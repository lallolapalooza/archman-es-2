Funciones/Subrutinas


subrutina zlahr2 (n, k, nb, a, lda, tau, t, ldt, y, ldy)
ZLAHR2 reduce el número especificado de primeras columnas de una matriz general rectangular A de modo que los elementos debajo de la subdiagonal especificada sean cero, y devuelve matrices auxiliares que son necesarias para aplicar la transformación a la parte no reducida de A.

Documentación de Función/Subrutina

subrutina zlahr2 (integer n, integer k, integer nb, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( nb ) tau, complex*16, dimension( ldt, nb ) t, integer ldt, complex*16, dimension( ldy, nb ) y, integer ldy)

ZLAHR2 reduce las primeras NB columnas de una matriz general compleja n x (n-k+1) A de modo que los elementos debajo de la k-ésima subdiagonal sean cero, y devuelve matrices auxiliares que son necesarias para aplicar la transformación a la parte no reducida de A.

Propósito:

!>
!> ZLAHR2 reduce las primeras NB columnas de una matriz general compleja n x (n-k+1)
!> A de modo que los elementos debajo de la k-ésima subdiagonal sean cero. La
!> reducción se realiza mediante una transformación unitaria de similitud
!> Q**H * A * Q. La subrutina devuelve las matrices V y T que determinan
!> Q como un reflector de bloque I - V*T*V**H, y también la matriz Y = A * V * T.
!>
!> Esta es una subrutina auxiliar llamada por ZGEHRD.
!>

Parámetros

N 
!>          N es INTEGER
!>          El orden de la matriz A.
!>

K

!>          K es INTEGER
!>          El desplazamiento para la reducción. Los elementos debajo de la
!>          k-ésima subdiagonal en las primeras NB columnas se reducen a cero.
!>          K < N.
!>

NB

!>          NB es INTEGER
!>          El número de columnas a reducir.
!>

A

!>          A es un array COMPLEX*16, dimensión (LDA,N-K+1)
!>          En la entrada, la matriz general A de n x (n-k+1).
!>          En la salida, los elementos en y sobre la k-ésima subdiagonal en
!>          las primeras NB columnas se sobrescriben con los elementos
!>          correspondientes de la matriz reducida; los elementos debajo de la k-ésima
!>          subdiagonal, junto con el array TAU, representan la matriz Q como un
!>          producto de reflectores elementales. Las otras columnas de A no cambian.
!>          Ver Detalles Adicionales.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A. LDA >= max(1,N).
!>

TAU

!>          TAU es un array COMPLEX*16, dimensión (NB)
!>          Los factores escalares de los reflectores elementales. Ver Detalles
!>          Adicionales.
!>

T

!>          T es un array COMPLEX*16, dimensión (LDT,NB)
!>          La matriz triangular superior T.
!>

LDT

!>          LDT es INTEGER
!>          La dimensión principal del array T. LDT >= NB.
!>

Y

!>          Y es un array COMPLEX*16, dimensión (LDY,NB)
!>          La matriz Y de n x nb.
!>

LDY

!>          LDY es INTEGER
!>          La dimensión principal del array Y. LDY >= N.
!>

Detalles Adicionales:

!>
!> La matriz Q se representa como un producto de nb reflectores elementales
!>
!>     Q = H(1) H(2) . . . H(nb).
!>
!> Cada H(i) tiene la forma
!>
!>     H(i) = I - tau * v * v**H
!>
!> donde tau es un escalar complejo, y v es un vector complejo con
!> v(1:i+k-1) = 0, v(i+k) = 1; v(i+k+1:n) se almacena en la salida en
!> A(i+k+1:n,i), y tau en TAU(i).
!>
!> Los elementos de los vectores v forman conjuntamente la matriz V de (n-k+1) x nb
!> que se necesita, junto con T e Y, para aplicar la transformación a la
!> parte no reducida de la matriz, utilizando una actualización de la forma:
!> A := (I - V*T*V**H) * (A - Y*V**H).
!>
!> El contenido de A en la salida se ilustra con el siguiente ejemplo
!> con n = 7, k = 3 y nb = 2:
!>
!>    ( a   a   a   a   a )
!>    ( a   a   a   a   a )
!>    ( a   a   a   a   a )
!>    ( h   h   a   a   a )
!>    ( v1  h   a   a   a )
!>    ( v1  v2  a   a   a )
!>    ( v1  v2  a   a   a )
!>
!> donde 'a' denota un elemento de la matriz original A, 'h' denota un
!> elemento modificado de la matriz de Hessenberg superior H, y vi denota un
!> elemento del vector que define H(i).
!>
!> Esta subrutina es una ligera modificación de ZLAHRD de LAPACK-3.0
!> que incorpora mejoras propuestas por Quintana-Orti y Van de
!> Gejin. Tenga en cuenta que las entradas de A(1:K,2:NB) difieren de las
!> devueltas por la ZLAHRD original de LAPACK-3.0. (Esta
!> subrutina no es compatible con versiones anteriores de ZLAHRD de LAPACK-3.0.)
!>

Referencias:

Gregorio Quintana-Orti y Robert van de Geijn, "Improving the performance of reduction to Hessenberg form," ACM Transactions on Mathematical Software, 32(2):180-194, June 2006.
