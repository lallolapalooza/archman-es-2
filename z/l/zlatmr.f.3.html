ZLATMR

Documentación de la Función/Subrutina

subrutina zlatmr (entero m, entero n, carácter dist, entero, dimensión( 4 ) iseed, carácter sym, complejo*16, dimensión( * ) d, entero mode, doble precisión cond, complejo*16 dmax, carácter rsign, carácter grade, complejo*16, dimensión( * ) dl, entero model, doble precisión condl, complejo*16, dimensión( * ) dr, entero moder, doble precisión condr, carácter pivtng, entero, dimensión( * ) ipivot, entero kl, entero ku, doble precisión sparse, doble precisión anorm, carácter pack, complejo*16, dimensión( lda, * ) a, entero lda, entero, dimensión( * ) iwork, entero info)

ZLATMR

Propósito:

!>
!>    ZLATMR genera matrices aleatorias de varios tipos para probar
!>    programas LAPACK.
!>
!>    ZLATMR opera aplicando la siguiente secuencia de
!>    operaciones:
!>
!>      Genera una matriz A con entradas aleatorias de distribución DIST
!>         que es simétrica si SYM='S', Hermítica si SYM='H', y
!>         no simétrica si SYM='N'.
!>
!>      Establece la diagonal a D, donde D puede ser introducida o
!>         calculada según MODE, COND, DMAX y RSIGN
!>         como se describe a continuación.
!>
!>      Califica la matriz, si se desea, desde la izquierda y/o derecha
!>         según lo especificado por GRADE. Las entradas DL, MODEL, CONDL, DR,
!>         MODER y CONDR también determinan la calificación como se describe
!>         a continuación.
!>
!>      Permuta, si se desea, las filas y/o columnas según lo especificado por
!>         PIVTNG y IPIVOT.
!>
!>      Establece entradas aleatorias a cero, si se desea, para obtener una matriz
!>         dispersa aleatoria según lo especificado por SPARSE.
!>
!>      Convierte A en una matriz de banda, si se desea, poniendo a cero la matriz
!>         fuera de una banda de ancho inferior KL y ancho superior KU.
!>
!>      Escala A, si se desea, para tener una entrada máxima ANORM.
!>
!>      Empaqueta la matriz si se desea. Las opciones especificadas por PACK son:
!>         sin empaquetar
!>         poner a cero la mitad superior (si es simétrica o Hermítica)
!>         poner a cero la mitad inferior (si es simétrica o Hermítica)
!>         almacenar la mitad superior columna a columna (si es simétrica o Hermítica
!>             o triangular superior cuadrada)
!>         almacenar la mitad inferior columna a columna (si es simétrica o Hermítica
!>             o triangular inferior cuadrada)
!>             igual que la mitad superior fila a fila si es simétrica
!>             igual que la mitad superior conjugada fila a fila si es Hermítica
!>         almacenar el triángulo inferior en formato de banda
!>             (si es simétrica o Hermítica)
!>         almacenar el triángulo superior en formato de banda
!>             (si es simétrica o Hermítica)
!>         almacenar toda la matriz en formato de banda
!>
!>    Nota: Si dos llamadas a ZLATMR difieren solo en el parámetro PACK,
!>          generarán matrices matemáticamente equivalentes.
!>
!>          Si dos llamadas a ZLATMR tienen ancho de banda completo (KL = M-1
!>          y KU = N-1), y difieren solo en los parámetros PIVTNG y PACK,
!>          entonces las matrices generadas diferirán solo en el orden de
!>          las filas y/o columnas, y de lo contrario
!>          contendrán los mismos datos. Esta consistencia no se mantiene y
!>          no se mantiene con un ancho de banda menor al completo.
!>

Parámetros

M 
!>          M es ENTERO
!>           Número de filas de A. No modificado.
!>

N

!>          N es ENTERO
!>           Número de columnas de A. No modificado.
!>

DIST

!>          DIST es CARACTER*1
!>           En la entrada, DIST especifica el tipo de distribución a utilizar
!>           para generar una matriz aleatoria.
!>           'U' => partes real e imaginaria son independientes
!>                  UNIFORME( 0, 1 )  ( 'U' para uniforme )
!>           'S' => partes real e imaginaria son independientes
!>                  UNIFORME( -1, 1 ) ( 'S' para simétrica )
!>           'N' => partes real e imaginaria son independientes
!>                  NORMAL( 0, 1 )   ( 'N' para normal )
!>           'D' => uniforme en el interior del disco unitario ( 'D' para disco )
!>           No modificado.
!>

ISEED

!>          ISEED es array de ENTEROS, dimensión (4)
!>           En la entrada, ISEED especifica la semilla del generador
!>           de números aleatorios. Deben estar entre 0 y 4095 inclusive,
!>           y ISEED(4) debe ser impar. El generador de números aleatorios
!>           usa una secuencia congruencial lineal limitada a enteros pequeños,
!>           y por lo tanto debe producir números aleatorios independientes de la máquina.
!>           Los valores de ISEED se cambian al salir, y pueden ser usados en la
!>           siguiente llamada a ZLATMR para continuar la misma secuencia de
!>           números aleatorios.
!>           Cambiado al salir.
!>

SYM

!>          SYM es CARACTER*1
!>           Si SYM='S', la matriz generada es simétrica.
!>           Si SYM='H', la matriz generada es Hermítica.
!>           Si SYM='N', la matriz generada no es simétrica.
!>           No modificado.
!>

D

!>          D es array de COMPLEJO*16, dimensión (min(M,N))
!>           En la entrada, este array especifica las entradas de la diagonal
!>           de la diagonal de A. D puede ser especificado
!>           en la entrada, o establecido según MODE y COND como se describe
!>           a continuación. Si la matriz es Hermítica, se tomará la parte real de D.
!>           Puede ser modificado al salir si MODE es distinto de cero.
!>

MODE

!>          MODE es ENTERO
!>           En la entrada describe cómo se usará D:
!>           MODE = 0 significa usar D como entrada
!>           MODE = 1 establece D(1)=1 y D(2:N)=1.0/COND
!>           MODE = 2 establece D(1:N-1)=1 y D(N)=1.0/COND
!>           MODE = 3 establece D(I)=COND**(-(I-1)/(N-1))
!>           MODE = 4 establece D(i)=1 - (i-1)/(N-1)*(1 - 1/COND)
!>           MODE = 5 establece D a números aleatorios en el rango
!>                    ( 1/COND , 1 ) tales que sus logaritmos
!>                    estén distribuidos uniformemente.
!>           MODE = 6 establece D a números aleatorios de la misma distribución
!>                    que el resto de la matriz.
!>           MODE < 0 tiene el mismo significado que ABS(MODE), excepto que
!>              el orden de los elementos de D se invierte.
!>           Por lo tanto, si MODE es positivo, D tiene entradas que van desde
!>              1 hasta 1/COND, si es negativo, desde 1/COND hasta 1,
!>           No modificado.
!>

COND

!>          COND es DOBLE PRECISIÓN
!>           En la entrada, se usa como se describe bajo MODE arriba.
!>           Si se usa, debe ser >= 1. No modificado.
!>

DMAX

!>          DMAX es COMPLEJO*16
!>           Si MODE no es -6, 0 ni 6, la diagonal se escala por
!>           DMAX / max(abs(D(i))), de modo que la entrada máxima absoluta
!>           de la diagonal sea abs(DMAX). Si DMAX es complejo (o cero),
!>           la diagonal se escalará por un número complejo (o cero).
!>

RSIGN

!>          RSIGN es CARACTER*1
!>           Si MODE no es -6, 0 ni 6, especifica el signo de la diagonal
!>           de la siguiente manera:
!>           'T' => las entradas de la diagonal se multiplican por un número complejo
!>                  aleatorio con valor absoluto 1, distribuido uniformemente.
!>           'F' => la diagonal no se modifica.
!>

GRADE

!>          GRADE es CARACTER*1
!>           Especifica si se debe calificar la matriz.
!>           'N' => no calificar
!>           'L' => calificar solo por la izquierda
!>           'R' => calificar solo por la derecha
!>           'B' => calificar por ambos lados
!>           No modificado.
!>

DL

!>          DL es COMPLEJO*16 array, dimensión (M)
!>           Si GRADE = 'L' o 'B', DL contiene las entradas de la matriz
!>           que se aplicará por la izquierda.
!>

MODEL

!>          MODEL es ENTERO
!>           Si GRADE = 'L' o 'B', MODEL describe cómo se establece DL.
!>           Ver descripción de MODE.
!>

CONDL

!>          CONDL es DOBLE PRECISIÓN
!>           Si GRADE = 'L' o 'B', CONDL se usa como se describe en MODE.
!>

DR

!>          DR es COMPLEJO*16 array, dimensión (N)
!>           Si GRADE = 'R' o 'B', DR contiene las entradas de la matriz
!>           que se aplicará por la derecha.
!>

MODER

!>          MODER es ENTERO
!>           Si GRADE = 'R' o 'B', MODER describe cómo se establece DR.
!>           Ver descripción de MODE.
!>

CONDR

!>          CONDR es DOBLE PRECISIÓN
!>           Si GRADE = 'R' o 'B', CONDR se usa como se describe en MODE.
!>

PIVTNG

!>          PIVTNG es CARACTER*1
!>           Especifica si se debe permutar las filas y/o columnas.
!>           'N' => no permutar
!>           'R' => permutar filas aleatoriamente
!>           'C' => permutar columnas aleatoriamente
!>           'B' => permutar filas y columnas aleatoriamente
!>           No modificado.
!>

IPIVOT

!>          IPIVOT es array de ENTEROS, dimensión (max(M,N))
!>           Si PIVTNG = 'R', 'C' o 'B', IPIVOT contiene los índices de
!>           permutación. IPIVOT(I) = J significa que la fila/columna J
!>           original se ha movido a la posición I.
!>           Los valores de IPIVOT son aleatorios entre 1 y M (si PIVTNG='R')
!>           o entre 1 y N (si PIVTNG='C' o 'B').
!>           Cambiado al salir.
!>

KL

!>          KL es ENTERO
!>           Si KL >= 0, la matriz se convierte en una matriz de banda
!>           con ancho inferior KL, poniendo a cero todas las entradas
!>           con índice de fila menos índice de columna mayor que KL.
!>           Si KL < 0, se omite la operación de banda inferior.
!>           No modificado.
!>

KU

!>          KU es ENTERO
!>           Si KU >= 0, la matriz se convierte en una matriz de banda
!>           con ancho superior KU, poniendo a cero todas las entradas
!>           con índice de columna menos índice de fila mayor que KU.
!>           Si KU < 0, se omite la operación de banda superior.
!>           No modificado.
!>

SPARSE

!>          SPARSE es DOBLE PRECISIÓN
!>           Si 0 < SPARSE < 1, SPARSE es la probabilidad de que una entrada
!>           aleatoria sea puesta a cero.
!>           Si SPARSE <= 0 o SPARSE >= 1, no se pone a cero ninguna entrada.
!>           No modificado.
!>

ANORM

!>          ANORM es DOBLE PRECISIÓN
!>           Si ANORM >= 0, la matriz A se escala de manera que su norma 1 sea
!>           igual a ANORM. La norma 1 se calcula como la suma máxima de los valores
!>           absolutos de las columnas.
!>           No modificado.
!>

PACK

!>          PACK es CARACTER*1
!>           Especifica el formato de salida de la matriz A.
!>           'N' => no empaquetar (formato de matriz estándar).
!>           'U' => almacenar solo la mitad superior (si M=N o si M>N).
!>                  Si es simétrica o Hermítica, solo la mitad superior
!>                  incluyendo la diagonal se almacena columna a columna.
!>           'L' => almacenar solo la mitad inferior (si M=N o si M<N).
!>                  Si es simétrica o Hermítica, solo la mitad inferior
!>                  incluyendo la diagonal se almacena columna a columna.
!>           'Z' => almacenar solo la mitad superior en formato de banda.
!>                  Si es simétrica o Hermítica, solo la mitad superior
!>                  incluyendo la diagonal se almacena en formato de banda.
!>           'B' => almacenar solo la mitad inferior en formato de banda.
!>                  Si es simétrica o Hermítica, solo la mitad inferior
!>                  incluyendo la diagonal se almacena en formato de banda.
!>           'S' => almacenar la matriz completa en formato de banda.
!>           No modificado.
!>

A

!>          A es COMPLEJO*16 array, dimensión (LDA, N)
!>           En la salida, A contiene la matriz generada.
!>

LDA

!>          LDA es ENTERO
!>           El tamaño de la primera dimensión de A. Debe ser al menos max(1, M).
!>           No modificado.
!>

IWORK

!>          IWORK es array de ENTEROS, dimensión (max(M,N))
!>           Espacio de trabajo. Contiene índices de permutación si PIVTNG = 'R','C','B'.
!>

INFO

!>          INFO es ENTERO
!>           = 0: éxito
!>           < 0: si INFO = -i, el i-ésimo argumento tenía un valor
!>                ilegal. Esto solo ocurre si i > 4 y se refiere a
!>                parámetros de grado o de banda.
!>

ZLATMR

Genera una matriz de prueba de formato general.

Parámetros

M

INTEGER. Número de filas de la matriz a generar.

N

INTEGER. Número de columnas de la matriz a generar.

DIST

CHARACTER*1. Especifica la distribución de los valores de la matriz A. 'U' = uniforme en (0,1) 'S' = simétrica alrededor de 0, con valores de probabilidad 'N' = normal multivariada 'D' = discreta: con prob p, es 1, con prob 1-p, es 0. 'L' = logarítmica (para probar la precisión limitada) 'C' = de condición especificada 'E' = de error especificado 'Z' = valores cero

SYM

CHARACTER*1. Especifica las propiedades de simetría de la matriz. 'N' = no simétrica 'S' = simétrica 'H' = hermítica

MODE

INTEGER. Especifica cómo se calculan los valores de la diagonal D. 0 = D se especifica en la entrada. 1 = D se genera aleatoriamente. 2 = D se genera para ser bien condicionada. 3 = D se genera para ser mal condicionada. 4 = D se genera de manera que se produzca un número específico de entradas no cero. 5 = D se genera como una matriz de Hilbert generalizada. -1 a -5 = lo mismo que 1 a 5, pero con valores de entrada D multiplicados por -1.

COND

DOUBLE PRECISION. Cuando MODE no es 0, especifica el número de condición de la matriz D generada.

D

COMPLEX*16 array, dimension (M). En la entrada, si MODE=0, este array especifica las entradas diagonales de una matriz diagonal. En la salida, D contendrá la diagonal de la matriz A.

RSIGN

CHARACTER*1. Especifica los signos de las entradas de la diagonal D. 'R' = signos aleatorios 'F' = signos fijos (todos positivos) 'U' = signo de la fila 'C' = signo de la columna No modificado.

DMAX

DOUBLE PRECISION. Cuando MODE>0, este parámetro especifica la magnitud máxima permitida para las entradas de D. No modificado.

GRADE

CHARACTER*1. Especifica la graduación de la matriz de la siguiente manera: 'N' => sin graduación 'L' => la matriz se premultiplica por diag( DL ) (solo si la matriz no es simétrica) 'R' => la matriz se postmultiplica por diag( DR ) (solo si la matriz no es simétrica) 'B' => la matriz se premultiplica por diag( DL ) y postmultiplica por diag( DR ) (solo si la matriz no es simétrica) 'H' => la matriz se premultiplica por diag( DL ) y postmultiplica por diag( CONJG(DL) ) (solo si la matriz es hermitiana o no simétrica) 'S' => la matriz se premultiplica por diag( DL ) y postmultiplica por diag( DL ) (solo si la matriz es simétrica o no simétrica) 'E' => la matriz se premultiplica por diag( DL ) y postmultiplica por inv( diag( DL ) ) ( 'S' para similaridad ) (solo si la matriz no es simétrica) Nota: si GRADE='S', entonces M debe ser igual a N. No modificado.

DL

COMPLEX*16 array, dimension (M). Si MODEL=0, entonces en la entrada este array especifica las entradas diagonales de una matriz diagonal utilizada como se describe en GRADE anteriormente. Si MODEL no es cero, entonces DL se establecerá según MODEL y CONDL, análogo a cómo D se establece según MODE y COND (excepto que no hay parámetro DMAX para DL). Si GRADE='E', entonces DL no puede tener entradas cero. No referenciado si GRADE = 'N' o 'R'. Cambiado en la salida.

MODEL

INTEGER. Esto especifica cómo se va a calcular el array diagonal DL, igual que MODE especifica cómo se va a calcular D. No modificado.

CONDL

DOUBLE PRECISION. Cuando MODEL no es cero, esto especifica el número de condición del DL calculado. No modificado.

DR

COMPLEX*16 array, dimension (N). Si MODER=0, entonces en la entrada este array especifica las entradas diagonales de una matriz diagonal utilizada como se describe en GRADE anteriormente. Si MODER no es cero, entonces DR se establecerá según MODER y CONDR, análogo a cómo D se establece según MODE y COND (excepto que no hay parámetro DMAX para DR). No referenciado si GRADE = 'N', 'L', 'H' o 'S'. Cambiado en la salida.

MODER

INTEGER. Esto especifica cómo se va a calcular el array diagonal DR, igual que MODE especifica cómo se va a calcular D. No modificado.

CONDR

DOUBLE PRECISION. Cuando MODER no es cero, esto especifica el número de condición del DR calculado. No modificado.

PIVTNG

CHARACTER*1. En la entrada especifica las permutaciones de pivote de la siguiente manera: 'N' o ' ' => ninguna. 'L' => pivote izquierdo o de fila (la matriz debe ser no simétrica). 'R' => pivote derecho o de columna (la matriz debe ser no simétrica). 'B' o 'F' => ambos o pivote completo, es decir, en ambos lados. En este caso, M debe ser igual a N. Si dos llamadas a ZLATMR tienen ambas ancho de banda completo (KL = M-1 y KU = N-1), y solo difieren en los parámetros PIVTNG y PACK, entonces las matrices generadas diferirán solo en el orden de las filas y/o columnas, y de lo contrario contendrán los mismos datos. Esta consistencia no puede ser mantenida con un ancho de banda menor que el completo.

IPIVOT

INTEGER array, dimension (N o M). Este array especifica la permutación utilizada. Después de generar la matriz básica, las filas, columnas o ambas se permutan. Si, por ejemplo, se selecciona pivoteo de fila, ZLATMR comienza con la *última* fila e interscambia la M-ésima y la IPIVOT(M)-ésima fila, luego se mueve a la penúltima fila, intercambiando la (M-1)-ésima y la IPIVOT(M-1)-ésima fila, y así sucesivamente. En términos de , la permutación es (1 IPIVOT(1)) (2 IPIVOT(2)) ... (M IPIVOT(M)) donde el ciclo más a la derecha se aplica primero. Este es el *inverso* del efecto del pivoteo en LINPACK. La idea es que al factorizar (con pivoteo) una matriz identidad que ha sido permutada inversamente de esta manera debería resultar en un vector de pivote idéntico a IPIVOT. No referenciado si PIVTNG = 'N'. No modificado.

KL

INTEGER. En la entrada especifica el ancho de banda inferior de la matriz. Por ejemplo, KL=0 implica triangular superior, KL=1 implica Hessenberg superior, y KL al menos M-1 implica que la matriz no es de banda. Debe ser igual a KU si la matriz es simétrica o hermitiana. No modificado.

KU

INTEGER. En la entrada especifica el ancho de banda superior de la matriz. Por ejemplo, KU=0 implica triangular inferior, KU=1 implica Hessenberg inferior, y KU al menos N-1 implica que la matriz no es de banda. Debe ser igual a KL si la matriz es simétrica o hermitiana. No modificado.

SPARSE

DOUBLE PRECISION. En la entrada especifica la dispersión de la matriz si se va a generar una matriz dispersa. SPARSE debe estar entre 0 y 1. Para generar una matriz dispersa, para cada entrada de matriz se genera un número aleatorio uniforme ( 0, 1 ), x, y se compara con SPARSE; si x es mayor, la entrada de la matriz no se modifica y si x es menor, la entrada se establece en cero. Por lo tanto, en promedio, una fracción SPARSE de las entradas se establecerá en cero. No modificado.

ANORM

DOUBLE PRECISION. En la entrada especifica la entrada máxima de la matriz de salida (la matriz de salida se multiplicará por una constante para que su entrada absoluta más grande sea igual a ANORM) si ANORM es no negativo. Si ANORM es negativo, no se realiza escalado. No modificado.

PACK

CHARACTER*1. En la entrada especifica el empaquetado de la matriz de la siguiente manera: 'N' => sin empaquetar 'U' => pone a cero todas las entradas subdiagonales (si es simétrica o hermitiana) 'L' => pone a cero todas las entradas superdiagonales (si es simétrica o hermitiana) 'C' => almacena el triángulo superior columna por columna (solo si la matriz es simétrica, hermitiana o triangular superior cuadrada) 'R' => almacena el triángulo inferior columna por columna (solo si la matriz es simétrica, hermitiana o triangular inferior cuadrada) (igual que la mitad superior fila por fila si es simétrica) (igual que la mitad superior conjugada fila por fila si es hermitiana) 'B' => almacena el triángulo inferior en un esquema de almacenamiento de banda (solo si la matriz es simétrica o hermitiana) 'Q' => almacena el triángulo superior en un esquema de almacenamiento de banda (solo si la matriz es simétrica o hermitiana) 'Z' => almacena toda la matriz en un esquema de almacenamiento de banda (el pivoteo se puede proporcionar utilizando esta opción para almacenar A en las filas finales de el almacenamiento asignado) Usando estas opciones, se pueden obtener los varios esquemas de almacenamiento empaquetado y de banda de LAPACK: GB => usar 'Z' PB, HB o TB => usar 'B' o 'Q' PP, HP o TP => usar 'C' o 'R' Si dos llamadas a ZLATMR difieren solo en el parámetro PACK, generarán matrices matemáticamente equivalentes. No modificado.

A

COMPLEX*16 array, dimension (LDA,N). En la salida A es la matriz de prueba deseada. Solo las entradas de A que son significativas en la salida serán referenciadas (incluso si A está en formato de almacenamiento empaquetado o de banda). Las 'esquinas no ocupadas' de A en formato de banda se pondrán a cero.

LDA

INTEGER. En la entrada LDA especifica la primera dimensión de A tal como se declara en el programa de llamada. Si PACK='N', 'U' o 'L', LDA debe ser al menos max ( 1, M ). Si PACK='C' o 'R', LDA debe ser al menos 1. Si PACK='B' o 'Q', LDA debe ser MIN ( KU+1, N ). Si PACK='Z', LDA debe ser al menos KUU+KLL+1, donde KUU = MIN ( KU, N-1 ) y KLL = MIN ( KL, M-1 ). No modificado.

IWORK

INTEGER array, dimension (N o M). Espacio de trabajo. No referenciado si PIVTNG = 'N'. Cambiado en la salida.

INFO

INTEGER.   !

  ! This routine generates a triangular or triangular-band matrix A of order

  ! N, with a spectral norm of ANORM, and an infinity norm of DMAX.

  !

  ! The matrix A is generated by the algorithm

  !

  !       A = U*D*V**T  or  A = U*D*V**H

  !

  ! where U and V are random orthogonal matrices, and D is a diagonal matrix

  ! with diagonal entries chosen randomly from [-1,1].

  !

  ! The generation of U and V may be controlled by the value of IRAN.

  !

  ! The triangle (upper or lower) may be specified by UPLO.

  !

  ! The matrix may be packed into one of the following formats:

  !       PACK = 'N'   (No packing)

  !       PACK = 'U'   (Upper triangular packed)

  !       PACK = 'L'   (Lower triangular packed)

  !       PACK = 'C'   (Lower triangular packed)

  !       PACK = 'R'   (Upper triangular packed)

  !

  ! The matrix may be symmetric or hermitian, or skew-symmetric or skew-hermitian.

  !       SYM = 'S'   (Symmetric)

  !       SYM = 'H'   (Hermitian)

  !       SYM = 'K'   (Skew-symmetric)

  !       SYM = 'Q'   (Skew-hermitian)

  !

  ! The matrix may be scaled to have a specified infinity norm.

  !       EQUED = 'Y'   (Matrix has been scaled)

  !       EQUED = 'N'   (Matrix has not been scaled)

  !

  ! The matrix may be generated with a specified condition number.

  !       SEQ = 'G'   (Generate matrix with random condition number)

  !       SEQ = 'R'   (Generate matrix with random entries)

  !

  ! The diagonal entries may be scaled to be within [TOL, 1].

  !

  ! The matrix may be generated as a band matrix.

  !       KL = Number of sub-diagonals

  !       KU = Number of super-diagonales

  !

  ! If ANORM is specified, the matrix is scaled to have spectral norm ANORM.

  ! If DMAX is specified, the matrix is scaled to have infinity norm DMAX.

  !

  ! Arguments:

  ! ----------

  !

  ! N       - INTEGER

  !         The order of the matrix A. N >= 0.

  !

  ! TOL     - REAL (KIND=8)

  !         Tolerance for the diagonal entries. Diagonal entries are scaled

  !         to lie in the range [TOL, 1].

  !

  ! IRAN    - INTEGER

  !         Controls the generation of random matrices U and V.

  !         = 0: U and V are not generated.

  !         = 1: U and V are generated randomly.

  !         = 2: U is generated randomly, V is the identity matrix.

  !         = 3: U is the identity matrix, V is generated randomly.

  !

  ! D       - REAL (KIND=8) array, DIMENSION (N)

  !         Diagonal entries of the matrix.

  !

  ! TEMP    - COMPLEX (KIND=8) array, DIMENSION (N)

  !         Temporary storage for diagonal entries.

  !

  ! Z       - COMPLEX (KIND=8) array, DIMENSION (N, N)

  !         Matrix for generating U and V.

  !

  ! NaOMe   - CHARACTER*1

  !         Specifies the name of the matrix.

  !         = 'A': General matrix

  !         = 'S': Symmetric matrix

  !         = 'H': Hermitian matrix

  !         = 'K': Skew-symmetric matrix

  !         = 'Q': Skew-hermitian matrix

  !

  ! NaOMe2  - CHARACTER*1

  !         Specifies the type of the matrix.

  !         = 'G': General matrix

  !         = 'R': Random matrix

  !

  ! A       - COMPLEX (KIND=8) array, DIMENSION (LDA, *)

  !         On exit, A contains the generated matrix.

  !

  ! LDA     - INTEGER

  !         The leading dimension of the array A.

  !

  ! SEQ     - CHARACTER*1

  !         Specifies the sequence of matrix generation.

  !         = 'G': Generate matrix with random condition number.

  !         = 'R': Generate matrix with random entries.

  !

  ! SYM     - CHARACTER*1

  !         Specifies the symmetry of the matrix.

  !         = 'N': No symmetry

  !         = 'S': Symmetric

  !         = 'H': Hermitian

  !         = 'K': Skew-symmetric

  !         = 'Q': Skew-hermitian

  !

  ! UPLO    - CHARACTER*1

  !         Specifies whether to generate the upper or lower triangle.

  !         = 'U': Upper triangle

  !         = 'L': Lower triangle

  !

  ! PACK    - CHARACTER*1

  !         Specifies the packing format.

  !         = 'N': No packing

  !         = 'U': Upper triangular packed

  !         = 'L': Lower triangular packed

  !         = 'C': Lower triangular packed (complex)

  !         = 'R': Upper triangular packed (real)

  !

  ! EQUED   - CHARACTER*1

  !         Specifies whether the matrix has been pre-conditioned (scaled).

  !         = 'Y': Matrix has been pre-conditioned.

  !         = 'N': Matrix has not been pre-conditioned.

  !

  ! KL      - INTEGER

  !         Number of sub-diagonals.

  !

  ! KU      - INTEGER

  !         Number of super-diagonales.

  !

  ! ANORM   - REAL (KIND=8)

  !         Spectral norm of the generated matrix.

  !

  ! DMAX    - REAL (KIND=8)

  !         Maximum absolute row or column sum (infinity norm).

  !

  ! R       - REAL (KIND=8) array, DIMENSION (N)

  !         Row scaling vector.

  !

  ! C       - REAL (KIND=8) array, DIMENSION (N)

  !         Column scaling vector.

  !

  ! WORK    - COMPLEX (KIND=8) array, DIMENSION (LWORK)

  !         Workspace array.

  !

  ! LWORK   - INTEGER

  !         The dimension of the array WORK. LWORK >= N*N.

  !

  ! INFO    - INTEGER

  !         = 0:  Successful exit

  !         < 0:  If INFO = -i, the i-th argument had an illegal value.

  !         > 0:  If INFO = i, then i is the value of the first invalid argument

  !               encountered during the generation of the matrix.

  !         For example:

  !           -22 => SPARSE not in range 0. to 1.

  !           -24 => PACK illegal string, or PACK='U', 'L', 'B' or 'Q'

  !                  and SYM='N', or PACK='C' and SYM='N' and either KL

  !                  not equal to 0 or N not equal to M, or PACK='R' and

  !                  SYM='N', and either KU not equal to 0 or N not equal

  !                  to M

  !           -26 => LDA too small

  !             1 => Error return from ZLATM1 (computing D)

  !             2 => Cannot scale diagonal to DMAX (max. entry is 0)

  !             3 => Error return from ZLATM1 (computing DL)

  !             4 => Error return from ZLATM1 (computing DR)

  !             5 => ANORM is positive, but matrix constructed prior to

  !                  attempting to scale it to have norm ANORM, is zero

  !
