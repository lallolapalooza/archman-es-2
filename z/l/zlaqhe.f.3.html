subroutine zlaqhe (character uplo, integer n, complex*16, dimension( lda, * ) a, integer lda, double precision, dimension( * ) s, double precision scond, double precision amax, character equed)

ZLAQHE escala una matriz Hermítica.

Propósito:

!>
!> ZLAQHE equilibra una matriz Hermítica A utilizando los factores de escala
!> en el vector S.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          Especifica si la parte triangular superior o inferior de la
!>          matriz Hermítica A está almacenada.
!>          = 'U':  Triangular superior
!>          = 'L':  Triangular inferior
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

A

!>          A es un array COMPLEX*16, de dimensión (LDA,N)
!>          En la entrada, la matriz Hermítica A.  Si UPLO = 'U', la parte
!>          superior triangular de N por N de A contiene la parte triangular
!>          superior de la matriz A, y la parte estrictamente triangular
!>          inferior de A no se referencia.  Si UPLO = 'L', la parte
!>          inferior triangular de N por N de A contiene la parte triangular
!>          inferior de la matriz A, y la parte estrictamente triangular
!>          superior de A no se referencia.
!>
!>          En la salida, si EQUED = 'Y', la matriz equilibrada:
!>          diag(S) * A * diag(S).
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(N,1).
!>

S

!>          S es un array DOUBLE PRECISION, de dimensión (N)
!>          Los factores de escala para A.
!>

SCOND

!>          SCOND es DOUBLE PRECISION
!>          Relación del S(i) más pequeño con el S(i) más grande.
!>

AMAX

!>          AMAX es DOUBLE PRECISION
!>          Valor absoluto de la entrada de matriz más grande.
!>

EQUED

!>          EQUED es CHARACTER*1
!>          Especifica si se realizó o no el equilibrio.
!>          = 'N':  No se realizó el equilibrio.
!>          = 'Y':  Se realizó el equilibrio, es decir, A ha sido reemplazado por
!>                  diag(S) * A * diag(S).
!>

Parámetros Internos:

!>  THRESH es un valor umbral utilizado para decidir si se debe realizar el
!>  escalado basándose en la relación de los factores de escala.  Si SCOND < THRESH,
!>  se realiza el escalado.
!>
!>  LARGE y SMALL son valores umbral utilizados para decidir si se debe
!>  realizar el escalado basándose en el tamaño absoluto del elemento de matriz
!>  más grande.
!>  Si AMAX > LARGE o AMAX < SMALL, se realiza el escalado.
!>
