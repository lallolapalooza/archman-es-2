DOCUMENTACIÓN DE FUNCIÓN/SUBRUTINA

subrutina zlaghe (integer n, integer k, double precision, dimension( * ) d, complex*16, dimension( lda, * ) a, integer lda, integer, dimension( 4 ) iseed, complex*16, dimension( * ) work, integer info)

ZLAGHE

Propósito:

!>
!> ZLAGHE genera una matriz hermitiana compleja A, pre- y post-multiplicando
!> una matriz diagonal real D con una matriz unitaria aleatoria:
!> A = U*D*U'. El semi-ancho de banda puede ser reducido a k mediante
!> transformaciones unitarias adicionales.
!>

Parámetros

N 
!>          N es ENTERO
!>          El orden de la matriz A.  N >= 0.
!>

K

!>          K es ENTERO
!>          El número de subdiagonales distintas de cero dentro de la banda de A.
!>          0 <= K <= N-1.
!>

D

!>          D es un array de DOBLE PRECISIÓN, dimensión (N)
!>          Los elementos diagonales de la matriz diagonal D.
!>

A

!>          A es un array de COMPLEJO*16, dimensión (LDA,N)
!>          La matriz hermitiana n por n generada A (se almacena la matriz
!>          completa).
!>

LDA

!>          LDA es ENTERO
!>          La dimensión principal del array A.  LDA >= N.
!>

ISEED

!>          ISEED es un array de ENTEROS, dimensión (4)
!>          En la entrada, la semilla del generador de números aleatorios; los
!>          elementos del array deben estar entre 0 y 4095, y ISEED(4) debe
!>          ser impar.
!>          En la salida, la semilla se actualiza.
!>

WORK

!>          WORK es un array de COMPLEJO*16, dimensión (2*N)
!>

INFO

!>          INFO es ENTERO
!>          = 0: salida exitosa
!>          < 0: si INFO = -i, el i-ésimo argumento tuvo un valor ilegal
!>
