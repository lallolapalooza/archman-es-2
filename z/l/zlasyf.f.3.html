subrutina zlasyf (carácter uplo, entero n, entero nb, entero kb, complejo*16, dimensión( lda, * ) a, entero lda, entero, dimensión( * ) ipiv, complejo*16, dimensión( ldw, * ) w, entero ldw, entero info)

ZLASYF calcula una factorización parcial de una matriz simétrica compleja utilizando el método de pivoteo diagonal de Bunch-Kaufman.

Propósito:

!>
!> ZLASYF calcula una factorización parcial de una matriz simétrica compleja
!> A utilizando el método de pivoteo diagonal de Bunch-Kaufman. La factorización
!> parcial tiene la forma:
!>
!> A  =  ( I  U12 ) ( A11  0  ) (  I       0    )  si UPLO = 'U', o:
!>       ( 0  U22 ) (  0   D  ) ( U12**T U22**T )
!>
!> A  =  ( L11  0 ) ( D    0  ) ( L11**T L21**T )  si UPLO = 'L'
!>       ( L21  I ) ( 0   A22 ) (  0       I    )
!>
!> donde el orden de D es como máximo NB. El orden real se devuelve en
!> el argumento KB, y es NB o NB-1, o N si N <= NB.
!> Tenga en cuenta que U**T denota la transpuesta de U.
!>
!> ZLASYF es una subrutina auxiliar llamada por ZSYTRF. Utiliza código bloqueado
!> (llamando a BLAS de Nivel 3) para actualizar la submatriz A11 (si UPLO = 'U') o
!> A22 (si UPLO = 'L').
!>

Parámetros

UPLO 
!>          UPLO es CARÁCTER*1
!>          Especifica si la parte triangular superior o inferior de la
!>          matriz simétrica A está almacenada:
!>          = 'U':  Triangular superior
!>          = 'L':  Triangular inferior
!>

N

!>          N es ENTERO
!>          El orden de la matriz A.  N >= 0.
!>

NB

!>          NB es ENTERO
!>          El número máximo de columnas de la matriz A que deben
!>          factorizarse.  NB debe ser al menos 2 para permitir bloques de pivote
!>          de 2x2.
!>

KB

!>          KB es ENTERO
!>          El número de columnas de A que se factorizan realmente.
!>          KB es NB-1 o NB, o N si N <= NB.
!>

A

!>          A es matriz COMPLEX*16, dimensión (LDA,N)
!>          En la entrada, la matriz simétrica A.  Si UPLO = 'U', la parte
!>          superior triangular n x n de A contiene la parte triangular
!>          superior de la matriz A, y la parte triangular estrictamente inferior
!>          de A no se hace referencia.  Si UPLO = 'L', la parte inferior
!>          triangular n x n de A contiene la parte triangular
!>          inferior de la matriz A, y la parte triangular estrictamente superior
!>          de A no se hace referencia.
!>          En la salida, A contiene detalles de la factorización parcial.
!>

LDA

!>          LDA es ENTERO
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

IPIV

!>          IPIV es matriz ENTERO, dimensión (N)
!>          Detalles de los intercambios y la estructura de bloques de D.
!>
!>          Si UPLO = 'U':
!>             Sólo los últimos KB elementos de IPIV se establecen.
!>
!>             Si IPIV(k) > 0, entonces las filas y columnas k e IPIV(k) fueron
!>             intercambiadas y D(k,k) es un bloque diagonal de 1x1.
!>
!>             Si IPIV(k) = IPIV(k-1) < 0, entonces las filas y columnas
!>             k-1 e -IPIV(k) fueron intercambiadas y D(k-1:k,k-1:k)
!>             es un bloque diagonal de 2x2.
!>
!>          Si UPLO = 'L':
!>             Sólo los primeros KB elementos de IPIV se establecen.
!>
!>             Si IPIV(k) > 0, entonces las filas y columnas k e IPIV(k) fueron
!>             intercambiadas y D(k,k) es un bloque diagonal de 1x1.
!>
!>             Si IPIV(k) = IPIV(k+1) < 0, entonces las filas y columnas
!>             k+1 e -IPIV(k) fueron intercambiadas y D(k:k+1,k:k+1)
!>             es un bloque diagonal de 2x2.
!>

W

!>          W es matriz COMPLEX*16, dimensión (LDW,NB)
!>

LDW

!>          LDW es ENTERO
!>          La dimensión principal del array W.  LDW >= max(1,N).
!>

INFO

!>          INFO es ENTERO
!>          = 0: salida exitosa
!>          > 0: si INFO = k, D(k,k) es exactamente cero. La factorización
!>               se ha completado, pero la matriz diagonal por bloques D es
!>               exactamente singular.
!>
