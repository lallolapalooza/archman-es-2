Funciones/Subrutinas


subrutina zlatrd (uplo, n, nb, a, lda, e, tau, w, ldw)
ZLATRD reduce las primeras nb filas y columnas de una matriz A simétrica/hermitiana a forma tridiagonal real mediante una transformación de semejanza unitaria.

Documentación de la Función/Subrutina

subrutina zlatrd (character uplo, integer n, integer nb, complex*16, dimension( lda, * ) a, integer lda, double precision, dimension( * ) e, complex*16, dimension( * ) tau, complex*16, dimension( ldw, * ) w, integer ldw)

ZLATRD reduce las primeras nb filas y columnas de una matriz A simétrica/hermitiana a forma tridiagonal real mediante una transformación de semejanza unitaria.

Propósito:

!>
!> ZLATRD reduce NB filas y columnas de una matriz A Hermitiana compleja a
!> forma tridiagonal Hermitiana mediante una transformación de semejanza unitaria
!> Q**H * A * Q, y devuelve las matrices V y W que son
!> necesarias para aplicar la transformación a la parte no reducida de A.
!>
!> Si UPLO = 'U', ZLATRD reduce las últimas NB filas y columnas de una
!> matriz, de la cual se proporciona el triángulo superior;
!> si UPLO = 'L', ZLATRD reduce las primeras NB filas y columnas de una
!> matriz, de la cual se proporciona el triángulo inferior.
!>
!> Esta es una subrutina auxiliar llamada por ZHETRD.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          Especifica si la parte triangular superior o inferior de la
!>          matriz Hermitiana A está almacenada:
!>          = 'U': Triángulo superior
!>          = 'L': Triángulo inferior
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.
!>

NB

!>          NB es INTEGER
!>          El número de filas y columnas a reducir.
!>

A

!>          A es un array COMPLEX*16, de dimensión (LDA,N)
!>          En la entrada, la matriz Hermitiana A. Si UPLO = 'U', la parte
!>          superior derecha de n por n de A contiene la parte triangular
!>          superior de la matriz A, y la parte estrictamente triangular
!>          inferior de A no se referencia. Si UPLO = 'L', la parte
!>          inferior izquierda de n por n de A contiene la parte triangular
!>          inferior de la matriz A, y la parte estrictamente triangular
!>          superior de A no se referencia.
!>          En la salida:
!>          si UPLO = 'U', las últimas NB columnas se han reducido a
!>            forma tridiagonal, con los elementos diagonales sobrescribiendo
!>            los elementos diagonales de A; los elementos por encima de la diagonal
!>            junto con el array TAU, representan la matriz unitaria Q como un
!>            producto de reflectores elementales;
!>          si UPLO = 'L', las primeras NB columnas se han reducido a
!>            forma tridiagonal, con los elementos diagonales sobrescribiendo
!>            los elementos diagonales de A; los elementos por debajo de la diagonal
!>            junto con el array TAU, representan la matriz unitaria Q como un
!>            producto de reflectores elementales.
!>          Ver Detalles Adicionales.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A. LDA >= max(1,N).
!>

E

!>          E es un array DOUBLE PRECISION, de dimensión (N-1)
!>          Si UPLO = 'U', E(n-nb:n-1) contiene los elementos de la superdiagonal
!>          de las últimas NB columnas de la matriz reducida;
!>          si UPLO = 'L', E(1:nb) contiene los elementos de la subdiagonal
!>          de las primeras NB columnas de la matriz reducida.
!>

TAU

!>          TAU es un array COMPLEX*16, de dimensión (N-1)
!>          Los factores escalares de los reflectores elementales, almacenados en
!>          TAU(n-nb:n-1) si UPLO = 'U', y en TAU(1:nb) si UPLO = 'L'.
!>          Ver Detalles Adicionales.
!>

W

!>          W es un array COMPLEX*16, de dimensión (LDW,NB)
!>          La matriz n por nb W requerida para actualizar la parte no reducida
!>          de A.
!>

LDW

!>          LDW es INTEGER
!>          La dimensión principal del array W. LDW >= max(1,N).
!>

Detalles Adicionales:

!>
!>  Si UPLO = 'U', la matriz Q se representa como un producto de reflectores
!>  elementales
!>
!>     Q = H(n) H(n-1) . . . H(n-nb+1).
!>
!>  Cada H(i) tiene la forma
!>
!>     H(i) = I - tau * v * v**H
!>
!>  donde tau es un escalar complejo, y v es un vector complejo con
!>  v(i:n) = 0 y v(i-1) = 1; v(1:i-1) se almacena en la salida en A(1:i-1,i),
!>  y tau en TAU(i-1).
!>
!>  Si UPLO = 'L', la matriz Q se representa como un producto de reflectores
!>  elementales
!>
!>     Q = H(1) H(2) . . . H(nb).
!>
!>  Cada H(i) tiene la forma
!>
!>     H(i) = I - tau * v * v**H
!>
!>  donde tau es un escalar complejo, y v es un vector complejo con
!>  v(1:i) = 0 y v(i+1) = 1; v(i+1:n) se almacena en la salida en A(i+1:n,i),
!>  y tau en TAU(i).
!>
!>  Los elementos de los vectores v juntos forman la matriz V de n por nb
!>  que se necesita, junto con W, para aplicar la transformación a la parte no reducida
!>  de la matriz, utilizando una actualización Hermitiana rank-2k de la forma:
!>  A := A - V*W**H - W*V**H.
!>
!>  Los contenidos de A en la salida se ilustran con los siguientes ejemplos
!>  con n = 5 y nb = 2:
!>
!>  si UPLO = 'U':                       si UPLO = 'L':
!>
!>    (  a   a   a   v4  v5 )              (  d                  )
!>    (      a   a   v4  v5 )              (  1   d              )
!>    (          a   1   v5 )              (  v1  1   a          )
!>    (              d   1  )              (  v1  v2  a   a      )
!>    (                  d  )              (  v1  v2  a   a   a  )
!>
!>  donde d denota un elemento diagonal de la matriz reducida, a denota
!>  un elemento de la matriz original que no ha cambiado, y vi denota
!>  un elemento del vector que define H(i).
!>
