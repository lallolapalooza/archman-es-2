Documentación de función/subrutina

subrutina zlalsd (character uplo, integer smlsiz, integer n, integer nrhs, double precision, dimension( * ) d, double precision, dimension( * ) e, complex*16, dimension( ldb, * ) b, integer ldb, double precision rcond, integer rank, complex*16, dimension( * ) work, double precision, dimension( * ) rwork, integer, dimension( * ) iwork, integer info)

ZLALSD utiliza la descomposición de valores singulares de A para resolver el problema de mínimos cuadrados.

Propósito:

!>
!> ZLALSD utiliza la descomposición de valores singulares de A para resolver el
!> problema de mínimos cuadrados de encontrar X que minimice la norma euclidiana de cada
!> columna de A*X-B, donde A es N por N superior bidiagonal, y X e B
!> son N por NRHS. La solución X sobrescribe a B.
!>
!> Los valores singulares de A menores que RCOND por el más grande
!> valor singular se tratan como cero al resolver el problema de mínimos cuadrados;
!> en este caso se devuelve una solución de norma mínima.
!> Los valores singulares reales se devuelven en D en orden ascendente.
!>
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>         = 'U': D y E definen una matriz superior bidiagonal.
!>         = 'L': D y E definen una matriz inferior bidiagonal.
!>

SMLSIZ

!>          SMLSIZ es INTEGER
!>         El tamaño máximo de los subproblemas en la parte inferior del
!>         árbol de cálculo.
!>

N

!>          N es INTEGER
!>         La dimensión de la matriz bidiagonal. N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>         El número de columnas de B. NRHS debe ser al menos 1.
!>

D

!>          D es un array DOUBLE PRECISION, de dimensión (N)
!>         En la entrada, D contiene la diagonal principal de la matriz bidiagonal.
!>         En la salida, si INFO = 0, D contiene sus valores singulares.
!>

E

!>          E es un array DOUBLE PRECISION, de dimensión (N-1)
!>         Contiene las entradas superdiagonales de la matriz bidiagonal.
!>         En la salida, E ha sido destruido.
!>

B

!>          B es un array COMPLEX*16, de dimensión (LDB,NRHS)
!>         En la entrada, B contiene los lados derechos del problema de mínimos cuadrados.
!>         En la salida, B contiene la solución X.
!>

LDB

!>          LDB es INTEGER
!>         La dimensión principal de B en el subprograma llamante.
!>         LDB debe ser al menos max(1,N).
!>

RCOND

!>          RCOND es DOUBLE PRECISION
!>         Los valores singulares de A menores o iguales a RCOND por el más grande
!>         valor singular se tratan como cero al resolver el problema de mínimos cuadrados.
!>         Si RCOND es negativo, se utiliza la precisión de la máquina en su lugar.
!>         Por ejemplo, si diag(S)*X=B fuera el problema de mínimos cuadrados,
!>         donde diag(S) es una matriz diagonal de valores singulares, la
!>         solución sería X(i) = B(i) / S(i) si S(i) es mayor que
!>         RCOND*max(S), y X(i) = 0 si S(i) es menor o igual a
!>         RCOND*max(S).
!>

RANK

!>          RANK es INTEGER
!>         El número de valores singulares de A mayores que RCOND por el más grande
!>         valor singular.
!>

WORK

!>          WORK es un array COMPLEX*16, de dimensión (N * NRHS)
!>

RWORK

!>          RWORK es un array DOUBLE PRECISION, de dimensión al menos
!>         (9*N + 2*N*SMLSIZ + 8*N*NLVL + 3*SMLSIZ*NRHS +
!>         MAX( (SMLSIZ+1)**2, N*(1+NRHS) + 2*NRHS ),
!>         donde
!>         NLVL = MAX( 0, INT( LOG_2( MIN( M,N )/(SMLSIZ+1) ) ) + 1 )
!>

IWORK

!>          IWORK es un array INTEGER, de dimensión al menos
!>         (3*N*NLVL + 11*N).
!>

INFO

!>          INFO es INTEGER
!>         = 0: Salida exitosa.
!>         < 0: Si INFO = -i, el i-ésimo argumento tuvo un valor ilegal.
!>         > 0: El algoritmo no pudo calcular un valor singular mientras
!>               trabajaba en la submatriz ubicada en las filas y columnas
!>               INFO/(N+1) a MOD(INFO,N+1).
!>
