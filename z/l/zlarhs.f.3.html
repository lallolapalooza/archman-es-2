Documentación de Función/Subrutina

subroutine zlarhs (character*3 path, character xtype, character uplo, character trans, integer m, integer n, integer kl, integer ku, integer nrhs, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( ldx, * ) x, integer ldx, complex*16, dimension( ldb, * ) b, integer ldb, integer, dimension( 4 ) iseed, integer info)

ZLARHS

Propósito:

!>
!> ZLARHS elige un conjunto de NRHS vectores solución aleatorios y configura
!> los lados derechos para el sistema lineal
!>    op(A) * X = B,
!> donde op(A) = A, A**T, o A**H, dependiendo de TRANS.
!>

Parámetros

PATH 
!>          PATH es CHARACTER*3
!>          El tipo de la matriz compleja A. PATH puede ser introducido en cualquier
!>          combinación de mayúsculas y minúsculas. Los caminos válidos incluyen
!>             xGE:  Matriz general m x n
!>             xGB:  Matriz de banda general
!>             xPO:  Hermítica positiva definida, almacenamiento 2-D
!>             xPP:  Hermítica positiva definida empaquetada
!>             xPB:  Hermítica positiva definida de banda
!>             xHE:  Hermítica indefinida, almacenamiento 2-D
!>             xHP:  Hermítica indefinida empaquetada
!>             xHB:  Hermítica indefinida de banda
!>             xSY:  Simétrica indefinida, almacenamiento 2-D
!>             xSP:  Simétrica indefinida empaquetada
!>             xSB:  Simétrica indefinida de banda
!>             xTR:  Triangular
!>             xTP:  Triangular empaquetada
!>             xTB:  Triangular de banda
!>             xQR:  Matriz general m x n
!>             xLQ:  Matriz general m x n
!>             xQL:  Matriz general m x n
!>             xRQ:  Matriz general m x n
!>          donde el primer carácter indica la precisión.
!>

XTYPE

!>          XTYPE es CHARACTER*1
!>          Especifica cómo se determinará la solución exacta X:
!>          = 'N':  Nueva solución; generar una X aleatoria.
!>          = 'C':  Calculada; usar el valor de X en la entrada.
!>

UPLO

!>          UPLO es CHARACTER*1
!>          Usado solo si A es simétrica o triangular; especifica si
!>          la parte superior o inferior de la matriz A se almacena.
!>          = 'U':  Triangular superior
!>          = 'L':  Triangular inferior
!>

TRANS

!>          TRANS es CHARACTER*1
!>          Usado solo si A no es simétrica; especifica la operación
!>          aplicada a la matriz A.
!>          = 'N':  B := A    * X  (Sin transponer)
!>          = 'T':  B := A**T * X  (Transpuesta)
!>          = 'C':  B := A**H * X  (Transpuesta conjugada)
!>

M

!>          M es INTEGER
!>          El número de filas de la matriz A.  M >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz A.  N >= 0.
!>

KL

!>          KL es INTEGER
!>          Usado solo si A es una matriz de banda; especifica el número de
!>          subdiagonales de A si A es una matriz de banda general o si A es
!>          simétrica o triangular y UPLO = 'L'; especifica el número de
!>          superdiagonales de A si A es simétrica o triangular y
!>          UPLO = 'U'.  0 <= KL <= M-1.
!>

KU

!>          KU es INTEGER
!>          Usado solo si A es una matriz de banda general o si A es
!>          triangular.
!>
!>          Si PATH = xGB, especifica el número de superdiagonales de A,
!>          y 0 <= KU <= N-1.
!>
!>          Si PATH = xTR, xTP, o xTB, especifica si la matriz
!>          tiene o no diagonal unitaria:
!>          = 1:  matriz con diagonal no unitaria (por defecto)
!>          = 2:  matriz con diagonal unitaria
!>

NRHS

!>          NRHS es INTEGER
!>          El número de vectores del lado derecho en el sistema A*X = B.
!>

A

!>          A es un array COMPLEX*16, dimensión (LDA,N)
!>          La matriz de prueba cuyo tipo está dado por PATH.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.
!>          Si PATH = xGB, LDA >= KL+KU+1.
!>          Si PATH = xPB, xSB, xHB, o xTB, LDA >= KL+1.
!>          De lo contrario, LDA >= max(1,M).
!>

X

!>          X es (o de salida) un array COMPLEX*16, dimensión (LDX,NRHS)
!>          En la entrada, si XTYPE = 'C' (para 'Calculada'), entonces X contiene
!>          la solución exacta del sistema de ecuaciones lineales.
!>          En la salida, si XTYPE = 'N' (para 'Nueva'), entonces X se inicializa
!>          con valores aleatorios.
!>

LDX

!>          LDX es INTEGER
!>          La dimensión principal del array X. Si TRANS = 'N',
!!>          LDX >= max(1,N); si TRANS = 'T', LDX >= max(1,M).
!>

B

!>          B es un array COMPLEX*16, dimensión (LDB,NRHS)
!>          El(los) vector(es) del lado derecho para el sistema de ecuaciones,
!>          calculado a partir de B = op(A) * X, donde op(A) está determinado por
!>          TRANS.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B. Si TRANS = 'N',
!>          LDB >= max(1,M); si TRANS = 'T', LDB >= max(1,N).
!>

ISEED

!>          ISEED es un array INTEGER, dimensión (4)
!>          La semilla para el generador de números aleatorios (usado en
!>          ZLATMS). Modificado en la salida.
!>

INFO

!>          INFO es INTEGER
!>          = 0: salida exitosa
!>          < 0: si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>
