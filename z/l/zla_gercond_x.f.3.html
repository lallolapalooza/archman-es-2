double precision function zla_gercond_x (character trans, integer n, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( ldaf, * ) af, integer ldaf, integer, dimension( * ) ipiv, complex*16, dimension( * ) x, integer info, complex*16, dimension( * ) work, double precision, dimension( * ) rwork)

ZLA_GERCOND_X calcula el número de condición de la norma infinita de op(A)*diag(x) para matrices generales.

Propósito:

!>
!>    ZLA_GERCOND_X calcula el número de condición de la norma infinita de
!>    op(A) * diag(X) donde X es un vector COMPLEX*16.
!>

Parámetros

TRANS 
!>          TRANS es CHARACTER*1
!>     Especifica la forma del sistema de ecuaciones:
!>       = 'N':  A * X = B     (Sin transposición)
!>       = 'T':  A**T * X = B  (Transpuesta)
!>       = 'C':  A**H * X = B  (Transpuesta conjugada = Transpuesta)
!>

N

!>          N es INTEGER
!>     El número de ecuaciones lineales, es decir, el orden de
!>     la matriz A.  N >= 0.
!>

A

!>          A es un array COMPLEX*16, dimension (LDA,N)
!>     En la entrada, la matriz A de N por N.
!>

LDA

!>          LDA es INTEGER
!>     La dimensión principal del array A.  LDA >= max(1,N).
!>

AF

!>          AF es un array COMPLEX*16, dimension (LDAF,N)
!>     Los factores L y U de la factorización
!>     A = P*L*U calculada por ZGETRF.
!>

LDAF

!>          LDAF es INTEGER
!>     La dimensión principal del array AF.  LDAF >= max(1,N).
!>

IPIV

!>          IPIV es un array INTEGER, dimension (N)
!>     Los índices de pivote de la factorización A = P*L*U
!>     calculada por ZGETRF; la fila i de la matriz fue intercambiada
!>     con la fila IPIV(i).
!>

X

!>          X es un array COMPLEX*16, dimension (N)
!>     El vector X en la fórmula op(A) * diag(X).
!>

INFO

!>          INFO es INTEGER
!>       = 0:  Salida exitosa.
!>     i > 0:  El i-ésimo argumento es inválido.
!>

WORK

!>          WORK es un array COMPLEX*16, dimension (2*N).
!>     Espacio de trabajo.
!>

RWORK

!>          RWORK es un array DOUBLE PRECISION, dimension (N).
!>     Espacio de trabajo.
!>
