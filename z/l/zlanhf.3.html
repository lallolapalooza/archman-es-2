función de precisión doble zlanhf (norma, transr, uplo, n, a, trabajo)

ZLANHF devuelve el valor de la norma 1, o la norma de Frobenius, o la norma infinito, o el elemento de mayor valor absoluto de una matriz Hermítica en formato RFP.

Documentación de la Función/Subrutina

función de precisión doble zlanhf (carácter norma, carácter transr, carácter uplo, entero n, complejo*16, dimensión(0:*) a, precisión doble, dimensión(0:*) trabajo)

ZLANHF devuelve el valor de la norma 1, o la norma de Frobenius, o la norma infinito, o el elemento de mayor valor absoluto de una matriz Hermítica en formato RFP.

Propósito:

!>
!> ZLANHF  devuelve el valor de la norma uno,  o la norma de Frobenius, o
!> la norma infinito,  o el elemento de  mayor valor absoluto de una
!> matriz Hermítica compleja A en formato RFP.
!>

Devuelve

ZLANHF 
!>
!>    ZLANHF = ( max(abs(A(i,j))), NORMA = 'M' o 'm'
!>             (
!>             ( norm1(A),         NORMA = '1', 'O' o 'o'
!>             (
!>             ( normI(A),         NORMA = 'I' o 'i'
!>             (
!>             ( normF(A),         NORMA = 'F', 'f', 'E' o 'e'
!>
!> donde  norm1  denota la norma uno de una matriz (suma máxima de columna),
!> normI  denota la norma infinito  de una matriz  (suma máxima de fila) y
!> normF  denota la  norma de Frobenius  de una matriz (raíz cuadrada de la suma de
!> cuadrados).  Tenga en cuenta que  max(abs(A(i,j)))  no es una  norma de matriz.
!>

Parámetros

NORMA 
!>          NORMA es CARACTER
!>            Especifica el valor a devolver en ZLANHF como se describe
!>            arriba.
!>

TRANSR

!>          TRANSR es CARACTER
!>            Especifica si el formato RFP de A es normal o
!>            transpuesto conjugado.
!>            = 'N':  El formato RFP es Normal
!>            = 'C':  El formato RFP es Transpuesto Conjugado
!>

UPLO

!>          UPLO es CARACTER
!>            En la entrada, UPLO especifica si la matriz RFP A provino
!>            de una matriz triangular superior o inferior como sigue:
!>
!>            UPLO = 'U' o 'u' RFP A provino de una matriz triangular
!>            superior
!>
!>            UPLO = 'L' o 'l' RFP A provino de una matriz triangular
!>            inferior
!>

N

!>          N es ENTERO
!>            El orden de la matriz A.  N >= 0.  Cuando N = 0, ZLANHF se
!>            establece a cero.
!>

A

!>          A es arreglo COMPLEX*16, dimensión ( N*(N+1)/2 );
!>            En la entrada, la matriz A en Formato RFP.
!>            El Formato RFP se describe mediante TRANSR, UPLO y N como sigue:
!>            Si TRANSR='N' entonces RFP A es (0:N,0:K-1) cuando N es par;
!>            K=N/2. RFP A es (0:N-1,0:K) cuando N es impar; K=N/2. Si
!>            TRANSR = 'C' entonces RFP es la Transpuesta Conjugada de RFP A
!>            como se define cuando TRANSR = 'N'. Los contenidos de RFP A
!>            se definen por UPLO como sigue: Si UPLO = 'U' la RFP A
!>            contiene los ( N*(N+1)/2 ) elementos de A superior empaquetada
!>            ya sea en formato normal o transpuesto conjugado. Si
!>            UPLO = 'L' la RFP A contiene los ( N*(N+1) /2 ) elementos
!>            de A inferior empaquetada ya sea en formato normal o transpuesto
!>            conjugado. La LDA de RFP A es (N+1)/2 cuando TRANSR = 'C'. Cuando
!>            TRANSR es 'N' la LDA es N+1 cuando N es par y es N cuando
!>            es impar. Vea la Nota a continuación para más detalles.
!>            Sin cambios en la salida.
!>

TRABAJO

!>          TRABAJO es arreglo de PRECISIÓN DOBLE, dimensión (LWORK),
!>            donde LWORK >= N cuando NORMA = 'I' o '1' o 'O'; en caso
!>            contrario, TRABAJO no se referencia.
!>

Function/Subroutine Documentation

This section details the functionality of the `ZLANHF` subroutine and its related routines within the LAPACK library.

ZLANHF

Computes the norm of a Hermitian matrix, optionally triangular.

Parameters:

  • NORM (CHARACTER*1): Specifies the type of norm to be computed.
    • '1' or 'O': 1-norm (maximum absolute column sum).
    • 'I': Infinity-norm (maximum absolute row sum).
    • 'F': Frobenius norm (square root of the sum of the squares of all elements).
    • 'M': Maximum absolute value of any element.
  • UPLO (CHARACTER*1): Specifies whether the matrix A is upper ('U') or lower ('L') triangular.
  • N (INTEGER): The order of the matrix A.
  • A (COMPLEX*16 array, dimension (LDA, N)): The Hermitian matrix.
  • LDA (INTEGER): The leading dimension of the array A.
  • RWORK (REAL*8 array, dimension (N)): Workspace array.
  • INFO (INTEGER): Output parameter.
    • INFO = 0: successful exit.
    • INFO < 0: if INFO = -i, the i-th argument had an illegal value.

Related Routines:

  • ZLANHE: Computes the norm of a general complex matrix (not necessarily Hermitian).
  • ZLANHP: Computes the norm of a packed Hermitian matrix.
  • ZLANHES: Computes the norm of a general complex matrix in Hessenedberg form.
  • ZLANHR: Computes the norm of a general complex matrix in upper triangular form.

The `ZLANHF` routine is particularly useful when dealing with Hermitian matrices and you need to compute specific matrix norms efficiently, taking advantage of the matrix's structure if it is triangular. The `RWORK` array is used for temporary storage during the computation. The `INFO` parameter indicates the success or failure of the operation.

Refer to the LAPACK documentation for detailed explanations and examples of each routine.
