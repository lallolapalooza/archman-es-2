ZLARFY

Propósito:

!>
!> ZLARFY aplica un reflector elemental, o matriz de Householder, H,
!> a una matriz Hermitiana n x n C, desde la izquierda y desde la derecha.
!>
!> H se representa en la forma
!>
!>    H = I - tau * v * v'
!>
!> donde tau es un escalar y v es un vector.
!>
!> Si tau es cero, entonces H se toma como la matriz identidad.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          Especifica si la parte triangular superior o inferior de la
!>          matriz Hermitiana C está almacenada.
!>          = 'U':  Triángulo superior
!>          = 'L':  Triángulo inferior
!>

N

!>          N es INTEGER
!>          El número de filas y columnas de la matriz C.  N >= 0.
!>

V

!>          V es un array COMPLEX*16, de dimensión
!>                  (1 + (N-1)*abs(INCV))
!>          El vector v como se describe arriba.
!>

INCV

!>          INCV es INTEGER
!>          El incremento entre elementos sucesivos de v.  INCV no debe
!>          ser cero.
!>

TAU

!>          TAU es COMPLEX*16
!>          El valor tau como se describe arriba.
!>

C

!>          C es un array COMPLEX*16, de dimensión (LDC, N)
!>          En la entrada, la matriz C.
!>          En la salida, C se sobrescribe con H * C * H'.
!>

LDC

!>          LDC es INTEGER
!>          La dimensión principal del array C.  LDC >= max( 1, N ).
!>

WORK

!>          WORK es un array COMPLEX*16, de dimensión (N)
!>
