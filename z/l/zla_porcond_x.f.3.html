doble precisión función zla_porcond_x (carácter uplo, entero n, complejo*16, dimensión( lda, * ) a, entero lda, complejo*16, dimensión( ldaf, * ) af, entero ldaf, complejo*16, dimensión( * ) x, entero info, complejo*16, dimensión( * ) work, doble precisión, dimensión( * ) rwork)

ZLA_PORCOND_X calcula el número de condición de la norma infinito de op(A)*diag(x) para matrices Hermitianas definidas positivas.

Propósito:

!>
!>    ZLA_PORCOND_X Calcula el número de condición de la norma infinito de
!>    op(A) * diag(X) donde X es un vector COMPLEX*16.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>       = 'U':  El triángulo superior de A está almacenado;
!>       = 'L':  El triángulo inferior de A está almacenado.
!>

N

!>          N es INTEGER
!>     El número de ecuaciones lineales, es decir, el orden de
!>     la matriz A.  N >= 0.
!>

A

!>          A es una matriz COMPLEX*16, dimensión (LDA,N)
!>     En la entrada, la matriz N-por-N A.
!>

LDA

!>          LDA es INTEGER
!>     La dimensión principal de la matriz A.  LDA >= max(1,N).
!>

AF

!>          AF es una matriz COMPLEX*16, dimensión (LDAF,N)
!>     El factor triangular U o L de la factorización de Cholesky
!>     A = U**H*U o A = L*L**H, tal como es calculada por ZPOTRF.
!>

LDAF

!>          LDAF es INTEGER
!>     La dimensión principal de la matriz AF.  LDAF >= max(1,N).
!>

X

!>          X es una matriz COMPLEX*16, dimensión (N)
!>     El vector X en la fórmula op(A) * diag(X).
!>

INFO

!>          INFO es INTEGER
!>       = 0:  Salida exitosa.
!>     i > 0:  El i-ésimo argumento es inválido.
!>

WORK

!>          WORK es una matriz COMPLEX*16, dimensión (2*N).
!>     Espacio de trabajo.
!>

RWORK

!>          RWORK es una matriz DOUBLE PRECISION, dimensión (N).
!>     Espacio de trabajo.
!>
