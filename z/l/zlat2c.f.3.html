subrutina zlat2c (uplo, n, a, lda, sa, ldsa, info)
ZLAT2C convierte una matriz triangular doble compleja a una matriz triangular compleja.

Documentación de la función/subrutina

subrutina zlat2c (carácter uplo, entero n, complejo*16, dimensión( lda, * ) a, entero lda, complejo, dimensión( ldsa, * ) sa, entero ldsa, entero info)

ZLAT2C convierte una matriz triangular doble compleja, SA, a una matriz triangular compleja, A.

Propósito:

!>
!> ZLAT2C convierte una matriz triangular COMPLEJA*16, SA, a una matriz triangular COMPLEJA, A.
!>
!> RMAX es el desbordamiento para la aritmética de PRECISIÓN SIMPLE
!> ZLAT2C comprueba que todas las entradas de A están entre -RMAX y
!> RMAX. Si no, la conversión se interrumpe y se eleva una bandera.
!>
!> Esta es una subrutina auxiliar, por lo que no hay comprobación de argumentos.
!>

Parámetros

UPLO 
!>          UPLO es CARACTER*1
!>          = 'U':  A es triangular superior;
!>          = 'L':  A es triangular inferior.
!>

N

!>          N es ENTERO
!>          El número de filas y columnas de la matriz A.  N >= 0.
!>

A

!>          A es un array COMPLEJO*16, dimensión (LDA,N)
!>          En la entrada, la matriz de coeficientes triangular A de N por N.
!>

LDA

!>          LDA es ENTERO
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

SA

!>          SA es un array COMPLEJO, dimensión (LDSA,N)
!>          Solo se hace referencia a la parte UPLO de SA. En la salida, si INFO=0,
!>          la matriz de coeficientes SA de N por N; si INFO>0, el contenido de
!>          la parte UPLO de SA no está especificado.
!>

LDSA

!>          LDSA es ENTERO
!>          La dimensión principal del array SA.  LDSA >= max(1,M).
!>

INFO

!>          INFO es ENTERO
!>          = 0:  salida exitosa.
!>          = 1:  una entrada de la matriz A es mayor que el umbral de desbordamiento
!>                de PRECISIÓN SIMPLE, en cuyo caso, el contenido
!>                de la parte UPLO de SA en la salida no está especificado.
!>
