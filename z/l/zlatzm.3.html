ZLATZM

Documentación de Función/Subrutina

subrutina zlatzm (character side, integer m, integer n, complex*16, dimension( * ) v, integer incv, complex*16 tau, complex*16, dimension( ldc, * ) c1, complex*16, dimension( ldc, * ) c2, integer ldc, complex*16, dimension( * ) work)

ZLATZM

Propósito:

!>
!> Esta subrutina está obsoleta y ha sido reemplazada por la subrutina ZUNMRZ.
!>
!> ZLATZM aplica una matriz de Householder generada por ZTZRQF a una matriz.
!>
!> Sea P = I - tau*u*u**H,   u = ( 1 ),
!>                               ( v )
!> donde v es un vector (m-1) si SIDE = 'L', o un vector (n-1) si
!> SIDE = 'R'.
!>
!> Si SIDE es igual a 'L', sea
!>        C = [ C1 ] 1
!>            [ C2 ] m-1
!>              n
!> Entonces C se sobrescribe por P*C.
!>
!> Si SIDE es igual a 'R', sea
!>        C = [ C1, C2 ] m
!>               1  n-1
!> Entonces C se sobrescribe por C*P.
!>

Parámetros

SIDE 
!>          SIDE es CHARACTER*1
!>          = 'L': forma P * C
!>          = 'R': forma C * P
!>

M

!>          M es INTEGER
!>          El número de filas de la matriz C.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz C.
!>

V

!>          V es un array COMPLEX*16, de dimensión
!>                  (1 + (M-1)*abs(INCV)) si SIDE = 'L'
!>                  (1 + (N-1)*abs(INCV)) si SIDE = 'R'
!>          El vector v en la representación de P. V no se usa
!>          si TAU = 0.
!>

INCV

!>          INCV es INTEGER
!>          El incremento entre elementos de v. INCV <> 0
!>

TAU

!>          TAU es COMPLEX*16
!>          El valor tau en la representación de P.
!>

C1

!>          C1 es un array COMPLEX*16, de dimensión
!>                         (LDC,N) si SIDE = 'L'
!>                         (M,1)   si SIDE = 'R'
!>          En la entrada, el vector n C1 si SIDE = 'L', o el vector m C1
!>          si SIDE = 'R'.
!>
!>          En la salida, la primera fila de P*C si SIDE = 'L', o la primera
!>          columna de C*P si SIDE = 'R'.
!>

C2

!>          C2 es un array COMPLEX*16, de dimensión
!>                         (LDC, N)   si SIDE = 'L'
!>                         (LDC, N-1) si SIDE = 'R'
!>          En la entrada, la matriz (m - 1) x n C2 si SIDE = 'L', o la
!>          matriz m x (n - 1) C2 si SIDE = 'R'.
!>
!>          En la salida, las filas 2:m de P*C si SIDE = 'L', o las columnas 2:m de C*P
!>          si SIDE = 'R'.
!>

LDC

!>          LDC es INTEGER
!>          La dimensión principal de los arrays C1 y C2.
!>          LDC >= max(1,M).
!>

WORK

!>          WORK es un array COMPLEX*16, de dimensión
!>                      (N) si SIDE = 'L'
!>                      (M) si SIDE = 'R'
!>
