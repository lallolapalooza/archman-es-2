subrutina zla_heamv (uplo, n, alpha, a, lda, x, incx, beta, y, incy)

ZLA_HEAMV calcula el producto de una matriz por un vector utilizando una matriz Hermítica indefinida para calcular cotas de error.

Documentación de Función/Subrutina

subrutina zla_heamv (integer uplo, integer n, double precision alpha, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( * ) x, integer incx, double precision beta, double precision, dimension( * ) y, integer incy)

ZLA_HEAMV calcula el producto de una matriz por un vector utilizando una matriz Hermítica indefinida para calcular cotas de error.

Propósito:

!>
!> ZLA_SYAMV  realiza la operación de matriz-vector
!>
!>         y := alpha*abs(A)*abs(x) + beta*abs(y),
!>
!> donde alpha y beta son escalares, x e y son vectores y A es una
!> matriz simétrica de n por n.
!>
!> Esta función se utiliza principalmente para calcular cotas de error.
!> Para proteger contra el desbordamiento durante la evaluación, los componentes
!> del vector resultante se modifican alejándolos de cero en (N+1)
!> veces el umbral de desbordamiento. Para evitar errores innecesariamente grandes
!> para la estructura de bloque incrustada en matrices generales,
!> los componentes cero no se modifican. Una entrada cero
!> se considera si todas las multiplicaciones involucradas
!> en el cálculo de esa entrada tienen al menos un multiplicando cero.
!>

Parámetros

UPLO 
!>          UPLO es INTEGER
!>           En la entrada, UPLO especifica si la parte triangular superior o inferior
!>           del array A se va a referenciar de la siguiente manera:
!>
!>              UPLO = BLAS_UPPER   Solo se hará referencia a la parte triangular superior de A
!>
!>              UPLO = BLAS_LOWER   Solo se hará referencia a la parte triangular inferior de A
!>
!>           Sin cambios a la salida.
!>

N

!>          N es INTEGER
!>           En la entrada, N especifica el número de columnas de la matriz A.
!>           N debe ser al menos cero.
!>           Sin cambios a la salida.
!>

ALPHA

!>          ALPHA es DOUBLE PRECISION.
!>           En la entrada, ALPHA especifica el escalar alpha.
!>           Sin cambios a la salida.
!>

A

!>          A es un array COMPLEX*16, de dimensión ( LDA, n ).
!>           Antes de la entrada, la parte principal de m por n del array A debe
!>           contener la matriz de coeficientes.
!>           Sin cambios a la salida.
!>

LDA

!>          LDA es INTEGER
!>           En la entrada, LDA especifica la primera dimensión de A tal como se declaró
!>           en el programa (sub)llamador. LDA debe ser al menos
!>           max( 1, n ).
!>           Sin cambios a la salida.
!>

X

!>          X es un array COMPLEX*16, de dimensión al menos
!>           ( 1 + ( n - 1 )*abs( INCX ) )
!>           Antes de la entrada, el array X incrementado debe contener el
!>           vector x.
!>           Sin cambios a la salida.
!>

INCX

!>          INCX es INTEGER
!>           En la entrada, INCX especifica el incremento para los elementos de
!>           X. INCX no debe ser cero.
!>           Sin cambios a la salida.
!>

BETA

!>          BETA es DOUBLE PRECISION.
!>           En la entrada, BETA especifica el escalar beta. Cuando BETA se
!>           proporciona como cero, Y no necesita ser establecido en la entrada.
!>           Sin cambios a la salida.
!>

Y

!>          Y es un array DOUBLE PRECISION, de dimensión
!>           ( 1 + ( n - 1 )*abs( INCY ) )
!>           Antes de la entrada con BETA distinto de cero, el array Y incrementado
!>           debe contener el vector y. A la salida, Y se sobrescribe con el
!>           vector y actualizado.
!>

INCY

!>          INCY es INTEGER
!>           En la entrada, INCY especifica el incremento para los elementos de
!>           Y. INCY no debe ser cero.
!>           Sin cambios a la salida.
!>
