doble precisión función zlanhe (norm, uplo, n, a, lda, work)

ZLANHE devuelve el valor de la norma 1, o la norma de Frobenius, o la norma infinito, o el elemento de mayor valor absoluto de una matriz Hermitiana compleja.

Documentación de Función/Subrutina

doble precisión función zlanhe (carácter norm, carácter uplo, entero n, complejo*16, dimensión( lda, * ) a, entero lda, doble precisión, dimensión( * ) work)

ZLANHE devuelve el valor de la norma 1, o la norma de Frobenius, o la norma infinito, o el elemento de mayor valor absoluto de una matriz Hermitiana compleja.

Propósito:

!>
!> ZLANHE  devuelve el valor de la norma uno,  o la norma de Frobenius, o
!> la  norma infinito,  o el  elemento de  mayor valor absoluto de una
!> matriz Hermitiana compleja A.
!>

Devuelve

ZLANHE 
!>
!>    ZLANHE = ( max(abs(A(i,j))), NORM = 'M' o 'm'
!>             (
!>             ( norm1(A),         NORM = '1', 'O' o 'o'
!>             (
!>             ( normI(A),         NORM = 'I' o 'i'
!>             (
!>             ( normF(A),         NORM = 'F', 'f', 'E' o 'e'
!>
!> donde  norm1  denota la  norma uno de una matriz (suma máxima de
!> columna), normI  denota la  norma infinito  de una matriz  (suma
!> máxima de fila) y normF  denota la  norma de Frobenius  de una matriz
!> (raíz cuadrada de la suma de cuadrados).  Tenga en cuenta que
!> max(abs(A(i,j)))  no es una norma de matriz consistente.
!>

Parámetros

NORM 
!>          NORM es CHARACTER*1
!>          Especifica el valor a devolver en ZLANHE como se describe
!>          arriba.
!>

UPLO

!>          UPLO es CHARACTER*1
!>          Especifica si se va a referenciar la parte triangular superior o
!>          inferior de la matriz Hermitiana A.
!>          = 'U':  Se referencia la parte triangular superior de A
!>          = 'L':  Se referencia la parte triangular inferior de A
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.  Cuando N = 0, ZLANHE se
!>          establece a cero.
!>

A

!>          A es un array COMPLEX*16, dimensión (LDA,N)
!>          La matriz Hermitiana A.  Si UPLO = 'U', la parte triangular
!>          superior de A de tamaño n por n contiene la parte triangular
!>          superior de la matriz A, y la parte triangular estrictamente
!>          inferior de A no se referencia.  Si UPLO = 'L', la parte
!>          triangular inferior de A de tamaño n por n contiene la parte
!>          triangular inferior de la matriz A, y la parte triangular
!>          estrictamente superior de A no se referencia. Tenga en cuenta
!>          que las partes imaginarias de los elementos diagonales no
!>          necesitan ser establecidas y se asumen que son cero.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(N,1).
!>

WORK

!>          WORK es un array DOUBLE PRECISION, dimensión (MAX(1,LWORK)),
!>          donde LWORK >= N cuando NORM = 'I' o '1' o 'O'; de lo
!>          contrario, WORK no se referencia.
!>
