función de precisión doble zlanhb (norma, uplo, n, k, ab, ldab, work)

ZLANHB devuelve el valor de la norma 1, o la norma de Frobenius, o la norma infinito, o el elemento de mayor valor absoluto de una matriz banda Hermitiana.

Documentación de la función/Subrutina

doble precisión función zlanhb (carácter norma, carácter uplo, entero n, entero k, complejo*16, dimensión( ldab, * ) ab, entero ldab, doble precisión, dimensión( * ) work)

ZLANHB devuelve el valor de la norma 1, o la norma de Frobenius, o la norma infinito, o el elemento de mayor valor absoluto de una matriz banda Hermitiana.

Propósito:

!>
!> ZLANHB devuelve el valor de la norma uno, o la norma de Frobenius, o
!> la norma infinito, o el elemento de mayor valor absoluto de una matriz
!> banda Hermitiana A de n por n, con k super-diagonales.
!>

Devuelve

ZLANHB 
!>
!>    ZLANHB = ( max(abs(A(i,j))), NORMA = 'M' o 'm'
!>             (
!>             ( norma1(A),         NORMA = '1', 'O' o 'o'
!>             (
!>             ( normaI(A),         NORMA = 'I' o 'i'
!>             (
!>             ( normaF(A),         NORMA = 'F', 'f', 'E' o 'e'
!>
!> donde norma1 denota la norma uno de una matriz (suma máxima de columna),
!> normaI denota la norma infinito de una matriz (suma máxima de fila) y
!> normaF denota la norma de Frobenius de una matriz (raíz cuadrada de la suma de
!> cuadrados). Tenga en cuenta que max(abs(A(i,j))) no es una norma matricial
!> consistente.
!>

Parámetros

NORMA 
!>          NORMA es CHARACTER*1
!>          Especifica el valor a devolver en ZLANHB como se describe
!>          arriba.
!>

UPLO

!>          UPLO es CHARACTER*1
!>          Especifica si se suministra la parte triangular superior o inferior
!>          de la matriz banda A.
!>          = 'U': Triangular superior
!>          = 'L': Triangular inferior
!>

N

!>          N es INTEGER
!>          El orden de la matriz A. N >= 0. Cuando N = 0, ZLANHB se
!>          establece a cero.
!>

K

!>          K es INTEGER
!>          El número de super-diagonales o sub-diagonales de la
!>          matriz banda A. K >= 0.
!>

AB

!>          AB es un array COMPLEX*16, dimensión (LDAB,N)
!>          La parte triangular superior o inferior de la matriz banda Hermitiana
!>          A, almacenada en las primeras K+1 filas de AB. La j-ésima columna
!>          de A se almacena en la j-ésima columna del array AB de la siguiente
!>          manera:
!>          si UPLO = 'U', AB(k+1+i-j,j) = A(i,j) para max(1,j-k)<=i<=j;
!>          si UPLO = 'L', AB(1+i-j,j)   = A(i,j) para j<=i<=min(n,j+k).
!>          Tenga en cuenta que las partes imaginarias de los elementos diagonales
!>          no es necesario que se establezcan y se asumen que son cero.
!>

LDAB

!>          LDAB es INTEGER
!>          La dimensión principal del array AB. LDAB >= K+1.
!>

WORK

!>          WORK es un array DOUBLE PRECISION, dimensión (MAX(1,LWORK)),
!>          donde LWORK >= N cuando NORMA = 'I' o '1' o 'O'; en caso contrario,
!>          WORK no se referencia.
!>
