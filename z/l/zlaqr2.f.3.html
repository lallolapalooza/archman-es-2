subroutine zlaqr2 (logical wantt, logical wantz, integer n, integer ktop, integer kbot, integer nw, complex*16, dimension( ldh, * ) h, integer ldh, integer iloz, integer ihiz, complex*16, dimension( ldz, * ) z, integer ldz, integer ns, integer nd, complex*16, dimension( * ) sh, complex*16, dimension( ldv, * ) v, integer ldv, integer nh, complex*16, dimension( ldt, * ) t, integer ldt, integer nv, complex*16, dimension( ldwv, * ) wv, integer ldwv, complex*16, dimension( * ) work, integer lwork)

ZLAQR2 realiza la transformación de semejanza unitaria de una matriz de Hessenberg para detectar y deflactar valores propios completamente convergidos de una submatriz principal de cola (deflactación temprana agresiva).

Propósito:

!>
!>    ZLAQR2 es idéntica a ZLAQR3 excepto que evita
!>    la recursión llamando a ZLAHQR en lugar de ZLAQR4.
!>
!>    Deflactación temprana agresiva:
!>
!>    ZLAQR2 acepta como entrada una matriz de Hessenberg superior
!>    H y realiza una transformación de semejanza unitaria
!>    diseñada para detectar y deflactar valores propios completamente
!>    convergidos de una submatriz principal de cola. En la salida, H ha sido
!>    sobrescrita por una nueva matriz de Hessenberg que es una perturbación de
!>    una transformación de semejanza unitaria de H. Se espera
!>    que la versión final de H tenga muchas entradas subdiagonales
!>    cero.
!>
!>

Parámetros

WANTT 
!>          WANTT es LOGICAL
!>          Si .TRUE., entonces la matriz de Hessenberg H se actualiza completamente
!>          para que el factor triangular de Schur pueda
!>          ser calculado (en cooperación con la subrutina llamante).
!>          Si .FALSE., entonces solo se actualiza H lo suficiente para preservar
!>          los valores propios.
!>

WANTZ

!>          WANTZ es LOGICAL
!>          Si .TRUE., entonces la matriz unitaria Z se actualiza
!>          para que el factor de Schur unitario pueda ser calculado
!>          (en cooperación con la subrutina llamante).
!>          Si .FALSE., entonces Z no se referencia.
!>

N

!>          N es INTEGER
!>          El orden de la matriz H y (si WANTZ es .TRUE.) el
!>          orden de la matriz unitaria Z.
!>

KTOP

!>          KTOP es INTEGER
!>          Se asume que KTOP = 1 o H(KTOP,KTOP-1)=0.
!>          KBOT y KTOP juntos determinan un bloque aislado
!>          a lo largo de la diagonal de la matriz de Hessenberg.
!>

KBOT

!>          KBOT es INTEGER
!>          Se asume sin comprobación que KBOT = N o H(KBOT+1,KBOT)=0. KBOT
!>          y KTOP juntos determinan un bloque aislado a lo largo de la
!>          diagonal de la matriz de Hessenberg.
!>

NW

!>          NW es INTEGER
!>          Tamaño de la ventana de deflactación. 1 <= NW <= (KBOT-KTOP+1).
!>

H

!>          H es un array COMPLEX*16, dimension (LDH,N)
!>          En la entrada, la sección N por N inicial de H almacena la
!>          matriz de Hessenberg sometida a deflactación temprana agresiva.
!>          En la salida, H ha sido transformada por una semejanza
!>          unitaria, perturbada, y devuelta
!>          a forma de Hessenberg que (se espera) tiene algunas
!>          entradas subdiagonales cero.
!>

LDH

!>          LDH es INTEGER
!>          Dimensión principal de H tal como se declara en la subrutina
!>          llamante. N <= LDH
!>

ILOZ

!>          ILOZ es INTEGER
!>

IHIZ

!>          IHIZ es INTEGER
!>          Especifica las filas de Z a las que se deben aplicar las transformaciones
!>          si WANTZ es .TRUE.. 1 <= ILOZ <= IHIZ <= N.
!>

Z

!>          Z es un array COMPLEX*16, dimension (LDZ,N)
!>          Si WANTZ es .TRUE., entonces en la salida, la transformación
!>          de semejanza unitaria mencionada anteriormente ha sido
!>          acumulada en Z(ILOZ:IHIZ,ILOZ:IHIZ) por la derecha.
!>          Si WANTZ es .FALSE., entonces Z no se referencia.
!>

LDZ

!>          LDZ es INTEGER
!>          La dimensión principal de Z tal como se declara en la
!>          subrutina llamante. 1 <= LDZ.
!>

NS

!>          NS es INTEGER
!>          El número de valores propios no convergidos (es decir, aproximados)
!>          devueltos en SR y SI que pueden ser utilizados como desplazamientos por
!>          la subrutina llamante.
!>

ND

!>          ND es INTEGER
!>          El número de valores propios convergidos descubiertos por esta
!>          subrutina.
!>

SH

!>          SH es un array COMPLEX*16, dimension (KBOT)
!>          En la salida, los valores propios aproximados que pueden
!>          ser utilizados para desplazamientos se almacenan en SH(KBOT-ND-NS+1)
!>          hasta SR(KBOT-ND). Los valores propios convergidos se
!>          almacenan en SH(KBOT-ND+1) hasta SH(KBOT).
!>

V

!>          V es un array COMPLEX*16, dimension (LDV,NW)
!>          Un array de trabajo de NW por NW.
!>

LDV

!>          LDV es INTEGER
!>          La dimensión principal de V tal como se declara en la
!>          subrutina llamante. NW <= LDV
!>

NH

!>          NH es INTEGER
!>          El número de columnas de T. NH >= NW.
!>

T

!>          T es un array COMPLEX*16, dimension (LDT,NW)
!>

LDT

!>          LDT es INTEGER
!>          La dimensión principal de T tal como se declara en la
!>          subrutina llamante. NW <= LDT
!>

NV

!>          NV es INTEGER
!>          El número de filas del array de trabajo WV disponibles para
!>          espacio de trabajo. NV >= NW.
!>

WV

!>          WV es un array COMPLEX*16, dimension (LDWV,NW)
!>

LDWV

!>          LDWV es INTEGER
!>          La dimensión principal de W tal como se declara en la
!>          subrutina llamante. NW <= LDV
!>

WORK

!>          WORK es un array COMPLEX*16, dimension (LWORK)
!>          A la salida, WORK(1) se establece en una estimación del valor óptimo
!>          de LWORK para los valores dados de N, NW, KTOP y KBOT.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array de trabajo WORK. LWORK = 2*NW
!>          es suficiente, pero una mayor eficiencia puede resultar de valores
!>          mayores de LWORK.
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo; ZLAQR2
!>          solo estima el tamaño óptimo del espacio de trabajo para los valores
!>          dados de N, NW, KTOP y KBOT. La estimación se devuelve
!>          en WORK(1). No se emite ningún mensaje de error relacionado con LWORK
!>          por XERBLA. Ni H ni Z son accedidos.
!>

NAME

zlaqr2 - ZLAQR2 applies a series of plane rotations to reduce the subdiagonal elements of a complex upper quasi-triangular matrix to zero.

SYNOPSIS

  SUBROUTINE ZLAQR2( WANTT, WANTZ, N, ILO, IHI, H, LDH, Z, LDZ,
                     TOL, NS, KS, DUMMY, INFO )

C interface

  void zlaqr2_f( int *wantt, int *wantz, int *n, int *ilo, int *ihi,
                 complex* h, int *ldh, complex* z, int *ldz,
                 doublereal *tol, int *ns, int *ks, int *dummy,
                 int *info )

Description

ZLAQR2 is a utility routine called by ZGEEVX, ZGESVX and ZHPVX. It is used to reduce the subdiagonal elements of a complex upper quasi-triangular matrix to zero by applying a series of plane rotations.

Arguments:

WANTT
LOGICAL. If .TRUE., the trigonometric transformations are accumulated in matrix T.
WANTZ
LOGICAL. If .TRUE., the complex transformations are accumulated in matrix Z.
N
INTEGER. The order of the upper quasi-triangular matrix H.
ILO
INTEGER. Default value 1. ILO and IHI indicate the rows and columns of H.
IHI
INTEGER. Default value N. ILO and IHI indicate the rows and columns of H.
H
COMPLEX*16 array, dimension (LDH, N). On entry, H contains the upper quasi-triangular matrix.
LDH
INTEGER. The leading dimension of the array H.
Z
COMPLEX*16 array, dimension (LDZ, N). If WANTZ is .TRUE., Z contains the transformation matrix. On exit, Z contains the accumulated transformations.
LDZ
INTEGER. The leading dimension of the array Z.
TOL
DOUBLE PRECISION. The tolerance to determine when a subdiagonal element is negligible.
NS
INTEGER. The number of wanted right eigenvectors.
KS
INTEGER. Default value 0. The number of blocks of wanted eigenvectors.
DUMMY
INTEGER. Not used.
INFO
INTEGER. Returns 0 if successful.
