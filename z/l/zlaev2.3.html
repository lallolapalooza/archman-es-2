Documentación de Función/Subrutina

subrutina zlaev2 (complex*16 a, complex*16 b, complex*16 c, double precision rt1, double precision rt2, double precision cs1, complex*16 sn1)

ZLAEV2 calcula los valores propios y los vectores propios de una matriz hermítica/simétrica de 2x2.

Propósito:

!>
!> ZLAEV2 calcula la descomposicion en valores propios de una matriz hermitiana de 2x2
!>    [  A         B  ]
!>    [  CONJG(B)  C  ].
!> Al regresar, RT1 es el valor propio de mayor valor absoluto, RT2 es el
!> valor propio de menor valor absoluto, y (CS1,SN1) es el vector propio derecho unitario
!> para RT1, dando la descomposicion
!>
!> [ CS1  CONJG(SN1) ] [    A     B ] [ CS1 -CONJG(SN1) ] = [ RT1  0  ]
!> [-SN1     CS1     ] [ CONJG(B) C ] [ SN1     CS1     ]   [  0  RT2 ].
!>

Parámetros

A 
!>          A es COMPLEX*16
!>         El elemento (1,1) de la matriz de 2x2.
!>

B

!>          B es COMPLEX*16
!>         El elemento (1,2) y el conjugado del elemento (2,1) de
!>         la matriz de 2x2.
!>

C

!>          C es COMPLEX*16
!>         El elemento (2,2) de la matriz de 2x2.
!>

RT1

!>          RT1 es DOUBLE PRECISION
!>         El valor propio de mayor valor absoluto.
!>

RT2

!>          RT2 es DOUBLE PRECISION
!>         El valor propio de menor valor absoluto.
!>

CS1

!>          CS1 es DOUBLE PRECISION
!>

SN1

!>          SN1 es COMPLEX*16
!>         El vector (CS1, SN1) es un vector propio derecho unitario para RT1.
!>

Más detalles:

!>
!>  RT1 es preciso hasta unos pocos ulps, salvo desbordamiento superior/inferior.
!>
!>  RT2 puede ser impreciso si hay una cancelación masiva en el
!>  determinante A*C-B*B; se necesitaría aritmética de precisión superior o
!>  redondeada/truncada correctamente para calcular RT2
!>  con precisión en todos los casos.
!>
!>  CS1 y SN1 son precisos hasta unos pocos ulps, salvo desbordamiento superior/inferior.
!>
!>  El desbordamiento solo es posible si RT1 está a un factor de 5 del desbordamiento.
!>  El desbordamiento inferior no es perjudicial si los datos de entrada son 0 o exceden
!>     umbral_desbordamiento_inferior / macheps.
!>
