subroutine zlaqhp (character uplo, integer n, complex*16, dimension( * ) ap, double precision, dimension( * ) s, double precision scond, double precision amax, character equed)

ZLAQHP escala una matriz Hermitiana almacenada en formato empaquetado.

Propósito:

!>
!> ZLAQHP equilibra una matriz Hermitiana A utilizando los factores de escala
!> en el vector S.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          Especifica si la parte triangular superior o inferior de la
!>          matriz Hermitiana A está almacenada.
!>          = 'U':  Triangular superior
!>          = 'L':  Triangular inferior
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

AP

!>          AP es un array COMPLEX*16, dimensión (N*(N+1)/2)
!>          En la entrada, la parte triangular superior o inferior de la matriz
!>          Hermitiana A, empaquetada por columnas en un array lineal. La j-ésima
!>          columna de A se almacena en el array AP como sigue:
!>          si UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) para 1<=i<=j;
!>          si UPLO = 'L', AP(i + (j-1)*(2n-j)/2) = A(i,j) para j<=i<=n.
!>
!>          En la salida, la matriz equilibrada: diag(S) * A * diag(S), en
!>          el mismo formato de almacenamiento que A.
!>

S

!>          S es un array DOUBLE PRECISION, dimensión (N)
!>          Los factores de escala para A.
!>

SCOND

!>          SCOND es DOUBLE PRECISION
!>          Razón del S(i) más pequeño al S(i) más grande.
!>

AMAX

!>          AMAX es DOUBLE PRECISION
!>          Valor absoluto de la entrada de matriz más grande.
!>

EQUED

!>          EQUED es CHARACTER*1
!>          Especifica si se realizó o no el equilibrio.
!>          = 'N':  No se realizó equilibrio.
!>          = 'Y':  Se realizó el equilibrio, es decir, A ha sido reemplazada por
!>                  diag(S) * A * diag(S).
!>

Parámetros internos:

!>  THRESH es un valor umbral utilizado para decidir si se debe realizar el
!>  escalado basándose en la razón de los factores de escala. Si SCOND < THRESH,
!>  se realiza el escalado.
!>
!>  LARGE y SMALL son valores umbral utilizados para decidir si se debe
!>  realizar el escalado basándose en el tamaño absoluto del elemento de matriz
!>  más grande. Si AMAX > LARGE o AMAX < SMALL, se realiza el escalado.
!>
