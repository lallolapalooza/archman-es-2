ZLAVHE

Propósito:

!>
!> ZLAVHE realiza una de las operaciones matriciales vectoriales
!>    x := A*x  o  x := A^H*x,
!> donde x es un vector de N elementos y A es uno de los factores
!> de la factorización de bloques U*D*U' o L*D*L' calculada por ZHETRF.
!>
!> Si TRANS = 'N', multiplica por U  o U * D  (o L  o L * D)
!> Si TRANS = 'C', multiplica por U' o D * U' (o L' o D * L')
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          Especifica si el factor almacenado en A es triangular superior o inferior.
!>          = 'U':  Triangular superior
!>          = 'L':  Triangular inferior
!>

TRANS

!>          TRANS es CHARACTER*1
!>          Especifica la operación a realizar:
!>          = 'N':  x := A*x
!>          = 'C':  x := A'*x
!>

DIAG

!>          DIAG es CHARACTER*1
!>          Especifica si los bloques diagonales son matrices unitarias o no.
!>          Si se asume que los bloques diagonales son unitarios,
!>          entonces A = U o A = L, de lo contrario A = U*D o A = L*D.
!>          = 'U':  Se asume que los bloques diagonales son matrices unitarias.
!>          = 'N':  Se asume que los bloques diagonales son matrices no unitarias.
!>

N

!>          N es ENTERO
!>          El número de filas y columnas de la matriz A.  N >= 0.
!>

NRHS

!>          NRHS es ENTERO
!>          El número de lados derechos, es decir, el número de vectores
!>          x a multiplicar por A.  NRHS >= 0.
!>

A

!>          A es un array COMPLEX*16, dimensión (LDA,N)
!>          La matriz diagonal de bloques D y los multiplicadores usados para
!>          obtener el factor U o L calculados por ZHETRF.
!>          Almacenado como una matriz triangular 2D.
!>

LDA

!>          LDA es ENTERO
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

IPIV

!>          IPIV es un array ENTERO, dimensión (N)
!>          Detalles de los intercambios y la estructura de bloques de D,
!>          tal como lo determina ZHETRF.
!>
!>          Si UPLO = 'U':
!>               Si IPIV(k) > 0, entonces las filas y columnas k e IPIV(k)
!>               fueron intercambiadas y D(k,k) es un bloque diagonal de 1x1.
!>               (Si IPIV( k ) = k, no se realizó ningún intercambio).
!>
!>               Si IPIV(k) = IPIV(k-1) < 0, entonces las filas y
!>               columnas k-1 e -IPIV(k) fueron intercambiadas,
!>               D(k-1:k,k-1:k) es un bloque diagonal de 2x2.
!>
!>          Si UPLO = 'L':
!>               Si IPIV(k) > 0, entonces las filas y columnas k e IPIV(k)
!>               fueron intercambiadas y D(k,k) es un bloque diagonal de 1x1.
!>               (Si IPIV( k ) = k, no se realizó ningún intercambio).
!>
!>               Si IPIV(k) = IPIV(k+1) < 0, entonces las filas y
!>               columnas k+1 e -IPIV(k) fueron intercambiadas,
!>               D(k:k+1,k:k+1) es un bloque diagonal de 2x2.
!>

B

!>          B es un array COMPLEX*16, dimensión (LDB,NRHS)
!>          A la entrada, B contiene NRHS vectores de longitud N.
!>          A la salida, B se sobrescribe con el producto A * B.
!>

LDB

!>          LDB es ENTERO
!>          La dimensión principal del array B.  LDB >= max(1,N).
!>

INFO

!>          INFO es ENTERO
!>          = 0: finalización exitosa
!>          < 0: si INFO = -k, el argumento k-ésimo tuvo un valor ilegal
!>
