ZLA_HERFSX_EXTENDED mejora la solución calculada de un sistema de ecuaciones lineales para matrices hermitianas indefinidas realizando un refinamiento iterativo de precisión extra y proporciona límites de error y estimaciones de error hacia atrás para la solución.

Propósito:

!>
!> ZLA_HERFSX_EXTENDED mejora la solución calculada de un sistema de
!> ecuaciones lineales mediante un refinamiento iterativo de precisión extra
!> y proporciona límites de error y estimaciones de error hacia atrás para la solución.
!> Esta subrutina es llamada por ZHERFSX para realizar el refinamiento iterativo.
!> Además del límite de error normwise, el código proporciona el límite de error
!> componente a componente máximo si es posible. Ver los comentarios para
!> ERR_BNDS_NORM y ERR_BNDS_COMP para detalles de los límites de error.
!> Tenga en cuenta que esta subrutina solo es responsable de establecer los
!> segundos campos de ERR_BNDS_NORM y ERR_BNDS_COMP.
!>

Parámetros

PREC_TYPE 
!>          PREC_TYPE es INTEGER
!>     Especifica la precisión intermedia a utilizar en el refinamiento.
!>     El valor se define por ILAPREC(P) donde P es un CHARACTER y P
!>          = 'S':  Simple
!>          = 'D':  Doble
!>          = 'I':  Indígena
!>          = 'X' o 'E':  Extra
!>

UPLO

!>          UPLO es CHARACTER*1
!>       = 'U':  El triángulo superior de A está almacenado;
!>       = 'L':  El triángulo inferior de A está almacenado.
!>

N

!>          N es INTEGER
!>     El número de ecuaciones lineales, es decir, el orden de la
!>     matriz A.  N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>     El número de lados derechos, es decir, el número de columnas de la
!>     matriz B.
!>

A

!>          A es una matriz COMPLEX*16, de dimensión (LDA,N)
!>     En la entrada, la matriz A de N por N.
!>

LDA

!>          LDA es INTEGER
!>     La dimensión principal del arreglo A.  LDA >= max(1,N).
!>

AF

!>          AF es una matriz COMPLEX*16, de dimensión (LDAF,N)
!>     La matriz diagonal de bloques D y los multiplicadores utilizados para
!>     obtener el factor U o L tal como lo calcula ZHETRF.
!>

LDAF

!>          LDAF es INTEGER
!>     La dimensión principal del arreglo AF.  LDAF >= max(1,N).
!>

IPIV

!>          IPIV es un arreglo INTEGER, de dimensión (N)
!>     Detalles de los intercambios y la estructura de bloques de D
!>     tal como se determinó por ZHETRF.
!>

COLEQU

!>          COLEQU es LOGICAL
!>     Si es .TRUE. entonces se realizó una   equilibración de columnas en A antes de llamar
!>     a esta rutina. Esto es necesario para calcular la solución y los límites
!>     de error correctamente.
!>

C

!>          C es un arreglo DOUBLE PRECISION, de dimensión (N)
!>     Los factores de escala de columna para A. Si COLEQU = .FALSE.,
!>     no se accede a C. Si se introduce C, cada elemento de C debe ser una potencia
!>     de la base para asegurar una solución y estimaciones de error fiables.
!>     La escala por potencias de la base no causa errores de redondeo a menos
!>     que el resultado cause un subdesbordamiento o desbordamiento. Los errores
!>     de redondeo durante la escala provocan el refinamiento con una matriz
!>     que no es equivalente a la matriz de entrada, produciendo estimaciones
!>     de error que pueden no ser fiables.
!>

B

!>          B es un arreglo COMPLEX*16, de dimensión (LDB,NRHS)
!>     La matriz del lado derecho B.
!>

LDB

!>          LDB es INTEGER
!>     La dimensión principal del arreglo B.  LDB >= max(1,N).
!>

Y

!>          Y es un arreglo COMPLEX*16, de dimensión (LDY,NRHS)
!>     En la entrada, la matriz solución X, tal como la calculó ZHETRS.
!>     En la salida, la matriz solución mejorada Y.
!>

LDY

!>          LDY es INTEGER
!>     La dimensión principal del arreglo Y.  LDY >= max(1,N).
!>

BERR_OUT

!>          BERR_OUT es un arreglo DOUBLE PRECISION, de dimensión (NRHS)
!>     En la salida, BERR_OUT(j) contiene el error relativo de retroceso
!>     componente a componente para el lado derecho j de la fórmula
!>         max(i) ( abs(RES(i)) / ( abs(op(A_s))*abs(Y) + abs(B_s) )(i) )
!>     donde abs(Z) es el valor absoluto componente a componente de la matriz
!>     o vector Z. Esto se calcula mediante ZLA_LIN_BERR.
!>

N_NORMS

!>          N_NORMS es INTEGER
!>     Determina qué límites de error devolver (ver ERR_BNDS_NORM
!>     y ERR_BNDS_COMP).
!>     Si N_NORMS >= 1 devuelve límites de error normwise.
!>     Si N_NORMS >= 2 devuelve límites de error componente a componente.
!>

ERR_BNDS_NORM

!>          ERR_BNDS_NORM es un arreglo DOUBLE PRECISION, de dimensión (NRHS, N_ERR_BNDS)
!>     Para cada lado derecho, este arreglo contiene información sobre
!>     varios límites de error y números de condición correspondientes al
!>     error relativo normwise, que se define de la siguiente manera:
!>
!>     Error relativo normwise en el i-ésimo vector solución:
!>             max_j (abs(XTRUE(j,i) - X(j,i)))
!>            ------------------------------
!>                  max_j abs(X(j,i))
!>
!>     El arreglo está indexado por el tipo de información de error tal como se describe
!>     a continuación. Actualmente hay hasta tres piezas de información
!>     devueltas.
!>
!>     El primer índice en ERR_BNDS_NORM(i,:) corresponde al i-ésimo
!>     lado derecho.
!>
!>     El segundo índice en ERR_BNDS_NORM(:,err) contiene los siguientes
!>     tres campos:
!>     err = 1  booleano. Confíe en la respuesta si el
!>              número de condición recíproco es menor que el umbral
!>              sqrt(n) * slam

Function/Subroutine Documentation

ZLA_HERFSX_EXTENDED computes error bounds and condition numbers for solving a complex hermitian positive definite linear system A * X = B. It is used by ZHERFSX.

Arguments

UPLO

UPLO is CHARACTER*1

Specifies whether the matrix A is upper or lower hermitian.

UPLO = 'U' or 'u': Upper Hermitian.

UPLO = 'L' or 'l': Lower Hermitian.

Used only when PARAMS(3) = 1.0 (i.e. when computing error bounds)

N

N is INTEGER

The order of the matrix A. N >= 0.

NRHS

NRHS is INTEGER

The number of right hand sides, i.e., the number of columns of the matrices B and X. NRHS >= 0.

A

A is COMPLEX*16 array, dimension (LDA,N)

On entry, the upper or lower trapezoidal part of the hermitian matrix A is to be given.

LDA

LDA is INTEGER

The leading dimension of the array A. LDA >= max(1,N).

AF

AF is COMPLEX*16 array, dimension (LDAF,N)

The factors of the factorization of A. Generated by ZPOTRF or ZHPTRF.

LDAF

LDAF is INTEGER

The leading dimension of the array AF. LDAF >= max(1,N).

IPIV

IPIV is INTEGER array, dimension (N)

Details of the factorization. Generated by ZGETRF.

B

B is COMPLEX*16 array, dimension (LDB,NRHS)

The right hand side matrix with NRHS solution vectors.

LDB

LDB is INTEGER

The leading dimension of the array B. LDB >= max(1,N).

X

X is COMPLEX*16 array, dimension (LDX,NRHS)

On entry, the solution matrix with NRHS solution vectors.

LDX

LDX is INTEGER

The leading dimension of the array X. LDX >= max(1,N).

ERR_BNDS_NORM

ERR_BNDS_NORM is DOUBLE PRECISION array, dimension (NRHS, 3)

The estimated error bounds and condition numbers for the normwise error.

The first index corresponds to the right hand side.

The second index contains the following three fields:

err = 1

Boolean: Trust the answer if the reciprocal condition number is less than the threshold sqrt(n) * slamch('Epsilon').

err = 2

Error bound: The estimated forward error, almost certainly within a factor of 10 of the true error so long as the next entry is greater than the threshold sqrt(n) * slamch('Epsilon'). This error bound should only be trusted if the previous boolean is true.

err = 3

Reciprocal condition number: Estimated normwise reciprocal condition number. Compared with the threshold sqrt(n) * slamch('Epsilon') to determine if the error estimate is . These reciprocal condition numbers are 1 / (norm(Z^{-1},inf) * norm(Z,inf)) for some appropriately scaled matrix Z.

Let Z = S*A, where S scales each row by a power of the radix so all absolute row sums of Z are approximately 1.

This subroutine is only responsible for setting the second field above.

See Lapack Working Note 165 for further details and extra cautions.

ERR_BNDS_COMP

ERR_BNDS_COMP is DOUBLE PRECISION array, dimension (NRHS, 3)

For each right-hand side, this array contains information about various error bounds and condition numbers corresponding to the componentwise relative error, which is defined as follows:

Componentwise relative error in the ith solution vector:

abs(XTRUE(j,i) - X(j,i))

max_j ----------------------

abs(X(j,i))

The array is indexed by the right-hand side i (on which the componentwise relative error depends), and the type of error information as described below. There currently are up to three pieces of information returned for each right-hand side. If componentwise accuracy is not requested (PARAMS(3) = 0.0), then ERR_BNDS_COMP is not accessed. If N_ERR_BNDS < 3, then at most the first (:,N_ERR_BNDS) entries are returned.

The first index in ERR_BNDS_COMP(i,:) corresponds to the ith right-hand side.

The second index in ERR_BNDS_COMP(:,err) contains the following three fields:

err = 1

Boolean. Trust the answer if the reciprocal condition number is less than the threshold sqrt(n) * slamch('Epsilon').

err = 2

Error bound: The estimated forward error, almost certainly within a factor of 10 of the true error so long as the next entry is greater than the threshold sqrt(n) * slamch('Epsilon'). This error bound should only be trusted if the previous boolean is true.

err = 3

Reciprocal condition number: Estimated componentwise reciprocal condition number. Compared with the threshold sqrt(n) * slamch('Epsilon') to determine if the error estimate is . These reciprocal condition numbers are 1 / (norm(Z^{-1},inf) * norm(Z,inf)) for some appropriately scaled matrix Z.

Let Z = S*(A*diag(x)), where x is the solution for the current right-hand side and S scales each row of A*diag(x) by a power of the radix so all absolute row sums of Z are approximately 1.

This subroutine is only responsible for setting the second field above.

See Lapack Working Note 165 for further details and extra cautions.

RES

RES is COMPLEX*16 array, dimension (N)

Workspace to hold the intermediate residual.

AYB

AYB is DOUBLE PRECISION array, dimension (N)

Workspace.

DY

DY is COMPLEX*16 array, dimension (N)

Workspace to hold the intermediate solution.

Y_TAIL

Y_TAIL is COMPLEX*16 array, dimension (N)

Workspace to hold the trailing bits of the intermediate solution.

RCOND

RCOND is DOUBLE PRECISION

Reciprocal scaled condition number. This is an estimate of the reciprocal Skeel condition number of the matrix A after equilibration (if done). If this is less than the machine precision (in particular, if it is zero), the matrix is singular to working precision. Note that the error may still be small even if this number is very small and the matrix appears ill- conditioned.

ITHRESH

ITHRESH is INTEGER

The maximum number of residual computations allowed for refinement. The default is 10. For 'aggressive' set to 100 to permit convergence using approximate factorizations or factorizations other than LU. If the factorization uses a technique other than Gaussian elimination, the guarantees in ERR_BNDS_NORM and ERR_BNDS_COMP may no longer be trustworthy.

RTHRESH

RTHRESH is DOUBLE PRECISION

Determines when to stop refinement if the error estimate stops decreasing. Refinement will stop when the next solution no longer satisfies norm(dx_{i+1}) < RTHRESH * norm(dx_i) where norm(Z) is the infinity norm of Z. RTHRESH satisfies 0 < RTHRESH <= 1. The default value is 0.5. For 'aggressive' set to 0.9 to permit convergence on extremely ill-conditioned matrices. See LAWN 165 for more details.

DZ_UB

DZ_UB is DOUBLE PRECISION

Determines when to start considering componentwise convergence. Componentwise convergence is only considered after each component of the solution Y is stable, which we define as the relative change in each component being less than DZ_UB. The default value is 0.25, requiring the first bit to be stable. See LAWN 165 for more details.

IGNORE_CWISE

IGNORE_CWISE is LOGICAL

If .TRUE. then ignore componentwise convergence. Default value is .FALSE..

INFO

INFO is INTEGER

= 0: Successful exit.

< 0: if INFO = -i, the ith argument to ZLA_HERFSX_EXTENDED had an illegal value
