Documentación de función/subrutina

double precision function zla_syrcond_x (character uplo, integer n, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( ldaf, * ) af, integer ldaf, integer, dimension( * ) ipiv, complex*16, dimension( * ) x, integer info, complex*16, dimension( * ) work, double precision, dimension( * ) rwork)

ZLA_SYRCOND_X calcula el número de condición de la norma infinito de op(A)*diag(x) para matrices simétricas indefinidas.

Propósito:

!>
!>    ZLA_SYRCOND_X Calcula el número de condición de la norma infinito de
!>    op(A) * diag(X) donde X es un vector COMPLEX*16.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>       = 'U':  El triángulo superior de A está almacenado;
!>       = 'L':  El triángulo inferior de A está almacenado.
!>

N

!>          N es INTEGER
!>     El número de ecuaciones lineales, es decir, el orden de la
!>     matriz A.  N >= 0.
!>

A

!>          A es un array COMPLEX*16, dimensión (LDA,N)
!>     En la entrada, la matriz A de N por N.
!>

LDA

!>          LDA es INTEGER
!>     La dimensión principal del array A.  LDA >= max(1,N).
!>

AF

!>          AF es un array COMPLEX*16, dimensión (LDAF,N)
!>     La matriz diagonal de bloques D y los multiplicadores utilizados para
!>     obtener el factor U o L calculado por ZSYTRF.
!>

LDAF

!>          LDAF es INTEGER
!>     La dimensión principal del array AF.  LDAF >= max(1,N).
!>

IPIV

!>          IPIV es un array INTEGER, dimensión (N)
!>     Detalles de los intercambios y la estructura de bloques de D
!>     según lo determinado por ZSYTRF.
!>

X

!>          X es un array COMPLEX*16, dimensión (N)
!>     El vector X en la fórmula op(A) * diag(X).
!>

INFO

!>          INFO es INTEGER
!>       = 0:  Salida exitosa.
!>     i > 0:  El i-ésimo argumento es inválido.
!>

WORK

!>          WORK es un array COMPLEX*16, dimensión (2*N).
!>     Espacio de trabajo.
!>

RWORK

!>          RWORK es un array DOUBLE PRECISION, dimensión (N).
!>     Espacio de trabajo.
!>
