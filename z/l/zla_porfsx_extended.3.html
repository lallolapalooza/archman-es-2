Documentación de Función/Subrutina

subroutine zla_porfsx_extended (integer prec_type, character uplo, integer n, integer nrhs, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( ldaf, * ) af, integer ldaf, logical colequ, double precision, dimension( * ) c, complex*16, dimension( ldb, * ) b, integer ldb, complex*16, dimension( ldy, * ) y, integer ldy, double precision, dimension( * ) berr_out, integer n_norms, double precision, dimension( nrhs, * ) err_bnds_norm, double precision, dimension( nrhs, * ) err_bnds_comp, complex*16, dimension( * ) res, double precision, dimension( * ) ayb, complex*16, dimension( * ) dy, complex*16, dimension( * ) y_tail, double precision rcond, integer ithresh, double precision rthresh, double precision dz_ub, logical ignore_cwise, integer info)

ZLA_PORFSX_EXTENDED mejora la solución calculada de un sistema de ecuaciones lineales para matrices simétricas o Hermitianas definidas positivas realizando un refinamiento iterativo de precisión extra y proporciona cotas de error y estimaciones de error hacia atrás para la solución.

Propósito:

!>
!> ZLA_PORFSX_EXTENDED mejora la solución calculada de un sistema de
!> ecuaciones lineales mediante un refinamiento iterativo de precisión extra
!> y proporciona cotas de error y estimaciones de error hacia atrás para la solución.
!> Esta subrutina es llamada por ZPORFSX para realizar el refinamiento iterativo.
!> Además de la cota de error normwise, el código proporciona la cota de error
!> máxima por componentes si es posible. Consulte los comentarios para ERR_BNDS_NORM
!> y ERR_BNDS_COMP para obtener detalles sobre las cotas de error. Tenga en cuenta que esta
!> subrutina solo es responsable de establecer los segundos campos de
!> ERR_BNDS_NORM y ERR_BNDS_COMP.
!>

Parámetros

PREC_TYPE 
!>          PREC_TYPE es INTEGER
!>     Especifica la precisión intermedia a utilizar en el refinamiento.
!>     El valor se define por ILAPREC(P) donde P es un CHARACTER y P
!>          = 'S':  Simple
!>          = 'D':  Doble
!>          = 'I':  Indígena
!>          = 'X' o 'E':  Extra
!>

UPLO

!>          UPLO es CHARACTER*1
!>       = 'U':  El triángulo superior de A está almacenado;
!>       = 'L':  El triángulo inferior de A está almacenado.
!>

N

!>          N es INTEGER
!>     El número de ecuaciones lineales, es decir, el orden de la
!>     matriz A.  N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>     El número de lados derechos, es decir, el número de columnas de la
!>     matriz B.
!>

A

!>          A es un array COMPLEX*16, de dimensión (LDA,N)
!>     En la entrada, la matriz N por N A.
!>

LDA

!>          LDA es INTEGER
!>     La dimensión principal del array A.  LDA >= max(1,N).
!>

AF

!>          AF es un array COMPLEX*16, de dimensión (LDAF,N)
!>     El factor triangular U o L de la factorización de Cholesky
!>     A = U**T*U o A = L*L**T, tal como se calcula por ZPOTRF.
!>

LDAF

!>          LDAF es INTEGER
!>     La dimensión principal del array AF.  LDAF >= max(1,N).
!>

COLEQU

!>          COLEQU es LOGICAL
!>     Si es .TRUE. entonces se realizó un escalado de columnas a A antes de llamar
!>     a esta subrutina. Esto es necesario para calcular correctamente la solución
!>     y las cotas de error.
!>

C

!>          C es un array DOUBLE PRECISION, de dimensión (N)
!>     Los factores de escala de columna para A. Si COLEQU = .FALSE., C
!>     no se accede. Si se introduce C, cada elemento de C debe ser una potencia
!>     de la base para asegurar una solución y estimaciones de error fiables.
!>     El escalado por potencias de la base no causa errores de redondeo a menos
!>     que el resultado sea un subdesbordamiento o desbordamiento. Los errores de
!>     redondeo durante el escalado
!>     producen un refinamiento con una matriz que no es equivalente a la
!>     matriz de entrada, produciendo estimaciones de error que pueden no ser
!>     fiables.
!>

B

!>          B es un array COMPLEX*16, de dimensión (LDB,NRHS)
!>     La matriz del lado derecho B.
!>

LDB

!>          LDB es INTEGER
!>     La dimensión principal del array B.  LDB >= max(1,N).
!>

Y

!>          Y es un array COMPLEX*16, de dimensión (LDY,NRHS)
!>     En la entrada, la matriz solución X, tal como la calcula ZPOTRS.
!>     En la salida, la matriz solución mejorada Y.
!>

LDY

!>          LDY es INTEGER
!>     La dimensión principal del array Y.  LDY >= max(1,N).
!>

BERR_OUT

!>          BERR_OUT es un array DOUBLE PRECISION, de dimensión (NRHS)
!>     En la salida, BERR_OUT(j) contiene el error relativo de retroceso por componentes
!>     para el lado derecho j de la fórmula
!>         max(i) ( abs(RES(i)) / ( abs(op(A_s))*abs(Y) + abs(B_s) )(i) )
!>     donde abs(Z) es el valor absoluto por componentes de la matriz
!>     o vector Z. Esto se calcula por ZLA_LIN_BERR.
!>

N_NORMS

!>          N_NORMS es INTEGER
!>     Determina qué cotas de error se devuelven (ver ERR_BNDS_NORM
!>     y ERR_BNDS_COMP).
!>     Si N_NORMS >= 1 devuelve cotas de error normwise.
!>     Si N_NORMS >= 2 devuelve cotas de error por componentes.
!>

ERR_BNDS_NORM

!>          ERR_BNDS_NORM es un array DOUBLE PRECISION, de dimensión (NRHS, N_ERR_BNDS)
!>     Para cada lado derecho, esta matriz contiene información sobre
!>     varias cotas de error y números de condición correspondientes al
!>     error relativo normwise, que se define de la siguiente manera:
!>
!>     Error relativo normwise en el i-ésimo vector solución:
!>             max_j (abs(XTRUE(j,i) - X(j,i)))
!>            ------------------------------
!>                  max_j abs(X(j,i))
!>
!>     La matriz se indexa por el tipo de información de error, tal como se describe
!>     a continuación. Actualmente hay hasta tres piezas de información
!>     devueltas.
!>
!>     El primer índice en ERR_BNDS_NORM(i,:) corresponde al i-ésimo
!>     lado derecho.
!>
!>     El segundo índice en ERR_BNDS_NORM(:,err) contiene los siguientes
!>     tres campos:
!>     err = 1  booleano. Confiar en la respuesta si el
!>              número de condición recíproco es menor que el umbral
!>              sqrt(n) * slamch('Epsilon').
!>
!>     err = 2  cota de error: El error directo estimado,
!>              casi con toda seguridad dentro de un factor de 10 del error verdadero
!>              siempre que la siguiente entrada sea mayor que el umbral
!>

NAME

zla_porfsx_extended - provides a detailed error analysis for the solution of a system of linear equations AX = B when A is a general band matrix

SYNOPSIS

    SUBROUTINE ZLA_PORFSX_EXTENDED(
             UPLO, N, NRHS, A, LDA, AFAC, LDAFAC, IPIV, B, LDB, X, LDX,
             ERR_BNDS_NORM, ERR_BNDS_COMP, RES, AYB, DY, Y_TAIL, RCOND,
             ITHRESH, RTHRESH, DZ_UB, IGNORE_CWISE, INFO
    )

        CHARACTER(LEN=1)  :: UPLO
        INTEGER           :: N
        INTEGER           :: NRHS
        COMPLEX*16, DIMENSION(LDA,*) :: A
        INTEGER           :: LDA
        COMPLEX*16, DIMENSION(LDAFAC,*) :: AFAC
        INTEGER           :: LDAFAC
        INTEGER, DIMENSION(:) :: IPIV
        COMPLEX*16, DIMENSION(LDB,*) :: B
        INTEGER           :: LDB
        COMPLEX*16, DIMENSION(LDX,*) :: X
        INTEGER           :: LDX
        DOUBLE PRECISION, DIMENSION(NRHS, 3) :: ERR_BNDS_NORM
        DOUBLE PRECISION, DIMENSION(NRHS, 3) :: ERR_BNDS_COMP
        COMPLEX*16, DIMENSION(N) :: RES
        DOUBLE PRECISION, DIMENSION(N) :: AYB
        COMPLEX*16, DIMENSION(N) :: DY
        COMPLEX*16, DIMENSION(N) :: Y_TAIL
        DOUBLE PRECISION           :: RCOND
        INTEGER           :: ITHRESH
        DOUBLE PRECISION           :: RTHRESH
        DOUBLE PRECISION           :: DZ_UB
        LOGICAL           :: IGNORE_CWISE
        INTEGER           :: INFO

Function/Subroutine Documentation

This subroutine is the core routine that computes error bounds and condition estimates for the solution of the system of linear equations AX = B where A is a general band matrix.

This subroutine is the core routine that computes error bounds and condition estimates for the solution of the system of linear equations AX = B.

Arguments:

UPLO

!>          UPLO is CHARACTER*1
!>          Specifies whether the matrix A is upper or lower triangular.
!>          = 'U': A is upper triangular
!>          = 'L': A is lower triangular

N

!>          N is INTEGER
!>          The order of the matrix A.  N >= 0.

NRHS

!>          NRHS is INTEGER
!>          The number of right hand sides, i.e., the number of columns of
!>          the matrices B, X, ERR_BNDS_NORM, and ERR_BNDS_COMP.
!>          NRHS >= 1.

A

!>          A is COMPLEX*16 array, dimension (LDA,N)
!>          The coefficient matrix A of the linear system.

LDA

!>          LDA is INTEGER
!>          The leading dimension of the array A. LDA >= max(1,N).

AFAC

!>          AFAC is COMPLEX*16 array, dimension (LDAFAC,N)
!>          The factors of A. AFAC contains the result of a factorization
!>          of A. For example, if A is LU factored, AFAC contains the LU
!>          factorization of A.

LDAFAC

!>          LDAFAC is INTEGER
!>          The leading dimension of the array AFAC. LDAFAC >= max(1,N).

IPIV

!>          IPIV is INTEGER array, dimension (N)
!>          The pivot indices from the factorization of A.

B

!>          B is COMPLEX*16 array, dimension (LDB,NRHS)
!>          The right hand side matrix B.

LDB

!>          LDB is INTEGER
!>          The leading dimension of the array B. LDB >= max(1,N).

X

!>          X is COMPLEX*16 array, dimension (LDX,NRHS)
!>          The solution matrix X.

LDX

!>          LDX is INTEGER
!>          The leading dimension of the array X. LDX >= max(1,N).

ERR_BNDS_NORM

!>          ERR_BNDS_NORM is DOUBLE PRECISION array, dimension (NRHS, 3)
!>     For each right-hand side, this array contains information about
!>     various error bounds and condition numbers corresponding to the
!>     normwise relative error, which is defined as follows:
!>
!>     Normwise relative error in the ith solution vector:
!>                    max_j abs(XTRUE(j,i) - X(j,i))
!>             --------------------------------------
!>                           max_j abs(X(j,i))
!>
!>     The array is indexed by the right-hand side i (on which the
!>     normwise relative error depends), and the type of error
!>     information as described below. There currently are up to three
!>     pieces of information returned for each right-hand side. If
!>     normwise accuracy is not requested (PARAMS(2) = 0.0), then
!>     ERR_BNDS_NORM is not accessed. If NRHS < 3, then at most
!>     the first (:,NRHS) entries are returned.
!>
!>     The first index in ERR_BNDS_NORM(i,:) corresponds to the ith
!>     right-hand side.
!>
!>     The second index in ERR_BNDS_NORM(:,err) contains the following
!>     three fields:
!>     err = 1  boolean. Trust the answer if the
!>              reciprocal condition number is less than the threshold
!>              sqrt(n) * slamch('Epsilon').
!>
!>     err = 2  error bound: The estimated forward error,
!>              almost certainly within a factor of 10 of the true error
!>              so long as the next entry is greater than the threshold
!>              sqrt(n) * slamch('Epsilon'). This error bound should only
!>              be trusted if the previous boolean is true.
!>
!>     err = 3  Reciprocal condition number: Estimated normwise
!>              reciprocal condition number.  Compared with the threshold
!>              sqrt(n) * slamch('Epsilon') to determine if the error
!>              estimate is . These reciprocal condition
!>              numbers are 1 / (norm(Z^{-1},inf) * norm(Z,inf)) for some
!>              appropriately scaled matrix Z.
!>              Let Z = S*A, where S scales each row by a power of the
!>              radix so all absolute row sums of Z are approximately 1.
!>
!>     This subroutine is only responsible for setting the second field
!>     above.
!>     See Lapack Working Note 165 for further details and extra
!>     cautions.
!>

ERR_BNDS_COMP

!>          ERR_BNDS_COMP is DOUBLE PRECISION array, dimension (NRHS, N_ERR_BNDS)
!>     For each right-hand side, this array contains information about
!>     various error bounds and condition numbers corresponding to the
!>     componentwise relative error, which is defined as follows:
!>
!>     Componentwise relative error in the ith solution vector:
!>                    abs(XTRUE(j,i) - X(j,i))
!>             max_j ----------------------
!>                         abs(X(j,i))
!>
!>     The array is indexed by the right-hand side i (on which the
!>     componentwise relative error depends), and the type of error
!>     information as described below. There currently are up to three
!>     pieces of information returned for each right-hand side. If
!>     componentwise accuracy is not requested (PARAMS(3) = 0.0), then
!>     ERR_BNDS_COMP is not accessed.  If N_ERR_BNDS < 3, then at most
!>     the first (:,N_ERR_BNDS) entries are returned.
!>
!>     The first index in ERR_BNDS_COMP(i,:) corresponds to the ith
!>     right-hand side.
!>
!>     The second index in ERR_BNDS_COMP(:,err) contains the following
!>     three fields:
!>     err = 1  boolean. Trust the answer if the
!>              reciprocal condition number is less than the threshold
!>              sqrt(n) * slamch('Epsilon').
!>
!>     err = 2  error bound: The estimated forward error,
!>              almost certainly within a factor of 10 of the true error
!>              so long as the next entry is greater than the threshold
!>              sqrt(n) * slamch('Epsilon'). This error bound should only
!>              be trusted if the previous boolean is true.
!>
!>     err = 3  Reciprocal condition number: Estimated componentwise
!>              reciprocal condition number.  Compared with the threshold
!!>              sqrt(n) * slamch('Epsilon') to determine if the error
!>              estimate is . These reciprocal condition
!>              numbers are 1 / (norm(Z^{-1},inf) * norm(Z,inf)) for some
!>              appropriately scaled matrix Z.
!>              Let Z = S*(A*diag(x)), where x is the solution for the
!>              current right-hand side and S scales each row of
!>              A*diag(x) by a power of the radix so all absolute row
!>              sums of Z are approximately 1.
!>
!>     This subroutine is only responsible for setting the second field
!>     above.
!>     See Lapack Working Note 165 for further details and extra
!>     cautions.
!>

RES

!>          RES is COMPLEX*16 array, dimension (N)
!>     Workspace to hold the intermediate residual.
!>

AYB

!>          AYB is DOUBLE PRECISION array, dimension (N)
!>     Workspace.
!>

DY

!>          DY is COMPLEX*16 PRECISION array, dimension (N)
!>     Workspace to hold the intermediate solution.
!>

Y_TAIL

!>          Y_TAIL is COMPLEX*16 array, dimension (N)
!>     Workspace to hold the trailing bits of the intermediate solution.
!>

RCOND

!>          RCOND is DOUBLE PRECISION
!>     Reciprocal scaled condition number.  This is an estimate of the
!>     reciprocal Skeel condition number of the matrix A after
!>     equilibration (if done).  If this is less than the machine
!>     precision (in particular, if it is zero), the matrix is singular
!>     to working precision.  Note that the error may still be small even
!>     if this number is very small and the matrix appears ill-
!>     conditioned.
!>

ITHRESH

!>          ITHRESH is INTEGER
!>     The maximum number of residual computations allowed for
!>     refinement. The default is 10. For 'aggressive' set to 100 to
!>     permit convergence using approximate factorizations or
!>     factorizations other than LU. If the factorization uses a
!>     technique other than Gaussian elimination, the guarantees in
!>     ERR_BNDS_NORM and ERR_BNDS_COMP may no longer be trustworthy.
!>

RTHRESH

!>          RTHRESH is DOUBLE PRECISION
!>     Determines when to stop refinement if the error estimate stops
!>     decreasing. Refinement will stop when the next solution no longer
!>     satisfies norm(dx_{i+1}) < RTHRESH * norm(dx_i) where norm(Z) is
!>     the infinity norm of Z. RTHRESH satisfies 0 < RTHRESH <= 1. The
!>     default value is 0.5. For 'aggressive' set to 0.9 to permit
!>     convergence on extremely ill-conditioned matrices. See LAWN 165
!>     for more details.
!>

DZ_UB

!>          DZ_UB is DOUBLE PRECISION
!>     Determines when to start considering componentwise convergence.
!>     Componentwise convergence is only considered after each component
!>     of the solution Y is stable, which we define as the relative
!>     change in each component being less than DZ_UB. The default value
!>     is 0.25, requiring the first bit to be stable. See LAWN 165 for
!>     more details.
!>

IGNORE_CWISE

!>          IGNORE_CWISE is LOGICAL
!>     If .TRUE. then ignore componentwise convergence. Default value
!>     is .FALSE..
!>

INFO

!>          INFO is INTEGER
!>       = 0:  Successful exit.
!>       < 0:  if INFO = -i, the ith argument to ZPOTRS had an illegal
!>             value
!>
