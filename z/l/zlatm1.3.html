DOCUMENTACIÓN DE FUNCIÓN/SUBRUTINA

subrutina zlatm1 (integer mode, double precision cond, integer irsign, integer idist, integer, dimension( 4 ) iseed, complex*16, dimension( * ) d, integer n, integer info)

ZLATM1

Propósito:

!>
!>    ZLATM1 calcula las entradas de D(1..N) según lo especificado por
!>    MODE, COND e IRSIGN. IDIST e ISEED determinan la generación
!>    de números aleatorios. ZLATM1 es llamada por ZLATMR para generar
!>    matrices de prueba aleatorias para programas LAPACK.
!>

Parámetros

MODE 
!>          MODE es INTEGER
!>           En la entrada describe cómo se debe calcular D:
!>           MODE = 0 significa no cambiar D.
!>           MODE = 1 establece D(1)=1 y D(2:N)=1.0/COND
!>           MODE = 2 establece D(1:N-1)=1 y D(N)=1.0/COND
!>           MODE = 3 establece D(I)=COND**(-(I-1)/(N-1))
!>           MODE = 4 establece D(i)=1 - (i-1)/(N-1)*(1 - 1/COND)
!>           MODE = 5 establece D a números aleatorios en el rango
!>                    ( 1/COND , 1 ) tales que sus logaritmos
!>                    estén distribuidos uniformemente.
!>           MODE = 6 establece D a números aleatorios de la misma distribución
!>                    que el resto de la matriz.
!>           MODE < 0 tiene el mismo significado que ABS(MODE), excepto que
!>              el orden de los elementos de D se invierte.
!>           Por lo tanto, si MODE es positivo, D tiene entradas que varían de
!>              1 a 1/COND, si es negativo, de 1/COND a 1.
!>           No modificado.
!>

COND

!>          COND es DOUBLE PRECISION
!>           En la entrada, se usa como se describe en MODE arriba.
!>           Si se usa, debe ser >= 1. No modificado.
!>

IRSIGN

!>          IRSIGN es INTEGER
!>           En la entrada, si MODE no es -6, 0 ni 6, determina el signo de
!>           las entradas de D
!>           0 => deja las entradas de D sin cambios
!>           1 => multiplica cada entrada de D por un número complejo aleatorio
!>                distribuido uniformemente con valor absoluto 1
!>

IDIST

!>          IDIST es INTEGER
!>           En la entrada, IDIST especifica el tipo de distribución que se
!>           utilizará para generar una matriz aleatoria.
!>           1 => partes real e imaginaria cada una UNIFORM( 0, 1 )
!>           2 => partes real e imaginaria cada una UNIFORM( -1, 1 )
!>           3 => partes real e imaginaria cada una NORMAL( 0, 1 )
!>           4 => número complejo uniforme en DISK( 0, 1 )
!>           No modificado.
!>

ISEED

!>          ISEED es un array INTEGER, dimension ( 4 )
!>           En la entrada ISEED especifica la semilla del generador de
!>           números aleatorios. El generador de números aleatorios utiliza
!>           una secuencia congruencial lineal limitada a enteros pequeños,
!>           y por lo tanto debería producir números aleatorios
!>           independientes de la máquina. Los valores de ISEED cambian en
!>           la salida, y pueden usarse en la siguiente llamada a ZLATM1
!>           para continuar la misma secuencia de números aleatorios.
!>           Cambiado en la salida.
!>

D

!>          D es un array COMPLEX*16, dimension ( N )
!>           Array a calcular según MODE, COND e IRSIGN.
!>           Puede ser modificado en la salida si MODE es distinto de cero.
!>

N

!>          N es INTEGER
!>           Número de entradas de D. No modificado.
!>

INFO

!>          INFO es INTEGER
!>            0  => terminación normal
!>           -1  => si MODE no está en el rango -6 a 6
!>           -2  => si MODE no es -6, 0 ni 6, y
!>                  IRSIGN no es 0 ni 1
!>           -3  => si MODE no es -6, 0 ni 6 y COND es menor que 1
!>           -4  => si MODE es igual a 6 o -6 y IDIST no está en el rango 1 a 4
!>           -7  => si N es negativo
!>
