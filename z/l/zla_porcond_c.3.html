doble precisión function zla_porcond_c (character uplo, integer n, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( ldaf, * ) af, integer ldaf, double precision, dimension( * ) c, logical capply, integer info, complex*16, dimension( * ) work, double precision, dimension( * ) rwork)

ZLA_PORCOND_C calcula el número de condición de la norma infinita de op(A)*inv(diag(c)) para matrices Hermitianas definidas positivas.

Propósito:

!>
!>    ZLA_PORCOND_C Calcula el número de condición de la norma infinita de
!>    op(A) * inv(diag(C)) donde C es un vector de DOBLE PRECISIÓN
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>       = 'U': El triángulo superior de A está almacenado;
!>       = 'L': El triángulo inferior de A está almacenado.
!>

N

!>          N es INTEGER
!>     El número de ecuaciones lineales, es decir, el orden de la
!>     matriz A.  N >= 0.
!>

A

!>          A es array COMPLEX*16, dimensión (LDA,N)
!>     En la entrada, la matriz A de N por N
!>

LDA

!>          LDA es INTEGER
!>     La dimensión principal del array A.  LDA >= max(1,N).
!>

AF

!>          AF es array COMPLEX*16, dimensión (LDAF,N)
!>     El factor triangular U o L de la factorización de Cholesky
!>     A = U**H*U o A = L*L**H, tal como se calcula por ZPOTRF.
!>

LDAF

!>          LDAF es INTEGER
!>     La dimensión principal del array AF.  LDAF >= max(1,N).
!>

C

!>          C es array DOUBLE PRECISION, dimensión (N)
!>     El vector C en la fórmula op(A) * inv(diag(C)).
!>

CAPPLY

!>          CAPPLY es LOGICAL
!>     Si .TRUE. entonces accede al vector C en la fórmula anterior.
!>

INFO

!>          INFO es INTEGER
!>       = 0:  Salida exitosa.
!>     i > 0:  El argumento i es inválido.
!>

WORK

!>          WORK es array COMPLEX*16, dimensión (2*N).
!>     Espacio de trabajo.
!>

RWORK

!>          RWORK es array DOUBLE PRECISION, dimensión (N).
!>     Espacio de trabajo.
!>
