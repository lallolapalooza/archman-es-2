Documentación de función/subrutina

subrutina zlaed0 (integer qsiz, integer n, double precision, dimension( * ) d, double precision, dimension( * ) e, complex*16, dimension( ldq, * ) q, integer ldq, complex*16, dimension( ldqs, * ) qstore, integer ldqs, double precision, dimension( * ) rwork, integer, dimension( * ) iwork, integer info)

ZLAED0 usado por ZSTEDC. Calcula todos los valores propios y los vectores propios correspondientes de una matriz tridiagonal simétrica irreducida usando el método de divide y vencerás.

Propósito:

!>
!> Usando el método de divide y vencerás, ZLAED0 calcula todos los valores
!> propios de una matriz tridiagonal simétrica que es un bloque diagonal
!> de aquellos de reducir una matriz hermítica densa o de banda y
!> los vectores propios correspondientes de la matriz densa o de banda.
!>

Parámetros

QSIZ 
!>          QSIZ es INTEGER
!>         La dimensión de la matriz unitaria usada para reducir
!>         la matriz completa a forma tridiagonal.  QSIZ >= N si ICOMPQ = 1.
!>

N

!>          N es INTEGER
!>         La dimensión de la matriz tridiagonal simétrica.  N >= 0.
!>

D

!>          D es un array de DOUBLE PRECISION, dimensión (N)
!>         En la entrada, los elementos diagonales de la matriz tridiagonal.
!>         En la salida, los valores propios en orden ascendente.
!>

E

!>          E es un array de DOUBLE PRECISION, dimensión (N-1)
!>         En la entrada, los elementos fuera de la diagonal de la matriz tridiagonal.
!>         En la salida, E ha sido destruido.
!>

Q

!>          Q es un array de COMPLEX*16, dimensión (LDQ,N)
!>         En la entrada, Q debe contener una matriz QSIZ x N cuyas columnas
!>         son ortonormales unitarias. Es parte de la matriz unitaria
!>         que reduce la matriz hermítica densa completa a una
!>         matriz tridiagonal simétrica (reducible).
!>

LDQ

!>          LDQ es INTEGER
!>         La dimensión principal del array Q.  LDQ >= max(1,N).
!>

IWORK

!>          IWORK es un array de INTEGER,
!>         la dimensión de IWORK debe ser al menos
!>                      6 + 6*N + 5*N*lg N
!>                      ( lg( N ) = el entero más pequeño k
!>                                  tal que 2^k >= N )
!>

RWORK

!>          RWORK es un array de DOUBLE PRECISION,
!>                               dimensión (1 + 3*N + 2*N*lg N + 3*N**2)
!>                        ( lg( N ) = el entero más pequeño k
!>                                    tal que 2^k >= N )
!>

QSTORE

!>          QSTORE es un array de COMPLEX*16, dimensión (LDQS, N)
!>         Se usa para almacenar partes de la matriz de vectores propios
!>         cuando ocurren las multiplicaciones de la matriz de actualización.
!>

LDQS

!>          LDQS es INTEGER
!>         La dimensión principal del array QSTORE.
!>         LDQS >= max(1,N).
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa.
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>          > 0:  El algoritmo no pudo calcular un valor propio mientras
!>                trabajaba en la submatriz ubicada en las filas y columnas
!>                INFO/(N+1) a mod(INFO,N+1).
!>
