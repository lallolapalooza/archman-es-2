DOCUMENTACIÓN DE LA FUNCIÓN/SUBRUTINA

subroutine zla_wwaddw (integer n, complex*16, dimension( * ) x, complex*16, dimension( * ) y, complex*16, dimension( * ) w)

ZLA_WWADDW añade un vector W a un vector de doble precisión simple (X, Y).

Propósito:

!>
!>    ZLA_WWADDW añade un vector W a un vector de doble precisión simple (X, Y).
!>
!>    Esto funciona para toda la aritmética de punto flotante de doble precisión
!>    hexagonal y binaria de IBM, pero no para la decimal.
!>

Parámetros

N 
!>          N es INTEGER
!>            La longitud de los vectores X, Y y W.
!>

X

!>          X es un array COMPLEX*16, de dimensión (N)
!>            La primera parte del vector de acumulación de doble precisión simple.
!>

Y

!>          Y es un array COMPLEX*16, de dimensión (N)
!>            La segunda parte del vector de acumulación de doble precisión simple.
!>

W

!>          W es un array COMPLEX*16, de dimensión (N)
!>            El vector que se va a añadir.
!>
