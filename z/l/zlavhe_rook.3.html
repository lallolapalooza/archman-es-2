Documentación de Función/Subrutina

subroutine zlavhe_rook (character uplo, character trans, character diag, integer n, integer nrhs, complex*16, dimension( lda, * ) a, integer lda, integer, dimension( * ) ipiv, complex*16, dimension( ldb, * ) b, integer ldb, integer info)

ZLAVHE_ROOK

Propósito:

ZLAVHE_ROOK realiza una de las operaciones de matriz-vector x := A*x o x := A^H*x, donde x es un vector de N elementos y A es uno de los factores de la factorización de bloque U*D*U' o L*D*L' calculada por ZHETRF_ROOK.

Si TRANS = 'N', multiplica por U o U * D (o L o L * D) Si TRANS = 'C', multiplica por U' o D * U' (o L' o D * L')

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          Especifica si el factor almacenado en A es triangular superior o
!>          inferior.
!>          = 'U':  Triangular superior
!>          = 'L':  Triangular inferior
!>

TRANS

!>          TRANS es CHARACTER*1
!>          Especifica la operación a realizar:
!>          = 'N':  x := A*x
!>          = 'C':   x := A^H*x
!>

DIAG

!>          DIAG es CHARACTER*1
!>          Especifica si los bloques diagonales son matrices unitarias o no.
!>          Si se asume que los bloques diagonales son unitarios, entonces
!>          A = U o A = L, de lo contrario A = U*D o A = L*D.
!>          = 'U':  Se asume que los bloques diagonales son matrices unitarias.
!>          = 'N':  Se asume que los bloques diagonales son matrices no unitarias.
!>

N

!>          N es INTEGER
!>          El número de filas y columnas de la matriz A.  N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de lados derechos, es decir, el número de vectores
!>          x a multiplicar por A.  NRHS >= 0.
!>

A

!>          A es un array COMPLEX*16, dimensión (LDA,N)
!>          La matriz diagonal de bloques D y los multiplicadores utilizados para
!>          obtener el factor U o L calculados por ZHETRF_ROOK.
!>          Almacenado como una matriz triangular 2-D.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

IPIV

!>          IPIV es un array INTEGER, dimensión (N)
!>          Detalles de los intercambios y la estructura de bloques de D,
!>          según lo determinado por ZHETRF_ROOK.
!>          Si UPLO = 'U':
!>             Solo los últimos KB elementos de IPIV se establecen.
!>
!>             Si IPIV(k) > 0, entonces las filas y columnas k y IPIV(k) fueron
!>             intercambiadas y D(k,k) es un bloque diagonal de 1x1.
!>
!>             Si IPIV(k) < 0 y IPIV(k-1) < 0, entonces las filas y
!>             columnas k y -IPIV(k) fueron intercambiadas y las filas y
!>             columnas k-1 y -IPIV(k-1) fueron intercambiadas,
!>             D(k-1:k,k-1:k) es un bloque diagonal de 2x2.
!>
!>          Si UPLO = 'L':
!>             Solo los primeros KB elementos de IPIV se establecen.
!>
!>             Si IPIV(k) > 0, entonces las filas y columnas k y IPIV(k)
!>             fueron intercambiadas y D(k,k) es un bloque diagonal de 1x1.
!>
!>             Si IPIV(k) < 0 y IPIV(k+1) < 0, entonces las filas y
!>             columnas k y -IPIV(k) fueron intercambiadas y las filas y
!>             columnas k+1 y -IPIV(k+1) fueron intercambiadas,
!>             D(k:k+1,k:k+1) es un bloque diagonal de 2x2.
!>

B

!>          B es un array COMPLEX, dimensión (LDB,NRHS)
!>          A la entrada, B contiene NRHS vectores de longitud N.
!>          A la salida, B se sobrescribe con el producto A * B.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B.  LDB >= max(1,N).
!>

INFO

!>          INFO es INTEGER
!>          = 0: salida exitosa
!>          < 0: si INFO = -k, el argumento k tenía un valor ilegal
!>
