ZATHURA(1) zathura ZATHURA(1)

NOMBRE

zathura - un visor de documentos

SINOPSIS

zathura [-e XID] [-c RUTA] [-d RUTA] [-p RUTA] [-w CONTRASEÑA] [-P NÚMERO] [--fork] [-l NIVEL] [-s] [-x COMANDO] [--synctex-forward ENTRADA] [--synctex-pid PID] [-find CADENA] <archivos>

DESCRIPCIÓN

zathura muestra los archivos dados. Si se proporciona un guión simple (-) como nombre de archivo, el contenido se leerá de la entrada estándar. Si no se proporcionan archivos, se lanzará una instancia vacía de zathura.

OPCIONES

-e,--reparent=xid
Se reparenta a la ventana especificada por xid
-c,--config-dir=ruta
Ruta al directorio de configuración
-d,--data-dir=ruta
Ruta al directorio de datos
-p,--plugins-dir=ruta
Ruta al directorio que contiene los plugins
-w,--password=contraseña
La contraseña de los documentos. Si se abren varios documentos a la vez, la contraseña se usará para el primero y zathura pedirá las contraseñas de los archivos restantes si es necesario.
-P,--page=número
Abre el documento en el número de página dado. Las páginas se numeran a partir de 1, y los números negativos indican números de página a partir del final del documento, siendo -1 la última página.
-f,--find=cadena
Abre el documento y busca la cadena dada.
-l,--log-level=nivel
Establece el nivel de registro (debug, info, warning, error)
-x,--synctex-editor-command=comando
Establece el comando del editor de synctex. Anula la configuración de synctex-editor-command.
--synctex-forward=entrada
Salta a la posición dada. El interruptor espera el mismo formato que se especifica para la vista -i de synctex. Si no se está ejecutando ninguna instancia para el documento especificado, se lanzará una nueva instancia (solo si no se especifica --synctex-pid).
--synctex-pid=pid
En lugar de buscar una instancia que tenga abierto el archivo correcto, intenta solo con la instancia con el PID dado. Tenga en cuenta que si el PID dado no tiene el archivo correcto abierto o no existe, no se iniciará ninguna instancia nueva.
--mode=modo
Inicia en un modo no predeterminado
--fork
Se bifurca en segundo plano
--version
Muestra la cadena de versión y sale
--help
Muestra la ayuda y sale

CONFIGURACIÓN

La apariencia y el comportamiento predeterminados de zathura se pueden sobrescribir modificando el archivo zathurarc (ruta predeterminada: ~/.config/zathura/zathurarc). Para una descripción detallada, consulte zathurarc(5).

SOPORTE SYNCTEX

Zathura admite tanto la sincronización hacia adelante como la sincronización inversa de synctex. Para habilitar la sincronización hacia adelante de synctex, consulte las opciones --synctex-forward y --synctex-editor. Zathura también emitirá una señal a través de la interfaz D-Bus. Para admitir la sincronización inversa de synctex, zathura proporciona una interfaz D-Bus que puede ser llamada por el editor. Para mayor comodidad, zathura también sabe cómo analizar la salida del comando synctex view. Es suficiente pasar los argumentos a la opción -i de synctex view a zathura a través de --synctex-forward y zathura pasará la información a la instancia correcta.

Para gvim, el soporte de sincronización hacia adelante e inversa se puede configurar de la siguiente manera: primero, agregue lo siguiente a la configuración de vim:

function! Synctex()
  execute "silent !zathura --synctex-forward " . line('.') . ":" . col('.') . ":" . bufname('%') . " " . g:syncpdf
  redraw!
endfunction
map <C-enter> :call Synctex()<cr>

Luego, inicie zathura con

zathura -x "gvim --servername vim -c \"let g:syncpdf='$1'\" --remote +%{line} %{input}" $file

Algunos editores admiten zathura como visor de serie:

  • LaTeXTools para SublimeText (https://latextools.readthedocs.io/en/latest/available-viewers/#zathura)
  • LaTeX para Atom (https://atom.io/packages/latex)

VARIABLES DE ENTORNO

ZATHURA_PLUGINS_PATH
Ruta al directorio que contiene los plugins. Este directorio solo se considera si no se especificó ningún otro directorio usando --plugins-dir.

SANDBOX

El binario zathura-sandbox ejecuta zathura con un sandbox basado en seccomp y/o landlock habilitado. Algunas funciones se deshabilitan cuando se usa el modo sandbox:

  • guardar/escribir archivos
  • uso de métodos de entrada como ibus
  • impresión
  • marcadores e historial
  • integración dbus
  • soporte synctex

El modo sandbox aún es experimental con algunas implementaciones de libc. Las implementaciones de libc admitidas y probadas actualmente son glibc.

BUGS CONOCIDOS

Si GDK_NATIVE_WINDOWS está habilitado, experimentará problemas con documentos grandes. En este caso, zathura podría fallar o las páginas no se renderizarán correctamente. Deshabilitar GDK_NATIVE_WINDOWS soluciona este problema. El mismo problema puede aparecer si overlay-scrollbar está habilitado en GTK_MODULES.

ZATHURA(1) User Manuals zathura(1)

NOMBRE

zathura - un visor de documentos

SINOPSIS

zathura [options] [file ...]

DESCRIPCIÓN

zathura es un visor de documentos extensible y configurable. Admite el uso de diferentes formatos de archivo mediante plugins. Actualmente soporta PDF, PostScript, DjVu, CHM, ePub, y MOBI.

OPCIONES

-h, --help
Mostrar mensaje de ayuda y salir.
-v, --version
Mostrar información sobre la versión y salir.
-p, --page page
Abrir el documento en la página especificada.
-l, --mode mode
Establecer el modo de visualización (por ejemplo, "normal", "presentation", "inverse").
-s, --stylesheet stylesheet
Cargar una hoja de estilos para la personalización.
-c, --config-dir dir
Establecer el directorio de configuración.

ENLACES DE TECLAS

zathura utiliza enlaces de teclas para la navegación y el control. Los enlaces de teclas predeterminados se pueden encontrar en el archivo de configuración (generalmente en ~/.config/zathura/zathurarc). Algunos enlaces comunes:

  • j: página siguiente
  • k: página anterior
  • gg: primera página
  • G: última página
  • /: buscar texto
  • n: siguiente coincidencia de búsqueda
  • N: coincidencia de búsqueda anterior
  • :w: guardar
  • :q: salir

PLUGINS

zathura utiliza plugins para admitir diferentes formatos de archivo. Los plugins comunes incluyen:

  • zathura-pdf-service: para archivos PDF
  • zathura-djvu-service: para archivos DjVu
  • zathura-ps-service: para archivos PostScript
  • zathura-cb-service: para archivos Comic Book (CBR, CBZ)
  • zathura-ocrad-service: para OCR (Reconocimiento Óptico de Caracteres)

CONFIGURACIÓN

La configuración de zathura se realiza a través del archivo zathurarc. Este archivo se puede encontrar en ~/.config/zathura/zathurarc o en /etc/zathura/zathurarc. Puede personalizar enlaces de teclas, opciones de visualización y más.

EJEMPLO

Para abrir un archivo PDF llamado documento.pdf en la página 5:

zathura --page 5 documento.pdf
