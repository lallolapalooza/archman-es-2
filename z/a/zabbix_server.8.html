ZABBIX_SERVER(8) Manual del Administrador del Sistema ZABBIX_SERVER(8)

NOMBRE

zabbix_server - Demonio del servidor Zabbix

SINOPSIS

zabbix_server [-c archivo-de-configuracion]
zabbix_server [-c archivo-de-configuracion] -R opcion-de-ejecucion
zabbix_server [-c archivo-de-configuracion] -T
zabbix_server -h
zabbix_server -V

DESCRIPCIÓN

zabbix_server es el demonio central del software Zabbix.

OPCIONES

-c, --config archivo-de-configuracion
Utiliza el archivo-de-configuracion alternativo en lugar del predeterminado.
-f, --foreground
Ejecuta el servidor Zabbix en primer plano.
-R, --runtime-control opcion-de-ejecucion
Realiza funciones administrativas de acuerdo con opcion-de-ejecucion.
Opciones de control de ejecución
config_cache_reload
Recarga la caché de configuración. Se ignora si la caché se está cargando actualmente. Se utilizará el archivo de configuración predeterminado (a menos que se especifique la opción -c) para encontrar el archivo PID y se enviará una señal al proceso listado en el archivo PID.
snmp_cache_reload
Recarga la caché SNMP.
housekeeper_execute
Ejecuta el housekeeper. Se ignora si el housekeeper se está ejecutando actualmente.
trigger_housekeeper_execute
Ejecuta el housekeeper de triggers (elimina problemas de triggers eliminados). Se ignora si el housekeeper de triggers se está ejecutando actualmente.
secrets_reload
Recarga los secretos de Vault. Se ignora si la caché de configuración o los secretos se están cargando actualmente.
diaginfo[=sección]
Registra información de diagnóstico interno de la sección especificada. La sección puede ser historycache, preprocessing, alerting, lld, valuecache, locks. Por defecto, se registra información de diagnóstico de todas las secciones.
prof_enable[=objetivo]
Habilita la creación de perfiles, afecta a todos los procesos si no se especifica un objetivo.
prof_disable[=objetivo]
Deshabilita la creación de perfiles, afecta a todos los procesos si no se especifica un objetivo.
ha_status
Muestra el estado del clúster de alta disponibilidad. Solo se puede realizar en el nodo activo.
ha_remove_node
ha_remove_node[=nombre|ID] Elimina un nodo de alta disponibilidad por su nombre o ID listado en ha_status. Solo se puede realizar en el nodo activo.
ha_set_failover_delay[=retraso]
Establece el retraso de conmutación por error de alta disponibilidad. El retraso se puede especificar utilizando sufijos de tiempo. Solo se puede realizar en el nodo activo.
log_level_increase[=objetivo]
Aumenta el nivel de registro, afecta a todos los procesos si no se especifica un objetivo.
log_level_decrease[=objetivo]
Disminuye el nivel de registro, afecta a todos los procesos si no se especifica un objetivo.
Objetivos de control de nivel de registro
tipo-de-proceso
Todos los procesos del tipo especificado (alerter, alert manager, availability manager, browser poller, configuration syncer, configuration syncer worker, connector manager, connector worker, discovery manager, escalator, ha manager, history poller, history syncer, housekeeper, http poller, icmp pinger, internal poller, ipmi manager, ipmi poller, java poller, odbc poller, poller, agent poller, http agent poller, snmp poller, preprocessing manager, proxy group manager, proxy poller, self-monitoring, service manager, snmp trapper, task manager, timer, trapper, unreachable poller, vmware collector)
tipo-de-proceso,N
Tipo y número de proceso (por ejemplo, poller,3)
pid
Identificador del proceso
Objetivos de control de creación de perfiles
tipo-de-proceso
Todos los procesos del tipo especificado (alerter, alert manager, availability manager, configuration syncer, connector manager, connector worker, discovery manager, escalator, ha manager, history poller, history syncer, housekeeper, http poller, icmp pinger, internal poller, ipmi manager, ipmi poller, java poller, odbc poller, poller, agent poller, http agent poller, snmp poller, preprocessing manager, proxy group manager, proxy poller, self-monitoring, service manager, snmp trapper, task manager, timer, trapper, unreachable poller, vmware collector)
tipo-de-proceso,N
Tipo y número de proceso (por ejemplo, history syncer,1)
pid
Identificador del proceso
scope
(rwlock, mutex, processing) se puede usar con tipo-de-proceso (por ejemplo, history syncer,1,processing)
-T, --test-config
Valida el archivo de configuración y sale.
-h, --help
Muestra esta ayuda y sale.
-V, --version
Muestra la información de la versión y sale.

ARCHIVOS

/usr/local/etc/zabbix_server.conf
Ubicación predeterminada del archivo de configuración del servidor Zabbix (si no se modificó durante la compilación).
