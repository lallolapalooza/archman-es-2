NOMBRE

zabbix_agent2 - Agente 2 de Zabbix

SINOPSIS

zabbix_agent2 [-c archivo-config]
zabbix_agent2 [-c archivo-config] [-v] -p
zabbix_agent2 [-c archivo-config] [-v] -t clave-elemento
zabbix_agent2 [-c archivo-config] -R opcion-tiempo-ejecucion
zabbix_agent2 [-c archivo-config] -T
zabbix_agent2 -h
zabbix_agent2 -V

DESCRIPCIÓN

zabbix_agent2 es una aplicación para monitorear parámetros de varios servicios.

OPCIONES

-c, --config archivo-config
Utilice el archivo-config alternativo en lugar del predeterminado.
-R, --runtime-control opcion-tiempo-ejecucion
Realiza funciones administrativas de acuerdo con opcion-tiempo-ejecucion.
Opciones de control en tiempo de ejecución
recargar_parametros_usuario
Recarga los parámetros de usuario desde el archivo de configuración
nivel_registro aumentar
Aumenta el nivel de registro
nivel_registro disminuir
Disminuye el nivel de registro
ayuda
Lista las opciones de control en tiempo de ejecución disponibles
metricas
Lista las métricas disponibles
version
Muestra la versión
-p, --print
Imprime los elementos conocidos y sale. Para cada elemento se utilizan valores predeterminados genéricos o valores predeterminados específicos para pruebas. Estos valores predeterminados se enumeran entre corchetes como parámetros de la clave del elemento. Los valores devueltos se incluyen entre corchetes y van precedidos del tipo del valor devuelto, separados por un carácter de barra vertical. Para los parámetros de usuario, el tipo es siempre t, ya que el agente no puede determinar todos los valores de retorno posibles. Los elementos que se muestran como que funcionan no están garantizados para funcionar desde el servidor Zabbix o zabbix_get al consultar un demonio agente en ejecución, ya que los permisos o el entorno pueden ser diferentes. Los tipos de valor devuelto son:
d
Número con parte decimal.
m
No soportado. Esto podría deberse a la consulta de un elemento que solo funciona en modo activo, como un elemento de monitoreo de registro, o un elemento que requiere múltiples valores recopilados. Los problemas de permisos o los parámetros de usuario incorrectos también podrían dar lugar al estado no soportado.
s
Texto. Longitud máxima ilimitada.
t
Texto. Igual que s.
u
Entero sin signo.
-t, --test clave-elemento
Prueba un único elemento y sale. Consulte --print para obtener la descripción de la salida.
-v, --verbose
Habilita la salida detallada al probar un elemento o imprimir elementos conocidos.
-T, --test-config
Valida el archivo de configuración y sale.
-h, --help
Muestra esta ayuda y sale.
-V, --version
Muestra la información de la versión y sale.

ARCHIVOS

/usr/local/etc/zabbix_agent2.conf
Ubicación predeterminada del archivo de configuración del agente 2 de Zabbix (si no se modificó durante la compilación).
