NOMBRE

zabbix_agentd - demonio del agente Zabbix

SINOPSIS

zabbix_agentd [-c archivo-de-configuración]
zabbix_agentd [-c archivo-de-configuración] -p
zabbix_agentd [-c archivo-de-configuración] -t clave-ítem
zabbix_agentd [-c archivo-de-configuración] -R opción-en-tiempo-de-ejecución
zabbix_agentd [-c archivo-de-configuración] -T
zabbix_agentd -h
zabbix_agentd -V

DESCRIPCIÓN

zabbix_agentd es un demonio para monitorear varios parámetros del servidor.

OPCIONES

-c, --config archivo-de-configuración
Usar el archivo-de-configuración alternativo en lugar del predeterminado.
-f, --foreground
Ejecutar el agente Zabbix en primer plano.
-R, --runtime-control opción-en-tiempo-de-ejecución
Realizar funciones administrativas según opción-en-tiempo-de-ejecución.
Opciones de control en tiempo de ejecución
userparameter_reload
Recargar parámetros de usuario desde el archivo de configuración
log_level_increase[=objetivo]
Incrementar el nivel de registro, afecta a todos los procesos si no se especifica un objetivo
log_level_decrease[=objetivo]
Disminuir el nivel de registro, afecta a todos los procesos si no se especifica un objetivo
Objetivos de control del nivel de registro
tipo-proceso
Todos los procesos del tipo especificado (comprobaciones activas, colector, oyente)
tipo-proceso,N
Tipo de proceso y número (por ejemplo, oyente,3)
pid
Identificador del proceso, hasta 65535. Para valores más grandes, especifique el objetivo como "tipo-proceso,N"
-p, --print
Imprimir los elementos conocidos y salir. Para cada elemento se utilizan los valores predeterminados genéricos, o se proporcionan valores predeterminados específicos para pruebas. Estos valores predeterminados se enumeran entre corchetes como parámetros de clave del elemento. Los valores devueltos se incluyen entre corchetes y van precedidos del tipo de valor devuelto, separados por un carácter de barra vertical. Para los parámetros de usuario, el tipo es siempre t, ya que el agente no puede determinar todos los valores de retorno posibles. Los elementos que se muestran como funcionales no garantizan que funcionen desde el servidor Zabbix o zabbix_get al consultar un demonio agente en ejecución, ya que los permisos o el entorno pueden ser diferentes. Los tipos de valor devueltos son:
d
Número con parte decimal.
m
No soportado. Esto podría deberse a la consulta de un elemento que solo funciona en modo activo, como un elemento de monitorización de registros, o un elemento que requiere múltiples valores recopilados. Los problemas de permisos o los parámetros de usuario incorrectos también podrían dar lugar al estado no soportado.
s
Texto. Longitud máxima ilimitada.
t
Texto. Igual que s.
u
Entero sin signo.
-t, --test clave-ítem
Probar un solo elemento y salir. Consulte --print para ver la descripción de la salida.
-T, --test-config
Validar el archivo de configuración y salir.
-h, --help
Mostrar esta ayuda y salir.
-V, --version
Mostrar información de la versión y salir.

ARCHIVOS

/usr/local/etc/zabbix_agentd.conf
Ubicación predeterminada del archivo de configuración del agente Zabbix (si no se modificó durante la compilación).
