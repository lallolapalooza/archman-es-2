NOMBRE

zathurarc - archivo de configuración de zathura

SINOPSIS

/etc/zathurarc, $XDG_CONFIG_HOME/zathura/zathurarc

DESCRIPCIÓN

El archivo zathurarc es un simple archivo de texto plano que puede ser poblado con varios comandos para cambiar el comportamiento y la apariencia de zathura, los cuales describiremos en las siguientes subsecciones. Cada línea (además de las líneas vacías y los comentarios (que comienzan con un # precedido) se evalúa por sí sola, por lo que no es posible escribir múltiples comandos en una sola línea.

COMANDOS

set - Cambiar opciones

Además del comando incorporado :set, zathura ofrece más opciones para cambiar y hace que esos cambios sean permanentes. Para sobrescribir una opción, solo tienes que añadir una línea estructurada como la siguiente:

set <opción> <nuevo valor>

El campo opción debe ser reemplazado por el nombre de la opción que se desea cambiar y el campo nuevo valor debe ser reemplazado por el nuevo valor que la opción debería obtener. El tipo del valor puede ser uno de los siguientes:

  • INT - Un número entero
  • FLOAT - Un número de punto flotante
  • STRING - Una cadena de caracteres
  • BOOL - Un valor booleano ("true" para verdadero, "false" para falso)

Además, te recomendamos que consultes las opciones para obtener una vista más detallada de las opciones que se pueden cambiar y a qué valores deberían configurarse.

El siguiente ejemplo debería ofrecer una visión más profunda de cómo se puede utilizar el comando set:

set opcion1 5
set opcion2 2.0
set opcion3 hola
set opcion4 hola\ mundo
set opcion5 "hola mundo"

Especialmente para opciones con cadenas como valores, ten en cuenta que es necesario escapar caracteres especiales y espacios en blanco. En el ejemplo anterior, opcion4 y opcion5 se establecen ambas a hola mundo, pero set opcion6 hola mundo solo establecería opcion6 a hola.

Para los colores, zathura admite códigos de color HTML y valores estilo CSS3 rgb(r,g,b) y rgba(r,g,b,a). Si deseas utilizar códigos de color para algunas opciones, asegúrate de citarlos adecuadamente o de escapar el símbolo de almohadilla.

set default-fg "#CCBBCC"
set default-fg \#CCBBCC

Para rgba, ten en cuenta que analiza los componentes de color como enteros entre 0 y 255 y el componente alfa como un flotante entre 0 y 1.

include - Incluir otro archivo de configuración

Este comando permite incluir otros archivos de configuración. Si se proporciona una ruta relativa, la ruta se resolverá en relación con el archivo de configuración que se está procesando actualmente.

include otro-config

map - Mapear un atajo

Es posible mapear o remapear nuevas combinaciones de teclas a funciones de atajo, lo que permite un alto nivel de personalización. El comando :map también se puede utilizar en el archivo zathurarc para hacer permanentes estos cambios:

map [modo] <combinación> <función de atajo> <argumento>
Modo
El comando map espera varios argumentos, de los cuales solo la combinación y el argumento de función de atajo son obligatorios. Dado que zathura utiliza varios modos, es posible mapear combinaciones solo para un modo específico pasando el argumento modo, que puede tomar uno de los siguientes valores:
  • normal (por defecto)
  • fullscreen
  • presentation
  • index

Los corchetes alrededor del valor son obligatorios.

Combinación de tecla única
El segundo argumento (posible) define la combinación de teclas utilizada que debe mapearse a la función de atajo y está estructurado de la siguiente manera. Por un lado, es posible asignarle simplemente letras individuales, números o signos:
map a funcion_atajo argumento_opcional
map b funcion_atajo argumento_opcional
map c funcion_atajo argumento_opcional
map 1 funcion_atajo argumento_opcional
map 2 funcion_atajo argumento_opcional
map 3 funcion_atajo argumento_opcional
map ! funcion_atajo argumento_opcional
map ? funcion_atajo argumento_opcional
Usando modificadores
También es posible usar modificadores como la tecla Control o Alt del teclado. Es posible usar los siguientes modificadores:
  • A - Alt
  • C - Control
  • S - Shift

Si se debe usar alguno de los modificadores para una combinación, es obligatorio definir la combinación con la siguiente estructura:

map <A-a> funcion_atajo
map <C-a> funcion_atajo

Comandos de búfer
Si un mapeo no coincide con ninguna de las definiciones anteriores pero sigue siendo un mapeo válido, se mapeará como un comando de búfer:
map abc salir
map test salir
Funciones de acceso directo
Las siguientes funciones de acceso directo se pueden mapear:
  • abort

    Vuelve al modo normal.

  • adjust_window

    Ajusta el ancho de la página. Los argumentos posibles son best-fit y width.

  • change_mode

    Cambia el modo actual. Pasa el modo deseado como argumento.

  • cycle_first_column

    En el diseño de varias páginas, alterna la columna en la que se muestra la primera página.

  • display_link:

    Muestra el destino del enlace.

  • exec:

    Ejecuta un comando externo. $FILE se expande a la ruta del documento actual, $PAGE al número de página actual y $DBUS al nombre del bus de la interfaz D-Bus.

  • file_chooser:

    Abre un cuadro de diálogo selector de archivos. Utiliza el selector de archivos nativo en Windows y MacOS, los portales de escritorio cuando están disponibles y, de lo contrario, GtkFileChooser.

  • focus_inputbar

    Enfoca la barra de entrada.

  • follow

    Sigue un enlace.

  • goto

    Ve a una página determinada.

  • jumplist

    Avanza/retrocede en la lista de saltos. Pasa forward como argumento para ir a la siguiente entrada y backward para ir a la anterior.

  • navigate

    Navega a la página siguiente/anterior.

  • navigate_index

    Navega por el índice.

  • print

    Muestra el cuadro de diálogo de impresión.

  • quit

    Sale de zathura.

  • recolor

    Recolorea las páginas.

  • reload

    Recarga el documento.

  • rotate

    Gira la página. Pasa rotate-ccw como argumento para la rotación en sentido contrario a las agujas del reloj y rotate-cw para la rotación en sentido horario.

  • scroll

    Desplaza.

  • search

    Busca el elemento siguiente/anterior. Pasa forward como argumento para buscar la siguiente coincidencia y backward para buscar la coincidencia anterior.

  • set

    Establece una opción.

  • snap_to_page

    Se ajusta a la página actual. Equivalente a goto <current_page>

  • toggle_fullscreen

    Activa/desactiva la pantalla completa.

  • toggle_index

    Muestra u oculta el índice.

  • toggle_inputbar

    Muestra u oculta la barra de entrada.

  • toggle_page_mode

    Alterna entre una y varias páginas por fila.

  • toggle_statusbar

    Muestra u oculta la barra de estado.

  • zoom

    Acerca o aleja el zoom.

  • mark_add

    Establece una marca rápida.

  • mark_evaluate

    Ve a una marca rápida.

  • feedkeys

    Simula pulsaciones de teclas. Ten en cuenta que todas las teclas se interpretarán como si se pulsaran en el teclado. Para introducir letras mayúsculas, sigue la misma convención que para las asignaciones de teclas, es decir, para X, usa <S-X>.

unmap - Eliminar un acceso directo

Además de mapear o remapear asignaciones de teclas personalizadas, es posible eliminar las existentes utilizando el comando :unmap. El comando se usa de la siguiente manera (la explicación de los parámetros se describe en la sección map de este documento)

unmap [mode] <binding>
