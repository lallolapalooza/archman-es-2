subrutina zaxpy (integer n, complex*16 za, complex*16, dimension(*) zx, integer incx, complex*16, dimension(*) zy, integer incy)

ZAXPY

Propósito:

!>
!>    ZAXPY una constante multiplicada por un vector más un vector.
!>

Parámetros

N 
!>          N es ENTERO
!>         número de elementos en el/los vector(es) de entrada
!>

ZA

!>          ZA es COMPLEX*16
!>           A la entrada, ZA especifica el escalar alpha.
!>

ZX

!>          ZX es un arreglo COMPLEX*16, dimension ( 1 + ( N - 1 )*abs( INCX ) )
!>

INCX

!>          INCX es ENTERO
!>         espaciado de almacenamiento entre elementos de ZX
!>

ZY

!>          ZY es un arreglo COMPLEX*16, dimension ( 1 + ( N - 1 )*abs( INCY ) )
!>

INCY

!>          INCY es ENTERO
!>         espaciado de almacenamiento entre elementos de ZY
!>
