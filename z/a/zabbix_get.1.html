ZABBIX_GET(1) Manual de Comandos Generales ZABBIX_GET(1)

NOMBRE

zabbix_get - utilidad de Zabbix get

SINOPSIS

zabbix_get -s nombre-host-o-IP [-p número-de-puerto] [-I dirección-IP] [-t tiempo-espera] -k clave-item
zabbix_get -s nombre-host-o-IP [-p número-de-puerto] [-I dirección-IP] [-t tiempo-espera] --tls-connect cert --tls-ca-file archivo-CA [--tls-crl-file archivo-CRL] [--tls-agent-cert-issuer emisor-certificado-agente] [--tls-agent-cert-subject asunto-certificado-agente] --tls-cert-file archivo-certificado --tls-key-file archivo-clave [--tls-cipher13 cadena-cifrado] [--tls-cipher cadena-cifrado] -k clave-item
zabbix_get -s nombre-host-o-IP [-p número-de-puerto] [-I dirección-IP] [-t tiempo-espera] --tls-connect psk --tls-psk-identity identidad-PSK --tls-psk-file archivo-PSK [--tls-cipher13 cadena-cifrado] [--tls-cipher cadena-cifrado] -k clave-item
zabbix_get -h
zabbix_get -V

DESCRIPCIÓN

zabbix_get es una utilidad de línea de comandos para obtener datos del agente Zabbix.

OPCIONES

-s, --host nombre-host-o-IP
Especifica el nombre o la dirección IP de un host.
-p, --port número-de-puerto
Especifica el número de puerto del agente que se ejecuta en el host. El valor predeterminado es 10050.
-I, --source-address dirección-IP
Especifica la dirección IP de origen.
-t, --timeout segundos
Especifica el tiempo de espera. Rango válido: 1-600 segundos (predeterminado: 30).
-k, --key clave-item
Especifica la clave del item para el que se recuperará el valor.
-P, --protocol valor
Protocolo utilizado para comunicarse con el agente. Valores:
auto
conectar usando el protocolo JSON, fallback y reintentar con el protocolo de texto plano (predeterminado)
json
conectar usando el protocolo JSON
plaintext
conectar usando el protocolo de texto plano donde solo se envía la clave del item (versiones 6.4.x y anteriores)
--tls-connect valor
Cómo conectarse al agente. Valores:
unencrypted
conectar sin cifrado (predeterminado)
psk
conectar usando TLS y una clave precompartida
cert
conectar usando TLS y un certificado
--tls-ca-file archivo-CA
Ruta completa de un archivo que contiene los certificados de la CA de nivel superior para la verificación del certificado del par.
--tls-crl-file archivo-CRL
Ruta completa de un archivo que contiene certificados revocados.
--tls-agent-cert-issuer emisor-certificado-agente
Emisor del certificado del agente permitido.
--tls-agent-cert-subject asunto-certificado-agente
Asunto del certificado del agente permitido.
--tls-cert-file archivo-certificado
Ruta completa de un archivo que contiene el certificado o la cadena de certificados.
--tls-key-file archivo-clave
Ruta completa de un archivo que contiene la clave privada.
--tls-psk-identity identidad-PSK
Cadena de identidad PSK.
--tls-psk-file archivo-PSK
Ruta completa de un archivo que contiene la clave precompartida.
--tls-cipher13 cadena-cifrado
Cadena de cifrado para OpenSSL 1.1.1 o superior para TLS 1.3. Anula los criterios de selección de suites de cifrado predeterminados. Esta opción no está disponible si la versión de OpenSSL es inferior a 1.1.1.
--tls-cipher cadena-cifrado
Cadena de prioridad GnuTLS (para TLS 1.2 y superior) o cadena de cifrado OpenSSL (solo para TLS 1.2). Anula los criterios de selección de suites de cifrado predeterminados.
-h, --help
Muestra esta ayuda y sale.
-V, --version
Muestra información de la versión y sale.

ESTADO DE SALIDA

El estado de salida es 0 si zabbix_get recupera correctamente un valor del agente Zabbix. Si la recuperación del valor falló, el estado de salida es 1.

EJEMPLOS

zabbix_get -s 127.0.0.1 -p 10050 -k "system.cpu.load[all,avg1]"
zabbix_get -s 127.0.0.1 -p 10050 -k "system.cpu.load[all,avg1]" --tls-connect cert --tls-ca-file /home/zabbix/zabbix_ca_file --tls-agent-cert-issuer "CN=Signing CA,OU=IT operations,O=Example Corp,DC=example,DC=com" --tls-agent-cert-subject "CN=server1,OU=IT operations,O=Example Corp,DC=example,DC=com" --tls-cert-file /home/zabbix/zabbix_get.crt --tls-key-file /home/zabbix/zabbix_get.key
zabbix_get -s 127.0.0.1 -p 10050 -k "system.cpu.load[all,avg1]" --tls-connect psk --tls-psk-identity "PSK ID Zabbix agentd" --tls-psk-file /home/zabbix/zabbix_agentd.psk
