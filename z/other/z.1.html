Z(1) Comandos de usuario Z(1)

NOMBRE

z - saltar alrededor

SINOPSIS

z [-chlrtx] [regex1 regex2 ... regexn]

DISPONIBILIDAD

bash, zsh

DESCRIPCIÓN

Rastrea tus directorios más utilizados, basándose en 'frecuencia'.

Después de una breve fase de aprendizaje, z te llevará al directorio más 'frecente' que coincida con TODAS las expresiones regulares dadas en la línea de comandos, en orden.

Por ejemplo, z foo bar coincidiría con /foo/bar pero no con /bar/foo.

OPCIONES

-c
restringir las coincidencias a subdirectorios del directorio actual
-e
mostrar la mejor coincidencia, no cambiar de directorio
-h
mostrar un breve mensaje de ayuda
-l
solo listar
-r
coincidir solo por rango
-t
coincidir solo por acceso reciente
-x
eliminar el directorio actual del archivo de datos

EJEMPLOS

z foo
cambiar al directorio más frecente que coincida con foo
z foo bar
cambiar al directorio más frecente que coincida con foo, luego con bar
z -r foo
cambiar al directorio con el rango más alto que coincida con foo
z -t foo
cambiar al directorio accedido más recientemente que coincida con foo
z -l foo
listar todos los directorios que coincidan con foo (por frecencia)

NOTAS

Instalación:

Coloca algo como esto en tu $HOME/.bashrc o $HOME/.zshrc:

. /usr/share/z/z.sh

Navega por los directorios un tiempo para construir la base de datos.

¡BENEFICIATE!

Opcionalmente:

Establece $_Z_CMD para cambiar el nombre del comando (por defecto z).
Establece $_Z_DATA para cambiar el archivo de datos (por defecto $HOME/.z).
Establece $_Z_MAX_SCORE a un valor menor para eliminar entradas más rápido (por defecto 9000).
Establece $_Z_NO_RESOLVE_SYMLINKS para evitar la resolución de enlaces simbólicos.
Establece $_Z_NO_PROMPT_COMMAND para manejar PROMPT_COMMAND/precmd tú mismo.
Establece $_Z_EXCLUDE_DIRS a un array de árboles de directorios a excluir.
Establece $_Z_OWNER para permitir el uso en modo 'sudo -s'.
(Estos ajustes deben ir en .bashrc/.zshrc antes de la línea añadida anteriormente.)
Instala la página de manual proporcionada z.1 en algún lugar de tu MANPATH, como /usr/local/man/man1.

Envejecimiento:

El rango de directorios mantenidos por z sufre un envejecimiento basado en una fórmula simple. El rango de cada entrada se incrementa cada vez que se accede a ella. Cuando la suma de los rangos supera los 9000, todos los rangos se multiplican por 0.99. Las entradas con un rango inferior a 1 se olvidan.

Frecuencia:

Frecuencia es un acrónimo de 'reciente' y 'frecuencia'. Es un rango ponderado que depende de con qué frecuencia y con qué recentidad ocurrió algo. Hasta donde yo sé, Mozilla acuñó el término.

Para z, un directorio que tiene un rango bajo pero ha sido accedido recientemente tendrá rápidamente un rango más alto que un directorio accedido frecuentemente hace mucho tiempo.

La frecuencia se determina en tiempo de ejecución.

Común:

Cuando varios directorios coinciden con todas las consultas, y todos tienen un prefijo común, z cambiará al directorio coincidente más corto, sin tener en cuenta la prioridad. Esto ha estado en vigor, aunque no documentado, durante bastante tiempo, pero probablemente debería ser configurable o reconsiderado.

Completado con Tab:

z soporta el completado con tabulación. Después de cualquier número de argumentos, presiona TAB para completar directorios que coincidan con cada argumento. Debido a las limitaciones de las implementaciones de completado, solo el último argumento se completará en el shell.

Internamente, z decide que has solicitado una compleción si el último argumento pasado es una ruta absoluta a un directorio existente. Esto puede causar un comportamiento inesperado si el último argumento para z comienza con /.

ENTORNO

Se define una función _z().

El contenido de la variable $_Z_CMD se antepone a _z 2>&1. Si no está establecida, $_Z_CMD toma el valor por defecto z.

La variable de entorno $_Z_DATA puede usarse para controlar la ubicación del archivo de datos. Si no está definida, la ubicación toma el valor por defecto $HOME/.z.

La variable de entorno $_Z_NO_RESOLVE_SYMLINKS puede ser establecida para evitar la resolución de enlaces simbólicos. Si no está establecida, los enlaces simbólicos se resolverán al añadirse al archivo de datos.

En bash, z añade un comando a la variable de entorno PROMPT_COMMAND para mantener su base de datos. En zsh, z añade una función _z_precmd al array precmd_functions.

La variable de entorno $_Z_NO_PROMPT_COMMAND puede ser establecida si deseas manejar PROMPT_COMMAND o precmd tú mismo.

La variable de entorno $_Z_EXCLUDE_DIRS puede ser establecida a un array de árboles de directorios a excluir del seguimiento. $HOME siempre está excluido. Los directorios deben ser rutas completas sin barras finales.

La variable de entorno $_Z_OWNER puede ser establecida a tu nombre de usuario, para permitir el uso de z cuando tu entorno sudo mantiene $HOME establecido.

ARCHIVOS

Los datos se almacenan en $HOME/.z. Esto puede ser anulado estableciendo la variable de entorno $_Z_DATA. Al inicializarse, z generará un error si esta ruta es un directorio, y no funcionará correctamente.

Se proporciona una página de manual (z.1).

VER TAMBIÉN

regex(7), pushd, popd, autojump, cdargs
