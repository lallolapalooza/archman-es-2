ZNC(1) Manual de Comandos Generales ZNC(1)

NOMBRE

znc - Un proxy de IRC avanzado

SINOPSIS

znc --help
znc --version
znc --makepass
znc [-n] [-d datadir] [-D] [-f]
znc [-n] [-d datadir] [-D] [-f] --makeconf
znc [-n] [-d datadir] [-D] [-f] --makepem

DESCRIPCIÓN

znc es un proxy de IRC. Se ejecuta como un demonio y se conecta a servidores de IRC, luego te permite conectarte desde una estación de trabajo y trabajar como el usuario que está conectado al servidor de IRC. Después de que te desconectes, mantiene la conexión con el servidor. Actúa como cualquier servidor de IRC normal, por lo que puedes usar cualquier cliente de IRC para conectarte a él.

OPCIONES

-h, --help
Muestra un breve mensaje de ayuda.
-v, --version
Muestra el número de versión completo.
-n, --no-color
No usar secuencias de escape de color.
-f, --foreground
No separar el proceso ZNC en segundo plano.
-D, --debug
Imprimir salida de depuración en la consola. Implica --foreground.
-d DATADIR, --datadir=DATADIR
Especificar otro directorio de datos. Aquí es donde znc guarda todo.
-c, --makeconf
Crear interactivamente una nueva configuración.
-s, --makepass
Generar hash de una contraseña para usarla en znc.conf.
-p, --makepem
Generar znc.pem. Este es el certificado del servidor que znc usa. Lo necesitas para SSL.
-r, --allow-root
No quejarse si ZNC se ejecuta con privilegios de root.

SEÑALES

Esta sección explica cómo znc reacciona a diferentes señales:

SIGINT
Salir de ZNC. Esto es equivalente a /znc shutdown
SIGHUP
Recargar znc.conf. Esto es equivalente a /znc rehash. NO lo hagas muy a menudo, ¡las cosas pueden romperse gravemente!
SIGUSR1
Escribir znc.conf. Esto es equivalente a /znc saveconfig

ARCHIVOS

/usr/local/share/znc/
Datos estáticos de módulos como skins de webadmin
/usr/local/lib/znc/
znc instala sus módulos en este directorio.
/usr/local/include/znc/
Estas son las cabeceras necesarias para compilar módulos propios.
~/.znc
Este es el directorio de datos por defecto. Las siguientes rutas asumen que lo usas. Si lo cambias con --datadir, entonces las siguientes líneas son relativas a ese directorio.
~/.znc/znc.pem
Este es el certificado del servidor que znc usa para escuchar en puertos SSL. Puedes generarlo con --makepem y puedes reemplazarlo con tu propio certificado, si quieres.
~/.znc/modules/
Si compilas tus propios módulos, puedes guardarlos aquí.
~/.znc/configs/znc.conf
Esta es la ruta a znc.conf. Usa --makeconf para una forma fácil de generarlo.
~/.znc/users/NOMBREDEUSUARIO/
Los datos de cada usuario se guardan en este directorio. NOMBREDEUSUARIO se refiere al nombre de usuario de ese usuario.
~/.znc/users/NOMBREDEUSUARIO/moddata/NOMBREDEMODULO/
Aquí es donde cada módulo puede guardar algunas cosas. Se usa principalmente para recordar configuraciones de módulos que no forman parte de znc.conf.
~/.znc/moddata/NOMBREDEMODULO/
Aquí es donde los módulos globales pueden guardar sus configuraciones.
