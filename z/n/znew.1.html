ZNEW(1) Manual de comandos generales ZNEW(1)

NOMBRE

znew - Recomprime archivos .Z a archivos .gz

SINOPSIS

znew [ -ftv9PK] [ nombre.Z ... ]

DESCRIPCIÓN

El comando Znew Recomprime archivos del formato .Z (compress) al formato .gz (gzip). Si desea Recomprimir un archivo que ya está en formato gzip, renombre el archivo para forzar una extensión .Z y luego aplique znew.

OPCIONES

-f
Forzar Recompresión de formato .Z a .gz incluso si ya existe un archivo .gz.
-t
Prueba los nuevos archivos antes de eliminar los originales.
-v
Verborrea. Muestra el nombre y el porcentaje de reducción para cada archivo comprimido.
-9
Usar el método de compresión más lento (compresión óptima).
-P
Usar tuberías para la conversión para reducir el uso de espacio en disco.
-K
Mantener un archivo .Z cuando sea más pequeño que el archivo .gz; implica -t.

VER TAMBIÉN

gzip(1), zmore(1), zdiff(1), zgrep(1), zforce(1), gzexe(1), compress(1)

ERRORES

Si se usa la opción -P, znew no mantiene la marca de tiempo si touch(1) no soporta la opción -r, y no mantiene los permisos si chmod(1) no soporta la opción --reference.
