NOMBRE

zoxide-add - añade un nuevo directorio o incrementa su rango

SINOPSIS

zoxide add [RUTAS]

DESCRIPCIÓN

Si el directorio no se encuentra ya en la base de datos, este comando crea una nueva entrada para él con una puntuación predeterminada de 1; de lo contrario, incrementa la puntuación existente en 1. Luego, establece el campo de última actualización de la entrada a la hora actual. Después de esto, ejecuta el algoritmo de **ENVEJECIMIENTO** en la base de datos. Véase zoxide(1) para más información sobre el algoritmo.

Si deseas evitar que un directorio se añada a la base de datos, consulta la variable de entorno **_ZO_EXCLUDE_DIRS** en zoxide(1).

OPCIONES

-h, --help
Imprime información de ayuda.
