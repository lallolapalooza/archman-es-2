NOMBRE

zoxide-import - importar datos de otras herramientas

SINOPSIS

zoxide import RUTA --from FORMATO [OPCIONES]

OPCIONES

--from FORMATO
El formato de la base de datos que se está importando:
autojump
z (para fasd, z, z.lua o zsh-z)

Nota: zoxide solo importa rutas de autojump, ya que su algoritmo de coincidencia es demasiado diferente para importar las puntuaciones.

-h, --help
Imprimir información de ayuda.
--merge
Por defecto, la importación falla si la base de datos actual no está ya vacía. Esta opción fusiona los datos importados en la base de datos existente.
