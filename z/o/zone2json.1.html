ZONE2JSON(1) Servidor Autoritativo de PowerDNS ZONE2JSON(1)

NOMBRE

zone2json - convertir zonas BIND a JSON

SINOPSIS

zone2json {--named-conf=RUTA, --zone-file=RUTA [--zone-name=NOMBRE]} [OPCIÓN]

DESCRIPCIÓN

zone2json analiza archivos de configuración de named.conf y archivos de zona de BIND y genera JSON en la salida estándar, que luego puede ser alimentado a la API de PowerDNS.

zone2json entiende la extensión de archivo maestro de BIND $GENERATE y también respetará $ORIGIN y $TTL.

OPCIONES

OPCIONES DE ENTRADA

--named-conf=<RUTA>
Lee RUTA para obtener la configuración de BIND
--zone=<RUTA>
Analiza solo el archivo de zona en RUTA. Entra en conflicto con el parámetro --named-conf.
--zone-name=<NOMBRE>
Al analizar una única zona sin una declaración $ORIGIN, establece ZONA como el nombre de la zona.

OTRAS OPCIONES

--help
Lista todas las opciones
--on-error-resume-next
Ignora los archivos de zona faltantes durante el análisis. Peligroso.
--verbose
Sé verboso durante la conversión.
