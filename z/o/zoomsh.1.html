NOMBRE

zoomsh - Shell ZOOM

SINOPSIS

zoomsh [-a archivo_apdu] [-e] [-v nivel_log] [comandos...]

DESCRIPCIÓN

zoomsh es un cliente ZOOM con una interfaz de línea de comandos simple. El cliente demuestra la API ZOOM y es útil para probar objetivos.

Puede pasar uno o más comandos a zoomsh. Estos comandos se invocan primero.

OPCIONES

-a archivo_apdu

Registra los paquetes de protocolo en archivo_apdu (registro APDU).

-e

Hace que zoomsh deje de procesar comandos tan pronto como ocurra un error. El código de salida de zoomsh es 1 si ocurre un error; 0 en caso contrario.

-v nivel_log

Establece el nivel de registro de YAZ a nivel_log.

EJEMPLOS

Si inicia yaz-ztest en una consola, puede usar el shell ZOOM de la siguiente manera:

$ zoomsh
ZOOM>connect localhost:9999
ZOOM>search computer
localhost:9999: 7 hits
ZOOM>show 0 1
1 Default USmarc
001    11224466
003 DLC
005 00000000000000.0
008 910710c19910701nju           00010 eng
010    $a    11224466
040    $a DLC $c DLC
050 00 $a 123-xyz
100 10 $a Jack Collins
245 10 $a How to program a computer
260 1  $a Penguin
263    $a 8710
300    $a p. cm.
ZOOM>quit

También puede lograr el mismo resultado pasando los comandos como argumentos en una sola línea de comandos:

$ zoomsh "connect localhost:9999" "search computer" "show 0 1" quit

COMANDOS

connect zurl

Conecta con el objetivo dado por zurl.

close [zurl]

Cierra la conexión con el objetivo dado por zurl o todos los objetivos si se omitió zurl.

show [inicio [conteo]]

Muestra conteo de registros comenzando en el desplazamiento dado por inicio. El primer registro tiene desplazamiento 0 (a diferencia del protocolo Z39.50).

quit

Sale de zoomsh.

set nombre [valor]

Establece la opción nombre a valor.

get nombre

Imprime el valor de la opción nombre.

help

Imprime la lista de comandos disponibles.
