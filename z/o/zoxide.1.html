NOMBRE

zoxide - un comando cd más inteligente

SINOPSIS

zoxide SUBCOMANDO [OPCIONES]

DESCRIPCIÓN

zoxide es un comando cd más inteligente para tu terminal. Realiza un seguimiento de los directorios que usas con más frecuencia y utiliza un algoritmo de clasificación para navegar a la mejor coincidencia.

USO

z foo              # cd al directorio de mayor rango que coincida con foo
z foo bar          # cd al directorio de mayor rango que coincida con foo y bar
z foo /            # cd a un subdirectorio que comience con foo

z ~/foo            # z también funciona como un comando cd normal
z foo/             # cd a una ruta relativa
z ..               # cd un nivel hacia arriba
z -                # cd al directorio anterior

zi foo             # cd con selección interactiva (usando fzf)

z foo<ESPACIO><TAB>  # muestra completaciones interactivas (solo bash 4.4+/fish/zsh)

SUBCOMANDOS

zoxide-add(1)
Añade un nuevo directorio a la base de datos, o incrementa su rango.
zoxide-import(1)
Importa entradas de otra aplicación.
zoxide-init(1)
Genera la configuración del shell.
zoxide-query(1)
Busca un directorio en la base de datos.
zoxide-remove(1)
Elimina un directorio de la base de datos.

OPCIONES

-h, --help
Imprime información de ayuda.
-V, --version
Imprime información de la versión.

VARIABLES DE ENTORNO

Se pueden usar variables de entorno para la configuración. Deben establecerse antes de llamar a zoxide-init(1).

_ZO_DATA_DIR
Especifica el directorio en el que se almacena la base de datos. El valor por defecto varía según el sistema operativo:
SO Ruta
Linux/BSD $XDG_DATA_HOME o $HOME/.local/share, ej. /home/alice/.local/share
macOS $HOME/Library/Application Support, ej. /Users/Alice/Library/Application Support
Windows %LOCALAPPDATA%, ej. C:\Users\Alice\AppData\Local
_ZO_ECHO
Cuando se establece en 1, z imprimirá el directorio coincidente antes de navegar a él.
_ZO_EXCLUDE_DIRS
Evita que los directorios especificados se añadan a la base de datos. Esto se proporciona como una lista de patrones (globs), separados por caracteres específicos del sistema operativo:
SO Separador
Linux/macOS/BSD :, ej. $HOME:$HOME/private/*
Windows ;, ej. $HOME;$HOME/private/*

Por defecto, esto se establece en $HOME. Después de configurar esto, es posible que necesites usar zoxide-remove(1) para eliminar cualquier entrada existente de la base de datos.

_ZO_FZF_OPTS
Opciones personalizadas para pasar a fzf(1) durante la selección interactiva. Consulta la página del manual para ver la lista completa de opciones.
_ZO_MAXAGE
Configura el algoritmo de envejecimiento, que limita el número máximo de entradas en la base de datos. Por defecto, esto se establece en 10000.
_ZO_RESOLVE_SYMLINKS
Cuando se establece en 1, z resolverá los enlaces simbólicos antes de añadir directorios a la base de datos.

ALGORITMO

ENVEJECIMIENTO
zoxide utiliza un parámetro llamado _ZO_MAXAGE para limitar el número de entradas en la base de datos en función de los patrones de uso. Si la FRECUENCIA total de los directorios en la base de datos supera este valor, dividimos la puntuación de cada directorio por un factor k, de modo que el nuevo total sea ~90% de _ZO_MAXAGE. A partir de entonces, si la nueva puntuación de algún directorio cae por debajo de 1, se elimina de la base de datos.

Teóricamente, el número máximo de directorios en la base de datos es 4 * _ZO_MAXAGE, aunque en la práctica es menor.

FRECUENCIA
A cada directorio en zoxide se le da una puntuación, comenzando con 1 la primera vez que se accede a él. Cada acceso subsiguiente aumenta la puntuación en 1. Cuando se realiza una consulta, calculamos la frecuencia basándonos en la última vez que se accedió al directorio:
Hora del último acceso Frecuencia
Dentro de la última hora puntuación * 4
Dentro del último día puntuación * 2
Dentro de la última semana puntuación / 2
De lo contrario puntuación / 4
