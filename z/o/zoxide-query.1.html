NOMBRE

zoxide-query - buscar un directorio en la base de datos

SINOPSIS

zoxide query [PALABRAS_CLAVE] [OPCIONES]

DESCRIPCIÓN

Consulta la base de datos para ver las rutas que coinciden con las palabras clave. El algoritmo de **COINCIDENCIA** exacto se describe en zoxide(1).

OPCIONES

--all
Mostrar directorios eliminados.
--exclude RUTA
Excluir una ruta de los resultados de la consulta.
-h, --help
Imprimir información de ayuda.
-i, --interactive
Usar selección interactiva. Esta opción requiere fzf(1).
-l, --list
Listar todos los resultados, en lugar de solo el de mayor frecuencia.
-s, --score
Imprimir la puntuación calculada además de la ruta coincidente.
