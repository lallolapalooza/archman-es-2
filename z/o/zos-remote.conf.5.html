NOMBRE

zos-remote.conf - archivo de configuración del plugin audisp-racf

DESCRIPCIÓN

zos-remote.conf controla la configuración del plugin del disparador de auditoría audispd-zos-remote(8). La ubicación predeterminada para este archivo es /etc/audit/zos-remote.conf, sin embargo, se puede especificar un archivo diferente como primer argumento al plugin audispd-zos-remote. Ver audispd-zos-remote(8) y auditd(8). Las opciones disponibles son las siguientes:

servidor
Este es el nombre de host o dirección IP del servidor IBM z/OS ITDS.
puerto
El número de puerto donde se está ejecutando ITDS en el servidor z/OS. El valor predeterminado es 389 (puerto ldap).
usuario
El ID de usuario de z/OS RACF que el plugin audispd-zos-remote utilizará para realizar solicitudes de auditoría remota. Este usuario necesita acceso de LECTURA al recurso de la clase FACILITY IRR.LDAP.REMOTE.AUDIT (ver audispd-zos-remote(8)).
contraseña
La contraseña asociada con el ID de usuario de z/OS configurado anteriormente.
tiempo-espera
El número de segundos que el plugin audispd-zos-remote esperará antes de renunciar a los intentos de conexión y envíos de eventos. El valor predeterminado es 15.
q_profundidad
El plugin audispd-zos-remote pondrá en cola los eventos de entrada hasta un máximo de q_profundidad eventos mientras intenta enviarlos remotamente. Esto puede manejar ráfagas de eventos o en caso de una conexión de red lenta. Sin embargo, el plugin audispd-zos-remote descartará eventos en caso de que la cola esté llena. La profundidad de cola predeterminada es 64. Aumente este valor si está experimentando descartes de eventos debido a una cola llena (audispd-zos-remote lo registrará en syslog).
