NOMBRE

zgrep - busca expresiones regulares en archivos posiblemente comprimidos

SINOPSIS

zgrep [ opciones_de_grep ] [ -e ] patrón nombre_archivo...

DESCRIPCIÓN

El comando zgrep invoca a grep en archivos comprimidos o gzipeados. Todas las opciones especificadas se pasan directamente a grep. Si no se especifica ningún archivo, la entrada estándar se descomprime si es necesario y se alimenta a grep. De lo contrario, los archivos dados se descomprimen si es necesario y se alimentan a grep.

Si la variable de entorno GREP está configurada, zgrep la utiliza como el programa grep a invocar.

ESTADO DE SALIDA

El estado de salida es 0 si hay coincidencia, 1 si no hay coincidencias, y 2 si hay problemas.

ERRORES

Las siguientes opciones de grep no son compatibles: --dereference-recursive (-R), --directories (-d), --exclude, --exclude-from, --exclude-dir, --include, --null (-Z), --null-data (-z) y --recursive (-r).
