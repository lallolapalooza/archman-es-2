ZGGESX calcula los valores propios, la forma de Schur y, opcionalmente, la matriz de vectores de Schur para matrices GE

Propósito:

!>
!> ZGGESX calcula para un par de matrices complejas no simétricas de N-por-N
!> (A,B), los valores propios generalizados, la forma de Schur compleja (S,T),
!> y, opcionalmente, las matrices izquierda y/o derecha de vectores de Schur (VSL
!> y VSR). Esto da la factorización de Schur generalizada
!>
!>      (A,B) = ( (VSL) S (VSR)**H, (VSL) T (VSR)**H )
!>
!> donde (VSR)**H es la transpuesta conjugada de VSR.
!>
!> Opcionalmente, también ordena los valores propios para que un clúster seleccionado
!> de valores propios aparezca en los bloques diagonales principales de la matriz
!> triangular superior S y la matriz triangular superior T; calcula
!> un número de condición recíproco para el promedio de los valores propios
!> seleccionados (RCONDE); y calcula un número de condición recíproco para
!> los subespacios deflacionantes derecho e izquierdo correspondientes a los valores
!> propios seleccionados (RCONDV). Las columnas principales de VSL y VSR forman
!> entonces una base ortonormal para los correspondientes autoespacios (subespacios
!> deflacionantes) izquierdos y derechos.
!>
!> Un valor propio generalizado para un par de matrices (A,B) es un escalar w
!> o una razón alpha/beta = w, tal que A - w*B es singular. Se representa
!> usualmente como el par (alpha,beta), ya que hay una interpretación razonable
!> para beta=0 o para ambos siendo cero.
!>
!> Un par de matrices (S,T) está en forma de Schur compleja generalizada si T es
!> triangular superior con diagonal no negativa y S es triangular superior.
!>

Parámetros

JOBVSL 
!>          JOBVSL es CHARACTER*1
!>          = 'N':  no calcular los vectores de Schur izquierdos;
!>          = 'V':  calcular los vectores de Schur izquierdos.
!>

JOBVSR

!>          JOBVSR es CHARACTER*1
!>          = 'N':  no calcular los vectores de Schur derechos;
!>          = 'V':  calcular los vectores de Schur derechos.
!>

SORT

!>          SORT es CHARACTER*1
!>          Especifica si los valores propios se ordenan o no en la
!>          diagonal de la forma de Schur generalizada.
!>          = 'N':  Los valores propios no se ordenan;
!>          = 'S':  Los valores propios se ordenan (ver SELCTG).
!>

SELCTG

!>          SELCTG es una FUNCIÓN LOGICAL de dos argumentos COMPLEX*16
!>          SELCTG debe declararse EXTERNAL en la subrutina llamante.
!>          Si SORT = 'N', SELCTG no se referencia.
!>          Si SORT = 'S', SELCTG se usa para seleccionar valores propios para ordenar
!>          en la parte superior izquierda de la forma de Schur.
!>          Tenga en cuenta que un valor propio complejo seleccionado puede ya no satisfacer
!>          SELCTG(ALPHA(j),BETA(j)) = .TRUE. después de ordenar, ya que
!>          el ordenamiento puede cambiar el valor de los valores propios complejos
!>          (especialmente si el valor propio está mal condicionado), en cuyo
!>          caso INFO se establece en N+3 ver INFO abajo).
!>

SENSE

!>          SENSE es CHARACTER*1
!>          Determina qué números de condición recíprocos se calculan.
!>          = 'N': No se calcula ninguno;
!>          = 'E': Se calcula solo para el promedio de los valores propios seleccionados;
!>          = 'V': Se calcula solo para los subespacios deflacionantes seleccionados;
!>          = 'B': Se calcula para ambos.
!>          Si SENSE = 'E', 'V', o 'B', SORT debe ser igual a 'S'.
!>

N

!>          N es INTEGER
!>          El orden de las matrices A, B, VSL y VSR. N >= 0.
!>

A

!>          A es un array COMPLEX*16, dimensión (LDA, N)
!>          En la entrada, la primera de las matrices del par.
!>          En la salida, A ha sido sobrescrita por su forma de Schur
!>          generalizada S.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal de A. LDA >= max(1,N).
!>

B

!>          B es un array COMPLEX*16, dimensión (LDB, N)
!>          En la entrada, la segunda de las matrices del par.
!>          En la salida, B ha sido sobrescrita por su forma de Schur
!>          generalizada T.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal de B. LDB >= max(1,N).
!>

SDIM

!>          SDIM es INTEGER
!>          Si SORT = 'N', SDIM = 0.
!>          Si SORT = 'S', SDIM = número de valores propios (después de ordenar)
!>          para los cuales SELCTG es verdadero.
!>

ALPHA

!>          ALPHA es un array COMPLEX*16, dimensión (N)
!>

BETA

!>          BETA es un array COMPLEX*16, dimensión (N)
!>          En la salida, ALPHA(j)/BETA(j), j=1,...,N, serán los
!>          valores propios generalizados. ALPHA(j) y BETA(j), j=1,...,N son
!>          las diagonales de la forma de Schur compleja (S,T). BETA(j) será
!>          un número real no negativo.
!>
!>          Nota: los cocientes ALPHA(j)/BETA(j) pueden fácilmente
!>          sobrefluctuar o subfluctuar, y BETA(j) puede incluso ser cero.
!>          Por lo tanto, el usuario debe evitar calcular ingenuamente el cociente alpha/beta.
!>          Sin embargo, ALPHA será siempre menor y generalmente
!>          comparable con norm(A) en magnitud, y BETA siempre menor
!>          y generalmente comparable con norm(B).
!>

VSL

!>          VSL es un array COMPLEX*16, dimensión (LDVSL,N)
!>          Si JOBVSL = 'V', VSL contendrá los vectores de Schur izquierdos.
!>          No se referencia si JOBVSL = 'N'.
!>

LDVSL

!>          LDVSL es INTEGER
!>          La dimensión principal de la matriz VSL. LDVSL >=1, y
!>          si JOBVSL = 'V', LDVSL >= N.
!>

VSR

!>          VSR es un array COMPLEX*16, dimensión (LDVSR,N)
!>          Si JOBVSR = 'V', VSR contendrá los vectores de Schur derechos.
!>          No se referencia si JOBVSR = 'N'.
!>

LDVSR

!>          LDVSR es INTEGER
!>          La dimensión principal de la matriz VSR. LDVSR >= 1, y
!>          si JOBVSR = 'V', LDVSR >= N.
!>

RCONDE

!>          RCONDE es un array DOUBLE PRECISION, dimensión ( 2 )
!>          Si SENSE = 'E' o 'B', RCONDE(1) y RCONDE(2) contienen los
!>          números de condición recíprocos para el promedio de los valores propios seleccionados.
!>

RCONDV

!>          RCONDV es un array DOUBLE PRECISION, dimensión ( 2 )
!>          Si SENSE = 'V' o 'B', RCONDV(1) y RCONDV(2) contienen los
!>          números de condición recíprocos para los subespacios deflacionantes
!>          izquierdo y derecho, respectivamente.
!>

WORK

!>          WORK es un array COMPLEX*16, dimensión (LWORK)
!>          En la salida, WORK(1) contiene el tamaño mínimo de LWORK.
!>

LWORK

!>          LWORK es INTEGER
!>          El tamaño del array WORK. LWORK >= max(1,2*N).
!>          Para un cálculo óptimo, LWORK >= max(1, 2*N*N + 2*N).
!>          Si LWORK = -1, entonces solo se calcula el tamaño óptimo de WORK
!>          y se almacena en WORK(1).
!>

RWORK

!>          RWORK es un array DOUBLE PRECISION, dimensión (max(1, 2*N-2))
!>          (Solo se usa si SENSE = 'E' o 'V' o 'B').
!>

IWORK

!>          IWORK es un array INTEGER, dimensión (max(1, 5*N))
!>          (Solo se usa si SORT = 'S').
!>

LIWORK

!>          LIWORK es INTEGER
!>          El tamaño del array IWORK. LIWORK >= max(1, 5*N).
!>

BWORK

!>          BWORK es un array LOGICAL, dimensión (max(1, N))
!>          (Solo se usa si SORT = 'S').
!>          BWORK(j) se usa para seleccionar el j-ésimo valor propio
!>          cuando se llama a SELCTG.
!>
