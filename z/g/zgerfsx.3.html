ZGERFSX

Propósito:

!>
!>    ZGERFSX mejora la solución calculada de un sistema de ecuaciones
!>    lineales y proporciona cotas de error y estimaciones de error hacia
!>    atrás para la solución. Además de la cota de error normwise, el código
!>    proporciona la cota de error componente a componente máxima si es posible.
!>    Consulte los comentarios para ERR_BNDS_NORM y ERR_BNDS_COMP para
!>    obtener detalles de las cotas de error.
!>
!>    El sistema original de ecuaciones lineales puede haber sido
!>    equilibrado antes de llamar a esta rutina, tal como se describe
!>    por los argumentos EQUED, R y C a continuación. En este caso,
!>    la solución y las cotas de error devueltas son para el sistema
!>    original no equilibrado.
!> 
!>     Algunos parámetros opcionales están agrupados en el array PARAMS.
!>     Estas configuraciones determinan cómo se realiza el refinamiento,
!>     pero a menudo los valores predeterminados son aceptables. Si los
!>     predeterminados son aceptables, los usuarios pueden pasar NPARAMS = 0
!>     lo que evita que el código fuente acceda al argumento PARAMS.
!>

Parámetros

TRANS 
!>          TRANS es CHARACTER*1
!>     Especifica la forma del sistema de ecuaciones:
!>       = 'N':  A * X = B     (Sin transposición)
!>       = 'T':  A**T * X = B  (Transpuesta)
!>       = 'C':  A**H * X = B  (Transpuesta conjugada)
!>

EQUED

!>          EQUED es CHARACTER*1
!>     Especifica la forma de equilibrado que se realizó en A
!>     antes de llamar a esta rutina. Esto es necesario para calcular
!>     la solución y las cotas de error correctamente.
!>       = 'N':  Sin equilibrado
!>       = 'R':  Equilibrado de filas, es decir, A ha sido premultiplicado
!>               por diag(R).
!>       = 'C':  Equilibrado de columnas, es decir, A ha sido postmultiplicado
!>               por diag(C).
!>       = 'B':  Equilibrado de filas y columnas, es decir, A ha sido
!>               reemplazado por diag(R) * A * diag(C).
!>               El lado derecho B ha sido modificado en consecuencia.
!>

N

!>          N es INTEGER
!>     El orden de la matriz A.  N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>     El número de lados derechos, es decir, el número de columnas
!>     de las matrices B y X.  NRHS >= 0.
!>

A

!>          A es array COMPLEX*16, dimensión (LDA,N)
!>     La matriz original A de N por N.
!>

LDA

!>          LDA es INTEGER
!>     La dimensión principal del array A.  LDA >= max(1,N).
!>

AF

!>          AF es array COMPLEX*16, dimensión (LDAF,N)
!>     Los factores L y U de la factorización A = P*L*U
!>     tal como se calculó con ZGETRF.
!>

LDAF

!>          LDAF es INTEGER
!>     La dimensión principal del array AF.  LDAF >= max(1,N).
!>

IPIV

!>          IPIV es array INTEGER, dimensión (N)
!>     Los índices de pivote de ZGETRF; para 1<=i<=N, la fila i de la
!>     matriz se intercambió con la fila IPIV(i).
!>

R

!>          R es array DOUBLE PRECISION, dimensión (N)
!>     Los factores de escala de fila para A.  Si EQUED = 'R' o 'B', A se
!>     multiplica a la izquierda por diag(R); si EQUED = 'N' o 'C', R
!>     no se accede.
!>     Si R se accede, cada elemento de R debe ser una potencia de la base
!>     para garantizar una solución y estimaciones de error fiables.
!>     La escala por potencias de la base no causa errores de redondeo
!>     a menos que el resultado sea subdesbordado o desbordado. Los
!>     errores de redondeo durante la escala conducen a un refinamiento
!>     con una matriz que no es equivalente a la matriz de entrada,
!>     produciendo estimaciones de error que pueden no ser fiables.
!>

C

!>          C es array DOUBLE PRECISION, dimensión (N)
!>     Los factores de escala de columna para A.  Si EQUED = 'C' o 'B', A se
!>     multiplica a la derecha por diag(C); si EQUED = 'N' o 'R', C
!>     no se accede.
!>     Si C se accede, cada elemento de C debe ser una potencia de la base
!>     para garantizar una solución y estimaciones de error fiables.
!>     La escala por potencias de la base no causa errores de redondeo
!>     a menos que el resultado sea subdesbordado o desbordado. Los
!>     errores de redondeo durante la escala conducen a un refinamiento
!>     con una matriz que no es equivalente a la matriz de entrada,
!>     produciendo estimaciones de error que pueden no ser fiables.
!>

B

!>          B es array COMPLEX*16, dimensión (LDB,NRHS)
!>     La matriz del lado derecho B.
!>

LDB

!>          LDB es INTEGER
!>     La dimensión principal del array B.  LDB >= max(1,N).
!>

X

!>          X es array COMPLEX*16, dimensión (LDX,NRHS)
!>     En la entrada, la matriz solución X, tal como la calculó ZGETRS.
!>     En la salida, la matriz solución mejorada X.
!>

LDX

!>          LDX es INTEGER
!>     La dimensión principal del array X.  LDX >= max(1,N).
!>

RCOND

!>          RCOND es DOUBLE PRECISION
!>     Condición recíproca escalada. Esta es una estimación del
!>     número de condición de Skeel recíproco de la matriz A después
!>     del equilibrado (si se realizó). Si este valor es menor que la
!>     precisión de la máquina (en particular, si es cero), la matriz es
!>     singular a la precisión de trabajo. Tenga en cuenta que el error
!>     aún puede ser pequeño incluso si este número es muy pequeño y la
!>     matriz parece mal condicionada.
!>

BERR

!>          BERR es array DOUBLE PRECISION, dimensión (NRHS)
!>     Error relativo componente a componente hacia atrás. Este es el
!>     error relativo componente a componente de cada vector solución X(j)
!>     (es decir, el cambio relativo más pequeño en cualquier elemento de A o B
!>     que haga que X(j) sea una solución exacta).
!>

N_ERR_BNDS

!>          N_ERR_BNDS es INTEGER
!>     Número de cotas de error a devolver por cada lado derecho
!>     y cada tipo (normwise o componente a componente). Consulte ERR_BNDS_NORM y
!>     ERR_BNDS_COMP a continuación.
!>

ERR_BNDS_NORM
