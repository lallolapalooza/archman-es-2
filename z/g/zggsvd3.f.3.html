ZGGSVD3 calcula la descomposición en valores singulares (SVD) para OTRAS matrices

Documentación de la Función/Subrutina

subrutina zggsvd3 (character jobu, character jobv, character jobq, integer m, integer n, integer p, integer k, integer l, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( ldb, * ) b, integer ldb, double precision, dimension( * ) alpha, double precision, dimension( * ) beta, complex*16, dimension( ldu, * ) u, integer ldu, complex*16, dimension( ldv, * ) v, integer ldv, complex*16, dimension( ldq, * ) q, integer ldq, complex*16, dimension( * ) work, integer lwork, double precision, dimension( * ) rwork, integer, dimension( * ) iwork, integer info)

ZGGSVD3 calcula la descomposición en valores singulares generalizada (GSVD) de una matriz compleja M por N A y una matriz compleja P por N B:

Propósito:

!>
!> ZGGSVD3 calcula la descomposición en valores singulares generalizada (GSVD)
!> de una matriz compleja M por N A y una matriz compleja P por N B:
!>
!>       U**H*A*Q = D1*( 0 R ),    V**H*B*Q = D2*( 0 R )
!>
!> donde U, V y Q son matrices unitarias.
!> Sea K+L = el rango numérico efectivo de la
!> matriz (A**H,B**H)**H, entonces R es una matriz triangular superior no singular de (K+L)-por-(K+L), D1 y D2 son matrices de M-por-(K+L) y P-por-(K+L) 
!> con las siguientes estructuras, respectivamente:
!>
!> Si M-K-L >= 0,
!>
!>                     K  L
!>        D1 =     K ( I  0 )
!>                 L ( 0  C )
!>             M-K-L ( 0  0 )
!>
!>                   K  L
!>        D2 =   L ( 0  S )
!>             P-L ( 0  0 )
!>
!>                 N-K-L  K    L
!>   ( 0 R ) = K (  0   R11  R12 )
!>             L (  0    0   R22 )
!> donde
!>
!>   C = diag( ALPHA(K+1), ... , ALPHA(K+L) ),
!>   S = diag( BETA(K+1),  ... , BETA(K+L) ),
!>   C**2 + S**2 = I.
!>
!>   R se almacena en A(1:K+L,N-K-L+1:N) al salir.
!>
!> Si M-K-L < 0,
!>
!>                   K M-K K+L-M
!>        D1 =   K ( I  0    0   )
!>             M-K ( 0  C    0   )
!>
!>                     K M-K K+L-M
!>        D2 =   M-K ( 0  S    0  )
!>             K+L-M ( 0  0    I  )
!>               P-L ( 0  0    0  )
!>
!>                    N-K-L  K   M-K  K+L-M
!>   ( 0 R ) =     K ( 0    R11  R12  R13  )
!>               M-K ( 0     0   R22  R23  )
!>             K+L-M ( 0     0    0   R33  )
!>
!> donde
!>
!>   C = diag( ALPHA(K+1), ... , ALPHA(M) ),
!>   S = diag( BETA(K+1),  ... , BETA(M) ),
!>   C**2 + S**2 = I.
!>
!>   (R11 R12 R13 ) se almacena en A(1:M, N-K-L+1:N), y R33 se almacena
!!>   ( 0  R22 R23 )
!>   en B(M-K+1:L,N+M-K-L+1:N) al salir.
!>
!> La rutina calcula C, S, R y opcionalmente las matrices de transformación
!> unitarias U, V y Q.
!>
!> En particular, si B es una matriz no singular N-por-N, entonces la GSVD de
!> A y B da implícitamente la SVD de A*inv(B):
!>                      A*inv(B) = U*(D1*inv(D2))*V**H.
!> Si ( A**H,B**H)**H tiene columnas ortonormales, entonces la GSVD de A y B es también
!> igual a la descomposición CS de A y B. Además, la GSVD puede
!> ser usada para derivar la solución del problema de valores propios:
!>                      A**H*A x = lambda* B**H*B x.
!> En alguna literatura, la GSVD de A y B se presenta en la forma
!>                  U**H*A*X = ( 0 D1 ),   V**H*B*X = ( 0 D2 )
!> donde U y V son ortogonales y X es no singular, y D1 y D2 son
!> ``diagonales''. La forma de GSVD anterior se puede convertir a la última
!> forma tomando la matriz no singular X como
!>
!>                       X = Q*(  I   0    )
!>                             (  0 inv(R) )
!>

NAME


ZGGSVD3 - ZGGSVD3 computes the generalized Schur decomposition of a
    complex pair of general matrices (A, B)






SYNOPSIS


 subroutine ZGGSVD3( JOBu, JOBv, JOBq, M, N, P, A, LDA, B, LDB, ALPHA, BETA, U, LDU, V, LDV, Q, LDQ, WORK, LWORK, RWORK, IWORK, INFO )

     CHARACTER          JOBu, JOBv, JOBq
     INTEGER            INFO
     INTEGER            LDA, LDB, LDQ, LDU, LDV
     INTEGER            LWORK, M, N, P
     COMPLEX*16         A( LDA, * ), B( LDB, * ), Q( LDQ, * ), U( LDU, * ), V( LDV, * ), WORK( * )
     DOUBLE PRECISION   ALPHA( * ), BETA( * ), RWORK( * )
     INTEGER            IWORK( * )







Function/Subroutine Documentation


ZGGSVD3 computes the generalized Schur decomposition of a complex
    pair of general matrices (A, B)


  A is an M-by-N matrix.
  B is a P-by-N matrix.



The unitary matrices U, V and Q are defined as follows:


  If JOBu is 'U', U is an M-by-M unitary matrix, and the linear unitary
  transformation is applied to the left of A:
     A = U * A' * Q**H
  If JOBu is 'N', U is not computed.

  If JOBv is 'V', V is an N-by-N unitary matrix, and the linear unitary
  transformation is applied to the right of A and B:
     B = V * B' * Q**H
  If JOBv is 'N', V is not computed.

  If JOBq is 'Q', Q is an N-by-N unitary matrix, and the linear unitary
  transformation is applied to the right of B:
     B = V * B' * Q**H
  If JOBq is 'N', Q is not computed.



The generalized Schur decomposition is:


  A = U * S * Q**H
  B = V * T * Q**H



where S and T are generalized upper triangular matrices.


If A is M-by-N and B is P-by-N, then S is M-by-N and T is P-by-N.


It is assumed that M >= N.

    BETA
    

      

    • BETA is DOUBLE PRECISION array, dimension (N)
      • 

    • For i = 1, ..., N, ALPHA(I) and BETA(I) are the diagonal elements of
    the generalized upper triangular matrices S and T respectively.
    Thus, the diagonal elements of the matrix pair (A, B) are scaled by a
    factor of 1/sqrt(ALPHA(I)**2 + BETA(I)**2).
    ALPHA(I) is in the range [0, 1] and BETA(I) is in the range [0, 1], and
    one of them is non-zero.

Internal Parameters:




  TOLA    DOUBLE PRECISION
  TOLB    DOUBLE PRECISION
          TOLA and TOLB are the thresholds to determine the effective
          rank of (A**H,B**H)**H. Generally, they are set to
                   TOLA = MAX(M,N)*norm(A)*MACHEPS,
                   TOLB = MAX(P,N)*norm(B)*MACHEPS.
          The size of TOLA and TOLB may affect the size of backward
          errors of the decomposition.
