ZGEDMD calcula la Descomposición de Modos Dinámicos (DMD) para un par de matrices de instantáneas de datos.

Propósito:

!>    ZGEDMD calcula la Descomposición de Modos Dinámicos (DMD) para
!>    un par de matrices de instantáneas de datos. Para las matrices
!>    de entrada X e Y tales que Y = A*X con una matriz A inaccesible,
!>    ZGEDMD calcula un cierto número de pares de Ritz de A utilizando
!>    la extracción estándar de Rayleigh-Ritz de un subespacio del
!>    rango(X) que se determina utilizando los vectores singulares izquierdos
!>    principales de X. Opcionalmente, ZGEDMD devuelve los residuos
!>    de los pares de Ritz calculados, la información necesaria para
!>    un refinamiento de los vectores de Ritz, o los vectores propios
!>    del DMD Exacto.
!>    Para más detalles ver las referencias listadas abajo. Para más
!>    detalles de la implementación ver [3].
!>

Referencias:

!>        and experimental data,

!>        decompositions: analysis and enhancements,

!>    'S' :: Las matrices de instantáneas de datos X e Y se multiplican
!>           con una matriz diagonal D tal que X*D tenga columnas
!>           no nulas unitarias (en la norma 2 euclidiana)
!>    'C' :: Las instantáneas se escalan como con la opción 'S'.
!>           Si se encuentra que una i-ésima columna de X es un vector
!>           cero y la correspondiente i-ésima columna de Y es
!>           no nula, entonces la i-ésima columna de Y se establece
!>           a cero y se activa una bandera de advertencia.
!>    'Y' :: Las matrices de instantáneas de datos X e Y se multiplican

JOBZ

!>    JOBZ (entrada) CHARACTER*1
!>    Determina si se calcularán los vectores propios (modos de Koopman).

!>           y se devolverán en la matriz Z.
!>           Ver la descripción de Z.
!>    'F' :: Los vectores propios (modos de Koopman) se devolverán
!>           en forma factorizada como el producto X(:,1:K)*W, donde X
!>           contiene una base POD (vectores singulares izquierdos principales
!>           de la matriz de datos X) y W contiene los vectores propios

!>    'N' :: Los vectores propios no se calculan.

JOBR

JOBF

NAME

zgedmd - zgedmd

SYNOPSIS

  SUBROUTINE ZGEDMD( JOBL, JOBR, JOBQ, JOBP,
                                 M, N, NCV, A, LDA,
                                 B, LDB, Q, LDQ, P, LDP,
                                 WORK, LWORK, RWORK, LRWORK,
                                 IWORK, LIWORK, INFO )
    INTEGER           JOBL, JOBR, JOBQ, JOBP, M, N, NCV,
                                 LDA, LDB, LDQ, LDP, LWORK,
                                 LRWORK, LIWORK, INFO
    DOUBLE COMPLEX  A( * ), B( * )
    DOUBLE COMPLEX  Q( * ), P( * )
    DOUBLE COMPLEX  WORK( * )
    DOUBLE PRECISION  RWORK( * )

Function/Subroutine Documentation

  Purpose
  =======
  This routine is deprecated. Use zggev instead.

  ZGEDMD computes the generalized eigenvalue decomposition of a
  real matrix pair (A, B) such that
  A*Z = lambda*B*Z.

  Arguments
  =========

  JOBL    (input) CHARACTER*1
          Specifies whether to compute the left eigenvectors L.
          = 'L':  Left eigenvectors (of A) are computed.
          = 'N':  Left eigenvectors (of A) are not computed.

  JOBR    (input) CHARACTER*1
          Specifies whether to compute the right eigenvectors R.
          = 'R':  Right eigenvectors (of A) are computed.
          = 'N':  Right eigenvectors (of A) are not computed.

  JOBQ    (input) CHARACTER*1
          Specifies whether to compute the left eigenvectors Q.
          = 'L':  Left eigenvectors (of B) are computed.
          = 'N':  Left eigenvectors (of B) are not computed.

  JOBP    (input) CHARACTER*1
          Specifies whether to compute the right eigenvectors P.
          = 'R':  Right eigenvectors (of B) are computed.
          = 'N':  Right eigenvectors (of B) are not computed.

  M       (input) INTEGER
          The number of rows of the matrices A and B. M >= 0.

  N       (input) INTEGER
          The number of columns of the matrices A and B. N >= 0.

  NCV     (input) INTEGER
          The number of trial vector subspaces to be used in the
          implicit subspace iteration. NCV must be at least K+1
          and at most N.

  A       (input/output) DOUBLE PRECISION array, dimension (LDA, N)
          On entry, the M x N matrix A.
          On exit, the upper triangular part of A is overwritten by
          the factorization result, and the remaining entries contain
          information about the Schur structure.

  LDA     (input) INTEGER
          The leading dimension of A. LDA >= max(1, M).

  B       (input/output) DOUBLE PRECISION array, dimension (LDB, N)
          On entry, the M x N matrix B.
          On exit, the upper triangular part of B is overwritten by
          the factorization result, and the remaining entries contain
          information about the Schur structure.

  LDB     (input) INTEGER
          The leading dimension of B. LDB >= max(1, M).

  Q       (output) DOUBLE COMPLEX array, dimension (LDQ, K)
