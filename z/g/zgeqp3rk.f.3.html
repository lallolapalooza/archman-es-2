Documentación de función/subrutina

subrutina zgeqp3rk (integer m, integer n, integer nrhs, integer kmax, double precision abstol, double precision reltol, complex*16, dimension( lda, * ) a, integer lda, integer k, double precision maxc2nrmk, double precision relmaxc2nrmk, integer, dimension( * ) jpiv, complex*16, dimension( * ) tau, complex*16, dimension( * ) work, integer lwork, double precision, dimension( * ) rwork, integer, dimension( * ) iwork, integer info)

ZGEQP3RK calcula una factorización QR truncada de Householder con pivoteo de columnas de una matriz compleja m-por-n A utilizando BLAS de Nivel 3 y sobrescribe la matriz B de m-por-nrhs con Q**H * B.

Propósito:

!>
!> ZGEQP3RK realiza dos tareas simultáneamente:
!>
!> Tarea 1: La rutina calcula una factorización QR truncada (de rango K) o de rango completo
!> con pivoteo de columnas de una matriz compleja
!> M-por-N utilizando BLAS de Nivel 3. K es el número de columnas
!> que fueron factorizadas, es decir, el rango de factorización de la
!> matriz R, K <= min(M,N).
!>
!>  A * P(K) = Q(K) * R(K)  =
!>
!>        = Q(K) * ( R11(K) R12(K) ) = Q(K) * (   R(K)_aprox    )
!>                 ( 0      R22(K) )          ( 0  R(K)_residual ),
!>
!> donde:
!>
!>  P(K)            es una matriz de permutación NxN;
!>  Q(K)            es una matriz unitaria MxM;
!>  R(K)_aprox   = ( R11(K), R12(K) ) es una aproximación de rango K de la
!>                    matriz R de rango completo con R11(K) triangular superior KxK
!>                    y R12(K) rectangular MxN. Las entradas diagonales
!>                    de R11(K) aparecen en orden no creciente
!>                    de valor absoluto, y los valores absolutos de todas ellas
!>                    superan la norma 2 de columna máxima de R22(K)
!>                    hasta el error de redondeo.
!>  R(K)_residual = R22(K) es el residuo de una aproximación de rango K
!>                    de la matriz R de rango completo. Es una matriz
!>                    rectangular (M-K)x(N-K);
!>  0               es una matriz cero (M-K)xK.
!>
!> Tarea 2: Al mismo tiempo, la rutina sobrescribe una matriz compleja
!> M-por-NRHS B con Q(K)**H * B utilizando BLAS de Nivel 3.
!>
!> =====================================================================
!>
!> Las matrices A y B se almacenan en la entrada en el array A como
!> los bloques izquierdo y derecho A(1:M,1:N) y A(1:M, N+1:N+NRHS)
!> respectivamente.
!>
!>                                  N     NRHS
!>             array_A   =   M  [ mat_A, mat_B ]
!>
!> Los criterios de truncamiento (es decir, cuándo detener la factorización)
!> pueden ser cualquiera de los siguientes:
!>
!>   1) El parámetro de entrada KMAX, el número máximo de columnas
!>      KMAX a factorizar, es decir, el rango de factorización está limitado
!>      a KMAX. Si KMAX >= min(M,N), el criterio no se utiliza.
!>
!>   2) El parámetro de entrada ABSTOL, la tolerancia absoluta para
!>      la norma 2 de columna máxima de la matriz residual R22(K). Esto
!>      significa que la factorización se detiene si esta norma es menor o
!>      igual a ABSTOL. Si ABSTOL < 0.0, el criterio no se utiliza.
!>
!>   3) El parámetro de entrada RELTOL, la tolerancia para la norma 2 de
!>      columna máxima de la matriz residual R22(K) dividida
!>      por la norma 2 de columna máxima de la matriz original A, que
!>      es igual a abs(R(1,1)). Esto significa que la factorización se detiene
!>      cuando la relación de la norma 2 de columna máxima de R22(K) a
!>      la norma 2 de columna máxima de A es menor o igual a RELTOL.
!>      Si RELTOL < 0.0, el criterio no se utiliza.
!>
!>   4) En caso de que los criterios de parada ABSTOL o RELTOL no se utilicen,
!>      y cuando la matriz residual R22(K) sea una matriz cero en algún
!>      paso de factorización K. (Este criterio de parada es implícito.)
!>
!>  El algoritmo se detiene cuando se satisface cualquiera de estas condiciones,
!>  de lo contrario, se factoriza toda la matriz A.
!>
!>  Para factorizar toda la matriz A, utilice los valores
!>  KMAX >= min(M,N), ABSTOL < 0.0 y RELTOL < 0.0.
!>
!>  La rutina devuelve:
!>     a) Q(K), R(K)_aprox = ( R11(K), R12(K) ),
!>        R(K)_residual = R22(K), P(K), es decir, las matrices resultantes
!>        de la factorización; P(K) está representada por JPIV,
!>        ( si K = min(M,N), R(K)_aprox es la matriz R completa,
!>        y no hay matriz residual R(K)_residual);
!>     b) K, el número de columnas que fueron factorizadas,
!>        es decir, el rango de factorización;
!>     c) MAXC2NRMK, la norma 2 de columna máxima de la matriz residual
!>        R(K)_residual = R22(K),
!>        ( si K = min(M,N), MAXC2NRMK = 0.0 );
!>     d) RELMAXC2NRMK es igual a MAXC2NRMK dividido por MAXC2NRM, la norma 2 de
!>        columna máxima de la matriz original A, que es igual
!>        a abs(R(1,1)), ( si K = min(M,N), RELMAXC2NRMK = 0.0 );
!>     e) Q(K)**H * B, la matriz B con la transformación unitaria
!>        Q(K)**H aplicada a la izquierda.
!>
!> La matriz de permutación NxN P(K) se almacena en forma compacta en
!> el array entero JPIV. Para 1 <= j <= N, la columna j
!> de la matriz A se intercambió con la columna JPIV(j).
!>
!> La matriz unitaria MxM Q se representa como un producto
!> de reflectores de Householder elementales
!>
!>     Q(K) = H(1) *  H(2) * . . . * H(K),
!>
!> donde K es el número de columnas que fueron factorizadas.
!>
!> Cada H(j) tiene la forma
!>
!>     H(j) = I - tau * v * v**H,
!>
!> donde 1 <= j <= K y
!>   I    es una matriz identidad MxM,
!>   tau  es un escalar complejo,
!>   v    es un vector complejo con v(1:j-1) = 0 y v(j) = 1.
!>
!> v(j+1:M) se almacena a la salida en A(j+1:M,j) y tau en TAU(j).
!>
!> Consulte la sección Detalles adicionales para obtener más información.
!>

Parámetros

M 
!>          M es INTEGER
!>          El número de filas de la matriz A. M >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz A. N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de lados derechos, es decir, el número de
!>          columnas de la matriz B. NRHS >= 0.
!>

KMAX

!>          KMAX es INTEGER
!>
!>          El primer criterio de parada de la factorización. KMAX >= 0.
!>
!>          El número máximo de columnas de la matriz A a factorizar,
!>          es decir, el rango máximo de factorización.
!>
!>          a) Si KMAX >= min(M,N), entonces este criterio de parada
!>                no se utiliza, la rutina factoriza columnas
!>                dependiendo de ABSTOL y RELTOL.
!>
!>          b) Si KMAX = 0, entonces este criterio de parada se
!>                satisface en la entrada y la rutina sale inmediatamente.
!>                Esto significa que la factorización no se realiza,
!>                las matrices A y B no se modifican, y
!>                la matriz A es en sí misma el residuo.
!>

ABSTOL

!>          ABSTOL es DOUBLE PRECISION
!>
!>          El segundo criterio de parada de la factorización, no puede ser NaN.
!>
!>          La tolerancia absoluta (umbral de parada) para
!>          la norma 2 de columna máxima de la matriz residual R22(K).
!>          El algoritmo converge (detiene la factorización) cuando
!>          la norma 2 de columna máxima de la matriz residual R22(K)
!>          es menor o igual a ABSTOL. Sea SAFMIN = DLAMCH('S').
!>
!>          a) Si ABSTOL es NaN, entonces no se realiza ningún cálculo
!>                y un mensaje de error (INFO = -5) es emitido
!>                por XERBLA.
!>
!>          b) Si ABSTOL < 0.0, entonces este criterio de parada no se
!>                usa, la rutina factoriza columnas dependiendo
!>                de KMAX y RELTOL.
!>                Esto incluye el caso ABSTOL = -Inf.
!>
!>          c) Si 0.0 <= ABSTOL < 2*SAFMIN, entonces se usa ABSTOL = 2*SAFMIN.
!>                Esto incluye el caso ABSTOL = -0.0.
!>
!>          d) Si 2*SAFMIN <= ABSTOL, entonces se usa el valor de entrada
!>                de ABSTOL.
!>
!>          Sea MAXC2NRM la norma 2 máxima de columna de la
!>          matriz original A completa.
!>          Si ABSTOL elegido anteriormente es >= MAXC2NRM, entonces este
!>          criterio de parada se satisface en la entrada y la rutina sale
!>          inmediatamente después de calcular MAXC2NRM. La rutina
!>          devuelve MAXC2NRM en MAXC2NORMK,
!>          y 1.0 en RELMAXC2NORMK.
!>          Esto incluye el caso ABSTOL = +Inf. Esto significa que la
!>          factorización no se realiza, las matrices A y B no se modifican,
!>          y la matriz A es en sí misma el residuo.
!>

RELTOL

!>          RELTOL es DOUBLE PRECISION
!>
!>          El tercer criterio de parada de la factorización, no puede ser NaN.
!>
!>          La tolerancia (umbral de parada) para la relación
!>          abs(R(K+1,K+1))/abs(R(1,1)) de la norma 2 máxima de columna
!>          de la matriz residual R22(K) a la norma 2 máxima de columna
!>          de la matriz original A. El algoritmo converge (detiene la
!>          factorización) cuando abs(R(K+1,K+1))/abs(R(1,1)) A es menor
!>          o igual a RELTOL. Sea EPS = DLAMCH('E').
!>
!>          a) Si RELTOL es NaN, entonces no se realiza ningún cálculo
!>                y se emite un mensaje de error (INFO = -6)
!>                por XERBLA.
!>
!>          b) Si RELTOL < 0.0, entonces este criterio de parada no se
!>                usa, la rutina factoriza columnas dependiendo
!>                de KMAX y ABSTOL.
!>                Esto incluye el caso RELTOL = -Inf.
!>
!>          c) Si 0.0 <= RELTOL < EPS, entonces se usa RELTOL = EPS.
!>                Esto incluye el caso RELTOL = -0.0.
!>
!>          d) Si EPS <= RELTOL, entonces se usa el valor de entrada de RELTOL.
!>
!>          Sea MAXC2NRM la norma 2 máxima de columna de la
!>          matriz original A completa.
!>          Si RELTOL elegido anteriormente es >= 1.0, entonces este criterio de
!>          parada se satisface en la entrada y la rutina sale
!>          inmediatamente después de calcular MAXC2NRM.
!>          La rutina devuelve MAXC2NRM en MAXC2NORMK,
!>          y 1.0 en RELMAXC2NORMK.
!>          Esto incluye el caso RELTOL = +Inf. Esto significa que la
!>          factorización no se realiza, las matrices A y B no se modifican,
!>          y la matriz A es en sí misma el residuo.
!>
!>          NOTA: Se recomienda que RELTOL satisfaga
!>                min( 10*max(M,N)*EPS, sqrt(EPS) ) <= RELTOL
!>

A

!>          A es una matriz COMPLEX*16, dimensión (LDA,N+NRHS)
!>
!>          En la entrada:
!>
!>          a) La submatriz A(1:M,1:N) contiene la matriz M-por-N A.
!!>          b) La submatriz A(1:M,N+1:N+NRHS) contiene la matriz M-por-NRHS
!>             B.
!>
!>                                  N     NRHS
!>              matriz_A   =   M  [ mat_A, mat_B ]
!>
!>          En la salida:
!>
!>          a) La submatriz A(1:M,1:N) contiene partes de los factores
!>             de la matriz A:
!>
!>            1) Si K = 0, A(1:M,1:N) contiene la matriz original A.
!>            2) Si K > 0, A(1:M,1:N) contiene partes de los
!>               factores:
!>
!>              1. Los elementos debajo de la diagonal de la submatriz
!>                 A(1:M,1:K) junto con TAU(1:K) representan la
!>                 matriz unitaria Q(K) como un producto de K
!>                 reflejos elementales de Householder.
!>
!>              2. Los elementos en y sobre la diagonal de
!>                 la submatriz A(1:K,1:N) contienen la matriz
!>                 upper-trapezoidal K-por-N
!>                 R(K)_aprox = ( R11(K), R12(K) ).
!>                 NOTA: Si K=min(M,N), es decir, factorización de rango completo,
!>                       entonces R_aprox(K) es el factor R completo que
!>                       es upper-trapezoidal. Si, además, M>=N,
!>                       entonces R es upper-triangular.
!>
!>              3. La submatriz A(K+1:M,K+1:N) contiene la matriz
!>                 rectangular (M-K)-por-(N-K) R(K)_residual = R22(K).
!>
!>          b) Si NRHS > 0, la submatriz A(1:M,N+1:N+NRHS) contiene
!>             el producto M-por-NRHS Q(K)**H * B.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal de la matriz A. LDA >= max(1,M).
!>          Esta es la dimensión principal para ambas matrices, A y B.
!>

K

!>          K es INTEGER
!>          Rango de factorización de la matriz A, es decir, el rango de
!>          el factor R, que es el mismo que el número de filas no nulas
!>          del factor R. 0 <= K <= min(M,KMAX,N).
!>
!>          K también representa el número de vectores de Householder no nulos.
!>
!>          NOTA: Si K = 0, a) las matrices A y B no se modifican;
!>                          b) la matriz TAU(1:min(M,N)) se establece en CERO,
!>                             si la matriz A no contiene NaN,
!>                             de lo contrario, los elementos TAU(1:min(M,N))
!>                             no están definidos;
!>                          c) los elementos de la matriz JPIV se establecen
!>                             de la siguiente manera: para j = 1:N, JPIV(j) = j.
!>

MAXC2NRMK

!>          MAXC2NRMK es DOUBLE PRECISION
!>          La norma 2 máxima de columna de la matriz residual R22(K),
!>          cuando la factorización se detuvo en el rango K. MAXC2NRMK >= 0.
!>
!>          a) Si K = 0, es decir, la factorización no se realizó,
!>             la matriz A no se modificó y es en sí misma una matriz residual,
!>             entonces MAXC2NRMK es igual a la norma 2 máxima de columna
!>             de la matriz original A.
!>
!>          b) Si 0 < K < min(M,N), entonces se devuelve MAXC2NRMK.
!>
!>          c) Si K = min(M,N), es decir, se factorizó toda la matriz A
!>             y no hay matriz residual,
!>             entonces MAXC2NRMK = 0.0.
!>
!>          NOTA: MAXC2NRMK en el paso de factorización K sería igual a
!>                R(K+1,K+1) en el siguiente paso de factorización K+1.
!>

RELMAXC2NRMK

!>          RELMAXC2NRMK es DOUBLE PRECISION
!>          La relación MAXC2NRMK / MAXC2NRM de la norma 2 máxima de columna
!>          de la matriz residual R22(K) (cuando la factorización
!>          se detuvo en el rango K) a la norma 2 máxima de columna
!>          de la matriz original A completa. RELMAXC2NRMK >= 0.
!>
!>          a) Si K = 0, es decir, la factorización no se realizó,
!>             la matriz A no se modificó y es en sí misma una matriz residual,
!>             entonces RELMAXC2NRMK = 1.0.
!>
!>          b) Si 0 < K < min(M,N), entonces
!>                se devuelve RELMAXC2NRMK = MAXC2NRMK / MAXC2NRM.
!>
!>          c) Si K = min(M,N), es decir, se factorizó toda la matriz A
!>             y no hay matriz residual,
!>             entonces RELMAXC2NRMK = 0.0.
!>
!>         NOTA: RELMAXC2NRMK en el paso de factorización K sería igual a
!>               abs(R(K+1,K+1))/abs(R(1,1)) en el siguiente paso de
!>               factorización K+1.
!>

JPIV

!>          JPIV es una matriz INTEGER, dimensión (N)
!>          Índices de pivote de columna. Para 1 <= j <= N, la columna j
!>          de la matriz A se intercambió con la columna JPIV(j).
!>
!>          Los elementos de la matriz JPIV(1:N) siempre se establecen
!>          por la rutina, por ejemplo, incluso cuando no se factorizaron columnas,
!>          es decir, cuando K = 0, los elementos se
!>          establecen como JPIV(j) = j para j = 1:N.
!>

TAU

!>          TAU es una matriz COMPLEX*16, dimensión (min(M,N))
!>          Los factores escalares de los reflectores elementales.
!>
!>          Si 0 < K <= min(M,N), solo los elementos TAU(1:K) de
!>          la matriz TAU son modificados por la factorización.
!>          Después de que se calcula la factorización, si no se encontró NaN
!>          durante la factorización, los elementos restantes
!>          TAU(K+1:min(M,N)) se establecen a cero, de lo contrario, los
!>          elementos TAU(K+1:min(M,N)) no se establecen y, por lo tanto,
!>          no están definidos.
!>          ( Si K = 0, todos los elementos de TAU se establecen a cero, si
!>          la matriz A no contiene NaN. )
!>

WORK

!>          WORK es una matriz COMPLEX*16, dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión de la matriz WORK.
!>          LWORK >= 1, si MIN(M,N) = 0, y
!>          LWORK >= N+NRHS-1, de lo contrario.
!>          Para un rendimiento óptimo LWORK >= NB*( N+NRHS+1 ),
!>          donde NB es el tamaño de bloque óptimo para ZGEQP3RK devuelto
!>          por ILAENV. Tamaño de bloque mínimo MINNB=2.
!>
!>          NOTA: La decisión de si usar código BLAS 2 no bloqueado
!>          o código BLAS 3 bloqueado se basa no solo en la dimensión
!>          LWORK del espacio de trabajo disponible WORK, sino también
!>          en la dimensión N de la matriz A a través del punto de cruce NX devuelto
!>          por ILAENV. (Para N menor que NX, se debe usar código no bloqueado.)
!>
!>          Si LWORK = -1, se asume una consulta de espacio de trabajo;
!>          la rutina solo calcula el tamaño óptimo de la matriz WORK,
!>          devuelve este valor como la primera entrada de la matriz WORK,
!>          y XERBLA no emite ningún mensaje de error relacionado con LWORK.
!>

RWORK

!>          RWORK es una matriz DOUBLE PRECISION, dimensión (2*N)
!>

IWORK

!>          IWORK es una matriz INTEGER, dimensión (N-1).
!>          Es una matriz de trabajo. (IWORK se usa para almacenar los índices
!>          de las columnas para la actualización descendente de la norma
!>          en la matriz residual en la subrutina auxiliar bloqueada ZLAQP3RK).
!>

INFO

!>          INFO es INTEGER
!>          1) INFO = 0: salida exitosa.
!>          2) INFO < 0: si INFO = -i, el i-ésimo argumento tenía un
!>                       valor ilegal.
!>          3) Si INFO = j_1, donde 1 <= j_1 <= N, entonces se detectó NaN
!>             y la rutina detiene el cálculo.
!>             La columna j_1 de la matriz A o el elemento j_1
!>             de la matriz TAU contiene la primera ocurrencia
!>             de NaN en el paso de factorización K+1 (cuando K columnas
!>             han sido factorizadas).
!>
!>             En la salida:
!>             K                  se establece en el número de
!>                                   columnas factorizadas sin
!>                                   excepción.
!>             MAXC2NRMK          se establece en NaN.
!>             RELMAXC2NRMK       se establece en NaN.
!>             TAU(K+1:min(M,N))  no se establece y contiene valores indefinidos.
!>

SUBROUTINE ZGEQP3RK( M, N, A, LDA, JPVT, TAU, WORK, LWORK, INFO )
!
! Purpose
! ======
!
! ZGEQP3RK computes the rank-revealing QR factorization of a complex
! M-by-N matrix A with column pivoting using Level 3 BLAS.
!
! The factorization is intended to find a rank-revealing QR factorization,
! i.e. the columns of A are permuted so that the leading columns are
! members of a basis for the range of A, and the remaining columns are
! nearly linearly independent of the basis.
!
! The resulting factorization is of the form:
!
! A * P = Q * R
!
! where P is a permutation matrix, Q is a unitary matrix, and R is
! upper trapezoidal. A is M-by-N and has full rank if M >= N and
! rank(A) = N. The diagonal elements of R are non-negative and are
! increasing in magnitude.
!
! This routine is similar to the LAPACK routine ZGEQP3, except that it
! uses Level 3 BLAS to achieve high performance.
!
! Arguments
! =========
!
! M (input) INTEGER
! The number of rows of the matrix A. M >= 0.
!
! N (input) INTEGER
! The number of columns of the matrix A. N >= 0.
!
! A (input/output) COMPLEX*16 array, dimension (LDA,N)
! On entry, the M-by-N matrix to be factorized.
! On exit, the elements on and above the trapezoid are used to
! contain the elements of R and in the lower trapezoid is used
! to store the elements of upper triangular matrix U, such that
! A = Q*R. The elements below the diagonal of R are not explicitly
! used.
!

! robust and efficient. The choice of threshold for declaring a pivot element
! to be zero is crucial for the rank revealing property and is related to the
! machine precision. The rank is determined by the number of diagonal elements
! of R that are greater than a threshold, which is computed based on the
! machine epsilon and the largest diagonal element of R.
!
! The algorithm overwrites the upper triangle of A with the factors R, and
! the elements below the diagonal of R store the Householder vectors.
!
! On exit, the matrix A is A = Q*R, where Q is unitary and R is upper
! trapezoidal. The matrix Q is not explicitly formed. It is instead
! represented by the elements of R and the array TAU.
!

! The elements of TAU are the scaling factors for the Householder vectors.
!

! that the i-th column of the permuted matrix is the k-th column of the

!
