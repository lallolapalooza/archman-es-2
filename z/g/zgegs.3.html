DOCUMENTACIÓN FUNCIÓN/SUBRUTINA

subroutine zgegs (character jobvsl, character jobvsr, integer n, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( ldb, * ) b, integer ldb, complex*16, dimension( * ) alpha, complex*16, dimension( * ) beta, complex*16, dimension( ldvsl, * ) vsl, integer ldvsl, complex*16, dimension( ldvsr, * ) vsr, integer ldvsr, complex*16, dimension( * ) work, integer lwork, double precision, dimension( * ) rwork, integer info)

ZGEGS calcula los valores propios, la forma de Schur y, opcionalmente, los vectores de Schur izquierdos y/o derechos de un par de matrices complejas (A,B)

Propósito:

!>
!> Esta subrutina está obsoleta y ha sido reemplazada por la subrutina ZGEES.
!>
!> ZGEGS calcula los valores propios, la forma de Schur y, opcionalmente,
!> los vectores de Schur izquierdos y/o derechos de un par de matrices complejas
!> (A,B).
!> Dadas dos matrices cuadradas A y B, la factorización de Schur generalizada
!> tiene la forma
!>
!>    A = Q*S*Z**H,  B = Q*T*Z**H
!>
!> donde Q y Z son matrices unitarias y S y T son triangulares superiores.
!> Las columnas de Q son los vectores de Schur izquierdos
!> y las columnas de Z son los vectores de Schur derechos.
!>
!> Si solo se necesitan los valores propios de (A,B), se debe utilizar la
!> subrutina controladora ZGEGV. Consulte ZGEGV para una descripción de los
!> valores propios del problema de valores propios generalizado no simétrico
!> (GNEP).
!>

Parámetros

JOBVSL 
!>          JOBVSL es CHARACTER*1
!>          = 'N':  no calcular los vectores de Schur izquierdos;
!>          = 'V':  calcular los vectores de Schur izquierdos (devueltos en VSL).
!>

JOBVSR

!>          JOBVSR es CHARACTER*1
!>          = 'N':  no calcular los vectores de Schur derechos;
!>          = 'V':  calcular los vectores de Schur derechos (devueltos en VSR).
!>

N

!>          N es INTEGER
!>          El orden de las matrices A, B, VSL y VSR.  N >= 0.
!>

A

!>          A es array COMPLEX*16, dimension (LDA, N)
!>          En la entrada, la matriz A.
!>          En la salida, la matriz triangular superior S de la factorización de
!>          Schur generalizada.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal de A.  LDA >= max(1,N).
!>

B

!>          B es array COMPLEX*16, dimension (LDB, N)
!>          En la entrada, la matriz B.
!>          En la salida, la matriz triangular superior T de la factorización de
!>          Schur generalizada.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal de B.  LDB >= max(1,N).
!>

ALPHA

!>          ALPHA es array COMPLEX*16, dimension (N)
!>          Los escalares complejos alpha que definen los valores propios de
!>          GNEP.  ALPHA(j) = S(j,j), el elemento diagonal de la forma de
!>          Schur de A.
!>

BETA

!>          BETA es array COMPLEX*16, dimension (N)
!>          Los escalares reales no negativos beta que definen los
!>          valores propios de GNEP.  BETA(j) = T(j,j), el elemento diagonal
!>          del factor triangular T.
!>
!>          Juntos, las cantidades alpha = ALPHA(j) y beta = BETA(j)
!>          representan el j-ésimo valor propio del par de matrices (A,B), en
!>          una de las formas lambda = alpha/beta o mu = beta/alpha.
!>          Dado que lambda o mu pueden desbordarse, no deben,
!>          en general, ser calculados.
!>

VSL

!>          VSL es array COMPLEX*16, dimension (LDVSL,N)
!>          Si JOBVSL = 'V', la matriz de vectores de Schur izquierdos Q.
!>          No referenciado si JOBVSL = 'N'.
!>

LDVSL

!>          LDVSL es INTEGER
!>          La dimensión principal de la matriz VSL. LDVSL >= 1, y
!>          si JOBVSL = 'V', LDVSL >= N.
!>

VSR

!>          VSR es array COMPLEX*16, dimension (LDVSR,N)
!>          Si JOBVSR = 'V', la matriz de vectores de Schur derechos Z.
!>          No referenciado si JOBVSR = 'N'.
!>

LDVSR

!>          LDVSR es INTEGER
!>          La dimensión principal de la matriz VSR. LDVSR >= 1, y
!>          si JOBVSR = 'V', LDVSR >= N.
!>

WORK

!>          WORK es array COMPLEX*16, dimension (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK.  LWORK >= max(1,2*N).
!>          Para un buen rendimiento, LWORK generalmente debe ser mayor.
!>          Para calcular el valor óptimo de LWORK, llame a ILAENV para obtener
!>          los tamaños de bloque (para ZGEQRF, ZUNMQR y CUNGQR). Luego calcule:
!>          NB  -- MAX de los tamaños de bloque para ZGEQRF, ZUNMQR y CUNGQR;
!>          el LWORK óptimo es N*(NB+1).
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo; la
!>          subrutina solo calcula el tamaño óptimo del array WORK, devuelve
!>          este valor como la primera entrada del array WORK, y XERBLA no emite
!>          ningún mensaje de error relacionado con LWORK.
!>

RWORK

!>          RWORK es array DOUBLE PRECISION, dimension (3*N)
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>          =1,...,N:
!>                La iteración QZ falló.  (A,B) no están en forma de Schur,
!!>                pero ALPHA(j) y BETA(j) deben ser correctos para
!>                j=INFO+1,...,N.
!>          > N:  errores que generalmente indican problemas de LAPACK:
!>                =N+1: retorno de error de ZGGBAL
!>                =N+2: retorno de error de ZGEQRF
!>                =N+3: retorno de error de ZUNMQR
!>                =N+4: retorno de error de ZUNGQR
!>                =N+5: retorno de error de ZGGHRD
!>                =N+6: retorno de error de ZHGEQZ (que no sea iteración fallida)
!>                =N+7: retorno de error de ZGGBAK (cálculo de VSL)
!>                =N+8: retorno de error de ZGGBAK (cálculo de VSR)
!>                =N+9: retorno de error de ZLASCL (varios lugares)
!>
