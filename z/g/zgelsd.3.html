DOCUMENTACIÓN DE FUNCIÓN/SUBRUTINA

subrutina zgelsd (entero m, entero n, entero nrhs, complejo*16, dimensión( lda, * ) a, entero lda, complejo*16, dimensión( ldb, * ) b, entero ldb, doble precisión, dimensión( * ) s, doble precisión rcond, entero rank, complejo*16, dimensión( * ) work, entero lwork, doble precisión, dimensión( * ) rwork, entero, dimensión( * ) iwork, entero info)

ZGELSD calcula la solución de norma mínima para un problema de mínimos cuadrados GE

Propósito:

!>
!> ZGELSD calcula la solución de norma mínima para un problema de mínimos cuadrados lineales reales
!>     minimizar la norma 2(| b - A*x |)
!> utilizando la descomposición en valores singulares (SVD) de A. A es una matriz M por N
!> que puede ser de rango deficiente.
!>
!> Se pueden manejar varios vectores del lado derecho b y vectores solución x en
!> una sola llamada; se almacenan como columnas de la
!> matriz B de mano derecha M por NRHS y la matriz solución X de N por NRHS.
!>
!> El problema se resuelve en tres pasos:
!> (1) Reducir la matriz de coeficientes A a forma bidiagonal con
!>     transformaciones de Householder, reduciendo el problema original
!>     a un (BLS)
!> (2) Resolver el BLS usando un enfoque de división y conquista.
!> (3) Aplicar hacia atrás todas las transformaciones de Householder para resolver
!>     el problema de mínimos cuadrados original.
!>
!> El rango efectivo de A se determina tratando como cero aquellos
!> valores singulares que son menores que RCOND multiplicado por el valor singular más grande.
!>
!>

Parámetros

M 
!>          M es ENTERO
!>          El número de filas de la matriz A. M >= 0.
!>

N

!>          N es ENTERO
!>          El número de columnas de la matriz A. N >= 0.
!>

NRHS

!>          NRHS es ENTERO
!>          El número de lados derechos, es decir, el número de columnas
!>          de las matrices B y X. NRHS >= 0.
!>

A

!>          A es una matriz COMPLEX*16, dimensión (LDA,N)
!>          En la entrada, la matriz A de M por N.
!>          En la salida, A ha sido destruida.
!>

LDA

!>          LDA es ENTERO
!>          La dimensión principal del arreglo A. LDA >= max(1,M).
!>

B

!>          B es una matriz COMPLEX*16, dimensión (LDB,NRHS)
!>          En la entrada, la matriz B de mano derecha M por NRHS.
!>          En la salida, B se sobrescribe con la matriz solución X de N por NRHS.
!>          Si m >= n y RANK = n, la suma de cuadrados residual para
!>          la solución en la i-ésima columna se da por la suma de
!>          cuadrados de los módulos de los elementos n+1:m en esa columna.
!>

LDB

!>          LDB es ENTERO
!>          La dimensión principal del arreglo B. LDB >= max(1,M,N).
!>

S

!>          S es un arreglo DOUBLE PRECISION, dimensión (min(M,N))
!>          Los valores singulares de A en orden decreciente.
!>          El número de condición de A en la norma 2 = S(1)/S(min(m,n)).
!>

RCOND

!>          RCOND es DOUBLE PRECISION
!>          RCOND se utiliza para determinar el rango efectivo de A.
!>          Los valores singulares S(i) <= RCOND*S(1) se tratan como cero.
!>          Si RCOND < 0, se utiliza la precisión de máquina en su lugar.
!>

RANK

!>          RANK es ENTERO
!>          El rango efectivo de A, es decir, el número de valores singulares
!>          que son mayores que RCOND*S(1).
!>

WORK

!>          WORK es un arreglo COMPLEX*16, dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es ENTERO
!>          La dimensión del arreglo WORK. LWORK debe ser al menos 1.
!>          La cantidad exacta mínima de espacio de trabajo necesario depende de M,
!>          N y NRHS. Siempre que LWORK sea al menos
!>              2*N + N*NRHS
!>          si M es mayor o igual que N o
!>              2*M + M*NRHS
!>          si M es menor que N, el código se ejecutará correctamente.
!>          Para un buen rendimiento, LWORK debería ser generalmente mayor.
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo del arreglo WORK y
!>          los tamaños mínimos de los arreglos RWORK y IWORK, y devuelve
!>          estos valores como las primeras entradas de los arreglos WORK, RWORK y
!>          IWORK, y XERBLA no emite ningún mensaje de error relacionado con LWORK.
!>

RWORK

!>          RWORK es un arreglo DOUBLE PRECISION, dimensión (MAX(1,LRWORK))
!>          LRWORK >=
!>             10*N + 2*N*SMLSIZ + 8*N*NLVL + 3*SMLSIZ*NRHS +
!>             MAX( (SMLSIZ+1)**2, N*(1+NRHS) + 2*NRHS )
!>          si M es mayor o igual que N o
!>             10*M + 2*M*SMLSIZ + 8*M*NLVL + 3*SMLSIZ*NRHS +
!>             MAX( (SMLSIZ+1)**2, N*(1+NRHS) + 2*NRHS )
!>          si M es menor que N, el código se ejecutará correctamente.
!>          SMLSIZ es devuelto por ILAENV y es igual al tamaño máximo
!>          de los subproblemas en la parte inferior del árbol de computación
!>          (generalmente alrededor de 25), y
!>             NLVL = MAX( 0, INT( LOG_2( MIN( M,N )/(SMLSIZ+1) ) ) + 1 )
!>          En la salida, si INFO = 0, RWORK(1) devuelve el LRWORK mínimo.
!>

IWORK

!>          IWORK es un arreglo INTEGER, dimensión (MAX(1,LIWORK))
!>          LIWORK >= max(1, 3*MINMN*NLVL + 11*MINMN),
!>          donde MINMN = MIN( M,N ).
!>          En la salida, si INFO = 0, IWORK(1) devuelve el LIWORK mínimo.
!>

INFO

!>          INFO es ENTERO
!>          = 0: salida exitosa
!>          < 0: si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>          > 0: el algoritmo para calcular la SVD no convergió;
!>                si INFO = i, i elementos fuera de la diagonal de una forma
!>                bidiagonal intermedia no convergieron a cero.
!>
