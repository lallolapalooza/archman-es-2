subrutina zgeqrs (integer m, integer n, integer nrhs, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( * ) tau, complex*16, dimension( ldb, * ) b, integer ldb, complex*16, dimension( lwork ) work, integer lwork, integer info)

ZGEQRS

Propósito:

!>
!> Resuelve el problema de mínimos cuadrados
!>     min || A*X - B ||
!> usando la factorización QR
!>     A = Q*R
!> calculada por ZGEQRF.
!>

Parámetros

M 
!>          M es INTEGER
!>          El número de filas de la matriz A.  M >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz A.  M >= N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de columnas de B.  NRHS >= 0.
!>

A

!>          A es un array COMPLEX*16, de dimensión (LDA,N)
!>          Detalles de la factorización QR de la matriz original A como
!>          devuelto por ZGEQRF.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= M.
!>

TAU

!>          TAU es un array COMPLEX*16, de dimensión (N)
!>          Detalles de la matriz ortogonal Q.
!>

B

!>          B es un array COMPLEX*16, de dimensión (LDB,NRHS)
!>          En la entrada, la matriz B de lado derecho de m por nrhs.
!>          En la salida, la matriz solución X de n por nrhs.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B. LDB >= M.
!>

WORK

!>          WORK es un array COMPLEX*16, de dimensión (LWORK)
!>

LWORK

!>          LWORK es INTEGER
!>          La longitud del array WORK.  LWORK debe ser al menos NRHS,
!>          y debe ser al menos NRHS*NB, donde NB es el tamaño del bloque
!>          para este entorno.
!>

INFO

!>          INFO es INTEGER
!>          = 0: salida exitosa
!>          < 0: si INFO = -i, el argumento i-ésimo tenía un valor ilegal
!>
