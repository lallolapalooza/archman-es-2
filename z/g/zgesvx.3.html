ZGESVX calcula la solución al sistema de ecuaciones lineales A * X = B para matrices GE

Propósito:

!>
!> ZGESVX utiliza la factorización LU para calcular la solución a un sistema
!> complejo de ecuaciones lineales
!>    A * X = B,
!> donde A es una matriz N por N y X y B son matrices N por NRHS.
!>
!> También se proporcionan cotas de error para la solución y una estimación
!> de la condición.
!>

Descripción:

!>
!> Se realizan los siguientes pasos:
!>
!> 1. Si FACT = 'E', se calculan factores de escala reales para equilibrar
!>    el sistema:
!>       TRANS = 'N':  diag(R)*A*diag(C)     *inv(diag(C))*X = diag(R)*B
!>       TRANS = 'T': (diag(R)*A*diag(C))**T *inv(diag(R))*X = diag(C)*B
!>       TRANS = 'C': (diag(R)*A*diag(C))**H *inv(diag(R))*X = diag(C)*B
!>    Si el sistema se equilibrará o no depende del escalado de la matriz A,
!>    pero si se utiliza el equilibrado, A se sobrescribe con
!>    diag(R)*A*diag(C) y B con diag(R)*B (si TRANS='N') o diag(C)*B
!>    (si TRANS = 'T' o 'C').
!>
!> 2. Si FACT = 'N' o 'E', se utiliza la descomposición LU para factorizar
!>    la matriz A (después del equilibrado si FACT = 'E') como
!>       A = P * L * U,
!>    donde P es una matriz de permutación, L es una matriz triangular
!>    inferior unitaria y U es triangular superior.
!>
!> 3. Si algún U(i,i)=0, de modo que U sea exactamente singular, la rutina
!>    devuelve INFO = i. De lo contrario, la forma factorizada de A se utiliza
!>    para estimar el número de condición de la matriz A. Si el recíproco
!>    del número de condición es menor que la precisión de la máquina,
!>    se devuelve INFO = N+1 como advertencia, pero la rutina continúa
!>    resolviendo X y calculando cotas de error como se describe a continuación.
!>
!> 4. El sistema de ecuaciones se resuelve para X utilizando la forma
!>    factorizada de A.
!>
!> 5. Se aplica refinamiento iterativo para mejorar la solución calculada
!>    y obtener cotas de error y estimaciones de error hacia atrás para ella.
!>
!> 6. Si se utilizó el equilibrado, la matriz X se premultiplica por
!>    diag(C) (si TRANS = 'N') o diag(R) (si TRANS = 'T' o 'C') de modo
!>    que resuelva el sistema original antes del equilibrado.
!>

Parámetros

FACT 
!>          FACT es CHARACTER*1
!>          Especifica si la forma factorizada de la matriz A se
!>          proporciona en la entrada, y si no, si la matriz A debe ser
!>          equilibrada antes de ser factorizada.
!>          = 'F':  En la entrada, AF y IPIV contienen la forma factorizada de A.
!>                  Si EQUED no es 'N', la matriz A ha sido
!>                  equilibrada con factores de escala dados por R y C.
!>                  A, AF e IPIV no se modifican.
!>          = 'N':  La matriz A se copiará en AF y se factorizará.
!>          = 'E':  La matriz A se equilibrará si es necesario, luego
!>                  se copiará en AF y se factorizará.
!>

TRANS

!>          TRANS es CHARACTER*1
!>          Especifica la forma del sistema de ecuaciones:
!>          = 'N':  A * X = B     (Sin transpuesta)
!>          = 'T':  A**T * X = B  (Transpuesta)
!>          = 'C':  A**H * X = B  (Transpuesta conjugada)
!>

N

!>          N es INTEGER
!>          El número de ecuaciones lineales, es decir, el orden de
!>          la matriz A.  N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de lados derechos, es decir, el número de columnas
!>          de las matrices B y X.  NRHS >= 0.
!>

A

!>          A es un array COMPLEX*16, de dimensión (LDA,N)
!>          En la entrada, la matriz A de N por N. Si FACT = 'F' y EQUED
!>          no es 'N', entonces A ha sido equilibrada por los factores de
!>          escala en R y/o C. A no se modifica si FACT = 'F' o
!>          'N', o si FACT = 'E' y EQUED = 'N' en la salida.
!>
!>          En la salida, si EQUED .ne. 'N', A se escala de la siguiente manera:
!>          EQUED = 'R':  A := diag(R) * A
!>          EQUED = 'C':  A := A * diag(C)
!>          EQUED = 'B':  A := diag(R) * A * diag(C).
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

AF

!>          AF es un array COMPLEX*16, de dimensión (LDAF,N)
!>          Si FACT = 'F', entonces AF es un argumento de entrada y en la
!>          entrada contiene los factores L y U de la factorización
!>          A = P*L*U calculada por ZGETRF. Si EQUED .ne. 'N', entonces
!>          AF es la forma factorizada de la matriz A equilibrada.
!>
!>          Si FACT = 'N', entonces AF es un argumento de salida y en la
!>          salida devuelve los factores L y U de la factorización A = P*L*U
!>          de la matriz original A.
!>
!>          Si FACT = 'E', entonces AF es un argumento de salida y en la
!>          salida devuelve los factores L y U de la factorización A = P*L*U
!>          de la matriz equilibrada A (ver la descripción de A para
!>          la forma de la matriz equilibrada).
!>

LDAF

!>          LDAF es INTEGER
!>          La dimensión principal del array AF.  LDAF >= max(1,N).
!>

IPIV

!>          IPIV es un array INTEGER, de dimensión (N)
!>          Si FACT = 'F', entonces IPIV es un argumento de entrada y en la
!>          entrada contiene los índices de pivote de la factorización A = P*L*U
!>          calculada por ZGETRF; la fila i de la matriz se intercambió
!>          con la fila IPIV(i).
!>
!>          Si FACT = 'N', entonces IPIV es un argumento de salida y en la
!>          salida contiene los índices de pivote de la factorización A = P*L*U
!>          de la matriz original A.
!>
!>          Si FACT = 'E', entonces IPIV es un argumento de salida y en la
!>          salida contiene los índices de pivote de la factorización A = P*L*U
!>          de la matriz equilibrada A.
!>

EQUED

!>          EQUED es CHARACTER*1
!>          Especifica la forma de equilibrado que se realizó.
!>          = 'N':  Sin equilibrado (siempre verdadero si FACT = 'N').
!>          = 'R':  Equilibrado de fila, es decir, A ha sido premultiplicada por
!>                  diag(R).
!>          = 'C':  Equilibrado de columna, es decir, A ha sido postmultiplicada
!>                  por diag(C).
!>          = 'B':  Equilibrado de fila y columna, es decir, A ha sido
!>                  reemplazada por diag(R) * A * diag(C).
!>          EQUED es un argumento de entrada si FACT = 'F'; de lo contrario, es un
!>          argumento de salida.
!>

R

!>          R es DO

INTEGER :: N, NRHS, LDA, LDAF, LDB, LDX, INFO
INTEGER :: IPIV( * )
REAL(KIND=8) :: R( * ), C( * ), RCOND
COMPLEX(KIND=16) :: A( * , * ), AF( * , * ), B( * , * ), X( * , * )

REAL(KIND=8) :: FERR( * ), BERR( * ), RWORK( * )

Function/Subroutine Documentation

This routine uses the left-right factorization of a general double precision rectangular matrix A to solve a single system of linear equations A*X = B, or to approximate the error bounds for the solution X. It uses iterative refinement to improve the computed solution.

The routine computes the solution X to a system of linear equations A*X = B, where A is an N-by-N complex matrix and X and B are N-by-NRHS complex matrices. Various matrix factorizations are used to estimate the condition number of the matrix and the forward and backward error bounds of the computed solution.

The general form of the problem is:

       OP(A)*X = B

where OP(A) is either A, A^T, or A^H, and A^T is the transpose of A, and A^H is the conjugate transpose of A.

Before equilibrium can be achieved, the diagonal elements of A are checked for the presence of zero. If A is equilibrium, the routine computes:

       diag(R)*A*diag(C) = U

And then:

       diag(R)*A*diag(C)*X = diag(R)*B

The input consists of:

A

!>          A is COMPLEX*16 array, dimension (LDA,N)
!>          The N-by-N matrix A.
!>

LDA

!>          LDA is INTEGER
!>          The leading dimension of the array A. LDA >= max(1,N).
!>

AF

!>          AF is COMPLEX*16 array, dimension (LDAF,N)
!>          The LU factorization of A, as returned by ZGETRF.
!>

LDAF

!>          LDAF is INTEGER
!>          The leading dimension of the array AF. LDAF >= max(1,N).
!>

IPIV

!>          IPIV is INTEGER array, dimension (N)
!>          The pivot indices from the LU factorization of A, as
!>          returned by ZGETRF.
!>

R

!>          R is DOUBLE PRECISION array, dimension (N)
!>          The row scale factors for A.  If EQUED = 'R' or 'B', A is
!>          multiplied on the left by diag(R); if EQUED = 'N' or 'C', R
!>          is not accessed.  R is an input argument if FACT = 'F';
!>          otherwise, R is an output argument.  If FACT = 'F' and
!>          EQUED = 'R' or 'B', each element of R must be positive.
!>

C

!>          C is DOUBLE PRECISION array, dimension (N)
!>          The column scale factors for A.  If EQUED = 'C' or 'B', A is
!>          multiplied on the right by diag(C); if EQUED = 'N' or 'R', C
!>          is not accessed.  C is an input argument if FACT = 'F';
!>          otherwise, C is an output argument.  If FACT = 'F' and
!>          EQUED = 'C' or 'B', each element of C must be positive.
!>

B

!>          B is COMPLEX*16 array, dimension (LDB,NRHS)
!>          On entry, the N-by-NRHS right hand side matrix B.
!>          On exit,
!>          if EQUED = 'N', B is not modified;
!>          if TRANS = 'N' and EQUED = 'R' or 'B', B is overwritten by
!>          diag(R)*B;
!>          if TRANS = 'T' or 'C' and EQUED = 'C' or 'B', B is
!>          overwritten by diag(C)*B.
!>

LDB

!>          LDB is INTEGER
!>          The leading dimension of the array B.  LDB >= max(1,N).
!>

X

!>          X is COMPLEX*16 array, dimension (LDX,NRHS)
!>          If INFO = 0 or INFO = N+1, the N-by-NRHS solution matrix X
!>          to the original system of equations.  Note that A and B are
!>          modified on exit if EQUED .ne. 'N', and the solution to the
!>          equilibrated system is inv(diag(C))*X if TRANS = 'N' and
!>          EQUED = 'C' or 'B', or inv(diag(R))*X if TRANS = 'T' or 'C'
!>          and EQUED = 'R' or 'B'.
!>

LDX

!>          LDX is INTEGER
!>          The leading dimension of the array X.  LDX >= max(1,N).
!>

RCOND

!>          RCOND is DOUBLE PRECISION
!>          The estimate of the reciprocal condition number of the matrix
!>          A after equilibration (if done).  If RCOND is less than the
!>          machine precision (in particular, if RCOND = 0), the matrix
!>          is singular to working precision.  This condition is
!>          indicated by a return code of INFO > 0.
!>

FERR

!>          FERR is DOUBLE PRECISION array, dimension (NRHS)
!>          The estimated forward error bound for each solution vector
!>          X(j) (the j-th column of the solution matrix X).
!>          If XTRUE is the true solution corresponding to X(j), FERR(j)
!>          is an estimated upper bound for the magnitude of the largest
!>          element in (X(j) - XTRUE) divided by the magnitude of the
!>          largest element in X(j).  The estimate is as reliable as
!>          the estimate for RCOND, and is almost always a slight
!>          overestimate of the true error.
!>

BERR

!>          BERR is DOUBLE PRECISION array, dimension (NRHS)
!>          The componentwise relative backward error of each solution
!>          vector X(j) (i.e., the smallest relative change in
!>          any element of A or B that makes X(j) an exact solution).
!>

WORK

!>          WORK is COMPLEX*16 array, dimension (2*N)
!>

RWORK

!>          RWORK is DOUBLE PRECISION array, dimension (MAX(1,2*N))
!>          On exit, RWORK(1) contains the reciprocal pivot growth
!>          factor norm(A)/norm(U). The  norm is
!>          used. If RWORK(1) is much less than 1, then the stability
!>          of the LU factorization of the (equilibrated) matrix A
!>          could be poor. This also means that the solution X, condition
!>          estimator RCOND, and forward error bound FERR could be
!>          unreliable. If factorization fails with 0<INFO<=N, then
!>          RWORK(1) contains the reciprocal pivot growth factor for the
!>          leading INFO columns of A.
!>

INFO

!>          INFO is INTEGER
!>          = 0:  successful exit
!>          < 0:  if INFO = -i, the i-th argument had an illegal value
!>          > 0:  if INFO = i, and i is
!>                <= N:  U(i,i) is exactly zero.  The factorization has
!>                       been completed, but the factor U is exactly
!>                       singular, so the solution and error bounds
!>                       could not be computed. RCOND = 0 is returned.
!>                = N+1: U is nonsingular, but RCOND is less than machine
!>                       precision, meaning that the matrix is singular
!>                       to working precision.  Nevertheless, the
!>                       solution and error bounds are computed because
!>                       there are a number of situations where the
!>                       computed solution can be more accurate than the
!>                       value of RCOND would suggest.
!>
