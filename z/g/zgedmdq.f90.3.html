ZGEDMDQ calcula la Descomposición de Modo Dinámico (DMD) para un par de matrices de instantáneas de datos.

Propósito:

!>    ZGEDMDQ calcula la Descomposición de Modo Dinámico (DMD) para
!>    un par de matrices de instantáneas de datos, utilizando una compresión
!>    de datos basada en la factorización QR. Para las matrices de entrada
!>    X e Y tales que Y = A*X con una matriz A inaccesible, ZGEDMDQ
!>    calcula un cierto número de pares de Ritz de A utilizando la extracción
!>    estándar de Rayleigh-Ritz de un subespacio de range(X) que se determina
!>    utilizando los vectores singulares izquierdos principales de X. Opcionalmente,
!>    ZGEDMDQ devuelve los residuos de los pares de Ritz calculados, la información
!>    necesaria para un refinamiento de los vectores de Ritz, o los vectores
!>    propios de la DMD Exacta.
!>    Para más detalles ver las referencias listadas
!>    abajo. Para más detalles de la implementación ver [3].
!>

Referencias:

NAME

zgedmdq - computes the singular value decomposition (SVD) of a real matrix

SYNOPSIS

SUBROUTINE ZGEDMDQ(
      INTEGER           JOBZ,
      INTEGER           JOBS,
      INTEGER           JOBQ,
      INTEGER           M,
      INTEGER           N,
      INTEGER           K,
      INTEGER           LDA,
      INTEGER           LDB,
      INTEGER           LDC,
      INTEGER           LDQ,
      INTEGER           LWORK,
      INTEGER           LIWORK,
      REAL(KIND=WP)     A(LDA,*),
      REAL(KIND=WP)     B(LDB,*),
      REAL(KIND=WP)     C(LDC,*),
      REAL(KIND=WP)     Q(LDQ,*),
      REAL(KIND=WP)     WORK(LWORK),
      INTEGER           IWORK(LIWORK),
      INTEGER           INFO )

Function/Subroutine Documentation

This subroutine computes the singular value decomposition (SVD) of a real matrix by applying a limited-memory variant of the Jacobi eigenvalue algorithm for computing the SVD of the product P = A*B*C, where A is M-by-N, B is N-by-N and C is N-by-K.

The SVD is computed as P = U*S*V', where U is M-by-M, S is M-by-K, and V is K-by-K. The matrix S is diagonal with non-negative entries (singular values).

The limited-memory Jacobi SVD algorithm is used for computing the SVD of the product P = A*B*C.

In this variant, ZGEDMDQ computes the SVD of a submatrix F(1:M,1:N-1) of the input matrix F (N-by-(N-1)).

The SVD is computed as F = U*S*V', where U is M-by-M, S is M-by-N-1, and V is (N-1)-by-(N-1). S is diagonal with non-negative entries.

The SVD is computed using a limited-memory variant of the Jacobi algorithm.

Arguments

JOBZ
Specifies whether to compute the left singular vectors.
'N': Do not compute the left singular vectors.
'V': Compute the left singular vectors.
JOBS
Specifies whether to compute the right singular vectors.
'N': Do not compute the right singular vectors.
'V': Compute the right singular vectors.
JOBQ
Specifies whether to compute the singular values.
'N': Do not compute the singular values.
'Q': Compute the singular values.
M
The number of rows of the input matrix F.
N
The number of columns of the input matrix F.
LDA
The leading dimension of the array F.
LDB
The leading dimension of the array B.
LDC
The leading dimension of the array C.
LDQ
The leading dimension of the array Q.
LWORK
The length of the workspace array WORK.
If LWORK = -1, then LZWORK is computed and returned in WORK(1).
LIWORK
The length of the workspace array IWORK.
If LIWORK = -1, then LIWORK is computed and returned in IWORK(1).
A
A is M-by-N.
B
B is N-by-N.
C
C is N-by-K.
Q
Q is K-by-K.
WORK
Workspace array.
On exit, WORK(1:N-1) contains the singular values of F.
IWORK
Workspace array.
Required only if WHTSVD = 2, 3, or 4.
INFO
Error flag.

Workspace Queries

If LWORK = -1 or LIWORK = -1, the routine computes the optimal workspace size for the given input parameters. The minimal workspace size is determined as follows:

Let MINMN = MIN(M,N).

LZWORK is initialized as MAX(2, MIN(M,N)+MLWQR, MINMN+MLWDMD).

The following updates are made based on the values of JOBZ and JOBQ:

if JOBZ == 'V' or JOBZ == 'F' THEN
     LZWORK = MAX(LZWORK, MINMN+MLWMQR)
if JOBQ == 'Q' THEN
     LZWORK = MAX(ZLWORK, MINMN+MLWGQR)

WORK

WORK (workspace/output) REAL(KIND=WP) LWORK-by-1 array
On exit,
WORK(1:N-1) contains the singular values of
the input submatrix F(1:M,1:N-1).
If the call to ZGEDMDQ is only workspace query, then
WORK(1) contains the minimal workspace length and
WORK(2) is the optimal workspace length. hence, the
length of work is at least 2.
See the description of LWORK.

LWORK

LWORK (input) INTEGER
The minimal length of the  workspace vector WORK.
LWORK is the same as in ZGEDMD, because in ZGEDMDQ
only ZGEDMD requires real workspace for snapshots
of dimensions MIN(M,N)-by-(N-1).
If on entry LWORK = -1, then a workspace query is
assumed and the procedure only computes the minimal
and the optimal workspace length for WORK.

IWORK

IWORK (workspace/output) INTEGER LIWORK-by-1 array
Workspace that is required only if WHTSVD equals
2 , 3 or 4 . (See the description of WHTSVD).
If on entry LWORK =-1 or LIWORK=-1, then the
minimal length of IWORK is computed and returned in
IWORK(1). See the description of LIWORK.

LIWORK

LIWORK (input) INTEGER
The minimal length of the workspace vector IWORK.
If WHTSVD == 1, then only IWORK(1) is used; LIWORK >=1
Let M1=MIN(M,N), N1=N-1. Then
If WHTSVD == 2, then LIWORK >= MAX(1,8*MIN(M1,N1))
If WHTSVD == 3, then LIWORK >= MAX(1,M1+N1-1)
If WHTSVD == 4, then LIWORK >= MAX(3,M1+3*N1)
If on entry LIWORK = -1, then a workspace query is
assumed and the procedure only computes the minimal
and the optimal workspace lengths for both WORK and
IWORK. See the descriptions of WORK and IWORK.

INFO

INFO (output) INTEGER
-i < 0 :: On entry, the i-th argument had an
          illegal value
   = 0 :: Successful return.
   = 1 :: Void input. Quick exit (M=0 or N=0).
   = 2 :: The SVD computation of X did not converge.
          Suggestion: Check the input data and/or
          repeat with different WHTSVD.
   = 3 :: The computation of the eigenvalues did not
          converge.
   = 4 :: If data scaling was requested on input and
          the procedure found inconsistency in the data
          such that for some column index i,
          X(:,i) = 0 but Y(:,i) /= 0, then Y(:,i) is set
          to zero if JOBS=='C'. The computation proceeds
          with original or modified data and warning
          flag is set with INFO=4.
