subroutine zggesx (character jobvsl, character jobvsr, character sort, external selctg, character sense, integer n, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( ldb, * ) b, integer ldb, integer sdim, complex*16, dimension( * ) alpha, complex*16, dimension( * ) beta, complex*16, dimension( ldvsl, * ) vsl, integer ldvsl, complex*16, dimension( ldvsr, * ) vsr, integer ldvsr, double precision, dimension( 2 ) rconde, double precision, dimension( 2 ) rcondv, complex*16, dimension( * ) work, integer lwork, double precision, dimension( * ) rwork, integer, dimension( * ) iwork, integer liwork, logical, dimension( * ) bwork, integer info)

ZGGESX calcula los valores propios, la forma de Schur y, opcionalmente, la matriz de vectores de Schur para matrices GE

Propósito:

!>
!> ZGGESX calcula para un par de matrices complejas no simétricas de N por N
!> (A,B), los valores propios generalizados, la forma de Schur compleja (S,T),
!> y, opcionalmente, las matrices izquierda y/o derecha de vectores de Schur (VSL
!> y VSR). Esto da la factorización de Schur generalizada
!>
!>      (A,B) = ( (VSL) S (VSR)**H, (VSL) T (VSR)**H )
!>
!> donde (VSR)**H es la traspuesta conjugada de VSR.
!>
!> Opcionalmente, también ordena los valores propios para que un clúster seleccionado
!> de valores propios aparezca en los bloques de diagonal principales de la matriz
!> triangular superior S y la matriz triangular superior T; calcula
!> un número de condición recíproco para el promedio de los valores propios seleccionados
!> (RCONDE); y calcula un número de condición recíproco para los subespacios de deflexión
!> derecha e izquierda correspondientes a los valores propios seleccionados
!> (RCONDV). Las columnas principales de VSL y VSR forman entonces una base ortonormal
!> para los subespacios de autovalores (subespacios de deflexión) izquierdo y derecho correspondientes.
!>
!> Un valor propio generalizado para un par de matrices (A,B) es un escalar w
!> o una razón alpha/beta = w, tal que A - w*B es singular. Se representa
!> usualmente como el par (alpha,beta), ya que hay una interpretación razonable
!> para beta=0 o para que ambos sean cero.
!>
!> Un par de matrices (S,T) está en forma de Schur generalizada compleja si T es
!> triangular superior con diagonal no negativa y S es triangular superior.
!>

Parámetros

JOBVSL 
!>          JOBVSL es CHARACTER*1
!>          = 'N':  no calcular los vectores de Schur izquierdos;
!>          = 'V':  calcular los vectores de Schur izquierdos.
!>

JOBVSR

!>          JOBVSR es CHARACTER*1
!>          = 'N':  no calcular los vectores de Schur derechos;
!>          = 'V':  calcular los vectores de Schur derechos.
!>

SORT

!>          SORT es CHARACTER*1
!>          Especifica si los valores propios deben ordenarse o no en la
!>          diagonal de la forma de Schur generalizada.
!>          = 'N':  Los valores propios no se ordenan;
!>          = 'S':  Los valores propios se ordenan (ver SELCTG).
!>

SELCTG

!>          SELCTG es una FUNCIÓN LOGICA de dos argumentos COMPLEX*16
!>          SELCTG debe ser declarada EXTERNAL en la subrutina llamante.
!>          Si SORT = 'N', SELCTG no se referencia.
!>          Si SORT = 'S', SELCTG se usa para seleccionar valores propios para ordenar
!>          en la parte superior izquierda de la forma de Schur.
!>          Tenga en cuenta que un valor propio complejo seleccionado puede ya no cumplir
!>          SELCTG(ALPHA(j),BETA(j)) = .TRUE. después de ordenarlo, ya que
!>          el ordenamiento puede cambiar el valor de los valores propios complejos
!>          (especialmente si el valor propio está mal condicionado), en este
!>          caso INFO se establece en N+3 ver INFO abajo).
!>

SENSE

!>          SENSE es CHARACTER*1
!>          Determina qué números de condición recíprocos se calculan.
!>          = 'N': Ninguno se calcula;
!>          = 'E': Calculado solo para el promedio de los valores propios seleccionados;
!>          = 'V': Calculado solo para subespacios de deflexión seleccionados;
!>          = 'B': Calculado para ambos.
!>          Si SENSE = 'E', 'V', o 'B', SORT debe ser igual a 'S'.
!>

N

!>          N es INTEGER
!>          El orden de las matrices A, B, VSL y VSR.  N >= 0.
!>

A

!>          A es un array COMPLEX*16, dimension (LDA, N)
!>          En la entrada, el primero del par de matrices.
!>          En la salida, A ha sido sobrescrito por su forma de Schur
!>          generalizada S.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal de A.  LDA >= max(1,N).
!>

B

!>          B es un array COMPLEX*16, dimension (LDB, N)
!>          En la entrada, el segundo del par de matrices.
!>          En la salida, B ha sido sobrescrito por su forma de Schur
!>          generalizada T.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal de B.  LDB >= max(1,N).
!>

SDIM

!>          SDIM es INTEGER
!>          Si SORT = 'N', SDIM = 0.
!>          Si SORT = 'S', SDIM = número de valores propios (después de ordenar)
!>          para los cuales SELCTG es verdadero.
!>

ALPHA

!>          ALPHA es un array COMPLEX*16, dimension (N)
!>

BETA

!>          BETA es un array COMPLEX*16, dimension (N)
!>          En la salida, ALPHA(j)/BETA(j), j=1,...,N, serán los
!>          valores propios generalizados.  ALPHA(j) y BETA(j),j=1,...,N  son
!>          las diagonales de la forma de Schur compleja (S,T).  BETA(j) será
!>          un real no negativo.
!>
!>          Nota: los cocientes ALPHA(j)/BETA(j) pueden fácilmente
!>          desbordarse o subdesbordarse, y BETA(j) puede ser incluso cero.  Por lo tanto, el usuario
!>          debe evitar calcular ingenuamente el cociente alpha/beta.
!>          Sin embargo, ALPHA siempre será menor y usualmente
!>          comparable con norm(A) en magnitud, y BETA siempre menor
!>          y usualmente comparable con norm(B).
!>

VSL

!>          VSL es un array COMPLEX*16, dimension (LDVSL,N)
!>          Si JOBVSL = 'V', VSL contendrá los vectores de Schur izquierdos.
!>          No se referencia si JOBVSL = 'N'.
!>

LDVSL

!>          LDVSL es INTEGER
!>          La dimensión principal de la matriz VSL. LDVSL >=1, y
!>          si JOBVSL = 'V', LDVSL >= N.
!>

VSR

!>          VSR es un array COMPLEX*16, dimension (LDVSR,N)
!>          Si JOBVSR = 'V', VSR contendrá los vectores de Schur derechos.
!>          No se referencia si JOBVSR = 'N'.
!>

LDVSR

!>          LDVSR es INTEGER
!>          La dimensión principal de la matriz VSR. LDVSR >= 1, y
!>          si JOBVSR = 'V', LDVSR >= N.
!>

RCONDE

!>          RCONDE es un array DOUBLE PRECISION, dimension ( 2 )
!>          Si SENSE = 'E' o 'B', RCONDE(1) y RCONDE(2) contienen los
!>          números de condición recíprocos para el promedio de los valores propios seleccionados
es.
!>          No referenciado si SENSE = 'N' o 'V'.
!>

RCONDV

!>          RCONDV es una matriz DOUBLE PRECISION, de dimensión ( 2 )
!>          Si SENSE = 'V' o 'B', RCONDV(1) y RCONDV(2) contienen el
!>          número de condición recíproco para los subespacios
!>          deflactantes seleccionados.
!>          No referenciado si SENSE = 'N' o 'E'.
!>

WORK

!>          WORK es una matriz COMPLEX*16, de dimensión (MAX(1,LWORK))
!>          A la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es un INTEGER
!>          La dimensión de la matriz WORK.
!>          Si N = 0, LWORK >= 1, en caso contrario si SENSE = 'E', 'V', o 'B',
!>          LWORK >= MAX(1,2*N,2*SDIM*(N-SDIM)), en caso contrario
!>          LWORK >= MAX(1,2*N).  Tenga en cuenta que 2*SDIM*(N-SDIM) <= N*N/2.
!>          Tenga en cuenta también que solo se devuelve un error si
!>          LWORK < MAX(1,2*N), pero si SENSE = 'E' o 'V' o 'B' esto puede
!>          no ser suficiente.
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el límite superior del tamaño óptimo de la matriz WORK
!>          y el tamaño mínimo de la matriz IWORK, devuelve estos
!>          valores como las primeras entradas de las matrices WORK e IWORK, y
!>          XERBLA no emite ningún mensaje de error relacionado con LWORK o LIWORK.
!>

RWORK

!>          RWORK es una matriz DOUBLE PRECISION, de dimensión ( 8*N )
!>          Espacio de trabajo real.
!>

IWORK

!>          IWORK es una matriz INTEGER, de dimensión (MAX(1,LIWORK))
!>          A la salida, si INFO = 0, IWORK(1) devuelve el LIWORK mínimo.
!>

LIWORK

!>          LIWORK es un INTEGER
!>          La dimensión de la matriz IWORK.
!>          Si SENSE = 'N' o N = 0, LIWORK >= 1, en caso contrario
!>          LIWORK >= N+2.
!>
!>          Si LIWORK = -1, entonces se asume una consulta de espacio de trabajo; la
!>          rutina solo calcula el límite superior del tamaño óptimo de la
!>          matriz WORK y el tamaño mínimo de la matriz IWORK, devuelve
!>          estos valores como las primeras entradas de las matrices WORK e IWORK, y
!>          XERBLA no emite ningún mensaje de error relacionado con LWORK o LIWORK.
!>

BWORK

!>          BWORK es una matriz LOGICAL, de dimensión (N)
!>          No referenciado si SORT = 'N'.
!>

INFO

!>          INFO es un INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>          = 1,...,N:
!>                La iteración QZ falló.  (A,B) no están en forma de Schur
!>                pero ALPHA(j) y BETA(j) deberían ser correctos para
!>                j=INFO+1,...,N.
!>          > N:  =N+1: falló la iteración QZ en ZHGEQZ
!>                =N+2: después de la reorganización, la aproximación de redondeo cambió los valores de
!>                      algunos valores propios complejos de modo que los
!>                      valores propios líderes en la forma de Schur Generalizada ya no cumplen SELCTG=.TRUE. Esto también
!>                      podría ser causado por el escalado.
!>                =N+3: falló la reorganización en ZTGSEN.
!>
