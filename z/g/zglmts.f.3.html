Documentación de la función/subrutina

subrutina zglmts (integer n, integer m, integer p, complex*16, dimension( lda, * ) a, complex*16, dimension( lda, * ) af, integer lda, complex*16, dimension( ldb, * ) b, complex*16, dimension( ldb, * ) bf, integer ldb, complex*16, dimension( * ) d, complex*16, dimension( * ) df, complex*16, dimension( * ) x, complex*16, dimension( * ) u, complex*16, dimension( lwork ) work, integer lwork, double precision, dimension( * ) rwork, double precision result)

ZGLMTS

Propósito:

!>
!> ZGLMTS prueba ZGGGLM - una subrutina para resolver el problema del
!> modelo lineal generalizado.
!>

Parámetros

N 
!>          N es INTEGER
!>          El número de filas de las matrices A y B.  N >= 0.
!>

M

!>          M es INTEGER
!>          El número de columnas de la matriz A.  M >= 0.
!>

P

!>          P es INTEGER
!>          El número de columnas de la matriz B.  P >= 0.
!>

A

!>          A es un array de COMPLEX*16, dimensión (LDA,M)
!>          La matriz N-por-M A.
!>

AF

!>          AF es un array de COMPLEX*16, dimensión (LDA,M)
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal de los arrays A, AF. LDA >= max(M,N).
!>

B

!>          B es un array de COMPLEX*16, dimensión (LDB,P)
!>          La matriz N-por-P A.
!>

BF

!>          BF es un array de COMPLEX*16, dimensión (LDB,P)
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal de los arrays B, BF. LDB >= max(P,N).
!>

D

!>          D es un array de COMPLEX*16, dimensión( N )
!>          En la entrada, el lado izquierdo de GLM.
!>

DF

!>          DF es un array de COMPLEX*16, dimensión( N )
!>

X

!>          X es un array de COMPLEX*16, dimensión( M )
!>          vector solución X en el problema GLM.
!>

U

!>          U es un array de COMPLEX*16, dimensión( P )
!>          vector solución U en el problema GLM.
!>

WORK

!>          WORK es un array de COMPLEX*16, dimensión (LWORK)
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK.
!>

RWORK

!>          RWORK es un array de DOUBLE PRECISION, dimensión (M)
!>

RESULT

!>          RESULT es DOUBLE PRECISION
!>          La razón de prueba:
!>                           norm( d - A*x - B*u )
!>            RESULT = -----------------------------------------
!>                     (norm(A)+norm(B))*(norm(x)+norm(u))*EPS
!>
