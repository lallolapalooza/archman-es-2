ZGELSD calcula la solución de norma mínima para un problema de mínimos cuadrados GE

Propósito:

!>
!> ZGELSD calcula la solución de norma mínima para un problema de mínimos
!> cuadrados lineal real:
!>     minimizar la norma 2 de (| b - A*x |)
!> utilizando la descomposición en valores singulares (SVD) de A. A es una
!> matriz M por N que puede ser de rango deficiente.
!>
!> Se pueden manejar varios vectores de mano derecha b y vectores solución x
!> en una sola llamada; se almacenan como las columnas de la matriz B de
!> mano derecha M por NRHS y la matriz solución X de N por NRHS.
!>
!> El problema se resuelve en tres pasos:
!> (1) Reducir la matriz de coeficientes A a forma bidiagonal con
!>     transformaciones de Householder, reduciendo el problema original
!>     a un (BLS)
!> (2) Resolver el BLS usando un enfoque de "divide y vencerás".
!> (3) Aplicar retroactivamente todas las transformaciones de Householder
!>     para resolver el problema de mínimos cuadrados original.
!>
!> El rango efectivo de A se determina tratando como cero aquellos
!> valores singulares que son menores que RCOND multiplicado por el valor
!> singular más grande.
!>
!>

Parámetros

M 
!>          M es INTEGER
!>          El número de filas de la matriz A. M >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz A. N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de manos derechas, es decir, el número de columnas
!>          de las matrices B y X. NRHS >= 0.
!>

A

!>          A es un array COMPLEX*16, de dimensión (LDA,N)
!>          En la entrada, la matriz M por N A.
!>          En la salida, A ha sido destruida.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A. LDA >= max(1,M).
!>

B

!>          B es un array COMPLEX*16, de dimensión (LDB,NRHS)
!>          En la entrada, la matriz de mano derecha B de M por NRHS.
!>          En la salida, B se sobrescribe con la matriz solución X de N por NRHS.
!>          Si m >= n y RANK = n, la suma de cuadrados residual para
!>          la solución en la i-ésima columna se da por la suma de
!>          cuadrados de los módulos de los elementos n+1:m en esa columna.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B. LDB >= max(1,M,N).
!>

S

!>          S es un array DOUBLE PRECISION, de dimensión (min(M,N))
!>          Los valores singulares de A en orden decreciente.
!>          El número de condición de A en la norma 2 = S(1)/S(min(m,n)).
!>

RCOND

!>          RCOND es DOUBLE PRECISION
!>          RCOND se usa para determinar el rango efectivo de A.
!>          Los valores singulares S(i) <= RCOND*S(1) se tratan como cero.
!>          Si RCOND < 0, se usa la precisión de la máquina en su lugar.
!>

RANK

!>          RANK es INTEGER
!>          El rango efectivo de A, es decir, el número de valores singulares
!>          que son mayores que RCOND*S(1).
!>

WORK

!>          WORK es un array COMPLEX*16, de dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK. LWORK debe ser al menos 1.
!>          La cantidad mínima exacta de espacio de trabajo necesario depende
!>          de M, N y NRHS. Mientras LWORK sea al menos
!>              2*N + N*NRHS
!>          si M es mayor o igual que N o
!>              2*M + M*NRHS
!>          si M es menor que N, el código se ejecutará correctamente.
!>          Para un buen rendimiento, LWORK generalmente debería ser mayor.
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de
!>          trabajo; la rutina solo calcula el tamaño óptimo del array WORK y
!>          los tamaños mínimos de los arrays RWORK y IWORK, y devuelve
!>          estos valores como las primeras entradas de los arrays WORK, RWORK
!>          e IWORK, y XERBLA no emite ningún mensaje de error relacionado con
!>          LWORK.
!>

RWORK

!>          RWORK es un array DOUBLE PRECISION, de dimensión (MAX(1,LRWORK))
!>          LRWORK >=
!>             10*N + 2*N*SMLSIZ + 8*N*NLVL + 3*SMLSIZ*NRHS +
!>             MAX( (SMLSIZ+1)**2, N*(1+NRHS) + 2*NRHS )
!>          si M es mayor o igual que N o
!>             10*M + 2*M*SMLSIZ + 8*M*NLVL + 3*SMLSIZ*NRHS +
!>             MAX( (SMLSIZ+1)**2, N*(1+NRHS) + 2*NRHS )
!>          si M es menor que N, el código se ejecutará correctamente.
!>          SMLSIZ lo devuelve ILAENV y es igual al tamaño máximo de los
!>          subproblemas en la parte inferior del árbol de computación
!>          (generalmente alrededor de 25), y
!>             NLVL = MAX( 0, INT( LOG_2( MIN( M,N )/(SMLSIZ+1) ) ) + 1 )
!>          En la salida, si INFO = 0, RWORK(1) devuelve el LRWORK mínimo.
!>

IWORK

!>          IWORK es un array INTEGER, de dimensión (MAX(1,LIWORK))
!>          LIWORK >= max(1, 3*MINMN*NLVL + 11*MINMN),
!>          donde MINMN = MIN( M,N ).
!>          En la salida, si INFO = 0, IWORK(1) devuelve el LIWORK mínimo.
!>

INFO

!>          INFO es INTEGER
!>          = 0: salida exitosa
!>          < 0: si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>          > 0: el algoritmo para calcular la SVD no convergió;
!>                si INFO = i, i elementos fuera de la diagonal de una
!>                forma bidiagonal intermedia no convergieron a cero.
!>

zgelsd.f(3)

LAPACK routine

NAME

zgelsd - zgelsd computes the minimum norm solution to the complex linear system

||b - Ax||_2 = min, using the singular value decomposition (SVD) of A;

or the least squares solution to a complex linear system of equations.

SYNOPSIS

SUBROUTINE ZGELSD( MATRIX_STORED_A, M, N, NRHS, A, LDA, B, LDB, SVD_VALUES, RCOND, RANK, WORK, LWORK, INFO )
<type> MATRIX_STORED_A
INTEGER M, N, NRHS, LDA, LDB, LWORK, INFO
DOUBLE PRECISION SVD_VALUES( * ), RCOND
COMPLEX*16 A( LDA, * ), B( LDB, * ), WORK( * )

Function/Subroutine Documentation

zgelsd is a subroutine in the LAPACK library. It is designed to solve

linear systems of equations using the Singular Value Decomposition (SVD).

Here's a breakdown of the parameters:

MATRIX_STORED_A

Specifies the storage format of the matrix A. Possible values are:

  • 'U': Upper triangular
  • 'L': Lower triangular

Note: In standard LAPACK usage, this parameter is often implicitly handled by the LAPACK routines and might not be explicitly exposed in all interfaces. For LAPACK routines that work directly with matrices (like zgeev), this is usually not a parameter.

M

The number of rows of the matrix A.

N

The number of columns of the matrix A.

NRHS

The number of right-hand sides, i.e., the number of columns of the matrix B.

A

The M-by-N matrix A. On entry, the array A contains the matrix to be factorized.

LDA

The leading dimension of the array A. `LDA` must be at least `max(1, M)`.

B

On entry, the M-by-NRHS matrix of right-hand sides. On exit, B is overwritten by the solution of the system. In the least squares case, B contains the minimum norm solution.

LDB

The leading dimension of the array B. `LDB` must be at least `max(1, M, N)`.

SVD_VALUES

On exit, the singular values of A, sorted in descending order.

RCOND

RCOND is a double precision value used to determine the effective rank of the matrix A. Singular values less than or equal to `RCOND * max(SVD_VALUES)` are treated as zero.

RANK

On exit, the effective rank of A.

WORK

A complex*16 array of dimension `LWORK`. On exit, `WORK(1)` contains the minimum required dimension `LWORK`.

LWORK

The dimension of the array WORK. `LWORK` must be at least `max(1, 3*min(M,N) + max(max(M,N), 3*NRHS))`. For optimal performance, `LWORK` should be `min(M,N) + max(M,N,3*NRHS)`.

INFO

INFO is an integer and on exit contains:

  • 0: The subroutine executed successfully.
  • < 0: If INFO = -i, the i-th argument had an illegal value.
  • > 0: If INFO = k, the SVD computation did not converge.
