ZGGSVD calcula la descomposición en valores singulares (SVD) para OTRAS matrices

Propósito:

!>
!> Esta rutina está obsoleta y ha sido reemplazada por la rutina ZGGSVD3.
!>
!> ZGGSVD calcula la descomposición en valores singulares generalizada (GSVD)
!> de una matriz compleja M por N, A, y una matriz compleja P por N, B:
!>
!>       U**H*A*Q = D1*( 0 R ),    V**H*B*Q = D2*( 0 R )
!>
!> donde U, V y Q son matrices unitarias.
!> Sea K+L = el rango numérico efectivo de la
!> matriz (A**H,B**H)**H, entonces R es una matriz triangular superior no singular de (K+L)-por-(K+L), D1 y D2 son matrices de M-por-(K+L) y P-por-(K+L)
!> y de las siguientes estructuras, respectivamente:
!>
!> Si M-K-L >= 0,
!>
!>                     K  L
!>        D1 =     K ( I  0 )
!>                 L ( 0  C )
!>             M-K-L ( 0  0 )
!>
!>                   K  L
!>        D2 =   L ( 0  S )
!>             P-L ( 0  0 )
!>
!>                 N-K-L  K    L
!>   ( 0 R ) = K (  0   R11  R12 )
!>             L (  0    0   R22 )
!> donde
!>
!>   C = diag( ALPHA(K+1), ... , ALPHA(K+L) ),
!>   S = diag( BETA(K+1),  ... , BETA(K+L) ),
!>   C**2 + S**2 = I.
!>
!>   R se almacena en A(1:K+L,N-K-L+1:N) al salir.
!>
!> Si M-K-L < 0,
!>
!>                   K M-K K+L-M
!>        D1 =   K ( I  0    0   )
!>             M-K ( 0  C    0   )
!>
!>                     K M-K K+L-M
!>        D2 =   M-K ( 0  S    0  )
!>             K+L-M ( 0  0    I  )
!>               P-L ( 0  0    0  )
!>
!>                    N-K-L  K   M-K  K+L-M
!>   ( 0 R ) =     K ( 0    R11  R12  R13  )
!>               M-K ( 0     0   R22  R23  )
!>             K+L-M ( 0     0    0   R33  )
!>
!> donde
!>
!>   C = diag( ALPHA(K+1), ... , ALPHA(M) ),
!>   S = diag( BETA(K+1),  ... , BETA(M) ),
!>   C**2 + S**2 = I.
!>
!>   (R11 R12 R13 ) se almacena en A(1:M, N-K-L+1:N), y R33 se almacena
!>   ( 0  R22 R23 )
!>   en B(M-K+1:L,N+M-K-L+1:N) al salir.
!>
!> La rutina calcula C, S, R y, opcionalmente, las matrices de transformación
!> unitarias U, V y Q.
!>
!> En particular, si B es una matriz no singular de N por N, entonces la GSVD de
!> A y B da implícitamente la SVD de A*inv(B):
!>                      A*inv(B) = U*(D1*inv(D2))*V**H.
!> Si ( A**H,B**H)**H tiene columnas ortonormales, entonces la GSVD de A y B es también
!> igual a la descomposición CS de A y B. Además, la GSVD se puede
!> utilizar para derivar la solución del problema de valores propios:
!>                      A**H*A x = lambda* B**H*B x.
!> En alguna literatura, la GSVD de A y B se presenta en la forma
!>                  U**H*A*X = ( 0 D1 ),   V**H*B*X = ( 0 D2 )
!> donde U y V son ortogonales y X es no singular, y D1 y D2 son
!> ``diagonales''. La forma GSVD anterior se puede convertir a la forma
!> posterior tomando la matriz no singular X como
!>
!>                       X = Q*(  I   0    )
!>                             (  0 inv(R) )
!>

Parámetros

JOBU 
!>          JOBU es CHARACTER*1
!>          = 'U':  Se calcula la matriz unitaria U;
!>          = 'N':  U no se calcula.
!>

JOBV

!>          JOBV es CHARACTER*1
!>          = 'V':  Se calcula la matriz unitaria V;
!>          = 'N':  V no se calcula.
!>

JOBQ

!>          JOBQ es CHARACTER*1
!>          = 'Q':  Se calcula la matriz unitaria Q;
!>          = 'N':  Q no se calcula.
!>

M

!>          M es INTEGER
!>          El número de filas de la matriz A.  M >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas de las matrices A y B.  N >= 0.
!>

P

!>          P es INTEGER
!>          El número de filas de la matriz B.  P >= 0.
!>

K

!>          K es INTEGER
!>

L

!>          L es INTEGER
!>
!>          Al salir, K y L especifican la dimensión de los subbloques
!>          descritos en Propósito.
!>          K + L = rango numérico efectivo de (A**H,B**H)**H.
!>

A

!>          A es COMPLEX*16 array, dimension (LDA,N)
!>          En la entrada, la matriz A de M por N.
!>          Al salir, A contiene la matriz triangular R, o parte de R.
!>          Ver Propósito para más detalles.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A. LDA >= max(1,M).
!>

B

!>          B es COMPLEX*16 array, dimension (LDB,N)
!>          En la entrada, la matriz B de P por N.
!>          Al salir, B contiene parte de la matriz triangular R si
!>          M-K-L < 0. Ver Propósito para más detalles.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B. LDB >= max(1,P).
!>

ALPHA

!>          ALPHA es array DOUBLE PRECISION, dimension (N)
!>

BETA

!>          BETA es array DOUBLE PRECISION, dimension (N)
!>
!>          Al salir, ALPHA y BETA contienen los pares de valores singulares generalizados
!>          de A y B;
!>            ALPHA(1:K) = 1,
!>            BETA(1:K)  = 0,
!>          y si M-K-L >= 0,
!>            ALPHA(K+1:K+L) = C,
!>            BETA(K+1:K+L)  = S,
!>          o si M-K-L < 0,
!>            ALPHA(K+1:M)=C, ALPHA(M+1:K+L)=0
!>            BETA(K+1:M) =S, BETA(M+1:K+L) =1
!>          y
!>            ALPHA(K+L+1:N) = 0
!>            BETA(K+L+1:N)  = 0
!>

U

!>          U es array COMPLEX*16, dimension (LDU,M)
!>          Si JOBU = 'U', U contiene la matriz unitaria U de M por M.
!>          Si JOBU = 'N', U no se referencia.
!>

LDU

!>          LDU es INTEGER
!>          La dimensión principal del array U. LDU >= max(1,M) si
!>          JOBU = 'U'; LDU >= 1 en caso contrario.
!>

V

!>          V es array COMPLEX*16, dimension (LDV,P)
!>          Si JOBV = 'V', V contiene la matriz unitaria V de P por P.
!>          Si JOBV = 'N', V no se referencia.
!>

LDV

!>          LDV es INTEGER
!>          La dimensión principal del array V. LDV >= max(1,P) si
!>          JOBV = 'V'; LDV >= 1 en caso contrario.
!>

Q

!>          Q es array COMPLEX*16, dimension (LDQ,N)
!>          Si JOBQ = 'Q', Q contiene la matriz unitaria Q de N por N.
!>          Si JOBQ = 'N', Q no se referencia.
!>

LDQ

!>

WORK

!>          WORK es COMPLEX*16 array, dimension (MAX(1,LWORK))
!>          (Salida) En la salida, WORK(1) contiene el valor mínimo de LWORK.
!>

RWORK

!>          RWORK es DOUBLE PRECISION array, dimension (MAX(1,LRWORK))
!>          (Salida) En la salida, RWORK(1) contiene el valor mínimo de LRWORK.
!>

IWORK

!>          IWORK es array INTEGER, dimension (MAX(1,LIWORK))
!>

INFO

!>          INFO es INTEGER
!>          = 0:  Error de procesamiento de datos.
!>          > 0:  Si el rango de la matriz (A**H,B**H)**H es menor que K+L,
!>                entonces el algoritmo de partición QR converge, pero
!>                el número de valores singulares de los subbloques
!>                (diag(ALPHA(K+1:K+L)), BETA(K+1:K+L)) que son
!>                aproximadamente cero es INFO.
!>          < 0:  Si INFO = -i, entonces el i-ésimo argumento se encuentra
!>                con un valor ilegal.
!>
