Documentación de la función/subrutina

subrutina zgqrts (integer n, integer m, integer p, complex*16, dimension( lda, * ) a, complex*16, dimension( lda, * ) af, complex*16, dimension( lda, * ) q, complex*16, dimension( lda, * ) r, integer lda, complex*16, dimension( * ) taua, complex*16, dimension( ldb, * ) b, complex*16, dimension( ldb, * ) bf, complex*16, dimension( ldb, * ) z, complex*16, dimension( ldb, * ) t, complex*16, dimension( ldb, * )bwk, integer ldb, complex*16, dimension( * ) taub, complex*16, dimension( lwork ) work, integer lwork, double precision, dimension( * ) rwork, double precision, dimension( 4 ) result)

ZGQRTS

Propósito:

!>
!> ZGQRTS prueba ZGGQRF, que calcula la factorización GQR de una
!> matriz A de N por M y una matriz B de N por P: A = Q*R y B = Q*T*Z.
!>

Parámetros

N 
!>          N es ENTERO
!>          El número de filas de las matrices A y B.  N >= 0.
!>

M

!>          M es ENTERO
!>          El número de columnas de la matriz A.  M >= 0.
!>

P

!>          P es ENTERO
!>          El número de columnas de la matriz B.  P >= 0.
!>

A

!>          A es un array COMPLEX*16, dimensión (LDA,M)
!>          La matriz A de N por M.
!>

AF

!>          AF es un array COMPLEX*16, dimensión (LDA,N)
!>          Detalles de la factorización GQR de A y B, como se devuelve
!>          por ZGGQRF, ver CGGQRF para más detalles.
!>

Q

!>          Q es un array COMPLEX*16, dimensión (LDA,N)
!>          La matriz unitaria Q de M por M.
!>

R

!>          R es un array COMPLEX*16, dimensión (LDA,MAX(M,N))
!>

LDA

!>          LDA es ENTERO
!>          La dimensión principal de los arrays A, AF, R y Q.
!>          LDA >= max(M,N).
!>

TAUA

!>          TAUA es un array COMPLEX*16, dimensión (min(M,N))
!>          Los factores escalares de los reflectores elementales, como se devuelve
!>          por ZGGQRF.
!>

B

!>          B es un array COMPLEX*16, dimensión (LDB,P)
!>          En la entrada, la matriz A de N por P.
!>

BF

!>          BF es un array COMPLEX*16, dimensión (LDB,N)
!>          Detalles de la factorización GQR de A y B, como se devuelve
!>          por ZGGQRF, ver CGGQRF para más detalles.
!>

Z

!>          Z es un array COMPLEX*16, dimensión (LDB,P)
!>          La matriz unitaria Z de P por P.
!>

T

!>          T es un array COMPLEX*16, dimensión (LDB,max(P,N))
!>

BWK

!>          BWK es un array COMPLEX*16, dimensión (LDB,N)
!>

LDB

!>          LDB es ENTERO
!>          La dimensión principal de los arrays B, BF, Z y T.
!>          LDB >= max(P,N).
!>

TAUB

!>          TAUB es un array COMPLEX*16, dimensión (min(P,N))
!>          Los factores escalares de los reflectores elementales, como se devuelve
!>          por DGGRQF.
!>

WORK

!>          WORK es un array COMPLEX*16, dimensión (LWORK)
!>

LWORK

!>          LWORK es ENTERO
!>          La dimensión del array WORK, LWORK >= max(N,M,P)**2.
!>

RWORK

!>          RWORK es un array DOUBLE PRECISION, dimensión (max(N,M,P))
!>

RESULT

!>          RESULT es un array DOUBLE PRECISION, dimensión (4)
!>          Las razones de prueba:
!>            RESULT(1) = norm( R - Q'*A ) / ( MAX(M,N)*norm(A)*ULP)
!>            RESULT(2) = norm( T*Z - Q'*B ) / (MAX(P,N)*norm(B)*ULP)
!>            RESULT(3) = norm( I - Q'*Q ) / ( M*ULP )
!>            RESULT(4) = norm( I - Z'*Z ) / ( P*ULP )
!>
