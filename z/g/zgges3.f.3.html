ZGGES3 calcula los valores propios, la forma de Schur, y opcionalmente, la matriz de vectores de Schur para matrices GE (algoritmo en bloques)

Documentación de la función/subrutina

subrutina zgges3 (character jobvsl, character jobvsr, character sort, external selctg, integer n, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( ldb, * ) b, integer ldb, integer sdim, complex*16, dimension( * ) alpha, complex*16, dimension( * ) beta, complex*16, dimension( ldvsl, * ) vsl, integer ldvsl, complex*16, dimension( ldvsr, * ) vsr, integer ldvsr, complex*16, dimension( * ) work, integer lwork, double precision, dimension( * ) rwork, logical, dimension( * ) bwork, integer info)

ZGGES3 calcula para un par de matrices complejas no simétricas de N por N (A,B), los valores propios generalizados, la forma de Schur generalizada (S, T), y opcionalmente, los vectores de Schur izquierdos y/o derechos (VSL y VSR). Esto da la factorización de Schur generalizada

Propósito:

!>
!> ZGGES3 calcula para un par de matrices complejas no simétricas de N
!> por N (A,B), los valores propios generalizados, la forma de Schur generalizada
!> (S, T), y opcionalmente, los vectores de Schur izquierdos y/o derechos (VSL
!> y VSR). Esto da la factorización de Schur generalizada
!>
!>         (A,B) = ( (VSL)*S*(VSR)**H, (VSL)*T*(VSR)**H )
!>
!> donde (VSR)**H es la transpuesta conjugada de VSR.
!>
!> Opcionalmente, también ordena los valores propios de modo que un clúster
!> seleccionado de valores propios aparezca en los bloques diagonales
!> principales de la matriz triangular superior S y la matriz triangular superior T.
!> Las columnas principales de VSL y VSR forman entonces una base unitaria para
!> los subespacios izquierdos y derechos correspondientes (subespacios que
!> decrecen).
!>
!> (Si solo se necesitan los valores propios generalizados, use el controlador
!> ZGGEV en su lugar, que es más rápido.)
!>
!> Un valor propio generalizado para un par de matrices (A,B) es un escalar w
!> o una relación alpha/beta = w, tal que A - w*B es singular. Se representa
!> usualmente como el par (alpha,beta), ya que hay una interpretación razonable
!> para beta=0, e incluso para ambos siendo cero.
!>
!> Un par de matrices (S,T) está en forma de Schur generalizada compleja si S
!> y T son triangulares superiores y, además, los elementos diagonales de T
!> son números reales no negativos.
!>

Parámetros

JOBVSL 
!>          JOBVSL es CHARACTER*1
!>          = 'N':  no calcula los vectores de Schur izquierdos;
!>          = 'V':  calcula los vectores de Schur izquierdos.
!>

JOBVSR

!>          JOBVSR es CHARACTER*1
!>          = 'N':  no calcula los vectores de Schur derechos;
!>          = 'V':  calcula los vectores de Schur derechos.
!>

SORT

!>          SORT es CHARACTER*1
!>          Especifica si se ordenan o no los valores propios en la
!>          diagonal de la forma de Schur generalizada.
!>          = 'N':  Los valores propios no se ordenan;
!>          = 'S':  Los valores propios se ordenan (ver SELCTG).
!>

SELCTG

!>          SELCTG es una FUNCIÓN LOGICA de dos argumentos COMPLEX*16
!>          SELCTG debe ser declarada EXTERNA en la subrutina llamante.
!>          Si SORT = 'N', SELCTG no se referencia.
!>          Si SORT = 'S', SELCTG se usa para seleccionar valores propios que se
!>          ordenarán en la parte superior izquierda de la forma de Schur.
!>          Un valor propio ALPHA(j)/BETA(j) se selecciona si
!>          SELCTG(ALPHA(j),BETA(j)) es verdadero.
!>
!>          Tenga en cuenta que un valor propio complejo seleccionado puede que ya no
!>          cumpla SELCTG(ALPHA(j),BETA(j)) = .TRUE. después de ordenarlo, ya que
!>          el ordenamiento puede cambiar el valor de los valores propios complejos
!>          (especialmente si el valor propio está mal condicionado), en cuyo caso
!>          INFO se establece en N+2 (Ver INFO a continuación).
!>

N

!>          N es INTEGER
!>          El orden de las matrices A, B, VSL y VSR. N >= 0.
!>

A

!>          A es un array COMPLEX*16, dimensión (LDA, N)
!>          En la entrada, la primera de las matrices del par.
!>          En la salida, A ha sido sobrescrita por su forma de Schur
!>          generalizada S.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal de A. LDA >= max(1,N).
!>

B

!>          B es un array COMPLEX*16, dimensión (LDB, N)
!>          En la entrada, la segunda de las matrices del par.
!>          En la salida, B ha sido sobrescrita por su forma de Schur
!>          generalizada T.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal de B. LDB >= max(1,N).
!>

SDIM

!>          SDIM es INTEGER
!>          Si SORT = 'N', SDIM = 0.
!>          Si SORT = 'S', SDIM = número de valores propios (después de ordenar)
!>          para los cuales SELCTG es verdadero.
!>

ALPHA

!>          ALPHA es un array COMPLEX*16, dimensión (N)
!>

BETA

!>          BETA es un array COMPLEX*16, dimensión (N)
!>          En la salida, ALPHA(j)/BETA(j), j=1,...,N, serán los
!>          valores propios generalizados. ALPHA(j), j=1,...,N y BETA(j),
!>          j=1,...,N son las diagonales de la forma de Schur compleja (A,B)
!>          devuelta por ZGGES3. Los BETA(j) serán reales no negativos.
!>
!>          Nota: los cocientes ALPHA(j)/BETA(j) pueden desbordarse o
!>          subdesbordarse fácilmente, y BETA(j) puede ser incluso cero.
!>          Por lo tanto, el usuario debe evitar calcular ingenuamente la
!>          relación alpha/beta.
!>          Sin embargo, ALPHA tendrá una magnitud menor o igual y usualmente
!>          comparable a norm(A), y BETA siempre menor o igual y usualmente
!>          comparable a norm(B).
!>

VSL

!>          VSL es un array COMPLEX*16, dimensión (LDVSL,N)
!>          Si JOBVSL = 'V', VSL contendrá los vectores de Schur izquierdos.
!>          No se referencia si JOBVSL = 'N'.
!>

LDVSL

!>          LDVSL es INTEGER
!>          La dimensión principal de la matriz VSL. LDVSL >= 1, y
!>          si JOBVSL = 'V', LDVSL >= N.
!>

VSR

!>          VSR es un array COMPLEX*16, dimensión (LDVSR,N)
!>          Si JOBVSR = 'V', VSR contendrá los vectores de Schur derechos.
!>          No se referencia si JOBVSR = 'N'.
!>

LDVSR

!>          LDVSR es INTEGER
!>          La dimensión principal de la matriz VSR. LDVSR >= 1, y
!>          si JOBVSR = 'V', LDVSR >= N.
!>

WORK

!>          WORK es un array COMPLEX*16, dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK. LWORK >= MAX(1,2*N)
!>          Para un buen rendimiento, LWORK debe ser generalmente mayor.
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo del array WORK, devuelve
!>          este valor como la primera entrada del array WORK, y XERBLA no emite
!>          ningún mensaje de error relacionado con LWORK.
!>

RWORK

!>          RWORK es un array DOUBLE PRECISION, dimensión (8*N)
!>

BWORK

!>          BWORK es un array LOGICAL, dimensión (N)
!>          No se referencia si SORT = 'N'.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa

NAME

            
zgges3 - esta rutina invoca a subrutinas de alto nivel para calcular los valores propios generalizados de un par de matrices complejas generales N x N (A, B).

        

        

            
SYNOPSIS

            
 Call ZGGES3( JOBVSL, JOBVSR, SORT, SELECT, N, A, LDA, B, LDB,
            &     LDVSL, VSL, LDVSL, VS R, LDVSR, ALPHA, BETA, WORK,
            &     LWORK, RWORK, BWORK, INFO )
            

        

        

            
Function/Subroutine Documentation

            

                
JOBVSL

                

                    
CHARACTER*1.  Input.
Specifies whether to compute the left Schur vector.
  JOBVSL = 'N': do not compute the left Schur vector.
  JOBVSL = 'V': compute the left Schur vector.

                

                
JOBVSR

                

                    
CHARACTER*1.  Input.
Specifies whether to compute the right Schur vector.
  JOBVSR = 'N': do not compute the right Schur vector.
  JOBVSR = 'V': compute the right Schur vector.

                

                
SORT

                

                    
CHARACTER*1.  Input.
Specifies whether or not to reorder the matrices A and B after
computation of the generalized Schur form.
  SORT = 'N': do not reorder.
  SORT = 'S': reorder according to the criterion specified by
              SELECT.

                

                
SELECT

                

                    
LOGICAL FUNCTION of (ALPHA, BETA).  Input.
If SORT = 'S', SELECT is used to specify the criterion that
determines the order of the eigenvalues in the generalized Schur
form. For each eigenvalue lambda = ALPHA(i) / BETA(i), SELECT
is called:
  If SELECT(lambda) is true, then the i-th eigenvalue is selected
  (urged to end up in the top left partition of the generalized
  Schur form).
If SORT = 'N', the array SELECT is not accessed.

                

                
N

                

                    
INTEGER.  Input.
The order of the matrices A and B.  N >= 0.

                

                
A

                

                    
COMPLEX*16       array, dimension (LDA, k).
On entry, the N-by-N matrix A.
On exit, A is overwritten by its generalized Schur form.
k = max(N,N)

                

                
LDA

                

                    
INTEGER.  Input.
The leading dimension of A.

                

                
B

                

                    
COMPLEX*16       array, dimension (LDB, k).
On entry, the N-by-N matrix B.
On exit, B is overwritten by its generalized Schur form.
k = max(N,N)

                

                
LDB

                

                    
INTEGER.  Input.
The leading dimension of B.

                

                
VSL

                

                    
COMPLEX*16       array, dimension (LDVSL, k).
On exit, if JOBVSL = 'V', VSL contains the left Schur vectors.
k = N

                

                
LDVSL

                

                    
INTEGER.  Input.
The leading dimension of the array VSL.

                

                
VSR

                

                    
COMPLEX*16       array, dimension (LDVSR, k).
On exit, if JOBVSR = 'V', VSR contains the right Schur vectors.
k = N

                

                
LDVSR

                

                    
INTEGER.  Input.
The leading dimension of the array VSR.

                

                
ALPHA

                

                    
COMPLEX*16       array, dimension (N).
On exit, ALPHA contains the complex eigenvalues.

                

                
BETA

                

                    
COMPLEX*16       array, dimension (N).
On exit, BETA contains the complex eigenvalues.

                

                
WORK

                

                    
COMPLEX*16       array, dimension (LWORK).
On exit, WORK(1) contains the minimum required value of LWORK.

                

                
LWORK

                

                    
INTEGER.  Input.
The dimension of the array WORK.
  LWORK = -1.  Then the minimum dimensions for the arrays A, B, VSL,
             VSR and the re- Nyquist frequency computed.
             The second dimension of A and B are returned in A(1,2)
             and B(1,2) respectively.
             The minimum dimension of the array VSL is returned in
             VSL(1,2).
             The minimum dimension of the array VSR is returned in
             VSR(1,2).
  If LWORK is sufficiently large, it returns the workspace required
  to perform the operation.
  LWORK >= max(N, 2*N, 6*N). For the optimal performance we need LWORK = N*(N+6).

                

                
RWORK

                

                    
DOUBLE PRECISION array, dimension (8*N).
             Real workspace array.

                

                
BWORK

                

                    
LOGICAL array, dimension (N).
             Logical workspace array. If SORT = 'S', then the user must
             provide LOGICAL array BWORK. The i-th entry of BWORK must be
             set to .TRUE. if the i-th eigenvalue is to be selected.
             If SORT = 'N', then BWORK is not accessed.

                

                
INFO

                

                    
INTEGER.  Output.
          = 0:  successful exit
          < 0:  if INFO = -i, the i-th argument had an illegal value.
          > 0:  if INFO = i, then the QZ iteration failed.  No
                definitive information about the location of deficiency
                is provided.
                =1:  Split block failed in ZGEQPF.
                =2:  Other than QZ iteration failed in ZLAQZ0.
                =3:  Reordering failed in ZTGSEN.

                

            

            
Details

            
INFO > 0
          > 0:  The QZ iteration has converged.  The Schur form is available
                but it is not the one requested.  ALPHA(j) and BETA(j)
                should be correct for j=1, ..., N.  INFO indicates the
                first index J for which ALPHA(j) and BETA(j) could not be
                correctly computed.
                Thus the matrix partitions are:
                A = [ A11 A12 ] B = [ B11 B12 ]
                    [  0  A22 ]     [  0  B22 ]
                where A11 and B11 are J-by-J.
                The eigenvalues of the original problem are those which
                would have been obtained by combining the eigenvalues of
                the pair (A11, B11) and (A22, B22).
                The pairs of eigenvalues are:
                (ALPHA(J), BETA(J)) for J = 1, ..., INFO
                (ALPHA(J), BETA(J)) for J = INFO + 1, ..., N

          <= 0:  The QZ iteration failed. The problem may have an
                integer overflow.
                INFO = -k: The k-th argument had an illegal value.
                INFO = N+1: Other than QZ iteration failed in ZLAQZ0.
                INFO = N+2: After reordering, roundoff changed values of
                      some complex eigenvalues so that leading
                      eigenvalues in the Generalized Schur form no
                      longer satisfy SELCTG=.TRUE. This could also
                      be caused due to scaling.
                INFO = N+3: reordering failed in ZTGSEN.
