subroutine zgesvxx (character fact, character trans, integer n, integer nrhs, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( ldaf, * ) af, integer ldaf, integer, dimension( * ) ipiv, character equed, double precision, dimension( * ) r, double precision, dimension( * ) c, complex*16, dimension( ldb, * ) b, integer ldb, complex*16, dimension( ldx , * ) x, integer ldx, double precision rcond, double precision rpvgrw, double precision, dimension( * ) berr, integer n_err_bnds, double precision, dimension( nrhs, * ) err_bnds_norm, double precision, dimension( nrhs, * ) err_bnds_comp, integer nparams, double precision, dimension( * ) params, complex*16, dimension( * ) work, double precision, dimension( * ) rwork, integer info)

ZGESVXX calcula la solución al sistema de ecuaciones lineales A * X = B para matrices GE

Propósito:

!>
!>    ZGESVXX utiliza la factorización LU para calcular la solución a un
!>    sistema de ecuaciones lineales complex*16  A * X = B,  donde A es una
!>    matriz N por N y X y B son matrices N por NRHS.
!>
!>    Si se solicita, se devuelven límites de error tanto normados como
!>    componentes máximos. ZGESVXX devolverá una solución con un error
!>    garantizado diminuto (O(eps) donde eps es la precisión de la máquina de
!>    trabajo) a menos que la matriz sea muy mal condicionada, en cuyo caso
!>    se devuelve una advertencia. También se calculan y devuelven los
!>    números de condición relevantes.
!>
!>    ZGESVXX acepta factorizaciones y factores de 
¡>    equilibración proporcionados por el usuario; consulte las
!>    definiciones de las opciones FACT y EQUED.
!>    Resolver con refinamiento y usar una factorización de una llamada
!>    anterior a ZGESVXX también producirá una solución con errores de
!>    O(eps) o advertencias, pero no podemos hacer esa afirmación para
!>    factores de factorización y 
¡>    equilibración proporcionados por el usuario en general si difieren de lo
!>    que ZGESVXX produciría por sí mismo.
!>

Descripción:

!>
!>    Se realizan los siguientes pasos:
!>
!>    1. Si FACT = 'E', se calculan factores de escala de doble precisión para 
¡>    equilibrar el sistema:
!>
!>      TRANS = 'N':  diag(R)*A*diag(C)     *inv(diag(C))*X = diag(R)*B
!>      TRANS = 'T': (diag(R)*A*diag(C))**T *inv(diag(R))*X = diag(C)*B
!>      TRANS = 'C': (diag(R)*A*diag(C))**H *inv(diag(R))*X = diag(C)*B
!>
!>    Si el sistema se equilibrará o no depende del escalado de la matriz A, 
¡>    pero si se utiliza la 
¡>    equilibración, A se sobrescribe con diag(R)*A*diag(C) y B con
!>    diag(R)*B (si TRANS='N') o diag(C)*B (si TRANS = 'T' o 'C').
!>
!>    2. Si FACT = 'N' o 'E', se utiliza la descomposición LU para factorizar
!>    la matriz A (después de la 
¡>    equilibración si FACT = 'E') como
!>
!>      A = P * L * U,
!>
!>    donde P es una matriz de permutación, L es una matriz triangular inferior
!>    unitaria y U es triangular superior.
!>
!>    3. Si algún U(i,i)=0, de modo que U sea exactamente singular, entonces la
!>    subrutina finaliza con INFO = i. De lo contrario, la forma factorizada de A
!>    se utiliza para estimar el número de condición de la matriz A (ver
!>    argumento RCOND). Si la inversa del número de condición es menor que la
!>    precisión de la máquina, la subrutina continúa resolviendo para X
!>    y calculando los límites de error como se describe a continuación.
!>
!>    4. El sistema de ecuaciones se resuelve para X utilizando la forma factorizada
!>    de A.
!>
!>    5. Por defecto (a menos que PARAMS(LA_LINRX_ITREF_I) se establezca en cero),
!>    la subrutina utilizará refinamiento iterativo para intentar obtener un
!>    error y límites de error pequeños. El refinamiento calcula el residual
!>    al menos con el doble de la precisión de trabajo.
!>
!>    6. Si se utilizó 
¡>    equilibración, la matriz X se premultiplica por
!>    diag(C) (si TRANS = 'N') o diag(R) (si TRANS = 'T' o 'C') para que
!>    resuelva el sistema original antes de la 
¡>    equilibración.
!> 
!>     Algunos parámetros opcionales están agrupados en la matriz PARAMS. Estas
!>     configuraciones determinan cómo se realiza el refinamiento, pero a menudo
!>     los valores predeterminados son aceptables. Si los valores predeterminados son
!>     aceptables, los usuarios pueden pasar NPARAMS = 0, lo que evita que el código
!>     fuente acceda al argumento PARAMS.
!>

Parámetros

FACT 
!>          FACT es CHARACTER*1
!>     Especifica si la forma factorizada de la matriz A se proporciona en la
!>     entrada, y si no, si la matriz A debe ser 
¡>    equilibrada antes de ser factorizada.
!>       = 'F':  En la entrada, AF y IPIV contienen la forma factorizada de A.
!>               Si EQUED no es 'N', la matriz A ha sido 
¡>    equilibrada con factores de escala dados por R y C.
!>               A, AF y IPIV no se modifican.
!>       = 'N':  La matriz A se copiará a AF y se factorizará.
!>       = 'E':  La matriz A se 
¡>    equilibrará si es necesario, luego
!>               se copiará a AF y se factorizará.
!>

TRANS

!>          TRANS es CHARACTER*1
!>     Especifica la forma del sistema de ecuaciones:
!>       = 'N':  A * X = B     (Sin transposición)
!>       = 'T':  A**T * X = B  (Transpuesta)
!>       = 'C':  A**H * X = B  (Transpuesta conjugada)
!>

N

!>          N es INTEGER
!>     El número de ecuaciones lineales, es decir, el orden de la
!>     matriz A.  N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>     El número de lados derechos, es decir, el número de columnas
!>     de las matrices B y X.  NRHS >= 0.
!>

A

!>          A es un array COMPLEX*16, de dimensión (LDA,N)
!>     En la entrada, la matriz N por N A. Si FACT = 'F' y EQUED no
!>     es 'N', entonces A ha sido 
¡>    equilibrada con los factores de escala en R y/o C.
!>     A no se modifica si FACT = 'F' o
!>     'N', o si FACT = 'E' y EQUED = 'N' en la salida.
!>
!>     En la salida, si EQUED .ne. 'N', A se escala de la siguiente manera:
!>     EQUED = 'R':  A := diag(R) * A
!>     EQUED = 'C':  A := A * diag(C)
!>     EQUED = 'B':  A := diag(R) * A * diag(C).
!>

LDA

!>          LDA es INTEGER
!>     La dimensión principal del array A.  LDA >= max(1,N).
!>

AF

!>          AF es un array COMPLEX*16, de dimensión (LDAF,N)
!>     Si FACT = 'F', entonces AF es un argumento de entrada y en la entrada
!>     contiene los factores L y U de la factorización
!>     A = P*L*U tal como fue calculada por ZGETRF. Si EQUED .ne. 'N', entonces
!>     AF es la forma factorizada de la matriz 
¡>    equilibrada A.
!>
!>     Si FACT = 'N', entonces AF es un argumento de salida y en la salida
!>     devuelve los factores L y U de la factorización A = P*L*U
!>     de la matriz original A.
!>
!>     Si FACT = 'E', entonces AF es un argumento de salida y en la salida
!>     devuelve los factores L y U de la factorización A = P*L*U
!>     de la matriz 
¡>    equilibrada A (ver la descripción de A para
!>     la equilibración).
!>

LDAF

!>          LDAF es INTEGER
!>     La dimensión principal del array AF.  LDAF >= max(1,N).
!>

IPIV

!>          IPIV es un array INTEGER, de dimensión (N)
!>     Si FACT = 'F', entonces IPIV es un argumento de entrada y en la entrada
!>     contiene las pivotes de la permutación de la factorización de A.
!>     Si FACT = 'N' o 'E', entonces IPIV es un argumento de salida y en la
!>     salida contiene las pivotes de la permutación de la factorización de A.
!>     El pivote I contiene el factor de la fila I con el elemento más grande en
!>     la columna K, donde K es la columna actual.
!>

EQUED

!>          EQUED es CHARACTER*1
!>     Especifica la 
¡>    equilibración de la matriz A.
!>     = 'N': Ninguna 
¡>    equilibración ha sido realizada.
!>     = 'R': La matriz A ha sido 
¡>    equilibrada por la izquierda (ver A).
!>     = 'C': La matriz A ha sido 
¡>    equilibrada por la derecha (ver A).
!>     = 'B': La matriz A ha sido 
¡>    equilibrada por la izquierda y por la derecha (ver A).
!>     Los factores de 
¡>    equilibración R y C están en los arrays R y C.
!>

R

!>          R es un array DOUBLE PRECISION, de dimensión (*)
!>     Si EQUED = 'R' o 'B', R contiene los factores de 
¡>    escala del lado izquierdo para la 
¡>    equilibración de A. R(i) = 1/norm(A(i,:)).
!>

C

!>          C es un array DOUBLE PRECISION, de dimensión (*)
!>     Si EQUED = 'C' o 'B', C contiene los factores de 
¡>    escala del lado derecho para la 
¡>    equilibración de A. C(i) = 1/norm(A(:,i)).
!>

B

!>          B es un array COMPLEX*16, de dimensión (LDB,NRHS)
!>     En la entrada, el N-by-NRHS matriz de lado derecho B.
!>     En la salida, si se utilizó 
¡>    equilibración, B se sobrescribe con diag(R)*B (si TRANS = 'N') o
!>    diag(C)*B (si TRANS = 'T' o 'C').
!>

LDB

!>          LDB es INTEGER
!>     La dimensión principal del array B.  LDB >= max(1,N).
!>

X

!>          X es un array COMPLEX*16, de dimensión (LDX,NRHS)
!>     En la salida, la solución N-by-NRHS de la matriz A*X = B.
!>     Si se utilizó 
¡>    equilibración, X se premultiplica por diag(C) (si TRANS = 'N') o
!>    diag(R) (si TRANS = 'T' o 'C') para que resuelva el sistema original.
!>

LDX

!>          LDX es INTEGER
!>     La dimensión principal del array X. LDX >= max(1,N).
!>

RCOND

!>          RCOND es DOUBLE PRECISION
!>     Una estimación del recíproco del número de condición de la matriz,
!>     aproximadamente RCOND = 1/cond(A).
!>

RPVGRW

!>          RPVGRW es DOUBLE PRECISION
!>     La ratio del número de condición inverso estimado por el número de
!>     condición estimado. RPGRW = RPVGRW * RCOND. RPVGRW es aproximadamente
!>     1 en la mayoría de los casos, pero puede ser grande si A es mal
!>     condicionada.
!>

BERR

!>          BERR es un array DOUBLE PRECISION, de dimensión (*)
!>     En la salida, BERR(j) contiene una estimación del error absoluto
!>     para la solución X(:,j), que es norm(X(:,j) - Xorig(:,j)) / norm(X(:,j))
!>     donde Xorig es la solución exacta.
!>

N_ERR_BNDS

!>          N_ERR_BNDS es INTEGER
!>     Número de errores límite computados en ERR_BNDS_NORM y
!>     ERR_BNDS_COMP.
!>

ERR_BNDS_NORM

!>          ERR_BNDS_NORM es un array DOUBLE PRECISION, de dimensión
!>     (NRHS, N_ERR_BNDS)
!>     En la salida, las estimaciones de los límites de error normados para
!>     cada lado derecho j:
!>     ERR_BNDS_NORM(j,1) = norm(X(:,j) - Xorig(:,j)) / norm(X(:,j))
!>     ERR_BNDS_NORM(j,2) = norm(X(:,j) - Xorig(:,j)) / norm(Xorig(:,j))
!>

ERR_BNDS_COMP

!>          ERR_BNDS_COMP es un array DOUBLE PRECISION, de dimensión
!>     (NRHS, N_ERR_BNDS)
!>     En la salida, las estimaciones de los límites de error por componentes
!>     para cada lado derecho j:
!>     ERR_BNDS_COMP(j,1) = max(|X(i,j) - Xorig(i,j)| / |Xorig(i,j)|)
!>     ERR_BNDS_COMP(j,2) = max(|X(i,j) - Xorig(i,j)| / |X(i,j)|)
!>

NPARAMS

!>          NPARAMS es INTEGER
!>     El número de parámetros en el array PARAMS. Si NPARAMS = 0,
!>     entonces el array PARAMS no se utiliza.
!>

PARAMS

!>          PARAMS es un array DOUBLE PRECISION, de dimensión (NPARAMS)
!>     Parámetros opcionales. Si NPARAMS = 0, entonces este argumento no se
!>     utiliza. Los parámetros son:
!>     PARAMS(1) = LA_LINRX_ITREF_I: número de iteraciones de refinamiento (0 si
!>     no se desea refinamiento).
!>     PARAMS(2) = LA_LINRX_RCOND: control de convergencia para el número de
!>     condición.
!>     PARAMS(3) = LA_LINRX_TYPE: tipo de error bound a calcular.
!>     PARAMS(4) = LA_LINRX_NORM: tipo de norma a utilizar.
!>     PARAMS(5) = LA_LINRX_OVFL: control de desbordamiento.
!>

WORK

!>          WORK es un array COMPLEX*16, de dimensión (*)
!>     Array de trabajo. El tamaño del array se determina al llamar a esta
!>     subrutina.
!>

RWORK

!>          RWORK es un array DOUBLE PRECISION, de dimensión (*)
!>     Array de trabajo. El tamaño del array se determina al llamar a esta
!>     subrutina.
!>

INFO

!>          INFO es INTEGER
!>     = 0:  Ejecución correcta.
!>     > 0: Si INFO = k, y k > 0, entonces U(k,k) es cero. La factorización
!>          ha sido completada, pero la matriz es singular.  No se puede
!>          calcular el número de condición ni los límites de error.
!>     < 0: Si INFO = -k, entonces el k-ésimo argumento no válido se ha
!>          detectado en la entrada. Un 1 indica que el k-ésimo argumento
!>          no válido.
!>

! ZGESVX documentation 
SUBROUTINE ZGESVX( FACT, TRANS, EQUED, N, NB, A, LDA, AF, LDAF, IPIV, 
     &                  EQUED, R, C, B, LDB, X, LDX, RCOND, RPVGRW, BERR, 
     &                  N_ERR_BNDS, ERR_BNDS_NORM, ERR_BNDS_COMP, NPARAMS, 
     &                  PARAMS, WORK, INFO )

ZGESVX performs a general dense LU factorization of a complex general matrix A and solves a complex general system of linear equations A*X = B. It also computes the condition number and error bounds for the system.

The driver routine ZGESVX first equilibrates the matrix if necessary, then applies a full set of levels of the partial Pivoting LU decomposition, solves the system of equations, and then refines the solution and computes error bounds.

Arguments

FACT
FACT is CHARACTER*1
 SPECIFIES WHETHER TO FACTORIZE THE MATRIX.
       = 'F': On entry, AF and IPIV contain the TU factorization of A.
              On exit, AF and IPIV are unchanged.
       = 'N': The driver recalculates the factorization of A.
       = 'E': The driver equilibrates the matrix A first.
              On entry, AF and IPIV contain the L*U factorization of
              the equilibrated matrix A.
TRANS
TRANS is CHARACTER*1
 SPECIFIES THE TYPE OF SYSTEM TO BE SOLVED.
       = 'N': Solve A*X = B         (No transpose)
       = 'T': Solve A**T * X = B   (Transpose)
       = 'C': Solve A**H * X = B   (Conjugate transpose)
EQUED
EQUED is CHARACTER*1
 SPECIFIES THE TYPE OF EQUILIBRATION USED.
       = 'N': No equilibration.
       = 'R': Row equilibration.
       = 'C': Column equilibration.
       = 'B': Both row and column equilibration.
       EQUED is an input argument if FACT = 'F'; otherwise, it is an
       output argument.
N
N is INTEGER
 The order of the matrix A.  N >= 0.
NB
NB is INTEGER
 The blocking factor used in the factorization.  NB >= 1.
A
A is COMPLEX*16 array, dimension (LDA,N)
 On entry, the array A may be factorized or not.
       If FACT = 'F', A is not used.
       If FACT = 'N', A contains the matrix A to be factorized.
       If FACT = 'E', A contains the equilibrated matrix A.
       On exit, if FACT = 'N', A contains the factors L and U from the
       factorization A = P*L*U; the factor L is stored below the diagonal
       in the strictly lower triangular part of the array, and the unit
       upper triangular factor U is stored on and above the diagonal of
       the array.
       If FACT = 'E', A contains the factors L and U from the
       factorization A = P*L*U; the factor L is stored below the diagonal
       in the strictly lower triangular part of the array, and the unit
       upper triangular factor U is stored on and above the diagonal of
       the array.
LDA
LDA is INTEGER
 The leading dimension of the array A.  LDA >= max(1,N).
AF
AF is COMPLEX*16 array, dimension (LDAF,N)
 On entry,
       if FACT = 'F', AF contains the factored matrix A.
       if FACT = 'N', AF is not accessed.
       if FACT = 'E', AF contains the factored equilibrated matrix A.
       On exit,
       if FACT = 'F', AF is unchanged.
       if FACT = 'N', AF contains the factored matrix A.
       if FACT = 'E', AF contains the factored equilibrated matrix A.
       (The form of the equilibrated matrix is defined by EQUED.)
LDAF
LDAF is INTEGER
 The leading dimension of the array AF.  LDAF >= max(1,N).
IPIV
IPIV is INTEGER array, dimension (N)
 If FACT = 'F', then IPIV is an input argument and on entry
       contains the pivot indices from the factorization A = P*L*U
       as computed by ZGETRF; row i of the matrix was interchanged
       with row IPIV(i).

       If FACT = 'N', then IPIV is an output argument and on exit
       contains the pivot indices from the factorization A = P*L*U
       of the original matrix A.

       If FACT = 'E', then IPIV is an output argument and on exit
       contains the pivot indices from the factorization A = P*L*U
       of the equilibrated matrix A.
EQUED
EQUED is CHARACTER*1
 Specifies the form of equilibration that was done.
       = 'N':  No equilibration (always true if FACT = 'N').
       = 'R':  Row equilibration, i.e., A has been premultiplied by
               diag(R).
       = 'C':  Column equilibration, i.e., A has been postmultiplied
               by diag(C).
       = 'B':  Both row and column equilibration, i.e., A has been
               replaced by diag(R) * A * diag(C).
       EQUED is an input argument if FACT = 'F'; otherwise, it is an
       output argument.
R
R is DOUBLE PRECISION array, dimension (N)
 The row scale factors for A.  If EQUED = 'R' or 'B', A is
       multiplied on the left by diag(R); if EQUED = 'N' or 'C', R
       is not accessed.  R is an input argument if FACT = 'F';
       otherwise, R is an output argument.  If FACT = 'F' and
       EQUED = 'R' or 'B', each element of R must be positive.
       If R is output, each element of R is a power of the radix.
       If R is input, each element of R should be a power of the radix
       to ensure a reliable solution and error estimates. Scaling by
       powers of the radix does not cause rounding errors unless the
       result underflows or overflows. Rounding errors during scaling
       lead to refining with a matrix that is not equivalent to the
       input matrix, producing error estimates that may not be
       reliable.
C
C is DOUBLE PRECISION array, dimension (N)
 The column scale factors for A.  If EQUED = 'C' or 'B', A is
       multiplied on the right by diag(C); if EQUED = 'N' or 'R', C
       is not accessed.  C is an input argument if FACT = 'F';
       otherwise, C is an output argument.  If FACT = 'F' and
       EQUED = 'C' or 'B', each element of C must be positive.
       If C is output, each element of C is a power of the radix.
       If C is input, each element of C should be a power of the radix
       to ensure a reliable solution and error estimates. Scaling by
       powers of the radix does not cause rounding errors unless the
       result underflows or overflows. Rounding errors during scaling
       lead to refining with a matrix that is not equivalent to the
       input matrix, producing error estimates that may not be
       reliable.
B
B is COMPLEX*16 array, dimension (LDB,NRHS)
 On entry, the N-by-NRHS right hand side matrix B.
       On exit,
       if EQUED = 'N', B is not modified;
       if TRANS = 'N' and EQUED = 'R' or 'B', B is overwritten by
              diag(R)*B;
       if TRANS = 'T' or 'C' and EQUED = 'C' or 'B', B is
              overwritten by diag(C)*B.
LDB
LDB is INTEGER
 The leading dimension of the array B.  LDB >= max(1,N).
X
X is COMPLEX*16 array, dimension (LDX,NRHS)
 If INFO = 0, the N-by-NRHS solution matrix X to the original
       system of equations.  Note that A and B are modified on exit
       if EQUED .ne. 'N', and the solution to the equilibrated system is
       inv(diag(C))*X if TRANS = 'N' and EQUED = 'C' or 'B', or
       inv(diag(R))*X if TRANS = 'T' or 'C' and EQUED = 'R' or 'B'.
LDX
LDX is INTEGER
 The leading dimension of the array X.  LDX >= max(1,N).
RCOND
RCOND is DOUBLE PRECISION
 Reciprocal scaled condition number.  This is an estimate of the
       reciprocal Skeel condition number of the matrix A after
       equilibration (if done).  If this is less than the machine
       precision (in particular, if it is zero), the matrix is singular
       to working precision.  Note that the error may still be small even
       if this number is very small and the matrix appears ill-
       conditioned.
RPVGRW
RPVGRW is DOUBLE PRECISION
 Reciprocal pivot growth.  On exit, this contains the reciprocal
       pivot growth factor norm(A)/norm(U). The infinity norm is used.  If this is much less than 1, then the stability of
       the LU factorization of the (equilibrated) matrix A could be poor.
       This also means that the solution X, estimated condition numbers,
       and error bounds could be unreliable. If factorization fails with
       0<INFO<=N, then this contains the reciprocal pivot growth factor
       for the leading INFO columns of A.  In ZGESVX, this quantity is
       returned in WORK(1).
BERR
BERR is DOUBLE PRECISION array, dimension (NRHS)
 Componentwise relative backward error.  This is the
       componentwise relative backward error of each solution vector X(j)
       (i.e., the smallest relative change in any element of A or B that
       makes X(j) an exact solution).
N_ERR_BNDS
N_ERR_BNDS is INTEGER
 Number of error bounds to return for each right hand side
       and each type (normwise or componentwise).  See ERR_BNDS_NORM and
       ERR_BNDS_COMP below.
ERR_BNDS_NORM
ERR_BNDS_NORM is DOUBLE PRECISION array, dimension (NRHS, N_ERR_BNDS)
 For each right-hand side, this array contains information about
       various error bounds and condition numbers corresponding to the
       normwise relative error, which is defined as follows:

       Normwise relative error in the ith solution vector:
               max_j (abs(XTRUE(j,i) - X(j,i)))
              ------------------------------
                    max_j abs(X(j,i))
