subroutine zgehrd (integer n, integer ilo, integer ihi, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( * ) tau, complex*16, dimension( * ) work, integer lwork, integer info)

ZGEHRD

Propósito:

!>
!> ZGEHRD reduce una matriz general compleja A a la forma de Hessenberg superior H
!> mediante una transformación de similaridad unitaria:  Q**H * A * Q = H .
!>

Parámetros

N 
!>          N es ENTERO
!>          El orden de la matriz A.  N >= 0.
!>

ILO

!>          ILO es ENTERO
!>

IHI

!>          IHI es ENTERO
!>
!>          Se asume que A ya es triangular superior en las filas
!>          y columnas 1:ILO-1 e IHI+1:N. ILO e IHI normalmente
!>          son establecidos por una llamada previa a ZGEBAL; de lo contrario,
!>          deberían ser establecidos a 1 y N respectivamente. Ver Detalles Adicionales.
!>          1 <= ILO <= IHI <= N, si N > 0; ILO=1 e IHI=0, si N=0.
!>

A

!>          A es un array COMPLEX*16, dimension (LDA,N)
!>          En la entrada, la matriz general N-por-N a reducir.
!>          En la salida, la triángulo superior y la primera subdiagonal de A
!>          se sobrescriben con la matriz de Hessenberg superior H, y los
!>          elementos debajo de la primera subdiagonal, con el array TAU,
!>          representan la matriz unitaria Q como un producto de
!>          reflejos elementales. Ver Detalles Adicionales.
!>

LDA

!>          LDA es ENTERO
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

TAU

!>          TAU es un array COMPLEX*16, dimension (N-1)
!>          Los factores escalares de los reflejos elementales (ver Detalles
!>          Adicionales). Los elementos 1:ILO-1 e IHI:N-1 de TAU se establecen
!>          a cero.
!>

WORK

!>          WORK es un array COMPLEX*16, dimension (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es ENTERO
!>          La longitud del array WORK.  LWORK >= max(1,N).
!>          Para un buen rendimiento, LWORK debería ser generalmente mayor.
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo del array WORK, devuelve
!>          este valor como la primera entrada del array WORK, y XERBLA no emite ningún
!>          mensaje de error relacionado con LWORK.
!>

INFO

!>          INFO es ENTERO
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>

Autor

Univ. of Tennessee

Univ. of California Berkeley

Univ. of Colorado Denver

NAG Ltd.

Detalles Adicionales:

!>
!>  La matriz Q se representa como un producto de (ihi-ilo) reflejos
!>  elementales
!>
!>     Q = H(ilo) H(ilo+1) . . . H(ihi-1).
!>
!>  Cada H(i) tiene la forma
!>
!>     H(i) = I - tau * v * v**H
!>
!>  donde tau es un escalar complejo, y v es un vector complejo con
!>  v(1:i) = 0, v(i+1) = 1 e v(ihi+1:n) = 0; v(i+2:ihi) se almacena en la salida
!>  en A(i+2:ihi,i), y tau en TAU(i).
!>
!>  El contenido de A se ilustra con el siguiente ejemplo, con
!>  n = 7, ilo = 2 e ihi = 6:
!>
!>  en la entrada,                        en la salida,
!>
!>  ( a   a   a   a   a   a   a )    (  a   a   h   h   h   h   a )
!>  (     a   a   a   a   a   a )    (      a   h   h   h   h   a )
!>  (     a   a   a   a   a   a )    (      h   h   h   h   h   h )
!>  (     a   a   a   a   a   a )    (      v2  h   h   h   h   h )
!>  (     a   a   a   a   a   a )    (      v2  v3  h   h   h   h )
!>  (     a   a   a   a   a   a )    (      v2  v3  v4  h   h   h )
!>  (                         a )    (                          a )
!>
!>  donde 'a' denota un elemento de la matriz original A, 'h' denota un
!>  elemento modificado de la matriz de Hessenberg superior H, y 'vi' denota un
!>  elemento del vector que define H(i).
!>
!>  Este archivo es una ligera modificación de la subrutina ZGEHRD de LAPACK-3.0
!>  que incorpora mejoras propuestas por Quintana-Orti y
!>  Van de Geijn (2006). (Ver ZLAHR2.)
!>
