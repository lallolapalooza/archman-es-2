Documentación de la función/subrutina

subrutina zgeevx (character balanc, character jobvl, character jobvr, character sense, integer n, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( * ) w, complex*16, dimension( ldvl, * ) vl, integer ldvl, complex*16, dimension( ldvr, * ) vr, integer ldvr, integer ilo, integer ihi, double precision, dimension( * ) scale, double precision abnrm, double precision, dimension( * ) rconde, double precision, dimension( * ) rcondv, complex*16, dimension( * ) work, integer lwork, double precision, dimension( * ) rwork, integer info)

ZGEEVX calcula los valores propios y, opcionalmente, los vectores propios izquierdos y/o derechos para matrices GE

Propósito:

!>
!> ZGEEVX calcula para una matriz compleja no simétrica N-por-N A, los
!> valores propios y, opcionalmente, los vectores propios izquierdos y/o derechos.
!>
!> Opcionalmente, también calcula una transformación de balanceo para mejorar
!> el condicionamiento de los valores propios y vectores propios (ILO, IHI,
!> SCALE y ABNRM), los recíprocos de los números de condición para los valores
!> propios (RCONDE) y los recíprocos de los números de condición para los
!> vectores propios derechos (RCONDV).
!>
!> El vector propio derecho v(j) de A satisface
!>                  A * v(j) = lambda(j) * v(j)
!> donde lambda(j) es su valor propio.
!> El vector propio izquierdo u(j) de A satisface
!>               u(j)**H * A = lambda(j) * u(j)**H
!> donde u(j)**H denota la transpuesta conjugada de u(j).
!>
!> Los vectores propios calculados se normalizan para tener norma Euclidiana
!> igual a 1 y el componente más grande real.
!>
!> Balancear una matriz significa permutar las filas y columnas para hacerla
!> más cercana a ser triangular superior, y aplicar una transformación de
!> similitud diagonal D * A * D**(-1), donde D es una matriz diagonal, para
!> hacer que sus filas y columnas estén más cerca en norma y que los números de
!> condición de sus valores propios y vectores propios sean menores.
!> Las permutaciones de filas y columnas no cambiarán los números de condición
!> (en aritmética exacta) pero la escala diagonal sí lo hará. Para más
!> explicación sobre el balanceo, ver la sección 4.10.2 de la Guía de Usuarios
!> de LAPACK.
!>

Parámetros

BALANC 
!>          BALANC es CHARACTER*1
!>          Indica cómo la matriz de entrada debe ser escalada diagonalmente
!>          y/o permutada para mejorar el condicionamiento de sus
!>          valores propios.
!>          = 'N': No escalar ni permutar diagonalmente;
!>          = 'P': Realizar permutaciones para hacer la matriz más cercana a
!>                 ser triangular superior. No escalar diagonalmente;
!>          = 'S': Escalar la matriz diagonalmente, es decir, reemplazar A por
!>                 D*A*D**(-1), donde D es una matriz diagonal elegida
!>                 para hacer las filas y columnas de A más iguales en norma.
!>                 No permutar;
!>          = 'B': Escalar diagonalmente y permutar A.
!>
!>          Los recíprocos de los números de condición calculados serán para la
!>          matriz después del balanceo y/o permutación. La permutación no cambia
!>          los números de condición (en aritmética exacta), pero el balanceo sí.
!>

JOBVL

!>          JOBVL es CHARACTER*1
!>          = 'N': los vectores propios izquierdos de A no se calculan;
!>          = 'V': los vectores propios izquierdos de A se calculan.
!>          Si SENSE = 'E' o 'B', JOBVL debe ser 'V'.
!>

JOBVR

!>          JOBVR es CHARACTER*1
!>          = 'N': los vectores propios derechos de A no se calculan;
!>          = 'V': los vectores propios derechos de A se calculan.
!>          Si SENSE = 'E' o 'B', JOBVR debe ser 'V'.
!>

SENSE

!>          SENSE es CHARACTER*1
!>          Determina qué recíprocos de números de condición se calculan.
!>          = 'N': No se calcula ninguno;
!>          = 'E': Calculado solo para valores propios;
!>          = 'V': Calculado solo para vectores propios derechos;
!>          = 'B': Calculado para valores propios y vectores propios derechos.
!>
!>          Si SENSE = 'E' o 'B', también deben calcularse los vectores propios
!>          izquierdos y derechos (JOBVL = 'V' y JOBVR = 'V').
!>

N

!>          N es INTEGER
!>          El orden de la matriz A. N >= 0.
!>

A

!>          A es un array COMPLEX*16, dimensión (LDA,N)
!>          En la entrada, la matriz A de N-por-N.
!>          En la salida, A ha sido sobrescrita. Si JOBVL = 'V' o
!>          JOBVR = 'V', A contiene la forma de Schur de la versión
!>          balanceada de la matriz A.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A. LDA >= max(1,N).
!>

W

!>          W es un array COMPLEX*16, dimensión (N)
!>          W contiene los valores propios calculados.
!>

VL

!>          VL es un array COMPLEX*16, dimensión (LDVL,N)
!>          Si JOBVL = 'V', los vectores propios izquierdos u(j) se almacenan uno
!>          tras otro en las columnas de VL, en el mismo orden
!>          que sus valores propios.
!>          Si JOBVL = 'N', VL no se referencia.
!>          u(j) = VL(:,j), la columna j de VL.
!>

LDVL

!>          LDVL es INTEGER
!>          La dimensión principal del array VL. LDVL >= 1; si
!>          JOBVL = 'V', LDVL >= N.
!>

VR

!>          VR es un array COMPLEX*16, dimensión (LDVR,N)
!>          Si JOBVR = 'V', los vectores propios derechos v(j) se almacenan uno
!>          tras otro en las columnas de VR, en el mismo orden
!>          que sus valores propios.
!>          Si JOBVR = 'N', VR no se referencia.
!>          v(j) = VR(:,j), la columna j de VR.
!>

LDVR

!>          LDVR es INTEGER
!>          La dimensión principal del array VR. LDVR >= 1; si
!>          JOBVR = 'V', LDVR >= N.
!>

ILO

!>          ILO es INTEGER
!>

IHI

!>          IHI es INTEGER
!>          ILO e IHI son valores enteros determinados cuando A fue
!>          balanceada. La A balanceada (i,j) = 0 si I > J y
!>          J = 1,...,ILO-1 o I = IHI+1,...,N.
!>

SCALE

!>          SCALE es un array DOUBLE PRECISION, dimensión (N)
!>          Detalles de las permutaciones y factores de escala aplicados
!>          al balancear A. Si P(j) es el índice de la fila y columna
!>          intercambiada con la fila y columna j, y D(j) es el factor de
!>          escala aplicado a la fila y columna j, entonces
!>          SCALE(J) = P(J),    para J = 1,...,ILO-1
!>                   = D(J),    para J = ILO,...,IHI
!>                   = P(J)     para J = IHI+1,...,N.
!>          El orden en que se realizan los intercambios es N hasta IHI+1,
!>          luego 1 hasta ILO-1.
!>

ABNRM

!>          ABNRM es DOUBLE PRECISION
!>          La norma uno de la matriz balanceada (el máximo
!>          de la suma de los valores absolutos de los elementos de cualquier
!>          columna).
!>

RCONDE

!>          RCONDE es un array DOUBLE PRECISION, dimensión (N)
!>          RCONDE(j) es el recíproco del número de condición del j-ésimo
!>          valor propio.
!>

RCONDV

RCONDV es un array de DOBLE PRECISIÓN, dimensión (N)

!>          RCONDV(j) es el número de condición recíproco del j-ésimo
!>          vector propio derecho.
!>

WORK

WORK es un array COMPLEX*16, dimensión (MAX(1,LWORK))

!>          A la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

LWORK es un ENTERO

!>          La dimensión del array WORK. Si SENSE = 'N' o 'E',
!>          LWORK >= max(1,2*N), y si SENSE = 'V' o 'B',
!>          LWORK >= N*N+2*N.
!>          Para un buen rendimiento, LWORK generalmente debe ser mayor.
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo del array WORK, devuelve
!>          este valor como la primera entrada del array WORK, y XERBLA no emite ningún mensaje de error
!>          relacionado con LWORK.
!>

RWORK

RWORK es un array de DOBLE PRECISIÓN, dimensión (2*N)

INFO

INFO es un ENTERO

!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>          > 0:  si INFO = i, el algoritmo QR no pudo calcular todos los
!>                valores propios, y no se han calculado vectores propios ni números de condición;
!>                los elementos 1:ILO-1 y i+1:N de W contienen valores propios que han convergido.
!>
