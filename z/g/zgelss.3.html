subrutina zgelss (m, n, nrhs, a, lda, b, ldb, s, rcond, rank, work, lwork, rwork, info)
ZGELSS resuelve sistemas sobredeterminados o subdeterminados para matrices GE

Documentación de la función/subrutina

subrutina zgelss (integer m, integer n, integer nrhs, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( ldb, * ) b, integer ldb, double precision, dimension( * ) s, double precision rcond, integer rank, complex*16, dimension( * ) work, integer lwork, double precision, dimension( * ) rwork, integer info)

ZGELSS resuelve sistemas sobredeterminados o subdeterminados para matrices GE

Propósito:

!>
!> ZGELSS calcula la solución de norma mínima para un problema de
!> mínimos cuadrados lineales complejos:
!>
!> Minimizar la norma 2 de | b - A*x |.
!>
!> utilizando la descomposición en valores singulares (SVD) de A. A es
!> una matriz M por N que puede ser de rango deficiente.
!>
!> Se pueden manejar varios vectores del lado derecho b y vectores de
!> solución x en una sola llamada; se almacenan como columnas de la
!> matriz B del lado derecho M por NRHS y la matriz de solución X
!> N por NRHS.
!>
!> El rango efectivo de A se determina tratando como cero aquellos
!> valores singulares que son menores que RCOND multiplicado por el valor
!> singular más grande.
!>

Parámetros

M 
!>          M es INTEGER
!>          El número de filas de la matriz A. M >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz A. N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de lados derechos, es decir, el número de columnas
!>          de las matrices B y X. NRHS >= 0.
!>

A

!>          A es un array COMPLEX*16, dimension (LDA,N)
!>          En la entrada, la matriz A de M por N.
!>          En la salida, las primeras min(m,n) filas de A se sobrescriben
!>          con sus vectores singulares derechos, almacenados por filas.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión líder del array A. LDA >= max(1,M).
!>

B

!>          B es un array COMPLEX*16, dimension (LDB,NRHS)
!>          En la entrada, la matriz B del lado derecho M por NRHS.
!>          En la salida, B se sobrescribe con la matriz de solución X
!>          de N por NRHS.
!>          Si m >= n y RANK = n, la suma de cuadrados de los residuos para
!>          la solución en la i-ésima columna se da como la suma de
!>          cuadrados de los módulos de los elementos n+1:m en esa columna.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión líder del array B. LDB >= max(1,M,N).
!>

S

!>          S es un array DOUBLE PRECISION, dimension (min(M,N))
!>          Los valores singulares de A en orden decreciente.
!>          El número de condición de A en la norma 2 = S(1)/S(min(m,n)).
!>

RCOND

!>          RCOND es DOUBLE PRECISION
!>          RCOND se usa para determinar el rango efectivo de A.
!>          Los valores singulares S(i) <= RCOND*S(1) se tratan como cero.
!>          Si RCOND < 0, se utiliza la precisión de máquina en su lugar.
!>

RANK

!>          RANK es INTEGER
!>          El rango efectivo de A, es decir, el número de valores singulares
!>          que son mayores que RCOND*S(1).
!>

WORK

!>          WORK es un array COMPLEX*16, dimension (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK. LWORK >= 1, y además:
!>          LWORK >=  2*min(M,N) + max(M,N,NRHS)
!>          Para un buen rendimiento, LWORK debería ser generalmente mayor.
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de
!>          trabajo; la rutina solo calcula el tamaño óptimo del array
!>          WORK, devuelve este valor como la primera entrada del array
!>          WORK, y XERBLA no emite ningún mensaje de error relacionado
!>          con LWORK.
!>

RWORK

!>          RWORK es un array DOUBLE PRECISION, dimension (5*min(M,N))
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>          > 0:  el algoritmo para calcular la SVD no convergió;
!>                si INFO = i, i elementos fuera de la diagonal de una forma
!>                bidiagonal intermedia no convergieron a cero.
!>
