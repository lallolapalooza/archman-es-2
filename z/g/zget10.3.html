Documentación de función/subrutina

subrutina zget10 (integer m, integer n, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( ldb, * ) b, integer ldb, complex*16, dimension( * ) work, double precision, dimension( * ) rwork, double precision result)

ZGET10

Propósito:

!>
!> ZGET10 compara dos matrices A y B y calcula la relación
!> RESULT = norm( A - B ) / ( norm(A) * M * EPS )
!>

Parámetros

M 
!>          M es INTEGER
!>          El número de filas de las matrices A y B.
!>

N

!>          N es INTEGER
!>          El número de columnas de las matrices A y B.
!>

A

!>          A es un array COMPLEX*16, dimension (LDA,N)
!>          La matriz A de m por n.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,M).
!>

B

!>          B es un array COMPLEX*16, dimension (LDB,N)
!>          La matriz B de m por n.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B.  LDB >= max(1,M).
!>

WORK

!>          WORK es un array COMPLEX*16, dimension (M)
!>

RWORK

!>          RWORK es un array COMPLEX*16, dimension (M)
!>

RESULT

!>          RESULT es DOUBLE PRECISION
!>          RESULT = norm( A - B ) / ( norm(A) * M * EPS )
!>
