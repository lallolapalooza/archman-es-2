ZGTRFS

Propósito:

!>
!> ZGTRFS mejora la solución calculada para un sistema de ecuaciones lineales
!> cuando la matriz de coeficientes es tridiagonal, y proporciona
!> límites de error y estimaciones de error hacia atrás para la solución.
!>

Parámetros

TRANS 
!>          TRANS es CHARACTER*1
!>          Especifica la forma del sistema de ecuaciones:
!>          = 'N':  A * X = B     (Sin transposición)
!>          = 'T':  A**T * X = B  (Transpuesta)
!>          = 'C':  A**H * X = B  (Transpuesta conjugada)
!>

N

!>          N es ENTERO
!>          El orden de la matriz A.  N >= 0.
!>

NRHS

!>          NRHS es ENTERO
!>          El número de lados derechos, es decir, el número de columnas
!>          de la matriz B.  NRHS >= 0.
!>

DL

!>          DL es un array COMPLEX*16, dimensión (N-1)
!>          Los elementos subdiagonales (N-1) de A.
!>

D

!>          D es un array COMPLEX*16, dimensión (N)
!>          Los elementos diagonales de A.
!>

DU

!>          DU es un array COMPLEX*16, dimensión (N-1)
!>          Los elementos superdiagonales (N-1) de A.
!>

DLF

!>          DLF es un array COMPLEX*16, dimensión (N-1)
!>          Los multiplicadores (N-1) que definen la matriz L de la
!>          factorización LU de A, tal como la calcula ZGTTRF.
!>

DF

!>          DF es un array COMPLEX*16, dimensión (N)
!>          Los n elementos diagonales de la matriz triangular superior U de
!>          la factorización LU de A.
!>

DUF

!>          DUF es un array COMPLEX*16, dimensión (N-1)
!>          Los elementos (N-1) de la primera superdiagonal de U.
!>

DU2

!>          DU2 es un array COMPLEX*16, dimensión (N-2)
!>          Los elementos (N-2) de la segunda superdiagonal de U.
!>

IPIV

!>          IPIV es un array ENTERO, dimensión (N)
!>          Los índices de pivote; para 1 <= i <= n, la fila i de la matriz fue
!>          intercambiada con la fila IPIV(i).  IPIV(i) será siempre i o i+1;
!>          IPIV(i) = i indica que no se requirió un intercambio de fila.
!>

B

!>          B es un array COMPLEX*16, dimensión (LDB,NRHS)
!>          La matriz del lado derecho B.
!>

LDB

!>          LDB es ENTERO
!>          La dimensión principal del array B.  LDB >= max(1,N).
!>

X

!>          X es un array COMPLEX*16, dimensión (LDX,NRHS)
!>          En la entrada, la matriz solución X, tal como fue calculada por ZGTTRS.
!>          En la salida, la matriz solución mejorada X.
!>

LDX

!>          LDX es ENTERO
!>          La dimensión principal del array X.  LDX >= max(1,N).
!>

FERR

!>          FERR es un array DOUBLE PRECISION, dimensión (NRHS)
!>          El límite de error hacia adelante estimado para cada vector solución
!>          X(j) (la j-ésima columna de la matriz solución X).
!>          Si XTRUE es la solución verdadera correspondiente a X(j), FERR(j)
!>          es un límite superior estimado para la magnitud del elemento más grande
!>          en (X(j) - XTRUE) dividido por la magnitud del elemento más grande
!>          en X(j).  La estimación es tan confiable como
!>          la estimación de RCOND, y es casi siempre un ligero
!>          sobreestimación del error verdadero.
!>

BERR

!>          BERR es un array DOUBLE PRECISION, dimensión (NRHS)
!>          El error hacia atrás relativo componente a componente de cada vector solución
!>          X(j) (es decir, el cambio relativo más pequeño en
!>          cualquier elemento de A o B que hace que X(j) sea una solución exacta).
!>

WORK

!>          WORK es un array COMPLEX*16, dimensión (2*N)
!>

RWORK

!>          RWORK es un array DOUBLE PRECISION, dimensión (N)
!>

INFO

!>          INFO es ENTERO
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>

Parámetros Internos:

!>  ITMAX es el número máximo de pasos de refinamiento iterativo.
!>
