Documentación de función/subrutina

subrutina zgbsvxx (character fact, character trans, integer n, integer kl, integer ku, integer nrhs, complex*16, dimension( ldab, * ) ab, integer ldab, complex*16, dimension( ldafb, * ) afb, integer ldafb, integer, dimension( * ) ipiv, character equed, double precision, dimension( * ) r, double precision, dimension( * ) c, complex*16, dimension( ldb, * ) b, integer ldb, complex*16, dimension( ldx , * ) x, integer ldx, double precision rcond, double precision rpvgrw, double precision, dimension( * ) berr, integer n_err_bnds, double precision, dimension( nrhs, * ) err_bnds_norm, double precision, dimension( nrhs, * ) err_bnds_comp, integer nparams, double precision, dimension( * ) params, complex*16, dimension( * ) work, double precision, dimension( * ) rwork, integer info)

ZGBSVXX calcula la solución al sistema de ecuaciones lineales A * X = B para matrices GB

Propósito:

!>
!>    ZGBSVXX utiliza la factorización LU para calcular la solución a un
!>    sistema complejo*16 de ecuaciones lineales  A * X = B,  donde A es una
!>    matriz N-por-N y X y B son matrices N-por-NRHS.
!>
!>    Si se solicita, se devuelven límites de error tanto normativos como
!>    de componente máxima. ZGBSVXX devolverá una solución con un error
!>    garantizado diminuto (O(eps) donde eps es la precisión de la máquina
!>    de trabajo) a menos que la matriz sea muy mal condicionada, en cuyo
!>    caso se devuelve una advertencia. También se calculan y devuelven
!>    los números de condición relevantes.
!>
!>    ZGBSVXX acepta factorizaciones y factores de equilibrado proporcionados
!>    por el usuario; consulte las definiciones de las opciones FACT y EQUED.
!>    Resolver con refinamiento y usar una factorización de una llamada
!>    anterior de ZGBSVXX también producirá una solución con errores O(eps)
!>    o advertencias, pero no podemos hacer esa afirmación para factores
!>    de factorización y equilibrado proporcionados por el usuario en general
!>    si difieren de lo que ZGBSVXX produciría por sí mismo.
!>

Descripción:

!>
!>    Se realizan los siguientes pasos:
!>
!>    1. Si FACT = 'E', se calculan factores de escala de precisión doble para
!>    equilibrar el sistema:
!>
!>      TRANS = 'N':  diag(R)*A*diag(C)     *inv(diag(C))*X = diag(R)*B
!>      TRANS = 'T': (diag(R)*A*diag(C))**T *inv(diag(R))*X = diag(C)*B
!>      TRANS = 'C': (diag(R)*A*diag(C))**H *inv(diag(R))*X = diag(C)*B
!>
!>    Si el sistema se equilibra o no depende de la escala de la matriz A,
!>    pero si se utiliza el equilibrado, A se sobrescribe con diag(R)*A*diag(C)
!>    y B con diag(R)*B (si TRANS='N') o diag(C)*B (si TRANS = 'T' o 'C').
!>
!>    2. Si FACT = 'N' o 'E', se utiliza la descomposición LU para factorizar
!>    la matriz A (después del equilibrado si FACT = 'E') como
!>
!>      A = P * L * U,
!>
!>    donde P es una matriz de permutación, L es una matriz triangular inferior
!>    unitaria y U es triangular superior.
!>
!>    3. Si algún U(i,i)=0, de modo que U sea exactamente singular, entonces la
!>    subrutina regresa con INFO = i. De lo contrario, la forma factorizada
!>    de A se utiliza para estimar el número de condición de la matriz A (ver
!>    argumento RCOND). Si la recíproca del número de condición es menor que
!>    la precisión de la máquina, la subrutina aún continúa resolviendo para X
!>    y calculando los límites de error como se describe a continuación.
!>
!>    4. El sistema de ecuaciones se resuelve para X utilizando la forma
!>    factorizada de A.
!>
!>    5. Por defecto (a menos que PARAMS(LA_LINRX_ITREF_I) se establezca en cero),
!>    la subrutina utilizará refinamiento iterativo para intentar obtener un
!>    error y límites de error pequeños. El refinamiento calcula el residuo
!>    con al menos el doble de la precisión de trabajo.
!>
!>    6. Si se utilizó el equilibrado, la matriz X se premultiplica por
!>    diag(C) (si TRANS = 'N') o diag(R) (si TRANS = 'T' o 'C') para que
!>    resuelva el sistema original antes del equilibrado.
!> 
!>     Algunos parámetros opcionales están agrupados en el array PARAMS.
!>     Estas configuraciones determinan cómo se realiza el refinamiento,
!>     pero a menudo los valores predeterminados son aceptables. Si los
!>     valores predeterminados son aceptables, los usuarios pueden pasar
!>     NPARAMS = 0, lo que evita que el código fuente acceda al argumento
!>     PARAMS.
!>

Parámetros

FACT 
!>          FACT es CHARACTER*1
!>     Especifica si la forma factorizada de la matriz A se proporciona en la
!>     entrada, y si no, si la matriz A debe equilibrarse antes de factorizarla.
!>       = 'F':  En la entrada, AF y IPIV contienen la forma factorizada de A.
!>               Si EQUED no es 'N', la matriz A ha sido equilibrada
!>               con factores de escala dados por R y C.
!>               A, AF e IPIV no se modifican.
!>       = 'N':  La matriz A se copiará en AF y se factorizará.
!>       = 'E':  La matriz A se equilibrará si es necesario, luego se
!>               copiará en AF y se factorizará.
!>

TRANS

!>          TRANS es CHARACTER*1
!>     Especifica la forma del sistema de ecuaciones:
!>       = 'N':  A * X = B     (Sin transposición)
!>       = 'T':  A**T * X = B  (Transpuesta)
!>       = 'C':  A**H * X = B  (Transpuesta conjugada = Transpuesta)
!>

N

!>          N es INTEGER
!>     El número de ecuaciones lineales, es decir, el orden de
!>     la matriz A.  N >= 0.
!>

KL

!>          KL es INTEGER
!>     El número de subdiagonales dentro de la banda de A.  KL >= 0.
!>

KU

!>          KU es INTEGER
!>     El número de superdiagonales dentro de la banda de A.  KU >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>     El número de lados derechos, es decir, el número de columnas
!>     de las matrices B y X.  NRHS >= 0.
!>

AB

!>          AB es array COMPLEX*16, dimension (LDAB,N)
!>     En la entrada, la matriz A en almacenamiento de banda, en las filas
!>     1 a KL+KU+1.
!>     La j-ésima columna de A se almacena en la j-ésima columna del
!>     array AB como sigue:
!>     AB(KU+1+i-j,j) = A(i,j) para max(1,j-KU)<=i<=min(N,j+kl)
!>
!>     Si FACT = 'F' y EQUED no es 'N', entonces AB debe haber sido
!>     equilibrado con los factores de escala en R y/o C. AB no se
!>     modifica si FACT = 'F' o 'N', o si FACT = 'E' y
!>     EQUED = 'N' en la salida.
!>
!>     En la salida, si EQUED .ne. 'N', A se escala como sigue:
!>     EQUED = 'R':  A := diag(R) * A
!>     EQUED = 'C':  A := A * diag(C)
!>     EQUED = 'B':  A := diag(R) * A * diag(C).
!>

LDAB

!>          LDAB es INTEGER
!>     La dimensión principal del array AB.  LDAB >= KL+KU+1.
!>

AFB

!>          AFB es array COMPLEX*16, dimension (LDAFB,N)
!>     Si FACT
= 'F', entonces AFB es un argumento de entrada y al entrar !> contiene los detalles de la factorización LU de la matriz de banda !> A, tal como fue calculada por ZGBTRF. U se almacena como una matriz triangular superior !> de banda con KL+KU superdiagonales en las filas 1 a KL+KU+1, !> y los multiplicadores usados durante la factorización se almacenan !> en las filas KL+KU+2 a 2*KL+KU+1. Si EQUED .ne. 'N', entonces AFB es !> la forma factorizada de la matriz A equilibrada. !> !> Si FACT = 'N', entonces AF es un argumento de salida y al salir !> devuelve los factores L y U de la factorización A = P*L*U !> de la matriz original A. !> !> Si FACT = 'E', entonces AF es un argumento de salida y al salir !> devuelve los factores L y U de la factorización A = P*L*U !> de la matriz equilibrada A (ver la descripción de A para !> la forma de la matriz equilibrada). !>

LDAFB

!>          LDAFB es un ENTERO
!>     La dimensión principal del array AFB. LDAFB >= 2*KL+KU+1.
!>

IPIV

!>          IPIV es un array ENTERO, de dimensión (N)
!>     Si FACT = 'F', entonces IPIV es un argumento de entrada y al entrar
!>     contiene los índices de pivote de la factorización A = P*L*U
!>     tal como fue calculada por ZGETRF; la fila i de la matriz fue intercambiada
!>     con la fila IPIV(i).
!>
!>     Si FACT = 'N', entonces IPIV es un argumento de salida y al salir
!>     contiene los índices de pivote de la factorización A = P*L*U
!>     de la matriz original A.
!>
!>     Si FACT = 'E', entonces IPIV es un argumento de salida y al salir
!>     contiene los índices de pivote de la factorización A = P*L*U
!>     de la matriz equilibrada A.
!>

EQUED

!>          EQUED es un CARACTER*1
!>     Especifica la forma de equilibrado que se realizó.
!>       = 'N':  Sin equilibrado (siempre verdadero si FACT = 'N').
!>       = 'R':  Equilibrado de filas, es decir, A ha sido premultiplicada por
!>               diag(R).
!>       = 'C':  Equilibrado de columnas, es decir, A ha sido postmultiplicada
!>               por diag(C).
!>       = 'B':  Equilibrado tanto de filas como de columnas, es decir, A ha sido
!>               reemplazada por diag(R) * A * diag(C).
!>     EQUED es un argumento de entrada si FACT = 'F'; de lo contrario, es un
!>     argumento de salida.
!>

R

!>          R es un array DOUBLE PRECISION, de dimensión (N)
!>     Los factores de escala de fila para A. Si EQUED = 'R' o 'B', A es
!>     multiplicada a la izquierda por diag(R); si EQUED = 'N' o 'C', R
!>     no se accede. R es un argumento de entrada si FACT = 'F';
!>     de lo contrario, R es un argumento de salida. Si FACT = 'F' y
!>     EQUED = 'R' o 'B', cada elemento de R debe ser positivo.
!>     Si R es de salida, cada elemento de R es una potencia de la base.
!>     Si R es de entrada, cada elemento de R debe ser una potencia de la base
!>     para asegurar una solución y estimaciones de error fiables. El escalado por
!>     potencias de la base no causa errores de redondeo a menos que el
!>     resultado sea un underflow o overflow. Los errores de redondeo durante el escalado
!>     conducen a una refinación con una matriz que no es equivalente a la
!>     matriz de entrada, produciendo estimaciones de error que pueden no ser
!>     fiables.
!>

C

!>          C es un array DOUBLE PRECISION, de dimensión (N)
!>     Los factores de escala de columna para A. Si EQUED = 'C' o 'B', A es
!>     multiplicada a la derecha por diag(C); si EQUED = 'N' o 'R', C
!>     no se accede. C es un argumento de entrada si FACT = 'F';
!>     de lo contrario, C es un argumento de salida. Si FACT = 'F' y
!>     EQUED = 'C' o 'B', cada elemento de C debe ser positivo.
!>     Si C es de salida, cada elemento de C es una potencia de la base.
!>     Si C es de entrada, cada elemento de C debe ser una potencia de la base
!>     para asegurar una solución y estimaciones de error fiables. El escalado por
!>     potencias de la base no causa errores de redondeo a menos que el
!>     resultado sea un underflow o overflow. Los errores de redondeo durante el escalado
!>     conducen a una refinación con una matriz que no es equivalente a la
!>     matriz de entrada, produciendo estimaciones de error que pueden no ser
!>     fiables.
!>

B

!>          B es un array COMPLEX*16, de dimensión (LDB,NRHS)
!>     A la entrada, la matriz B del lado derecho de N por NRHS.
!>     A la salida,
!>     si EQUED = 'N', B no se modifica;
!>     si TRANS = 'N' y EQUED = 'R' o 'B', B se sobrescribe con
!>        diag(R)*B;
!>     si TRANS = 'T' o 'C' y EQUED = 'C' o 'B', B se
!>        sobrescribe con diag(C)*B.
!>

LDB

!>          LDB es un ENTERO
!>     La dimensión principal del array B. LDB >= max(1,N).
!>

X

!>          X es un array COMPLEX*16, de dimensión (LDX,NRHS)
!>     Si INFO = 0, la matriz X de solución de N por NRHS del sistema original
!>     de ecuaciones. Tenga en cuenta que A y B se modifican a la salida
!>     si EQUED .ne. 'N', y la solución del sistema equilibrado es
!>     inv(diag(C))*X si TRANS = 'N' y EQUED = 'C' o 'B', o
!>     inv(diag(R))*X si TRANS = 'T' o 'C' y EQUED = 'R' o 'B'.
!>

LDX

!>          LDX es un ENTERO
!>     La dimensión principal del array X. LDX >= max(1,N).
!>

RCOND

!>          RCOND es DOUBLE PRECISION
!>     Número de condición escalado recíproco. Esta es una estimación del
!>     número de condición de Skeel recíproco de la matriz A después del
!>     equilibrado (si se realizó). Si es menor que la precisión de la máquina
!>     (en particular, si es cero), la matriz es singular
!>     a la precisión de trabajo. Tenga en cuenta que el error aún puede ser pequeño incluso
!>     si este número es muy pequeño y la matriz parece mal
!>     condicionada.
!>

RPVGRW

!>          RPVGRW es DOUBLE PRECISION
!>     Crecimiento recíproco del pivote. A la salida, contiene el factor de
!>     crecimiento recíproco del pivote norm(A)/norm(U). La
!>     norma usada. Si esto es mucho menor que 1, entonces la estabilidad de
!>     la factorización LU de la matriz (equilibrada) A podría ser pobre.
!>     Esto también significa que la solución X, los números de condición estimados,
!>     y las cotas de error podrían no ser fiables. Si la factorización falla con
!>     0<INFO<=N, entonces esto contiene el factor de crecimiento recíproco del pivote
!>     para las columnas de pivote INFO de A. En ZGESVX, esta cantidad es
!>     devuelta en RWORK(1).
!>

BERR

!>          BERR es un array DOUBLE PRECISION, de dimensión (NRHS)
!>     Error relativo de retroceso componente a componente. Este es el
!>     error relativo de retroceso componente a componente de cada vector solución X(j)
!>     (es decir, el cambio relativo más pequeño en cualquier elemento de A o B que
!>     haga que X(j) sea una solución exacta).
!>

N_ERR_BNDS

!>          N_ERR_BNDS es un ENTERO
!>     Número de cotas de error a devolver para cada lado derecho
!>     y cada tipo (normwise o componentwise). Ver ERR_BNDS_NORM y
!>     ERR_BNDS_COMP a continuación.
!>

ERR_BNDS_NORM

!>          ERR_BNDS_NORM es un array DOUBLE PRECISION, de dimensión (NRHS, N_ERR_BNDS)
!>     Para cada lado derecho, este array contiene información sobre
!>     varias cotas de error y números de condición correspondientes al
!>     error relativo normwise, que se define de la siguiente manera:
!>
!>     Error relativo normwise en el i-ésimo vector solución:
!>             max_j (abs(XTRUE(j,i) - X(j,i)))
!>            ------------------------------
!>                  max_j abs(X(j,i))
!>
!>     El array está indexado por el tipo de información de error tal como se describe
!>     a continuación. Actualmente hay hasta tres piezas de información
!>     devueltas.
!>
!>     El primer índice en ERR_BNDS_NORM(i,:) corresponde al i-ésimo
!>     lado derecho.
!>
!>     El segundo índice en ERR_BNDS_NORM(:,err) contiene los siguientes
!>     tres campos:
!>     err = 1  booleano. Confíe en la respuesta si el
!>              número de condición recíproco es menor que el umbral
!>              sqrt(n) * dlamch('Epsilon').
!>
!>     err = 2  cota de error: El error directo estimado,
!>              casi seguramente dentro de un factor de 10 del error verdadero
!>              siempre que la siguiente entrada sea mayor que el umbral
!>              sqrt(n) * dlamch('Epsilon'). Esta cota de error solo debe
!>              confiarse si el booleano anterior es verdadero.
!>
!>     err = 3  Número de condición recíproco: Estimación normwise
!>              número de condición recíproco. Comparado con el umbral
!>              sqrt(n) * dlamch('Epsilon') para determinar si el error
!>              la estimación es . Estos números de condición
!>              recíprocos son 1 / (norm(Z^{-1},inf) * norm(Z,inf)) para alguna
!>              matriz Z apropiadamente escalada.
!>              Sea Z = S*A, donde S escala cada fila por una potencia de la
!>              base de tal manera que todas las sumas de filas absolutas de Z son aproximadamente 1.
!>
!>     Ver Lapack Working Note 165 para más detalles y precauciones adicionales.
!>

ERR_BNDS_COMP

!>          ERR_BNDS_COMP es un array DOUBLE PRECISION, de dimensión (NRHS, N_ERR_BNDS)
!>     Para cada lado derecho, este array contiene información sobre
!>     varias cotas de error y números de condición correspondientes al
!>     error relativo componente a componente, que se define de la siguiente manera:
!>
!>     Error relativo componente a componente en el i-ésimo vector solución:
!>                    abs(XTRUE(j,i) - X(j,i))
!>             max_j ----------------------
!>                         abs(X(j,i))
!>
!>     El array está indexado por el lado derecho i (del cual depende el
!>     error relativo componente a componente), y el tipo de información de error tal como se describe
!>     a continuación. Actualmente hay hasta tres piezas de información
!>     devueltas para cada lado derecho. Si
!>     no se solicita precisión componente a componente (PARAMS(3) = 0.0), entonces
!>     ERR_BNDS_COMP no se accede. Si N_ERR_BNDS < 3, entonces se devuelven como máximo
!>     las primeras entradas (:,N_ERR_BNDS).
!>
!>     El primer índice en ERR_BNDS_COMP(i,:) corresponde al i-ésimo
!>     lado derecho.
!>
!>     El segundo índice en ERR_BNDS_COMP(:,err) contiene los siguientes
!>     tres campos:
!>     err = 1  booleano. Confíe en la respuesta si el
!>              número de condición recíproco es menor que el umbral
!>              sqrt(n) * dlamch('Epsilon').
!>
!>     err = 2  cota de error: El error directo estimado,
!>              casi seguramente dentro de un factor de 10 del error verdadero
!>              siempre que la siguiente entrada sea mayor que el umbral
!>              sqrt(n) * dlamch('Epsilon'). Esta cota de error solo debe
!>              confiarse si el booleano anterior es verdadero.
!>
!>     err = 3  Número de condición recíproco: Estimación componente a componente
!>              número de condición recíproco. Comparado con el umbral
!>              sqrt(n) * dlamch('Epsilon') para determinar si el error
!>              la estimación es . Estos números de condición
!>              recíprocos son 1 / (norm(Z^{-1},inf) * norm(Z,inf)) para alguna
!>              matriz Z apropiadamente escalada.
!>              Sea Z = S*(A*diag(x)), donde x es la solución para el
!>              lado derecho actual y S escala cada fila de
!>              A*diag(x) por una potencia de la base de tal manera que todas las sumas de filas absolutas
!>              de Z son aproximadamente 1.
!>
!>     Ver Lapack Working Note 165 para más detalles.

call zgbsvxx( character jobz, character trans, integer m,
    integer kl, integer ku, complex*16, dimension(*) :: ab, integer ldab,
    complex*16, dimension(*) :: b, integer ldb, complex*16, dimension(*) ::
    x, integer ldx, double precision :: rcond, integer, dimension(*) :: rpiv,
    double precision, dimension(*) :: s, double precision, dimension(*) ::
    rwork, complex*16, dimension(*) :: work, integer :: info )






Function/Subroutine Documentation


zgbsvxx


  Purpose
  =======
  ZGBSVXX uses the left generalized eigenvectors of a generalized Band
  Matrix Eigenvalue Problem (GBEP) A*x = lambda*B*x to compute the condition
  number RCOND, the error bounds ERR BNDS NORM and ERR BNDS COMP, and the
  approximate solutions X to the system of equations A*X = B, AAT*X = B,
  or A.'*X = B. Here AAT is the conjugate transpose of A, and A.' is the
  transpose of A.

  Arguments
  =========
  JOBZ    (input) CHARACTER*1
          Specifies the form of the problem:
          = 'N': Solve A*X = B only.
          = 'A': Solve A*X = B, AAT*X = B, and A.'*X = B.
          (For further options, see Users' Guide)

  TRANS   (input) CHARACTER*1
          Specifies the form of the system of equations to be solved:
          = 'N': Solve A*X = B (No transpose)
          = 'C': Solve A**H*X = B (Conjugate transpose)
          = 'T': Solve A**T*X = B (Transpose)

  M       (input) INTEGER
          The number of order of the matrix A. M >= 0.
          To compute the condition number and error bounds for the
          system of equations A*X=B, M must be >= 0.

  KL      (input) INTEGER
          The number of superdiagonals of A. KL >= 0.

  KU      (input) INTEGER
          The number of subdiagonals of A. KU >= 0.

  AB      (input) COMPLEX*16 array, dimension (LDAB,K)
          On entry, the array AB contains details of the matrix A.
          The number of rows and columns of A is M and the number of
          columns of B is K.
          On exit, the lower triangle of AB is destroyed and replaced by
          information about the LU factorization of A.

  LDAB    (input) INTEGER
          The leading dimension of the array AB. LDAB >= max(1, M).

  B       (input) COMPLEX*16 array, dimension (LDB,NRHS)
          On entry, the right hand side matrix B.
          On exit, if JOBZ = 'N', B is overwritten by the solution matrix X.
          If JOBZ = 'A', B is overwritten by the solutions to A*X = B,
          AAT*X = B, and A.'*X = B, in that order.

  LDB     (input) INTEGER
          The leading dimension of the array B. LDB >= max(1, M).

  X       (output) COMPLEX*16 array, dimension (LDX,NRHS)
          If JOBZ = 'N', X contains the solution matrix X to A*X=B.
          If JOBZ = 'A', X contains the solutions to A*X=B, AAT*X=B,
          and A.'*X=B, in that order.

  LDX     (input) INTEGER
          The leading dimension of the array X. LDX >= max(1, M).

  RCOND   (output) DOUBLE PRECISION
          Estimate of the reciprocal condition number of the matrix A.
          RCOND is `None' if INFO < 0.
