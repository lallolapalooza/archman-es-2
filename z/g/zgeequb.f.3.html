ZGEEQUB

Documentación de función/subrutina

subroutine zgeequb (integer m, integer n, complex*16, dimension( lda, * ) a, integer lda, double precision, dimension( * ) r, double precision, dimension( * ) c, double precision rowcnd, double precision colcnd, double precision amax, integer info)

ZGEEQUB

Propósito:

!>
!> ZGEEQUB calcula los escalados de fila y columna destinados a equilibrar una
!> matriz A de M por N y reducir su número de condición. R devuelve los factores
!> de escala de fila y C los factores de escala de columna, elegidos para intentar
!> que el elemento más grande en cada fila y columna de la matriz B con
!> elementos B(i,j)=R(i)*A(i,j)*C(j) tenga un valor absoluto de como máximo
!> la base.
!>
!> R(i) y C(j) están restringidos a ser una potencia de la base entre
!> SMLNUM = número seguro más pequeño y BIGNUM = número seguro más grande. El uso
!> de estos factores de escalado no garantiza la reducción del número de condición
!> de A, pero funciona bien en la práctica.
!>
!> Esta rutina difiere de ZGEEQU al restringir los factores de escalado
!> a una potencia de la base. Salvo desbordamientos (overflow/underflow), el escalado por
!> estos factores no introduce errores de redondeo adicionales. Sin embargo, las
!> magnitudes de las entradas escaladas ya no son aproximadamente 1, sino que se encuentran
!> entre sqrt(base) y 1/sqrt(base).
!>

Parámetros

M 
!>          M es ENTERO
!>          El número de filas de la matriz A. M >= 0.
!>

N

!>          N es ENTERO
!>          El número de columnas de la matriz A. N >= 0.
!>

A

!>          A es una matriz COMPLEX*16, de dimensión (LDA,N)
!>          La matriz M por N cuyos factores de equilibrado se
!>          deben calcular.
!>

LDA

!>          LDA es ENTERO
!>          La dimensión principal de la matriz A. LDA >= max(1,M).
!>

R

!>          R es una matriz DOUBLE PRECISION, de dimensión (M)
!>          Si INFO = 0 o INFO > M, R contiene los factores de escala de fila
!>          para A.
!>

C

!>          C es una matriz DOUBLE PRECISION, de dimensión (N)
!>          Si INFO = 0, C contiene los factores de escala de columna para A.
!>

ROWCND

!>          ROWCND es DOUBLE PRECISION
!>          Si INFO = 0 o INFO > M, ROWCND contiene la relación entre el R(i)
!>          más pequeño y el R(i) más grande. Si ROWCND >= 0.1 y
!>          AMAX no es ni demasiado grande ni demasiado pequeño, no vale la pena
!>          escalar con R.
!>

COLCND

!>          COLCND es DOUBLE PRECISION
!>          Si INFO = 0, COLCND contiene la relación entre el C(i)
!>          más pequeño y el C(i) más grande. Si COLCND >= 0.1, no vale la pena
!>          escalar con C.
!>

AMAX

!>          AMAX es DOUBLE PRECISION
!>          Valor absoluto del elemento de matriz más grande. Si AMAX está muy
!>          cerca del desbordamiento (overflow) o muy cerca del subdesbordamiento (underflow),
!>          la matriz debería escalarse.
!>

INFO

!>          INFO es ENTERO
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>          > 0:  si INFO = i, y i es
!>                <= M:  la fila i de A es exactamente cero
!>                >  M:  la columna (i-M) de A es exactamente cero
!>
