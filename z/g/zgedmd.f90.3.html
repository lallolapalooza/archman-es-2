ZGEDMD calcula la Descomposición de Modos Dinámicos (DMD) para un par de matrices de instantáneas de datos.

Propósito:

!>    ZGEDMD calcula la Descomposición de Modos Dinámicos (DMD) para
!>    un par de matrices de instantáneas de datos. Para las matrices
!>    de entrada X e Y tales que Y = A*X con una matriz A inaccesible,
!>    ZGEDMD calcula un cierto número de pares de Ritz de A utilizando
!>    la extracción estándar de Rayleigh-Ritz de un subespacio de
!>    rango(X) que se determina usando los vectores singulares izquierdos
!>    principales de X. Opcionalmente, ZGEDMD devuelve los residuos
!>    de los pares de Ritz calculados, la información necesaria para
!>    un refinamiento de los vectores de Ritz, o los vectores propios de
!>    la DMD Exacta.
!>    Para más detalles véanse las referencias listadas
!>    a continuación. Para más detalles de la implementación véase [3].
!>

Referencias:

!>           columnas no nulas unitarias (en la norma euclidiana 2)
!>    'C' :: Las instantáneas se escalan como con la opción 'S'.
!>           Si se descubre que una i-ésima columna de X es un vector
!>           cero y la correspondiente i-ésima columna de Y no es cero,
!>           entonces la i-ésima columna de Y se establece a cero y se
!>           eleva una bandera de advertencia.
!>    'Y' :: Las matrices de instantáneas de datos X e Y se multiplican

!> 1 :: ZGESVD (el algoritmo QR SVD) !> 2 :: ZGESDD (el algoritmo Divide and Conquer; si hay !> suficiente espacio de trabajo disponible, esta es la opción más rápida) !> 3 :: ZGESVDQ (el SVD QR precondicionado; esta y la 4 !> son las opciones más precisas) !> 4 :: ZGEJSV (el SVD Jacobi precondicionado; esta y la 3 !> son las opciones más precisas) !> Para los cuatro métodos anteriores, es posible una diferencia significativa en !> la precisión de los valores singulares pequeños si !> las instantáneas varían en norma de tal manera que X está severamente !> mal condicionada. Si los valores singulares pequeños (menores que EPS*||X||) !> son de interés y JOBS=='N', entonces !> las opciones (3, 4) dan los resultados más precisos, donde !> la opción 4 es ligeramente mejor y con un trasfondo teórico más fuerte. !> Si JOBS=='S', es decir, las columnas de X se normalizarán, !> entonces todos los métodos dan resultados casi igualmente precisos. !>

Function/Subroutine Documentation

This subroutine is part of the LAPACK routines that compute the singular value decomposition (SVD) of a matrix.

It computes the SVD of a matrix A of dimension n x n, and potentially a second matrix B of dimension n x n.

 A = U * S * V**H
 B = U * C * V**H

where S is a real diagonal matrix with nonnegative diagonal entries (the singular values), U and V are unitary matrices, and C is a complex diagonal matrix.

The SVD is computed using a divide and conquer approach.

The routine also computes the SVD of the matrix:

 T = sigma*I + A

and returns the singular values in the array S.

Arguments

n
The order of the matrices A and B. n >= 0.
k
The number of singular values to be computed. 0 <= k <= n.
A
On entry, the complex array A of dimension (lda, n).
On exit, the array A is overwritten by information about the SVD.
lda
The leading dimension of the array A. lda >= max(1, n).
B
On entry, the complex array B of dimension (ldb, n).
On exit, the array B is overwritten by information about the SVD.
ldb
The leading dimension of the array B. ldb >= max(1, n).
sigma
The scalar value sigma.
S
On exit, the real array S of dimension n. Contains the singular values of T = sigma*I + A in descending order.
U
On exit, the complex array U of dimension (ldu, n). Contains the unitary matrix U.
ldu
The leading dimension of the array U. ldu >= max(1, n).
V
On exit, the complex array V of dimension (ldv, n). Contains the unitary matrix V.
ldv
The leading dimension of the array V. ldv >= max(1, n).
C
On exit, the complex array C of dimension (ldc, n). Contains the diagonal matrix C.
ldc
The leading dimension of the array C. ldc >= max(1, n).

work
On exit, the complex array work of dimension (lwork).
lwork
The dimension of the array work. lwork >= max(1, 2*n).
iwork
On exit, the integer array iwork of dimension (liwork).
liwork
The dimension of the array iwork. liwork >= max(1, 2*n).
info

info = 0: successful exit

info < 0: if info = -i, the i-th argument had an illegal value.

info > 0: if info = i, the algorithm did not converge for the i-th singular value. The diagonal element S(i) will be incorrect. Suggestion: Check the input data and/or repeat with different WHTSVD.

info = 3 :: The computation of the eigenvalues did not converge.

info = 4 :: If data scaling was requested on input and the procedure found inconsistency in the data such that for some column index i, X(:,i) = 0 but Y(:,i) /= 0, then Y(:,i) is set to zero if JOBS=='C'. The computation proceeds with original or modified data and warning flag is set with INFO=4.
