DOCUMENTACIÓN DE FUNCIÓN/SUBRUTINA

subrutina zgegv (character jobvl, character jobvr, integer n, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( ldb, * ) b, integer ldb, complex*16, dimension( * ) alpha, complex*16, dimension( * ) beta, complex*16, dimension( ldvl, * ) vl, integer ldvl, complex*16, dimension( ldvr, * ) vr, integer ldvr, complex*16, dimension( * ) work, integer lwork, double precision, dimension( * ) rwork, integer info)

ZGEGV calcula los valores propios y, opcionalmente, los vectores propios izquierdos y/o derechos de un par de matrices complejas (A,B).

Propósito:

!>
!> Esta rutina está obsoleta y ha sido reemplazada por la rutina ZGGEV.
!>
!> ZGEGV calcula los valores propios y, opcionalmente, los vectores propios izquierdos y/o derechos de un par de matrices complejas (A,B).
!> Dadas dos matrices cuadradas A y B,
!> el problema de valores propios generalizado no simétrico (GNEP) consiste en encontrar los
!> valores propios lambda y los vectores propios correspondientes (no nulos) x tales
!> que
!>    A*x = lambda*B*x.
!>
!> Una forma alternativa es encontrar los valores propios mu y los vectores propios correspondientes y
!> tales que
!>    mu*A*y = B*y.
!>
!> Estas dos formas son equivalentes con mu = 1/lambda e x = y si
!> ni lambda ni mu son cero. Para tratar el caso en que
!> lambda o mu son cero o pequeños, se devuelven dos valores alpha y beta
!> para cada valor propio, tales que lambda = alpha/beta y
!> mu = beta/alpha.
!>
!> Los vectores x e y en las ecuaciones anteriores son vectores propios derechos del
!> par de matrices (A,B). Los vectores u y v que satisfacen
!>    u**H*A = lambda*u**H*B  o  mu*v**H*A = v**H*B
!> son vectores propios izquierdos de (A,B).
!>
!> Nota: esta rutina realiza en A y B
!>

Parámetros

JOBVL 
!>          JOBVL es CHARACTER*1
!>          = 'N':  no calcular los vectores propios generalizados izquierdos;
!>          = 'V':  calcular los vectores propios generalizados izquierdos (devueltos
!>                  en VL).
!>

JOBVR

!>          JOBVR es CHARACTER*1
!>          = 'N':  no calcular los vectores propios generalizados derechos;
!>          = 'V':  calcular los vectores propios generalizados derechos (devueltos
!>                  en VR).
!>

N

!>          N es INTEGER
!>          El orden de las matrices A, B, VL y VR. N >= 0.
!>

A

!>          A es COMPLEX*16 array, dimension (LDA, N)
!>          En la entrada, la matriz A.
!>          Si JOBVL = 'V' o JOBVR = 'V', entonces en la salida A
!>          contiene la forma de Schur de A de la factorización de Schur
!>          generalizada del par (A,B) después de equilibrar. Si no se
!>          calcularon vectores propios, entonces solo los elementos diagonales
!>          de la forma de Schur serán correctos. Ver ZGGHRD y ZHGEQZ
!>          para más detalles.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal de A. LDA >= max(1,N).
!>

B

!>          B es COMPLEX*16 array, dimension (LDB, N)
!>          En la entrada, la matriz B.
!>          Si JOBVL = 'V' o JOBVR = 'V', entonces en la salida B contiene la
!>          matriz triangular superior obtenida de B en la factorización de Schur
!>          generalizada del par (A,B) después de equilibrar.
!>          Si no se calcularon vectores propios, entonces solo los elementos diagonales
!>          de B serán correctos. Ver ZGGHRD y ZHGEQZ para
!>          más detalles.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal de B. LDB >= max(1,N).
!>

ALPHA

!>          ALPHA es COMPLEX*16 array, dimension (N)
!>          Los escalares complejos alpha que definen los valores propios del
!>          GNEP.
!>

BETA

!>          BETA es COMPLEX*16 array, dimension (N)
!>          Los escalares complejos beta que definen los valores propios del GNEP.
!>
!>          Juntos, las cantidades alpha = ALPHA(j) y beta = BETA(j)
!>          representan el j-ésimo valor propio del par de matrices (A,B), en
!>          una de las formas lambda = alpha/beta o mu = beta/alpha.
!>          Dado que lambda o mu pueden desbordar, no deben,
!>          en general, ser calculados.
!>

VL

!>          VL es COMPLEX*16 array, dimension (LDVL,N)
!>          Si JOBVL = 'V', los vectores propios izquierdos u(j) se almacenan
!>          en las columnas de VL, en el mismo orden que sus valores propios.
!>          Cada vector propio se escala de modo que su componente más grande tenga
!>          abs(parte real) + abs(parte imaginaria) = 1, excepto para los vectores propios
!>          correspondientes a un valor propio con alpha = beta = 0, que
!>          se establecen en cero.
!>          No referenciado si JOBVL = 'N'.
!>

LDVL

!>          LDVL es INTEGER
!>          La dimensión principal de la matriz VL. LDVL >= 1, y
!>          si JOBVL = 'V', LDVL >= N.
!>

VR

!>          VR es COMPLEX*16 array, dimension (LDVR,N)
!>          Si JOBVR = 'V', los vectores propios derechos x(j) se almacenan
!>          en las columnas de VR, en el mismo orden que sus valores propios.
!>          Cada vector propio se escala de modo que su componente más grande tenga
!>          abs(parte real) + abs(parte imaginaria) = 1, excepto para los vectores propios
!>          correspondientes a un valor propio con alpha = beta = 0, que
!>          se establecen en cero.
!>          No referenciado si JOBVR = 'N'.
!>

LDVR

!>          LDVR es INTEGER
!>          La dimensión principal de la matriz VR. LDVR >= 1, y
!>          si JOBVR = 'V', LDVR >= N.
!>

WORK

!>          WORK es COMPLEX*16 array, dimension (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK. LWORK >= max(1,2*N).
!>          Para un buen rendimiento, LWORK generalmente debe ser mayor.
!>          Para calcular el valor óptimo de LWORK, llame a ILAENV para obtener
!>          los tamaños de bloque (para ZGEQRF, ZUNMQR y ZUNGQR). Luego calcule:
!>          NB -- MAX de los tamaños de bloque para ZGEQRF, ZUNMQR y ZUNGQR;
!>          El LWORK óptimo es MAX( 2*N, N*(NB+1) ).
!>
!>          Si LWORK = -1, se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo del array WORK, devuelve
!>          este valor como la primera entrada del array WORK, y XERBLA no emite
!>          ningún mensaje de error relacionado con LWORK.
!>

RWORK

!>          RWORK es DOUBLE PRECISION array, dimension (8*N)
!>

INFO

Function/Subroutine Documentation

ZGEGV computes the generalized eigenvalues for each pair of complex vectors of the form (A, B), such that A*x = lambda*B*x.

Left generalized eigenvectors are computed if JOBVL is 'V'; otherwise, they are not computed.

Right generalized eigenvectors are computed if JOBVR is 'V'; otherwise, they are not computed.

The eigenvalues are computed at no extra cost. The eigenvectors are computed at an extra cost of

O(n**3), which involves matrix multiplications of

O(n**3) during the BGGBAK call.

Arguments:

JOBVL – CHARACTER*1.
If JOBVL =‘N’, then do not compute the left generalized eigenvectors of A and B.
JOBVL – CHARACTER*1.
If JOBVL =‘V’, then compute the left generalized eigenvectors of A and B.
JOBVR – CHARACTER*1.
If JOBVR =‘N’, then do not compute the right generalized eigenvectors of A and B.
JOBVR – CHARACTER*1.
If JOBVR =‘V’, then compute the right generalized eigenvectors of A and B.
N – INTEGER.
The order of the matrices A and B. N • 0.
A – COMPLEX*16 array, dimension (LDA, N).
On entry, the first N rows and N columns of A. On exit, if JOBVL =‘V’ or JOBVR =‘V’, A is overwritten by its upper triangular matrix.
LDA – INTEGER.
The leading dimension of A.
B – COMPLEX*16 array, dimension (LDB, N).
On entry, the first N rows and N columns of B. On exit, B is overwritten by its upper triangular matrix.
LDB – INTEGER.
The leading dimension of B.
ALPHA – COMPLEX*16 array, dimension (N).
On exit, ALPHA(i) contains the numerator of the ith generalized eigenvalue.
BETA – COMPLEX*16 array, dimension (N).
On exit, BETA(i) contains the denominator of the ith generalized eigenvalue.
VL – COMPLEX*16 array, dimension (LDVL, N).
On exit, if JOBVL =‘V’, VL contains the normalized left generalized eigenvectors, such that the column VL(i) is the left generalized eigenvector corresponding to the eigenvalue ALPHA(i)/BETA(i). On exit, if JOBVL =‘N’, the unused portion of the array VL is not modified.
LDVL – INTEGER.
The leading dimension of the array VL.
VR – COMPLEX*16 array, dimension (LDVR, N).
On exit, if JOBVR =‘V’, VR contains the normalized right generalized eigenvectors, such that the column VR(i) is the right generalized eigenvector corresponding to the eigenvalue ALPHA(i)/BETA(i). On exit, if JOBVR =‘N’, the unused portion of the array VR is not modified.
LDVR – INTEGER.
The leading dimension of the array VR.
WORK – COMPLEX*16 array, dimension (LWORK).
On exit, if LWORK = -1, WORK(1) contains the optimal LWORK.
LWORK – INTEGER.
The dimension of the array WORK.
RWORK – REAL*8 array, dimension (max(1, 8*N)).
On exit, if LWORK = -1, RWORK(1) contains the optimal LWORK.
INFO – INTEGER.
  • INFO = 0: success
  • INFO < 0: if INFO = -i, the i-th argument had an illegal value.
  • INFO = 1: some or all eigenvalues converged after 30*N maxit iterations.
  • INFO = 2: the algorithm did not converge; if INFO = 2, let N = N+2, error return from ZGEQPF
  • INFO = 3: the algorithm did not converge; if INFO = 3, let N = N+3, error return from ZTGEVC
  • INFO = 4: the algorithm did not converge; if INFO = 4, let N = N+4, error return from ZGEBAL
  • INFO = 5: the algorithm did not converge; if INFO = 5, let N = N+5, error return from ZGEES
  • INFO = 6: the algorithm did not converge; if INFO = 6, let N = N+6, error return from ZTGEVC
  • INFO = 7: error return from ZTGEVC
  • INFO = N+1: error return from ZTGEVC
  • INFO = N+2: error return from ZGGBAK (computing VL)
  • INFO = N+3: error return from ZGGBAK (computing VR)
  • INFO = N+4: error return from ZLASCL (various calls)

Further Details:

 Balancing
 ---------
 This driver calls ZGGBAL to both permute and scale rows and columns
 of A and B. The permutations PL and PR are chosen so that PL*A*PR
 and PL*B*R will be upper triangular except for the diagonal blocks
 A(i:j,i:j) and B(i:j,i:j), with i and j as close together as
 possible. The diagonal scaling matrices DL and DR are chosen so
 that the pair DL*PL*A*PR*DR, DL*PL*B*PR*DR have elements close to
 one (except for the elements that start out zero.)
 After the eigenvalues and eigenvectors of the balanced matrices
 have been computed, ZGGBAK transforms the eigenvectors back to what
 they would have been (in perfect arithmetic) if they had not been
 balanced.
 Contents of A and B on Exit
 -------- -- - --- - -- ----
 If any eigenvectors are computed (either JOBVL='V' or JOBVR='V' or
 both), then on exit the arrays A and B will contain the complex Schur
 form[*] of the versions of A and B. If no eigenvectors
 are computed, then only the diagonal blocks will be correct.
 [*] In other words, upper triangular form.
