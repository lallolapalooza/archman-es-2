subrutina zgebd2 (m, n, a, lda, d, e, tauq, taup, work, info)


ZGEBD2 reduce una matriz general a forma bidiagonal utilizando un algoritmo sin bloqueo.

Documentación de función/subrutina

subrutina zgebd2 (integer m, integer n, complex*16, dimension( lda, * ) a, integer lda, double precision, dimension( * ) d, double precision, dimension( * ) e, complex*16, dimension( * ) tauq, complex*16, dimension( * ) taup, complex*16, dimension( * ) work, integer info)

ZGEBD2 reduce una matriz general a forma bidiagonal utilizando un algoritmo sin bloqueo.

Propósito:

!>
!> ZGEBD2 reduce una matriz general compleja m por n, A, a una forma bidiagonal
!> real superior o inferior B mediante una transformación unitaria: Q**H * A * P = B.
!>
!> Si m >= n, B es bidiagonal superior; si m < n, B es bidiagonal inferior.
!>

Parámetros

M 
!>          M es ENTERO
!>          El número de filas de la matriz A.  M >= 0.
!>

N

!>          N es ENTERO
!>          El número de columnas de la matriz A.  N >= 0.
!>

A

!>          A es un array COMPLEX*16, de dimensión (LDA,N)
!>          En la entrada, la matriz general m por n a reducir.
!>          En la salida,
!>          si m >= n, la diagonal y la primera superdiagonal se sobrescriben
!>            con la matriz bidiagonal superior B; los elementos debajo de la
!>            diagonal, junto con el array TAUQ, representan la matriz unitaria
!>            Q como un producto de   reflejos elementales, y los elementos
!>            por encima de la primera superdiagonal, junto con el array TAUP,
!>            representan la matriz unitaria P como un producto de reflejos
!>            elementales;
!>          si m < n, la diagonal y la primera subdiagonal se sobrescriben
!>            con la matriz bidiagonal inferior B; los elementos debajo de la
!>            primera subdiagonal, junto con el array TAUQ, representan la matriz
!>            unitaria Q como un producto de   reflejos elementales, y los
!>            elementos por encima de la diagonal, junto con el array TAUP,
!>            representan la matriz unitaria P como un producto de reflejos
!>            elementales.
!>          Ver Detalles Adicionales.
!>

LDA

!>          LDA es ENTERO
!>          La dimensión principal del array A.  LDA >= max(1,M).
!>

D

!>          D es un array DOUBLE PRECISION, de dimensión (min(M,N))
!>          Los elementos diagonales de la matriz bidiagonal B:
!>          D(i) = A(i,i).
!>

E

!>          E es un array DOUBLE PRECISION, de dimensión (min(M,N)-1)
!>          Los elementos fuera de la diagonal de la matriz bidiagonal B:
!>          si m >= n, E(i) = A(i,i+1) para i = 1,2,...,n-1;
!>          si m < n, E(i) = A(i+1,i) para i = 1,2,...,m-1.
!>

TAUQ

!>          TAUQ es un array COMPLEX*16, de dimensión (min(M,N))
!>          Los factores escalares de los reflejos elementales que
!>          representan la matriz unitaria Q. Ver Detalles Adicionales.
!>

TAUP

!>          TAUP es un array COMPLEX*16, de dimensión (min(M,N))
!>          Los factores escalares de los reflejos elementales que
!>          representan la matriz unitaria P. Ver Detalles Adicionales.
!>

WORK

!>          WORK es un array COMPLEX*16, de dimensión (max(M,N))
!>

INFO

!>          INFO es ENTERO
!>          = 0: salida exitosa
!>          < 0: si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>

Detalles Adicionales:

!>
!>  Las matrices Q y P se representan como productos de reflejos
!>  elementales:
!>
!>  Si m >= n,
!>
!>     Q = H(1) H(2) . . . H(n)  y  P = G(1) G(2) . . . G(n-1)
!>
!>  Cada H(i) y G(i) tiene la forma:
!>
!>     H(i) = I - tauq * v * v**H  y G(i) = I - taup * u * u**H
!>
!>  donde tauq y taup son escalares complejos, y v y u son vectores complejos;
!>  v(1:i-1) = 0, v(i) = 1, y v(i+1:m) se almacena en la salida en
!>  A(i+1:m,i); u(1:i) = 0, u(i+1) = 1, y u(i+2:n) se almacena en la salida en
!>  A(i,i+2:n); tauq se almacena en TAUQ(i) y taup en TAUP(i).
!>
!>  Si m < n,
!>
!>     Q = H(1) H(2) . . . H(m-1)  y  P = G(1) G(2) . . . G(m)
!>
!>  Cada H(i) y G(i) tiene la forma:
!>
!>     H(i) = I - tauq * v * v**H  y G(i) = I - taup * u * u**H
!>
!>  donde tauq y taup son escalares complejos, v y u son vectores complejos;
!>  v(1:i) = 0, v(i+1) = 1, y v(i+2:m) se almacena en la salida en A(i+2:m,i);
!>  u(1:i-1) = 0, u(i) = 1, y u(i+1:n) se almacena en la salida en
!>  A(i,i+1:n); tauq se almacena en TAUQ(i) y taup en TAUP(i).
!>
!>  Los contenidos de A en la salida se ilustran mediante los siguientes ejemplos:
!>
!>  m = 6 y n = 5 (m > n):          m = 5 y n = 6 (m < n):
!>
!>    (  d   e   u1  u1  u1 )           (  d   u1  u1  u1  u1  u1 )
!>    (  v1  d   e   u2  u2 )           (  e   d   u2  u2  u2  u2 )
!>    (  v1  v2  d   e   u3 )           (  v1  e   d   u3  u3  u3 )
!>    (  v1  v2  v3  d   e  )           (  v1  v2  e   d   u4  u4 )
!>    (  v1  v2  v3  v4  d  )           (  v1  v2  v3  e   d   u5 )
!>    (  v1  v2  v3  v4  v5 )
!>
!>  donde d y e denotan elementos diagonales y fuera de la diagonal de B, vi
!>  denota un elemento del vector que define H(i), y ui un elemento del
!>  vector que define G(i).
!>
