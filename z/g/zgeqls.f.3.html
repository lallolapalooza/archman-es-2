Documentación de la Función/Subrutina

subrutina zgeqls (integer m, integer n, integer nrhs, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( * ) tau, complex*16, dimension( ldb, * ) b, integer ldb, complex*16, dimension( lwork ) work, integer lwork, integer info)

ZGEQLS

Propósito:

!>
!> Resolver el problema de mínimos cuadrados
!>     min || A*X - B ||
!> usando la factorización QL
!>     A = Q*L
!> calculada por ZGEQLF.
!>

Parámetros

M 
!>          M es ENTERO
!>          El número de filas de la matriz A.  M >= 0.
!>

N

!>          N es ENTERO
!>          El número de columnas de la matriz A.  M >= N >= 0.
!>

NRHS

!>          NRHS es ENTERO
!>          El número de columnas de B.  NRHS >= 0.
!>

A

!>          A es un array de COMPLEX*16, dimensión (LDA,N)
!>          Detalles de la factorización QL de la matriz original A como
!>          devuelto por ZGEQLF.
!>

LDA

!>          LDA es ENTERO
!>          La dimensión principal del array A.  LDA >= M.
!>

TAU

!>          TAU es un array de COMPLEX*16, dimensión (N)
!>          Detalles de la matriz ortogonal Q.
!>

B

!>          B es un array de COMPLEX*16, dimensión (LDB,NRHS)
!>          En la entrada, la matriz B del lado derecho de m x nrhs.
!>          En la salida, la matriz solución X de n x nrhs, almacenada en las filas
!>          m-n+1:m.
!>

LDB

!>          LDB es ENTERO
!>          La dimensión principal del array B. LDB >= M.
!>

WORK

!>          WORK es un array de COMPLEX*16, dimensión (LWORK)
!>

LWORK

!>          LWORK es ENTERO
!>          La longitud del array WORK.  LWORK debe ser al menos NRHS,
!>          y debe ser al menos NRHS*NB, donde NB es el tamaño del bloque
!>          para este entorno.
!>

INFO

!>          INFO es ENTERO
!>          = 0: salida exitosa
!>          < 0: si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>
