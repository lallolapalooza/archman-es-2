subroutine zgeesx (character jobvs, character sort, external select, character sense, integer n, complex*16, dimension( lda, * ) a, integer lda, integer sdim, complex*16, dimension( * ) w, complex*16, dimension( ldvs, * ) vs, integer ldvs, double precision rconde, double precision rcondv, complex*16, dimension( * ) work, integer lwork, double precision, dimension( * ) rwork, logical, dimension( * ) bwork, integer info)

ZGEESX calcula los valores propios, la forma de Schur y, opcionalmente, la matriz de vectores de Schur para matrices GE

Propósito:

!>
!> ZGEESX calcula para una matriz compleja N-por-N no simétrica A, los
!> valores propios, la forma de Schur T y, opcionalmente, la matriz de vectores
!> de Schur Z. Esto da la factorización de Schur A = Z*T*(Z**H).
!>
!> Opcionalmente, también ordena los valores propios en la diagonal de la
!> forma de Schur para que los valores propios seleccionados estén en la parte
!> superior izquierda;
!> calcula un número de condición recíproco para el promedio de los
!> valores propios seleccionados (RCONDE); y calcula un número de condición
!> recíproco para el subespacio invariante derecho correspondiente a los
!> valores propios seleccionados (RCONDV). Las columnas principales de Z forman una
!> base ortonormal para este subespacio invariante.
!>
!> Para más explicación de los números de condición recíprocos RCONDE
!> y RCONDV, véase la Sección 4.10 de la Guía del Usuario de LAPACK (donde
!> estas cantidades se llaman s y sep respectivamente).
!>
!> Una matriz compleja está en forma de Schur si es triangular superior.
!>

Parámetros

JOBVS 
!>          JOBVS es CHARACTER*1
!>          = 'N': No se calculan los vectores de Schur;
!>          = 'V': Se calculan los vectores de Schur.
!>

SORT

!>          SORT es CHARACTER*1
!>          Especifica si se deben ordenar o no los valores propios en la
!>          diagonal de la forma de Schur.
!>          = 'N': Los valores propios no se ordenan;
!>          = 'S': Los valores propios se ordenan (ver SELECT).
!>

SELECT

!>          SELECT es una FUNCIÓN LOGICA de un argumento COMPLEX*16
!>          SELECT debe ser declarada EXTERNA en la subrutina que la llama.
!>          Si SORT = 'S', SELECT se usa para seleccionar los valores propios a ordenar
!>          en la parte superior izquierda de la forma de Schur.
!>          Si SORT = 'N', SELECT no se referencia.
!>          Un valor propio W(j) se selecciona si SELECT(W(j)) es verdadero.
!>

SENSE

!>          SENSE es CHARACTER*1
!>          Determina qué números de condición recíprocos se calculan.
!>          = 'N': No se calcula ninguno;
!>          = 'E': Se calcula solo para el promedio de los valores propios seleccionados;
!>          = 'V': Se calcula solo para el subespacio invariante derecho seleccionado;
!>          = 'B': Se calcula para ambos.
!>          Si SENSE = 'E', 'V' o 'B', SORT debe ser igual a 'S'.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A. N >= 0.
!>

A

!>          A es una matriz COMPLEX*16, dimensión (LDA, N)
!>          En la entrada, la matriz N-por-N A.
!>          En la salida, A se sobrescribe con su forma de Schur T.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal de la matriz A.  LDA >= max(1,N).
!>

SDIM

!>          SDIM es INTEGER
!>          Si SORT = 'N', SDIM = 0.
!>          Si SORT = 'S', SDIM = número de valores propios para los que
!>                         SELECT es verdadero.
!>

W

!>          W es una matriz COMPLEX*16, dimensión (N)
!>          W contiene los valores propios calculados, en el mismo orden
!>          en que aparecen en la diagonal de la forma de Schur de salida T.
!>

VS

!>          VS es una matriz COMPLEX*16, dimensión (LDVS,N)
!>          Si JOBVS = 'V', VS contiene la matriz unitaria Z de vectores
!>          de Schur.
!>          Si JOBVS = 'N', VS no se referencia.
!>

LDVS

!>          LDVS es INTEGER
!>          La dimensión principal de la matriz VS.  LDVS >= 1, y si
!>          JOBVS = 'V', LDVS >= N.
!>

RCONDE

!>          RCONDE es DOUBLE PRECISION
!>          Si SENSE = 'E' o 'B', RCONDE contiene el número de condición
!>          recíproco para el promedio de los valores propios seleccionados.
!>          No se referencia si SENSE = 'N' o 'V'.
!>

RCONDV

!>          RCONDV es DOUBLE PRECISION
!>          Si SENSE = 'V' o 'B', RCONDV contiene el número de condición
!>          recíproco para el subespacio invariante derecho seleccionado.
!>          No se referencia si SENSE = 'N' o 'E'.
!>

WORK

!>          WORK es una matriz COMPLEX*16, dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión de la matriz WORK.  LWORK >= max(1,2*N).
!>          Además, si SENSE = 'E' o 'V' o 'B', LWORK >= 2*SDIM*(N-SDIM),
!>          donde SDIM es el número de valores propios seleccionados calculados por
!>          esta rutina.  Tenga en cuenta que 2*SDIM*(N-SDIM) <= N*N/2. Tenga en cuenta también
!>          que solo se devuelve un error si LWORK < max(1,2*N), pero si
!>          SENSE = 'E' o 'V' o 'B', esto puede no ser suficiente.
!>          Para un buen rendimiento, LWORK generalmente debe ser mayor.
!>
!>          Si LWORK = -1, se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el límite superior del tamaño óptimo de la
!>          matriz WORK, devuelve este valor como la primera entrada de la
!>          matriz WORK, y XERBLA no emite ningún mensaje de error relacionado con LWORK.
!>

RWORK

!>          RWORK es una matriz DOUBLE PRECISION, dimensión (N)
!>

BWORK

!>          BWORK es una matriz LOGICAL, dimensión (N)
!>          No se referencia si SORT = 'N'.
!>

INFO

!>          INFO es INTEGER
!>          = 0: finalización exitosa
!>          < 0: si INFO = -i, el argumento i tuvo un valor ilegal.
!>          > 0: si INFO = i, y i es
!>             <= N: el algoritmo QR falló en calcular todos los
!>                   valores propios; los elementos 1:ILO-1 y i+1:N de W
!>                   contienen aquellos valores propios que han convergido; si
!>                   JOBVS = 'V', VS contiene la transformación que
!>                   reduce A a su forma de Schur parcialmente convergida.
!>             = N+1: los valores propios no pudieron ser reordenados porque algunos
!>                   valores propios estaban demasiado cerca para separarse (el problema
!>                   es muy mal condicionado);
!>             = N+2: después de reordenar, el redondeo cambió los valores de algunos
!>                   valores propios complejos de tal manera que los valores propios principales
!>                   en la forma de Schur ya no satisfacen SELECT=.TRUE. Esto
!>                   también podría ser causado por un subdesbordamiento debido al escalado.
!>
