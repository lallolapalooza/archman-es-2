Documentación de Función/Subrutina

subrutina zget07 (character trans, integer n, integer nrhs, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( ldb, * ) b, integer ldb, complex*16, dimension( ldx, * ) x, integer ldx, complex*16, dimension( ldxact, * ) xact, integer ldxact, double precision, dimension( * ) ferr, logical chkferr, double precision, dimension( * ) berr, double precision, dimension( * ) reslts)

ZGET07

Propósito:

!>
!> ZGET07 prueba los límites de error del refinamiento iterativo para la
!> solución calculada de un sistema de ecuaciones op(A)*X = B, donde A es una
!> matriz general de n por n y op(A) = A o A**T, dependiendo de TRANS.
!>
!> RESLTS(1) = prueba del límite de error
!>           = norm(X - XACT) / ( norm(X) * FERR )
!>
!> Se devuelve un valor grande si esta relación no es menor que uno.
!>
!> RESLTS(2) = residuo de la rutina de refinamiento iterativo
!>           = el máximo de BERR / ( (n+1)*EPS + (*) ), donde
!>             (*) = (n+1)*UNFL / (min_i (abs(op(A))*abs(X) +abs(b))_i )
!>

Parámetros

TRANS 
!>          TRANS es CHARACTER*1
!>          Especifica la forma del sistema de ecuaciones.
!>          = 'N':  A * X = B     (Sin transponer)
!>          = 'T':  A**T * X = B  (Transpuesta)
!>          = 'C':  A**H * X = B  (Transpuesta conjugada = Transpuesta)
!>

N

!>          N es INTEGER
!>          El número de filas de las matrices X y XACT.  N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de columnas de las matrices X y XACT.  NRHS >= 0.
!>

A

!>          A es un array COMPLEX*16, dimensión (LDA,N)
!>          La matriz original A de n por n.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

B

!>          B es un array COMPLEX*16, dimensión (LDB,NRHS)
!>          Los vectores del lado derecho para el sistema de ecuaciones
!>          lineales.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B.  LDB >= max(1,N).
!>

X

!>          X es un array COMPLEX*16, dimensión (LDX,NRHS)
!>          Los vectores de solución calculados. Cada vector se almacena como
!>          una columna de la matriz X.
!>

LDX

!>          LDX es INTEGER
!>          La dimensión principal del array X.  LDX >= max(1,N).
!>

XACT

!>          XACT es un array COMPLEX*16, dimensión (LDXACT,NRHS)
!>          Los vectores de solución exactos. Cada vector se almacena como
!>          una columna de la matriz XACT.
!>

LDXACT

!>          LDXACT es INTEGER
!>          La dimensión principal del array XACT.  LDXACT >= max(1,N).
!>

FERR

!>          FERR es un array DOUBLE PRECISION, dimensión (NRHS)
!>          Los límites de error directo estimados para cada vector solución
!>          X.  Si XTRUE es la solución verdadera, FERR limita la magnitud
!>          de la entrada más grande en (X - XTRUE) dividida por la magnitud
!>          de la entrada más grande en X.
!>

CHKFERR

!>          CHKFERR es LOGICAL
!>          Se establece en .TRUE. para comprobar FERR, .FALSE. para no
!>          comprobar FERR.
!>          Cuando el sistema de prueba está mal condicionado, la
!>          solución en XACT puede ser incorrecta.
!>

BERR

!>          BERR es un array DOUBLE PRECISION, dimensión (NRHS)
!>          El error relativo componente a componente de cada vector solución
!>          (es decir, el cambio relativo más pequeño en cualquier entrada de A
!>          o B que haga que X sea una solución exacta).
!>

RESLTS

!>          RESLTS es un array DOUBLE PRECISION, dimensión (2)
!>          El máximo sobre los vectores de solución NRHS de las relaciones:
!>          RESLTS(1) = norm(X - XACT) / ( norm(X) * FERR )
!>          RESLTS(2) = BERR / ( (n+1)*EPS + (*) )
!>
