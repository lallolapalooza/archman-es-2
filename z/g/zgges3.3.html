Documentación de la función/subrutina

subrutina zgges3 (character jobvsl, character jobvsr, character sort, external selctg, integer n, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( ldb, * ) b, integer ldb, integer sdim, complex*16, dimension( * ) alpha, complex*16, dimension( * ) beta, complex*16, dimension( ldvsl, * ) vsl, integer ldvsl, complex*16, dimension( ldvsr, * ) vsr, integer ldvsr, complex*16, dimension( * ) work, integer lwork, double precision, dimension( * ) rwork, logical, dimension( * ) bwork, integer info)

ZGGES3 calcula los valores propios, la forma de Schur generalizada y, opcionalmente, los vectores de Schur izquierdos y/o derechos para matrices complejas N por N no simétricas (A,B), la forma de Schur generalizada (S, T), y opcionalmente vectores de Schur izquierdos y/o derechos (VSL y VSR). Esto da la factorización de Schur generalizada (A,B) = ( (VSL)*S*(VSR)**H, (VSL)*T*(VSR)**H ) donde (VSR)**H es la transpuesta conjugada de VSR. Opcionalmente, también ordena los valores propios para que un grupo seleccionado de valores propios aparezca en los bloques de diagonal principales de la matriz triangular superior S y la matriz triangular superior T. Las columnas principales de VSL y VSR forman entonces una base unitaria para los correspondientes subespacios propios izquierdos y derechos (subespacios de deflexión). (Si solo se necesitan los valores propios generalizados, use el controlador ZGGEV en su lugar, que es más rápido.) Un valor propio generalizado para un par de matrices (A,B) es un escalar w o una relación alpha/beta = w, tal que A - w*B es singular. Se suele representar como el par (alpha,beta), ya que hay una interpretación razonable para beta=0, e incluso para que ambos sean cero. Un par de matrices (S,T) está en forma de Schur compleja generalizada si S y T son triangulares superiores y, además, los elementos de la diagonal de T son números reales no negativos.

NAME

zgges3 — Calculates the Schur decomposition of a complex generalized eigenvalue problem.

SYNOPSIS

  SUBROUTINE ZGGES3( JOBVSL, JOBVSR, SORT, SELCTG, N, A, LDA, B, LDB,
                        SDIM, VSLA, LDSLA, VSRB, LDVSRB, WORK, LWORK,
                        RWORK, IWORK, BWORK, INFO )
    CHARACTER          JOBVSL, JOBVSR, SORT
    LOGICAL            SELCTG
    INTEGER            N, LDA, LDB, SDIM, LDSLA, LDVSRB, LWORK, INFO
    COMPLEX*16         A( LDA, * ), B( LDB, * ), VSLA( LDSLA, * ),
                        VSRB( LDVSRB, * )
    COMPLEX*16         WORK( * )
    DOUBLE PRECISION   RWORK( * )
    LOGICAL            IWORK( * ), BWORK( * )

Function/Subroutine Documentation

ZGGES3 computes the generalized Schur decomposition of a complex pair (A, B) in the form (A, B) = (VSLA*A*VSRBH, VSLA*B*VSRBH), such that A is upper triangular and B is upper triangular (block diagonal). If requested, the decomposition is such that all the selected leading generalized eigenvalues are those in the SLCT array for which SELCTG returns .TRUE.

The function also computes the Schur vectors VSL and VSR, and the generalized eigenvalues.

Arguments:

JOBVSL
CHARACTER*1.
= 'N': Do not compute the left Schur vectors (VSLA).
= 'V': Compute the left Schur vectors (VSLA).
JOBVSR
CHARACTER*1.
= 'N': Do not compute the right Schur vectors (VSRB).
= 'V': Compute the right Schur vectors (VSRB).
SORT
CHARACTER*1.
= 'N': Compute the generalized Schur decomposition without sorting.
= 'S': Compute the generalized Schur decomposition with sorting. Eigenvalues are sorted according to the SELCTG array.
SELCTG
LOGICAL. User-provided selection function.
If SORT = 'S', SELCTG is used to select the generalized eigenvalues.
For each i = 1, ..., N, if SELCTG(ALPHA(i)) is .TRUE., then the i-th generalized eigenvalue (ALPHA(i), BETA(i)) is selected.
If SORT = 'N', SELCTG is not referenced.
N
INTEGER. The order of the matrices A and B.
A
COMPLEX*16 array, dimension (LDA, *). On entry, the N-by-N-matrix A.
On exit, A is overwritten by its upper triangular form.
LDA
INTEGER. The leading dimension of A.
B
COMPLEX*16 array, dimension (LDB, *). On entry, the N-by-N-matrix B.
On exit, B is overwritten by its upper triangular block diagonal form.
LDB
INTEGER. The leading dimension of B.
SDIM
INTEGER. The number of selected generalized eigenvalues.
If SORT = 'S', SDIM = number of elements for which SELCTG is .TRUE.
If SORT = 'N', SDIM = 0.
VSLA
COMPLEX*16 array, dimension (LDSLA, *). If JOBVSL = 'V', VSLA is an N-by-N matrix which contains the left Schur vectors (columns).
LDSLA
INTEGER. The leading dimension of VSLA.
VSRB
COMPLEX*16 array, dimension (LDVSRB, *). If JOBVSR = 'V', VSRB is an N-by-N matrix which contains the right Schur vectors (columns).
LDVSRB
INTEGER. The leading dimension of VSRB.
WORK
COMPLEX*16 array, dimension (LWORK). Used for workspace.
On exit, WORK(1) contains the minimum LWORK.
LWORK
INTEGER. The dimension of the array WORK.
If LWORK = -1, then only the optimal workspace size is computed.
RWORK
DOUBLE PRECISION array, dimension (max(1, N)).
IWORK
INTEGER array, dimension (max(1, 2*N)).
BWORK
LOGICAL array, dimension (max(1, N)).
INFO
INTEGER.
= 0: successful exit.
< 0: If INFO = -i, the i-th argument had an illegal value.
> 0: If INFO = i, then the QZ iteration failed.
i = 1, ..., N: The QZ iteration failed. (A, B) are not in Schur form, but ALPHA(j) and BETA(j) should be correct for j=INFO+1,...,N.
> N: other than QZ iteration failed in ZLAQZ0
> =N+1: after reordering, roundoff changed values of some complex eigenvalues so that leading eigenvalues in the Generalized Schur form no longer satisfy SELCTG=.TRUE. This could also be caused due to scaling.
> =N+2: reordering failed in ZTGSEN.
