subrutina zgesc2 (n, a, lda, rhs, ipiv, jpiv, scale)
ZGESC2 resuelve un sistema de ecuaciones lineales utilizando la factorización LU con pivoteo completo calculada por sgetc2.

Documentación de Función/Subrutina

subrutina zgesc2 (integer n, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( * ) rhs, integer, dimension( * ) ipiv, integer, dimension( * ) jpiv, double precision scale)

ZGESC2 resuelve un sistema de ecuaciones lineales utilizando la factorización LU con pivoteo completo calculada por sgetc2.

Propósito:

!>
!> ZGESC2 resuelve un sistema de ecuaciones lineales
!>
!>           A * X = scale* RHS
!>
!> con una matriz general N por N, A, utilizando la factorización LU con
!> pivoteo completo calculada por ZGETC2.
!>
!>

Parámetros

N 
!>          N es INTEGER
!>          El número de columnas de la matriz A.
!>

A

!>          A es una matriz COMPLEX*16, de dimensión (LDA, N)
!>          En la entrada, la parte LU de la factorización de la matriz A
!>          de N por N calculada por ZGETC2: A = P * L * U * Q
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal de la matriz A. LDA >= max(1, N).
!>

RHS

!>          RHS es una matriz COMPLEX*16, de dimensión N.
!>          En la entrada, el vector del lado derecho b.
!>          En la salida, el vector solución X.
!>

IPIV

!>          IPIV es una matriz INTEGER, de dimensión (N).
!>          Los índices de pivote; para 1 <= i <= N, la fila i de la
!>          matriz ha sido intercambiada con la fila IPIV(i).
!>

JPIV

!>          JPIV es una matriz INTEGER, de dimensión (N).
!>          Los índices de pivote; para 1 <= j <= N, la columna j de la
!>          matriz ha sido intercambiada con la columna JPIV(j).
!>

SCALE

!>          SCALE es DOUBLE PRECISION
!>           En la salida, SCALE contiene el factor de escala. SCALE se elige
!>           0 <= SCALE <= 1 para prevenir desbordamientos en la solución.
!>
