ZGET23

Propósito:

!>
!>    ZGET23  comprueba el controlador del problema de valores propios no simétricos CGEEVX.
!>    Si COMP = .FALSE., se realizarán las primeras 8 de las siguientes pruebas en
!>    la matriz de entrada A, y también la prueba 9 si LWORK es suficientemente grande.
!>    si COMP es .TRUE., se realizarán las 11 pruebas.
!>
!>    (1)     | A * VR - VR * W | / ( n |A| ulp )
!>
!>      Aquí VR es la matriz de los vectores propios derechos unitarios.
!>      W es una matriz diagonal con entradas diagonales W(j).
!>
!>    (2)     | A**H * VL - VL * W**H | / ( n |A| ulp )
!>
!>      Aquí VL es la matriz de los vectores propios izquierdos unitarios, A**H es la
!>      conjugada transpuesta de A, y W es como se describió anteriormente.
!>
!>    (3)     | |VR(i)| - 1 | / ulp y el componente más grande real
!>
!>      VR(i) denota la i-ésima columna de VR.
!>
!>    (4)     | |VL(i)| - 1 | / ulp y el componente más grande real
!>
!>      VL(i) denota la i-ésima columna de VL.
!>
!>    (5)     0 si W(completa) = W(parcial), 1/ulp en caso contrario
!>
!>      W(completa) denota los valores propios calculados cuando VR, VL, RCONDV
!>      y RCONDE también se calculan, y W(parcial) denota los
!>      valores propios calculados cuando solo algunos de VR, VL, RCONDV y
!>      RCONDE se calculan.
!>
!>    (6)     0 si VR(completa) = VR(parcial), 1/ulp en caso contrario
!>
!>      VR(completa) denota los vectores propios derechos calculados cuando VL, RCONDV
!>      y RCONDE se calculan, y VR(parcial) denota el resultado
!>      cuando solo algunos de VL y RCONDV se calculan.
!>
!>    (7)     0 si VL(completa) = VL(parcial), 1/ulp en caso contrario
!>
!>      VL(completa) denota los vectores propios izquierdos calculados cuando VR, RCONDV
!>      y RCONDE se calculan, y VL(parcial) denota el resultado
!>      cuando solo algunos de VR y RCONDV se calculan.
!>
!>    (8)     0 si SCALE, ILO, IHI, ABNRM (completa) =
!>                 SCALE, ILO, IHI, ABNRM (parcial)
!>            1/ulp en caso contrario
!>
!>      SCALE, ILO, IHI y ABNRM describen cómo se equilibra la matriz.
!>      (completa) es cuando VR, VL, RCONDE y RCONDV también se calculan, y
!>      (parcial) es cuando algunos no se calculan.
!>
!>    (9)     0 si RCONDV(completa) = RCONDV(parcial), 1/ulp en caso contrario
!>
!>      RCONDV(completa) denota los recíprocos de los números de condición de los
!>      vectores propios derechos calculados cuando VR, VL y RCONDE también se calculan.
!>      RCONDV(parcial) denota los recíprocos de los números de condición cuando solo
!>      algunos de VR, VL y RCONDE se calculan.
!>
!>   (10)     |RCONDV - RCDVIN| / cond(RCONDV)
!>
!>      RCONDV es el recíproco del número de condición del vector propio derecho
!>      calculado por ZGEEVX y RCDVIN (el valor verdadero precalculado)
!>      se proporciona como entrada. cond(RCONDV) es el número de condición de
!>      RCONDV, y tiene en cuenta los errores en el cálculo de RCONDV, de modo
!>      que la cantidad resultante debería ser O(ULP). cond(RCONDV) es
!>      esencialmente dado por norm(A)/RCONDE.
!>
!>   (11)     |RCONDE - RCDEIN| / cond(RCONDE)
!>
!>      RCONDE es el recíproco del número de condición del valor propio
!>      calculado por ZGEEVX y RCDEIN (el valor verdadero precalculado)
!>      se proporciona como entrada. cond(RCONDE) es el número de condición de
!>      RCONDE, y tiene en cuenta los errores en el cálculo de RCONDE,
!>      de modo que la cantidad resultante debería ser O(ULP). cond(RCONDE)
!>      es esencialmente dado por norm(A)/RCONDV.
!>

Parámetros

COMP 
!>          COMP es LOGICAL
!>          COMP describe qué pruebas de entrada realizar:
!>            = .FALSE. si los números de condición calculados no deben
!>                      ser probados contra RCDVIN y RCDEIN
!>            = .TRUE.  si deben ser comparados
!>

ISRT

!>          ISRT es INTEGER
!>          Si COMP = .TRUE., ISRT indica cómo se ordenan los valores propios
!>          correspondientes a los valores en RCDVIN y RCDEIN:
!>            = 0 significa que los valores propios se ordenan por
!>                parte real creciente
!>            = 1 significa que los valores propios se ordenan por
!>                parte imaginaria creciente
!>          Si COMP = .FALSE., ISRT no se referencia.
!>

BALANC

!>          BALANC es CHARACTER
!>          Describe la opción de equilibrio a probar.
!>            = 'N' para ninguna permutación o escalado diagonal
!>            = 'P' para permutación pero sin escalado diagonal
!>            = 'S' para ninguna permutación pero con escalado diagonal
!>            = 'B' para permutación y escalado diagonal
!>

JTYPE

!>          JTYPE es INTEGER
!>          Tipo de matriz de entrada. Se utiliza para etiquetar la salida si ocurre un error.
!>

THRESH

!>          THRESH es DOUBLE PRECISION
!>          Una prueba se considerará si el valor calculado,
!>          como se describe anteriormente, excede THRESH. Tenga en cuenta que el error
!>          se escala para que sea O(1), por lo que THRESH debería ser un múltiplo razonablemente
!>          pequeño de 1, por ejemplo, 10 o 100. En particular,
!>          no debe depender de la precisión (simple vs. doble)
!>          o el tamaño de la matriz. Debe ser al menos cero.
!>

ISEED

!>          ISEED es un array INTEGER, de dimensión (4)
!>          Si COMP = .FALSE., la semilla del generador de números aleatorios
!>          utilizado para producir la matriz.
!>          Si COMP = .TRUE., ISEED(1) = el número del ejemplo.
!>          Se utiliza para etiquetar la salida si ocurre un error.
!>

NOUNIT

!>          NOUNIT es INTEGER
!>          El número de unidad FORTRAN para imprimir mensajes de error
!>          (por ejemplo, si una rutina devuelve INFO distinto de 0).
!>

N

!>          N es

zget23 -

Function/Subroutine Documentation

LINE
LINE is CHARACTER*1

Specifies the form of the problem to be solved. Only LINE = 'S' and LINE = 'N' are recognized.

If LINE = 'S', then the following are supplied:

          A, VL, LDVL, VR, LDVR, LRE, LDLRE, W, W1,
          RCONDV, RCNDV1, RCDVIN, RCONDE, RCNDE1, RCDEIN,
          SCALE, SCALE1

and the subroutine ZGET23 tests the output of ZGEEV.

If LINE = 'N', then the following are supplied:

          A, VL, LDVL, VR, LDVR, LRE, LDLRE, W, W1,
          RCONDV, RCNDV1, RCDVIN, RCONDE, RCNDE1, RCDEIN,
          SCALE, SCALE1

and the subroutine ZGET23 tests the output of ZGEEVX.

N
N is INTEGER

The dimension of the matrix A. N must be at least 0.

A
A is COMPLEX*16 array, dimension (LDA,N)

A is the matrix A whose eigenvalues and eigenvectors are approximated. This array is not modified.

LDA
LDA is INTEGER

The leading dimension of A, and H. LDA must be at least 1 and at least N.

H
H is COMPLEX*16 array, dimension (LDA,N)

Another copy of the test matrix A, modified by ZGEEVX. This array is not used if LINE = 'S'.

W
W is COMPLEX*16 array, dimension (N)

Contains the computed eigenvalues of A. Only the first N elements are used.

W1
W1 is COMPLEX*16 array, dimension (N)

Contains the computed eigenvalues of A. Only the first N elements are used.

VL
VL is COMPLEX*16 array, dimension (LDVL,N)

Contains the computed left eigenvectors of A. Only the first N columns are used.

LDVL
LDVL is INTEGER

Leading dimension of VL. Must be at least max(1,N).

VR
VR is COMPLEX*16 array, dimension (LDVR,N)

Contains the computed right eigenvectors of A. Only the first N columns are used.

LDVR
LDVR is INTEGER

Leading dimension of VR. Must be at least max(1,N).

LRE
LRE is COMPLEX*16 array, dimension (LDLRE,N)

Contains the computed eigenvectors of A. Only the first N columns are used.

LDLRE
LDLRE is INTEGER

Leading dimension of LRE. Must be at least max(1,N).

RCONDV
RCONDV is DOUBLE PRECISION array, dimension (N)

RCONDV(j) is an estimate of the reciprocal condition number of the j-th eigenvector. This array is used only if LINE = 'N'.

RCNDV1
RCNDV1 is DOUBLE PRECISION array, dimension (N)

RCONDV(j) is an estimate of the reciprocal condition number of the j-th eigenvector. This array is used only if LINE = 'S'.

RCDVIN
RCDVIN is DOUBLE PRECISION array, dimension (N)

If LINE = 'S', RCDVIN(j) is the reciprocal condition number of the j-th eigenvector computed by ZGEEV. If LINE = 'N', RCDVIN is not used.

RCONDE
RCONDE is DOUBLE PRECISION array, dimension (N)

RCONDE(j) is an estimate of the reciprocal condition number of the j-th eigenvalue. This array is used only if LINE = 'N'.

RCNDE1
RCNDE1 is DOUBLE PRECISION array, dimension (N)

RCONDE(j) is an estimate of the reciprocal condition number of the j-th eigenvalue. This array is used only if LINE = 'S'.

RCDEIN
RCDEIN is DOUBLE PRECISION array, dimension (N)

If LINE = 'S', RCDEIN(j) is the reciprocal condition number of the j-th eigenvalue computed by ZGEEV. If LINE = 'N', RCDEIN is not used.

SCALE
SCALE is DOUBLE PRECISION array, dimension (N)

SCALE(j) is the scale factor used in the j-th step of equilibration for ZGEEVX. This array is used only if LINE = 'N'.

SCALE1
SCALE1 is DOUBLE PRECISION array, dimension (N)

SCALE1(j) is the scale factor used in the j-th step of equilibration for ZGEEV. This array is used only if LINE = 'S'.

RESULT
RESULT is DOUBLE PRECISION array, dimension (11)

The values computed by the 11 tests described below. The values are currently limited to 1/ulp, to avoid overflow.

WORK
WORK is COMPLEX*16 array, dimension (LWORK)

Workspace array. Its dimensions depend on LINE.

LWORK
LWORK is INTEGER

The number of entries in WORK. This must be at least 2*N. If LINE = 'N', LWORK must be at least 2*N + 2*N*N.

RWORK
RWORK is DOUBLE PRECISION array, dimension (2*N)

Workspace array.

INFO
INFO is INTEGER

If 0, successful exit.

If <0, input parameter -INFO had an incorrect value.

If >0, ZGEEV or ZGEEVX returned an error code, the absolute value of which is returned.

The routine ZGET23 is a testing function, which calls the LAPACK routine ZGEEV or ZGEEVX, and then checks the output of the routine for correctness.

If LINE = 'S', ZGEEV is called. ZGEEV computes the eigenvalues and left and right eigenvectors of a complex rectangular matrix.

If LINE = 'N', ZGEEVX is called. ZGEEVX computes the eigenvalues and left and right eigenvectors of a complex rectangular matrix.

Tests performed:

  1. Check computation of eigenvalues.
  2. Check computation of left eigenvectors.
  3. Check computation of right eigenvectors.
  4. Check condition number of left eigenvectors.
  5. Check condition number of right eigenvectors.
  6. Check condition number of eigenvalues.
  7. Check computation of eigenvalues (if partial eigendecomposition was computed).
  8. Check computation of left eigenvectors (if partial eigendecomposition was computed).
  9. Check computation of right eigenvectors (if partial eigendecomposition was computed).
  10. Check condition number of left eigenvectors (if partial eigendecomposition was computed).
  11. Check condition number of right eigenvectors (if partial eigendecomposition was computed).
