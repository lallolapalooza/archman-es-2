ZGEMM

Documentación de Función/Subrutina

subrutina zgemm (character transa, character transb, integer m, integer n, integer k, complex*16 alpha, complex*16, dimension(lda,*) a, integer lda, complex*16, dimension(ldb,*) b, integer ldb, complex*16 beta, complex*16, dimension(ldc,*) c, integer ldc)

ZGEMM

Propósito:

!>
!> ZGEMM  realiza una de las operaciones de matriz-matriz
!>
!>    C := alpha*op( A )*op( B ) + beta*C,
!>
!> donde  op( X ) es uno de
!>
!>    op( X ) = X   o   op( X ) = X**T   o   op( X ) = X**H,
!>
!> alpha y beta son escalares, y A, B y C son matrices, con op( A )
!> una matriz de m por k,  op( B )  una matriz de  k por n y  C una matriz de m por n.
!>

Parámetros

TRANSA 
!>          TRANSA es CHARACTER*1
!>           En la entrada, TRANSA especifica la forma de op( A ) a utilizar en
!>           la multiplicación de matrices de la siguiente manera:
!>
!>              TRANSA = 'N' o 'n',  op( A ) = A.
!>
!>              TRANSA = 'T' o 't',  op( A ) = A**T.
!>
!>              TRANSA = 'C' o 'c',  op( A ) = A**H.
!>

TRANSB

!>          TRANSB es CHARACTER*1
!>           En la entrada, TRANSB especifica la forma de op( B ) a utilizar en
!>           la multiplicación de matrices de la siguiente manera:
!>
!>              TRANSB = 'N' o 'n',  op( B ) = B.
!>
!>              TRANSB = 'T' o 't',  op( B ) = B**T.
!>
!>              TRANSB = 'C' o 'c',  op( B ) = B**H.
!>

M

!>          M es INTEGER
!>           En la entrada,  M  especifica  el número  de filas  de la  matriz
!>           op( A ) y de la  matriz  C.  M  debe  ser  al menos  cero.
!>

N

!>          N es INTEGER
!>           En la entrada,  N  especifica  el número  de columnas  de la matriz
!>           op( B ) y el número de columnas de la matriz C. N debe
!>           ser al menos  cero.
!>

K

!>          K es INTEGER
!>           En la entrada,  K  especifica  el número  de columnas  de la matriz
!>           op( A ) y el número de filas de la matriz op( B ). K debe
!>           ser al menos  cero.
!>

ALPHA

!>          ALPHA es COMPLEX*16
!>           En la entrada, ALPHA especifica el escalar alpha.
!>

A

!>          A es un array COMPLEX*16, de dimensión ( LDA, ka ), donde ka es
!>           k  cuando  TRANSA = 'N' o 'n',  y es  m  en caso contrario.
!>           Antes de la entrada con  TRANSA = 'N' o 'n',  la parte principal  m por k
!>           del array  A  debe contener la matriz  A,  en caso contrario
!>           la parte principal  k por m  del array  A  debe contener la
!>           matriz A.
!>

LDA

!>          LDA es INTEGER
!>           En la entrada, LDA especifica la primera dimensión de A tal como se declara
!>           en el programa llamador (subrutina). Cuando  TRANSA = 'N' o 'n' entonces
!>           LDA debe ser al menos  max( 1, m ), en caso contrario  LDA debe ser
!>           al menos  max( 1, k ).
!>

B

!>          B es un array COMPLEX*16, de dimensión ( LDB, kb ), donde kb es
!>           n  cuando  TRANSB = 'N' o 'n',  y es  k  en caso contrario.
!>           Antes de la entrada con  TRANSB = 'N' o 'n',  la parte principal  k por n
!>           del array  B  debe contener la matriz  B,  en caso contrario
!>           la parte principal  n por k  del array  B  debe contener la
!>           matriz B.
!>

LDB

!>          LDB es INTEGER
!>           En la entrada, LDB especifica la primera dimensión de B tal como se declara
!>           en el programa llamador (subrutina). Cuando  TRANSB = 'N' o 'n' entonces
!>           LDB debe ser al menos  max( 1, k ), en caso contrario  LDB debe ser
!>           al menos  max( 1, n ).
!>

BETA

!>          BETA es COMPLEX*16
!>           En la entrada,  BETA  especifica el escalar  beta.  Cuando  BETA  se
!>           suministra como cero entonces C no necesita ser establecido en la entrada.
!>

C

!>          C es un array COMPLEX*16, de dimensión ( LDC, N )
!>           Antes de la entrada, la parte principal  m por n  del array  C debe
!>           contener la matriz  C,  excepto cuando  beta  es cero, en cuyo
!>           caso C no necesita ser establecido en la entrada.
!>           En la salida, el array  C  se sobrescribe con la matriz  m por n
!>           ( alpha*op( A )*op( B ) + beta*C ).
!>

LDC

!>          LDC es INTEGER
!>           En la entrada, LDC especifica la primera dimensión de C tal como se declara
!>           en el programa (subrutina) llamador.   LDC  debe  ser  al  menos
!>           max( 1, m ).
!>
