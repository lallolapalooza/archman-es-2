Documentación de función/subrutina

subrutina zgemqrt (caracter side, caracter trans, entero m, entero n, entero k, entero nb, complejo*16, dimensión( ldv, * ) v, entero ldv, complejo*16, dimensión( ldt, * ) t, entero ldt, complejo*16, dimensión( ldc, * ) c, entero ldc, complejo*16, dimensión( * ) work, entero info)

ZGEMQRT

Propósito:

!>
!> ZGEMQRT sobrescribe la matriz general compleja M por N llamada C con
!>
!>                 SIDE = 'L'     SIDE = 'R'
!> TRANS = 'N':      Q C            C Q
!> TRANS = 'C':    Q**H C            C Q**H
!>
!> donde Q es una matriz ortogonal compleja definida como el producto de K
!> reflectores elementales:
!>
!>       Q = H(1) H(2) . . . H(K) = I - V T V**H
!>
!> generada usando la representación WY compacta tal como es devuelta por ZGEQRT.
!>
!> Q es de orden M si SIDE = 'L' y de orden N si SIDE = 'R'.
!>

Parámetros

SIDE 
!>          SIDE es CHARACTER*1
!>          = 'L': aplicar Q o Q**H desde la Izquierda;
!>          = 'R': aplicar Q o Q**H desde la Derecha.
!>

TRANS

!>          TRANS es CHARACTER*1
!>          = 'N':  Sin transponer, aplicar Q;
!>          = 'C':  Transpuesta conjugada, aplicar Q**H.
!>

M

!>          M es ENTERO
!>          El número de filas de la matriz C. M >= 0.
!>

N

!>          N es ENTERO
!>          El número de columnas de la matriz C. N >= 0.
!>

K

!>          K es ENTERO
!>          El número de reflectores elementales cuyo producto define
!>          la matriz Q.
!>          Si SIDE = 'L', M >= K >= 0;
!>          si SIDE = 'R', N >= K >= 0.
!>

NB

!>          NB es ENTERO
!>          El tamaño del bloque utilizado para el almacenamiento de T.  K >= NB >= 1.
!>          Debe ser el mismo valor de NB utilizado para generar T
!>          en ZGEQRT.
!>

V

!>          V es un array COMPLEX*16, dimensión (LDV,K)
!>          La i-ésima columna debe contener el vector que define el
!>          reflector elemental H(i), para i = 1,2,...,k, tal como es devuelto por
!>          ZGEQRT en las primeras K columnas de su argumento de array A.
!>

LDV

!>          LDV es ENTERO
!>          La dimensión principal del array V.
!>          Si SIDE = 'L', LDA >= max(1,M);
!>          si SIDE = 'R', LDA >= max(1,N).
!>

T

!>          T es un array COMPLEX*16, dimensión (LDT,K)
!>          Los factores triangulares superiores de los reflectores de bloque
!>          tal como son devueltos por ZGEQRT, almacenados como una matriz NB por N.
!>

LDT

!>          LDT es ENTERO
!>          La dimensión principal del array T.  LDT >= NB.
!>

C

!>          C es un array COMPLEX*16, dimensión (LDC,N)
!>          En la entrada, la matriz C de M por N.
!>          En la salida, C es sobrescrita por Q C, Q**H C, C Q**H o C Q.
!>

LDC

!>          LDC es ENTERO
!>          La dimensión principal del array C. LDC >= max(1,M).
!>

WORK

!>          WORK es un array COMPLEX*16. La dimensión de WORK es
!>           N*NB si SIDE = 'L', o  M*NB si SIDE = 'R'.
!>

INFO

!>          INFO es ENTERO
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>
