DOCUMENTACIÓN DE LA FUNCIÓN/SUBRUTINA

subroutine zgesdd (character jobz, integer m, integer n, complex*16, dimension( lda, * ) a, integer lda, double precision, dimension( * ) s, complex*16, dimension( ldu, * ) u, integer ldu, complex*16, dimension( ldvt, * ) vt, integer ldvt, complex*16, dimension( * ) work, integer lwork, double precision, dimension( * ) rwork, integer, dimension( * ) iwork, integer info)

ZGESDD

Propósito:

!>
!> ZGESDD calcula la descomposición en valores singulares (SVD) de una matriz
!> compleja M por N, A, calculando opcionalmente los vectores singulares
!> izquierdos y/o derechos, mediante el método de divide y vencerás. La SVD se
!> escribe:
!>
!>      A = U * SIGMA * transpuesta-conjugada(V)
!>
!> donde SIGMA es una matriz M por N que es cero excepto por sus
!> min(m,n) elementos diagonales, U es una matriz unitaria M por M, y
!> V es una matriz unitaria N por N. Los elementos diagonales de SIGMA
!> son los valores singulares de A; son reales y no negativos, y se
!> devuelven en orden descendente. Las primeras min(m,n) columnas de
!> U y V son los vectores singulares izquierdos y derechos de A.
!>
!> Nótese que la rutina devuelve VT = V**H, no V.
!>
!>

Parámetros

JOBZ 
!>          JOBZ es CHARACTER*1
!>          Especifica las opciones para calcular toda o parte de la matriz U:
!>          = 'A':  todas las M columnas de U y todas las N filas de V**H se
!>                  devuelven en los arrays U y VT;
!>          = 'S':  las primeras min(M,N) columnas de U y las primeras
!>                  min(M,N) filas de V**H se devuelven en los arrays U
!>                  y VT;
!>          = 'O':  Si M >= N, las primeras N columnas de U se sobrescriben
!>                  en el array A y todas las filas de V**H se devuelven en
!>                  el array VT;
!>                  de lo contrario, todas las columnas de U se devuelven en
!>                  el array U y las primeras M filas de V**H se sobrescriben
!>                  en el array A;
!>          = 'N':  no se calculan columnas de U ni filas de V**H.
!>

M

!>          M es INTEGER
!>          El número de filas de la matriz de entrada A.  M >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz de entrada A.  N >= 0.
!>

A

!>          A es un array COMPLEX*16, dimensión (LDA,N)
!>          En la entrada, la matriz A de M por N.
!>          En la salida,
!>          si JOBZ = 'O',  A se sobrescribe con las primeras N columnas
!>                          de U (los vectores singulares izquierdos,
!>                          almacenados por columnas) si M >= N;
!>                          A se sobrescribe con las primeras M filas
!>                          de V**H (los vectores singulares derechos,
!>                          almacenados por filas) en caso contrario.
!>          si JOBZ .ne. 'O', el contenido de A se destruye.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,M).
!>

S

!>          S es un array DOUBLE PRECISION, dimensión (min(M,N))
!>          Los valores singulares de A, ordenados de forma que S(i) >= S(i+1).
!>

U

!>          U es un array COMPLEX*16, dimensión (LDU,UCOL)
!>          UCOL = M si JOBZ = 'A' o JOBZ = 'O' y M < N;
!>          UCOL = min(M,N) si JOBZ = 'S'.
!>          Si JOBZ = 'A' o JOBZ = 'O' y M < N, U contiene la matriz
!>          unitaria M por M, U;
!>          si JOBZ = 'S', U contiene las primeras min(M,N) columnas de
!>          U (los vectores singulares izquierdos, almacenados por
!>          columnas);
!>          si JOBZ = 'O' y M >= N, o JOBZ = 'N', U no se utiliza.
!>

LDU

!>          LDU es INTEGER
!>          La dimensión principal del array U.  LDU >= 1;
!>          si JOBZ = 'S' o 'A' o JOBZ = 'O' y M < N, LDU >= M.
!>

VT

!>          VT es un array COMPLEX*16, dimensión (LDVT,N)
!>          Si JOBZ = 'A' o JOBZ = 'O' y M >= N, VT contiene la matriz
!>          unitaria N por N, V**H;
!>          si JOBZ = 'S', VT contiene las primeras min(M,N) filas de
!>          V**H (los vectores singulares derechos, almacenados por filas);
!>          si JOBZ = 'O' y M < N, o JOBZ = 'N', VT no se utiliza.
!>

LDVT

!>          LDVT es INTEGER
!>          La dimensión principal del array VT.  LDVT >= 1;
!>          si JOBZ = 'A' o JOBZ = 'O' y M >= N, LDVT >= N;
!>          si JOBZ = 'S', LDVT >= min(M,N).
!>

WORK

!>          WORK es un array COMPLEX*16, dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK. LWORK >= 1.
!>          Si LWORK = -1, se asume una consulta de espacio de trabajo. El
!>          tamaño óptimo para el array WORK se calcula y se almacena en
!>          WORK(1), y no se realiza ningún otro trabajo aparte de la
!>          verificación de argumentos.
!>
!>          Sea mx = max(M,N) y mn = min(M,N).
!>          Si JOBZ = 'N', LWORK >= 2*mn + mx.
!>          Si JOBZ = 'O', LWORK >= 2*mn*mn + 2*mn + mx.
!>          Si JOBZ = 'S', LWORK >=   mn*mn + 3*mn.
!>          Si JOBZ = 'A', LWORK >=   mn*mn + 2*mn + mx.
!>          Estos no son mínimos estrictos en todos los casos; ver comentarios
!>          dentro del código.
!>          Para un buen rendimiento, LWORK debería ser generalmente mayor;
!>          se recomienda una consulta.
!>

RWORK

!>          RWORK es un array DOUBLE PRECISION, dimensión (MAX(1,LRWORK))
!>          Sea mx = max(M,N) y mn = min(M,N).
!>          Si JOBZ = 'N',    LRWORK >= 5*mn (LAPACK <= 3.6 necesita 7*mn);
!>          si no, si mx >> mn, LRWORK >= 5*mn*mn + 5*mn;
!>          si no,          LRWORK >= max( 5*mn*mn + 5*mn,
!>                                          2*mx*mn + 2*mn*mn + mn ).
!>

IWORK

!>          IWORK es un array INTEGER, dimensión (8*min(M,N))
!>

INFO

!>          INFO es INTEGER
!>          <  0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>          = -4:  si A tenía una entrada NAN.
!>          >  0:  El proceso de actualización de DBDSDC no convergió.
!>          =  0:  salida exitosa.
!>
