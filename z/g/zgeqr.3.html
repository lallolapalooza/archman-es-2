Documentación de función/subrutina

subrutina zgeqr (integer m, integer n, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( * ) t, integer tsize, complex*16, dimension( * ) work, integer lwork, integer info)

ZGEQR

Propósito:

!>
!> ZGEQR calcula una factorización QR de una matriz compleja M por N, A:
!>
!>    A = Q * ( R ),
!>            ( 0 )
!>
!> donde:
!>
!>    Q es una matriz ortogonal M por M;
!>    R es una matriz triangular superior N por N;
!>    0 es una matriz cero de (M-N) por N, si M > N.
!>
!>

Parámetros

M 
!>          M es INTEGER
!>          El número de filas de la matriz A.  M >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz A.  N >= 0.
!>

A

!>          A es un array COMPLEX*16, dimensión (LDA,N)
!>          En la entrada, la matriz A de M por N.
!>          En la salida, los elementos en y por encima de la diagonal del array
!>          contienen la matriz trapezoidal superior R de min(M,N) por N
!>          (R es triangular superior si M >= N);
!>          los elementos por debajo de la diagonal se usan para almacenar parte de la
!>          estructura de datos para representar Q.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,M).
!>

T

!>          T es un array COMPLEX*16, dimensión (MAX(5,TSIZE))
!>          En la salida, si INFO = 0, T(1) devuelve TSIZE óptimo (o mínimo o
!>          óptimo, si se asume una consulta) . Ver TSIZE para detalles.
!>          T restante contiene parte de la estructura de datos usada para representar Q.
!>          Si se desea aplicar o construir Q, entonces se necesita mantener T
!>          (además de A) y pasarlo a subrutinas posteriores.
!>

TSIZE

!>          TSIZE es INTEGER
!>          Si TSIZE >= 5, la dimensión del array T.
!>          Si TSIZE = -1 o -2, entonces se asume una consulta de espacio de trabajo.
!>          La rutina solo calcula los tamaños de los arrays T y WORK, devuelve estos
!>          valores como las primeras entradas de los arrays T y WORK, y XERBLA
!>          no emite ningún mensaje de error relacionado con T o WORK.
!>          Si TSIZE = -1, la rutina calcula el tamaño óptimo de T para un rendimiento
!>          óptimo y devuelve este valor en T(1).
!>          Si TSIZE = -2, la rutina calcula el tamaño mínimo de T y devuelve este
!>          valor en T(1).
!>

WORK

!>          (espacio de trabajo) array COMPLEX*16, dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) contiene LWORK óptimo (o mínimo o
!>          óptimo, si se asumió una consulta).
!>          Ver LWORK para detalles.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK. LWORK >= 1.
!>          Si LWORK = -1 o -2, entonces se asume una consulta de espacio de trabajo.
!>          La rutina solo calcula los tamaños de los arrays T y WORK, devuelve estos
!>          valores como las primeras entradas de los arrays T y WORK, y XERBLA
!>          no emite ningún mensaje de error relacionado con T o WORK.
!>          Si LWORK = -1, la rutina calcula el tamaño óptimo de WORK para un rendimiento
!>          óptimo y devuelve este valor en WORK(1).
!>          Si LWORK = -2, la rutina calcula el tamaño mínimo de WORK y devuelve este
!>          valor en WORK(1).
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>

Detalles adicionales

!>
!> El objetivo de la interfaz es dar máxima libertad a los desarrolladores para
!> crear cualquier algoritmo de factorización QR que deseen. La triangular
!!> (trapezoidal) R debe almacenarse en la parte superior de A. La parte inferior de A
!> y el array T pueden usarse para almacenar cualquier información relevante para aplicar o
!> construir el factor Q. El array WORK puede desecharse de forma segura después de la salida.
!>
!> Precaución: No se debe esperar que los tamaños de T y WORK sean los mismos de una
!> implementación de LAPACK a otra, o incluso de una ejecución a otra.
!> Se necesita una consulta de espacio de trabajo (para T y WORK) en cada ejecución. Sin embargo,
!> para una ejecución dada, el tamaño de T y WORK son fijos y no cambiarán
!> de una consulta a otra.
!>
!>

Detalles adicionales particulares de esta implementación de LAPACK:

!>
!> Estos detalles son particulares para esta implementación de LAPACK. Los usuarios no deben
!> darlos por sentados. Estos detalles pueden cambiar en el futuro y es poco probable
!> que sean ciertos para otra implementación de LAPACK. Estos detalles son relevantes si uno quiere
!> intentar entender el código. No forman parte de la interfaz.
!>
!> En esta versión,
!>
!>          T(2): tamaño de bloque de fila (MB)
!>          T(3): tamaño de bloque de columna (NB)
!>          T(6:TSIZE): estructura de datos necesaria para Q, calculada por
!>                           ZLATSQR o ZGEQRT
!>
!>  Dependiendo de las dimensiones de la matriz M y N, y los tamaños de bloque de fila y columna
!>  MB y NB devueltos por ILAENV, ZGEQR usará ZLATSQR (si la matriz es alta y delgada) o ZGEQRT para calcular
!>  la factorización QR.
!>
!>
