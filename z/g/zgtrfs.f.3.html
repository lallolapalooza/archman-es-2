subrutina zgtrfs (character trans, integer n, integer nrhs, complex*16, dimension( * ) dl, complex*16, dimension( * ) d, complex*16, dimension( * ) du, complex*16, dimension( * ) dlf, complex*16, dimension( * ) df, complex*16, dimension( * ) duf, complex*16, dimension( * ) du2, integer, dimension( * ) ipiv, complex*16, dimension( ldb, * ) b, integer ldb, complex*16, dimension( ldx, * ) x, integer ldx, double precision, dimension( * ) ferr, double precision, dimension( * ) berr, complex*16, dimension( * ) work, double precision, dimension( * ) rwork, integer info)

ZGTRFS

Propósito:

!>
!> ZGTRFS mejora la solución calculada para un sistema de ecuaciones
!> lineales cuando la matriz de coeficientes es tridiagonal, y proporciona
!> cotas de error y estimaciones de error hacia atrás para la solución.
!>

Parámetros

TRANS 
!>          TRANS es CHARACTER*1
!>          Especifica la forma del sistema de ecuaciones:
!>          = 'N':  A * X = B     (Sin transpuesta)
!>          = 'T':  A**T * X = B  (Transpuesta)
!>          = 'C':  A**H * X = B  (Transpuesta conjugada)
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de lados derechos, es decir, el número de columnas
!>          de la matriz B.  NRHS >= 0.
!>

DL

!>          DL es una matriz COMPLEX*16, dimensión (N-1)
!>          Los elementos subdiagonales (N-1) de A.
!>

D

!>          D es una matriz COMPLEX*16, dimensión (N)
!>          Los elementos diagonales de A.
!>

DU

!>          DU es una matriz COMPLEX*16, dimensión (N-1)
!>          Los elementos superdiagonales (N-1) de A.
!>

DLF

!>          DLF es una matriz COMPLEX*16, dimensión (N-1)
!>          Los multiplicadores (N-1) que definen la matriz L de la
!>          factorización LU de A calculada por ZGTTRF.
!>

DF

!>          DF es una matriz COMPLEX*16, dimensión (N)
!>          Los N elementos diagonales de la matriz triangular superior U de
!>          la factorización LU de A.
!>

DUF

!>          DUF es una matriz COMPLEX*16, dimensión (N-1)
!>          Los elementos (N-1) de la primera superdiagonal de U.
!>

DU2

!>          DU2 es una matriz COMPLEX*16, dimensión (N-2)
!>          Los elementos (N-2) de la segunda superdiagonal de U.
!>

IPIV

!>          IPIV es una matriz INTEGER, dimensión (N)
!>          Los índices de pivote; para 1 <= i <= n, la fila i de la matriz fue
!>          intercambiada con la fila IPIV(i). IPIV(i) siempre será
!>          i o i+1; IPIV(i) = i indica que no se requirió un intercambio de filas.
!>

B

!>          B es una matriz COMPLEX*16, dimensión (LDB,NRHS)
!>          La matriz del lado derecho B.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión líder del array B. LDB >= max(1,N).
!>

X

!>          X es una matriz COMPLEX*16, dimensión (LDX,NRHS)
!>          En la entrada, la matriz de solución X, tal como fue calculada por ZGTTRS.
!>          En la salida, la matriz de solución mejorada X.
!>

LDX

!>          LDX es INTEGER
!>          La dimensión líder del array X. LDX >= max(1,N).
!>

FERR

!>          FERR es una matriz DOUBLE PRECISION, dimensión (NRHS)
!>          La cota de error hacia adelante estimada para cada vector de solución
!>          X(j) (la j-ésima columna de la matriz de solución X).
!>          Si XTRUE es la solución verdadera correspondiente a X(j), FERR(j)
!>          es una cota superior estimada para la magnitud del elemento más grande
!>          en (X(j) - XTRUE) dividido por la magnitud del elemento más grande
!>          en X(j). La estimación es tan fiable como
!>          la estimación para RCOND, y es casi siempre una ligera
!>          sobreestimación del error verdadero.
!>

BERR

!>          BERR es una matriz DOUBLE PRECISION, dimensión (NRHS)
!>          El error hacia atrás relativo componente a componente de cada vector de solución
!>          X(j) (es decir, el cambio relativo más pequeño en
!>          cualquier elemento de A o B que haga de X(j) una solución exacta).
!>

WORK

!>          WORK es una matriz COMPLEX*16, dimensión (2*N)
!>

RWORK

!>          RWORK es una matriz DOUBLE PRECISION, dimensión (N)
!>

INFO

!>          INFO es INTEGER
!>          = 0:  Salida exitosa
!>          < 0:  Si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>

Parámetros internos:

!>  ITMAX es el número máximo de pasos de refinamiento iterativo.
!>
