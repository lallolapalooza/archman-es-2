DOCUMENTACIÓN DE FUNCIÓN/SUBRUTINA

subroutine zgeqp3rk (integer m, integer n, integer nrhs, integer kmax, double precision abstol, double precision reltol, complex*16, dimension( lda, * ) a, integer lda, integer k, double precision maxc2nrmk, double precision relmaxc2nrmk, integer, dimension( * ) jpiv, complex*16, dimension( * ) tau, complex*16, dimension( * ) work, integer lwork, double precision, dimension( * ) rwork, integer, dimension( * ) iwork, integer info)

ZGEQP3RK calcula una factorización QR Householder truncada con pivote de columna de una matriz compleja m por n A utilizando BLAS de Nivel 3 y sobrescribe la matriz m por nrhs B con Q**H * B.

Propósito:

!>
!> ZGEQP3RK realiza dos tareas simultáneamente:
!>
!> Tarea 1: La rutina calcula una factorización Householder QR truncada (rango K)
!> o de rango completo con pivote de columna de una matriz compleja
!> M por N A utilizando BLAS de Nivel 3. K es el número de columnas
!> que se factorizaron, es decir, el rango de factorización de la
!> factor R, K <= min(M,N).
!>
!>  A * P(K) = Q(K) * R(K)  =
!>
!>        = Q(K) * ( R11(K) R12(K) ) = Q(K) * (   R(K)_aproximada    )
!>                 ( 0      R22(K) )          ( 0  R(K)_residual ),
!>
!> donde:
!>
!>  P(K)            es una matriz de permutación N por N;
!>  Q(K)            es una matriz unitaria M por M;
!>  R(K)_aproximada = ( R11(K), R12(K) ) es una aproximación de rango K del
!>                    factor R de rango completo con R11(K) triangular
!>                    superior K por K y R12(K) rectangular K por N. Las
!>                    entradas diagonales de R11(K) aparecen en orden
!>                    no creciente de valor absoluto, y los valores
!>                    absolutos de todas ellas exceden la norma 2 de
!>                    columna máxima de R22(K) hasta el error de redondeo.
!>  R(K)_residual = R22(K) es el residuo de una aproximación de rango K
!>                    del factor R de rango completo. Es una matriz
!>                    rectangular (M-K) por (N-K);
!>  0               es una matriz cero (M-K) por K.
!>
!> Tarea 2: Al mismo tiempo, la rutina sobrescribe una matriz compleja
!> M por NRHS B con Q(K)**H * B utilizando BLAS de Nivel 3.
!>
!> =====================================================================
!>
!> Las matrices A y B se almacenan en la entrada en el array A como
!> los bloques izquierdo y derecho A(1:M,1:N) y A(1:M, N+1:N+NRHS)
!> respectivamente.
!>
!>                                  N     NRHS
!>             array_A   =   M  [ mat_A, mat_B ]
!>
!> Los criterios de truncamiento (es decir, cuándo detener la factorización)
!> pueden ser cualquiera de los siguientes:
!>
!>   1) El parámetro de entrada KMAX, el número máximo de columnas
!>      KMAX a factorizar, es decir, el rango de factorización se limita
!>      a KMAX. Si KMAX >= min(M,N), el criterio no se utiliza.
!>
!>   2) El parámetro de entrada ABSTOL, la tolerancia absoluta para
!>      la norma 2 de columna máxima de la matriz residual R22(K). Esto
!>      significa que la factorización se detiene si esta norma es menor
!>      o igual a ABSTOL. Si ABSTOL < 0.0, el criterio no se utiliza.
!>
!>   3) El parámetro de entrada RELTOL, la tolerancia para la norma 2
!>      de columna máxima de la matriz residual R22(K) dividida por la
!>      norma 2 de columna máxima de la matriz original A, que es igual
!>      a abs(R(1,1)). Esto significa que la factorización se detiene
!>      cuando la relación de la norma 2 de columna máxima de R22(K)
!>      a la norma 2 de columna máxima de A es menor o igual a RELTOL.
!>      Si RELTOL < 0.0, el criterio no se utiliza.
!>
!>   4) En caso de que los criterios de parada ABSTOL o RELTOL no se utilicen,
!>      y cuando la matriz residual R22(K) es una matriz cero en algún
!>      paso de factorización K. (Este criterio de parada es implícito.)
!>
!>  El algoritmo se detiene cuando se satisface cualquiera de estas
!>  condiciones por primera vez, de lo contrario, se factoriza toda la
!>  matriz A.
!>
!>  Para factorizar toda la matriz A, use los valores
!>  KMAX >= min(M,N), ABSTOL < 0.0 y RELTOL < 0.0.
!>
!>  La rutina devuelve:
!>     a) Q(K), R(K)_aproximada = ( R11(K), R12(K) ),
!>        R(K)_residual = R22(K), P(K), es decir, las matrices resultantes
!>        de la factorización; P(K) está representada por JPIV,
!>        ( si K = min(M,N), R(K)_aproximada es el factor R completo,
!>        y no hay matriz residual R(K)_residual);
!>     b) K, el número de columnas que se factorizaron,
!>        es decir, rango de factorización;
!>     c) MAXC2NRMK, la norma 2 de columna máxima de la matriz
!>        residual R(K)_residual = R22(K),
!>        ( si K = min(M,N), MAXC2NRMK = 0.0 );
!>     d) RELMAXC2NRMK igual a MAXC2NRMK dividido por MAXC2NRM, la norma 2
!>        de columna máxima de la matriz original A, que es igual
!>        a abs(R(1,1)), ( si K = min(M,N), RELMAXC2NRMK = 0.0 );
!>     e) Q(K)**H * B, la matriz B con la transformación unitaria
!>        Q(K)**H aplicada a la izquierda.
!>
!> La matriz de permutación N por N P(K) se almacena en forma compacta en
!> el array entero JPIV. Para 1 <= j <= N, la columna j
!> de la matriz A se intercambió con la columna JPIV(j).
!>
!> La matriz unitaria M por M Q se representa como un producto
!> de reflectores de Householder elementales
!>
!>     Q(K) = H(1) *  H(2) * . . . * H(K),
!>
!> donde K es el número de columnas que se factorizaron.
!>
!> Cada H(j) tiene la forma
!>
!>     H(j) = I - tau * v * v**H,
!>
!> donde 1 <= j <= K y
!>   I    es una matriz identidad M por M,
!>   tau  es un escalar complejo,
!>   v    es un vector complejo con v(1:j-1) = 0 y v(j) = 1.
!>
!> v(j+1:M) se almacena en la salida en A(j+1:M,j) y tau en TAU(j).
!>
!> Ver la sección Detalles Adicionales para más información.
!>

Parámetros

M 
!>          M es INTEGER
!>          El número de filas de la matriz A. M >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz A. N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de lados derechos, es decir, el número de
!>          columnas de la matriz B. NRHS >= 0.
!>

KMAX

!>          KMAX es INTEGER
!>
!>          El primer criterio de parada de factorización. KMAX >= 0.
!>
!>          El número máximo de columnas de la matriz A a factorizar,
!>          es decir, el rango máximo de factorización.
!>
!>          a) Si KMAX >= min(M,N), entonces este criterio de parada
!>                no se utiliza, la rutina factoriza columnas
!>                dependiendo de ABSTOL y RELTOL.
!>
!>          b) Si KMAX = 0, entonces este criterio de parada se
!>                satisface en la entrada y la rutina sale inmediatamente.
!>                Esto significa que la factorización no se realiza,
!>                las matrices A y B no se modifican, y
!>                la matriz A es en sí misma el residuo.
!>

ABSTOL

!>          ABSTOL es DOUBLE PRECISION
!>
!>          El segundo criterio de parada de factorización, no puede ser NaN.
!>
!>          La tolerancia absoluta (umbral de parada) para la
!>          norma 2 de columna máxima de la matriz residual R22(K).
!>          El algoritmo converge (detiene la factorización) cuando
!>          la norma 2 de columna máxima de la matriz residual R22(K)
!>          es menor o igual a ABSTOL. Sea SAFMIN = DLAMCH('S').
!>
!>          a) Si ABSTOL es NaN, entonces no se realiza ningún cálculo
!>

RELTOL

!>          RELTOL es DOUBLE PRECISION
!>
!>          El tercer criterio de parada de la factorización, no puede ser NaN.
!>
!>          La tolerancia (umbral de parada) para la razón
!>          abs(R(K+1,K+1))/abs(R(1,1)) de la norma 2 de columna máxima de
!>          la matriz residual R22(K) a la norma 2 de columna máxima de
!>          la matriz original A. El algoritmo converge (detiene la
!>          factorización) cuando abs(R(K+1,K+1))/abs(R(1,1)) es menor
!>          o igual a RELTOL. Sea EPS = DLAMCH('E').
!>
!>          a) Si RELTOL es NaN, entonces no se realiza ningún cálculo
!>                y se emite un mensaje de error ( INFO = -6 )
!>                por XERBLA.
!>
!>          b) Si RELTOL < 0.0, entonces este criterio de parada no
!>                se utiliza, la rutina factoriza columnas dependiendo
!>                de KMAX y ABSTOL.
!>                Esto incluye el caso RELTOL = -Inf.
!>
!>          c) Si 0.0 <= RELTOL < EPS, entonces se utiliza RELTOL = EPS.
!>                Esto incluye el caso RELTOL = -0.0.
!>
!>          d) Si EPS <= RELTOL entonces se utiliza el valor de entrada de RELTOL.
!>
!>          Sea MAXC2NRM la norma 2 de columna máxima de la
!>          matriz original A completa.
!>          Si RELTOL elegido anteriormente es >= 1.0, entonces este
!>          criterio de parada se satisface en la entrada y la rutina sale
!>          inmediatamente después de calcular MAXC2NRM.
!>          La rutina devuelve MAXC2NRM en MAXC2NORMK,
!>          y 1.0 en RELMAXC2NORMK.
!>          Esto incluye el caso RELTOL = +Inf. Esto significa que la
!>          factorización no se realiza, las matrices A y B no se modifican,
!>          y la matriz A es ella misma el residuo.
!>
!>          NOTA: Recomendamos que RELTOL satisfaga
!>                min( 10*max(M,N)*EPS, sqrt(EPS) ) <= RELTOL
!>

A

!>          A es un array COMPLEX*16, dimensión (LDA,N+NRHS)
!>
!>          En la entrada:
!>
!>          a) La submatriz A(1:M,1:N) contiene la matriz A de M por N.
!>          b) La submatriz A(1:M,N+1:N+NRHS) contiene la matriz B de M por NRHS.
!>
!>                                  N     NRHS
!>              array_A   =   M  [ mat_A, mat_B ]
!>
!>          En la salida:
!>
!>          a) La submatriz A(1:M,1:N) contiene partes de los factores
!>             de la matriz A:
!>
!>            1) Si K = 0, A(1:M,1:N) contiene la matriz original A.
!>            2) Si K > 0, A(1:M,1:N) contiene partes de los
!>            factores:
!>
!>              1. Los elementos por debajo de la diagonal de la submatriz
!>                 A(1:M,1:K) junto con TAU(1:K) representan la
!>                 matriz unitaria Q(K) como un producto de K
!>                 reflectores elementales de Householder.
!>
!>              2. Los elementos en y por encima de la diagonal de
!>                 la submatriz A(1:K,1:N) contienen la matriz
!>                 cuasi-superior de K por N
!>                 R(K)_aproximada = ( R11(K), R12(K) ).
!>                 NOTA: Si K=min(M,N), es decir, factorización de rango completo,
!>                       entonces R_aproximada(K) es el factor R completo que
!>                       es cuasi-superior. Si, además, M>=N,
!>                       entonces R es triangular superior.
!>
!>              3. La submatriz A(K+1:M,K+1:N) contiene la matriz
!>                 rectangular (M-K)-por-(N-K) R(K)_residual = R22(K).
!>
!>          b) Si NRHS > 0, la submatriz A(1:M,N+1:N+NRHS) contiene
!>             el producto Q(K)**H * B de M por NRHS.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A. LDA >= max(1,M).
!>          Esta es la dimensión principal para ambas matrices, A y B.
!>

K

!>          K es INTEGER
!>          Rango de factorización de la matriz A, es decir, el rango de
!>          del factor R, que es el mismo que el número de filas no nulas
!>          del factor R. 0 <= K <= min(M,KMAX,N).
!>
!>          K también representa el número de vectores de Householder no nulos.
!>
!>          NOTA: Si K = 0, a) los arrays A y B no se modifican;
!>                          b) el array TAU(1:min(M,N)) se establece en CERO,
!>                             si la matriz A no contiene NaN,
!>                             de lo contrario los elementos TAU(1:min(M,N))
!>                             no están definidos;
!>                          c) los elementos del array JPIV se establecen
!>                             de la siguiente manera: para j = 1:N, JPIV(j) = j.
!>

MAXC2NRMK

!>          MAXC2NRMK es DOUBLE PRECISION
!>          La norma 2 de columna máxima de la matriz residual R22(K),
!>          cuando la factorización se detuvo en el rango K. MAXC2NRMK >= 0.
!>
!>          a) Si K = 0, es decir, la factorización no se realizó,
!>             la matriz A no se modificó y es ella misma una matriz residual,
!>             entonces MAXC2NRMK es igual a la norma 2 de columna máxima
!>             de la matriz original A.
!>
!>          b) Si 0 < K < min(M,N), entonces se devuelve MAXC2NRMK.
!>
!>          c) Si K = min(M,N), es decir, toda la matriz A se
!>             factorizó y no hay matriz residual,
!>             entonces MAXC2NRMK = 0.0.
!>
!>          NOTA: MAXC2NRMK en el paso de factorización K sería igual a
!>                R(K+1,K+1) en el siguiente paso de factorización K+1.
!>

RELMAXC2NRMK

!>          RELMAXC2NRMK es DOUBLE PRECISION
!>          La razón MAXC2NRMK / MAXC2NRM de la norma 2 de columna
!>          máxima de la matriz residual R22(K) (cuando la factorización
!>          se detuvo en el rango K) a la norma 2 de columna máxima de
!>          la matriz original A completa. RELMAXC2NRMK >= 0.
!>
!>          a) Si K = 0, es decir, la factorización no se realizó,
!>             la matriz A no se modificó y es ella misma una matriz residual,
!>             entonces RELMAXC2NRMK = 1.0.
!>
!>          b) Si 0 < K < min(M,N), entonces se devuelve
!>                RELMAXC2NRMK = MAXC2NRMK / MAXC2NRM.
!>
!>          c) Si K = min(M,N), es decir, toda la matriz A se
!>             factorizó y no hay matriz residual,
!>             entonces RELMAXC2NRMK = 0.0.
!>
!>         NOTA: RELMAXC2NRMK en el paso de factorización K sería igual a
!>               abs(R(K+1,K+1))/abs(R(1,1)) en el siguiente paso de
!>               factorización K+1.
!>

JPIV

!>          JPIV es un array INTEGER, dimensión (N)
!>          Índices de pivote de columna. Para 1 <= j <= N, la columna j
!>          de la matriz A se intercambió con la columna JPIV(j).
!>
!>          Los elementos del array JPIV(1:N) siempre se establecen
!>          por la rutina, por ejemplo, incluso cuando no se factorizaron
!>          columnas, es decir, cuando K = 0, los elementos se
!>          establecen como JPIV(j) = j para j = 1:N.
!>

TAU

!>          TAU es un array COMPLEX*16, dimensión (min(M,N))
!>          Los factores escalares de los reflectores elementales.
!>
!>          Si 0 < K <= min(M,N), solo los elementos TAU(1:K) del
!>          array TAU son modificados por la factorización.
!>          Después de que se calcula la factorización, si no se encontró NaN
!>          durante la factorización, los elementos restantes
!>          TAU(K+1:min(M,N)) se establecen a cero, de lo contrario, los
!>          elementos TAU(K+1:min(M,N)) no se establecen y por lo tanto
!>          no están definidos.
!>          ( Si K = 0, todos los elementos de TAU se establecen a cero, si
!>          la matriz A no contiene NaN. )
!>

WORK

!>          WORK es un array COMPLEX*16, dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK.
!>          LWORK >= 1, si MIN(M,N) = 0, y
!>          LWORK >= N+NRHS-1, en caso contrario.
!>          Para un rendimiento óptimo LWORK >= NB*( N+NRHS+1 ),
!>          donde NB es el tamaño de bloque óptimo para ZGEQP3RK devuelto
!>          por ILAENV. Tamaño de bloque mínimo MINNB=2.
!>
!>          NOTA: La decisión de utilizar código BLAS 2 no bloqueado
!>          o código BLAS 3 bloqueado se basa no solo en la dimensión
!>          LWORK del espacio de trabajo disponible WORK, sino también en la
!>          dimensión N de la matriz A a través del punto de cruce NX devuelto
!>          por ILAENV. (Para N menor que NX, se debe usar código no bloqueado.)
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo;
!>          la rutina solo calcula el tamaño óptimo del array WORK,
!>          devuelve este valor como la primera entrada del array WORK,
!>          y XERBLA no emite ningún mensaje de error relacionado con LWORK.
!>

RWORK

!>          RWORK es un array DOUBLE PRECISION, dimensión (2*N)
!>

IWORK

!>          IWORK es un array INTEGER, dimensión (N-1).
!>          Es un array de trabajo. (IWORK se utiliza para almacenar los índices
!>          de las columnas para la actualización descendente de normas en la
!>          matriz residual en la subrutina auxiliar bloqueada ZLAQP3RK).
!>

INFO

!>          INFO es INTEGER
!>          1) INFO = 0: salida exitosa.
!>          2) INFO < 0: si INFO = -i, el i-ésimo argumento tenía un
!>                       valor ilegal.
!>          3) Si INFO = j_1, donde 1 <= j_1 <= N, entonces se detectó NaN
!>             y la rutina detiene el cálculo.
!>             La columna j_1 de la matriz A o el elemento j_1
!>             del array TAU contiene la primera ocurrencia
!>             de NaN en el paso de factorización K+1 (cuando K columnas
!>             han sido factorizadas).
!>
!>             En la salida:
!>             K                  se establece en el número de
!>                                   columnas factorizadas sin
!>                                   excepción.
!>             MAXC2NRMK          se establece en NaN.
!>             RELMAXC2NRMK       se establece en NaN.
!>             TAU(K+1:min(M,N))  no se establece y contiene valores
!>                                  indefinidos.
!>
!> puede contener NaN. !> 4) Si INFO = j_2, donde N+1 <= j_2 <= 2*N, entonces no se !> detectó ningún NaN, pero se detectó +Inf (o -Inf) y la !> rutina continúa la computación hasta su finalización. !> La columna (j_2-N) de la matriz A contiene la primera !> ocurrencia de +Inf (o -Inf) en el paso de factorización !> K+1 (cuando K columnas han sido factorizadas). !>

Detalles adicionales:

!> ZGEQP3RK se basa en el mismo algoritmo de factorización QR de
!> Householder BLAS3 con pivoteo de columnas que la rutina ZGEQP3,
!> la cual utiliza la rutina ZLARFG para generar reflectores de
!> Householder para la factorización QR.
!>
!> También podemos escribir:
!>
!>   A = A_approx(K) + A_residual(K)
!>
!> La matriz de aproximación de bajo rango A(K)_approx de la
!> factorización QR truncada de rango K de la matriz A es:
!>
!>   A(K)_approx = Q(K) * ( R(K)_approx ) * P(K)**T
!>                        (     0     0 )
!>
!>               = Q(K) * ( R11(K) R12(K) ) * P(K)**T
!>                        (      0      0 )
!>
!> El residuo A_residual(K) de la matriz A es:
!>
!>   A_residual(K) = Q(K) * ( 0              0 ) * P(K)**T =
!>                          ( 0  R(K)_residual )
!>
!>                 = Q(K) * ( 0        0 ) * P(K)**T
!>                          ( 0   R22(K) )
!>
!> La factorización truncada (de rango K) garantiza que la norma
!> 2 máxima de las columnas de A_residual(K) es menor o igual a
!> MAXC2NRMK hasta el error de redondeo.
!>
!> NOTA: Se puede calcular fácilmente una aproximación de los
!>       vectores nulos de A a partir de R11(K) y R12(K):
!>
!>       Null( A(K) )_approx = P * ( inv(R11(K)) * R12(K) )
!>                                 (         -I           )
!>
!>
