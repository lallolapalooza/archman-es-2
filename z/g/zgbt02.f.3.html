ZGBT02

Documentación de función/subrutina

subrutina zgbt02 (character trans, integer m, integer n, integer kl, integer ku, integer nrhs, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( ldx, * ) x, integer ldx, complex*16, dimension( ldb, * ) b, integer ldb, double precision, dimension( * ) rwork, double precision resid)

ZGBT02

Propósito:

!>
!> ZGBT02 calcula el residuo para una solución de un sistema de
!> ecuaciones de banda op(A)*X = B:
!>    RESID = norm(B - op(A)*X) / ( norm(op(A)) * norm(X) * EPS ),
!> donde op(A) = A, A**T, o A**H, dependiendo de TRANS, y EPS es la
!> épsilon de la máquina.
!>

Parámetros

TRANS 
!>          TRANS es CHARACTER*1
!>          Especifica la forma del sistema de ecuaciones:
!>          = 'N':  A    * X = B  (Sin transposición)
!>          = 'T':  A**T * X = B  (Transpuesta)
!>          = 'C':  A**H * X = B  (Transpuesta conjugada)
!>

M

!>          M es INTEGER
!>          El número de filas de la matriz A.  M >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz A.  N >= 0.
!>

KL

!>          KL es INTEGER
!>          El número de subdiagonales dentro de la banda de A.  KL >= 0.
!>

KU

!>          KU es INTEGER
!>          El número de superdiagonales dentro de la banda de A.  KU >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de columnas de B.  NRHS >= 0.
!>

A

!>          A es un array COMPLEX*16, de dimensión (LDA,N)
!>          La matriz original A en almacenamiento de banda, almacenada
!>          en las filas 1 a KL+KU+1.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,KL+KU+1).
!>

X

!>          X es un array COMPLEX*16, de dimensión (LDX,NRHS)
!>          Los vectores solución calculados para el sistema de
!>          ecuaciones lineales.
!>

LDX

!>          LDX es INTEGER
!>          La dimensión principal del array X. Si TRANS = 'N',
!>          LDX >= max(1,N); si TRANS = 'T' o 'C', LDX >= max(1,M).
!>

B

!>          B es un array COMPLEX*16, de dimensión (LDB,NRHS)
!>          A la entrada, los vectores del lado derecho para el sistema de
!>          ecuaciones lineales.
!>          A la salida, B se sobrescribe con la diferencia B - A*X.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B. Si TRANS = 'N',
!>          LDB >= max(1,M); si TRANS = 'T' o 'C', LDB >= max(1,N).
!>

RWORK

!>          RWORK es un array DOUBLE PRECISION, de dimensión (MAX(1,LRWORK)),
!>          donde LRWORK >= M cuando TRANS = 'T' o 'C'; de lo contrario,
!>          RWORK no se referencia.
!>

RESID

!>          RESID es DOUBLE PRECISION
!>          El máximo sobre el número de lados derechos de
!>          norm(B - op(A)*X) / ( norm(op(A)) * norm(X) * EPS ).
!>
