ZGET23

Propósito:

!>
!>    ZGET23  comprueba el controlador del problema de valores propios no simétrico CGEEVX.
!>    Si COMP = .FALSE., las primeras 8 de las siguientes pruebas se realizarán en
!>    la matriz de entrada A, y también la prueba 9 si LWORK es suficientemente grande.
!>    Si COMP es .TRUE. se realizarán las 11 pruebas.
!>
!>    (1)     | A * VR - VR * W | / ( n |A| ulp )
!>
!>      Aquí VR es la matriz de los vectores propios derechos unitarios.
!>      W es una matriz diagonal con entradas diagonales W(j).
!>
!>    (2)     | A**H * VL - VL * W**H | / ( n |A| ulp )
!>
!>      Aquí VL es la matriz de los vectores propios izquierdos unitarios, A**H es la
!>      transpuesta conjugada de A, y W es como se indicó anteriormente.
!>
!>    (3)     | |VR(i)| - 1 | / ulp y el componente más grande real
!>
!>      VR(i) denota la i-ésima columna de VR.
!>
!>    (4)     | |VL(i)| - 1 | / ulp y el componente más grande real
!>
!>      VL(i) denota la i-ésima columna de VL.
!>
!>    (5)     0 si W(completo) = W(parcial), 1/ulp de lo contrario
!>
!>      W(completo) denota los valores propios calculados cuando VR, VL, RCONDV
!>      y RCONDE también se calculan, y W(parcial) denota los
!>      valores propios calculados cuando solo algunos de VR, VL, RCONDV y
!>      RCONDE se calculan.
!>
!>    (6)     0 si VR(completo) = VR(parcial), 1/ulp de lo contrario
!>
!>      VR(completo) denota los vectores propios derechos calculados cuando VL, RCONDV
!!>      y RCONDE se calculan, y VR(parcial) denota el resultado
!>      cuando solo algunos de VL y RCONDV se calculan.
!>
!>    (7)     0 si VL(completo) = VL(parcial), 1/ulp de lo contrario
!>
!>      VL(completo) denota los vectores propios izquierdos calculados cuando VR, RCONDV
!>      y RCONDE se calculan, y VL(parcial) denota el resultado
!>      cuando solo algunos de VR y RCONDV se calculan.
!>
!>    (8)     0 si SCALE, ILO, IHI, ABNRM (completo) =
!>                 SCALE, ILO, IHI, ABNRM (parcial)
!>            1/ulp de lo contrario
!>
!>      SCALE, ILO, IHI y ABNRM describen cómo se equilibra la matriz.
!>      (completo) es cuando VR, VL, RCONDE y RCONDV también se calculan, y
!>      (parcial) es cuando algunos no se calculan.
!>
!>    (9)     0 si RCONDV(completo) = RCONDV(parcial), 1/ulp de lo contrario
!>
!>      RCONDV(completo) denota los recíprocos de los números de condición de los
!>      vectores propios derechos calculados cuando VR, VL y RCONDE también se
!>      calculan. RCONDV(parcial) denota los recíprocos de los números de condición
!>      cuando solo algunos de VR, VL y RCONDE se calculan.
!>
!>   (10)     |RCONDV - RCDVIN| / cond(RCONDV)
!>
!>      RCONDV es el recíproco del número de condición del vector propio
!>      derecho calculado por ZGEEVX y RCDVIN (el valor verdadero precalculado)
!>      se proporciona como entrada. cond(RCONDV) es el número de condición de
!>      RCONDV, y tiene en cuenta los errores en el cálculo de RCONDV, por lo
!>      que la cantidad resultante debe ser O(ULP). cond(RCONDV) se da
!>      esencialmente por norm(A)/RCONDE.
!>
!>   (11)     |RCONDE - RCDEIN| / cond(RCONDE)
!>
!>      RCONDE es el recíproco del número de condición del valor propio
!>      calculado por ZGEEVX y RCDEIN (el valor verdadero precalculado)
!>      se proporciona como entrada. cond(RCONDE) es el número de condición de
!>      RCONDE, y tiene en cuenta los errores en el cálculo de RCONDE,
!>      por lo que la cantidad resultante debe ser O(ULP). cond(RCONDE)
!>      se da esencialmente por norm(A)/RCONDV.
!>

Parámetros

COMP 
!>          COMP es LOGICAL
!>          COMP describe qué pruebas de entrada se realizarán:
!>            = .FALSE. si los números de condición calculados no se van a
!>                      probar contra RCDVIN y RCDEIN
!>            = .TRUE.  si se van a comparar
!>

ISRT

!>          ISRT es INTEGER
!>          Si COMP = .TRUE., ISRT indica en qué orden se ordenan los valores propios
!>          correspondientes a los valores en RCDVIN y RCDEIN:
!>            = 0 significa que los valores propios se ordenan por
!>                parte real creciente
!>            = 1 significa que los valores propios se ordenan por
!>                parte imaginaria creciente
!>          Si COMP = .FALSE., ISRT no se referencia.
!>

BALANC

!>          BALANC es CHARACTER
!>          Describe la opción de equilibrio que se probará.
!>            = 'N' para ninguna permutación o escalado diagonal
!>            = 'P' para permutación pero sin escalado diagonal
!>            = 'S' para ninguna permutación pero con escalado diagonal
!>            = 'B' para permutación y escalado diagonal
!>

JTYPE

!>          JTYPE es INTEGER
!>          Tipo de matriz de entrada. Se utiliza para etiquetar la salida si ocurre un error.
!>

THRESH

!>          THRESH es DOUBLE PRECISION
!>          Una prueba contará como si el , calculado como
!>          se describe anteriormente, excede THRESH. Tenga en cuenta que el error
!>          se escala para que sea O(1), por lo que THRESH debe ser un múltiplo razonablemente
!>          pequeño de 1, por ejemplo, 10 o 100. En particular,
!>          no debe depender de la precisión (simple vs. doble)
!>          o del tamaño de la matriz. Debe ser al menos cero.
!>

ISEED

!>          ISEED es un array INTEGER, dimension (4)
!>          Si COMP = .FALSE., la semilla del generador de números aleatorios
!>          utilizada para producir la matriz.
!>          Si COMP = .TRUE., ISEED(1) = el número del ejemplo.
!>          Se utiliza para etiquetar la salida si ocurre un error.
!>

NOUNIT

!>          NOUNIT es INTEGER
!>          El número de unidad FORTRAN para imprimir mensajes de error
!>          (por ejemplo, si una rutina devuelve INFO distinto de 0).
!>

N

!>          N es INT

ZGET23 is a subroutine that tests the subroutine ZGEEVX.

This subroutine tests the driver subroutine ZGEEVX.

Parameters:

N

!>          N is INTEGER
!>          The number of columns and rows of the matrix A.
!>          The dimension of A, N, must be at least 0.

NM

!>          NM is INTEGER
!>          The number of columns and rows of the matrix A.
!>          The dimension of A, N, must be at least 0.

LDA

!>          LDA is INTEGER
!>          The leading dimension of A, and H. LDA must be at
!>          least 1 and at least N.

A

!>          A is COMPLEX*16 array, dimension (LDA,N)
!>          Used to hold the matrix whose eigenvalues are to be
!>          computed.

LDVL

!>          LDVL is INTEGER
!>          Leading dimension of VL. Must be at least max(1,N).

VL

!>          VL is COMPLEX*16 array, dimension (LDVL,N)
!>          VL holds the computed left eigenvectors.

LDVR

!>          LDVR is INTEGER
!>          Leading dimension of VR. Must be at least max(1,N).

VR

!>          VR is COMPLEX*16 array, dimension (LDVR,N)
!>          VR holds the computed right eigenvectors.

LDLRE

!>          LDLRE is INTEGER
!>          Leading dimension of LRE. Must be at least max(1,N).

LRE

!>          LRE is COMPLEX*16 array, dimension (LDLRE,N)
!>          LRE holds the computed right or left eigenvectors.

W

!>          W is COMPLEX*16 array, dimension (N)
!>          Contains the eigenvalues of A.

W1

!>          W1 is COMPLEX*16 array, dimension (N)
!>          Like W, this array contains the eigenvalues of A,
!>          but those computed when ZGEEVX only computes a partial
!>          eigendecomposition, i.e. not the eigenvalues and left
!>          and right eigenvectors.

RCONDV

!>          RCONDV is DOUBLE PRECISION array, dimension (N)
!>          RCONDV holds the computed reciprocal condition numbers
!>          for eigenvectors.

RCNDV1

!>          RCNDV1 is DOUBLE PRECISION array, dimension (N)
!>          RCNDV1 holds more computed reciprocal condition numbers
!>          for eigenvectors.

RCDVIN

!>          RCDVIN is DOUBLE PRECISION array, dimension (N)
!>          When COMP = .TRUE. RCDVIN holds the precomputed reciprocal
!>          condition numbers for eigenvectors to be compared with
!>          RCONDV.

RCONDE

!>          RCONDE is DOUBLE PRECISION array, dimension (N)
!>          RCONDE holds the computed reciprocal condition numbers
!>          for eigenvalues.

RCNDE1

!>          RCNDE1 is DOUBLE PRECISION array, dimension (N)
!>          RCNDE1 holds more computed reciprocal condition numbers
!>          for eigenvalues.

RCDEIN

!>          RCDEIN is DOUBLE PRECISION array, dimension (N)
!>          When COMP = .TRUE. RCDEIN holds the precomputed reciprocal
!>          condition numbers for eigenvalues to be compared with
!>          RCONDE.

SCALE

!>          SCALE is DOUBLE PRECISION array, dimension (N)
!>          Holds information describing balancing of matrix.

SCALE1

!>          SCALE1 is DOUBLE PRECISION array, dimension (N)
!>          Holds information describing balancing of matrix.

RESULT

!>          RESULT is DOUBLE PRECISION array, dimension (11)
!>          The values computed by the 11 tests described above.
!>          The values are currently limited to 1/ulp, to avoid
!>          overflow.

WORK

!>          WORK is COMPLEX*16 array, dimension (LWORK)

LWORK

!>          LWORK is INTEGER
!>          The number of entries in WORK.  This must be at least
!>          2*N, and 2*N+N**2 if tests 9, 10 or 11 are to be performed.

RWORK

!>          RWORK is DOUBLE PRECISION array, dimension (2*N)

INFO

!>          INFO is INTEGER
!>          If 0,  successful exit.
!>          If <0, input parameter -INFO had an incorrect value.
!>          If >0, ZGEEVX returned an error code, the absolute
!>                 value of which is returned.
