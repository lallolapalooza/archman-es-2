ZGSVTS3

Propósito:

!>
!> ZGSVTS3 prueba ZGGSVD3, que calcula el GSVD de una matriz M-por-N A
!> y una matriz P-por-N B:
!>              U'*A*Q = D1*R y V'*B*Q = D2*R.
!>

Parámetros

M 
!>          M es INTEGER
!>          El número de filas de la matriz A.  M >= 0.
!>

P

!>          P es INTEGER
!>          El número de filas de la matriz B.  P >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas de las matrices A y B.  N >= 0.
!>

A

!>          A es COMPLEX*16 array, dimension (LDA,M)
!>          La matriz A de M por N.
!>

AF

!>          AF es COMPLEX*16 array, dimension (LDA,N)
!>          Detalles del GSVD de A y B, devueltos por ZGGSVD3,
!>          ver ZGGSVD3 para más detalles.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal de los arrays A y AF.
!>          LDA >= max( 1,M ).
!>

B

!>          B es COMPLEX*16 array, dimension (LDB,P)
!>          En la entrada, la matriz B de P por N.
!>

BF

!>          BF es COMPLEX*16 array, dimension (LDB,N)
!>          Detalles del GSVD de A y B, devueltos por ZGGSVD3,
!>          ver ZGGSVD3 para más detalles.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal de los arrays B y BF.
!>          LDB >= max(1,P).
!>

U

!>          U es COMPLEX*16 array, dimension(LDU,M)
!>          La matriz unitaria U de M por M.
!>

LDU

!>          LDU es INTEGER
!>          La dimensión principal del array U. LDU >= max(1,M).
!>

V

!>          V es COMPLEX*16 array, dimension(LDV,M)
!>          La matriz unitaria V de P por P.
!>

LDV

!>          LDV es INTEGER
!>          La dimensión principal del array V. LDV >= max(1,P).
!>

Q

!>          Q es COMPLEX*16 array, dimension(LDQ,N)
!>          La matriz unitaria Q de N por N.
!>

LDQ

!>          LDQ es INTEGER
!>          La dimensión principal del array Q. LDQ >= max(1,N).
!>

ALPHA

!>          ALPHA es DOUBLE PRECISION array, dimension (N)
!>

BETA

!>          BETA es DOUBLE PRECISION array, dimension (N)
!>
!>          Los pares de valores singulares generalizados de A y B, las
!>          matrices "diagonales" D1 y D2 se construyen a partir de
!>          ALPHA y BETA, ver la subrutina ZGGSVD3 para detalles.
!>

R

!>          R es COMPLEX*16 array, dimension(LDQ,N)
!>          La matriz triangular superior R.
!>

LDR

!>          LDR es INTEGER
!>          La dimensión principal del array R. LDR >= max(1,N).
!>

IWORK

!>          IWORK es INTEGER array, dimension (N)
!>

WORK

!>          WORK es COMPLEX*16 array, dimension (LWORK)
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK,
!>          LWORK >= max(M,P,N)*max(M,P,N).
!>

RWORK

!>          RWORK es DOUBLE PRECISION array, dimension (max(M,P,N))
!>

RESULT

!>          RESULT es DOUBLE PRECISION array, dimension (6)
!>          Las razones de prueba:
!>          RESULT(1) = norm( U'*A*Q - D1*R ) / ( MAX(M,N)*norm(A)*ULP)
!>          RESULT(2) = norm( V'*B*Q - D2*R ) / ( MAX(P,N)*norm(B)*ULP)
!>          RESULT(3) = norm( I - U'*U ) / ( M*ULP )
!>          RESULT(4) = norm( I - V'*V ) / ( P*ULP )
!>          RESULT(5) = norm( I - Q'*Q ) / ( N*ULP )
!>          RESULT(6) = 0        si ALPHA está en orden decreciente;
!>                    = ULPINV   en caso contrario.
!>
