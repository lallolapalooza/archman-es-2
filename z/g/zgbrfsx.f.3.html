Documentación de Función/Subrutina

subrutina zgbrfsx (character trans, character equed, integer n, integer kl, integer ku, integer nrhs, complex*16, dimension( ldab, * ) ab, integer ldab, complex*16, dimension( ldafb, * ) afb, integer ldafb, integer, dimension( * ) ipiv, double precision, dimension( * ) r, double precision, dimension( * ) c, complex*16, dimension( ldb, * ) b, integer ldb, complex*16, dimension( ldx , * ) x, integer ldx, double precision rcond, double precision, dimension( * ) berr, integer n_err_bnds, double precision, dimension( nrhs, * ) err_bnds_norm, double precision, dimension( nrhs, * ) err_bnds_comp, integer nparams, double precision, dimension( * ) params, complex*16, dimension( * ) work, double precision, dimension( * ) rwork, integer info)

ZGBRFSX

Propósito:

!>
!>    ZGBRFSX mejora la solución computada de un sistema de ecuaciones
!>    lineales y proporciona cotas de error y estimaciones de error
!>    hacia atrás para la solución. Además de la cota de error normativa,
!>    el código proporciona una cota de error máxima por componentes si es
!>    posible. Ver los comentarios para ERR_BNDS_NORM y ERR_BNDS_COMP para
!>    detalles de las cotas de error.
!>
!>    El sistema original de ecuaciones lineales puede haber sido
!>    equilibrado antes de llamar a esta rutina, como se describe por los
!>    argumentos EQUED, R y C a continuación. En este caso, la solución y
!>    las cotas de error devueltas son para el sistema original no
!>    equilibrado.
!> 
!>     Algunos parámetros opcionales están agrupados en el array PARAMS.
!>     Estas configuraciones determinan cómo se realiza el refinamiento,
!>     pero a menudo los valores predeterminados son aceptables. Si los
!>     valores predeterminados son aceptables, los usuarios pueden pasar
!>     NPARAMS = 0, lo que evita que el código fuente acceda al argumento
!>     PARAMS.
!>

Parámetros

TRANS 
!>          TRANS es CHARACTER*1
!>     Especifica la forma del sistema de ecuaciones:
!>       = 'N':  A * X = B     (Sin transposición)
!>       = 'T':  A**T * X = B  (Transpuesta)
!>       = 'C':  A**H * X = B  (Transpuesta conjugada)
!>

EQUED

!>          EQUED es CHARACTER*1
!>     Especifica la forma de equilibrado que se realizó en A
!>     antes de llamar a esta rutina. Esto es necesario para calcular
!>     la solución y las cotas de error correctamente.
!>       = 'N':  Sin equilibrado
!>       = 'R':  Equilibrado de filas, es decir, A ha sido premultiplicada
!>               por diag(R).
!>       = 'C':  Equilibrado de columnas, es decir, A ha sido postmultiplicada
!>               por diag(C).
!>       = 'B':  Equilibrado tanto de filas como de columnas, es decir, A ha sido
!>               reemplazada por diag(R) * A * diag(C).
!>               El lado derecho B ha sido modificado en consecuencia.
!>

N

!>          N es INTEGER
!>     El orden de la matriz A.  N >= 0.
!>

KL

!>          KL es INTEGER
!>     El número de subdiagonales dentro de la banda de A.  KL >= 0.
!>

KU

!>          KU es INTEGER
!>     El número de superdiagonales dentro de la banda de A.  KU >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>     El número de lados derechos, es decir, el número de columnas
!>     de las matrices B y X.  NRHS >= 0.
!>

AB

!>          AB es COMPLEX*16 array, dimension (LDAB,N)
!>     La matriz de banda original A, almacenada en las filas 1 a KL+KU+1.
!>     La j-ésima columna de A se almacena en la j-ésima columna del
!>     array AB de la siguiente manera:
!>     AB(ku+1+i-j,j) = A(i,j) para max(1,j-ku) <= i <= min(n,j+kl).
!>

LDAB

!>          LDAB es INTEGER
!>     La dimensión principal del array AB.  LDAB >= KL+KU+1.
!>

AFB

!>          AFB es COMPLEX*16 array, dimension (LDAFB,N)
!>     Detalles de la factorización LU de la matriz de banda A, tal como
!>     calculada por ZGBTRF. U se almacena como una matriz de banda
!>     triangular superior con KL+KU superdiagonales en las filas 1 a
!>     KL+KU+1, y los multiplicadores usados durante la factorización se
!>     almacenan en las filas KL+KU+2 a 2*KL+KU+1.
!>

LDAFB

!>          LDAFB es INTEGER
!>     La dimensión principal del array AFB.  LDAFB >= 2*KL*KU+1.
!>

IPIV

!>          IPIV es INTEGER array, dimension (N)
!>     Los índices de pivote de ZGETRF; para 1<=i<=N, la fila i de la
!>     matriz fue intercambiada con la fila IPIV(i).
!>

R

!>          R es DOUBLE PRECISION array, dimension (N)
!>     Los factores de escala de fila para A. Si EQUED = 'R' o 'B', A se
!>     multiplica a la izquierda por diag(R); si EQUED = 'N' o 'C', R
!>     no se accede. R es un argumento de entrada si FACT = 'F';
!>     de lo contrario, R es un argumento de salida. Si FACT = 'F' y
!>     EQUED = 'R' o 'B', cada elemento de R debe ser positivo.
!>     Si R es una salida, cada elemento de R es una potencia de la base.
!>     Si R es una entrada, cada elemento de R debe ser una potencia de la base
!>     para asegurar una solución y estimaciones de error fiables. El
!>     escalado por potencias de la base no causa errores de redondeo a
!>     menos que el resultado cause desbordamiento inferior o superior.
!>     Los errores de redondeo durante el escalado conducen a refinar con
!>     una matriz que no es equivalente a la matriz de entrada, produciendo
!>     estimaciones de error que pueden no ser fiables.
!>

C

!>          C es DOUBLE PRECISION array, dimension (N)
!>     Los factores de escala de columna para A. Si EQUED = 'C' o 'B', A se
!>     multiplica a la derecha por diag(C); si EQUED = 'N' o 'R', C
!>     no se accede. C es un argumento de entrada si FACT = 'F';
!>     de lo contrario, C es un argumento de salida. Si FACT = 'F' y
!>     EQUED = 'C' o 'B', cada elemento de C debe ser positivo.
!>     Si C es una salida, cada elemento de C es una potencia de la base.
!>     Si C es una entrada, cada elemento de C debe ser una potencia de la base
!>     para asegurar una solución y estimaciones de error fiables. El
!>     escalado por potencias de la base no causa errores de redondeo a
!>     menos que el resultado cause desbordamiento inferior o superior.
!>     Los errores de redondeo durante el escalado conducen a refinar con
!>     una matriz que no es equivalente a la matriz de entrada, produciendo
!>     estimaciones de error que pueden no ser fiables.
!>

B

!>          B es COMPLEX*16 array, dimension (LDB,NRHS)
!>     La matriz del lado derecho B.
!>

LDB

!>          LDB es INTEGER
!>     La dimensión principal del array B.  LDB >= max(1,N).
!>

X

!>          X es COMPLEX*16 array, dimension (LDX,NRHS)
!>     En la entrada, la matriz solución X, tal como fue calculada por ZGETRS.
!>     En la salida, la matriz solución mejorada X.
!>

LDX

!>          LDX es INTEGER
!>     La dimensión principal del array X.  LDX >= max(1,N).
!>

RCOND

!>

BERR

!>          BERR es DOUBLE PRECISION array, dimension (NRHS)
!>     La estimación del error hacia atrás para cada uno de los sistemas
!>     lineales resueltos. Si norm(u.A - v.B) es la magnitud del error
!>     hacia atrás, entonces BERR(j) está en la escala de 1 para
!>     norm(u.A - v.B) / norm(v.B).
!>

N_ERR_BNDS

!>          N_ERR_BNDS es INTEGER
!>     El número de cotas de error calculadas en ERR_BNDS_NORM y
!>     ERR_BNDS_COMP.
!>

ERR_BNDS_NORM

!>          ERR_BNDS_NORM es DOUBLE PRECISION array, dimension
!>          (NRHS, N_ERR_BNDS)
!>     Las cotas de error normativas hacia adelante.  ERR_BNDS_NORM(j, k)
!>     contiene la k-ésima cota de error normativa hacia adelante para el
!>     j-ésimo sistema. Las cotas se calculan usando la norma 1.
!>

ERR_BNDS_COMP

!>          ERR_BNDS_COMP es DOUBLE PRECISION array, dimension
!>          (NRHS, N_ERR_BNDS)
!>     Las cotas de error máximas por componentes hacia adelante.
!>     ERR_BNDS_COMP(j, k) contiene la k-ésima cota de error máxima por
!>     componentes hacia adelante para el j-ésimo sistema. Las cotas se
!>     calculan usando la norma infinito.
!>

NPARAMS

!>          NPARAMS es INTEGER
!>     El número de parámetros opcionales en PARAMS. Si NPARAMS = 0,
!>     se utilizan los valores predeterminados para los parámetros opcionales.
!>

PARAMS

!>          PARAMS es DOUBLE PRECISION array, dimension (NPARAMS)
!>     Array de parámetros opcionales. Actualmente no se utilizan parámetros.
!>

WORK

!>          WORK es COMPLEX*16 array, dimension (MAX(2,N)*NRHS)
!>     Espacio de trabajo.
!>

RWORK

!>          RWORK es DOUBLE PRECISION array, dimension (MAX(2,N)*NRHS)
!>     Espacio de trabajo para valores reales.
!>

INFO

!>          INFO es INTEGER
!>     = 0:  Se completó con éxito.
!>     < 0:  Si INFO = -i, el i-ésimo argumento fue de entrada no válido.
!>     > 0:  Si INFO = i, entonces i de las 2*N+2*NRHS últimas
!>          iteraciones de refinamiento no convergieron.
!>

RCOND es DOUBLE PRECISION !> Número de condición escalado recíproco. Esta es una estimación del !> número de condición de Skeel recíproco de la matriz A después de !> la equilibración (si se realizó). Si esto es menor que la precisión de la !> máquina (en particular, si es cero), la matriz es singular !> para la precisión de trabajo. Tenga en cuenta que el error aún puede ser pequeño incluso !> si este número es muy pequeño y la matriz parece mal condicionada. !>

BERR

!>          BERR es un array de DOUBLE PRECISION, de dimensión (NRHS)
!>     Error residual relativo componente a componente. Este es el
!>     error residual relativo componente a componente de cada vector solución X(j)
!>     (es decir, el menor cambio relativo en cualquier elemento de A o B que
!>     haga que X(j) sea una solución exacta).
!>

N_ERR_BNDS

!>          N_ERR_BNDS es un INTEGER
!>     Número de cotas de error a devolver para cada lado derecho
!>     y cada tipo (norma o componente a componente). Véase ERR_BNDS_NORM y
!>     ERR_BNDS_COMP a continuación.
!>

ERR_BNDS_NORM

!>          ERR_BNDS_NORM es un array de DOUBLE PRECISION, de dimensión (NRHS, N_ERR_BNDS)
!>     Para cada lado derecho, este array contiene información sobre
!>     varias cotas de error y números de condición correspondientes al
!>     error relativo en norma, que se define como sigue:
!>
!>     Error relativo en norma del i-ésimo vector solución:
!>             max_j (abs(XTRUE(j,i) - X(j,i)))
!>            ------------------------------
!>                  max_j abs(X(j,i))
!>
!>     El array está indexado por el tipo de información de error según se describe
!>     a continuación. Actualmente se devuelven hasta tres piezas de información.
!>
!>     El primer índice en ERR_BNDS_NORM(i,:) corresponde al i-ésimo
!>     lado derecho.
!>
!>     El segundo índice en ERR_BNDS_NORM(:,err) contiene los siguientes
!>     tres campos:
!>     err = 1  booleano. Confiar en la respuesta si el
!>              número de condición recíproco es menor que el umbral
!>              sqrt(n) * dlamch('Epsilon').
!>
!>     err = 2  cota de error: El error directo estimado,
!>              casi con seguridad dentro de un factor de 10 del error real
!>              siempre que la siguiente entrada sea mayor que el umbral
!>              sqrt(n) * dlamch('Epsilon'). Esta cota de error solo debe
!>              confiarse si el booleano anterior es verdadero.
!>
!>     err = 3  Número de condición recíproco: Estimación del número de condición
!>              recíproco en norma. Comparado con el umbral
!>              sqrt(n) * dlamch('Epsilon') para determinar si la estimación del error
!>              es . Estos números de condición
!>              recíprocos son 1 / (norm(Z^{-1},inf) * norm(Z,inf)) para alguna
!>              matriz Z apropiadamente escalada.
!>              Sea Z = S*A, donde S escala cada fila por una potencia de la
!>              base para que todas las sumas de filas absolutas de Z sean aproximadamente 1.
!>
!>     Véase la Nota de Trabajo 165 de Lapack para más detalles y precauciones adicionales.
!>

ERR_BNDS_COMP

!>          ERR_BNDS_COMP es un array de DOUBLE PRECISION, de dimensión (NRHS, N_ERR_BNDS)
!>     Para cada lado derecho, este array contiene información sobre
!>     varias cotas de error y números de condición correspondientes al
!>     error relativo componente a componente, que se define como sigue:
!>
!>     Error relativo componente a componente del i-ésimo vector solución:
!>                    abs(XTRUE(j,i) - X(j,i))
!>             max_j ----------------------
!>                         abs(X(j,i))
!>
!>     El array está indexado por el i-ésimo lado derecho (del que depende el
!>     error relativo componente a componente), y el tipo de información de error según
!>     se describe a continuación. Actualmente se devuelven hasta tres piezas de información
!>     para cada lado derecho. Si no se solicita precisión componente a componente
!>     (PARAMS(3) = 0.0), entonces ERR_BNDS_COMP no se accede. Si N_ERR_BNDS < 3, entonces se
!>     devuelven como máximo las primeras (:,N_ERR_BNDS) entradas.
!>
!>     El primer índice en ERR_BNDS_COMP(i,:) corresponde al i-ésimo
!>     lado derecho.
!>
!>     El segundo índice en ERR_BNDS_COMP(:,err) contiene los siguientes
!>     tres campos:
!>     err = 1  booleano. Confiar en la respuesta si el
!>              número de condición recíproco es menor que el umbral
!>              sqrt(n) * dlamch('Epsilon').
!>
!>     err = 2  cota de error: El error directo estimado,
!>              casi con seguridad dentro de un factor de 10 del error real
!>              siempre que la siguiente entrada sea mayor que el umbral
!>              sqrt(n) * dlamch('Epsilon'). Esta cota de error solo debe
!>              confiarse si el booleano anterior es verdadero.
!>
!>     err = 3  Número de condición recíproco: Estimación del número de condición
!>              recíproco componente a componente. Comparado con el umbral
!>              sqrt(n) * dlamch('Epsilon') para determinar si la estimación del error
!>              es . Estos números de condición
!>              recíprocos son 1 / (norm(Z^{-1},inf) * norm(Z,inf)) para alguna
!>              matriz Z apropiadamente escalada.
!>              Sea Z = S*(A*diag(x)), donde x es la solución para el
!>              lado derecho actual y S escala cada fila de
!>              A*diag(x) por una potencia de la base para que todas las sumas de filas
!>              absolutas de Z sean aproximadamente 1.
!>
!>     Véase la Nota de Trabajo 165 de Lapack para más detalles y precauciones adicionales.
!>

NPARAMS

!>          NPARAMS es un INTEGER
!>     Especifica el número de parámetros establecidos en PARAMS. Si es <= 0, el
!>     array PARAMS nunca se referencia y se utilizan los valores predeterminados.
!>

PARAMS

!>          PARAMS es un array de DOUBLE PRECISION, de dimensión NPARAMS
!>     Especifica los parámetros del algoritmo. Si una entrada es < 0.0, entonces
!>     esa entrada se rellenará con el valor predeterminado utilizado para ese
!>     parámetro. Solo se accede a las posiciones hasta NPARAMS; se utilizan valores
!>     predeterminados para parámetros de mayor número.
!>
!>       PARAMS(LA_LINRX_ITREF_I = 1) : Si se debe realizar refinamiento iterativo
!>            o no.
!>         Predeterminado: 1.0D+0
!>            = 0.0:  No se realiza refinamiento y no se calculan cotas de error.
!>            = 1.0:  Utilizar el algoritmo de refinamiento de doble precisión,
!>                    posiblemente con cálculos de doble precisión simple si el
!>                    entorno de compilación no soporta DOBLE PRECISION.
!>              (otros valores están reservados para uso futuro)
!>
!>       PARAMS(LA_LINRX_ITHRESH_I = 2) : Número máximo de cálculos de residuo
!>            permitidos para el refinamiento.
!>         Predeterminado: 10
!>         Agresivo: Establecido en 100 para permitir la convergencia utilizando
!>                     factorizaciones aproximadas o factorizaciones distintas de LU. Si
!>                     la factorización utiliza una técnica distinta de la eliminación
!>                     gaussiana, las garantías en
!>                     err_bnds_norm y err_bnds_comp pueden dejar de ser
!>                     confiables.
!>
!>       PARAMS(LA_LINRX_CWISE_I = 3) : Indicador que determina si el código
!>            intentará encontrar una solución con un error relativo componente a
!>            componente pequeño en el algoritmo de doble precisión. Positivo
!>            es verdadero, 0.0 es falso.
!>         Predeterminado: 1.0 (intentar convergencia componente a componente)
!>

WORK

!>          WORK es un array de COMPLEX*16, de dimensión (2*N)
!>

RWORK

!>          RWORK es un array de DOUBLE PRECISION, de dimensión (2*N)
!>

INFO

!>          INFO es un INTEGER
!>       = 0:  Salida exitosa. La solución de cada lado derecho está
!>         garantizada.
!>       < 0:  Si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>       > 0 y <= N:  U(INFO,INFO) es exactamente cero. La factorización
!>         se ha completado, pero el factor U es exactamente singular, por lo que
!>         la solución y las cotas de error no pudieron calcularse. Se devuelve RCOND = 0.
!>       = N+J: La solución correspondiente al J-ésimo lado derecho
!>         no está garantizada. Las soluciones correspondientes a otros lados derechos
!>         K con K > J tampoco pueden estar garantizadas, pero
!>         solo se informa el primer lado derecho de este tipo. Si no se solicita un error
!>         componente a componente pequeño (PARAMS(3) = 0.0), entonces
!>         el J-ésimo lado derecho es el primero con una cota de error en norma
!>         que no está garantizada (el menor J tal que ERR_BNDS_NORM(J,1) = 0.0). Por defecto (PARAMS(3) = 1.0)
!>         el J-ésimo lado derecho es el primero con una cota de error en norma o
!>         componente a componente que no está garantizada (el menor
!>         J tal que o bien ERR_BNDS_NORM(J,1) = 0.0 o
!>         ERR_BNDS_COMP(J,1) = 0.0). Véase la definición de
!>         ERR_BNDS_NORM(:,1) y ERR_BNDS_COMP(:,1). Para obtener información
!>         sobre todos los lados derechos, compruebe ERR_BNDS_NORM o
!>         ERR_BNDS_COMP.
!>
