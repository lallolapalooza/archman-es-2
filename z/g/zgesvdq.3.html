ZGESVDQ calcula la descomposición en valores singulares (SVD) con un método SVD QR precondicionado con QR para matrices GE

Documentación de función/subrutina

subrutina zgesvdq (character joba, character jobp, character jobr, character jobu, character jobv, integer m, integer n, complex*16, dimension( lda, * ) a, integer lda, double precision, dimension( * ) s, complex*16, dimension( ldu, * ) u, integer ldu, complex*16, dimension( ldv, * ) v, integer ldv, integer numrank, integer, dimension( * ) iwork, integer liwork, complex*16, dimension( * ) cwork, integer lcwork, double precision, dimension( * ) rwork, integer lrwork, integer info)

ZGESVDQ calcula la descomposición en valores singulares (SVD) de una matriz compleja M por N A, donde M >= N. La SVD de A se escribe como [++] [xx] [x0] [xx] A = U * SIGMA * V^*, [++] = [xx] * [ox] * [xx] [++] [xx] donde SIGMA es una matriz diagonal N por N, U es una matriz ortonormal M por N, y V es una matriz unitaria N por N. Los elementos diagonales de SIGMA son los valores singulares de A. Las columnas de U y V son los vectores singulares izquierdos y derechos de A, respectivamente.

Parámetros

JOBA 
!>  JOBA es CHARACTER*1
!>  Especifica el nivel de precisión en la SVD calculada
!>  = 'A' La precisión solicitada corresponde a tener el error hacia atrás
!>        acotado por || delta A ||_F <= f(m,n) * EPS * || A ||_F,
!>        donde EPS = DLAMCH('Epsilon'). Esto autoriza a ZGESVDQ a
!>        truncar el factor triangular calculado en una factorización QR que revela el rango
!>        siempre que la parte truncada esté por debajo del umbral del orden de EPS * ||A||_F.
!>        Este es un nivel de truncamiento agresivo.
!>  = 'M' Similar a 'A', pero el truncamiento es más suave:
!>        sólo se permite cuando hay una caída en la diagonal del factor
!>        triangular en la factorización QR. Este es un nivel de truncamiento medio.
!>  = 'H' Se solicita alta precisión. No se intenta determinar el rango numérico basado
!>        en la factorización QR que revela el rango.
!>  = 'E' Igual que 'H', y además se estima el número de condición de A escalada por columna
!>        y se devuelve en  RWORK(1).
!>        N^(-1/4)*RWORK(1) <= ||pinv(A_escalada)||_2 <= N^(1/4)*RWORK(1)
!>

JOBP

!>  JOBP es CHARACTER*1
!>  = 'P' Las filas de A se ordenan en orden decreciente con respecto a
!>        ||A(i,:)||_\infty. Esto mejora la precisión numérica a costa de
!>        movimientos de datos adicionales. Recomendado para robustez numérica.
!>  = 'N' Sin pivoteo de filas.
!>

JOBR

!>          JOBR es CHARACTER*1
!>          = 'T' Después de la factorización QR pivoteada inicial, se aplica ZGESVD a
!>          la adjunta R**H del factor triangular R calculado. Esto implica
!>          algún movimiento de datos adicional (transposiciones de matrices). Útil para
!>          experimentos, investigación y desarrollo.
!>          = 'N' El factor triangular R se proporciona como entrada a CGESVD. Esto puede
!>          ser preferible ya que implica menos movimiento de datos.
!>

JOBU

!>          JOBU es CHARACTER*1
!>          = 'A' Se calculan todos los M vectores singulares izquierdos y se devuelven en
!>          la matriz U. Ver la descripción de U.
!>          = 'S' o 'U' Se calculan N = min(M,N) vectores singulares izquierdos y se devuelven
!>          en la matriz U. Ver la descripción de U.
!>          = 'R' Se determina el rango numérico NUMRANK y sólo se calculan NUMRANK vectores singulares
!>          izquierdos y se devuelven en la matriz U.
!>          = 'F' Los N vectores singulares izquierdos se devuelven en forma factorizada como el
!>          producto del factor Q de la factorización QR inicial y los
!>          N vectores singulares izquierdos de (R**H , 0)**H. Si se utiliza el pivoteo de filas,
!>          entonces la información necesaria sobre el pivoteo de filas se almacena en
!>          IWORK(N+1:N+M-1).
!>          = 'N' Los vectores singulares izquierdos no se calculan.
!>

JOBV

!>          JOBV es CHARACTER*1
!>          = 'A', 'V' Se calculan todos los N vectores singulares derechos y se devuelven en
!>          la matriz V.
!>          = 'R' Se determina el rango numérico NUMRANK y sólo se calculan NUMRANK vectores singulares
!>          derechos y se devuelven en la matriz V. Esta opción está
!>          permitida sólo si JOBU = 'R' o JOBU = 'N'; de lo contrario es ilegal.
!>          = 'N' Los vectores singulares derechos no se calculan.
!>

M

!>          M es INTEGER
!>          El número de filas de la matriz de entrada A.  M >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz de entrada A.  M >= N >= 0.
!>

A

!>          A es un array COMPLEX*16 de dimensiones LDA x N
!>          En la entrada, la matriz de entrada A.
!>          En la salida, si JOBU .NE. 'N' o JOBV .NE. 'N', la parte triangular inferior de A contiene
!>          los vectores de Householder tal como los almacena ZGEQP3. Si JOBU = 'F', estos vectores de
!>          Householder junto con CWORK(1:N) pueden usarse para restaurar los factores Q de
!>          la factorización QR pivoteada inicial de A. Ver la descripción de U.
!>

LDA

!>          LDA es INTEGER.
!>          La dimensión principal del array A.  LDA >= max(1,M).
!>

S

!>          S es un array DOUBLE PRECISION de dimensión N.
!>          Los valores singulares de A, ordenados de modo que S(i) >= S(i+1).
!>

U

!>          U es un array COMPLEX*16, de dimensiones
!>          LDU x M si JOBU = 'A'; ver la descripción de LDU. En este caso,
!>          en la salida, U contiene los M vectores singulares izquierdos.
!>          LDU x N si JOBU = 'S', 'U', 'R' ; ver la descripción de LDU. En este
!>          caso, U contiene los N o los NUMRANK vectores singulares izquierdos principales.
!>          LDU x N si JOBU = 'F' ; ver la descripción de LDU. En este caso U
!>          contiene una matriz unitaria N x N que puede usarse para formar los vectores singulares
!>          izquierdos.
!>          Si JOBU = 'N', U no se referencia.
!>

LDU

!>          LDU es INTEGER.
!>          La dimensión principal del array U.
!>          Si JOBU = 'A', 'S', 'U', 'R',  LDU >= max(1,M).
!>          Si JOBU = 'F',                 LDU >= max(1,N).
!>          En caso contrario,             LDU >= 1.
!>

V

!>          V es un array COMPLEX*16, de dimensiones
!>          LDV x N si JOBV = 'A', 'V', 'R' o si JOBA = 'E' .
!>          Si JOBV = 'A', o 'V',  V contiene la matriz unitaria N x N  V**H;
!>          Si JOBV = 'R', V contiene las primeras NUMRANK filas de V**H (los vectores singulares
!>          derechos, almacenados fila a fila, de los NUMRANK valores singulares más grandes).
!>          Si JOBV = 'N' y JOBA = 'E', V se usa como espacio de trabajo.
!>          Si JOBV = 'N', y JOBA.NE.'E', V no se referencia.
!>

LDV

!>          LDV es INTEGER
!>          La dimensión principal del array V.
!>          Si JOBV = 'A', 'V', 'R',  o JOBA = 'E', LDV >= max(1,N).
!>          En caso contrario,        LDV >= 1.
!>

NUMRANK

!>          NUMRANK es INTEGER

NAME

ZGESVDQ - computes the singular value decomposition (SVD) of a complex rectangular matrix.

SYNOPSIS

 SUBROUTINE ZGESVDQ( JOBU, JOBV, M, N, A, LDA, B, LDB, RWORK, TOL,
                    IWORK, LIWORK, CWORK, LCWORK, LRWORK, INFO )
  CHARACTER(LEN=1) JOBU, JOBV
  INTEGER M, N, LDA, LDB, LIWORK, LCWORK, LRWORK, INFO
  COMPLEX*16 A( LDA, * ), B( LDB, * )
  DOUBLE PRECISION RWORK( * ), TOL
  INTEGER IWORK( * )
  COMPLEX*16 CWORK( * )

Function/Subroutine Documentation

ZGESVDQ computes the singular value decomposition (SVD) of a complex rectangular matrix A, A = U * S * V**H, where U is an M-by-M unitary matrix, S is an M-by-N matrix with non-negative real numbers on the diagonal and zeros elsewhere, and V is an N-by-N unitary matrix. The columns of U are the left-singular vectors, and the columns of V are the right-singular vectors.

This routine is a modified version of the LAPACK routine ZGESVD. It uses a QR-based method which is particularly effective for computing the SVD with high accuracy. It employs the rank-revealing QR factorization (ZGEQPF) as a preconditioner for the SVD computation.

Arguments:

JOBU

 Character*1.
 Specifies whether to compute the columns of U:
 = 'A': all M columns of U are returned in the array A;
 = 'S': the first N columns of U are returned in the array A;
 = 'O': the first K columns of U are returned in the array A,
        where K is the number of non-zero singular values.
 = 'N': no columns of U are returned (the space is not needed).
 Note that A is overwritten by the output:
 If JOBU = 'A' or 'S', A is overwritten by U.
 If JOBU = 'O', the orthogonal matrix U is stored on the
 array B.
 If JOBU = 'N', B is not used.

JOBV

 Character*1.
 Specifies whether to compute the columns of V:
 = 'A': all N columns of V are returned in the array B;
 = 'S': the first K columns of V are returned in the array B,
        where K is the number of non-zero singular values.
 = 'N': no columns of V are returned (the space is not needed).
 Note that B is overwritten by the output:
 If JOBV = 'A', B is overwritten by V.
 If JOBV = 'S', the first K columns of V are returned in the
 array B.
 If JOBV = 'N', B is not used.

M

 Integer.
 The number of rows of the matrix A. M >= 0.

N

 Integer.
 The number of columns of the matrix A. N >= 0.

A

 Complex*16 array, dimension (LDA, N).
 On entry, the M-by-N matrix A.
 On exit,
 if JOBU = 'A', A is overwritten by the unitary matrix U (M-by-M).
 if JOBU = 'S', A is overwritten by the first N columns of U.
 if JOBU = 'O', the first K columns of U are returned in the array B.
 if JOBU = 'N', A is not used.

LDA

 Integer.
 The leading dimension of the array A. LDA >= max(1, M).

B

 Complex*16 array, dimension (LDB, N).
 On entry, if JOBU = 'O', B must contain the M-by-K matrix that results
 from the QR factorization of A.
 On exit,
 if JOBV = 'A', B is overwritten by the unitary matrix V (N-by-N).
 if JOBV = 'S', the first K columns of V are returned in B.
 if JOBU = 'O', the first K columns of U are returned in B.
 if JOBV = 'N', B is not used.

LDB

 Integer.
 The leading dimension of the array B.
 If JOBU = 'O', LDB >= M.
 If JOBV = 'A' or 'S', LDB >= N.

RWORK

 Double Precision array, dimension (max(1, LRWORK)).
 On exit,
 RWORK(1) contains an estimate of the condition number of column scaled A.
 RWORK(2) contains the number of singular values computed as exact zeros.

TOL

 Double Precision.
 User argument specifying the tolerance for thresholding singular
 values. Singular values S(i) are treated as zero if S(i) <= TOL * S(1).
 If TOL < 0, the tolerance is set to machine epsilon times max(M,N).

IWORK

 Integer array, dimension (max(1, LIWORK)).
 On exit, IWORK(1:N) contains the column pivoting permutation of the
 rank revealing QR factorization.

LIWORK

 Integer.
 The dimension of the array IWORK.
 LIWORK >= N.
 If LIWORK = -1, then a workspace query is assumed; the routine only
 calculates and returns the minimal required size for IWORK.

CWORK

 Complex*16 array, dimension (max(2, LCWORK)).
 On exit, CWORK(1:N) contains parameters needed to recover the Q factor
 from the QR factorization computed by ZGEQP3.

LCWORK

 Integer.
 The dimension of the array CWORK.
 LCWORK >= N.
 If LCWORK = -1, then a workspace query is assumed; the routine only
 calculates and returns the minimal required size for CWORK.

LRWORK

 Integer.
 The dimension of the array RWORK.
 LRWORK >= max(2, 5*N).
 If LRWORK = -1, then a workspace query is assumed; the routine only
 calculates and returns the minimal required size for RWORK.

INFO

 Integer.
 = 0: successful exit.
 < 0: if INFO = -i, the i-th argument had an illegal value.
 > 0: if ZBDSQR did not converge, INFO specifies how many superdiagonals
      of an intermediate bidiagonal form B (computed in ZGESVD) did not
      converge to zero.

Further Details:

!>
!>   1. The data movement (matrix transpose) is coded using simple nested
!>   DO-loops because BLAS and LAPACK do not provide corresponding subroutines.
!>   Those DO-loops are easily identified in this source code - by the CONTINUE
!>   statements labeled with 11**. In an optimized version of this code, the
!>   nested DO loops should be replaced with calls to an optimized subroutine.
!>   2. This code scales A by 1/SQRT(M) if the largest ABS(A(i,j)) could cause
!>   column norm overflow. This is the minial precaution and it is left to the
!>   SVD routine (CGESVD) to do its own preemptive scaling if potential over-
!>   or underflows are detected. To avoid repeated scanning of the array A,
!>   an optimal implementation would do all necessary scaling before calling
!>   CGESVD and the scaling in CGESVD can be switched off.
!>   3. Other comments related to code optimization are given in comments in the
!>   code, enclosed in [[double brackets]].
!>
