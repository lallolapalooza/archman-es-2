ZGGEV3 calcula los valores propios y, opcionalmente, los vectores propios izquierdos y/o derechos para matrices GE (algoritmo en bloques)

Propósito:

!>
!> ZGGEV3 calcula para un par de matrices complejas no simétricas N por N
!> (A,B), los valores propios generalizados, y opcionalmente, los vectores propios
!> generalizados izquierdos y/o derechos.
!>
!> Un valor propio generalizado para un par de matrices (A,B) es un escalar
!> lambda o una relación alpha/beta = lambda, tal que A - lambda*B es
!> singular. Se representa usualmente como el par (alpha,beta), ya que
!> hay una interpretación razonable para beta=0, e incluso para ambos
!> siendo cero.
!>
!> El vector propio generalizado derecho v(j) correspondiente al
!> valor propio generalizado lambda(j) de (A,B) satisface
!>
!>              A * v(j) = lambda(j) * B * v(j).
!>
!> El vector propio generalizado izquierdo u(j) correspondiente al
!> valor propio generalizado lambda(j) de (A,B) satisface
!>
!>              u(j)**H * A = lambda(j) * u(j)**H * B
!>
!> donde u(j)**H es la transpuesta conjugada de u(j).
!>

Parámetros

JOBVL 
!>          JOBVL es CHARACTER*1
!>          = 'N':  no calcula los vectores propios generalizados izquierdos;
!>          = 'V':  calcula los vectores propios generalizados izquierdos.
!>

JOBVR

!>          JOBVR es CHARACTER*1
!>          = 'N':  no calcula los vectores propios generalizados derechos;
!>          = 'V':  calcula los vectores propios generalizados derechos.
!>

N

!>          N es INTEGER
!>          El orden de las matrices A, B, VL, y VR.  N >= 0.
!>

A

!>          A es una matriz COMPLEX*16, dimensión (LDA, N)
!>          En la entrada, la matriz A en el par (A,B).
!>          En la salida, A ha sido sobrescrita.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal de A.  LDA >= max(1,N).
!>

B

!>          B es una matriz COMPLEX*16, dimensión (LDB, N)
!>          En la entrada, la matriz B en el par (A,B).
!>          En la salida, B ha sido sobrescrita.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal de B.  LDB >= max(1,N).
!>

ALPHA

!>          ALPHA es una matriz COMPLEX*16, dimensión (N)
!>

BETA

!>          BETA es una matriz COMPLEX*16, dimensión (N)
!>          En la salida, ALPHA(j)/BETA(j), j=1,...,N, serán los
!>          valores propios generalizados.
!>
!>          Nota: los cocientes ALPHA(j)/BETA(j) pueden fácilmente sobreflo-
!>          o subflo-tacar, y BETA(j) puede incluso ser cero. Por lo tanto, el usuario
!>          debe evitar calcular ingenuamente la relación alpha/beta.
!>          Sin embargo, ALPHA siempre será menor y usualmente
!>          comparable con norm(A) en magnitud, y BETA siempre menor
!>          y usualmente comparable con norm(B).
!>

VL

!>          VL es una matriz COMPLEX*16, dimensión (LDVL,N)
!>          Si JOBVL = 'V', los vectores propios generalizados izquierdos u(j) se
!>          almacenan uno tras otro en las columnas de VL, en el mismo
!>          orden que sus valores propios.
!>          Cada vector propio se escala de modo que el componente más grande tenga
!>          abs(parte real) + abs(parte imaginaria) = 1.
!>          No referenciado si JOBVL = 'N'.
!>

LDVL

!>          LDVL es INTEGER
!>          La dimensión principal de la matriz VL. LDVL >= 1, y
!>          si JOBVL = 'V', LDVL >= N.
!>

VR

!>          VR es una matriz COMPLEX*16, dimensión (LDVR,N)
!>          Si JOBVR = 'V', los vectores propios generalizados derechos v(j) se
!>          almacenan uno tras otro en las columnas de VR, en el mismo
!>          orden que sus valores propios.
!>          Cada vector propio se escala de modo que el componente más grande tenga
!>          abs(parte real) + abs(parte imaginaria) = 1.
!>          No referenciado si JOBVR = 'N'.
!>

LDVR

!>          LDVR es INTEGER
!>          La dimensión principal de la matriz VR. LDVR >= 1, y
!>          si JOBVR = 'V', LDVR >= N.
!>

WORK

!>          WORK es una matriz COMPLEX*16, dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK. LWORK >= MAX(1,2*N).
!>          Para un buen rendimiento, LWORK debe ser generalmente mayor.
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo del array WORK, devuelve
!>          este valor como la primera entrada del array WORK, y XERBLA no emite ningún
!>          mensaje de error relacionado con LWORK.
!>

RWORK

!>          RWORK es una matriz DOUBLE PRECISION, dimensión (8*N)
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tuvo un valor ilegal.
!>          =1,...,N:
!>                La iteración QZ falló. No se han calculado vectores propios,
!>                pero ALPHA(j) y BETA(j) deberían ser correctos para j=INFO+1,...,N.
!>          > N:  =N+1: falló la iteración QZ en ZHGEQZ,
!>                =N+2: retorno de error desde ZTGEVC.
!>

    NAME

    zggev3.3 - Computes the generalized eigenvalues for a pair of complex-valued matrices (single-precision).

    SYNOPSIS

    zggev3(jobvl, jobvr, n, a, lda, b, ldb, alpha, beta, vl, ldvl, vr, ldvr, work, lwork, rwork, info)

    Function/Subroutine Documentation

    zggev3

    Purpose:

    zggev3 computes the generalized eigenvalues and, optionally, the left and/or right generalized eigenvectors for a pair of complex-valued matrices A and B (single-precision).

    Arguments:

    • jobvl (character):
      • 'N': Do not compute the left generalized eigenvectors.
      • 'V': Compute the left generalized eigenvectors.
    • jobvr (character):
      • 'N': Do not compute the right generalized eigenvectors.
      • 'V': Compute the right generalized eigenvectors.
    • n (integer): The order of the matrices A and B. n ≥ 0.
    • a (complex*16 array, dimension (lda, N)): The first matrix A.
    • lda (integer): The leading dimension of the array A. lda ≥ max(1, N).
    • b (complex*16 array, dimension (ldb, N)): The second matrix B.
    • ldb (integer): The leading dimension of the array B. ldb ≥ max(1, N).
    • alpha (complex*16 array, dimension (N)): The first N components of the array. This array contains the first eigenvalues alpha(i).
    • beta (complex*16 array, dimension (N)): The second N components of the array. This array contains the second eigenvalues beta(i).
    • vl (complex*16 array, dimension (ldvl, N)): If jobvl = 'V', vl contains the left eigenvectors of A and B.
    • ldvl (integer): The leading dimension of the array vl. ldvl ≥ N.
    • vr (complex*16 array, dimension (ldvr, N)): If jobvr = 'V', vr contains the right eigenvectors of A and B.
    • ldvr (integer): The leading dimension of the array vr. ldvr ≥ N.
    • work (complex*16 array, dimension (lwork)): Workspace array.
    • lwork (integer): The dimension of the array work. lwork ≥ max(1, 2*N).
    • rwork (double precision array, dimension (max(1, 8*N))): Workspace array.
    • info (integer):
      • 0: successful exit
      • < 0: if info = -i, the i-th argument had an illegal value.
      • > 0: if info = i > 0, the algorithm for QR decomposition of A failed to compute an upper triangular matrix.
