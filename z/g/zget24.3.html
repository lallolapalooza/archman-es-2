subroutine zget24 (logical comp, integer jtype, double precision thresh, integer, dimension( 4 ) iseed, integer nounit, integer n, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( lda, * ) h, complex*16, dimension( lda, * ) ht, complex*16, dimension( * ) w, complex*16, dimension( * ) wt, complex*16, dimension( * ) wtmp, complex*16, dimension( ldvs, * ) vs, integer ldvs, complex*16, dimension( ldvs, * ) vs1, double precision rcdein, double precision rcdvin, integer nslct, integer, dimension( * ) islct, integer isrt, double precision, dimension( 17 ) result, complex*16, dimension( * ) work, integer lwork, double precision, dimension( * ) rwork, logical, dimension( * ) bwork, integer info)

ZGET24

Propósito:

!>
!>    ZGET24 comprueba el problema de valores propios (forma de Schur) no simétrico
!>    controlador experto ZGEESX.
!>
!>    Si COMP = .FALSE., las primeras 13 de las siguientes pruebas se realizarán
!>    en la matriz de entrada A, y también las pruebas 14 y 15
!>    si LWORK es suficientemente grande.
!>    Si COMP = .TRUE., se realizarán las 17 pruebas.
!>
!>    (1)     0 si T está en forma de Schur, 1/ulp en caso contrario
!>           (sin ordenación de valores propios)
!>
!>    (2)     | A - VS T VS' | / ( n |A| ulp )
!>
!>      Aquí VS es la matriz de vectores propios de Schur, y T está en forma de Schur
!>      (sin ordenación de valores propios).
!>
!>    (3)     | I - VS VS' | / ( n ulp ) (sin ordenación de valores propios).
!>
!>    (4)     0     si W son valores propios de T
!>            1/ulp en caso contrario
!>            (sin ordenación de valores propios)
!>
!>    (5)     0     si T(con VS) = T(sin VS),
!>            1/ulp en caso contrario
!>            (sin ordenación de valores propios)
!>
!>    (6)     0     si valores_propios(con VS) = valores_propios(sin VS),
!>            1/ulp en caso contrario
!>            (sin ordenación de valores propios)
!>
!>    (7)     0 si T está en forma de Schur, 1/ulp en caso contrario
!>            (con ordenación de valores propios)
!>
!>    (8)     | A - VS T VS' | / ( n |A| ulp )
!>
!>      Aquí VS es la matriz de vectores propios de Schur, y T está en forma de Schur
!>      (con ordenación de valores propios).
!>
!>    (9)     | I - VS VS' | / ( n ulp ) (con ordenación de valores propios).
!>
!>    (10)    0     si W son valores propios de T
!>            1/ulp en caso contrario
!>            Si el espacio de trabajo es suficiente, también compara W con y
!>            sin números de condición recíprocos
!>            (con ordenación de valores propios)
!>
!>    (11)    0     si T(con VS) = T(sin VS),
!>            1/ulp en caso contrario
!>            Si el espacio de trabajo es suficiente, también compara T con y sin
!>            números de condición recíprocos
!>            (con ordenación de valores propios)
!>
!>    (12)    0     si valores_propios(con VS) = valores_propios(sin VS),
!>            1/ulp en caso contrario
!>            Si el espacio de trabajo es suficiente, también compara VS con y sin
!>            números de condición recíprocos
!>            (con ordenación de valores propios)
!>
!>    (13)    si la ordenación funcionó y SDIM es el número de
!>            valores propios que fueron SELECCIONADOS
!>            Si el espacio de trabajo es suficiente, también compara SDIM con y
!>            sin números de condición recíprocos
!>
!>    (14)    si RCONDE es el mismo sin importar si VS y/o RCONDV se calcularon
!>
!>    (15)    si RCONDV es el mismo sin importar si VS y/o RCONDE se calcularon
!>
!>    (16)  |RCONDE - RCDEIN| / cond(RCONDE)
!>
!>       RCONDE es el número de condición promedio recíproco del valor propio
!>       calculado por ZGEESX y RCDEIN (el valor verdadero precalculado)
!>       se proporciona como entrada. cond(RCONDE) es el número de condición
!!       de RCONDE, y tiene en cuenta los errores al calcular RCONDE,
!>       de modo que la cantidad resultante debería ser O(ULP). cond(RCONDE)
!>       se da esencialmente por norm(A)/RCONDV.
!>
!>    (17)  |RCONDV - RCDVIN| / cond(RCONDV)
!>
!>       RCONDV es el número de condición recíproco del subespacio invariante derecho
!>       calculado por ZGEESX y RCDVIN (el valor verdadero precalculado)
!>       se proporciona como entrada. cond(RCONDV) es el número de condición
!>       de RCONDV, y tiene en cuenta los errores al calcular RCONDV,
!>       de modo que la cantidad resultante debería ser O(ULP).
!>       cond(RCONDV) se da esencialmente por norm(A)/RCONDE.
!>

Parámetros

COMP 
!>          COMP es LOGICAL
!>          COMP describe qué pruebas de entrada se realizarán:
!>            = .FALSE. si los números de condición calculados no deben
!>                      ser probados contra RCDVIN y RCDEIN
!>            = .TRUE.  si deben compararse
!>

JTYPE

!>          JTYPE es INTEGER
!>          Tipo de matriz de entrada. Se utiliza para etiquetar la salida si ocurre un error.
!>

ISEED

!>          ISEED es un array INTEGER, de dimensión (4)
!>          Si COMP = .FALSE., la semilla del generador de números aleatorios
!>          utilizada para producir la matriz.
!>          Si COMP = .TRUE., ISEED(1) = el número del ejemplo.
!>          Se utiliza para etiquetar la salida si ocurre un error.
!>

THRESH

!>          THRESH es DOUBLE PRECISION
!>          Una prueba se considerará si lo calculado,
!>          como se describe anteriormente, excede THRESH. Tenga en cuenta que el error
!>          se escala para que sea O(1), por lo que THRESH debe ser un múltiplo
!>          razonablemente pequeño de 1, por ejemplo, 10 o 100. En particular,
!>          no debe depender de la precisión (simple vs. doble)
!>          o el tamaño de la matriz. Debe ser al menos cero.
!>

NOUNIT

!>          NOUNIT es INTEGER
!>          El número de unidad FORTRAN para imprimir mensajes de error
!>          (por ejemplo, si una rutina devuelve INFO distinto de 0).
!>

N

!>          N es INTEGER
!>          La dimensión de A. N debe ser al menos 0.
!>

A

!>          A es un array COMPLEX*16, de dimensión (LDA, N)
!>          Se utiliza para mantener la matriz cuyos valores propios se van a
!>          calcular.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal de A y H. LDA debe ser
!>          al menos 1 y al menos N.
!>

H

!>          H es un array COMPLEX*16, de dimensión (LDA, N)
!>          Otra copia de la matriz de prueba A, modificada por ZGEESX.
!>

HT

!>          HT es un array COMPLEX*16, de dimensión (LDA, N)
!>          Otra copia más de la matriz de prueba A, modificada por ZGEESX.
!>

W

!>          W es un array COMPLEX*16, de dimensión (N)
!>          Los valores propios calculados de A.
!>

WT

!>          WT es un array COMPLEX*16, de dimensión (N)
!>          Al igual que W, este array contiene los valores propios de A,
!>          pero aquellos calculados cuando ZGEESX solo calcula una
!>          descomposición de valores propios parcial, es decir, sin vectores de Schur
!>

WTMP

!>          WTMP es un array COMPLEX*16, de dimensión (N)

NAME

zget24

ZGET24 -Este subprograma realiza pruebas de precisión de los subprogramas de la biblioteca LAPACK que calculan el número de condición de los valores propios y los vectores propios de una matriz general compleja.

Function/Subroutine Documentation

COMP

        COMP is CHARACTER*1
        = 'C': compute condition numbers for the average of the selected
               eigenvalues and for the selected right invariant subspace.
        = 'N': compute condition numbers for the average of the selected
               eigenvalues and for the selected right invariant subspace.

SELECT

        SELECT is LOGICAL array, dimension (N)
        On entry, SELECT indicates which eigenvalue(s) to select. To select the
        J-th eigenvalue, SELECT(J) must be set to .TRUE.
        On exit, SELECT is undefined.

N

        N is INTEGER
        The order of the matrix A. N >= 0.

A

        A is COMPLEX*16 array, dimension (LDA, N)
        On entry, A contains the coefficient matrix.

LDA

        LDA is INTEGER
        Leading dimension of A. LDA >= max(1, N).

B

        B is COMPLEX*16 array, dimension (LDB, N)
        On entry, B contains the coefficient matrix.

LDB

        LDB is INTEGER
        Leading dimension of B. LDB >= max(1, N).

ALPHAR

        ALPHAR is DOUBLE PRECISION array, dimension (N)
        ALPHAR and ALPHAI contain the real and imaginary parts of the
        eigenvalues of A.

ALPHAI

        ALPHAI is DOUBLE PRECISION array, dimension (N)
        See comments for ALPHAR.

BETA

        BETA is DOUBLE PRECISION array, dimension (N)
        BETA contains the eigenvalues of B.
        See comments for ALPHAR.

CDENSE

        CDENSE is COMPLEX*16 array, dimension (N, N)
        CDENSE contains the Schur vectors derived from the generalized
        eigenvalue problem A*x = lambda*B*x.

SDENSE

        SDENSE is COMPLEX*16 array, dimension (N, N)
        SDENSE contains the Schur vectors derived from the generalized
        eigenvalue problem A*x = lambda*B*x.

VS

        VS is COMPLEX*16 array, dimension (LDVS, N)
        VS holds the computed Schur vectors.

LDVS

        LDVS is INTEGER
        Leading dimension of VS. Must be at least max(1, N).

VS1

        VS1 is COMPLEX*16 array, dimension (LDVS, N)
        VS1 holds another copy of the computed Schur vectors.

RCDEIN

        RCDEIN is DOUBLE PRECISION
        When COMP = .TRUE. RCDEIN holds the precomputed reciprocal
        condition number for the average of selected eigenvalues.

RCDVIN

        RCDVIN is DOUBLE PRECISION
        When COMP = .TRUE. RCDVIN holds the precomputed reciprocal
        condition number for the selected right invariant subspace.

NSLCT

        NSLCT is INTEGER
        When COMP = .TRUE. the number of selected eigenvalues
        corresponding to the precomputed values RCDEIN and RCDVIN.

ISLCT

        ISLCT is INTEGER array, dimension (NSLCT)
        When COMP = .TRUE. ISLCT selects the eigenvalues of the
        input matrix corresponding to the precomputed values RCDEIN
        and RCDVIN. For I=1, ... ,NSLCT, if ISLCT(I) = J, then the
        eigenvalue with the J-th largest real or imaginary part is
        selected. The real part is used if ISRT = 0, and the
        imaginary part if ISRT = 1.
        Not referenced if COMP = .FALSE.

ISRT

        ISRT is INTEGER
        When COMP = .TRUE., ISRT describes how ISLCT is used to
        choose a subset of the spectrum.
        Not referenced if COMP = .FALSE.

RESULT

        RESULT is DOUBLE PRECISION array, dimension (17)
        The values computed by the 17 tests described above.
        The values are currently limited to 1/ulp, to avoid
        overflow.

WORK

        WORK is COMPLEX*16 array, dimension (2*N*N)

LWORK

        LWORK is INTEGER
        The number of entries in WORK to be passed to ZGEESX. This
        must be at least 2*N, and N*(N+1)/2 if tests 14--16 are to
        be performed.

RWORK

        RWORK is DOUBLE PRECISION array, dimension (N)

BWORK

        BWORK is LOGICAL array, dimension (N)

INFO

        INFO is INTEGER
        If 0,  successful exit.
        If <0, input parameter -INFO had an incorrect value.
        If >0, ZGEESX returned an error code, the absolute
               value of which is returned.
