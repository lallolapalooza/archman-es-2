subrutina zgtsvx (character fact, character trans, integer n, integer nrhs, complex*16, dimension( * ) dl, complex*16, dimension( * ) d, complex*16, dimension( * ) du, complex*16, dimension( * ) dlf, complex*16, dimension( * ) df, complex*16, dimension( * ) duf, complex*16, dimension( * ) du2, integer, dimension( * ) ipiv, complex*16, dimension( ldb, * ) b, integer ldb, complex*16, dimension( ldx, * ) x, integer ldx, double precision rcond, double precision, dimension( * ) ferr, double precision, dimension( * ) berr, complex*16, dimension( * ) work, double precision, dimension( * ) rwork, integer info)

ZGTSVX calcula la solución del sistema de ecuaciones lineales A * X = B para matrices GT

Propósito:

!>
!> ZGTSVX utiliza la factorización LU para calcular la solución de un sistema
!> complejo de ecuaciones lineales A * X = B, A**T * X = B, o A**H * X = B,
!> donde A es una matriz tridiagonal de orden N y X y B son matrices N por NRHS.
!>
!> También se proporcionan límites de error en la solución y una estimación de
!> la condición.
!>

Descripción:

!>
!> Se realizan los siguientes pasos:
!>
!> 1. Si FACT = 'N', se utiliza la descomposición LU para factorizar la matriz A
!>    como A = L * U, donde L es un producto de matrices de permutación y
!>    bidiagonales inferiores unitarias y U es triangular superior con no ceros
!>    solo en la diagonal principal y las dos superdiagonales superiores.
!>
!> 2. Si algún U(i,i)=0, por lo que U es exactamente singular, entonces la rutina
!>    devuelve INFO = i. De lo contrario, se utiliza la forma factorizada de A
!>    para estimar el número de condición de la matriz A. Si el
!>    recíproco del número de condición es menor que la precisión de la máquina,
!>    se devuelve INFO = N+1 como una advertencia, pero la rutina aún continúa
!>    resolviendo X y calculando límites de error como se describe a continuación.
!>
!> 3. El sistema de ecuaciones se resuelve para X utilizando la forma factorizada
!>    de A.
!>
!> 4. Se aplica refinamiento iterativo para mejorar la matriz solución calculada
!>    y calcular los límites de error y las estimaciones de error hacia atrás
!>    para la misma.
!>

Parámetros

FACT 
!>          FACT es CHARACTER*1
!>          Especifica si la forma factorizada de A se ha proporcionado o no
!>          en la entrada.
!>          = 'F':  DLF, DF, DUF, DU2, y IPIV contienen la forma factorizada
!>                  de A; DL, D, DU, DLF, DF, DUF, DU2 e IPIV no se modificarán.
!>          = 'N':  La matriz se copiará a DLF, DF y DUF
!>                  y se factorizará.
!>

TRANS

!>          TRANS es CHARACTER*1
!>          Especifica la forma del sistema de ecuaciones:
!>          = 'N':  A * X = B     (Sin transposición)
!>          = 'T':  A**T * X = B  (Transpuesta)
!>          = 'C':  A**H * X = B  (Transpuesta conjugada)
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de lados derechos, es decir, el número de columnas
!>          de la matriz B.  NRHS >= 0.
!>

DL

!>          DL es un array COMPLEX*16, dimensión (N-1)
!>          Los (n-1) elementos subdiagonales de A.
!>

D

!>          D es un array COMPLEX*16, dimensión (N)
!>          Los n elementos diagonales de A.
!>

DU

!>          DU es un array COMPLEX*16, dimensión (N-1)
!>          Los (n-1) elementos superdiagonales de A.
!>

DLF

!>          DLF es un array COMPLEX*16, dimensión (N-1)
!>          Si FACT = 'F', entonces DLF es un argumento de entrada y en la
!>          entrada contiene los (n-1) multiplicadores que definen la matriz L de
!>          la factorización LU de A calculada por ZGTTRF.
!>
!>          Si FACT = 'N', entonces DLF es un argumento de salida y en la salida
!>          contiene los (n-1) multiplicadores que definen la matriz L de
!>          la factorización LU de A.
!>

DF

!>          DF es un array COMPLEX*16, dimensión (N)
!>          Si FACT = 'F', entonces DF es un argumento de entrada y en la
!>          entrada contiene los n elementos diagonales de la matriz
!>          triangular superior U de la factorización LU de A.
!>
!>          Si FACT = 'N', entonces DF es un argumento de salida y en la salida
!>          contiene los n elementos diagonales de la matriz
!>          triangular superior U de la factorización LU de A.
!>

DUF

!>          DUF es un array COMPLEX*16, dimensión (N-1)
!>          Si FACT = 'F', entonces DUF es un argumento de entrada y en la
!>          entrada contiene los (n-1) elementos de la primera superdiagonal de U.
!>
!>          Si FACT = 'N', entonces DUF es un argumento de salida y en la salida
!>          contiene los (n-1) elementos de la primera superdiagonal de U.
!>

DU2

!>          DU2 es un array COMPLEX*16, dimensión (N-2)
!>          Si FACT = 'F', entonces DU2 es un argumento de entrada y en la
!>          entrada contiene los (n-2) elementos de la segunda superdiagonal de
!>          U.
!>
!>          Si FACT = 'N', entonces DU2 es un argumento de salida y en la salida
!>          contiene los (n-2) elementos de la segunda superdiagonal de
!>          U.
!>

IPIV

!>          IPIV es un array INTEGER, dimensión (N)
!>          Si FACT = 'F', entonces IPIV es un argumento de entrada y en la
!>          entrada contiene los índices de pivote de la factorización LU de A
!>          calculada por ZGTTRF.
!>
!>          Si FACT = 'N', entonces IPIV es un argumento de salida y en la salida
!>          contiene los índices de pivote de la factorización LU de A;
!>          la fila i de la matriz se intercambió con la fila IPIV(i).
!>          IPIV(i) siempre será i o i+1; IPIV(i) = i indica que no se requirió
!>          un intercambio de filas.
!>

B

!>          B es un array COMPLEX*16, dimensión (LDB,NRHS)
!>          La matriz del lado derecho B de N por NRHS.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B.  LDB >= max(1,N).
!>

X

!>          X es un array COMPLEX*16, dimensión (LDX,NRHS)
!>          Si INFO = 0 o INFO = N+1, la matriz solución X de N por NRHS.
!>

LDX

!>          LDX es INTEGER
!>          La dimensión principal del array X.  LDX >= max(1,N).
!>

RCOND

!>          RCOND es DOUBLE PRECISION
!>          La estimación del número de condición recíproco de la matriz
!>          A.  Si RCOND es menor que la precisión de la máquina (en
!>          particular, si RCOND = 0), la matriz es singular con precisión de
!>          trabajo. Esta condición se indica con un código de retorno de
!>          INFO > 0.
!>

FERR

!>          FERR es un array DOUBLE PRECISION, dimensión (NRHS)
!>          El límite de error directo estimado para cada vector solución
!>          X(j) (la columna j de la matriz solución X).
!>

BERR

!>          BERR es un array DOUBLE PRECISION, dimensión (NRHS)
!>          El error hacia atrás real estimado para cada solución vectorizada
!>          X(j).
!>

WORK

!>          WORK es un array COMPLEX*16, dimensión (max(2*N, LWORK))
!>          donde LWORK es la longitud requerida para el workspace de la
!>          subrutina de refinamiento y solución.
!>
!>          Si FACT = 'N', entonces WORK es un argumento de salida y contiene
!>          la información de workspace requerida.
!>

RWORK

!>          RWORK es un array DOUBLE PRECISION, dimensión (N)
!>          Workspace de longitud requerida para el refinamiento iterativo.
!>

INFO

!>          INFO es INTEGER
!>          = 0: ejecución correcta.
!>          < 0: si INFO = -i, entonces el i-ésimo argumento ingresado tuvo un
!>               valor ilegal. Se asegura que los argumentos 1 hasta -i están
!>               de acuerdo con el resto de los argumentos.
!>          > 0: si INFO = i, y 1 <= i <= N, entonces U(i,i) es cero. La factorización
!>               ha tomado su curso, pero la matriz es singular. Se puede exigir
!>               encontrar la solución, pero el número de condición
!>               no se puede estimar.
!>               Si INFO = N+1, el recíproco del número de condición de A es
!>               muy pequeño. La matriz es singular o casi mal condicionada
!>               a la precisión de trabajo y las soluciones pueden no ser
!>               exactas.
!>

ZGTSV

ZGTSVX uses the fast GGBALAPACK routines to solve the system of equations AX = B

Subroutine ZGTSVX

SUBROUTINE ZGTSVX(
     FACT, TRANS, N, NRHS, DL, D, DR, DU, CL, C, CR, CU, CLB,     &
     DNB, DRB,     &
     B, LDB,      &
     X, LDX,      &
     RCOND, FERR, BERR, WORK, RWORK, INFO )

The subroutine ZGTSVX is a driver routine for solving AX = B, where A is a general tridiagonal matrix. It uses GGBALAPACK routines to compute the factorization of A, and then uses the factored form to compute the solution X of the system of equations.

Arguments

FACT
CHARACTER*1

Specifies whether or not the factorization of A has been computed by previous calls and passed to ZGTSVX. = 'F': On entry, FACT = 'F' specifies that A is already factored by ZGTF (or some other factorization routine). = 'N': On entry, FACT = 'N' specifies that the factorization of A needs to be computed and passed to ZGTSVX. = 'E': On entry, FACT = 'E' specifies that the factorization of A has already been computed by ZGTF and passed to ZGTSVX. ZGTF is called only if FACT is not 'F'. Unchanged on exit.

TRANS
CHARACTER*1

Specifies the form of the system of equations to be solved. = 'N': Solve A*X = B (No transpose). = 'T': Solve A**T*X = B (Transpose). = 'C': Solve A**H*X = B (Conjugate transpose). Unchanged on exit.

N
INTEGER

The order of the matrix A. N >= 0. Unchanged on exit.

NRHS
INTEGER

The number of right hand sides, i.e., the number of columns of the matrix B. NRHS >= 0. Unchanged on exit.

DL
COMPLEX*16 array, dimension (N-1)

The (n-1) sub-diagonal elements of the matrix A. On exit, DL may be over-written by details of the factorization.

D
COMPLEX*16 array, dimension (N)

The diagonal elements of the matrix A. On exit, D may be over-written by details of the factorization.

DR
COMPLEX*16 array, dimension (N-1)

The (n-1) super-diagonal elements of the matrix A. On exit, DR may be over-written by details of the factorization.

DU
COMPLEX*16 array, dimension (N-2)

The (n-2) second super-diagonal elements of the matrix A. On exit, DU may be over-written by details of the factorization.

CL
COMPLEX*16 array, dimension (N-1)

The (n-1) sub-diagonal elements of the matrix A. On exit, CL may be over-written by details of the factorization.

C
COMPLEX*16 array, dimension (N)

The diagonal elements of the matrix A. On exit, C may be over-written by details of the factorization.

CR
COMPLEX*16 array, dimension (N-1)

The (n-1) super-diagonal elements of the matrix A. On exit, CR may be over-written by details of the factorization.

CU
COMPLEX*16 array, dimension (N-2)

The (n-2) second super-diagonal elements of the matrix A. On exit, CU may be over-written by details of the factorization.

CLB
COMPLEX*16 array, dimension (N-1)

The (n-1) sub-diagonal elements of the matrix A. On exit, CLB may be over-written by details of the factorization.

DNB
COMPLEX*16 array, dimension (N)

The diagonal elements of the matrix A. On exit, DNB may be over-written by details of the factorization.

DRB
COMPLEX*16 array, dimension (N-1)

The (n-1) super-diagonal elements of the matrix A. On exit, DRB may be over-written by details of the factorization.

B
COMPLEX*16 array, dimension (LDB, NRHS)

The right-hand side matrix B. On exit, the modification of B depends on the value of TRANS.

LDB
INTEGER

The leading dimension of the array B. LDB >= max(1,N). Unchanged on exit.

X
COMPLEX*16 array, dimension (LDX, NRHS)

The solution matrix X. On exit, the modification of X depends on the value of TRANS.

LDX
INTEGER

The leading dimension of the array X. LDX >= max(1,N). Unchanged on exit.

RCOND
DOUBLE PRECISION

An estimate of the reciprocal of the condition number of A. RCOND is computed by ZGSTSV.RCOND. If RCOND is small, the matrix A is close to singular and the solution X may be inaccurate.

FERR
DOUBLE PRECISION array, dimension (NRHS)

An upper bound for the magnitude of the largest element in (X(j) - XTRUE) divided by the magnitude of the largest element in X(j), where X(j) is the j-th column of the solution computed by the routine, and XTRUE is the corresponding true solution. The estimate is as reliable as the estimate for RCOND, and is almost always a slight overestimate of the true error.

BERR
DOUBLE PRECISION array, dimension (NRHS)

The componentwise relative backward error of each solution vector X(j) (i.e., the smallest relative change in any element of A or B that makes X(j) an exact solution).

WORK
COMPLEX*16 array, dimension (2*N)

Scratch workspace for the routine.

RWORK
DOUBLE PRECISION array, dimension (N)

Scratch workspace for the routine.

INFO
INTEGER

= 0: successful exit < 0: if INFO = -i, the i-th argument had an illegal value > 0: if INFO = i, and i is <= N: U(i,i) is exactly zero. The factorization has not been completed unless i = N, but the factor U is exactly singular, so the solution and error bounds could not be computed. RCOND = 0 is returned. = N+1: U is nonsingular, but RCOND is less than machine precision, meaning that the matrix is singular to working precision. Nevertheless, the solution and error bounds are computed because there are a number of situations where the computed solution can be more accurate than the value of RCOND would suggest.
