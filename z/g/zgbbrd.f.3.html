Documentación de Función/Subrutina

subrutina zgbbrd (character vect, integer m, integer n, integer ncc, integer kl, integer ku, complex*16, dimension( ldab, * ) ab, integer ldab, double precision, dimension( * ) d, double precision, dimension( * ) e, complex*16, dimension( ldq, * ) q, integer ldq, complex*16, dimension( ldpt, * ) pt, integer ldpt, complex*16, dimension( ldc, * ) c, integer ldc, complex*16, dimension( * ) work, double precision, dimension( * ) rwork, integer info)

ZGBBRD

Propósito:

!>
!> ZGBBRD reduce una matriz de banda general compleja m por n A a la forma
!> bidiagonal superior real B mediante una transformación unitaria: Q**H * A * P = B.
!>
!> La rutina calcula B, y opcionalmente forma Q o P**H, o calcula
!> Q**H*C para una matriz C dada.
!>

Parámetros

VECT 
!>          VECT es CHARACTER*1
!>          Especifica si las matrices Q y P**H deben formarse o no.
!>          = 'N': no formar Q ni P**H;
!>          = 'Q': formar solo Q;
!>          = 'P': formar solo P**H;
!>          = 'B': formar ambas.
!>

M

!>          M es INTEGER
!>          El número de filas de la matriz A.  M >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz A.  N >= 0.
!>

NCC

!>          NCC es INTEGER
!>          El número de columnas de la matriz C.  NCC >= 0.
!>

KL

!>          KL es INTEGER
!>          El número de subdiagonales de la matriz A. KL >= 0.
!>

KU

!>          KU es INTEGER
!>          El número de superdiagonales de la matriz A. KU >= 0.
!>

AB

!>          AB es una matriz COMPLEX*16, de dimensión (LDAB,N)
!>          En la entrada, la matriz de banda m por n A, almacenada en las filas 1 a
!>          KL+KU+1. La j-ésima columna de A se almacena en la j-ésima columna de
!>          la matriz AB de la siguiente manera:
!>          AB(ku+1+i-j,j) = A(i,j) para max(1,j-ku)<=i<=min(m,j+kl).
!>          En la salida, A se sobrescribe con valores generados durante la
!>          reducción.
!>

LDAB

!>          LDAB es INTEGER
!>          La dimensión principal de la matriz A. LDAB >= KL+KU+1.
!>

D

!>          D es una matriz DOUBLE PRECISION, de dimensión (min(M,N))
!>          Los elementos diagonales de la matriz bidiagonal B.
!>

E

!>          E es una matriz DOUBLE PRECISION, de dimensión (min(M,N)-1)
!>          Los elementos superdiagonales de la matriz bidiagonal B.
!>

Q

!>          Q es una matriz COMPLEX*16, de dimensión (LDQ,M)
!>          Si VECT = 'Q' o 'B', la matriz unitaria m por m Q.
!>          Si VECT = 'N' o 'P', la matriz Q no se referencia.
!>

LDQ

!>          LDQ es INTEGER
!>          La dimensión principal de la matriz Q.
!>          LDQ >= max(1,M) si VECT = 'Q' o 'B'; LDQ >= 1 en caso contrario.
!>

PT

!>          PT es una matriz COMPLEX*16, de dimensión (LDPT,N)
!>          Si VECT = 'P' o 'B', la matriz unitaria n por n P'.
!>          Si VECT = 'N' o 'Q', la matriz PT no se referencia.
!>

LDPT

!>          LDPT es INTEGER
!>          La dimensión principal de la matriz PT.
!>          LDPT >= max(1,N) si VECT = 'P' o 'B'; LDPT >= 1 en caso contrario.
!>

C

!>          C es una matriz COMPLEX*16, de dimensión (LDC,NCC)
!>          En la entrada, una matriz C de m por ncc.
!>          En la salida, C se sobrescribe con Q**H*C.
!>          C no se referencia si NCC = 0.
!>

LDC

!>          LDC es INTEGER
!>          La dimensión principal de la matriz C.
!>          LDC >= max(1,M) si NCC > 0; LDC >= 1 si NCC = 0.
!>

WORK

!>          WORK es una matriz COMPLEX*16, de dimensión (max(M,N))
!>

RWORK

!>          RWORK es una matriz DOUBLE PRECISION, de dimensión (max(M,N))
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa.
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>
