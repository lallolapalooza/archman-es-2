ZGGSVP3

Propósito:

!>
!> ZGGSVP3 calcula matrices unitarias U, V y Q tales que
!>
!>                    N-K-L  K    L
!>  U**H*A*Q =     K ( 0    A12  A13 )  si M-K-L >= 0;
!>                 L ( 0     0   A23 )
!>             M-K-L ( 0     0    0  )
!>
!>                  N-K-L  K    L
!>         =     K ( 0    A12  A13 )  si M-K-L < 0;
!>             M-K ( 0     0   A23 )
!>
!>                  N-K-L  K    L
!>  V**H*B*Q =   L ( 0     0   B13 )
!>             P-L ( 0     0    0  )
!>
!> donde la matriz KxK A12 y la matriz LxL B13 no son singulares
!> triangulares superiores; A23 es triangular superior LxL si M-K-L >= 0,
!> de lo contrario A23 es trapezoidal superior (M-K)xL. K+L = el rango
!> numérico efectivo de la matriz (M+P)xN (A**H,B**H)**H.
!>
!> Esta descomposición es el paso de preprocesamiento para calcular la
!> Descomposición de Valores Singulares Generalizada (GSVD), véase la subrutina
!> ZGGSVD3.
!>

Parámetros

JOBU 
!>          JOBU es CHARACTER*1
!>          = 'U':  se calcula la matriz unitaria U;
!>          = 'N':  U no se calcula.
!>

JOBV

!>          JOBV es CHARACTER*1
!>          = 'V':  se calcula la matriz unitaria V;
!>          = 'N':  V no se calcula.
!>

JOBQ

!>          JOBQ es CHARACTER*1
!>          = 'Q':  se calcula la matriz unitaria Q;
!>          = 'N':  Q no se calcula.
!>

M

!>          M es INTEGER
!>          El número de filas de la matriz A.  M >= 0.
!>

P

!>          P es INTEGER
!>          El número de filas de la matriz B.  P >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas de las matrices A y B.  N >= 0.
!>

A

!>          A es array COMPLEX*16, dimensión (LDA,N)
!>          En la entrada, A contiene la matriz triangular (o trapezoidal)
!>          descrita en el propósito.
!>          En la salida, A contiene la matriz triangular (o trapezoidal)
!>          descrita en la sección Propósito.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A. LDA >= max(1,M).
!>

B

!>          B es array COMPLEX*16, dimensión (LDB,N)
!>          En la entrada, la matriz PxN B.
!>          En la salida, B contiene la matriz triangular descrita en
!>          la sección Propósito.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B. LDB >= max(1,P).
!>

TOLA

!>          TOLA es DOUBLE PRECISION
!>

TOLB

!>          TOLB es DOUBLE PRECISION
!>
!>          TOLA y TOLB son los umbrales para determinar el rango
!>          numérico efectivo de la matriz B y un subbloque de A.
!>          Generalmente, se establecen como:
!>             TOLA = MAX(M,N)*norm(A)*MAZHEPS,
!>             TOLB = MAX(P,N)*norm(B)*MAZHEPS.
!>          El tamaño de TOLA y TOLB puede afectar los errores hacia atrás
!>          de la descomposición.
!>

K

!>          K es INTEGER
!>

L

!>          L es INTEGER
!>
!>          En la salida, K y L especifican la dimensión de los subbloques
!>          descritos en la sección Propósito.
!>          K + L = rango numérico efectivo de (A**H,B**H)**H.
!>

U

!>          U es array COMPLEX*16, dimensión (LDU,M)
!>          Si JOBU = 'U', U contiene la matriz unitaria U.
!>          Si JOBU = 'N', U no se utiliza.
!>

LDU

!>          LDU es INTEGER
!>          La dimensión principal del array U. LDU >= max(1,M) si
!>          JOBU = 'U'; LDU >= 1 en caso contrario.
!>

V

!>          V es array COMPLEX*16, dimensión (LDV,P)
!>          Si JOBV = 'V', V contiene la matriz unitaria V.
!>          Si JOBV = 'N', V no se utiliza.
!>

LDV

!>          LDV es INTEGER
!>          La dimensión principal del array V. LDV >= max(1,P) si
!>          JOBV = 'V'; LDV >= 1 en caso contrario.
!>

Q

!>          Q es array COMPLEX*16, dimensión (LDQ,N)
!>          Si JOBQ = 'Q', Q contiene la matriz unitaria Q.
!>          Si JOBQ = 'N', Q no se utiliza.
!>

LDQ

!>          LDQ es INTEGER
!>          La dimensión principal del array Q. LDQ >= max(1,N) si
!>          JOBQ = 'Q'; LDQ >= 1 en caso contrario.
!>

IWORK

!>          IWORK es array INTEGER, dimensión (N)
!>

RWORK

!>          RWORK es array DOUBLE PRECISION, dimensión (2*N)
!>

TAU

!>          TAU es array COMPLEX*16, dimensión (N)
!>

WORK

!>          WORK es array COMPLEX*16, dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK. LWORK >= 1.
!>
!>          Si LWORK = -1, se asume una consulta de espacio de trabajo;
!>          la rutina solo calcula el tamaño óptimo del array WORK,
!>          devuelve este valor como la primera entrada del array WORK,
!>          y XERBLA no emite ningún mensaje de error relacionado con LWORK.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>
