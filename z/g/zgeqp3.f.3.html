Documentación de Función/Subrutina

subrutina zgeqp3 (integer m, integer n, complex*16, dimension( lda, * ) a, integer lda, integer, dimension( * ) jpvt, complex*16, dimension( * ) tau, complex*16, dimension( * ) work, integer lwork, double precision, dimension( * ) rwork, integer info)

ZGEQP3

Propósito:

!>
!> ZGEQP3 calcula una factorización QR con pivoteo de columnas de una
!> matriz A: A*P = Q*R utilizando BLAS de Nivel 3.
!>

Parámetros

M 
!>          M es INTEGER
!>          El número de filas de la matriz A. M >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz A. N >= 0.
!>

A

!>          A es array COMPLEX*16, dimensión (LDA,N)
!>          En la entrada, la matriz M-por-N A.
!>          En la salida, la parte triangular superior del array contiene la
!>          matriz superior trapezoidal R de min(M,N)-por-N; los elementos debajo
!>          de la diagonal, junto con el array TAU, representan la
!>          matriz unitaria Q como un producto de min(M,N) 
!>          reflejos elementales.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A. LDA >= max(1,M).
!>

JPVT

!>          JPVT es array INTEGER, dimensión (N)
!>          En la entrada, si JPVT(J).ne.0, la J-ésima columna de A se permuta
!>          al frente de A*P (una columna líder); si JPVT(J)=0,
!>          la J-ésima columna de A es una columna libre.
!>          En la salida, si JPVT(J)=K, entonces la J-ésima columna de A*P fue la
!>          la K-ésima columna de A.
!>

TAU

!>          TAU es array COMPLEX*16, dimensión (min(M,N))
!>          Los factores escalares de los reflejos elementales.
!>

WORK

!>          WORK es array COMPLEX*16, dimensión (MAX(1,LWORK))
!>          En la salida, si INFO=0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK. LWORK >= N+1.
!>          Para un rendimiento óptimo LWORK >= ( N+1 )*NB, donde NB
!>          es el tamaño de bloque óptimo.
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo del array WORK, devuelve
!>          este valor como la primera entrada del array WORK, y XERBLA no emite ningún mensaje de error
!>          relacionado con LWORK.
!>

RWORK

!>          RWORK es array DOUBLE PRECISION, dimensión (2*N)
!>

INFO

!>          INFO es INTEGER
!>          = 0: salida exitosa.
!>          < 0: si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>

Detalles Adicionales:

!>
!>  La matriz Q se representa como un producto de reflejos elementales
!>
!>     Q = H(1) H(2) . . . H(k), donde k = min(m,n).
!>
!>  Cada H(i) tiene la forma
!>
!>     H(i) = I - tau * v * v**H
!>
!>  donde tau es un escalar complejo, y v es un vector real/complejo
!>  con v(1:i-1) = 0 y v(i) = 1; v(i+1:m) se almacena en la salida en
!>  A(i+1:m,i), y tau en TAU(i).
!>
