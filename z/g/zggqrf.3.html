Documentación de Función/Subrutina

subrutina zggqrf (integer n, integer m, integer p, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( * ) taua, complex*16, dimension( ldb, * ) b, integer ldb, complex*16, dimension( * ) taub, complex*16, dimension( * ) work, integer lwork, integer info)

ZGGQRF

Propósito:

!>
!> ZGGQRF calcula una factorización QR generalizada de una matriz N por M, A,
!> y una matriz N por P, B:
!>
!>             A = Q*R,        B = Q*T*Z,
!>
!> donde Q es una matriz unitaria N por N, Z es una matriz unitaria P por P,
!> y R y T asumen una de las siguientes formas:
!>
!> si N >= M,  R = ( R11 ) M  ,   o si N < M,  R = ( R11  R12 ) N,
!>                 (  0  ) N-M                         N   M-N
!>                    M                                    M
!>
!> donde R11 es triangular superior, y
!>
!> si N <= P,  T = ( 0  T12 ) N,   o si N > P,  T = ( T11 ) N-P,
!>                  P-N  N                           ( T21 ) P
!>                                                      P
!>
!> donde T12 o T21 es triangular superior.
!>
!> En particular, si B es cuadrada y no singular, la factorización GQR
!> de A y B da implícitamente la factorización QR de inv(B)*A:
!>
!>              inv(B)*A = Z**H * (inv(T)*R)
!>
!> donde inv(B) denota la inversa de la matriz B, y Z**H denota la
!> transpuesta conjugada de la matriz Z.
!>

Parámetros

N 
!>          N es INTEGER
!>          El número de filas de las matrices A y B. N >= 0.
!>

M

!>          M es INTEGER
!>          El número de columnas de la matriz A.  M >= 0.
!>

P

!>          P es INTEGER
!>          El número de columnas de la matriz B.  P >= 0.
!>

A

!>          A es una matriz COMPLEX*16, dimensión (LDA,M)
!>          En la entrada, la matriz A de N por M.
!>          En la salida, los elementos en y por encima de la diagonal de la matriz
!>          contienen la matriz trapezoidal superior R de min(N,M) por M (R es
!>          triangular superior si N >= M); los elementos por debajo de la diagonal,
!>          junto con la matriz TAUA, representan la matriz unitaria Q como un
!>          producto de min(N,M) reflectores elementales (ver Detalles Adicionales).
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal de la matriz A. LDA >= max(1,N).
!>

TAUA

!>          TAUA es una matriz COMPLEX*16, dimensión (min(N,M))
!>          Los factores escalares de los reflectores elementales que
!>          representan la matriz unitaria Q (ver Detalles Adicionales).
!>

B

!>          B es una matriz COMPLEX*16, dimensión (LDB,P)
!>          En la entrada, la matriz B de N por P.
!>          En la salida, si N <= P, el triángulo superior de la submatriz
!>          B(1:N,P-N+1:P) contiene la matriz triangular superior T de N por N;
!>          si N > P, los elementos en y por encima de la (N-P)-ésima subdiagonal
!>          contienen la matriz trapezoidal superior T de N por P; los elementos
!>          restantes, junto con la matriz TAUB, representan la matriz unitaria
!>          Z como un producto de reflectores elementales (ver Detalles Adicionales).
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal de la matriz B. LDB >= max(1,N).
!>

TAUB

!>          TAUB es una matriz COMPLEX*16, dimensión (min(N,P))
!>          Los factores escalares de los reflectores elementales que
!>          representan la matriz unitaria Z (ver Detalles Adicionales).
!>

WORK

!>          WORK es una matriz COMPLEX*16, dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión de la matriz WORK. LWORK >= max(1,N,M,P).
!>          Para un rendimiento óptimo LWORK >= max(N,M,P)*max(NB1,NB2,NB3),
!>          donde NB1 es el tamaño de bloque óptimo para la factorización QR
!>          de una matriz N por M, NB2 es el tamaño de bloque óptimo para
!>          la factorización RQ de una matriz N por P, y NB3 es el tamaño de bloque
!>          óptimo para una llamada a ZUNMQR.
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo;
!>          la rutina solo calcula el tamaño óptimo de la matriz WORK, devuelve
!>          este valor como la primera entrada de la matriz WORK, y XERBLA no
!>          emite ningún mensaje de error relacionado con LWORK.
!>

INFO

!>          INFO es INTEGER
!>           = 0:  salida exitosa
!>           < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>

Detalles Adicionales:

!>
!>  La matriz Q se representa como un producto de reflectores elementales
!>
!>     Q = H(1) H(2) . . . H(k), donde k = min(n,m).
!>
!>  Cada H(i) tiene la forma
!>
!>     H(i) = I - taua * v * v**H
!>
!>  donde taua es un escalar complejo, y v es un vector complejo con
!>  v(1:i-1) = 0 y v(i) = 1; v(i+1:n) se almacena en la salida en A(i+1:n,i),
!>  y taua en TAUA(i).
!>  Para formar Q explícitamente, use la subrutina ZUNGQR de LAPACK.
!>  Para usar Q para actualizar otra matriz, use la subrutina ZUNMQR de LAPACK.
!>
!>  La matriz Z se representa como un producto de reflectores elementales
!>
!>     Z = H(1) H(2) . . . H(k), donde k = min(n,p).
!>
!>  Cada H(i) tiene la forma
!>
!>     H(i) = I - taub * v * v**H
!>
!>  donde taub es un escalar complejo, y v es un vector complejo con
!>  v(p-k+i+1:p) = 0 y v(p-k+i) = 1; v(1:p-k+i-1) se almacena en la salida en
!>  B(n-k+i,1:p-k+i-1), y taub en TAUB(i).
!>  Para formar Z explícitamente, use la subrutina ZUNGRQ de LAPACK.
!>  Para usar Z para actualizar otra matriz, use la subrutina ZUNMRQ de LAPACK.
!>
