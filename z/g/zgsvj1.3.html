subroutine zgsvj1 (character*1 jobv, integer m, integer n, integer n1, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( n ) d, double precision, dimension( n ) sva, integer mv, complex*16, dimension( ldv, * ) v, integer ldv, double precision eps, double precision sfmin, double precision tol, integer nsweep, complex*16, dimension( lwork ) work, integer lwork, integer info)

ZGSVJ1 pre-procesador para la rutina zgesvj, aplica rotaciones de Jacobi dirigidas solo a pivotes particulares.

Propósito:

!>
!> ZGSVJ1 es llamada desde ZGESVJ como un pre-procesador y ese es su propósito
!> principal. Aplica rotaciones de Jacobi de la misma manera que ZGESVJ, pero
!> se dirige solo a pivotes particulares y no verifica la convergencia
!> (criterio de parada). Pocos parámetros de ajuste (marcados con [TP]) están
!> disponibles para el implementador.
!>
!> Detalles Adicionales
!> ~~~~~~~~~~~~~~~~~~~
!> ZGSVJ1 aplica unas pocas barridas de rotaciones de Jacobi en el espacio de
!> columnas de la matriz de entrada M por N, A. Los pares de pivotes se toman
!> del bloque fuera de la diagonal (1,2) en la matriz de Gram correspondiente
!> N por N, A^T * A. Las entradas de bloque (tiles) del bloque fuera de la
!> diagonal (1,2) están marcadas por los [x] en el siguiente esquema:
!>
!>    | *  *  * [x] [x] [x]|
!>    | *  *  * [x] [x] [x]|    Ciclo de filas en los bloques [x] nblr-por-nblc.
!>    | *  *  * [x] [x] [x]|    Pivoteo cíclico de filas dentro de cada bloque [x].
!>    |[x] [x] [x] *  *  * |
!>    |[x] [x] [x] *  *  * |
!>    |[x] [x] [x] *  *  * |
!>
!> En términos de las columnas de A, las primeras N1 columnas se rotan 'contra'
!> las restantes N-N1 columnas, intentando aumentar el ángulo entre los
!> subespacios correspondientes. El bloque fuera de la diagonal es N1-por-(N-N1)
!> y se divide en mosaicos usando mosaicos cuadradas de lado KBL. Aquí, KBL es
!> un parámetro de ajuste. El número de barridas se da en NSWEEP y el umbral
!> de ortogonalidad se da en TOL.
!>

Parámetros

JOBV 
!>          JOBV es CHARACTER*1
!>          Especifica si la salida de este procedimiento se utiliza
!>          para calcular la matriz V:
!>          = 'V': el producto de las rotaciones de Jacobi se acumula
!>                 multiplicando a la derecha la matriz V de N por N.
!>                (Ver la descripción de V.)
!>          = 'A': el producto de las rotaciones de Jacobi se acumula
!>                 multiplicando a la derecha la matriz V de MV por N.
!>                (Ver las descripciones de MV y V.)
!>          = 'N': las rotaciones de Jacobi no se acumulan.
!>

M

!>          M es INTEGER
!>          El número de filas de la matriz de entrada A. M >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz de entrada A.
!>          M >= N >= 0.
!>

N1

!>          N1 es INTEGER
!>          N1 especifica la partición de bloque 2x2, las primeras N1 columnas
!>          se rotan 'contra' las restantes N-N1 columnas de A.
!>

A

!>          A es COMPLEX*16 array, dimension (LDA,N)
!>          En la entrada, la matriz M por N A, tal que A*diag(D) representa
!>          la matriz de entrada.
!>          En la salida,
!>          A_onexit * D_onexit representa la matriz de entrada A*diag(D)
!>          multiplicada a la derecha por una secuencia de rotaciones de Jacobi,
!>          donde el umbral de rotación y el número total de barridas se dan en
!>          TOL y NSWEEP, respectivamente.
!>          (Ver las descripciones de N1, D, TOL y NSWEEP.)
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A. LDA >= max(1,M).
!>

D

!>          D es COMPLEX*16 array, dimension (N)
!>          El array D acumula los factores de escala de las rotaciones de Jacobi
!>          rápidamente escaladas.
!>          En la entrada, A*diag(D) representa la matriz de entrada.
!>          En la salida, A_onexit*diag(D_onexit) representa la matriz de entrada
!>          multiplicada a la derecha por una secuencia de rotaciones de Jacobi,
!>          donde el umbral de rotación y el número total de barridas se dan en
!>          TOL y NSWEEP, respectivamente.
!>          (Ver las descripciones de N1, A, TOL y NSWEEP.)
!>

SVA

!>          SVA es DOUBLE PRECISION array, dimension (N)
!>          En la entrada, SVA contiene las normas euclidianas de las columnas de
!>          la matriz A*diag(D).
!>          En la salida, SVA contiene las normas euclidianas de las columnas de
!>          la matriz onexit*diag(D_onexit).
!>

MV

!>          MV es INTEGER
!>          Si JOBV = 'A', entonces MV filas de V se multiplican a la derecha por
!>                           una secuencia de rotaciones de Jacobi.
!>          Si JOBV = 'N',   entonces MV no se hace referencia.
!>

V

!>          V es COMPLEX*16 array, dimension (LDV,N)
!>          Si JOBV = 'V', entonces N filas de V se multiplican a la derecha por
!>                           una secuencia de rotaciones de Jacobi.
!>          Si JOBV = 'A', entonces MV filas de V se multiplican a la derecha por
!>                           una secuencia de rotaciones de Jacobi.
!>          Si JOBV = 'N',   entonces V no se hace referencia.
!>

LDV

!>          LDV es INTEGER
!>          La dimensión principal del array V, LDV >= 1.
!>          Si JOBV = 'V', LDV >= N.
!>          Si JOBV = 'A', LDV >= MV.
!>

EPS

!>          EPS es DOUBLE PRECISION
!>          EPS = DLAMCH('Epsilon')
!>

SFMIN

!>          SFMIN es DOUBLE PRECISION
!>          SFMIN = DLAMCH('Safe Minimum')
!>

TOL

!>          TOL es DOUBLE PRECISION
!>          TOL es el umbral para las rotaciones de Jacobi. Para un par
!>          A(:,p), A(:,q) de columnas pivote, la rotación de Jacobi se
!>          aplica solo si ABS(COS(angle(A(:,p),A(:,q)))) > TOL.
!>

NSWEEP

!>          NSWEEP es INTEGER
!>          NSWEEP es el número de barridas de rotaciones de Jacobi a
!>          realizar.
!>

WORK

!>          WORK es COMPLEX*16 array, dimension (LWORK)
!>

LWORK

!>          LWORK es INTEGER
!>          LWORK es la dimensión de WORK. LWORK >= M.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa.
!>          < 0:  si INFO = -i, entonces el i-ésimo argumento tuvo un valor ilegal
!>
