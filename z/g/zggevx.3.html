subroutine zggevx (character balanc, character jobvl, character jobvr, character sense, integer n, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( ldb, * ) b, integer ldb, complex*16, dimension( * ) alpha, complex*16, dimension( * ) beta, complex*16, dimension( ldvl, * ) vl, integer ldvl, complex*16, dimension( ldvr, * ) vr, integer ldvr, integer ilo, integer ihi, double precision, dimension( * ) lscale, double precision, dimension( * ) rscale, double precision abnrm, double precision bbnrm, double precision, dimension( * ) rconde, double precision, dimension( * ) rcondv, complex*16, dimension( * ) work, integer lwork, double precision, dimension( * ) rwork, integer, dimension( * ) iwork, logical, dimension( * ) bwork, integer info)

ZGGEVX calcula los valores propios y, opcionalmente, los vectores propios izquierdos y/o derechos para matrices GE

Propósito:

!>
!> ZGGEVX calcula para un par de matrices complejas no simétricas de N por N
!> (A,B) los valores propios generalizados y, opcionalmente, los vectores propios generalizados izquierdos y/o derechos.
!>
!> Opcionalmente, también calcula una transformación de balanceo para mejorar
!> el condicionamiento de los valores propios y vectores propios (ILO, IHI,
!> LSCALE, RSCALE, ABNRM y BBNRM), los recíprocos de los números de condición
!> para los valores propios (RCONDE) y los recíprocos de los números de condición
!> para los vectores propios derechos (RCONDV).
!>
!> Un valor propio generalizado para un par de matrices (A,B) es un escalar
!> lambda o una razón alpha/beta = lambda, tal que A - lambda*B es
!> singular. Generalmente se representa como el par (alpha, beta), ya que
!> existe una interpretación razonable para beta=0, e incluso para ambos
!> siendo cero.
!>
!> El vector propio derecho v(j) correspondiente al valor propio lambda(j)
!> de (A,B) satisface
!>                  A * v(j) = lambda(j) * B * v(j) .
!> El vector propio izquierdo u(j) correspondiente al valor propio lambda(j)
!> de (A,B) satisface
!>                  u(j)**H * A  = lambda(j) * u(j)**H * B.
!> donde u(j)**H es la transpuesta conjugada de u(j).
!>
!>

Parámetros

BALANC 
!>          BALANC es CHARACTER*1
!>          Especifica la opción de balanceo a realizar:
!>          = 'N':  no escalar ni permutar diagonalmente;
!>          = 'P':  solo permutar;
!>          = 'S':  solo escalar;
!>          = 'B':  permutar y escalar.
!>          Los recíprocos de los números de condición calculados serán para las
!>          matrices después de permutar y/o balancear. La permutación no
!>          cambia los números de condición (en aritmética exacta), pero
!>          el balanceo sí lo hace.
!>

JOBVL

!>          JOBVL es CHARACTER*1
!>          = 'N':  no calcular los vectores propios generalizados izquierdos;
!>          = 'V':  calcular los vectores propios generalizados izquierdos.
!>

JOBVR

!>          JOBVR es CHARACTER*1
!>          = 'N':  no calcular los vectores propios generalizados derechos;
!>          = 'V':  calcular los vectores propios generalizados derechos.
!>

SENSE

!>          SENSE es CHARACTER*1
!>          Determina qué recíprocos de números de condición se calculan.
!>          = 'N': no se calcula ninguno;
!>          = 'E': se calcula solo para valores propios;
!>          = 'V': se calcula solo para vectores propios;
!>          = 'B': se calcula para valores propios y vectores propios.
!>

N

!>          N es INTEGER
!>          El orden de las matrices A, B, VL y VR. N >= 0.
!>

A

!>          A es un array COMPLEX*16, de dimensión (LDA, N)
!>          En la entrada, la matriz A en el par (A,B).
!>          En la salida, A ha sido sobrescrita. Si JOBVL='V' o JOBVR='V'
!>          o ambas, entonces A contiene la primera parte de la forma de Schur
!>          compleja de las versiones de entrada de A y B.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal de A. LDA >= max(1,N).
!>

B

!>          B es un array COMPLEX*16, de dimensión (LDB, N)
!>          En la entrada, la matriz B en el par (A,B).
!>          En la salida, B ha sido sobrescrita. Si JOBVL='V' o JOBVR='V'
!>          o ambas, entonces B contiene la segunda parte de la forma de Schur
!>          compleja de las versiones de entrada de A y B.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal de B. LDB >= max(1,N).
!>

ALPHA

!>          ALPHA es un array COMPLEX*16, de dimensión (N)
!>

BETA

!>          BETA es un array COMPLEX*16, de dimensión (N)
!>          En la salida, ALPHA(j)/BETA(j), j=1,...,N, serán los valores propios
!>          generalizados.
!>
!>          Nota: el cociente ALPHA(j)/BETA(j) puede desbordarse o subdesbordarse
!>          fácilmente, y BETA(j) puede incluso ser cero. Por lo tanto, el usuario
!>          debe evitar calcular ingenuamente el cociente ALPHA/BETA.
!>          Sin embargo, ALPHA será siempre menor y usualmente comparable
!>          con norm(A) en magnitud, y BETA siempre menor y usualmente comparable
!>          con norm(B).
!>

VL

!>          VL es un array COMPLEX*16, de dimensión (LDVL,N)
!>          Si JOBVL = 'V', los vectores propios generalizados izquierdos u(j) se
!>          almacenan uno tras otro en las columnas de VL, en el mismo
!>          orden que sus valores propios.
!>          Cada vector propio se escalará de modo que el componente más grande
!>          tenga abs(parte real) + abs(parte imaginaria) = 1.
!>          No referenciado si JOBVL = 'N'.
!>

LDVL

!>          LDVL es INTEGER
!>          La dimensión principal de la matriz VL. LDVL >= 1, y
!>          si JOBVL = 'V', LDVL >= N.
!>

VR

!>          VR es un array COMPLEX*16, de dimensión (LDVR,N)
!>          Si JOBVR = 'V', los vectores propios generalizados derechos v(j) se
!>          almacenan uno tras otro en las columnas de VR, en el mismo
!>          orden que sus valores propios.
!>          Cada vector propio se escalará de modo que el componente más grande
!>          tenga abs(parte real) + abs(parte imaginaria) = 1.
!>          No referenciado si JOBVR = 'N'.
!>

LDVR

!>          LDVR es INTEGER
!>          La dimensión principal de la matriz VR. LDVR >= 1, y
!>          si JOBVR = 'V', LDVR >= N.
!>

ILO

!>          ILO es INTEGER
!>

IHI

!>          IHI es INTEGER
!>          ILO e IHI son valores enteros tales que en la salida
!>          A(i,j) = 0 y B(i,j) = 0 si i > j y
!>          j = 1,...,ILO-1 o i = IHI+1,...,N.
!>          Si BALANC = 'N' o 'S', ILO = 1 e IHI = N.
!>

LSCALE

!>          LSCALE es un array DOUBLE PRECISION, de dimensión (N)
!>          Información sobre el escalado de la matriz A. En la salida,
!>          LSCALE(i) se usa para escalar la fila i de A si
!>          BALANC = 'S' o 'B'. La matriz diagonal de escalado D está
!>          formada por LSCALE(i).
!>

RSCALE

!>          RSCALE es un array DOUBLE PRECISION, de dimensión (N)
!>          Información sobre el escalado de la matriz B. En la salida,
!>          RSCALE(i) se usa para escalar la columna i de B si
!>          BALANC = 'S' o 'B'. La matriz diagonal de escalado E está
!>          formada por RSCALE(i).
!>

ABNRM

!>          ABNRM es DOUBLE PRECISION
!>          La norma 1-MA de A si BALANC = 'S' o 'B'. De otra forma,
!>          ABNRM no está definida.
!>

BBNRM

!>          BBNRM es DOUBLE PRECISION
!>          La norma 1-MA de B si BALANC = 'S' o 'B'. De otra forma,
!>          BBNRM no está definida.
!>

RCONDE

!>          RCONDE es un array DOUBLE PRECISION, de dimensión (N)
!>          Si SENSE = 'E' o 'B', RCONDE(j) es el recíproco del número de
!>          condición del j-ésimo valor propio generalizado.
!>          RCONDE(j) = abs(beta(j)) / (norm(A, U) |beta(j)| + norm(B, U) |alpha(j)|)
!>          donde norm(A, U) y norm(B, U) son las normas de las matrices A y B
!>          (escaladas y/o permutadas) en la norma de unidad.
!>          En la salida, RCONDE(j) es 0 si el valor propio es ilimitado.
!>          No referenciado si SENSE = 'N' o 'V'.
!>

RCONDV

!>          RCONDV es un array DOUBLE PRECISION, de dimensión (N)
!>          Si SENSE = 'V' o 'B', RCONDV(j) es el recíproco del número de
!>          condición del j-ésimo vector propio generalizado derecho.
!>          No referenciado si SENSE = 'N' o 'E'.
!>

WORK

!>          WORK es un array COMPLEX*16, de dimensión (LWORK)
!>          En la salida, WORK(1) es el tamaño del bloque de trabajo óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK. Debe ser al menos el valor devuelto
!>          por ZGEBAL, ZGGEHV, y ZGGEVX.
!>          Si LWORK = -1, entonces el tamaño óptimo se calcula y se almacena
!>          en WORK(1) y se devuelve un código de error.
!>

RWORK

!>          RWORK es un array DOUBLE PRECISION, de dimensión (N)
!>

IWORK

!>          IWORK es un array INTEGER, de dimensión (N)
!>          Si JOBVL='V' o JOBVR='V', IWORK se usa para almacenar los índices
!>          de los elementos de los vectores propios (para la optimización
!>          del cálculo de los vectores propios).
!>

BWORK

!>          BWORK es un array LOGICAL, de dimensión (N)
!>          Si JOBVL='V' o JOBVR='V', BWORK se usa internamente para
!>          la manipulación de los bloques de Schur.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  triunfo
!>          < 0:  si INFO = -i, la i-ésima argumento inválido
!>          > 0:  si INFO = i, el i-ésimo algoritmo de subrutina de convergencia
!>               para el valor propio i falló en converger. Los valores propios
!>               (y vectores propios) no están definidos.
!>

NAME

zggevx - This subroutine computes the generalized eigenvalues and, optionally, the left and right generalized eigenvectors for a pair of complex-conjugate matrices A and B.

SYNOPSIS

       SUBROUTINE ZGGEVX( JOBVL, JOBVR, SENSE, N, A, LDA, B, LDB,
                          ALPHA, BETA, VL, LDVL, VR, LDVR, PL, PR,
                          LSCALE, RSCALE, ABNRM, BBNRM, RCONDE, RCONDV,
                          WORK, LWORK, RWORK, IWORK, BWORK, INFO )
      
      CHARACTER * 1          JOBVL, JOBVR, SENSE
      INTEGER                N, LDA, LDB, LDVL, LDVR, LWORK
      COMPLEX*16             A( LDA, * ), B( LDB, * ), VL( LDVL, * ),
                             VR( LDVR, * ), WORK( * )
      DOUBLE PRECISION       ALPHA( * ), BETA( * ), PL( * ), PR( * ),
                             LSCALE( * ), RSCALE( * ), ABNRM, BBNRM,
                             RCONDE( * ), RCONDV( * ), RWORK( * )
      INTEGER                IWORK( * )
      LOGICAL                BWORK( * )

Function/Subroutine Documentation

JOBVL

!>          JOBVL is CHARACTER*1
!>          = 'N': left generalized eigenvectors are not computed.
!>          = 'V': left generalized eigenvectors are computed.
!>

JOBVR

!>          JOBVR is CHARACTER*1
!>          = 'N': right generalized eigenvectors are not computed.
!>          = 'V': right generalized eigenvectors are computed.
!>

SENSE

!>          SENSE is CHARACTER*1
!>          = 'N': none of the reciprocal condition numbers is computed.
!>          = 'E': only the reciprocal condition numbers of the eigenvalues may be computed.
!>          = 'V': only the reciprocal condition numbers of the eigenvectors may be computed.
!>          = 'B': both the reciprocal condition numbers of the eigenvalues and the eigenvectors may be computed.
!>

N

!>          N is INTEGER
!>          The order of the matrices A and B. N >= 0.
!>

A

!>          A is COMPLEX*16 array, dimension (LDA, * )
!>          On entry, the upper triangular part of matrix A in the
!>          N x N upper triangular band matrix.
!>          On exit, A is destroyed.
!>

LDA

!>          LDA is INTEGER
!>          The leading dimension of A. LDA >= max(1,N).
!>

B

!>          B is COMPLEX*16 array, dimension (LDB, * )
!>          On entry, the upper triangular part of matrix B in the
!>          N x N upper triangular band matrix.
!>          On exit, B is destroyed.
!>

LDB

!>          LDB is INTEGER
!>          The leading dimension of B. LDB >= max(1,N).
!>

ALPHA

!>          ALPHA is DOUBLE PRECISION array, dimension (N)
!>          BETA is DOUBLE PRECISION array, dimension (N)
!>          On exit, ALPHA(i) and BETA(i) are the eigenvalues such
!>          that the generalized eigenvalues are computed as the ratios
!>          ALPHA(i) / BETA(i).
!>          The eigenvalues are not normalized.
!>

VL

!>          VL is COMPLEX*16 array, dimension (LDVL, *)
!>          If JOBVL = 'V', VL contains the left generalized eigenvectors,
!>          with the i-th eigenvector VL(i) in the i-th column of VL.
!>

LDVL

!>          LDVL is INTEGER
!>          The leading dimension of the array VL. LDVL >= N.
!>

VR

!>          VR is COMPLEX*16 array, dimension (LDVR, *)
!>          If JOBVR = 'V', VR contains the right generalized eigenvectors,
!>          with the i-th eigenvector VR(i) in the i-th column of VR.
!>

LDVR

!>          LDVR is INTEGER
!>          The leading dimension of the array VR. LDVR >= N.
!>

PL

!>          PL is DOUBLE PRECISION array, dimension (N)
!>          PR is DOUBLE PRECISION array, dimension (N)
!>          Details of the permutations and scaling factors applied
!>          to the left side of A and B.  If PL(j) is the index of the
!>          row interchanged with row j, and DL(j) is the scaling
!>          factor applied to row j, then
!>            PL(j) = DL(j)  for j = 1,...,ILO-1
!>                  = -DL(j) for j = ILO,...,IHI
!>                  = DL(j)  for j = IHI+1,...,N.
!>          The order in which the interchanges are made is N to IHI+1,
!>          then 1 to ILO-1.
!>

LSCALE

!>          LSCALE is DOUBLE PRECISION array, dimension (N)
!>          Details of the permutations and scaling factors applied
!>          to the left side of A and B.  If PL(j) is the index of the
!>          row interchanged with row j, and DL(j) is the scaling
!>          factor applied to row j, then
!>            LSCALE(j) = PL(j)  for j = 1,...,ILO-1
!>                      = DL(j)  for j = ILO,...,IHI
!>                      = PL(j)  for j = IHI+1,...,N.
!>          The order in which the interchanges are made is N to IHI+1,
!>          then 1 to ILO-1.
!>

RSCALE

!>          RSCALE is DOUBLE PRECISION array, dimension (N)
!>          Details of the permutations and scaling factors applied
!>          to the right side of A and B.  If PR(j) is the index of the
!>          column interchanged with column j, and DR(j) is the scaling
!>          factor applied to column j, then
!>            RSCALE(j) = PR(j)  for j = 1,...,ILO-1
!>                      = DR(j)  for j = ILO,...,IHI
!>                      = PR(j)  for j = IHI+1,...,N
!>          The order in which the interchanges are made is N to IHI+1,
!>          then 1 to ILO-1.
!>

ABNRM

!>          ABNRM is DOUBLE PRECISION
!>          The one-norm of the balanced matrix A.
!>

BBNRM

!>          BBNRM is DOUBLE PRECISION
!>          The one-norm of the balanced matrix B.
!>

RCONDE

!>          RCONDE is DOUBLE PRECISION array, dimension (N)
!>          If SENSE = 'E' or 'B', the reciprocal condition numbers of
!>          the eigenvalues, stored in consecutive elements of the array.
!>          If SENSE = 'N' or 'V', RCONDE is not referenced.
!>

RCONDV

!>          RCONDV is DOUBLE PRECISION array, dimension (N)
!>          If JOB = 'V' or 'B', the estimated reciprocal condition
!>          numbers of the eigenvectors, stored in consecutive elements
!>          of the array. If the eigenvalues cannot be reordered to
!>          compute RCONDV(j), RCONDV(j) is set to 0; this can only occur
!>          when the true value would be very small anyway.
!>          If SENSE = 'N' or 'E', RCONDV is not referenced.
!>

WORK

!>          WORK is COMPLEX*16 array, dimension (MAX(1,LWORK))
!>          On exit, if INFO = 0, WORK(1) returns the optimal LWORK.
!>

LWORK

!>          LWORK is INTEGER
!>          The dimension of the array WORK. LWORK >= max(1,2*N).
!>          If SENSE = 'E', LWORK >= max(1,4*N).
!>          If SENSE = 'V' or 'B', LWORK >= max(1,2*N*N+2*N).
!>
!>          If LWORK = -1, then a workspace query is assumed; the routine
!>          only calculates the optimal size of the WORK array, returns
!>          this value as the first entry of the WORK array, and no error
!>          message related to LWORK is issued by XERBLA.
!>

RWORK

!>          RWORK is DOUBLE PRECISION array, dimension (lrwork)
!>          lrwork must be at least max(1,6*N) if BALANC = 'S' or 'B',
!>          and at least max(1,2*N) otherwise.
!>          Real workspace.
!>

IWORK

!>          IWORK is INTEGER array, dimension (N+2)
!>          If SENSE = 'E', IWORK is not referenced.
!>

BWORK

!>          BWORK is LOGICAL array, dimension (N)
!>          If SENSE = 'N', BWORK is not referenced.
!>

INFO

!>          INFO is INTEGER
!>          = 0:  successful exit
!>          < 0:  if INFO = -i, the i-th argument had an illegal value.
!>          = 1,...,N:
!>                The QZ iteration failed.  No eigenvectors have been
!>                calculated, but ALPHA(j) and BETA(j) should be correct
!>                for j=INFO+1,...,N.
!>          > N:  =N+1: other than QZ iteration failed in ZHGEQZ.
!>                =N+2: error return from ZTGEVC.
!>

Further Details:

!>
!>  Balancing a matrix pair (A,B) includes, first, permuting rows and
!>  columns to isolate eigenvalues, second, applying diagonal similarity
!>  transformation to the rows and columns to make the rows and columns
!>  as close in norm as possible. The computed reciprocal condition
!>  numbers correspond to the balanced matrix. Permuting rows and columns
!>  will not change the condition numbers (in exact arithmetic) but
!>  diagonal scaling will.  For further explanation of balancing, see
!>  section 4.11.1.2 of LAPACK Users' Guide.
!>
!>  An approximate error bound on the chordal distance between the i-th
!>  computed generalized eigenvalue w and the corresponding exact
!>  eigenvalue lambda is
!>
!>       chord(w, lambda) <= EPS * norm(ABNRM, BBNRM) / RCONDE(I)
!>
!>  An approximate error bound for the angle between the i-th computed
!>  eigenvector VL(i) or VR(i) is given by
!>
!>       EPS * norm(ABNRM, BBNRM) / DIF(i).
!>
!>  For further explanation of the reciprocal condition numbers RCONDE
!>  and RCONDV, see section 4.11 of LAPACK User's Guide.
!>
