Documentación de Función/Subrutina

subrutina zget51 (integer itype, integer n, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( ldb, * ) b, integer ldb, complex*16, dimension( ldu, * ) u, integer ldu, complex*16, dimension( ldv, * ) v, integer ldv, complex*16, dimension( * ) work, double precision, dimension( * ) rwork, double precision result)

ZGET51

Propósito:

!>
!>      ZGET51  generalmente comprueba una descomposición de la forma
!>
!>              A = U B V**H
!>
!>      donde **H significa transpuesta conjugada y U y V son unitarias.
!>
!>      Específicamente, si ITYPE=1
!>
!>              RESULT = | A - U B V**H | / ( |A| n ulp )
!>
!>      Si ITYPE=2, entonces:
!>
!>              RESULT = | A - B | / ( |A| n ulp )
!>
!>      Si ITYPE=3, entonces:
!>
!>              RESULT = | I - U U**H | / ( n ulp )
!>

Parámetros

ITYPE 
!>          ITYPE es INTEGER
!>          Especifica el tipo de pruebas a realizar.
!>          =1: RESULT = | A - U B V**H | / ( |A| n ulp )
!>          =2: RESULT = | A - B | / ( |A| n ulp )
!>          =3: RESULT = | I - U U**H | / ( n ulp )
!>

N

!>          N es INTEGER
!>          El tamaño de la matriz. Si es cero, ZGET51 no hace nada.
!>          Debe ser al menos cero.
!>

A

!>          A es un array COMPLEX*16, dimension (LDA, N)
!>          La matriz original (no factorizada).
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal de A. Debe ser al menos 1
!>          y al menos N.
!>

B

!>          B es un array COMPLEX*16, dimension (LDB, N)
!>          La matriz factorizada.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal de B. Debe ser al menos 1
!>          y al menos N.
!>

U

!>          U es un array COMPLEX*16, dimension (LDU, N)
!>          La matriz unitaria en el lado izquierdo de la
!>          descomposición.
!>          No se referencia si ITYPE=2
!>

LDU

!>          LDU es INTEGER
!>          La dimensión principal de U. LDU debe ser al menos N y
!>          al menos 1.
!>

V

!>          V es un array COMPLEX*16, dimension (LDV, N)
!>          La matriz unitaria en el lado izquierdo de la
!>          descomposición.
!>          No se referencia si ITYPE=2
!>

LDV

!>          LDV es INTEGER
!>          La dimensión principal de V. LDV debe ser al menos N y
!>          al menos 1.
!>

WORK

!>          WORK es un array COMPLEX*16, dimension (2*N**2)
!>

RWORK

!>          RWORK es un array DOUBLE PRECISION, dimension (N)
!>

RESULT

!>          RESULT es DOUBLE PRECISION
!>          Los valores calculados por la prueba especificada por ITYPE. El
!>          valor está actualmente limitado a 1/ulp, para evitar desbordamiento.
!>          Los errores se marcan con RESULT=10/ulp.
!>
