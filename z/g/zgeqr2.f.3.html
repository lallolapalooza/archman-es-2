DOCUMENTACIÓN DE FUNCIÓN/SUBRUTINA

subrutina zgeqr2 (integer m, integer n, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( * ) tau, complex*16, dimension( * ) work, integer info)

ZGEQR2 calcula la factorización QR de una matriz rectangular general utilizando un algoritmo sin bloqueo.

Propósito:

!>
!> ZGEQR2 calcula una factorización QR de una matriz compleja m por n A:
!>
!>    A = Q * ( R ),
!>            ( 0 )
!>
!> donde:
!>
!>    Q es una matriz ortogonal m por m;
!>    R es una matriz triangular superior n por n;
!>    0 es una matriz cero (m-n) por n, si m > n.
!>
!>

Parámetros

M 
!>          M es INTEGER
!>          El número de filas de la matriz A.  M >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz A.  N >= 0.
!>

A

!>          A es un array COMPLEX*16, de dimensión (LDA,N)
!>          En la entrada, la matriz m por n A.
!>          En la salida, los elementos en y sobre la diagonal del array
!>          contienen la matriz trapezoidal superior R de dimensión min(m,n) por n
!>          (R es triangular superior si m >= n); los elementos debajo de la
!>          diagonal, junto con el array TAU, representan la matriz unitaria Q
!>          como un producto de reflectores elementales (ver Detalles adicionales).
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,M).
!>

TAU

!>          TAU es un array COMPLEX*16, de dimensión (min(M,N))
!>          Los factores escalares de los reflectores elementales (ver Detalles
!>          adicionales).
!>

WORK

!>          WORK es un array COMPLEX*16, de dimensión (N)
!>

INFO

!>          INFO es INTEGER
!>          = 0: salida exitosa
!>          < 0: si INFO = -i, el argumento i-ésimo tuvo un valor ilegal
!>

Autor

Universidad de Tennessee

Universidad de California Berkeley

Universidad de Colorado Denver

NAG Ltd.

Detalles adicionales:

!>
!> La matriz Q se representa como un producto de reflectores elementales
!>
!>    Q = H(1) H(2) . . . H(k), donde k = min(m,n).
!>
!> Cada H(i) tiene la forma
!>
!>    H(i) = I - tau * v * v**H
!>
!> donde tau es un escalar complejo, y v es un vector complejo con
!> v(1:i-1) = 0 y v(i) = 1; v(i+1:m) se almacena en la salida en A(i+1:m,i),
!> y tau en TAU(i).
!>
