Documentación de la función/subrutina

subroutine zgelsx (integer m, integer n, integer nrhs, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( ldb, * ) b, integer ldb, integer, dimension( * ) jpvt, double precision rcond, integer rank, complex*16, dimension( * ) work, double precision, dimension( * ) rwork, integer info)

ZGELSX resuelve sistemas sobredeterminados o subdeterminados para matrices GE

Propósito:

!>
!> Esta rutina está obsoleta y ha sido reemplazada por la rutina ZGELSY.
!>
!> ZGELSX calcula la solución de norma mínima para un problema de mínimos
!> cuadrados lineales complejos:
!>     minimizar || A * X - B ||
!> utilizando una factorización ortogonal completa de A. A es una matriz M-por-N
!> que puede ser de rango deficiente.
!>
!> Se pueden manejar varios vectores del lado derecho b y vectores solución x
!> en una sola llamada; se almacenan como las columnas de la matriz B del lado
!> derecho M-por-NRHS y la matriz solución X de N-por-NRHS.
!>
!> La rutina primero calcula una factorización QR con pivoteo de columnas:
!>     A * P = Q * [ R11 R12 ]
!>                 [  0  R22 ]
!> con R11 definido como la submatriz principal más grande cuya condición estimada
!> es menor que 1/RCOND. El orden de R11, RANK,
!> es el rango efectivo de A.
!>
!> Entonces, R22 se considera insignificante, y R12 se aniquila
!> mediante transformaciones unitarias desde la derecha, llegando a la
!> factorización ortogonal completa:
!>    A * P = Q * [ T11 0 ] * Z
!>                [  0  0 ]
!> La solución de norma mínima es entonces
!>    X = P * Z**H [ inv(T11)*Q1**H*B ]
!>                 [        0         ]
!> donde Q1 consta de las primeras RANK columnas de Q.
!>

Parámetros

M 
!>          M es INTEGER
!>          El número de filas de la matriz A.  M >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz A.  N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de lados derechos, es decir, el número de
!>          columnas de las matrices B y X. NRHS >= 0.
!>

A

!>          A es un array COMPLEX*16, dimensión (LDA,N)
!>          En la entrada, la matriz M-por-N A.
!>          En la salida, A ha sido sobrescrito con detalles de su
!>          factorización ortogonal completa.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,M).
!>

B

!>          B es un array COMPLEX*16, dimensión (LDB,NRHS)
!>          En la entrada, la matriz del lado derecho M-por-NRHS B.
!>          En la salida, la matriz solución N-por-NRHS X.
!>          Si m >= n y RANK = n, la suma residual de cuadrados para
!>          la solución en la i-ésima columna se da como la suma de
!>          cuadrados de los elementos N+1:M en esa columna.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B. LDB >= max(1,M,N).
!>

JPVT

!>          JPVT es un array INTEGER, dimensión (N)
!>          En la entrada, si JPVT(i) .ne. 0, la i-ésima columna de A es una
!>          columna inicial, de lo contrario es una columna libre. Antes
!>          de la factorización QR de A, todas las columnas iniciales se
!>          permutan a las posiciones principales; solo las columnas libres
!>          restantes se mueven como resultado del pivoteo de columnas
!>          durante la factorización.
!>          En la salida, si JPVT(i) = k, entonces la i-ésima columna de A*P
!>          fue la k-ésima columna de A.
!>

RCOND

!>          RCOND es DOUBLE PRECISION
!>          RCOND se utiliza para determinar el rango efectivo de A, que
!>          se define como el orden de la submatriz triangular principal
!>          más grande R11 en la factorización QR con pivoteo de A,
!>          cuya condición estimada es < 1/RCOND.
!>

RANK

!>          RANK es INTEGER
!>          El rango efectivo de A, es decir, el orden de la submatriz
!>          R11. Esto es lo mismo que el orden de la submatriz T11
!>          en la factorización ortogonal completa de A.
!>

WORK

!>          WORK es un array COMPLEX*16, dimensión
!>                      (min(M,N) + max( N, 2*min(M,N)+NRHS )),
!>

RWORK

!>          RWORK es un array DOUBLE PRECISION, dimensión (2*N)
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>
