Documentación de Función/Subrutina

subroutine zgecon (character norm, integer n, complex*16, dimension( lda, * ) a, integer lda, double precision anorm, double precision rcond, complex*16, dimension( * ) work, double precision, dimension( * ) rwork, integer info)

ZGECON

Propósito:

!>
!> ZGECON estima el recíproco del número de condición de una matriz compleja general A,
!> en la norma 1 o en la norma infinito, utilizando la factorización LU calculada por ZGETRF.
!>
!> Se obtiene una estimación para norm(inv(A)), y el recíproco del número de condición
!> se calcula como
!>    RCOND = 1 / ( norm(A) * norm(inv(A)) ).
!>

Parámetros

NORM 
!>          NORM es CHARACTER*1
!>          Especifica si se requiere el número de condición en norma 1 o en norma
!>          infinito:
!>          = '1' o 'O':  norma 1;
!>          = 'I':         norma infinito.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

A

!>          A es un array COMPLEX*16, dimension (LDA,N)
!>          Los factores L y U de la factorización A = P*L*U
!>          tal como se calculan por ZGETRF.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

ANORM

!>          ANORM es DOUBLE PRECISION
!>          Si NORM = '1' o 'O', la norma 1 de la matriz original A.
!>          Si NORM = 'I', la norma infinito de la matriz original A.
!>

RCOND

!>          RCOND es DOUBLE PRECISION
!>          El recíproco del número de condición de la matriz A,
!>          calculado como RCOND = 1/(norm(A) * norm(inv(A))).
!>

WORK

!>          WORK es un array COMPLEX*16, dimension (2*N)
!>

RWORK

!>          RWORK es un array DOUBLE PRECISION, dimension (2*N)
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>                Los NaN son valores ilegales para ANORM, y se propagan al
!>                parámetro de salida RCOND.
!>                El infinito es ilegal para ANORM, y se propaga al parámetro
!>                de salida RCOND como 0.
!>          = 1:  si RCOND = NaN, o
!>                   RCOND = Inf, o
!>                   la norma calculada de la inversa de A es 0.
!>                En este último caso, se devuelve RCOND = 0.
!>
