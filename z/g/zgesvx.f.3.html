subroutine zgesvx (character fact, character trans, integer n, integer nrhs, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( ldaf, * ) af, integer ldaf, integer, dimension( * ) ipiv, character equed, double precision, dimension( * ) r, double precision, dimension( * ) c, complex*16, dimension( ldb, * ) b, integer ldb, complex*16, dimension( ldx, * ) x, integer ldx, double precision rcond, double precision, dimension( * ) ferr, double precision, dimension( * ) berr, complex*16, dimension( * ) work, double precision, dimension( * ) rwork, integer info)

ZGESVX calcula la solución al sistema de ecuaciones lineales A * X = B para matrices GE

Propósito:

!>
!> ZGESVX utiliza la factorización LU para calcular la solución de un sistema
!> lineal complejo de ecuaciones
!>    A * X = B,
!> donde A es una matriz N-por-N y X y B son matrices N-por-NRHS.
!>
!> También se proporcionan cotas de error sobre la solución y una estimación
!> de la condición.
!>

Descripción:

!>
!> Se realizan los siguientes pasos:
!>
!> 1. Si FACT = 'E', se calculan factores de escala reales para equilibrar
!>    el sistema:
!>       TRANS = 'N':  diag(R)*A*diag(C)     *inv(diag(C))*X = diag(R)*B
!>       TRANS = 'T': (diag(R)*A*diag(C))**T *inv(diag(R))*X = diag(C)*B
!>       TRANS = 'C': (diag(R)*A*diag(C))**H *inv(diag(R))*X = diag(C)*B
!>    Si el sistema se equilibrará o no depende del escalado de la matriz A,
!>    pero si se utiliza el equilibrado, A se sobrescribe con
!>    diag(R)*A*diag(C) y B con diag(R)*B (si TRANS='N')
!>    o diag(C)*B (si TRANS = 'T' o 'C').
!>
!> 2. Si FACT = 'N' o 'E', se utiliza la descomposición LU para factorizar
!>    la matriz A (después del equilibrado si FACT = 'E') como
!>       A = P * L * U,
!>    donde P es una matriz de permutación, L es una matriz triangular inferior
!>    unitaria y U es triangular superior.
!>
!> 3. Si algún U(i,i)=0, de modo que U sea exactamente singular, la rutina
!>    devuelve INFO = i. De lo contrario, la forma factorizada de A se usa
!>    para estimar el número de condición de la matriz A. Si el
!>    recíproco del número de condición es menor que la precisión de la máquina,
!>    se devuelve INFO = N+1 como advertencia, pero la rutina aún continúa
!>    resolviendo para X y calculando cotas de error como se describe a
!>    continuación.
!>
!> 4. El sistema de ecuaciones se resuelve para X utilizando la forma
!>    factorizada de A.
!>
!> 5. Se aplica refinamiento iterativo para mejorar la solución calculada
!>    y calcular cotas de error y estimaciones de error hacia atrás
!>    para la misma.
!>
!> 6. Si se utilizó el equilibrado, la matriz X se premultiplica por
!>    diag(C) (si TRANS = 'N') o diag(R) (si TRANS = 'T' o 'C') para
!>    que resuelva el sistema original antes del equilibrado.
!>

Parámetros

FACT 
!>          FACT es CHARACTER*1
!>          Especifica si la forma factorizada de la matriz A se
!>          proporciona en la entrada, y si no, si la matriz A debe ser
!>          equilibrada antes de ser factorizada.
!>          = 'F':  En la entrada, AF e IPIV contienen la forma factorizada de A.
!>                  Si EQUED no es 'N', la matriz A ha sido
!>                  equilibrada con los factores de escala dados por R y C.
!>                  A, AF e IPIV no se modifican.
!>          = 'N':  La matriz A se copiará en AF y se factorizará.
!>          = 'E':  La matriz A se equilibrará si es necesario, luego
!>                  se copiará en AF y se factorizará.
!>

TRANS

!>          TRANS es CHARACTER*1
!>          Especifica la forma del sistema de ecuaciones:
!>          = 'N':  A * X = B     (Sin transpuesta)
!>          = 'T':  A**T * X = B  (Transpuesta)
!>          = 'C':  A**H * X = B  (Transpuesta conjugada)
!>

N

!>          N es INTEGER
!>          El número de ecuaciones lineales, es decir, el orden de
!>          la matriz A.  N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de lados derechos, es decir, el número de columnas
!>          de las matrices B y X.  NRHS >= 0.
!>

A

!>          A es un array COMPLEX*16, dimensión (LDA,N)
!>          En la entrada, la matriz N-por-N A. Si FACT = 'F' y EQUED
!>          no es 'N', entonces A ha sido equilibrada por los
!>          factores de escala en R y/o C.
!>          A no se modifica si FACT = 'F' o
!>          'N', o si FACT = 'E' y EQUED = 'N' en la salida.
!>
!>          En la salida, si EQUED .ne. 'N', A se escala de la siguiente manera:
!>          EQUED = 'R':  A := diag(R) * A
!>          EQUED = 'C':  A := A * diag(C)
!>          EQUED = 'B':  A := diag(R) * A * diag(C).
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

AF

!>          AF es un array COMPLEX*16, dimensión (LDAF,N)
!>          Si FACT = 'F', entonces AF es un argumento de entrada y en la entrada
!>          contiene los factores L y U de la factorización
!>          A = P*L*U calculada por ZGETRF. Si EQUED .ne. 'N', entonces
!>          AF es la forma factorizada de la matriz equilibrada A.
!>
!>          Si FACT = 'N', entonces AF es un argumento de salida y en la salida
!>          devuelve los factores L y U de la factorización A = P*L*U
!>          de la matriz original A.
!>
!>          Si FACT = 'E', entonces AF es un argumento de salida y en la salida
!>          devuelve los factores L y U de la factorización A = P*L*U
!>          de la matriz equilibrada A (ver la descripción de A para
!>          la forma de la matriz equilibrada).
!>

LDAF

!>          LDAF es INTEGER
!>          La dimensión principal del array AF.  LDAF >= max(1,N).
!>

IPIV

!>          IPIV es un array INTEGER, dimensión (N)
!>          Si FACT = 'F', entonces IPIV es un argumento de entrada y en la entrada
!>          contiene los índices de pivote de la factorización A = P*L*U
!>          calculada por ZGETRF; la fila i de la matriz fue intercambiada
!>          con la fila IPIV(i).
!>
!>          Si FACT = 'N', entonces IPIV es un argumento de salida y en la salida
!>          contiene los índices de pivote de la factorización A = P*L*U
!>          de la matriz original A.
!>
!>          Si FACT = 'E', entonces IPIV es un argumento de salida y en la salida
!>          contiene los índices de pivote de la factorización A = P*L*U
!>          de la matriz equilibrada A.
!>

EQUED

!>          EQUED es CHARACTER*1
!>          Especifica la forma de equilibrado que se realizó.
!>          = 'N':  Sin equilibrado (siempre verdadero si FACT = 'N').
!>          = 'R':  Equilibrado de filas, es decir, A se ha premultiplicado por
!>                  diag(R).
!>          = 'C':  Equilibrado de columnas, es decir, A se ha postmultiplicado
!>                  por diag(C).
!>          = 'B':  Equilibrado de filas y columnas, es decir, A ha sido
!>                  reemplazado por diag(R) * A * diag(C).
!>          EQUED es un argumento de entrada si FACT = 'F'; de lo contrario, es un
!>          argumento de salida.
!>

R

!>          R es un array de PRECISIÓN DOBLE, dimensión (N)
!>          Si EQUED = 'R' o 'B', R contiene los factores de escala de fila
!>          utilizados para equilibrar la matriz A.
!>          Si FACT = 'F', R es un argumento de entrada.
!>          Si FACT = 'E', R es un argumento de salida.
!>

C

!>          C es un array de PRECISIÓN DOBLE, dimensión (N)
!>          Si EQUED = 'C' o 'B', C contiene los factores de escala de columna
!>          utilizados para equilibrar la matriz A.
!>          Si FACT = 'F', C es un argumento de entrada.
!>          Si FACT = 'E', C es un argumento de salida.
!>

B

!>          B es un array COMPLEX*16, dimensión (LDB,NRHS)
!>          En la entrada, la matriz N-por-NRHS del lado derecho.
!>          En la salida, B se modifica si el equilibrado de filas se realiza
!>          con FACT = 'E', es decir, si EQUED = 'R' o 'B'. El sistema se resuelve
!>          para X, que se calcula en la salida.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal de la matriz B. LDB >= max(1,N).
!>

X

!>          X es un array COMPLEX*16, dimensión (LDX,NRHS)
!>          En la salida, la solución de N-por-NRHS al sistema de ecuaciones.
!>          Se ignora si NRHS = 0.
!>

LDX

!>          LDX es INTEGER
!>          La dimensión principal de la matriz X. LDX >= max(1,N).
!>

RCOND

!>          RCOND es DOUBLE PRECISION
!>          El recíproco estimado del número de condición de la matriz.
!>          Se utiliza para estimar las cotas de error.
!>

FERR

!>          FERR es DOUBLE PRECISION, dimensión (NRHS)
!>          El error de adelante estimado para cada columna de B.
!>          FERR(j) está en la escala relativa a la norma de la solución
!>          correspondiente.
!>

BERR

!>          BERR es DOUBLE PRECISION, dimensión (NRHS)
!>          El error de atrás estimado para cada columna de B.
!>          BERR(j) está en la escala relativa a la norma de la solución
!>          correspondiente.
!>

WORK

!>          WORK es COMPLEX*16 array, dimensión (MAX(2*N,LRWORK))
!>          En la salida, WORK(1) contiene el tamaño mínimo requerido
!>          para el array WORK si LRWORK >= 2*N.
!>

RWORK

!>          RWORK es DOUBLE PRECISION array, dimensión (MAX(N,LRWORK))
!>          En la salida, RWORK(1) contiene el tamaño mínimo requerido
!>          para el array RWORK si LRWORK >= N.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  Ejecución correcta.
!>          < 0:  Si INFO = -i, la i-ésima entrada del argumento era inválida.
!>                Se garantiza que INFO = -i, donde |i| >= 1.
!>          > 0:  Si INFO = i, entonces U(i,i) es cero y la matriz está singular.
!>                La factorización ha sido completada, pero no se puede continuar.
!>                El rango de la matriz es < N.
!>          = N+1: La matriz está casi singular.  RCOND es menor que la
!>                 precisión de la máquina. La solución y las cotas de error
!>                 se calculan, pero pueden ser poco fiables.
!>

INTEL WASP Team

NAME

zgesvx - The subroutine zgesvx uses the full Z LU factorization to solve the complex general linear system of linear equations A * X = B, and provides estimates for the accuracy of the computed solution, and if the matrix A is singular.

SYNOPSIS

SUBROUTINE ZGESVX(
   FACT, JOBZ, TRANS, EQUED, N, NRHS,
   A, LDA, AF, LDAF, IPIV,
   B, LDB, X, LDX, RCOND, FERR, BERR,
   WORK, RWORK, INFO )

Parameters

FACT
CHARACTER*1. FACT specifies the specific subprograms to be used. Last-in, First-out (LIFO) stack, last-in, first-out (LIFO) stack, last-in, first-out (LIFO) stack, last-in, first-out (LIFO) stack.
JOBZ
CHARACTER*1. Specifies whether to compute an estimate of the reciprocal condition number of the matrix. 'N': Compute the reciprocal condition number without computing the error bounds.
TRANS
CHARACTER*1. Specifies the form of the system of equations. 'N': Do not transpose the matrix A. 'T': Transpose the matrix A. 'C': Conjugate transpose the matrix A.
EQUED
CHARACTER*1. Specifies the form of equilibration computed by the users. 'N': No equilibration. 'R': Row equilibration was performed, i.e. A was replaced by diag(R)*A, which is equilibrated. 'C': Column equilibration was performed, i.e. A was replaced by A*diag(C), which is equilibrated. 'B': Both row and column equilibration were performed, i.e. A was replaced by diag(R)*A*diag(C). Equilibration is not specified by the user, and no scaling is done.
N
INTEGER. The order of the matrix A. N >= 0.
NRHS
INTEGER. The number of right hand sides, i.e. the number of columns of the matrices B and X. NRHS >= 0.
A
COMPLEX*16 array, dimension (LDA, N). On entry, the array A contains the matrix to be factorized. On exit, if FACT = 'F', the factorization A = P*L*U is stored in the entries of A, and all the moduli of the largest elements of each column of L are stored in R (if EQUED = 'R' or 'B'). If FACT = 'N', the LU factorization of A is in the array AF.
LDA
INTEGER. The leading dimension of the array A. LDA >= max(1, N).
AF
COMPLEX*16 array, dimension (LDAF, N). The LU factorization of A, as returned by ZGETRF. AF is used when FACT = 'F'. See the description of A above.
LDAF
INTEGER. The leading dimension of the array AF. LDAF >= max(1, N).
IPIV
INTEGER array, dimension (min(N+1, 6144)). The pivot indices from the LU factorization; for each column j, IPIV[j] denotes the row with the largest entry in column j, off and on or below the main diagonal. If IPIV[j] = k, then row j of the factor L is a permutation of the row k of the unit lower triangular factor L, so that P is the permutation matrix defined by IPIV. IPIV is an input argument if FACT = 'F'; otherwise, IPIV is an output argument.
B
COMPLEX*16 array, dimension (LDB, NRHS). On entry, the N-by-NRHS right hand side matrix B. On exit, if EQUED = 'N', B is not modified; if TRANS = 'N' and EQUED = 'R' or 'B', B is overwritten by diag(R)*B; if TRANS = 'T' or 'C' and EQUED = 'C' or 'B', B is overwritten by diag(C)*B.
LDB
INTEGER. The leading dimension of the array B. LDB >= max(1,N).
X
COMPLEX*16 array, dimension (LDX, NRHS). If INFO = 0 or INFO = N+1, the N-by-NRHS solution matrix X to the original system of equations. Note that A and B are modified on exit if EQUED .ne. 'N', and the solution to the equilibrated system is inv(diag(C))*X if TRANS = 'N' and EQUED = 'C' or 'B', or inv(diag(R))*X if TRANS = 'T' or 'C' and EQUED = 'R' or 'B'.
LDX
INTEGER. The leading dimension of the array X. LDX >= max(1,N).
RCOND
DOUBLE PRECISION. The estimate of the reciprocal condition number of the matrix A after equilibration (if done). If RCOND is less than the machine precision (in particular, if RCOND = 0), the matrix is singular to working precision. This condition is indicated by a return code of INFO > 0.
FERR
DOUBLE PRECISION array, dimension (NRHS). The estimated forward error bound for each solution vector X(j) (the j-th column of the solution matrix X). If XTRUE is the true solution corresponding to X(j), FERR(j) is an estimated upper bound for the magnitude of the largest element in (X(j) - XTRUE) divided by the magnitude of the largest element in X(j). The estimate is as reliable as the estimate for RCOND, and is almost always a slight overestimate of the true error.
BERR
DOUBLE PRECISION array, dimension (NRHS). The componentwise relative backward error of each solution vector X(j) (i.e., the smallest relative change in any element of A or B that makes X(j) an exact solution).
WORK
COMPLEX*16 array, dimension (2*N).
RWORK
DOUBLE PRECISION array, dimension (MAX(1,2*N)). On exit, RWORK(1) contains the reciprocal pivot growth factor norm(A)/norm(U). The norm is used. If RWORK(1) is much less than 1, then the stability of the LU factorization of the (equilibrated) matrix A could be poor. This also means that the solution X, condition estimator RCOND, and forward error bound FERR could be unreliable. If factorization fails with 0<INFO<=N, then RWORK(1) contains the reciprocal pivot growth factor for the leading INFO columns of A.
INFO
INTEGER. = 0: successful exit < 0: if INFO = -i, the i-th argument had an illegal value > 0: if INFO = i, and i is <= N: U(i,i) is exactly zero. The factorization has been completed, but the factor U is exactly singular, so the solution and error bounds could not be computed. RCOND = 0 is returned. = N+1: U is nonsingular, but RCOND is less than machine precision, meaning that the matrix is singular to working precision. Nevertheless, the solution and error bounds are computed because there are a number of situations where the computed solution can be more accurate than the value of RCOND would suggest.
