Documentación de Función/Subrutina

subrutina zgtt01 (integer n, complex*16, dimension( * ) dl, complex*16, dimension( * ) d, complex*16, dimension( * ) du, complex*16, dimension( * ) dlf, complex*16, dimension( * ) df, complex*16, dimension( * ) duf, complex*16, dimension( * ) du2, integer, dimension( * ) ipiv, complex*16, dimension( ldwork, * ) work, integer ldwork, double precision, dimension( * ) rwork, double precision resid)

ZGTT01

Propósito:

!>
!> ZGTT01 reconstruye una matriz tridiagonal A a partir de su factorización LU
!> y calcula el residuo
!>    norm(L*U - A) / ( norm(A) * EPS ),
!> donde EPS es la epsilon de la máquina.
!>

Parámetros

N 
!>          N es ENTERO
!>          El orden de la matriz A.  N >= 0.
!>

DL

!>          DL es un array COMPLEX*16, dimension (N-1)
!>          Los elementos subdiagonales (n-1) de A.
!>

D

!>          D es un array COMPLEX*16, dimension (N)
!>          Los elementos diagonales de A.
!>

DU

!>          DU es un array COMPLEX*16, dimension (N-1)
!>          Los elementos superdiagonales (n-1) de A.
!>

DLF

!>          DLF es un array COMPLEX*16, dimension (N-1)
!>          Los multiplicadores (n-1) que definen la matriz L a partir de la
!>          factorización LU de A.
!>

DF

!>          DF es un array COMPLEX*16, dimension (N)
!>          Los n elementos diagonales de la matriz triangular superior U de la
!>          factorización LU de A.
!>

DUF

!>          DUF es un array COMPLEX*16, dimension (N-1)
!>          Los elementos (n-1) de la primera superdiagonal de U.
!>

DU2

!>          DU2 es un array COMPLEX*16, dimension (N-2)
!>          Los elementos (n-2) de la segunda superdiagonal de U.
!>

IPIV

!>          IPIV es un array ENTERO, dimension (N)
!>          Los índices de pivote; para 1 <= i <= n, la fila i de la matriz se
!>          intercambió con la fila IPIV(i). IPIV(i) siempre será i o i+1;
!>          IPIV(i) = i indica que no se requirió un intercambio de fila.
!>

WORK

!>          WORK es un array COMPLEX*16, dimension (LDWORK,N)
!>

LDWORK

!>          LDWORK es ENTERO
!>          La dimensión principal del array WORK. LDWORK >= max(1,N).
!>

RWORK

!>          RWORK es un array DOUBLE PRECISION, dimension (N)
!>

RESID

!>          RESID es DOUBLE PRECISION
!>          El residuo escalado: norm(L*U - A) / (norm(A) * EPS)
!>
