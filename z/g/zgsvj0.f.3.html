Documentación de Función/Subrutina

subrutina zgsvj0 (character*1 jobv, integer m, integer n, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( n ) d, double precision, dimension( n ) sva, integer mv, complex*16, dimension( ldv, * ) v, integer ldv, double precision eps, double precision sfmin, double precision tol, integer nsweep, complex*16, dimension( lwork ) work, integer lwork, integer info)

ZGSVJ0 preprocesador para la rutina zgesvj.

Propósito:

!>
!> ZGSVJ0 es llamada desde ZGESVJ como preprocesador y ese es su propósito principal.
!> Aplica rotaciones de Jacobi de la misma manera que lo hace ZGESVJ, pero
!> no verifica la convergencia (criterio de parada). Hay pocos parámetros de ajuste
!> (marcados con [TP]) disponibles para el implementador.
!>

Parámetros

JOBV 
!>          JOBV es CHARACTER*1
!>          Especifica si la salida de este procedimiento se usa
!>          para calcular la matriz V:
!>          = 'V': el producto de las rotaciones de Jacobi se acumula
!>                 premultiplicando la matriz V de N por N.
!>                (Ver la descripción de V.)
!>          = 'A': el producto de las rotaciones de Jacobi se acumula
!>                 premultiplicando la matriz V de MV por N.
!>                (Ver las descripciones de MV y V.)
!>          = 'N': las rotaciones de Jacobi no se acumulan.
!>

M

!>          M es INTEGER
!>          El número de filas de la matriz de entrada A. M >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz de entrada A.
!>          M >= N >= 0.
!>

A

!>          A es un array COMPLEX*16, de dimensión (LDA,N)
!>          En la entrada, la matriz A de M por N, tal que A*diag(D) representa
!>          la matriz de entrada.
!>          En la salida,
!>          A_salida * diag(D_salida) representa la matriz de entrada A*diag(D)
!>          premultiplicada por una secuencia de rotaciones de Jacobi, donde el
!>          umbral de rotación y el número total de barridos se dan en
!>          TOL y NSWEEP, respectivamente.
!>          (Ver las descripciones de D, TOL y NSWEEP.)
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A. LDA >= max(1,M).
!>

D

!>          D es un array COMPLEX*16, de dimensión (N)
!>          El array D acumula los factores de escala de las rotaciones de Jacobi
!>          escaladas complejas.
!>          En la entrada, A*diag(D) representa la matriz de entrada.
!>          En la salida, A_salida*diag(D_salida) representa la matriz de entrada
!>          premultiplicada por una secuencia de rotaciones de Jacobi, donde el
!>          umbral de rotación y el número total de barridos se dan en
!>          TOL y NSWEEP, respectivamente.
!>          (Ver las descripciones de A, TOL y NSWEEP.)
!>

SVA

!>          SVA es un array DOUBLE PRECISION, de dimensión (N)
!>          En la entrada, SVA contiene las normas euclidianas de las columnas de
!>          la matriz A*diag(D).
!>          En la salida, SVA contiene las normas euclidianas de las columnas de
!>          la matriz A_salida*diag(D_salida).
!>

MV

!>          MV es INTEGER
!>          Si JOBV = 'A', entonces MV filas de V se multiplican
!>                           por una secuencia de rotaciones de Jacobi.
!>          Si JOBV = 'N',   entonces MV no se referencia.
!>

V

!>          V es un array COMPLEX*16, de dimensión (LDV,N)
!>          Si JOBV = 'V' entonces N filas de V se multiplican
!>                           por una secuencia de rotaciones de Jacobi.
!>          Si JOBV = 'A' entonces MV filas de V se multiplican
!>                           por una secuencia de rotaciones de Jacobi.
!>          Si JOBV = 'N',   entonces V no se referencia.
!>

LDV

!>          LDV es INTEGER
!>          La dimensión principal del array V, LDV >= 1.
!>          Si JOBV = 'V', LDV >= N.
!>          Si JOBV = 'A', LDV >= MV.
!>

EPS

!>          EPS es DOUBLE PRECISION
!>          EPS = DLAMCH('Epsilon')
!>

SFMIN

!>          SFMIN es DOUBLE PRECISION
!>          SFMIN = DLAMCH('Safe Minimum')
!>

TOL

!>          TOL es DOUBLE PRECISION
!>          TOL es el umbral para las rotaciones de Jacobi. Para un par
!>          A(:,p), A(:,q) de columnas pivote, la rotación de Jacobi se
!>          aplica solo si ABS(COS(angulo(A(:,p),A(:,q)))) > TOL.
!>

NSWEEP

!>          NSWEEP es INTEGER
!>          NSWEEP es el número de barridos de rotaciones de Jacobi a realizar.
!>

WORK

!>          WORK es un array COMPLEX*16, de dimensión (LWORK)
!>

LWORK

!>          LWORK es INTEGER
!>          LWORK es la dimensión de WORK. LWORK >= M.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa.
!>          < 0:  si INFO = -i, entonces el i-ésimo argumento tenía un valor ilegal.
!>

Detalles adicionales:
