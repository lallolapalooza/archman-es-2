ZGEGS calcula los valores propios, la forma de Schur y, opcionalmente, los vectores de Schur izquierdos y/o derechos de un par de matrices complejas (A,B)

Propósito:

!>
!> Esta rutina está obsoleta y ha sido reemplazada por la rutina ZGEES.
!>
!> ZGEGS calcula los valores propios, la forma de Schur y, opcionalmente, los
!> vectores de Schur izquierdos y/o derechos de un par de matrices complejas (A,B).
!> Dadas dos matrices cuadradas A y B, la factorización de Schur generalizada
!> tiene la forma
!>
!>    A = Q*S*Z**H,  B = Q*T*Z**H
!>
!> donde Q y Z son matrices unitarias y S y T son triangulares superiores.
!> Las columnas de Q son los vectores de Schur izquierdos
!> y las columnas de Z son los vectores de Schur derechos.
!>
!> Si solo se necesitan los valores propios de (A,B), se debe usar la rutina
!> controladora ZGEGV en su lugar. Ver ZGEGV para una descripción de los
!> valores propios del problema de valores propios generalizado no simétrico
!> (GNEP).
!>

Parámetros

JOBVSL 
!>          JOBVSL es CHARACTER*1
!>          = 'N':  no calcular los vectores de Schur izquierdos;
!>          = 'V':  calcular los vectores de Schur izquierdos (devueltos en VSL).
!>

JOBVSR

!>          JOBVSR es CHARACTER*1
!>          = 'N':  no calcular los vectores de Schur derechos;
!>          = 'V':  calcular los vectores de Schur derechos (devueltos en VSR).
!>

N

!>          N es INTEGER
!>          El orden de las matrices A, B, VSL y VSR.  N >= 0.
!>

A

!>          A es un array COMPLEX*16, de dimensión (LDA, N)
!>          En la entrada, la matriz A.
!>          En la salida, la matriz triangular superior S de la factorización de
!>          Schur generalizada.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal de A.  LDA >= max(1,N).
!>

B

!>          B es un array COMPLEX*16, de dimensión (LDB, N)
!>          En la entrada, la matriz B.
!>          En la salida, la matriz triangular superior T de la factorización de
!>          Schur generalizada.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal de B.  LDB >= max(1,N).
!>

ALPHA

!>          ALPHA es un array COMPLEX*16, de dimensión (N)
!>          Los escalares complejos alpha que definen los valores propios de
!>          GNEP.  ALPHA(j) = S(j,j), el elemento diagonal de la forma de
!>          Schur de A.
!>

BETA

!>          BETA es un array COMPLEX*16, de dimensión (N)
!>          Los escalares reales no negativos beta que definen los
!>          valores propios de GNEP.  BETA(j) = T(j,j), el elemento diagonal
!>          del factor triangular T.
!>
!>          En conjunto, las cantidades alpha = ALPHA(j) y beta = BETA(j)
!>          representan el j-ésimo valor propio del par de matrices (A,B), en
!>          una de las formas lambda = alpha/beta o mu = beta/alpha.
!>          Dado que lambda o mu pueden desbordarse, en general no deben
!>          calcularse.
!>

VSL

!>          VSL es un array COMPLEX*16, de dimensión (LDVSL,N)
!>          Si JOBVSL = 'V', la matriz de vectores de Schur izquierdos Q.
!>          No se referencia si JOBVSL = 'N'.
!>

LDVSL

!>          LDVSL es INTEGER
!>          La dimensión principal de la matriz VSL. LDVSL >= 1, y
!>          si JOBVSL = 'V', LDVSL >= N.
!>

VSR

!>          VSR es un array COMPLEX*16, de dimensión (LDVSR,N)
!>          Si JOBVSR = 'V', la matriz de vectores de Schur derechos Z.
!>          No se referencia si JOBVSR = 'N'.
!>

LDVSR

!>          LDVSR es INTEGER
!>          La dimensión principal de la matriz VSR. LDVSR >= 1, y
!>          si JOBVSR = 'V', LDVSR >= N.
!>

WORK

!>          WORK es un array COMPLEX*16, de dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK.  LWORK >= max(1,2*N).
!>          Para un buen rendimiento, LWORK debe ser generalmente mayor.
!>          Para calcular el valor óptimo de LWORK, llame a ILAENV para
!>          obtener los tamaños de bloque (para ZGEQRF, ZUNMQR y CUNGQR).
!>          Luego calcule:
!>          NB  -- MAX de los tamaños de bloque para ZGEQRF, ZUNMQR y CUNGQR;
!>          el LWORK óptimo es N*(NB+1).
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo;
!>          la rutina solo calcula el tamaño óptimo del array WORK, devuelve
!>          este valor como la primera entrada del array WORK y XERBLA no
!>          emite ningún mensaje de error relacionado con LWORK.
!>

RWORK

!>          RWORK es un array DOUBLE PRECISION, de dimensión (3*N)
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>          =1,...,N:
!>                La iteración QZ falló.  (A,B) no están en forma de Schur,
!>                pero ALPHA(j) y BETA(j) deberían ser correctos para
!>                j=INFO+1,...,N.
!>          > N:  errores que usualmente indican problemas de LAPACK:
!>                =N+1: retorno de error de ZGGBAL
!>                =N+2: retorno de error de ZGEQRF
!>                =N+3: retorno de error de ZUNMQR
!>                =N+4: retorno de error de ZUNGQR
!>                =N+5: retorno de error de ZGGHRD
!>                =N+6: retorno de error de ZHGEQZ (distinto de iteración fallida)
!>                =N+7: retorno de error de ZGGBAK (calculando VSL)
!>                =N+8: retorno de error de ZGGBAK (calculando VSR)
!>                =N+9: retorno de error de ZLASCL (varios lugares)
!>

NAME

zgegs - computes the generalized Schur decomposition of a complex non-symmetric matrix A and a complex upper triangular matrix B

SYNOPSIS

SUBROUTINE ZGEGS(
  JOBVSL, JOBVSR, N, A, LDA, B, LDB, ALPHA, BETA, VS, LDS, VSR, LDSR, WORK,
  LWORK, INFO)
CHARACTER * 1 JOBVSL, JOBVSR
INTEGER N, LDA, LDB, LDS, LDSR, LWORK, INFO
COMPLEX*16 A(LDA, N), B(LDB, N), ALPHA(N), BETA(N), VS(LDS, N),
     VSR(LDSR, N), WORK(LWORK)

Function/Subroutine Documentation

ZGEGS computes the generalized Schur decomposition of a square matrix pair (A, B) of order N.

A generalized Schur decomposition of A and B is a unitary transformation Q and Z such that

Q H A Z = T

Q H B Z = T

where T is an upper triangular matrix. The diagonal elements of T are the generalized eigenvalues of A and B.

ZGEGS overwrites A and B on return.

For more details, see the LAPACK documentation for ZGEGS.
