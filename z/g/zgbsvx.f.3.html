subroutine zgbsvx (character fact, character trans, integer n, integer kl, integer ku, integer nrhs, complex*16, dimension( ldab, * ) ab, integer ldab, complex*16, dimension( ldafb, * ) afb, integer ldafb, integer, dimension( * ) ipiv, character equed, double precision, dimension( * ) r, double precision, dimension( * ) c, complex*16, dimension( ldb, * ) b, integer ldb, complex*16, dimension( ldx, * ) x, integer ldx, double precision rcond, double precision, dimension( * ) ferr, double precision, dimension( * ) berr, complex*16, dimension( * ) work, double precision, dimension( * ) rwork, integer info)

ZGBSVX calcula la solución al sistema de ecuaciones lineales A * X = B para matrices GB

Propósito:

!>
!> ZGBSVX utiliza la factorización LU para calcular la solución a un sistema
!> complejo de ecuaciones lineales A * X = B, A**T * X = B, o A**H * X = B,
!> donde A es una matriz de banda de orden N con KL subdiagonales y KU
!> superdiagonales, y X e B son matrices N-por-NRHS.
!>
!> También se proporcionan cotas de error en la solución y una estimación
!> de la condición.
!>

Descripción:

!>
!> Esta subrutina realiza los siguientes pasos:
!>
!> 1. Si FACT = 'E', se calculan factores de escala reales para
!>    equilibrar el sistema:
!>       TRANS = 'N':  diag(R)*A*diag(C)     *inv(diag(C))*X = diag(R)*B
!>       TRANS = 'T': (diag(R)*A*diag(C))**T *inv(diag(R))*X = diag(C)*B
!>       TRANS = 'C': (diag(R)*A*diag(C))**H *inv(diag(R))*X = diag(C)*B
!>    Si el sistema se equilibrará o no depende del escalado de la
!>    matriz A, pero si se utiliza el equilibrado, A se sobrescribe
!>    con diag(R)*A*diag(C) y B con diag(R)*B (si TRANS='N')
!>    o diag(C)*B (si TRANS = 'T' o 'C').
!>
!> 2. Si FACT = 'N' o 'E', se utiliza la descomposición LU para factorizar
!>    la matriz A (después del equilibrado si FACT = 'E') como
!>       A = L * U,
!>    donde L es un producto de matrices de permutación y triangulares
!>    inferiores unitarias con KL subdiagonales, y U es triangular superior
!>    con KL+KU superdiagonales.
!>
!> 3. Si algún U(i,i)=0, de modo que U sea exactamente singular, la rutina
!>    devuelve INFO = i. De lo contrario, la forma factorizada de A se
!>    utiliza para estimar el número de condición de la matriz A. Si el
!>    recíproco del número de condición es menor que la precisión de
!>    máquina, se devuelve INFO = N+1 como advertencia, pero la rutina
!>    continúa resolviendo para X y calculando cotas de error como se
!>    describe a continuación.
!>
!> 4. El sistema de ecuaciones se resuelve para X utilizando la forma
!>    factorizada de A.
!>
!> 5. Se aplica refinamiento iterativo para mejorar la solución calculada
!>    y obtener cotas de error y estimaciones de error hacia atrás para
!>    ella.
!>
!> 6. Si se utilizó el equilibrado, la matriz X se premultiplica por
!>    diag(C) (si TRANS = 'N') o diag(R) (si TRANS = 'T' o 'C') para
!>    que resuelva el sistema original antes del equilibrado.
!>

Parámetros

FACT 
!>          FACT es CHARACTER*1
!>          Especifica si la forma factorizada de la matriz A se
!>          proporciona en la entrada, y si no, si la matriz A debe
!>          equilibrarse antes de factorizarse.
!>          = 'F':  En la entrada, AFB e IPIV contienen la forma factorizada
!>                  de A. Si EQUED no es 'N', la matriz A ha sido
!>                  equilibrada con factores de escala dados por R y C.
!>                  AB, AFB e IPIV no se modifican.
!>          = 'N':  La matriz A se copiará en AFB y se factorizará.
!>          = 'E':  La matriz A se equilibrará si es necesario, luego
!>                  se copiará en AFB y se factorizará.
!>

TRANS

!>          TRANS es CHARACTER*1
!>          Especifica la forma del sistema de ecuaciones.
!>          = 'N':  A * X = B     (Sin transpuesta)
!>          = 'T':  A**T * X = B  (Transpuesta)
!>          = 'C':  A**H * X = B  (Transpuesta conjugada)
!>

N

!>          N es INTEGER
!>          El número de ecuaciones lineales, es decir, el orden de
!>          la matriz A.  N >= 0.
!>

KL

!>          KL es INTEGER
!>          El número de subdiagonales dentro de la banda de A.  KL >= 0.
!>

KU

!>          KU es INTEGER
!>          El número de superdiagonales dentro de la banda de A.  KU >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de lados derechos, es decir, el número de columnas
!>          de las matrices B y X.  NRHS >= 0.
!>

AB

!>          AB es array COMPLEX*16, dimensión (LDAB,N)
!>          En la entrada, la matriz A en almacenamiento de banda, en las filas 1 a KL+KU+1.
!>          La j-ésima columna de A se almacena en la j-ésima columna del
!>          array AB como sigue:
!>          AB(KU+1+i-j,j) = A(i,j) para max(1,j-KU)<=i<=min(N,j+kl)
!>
!>          Si FACT = 'F' y EQUED no es 'N', entonces A debe haber sido
!>          equilibrada con los factores de escala en R y/o C. AB no
!>          se modifica si FACT = 'F' o 'N', o si FACT = 'E' y
!>          EQUED = 'N' en la salida.
!>
!>          En la salida, si EQUED .ne. 'N', A se escala como sigue:
!>          EQUED = 'R':  A := diag(R) * A
!>          EQUED = 'C':  A := A * diag(C)
!>          EQUED = 'B':  A := diag(R) * A * diag(C).
!>

LDAB

!>          LDAB es INTEGER
!>          La dimensión principal del array AB.  LDAB >= KL+KU+1.
!>

AFB

!>          AFB es array COMPLEX*16, dimensión (LDAFB,N)
!>          Si FACT = 'F', entonces AFB es un argumento de entrada y en la entrada
!>          contiene detalles de la factorización LU de la matriz de banda
!>          A, tal como se calculó con ZGBTRF. U se almacena como una matriz
!>          triangular superior de banda con KL+KU superdiagonales en las
!>          filas 1 a KL+KU+1, y los multiplicadores utilizados durante la
!>          factorización se almacenan en las filas KL+KU+2 a 2*KL+KU+1.
!>          Si EQUED .ne. 'N', entonces AFB es la forma factorizada de la
!>          matriz A equilibrada.
!>
!>          Si FACT = 'N', entonces AFB es un argumento de salida y en la salida
!>          devuelve detalles de la factorización LU de A.
!>
!>          Si FACT = 'E', entonces AFB es un argumento de salida y en la salida
!>          devuelve detalles de la factorización LU de la matriz A
!>          equilibrada (ver la descripción de AB para la forma de la
!>          matriz equilibrada).
!>

LDAFB

!>          LDAFB es INTEGER
!>          La dimensión principal del array AFB.  LDAFB >= 2*KL+KU+1.
!>

IPIV

!>          IPIV es array INTEGER, dimensión (N)
!>          Si FACT = 'F', entonces IPIV es un argumento de entrada y en la entrada
!>          contiene los índices de pivote de la factorización A = L*U
!>          tal como se calculó con ZGBTRF; la fila i de la matriz se
!>          intercambió con la fila IPIV(i).
!>
!>          Si FACT = 'N', entonces IPIV es un argumento de salida y en la salida
!>          contiene los índices de pivote de la factorización A = L*U
!>

NAME

zgbsvx - ZGBSVX computes the solution to a complex general band system of linear equations A*X = B, and provides error bounds and estimates of the condition number for the system.

SYNOPSIS

CALL ZGBSVX( FACT, TRANS, N, KL, KU, NRHS, AB, LDAB, B, LDB, X, LDX, RCOND, FERR, BERR, WORK, RWORK, IPIV, INFO )

Function/Subroutine Documentation

ZGBSVX performs the following steps:

1. Reorder the rows and columns of A to minimize the number of zero elements. (This step is optional.)

2. If FACT = 'N' or 'E', compute the LU factorization of A (or of the reordered A) to find the solution and error bounds.

3. If FACT = 'F', use the provided LU factorization to find the solution and error bounds.

4. Compute the forward error bound and backward error estimate for the computed solution.

This subroutine uses a loop-free approach to solve the system of equations. The condition number is computed using the L1 norm. For the forward error bound and backward error estimate, the L1 norm is used.

The routine returns the solution X to the original system A*X = B.

Arguments:

FACT

CHARACTER*1
 Specfies the form of the problem to be solved:
 = 'N': Compute the LU factorization and solve the system of equations.
 = 'E': Compute the LU factorization of the reordered matrix and solve the system of equations.
 = 'F': Use the precomputed LU factorization in AB and solve the system of equations.

TRANS

CHARACTER*1
 Specifies the form of the system of equations to be solved:
 = 'N': A * X = B (No transpose)
 = 'T': A**T * X = B (Transpose)
 = 'C': A**H * X = B (Conjugate transpose)

N

INTEGER
 The order of the matrix A. N >= 0.

KL

INTEGER
 The number of subdiagonals of the matrix A. KL >= 0.

KU

INTEGER
 The number of superdiagonals of the matrix A. KU >= 0.

NRHS

INTEGER
 The number of right hand sides, i.e., the number of columns of the matrices B and X. NRHS >= 0.

AB

COMPLEX*16 array, dimension (LDAB, N)
 On entry, the array AB contains the matrix A, partitioned by diagonals.
 For FACT = 'F', AB must contain the L and U factors.
 On exit, AB is overwritten by details of the LU factorization.

LDAB

INTEGER
 The leading dimension of the array AB. LDAB >= (KL + KU + 1).

B

COMPLEX*16 array, dimension (LDB, NRHS)
 On entry, the right hand side matrix B.
 On exit, B is overwritten by the solution matrix X if FACT = 'N' or 'E'.
 If FACT = 'F', B is overwritten by the solution matrix X if TRANS = 'N'.
 If FACT = 'F', TRANS = 'T' or 'C', and EQUED = 'C' or 'B', B is overwritten by diag(C)*B.

LDB

INTEGER
 The leading dimension of the array B. LDB >= max(1,N).

X

COMPLEX*16 array, dimension (LDX, NRHS)
 On exit, if INFO = 0, X contains the solution matrix X to the original system of equations.
 Note that A and B are modified on exit if EQUED .ne. 'N', and the solution to the equilibrated system is inv(diag(C))*X if TRANS = 'N' and EQUED = 'C' or 'B', or inv(diag(R))*X if TRANS = 'T' or 'C' and EQUED = 'R' or 'B'.

LDX

INTEGER
 The leading dimension of the array X. LDX >= max(1,N).

RCOND

DOUBLE PRECISION
 On exit, RCOND is an estimate of the reciprocal condition number of the matrix A after equilibration (if done). If RCOND is less than the machine precision (in particular, if RCOND = 0), the matrix is singular to working precision. This condition is indicated by a return code of INFO > 0.

FERR

DOUBLE PRECISION array, dimension (NRHS)
 On exit, FERR contains the estimated forward error bound for each solution vector X(j) (the j-th column of the solution matrix X). If XTRUE is the true solution corresponding to X(j), FERR(j) is an estimated upper bound for the magnitude of the largest element in (X(j) - XTRUE) divided by the magnitude of the largest element in X(j). The estimate is as reliable as the estimate for RCOND, and is almost always a slight overestimate of the true error.

BERR

DOUBLE PRECISION array, dimension (NRHS)
 On exit, BERR contains the componentwise relative backward error of each solution vector X(j) (i.e., the smallest relative change in any element of A or B that makes X(j) an exact solution).

WORK

COMPLEX*16 array, dimension (2*N)

RWORK

DOUBLE PRECISION array, dimension (N)
 On exit, RWORK(1) contains the reciprocal pivot growth factor norm(A)/norm(U). The L1 norm is used. If RWORK(1) is much less than 1, then the stability of the LU factorization of the (equilibrated) matrix A could be poor. This also means that the solution X, condition estimator RCOND, and forward error bound FERR could be unreliable. If factorization fails with 0<INFO<=N, then RWORK(1) contains the reciprocal pivot growth factor for the leading INFO columns of A.

IPIV

INTEGER array, dimension (N)
 On exit, IPIV contains the pivot indices from the factorization of the original matrix A.
          If FACT = 'E', then IPIV is an output argument and on exit
          contains the pivot indices from the factorization A = L*U
          of the equilibrated matrix A.

EQUED

CHARACTER*1
 Specifies the form of equilibration that was done.
 = 'N':  No equilibration (always true if FACT = 'N').
 = 'R':  Row equilibration, i.e., A has been premultiplied by
         diag(R).
 = 'C':  Column equilibration, i.e., A has been postmultiplied
         by diag(C).
 = 'B':  Both row and column equilibration, i.e., A has been
         replaced by diag(R) * A * diag(C).
 EQUED is an input argument if FACT = 'F'; otherwise, it is an
 output argument.

R

DOUBLE PRECISION array, dimension (N)
 The row scale factors for A.  If EQUED = 'R' or 'B', A is
 multiplied on the left by diag(R); if EQUED = 'N' or 'C', R
 is not accessed.  R is an input argument if FACT = 'F';
 otherwise, R is an output argument.  If FACT = 'F' and
 EQUED = 'R' or 'B', each element of R must be positive.

C

DOUBLE PRECISION array, dimension (N)
 The column scale factors for A.  If EQUED = 'C' or 'B', A is
 multiplied on the right by diag(C); if EQUED = 'N' or 'R', C
 is not accessed.  C is an input argument if FACT = 'F';
 otherwise, C is an output argument.  If FACT = 'F' and
 EQUED = 'C' or 'B', each element of C must be positive.

INFO

INTEGER
 = 0:  successful exit
 < 0:  if INFO = -i, the i-th argument had an illegal value
 > 0:  if INFO = i, and i is
        <= N:  U(i,i) is exactly zero.  The factorization
                has been completed, but the factor U is exactly
                singular, so the solution and error bounds
                could not be computed. RCOND = 0 is returned.
        = N+1: U is nonsingular, but RCOND is less than machine
               precision, meaning that the matrix is singular
               to working precision.  Nevertheless, the
               solution and error bounds are computed because
               there are a number of situations where the
               computed solution can be more accurate than the
               value of RCOND would suggest.
