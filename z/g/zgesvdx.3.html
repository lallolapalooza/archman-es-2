ZGESVDX calcula la descomposición en valores singulares (SVD) de matrices GE

Propósito:

!>
!>  ZGESVDX calcula la descomposición en valores singulares (SVD) de una matriz compleja
!>  M por N, A, calculando opcionalmente los vectores singulares izquierdos y/o derechos.
!>  La SVD se escribe:
!>
!>      A = U * SIGMA * transpuesta(V)
!>
!>  donde SIGMA es una matriz M por N que es cero excepto por sus
!>  elementos diagonales min(m,n), U es una matriz unitaria M por M, y
!>  V es una matriz unitaria N por N.  Los elementos diagonales de SIGMA
!>  son los valores singulares de A; son reales y no negativos, y
!>  se devuelven en orden descendente. Las primeras min(m,n) columnas de
!>  U y V son los vectores singulares izquierdos y derechos de A.
!>
!>  ZGESVDX utiliza un problema de valores propios para obtener la SVD, lo que
!>  permite el cálculo de un subconjunto de valores y
!>  vectores singulares. Ver DBDSVDX para más detalles.
!>
!>  Tenga en cuenta que la rutina devuelve V**T, no V.
!>

Parámetros

JOBU 
!>          JOBU es CHARACTER*1
!>          Especifica las opciones para calcular todo o parte de la matriz U:
!>          = 'V':  se devuelven las primeras min(m,n) columnas de U (los vectores singulares
!>                  izquierdos) o según lo especificado por RANGE en
!>                  la matriz U;
!>          = 'N':  no se calculan columnas de U (no hay vectores singulares izquierdos).
!>

JOBVT

!>          JOBVT es CHARACTER*1
!>           Especifica las opciones para calcular todo o parte de la matriz
!>           V**T:
!>           = 'V':  se devuelven las primeras min(m,n) filas de V**T (los vectores singulares
!>                   derechos) o según lo especificado por RANGE en
!>                   la matriz VT;
!>           = 'N':  no se calculan filas de V**T (no hay vectores singulares derechos).
!>

RANGE

!>          RANGE es CHARACTER*1
!>          = 'A': se encontrarán todos los valores singulares.
!>          = 'V': se encontrarán todos los valores singulares en el intervalo semiabierto (VL,VU]
!>                 .
!>          = 'I': se encontrarán los valores singulares desde el IL-ésimo hasta el IU-ésimo.
!>

M

!>          M es INTEGER
!>          El número de filas de la matriz de entrada A.  M >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz de entrada A.  N >= 0.
!>

A

!>          A es una matriz COMPLEX*16, dimensión (LDA,N)
!>          En la entrada, la matriz M por N A.
!>          En la salida, el contenido de A se destruye.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal de la matriz A.  LDA >= max(1,M).
!>

VL

!>          VL es DOUBLE PRECISION
!>          Si RANGE='V', el límite inferior del intervalo a
!>          buscar para los valores singulares. VU > VL.
!>          No se hace referencia si RANGE = 'A' o 'I'.
!>

VU

!>          VU es DOUBLE PRECISION
!>          Si RANGE='V', el límite superior del intervalo a
!>          buscar para los valores singulares. VU > VL.
!>          No se hace referencia si RANGE = 'A' o 'I'.
!>

IL

!>          IL es INTEGER
!>          Si RANGE='I', el índice del
!>          valor singular más pequeño a devolver.
!>          1 <= IL <= IU <= min(M,N), si min(M,N) > 0.
!>          No se hace referencia si RANGE = 'A' o 'V'.
!>

IU

!>          IU es INTEGER
!>          Si RANGE='I', el índice del
!>          valor singular más grande a devolver.
!>          1 <= IL <= IU <= min(M,N), si min(M,N) > 0.
!>          No se hace referencia si RANGE = 'A' o 'V'.
!>

NS

!>          NS es INTEGER
!>          El número total de valores singulares encontrados,
!>          0 <= NS <= min(M,N).
!>          Si RANGE = 'A', NS = min(M,N); si RANGE = 'I', NS = IU-IL+1.
!>

S

!>          S es una matriz DOUBLE PRECISION, dimensión (min(M,N))
!>          Los valores singulares de A, ordenados de forma que S(i) >= S(i+1).
!>

U

!>          U es una matriz COMPLEX*16, dimensión (LDU,UCOL)
!>          Si JOBU = 'V', U contiene las columnas de U (los vectores singulares
!>          izquierdos, almacenados por columnas) según lo especificado por RANGE; si
!>          JOBU = 'N', U no se hace referencia.
!>          Nota: El usuario debe asegurarse de que UCOL >= NS; si RANGE = 'V',
!>          el valor exacto de NS no se conoce de antemano y se debe usar un límite superior.
!>

LDU

!>          LDU es INTEGER
!>          La dimensión principal de la matriz U.  LDU >= 1; si
!>          JOBU = 'V', LDU >= M.
!>

VT

!>          VT es una matriz COMPLEX*16, dimensión (LDVT,N)
!>          Si JOBVT = 'V', VT contiene las filas de V**T (los vectores singulares
!>          derechos, almacenados por filas) según lo especificado por RANGE; si JOBVT = 'N',
!>          VT no se hace referencia.
!>          Nota: El usuario debe asegurarse de que LDVT >= NS; si RANGE = 'V',
!>          el valor exacto de NS no se conoce de antemano y se debe usar un límite superior.
!>

LDVT

!>          LDVT es INTEGER
!>          La dimensión principal de la matriz VT.  LDVT >= 1; si
!>          JOBVT = 'V', LDVT >= NS (ver arriba).
!>

WORK

!>          WORK es una matriz COMPLEX*16, dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo;
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión de la matriz WORK.
!>          LWORK >= MAX(1,MIN(M,N)*(MIN(M,N)+4)) para las rutas (ver
!>          comentarios dentro del código):
!>             - RUTA 1  (M mucho mayor que N)
!>             - RUTA 1t (N mucho mayor que M)
!>          LWORK >= MAX(1,MIN(M,N)*2+MAX(M,N)) para las otras rutas.
!>          Para un buen rendimiento, LWORK debería ser generalmente mayor.
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo de la matriz WORK, devuelve
!>          este valor como la primera entrada de la matriz WORK, y XERBLA no emite ningún mensaje de error
!>          relacionado con LWORK.
!>

RWORK

!>          RWORK es una matriz DOUBLE PRECISION, dimensión (MAX(1,LRWORK))
!>          LRWORK >= MIN(M,N)*(MIN(M,N)*2+15*MIN(M,N)).
!>

IWORK

!>          IWORK es una matriz INTEGER, dimensión (12*MIN(M,N))
!>          Si INFO = 0, los primeros NS elementos de IWORK son cero. Si INFO > 0,
!>          entonces IWORK contiene los índices de los autovectores que fallaron
!>          en converger en DBDSVDX/DSTEVX.
!>

INFO
