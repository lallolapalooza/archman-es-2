subrutina zggev (character jobvl, character jobvr, integer n, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( ldb, * ) b, integer ldb, complex*16, dimension( * ) alpha, complex*16, dimension( * ) beta, complex*16, dimension( ldvl, * ) vl, integer ldvl, complex*16, dimension( ldvr, * ) vr, integer ldvr, complex*16, dimension( * ) work, integer lwork, double precision, dimension( * ) rwork, integer info)

ZGGEV calcula los valores propios y, opcionalmente, los vectores propios izquierdos y/o derechos para matrices GE

Propósito:

!>
!> ZGGEV calcula para un par de matrices complejas no simétricas de N-por-N
!> (A,B), los valores propios generalizados, y opcionalmente, los vectores propios generalizados izquierdos y/o derechos.
!>
!> Un valor propio generalizado para un par de matrices (A,B) es un escalar
!> lambda o una relación alpha/beta = lambda, tal que A - lambda*B es
!> singular. Normalmente se representa como el par (alpha,beta), ya que
!> hay una interpretación razonable para beta=0, e incluso para que ambos
!> sean cero.
!>
!> El vector propio generalizado derecho v(j) correspondiente al
!> valor propio generalizado lambda(j) de (A,B) satisface
!>
!>              A * v(j) = lambda(j) * B * v(j).
!>
!> El vector propio generalizado izquierdo u(j) correspondiente al
!> valor propio generalizado lambda(j) de (A,B) satisface
!>
!>              u(j)**H * A = lambda(j) * u(j)**H * B
!>
!> donde u(j)**H es la transpuesta conjugada de u(j).
!>

Parámetros

JOBVL 
!>          JOBVL es CHARACTER*1
!>          = 'N':  no calcular los vectores propios generalizados izquierdos;
!>          = 'V':  calcular los vectores propios generalizados izquierdos.
!>

JOBVR

!>          JOBVR es CHARACTER*1
!>          = 'N':  no calcular los vectores propios generalizados derechos;
!>          = 'V':  calcular los vectores propios generalizados derechos.
!>

N

!>          N es INTEGER
!>          El orden de las matrices A, B, VL y VR.  N >= 0.
!>

A

!>          A es un array COMPLEX*16, dimensión (LDA, N)
!>          En la entrada, la matriz A en el par (A,B).
!>          En la salida, A ha sido sobrescrita.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal de A.  LDA >= max(1,N).
!>

B

!>          B es un array COMPLEX*16, dimensión (LDB, N)
!>          En la entrada, la matriz B en el par (A,B).
!>          En la salida, B ha sido sobrescrita.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal de B.  LDB >= max(1,N).
!>

ALPHA

!>          ALPHA es un array COMPLEX*16, dimensión (N)
!>

BETA

!>          BETA es un array COMPLEX*16, dimensión (N)
!>          En la salida, ALPHA(j)/BETA(j), j=1,...,N, serán los
!>          valores propios generalizados.
!>
!>          Nota: los cocientes ALPHA(j)/BETA(j) pueden fácilmente sobreflo- o
!>          subflo-escribir, y BETA(j) puede incluso ser cero. Por lo tanto, el usuario
!>          debe evitar calcular ingenuamente la relación alpha/beta.
!>          Sin embargo, ALPHA siempre será menor y generalmente
!>          comparable con norm(A) en magnitud, y BETA siempre menor
!>          y generalmente comparable con norm(B).
!>

VL

!>          VL es un array COMPLEX*16, dimensión (LDVL,N)
!>          Si JOBVL = 'V', los vectores propios generalizados izquierdos u(j) se
!>          almacenan uno tras otro en las columnas de VL, en el mismo
!>          orden que sus valores propios.
!>          Cada vector propio se escala para que el componente más grande tenga
!>          abs(parte real) + abs(parte imaginaria) = 1.
!>          No referenciado si JOBVL = 'N'.
!>

LDVL

!>          LDVL es INTEGER
!>          La dimensión principal de la matriz VL. LDVL >= 1, y
!>          si JOBVL = 'V', LDVL >= N.
!>

VR

!>          VR es un array COMPLEX*16, dimensión (LDVR,N)
!>          Si JOBVR = 'V', los vectores propios generalizados derechos v(j) se
!>          almacenan uno tras otro en las columnas de VR, en el mismo
!>          orden que sus valores propios.
!>          Cada vector propio se escala para que el componente más grande tenga
!>          abs(parte real) + abs(parte imaginaria) = 1.
!>          No referenciado si JOBVR = 'N'.
!>

LDVR

!>          LDVR es INTEGER
!>          La dimensión principal de la matriz VR. LDVR >= 1, y
!>          si JOBVR = 'V', LDVR >= N.
!>

WORK

!>          WORK es un array COMPLEX*16, dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK.  LWORK >= max(1,2*N).
!>          Para un buen rendimiento, LWORK debe ser generalmente mayor.
!>
!>          Si LWORK = -1, se asume una consulta de espacio de trabajo; la rutina
!>          sólo calcula el tamaño óptimo del array WORK, devuelve
!>          este valor como la primera entrada del array WORK, y XERBLA no emite ningún mensaje de error
!>          relacionado con LWORK.
!>

RWORK

!>          RWORK es un array DOUBLE PRECISION, dimensión (8*N)
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tuvo un valor ilegal.
!>          =1,...,N:
!>                La iteración QZ falló. No se han calculado vectores propios,
!>                pero ALPHA(j) y BETA(j) deberían ser
!>                correctos para j=INFO+1,...,N.
!>          > N:  =N+1: falló la iteración QZ en ZHGEQZ,
!>                =N+2: retorno de error de ZTGEVC.
!>

zggev(3)

NOMBRE

zggev - Resuelve el problema general de valores propios generalizado para matrices complejas.

SINOPSIS

subroutine zggev(jobvl, jobvr, n, a, lda, b, ldb, alpha, beta, vl, ldvl, vr, ldvr, work, lwork, rwork, info)

DESCRIPCIÓN

zggev calcula los valores propios generalizados y los vectores propios correspondientes de dos matrices complejas generales A y B.

El problema de valores propios generalizado se define como:

$$ A x = \lambda B x $$

o, en forma equivalente,

$$ \alpha A x = \beta B x $$

donde $\lambda$ es un valor propio generalizado y $x$ es un vector propio generalizado.

PARÁMETROS

jobvl (character)
Indica si se calcularán los vectores propios izquierdos.
  • 'N': No se calculan los vectores propios izquierdos.
  • 'V': Se calculan los vectores propios izquierdos.
jobvr (character)
Indica si se calcularán los vectores propios derechos.
  • 'N': No se calculan los vectores propios derechos.
  • 'V': Se calculan los vectores propios derechos.
n (integer)
El orden de las matrices A y B. n ≥ 0.
a (complex*16)
Matriz de entrada de tamaño (lda, n).
lda (integer)
El primer límite de A. lda ≥ max(1, n).
b (complex*16)
Matriz de entrada de tamaño (ldb, n).
ldb (integer)
El primer límite de B. ldb ≥ max(1, n).
alpha (complex*16)
Salida: el vector de tamaño n que contiene los numeradores de los valores propios generalizados.
beta (complex*16)
Salida: el vector de tamaño n que contiene los denominadores de los valores propios generalizados.
vl (complex*16)
Salida: si jobvl es 'V', vl contiene los vectores propios izquierdos normalizados.
ldvl (integer)
El primer límite de vl. Si jobvl es 'V', ldvl ≥ n.
vr (complex*16)
Salida: si jobvr es 'V', vr contiene los vectores propios derechos normalizados.
ldvr (integer)
El primer límite de vr. Si jobvr es 'V', ldvr ≥ n.
work (complex*16)
Array de trabajo. La longitud de work depende de lwork.
lwork (integer)
La longitud del array work. lwork ≥ 0. Para determinar el tamaño óptimo de lwork, se debe establecer lwork a -1, y work contendrá el tamaño óptimo en la primera posición.
rwork (double precision)
Array de trabajo real de tamaño (lrwork).
lrwork (integer)
La longitud del array rwork. lrwork ≥ max(1, 2*n).
info (integer)
  • info = 0: ejecución correcta.
  • info < 0: si info = -i, el i-ésimo argumento había sido ilegal.
  • info > 0: si info = i, el algoritmo de QR falló en converger; i es el número de iteraciones que se tomaron.

DETALLES

Los valores propios generalizados se calculan como $\alpha_i / \beta_i$.

Si $\beta_i$ es cero, entonces el valor propio es infinito.

Los vectores propios izquierdos y derechos se calculan de manera que:

$$ A v = \lambda B v $$

$$ u^{H} A = \lambda u^{H} B $$

donde $v$ son los vectores propios derechos y $u$ son los vectores propios izquierdos.

VER TAMBIÉN

zgeev(3), zgesv(3)

REFERENCIAS

zggev está basado en el código ZGGEVX de LAPACK.
