Function/Subroutine Documentation

This subroutine is part of the LAPACK routines that compute the solution to a set of linear equations $Ax = b$.

Description

ZGERFSX computes the solution to a set of linear equations $Ax = b$ with WARRANTIES on the computed solusi and error bounds.

This subroutine supports iterative refinement. Iterative refinement consists of the following steps:

  1. Compute the solution $x$ to $Ax = b$.
  2. Compute the residual $r = b - Ax$.
  3. Compute an estimate $dx$ of the error $dx = x_{true} - x$.
  4. Compute the solution $x + dx$ to $Ax = b$.

The routines provides error bounds for both the normwise relative error and the componentwise relative error.

Parameters

TRANS

CHARACTER*1. Specifies the form of the system of equations:

'N' : $A x = b$ (No transpose)

'T' : $A^T x = b$ (Transpose)

'C' : $A^H x = b$ (Conjugate transpose)

'G' : $A$ or $A^T$ or $A^H$. $A$ is general rectangular.

Constraint: TRANS = 'N', 'T', 'C' or 'G'.

EQUED

CHARACTER*1. Specifies the equilibration condition:

'N' : No equilibration computed.

'R' : Row equilibration computed and applied.

'C' : Column equilibration computed and applied.

'B' : Both row and column equilibration computed and applied.

Constraint: EQUED = 'N', 'R', 'C' or 'B'.

N

INTEGER. The order of the matrix A. N >= 0.

NRHS

INTEGER. The number of right hand sides, i.e., the number of columns of the matrices B, X, AF, and A. NRHS >= 0.

A

COMPLEX*16 array, dimension (LDA, N). The coefficient matrix A.

LDA

INTEGER. The leading dimension of the array A. LDA >= max(1, N).

AF

COMPLEX*16 array, dimension (LDAF, N). The factors L and U from the factorization of A (or ABA)

The exact details of the storage, and the contents of the array AF depend on the value of EQUED and TRANS.

LDAF

INTEGER. The leading dimension of the array AF. LDAF >= max(1, N).

IPIV

INTEGER array, dimension (N). The pivot indices derived from the factorization of A.

B

COMPLEX*16 array, dimension (LDB, NRHS). The right hand side matrix B.

LDB

INTEGER. The leading dimension of the array B. LDB >= max(1, N).

X

COMPLEX*16 array, dimension (LDX, NRHS). The solution matrix X.

LDX

INTEGER. The leading dimension of the array X. LDX >= max(1, N).

RCOND

DOUBLE PRECISION array, dimension (NRHS). Each element contains an estimate of the reciprocal condition number of the matrix A. This is an estimate of 1/cond(A).

BERR

DOUBLE PRECISION array, dimension (NRHS). Each element contains an estimate of the relative backward error, and is defined as follows:

berr = max_i ( abs( res(i) ) / ( abs(op(A))*abs(x) + abs(b) )

where res = b - Ax (computed by ZLACON), op(A) is A in the case of TRANS='N' and A^H in the case of TRANS='C', and the maximum is taken over the components of the vectors.

RESL

DOUBLE PRECISION array, dimension (NRHS). Each element contains an estimate of the relative forward error, and is defined as follows:

resl = max_i ( abs( x_{true}(i) - x(i) ) / abs( x(i) ) )

where the maximum is taken over the components of the vectors.

RESR

DOUBLE PRECISION array, dimension (NRHS). Each element contains an estimate of the relative forward error, and is defined as follows:

resr = max_i ( abs( x_{true}(i) - x(i) ) )

where the maximum is taken over the components of the vectors.

OFFSET

DOUBLE PRECISION array, dimension (NRHS). Each element contains an estimate of the scaled backward error, and is defined as follows:

offset = max_i ( abs( res(i) ) / ( abs(op(A))*abs(x) + abs(b) ) )

where the maximum is taken over the components of the vectors.

EQOK

LOGICAL. EQOK is true if the equilibration computed by ZEQUIL was not exceed the limits of double precision.

INFO

INTEGER. INFO is an integer output flag. If INFO = 0, the routine was successful. If INFO < 0, the i-th argument had an illegal value. If INFO > 0, the i-th diagonal element of the Schur factor is zero. The diagonal element is equal to zero if INFO > N. If INFO = N+J, then the solution corresponding to the J-th right-hand side is not guaranteed.
