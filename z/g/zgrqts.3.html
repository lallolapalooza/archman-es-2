subrutina zgrqts (integer m, integer p, integer n, complex*16, dimension( lda, * ) a, complex*16, dimension( lda, * ) af, complex*16, dimension( lda, * ) q, complex*16, dimension( lda, * ) r, integer lda, complex*16, dimension( * ) taua, complex*16, dimension( ldb, * ) b, complex*16, dimension( ldb, * ) bf, complex*16, dimension( ldb, * ) z, complex*16, dimension( ldb, * ) t, complex*16, dimension( ldb, * ) bwk, integer ldb, complex*16, dimension( * ) taub, complex*16, dimension( lwork ) work, integer lwork, double precision, dimension( * ) rwork, double precision, dimension( 4 ) result)

ZGRQTS

Propósito:

!>
!> ZGRQTS prueba ZGGRQF, que calcula la factorización GRQ de una
!> matriz M por N, A, y una matriz P por N, B: A = R*Q y B = Z*T*Q.
!>

Parámetros

M 
!>          M es ENTERO
!>          El número de filas de la matriz A.  M >= 0.
!>

P

!>          P es ENTERO
!>          El número de filas de la matriz B.  P >= 0.
!>

N

!>          N es ENTERO
!>          El número de columnas de las matrices A y B.  N >= 0.
!>

A

!>          A es un array COMPLEX*16, dimension (LDA,N)
!>          La matriz M por N, A.
!>

AF

!>          AF es un array COMPLEX*16, dimension (LDA,N)
!>          Detalles de la factorización GRQ de A y B, tal como se devuelve
!>          por ZGGRQF, ver CGGRQF para más detalles.
!>

Q

!>          Q es un array COMPLEX*16, dimension (LDA,N)
!>          La matriz unitaria N por N, Q.
!>

R

!>          R es un array COMPLEX*16, dimension (LDA,MAX(M,N))
!>

LDA

!>          LDA es ENTERO
!>          La dimensión principal de los arrays A, AF, R y Q.
!>          LDA >= max(M,N).
!>

TAUA

!>          TAUA es un array COMPLEX*16, dimension (min(M,N))
!>          Los factores escalares de los reflectores elementales, tal como se devuelven
!>          por DGGQRC.
!>

B

!>          B es un array COMPLEX*16, dimension (LDB,N)
!>          En la entrada, la matriz P por N, A.
!>

BF

!>          BF es un array COMPLEX*16, dimension (LDB,N)
!>          Detalles de la factorización GQR de A y B, tal como se devuelve
!>          por ZGGRQF, ver CGGRQF para más detalles.
!>

Z

!>          Z es un array DOUBLE PRECISION, dimension (LDB,P)
!>          La matriz unitaria P por P, Z.
!>

T

!>          T es un array COMPLEX*16, dimension (LDB,max(P,N))
!>

BWK

!>          BWK es un array COMPLEX*16, dimension (LDB,N)
!>

LDB

!>          LDB es ENTERO
!>          La dimensión principal de los arrays B, BF, Z y T.
!>          LDB >= max(P,N).
!>

TAUB

!>          TAUB es un array COMPLEX*16, dimension (min(P,N))
!>          Los factores escalares de los reflectores elementales, tal como se devuelven
!>          por DGGRQF.
!>

WORK

!>          WORK es un array COMPLEX*16, dimension (LWORK)
!>

LWORK

!>          LWORK es ENTERO
!>          La dimensión del array WORK, LWORK >= max(M,P,N)**2.
!>

RWORK

!>          RWORK es un array DOUBLE PRECISION, dimension (M)
!>

RESULT

!>          RESULT es un array DOUBLE PRECISION, dimension (4)
!>          Las razones de prueba:
!>            RESULT(1) = norm( R - A*Q' ) / ( MAX(M,N)*norm(A)*ULP)
!>            RESULT(2) = norm( T*Q - Z'*B ) / (MAX(P,N)*norm(B)*ULP)
!>            RESULT(3) = norm( I - Q'*Q ) / ( N*ULP )
!>            RESULT(4) = norm( I - Z'*Z ) / ( P*ULP )
!>
