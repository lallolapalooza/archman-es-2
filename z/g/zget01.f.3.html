Documentación de Función/Subrutina

subrutina zget01 (integer m, integer n, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( ldafac, * ) afac, integer ldafac, integer, dimension( * ) ipiv, double precision, dimension( * ) rwork, double precision resid)

ZGET01

Propósito:

!>
!> ZGET01 reconstruye una matriz A a partir de su factorización L*U y
!> calcula el residuo
!>    norm(L*U - A) / ( N * norm(A) * EPS ),
!> donde EPS es la epsilon de la máquina.
!>

Parámetros

M 
!>          M es ENTERO
!>          El número de filas de la matriz A.  M >= 0.
!>

N

!>          N es ENTERO
!>          El número de columnas de la matriz A.  N >= 0.
!>

A

!>          A es un array COMPLEX*16, dimension (LDA,N)
!>          La matriz original A de M x N.
!>

LDA

!>          LDA es ENTERO
!>          La dimensión principal del array A.  LDA >= max(1,M).
!>

AFAC

!>          AFAC es un array COMPLEX*16, dimension (LDAFAC,N)
!>          La forma factorizada de la matriz A.  AFAC contiene los factores
!>          L y U de la factorización L*U calculada por ZGETRF.
!>          Se sobrescribe con la matriz reconstruida y luego con la
!>          diferencia L*U - A.
!>

LDAFAC

!>          LDAFAC es ENTERO
!>          La dimensión principal del array AFAC.  LDAFAC >= max(1,M).
!>

IPIV

!>          IPIV es un array ENTERO, dimension (N)
!>          Los índices de pivote de ZGETRF.
!>

RWORK

!>          RWORK es un array DOUBLE PRECISION, dimension (M)
!>

RESID

!>          RESID es DOUBLE PRECISION
!>          norm(L*U - A) / ( N * norm(A) * EPS )
!>
