subrutina zgbsvx (carácter fact, carácter trans, entero n, entero kl, entero ku, entero nrhs, complejo*16, dimensión( ldab, * ) ab, entero ldab, complejo*16, dimensión( ldafb, * ) afb, entero ldafb, entero, dimensión( * ) ipiv, carácter equed, doble precisión, dimensión( * ) r, doble precisión, dimensión( * ) c, complejo*16, dimensión( ldb, * ) b, entero ldb, complejo*16, dimensión( ldx, * ) x, entero ldx, doble precisión rcond, doble precisión, dimensión( * ) ferr, doble precisión, dimensión( * ) berr, complejo*16, dimensión( * ) work, doble precisión, dimensión( * ) rwork, entero info)

ZGBSVX calcula la solución al sistema de ecuaciones lineales A * X = B para matrices GB

Propósito:

!>
!> ZGBSVX utiliza la factorización LU para calcular la solución de un sistema
!> complejo de ecuaciones lineales A * X = B, A**T * X = B, o A**H * X = B,
!> donde A es una matriz de banda de orden N con KL subdiagonales y KU
!> superdiagonales, y X y B son matrices N por NRHS.
!>
!> También se proporcionan cotas de error para la solución y una estimación
!> de la condición.
!>

Descripción:

!>
!> Esta subrutina realiza los siguientes pasos:
!>
!> 1. Si FACT = 'E', se calculan factores de escala reales para equilibrar
!>    el sistema:
!>       TRANS = 'N':  diag(R)*A*diag(C)     *inv(diag(C))*X = diag(R)*B
!>       TRANS = 'T': (diag(R)*A*diag(C))**T *inv(diag(R))*X = diag(C)*B
!>       TRANS = 'C': (diag(R)*A*diag(C))**H *inv(diag(R))*X = diag(C)*B
!>    Si el sistema se equilibrará o no depende del
!>    escalado de la matriz A, pero si se usa el equilibrado, A se
!>    sobrescribe con diag(R)*A*diag(C) y B con diag(R)*B (si TRANS='N')
!>    o diag(C)*B (si TRANS = 'T' o 'C').
!>
!> 2. Si FACT = 'N' o 'E', se utiliza la descomposición LU para factorizar
!>    la matriz A (después del equilibrado si FACT = 'E') como
!>       A = L * U,
!>    donde L es un producto de matrices de permutación y triangulares inferiores unitarias
!>    con KL subdiagonales, y U es triangular superior con
!>    KL+KU superdiagonales.
!>
!> 3. Si algún U(i,i)=0, de modo que U sea exactamente singular, entonces la rutina
!>    devuelve INFO = i. De lo contrario, la forma factorizada de A se utiliza
!>    para estimar el número de condición de la matriz A. Si el
!>    recíproco del número de condición es menor que la precisión de la máquina,
!>    se devuelve INFO = N+1 como advertencia, pero la rutina continúa
!>    resolviendo para X y calculando las cotas de error como se describe a continuación.
!>
!> 4. El sistema de ecuaciones se resuelve para X utilizando la forma factorizada
!>    de A.
!>
!> 5. Se aplica refinamiento iterativo para mejorar la solución calculada
!>    y calcular cotas de error y estimaciones de error hacia atrás
!>    para ella.
!>
!> 6. Si se utilizó el equilibrado, la matriz X se premultiplica por
!>    diag(C) (si TRANS = 'N') o diag(R) (si TRANS = 'T' o 'C') para
!>    que resuelva el sistema original antes del equilibrado.
!>

Parámetros

FACT 
!>          FACT es CHARACTER*1
!>          Especifica si la forma factorizada de la matriz A se
!>          suministra o no en la entrada, y si no, si la matriz A debe ser
!>          equilibrada antes de ser factorizada.
!>          = 'F':  En la entrada, AFB y IPIV contienen la forma factorizada de
!>                  A.  Si EQUED no es 'N', la matriz A ha sido
!>                  equilibrada con factores de escala dados por R y C.
!>                  AB, AFB, e IPIV no se modifican.
!>          = 'N':  La matriz A se copiará en AFB y se factorizará.
!>          = 'E':  La matriz A se equilibrará si es necesario, luego
!>                  se copiará en AFB y se factorizará.
!>

TRANS

!>          TRANS es CHARACTER*1
!>          Especifica la forma del sistema de ecuaciones.
!>          = 'N':  A * X = B     (Sin transposición)
!>          = 'T':  A**T * X = B  (Transposición)
!>          = 'C':  A**H * X = B  (Transpuesta conjugada)
!>

N

!>          N es INTEGER
!>          El número de ecuaciones lineales, es decir, el orden de
!>          la matriz A.  N >= 0.
!>

KL

!>          KL es INTEGER
!>          El número de subdiagonales dentro de la banda de A.  KL >= 0.
!>

KU

!>          KU es INTEGER
!>          El número de superdiagonales dentro de la banda de A.  KU >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de lados derechos, es decir, el número de columnas
!>          de las matrices B y X.  NRHS >= 0.
!>

AB

!>          AB es una matriz COMPLEX*16, dimensión (LDAB,N)
!>          En la entrada, la matriz A en almacenamiento de banda, en las filas 1 a KL+KU+1.
!>          La j-ésima columna de A se almacena en la j-ésima columna de la
!>          matriz AB como sigue:
!>          AB(KU+1+i-j,j) = A(i,j) para max(1,j-KU)<=i<=min(N,j+kl)
!>
!>          Si FACT = 'F' y EQUED no es 'N', entonces A debe haber sido
!>          equilibrada por los factores de escala en R y/o C. AB no se
!>          modifica si FACT = 'F' o 'N', o si FACT = 'E' y
!>          EQUED = 'N' en la salida.
!>
!>          En la salida, si EQUED .ne. 'N', A se escala como sigue:
!>          EQUED = 'R':  A := diag(R) * A
!>          EQUED = 'C':  A := A * diag(C)
!>          EQUED = 'B':  A := diag(R) * A * diag(C).
!>

LDAB

!>          LDAB es INTEGER
!>          La dimensión principal de la matriz AB.  LDAB >= KL+KU+1.
!>

AFB

!>          AFB es una matriz COMPLEX*16, dimensión (LDAFB,N)
!>          Si FACT = 'F', entonces AFB es un argumento de entrada y en la entrada
!>          contiene detalles de la factorización LU de la matriz de banda
!>          A, tal como fue calculada por ZGBTRF. U se almacena como una matriz de banda
!>          triangular superior con KL+KU superdiagonales en las filas 1 a KL+KU+1,
!>          y los multiplicadores utilizados durante la factorización se almacenan
!>          en las filas KL+KU+2 a 2*KL+KU+1. Si EQUED .ne. 'N', entonces AFB
!>          es la forma factorizada de la matriz A equilibrada.
!>
!>          Si FACT = 'N', entonces AFB es un argumento de salida y en la salida
!>          devuelve detalles de la factorización LU de A.
!>
!>          Si FACT = 'E', entonces AFB es un argumento de salida y en la salida
!>          devuelve detalles de la factorización LU de la matriz A equilibrada
!>          (ver la descripción de AB para la forma de la
!>          matriz equilibrada).
!>

LDAFB

!>          LDAFB es INTEGER
!>          La dimensión principal de la matriz AFB.  LDAFB >= 2*KL+KU+1.
!>

IPIV

!>          IPIV es una matriz INTEGER, dimensión (N)
!>          Si FACT = 'F', entonces IPIV es un argumento de entrada y en la entrada
!>          contiene los índices de pivote de la factorización A = L*U
!>          tal como fue calculada por ZGBTRF; la fila i de la matriz fue intercambiada
!>          con la fila IPIV(i).
!>
!>          Si FACT = 'N', entonces IPIV es un argumento de salida y en la salida
!>          contiene los índices de pivote de la factorización A = L*U
!>

de la matriz original A. !> !> Si FACT = 'E', entonces IPIV es un argumento de salida y, al !> salir, contiene los índices de pivote de la factorización !> A = L*U de la matriz A equilibrada. !>

EQUED

!>          EQUED es CHARACTER*1
!>          Especifica la forma de   equilibrio que se realizó.
!>          = 'N':  Sin   equilibrio (siempre cierto si FACT = 'N').
!>          = 'R':  Equilibrio de filas, es decir, A ha sido premultiplicada
!>                  por diag(R).
!>          = 'C':  Equilibrio de columnas, es decir, A ha sido postmultiplicada
!>                  por diag(C).
!>          = 'B':  Equilibrio tanto de filas como de columnas, es decir, A ha
!>                  sido reemplazada por diag(R) * A * diag(C).
!>          EQUED es un argumento de entrada si FACT = 'F'; de lo contrario,
!>          es un argumento de salida.
!>

R

!>          R es un array DOUBLE PRECISION, de dimensión (N)
!>          Los factores de escala de fila para A. Si EQUED = 'R' o 'B', A
!>          se multiplica por la izquierda por diag(R); si EQUED = 'N' o 'C',
!>          R no se accede. R es un argumento de entrada si FACT = 'F';
!>          de lo contrario, R es un argumento de salida. Si FACT = 'F' y
!>          EQUED = 'R' o 'B', cada elemento de R debe ser positivo.
!>

C

!>          C es un array DOUBLE PRECISION, de dimensión (N)
!>          Los factores de escala de columna para A. Si EQUED = 'C' o 'B',
!>          A se multiplica por la derecha por diag(C); si EQUED = 'N' o 'R',
!>          C no se accede. C es un argumento de entrada si FACT = 'F';
!>          de lo contrario, C es un argumento de salida. Si FACT = 'F' y
!>          EQUED = 'C' o 'B', cada elemento de C debe ser positivo.
!>

B

!>          B es un array COMPLEX*16, de dimensión (LDB,NRHS)
!>          A la entrada, la matriz del lado derecho B.
!>          A la salida,
!>          si EQUED = 'N', B no se modifica;
!>          si TRANS = 'N' y EQUED = 'R' o 'B', B se sobrescribe con
!>          diag(R)*B;
!>          si TRANS = 'T' o 'C' y EQUED = 'C' o 'B', B se sobrescribe
!>          con diag(C)*B.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B. LDB >= max(1,N).
!>

X

!>          X es un array COMPLEX*16, de dimensión (LDX,NRHS)
!>          Si INFO = 0 o INFO = N+1, la matriz solución X de NxNRHS
!>          del sistema original de ecuaciones. Tenga en cuenta que A y B
!>          se modifican a la salida si EQUED .ne. 'N', y la solución del
!>          sistema   equilibrado es inv(diag(C))*X si TRANS = 'N' y
!>          EQUED = 'C' o 'B', o inv(diag(R))*X si TRANS = 'T' o 'C'
!>          y EQUED = 'R' o 'B'.
!>

LDX

!>          LDX es INTEGER
!>          La dimensión principal del array X. LDX >= max(1,N).
!>

RCOND

!>          RCOND es DOUBLE PRECISION
!>          La estimación del recíproco del número de condición de la
!>          matriz A después del   equilibrio (si se realizó). Si RCOND
!>          es menor que la precisión de la máquina (en particular, si
!>          RCOND = 0), la matriz es singular con precisión de trabajo.
!>          Esta condición se indica con un código de retorno de INFO > 0.
!>

FERR

!>          FERR es un array DOUBLE PRECISION, de dimensión (NRHS)
!>          El límite de error hacia adelante estimado para cada vector solución
!>          X(j) (la j-ésima columna de la matriz solución X).
!>          Si XTRUE es la solución verdadera correspondiente a X(j), FERR(j)
!>          es un límite superior estimado para la magnitud del elemento más
!>          grande en (X(j) - XTRUE) dividido por la magnitud del elemento más
!>          grande en X(j). La estimación es tan fiable como la estimación
!>          para RCOND, y casi siempre es una ligera sobreestimación del
!>          error verdadero.
!>

BERR

!>          BERR es un array DOUBLE PRECISION, de dimensión (NRHS)
!>          El error hacia atrás relativo componente a componente de cada vector
!>          solución X(j) (es decir, el cambio relativo más pequeño en cualquier
!>          elemento de A o B que haga que X(j) sea una solución exacta).
!>

WORK

!>          WORK es un array COMPLEX*16, de dimensión (2*N)
!>

RWORK

!>          RWORK es un array DOUBLE PRECISION, de dimensión (MAX(1,N))
!>          A la salida, RWORK(1) contiene el factor de crecimiento del pivote
!>          recíproco norm(A)/norm(U). Se utiliza la norma . Si RWORK(1)
!>          es mucho menor que 1, la estabilidad de la factorización LU de la
!>          matriz (equilibrada) A podría ser pobre. Esto también significa
!>          que la solución X, el estimador de condición RCOND y el límite de
!>          error hacia adelante FERR podrían no ser fiables. Si la
!>          factorización falla con 0<INFO<=N, entonces RWORK(1) contiene el
!>          factor de crecimiento del pivote para las N columnas principales
!>          de A.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>          > 0:  si INFO = i, y i es
!>                <= N:  U(i,i) es exactamente cero. La factorización se ha
!>                       completado, pero el factor U es exactamente singular,
!>                       por lo que la solución y los límites de error no
!>                       pudieron calcularse. Se devuelve RCOND = 0.
!>                = N+1: U es no singular, pero RCOND es menor que la precisión
!>                       de la máquina, lo que significa que la matriz es
!>                       singular con precisión de trabajo. Sin embargo, la
!>                       solución y los límites de error se calculan porque
!>                       hay varias situaciones en las que la solución
!>                       calculada puede ser más precisa que lo que sugeriría
!>                       el valor de RCOND.
!>
