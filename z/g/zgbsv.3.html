DOCUMENTACIÓN DE FUNCIÓN/SUBRUTINA

subroutine zgbsv (integer n, integer kl, integer ku, integer nrhs, complex*16, dimension( ldab, * ) ab, integer ldab, integer, dimension( * ) ipiv, complex*16, dimension( ldb, * ) b, integer ldb, integer info)

ZGBSV calcula la solución al sistema de ecuaciones lineales A * X = B para matrices GB (controlador simple)

Propósito:

!>
!> ZGBSV calcula la solución a un sistema complejo de ecuaciones lineales
!> A * X = B, donde A es una matriz de banda de orden N con KL subdiagonales
!> y KU superdiagonales, y X y B son matrices N por NRHS.
!>
!> Se utiliza la descomposición LU con pivoteo parcial e intercambios de filas
!> para factorizar A como A = L * U, donde L es un producto de matrices de
!> permutación y triangulares inferiores unitarias con KL subdiagonales, y U es
!> triangular superior con KL+KU superdiagonales. La forma factorizada de A
!> se utiliza entonces para resolver el sistema de ecuaciones A * X = B.
!>

Parámetros

N 
!>          N es INTEGER
!>          El número de ecuaciones lineales, es decir, el orden de la
!>          matriz A.  N >= 0.
!>

KL

!>          KL es INTEGER
!>          El número de subdiagonales dentro de la banda de A.  KL >= 0.
!>

KU

!>          KU es INTEGER
!>          El número de superdiagonales dentro de la banda de A.  KU >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de lados derechos, es decir, el número de columnas
!>          de la matriz B.  NRHS >= 0.
!>

AB

!>          AB es array de COMPLEX*16, dimensión (LDAB,N)
!>          En la entrada, la matriz A en almacenamiento de banda, en las filas KL+1 a
!>          2*KL+KU+1; las filas 1 a KL del array no necesitan ser establecidas.
!>          La j-ésima columna de A se almacena en la j-ésima columna del
!>          array AB como sigue:
!>          AB(KL+KU+1+i-j,j) = A(i,j) para max(1,j-KU)<=i<=min(N,j+KL)
!>          En la salida, detalles de la factorización: U se almacena como una
!>          matriz de banda triangular superior con KL+KU superdiagonales en
!>          las filas 1 a KL+KU+1, y los multiplicadores utilizados durante la
!>          factorización se almacenan en las filas KL+KU+2 a 2*KL+KU+1.
!>          Ver más abajo para más detalles.
!>

LDAB

!>          LDAB es INTEGER
!>          La dimensión líder del array AB.  LDAB >= 2*KL+KU+1.
!>

IPIV

!>          IPIV es array de INTEGER, dimensión (N)
!>          Los índices de pivote que definen la matriz de permutación P;
!>          la fila i de la matriz fue intercambiada con la fila IPIV(i).
!>

B

!>          B es array de COMPLEX*16, dimensión (LDB,NRHS)
!>          En la entrada, la matriz B del lado derecho N por NRHS.
!>          En la salida, si INFO = 0, la matriz solución X N por NRHS.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión líder del array B.  LDB >= max(1,N).
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>          > 0:  si INFO = i, U(i,i) es exactamente cero. La factorización
!>                se ha completado, pero el factor U es exactamente
!>                singular y la solución no se ha calculado.
!>

Detalles adicionales:

!>
!>  El esquema de almacenamiento de banda se ilustra con el siguiente ejemplo,
!>  cuando M = N = 6, KL = 2, KU = 1:
!>
!>  En la entrada:                       En la salida:
!>
!>      *    *    *    +    +    +       *    *    *   u14  u25  u36
!>      *    *    +    +    +    +       *    *   u13  u24  u35  u46
!>      *   a12  a23  a34  a45  a56      *   u12  u23  u34  u45  u56
!>     a11  a22  a33  a44  a55  a66     u11  u22  u33  u44  u55  u66
!>     a21  a32  a43  a54  a65   *      m21  m32  m43  m54  m65   *
!>     a31  a42  a53  a64   *    *      m31  m42  m53  m64   *    *
!>
!>  Los elementos del array marcados con * no son utilizados por la subrutina;
!>  los elementos marcados con + no necesitan ser establecidos en la entrada,
!>  pero son requeridos por la subrutina para almacenar elementos de U debido
!>  al relleno resultante de los intercambios de filas.
!>
