ZGEJSV

Propósito:

!>
!> ZGEJSV calcula la descomposición en valores singulares (SVD) de una matriz
!> compleja M por N [A], donde M >= N. La SVD de [A] se escribe como
!>
!>              [A] = [U] * [SIGMA] * [V]^*,
!>
!> donde [SIGMA] es una matriz N por N (M por N) que es cero excepto por sus N
!> elementos diagonales, [U] es una matriz unitaria M por N (o M por M), y
!> [V] es una matriz unitaria N por N. Los elementos diagonales de [SIGMA] son
!> los valores singulares de [A]. Las columnas de [U] y [V] son los vectores
!> singulares izquierdos y derechos de [A], respectivamente. Las matrices [U] y [V]
!> se calculan y almacenan en los arreglos U y V, respectivamente. La diagonal
!> de [SIGMA] se calcula y almacena en el arreglo SVA.
!>

Parámetros

JOBA 
!>          JOBA es CHARACTER*1
!>         Especifica el nivel de precisión:
!>       = 'C': Esta opción funciona bien (alta precisión relativa) si A = B * D,
!>              con B bien condicionada y una matriz diagonal D arbitraria.
!>              La precisión no puede ser perjudicial por escalado de COLUMNA. La
!>              precisión de la salida calculada depende de la condición de
!>              B, y el procedimiento apunta a la mejor precisión teórica.
!>              El error relativo max_{i=1:N}|d sigma_i| / sigma_i está
!>              acotado por f(M,N)*epsilon* cond(B), independiente de D.
!>              La matriz de entrada se preprocesa con la QRF con pivoteo de columna.
!>              Este preprocesamiento inicial y precondicionamiento por
!>              una factorización QR de rango revelador es común para todos los valores de
!>              JOBA. Las acciones adicionales se especifican de la siguiente manera:
!>       = 'E': Cálculo como con 'C' con una estimación adicional del
!>              número de condición de B. Proporciona un límite de error realista.
!>       = 'F': Si A = D1 * C * D2 con escalados diagonales mal
!>              condicionados D1, D2, y una matriz C bien condicionada, esta opción da
!>              mayor precisión que la opción 'C'. Si la estructura de la
!>              matriz de entrada no se conoce, y se desea precisión relativa,
!>              entonces esta opción es recomendable. La matriz de entrada A
!>              se preprocesa con la factorización QR con pivoteo COMPLETO (filas y
!>              columnas).
!>       = 'G': Cálculo como con 'F' con una estimación adicional del
!>              número de condición de B, donde A=B*D. Si A tiene filas fuertemente ponderadas,
!>              entonces usar este número de condición da un límite de error demasiado pesimista.
!>       = 'A': Los valores singulares pequeños no están bien determinados por los datos
!>              y se consideran ruidosos; la matriz se trata como
!>              numéricamente de rango deficiente. El error en los valores singulares
!>              calculados está acotado por f(m,n)*epsilon*||A||.
!>              La SVD calculada A = U * S * V^* restaura A hasta
!>              f(m,n)*epsilon*||A||.
!>              Esto da al procedimiento licencia para descartar (poner a cero)
!>              todos los valores singulares por debajo de N*epsilon*||A||.
!>       = 'R': Similar a 'A'. La propiedad de rango revelador de la QR inicial
!>              factorización se usa para revelar (usando el factor triangular)
!>              una brecha sigma_{r+1} < epsilon * sigma_r en cuyo caso el
!>              RANGO numérico se declara como r. La SVD se calcula con
!>              límites de error absolutos, pero con más precisión que con 'A'.
!>

JOBU

!>          JOBU es CHARACTER*1
!>         Especifica si se calculan las columnas de U:
!>       = 'U': N columnas de U se devuelven en el arreglo U.
!>       = 'F': el conjunto completo de M vectores singulares izquierdos se
!>              devuelve en el arreglo U.
!>       = 'W': U puede usarse como espacio de trabajo de longitud M*N. Véase la
!>              descripción de U.
!>       = 'N': U no se calcula.
!>

JOBV

!>          JOBV es CHARACTER*1
!>         Especifica si se calcula la matriz V:
!>       = 'V': N columnas de V se devuelven en el arreglo V; las rotaciones de Jacobi
!>              no se acumulan explícitamente.
!>       = 'J': N columnas de V se devuelven en el arreglo V, pero se
!>              calculan como el producto de rotaciones de Jacobi, si JOBT = 'N'.
!>       = 'W': V puede usarse como espacio de trabajo de longitud N*N. Véase la
!>              descripción de V.
!>       = 'N': V no se calcula.
!>

JOBR

!>          JOBR es CHARACTER*1
!>         Especifica el RANGO para los valores singulares. Da licencia para
!>         poner a cero los valores singulares positivos pequeños si están fuera
!>         del rango especificado. Si A .NE. 0 se escala de manera que el valor
!>         singular más grande de c*A sea alrededor de SQRT(BIG), BIG=DLAMCH('O'),
!>         entonces JOBR da licencia para matar columnas de A cuyo norma en c*A es menor que
!>         SQRT(SFMIN) (para JOBR = 'R'), o menor que SMALL=SFMIN/EPSLN,
!>         donde SFMIN=DLAMCH('S'), EPSLN=DLAMCH('E').
!>       = 'N': No matar columnas pequeñas de c*A. Esta opción asume que
!>              BLAS y las factorizaciones QR y los solucionadores triangulares están
!>              implementados para trabajar en ese rango. Si la condición de A
!>              es mayor que BIG, use ZGESVJ.
!>       = 'R': Rango RESTRINGIDO para sigma(c*A) es [SQRT(SFMIN), SQRT(BIG)]
!>              (aproximadamente, como se describe arriba). Esta opción es recomendable.
!>                                             ===========================
!>         Para calcular los valores singulares en el rango COMPLETO [SFMIN,BIG]
!>         use ZGESVJ.
!>

JOBT

!>          JOBT es CHARACTER*1
!>         Si la matriz es cuadrada, el procedimiento puede decidir usar la A
!>         transpuesta si A^* parece ser mejor con respecto a la convergencia.
!>         Si la matriz no es cuadrada, JOBT se ignora.
!>         La decisión se basa en dos valores de entropía sobre la órbita adjunta
!>         de A^* * A. Véanse las descripciones de RWORK(6) y RWORK(7).
!>       = 'T': transponer si la prueba de entropía indica posiblemente una convergencia
!>              más rápida del proceso de Jacobi si A^* se toma como entrada. Si A se
!>              reemplaza con A^*, entonces el pivoteo de fila se incluye automáticamente.
!>       = 'N': no especular.
!>         La opción 'T' puede usarse para calcular solo los valores singulares, o
!>         la SVD completa (U, SIGMA y V). Para un solo conjunto de vectores singulares
!>         (U o V), el llamador debe proporcionar tanto U como V, ya que una de las
!>         matrices se usa como espacio de trabajo si la matriz A se transpone.
!>         El implementador puede eliminar fácilmente esta restricción y hacer el
!>         código más complicado. Véanse las descripciones de U y V.
!>         En general, esta opción se considera experimental, y se debe preferir
!>         'N';. Esto está sujeto a cambios en el futuro.
!>

JOBP

!>          JOBP es CHARACTER*1
!>         Da licencia para introducir perturbaciones estructuradas para ahogar
!>         números desnormalizados. Esta licencia debería estar activa si los
!>         desnormalizados

Function/Subroutine Documentation


The subroutine called is ZGEJSV




    ZGEJSV computes the singular value decomposition (SVD) of a complex
    general rectangular matrix A.
    The SVD is A = U * S * V^H, where S is an upper triangular matrix
    with real non-negative diagonal entries and zero strictly lower
    triangular entries, and U and V are unitary matrices.
    
    The decomposition is computed using an iterative Jacobi SVD algorithm.
    
    The algorithm exploits the following properties:
    
    1. The SVD of a matrix A is related to the SVD of a triangular matrix B
       obtained by pre-processing A.
       
    2. The SVD of a triangular matrix T can be computed efficiently using
       block Jacobi rotations.
    
    The algorithm is robust and it can handle the full range of singular values
    from underflow to overflow, provided that the machine arithmetic and the
    BLAS and LAPACK routines called by ZGEJSV are implemented to work in that
    range. If that is not the case, then the restriction for safe computation
    with the singular values in the range of normalized IEEE numbers is that the
    spectral condition number kappa(A) = sigma_max(A) / sigma_min(A) does not
    overflow. This code (ZGEJSV) is best used in this restricted range,
    meaning that singular values of magnitude below ||A||_2 / DLAMCH('O') are
    returned as zeros. See JOBR for details on this.
    
    The following options are available:
    
    - Compute only the singular values of A.
    - Compute the singular values of A and the left singular vectors U.
    - Compute the singular values of A and the right singular vectors V.
    - Compute the singular values of A and both the left and the right singular
      vectors U and V.
    
    In addition, the algorithm computes the rank revealing QR factorization
    of A as a pre-processing step, and it can optionally use A^* to compute
    the SVD, which can increase the accuracy in some cases.
    
    Arguments:
    
    JOBA    (input) CHARACTER*1
            Specifies the computation of the rank revealing QR factorization
            of A:
            = 'C': Compute the rank revealing QR factorization of A.
            = 'N': No rank revealing QR factorization is computed.
            = 'F': Compute the rank revealing QR factorization of A^H.
            = 'G': Compute the rank revealing QR factorization of A^H.
                   This is identical to 'F'.
            = 'A': Compute the rank revealing QR factorization of either A
                   or A^H.
            
    JOBV    (input) CHARACTER*1
            Specifies the computation of the right singular vectors V:
            = 'N': No right singular vectors are computed.
            = 'V': The right singular vectors V are computed.
            = 'J': The right singular vectors J are computed. J is a
                   lower triangular matrix and has the same structure as
                   the upper triangular matrix S returned by ZGESVD.
            
    JOBT    (input) CHARACTER*1
            Specifies the computation of the upper triangular matrix T:
            = 'N': The upper triangular matrix T is not computed.
            = 'T': The upper triangular matrix T is computed.
            
    JOBU    (input) CHARACTER*1
            Specifies the computation of the left singular vectors U:
            = 'N': No left singular vectors are computed.
            = 'U': The left singular vectors U are computed.
            = 'F': The full left singular vectors U are computed.

            The number of rows of the matrix A. M >= 0.
            
    N       (input) INTEGER
            The number of columns of the matrix A. N >= 0.

            On entry, the M-by-N matrix A.
            On exit, the factors R from the rank revealing QR factorization of A
            or A^H are stored in the upper triangular part of A.

            The leading dimension of the array A. LDA >= max(1, M).

            descending order.

            On exit, E contains zeros.

            On exit, if JOBV = 'U' or JOBV = 'J', U contains the left
            singular vectors of A, K = M.
            If JOBV = 'V', U contains the left singular vectors of A, K = M.
            If JOBU = 'U' or JOBU = 'F', U contains the left singular vectors
            of A, K = M.
            If JOBU = 'N', U is not used.
            
    LDU     (input) INTEGER
            The leading dimension of the array U.
            If JOBU = 'U' or JOBU = 'F', LDU >= max(1, M).
            If JOBU = 'N', LDU >= 1.
            
    V       (output) DOUBLE COMPLEX array, dimension (LDV, K)
            On exit, if JOBV = 'V' or JOBV = 'J', V contains the right
            singular vectors of A, K = N.
            If JOBV = 'N', V is not used.
            
    LDV     (input) INTEGER
            The leading dimension of the array V.
            If JOBV = 'V' or JOBV = 'J', LDV >= max(1, N).
            If JOBV = 'N', LDV >= 1.
            
    T       (output) DOUBLE COMPLEX array, dimension (LDT, N)
            On exit, if JOBT = 'T', T contains the upper triangular matrix
            with the diagonal entries of the singular values and zeros
            in the strictly lower triangular part.
            If JOBT = 'N', T is not used.
            
    LDT     (input) INTEGER
            The leading dimension of the array T.
            If JOBT = 'T', LDT >= max(1, N).
            If JOBT = 'N', LDT >= 1.
            
    X       (output) DOUBLE COMPLEX array, dimension (M)
            On exit, if JOBV = 'J', X contains the diagonal entries of
            the upper triangular matrix S.
            If JOBV = 'N', X is not used.
            
    TOL     (input) DOUBLE PRECISION
            Tolerance for determining the rank of A. The rank is computed
            using the threshold max(M,N)*S(1)*TOL.

            On exit, if LRWORK = -1 or LWORK = -1, UWORK(1) contains the
            required length of UWORK.
            
    LRWORK  (input) INTEGER
            The dimension of the array UWORK.

            On exit, IWORK contains the following information:
            IWORK(1) = the numerical rank determined after the initial
                       QR factorization with pivoting. See the descriptions
                       of JOBA and JOBR.
            IWORK(2) = the number of the computed nonzero singular values.
            IWORK(3) = if nonzero, a warning message:
                       If IWORK(3) = 1 then some of the column norms of A
                       were denormalized floats. The requested high accuracy
                       is not warranted by the data.
            IWORK(4) = 1 or -1. If IWORK(4) = 1, then the procedure used A^* to

            If the call to ZGEJSV is a workspace query (indicated by LWORK = -1 or
            LRWORK = -1), then on exit IWORK(1) contains the required length of

            > 0: ZGEJSV did not converge in the maximal allowed number
                 of sweeps. The computed values may be inaccurate.
            
    Workspace considerations:
    
    The minimum and recommended workspace sizes for UWORK are
    LRWORK = max( 7, 2*N ) and LRWORK = max( 7, 2*N + 2*M ) respectively.
    
    The minimum and recommended workspace sizes for IWORK are
    max( 4, N ) and max( 4, N + M ) respectively.
    
    
    Workspace query:

    and recommended workspace sizes for UWORK and IWORK, respectively, and

    1. If only the singular values are requested, i.e.
       .NOT.(LSAME(JOBU,'U').OR.LSAME(JOBU,'F')) .AND.
       .NOT.(LSAME(JOBV,'V').OR.LSAME(JOBV,'J'))
       then:
       1.1. If LSAME(JOBT,'T') .OR. LSAME(JOBA,'F') .OR. LSAME(JOBA,'G'),
       then LRWORK = max( 7, 2 * M ).
       1.2. Otherwise, LRWORK  = max( 7, N ).
       
    2. If singular values with the right singular vectors are requested
       i.e. if
       (LSAME(JOBV,'V').OR.LSAME(JOBV,'J')) .AND.
       .NOT.(LSAME(JOBU,'U').OR.LSAME(JOBU,'F'))
       then:
       2.1. If LSAME(JOBT,'T') .OR. LSAME(JOBA,'F') .OR. LSAME(JOBA,'G'),
       then LRWORK = max( 7, 2 * M ).
       2.2. Otherwise, LRWORK  = max( 7, N ).
       
    3. If singular values with the left singular vectors are requested, i.e. if
       (LSAME(JOBU,'U').OR.LSAME(JOBU,'F')) .AND.
       .NOT.(LSAME(JOBV,'V').OR.LSAME(JOBV,'J'))
       then:
       3.1. If LSAME(JOBT,'T') .OR. LSAME(JOBA,'F') .OR. LSAME(JOBA,'G'),

       3.2. Otherwise, LRWORK  = max( 7, N ).

       are requested, i.e. if
       (LSAME(JOBU,'U').OR.LSAME(JOBU,'F')) .AND.
       (LSAME(JOBV,'V').OR.LSAME(JOBV,'J'))
       then:
       4.1. If LSAME(JOBT,'T') .OR. LSAME(JOBA,'F') .OR. LSAME(JOBA,'G'),
       then LRWORK = max( 7, 2 * M ).
       4.2. Otherwise, LRWORK  = max( 7, N ).

    the length of RWORK is returned in RWORK(1).

    IWORK is INTEGER array, of dimension at least 4, that further depends

       If ( LSAME(JOBT,'T') .OR. LSAME(JOBA,'F') .OR. LSAME(JOBA,'G') )

    2. If the singular values and the right singular vectors are requested then:
       If ( LSAME(JOBT,'T') .OR. LSAME(JOBA,'F') .OR. LSAME(JOBA,'G') )
       then the length of IWORK is N+M; otherwise the length of IWORK is N.
    3. If the singular values and the left singular vectors are requested then:
       If ( LSAME(JOBT,'T') .OR. LSAME(JOBA,'F') .OR. LSAME(JOBA,'G') )
       then the length of IWORK is N+M; otherwise the length of IWORK is N.
    4. If the singular values with both the left and the right singular vectors

       4.1. If LSAME(JOBV,'J') the length of IWORK is determined as follows:

Further Details:




    ZGEJSV implements a preconditioned Jacobi SVD algorithm. It uses ZGEQP3,
    ZGEQRF, and ZGELQF as preprocessors and preconditioners. Optionally, an
    additional row pivoting can be used as a preprocessor, which in some
    cases results in much higher accuracy. An example is matrix A with the
    structure A = D1 * C * D2, where D1, D2 are arbitrarily ill-conditioned
    diagonal matrices and C is well-conditioned matrix. In that case, complete
    pivoting in the first QR factorizations provides accuracy dependent on the
    condition number of C, and independent of D1, D2. Such higher accuracy is
    not completely understood theoretically, but it works well in practice.
    Further, if A can be written as A = B*D, with well-conditioned B and some
    diagonal D, then the high accuracy is guaranteed, both theoretically and
    in software, independent of D. For more details see [1], [2].
    The computational range for the singular values can be the full range
    ( UNDERFLOW,OVERFLOW ), provided that the machine arithmetic and the BLAS
    & LAPACK routines called by ZGEJSV are implemented to work in that range.
    If that is not the case, then the restriction for safe computation with
    the singular values in the range of normalized IEEE numbers is that the
    spectral condition number kappa(A)=sigma_max(A)/sigma_min(A) does not
    overflow. This code (ZGEJSV) is best used in this restricted range,
    meaning that singular values of magnitude below ||A||_2 / DLAMCH('O') are
    returned as zeros. See JOBR for details on this.
    Further, this implementation is somewhat slower than the one described
    in [1,2] due to replacement of some non-LAPACK components, and because
    the choice of some tuning parameters in the iterative part (ZGESVJ) is
    left to the implementer on a particular machine.
    The rank revealing QR factorization (in this code: ZGEQP3) should be
    implemented as in [3]. We have a new version of ZGEQP3 under development
    that is more robust than the current one in LAPACK, with a cleaner cut in
    rank deficient cases. It will be available in the SIGMA library [4].
    If M is much larger than N, it is obvious that the initial QRF with
    column pivoting can be preprocessed by the QRF without pivoting. That
    well known trick is not used in ZGEJSV because in some cases heavy row
    weighting can be treated with complete pivoting. The overhead in cases
    M much larger than N is then only due to pivoting, but the benefits in
    terms of accuracy have prevailed. The implementer/user can incorporate
    this extra QRF step easily. The implementer can also improve data movement
    (matrix transpose, matrix copy, matrix transposed copy) - this
    implementation of ZGEJSV uses only the simplest, naive data movement.
