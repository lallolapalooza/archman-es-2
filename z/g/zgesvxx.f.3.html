ZGESVXX calcula la solución al sistema de ecuaciones lineales A * X = B para matrices GE

Propósito:

!>
!>    ZGESVXX utiliza la factorización LU para calcular la solución a un
!>    sistema de ecuaciones lineales complejo*16  A * X = B,  donde A es una
!>    matriz N por N y X y B son matrices N por NRHS.
!>
!>    Si se solicita, se devuelven cotas de error tanto normwise como
!>    componente a componente. ZGESVXX devolverá una solución con un error
!>    garantizado y minúsculo (O(eps) donde eps es la precisión de la máquina
!>    de trabajo) a menos que la matriz sea muy mal condicionada, en cuyo
!>    caso se devuelve una advertencia. También se calculan y devuelven
!>    los números de condición relevantes.
!>
!>    ZGESVXX acepta factorizaciones y factores de equilibrado proporcionados
!>    por el usuario; consulte las definiciones de las opciones FACT y EQUED.
!>    Resolver con refinamiento y usar una factorización de una llamada
!>    anterior a ZGESVXX también producirá una solución con errores O(eps)
!>    o advertencias, pero no podemos afirmar eso para factores de
!>    factorización y equilibrado proporcionados por el usuario en general
!>    si difieren de lo que ZGESVXX produciría por sí mismo.
!>

Descripción:

!>
!>    Se realizan los siguientes pasos:
!>
!>    1. Si FACT = 'E', se calculan factores de escala de doble precisión para equilibrar
!>    el sistema:
!>
!>      TRANS = 'N':  diag(R)*A*diag(C)     *inv(diag(C))*X = diag(R)*B
!>      TRANS = 'T': (diag(R)*A*diag(C))**T *inv(diag(R))*X = diag(C)*B
!>      TRANS = 'C': (diag(R)*A*diag(C))**H *inv(diag(R))*X = diag(C)*B
!>
!>    Independientemente de si el sistema se equilibrará o no, dependerá
!>    del escalado de la matriz A, pero si se utiliza el equilibrado, A se
!>    sobrescribe con diag(R)*A*diag(C) y B con diag(R)*B (si TRANS='N')
!>    o diag(C)*B (si TRANS = 'T' o 'C').
!>
!>    2. Si FACT = 'N' o 'E', se utiliza la descomposición LU para factorizar
!>    la matriz A (después del equilibrado si FACT = 'E') como
!>
!>      A = P * L * U,
!>
!>    donde P es una matriz de permutación, L es una matriz triangular inferior unitaria
!>    y U es triangular superior.
!>
!>    3. Si algún U(i,i)=0, de modo que U es exactamente singular, entonces la
!>    subrutina devuelve INFO = i. De lo contrario, la forma factorizada de A
!>    se utiliza para estimar el número de condición de la matriz A (ver
!>    argumento RCOND). Si la inversa del número de condición es menor que
!>    la precisión de la máquina, la subrutina continúa resolviendo para X
!>    y calculando cotas de error como se describe a continuación.
!>
!>    4. El sistema de ecuaciones se resuelve para X utilizando la forma factorizada
!>    de A.
!>
!>    5. Por defecto (a menos que PARAMS(LA_LINRX_ITREF_I) se establezca en cero),
!>    la subrutina utilizará refinamiento iterativo para intentar obtener un
!>    pequeño error y cotas de error. El refinamiento calcula el residuo con
!>    al menos el doble de la precisión de trabajo.
!>
!>    6. Si se utilizó el equilibrado, la matriz X se premultiplica por
!>    diag(C) (si TRANS = 'N') o diag(R) (si TRANS = 'T' o 'C') para
!>    que resuelva el sistema original antes del equilibrado.
!> 
!>     Algunos parámetros opcionales están agrupados en la matriz PARAMS. Estas
!>     configuraciones determinan cómo se realiza el refinamiento, pero a menudo
!>     los valores predeterminados son aceptables. Si los valores predeterminados son aceptables, los usuarios
!>     pueden pasar NPARAMS = 0, lo que evita que el código fuente acceda
!>     al argumento PARAMS.
!>

Parámetros

FACT 
!>          FACT es CHARACTER*1
!>     Especifica si la forma factorizada de la matriz A se
!>     proporciona en la entrada, y si no, si la matriz A debe ser
!>     equilibrada antes de ser factorizada.
!>       = 'F':  En la entrada, AF e IPIV contienen la forma factorizada de A.
!>               Si EQUED no es 'N', la matriz A ha sido
!>               equilibrada con factores de escala dados por R y C.
!>               A, AF e IPIV no se modifican.
!>       = 'N':  La matriz A se copiará a AF y se factorizará.
!>       = 'E':  La matriz A se equilibrará si es necesario, luego
!>               se copiará a AF y se factorizará.
!>

TRANS

!>          TRANS es CHARACTER*1
!>     Especifica la forma del sistema de ecuaciones:
!>       = 'N':  A * X = B     (Sin transposición)
!>       = 'T':  A**T * X = B  (Transpuesta)
!>       = 'C':  A**H * X = B  (Transpuesta conjugada)
!>

N

             UPLO, TRANS, N, NRHS, A, LDA, B, LDB,

Function/Subroutine Documentation

!> \brief \
!> ZGESVXX solves a general system of linear equations AX = B with
!> ZGSVXX.
!>
!> Details
!> =======
!>
!> The routine ZGESVXX computes the solution to a general system of linear
!> equations AX = B, where A is an N-by-N complex matrix and X and B are
!> N-by-NRHS complex matrices. Error bounds are computed for the solution.
!>
!> ZGESVXX is a driver routine that calls the auxiliary routines:
!>    - ZLAGvx
!>    - ZLATvx
!>
!> It is not guaranteed to be more efficient than calling the auxiliary
!> routines.
!>
!> The problem is solved in the following steps:
!>
!> 1. Equilibration:
!>    If Equil is not FALSE, the routine may equilibrate the matrix A in
!>    order to reduce the likelihood of underflow or overflow during
!>    computation. As part of equilibration, the routine may perform a
!>    permutating of the rows and columns. Let P and Q be permutation
!>    matrices such that
!>       P*A*Q = S*A',
!>    where S is a diagonal matrix and A' is still a general matrix.
!>    The system A*X = B becomes S*A'*Q^T*X = P*B.
!>    Let X be the solution. Then Q*X is the solution of the original
!>    system.
!>
!> 2. Factorization:
!>    The routine factorizes the scaled matrix A'.
!>
!> 3. Solution:
!>    The scaled system is solved using the factorization.
!>
!> 4. Computing Error Bounds:
!>    The routines ZLATvx computes the condition number and error bounds
!>    for the solution.
!>
!> 5. Computing Rcond:
!>    The routine ZLAGvx computes the reciprocal pivot growth factor
!>    Rcond. This is used to estimate the condition number of the
!>    matrix.
!>
!> 6. Unsquaring:
!>    If equilibration was performed, the solution is back-transformed
!>    to the original problem.
!>
!> Usage
!> =====
!>
!> Complex*16
!>
!> SUBROUTINE ZGESVXX( UPLO, TRANS, N, NRHS, A, LDA, B, LDB,
!>                     SWP, EQUED, RCOND, RPv, AF, LDAF, BWork,
!>                     INFO, PARAMS )
!>
!> Arguments
!> =========
!>
!> UPLO (CHARACTER*1)
!>          = 'U': Upper triangle of A is stored;
!>          = 'L': Lower triangle of A is stored.
!>
!> TRANS (CHARACTER*1)
!>          = 'N': No transpose, A is                  A      .
!>          = 'T': Transpose,  A is                  A**H   .
