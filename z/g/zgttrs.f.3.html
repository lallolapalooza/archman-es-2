Documentación de Función/Subrutina

subrutina zgttrs (character trans, integer n, integer nrhs, complex*16, dimension( * ) dl, complex*16, dimension( * ) d, complex*16, dimension( * ) du, complex*16, dimension( * ) du2, integer, dimension( * ) ipiv, complex*16, dimension( ldb, * ) b, integer ldb, integer info)

ZGTTRS

Propósito:

!>
!> ZGTTRS resuelve uno de los sistemas de ecuaciones
!>    A * X = B,  A**T * X = B,  o  A**H * X = B,
!> con una matriz tridiagonal A utilizando la factorización LU calculada
!> por ZGTTRF.
!>

Parámetros

TRANS 
!>          TRANS es CHARACTER*1
!>          Especifica la forma del sistema de ecuaciones.
!>          = 'N':  A * X = B     (Sin transpuesta)
!>          = 'T':  A**T * X = B  (Transpuesta)
!>          = 'C':  A**H * X = B  (Transpuesta conjugada)
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de lados derechos, es decir, el número de columnas
!>          de la matriz B.  NRHS >= 0.
!>

DL

!>          DL es un array COMPLEX*16, dimensión (N-1)
!>          Los (n-1) multiplicadores que definen la matriz L de la
!>          factorización LU de A.
!>

D

!>          D es un array COMPLEX*16, dimensión (N)
!>          Los n elementos diagonales de la matriz triangular superior U de
!>          la factorización LU de A.
!>

DU

!>          DU es un array COMPLEX*16, dimensión (N-1)
!>          Los (n-1) elementos de la primera superdiagonal de U.
!>

DU2

!>          DU2 es un array COMPLEX*16, dimensión (N-2)
!>          Los (n-2) elementos de la segunda superdiagonal de U.
!>

IPIV

!>          IPIV es un array INTEGER, dimensión (N)
!>          Los índices de pivote; para 1 <= i <= n, la fila i de la matriz fue
!>          intercambiada con la fila IPIV(i).  IPIV(i) siempre será
!>          i o i+1; IPIV(i) = i indica que no se requirió un intercambio de filas.
!>

B

!>          B es un array COMPLEX*16, dimensión (LDB,NRHS)
!>          En la entrada, la matriz de vectores del lado derecho B.
!>          En la salida, B se sobrescribe con los vectores solución X.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B.  LDB >= max(1,N).
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -k, el k-ésimo argumento tuvo un valor ilegal
!>
