subrutina zgeqlf (integer m, integer n, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( * ) tau, complex*16, dimension( * ) work, integer lwork, integer info)

ZGEQLF

Propósito:

!>
!> ZGEQLF calcula una factorización QL de una matriz compleja M por N, A:
!> A = Q * L.
!>

Parámetros

M 
!>          M es INTEGER
!>          El número de filas de la matriz A.  M >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz A.  N >= 0.
!>

A

!>          A es un array COMPLEX*16, dimensión (LDA,N)
!>          En la entrada, la matriz A de M por N.
!>          En la salida,
!>          si m >= n, el triángulo inferior de la submatriz
!>          A(m-n+1:m,1:n) contiene la matriz triangular inferior L de N por N;
!>          si m <= n, los elementos en y debajo de la superdiagonal (n-m)-ésima contienen la matriz trapezoidal inferior L de M por N;
!>          los elementos restantes, junto con el array TAU, representan la
!>          matriz unitaria Q como un producto de reflectores elementales
!>          (ver Más detalles).
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,M).
!>

TAU

!>          TAU es un array COMPLEX*16, dimensión (min(M,N))
!>          Los factores escalares de los reflectores elementales (ver Más
!>          detalles).
!>

WORK

!>          WORK es un array COMPLEX*16, dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK.
!>          LWORK >= 1, si MIN(M,N) = 0, y LWORK >= N en caso contrario.
!>          Para un rendimiento óptimo LWORK >= N*NB, donde NB es
!>          el tamaño de bloque óptimo.
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo del array WORK, devuelve
!>          este valor como la primera entrada del array WORK, y XERBLA no emite ningún mensaje de error
!>          relacionado con LWORK.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tuvo un valor ilegal
!>

Más detalles:

!>
!>  La matriz Q se representa como un producto de reflectores elementales
!>
!>     Q = H(k) . . . H(2) H(1), donde k = min(m,n).
!>
!>  Cada H(i) tiene la forma
!>
!>     H(i) = I - tau * v * v**H
!>
!>  donde tau es un escalar complejo, y v es un vector complejo con
!>  v(m-k+i+1:m) = 0 y v(m-k+i) = 1; v(1:m-k+i-1) se almacena en la salida en
!>  A(1:m-k+i-1,n-k+i), y tau en TAU(i).
!>
