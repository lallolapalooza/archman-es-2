Documentación de la función/subrutina

subrutina zgemlq (character side, character trans, integer m, integer n, integer k, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( * ) t, integer tsize, complex*16, dimension( ldc, * ) c, integer ldc, complex*16, dimension( * ) work, integer lwork, integer info)

ZGEMLQ

Propósito:

!>
!>     ZGEMLQ sobrescribe la matriz general real M por N C con
!>
!>                      SIDE = 'L'     SIDE = 'R'
!>      TRANS = 'N':      Q * C          C * Q
!>      TRANS = 'C':      Q**H * C       C * Q**H
!>      donde Q es una matriz unitaria compleja definida como el producto
!>      de reflectores elementales en bloque calculados por la factorización
!>      LQ de ancho corto (ZGELQ)
!>
!>

Parámetros

SIDE 
!>          SIDE es CHARACTER*1
!>          = 'L': aplicar Q o Q**H desde la Izquierda;
!>          = 'R': aplicar Q o Q**H desde la Derecha.
!>

TRANS

!>          TRANS es CHARACTER*1
!>          = 'N':  Sin transponer, aplicar Q;
!>          = 'C':  Transpuesta conjugada, aplicar Q**H.
!>

M

!>          M es INTEGER
!>          El número de filas de la matriz A.  M >=0.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz C. N >= 0.
!>

K

!>          K es INTEGER
!>          El número de reflectores elementales cuyo producto define
!>          la matriz Q.
!>          Si SIDE = 'L', M >= K >= 0;
!>          si SIDE = 'R', N >= K >= 0.
!>
!>

A

!>          A es un array COMPLEX*16, de dimensión
!>                               (LDA,M) si SIDE = 'L',
!>                               (LDA,N) si SIDE = 'R'
!>          Parte de la estructura de datos para representar Q tal como es devuelta por ZGELQ.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A. LDA >= max(1,K).
!>

T

!>          T es un array COMPLEX*16, de dimensión (MAX(5,TSIZE)).
!>          Parte de la estructura de datos para representar Q tal como es devuelta por ZGELQ.
!>

TSIZE

!>          TSIZE es INTEGER
!>          La dimensión del array T. TSIZE >= 5.
!>

C

!>          C es un array COMPLEX*16, de dimensión (LDC,N)
!>          En la entrada, la matriz C de M por N.
!>          En la salida, C es sobrescrita por Q*C o Q**H*C o C*Q**H o C*Q.
!>

LDC

!>          LDC es INTEGER
!>          La dimensión principal del array C. LDC >= max(1,M).
!>

WORK

!>          (espacio de trabajo) array COMPLEX*16, de dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK mínimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK. LWORK >= 1.
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo. La rutina
!>          sólo calcula el tamaño del array WORK, devuelve este
!>          valor como WORK(1), y XERBLA no emite ningún mensaje de error relacionado con WORK.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>
