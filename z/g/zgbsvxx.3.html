ZGBSVXX calcula la solución al sistema de ecuaciones lineales A * X = B para matrices GB

Propósito:

!>
!>    ZGBSVXX utiliza la factorización LU para calcular la solución a un
!>    sistema de ecuaciones lineales complex*16  A * X = B, donde A es una
!>    matriz N por N y X y B son matrices N por NRHS.
!>
!>    Si se solicita, se devuelven límites de error tanto normados como de
!>    máximo componente. ZGBSVXX devolverá una solución con un error garantizado
!>    diminuto (O(eps) donde eps es la precisión de la máquina de trabajo) a
!>    menos que la matriz sea muy mal condicionada, en cuyo caso se devuelve
!>    una advertencia. También se calculan y devuelven los números de condición
!>    relevantes.
!>
!>    ZGBSVXX acepta factorizaciones y factores de   equilibrio proporcionados por el usuario; véase las
!>    definiciones de las opciones FACT y EQUED.
!>    Resolver con refinamiento y usar una factorización de una llamada
!>    ZGBSVXX anterior también producirá una solución con errores O(eps) o
!>    advertencias, pero no podemos afirmar eso para factorizaciones y
!>    factores de equilibrio proporcionados por el usuario si difieren de lo
!>    que ZGBSVXX produciría por sí mismo.
!>

Descripción:

!>
!>    Se realizan los siguientes pasos:
!>
!>    1. Si FACT = 'E', se calculan factores de escala de doble precisión para equilibrar
!>    el sistema:
!>
!>      TRANS = 'N':  diag(R)*A*diag(C)     *inv(diag(C))*X = diag(R)*B
!>      TRANS = 'T': (diag(R)*A*diag(C))**T *inv(diag(R))*X = diag(C)*B
!>      TRANS = 'C': (diag(R)*A*diag(C))**H *inv(diag(R))*X = diag(C)*B
!>
!>    Si el sistema se va a equilibrar o no, depende del
!>    escalado de la matriz A, pero si se usa el equilibrio, A se
!>    sobrescribe con diag(R)*A*diag(C) y B con diag(R)*B (si TRANS='N')
!>    o diag(C)*B (si TRANS = 'T' o 'C').
!>
!>    2. Si FACT = 'N' o 'E', se utiliza la descomposición LU para factorizar
!>    la matriz A (después del equilibrio si FACT = 'E') como
!>
!>      A = P * L * U,
!>
!>    donde P es una matriz de permutación, L es una matriz triangular inferior unitaria
!>    y U es triangular superior.
!>
!>    3. Si algún U(i,i)=0, de modo que U sea exactamente singular, entonces la
!>    subrutina devuelve INFO = i. De lo contrario, la forma factorizada de A
!>    se utiliza para estimar el número de condición de la matriz A (véase
!>    el argumento RCOND). Si la inversa del número de condición es menor que
!>    la precisión de la máquina, la subrutina continúa resolviendo para X
!>    y calculando los límites de error como se describe a continuación.
!>
!>    4. El sistema de ecuaciones se resuelve para X utilizando la forma factorizada de A.
!>
!>    5. Por defecto (a menos que PARAMS(LA_LINRX_ITREF_I) se establezca en cero),
!>    la subrutina utilizará refinamiento iterativo para intentar obtener un error
!>    y límites de error pequeños. El refinamiento calcula el residuo con
!>    al menos el doble de la precisión de trabajo.
!>
!>    6. Si se utilizó el equilibrio, la matriz X se premultiplica por
!>    diag(C) (si TRANS = 'N') o diag(R) (si TRANS = 'T' o 'C') para
!>    que resuelva el sistema original antes del equilibrio.
!> 
!>     Algunos parámetros opcionales se agrupan en la matriz PARAMS. Estos
!>     ajustes determinan cómo se realiza el refinamiento, pero a menudo los
!>     valores predeterminados son aceptables. Si los valores predeterminados
!>     son aceptables, los usuarios pueden pasar NPARAMS = 0, lo que evita que
!>     el código fuente acceda al argumento PARAMS.
!>

Parámetros

FACT 
!>          FACT es CHARACTER*1
!>     Especifica si la forma factorizada de la matriz A se
!>     proporciona o no en la entrada, y si no, si la matriz A debe ser
!>     equilibrada antes de factorizarla.
!>       = 'F':  En la entrada, AF e IPIV contienen la forma factorizada de A.
!>               Si EQUED no es 'N', la matriz A ha sido
!>               equilibrada con los factores de escala dados por R y C.
!>               A, AF e IPIV no se modifican.
!>       = 'N':  La matriz A se copiará a AF y se factorizará.
!>       = 'E':  La matriz A se equilibrará si es necesario, luego
!>               se copiará a AF y se factorizará.
!>

TRANS

!>          TRANS es CHARACTER*1
!>     Especifica la forma del sistema de ecuaciones:
!>       = 'N':  A * X = B     (Sin transposición)
!>       = 'T':  A**T * X = B  (Transposición)
!>       = 'C':  A**H * X = B  (Transpuesta conjugada = Transpuesta)
!>

N

!>          N es INTEGER
!>     El número de ecuaciones lineales, es decir, el orden de
!>     la matriz A.  N >= 0.
!>

KL

!>          KL es INTEGER
!>     El número de subdiagonales dentro de la banda de A.  KL >= 0.
!>

KU

!>          KU es INTEGER
!>     El número de superdiagonales dentro de la banda de A.  KU >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>     El número de lados derechos, es decir, el número de columnas
!>     de las matrices B y X.  NRHS >= 0.
!>

AB

!>          AB es un array COMPLEX*16, dimensión (LDAB,N)
!>     En la entrada, la matriz A en almacenamiento de banda, en las filas 1 a KL+KU+1.
!>     La j-ésima columna de A se almacena en la j-ésima columna de la
!>     matriz AB como sigue:
!>     AB(KU+1+i-j,j) = A(i,j) para max(1,j-KU) <= i <= min(N,j+kl)
!>
!>     Si FACT = 'F' y EQUED no es 'N', entonces AB debe haber sido
!>     equilibrada por los factores de escala en R y/o C. AB no
!>     se modifica si FACT = 'F' o 'N', o si FACT = 'E' y
!>     EQUED = 'N' en la salida.
!>
!>     En la salida, si EQUED .ne. 'N', A se escala como sigue:
!>     EQUED = 'R':  A := diag(R) * A
!>     EQUED = 'C':  A := A * diag(C)
!>     EQUED = 'B':  A := diag(R) * A * diag(C).
!>

LDAB

!>          LDAB es INTEGER
!>     La dimensión principal de la matriz AB.  LDAB >= KL+KU+1.
!>

AFB

!>          AFB es un array COMPLEX*16, dimensión (LDAFB,N)
!>     Si FACT =
'F', entonces AFB es un argumento de entrada y en la entrada !> contiene detalles de la factorización LU de la matriz de banda !> A, como la calculó ZGBTRF. U se almacena como una matriz triangular superior !> de banda con KL+KU superdiagonales en las filas 1 a KL+KU+1, !> y los multiplicadores utilizados durante la factorización se almacenan !> en las filas KL+KU+2 a 2*KL+KU+1. Si EQUED .ne. 'N', entonces AFB es !> la forma factorizada de la matriz de equilibrated A. !> !> Si FACT = 'N', entonces AF es un argumento de salida y en la salida !> devuelve los factores L y U de la factorización A = P*L*U !> de la matriz original A. !> !> Si FACT = 'E', entonces AF es un argumento de salida y en la salida !> devuelve los factores L y U de la factorización A = P*L*U !> de la matriz equilibrada A (ver la descripción de A para !> la forma de la matriz equilibrada). !>

LDAFB

!>          LDAFB es ENTERO
!>     La dimensión principal del array AFB. LDAFB >= 2*KL+KU+1.
!>

IPIV

!>          IPIV es un array ENTERO, de dimensión (N)
!>     Si FACT = 'F', entonces IPIV es un argumento de entrada y en la entrada
!>     contiene los índices de pivote de la factorización A = P*L*U
!>     calculada por ZGETRF; la fila i de la matriz se intercambió
!>     con la fila IPIV(i).
!>
!>     Si FACT = 'N', entonces IPIV es un argumento de salida y en la salida
!>     contiene los índices de pivote de la factorización A = P*L*U
!>     de la matriz original A.
!>
!>     Si FACT = 'E', entonces IPIV es un argumento de salida y en la salida
!>     contiene los índices de pivote de la factorización A = P*L*U
!>     de la matriz equilibrada A.
!>

EQUED

!>          EQUED es un CHARACTER*1
!>     Especifica la forma de equilibrado que se realizó.
!>       = 'N':  Sin equilibrado (siempre verdadero si FACT = 'N').
!>       = 'R':  Equilibrado de fila, es decir, A se ha premultiplicado por
!>               diag(R).
!>       = 'C':  Equilibrado de columna, es decir, A se ha postmultiplicado
!>               por diag(C).
!>       = 'B':  Equilibrado de fila y columna, es decir, A ha sido
!>               reemplazado por diag(R) * A * diag(C).
!>     EQUED es un argumento de entrada si FACT = 'F'; de lo contrario, es un
!>     argumento de salida.
!>

R

!>          R es un array DOUBLE PRECISION, de dimensión (N)
!>     Los factores de escala de fila para A. Si EQUED = 'R' o 'B', A se
!>     multiplica a la izquierda por diag(R); si EQUED = 'N' o 'C', R
!>     no se accede. R es un argumento de entrada si FACT = 'F';
!>     de lo contrario, R es un argumento de salida. Si FACT = 'F' y
!>     EQUED = 'R' o 'B', cada elemento de R debe ser positivo.
!>     Si R es de salida, cada elemento de R es una potencia de la base.
!>     Si R es de entrada, cada elemento de R debe ser una potencia de la base
!>     para garantizar una solución confiable y estimaciones de error. La escala por
!>     potencias de la base no causa errores de redondeo a menos que el
!>     resultado sea un subdesbordamiento o desbordamiento. Los errores de redondeo durante la escala
!>     llevan a refinar con una matriz que no es equivalente a la
!>     matriz de entrada, produciendo estimaciones de error que pueden no ser
!>     confiables.
!>

C

!>          C es un array DOUBLE PRECISION, de dimensión (N)
!>     Los factores de escala de columna para A. Si EQUED = 'C' o 'B', A se
!>     multiplica a la derecha por diag(C); si EQUED = 'N' o 'R', C
!>     no se accede. C es un argumento de entrada si FACT = 'F';
!>     de lo contrario, C es un argumento de salida. Si FACT = 'F' y
!>     EQUED = 'C' o 'B', cada elemento de C debe ser positivo.
!>     Si C es de salida, cada elemento de C es una potencia de la base.
!>     Si C es de entrada, cada elemento de C debe ser una potencia de la base
!>     para garantizar una solución confiable y estimaciones de error. La escala por
!>     potencias de la base no causa errores de redondeo a menos que el
!>     resultado sea un subdesbordamiento o desbordamiento. Los errores de redondeo durante la escala
!>     llevan a refinar con una matriz que no es equivalente a la
!>     matriz de entrada, produciendo estimaciones de error que pueden no ser
!>     confiables.
!>

B

!>          B es un array COMPLEX*16, de dimensión (LDB,NRHS)
!>     En la entrada, la matriz B del lado derecho de N por NRHS.
!>     En la salida,
!>     si EQUED = 'N', B no se modifica;
!>     si TRANS = 'N' y EQUED = 'R' o 'B', B se sobrescribe con
!>        diag(R)*B;
!>     si TRANS = 'T' o 'C' y EQUED = 'C' o 'B', B se
!>        sobrescribe con diag(C)*B.
!>

LDB

!>          LDB es ENTERO
!>     La dimensión principal del array B. LDB >= max(1,N).
!>

X

!>          X es un array COMPLEX*16, de dimensión (LDX,NRHS)
!>     Si INFO = 0, la matriz de solución X de N por NRHS para el sistema original
!>     de ecuaciones. Tenga en cuenta que A y B se modifican en la salida
!>     si EQUED .ne. 'N', y la solución del sistema equilibrado es
!>     inv(diag(C))*X si TRANS = 'N' y EQUED = 'C' o 'B', o
!>     inv(diag(R))*X si TRANS = 'T' o 'C' y EQUED = 'R' o 'B'.
!>

LDX

!>          LDX es ENTERO
!>     La dimensión principal del array X. LDX >= max(1,N).
!>

RCOND

!>          RCOND es DOUBLE PRECISION
!>     Condición inversa escalada. Esta es una estimación de la
!>     condición inversa de Skeel de la matriz A después del
!>     equilibrado (si se realizó). Si es menor que la precisión de la máquina
!>     (en particular, si es cero), la matriz es singular
!>     para la precisión de trabajo. Tenga en cuenta que el error aún puede ser pequeño incluso
!>     si este número es muy pequeño y la matriz parece mal condicionada.
!>

RPVGRW

!>          RPVGRW es DOUBLE PRECISION
!>     Crecimiento inverso del pivote. En la salida, esto contiene el inverso del
!>     factor de crecimiento del pivote norm(A)/norm(U). Se utiliza la norma.
!>     Si esto es mucho menor que 1, entonces la estabilidad de
!>     la factorización LU de la matriz A (equilibrada) podría ser pobre.
!>     Esto también significa que la solución X, las condiciones estimadas
!>     y los límites de error podrían no ser confiables. Si la factorización falla con
!>     0<INFO<=N, entonces esto contiene el factor de crecimiento inverso del pivote
!>     para las columnas INFO principales de A. En ZGESVX, esta cantidad es
!>     devuelta en RWORK(1).
!>

BERR

!>          BERR es un array DOUBLE PRECISION, de dimensión (NRHS)
!>     Error relativo de retroceso componente a componente. Este es el
!>     error relativo de retroceso componente a componente de cada vector solución X(j)
!>     (es decir, el cambio relativo más pequeño en cualquier elemento de A o B que
!>     haga que X(j) sea una solución exacta).
!>

N_ERR_BNDS

!>          N_ERR_BNDS es ENTERO
!>     Número de límites de error a devolver para cada lado derecho
!>     y cada tipo (normwise o componente a componente). Ver ERR_BNDS_NORM y
!>     ERR_BNDS_COMP a continuación.
!>

ERR_BNDS_NORM

!>          ERR_BNDS_NORM es un array DOUBLE PRECISION, de dimensión (NRHS, N_ERR_BNDS)
!>     Para cada lado derecho, este array contiene información sobre
!>     varios límites de error y números de condición correspondientes al
!>     error relativo normwise, que se define de la siguiente manera:
!>
!>     Error relativo normwise en el i-ésimo vector solución:
!>             max_j (abs(XTRUE(j,i) - X(j,i)))
!>            ------------------------------
!>                  max_j abs(X(j,i))
!>
!>     El array está indexado por el tipo de información de error tal como se describe
!>     a continuación. Actualmente hay hasta tres piezas de información
!>     devueltas.
!>
!>     El primer índice en ERR_BNDS_NORM(i,:) corresponde al i-ésimo
!>     lado derecho.
!>
!>     El segundo índice en ERR_BNDS_NORM(:,err) contiene los siguientes
!>     tres campos:
!>     err = 1  booleano. Confiar en la respuesta si el
!>              número de condición inverso es menor que el umbral
!>              sqrt(n) * dlamch('Epsilon').
!>
!>     err = 2  límite de error: El error de avance estimado,
!>              casi con certeza dentro de un factor de 10 del error real
!>              siempre que la siguiente entrada sea mayor que el umbral
!>              sqrt(n) * dlamch('Epsilon'). Este límite de error solo debe
!>              confiarse si el booleano anterior es verdadero.
!>
!>     err = 3  Número de condición inverso: Estimado normwise
!>              número de condición inverso. Comparado con el umbral
!>              sqrt(n) * dlamch('Epsilon') para determinar si el error
!>              la estimación es . Estos números de condición inversos
!>              son 1 / (norm(Z^{-1},inf) * norm(Z,inf)) para alguna
!>              matriz Z escalada apropiadamente.
!>              Sea Z = S*A, donde S escala cada fila por una potencia de la
!>              base para que todas las sumas de filas absolutas de Z sean aproximadamente 1.
!>
!>     Ver Lapack Working Note 165 para más detalles y precauciones adicionales.
!>

ERR_BNDS_COMP


!>          ERR_BNDS_COMP es un array DOUBLE PRECISION, de dimensión (NRHS, N_ERR_BNDS)
!>     Para cada lado derecho, este array contiene información sobre
!>     varios límites de error y números de condición correspondientes al
!>     error relativo componente a componente, que se define de la siguiente manera:
!>
!>     Error relativo componente a componente en el i-ésimo vector solución:
!>                    abs(XTRUE(j,i) - X(j,i))
!>             max_j ----------------------
!>                         abs(X(j,i))
!>
!>     El array está indexado por el lado derecho i (del cual depende el
!>     error relativo componente a componente), y el tipo de información de error tal como se describe
!>     a continuación. Actualmente hay hasta tres piezas de información devueltas para cada lado derecho. Si
!>     la precisión componente a componente no se solicita (PARAMS(3) = 0.0), entonces
!>     ERR_BNDS_COMP no se accede. Si N_ERR_BNDS < 3, entonces como máximo
!>     se devuelven las primeras (:,N_ERR_BNDS) entradas.
!>
!>     El primer índice en ERR_BNDS_COMP(i,:) corresponde al i-ésimo
!>     lado derecho.
!>
!>     El segundo índice en ERR_BNDS_COMP(:,err) contiene los siguientes
!>     tres campos:
!>     err = 1  booleano. Confiar en la respuesta si el
!>              número de condición inverso es menor que el umbral
!>              sqrt(n) * dlamch('Epsilon').
!>
!>     err = 2  límite de error: El error de avance estimado,
!>              casi con certeza dentro de un factor de 10 del error real
!>              siempre que la siguiente entrada sea mayor que el umbral
!>              sqrt(n) * dlamch('Epsilon'). Este límite de error solo debe
!>              confiarse si el booleano anterior es verdadero.
!>
!>     err = 3  Número de condición inverso: Estimado componente a componente
!>              número de condición inverso. Comparado con el umbral
!>              sqrt(n) * dlamch('Epsilon') para determinar si el error
!>              la estimación es . Estos números de condición inversos
!>              son 1 / (norm(Z^{-1},inf) * norm(Z,inf)) para alguna
!>              matriz Z escalada apropiadamente.
!>              Sea Z = S*(A*diag(x)), donde x es la solución para el
!>              lado derecho actual y S escala cada fila de
!>              A*diag(x) por una potencia de la base para que todas las sumas de filas
!>              absolutas de Z sean aproximadamente 1.
!>
!>     Ver Lapack Working Note 165 para más detalles.

NAME


zgbsvxx


realigen zgbcon & zgbtrf & zgbtrs & zgbcon & zgbcon & zgbcon & zgbcon & zgbcon & zgbcon & zgbcon






SYNOPSIS


SUBROUTINE zgbsvxx( MATTYPE, TRANS, N, KL, KU, AB, LDAB, DIP, DL, DR, B,
& LDB, X, LDX, RCOND, FERR, BERR, WORK, RWORK, INFO )
CHARACTER(LEN=1) MATTYPE
CHARACTER(LEN=1) TRANS
INTEGER N, KL, KU, LDAB, LDB, LDX, INFO
INTEGER DIP( * ), DL( * ), DR( * )
COMPLEX*16 AB( LDAB, * ), B( LDB, * ), X( LDX, * ), WORK( * )
DOUBLE PRECISION RCOND, FERR( * ), BERR( * ), RWORK( * )







Function/Subroutine Documentation




zgbsvxx computes the solution to a complex general band system of linear
    equations


   A * X = B,



or the least squares solution, with iterative refinement, and error
    bounding.


The band system is defined by the complex matrix A of size N x N, which has
    KL sub-diagonals and KU super-diagonals.


A general band matrix is typically represented by a rectangular array AB of
    size (KL+KU+1) x N. The subdiagonal entries are stored in the first KL rows,
    the diagonal entries in the (KL+1)-th row, and the superdiagonal entries in
    the rows from KL+2 to KL+KU+1.


For example, if N=4, KL=1, KU=2, the matrix AB is:


   AB(1,1) = A(2,1)
   AB(2,1) = A(1,1)   AB(2,2) = A(2,2)   AB(2,3) = A(3,3)   AB(2,4) = A(4,4)
   AB(3,1) = A(3,2)   AB(3,3) = A(3,3)   AB(3,4) = A(4,4)
   AB(4,1) = A(4,2)   AB(4,2) = A(4,3)



This routine calls the following LAPACK routines:


   zgbtrf
   zgbtrs
   zgbcon



Arguments


MATTYPE


     MATTYPE is CHARACTER*1
     Specifies the form of the system of equations.
     = 'N': A*X = B, normal equations.
     = 'T': A' * X = B, where A' is the transpose of A.
     = 'C': A' * X = B, where A' is the conjugate transpose of A.
     = 'U': Upper triangular band.
     = 'L': Lower triangular band.
     = 'S': Symmetric band.
     = 'H': Hermitian band.
     In MATLAB, A' denotes conjugate transpose. If A is real, A' is A-transpose.
     MATTYPE = 'N' and 'T' are supported.
     MATTYPE = 'U', 'L', 'S', 'H' are supported.



TRANS


     TRANS is CHARACTER*1
     Specifies whether to solve the system or its transpose.
     = 'N': Solve A * X = B.
     = 'T': Solve A' * X = B.
     = 'C': Solve A' * X = B, where A' is the conjugate transpose of A.
     Only TRANS = 'N' is supported for non-triangular matrices.



N


     N is INTEGER
     The order of the band matrix A. N >= 0.



KL


     KL is INTEGER
     The number of sub-diagonals of the band matrix A. KL >= 0.



KU


     KU is INTEGER
     The number of super-diagonals of the band matrix A. KU >= 0.



AB


     AB is COMPLEX*16 array, dimension (LDAB,N)
     On entry, the N x N band matrix A in band storage format.
     On exit, AB is overwritten by details of its LU factorization.
     If MATTYPE = 'U' or 'L', AB is overwritten by its triangular factorization.
