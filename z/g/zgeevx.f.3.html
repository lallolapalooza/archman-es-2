subroutine zgeevx (character balanc, character jobvl, character jobvr, character sense, integer n, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( * ) w, complex*16, dimension( ldvl, * ) vl, integer ldvl, complex*16, dimension( ldvr, * ) vr, integer ldvr, integer ilo, integer ihi, double precision, dimension( * ) scale, double precision abnrm, double precision, dimension( * ) rconde, double precision, dimension( * ) rcondv, complex*16, dimension( * ) work, integer lwork, double precision, dimension( * ) rwork, integer info)

ZGEEVX calcula los valores propios y, opcionalmente, los vectores propios izquierdos y/o derechos para matrices GE

Propósito:

!>
!> ZGEEVX calcula para una matriz compleja N-por-N no simétrica A, los
!> valores propios y, opcionalmente, los vectores propios izquierdos y/o derechos.
!>
!> Opcionalmente, también calcula una transformación de balanceo para mejorar
!> el condicionamiento de los valores propios y vectores propios (ILO, IHI,
!> SCALE y ABNRM), recíprocos de los números de condición para los valores
!> propios (RCONDE), y recíprocos de los números de condición para los
!> vectores propios derechos (RCONDV).
!>
!> El vector propio derecho v(j) de A satisface
!>                  A * v(j) = lambda(j) * v(j)
!> donde lambda(j) es su valor propio.
!> El vector propio izquierdo u(j) de A satisface
!>               u(j)**H * A = lambda(j) * u(j)**H
!> donde u(j)**H denota la transpuesta conjugada de u(j).
!>
!> Los vectores propios calculados se normalizan para tener norma Euclidiana
!> igual a 1 y componente real más grande.
!>
!> Balancear una matriz significa permutar las filas y columnas para hacerla
!> más cercana a ser triangular superior, y aplicar una transformación de
!> similitud diagonal D * A * D**(-1), donde D es una matriz diagonal, para
!> hacer que sus filas y columnas sean más cercanas en norma y los números de
!> condición de sus valores propios y vectores propios sean menores. Para
!> una explicación más detallada del balanceo, consulte la sección 4.10.2
!> de la Guía del Usuario de LAPACK.
!>

Parámetros

BALANC 
!>          BALANC es CHARACTER*1
!>          Indica cómo la matriz de entrada debe ser escalada
!>          diagonalmente y/o permutada para mejorar el condicionamiento de sus
!>          valores propios.
!>          = 'N': No escalar ni permutar diagonalmente;
!>          = 'P': Realizar permutaciones para hacer la matriz más cercana a
!>                 ser triangular superior. No escalar diagonalmente;
!>          = 'S': Escalar diagonalmente la matriz, es decir, reemplazar A por
!>                 D*A*D**(-1), donde D es una matriz diagonal elegida
!>                 para que las filas y columnas de A tengan normas más
!>                 iguales. No permutar;
!>          = 'B': Escalar diagonalmente y permutar A.
!>
!>          Los recíprocos de los números de condición calculados serán para la
!>          matriz después del balanceo y/o permutación. La permutación no
!>          cambia los números de condición (en aritmética exacta), pero el
!>          balanceo sí.
!>

JOBVL

!>          JOBVL es CHARACTER*1
!>          = 'N': no se calculan los vectores propios izquierdos de A;
!>          = 'V': se calculan los vectores propios izquierdos de A.
!>          Si SENSE = 'E' o 'B', JOBVL debe ser = 'V'.
!>

JOBVR

!>          JOBVR es CHARACTER*1
!>          = 'N': no se calculan los vectores propios derechos de A;
!>          = 'V': se calculan los vectores propios derechos de A.
!>          Si SENSE = 'E' o 'B', JOBVR debe ser = 'V'.
!>

SENSE

!>          SENSE es CHARACTER*1
!>          Determina qué recíprocos de los números de condición se calculan.
!>          = 'N': no se calcula ninguno;
!>          = 'E': se calculan solo para valores propios;
!>          = 'V': se calculan solo para vectores propios derechos;
!>          = 'B': se calculan para valores propios y vectores propios derechos.
!>
!>          Si SENSE = 'E' o 'B', también deben calcularse los vectores propios
!>          izquierdos y derechos (JOBVL = 'V' y JOBVR = 'V').
!>

N

!>          N es INTEGER
!>          El orden de la matriz A. N >= 0.
!>

A

!>          A es un array COMPLEX*16, de dimensiones (LDA,N)
!>          En la entrada, la matriz N-por-N A.
!>          En la salida, A ha sido sobrescrita. Si JOBVL = 'V' o
!>          JOBVR = 'V', A contiene la forma de Schur de la versión
!>          balanceada de la matriz A.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A. LDA >= max(1,N).
!>

W

!>          W es un array COMPLEX*16, de dimensiones (N)
!>          W contiene los valores propios calculados.
!>

VL

!>          VL es un array COMPLEX*16, de dimensiones (LDVL,N)
!>          Si JOBVL = 'V', los vectores propios izquierdos u(j) se almacenan
!>          uno tras otro en las columnas de VL, en el mismo orden
!>          que sus valores propios.
!>          Si JOBVL = 'N', VL no se referencia.
!>          u(j) = VL(:,j), la j-ésima columna de VL.
!>

LDVL

!>          LDVL es INTEGER
!>          La dimensión principal del array VL. LDVL >= 1; si
!>          JOBVL = 'V', LDVL >= N.
!>

VR

!>          VR es un array COMPLEX*16, de dimensiones (LDVR,N)
!>          Si JOBVR = 'V', los vectores propios derechos v(j) se almacenan
!>          uno tras otro en las columnas de VR, en el mismo orden
!>          que sus valores propios.
!>          Si JOBVR = 'N', VR no se referencia.
!>          v(j) = VR(:,j), la j-ésima columna de VR.
!>

LDVR

!>          LDVR es INTEGER
!>          La dimensión principal del array VR. LDVR >= 1; si
!>          JOBVR = 'V', LDVR >= N.
!>

ILO

!>          ILO es INTEGER
!>

IHI

!>          IHI es INTEGER
!>          ILO e IHI son valores enteros determinados cuando A fue
!>          balanceada. El A(i,j) balanceado = 0 si I > J y
!>          J = 1,...,ILO-1 o I = IHI+1,...,N.
!>

SCALE

!>          SCALE es un array DOUBLE PRECISION, de dimensiones (N)
!>          Detalles de las permutaciones y factores de escala aplicados
!>          al balancear A. Si P(j) es el índice de la fila y columna
!>          intercambiada con la fila y columna j, y D(j) es el factor de
!>          escala aplicado a la fila y columna j, entonces
!>          SCALE(J) = P(J),    para J = 1,...,ILO-1
!>                   = D(J),    para J = ILO,...,IHI
!>                   = P(J)     para J = IHI+1,...,N.
!>          El orden en que se realizan los intercambios es de N a IHI+1,
!>          luego de 1 a ILO-1.
!>

ABNRM

!>          ABNRM es DOUBLE PRECISION
!>          La norma uno de la matriz balanceada (el máximo
!>          de la suma de valores absolutos de los elementos de cualquier columna).
!>

RCONDE

!>          RCONDE es un array DOUBLE PRECISION, de dimensiones (N)
!>          RCONDE(j) es el recíproco del número de condición del j-ésimo
!>          valor propio.
!>

LAPACK routine

NAME

zgeevx - computes for an N x N complex matrix A, the eigenvalues and, if desired, the left and right eigenvectors and the condition numbers for the eigenvalues and right eigenvectors.

SYNOPSIS

SUBROUTINE ZGEEVX(
 BALANC, SENSE, N, A, LDA, VL, LDVL, VR, LDVR,
 ILO, IHI, SCALE, ABNRM, RCONDV, WORK, LWORK, RWORK, INFO
)
CHARACTER * 1 BALANC
CHARACTER * 1 SENSE
INTEGER N
COMPLEX*16 A( LDA, * )
INTEGER LDA
COMPLEX*16 VL( LDVL, * )
INTEGER LDVL
COMPLEX*16 VR( LDVR, * )
INTEGER LDVR
INTEGER ILO

DOUBLE PRECISION ABNRM
DOUBLE PRECISION RCONDV( * )

Function/Subroutine Documentation

BALANC

CHARACTER*1. Specifies whether or not the balancing is done.

'N': No balancing is done.

'P': Rows and columns of A are permuted, but not scaled.

'S': Rows and columns of A are scaled but not permuted.

'B': Rows and columns of A are both permuted and scaled.

SENSE

CHARACTER*1. Determines which condition numbers are computed.

'N': None are computed.

'E': Only the condition numbers for the eigenvalues are computed.

'V': Only the condition numbers for the right eigenvectors are computed.

'B': Both the condition numbers for the eigenvalues and the right eigenvectors are computed.

N

INTEGER. The order of the matrix A. N >= 0.

A

COMPLEX*16 array, dimension (LDA, N).

On entry, the N-by-N general matrix A.

On exit, if BALANC = 'P' or 'B', A is permuted according to the permutation vector ILO to IHI. The blocked sections of A that have been scaled are left unscaled.

LDA

INTEGER. The leading dimension of the array A. LDA >= max(1,N).

VL

COMPLEX*16 array, dimension (LDVL, N).

If ILO <= i <= IHI, VL(i,j) contains the j-th left eigenvector of the matrix A. The eigenvectors are normalized so that the maximum absolute value of each normally scaled eigenvector is 1.

For j < ILO or j > IHI, VL(j,j) is set to 1.

The output eigenvectors depend on the scaling of the matrix performed by BALANC. If the matrix A is not balanced, the eigenvectors are correct. If the matrix A is balanced, the output eigenvectors are computed for the balanced matrix and are returned in the array VL.

LDVL

INTEGER. The leading dimension of the array VL. LDVL >= 1. If HOWMNY = 'R' or 'B', LDVL >= N.

VR

COMPLEX*16 array, dimension (LDVR, N).

If ILO <= i <= IHI, VR(i,j) contains the j-th right eigenvector of the matrix A. The eigenvectors are normalized so that the maximum absolute value of each normally scaled eigenvector is 1.

For j < ILO or j > IHI, VR(j,j) is set to 1.

The output eigenvectors depend on the scaling of the matrix performed by BALANC. If the matrix A is not balanced, the eigenvectors are correct. If the matrix A is balanced, the output eigenvectors are computed for the balanced matrix and are returned in the array VR.

LDVR

INTEGER. The leading dimension of the array VR. LDVR >= 1. If HOWMNY = 'L' or 'B', LDVR >= N.

ILO

INTEGER.

ILO and IHI determine out of N which rows and columns of A are in the final rebalanced matrix for which the eigenvectors are to be computed.

1 <= ILO <= IHI <= N.

IHI

INTEGER.

SCALE

DOUBLE PRECISION array, dimension (N).

Details of the row and column scaling factors computed when BALANC = 'S' or 'B'. The j-th diagonal element of the balanced matrix is A(j,j)*SCALE(j). The range of each element in SCALE is [0.6D0, 1.6D0] or 1.0 if no scaling occurred.

ABNRM

DOUBLE PRECISION. The 1-norm of the balanced matrix. If SALENT = 'N', ABNRM is not computed.

RCONDV

DOUBLE PRECISION array, dimension (N).

RCONDV(j) is the reciprocal condition number of the j-th right eigenvector.

WORK

COMPLEX*16 array, dimension (MAX(1,LWORK)).

On exit, if INFO = 0, WORK(1) returns the optimal LWORK.

LWORK

INTEGER. The dimension of the array WORK. If SENSE = 'N' or 'E', LWORK >= max(1,2*N), and if SENSE = 'V' or 'B', LWORK >= N*N+2*N.

For good performance, LWORK must generally be larger.

If LWORK = -1, then a workspace query is assumed; the routine only calculates the optimal size of the WORK array, returns this value as the first entry of the WORK array, and no error message related to LWORK is issued by XERBLA.

RWORK

DOUBLE PRECISION array, dimension (2*N).

INFO

INTEGER.

= 0: successful exit.

< 0: if INFO = -i, the i-th argument had an illegal value.

> 0: if INFO = i, the QR algorithm failed to compute all the eigenvalues, and no eigenvectors or condition numbers have been computed; elements 1:ILO-1 and i+1:N of W contain eigenvalues which have converged.
