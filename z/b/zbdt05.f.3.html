DOCUMENTACIÓN DE FUNCIÓN/SUBRUTINA

subrutina zbdt05 (entero m, entero n, complejo*16, dimensión( lda, * ) a, entero lda, doble precisión, dimensión( * ) s, entero ns, complejo*16, dimensión( * ) u, entero ldu, complejo*16, dimensión( ldvt, * ) vt, entero ldvt, complejo*16, dimensión( * ) work, doble precisión resid)

ZBDT05

Propósito:

!>
!> ZBDT05 reconstruye una matriz bidiagonal B a partir de su SVD (parcial):
!>    S = U' * B * V
!> donde U y V son matrices ortogonales y S es diagonal.
!>
!> La relación de prueba para probar la descomposición en valores singulares es
!>    RESID = norm( S - U' * B * V ) / ( n * norm(B) * EPS )
!> donde VT = V' y EPS es la precisión de la máquina.
!>

Parámetros

M 
!>          M es ENTERO
!>          El número de filas de las matrices A y U.
!>

N

!>          N es ENTERO
!>          El número de columnas de las matrices A y VT.
!>

A

!>          A es una matriz COMPLEX*16, dimensión (LDA,N)
!>          La matriz A de m por n.
!>

LDA

!>          LDA es ENTERO
!>          La dimensión principal del array A.  LDA >= max(1,M).
!>

S

!>          S es un array DOUBLE PRECISION, dimensión (NS)
!>          Los valores singulares de la SVD (parcial) de B, ordenados en
!>          orden decreciente.
!>

NS

!>          NS es ENTERO
!>          El número de valores/vectores singulares de la SVD (parcial)
!>          de B.
!>

U

!>          U es un array COMPLEX*16, dimensión (LDU,NS)
!>          La matriz ortogonal U de n por ns en S = U' * B * V.
!>

LDU

!>          LDU es ENTERO
!>          La dimensión principal del array U.  LDU >= max(1,N)
!>

VT

!>          VT es un array COMPLEX*16, dimensión (LDVT,N)
!>          La matriz ortogonal V de n por ns en S = U' * B * V.
!>

LDVT

!>          LDVT es ENTERO
!>          La dimensión principal del array VT.
!>

WORK

!>          WORK es un array COMPLEX*16, dimensión (M,N)
!>

RESID

!>          RESID es DOUBLE PRECISION
!>          La relación de prueba:  norm(S - U' * A * V) / ( n * norm(A) * EPS )
!>
