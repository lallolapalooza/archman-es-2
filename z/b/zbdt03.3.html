DOCUMENTACIÓN DE FUNCIÓN/SUBRUTINA

subrutina zbdt03 (character uplo, integer n, integer kd, double precision, dimension( * ) d, double precision, dimension( * ) e, complex*16, dimension( ldu, * ) u, integer ldu, double precision, dimension( * ) s, complex*16, dimension( ldvt, * ) vt, integer ldvt, complex*16, dimension( * ) work, double precision resid)

ZBDT03

Propósito:

!>
!> ZBDT03 reconstruye una matriz bidiagonal B a partir de su SVD:
!>    S = U' * B * V
!> donde U y V son matrices ortogonales y S es diagonal.
!>
!> La relación de prueba para probar la descomposición en valores singulares es
!>    RESID = norm( B - U * S * VT ) / ( n * norm(B) * EPS )
!> donde VT = V' y EPS es la precisión de la máquina.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          Especifica si la matriz B es superior o inferior bidiagonal.
!>          = 'U':  Superior bidiagonal
!>          = 'L':  Inferior bidiagonal
!>

N

!>          N es INTEGER
!>          El orden de la matriz B.
!>

KD

!>          KD es INTEGER
!>          El ancho de banda de la matriz bidiagonal B. Si KD = 1, la
!>          matriz B es bidiagonal, y si KD = 0, B es diagonal y E no
!>          se referencia. Si KD es mayor que 1, se asume que es
!>          1, y si KD es menor que 0, se asume que es 0.
!>

D

!>          D es array DOUBLE PRECISION, dimensión (N)
!>          Los n elementos diagonales de la matriz bidiagonal B.
!>

E

!>          E es array DOUBLE PRECISION, dimensión (N-1)
!>          Los n-1 elementos superdiagonales de la matriz bidiagonal B
!>          si UPLO = 'U', o los n-1 elementos subdiagonales de B si
!>          UPLO = 'L'.
!>

U

!>          U es array COMPLEX*16, dimensión (LDU,N)
!>          La matriz ortogonal n x n U en la reducción B = U'*A*P.
!>

LDU

!>          LDU es INTEGER
!>          La dimensión principal del array U. LDU >= max(1,N)
!>

S

!>          S es array DOUBLE PRECISION, dimensión (N)
!>          Los valores singulares de la SVD de B, ordenados en orden
!>          decreciente.
!>

VT

!>          VT es array COMPLEX*16, dimensión (LDVT,N)
!>          La matriz ortogonal n x n V' en la reducción
!>          B = U * S * V'.
!>

LDVT

!>          LDVT es INTEGER
!>          La dimensión principal del array VT.
!>

WORK

!>          WORK es array COMPLEX*16, dimensión (2*N)
!>

RESID

!>          RESID es DOUBLE PRECISION
!>          La relación de prueba: norm(B - U * S * V') / ( n * norm(A) * EPS )
!>
