Propósito:

!>
!> ZBBCSD calcula la descomposición CS de una matriz unitaria en
!> forma de bloque bidiagonal,
!>
!>
!>     [ B11 | B12 0  0 ]
!>     [  0  |  0 -I  0 ]
!> X = [----------------]
!>     [ B21 | B22 0  0 ]
!>     [  0  |  0  0  I ]
!>
!>                               [  C | -S  0  0 ]
!>                   [ U1 |    ] [  0 |  0 -I  0 ] [ V1 |    ]**H
!>                 = [---------] [---------------] [---------]   .
!>                   [    | U2 ] [  S |  C  0  0 ] [    | V2 ]
!>                               [  0 |  0  0  I ]
!>
!> X es M-por-M, su bloque superior izquierdo es P-por-Q, y Q no debe ser mayor
!> que P, M-P, o M-Q. (Si Q no es el índice más pequeño, entonces X debe ser
!> transpuesta y/o permutada. Esto puede hacerse en tiempo constante usando
!> las opciones TRANS y SIGNS. Ver ZUNCSD para detalles.)
!>
!> Las matrices bidiagonales B11, B12, B21 y B22 están representadas
!> implícitamente por los ángulos THETA(1:Q) y PHI(1:Q-1).
!>
!> Las matrices unitarias U1, U2, V1T y V2T son de entrada/salida.
!> Las matrices de entrada se premultiplican o postmultiplican por las matrices
!> de vectores singulares apropiadas.
!>

NAME

ZBBCSD - Este subroutine calcula la descomposición CS completa de dos matrices de banda de Hessenberg.

SYNOPSIS

SUBROUTINE ZBBCSD( JOBU, JOBV, M, P, Q, THETA, PHI, R, LDR, TT, LTT, U, LDU, V, LDV, B11D, B11E, B12D, B12E, B21D, B21E, B22D, B22E, RWORK, LRWORK, INFO )

    CHARACTER(LEN=1) JOBU, JOBV
    INTEGER M, P, Q, LDR, LTT, LDU, LDV, LRWORK, INFO
    DOUBLE PRECISION THETA( * ), PHI( * ), R( * ), TT( * ), U( * ), V( * ), B11D( * ), B11E( * ), B12D( * ), B12E( * ), B21D( * ), B21E( * ), B22D( * ), B22E( * ), RWORK( * )

Function/Subroutine Documentation

ZBBCSD calcula la descomposición CS completa de dos matrices de banda de Hessenberg.

La descomposición CS de dos matrices A y B se define como:

A = [ A11 A12 ]
                [ A21 A22 ]

donde A11 está en la esquina superior izquierda, A12 está en la esquina superior derecha, A21 está en la esquina inferior izquierda y A21 está en la esquina inferior derecha.

y

B = [ B11 B12 ]
                [ B21 B22 ]

El objetivo de la descomposición CS es encontrar matrices unitarias X, Y, Z tales que:

A*X = [ R_C * diag(C_1)  -S_C * diag(S_1) ]
                  [ R_S * diag(S_1)   S_S * diag(C_1) ]

y

B*Y = [ R_C * diag(S_1)   S_C * diag(C_1) ]
                  [ R_S * diag(C_1)  -S_S * diag(S_1) ]

donde R_C, R_S, S_C, S_S son matrices diagonales y C_1, S_1 son vectores de coseno y seno.

El subroutine calcula las matrices U y V tales que:

A*U = [ T_11  T_12 ]
                  [ T_21  T_22 ]

y

B*V = [ T_21  T_22 ]
                  [ T_11  T_12 ]

donde T_11, T_12, T_21, T_22 son matrices de banda de Hessenberg de tamaño apropiado.

Los parámetros son:

JOBU

CHARACTER(LEN=1). Especifica si se deben calcular las columnas de U.

= 'Y': Las columnas de U se calculan y se devuelven en U.

= 'N': No se calculan las columnas de U.

JOBV

CHARACTER(LEN=1). Especifica si se deben calcular las columnas de V.

= 'Y': Las columnas de V se calculan y se devuelven en V.

= 'N': No se calculan las columnas de V.

M

INTEGER. El número de filas de la matriz A.

P

INTEGER. El número de columnas de la matriz A.

Q

INTEGER. El número de columnas de la matriz B.

THETA

DOUBLE PRECISION array, dimension (MIN(M,P)). En la entrada, contiene los ángulos theta.

PHI

DOUBLE PRECISION array, dimension (MIN(P,Q)). En la entrada, contiene los ángulos phi.

R

DOUBLE PRECISION array, dimension (LDR, MIN(M,P)). En la entrada, contiene la matriz R de la descomposición QR de A.

LDR

INTEGER. El primer límite de dimensiones de la matriz R.

TT

DOUBLE PRECISION array, dimension (LTT, MIN(P,Q)). En la entrada, contiene la matriz TT de la descomposición QR de B.

LTT

INTEGER. El primer límite de dimensiones de la matriz TT.

U

DOUBLE PRECISION array, dimension (LDU, M). Si JOBU = 'Y', U contiene la matriz unitaria U.

LDU

INTEGER. El primer límite de dimensiones de la matriz U.

V

DOUBLE PRECISION array, dimension (LDV, Q). Si JOBV = 'Y', V contiene la matriz unitaria V.

LDV

INTEGER. El primer límite de dimensiones de la matriz V.

B11D

DOUBLE PRECISION array, dimension (M). Si ZBBCSD converge, B11D contiene los cosenos de THETA(1), ..., THETA(M). Si ZBBCSD falla en converger, B11D contiene la diagonal del bloque superior izquierdo parcialmente reducido.

B11E

DOUBLE PRECISION array, dimension (M-1). Si ZBBCSD converge, B11E contiene ceros. Si ZBBCSD falla en converger, B11E contiene la subdiagonal del bloque superior izquierdo parcialmente reducido.

B12D

DOUBLE PRECISION array, dimension (P). Si ZBBCSD converge, B12D contiene los cosenos de THETA(1), ..., THETA(P). Si ZBBCSD falla en converger, B12D contiene la diagonal del bloque superior derecho parcialmente reducido.

B12E

DOUBLE PRECISION array, dimension (P-1). Si ZBBCSD converge, B12E contiene ceros. Si ZBBCSD falla en converger, B12E contiene la subdiagonal del bloque superior derecho parcialmente reducido.

B21D

DOUBLE PRECISION array, dimension (Q). Si ZBBCSD converge, B21D contiene los senos negativos de THETA(1), ..., THETA(Q). Si ZBBCSD falla en converger, B21D contiene la diagonal del bloque inferior izquierdo parcialmente reducido.

B21E

DOUBLE PRECISION array, dimension (Q-1). Si ZBBCSD converge, B21E contiene ceros. Si ZBBCSD falla en converger, B21E contiene la subdiagonal del bloque inferior izquierdo parcialmente reducido.

B22D

DOUBLE PRECISION array, dimension (Q). Si ZBBCSD converge, B22D contiene los senos negativos de THETA(1), ..., THETA(Q). Si ZBBCSD falla en converger, B22D contiene la diagonal del bloque inferior derecho parcialmente reducido.

B22E

DOUBLE PRECISION array, dimension (Q-1). Si ZBBCSD converge, B22E contiene ceros. Si ZBBCSD falla en converger, B22E contiene la subdiagonal del bloque inferior derecho parcialmente reducido.

RWORK

DOUBLE PRECISION array, dimension (MAX(1,LRWORK)). En la salida, si INFO = 0, RWORK(1) devuelve LRWORK óptimo.

LRWORK

INTEGER. La dimensión del array RWORK. LRWORK >= MAX(1,8*Q).

Si LRWORK = -1, se asume una consulta de espacio de trabajo; la rutina solo calcula el tamaño óptimo del array RWORK, devuelve este valor como la primera entrada del array de trabajo y XERBLA no emite ningún mensaje de error relacionado con LRWORK.

INFO

INTEGER.

= 0: Salida exitosa.

< 0: Si INFO = -i, el i-ésimo argumento tenía un valor ilegal.

> 0: Si ZBBCSD no convergió, INFO especifica el número de entradas distintas de cero en PHI, y B11D, B11E, etc., contienen la matriz parcialmente reducida.

Parámetros Internos:

TOLMUL  DOUBLE PRECISION, default = MAX(10,MIN(100,EPS**(-1/8)))
                    TOLMUL controla el criterio de convergencia del bucle QR.
                    Los ángulos THETA(i), PHI(i) se redondean a 0 o PI/2 cuando
                    están dentro de TOLMUL*EPS de cualquiera de los límites.
