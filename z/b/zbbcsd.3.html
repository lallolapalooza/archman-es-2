subroutine zbbcsd (character jobu1, character jobu2, character jobv1t, character jobv2t, character trans, integer m, integer p, integer q, double precision, dimension( * ) theta, double precision, dimension( * ) phi, complex*16, dimension( ldu1, * ) u1, integer ldu1, complex*16, dimension( ldu2, * ) u2, integer ldu2, complex*16, dimension( ldv1t, * ) v1t, integer ldv1t, complex*16, dimension( ldv2t, * ) v2t, integer ldv2t, double precision, dimension( * ) b11d, double precision, dimension( * ) b11e, double precision, dimension( * ) b12d, double precision, dimension( * ) b12e, double precision, dimension( * ) b21d, double precision, dimension( * ) b21e, double precision, dimension( * ) b22d, double precision, dimension( * ) b22e, double precision, dimension( * ) rwork, integer lrwork, integer info)

ZBBCSD

Propósito:

!>
!> ZBBCSD calcula la descomposición CS de una matriz unitaria en
!> forma de bloque bidiagonal,
!>
!>
!>     [ B11 | B12 0  0 ]
!>     [  0  |  0 -I  0 ]
!> X = [----------------]
!>     [ B21 | B22 0  0 ]
!>     [  0  |  0  0  I ]
!>
!>                               [  C | -S  0  0 ]
!>                   [ U1 |    ] [  0 |  0 -I  0 ] [ V1 |    ]**H
!>                 = [---------] [---------------] [---------]   .
!>                   [    | U2 ] [  S |  C  0  0 ] [    | V2 ]
!>                               [  0 |  0  0  I ]
!>
!> X es M-por-M, su bloque superior izquierdo es P-por-Q, y Q no debe ser mayor
!> que P, M-P, o M-Q. (Si Q no es el índice más pequeño, entonces X debe ser
!> transpuesta y/o permutada. Esto se puede hacer en tiempo constante usando
!> las opciones TRANS y SIGNS. Ver ZUNCSD para detalles.)
!>
!> Las matrices bidiagonales B11, B12, B21 y B22 se representan
!> implícitamente por los ángulos THETA(1:Q) y PHI(1:Q-1).
!>
!> Las matrices unitarias U1, U2, V1T y V2T son de entrada/salida.
!> Las matrices de entrada se multiplican previa o posteriormente por las
!> matrices de vectores singulares apropiadas.
!>

Parámetros

JOBU1 
!>          JOBU1 es CHARACTER
!>          = 'Y':      U1 se actualiza;
!>          en caso contrario:  U1 no se actualiza.
!>

JOBU2

!>          JOBU2 es CHARACTER
!>          = 'Y':      U2 se actualiza;
!>          en caso contrario:  U2 no se actualiza.
!>

JOBV1T

!>          JOBV1T es CHARACTER
!>          = 'Y':      V1T se actualiza;
!>          en caso contrario:  V1T no se actualiza.
!>

JOBV2T

!>          JOBV2T es CHARACTER
!>          = 'Y':      V2T se actualiza;
!>          en caso contrario:  V2T no se actualiza.
!>

TRANS

!>          TRANS es CHARACTER
!>          = 'T':      X, U1, U2, V1T y V2T se almacenan en orden de fila
!>                      principal (row-major);
!>          en caso contrario:  X, U1, U2, V1T y V2T se almacenan en orden de
!>                      columna principal (column-major).
!>

M

!>          M es INTEGER
!>          El número de filas y columnas en X, la matriz unitaria en
!>          forma de bloque bidiagonal.
!>

P

!>          P es INTEGER
!>          El número de filas del bloque superior izquierdo de X. 0 <= P <= M.
!>

Q

!>          Q es INTEGER
!>          El número de columnas del bloque superior izquierdo de X.
!>          0 <= Q <= MIN(P,M-P,M-Q).
!>

THETA

!>          THETA es un array de DOUBLE PRECISION, de dimensión (Q)
!>          A la entrada, los ángulos THETA(1),...,THETA(Q) que, junto con
!>          PHI(1), ...,PHI(Q-1), definen la matriz en forma de bloque
!>          bidiagonal. A la salida, los ángulos cuyos cosenos y senos definen
!>          los bloques diagonales en la descomposición CS.
!>

PHI

!>          PHI es un array de DOUBLE PRECISION, de dimensión (Q-1)
!>          Los ángulos PHI(1),...,PHI(Q-1) que, junto con THETA(1),...,
!>          THETA(Q), definen la matriz en forma de bloque bidiagonal.
!>

U1

!>          U1 es un array de COMPLEX*16, de dimensión (LDU1,P)
!>          A la entrada, una matriz P-por-P. A la salida, U1 se multiplica
!>          posteriormente por la matriz de vectores singulares izquierdos común a [ B11 ; 0 ] y
!>          [ B12 0 0 ; 0 -I 0 0 ].
!>

LDU1

!>          LDU1 es INTEGER
!>          La dimensión principal del array U1, LDU1 >= MAX(1,P).
!>

U2

!>          U2 es un array de COMPLEX*16, de dimensión (LDU2,M-P)
!>          A la entrada, una matriz (M-P)-por-(M-P). A la salida, U2 se
!>          multiplica posteriormente por la matriz de vectores singulares izquierdos común a
!>          [ B21 ; 0 ] y [ B22 0 0 ; 0 0 I ].
!>

LDU2

!>          LDU2 es INTEGER
!>          La dimensión principal del array U2, LDU2 >= MAX(1,M-P).
!>

V1T

!>          V1T es un array de COMPLEX*16, de dimensión (LDV1T,Q)
!>          A la entrada, una matriz Q-por-Q. A la salida, V1T se multiplica
!>          previamente por la transpuesta conjugada de la matriz de vectores singulares
!>          derechos común a [ B11 ; 0 ] y [ B21 ; 0 ].
!>

LDV1T

!>          LDV1T es INTEGER
!>          La dimensión principal del array V1T, LDV1T >= MAX(1,Q).
!>

V2T

!>          V2T es un array de COMPLEX*16, de dimensión (LDV2T,M-Q)
!>          A la entrada, una matriz (M-Q)-por-(M-Q). A la salida, V2T se
!>          multiplica previamente por la transpuesta conjugada de la matriz de
!>          vectores singulares derechos común a [ B12 0 0 ; 0 -I 0 ] y
!>          [ B22 0 0 ; 0 0 I ].
!>

LDV2T

!>          LDV2T es INTEGER
!>          La dimensión principal del array V2T, LDV2T >= MAX(1,M-Q).
!>

B11D

!>          B11D es un array de DOUBLE PRECISION, de dimensión (Q)
!>          Cuando ZBBCSD converge, B11D contiene los cosenos de THETA(1),
!>          ..., THETA(Q). Si ZBBCSD no converge, entonces B11D
!>          contiene la diagonal del bloque superior izquierdo parcialmente reducido.
!>

B11E

!>          B11E es un array de DOUBLE PRECISION, de dimensión (Q-1)
!>          Cuando ZBBCSD converge, B11E contiene ceros. Si ZBBCSD no
!>          converge, entonces B11E contiene la superdiagonal del
!>          bloque superior izquierdo parcialmente reducido.
!>

B12D

!>          B12D es un array de DOUBLE PRECISION, de dimensión (Q)
!>          Cuando ZBBCSD converge, B12D contiene los senos negativos de
!>          THETA(1), ..., THETA(Q). Si ZBBCSD no converge, entonces
!>          B12D contiene la diagonal del bloque superior derecho parcialmente reducido.
!>

B12E

!>          B12E es un array de DOUBLE PRECISION, de dimensión (Q-1)
!>          Cuando
n ZBBCSD converge, B12E contiene ceros. Si ZBBCSD falla !> en converger, entonces B12E contiene la subdiagonal del !> bloque superior derecho parcialmente reducido. !>

B21D

!>          B21D es un array DOUBLE PRECISION, de dimensión (Q)
!>          Cuando ZBBCSD converge, B21D contiene los senos negativos de
!>          THETA(1), ..., THETA(Q). Si ZBBCSD falla en converger, entonces
!>          B21D contiene la diagonal del bloque inferior izquierdo parcialmente reducido.
!>

B21E

!>          B21E es un array DOUBLE PRECISION, de dimensión (Q-1)
!>          Cuando ZBBCSD converge, B21E contiene ceros. Si ZBBCSD falla
!>          en converger, entonces B21E contiene la subdiagonal del
!>          bloque inferior izquierdo parcialmente reducido.
!>

B22D

!>          B22D es un array DOUBLE PRECISION, de dimensión (Q)
!>          Cuando ZBBCSD converge, B22D contiene los senos negativos de
!>          THETA(1), ..., THETA(Q). Si ZBBCSD falla en converger, entonces
!>          B22D contiene la diagonal del bloque inferior derecho parcialmente reducido.
!>

B22E

!>          B22E es un array DOUBLE PRECISION, de dimensión (Q-1)
!>          Cuando ZBBCSD converge, B22E contiene ceros. Si ZBBCSD falla
!>          en converger, entonces B22E contiene la subdiagonal del
!>          bloque inferior derecho parcialmente reducido.
!>

RWORK

!>          RWORK es un array DOUBLE PRECISION, de dimensión (MAX(1,LRWORK))
!>          Al salir, si INFO = 0, RWORK(1) devuelve el LRWORK óptimo.
!>

LRWORK

!>          LRWORK es un INTEGER
!>          La dimensión del array RWORK. LRWORK >= MAX(1,8*Q).
!>
!>          Si LRWORK = -1, entonces se asume una consulta de espacio de trabajo; la
!>          rutina solo calcula el tamaño óptimo del array RWORK,
!>          devuelve este valor como la primera entrada del array de trabajo, y
!>          XERBLA no emite ningún mensaje de error relacionado con LRWORK.
!>

INFO

!>          INFO es un INTEGER
!>          = 0: salida exitosa.
!>          < 0: si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>          > 0: si ZBBCSD no convergió, INFO especifica el número
!>                de entradas distintas de cero en PHI, y B11D, B11E, etc.,
!>                contienen la matriz parcialmente reducida.
!>

Parámetros Internos:

!>  TOLMUL  DOUBLE PRECISION, por defecto = MAX(10,MIN(100,EPS**(-1/8)))
!>          TOLMUL controla el criterio de convergencia del bucle QR.
!>          Los ángulos THETA(i), PHI(i) se redondean a 0 o PI/2 cuando están
!>          dentro de TOLMUL*EPS de cualquiera de los límites.
!>

Referencias:

[1] Brian D. Sutton. Computing the complete CS decomposition. Numer. Algorithms, 50(1):33-65, 2009.
