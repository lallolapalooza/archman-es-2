Documentación de la función/subrutina

subrutina zbdt02 (integer m, integer n, complex*16, dimension( ldb, * ) b, integer ldb, complex*16, dimension( ldc, * ) c, integer ldc, complex*16, dimension( ldu, * ) u, integer ldu, complex*16, dimension( * ) work, double precision, dimension( * ) rwork, double precision resid)

ZBDT02

Propósito:

!>
!> ZBDT02 comprueba el cambio de base C = U**H * B calculando el
!> residuo
!>
!>    RESID = norm(B - U * C) / ( max(m,n) * norm(B) * EPS ),
!>
!> donde B y C son matrices de M por N, U es una matriz ortogonal de M por M,
!> y EPS es la precisión de la máquina.
!>

Parámetros

M 
!>          M es ENTERO
!>          El número de filas de las matrices B y C y el orden de
!>          la matriz Q.
!>

N

!>          N es ENTERO
!>          El número de columnas de las matrices B y C.
!>

B

!>          B es un array COMPLEX*16, dimensión (LDB,N)
!>          La matriz B de M por N.
!>

LDB

!>          LDB es ENTERO
!>          La dimensión principal del array B.  LDB >= max(1,M).
!>

C

!>          C es un array COMPLEX*16, dimensión (LDC,N)
!>          La matriz C de M por N, que se supone contiene U**H * B.
!>

LDC

!>          LDC es ENTERO
!>          La dimensión principal del array C.  LDC >= max(1,M).
!>

U

!>          U es un array COMPLEX*16, dimensión (LDU,M)
!>          La matriz ortogonal U de M por M.
!>

LDU

!>          LDU es ENTERO
!>          La dimensión principal del array U.  LDU >= max(1,M).
!>

WORK

!>          WORK es un array COMPLEX*16, dimensión (M)
!>

RWORK

!>          RWORK es un array DOUBLE PRECISION, dimensión (M)
!>

RESID

!>          RESID es DOUBLE PRECISION
!>          RESID = norm(B - U * C) / ( max(m,n) * norm(B) * EPS ),
!>
