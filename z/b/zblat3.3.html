program zblat3

ZBLAT3

Propósito:

!>
!> Programa de prueba para el Nivel 3 BLAS COMPLEX*16.
!>
!> El programa debe ser dirigido por un archivo de datos corto. Los primeros 14 registros
!> se leen usando entrada de lista dirigida, los últimos 10 registros
!> se leen usando el formato ( A6, L2 ). Un ejemplo anotado de un archivo de datos
!> se puede obtener eliminando los primeros 3 caracteres de las siguientes 23 líneas:
!> 'zblat3.out'      NOMBRE DEL ARCHIVO DE SALIDA DE RESUMEN
!> 6                 NÚMERO DE UNIDAD DEL ARCHIVO DE RESUMEN
!> 'ZBLAT3.SNAP'     NOMBRE DEL ARCHIVO DE SALIDA DE INSTANTÁNEA
!> -1                NÚMERO DE UNIDAD DEL ARCHIVO DE INSTANTÁNEA (NO USADO SI .LT. 0)
!> F        BANDERA LÓGICA, T PARA REBOBINAR EL ARCHIVO DE INSTANTÁNEA DESPUÉS DE CADA REGISTRO.
!> F        BANDERA LÓGICA, T PARA DETENERSE EN CASOS DE FALLO.
!> T        BANDERA LÓGICA, T PARA PROBAR LAS SALIDAS DE ERROR.
!> 16.0     VALOR UMBRAL DE LA RELACIÓN DE PRUEBA
!> 6                 NÚMERO DE VALORES DE N
!> 0 1 2 3 5 9       VALORES DE N
!> 3                 NÚMERO DE VALORES DE ALPHA
!> (0.0,0.0) (1.0,0.0) (0.7,-0.9)       VALORES DE ALPHA
!> 3                 NÚMERO DE VALORES DE BETA
!> (0.0,0.0) (1.0,0.0) (1.3,-1.1)       VALORES DE BETA
!> ZGEMM  T ESCRIBIR F PARA NO PROBAR. MISMAS COLUMNAS.
!> ZHEMM  T ESCRIBIR F PARA NO PROBAR. MISMAS COLUMNAS.
!> ZSYMM  T ESCRIBIR F PARA NO PROBAR. MISMAS COLUMNAS.
!> ZTRMM  T ESCRIBIR F PARA NO PROBAR. MISMAS COLUMNAS.
!> ZTRSM  T ESCRIBIR F PARA NO PROBAR. MISMAS COLUMNAS.
!> ZHERK  T ESCRIBIR F PARA NO PROBAR. MISMAS COLUMNAS.
!> ZSYRK  T ESCRIBIR F PARA NO PROBAR. MISMAS COLUMNAS.
!> ZHER2K T ESCRIBIR F PARA NO PROBAR. MISMAS COLUMNAS.
!> ZSYR2K T ESCRIBIR F PARA NO PROBAR. MISMAS COLUMNAS.
!> ZGEMMTR T ESCRIBIR F PARA NO PROBAR. MISMAS COLUMNAS.
!>
!>

!>    Computer Science Division, Argonne National Laboratory, 9700
