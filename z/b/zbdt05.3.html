subrutina zbdt05 (integer m, integer n, complex*16, dimension( lda, * ) a, integer lda, double precision, dimension( * ) s, integer ns, complex*16, dimension( * ) u, integer ldu, complex*16, dimension( ldvt, * ) vt, integer ldvt, complex*16, dimension( * ) work, double precision resid)

ZBDT05

Propósito:

!>
!> ZBDT05 reconstruye una matriz bidimensional B a partir de su SVD (parcial):
!>    S = U' * B * V
!> donde U y V son matrices ortogonales y S es diagonal.
!>
!> La razón de prueba para verificar la descomposición de valores singulares es
!>    RESID = norm( S - U' * B * V ) / ( n * norm(B) * EPS )
!> donde VT = V' y EPS es la precisión de la máquina.
!>

Parámetros

M 
!>          M es INTEGER
!>          El número de filas de las matrices A y U.
!>

N

!>          N es INTEGER
!>          El número de columnas de las matrices A y VT.
!>

A

!>          A es una matriz COMPLEX*16, dimensión (LDA,N)
!>          La matriz A de m por n.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del arreglo A. LDA >= max(1,M).
!>

S

!>          S es un arreglo de DOUBLE PRECISION, dimensión (NS)
!>          Los valores singulares de la SVD (parcial) de B, ordenados en
!>          orden decreciente.
!>

NS

!>          NS es INTEGER
!>          El número de valores/vectores singulares de la SVD (parcial)
!>          de B.
!>

U

!>          U es un arreglo COMPLEX*16, dimensión (LDU,NS)
!>          La matriz ortogonal U de n por ns en S = U' * B * V.
!>

LDU

!>          LDU es INTEGER
!>          La dimensión principal del arreglo U. LDU >= max(1,N)
!>

VT

!>          VT es un arreglo COMPLEX*16, dimensión (LDVT,N)
!>          La matriz ortogonal V de n por ns en S = U' * B * V.
!>

LDVT

!>          LDVT es INTEGER
!>          La dimensión principal del arreglo VT.
!>

WORK

!>          WORK es un arreglo COMPLEX*16, dimensión (M,N)
!>

RESID

!>          RESID es DOUBLE PRECISION
!>          La razón de prueba:  norm(S - U' * A * V) / ( n * norm(A) * EPS )
!>
