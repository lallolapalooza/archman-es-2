NOMBRE

zblocklist - herramienta de lista de bloqueo de IP de zmap

SINOPSIS

zblocklist [ -b <lista_de_bloqueo> ] [ -w <lista_de_permisos> ] [ OPCIONES... ]

DESCRIPCIÓN

ZBlacklist es una herramienta de red para limitar y deduplicar una lista de direcciones IP utilizando una lista de bloqueo o una lista de permisos.

OPCIONES

OPCIONES BÁSICAS

-b, --archivo-lista-bloqueo=ruta
Archivo de subredes a excluir, en notación CIDR, una por línea. Se recomienda usar esto para excluir direcciones RFC 1918, multidifusión, espacio reservado por IANA y otras direcciones de propósito especial de IANA. Un archivo de lista de bloqueo de ejemplo blocklist.conf para este propósito.
-w, --archivo-lista-permisos=nombre
Archivo de subredes a incluir, en notación CIDR, una por línea. Todas las demás subredes serán excluidas.
-l, --archivo-registro=nombre
Archivo al que registrar.
--desactivar-syslog
Desactivar el registro de mensajes a syslog.
-v, --verbosidad
Nivel de detalle del registro (0-5, predeterminado=3)
--no-verificar-duplicados
No deduplicar las direcciones de entrada. El valor predeterminado es falso.
--ignorar-errores-lista-bloqueo
Ignorar entradas inválidas, malformadas o no resolubles en la lista de bloqueo/permisos. El valor predeterminado es falso.
--ignorar-errores-entrada
No imprimir entradas inválidas en la entrada. El valor predeterminado es falso.

OPCIONES ADICIONALES

-h, --ayuda
Imprimir ayuda y salir
-V, --version
Imprimir versión y salir
