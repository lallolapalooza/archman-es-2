ZBARIMG(1) Lector de códigos de barras ZBar ZBARIMG(1)

NOMBRE

zbarimg - escanea y decodifica códigos de barras de archivos de imagen

SINOPSIS

zbarimg [-qv] [--polygon] [--quiet] [--verbose[=n]]
{-dD | --display | --nodisplay | --xml | --noxml | -S[simbología.]configuración[=valor] | --set [simbología.]configuración[=valor] | imagen...}

zbarimg {-h | --help | --version}

DESCRIPCIÓN

Para cada archivo de imagen especificado, zbarimg escanea la imagen en busca de códigos de barras e imprime cualquier dato decodificado en la salida estándar. Las imágenes pueden mostrarse opcionalmente en pantalla.

La biblioteca subyacente actualmente soporta las simbologías EAN-13 (incluyendo subconjuntos UPC e ISBN), EAN-8, DataBar, DataBar Expanded, Code 128, Code 93, Code 39, Codabar, Interleaved 2 de 5 y QR Code. El tipo específico de cada símbolo detectado se imprime con los datos decodificados.

Tenga en cuenta que "imagen" en este contexto se refiere a cualquier formato soportado por ImageMagick, incluyendo muchos formatos vectoriales como PDF y PostScript. Tenga en cuenta que los formatos vectoriales se rasterizan antes de escanear; rasterice manualmente las imágenes vectoriales antes de escanear para evitar corromper involuntariamente los mapas de bits de códigos de barras incrustados.

OPCIONES

Este programa sigue la sintaxis habitual de línea de comandos de GNU. Las opciones de una sola letra pueden agruparse, las opciones largas comienzan con dos guiones (`-').

-h, --help

Imprime un breve mensaje de ayuda describiendo las opciones de la línea de comandos en la salida estándar y sale.

--version

Imprime la información de la versión del programa en la salida estándar y sale.

-v, --verbose[=n]

Aumenta el nivel de salida de depuración. Múltiples opciones -v generan más información. Alternativamente, especifique n para establecer el nivel de depuración directamente.

-S[simbología.]configuración[=valor], --set [simbología.]configuración[=valor]

Establece la opción de configuración del decodificador configuración para la simbología a valor. valor por defecto es 1 si se omite. simbología es uno de ean13, ean8, upca, upce, isbn13, isbn10, i25, codabar, code39, code93, code128, qrcode o el valor especial *. Si se omite simbología o es *, la configuración se establecerá para todas las simbologías aplicables. Estas son las configuraciones actualmente reconocidas. Prefije una configuración con "no-" para negarla. No todas las configuraciones son apropiadas para todas las simbologías.

enable

Controla la decodificación/informe de una simbología. Para simbologías que son solo subconjuntos de ean13 (upca, upce, isbn13, isbn10), esta configuración controla si los subconjuntos se detectan y se informan como tales. Estos casos especiales están deshabilitados por defecto, todas las demás simbologías están habilitadas por defecto.

disable

Antónimo de enable.

emit-check

Controla si los dígitos de verificación se incluyen en la salida decodificada. Habilitado por defecto. Esta configuración no se aplica para code128, que nunca devuelve el dígito de verificación. Tampoco se aplica a los casos en los que el dígito de verificación está deshabilitado (ver add-check). Los dígitos de verificación actualmente no están implementados para i25 o code39.

add-check

Habilita la decodificación y verificación de un dígito de verificación para simbologías donde es opcional: esto incluirá code39 y i25, ninguno de los cuales implementa aún el dígito de verificación.

ascii

Habilita secuencias de escape que codifican el conjunto completo de caracteres ASCII. Esto se aplicaría a code39, excepto que tampoco está implementado...

position

Habilita la recopilación de información de posición del símbolo. Habilitado por defecto. Actualmente, la información de posición es inutilizable, por lo que puede ahorrar algunos ciclos deshabilitándola.

test-inverted

Especialmente para imágenes de código QR, a veces la imagen está invertida, por ejemplo, las líneas están escritas en blanco en lugar de negro. Esta opción hace que ZBar invierta la imagen y la analice de nuevo, en caso de que falle con el orden normal. Habilitarla afecta a todos los decodificadores.

min-length=n, max-length=n

Limita el número de caracteres decodificados en un símbolo válido. Si un resultado de decodificación está fuera del rango configurado min/max (inclusive), no se informará. Establézcalo en 0 para deshabilitar la verificación correspondiente. Esta configuración se aplica a simbologías de longitud variable: i25, codabar, code39, code128 y pdf417. min-length por defecto es 6 para i25 y 1 para code39 (según la recomendación de autodiscriminación de Code 39); todos los demás por defecto son 0.

x-density=n, y-density=n

Ajusta la densidad de los pases del escáner. Valores más bajos escanean más de la imagen a costa de un menor rendimiento. Establecer en 0 deshabilita el escaneo en ese eje. Los valores por defecto son ambos 1.

--polygon

Salida de puntos del polígono que contiene el código de barras. Usando un formato compatible con el elemento <polygon> del lenguaje de marcado Gráficos Vectoriales Escalables (SVG).

-q, --quiet

Operación silenciosa; solo imprime los datos del símbolo decodificado. Específicamente, esto deshabilita la línea de estadísticas impresa (en stderr) antes de salir, así como el mensaje de advertencia impreso (también en stderr) cuando no se encuentran códigos de barras en una imagen.

-d, --display, -D, --nodisplay

Habilita/deshabilita la visualización de los archivos de imagen subsiguientes, hasta que se encuentre la siguiente opción --display o --nodisplay. Esta opción puede aparecer varias veces para habilitar la visualización de imágenes específicas. La visualización de imágenes está deshabilitada por defecto.

--xml, --noxml

Habilita/deshabilita la salida de resultados usando un formato XML. Este formato envuelve los datos brutos del símbolo con información sobre el escaneo (como índices de página) en un formato fácil de analizar. El último esquema está disponible en http://zbar.sourceforge.net/2008/barcode.xsd.

--raw

Habilita la salida de datos brutos del símbolo. Este formato imprime los datos del símbolo separados por saltos de línea sin la información adicional del tipo de simbología que se imprime por defecto.

EJEMPLOS

Escanea una imagen PNG de un símbolo de código de barras UPC y pasa los datos resultantes a un script que busca el código en una base de datos y hace algo útil con él:

zbarimg product.png | upcrpc.py

El script upcrpc.py incluido en el subdirectorio examples/ de la distribución realizará una llamada XMLRPC a una popular base de datos de UPC en Internet e imprimirá la descripción del producto si se encuentra.

Escanea una imagen JPEG que contiene varios códigos de barras y muestra la imagen en una ventana, deshabilitando también el reconocimiento de códigos Interleaved 2 de 5 para evitar confusiones con otras simbologías o ruido de fondo:

zbarimg --display -Si25.disable label.jpg

Busca en un documento escaneado solo códigos Code 39, usando el formato de salida XML para que los números de página estén disponibles. Para habilitar solo Code 39, primero se deshabilitan todas las simbologías y luego se vuelve a habilitar Code 39:

zbarimg --xml -Sdisable -Scode39.enable scan.tiff

ESTADO DE SALIDA

zbarimg devuelve un código de salida para indicar el estado de la ejecución del programa. Los códigos de salida actuales son:

0

Se detectaron códigos de barras correctamente en todas las imágenes. Puede haberse generado advertencias, pero ningún error.

1

Ocurrió un error al procesar alguna(s) imagen(es). Esto incluye argumentos incorrectos, errores de E/S y errores de manejo de imágenes de ImageMagick.

2

Error fatal de ImageMagick.

3

El usuario abandonó el programa antes de que se escanearan todas las imágenes. Solo aplica cuando se ejecuta en modo interactivo (con --display).

4

No se detectó ningún código de barras en una o más de las imágenes. No ocurrieron otros errores.
