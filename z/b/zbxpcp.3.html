NOMBRE

zbxpcp - Módulo cargable PCP del agente Zabbix

DESCRIPCIÓN

El módulo cargable zbxpcp extiende el agente Zabbix al hacer que las métricas de Performance Co-Pilot (PCP) estén disponibles para él. Con el módulo zbxpcp configurado en zabbix_agentd.conf, todas las métricas de PCP están disponibles desde el agente Zabbix como cualquier otro elemento del agente. Como módulo cargable (DSO), zbxpcp no depende de ningún programa externo, sino que utiliza directamente las API de PCP para recuperar métricas de PCP cuando se solicitan.

Una instalación típica de PCP en Linux ofrece más de 1000 métricas por defecto y, a su vez, es extensible con sus propios complementos o PMDA (``Agentes de dominio de métricas de rendimiento''). Además de estadísticas muy completas basadas en /proc, los PMDA de PCP fácilmente disponibles proporcionan soporte para componentes a nivel de sistema y aplicación como 389 Directory Server, Apache, contenedores, HAProxy, GFS2, Gluster, libvirt, MySQL, NFS, Oracle, Postfix, PostgreSQL, Samba y Sendmail, entre otros. PCP también se ejecuta en muchas plataformas, incluyendo Linux, macOS, FreeBSD, NetBSD, Solaris y Windows.

Para una introducción a PCP, consulte PCPIntro(1). Para investigar las métricas de PCP disponibles, utilice, por ejemplo, pminfo(1). La Guía de referencia rápida de PCP está disponible en la página de inicio de PCP en https://pcp.io/.

Para obtener información general sobre la recopilación de datos de Zabbix y los módulos cargables, consulte https://www.zabbix.com/documentation/3.0/manual/config/items. Para obtener información general y descargas de Zabbix, consulte https://www.zabbix.com/.

zbxpcp es compatible con la versión de la API de módulos de Zabbix 1.

CONFIGURACIÓN

Primero, asegúrese de que PCP esté instalado y configurado correctamente. Consulte las referencias anteriores para obtener instrucciones y utilice, por ejemplo, pminfo(1) para asegurarse de que las métricas de PCP se puedan recuperar. Para habilitar el módulo cargable zbxpcp en un agente Zabbix, las siguientes líneas deben agregarse al archivo de configuración del agente Zabbix zabbix_agentd.conf (asegúrese de usar la ruta correcta de LoadModulePath):

LoadModulePath=/usr/lib64/zabbix/agent/
LoadModule=zbxpcp.so

Después de reiniciar el agente Zabbix, todas las métricas de PCP estarán disponibles con el prefijo ``pcp.'' como todos los demás elementos del agente. Esto se puede verificar con los siguientes comandos:

$ pminfo -t
$ zabbix_agentd -p
$ pminfo -f kernel.all.sysfork
$ zabbix_get -s 127.0.0.1 -p 10050 -k pcp.kernel.all.sysfork

Luego, para recopilar métricas de PCP de los agentes Zabbix, la configuración del lado del servidor de Zabbix es la habitual (consulte la documentación de Zabbix si es necesario).

El servicio PCP pmcd debe estar siempre en ejecución al iniciar un agente Zabbix con zbxpcp habilitado, de lo contrario, el módulo no se cargará y las métricas de PCP no estarán disponibles. Se debe tener especial cuidado para asegurarse de que esto suceda también al reiniciar el sistema.

ARCHIVOS

/etc/zabbix/zabbix_agentd.conf
Ubicación típica del archivo de configuración del agente Zabbix.
/etc/zabbix/zbxpcp-derived-metrics.conf
Archivo de configuración opcional de métricas derivadas de PCP para zbxpcp. Consulte pmLoadDerivedConfig(3) para más información sobre métricas derivadas.
$PCP_LIB_DIR/zabbix/agent/zbxpcp.so
Módulo PCP cargable del agente Zabbix.
