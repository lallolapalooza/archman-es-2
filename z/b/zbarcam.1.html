NOMBRE

zbarcam - escanea y decodifica códigos de barras desde un dispositivo de video

SINOPSIS

zbarcam [-qv] [--quiet] [--nodisplay] [--xml] [--verbose[=n]] [--prescale=AxH] [-S[simbología.]configuración[=valor]] [--set [simbología.]configuración[=valor]] [dispositivo]

zbarcam {-h | --help | --version}

DESCRIPCIÓN

zbarcam escanea una fuente de video video4linux (por ejemplo, una webcam) en busca de códigos de barras e imprime cualquier dato decodificado en la salida estándar. El flujo de video también se muestra en la pantalla.

dispositivo es la ruta al archivo especial de carácter de video4linux (versión 1 o 2) (número mayor 81 y número menor 0 a 63). Por defecto es /dev/video0

La biblioteca subyacente actualmente soporta las simbologías EAN-13 (incluidos subconjuntos UPC e ISBN), EAN-8, DataBar, DataBar Expanded, Code 128, Code 93, Code 39, Codabar, Interleaved 2 of 5 y QR Code. El tipo específico de cada símbolo detectado se imprime junto con los datos decodificados.

OPCIONES

Este programa sigue la sintaxis habitual de línea de comandos de GNU. Las opciones de una sola letra pueden agruparse, las opciones largas comienzan con dos guiones (`-').

-h, --help

Imprime un breve mensaje de ayuda que describe las opciones de la línea de comandos en la salida estándar y sale.

--version

Imprime la información de la versión del programa en la salida estándar y sale.

-v, --verbose[=n]

Aumenta el nivel de salida de depuración. Múltiples opciones -v generan más detalles. Alternativamente, especifica n para establecer el nivel de depuración directamente.

-S[simbología.]configuración[=valor], --set [simbología.]configuración[=valor]

Establece la opción de configuración del decodificador configuración para simbología a valor. valor por defecto es 1 si se omite. simbología es una de ean13, ean8, upca, upce, isbn13, isbn10, i25, codabar, code39, code93, code128, qrcode o el valor especial *. Si se omite simbología o es *, la configuración se establecerá para todas las simbologías aplicables. Estas son las configuraciones reconocidas actualmente. Antepón "no-" a una configuración para negarla. No todas las configuraciones son apropiadas para todas las simbologías.

enable

Controla la decodificación/reporte de una simbología. Para simbologías que son solo subconjuntos de ean13 (upca, upce, isbn13, isbn10), esta configuración controla si los subconjuntos se detectan y reportan como tales. Estos casos especiales están deshabilitados por defecto, todas las demás simbologías están habilitadas por defecto.

disable

Antónimo de enable.

emit-check

Controla si los dígitos de verificación se incluyen en la salida decodificada. Habilitado por defecto. Esta configuración no se aplica a code128, que nunca devuelve el dígito de verificación. Tampoco se aplica a los casos en que el dígito de verificación está deshabilitado (ver add-check). Los dígitos de verificación actualmente no están implementados para i25 o code39.

add-check

Habilita la decodificación y verificación de un dígito de verificación para simbologías donde es opcional: esto incluirá code39 y i25, ninguno de los cuales implementa aún el dígito de verificación.

ascii

Habilita secuencias de escape que codifican el conjunto completo de caracteres ASCII. Esto se aplicaría a code39, excepto que tampoco está implementado...

position

Habilita la recopilación de información de posición del símbolo. Habilitado por defecto. Actualmente, la información de posición no es utilizable, por lo que puede ahorrar algunos ciclos deshabilitándola.

test-inverted

Especialmente para imágenes de códigos QR, a veces la imagen está invertida, por ejemplo, las líneas están escritas en blanco en lugar de negro. Esta opción hace que ZBar invierta la imagen y la analice de nuevo, en caso de que falle con el orden normal. Habilitarla afecta a todos los decodificadores.

min-length=n, max-length=n

Limita el número de caracteres decodificados en un símbolo válido. Si un resultado de decodificación está fuera del rango mínimo/máximo configurado (inclusivo), no se informará. Establecer en 0 para deshabilitar la verificación correspondiente. Esta configuración se aplica a simbologías de longitud variable: i25, codabar, code39, code128 y pdf417. min-length por defecto es 6 para i25 y 1 para code39 (según la recomendación de autodiscriminación de Code 39); todos los demás por defecto son 0.

x-density=n, y-density=n

Ajusta la densidad de los pases del escáner. Valores más bajos escanean más de la imagen a costa de un rendimiento reducido. Establecer en 0 deshabilita el escaneo en ese eje. Los valores por defecto son ambos 1.

-q, --quiet

Operación silenciosa; deshabilita el pitido audible que de lo contrario se emite cuando se decodifica un símbolo.

--nodisplay

Deshabilita la ventana de video de salida. La entrada de video se escaneará hasta que el programa se interrumpa o se le indique de otra manera.

--xml

Transmite los resultados utilizando un formato de salida XML. Este formato envuelve los datos brutos del símbolo con información sobre el escaneo en un formato fácil de analizar. El último esquema está disponible en http://zbar.sourceforge.net/2008/barcode.xsd

--raw

Utiliza el formato de salida de datos de símbolo crudo. Este formato imprime los datos del símbolo separados por saltos de línea sin la información adicional del tipo de simbología que se imprime por defecto.

--prescale=AxH

Solicita el escalado de la entrada de video del controlador de la cámara. Posiblemente útil para reducir fotogramas enormes para lograr una mayor velocidad de fotogramas. Tenga en cuenta que el controlador puede ajustar o ignorar completamente la solicitud de escalado.

EJEMPLOS

Escanee códigos de barras utilizando el segundo dispositivo de video y canalice los datos resultantes a través de un script que busque cada código en una base de datos y haga algo útil con ellos:

zbarcam /dev/video1 | upcrpc.py

El script upcrpc.py incluido en el subdirectorio examples/ de la distribución realizará una llamada XMLRPC a una base de datos UPC popular en Internet e imprimirá la descripción del producto si se encuentra.

Escanee códigos de barras utilizando el dispositivo de video predeterminado y transmita los resultados a stdout en formato XML, también deshabilite el reconocimiento de códigos Interleaved 2 of 5 para evitar confusiones con otras simbologías o ruido de fondo:

zbarcam --xml -Si25.disable

Escanee solo para Code 39, sin usar la ventana de vista previa - quizás para una instalación fija. Para habilitar solo Code 39, primero se deshabilitan todas las simbologías, luego se vuelve a habilitar Code 39:

zbarcam --nodisplay -Sdisable -Scode39.enable

ESTADO DE SALIDA

zbarcam devuelve un código de salida para indicar el estado de ejecución del programa. Los códigos de salida actuales son:

0

Finalización exitosa del programa.

1

Ocurrió un error. Esto incluye argumentos incorrectos y errores de E/S.

2

Ocurrió un error fatal.

NAME

zbarcam - barcode scanner

SYNOPSIS

zbarcam [options] [image]

DESCRIPTION

zbarcam is a video device barcode scanner. It can scan barcodes from a video stream or an image file.

OPTIONS

--barcode-type type
Scan only for barcodes of the specified type (e.g., QRCODE, EAN13). Multiple types can be specified.
--dshow
Use DirectShow video capture driver on Windows.
--fps rate
Set the desired video capture frame rate.
--full-screen
Run in full-screen mode.
--list-devices
List available video devices and exit.
--logfile file
Write scanner output to the specified file.
--quiet
Suppress all output except for detected barcodes.
--raw
Output raw barcode data without type information.
--verbose level
Set the verbosity level of the output (0-4).
--version
Show program version and exit.
-h, --help
Show a help message and exit.

EXAMPLES

Scan barcodes from a video file:

zbarcam video.mp4

Scan only for QR codes from a webcam and save output to a log file:

zbarcam --barcode-type QRCODE --logfile barcodes.txt

EXIT STATUS

Returns 0 if successful, non-zero otherwise.
