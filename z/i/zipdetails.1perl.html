NOMBRE

zipdetails - muestra la estructura interna de los archivos zip

SINOPSIS

zipdetails [opciones] archivo.zip

DESCRIPCIÓN

Este programa crea un informe detallado sobre la estructura interna de los archivos zip. Para cada elemento de metadatos dentro de un archivo zip, el programa generará

el desplazamiento dentro del archivo zip donde se encuentra el elemento.
una representación textual para el elemento.
un volcado hexadecimal opcional del elemento.

El programa asume un conocimiento previo de la estructura interna de los archivos Zip. Deberías tener a mano una copia de la definición del archivo zip, APPNOTE.TXT https://pkware.cachefly.net/webdocs/casestudies/APPNOTE.TXT, para ayudar a comprender la salida de este programa.

Comportamiento por defecto

Por defecto, el programa espera recibir un archivo zip bien formado. Navegará por el archivo zip analizando primero el "Directorio Central" al final del archivo. Si se encuentra el "Directorio Central", luego recorrerá secuencialmente los registros zip comenzando desde el principio del archivo. Ver "Análisis Avanzado" para otras opciones de procesamiento.

Si el programa encuentra algún problema estructural o de portabilidad con el archivo zip, imprimirá un mensaje en el punto en que encuentre el problema y/o en un resumen al final del informe de salida. Aunque el conjunto de problemas que se pueden detectar no es exhaustivo, no asumas que este programa puede encontrar *todos* los problemas posibles en un archivo zip; es probable que haya condiciones de borde que deban abordarse.

Si tienes sugerencias para casos de uso donde esto podría mejorarse, considera crear una solicitud de mejora (ver "SOPORTE").

Campos de Fecha y Hora

Los campos de fecha/hora encontrados en los archivos zip se muestran en hora local. Utiliza la opción "--utc" para mostrar estos campos en Tiempo Universal Coordinado (UTC).

Nombres de Archivo y Comentarios

Los nombres de archivo y comentarios se decodifican/codifican utilizando la codificación del sistema por defecto del host que ejecuta "zipdetails". Cuando la codificación del sistema no se puede determinar, se utilizará "cp437".

Las excepciones son:

  • cuando la "Bandera de Codificación de Idioma" está establecida en el archivo zip, se asume que los campos de nombre de archivo/comentario están codificados en UTF-8.
  • la definición del campo de metadatos implica codificación de conjunto de caracteres UTF-8

Ver "Problemas de Codificación de Nombres de Archivo" y "Opciones de Codificación de Nombres de Archivo y Comentarios" para formas de controlar la codificación de los campos de nombre de archivo/comentario.

OPCIONES

Opciones Generales

"-h", "--help"
Mostrar ayuda
"--redact"
Ofuscar los nombres de archivo y los datos de carga útil en la salida. Útil para el caso de uso en el que los archivos zip contienen datos sensibles que no se pueden compartir.
"--scan"
Escanear pesimistamente el archivo zip buscando posibles registros zip. Puede ser propenso a errores. Para archivos zip muy grandes, esta opción es lenta. Considera usar la opción "--walk" primero. Ver "Opciones de Análisis Avanzado"
"--utc"
Por defecto, los campos de fecha/hora se muestran en hora local. Utiliza esta opción para mostrarlos en Tiempo Universal Coordinado (UTC).
"-v"
Habilitar modo Verboso. Ver "Salida Verbosa".
"--version"
Mostrar el número de versión del programa y salir.
"--walk"
Recorrer optimísticamente el archivo zip buscando posibles registros zip. Ver "Opciones de Análisis Avanzado"

Opciones de Codificación de Nombres de Archivo y Comentarios

Ver "Problemas de Codificación de Nombres de Archivo"

"--encoding nombre"
Usar la codificación "nombre" al leer nombres de archivo/comentarios del archivo zip.

Cuando esta opción no se especifica, se utiliza la codificación del sistema por defecto.

"--no-encoding"
Deshabilitar toda codificación/decodificación de nombres de archivo y comentarios. Los nombres de archivo/comentarios se procesan como flujos de bytes.

Esta opción no está habilitada por defecto.

"--output-encoding nombre"
Usar la codificación "nombre" al escribir nombres de archivo/comentarios en la pantalla. Por defecto se utilizará la codificación del sistema.
"--language-encoding", "--no-language-encoding"
Los archivos zip modernos establecen una entrada de metadatos en los archivos zip, llamada "Bandera de codificación de idioma", cuando escriben nombres de archivo/comentarios codificados en UTF-8.

Ocasionalmente, algunas aplicaciones establecen la "Bandera de Codificación de Idioma" pero escriben datos que no son UTF-8 en los campos de nombre de archivo/comentario del archivo zip. Esto generalmente resultará en texto corrupto para los nombres de archivo/comentarios.

Para manejar este caso de uso, establece la opción "--no-language-encoding" y, si es necesario, establece la opción "--encoding nombre" a la codificación realmente utilizada.

Por defecto es "--language-encoding".

"--debug-encoding"
Mostrar información de depuración adicional cuando ha cambiado la codificación de un nombre de archivo/comentario.

Opciones de Control de Mensajes

"--messages", "--no-messages"
Habilitar/deshabilitar la salida de todos los mensajes informativos/de advertencia/de error.

Deshabilitar mensajes significa que no se realizan comprobaciones para verificar que el archivo zip está bien formado.

Por defecto está habilitado.

"--exit-bitmask", "--no-exit-bitmask"
Habilitar/deshabilitar la máscara de bits de estado de salida para los mensajes. Por defecto deshabilitado. Los valores de la máscara de bits son: 1 para información, 2 para advertencia y 4 para error.

Salida por defecto

Por defecto, "zipdetails" mostrará cada campo de metadatos del archivo zip en tres columnas.

1.
El desplazamiento, en hexadecimal, hasta el inicio del campo en relación con el principio del archivo.
2.
El nombre del campo.
3.
Información detallada sobre el contenido del campo. El formato depende del tipo de datos:
  • Valores Numéricos

    Si el campo contiene un valor numérico de 8 bits, 16 bits, 32 bits o 64 bits, se mostrará tanto en hexadecimal como en decimal, por ejemplo, "002A (42)".

    Ten en cuenta que los archivos Zip almacenan la mayoría de los valores numéricos en codificación *little-endian* (hay algunas raras instancias donde se usa *big-endian*). El valor leído del archivo zip se le quitará la codificación *endian* antes de mostrarse.

    A continuación, se incluye una descripción opcional de lo que significa el valor numérico.

  • Cadena

    Si el campo corresponde a una cadena imprimible, se mostrará entre comillas simples.

  • Datos Binarios

    El término *Datos Binarios* es solo una categoría general para todos los demás metadatos en el archivo zip. Estos datos se muestran como una serie de valores de bytes ascii-hexadecimales en el mismo orden en que se almacenan en el archivo zip.

Por ejemplo, asumiendo que tienes un archivo zip, "test.zip", con una entrada

$ unzip -l  test.zip
Archive:  test.zip
Length      Date    Time    Name
---------  ---------- -----   ----
    446  2023-03-22 20:03   lorem.txt
---------                     -------
    446                     1 file

LIMITACIONES

Las siguientes características de los archivos zip no están soportadas por este programa:

  • Archivos Zip multipartes/divididos/intercalados.

    Este programa no puede proporcionar un informe general sobre las partes combinadas de un archivo zip multipartes.

    Lo mejor que puedes hacer es ejecutar con las opciones "--scan" o "--walk" contra partes individuales. Algunas contendrán metadatos de archivos zip que serán detectados y otras solo contendrán datos de carga comprimidos.

  • Directorio Central Cifrado

    Cuando el cifrado fuerte de pkzip está habilitado en un archivo zip, este programa aún puede analizar la mayoría de los metadatos del archivo zip. La excepción es cuando el "Directorio Central" de un archivo zip también está cifrado. Este programa no puede analizar ningún metadato de un "Directorio Central" cifrado.

  • Archivos Zip Corruptos

    Cuando "zipdetails" encuentra un archivo zip corrupto, hará una o más de las siguientes acciones:

  • Mostrar detalles de la corrupción y continuar
  • Mostrar detalles de la corrupción y terminar
  • Terminar con un mensaje genérico

Cuál de las opciones anteriores se muestra depende de la gravedad de la corrupción.

VER TAMBIÉN

La referencia principal para los archivos Zip es APPNOTE.TXT https://pkware.cachefly.net/webdocs/casestudies/APPNOTE.TXT.

Una referencia alternativa es el appnote de Info-Zip. Esto está disponible en <ftp://ftp.info-zip.org/pub/infozip/doc/>

Para detalles sobre el cifrado AES de WinZip, consulta Información de Cifrado AES: Especificación de Cifrado AE-1 y AE-2 https://www.winzip.com/en/support/aes-encryption/.

El programa "zipinfo" que viene con la distribución de info-zip (http://www.info-zip.org/) también puede mostrar detalles de la estructura de un archivo zip.
