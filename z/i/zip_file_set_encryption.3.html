zip_file_set_encryption(3)

Paquete: libzip

Licencias: BSD

ZIP_FILE_SET_ENCRYPTION(3) Manual de funciones de la biblioteca ZIP_FILE_SET_ENCRYPTION(3)

NOMBRE

zip_file_set_encryption — establece el método de cifrado para un archivo en zip

BIBLIOTECA

libzip (-lzip)

SINOPSIS

#include <zip.h>

int
zip_file_set_encryption(zip_t *archive, zip_uint64_t index, zip_uint16_t method, const char *password);

DESCRIPCIÓN

La función zip_file_set_encryption() establece el método de cifrado para el archivo en la posición index en el archivo zip a method usando la contraseña password. El method es el mismo que se devuelve en zip_stat(3). Para el argumento method, actualmente solo se admiten los siguientes valores:

ZIP_EM_NONE
Sin cifrado.
ZIP_EM_AES_128
Cifrado Winzip AES-128.
ZIP_EM_AES_192
Cifrado Winzip AES-192.
ZIP_EM_AES_256
Cifrado Winzip AES-256.
ZIP_EM_TRAD_PKWARE
Cifrado tradicional PKWare. No utilice este método, no es seguro. Solo se proporciona por compatibilidad con versiones anteriores.

Si password es NULL, se utiliza la contraseña predeterminada proporcionada por zip_set_default_password(3).

El método de cifrado actual para un archivo en un archivo zip se puede determinar usando zip_stat(3).

VALORES DE RETORNO

En caso de finalización exitosa, se devuelve 0. De lo contrario, se devuelve -1 y la información de error en archive se establece para indicar el error.

ERRORES

zip_file_set_encryption() falla si:

[ZIP_ER_ENCRNOTSUPP]
Se solicitó un método de compresión no admitido.
[ZIP_ER_INVAL]
index no es un índice de archivo válido en archive, o la combinación de argumentos es inválida.
[ZIP_ER_MEMORY]
No se pudo asignar la memoria requerida.
[ZIP_ER_RDONLY]
Archivo zip de solo lectura, no se permiten cambios.

VER TAMBIÉN

libzip(3), zip_encryption_method_supported(3), zip_fopen_encrypted(3), zip_fopen_index_encrypted(3), zip_set_default_password(3), zip_stat(3)

HISTORIA

zip_file_set_encryption() se añadió en libzip 1.2.0.
