zip_source_seek_compute_offset(3)

Paquete: libzip

Licencias: BSD

ZIP_SOURCE_SEEK_COMPUTE_OFFSET(3) Manual de funciones de biblioteca ZIP_SOURCE_SEEK_COMPUTE_OFFSET(3)

NOMBRE

zip_source_seek_compute_offset — valida argumentos y calcula el desplazamiento

BIBLIOTECA

libzip (-lzip)

SINOPSIS

#include <zip.h>

zip_int64_t
zip_source_seek_compute_offset(zip_uint64_t offset, zip_uint64_t length, void *data, zip_uint64_t data_length, zip_error_t *error);

DESCRIPCIÓN

Use esta función para calcular el desplazamiento para un comando ZIP_SOURCE_SEEK o ZIP_SOURCE_SEEK_WRITE. data y data_length son los argumentos para la devolución de llamada de origen, offset es el desplazamiento actual y length es la longitud de los datos de origen o, para ZIP_SOURCE_SEEK_WRITE, la cantidad de datos escritos.

VALORES DEVUELTOS

En caso de éxito, devuelve el nuevo desplazamiento; en caso de error, devuelve -1 y establece error.

ERRORES

zip_source_seek_compute_offset() falla si:

[ZIP_ER_INVAL]
Uno de los argumentos es inválido o la búsqueda colocaría el desplazamiento fuera de los datos.

VER TAMBIÉN

zip_source_function(3)

HISTORIA

zip_source_seek_compute_offset() se añadió en libzip 1.0.
