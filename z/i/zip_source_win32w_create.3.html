ZIP_SOURCE_WIN32W(3) Manual de funciones de biblioteca ZIP_SOURCE_WIN32W(3)

NOMBRE

zip_source_win32w, zip_source_win32w_create — crear origen de datos a partir de un nombre de archivo Unicode de Windows

BIBLIOTECA

libzip (-lzip)

SINOPSIS

#include <zip.h>

zip_source_t *
zip_source_win32w(zip_t *archive, const wchar_t *fname, zip_uint64_t start, zip_int64_t len);

zip_source_t *
zip_source_win32w_create(const wchar_t *fname, zip_uint64_t start, zip_int64_t len, zip_error_t *error);

DESCRIPCIÓN

Las funciones zip_source_win32w() y zip_source_win32w_create() crean un origen zip en Windows usando un nombre Unicode de Windows. Abren fname y leen len bytes desde la posición start. Para una descripción del argumento len, ver zip_source_file(3).

Si el archivo soporta búsqueda, el origen puede ser usado para abrir un archivo zip desde él.

El archivo se abre y se lee cuando se utilizan los datos del origen, normalmente por zip_close() o zip_open_from_source().

VALORES DE RETORNO

Al completarse con éxito, se devuelve el origen creado. De lo contrario, se devuelve NULL y el código de error en archive o error se establece para indicar el error.

ERRORES

zip_source_win32w() y zip_source_win32w_create() fallan si:

[ZIP_ER_INVAL]
fname, start, o len son inválidos.
[ZIP_ER_MEMORY]
No se pudo asignar la memoria requerida.
[ZIP_ER_OPEN]
Falló la apertura de fname.

VER TAMBIÉN

libzip(3), zip_file_add(3), zip_file_replace(3), zip_source(5), zip_source_file(3), zip_source_win32a(3), zip_source_win32handle(3)

HISTORIAL

zip_source_win32w() se añadió en libzip 1.0.

ZIP_LENGTH_TO_END y ZIP_LENGTH_UNCHECKED se añadieron en libzip 1.10.1.
