zip_source_stat(3)

Paquete: libzip

Licencias: BSD

ZIP_SOURCE_STAT(3) Manual de funciones de biblioteca ZIP_SOURCE_STAT(3)

NOMBRE

zip_source_stat — obtener información sobre zip_source

BIBLIOTECA

libzip (-lzip)

SINOPSIS

#include <zip.h>

int
zip_source_stat(zip_source_t *source, zip_stat_t *sb);

DESCRIPCIÓN

La función zip_source_stat() obtiene información sobre la fuente zip source

El argumento sb es un puntero a una struct zip_source_stat (mostrada a continuación), en la que se coloca la información sobre la fuente zip.

struct zip_source_stat {
    zip_uint64_t valid;                 /* qué campos tienen valores válidos */
    const char *name;                   /* nombre del archivo */
    zip_uint64_t index;                 /* índice dentro del archivo */
    zip_uint64_t size;                  /* tamaño del archivo (sin comprimir) */
    zip_uint64_t comp_size;             /* tamaño del archivo (comprimido) */
    time_t mtime;                       /* tiempo de modificación */
    zip_uint32_t crc;                   /* crc de los datos del archivo */
    zip_uint16_t comp_method;           /* método de compresión utilizado */
    zip_uint16_t encryption_method;     /* método de cifrado utilizado */
    zip_uint32_t flags;                 /* reservado para uso futuro */
};
La estructura a la que apunta sb debe inicializarse con zip_stat_init(3) antes de llamar a zip_source_stat().

El campo valid de la estructura especifica qué otros campos son válidos. Compruebe si la bandera definida por las siguientes definiciones se encuentra en valid antes de acceder a los campos:

ZIP_STAT_NAME
name
ZIP_STAT_INDEX
index
ZIP_STAT_SIZE
size
ZIP_STAT_COMP_SIZE
comp_size
ZIP_STAT_MTIME
mtime
ZIP_STAT_CRC
crc
ZIP_STAT_COMP_METHOD
comp_method
ZIP_STAT_ENCRYPTION_METHOD
encryption_method
ZIP_STAT_FLAGS
flags

NOTA: Algunos campos solo pueden completarse después de haber leído todos los datos de la fuente, por ejemplo, los campos crc o size.

VALORES DE RETORNO

Al completarse con éxito, se devuelve 0. De lo contrario, se devuelve -1 y la información de error en source se establece para indicar el error.

VER TAMBIÉN

libzip(3), zip_source(5)

HISTORIA

zip_source_stat() se añadió en libzip 1.0.
