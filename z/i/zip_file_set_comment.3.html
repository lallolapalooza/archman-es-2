zip_file_set_comment(3)

Paquete: libzip

Licencias: BSD

ZIP_FILE_SET_COMMENT(3) Manual de funciones de biblioteca ZIP_FILE_SET_COMMENT(3)

NOMBRE

zip_file_set_comment — establece el comentario para un archivo en un zip

BIBLIOTECA

libzip (-lzip)

SINOPSIS

#include <zip.h>

int
zip_file_set_comment(zip_t *archive, zip_uint64_t index, const char *comment, zip_uint16_t len, zip_flags_t flags);

DESCRIPCIÓN

La función zip_file_set_comment() establece el comentario para el archivo en la posición index en el archivo zip a comment de longitud len. Si comment es NULL y len es 0, se eliminará el comentario del archivo. El argumento flags puede ser cualquiera de:

ZIP_FL_ENC_GUESS
Adivina la codificación de comment (por defecto). (Sólo se reconocen CP-437 y UTF-8).
ZIP_FL_ENC_UTF_8
Interpreta comment como UTF-8.
ZIP_FL_ENC_CP437
Interpreta comment como página de códigos 437 (CP-437).

VALORES DE RETORNO

Al completarse con éxito se devuelve 0. De lo contrario, se devuelve -1 y la información de error en archive se establece para indicar el error.

ERRORES

zip_file_set_comment() falla si:

[ZIP_ER_INVAL]
index no es un índice de archivo válido en archive, o len es menor que 0 o mayor que la longitud máxima del comentario en un archivo zip (65535), o comment no es una cadena codificada en UTF-8 válida.
[ZIP_ER_MEMORY]
No se pudo asignar la memoria requerida.
[ZIP_ER_RDONLY]
El archive se abrió en modo de solo lectura.

VER TAMBIÉN

libzip(3), zip_file_get_comment(3), zip_get_archive_comment(3), zip_set_archive_comment(3)

HISTORIA

zip_file_set_comment() se añadió en libzip 0.11.
