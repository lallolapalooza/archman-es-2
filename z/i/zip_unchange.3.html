zip_unchange(3)

Paquete: libzip

Licencias: BSD

ZIP_UNCHANGE(3) Manual de funciones de biblioteca ZIP_UNCHANGE(3)

NOMBRE

zip_unchange — deshacer cambios en un archivo dentro de un archivo zip

BIBLIOTECA

libzip (-lzip)

SINOPSIS

#include <zip.h>

int
zip_unchange(zip_t *archive, zip_uint64_t index);

DESCRIPCIÓN

Los cambios en el archivo en la posición index se revierten.

VALORES DE RETORNO

Si la operación se completa con éxito, se devuelve 0. De lo contrario, se devuelve -1 y el código de error en archive se establece para indicar el error.

ERRORES

zip_unchange() falla si:

[ZIP_ER_EXISTS]
Deshacer el cambio de nombre resultaría en un nombre duplicado en el archivo.
[ZIP_ER_INVAL]
index no es un índice de archivo válido en zip.

VER TAMBIÉN

libzip(3), zip_unchange_all(3), zip_unchange_archive(3)

HISTORIA

zip_unchange() se añadió en libzip 0.6. En libzip 0.10, el tipo de index se cambió de int a zip_uint64_t.
