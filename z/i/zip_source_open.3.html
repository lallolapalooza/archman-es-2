zip_source_open(3)

Paquete: libzip

Licencias: BSD

ZIP_SOURCE_OPEN(3) Manual de funciones de la biblioteca ZIP_SOURCE_OPEN(3)

NOMBRE

zip_source_open — abre zip_source para lectura

BIBLIOTECA

libzip (-lzip)

SINOPSIS

#include <zip.h>

int
zip_source_open(zip_source_t *source);

DESCRIPCIÓN

La función zip_source_open() abre source para lectura.

VALORES DE RETORNO

Al completarse con éxito, se devuelve 0. De lo contrario, se devuelve -1 y la información de error en source se establece para indicar el error.

VER TAMBIÉN

libzip(3), zip_source(5), zip_source_begin_write(3), zip_source_close(3), zip_source_read(3), zip_source_seek(3), zip_source_tell(3)

HISTORIA

zip_source_open() se añadió en libzip 1.0.
