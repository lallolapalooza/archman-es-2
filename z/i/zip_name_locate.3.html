NOMBRE

zip_name_locate — obtener el índice de un archivo por nombre

BIBLIOTECA

libzip (-lzip)

SINOPSIS

#include <zip.h>

zip_int64_t
zip_name_locate(zip_t *archive, const char *fname, zip_flags_t flags);

DESCRIPCION

La función zip_name_locate() devuelve el índice del archivo llamado fname en archive. Si archive no contiene un archivo con ese nombre, se devuelve -1.

Si no se especifican ni ZIP_FL_ENC_RAW ni ZIP_FL_ENC_STRICT, se adivina la codificación del nombre en el archivo ZIP y se convierte a UTF-8, si es necesario, antes de comparar.

Si no se especifican ni ZIP_FL_ENC_CP437 ni ZIP_FL_ENC_UTF_8, se adivina la codificación de fname.

Solo se reconocen CP-437 y UTF-8.

Las flags se especifican mediante ORando los siguientes valores, o 0 para ninguno de ellos.

ZIP_FL_NOCASE
Ignora las distinciones entre mayúsculas y minúsculas. (Solo funcionará bien si los nombres de archivo son ASCII). Con esta bandera, zip_name_locate() será lento para archivos con muchos archivos.
ZIP_FL_NODIR
Ignora la parte del directorio del nombre del archivo en el archivo. Con esta bandera, zip_name_locate() será lento para archivos con muchos archivos.
ZIP_FL_ENC_GUESS
Esta bandera no tiene efecto (su valor es 0); puede usarse para denotar explícitamente la ausencia de banderas de codificación.
ZIP_FL_ENC_RAW
Compara fname con los nombres sin modificar tal como están en el archivo ZIP, sin convertirlos a UTF-8.
ZIP_FL_ENC_STRICT
Sigue la especificación ZIP y espera nombres codificados en CP-437 en el archivo ZIP (excepto si están explícitamente marcados como UTF-8). Conviértelos a UTF-8 antes de comparar.
ZIP_FL_ENC_CP437
fname está codificado como CP-437.
ZIP_FL_ENC_UTF_8
fname está codificado como UTF-8.

Nota: ASCII es un subconjunto de CP-437 y UTF-8.

VALORES DE RETORNO

zip_name_locate() devuelve el índice del archivo llamado fname o -1, si archive no contiene una entrada con ese nombre.

ERRORES

zip_name_locate() falla si:

[ZIP_ER_INVAL]
Uno de los argumentos es inválido.
[ZIP_ER_MEMORY]
No se pudo asignar la memoria requerida.
[ZIP_ER_NOENT]
No se encontró ninguna entrada con el nombre fname en el archivo.

VER TAMBIÉN

libzip(3), zip_get_name(3)

HISTORIA

zip_name_locate() se añadió en libzip 0.6. En libzip 0.11, el tipo de retorno se cambió de int a zip_int64_t. En libzip 0.11, el tipo de flags se cambió de int a zip_flags_t.
