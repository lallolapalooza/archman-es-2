zip_get_archive_flag(3)

Paquete: libzip

Licencias: BSD

ZIP_GET_ARCHIVE_FLAG(3) Manual de funciones de biblioteca ZIP_GET_ARCHIVE_FLAG(3)

NOMBRE

zip_get_archive_flag — obtener indicadores de estado para zip

BIBLIOTECA

libzip (-lzip)

SINOPSIS

#include <zip.h>

int
zip_get_archive_flag(zip_t *archive, zip_flags_t flag, zip_flags_t flags);

DESCRIPCIÓN

La función zip_get_archive_flag() devuelve si el indicador flag está establecido para el archivo archive. Los indicadores del archivo pueden haber sido modificados con zip_set_archive_flag(); si flags se establece en ZIP_FL_UNCHANGED, se prueban los indicadores originales sin cambios.

Los indicadores soportados son:

ZIP_AFL_CREATE_OR_KEEP_FILE_FOR_EMPTY_ARCHIVE
Si este indicador se anula, el archivo se eliminará si el archivo está vacío. Si está establecido, se creará un archivo vacío, lo cual no es recomendado por la especificación zip. Este indicador siempre se anula a menos que sea explícitamente establecido por el usuario con zip_set_archive_flag(3).
ZIP_AFL_IS_TORRENTZIP
El archivo está en formato torrentzip.
ZIP_AFL_RDONLY
El archivo es de solo lectura.
ZIP_AFL_WANT_TORRENTZIP
Si el indicador está establecido, el archivo se escribirá en formato torrentzip. Este indicador siempre se anula a menos que sea explícitamente establecido por el usuario con zip_set_archive_flag(3).

VALORES DE RETORNO

zip_get_archive_flag() devuelve 1 si flag está establecido para archive, 0 si no, y -1 si ocurrió un error.

VER TAMBIÉN

libzip(3), zip_set_archive_flag(3)

HISTORIA

zip_get_archive_flag() se agregó en libzip 0.9. En libzip 0.11, el tipo de flag se cambió de int a zip_flags_t m y el tipo de flags se cambió de int a zip_flags_t. ZIP_AFL_CREATE_OR_KEEP_FILE_FOR_EMPTY_ARCHIVE, ZIP_AFL_IS_TORRENTZIP, y ZIP_AFL_WANT_TORRENTZIP se agregaron en libzip 1.10.0.
