ZIPTOOL(1) Manual de Comandos Generales ZIPTOOL(1)

NOMBRE

ziptool — modificar archivos zip

SINOPSIS

ziptool [-ceghnrst] [-l longitud] [-o desplazamiento] archivo-zip comando [args-comando ...] [comando [args-comando ...] ...]

DESCRIPCIÓN

ziptool modifica el archivo zip archivo-zip según los comandos dados.

Opciones soportadas:

-c
Comprueba la consistencia del archivo zip al abrirlo.
-e
Genera un error si el archivo ya existe (solo útil con -n).
-g
Adivina la codificación del nombre de archivo (para el comando stat).
-h
Muestra la ayuda.
-l longitud
Lee solo longitud bytes del archivo. Ver también -o.
-n
Crea el archivo si no existe. Ver también -e.
-o desplazamiento
Empieza a leer el archivo de entrada desde el desplazamiento. Ver también -l.
-r
Imprime la codificación cruda del nombre de archivo sin traducción (para el comando stat).
-s
Sigue estrictamente la convención de nombres de archivo (para el comando stat).
-t
Ignora el contenido actual del archivo, si lo hubiera. Nota: úselo con cuidado, elimina todo el contenido existente del archivo cuando modifique el archivo.

Comandos

Para todos los comandos a continuación, el índice es basado en cero. En otras palabras, la primera entrada en el archivo zip tiene el índice 0.

Comandos y argumentos soportados:

add nombre contenido
Añade un archivo llamado nombre usando la cadena contenido de la línea de comandos como datos.
add_dir nombre
Añade el directorio nombre.
add_file nombre archivo_a_añadir desplazamiento longitud
Añade el archivo nombre al archivo, usando longitud bytes del archivo archivo_a_añadir como datos de entrada, comenzando en el desplazamiento.
add_from_zip nombre nombre_archivo índice desplazamiento longitud
Añade un archivo llamado nombre al archivo usando datos de otro archivo zip nombre_archivo usando la entrada con índice índice y leyendo longitud bytes desde el desplazamiento.
cat índice
Saca el contenido del archivo para la entrada índice a la salida estándar.
count_extra índice flags
Imprime el número de campos extra para la entrada del archivo índice usando flags.
count_extra_by_id índice id_extra flags
Imprime el número de campos extra de tipo id_extra para la entrada del archivo índice usando flags.
delete índice
Elimina la entrada en el índice índice del archivo zip.
delete_extra índice índice_extra flags
Elimina el campo extra número índice_extra de la entrada del archivo índice usando flags.
delete_extra_by_id índice id_extra índice_extra flags
Elimina el campo extra número índice_extra de tipo id_extra de la entrada del archivo índice usando flags.
get_archive_comment
Imprime el comentario del archivo.
get_archive_flag flag
Imprime el estado del flag del archivo flag.
get_extra índice índice_extra flags
Imprime el campo extra número índice_extra para la entrada del archivo índice usando flags.
get_extra_by_id índice id_extra índice_extra flags
Imprime el campo extra número índice_extra de tipo id_extra para la entrada del archivo índice usando flags.
get_file_comment índice
Obtiene el comentario del archivo para la entrada del archivo índice.
get_num_entries flags
Imprime el número de entradas en el archivo usando flags.
name_locate nombre flags
Busca una entrada en el archivo con el nombre de archivo nombre usando flags e imprime su índice.
rename índice nombre
Renombra la entrada del archivo índice a nombre.
replace_file_contents índice datos
Reemplaza el contenido del archivo para la entrada del archivo índice con la cadena datos.
set_archive_comment comentario
Establece el comentario del archivo a comentario.
get_archive_flag flag valor
Establece el flag del archivo flag a valor.
set_extra índice id_extra índice_extra flags valor
Establece el campo extra número índice_extra de tipo id_extra para la entrada del archivo índice usando flags a valor.
set_file_comment índice comentario
Establece el comentario del archivo para la entrada del archivo índice a la cadena comentario.

NAME

ziptool — a command-line tool to manipulate ZIP archives

SYNOPSIS

ziptool [OPTIONS] archive command [arguments…]

DESCRIPTION

The ziptool utility is a command-line tool to manipulate ZIP archives using the libzip library.

The commands that can be performed are:

add file [newname]
Add file to the archive. If newname is specified, it will be used as the name of the file in the archive. Otherwise, the base name of file will be used.
cat index
Write the content of archive entry index to standard output.
delete index
Delete archive entry index.
extract index [path]
Extract archive entry index to the current directory, or to path if specified. If index is a directory, it is extracted recursively.
extract_all [path]
Extract all entries from the archive to the current directory, or to path if specified.
get_archive_flag flag
Get the value of archive flag flag.
get_error_num
Get the error number of the last failed operation.
get_error_system
Get the system error number of the last failed operation.
get_num_entries
Get the number of entries in the archive.
get_zip_comment
Get the comment of the zip archive.
get_zip_filename
Get the filename of the zip archive.
get_zip_num_entries
Get the number of entries in the zip archive.
ls
List the contents of the archive.
open archive [mode]
Open archive archive. The default mode is read/write. Available modes are: r (read), w (write), a (append), x (create).
set_archive_comment comment
Set the comment for the zip archive to comment.
set_archive_flag flag value
Set archive flag flag to value. See Archive flags below.
set_file_compression index method compression_flags
Set file compression method for archive entry index to method using compression_flags. Note: Currently, compression_flags are ignored.
set_file_encryption index method password
Set file encryption method for archive entry index to method with password password.
set_file_mtime index timestamp
Set file modification time for archive entry index to UNIX mtime timestamp.
set_file_mtime_all timestamp
Set file modification time for all archive entries to UNIX mtime timestamp.
set_password password
Set default password for encryption/decryption to password.
stat index
Print information about archive entry index.

Flags

Some commands take flag arguments. Each character in the argument sets the corresponding flag. Use 0 or the empty string for no flags.

Supported flags are:

4
ZIP_FL_ENC_CP437
8
ZIP_FL_ENC_UTF_8
C
ZIP_FL_NOCASE
c
ZIP_FL_CENTRAL
d
ZIP_FL_NODIR
l
ZIP_FL_LOCAL
r
ZIP_FL_ENC_RAW
s
ZIP_FL_ENC_STRICT
u
ZIP_FL_UNCHANGED

Archive flags

get_archive_flag and set_archive_flag work on the following flags:

  • create-or-keep-empty-file-for-archive
  • is-torrentzip
  • rdonly
  • want-torrentzip

Compression Methods

Some commands take compression method arguments. Supported methods are:

  • default
  • deflate
  • store

Encryption Methods

Some commands take encryption method arguments. Supported methods are:

  • none
  • AES-128
  • AES-192
  • AES-256

EXIT STATUS

The ziptool utility exits 0 on success, and >0 if an error occurs.

EXAMPLES

Add a file called teststring.txt to the zip archive testbuffer.zip with data “This is a test.\n” where “\n” is replaced with a newline character:

ziptool testbuffer.zip add teststring.txt \"This is a test.\n\"

Delete the first file from the zip archive testfile.zip:

ziptool testfile.zip delete 0

zipcmp(1), zipmerge(1), libzip(3)

HISTORY

ziptool was added in libzip 1.1.
