NOMBRE

ziproxylogtool - es un analizador de registros de bajo nivel

SINOPSIS

ziproxylogtool [opciones_generales] [opciones_de_filtrado]

DESCRIPCIÓN

ziproxylogtool es un analizador de registros de bajo nivel, cuyo propósito es ser invocado por scripts. Se espera que sea razonablemente rápido y genérico.

Estos programas siguen la sintaxis habitual de línea de comandos de GNU, con opciones largas que comienzan con dos guiones (`-'). A continuación se incluye un resumen de las opciones.

OPCIONES GENERALES

-m, --mode modo
Modo de salida: 
"g" - Estadísticas globales
"h" - Estadísticas por host (accesos, bytes_entrada, bytes_salida, %compresión, nombre_host)
"f" - Modo de filtrado (filtra entradas de registro según las opciones de filtrado)
-i, --in-file nombre_archivo
Archivo de entrada (archivo de registro de Ziproxy). Si no se especifica, usa stdin.
-o, --out-file nombre_archivo
Archivo de salida (salida de estadísticas). Si no se especifica, usa stdout.
-h, --help
Mostrar ayuda resumida

OPCIONES DE FILTRADO

Si se omiten, no se aplicarán.

-1, --epoch-min epoca_unix
Filtrar entradas a partir de esa época.
-2, --epoch-max epoca_unix
Filtrar entradas anteriores a esa época.
-3, --bytes-in-min bytes
Filtrar entradas donde bytes_entrada >= <bytes>
-4, --bytes-in-max bytes
Filtrar entradas donde bytes_entrada < <bytes>
-5, --bytes-out-min bytes
Filtrar entradas donde bytes_salida >= <bytes>
-6, --bytes-out-max bytes
Filtrar entradas donde bytes_salida < <bytes>
-7, --delay-min mili_segundos
Filtrar entradas donde el retraso >= <mili_segundos>
-8, --delay-max mili_segundos
Filtrar entradas donde el retraso < <mili_segundos>
