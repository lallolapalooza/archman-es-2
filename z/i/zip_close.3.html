zip_close(3)

Paquete: libzip

Licencias: BSD

ZIP_CLOSE(3) Manual de funciones de biblioteca ZIP_CLOSE(3)

NOMBRE

zip_close — cerrar archivo zip

BIBLIOTECA

libzip (-lzip)

SINOPSIS

#include <zip.h>

int
zip_close(zip_t *archive);

DESCRIPCIÓN

La función zip_close() escribe en el disco cualquier cambio realizado en archive. Si archive no contiene archivos, el archivo se elimina por completo (no se escribe ningún archivo vacío), a menos que se establezca la bandera de archivo ZIP_AFL_CREATE_OR_KEEP_FILE_FOR_EMPTY_ARCHIVE. Si tiene éxito, archive se libera. De lo contrario, archive no se modifica y aún debe liberarse.

Para cerrar y liberar un archivo zip sin guardar los cambios, use zip_discard(3).

Las actualizaciones de progreso para las interfaces gráficas se pueden implementar utilizando zip_register_progress_callback_with_state(3). La cancelación de la escritura de un archivo durante zip_close se puede implementar utilizando zip_register_cancel_callback_with_state(3).

VALORES DE RETORNO

Al completarse con éxito, se devuelve 0. De lo contrario, se devuelve -1 y el código de error en archive se establece para indicar el error.

ERRORES

zip_close() fallará si:

[ZIP_ER_EOF]
Se encontró un fin de archivo inesperado al leer de un archivo.
[ZIP_ER_INTERNAL]
La función de devolución de llamada de un archivo agregado o reemplazado devolvió un error pero no informó cuál.
[ZIP_ER_INVAL]
El argumento path es NULL.
[ZIP_ER_MEMORY]
No se pudo asignar la memoria requerida.
[ZIP_ER_NOZIP]
El archivo no es un archivo zip.
[ZIP_ER_READ]
Se produjo un error al leer un archivo.
[ZIP_ER_RENAME]
No se pudo renombrar un archivo temporal a su nombre final.
[ZIP_ER_SEEK]
Se produjo un error al buscar en un archivo.
[ZIP_ER_TMPOPEN]
No se pudo crear un archivo temporal.
[ZIP_ER_WRITE]
Se produjo un error al escribir en un archivo.
[ZIP_ER_ZLIB]
Se produjo un error durante la (des)compresión de un flujo con zlib(3).
Además, se pasarán los errores devueltos por la función de devolución de llamada para archivos agregados o reemplazados.

VER TAMBIÉN

libzip(3), zip_discard(3), zip_fdopen(3), zip_get_error(3), zip_open(3), zip_register_cancel_callback_with_state(3), zip_register_progress_callback_with_state(3), zip_set_archive_flag(3), zip_strerror(3)

HISTORIA

zip_close() se agregó en libzip 0.6.

AUTORES

Dieter Baron <dillo@nih.at> y Thomas Klausner <wiz@gatalith.at>

ADVERTENCIAS

Tenga en cuenta que todos los índices, la información de zip_stat(3) y otros datos sobre el archivo no son válidos después de zip_close. Cuando vuelva a abrir el mismo archivo, será una estructura zip_t completamente nueva.
