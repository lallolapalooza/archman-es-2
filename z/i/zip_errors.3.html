zip_errors(3)

Paquete: libzip

Licencias: BSD

ZIP_ERRORS(3) Manual de funciones de biblioteca ZIP_ERRORS(3)

NOMBRE

zip_errors — lista de todos los códigos de error de libzip

BIBLIOTECA

libzip (-lzip)

SINOPSIS

#include <zip.h>

DESCRIPCIÓN

Los siguientes códigos de error son utilizados por libzip:

[ZIP_ER_CANCELLED]
Operación cancelada.
[ZIP_ER_CHANGED]
La entrada ha sido modificada.
[ZIP_ER_CLOSE]
El cierre del archivo zip falló.
[ZIP_ER_COMPNOTSUPP]
Método de compresión no soportado.
[ZIP_ER_COMPRESSED_DATA]
Datos comprimidos inválidos.
[ZIP_ER_CRC]
Error de CRC.
[ZIP_ER_DATA_LENGTH]
Longitud de datos inesperada.
[ZIP_ER_DELETED]
La entrada ha sido eliminada.
[ZIP_ER_ENCRNOTSUPP]
Método de encriptación no soportado.
[ZIP_ER_EOF]
Fin de archivo prematuro.
[ZIP_ER_EXISTS]
El archivo ya existe.
[ZIP_ER_INCONS]
Archivo zip inconsistente.
[ZIP_ER_INTERNAL]
Error interno.
[ZIP_ER_INUSE]
El recurso todavía está en uso.
[ZIP_ER_INVAL]
Argumento inválido.
[ZIP_ER_MEMORY]
Fallo de malloc.
[ZIP_ER_MULTIDISK]
Los archivos zip multidisco no están soportados.
[ZIP_ER_NOENT]
No existe tal archivo.
[ZIP_ER_NOPASSWD]
No se proporcionó contraseña.
[ZIP_ER_NOT_ALLOWED]
No permitido en torrentzip.
[ZIP_ER_NOZIP]
No es un archivo zip.
[ZIP_ER_OK]
Sin error.
[ZIP_ER_OPEN]
No se puede abrir el archivo.
[ZIP_ER_OPNOTSUPP]
Operación no soportada.
[ZIP_ER_RDONLY]
Archivo de solo lectura.
[ZIP_ER_READ]
Error de lectura.
[ZIP_ER_REMOVE]
No se puede eliminar el archivo.
[ZIP_ER_RENAME]
El cambio de nombre del archivo temporal falló.
[ZIP_ER_SEEK]
Error de búsqueda.
[ZIP_ER_TELL]
Error de tell.
[ZIP_ER_TMPOPEN]
Fallo al crear el archivo temporal.
[ZIP_ER_TRUNCATED_ZIP]
Archivo zip posiblemente truncado o corrupto.
[ZIP_ER_WRITE]
Error de escritura.
[ZIP_ER_WRONGPASSWD]
Se proporcionó una contraseña incorrecta.
[ZIP_ER_ZIPCLOSED]
El archivo zip contenedor fue cerrado.
[ZIP_ER_ZLIB]
Error de Zlib.
