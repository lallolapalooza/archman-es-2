zip_source_zip_create(3)

Paquete: libzip

Licencias: BSD

ZIP_SOURCE_ZIP(3) Manual de funciones de la biblioteca ZIP_SOURCE_ZIP(3)

NOMBRE

zip_source_zip, zip_source_zip_create — crear fuente de datos desde un archivo zip (interfaz obsoleta)

BIBLIOTECA

libzip (-lzip)

SINOPSIS

#include <zip.h>

zip_source_t *
zip_source_zip(zip_t *archive, zip_t *srcarchive, zip_uint64_t srcidx, zip_flags_t flags, zip_uint64_t start, zip_int64_t len);

zip_source_t *
zip_source_zip_create(zip_t *srcarchive, zip_uint64_t srcidx, zip_flags_t flags, zip_uint64_t start, zip_int64_t len, zip_error_t *error);

DESCRIPCIÓN

Las funciones zip_source_zip() y zip_source_zip_create() son las versiones obsoletas de zip_source_zip_file(3) o zip_source_zip_file_create(3) respectivamente. Si desea obtener los datos comprimidos del archivo completo, use

zip_source_zip_file(za, source_archive, source_index, ZIP_FL_COMPRESSED, 0, -1, NULL)

Las funciones zip_source_zip() y zip_source_zip_create() crean una fuente zip desde un archivo en un archivo zip. El argumento srcarchive es el archivo zip (abierto) que contiene el archivo zip de origen en el índice srcidx. Se utilizarán len bytes desde la posición start en el zip_source. Si len es 0 o -1, se utilizará el resto del archivo, comenzando desde start. Si start es cero y len es -1, se copiará todo el archivo sin descomprimirlo.

Las banderas admitidas son:

ZIP_FL_UNCHANGED
Intenta obtener los datos originales sin ningún cambio que se haya podido realizar en srcarchive después de abrirlo.

VALORES DE RETORNO

Al completarse con éxito, se devuelve la fuente creada. En caso contrario, se devuelve NULL y el código de error en archive o error se establece para indicar el error.

ERRORES

zip_source_zip() y zip_source_zip_create() fallan si:

[ZIP_ER_CHANGED]
Se solicitaron datos sin cambios, pero no están disponibles.
[ZIP_ER_INVAL]
srcarchive, srcidx, start, o len son inválidos.
[ZIP_ER_MEMORY]
No se pudo asignar la memoria requerida.
Adicionalmente, pueden devolver todos los códigos de error de zip_stat_index() y zip_fopen_index().

VER TAMBIÉN

libzip(3), zip_file_add(3), zip_file_replace(3), zip_source(5)

HISTORIA

zip_source_zip() se añadió en libzip 1.0. zip_source_zip_create() se añadió en libzip 1.8.0. Ambas fueron marcadas como obsoletas en libzip 1.10.0. Use zip_source_zip_file() o zip_source_zip_file_create() en su lugar.
