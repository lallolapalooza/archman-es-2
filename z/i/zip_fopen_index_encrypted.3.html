zip_fopen_index_encrypted(3)

Paquete: libzip

Licencias: BSD

ZIP_FOPEN_ENCRYPTED(3) Manual de funciones de biblioteca ZIP_FOPEN_ENCRYPTED(3)

NOMBRE

zip_fopen_encrypted, zip_fopen_index_encrypted — abrir archivo cifrado en un archivo zip para lectura

BIBLIOTECA

libzip (-lzip)

SINOPSIS

#include <zip.h>

zip_file_t *
zip_fopen_encrypted(zip_t *archivo, const char *fname, zip_flags_t flags, const char *password);

zip_file_t *
zip_fopen_index_encrypted(zip_t *archivo, zip_uint64_t index, zip_flags_t flags, const char *password);

DESCRIPCIÓN

La función zip_fopen_encrypted() abre el archivo cifrado con nombre fname en archivo usando la contraseña proporcionada en el argumento password. Si password es NULL o una cadena vacía, se usa la contraseña predeterminada (ver zip_set_default_password(3)). El argumento flags es el mismo que para zip_fopen(3).

La función zip_fopen_index_encrypted() abre el archivo en la posición index, ver zip_fopen_index(3). Estas funciones son llamadas automáticamente por zip_fopen(3); solo necesita llamarlas si desea especificar una contraseña no predeterminada (ver zip_set_default_password(3)).

VALORES DE RETORNO

Al completarse con éxito, se devuelve un puntero a struct zip_file. De lo contrario, se devuelve NULL y el código de error en archivo se establece para indicar el error.

ERRORES

[ZIP_ER_NOPASSWD]
No se proporcionó contraseña.

La función zip_fopen_encrypted() también puede fallar y establecer zip_err para cualquiera de los errores especificados para la rutina zip_fopen(3).

La función zip_fopen_index_encrypted() también puede fallar y establecer zip_err para cualquiera de los errores especificados para la rutina zip_fopen_index(3).

VER TAMBIÉN

libzip(3), zip_fclose(3), zip_fopen(3), zip_fread(3), zip_get_num_entries(3), zip_name_locate(3)

HISTORIA

zip_fopen_encrypted() y zip_fopen_index_encrypted() se agregaron en libzip 1.0.

AUTORES

Dieter Baron <dillo@nih.at> y Thomas Klausner <wiz@gatalith.at>

ADVERTENCIAS

El formato de archivo zip proporciona una posibilidad muy limitada para la verificación de contraseñas (un hash corto se compara con un byte en el archivo zip). Por esta razón, leer un archivo con una contraseña incorrecta puede fallar inmediatamente con ZIP_ER_WRONGPASSWD, pero si la discrepancia no se detecta, un error de zlib puede devolverse más tarde. Dado que los errores de zlib también pueden ser causados por datos comprimidos corruptos, no hay forma de asegurarse de si la contraseña era incorrecta o correcta, pero los datos comprimidos eran inválidos.
