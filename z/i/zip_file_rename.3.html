zip_file_rename(3)

Paquete: libzip

Licencias: BSD

ZIP_FILE_RENAME(3) Manual de funciones de biblioteca ZIP_FILE_RENAME(3)

NOMBRE

zip_file_rename — renombrar archivo en un archivo zip

BIBLIOTECA

libzip (-lzip)

SINOPSIS

#include <zip.h>

int
zip_file_rename(zip_t *archive, zip_uint64_t index, const char *name, zip_flags_t flags);

DESCRIPCIÓN

El archivo en la posición index en el archivo zip archive se renombra a name. El argumento flags puede ser cualquiera de:

ZIP_FL_ENC_GUESS
Adivinar la codificación de name (por defecto). (Solo se reconocen CP-437 y UTF-8).
ZIP_FL_ENC_UTF_8
Interpretar name como UTF-8.
ZIP_FL_ENC_CP437
Interpretar name como página de códigos 437 (CP-437).

VALORES DE RETORNO

Si la operación se completa con éxito, se devuelve 0. De lo contrario, se devuelve -1 y el código de error en archive se establece para indicar el error.

ERRORES

zip_file_rename() falla si:

[ZIP_ER_DELETED]
El archivo a renombrar ha sido eliminado del archivo zip.
[ZIP_ER_EXISTS]
Ya existe un archivo llamado name en el archivo zip.
[ZIP_ER_INVAL]
index no es un índice de archivo válido en archive, name es NULL, una cadena vacía, o no es una cadena codificada en UTF-8 válida. Tampoco se puede renombrar un archivo a un directorio o viceversa. Los directorios se denotan con una barra inclinada al final.

VER TAMBIÉN

libzip(3), zip_unchange(3)

HISTORIAL

zip_file_rename() se agregó en libzip 0.11.
