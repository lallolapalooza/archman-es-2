zip_fopen(3)

Paquete: libzip

Licencias: BSD

ZIP_FOPEN(3) Manual de funciones de biblioteca ZIP_FOPEN(3)

NOMBRE

zip_fopen, zip_fopen_index — abrir un archivo en un archivo zip para lectura

BIBLIOTECA

libzip (-lzip)

SINOPSIS

#include <zip.h>

zip_file_t *
zip_fopen(zip_t *archive, const char *fname, zip_flags_t flags);

zip_file_t *
zip_fopen_index(zip_t *archive, zip_uint64_t index, zip_flags_t flags);

DESCRIPCIÓN

La función zip_fopen() abre el archivo con el nombre fname en archive. El argumento flags especifica cómo se debe realizar la búsqueda del nombre, de acuerdo con los valores descritos en zip_name_locate(3). Además, los siguientes valores pueden ser combinados con él mediante un or.

ZIP_FL_COMPRESSED
Lee los datos comprimidos. De lo contrario, los datos son descomprimidos por zip_fread().
ZIP_FL_UNCHANGED
Lee los datos originales del archivo zip, ignorando cualquier cambio realizado en el archivo; esto no es compatible con todas las fuentes de datos.

La función zip_fopen_index() abre el archivo en la posición index.

Si se encuentran datos cifrados, las funciones llaman a zip_fopen_encrypted(3) o zip_fopen_index_encrypted(3) respectivamente, utilizando la contraseña predeterminada establecida con zip_set_default_password(3).

VALORES DE RETORNO

Al completarse con éxito, se devuelve un puntero a struct zip_file. De lo contrario, se devuelve NULL y el código de error en archive se establece para indicar el error.

ERRORES

[ZIP_ER_CHANGED]
Los datos del archivo han sido modificados y la fuente de datos no admite la relectura de datos.
[ZIP_ER_COMPNOTSUPP]
El método de compresión utilizado no es compatible.
[ZIP_ER_ENCRNOTSUPP]
El método de cifrado utilizado no es compatible.
[ZIP_ER_MEMORY]
No se pudo asignar la memoria requerida.
[ZIP_ER_NOPASSWD]
El archivo está cifrado, pero no se ha proporcionado ninguna contraseña.
[ZIP_ER_READ]
Se produjo un error al leer el archivo.
[ZIP_ER_SEEK]
Se produjo un error al buscar en el archivo.
[ZIP_ER_WRONGPASSWD]
La contraseña proporcionada no coincide con la contraseña utilizada para el cifrado. Tenga en cuenta que algunas contraseñas incorrectas no son detectadas por la comprobación realizada por zip_fopen().
[ZIP_ER_ZLIB]
Falló la inicialización del flujo zlib.

La función zip_fopen() también puede fallar y establecer zip_err para cualquiera de los errores especificados para la rutina zip_name_locate(3).

La función zip_fopen_index() también puede fallar con ZIP_ER_INVAL si index no es válido.

VER TAMBIÉN

libzip(3), zip_fclose(3), zip_fread(3), zip_fseek(3), zip_get_num_entries(3), zip_name_locate(3), zip_set_default_password(3)

HISTORIA

zip_fopen() y zip_fopen_index() se añadieron en libzip 1.0.
