ZIP_SET_FILE_COMPRESSION(3) Manual de funciones de la biblioteca ZIP_SET_FILE_COMPRESSION(3)

NOMBRE

zip_set_file_compression — establecer el método de compresión para un archivo zip

BIBLIOTECA

libzip (-lzip)

SINOPSIS

#include <zip.h>

int
zip_set_file_compression(zip_t *archive, zip_uint64_t index, zip_int32_t comp, zip_uint32_t comp_flags);

DESCRIPCIÓN

La función zip_set_file_compression() establece el método de compresión para el archivo en la posición index en el archivo zip a comp con las comp_flags específicas del método de compresión. comp es el mismo que se devuelve en zip_stat(3). Para el argumento comp, actualmente solo se soportan los siguientes valores:

ZIP_CM_DEFAULT
compresión por defecto; actualmente lo mismo que ZIP_CM_DEFLATE, pero se ignoran los flags.
ZIP_CM_STORE
Almacenar el archivo sin comprimir.
ZIP_CM_BZIP2
Comprimir el archivo utilizando el algoritmo bzip2(1).
ZIP_CM_DEFLATE
Deflactar el archivo con el algoritmo zlib(3) y opciones por defecto.
ZIP_CM_XZ
Usar el algoritmo xz(1) para la compresión.
ZIP_CM_ZSTD
Usar el algoritmo zstd(1) para la compresión.

NOTA: Solo se puede asumir que los métodos deflate y store son universalmente soportados.

El argumento comp_flags define el nivel de compresión. Este valor depende del algoritmo de compresión. En general, los números más bajos significan compresión/descompresión más rápida y los números más altos significan compresión/descompresión más lenta. Para ZIP_CM_BZIP, ZIP_CM_DEFLATE y ZIP_CM_XZ, 1 es la compresión más rápida y 9 la mejor, 0 elige el valor por defecto. Para ZIP_CM_ZSTD los valores posibles son ZSTD_minCLevel(3) a ZSTD_maxCLevel(3); los valores negativos deben convertirse a zip_uint32_t.

Se podrían añadir más flags específicos del método de compresión con el tiempo.

El método de compresión actual para un archivo en un archivo zip se puede determinar utilizando zip_stat(3).

VALORES DE RETORNO

Si la operación se completa con éxito, se devuelve 0. De lo contrario, se devuelve -1 y la información de error en archive se establece para indicar el error.

ERRORES

zip_set_file_compression() falla si:

[ZIP_ER_COMPNOTSUPP]
Se solicitó un método de compresión no soportado.
[ZIP_ER_INVAL]
index no es un índice de archivo válido en archive, o la combinación de argumentos es inválida.
[ZIP_ER_RDONLY]
Archivo zip de solo lectura, no se permiten cambios.

VER TAMBIÉN

libzip(3), zip_compression_method_supported(3), zip_stat(3)

HISTORIA

zip_set_file_compression() se añadió en libzip 0.11.
