ZIP_ERROR_CODE_SYSTEM(3) Manual de Funciones de Biblioteca ZIP_ERROR_CODE_SYSTEM(3)

NOMBRE

zip_error_code_system — obtener la parte del código de error del sistema operativo de zip_error

BIBLIOTECA

libzip (-lzip)

SINOPSIS

#include <zip.h>

int
zip_error_code_system(const zip_error_t *ze);

DESCRIPCIÓN

La función zip_error_code_system() devuelve la parte específica del sistema del error del error zip_error ze. Para saber qué sistema informó del error, utilice zip_error_system_type(3).

VER TAMBIÉN

libzip(3), zip_error_code_zip(3), zip_error_system_type(3)

HISTORIA

zip_error_code_system() se añadió en libzip 1.0.
