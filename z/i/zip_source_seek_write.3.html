ZIP_SOURCE_SEEK_WRITE(3) Manual de Funciones de Biblioteca ZIP_SOURCE_SEEK_WRITE(3)

NOMBRE

zip_source_seek_write — establece el desplazamiento de escritura en el origen zip

BIBLIOTECA

libzip (-lzip)

SINOPSIS

#include <zip.h>

int
zip_source_seek_write(zip_source_t *source, zip_int64_t offset, int whence);

DESCRIPCIÓN

La función zip_source_seek_write() establece el desplazamiento de escritura actual para source. Al igual que en fseek(3), dependiendo del argumento whence, el offset se cuenta relativo a:

SEEK_SET
inicio del archivo
SEEK_CUR
desplazamiento de escritura actual en el archivo
SEEK_END
final del archivo

VALORES DE RETORNO

Al completarse con éxito, se devuelve 0. De lo contrario, se devuelve -1 y la información de error en source se establece para indicar el error.

VER TAMBIÉN

libzip(3), zip_source(5), zip_source_begin_write(3), zip_source_commit_write(3), zip_source_rollback_write(3), zip_source_tell_write(3), zip_source_write(3)

HISTORIAL

zip_source_seek_write() se añadió en libzip 1.0.
