NOMBRE

zipcloak - cifra entradas en un archivo zip

SINOPSIS

zipcloak [-d] [-b ruta] [-h] [-v] [-L] archivo.zip

ARGUMENTOS


archivo.zip Archivo zip para cifrar entradas en

OPCIONES

-b ruta
--temp-path ruta
Usa el directorio dado por ruta para el archivo zip temporal.
-d
--decrypt
Descifra entradas cifradas (copia si se proporciona la contraseña incorrecta).
-h
--help 
Muestra una breve ayuda.
-L
--license
Muestra la licencia del software.
-O ruta
--output-file archivo.zip
Escribe la salida al nuevo archivo archivo.zip, dejando el archivo original intacto.
-q
--quiet
Operación silenciosa. Suprime algunos mensajes informativos.
-v
--version
Muestra información de la versión.

DESCRIPCIÓN

zipcloak cifra todas las entradas no cifradas en el archivo zip. Esta es la acción por defecto.

La opción -d se utiliza para descifrar entradas cifradas en el archivo zip.
zipcloak utiliza el cifrado zip original que se considera débil.

EJEMPLOS

Por añadir.

ERRORES

Archivos grandes (más de 2 GB) y archivos grandes aún no soportados.

Archivos divididos aún no soportados. Una solución es convertir el archivo dividido en un archivo de un solo archivo usando zip y luego usar zipcloak en el archivo de un solo archivo. Si es necesario, el archivo resultante se puede dividir nuevamente usando zip.
