zip_file_replace(3)

Paquete: libzip

Licencias: BSD

ZIP_FILE_ADD(3) Manual de funciones de biblioteca ZIP_FILE_ADD(3)

NOMBRE

zip_file_add, zip_file_replace — añadir archivo al archivo zip o reemplazar archivo en archivo zip

BIBLIOTECA

libzip (-lzip)

SINOPSIS

#include <zip.h>

zip_int64_t
zip_file_add(zip_t *archive, const char *name, zip_source_t *source, zip_flags_t flags);

int
zip_file_replace(zip_t *archive, zip_uint64_t index, zip_source_t *source, zip_flags_t flags);

DESCRIPCIÓN

La función zip_file_add() añade un archivo a un archivo zip, mientras que zip_file_replace() reemplaza un archivo existente en un archivo zip. El argumento archive especifica el archivo zip al que se debe añadir el archivo. name es el nombre del archivo en el archivo zip (para zip_file_add()), mientras que index especifica qué archivo debe ser reemplazado (para zip_file_replace()). El argumento flags puede ser cualquier combinación de ZIP_FL_OVERWRITE con una de ZIP_FL_ENC_*:

ZIP_FL_OVERWRITE
Sobrescribir cualquier archivo existente del mismo nombre. Solo para zip_file_add.
ZIP_FL_ENC_GUESS
Adivinar la codificación de name (predeterminado). (Solo se reconocen CP-437 y UTF-8).
ZIP_FL_ENC_UTF_8
Interpretar name como UTF-8.
ZIP_FL_ENC_CP437
Interpretar name como página de códigos 437 (CP-437).
Los datos se obtienen del argumento source, véase zip_source(5).

NOTA: zip_source_free(3) no debe llamarse en un source después de que se haya utilizado con éxito en una llamada zip_file_add o zip_file_replace.

Tenga en cuenta también que al usar zip_replace, la información del campo extra del archivo de destino se eliminará, ya que esto suele depender del contenido del archivo. Si desea conservarlos, consúltalos de antemano con zip_file_extra_field_get(3) y restáuralos después de zip_replace con zip_file_extra_field_set(3).

VALORES DE RETORNO

Al completarse con éxito, zip_file_add() devuelve el índice del nuevo archivo en el archivo zip, y zip_file_replace() devuelve 0. De lo contrario, se devuelve -1 y el código de error en archive se establece para indicar el error.

EJEMPLOS

zip_source_t *s;
const char buf[]="teststring";

if ((s=zip_source_buffer(archive, buf, sizeof(buf), 0)) == NULL ||
    zip_file_add(archive, name, s, ZIP_FL_ENC_UTF_8) < 0) {
    zip_source_free(s);
    printf("error adding file: %s\n", zip_strerror(archive));
}

ERRORES

zip_file_add() y zip_file_replace() fallan si:

[ZIP_ER_EXISTS]
Ya existe un archivo llamado name en el archivo zip. (Solo se aplica a zip_file_add(), y solo si ZIP_FL_OVERWRITE no se proporciona).
[ZIP_ER_INVAL]
source o name son NULL, o index es inválido.
[ZIP_ER_MEMORY]
No se pudo asignar la memoria requerida.
[ZIP_ER_RDONLY]
El archivo zip se abrió en modo de solo lectura.

VER TAMBIÉN

libzip(3), zip_source(5)

HISTORIA

zip_file_add() y zip_file_replace() se añadieron en libzip 0.11.
