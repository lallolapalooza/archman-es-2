ZIP_DELETE(3) Manual de funciones de biblioteca ZIP_DELETE(3)

NOMBRE

zip_delete — eliminar archivo de un archivo zip

BIBLIOTECA

libzip (-lzip)

SINOPSIS

#include <zip.h>

int
zip_delete(zip_t *archive, zip_uint64_t index);

DESCRIPCIÓN

El archivo en la posición index en el archivo zip archive se marca como eliminado.

VALORES DE RETORNO

Al completar con éxito se devuelve 0. De lo contrario, se devuelve -1 y el código de error en archive se establece para indicar el error.

ERRORES

zip_delete() falla si:

[ZIP_ER_INVAL]
El index no es un índice de archivo válido en archive.

VER TAMBIÉN

libzip(3), zip_unchange(3)

HISTORIA

zip_delete() se añadió en libzip 0.6. En libzip 0.10 el tipo de index se cambió de int a zip_uint64_t.
