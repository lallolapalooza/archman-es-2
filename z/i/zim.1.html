ZIM(1) Comandos de usuario ZIM(1)

NOMBRE

zim - Editor de Wiki de Escritorio

SINOPSIS

uso: zim [OPCIONES] [CUADERNO [ENLACE_PAGINA]]
o: zim --gui [OPCIONES] [CUADERNO [ENLACE_PAGINA]]
o: zim --server [OPCIONES] [CUADERNO]
o: zim --export [OPCIONES] CUADERNO [PAGINA]
o: zim --import [OPCIONES] CUADERNO PAGINA ARCHIVOS
o: zim --search [OPCIONES] CUADERNO CONSULTA
o: zim --index [OPCIONES] CUADERNO
o: zim --plugin PLUGIN [ARGUMENTOS]
o: zim --manual [OPCIONES] [ENLACE_PAGINA]
o: zim --help

CUADERNO puede ser una ruta de archivo local, una URI de archivo local o un nombre de cuaderno PAGINA puede ser un nombre de página completamente especificado ENLACE_PAGINA es un nombre de página completamente especificado, opcionalmente ampliado con un ID de ancla

DESCRIPCIÓN

Zim es un editor de texto gráfico utilizado para mantener una colección de páginas wiki. Cada página puede contener enlaces a otras páginas, formato simple e imágenes. Las páginas se almacenan en una estructura de carpetas, como en un esquema, y pueden tener archivos adjuntos. Crear una nueva página es tan fácil como enlazar a una página inexistente. Todos los datos se almacenan en archivos de texto plano con formato wiki. Varios complementos proporcionan funcionalidad adicional, como un gestor de listas de tareas, un editor de ecuaciones, un icono de bandeja y soporte para control de versiones.

Zim se puede utilizar para:

•
Mantener un archivo de notas
•
Mantener un diario diario o semanal
•
Tomar notas durante reuniones o conferencias
•
Organizar listas de tareas
•
Redactar entradas de blog y correos electrónicos
•
Hacer lluvia de ideas

OPCIONES

Opciones generales:
--gui ejecuta el editor (esta es la opción predeterminada)
--server ejecuta el servidor web
--export exporta a un formato diferente
--import importa uno o más archivos a un cuaderno
--search ejecuta una consulta de búsqueda en un cuaderno
--index construye un índice para un cuaderno
--plugin llama a una función específica del complemento
--manual abre el manual de usuario
-V, --verbose imprime información en la terminal
-D, --debug imprime mensajes de depuración
-v, --version imprime la versión y sale
-h, --help imprime este texto

Opciones de GUI:
--list muestra la lista de cuadernos en lugar de
abrir el cuaderno predeterminado
--geometry tamaño y posición de la ventana como AxAxX+Y
--fullscreen inicia en modo de pantalla completa
--non-unique inicia un nuevo proceso, no se conecta a un proceso existente
--standalone inicia un nuevo proceso por cuaderno, implica --non-unique

Opciones del servidor:
--port puerto a utilizar (por defecto es 8080)
--template nombre o ruta de archivo de la plantilla a utilizar
--private sirve solo a localhost
--gui ejecuta el envoltorio de GUI para el servidor

Opciones de exportación:
-o, --output directorio de salida (opción obligatoria)
--format formato a utilizar (por defecto es 'html')
--template nombre o ruta de archivo de la plantilla a utilizar
--root-url url a utilizar para la raíz del documento
--index-page nombre de la página de índice
-r, --recursive al exportar una página, exportar también las subpáginas
-s, --singlefile exporta todas las páginas a un único archivo de salida
-O, --overwrite fuerza la sobrescritura de archivo(s) existente(s)

Opciones de importación:
--format formato a leer (por defecto es 'wiki')
--assubpage importa archivos como subpáginas de RUTA, esto es implícitamente verdadero
cuando RUTA termina con ":" o cuando se proporcionan varios archivos

Opciones de búsqueda:
-s, --with-scores imprime la puntuación de cada página, ordena por puntuación

Opciones de índice:
-f, --flush vacía el índice primero y fuerza la reconstrucción

Pruebe 'zim --manual' para obtener más ayuda.
