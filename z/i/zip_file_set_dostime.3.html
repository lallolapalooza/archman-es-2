zip_file_set_dostime(3)

Paquete: libzip

Licencias: BSD

ZIP_FILE_SET_MTIME(3) Manual de funciones de biblioteca ZIP_FILE_SET_MTIME(3)

NOMBRE

zip_file_set_dostime, zip_file_set_mtime — establecer la hora de última modificación (mtime) para un archivo en zip

BIBLIOTECA

libzip (-lzip)

SINOPSIS

#include <zip.h>

int
zip_file_set_dostime(zip_t *archive, zip_uint64_t index, zip_uint16_t dostime, zip_uint16_t dosdate, zip_flags_t flags);

int
zip_file_set_mtime(zip_t *archive, zip_uint64_t index, time_t mtime, zip_flags_t flags);

DESCRIPCIÓN

La función zip_file_set_mtime() establece la hora de última modificación (mtime) del archivo en la posición index en el archivo zip a mtime. Actualmente, no se implementa ningún soporte para ningún flags.

En el archivo zip, la hora y la fecha se guardan como dos enteros de 16 bits. Para establecer los valores directamente, llame a la función zip_file_set_dostime(). Los valores de los bytes de hora se definen de la siguiente manera:

0-4
segundos divididos por dos (1-2 = 1, 3-4 = 2, ...)
5-10
minuto (0-59)
11-15
hora (0-23)

Los valores de los bytes de fecha se definen de la siguiente manera:

0-4
día del mes (1-31)
5-8
mes (enero = 1, febrero = 2, ...)
9-15
año de desplazamiento desde 1980 (1980 = 0, 1981 = 1, ...)

VALORES DE RETORNO

Al completarse con éxito, se devuelve 0. De lo contrario, se devuelve -1 y la información de error en archive se establece para indicar el error.

ERRORES

zip_file_set_dostime() y zip_file_set_mtime() fallan si:

[ZIP_ER_INVAL]
index no es un índice de archivo válido en archive.
[ZIP_ER_MEMORY]
No se pudo asignar la memoria requerida.
[ZIP_ER_OPNOTSUPP]
La encriptación tradicional de PKWare utiliza la mtime del archivo, por lo tanto, no se puede cambiar sin volver a cifrar los datos.
[ZIP_ER_RDONLY]
El archive se abrió en modo de solo lectura.

VER TAMBIÉN

libzip(3), zip_stat(3)

HISTORIA

La función zip_file_set_mtime() se añadió en libzip 1.0. La función zip_file_set_dostime() se añadió en libzip 1.6.

AUTORES

Dieter Baron <dillo@nih.at> y Thomas Klausner <wiz@gatalith.at>

ADVERTENCIAS

Siguiendo la práctica histórica, la función zip_file_set_mtime() traduce la hora del archivo zip a la zona horaria local. Si desea evitar esto, utilice la función zip_file_set_dostime() en su lugar.
