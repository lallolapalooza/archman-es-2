zip_error_clear(3)

Paquete: libzip

Licencias: BSD

ZIP_ERROR_CLEAR(3) Manual de funciones de la biblioteca ZIP_ERROR_CLEAR(3)

NOMBRE

zip_error_clear, zip_file_error_clear — borra el estado de error para el archivo o fichero

BIBLIOTECA

libzip (-lzip)

SINOPSIS

#include <zip.h>

void
zip_error_clear(zip_t *archive);

void
zip_file_error_clear(zip_file_t *file);

DESCRIPCIÓN

La función zip_error_clear() borra el estado de error para el archivo zip archive.

La función zip_file_error_clear() hace lo mismo para el fichero zip file.

VER TAMBIÉN

libzip(3), zip_get_error(3)

HISTORIA

zip_error_clear() y zip_file_error_clear() se añadieron en libzip 0.8.
