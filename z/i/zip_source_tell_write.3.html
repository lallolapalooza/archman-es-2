NOMBRE

zip_source_tell_write — informa la posición actual de escritura en la fuente zip

BIBLIOTECA

libzip (-lzip)

SINOPSIS

#include <zip.h>

zip_int64_t
zip_source_tell_write(zip_source_t *source);

DESCRIPCIÓN

La función zip_source_tell_write() devuelve la posición actual de escritura para source. El valor de retorno puede pasarse a zip_source_seek_write(3) con whence establecido en SEEK_SET para volver a la misma ubicación en la fuente.

VALORES DE RETORNO

En caso de éxito, se devuelve la posición actual de escritura. De lo contrario, se devuelve -1 y la información de error en source se establece para indicar el error.

VER TAMBIÉN

libzip(3), zip_source(5), zip_source_begin_write(3), zip_source_commit_write(3), zip_source_rollback_write(3), zip_source_tell(3), zip_source_write(3)

HISTORIA

zip_source_tell_write() se añadió en libzip 1.0.
