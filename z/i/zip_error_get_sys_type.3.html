ZIP_ERROR_GET_SYS_TYPE(3) Manual de Funciones de Biblioteca ZIP_ERROR_GET_SYS_TYPE(3)

NOMBRE

zip_error_get_sys_type — obtener el tipo de código de error del sistema (interfaz obsoleta)

BIBLIOTECA

libzip (-lzip)

SINOPSIS

#include <zip.h>

int
zip_error_get_sys_type(int ze);

DESCRIPCIÓN

La función zip_error_get_sys_type() está obsoleta; use zip_error_init_with_code(3) y zip_error_system_type(3) en su lugar.

Reemplace

int i = zip_error_get_sys_type(ze);
con 
zip_error_t error;
zip_error_init_with_code(&error, ze);
int i = zip_error_system_type(&error);

VER TAMBIÉN

libzip(3), zip_error_init_with_code(3), zip_error_system_type(3)

HISTORIAL

zip_error_get_sys_type() se añadió en libzip 0.6. Quedó obsoleta en libzip 1.0, use zip_error_system_type() en su lugar.
