NOMBRE

zip_set_archive_comment — establecer el comentario del archivo zip

BIBLIOTECA

libzip (-lzip)

SINOPSIS

#include <zip.h>

int
zip_set_archive_comment(zip_t *archive, const char *comment, zip_uint16_t len);

DESCRIPCIÓN

La función zip_set_archive_comment() establece el comentario para todo el archivo zip. Si comment es NULL y len es 0, el comentario del archivo se eliminará. comment debe estar codificado en ASCII o UTF-8.

VALORES DE RETORNO

Si la operación se completa con éxito, se devuelve 0. De lo contrario, se devuelve -1 y la información de error en archive se establece para indicar el error.

ERRORES

zip_set_archive_comment() falla si:

[ZIP_ER_INVAL]
len es menor que 0 o más larga que la longitud máxima del comentario en un archivo zip (65535), o comment no es una cadena codificada en UTF-8 válida.
[ZIP_ER_MEMORY]
No se pudo asignar la memoria requerida.

VER TAMBIÉN

libzip(3), zip_file_get_comment(3), zip_file_set_comment(3), zip_get_archive_comment(3)

HISTORIA

zip_set_archive_comment() se agregó en libzip 0.7. En libzip 0.11, el tipo de len se cambió de int a zip_uint16_t.
