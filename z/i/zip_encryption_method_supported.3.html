Paquete: libzip

Licencias: BSD

ZIP_ENCRYPTION_METHOD_SUPPORTED(3) Manual de funciones de biblioteca ZIP_ENCRYPTION_METHOD_SUPPORTED(3)

NOMBRE

zip_encryption_method_supported — devuelve si un método de cifrado es compatible

BIBLIOTECA

libzip (-lzip)

SINOPSIS

#include <zip.h>

int
zip_encryption_method_supported(zip_int16_t method, int encrypt);

DESCRIPCIÓN

La función zip_encryption_method_supported() devuelve si el método de cifrado method es compatible para cifrado (si encrypt es cero) o descifrado (de lo contrario).

VALORES DEVUELTOS

Devuelve 1 si el método es compatible, 0 en caso contrario.

VER TAMBIÉN

libzip(3), zip_compression_method_supported(3), zip_file_set_encryption(3)

HISTORIA

zip_encryption_method_supported() se añadió en libzip 1.7.0.
