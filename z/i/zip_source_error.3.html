Paquete: libzip

Licencias: BSD

ZIP_SOURCE_ERROR(3) Manual de funciones de biblioteca ZIP_SOURCE_ERROR(3)

NOMBRE

zip_source_error — obtener el error de zip para la fuente de datos

BIBLIOTECA

libzip (-lzip)

SINOPSIS

#include <zip.h>

zip_error_t *
zip_source_error(zip_source_t *source);

DESCRIPCIÓN

La función zip_source_error() devuelve el error de zip para la fuente de datos source.

VER TAMBIÉN

libzip(3), zip_error_code_system(3), zip_error_code_zip(3)

HISTORIAL

zip_source_error() se añadió en libzip 1.0.
