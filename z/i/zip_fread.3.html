zip_fread(3)

Paquete: libzip

Licencias: BSD

ZIP_FREAD(3) Manual de funciones de biblioteca ZIP_FREAD(3)

NOMBRE

zip_fread — leer de un archivo

BIBLIOTECA

libzip (-lzip)

SINOPSIS

#include <zip.h>

zip_int64_t
zip_fread(zip_file_t *archivo, void *buf, zip_uint64_t nbytes);

DESCRIPCIÓN

La función zip_fread() lee hasta nbytes bytes de archivo a buf desde la posición actual en el archivo (ver zip_fseek(3)). Después de leer, la posición actual se actualiza por la cantidad de bytes leídos.

VALORES DE RETORNO

Si tiene éxito, se devuelve el número de bytes leídos. Cuando se llama a zip_fread() después de alcanzar el final del archivo, se devuelve 0. En caso de error, se devuelve -1.

VER TAMBIÉN

libzip(3), zip_fclose(3), zip_file_get_error(3), zip_fopen(3), zip_fseek(3)

HISTORIAL

zip_fread() se añadió en libzip 0.6. En libzip 0.10 se cambió el tipo de retorno de ssize_t a zip_int64_t. En libzip 0.10 se cambió el tipo de nbytes de size_t a zip_uint64_t.
