ZIP_SOURCE(5) Manual de formatos de archivo ZIP_SOURCE(5)

NOMBRE

zip_source — estructura de origen de datos zip

BIBLIOTECA

libzip (-lzip)

SINOPSIS

#include <zip.h>

zip_source_t *fuente;

DESCRIPCIÓN

Un zip_source_t representa un origen de datos (o un destino cuando se usa para escribir). libzip(3) lo usa para agregar o reemplazar el contenido de un archivo en un archivo zip. Si la fuente admite búsqueda, también se puede usar para abrir archivos zip desde ella.

Los datos pueden provenir de un archivo en disco (zip_source_file(3), zip_source_file_create(3), zip_source_filep(3), o zip_source_filep_create(3)), memoria (zip_source_buffer(3), zip_source_buffer_create(3), zip_source_buffer_fragment(3), o zip_source_buffer_fragment_create(3)), un archivo dentro de un archivo (zip_source_zip(3)), o proporcionado a través de una función de devolución de llamada (zip_source_function(3) o zip_source_function_create(3)). zip_source_window(3) o zip_source_window_create(3) se pueden usar para restringir el acceso a una parte de los datos contenidos.

También se puede usar como un filtro para procesar los datos proporcionados por un zip_source_t subyacente (por ejemplo, para comprimirlo o calcular una suma de verificación), creado con zip_source_layered(3) o zip_source_layered_create(3)).

Las fuentes se liberan con zip_source_free(3).

Las fuentes deben admitir la lectura y, opcionalmente, la búsqueda y la escritura.

zip_source_t tiene un contador de referencias y se crea con un contador de referencias de 1. zip_open_from_source(3), zip_file_add(3) y zip_file_replace(3) tomarán la propiedad de la fuente pasada (disminuirán el contador de referencias cuando terminen de usarla), por lo que solo se debe llamar a zip_source_free(3) cuando estas funciones devuelvan un error. Los datos subyacentes (archivo o búfer) deben permanecer válidos hasta que se cierre el archivo. Utilice zip_source_keep(3) para aumentar el contador de referencias, por ejemplo, si necesita la fuente después de zip_close(3).
