zip_dir_add(3)

Paquete: libzip

Licencias: BSD

ZIP_DIR_ADD(3) Manual de funciones de biblioteca ZIP_DIR_ADD(3)

NOMBRE

zip_dir_add — añadir un directorio a un archivo zip

BIBLIOTECA

libzip (-lzip)

SINOPSIS

#include <zip.h>

zip_int64_t
zip_dir_add(zip_t *archive, const char *name, zip_flags_t flags);

DESCRIPCIÓN

La función zip_dir_add() añade un directorio a un archivo zip. El argumento archive especifica el archivo zip al que se debe añadir el directorio. name es el nombre del directorio en el archivo zip.

Esta función añade una entrada al archivo. No comprueba si existe un directorio con ese nombre en el sistema de archivos, ni añade su contenido si lo hay. El argumento flags puede ser cualquiera de los siguientes:

ZIP_FL_ENC_GUESS
Adivina la codificación de name (predeterminado). (Solo se reconocen CP-437 y UTF-8).
ZIP_FL_ENC_UTF_8
Interpreta name como UTF-8.
ZIP_FL_ENC_CP437
Interpreta name como página de códigos 437 (CP-437).

VALORES DE RETORNO

Al completarse con éxito, se devuelve el índice de la nueva entrada en el archivo. De lo contrario, se devuelve -1 y el código de error en archive se establece para indicar el error.

ERRORES

zip_dir_add() falla si:

[ZIP_ER_EXISTS]
Ya existe una entrada llamada name en el archivo.
[ZIP_ER_INVAL]
archive o name son NULL, o nombres de archivo codificados en UTF-8 no válidos.
[ZIP_ER_MEMORY]
No se pudo asignar la memoria requerida.

VEA TAMBIÉN

libzip(3), zip_file_add(3)

HISTORIA

zip_dir_add() se añadió en libzip 0.11.
