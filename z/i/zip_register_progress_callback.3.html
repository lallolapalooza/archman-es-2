zip_register_progress_callback(3)

Paquete: libzip

Licencias: BSD

ZIP_REGISTER_PROGRESS_CALLBACK(3) Manual de funciones de biblioteca ZIP_REGISTER_PROGRESS_CALLBACK(3)

NOMBRE

zip_register_progress_callback — proporciona actualizaciones durante zip_close (interfaz obsoleta)

BIBLIOTECA

libzip (-lzip)

SINOPSIS

#include <zip.h>

typedef void (*zip_progress_callback_t)(double);

void
zip_register_progress_callback(zip_t *archive, zip_progress_callback_t progress_callback);

DESCRIPCIÓN

La función zip_register_progress_callback() es la versión obsoleta de zip_register_progress_callback_with_state(3).

La zip_register_progress_callback() registra una función de devolución de llamada progress_callback para el archivo zip archive. Esta función se llama durante zip_close(3) después de cada entrada del archivo zip que se escribe completamente en disco. El valor es un double en el rango de 0.0 a 1.0. Esto se puede utilizar para proporcionar indicadores de progreso para las interfaces de usuario.

VER TAMBIÉN

libzip(3), zip_close(3)

HISTORIA

zip_register_progress_callback() se añadió en libzip 1.2.0. Fue marcada como obsoleta en libzip 1.3.0, use zip_register_progress_callback_with_state() en su lugar.
