zip_source_buffer_fragment(3)

Paquete: libzip

Licencias: BSD

ZIP_SOURCE_BUFFER_FRAGMENT(3) Manual de Funciones de Librería ZIP_SOURCE_BUFFER_FRAGMENT(3)

NOMBRE

zip_source_buffer_fragment, zip_source_buffer_fragment_create — crear fuente zip a partir de múltiples buffers

LIBRERÍA

libzip (-lzip)

SINOPSIS

#include <zip.h>

zip_source_t *
zip_source_buffer_fragment(zip_t *archive, zip_buffer_fragment_t *fragments, zip_uint64_t nfragments, int freep);

zip_source_t *
zip_source_buffer_fragment_create(zip_buffer_fragment_t *fragments, zip_uint64_t nfragments, int freep, zip_error_t *error);

DESCRIPCIÓN

Las funciones zip_source_buffer_fragment() y zip_source_buffer_fragment_create() crean una fuente zip a partir de los datos en fragments. nfragments especifica el número de fragmentos. Si freep es distinto de cero, los datos se liberarán cuando ya no sean necesarios.

struct zip_stat {
    zip_uint8_t *data;    /* puntero a los datos reales */
    zip_uint64_t length;  /* longitud de este fragmento */
};

Los datos a los que apunta fragments deben permanecer válidos durante la vida útil de la fuente creada. fragments en sí puede descartarse una vez creada la fuente.

La fuente puede usarse para abrir un archivo zip desde.

VALORES DE RETORNO

Al completarse con éxito, se devuelve la fuente creada. En caso contrario, se devuelve NULL y el código de error en archive o error se establece para indicar el error.

ERRORES

zip_source_buffer() y zip_source_buffer_create() fallan si:

[ZIP_ER_INVAL]
nfragments es mayor que cero y fragments es NULL.
[ZIP_ER_MEMORY]
No se pudo asignar la memoria requerida.

VER TAMBIÉN

libzip(3), zip_file_add(3), zip_file_replace(3), zip_open_from_source(3), zip_source(5)

HISTORIA

zip_source_buffer_fragment() y zip_source_buffer_fragment_create() se añadieron en libzip 1.4.0.
