NOMBRE

zip — estructura del archivo zip

BIBLIOTECA

libzip (-lzip)

SINOPSIS

#include <zip.h>

zip_t *archivo;

DESCRIPCIÓN

Un zip representa un archivo zip abierto y se utiliza para todas las funciones que acceden y modifican archivos.

Se crea con zip_open(3), zip_open_from_source(3), o zip_fdopen(3).

Se cierra con zip_close(3) (guardando cambios) o con zip_discard(3) (descartando cambios).

Todos los objetos que representan partes de un archivo (como zip_file_t) solo son válidos mientras el archivo permanezca abierto.

VER TAMBIÉN

libzip(3), zip_close(3), zip_discard(3), zip_fopen(3), zip_open(3), zip_open_from_source(3)
