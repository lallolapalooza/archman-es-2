zip_set_archive_flag(3)

Paquete: libzip

Licencias: BSD

ZIP_SET_ARCHIVE_FLAG(3) Manual de funciones de biblioteca ZIP_SET_ARCHIVE_FLAG(3)

NOMBRE

zip_set_archive_flag — establecer bandera de archivo zip

BIBLIOTECA

libzip (-lzip)

SINOPSIS

#include <zip.h>

int
zip_set_archive_flag(zip_t *archive, zip_flags_t flag, int value);

DESCRIPCIÓN

La función zip_set_archive_flag() establece la bandera flag para el archivo archive al valor value.

Las banderas admitidas son:

ZIP_AFL_CREATE_OR_KEEP_FILE_FOR_EMPTY_ARCHIVE
Si esta bandera se desactiva, el archivo se eliminará si está vacío. Si se activa, se creará un archivo vacío, lo cual no es recomendado por la especificación zip.
ZIP_AFL_RDONLY
Si esta bandera se activa, no se permitirán modificaciones en el archivo. Esta bandera solo se puede desactivar si se estableció manualmente con zip_set_archive_flag, no si el archivo se abrió en modo solo lectura.
ZIP_AFL_WANT_TORRENTZIP
Si esta bandera se activa, el archivo se escribirá en formato torrentzip.

VALORES DE RETORNO

Al completarse con éxito, se devuelve 0, y -1 si ocurrió un error.

VER TAMBIÉN

libzip(3), zip_get_archive_flag(3)

HISTORIAL

zip_set_archive_flag() se agregó en libzip 0.9. En libzip 0.11, el tipo de flag se cambió de int a zip_flags_t. ZIP_AFL_CREATE_OR_KEEP_FILE_FOR_EMPTY_ARCHIVE y ZIP_AFL_WANT_TORRENTZIP se agregaron en libzip 1.10.0.
