Licencias: BSD

ZIP_FILE_ATTRIBUTES_INIT(3) Manual de funciones de biblioteca ZIP_FILE_ATTRIBUTES_INIT(3)

NOMBRE

zip_file_attributes_init — inicializa la estructura de atributos de archivo zip

BIBLIOTECA

libzip (-lzip)

SINOPSIS

#include <zip.h>

void
zip_file_attributes_init(zip_file_attributes_t *attributes);

DESCRIPCIÓN

La función zip_file_attributes_init() inicializa una estructura zip_file_attributes_t con valores predeterminados. Debe llamarse antes de modificar dicha estructura por primera vez.

VER TAMBIÉN

libzip(3), zip_source_function(3)

HISTORIA

zip_file_attributes_init() se añadió en libzip 1.7.0.
