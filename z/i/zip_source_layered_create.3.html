ZIP_SOURCE_LAYERED_CREATE(3) Manual de Funciones de Biblioteca ZIP_SOURCE_LAYERED_CREATE(3)

NOMBRE

zip_source_layered, zip_source_layered_create — crear una fuente de datos en capas a partir de una función

BIBLIOTECA

libzip (-lzip)

SINOPSIS

#include <zip.h>

zip_source_t *
zip_source_layered(zip_t *archivo, zip_source_t *fuente, zip_source_layered_callback fn, void *userdata);

zip_source_t *
zip_source_layered_create(zip_source_t *fuente, zip_source_layered_callback fn, void *userdata, zip_error_t *error);

DESCRIPCIÓN

Las funciones zip_source_layered() y zip_source_layered_create() crean una fuente de zip en capas a partir de la función proporcionada por el usuario fn, que debe ser del siguiente tipo:

typedef zip_int64_t (*p_source_layered_callback)(zip_source_t *fuente, void *userdata, void *data, zip_uint64_t length, zip_source_cmd_t cmd);

archivo o error se usan para informar de errores y pueden ser NULL.

Cuando la biblioteca llama a la función, el primer argumento es la fuente de la capa inferior, el segundo argumento es el argumento userdata proporcionado a la función. Los dos argumentos siguientes son un búfer data de tamaño length cuando se pasan datos o se espera recibirlos, o de lo contrario NULL y 0. El último argumento, cmd, especifica qué acción debe realizar la función.

Consulte zip_source_function(3) para obtener una descripción de los comandos.

Una fuente en capas transforma los datos o metadatos de la fuente inferior de alguna manera. Las fuentes en capas no pueden admitir escritura y no son suficientes para admitir limpiamente métodos de compresión o cifrado adicionales. Esto puede revisarse en una versión posterior de libzip.

En caso de éxito, la fuente en capas se hace cargo de la fuente. El llamador no debe liberarla.

La interacción con la capa inferior depende del comando:

ZIP_SOURCE_ACCEPT_EMPTY

Si la fuente en capas admite este comando, la capa inferior no se llama automáticamente. De lo contrario, se utiliza el valor de retorno de la fuente inferior.

ZIP_SOURCE_CLOSE

La capa inferior se cierra después de que la función de devolución de llamada retorna.

ZIP_SOURCE_ERROR

La capa inferior no se llama automáticamente. Si necesita recuperar información de error de la capa inferior, utilice zip_error_set_from_source(3) o zip_source_pass_to_lower_layer(3).

ZIP_SOURCE_FREE

La capa inferior se libera después de que la función de devolución de llamada retorna.

ZIP_SOURCE_GET_FILE_ATTRIBUTES

Los atributos de la capa inferior se fusionan con los atributos devueltos por la función de devolución de llamada: la información establecida por la función de devolución de llamada prevalece sobre la capa inferior, con las siguientes excepciones: se utiliza la version_needed más alta y las general_purpose_bit_flags solo se sobrescriben si el bit correspondiente está establecido en general_purpose_bit_mask.

ZIP_SOURCE_OPEN

La capa inferior se abre antes de llamar a la función de devolución de llamada.

ZIP_SOURCE_READ

La capa inferior no se llama automáticamente.

ZIP_SOURCE_SEEK

La capa inferior no se llama automáticamente.

ZIP_SOURCE_STAT

data contiene la información de estado de la capa inferior cuando se llama a la función de devolución de llamada.

ZIP_SOURCE_SUPPORTS

data contiene el mapa de bits de comandos admitidos por la capa inferior cuando se llama a la función de devolución de llamada. Dado que las fuentes en capas no pueden admitir escritura, todos los comandos relacionados con la escritura se eliminan del mapa de bits de soporte devuelto.

ZIP_SOURCE_TELL

La capa inferior no se llama automáticamente.

VALORES DE RETORNO

Al completarse con éxito, se devuelve la fuente creada. En caso contrario, se devuelve NULL y el código de error en archivo o error se establece para indicar el error (a menos que sea NULL).

ERRORES

zip_source_layered() falla si:

[ZIP_ER_MEMORY]
No se pudo asignar la memoria requerida.

VER TAMBIÉN

HISTORIA
