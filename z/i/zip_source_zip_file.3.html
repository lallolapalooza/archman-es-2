Paquete: libzip

Licencias: BSD

ZIP_SOURCE_ZIP_FILE(3) Manual de funciones de biblioteca ZIP_SOURCE_ZIP_FILE(3)

NOMBRE

zip_source_zip_file, zip_source_zip_file_create — crear origen de datos desde un archivo zip

BIBLIOTECA

libzip (-lzip)

SINOPSIS

#include <zip.h>

zip_source_t *
zip_source_zip_file(zip_t *archive, zip_t *srcarchive, zip_uint64_t srcidx, zip_flags_t flags, zip_uint64_t start, zip_int64_t length, const char *password);

zip_source_t *
zip_source_zip_file_create(zip_t *srcarchive, zip_uint64_t srcidx, zip_flags_t flags, zip_uint64_t start, zip_int64_t length, const char *password, zip_error_t *error);

DESCRIPCIÓN

Las funciones zip_source_zip_file() y zip_source_zip_file_create() crean un origen zip desde un archivo en un archivo zip. El argumento srcarchive es el archivo zip (abierto) que contiene el archivo zip de origen en el índice srcidx. Se utilizarán length bytes desde la posición start en el zip_source. Si length es -1, se utiliza el resto del archivo, comenzando desde start.

Si tiene la intención de copiar un archivo de un archivo a otro, utilizar la bandera ZIP_FL_COMPRESSED es más eficiente, ya que evita volver a comprimir los datos del archivo.

Las banderas admitidas son:

ZIP_FL_COMPRESSED
Obtener los datos comprimidos. Esto solo se admite si se solicitan todos los datos del archivo (start == 0 y length == -1). No se admite para datos modificados. El valor predeterminado es sin comprimir.
ZIP_FL_ENCRYPTED
Obtener los datos cifrados. (Esta bandera implica ZIP_FL_COMPRESSED). Esto solo se admite si se solicitan todos los datos del archivo (start == 0 y length == -1). El valor predeterminado es descifrado.
ZIP_FL_UNCHANGED
Intentar obtener los datos originales sin ningún cambio que pueda haberse hecho en srcarchive después de abrirlo.

VALORES DE RETORNO

Al completarse con éxito, se devuelve el origen creado. De lo contrario, se devuelve NULL y el código de error en archive o error se establece para indicar el error.

ERRORES

zip_source_zip_file() y zip_source_zip_file_create() fallan si:

[ZIP_ER_CHANGED]
Se solicitaron datos sin modificar, pero no están disponibles.
[ZIP_ER_INVAL]
srcarchive, srcidx, start, o length son inválidos.
[ZIP_ER_MEMORY]
No se pudo asignar la memoria requerida.
Además, puede devolver todos los códigos de error de zip_stat_index() y zip_fopen_index().

VER TAMBIÉN

libzip(3), zip_file_add(3), zip_file_replace(3), zip_source(5)

HISTORIA

zip_source_zip_file() y zip_source_zip_file_create() se añadieron en libzip 1.10.0.
