ZIP_SOURCE_SEEK(3) Manual de funciones de la biblioteca ZIP_SOURCE_SEEK(3)

NOMBRE

zip_source_seek — establecer el desplazamiento de lectura en la fuente zip

BIBLIOTECA

libzip (-lzip)

SINOPSIS

#include <zip.h>

int
zip_source_seek(zip_source_t *source, zip_int64_t offset, int whence);

DESCRIPCIÓN

La función zip_source_seek() establece el desplazamiento de lectura actual para source. Al igual que en fseek(3), dependiendo del argumento whence, el offset se cuenta en relación con:

SEEK_SET
inicio del archivo
SEEK_CUR
desplazamiento de lectura actual en el archivo
SEEK_END
final del archivo

VALORES DE RETORNO

Si la operación se completa con éxito, se devuelve 0. De lo contrario, se devuelve -1 y la información de error en source se establece para indicar el error.

VER TAMBIÉN

libzip(3), zip_source(5), zip_source_is_seekable(3), zip_source_read(3), zip_source_tell(3)

HISTORIAL

zip_source_seek() se añadió en libzip 1.0.
