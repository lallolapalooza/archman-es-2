Paquete: libzip

Licencias: BSD

ZIP_SET_DEFAULT_PASSWORD(3) Manual de funciones de biblioteca ZIP_SET_DEFAULT_PASSWORD(3)

NOMBRE

zip_set_default_password — establece la contraseña predeterminada para archivos cifrados en zip

BIBLIOTECA

libzip (-lzip)

SINOPSIS

#include <zip.h>

int
zip_set_default_password(zip_t *archive, const char *password);

DESCRIPCION

La función zip_set_default_password() establece la contraseña predeterminada utilizada al acceder a archivos cifrados. Si password es NULL o una cadena vacía, la contraseña predeterminada se desactiva.

Si prefiere una contraseña diferente para archivos individuales, utilice zip_fopen_encrypted(3) en lugar de zip_fopen(3). Sin embargo, normalmente se utiliza la misma contraseña para cada archivo en un archivo zip.

La contraseña no se verifica al llamar a esta función. Consulte la sección CAVEATS de zip_fopen_encrypted(3) para obtener más detalles sobre el manejo de contraseñas.

VALORES DE RETORNO

Al finalizar correctamente, se devuelve 0. De lo contrario, se devuelve -1 y la información de error en archive se establece para indicar el error.

ERRORES

zip_set_default_password() falla si:

[ZIP_ER_MEMORY]
No se pudo asignar la memoria requerida.

VER TAMBIÉN

libzip(3), zip_fopen(3), zip_fopen_encrypted(3)

HISTORIAL

zip_set_default_password() se añadió en libzip 0.10.
