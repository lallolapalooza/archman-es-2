zip_source_filep(3)

Paquete: libzip

Licencias: BSD

ZIP_SOURCE_FILEP(3) Manual de funciones de biblioteca ZIP_SOURCE_FILEP(3)

NOMBRE

zip_source_filep, zip_source_filep_create — crear una fuente de datos desde un FILE *

BIBLIOTECA

libzip (-lzip)

SINOPSIS

#include <zip.h>

zip_source_t *
zip_source_filep(zip_t *archive, FILE *file, zip_uint64_t start, zip_int64_t len);

zip_source_t *
zip_source_filep_create(FILE *file, zip_uint64_t start, zip_int64_t len, zip_error_t *error);

DESCRIPCIÓN

Las funciones zip_source_filep() y zip_source_filep_create() crean una fuente zip desde un flujo de archivo. Leen len bytes desde la posición start del flujo de archivo abierto file. Para una descripción del argumento len, véase zip_source_file(3).

Si el flujo de archivo admite búsqueda, la fuente se puede utilizar para abrir un archivo zip de solo lectura.

El flujo de archivo se cierra cuando se libera la fuente, generalmente mediante zip_close(3).

VALORES DE RETORNO

En caso de éxito, se devuelve la fuente creada. De lo contrario, se devuelve NULL y el código de error en archive o error se establece para indicar el error.

ERRORES

zip_source_filep() falla si:

[ZIP_ER_INVAL]
file, start, o len son inválidos.
[ZIP_ER_MEMORY]
No se pudo asignar la memoria requerida.

VER TAMBIÉN

libzip(3), zip_file_add(3), zip_file_replace(3), zip_source(5), zip_source_file(3)

HISTORIA

zip_source_filep() y zip_source_filep_create() se agregaron en libzip 1.0.

ZIP_LENGTH_TO_END y ZIP_LENGTH_UNCHECKED se agregaron en libzip 1.10.1.
