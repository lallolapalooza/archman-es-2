zip_source_file_create(3)

Paquete: libzip

Licencias: BSD

ZIP_SOURCE_FILE(3) Manual de funciones de biblioteca ZIP_SOURCE_FILE(3)

NOMBRE

zip_source_file, zip_source_file_create — crear origen de datos desde un archivo

BIBLIOTECA

libzip (-lzip)

SINOPSIS

#include <zip.h>

zip_source_t *
zip_source_file(zip_t *archive, const char *fname, zip_uint64_t start, zip_int64_t len);

zip_source_t *
zip_source_file_create(const char *fname, zip_uint64_t start, zip_int64_t len, zip_error_t *error);

DESCRIPCIÓN

Las funciones zip_source_file() y zip_source_file_create() crean un origen zip desde un archivo. Abren fname y leen len bytes desde el desplazamiento start desde él.

Al pasar ZIP_LENGTH_TO_END (o -1, que está obsoleto) como len, zip_source_file determina el tamaño del archivo cuando se llama y lo utiliza como el tamaño esperado del archivo. Si el tamaño del archivo aumenta entre la creación y la lectura del origen, los datos adicionales se ignoran. Si el archivo se reduce, libzip lo trata como un error (ZIP_ER_DATA_LENGTH).

Al pasar ZIP_LENGTH_UNCHECKED como len, zip_source_file asume que el tamaño del archivo es desconocido. La lectura desde el origen devuelve tanta cantidad de datos como haya en ese momento (normalmente al llamar a zip_close(3)).

libzip puede realizar diversas optimizaciones si se conoce el tamaño de un origen cuando se crea, por lo que ZIP_LENGTH_TO_END es preferible. Si trabajas con archivos que probablemente cambien mientras los procesas, puedes usar el menos eficiente ZIP_LENGTH_UNCHECKED.

Si el archivo admite búsqueda, el origen se puede utilizar para abrir un archivo zip desde él.

El archivo se abre y se lee cuando se utilizan los datos del origen, normalmente mediante zip_close() o zip_open_from_source().

VALORES DE RETORNO

Al completarse con éxito, se devuelve el origen creado. De lo contrario, se devuelve NULL y el código de error en archive o error se establece para indicar el error.

ERRORES

zip_source_file() y zip_source_file_create() fallan si:

[ZIP_ER_INVAL]
fname, start, o len son inválidos.
[ZIP_ER_MEMORY]
No se pudo asignar la memoria requerida.
[ZIP_ER_OPEN]
Falló la apertura de fname.

VER TAMBIÉN

libzip(3), zip_file_add(3), zip_file_replace(3), zip_source(5)

HISTORIAL

zip_source_file() y zip_source_file_create() se agregaron en libzip 1.0.

ZIP_LENGTH_TO_END y ZIP_LENGTH_UNCHECKED se agregaron en libzip 1.10.1.
