zip_file_strerror(3)

Paquete: libzip

Licencias: BSD

ZIP_FILE_STRERROR(3) Manual de funciones de la biblioteca ZIP_FILE_STRERROR(3)

NOMBRE

zip_file_strerror, zip_strerror — obtener representación en cadena para un error de zip

BIBLIOTECA

libzip (-lzip)

SINOPSIS

#include <zip.h>

const char *
zip_file_strerror(zip_file_t *file);

const char *
zip_strerror(zip_t *archive);

DESCRIPCIÓN

La función zip_strerror() devuelve una cadena que describe el último error para el archivo zip archive, mientras que la función zip_file_strerror() hace lo mismo para un archivo zip file (un archivo dentro de un archivo comprimido). La cadena devuelta no debe ser modificada ni liberada, y se vuelve inválida cuando archive o file, respectivamente, se cierran o en la siguiente llamada a zip_strerror() o zip_file_strerror(), respectivamente, para el mismo archivo.

VALORES DE RETORNO

zip_file_strerror() y zip_strerror() devuelven un puntero a la cadena de error.

VER TAMBIÉN

libzip(3), zip_error_strerror(3)

HISTORIA

zip_file_strerror() y zip_strerror() se añadieron en libzip 0.6.
