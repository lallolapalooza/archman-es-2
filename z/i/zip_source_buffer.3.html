zip_source_buffer(3)

Paquete: libzip

Licencias: BSD

ZIP_SOURCE_BUFFER(3) Manual de funciones de biblioteca ZIP_SOURCE_BUFFER(3)

NOMBRE

zip_source_buffer, zip_source_buffer_create — crear una fuente zip desde un búfer

BIBLIOTECA

libzip (-lzip)

SINOPSIS

#include <zip.h>

zip_source_t *
zip_source_buffer(zip_t *archive, const void *data, zip_uint64_t len, int freep);

zip_source_t *
zip_source_buffer_create(const void *data, zip_uint64_t len, int freep, zip_error_t *error);

DESCRIPCIÓN

Las funciones zip_source_buffer() y zip_source_buffer_create() crean una fuente zip a partir del búfer data de tamaño len. Si freep es distinto de cero, el búfer se liberará cuando ya no sea necesario. data debe permanecer válido durante la vida útil de la fuente creada.

La fuente puede usarse para abrir un archivo zip.

VALORES DE RETORNO

Al completarse con éxito, se devuelve la fuente creada. De lo contrario, se devuelve NULL y el código de error en archive o error se establece para indicar el error.

ERRORES

zip_source_buffer() y zip_source_buffer_create() fallan si:

[ZIP_ER_INVAL]
len es mayor que cero y data es NULL.
[ZIP_ER_MEMORY]
No se pudo asignar la memoria requerida.

VER TAMBIÉN

libzip(3), zip_file_add(3), zip_file_replace(3), zip_open_from_source(3), zip_source(5)

HISTORIA

zip_source_buffer() y zip_source_buffer_create() se añadieron en libzip 1.0.
