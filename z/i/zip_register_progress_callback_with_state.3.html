zip_register_progress_callback_with_state(3)

Paquete: libzip

Licencias: BSD

ZIP_REGISTER_PROGRESS_CALLBACK_WITH_STATE(3) Manual de funciones de biblioteca ZIP_REGISTER_PROGRESS_CALLBACK_WITH_STATE(3)

NOMBRE

zip_register_progress_callback_with_state — proporcionar actualizaciones durante zip_close

BIBLIOTECA

libzip (-lzip)

SINOPSIS

#include <zip.h>

typedef void (*zip_progress_callback)(zip_t *, double, void *);

void
zip_register_progress_callback_with_state(zip_t *archive, double precision, zip_progress_callback callback, void (*ud_free)(void *), void *ud);

DESCRIPCIÓN

La función zip_register_progress_callback_with_state() registra una función de devolución de llamada callback para el archivo zip archive. El argumento precision es un double en el rango de 0.00 a 1.0 que define el cambio más pequeño para el cual se debe llamar a la devolución de llamada (para evitar llamadas demasiado frecuentes). La función ud_free se llama durante la limpieza para eliminar los datos de usuario suministrados en ud.

La función de devolución de llamada se llama durante zip_close(3) en intervalos regulares (después de cada entrada del archivo zip que se escribe completamente en el disco, y mientras se escriben datos para las entradas) con el archivo zip archive, el estado de progreso actual como un double, y los datos de usuario proporcionados por el usuario ud como argumentos. El estado de progreso es un double en el rango de 0.0 a 1.0. Esto se puede utilizar para proporcionar indicadores de progreso para interfaces de usuario.

VER TAMBIÉN

libzip(3), zip_close(3), zip_register_cancel_callback_with_state(3)

HISTORIAL

zip_register_progress_callback_with_state() se agregó en libzip 1.3.0.
