zip_file_extra_field_delete_by_id(3)

Paquete: libzip

Licencias: BSD

ZIP_FILE_EXTRA_FIELD_DELETE(3) Manual de funciones de la biblioteca ZIP_FILE_EXTRA_FIELD_DELETE(3)

NOMBRE

zip_file_extra_field_delete, zip_file_extra_field_delete_by_id — eliminar campo extra para un archivo en zip

BIBLIOTECA

libzip (-lzip)

SINOPSIS

#include <zip.h>

int
zip_file_extra_field_delete(zip_t *archive, zip_uint64_t index, zip_uint16_t extra_field_index, zip_flags_t flags);

int
zip_file_extra_field_delete_by_id(zip_t *archive, zip_uint64_t index, zip_uint16_t extra_field_id, zip_uint16_t extra_field_index, zip_flags_t flags);

DESCRIPCIÓN

La función zip_file_extra_field_delete() elimina el campo extra con el índice extra_field_index para el archivo en la posición index en el archivo zip.

Si extra_field_index es ZIP_EXTRA_FIELD_ALL, entonces se eliminarán todos los campos extras.

Los siguientes flags son compatibles:

ZIP_FL_CENTRAL
Eliminar campos extras del directorio central del archivo.
ZIP_FL_LOCAL
Eliminar campos extras de las cabeceras de archivos locales.

La función zip_file_extra_field_delete_by_id() elimina el campo extra con el ID (firma de dos bytes) extra_field_id y el índice extra_field_index (es decir, el extra_field_index'ésimo campo extra con ID extra_field_id) Los otros argumentos son los mismos que para zip_file_extra_field_delete() (ZIP_EXTRA_FIELD_ALL eliminará todos los campos extras del ID especificado).

Tenga en cuenta que debido al diseño de la biblioteca, el índice de un campo extra puede ser diferente entre el directorio central y las cabeceras de archivos locales. Por esta razón, no está permitido especificar tanto ZIP_FL_CENTRAL como ZIP_FL_LOCAL en flags, excepto al eliminar todos los campos extras (es decir, extra_field_index siendo ZIP_EXTRA_FIELD_ALL).

VALORES DE RETORNO

Al completarse con éxito, se devuelve 0. De lo contrario, se devuelve -1 y el código de error en archive se establece para indicar el error.

ERRORES

zip_file_extra_field_delete() y zip_file_extra_field_delete_by_id() fallan si:

[ZIP_ER_NOENT]
index no es un índice de archivo válido en archive.

VER TAMBIÉN

libzip(3), zip_file_extra_field_get(3), zip_file_extra_field_set(3), zip_file_extra_fields_count(3)

HISTORIA

zip_file_extra_field_delete() y zip_file_extra_field_delete_by_id() se añadieron en libzip 0.11.
