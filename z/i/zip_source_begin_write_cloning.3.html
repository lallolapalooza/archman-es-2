zip_source_begin_write_cloning(3)

Paquete: libzip

Licencias: BSD

ZIP_SOURCE_BEGIN_WRITE(3) Manual de funciones de biblioteca ZIP_SOURCE_BEGIN_WRITE(3)

NOMBRE

zip_source_begin_write, zip_source_begin_write_cloning — prepara la fuente zip para escribir

BIBLIOTECA

libzip (-lzip)

SINOPSIS

#include <zip.h>

int
zip_source_begin_write(zip_source_t *source);

int
zip_source_begin_write_cloning(zip_source_t *source, zip_uint64_t offset);

DESCRIPCIÓN

Las funciones zip_source_begin_write() y zip_source_begin_write_cloning() preparan source para escribir. Generalmente esto implica crear archivos temporales o asignar buffers.

zip_source_begin_write_cloning() conserva los primeros offset bytes del archivo original. Esto se hace de manera eficiente, y las escrituras en source no sobrescribirán los datos originales hasta que se llame a zip_commit_write().

VALORES DE RETORNO

Si la operación se completa con éxito, se devuelve 0. De lo contrario, se devuelve -1 y la información de error en source se establece para indicar el error.

VER TAMBIÉN

libzip(3), zip_source(5), zip_source_commit_write(3), zip_source_rollback_write(3), zip_source_seek_write(3), zip_source_tell_write(3), zip_source_write(3)

HISTORIA

zip_source_begin_write() se añadió en libzip 1.0.

zip_source_begin_write_cloning() se añadió en libzip 1.4.0.
