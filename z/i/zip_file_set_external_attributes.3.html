Paquete: libzip

Licencias: BSD

ZIP_FILE_SET_EXTERNAL_ATTRIBUTES(3) Manual de Funciones de Librería ZIP_FILE_SET_EXTERNAL_ATTRIBUTES(3)

NOMBRE

zip_file_set_external_attributes — establecer atributos externos para un archivo en zip

LIBRERÍA

libzip (-lzip)

SINOPSIS

#include <zip.h>

int
zip_file_set_external_attributes(zip_t *archive, zip_uint64_t index, zip_flags_t flags, zip_uint8_t opsys, zip_uint32_t attributes);

DESCRIPCIÓN

La función zip_file_set_external_attributes() establece el sistema operativo y los atributos externos para el archivo en la posición index en el archivo zip. Actualmente, no se admiten flags.

Para obtener una lista de valores de opsys conocidos, consulte zip_file_get_external_attributes(3).

VALORES DE RETORNO

Al completarse con éxito, se devuelve 0. De lo contrario, se devuelve -1 y la información de error en archive se establece para indicar el error.

ERRORES

zip_file_set_external_attributes() falla si:

[ZIP_ER_INVAL]
index no es un índice de archivo válido en archive.
[ZIP_ER_MEMORY]
No se pudo asignar la memoria requerida.
[ZIP_ER_RDONLY]
El archive se abrió en modo de solo lectura.

VER TAMBIÉN

libzip(3), zip_file_get_external_attributes(3)

HISTORIA

zip_file_set_external_attributes() se añadió en libzip 0.11.2.
