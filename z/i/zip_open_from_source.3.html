zip_open_from_source(3)

Paquete: libzip

Licencias: BSD

ZIP_OPEN(3) Manual de funciones de biblioteca ZIP_OPEN(3)

NOMBRE

zip_open, zip_open_from_source — abrir archivo zip

BIBLIOTECA

libzip (-lzip)

SINOPSIS

#include <zip.h>

zip_t *
zip_open(const char *path, int flags, int *errorp);

zip_t *
zip_open_from_source(zip_source_t *zs, int flags, zip_error_t *ze);

DESCRIPCIÓN

La función zip_open() abre el archivo zip especificado por path y devuelve un puntero a una struct zip, utilizada para manipular el archivo. Las flags se especifican mediante la combinación (mediante o) de los siguientes valores, o 0 si no se utiliza ninguno.

ZIP_CHECKCONS
Realiza comprobaciones de consistencia adicionales y más estrictas en el archivo, y devuelve un error si fallan.
ZIP_CREATE
Crea el archivo si no existe.
ZIP_EXCL
Devuelve un error si el archivo ya existe.
ZIP_TRUNCATE
Si el archivo existe, ignora su contenido actual. Es decir, lo trata de la misma manera que un archivo vacío.
ZIP_RDONLY
Abre el archivo en modo de solo lectura.

Si ocurre un error y errorp no es NULL, se establecerá con el código de error correspondiente.

La función zip_open_from_source() abre un archivo zip encapsulado por el zip_source zs utilizando las flags proporcionadas. En caso de error, se rellena el zip_error ze.

VALORES DE RETORNO

En caso de éxito, zip_open() y zip_open_from_source() devuelven un puntero a struct zip. De lo contrario, se devuelve NULL y zip_open() establece *errorp para indicar el error, mientras que zip_open_from(source) establece ze para indicar el error.

EJEMPLOS

Aquí hay un ejemplo de cómo podrías informar de errores durante la ejecución de zip_open:

    zip_t *za;
    int err;

    if ((za = zip_open(name, 0, &err)) == NULL) {
        zip_error_t error;
        zip_error_init_with_code(&error, err);
        fprintf(stderr, "%s: no se puede abrir el archivo zip '%s': %s\n",
	        progname, name, zip_error_strerror(&error));
        zip_error_fini(&error);
        return -1;
    }

ERRORES

El archivo especificado por path se abre a menos que:

[ZIP_ER_EXISTS]
El archivo especificado por path existe y se ha establecido ZIP_EXCL.
[ZIP_ER_INCONS]
Se encontraron inconsistencias en el archivo especificado por path. Este error a menudo se produce al especificar ZIP_CHECKCONS, pero también puede ocurrir sin él.
[ZIP_ER_INVAL]
El argumento path es NULL.
[ZIP_ER_MEMORY]
No se pudo asignar la memoria requerida.
[ZIP_ER_NOENT]
El archivo especificado por path no existe y no se ha establecido ZIP_CREATE.
[ZIP_ER_NOZIP]
El archivo especificado por path no es un archivo zip.
[ZIP_ER_OPEN]
No se pudo abrir el archivo especificado por path.
[ZIP_ER_READ]
Se produjo un error de lectura; consulta errno para más detalles.
[ZIP_ER_SEEK]
El archivo especificado por path no permite búsquedas.
Para los archivos recién creados, zip_open() no intenta crear el archivo; esto se hace al llamar a zip_close(3) y cualquier error, como la falta de permisos de escritura, se informará en ese momento.

VER TAMBIÉN

libzip(3), zip_close(3), zip_error_strerror(3), zip_fdopen(3), zip_source(5)

HISTORIAL

zip_open() y zip_open_from_source() se añadieron en libzip 1.0.
