zip_file_extra_field_get_by_id(3)

Paquete: libzip

Licencias: BSD

ZIP_FILE_EXTRA_FIELD_GET(3) Manual de funciones de la biblioteca ZIP_FILE_EXTRA_FIELD_GET(3)

NOMBRE

zip_file_extra_field_get, zip_file_extra_field_get_by_id — obtener campo extra para un archivo en un zip

BIBLIOTECA

libzip (-lzip)

SINOPSIS

#include <zip.h>

const zip_uint8_t *
zip_file_extra_field_get(zip_t *archive, zip_uint64_t index, zip_uint16_t extra_field_index, zip_uint16_t *idp, zip_uint16_t *lenp, zip_flags_t flags);

const zip_uint8_t *
zip_file_extra_field_get_by_id(zip_t *archive, zip_uint64_t index, zip_uint16_t extra_field_id, zip_uint16_t extra_field_index, zip_uint16_t *lenp, zip_flags_t flags);

DESCRIPCIÓN

La función zip_file_extra_field_get() devuelve el campo extra con el índice extra_field_index para el archivo en la posición index en el archivo zip. Este puntero no debe ser modificado ni liberado con free(3), y se vuelve inválido cuando archive se cierra. Si idp no es NULL, el entero al que apunta se establecerá en el ID (firma de dos bytes) del campo extra seleccionado. Si lenp no es NULL, el entero al que apunta se establecerá en la longitud del campo extra. En términos generales, se deben pasar lenp y idp ya que solo se devuelven los datos del campo extra (es decir, ni el ID ni la longitud, si los argumentos idp y lenp no se proporcionan).

Los siguientes flags son compatibles:

ZIP_FL_CENTRAL
Devolver campos extra del directorio central del archivo.
ZIP_FL_LOCAL
Devolver campos extra de las cabeceras de archivos locales.
ZIP_FL_UNCHANGED
Devolver los campos extra originales sin cambios, ignorando cualquier cambio realizado.

La función zip_file_extra_field_get_by_id() devuelve el campo extra con el ID (firma de dos bytes) extra_field_id y el índice extra_field_index (en otras palabras, el extra_field_indexº campo extra con ID extra_field_id) Los otros argumentos son los mismos que para zip_file_extra_field_get().

VALORES DEVUELTOS

Si la operación se completa con éxito, se devuelve un puntero a un campo extra, o NULL si no hay un campo extra con ese extra_field_index para el archivo con índice index. En caso de error, se devuelve NULL y el código de error en archive se establece para indicar el error.

ERRORES

zip_file_extra_field_get() y zip_file_extra_field_get_by_id() fallan si:

[ZIP_ER_NOENT]
index no es un índice de archivo válido en archive, o extra_field_index no es un índice de archivo extra válido (para el ID extra_field_id).

VER TAMBIÉN

libzip(3), zip_file_extra_field_delete(3), zip_file_extra_field_set(3), zip_file_extra_fields_count(3)

HISTORIA

zip_file_extra_field_get() y zip_file_extra_field_get_by_id() se añadieron en libzip 0.11.

AUTORES

Dieter Baron <dillo@nih.at> y Thomas Klausner <wiz@gatalith.at>

ADVERTENCIAS

Tenga en cuenta que los IDs de campos extra 0x0001 (extensión ZIP64), 0x6375 (comentario Infozip UTF-8) y 0x7075 (nombre de archivo Infozip UTF-8) no se pueden leer utilizando zip_file_extra_field_get() ya que son utilizados internamente por libzip(3).
