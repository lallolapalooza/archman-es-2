zip_file_get_comment(3)

Paquete: libzip

Licencias: BSD

ZIP_FILE_GET_COMMENT(3) Manual de funciones de la biblioteca ZIP_FILE_GET_COMMENT(3)

NOMBRE

zip_file_get_comment — obtener el comentario de un archivo en un zip

BIBLIOTECA

libzip (-lzip)

SINOPSIS

#include <zip.h>

const char *
zip_file_get_comment(zip_t *archive, zip_uint64_t index, zip_uint32_t *lenp, zip_flags_t flags);

DESCRIPCIÓN

La función zip_file_get_comment() devuelve el comentario del archivo en la posición index en el archivo zip. El nombre está codificado en UTF-8 a menos que se especifique ZIP_FL_ENC_RAW (ver abajo). Este puntero no debe ser modificado ni liberado con free(3), y se invalida cuando se cierra archive. Si lenp no es NULL, el entero al que apunta se establecerá en la longitud del comentario. Si flags se establece en ZIP_FL_UNCHANGED, se devuelve el comentario original sin cambios.

Adicionalmente, se admiten las siguientes flags:

ZIP_FL_ENC_RAW
Devuelve el comentario sin modificar tal como está en el archivo ZIP.
ZIP_FL_ENC_GUESS
(Por defecto.) Adivina la codificación del comentario en el archivo ZIP y la convierte a UTF-8, si es necesario. (Solo se reconocen CP-437 y UTF-8).
ZIP_FL_ENC_STRICT
Sigue la especificación ZIP para nombres de archivo y la extiende a comentarios de archivo, esperando que estén codificados en CP-437 en el archivo ZIP (excepto si es un comentario UTF-8 del campo extra especial). Lo convierte a UTF-8.
Nota: ASCII es un subconjunto de CP-437 y UTF-8.

VALORES DE RETORNO

Al completarse con éxito, se devuelve un puntero al comentario, o NULL si no hay comentario. En caso de error, se devuelve NULL y el código de error en archive se establece para indicar el error.

ERRORES

zip_file_get_comment() falla si:

[ZIP_ER_INVAL]
index no es un índice de archivo válido en archive.

VER TAMBIÉN

libzip(3), zip_file_set_comment(3), zip_get_archive_comment(3)

HISTORIAL

zip_file_get_comment() se añadió en libzip 0.11.
