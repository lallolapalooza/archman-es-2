Paquete: libzip

Licencias: BSD

ZIP_SOURCE_FUNCTION(3) Manual de funciones de la biblioteca ZIP_SOURCE_FUNCTION(3)

NOMBRE

zip_source_function, zip_source_function_create — crear fuente de datos a partir de una función

BIBLIOTECA

libzip (-lzip)

SINOPSIS

#include <zip.h>

zip_source_t *
zip_source_function(zip_t *archive, zip_source_callback fn, void *userdata);

zip_source_t *
zip_source_function_create(zip_source_callback fn, void *userdata, zip_error_t *error);

DESCRIPCIÓN

Las funciones zip_source_function() y zip_source_function_create() crean una fuente zip a partir de la función proporcionada por el usuario fn, la cual debe ser del siguiente tipo:

typedef zip_int64_t (*zip_source_callback)(void *userdata, void *data, zip_uint64_t len, zip_source_cmd_t cmd);

archive o error se utilizan para informar de errores y pueden ser NULL.

Cuando es llamada por la biblioteca, el primer argumento es el argumento userdata proporcionado a la función. Los siguientes dos argumentos son un búfer data de tamaño len cuando se pasan datos o se espera recibirlos, o bien NULL y 0. El último argumento, cmd, especifica qué acción debe realizar la función.

Dependiendo de los usos, existen tres conjuntos útiles de comandos que deben ser soportados por un zip_source_callback():

fuente de lectura
Proporcionar datos en streaming (para datos de archivo añadidos a archivos). Debe soportar ZIP_SOURCE_OPEN, ZIP_SOURCE_READ, ZIP_SOURCE_CLOSE, ZIP_SOURCE_STAT y ZIP_SOURCE_ERROR.

Si su fuente utiliza memoria asignada (incluyendo userdata), también debe implementar ZIP_SOURCE_FREE para evitar fugas de memoria.

fuente de lectura con búsqueda
Igual que la anterior, pero desde una fuente que permite la lectura desde desplazamientos arbitrarios (también para archivos zip de solo lectura). Además, debe soportar ZIP_SOURCE_SEEK, ZIP_SOURCE_TELL y ZIP_SOURCE_SUPPORTS.
fuente de lectura/escritura
Igual que la anterior, pero permitiendo además la escritura (también para archivos zip modificables). Además, debe soportar ZIP_SOURCE_BEGIN_WRITE, ZIP_SOURCE_COMMIT_WRITE, ZIP_SOURCE_ROLLBACK_WRITE, ZIP_SOURCE_SEEK_WRITE, ZIP_SOURCE_TELL_WRITE y ZIP_SOURCE_REMOVE.

Además de lo anterior, soportar el pseudocomando ZIP_SOURCE_SUPPORTS_REOPEN permite llamar a zip_source_open() de nuevo después de llamar a zip_source_close().

ZIP_SOURCE_ACCEPT_EMPTY

Devolver 1 si se debe aceptar una fuente vacía como un archivo zip válido. Este es el valor predeterminado si este comando no es soportado por una fuente. Las fuentes basadas en sistemas de archivos deben devolver 0.

ZIP_SOURCE_BEGIN_WRITE

Prepara la fuente para la escritura. Utilice esto para crear cualquier archivo temporal.

ZIP_SOURCE_BEGIN_WRITE_CLONING

Prepara la fuente para la escritura, conservando los primeros len bytes del archivo original. Implemente este comando solo si es más eficiente que copiar los datos y si no sobrescribe el archivo original de forma destructiva (aún debe poder ejecutar ZIP_SOURCE_ROLLBACK_WRITE).

La próxima escritura debe ocurrir en el byte offset.

ZIP_SOURCE_CLOSE

La lectura ha finalizado.

ZIP_SOURCE_COMMIT_WRITE

Finaliza la escritura en la fuente. Reemplaza los datos originales con los datos recién escritos. Limpia archivos temporales o búferes internos. Posteriormente, abrir y leer desde la fuente debe devolver los datos recién escritos.

ZIP_SOURCE_ERROR

Obtener información de error. data apunta a un array de dos enteros, que deben ser llenados con el código de error de libzip y el código de error del sistema correspondiente al error que ocurrió. Consulte zip_errors(3) para más detalles sobre los códigos de error. Si la fuente almacena información de error en una zip_error_t, use zip_error_to_data(3) y devuelva su valor de retorno. De lo contrario, devuelva 2 * sizeof(int).

ZIP_SOURCE_FREE

Limpia y libera todos los recursos, incluyendo userdata. La función de callback no será llamada nuevamente.

ZIP_SOURCE_GET_FILE_ATTRIBUTES

Proporcionar información sobre varios datos. Luego, los datos deben ser colocados en la entrada apropiada de la estructura zip_file_attributes_t pasada, y el valor apropiado de ZIP_FILE_ATTRIBUTES_* debe ser aplicado mediante OR al miembro valid para indicar que los datos correspondientes han sido proporcionados. Una estructura zip_file_attributes_t puede ser inicializada usando zip_file_attributes_init(3).

modo ASCII
Si un archivo es un archivo de texto plano en ASCII. Puede ser utilizado por herramientas de extracción para convertir automáticamente los finales de línea (parte de los atributos internos del archivo). Miembro ascii, indicador ZIP_FILE_ATTRIBUTES_ASCII.
Indicadores de bits de propósito general (limitado a Indicadores de Compresión)
El indicador de bits de propósito general en el encabezado de directorio local y central del zip contiene información sobre el método de compresión. Miembro general_purpose_bit_flags

general_purpose_bit_mask y general_purpose_bit_mask para indicar qué miembros han sido establecidos; flag ZIP_FILE_ATTRIBUTES_GENERAL_PURPOSE_BIT_FLAGS.
Atributos de Archivo Externo
Los atributos de archivo externo (normalmente específicos del sistema operativo). Miembro external_file_attributes, flag ZIP_FILE_ATTRIBUTES_EXTERNAL_FILE_ATTRIBUTES.
Versión Necesaria
Una versión mínima necesaria requerida para desempaquetar esta entrada (en el formato habitual "mayor * 10 + menor"). Miembro version_needed, flag ZIP_FILE_ATTRIBUTES_VERSION_NEEDED.
Sistema Operativo
Uno de los sistemas operativos definidos por las variables ZIP_OPSYS_* (ver zip.h). Este valor afecta la interpretación de los atributos de archivo externo. Miembro host_system, flag ZIP_FILE_ATTRIBUTES_HOST_SYSTEM.

ZIP_SOURCE_OPEN

Prepararse para leer.

ZIP_SOURCE_READ

Leer datos en el búfer data de tamaño len. Devolver el número de bytes colocados en data en caso de éxito, y cero para fin de archivo.

ZIP_SOURCE_REMOVE

Eliminar el archivo subyacente. Se llama si un archivo zip está vacío al cerrarse.

ZIP_SOURCE_ROLLBACK_WRITE

Abortar la escritura en la fuente. Descartar los datos escritos. Limpiar archivos temporales o búferes internos. Posteriormente, abrir y leer desde la fuente debería devolver los datos originales.

ZIP_SOURCE_SEEK

Especificar la posición desde la cual leer el siguiente byte, como fseek(3). Usar ZIP_SOURCE_GET_ARGS(3) para decodificar los argumentos en la siguiente estructura:

struct zip_source_args_seek {
    zip_int64_t offset;
    int whence;
};

Si se conoce el tamaño de los datos de la fuente, usar zip_source_seek_compute_offset(3) para validar los argumentos y calcular el nuevo desplazamiento.

ZIP_SOURCE_SEEK_WRITE

Especificar la posición en la cual escribir el siguiente byte, como fseek(3). Ver ZIP_SOURCE_SEEK para detalles.

ZIP_SOURCE_STAT

Obtener información meta para los datos de entrada. data apunta a una struct zip_stat asignada, que debe ser inicializada usando zip_stat_init(3) y luego rellenada.

Para datos sin comprimir y sin cifrar, toda la información es opcional. Sin embargo, rellene tanta información como esté fácilmente disponible.

Si los datos están comprimidos, ZIP_STAT_COMP_METHOD, ZIP_STAT_SIZE, y ZIP_STAT_CRC deben ser rellenados.

Si los datos están cifrados, ZIP_STAT_ENCRYPTION_METHOD, ZIP_STAT_COMP_METHOD, ZIP_STAT_SIZE, y ZIP_STAT_CRC deben ser rellenados.

La información que solo está disponible después de que la fuente ha sido leída (por ejemplo, tamaño) puede omitirse en una llamada anterior. NOTA: zip_source_function() puede ser llamado con este argumento incluso después de ser llamado con ZIP_SOURCE_CLOSE.

Devolver sizeof(struct zip_stat) en caso de éxito.

ZIP_SOURCE_SUPPORTS

Devolver un mapa de bits especificando qué comandos son soportados. Usar zip_source_make_command_bitmap(3). Si este comando no está implementado, se asume que la fuente es una fuente de lectura sin soporte de búsqueda.

ZIP_SOURCE_TELL

Devolver el desplazamiento de lectura actual en la fuente, como ftell(3).

ZIP_SOURCE_TELL_WRITE

Devolver el desplazamiento de escritura actual en la fuente, como ftell(3).

ZIP_SOURCE_WRITE

Escribir datos en la fuente. Devolver el número de bytes escritos.

ZIP_SOURCE_SUPPORTS_REOPEN

Este comando nunca se invoca realmente, el soporte para él señala la capacidad de manejar múltiples ciclos de apertura/lectura/cierre.

Valores de Retorno

Los comandos deben devolver -1 en caso de error. ZIP_SOURCE_ERROR será llamado para recuperar el código de error. En caso de éxito, los comandos devuelven 0, a menos que se especifique lo contrario en la descripción anterior.

Convenciones de Llamada

La biblioteca siempre emitirá ZIP_SOURCE_OPEN antes de emitir ZIP_SOURCE_READ, ZIP_SOURCE_SEEK, o ZIP_SOURCE_TELL. Cuando ya no desee leer de esta fuente, emitirá ZIP_SOURCE_CLOSE. Si la biblioteca desea leer los datos nuevamente, emitirá ZIP_SOURCE_OPEN una segunda vez. Si la función es incapaz de proporcionar los datos nuevamente, debería devolver -1.

ZIP_SOURCE_BEGIN_WRITE o ZIP_SOURCE_BEGIN_WRITE_CLONING serán llamados antes de ZIP_SOURCE_WRITE, ZIP_SOURCE_SEEK_WRITE, o ZIP_SOURCE_TELL_WRITE. Cuando la escritura esté completa, se llamará a ZIP_SOURCE_COMMIT_WRITE o ZIP_SOURCE_ROLLBACK_WRITE.

ZIP_SOURCE_ACCEPT_EMPTY, ZIP_SOURCE_GET_FILE_ATTRIBUTES, y ZIP_SOURCE_STAT pueden ser emitidos en cualquier momento.

ZIP_SOURCE_ERROR solo se emitirá en respuesta a que la función devuelva -1.

ZIP_SOURCE_FREE será el último comando emitido; si se llamó a ZIP_SOURCE_OPEN y tuvo éxito, se llamará a ZIP_SOURCE_CLOSE antes de ZIP_SOURCE_FREE, y de manera similar para ZIP_SOURCE_BEGIN_WRITE o ZIP_SOURCE_BEGIN_WRITE_CLONING y ZIP_SOURCE_COMMIT_WRITE o ZIP_SOURCE_ROLLBACK_WRITE.

VALORES DE RETORNO

Tras una finalización exitosa, se devuelve la fuente creada. De lo contrario, se devuelve NULL y el código de error en archive o error se establece para indicar el error (a menos que sea NULL).

ERRORES

zip_source_function() falla si:

[ZIP_ER_MEMORY]
No se pudo asignar la memoria requerida.
