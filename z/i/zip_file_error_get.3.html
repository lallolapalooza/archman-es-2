zip_file_error_get(3)

Paquete: libzip

Licencias: BSD

ZIP_ERROR_GET(3) Manual de funciones de la biblioteca ZIP_ERROR_GET(3)

NOMBRE

zip_error_get, zip_file_error_get — obtener códigos de error para archivo o fichero (interfaz obsoleta)

BIBLIOTECA

libzip (-lzip)

SINOPSIS

#include <zip.h>

void
zip_error_get(zip_t *archive, int *zep, int *sep);

void
zip_file_error_get(zip_file_t *file, int *zep, int *sep);

DESCRIPCIÓN

Las funciones zip_error_get() y zip_file_error_get() están obsoletas. Use zip_error_code_system(3), zip_error_code_zip(3), zip_file_get_error(3), y zip_get_error(3) en su lugar.

Para zip_error_get(), reemplace

int ze, se;
zip_error_get(za, &ze, &se);
con 
int ze, se;
zip_error_t *error = zip_get_error(za);
ze = zip_error_code_zip(error);
se = zip_error_code_system(error);
Para zip_file_error_get(), reemplace 
int ze, se;
zip_file_error_get(zf, &ze, &se);
con 
int ze, se;
zip_error_t *error = zip_file_get_error(zf);
ze = zip_error_code_zip(error);
se = zip_error_code_system(error);

VER TAMBIÉN

libzip(3), zip_error_code_system(3), zip_error_code_zip(3), zip_file_get_error(3), zip_get_error(3)

HISTORIA

zip_error_get() se añadió en libzip 0.6. Se obsoletó en libzip 1.0, use zip_get_error(), zip_error_code_zip(), / zip_error_code_system() en su lugar.

zip_file_error_get() se añadió en libzip 0.6. Se obsoletó en libzip 1.0, use zip_file_get_error(), zip_error_code_zip(), / zip_error_code_system() en su lugar.
