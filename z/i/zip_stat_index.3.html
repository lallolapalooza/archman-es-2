zip_stat_index(3)

Paquete: libzip

Licencias: BSD

ZIP_STAT(3) Manual de funciones de biblioteca ZIP_STAT(3)

NOMBRE

zip_stat, zip_stat_index — obtener información sobre un archivo

BIBLIOTECA

libzip (-lzip)

SINOPSIS

#include <zip.h>

int
zip_stat(zip_t *archivo, const char *fname, zip_flags_t flags, zip_stat_t *sb);

int
zip_stat_index(zip_t *archivo, zip_uint64_t índice, zip_flags_t flags, zip_stat_t *sb);

DESCRIPCIÓN

La función zip_stat() obtiene información sobre el archivo llamado fname en archivo. El argumento flags especifica cómo debe realizarse la búsqueda del nombre. Sus valores se describen en zip_name_locate(3). Además, ZIP_FL_UNCHANGED puede ser or en él para solicitar información sobre el archivo original en el archivo, ignorando cualquier cambio realizado.

La función zip_stat_index() obtiene información sobre el archivo en la posición índice.

El argumento sb es un puntero a una struct zip_stat (mostrada a continuación), en la que se coloca la información sobre el archivo.

struct zip_stat {
    zip_uint64_t valid;                 /* qué campos tienen valores válidos */
    const char *name;                   /* nombre del archivo */
    zip_uint64_t index;                 /* índice dentro del archivo */
    zip_uint64_t size;                  /* tamaño del archivo (sin comprimir) */
    zip_uint64_t comp_size;             /* tamaño del archivo (comprimido) */
    time_t mtime;                       /* hora de modificación */
    zip_uint32_t crc;                   /* crc de los datos del archivo */
    zip_uint16_t comp_method;           /* método de compresión utilizado */
    zip_uint16_t encryption_method;     /* método de cifrado utilizado */
    zip_uint32_t flags;                 /* reservado para uso futuro */
};
La estructura apuntada por sb debe ser asignada antes de llamar a zip_stat() o zip_stat_index().

El campo valid de la estructura especifica qué otros campos son válidos. Compruebe si la bandera definida por las siguientes definiciones se encuentra en valid antes de acceder a los campos:

ZIP_STAT_NAME
name
ZIP_STAT_INDEX
index
ZIP_STAT_SIZE
size
ZIP_STAT_COMP_SIZE
comp_size
ZIP_STAT_MTIME
mtime
ZIP_STAT_CRC
crc
ZIP_STAT_COMP_METHOD
comp_method
ZIP_STAT_ENCRYPTION_METHOD
encryption_method
ZIP_STAT_FLAGS
flags

VALORES DE RETORNO

Al completarse con éxito, se devuelve 0. De lo contrario, se devuelve -1 y la información de error en archivo se establece para indicar el error.

ERRORES

La función zip_stat() puede fallar por cualquiera de los errores especificados para la rutina zip_name_locate(3).

La función zip_stat_index() falla y establece la información de error a ZIP_ER_INVAL si índice no es válido. Si ZIP_FL_UNCHANGED no está establecido y no se puede obtener información del callback de origen, la información de error se establece a ZIP_ER_CHANGED.

VER TAMBIÉN

libzip(3), zip_get_num_entries(3), zip_name_locate(3), zip_stat_init(3)

HISTORIAL

zip_stat() se añadió en libzip 0.6. En libzip 0.11, el tipo de flags se cambió de int a zip_flags_t.

zip_stat_index() se añadió en libzip 0.6. En libzip 0.10, el tipo de índice se cambió de int a zip_uint64_t. En libzip 0.11, el tipo de flags se cambió de int a zip_flags_t.
