NOMBRE

zip_file — archivo en un archivo comprimido

BIBLIOTECA

libzip (-lzip)

SINOPSIS

#include <zip.h>

zip_file_t *archivo;

DESCRIPCIÓN

Un zip_file representa un archivo dentro de un archivo comprimido, abierto para lectura. Se crea con zip_fopen(3), zip_fopen_index(3), zip_fopen_encrypted(3), o zip_fopen_index_encrypted(3).

Los datos se acceden con zip_fread(3), zip_file_is_seekable(3), zip_ftell(3), o zip_fseek(3).

Se cierra con zip_fclose(3).

Si el zip_t contenedor se cierra, todos los usos posteriores del zip_file_t devuelven un error. Es un envoltorio de conveniencia alrededor de un zip_source_t tal como se crea con zip_source_zip(3).

VER TAMBIÉN
