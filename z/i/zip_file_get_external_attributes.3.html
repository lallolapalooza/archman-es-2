zip_file_get_external_attributes(3)

Paquete: libzip

Licencias: BSD

ZIP_FILE_GET_EXTERNAL_ATTRIBUTES(3) Manual de funciones de la biblioteca ZIP_FILE_GET_EXTERNAL_ATTRIBUTES(3)

NOMBRE

zip_file_get_external_attributes — obtener atributos externos para un archivo en un zip

BIBLIOTECA

libzip (-lzip)

SINOPSIS

#include <zip.h>

int
zip_file_get_external_attributes(zip_t *archive, zip_uint64_t index, zip_flags_t flags, zip_uint8_t *opsys, zip_uint32_t *attributes);

DESCRIPCIÓN

La función zip_file_get_external_attributes() devuelve el sistema operativo y los atributos externos del archivo en la posición index en el archivo zip. Los atributos externos generalmente contienen los permisos de archivo específicos del sistema operativo. Si flags está establecido en ZIP_FL_UNCHANGED, se devuelven los valores originales sin cambios. Si opsys o attributes son NULL, no se rellenan.

Los siguientes sistemas operativos están definidos por la especificación zip:

  • ZIP_OPSYS_ACORN_RISC
  • ZIP_OPSYS_ALTERNATE_MVS
  • ZIP_OPSYS_AMIGA
  • ZIP_OPSYS_ATARI_ST
  • ZIP_OPSYS_BEOS
  • ZIP_OPSYS_CPM
  • ZIP_OPSYS_DOS
  • ZIP_OPSYS_MACINTOSH
  • ZIP_OPSYS_MVS
  • ZIP_OPSYS_OPENVMS
  • ZIP_OPSYS_OS_2
  • ZIP_OPSYS_OS_400
  • ZIP_OPSYS_OS_X
  • ZIP_OPSYS_TANDEM
  • ZIP_OPSYS_UNIX
  • ZIP_OPSYS_VFAT
  • ZIP_OPSYS_VM_CMS
  • ZIP_OPSYS_VSE
  • ZIP_OPSYS_WINDOWS_NTFS (poco común, usar ZIP_OPSYS_DOS en su lugar)
  • ZIP_OPSYS_Z_SYSTEM

Las definiciones anteriores siguen la Appnote de PKWARE Inc.; tenga en cuenta que la Appnote de InfoZIP tiene un mapeo ligeramente diferente.

VALORES DE RETORNO

Al completarse con éxito, se devuelve 0. En caso de error, se devuelve -1 y el código de error en archive se establece para indicar el error.

EJEMPLOS

El siguiente código se puede utilizar para expandir attributes si el sistema operativo es ZIP_OPSYS_DOS.

#include <sys/stat.h>

#define FA_RDONLY       0x01            // FILE_ATTRIBUTE_READONLY
#define FA_DIREC        0x10            // FILE_ATTRIBUTE_DIRECTORY

static mode_t
_zip_dos_attr2mode(zip_uint32_t attr)
{
   mode_t m = S_IRUSR | S_IRGRP | S_IROTH;
   if (0 == (attr & FA_RDONLY))
      m |= S_IWUSR | S_IWGRP | S_IWOTH;

   if (attr & FA_DIREC)
      m = (S_IFDIR | (m & ~S_IFMT)) | S_IXUSR | S_IXGRP | S_IXOTH;

   return m;
}

ERRORES

zip_file_get_external_attributes() falla si:

[ZIP_ER_INVAL]
index no es un índice de archivo válido en archive.

VER TAMBIÉN

libzip(3), zip_file_set_external_attributes(3)

HISTORIA

zip_file_get_external_attributes() se añadió en libzip 0.11.2.
