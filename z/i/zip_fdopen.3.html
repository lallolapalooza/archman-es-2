zip_fdopen(3)

Paquete: libzip

Licencias: BSD

ZIP_FDOPEN(3) Manual de funciones de biblioteca ZIP_FDOPEN(3)

NOMBRE

zip_fdopen — abrir un archivo zip usando un descriptor de archivo abierto

BIBLIOTECA

libzip (-lzip)

SINOPSIS

#include <zip.h>

zip_t *
zip_fdopen(int fd, int flags, int *errorp);

DESCRIPCIÓN

El archivo zip especificado por el descriptor de archivo abierto fd se abre y se devuelve un puntero a una struct zip, utilizada para manipular el archivo. En contraste con zip_open(3), al usar zip_fdopen, el archivo solo se puede abrir en modo de solo lectura. El argumento fd no se puede usar más después de llamar a zip_fdopen. Las flags se especifican mediante or adicionar las siguientes valores, o 0 para ninguno de ellos.

ZIP_CHECKCONS
Realiza comprobaciones de consistencia más estrictas y adicionales en el archivo, y genera un error si fallan.

Si ocurre un error y errorp no es NULL, se establecerá con el código de error correspondiente.

VALORES DE RETORNO

Al completarse con éxito, zip_fdopen() devuelve un puntero struct zip, y fd no debe usarse más, ni pasarse a close(2). De lo contrario, se devuelve NULL y *errorp se establece para indicar el error. En caso de error, fd permanece sin cambios.

ERRORES

El archivo especificado por fd se prepara para su uso por libzip(3) a menos que:

[ZIP_ER_INCONS]
Se encontraron inconsistencias en el archivo especificado por path. Este error a menudo es causado por especificar ZIP_CHECKCONS, pero también puede ocurrir sin él.
[ZIP_ER_INVAL]
El argumento flags es inválido. No todas las flags de zip_open(3) están permitidas para zip_fdopen, ver DESCRIPCIÓN.
[ZIP_ER_MEMORY]
No se pudo asignar la memoria requerida.
[ZIP_ER_NOZIP]
El archivo especificado por fd no es un archivo zip.
[ZIP_ER_OPEN]
El archivo especificado por fd no pudo ser preparado para su uso por libzip(3).
[ZIP_ER_OPNOTSUPP]
Esta funcionalidad ha sido deshabilitada en tiempo de compilación.
[ZIP_ER_READ]
Ocurrió un error de lectura; ver errno para detalles.
[ZIP_ER_SEEK]
El archivo especificado por fd no permite buscar.

VER TAMBIÉN

libzip(3), zip_close(3), zip_error_strerror(3), zip_open(3)

HISTORIA

zip_fdopen() se añadió en libzip 1.0.
