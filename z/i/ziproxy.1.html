NOMBRE

ziproxy - un servidor proxy HTTP de compresión

SINOPSIS

ziproxy <-d|-i|-k> [-c archivo_config] [-u nombre_usuario] [-g nombre_grupo] [-p archivo_pid] [-h]

DESCRIPCIÓN

ziproxy es un servidor proxy HTTP de reenvío, sin caché y con compresión. Básicamente, reduce el tamaño de las imágenes convirtiéndolas a JPEGs de menor calidad y comprime (gzip) HTML y otros datos similares a texto.

OPCIONES

Estos programas siguen la sintaxis habitual de línea de comandos de GNU, con opciones largas que comienzan con dos guiones (`-'). A continuación se incluye un resumen de las opciones.

-d, --daemon-mode
Se utiliza al ejecutarse en modo independiente.
-i, --inetd-mode
Se utiliza al ejecutarse desde inetd o xinetd.
-k, --stop-daemon
Detiene el demonio.
-c, --config-file archivo_config
Ruta completa al archivo ziproxy.conf (en lugar del predeterminado).
-u, --user nombre_usuario
Ejecuta el demonio como el usuario especificado. Si no se especifica y se proporciona nombre_usuario, utiliza el grupo de nombre_usuario.
-g, --group nombre_grupo
Ejecuta el demonio como el grupo especificado.
-p, --pid-file archivo_pid
Utiliza el archivo PID especificado para el control del demonio.
-h, --help
Muestra una ayuda resumida.
