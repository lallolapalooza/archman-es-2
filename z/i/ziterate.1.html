NOMBRE

ziterate - Archivo de generación de permutación de IPs de ZMap

SINOPSIS

ziterate [ -b <lista_bloqueados> ] [ -w <lista_permitidos> ] [ OPCIONES... ]

DESCRIPCIÓN

ZIterate es una herramienta de red que producirá direcciones IPv4 en un orden de permutación pseudorandom similar a cómo ZMap genera direcciones aleatorias para ser escaneadas.

OPCIONES

OPCIONES BÁSICAS

-p, --puertos-objetivo=puerto(s)
Lista de puertos TCP/UDP y/o rangos de puertos para escanear. (ej. 80,443,100-105). Use ´*´ para escanear todos los puertos, incluido el puerto 0. Si no se especifica ningún puerto, ziterate solo generará IPs.
-b, --archivo-lista-bloqueados=ruta
Archivo de subredes a excluir, en notación CIDR, una por línea. Se recomienda usarlo para excluir direcciones RFC 1918, multidifusión, espacio reservado de IANA y otras direcciones de propósito especial de IANA. Un ejemplo de archivo de lista de bloqueados blocklist.conf para este propósito.
-w, --archivo-lista-permitidos=nombre
Archivo de subredes a incluir, en notación CIDR, una por línea. Todas las demás subredes serán excluidas.
-l, --archivo-log=nombre
Archivo al que registrar.
--desactivar-syslog
Desactiva el registro de mensajes a syslog.
-v, --verbosidad
Nivel de detalle del registro (0-5, por defecto=3)
--ignorar-errores-lista-bloqueados
Ignora entradas inválidas en la lista de bloqueados. Por defecto es falso.
--seed=n
Semilla utilizada para seleccionar la permutación de direcciones.
-n, --max-objetivos=n
Limita el número de IPs a generar (como número o como porcentaje del espacio de direcciones)

DIVISIÓN EN PARTES (SHARDING)

--shards=n
Número total de partes.
--shard=n
Parte a la que se dirige este escaneo. Índice cero.

OPCIONES ADICIONALES

-h, --ayuda
Imprime el texto de ayuda y sale.
-V, --version
Imprime la versión y sale.
