NOMBRE

zmq_msg_get - obtener propiedad del mensaje

SINOPSIS

int zmq_msg_get (zmq_msg_t *mensaje, int propiedad);

DESCRIPCIÓN

La función zmq_msg_get() devolverá el valor de la propiedad especificada por el argumento propiedad para el mensaje apuntado por el argumento mensaje.

Las siguientes propiedades se pueden recuperar con la función zmq_msg_get():

ZMQ_MORE

Indica que hay más fotogramas de mensaje que seguirán después del mensaje.

ZMQ_SRCFD

Devuelve el descriptor de archivo del socket desde el que se leyó el mensaje. Esto permite a la aplicación recuperar el punto final remoto a través de getpeername(2). Tenga en cuenta que el socket respectivo ya podría estar cerrado, o incluso reutilizado. Actualmente solo implementado para sockets TCP.

ZMQ_SHARED

Indica que un mensaje PUEDE compartir almacenamiento subyacente con otra copia de este mensaje.

VALOR DE RETORNO

La función zmq_msg_get() devolverá el valor de la propiedad si tiene éxito. De lo contrario, devolverá -1 y establecerá errno en uno de los valores definidos a continuación.

ERRORES

EINVAL

La propiedad solicitada es desconocida.

EJEMPLO

Recibir un mensaje de varios fotogramas.

zmq_msg_t frame;
while (true) {
    //  Crear un mensaje 0MQ vacío para contener el fotograma del mensaje
    int rc = zmq_msg_init (&frame);
    assert (rc == 0);
    //  Bloquear hasta que haya un mensaje disponible para recibir del socket
    rc = zmq_msg_recv (socket, &frame, 0);
    assert (rc != -1);
    if (zmq_msg_get (&frame, ZMQ_MORE))
        fprintf (stderr, "more\n");
    else {
        fprintf (stderr, "end\n");
        break;
    }
    zmq_msg_close (&frame);
}
