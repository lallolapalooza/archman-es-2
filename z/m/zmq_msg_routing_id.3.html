zmq_msg_routing_id(3)

Paquete: zeromq

Licencias: MPL2

ZMQ_MSG_ROUTING_ID(3) Manual de 0MQ ZMQ_MSG_ROUTING_ID(3)

NOMBRE

zmq_msg_routing_id - devuelve el ID de enrutamiento del mensaje, si existe

SINOPSIS

uint32_t zmq_msg_routing_id (zmq_msg_t *mensaje);

DESCRIPCIÓN

La función zmq_msg_routing_id() devuelve el ID de enrutamiento del mensaje, si existe. El ID de enrutamiento se establece en todos los mensajes recibidos de un socket ZMQ_SERVER. Para enviar un mensaje a un socket ZMQ_SERVER, debes establecer el ID de enrutamiento de un peer ZMQ_CLIENT conectado. Los IDs de enrutamiento son transitorios.

VALOR DE RETORNO

La función zmq_msg_routing_id() devolverá cero si no hay un ID de enrutamiento; de lo contrario, devolverá un entero sin signo de 32 bits mayor que cero.

EJEMPLO

Recibir un mensaje de cliente y su ID de enrutamiento.

void *ctx = zmq_ctx_new ();
assert (ctx);
void *server = zmq_socket (ctx, ZMQ_SERVER);
assert (server);
int rc = zmq_bind (server, "tcp://127.0.0.1:8080");
assert (rc == 0);
zmq_msg_t message;
rc = zmq_msg_init (&message);
assert (rc == 0);
//  Recibir un mensaje del socket
rc = zmq_msg_recv (server, &message, 0);
assert (rc != -1);
uint32_t routing_id = zmq_msg_routing_id (&message);
assert (routing_id);

VER TAMBIÉN
