NOMBRE

zmq_msg_gets - obtener propiedad de metadatos del mensaje

SINOPSIS

const char *zmq_msg_gets (zmq_msg_t *mensaje, const char *propiedad);

DESCRIPCIÓN

La función zmq_msg_gets() devolverá el valor de cadena para la propiedad de metadatos especificada por el argumento propiedad para el mensaje apuntado por el argumento mensaje. Tanto el argumento propiedad como el valor serán cadenas codificadas en UTF8 y terminadas en NULL.

Los metadatos se definen por conexión durante el apretón de manos de conexión de ZeroMQ, como se especifica en <rfc.zeromq.org/spec:37>. Las aplicaciones pueden establecer propiedades de metadatos usando la opción ZMQ_METADATA de zmq_setsockopt(3). Las propiedades de metadatos de la aplicación deben prefijarse con X-.

Además de los metadatos de la aplicación, las siguientes propiedades ZMTP se pueden recuperar con la función zmq_msg_gets():

Socket-Type
Routing-Id

Nota: Identity es un alias obsoleto para Routing-Id.

Adicionalmente, cuando esté disponible para el transporte subyacente, la propiedad Peer-Address devolverá la dirección IP del punto final remoto, tal como la devuelve getnameinfo(2).

Los nombres de estas propiedades también se definen en zmq.h como ZMQ_MSG_PROPERTY_SOCKET_TYPE, ZMQ_MSG_PROPERTY_ROUTING_ID y ZMQ_MSG_PROPERTY_PEER_ADDRESS. Actualmente, estas definiciones solo están disponibles como una API BORRADOR.

Otras propiedades pueden definirse según el mecanismo de seguridad subyacente; consulte el ejemplo de conexión autenticada ZAP a continuación.

VALOR DE RETORNO

La función zmq_msg_gets() devolverá el valor de cadena para la propiedad si tiene éxito. De lo contrario, devolverá NULL y establecerá errno en uno de los valores definidos a continuación. El llamador no debe modificar ni liberar el valor devuelto, que será propiedad del mensaje. La codificación de la propiedad y el valor será UTF8.

ERRORES

EINVAL

La propiedad solicitada es desconocida.

EJEMPLO

Obtener el ID de usuario autenticado por ZAP para un mensaje:.

zmq_msg_t msg;
zmq_msg_init (&msg);
rc = zmq_msg_recv (&msg, dealer, 0);
assert (rc != -1);
const char *user_id = zmq_msg_gets (&msg, ZMQ_MSG_PROPERTY_USER_ID);
zmq_msg_close (&msg);
