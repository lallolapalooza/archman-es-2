NOMBRE

zmq_ctx_get - obtener opciones del contexto

SINOPSIS

int zmq_ctx_get (void *context, int option_name);

DESCRIPCIÓN

La función zmq_ctx_get() devolverá la opción especificada por el argumento option_name.

La función zmq_ctx_get() acepta los siguientes nombres de opciones:

ZMQ_IO_THREADS: Obtener número de hilos de E/S

El argumento ZMQ_IO_THREADS devuelve el tamaño del pool de hilos de 0MQ para este contexto.

ZMQ_MAX_SOCKETS: Obtener número máximo de sockets

El argumento ZMQ_MAX_SOCKETS devuelve el número máximo de sockets permitidos para este contexto.

ZMQ_MAX_MSGSZ: Obtener tamaño máximo del mensaje

El argumento ZMQ_MAX_MSGSZ devuelve el tamaño máximo de un mensaje permitido para este contexto. El valor predeterminado es INT_MAX.

ZMQ_ZERO_COPY_RECV: Obtener estrategia de decodificación del mensaje

El argumento ZMQ_ZERO_COPY_RECV devuelve si el decodificador de mensajes utiliza una estrategia de copia cero al recibir mensajes. El valor predeterminado es 1. NOTA: en estado DRAFT, aún no disponible en versiones estables.

ZMQ_SOCKET_LIMIT: Obtener el mayor número configurable de sockets

El argumento ZMQ_SOCKET_LIMIT devuelve el mayor número de sockets que zmq_ctx_set(3) aceptará.

ZMQ_IPV6: Establecer opción IPv6

El argumento ZMQ_IPV6 devuelve la opción IPv6 para el contexto.

ZMQ_BLOCKY: Obtener configuración de bloqueo

El argumento ZMQ_BLOCKY devuelve 1 si el contexto se bloqueará al terminar, cero si la "apuesta de bloqueo perpetuo al terminar el contexto" se deshabilitó estableciendo ZMQ_BLOCKY a falso en todos los contextos nuevos.

ZMQ_THREAD_SCHED_POLICY: Obtener política de planificación para hilos de E/S

El argumento ZMQ_THREAD_SCHED_POLICY devuelve la política de planificación para el pool de hilos interno del contexto.

ZMQ_THREAD_NAME_PREFIX: Obtener prefijo de nombre para hilos de E/S

El argumento ZMQ_THREAD_NAME_PREFIX obtiene el prefijo numérico de cada hilo creado para el pool de hilos interno del contexto.

ZMQ_MSG_T_SIZE: Obtener el tamaño de zmq_msg_t en tiempo de ejecución

El argumento ZMQ_MSG_T_SIZE devuelve el tamaño de la estructura zmq_msg_t en tiempo de ejecución, tal como se define en la cabecera pública include/zmq.h. Esto es útil, por ejemplo, para enlaces FFI que no pueden simplemente usar un sizeof().

VALOR DE RETORNO

La función zmq_ctx_get() devuelve un valor de 0 o mayor si tiene éxito. De lo contrario, devuelve -1 y establece errno a uno de los valores definidos a continuación.

ERRORES

EINVAL

La opción solicitada option_name es desconocida.

EFAULT

El context proporcionado es inválido.

EJEMPLO

Establecer un límite en el número de sockets.

void *context = zmq_ctx_new ();
zmq_ctx_set (context, ZMQ_MAX_SOCKETS, 256);
int max_sockets = zmq_ctx_get (context, ZMQ_MAX_SOCKETS);
assert (max_sockets == 256);

Desactivar la táctica de bloqueo del contexto.

zmq_ctx_set (ctx, ZMQ_BLOCKY, false);
