zmq_close(3)

Paquete: zeromq

Licencias: MPL2

ZMQ_CLOSE(3) Manual de 0MQ ZMQ_CLOSE(3)

NOMBRE

zmq_close - cerrar socket 0MQ

SINOPSIS

int zmq_close (void *socket);

DESCRIPCIÓN

La función zmq_close() destruirá el socket al que se refiere el argumento socket. Cualquier mensaje pendiente recibido físicamente de la red pero aún no recibido por la aplicación con zmq_recv() se descartará. El comportamiento al descartar mensajes enviados por la aplicación con zmq_send() pero no transferidos físicamente a la red depende del valor de la opción de socket ZMQ_LINGER para el socket especificado.

zmq_close() debe llamarse exactamente una vez por cada socket. Si nunca se llama, zmq_ctx_term() se bloqueará para siempre. Si se llama varias veces para el mismo socket o si socket no apunta a un socket, el comportamiento es indefinido.


Nota

La configuración predeterminada de ZMQ_LINGER no descarta mensajes no enviados; este comportamiento puede hacer que la aplicación se bloquee al llamar a zmq_ctx_term(). Para más detalles, consulte zmq_setsockopt(3) y zmq_ctx_term(3).


Nota

Esta API se completará de forma asíncrona, por lo que no todo se liberará después de que regrese. Ver arriba para detalles sobre linger.

VALOR DE RETORNO

La función zmq_close() devolverá cero si tiene éxito. De lo contrario, devolverá -1 y establecerá errno a uno de los valores definidos a continuación.

ERRORES

ENOTSOCK

El socket proporcionado era NULL.
