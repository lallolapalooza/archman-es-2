Paquete: zeromq

NOMBRE

zmq_msg_init - inicializar un mensaje 0MQ vacío

SINOPSIS

int zmq_msg_init (zmq_msg_t *msg);

DESCRIPCIÓN

La función zmq_msg_init() inicializará el objeto de mensaje referenciado por msg para representar un mensaje vacío. Esta función es más útil cuando se llama antes de recibir un mensaje con zmq_msg_recv().


Precaución

Nunca acceda a los miembros de zmq_msg_t directamente, en su lugar, utilice siempre la familia de funciones zmq_msg.


Precaución

Las funciones zmq_msg_init(), zmq_msg_init_data(), zmq_msg_init_size() y zmq_msg_init_buffer() son mutuamente excluyentes. Nunca inicialice el mismo zmq_msg_t dos veces.

VALOR DE RETORNO

La función zmq_msg_init() siempre devuelve cero.

ERRORES

No se definen errores.

EJEMPLO

Recibir un mensaje de un socket.

zmq_msg_t msg;
rc = zmq_msg_init (&msg);
assert (rc == 0);
int nbytes = zmq_msg_recv (socket, &msg, 0);
assert (nbytes != -1);
