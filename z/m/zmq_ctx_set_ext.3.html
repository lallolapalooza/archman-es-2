NOMBRE

zmq_ctx_set_ext - establecer opciones de contexto extendidas

SINOPSIS

int zmq_ctx_set_ext (void *context, int option_name, const void *option_value, size_t option_len);

DESCRIPCIÓN

La función zmq_ctx_set_ext() establecerá la opción especificada por el argumento option_name al valor apuntado por el argumento option_value para el contexto 0MQ apuntado por el argumento context. El argumento option_len es el tamaño del valor de la opción en bytes. Para opciones que toman un valor de tipo "cadena de caracteres", los datos de bytes proporcionados no deben contener bytes nulos, o deben terminar en un único byte nulo (carácter NUL ASCII terminador).

La función zmq_ctx_set_ext() acepta todos los nombres de opciones aceptados por zmq_ctx_set(). Las opciones que tienen más sentido establecer con zmq_ctx_set_ext() en lugar de zmq_ctx_set() son las siguientes opciones:

ZMQ_THREAD_NAME_PREFIX: Establecer prefijo de nombre para hilos de E/S

El argumento ZMQ_THREAD_NAME_PREFIX establece un prefijo de cadena a cada hilo creado para el grupo de hilos del contexto interno. Esta opción solo se admite en Linux. Esta opción es útil para ayudar en la depuración realizada a través de "top -H" o "gdb"; en caso de que varios procesos en el sistema estén utilizando ZeroMQ, es útil proporcionar a través de esta opción de contexto un prefijo específico de la aplicación para distinguir los hilos de fondo de ZeroMQ que pertenecen a diferentes procesos. Esta opción solo se aplica antes de crear ningún socket en el contexto.

Tipo de valor de la opción cadena de caracteres
Unidad del valor de la opción N/A
Valor predeterminado cadena vacía

VALOR DE RETORNO

La función zmq_ctx_set_ext() devuelve cero si tiene éxito. De lo contrario, devuelve -1 y establece errno a uno de los valores definidos a continuación.

ERRORES

EINVAL

El option_name solicitado no es válido.

EFAULT

El context proporcionado no es válido.

EJEMPLO

Establecer un prefijo en los nombres de hilos internos de ZMQ:.

void *context = zmq_ctx_new ();
const char prefix[] = "MiApp";
size_t prefixLen = sizeof(prefix);
zmq_ctx_set (context, ZMQ_THREAD_NAME_PREFIX, &prefix, &prefixLen);
char buff[256];
size_t buffLen = sizeof(buff);
int rc = zmq_ctx_get (context, ZMQ_THREAD_NAME_PREFIX, &buff, &buffLen);
assert (rc == 0);
assert (buffLen == prefixLen);
