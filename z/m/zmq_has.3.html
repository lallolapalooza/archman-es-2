NOMBRE

zmq_has - comprobar una capacidad de ZMQ

SINOPSIS

int zmq_has (const char *capability);

DESCRIPCIÓN

La función zmq_has() informará si una capacidad especificada está disponible en la biblioteca. Esto permite a los enlaces y aplicaciones consultar una biblioteca directamente, para opciones de transporte y seguridad.

Las capacidades serán cadenas en minúsculas. Las siguientes capacidades están definidas:

•ipc - la biblioteca soporta el protocolo ipc://
•pgm - la biblioteca soporta el protocolo pgm://
•tipc - la biblioteca soporta el protocolo tipc://
•norm - la biblioteca soporta el protocolo norm://
•curve - la biblioteca soporta el mecanismo de seguridad CURVE
•gssapi - la biblioteca soporta el mecanismo de seguridad GSSAPI
•draft - la biblioteca está compilada con la API draft

Cuando se proporcione este método, el archivo de cabecera zmq.h definirá ZMQ_HAS_CAPABILITIES.

VALOR DEVUELTO

La función zmq_has() devolverá 1 si se proporciona la capacidad especificada. De lo contrario, devolverá 0.
