Paquete: zeromq

Licencias: MPL2

ZMQ_PROXY_STEERABLE(3) Manual 0MQ ZMQ_PROXY_STEERABLE(3)

NOMBRE

zmq_proxy_steerable - proxy 0MQ integrado con flujo de control

SINOPSIS

int zmq_proxy_steerable (const void *frontend, const void *backend, const void *capture, const void *control);

DESCRIPCIÓN

La función zmq_proxy_steerable() es una variante de la función zmq_proxy(). Acepta un cuarto socket de control. Cuando el socket control es NULL, las dos funciones operan de manera idéntica.

Cuando se proporciona un socket control de tipo REP a la función proxy, la aplicación puede enviar comandos al proxy. Los siguientes comandos son compatibles.

PAUSE

El proxy dejará de transferir mensajes entre sus endpoints.

RESUME

El proxy reanudará la transferencia de mensajes entre sus endpoints.

TERMINATE

La función proxy finalizará con un valor de retorno de 0.

STATISTICS

El comportamiento del proxy permanecerá sin cambios y responderá con un conjunto de valores resumen simples de los mensajes que se han enviado a través del proxy, como se describe a continuación.

Hay ocho valores de estadísticas, cada uno de tamaño uint64_t en el mensaje de varias partes de respuesta al comando STATISTICS. Estos son:

•número de mensajes recibidos por el socket frontend
•número de bytes recibidos por el socket frontend
•número de mensajes enviados por el socket frontend
•número de bytes enviados por el socket frontend
•número de mensajes recibidos por el socket backend
•número de bytes recibidos por el socket backend
•número de mensajes enviados por el socket backend
•número de bytes enviados por el socket backend

VALOR DE RETORNO

La función zmq_proxy_steerable() devuelve 0 si se recibe TERMINATE en su socket de control. De lo contrario, devuelve -1 y errno se establece en ETERM o EINTR (el contexto 0MQ asociado con cualquiera de los sockets especificados fue terminado) o EFAULT (el frontend o backend proporcionado fue inválido).

EJEMPLO

Crear una función para ejecutar el proxy.

// Crear los sockets frontend y backend a proxificar
void *frontend = zmq_socket (context, ZMQ_ROUTER);
void *backend = zmq_socket (context, ZMQ_DEALER);
// Crear el socket de control del proxy
void *control = zmq_socket (context, ZMQ_REP);
// Vincular los sockets.
zmq_bind (frontend, "tcp://*:5555");
zmq_bind (backend, "tcp://*:5556");
zmq_bind (control, "tcp://*:5557");
zmq_proxy_steerable(frontend, backend, NULL, control);

Código en otro hilo/proceso para dirigir el proxy..

void *control = zmq_socket (context, ZMQ_REQ);
zmq_connect (control, "tcp://*:5557");
zmq_msg_t msg;
zmq_send (control, "PAUSE", 5, 0);
zmq_msg_recv (&msg, control, 0));
zmq_send (control, "RESUME", 6, 0);
zmq_msg_recv (&msg, control, 0));
zmq_send (control, "STATISTICS", 10, 0);
while (1) {
    zmq_msg_recv (&msg, control, 0));
    printf(" %lu", *(uint64_t *)zmq_msg_data (&msg));
    if (!zmq_msg_get (&msg, ZMQ_MORE))
        break;
}
printf("\n");
zmq_send (control, "TERMINATE", 9, 0);
zmq_msg_recv (&msg, control, 0));
zmq_close(frontend);
zmq_close(backend);
zmq_close(control);
