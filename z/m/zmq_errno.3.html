NOMBRE

zmq_errno - recuperar el valor de errno para el hilo llamante

SINOPSIS

int zmq_errno (void);

DESCRIPCIÓN

La función zmq_errno() recuperará el valor de la variable errno para el hilo llamante.

La función zmq_errno() se proporciona para ayudar a los usuarios en sistemas no POSIX que experimentan problemas para recuperar el valor correcto de errno directamente. Específicamente, los usuarios en sistemas Win32 cuya aplicación esté utilizando una biblioteca en tiempo de ejecución C diferente de la biblioteca en tiempo de ejecución C utilizada por 0MQ necesitarán usar zmq_errno() para un funcionamiento correcto.


Importante

Los usuarios que no experimenten problemas para recuperar el valor correcto de errno no deben usar esta función y, en su lugar, deben acceder directamente a la variable errno.

VALOR DE RETORNO

La función zmq_errno() devolverá el valor de la variable errno para el hilo llamante.

ERRORES

No se definen errores.
