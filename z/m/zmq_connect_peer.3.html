zmq_connect_peer(3)

Paquete: zeromq

Licencias: MPL2

ZMQ_CONNECT_PEER(3) Manual de 0MQ ZMQ_CONNECT_PEER(3)

NOMBRE

zmq_connect_peer - crea una conexión saliente desde un socket y devuelve el ID de enrutamiento de la conexión de forma segura para hilos y atómica.

SINOPSIS

uint32_t zmq_connect_peer (void *socket, const char *endpoint);

DESCRIPCIÓN

La función zmq_connect_peer() conecta un socket ZMQ_PEER a un endpoint y luego devuelve el routing_id del endpoint.

El endpoint es una cadena que consiste en un transporte:// seguido de una dirección. El transporte especifica el protocolo subyacente a utilizar. La dirección especifica la dirección específica del transporte a la que conectarse.

La función solo se admite en el tipo de socket ZMQ_PEER y, de lo contrario, devolvería 0 con errno establecido en ENOTSUP.

zmq_connect_peer() admite los siguientes transportes:

tcp

transporte de unidifusión utilizando TCP, véase zmq_tcp(7)

ipc

transporte local de comunicación entre procesos, véase zmq_ipc(7)

inproc

transporte local de comunicación dentro de un proceso (entre hilos), véase zmq_inproc(7)

ws

transporte de unidifusión utilizando WebSockets, véase zmq_ws(7)

wss

transporte de unidifusión utilizando WebSockets sobre TLS, véase zmq_wss(7)

VALOR DE RETORNO

La función zmq_connect_peer() devuelve el routing_id del par si tiene éxito. De lo contrario, devuelve 0 y establece errno en uno de los valores definidos a continuación.

ERRORES

EINVAL

El endpoint proporcionado es inválido.

EPROTONOSUPPORT

El protocolo de transporte solicitado no es compatible con ZMQ_PEER.

ENOCOMPATPROTO

El protocolo de transporte solicitado no es compatible con el tipo de socket.

ETERM

El contexto 0MQ context asociado con el socket especificado fue terminado.

ENOTSOCK

El socket proporcionado era inválido.

EMTHREAD

No hay hilos de E/S disponibles para realizar la tarea.

ENOTSUP

El socket no es de tipo ZMQ_PEER.

EFAULT

La opción ZMQ_IMMEDIATE está establecida en el socket.

EJEMPLO

Conectar un socket de par a un transporte TCP y enviar un mensaje.

/* Crear un socket ZMQ_SUB */
void *socket = zmq_socket (context, ZMQ_PEER);
assert (socket);
/* Conectarlo al servidor host001, puerto 5555 usando un transporte TCP */
uint32_t routing_id = zmq_connect (socket, "tcp://server001:5555");
assert (routing_id == 0);
/* Envío de un mensaje al par */
zmq_msg_t msg;
int rc = zmq_msg_init_data (&msg, "HOLA", 5, NULL, NULL);
assert (rc == 0);
rc = zmq_msg_set_routing_id (&msg, routing_id);
assert (rc == 0);
rc = zmq_msg_send (&msg, socket, 0);
assert (rc == 5);
rc = zmq_msg_close (&msg);
assert (rc == 0);
