NOMBRE

zmq_bind - aceptar conexiones entrantes en un socket

SINTAXIS

int zmq_bind (void *socket, const char *endpoint);

DESCRIPCIÓN

La función zmq_bind() enlaza el socket a un endpoint local y luego acepta conexiones entrantes en ese endpoint.

El endpoint es una cadena que consiste en un transporte:// seguido de una dirección. El transporte especifica el protocolo subyacente a utilizar. La dirección especifica la dirección específica del transporte a la que enlazar.

0MQ proporciona los siguientes transportes:

tcp

transporte unicast usando TCP, ver zmq_tcp(7)

ipc

transporte local de comunicación entre procesos, ver zmq_ipc(7)

inproc

transporte local de comunicación dentro del proceso (entre hilos), ver zmq_inproc(7)

pgm, epgm

transporte multicast fiable usando PGM, ver zmq_pgm(7)

vmci

interfaz de comunicación de máquina virtual (VMCI), ver zmq_vmci(7)

udp

unicast y multicast no fiable usando UDP, ver zmq_udp(7)

Todos los tipos de socket de 0MQ excepto ZMQ_PAIR y ZMQ_CHANNEL soportan semánticas uno-a-muchos y muchos-a-uno. Las semánticas precisas dependen del tipo de socket y se definen en zmq_socket(3).

Los transportes ipc, tcp, vmci y udp aceptan direcciones comodín: ver zmq_ipc(7), zmq_tcp(7), zmq_vmci(7) y zmq_udp(7) para más detalles.


Nota

la sintaxis de la dirección puede ser diferente para zmq_bind() y zmq_connect(), especialmente para los transportes tcp, pgm y epgm.


Nota

después de un zmq_bind(), el socket entra en un estado mudo hasta que se establezca al menos una conexión entrante o saliente, momento en el cual el socket entra en un estado listo. En el estado mudo, el socket bloquea o descarta mensajes según el tipo de socket, como se define en zmq_socket(3). Por el contrario, después de un libzmq:zmq_connect[3], el socket entra en el estado listo.

VALOR DE RETORNO

La función zmq_bind() devuelve cero si tiene éxito. De lo contrario, devuelve -1 y establece errno a uno de los valores definidos a continuación.

ERRORES

EINVAL

El endpoint proporcionado es inválido.

EPROTONOSUPPORT

El protocolo de transporte solicitado no es soportado.

ENOCOMPATPROTO

El protocolo de transporte solicitado no es compatible con el tipo de socket.

EADDRINUSE

La dirección solicitada ya está en uso.

EADDRNOTAVAIL

La dirección solicitada no era local.

ENODEV

La dirección solicitada especifica una interfaz inexistente.

ETERM

El contexto 0MQ asociado con el socket especificado fue terminado.

ENOTSOCK

El socket proporcionado era inválido.

EMTHREAD

No hay ningún hilo de E/S disponible para realizar la tarea.

EJEMPLO

Enlazar un socket publisher a un transporte in-process y a uno TCP.

/* Crear un socket ZMQ_PUB */
void *socket = zmq_socket (context, ZMQ_PUB);
assert (socket);
/* Enlazarlo a un transporte in-process con la dirección 'my_publisher' */
int rc = zmq_bind (socket, "inproc://my_publisher");
assert (rc == 0);
/* Enlazarlo a un transporte TCP en el puerto 5555 de la interfaz 'eth0' */
rc = zmq_bind (socket, "tcp://eth0:5555");
assert (rc == 0);
