NOMBRE

zmq_timers - funciones auxiliares para callbacks de temporizadores multiplataforma

SINOPSIS

typedef void(zmq_timer_fn) (int id_temporizador, void *arg);

void *zmq_timers_new (void);

int zmq_timers_destroy (void *temporizadores_p);*

int zmq_timers_add (void *temporizadores, size_t intervalo, zmq_timer_fn manejador, void *arg);

int zmq_timers_cancel (void *temporizadores, int id_temporizador);

int zmq_timers_set_interval (void *temporizadores, int id_temporizador, size_t intervalo);

int zmq_timers_reset (void *temporizadores, int id_temporizador);

long zmq_timers_timeout (void *temporizadores);

int zmq_timers_execute (void *temporizadores);

DESCRIPCIÓN

Las funciones zmq_timers*_ proporcionan acceso multiplataforma a callbacks de temporizadores. Una vez que un temporizador ha sido registrado, se repetirá en el intervalo especificado hasta que sea cancelado manualmente. Para ejecutar los callbacks, se debe llamar a zmq_timers_execute.

zmq_timers_new y zmq_timers_destroy gestionan la vida útil de una instancia de temporizador. zmq_timers_new crea y devuelve una nueva instancia de temporizador, mientras que zmq_timers_destroy la destruye. Se debe pasar un puntero a un temporizador válido como argumento temporizadores_p de zmq_timers_destroy. En particular, zmq_timers_destroy no se puede llamar varias veces para la misma instancia de temporizador. zmq_timers_destroy establece el puntero pasado a NULL en caso de una ejecución exitosa.

zmq_timers_add y zmq_timers_cancel gestionan los temporizadores registrados.

zmq_timers_add registra un nuevo temporizador con una instancia dada. temporizadores debe apuntar a un objeto temporizadores válido. El parámetro intervalo especifica la expiración del temporizador en milisegundos. manejador y arg especifican el callback que se invocará en la expiración y el parámetro opcional que se pasará. El callback debe ser una función válida que implemente el prototipo zmq_timer_fn. Se devolverá un ID que se puede utilizar para modificar o cancelar el temporizador.

zmq_timers_cancel cancelará el temporizador asociado con id_temporizador de la instancia temporizadores.

zmq_timers_set_interval establecerá la expiración del temporizador asociado con id_temporizador de la instancia temporizadores a intervalo milisegundos en el futuro.

zmq_timers_reset reiniciará el temporizador asociado con id_temporizador de la instancia temporizadores.

zmq_timers_timeout devolverá el tiempo restante en milisegundos hasta que expire el próximo temporizador registrado con temporizadores.

zmq_timers_execute ejecutará los callbacks de todos los temporizadores expirados de la instancia temporizadores.

SEGURIDAD DE HILOS

Como la mayoría de los otros objetos 0MQ, los temporizadores no son seguros para hilos. Todas las operaciones deben llamarse desde el mismo hilo. De lo contrario, el comportamiento es indefinido.

VALOR DE RETORNO

zmq_timers_new siempre devuelve un puntero válido a un poll.

Todas las funciones que devuelven un int, devuelven -1 en caso de fallo. En ese caso, zmq_errno() puede usarse para consultar el tipo de error como se describe a continuación.

zmq_timers_timeout devuelve el tiempo restante en milisegundos hasta que expire el próximo temporizador registrado con temporizadores, o -1 si no quedan temporizadores.

Todas las demás funciones devuelven 0 en caso de ejecución exitosa.

ERRORES

En zmq_timers_destroy, zmq_poller_cancel, zmq_timers_set_interval, zmq_timers_reset, zmq_timers_timeout y zmq_timers_execute: EFAULT:: temporizadores no apuntaba a un temporizador válido. Tenga en cuenta que pasar un puntero inválido (por ejemplo, un puntero a memoria desasignada) puede causar un comportamiento indefinido (por ejemplo, una violación de acceso).

En zmq_timers_add: EFAULT:: temporizadores no apuntaba a un temporizador válido o manejador no apuntaba a una función válida.

En zmq_poller_cancel, zmq_timers_set_interval y zmq_timers_timeout: EINVAL:: id_temporizador no existía o ya había sido cancelado.

EJEMPLO

Añade un temporizador con un callback simple que cambia un booleano..

    void manejador (int id_temporizador_, void *arg_)
    {
        (void) id_temporizador_; //  Evita advertencias del compilador 'sin usar'
        *((bool *) arg_) = true;
    }
    ...
    void *temporizadores = zmq_timers_new ();
    assert (temporizadores);
    bool temporizador_invocado = false;
    const unsigned long tiempo_total = 100;
    int id_temporizador =
      zmq_timers_add (temporizadores, tiempo_total, manejador, &temporizador_invocado);
    assert (id_temporizador);
    //  El temporizador aún no debería haber sido invocado
    int rc = zmq_timers_execute (temporizadores);
    assert (rc == 0);
    //  Espera la mitad del tiempo y vuelve a comprobar
    long tiempo_espera = zmq_timers_timeout (temporizadores);
    assert (rc != -1);
    msleep (tiempo_espera / 2);
    rc = zmq_timers_execute (temporizadores);
    assert (rc == 0);
    // Espera hasta el final
    rc = msleep (zmq_timers_timeout (temporizadores));
    assert (rc == 0);
    assert (temporizador_invocado);
    rc = zmq_timers_destroy (&temporizadores);
    assert (rc == 0);
