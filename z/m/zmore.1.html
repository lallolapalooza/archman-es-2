ZMORE(1) Manual de comandos generales ZMORE(1)

NOMBRE

zmore - filtro de examen de archivos para visualización CRT de texto comprimido

SINOPSIS

zmore [ nombre ... ]

DESCRIPCIÓN

El comando zmore es un filtro que permite examinar archivos comprimidos o de texto plano pantalla por pantalla en un terminal de pantalla suave. El comando zmore funciona en archivos comprimidos con compress, pack o gzip, y también en archivos sin comprimir. Si un archivo no existe, zmore busca un archivo con el mismo nombre al que se le ha añadido el sufijo .gz, .z o .Z.

El comando zmore normalmente se detiene después de cada pantalla, imprimiendo --More-- en la parte inferior de la pantalla. Si el usuario luego presiona una tecla de retorno, se muestra una línea más. Si el usuario presiona una barra espaciadora, se muestra otra pantalla. Otras posibilidades se enumeran más adelante.

El comando zmore busca en el archivo /etc/termcap para determinar las características del terminal y el tamaño de ventana predeterminado. En un terminal capaz de mostrar 24 líneas, el tamaño de ventana predeterminado es de 22 líneas. Para usar un paginador distinto del predeterminado more, establezca la variable de entorno PAGER al nombre del programa deseado, como less.

Otras secuencias que se pueden teclear cuando zmore se detiene, y sus efectos, son las siguientes (i es un argumento entero opcional, con valor predeterminado 1):

i<espacio>
muestra i líneas más, (o otra pantalla si no se proporciona argumento)
^D
muestra 11 líneas más (un "scroll"). Si se proporciona i, entonces el tamaño del scroll se establece en i.
d
igual que ^D (control-D)
iz
igual que presionar una barra espaciadora excepto que i, si está presente, se convierte en el nuevo tamaño de ventana.
is
salta i líneas e imprime una pantalla de líneas
if
salta i pantallas e imprime una pantalla de líneas
q o Q
Salir.
=
Muestra el número de línea actual.
i/exp
busca la i-ésima ocurrencia de la expresión regular exp. Los caracteres de borrado y eliminación del usuario pueden ser utilizados para editar la expresión regular. Borrar hacia atrás más allá de la primera columna cancela el comando de búsqueda.
in
busca la i-ésima ocurrencia de la última expresión regular introducida.
!comando
invoca un shell con comando. El carácter `!' en "comando" se reemplaza con el comando de shell anterior. La secuencia "\!" se reemplaza por "!".
:q o :Q
Salir (igual que q o Q).
.
(punto) repite el comando anterior.

Los comandos surten efecto inmediatamente, es decir, no es necesario presionar una tecla de retorno. Hasta el momento en que se ingresa el propio carácter de comando, el usuario puede presionar el carácter de eliminación de línea para cancelar el argumento numérico que se está formando. Además, el usuario puede presionar el carácter de borrado para redisplayar el mensaje --More--.

En cualquier momento en que la salida se esté enviando al terminal, el usuario puede presionar la tecla de salir (normalmente control-\). El comando zmore dejará de enviar salida y mostrará el mensaje de aviso --More--. El usuario puede entonces ingresar uno de los comandos anteriores de la manera normal. Desafortunadamente, se pierde algo de salida cuando se hace esto, debido al hecho de que cualquier carácter esperando en la cola de salida del terminal se vacía cuando ocurre la señal de salida.

El terminal se configura en modo noecho por este programa para que la salida pueda ser continua. Lo que escriba, por lo tanto, no se mostrará en su terminal, excepto para los comandos / y !.

Si la salida estándar no es un teletipo, entonces zmore actúa igual que zcat, excepto que se imprime un encabezado antes de cada archivo si hay más de un archivo.
