DESCRIPTION

The `zchk*` routines are called by the LAPACK test programs to check the correctness of the block matrix multiplication routines.

These routines perform tests on a subset of the block matrix multiplication routines.

The specific routines being checked by each `zchk*` routine depend on the version of LAPACK. The interfaces provided here reflect a common set of parameters but may not be exhaustive for all LAPACK versions.

For detailed information on the arguments and the specific block matrix multiplication routines checked by each `zchk*` routine, refer to the LAPACK User's Guide or the source code of the specific LAPACK version being used.

sname
Character*7. The name of the routine being tested.

thresh
Double precision. The threshold for reporting errors.

Integer. The unit number to output error messages to.
ntra
Integer. The unit number to output tracing information to.
