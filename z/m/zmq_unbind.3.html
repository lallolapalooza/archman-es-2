NOMBRE

zmq_unbind - Dejar de aceptar conexiones en un socket

SINOPSIS

int zmq_unbind (void *socket, const char *endpoint);

DESCRIPCIÓN

La función zmq_unbind() desvincula un socket especificado por el argumento socket del endpoint especificado por el argumento endpoint.

Además, la cola de mensajes entrantes asociada con el endpoint se descartará. Esto significa que después de desvincular un endpoint, es posible recibir mensajes originarios del mismo endpoint si ya estaban presentes en la cola de mensajes entrantes antes de desvincular.

El argumento endpoint es como se describe en zmq_bind(3)

Desvincular dirección wildcard de un socket

Cuando se utilizó el endpoint comodín * (descrito en zmq_tcp(7), zmq_ipc(7), zmq_udp(7) y zmq_vmci(7)) en zmq_bind(), el llamador debe usar el endpoint real obtenido de la opción de socket ZMQ_LAST_ENDPOINT para desvincular ese endpoint de un socket.

VALOR DE RETORNO

La función zmq_unbind() devolverá cero si tiene éxito. De lo contrario, devolverá -1 y establecerá errno a uno de los valores definidos a continuación.

ERRORES

EINVAL

El endpoint proporcionado es inválido.

ETERM

El contexto 0MQ asociado con el socket especificado fue terminado.

ENOTSOCK

El socket proporcionado era inválido.

ENOENT

El endpoint proporcionado no estaba previamente vinculado.

EJEMPLOS

Desvincular un socket suscriptor de un transporte TCP.

/* Crear un socket ZMQ_SUB */
void *socket = zmq_socket (context, ZMQ_SUB);
assert (socket);
/* Conectarlo al servidor host server001, puerto 5555 usando un transporte TCP */
rc = zmq_bind (socket, "tcp://127.0.0.1:5555");
assert (rc == 0);
/* Desconectarse del endpoint previamente conectado */
rc = zmq_unbind (socket, "tcp://127.0.0.1:5555");
assert (rc == 0);

Desvincular un socket vinculado con wildcard *.

/* Crear un socket ZMQ_SUB */
void *socket = zmq_socket (context, ZMQ_SUB);
assert (socket);
/* Vincularlo al puerto efímero asignado por el sistema usando un transporte TCP */
rc = zmq_bind (socket, "tcp://127.0.0.1:*");
assert (rc == 0);
/* Obtener el endpoint real */
const size_t buf_size = 32;
char buf[buf_size];
rc = zmq_getsockopt (socket, ZMQ_LAST_ENDPOINT, buf, (size_t *)&buf_size);
assert (rc == 0);
/* Desvincular el socket por endpoint real */
rc = zmq_unbind (socket, buf);
assert (rc == 0);

NOTA

Tenga en cuenta que aunque la implementación es similar a zmq_disconnect(), las semánticas son diferentes y las dos funciones no deben usarse indistintamente. Los sockets vinculados deben desvincularse y los sockets conectados deben desconectarse.
