NOMBRE

zmq_msg_set_routing_id - establecer la propiedad de ID de enrutamiento en el mensaje

SINOPSIS

int zmq_msg_set_routing_id (zmq_msg_t *mensaje, uint32_t routing_id);

DESCRIPCIÓN

La función zmq_msg_set_routing_id() establece el routing_id especificado en el mensaje al que apunta el argumento mensaje. El routing_id debe ser mayor que cero. Para obtener un ID de enrutamiento válido, debes recibir un mensaje de un socket ZMQ_SERVER y utilizar el método libzmq:zmq_msg_routing_id. Los ID de enrutamiento son transitorios.

VALOR DE RETORNO

La función zmq_msg_set_routing_id() devolverá cero si tiene éxito. De lo contrario, devolverá -1 y establecerá errno en uno de los valores definidos a continuación.

ERRORES

EINVAL

El routing_id proporcionado es cero.
