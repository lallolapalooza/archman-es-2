ZMQ_SOCKET_MONITOR(3) Manual de 0MQ ZMQ_SOCKET_MONITOR(3)

NOMBRE

zmq_socket_monitor - monitorizar eventos de socket

SINOPSIS

int zmq_socket_monitor (void *socket, char *endpoint, int events);

DESCRIPCIÓN

El método zmq_socket_monitor() permite a un hilo de la aplicación rastrear eventos de socket (como conexiones) en un socket ZeroMQ. Cada llamada a este método crea un socket ZMQ_PAIR y lo enlaza al endpoint inproc:// especificado. Para recopilar los eventos del socket, debes crear tu propio socket ZMQ_PAIR y conectarlo al endpoint.

Tenga en cuenta que también existe una función DRAFT zmq_socket_monitor_versioned(3), que permite suscribirse a eventos que proporcionan más información. Llamar a zmq_socket_monitor es equivalente a llamar a zmq_socket_monitor_versioned con el parámetro event_version establecido en 1, con la excepción de los casos de error.

El argumento events es una máscara de bits de los eventos de socket que desea monitorizar, consulte Eventos soportados a continuación. Para monitorizar todos los eventos, use el valor de evento ZMQ_EVENT_ALL. NOTA: a medida que se añaden nuevos eventos, el valor de "catch-all" comenzará a devolverlos. Una aplicación que dependa de una secuencia de eventos estricta y fija no debe usar ZMQ_EVENT_ALL para garantizar la compatibilidad con versiones futuras.

Cada evento se envía como dos frames. El primer frame contiene un número de evento (16 bits) y un valor de evento (32 bits) que proporciona datos adicionales según el número de evento. El segundo frame contiene una cadena que especifica el endpoint afectado.

El método _zmq_socket_monitor()_ solo soporta transportes orientados a
conexión, es decir, TCP, IPC y TIPC.

EVENTOS SOPORTADOS

ZMQ_EVENT_CONNECTED

El socket se ha conectado con éxito a un par remoto. El valor del evento es el descriptor de archivo (FD) del socket de red subyacente. Advertencia: no hay garantía de que el FD siga siendo válido cuando su código reciba este evento.

ZMQ_EVENT_CONNECT_DELAYED

Una solicitud de conexión en el socket está pendiente. El valor del evento no está especificado.

ZMQ_EVENT_CONNECT_RETRIED

Una solicitud de conexión falló y ahora se está reintentando. El valor del evento es el intervalo de reconexión en milisegundos. Tenga en cuenta que el intervalo de reconexión se recalcula en cada reintento.

ZMQ_EVENT_LISTENING

El socket se enlazó con éxito a una interfaz de red. El valor del evento es el FD del socket de red subyacente. Advertencia: no hay garantía de que el FD siga siendo válido cuando su código reciba este evento.

ZMQ_EVENT_BIND_FAILED

El socket no pudo enlazarse a una interfaz dada. El valor del evento es el errno generado por la llamada al sistema bind.

ZMQ_EVENT_ACCEPTED

El socket ha aceptado una conexión de un par remoto. El valor del evento es el FD del socket de red subyacente. Advertencia: no hay garantía de que el FD siga siendo válido cuando su código reciba este evento.

ZMQ_EVENT_ACCEPT_FAILED

El socket ha rechazado una conexión de un par remoto. El valor del evento es el errno generado por la llamada al sistema accept.

ZMQ_EVENT_CLOSED

El socket se cerró. El valor del evento es el FD del socket de red (ahora cerrado).

ZMQ_EVENT_CLOSE_FAILED

El cierre del socket falló. El valor del evento es el errno devuelto por la llamada al sistema. Tenga en cuenta que este evento solo ocurre en transportes IPC.

ZMQ_EVENT_DISCONNECTED

El socket se desconectó inesperadamente. El valor del evento es el FD del socket de red subyacente. Advertencia: este socket se cerrará.

ZMQ_EVENT_MONITOR_STOPPED

La monitorización en este socket ha finalizado.

ZMQ_EVENT_HANDSHAKE_FAILED_NO_DETAIL

Error no especificado durante el handshake. El valor del evento es un errno.

ZMQ_EVENT_HANDSHAKE_SUCCEEDED

El handshake del mecanismo de seguridad ZMTP tuvo éxito. El valor del evento no está especificado.

ZMQ_EVENT_HANDSHAKE_FAILED_PROTOCOL

El handshake del mecanismo de seguridad ZMTP falló debido a algún error de protocolo del mecanismo, ya sea entre los pares del mecanismo ZMTP, o entre el servidor del mecanismo y el manejador ZAP. Esto indica un error de configuración o implementación en cualquiera de los pares o en el manejador ZAP. El valor del evento es uno de los valores ZMQ_PROTOCOL_ERROR_*: ZMQ_PROTOCOL_ERROR_ZMTP_UNSPECIFIED ZMQ_PROTOCOL_ERROR_ZMTP_UNEXPECTED_COMMAND ZMQ_PROTOCOL_ERROR_ZMTP_INVALID_SEQUENCE ZMQ_PROTOCOL_ERROR_ZMTP_KEY_EXCHANGE ZMQ_PROTOCOL_ERROR_ZMTP_MALFORMED_COMMAND_UNSPECIFIED ZMQ_PROTOCOL_ERROR_ZMTP_MALFORMED_COMMAND_MESSAGE ZMQ_PROTOCOL_ERROR_ZMTP_MALFORMED_COMMAND_HELLO ZMQ_PROTOCOL_ERROR_ZMTP_MALFORMED_COMMAND_INITIATE ZMQ_PROTOCOL_ERROR_ZMTP_MALFORMED_COMMAND_ERROR ZMQ_PROTOCOL_ERROR_ZMTP_MALFORMED_COMMAND_READY ZMQ_PROTOCOL_ERROR_ZMTP_MALFORMED_COMMAND_WELCOME ZMQ_PROTOCOL_ERROR_ZMTP_INVALID_METADATA ZMQ_PROTOCOL_ERROR_ZMTP_CRYPTOGRAPHIC ZMQ_PROTOCOL_ERROR_ZMTP_MECHANISM_MISMATCH ZMQ_PROTOCOL_ERROR_ZAP_UNSPECIFIED ZMQ_PROTOCOL_ERROR_ZAP_MALFORMED_REPLY ZMQ_PROTOCOL_ERROR_ZAP_BAD_REQUEST_ID ZMQ_PROTOCOL_ERROR_ZAP_BAD_VERSION ZMQ_PROTOCOL_ERROR_ZAP_INVALID_STATUS_CODE ZMQ_PROTOCOL_ERROR_ZAP_INVALID_METADATA

ZMQ_EVENT_HANDSHAKE_FAILED_AUTH

El handshake del mecanismo de seguridad ZMTP falló debido a un fallo de autenticación. El valor del evento es el código de estado devuelto por el manejador ZAP (es decir, 300, 400 o 500).

VALOR DE RETORNO

La función zmq_socket_monitor() devuelve un valor de 0 o mayor si tiene éxito. De lo contrario, devuelve -1 y establece errno a uno de los valores definidos a continuación.

ERRORES

ETERM

El contexto context de 0MQ asociado con el socket especificado fue terminado.

EPROTONOSUPPORT

El protocolo de transporte solicitado no es compatible. Se requieren sockets de monitor para usar el transporte inproc://.

EINVAL

El endpoint proporcionado es inválido.

zmq_socket_monitor(3) — 0MQ 4.3.5

NAME

zmq_socket_monitor — set up a socket monitor

SYNOPSIS

#include <zmq.h>
int zmq_socket_monitor(zmq::socket_t *socket, const char *addr, int events);

DESCRIPTION

The zmq_socket_monitor function shall set up a monitor on the specified socket. The monitor shall send event messages to the specified addr. The addr must be an endpoint using the inproc transport. The monitor shall send events specified by events. This functionality is only supported for inproc sockets.

The events argument is a bitmask of events to monitor. The full list of events is defined in zmq.h and is detailed in the SUPPORTED EVENTS section.

When an event occurs on the monitored socket, the monitor shall send a multi-part message to the specified addr. The first part of the message contains the event code and event value. The second part contains the event address.

The first part is a 16-bit event code followed by a 32-bit event value.

uint16_t event;
uint32_t value;
memcpy(&event, zmq_msg_data(&msg), sizeof(event));
memcpy(&value, (char*)zmq_msg_data(&msg) + sizeof(event), sizeof(value));

The second part is the event address, as a string.

char *address = (char*)zmq_msg_data(&msg);
size_t size = zmq_msg_size(&msg);

The monitor is implicitly enabled when zmq_socket_monitor is called. It is stopped when the monitored socket is closed or zmq_ctx_term is called.

The monitor socket is of type ZMQ_PAIR. For each monitored socket you must create a ZMQ_PAIR socket and zmq_connect to the addr you specified in zmq_socket_monitor.

SUPPORTED EVENTS

ZMQ_EVENT_CONNECTED
The socket successfully connected to a peer.
ZMQ_EVENT_CONNECT_DELAYED
The socket is attempting to connect to a peer; this event is sent if the connection attempt is delayed.
ZMQ_EVENT_ACCEPTED
A peer successfully connected to the socket.
ZMQ_EVENT_ACCEPT_FAILED
A connection attempt by a peer failed.
ZMQ_EVENT_CLOSED
The socket was closed.
ZMQ_EVENT_CLOSE_FAILED
A requested socket close operation failed.
ZMQ_EVENT_LISTENING
The socket is successfully listening for incoming connections.
ZMQ_EVENT_ERROR
An error occurred on the socket.
ZMQ_EVENT_HANDSHAKE_SUCCEEDED
The ZMTP handshake was successfully completed.
ZMQ_EVENT_HANDSHAKE_FAILED
The ZMTP handshake failed.
ZMQ_EVENT_MONITOR_STOPPED
The monitor has stopped accepting events.
ZMQ_EVENT_ALL
All events.

RETURN VALUE

The zmq_socket_monitor function shall return zero on success and -1 on failure. If -1 is returned, the errno variable shall be set to an appropriate value.

ERRORS

EINVAL An invalid argument was received.

ENOTSUP The monitor functionality is not supported for the specified address type.

ETERM The ZeroMQ context was terminated.

EXAMPLE

The following example sets up a monitor on a ZMQ_DEALER socket, connects to it, performs a basic ping, and then collects and checks the monitor events.

#include <zmq.h>
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <assert.h>
#include <errno.h>

// Helper function to close sockets with zero linger
static void close_zero_linger (void *socket) {
    int linger = 0;
    int rc = zmq_setsockopt (socket, ZMQ_LINGER, &linger, sizeof (linger));
    assert (rc == 0);
    zmq_close (socket);
}

// Helper function to read a monitor event
static int get_monitor_event(void *monitor, uint32_t *value, char **address) {
    zmq_msg_t msg;
    // First frame in message contains event code and value
    zmq_msg_init(&msg);
    if (zmq_msg_recv(&msg, monitor, 0) == -1)
        return -1;              // Interrupted, presumably
    assert(zmq_msg_more(&msg));
    uint8_t *data = (uint8_t *) zmq_msg_data(&msg);
    uint16_t event = *(uint16_t *) (data);
    if (value)
        *value = *(uint32_t *) (data + 2);
    // Second frame in message contains event address
    zmq_msg_init(&msg);
    if (zmq_msg_recv(&msg, monitor, 0) == -1)
        return -1;              // Interrupted, presumably
    assert(!zmq_msg_more(&msg));
    if (address) {
        uint8_t *data = (uint8_t *) zmq_msg_data(&msg);
        size_t size = zmq_msg_size(&msg);
        *address = (char *) malloc (size + 1);
        memcpy(*address, data, size);
        (*address)[size] = 0;
    }
    return event;
}

// Simple ping-pong function between two sockets
static void bounce(void *client, void *server) {
    zmq_msg_t msg;
    zmq_msg_init(&msg);
    assert(zmq_msg_send(&msg, client, ZMQ_SNDMORE) == 2);
    zmq_msg_close(&msg);

    zmq_msg_init(&msg);
    assert(zmq_msg_recv(&msg, server, 0) == 0);
    assert(zmq_msg_send(&msg, server, ZMQ_SNDMORE) == 2);
    zmq_msg_close(&msg);

    zmq_msg_init(&msg);
    assert(zmq_msg_recv(&msg, client, 0) == 0);
    zmq_msg_close(&msg);
}

int main (void)
{
    void *ctx = zmq_ctx_new ();
    assert (ctx);
    // We'll monitor these two sockets
    void *client = zmq_socket (ctx, ZMQ_DEALER);
    assert (client);
    void *server = zmq_socket (ctx, ZMQ_DEALER);
    assert (server);
    // Socket monitoring only works over inproc://
    int rc = zmq_socket_monitor (client, "tcp://127.0.0.1:9999", 0);
    assert (rc == -1);
    assert (zmq_errno () == EPROTONOSUPPORT);
    // Monitor all events on client and server sockets
    rc = zmq_socket_monitor (client, "inproc://monitor-client", ZMQ_EVENT_ALL);
    assert (rc == 0);
    rc = zmq_socket_monitor (server, "inproc://monitor-server", ZMQ_EVENT_ALL);
    assert (rc == 0);
    // Create two sockets for collecting monitor events
    void *client_mon = zmq_socket (ctx, ZMQ_PAIR);
    assert (client_mon);
    void *server_mon = zmq_socket (ctx, ZMQ_PAIR);
    assert (server_mon);
    // Connect these to the inproc endpoints so they'll get events
    rc = zmq_connect (client_mon, "inproc://monitor-client");
    assert (rc == 0);
    rc = zmq_connect (server_mon, "inproc://monitor-server");
    assert (rc == 0);
    // Now do a basic ping test
    rc = zmq_bind (server, "tcp://127.0.0.1:9998");
    assert (rc == 0);
    rc = zmq_connect (client, "tcp://127.0.0.1:9998");
    assert (rc == 0);
    bounce (client, server);
    // Close client and server
    close_zero_linger (client);
    close_zero_linger (server);
    // Now collect and check events from both sockets
    int event = get_monitor_event (client_mon, NULL, NULL);
    if (event == ZMQ_EVENT_CONNECT_DELAYED)
        event = get_monitor_event (client_mon, NULL, NULL);
    assert (event == ZMQ_EVENT_CONNECTED);
    event = get_monitor_event (client_mon, NULL, NULL);
    assert (event == ZMQ_EVENT_HANDSHAKE_SUCCEEDED);
    event = get_monitor_event (client_mon, NULL, NULL);
    assert (event == ZMQ_EVENT_MONITOR_STOPPED);
    // This is the flow of server events
    event = get_monitor_event (server_mon, NULL, NULL);
    assert (event == ZMQ_EVENT_LISTENING);
    event = get_monitor_event (server_mon, NULL, NULL);
    assert (event == ZMQ_EVENT_ACCEPTED);
    event = get_monitor_event (server_mon, NULL, NULL);
    assert (event == ZMQ_EVENT_HANDSHAKE_SUCCEEDED);
    event = get_monitor_event (server_mon, NULL, NULL);
    assert (event == ZMQ_EVENT_CLOSED);
    event = get_monitor_event (server_mon, NULL, NULL);
    assert (event == ZMQ_EVENT_MONITOR_STOPPED);
    // Close down the sockets
    close_zero_linger (client_mon);
    close_zero_linger (server_mon);
    zmq_ctx_term (ctx);
    return 0 ;
}
