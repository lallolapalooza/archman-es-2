zmq_poll(3)

Paquete: zeromq

Licencias: MPL2

ZMQ_POLL(3) Manual de 0MQ ZMQ_POLL(3)

NOMBRE

zmq_poll - multiplexación de entrada/salida

SINOPSIS

int zmq_poll (zmq_pollitem_t *items, int nitems, long timeout);

DESCRIPCIÓN

La función zmq_poll() proporciona un mecanismo para que las aplicaciones multiplexen eventos de entrada/salida en un modo de disparo por nivel sobre un conjunto de sockets. Cada miembro del array al que apunta el argumento items es una estructura zmq_pollitem_t. El argumento nitems especifica el número de elementos en el array items. La estructura zmq_pollitem_t se define de la siguiente manera:

typedef struct
{
    void *socket;
    zmq_fd_t fd;
    short events;
    short revents;
} zmq_pollitem_t;

Para cada elemento zmq_pollitem_t, zmq_poll() examinará ya sea el socket 0MQ referenciado por socket o el socket estándar especificado por el descriptor de archivo fd, para los eventos especificados en events. Si tanto socket como fd están configurados en un solo zmq_pollitem_t, el socket 0MQ referenciado por socket tendrá prioridad y el valor de fd se ignorará.

Para cada elemento zmq_pollitem_t, zmq_poll() primero borrará el miembro revents, y luego indicará cualquier evento solicitado que haya ocurrido estableciendo el bit correspondiente a la condición del evento en el miembro revents.

Si ninguno de los eventos solicitados ha ocurrido en ningún elemento zmq_pollitem_t, zmq_poll() esperará timeout milisegundos para que ocurra un evento en cualquiera de los elementos solicitados. Si el valor de timeout es 0, zmq_poll() devolverá inmediatamente. Si el valor de timeout es -1, zmq_poll() se bloqueará indefinidamente hasta que ocurra un evento solicitado en al menos un zmq_pollitem_t.

Los miembros events y revents de zmq_pollitem_t son máscaras de bits construidas mediante la operación OR de una combinación de las siguientes banderas de eventos:

ZMQ_POLLIN

Para sockets 0MQ, se puede recibir al menos un mensaje del socket sin bloquear. Para sockets estándar, esto es equivalente a la bandera POLLIN de la llamada al sistema poll() y generalmente significa que se puede leer al menos un byte de datos del fd sin bloquear.

ZMQ_POLLOUT

Para sockets 0MQ, se puede enviar al menos un mensaje al socket sin bloquear. Para sockets estándar, esto es equivalente a la bandera POLLOUT de la llamada al sistema poll() y generalmente significa que se puede escribir al menos un byte de datos en fd sin bloquear.

ZMQ_POLLERR

Para sockets estándar, esta bandera se pasa a través de zmq_poll() a la llamada al sistema subyacente poll() y generalmente significa que existe alguna condición de error en el socket especificado por fd. Para sockets 0MQ, esta bandera no tiene efecto si se establece en events, y zmq_poll() nunca la devolverá en revents.

ZMQ_POLLPRI

Para sockets 0MQ, esta bandera no es útil. Para sockets estándar, significa que hay datos urgentes para leer. Consulte la bandera POLLPRI para obtener más información. Para el descriptor de archivo, consulte su caso de uso: como ejemplo, las interrupciones GPIO se señalan a través de un evento POLLPRI. Esta bandera no tiene efecto en Windows.

Nota

La función zmq_poll() puede implementarse o emularse utilizando interfaces del sistema operativo distintas de poll(), y como tal puede estar sujeta a los límites de esas interfaces de maneras no definidas en esta documentación.

SEGURIDAD EN HILOS

El array zmq_pollitem_t solo debe ser utilizado por el hilo que llamará/está llamando a zmq_poll.

Si un socket está contenido en múltiples arrays zmq_pollitem_t, cada uno propiedad de un hilo diferente, el socket en sí mismo debe ser seguro para hilos (Servidor, Cliente, ...). De lo contrario, el comportamiento no está definido.

VALOR DE RETORNO

Al completarse con éxito, la función zmq_poll() devolverá el número de estructuras zmq_pollitem_t con eventos señalados en revents o 0 si no se han señalado eventos. En caso de error, zmq_poll() devolverá -1 y establecerá errno a uno de los valores definidos a continuación.

ERRORES

ETERM

Al menos uno de los miembros del array items hace referencia a un socket cuyo contexto 0MQ asociado fue terminado.

EFAULT

El items proporcionado no era válido (NULL).

EINTR

La operación fue interrumpida por la entrega de una señal antes de que hubiera eventos disponibles.

EJEMPLO

Esperando indefinidamente eventos de entrada en un socket 0MQ y un socket estándar..

zmq_pollitem_t items [2];
/* El primer elemento se refiere al socket 0MQ 'socket' */
items[0].socket = socket;
items[0].events = ZMQ_POLLIN;
/* El segundo elemento se refiere al socket estándar 'fd' */
items[1].socket = NULL;
items[1].fd = fd;
items[1].events = ZMQ_POLLIN;
/* Esperar eventos indefinidamente */
int rc = zmq_poll (items, 2, -1);
assert (rc >= 0);
/* Los eventos devueltos se almacenarán en items[].revents */
