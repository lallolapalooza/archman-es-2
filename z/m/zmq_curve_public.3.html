ZMQ_CURVE_PUBLIC(3) Manual de 0MQ ZMQ_CURVE_PUBLIC(3)

NOMBRE

zmq_curve_public - derivar la clave pública a partir de una clave privada

SINOPSIS

int zmq_curve_public (char *z85_public_key, char *z85_secret_key);

DESCRIPCIÓN

La función zmq_curve_public() derivará la clave pública a partir de una clave privada. El llamante proporciona dos búferes, cada uno de al menos 41 octetos de tamaño. En z85_secret_key el llamante proporcionará la clave privada, y la función almacenará la clave pública en z85_public_key. Las claves están codificadas usando zmq_z85_encode(3).

VALOR DE RETORNO

La función zmq_curve_public() devolverá 0 si tiene éxito, de lo contrario, devolverá -1 y establecerá errno a uno de los valores definidos a continuación.

ERRORES

ENOTSUP

La biblioteca libzmq no fue compilada con soporte criptográfico (libsodium).

EJEMPLO

Derivando la clave pública de una clave privada CURVE.

char public_key [41];
char secret_key [41];
int rc = zmq_curve_keypair (public_key, secret_key);
assert (rc == 0);
char derived_public[41];
rc = zmq_curve_public (derived_public, secret_key);
assert (rc == 0);
assert (!strcmp (derived_public, public_key));
