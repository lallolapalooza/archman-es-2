NOMBRE

zmq_tcp - transporte unicast de 0MQ usando TCP

SINOPSIS

TCP es un transporte ubicuo, fiable y unicast. Al conectar aplicaciones distribuidas a través de una red con 0MQ, usar el transporte TCP probablemente será tu primera opción.

DIRECCIONAMIENTO

Un punto final (endpoint) de 0MQ es una cadena que consiste en un transporte:// seguido de una dirección. El transporte especifica el protocolo subyacente a usar. La dirección especifica la dirección específica del transporte a la que conectarse.

Para el transporte TCP, el transporte es tcp, y el significado de la parte de la dirección se define a continuación.

Asignación de una dirección local a un socket

Al asignar una dirección local a un socket usando zmq_bind() con el transporte tcp, el endpoint se interpretará como una interfaz seguida de dos puntos y el número de puerto TCP a usar.

Una interfaz puede especificarse de alguna de las siguientes maneras:

•El comodín *, que significa todas las interfaces disponibles.
•La dirección IPv4 o IPv6 principal asignada a la interfaz, en su representación numérica.
•El nombre de interfaz no portátil tal como lo define el sistema operativo.

El número de puerto TCP puede especificarse de:

•Un valor numérico, usualmente por encima de 1024 en sistemas POSIX.
•El comodín *, que significa un puerto efímero asignado por el sistema.

Al usar puertos efímeros, el llamador debe recuperar el puerto asignado real usando la opción de socket ZMQ_LAST_ENDPOINT. Ver zmq_getsockopt(3) para más detalles.

Desvinculación de dirección comodín de un socket

Cuando se usó el endpoint comodín * en zmq_bind(), el llamador debe usar el endpoint real obtenido de la opción de socket ZMQ_LAST_ENDPOINT para desvincular este endpoint de un socket usando zmq_unbind().

Conexión de un socket

Al conectar un socket a una dirección de par usando zmq_connect() con el transporte tcp, el endpoint se interpretará como una dirección de par seguida de dos puntos y el número de puerto TCP a usar. Opcionalmente puedes especificar un endpoint_origen que se usará como la dirección de origen para tu conexión; tcp://endpoint_origen;'endpoint', ver la descripción de interfaz arriba para más detalles.

Una dirección de par puede especificarse de alguna de las siguientes maneras:

•El nombre DNS del par.
•La dirección IPv4 o IPv6 del par, en su representación numérica.

Nota: Una descripción del Protocolo de Transporte de Mensajes de ZeroMQ (ZMTP) que es utilizado por el transporte TCP se puede encontrar en http://rfc.zeromq.org/spec:23

HWM

Para el transporte TCP, el mecanismo de marca de agua alta (HWM) funciona en conjunto con los búferes del socket TCP manejados a nivel del sistema operativo. Dependiendo del sistema operativo y de varios otros factores, el tamaño de dichos búferes TCP será diferente. Además, los búferes TCP proporcionados por el sistema operativo acomodarán un número variable de mensajes dependiendo del tamaño de los mensajes (a diferencia de los ajustes de HWM de ZMQ, los búferes de socket TCP se miden en bytes y no en mensajes).

Esto puede resultar en comportamientos aparentemente inexplicables: por ejemplo, puedes esperar que al establecer ZMQ_SNDHWM a 100 en un socket que usa el transporte TCP, se bloquee la transmisión del mensaje 101-ésimo si el receptor es lento. Esto es muy improbable cuando se usa el transporte TCP ya que los búferes TCP del sistema operativo normalmente proporcionarán suficiente almacenamiento intermedio para permitirte enviar mucho más de 100 mensajes.

Por supuesto, si el receptor es lento, la transmisión en un socket ZMQ TCP eventualmente activará el "estado de silencio" del socket; simplemente no confíes en el valor exacto de HWM.

Obviamente, las mismas consideraciones se aplican para la HWM de recepción (ver ZMQ_RCVHWM).

EJEMPLOS

Asignación de una dirección local a un socket.

//  Puerto TCP 5555 en todas las interfaces disponibles
rc = zmq_bind(socket, "tcp://*:5555");
assert (rc == 0);
//  Puerto TCP 5555 en la interfaz de bucle local en todas las plataformas
rc = zmq_bind(socket, "tcp://127.0.0.1:5555");
assert (rc == 0);
//  Puerto TCP 5555 en la primera interfaz de red Ethernet en Linux
rc = zmq_bind(socket, "tcp://eth0:5555");
assert (rc == 0);

Conexión de un socket.

//  Conectando usando una dirección IP
rc = zmq_connect(socket, "tcp://192.168.1.1:5555");
assert (rc == 0);
//  Conectando usando un nombre DNS
rc = zmq_connect(socket, "tcp://server1:5555");
assert (rc == 0);
//  Conectando usando un nombre DNS y enlazando a eth1
rc = zmq_connect(socket, "tcp://eth1:0;server1:5555");
assert (rc == 0);
//  Conectando usando una dirección IP y enlazando a una dirección IP
rc = zmq_connect(socket, "tcp://192.168.1.17:5555;192.168.1.1:5555");
assert (rc == 0);
