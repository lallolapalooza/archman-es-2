ZMQ_MSG_SEND(3) Manual de 0MQ ZMQ_MSG_SEND(3)

NOMBRE

zmq_msg_send - enviar una parte de mensaje en un socket

SINOPSIS

int zmq_msg_send (zmq_msg_t *msg, void *socket, int flags);

DESCRIPCIÓN

La función zmq_msg_send() es idéntica a zmq_sendmsg(3), que será obsoleta en versiones futuras. zmq_msg_send() es más consistente con otras funciones de manipulación de mensajes.

La función zmq_msg_send() pondrá en cola el mensaje referenciado por el argumento msg para ser enviado al socket referenciado por el argumento socket. El argumento flags es una combinación de las banderas definidas a continuación:

ZMQ_DONTWAIT

Para tipos de socket (DEALER, PUSH) que se bloquean (ya sea con la opción ZMQ_IMMEDIATE establecida y sin un par disponible, o todos los pares con el marcador de agua alta (high-water mark) lleno), especifica que la operación debe realizarse en modo no bloqueante. Si el mensaje no se puede poner en cola en el socket, la función zmq_msg_send() fallará con errno establecido en EAGAIN.

ZMQ_SNDMORE

Especifica que el mensaje que se envía es un mensaje multipart (de varias partes), y que seguirán más partes del mensaje. Consulte la sección sobre mensajes multipart para una descripción detallada.

La estructura zmq_msg_t pasada a zmq_msg_send() se anula en una llamada exitosa. Si desea enviar el mismo mensaje a varios sockets, debe copiarlo (por ejemplo, usando zmq_msg_copy()). Si la llamada falla, la estructura zmq_msg_t permanece intacta y debe ser consumida por otra llamada a zmq_msg_send() en el mismo u otro socket, o liberada usando zmq_msg_close() para evitar una fuga de memoria.


Nota

Una invocación exitosa de zmq_msg_send() no indica que el mensaje se haya transmitido a la red, solo que se ha puesto en cola en el socket y que 0MQ ha asumido la responsabilidad del mensaje. No necesita llamar a zmq_msg_close() después de un zmq_msg_send() exitoso.

Mensajes multipart

Un mensaje 0MQ se compone de 1 o más partes de mensaje. Cada parte de mensaje es una zmq_msg_t independiente por derecho propio. 0MQ garantiza la entrega atómica de mensajes: los pares recibirán todas las partes del mensaje de un mensaje o ninguna. El número total de partes del mensaje es ilimitado excepto por la memoria disponible.

Una aplicación que envía mensajes multipart debe usar la bandera ZMQ_SNDMORE al enviar cada parte del mensaje excepto la última.

VALOR DE RETORNO

La función zmq_msg_send() devolverá el número de bytes en el mensaje si tiene éxito (si el número de bytes es mayor que MAX_INT, la función devolverá MAX_INT). De lo contrario, devolverá -1 y establecerá errno en uno de los valores definidos a continuación.

ERRORES

EAGAIN

Se solicitó el modo no bloqueante y el mensaje no se puede enviar en este momento.

ENOTSUP

La operación zmq_msg_send() no es compatible con este tipo de socket.

EINVAL

El emisor intentó enviar datos multipart, lo cual el tipo de socket no permite.

EFSM

La operación zmq_msg_send() no se puede realizar en este socket en este momento debido a que el socket no está en el estado apropiado. Este error puede ocurrir con tipos de socket que cambian entre varios estados, como ZMQ_REP. Consulte la sección de patrones de mensajería de zmq_socket(3) para más información.

ETERM

El contexto 0MQ asociado con el socket especificado fue terminado.

ENOTSOCK

El socket proporcionado era inválido.

EINTR

La operación fue interrumpida por la entrega de una señal antes de que se enviara el mensaje.

EFAULT

Mensaje inválido.

EHOSTUNREACH

El mensaje no se puede enrutar.

EJEMPLO

Rellenando un mensaje y enviándolo a un socket.

/* Crear un nuevo mensaje, asignando 6 bytes para el contenido del mensaje */
zmq_msg_t msg;
int rc = zmq_msg_init_size (&msg, 6);
assert (rc == 0);
/* Rellenar el contenido del mensaje con 'AAAAAA' */
memset (zmq_msg_data (&msg), 'A', 6);
/* Enviar el mensaje al socket */
rc = zmq_msg_send (&msg, socket, 0);
assert (rc == 6);

Enviando un mensaje multipart.

/* Enviar un mensaje multipart que consta de tres partes al socket */
rc = zmq_msg_send (&part1, socket, ZMQ_SNDMORE);
rc = zmq_msg_send (&part2, socket, ZMQ_SNDMORE);
/* Parte final; no hay más partes a seguir */
rc = zmq_msg_send (&part3, socket, 0);
