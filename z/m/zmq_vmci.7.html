NOMBRE

zmq_vmci - transporte 0MQ sobre la interfaz de comunicaciones de máquinas virtuales (VMCI) sockets

SINOPSIS

El transporte VMCI pasa mensajes entre máquinas virtuales de VMware que se ejecutan en el mismo host, entre la máquina virtual y el host, y dentro de las máquinas virtuales (transporte entre procesos como ipc).


Nota

La comunicación entre una máquina virtual y el host no es compatible en Mac OS X 10.9 y versiones posteriores.

DIRECCIONAMIENTO

Un endpoint de 0MQ es una cadena que consiste en untransporte:// seguido de unadirección. Eltransporteespecifica el protocolo subyacente a usar. Ladirecciónespecifica la dirección específica del transporte a la que conectarse.

Para el transporte VMCI, el transporte es vmci, y el significado de la parte de ladirecciónse define a continuación.

Vinculación de un socket

Al vincular unsocketa una dirección local usando zmq_bind()con el transportevmci, elendpointse interpretará como unainterfazseguida de dos puntos y el número de puerto TCP a utilizar.

Unainterfazpuede especificarse mediante cualquiera de los siguientes:

•El comodín *, que significa todas las interfaces disponibles.
•Un entero devuelto por VMCISock_GetLocalCID o @ (ZeroMQ llamará a VMCISock_GetLocalCID internamente).

El puerto puede especificarse mediante:

•Un valor numérico, generalmente superior a 1024 en sistemas POSIX.
•El comodín *, que significa un puerto efímero asignado por el sistema.

Desvinculación de la dirección comodín de un socket

Cuando se utilizó el comodín *endpointenzmq_bind(), el llamador debe usar elendpointreal obtenido de la opción de socket ZMQ_LAST_ENDPOINT para desvincular esteendpointde un socket usando zmq_unbind().

Conexión de un socket

Al conectar un socket a una dirección de par usando zmq_connect()con el transportevmci, elendpointse interpretarán como unadirección de parseguida de dos puntos y el número de puerto a utilizar.

Unadirección de pardebe ser un CID del par.

EJEMPLOS

Asignación de una dirección local a un socket.

// Puerto VMCI 5555 en todas las interfaces disponibles
rc = zmq_bind(socket, "vmci://*:5555");
assert (rc == 0);
// Puerto VMCI 5555 en la interfaz de loop-back local en todas las plataformas
cid = VMCISock_GetLocalCID();
sprintf(endpoint, "vmci://%d:5555", cid);
rc = zmq_bind(socket, endpoint);
assert (rc == 0);

Conexión de un socket.

// Conexión usando un CID
sprintf(endpoint, "vmci://%d:5555", cid);
rc = zmq_connect(socket, endpoint);
assert (rc == 0);
