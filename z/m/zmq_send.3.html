NOMBRE

zmq_send - enviar una parte de mensaje en un socket

SINOPSIS

int zmq_send (void *socket, const void *buf, size_t len, int flags);

DESCRIPCIÓN

La función zmq_send() pondrá en cola un mensaje creado a partir del búfer referenciado por los argumentos buf y len. El argumento flags es una combinación de las banderas definidas a continuación:

ZMQ_DONTWAIT

Para tipos de socket (DEALER, PUSH) que bloquean (ya sea con la opción ZMQ_IMMEDIATE establecida y sin un par disponible, o todos los pares con una marca de alta agua llena), especifica que la operación debe realizarse en modo no bloqueante. Si el mensaje no se puede poner en cola en el socket, la función zmq_send() fallará con errno establecido en EAGAIN.

ZMQ_SNDMORE

Especifica que el mensaje que se está enviando es un mensaje multipart (de varias partes) y que seguirán más partes de mensaje. Consulte la sección sobre mensajes multipart a continuación para obtener una descripción detallada.

Nota

Una invocación exitosa de zmq_send() no indica que el mensaje se haya transmitido a la red, solo que se ha puesto en cola en el socket y 0MQ ha asumido la responsabilidad del mensaje.

Mensajes multipart

Un mensaje 0MQ se compone de 1 o más partes de mensaje. 0MQ garantiza la entrega atómica de mensajes: los pares recibirán todas las partes del mensaje de un mensaje o ninguna. El número total de partes de mensaje es ilimitado, excepto por la memoria disponible.

Una aplicación que envía mensajes multipart debe usar la bandera ZMQ_SNDMORE al enviar cada parte del mensaje excepto la última.

VALOR DE RETORNO

La función zmq_send() devolverá el número de bytes del mensaje si tiene éxito. De lo contrario, devolverá -1 y establecerá errno en uno de los valores definidos a continuación.

ERRORES

EAGAIN

Se solicitó el modo no bloqueante y el mensaje no se puede enviar en este momento.

ENOTSUP

La operación zmq_send() no es compatible con este tipo de socket.

EINVAL

El remitente intentó enviar datos multipart, lo que el tipo de socket no permite.

EFSM

La operación zmq_send() no se puede realizar en este socket en este momento debido a que el socket no está en el estado adecuado. Este error puede ocurrir con tipos de socket que cambian entre varios estados, como ZMQ_REP. Consulte la sección patrones de mensajería de zmq_socket(3) para obtener más información.

ETERM

El contexto 0MQ asociado con el socket especificado fue terminado.

ENOTSOCK

El socket proporcionado no era válido.

EINTR

La operación fue interrumpida por la entrega de una señal antes de que se enviara el mensaje.

EHOSTUNREACH

El mensaje no se puede enrutar.

EJEMPLO

Enviando un mensaje multipart.

/* Enviar un mensaje multipart que consta de tres partes al socket */
rc = zmq_send (socket, "ABC", 3, ZMQ_SNDMORE);
assert (rc == 3);
rc = zmq_send (socket, "DEFGH", 5, ZMQ_SNDMORE);
assert (rc == 5);
/* Parte final; no hay más partes que sigan */
rc = zmq_send (socket, "JK", 2, 0);
assert (rc == 2);
