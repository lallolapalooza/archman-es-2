!>    (1) y = ( Inf + 0   * I)
!>    (2) y = (-Inf + 0   * I)
!>    (3) y = ( 0   + Inf * I)
!>    (4) y = ( 0   - Inf * I)

!>                 NaN (caso 5).
!>
!> (b) Entradas NaN:
!>    (1) y = (NaN + 0   * I)
!>    (2) y = (0   + NaN * I)
!>    (3) y = (NaN + NaN * I)
!> Pruebas:
!>    (a) 0 * y es NaN.

!>    (c) y * y es NaN.
