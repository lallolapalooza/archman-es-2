NOMBRE

zmq_gssapi - autenticación segura y confidencialidad

SINOPSIS

El mecanismo GSSAPI define un mecanismo para autenticación segura y confidencialidad para comunicaciones entre un cliente y un servidor utilizando la Interfaz de Programación de Aplicaciones de Servicios Genéricos de Seguridad (GSSAPI). El mecanismo GSSAPI se puede usar tanto en redes públicas como privadas. GSSAPI está definido en el RFC-2743 de IETF: http://tools.ietf.org/html/rfc2743. El mecanismo GSSAPI de ZeroMQ se define en este documento: http://rfc.zeromq.org/spec:38.

ROLES DE CLIENTE Y SERVIDOR

Un socket que utiliza GSSAPI puede ser cliente o servidor, pero no ambos.

Para convertirse en un servidor GSSAPI, la aplicación establece la opción ZMQ_GSSAPI_SERVER en el socket.

Para convertirse en un cliente GSSAPI, la aplicación establece la opción ZMQ_GSSAPI_SERVICE_PRINCIPAL con el nombre del principal en el servidor al que pretende conectarse.

En cliente o servidor, la aplicación puede establecer adicionalmente la opción ZMQ_GSSAPI_PRINCIPAL para proporcionar al socket el nombre del principal para el cual se deben adquirir las credenciales GSSAPI. Si esta opción no se establece, se utilizan las credenciales predeterminadas.

CIFRADO OPCIONAL

Por defecto, el mecanismo GSSAPI cifrará todas las comunicaciones entre cliente y servidor. Si no se desea cifrado (por ejemplo, en redes privadas), las aplicaciones cliente y servidor pueden deshabilitarlo estableciendo la opción ZMQ_GSSAPI_PLAINTEXT. Tanto el cliente como el servidor deben establecer esta opción al mismo valor.

NOMBRES DE PRINCIPALES

Los nombres de principales especificados con las opciones ZMQ_GSSAPI_SERVICE_PRINCIPAL o ZMQ_GSSAPI_PRINCIPAL se interpretan como tipos de nombre "basados en host" por defecto. Las opciones ZMQ_GSSAPI_PRINCIPAL_NAMETYPE y ZMQ_GSSAPI_SERVICE_PRINCIPAL_NAMETYPE pueden usarse para cambiar el tipo de nombre a uno de:

ZMQ_GSSAPI_NT_HOSTBASED

El nombre debe tener el formato "servicio" o "servicio@nombrehost", que se analizará en un principal de "servicio/nombrehost" en el ámbito local. Este es el tipo de nombre predeterminado.

ZMQ_GSSAPI_NT_USER_NAME

El nombre debe ser un nombre de usuario local, que se analizará en un principal de un solo componente en el ámbito local.

ZMQ_GSSAPI_NT_KRB5_PRINCIPAL

El nombre es una cadena de nombre de principal. Este tipo de nombre solo funciona con el mecanismo GSSAPI krb5.
