NOMBRE

zmq_udp - Transporte multicast y unicast UDP de 0MQ

SINOPSIS

UDP es un protocolo de transporte de datos no confiable a través de redes IP. UDP admite comunicación tanto unicast como multicast.

DESCRIPCIÓN

El transporte UDP solo se puede usar con los tipos de socket ZMQ_RADIO y ZMQ_DISH.

DIRECCIONAMIENTO

Un endpoint de 0MQ es una cadena que consta de un transporte:// seguido de una dirección. El transporte especifica el protocolo subyacente a usar. La dirección especifica la dirección específica del transporte a la que conectarse.

Para el transporte UDP, el transporte es udp. El significado de la parte de la dirección se define a continuación.

VINCULACIÓN DE UN SOCKET

Con udp, solo podemos vincular el tipo de socket ZMQ_DISH. Al vincular un socket usando zmq_bind() con el transporte udp, el endpoint se interpretará como una interfaz seguida de dos puntos y el número de puerto UDP a usar.

Una interfaz puede especificarse por cualquiera de los siguientes:

•El comodín *, que significa todas las interfaces disponibles.
•El nombre de la interfaz de red (por ejemplo, eth0, lo, wlan0, etc.)
•La dirección primaria asignada a la interfaz, en su representación numérica.
•Dirección multicast en su representación numérica a la que el socket debe unirse.

El número de puerto UDP se puede especificar como un valor numérico, generalmente superior a 1024 en sistemas POSIX.

CONEXIÓN DE UN SOCKET

Con udp, solo podemos conectar el tipo de socket ZMQ_RADIO. Al conectar un socket a una dirección de par usando zmq_connect() con el transporte udp, el endpoint se interpretará como una dirección de par seguida de dos puntos y el número de puerto UDP a usar.

Una dirección de par puede especificarse por cualquiera de los siguientes:

•La dirección IPv4 o IPv6 del par, en su representación numérica o usando su nombre de host.
•Dirección multicast en su representación numérica.

EJEMPLOS

Vinculación de un socket.

//  Unicast - Puerto UDP 5555 en todas las interfaces disponibles
rc = zmq_bind(dish, "udp://*:5555");
assert (rc == 0);
//  Unicast - Puerto UDP 5555 en la interfaz de loopback local
rc = zmq_bind(dish, "udp://127.0.0.1:5555");
assert (rc == 0);
//  Unicast - Puerto UDP 5555 en la interfaz eth1
rc = zmq_bind(dish, "udp://eth1:5555");
assert (rc == 0);
//  Multicast - Puerto UDP 5555 en una dirección Multicast
rc = zmq_bind(dish, "udp://239.0.0.1:5555");
assert (rc == 0);
//  Igual que lo anterior pero uniéndose solo en la interfaz eth0
rc = zmq_bind(dish, "udp://eth0;239.0.0.1:5555");
assert (rc == 0);
//  Igual que lo anterior usando multicast IPv6
rc = zmq_bind(dish, "udp://eth0;[ff02::1]:5555");
assert (rc == 0);

Conexión de un socket.

//  Conexión usando una dirección IP Unicast
rc = zmq_connect(radio, "udp://192.168.1.1:5555");
assert (rc == 0);
//  Conexión usando una dirección Multicast
rc = zmq_connect(socket, "udp://239.0.0.1:5555);
assert (rc == 0);
//  Conexión usando una dirección Multicast a través de la interfaz local wlan0
rc = zmq_connect(socket, "udp://wlan0;239.0.0.1:5555);
assert (rc == 0);
//  Conexión a multicast IPv6
rc = zmq_connect(socket, "udp://[ff02::1]:5555);
assert (rc == 0);
