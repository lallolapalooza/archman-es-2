ZMQ_SEND_CONST(3) Manual de 0MQ ZMQ_SEND_CONST(3)

NOMBRE

zmq_send_const - envía una parte de mensaje de memoria constante a un socket

SINOPSIS

int zmq_send_const (void *socket, const void *buf, size_t len, int flags);

DESCRIPCIÓN

La función zmq_send_const() pondrá en cola un mensaje creado a partir del buffer referenciado por los argumentos buf y len. Se asume que el buffer del mensaje es de memoria constante y, por lo tanto, no será copiado ni liberado de ninguna manera. El argumento flags es una combinación de las banderas definidas a continuación:

ZMQ_DONTWAIT

Para tipos de socket (DEALER, PUSH) que se bloquean (ya sea con la opción ZMQ_IMMEDIATE establecida y sin un peer disponible, o todos los peers con la marca de alta agua (high-water mark) llena), especifica que la operación debe realizarse en modo no bloqueante. Si el mensaje no se puede poner en cola en el socket, la función zmq_send_const() fallará con errno establecido en EAGAIN.

ZMQ_SNDMORE

Especifica que el mensaje que se está enviando es un mensaje multipart (múltiples partes) y que seguirán más partes del mensaje. Consulte la sección sobre mensajes multipart a continuación para obtener una descripción detallada.

Nota

Una invocación exitosa de zmq_send_const() no indica que el mensaje se haya transmitido a la red, solo que se ha puesto en cola en el socket y que 0MQ ha asumido la responsabilidad del mensaje.

Mensajes multipart

Un mensaje 0MQ consta de 1 o más partes de mensaje. 0MQ garantiza la entrega atómica de mensajes: los peers recibirán todas las partes del mensaje de un mensaje o ninguna. El número total de partes del mensaje es ilimitado, excepto por la memoria disponible.

Una aplicación que envía mensajes multipart debe usar la bandera ZMQ_SNDMORE al enviar cada parte del mensaje, excepto la última.

VALOR DE RETORNO

La función zmq_send_const() devolverá el número de bytes del mensaje si tiene éxito. De lo contrario, devolverá -1 y establecerá errno a uno de los valores definidos a continuación.

ERRORES

EAGAIN

Se solicitó el modo no bloqueante y el mensaje no se puede enviar en este momento.

ENOTSUP

La operación zmq_send_const() no es compatible con este tipo de socket.

EFSM

La operación zmq_send_const() no se puede realizar en este socket en este momento debido a que el socket no se encuentra en el estado apropiado. Este error puede ocurrir con tipos de socket que cambian entre varios estados, como ZMQ_REP. Consulte la sección de patrones de mensajería de zmq_socket(3) para más información.

ETERM

El contexto 0MQ asociado con el socket especificado fue terminado.

ENOTSOCK

El socket proporcionado no era válido.

EINTR

La operación fue interrumpida por la entrega de una señal antes de que se enviara el mensaje.

EHOSTUNREACH

El mensaje no se puede enrutar.

EJEMPLO

Envío de un mensaje multipart.

/* Enviar un mensaje multipart de tres partes al socket */
rc = zmq_send_const (socket, "ABC", 3, ZMQ_SNDMORE);
assert (rc == 3);
rc = zmq_send_const (socket, "DEFGH", 5, ZMQ_SNDMORE);
assert (rc == 5);
/* Parte final; no hay más partes que seguir */
rc = zmq_send_const (socket, "JK", 2, 0);
assert (rc == 2);
