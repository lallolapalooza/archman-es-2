NOMBRE

zmq_z85_decode - decodifica una clave binaria de texto imprimible Z85

SINOPSIS

uint8_t *zmq_z85_decode (uint8_t *dest, const char *string);

DESCRIPCIÓN

La función zmq_z85_decode() decodificará string en dest. La longitud de string deberá ser divisible por 5. dest debe ser lo suficientemente grande para el valor decodificado (0.8 x strlen (string)).

La codificación seguirá la especificación ZMQ RFC 32.

VALOR DE RETORNO

La función zmq_z85_decode() devolverá dest si tiene éxito, de lo contrario devolverá NULL.

EJEMPLO

Decodificando una clave CURVE.

const char decoded [] = "rq:rM>}U?@Lns47E1%kR.o@n%FcmmsL/@{H8]yf7";
uint8_t public_key [32];
zmq_z85_decode (public_key, decoded);
