NOMBRE

zmq_tipc - transporte unicast de 0MQ usando TIPC

SINOPSIS

TIPC es un protocolo IPC de clúster con un esquema de direccionamiento transparente a la ubicación.

DIRECCIONAMIENTO

Un punto final de 0MQ es una cadena que consta de un protocolo de transporte:// seguido de una dirección. El transporte especifica el protocolo subyacente a usar. La dirección especifica la dirección específica del transporte a la que conectarse.

Para el transporte TIPC, el transporte es tipc y el significado de la parte de dirección se define a continuación.

Asignar un nombre de puerto a un socket

Al asignar un nombre de puerto a un socket usando zmq_bind() con el transporte tipc, el endpoint se define en el formato: {tipo, inferior, superior}

•Tipo es el ID numérico (u32) de tu servicio.
•Inferior y Superior especifican un rango para tu servicio.

Publicar el mismo servicio con ID inferiores/superiores superpuestos causará que las solicitudes de conexión se distribuyan en estos de forma round-robin.

Conectar un socket

Al conectar un socket a una dirección par usando zmq_connect() con el transporte tipc, el endpoint se interpretará como un ID de servicio, seguido de una coma y el ID de instancia.

El ID de instancia debe estar dentro del rango inferior/superior de un nombre de puerto publicado para que el endpoint sea válido.

EJEMPLOS

Asignar una dirección local a un socket.

//  Publicar el ID de servicio TIPC 5555
rc = zmq_bind(socket, "tipc://{5555,0,0}");
assert (rc == 0);
//  Publicar el ID de servicio TIPC 5555 con un rango de servicio de 0-100
rc = zmq_bind(socket, "tipc://{5555,0,100}");
assert (rc == 0);

Conectar un socket.

//  Conectar al ID de instancia 50 del servicio 5555
rc = zmq_connect(socket, "tipc://{5555,50}");
assert (rc == 0);
