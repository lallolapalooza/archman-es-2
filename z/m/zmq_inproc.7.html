NOMBRE

zmq_inproc - transporte de comunicación local en proceso (entre hilos) de 0MQ

SINOPSIS

El transporte en proceso pasa mensajes a través de memoria directamente entre hilos que comparten un único contexto de 0MQ.


Nota

Ningún hilo de E/S está involucrado en el paso de mensajes utilizando el transporte inproc. Por lo tanto, si está utilizando un contexto de 0MQ solo para mensajería en proceso, puede inicializar el contexto con cero hilos de E/S. Consulte zmq_init(3) para obtener detalles.

DIRECCIONAMIENTO

Un punto final de 0MQ es una cadena que consiste en un transporte:// seguido de una dirección. El transporte especifica el protocolo subyacente a usar. La dirección especifica la dirección específica del transporte a la que conectarse.

Para el transporte en proceso, el transporte es inproc, y el significado de la parte de la dirección se define a continuación.

Asignación de una dirección local a un socket

Al asignar una dirección local a un socket usando zmq_bind() con el transporte inproc, el punto final se interpretarará como una cadena arbitraria que identifica el nombre a crear. El nombre debe ser único dentro del contexto de 0MQ asociado con el socket y puede tener hasta 256 caracteres de longitud. No se imponen otras restricciones al formato del nombre.

Conexión de un socket

Al conectar un socket a una dirección de par usando zmq_connect() con el transporte inproc, el punto final se interpretarará como una cadena arbitraria que identifica el nombre al que conectarse. Antes de la versión 4.0, el nombre debe haber sido creado previamente asignándolo al menos a un socket dentro del mismo contexto de 0MQ que el socket que se está conectando. Desde la versión 4.0, el orden de zmq_bind() y zmq_connect() no importa, al igual que para el tipo de transporte tcp.

EJEMPLOS

Asignación de una dirección local a un socket.

//  Asigna el nombre en proceso "#1"
rc = zmq_bind(socket, "inproc://#1");
assert (rc == 0);
//  Asigna el nombre en proceso "mi-punto-final"
rc = zmq_bind(socket, "inproc://mi-punto-final");
assert (rc == 0);

Conexión de un socket.

//  Conecta al nombre en proceso "#1"
rc = zmq_connect(socket, "inproc://#1");
assert (rc == 0);
//  Conecta al nombre en proceso "mi-punto-final"
rc = zmq_connect(socket, "inproc://mi-punto-final");
assert (rc == 0);
