NOMBRE

zmq_ctx_shutdown - apagar un contexto 0MQ

SINOPSIS

int zmq_ctx_shutdown (void *context);

DESCRIPCIÓN

La función zmq_ctx_shutdown() apagará el contexto 0MQ context.

El apagado del contexto hará que cualquier operación bloqueante actualmente en progreso en sockets abiertos dentro de context retorne inmediatamente con un código de error ETERM. Con la excepción de zmq_close(), cualquier operación posterior en sockets abiertos dentro de context fallará con un código de error ETERM. No se pueden crear más sockets usando zmq_socket() en un contexto para el cual se ha llamado zmq_ctx_shutdown(); retornará y establecerá errno a ETERM.

Esta función es opcional; el código cliente todavía debe llamar a la función zmq_ctx_term(3) para liberar todos los recursos asignados por zeromq.

VALOR DE RETORNO

La función zmq_ctx_shutdown() retornará cero si es exitosa. De lo contrario, retornará -1 y establecerá errno a uno de los valores definidos a continuación.

ERRORES

EFAULT

El context proporcionado era inválido.
