zretune(1) COMANDOS DE USUARIO zretune(1)

NOMBRE

zretune - remuestrea un archivo de audio para cambiar su tono

SINOPSIS

zretune [opciones] archivo-entrada archivo-salida

DESCRIPCIÓN

zretune remuestrea un archivo de audio por el inverso de una relación dada directamente o expresada en centésimas, sin cambiar la tasa de muestreo nominal. El resultado es cambiar el tono musical y la longitud del archivo. La entrada puede ser cualquier archivo de audio legible por la biblioteca libsndfile. El tipo de archivo de salida es WAV, WAVEX, CAF, AIFF o FLAC.

OPCIONES

--help
Muestra un breve texto de ayuda.
--ratio pitch ratio
El rango aceptado es de 0.5 a 2.0. El rango útil en la práctica será menor.
--cent cambio en centésimas
El número de centésimas por las que se cambia el tono. El rango aceptado es +/- 1200 centésimas, el rango útil en la práctica será algo como +/- 100 centésimas.

Tipo de archivo de salida

--wav
Produce un archivo WAV, o para más de 2 canales, un archivo WAVEX. Esta es la opción predeterminada.
--amb
Produce un archivo WAVEX con el GUID de Ambisonics. Dichos archivos deben tener la extensión de nombre de archivo .amb.
--caf
Produce un archivo Core Audio.
--aiff
Produce un archivo AIFF.
--flac
Produce un archivo FLAC.

Formato de muestra de salida

--16bit
El formato de muestra de salida es de 16 bits con signo. Esta opción también habilita el uso de dithering, descrito a continuación.
--24bit
El formato de muestra de salida es de 24 bits. Esta es la opción predeterminada.
--float
El formato de muestra de salida es de punto flotante de 32 bits.

Dithering

--rec
Añade ruido de dithering blanco con una distribución rectangular. Esta es la mejor opción si los datos de salida se van a procesar de nuevo, pero en ese caso sería recomendable usar 24 bits o flotante.
--tri
Añade ruido filtrado con una distribución triangular. Comparado con el dither rectangular, esto reduce la densidad de ruido en el rango de frecuencias bajas.
--lips
Esto utiliza el filtro de retroalimentación de error óptimo descrito por Stanley Lipschitz. Se recomienda si la salida es el formato de distribución final, por ejemplo, para un CD.

Temporización

--pad
Inserta muestras de entrada con valor cero al principio y al final para que la salida incluya la respuesta completa del filtro simétrico incluso para las primeras y últimas muestras.

ESTADO DE SALIDA

Cero en caso de que no haya errores, distinto de cero en caso contrario.
