Documentación de la función/subrutina

subrutina zrscl (integer n, complex*16 a, complex*16, dimension( * ) x, integer incx)

ZDRSCL multiplica un vector por el recíproco de un escalar real.

Propósito:

!>
!> ZRSCL multiplica un vector complejo de n elementos x por el escalar complejo
!> 1/a. Esto se hace sin desbordamiento ni subdesbordamiento, siempre que
!> el resultado final x/a no desborde ni subdesborde.
!>

Parámetros

N 
!>          N es ENTERO
!>          El número de componentes del vector x.
!>

A

!>          A es COMPLEX*16
!>          El escalar a que se utiliza para dividir cada componente de x.
!>          A no debe ser 0, de lo contrario la subrutina dividirá por cero.
!>

X

!>          X es un array COMPLEX*16, de dimensión
!>                         (1+(N-1)*abs(INCX))
!>          El vector x de n elementos.
!>

INCX

!>          INCX es ENTERO
!>          El incremento entre valores sucesivos de SX, el vector.
!>          > 0:  SX(1) = X(1) y SX(1+(i-1)*INCX) = x(i),     1< i<= n
!>
