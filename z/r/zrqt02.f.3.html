ZRQT02

Propósito:

!>
!> ZRQT02 prueba ZUNGRQ, que genera una matriz m por n Q con
!> filas ortonormales que se define como el producto de k
!> reflectores elementales.
!>
!> Dada la factorización RQ de una matriz m por n A, ZRQT02 genera
!> la matriz ortogonal Q definida por la factorización de las últimas k
!> filas de A; compara R(m-k+1:m,n-m+1:n) con
!> A(m-k+1:m,1:n)*Q(n-m+1:n,1:n)', y comprueba que las filas de Q son
!> ortonormales.
!>

Parámetros

M 
!>          M es ENTERO
!>          El número de filas de la matriz Q a generar.  M >= 0.
!>

N

!>          N es ENTERO
!>          El número de columnas de la matriz Q a generar.
!>          N >= M >= 0.
!>

K

!>          K es ENTERO
!>          El número de reflectores elementales cuyo producto define la
!>          matriz Q. M >= K >= 0.
!>

A

!>          A es un array COMPLEX*16, dimensión (LDA,N)
!>          La matriz m por n A que fue factorizada por ZRQT01.
!>

AF

!>          AF es un array COMPLEX*16, dimensión (LDA,N)
!>          Detalles de la factorización RQ de A, como la devuelve ZGERQF.
!>          Ver ZGERQF para más detalles.
!>

Q

!>          Q es un array COMPLEX*16, dimensión (LDA,N)
!>

R

!>          R es un array COMPLEX*16, dimensión (LDA,M)
!>

LDA

!>          LDA es ENTERO
!>          La dimensión principal de los arrays A, AF, Q y L. LDA >= N.
!>

TAU

!>          TAU es un array COMPLEX*16, dimensión (M)
!>          Los factores escalares de los reflectores elementales correspondientes
!>          a la factorización RQ en AF.
!>

WORK

!>          WORK es un array COMPLEX*16, dimensión (LWORK)
!>

LWORK

!>          LWORK es ENTERO
!>          La dimensión del array WORK.
!>

RWORK

!>          RWORK es un array DOUBLE PRECISION, dimensión (M)
!>

RESULT

!>          RESULT es un array DOUBLE PRECISION, dimensión (2)
!>          Los ratios de prueba:
!>          RESULT(1) = norm( R - A*Q' ) / ( N * norm(A) * EPS )
!>          RESULT(2) = norm( I - Q*Q' ) / ( N * EPS )
!>
