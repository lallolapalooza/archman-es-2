Documentación de la función/subrutina

subrutina zrotg (complex(wp) a, complex(wp) b, real(wp) c, complex(wp) s)

ZROTG genera una rotación de Givens con coseno real y seno complejo.

Propósito:

!>
!> ZROTG construye una rotación de plano
!>    [  c         s ] [ a ] = [ r ]
!>    [ -conjg(s)  c ] [ b ]   [ 0 ]
!> donde c es real, s es complejo, y c**2 + conjg(s)*s = 1.
!>
!> El cálculo utiliza las fórmulas
!>    |x| = sqrt( Re(x)**2 + Im(x)**2 )
!>    sgn(x) = x / |x|  si x /= 0
!>           = 1        si x  = 0
!>    c = |a| / sqrt(|a|**2 + |b|**2)
!>    s = sgn(a) * conjg(b) / sqrt(|a|**2 + |b|**2)
!>    r = sgn(a)*sqrt(|a|**2 + |b|**2)
!> Cuando a y b son reales y r /= 0, las fórmulas se simplifican a
!>    c = a / r
!>    s = b / r
!> lo mismo que en DROTG cuando |a| > |b|. Cuando |b| >= |a|,
!> el signo de c y s será diferente de los calculados por DROTG
!> si los signos de a y b no son los mismos.
!>
!>

A
