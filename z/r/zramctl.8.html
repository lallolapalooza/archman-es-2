ZRAMCTL(8) Administración del Sistema ZRAMCTL(8)

NOMBRE

zramctl - configurar y controlar dispositivos zram

SINOPSIS

Obtener información:

zramctl [opciones]

Restablecer zram:

zramctl -r zramdev...

Imprimir el nombre del primer dispositivo zram no utilizado:

zramctl -f

Configurar un dispositivo zram:

zramctl [-f | zramdev] [-s tamaño] [-t número] [-a algoritmo]

DESCRIPCIÓN

zramctl se utiliza para configurar rápidamente los parámetros de los dispositivos zram, para restablecerlos y para consultar el estado de los dispositivos zram utilizados.

Si no se proporciona ninguna opción, se muestran todos los dispositivos zram con tamaño distinto de cero.

Tenga en cuenta que el nodo zramdev especificado en la línea de comandos debe existir. El comando zramctl crea nuevos nodos /dev/zram<N> solo cuando se especifica la opción --find. Es posible (y común) que después del arranque del sistema los nodos /dev/zram<N> no se hayan creado todavía.

OPCIONES

-a, --algorithm lzo|lz4|lz4hc|deflate|842|zstd

Establece el algoritmo de compresión a utilizar para comprimir datos en el dispositivo zram.

La lista de algoritmos compatibles podría ser inexacta ya que depende de la configuración actual del kernel. Una visión general básica se puede obtener ejecutando el comando "cat /sys/block/zram0/comp_algorithm"; sin embargo, tenga en cuenta que esta lista también podría estar incompleta. Esto se debe a que ZRAM utiliza la API de Criptografía, y si ciertos algoritmos se compilaron como módulos, es imposible enumerarlos a todos.

-f, --find

Busca el primer dispositivo zram no utilizado. Si está presente un argumento --size, inicializa el dispositivo.

-n, --noheadings

No imprime una línea de encabezado en la salida de estado.

-o, --output lista

Define las columnas de salida de estado a utilizar. Si no se especifica ninguna disposición de salida, se utiliza un conjunto por defecto. Use --help para obtener una lista de todas las columnas soportadas.

La lista por defecto de columnas puede extenderse si lista se especifica en el formato +lista (por ejemplo, zramctl -o+COMP-RATIO).

-p, --algorithm-params

Establece los parámetros del algoritmo, por ejemplo, level=9 dict=/etc/dictionary para establecer el nivel de compresión y un diccionario preentrenado. Los parámetros son específicos del algoritmo.

--output-all

Imprime todas las columnas disponibles.

--raw

Utiliza el formato crudo para la salida de estado.

-r, --reset

Restablece las opciones del dispositivo(s) zram especificado(s). Las configuraciones del dispositivo zram solo pueden modificarse después de un restablecimiento.

-s, --size tamaño

Crea un dispositivo zram del tamaño especificado. Los dispositivos zram se alinean a las páginas de memoria; cuando el tamaño solicitado no es múltiplo del tamaño de página, se redondeará al siguiente múltiplo. Cuando no se especifica lo contrario, la unidad del parámetro tamaño son bytes.

El argumento tamaño puede ir seguido de los sufijos multiplicadores KiB (=1024), MiB (=1024*1024), y así sucesivamente para GiB, TiB, PiB, EiB, ZiB e YiB (el "iB" es opcional, por ejemplo, "K" tiene el mismo significado que "KiB") o los sufijos KB (=1000), MB (=1000*1000), y así sucesivamente para GB, TB, PB, EB, ZB e YB.

-t, --streams número

Establece el número máximo de flujos de compresión que pueden utilizarse para el dispositivo. Por defecto, se utilizan todas las CPU y un flujo para los kernels anteriores a 4.6.

-h, --help

Muestra el texto de ayuda y sale.

-V, --version

Muestra la versión y sale.

ESTADO DE SALIDA

zramctl devuelve 0 en caso de éxito, un valor distinto de cero en caso de fallo.

ARCHIVOS

/dev/zram[0..N]

Dispositivos de bloque zram

EJEMPLO

Los siguientes comandos configuran un dispositivo zram con un tamaño de un gigabyte y lo utilizan como dispositivo de intercambio.

 # zramctl --find --size 1024M
 /dev/zram0
 # mkswap /dev/zram0
 # swapon /dev/zram0
 ...
 # swapoff /dev/zram0
 # zramctl --reset /dev/zram0
