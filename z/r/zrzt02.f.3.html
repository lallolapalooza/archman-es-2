doble precisión función zrzt02 (integer m, integer n, complex*16, dimension( lda, * ) af, integer lda, complex*16, dimension( * ) tau, complex*16, dimension( lwork ) work, integer lwork)

ZRZT02

Propósito:

!>
!> ZRZT02 devuelve
!>      || I - Q'*Q || / ( M * eps)
!> donde la matriz Q está definida por las transformaciones de Householder
!> generadas por ZTZRZF.
!>

Parámetros

M 
!>          M es ENTERO
!>          El número de filas de la matriz AF.
!>

N

!>          N es ENTERO
!>          El número de columnas de la matriz AF.
!>

AF

!>          AF es un array COMPLEX*16, de dimensión (LDA,N)
!>          La salida de ZTZRZF.
!>

LDA

!>          LDA es ENTERO
!>          La dimensión principal del array AF.
!>

TAU

!>          TAU es un array COMPLEX*16, de dimensión (M)
!>          Detalles de las transformaciones de Householder según se devuelven
!>          en ZTZRZF.
!>

WORK

!>          WORK es un array COMPLEX*16, de dimensión (LWORK)
!>

LWORK

!>          LWORK es ENTERO
!>          Longitud del array WORK. LWORK >= N*N+N.
!>
