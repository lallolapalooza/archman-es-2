ZRAM-GENERATOR(8) Manual del Administrador del Sistema ZRAM-GENERATOR(8)

NOMBRE

zram-generator - Generador de unidades systemd para dispositivos de swap zram

SINOPSIS

/usr/lib/systemd/system-generators/zram-generator DIRECTORIO_DESTINO [DIRECTORIO_DESTINO_2 DIRECTORIO_DESTINO_3]
/usr/lib/systemd/system-generators/zram-generator --setup-device DISPOSITIVO
/usr/lib/systemd/system-generators/zram-generator --reset-device DISPOSITIVO

DESCRIPCIÓN

zram-generator es un generador que crea unidades systemd para formatear y usar dispositivos de RAM comprimida, ya sea como swap o como un sistema de archivos.

El generador será invocado por systemd al inicio del sistema. Luego, el generador:

1.
leerá archivos de configuración de {/etc,/lib}/systemd/zram-generator.conf[.d] (ver zram-generator.conf(5) para detalles);
2.
generará unidades systemd.swap(5) y/o systemd.mount(5) en DIRECTORIO_DESTINO y las conectará a swap.target o local-fs.target según corresponda;
3.
asegurará que el módulo zram esté cargado y creará los dispositivos solicitados.

El generador no hace nada si se ejecuta dentro de un contenedor (según lo determinado por systemd-detect-virt(8) --container).

El generador también entiende la opción de línea de comandos del kernel systemd.zram. Ver zram-generator.conf(5) para detalles.

Establecer la variable de entorno ZRAM_GENERATOR_ROOT hace que el generador se ejecute en modo de prueba, en cuyo caso se ignora la contenedorización y se omite el paso 3.
Para las ramificaciones de ZRAM_GENERATOR_ROOT en el manejo de la configuración, ver zram-generator.conf(5).

Las unidades dev-zramN.swap generadas dependen de systemd-zram-setup@zramN.service, la cual:

1.
leerá archivos de configuración de {/etc,/lib}/systemd/zram-generator.conf[.d] (ver zram-generator.conf(5) para detalles);
2.
establecerá el algoritmo de compresión deseado, si lo hay; si el kernel actual no entiende el algoritmo especificado, se emitirá una advertencia, pero la ejecución continuará;
3.
establecerá el tamaño deseado del bloque y lo formateará como swap con systemd-makefs(8).

Las unidades path-to-mount-point.mount generadas dependen de systemd-zram-setup@zramN.service. El efecto es similar a lo que ocurre con las unidades de swap, pero por supuesto se formatean con un sistema de archivos.

Cuando la unidad se detiene, el dispositivo zram se reinicia, liberando memoria y permitiendo que el dispositivo sea reutilizado.

zram-generator implementa systemd.generator(7).

Aplicación de cambios de configuración

Este generador se invoca al inicio del sistema, y los dispositivos que configura se crearán también muy pronto, por lo que la forma más fácil de aplicar cambios de configuración es simplemente reiniciar la máquina.

Sin embargo, a veces puede ser útil añadir nuevos dispositivos o aplicar cambios de configuración en tiempo de ejecución. Aplicar nueva configuración significa reiniciar las unidades, y eso a su vez significa recrear los dispositivos zram. Esto significa que los sistemas de archivos se desmontan temporalmente y su contenido se pierde, y las páginas se mueven del dispositivo de swap comprimido a otra memoria. Si esto es aceptable, se puede usar systemctl restart systemd-zram-setup@zramN o systemctl restart systemd-zram-setup@* para recrear un dispositivo específico o todos los dispositivos configurados. (Si el dispositivo no existía, restart lo creará.) Si la forma en que se utiliza el dispositivo (por ejemplo, el punto de montaje o el tipo de sistema de archivos) se cambia, se debe llamar primero a systemctl daemon-reload para recrear las unidades de systemd. Si un dispositivo o punto de montaje se elimina de la configuración, la unidad debe detenerse antes de llamar a daemon-reload. De lo contrario, systemd no sabrá cómo detener la unidad correctamente.
