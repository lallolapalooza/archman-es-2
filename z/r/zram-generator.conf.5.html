ZRAM-GENERATOR.CONF(5) Manual de Formatos de Archivo ZRAM-GENERATOR.CONF(5)

NOMBRE

zram-generator.conf - Generador de unidades systemd para dispositivos zram swap (configuración)

SINOPSIS

/usr/lib/systemd/zram-generator.conf
/usr/local/lib/systemd/zram-generator.conf
/etc/systemd/zram-generator.conf
/run/systemd/zram-generator.conf

/usr/lib/systemd/zram-generator.conf.d/*.conf
/usr/local/lib/systemd/zram-generator.conf.d/*.conf
/etc/systemd/zram-generator.conf.d/*.conf
/run/systemd/zram-generator.conf.d/*.conf

DESCRIPCIÓN

Estos archivos configuran los dispositivos creados por zram-generator(8). Consulte systemd.syntax(5) para una descripción general de la sintaxis.

DIRECTORIOS DE CONFIGURACIÓN Y PRECEDENCIA

La configuración predeterminada no especifica ningún dispositivo. Consulte /usr/share/zram-generator/zram-generator.conf.example para un archivo de configuración de ejemplo.

Cuando los paquetes necesitan personalizar la configuración, pueden instalar fragmentos de configuración en /usr/lib/systemd/zram-generator.conf.d/. Los archivos en /etc/ están reservados para el administrador local, quien puede usar esta lógica para anular los archivos de configuración instalados por los paquetes del proveedor. El archivo de configuración principal se lee antes que cualquiera de los directorios de configuración y tiene la menor precedencia; las entradas en un archivo de cualquier directorio de configuración anulan las entradas en el archivo de configuración único. Los archivos en los subdirectorios de configuración *.conf.d/ se ordenan por su nombre de archivo en orden lexicográfico, independientemente de en qué subdirectorios residan. Cuando varios archivos especifican la misma opción, para opciones que solo aceptan un único valor, la entrada en el archivo con el nombre lexicográficamente más reciente tiene precedencia. Se recomienda prefijar todos los nombres de archivo en esos subdirectorios con un número de dos dígitos y un guion, para simplificar el orden de los archivos.

Para deshabilitar un archivo de configuración proporcionado por el proveedor, la forma recomendada es colocar un enlace simbólico a /dev/null en el directorio de configuración en /etc/, con el mismo nombre de archivo que el archivo de configuración del proveedor.

El generador entiende la siguiente opción en la línea de comandos del kernel: systemd.zram[=0|1]. Cuando se especifica con un argumento verdadero (o sin argumento), se creará el dispositivo zram0. Se aplican las opciones predeterminadas, pero pueden ser anuladas por la configuración en disco si está presente. Cuando se especifica con un argumento falso, el generador no creará dispositivos zram. Esta opción, por lo tanto, tiene mayor prioridad que los archivos de configuración.

OPCIONES

Cada dispositivo se configura de forma independiente en su sección [zramN], donde N es un entero no negativo. La sección global puede contener DIRECTIVAS. Se ignoran otras secciones.

Los dispositivos con un tamaño final de 0 serán descartados.

•
host-memory-limit=
Establece el límite superior de RAM total utilizable (definido por MemTotal en /proc/meminfo, ver proc(5)) por encima del cual el dispositivo no se creará.
Esto toma un número no negativo, representando ese límite en megabytes, o la cadena literal none, que se puede usar para anular un límite establecido anteriormente.
Por defecto es none.
•
zram-size=
Establece el tamaño del dispositivo zram como una función de MemTotal, disponible como la variable ram. Las DIRECTIVAS adicionales pueden proporcionar variables.
Se admiten operadores aritméticos (^%/*-+), e, π, sufijos SI, log(), int(), ceil(), floor(), round(), abs(), min(), max() y funciones trigonométricas.
Por defecto es min(ram / 2, 4096).
•
zram-resident-limit=
Establece el límite máximo de memoria residente del dispositivo zram (o 0 para ningún límite) como una función de MemTotal, disponible como la variable ram.
Mismo formato que zram-size. Por defecto es 0.
•
compression-algorithm=
Especifica el algoritmo utilizado para comprimir el dispositivo zram.
Esto toma una cadena de lista separada por espacios, representando los algoritmos a usar y parámetros entre paréntesis.
Consulte /sys/block/zram0/comp_algorithm (y .../recomp_algorithm) para ver una lista de algoritmos de compresión cargados actualmente, pero tenga en cuenta que se pueden cargar otros adicionales bajo demanda.
Si no se establece, no se configurará ninguno y se usará el valor predeterminado del kernel.
Si se proporcionan más de uno, y la recompresión está habilitada en el kernel, los subsiguientes se establecerán como los algoritmos de recompresión, con prioridad decreciente.
Si un algoritmo de compresión va seguido de una lista de parámetros entre paréntesis y separados por comas, estos se pasarán a .../algorithm_params (y .../recompress). Una lista de parámetros entre paréntesis sin un algoritmo de compresión se establece como los parámetros globales de recompresión.
•
writeback-device=
Escribe páginas incompresibles, para las cuales no se obtuvo ganancia, al dispositivo especificado bajo presión de memoria. Esto corresponde al parámetro /sys/block/zramX/backing_dev.
Toma una ruta a un dispositivo de bloque, como /dev/disk/by-partuuid/2d54ffa0-01 o /dev/zvol/tarta-zoot/swap-writeback.
Si no se establece, no se utiliza ninguno y las páginas incompresibles se mantienen en RAM.
•
swap-priority=
Controla la prioridad swap relativa, un valor entre -1 y 32767. Números más altos indican mayor prioridad.
Si no se establece, se usa 100.
•
mount-point=
Formatea el dispositivo con un sistema de archivos (no como swap) y monta este sistema de archivos sobre el directorio especificado. Cuando ni esta opción ni fs-type= se especifican, el dispositivo se formateará como swap.
Tenga en cuenta que el dispositivo es temporal: el contenido se destruirá automáticamente después de desmontar el sistema de archivos (para liberar la memoria de respaldo).
•
fs-type=
Especifica cómo se formateará el dispositivo. El valor predeterminado es ext2 si se especifica mount-point, y swap en caso contrario. (Efectivamente, el dispositivo se formateará como swap, si no se especifican ni fs-type= ni mount-point=).
Tenga en cuenta que el dispositivo es temporal: el contenido se destruirá automáticamente después de desmontar el sistema de archivos (para liberar la memoria de respaldo).
Consulte también systemd-makefs(8).
•
options=
Establece las opciones de montaje o swapon. La disponibilidad depende de fs-type.
Por defecto es discard.

DIRECTIVAS

La sección global (antes de cualquier encabezado de sección) puede contener directivas en la siguiente forma:

•
set!variable=programa
programa es ejecutado por el shell como si fuera system(3), su flujo de salida estándar se analiza como una expresión aritmética (como zram-size/zram-resident-limit), luego el resultado se guarda en variable, utilizable en set!s y zram-sizes/zram-resident-limits posteriores.

zram-generator.conf(5) — zram-generator developers — December 2024

NOMBRE

zram-generator.conf — zram-configuración del generador

SINOPSIS


/etc/systemd/zram-generator.conf
/usr/local/lib/systemd/zram-generator.conf
/etc/systemd/zram-generator.d/*.conf
/usr/local/lib/systemd/zram-generator.d/*.conf

DESCRIPCIÓN

El archivo de configuración zram-generator.conf se utiliza para configurar el generador de dispositivos zram.

Los archivos de configuración se analizan en el orden especificado en la sección DIRECTORIOS DE CONFIGURACIÓN Y PRECEDENCIA. Los valores de las directivas sólo se leerán del primer archivo que las contenga.

La configuración se divide en secciones marcadas con [zram-generator].

DIRECTORIOS DE CONFIGURACIÓN Y PRECEDENCIA

El archivo de configuración principal y los fragmentos de configuración se buscan en los siguientes directorios, en orden:

1.
/etc/systemd/zram-generator.conf
2.
/usr/local/lib/systemd/zram-generator.conf
3.
/etc/systemd/zram-generator.d/
4.
/usr/local/lib/systemd/zram-generator.d/

Los archivos de configuración deben tener extensiones .conf. Se analizan en orden alfabético por nombre de archivo dentro de cada directorio.

Si un archivo de configuración no se encuentra en el sistema, se utiliza la configuración predeterminada.

OPCIONES

Las siguientes opciones pueden configurarse en la sección [zram-generator]:

•
host-memory-limit=
Especifica el tamaño máximo de RAM del host que se va a utilizar para zram. Si no se especifica, se utiliza toda la RAM del host.
Esto toma un número no negativo, representando el límite en megabytes, o la cadena literal none, que puede ser utilizada para anular un límite establecido previamente.
•
zram-size=
Especifica el tamaño de los dispositivos zram. Esto puede ser una expresión aritmética que haga referencia a la memoria RAM del host (ram).
Por ejemplo, zram-size = ram / 2 establecería el tamaño de zram a la mitad de la RAM del host.
El valor predeterminado es 0.5 del total de RAM utilizable del host, hasta un máximo de 4GB.
•
compression-algorithm=
Especifica el algoritmo de compresión a utilizar para los dispositivos zram. Los algoritmos admitidos dependen de la compilación del kernel. Los valores comunes incluyen lz4, zstd, lzo y deflate.
Si no se especifica, se utiliza el algoritmo predeterminado del kernel.
•
swap-priority=
Especifica la prioridad de las entradas de swap de zram. Las prioridades más altas se prefieren sobre las más bajas. Los valores van de 0 a 100.
El valor predeterminado es 100.
•
swap-makedirs=
Si está establecido en yes, se crearán directorios para el swap de zram.
El valor predeterminado es no.
•
swap-label=
Especifica una etiqueta para las entradas de swap de zram.
•
swap-options=
Especifica opciones adicionales para las entradas de swap de zram.

DIRECTIVAS

Las siguientes directivas pueden utilizarse en el archivo de configuración:

zram-size=expresión
Define el tamaño de los dispositivos zram como una expresión aritmética que hace referencia a la memoria RAM del host (ram).

Ejemplo: zram-size = min(ram, 4096) + max(ram - 4096, 0) / 2 creará un dispositivo zram cuyo tamaño es igual a la RAM hasta 4GB, y la mitad de la RAM por encima de 4GB.

zram-device=ruta
Especifica la ruta de acceso del dispositivo zram. Si no se especifica, se utiliza la ruta predeterminada (/dev/zram0).

VARIABLES DE ENTORNO

Las siguientes variables de entorno pueden ser utilizadas por el lenguaje de expresiones zram-size:

ram
Tamaño total de RAM utilizable del host en MiB.

Se pueden utilizar las siguientes funciones:

min(arg1, arg2)
Devuelve el menor de los dos argumentos.
max(arg1, arg2)
Devuelve el mayor de los dos argumentos.

OPCIONES OBSOLETAS

•
memory-limit=
Alias de compatibilidad para host-memory-limit.
•
zram-fraction=
Define el factor de escala del tamaño del dispositivo zram en relación con la RAM utilizable total.
Toma un número de punto flotante no negativo que representa ese factor.
Se establece como valor predeterminado en 0.5. Establecer esto o max-zram-size anula zram-size.
•
max-zram-size=
Establece el límite para el tamaño del dispositivo zram obtenido por zram-fraction.
Toma un número no negativo, representando ese límite en megabytes, o la cadena literal none, que puede ser utilizada para anular un límite establecido previamente.
Se establece como valor predeterminado en 4096. Establecer esto o zram-fraction anula zram-size.
