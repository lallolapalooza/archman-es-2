zresample(1) COMANDOS DE USUARIO zresample(1)

NOMBRE

zresample - remuestrea y cambia el formato de muestra de archivos de audio

SINOPSIS

zresample [opciones] archivo-entrada archivo-salida

DESCRIPCIÓN

zresample copia un archivo de audio, cambiando la frecuencia de muestreo y/o el formato de muestra. Para salida de 16 bits también puede realizar dithering en la señal de audio. La entrada puede ser cualquier archivo de audio legible por la biblioteca libsndfile. El tipo de archivo de salida es WAV, WAVEX, CAF, AIFF o FLAC.

OPCIONES

--help
Muestra un texto de ayuda breve.
--rate frecuencia-de-muestra
Establece la frecuencia de muestreo de salida. Zresample utiliza la biblioteca zita-resampler, lo que significa que no todas las combinaciones de frecuencia de muestreo de entrada/salida serán aceptadas. La relación de remuestreo debe ser reducible a una fracción a/b con ambos a y b menores o iguales a 1000.
--gain ganancia
Ganancia en dB, por defecto cero.

Tipo de archivo de salida

--wav
Produce un archivo WAV, o para más de 2 canales, un archivo WAVEX. Esta es la opción por defecto.
--amb
Produce un archivo WAVEX con el GUID Ambisonic. Dichos archivos deben tener la extensión de nombre de archivo .amb.
--caf
Produce un archivo Core Audio.
--aiff
Produce un archivo AIFF.
--flac
Produce un archivo FLAC.

Formato de muestra de salida

--16bit
El formato de muestra de salida es de 16 bits con signo. Esta opción también habilita el uso de dithering, descrito a continuación.
--24bit
El formato de muestra de salida es de 24 bits. Esta es la opción por defecto.
--float
El formato de muestra de salida es de punto flotante de 32 bits.

Dithering

--rec
Añade ruido de dithering blanco con distribución rectangular. Esta es la mejor opción si los datos de salida van a ser procesados de nuevo, pero en ese caso sería aconsejable usar 24 bits o flotante.
--tri
Añade ruido filtrado con distribución triangular. Comparado con el dither rectangular, esto reduce la densidad del ruido en el rango de frecuencias bajas.
--lips
Esto utiliza el filtro de retroalimentación de error óptimo descrito por Stanley Lipschitz. Se recomienda si la salida es el formato de distribución final, por ejemplo, para un CD.

Temporización

--pad
Inserta muestras de entrada de valor cero al principio y al final para que la salida incluya la respuesta completa del filtro simétrico incluso para las muestras de principio y fin.

ESTADO DE SALIDA

Cero en caso de no haber errores, distinto de cero en caso contrario.
