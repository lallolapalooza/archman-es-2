subrutina zrot (n, cx, incx, cy, incy, c, s)
ZROT aplica una rotación de plano con coseno real y seno complejo a un par de vectores complejos.

Documentación de Función/Subrutina

subrutina zrot (entero n, complejo*16, dimensión( * ) cx, entero incx, complejo*16, dimensión( * ) cy, entero incy, doble precisión c, complejo*16 s)

ZROT aplica una rotación de plano con coseno real y seno complejo a un par de vectores complejos.

Propósito:

!>
!> ZROT aplica una rotación de plano, donde el cos (C) es real y el
!> sin (S) es complejo, y los vectores CX y CY son complejos.
!>

Parámetros

N 
!>          N es ENTERO
!>          El número de elementos en los vectores CX y CY.
!>

CX

!>          CX es un array de COMPLEJO*16, dimensión (N)
!>          En la entrada, el vector X.
!>          En la salida, CX se sobrescribe con C*X + S*Y.
!>

INCX

!>          INCX es ENTERO
!>          El incremento entre valores sucesivos de CX.  INCX <> 0.
!>

CY

!>          CY es un array de COMPLEJO*16, dimensión (N)
!>          En la entrada, el vector Y.
!>          En la salida, CY se sobrescribe con -CONJG(S)*X + C*Y.
!>

INCY

!>          INCY es ENTERO
!>          El incremento entre valores sucesivos de CY.  INCX <> 0.
!>

C

!>          C es DOBLE PRECISIÓN
!>

S

!>          S es COMPLEJO*16
!>          C y S definen una rotación
!>             [  C          S  ]
!>             [ -conjg(S)   C  ]
!>          donde C*C + S*CONJG(S) = 1.0.
!>
