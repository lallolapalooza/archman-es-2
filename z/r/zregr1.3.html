subrutina zregr1 (character*1 trans, integer m, integer n, logical ly, integer kl, integer ku, complex*16 alpha, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( * ) x, integer incx, complex*16 beta, complex*16, dimension( * ) y, integer incy, complex*16, dimension( * ) ys)

Este es un registro de prueba de nivel 2 de BLAS complejo.

Propósito:

  La subrutina ZREGR1 calcula el error entre los resultados de las
  operaciones de matriz-vector del nivel 2 BLAS y los resultados
  calculados por ZGERC, ZGERU, ZHER, ZHPR, ZHER2 y ZHPR2.

Argumentos:

  trans   (input) CHARACTER*1
          Especifica la operación a realizar.
          'N' o 'n': A*x = y
          'T' o 't': A**T*x = y
          'C' o 'c': A**H*x = y
          (donde A**H es la transpuesta conjugada de A)

  m       (input) INTEGER
          El número de filas de la matriz A.

  n       (input) INTEGER
          El número de columnas de la matriz A.

  ly      (input) LOGICAL
          Si es .TRUE., se generan y prueban los resultados de la subrutina
          ZGERC/ZGERU/ZHER/ZHPR/ZHER2/ZHPR2. De lo contrario, no se genera
          ningún resultado de subrutina ZGERC/ZGERU/ZHER/ZHPR/ZHER2/ZHPR2.

  kl      (input) INTEGER
          Si trans = 'N' o 'n', kl es el número de subdiagonales en A.
          Si trans = 'T' o 't' o 'C' o 'c', kl es el número de subdiagonales en A**T.

  ku      (input) INTEGER
          Si trans = 'N' o 'n', ku es el número de superdiagonales en A.
          Si trans = 'T' o 't' o 'C' o 'c', ku es el número de superdiagonales en A**T.

  alpha   (input) COMPLEX*16
          Escalar alfa.

  a       (input) COMPLEX*16 array, dimension (lda,*)
          Matriz A. El tamaño depende de kl y ku.

  lda     (input) INTEGER
          El tamaño principal de la matriz A.

  x       (input) COMPLEX*16 array, dimension (*)
          Vector x de tamaño n.

  incx    (input) INTEGER
          Factor de incremento para x.

  beta    (input) COMPLEX*16
          Escalar beta.

  y       (input) COMPLEX*16 array, dimension (*)
          Vector y. El tamaño depende de incy.

  incy    (input) INTEGER
          Factor de incremento para y.

  ys      (input) COMPLEX*16 array, dimension (*)
          Vector y escalado. Usado para almacenar la salida de las subrutinas ZGERC/ZGERU/ZHER/ZHPR/ZHER2/ZHPR2.
