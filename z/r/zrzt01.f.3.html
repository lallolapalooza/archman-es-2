Documentación de función/subrutina

función de precisión doble zrzt01 (m entero, n entero, complex*16, dimension( lda, * ) a, complex*16, dimension( lda, * ) af, lda entero, tau complex*16, dimension( * ) work, lwork entero)

ZRZT01

Propósito:

!>
!> ZRZT01 devuelve
!>      || A - R*Q || / ( M * eps * ||A|| )
!> para una A trapezoidal superior que fue factorizada con ZTZRZF.
!>

Parámetros

M 
!>          M es ENTERO
!>          El número de filas de las matrices A y AF.
!>

N

!>          N es ENTERO
!>          El número de columnas de las matrices A y AF.
!>

A

!>          A es un array COMPLEX*16, dimension (LDA,N)
!>          La matriz trapezoidal superior original M por N, A.
!>

AF

!>          AF es un array COMPLEX*16, dimension (LDA,N)
!>          La salida de ZTZRZF para la matriz de entrada A.
!>          El triángulo inferior no se referencia.
!>

LDA

!>          LDA es ENTERO
!>          La dimensión principal de los arrays A y AF.
!>

TAU

!>          TAU es un array COMPLEX*16, dimension (M)
!>          Detalles de las transformaciones de Householder devueltas por
!>          ZTZRZF.
!>

WORK

!>          WORK es un array COMPLEX*16, dimension (LWORK)
!>

LWORK

!>          LWORK es ENTERO
!>          La longitud del array WORK. LWORK >= m*n + m.
!>
