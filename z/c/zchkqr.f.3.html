Propósito:

!>
!> ZCHKQR prueba ZGEQRF, ZUNGQR y ZUNMQR.
!>

Parámetros

DOTYPE 
!>          DOTYPE es un array LOGICAL, dimensión (NTYPES)
!>          Los tipos de matrices a usar para las pruebas. Las matrices de tipo j
!>          (para 1 <= j <= NTYPES) se usan para las pruebas si DOTYPE(j) =
!>          .TRUE.; si DOTYPE(j) = .FALSE., entonces el tipo j no se usa.
!>

NM

!>          NM es INTEGER
!>          El número de valores de M contenidos en el vector MVAL.
!>

MVAL

!>          MVAL es un array INTEGER, dimensión (NM)
!>          Los valores de la dimensión de fila M de la matriz.
!>

NN

!>          NN es INTEGER
!>          El número de valores de N contenidos en el vector NVAL.
!>

NVAL

!>          NVAL es un array INTEGER, dimensión (NN)
!>          Los valores de la dimensión de columna N de la matriz.
!>

NNB

!>          NNB es INTEGER
!>          El número de valores de NB y NX contenidos en los
!>          vectores NBVAL y NXVAL. Los parámetros de bloqueo se usan
!>          en pares (NB,NX).
!>

NBVAL

!>          NBVAL es un array INTEGER, dimensión (NNB)
!>          Los valores del tamaño de bloque NB.
!>

NXVAL

!>          NXVAL es un array INTEGER, dimensión (NNB)
!>          Los valores del punto de cruce NX.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de vectores del lado derecho a generar para
!>          cada sistema lineal.
!>

THRESH

!>          THRESH es DOUBLE PRECISION
!>          El valor umbral para las relaciones de prueba. Un resultado se
!>          incluye en el archivo de salida si RESULT >= THRESH. Para que
!>          se imprima cada relación de prueba, use THRESH = 0.
!>

TSTERR

!>          TSTERR es LOGICAL
!>          Indicador que señala si se deben probar las salidas de error.
!>

NMAX

!>          NMAX es INTEGER
!>          El valor máximo permitido para M o N, usado para dimensionar
!>          los arrays de trabajo.
!>

A

!>          A es un array COMPLEX*16, dimensión (NMAX*NMAX)
!>

AF

!>          AF es un array COMPLEX*16, dimensión (NMAX*NMAX)
!>

AQ

!>          AQ es un array COMPLEX*16, dimensión (NMAX*NMAX)
!>

AR

!>          AR es un array COMPLEX*16, dimensión (NMAX*NMAX)
!>

AC

!>          AC es un array COMPLEX*16, dimensión (NMAX*NMAX)
!>

B

!>          B es un array COMPLEX*16, dimensión (NMAX*NRHS)
!>

X

!>          X es un array COMPLEX*16, dimensión (NMAX*NRHS)
!>

XACT

!>          XACT es un array COMPLEX*16, dimensión (NMAX*NRHS)
!>

TAU

!>          TAU es un array COMPLEX*16, dimensión (NMAX)
!>

WORK

!>          WORK es un array COMPLEX*16, dimensión (NMAX*NMAX)
!>

RWORK

!>          RWORK es un array DOUBLE PRECISION, dimensión (NMAX)
!>

IWORK

!>          IWORK es un array INTEGER, dimensión (NMAX)
!>

NOUT

!>          NOUT es INTEGER
!>          El número de unidad para la salida.
!>
