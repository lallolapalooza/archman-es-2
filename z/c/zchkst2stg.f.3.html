ZCHKST2STG

Propósito:

!>
!> ZCHKST2STG  verifica las rutinas del problema de valores propios Hermíticos
!> utilizando las técnicas de reducción de 2 etapas. Dado que la generación
!> de Q o los vectores no está disponible en esta versión, solo
!> comparamos el valor propio resultante al usar la reducción de 2 etapas con
!> la considerada como referencia utilizando la reducción estándar de 1 etapa
!> ZHETRD. Para ello, llamamos al ZHETRD estándar y calculamos D1 usando
!> DSTEQR, luego llamamos al ZHETRD_2STAGE de 2 etapas con Superior e Inferior
!> y calculamos D2 y D3 usando DSTEQR y luego reemplazamos las pruebas
!> 3 y 4 por las pruebas 11 y 12. Las pruebas 1 y 2 permanecen para verificar que
!> los resultados de 1 etapa están bien y se puede confiar en ellos.
!> Esta rutina de prueba convergerá a ZCHKST en la próxima
!> versión cuando se implementen los vectores y la generación de Q.
!>
!>    ZHETRD factoriza A como  U S U* , donde * significa transpuesta conjugada,
!>    S es real simétrica tridiagonal, y U es unitaria.
!>    ZHETRD puede usar solo la parte inferior o solo la parte superior
!>    de A; ZCHKST2STG verifica ambos casos.
!>    U se representa como un producto de transformaciones de Householder
!>    cuyos vectores se almacenan en las primeras
!>    n-1 columnas de V, y cuyos factores de escala están en TAU.
!>
!>    ZHPTRD hace lo mismo que ZHETRD, excepto que A y V se almacenan
!>    en formato  .
!>
!>    ZUNGTR construye la matriz U a partir del contenido de V y TAU.
!>
!>    ZUPGTR construye la matriz U a partir del contenido de VP y TAU.
!>
!>    ZSTEQR factoriza S como  Z D1 Z* , donde Z es la matriz
!>    unitaria de autovectores y D1 es una matriz diagonal con
!>    los autovalores en la diagonal.  D2 es la matriz de
!>    autovalores calculada cuando Z no se calcula.
!>
!>    DSTERF calcula D3, la matriz de autovalores, por el
!>    método PWK, que no produce autovectores.
!>
!>    ZPTEQR factoriza S como  Z4 D4 Z4* , para una
!>    matriz tridiagonal Hermítica positiva definida.
!>    D5 es la matriz de autovalores calculada cuando Z no se
!>    calcula.
!>
!>    DSTEBZ calcula autovalores seleccionados.  WA1, WA2, y
!>    WA3 denotarán autovalores calculados con alta
!>    precisión absoluta, con diferentes opciones de rango.
!>    WR denotará autovalores calculados con alta precisión relativa.
!>
!>    ZSTEIN calcula Y, los autovectores de S, dados los
!>    autovalores.
!>
!>    ZSTEDC factoriza S como Z D1 Z* , donde Z es la unitaria
!>    matriz de autovectores y D1 es una matriz diagonal con
!>    los autovalores en la diagonal (opción 'I'). También
!>    puede actualizar una matriz unitaria de entrada, generalmente la salida
!>    de ZHETRD/ZUNGTR o ZHPTRD/ZUPGTR (opción 'V'). También
!>    puede calcular solo autovalores (opción 'N').
!>
!>    ZSTEMR factoriza S como Z D1 Z* , donde Z es la unitaria
!>    matriz de autovectores y D1 es una matriz diagonal con
!>    los autovalores en la diagonal (opción 'I').  ZSTEMR
!>    utiliza la Representación Relativamente Robusta siempre que sea posible.
!>
!> Cuando se llama a ZCHKST2STG, un número de matrices de tamaño () y
!> un número de matrices de tipo se especifican. Para cada tamaño ()
!> y cada tipo de matriz, se generará y utilizará una matriz
!> para probar las rutinas de autovalores Hermíticos. Para cada matriz, se
!> realizarán una serie de pruebas:
!>
!> (1)     | A - V S V* | / ( |A| n ulp ) ZHETRD( UPLO='U', ... )
!>
!> (2)     | I - UV* | / ( n ulp )        ZUNGTR( UPLO='U', ... )
!>
!> (3)     | A - V S V* | / ( |A| n ulp ) ZHETRD( UPLO='L', ... )
!>         reemplazado por | D1 - D2 | / ( |D1| ulp ) donde D1 es la
!>         matriz de autovalores calculada usando S y D2 es la
!>         matriz de autovalores calculada usando S_2stage la salida de
!>         ZHETRD_2STAGE(, ,....). D1 y D2 se calculan
!>         vía DSTEQR('N',...)
!>
!> (4)     | I - UV* | / ( n ulp )        ZUNGTR( UPLO='L', ... )
!>         reemplazado por | D1 - D3 | / ( |D1| ulp ) donde D1 es la
!>         matriz de autovalores calculada usando S y D3 es la
!>         matriz de autovalores calculada usando S_2stage la salida de
!>         ZHETRD_2STAGE(, ,....). D1 y D3 se calculan
!>         vía DSTEQR('N',...)
!>
!> (5-8)   Igual que 1-4, pero para ZHPTRD y ZUPGTR.
!>
!> (9)     | S - Z D Z* | / ( |S| n ulp ) ZSTEQR('V',...)
!>
!> (10)    | I - ZZ* | / ( n ulp )        ZSTEQR('V',...)
!>
!> (11)    | D1 - D2 | / ( |D1| ulp )        ZSTEQR('N',...)
!>
!> (12)    | D1 - D3 | / ( |D1| ulp )        DSTERF
!>
!> (13)    0 si los autovalores verdaderos (calculados por conteo de Sturm)
!>         de S están dentro de THRESH de
!>         aquellos en D1.  2*THRESH si no lo están.  (Probado usando
!>         DSTECH)
!>
!> Para S definida positiva,
!>
!> (14)    | S - Z4 D4 Z4* | / ( |S| n ulp ) ZPTEQR('V',...)
!>
!> (15)    | I - Z4 Z4* | / ( n ulp )        ZPTEQR('V',...)
!>
!> (16)    | D4 - D5 | / ( 100 |D4| ulp )       ZPTEQR('N',...)
!>
!> Cuando S también es diagonalmente dominante por el factor gamma < 1,
!>
!> (17)    max | D4(i) - WR(i) | / ( |D4(i)| omega ) ,
!>          i
!>         omega = 2 (2n-1) ULP (1 + 8 gamma**2) / (1 - gamma)**4
!>                                              DSTEBZ( 'A', 'E', ...)
!>
!> (18)    | WA1 - D3 | / ( |D3| ulp )          DSTEBZ( 'A', 'E', ...)
!>
!> (19)    ( max { min | WA2(i)-WA3(j) | } +
!>            i     j
!>           max { min | WA3(i)-WA2(j) | } ) / ( |D3| ulp )

Parámetros

NSIZES 
!>          NSIZES es INTEGER
!>          El número de tamaños de matrices a utilizar. Si es cero,
!>          ZCHKST2STG no hace nada. Debe ser al menos cero.
!>

NN

!>          NN es un array INTEGER, de dimensión (NSIZES)
!>          Un array que contiene los tamaños a utilizar para las matrices.
!>          Los valores cero serán omitidos. Los valores deben ser al menos
!>          cero.
!>

NTYPES

!>          NTYPES es INTEGER
!>          El número de elementos en DOTYPE. Si es cero, ZCHKST2STG
!>          no hace nada. Debe ser al menos cero. Si es MAXTYP+1
!>          y NSIZES es 1, entonces se define un tipo adicional, MAXTYP+1,
!>          que consiste en usar la matriz que esté en A. Esto
!>          solo es útil si DOTYPE(1:MAXTYP) es .FALSE. y
!>          DOTYPE(MAXTYP+1) es .TRUE. .
!>

DOTYPE

!>          DOTYPE es un array LOGICAL, de dimensión (NTYPES)
!>          Si DOTYPE(j) es .TRUE., entonces para cada tamaño en NN se generará
!>          una matriz de ese tamaño y de tipo j.
!>          Si NTYPES es menor que el número máximo de tipos
!>          definidos (PARAMETER MAXTYP), entonces los tipos NTYPES+1 hasta
!>          MAXTYP no se generarán. Si NTYPES es mayor
!>          que MAXTYP, DOTYPE(MAXTYP+1) hasta DOTYPE(NTYPES)
!>          serán ignorados.
!>

ISEED

!>          ISEED es un array INTEGER, de dimensión (4)
!>          A la entrada ISEED especifica la semilla del generador de números
!>          aleatorios. Los elementos del array deben estar entre 0 y 4095;
!>          si no, se reducirán módulo 4096. Además, ISEED(4) debe
!>          ser impar. El generador de números aleatorios utiliza una secuencia
!>          congruencial lineal limitada a enteros pequeños, y por lo tanto
!>          debería producir números aleatorios independientes de la máquina. Los
!>          valores de ISEED se modifican a la salida y se pueden usar en la
!>          siguiente llamada a ZCHKST2STG para continuar la misma secuencia de
!>          números aleatorios.
!>

THRESH

!>          THRESH es DOUBLE PRECISION
!>          Una prueba se contará como un error si el error, calculado como
!>          se describe arriba, excede THRESH. Tenga en cuenta que el error
!>          se escala para ser O(1), por lo que THRESH debería ser un múltiplo
!>          razonablemente pequeño de 1, por ejemplo, 10 o 100. En particular,
!>          no debe depender de la precisión (simple o doble)
!>          ni del tamaño de la matriz. Debe ser al menos cero.
!>

NOUNIT

!>          NOUNIT es INTEGER
!>          El número de unidad FORTRAN para imprimir mensajes de error
!>          (por ejemplo, si una rutina devuelve IINFO distinto de 0.)
!>

A

!>          A es un array COMPLEX*16 de
!>                                  dimensión ( LDA , max(NN) )
!>          Se utiliza para almacenar la matriz cuyos valores propios se van a
!>          calcular. A la salida, A contiene la última matriz utilizada.
!>
!> LDA es INTEGER !> La dimensión principal de A. Debe ser !> al menos 1 y al menos max( NN ). !>

AP

!>          AP es un array COMPLEX*16 de
!>                      dimensión( max(NN)*max(NN+1)/2 )
!>          La matriz A almacenada en formato empaquetado.
!>

SD

!>          SD es un array DOUBLE PRECISION de
!>                             dimensión( max(NN) )
!>          La diagonal de la matriz tridiagonal calculada por ZHETRD.
!>          A la salida, SD y SE contienen la forma tridiagonal de
!>          la matriz en A.
!>

SE

!>          SE es un array DOUBLE PRECISION de
!>                             dimensión( max(NN) )
!>          La subdiagonal de la matriz tridiagonal calculada por
!>          ZHETRD. A la salida, SD y SE contienen la forma tridiagonal de
!>          la matriz en A.
!>

D1

!>          D1 es un array DOUBLE PRECISION de
!>                             dimensión( max(NN) )
!>          Los valores propios de A, calculados por ZSTEQR simultáneamente
!>          con Z. A la salida, los valores propios en D1 corresponden con la
!>          matriz en A.
!>

D2

!>          D2 es un array DOUBLE PRECISION de
!>                             dimensión( max(NN) )
!>          Los valores propios de A, calculados por ZSTEQR si Z no se
!>          calcula. A la salida, los valores propios en D2 corresponden con la
!>          matriz en A.
!>

D3

!>          D3 es un array DOUBLE PRECISION de
!>                             dimensión( max(NN) )
!>          Los valores propios de A, calculados por DSTERF. A la salida, los
!>          valores propios en D3 corresponden con la matriz en A.
!>

D4

!>          D4 es un array DOUBLE PRECISION de
!>                             dimensión( max(NN) )
!>          Los valores propios de A, calculados por ZPTEQR(V).
!>          ZPTEQR factoriza S como Z4 D4 Z4*
!>          A la salida, los valores propios en D4 corresponden con la matriz en A.
!>

D5

!>          D5 es un array DOUBLE PRECISION de
!>                             dimensión( max(NN) )
!>          Los valores propios de A, calculados por ZPTEQR(N)
!>          cuando Z no se calcula. A la salida, los
!>          valores propios en D4 corresponden con la matriz en A.
!>

WA1

!>          WA1 es un array DOUBLE PRECISION de
!>                             dimensión( max(NN) )
!>          Todos los valores propios de A, calculados con alta
!>          precisión absoluta, con diferentes opciones de rango.
!>          calculados por DSTEBZ.
!>

WA2

!>          WA2 es un array DOUBLE PRECISION de
!>                             dimensión( max(NN) )
!>          Valores propios seleccionados de A, calculados con alta
!>          precisión absoluta, con diferentes opciones de rango.
!>          calculados por DSTEBZ.
!>          Se eligen valores aleatorios para IL y IU, y se solicitan los
!>          valores propios del IL-ésimo al IU-ésimo.
!>

WA3

!>          WA3 es un array DOUBLE PRECISION de
!>                             dimensión( max(NN) )
!>          Valores propios seleccionados de A, calculados con alta
!>          precisión absoluta, con diferentes opciones de rango.
!>          calculados por DSTEBZ.
!>          Se determinan los valores VL y VU del IL-ésimo y IU-ésimo
!>          valor propio y se solicitan todos los valores propios en este rango.
!>

WR

!>          WR es un array DOUBLE PRECISION de
!>                             dimensión( max(NN) )
!>          Todos los valores propios de A, calculados con alta
!>          precisión absoluta, con diferentes opciones.
!>          calculados por DSTEBZ.
!>

U
