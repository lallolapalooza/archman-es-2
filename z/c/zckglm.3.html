Documentación de Función/Subrutina

subrutina zckglm (nn entero, entero, dimension(* ) nval, entero, dimension(* ) mval, entero, dimension(* ) pval, nmats entero, entero, dimension(4 ) iseed, thresh precisión doble, nmax entero, complejo*16, dimension(* ) a, complejo*16, dimension(* ) af, complejo*16, dimension(* ) b, complejo*16, dimension(* ) bf, complejo*16, dimension(* ) x, complejo*16, dimension(* ) work, precisión doble, dimension(* ) rwork, nin entero, nout entero, info entero)

ZCKGLM

Propósito:

!>
!> ZCKGLM prueba ZGGGLM - subrutina para resolver el problema del modelo
!> lineal generalizado.
!>

Parámetros

NN 
!>          NN es ENTERO
!>          El número de valores de N, M y P contenidos en los vectores
!>          NVAL, MVAL y PVAL.
!>

NVAL

!>          NVAL es un array de ENTEROS, dimension (NN)
!>          Los valores de la dimensión de fila de la matriz N.
!>

MVAL

!>          MVAL es un array de ENTEROS, dimension (NN)
!>          Los valores de la dimensión de columna de la matriz M.
!>

PVAL

!>          PVAL es un array de ENTEROS, dimension (NN)
!>          Los valores de la dimensión de columna de la matriz P.
!>

NMATS

!>          NMATS es ENTERO
!>          El número de tipos de matrices a probar para cada combinación
!>          de dimensiones de matriz. Si NMATS >= NTYPES (el número máximo
!>          de tipos de matriz), entonces se generan todos los tipos diferentes
!>          para la prueba. Si NMATS < NTYPES, se lee otra línea de entrada
!>          para obtener los números de los tipos de matriz a utilizar.
!>

ISEED

!>          ISEED es un array de ENTEROS, dimension (4)
!>          En la entrada, la semilla del generador de números aleatorios. Los
!>          elementos del array deben estar entre 0 y 4095; de lo contrario,
!>          se reducirán módulo 4096, y ISEED(4) debe ser impar.
!>          En la salida, la siguiente semilla en la secuencia de números
!>          aleatorios después de que se hayan generado todas las matrices de prueba.
!>

THRESH

!>          THRESH es de PRECISIÓN DOBLE
!>          El valor umbral para las relaciones de prueba. Un resultado se
!>          incluye en el archivo de salida si RESID >= THRESH. Para que se
!>          imprima cada relación de prueba, use THRESH = 0.
!>

NMAX

!>          NMAX es ENTERO
!>          El valor máximo permitido para M o N, utilizado en la
!>          dimensionamiento de los arrays de trabajo.
!>

A

!>          A es un array de COMPLEJO*16, dimension (NMAX*NMAX)
!>

AF

!>          AF es un array de COMPLEJO*16, dimension (NMAX*NMAX)
!>

B

!>          B es un array de COMPLEJO*16, dimension (NMAX*NMAX)
!>

BF

!>          BF es un array de COMPLEJO*16, dimension (NMAX*NMAX)
!>

X

!>          X es un array de COMPLEJO*16, dimension (4*NMAX)
!>

RWORK

!>          RWORK es un array de PRECISIÓN DOBLE, dimension (NMAX)
!>

WORK

!>          WORK es un array de COMPLEJO*16, dimension (NMAX*NMAX)
!>

NIN

!>          NIN es ENTERO
!>          El número de unidad para la entrada.
!>

NOUT

!>          NOUT es ENTERO
!>          El número de unidad para la salida.
!>

INFO

!>          INFO es ENTERO
!>          = 0 :  salida exitosa
!>          > 0 :  Si ZLATMS devuelve un código de error, se devuelve su valor
!>                 absoluto.
!>
