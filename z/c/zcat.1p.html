ZCAT(1P) Manual del programador POSIX ZCAT(1P)

PROLOG

Esta página del manual forma parte del Manual del programador POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual de Linux correspondiente para conocer los detalles del comportamiento en Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

zcat — expandir y concatenar datos

SINOPSIS

zcat [archivo...]

DESCRIPCIÓN

La utilidad zcat escribirá en la salida estándar la forma descomprimida de los archivos que han sido comprimidos utilizando la utilidad compress. Es el equivalente de uncompress -c. Los archivos de entrada no se ven afectados.

OPCIONES

Ninguna.

𝙊PERANDOS

Se admitirá el siguiente operando:

archivo
La ruta de un archivo procesado previamente por la utilidad compress. Si archivo ya tiene el sufijo .Z especificado, se utiliza tal como se envía. De lo contrario, el sufijo .Z se añade al nombre del archivo antes de procesarlo.

ENTRADA ESTÁNDAR

La entrada estándar se utilizará solo si no se especifican operandos archivo, o si un operando archivo es '-'.

ARCHIVOS DE ENTRADA

Los archivos de entrada serán archivos comprimidos en el formato producido por la utilidad compress.

VARIABLES DE ENTORNO

Las siguientes variables de entorno afectarán la ejecución de zcat:

LANG
Proporciona un valor predeterminado para las variables de internacionalización que no están establecidas o están vacías. (Consulte el volumen de Definiciones Base de POSIX.1‐2017, Sección 8.2, Variables de internacionalización para conocer la precedencia de las variables de internacionalización utilizadas para determinar los valores de las categorías de localización).
LC_ALL
Si se establece en un valor de cadena no vacío, anula los valores de todas las demás variables de internacionalización.
LC_CTYPE
Determina la localización para la interpretación de secuencias de bytes de datos de texto como caracteres (por ejemplo, caracteres de un solo byte frente a caracteres multibyte en los argumentos).
LC_MESSAGES

Determina la localización que debe utilizarse para afectar al formato y contenido de los mensajes de diagnóstico escritos en la salida de error estándar.
NLSPATH
Determina la ubicación de los catálogos de mensajes para el procesamiento de LC_MESSAGES.

EVENTOS ASÍNCRONOS

Predeterminado.

SALIDA ESTÁNDAR

Los archivos comprimidos proporcionados como entrada se escribirán en la salida estándar en su forma descomprimida.

SALIDA DE ERROR ESTÁNDAR

La salida de error estándar se utilizará solo para mensajes de diagnóstico.

ARCHIVOS DE SALIDA

Ninguno.

DESCRIPCIÓN EXTENDIDA

Ninguna.

ESTADO DE SALIDA

Se devolverán los siguientes valores de salida:

 0
Finalización exitosa.
>0
Ocurrió un error.
