subroutine zchkgg (nsizes entero, nn, dimension( * ) nn entero, ntypes entero, dotype, dimension( * ) dotype lógico, iseed, dimension( 4 ) iseed entero, thresh precisión doble, tstdif lógico, thrshn precisión doble, nounit entero, a, dimension( lda, * ) a complex*16, lda entero, b, dimension( lda, * ) b complex*16, h, dimension( lda, * ) h complex*16, t, dimension( lda, * ) t complex*16, s1, dimension( lda, * ) s1 complex*16, s2, dimension( lda, * ) s2 complex*16, p1, dimension( lda, * ) p1 complex*16, p2, dimension( lda, * ) p2 complex*16, u, dimension( ldu, * ) u complex*16, ldu entero, v, dimension( ldu, * ) v complex*16, q, dimension( ldu, * ) q complex*16, z, dimension( ldu, * ) z complex*16, alpha1, dimension( * ) alpha1 complex*16, beta1, dimension( * ) beta1 complex*16, alpha3, dimension( * ) alpha3 complex*16, beta3, dimension( * ) beta3 complex*16, evectl, dimension( ldu, * ) evectl complex*16, evectr, dimension( ldu, * ) evectr complex*16, work, dimension( * ) work complex*16, lwork entero, rwork, dimension( * ) rwork precisión doble, llwork, dimension( * ) llwork lógico, result, dimension( 15 ) result precisión doble, info entero)

ZCHKGG

Propósito:

!>
!> ZCHKGG verifica las rutinas del problema de valores propios generalizados no simétricos.
!>                                H          H        H
!> ZGGHRD factoriza A y B como U H V  y U T V , donde   significa transpuesta conjugada,
!> H es Hesenberg, T es triangular y U y V son unitarias.
!>
!>                                 H          H
!> ZHGEQZ factoriza H y T como  Q S Z  y Q P Z , donde P y S son triangulares superiores
!> y Q y Z son unitarias. También calcula los valores propios generalizados
!> (alpha(1),beta(1)),...,(alpha(n),beta(n)), donde alpha(j)=S(j,j) y beta(j)=P(j,j)
!> -- así, w(j) = alpha(j)/beta(j) es una raíz del problema de valores propios generalizados
!>
!>     det( A - w(j) B ) = 0
!>
!> y m(j) = beta(j)/alpha(j) es una raíz del problema esencialmente equivalente
!>
!>     det( m(j) A - B ) = 0
!>
!> ZTGEVC calcula la matriz L de vectores propios izquierdos y la matriz R de vectores
!> propios derechos para el par de matrices ( S, P ). En la descripción siguiente, l y r
!> son vectores propios izquierdos y derechos correspondientes a los valores propios
!> generalizados (alpha,beta).
!>
!> Cuando se llama a ZCHKGG, se especifican un número de tamaños de matriz () y un
!> número de tipos de matriz. Para cada tamaño () y cada tipo de matriz, se generará y
!> utilizará una matriz para probar las rutinas de valores propios no simétricos.
!> Para cada matriz, se realizarán 13 pruebas. Las doce primeras  deberían ser
!> pequeñas -- O(1). Se compararán con el umbral THRESH:
!>
!>                  H
!> (1)   | A - U H V  | / ( |A| n ulp )
!>
!>                  H
!> (2)   | B - U T V  | / ( |B| n ulp )
!>
!>               H
!> (3)   | I - UU  | / ( n ulp )
!>
!>               H
!> (4)   | I - VV  | / ( n ulp )
!>
!>                  H
!> (5)   | H - Q S Z  | / ( |H| n ulp )
!>
!>                  H
!> (6)   | T - Q P Z  | / ( |T| n ulp )
!>
!>               H
!> (7)   | I - QQ  | / ( n ulp )
!>
!>               H
!> (8)   | I - ZZ  | / ( n ulp )
!>
!> (9)  max sobre todos los pares de valores propios/vectores propios izquierdos (beta/alpha,l) de
!>                           H
!>       | (beta A - alpha B) l | / ( ulp max( |beta A|, |alpha B| ) )
!>
!> (10) max sobre todos los pares de valores propios/vectores propios izquierdos (beta/alpha,l') de
!>                           H
!>       | (beta H - alpha T) l' | / ( ulp max( |beta H|, |alpha T| ) )
!>
!>       donde los vectores propios l' son el resultado de pasar Q a
!>       DTGEVC y transformar de vuelta (JOB='B').
!>
!> (11) max sobre todos los pares de valores propios/vectores propios derechos (beta/alpha,r) de
!>
!>       | (beta A - alpha B) r | / ( ulp max( |beta A|, |alpha B| ) )
!>
!> (12) max sobre todos los pares de valores propios/vectores propios derechos (beta/alpha,r') de
!>
!>       | (beta H - alpha T) r' | / ( ulp max( |beta H|, |alpha T| ) )
!>
!>       donde los vectores propios r' son el resultado de pasar Z a
!>       DTGEVC y transformar de vuelta (JOB='B').
!>
!> Las últimas tres relaciones de prueba serán generalmente pequeñas, pero no hay
!> requisito matemático de que lo sean. Por lo tanto, se comparan con THRESH solo
!> si TSTDIF es .TRUE.
!>
!> (13)  | S(Q,Z calculado) - S(Q,Z no calculado) | / ( |S| ulp )
!>
!> (14)  | P(Q,Z calculado) - P(Q,Z no calculado) | / ( |P| ulp )
!>
!> (15)  max( |alpha(Q,Z calculado) - alpha(Q,Z no calculado)|/|S| ,
!>            |beta(Q,Z calculado) - beta(Q,Z no calculado)|/|P| ) / ulp
!>
!> Además, se verifica la normalización de L y R, y se compara con el umbral THRSHN.
!>
!> Matrices de Prueba
!> ---- --------
!>
!> Los tamaños de las matrices de prueba se especifican mediante un array
!> NN(1:NSIZES); el valor de cada elemento NN(j) especifica un tamaño.
!> Los tipos se especifican mediante un array lógico DOTYPE( 1:NTYPES ); si
!> DOTYPE(j) es .TRUE., entonces se generará la matriz de tipo j.
!> Actualmente, la lista de tipos posibles es:
!>
!> (1)  ( 0, 0 )         (un par de matrices cero)
!>
!> (2)  ( I, 0 )         (una identidad y una matriz cero)
!>
!> (3)  ( 0, I )         (una identidad y una matriz cero)
!>
!> (4)  ( I, I )         (un par de matrices identidad)
!>
!>         t   t
!> (5)  ( J , J  )       (un par de bloques de Jordan transpuestos)
!>
!>                                     t                ( I   0  )
!!> (6)  ( X, Y )         donde  X = ( J   0  )  y Y = (      t )
!>                                  ( 0   I  )          ( 0   J  )
!>                       y I es una identidad kxk y J un bloque de Jordan (k+1)x(k+1); k=(N-1)/2
!>
!> (7)  ( D, I )         donde D es P*D1, P es una matriz unitaria diagonal aleatoria
!>                       (es decir, con entradas de magnitud 1 aleatorias en la diagonal),
!>                       y D1=diag( 0, 1,..., N-1 ) (es decir, una matriz diagonal con
!>                       D1(1,1)=0, D1(2,2)=1, ..., D1(N,N)=N-1.)
!> (8)  ( I, D )
!>
!> (9)  ( big*D, small*I ) donde  es cercano al desbordamiento y small=1/big
!>
!> (10) ( small*D, big*I )
!>
!> (11) ( big*I, small*D )
!>
!> (12) ( small*I, big*D )
!>
!> (13) ( big*D, big*I )
!>
!> (14) ( small*D, small*I )
!>
!> (15) ( D1, D2 )        donde D1=P*diag( 0, 0, 1, ..., N-3, 0 ) y
!>                        D2=Q*diag( 0, N-3, N-4,..., 1, 0, 0 ), y
!>                        P y Q son matrices unitarias diagonales aleatorias.

zchkgg

zchkgg
zchkgg

ZCHKGG tests the general matrix-matrix multiplication routines.

This subroutine is called by the driver routine ZCHDRV.

The following tests are performed:

  • Test 1: Check the accuracy of ZGGHRD.

    (A, B) = ( U * H * V, U * T * V ) where H is upper Hessenberg and T is upper triangular.

  • Test 2: Check the accuracy of ZHGEQZ.

    (H, T) = ( Q * S1 * Z, Q * P1 * Z ) where S1 and P1 are upper triangular.

    (A, B) = ( U * S1 * V, U * P1 * V )

  • Test 3: Check the accuracy of the eigenvectors computed by ZHGEQZ.

    (A, B) = ( U * S2 * V, U * P2 * V ) where S2 and P2 are upper triangular.

    (A, B) = ( U * S2 * V, U * P2 * V )

    A*Z = EVECTL*ALPHA3, B*Z = EVECTL*BETA3

    EVECTR*A = ALPHA3*EVECTR, EVECTR*B = BETA3*EVECTR

The arguments are described below.

Types of matrix used in test 1 and 2

The following are the matrix types tested in ZCHKGG:

Matrix types

!>           t   t
!> (16) U ( J , J ) V     where U and V are random unitary matrices.
!>
!> (17) U ( T1, T2 ) V    where T1 and T2 are upper triangular matrices
!>                        with random O(1) entries above the diagonal
!>                        and diagonal entries diag(T1) =
!>                        P*( 0, 0, 1, ..., N-3, 0 ) and diag(T2) =
!>                        Q*( 0, N-3, N-4,..., 1, 0, 0 )
!>
!> (18) U ( T1, T2 ) V    diag(T1) = ( 0, 0, 1, 1, s, ..., s, 0 )
!>                        diag(T2) = ( 0, 1, 0, 1,..., 1, 0 )
!>                        s = machine precision.
!>
!> (19) U ( T1, T2 ) V    diag(T1)=( 0, 0, 1, 1, 1-d, ..., 1-(N-5)*d=s, 0 )
!>                        diag(T2) = ( 0, 1, 0, 1, ..., 1, 0 )
!>
!>                                                        N-5
!> (20) U ( T1, T2 ) V    diag(T1)=( 0, 0, 1, 1, a, ..., a   =s, 0 )
!>                        diag(T2) = ( 0, 1, 0, 1, ..., 1, 0, 0 )
!>
!> (21) U ( T1, T2 ) V    diag(T1)=( 0, 0, 1, r1, r2, ..., r(N-4), 0 )
!>                        diag(T2) = ( 0, 1, 0, 1, ..., 1, 0, 0 )
!>                        where r1,..., r(N-4) are random.
!>
!> (22) U ( big*T1, small*T2 ) V   diag(T1) = P*( 0, 0, 1, ..., N-3, 0 )
!>                                 diag(T2) = ( 0, 1, ..., 1, 0, 0 )
!>
!> (23) U ( small*T1, big*T2 ) V   diag(T1) = P*( 0, 0, 1, ..., N-3, 0 )
!>                                 diag(T2) = ( 0, 1, ..., 1, 0, 0 )
!>
!> (24) U ( small*T1, small*T2 ) V diag(T1) = P*( 0, 0, 1, ..., N-3, 0 )
!>                                 diag(T2) = ( 0, 1, ..., 1, 0, 0 )
!>
!> (25) U ( big*T1, big*T2 ) V     diag(T1) = P*( 0, 0, 1, ..., N-3, 0 )
!>                                 diag(T2) = ( 0, 1, ..., 1, 0, 0 )
!>
!> (26) U ( T1, T2 ) V     where T1 and T2 are random upper-triangular
!>                         matrices.
!>

Parameters

NSIZES

NSIZES is INTEGER

The number of sizes of matrices to use. If it is zero, ZCHKGG does nothing. It must be at least zero.

NN

NN is INTEGER array, dimension (NSIZES)

An array containing the sizes to be used for the matrices. Zero values will be skipped. The values must be at least zero.

NTYPES

NTYPES is INTEGER

The number of elements in DOTYPE. If it is zero, ZCHKGG does nothing. It must be at least zero. If it is MAXTYP+1 and NSIZES is 1, then an additional type, MAXTYP+1 is defined, which is to use whatever matrix is in A. This is only useful if DOTYPE(1:MAXTYP) is .FALSE. and DOTYPE(MAXTYP+1) is .TRUE.

DOTYPE

DOTYPE is LOGICAL array, dimension (NTYPES)

If DOTYPE(j) is .TRUE., then for each size in NN a matrix of that size and of type j will be generated. If NTYPES is smaller than the maximum number of types defined (PARAMETER MAXTYP), then types NTYPES+1 through MAXTYP will not be generated. If NTYPES is larger than MAXTYP, DOTYPE(MAXTYP+1) through DOTYPE(NTYPES) will be ignored.

ISEED

ISEED is INTEGER array, dimension (4)

On entry ISEED specifies the seed of the random number generator. The array elements should be between 0 and 4095; if not they will be reduced mod 4096. Also, ISEED(4) must be odd. The random number generator uses a linear congruential sequence limited to small integers, and so should produce machine independent random numbers. The values of ISEED are changed on exit, and can be used in the next call to ZCHKGG to continue the same random number sequence.

THRESH

THRESH is DOUBLE PRECISION

A test will count as if the , computed as described above, exceeds THRESH. Note that the error is scaled to be O(1), so THRESH should be a reasonably small multiple of 1, e.g., 10 or 100. In particular, it should not depend on the precision (single vs. double) or the size of the matrix. It must be at least zero.

TSTDIF

TSTDIF is LOGICAL

Specifies whether test ratios 13-15 will be computed and compared with THRESH.

= .FALSE.: Only test ratios 1-12 will be computed and tested. Ratios 13-15 will be set to zero.

= .TRUE.: All the test ratios 1-15 will be computed and tested.

THRSHN

THRSHN is DOUBLE PRECISION

Threshold for reporting eigenvector normalization error. If the normalization of any eigenvector differs from 1 by more than THRSHN*ulp, then a special error message will be printed. (This is handled separately from the other tests, since only a compiler or programming error should cause an error message, at least if THRSHN is at least 5--10.)

NOUNIT

NOUNIT is INTEGER

The FORTRAN unit number for printing out error messages (e.g., if a routine returns IINFO not equal to 0.)

A

A is COMPLEX*16 array, dimension (LDA, max(NN))

Used to hold the original A matrix. Used as input only if NTYPES=MAXTYP+1, DOTYPE(1:MAXTYP)=.FALSE., and DOTYPE(MAXTYP+1)=.TRUE.

LDA

LDA is INTEGER

The leading dimension of A, B, H, T, S1, P1, S2, and P2. It must be at least 1 and at least max( NN ).

B

B is COMPLEX*16 array, dimension (LDA, max(NN))

Used to hold the original B matrix. Used as input only if NTYPES=MAXTYP+1, DOTYPE(1:MAXTYP)=.FALSE., and DOTYPE(MAXTYP+1)=.TRUE.

H

H is COMPLEX*16 array, dimension (LDA, max(NN))

The upper Hessenberg matrix computed from A by ZGGHRD.

T

T is COMPLEX*16 array, dimension (LDA, max(NN))

The upper triangular matrix computed from B by ZGGHRD.

S1

S1 is COMPLEX*16 array, dimension (LDA, max(NN))

The Schur (upper triangular) matrix computed from H by ZHGEQZ when Q and Z are also computed.

S2

S2 is COMPLEX*16 array, dimension (LDA, max(NN))

The Schur (upper triangular) matrix computed from H by ZHGEQZ when Q and Z are not computed.

P1

P1 is COMPLEX*16 array, dimension (LDA, max(NN))

The upper triangular matrix computed from T by ZHGEQZ when Q and Z are also computed.

P2

P2 is COMPLEX*16 array, dimension (LDA, max(NN))

The upper triangular matrix computed from T by ZHGEQZ when Q and Z are not computed.

U

U is COMPLEX*16 array, dimension (LDU, max(NN))

The (left) unitary matrix computed by ZGGHRD.

LDU

LDU is INTEGER

The leading dimension of U, V, Q, Z, EVECTL, and EVEZTR. It must be at least 1 and at least max( NN ).

V

V is COMPLEX*16 array, dimension (LDU, max(NN))

The (right) unitary matrix computed by ZGGHRD.

Q

Q is COMPLEX*16 array, dimension (LDU, max(NN))

The (left) unitary matrix computed by ZHGEQZ.

Z

Z is COMPLEX*16 array, dimension (LDU, max(NN))

The (left) unitary matrix computed by ZHGEQZ.

ALPHA1

ALPHA1 is COMPLEX*16 array, dimension (max(NN))

BETA1

BETA1 is COMPLEX*16 array, dimension (max(NN))

The generalized eigenvalues of (A,B) computed by ZHGEQZ when Q, Z, and the full Schur matrices are computed.

ALPHA3

ALPHA3 is COMPLEX*16 array, dimension (max(NN))

BETA3

BETA3 is COMPLEX*16 array, dimension (max(NN))

The generalized eigenvalues of (A,B) computed by ZHGEQZ when neither Q, Z, nor the Schur matrices are computed.

EVECTL

EVECTL is COMPLEX*16 array, dimension (LDU, max(NN))

The (lower triangular) left eigenvector matrix for the matrices in S1 and P1.

EVECTR

EVECTR is COMPLEX*16 array, dimension (LDU, max(NN))

The (upper triangular) right eigenvector matrix for the matrices in S1 and P1.

WORK

WORK is COMPLEX*16 array, dimension (LWORK)

LWORK

LWORK is INTEGER

The number of entries in WORK. This must be at least max( 4*N, 2 * N**2, 1 ), for all N=NN(j).

RWORK

RWORK is DOUBLE PRECISION array, dimension (2*max(NN))

LLWORK

LLWORK is LOGICAL array, dimension (max(NN))

RESULT

RESULT is DOUBLE PRECISION array, dimension (15)

The values computed by the tests described above. The values are currently limited to 1/ulp, to avoid overflow.

INFO

INFO is INTEGER

= 0: successful exit.

< 0: if INFO = -i, the i-th argument had an illegal value.

> 0: A routine returned an error code. INFO is the absolute value of the INFO value returned.
