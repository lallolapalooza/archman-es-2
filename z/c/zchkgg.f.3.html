Propósito:

!>
!> ZCHKGG  verifica las rutinas del problema de valores propios generalizados no simétricos.
!>                                H          H        H
!> ZGGHRD factoriza A y B como U H V  y U T V , donde   significa transpuesta conjugada,
!> H es de Hesenberg, T es triangular y U y V son unitarias.
!>
!>                                 H          H
!> ZHGEQZ factoriza H y T como  Q S Z  y Q P Z , donde P y S son triangulares superiores
!> y Q y Z son unitarias. También calcula los valores propios generalizados
!> (alpha(1),beta(1)),...,(alpha(n),beta(n)), donde alpha(j)=S(j,j) y beta(j)=P(j,j) --
!> por lo tanto, w(j) = alpha(j)/beta(j) es una raíz del problema de valores propios generalizados
!>
!>     det( A - w(j) B ) = 0
!>
!> y m(j) = beta(j)/alpha(j) es una raíz del problema esencialmente equivalente
!>
!>     det( m(j) A - B ) = 0
!>
!> ZTGEVC calcula la matriz L de vectores propios izquierdos y la matriz R de vectores
!> propios derechos para el par de matrices ( S, P ). En la descripción a continuación,
!> l y r son vectores propios izquierdos y derechos correspondientes a los valores propios
!> generalizados (alpha,beta).
!>
!> Cuando se llama a ZCHKGG, se especifica un número de tamaños de matriz y un
!> número de tipos de matriz. Para cada tamaño y cada tipo de matriz, se generará
!> y utilizará una matriz para probar las rutinas de valores propios no simétricos.
!> Para cada matriz, se realizarán 13 pruebas. Los doce primeros  deberían ser
!> pequeños -- O(1). Se compararán con el umbral THRESH:
!>
!>                  H
!> (1)   | A - U H V  | / ( |A| n ulp )
!>
!>                  H
!> (2)   | B - U T V  | / ( |B| n ulp )
!>
!>               H
!> (3)   | I - UU  | / ( n ulp )
!>
!>               H
!> (4)   | I - VV  | / ( n ulp )
!>
!>                  H
!> (5)   | H - Q S Z  | / ( |H| n ulp )
!>
!>                  H
!> (6)   | T - Q P Z  | / ( |T| n ulp )
!>
!>               H
!> (7)   | I - QQ  | / ( n ulp )
!>
!>               H
!> (8)   | I - ZZ  | / ( n ulp )
!>
!> (9)   maximo sobre todos los pares de valores/vectores propios izquierdos (beta/alpha,l) de
!>                           H
!>       | (beta A - alpha B) l | / ( ulp max( |beta A|, |alpha B| ) )
!>
!> (10)  maximo sobre todos los pares de valores/vectores propios izquierdos (beta/alpha,l') de
!>                           H
!>       | (beta H - alpha T) l' | / ( ulp max( |beta H|, |alpha T| ) )
!>
!>       donde los vectores propios l' son el resultado de pasar Q a
!>       DTGEVC y transformar de vuelta (JOB='B').
!>
!> (11)  maximo sobre todos los pares de valores/vectores propios derechos (beta/alpha,r) de
!>
!>       | (beta A - alpha B) r | / ( ulp max( |beta A|, |alpha B| ) )
!>
!> (12)  maximo sobre todos los pares de valores/vectores propios derechos (beta/alpha,r') de
!>
!>       | (beta H - alpha T) r' | / ( ulp max( |beta H|, |alpha T| ) )
!>
!>       donde los vectores propios r' son el resultado de pasar Z a
!>       DTGEVC y transformar de vuelta (JOB='B').
!>
!> Los últimos tres ratios de prueba generalmente serán pequeños, pero no hay un
!> requisito matemático para que lo sean. Por lo tanto, se comparan con THRESH
!> solo si TSTDIF es .TRUE.
!>
!> (13)  | S(Q,Z calculado) - S(Q,Z no calculado) | / ( |S| ulp )
!>
!> (14)  | P(Q,Z calculado) - P(Q,Z no calculado) | / ( |P| ulp )
!>
!> (15)  max( |alpha(Q,Z calculado) - alpha(Q,Z no calculado)|/|S| ,
!>            |beta(Q,Z calculado) - beta(Q,Z no calculado)|/|P| ) / ulp
!>
!> Además, se comprueba la normalización de L y R, y se compara
!> con el umbral THRSHN.
!>
!> Matrices de Prueba
!> ---- --------
!>
!> Los tamaños de las matrices de prueba se especifican mediante un array
!> NN(1:NSIZES); el valor de cada elemento NN(j) especifica un tamaño.
!> Los tipos de matriz se especifican mediante un array lógico DOTYPE( 1:NTYPES ); si
!> DOTYPE(j) es .TRUE., entonces se generará el tipo de matriz j.
!> Actualmente, la lista de tipos posibles es:
!>
!> (1)  ( 0, 0 )         (un par de matrices cero)
!>
!> (2)  ( I, 0 )         (una identidad y una matriz cero)
!>
!> (3)  ( 0, I )         (una identidad y una matriz cero)
!>
!> (4)  ( I, I )         (un par de matrices identidad)
!>
!>         t   t
!> (5)  ( J , J  )       (un par de bloques de Jordan transpuestos)
!>
!>                                     t                ( I   0  )
!> (6)  ( X, Y )         donde  X = ( J   0  )  y Y = (      t )
!>                                  ( 0   I  )          ( 0   J  )
!>                       y I es una identidad k x k y J un bloque de Jordan (k+1)x(k+1); k=(N-1)/2
!>
!> (7)  ( D, I )         donde D es P*D1, P es una matriz diagonal unitaria aleatoria
!>                       (es decir, con entradas de magnitud 1 aleatorias en la diagonal),
!>                       y D1=diag( 0, 1,..., N-1 ) (es decir, una matriz diagonal con D1(1,1)=0,
!>                       D1(2,2)=1, ..., D1(N,N)=N-1.)
!> (8)  ( I, D )
!>
!> (9)  ( big*D, small*I ) donde  es cercano al desbordamiento y small=1/big
!>
!> (10) ( small*D, big*I )
!>
!> (11) ( big*I, small*D )
!>
!> (12) ( small*I, big*D )
!>
!> (13) ( big*D, big*I )
!>
!> (14) ( small*D, small*I )
!>
!> (15) ( D1, D2 )        donde D1=P*diag( 0, 0, 1, ..., N-3, 0 ) y
!>                        D2=Q*diag( 0, N-3, N-4,..., 1, 0, 0 ), y
!>                        P y Q son matrices diagonales unitarias aleatorias.
