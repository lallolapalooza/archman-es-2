subrutina zcposv (carácter uplo, entero n, entero nrhs, complejo*16, dimensión( lda, * ) a, entero lda, complejo*16, dimensión( ldb, * ) b, entero ldb, complejo*16, dimensión( ldx, * ) x, entero ldx, complejo*16, dimensión( n, * ) work, complejo, dimensión( * ) swork, doble_precisión, dimensión( * ) rwork, entero iter, entero info)

ZCPOSV calcula la solución al sistema de ecuaciones lineales A * X = B para matrices PO

Propósito:

!>
!> ZCPOSV calcula la solución a un sistema complejo de ecuaciones lineales
!>    A * X = B,
!> donde A es una matriz Hermitiana positiva definida de N por N y X y B
!> son matrices de N por NRHS.
!>
!> ZCPOSV primero intenta factorizar la matriz en COMPLEX y utiliza esta
!> factorización dentro de un procedimiento de refinamiento iterativo para producir una
!> solución con calidad de error hacia atrás normativo COMPLEX*16 (ver más abajo).
!> Si el enfoque falla, el método cambia a una factorización y solución
!> de COMPLEX*16.
!>
!> El refinamiento iterativo no será una estrategia ganadora si
!> la relación rendimiento COMPLEX sobre rendimiento COMPLEX*16 es demasiado
!> pequeña. Una estrategia razonable debería tener en cuenta el número de lados derechos
!> y el tamaño de la matriz. Esto podría hacerse
!> con una llamada a ILAENV en el futuro. Hasta ahora, siempre intentamos
!> el refinamiento iterativo.
!>
!> El proceso de refinamiento iterativo se detiene si
!>     ITER > ITERMAX
!> o para todos los RHS tenemos:
!>     RNRM < SQRT(N)*XNRM*ANRM*EPS*BWDMAX
!> donde
!>     o ITER es el número de la iteración actual en el refinamiento
!>       iterativo
!>     o RNRM es la norma infinito del residuo
!>     o XNRM es la norma infinito de la solución
!>     o ANRM es la norma operador infinito de la matriz A
!>     o EPS es el epsilon de la máquina devuelto por DLAMCH('Epsilon')
!> El valor ITERMAX y BWDMAX se fijan en 30 y 1.0D+00
!> respectivamente.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          = 'U':  El triángulo superior de A está almacenado;
!>          = 'L':  El triángulo inferior de A está almacenado.
!>

N

!>          N es ENTERO
!>          El número de ecuaciones lineales, es decir, el orden de
!>          la matriz A.  N >= 0.
!>

NRHS

!>          NRHS es ENTERO
!>          El número de lados derechos, es decir, el número de columnas
!>          de la matriz B.  NRHS >= 0.
!>

A

!>          A es un array COMPLEX*16,
!>          dimensión (LDA,N)
!>          En la entrada, la matriz Hermitiana A. Si UPLO = 'U', la parte
!>          superior triangular de N por N de A contiene la parte
!>          superior triangular de la matriz A, y la parte estrictamente inferior
!>          triangular de A no se referencia. Si UPLO = 'L', la parte
!>          inferior triangular de N por N de A contiene la parte
!>          inferior triangular de la matriz A, y la parte estrictamente superior
!>          triangular de A no se referencia.
!>
!>          Tenga en cuenta que las partes imaginarias de los elementos
!>          diagonales no necesitan ser establecidas y se asume que son cero.
!>
!>          En la salida, si el refinamiento iterativo se ha utilizado con éxito
!>          (INFO = 0 e ITER >= 0, ver descripción abajo), entonces A no ha cambiado,
!>          si se ha utilizado la factorización de doble precisión
!>          (INFO = 0 e ITER < 0, ver descripción abajo), entonces el
!>          array A contiene el factor U o L de la factorización de Cholesky
!>          A = U**H*U o A = L*L**H.
!>

LDA

!>          LDA es ENTERO
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

B

!>          B es un array COMPLEX*16, dimensión (LDB,NRHS)
!>          La matriz B de N por NRHS en el lado derecho.
!>

LDB

!>          LDB es ENTERO
!>          La dimensión principal del array B.  LDB >= max(1,N).
!>

X

!>          X es un array COMPLEX*16, dimensión (LDX,NRHS)
!>          Si INFO = 0, la matriz solución X de N por NRHS.
!>

LDX

!>          LDX es ENTERO
!>          La dimensión principal del array X.  LDX >= max(1,N).
!>

WORK

!>          WORK es un array COMPLEX*16, dimensión (N,NRHS)
!>          Este array se utiliza para contener los vectores residuales.
!>

SWORK

!>          SWORK es un array COMPLEX, dimensión (N*(N+NRHS))
!>          Este array se utiliza para usar la matriz de precisión simple y los
!>          lados derechos o soluciones en precisión simple.
!>

RWORK

!>          RWORK es un array DOUBLE PRECISION, dimensión (N)
!>

ITER

!>          ITER es ENTERO
!>          < 0: el refinamiento iterativo ha fallado, se ha realizado una
!>               factorización COMPLEX*16
!>               -1 : la rutina recurrió a precisión completa por
!>                    razones específicas de implementación o máquina
!>               -2 : la reducción de la precisión provocó un desbordamiento,
!>                    la rutina recurrió a precisión completa
!>               -3 : fallo de CPOTRF
!>               -31: se detuvo el refinamiento iterativo después de la 30ª
!>                    iteración
!>          > 0: el refinamiento iterativo se ha utilizado con éxito.
!>               Devuelve el número de iteraciones
!>

INFO

!>          INFO es ENTERO
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>          > 0:  si INFO = i, el menor principal de orden i
!>                de (COMPLEX*16) A no es positivo, por lo que la factorización
!>                no pudo completarse y la solución no se ha
!>                calculado.
!>

    NAME

    zcposv - sets position of a cursor

    SYNOPSIS

    void zcposv(int x, int y);

    DESCRIPTION

    The zcposv function sets the position of the cursor to (x, y). The top-left corner is (0, 0).

    RETURN VALUE

    None.

    ERRORS

    None.

    EXAMPLES

    zcposv(10, 20);
