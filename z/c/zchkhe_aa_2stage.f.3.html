ZCHKHE_AA_2STAGE

Propósito:

!>
!> ZCHKSY_AA_2STAGE prueba ZHETRF_AA_2STAGE, -TRS_AA_2STAGE.
!>

Parámetros

DOTYPE 
!>          DOTYPE es un array LÓGICO, dimensión (NTIPOS)
!>          Los tipos de matrices a utilizar para las pruebas. Las matrices de tipo j
!>          (para 1 <= j <= NTIPOS) se utilizan para las pruebas si DOTYPE(j) =
!>          .TRUE.; si DOTYPE(j) = .FALSE., entonces el tipo j no se utiliza.
!>

NN

!>          NN es ENTERO
!>          El número de valores de N contenidos en el vector NVAL.
!>

NVAL

!>          NVAL es un array ENTERO, dimensión (NN)
!>          Los valores de la dimensión de la matriz N.
!>

NNB

!>          NNB es ENTERO
!>          El número de valores de NB contenidos en el vector NBVAL.
!>

NBVAL

!>          NBVAL es un array ENTERO, dimensión (NNB)
!>          Los valores del tamaño del bloque NB.
!>

NNS

!>          NNS es ENTERO
!>          El número de valores de NRHS contenidos en el vector NSVAL.
!>

NSVAL

!>          NSVAL es un array ENTERO, dimensión (NNS)
!>          Los valores del número de lados derechos NRHS.
!>

THRESH

!>          THRESH es DOBLE PRECISIÓN
!>          El valor umbral para las relaciones de prueba. Un resultado se
!>          incluye en el archivo de salida si RESULT >= THRESH. Para que
!>          cada relación de prueba se imprima, use THRESH = 0.
!>

TSTERR

!>          TSTERR es LÓGICO
!>          Indicador que señala si se deben probar las salidas de error.
!>

NMAX

!>          NMAX es ENTERO
!>          El valor máximo permitido para N, utilizado en la dimensionamiento de los
!>          arrays de trabajo.
!>

A

!>          A es un array COMPLEJO*16, dimensión (NMAX*NMAX)
!>

AFAC

!>          AFAC es un array COMPLEJO*16, dimensión (NMAX*NMAX)
!>

AINV

!>          AINV es un array COMPLEJO*16, dimensión (NMAX*NMAX)
!>

B

!>          B es un array COMPLEJO*16, dimensión (NMAX*NSMAX)
!>          donde NSMAX es la entrada más grande en NSVAL.
!>

X

!>          X es un array COMPLEJO*16, dimensión (NMAX*NSMAX)
!>

XACT

!>          XACT es un array COMPLEJO*16, dimensión (NMAX*NSMAX)
!>

WORK

!>          WORK es un array COMPLEJO*16, dimensión (NMAX*max(3,NSMAX))
!>

RWORK

!>          RWORK es un array DOBLE PRECISIÓN, dimensión (max(NMAX,2*NSMAX))
!>

IWORK

!>          IWORK es un array ENTERO, dimensión (2*NMAX)
!>

NOUT

!>          NOUT es ENTERO
!>          El número de unidad para la salida.
!>
