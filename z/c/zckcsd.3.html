ZCKCSD

Propósito:

!>
!> ZCKCSD prueba ZUNCSD:
!>        el CSD para una matriz unitaria M-por-M X particionada como
!>        [ X11 X12; X21 X22 ]. X11 es P-por-Q.
!>

Parámetros

NM 
!>          NM es ENTERO
!>          El número de valores de M contenidos en el vector MVAL.
!>

MVAL

!>          MVAL es un array de ENTEROS, dimensión (NM)
!>          Los valores de la dimensión de fila de la matriz M.
!>

PVAL

!>          PVAL es un array de ENTEROS, dimensión (NM)
!>          Los valores de la dimensión de fila de la matriz P.
!>

QVAL

!>          QVAL es un array de ENTEROS, dimensión (NM)
!>          Los valores de la dimensión de columna de la matriz Q.
!>

NMATS

!>          NMATS es ENTERO
!>          El número de tipos de matrices a probar para cada combinación
!>          de dimensiones de matriz. Si NMATS >= NTYPES (el número máximo
!>          de tipos de matriz), entonces se generan todos los tipos diferentes
!>          para la prueba. Si NMATS < NTYPES, se lee otra línea de entrada
!>          para obtener los números de los tipos de matriz a utilizar.
!>

ISEED

!>          ISEED es un array de ENTEROS, dimensión (4)
!>          En la entrada, la semilla del generador de números aleatorios. Los elementos
!>          del array deben estar entre 0 y 4095, de lo contrario se reducirán
!>          módulo 4096, y ISEED(4) debe ser impar.
!>          En la salida, la siguiente semilla en la secuencia de números aleatorios
!>          después de que se hayan generado todas las matrices de prueba.
!>

THRESH

!>          THRESH es DOBLE PRECISIÓN
!>          El valor umbral para las relaciones de prueba. Un resultado se
!>          incluye en el archivo de salida si RESULTADO >= THRESH. Para imprimir
!>          cada relación de prueba, use THRESH = 0.
!>

MMAX

!>          MMAX es ENTERO
!>          El valor máximo permitido para M, utilizado en la dimensionamiento
!>          de los arrays de trabajo.
!>

X

!>          X es un array COMPLEJO*16, dimensión (MMAX*MMAX)
!>

XF

!>          XF es un array COMPLEJO*16, dimensión (MMAX*MMAX)
!>

U1

!>          U1 es un array COMPLEJO*16, dimensión (MMAX*MMAX)
!>

U2

!>          U2 es un array COMPLEJO*16, dimensión (MMAX*MMAX)
!>

V1T

!>          V1T es un array COMPLEJO*16, dimensión (MMAX*MMAX)
!>

V2T

!>          V2T es un array COMPLEJO*16, dimensión (MMAX*MMAX)
!>

THETA

!>          THETA es un array de DOBLE PRECISIÓN, dimensión (MMAX)
!>

IWORK

!>          IWORK es un array de ENTEROS, dimensión (MMAX)
!>

WORK

!>          WORK es un array COMPLEJO*16
!>

RWORK

!>          RWORK es un array de DOBLE PRECISIÓN
!>

NIN

!>          NIN es ENTERO
!>          La unidad de número para la entrada.
!>

NOUT

!>          NOUT es ENTERO
!>          La unidad de número para la salida.
!>

INFO

!>          INFO es ENTERO
!>          = 0 :  Salida exitosa
!>          > 0 :  Si ZLAROR devuelve un código de error, se devuelve su valor absoluto.
!>
