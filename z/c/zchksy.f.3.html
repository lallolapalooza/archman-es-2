Documentación de función/subrutina

subrutina zchksy (logical, dimension( * ) dotype, integer nn, integer, dimension( * ) nval, integer nnb, integer, dimension( * ) nbval, integer nns, integer, dimension( * ) nsval, double precision thresh, logical tsterr, integer nmax, complex*16, dimension( * ) a, complex*16, dimension( * ) afac, complex*16, dimension( * ) ainv, complex*16, dimension( * ) b, complex*16, dimension( * ) x, complex*16, dimension( * ) xact, complex*16, dimension( * ) work, double precision, dimension( * ) rwork, integer, dimension( * ) iwork, integer nout)

ZCHKSY

Propósito

!>
!> ZCHKSY prueba ZSYTRF, -TRI2, -TRS, -TRS2, -RFS y -CON.
!>

Parámetros

DOTYPE 
!>          DOTYPE es un array LOGICAL, de dimensión (NTYPES)
!>          Los tipos de matrices a utilizar para las pruebas. Las matrices
!>          de tipo j (para 1 <= j <= NTYPES) se utilizan para las pruebas
!>          si DOTYPE(j) = .TRUE.; si DOTYPE(j) = .FALSE., entonces el tipo j
!>          no se utiliza.
!>

NN

!>          NN es un INTEGER
!>          El número de valores de N contenidos en el vector NVAL.
!>

NVAL

!>          NVAL es un array INTEGER, de dimensión (NN)
!>          Los valores de la dimensión de la matriz N.
!>

NNB

!>          NNB es un INTEGER
!>          El número de valores de NB contenidos en el vector NBVAL.
!>

NBVAL

!>          NBVAL es un array INTEGER, de dimensión (NNB)
!>          Los valores del tamaño de bloque NB.
!>

NNS

!>          NNS es un INTEGER
!>          El número de valores de NRHS contenidos en el vector NSVAL.
!>

NSVAL

!>          NSVAL es un array INTEGER, de dimensión (NNS)
!>          Los valores del número de lados derechos NRHS.
!>

THRESH

!>          THRESH es DOUBLE PRECISION
!>          El valor umbral para las relaciones de prueba. Un resultado
!>          se incluye en el archivo de salida si RESULT >= THRESH. Para que
!>          se imprima cada relación de prueba, use THRESH = 0.
!>

TSTERR

!>          TSTERR es LOGICAL
!>          Indicador que señala si se deben probar las salidas de error.
!>

NMAX

!>          NMAX es un INTEGER
!>          El valor máximo permitido para N, utilizado en la dimensionamiento
!>          de los arrays de trabajo.
!>

A

!>          A es un array COMPLEX*16, de dimensión (NMAX*NMAX)
!>

AFAC

!>          AFAC es un array COMPLEX*16, de dimensión (NMAX*NMAX)
!>

AINV

!>          AINV es un array COMPLEX*16, de dimensión (NMAX*NMAX)
!>

B

!>          B es un array COMPLEX*16, de dimensión (NMAX*NSMAX)
!>          donde NSMAX es la entrada más grande en NSVAL.
!>

X

!>          X es un array COMPLEX*16, de dimensión (NMAX*NSMAX)
!>

XACT

!>          XACT es un array COMPLEX*16, de dimensión (NMAX*NSMAX)
!>

WORK

!>          WORK es un array COMPLEX*16, de dimensión (NMAX*max(2,NSMAX))
!>

RWORK

!>          RWORK es un array DOUBLE PRECISION, de dimensión (NMAX+2*NSMAX)
!>

IWORK

!>          IWORK es un array INTEGER, de dimensión (NMAX)
!>

NOUT

!>          NOUT es un INTEGER
!>          El número de unidad para la salida.
!>
