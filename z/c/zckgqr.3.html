ZCKGQR

Propósito:

!>
!> Pruebas de ZCKGQR
!> ZGGQRF: Factorización GQR para la matriz A de N por M y la matriz B de N por P,
!> ZGGRQF: Factorización GRQ para la matriz A de M por N y la matriz B de P por N.
!>

Parámetros

NM 
!>          NM es INTEGER
!>          El número de valores de M contenidos en el vector MVAL.
!>

MVAL

!>          MVAL es un array INTEGER, dimension (NM)
!>          Los valores de la dimensión de fila(columna) de la matriz M.
!>

NP

!>          NP es INTEGER
!>          El número de valores de P contenidos en el vector PVAL.
!>

PVAL

!>          PVAL es un array INTEGER, dimension (NP)
!>          Los valores de la dimensión de fila(columna) de la matriz P.
!>

NN

!>          NN es INTEGER
!>          El número de valores de N contenidos en el vector NVAL.
!>

NVAL

!>          NVAL es un array INTEGER, dimension (NN)
!>          Los valores de la dimensión de columna(fila) de la matriz N.
!>

NMATS

!>          NMATS es INTEGER
!>          El número de tipos de matrices a probar para cada combinación
!>          de dimensiones de matriz. Si NMATS >= NTYPES (el número
!>          máximo de tipos de matrices), entonces se generan todos los tipos
!>          diferentes para la prueba. Si NMATS < NTYPES, se lee otra línea
!>          de entrada para obtener los números de los tipos de matrices a usar.
!>

ISEED

!>          ISEED es un array INTEGER, dimension (4)
!>          En la entrada, la semilla del generador de números aleatorios. Los elementos
!>          del array deben estar entre 0 y 4095, de lo contrario se reducirán
!>          módulo 4096, y ISEED(4) debe ser impar.
!>          En la salida, la siguiente semilla en la secuencia de números aleatorios después
!>          de que todas las matrices de prueba han sido generadas.
!>

THRESH

!>          THRESH es DOUBLE PRECISION
!>          El valor umbral para las relaciones de prueba. Un resultado se
!>          incluye en el archivo de salida si RESULT >= THRESH. Para que
!>          se imprima cada relación de prueba, use THRESH = 0.
!>

NMAX

!>          NMAX es INTEGER
!>          El valor máximo permitido para M o N, utilizado en la dimensionamiento
!>          de los arrays de trabajo.
!>

A

!>          A es un array COMPLEX*16, dimension (NMAX*NMAX)
!>

AF

!>          AF es un array COMPLEX*16, dimension (NMAX*NMAX)
!>

AQ

!>          AQ es un array COMPLEX*16, dimension (NMAX*NMAX)
!>

AR

!>          AR es un array COMPLEX*16, dimension (NMAX*NMAX)
!>

TAUA

!>          TAUA es un array COMPLEX*16, dimension (NMAX)
!>

B

!>          B es un array COMPLEX*16, dimension (NMAX*NMAX)
!>

BF

!>          BF es un array COMPLEX*16, dimension (NMAX*NMAX)
!>

BZ

!>          BZ es un array COMPLEX*16, dimension (NMAX*NMAX)
!>

BT

!>          BT es un array COMPLEX*16, dimension (NMAX*NMAX)
!>

BWK

!>          BWK es un array COMPLEX*16, dimension (NMAX*NMAX)
!>

TAUB

!>          TAUB es un array COMPLEX*16, dimension (NMAX)
!>

WORK

!>          WORK es un array COMPLEX*16, dimension (NMAX*NMAX)
!>

RWORK

!>          RWORK es un array DOUBLE PRECISION, dimension (NMAX)
!>

NIN

!>          NIN es INTEGER
!>          El número de unidad para la entrada.
!>

NOUT

!>          NOUT es INTEGER
!>          El número de unidad para la salida.
!>

INFO

!>          INFO es INTEGER
!>          = 0 :  salida exitosa
!>          > 0 :  Si ZLATMS devuelve un código de error, se devuelve su valor absoluto.
!>
