Propósito:

!>
!>    ZCHKHS  comprueba las rutinas del problema de valores propios no simétricos.
!>
!>            ZGEHRD factoriza A como  U H U' , donde ' significa transpuesta conjugada,
!>            H es de Hessenberg y U es unitaria.
!>
!>            ZUNGHR genera la matriz unitaria U.
!>
!>            ZUNMHR multiplica una matriz por la matriz unitaria U.
!>
!>            ZHSEQR factoriza H como  Z T Z' , donde Z es unitaria y T
!>            es triangular superior. También calcula los valores propios,
!>            w(1), ..., w(n); definimos una matriz diagonal W cuyas
!>            entradas (diagonales) son los valores propios.
!>
!>            ZTREVC calcula la matriz de vectores propios izquierdos L y la
!>            matriz de vectores propios derechos R para la matriz T. Las
!>            columnas de L son los conjugados complejos de los vectores propios
!>            izquierdos de T. Las columnas de R son los vectores propios derechos
!>            de T. L es triangular inferior y R es triangular superior.
!>
!>            ZHSEIN calcula la matriz de vectores propios izquierdos Y y la
!>            matriz de vectores propios derechos X para la matriz H. Las
!>            columnas de Y son los conjugados complejos de los vectores propios
!>            izquierdos de H. Las columnas de X son los vectores propios derechos
!>            de H. Y es triangular inferior y X es triangular superior.
!>
!>            ZTREVC3 calcula matrices de vectores propios izquierdos y derechos
!>            a partir de una matriz de Schur T y las transforma de vuelta con Z
!>            en matrices de vectores propios L y R para A. L y R son
!>            matrices GE.
!>
!>    Cuando se llama a ZCHKHS, se especifica un número de tamaños de matriz  () y un
!>    número de tipos de matriz. Para cada tamaño ()
!>    y cada tipo de matriz, se generará y utilizará una matriz para
!>    probar las rutinas de valores propios no simétricos. Para cada matriz, se realizarán 16
!>    pruebas:
!>
!>    (1)     | A - U H U**H | / ( |A| n ulp )
!>
!>    (2)     | I - UU**H | / ( n ulp )
!>
!>    (3)     | H - Z T Z**H | / ( |H| n ulp )
!>
!>    (4)     | I - ZZ**H | / ( n ulp )
!>
!>    (5)     | A - UZ H (UZ)**H | / ( |A| n ulp )
!>
!>    (6)     | I - UZ (UZ)**H | / ( n ulp )
!>
!>    (7)     | T(Z calculado) - T(Z no calculado) | / ( |T| ulp )
!>
!>    (8)     | W(Z calculado) - W(Z no calculado) | / ( |W| ulp )
!>
!>    (9)     | TR - RW | / ( |T| |R| ulp )
!>
!>    (10)    | L**H T - W**H L | / ( |T| |L| ulp )
!>
!>    (11)    | HX - XW | / ( |H| |X| ulp )
!>
!>    (12)    | Y**H H - W**H Y | / ( |H| |Y| ulp )
!>
!>    (13)    | AX - XW | / ( |A| |X| ulp )
!>
!>    (14)    | Y**H A - W**H Y | / ( |A| |Y| ulp )
!>
!>    (15)    | AR - RW | / ( |A| |R| ulp )
!>
!>    (16)    | LA - WL | / ( |A| |L| ulp )
!>
!>    Los tamaños  se especifican mediante un array NN(1:NSIZES); el valor de
!>    cada elemento NN(j) especifica un tamaño.
!>    Los tipos  se especifican mediante un array lógico DOTYPE( 1:NTYPES );
!>    si DOTYPE(j) es .TRUE., entonces se generará el tipo de matriz .
!>    Actualmente, la lista de tipos posibles es:
!>
!>    (1)  La matriz cero.
!>    (2)  La matriz identidad.
!>    (3)  Un bloque de Jordan (transpuesto), con 1 en la diagonal.
!>
!>    (4)  Una matriz diagonal con entradas espaciadas uniformemente
!>         1, ..., ULP  y ángulos complejos aleatorios.
!>         (ULP = (primer número mayor que 1) - 1 )
!>    (5)  Una matriz diagonal con entradas espaciadas geométricamente
!>         1, ..., ULP  y ángulos complejos aleatorios.
!>    (6)  Una matriz diagonal con entradas  1, ULP, ..., ULP
!>         y ángulos complejos aleatorios.
!>
!>    (7)  Igual que (4), pero multiplicado por SQRT( umbral de desbordamiento )
!>    (8)  Igual que (4), pero multiplicado por SQRT( umbral de subdesbordamiento )
!>
!>    (9)  Una matriz de la forma  U' T U, donde U es unitaria y
!>         T tiene entradas espaciadas uniformemente 1, ..., ULP con ángulos complejos
!>         aleatorios en la diagonal y entradas O(1) aleatorias en el triángulo
!>         superior.
!>
!>    (10) Una matriz de la forma  U' T U, donde U es unitaria y
!>         T tiene entradas espaciadas geométricamente 1, ..., ULP con ángulos
!>         complejos aleatorios en la diagonal y entradas O(1) aleatorias en el
!>         triángulo superior.
!>
!>    (11) Una matriz de la forma  U' T U, donde U es unitaria y
!>         T tiene entradas  1, ULP,..., ULP con ángulos
!>         complejos aleatorios en la diagonal y entradas O(1) aleatorias en el
!>         triángulo superior.
!>
!>    (12) Una matriz de la forma  U' T U, donde U es unitaria y
!>         T tiene valores propios complejos elegidos aleatoriamente de
!>         ULP < |z| < 1   y entradas O(1) aleatorias en el triángulo
!>         superior.
!>
!>    (13) Una matriz de la forma  X' T X, donde X tiene condición
!>         SQRT( ULP ) y T tiene entradas espaciadas uniformemente 1, ..., ULP
!>         con ángulos complejos aleatorios en la diagonal y entradas O(1)
!>         aleatorias en el triángulo superior.
!>
!>    (14) Una matriz de la forma  X' T X, donde X tiene condición
!>         SQRT( ULP ) y T tiene entradas espaciadas geométricamente
!>         1, ..., ULP con ángulos complejos aleatorios en la diagonal y
!>         entradas O(1) aleatorias en el triángulo superior.
!>
!>    (15) Una matriz de la forma  X' T X, donde X tiene condición

!>         complejos aleatorios en la diagonal y entradas O(1) aleatorias en el
!>         triángulo superior.
!>
!>    (16) Una matriz de la forma  X' T X, donde X tiene condición

!>
!>    (17) Igual que (16), pero multiplicado por SQRT( umbral de desbordamiento )

NSIZES - INTEGER
          El número de tamaños de matrices a utilizar. Si es cero,
          ZCHKHS no hace nada. Debe ser al menos cero.
          No modificado.

NN     - INTEGER array, dimension (NSIZES)
          Un array que contiene los tamaños que se utilizarán para las matrices.
          Los valores cero se omitirán. Los valores deben ser al menos
          cero.
          No modificado.

NTYPES - INTEGER
          El número de elementos en DOTYPE. Si es cero, ZCHKHS
          no hace nada. Debe ser al menos cero. Si es MAXTYP+1
          y NSIZES es 1, entonces se define un tipo adicional, MAXTYP+1,
          que es usar la matriz que esté en A. Esto
          solo es útil si DOTYPE(1:MAXTYP) es .FALSE. y
          DOTYPE(MAXTYP+1) es .TRUE. .
          No modificado.

DOTYPE - LOGICAL array, dimension (NTYPES)
          Si DOTYPE(j) es .TRUE., entonces para cada tamaño en NN se
          generará una matriz de ese tamaño y de tipo j.
          Si NTYPES es menor que el número máximo de tipos
          definidos (PARAMETER MAXTYP), entonces los tipos NTYPES+1 hasta
          MAXTYP no se generarán. Si NTYPES es mayor
          que MAXTYP, DOTYPE(MAXTYP+1) hasta DOTYPE(NTYPES)
          se ignorarán.
          No modificado.

ISEED  - INTEGER array, dimension (4)
          En la entrada, ISEED especifica la semilla del generador
          de números aleatorios. Los elementos del array deben estar
          entre 0 y 4095; si no, se reducirán módulo 4096.
          Además, ISEED(4) debe ser impar. El generador de números
          aleatorios utiliza una secuencia congruencial lineal limitada a
          enteros pequeños, y por lo tanto debería producir números
          aleatorios independientes de la máquina. Los
          valores de ISEED se modifican a la salida y pueden usarse en la
          siguiente llamada a ZCHKHS para continuar la misma secuencia
          de números aleatorios.
          Modificado.

THRESH - DOUBLE PRECISION
          Una prueba se considerará que ha fallado si el error,
          calculado como se describe anteriormente, excede THRESH.
          Tenga en cuenta que el error se escala para que sea O(1), por
          lo que THRESH debe ser un múltiplo razonablemente pequeño de 1,
          por ejemplo, 10 o 100. En particular,
          no debe depender de la precisión (simple frente a doble)
          o del tamaño de la matriz. Debe ser al menos cero.
          No modificado.

NOUNIT - INTEGER
          El número de unidad FORTRAN para imprimir mensajes de error
          (por ejemplo, si una rutina devuelve IINFO distinto de 0).
          No modificado.

A      - COMPLEX*16 array, dimension (LDA,max(NN))
          Se utiliza para almacenar la matriz cuyos valores propios
          se van a calcular. A la salida, A contiene la última matriz utilizada.
          Modificado.

LDA    - INTEGER
          La dimensión principal de A, H, T1 y T2. Debe ser
          al menos 1 y al menos max( NN ).
          No modificado.

H      - COMPLEX*16 array, dimension (LDA,max(NN))
          La matriz de Hessenberg superior calculada por ZGEHRD.
          A la salida, H contiene la forma de Hessenberg de la matriz en A.
          Modificado.

T1     - COMPLEX*16 array, dimension (LDA,max(NN))
          La matriz de Schur (=) calculada por ZHSEQR
          si se calcula Z. A la salida, T1 contiene la forma de Schur de
          la matriz en A.
          Modificado.

T2     - COMPLEX*16 array, dimension (LDA,max(NN))
          La matriz de Schur calculada por ZHSEQR cuando Z no se calcula.
          Debe ser idéntica a T1.
          Modificado.

LDU    - INTEGER
          La dimensión principal de U, Z, UZ y UU. Debe ser
          al menos 1 y al menos max( NN ).
          No modificado.

U      - COMPLEX*16 array, dimension (LDU,max(NN))
          La matriz unitaria calculada por ZGEHRD.
          Modificado.

Z      - COMPLEX*16 array, dimension (LDU,max(NN))
          La matriz unitaria calculada por ZHSEQR.
          Modificado.

UZ     - COMPLEX*16 array, dimension (LDU,max(NN))
          El producto de U por Z.
          Modificado.

W1     - COMPLEX*16 array, dimension (max(NN))
          Los valores propios de A, calculados por una descomposición
          de Schur completa H = Z T Z'. A la salida, W1 contiene los
          valores propios de la matriz en A.
          Modificado.

W3     - COMPLEX*16 array, dimension (max(NN))
          Los valores propios de A, calculados por una descomposición
          de Schur parcial (Z no calculada, T calculada solo tanto
          como sea necesario para determinar los valores propios).
          A la salida, W3 contiene los valores propios de la matriz en A,
          posiblemente perturbados por ZHSEIN.
          Modificado.

EVECTL - COMPLEX*16 array, dimension (LDU,max(NN))
          La traspuesta conjugada de la matriz de vectores propios izquierdos
          (triangular superior) para la matriz en T1.
          Modificado.

EVEZTR - COMPLEX*16 array, dimension (LDU,max(NN))
          La matriz de vectores propios derechos (triangular superior)
          para la matriz en T1.
          Modificado.

EVECTY - COMPLEX*16 array, dimension (LDU,max(NN))
          La traspuesta conjugada de la matriz de vectores propios izquierdos
          para la matriz en H.
          Modificado.

EVECTX - COMPLEX*16 array, dimension (LDU,max(NN))
          La matriz de vectores propios derechos para la matriz en H.
          Modificado.

UU     - COMPLEX*16 array, dimension (LDU,max(NN))
          Detalles de la matriz unitaria calculada por ZGEHRD.
          Modificado.

TAU    - COMPLEX*16 array, dimension (max(NN))
          Detalles adicionales de la matriz unitaria calculada por ZGEHRD.
          Modificado.

WORK   - COMPLEX*16 array, dimension (NWORK)
          Espacio de trabajo.
          Modificado.

NWORK  - INTEGER
          El número de entradas en WORK. NWORK >= 4*NN(j)*NN(j) + 2.

RWORK  - DOUBLE PRECISION array, dimension (max(NN))
          Espacio de trabajo. Podría estar en equivalencia con IWORK,
          pero no con SELECT.
          Modificado.

IWORK  - INTEGER array, dimension (max(NN))
          Espacio de trabajo.
          Modificado.

SELECT - LOGICAL array, dimension (max(NN))
          Espacio de trabajo. Podría estar en equivalencia con IWORK,
          pero no con RWORK.
          Modificado.

RESULT - DOUBLE PRECISION array, dimension (16)
          Los valores calculados por las catorce pruebas descritas
          anteriormente. Los valores están actualmente limitados a 1/ulp,
          para evitar desbordamientos.
          Modificado.

INFO   - INTEGER
          Si es 0, entonces todo funcionó correctamente.
           -1: NSIZES < 0
           -2: Algún NN(j) < 0
           -3: NTYPES < 0
           -6: THRESH < 0
           -9: LDA < 1 o LDA < NMAX, donde NMAX es max( NN(j) ).
          -14: LDU < 1 o LDU < NMAX.
          -26: NWORK es demasiado pequeño.
          Si ZLATMR, CLATMS o CLATME devuelven un código de error, se
              devuelve su valor absoluto.
          Si es 1, entonces ZHSEQR no pudo encontrar todos los desplazamientos.
          Si es 2, entonces el código EISPACK (para bloques pequeños) falló.
          Si es >2, entonces 30*N iteraciones no fueron suficientes para
              encontrar un valor propio o para descomponer el problema.
          Modificado.

    zchkhs(3)

    NAME

    zchkhs - Check for Hamiltonian cycles

    SYNOPSIS

    int zchkhs(int n, const int *adj, int *cycle)

    Function/Subroutine Documentation

    The zchkhs function checks if a given undirected graph contains a Hamiltonian cycle.

    Parameters:

    • n: The number of vertices in the graph.
    • adj: An array representing the adjacency matrix of the graph. adj[i*n + j] is 1 if there is an edge between vertex i and vertex j, and 0 otherwise.
    • cycle: An array to store the Hamiltonian cycle if one is found. The array should have a size of at least n. If a cycle is found, cycle[i] will contain the i-th vertex in the cycle.

    Return Value:

    • Returns 1 if a Hamiltonian cycle is found, and 0 otherwise.

    Description:

    A Hamiltonian cycle is a cycle in an undirected graph that visits each vertex exactly once and returns to the starting vertex. This function implements a backtracking algorithm to find such a cycle.

    The algorithm starts from an arbitrary vertex (usually vertex 0) and tries to build a path by visiting adjacent vertices. It keeps track of the visited vertices to ensure each vertex is visited only once. If the path includes all vertices and the last vertex is adjacent to the starting vertex, a Hamiltonian cycle is found. If at any point the algorithm cannot extend the path, it backtracks to the previous vertex and tries a different path.

    The adjacency matrix adj is assumed to be symmetric since the graph is undirected. The diagonal elements (adj[i*n + i]) are typically 0.

    If a Hamiltonian cycle is found, the function populates the cycle array with the sequence of vertices forming the cycle. The first element of cycle will be the starting vertex, and the last element will be the vertex before returning to the start.

    The time complexity of this algorithm is generally exponential in the worst case, as it might need to explore a significant portion of the possible paths.
