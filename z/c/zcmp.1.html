NOMBRE

zcmp, zdiff - comparar archivos comprimidos

SINOPSIS

zcmp [ opciones_cmp ] archivo1 [ archivo2 ]
zdiff [ opciones_diff ] archivo1 [ archivo2 ]

DESCRIPCIÓN

Los comandos zcmp y zdiff se utilizan para invocar el programa cmp o diff en archivos comprimidos con gzip. Todas las opciones especificadas se pasan directamente a cmp o diff. Si solo se especifica archivo1, se compara con el contenido descomprimido de archivo1.gz. Si se especifican dos archivos, sus contenidos (descomprimidos si es necesario) se alimentan a cmp o diff. Los archivos de entrada no se modifican. El estado de salida de cmp o diff se conserva.

VER TAMBIÉN

cmp(1), diff(1), zmore(1), zgrep(1), znew(1), zforce(1), gzip(1), gzexe(1)

ERRORES

Los mensajes de los programas cmp o diff pueden referirse a nombres de archivo como "-" en lugar de a los nombres de archivo especificados.
