ZCKGSV

Propósito

!>
!> ZCKGSV prueba ZGGSVD:
!>        la GSVD para la matriz M-por-N A y la matriz P-por-N B.
!>

Parámetros

NM 
!>          NM es ENTERO
!>          El número de valores de M contenidos en el vector MVAL.
!>

MVAL

!>          MVAL es un array ENTERO, dimension (NM)
!>          Los valores de la dimensión de fila de la matriz M.
!>

PVAL

!>          PVAL es un array ENTERO, dimension (NP)
!>          Los valores de la dimensión de fila de la matriz P.
!>

NVAL

!>          NVAL es un array ENTERO, dimension (NN)
!>          Los valores de la dimensión de columna de la matriz N.
!>

NMATS

!>          NMATS es ENTERO
!>          El número de tipos de matrices a probar para cada combinación
!>          de dimensiones de matriz. Si NMATS >= NTYPES (el número máximo
!>          de tipos de matriz), entonces se generan todos los tipos diferentes
!>          para la prueba. Si NMATS < NTYPES, se lee otra línea de entrada
!>          para obtener los números de los tipos de matriz a utilizar.
!>

ISEED

!>          ISEED es un array ENTERO, dimension (4)
!>          A la entrada, la semilla del generador de números aleatorios. Los elementos
!>          del array deben estar entre 0 y 4095, de lo contrario se reducirán
!>          módulo 4096, y ISEED(4) debe ser impar.
!>          A la salida, la siguiente semilla en la secuencia de números aleatorios
!>          después de que todas las matrices de prueba hayan sido generadas.
!>

THRESH

!>          THRESH es DOUBLE PRECISION
!>          El valor umbral para las relaciones de prueba. Un resultado se
!>          incluye en el archivo de salida si RESULT >= THRESH. Para que
!>          se imprima cada relación de prueba, use THRESH = 0.
!>

NMAX

!>          NMAX es ENTERO
!>          El valor máximo permitido para M o N, utilizado en la dimensionamiento
!>          de los arrays de trabajo.
!>

A

!>          A es un array COMPLEX*16, dimension (NMAX*NMAX)
!>

AF

!>          AF es un array COMPLEX*16, dimension (NMAX*NMAX)
!>

B

!>          B es un array COMPLEX*16, dimension (NMAX*NMAX)
!>

BF

!>          BF es un array COMPLEX*16, dimension (NMAX*NMAX)
!>

U

!>          U es un array COMPLEX*16, dimension (NMAX*NMAX)
!>

V

!>          V es un array COMPLEX*16, dimension (NMAX*NMAX)
!>

Q

!>          Q es un array COMPLEX*16, dimension (NMAX*NMAX)
!>

ALPHA

!>          ALPHA es un array DOUBLE PRECISION, dimension (NMAX)
!>

BETA

!>          BETA es un array DOUBLE PRECISION, dimension (NMAX)
!>

R

!>          R es un array COMPLEX*16, dimension (NMAX*NMAX)
!>

IWORK

!>          IWORK es un array ENTERO, dimension (NMAX)
!>

WORK

!>          WORK es un array COMPLEX*16, dimension (NMAX*NMAX)
!>

RWORK

!>          RWORK es un array DOUBLE PRECISION, dimension (NMAX)
!>

NIN

!>          NIN es ENTERO
!>          La unidad de acceso para entrada.
!>

NOUT

!>          NOUT es ENTERO
!>          La unidad de acceso para salida.
!>

INFO

!>          INFO es ENTERO
!>          = 0 :  salida exitosa
!>          > 0 :  Si ZLATMS devuelve un código de error, su valor absoluto
!>                 se devuelve.
!>
