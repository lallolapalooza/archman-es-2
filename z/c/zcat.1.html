GZIP(1) Manual de Comandos Generales GZIP(1)

NOMBRE

gzip, gunzip, zcat - comprimir o expandir archivos

SINOPSIS

gzip [ -acdfhklLnNrtvV19 ] [-S sufijo] [ nombre ... ]
gunzip [ -acfhklLnNrtvV ] [-S sufijo] [ nombre ... ]
zcat [ -fhLV ] [ nombre ... ]

DESCRIPCIÓN

El comando gzip reduce el tamaño de los archivos nombrados utilizando codificación Lempel-Ziv (LZ77). Siempre que sea posible, cada archivo se reemplaza por uno con la extensión .gz, conservando los mismos permisos de propietario, y los tiempos de acceso y modificación. (La extensión predeterminada es z para MSDOS, FAT de OS/2, FAT de Windows NT y Atari.) Si no se especifican archivos, o si un nombre de archivo es "-", la entrada estándar se comprime a la salida estándar. El comando gzip solo intentará comprimir archivos regulares. En particular, ignorará los enlaces simbólicos.

Si el nombre del archivo comprimido es demasiado largo para su sistema de archivos, gzip lo trunca. El comando gzip intenta truncar solo las partes del nombre de archivo que tengan más de 3 caracteres de longitud. (Una parte está delimitada por puntos). Si el nombre consta solo de partes pequeñas, se truncan las partes más largas. Por ejemplo, si los nombres de archivo están limitados a 14 caracteres, gzip.msdos.exe se comprime a gzi.msd.exe.gz. Los nombres no se truncan en sistemas que no tienen un límite en la longitud del nombre de archivo.

Por defecto, gzip mantiene el nombre original del archivo y la marca de tiempo en el archivo comprimido. Estos se utilizan al descomprimir el archivo con la opción -N. Esto es útil cuando el nombre del archivo comprimido fue truncado o cuando la marca de tiempo no se conservó después de una transferencia de archivos.

Los archivos comprimidos se pueden restaurar a su forma original usando gzip -d o gunzip o zcat. Si el nombre original guardado en el archivo comprimido no es adecuado para su sistema de archivos, se construye un nuevo nombre a partir del original para hacerlo válido.

gunzip toma una lista de archivos en su línea de comandos y reemplaza cada archivo cuyo nombre termina con .gz, -gz, .z, -z, o _z (ignorando mayúsculas/minúsculas) y que comienza con el número mágico correcto con un archivo descomprimido sin la extensión original. gunzip también reconoce las extensiones especiales .tgz y .taz como atajos para .tar.gz y .tar.Z respectivamente. Al comprimir, gzip usa la extensión .tgz si es necesario en lugar de truncar un archivo con una extensión .tar.

Actualmente gunzip puede descomprimir archivos creados por gzip, zip, compress, compress -H o pack. La detección del formato de entrada es automática. Al usar los dos primeros formatos, gunzip verifica una CRC de 32 bits. Para pack y gunzip verifica la longitud sin comprimir. El formato estándar compress no fue diseñado para permitir verificaciones de consistencia. Sin embargo, gunzip a veces puede detectar un archivo .Z defectuoso. Si obtiene un error al descomprimir un archivo .Z, no asuma que el archivo .Z es correcto simplemente porque el uncompress estándar no se queja. Esto generalmente significa que el uncompress estándar no verifica su entrada y genera felizmente resultados basura. El formato SCO compress -H (método de compresión lzh) no incluye una CRC pero también permite algunas verificaciones de consistencia.

Los archivos creados por zip solo pueden ser descomprimidos por gzip si tienen un solo miembro comprimido con el método 'deflate'. Esta característica solo está destinada a ayudar a la conversión de archivos tar.zip al formato tar.gz. Para extraer un archivo zip con un solo miembro, use un comando como 'gunzip <foo.zip' o 'gunzip -S .zip foo.zip'. Para extraer archivos zip con varios miembros, use unzip en lugar de gunzip.

El comando zcat es idéntico a gunzip -c. (En algunos sistemas, zcat puede estar instalado como gzcat para preservar el enlace original a compress.) zcat descomprime una lista de archivos en la línea de comandos o su entrada estándar y escribe los datos descomprimidos en la salida estándar. zcat descomprimirá archivos que tengan el número mágico correcto, tengan o no el sufijo .gz.

El comando gzip utiliza el algoritmo Lempel-Ziv utilizado en zip y PKZIP. La cantidad de compresión obtenida depende del tamaño de la entrada y la distribución de subcadenas comunes. Típicamente, el texto como código fuente o inglés se reduce en un 60%–70%. La compresión es generalmente mucho mejor que la lograda por LZW (como se usa en compress), codificación Huffman (como se usa en pack) o codificación Huffman adaptativa (compact).

La compresión siempre se realiza, incluso si el archivo comprimido es ligeramente más grande que el original. La expansión en el peor caso es de unos pocos bytes para la cabecera del archivo gzip, más 5 bytes por cada bloque de 32 KiB, o una relación de expansión del 0.015% para archivos grandes. El número real de bloques de disco utilizados casi nunca aumenta.

gzip normalmente conserva el modo y la marca de tiempo de modificación de un archivo al comprimir o descomprimir. Si tiene los privilegios apropiados, también conserva el propietario y el grupo del archivo.

OPCIONES

-a --ascii
Modo de texto ASCII: convierte los finales de línea usando convenciones locales. Esta opción solo se admite en algunos sistemas no Unix. Para MSDOS, CR LF se convierte a LF al comprimir, y LF se convierte a CR LF al descomprimir.
-c --stdout --to-stdout
Escribir la salida en la salida estándar; mantener los archivos originales sin cambios. Si hay varios archivos de entrada, la salida consiste en una secuencia de miembros comprimidos de forma independiente. Para obtener una mejor compresión, concatene todos los archivos de entrada antes de comprimirlos.
-d --decompress --uncompress
Descomprimir.
-f --force
Forzar la compresión o descompresión incluso si el archivo tiene múltiples enlaces o el archivo correspondiente ya existe, o si los datos comprimidos se leen o escriben en un terminal. Si los datos de entrada no están en un formato reconocido por gzip, y si la opción --stdout también está dada, copiar los datos de entrada sin cambios a la salida estándar: dejar que zcat se comporte como cat. Si no se da -f, y cuando no se ejecuta en segundo plano, gzip solicita verificar si se debe sobrescribir un archivo existente.
-h --help
Mostrar una pantalla de ayuda y salir.
-k --keep
Mantener (no eliminar) los archivos de entrada durante la compresión o descompresión.
-l --list
Para cada archivo comprimido, listar los siguientes campos:


tamaño comprimido: tamaño del archivo comprimido
tamaño sin comprimir: tamaño del archivo sin comprimir
ratio: relación de compresión (0.0% si es desconocido)
nombre_sin_comprimir: nombre del archivo sin comprimir

El tamaño sin comprimir se da como -1 para archivos que no están en formato gzip, como los archivos .Z comprimidos. Para obtener el tamaño sin comprimir de dicho archivo, puede usar:


zcat file.Z | wc -c

En combinación con la opción --verbose, también se muestran los siguientes campos:


método: método de compresión
crc: la CRC de 32 bits de los datos sin comprimir
fecha y hora: marca de tiempo para el archivo sin comprimir

Los métodos de compresión actualmente admitidos son deflate, compress, lzh (SCO compress -H) y pack. La crc se da como ffffffff para un archivo que no está en formato gzip.

Con --name, el nombre sin comprimir, la fecha y la hora son los almacenados dentro del archivo comprimido si están presentes.

Con --verbose, también se muestran los totales de tamaño y la relación de compresión para todos los archivos, a menos que algunos tamaños sean desconocidos. Con --quiet, las líneas de título y totales no se muestran.

-L --license
Mostrar la licencia de gzip y salir.
-n --no-name
Al comprimir, no guardar el nombre y la marca de tiempo originales del archivo por defecto. (El nombre original siempre se guarda si el nombre tuvo que ser truncado). Al descomprimir, no restaurar el nombre original del archivo si está presente (eliminar
Solo el sufijo gzip del nombre del archivo comprimido) y no restaure la marca de tiempo original si está presente (cópiela del archivo comprimido). Esta opción es la predeterminada al descomprimir.
-N --name
Al comprimir, guarde siempre el nombre de archivo original y guarde la parte de segundos de la marca de tiempo de modificación original si la original es un archivo regular y su marca de tiempo es al menos 1 (1970-01-01 00:00:01 UTC) y es menor que 2**32 (2106-02-07 06:28:16 UTC, asumiendo que no se cuentan los segundos bisiestos); esta es la opción predeterminada. Al descomprimir, restaure desde el nombre de archivo y la marca de tiempo guardados si están presentes. Esta opción es útil en sistemas que tienen un límite en la longitud del nombre del archivo o cuando la marca de tiempo se ha perdido después de una transferencia de archivos.
-q --quiet
Suprimir todas las advertencias.
-r --recursive
Recorrer la estructura del directorio de forma recursiva. Si alguno de los nombres de archivo especificados en la línea de comandos son directorios, gzip descenderá en el directorio y comprimirá todos los archivos que encuentre allí (o los descomprimirá en el caso de gunzip).
-S .suf --suffix .suf
Al comprimir, utilice el sufijo .suf en lugar de .gz. Aunque se puede proporcionar cualquier sufijo no vacío siempre que no contenga "/", se deben evitar sufijos distintos de .z y .gz para evitar confusiones cuando los archivos se transfieren a otros sistemas.

Al descomprimir, agregue .suf al principio de la lista de sufijos a probar, al derivar un nombre de archivo de salida de un nombre de archivo de entrada.

--synchronous
Utilizar salida síncrona. Con esta opción, es menos probable que gzip pierda datos durante un fallo del sistema, pero puede ser considerablemente más lento.
-t --test
Probar. Comprobar la integridad del archivo comprimido y luego salir.
-v --verbose
Detallado. Mostrar el nombre y el porcentaje de reducción para cada archivo comprimido o descomprimido.
-V --version
Versión. Mostrar el número de versión y las opciones de compilación y luego salir.
-# --fast --best
Regular la velocidad de compresión utilizando el dígito especificado #, donde -1 o --fast indica el método de compresión más rápido (menos compresión) y -9 o --best indica el método de compresión más lento (mejor compresión). El nivel de compresión predeterminado es -6 (es decir, sesgado hacia una alta compresión a expensas de la velocidad).
--rsyncable
Cuando sincronice un archivo comprimido entre dos ordenadores, esta opción permite a rsync transferir solo los archivos que se modificaron en el archivo en lugar de todo el archivo. Normalmente, después de realizar un cambio en cualquier archivo del archivo, el algoritmo de compresión puede generar una nueva versión del archivo que no coincide con la versión anterior del archivo. En este caso, rsync transfiere toda la nueva versión del archivo al ordenador remoto. Con esta opción, rsync puede transferir solo los archivos modificados, así como una pequeña cantidad de metadatos que se requieren para actualizar la estructura del archivo en el área que se modificó.

USO AVANZADO

Se pueden concatenar varios archivos comprimidos. En este caso, gunzip extraerá todos los miembros a la vez. Por ejemplo:


gzip -c file1 > foo.gz
gzip -c file2 >> foo.gz

Entonces


gunzip -c foo

es equivalente a


cat file1 file2

En caso de daño en un miembro de un archivo .gz, otros miembros aún pueden recuperarse (si el miembro dañado se elimina). Sin embargo, puede obtener una mejor compresión comprimiendo todos los miembros a la vez:


cat file1 file2 | gzip > foo.gz

comprime mejor que


gzip -c file1 file2 > foo.gz

Si desea volver a comprimir archivos concatenados para obtener una mejor compresión, haga:


gzip -cd old.gz | gzip > new.gz

Si un archivo comprimido consta de varios miembros, el tamaño sin comprimir y el CRC informados por la opción --list se aplican solo al último miembro. Si necesita el tamaño sin comprimir para todos los miembros, puede usar:


gzip -cd file.gz | wc -c

Si desea crear un único archivo de archivo con varios miembros para que los miembros puedan extraerse de forma independiente más tarde, utilice un archivador como tar o zip. GNU tar admite la opción -z para invocar gzip de forma transparente. gzip está diseñado como un complemento de tar, no como un reemplazo.

ENTORNO

La variable de entorno GZIP puede contener un conjunto de opciones predeterminadas para gzip. Estas opciones se interpretan en primer lugar y pueden ser anuladas por parámetros explícitos de la línea de comandos. Como esto puede causar problemas al usar scripts, esta función solo es compatible con --rsyncable, --synchronous y opciones como -9 que establecen el nivel de compresión; cualquier otra opción u operando en GZIP se ignora silenciosamente.

Puede usar una alias o un script en su lugar. Por ejemplo, en lugar de establecer GZIP="-9" en el entorno, si gzip está en el directorio /usr/bin, puede anteponer $HOME/bin a su PATH y crear un script ejecutable $HOME/bin/gzip que contenga lo siguiente:


#! /bin/sh
export PATH=/usr/bin
exec gzip -9 "$@"

DIAGNÓSTICOS

El estado de salida es normalmente 0; si ocurre un error, el estado de salida es 1. Si ocurre una advertencia, el estado de salida es 2.

Uso: gzip [-cdfhklLnNrtvV19] [-S sufijo] [archivo ...]
Se especificaron opciones inválidas en la línea de comandos.
archivo: no está en formato gzip
El archivo especificado a gunzip no ha sido comprimido.
archivo: Entrada corrupta.
Utilice zcat para recuperar algunos datos. El archivo comprimido se ha dañado. Los datos hasta el punto de fallo se pueden recuperar usando


zcat archivo > recuperar

archivo: comprimido con xx bits, solo puede manejar yy bits
El archivo fue comprimido (usando LZW) por un programa que podía manejar más bits que el código de descompresión en esta máquina. Vuelva a comprimir el archivo con gzip, que comprime mejor y utiliza menos memoria.
archivo: ya tiene el sufijo .gz -- sin cambios
Se asume que el archivo ya está comprimido. Renombre el archivo e inténtelo de nuevo.
archivo ya existe; ¿desea sobrescribir (s o n)?
Responda "s" si desea que el archivo de salida sea reemplazado; "n" si no.
gunzip: entrada corrupta
Se detectó una violación SIGSEGV que generalmente significa que el archivo de entrada se ha corrompido.
xx.x% Porcentaje de la entrada ahorrado por la compresión.
(Solo relevante para -v y -l.)
-- no es un archivo o directorio regular: ignorado
Cuando el archivo de entrada no es un archivo o directorio regular (por ejemplo, un enlace simbólico, socket, FIFO, archivo de dispositivo), se deja sin alterar.
-- tiene xx enlaces más: sin cambios
El archivo de entrada tiene enlaces; se deja sin cambios. Consulte ln(1) para obtener más información. Use la bandera -f para forzar la compresión de archivos con múltiples enlaces.

ADVERTENCIAS

Al escribir datos comprimidos en una cinta, generalmente es necesario rellenar la salida con ceros hasta un límite de bloque. Cuando los datos se leen y todo el bloque se pasa a gunzip para su descompresión, gunzip detecta que hay basura adicional al final después de los datos comprimidos y emite una advertencia por defecto. Puede usar la opción --quiet para suprimir la advertencia.

ERRORES

En casos raros, la opción --best da una compresión peor que el nivel de compresión predeterminado (-6). En algunos archivos muy redundantes, compress comprime mejor que gzip.
