ZCHKBD

Propósito:

!>
!> ZCHKBD comprueba las rutinas de descomposición de valores singulares (SVD).
!>
!> ZGEBRD reduce una matriz general compleja m por n, A, a una forma
!> bidiagonal real superior o inferior mediante una transformación ortogonal:
!> Q' * A * P = B (o A = Q * B * P'). La matriz B es bidiagonal superior
!> si m >= n y bidiagonal inferior si m < n.
!>
!> ZUNGBR genera las matrices ortogonales Q y P' a partir de ZGEBRD.
!> Nótese que Q y P no son necesariamente cuadradas.
!>
!> ZBDSQR calcula la descomposición de valores singulares de la matriz
!> bidiagonal B como B = U S V'. Se llama tres veces para calcular
!>    1)  B = U S1 V', donde S1 es la matriz diagonal de valores singulares
!>        y las columnas de las matrices U y V son los vectores singulares
!>        izquierdos y derechos, respectivamente, de B.
!>    2)  Igual que 1), pero los valores singulares se almacenan en S2 y
!>        no se calculan los vectores singulares.
!>    3)  A = (UQ) S (P'V'), la SVD de la matriz original A.
!> Además, ZBDSQR tiene una opción para aplicar la matriz ortogonal
!> izquierda U a una matriz X, útil en aplicaciones de mínimos cuadrados.
!>
!> Para cada par de dimensiones de matriz (M,N) y cada tipo de matriz
!> seleccionado, se generan una matriz A de m por n y una matriz X de m
!> por NRHS. Las dimensiones del problema son las siguientes:
!>    A:          M x N
!>    Q:          M x min(M,N) (pero M x M si NRHS > 0)
!>    P:          min(M,N) x N
!>    B:          min(M,N) x min(M,N)
!>    U, V:       min(M,N) x min(M,N)
!>    S1, S2      diagonal, orden min(M,N)
!>    X:          M x NRHS
!>
!> Para cada matriz generada, se realizan 14 pruebas:
!>
!> Prueba ZGEBRD y ZUNGBR
!>
!> (1)   | A - Q B PT | / ( |A| max(M,N) ulp ), PT = P'
!>
!> (2)   | I - Q' Q | / ( M ulp )
!>
!> (3)   | I - PT PT' | / ( N ulp )
!>
!> Prueba ZBDSQR en matriz bidiagonal B
!>
!> (4)   | B - U S1 VT | / ( |B| min(M,N) ulp ), VT = V'
!>
!> (5)   | Y - U Z | / ( |Y| max(min(M,N),k) ulp ), donde Y = Q' X
!>                                                  y   Z = U' Y.
!> (6)   | I - U' U | / ( min(M,N) ulp )
!>
!> (7)   | I - VT VT' | / ( min(M,N) ulp )
!>
!> (8)   S1 contiene min(M,N) valores no negativos en orden decreciente.
!>       (Devuelve 0 si es cierto, 1/ULP si es falso).
!>
!> (9)   0 si los valores singulares verdaderos de B están dentro de
!>       THRESH de los de S1.  2*THRESH si no lo están.  (Comprobado
!>       usando DSVDCH)
!>
!> (10)  | S1 - S2 | / ( |S1| ulp ), donde S2 se calcula sin
!>                                   calcular U y V.
!>
!> Prueba ZBDSQR en matriz A
!>
!> (11)  | A - (QU) S (VT PT) | / ( |A| max(M,N) ulp )
!>
!> (12)  | X - (QU) Z | / ( |X| max(M,k) ulp )
!>
!> (13)  | I - (QU)'(QU) | / ( M ulp )
!>
!> (14)  | I - (VT PT) (PT'VT') | / ( N ulp )
!>
!> Los posibles tipos de matriz son
!>
!> (1)  La matriz cero.
!> (2)  La matriz identidad.
!>
!> (3)  Una matriz diagonal con entradas espaciadas uniformemente
!>      1, ..., ULP  y signos aleatorios.
!>      (ULP = (primer número mayor que 1) - 1 )
!> (4)  Una matriz diagonal con entradas espaciadas geométricamente
!>      1, ..., ULP  y signos aleatorios.
!> (5)  Una matriz diagonal con entradas 1, ULP, ..., ULP
!>      y signos aleatorios.
!>
!> (6)  Igual que (3), pero multiplicado por SQRT( umbral de
!>      desbordamiento )
!> (7)  Igual que (3), pero multiplicado por SQRT( umbral de
!>      subdesbordamiento )
!>
!> (8)  Una matriz de la forma  U D V, donde U y V son ortogonales y
!>      D tiene entradas espaciadas uniformemente 1, ..., ULP con
!>      signos aleatorios en la diagonal.
!>
!> (9)  Una matriz de la forma  U D V, donde U y V son ortogonales y
!>      D tiene entradas espaciadas geométricamente 1, ..., ULP con
!>      signos aleatorios en la diagonal.
!>
!> (10) Una matriz de la forma  U D V, donde U y V son ortogonales y
!>      D tiene entradas 1, ULP,..., ULP con signos aleatorios
!>      en la diagonal.
!>
!> (11) Igual que (8), pero multiplicado por SQRT( umbral de
!>      desbordamiento )
!> (12) Igual que (8), pero multiplicado por SQRT( umbral de
!>      subdesbordamiento )
!>
!> (13) Matriz rectangular con entradas aleatorias elegidas de (-1,1).
!> (14) Igual que (13), pero multiplicado por SQRT( umbral de
!>      desbordamiento )
!> (15) Igual que (13), pero multiplicado por SQRT( umbral de
!>      subdesbordamiento )
!>
!> Caso especial:
!> (16) Una matriz bidiagonal con entradas aleatorias elegidas de una
!>      distribución logarítmica en [ulp^2,ulp^(-2)]  (Es decir, cada
!>      entrada es  e^x, donde x se elige uniformemente en
!>      [ 2 log(ulp), -2 log(ulp) ] .)  Para *este* tipo:
!>      (a) ZGEBRD no se llama para reducirla a forma bidiagonal.
!>      (b) la bidiagonal es  min(M,N) x min(M,N); si M

Function/Subroutine Documentation

SUBROUTINE ZCHBD

ZCHBD es una rutina de prueba para el paquete ZBCC: rutinas de bidiagonalización de matrices rectangulares complejas. A continuación se describen los parámetros del argumento. A continuación se definen las variables y parámetros locales.

Argumentos de Entrada/Salida:

NSIZES
 NSIZES es INTEGER
 El número de pares (M,N) a probar.
NVAL
 NVAL es INTEGER array, dimension (NSIZES)
 Los valores de N a probar. NVAL(j) debe ser al menos 0.
NMAX
 NMAX es INTEGER
 El valor máximo de N en NVAL.
NTYPES
 NTYPES es INTEGER
 El número de tipos de matriz a probar.
 El tipo J se especifica mediante los valores de KVAL(J), KMODE(J),
 y KMAGN(J). Si JTYPE = 1,...10,
 entonces KVAL(J) es el valor general de tipo, KMODE(J) es el modo
 a pasar a la rutina generadora de matrices, y KMAGN(J) es la
 orden de magnitud.
 Si NTYPES es mayor que el número máximo de tipos definidos
 (PARÁMETRO MAXTYP), entonces los tipos NTYPES+1 a MAXTYP no se generarán.
 Si NTYPES es mayor que MAXTYP, DOTYPE(MAXTYP+1) a DOTYPE(NTYPES) se ignorarán.
KVAL
 KVAL es INTEGER array, dimension (NTYPES)
 Define el tipo de matriz a generar.
NPERTS
 NPERTS es INTEGER
 El número de perturbaciones a realizar en cada matriz generada.
 Por ejemplo, si se genera una matriz de tipo 1, entonces NPERTS
 matrices se generan y se prueban.
NRHS
 NRHS es INTEGER
 El número de columnas en las matrices X, Y,
 y Z, utilizados en la prueba de ZBDSQR. Si NRHS = 0, entonces las
 operaciones del lado derecho no se pondrán a prueba.
 NRHS debe ser al menos 0.
ISEED
 ISEED es un array INTEGER, dimension (4)
 En la entrada, ISEED especifica la semilla del generador de números
 aleatorios. Los elementos del array deben estar entre 0 y 4095;
 si no, se reducirán módulo 4096. Además, ISEED(4) debe
 ser impar. Los valores de ISEED se modifican en la salida y pueden
 usarse en la siguiente llamada a ZCHKBD para continuar la misma secuencia
 de números aleatorios.
THRESH
 THRESH es DOUBLE PRECISION
 El valor umbral para las relaciones de prueba. Un resultado se
 incluye en el archivo de salida si RESULT >= THRESH. Para que cada
 relación de prueba se imprima, use THRESH = 0. Tenga en cuenta que el
 valor esperado de las relaciones de prueba es O(1), por lo que THRESH debería
 ser un múltiplo razonablemente pequeño de 1, por ejemplo, 10 o 100.
A
 A es un array COMPLEX*16, dimension (LDA,NMAX)
 donde NMAX es el valor máximo de N en NVAL.
LDA
 LDA es INTEGER
 La dimensión principal del array A. LDA >= max(1,MMAX),
 donde MMAX es el valor máximo de M en MVAL.
BD
 BD es un array DOUBLE PRECISION, dimension
 (max(min(MVAL(j),NVAL(j))))
BE
 BE es un array DOUBLE PRECISION, dimension
 (max(min(MVAL(j),NVAL(j))))
S1
 S1 es un array DOUBLE PRECISION, dimension
 (max(min(MVAL(j),NVAL(j))))
S2
 S2 es un array DOUBLE PRECISION, dimension
 (max(min(MVAL(j),NVAL(j))))
X
 X es un array COMPLEX*16, dimension (LDX,NRHS)
LDX
 LDX es INTEGER
 La dimensión principal de los arrays X, Y y Z.
 LDX >= max(1,MMAX).
Y
 Y es un array COMPLEX*16, dimension (LDX,NRHS)
Z
 Z es un array COMPLEX*16, dimension (LDX,NRHS)
Q
 Q es un array COMPLEX*16, dimension (LDQ,MMAX)
LDQ
 LDQ es INTEGER
 La dimensión principal del array Q. LDQ >= max(1,MMAX).
PT
 PT es un array COMPLEX*16, dimension (LDPT,NMAX)
LDPT
 LDPT es INTEGER
 La dimensión principal de los arrays PT, U y V.
 LDPT >= max(1, max(min(MVAL(j),NVAL(j)))).
U
 U es un array COMPLEX*16, dimension
 (LDPT,max(min(MVAL(j),NVAL(j))))
VT
 VT es un array COMPLEX*16, dimension
 (LDPT,max(min(MVAL(j),NVAL(j))))
WORK
 WORK es un array COMPLEX*16, dimension (LWORK)
LWORK
 LWORK es INTEGER
 El número de entradas en WORK. Debe ser al menos
 3(M+N) y M(M + max(M,N,k) + 1) + N*min(M,N) para todos los
 pares (M,N)=(MM(j),NN(j))
RWORK
 RWORK es un array DOUBLE PRECISION, dimension
 (5*max(min(M,N)))
NOUT
 NOUT es INTEGER
 El número de unidad FORTRAN para imprimir mensajes de error
 (por ejemplo, si una rutina devuelve IINFO distinto de 0).
INFO
 INFO es INTEGER
 Si es 0, entonces todo funcionó correctamente.
 -1: NSIZES < 0
 -2: Algunos MM(j) < 0
 -3: Algunos NN(j) < 0
 -4: NTYPES < 0
 -6: NRHS < 0
 -8: THRESH < 0
 -11: LDA < 1 o LDA < MMAX, donde MMAX es max( MM(j) ).
 -17: LDB < 1 o LDB < MMAX.
 -21: LDQ < 1 o LDQ < MMAX.
 -23: LDP < 1 o LDP < MNMAX.
 -27: LWORK demasiado pequeño.
 Si ZLATMR, CLATMS, ZGEBRD, ZUNGBR, o ZBDSQR,
 devuelve un código de error, el
 valor absoluto del mismo se devuelve.

NFAIL

COND, IMODE
Valores a pasar a los generadores de matrices.
ANORM
Norma de A; pasada a los generadores de matrices.

Umbrales de desbordamiento y desbordamiento inferior.
RTOVFL, RTUNFL
Raíces cuadradas de los dos valores anteriores.
ULP, ULPINV
Precisión relativa más fina y su inversa.
KTYPE(j)
El tipo general (1-10) para el tipo.
KMODE(j)
El valor MODE a pasar al generador de matrices para el tipo.

El orden de magnitud ( O(1), O(overflow^(1/2) ), O(underflow^(1/2) )
