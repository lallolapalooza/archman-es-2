ZCSDTS

Propósito:

!>
!> ZCSDTS prueba ZUNCSD, que, dada una matriz unitaria particionada M-por-M X,
!>              Q  M-Q
!>       X = [ X11 X12 ] P   ,
!>           [ X21 X22 ] M-P
!>
!> calcula el CSD
!>
!>       [ U1    ]**T * [ X11 X12 ] * [ V1    ]
!>       [    U2 ]      [ X21 X22 ]   [    V2 ]
!>
!>                             [  I  0  0 |  0  0  0 ]
!>                             [  0  C  0 |  0 -S  0 ]
!>                             [  0  0  0 |  0  0 -I ]
!>                           = [---------------------] = [ D11 D12 ] .
!>                             [  0  0  0 |  I  0  0 ]   [ D21 D22 ]
!>                             [  0  S  0 |  0  C  0 ]
!>                             [  0  0  I |  0  0  0 ]
!>
!> y también SORCSD2BY1, que, dada
!>          Q
!>       [ X11 ] P   ,
!>       [ X21 ] M-P
!>
!> calcula el CSD 2x1
!>
!>                                     [  I  0  0 ]
!>                                     [  0  C  0 ]
!>                                     [  0  0  0 ]
!>       [ U1    ]**T * [ X11 ] * V1 = [----------] = [ D11 ] ,
!>       [    U2 ]      [ X21 ]        [  0  0  0 ]   [ D21 ]
!>                                     [  0  S  0 ]
!>                                     [  0  0  I ]
!>

Parámetros

M 
!>          M es INTEGER
!>          El número de filas de la matriz X.  M >= 0.
!>

P

!>          P es INTEGER
!>          El número de filas de la matriz X11.  P >= 0.
!>

Q

!>          Q es INTEGER
!>          El número de columnas de la matriz X11.  Q >= 0.
!>

X

!>          X es un array COMPLEX*16, dimensión (LDX,M)
!>          La matriz M-por-M X.
!>

XF

!>          XF es un array COMPLEX*16, dimensión (LDX,M)
!>          Detalles del CSD de X, tal como lo devuelve ZUNCSD;
!>          ver ZUNCSD para más detalles.
!>

LDX

!>          LDX es INTEGER
!>          La dimensión principal de los arrays X y XF.
!>          LDX >= max( 1,M ).
!>

U1

!>          U1 es un array COMPLEX*16, dimensión(LDU1,P)
!>          La matriz unitaria P-por-P U1.
!>

LDU1

!>          LDU1 es INTEGER
!>          La dimensión principal del array U1. LDU >= max(1,P).
!>

U2

!>          U2 es un array COMPLEX*16, dimensión(LDU2,M-P)
!>          La matriz unitaria (M-P)-por-(M-P) U2.
!>

LDU2

!>          LDU2 es INTEGER
!>          La dimensión principal del array U2. LDU >= max(1,M-P).
!>

V1T

!>          V1T es un array COMPLEX*16, dimensión(LDV1T,Q)
!>          La matriz unitaria Q-por-Q V1T.
!>

LDV1T

!>          LDV1T es INTEGER
!>          La dimensión principal del array V1T. LDV1T >=
!>          max(1,Q).
!>

V2T

!>          V2T es un array COMPLEX*16, dimensión(LDV2T,M-Q)
!>          La matriz unitaria (M-Q)-por-(M-Q) V2T.
!>

LDV2T

!>          LDV2T es INTEGER
!>          La dimensión principal del array V2T. LDV2T >=
!>          max(1,M-Q).
!>

THETA

!>          THETA es un array DOUBLE PRECISION, dimensión MIN(P,M-P,Q,M-Q)
!>          Los valores CS de X; las matrices C y S esencialmente diagonales
!>          se construyen a partir de THETA; ver la subrutina ZUNCSD para
!>          detalles.
!>

IWORK

!>          IWORK es un array INTEGER, dimensión (M)
!>

WORK

!>          WORK es un array COMPLEX*16, dimensión (LWORK)
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK
!>

RWORK

!>          RWORK es un array DOUBLE PRECISION
!>

RESULT

!>          RESULT es un array DOUBLE PRECISION, dimensión (15)
!>          Las relaciones de prueba:
!>          Primero, el CSD 2x2:
!>          RESULT(1) = norm( U1'*X11*V1 - D11 ) / ( MAX(1,P,Q)*EPS2 )
!>          RESULT(2) = norm( U1'*X12*V2 - D12 ) / ( MAX(1,P,M-Q)*EPS2 )
!>          RESULT(3) = norm( U2'*X21*V1 - D21 ) / ( MAX(1,M-P,Q)*EPS2 )
!>          RESULT(4) = norm( U2'*X22*V2 - D22 ) / ( MAX(1,M-P,M-Q)*EPS2 )
!>          RESULT(5) = norm( I - U1'*U1 ) / ( MAX(1,P)*ULP )
!>          RESULT(6) = norm( I - U2'*U2 ) / ( MAX(1,M-P)*ULP )
!>          RESULT(7) = norm( I - V1T'*V1T ) / ( MAX(1,Q)*ULP )
!>          RESULT(8) = norm( I - V2T'*V2T ) / ( MAX(1,M-Q)*ULP )
!>          RESULT(9) = 0        si THETA está en orden creciente y
!>                               todos los ángulos están en [0,pi/2]
!>                    = ULPINV   de lo contrario.
!>          Luego, el CSD 2x1:
!>          RESULT(10) = norm( U1'*X11*V1 - D11 ) / ( MAX(1,P,Q)*EPS2 )
!>          RESULT(11) = norm( U2'*X21*V1 - D21 ) / ( MAX(1,M-P,Q)*EPS2 )
!>          RESULT(12) = norm( I - U1'*U1 ) / ( MAX(1,P)*ULP )
!>          RESULT(13) = norm( I - U2'*U2 ) / ( MAX(1,M-P)*ULP )
!>          RESULT(14) = norm( I - V1T'*V1T ) / ( MAX(1,Q)*ULP )
!>          RESULT(15) = 0        si THETA está en orden creciente y
!>                               todos los ángulos están en [0,pi/2]
!>                     = ULPINV   de lo contrario.
!>          ( EPS2 = MAX( norm( I - X'*X ) / M, ULP ). )
!>

ZCSDTS

SUBROUTINE ZCSDTS( UPLO, N, V, LDV, DV, VPVT, WORK, INFO )

Purpose:

ZCSDTS computes the solution to the system of linear equations A * X = B, where A is an n-by-n complex matrix given in Schur form, and X and B are n-by-n matrices.

Parameters:

  • UPLO: CHARACTER*1. Specifies whether the matrix A is upper or lower triangular. 'U' indicates upper triangular, 'L' indicates lower triangular.
  • N: INTEGER. The order of the matrix A.
  • V: COMPLEX*16 array, dimension (LDV,N). On entry, V contains the right Schur vector of A. On exit, V contains the solution matrix X.
  • LDV: INTEGER. The leading dimension of the array V. LDV >= N.
  • DV: COMPLEX*16 array, dimension (N). On entry, DV contains the diagonal elements of the eigenvalues of A.
  • VPVT: COMPLEX*16 array, dimension (N). On entry, VPVT contains the product of the Schur vector V and its transpose (V*V^T). This is used to check for singularity.
  • WORK: COMPLEX*16 array, dimension (N*N). A workspace array.
  • INFO: INTEGER. > 0: If INFO = k, then the k-th diagonal element of the solution is zero, indicating that the matrix A is singular. = 0: Normal termination. < 0: Illegal value for one of the parameters.
