subroutine zchkhb2stg (integer nsizes, integer, dimension( * ) nn, integer nwdths, integer, dimension( * ) kk, integer ntypes, logical, dimension( * ) dotype, integer, dimension( 4 ) iseed, double precision thresh, integer nounit, complex*16, dimension( lda, * ) a, integer lda, double precision, dimension( * ) sd, double precision, dimension( * ) se, double precision, dimension( * ) d1, double precision, dimension( * ) d2, double precision, dimension( * ) d3, complex*16, dimension( ldu, * ) u, integer ldu, complex*16, dimension( * ) work, integer lwork, double precision, dimension( * ) rwork, double precision, dimension( * ) result, integer info)

ZCHKHB2STG

Propósito:

!>
!> ZCHKHB2STG prueba la reducción de una matriz de banda Hermitiana a la forma
!> tridiagonal, utilizada con el problema de valores propios Hermitiano.
!>
!> ZHBTRD factoriza una matriz de banda Hermitiana A como U S U*, donde * significa
!> transpuesta conjugada, S es tridiagonal simétrica y U es unitaria.
!> ZHBTRD puede usar solo la parte triangular inferior o solo la superior
!> de A; ZCHKHB2STG comprueba ambos casos.
!>
!> ZHETRD_HB2ST factoriza una matriz de banda Hermitiana A como U S U*,
!> donde * significa transpuesta conjugada, S es tridiagonal simétrica y U es
!> unitaria. ZHETRD_HB2ST puede usar solo la parte triangular inferior o solo
!> la superior de A; ZCHKHB2STG comprueba ambos casos.
!>
!> DSTEQR factoriza S como Z D1 Z'.
!> D1 es la matriz de valores propios calculados cuando Z no se calcula
!> y a partir de S resultante de DSBTRD (usado como referencia para DSYTRD_SB2ST)
!> D2 es la matriz de valores propios calculados cuando Z no se calcula
!> y a partir de S resultante de DSYTRD_SB2ST.
!> D3 es la matriz de valores propios calculados cuando Z no se calcula
!> y a partir de S resultante de DSYTRD_SB2ST.
!>
!> Cuando se llama a ZCHKHB2STG, se especifican un número de tamaños de matriz (),
!> un número de anchos de banda () y un número de tipos de matriz. Para cada tamaño (),
!> cada ancho de banda () menor o igual a , y cada tipo de matriz, se generará
!> una matriz y se utilizará para probar la rutina de reducción de banda Hermitiana.
!> Para cada matriz, se realizarán una serie de pruebas:
!>
!> (1) | A - V S V* | / ( |A| n ulp ) calculado por ZHBTRD con
!>                                         UPLO='U'
!>
!> (2) | I - UU* | / ( n ulp )
!>
!> (3) | A - V S V* | / ( |A| n ulp ) calculado por ZHBTRD con
!>                                         UPLO='L'
!>
!> (4) | I - UU* | / ( n ulp )
!>
!> (5) | D1 - D2 | / ( |D1| ulp ) donde D1 es calculado por
!>                                         DSBTRD con UPLO='U' y
!>                                         D2 es calculado por
!>                                         ZHETRD_HB2ST con UPLO='U'
!>
!> (6) | D1 - D3 | / ( |D1| ulp ) donde D1 es calculado por
!>                                         DSBTRD con UPLO='U' y
!>                                         D3 es calculado por
!>                                         ZHETRD_HB2ST con UPLO='L'
!>
!> Los se especifican por un array NN(1:NSIZES); el valor de
!> cada elemento NN(j) especifica un tamaño.
!> Los se especifican por un array lógico DOTYPE( 1:NTYPES );
!> si DOTYPE(j) es .VERDADERO., entonces se generará el tipo de matriz.
!> Actualmente, la lista de tipos posibles es:
!>
!> (1) La matriz cero.
!> (2) La matriz identidad.
!>
!> (3) Una matriz diagonal con entradas espaciadas uniformemente
!>      1, ..., ULP y signos aleatorios.
!>      (ULP = (primer número mayor que 1) - 1 )
!> (4) Una matriz diagonal con entradas espaciadas geométricamente
!>      1, ..., ULP y signos aleatorios.
!> (5) Una matriz diagonal con entradas 1, ULP, ..., ULP
!>      y signos aleatorios.
!>
!> (6) Igual que (4), pero multiplicado por SQRT( umbral de desbordamiento )
!> (7) Igual que (4), pero multiplicado por SQRT( umbral de subdesbordamiento )
!>
!> (8) Una matriz de la forma U* D U, donde U es unitaria y
!>      D tiene entradas espaciadas uniformemente 1, ..., ULP con signos aleatorios
!>      en la diagonal.
!>
!> (9) Una matriz de la forma U* D U, donde U es unitaria y
!>      D tiene entradas espaciadas geométricamente 1, ..., ULP con signos aleatorios
!>      en la diagonal.
!>
!> (10) Una matriz de la forma U* D U, donde U es unitaria y
!>      D tiene entradas 1, ULP,..., ULP con signos aleatorios
!>      en la diagonal.
!>
!> (11) Igual que (8), pero multiplicado por SQRT( umbral de desbordamiento )
!> (12) Igual que (8), pero multiplicado por SQRT( umbral de subdesbordamiento )
!>
!> (13) Matriz Hermitiana con entradas aleatorias elegidas de (-1,1).
!> (14) Igual que (13), pero multiplicado por SQRT( umbral de desbordamiento )
!> (15) Igual que (13), pero multiplicado por SQRT( umbral de subdesbordamiento )
!>

Parámetros

NSIZES 
!>          NSIZES es INTEGER
!>          El número de tamaños de matrices a usar. Si es cero,
!>          ZCHKHB2STG no hace nada. Debe ser al menos cero.
!>

NN

!>          NN es un array INTEGER, dimension (NSIZES)
!>          Un array que contiene los tamaños a usar para las matrices.
!>          Los valores cero serán omitidos. Los valores deben ser al menos
!!>          cero.
!>

NWDTHS

!>          NWDTHS es INTEGER
!>          El número de anchos de banda a usar. Si es cero,
!>          ZCHKHB2STG no hace nada. Debe ser al menos cero.
!>

KK

!>          KK es un array INTEGER, dimension (NWDTHS)
!>          Un array que contiene los anchos de banda a usar para las matrices
!>          de banda. Los valores deben ser al menos cero.
!>

NTYPES

!>          NTYPES es INTEGER
!>          El número de elementos en DOTYPE. Si es cero, ZCHKHB2STG
!>          no hace nada. Debe ser al menos cero. Si es MAXTYP+1
!>          y NSIZES es 1, entonces se define un tipo adicional, MAXTYP+1,
!>          que es usar cualquier matriz que esté en A. Esto
!>          solo es útil si DOTYPE(1:MAXTYP) es .FALSO. y
!>          DOTYPE(MAXTYP+1) es .VERDADERO. .
!>

DOTYPE

!>          DOTYPE es un array LOGICAL, dimension (NTYPES)
!>          Si DOTYPE(j) es .VERDADERO., entonces para cada tamaño en NN se generará
!>          una matriz de ese tamaño y de tipo j.
!>          Si NTYPES es menor que el número máximo de tipos
!>          definidos (PARAMETER MAXTYP), entonces los tipos NTYPES+1 hasta
!>          MAXTYP no se generarán. Si NTYPES es mayor
!>          que MAXTYP, DOTYPE(MAXTYP+1) hasta DOTYPE(NTYPES)
!>          serán ignorados.
!>

ISEED

!>          ISEED es un array INTEGER, dimension (4)
!>          A la entrada ISEED especifica la semilla del generador de números
!>          aleatorios. Los elementos del array deben estar entre 0 y 4095;
!>          si no, se reducirán módulo 4096. Además, ISEED(4) debe
!>          ser impar. El generador de números aleatorios utiliza una secuencia
!>          congruencial lineal limitada a enteros pequeños, y por lo tanto
!>          debería producir números aleatorios independientes de la máquina. Los
!>          valores de ISEED cambian a la salida y pueden ser usados en la
!>          siguiente llamada a ZCHKHB2STG para continuar la misma secuencia de
!>          números aleatorios.
!>

NAME

zchkhb2stg - generates a random Hermitian-definite matrix A, and computes the singular values and condition number of the factored matrix LDL* of A.

SYNOPSIS

  SUBROUTINE ZCHKHB2STG(THRESH, NOUNIT, A, LDA, SD, SE, D1, D2, D3, U, LDU,
                        WORK, LWORK, RWORK, RESULT, INFO)

Function/Subroutine Documentation

This routine is a testing driver for the subroutine ZHBTRD.

THRESH

!>          THRESH is DOUBLE PRECISION
!>          A test will count as  if the , computed as
!>          described above, exceeds THRESH.  Note that the error
!>          is scaled to be O(1), so THRESH should be a reasonably
!>          small multiple of 1, e.g., 10 or 100.  In particular,
!>          it should not depend on the precision (single vs. double)
!>          or the size of the matrix.  It must be at least zero.
!>

NOUNIT

!>          NOUNIT is INTEGER
!>          The FORTRAN unit number for printing out error messages
!>          (e.g., if a routine returns IINFO not equal to 0.)
!>

A

!>          A is COMPLEX*16 array, dimension
!>                            (LDA, max(NN))
!>          Used to hold the matrix whose eigenvalues are to be
!>          computed.
!>

LDA

!>          LDA is INTEGER
!>          The leading dimension of A.  It must be at least 2 (not 1!)
!>          and at least max( KK )+1.
!>

SD

!>          SD is DOUBLE PRECISION array, dimension (max(NN))
!>          Used to hold the diagonal of the tridiagonal matrix computed
!>          by ZHBTRD.
!>

SE

!>          SE is DOUBLE PRECISION array, dimension (max(NN))
!>          Used to hold the off-diagonal of the tridiagonal matrix
!>          computed by ZHBTRD.
!>

D1

!>          D1 is DOUBLE PRECISION array, dimension (max(NN))
!>

D2

!>          D2 is DOUBLE PRECISION array, dimension (max(NN))
!>


*>
D3

!>          D3 is DOUBLE PRECISION array, dimension (max(NN))
!>

U

!>          U is COMPLEX*16 array, dimension (LDU, max(NN))
!>          Used to hold the unitary matrix computed by ZHBTRD.
!>

LDU

!>          LDU is INTEGER
!>          The leading dimension of U.  It must be at least 1
!>          and at least max( NN ).
!>

WORK

LWORK

RWORK

RESULT
