Documentación de Función/Subrutina

subrutina zchkpp (logical, dimension( * ) dotype, integer nn, integer, dimension( * ) nval, integer nns, integer, dimension( * ) nsval, double precision thresh, logical tsterr, integer nmax, complex*16, dimension( * ) a, complex*16, dimension( * ) afac, complex*16, dimension( * ) ainv, complex*16, dimension( * ) b, complex*16, dimension( * ) x, complex*16, dimension( * ) xact, complex*16, dimension( * ) work, double precision, dimension( * ) rwork, integer nout)

ZCHKPP

Propósito:

!>
!> ZCHKPP prueba ZPPTRF, -TRI, -TRS, -RFS, y -CON
!>

Parámetros

DOTYPE 
!>          DOTYPE es un array LOGICAL, de dimensión (NTYPES)
!>          Los tipos de matriz a utilizar para la prueba. Las matrices de tipo j
!>          (para 1 <= j <= NTYPES) se utilizan para la prueba si DOTYPE(j) =
!>          .TRUE.; si DOTYPE(j) = .FALSE., entonces el tipo j no se utiliza.
!>

NN

!>          NN es INTEGER
!>          El número de valores de N contenidos en el vector NVAL.
!>

NVAL

!>          NVAL es un array INTEGER, de dimensión (NN)
!>          Los valores de la dimensión de la matriz N.
!>

NNS

!>          NNS es INTEGER
!>          El número de valores de NRHS contenidos en el vector NSVAL.
!>

NSVAL

!>          NSVAL es un array INTEGER, de dimensión (NNS)
!>          Los valores del número de lados derechos NRHS.
!>

THRESH

!>          THRESH es DOUBLE PRECISION
!>          El valor umbral para las relaciones de prueba. Un resultado se
!>          incluye en el archivo de salida si RESULT >= THRESH. Para que
!>          cada relación de prueba se imprima, use THRESH = 0.
!>

TSTERR

!>          TSTERR es LOGICAL
!>          Bandera que indica si se deben probar las salidas de error.
!>

NMAX

!>          NMAX es INTEGER
!>          El valor máximo permitido para N, utilizado en la dimensionamiento de los
!>          arrays de trabajo.
!>

A

!>          A es un array COMPLEX*16, de dimensión
!>                      (NMAX*(NMAX+1)/2)
!>

AFAC

!>          AFAC es un array COMPLEX*16, de dimensión
!>                      (NMAX*(NMAX+1)/2)
!>

AINV

!>          AINV es un array COMPLEX*16, de dimensión
!>                      (NMAX*(NMAX+1)/2)
!>

B

!>          B es un array COMPLEX*16, de dimensión (NMAX*NSMAX)
!>          donde NSMAX es la entrada más grande en NSVAL.
!>

X

!>          X es un array COMPLEX*16, de dimensión (NMAX*NSMAX)
!>

XACT

!>          XACT es un array COMPLEX*16, de dimensión (NMAX*NSMAX)
!>

WORK

!>          WORK es un array COMPLEX*16, de dimensión
!>                      (NMAX*max(3,NSMAX))
!>

RWORK

!>          RWORK es un array DOUBLE PRECISION, de dimensión
!>                      (max(NMAX,2*NSMAX))
!>

NOUT

!>          NOUT es INTEGER
!>          El número de unidad para la salida.
!>
