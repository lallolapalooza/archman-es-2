Documentación de la Función/Subrutina

subroutine zchkunhr_col (double precision thresh, logical tsterr, integer nm, integer, dimension( * ) mval, integer nn, integer, dimension( * ) nval, integer nnb, integer, dimension( * ) nbval, integer nout)

ZCHKUNHR_COL

Propósito:

!>
!> ZCHKUNHR_COL prueba:
!>   1) ZUNGTSQR y ZUNHR_COL usando ZLATSQR, ZGEMQRT,
!>   2) ZUNGTSQR_ROW y ZUNHR_COL dentro de ZGETSQRHRT
!>      (que llama a ZLATSQR, ZUNGTSQR_ROW y ZUNHR_COL) usando ZGEMQRT.
!> Por lo tanto, ZLATSQR (parte de ZGEQR), ZGEMQRT (parte de ZGEMQR)
!> tienen que ser probados antes de esta prueba.
!>
!>

Parámetros

THRESH 
!>          THRESH es DOUBLE PRECISION
!>          El valor umbral para las ratios de prueba. Un resultado se
!>          incluye en el archivo de salida si RESULT >= THRESH. Para tener
!>          cada ratio de prueba impreso, usar THRESH = 0.
!>

TSTERR

!>          TSTERR es LOGICAL
!>          Bandera que indica si se deben probar las salidas de error.
!>

NM

!>          NM es INTEGER
!>          El número de valores de M contenidos en el vector MVAL.
!>

MVAL

!>          MVAL es un array INTEGER, dimension (NM)
!>          Los valores de la dimensión de fila de la matriz M.
!>

NN

!>          NN es INTEGER
!>          El número de valores de N contenidos en el vector NVAL.
!>

NVAL

!>          NVAL es un array INTEGER, dimension (NN)
!>          Los valores de la dimensión de columna de la matriz N.
!>

NNB

!>          NNB es INTEGER
!>          El número de valores de NB contenidos en el vector NBVAL.
!>

NBVAL

!>          NBVAL es un array INTEGER, dimension (NNB)
!>          Los valores del tamaño de bloque NB.
!>

NOUT

!>          NOUT es INTEGER
!>          El número de unidad para la salida.
!>
