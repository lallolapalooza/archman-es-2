Documentación de la Función/Subrutina

subrutina zchkhb (integer nsizes, integer, dimension( * ) nn, integer nwdths, integer, dimension( * ) kk, integer ntypes, logical, dimension( * ) dotype, integer, dimension( 4 ) iseed, double precision thresh, integer nounit, complex*16, dimension( lda, * ) a, integer lda, double precision, dimension( * ) sd, double precision, dimension( * ) se, complex*16, dimension( ldu, * ) u, integer ldu, complex*16, dimension( * ) work, integer lwork, double precision, dimension( * ) rwork, double precision, dimension( * ) result, integer info)

ZCHKHB

Propósito:

!>
!> ZCHKHB prueba la reducción de una matriz Hermitiana de banda a forma
!> tridiagonal, utilizada con el problema de valores propios Hermitiano.
!>
!> ZHBTRD factoriza una matriz Hermitiana de banda A como U S U* , donde * significa
!> transpuesta conjugada, S es tridiagonal simétrica y U es unitaria.
!> ZHBTRD puede usar solo la parte triangular inferior o solo la superior
!> de A; ZCHKHB comprueba ambos casos.
!>
!> Cuando se llama a ZCHKHB, se especifican un número de tamaños de matriz  (),
!> un número de anchos de banda (), y un número de tipos de matriz.
!> Para cada tamaño (), cada ancho de banda () menor o igual que ,
!> y cada tipo de matriz, se generará una matriz y se utilizará para probar
!> la rutina de reducción Hermitiana de banda. Para cada matriz, se realizarán
!> un número de pruebas:
!>
!> (1)     | A - V S V* | / ( |A| n ulp )  calculado por ZHBTRD con
!>                                         UPLO='U'
!>
!> (2)     | I - UU* | / ( n ulp )
!>
!> (3)     | A - V S V* | / ( |A| n ulp )  calculado por ZHBTRD con
!>                                         UPLO='L'
!>
!> (4)     | I - UU* | / ( n ulp )
!>
!> Los  se especifican por un array NN(1:NSIZES); el valor de
!> cada elemento NN(j) especifica un tamaño.
!> Los  se especifican por un array lógico DOTYPE( 1:NTYPES );
!> si DOTYPE(j) es .TRUE., entonces se generará la matriz de tipo .
!> Actualmente, la lista de tipos posibles es:
!>
!> (1)  La matriz cero.
!> (2)  La matriz identidad.
!>
!> (3)  Una matriz diagonal con entradas espaciadas uniformemente
!>      1, ..., ULP  y signos aleatorios.
!>      (ULP = (primer número mayor que 1) - 1 )
!> (4)  Una matriz diagonal con entradas espaciadas geométricamente
!>      1, ..., ULP  y signos aleatorios.
!> (5)  Una matriz diagonal con entradas  1, ULP, ..., ULP
!>      y signos aleatorios.
!>
!> (6)  Igual que (4), pero multiplicado por SQRT( umbral de desbordamiento )
!> (7)  Igual que (4), pero multiplicado por SQRT( umbral de subdesbordamiento )
!>
!> (8)  Una matriz de la forma  U* D U, donde U es unitaria y
!>      D tiene entradas espaciadas uniformemente 1, ..., ULP con signos
!>      aleatorios en la diagonal.
!>
!> (9)  Una matriz de la forma  U* D U, donde U es unitaria y
!>      D tiene entradas espaciadas geométricamente 1, ..., ULP con signos
!>      aleatorios en la diagonal.
!>
!> (10) Una matriz de la forma  U* D U, donde U es unitaria y
!>      D tiene entradas  1, ULP,..., ULP con signos
!>      aleatorios en la diagonal.
!>
!> (11) Igual que (8), pero multiplicado por SQRT( umbral de desbordamiento )
!> (12) Igual que (8), pero multiplicado por SQRT( umbral de subdesbordamiento )
!>
!> (13) Matriz Hermitiana con entradas aleatorias elegidas de (-1,1).
!> (14) Igual que (13), pero multiplicado por SQRT( umbral de desbordamiento )
!> (15) Igual que (13), pero multiplicado por SQRT( umbral de subdesbordamiento )
!>

Parámetros

NSIZES 
!>          NSIZES es INTEGER
!>          El número de tamaños de matrices a utilizar. Si es cero,
!>          ZCHKHB no hace nada. Debe ser al menos cero.
!>

NN

!>          NN es un array INTEGER, dimension (NSIZES)
!>          Un array que contiene los tamaños a utilizar para las matrices.
!>          Los valores cero serán omitidos. Los valores deben ser al menos
!>          cero.
!>

NWDTHS

!>          NWDTHS es INTEGER
!>          El número de anchos de banda a utilizar. Si es cero,
!>          ZCHKHB no hace nada. Debe ser al menos cero.
!>

KK

!>          KK es un array INTEGER, dimension (NWDTHS)
!>          Un array que contiene los anchos de banda a utilizar para las
!>          matrices de banda. Los valores deben ser al menos cero.
!>

NTYPES

!>          NTYPES es INTEGER
!>          El número de elementos en DOTYPE. Si es cero, ZCHKHB
!>          no hace nada. Debe ser al menos cero. Si es MAXTYP+1
!>          y NSIZES es 1, entonces se define un tipo adicional, MAXTYP+1,
!>          que es usar cualquier matriz que esté en A. Esto
!>          sólo es útil si DOTYPE(1:MAXTYP) es .FALSE. y
!>          DOTYPE(MAXTYP+1) es .TRUE. .
!>

DOTYPE

!>          DOTYPE es un array LOGICAL, dimension (NTYPES)
!>          Si DOTYPE(j) es .TRUE., entonces para cada tamaño en NN se generará
!>          una matriz de ese tamaño y de tipo j.
!>          Si NTYPES es menor que el número máximo de tipos
!>          definidos (PARAMETER MAXTYP), entonces los tipos NTYPES+1 hasta
!>          MAXTYP no se generarán. Si NTYPES es mayor
!>          que MAXTYP, DOTYPE(MAXTYP+1) hasta DOTYPE(NTYPES)
!>          serán ignorados.
!>

ISEED

!>          ISEED es un array INTEGER, dimension (4)
!>          A la entrada, ISEED especifica la semilla del generador de números
!>          aleatorios. Los elementos del array deben estar entre 0 y 4095;
!>          si no, se reducirán módulo 4096. Además, ISEED(4) debe
!>          ser impar. El generador de números aleatorios utiliza una secuencia
!>          congruencial lineal limitada a enteros pequeños, y por lo tanto
!>          debería producir números aleatorios independientes de la máquina. Los
!>          valores de ISEED se modifican a la salida y pueden usarse en la
!>          siguiente llamada a ZCHKHB para continuar la misma secuencia de números
!>          aleatorios.
!>

THRESH

!>          THRESH es DOUBLE PRECISION
!>          Una prueba contará como  si el , calculado como
!>          se describe arriba, excede THRESH. Tenga en cuenta que el error
!>          está escalado para ser O(1), por lo que THRESH debería ser un múltiplo
!>          razonablemente pequeño de 1, por ejemplo, 10 o 100. En particular,
!>          no debe depender de la precisión (simple o doble)
!>          o del tamaño de la matriz. Debe ser al menos cero.
!>

NOUNIT

!>          NOUNIT es INTEGER
!>          El número de unidad FORTRAN para imprimir mensajes de error
!>          (por ejemplo, si una rutina devuelve IINFO distinto de 0).
!>

A

!>          A es un array COMPLEX*16, dimension
!>                            (LDA, max(NN))
!>          Se utiliza para almacenar la matriz cuyos valores propios se van a
!>          calcular.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal de A. Debe ser al menos 2 (¡no 1!)
!>          y al menos max( KK )+1.
!>

SD

!>          SD es un array DOUBLE PRECISION, dimension (max(NN))
!>          Se utiliza para almacenar la diagonal de la matriz tridiagonal calculada
!>          por ZHBTRD.
!>

SE

!>          SE es un array DOUBLE PRECISION, dimension (max(NN))
!>          Se utiliza para almacenar los sub-diagonales de la matriz tridiagonal
!>          calculada por ZHBTRD.
!>

U

!>          U es un array COMPLEX*16, dimension (LDU, max(NN))
!>

Author

Used to hold the unitary matrix computed by ZHBTRD.

LDU

          LDU is INTEGER
          The leading dimension of U.  It must be at least 1
          and at least max( NN ).

WORK

          WORK is COMPLEX*16 array, dimension (LWORK)

LWORK

          LWORK is INTEGER
          The number of entries in WORK.  This must be at least
          max( LDA+1, max(NN)+1 )*max(NN).

RWORK

          RWORK is DOUBLE PRECISION array

RESULT

          RESULT is DOUBLE PRECISION array, dimension (4)
          The values computed by the tests described above.
          The values are currently limited to 1/ulp, to avoid
          overflow.

INFO

          INFO is INTEGER
          If 0, then everything ran OK.

Some Local Variables and Parameters:

---- ----- --------- --- ----------

ZERO, ONE Real 0 and 1.

MAXTYP The number of types defined.

NTEST The number of tests performed, or which can

be performed so far, for the current matrix.

NTESTT The total number of tests performed so far.

NMAX Largest value in NN.

NMATS The number of matrices generated so far.

NERRS The number of tests which have exceeded THRESH

so far.

COND, IMODE Values to be passed to the matrix generators.

ANORM Norm of A; passed to matrix generators.

OVFL, UNFL Overflow and underflow thresholds.

ULP, ULPINV Finest relative precision and its inverse.

RTOVFL, RTUNFL Square roots of the previous 2 values.

The following four arrays decode JTYPE:

KTYPE(j) The general type (1-10) for type .

KMODE(j) The MODE value to be passed to the matrix

generator for type .

KMAGN(j) The order of magnitude ( O(1),

O(overflow^(1/2) ), O(underflow^(1/2) )
