ZCHKQL

Propósito:

!>
!> ZCHKQL prueba ZGEQLF, ZUNGQL y ZUNMQL.
!>

Parámetros

DOTYPE 
!>          DOTYPE es un array LOGICAL, de dimensión (NTYPES)
!>          Los tipos de matrices a utilizar para las pruebas. Las matrices de tipo j
!>          (para 1 <= j <= NTYPES) se utilizan para las pruebas si DOTYPE(j) =
!>          .TRUE.; si DOTYPE(j) = .FALSE., entonces el tipo j no se usa.
!>

NM

!>          NM es INTEGER
!>          El número de valores de M contenidos en el vector MVAL.
!>

MVAL

!>          MVAL es un array INTEGER, de dimensión (NM)
!>          Los valores de la dimensión de fila M de la matriz.
!>

NN

!>          NN es INTEGER
!>          El número de valores de N contenidos en el vector NVAL.
!>

NVAL

!>          NVAL es un array INTEGER, de dimensión (NN)
!>          Los valores de la dimensión de columna N de la matriz.
!>

NNB

!>          NNB es INTEGER
!>          El número de valores de NB y NX contenidos en
!>          los vectores NBVAL y NXVAL. Los parámetros de bloqueo se utilizan
!>          en pares (NB,NX).
!>

NBVAL

!>          NBVAL es un array INTEGER, de dimensión (NNB)
!>          Los valores del tamaño de bloque NB.
!>

NXVAL

!>          NXVAL es un array INTEGER, de dimensión (NNB)
!>          Los valores del punto de cruce NX.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de vectores del lado derecho a generar para
!>          cada sistema lineal.
!>

THRESH

!>          THRESH es DOUBLE PRECISION
!>          El valor umbral para las ratios de prueba. Un resultado se
!>          incluye en el archivo de salida si RESULTADO >= UMBRAL. Para que
!>          se imprima cada ratio de prueba, use UMBRAL = 0.
!>

TSTERR

!>          TSTERR es LOGICAL
!>          Indicador que señala si se deben probar las salidas de error.
!>

NMAX

!>          NMAX es INTEGER
!>          El valor máximo permitido para M o N, utilizado para dimensionar
!>          los arrays de trabajo.
!>

A

!>          A es un array COMPLEX*16, de dimensión (NMAX*NMAX)
!>

AF

!>          AF es un array COMPLEX*16, de dimensión (NMAX*NMAX)
!>

AQ

!>          AQ es un array COMPLEX*16, de dimensión (NMAX*NMAX)
!>

AL

!>          AL es un array COMPLEX*16, de dimensión (NMAX*NMAX)
!>

AC

!>          AC es un array COMPLEX*16, de dimensión (NMAX*NMAX)
!>

B

!>          B es un array COMPLEX*16, de dimensión (NMAX*NRHS)
!>

X

!>          X es un array COMPLEX*16, de dimensión (NMAX*NRHS)
!>

XACT

!>          XACT es un array COMPLEX*16, de dimensión (NMAX*NRHS)
!>

TAU

!>          TAU es un array COMPLEX*16, de dimensión (NMAX)
!>

WORK

!>          WORK es un array COMPLEX*16, de dimensión (NMAX*NMAX)
!>

RWORK

!>          RWORK es un array DOUBLE PRECISION, de dimensión (NMAX)
!>

NOUT

!>          NOUT es INTEGER
!>          El número de unidad para la salida.
!>
