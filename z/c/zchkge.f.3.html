ZCHKGE

Propósito:

!>
!> ZCHKGE prueba ZGETRF, -TRI, -TRS, -RFS, y -CON.
!>

Parámetros

DOTYPE 
!>          DOTYPE es un array LOGICAL, dimension (NTYPES)
!>          Los tipos de matriz a utilizar para las pruebas. Las matrices de tipo j
!>          (para 1 <= j <= NTYPES) se utilizan para las pruebas si DOTYPE(j) =
!>          .TRUE.; si DOTYPE(j) = .FALSE., entonces el tipo j no se utiliza.
!>

NM

!>          NM es un ENTERO
!>          El número de valores de M contenidos en el vector MVAL.
!>

MVAL

!>          MVAL es un array ENTERO, dimension (NM)
!>          Los valores de la dimensión de fila de la matriz M.
!>

NN

!>          NN es un ENTERO
!>          El número de valores de N contenidos en el vector NVAL.
!>

NVAL

!>          NVAL es un array ENTERO, dimension (NN)
!>          Los valores de la dimensión de columna de la matriz N.
!>

NNB

!>          NNB es un ENTERO
!>          El número de valores de NB contenidos en el vector NBVAL.
!>

NBVAL

!>          NBVAL es un array ENTERO, dimension (NNB)
!>          Los valores del tamaño del bloque NB.
!>

NNS

!>          NNS es un ENTERO
!>          El número de valores de NRHS contenidos en el vector NSVAL.
!>

NSVAL

!>          NSVAL es un array ENTERO, dimension (NNS)
!>          Los valores del número de lados derechos NRHS.
!>

THRESH

!>          THRESH es un DOUBLE PRECISION
!>          El valor umbral para las relaciones de prueba. Un resultado se
!>          incluye en el archivo de salida si RESULT >= THRESH. Para que
!>          se imprima cada relación de prueba, use THRESH = 0.
!>

TSTERR

!>          TSTERR es un LOGICAL
!>          Indicador que determina si se deben probar las salidas de error.
!>

NMAX

!>          NMAX es un ENTERO
!>          El valor máximo permitido para M o N, utilizado en la dimensionamiento
!>          de los arrays de trabajo.
!>

A

!>          A es un array COMPLEX*16, dimension (NMAX*NMAX)
!>

AFAC

!>          AFAC es un array COMPLEX*16, dimension (NMAX*NMAX)
!>

AINV

!>          AINV es un array COMPLEX*16, dimension (NMAX*NMAX)
!>

B

!>          B es un array COMPLEX*16, dimension (NMAX*NSMAX)
!>          donde NSMAX es la entrada más grande en NSVAL.
!>

X

!>          X es un array COMPLEX*16, dimension (NMAX*NSMAX)
!>

XACT

!>          XACT es un array COMPLEX*16, dimension (NMAX*NSMAX)
!>

WORK

!>          WORK es un array COMPLEX*16, dimension
!>                      (NMAX*max(3,NSMAX))
!>

RWORK

!>          RWORK es un array DOUBLE PRECISION, dimension
!>                      (max(2*NMAX,2*NSMAX+NWORK))
!>

IWORK

!>          IWORK es un array ENTERO, dimension (NMAX)
!>

NOUT

!>          NOUT es un ENTERO
!>          El número de unidad para la salida.
!>
