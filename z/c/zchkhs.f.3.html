ZCHKHS

Propósito:

!>
!>    ZCHKHS  verifica las rutinas del problema de valores propios no simétricos.
!>
!>            ZGEHRD factoriza A como  U H U' , donde ' significa transpuesta conjugada,
!>            H es de Hessenberg y U es unitaria.
!>
!>            ZUNGHR genera la matriz unitaria U.
!>
!>            ZUNMHR multiplica una matriz por la matriz unitaria U.
!>
!>            ZHSEQR factoriza H como  Z T Z' , donde Z es unitaria y T
!>            es triangular superior. También calcula los valores propios,
!>            w(1), ..., w(n); definimos una matriz diagonal W cuyas
!>            entradas (diagonales) son los valores propios.
!>
!>            ZTREVC calcula la matriz de vectores propios izquierdos L y la
!>            matriz de vectores propios derechos R para la matriz T. Las
!>            columnas de L son los conjugados complejos de los vectores propios
!>            izquierdos de T. Las columnas de R son los vectores propios derechos
!>            de T. L es triangular inferior y R es triangular superior.
!>
!>            ZHSEIN calcula la matriz de vectores propios izquierdos Y y la
!>            matriz de vectores propios derechos X para la matriz H. Las
!>            columnas de Y son los conjugados complejos de los vectores propios
!>            izquierdos de H. Las columnas de X son los vectores propios derechos
!>            de H. Y es triangular inferior y X es triangular superior.
!>
!>            ZTREVC3 calcula las matrices de vectores propios izquierdos y derechos
!>            a partir de una matriz de Schur T y las retrotransforma con Z
!>            a matrices de vectores propios L y R para A. L y R son
!>            matrices GE.
!>
!>    Cuando se llama a ZCHKHS, se especifican un número de tamaños de matriz
!>    y un número de tipos de matriz. Para cada tamaño y cada tipo de matriz,
!>    se generará y se usará una matriz para probar las rutinas de valores propios
!>    no simétricos. Para cada matriz, se realizarán 16 pruebas:
!>
!>    (1)     | A - U H U**H | / ( |A| n ulp )
!>
!>    (2)     | I - UU**H | / ( n ulp )
!>
!>    (3)     | H - Z T Z**H | / ( |H| n ulp )
!>
!>    (4)     | I - ZZ**H | / ( n ulp )
!>
!>    (5)     | A - UZ H (UZ)**H | / ( |A| n ulp )
!>
!>    (6)     | I - UZ (UZ)**H | / ( n ulp )
!>
!>    (7)     | T(Z calculado) - T(Z no calculado) | / ( |T| ulp )
!>
!>    (8)     | W(Z calculado) - W(Z no calculado) | / ( |W| ulp )
!>
!>    (9)     | TR - RW | / ( |T| |R| ulp )
!>
!>    (10)    | L**H T - W**H L | / ( |T| |L| ulp )
!>
!>    (11)    | HX - XW | / ( |H| |X| ulp )
!>
!>    (12)    | Y**H H - W**H Y | / ( |H| |Y| ulp )
!>
!>    (13)    | AX - XW | / ( |A| |X| ulp )
!>
!>    (14)    | Y**H A - W**H Y | / ( |A| |Y| ulp )
!>
!>    (15)    | AR - RW | / ( |A| |R| ulp )
!>
!>    (16)    | LA - WL | / ( |A| |L| ulp )
!>
!>    Los tamaños se especifican mediante un array NN(1:NSIZES); el valor de
!>    cada elemento NN(j) especifica un tamaño.
!>    Los tipos se especifican mediante un array lógico DOTYPE( 1:NTYPES );
!>    si DOTYPE(j) es .TRUE., entonces se generará la matriz de tipo j.
!>    Actualmente, la lista de tipos posibles es:
!>
!>    (1)  La matriz cero.
!>    (2)  La matriz identidad.
!>    (3)  Un bloque de Jordan (transpuesto), con 1s en la diagonal.
!>
!>    (4)  Una matriz diagonal con entradas espaciadas uniformemente
!>         1, ..., ULP y ángulos complejos aleatorios.
!>         (ULP = (primer número mayor que 1) - 1 )
!>    (5)  Una matriz diagonal con entradas espaciadas geométricamente
!>         1, ..., ULP y ángulos complejos aleatorios.
!>    (6)  Una matriz diagonal con entradas 1, ULP, ..., ULP
!>         y ángulos complejos aleatorios.
!>
!>    (7)  Igual que (4), pero multiplicado por SQRT( umbral de desbordamiento )
!>    (8)  Igual que (4), pero multiplicado por SQRT( umbral de subdesbordamiento )
!>
!>    (9)  Una matriz de la forma  U' T U, donde U es unitaria y
!>         T tiene entradas espaciadas uniformemente 1, ..., ULP con ángulos complejos aleatorios en la diagonal y entradas O(1) en el triángulo superior.
!>
!>    (10) Una matriz de la forma  U' T U, donde U es unitaria y
!>         T tiene entradas espaciadas geométricamente 1, ..., ULP con ángulos complejos aleatorios en la diagonal y entradas O(1) en el triángulo superior.
!>
!>    (11) Una matriz de la forma  U' T U, donde U es unitaria y
!>         T tiene entradas 1, ULP,..., ULP con ángulos complejos aleatorios en la diagonal y entradas O(1) en el triángulo superior.
!>
!>    (12) Una matriz de la forma  U' T U, donde U es unitaria y
!>         T tiene valores propios complejos elegidos aleatoriamente de
!>         ULP < |z| < 1   y entradas O(1) aleatorias en el triángulo superior.
!>
!>    (13) Una matriz de la forma  X' T X, donde X tiene condición
!>         SQRT( ULP ) y T tiene entradas espaciadas uniformemente 1, ..., ULP
!>         con ángulos complejos aleatorios en la diagonal y entradas O(1) aleatorias en el triángulo superior.
!>
!>    (14) Una matriz de la forma  X' T X, donde X tiene condición
!>         SQRT( ULP ) y T tiene entradas espaciadas geométricamente
!>         1, ..., ULP con ángulos complejos aleatorios en la diagonal y entradas O(1) aleatorias en el triángulo superior.
!>
!>    (15) Una matriz de la forma  X' T X, donde X tiene condición
!>         SQRT( ULP ) y T tiene entradas 1, ULP,..., ULP con ángulos complejos aleatorios en la diagonal y entradas O(1) aleatorias en el triángulo superior.
!>
!>    (16) Una matriz de la forma  X' T X, donde X tiene condición
!>         SQRT( ULP ) y T tiene valores propios complejos elegidos aleatoriamente
!>         de   ULP < |z| < 1   y entradas O(1) aleatorias en el triángulo superior.
!>
!>    (17) Igual que (16), pero multiplicado por SQRT( umbral de desbordamiento )
!>

NAME

ZCHKHS

SYNOPSIS

  SUBROUTINE ZCHKHS( NSIZES, NN, NTYPES, DOTYPE, ISEED, THRESH, NOUNIT,
 &                   A, LDA, H, T1, T2, LDU, U, Z, UZ, W1, W3, EVECTL, EVEZTR,
 &                   EVECTY, EVECTX, UU, TAU, WORK, NWORK, RWORK, IWORK,
 &                   SELECT, RESULT, INFO )

DESCRIPTION

ZCHKHS is a subroutine that tests the nonsymmetric eigenvalue routines ZGEHRD, ZHSEQR, ZTREVC, and ZTRNA. It consists of the following steps:

  1. A loop over the number of matrix sizes specified by NN.

  2. A loop over the matrix types specified by DOTYPE.

  3. For each combination of matrix size and type, a matrix A is generated.

  4. The matrix A is factored as A = U H U' where U is unitary and H is upper Hessenberg. U and H are saved.

  5. The Hessenberg matrix H is factored as H = Z T Z' where Z is unitary and T is upper triangular. Z and T are saved.

  6. The eigenvalues of A are computed from the diagonal entries of T.

  7. The eigenvectors of H are computed.

  8. The eigenvectors of A are computed from the eigenvectors of H.

  9. The result of each step is tested for correctness.

The matrix types are defined as follows:

 (1)  A = 0.
 (2)  A = scalar*I.
 (3)  A = diag(d(i)) where d(i) are randomly distributed numbers.
 (4)  A = diag(d(i)) where d(i) are randomly distributed numbers,
      scaled by SQRT( overflow threshold )
 (5)  A = diag(d(i)) where d(i) are randomly distributed numbers,
      scaled by SQRT( underflow threshold )
 (6)  A = diag(d(i)) where d(i) are random eigenvalues.
 (7)  A = diag(d(i)) where d(i) are random eigenvalues,
      scaled by SQRT( overflow threshold )
 (8)  A = diag(d(i)) where d(i) are random eigenvalues,
      scaled by SQRT( underflow threshold )
 (9)  A is a random matrix with entries chosen from |z| < 1.
 (10) A is a random matrix with entries chosen from |z| < 1,
      scaled by SQRT( overflow threshold )
 (11) A is a random matrix with entries chosen from |z| < 1,
      scaled by SQRT( underflow threshold )
 (12) A is a random matrix with entries chosen from |z| < 1,
      scaled by the overflow threshold.
 (13) A is a random matrix with entries chosen from |z| < 1,
      scaled by the underflow threshold.
 (14) A is a random nonsymmetric matrix with eigenvalues near +/- 1.
 (15) Same as (14), but multiplied by SQRT( overflow threshold )
 (16) Same as (14), but multiplied by SQRT( underflow threshold )
 (17) A is a nonsymmetric matrix with random entries chosen from
      |z| < 1, scaled by the overflow threshold.
 (18) Same as (16), but multiplied by SQRT( underflow threshold )
 (19) Nonsymmetric matrix with random entries chosen from |z| < 1
 (20) Same as (19), but multiplied by SQRT( overflow threshold )
 (21) Same as (19), but multiplied by SQRT( underflow threshold )

ARGUMENTS

NSIZES - INTEGER
The number of sizes of matrices to use. If it is zero, ZCHKHS does nothing. It must be at least zero. Not modified.
NN - INTEGER array, dimension (NSIZES)
An array containing the sizes to be used for the matrices. Zero values will be skipped. The values must be at least zero. Not modified.
NTYPES - INTEGER
The number of elements in DOTYPE. If it is zero, ZCHKHS does nothing. It must be at least zero. If it is MAXTYP+1 and NSIZES is 1, then an additional type, MAXTYP+1 is defined, which is to use whatever matrix is in A. This is only useful if DOTYPE(1:MAXTYP) is .FALSE. and DOTYPE(MAXTYP+1) is .TRUE. . Not modified.
DOTYPE - LOGICAL array, dimension (NTYPES)
If DOTYPE(j) is .TRUE., then for each size in NN a matrix of that size and of type j will be generated. If NTYPES is smaller than the maximum number of types defined (PARAMETER MAXTYP), then types NTYPES+1 through MAXTYP will not be generated. If NTYPES is larger than MAXTYP, DOTYPE(MAXTYP+1) through DOTYPE(NTYPES) will be ignored. Not modified.
ISEED - INTEGER array, dimension (4)
On entry ISEED specifies the seed of the random number generator. The array elements should be between 0 and 4095; if not they will be reduced mod 4096. Also, ISEED(4) must be odd. The random number generator uses a linear congruential sequence limited to small integers, and so should produce machine independent random numbers. The values of ISEED are changed on exit, and can be used in the next call to ZCHKHS to continue the same random number sequence. Modified.
THRESH - DOUBLE PRECISION
A test will count as if the , computed as described above, exceeds THRESH. Note that the error is scaled to be O(1), so THRESH should be a reasonably small multiple of 1, e.g., 10 or 100. In particular, it should not depend on the precision (single vs. double) or the size of the matrix. It must be at least zero. Not modified.
NOUNIT - INTEGER
The FORTRAN unit number for printing out error messages (e.g., if a routine returns IINFO not equal to 0.) Not modified.
A - COMPLEX*16 array, dimension (LDA,max(NN))
Used to hold the matrix whose eigenvalues are to be computed. On exit, A contains the last matrix actually used. Modified.
LDA - INTEGER
The leading dimension of A, H, T1 and T2. It must be at least 1 and at least max( NN ). Not modified.
H - COMPLEX*16 array, dimension (LDA,max(NN))
The upper hessenberg matrix computed by ZGEHRD. On exit, H contains the Hessenberg form of the matrix in A. Modified.
T1 - COMPLEX*16 array, dimension (LDA,max(NN))
The Schur (=) matrix computed by ZHSEQR if Z is computed. On exit, T1 contains the Schur form of the matrix in A. Modified.
T2 - COMPLEX*16 array, dimension (LDA,max(NN))
The Schur matrix computed by ZHSEQR when Z is not computed. This should be identical to T1. Modified.
LDU - INTEGER
The leading dimension of U, Z, UZ and UU. It must be at least 1 and at least max( NN ). Not modified.
U - COMPLEX*16 array, dimension (LDU,max(NN))
The unitary matrix computed by ZGEHRD. Modified.
Z - COMPLEX*16 array, dimension (LDU,max(NN))
The unitary matrix computed by ZHSEQR. Modified.
UZ - COMPLEX*16 array, dimension (LDU,max(NN))
The product of U times Z. Modified.
W1 - COMPLEX*16 array, dimension (max(NN))
The eigenvalues of A, as computed by a full Schur decomposition H = Z T Z'. On exit, W1 contains the eigenvalues of the matrix in A. Modified.
W3 - COMPLEX*16 array, dimension (max(NN))
The eigenvalues of A, as computed by a partial Schur decomposition (Z not computed, T only computed as much as is necessary for determining eigenvalues). On exit, W3 contains the eigenvalues of the matrix in A, possibly perturbed by ZHSEIN. Modified.
EVECTL - COMPLEX*16 array, dimension (LDU,max(NN))
The conjugate transpose of the (upper triangular) left eigenvector matrix for the matrix in T1. Modified.
EVEZTR - COMPLEX*16 array, dimension (LDU,max(NN))
The (upper triangular) right eigenvector matrix for the matrix in T1. Modified.
EVECTY - COMPLEX*16 array, dimension (LDU,max(NN))
The conjugate transpose of the left eigenvector matrix for the matrix in H. Modified.
EVECTX - COMPLEX*16 array, dimension (LDU,max(NN))
The right eigenvector matrix for the matrix in H. Modified.
UU - COMPLEX*16 array, dimension (LDU,max(NN))
Details of the unitary matrix computed by ZGEHRD. Modified.
TAU - COMPLEX*16 array, dimension (max(NN))
Further details of the unitary matrix computed by ZGEHRD. Modified.
WORK - COMPLEX*16 array, dimension (NWORK)
Workspace. Modified.
NWORK - INTEGER
The number of entries in WORK. NWORK >= 4*NN(j)*NN(j) + 2.
RWORK - DOUBLE PRECISION array, dimension (max(NN))
Workspace. Could be equivalenced to IWORK, but not SELECT. Modified.
IWORK - INTEGER array, dimension (max(NN))
Workspace. Modified.
SELECT - LOGICAL array, dimension (max(NN))
Workspace. Could be equivalenced to IWORK, but not RWORK. Modified.
RESULT - DOUBLE PRECISION array, dimension (16)
The values computed by the fourteen tests described above. The values are currently limited to 1/ulp, to avoid overflow. Modified.
INFO - INTEGER
If 0, then everything ran OK. -1: NSIZES < 0 -2: Some NN(j) < 0 -3: NTYPES < 0 -6: THRESH < 0 -9: LDA < 1 or LDA < NMAX, where NMAX is max( NN(j) ). -14: LDU < 1 or LDU < NMAX. -26: NWORK too small. If ZLATMR, CLATMS, or CLATME returns an error code, the absolute value of it is returned. If 1, then ZHSEQR could not find all the shifts. If 2, then the EISPACK code (for small blocks) failed. If >2, then 30*N iterations were not enough to find an eigenvalue or to decompose the problem. Modified.

LOCAL VARIABLES AND PARAMETERS

    Some Local Variables and Parameters:
    ---- ----- --------- --- ----------

    ZERO, ONE       Real 0 and 1.
    MAXTYP          The number of types defined.
    MTEST           The number of tests defined: care must be taken
                    that (1) the size of RESULT, (2) the number of
                    tests actually performed, and (3) MTEST agree.
    NTEST           The number of tests performed on this matrix
                    so far.  This should be less than MTEST, and
                    equal to it by the last test.  It will be less
                    if any of the routines being tested indicates
                    that it could not compute the matrices that
                    would be tested.
    NMAX            Largest value in NN.
    NMATS           The number of matrices generated so far.
    NERRS           The number of tests which have exceeded THRESH
                    so far (computed by DLAFTS).
    COND, CONDS,
    IMODE           Values to be passed to the matrix generators.
    ANORM           Norm of A; passed to matrix generators.

    OVFL, UNFL      Overflow and underflow thresholds.
    ULP, ULPINV     Finest relative precision and its inverse.
    RTOVFL, RTUNFL,
    RTULP, RTULPI   Square roots of the previous 4 values.

            The following four arrays decode JTYPE:
    KTYPE(j)        The general type (1-10) for type .
    KMODE(j)        The MODE value to be passed to the matrix
                    generator for type .
    KMAGN(j)        The order of magnitude ( O(1),
                    O(overflow^(1/2) ), O(underflow^(1/2) )
    KCONDS(j)       Selects whether CONDS is to be 1 or
                    1/sqrt(ulp).  (0 means irrelevant.)

Documentación de Funciones/Subrutinas

zchkhs comprueba si una matriz compleja conjugada A(N, N) o A(M, N) es hermitiana.

a

Matriz a comprobar.

lda

Dobz del primer dimension de la matriz A.

n

Numero de columnas de la matriz A.

b

Matriz que sera sustituida por la diferencia A - AH.

ldb

Dobz del primer dimension de la matriz B.

m

Numero de filas de la matriz A.

eps

Tolerancia para la comprobacion de la hermiticidad.
