ZBLAT2

Propósito:

!>
!> Programa de prueba para las BLAS de Nivel 2 COMPLEJAS*16.
!>
!> El programa debe ser dirigido por un archivo de datos corto. Los primeros 18 registros
!> se leen usando entrada de lista dirigida, los últimos 17 registros
!> se leen usando el formato ( A6, L2 ). Un ejemplo anotado de un archivo de datos
!> se puede obtener eliminando los primeros 3 caracteres de las siguientes 35 líneas:
!> 'zblat2.out'      NOMBRE DEL ARCHIVO DE SALIDA DE RESUMEN
!> 6                 NÚMERO DE UNIDAD DEL ARCHIVO DE RESUMEN
!> 'CBLA2T.SNAP'     NOMBRE DEL ARCHIVO DE SALIDA DE INSTANTÁNEA
!> -1                NÚMERO DE UNIDAD DEL ARCHIVO DE INSTANTÁNEA (NO USADO SI .LT. 0)
!> F        BANDERA LÓGICA, T PARA REBOBINAR EL ARCHIVO DE INSTANTÁNEA DESPUÉS DE CADA REGISTRO.
!> F        BANDERA LÓGICA, T PARA DETENERSE EN FALLOS.
!> T        BANDERA LÓGICA, T PARA PROBAR LAS SALIDAS DE ERROR.
!> 16.0     VALOR UMBRAL DE LA RELACIÓN DE PRUEBA
!> 6                 NÚMERO DE VALORES DE N
!> 0 1 2 3 5 9       VALORES DE N
!> 4                 NÚMERO DE VALORES DE K
!> 0 1 2 4           VALORES DE K
!> 4                 NÚMERO DE VALORES DE INCX E INCY
!> 1 2 -1 -2         VALORES DE INCX E INCY
!> 3                 NÚMERO DE VALORES DE ALPHA
!> (0.0,0.0) (1.0,0.0) (0.7,-0.9)       VALORES DE ALPHA
!> 3                 NÚMERO DE VALORES DE BETA
!> (0.0,0.0) (1.0,0.0) (1.3,-1.1)       VALORES DE BETA
!> ZGEMV  T Poner F para NO PROBAR. Mismas columnas.
!> ZGBMV  T Poner F para NO PROBAR. Mismas columnas.
!> ZHEMV  T Poner F para NO PROBAR. Mismas columnas.
