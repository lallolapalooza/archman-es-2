NOMBRE

zcav - programa para probar el rendimiento de unidades de disco sin procesar.

SINOPSIS

zcav [-b tamaño-bloque[:tamaño-chunk]] [-c contador] [-r [bloque-inicial]:bloque-final] [-w] [-s tasa-salto] [-u uid-a-usar:gid-a-usar] [-g gid-a-usar] [-l archivo-registro] [-f] nombre-archivo [-l archivo-registro [-f] nombre-archivo]...

DESCRIPCIÓN

Esta página del manual documenta brevemente el programa zcav.

Los discos duros modernos tienen una velocidad de rotación constante pero tienen números variables de sectores por pista (las pistas exteriores son más largas y tienen más sectores). Esto se conoce como Velocidad Angular Constante Zonificada (o ZCAV). Las pistas exteriores tendrán una mayor tasa de transferencia de datos debido a que tienen más sectores por pista, estas pistas generalmente tienen los números de pista/sector más bajos.

Este programa prueba el rendimiento ZCAV de un disco duro, leyendo todos los datos en él un número especificado de veces. El nombre de archivo dado como primer parámetro, puede especificarse como -, para entrada estándar. Este archivo se abrirá en modo de solo lectura y en operación normal será /dev/hdX o /dev/ide/host0/busX/targetY/lun0/disc dependiendo de si usa devfs o no (NB los sistemas operativos distintos de Linux tendrán nombres de dispositivo diferentes).

La salida debería poder ser graficada fácilmente con gnuplot, que es lo que yo uso para ver los resultados.

OPCIONES

-b
el tamaño (en Megas) de los bloques a leer/escribir (predeterminado 512M), opcionalmente seguido por un ':' y el tamaño de chunk para operaciones de lectura/escritura (predeterminado 1M). Tenga en cuenta que el tamaño de chunk debe ser menor o igual al tamaño del bloque y también debe ser significativamente menor que el tamaño de la RAM en la máquina. Tenga en cuenta también que para la prueba de escritura habrá un fsync() después de escribir cada chunk.
-c
el número de veces que se leerá/escribirá todo el disco.
-r
el rango de datos (en Megas) a leer/escribir en cada pasada (predeterminado todo el dispositivo). Útil si desea probar rápidamente una parte de un disco grande. Si se da un solo número, ese es el último bloque a leer, si son dos números, es el inicio y el fin de un rango. Los valores están en megas, pero se redondean hacia abajo al tamaño del bloque.
-s
tasa de salto. La opción -s 10 hará que lea cada 10º bloque y omita el resto. Acepta valores de 2 a 20.
-f
el nombre de archivo para los datos de entrada. Esto no es necesario en sistemas bien configurados que tienen una Glibc reciente donde puede especificar el nombre de archivo sin la opción -f.
-u
id de usuario a usar. Al ejecutar como root, especifique el UID para ejecutar las pruebas, no se recomienda usar root, así que si desea ejecutar como root use -u root. Además, si desea especificar el grupo a usar, use el formato usuario:grupo. Si especifica un usuario por nombre pero ningún grupo, se elegirá el grupo principal de ese usuario. Si especifica un usuario por número y ningún grupo, el grupo será nogroup.
-g
id de grupo a usar. Igual que usar :grupo para el parámetro -u, solo una forma diferente de especificarlo para compatibilidad con otros programas.
-w
escribir bloques de ceros en el disco en lugar de leer del disco - ¡destruirá datos!
