subrutina zchkhb2stg (integer nsizes, integer, dimension( * ) nn, integer nwdths, integer, dimension( * ) kk, integer ntypes, logical, dimension( * ) dotype, integer, dimension( 4 ) iseed, double precision thresh, integer nounit, complex*16, dimension( lda, * ) a, integer lda, double precision, dimension( * ) sd, double precision, dimension( * ) se, double precision, dimension( * ) d1, double precision, dimension( * ) d2, double precision, dimension( * ) d3, complex*16, dimension( ldu, * ) u, integer ldu, complex*16, dimension( * ) work, integer lwork, double precision, dimension( * ) rwork, double precision, dimension( * ) result, integer info)

ZCHKHB2STG

Propósito:

!>
!> ZCHKHB2STG prueba la reducción de una matriz de banda Hermítica a forma
!> tridiagonal, utilizada con el problema de valores propios Hermíticos.
!>
!> ZHBTRD factoriza una matriz de banda Hermítica A como U S U*, donde * denota
!> transpuesta conjugada, S es tridiagonal simétrica, y U es unitaria.
!> ZHBTRD puede usar solo la parte triangular inferior o solo la superior
!> de A; ZCHKHB2STG verifica ambos casos.
!>
!> ZHETRD_HB2ST factoriza una matriz de banda Hermítica A como U S U*,
!> donde * denota transpuesta conjugada, S es tridiagonal simétrica, y U es
!> unitaria. ZHETRD_HB2ST puede usar solo la parte triangular inferior o solo la
!> superior de A; ZCHKHB2STG verifica ambos casos.
!>
!> DSTEQR factoriza S como Z D1 Z'.
!> D1 es la matriz de valores propios calculados cuando Z no se calcula
!> y a partir de S resultante de DSBTRD (utilizada como referencia para DSYTRD_SB2ST)
!> D2 es la matriz de valores propios calculados cuando Z no se calcula
!> y a partir de S resultante de DSYTRD_SB2ST.
!> D3 es la matriz de valores propios calculados cuando Z no se calcula
!> y a partir de S resultante de DSYTRD_SB2ST.
!>
!> Cuando se llama a ZCHKHB2STG, se especifica un número de tamaños de matriz (),
!> un número de anchos de banda () y un número de tipos de matriz. Para cada tamaño (),
!> cada ancho de banda () menor o igual a , y cada tipo de matriz, se generará
!> una matriz y se utilizará para probar la rutina de reducción Hermítica de banda.
!> Para cada matriz, se realizarán una serie de pruebas:
!>
!> (1) | A - V S V* | / ( |A| n ulp ) calculado por ZHBTRD con UPLO='U'
!>
!> (2) | I - UU* | / ( n ulp )
!>
!> (3) | A - V S V* | / ( |A| n ulp ) calculado por ZHBTRD con UPLO='L'
!>
!> (4) | I - UU* | / ( n ulp )
!>
!> (5) | D1 - D2 | / ( |D1| ulp ) donde D1 es calculado por DSBTRD con UPLO='U' y
!> D2 es calculado por ZHETRD_HB2ST con UPLO='U'
!>
!> (6) | D1 - D3 | / ( |D1| ulp ) donde D1 es calculado por
!> DSBTRD con UPLO='U' y
!> D3 es calculado por
!> ZHETRD_HB2ST con UPLO='L'
!>
!> Los se especifican mediante un array NN(1:NSIZES); el valor de
!> cada elemento NN(j) especifica un tamaño.
!> Los se especifican mediante un array lógico DOTYPE( 1:NTYPES );
!> si DOTYPE(j) es .TRUE., se generará una matriz de tipo j.
!> Actualmente, la lista de tipos posibles es:
!>
!> (1) La matriz cero.
!> (2) La matriz identidad.
!>
!> (3) Una matriz diagonal con entradas espaciadas uniformemente
!> 1, ..., ULP y signos aleatorios.
!> (ULP = (primer número mayor que 1) - 1)
!> (4) Una matriz diagonal con entradas espaciadas geométricamente
!> 1, ..., ULP y signos aleatorios.
!> (5) Una matriz diagonal con entradas 1, ULP, ..., ULP
!> y signos aleatorios.
!>
!> (6) Igual que (4), pero multiplicada por SQRT( umbral de desbordamiento )
!> (7) Igual que (4), pero multiplicada por SQRT( umbral de subdesbordamiento )
!>
!> (8) Una matriz de la forma U* D U, donde U es unitaria y
!> D tiene entradas espaciadas uniformemente 1, ..., ULP con signos aleatorios
!> en la diagonal.
!>
!> (9) Una matriz de la forma U* D U, donde U es unitaria y
!> D tiene entradas espaciadas geométricamente 1, ..., ULP con signos aleatorios
!> en la diagonal.
!>
!> (10) Una matriz de la forma U* D U, donde U es unitaria y
!> D tiene entradas 1, ULP,..., ULP con signos aleatorios
!> en la diagonal.
!>
!> (11) Igual que (8), pero multiplicada por SQRT( umbral de desbordamiento )
!> (12) Igual que (8), pero multiplicada por SQRT( umbral de subdesbordamiento )
!>
!> (13) Matriz Hermítica con entradas aleatorias elegidas de (-1,1).
!> (14) Igual que (13), pero multiplicada por SQRT( umbral de desbordamiento )
!> (15) Igual que (13), pero multiplicada por SQRT( umbral de subdesbordamiento )
!>

Parámetros

NSIZES 
!>          NSIZES es INTEGER
!>          El número de tamaños de matrices a utilizar. Si es cero,
!>          ZCHKHB2STG no hace nada. Debe ser al menos cero.
!>

NN

!>          NN es un array INTEGER, dimension (NSIZES)
!>          Un array que contiene los tamaños a utilizar para las matrices.
!>          Los valores cero se omitirán. Los valores deben ser al menos
!>          cero.
!>

NWDTHS

!>          NWDTHS es INTEGER
!>          El número de anchos de banda a utilizar. Si es cero,
!>          ZCHKHB2STG no hace nada. Debe ser al menos cero.
!>

KK

!>          KK es un array INTEGER, dimension (NWDTHS)
!>          Un array que contiene los anchos de banda a utilizar para las matrices
!>          de banda. Los valores deben ser al menos cero.
!>

NTYPES

!>          NTYPES es INTEGER
!>          El número de elementos en DOTYPE. Si es cero, ZCHKHB2STG
!>          no hace nada. Debe ser al menos cero. Si es MAXTYP+1
!>          y NSIZES es 1, entonces se define un tipo adicional, MAXTYP+1,
!>          que es usar cualquier matriz que esté en A. Esto
!>          solo es útil si DOTYPE(1:MAXTYP) es .FALSE. y
!>          DOTYPE(MAXTYP+1) es .TRUE. .
!>

DOTYPE

!>          DOTYPE es un array LOGICAL, dimension (NTYPES)
!>          Si DOTYPE(j) es .TRUE., entonces para cada tamaño en NN se generará
!>          una matriz de ese tamaño y de tipo j.
!>          Si NTYPES es menor que el número máximo de tipos
!>          definidos (PARAMETER MAXTYP), entonces los tipos NTYPES+1 hasta
!>          MAXTYP no se generarán. Si NTYPES es mayor
!>          que MAXTYP, DOTYPE(MAXTYP+1) hasta DOTYPE(NTYPES)
!>          se ignorarán.
!>

ISEED

!>          ISEED es un array INTEGER, dimension (4)
!>          A la entrada ISEED especifica la semilla del generador de números
!>          aleatorios. Los elementos del array deben estar entre 0 y 4095;
!>          si no, se reducirán módulo 4096. Además, ISEED(4) debe
!>          ser impar. El generador de números aleatorios utiliza una secuencia
!>          congruencial lineal limitada a enteros pequeños, y por lo tanto
!>          debería producir números aleatorios independientes de la máquina. Los
!>          valores de ISEED se modifican a la salida y pueden ser utilizados en la
!>          siguiente llamada a ZCHKHB2STG para continuar la misma secuencia de números
!>          aleatorios.
!>

THRESH

!>          THRESH es DOUBLE PRECISION
!>          Umbral para las pruebas relativas. Por ejemplo, si
!>          THRESH es 10.0, entonces para las pruebas relativas se
!>          considerará un error si el residuo normalizado es mayor que 10*ulp.
!>

NOUNNIT

!>          NOUNIT es INTEGER
!>          NOUNIT es un flag para determinar si se debe probar el
!>          cálculo de la matriz unitaria U.
!>          = 0: La matriz unitaria U se calcula y se prueba.
!>          -ne 0: La matriz unitaria U no se calcula ni se prueba.
!>

A

!>          A es COMPLEX*16 array, dimension (LDA, *)
!>          En la entrada, A es una matriz de banda Hermítica de tamaño (N, N)
!>          con ancho de banda K. Si K=0, A es una matriz diagonal.
!>          Si el tipo de matriz es 13, 14 o 15, solo se utiliza el
!>          triángulo superior de A.
!>          A la salida, A contiene la matriz tridiagonal S.
!>

LDA

!>          LDA es INTEGER
!>          El dimensionamiento de la matriz A. Debe ser al menos max(1,N).
!>

SD

!>          SD es DOUBLE PRECISION array, dimension (*)
!>          En la salida, SD contiene los valores propios de la matriz
!>          tridiagonal S.
!>

SE

!>          SE es DOUBLE PRECISION array, dimension (*)
!>          En la salida, SE contiene los valores propios de la matriz
!>          tridiagonal S.
!>

D1

!>          D1 es DOUBLE PRECISION array, dimension (*)
!>          En la salida, D1 contiene los valores propios de la matriz
!>          tridiagonal S, calculado usando el procedimiento de referencia.
!>

D2

!>          D2 es DOUBLE PRECISION array, dimension (*)
!>          En la salida, D2 contiene los valores propios de la matriz
!>          tridiagonal S, calculado usando el procedimiento de prueba.
!>

D3

!>          D3 es DOUBLE PRECISION array, dimension (*)
!>          En la salida, D3 contiene los valores propios de la matriz
!>          tridiagonal S, calculado usando el procedimiento de prueba.
!>

U

!>          U es COMPLEX*16 array, dimension (LDU, *)
!>          En la salida, U contiene la matriz unitaria V.
!>

LDU

!>          LDU es INTEGER
!>          El dimensionamiento de la matriz U. Debe ser al menos max(1,N).
!>

WORK

!>          WORK es COMPLEX*16 array, dimension (LWORK)
!>

LWORK

!>          LWORK es INTEGER
!>          La longitud de la matriz WORK. Debe ser al menos
!>          max(N*N, 2*N) para ZHBTRD y max(N, 2*N) para ZHETRD_HB2ST.
!>

RWORK

!>          RWORK es DOUBLE PRECISION array, dimension (*)
!>

RESULT

!>          RESULT es DOUBLE PRECISION array, dimension (*)
!>          El array de resultados. RESULT(j) contiene el valor del test j.
!>          Por ejemplo, si RESULT(1) es 0, el test 1 pasó.
!>

INFO

!>          INFO es INTEGER
!>          INFO = 0: éxito.
!>          INFO < 0: si el argumento i-ésimo (negativo) era inválido.
!>          INFO > 0: si la rutina de actualización falló al converger.
!>

NAME

zchkhb2stg - Performs tests for the subroutine ZHB2ST

SYNOPSIS

SUBROUTINE ZCHKHBTSTG( 
     THRESH, NOUNIT, A, LDA, SD, SE, D1, D2, D3, U, LDU, WORK, LWORK, 
     RWORK, RESULT, INFO )
INTEGER NOUNIT, LDA, LDU, LWORK, INFO
DOUBLE PRECISION THRESH, SD(*), SE(*), D1(*), D2(*), D3(*), RWORK(*), 
     RESULT(*)
COMPLEX*16 A(LDA,*), U(LDU,*), WORK(LWORK)

Function/Subroutine Documentation


THRESH

!>          THRESH is DOUBLE PRECISION
!>          A test will count as if the , computed as
!>          described above, exceeds THRESH. Note that the error
!>          is scaled to be O(1), so THRESH should be a reasonably
!>          small multiple of 1, e.g., 10 or 100. In particular,
!>          it should not depend on the precision (single vs. double)
!>          or the size of the matrix. It must be at least zero.
!>

NOUNIT

!>          NOUNIT is INTEGER
!>          The FORTRAN unit number for printing out error messages
!>          (e.g., if a routine returns IINFO not equal to 0.)
!>

A

!>          A is COMPLEX*16 array, dimension
!>                            (LDA, max(NN))
!>          Used to hold the matrix whose eigenvalues are to be
!>          computed.
!>

LDA

!>          LDA is INTEGER
!>          The leading dimension of A. It must be at least 2 (not 1!)
!>          and at least max( KK )+1.
!>

SD

!>          SD is DOUBLE PRECISION array, dimension (max(NN))
!>          Used to hold the diagonal of the tridiagonal matrix computed
!>          by ZHBTRD.
!>

SE

!>          SE is DOUBLE PRECISION array, dimension (max(NN))
!>          Used to hold the off-diagonal of the tridiagonal matrix
!>          computed by ZHBTRD.
!>

D1

!>          D1 is DOUBLE PRECISION array, dimension (max(NN))
!>

D2

!>          D2 is DOUBLE PRECISION array, dimension (max(NN))
!>


*>
D3

!>          D3 is DOUBLE PRECISION array, dimension (max(NN))
!>

U

!>          U is COMPLEX*16 array, dimension (LDU, max(NN))
!>          Used to hold the unitary matrix computed by ZHBTRD.
!>

LDU

!>          LDU is INTEGER
!>          The leading dimension of U. It must be at least 1
!>          and at least max( NN ).
!>

WORK

!>          WORK is COMPLEX*16 array, dimension (LWORK)
!>

LWORK

!>          LWORK is INTEGER
!>          The number of entries in WORK. This must be at least
!>          max( LDA+1, max(NN)+1 )*max(NN).
!>

RWORK

!>          RWORK is DOUBLE PRECISION array
!>

RESULT

!>          RESULT is DOUBLE PRECISION array, dimension (4)
!>          The values computed by the tests described above.
!>          The values are currently limited to 1/ulp, to avoid
!>          overflow.
!>

INFO

!>          INFO is INTEGER
!>          If 0, then everything ran OK.
