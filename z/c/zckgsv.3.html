ZCKGSV

Propósito:

!>
!> ZCKGSV prueba ZGGSVD:
!>        la GSVD para la matriz A de M por N y la matriz B de P por N.
!>

Parámetros

NM 
!>          NM es ENTERO
!>          El número de valores de M contenidos en el vector MVAL.
!>

MVAL

!>          MVAL es un array ENTERO, dimensión (NM)
!>          Los valores de la dimensión de filas de la matriz M.
!>

PVAL

!>          PVAL es un array ENTERO, dimensión (NP)
!>          Los valores de la dimensión de filas de la matriz P.
!>

NVAL

!>          NVAL es un array ENTERO, dimensión (NN)
!>          Los valores de la dimensión de columnas de la matriz N.
!>

NMATS

!>          NMATS es ENTERO
!>          El número de tipos de matriz que se probarán para cada combinación
!>          de dimensiones de matriz. Si NMATS >= NTYPES (el número máximo
!>          de tipos de matriz), entonces se generan todos los tipos diferentes
!>          para la prueba. Si NMATS < NTYPES, se lee otra línea de entrada
!>          para obtener los números de los tipos de matriz a utilizar.
!>

ISEED

!>          ISEED es un array ENTERO, dimensión (4)
!>          En la entrada, la semilla del generador de números aleatorios. Los
!>          elementos del array deben estar entre 0 y 4095, de lo contrario se
!>          reducirán módulo 4096, y ISEED(4) debe ser impar.
!>          En la salida, la siguiente semilla en la secuencia de números
!>          aleatorios después de que se hayan generado todas las matrices de prueba.
!>

THRESH

!>          THRESH es PRECISIÓN DOBLE
!>          El valor umbral para las relaciones de prueba. Un resultado se
!>          incluye en el archivo de salida si RESULT >= THRESH. Para imprimir
!>          todas las relaciones de prueba, use THRESH = 0.
!>

NMAX

!>          NMAX es ENTERO
!>          El valor máximo permitido para M o N, utilizado en la dimensionamiento
!>          de los arrays de trabajo.
!>

A

!>          A es un array COMPLEX*16, dimensión (NMAX*NMAX)
!>

AF

!>          AF es un array COMPLEX*16, dimensión (NMAX*NMAX)
!>

B

!>          B es un array COMPLEX*16, dimensión (NMAX*NMAX)
!>

BF

!>          BF es un array COMPLEX*16, dimensión (NMAX*NMAX)
!>

U

!>          U es un array COMPLEX*16, dimensión (NMAX*NMAX)
!>

V

!>          V es un array COMPLEX*16, dimensión (NMAX*NMAX)
!>

Q

!>          Q es un array COMPLEX*16, dimensión (NMAX*NMAX)
!>

ALPHA

!>          ALPHA es un array de PRECISIÓN DOBLE, dimensión (NMAX)
!>

BETA

!>          BETA es un array de PRECISIÓN DOBLE, dimensión (NMAX)
!>

R

!>          R es un array COMPLEX*16, dimensión (NMAX*NMAX)
!>

IWORK

!>          IWORK es un array ENTERO, dimensión (NMAX)
!>

WORK

!>          WORK es un array COMPLEX*16, dimensión (NMAX*NMAX)
!>

RWORK

!>          RWORK es un array de PRECISIÓN DOBLE, dimensión (NMAX)
!>

NIN

!>          NIN es ENTERO
!>          La unidad numérica para la entrada.
!>

NOUT

!>          NOUT es ENTERO
!>          La unidad numérica para la salida.
!>

INFO

!>          INFO es ENTERO
!>          = 0 :  salida exitosa
!>          > 0 :  Si ZLATMS devuelve un código de error, se devuelve su valor
!>                 absoluto.
!>
