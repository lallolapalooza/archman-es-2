ZCKLSE

Propósito:

!>
!> ZCKLSE prueba ZGGLSE - una subrutina para resolver el problema de mínimos cuadrados lineales con restricciones de igualdad (LSE).
!>

Parámetros

NN 
!>          NN es ENTERO
!>          El número de valores de (M,P,N) contenidos en los vectores
!>          (MVAL, PVAL, NVAL).
!>

MVAL

!>          MVAL es un array ENTERO, dimensión (NN)
!>          Los valores de la dimensión M (fila/columna) de la matriz.
!>

PVAL

!>          PVAL es un array ENTERO, dimensión (NN)
!>          Los valores de la dimensión P (fila/columna) de la matriz.
!>

NVAL

!>          NVAL es un array ENTERO, dimensión (NN)
!>          Los valores de la dimensión N (columna/fila) de la matriz.
!>

NMATS

!>          NMATS es ENTERO
!>          El número de tipos de matrices a probar para cada combinación
!>          de dimensiones de matriz. Si NMATS >= NTYPES (el número
!>          máximo de tipos de matrices), entonces se generan todos los tipos diferentes
!>          para la prueba. Si NMATS < NTYPES, se lee otra línea de entrada
!>          para obtener los números de los tipos de matrices a usar.
!>

ISEED

!>          ISEED es un array ENTERO, dimensión (4)
!>          En la entrada, la semilla del generador de números aleatorios. Los elementos
!>          del array deben estar entre 0 y 4095, de lo contrario se reducirán
!>          módulo 4096, y ISEED(4) debe ser impar.
!>          En la salida, la siguiente semilla en la secuencia de números aleatorios
!>          después de que se hayan generado todas las matrices de prueba.
!>

THRESH

!>          THRESH es PRECISIÓN DOBLE
!>          El valor umbral para las razones de prueba. Un resultado se
!>          incluye en el archivo de salida si RESULTADO >= UMBRAL. Para que
!>          cada razón de prueba se imprima, use UMBRAL = 0.
!>

NMAX

!>          NMAX es ENTERO
!>          El valor máximo permitido para M o N, utilizado en la dimensionamiento
!>          de los arrays de trabajo.
!>

A

!>          A es un array COMPLEJO*16, dimensión (NMAX*NMAX)
!>

AF

!>          AF es un array COMPLEJO*16, dimensión (NMAX*NMAX)
!>

B

!>          B es un array COMPLEJO*16, dimensión (NMAX*NMAX)
!>

BF

!>          BF es un array COMPLEJO*16, dimensión (NMAX*NMAX)
!>

X

!>          X es un array COMPLEJO*16, dimensión (5*NMAX)
!>

WORK

!>          WORK es un array COMPLEJO*16, dimensión (NMAX*NMAX)
!>

RWORK

!>          RWORK es un array PRECISIÓN DOBLE, dimensión (NMAX)
!>

NIN

!>          NIN es ENTERO
!>          El número de unidad para entrada.
!>

NOUT

!>          NOUT es ENTERO
!>          El número de unidad para salida.
!>

INFO

!>          INFO es ENTERO
!>          = 0 :  salida exitosa
!>          > 0 :  Si ZLATMS devuelve un código de error, su valor absoluto
!>                 se devuelve.
!>
