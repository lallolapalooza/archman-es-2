subroutine zcgesv (integer n, integer nrhs, complex*16, dimension( lda, * ) a, integer lda, integer, dimension( * ) ipiv, complex*16, dimension( ldb, * ) b, integer ldb, complex*16, dimension( ldx, * ) x, integer ldx, complex*16, dimension( n, * ) work, complex, dimension( * ) swork, double precision, dimension( * ) rwork, integer iter, integer info)

ZCGESV calcula la solución al sistema de ecuaciones lineales A * X = B para matrices GE (precisión mixta con refinamiento iterativo)

Propósito:

!>
!> ZCGESV calcula la solución a un sistema de ecuaciones lineales complejo
!>    A * X = B,
!> donde A es una matriz N por N y X y B son matrices N por NRHS.
!>
!> ZCGESV primero intenta factorizar la matriz en COMPLEX y usar esta
!> factorización dentro de un procedimiento de refinamiento iterativo para producir una
!> solución con calidad de error residual normwise de COMPLEX*16 (ver abajo).
!> Si el enfoque falla, el método cambia a una factorización y solución
!> de COMPLEX*16.
!>
!> El refinamiento iterativo no será una estrategia ganadora si
!> la relación entre el rendimiento de COMPLEX y el rendimiento de COMPLEX*16 es demasiado
!> pequeña. Una estrategia razonable debería tener en cuenta el número de lados derechos
!> y el tamaño de la matriz. Esto podría hacerse
!> con una llamada a ILAENV en el futuro. Hasta ahora, siempre intentamos
!> el refinamiento iterativo.
!>
!> El proceso de refinamiento iterativo se detiene si
!>     ITER > ITERMAX
!> o para todos los RHS tenemos:
!>     RNRM < SQRT(N)*XNRM*ANRM*EPS*BWDMAX
!> donde
!>     o ITER es el número de la iteración actual en el proceso
!>       de refinamiento iterativo
!>     o RNRM es la norma infinita del residuo
!>     o XNRM es la norma infinita de la solución
!>     o ANRM es la norma del operador infinito de la matriz A
!>     o EPS es el epsilon de máquina devuelto por DLAMCH('Epsilon')
!> Los valores ITERMAX y BWDMAX se fijan en 30 y 1.0D+00
!> respectivamente.
!>

Parámetros

N 
!>          N es INTEGER
!>          El número de ecuaciones lineales, es decir, el orden de
!>          la matriz A.  N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de lados derechos, es decir, el número de columnas
!>          de la matriz B.  NRHS >= 0.
!>

A

!>          A es un array COMPLEX*16,
!>          dimensión (LDA,N)
!>          En la entrada, la matriz de coeficientes A de N por N.
!>          En la salida, si el refinamiento iterativo se ha utilizado con éxito
!>          (INFO = 0 e ITER >= 0, ver descripción abajo), entonces A no cambia,
!>          si se ha utilizado la factorización de precisión doble
!>          (INFO = 0 e ITER < 0, ver descripción abajo), entonces el
!>          array A contiene los factores L y U de la factorización
!>          A = P*L*U; los elementos diagonales unitarios de L no se almacenan.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

IPIV

!>          IPIV es un array INTEGER, dimensión (N)
!>          Los índices de pivote que definen la matriz de permutación P;
!>          la fila i de la matriz se intercambió con la fila IPIV(i).
!>          Corresponde a la factorización de precisión simple
!>          (si INFO = 0 e ITER >= 0) o a la factorización de precisión doble
!>          (si INFO = 0 e ITER < 0).
!>

B

!>          B es un array COMPLEX*16, dimensión (LDB,NRHS)
!>          La matriz del lado derecho B de N por NRHS.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B.  LDB >= max(1,N).
!>

X

!>          X es un array COMPLEX*16, dimensión (LDX,NRHS)
!>          Si INFO = 0, la matriz solución X de N por NRHS.
!>

LDX

!>          LDX es INTEGER
!>          La dimensión principal del array X.  LDX >= max(1,N).
!>

WORK

!>          WORK es un array COMPLEX*16, dimensión (N,NRHS)
!>          Este array se utiliza para almacenar los vectores residuales.
!>

SWORK

!>          SWORK es un array COMPLEX, dimensión (N*(N+NRHS))
!>          Este array se utiliza para usar la matriz de precisión simple y los
!>          lados derechos o soluciones en precisión simple.
!>

RWORK

!>          RWORK es un array DOUBLE PRECISION, dimensión (N)
!>

ITER

!>          ITER es INTEGER
!>          < 0: el refinamiento iterativo ha fallado, se ha realizado
!>               una factorización COMPLEX*16
!>               -1 : la rutina recurrió a la precisión completa por
!>                    razones específicas de la implementación o de la máquina
!>               -2 : la reducción de la precisión provocó un desbordamiento,
!>                    la rutina recurrió a la precisión completa
!>               -3 : fallo de CGETRF
!>               -31: detiene el refinamiento iterativo después de la 30ª
!>                    iteración
!>          > 0: el refinamiento iterativo se ha utilizado con éxito.
!>               Devuelve el número de iteraciones
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>          > 0:  si INFO = i, U(i,i) calculado en COMPLEX*16 es exactamente
!>                cero.  La factorización se ha completado, pero el
!>                factor U es exactamente singular, por lo que la solución
!>                no pudo calcularse.
!>
