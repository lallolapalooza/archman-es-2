Documentación de la función/subrutina

subrutina zchkst (integer nsizes, integer, dimension( * ) nn, integer ntypes, logical, dimension( * ) dotype, integer, dimension( 4 ) iseed, double precision thresh, integer nounit, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( * ) ap, double precision, dimension( * ) sd, double precision, dimension( * ) se, double precision, dimension( * ) d1, double precision, dimension( * ) d2, double precision, dimension( * ) d3, double precision, dimension( * ) d4, double precision, dimension( * ) d5, double precision, dimension( * ) wa1, double precision, dimension( * ) wa2, double precision, dimension( * ) wa3, double precision, dimension( * ) wr, complex*16, dimension( ldu, * ) u, integer ldu, complex*16, dimension( ldu, * ) v, complex*16, dimension( * ) vp, complex*16, dimension( * ) tau, complex*16, dimension( ldu, * ) z, complex*16, dimension( * ) work, integer lwork, double precision, dimension( * ) rwork, integer lrwork, integer, dimension( * ) iwork, integer liwork, double precision, dimension( * ) result, integer info)

ZCHKST

Propósito:

!>
!> ZCHKST  verifica las rutinas del problema de valores propios Hermíticos.
!>
!>    ZHETRD factoriza A como  U S U* , donde * significa transpuesta conjugada,
!>    S es real simétrica tridiagonal, y U es unitaria.
!>    ZHETRD puede usar solo la parte triangular inferior o superior
!>    de A; ZCHKST verifica ambos casos.
!>    U se representa como un producto de transformaciones de Householder
!>    cuyos vectores se almacenan en las primeras
!>    n-1 columnas de V, y cuyos factores de escala se encuentran en TAU.
!>
!>    ZHPTRD hace lo mismo que ZHETRD, excepto que A y V se almacenan
!>    en formato  .
!>
!>    ZUNGTR construye la matriz U a partir del contenido de V y TAU.
!>
!>    ZUPGTR construye la matriz U a partir del contenido de VP y TAU.
!>
!>    ZSTEQR factoriza S como  Z D1 Z* , donde Z es la matriz
!>    unitaria de vectores propios y D1 es una matriz diagonal con
!>    los valores propios en la diagonal.  D2 es la matriz de
!>    valores propios calculada cuando Z no se calcula.
!>
!>    DSTERF calcula D3, la matriz de valores propios, mediante el
!>    método PWK, que no produce vectores propios.
!>
!>    ZPTEQR factoriza S como  Z4 D4 Z4* , para una
!>    matriz tridiagonal Hermítica positiva definida.
!>    D5 es la matriz de valores propios calculada cuando Z no se
!>    calcula.
!>
!>    DSTEBZ calcula valores propios seleccionados.  WA1, WA2, y
!>    WA3 denotarán valores propios calculados con alta
!>    precisión absoluta, con diferentes opciones de rango.
!>    WR denotará valores propios calculados con alta
!>    precisión relativa.
!>
!>    ZSTEIN calcula Y, los vectores propios de S, dados los
!>    valores propios.
!>
!>    ZSTEDC factoriza S como Z D1 Z* , donde Z es la matriz unitaria
!>    de vectores propios y D1 es una matriz diagonal con
!>    los valores propios en la diagonal ('I' opción). También puede
!>    actualizar una matriz unitaria de entrada, usualmente la salida
!>    de ZHETRD/ZUNGTR o ZHPTRD/ZUPGTR ('V' opción). También puede
!>    simplemente calcular valores propios ('N' opción).
!>
!>    ZSTEMR factoriza S como Z D1 Z* , donde Z es la matriz unitaria
!>    de vectores propios y D1 es una matriz diagonal con
!>    los valores propios en la diagonal ('I' opción).  ZSTEMR
!>    utiliza la Representación Relativamente Robusta siempre que sea posible.
!>
!> Cuando se llama a ZCHKST, se especifica un número de tamaños de matriz  ()
!> y un número de tipos de matriz.  Para cada tamaño ()
!> y cada tipo de matriz, se generará una matriz y se utilizará
!> para probar las rutinas de valores propios Hermíticos. Para cada matriz, se
!> realizarán una serie de pruebas:
!>
!> (1)     | A - V S V* | / ( |A| n ulp ) ZHETRD( UPLO='U', ... )
!>
!> (2)     | I - UV* | / ( n ulp )        ZUNGTR( UPLO='U', ... )
!>
!> (3)     | A - V S V* | / ( |A| n ulp ) ZHETRD( UPLO='L', ... )
!>
!> (4)     | I - UV* | / ( n ulp )        ZUNGTR( UPLO='L', ... )
!>
!> (5-8)   Igual que 1-4, pero para ZHPTRD y ZUPGTR.
!>
!> (9)     | S - Z D Z* | / ( |S| n ulp ) ZSTEQR('V',...)
!>
!> (10)    | I - ZZ* | / ( n ulp )        ZSTEQR('V',...)
!>
!> (11)    | D1 - D2 | / ( |D1| ulp )        ZSTEQR('N',...)
!>
!> (12)    | D1 - D3 | / ( |D1| ulp )        DSTERF
!>
!> (13)    0 si los valores propios verdaderos (calculados por conteo de Sturm)
!>         de S están dentro de THRESH de
!>         los de D1.  2*THRESH si no lo están.  (Probado usando
!>         DSTECH)
!>
!> Para S definida positiva,
!>
!> (14)    | S - Z4 D4 Z4* | / ( |S| n ulp ) ZPTEQR('V',...)
!>
!> (15)    | I - Z4 Z4* | / ( n ulp )        ZPTEQR('V',...)
!>
!> (16)    | D4 - D5 | / ( 100 |D4| ulp )       ZPTEQR('N',...)
!>
!> Cuando S es también diagonalmente dominante por el factor gamma < 1,
!>
!> (17)    max | D4(i) - WR(i) | / ( |D4(i)| omega ) ,
!>          i
!>         omega = 2 (2n-1) ULP (1 + 8 gamma**2) / (1 - gamma)**4
!>                                              DSTEBZ( 'A', 'E', ...)
!>
!> (18)    | WA1 - D3 | / ( |D3| ulp )          DSTEBZ( 'A', 'E', ...)
!>
!> (19)    ( max { min | WA2(i)-WA3(j) | } +
!>            i     j
!>           max { min | WA3(i)-WA2(j) | } ) / ( |D3| ulp )
!>            i     j
!>                                              DSTEBZ( 'I', 'E', ...)
!>
!> (20)    | S - Y WA1 Y* | / ( |S| n ulp )  DSTEBZ, ZSTEIN
!>
!> (21)    | I - Y Y* | / ( n ulp )          DSTEBZ, ZSTEIN
!>
!> (22)    | S - Z D Z* | / ( |S| n ulp )    ZSTEDC('I')
!>
!> (23)    | I - ZZ* | / ( n ulp )           ZSTEDC('I')
!>
!> (24)    | S - Z D Z* | / ( |S| n ulp )    ZSTEDC('V')
!>
!> (25)    | I - ZZ* | / ( n ulp )           ZSTEDC('V')
!>
!> (26)    | D1 - D2 | / ( |D1| ulp )           ZSTEDC('V') y
!>                                              ZSTEDC('N')
!>
!> La prueba 27 está deshabilitada actualmente porque ZSTEMR no
!> garantiza alta precisión relativa.
!>
!> (27)    max | D6(i) - WR(i) | / ( |D6(i)| omega ) ,
!>          i
!>         omega = 2 (2n-1) ULP (1 + 8 gamma**2) / (1 - gamma)**4
!>                                              ZSTEMR('V', 'A')
!>
!> (28)    max | D6(i) - WR(i) | / ( |D6(i)| omega ) ,
!>          i
!>         omega = 2 (2n-1) ULP (1 + 8 gamma**2) / (1 - gamma)**4
!>                                              ZSTEMR('V', 'I')
!>
!> Las pruebas 29 a 34 están deshabilitadas actualmente porque ZSTEMR
!> no maneja solicitudes de espectro parcial.
!>
!> (29)    | S - Z D Z* | / ( |S| n ulp )    ZSTEMR('V', 'I')
!>
!> (30)
| I - ZZ* | / ( n ulp ) ZSTEMR('V', 'I') !> !> (31) ( max { min | WA2(i)-WA3(j) | } + !> i j !> max { min | WA3(i)-WA2(j) | } ) / ( |D3| ulp ) !> i j !> ZSTEMR('N', 'I') vs. CSTEMR('V', 'I') !> !> (32) | S - Z D Z* | / ( |S| n ulp ) ZSTEMR('V', 'V') !> !> (33) | I - ZZ* | / ( n ulp ) ZSTEMR('V', 'V') !> !> (34) ( max { min | WA2(i)-WA3(j) | } + !> i j !> max { min | WA3(i)-WA2(j) | } ) / ( |D3| ulp ) !> i j !> ZSTEMR('N', 'V') vs. CSTEMR('V', 'V') !> !> (35) | S - Z D Z* | / ( |S| n ulp ) ZSTEMR('V', 'A') !> !> (36) | I - ZZ* | / ( n ulp ) ZSTEMR('V', 'A') !> !> (37) ( max { min | WA2(i)-WA3(j) | } + !> i j !> max { min | WA3(i)-WA2(j) | } ) / ( |D3| ulp ) !> i j !> ZSTEMR('N', 'A') vs. CSTEMR('V', 'A') !> !> Los se especifican mediante un array NN(1:NSIZES); el valor de !> cada elemento NN(j) especifica un tamaño. !> Los se especifican mediante un array lógico DOTYPE( 1:NTYPES ); !> si DOTYPE(j) es .TRUE., entonces se generará la matriz de tipo . !> Actualmente, la lista de tipos posibles es: !> !> (1) La matriz cero. !> (2) La matriz identidad. !> !> (3) Una matriz diagonal con entradas espaciadas uniformemente !> 1, ..., ULP y signos aleatorios. !> (ULP = (primer número mayor que 1) - 1 ) !> (4) Una matriz diagonal con entradas espaciadas geométricamente !> 1, ..., ULP y signos aleatorios. !> (5) Una matriz diagonal con entradas 1, ULP, ..., ULP !> y signos aleatorios. !> !> (6) Igual que (4), pero multiplicado por la raíz cuadrada del !> umbral de desbordamiento. !> (7) Igual que (4), pero multiplicado por la raíz cuadrada del !> umbral de subdesbordamiento. !> !> (8) Una matriz de la forma U* D U, donde U es unitaria y !> D tiene entradas espaciadas uniformemente 1, ..., ULP con signos aleatorios !> en la diagonal. !> !> (9) Una matriz de la forma U* D U, donde U es unitaria y !> D tiene entradas espaciadas geométricamente 1, ..., ULP con signos aleatorios !> en la diagonal. !> !> (10) Una matriz de la forma U* D U, donde U es unitaria y !> D tiene entradas 1, ULP,..., ULP con signos aleatorios !> en la diagonal. !> !> (11) Igual que (8), pero multiplicado por la raíz cuadrada del !> umbral de desbordamiento. !> (12) Igual que (8), pero multiplicado por la raíz cuadrada del !> umbral de subdesbordamiento. !> !> (13) Matriz Hermitiana con entradas aleatorias elegidas de (-1,1). !> (14) Igual que (13), pero multiplicado por la raíz cuadrada del !> umbral de desbordamiento. !> (15) Igual que (13), pero multiplicado por la raíz cuadrada del !> umbral de subdesbordamiento. !> (16) Igual que (8), pero los elementos de la diagonal son todos positivos. !> (17) Igual que (9), pero los elementos de la diagonal son todos positivos. !> (18) Igual que (10), pero los elementos de la diagonal son todos positivos. !> (19) Igual que (16), pero multiplicado por la raíz cuadrada del !> umbral de desbordamiento. !> (20) Igual que (16), pero multiplicado por la raíz cuadrada del !> umbral de subdesbordamiento. !> (21) Una matriz tridiagonal, diagonalmente dominante, con entradas diagonales !> espaciadas geométricamente 1, ..., ULP. !>

Parámetros

NSIZES 
!>          NSIZES es INTEGER
!>          El número de tamaños de matrices a utilizar. Si es cero,
!>          ZCHKST no hace nada. Debe ser al menos cero.
!>

NN

!>          NN es un array INTEGER, de dimensión (NSIZES)
!>          Un array que contiene los tamaños a utilizar para las matrices.
!>          Los valores cero se omitirán. Los valores deben ser al menos
!>          cero.
!>

NTYPES

!>          NTYPES es INTEGER
!>          El número de elementos en DOTYPE. Si es cero, ZCHKST
!>          no hace nada. Debe ser al menos cero. Si es MAXTYP+1
!>          y NSIZES es 1, entonces se define un tipo adicional, MAXTYP+1,
!>          que consiste en usar la matriz que esté en A. Esto
!>          sólo es útil si DOTYPE(1:MAXTYP) es .FALSE. y
!>          DOTYPE(MAXTYP+1) es .TRUE. .
!>

DOTYPE

!>          DOTYPE es un array LOGICAL, de dimensión (NTYPES)
!>          Si DOTYPE(j) es .TRUE., entonces para cada tamaño en NN se generará
!>          una matriz de ese tamaño y de tipo j.
!>          Si NTYPES es menor que el número máximo de tipos
!>          definidos (PARAMETER MAXTYP), entonces los tipos NTYPES+1 hasta
!>          MAXTYP no se generarán. Si NTYPES es mayor
!>          que MAXTYP, DOTYPE(MAXTYP+1) hasta DOTYPE(NTYPES)
!>          serán ignorados.
!>

ISEED

!>          ISEED es un array INTEGER, de dimensión (4)
!>          A la entrada, ISEED especifica la semilla del generador de números
!>          aleatorios. Los elementos del array deben estar entre 0 y 4095;
!>          si no, se reducirán módulo 4096. Además, ISEED(4) debe
!>          ser impar. El generador de números aleatorios utiliza una secuencia
!>          congruencial lineal limitada a enteros pequeños, y por lo tanto
!>          debería producir números aleatorios independientes de la máquina. Los
!>          valores de ISEED se modifican a la salida y se pueden usar en la
!>          siguiente llamada a ZCHKST para continuar la misma secuencia de números
!>          aleatorios.
!>

THRESH

!>          THRESH es DOUBLE PRECISION
!>          Una prueba se considerará como  si el error, calculado
!>          como se describe arriba, excede THRESH. Tenga en cuenta que el error
!>          está escalado para ser O(1), por lo que THRESH debería ser un múltiplo
!>          razonablemente pequeño de 1, por ejemplo, 10 o 100. En particular,
!>          no debe depender de la precisión (simple vs. doble)
!>          ni del tamaño de la matriz. Debe ser al menos cero.
!>

NOUNIT

!>          NOUNIT es INTEGER
!>          El número de unidad FORTRAN para imprimir mensajes de error
!!>          (por ejemplo, si una rutina devuelve IINFO distinto de 0).
!>

A

!>          A es un array COMPLEX*16 de
!>                                  dimensión ( LDA , max(NN) )
!>          Se utiliza para almacenar la matriz cuyos valores propios se van a
!>          calcular. A la salida, A contiene la última matriz realmente
!>          utilizada.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal de A. Debe ser
!>          al menos 1 y al menos max( NN ).
!>

AP

!>          AP es un array COMPLEX*16 de
!>                      dimensión( max(NN)*max(NN+1)/2 )
!>          La matriz A almacenada en formato empaquetado.
!>

SD

!>          SD es un array DOUBLE PRECISION de
!>                             dimensión( max(NN) )
!>          La diagonal de la matriz tridiagonal calculada por ZHETRD.
!>          A la salida, SD y SE contienen la forma tridiagonal de la
!>          matriz en A.
!>

SE

!>          SE es un array DOUBLE PRECISION de
!>                             dimensión( max(NN) )
!>          La subdiagonal de la matriz tridiagonal calculada por
!>          ZHETRD. A la salida, SD y SE contienen la forma tridiagonal de
!>          la matriz en A.
!>

D1

!>          D1 es un array DOUBLE PRECISION de
!>                             dimensión( max(NN) )
!>          Los valores propios de A, calculados por ZSTEQR simultáneamente
!>          con Z. A la salida, los valores propios en D1 corresponden a la
!>          matriz en A.
!>

D2

!>          D2 es un array DOUBLE PRECISION de
!>                             dimensión( max(NN) )
!>          Los valores propios de A, calculados por ZSTEQR si Z no se
!>          calcula. A la salida, los valores propios en D2 corresponden a la
!>          matriz en A.
!>

D3

!>          D3 es un array DOUBLE PRECISION de
!>                             dimensión( max(NN) )
!>          Los valores propios de A, calculados por DSTERF. A la salida, los
!>          valores propios en D3 corresponden a la matriz en A.
!>

D4

!>          D4 es un array DOUBLE PRECISION de
!>                             dimensión( max(NN) )
!>          Los valores propios de A, calculados por ZPTEQR(V).
!>          ZPTEQR descompone S como  Z4 D4 Z4*
!>          A la salida, los valores propios en D4 corresponden a la matriz en A.
!>

D5

!>          D5 es un array DOUBLE PRECISION de
!>                             dimensión( max(NN) )
!>          Los valores propios de A, calculados por ZPTEQR(N)
!>          cuando Z no se calcula. A la salida, los
!>          valores propios en D4 corresponden a la matriz en A.
!>

WA1

!>          WA1 es un array DOUBLE PRECISION de
!>                             dimensión( max(NN) )
!>          Todos los valores propios de A, calculados con alta
!>          precisión absoluta, con diferentes opciones de rango.
!>          Calculados por DSTEBZ.
!>

WA2

!>          WA2 es un array DOUBLE PRECISION de
!>                             dimensión( max(NN) )
!>          Valores propios seleccionados de A, calculados con alta
!>          precisión absoluta, con diferentes opciones de rango.
!>          Calculados por DSTEBZ.
!>          Elige valores aleatorios para IL y IU, y solicita los
!>          valores propios del iL-ésimo al iU-ésimo.
!>

WA3

!>          WA3 es un array DOUBLE PRECISION de
!>                             dimensión( max(NN) )
!>          Valores propios seleccionados de A, calculados con alta
!>          precisión absoluta, con diferentes opciones de rango.
!>          Calculados por DSTEBZ.
!>          Determina los valores VL y VU de los valores propios iL-ésimo y iU-ésimo
!>          y solicita todos los valores propios en este rango.
!>

WR

!>          WR es un array DOUBLE PRECISION de
!>                             dimensión( max(NN) )
!>          Todos los valores propios de A, calculados con alta
!>          precisión absoluta, con diferentes opciones.
!>          Calculados por DSTEBZ.
!>

U

!>          U es un array COMPLEX*16 de
!>                             dimensión( LDU, max(NN) ).
!>          La matriz unitaria calculada por ZHETRD + ZUNGTR.
!>

LDU

!>          LDU es INTEGER
!>          La dimensión principal de U, Z y V. Debe ser al menos 1
!>          y al menos max( NN ).
!>

V

!>          V es un array COMPLEX*16 de
!>                             dimensión( LDU, max(NN) ).
!>          Los vectores de Householder calculados por ZHETRD al reducir A a
!>          forma tridiagonal. Los vectores calculados con UPLO='U' están
!>          en el triángulo superior, y los vectores calculados con UPLO='L'
!>          están en el triángulo inferior. (Como se describe en ZHETRD, los
!>          elementos de la sub y superdiagonal no se establecen en 1, aunque el
!>          vector de Householder real tiene un 1 en esa posición. Las
!>          rutinas que usan V, como ZUNGTR, establecen esas entradas a
!>          1 antes de usarlas, y luego las restauran más tarde.)
!>

VP

!>          VP es un array COMPLEX*16 de
!>                      dimensión( max(NN)*max(NN+1)/2 )
!>          La matriz V almacenada en formato empaquetado.
!>

TAU

!>          TAU es un array COMPLEX*16 de
!>                             dimensión( max(NN) )
!>
;          Los factores Householder calculados por ZHETRD para reducir A
!>          a forma tridiagonal.
!>

Z

!>          Z es un array COMPLEX*16 de
!>                             dimensión ( LDU, max(NN) ).
!>          La matriz unitaria de vectores propios calculada por ZSTEQR,
!>          ZPTEQR y ZSTEIN.
!>

WORK

!>          WORK es un array COMPLEX*16 de
!>                      dimensión ( LWORK )
!>

LWORK

!>          LWORK es un INTEGER
!>          El número de entradas en WORK. Debe ser al menos
!>          1 + 4 * Nmax + 2 * Nmax * lg Nmax + 3 * Nmax**2
!>          donde Nmax = max( NN(j), 2 ) y lg = log base 2.
!>

IWORK

!>          IWORK es un array INTEGER,
!>          Espacio de trabajo.
!>

LIWORK

!>          LIWORK es un INTEGER
!>          El número de entradas en IWORK. Debe ser al menos
!>                  6 + 6*Nmax + 5 * Nmax * lg Nmax
!>          donde Nmax = max( NN(j), 2 ) y lg = log base 2.
!>

RWORK

!>          RWORK es un array DOUBLE PRECISION
!>

LRWORK

!>          LRWORK es un INTEGER
!>          El número de entradas en LRWORK (dimensión( ??? )
!>

RESULT

!>          RESULT es un array DOUBLE PRECISION, dimensión (26)
!>          Los valores calculados por las pruebas descritas anteriormente.
!>          Los valores están limitados actualmente a 1/ulp, para evitar
!>          desbordamiento.
!>

INFO

!>          INFO es un INTEGER
!>          Si es 0, entonces todo funcionó correctamente.
!>           -1: NSIZES < 0
!>           -2: Algún NN(j) < 0
!>           -3: NTYPES < 0
!>           -5: THRESH < 0
!>           -9: LDA < 1 o LDA < NMAX, donde NMAX es max( NN(j) ).
!>          -23: LDU < 1 o LDU < NMAX.
!>          -29: LWORK demasiado pequeño.
!>          Si ZLATMR, CLATMS, ZHETRD, ZUNGTR, ZSTEQR, DSTERF,
!>              o ZUNMC2 devuelven un código de error, el
!>              valor absoluto de este se devuelve.
!>
!>-----------------------------------------------------------------------
!>
!>       Algunas Variables y Parámetros Locales:
!>       ---- ----- --------- --- ----------
!>       ZERO, ONE       Reales 0 y 1.
!>       MAXTYP          El número de tipos definidos.
!>       NTEST           El número de pruebas realizadas, o que pueden
!>                       realizarse hasta ahora, para la matriz actual.
!>       NTESTT          El número total de pruebas realizadas hasta ahora.
!>       NBLOCK          Tamaño del bloque devuelto por ENVIR.
!>       NMAX            Valor más grande en NN.
!>       NMATS           El número de matrices generadas hasta ahora.
!>       NERRS           El número de pruebas que han excedido THRESH
!>                       hasta ahora.
!>       COND, IMODE     Valores que se pasarán a los generadores de matrices.
!>       ANORM           Norma de A; pasada a los generadores de matrices.
!>
!>       OVFL, UNFL      Umbrales de desbordamiento y subdesbordamiento.
!>       ULP, ULPINV     Precisión relativa más fina y su inversa.
!>       RTOVFL, RTUNFL  Raíces cuadradas de los dos valores anteriores.
!>               Los siguientes cuatro arrays decodifican JTYPE:
!>       KTYPE(j)        El tipo general (1-10) para el tipo .
!>       KMODE(j)        El valor MODE que se pasará al generador de matrices
