Function/Subroutine Documentation

subroutine zchk3 (integer n, complex*16, dimension(lda,*) a, integer lda, double precision tol, integer nw, character*1 op)

This subroutine is called by the tests which check the
routines.

Arguments

n
(input) INTEGER. The order of the matrix A .
a
(input) COMPLEX*16 array, dimension (lda, n). The matrix A.
lda
(input) INTEGER. The leading dimension of the array A.
tol
(input) DOUBLE PRECISION. The tolerance for judging the number of non-zero elements.
nw
(input) INTEGER. The number of columns of A to check.
op
(input) CHARACTER*1. Specifies the operation:
'U'
Checks the upper triangle.
'L'
Checks the lower triangle.
'B'
Checks both upper and lower triangles.

Author: 

       This subroutine is a translation of ZCHK3 by
       J. Demmel and N. Nichols, Courant Institute, New York University, USA.

Date: 

       September 2012

Acknowledgements: 

       This version has been modified to incorporate the following warnings:
       - If the number of non-zero elements is 0, and the input matrix is not
         all zeros, then the subroutine will return an error.
       - If the number of non-zero elements is greater than zero, and the input
         matrix is all zeros, then the subroutine will return an error.

Further details: 

       The routine calls ZTRAN3 to compute the number of non-zero elements
       in the upper triangle of the matrix A. It then compares this number
       with the input tolerance `tol`. If the number of non-zero elements is
       less than `tol`, an error is reported.

Contributors: 

       September 2012,
       Combined LAPACK routines.
