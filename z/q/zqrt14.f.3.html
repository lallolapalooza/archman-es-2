double precision function zqrt14 (trans, m, n, nrhs, a, lda, x, ldx, work, lwork)

Documentación de Función/Subrutina

double precision function zqrt14 (character trans, integer m, integer n, integer nrhs, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( ldx, * ) x, integer ldx, complex*16, dimension( lwork ) work, integer lwork)

ZQRT14

Propósito:

!>
!> ZQRT14 comprueba si X está en el espacio de filas de A o A'. Lo hace
!> escalando tanto X como A para que sus normas estén en el rango
!> [sqrt(eps), 1/sqrt(eps)], luego computando una factorización QR de [A,X]
!> (si TRANS = 'C') o una factorización LQ de [A',X]' (si TRANS = 'N'),
!> y devolviendo la norma del triángulo final, escalada por
!> MAX(M,N,NRHS)*eps.
!>

Parámetros

TRANS 
!>          TRANS es CHARACTER*1
!>          = 'N':  Sin transpuesta, comprobar si X está en el espacio de filas de A
!>          = 'C':  Transpuesta conjugada, comprobar si X está en el espacio de filas de A'.
!>

M

!>          M es INTEGER
!>          El número de filas de la matriz A.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz A.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de lados derechos, es decir, el número de columnas
!>          de X.
!>

A

!>          A es un array COMPLEX*16, dimensión (LDA,N)
!>          La matriz A de M por N.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.
!>

X

!>          X es un array COMPLEX*16, dimensión (LDX,NRHS)
!>          Si TRANS = 'N', la matriz X de N por NRHS.
!>          Si TRANS = 'C', la matriz X de M por NRHS.
!>

LDX

!>          LDX es INTEGER
!>          La dimensión principal del array X.
!>

WORK

!>          WORK es un array COMPLEX*16, dimensión (LWORK)
!>

LWORK

!>          LWORK es INTEGER
!>          longitud del array de espacio de trabajo requerido
!>          Si TRANS = 'N', LWORK >= (M+NRHS)*(N+2);
!>          si TRANS = 'C', LWORK >= (N+NRHS)*(M+2).
!>
