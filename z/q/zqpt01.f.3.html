Documentación de Función/Subrutina

double precision function zqpt01 (integer m, integer n, integer k, complex*16, dimension( lda, * ) a, complex*16, dimension( lda, * ) af, integer lda, complex*16, dimension( * ) tau, integer, dimension( * ) jpvt, complex*16, dimension( lwork ) work, integer lwork)

ZQPT01

Propósito:

!>
!> ZQPT01 prueba la factorización QR con pivoteo de una matriz A. El
!> array AF contiene la factorización QR (posiblemente parcial) de A, donde
!> el triángulo superior de AF(1:k,1:k) es un factor triangular parcial,
!> las entradas debajo de la diagonal en las primeras k columnas son los
!> vectores de Householder, y el resto de AF contiene una matriz parcialmente actualizada.
!>
!> Esta función devuelve ||A*P - Q*R|| / ( ||norma(A)||*eps*max(M,N) )
!>

Parámetros

M 
!>          M es ENTERO
!>          El número de filas de las matrices A y AF.
!>

N

!>          N es ENTERO
!>          El número de columnas de las matrices A y AF.
!>

K

!>          K es ENTERO
!>          El número de columnas de AF que han sido reducidas
!>          a forma triangular superior.
!>

A

!>          A es un array COMPLEX*16, dimensión (LDA, N)
!>          La matriz original A.
!>

AF

!>          AF es un array COMPLEX*16, dimensión (LDA,N)
!>          La salida (posiblemente parcial) de ZGEQPF. El triángulo superior
!>          de AF(1:k,1:k) es un factor triangular parcial, las entradas
!>          debajo de la diagonal en las primeras k columnas son los vectores de
!>          Householder, y el resto de AF contiene una matriz parcialmente actualizada.
!>

LDA

!>          LDA es ENTERO
!>          La dimensión principal de los arrays A y AF.
!>

TAU

!>          TAU es un array COMPLEX*16, dimensión (K)
!>          Detalles de las transformaciones de Householder devueltas por
!>          ZGEQPF.
!>

JPVT

!>          JPVT es un array ENTERO, dimensión (N)
!>          Información de pivote devuelta por ZGEQPF.
!>

WORK

!>          WORK es un array COMPLEX*16, dimensión (LWORK)
!>

LWORK

!>          LWORK es ENTERO
!>          La longitud del array WORK. LWORK >= M*N+N.
!>
