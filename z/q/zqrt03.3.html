Documentación de Función/Subrutina

subroutine zqrt03 (integer m, integer n, integer k, complex*16, dimension( lda, * ) af, complex*16, dimension( lda, * ) c, complex*16, dimension( lda, * ) cc, complex*16, dimension( lda, * ) q, integer lda, complex*16, dimension( * ) tau, complex*16, dimension( lwork ) work, integer lwork, double precision, dimension( * ) rwork, double precision, dimension( * ) result)

ZQRT03

Propósito:

!>
!> ZQRT03 prueba ZUNMQR, que calcula Q*C, Q'*C, C*Q o C*Q'.
!>
!> ZQRT03 compara los resultados de una llamada a ZUNMQR con los resultados de
!> formar Q explícitamente mediante una llamada a ZUNGQR y luego realizar la
!> multiplicación de matrices mediante una llamada a ZGEMM.
!>

Parámetros

M 
!>          M es INTEGER
!>          El orden de la matriz ortogonal Q.  M >= 0.
!>

N

!>          N es INTEGER
!>          El número de filas o columnas de la matriz C; C es m-por-n si
!>          Q se aplica desde la izquierda, o n-por-m si Q se aplica desde
!>          la derecha.  N >= 0.
!>

K

!>          K es INTEGER
!>          El número de reflectores elementales cuyo producto define la
!>          matriz ortogonal Q.  M >= K >= 0.
!>

AF

!>          AF es COMPLEX*16 array, dimension (LDA,N)
!>          Detalles de la factorización QR de una matriz m-por-n, como
!>          devuelto por ZGEQRF. Ver ZGEQRF para más detalles.
!>

C

!>          C es COMPLEX*16 array, dimension (LDA,N)
!>

CC

!>          CC es COMPLEX*16 array, dimension (LDA,N)
!>

Q

!>          Q es COMPLEX*16 array, dimension (LDA,M)
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal de los arrays AF, C, CC y Q.
!>

TAU

!>          TAU es COMPLEX*16 array, dimension (min(M,N))
!>          Los factores escalares de los reflectores elementales
!>          correspondientes a la factorización QR en AF.
!>

WORK

!>          WORK es COMPLEX*16 array, dimension (LWORK)
!>

LWORK

!>          LWORK es INTEGER
!>          La longitud de WORK.  LWORK debe ser al menos M, y debería ser
!>          M*NB, donde NB es el tamaño del bloque para este entorno.
!>

RWORK

!>          RWORK es DOUBLE PRECISION array, dimension (M)
!>

RESULT

!>          RESULT es DOUBLE PRECISION array, dimension (4)
!>          Las ratios de prueba comparan dos técnicas para multiplicar una
!>          matriz aleatoria C por una matriz ortogonal m-por-m Q.
!>          RESULT(1) = norm( Q*C - Q*C )  / ( M * norm(C) * EPS )
!>          RESULT(2) = norm( C*Q - C*Q )  / ( M * norm(C) * EPS )
!>          RESULT(3) = norm( Q'*C - Q'*C )/ ( M * norm(C) * EPS )
!>          RESULT(4) = norm( C*Q' - C*Q' )/ ( M * norm(C) * EPS )
!>
