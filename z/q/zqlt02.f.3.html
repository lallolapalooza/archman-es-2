DOCUMENTACIÓN DE LA FUNCIÓN/SUBRUTINA

subrutina zqlt02 (integer m, integer n, integer k, complex*16, dimension( lda, * ) a, complex*16, dimension( lda, * ) af, complex*16, dimension( lda, * ) q, complex*16, dimension( lda, * ) l, integer lda, complex*16, dimension( * ) tau, complex*16, dimension( lwork ) work, integer lwork, double precision, dimension( * ) rwork, double precision, dimension( * ) result)

ZQLT02

Propósito:

!>
!> ZQLT02 prueba ZUNGQL, que genera una matriz m-por-n Q con
!> columnas ortonormales que se define como el producto de k
!> reflectores elementales.
!>
!> Dada la factorización QL de una matriz A de m-por-n, ZQLT02 genera
!> la matriz ortogonal Q definida por la factorización de las últimas k
!> columnas de A; compara L(m-n+1:m,n-k+1:n) con
!> Q(1:m,m-n+1:m)'*A(1:m,n-k+1:n), y comprueba que las columnas de Q
!> son ortonormales.
!>

Parámetros

M 
!>          M es INTEGER
!>          El número de filas de la matriz Q a generar.  M >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz Q a generar.
!>          M >= N >= 0.
!>

K

!>          K es INTEGER
!>          El número de reflectores elementales cuyo producto define la
!>          matriz Q. N >= K >= 0.
!>

A

!>          A es array COMPLEX*16, dimension (LDA,N)
!>          La matriz m-por-n A que fue factorizada por ZQLT01.
!>

AF

!>          AF es array COMPLEX*16, dimension (LDA,N)
!>          Detalles de la factorización QL de A, tal como se devuelve
!>          por ZGEQLF. Ver ZGEQLF para más detalles.
!>

Q

!>          Q es array COMPLEX*16, dimension (LDA,N)
!>

L

!>          L es array COMPLEX*16, dimension (LDA,N)
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal de los arrays A, AF, Q y L. LDA >= M.
!>

TAU

!>          TAU es array COMPLEX*16, dimension (N)
!>          Los factores escalares de los reflectores elementales
!>          correspondientes a la factorización QL en AF.
!>

WORK

!>          WORK es array COMPLEX*16, dimension (LWORK)
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK.
!>

RWORK

!>          RWORK es array DOUBLE PRECISION, dimension (M)
!>

RESULT

!>          RESULT es array DOUBLE PRECISION, dimension (2)
!>          Las razones de prueba:
!>          RESULT(1) = norm( L - Q'*A ) / ( M * norm(A) * EPS )
!>          RESULT(2) = norm( I - Q'*Q ) / ( M * EPS )
!>
