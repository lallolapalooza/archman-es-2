Documentación de la función/subrutina

double precision function zqrt17 (character trans, integer iresid, integer m, integer n, integer nrhs, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( ldx, * ) x, integer ldx, complex*16, dimension( ldb, * ) b, integer ldb, complex*16, dimension( ldb, * ) c, complex*16, dimension( lwork ) work, integer lwork)

ZQRT17

Propósito:

!>
!> ZQRT17 calcula la razón
!>
!>    norm(R**H * op(A)) / ( norm(A) * alpha * max(M,N,NRHS) * EPS ),
!>
!> donde R = B - op(A)*X, op(A) es A o A**H, dependiendo de TRANS, EPS
!> es la epsilon de máquina, y
!>
!>    alpha = norm(B) si IRESID = 1 (problema de residuo cero)
!>    alpha = norm(R) si IRESID = 2 (en caso contrario).
!>
!> La norma utilizada es la norma 1.
!>

Parámetros

TRANS 
!>          TRANS es CHARACTER*1
!>          Especifica si se usa o no la transpuesta de A.
!>          = 'N':  Sin transpuesta, op(A) = A.
!>          = 'C':  Transpuesta conjugada, op(A) = A**H.
!>

IRESID

!>          IRESID es INTEGER
!>          IRESID = 1 indica problema de residuo cero.
!>          IRESID = 2 indica residuo no nulo.
!>

M

!>          M es INTEGER
!>          El número de filas de la matriz A.
!>          Si TRANS = 'N', el número de filas de la matriz B.
!>          Si TRANS = 'C', el número de filas de la matriz X.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz A.
!>          Si TRANS = 'N', el número de filas de la matriz X.
!>          Si TRANS = 'C', el número de filas de la matriz B.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de columnas de las matrices X y B.
!>

A

!>          A es COMPLEX*16 array, dimension (LDA,N)
!>          La matriz A de m-por-n.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A. LDA >= M.
!>

X

!>          X es COMPLEX*16 array, dimension (LDX,NRHS)
!>          Si TRANS = 'N', la matriz X de n-por-nrhs.
!>          Si TRANS = 'C', la matriz X de m-por-nrhs.
!>

LDX

!>          LDX es INTEGER
!>          La dimensión principal del array X.
!>          Si TRANS = 'N', LDX >= N.
!>          Si TRANS = 'C', LDX >= M.
!>

B

!>          B es COMPLEX*16 array, dimension (LDB,NRHS)
!>          Si TRANS = 'N', la matriz B de m-por-nrhs.
!>          Si TRANS = 'C', la matriz B de n-por-nrhs.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B.
!>          Si TRANS = 'N', LDB >= M.
!>          Si TRANS = 'C', LDB >= N.
!>

C

!>          C es COMPLEX*16 array, dimension (LDB,NRHS)
!>

WORK

!>          WORK es COMPLEX*16 array, dimension (LWORK)
!>

LWORK

!>          LWORK es INTEGER
!>          La longitud del array WORK. LWORK >= NRHS*(M+N).
!>
