DOCUMENTACIÓN DE FUNCIÓN/SUBRUTINA

subroutine zppcon (character uplo, integer n, complex*16, dimension( * ) ap, double precision anorm, double precision rcond, complex*16, dimension( * ) work, double precision, dimension( * ) rwork, integer info)

ZPPCON

Propósito:

!>
!> ZPPCON estima la recíproca del número de condición (en la norma 1)
!> de una matriz compleja Hermitiana positiva definida empaquetada,
!> utilizando la factorización de Cholesky A = U**H*U o A = L*L**H
!> calculada por ZPPTRF.
!>
!> Se obtiene una estimación para norm(inv(A)), y la recíproca del
!> número de condición se calcula como RCOND = 1 / (ANORM * norm(inv(A))).
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          = 'U':  El triángulo superior de A está almacenado;
!>          = 'L':  El triángulo inferior de A está almacenado.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

AP

!>          AP es un array COMPLEX*16, dimensión (N*(N+1)/2)
!>          El factor triangular U o L de la factorización de Cholesky
!>          A = U**H*U o A = L*L**H, empaquetado por columnas en un array
!>          lineal. La j-ésima columna de U o L se almacena en el array AP
!>          de la siguiente manera:
!>          si UPLO = 'U', AP(i + (j-1)*j/2) = U(i,j) para 1<=i<=j;
!>          si UPLO = 'L', AP(i + (j-1)*(2n-j)/2) = L(i,j) para j<=i<=n.
!>

ANORM

!>          ANORM es DOUBLE PRECISION
!>          La norma 1 (o norma infinito) de la matriz Hermitiana A.
!>

RCOND

!>          RCOND es DOUBLE PRECISION
!>          La recíproca del número de condición de la matriz A,
!>          calculada como RCOND = 1/(ANORM * AINVNM), donde AINVNM es
!>          una estimación de la norma 1 de inv(A) calculada en esta rutina.
!>

WORK

!>          WORK es un array COMPLEX*16, dimensión (2*N)
!>

RWORK

!>          RWORK es un array DOUBLE PRECISION, dimensión (N)
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>
