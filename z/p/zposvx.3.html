ZPOSVX calcula la solución al sistema de ecuaciones lineales A * X = B para matrices PO

Propósito:

!>
!> ZPOSVX utiliza la factorización de Cholesky A = U**H*U o A = L*L**H para
!> calcular la solución a un sistema complejo de ecuaciones lineales
!>    A * X = B,
!> donde A es una matriz Hermitiana positiva definida de N por N y X y B
!> son matrices de N por NRHS.
!>
!> También se proporcionan límites de error en la solución y una estimación
!> de la condición.
!>

Descripción:

!>
!> Se realizan los siguientes pasos:
!>
!> 1. Si FACT = 'E', se calculan factores de escala reales para equilibrar
!>    el sistema:
!>       diag(S) * A * diag(S) * inv(diag(S)) * X = diag(S) * B
!>    Si el sistema se equilibrará o no depende de la escala de la matriz A,
!>    pero si se usa el equilibrado, A se sobrescribe con diag(S)*A*diag(S)
!>    y B con diag(S)*B.
!>
!> 2. Si FACT = 'N' o 'E', se utiliza la descomposición de Cholesky para
!>    factorizar la matriz A (después del equilibrado si FACT = 'E') como
!>       A = U**H* U,  si UPLO = 'U', o
!>       A = L * L**H,  si UPLO = 'L',
!>    donde U es una matriz triangular superior y L es una matriz triangular
!>    inferior.
!>
!> 3. Si el menor principal principal de orden i no es positivo,
!>    entonces la rutina retorna con INFO = i. De lo contrario, la forma
!>    factorizada de A se utiliza para estimar el número de condición de
!>    la matriz A. Si la recíproca del número de condición es menor que la
!>    precisión de la máquina, se devuelve INFO = N+1 como una advertencia,
!>    pero la rutina aún continúa para resolver X y calcular los límites
!>    de error como se describe a continuación.
!>
!> 4. El sistema de ecuaciones se resuelve para X utilizando la forma
!>    factorizada de A.
!>
!> 5. Se aplica refinamiento iterativo para mejorar la solución calculada
!>    y calcular los límites de error y las estimaciones de error hacia atrás
!>    para ella.
!>
!> 6. Si se utilizó el equilibrado, la matriz X se premultiplica por
!>    diag(S) para que resuelva el sistema original antes
!>    del equilibrado.
!>

Parámetros

FACT 
!>          FACT es CHARACTER*1
!>          Especifica si la forma factorizada de la matriz A se proporciona
!>          en la entrada, y si no, si la matriz A debe equilibrarse antes de
!>          ser factorizada.
!>          = 'F':  En la entrada, AF contiene la forma factorizada de A.
!>                  Si EQUED = 'Y', la matriz A ha sido equilibrada
!>                  con factores de escala dados por S. A y AF no se
!>                  modificarán.
!>          = 'N':  La matriz A se copiará en AF y se factorizará.
!>          = 'E':  La matriz A se equilibrará si es necesario, luego
!>                  se copiará en AF y se factorizará.
!>

UPLO

!>          UPLO es CHARACTER*1
!>          = 'U':  Se almacena el triángulo superior de A;
!>          = 'L':  Se almacena el triángulo inferior de A.
!>

N

!>          N es INTEGER
!>          El número de ecuaciones lineales, es decir, el orden de
!>          la matriz A.  N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de lados derechos, es decir, el número de columnas
!>          de las matrices B y X.  NRHS >= 0.
!>

A

!>          A es una matriz COMPLEX*16, dimensión (LDA,N)
!>          En la entrada, la matriz Hermitiana A, excepto si FACT = 'F' y
!>          EQUED = 'Y', entonces A debe contener la matriz equilibrada
!>          diag(S)*A*diag(S). Si UPLO = 'U', la parte superior
!>          N-por-N de A contiene la parte triangular superior de la matriz A,
!>          y la parte estrictamente triangular inferior de A no se referencia.
!>          Si UPLO = 'L', la parte inferior N-por-N de A contiene la parte
!>          triangular inferior de la matriz A, y la parte estrictamente
!>          triangular superior de A no se referencia. A no se modifica si
!>          FACT = 'F' o 'N', o si FACT = 'E' y EQUED = 'N' en la salida.
!>
!>          En la salida, si FACT = 'E' y EQUED = 'Y', A se sobrescribe con
!>          diag(S)*A*diag(S).
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal de la matriz A.  LDA >= max(1,N).
!>

AF

!>          AF es una matriz COMPLEX*16, dimensión (LDAF,N)
!>          Si FACT = 'F', entonces AF es un argumento de entrada y en la entrada
!>          contiene el factor triangular U o L de la factorización de Cholesky
!>          A = U**H *U o A = L*L**H, en el mismo formato de almacenamiento
!>          que A. Si EQUED .ne. 'N', entonces AF es la forma factorizada
!>          de la matriz equilibrada diag(S)*A*diag(S).
!>
!>          Si FACT = 'N', entonces AF es un argumento de salida y en la salida
!>          devuelve el factor triangular U o L de la factorización de Cholesky
!>          A = U**H *U o A = L*L**H de la matriz original A.

!>          Si FACT = 'E', entonces AF es un argumento de salida y en la salida

!>          A = U**H *U o A = L*L**H de la matriz equilibrada A (ver la
!>          descripción de A para la forma de la matriz equilibrada).
!>

LDAF

!>          LDAF es INTEGER
!>          La dimensión principal de la matriz AF.  LDAF >= max(1,N).

EQUED

!>          EQUED es CHARACTER*1
!>          Especifica la forma de equilibrado que se realizó.

S

B

Function/Subroutine Documentation

ZPOSVX solves a system of linear equations A*X = B where A is a symmetric positive definite band matrix, and B and X are general band matrices.

The routine first equilibrates the system if indicated by the input parameter EQUED. Then, it factorizes the matrix A.

Finally, ZPOSVX computes the solution X and estimates the forward and backward error bounds in the solution.

The factorization is computed by calling ZPBTRF. The solution is computed by calling ZPBTFS.

Rethinking the problem statement:

The description of EQBDSC and X seem to suggest that these are related to general triangular systems, not band systems.

If EQUED = 'Y', then A and B are modified on exit, and the solution to the equilibrated system is inv(diag(S))*X.

LDX

!>          LDX is INTEGER
!>          The leading dimension of the array X. LDX >= max(1,N).

RCOND

!>          RCOND is DOUBLE PRECISION
!>          The estimate of the reciprocal condition number of the matrix
!>          A after equilibration (if done). If RCOND is less than the
!>          machine precision (in particular, if RCOND = 0), the matrix
!>          is singular to working precision. This condition is
!>          indicated by a return code of INFO > 0.

FERR

!>          FERR is DOUBLE PRECISION array, dimension (NRHS)
!>          The estimated forward error bound for each solution vector
!>          X(j) (the j-th column of the solution matrix X).
!>          If XTRUE is the true solution corresponding to X(j), FERR(j)
!>          is an estimated upper bound for the magnitude of the largest
!>          element in (X(j) - XTRUE) divided by the magnitude of the
!>          largest element in X(j). The estimate is as reliable as
!>          the estimate for RCOND, and is almost always a slight
!>          overestimate of the true error.

BERR

!>          BERR is DOUBLE PRECISION array, dimension (NRHS)
!>          The componentwise relative backward error of each solution
!>          vector X(j) (i.e., the smallest relative change in
!>          any element of A or B that makes X(j) an exact solution).

!>          RWORK is DOUBLE PRECISION array, dimension (N)
