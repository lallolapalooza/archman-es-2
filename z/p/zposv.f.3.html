Documentación de función/subrutina

subrutina zposv (character uplo, integer n, integer nrhs, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( ldb, * ) b, integer ldb, integer info)

ZPOSV calcula la solución al sistema de ecuaciones lineales A * X = B para matrices Hermitianas positivas definidas

Propósito:

!>
!> ZPOSV calcula la solución a un sistema de ecuaciones lineales complejas
!>    A * X = B,
!> donde A es una matriz Hermitiana positiva definida de N x N y X y B
!> son matrices de N x NRHS.
!>
!> Se utiliza la descomposición de Cholesky para factorizar A como
!>    A = U**H* U,  si UPLO = 'U', o
!>    A = L * L**H,  si UPLO = 'L',
!> donde U es una matriz triangular superior y L es una matriz triangular
!> inferior.  La forma factorizada de A se utiliza luego para resolver el sistema de
!> ecuaciones A * X = B.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          = 'U':  La parte triangular superior de A está almacenada;
!>          = 'L':  La parte triangular inferior de A está almacenada.
!>

N

!>          N es INTEGER
!>          El número de ecuaciones lineales, es decir, el orden de
!>          la matriz A.  N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de lados derechos, es decir, el número de columnas
!>          de la matriz B.  NRHS >= 0.
!>

A

!>          A es un array COMPLEX*16, dimensión (LDA,N)
!>          En la entrada, la matriz Hermitiana A.  Si UPLO = 'U', la parte
!>          superior triangular N x N líder de A contiene la parte triangular
!>          superior de la matriz A, y la parte triangular estrictamente inferior
!>          de A no se referencia. Si UPLO = 'L', la parte triangular
!>          inferior N x N líder de A contiene la parte triangular
!>          inferior de la matriz A, y la parte triangular estrictamente superior
!>          de A no se referencia.
!>
!>          En la salida, si INFO = 0, el factor U o L de la factorización de Cholesky
!!>          A = U**H *U o A = L*L**H.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión líder del array A.  LDA >= max(1,N).
!>

B

!>          B es un array COMPLEX*16, dimensión (LDB,NRHS)
!>          En la entrada, la matriz del lado derecho B de N x NRHS.
!>          En la salida, si INFO = 0, la matriz solución X de N x NRHS.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión líder del array B.  LDB >= max(1,N).
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>          > 0:  si INFO = i, el menor principal de orden i
!>                de A no es positivo, por lo que la factorización no pudo
!>                completarse y la solución no se ha calculado.
!>
