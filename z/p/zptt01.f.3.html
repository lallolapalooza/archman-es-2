Documentación de función/subrutina

subrutina zptt01 (integer n, double precision, dimension( * ) d, complex*16, dimension( * ) e, double precision, dimension( * ) df, complex*16, dimension( * ) ef, complex*16, dimension( * ) work, double precision resid)

ZPTT01

Propósito:

!>
!> ZPTT01 reconstruye una matriz tridiagonal A a partir de su
!> factorización L*D*L' y calcula el residuo
!>    norm(L*D*L' - A) / ( n * norm(A) * EPS ),
!> donde EPS es la epsilon de la máquina.
!>

Parámetros

N 
!>          N es ENTERO
!>          El orden de la matriz A.
!>

D

!>          D es un array de DOBLE PRECISION, dimensión (N)
!>          Los n elementos diagonales de la matriz tridiagonal A.
!>

E

!>          E es un array de COMPLEX*16, dimensión (N-1)
!>          Los (n-1) elementos subdiagonales de la matriz tridiagonal A.
!>

DF

!>          DF es un array de DOBLE PRECISION, dimensión (N)
!>          Los n elementos diagonales del factor L de la factorización L*D*L'
!>          de A.
!>

EF

!>          EF es un array de COMPLEX*16, dimensión (N-1)
!>          Los (n-1) elementos subdiagonales del factor L de la
!>          factorización L*D*L' de A.
!>

WORK

!>          WORK es un array de COMPLEX*16, dimensión (2*N)
!>

RESID

!>          RESID es DOBLE PRECISION
!>          norm(L*D*L' - A) / (n * norm(A) * EPS)
!>
