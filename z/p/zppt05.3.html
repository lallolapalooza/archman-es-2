Documentación de Función/Subrutina

subrutina zppt05 (character uplo, integer n, integer nrhs, complex*16, dimension( * ) ap, complex*16, dimension( ldb, * ) b, integer ldb, complex*16, dimension( ldx, * ) x, integer ldx, complex*16, dimension( ldxact, * ) xact, integer ldxact, double precision, dimension( * ) ferr, double precision, dimension( * ) berr, double precision, dimension( * ) reslts)

ZPPT05

Propósito:

!>
!> ZPPT05 prueba los límites de error del refinamiento iterativo para la
!> solución calculada de un sistema de ecuaciones A*X = B, donde A es una
!> matriz Hermitiana en formato de almacenamiento empaquetado.
!>
!> RESLTS(1) = prueba del límite de error
!>           = norm(X - XACT) / ( norm(X) * FERR )
!>
!> Se devuelve un valor grande si esta proporción no es menor que uno.
!>
!> RESLTS(2) = residuo de la rutina de refinamiento iterativo
!>           = el máximo de BERR / ( (n+1)*EPS + (*) ), donde
!>             (*) = (n+1)*UNFL / (min_i (abs(A)*abs(X) +abs(b))_i )
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          Especifica si la parte triangular superior o inferior de la
!>          matriz Hermitiana A está almacenada.
!>          = 'U':  Triangular superior
!>          = 'L':  Triangular inferior
!>

N

!>          N es INTEGER
!>          El número de filas de las matrices X, B y XACT, y el
!>          orden de la matriz A.  N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de columnas de las matrices X, B y XACT.
!>          NRHS >= 0.
!>

AP

!>          AP es una matriz COMPLEX*16, dimensión (N*(N+1)/2)
!>          La parte triangular superior o inferior de la matriz Hermitiana A,
!>          empaquetada por columnas en un array lineal. La j-ésima columna
!>          de A se almacena en el array AP de la siguiente manera:
!>          si UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) para 1<=i<=j;
!>          si UPLO = 'L', AP(i + (j-1)*(2n-j)/2) = A(i,j) para j<=i<=n.
!>

B

!>          B es una matriz COMPLEX*16, dimensión (LDB,NRHS)
!>          Los vectores del lado derecho para el sistema de ecuaciones
!>          lineales.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B.  LDB >= max(1,N).
!>

X

!>          X es una matriz COMPLEX*16, dimensión (LDX,NRHS)
!>          Los vectores de solución calculados. Cada vector se almacena como
!>          una columna de la matriz X.
!>

LDX

!>          LDX es INTEGER
!>          La dimensión principal del array X.  LDX >= max(1,N).
!>

XACT

!>          XACT es una matriz COMPLEX*16, dimensión (LDXACT,NRHS)
!>          Los vectores de solución exactos. Cada vector se almacena como
!>          una columna de la matriz XACT.
!>

LDXACT

!>          LDXACT es INTEGER
!>          La dimensión principal del array XACT.  LDXACT >= max(1,N).
!>

FERR

!>          FERR es una matriz DOUBLE PRECISION, dimensión (NRHS)
!>          Los límites de error hacia adelante estimados para cada vector
!>          de solución X.  Si XTRUE es la solución verdadera, FERR acota la
!>          magnitud de la entrada más grande en (X - XTRUE) dividida por la
!>          magnitud de la entrada más grande en X.
!>

BERR

!>          BERR es una matriz DOUBLE PRECISION, dimensión (NRHS)
!>          El error de retroceso relativo componente a componente de cada
!>          vector de solución (es decir, el cambio relativo más pequeño en
!>          cualquier entrada de A o B que haga de X una solución exacta).
!>

RESLTS

!>          RESLTS es una matriz DOUBLE PRECISION, dimensión (2)
!>          El máximo sobre los vectores de solución NRHS de las proporciones:
!>          RESLTS(1) = norm(X - XACT) / ( norm(X) * FERR )
!>          RESLTS(2) = BERR / ( (n+1)*EPS + (*) )
!>
