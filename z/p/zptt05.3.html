Documentación de la función/subrutina

subroutine zptt05 (integer n, integer nrhs, double precision, dimension( * ) d, complex*16, dimension( * ) e, complex*16, dimension( ldb, * ) b, integer ldb, complex*16, dimension( ldx, * ) x, integer ldx, complex*16, dimension( ldxact, * ) xact, integer ldxact, double precision, dimension( * ) ferr, double precision, dimension( * ) berr, double precision, dimension( * ) reslts)

ZPTT05

Propósito:

!>
!> ZPTT05 prueba los límites de error del refinamiento iterativo para la
!> solución calculada de un sistema de ecuaciones A*X = B, donde A es una
!> matriz tridiagonal hermitiana de orden n.
!>
!> RESLTS(1) = prueba del límite de error
!>           = norma(X - XACT) / ( norma(X) * FERR )
!>
!> Se devuelve un valor grande si esta relación no es menor que uno.
!>
!> RESLTS(2) = residuo de la rutina de refinamiento iterativo
!>           = el máximo de BERR / ( NZ*EPS + (*) ), donde
!>             (*) = NZ*UNFL / (min_i (abs(A)*abs(X) +abs(b))_i )
!>             y NZ = número máx. de no ceros en cualquier fila de A, más 1
!>

Parámetros

N 
!>          N es ENTERO
!>          El número de filas de las matrices X, B y XACT, y el
!>          orden de la matriz A.  N >= 0.
!>

NRHS

!>          NRHS es ENTERO
!>          El número de columnas de las matrices X, B y XACT.
!>          NRHS >= 0.
!>

D

!>          D es un array de DOBLE PRECISIÓN, dimensión (N)
!>          Los n elementos diagonales de la matriz tridiagonal A.
!>

E

!>          E es un array de COMPLEJO*16, dimensión (N-1)
!>          Los (n-1) elementos subdiagonales de la matriz tridiagonal A.
!>

B

!>          B es un array de COMPLEJO*16, dimensión (LDB,NRHS)
!>          Los vectores del lado derecho para el sistema de ecuaciones
!>          lineales.
!>

LDB

!>          LDB es ENTERO
!>          La dimensión principal del array B.  LDB >= max(1,N).
!>

X

!>          X es un array de COMPLEJO*16, dimensión (LDX,NRHS)
!>          Los vectores solución calculados. Cada vector se almacena como
!>          una columna de la matriz X.
!>

LDX

!>          LDX es ENTERO
!>          La dimensión principal del array X.  LDX >= max(1,N).
!>

XACT

!>          XACT es un array de COMPLEJO*16, dimensión (LDX,NRHS)
!>          Los vectores solución exactos. Cada vector se almacena como
!>          una columna de la matriz XACT.
!>

LDXACT

!>          LDXACT es ENTERO
!>          La dimensión principal del array XACT.  LDXACT >= max(1,N).
!>

FERR

!>          FERR es un array de DOBLE PRECISIÓN, dimensión (NRHS)
!>          Los límites de error hacia adelante estimados para cada vector
!>          solución X. Si XTRUE es la solución verdadera, FERR limita la
!>          magnitud de la entrada más grande en (X - XTRUE) dividida por
!>          la magnitud de la entrada más grande en X.
!>

BERR

!>          BERR es un array de DOBLE PRECISIÓN, dimensión (NRHS)
!>          El error residual relativo componente a componente de cada
!>          vector solución (es decir, el cambio relativo más pequeño en
!>          cualquier entrada de A o B que haga de X una solución exacta).
!>

RESLTS

!>          RESLTS es un array de DOBLE PRECISIÓN, dimensión (2)
!>          El máximo sobre los vectores solución NRHS de las relaciones:
!>          RESLTS(1) = norma(X - XACT) / ( norma(X) * FERR )
!>          RESLTS(2) = BERR / ( NZ*EPS + (*) )
!>
