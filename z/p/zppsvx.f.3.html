ZPPSVX calcula la solución al sistema de ecuaciones lineales A * X = B para matrices HERMITIANAS

Propósito:

!>
!> ZPPSVX utiliza la factorización de Cholesky A = U**H * U o A = L * L**H para
!> calcular la solución a un sistema complejo de ecuaciones lineales
!>    A * X = B,
!> donde A es una matriz Hermitiana positiva definida de N por N almacenada en
!> formato empaquetado y X y B son matrices de N por NRHS.
!>
!> También se proporcionan cotas de error para la solución y una estimación de la condición.
!>

Descripción:

!>
!> Se realizan los siguientes pasos:
!>
!> 1. Si FACT = 'E', se calculan factores de escala reales para equilibrar
!>    el sistema:
!>       diag(S) * A * diag(S) * inv(diag(S)) * X = diag(S) * B
!>    Si el sistema se equilibrará o no depende de la escala de la matriz A,
!>    pero si se utiliza el equilibrado, A se sobrescribe con diag(S)*A*diag(S)
!>    y B con diag(S)*B.
!>
!> 2. Si FACT = 'N' o 'E', se utiliza la descomposición de Cholesky para
!>    factorizar la matriz A (después del equilibrado si FACT = 'E') como
!>       A = U**H * U ,  si UPLO = 'U', o
!>       A = L * L**H,  si UPLO = 'L',
!>    donde U es una matriz triangular superior, L es una matriz triangular inferior,
!>    y **H indica traspuesta conjugada.
!>
!> 3. Si el menor principal principal de orden i no es positivo,
!>    la rutina devuelve INFO = i. De lo contrario, la forma factorizada
!>    de A se utiliza para estimar el número de condición de la matriz
!>    A. Si la recíproca del número de condición es menor que la precisión
!>    de la máquina, se devuelve INFO = N+1 como advertencia, pero la rutina
!>    continúa resolviendo X y calculando las cotas de error como se describe
!>    a continuación.
!>
!> 4. El sistema de ecuaciones se resuelve para X utilizando la forma factorizada
!>    de A.
!>
!> 5. Se aplica refinamiento iterativo para mejorar la solución calculada
!>    y calcular las cotas de error y las estimaciones de error hacia atrás
!>    para ella.
!>
!> 6. Si se utilizó el equilibrado, la matriz X se premultiplica por
!>    diag(S) para que resuelva el sistema original antes del
!>    equilibrado.
!>

Parámetros

FACT 
!>          FACT es CHARACTER*1
!>          Especifica si la forma factorizada de la matriz A se
!>          proporciona en la entrada, y si no, si la matriz A debe ser
!>          equilibrada antes de ser factorizada.
!>          = 'F':  En la entrada, AFP contiene la forma factorizada de A.
!>                  Si EQUED = 'Y', la matriz A ha sido equilibrada
!>                  con factores de escala dados por S. AP y AFP no
!>                  serán modificados.
!>          = 'N':  La matriz A se copiará a AFP y se factorizará.
!>          = 'E':  La matriz A se equilibrará si es necesario, luego
!>                  se copiará a AFP y se factorizará.
!>

UPLO

!>          UPLO es CHARACTER*1
!>          = 'U':  Se almacena el triángulo superior de A;
!>          = 'L':  Se almacena el triángulo inferior de A.
!>

N

!>          N es INTEGER
!>          El número de ecuaciones lineales, es decir, el orden de
!>          la matriz A.  N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de lados derechos, es decir, el número de columnas
!>          de las matrices B y X.  NRHS >= 0.
!>

AP

!>          AP es un array COMPLEX*16, dimensión (N*(N+1)/2)
!>          En la entrada, el triángulo superior o inferior de la matriz Hermitiana
!>          A, empaquetado columna a columna en un array lineal, excepto si FACT = 'F'
!>          y EQUED = 'Y', entonces A debe contener la matriz equilibrada
!>          diag(S)*A*diag(S). La j-ésima columna de A se almacena en
!>          el array AP como sigue:
!>          si UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) para 1<=i<=j;
!>          si UPLO = 'L', AP(i + (j-1)*(2n-j)/2) = A(i,j) para j<=i<=n.
!>          Ver más abajo para más detalles. A no se modifica si
!>          FACT = 'F' o 'N', o si FACT = 'E' y EQUED = 'N' en la salida.
!>
!>          En la salida, si FACT = 'E' y EQUED = 'Y', A se sobrescribe con
!>          diag(S)*A*diag(S).
!>

AFP

!>          AFP es un array COMPLEX*16, dimensión (N*(N+1)/2)
!>          Si FACT = 'F', entonces AFP es un argumento de entrada y en la entrada
!>          contiene el factor triangular U o L de la factorización de Cholesky
!>          A = U**H*U o A = L*L**H, en el mismo formato de almacenamiento que A.
!>          Si EQUED .ne. 'N', entonces AFP es la forma factorizada de la matriz
!>          equilibrada A.
!>
!>          Si FACT = 'N', entonces AFP es un argumento de salida y en la salida
!>          devuelve el factor triangular U o L de la factorización de Cholesky
!>          A = U**H * U o A = L * L**H de la matriz original A.
!>
!>          Si FACT = 'E', entonces AFP es un argumento de salida y en la salida
!>          devuelve el factor triangular U o L de la factorización de Cholesky
!>          A = U**H * U o A = L * L**H de la matriz equilibrada A (ver la descripción
!>          de AP para la forma de la matriz equilibrada).
!>

EQUED

!>          EQUED es CHARACTER*1
!>          Especifica la forma de equilibrado que se realizó.
!>          = 'N':  Sin equilibrado (siempre verdadero si FACT = 'N').
!>          = 'Y':  Se realizó el equilibrado, es decir, A se ha reemplazado por
!>                  diag(S) * A * diag(S).
!>          EQUED es un argumento de entrada si FACT = 'F'; de lo contrario, es un
!>          argumento de salida.
!>

S

!>          S es un array DOUBLE PRECISION, dimensión (N)
!>          Los factores de escala para A; no se accede si EQUED = 'N'. S es
!>          un argumento de entrada si FACT = 'F'; de lo contrario, S es un
!>          argumento de salida. Si FACT = 'F' y EQUED = 'Y', cada elemento de S
!>          debe ser positivo.
!>

B

!>          B es un array COMPLEX*16, dimensión (LDB,NRHS)
!>          En la entrada, la matriz B de N por NRHS del lado derecho.
!>          En la salida, si EQUED = 'N', B no se modifica; si EQUED = 'Y',
!>          B se sobrescribe con diag(S) * B.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B.  LDB >= max(1,N).
!>

X

!>          X es un array COMPLEX*16, dimensión (LDX,NRHS)
!>          Si INFO = 0 o INFO = N+1, la matriz solución X de N por NRHS a
!>          el sistema original de ecuaciones. Tenga en cuenta que si EQUED = 'Y',
!>          A y B se modifican en la salida, y la solución al sistema
!>          equilibrado es inv(diag(S))*X.
!>

LDX

!>          LDX es INTEGER
!>          La dimensión principal del array X.  LDX >= max(1,N).
!>

RCOND

Function/Subroutine Documentation

  > PURPOSE:
  >
  > ZPPsvx is a driver routine that solves the complex Hermitian positive
  > definite system of linear equations A * X = B for a vector X,
  > where A is represented in packed storage.
  >
  > This routine uses the factored form of the matrix A to solve the
  > system of equations. It also provides an estimate of the forward and
  > backward error bounds in the solution vector X.
  >
  > Arguments:
  >
  > FACT    (input) CHARACTER*1
  >         Specifies the form of the comparison matrix computed by
  >         ZPPsvx.
  >
  >         = 'E':  The routine routine will compute a general comparison
  >                 matrix R that is positive definite.
  >
  >         = 'N':  The routine expects that a factored comparison
  >                 matrix AFAC will be supplied on entry. If FACT = 'E',
  >                 the factored comparison matrix is passed out on the
  >                 argument AFAC.
  >
  > UPLO    (input) CHARACTER*1
  >         On entry to ZPPsvx, UPLO specifies whether the Hermitian
  >         matrix A is upper or lower triangular stored in packed format.
  >         UPLO = 'U': Upper triangular part of A is stored.
  >         UPLO = 'L': Lower triangular part of A is stored.
  >
  > N       (input) INTEGER
  >         The order of the matrix A. N >= 0.
  >
  > NRHS    (input) INTEGER
  >         The number of right hand sides, i.e., the number of columns
  >         of the matrices B and X. NRHS >= 0.
  >
  > AP      (input) COMPLEX*16 array, dimension (N*(N+1)/2)
  >         The packed matrix A.
  >
  > B       (input) COMPLEX*16 array, dimension (LDB,NRHS)
  >         The right hand side matrix of size N x NRHS.
  >
  > LDB     (input) INTEGER
  >         The leading dimension of the array B. LDB >= max(1,N).
  >
  > X       (output) COMPLEX*16 array, dimension (LDX,NRHS)
  >         If INFO = 0, X contains the solution vectors for the
  >         system of equations A * X = B.
  >
  > LDX     (input) INTEGER
  >         The leading dimension of the array X. LDX >= max(1,N).
  >
  > RCOND   (output) DOUBLE PRECISION
  >         The reciprocal of the condition number of A.  In the
  >         cases where the matrix is not well-conditioned, this
  >         value may be close to zero.
  >
  > FERR    (output) DOUBLE PRECISION array, dimension (NRHS)
  >         The estimated forward error bound for each solution vector
  >         X(j) (the j-th column of the solution matrix X).
  >         If XTRUE is the true solution corresponding to X(j), FERR(j)
  >         is an estimated upper bound for the magnitude of the largest
  >         element in (X(j) - XTRUE) divided by the magnitude of the
  >         largest element in X(j).  The estimate is as reliable as
  >         the estimate for RCOND, and is almost always a slight
  >         overestimate of the true error.
  >
  > BERR    (output) DOUBLE PRECISION array, dimension (NRHS)
  >         The componentwise relative backward error of each solution
  &>         vector X(j) (i.e., the smallest relative change in
  >         any element of A or B that makes X(j) an exact solution).
  >
  > AFAC    (input/output) COMPLEX*16 array, dimension (N*(N+1)/2)
  >         On entry, if FACT = 'N', AFAC contains the packed factored
  >         form of the comparison matrix A.
  >         On exit, if FACT = 'E', AFAC contains the packed factored
  >         form of the comparison matrix A.
  >
  > IWORK   (workspace) INTEGER array, dimension (N)
  >
  > INFO    (output) INTEGER
  >         = 0:  successful exit
  >         < 0:  if INFO = -i, the i-th argument had an illegal value
  >         > 0:  if INFO = i, and i is
  >               <= N:  the leading principal minor of order i of A
  >                      is not positive, so the factorization could not
  >                      be completed, and the solution has not been
  >                      computed. RCOND = 0 is returned.
  >               = N+1: U is nonsingular, but RCOND is less than machine
  >                      precision, meaning that the matrix is singular
  >                      to working precision.  Nevertheless, the
  >                      solution and error bounds are computed because
  >                      there are a number of situations where the
  >                      computed solution can be more accurate than the
  >                      value of RCOND would suggest.
  >

The reciprocal condition number of the matrix A after equilibration (if done). If RCOND is less than the machine precision (in particular, if RCOND = 0), the matrix is singular to working precision. This condition is indicated by a return code of INFO > 0.

Further Details:

 The packed storage scheme is illustrated by the following example
 when N = 4, UPLO = 'U':

 Two-dimensional storage of the Hermitian matrix A:

    a11 a12 a13 a14
        a22 a23 a24
            a33 a34     (aij = conjg(aji))
                a44

 Packed storage of the upper triangle of A:

 AP = [ a11, a12, a22, a13, a23, a33, a14, a24, a34, a44 ]
