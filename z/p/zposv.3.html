DOCUMENTACIÓN DE FUNCIÓN/SUBRUTINA

subrutina zposv (caracter uplo, entero n, entero nrhs, complejo*16, dimensión( lda, * ) a, entero lda, complejo*16, dimensión( ldb, * ) b, entero ldb, entero info)

ZPOSV calcula la solución al sistema de ecuaciones lineales A * X = B para matrices PO

Propósito:

!>
!> ZPOSV calcula la solución a un sistema complejo de ecuaciones lineales
!>    A * X = B,
!> donde A es una matriz Hermítica positiva definida de N por N y X y B
!> son matrices de N por NRHS.
!>
!> Se utiliza la descomposición de Cholesky para factorizar A como
!>    A = U**H* U,  si UPLO = 'U', o
!>    A = L * L**H,  si UPLO = 'L',
!> donde U es una matriz triangular superior y L es una matriz triangular
!> inferior.  La forma factorizada de A se utiliza luego para resolver el sistema de
!> ecuaciones A * X = B.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          = 'U':  El triángulo superior de A está almacenado;
!>          = 'L':  El triángulo inferior de A está almacenado.
!>

N

!>          N es INTEGER
!>          El número de ecuaciones lineales, es decir, el orden de
!>          la matriz A.  N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de lados derechos, es decir, el número de columnas
!>          de la matriz B.  NRHS >= 0.
!>

A

!>          A es una matriz COMPLEX*16, dimensión (LDA,N)
!>          En la entrada, la matriz Hermítica A.  Si UPLO = 'U', la parte
!>          superior triangular de N por N de A contiene la parte
!>          triangular superior de la matriz A, y la parte estrictamente
!>          triangular inferior de A no se referencia. Si UPLO = 'L', la parte
!>          inferior triangular de N por N de A contiene la parte
!>          triangular inferior de la matriz A, y la parte estrictamente
!>          triangular superior de A no se referencia.
!>
!>          En la salida, si INFO = 0, el factor U o L de la
!>          factorización de Cholesky A = U**H *U o A = L*L**H.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

B

!>          B es una matriz COMPLEX*16, dimensión (LDB,NRHS)
!>          En la entrada, la matriz B del lado derecho de N por NRHS.
!>          En la salida, si INFO = 0, la matriz solución X de N por NRHS.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B.  LDB >= max(1,N).
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>          > 0:  si INFO = i, el menor principal principal de orden i
!>                de A no es positivo, por lo que la factorización no pudo
!>                completarse y la solución no se ha calculado.
!>
