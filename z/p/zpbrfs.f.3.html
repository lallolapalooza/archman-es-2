subrutina zpbrfs (character uplo, integer n, integer kd, integer nrhs, complex*16, dimension( ldab, * ) ab, integer ldab, complex*16, dimension( ldafb, * ) afb, integer ldafb, complex*16, dimension( ldb, * ) b, integer ldb, complex*16, dimension( ldx, * ) x, integer ldx, double precision, dimension( * ) ferr, double precision, dimension( * ) berr, complex*16, dimension( * ) work, double precision, dimension( * ) rwork, integer info)

ZPBRFS

Propósito:

!>
!> ZPBRFS mejora la solución calculada de un sistema de ecuaciones lineales
!> cuando la matriz de coeficientes es Hermitiana positiva definida
!> y de banda, y proporciona cotas de error y estimaciones de error hacia atrás
!> para la solución.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          = 'U':  El triángulo superior de A se almacena;
!>          = 'L':  El triángulo inferior de A se almacena.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

KD

!>          KD es INTEGER
!>          El número de superdiagonales de la matriz A si UPLO = 'U',
!>          o el número de subdiagonales si UPLO = 'L'.  KD >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de lados derechos, es decir, el número de columnas
!>          de las matrices B y X.  NRHS >= 0.
!>

AB

!>          AB es un array COMPLEX*16, dimensión (LDAB,N)
!>          El triángulo superior o inferior de la matriz de banda Hermitiana A,
!>          almacenado en las primeras KD+1 filas del array. La j-ésima columna
!>          de A se almacena en la j-ésima columna del array AB de la siguiente manera:
!>          si UPLO = 'U', AB(kd+1+i-j,j) = A(i,j) para max(1,j-kd)<=i<=j;
!>          si UPLO = 'L', AB(1+i-j,j)    = A(i,j) para j<=i<=min(n,j+kd).
!>

LDAB

!>          LDAB es INTEGER
!>          La dimensión principal del array AB.  LDAB >= KD+1.
!>

AFB

!>          AFB es un array COMPLEX*16, dimensión (LDAFB,N)
!>          El factor triangular U o L de la factorización de Cholesky
!>          A = U**H*U o A = L*L**H de la matriz de banda A, tal como se calcula por
!>          ZPBTRF, en el mismo formato de almacenamiento que A (ver AB).
!>

LDAFB

!>          LDAFB es INTEGER
!>          La dimensión principal del array AFB.  LDAFB >= KD+1.
!>

B

!>          B es un array COMPLEX*16, dimensión (LDB,NRHS)
!>          La matriz del lado derecho B.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B.  LDB >= max(1,N).
!>

X

!>          X es un array COMPLEX*16, dimensión (LDX,NRHS)
!>          En la entrada, la matriz solución X, tal como se calcula por ZPBTRS.
!>          En la salida, la matriz solución mejorada X.
!>

LDX

!>          LDX es INTEGER
!>          La dimensión principal del array X.  LDX >= max(1,N).
!>

FERR

!>          FERR es un array DOUBLE PRECISION, dimensión (NRHS)
!>          La cota de error hacia adelante estimada para cada vector solución
!>          X(j) (la j-ésima columna de la matriz solución X).
!>          Si XTRUE es la solución verdadera correspondiente a X(j), FERR(j)
!>          es una cota superior estimada para la magnitud del elemento más grande
!>          en (X(j) - XTRUE) dividido por la magnitud del elemento más grande
!>          en X(j). La estimación es tan confiable como
!>          la estimación para RCOND, y es casi siempre una ligera
!>          sobreestimación del error verdadero.
!>

BERR

!>          BERR es un array DOUBLE PRECISION, dimensión (NRHS)
!>          El error hacia atrás relativo componente a componente de cada vector solución
!>          X(j) (es decir, el cambio relativo más pequeño en
!>          cualquier elemento de A o B que hace que X(j) sea una solución exacta).
!>

WORK

!>          WORK es un array COMPLEX*16, dimensión (2*N)
!>

RWORK

!>          RWORK es un array DOUBLE PRECISION, dimensión (N)
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>

Parámetros Internos:

!>  ITMAX es el número máximo de pasos de refinamiento iterativo.
!>
