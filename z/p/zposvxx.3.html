Funciones/Subrutinas

ZPOSVXX calcula la solución al sistema de ecuaciones lineales A * X = B para matrices PO

Documentación de Función/Subrutina

subrutina zposvxx (character fact, character uplo, integer n, integer nrhs, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( ldaf, * ) af, integer ldaf, character equed, double precision, dimension( * ) s, complex*16, dimension( ldb, * ) b, integer ldb, complex*16, dimension( ldx, * ) x, integer ldx, double precision rcond, double precision rpvgrw, double precision, dimension( * ) berr, integer n_err_bnds, double precision, dimension( nrhs, * ) err_bnds_norm, double precision, dimension( nrhs, * ) err_bnds_comp, integer nparams, double precision, dimension( * ) params, complex*16, dimension( * ) work, double precision, dimension( * ) rwork, integer info)

ZPOSVXX calcula la solución al sistema de ecuaciones lineales A * X = B para matrices PO

Propósito:

!>
!>    ZPOSVXX usa la factorización de Cholesky A = U**T*U o A = L*L**T
!>    para calcular la solución a un sistema de ecuaciones lineales complex*16
!>    A * X = B, donde A es una matriz Hermitiana positiva definida de N-por-N
!>    y X y B son matrices de N-por-NRHS.
!>
!>    Si se solicita, se devuelven límites de error tanto normados como
!>    componentes máximos. ZPOSVXX devolverá una solución con un error
!>    garantizado minúsculo (O(eps) donde eps es la precisión de la máquina de
!>    trabajo) a menos que la matriz sea muy mal condicionada, en cuyo caso
!>    se devuelve una advertencia. También se calculan y devuelven números de
!>    condición relevantes.
!>
!>    ZPOSVXX acepta factorizaciones y factores de equilibrado proporcionados
!>    por el usuario; véanse las definiciones de las opciones FACT y EQUED.
!>    Resolver con refinamiento y usar una factorización de una llamada previa
!>    a ZPOSVXX también producirá una solución con errores O(eps) o advertencias,
!>    pero no podemos afirmar eso para factorizaciones y factores de equilibrado
!>    proporcionados por el usuario en general si difieren de lo que ZPOSVXX
!>    produciría por sí mismo.
!>

Descripción:

!>
!>    Se realizan los siguientes pasos:
!>
!>    1. Si FACT = 'E', se calculan factores de escala de precisión doble para equilibrar
!>    el sistema:
!>
!>      diag(S)*A*diag(S)     *inv(diag(S))*X = diag(S)*B
!>
!>    Si el sistema se va a equilibrar o no depende del escalado de
!>    la matriz A, pero si se utiliza el equilibrado, A se sobrescribe
!>    con diag(S)*A*diag(S) y B con diag(S)*B.
!>
!>    2. Si FACT = 'N' o 'E', se utiliza la descomposición de Cholesky para
!>    factorizar la matriz A (después de equilibrarla si FACT = 'E') como
!>       A = U**T* U,  si UPLO = 'U', o
!>       A = L * L**T,  si UPLO = 'L',
!>    donde U es una matriz triangular superior y L es una matriz triangular
!>    inferior.
!>
!>    3. Si el menor principal principal de orden i no es positivo,
!>    entonces la rutina devuelve INFO = i. De lo contrario, la forma factorizada
!>    de A se utiliza para estimar el número de condición de la matriz
!>    A (ver argumento RCOND). Si la inversa del número de condición
!>    es menor que la precisión de la máquina, la rutina aún continúa para
!>    resolver para X y calcular los límites de error como se describe a
!>    continuación.
!>
!>    4. El sistema de ecuaciones se resuelve para X utilizando la forma factorizada
!>    de A.
!>
!>    5. Por defecto (a menos que PARAMS(LA_LINRX_ITREF_I) se establezca en cero),
!>    la rutina utilizará refinamiento iterativo para intentar obtener un error
!>    pequeño y límites de error. El refinamiento calcula el residual a
!>    al menos el doble de la precisión de trabajo.
!>
!>    6. Si se utilizó el equilibrado, la matriz X se premultiplica por
!>    diag(S) para que resuelva el sistema original antes de
!>    equilibrarlo.
!> 
!>     Algunos parámetros opcionales están agrupados en el array PARAMS. Estos
!>     ajustes determinan cómo se realiza el refinamiento, pero a menudo los
!>     valores predeterminados son aceptables. Si los valores predeterminados
!>     son aceptables, los usuarios pueden pasar NPARAMS = 0 lo que evita que
!>     el código fuente acceda al argumento PARAMS.
!>

Parámetros

FACT 
!>          FACT es CHARACTER*1
!>     Especifica si la forma factorizada de la matriz A se proporciona
!!>     en la entrada, y si no, si la matriz A debe equilibrarse antes
!>     de ser factorizada.
!>       = 'F': En la entrada, AF contiene la forma factorizada.
!>              Si EQUED no es 'N', la matriz A se ha equilibrado
!>              con factores de escala dados por S.
!>              A y AF no se modifican.
!>       = 'N': La matriz A se copiará a AF y se factorizará.
!>       = 'E': La matriz A se equilibrará si es necesario, luego
!>              se copiará a AF y se factorizará.
!>

UPLO

!>          UPLO es CHARACTER*1
!>       = 'U': Se almacena la parte triangular superior de A;
!>       = 'L': Se almacena la parte triangular inferior de A.
!>

N

!>          N es INTEGER
!>     El número de ecuaciones lineales, es decir, el orden de la
!>     matriz A. N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>     El número de lados derechos, es decir, el número de columnas
!>     de las matrices B y X. NRHS >= 0.
!>

A

!>          A es array COMPLEX*16, dimension (LDA,N)
!>     En la entrada, la matriz Hermitiana A, excepto si FACT = 'F' y EQUED =
!>     'Y', entonces A debe contener la matriz equilibrada
!>     diag(S)*A*diag(S). Si UPLO = 'U', la parte superior de N por N de A contiene
!>     la parte triangular superior de la matriz A, y la parte estrictamente
!>     triangular inferior de A no se referencia. Si UPLO = 'L', la parte inferior
!>     de N por N de A contiene la parte triangular inferior de la matriz A, y
!>     la parte estrictamente triangular superior de A no se referencia.
!>     A no se modifica si FACT = 'F' o 'N', o si FACT = 'E' y EQUED =
!>     'N' en la salida.
!>
!>     En la salida, si FACT = 'E' y EQUED = 'Y', A se sobrescribe con
!>     diag(S)*A*diag(S).
!>

LDA

!>          LDA es INTEGER
!>     La dimensión principal del array A. LDA >= max(1,N).
!>

AF

!>          AF es array COMPLEX*16, dimension (LDAF,N)
!>     Si FACT = 'F', entonces AF es un argumento de entrada y en la entrada
!>     contiene el factor triangular U o L de la factorización de Cholesky
!>     A = U**T*U o A = L*L**T, en el mismo formato de almacenamiento que A.
!>     Si EQUED .ne. 'N', entonces AF es la forma factorizada de la matriz
!>     equilibrada diag(S)*A*diag(S).
!>
!>     Si FACT = 'N', entonces AF es un argumento de salida y en la salida
!>     devuelve el factor triangular U o L de la factorización de Cholesky
!>     A = U**T*U o A = L*L**T de la matriz original A.
!>
!>     Si FACT = 'E', entonces AF es un argumento de salida y en la salida
!>     devuelve el factor triangular U o L de la factorización de Cholesky
!>     A = U**T*U o A = L*L**T de la matriz equilibrada A (ver la descripción
!>     de A para la forma de la matriz equilibrada).
!>

LDAF

!>          LDAF es INTEGER
!>     La dimensión principal del array AF. LDAF >= max(1,N).
!>

EQUED

!>          EQUED es CHARACTER*1
!>     Especifica si la matriz fue equilibrada, y si lo fue, si el equilibrado
!>     fue diagonal o no.
!>       = 'N': Ningún equilibrado se realizó.
!>       = 'Y': El equilibrado se realizó con factores S de escala diagonal.
!>       = 'S': El equilibrado se realizó con factores S de escala no
!>              diagonal, o solo se aplicó el escalado de filas o
!>              columnas.
!>       = 'B': El equilibrado se realizó con factores S de escala diagonal
!>              y también con escalado de filas/columnas.
!>

S

!>          S es array DOUBLE PRECISION, dimension (N)
!>     Los factores de escala utilizados para equilibrar la matriz A.
!>     El array S solo se utiliza si EQUED = 'Y', 'S' o 'B'.
!>     En la entrada, si FACT = 'F' y EQUED .ne. 'N', entonces S contiene
!>     los factores de escala de la matriz A.
!>     En la salida, si FACT = 'E' y EQUED = 'Y', 'S' o 'B', S contiene
!>     los factores de escala utilizados para equilibrar la matriz A.
!>     Si EQUED = 'N', S no se utiliza.
!>

B

!>          B es array COMPLEX*16, dimension (LDB,NRHS)
!>     En la entrada, la matriz B de N-por-NRHS.
!>     En la salida, si FACT = 'E' y EQUED = 'Y', B se sobrescribe con
!>     diag(S)*B.
!>

LDB

!>          LDB es INTEGER
!>     La dimensión principal del array B. LDB >= max(1,N).
!>

X

!>          X es array COMPLEX*16, dimension (LDX,NRHS)
!>     En la salida, la solución al sistema A * X = B.
!>

LDX

!>          LDX es INTEGER
!>     La dimensión principal del array X. LDX >= max(1,N).
!>

RCOND

!>          RCOND es DOUBLE PRECISION
!>     En la salida, una estimación del número de condición recíproco de
!>     la matriz A. La estimación se realiza utilizando los valores
!>     singulares de la factorización de Cholesky.
!>

RPVGRW

!>          RPVGRW es DOUBLE PRECISION
!>     En la salida, el factor de crecimiento relativo de la norma de la
!>     matriz inversa.  Este valor se utiliza para calcular el límite
!>     de error normado.
!>

BERR

!>          BERR es array DOUBLE PRECISION, dimension (NRHS)
!>     En la salida, el límite de error estimado para cada una de las
!>     soluciones X(i) (i.e. norm(X(i) - Xref(i)) / norm(Xref(i)) ).
!>     Este límite de error es la norma más grande entre el error
!>     normado y el error componente a componente.
!>

N_ERR_BNDS

!>          N_ERR_BNDS es INTEGER
!>     El número de límites de error que se calcularán y devolverán.
!>     Normalmente, N_ERR_BNDS = 3.
!>       = 0: No se calcularán límites de error.
!>       = 1: Se calculará el límite de error normado.
!>       = 2: Se calculará el límite de error componente a componente.
!>       = 3: Se calcularán ambos, el límite de error normado y el
!>            límite de error componente a componente.
!>

ERR_BNDS_NORM

!>          ERR_BNDS_NORM es array DOUBLE PRECISION, dimension (NRHS)
!>     En la salida, si N_ERR_BNDS >= 1, contiene los límites de error
!>     normados para cada una de las soluciones X(i).
!>     norm(X(i) - Xref(i)) / norm(Xref(i))
!>

ERR_BNDS_COMP

!>          ERR_BNDS_COMP es array DOUBLE PRECISION, dimension (NRHS)
!>     En la salida, si N_ERR_BNDS >= 2, contiene los límites de error
!>     componente a componente para cada una de las soluciones X(i).
!>     max(|X(i) - Xref(i)| / |Xref(i)|)
!>

NPARAMS

!>          NPARAMS es INTEGER
!>     El número de parámetros opcionales que se van a pasar en el array
!>     PARAMS. Si NPARAMS = 0, entonces el array PARAMS no se utiliza.
!>

PARAMS

!>          PARAMS es array DOUBLE PRECISION, dimension (NPARAMS)
!>     Los parámetros opcionales. Actualmente, se utiliza el siguiente
!>     parámetro opcional:
!>
!>     PARAMS(LA_LINRX_ITREF_I) = valor. Si este valor es 0,
!>     el refinamiento iterativo se desactiva. Por defecto, este valor
!>     es 1, lo que significa que el refinamiento iterativo está activado.
!>

WORK

!>          WORK es array COMPLEX*16, dimension (max(1,LWORK))
!>     En la salida, WORK(1) contiene el tamaño mínimo de LWORK.
!>

LWORK

!>          LWORK es INTEGER
!>     El tamaño del array WORK.  Este parámetro no se utiliza en esta
!>     implementación.
!>

RWORK

!>          RWORK es array DOUBLE PRECISION, dimension (max(1,LRWORK))
!>     En la salida, RWORK(1) contiene el tamaño mínimo de LRWORK.
!>

LRWORK

!>          LRWORK es INTEGER
!>     El tamaño del array RWORK. Este parámetro no se utiliza en esta
!>     implementación.
!>

INFO

!>          INFO es INTEGER
!>     = 0: El proceso de ejecución ha finalizado correctamente.
!>     > 0: Si INFO = i, y 1 <= i <= N, entonces el menor principal
!>          principal de orden i de A es no positivo. Esto significa que la
!>          factorización de Cholesky no pudo completarse, y la matriz
!>          no es positiva definida.
!>     = N+1: Si el cálculo del número de condición recíproco RCOND
!>            causó un problema.
!>     = N+2: Si el cálculo de los límites de error causó un problema.
!>     = N+3: Si el refinamiento iterativo causó un problema.
!>

     LDAF es INTEGER
     La dimensión principal del array AF. LDAF >= max(1,N).

EQUED

     EQUED es CHARACTER*1
     Especifica la forma de equilibrado que se realizó.
       = 'N': No se realizó equilibrado (siempre cierto si FACT = 'N').
       = 'Y': Se realizó equilibrado tanto de filas como de columnas, es decir, A ha sido
               reemplazado por diag(S) * A * diag(S).
     EQUED es un argumento de entrada si FACT = 'F'; de lo contrario, es un
     argumento de salida.

S

     S es un array DOUBLE PRECISION, de dimensión (N)
     Los factores de escala de fila para A. Si EQUED = 'Y', A se multiplica por
     la izquierda y por la derecha por diag(S). S es un argumento de entrada si FACT =
     'F'; de lo contrario, S es un argumento de salida. Si FACT = 'F' y EQUED
     = 'Y', cada elemento de S debe ser positivo. Si S es de salida, cada
     elemento de S es una potencia de la base. Si S es de entrada, cada elemento
     de S debe ser una potencia de la base para asegurar una solución fiable
     y estimaciones de error. El escalado por potencias de la base no causa
     errores de redondeo a menos que el resultado sufra un desbordamiento inferior o superior.
     Los errores de redondeo durante el escalado conducen a una refinación con una matriz que
     no es equivalente a la matriz de entrada, produciendo estimaciones de error
     que pueden no ser fiables.

B

     B es un array COMPLEX*16, de dimensión (LDB,NRHS)
     A la entrada, la matriz B de mano derecha de N por NRHS.
     A la salida,
     si EQUED = 'N', B no se modifica;
     si EQUED = 'Y', B se sobrescribe por diag(S)*B;

LDB

     LDB es INTEGER
     La dimensión principal del array B. LDB >= max(1,N).

X

     X es un array COMPLEX*16, de dimensión (LDX,NRHS)
     Si INFO = 0, la matriz solución X de N por NRHS del sistema original
     de ecuaciones. Tenga en cuenta que A y B se modifican a la salida si
     EQUED .ne. 'N', y la solución del sistema equilibrado es
     inv(diag(S))*X.

LDX

     LDX es INTEGER
     La dimensión principal del array X. LDX >= max(1,N).

RCOND

     RCOND es DOUBLE PRECISION
     Recíproco del número de condición escalado. Esta es una estimación del
     número de condición de Skeel recíproco de la matriz A después del
     equilibrado (si se realizó). Si es menor que la precisión de la máquina
     (en particular, si es cero), la matriz es singular
     para la precisión de trabajo. Tenga en cuenta que el error puede ser pequeño incluso
     si este número es muy pequeño y la matriz parece mal
     condicionada.

RPVGRW

     RPVGRW es DOUBLE PRECISION
     Crecimiento recíproco de pivote. A la salida, esto contiene el factor
     de crecimiento recíproco del pivote norm(A)/norm(U). Se utiliza la
     norma. Si esto es mucho menor que 1, entonces la estabilidad de
     la factorización LU de la matriz A (equilibrada) podría ser pobre.
     Esto también significa que la solución X, los números de condición estimados
     y los límites de error podrían no ser fiables. Si la factorización falla con
     0<INFO<=N, entonces esto contiene el factor de crecimiento recíproco del pivote
     para las columnas INFO principales de A.

BERR

     BERR es un array DOUBLE PRECISION, de dimensión (NRHS)
     Error residual relativo componente a componente. Este es el
     error residual relativo componente a componente de cada vector solución X(j)
     (es decir, el cambio relativo más pequeño en cualquier elemento de A o B que
     hace que X(j) sea una solución exacta).

N_ERR_BNDS

     N_ERR_BNDS es INTEGER
     Número de límites de error a devolver para cada mano derecha
     y cada tipo (normwise o componente a componente). Ver ERR_BNDS_NORM y
     ERR_BNDS_COMP a continuación.

ERR_BNDS_NORM

     ERR_BNDS_NORM es un array DOUBLE PRECISION, de dimensión (NRHS, N_ERR_BNDS)
     Para cada mano derecha, este array contiene información sobre
     varios límites de error y números de condición correspondientes al
     error relativo normwise, que se define como sigue:

     Error relativo normwise en el i-ésimo vector solución:
             max_j (abs(XTRUE(j,i) - X(j,i)))
            ------------------------------
                  max_j abs(X(j,i))

     El array se indexa por el tipo de información de error como se describe
     a continuación. Actualmente hay hasta tres piezas de información
     devueltas.

     El primer índice en ERR_BNDS_NORM(i,:) corresponde a la i-ésima
     mano derecha.

     El segundo índice en ERR_BNDS_NORM(:,err) contiene los siguientes
     tres campos:
     err = 1  booleano. Confíe en la respuesta si el
              número de condición recíproco es menor que el umbral
              sqrt(n) * dlamch('Epsilon').

     err = 2  límite de error: El error directo estimado,
              casi ciertamente dentro de un factor de 10 del error real
              siempre que la siguiente entrada sea mayor que el umbral
              sqrt(n) * dlamch('Epsilon'). Este límite de error solo debe
              confiarse si el booleano anterior es verdadero.

     err = 3  Número de condición recíproco: Estimación normwise
              número de condición recíproco. Comparado con el umbral
              sqrt(n) * dlamch('Epsilon') para determinar si el error
              la estimación es . Estos números de condición recíprocos
              son 1 / (norm(Z^{-1},inf) * norm(Z,inf)) para alguna
              matriz Z apropiadamente escalada.
              Sea Z = S*A, donde S escala cada fila por una potencia de la
              base para que todas las sumas de filas absolutas de Z sean aproximadamente 1.

     Consulte la Nota de Trabajo 165 de Lapack para obtener más detalles y precauciones adicionales.

ERR_BNDS_COMP

     ERR_BNDS_COMP es un array DOUBLE PRECISION, de dimensión (NRHS, N_ERR_BNDS)
     Para cada mano derecha, este array contiene información sobre
     varios límites de error y números de condición correspondientes al
     error relativo componente a componente, que se define como sigue:

     Error relativo componente a componente en el i-ésimo vector solución:
                    abs(XTRUE(j,i) - X(j,i))
             max_j ----------------------
                         abs(X(j,i))

     El array se indexa por la mano derecha i (de la que depende el
     error relativo componente a componente), y el tipo de información de error como se describe
     a continuación. Actualmente hay hasta tres piezas de información
     devueltas para cada mano derecha. Si
     no se solicita precisión componente a componente (PARAMS(3) = 0.0), entonces
     ERR_BNDS_COMP no se accede. Si N_ERR_BNDS < 3, entonces como máximo
     se devuelven las primeras entradas (:,N_ERR_BNDS).

     El primer índice en ERR_BNDS_COMP(i,:) corresponde a la i-ésima
     mano derecha.

     El segundo índice en ERR_BNDS_COMP(:,err) contiene los siguientes
     tres campos:
     err = 1  booleano. Confíe en la respuesta si el
              número de condición recíproco es menor que el umbral
              sqrt(n) * dlamch('Epsilon').

     err = 2  límite de error: El error directo estimado,
              casi ciertamente dentro de un factor de 10 del error real
              siempre que la siguiente entrada sea mayor que el umbral
              sqrt(n) * dlamch('Epsilon'). Este límite de error solo debe
              confiarse si el booleano anterior es verdadero.

     err = 3  Número de condición recíproco: Estimación componente a componente
              número de condición recíproco. Comparado con el umbral
              sqrt(n) * dlamch('Epsilon') para determinar si el error
              la estimación es . Estos números de condición recíprocos
              son 1 / (norm(Z^{-1},inf) * norm(Z,inf)) para alguna
              matriz Z apropiadamente escalada.
              Sea Z = S*(A*diag(x)), donde x es la solución para
              la mano derecha actual y S escala cada fila de
              A*diag(x) por una potencia de la base para que todas las sumas de filas absolutas
              de Z sean aproximadamente 1.

     Consulte la Nota de Trabajo 165 de Lapack para obtener más detalles y precauciones adicionales.

NPARAMS

     NPARAMS es INTEGER
     Especifica el número de parámetros establecidos en PARAMS. Si es <= 0, la
     matriz PARAMS nunca se accede y se utilizan los valores predeterminados.

PARAMS

     PARAMS es un array DOUBLE PRECISION, de dimensión NPARAMS
     Especifica los parámetros del algoritmo. Si una entrada es < 0.0, entonces
     esa entrada se rellenará con el valor predeterminado utilizado para ese
     parámetro. Solo se accede a las posiciones hasta NPARAMS; se utilizan los valores predeterminados
     para parámetros de número superior.

       PARAMS(LA_LINRX_ITREF_I = 1) : Si se realiza un refinamiento iterativo
            o no.
         Predeterminado: 1.0D+0
            = 0.0: No se realiza refinamiento y no se calculan límites de error.
            = 1.0: Utiliza el algoritmo de refinamiento de precisión extra.
              (otros valores están reservados para uso futuro)

       PARAMS(LA_LINRX_ITHRESH_I = 2) : Número máximo de residuales
            cálculos permitidos para el refinamiento.
         Predeterminado: 10
         Agresivo: Establecido en 100 para permitir la convergencia utilizando factorizaciones aproximadas
                     o factorizaciones distintas de LU. Si
                     la factorización utiliza una técnica distinta de
                     la eliminación gaussiana, las garantías en
                     err_bnds_norm y err_bnds_comp pueden ya no ser
                     fiables.

       PARAMS(LA_LINRX_CWISE_I = 3) : Bandera que determina si el código
            intentará encontrar una solución con un pequeño error relativo componente a componente
            en el algoritmo de doble precisión. Positivo
            es verdadero, 0.0 es falso.
         Predeterminado: 1.0 (intenta la convergencia componente a componente)

WORK

     WORK es un array COMPLEX*16, de dimensión (2*N)

RWORK
