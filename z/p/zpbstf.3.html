Documentación de función/subrutina

subrutina zpbstf (character uplo, integer n, integer kd, complex*16, dimension( ldab, * ) ab, integer ldab, integer info)

ZPBSTF

Propósito:

!>
!> ZPBSTF calcula una factorización de Cholesky dividida de una matriz de banda
!> Hermitiana positiva definida compleja A.
!>
!> Esta rutina está diseñada para ser utilizada conjuntamente con ZHBGST.
!>
!> La factorización tiene la forma A = S**H*S donde S es una matriz de banda
!> del mismo ancho de banda que A y la siguiente estructura:
!>
!>   S = ( U    )
!>       ( M  L )
!>
!> donde U es triangular superior de orden m = (n+kd)/2, y L es triangular
!> inferior de orden n-m.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          = 'U':  El triángulo superior de A está almacenado;
!>          = 'L':  El triángulo inferior de A está almacenado.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

KD

!>          KD es INTEGER
!>          El número de superdiagonales de la matriz A si UPLO = 'U',
!>          o el número de subdiagonales si UPLO = 'L'.  KD >= 0.
!>

AB

!>          AB es un array COMPLEX*16, dimensión (LDAB,N)
!>          En la entrada, el triángulo superior o inferior de la matriz de banda
!>          Hermitiana A, almacenado en las primeras kd+1 filas del array. La
!>          columna j de A se almacena en la columna j del array AB
!>          como sigue:
!>          si UPLO = 'U', AB(kd+1+i-j,j) = A(i,j) para max(1,j-kd)<=i<=j;
!>          si UPLO = 'L', AB(1+i-j,j)    = A(i,j) para j<=i<=min(n,j+kd).
!>
!>          En la salida, si INFO = 0, el factor S de la factorización de Cholesky
!>          dividida A = S**H*S. Ver Detalles adicionales.
!>

LDAB

!>          LDAB es INTEGER
!>          La dimensión principal del array AB.  LDAB >= KD+1.
!>

INFO

!>          INFO es INTEGER
!>          = 0: salida exitosa
!>          < 0: si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>          > 0: si INFO = i, la factorización no pudo completarse,
!>               porque el elemento actualizado a(i,i) era negativo; la
!>               matriz A no es positiva definida.
!>

Detalles adicionales:

!>
!>  El esquema de almacenamiento de banda se ilustra con el siguiente ejemplo, cuando
!>  N = 7, KD = 2:
!>
!>  S = ( s11  s12  s13                     )
!>      (      s22  s23  s24                )
!>      (           s33  s34                )
!>      (                s44                )
!>      (           s53  s54  s55           )
!>      (                s64  s65  s66      )
!>      (                     s75  s76  s77 )
!>
!>  Si UPLO = 'U', el array AB contiene:
!>
!>  en la entrada:                      en la salida:
!>
!>   *    *   a13  a24  a35  a46  a57   *    *   s13  s24  s53**H s64**H s75**H
!>   *   a12  a23  a34  a45  a56  a67   *   s12  s23  s34  s54**H s65**H s76**H
!>  a11  a22  a33  a44  a55  a66  a77  s11  s22  s33  s44  s55    s66    s77
!>
!>  Si UPLO = 'L', el array AB contiene:
!>
!>  en la entrada:                      en la salida:
!>
!>  a11  a22  a33  a44  a55  a66  a77  s11    s22    s33    s44  s55  s66  s77
!>  a21  a32  a43  a54  a65  a76   *   s12**H s23**H s34**H s54  s65  s76   *
!>  a31  a42  a53  a64  a64   *    *   s13**H s24**H s53    s64  s75   *    *
!>
!>  Los elementos del array marcados con * no son utilizados por la rutina; s12**H
!>  denota conj(s12); los elementos diagonales de S son reales.
!>
