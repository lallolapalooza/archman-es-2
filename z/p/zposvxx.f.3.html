subroutine zposvxx (character fact, character uplo, integer n, integer nrhs, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( ldaf, * ) af, integer ldaf, character equed, double precision, dimension( * ) s, complex*16, dimension( ldb, * ) b, integer ldb, complex*16, dimension( ldx, * ) x, integer ldx, double precision rcond, double precision rpvgrw, double precision, dimension( * ) berr, integer n_err_bnds, double precision, dimension( nrhs, * ) err_bnds_norm, double precision, dimension( nrhs, * ) err_bnds_comp, integer nparams, double precision, dimension( * ) params, complex*16, dimension( * ) work, double precision, dimension( * ) rwork, integer info)

ZPOSVXX computes the solution to system of linear equations A * X = B for PO matrices

Purpose:

!>
!>    ZPOSVXX uses the Cholesky factorization A = U**T*U or A = L*L**T
!>    to compute the solution to a complex*16 system of linear equations
!>    A * X = B, where A is an N-by-N Hermitian positive definite matrix
!>    and X and B are N-by-NRHS matrices.
!>
!>    If requested, both normwise and maximum componentwise error bounds
!>    are returned. ZPOSVXX will return a solution with a tiny
!>    guaranteed error (O(eps) where eps is the working machine
!>    precision) unless the matrix is very ill-conditioned, in which
!>    case a warning is returned. Relevant condition numbers also are
!>    calculated and returned.
!>
!>    ZPOSVXX accepts user-provided factorizations and equilibration
!>    factors; see the definitions of the FACT and EQUED options.
!>    Solving with refinement and using a factorization from a previous
!>    ZPOSVXX call will also produce a solution with either O(eps)
!>    errors or warnings, but we cannot make that claim for general
!>    user-provided factorizations and equilibration factors if they
!>    differ from what ZPOSVXX would itself produce.
!>

Description:

!>
!>    The following steps are performed:
!>
!>    1. If FACT = 'E', double precision scaling factors are computed to equilibrate
!>    the system:
!>
!>      diag(S)*A*diag(S)     *inv(diag(S))*X = diag(S)*B
!>
!>    Whether or not the system will be equilibrated depends on the
!>    scaling of the matrix A, but if equilibration is used, A is
!>    overwritten by diag(S)*A*diag(S) and B by diag(S)*B.
!>
!>    2. If FACT = 'N' or 'E', the Cholesky decomposition is used to
!>    factor the matrix A (after equilibration if FACT = 'E') as
!>       A = U**T* U,  if UPLO = 'U', or
!>       A = L * L**T,  if UPLO = 'L',
!>    where U is an upper triangular matrix and L is a lower triangular
!>    matrix.
!>
!>    3. If the leading principal minor of order i is not positive,
!>    then the routine returns with INFO = i. Otherwise, the factored
!>    form of A is used to estimate the condition number of the matrix
!>    A (see argument RCOND).  If the reciprocal of the condition number
!>    is less than machine precision, the routine still goes on to solve
!>    for X and compute error bounds as described below.
!>
!>    4. The system of equations is solved for X using the factored form
!>    of A.
!>
!>    5. By default (unless PARAMS(LA_LINRX_ITREF_I) is set to zero),
!>    the routine will use iterative refinement to try to get a small
!>    error and error bounds.  Refinement calculates the residual to at
!>    least twice the working precision.
!>
!>    6. If equilibration was used, the matrix X is premultiplied by
!>    diag(S) so that it solves the original system before
!>    equilibration.
!> 
!>     Some optional parameters are bundled in the PARAMS array.  These
!>     settings determine how refinement is performed, but often the
!>     defaults are acceptable.  If the defaults are acceptable, users
!>     can pass NPARAMS = 0 which prevents the source code from accessing
!>     the PARAMS argument.
!>

Parameters

FACT 
!>          FACT is CHARACTER*1
!>     Specifies whether or not the factored form of the matrix A is
!>     supplied on entry, and if not, whether the matrix A should be
!>     equilibrated before it is factored.
!>       = 'F':  On entry, AF contains the factored form of A.
!>               If EQUED is not 'N', the matrix A has been
!>               equilibrated with scaling factors given by S.
!>               A and AF are not modified.
!>       = 'N':  The matrix A will be copied to AF and factored.
!>       = 'E':  The matrix A will be equilibrated if necessary, then
!>               copied to AF and factored.
!>

UPLO

!>          UPLO is CHARACTER*1
!>       = 'U':  Upper triangle of A is stored;
!>       = 'L':  Lower triangle of A is stored.
!>

N

!>          N is INTEGER
!>     The number of linear equations, i.e., the order of the
!>     matrix A.  N >= 0.
!>

NRHS

!>          NRHS is INTEGER
!>     The number of right hand sides, i.e., the number of columns
!>     of the matrices B and X.  NRHS >= 0.
!>

A

!>          A is COMPLEX*16 array, dimension (LDA,N)
!>     On entry, the Hermitian matrix A, except if FACT = 'F' and EQUED =
!!>     'Y', then A must contain the equilibrated matrix
!>     diag(S)*A*diag(S).  If UPLO = 'U', the leading N-by-N upper
!>     triangular part of A contains the upper triangular part of the
!>     matrix A, and the strictly lower triangular part of A is not
!>     referenced.  If UPLO = 'L', the leading N-by-N lower triangular
!>     part of A contains the lower triangular part of the matrix A, and
!>     the strictly upper triangular part of A is not referenced.  A is
!>     not modified if FACT = 'F' or 'N', or if FACT = 'E' and EQUED =
!>     'N' on exit.
!>
!>     On exit, if FACT = 'E' and EQUED = 'Y', A is overwritten by
!>     diag(S)*A*diag(S).
!>

LDA

!>          LDA is INTEGER
!>     The leading dimension of the array A.  LDA >= max(1,N).
!>

AF

!>          AF is COMPLEX*16 array, dimension (LDAF,N)
!>     If FACT = 'F', then AF is an input argument and on entry
!>     contains the triangular factor U or L from the Cholesky
!>     factorization A = U**T*U or A = L*L**T, in the same storage
!>     format as A.  If EQUED .ne. 'N', then AF is the factored
!>     form of the equilibrated matrix diag(S)*A*diag(S).
!>
!>     If FACT = 'N', then AF is an output argument and on exit
!>     returns the triangular factor U or L from the Cholesky
!>     factorization A = U**T*U or A = L*L**T of the original
!>     matrix A.
!>
!>     If FACT = 'E', then AF is an output argument and on exit
!>     returns the triangular factor U or L from the Cholesky
!!>     factorization A = U**T*U or A = L*L**T of the equilibrated
!>     matrix A (see the description of A for the form of the
!>     equilibrated matrix).
!> 
LDAF


!>          LDAF es INTEGER
!>     La dimensión principal del arreglo AF.  LDAF >= max(1,N).
!> 


EQUED


!>          EQUED es CHARACTER*1
!>     Especifica la forma de   equilibrado que se realizó.
!>       = 'N':  Sin   equilibrado (siempre cierto si FACT = 'N').
!>       = 'Y':  Equilibrado de fila y columna, es decir, A ha sido
!>               reemplazado por diag(S) * A * diag(S).
!>     EQUED es un argumento de entrada si FACT = 'F'; de lo contrario,
!>     es un argumento de salida.
!> 


S


!>          S es un arreglo DOUBLE PRECISION, de dimensión (N)
!>     Los factores de escala de fila para A.  Si EQUED = 'Y', A se multiplica
!>     a la izquierda y a la derecha por diag(S).  S es un argumento de
!>     entrada si FACT = 'F'; de lo contrario, S es un argumento de
!>     salida. Si FACT = 'F' y EQUED = 'Y', cada elemento de S debe ser
!>     positivo. Si S es de salida, cada elemento de S es una potencia
!>     de la base. Si S es de entrada, cada elemento de S debe ser una
!>     potencia de la base para asegurar una solución fiable y estimaciones
!>     de error. El escalado por potencias de la base no causa errores de
!>     redondeo a menos que el resultado sea subdesbordado o desbordado.
!>     Los errores de redondeo durante el escalado conducen a un refinamiento
!>     con una matriz que no es equivalente a la matriz de entrada,
!>     produciendo estimaciones de error que pueden no ser fiables.
!> 


B


!>          B es un arreglo COMPLEX*16, de dimensión (LDB,NRHS)
!>     A la entrada, la matriz B del lado derecho de N por NRHS.
!>     A la salida,
!>     si EQUED = 'N', B no se modifica;
!>     si EQUED = 'Y', B se sobrescribe por diag(S)*B;
!> 


LDB


!>          LDB es INTEGER
!>     La dimensión principal del arreglo B.  LDB >= max(1,N).
!> 


X


!>          X es un arreglo COMPLEX*16, de dimensión (LDX,NRHS)
!>     Si INFO = 0, la matriz de solución X de N por NRHS del sistema
!>     original de ecuaciones.  Tenga en cuenta que A y B se modifican a la
!>     salida si EQUED .ne. 'N', y la solución del sistema equilibrado es
!>     inv(diag(S))*X.
!> 


LDX


!>          LDX es INTEGER
!>     La dimensión principal del arreglo X.  LDX >= max(1,N).
!> 


RCOND


!>          RCOND es DOUBLE PRECISION
!>     Condición recíproca escalada. Esta es una estimación del
!>     número de condición de Skeel recíproco de la matriz A después
!>     del   equilibrado (si se realizó). Si es menor que la precisión
!>     de la máquina (en particular, si es cero), la matriz es singular
!>     a la precisión de trabajo. Tenga en cuenta que el error aún puede ser
!>     pequeño incluso si este número es muy pequeño y la matriz parece
!>     mal condicionada.
!> 


RPVGRW


!>          RPVGRW es DOUBLE PRECISION
!>     Crecimiento recíproco del pivote. A la salida, contiene el factor
!>     de crecimiento del pivote recíproco norm(A)/norm(U). Se utiliza
!>     la norma inf. Si esto es mucho menor que 1, entonces la estabilidad
!>     de la factorización LU de la matriz A (equilibrada) podría ser pobre.
!>     Esto también significa que la solución X, los números de condición
!>     estimados y los límites de error podrían no ser fiables. Si la
!>     factorización falla con 0<INFO<=N, entonces esto contiene el factor
!>     de crecimiento recíproco del pivote para las columnas INFO principales
!>     de A.
!> 


BERR


!>          BERR es un arreglo DOUBLE PRECISION, de dimensión (NRHS)
!>     Error relativo de retroceso componente a componente. Este es el
!>     error relativo de retroceso componente a componente de cada vector
!>     solución X(j) (es decir, el cambio relativo más pequeño en cualquier
!>     elemento de A o B que hace que X(j) sea una solución exacta).
!> 


N_ERR_BNDS


!>          N_ERR_BNDS es INTEGER
!>     Número de límites de error a devolver para cada lado derecho
!>     y cada tipo (normwise o componente a componente). Véanse ERR_BNDS_NORM
!>     y ERR_BNDS_COMP a continuación.
!> 


ERR_BNDS_NORM


!>          ERR_BNDS_NORM es un arreglo DOUBLE PRECISION, de dimensión (NRHS, N_ERR_BNDS)
!>     Para cada lado derecho, esta matriz contiene información sobre
!>     varios límites de error y números de condición correspondientes al
!>     error relativo normwise, que se define de la siguiente manera:
!>
!>     Error relativo normwise en el i-ésimo vector solución:
!>             max_j (abs(XTRUE(j,i) - X(j,i)))
!>            ------------------------------
!>                  max_j abs(X(j,i))
!>
!>     La matriz se indexa por el tipo de información de error según se describe
!>     a continuación. Actualmente se devuelven hasta tres piezas de información.
!>
!>     El primer índice en ERR_BNDS_NORM(i,:) corresponde al i-ésimo
!>     lado derecho.
!>
!>     El segundo índice en ERR_BNDS_NORM(:,err) contiene los siguientes
!>     tres campos:
!>     err = 1  booleano. Confiar en la respuesta si el
!>              número de condición recíproco es menor que el umbral
!>              sqrt(n) * dlamch('Epsilon').
!>
!>     err = 2  límite de error: El error directo estimado,
!>              casi con seguridad dentro de un factor de 10 del error real
!>              siempre que la siguiente entrada sea mayor que el umbral
!>              sqrt(n) * dlamch('Epsilon'). Este límite de error solo debe
!>              confiarse si el booleano anterior es verdadero.
!>
!>     err = 3  Número de condición recíproco: Número de condición
!>              recíproco estimado normwise. Comparado con el umbral
!>              sqrt(n) * dlamch('Epsilon') para determinar si la estimación
!>              del error es . Estos números de condición
!>              recíprocos son 1 / (norm(Z^{-1},inf) * norm(Z,inf)) para alguna
!>              matriz Z apropiadamente escalada.
!>              Sea Z = S*A, donde S escala cada fila por una potencia de la
!>              base de modo que todas las sumas de filas absolutas de Z sean
!>              aproximadamente 1.
!>
!>     Consulte Lapack Working Note 165 para obtener más detalles y precauciones
!>     adicionales.
!> 


ERR_BNDS_COMP


!>          ERR_BNDS_COMP es un arreglo DOUBLE PRECISION, de dimensión (NRHS, N_ERR_BNDS)
!>     Para cada lado derecho, esta matriz contiene información sobre
!>     varios límites de error y números de condición correspondientes al
!>     error relativo componente a componente, que se define de la siguiente
!>     manera:
!>
!>     Error relativo componente a componente en el i-ésimo vector solución:
!>                    abs(XTRUE(j,i) - X(j,i))
!>             max_j ----------------------
!>                         abs(X(j,i))
!>
!>     La matriz se indexa por el lado derecho i (del que depende el error
!>     relativo componente a componente), y el tipo de información de error
!>     según se describe a continuación. Actualmente se devuelven hasta tres
!>     piezas de información para cada lado derecho. Si no se solicita
!>     precisión componente a componente (PARAMS(3) = 0.0), entonces
!>     ERR_BNDS_COMP no se accede. Si N_ERR_BNDS < 3, entonces como máximo
!>     se devuelven las primeras (:,N_ERR_BNDS) entradas.
!>
!>     El primer índice en ERR_BNDS_COMP(i,:) corresponde al i-ésimo
!>     lado derecho.
!>
!>     El segundo índice en ERR_BNDS_COMP(:,err) contiene los siguientes
!>     tres campos:
!>     err = 1  booleano. Confiar en la respuesta si el
!>              número de condición recíproco es menor que el umbral
!>              sqrt(n) * dlamch('Epsilon').
!>
!>     err = 2  límite de error: El error directo estimado,
!>              casi con seguridad dentro de un factor de 10 del error real
!>              siempre que la siguiente entrada sea mayor que el umbral
!>              sqrt(n) * dlamch('Epsilon'). Este límite de error solo debe
!>              confiarse si el booleano anterior es verdadero.
!>
!>     err = 3  Número de condición recíproco: Número de condición
!>              recíproco estimado componente a componente. Comparado con el
!>              umbral sqrt(n) * dlamch('Epsilon') para determinar si la
!>              estimación del error es . Estos números de condición
!>              recíprocos son 1 / (norm(Z^{-1},inf) * norm(Z,inf)) para alguna
!>              matriz Z apropiadamente escalada.
!>              Sea Z = S*(A*diag(x)), donde x es la solución para el
!>              lado derecho actual y S escala cada fila de
!>              A*diag(x) por una potencia de la base de modo que todas las
!>              sumas de filas absolutas de Z sean aproximadamente 1.
!>
!>     Consulte Lapack Working Note 165 para obtener más detalles y precauciones
!>     adicionales.
!> 


NPARAMS


!>          NPARAMS es INTEGER
!>     Especifica el número de parámetros establecidos en PARAMS. Si es <= 0,
!>     el arreglo PARAMS nunca se accede y se utilizan los valores predeterminados.
!> 


PARAMS


!>          PARAMS es un arreglo DOUBLE PRECISION, de dimensión NPARAMS
!>     Especifica los parámetros del algoritmo. Si una entrada es < 0.0,
!>     entonces esa entrada se rellenará con el valor predeterminado utilizado para ese
!>     parámetro. Solo se accede a las posiciones hasta NPARAMS; se utilizan
!>     predeterminados para los parámetros de mayor número.
!>
!>       PARAMS(LA_LINRX_ITREF_I = 1) : Si se debe realizar refinamiento
!>            iterativo o no.
!>         Predeterminado: 1.0D+0
!>            = 0.0:  No se realiza refinamiento y no se calculan límites de error.
!>            = 1.0:  Utiliza el algoritmo de refinamiento de precisión extra.
!>              (otros valores están reservados para uso futuro)
!>
!>       PARAMS(LA_LINRX_ITHRESH_I = 2) : Número máximo de residuales
!>            cálculos permitidos para el refinamiento.
!>         Predeterminado: 10
!>         Agresivo: Establecido en 100 para permitir la convergencia usando
!>                     factorizaciones aproximadas o factorizaciones distintas de LU. Si
!>                     la factorización utiliza una técnica distinta de la
!>                     eliminación gaussiana, las garantías en
!>                     err_bnds_norm y err_bnds_comp pueden ya no ser
!>                     fiables.
!>
!>       PARAMS(LA_LINRX_CWISE_I = 3) : Bandera que determina si el código
!>            intentará encontrar una solución con un error relativo componente
!>            a componente pequeño en el algoritmo de doble precisión. Positivo
!>            es verdadero, 0.0 es falso.
!>         Predeterminado: 1.0 (intentar convergencia componente a componente)
!> 


WORK


!>          WORK es un arreglo COMPLEX*16, de dimensión (2*N)
!> 


RWORK


!>          RWORK es un arreglo DOUBLE PRECISION, de dimensión (2*N)
!> 


INFO


!>          INFO es INTEGER
!>       = 0:  Salida exitosa. La solución de cada lado derecho está
!>         garantizada.
!>       < 0:  Si INFO = -i, el argumento i tuvo un valor ilegal
!>       > 0 y <= N:  U(INFO,INFO) es exactamente cero. La factorización
!>         se ha completado, pero el factor U es exactamente singular, por lo
!>         que la solución y los límites de error no pudieron calcularse. RCOND = 0
!>         se devuelve.
!>       = N+J: La solución correspondiente al lado derecho J
!>         no está garantizada. Las soluciones correspondientes a otros lados
!>         derechos K con K > J tampoco pueden estar garantizadas, pero
!>         solo se informa el primer lado derecho de este tipo. Si no se solicita
!>         un error componente a componente pequeño (PARAMS(3) = 0.0), entonces
!>         el lado derecho J es el primero con un límite de error normwise que no está
!>         garantizado.
!> 

eed (el más pequeño J
!>         tal que ERR_BNDS_NORM(J,1) = 0.0). Por defecto (PARAMS(3) = 1.0)
!>         el J-ésimo lado derecho es el primero con un límite de error
!>         norm-wise o componente-wise que no está garantizado (el más pequeño
!>         J tal que ERR_BNDS_NORM(J,1) = 0.0 o
!>         ERR_BNDS_COMP(J,1) = 0.0). Ver la definición de
!>         ERR_BNDS_NORM(:,1) y ERR_BNDS_COMP(:,1). Para obtener información
!>         sobre todos los lados derechos comprobar ERR_BNDS_NORM o
!>         ERR_BNDS_COMP.
!>
