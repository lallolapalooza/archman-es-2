Documentación de la función/subrutina

subrutina zpoequb (integer n, complex*16, dimension( lda, * ) a, integer lda, double precision, dimension( * ) s, double precision scond, double precision amax, integer info)

ZPOEQUB

Propósito:

!>
!> ZPOEQUB calcula escalados de fila y columna destinados a equilibrar una
!> matriz Hermítica positiva definida A y reducir su número de condición
!> (con respecto a la norma dos). S contiene los factores de escala,
!> S(i) = 1/sqrt(A(i,i)), elegidos de tal manera que la matriz escalada B con
!> elementos B(i,j) = S(i)*A(i,j)*S(j) tenga unos en la diagonal. Esta
!> elección de S pone el número de condición de B dentro de un factor N del
!> menor número de condición posible sobre todos los escalados diagonales posibles.
!>
!> Esta rutina difiere de ZPOEQU al restringir los factores de escala
!> a una potencia de la base. Salvo desbordamiento y subdesbordamiento,
!> el escalado por estos factores no introduce errores de redondeo adicionales.
!> Sin embargo, las entradas diagonales escaladas ya no son aproximadamente 1,
!> sino que se encuentran entre sqrt(radix) y 1/sqrt(radix).
!>

Parámetros

N 
!>          N es ENTERO
!>          El orden de la matriz A. N >= 0.
!>

A

!>          A es un array COMPLEX*16, dimensión (LDA,N)
!>          La matriz Hermítica positiva definida de N por N cuyos factores de
!>          escala se van a calcular. Solo se referencian los elementos diagonales de A.
!>

LDA

!>          LDA es ENTERO
!>          La dimensión principal del array A. LDA >= max(1,N).
!>

S

!>          S es un array DOUBLE PRECISION, dimensión (N)
!>          Si INFO = 0, S contiene los factores de escala para A.
!>

SCOND

!>          SCOND es DOUBLE PRECISION
!>          Si INFO = 0, S contiene la relación del S(i) más pequeño con
!>          el S(i) más grande. Si SCOND >= 0.1 y AMAX no es ni demasiado
!>          grande ni demasiado pequeño, no vale la pena escalar con S.
!>

AMAX

!>          AMAX es DOUBLE PRECISION
!>          Valor absoluto del elemento de matriz más grande. Si AMAX está muy
!>          cerca del desbordamiento o muy cerca del subdesbordamiento,
!>          la matriz debe escalarse.
!>

INFO

!>          INFO es ENTERO
!>          = 0:  Salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tuvo un valor ilegal
!>          > 0:  si INFO = i, el i-ésimo elemento diagonal no es positivo.
!>
