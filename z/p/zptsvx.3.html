ZPTSVX calcula la solución al sistema de ecuaciones lineales A * X = B para matrices PT

Propósito:

!>
!> ZPTSVX utiliza la factorización A = L*D*L**H para calcular la solución
!> de un sistema complejo de ecuaciones lineales A*X = B, donde A es una
!> matriz tridiagonal hermitiana positiva definida de orden N y X y B
!> son matrices de N por NRHS.
!>
!> También se proporcionan límites de error en la solución y una estimación
!> de la condición.
!>

Descripción:

!>
!> Se realizan los siguientes pasos:
!>
!> 1. Si FACT = 'N', la matriz A se factoriza como A = L*D*L**H, donde L
!>    es una matriz bidiagonal inferior unitaria y D es diagonal. La
!>    factorización también puede considerarse de la forma
!>    A = U**H*D*U.
!>
!> 2. Si el menor principal principal de orden i no es positivo,
!>    la rutina devuelve INFO = i. De lo contrario, la forma factorizada
!>    de A se utiliza para estimar el número de condición de la matriz
!>    A. Si el recíproco del número de condición es menor que la precisión
!>    de la máquina, se devuelve INFO = N+1 como advertencia, pero la rutina
!>    continúa resolviendo para X y calculando los límites de error como
!>    se describe a continuación.
!>
!> 3. El sistema de ecuaciones se resuelve para X utilizando la forma factorizada
!>    de A.
!>
!> 4. Se aplica refinamiento iterativo para mejorar la solución calculada
!>    y calcular los límites de error y las estimaciones de error hacia atrás
!>    para la misma.
!>

Parámetros

FACT 
!>          FACT es CHARACTER*1
!>          Especifica si la forma factorizada de la matriz
!>          A se proporciona o no en la entrada.
!>          = 'F':  En la entrada, DF y EF contienen la forma factorizada de A.
!>                  D, E, DF y EF no se modificarán.
!>          = 'N':  La matriz A se copiará en DF y EF y
!>                  se factorizará.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de lados derechos, es decir, el número de columnas
!>          de las matrices B y X.  NRHS >= 0.
!>

D

!>          D es un array DOUBLE PRECISION, dimensión (N)
!>          Los n elementos diagonales de la matriz tridiagonal A.
!>

E

!>          E es un array COMPLEX*16, dimensión (N-1)
!>          Los n-1 elementos subdiagonales de la matriz tridiagonal A.
!>

DF

!>          DF es un array DOUBLE PRECISION, dimensión (N)
!>          Si FACT = 'F', entonces DF es un argumento de entrada y en la entrada
!>          contiene los n elementos diagonales de la matriz diagonal D
!>          de la factorización L*D*L**H de A.
!>          Si FACT = 'N', entonces DF es un argumento de salida y en la salida
!>          contiene los n elementos diagonales de la matriz diagonal D
!>          de la factorización L*D*L**H de A.
!>

EF

!>          EF es un array COMPLEX*16, dimensión (N-1)
!>          Si FACT = 'F', entonces EF es un argumento de entrada y en la entrada
!>          contiene los n-1 elementos subdiagonales del factor unitario
!>          bidiagonal L de la factorización L*D*L**H de A.
!>          Si FACT = 'N', entonces EF es un argumento de salida y en la salida
!>          contiene los n-1 elementos subdiagonales del factor unitario
!>          bidiagonal L de la factorización L*D*L**H de A.
!>

B

!>          B es un array COMPLEX*16, dimensión (LDB,NRHS)
!>          La matriz del lado derecho B de N por NRHS.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B.  LDB >= max(1,N).
!>

X

!>          X es un array COMPLEX*16, dimensión (LDX,NRHS)
!>          Si INFO = 0 o INFO = N+1, la matriz solución X de N por NRHS.
!>

LDX

!>          LDX es INTEGER
!>          La dimensión principal del array X.  LDX >= max(1,N).
!>

RCOND

!>          RCOND es DOUBLE PRECISION
!>          El número de condición recíproco de la matriz A. Si RCOND
!>          es menor que la precisión de la máquina (en particular, si
!>          RCOND = 0), la matriz es singular con precisión de trabajo.
!>          Esta condición se indica con un código de retorno INFO > 0.
!>

FERR

!>          FERR es un array DOUBLE PRECISION, dimensión (NRHS)
!>          El límite de error hacia adelante para cada vector solución
!>          X(j) (la j-ésima columna de la matriz solución X).
!>          Si XTRUE es la solución verdadera correspondiente a X(j), FERR(j)
!>          es un límite superior estimado para la magnitud del elemento más
!>          grande en (X(j) - XTRUE) dividido por la magnitud del elemento más
!>          grande en X(j).
!>

BERR

!>          BERR es un array DOUBLE PRECISION, dimensión (NRHS)
!>          El error hacia atrás relativo componente a componente de cada vector solución
!>          X(j) (es decir, el cambio relativo más pequeño en cualquier
!>          elemento de A o B que hace que X(j) sea una solución exacta).
!>

WORK

!>          WORK es un array COMPLEX*16, dimensión (N)
!>

RWORK

!>          RWORK es un array DOUBLE PRECISION, dimensión (N)
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>          > 0:  si INFO = i, y i es
!>                <= N:  el menor principal principal de orden i de A
!>                       no es positivo, por lo que la factorización no pudo
!>                       completarse y la solución no se ha calculado.
!>                       Se devuelve RCOND = 0.
!>                = N+1: U es no singular, pero RCOND es menor que la precisión
!>                       de la máquina, lo que significa que la matriz es singular
!>                       para la precisión de trabajo. Sin embargo, la
!>                       solución y los límites de error se calculan porque
!>                       hay varias situaciones en las que la solución calculada
!>                       puede ser más precisa que el valor de RCOND sugeriría.
!>

NAME

zptsvx - Solves a complex system of linear equations A*X = B where A is a general band matrix, using the LUBAND decomposition.

SYNOPSIS

SUBROUTINE ZPTSVX(FACT, TRANS, N, NRHS, DLB, DUB, RB, SUBB, LDASUB, AFB, LDAFB, IPIV, B, LDB, X, LDX, RCOND, FERR, BERR, INFO)

INTEGER N, NRHS, LDASUB, LDAFB, LDB, LDX CHARACTER * ( * ) FACT, TRANS COMPLEX*16 DLB( * ), DUB( * ), RB( * ), SUBB( * ), AFB( * ), B( * ), X( * ) INTEGER IPIV( * ) DOUBLE PRECISION RCOND DOUBLE PRECISION FERR( * ), BERR( * ) INTEGER INFO

Function/Subroutine Documentation

ZPTSVX uses the Left-Looking Banded LU decomposition with partial pivoting (ZGBTRF) to solve the system of equations:

A*X = B

where A is an N-by-N complex band matrix with KL subdiagonals and KU superdiagonals.

The LUBAND decomposition is applied to A. The factorization is computed only once, and then used to solve the system for multiple right-hand sides.

Arguments:

  • FACT: CHARACTER*1. Specifies whether or not the factorization of A has been computed and stored in AFB.
    • 'E' (Equilibrate): The input matrix A is not factored. The LUBAND decomposition will be computed in the arrays DLB, DUB, RB, SUBB, and AFB.
    • 'N' (Not factored): The factorization of A is already stored in AFB.
  • TRANS: CHARACTER*1. Specifies the form of the system of equations:
    • 'N' (No transpose): A*X = B (default)
    • 'T' (Transpose): AT*X = B
    • 'C' (Conjugate transpose): AH*X = B
  • N: INTEGER. The order of the matrix A.
  • NRHS: INTEGER. The number of right-hand sides, i.e., the number of columns in the arrays B and X.
  • DLB: COMPLEX*16 array, dimension (KL). The LU decomposition of the lower band part of A.
  • DUB: COMPLEX*16 array, dimension (KU). The LU decomposition of the upper band part of A.
  • RB: COMPLEX*16 array, dimension (KL). The LU decomposition of the lower band part of A.
  • SUBB: COMPLEX*16 array, dimension (KL). The LU decomposition of the lower band part of A.
  • LDASUB: INTEGER. The leading dimension of the array SUBB.
  • AFB: COMPLEX*16 array, dimension (LDAFB, N). The LU decomposition of the band matrix A.
  • LDAFB: INTEGER. The leading dimension of the array AFB.
  • IPIV: INTEGER array, dimension (MIN(N, KL+KU+1)). Pivots indicating the row interchanges during the LU decomposition.
  • B: COMPLEX*16 array, dimension (LDB, NRHS). On entry, the right-hand side matrix B. On exit, B is overwritten by the solution matrix X.
  • LDB: INTEGER. The leading dimension of the array B.
  • X: COMPLEX*16 array, dimension (LDX, NRHS). On exit, the solution matrix X.
  • LDX: INTEGER. The leading dimension of the array X.
  • RCOND: DOUBLE PRECISION. On exit, an estimate of the reciprocal of the condition number of A.
  • FERR: DOUBLE PRECISION array, dimension (NRHS). On exit, an estimate of the forward error bound for each column of X.
  • BERR: DOUBLE PRECISION array, dimension (NRHS). On exit, an estimate of the backward error bound for each column of X.
  • INFO: INTEGER.
    • 0: Successful exit.
    • <0: If -i, the i-th argument had an illegal value.
    • >0: If `i`, `i` diagonal elements of the LUBAND decomposed matrix `A` are zero, so the decomposition is singular.
