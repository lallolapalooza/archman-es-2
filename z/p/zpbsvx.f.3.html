subrutina zpbsvx (character fact, character uplo, integer n, integer kd, integer nrhs, complex*16, dimension( ldab, * ) ab, integer ldab, complex*16, dimension( ldafb, * ) afb, integer ldafb, character equed, double precision, dimension( * ) s, complex*16, dimension( ldb, * ) b, integer ldb, complex*16, dimension( ldx, * ) x, integer ldx, double precision rcond, double precision, dimension( * ) ferr, double precision, dimension( * ) berr, complex*16, dimension( * ) work, double precision, dimension( * ) rwork, integer info)

ZPBSVX calcula la solución al sistema de ecuaciones lineales A * X = B para matrices OTROS

Propósito:

!>
!> ZPBSVX utiliza la factorización de Cholesky A = U**H*U o A = L*L**H para
!> calcular la solución a un sistema complejo de ecuaciones lineales
!>    A * X = B,
!> donde A es una matriz de banda Hermitiana positiva definida de tamaño N x N y X
!> e B son matrices de tamaño N x NRHS.
!>
!> También se proporcionan cotas de error en la solución y una estimación de la condición.
!>

Descripción:

!>
!> Se realizan los siguientes pasos:
!>
!> 1. Si FACT = 'E', se calculan factores de escala reales para equilibrar
!>    el sistema:
!>       diag(S) * A * diag(S) * inv(diag(S)) * X = diag(S) * B
!>    Si el sistema se va a equilibrar o no depende del
!>    escalado de la matriz A, pero si se utiliza el equilibrado, A se
!>    sobrescribe con diag(S)*A*diag(S) y B con diag(S)*B.
!>
!> 2. Si FACT = 'N' o 'E', se utiliza la descomposición de Cholesky para
!>    factorizar la matriz A (después del equilibrado si FACT = 'E') como
!>       A = U**H * U,  si UPLO = 'U', o
!>       A = L * L**H,  si UPLO = 'L',
!>    donde U es una matriz de banda triangular superior, y L es una matriz de banda triangular inferior.
!>
!> 3. Si el menor principal principal de orden i no es positivo,
!>    entonces la rutina regresa con INFO = i. De lo contrario, la forma factorizada
!>    de A se utiliza para estimar el número de condición de la matriz
!>    A.  Si el recíproco del número de condición es menor que la precisión de la máquina,
!>    INFO = N+1 se regresa como una advertencia, pero la rutina
!>    aún continúa resolviendo X y calculando cotas de error como
!>    se describe a continuación.
!>
!> 4. El sistema de ecuaciones se resuelve para X utilizando la forma factorizada
!>    de A.
!>
!> 5. Se aplica refinamiento iterativo para mejorar la solución calculada
!>    la matriz y calcular cotas de error y estimaciones de error hacia atrás
!>    para ella.
!>
!> 6. Si se utilizó el equilibrado, la matriz X se premultiplica por
!>    diag(S) para que resuelva el sistema original antes de
!>    el equilibrado.
!>

Parámetros

FACT 
!>          FACT es CHARACTER*1
!>          Especifica si la forma factorizada de la matriz A se
!>          proporciona en la entrada, y si no, si la matriz A debe ser
!>          equilibrada antes de factorizarla.
!>          = 'F':  En la entrada, AFB contiene la forma factorizada de A.
!>                  Si EQUED = 'Y', la matriz A ha sido equilibrada
!>                  con factores de escala dados por S.  AB y AFB no
!>                  serán modificados.
!>          = 'N':  La matriz A se copiará a AFB y se factorizará.
!>          = 'E':  La matriz A se equilibrará si es necesario, luego
!>                  se copiará a AFB y se factorizará.
!>

UPLO

!>          UPLO es CHARACTER*1
!>          = 'U':  Se almacena el triángulo superior de A;
!>          = 'L':  Se almacena el triángulo inferior de A.
!>

N

!>          N es INTEGER
!>          El número de ecuaciones lineales, es decir, el orden de
!>          la matriz A.  N >= 0.
!>

KD

!>          KD es INTEGER
!>          El número de superdiagonales de la matriz A si UPLO = 'U',
!>          o el número de subdiagonales si UPLO = 'L'.  KD >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de lados derechos, es decir, el número de columnas
!>          de las matrices B y X.  NRHS >= 0.
!>

AB

!>          AB es COMPLEX*16 array, dimension (LDAB,N)
!>          En la entrada, el triángulo superior o inferior de la matriz de banda Hermitiana
!>          A, almacenado en las primeras KD+1 filas del array, excepto
!>          si FACT = 'F' y EQUED = 'Y', entonces A debe contener la
!>          matriz equilibrada diag(S)*A*diag(S).  La j-ésima columna de A
!>          se almacena en la j-ésima columna del array AB como sigue:
!>          si UPLO = 'U', AB(KD+1+i-j,j) = A(i,j) para max(1,j-KD)<=i<=j;
!>          si UPLO = 'L', AB(1+i-j,j)    = A(i,j) para j<=i<=min(N,j+KD).
!>          Ver más detalles abajo.
!>
!>          En la salida, si FACT = 'E' y EQUED = 'Y', A se sobrescribe con
!>          diag(S)*A*diag(S).
!>

LDAB

!>          LDAB es INTEGER
!>          La dimensión principal del array A.  LDAB >= KD+1.
!>

AFB

!>          AFB es COMPLEX*16 array, dimension (LDAFB,N)
!>          Si FACT = 'F', entonces AFB es un argumento de entrada y en la entrada
!>          contiene el factor triangular U o L de la factorización de Cholesky
!>          A = U**H *U o A = L*L**H de la matriz de banda
!>          A, en el mismo formato de almacenamiento que A (ver AB). Si EQUED = 'Y',
!>          entonces AFB es la forma factorizada de la matriz A equilibrada.
!>
!>          Si FACT = 'N', entonces AFB es un argumento de salida y en la salida
!>          devuelve el factor triangular U o L de la factorización de Cholesky
!>          A = U**H *U o A = L*L**H.
!>
!>          Si FACT = 'E', entonces AFB es un argumento de salida y en la salida
!>          devuelve el factor triangular U o L de la factorización de Cholesky
!>          A = U**H *U o A = L*L**H de la matriz equilibrada
!>          (ver la descripción de A para la forma de la
!>          matriz equilibrada).
!>

LDAFB

!>          LDAFB es INTEGER
!>          La dimensión principal del array AFB.  LDAFB >= KD+1.
!>

EQUED

!>          EQUED es CHARACTER*1
!>          Especifica la forma de equilibrado que se realizó.
!>          = 'N':  Sin equilibrado (siempre verdadero si FACT = 'N').
!>          = 'Y':  Se realizó el equilibrado, es decir, A ha sido reemplazada por
!>                  diag(S) * A * diag(S).
!>          EQUED es un argumento de entrada si FACT = 'F'; de lo contrario, es un
!>          argumento de salida.
!>

S

!>          S es DOUBLE PRECISION array, dimension (N)
!>          Los factores de escala para A; no se accede si EQUED = 'N'.  S es
!>          un argumento de entrada si FACT = 'F'; de lo contrario, S es un argumento de
!>          salida.  Si FACT = 'F' y EQUED = 'Y', cada elemento de S
!>          debe ser positivo.
!>

B

!>          B es COMPLEX*16 array, dimension (LDB,NRHS)
!>          En la entrada, la matriz B del lado derecho N x NRHS.
!>          En la salida, si EQUED = 'N', B no se modifica; si EQUED = 'Y',
!>          B se sobrescribe con diag(S) * B.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B.  LDB >= max(1,N).
!>

X

!>          X es COMPLEX*16 array,



X


X – solve a system of linear equations







SYNOPSIS


SUBROUTINE ZPBSRVX(
   UPLO, N, KD, NRHS, AB, LDAB, B, LDB, X, LDX, RCOND, FERR, BERR, WORK,
   RWORK, INFO
   )

   CHARACTER * 1                   :: UPLO
   INTEGER                         :: N, KD, NRHS, LDAB, LDB, LDX, INFO
   COMPLEX*16                      :: AB( LDAB, * ), B( LDB, * ), X( LDX, * )
   DOUBLE PRECISION                :: RCOND, FERR( * ), BERR( * )
   COMPLEX*16                      :: WORK( * )
   DOUBLE PRECISION                :: RWORK( * )








Function/Subroutine Documentation


ZPBSRVX solves a system of complex Hermitian positive definite
    band linear equations


     A * X = B,



where A is a complex Hermitian positive definite band matrix, X is the
    solution matrix, and B is the right-hand side matrix. Various
    precomputation steps are performed, to give SRFA a choice of algorithms.


A is a band matrix of bandwidth KD, which is assumed to be stored
    in COMPLEX*16 array AB, such that the local elements of the matrix A are
    stored in the columns of AB. See Further Details for the exact format.


This routine is the driver routine for the symmetric band positive
    definite, Hermitian band positive definite, and related update problems.


Arguments:




UPLO


UPLO is CHARACTER * 1


= 'U': Upper triangle of A is stored and will be used.


= 'L': Lower triangle of A is stored and will be used.


N


N is INTEGER


The order of the matrix A. N >= 0.


KD


KD is INTEGER


The number of super-diagonals plus the main diagonal of the matrix.


0 <= KD <= N-1.


NRHS


NRHS is INTEGER


The number of columns in the arrays B and X. NRHS >= 0.


AB


AB is COMPLEX*16 array, dimension (LDAB,K+1)


On entry, the upper or lower triangle of the Hermitian band matrix A,
        stored column by column. The columns of AB are indexed from 1 to
        K+1. See Further Details.


On exit, if EQUED = 'Y', AB is overwritten by diag(S)*A*inv(diag(S)).


LDAB


LDAB is INTEGER


The leading dimension of the array AB. LDAB >= max(1,N).


B


B is COMPLEX*16 array, dimension (LDB,NRHS)


On entry, the right-hand side matrix B.


On exit, if EQUED = 'Y', B is overwritten by diag(S)*B.


LDB


LDB is INTEGER


The leading dimension of the array B.


LDB >= max(1,N).


X


X is COMPLEX*16 array, dimension (LDX,NRHS)


If INFO = 0 or INFO = N+1, the N-by-NRHS solution matrix X to the
        original system of equations. Note that if EQUED = 'Y', A and B
        are modified on exit, and the solution to the equilibrated system
        is inv(diag(S))*X.


LDX


LDX is INTEGER


The leading dimension of the array X. LDX >= max(1,N).


RCOND


RCOND is DOUBLE PRECISION


The estimate of the reciprocal condition number of the matrix A after
        equilibration (if done). If RCOND is less than the machine
        precision (in particular, if RCOND = 0), the matrix is singular
        to working precision. This condition is indicated by a return code
        of INFO > 0.


FERR


FERR is DOUBLE PRECISION array, dimension (NRHS)


The estimated forward error bound for each solution vector X(j) (the j-th
        column of the solution matrix X). If XTRUE is the true solution
        corresponding to X(j), FERR(j) is an estimated upper bound for the
        magnitude of the largest element in (X(j) - XTRUE) divided by the
        magnitude of the largest element in X(j). The estimate is as reliable
        as the estimate for RCOND, and is almost always a slight
        overestimate of the true error.


BERR


BERR is DOUBLE PRECISION array, dimension (NRHS)


The componentwise relative backward error of each solution vector X(j)
        (i.e., the smallest relative change in any element of A or B that
        makes X(j) an exact solution).


WORK


WORK is COMPLEX*16 array, dimension (2*N)


RWORK


RWORK is DOUBLE PRECISION array, dimension (N)


INFO


INFO is INTEGER


= 0: successful exit


< 0: if INFO = -i, the i-th argument had an illegal value


> 0: if INFO = i, and i is


<= N: the leading principal minor of order i of A is not positive,
        so the factorization could not be completed, and the solution
        has not been computed. RCOND = 0 is returned.


= N+1: U is nonsingular, but RCOND is less than machine precision,
        meaning that the matrix is singular to working precision.
        Nevertheless, the solution and error bounds are computed because
        there are a number of situations where the computed solution can
        be more accurate than the value of RCOND would suggest.

Further Details


  The band storage scheme is illustrated by the following example, when
  N = 6, KD = 2, and UPLO = 'U':

  Two-dimensional storage of the Hermitian matrix A:

     a11  a12  a13
          a22  a23  a24
               a33  a34  a35
                    a44  a45  a46
                         a55  a56
     (aij=conjg(aji))         a66

  Band storage of the upper triangle of A:

     *    *   a13  a24  a35  a46
     *   a12  a23  a34  a45  a56
    a11  a22  a33  a44  a55  a66

  Array elements marked * are not used by the routine.

  Similarly, if UPLO = 'L' the format of A is as follows:

     a11  a22  a33  a44  a55  a66
     a21  a32  a43  a54  a65   *
     a31  a42  a53  a64   *    *

  Array elements marked * are not used by the routine.
