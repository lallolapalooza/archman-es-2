ZPPSVX calcula la solución al sistema de ecuaciones lineales A * X = B para matrices OTHER

Propósito:

!>
!> ZPPSVX utiliza la factorización de Cholesky A = U**H * U o A = L * L**H para
!> calcular la solución a un sistema complejo de ecuaciones lineales
!>    A * X = B,
!> donde A es una matriz Hermítica positiva definida de N por N almacenada en
!> formato empaquetado y X y B son matrices de N por NRHS.
!>
!> También se proporcionan límites de error en la solución y una estimación de la condición.
!>

Descripción:

!>
!> Se realizan los siguientes pasos:
!>
!> 1. Si FACT = 'E', se calculan factores de escala reales para equilibrar
!>    el sistema:
!>       diag(S) * A * diag(S) * inv(diag(S)) * X = diag(S) * B
!>    Si el sistema se va a equilibrar o no, depende del escalado de
!>    la matriz A, pero si se utiliza el equilibrado, A se sobrescribe con
!>    diag(S)*A*diag(S) y B con diag(S)*B.
!>
!> 2. Si FACT = 'N' o 'E', se utiliza la descomposición de Cholesky para
!>    factorizar la matriz A (después del equilibrado si FACT = 'E') como
!>       A = U**H * U ,  si UPLO = 'U', o
!>       A = L * L**H,  si UPLO = 'L',
!>    donde U es una matriz triangular superior, L es una matriz triangular
!>    inferior, y **H indica la traspuesta conjugada.
!>
!> 3. Si el menor principal principal de orden i no es positivo,
!>    entonces la rutina retorna con INFO = i. De lo contrario, la forma factorizada
!>    de A se utiliza para estimar el número de condición de la matriz
!>    A. Si la inversa del número de condición es menor que la precisión de la máquina,
!>    se retorna INFO = N+1 como una advertencia, pero la rutina
!>    continúa resolviendo para X y calculando los límites de error como
!>    se describe a continuación.
!>
!> 4. El sistema de ecuaciones se resuelve para X utilizando la forma factorizada
!>    de A.
!>
!> 5. Se aplica refinamiento iterativo para mejorar la solución calculada
!>    matriz y calcular los límites de error y las estimaciones de error hacia atrás
!>    para ella.
!>
!> 6. Si se utilizó el equilibrado, la matriz X se premultiplica por
!>    diag(S) para que resuelva el sistema original antes de
!>    el equilibrado.
!>

Parámetros

FACT 
!>          FACT es CHARACTER*1
!>          Especifica si la forma factorizada de la matriz A se
!>          suministra en la entrada, y si no, si la matriz A debe ser
!>          equilibrada antes de ser factorizada.
!>          = 'F':  En la entrada, AFP contiene la forma factorizada de A.
!>                  Si EQUED = 'Y', la matriz A ha sido equilibrada
!>                  con factores de escala dados por S. AP y AFP no
!>                  serán modificados.
!>          = 'N':  La matriz A se copiará a AFP y se factorizará.
!>          = 'E':  La matriz A se equilibrará si es necesario, luego
!>                  se copiará a AFP y se factorizará.
!>

UPLO

!>          UPLO es CHARACTER*1
!>          = 'U':  Se almacena el triángulo superior de A;
!>          = 'L':  Se almacena el triángulo inferior de A.
!>

N

!>          N es INTEGER
!>          El número de ecuaciones lineales, es decir, el orden de
!>          la matriz A.  N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de lados derechos, es decir, el número de columnas
!>          de las matrices B y X.  NRHS >= 0.
!>

AP

!>          AP es un array COMPLEX*16, dimensión (N*(N+1)/2)
!>          En la entrada, el triángulo superior o inferior de la matriz Hermítica
!>          A, empaquetado por columnas en un array lineal, excepto si FACT = 'F'
!>          y EQUED = 'Y', entonces A debe contener la matriz equilibrada
!>          diag(S)*A*diag(S). La j-ésima columna de A se almacena en el
!>          array AP como sigue:
!>          si UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) para 1<=i<=j;
!>          si UPLO = 'L', AP(i + (j-1)*(2n-j)/2) = A(i,j) para j<=i<=n.
!>          Ver más abajo para más detalles. A no se modifica si
!>          FACT = 'F' o 'N', o si FACT = 'E' y EQUED = 'N' en la salida.
!>
!>          En la salida, si FACT = 'E' y EQUED = 'Y', A se sobrescribe con
!>          diag(S)*A*diag(S).
!>

AFP

!>          AFP es un array COMPLEX*16, dimensión (N*(N+1)/2)
!>          Si FACT = 'F', entonces AFP es un argumento de entrada y en la entrada
!>          contiene el factor triangular U o L de la factorización de Cholesky
!>          A = U**H*U o A = L*L**H, en el mismo formato de almacenamiento
!>          que A. Si EQUED .ne. 'N', entonces AFP es la forma factorizada
!>          de la matriz equilibrada A.
!>
!>          Si FACT = 'N', entonces AFP es un argumento de salida y en la salida
!>          retorna el factor triangular U o L de la factorización de Cholesky
!>          A = U**H * U o A = L * L**H de la matriz original
!>          A.
!>
!>          Si FACT = 'E', entonces AFP es un argumento de salida y en la salida
!>          retorna el factor triangular U o L de la factorización de Cholesky
!>          A = U**H * U o A = L * L**H de la matriz equilibrada
!>          A (ver la descripción de AP para la forma de la
!>          matriz equilibrada).
!>

EQUED

!>          EQUED es CHARACTER*1
!>          Especifica la forma de equilibrado que se realizó.
!>          = 'N':  Sin equilibrado (siempre verdadero si FACT = 'N').
!>          = 'Y':  Se realizó equilibrado, es decir, A ha sido reemplazada por
!>                  diag(S) * A * diag(S).
!>          EQUED es un argumento de entrada si FACT = 'F'; de lo contrario, es un
!>          argumento de salida.
!>

S

!>          S es un array DOUBLE PRECISION, dimensión (N)
!>          Los factores de escala para A; no se accede si EQUED = 'N'. S es
!>          un argumento de entrada si FACT = 'F'; de lo contrario, S es un
!>          argumento de salida. Si FACT = 'F' y EQUED = 'Y', cada elemento de S
!>          debe ser positivo.
!>

B

!>          B es un array COMPLEX*16, dimensión (LDB,NRHS)
!>          En la entrada, la matriz del lado derecho B de N por NRHS.
!>          En la salida, si EQUED = 'N', B no se modifica; si EQUED = 'Y',
!>          B se sobrescribe con diag(S) * B.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B.  LDB >= max(1,N).
!>

X

!>          X es un array COMPLEX*16, dimensión (LDX,NRHS)
!>          Si INFO = 0 o INFO = N+1, la matriz solución X de N por NRHS
!>          del sistema original de ecuaciones.  Tenga en cuenta que si EQUED = 'Y',
!>          A y B se modifican en la salida, y la solución del
!>          sistema equilibrado es inv(diag(S))*X.
!>

LDX

!>          LDX es INTEGER
!>          La dimensión principal del array X.  LDX >= max(1,N).
!>

RCOND

!>          RCOND is DOUBLE PRECISION
!>          An estimate of the reciprocal condition number of the matrix
!>          A after equilibration (if done).  If RCOND is less than the
!>          machine precision (in particular, if RCOND = 0), the matrix
!>          is singular to working precision.  This condition is
!>          indicated by a return code of INFO > 0.
!>

FERR

!>          FERR is DOUBLE PRECISION array, dimension (NRHS)
!>          The estimated forward error bound for each solution vector
!>          X(j) (the j-th column of the solution matrix X).
!>          If XTRUE is the true solution corresponding to X(j), FERR(j)
!>          is an estimated upper bound for the magnitude of the largest
!>          element in (X(j) - XTRUE) divided by the magnitude of the
!>          largest element in X(j).  The estimate is as reliable as
!>          the estimate for RCOND, and is almost always a slight
!>          overestimate of the true error.
!>

BERR

!>          BERR is DOUBLE PRECISION array, dimension (NRHS)
!>          The componentwise relative backward error of each solution
!>          vector X(j) (i.e., the smallest relative change in
!>          any element of A or B that makes X(j) an exact solution).
!>

WORK

!>          WORK is COMPLEX*16 array, dimension (2*N)
!>

RWORK

!>          RWORK is DOUBLE PRECISION array, dimension (N)
!>

INFO

!>          INFO is INTEGER
!>          = 0:  successful exit
!>          < 0:  if INFO = -i, the i-th argument had an illegal value
!>          > 0:  if INFO = i, and i is
!>                <= N:  the leading principal minor of order i of A
!>                       is not positive, so the factorization could not
!>                       be completed, and the solution has not been
!>                       computed. RCOND = 0 is returned.
!>                = N+1: U is nonsingular, but RCOND is less than machine
!>                       precision, meaning that the matrix is singular
!>                       to working precision.  Nevertheless, the
!>                       solution and error bounds are computed because
!>                       there are a number of situations where the
!>                       computed solution can be more accurate than the
!>                       value of RCOND would suggest.
!>
