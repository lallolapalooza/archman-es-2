ZPBSVX calcula la solución al sistema de ecuaciones lineales A * X = B para matrices OTROS

Propósito:

!>
!> ZPBSVX utiliza la factorización de Cholesky A = U**H*U o A = L*L**H para
!> calcular la solución a un sistema complejo de ecuaciones lineales
!>    A * X = B,
!> donde A es una matriz de banda Hermitiana positiva definida de NxN y X
!> e B son matrices de NxNRHS.
!>
!> También se proporcionan límites de error en la solución y una estimación de la condición.
!>

Descripción:

!>
!> Se realizan los siguientes pasos:
!>
!> 1. Si FACT = 'E', se calculan factores de escala reales para equilibrar
!>    el sistema:
!>       diag(S) * A * diag(S) * inv(diag(S)) * X = diag(S) * B
!>    Si el sistema se equilibrará o no depende de la
!>    escala de la matriz A, pero si se utiliza el equilibrado, A se
!>    sobrescribe con diag(S)*A*diag(S) y B con diag(S)*B.
!>
!> 2. Si FACT = 'N' o 'E', se utiliza la descomposición de Cholesky para
!>    factorizar la matriz A (después del equilibrado si FACT = 'E') como
!>       A = U**H * U,  si UPLO = 'U', o
!>       A = L * L**H,  si UPLO = 'L',
!>    donde U es una matriz de banda triangular superior y L es una matriz de banda triangular inferior.
!>
!> 3. Si el menor principal principal de orden i no es positivo,
!>    entonces la rutina regresa con INFO = i. De lo contrario, la forma factorizada
!>    de A se utiliza para estimar el número de condición de la matriz
!>    A. Si la recíproca del número de condición es menor que la precisión de la máquina,
!>    se devuelve INFO = N+1 como advertencia, pero la rutina
!>    continúa para resolver X y calcular los límites de error como
!>    se describe a continuación.
!>
!> 4. El sistema de ecuaciones se resuelve para X utilizando la forma factorizada
!>    de A.
!>
!> 5. Se aplica refinamiento iterativo para mejorar la matriz solución calculada
!>    y calcular los límites de error y las estimaciones de error hacia atrás
!>    para la misma.
!>
!> 6. Si se utilizó el equilibrado, la matriz X se premultiplica por
!>    diag(S) para que resuelva el sistema original antes de
!>    el equilibrado.
!>

Parámetros

FACT 
!>          FACT es CHARACTER*1
!>          Especifica si la forma factorizada de la matriz A se
!>          suministra en la entrada, y si no, si la matriz A debe ser
!>          equilibrada antes de ser factorizada.
!>          = 'F':  En la entrada, AFB contiene la forma factorizada de A.
!>                  Si EQUED = 'Y', la matriz A ha sido equilibrada
!>                  con factores de escala dados por S. AB y AFB no
!>                  serán modificados.
!>          = 'N':  La matriz A se copiará en AFB y se factorizará.
!>          = 'E':  La matriz A se equilibrará si es necesario, luego
!>                  se copiará en AFB y se factorizará.
!>

UPLO

!>          UPLO es CHARACTER*1
!>          = 'U':  Se almacena el triángulo superior de A;
!>          = 'L':  Se almacena el triángulo inferior de A.
!>

N

!>          N es INTEGER
!>          El número de ecuaciones lineales, es decir, el orden de
!>          la matriz A.  N >= 0.
!>

KD

!>          KD es INTEGER
!>          El número de superdiagonales de la matriz A si UPLO = 'U',
!>          o el número de subdiagonales si UPLO = 'L'.  KD >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de lados derechos, es decir, el número de columnas
!>          de las matrices B y X.  NRHS >= 0.
!>

AB

!>          AB es una matriz COMPLEX*16, dimensión (LDAB,N)
!>          En la entrada, el triángulo superior o inferior de la matriz de banda Hermitiana
!>          A, almacenada en las primeras KD+1 filas de la matriz, excepto
!>          si FACT = 'F' y EQUED = 'Y', entonces A debe contener la
!>          matriz equilibrada diag(S)*A*diag(S).  La j-ésima columna de A
!>          se almacena en la j-ésima columna de la matriz AB de la siguiente manera:
!>          si UPLO = 'U', AB(KD+1+i-j,j) = A(i,j) para max(1,j-KD)<=i<=j;
!>          si UPLO = 'L', AB(1+i-j,j)    = A(i,j) para j<=i<=min(N,j+KD).
!>          Ver más abajo para más detalles.
!>
!>          En la salida, si FACT = 'E' y EQUED = 'Y', A se sobrescribe con
!>          diag(S)*A*diag(S).
!>

LDAB

!>          LDAB es INTEGER
!>          La dimensión principal de la matriz A.  LDAB >= KD+1.
!>

AFB

!>          AFB es una matriz COMPLEX*16, dimensión (LDAFB,N)
!>          Si FACT = 'F', entonces AFB es un argumento de entrada y en la entrada
!>          contiene el factor triangular U o L de la factorización de Cholesky
!>          A = U**H *U o A = L*L**H de la matriz de banda
!>          A, en el mismo formato de almacenamiento que A (ver AB). Si EQUED = 'Y',
!>          entonces AFB es la forma factorizada de la matriz A equilibrada.
!>
!>          Si FACT = 'N', entonces AFB es un argumento de salida y en la salida
!>          devuelve el factor triangular U o L de la factorización de Cholesky
!>          A = U**H *U o A = L*L**H.
!>
!>          Si FACT = 'E', entonces AFB es un argumento de salida y en la salida
!>          devuelve el factor triangular U o L de la factorización de Cholesky
!>          A = U**H *U o A = L*L**H de la matriz equilibrada A (ver la descripción de A para la forma de la
!>          matriz equilibrada).
!>

LDAFB

!>          LDAFB es INTEGER
!>          La dimensión principal de la matriz AFB.  LDAFB >= KD+1.
!>

EQUED

!>          EQUED es CHARACTER*1
!>          Especifica la forma de equilibrado que se realizó.
!>          = 'N':  Sin equilibrado (siempre verdadero si FACT = 'N').
!>          = 'Y':  Se realizó el equilibrado, es decir, A ha sido reemplazada por
!>                  diag(S) * A * diag(S).
!>          EQUED es un argumento de entrada si FACT = 'F'; de lo contrario, es un
!>          argumento de salida.
!>

S

!>          S es una matriz DOUBLE PRECISION, dimensión (N)
!>          Los factores de escala para A; no se accede si EQUED = 'N'.  S es
!>          un argumento de entrada si FACT = 'F'; de lo contrario, S es un
!>          argumento de salida. Si FACT = 'F' y EQUED = 'Y', cada elemento de S
!>          debe ser positivo.
!>

B

!>          B es una matriz COMPLEX*16, dimensión (LDB,NRHS)
!>          En la entrada, la matriz B de lado derecho de NxNRHS.
!>          En la salida, si EQUED = 'N', B no se modifica; si EQUED = 'Y',
!>          B se sobrescribe con diag(S) * B.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal de la matriz B.  LDB >= max(1,N).
!>

CHARACTER*1. On entry, UPLO specifies
    whether the upper or lower triangular part of the band matrix

 UPLO = ＇U＇   Only the upper triangular part of A is supplied.
 UPLO = ＇L＇   Only the lower triangular part of A is supplied.

    KD >= 0.

  


NRHS




INTEGER. The number of right-hand sides, i.e., the

Description


The subroutine ZPBSVX uses the left-side
    Q L factorization to solve a complex Hermitian positive-definite
    band system of linear equations


    A * X = B



The routine also provides an estimate for the reciprocal
    condition number of A. The structure in the description lists the
    arguments and their types and provides details about the values and
    properties of the parameters.


The main purpose of the subroutine is to solve systems of linear
    equations involving Hermitian positive-definite band matrices. It
    uses LU factorization with partial pivoting and provides error
    estimates for the solution.


INFO = 0: successful exit


INFO < 0: if INFO = -i, the i-th
    argument had an illegal value.


INFO > 0: if INFO = i, and i is




    <= N:  the leading principal minor of order i of A
           is not positive, so the factorization could not
           be completed, and the solution has not been
           computed. RCOND = 0 is returned.
    = N+1: U is nonsingular, but RCOND is less than machine
           precision, meaning that the matrix is singular
           to working precision.  Nevertheless, the
           solution and error bounds are computed because
           there are a number of situations where the
           computed solution can be more accurate than the
           value of RCOND would suggest.





If INFO = 0 or INFO = N+1, the N-by-NRHS
    solution matrix X to the original system of equations.


Note that if EQUED = 'Y', A and
    B are modified on exit, and the solution to the
    equilibrated system is inv(diag(S))*X.


LDX is the leading dimension of the array
    X. LDX >= max(1,N).


RCOND is the estimate of the reciprocal condition
    number of the matrix A after equilibration (if done). If
    RCOND is less than the machine precision (in particular, if
    RCOND = 0), the matrix is singular to working precision. This
    condition is indicated by a return code of INFO > 0.


FERR is the estimated forward error bound for each
    solution vector X(j) (the j-th column of the solution matrix
    X).


If XTRUE is the true solution corresponding to
    X(j), FERR(j) is an estimated upper bound for the
    magnitude of the largest element in (X(j) - XTRUE)
    divided by the magnitude of the largest element in X(j). The
    estimate is as reliable as the estimate for RCOND, and is
    almost always a slight overestimate of the true error.


BERR is the componentwise relative backward error of
    each solution vector X(j) (i.e., the smallest relative change in
    any element of A or B that makes X(j) an
    exact solution).


WORK is a complex*16 array of dimension (2*N).


RWORK is a double precision array of dimension
    (N).

Further Details


   The band storage scheme is illustrated by the following example, when
   N = 6, KD = 2, and UPLO = 'U':

   Two-dimensional storage of the Hermitian matrix A:

      a11  a12  a13
           a22  a23  a24
                a33  a34  a35
                     a44  a45  a46
                          a55  a56
(aij=conjg(aji))              a66

   Band storage of the upper triangle of A:

      *    *   a13  a24  a35  a46
      *   a12  a23  a34  a45  a56
     a11  a22  a33  a44  a55  a66

   Similarly, if UPLO = 'L' the format of A is as follows:

     a11  a22  a33  a44  a55  a66
     a21  a32  a43  a54  a65   *
     a31  a42  a53  a64   *    *

   Array elements marked * are not used by the routine.
