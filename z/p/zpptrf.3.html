subrutina zpptrf (carácter uplo, entero n, complejo*16, dimensión( * ) ap, entero info)

ZPPTRF

Propósito:

!>
!> ZPPTRF calcula la factorización de Cholesky de una matriz compleja Hermitiana
!> positiva definida A almacenada en formato empaquetado.
!>
!> La factorización tiene la forma
!>    A = U**H * U,  si UPLO = 'U', o
!>    A = L  * L**H,  si UPLO = 'L',
!> donde U es una matriz triangular superior y L es triangular inferior.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          = 'U':  El triángulo superior de A está almacenado;
!>          = 'L':  El triángulo inferior de A está almacenado.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

AP

!>          AP es un array COMPLEX*16, de dimensión (N*(N+1)/2)
!>          En la entrada, el triángulo superior o inferior de la matriz Hermitiana
!>          A, empaquetado por columnas en un array lineal. La j-ésima columna de A
!>          se almacena en el array AP de la siguiente manera:
!>          si UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) para 1<=i<=j;
!>          si UPLO = 'L', AP(i + (j-1)*(2n-j)/2) = A(i,j) para j<=i<=n.
!>          Ver más detalles abajo.
!>
!>          En la salida, si INFO = 0, el factor triangular U o L de la
!>          factorización de Cholesky A = U**H*U o A = L*L**H, en el mismo
!>          formato de almacenamiento que A.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tuvo un valor ilegal
!>          > 0:  si INFO = i, el menor principal principal de orden i
!>                no es positivo, y la factorización no pudo ser
!>                completada.
!>

Detalles adicionales:

!>
!>  El esquema de almacenamiento empaquetado se ilustra con el siguiente ejemplo
!>  cuando N = 4, UPLO = 'U':
!>
!>  Almacenamiento bidimensional de la matriz Hermitiana A:
!>
!>     a11 a12 a13 a14
!>         a22 a23 a24
!>             a33 a34     (aij = conjg(aji))
!>                 a44
!>
!>  Almacenamiento empaquetado del triángulo superior de A:
!>
!>  AP = [ a11, a12, a22, a13, a23, a33, a14, a24, a34, a44 ]
!>
