subrutina zpbt01 (carácter uplo, entero n, entero kd, complejo*16, dimensión( lda, * ) a, entero lda, complejo*16, dimensión( ldafac, * ) afac, entero ldafac, doble precisión, dimensión( * ) rwork, doble precisión resid)

ZPBT01

Propósito:

!>
!> ZPBT01 reconstruye una matriz de banda hermítica positiva definida A a partir de
!> su factorización L*L' o U'*U y calcula el residuo
!>    norm( L*L' - A ) / ( N * norm(A) * EPS ) o
!>    norm( U'*U - A ) / ( N * norm(A) * EPS ),
!> donde EPS es el epsilon de la máquina, L' es la transpuesta conjugada de
!> L, y U' es la transpuesta conjugada de U.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          Especifica si la parte triangular superior o inferior de la
!>          matriz hermítica A está almacenada:
!>          = 'U':  Triangular superior
!>          = 'L':  Triangular inferior
!>

N

!>          N es ENTERO
!>          El número de filas y columnas de la matriz A.  N >= 0.
!>

KD

!>          KD es ENTERO
!>          El número de superdiagonales de la matriz A si UPLO = 'U',
!>          o el número de subdiagonales si UPLO = 'L'.  KD >= 0.
!>

A

!>          A es un array de COMPLEX*16, dimensión (LDA,N)
!>          La matriz de banda hermítica original A.  Si UPLO = 'U', la
!>          parte triangular superior de A se almacena como una matriz de banda; si
!>          UPLO = 'L', la parte triangular inferior de A se almacena. Las
!>          columnas del triángulo apropiado se almacenan en las columnas
!>          de A y las diagonales del triángulo se almacenan en las filas
!>          de A. Ver ZPBTRF para más detalles.
!>

LDA

!>          LDA es ENTERO.
!>          La dimensión principal del array A.  LDA >= max(1,KD+1).
!>

AFAC

!>          AFAC es un array de COMPLEX*16, dimensión (LDAFAC,N)
!>          La forma factorizada de la matriz A. AFAC contiene el factor
!>          L o U de la factorización L*L' o U'*U en formato de almacenamiento de banda,
!>          tal como se calcula por ZPBTRF.
!>

LDAFAC

!>          LDAFAC es ENTERO
!>          La dimensión principal del array AFAC.
!>          LDAFAC >= max(1,KD+1).
!>

RWORK

!>          RWORK es un array de DOBLE PRECISIÓN, dimensión (N)
!>

RESID

!>          RESID es DOBLE PRECISIÓN
!>          Si UPLO = 'L', norm(L*L' - A) / ( N * norm(A) * EPS )
!>          Si UPLO = 'U', norm(U'*U - A) / ( N * norm(A) * EPS )
!>
