Documentación de Función/Subrutina

subrutina zpotrf (character uplo, integer n, complex*16, dimension( lda, * ) a, integer lda, integer info)

ZPOTRF

Propósito:

!>
!> ZPOTRF calcula la factorización de Cholesky de una matriz compleja Hermítica
!> positiva definida A.
!>
!> La factorización tiene la forma
!>    A = U**H * U,  si UPLO = 'U', o
!>    A = L  * L**H,  si UPLO = 'L',
!> donde U es una matriz triangular superior y L es triangular inferior.
!>
!> Esta es la versión en bloques del algoritmo, llamando a BLAS Nivel 3.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          = 'U':  El triángulo superior de A está almacenado;
!>          = 'L':  El triángulo inferior de A está almacenado.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

A

!>          A es un array COMPLEX*16, de dimensión (LDA,N)
!>          En la entrada, la matriz Hermítica A.  Si UPLO = 'U', la parte
!>          triangular superior N-por-N principal de A contiene la parte
!>          triangular superior de la matriz A, y la parte estrictamente
!>          triangular inferior de A no se referencia. Si UPLO = 'L', la parte
!>          triangular inferior N-por-N principal de A contiene la parte
!>          triangular inferior de la matriz A, y la parte estrictamente
!>          triangular superior de A no se referencia.
!>
!>          En la salida, si INFO = 0, el factor U o L de la factorización de
!>          Cholesky A = U**H *U o A = L*L**H.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

INFO

!>          INFO es INTEGER
!>          = 0:  Salida exitosa
!>          < 0:  Si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>          > 0:  Si INFO = i, el menor principal líder de orden i
!>                no es positivo, y la factorización no pudo ser
!>                completada.
!>
