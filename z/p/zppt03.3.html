subrutina zppt03 (carácter uplo, entero n, complejo*16, dimensión( * ) a, complejo*16, dimensión( * ) ainv, complejo*16, dimensión( ldwork, * ) work, entero ldwork, doble precisión, dimensión( * ) rwork, doble precisión rcond, doble precisión resid)

ZPPT03

Propósito:

!>
!> ZPPT03 calcula el residuo para una matriz hermítica empaquetada multiplicada por su
!> inversa:
!>    norm( I - A*AINV ) / ( N * norm(A) * norm(AINV) * EPS ),
!> donde EPS es la epsilon de la máquina.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          Especifica si la parte triangular superior o inferior de la
!>          matriz hermítica A está almacenada:
!>          = 'U':  Triangular superior
!>          = 'L':  Triangular inferior
!>

N

!>          N es INTEGER
!>          El número de filas y columnas de la matriz A.  N >= 0.
!>

A

!>          A es una matriz COMPLEX*16, dimensión (N*(N+1)/2)
!>          La matriz hermítica original A, almacenada como una matriz
!>          triangular empaquetada.
!>

AINV

!>          AINV es una matriz COMPLEX*16, dimensión (N*(N+1)/2)
!>          La inversa (hermítica) de la matriz A, almacenada como una matriz
!>          triangular empaquetada.
!>

WORK

!>          WORK es una matriz COMPLEX*16, dimensión (LDWORK,N)
!>

LDWORK

!>          LDWORK es INTEGER
!>          La dimensión principal de la matriz WORK.  LDWORK >= max(1,N).
!>

RWORK

!>          RWORK es una matriz DOUBLE PRECISION, dimensión (N)
!>

RCOND

!>          RCOND es DOUBLE PRECISION
!>          El recíproco del número de condición de A, calculado como
!>          ( 1/norm(A) ) / norm(AINV).
!>

RESID

!>          RESID es DOUBLE PRECISION
!>          norm(I - A*AINV) / ( N * norm(A) * norm(AINV) * EPS )
!>
