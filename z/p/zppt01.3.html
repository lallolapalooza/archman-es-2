subrutina zppt01 (carácter uplo, entero n, complejo*16, dimensión( * ) a, complejo*16, dimensión( * ) afac, doble precisión, dimensión( * ) rwork, doble precisión resid)

ZPPT01

Propósito:

!>
!> ZPPT01 reconstruye una matriz A hermítica positiva definida empaquetada
!> a partir de su factorización L*L' o U'*U y calcula la residual
!>    norm( L*L' - A ) / ( N * norm(A) * EPS ) o
!>    norm( U'*U - A ) / ( N * norm(A) * EPS ),
!> donde EPS es la epsilon de la máquina, L' es la transpuesta conjugada de
!> L, y U' es la transpuesta conjugada de U.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          Especifica si la parte triangular superior o inferior de la
!>          matriz hermítica A está almacenada:
!>          = 'U':  Triangular superior
!>          = 'L':  Triangular inferior
!>

N

!>          N es INTEGER
!>          El número de filas y columnas de la matriz A. N >= 0.
!>

A

!>          A es un array COMPLEX*16, dimensión (N*(N+1)/2)
!>          La matriz hermítica original A, almacenada como una matriz
!>          triangular empaquetada.
!>

AFAC

!>          AFAC es un array COMPLEX*16, dimensión (N*(N+1)/2)
!>          En la entrada, el factor L o U de la factorización L*L' o U'*U
!>          de A, almacenado como una matriz triangular empaquetada.
!>          Se sobrescribe con la matriz reconstruida, y luego con la
!>          diferencia L*L' - A (o U'*U - A).
!>

RWORK

!>          RWORK es un array DOUBLE PRECISION, dimensión (N)
!>

RESID

!>          RESID es DOUBLE PRECISION
!>          Si UPLO = 'L', norm(L*L' - A) / ( N * norm(A) * EPS )
!>          Si UPLO = 'U', norm(U'*U - A) / ( N * norm(A) * EPS )
!>
