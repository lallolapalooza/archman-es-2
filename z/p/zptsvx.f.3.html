subrutina zptsvx (character fact, integer n, integer nrhs, double precision, dimension( * ) d, complex*16, dimension( * ) e, double precision, dimension( * ) df, complex*16, dimension( * ) ef, complex*16, dimension( ldb, * ) b, integer ldb, complex*16, dimension( ldx, * ) x, integer ldx, double precision rcond, double precision, dimension( * ) ferr, double precision, dimension( * ) berr, complex*16, dimension( * ) work, double precision, dimension( * ) rwork, integer info)

ZPTSVX calcula la solución al sistema de ecuaciones lineales A * X = B para matrices PT

Propósito:

!>
!> ZPTSVX utiliza la factorización A = L*D*L**H para calcular la solución
!> de un sistema complejo de ecuaciones lineales A*X = B, donde A es una
!> matriz tridiagonal Hermitiana positiva definida de N por N y X y B
!> son matrices de N por NRHS.
!>
!> También se proporcionan cotas de error en la solución y una estimación
!> de la condición.
!>

Descripción:

!>
!> Se realizan los siguientes pasos:
!>
!> 1. Si FACT = 'N', la matriz A se factoriza como A = L*D*L**H, donde L
!>    es una matriz bidiagonal inferior unitaria y D es diagonal. La
!>    factorización también puede considerarse de la forma
!>    A = U**H*D*U.
!>
!> 2. Si el menor principal principal de orden i no es positivo,
!>    entonces la rutina retorna con INFO = i. De lo contrario, la forma
!>    factorizada de A se utiliza para estimar el número de condición de la
!>    matriz A. Si la inversa del número de condición es menor que la
!>    precisión de la máquina, se devuelve INFO = N+1 como advertencia,
!>    pero la rutina continúa resolviendo para X y calculando cotas de
!>    error como se describe a continuación.
!>
!> 3. El sistema de ecuaciones se resuelve para X utilizando la forma
!>    factorizada de A.
!>
!> 4. Se aplica refinamiento iterativo para mejorar la solución calculada
!>    y obtener cotas de error y estimaciones de error hacia atrás.
!>

Parámetros

FACT 
!>          FACT es CHARACTER*1
!>          Especifica si la forma factorizada de la matriz
!>          A se proporciona o no en la entrada.
!>          = 'F':  En la entrada, DF y EF contienen la forma factorizada de A.
!>                  D, E, DF y EF no se modificarán.
!>          = 'N':  La matriz A se copiará a DF y EF y
!>                  se factorizará.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de lados derechos, es decir, el número de columnas
!>          de las matrices B y X.  NRHS >= 0.
!>

D

!>          D es un array de DOUBLE PRECISION, dimensión (N)
!>          Los n elementos diagonales de la matriz tridiagonal A.
!>

E

!>          E es un array de COMPLEX*16, dimensión (N-1)
!>          Los n-1 elementos subdiagonales de la matriz tridiagonal A.
!>

DF

!>          DF es un array de DOUBLE PRECISION, dimensión (N)
!>          Si FACT = 'F', entonces DF es un argumento de entrada y en la entrada
!>          contiene los n elementos diagonales de la matriz diagonal D
!>          de la factorización L*D*L**H de A.
!>          Si FACT = 'N', entonces DF es un argumento de salida y en la salida
!>          contiene los n elementos diagonales de la matriz diagonal D
!>          de la factorización L*D*L**H de A.
!>

EF

!>          EF es un array de COMPLEX*16, dimensión (N-1)
!>          Si FACT = 'F', entonces EF es un argumento de entrada y en la entrada
!>          contiene los n-1 elementos subdiagonales del factor unitario
!>          bidiagonal L de la factorización L*D*L**H de A.
!>          Si FACT = 'N', entonces EF es un argumento de salida y en la salida
!>          contiene los n-1 elementos subdiagonales del factor unitario
!>          bidiagonal L de la factorización L*D*L**H de A.
!>

B

!>          B es un array de COMPLEX*16, dimensión (LDB,NRHS)
!>          La matriz del lado derecho B de N por NRHS.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B.  LDB >= max(1,N).
!>

X

!>          X es un array de COMPLEX*16, dimensión (LDX,NRHS)
!>          Si INFO = 0 o INFO = N+1, la matriz solución X de N por NRHS.
!>

LDX

!>          LDX es INTEGER
!>          La dimensión principal del array X.  LDX >= max(1,N).
!>

RCOND

!>          RCOND es DOUBLE PRECISION
!>          La inversa del número de condición de la matriz A. Si RCOND
!>          es menor que la precisión de la máquina (en particular, si
!>          RCOND = 0), la matriz es singular con precisión de trabajo.
!>          Esta condición se indica con un código de retorno INFO > 0.
!>

FERR

!>          FERR es un array de DOUBLE PRECISION, dimensión (NRHS)
!>          La cota de error hacia adelante para cada vector solución
!>          X(j) (la j-ésima columna de la matriz solución X).
!>          Si XTRUE es la solución verdadera correspondiente a X(j), FERR(j)
!>          es una cota superior estimada para la magnitud del elemento más
!>          grande en (X(j) - XTRUE) dividido por la magnitud del elemento más
!>          grande en X(j).
!>

BERR

!>          BERR es un array de DOUBLE PRECISION, dimensión (NRHS)
!>          El error hacia atrás relativo componente a componente de cada
!>          vector solución X(j) (es decir, el cambio relativo más pequeño en
!>          cualquier elemento de A o B que haga que X(j) sea una solución
!>          exacta).
!>

WORK

!>          WORK es un array de COMPLEX*16, dimensión (N)
!>

RWORK

!>          RWORK es un array de DOUBLE PRECISION, dimensión (N)
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>          > 0:  si INFO = i, y i es
!>                <= N:  el menor principal principal de orden i de A
!>                       no es positivo, por lo que la factorización no pudo
!>                       completarse y la solución no se ha calculado. Se devuelve RCOND = 0.
!>                = N+1: U es no singular, pero RCOND es menor que la precisión
!>                       de la máquina, lo que significa que la matriz es singular
!>                       con precisión de trabajo. Sin embargo, la solución y las
!>                       cotas de error se calculan porque hay varias situaciones
!>                       en las que la solución calculada puede ser más precisa que
!>                       lo que sugeriría el valor de RCOND.
!>

NAME

PGGSTRF – ?PGGSTRF computes the Schur factorization of a general matrix pair (A, B).

SYNOPSIS

CHARACTER * 1 UPLO, TRANSB, SYM

INTEGER M, N, NB, IA, JA, IB, JB, IQ, JQ, IZ, JZ, INFO

INTEGER DESCA( * ), DESCB( * ), DESCQ( * ), DESCZ( * )

REAL(KIND=8) ALPHAR( * ), ALPHAI( * ), BETA( * ), RWORK( * ), LDWRK

Function/Subroutine Documentation

PGGSTRF ?PGGSTRF computes the Schur factorization of a general matrix pair (A, B), i.e., it is intended to compute the factorization of the upper triangular matrix pair (A, B) as:

A = Q * T * Z**H

B = Q * U * Z**H

where T is upper triangular and U is upper triangular (or upper Hessenberg) and Q and Z are unitary matrices. PGGSTRF forms the Schur decomposition of a general matrix pair (A, B).

On entry, UPLO specifies the form of the upper triangular matrices T
