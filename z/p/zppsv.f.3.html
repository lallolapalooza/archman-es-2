subrutina zppsv (uplo, n, nrhs, ap, b, ldb, info)
ZPPSV calcula la solución del sistema de ecuaciones lineales A * X = B para matrices OTRAS

Documentación de función/subrutina

subrutina zppsv (carácter uplo, entero n, entero nrhs, complejo*16, dimensión( * ) ap, complejo*16, dimensión( ldb, * ) b, entero ldb, entero info)

ZPPSV calcula la solución de un sistema complejo de ecuaciones lineales
A * X = B,
donde A es una matriz Hermítica positiva definida de N por N almacenada en formato empaquetado y X e B son matrices de N por NRHS.

Propósito:

!>
!> ZPPSV calcula la solución de un sistema complejo de ecuaciones
!>    A * X = B,
!> donde A es una matriz Hermítica positiva definida de N por N almacenada en
!> formato empaquetado y X e B son matrices de N por NRHS.
!>
!> Se utiliza la descomposición de Cholesky para factorizar A como
!>    A = U**H * U,  si UPLO = 'U', o
!>    A = L * L**H,  si UPLO = 'L',
!> donde U es una matriz triangular superior y L es una matriz triangular
!> inferior.  Luego se utiliza la forma factorizada de A para resolver el
!> sistema de ecuaciones A * X = B.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          = 'U':  El triángulo superior de A está almacenado;
!>          = 'L':  El triángulo inferior de A está almacenado.
!>

N

!>          N es INTEGER
!>          El número de ecuaciones lineales, es decir, el orden de la
!>          matriz A.  N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de lados derechos, es decir, el número de columnas
!>          de la matriz B.  NRHS >= 0.
!>

AP

!>          AP es un array COMPLEX*16, dimensión (N*(N+1)/2)
!>          En la entrada, el triángulo superior o inferior de la matriz
!>          Hermítica A, empaquetado por columnas en un array lineal.  La
!>          columna j de A se almacena en el array AP como sigue:
!>          si UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) para 1<=i<=j;
!>          si UPLO = 'L', AP(i + (j-1)*(2n-j)/2) = A(i,j) para j<=i<=n.
!>          Ver más abajo para más detalles.
!>
!>          En la salida, si INFO = 0, el factor U o L de la factorización
!>          de Cholesky A = U**H*U o A = L*L**H, en el mismo formato de
!>          almacenamiento que A.
!>

B

!>          B es un array COMPLEX*16, dimensión (LDB,NRHS)
!>          En la entrada, la matriz B del lado derecho de N por NRHS.
!>          En la salida, si INFO = 0, la matriz solución X de N por NRHS.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B.  LDB >= max(1,N).
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el argumento i tenía un valor ilegal
!>          > 0:  si INFO = i, el menor principal líder de orden i
!>                de A no es positivo, por lo que la factorización no se
!>                pudo completar y la solución no se ha calculado.
!>

Detalles adicionales:

!>
!>  El esquema de almacenamiento empaquetado se ilustra con el siguiente ejemplo
!>  cuando N = 4, UPLO = 'U':
!>
!>  Almacenamiento bidimensional de la matriz Hermítica A:
!>
!>     a11 a12 a13 a14
!>         a22 a23 a24
!>             a33 a34     (aij = conjg(aji))
!>                 a44
!>
!>  Almacenamiento empaquetado del triángulo superior de A:
!>
!>  AP = [ a11, a12, a22, a13, a23, a33, a14, a24, a34, a44 ]
!>
