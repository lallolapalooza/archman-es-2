Documentación de Función/Subrutina

subrutina zptrfs (character uplo, integer n, integer nrhs, double precision, dimension( * ) d, complex*16, dimension( * ) e, double precision, dimension( * ) df, complex*16, dimension( * ) ef, complex*16, dimension( ldb, * ) b, integer ldb, complex*16, dimension( ldx, * ) x, integer ldx, double precision, dimension( * ) ferr, double precision, dimension( * ) berr, complex*16, dimension( * ) work, double precision, dimension( * ) rwork, integer info)

ZPTRFS

Propósito:

!>
!> ZPTRFS mejora la solución calculada de un sistema de ecuaciones lineales
!> cuando la matriz de coeficientes es hermitiana positiva definida
!> y tridiagonal, y proporciona límites de error y estimaciones de error hacia atrás
!> para la solución.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          Especifica si la superdiagonal o la subdiagonal de la
!>          matriz tridiagonal A se almacena y la forma de la
!>          factorización:
!>          = 'U':  E es la superdiagonal de A, y A = U**H*D*U;
!>          = 'L':  E es la subdiagonal de A, y A = L*D*L**H.
!>          (Las dos formas son equivalentes si A es real.)
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de lados derechos, es decir, el número de columnas
!>          de la matriz B.  NRHS >= 0.
!>

D

!>          D es un array de DOUBLE PRECISION, de dimensión (N)
!>          Los n elementos diagonales reales de la matriz tridiagonal A.
!>

E

!>          E es un array de COMPLEX*16, de dimensión (N-1)
!>          Los (n-1) elementos fuera de la diagonal de la matriz tridiagonal A
!>          (ver UPLO).
!>

DF

!>          DF es un array de DOUBLE PRECISION, de dimensión (N)
!>          Los n elementos diagonales de la matriz diagonal D de
!>          la factorización calculada por ZPTTRF.
!>

EF

!>          EF es un array de COMPLEX*16, de dimensión (N-1)
!>          Los (n-1) elementos fuera de la diagonal de la unidad bidiagonal
!>          factor U o L de la factorización calculada por ZPTTRF
!>          (ver UPLO).
!>

B

!>          B es un array de COMPLEX*16, de dimensión (LDB,NRHS)
!>          La matriz del lado derecho B.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B.  LDB >= max(1,N).
!>

X

!>          X es un array de COMPLEX*16, de dimensión (LDX,NRHS)
!>          En la entrada, la matriz solución X, calculada por ZPTTRS.
!>          En la salida, la matriz solución mejorada X.
!>

LDX

!>          LDX es INTEGER
!>          La dimensión principal del array X.  LDX >= max(1,N).
!>

FERR

!>          FERR es un array de DOUBLE PRECISION, de dimensión (NRHS)
!>          El límite de error hacia adelante para cada vector solución
!>          X(j) (la j-ésima columna de la matriz solución X).
!>          Si XTRUE es la solución verdadera correspondiente a X(j), FERR(j)
!>          es un límite superior estimado para la magnitud del elemento más grande
!>          en (X(j) - XTRUE) dividido por la magnitud del elemento más grande
!>          en X(j).
!>

BERR

!>          BERR es un array de DOUBLE PRECISION, de dimensión (NRHS)
!>          El error relativo componente a componente hacia atrás de cada vector solución
!>          X(j) (es decir, el cambio relativo más pequeño en
!>          cualquier elemento de A o B que haga que X(j) sea una solución exacta).
!>

WORK

!>          WORK es un array de COMPLEX*16, de dimensión (N)
!>

RWORK

!>          RWORK es un array de DOUBLE PRECISION, de dimensión (N)
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tuvo un valor ilegal
!>

Parámetros Internos:

!>  ITMAX es el número máximo de pasos de refinamiento iterativo.
!>
