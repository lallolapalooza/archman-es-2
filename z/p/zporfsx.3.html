subroutine zporfsx (character uplo, character equed, integer n, integer nrhs, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( ldaf, * ) af, integer ldaf, double precision, dimension( * ) s, complex*16, dimension( ldb, * ) b, integer ldb, complex*16, dimension( ldx, * ) x, integer ldx, double precision rcond, double precision, dimension( * ) berr, integer n_err_bnds, double precision, dimension( nrhs, * ) err_bnds_norm, double precision, dimension( nrhs, * ) err_bnds_comp, integer nparams, double precision, dimension(*) params, complex*16, dimension( * ) work, double precision, dimension( * ) rwork, integer info)

ZPORFSX

Propósito:

!>
!>    ZPORFSX mejora la solución calculada de un sistema de ecuaciones
!>    lineales cuando la matriz de coeficientes es Hermítica positiva
!>    definida, y proporciona límites de error y estimaciones de error
!>    hacia atrás para la solución. Además del límite de error normwise,
!>    el código proporciona el límite de error componente a componente
!>    si es posible. Ver los comentarios para ERR_BNDS_NORM y ERR_BNDS_COMP
!>    para detalles de los límites de error.
!>
!>    El sistema original de ecuaciones lineales puede haber sido
!>    equilibrado antes de llamar a esta rutina, como se describe en los
!>    argumentos EQUED y S a continuación. En este caso, la solución y los
!>    límites de error devueltos son para el sistema original no
!>    equilibrado.
!> 
!>     Algunos parámetros opcionales están agrupados en la matriz PARAMS.
!>     Estas configuraciones determinan cómo se realiza el refinamiento,
!>     pero a menudo los valores predeterminados son aceptables. Si los
!>     valores predeterminados son aceptables, los usuarios pueden pasar
!>     NPARAMS = 0, lo que evita que el código fuente acceda al argumento
!>     PARAMS.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>       = 'U':  El triángulo superior de A está almacenado;
!>       = 'L':  El triángulo inferior de A está almacenado.
!>

EQUED

!>          EQUED es CHARACTER*1
!>     Especifica la forma de equilibrado que se realizó en A
!>     antes de llamar a esta rutina. Esto es necesario para calcular
!>     la solución y los límites de error correctamente.
!>       = 'N':  Sin equilibrado
!>       = 'Y':  Equilibrado de filas y columnas, es decir, A ha sido
!>               reemplazada por diag(S) * A * diag(S).
!>               El lado derecho B se ha modificado en consecuencia.
!>

N

!>          N es INTEGER
!>     El orden de la matriz A.  N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>     El número de lados derechos, es decir, el número de columnas
!>     de las matrices B y X.  NRHS >= 0.
!>

A

!>          A es COMPLEX*16 array, dimension (LDA,N)
!>     La matriz Hermítica A.  Si UPLO = 'U', la parte triangular
!>     superior N-por-N líder de A contiene la parte triangular superior
!>     de la matriz A, y la parte estrictamente triangular inferior de A
!>     no se referencia. Si UPLO = 'L', la parte triangular
!>     inferior N-por-N líder de A contiene la parte triangular inferior
!>     de la matriz A, y la parte estrictamente triangular superior de A
!>     no se referencia.
!>

LDA

!>          LDA es INTEGER
!>     La dimensión líder del array A.  LDA >= max(1,N).
!>

AF

!>          AF es COMPLEX*16 array, dimension (LDAF,N)
!>     El factor triangular U o L de la factorización de Cholesky
!>     A = U**H*U o A = L*L**H, como fue calculado por ZPOTRF.
!>

LDAF

!>          LDAF es INTEGER
!>     La dimensión líder del array AF.  LDAF >= max(1,N).
!>

S

!>          S es DOUBLE PRECISION array, dimension (N)
!>     Los factores de escala para A.  Si EQUED = 'Y', A se multiplica a
!>     la izquierda y a la derecha por diag(S).  S es un argumento de
!>     entrada si FACT = 'F'; de lo contrario, S es un argumento de
!>     salida. Si FACT = 'F' y EQUED = 'Y', cada elemento de S debe ser
!>     positivo. Si S es de salida, cada elemento de S es una potencia
!>     del radix. Si S es de entrada, cada elemento de S debe ser una
!>     potencia del radix para asegurar una solución y estimaciones de
!>     error confiables. El escalado por potencias del radix no causa
!>     errores de redondeo a menos que el resultado sea un subdesbordamiento
!>     o un desbordamiento. Los errores de redondeo durante el escalado
!>     conducen a un refinamiento con una matriz que no es equivalente a
!>     la matriz de entrada, produciendo estimaciones de error que pueden
!>     no ser confiables.
!>

B

!>          B es COMPLEX*16 array, dimension (LDB,NRHS)
!>     La matriz del lado derecho B.
!>

LDB

!>          LDB es INTEGER
!>     La dimensión líder del array B.  LDB >= max(1,N).
!>

X

!>          X es COMPLEX*16 array, dimension (LDX,NRHS)
!>     En la entrada, la matriz solución X, como fue calculada por ZGETRS.
!>     En la salida, la matriz solución mejorada X.
!>

LDX

!>          LDX es INTEGER
!>     La dimensión líder del array X.  LDX >= max(1,N).
!>

RCOND

!>          RCOND es DOUBLE PRECISION
!>     Condición escalada recíproca. Esta es una estimación del número de
!>     condición de Skeel escalado recíproco de la matriz A después del
!>     equilibrado (si se realizó). Si esto es menor que la precisión de
!>     la máquina (en particular, si es cero), la matriz es singular
!>     a la precisión de trabajo. Tenga en cuenta que el error puede ser
!>     aún pequeño incluso si este número es muy pequeño y la matriz
!>     parece mal condicionada.
!>

BERR

!>          BERR es DOUBLE PRECISION array, dimension (NRHS)
!>     Error de retroceso relativo componente a componente. Este es el
!>     error de retroceso relativo componente a componente de cada vector
!>     solución X(j) (es decir, el cambio relativo más pequeño en cualquier
!>     elemento de A o B que haga que X(j) sea una solución exacta).
!>

N_ERR_BNDS

!>          N_ERR_BNDS es INTEGER
!>     Número de límites de error a devolver para cada lado derecho
!>     y cada tipo (normwise o componente a componente). Ver ERR_BNDS_NORM y
!>     ERR_BNDS_COMP abajo.
!>

ERR_BNDS_NORM

!>          ERR_BNDS_NORM es DOUBLE PRECISION array, dimension (NRHS, N_ERR_BNDS)
!>     Para cada lado derecho, esta matriz contiene información sobre
!>     varios límites de error y números de condición correspondientes al
!>     error relativo normwise, que se define de la siguiente manera:
!>
!>     Error relativo normwise en el i-ésimo vector solución:
!>             max_j (abs(XTRUE(j,i) - X(j,i)))
!>            ------------------------------
!>                  max_j abs(X(j,i))
!>
!>     La matriz se indexa por el tipo de información de error como se
!>     describe a continuación. Actualmente hay hasta tres piezas de
!>     información devueltas.
!>
!>     El primer índice en ERR_BNDS_NORM(i,:) corresponde al i-ésimo
!>     lado derecho.
!>
!>     El segundo índice en ERR_BNDS_NORM(:,err) contiene los siguientes
!>     tres campos:
!>     err = 1  booleano. Confíe en la respuesta si

ERR_BNDS_COMP

!> ERR_BNDS_COMP es un array de PRECISIÓN DOBLE, de dimensión (NRHS, N_ERR_BNDS)
!> Para cada lado derecho, este array contiene información sobre
!> varios límites de error y números de condición correspondientes al
!> error relativo componente a componente, que se define de la siguiente manera:
!>
!> Error relativo componente a componente en el i-ésimo vector de solución:
!> abs(XTRUE(j,i) - X(j,i))
!> max_j ----------------------
!> abs(X(j,i))
!>
!> El array está indexado por el lado derecho i (del cual depende el
!> error relativo componente a componente), y el tipo de información de error
!> como se describe a continuación. Actualmente hay hasta tres
!> piezas de información devueltas para cada lado derecho. Si
!> no se solicita precisión componente a componente (PARAMS(3) = 0.0), entonces
!> ERR_BNDS_COMP no se accede. Si N_ERR_BNDS < 3, entonces como máximo
!> las primeras entradas (:,N_ERR_BNDS) son devueltas.
!>
!> El primer índice en ERR_BNDS_COMP(i,:) corresponde al i-ésimo
!> lado derecho.
!>
!> El segundo índice en ERR_BNDS_COMP(:,err) contiene los siguientes
!> tres campos:
!> err = 1 booleano. Confía en la respuesta si el
!> número de condición recíproco es menor que el umbral
!> sqrt(n) * dlamch('Epsilon').
!>
!> err = 2 límite de error: El error directo estimado,
!> casi con seguridad dentro de un factor de 10 del error real
!> siempre que la siguiente entrada sea mayor que el umbral
!> sqrt(n) * dlamch('Epsilon'). Este límite de error solo debe
!> confiarse si el booleano anterior es verdadero.
!>
!> err = 3 número de condición recíproco: Componente estimada
!> número de condición recíproco. Comparado con el umbral
!> sqrt(n) * dlamch('Epsilon') para determinar si el error
!> la estimación es . Estos números de condición recíprocos
!> son 1 / (norm(Z^{-1},inf) * norm(Z,inf)) para alguna
!> matriz Z apropiadamente escalada.
!> Sea Z = S*(A*diag(x)), donde x es la solución para el
!> lado derecho actual y S escala cada fila de
!> A*diag(x) por una potencia de la base para que todas las sumas absolutas de fila de Z sean aproximadamente 1.
!>
!> Consulte la Nota de trabajo de Lapack 165 para obtener más detalles y precauciones adicionales.
!>

NPARAMS


!> NPARAMS es un ENTERO
!> Especifica el número de parámetros establecidos en PARAMS. Si es <= 0,
!> el array PARAMS nunca se referencia y se utilizan los valores predeterminados.
!>

PARAMS


!> PARAMS es un array de PRECISIÓN DOBLE, de dimensión NPARAMS
!> Especifica los parámetros del algoritmo. Si una entrada es < 0.0, entonces
!> esa entrada se llenará con el valor predeterminado utilizado para ese
!> parámetro. Solo se accede a las posiciones hasta NPARAMS; se utilizan valores predeterminados
!> para parámetros de mayor número.
!>
!> PARAMS(LA_LINRX_ITREF_I = 1) : Si realizar o no el refinamiento iterativo.
!> Valor predeterminado: 1.0D+0
!> = 0.0: No se realiza refinamiento y no se calculan límites de error.
!> = 1.0: Utiliza el algoritmo de refinamiento de doble precisión,
!> posiblemente con cálculos de precisión simple duplicados si el
!> entorno de compilación no admite PRECISIÓN DOBLE.
!> (otros valores están reservados para uso futuro)
!>
!> PARAMS(LA_LINRX_ITHRESH_I = 2) : Número máximo de residuales
!> cálculos permitidos para el refinamiento.
!> Valor predeterminado: 10
!> Agresivo: Establecido en 100 para permitir la convergencia utilizando aproximaciones
!> factorizaciones o factorizaciones distintas de LU. Si
!> la factorización utiliza una técnica distinta de
!> eliminación gaussiana, las garantías en
!> err_bnds_norm y err_bnds_comp pueden ya no ser
!> confiables.
!>
!> PARAMS(LA_LINRX_CWISE_I = 3) : Indicador que determina si el código
!> intentará encontrar una solución con un pequeño componente
!> error relativo en el algoritmo de doble precisión. Positivo
!> es verdadero, 0.0 es falso.
!> Valor predeterminado: 1.0 (intentar convergencia componente a componente)
!>

WORK


!> WORK es un array COMPLEX*16, de dimensión (2*N)
!>

RWORK


!> RWORK es un array de PRECISIÓN DOBLE, de dimensión (2*N)
!>

INFO


!> INFO es un ENTERO
!> = 0: Salida exitosa. La solución para cada lado derecho está
!> garantizada.
!> < 0: Si INFO = -i, el i-ésimo argumento tuvo un valor ilegal.
!> > 0 y <= N: U(INFO,INFO) es exactamente cero. La factorización
!> se ha completado, pero el factor U es exactamente singular, por lo que
!> la solución y los límites de error no pudieron calcularse. RCOND = 0
!> se devuelve.
!> = N+J: La solución correspondiente al J-ésimo lado derecho no
!> está garantizada. Las soluciones correspondientes a otros lados derechos
!> K con K > J también pueden no estar garantizadas, pero
!> solo se informa el primer lado derecho de este tipo. Si un pequeño
!> error componente a componente no se solicita (PARAMS(3) = 0.0), entonces
!> el J-ésimo lado derecho es el primero con un límite de error normwise
!> que no está garantizado (el J más pequeño tal que
!> ERR_BNDS_NORM(J,1) = 0.0). Por defecto (PARAMS(3) = 1.0)
!> el J-ésimo lado derecho es el primero con un límite de error normwise o
!> componente a componente que no está garantizado (el J más pequeño
!> tal que ERR_BNDS_NORM(J,1) = 0.0 o
!> ERR_BNDS_COMP(J,1) = 0.0). Consulte la definición de
!> ERR_BNDS_NORM(:,1) y ERR_BNDS_COMP(:,1). Para obtener información
!> sobre todos los lados derechos, consulte ERR_BNDS_NORM o
!> ERR_BNDS_COMP.
!>
