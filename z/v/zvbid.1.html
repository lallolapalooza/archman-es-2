zvbid(1) Demone proxy VBI zvbid(1)

NOMBRE

zvbid - Demone proxy VBI

SINOPSIS

zvbid [ opciones ]

DESCRIPCIÓN

zvbid es un proxy para dispositivos VBI, es decir, reenvía uno o más flujos de datos VBI a uno o más clientes conectados y gestiona las solicitudes de cambio de canal.

OPCIONES

-dev ruta
Ruta de un dispositivo del cual leer datos. Este argumento puede ser dado varias veces con diferentes dispositivos.
-buffers contador
Número de buffers a asignar para capturar datos brutos VBI de dispositivos que soportan transmisión (actualmente solo video4linux, rev. 2). Un mayor número de buffers puede prevenir la pérdida de datos en caso de alta latencia. La desventaja es un mayor consumo de memoria (típicamente 65kB por buffer). El contador por defecto es 8, el máximo es 32.
-nodetach
El proceso demone permanece conectado a la terminal desde la cual fue iniciado (por ejemplo, para que puedas detenerlo presionando las teclas Control-C). Destinado solo para la resolución de problemas.
-kill
Termina un demone proxy que se ejecuta para el dispositivo dado.
-debug nivel
Habilita la salida de depuración: 0= desactivado (por defecto); 1= mensajes generales; Adicionalmente se pueden añadir 2, 4, 8, ... para habilitar la salida de depuración para varias categorías.
-syslog nivel
Habilita la salida de syslog.
-loglevel nivel
Nivel del archivo de registro
-logfile ruta
Ruta al archivo de registro.
-maxclients contador
Máx. número de clientes permitidos para conectarse simultáneamente.
-help
Imprime una breve descripción de todas las opciones de línea de comandos.
