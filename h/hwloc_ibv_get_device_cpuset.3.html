int hwloc_ibv_get_device_cpuset (hwloc_topology_t topology, struct ibv_device * ibdev, hwloc_cpuset_t set) [inline]

Obtiene el conjunto de CPU de procesadores que están físicamente cerca del dispositivo ibdev. Almacena en set el conjunto de CPU que describe la localidad del dispositivo OpenFabrics ibdev (InfiniBand, etc.).

La topología topology y el dispositivo ibdev deben coincidir con la máquina local. La detección de dispositivos de E/S no es necesaria en la topología.

La función solo devuelve la localidad del dispositivo. Si se necesita más información sobre el dispositivo, se deben usar objetos del sistema operativo en su lugar, consulte hwloc_ibv_get_device_osdev() y hwloc_ibv_get_device_osdev_by_name().

Actualmente, esta función solo se implementa de forma significativa para Linux; otros sistemas simplemente obtendrán un conjunto de CPU completo.

Retorna

0 si tiene éxito.

-1 en caso de error, por ejemplo, si no se pudo encontrar la información del dispositivo.

hwloc_obj_t hwloc_ibv_get_device_osdev (hwloc_topology_t topology, struct ibv_device * ibdev) [inline]

Obtiene el objeto del dispositivo del sistema operativo hwloc correspondiente al dispositivo OpenFabrics ibdev.

Retorna

El objeto del dispositivo del sistema operativo hwloc que describe el dispositivo OpenFabrics ibdev (InfiniBand, etc.).

NULL si no se pudo encontrar ninguno.

La topología topology y el dispositivo ibdev deben coincidir con la máquina local. La detección de dispositivos de E/S debe estar habilitada en la topología. Si no es así, la localidad del objeto aún puede encontrarse utilizando hwloc_ibv_get_device_cpuset().

Nota

El objeto del dispositivo PCI correspondiente se puede obtener examinando el objeto padre del dispositivo del sistema operativo.

hwloc_obj_t hwloc_ibv_get_device_osdev_by_name (hwloc_topology_t topology, const char * ibname) [inline]

Obtiene el objeto del dispositivo del sistema operativo hwloc correspondiente al dispositivo OpenFabrics llamado ibname.

Retorna

El objeto del dispositivo del sistema operativo hwloc que describe el dispositivo OpenFabrics (InfiniBand, Omni-Path, usNIC, etc) cuyo nombre es ibname (mlx5_0, hfi1_0, usnic_0, qib0, etc).

NULL si no se pudo encontrar ninguno.

El nombre ibname generalmente se obtiene de ibv_get_device_name().

La topología topology no necesariamente tiene que coincidir con la máquina actual. Por ejemplo, la topología puede ser una importación XML de un host remoto. La detección de dispositivos de E/S debe estar habilitada en la topología.

Nota

El objeto del dispositivo PCI correspondiente se puede obtener examinando el objeto padre del dispositivo del sistema operativo.
