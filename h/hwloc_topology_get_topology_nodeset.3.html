hwloc_const_cpuset_t hwloc_topology_get_allowed_cpuset (hwloc_topology_t topología)

Obtener el conjunto de CPU permitido.

Devuelve

el conjunto de CPU de los procesadores permitidos del sistema.

Nota

Esta función no puede devolver NULL.

Si la bandera de topología HWLOC_TOPOLOGY_FLAG_INCLUDE_DISALLOWED no se estableció, esto es idéntico a hwloc_topology_get_topology_cpuset(), lo que significa que todas las PUs están permitidas.

Si se estableció HWLOC_TOPOLOGY_FLAG_INCLUDE_DISALLOWED, aplicar hwloc_bitmap_intersects() sobre el resultado de esta función y sobre un conjunto de CPU de objeto verifica si hay PUs permitidas dentro de ese objeto. Aplicar hwloc_bitmap_and() devuelve la lista de estas PUs permitidas.

El conjunto de CPU devuelto no se ha asignado recientemente y, por lo tanto, no debe modificarse ni liberarse; se debe usar hwloc_bitmap_dup() para obtener una copia local.

hwloc_const_nodeset_t hwloc_topology_get_allowed_nodeset (hwloc_topology_t topología)

Obtener el conjunto de nodos permitido.

Devuelve

el conjunto de nodos de memoria permitidos del sistema.

Nota

Esta función no puede devolver NULL.

Si la bandera de topología HWLOC_TOPOLOGY_FLAG_INCLUDE_DISALLOWED no se estableció, esto es idéntico a hwloc_topology_get_topology_nodeset(), lo que significa que todos los nodos NUMA están permitidos.

Si se estableció HWLOC_TOPOLOGY_FLAG_INCLUDE_DISALLOWED, aplicar hwloc_bitmap_intersects() sobre el resultado de esta función y sobre un conjunto de nodos de objeto verifica si hay nodos NUMA permitidos dentro de ese objeto. Aplicar hwloc_bitmap_and() devuelve la lista de estos nodos NUMA permitidos.

El conjunto de nodos devuelto no se ha asignado recientemente y, por lo tanto, no debe modificarse ni liberarse; se debe usar hwloc_bitmap_dup() para obtener una copia local.

Devuelve
