Descripción Detallada Las aplicaciones que manipulan muchas topologías similares, por ejemplo una para cada nodo de un clúster homogéneo, pueden querer comprimir las topologías para reducir la huella de memoria. Este archivo ofrece una forma de manipular la diferencia entre topologías y exportar/importarla a/desde XML. La compresión puede lograrse almacenando una topología completamente mientras que las demás solo se describen por sus diferencias con la anterior. La topología real puede reconstruirse cuando sea necesario aplicando la diferencia precalculada a la topología de referencia.
Esta interfaz está dirigida a nodos muy similares. Solo se admiten diferencias muy simples entre topologías, por ejemplo un cambio en el tamaño de la memoria, el nombre del objeto o algún atributo de información. Diferencias más complejas como añadir o eliminar objetos no pueden representarse en las estructuras de diferencia y por lo tanto devuelven errores. Las diferencias entre conjuntos de objetos o conjuntos permitidos a nivel de topología tampoco pueden representarse. Esto significa que no es necesario aplicar la diferencia al examinar la organización del árbol (cuántos niveles, cuántos objetos por nivel, qué tipo de objetos, conjuntos de CPU y nodos, etc.) y al vincularse a objetos. Sin embargo, la diferencia debe aplicarse al examinar los atributos de los objetos como el nombre, el tamaño de la memoria o los atributos de información.Documentación de Definiciones de Tipos

int hwloc_topology_diff_build (hwloc_topology_t topology, hwloc_topology_t newtopology, unsigned long flags, hwloc_topology_diff_t * diff)

Calcula la diferencia entre 2 topologías. La diferencia se almacena como una lista de hwloc_topology_diff_t entradas que comienzan en diff. Se calcula realizando un recorrido en profundidad de ambos árboles de topología simultáneamente.

Si la diferencia entre 2 objetos es demasiado compleja para ser representada (por ejemplo, si algunos objetos tienen tipos diferentes, o números diferentes de hijos), se encola una entrada de diferencia especial de tipo HWLOC_TOPOLOGY_DIFF_TOO_COMPLEX . El cálculo de la diferencia no continúa por debajo de estos objetos. Por lo tanto, cada una de estas entradas de diferencia significa que la diferencia entre dos subárboles no pudo ser calculada.

Devuelve

0 si la diferencia puede ser representada correctamente.

0 con diff apuntando a NULL si no hay diferencia entre las topologías.

1 si la diferencia es demasiado compleja (ver arriba). Algunas entradas en la lista serán de tipo HWLOC_TOPOLOGY_DIFF_TOO_COMPLEX.

-1 en cualquier otro error.

Nota

flags actualmente no se utiliza. Debe ser 0.

La salida diff debe liberarse con hwloc_topology_diff_destroy().

La salida diff solo puede exportarse a XML o pasarse a hwloc_topology_diff_apply() si se devolvió 0, es decir, si no hay ninguna entrada de tipo HWLOC_TOPOLOGY_DIFF_TOO_COMPLEX en la lista.

La salida diff puede ser modificada eliminando algunas entradas de la lista. Las entradas eliminadas deben liberarse pasándolas a hwloc_topology_diff_destroy() (posiblemente como otra lista).

int hwloc_topology_diff_export_xml (hwloc_topology_diff_t diff, const char * refname, const char * xmlpath)

Exporta una lista de diferencias de topología a un archivo XML. Si no es NULL, refname define una cadena identificadora para la topología de referencia que se utilizó como base al calcular esta diferencia. Este identificador es normalmente el nombre del otro archivo XML que contiene la topología de referencia. Este atributo se devuelve al leer la diferencia desde XML.

Devuelve

0 en caso de éxito, -1 en caso de error.

int hwloc_topology_diff_export_xmlbuffer (hwloc_topology_diff_t diff, const char * refname, char ** xmlbuffer, int * buflen)

Exporta una lista de diferencias de topología a un búfer XML. Si no es NULL, refname define una cadena identificadora para la topología de referencia que se utilizó como base al calcular esta diferencia. Este identificador es normalmente el nombre del otro archivo XML que contiene la topología de referencia. Este atributo se devuelve al leer la diferencia desde XML.

El búfer devuelto termina con un \0 que está incluido en la longitud devuelta.

Devuelve

0 en caso de éxito, -1 en caso de error.

Nota

El búfer XML debe liberarse más adelante con hwloc_free_xmlbuffer().

int hwloc_topology_diff_load_xml (const char * xmlpath, hwloc_topology_diff_t * diff, char ** refname)

Carga una lista de diferencias de topología desde un archivo XML. Si no es NULL, refname se rellenará con la cadena identificadora de la topología de referencia para el archivo de diferencia, si se especificó alguna en el archivo XML. Este identificador es normalmente el nombre del otro archivo XML que contiene la topología de referencia.

Devuelve

0 en caso de éxito, -1 en caso de error.

Nota

el puntero devuelto en refname debe ser liberado más adelante por el llamador.

int hwloc_topology_diff_load_xmlbuffer (const char * xmlbuffer, int buflen, hwloc_topology_diff_t * diff, char ** refname)

Carga una lista de diferencias de topología desde un búfer XML. Construye una lista de diferencias a partir del búfer de memoria XML dado en xmlbuffer y de longitud buflen (incluyendo un \0 final). Este búfer puede haber sido rellenado anteriormente con hwloc_topology_diff_export_xmlbuffer().

Si no es NULL, refname se rellenará con la cadena identificadora de la topología de referencia para el archivo de diferencia, si se especificó alguna en el archivo XML. Este identificador es normalmente el nombre del otro archivo XML que contiene la topología de referencia.

Devuelve

0 en caso de éxito, -1 en caso de error.

Nota

el puntero devuelto en refname debe ser liberado más adelante por el llamador.
