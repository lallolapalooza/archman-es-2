hwloc_obj_type_t hwloc_get_depth_type (hwloc_topology_t topology, int depth)

Devuelve el tipo de objetos en la profundidad depth. depth debe estar entre 0 y hwloc_topology_get_depth()-1, o una profundidad virtual como HWLOC_TYPE_DEPTH_NUMANODE.

Retorna

El tipo de objetos en la profundidad depth.

(hwloc_obj_type_t)-1 si la profundidad depth no existe.

int hwloc_get_memory_parents_depth (hwloc_topology_t topology)

Devuelve la profundidad de los padres donde se adjuntan los objetos de memoria. Los objetos de memoria tienen profundidades negativas virtuales porque no forman parte de la jerarquía principal de objetos del lado de la CPU. Esta profundidad no debe compararse con otras profundidades de nivel.

Si todos los objetos de Memoria se adjuntan a padres Normales en la misma profundidad, esta profundidad de padre puede compararse con otras como normalmente, por ejemplo para saber si los nodos NUMA están adjuntos por encima o por debajo de los Paquetes.

Retorna

La profundidad de los padres Normales de todos los hijos de memoria si todos estos padres tienen la misma profundidad. Por ejemplo, la profundidad del nivel del Paquete si todos los nodos NUMA están adjuntos a objetos de Paquete.

HWLOC_TYPE_DEPTH_MULTIPLE si los padres Normales de todos los hijos de memoria no tienen la misma profundidad. Por ejemplo, si algunos nodos NUMA están adjuntos a Paquetes mientras que otros están adjuntos a Grupos.

int hwloc_get_type_depth (hwloc_topology_t topology, hwloc_obj_type_t type)

Devuelve la profundidad de los objetos de tipo type.

Devuelve

La profundidad de los objetos de tipo type.

Una profundidad virtual negativa si se proporciona un tipo de objeto NUMA, E/S o Misc. Estos objetos se almacenan en niveles especiales que no están relacionados con la CPU. Esta profundidad virtual puede pasarse a otras funciones de hwloc, como hwloc_get_obj_by_depth() pero no debe considerarse como una profundidad real por la aplicación. En particular, no debe compararse con ninguna otra profundidad de objeto ni con la profundidad de toda la topología.

HWLOC_TYPE_DEPTH_UNKNOWN si no hay ningún objeto de este tipo presente en la arquitectura subyacente, o si el SO no proporciona este tipo de información.

HWLOC_TYPE_DEPTH_MULTIPLE si se proporciona el tipo HWLOC_OBJ_GROUP y existen múltiples niveles de Grupos.

Nota

Si el tipo está ausente pero un tipo similar es aceptable, véase también hwloc_get_type_or_below_depth() y hwloc_get_type_or_above_depth().

Véase también

hwloc_get_memory_parents_depth() para gestionar la profundidad de los objetos de memoria.

hwloc_get_type_sscanf_as_depth() para devolver la profundidad de objetos cuyo tipo se proporciona como una cadena.

int hwloc_get_type_or_above_depth (hwloc_topology_t topology, hwloc_obj_type_t type) [inline]

Devuelve la profundidad de los objetos de tipo type o superior. Si no hay ningún objeto de este tipo presente en la arquitectura subyacente, la función devuelve la profundidad del primer objeto 'presente' que normalmente contiene type.

Esta función solo es significativa para tipos de objetos normales. Si se proporciona un tipo de objeto de memoria, E/S o Misc, siempre se devuelve la profundidad virtual correspondiente (véase hwloc_get_type_depth()).

Puede devolver HWLOC_TYPE_DEPTH_MULTIPLE para HWLOC_OBJ_GROUP igual que hwloc_get_type_depth().

int hwloc_get_type_or_below_depth (hwloc_topology_t topology, hwloc_obj_type_t type) [inline]

Devuelve la profundidad de los objetos de tipo type o inferior. Si no hay ningún objeto de este tipo presente en la arquitectura subyacente, la función devuelve la profundidad del primer objeto 'presente' que normalmente se encuentra dentro de type.

Esta función solo es significativa para tipos de objetos normales. Si se proporciona un tipo de objeto de memoria, E/S o Misc, siempre se devuelve la profundidad virtual correspondiente (véase hwloc_get_type_depth()).

Puede devolver HWLOC_TYPE_DEPTH_MULTIPLE para HWLOC_OBJ_GROUP igual que hwloc_get_type_depth().

int hwloc_topology_get_depth (hwloc_topology_t restrict topology)

Obtiene la profundidad del árbol jerárquico de objetos. Esta es la profundidad de HWLOC_OBJ_PU objetos más uno.

Devuelve

la profundidad del árbol de objetos.

Nota

Los nodos NUMA, los objetos E/S y Misc se ignoran al calcular la profundidad del árbol (se colocan en niveles especiales).
