NOMBRE

hugin_hdrmerge - Fusionar imágenes superpuestas

SINOPSIS

hugin_hdrmerge [opciones] -o salida.exr archivos-entrada

OPCIONES

-o prefijo
Archivo de salida
-m modo
Modo de fusión, puede ser uno de: avg, avg_slow, khan (predeterminado), si avg, no se aplican las opciones -i, -s o -d
-i iter
Número de iteraciones a ejecutar (el valor predeterminado es 1)
-c
Considerar solo píxeles que están definidos en todas las imágenes (solo modo avg)
-s archivo
Archivos de depuración para guardar cada iteración, puede ser uno de:
a - todos los archivos de depuración (solo se puede usar solo)
w - pesos calculados de cada iteración
r - imagen resultante de cada iteración
s - imágenes de origen antes del procesamiento

Si verbose >= 3, se generan todos los archivos de depuración a menos que se especifique lo contrario

-a cálculos
Aplicar uno o más cálculos avanzados, puede ser uno o más de:
b - sesgar los pesos logarítmicamente
c - elegir píxeles con el peso más alto en lugar de promediar (anula las opciones -a b y -a d)
d - elegir un píxel con el peso más alto en lugar de promediar cuando todos los pesos de los píxeles están dentro del 10% unos de otros
h - favorecer una alta relación señal/ruido
i - ignorar el canal alfa
-e
Exportar cada peso inicial a <rutas_archivo_entrada>_iw.<ext>
-l
Cargar un peso inicial previamente exportado con respecto a los nombres de archivo de entrada.

NOTA: si las opciones -e y -l están activas, el programa calculará y guardará los pesos iniciales, luego esperará hasta que el usuario indique que puede continuar cargando los pesos guardados previamente.

-v
Verboso, imprime mensajes de progreso, repite para una salida aún más verbosa
-h
Muestra el resumen de ayuda.
