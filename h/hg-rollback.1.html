Paquete: mercurial

HG(ROLLBACK) HG(ROLLBACK)

NOMBRE

hg rollback - revertir la última transacción (PELIGROSO) (OBSOLETO)

SINOPSIS

hg rollback

DESCRIPCIÓN

Por favor, use hg commit --amend en lugar de rollback para corregir errores en el último commit.

Este comando debe usarse con cuidado. Solo hay un nivel de rollback, y no hay forma de deshacer un rollback. También restaurará el estado del directorio en el momento de la última transacción, perdiendo cualquier cambio en el estado del directorio desde ese momento. Este comando no altera el directorio de trabajo.

Las transacciones se utilizan para encapsular los efectos de todos los comandos que crean nuevos conjuntos de cambios o propagan conjuntos de cambios existentes en un repositorio.

Por ejemplo, los siguientes comandos son transaccionales y sus efectos pueden ser revertidos:

  • commit
  • import
  • pull
  • push (con este repositorio como destino)
  • unbundle

    Para evitar la pérdida permanente de datos, rollback se negará a revertir una transacción de commit si no está extraída. Use --force para anular esta protección.

    El comando rollback puede ser completamente deshabilitado configurando el ajuste de configuración ui.rollback en false. Si está aquí porque quiere usar rollback y está deshabilitado, puede volver a habilitar el comando estableciendo ui.rollback en true.

    Este comando no está diseñado para usarse en repositorios públicos. Una vez que los cambios son visibles para la extracción por otros usuarios, revertir una transacción localmente es ineficaz (alguien más puede haber extraído los cambios). Además, es posible una condición de carrera con los lectores del repositorio; por ejemplo, un pull en progreso desde el repositorio puede fallar si se realiza un rollback.

    Devuelve 0 si tiene éxito, 1 si no hay datos de rollback disponibles.

OPCIONES

-n, --dry-run
no realizar acciones, solo imprimir la salida
-f, --force
ignorar medidas de seguridad
