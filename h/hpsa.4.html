hpsa(4) Manual de Controladores de Dispositivos hpsa(4)

NOMBRE

hpsa - Controlador SCSI de HP Smart Array

SINOPSIS

modprobe hpsa [ hpsa_allow_any=1 ]

DESCRIPCIÓN

hpsa es un controlador SCSI para los controladores RAID HP Smart Array.

Opciones

hpsa_allow_any=1: Esta opción permite que el controlador intente operar en cualquier controlador de hardware RAID HP Smart Array, incluso si no es reconocido explícitamente por el controlador. Esto permite que hardware más nuevo funcione con controladores más antiguos. Típicamente se usa para permitir la instalación de sistemas operativos desde medios que preceden al controlador RAID, aunque también puede usarse para permitir que hpsa controle controladores más antiguos que normalmente serían manejados por el controlador cciss(4). Estas placas más antiguas no han sido probadas y no son compatibles con hpsa, y cciss(4) aún debe usarse para ellas.

Hardware soportado

El controlador hpsa soporta las siguientes placas Smart Array:

    Smart Array P700M
    Smart Array P212
    Smart Array P410
    Smart Array P410i
    Smart Array P411
    Smart Array P812
    Smart Array P712m
    Smart Array P711m
    StorageWorks P1210m

Desde Linux 4.14, también se soportan las siguientes placas Smart Array:

    Smart Array 5300
    Smart Array 5312
    Smart Array 532
    Smart Array 5i
    Smart Array 6400
    Smart Array 6400 EM
    Smart Array 641
    Smart Array 642
    Smart Array 6i
    Smart Array E200
    Smart Array E200i
    Smart Array E200i
    Smart Array E200i
    Smart Array E200i
    Smart Array E500
    Smart Array P400
    Smart Array P400i
    Smart Array P600
    Smart Array P700m
    Smart Array P800

Detalles de configuración

Para configurar controladores HP Smart Array, utilice la Utilidad de Configuración de Arreglos de HP (ya sea hpacuxe(8) o hpacucli(8)) o la Utilidad de Configuración Basada en ROM Offline (ORCA) ejecutada desde la ROM de opción del Smart Array al arrancar.

ARCHIVOS

Nodos de dispositivo

Los discos lógicos se acceden a través del controlador de disco SCSI (sd(4)), las unidades de cinta a través del controlador de cinta SCSI (st(4)), y el controlador RAID a través del controlador genérico SCSI (sg(4)), con nodos de dispositivo llamados /dev/sd*, /dev/st*, y /dev/sg*, respectivamente.

Archivos de atributo de host específicos de HPSA en /sys

/sys/class/scsi_host/host*/rescan
Este es un atributo de solo escritura. Escribir en este atributo hará que el controlador busque dispositivos nuevos, cambiados o eliminados (por ejemplo, unidades de cinta conectadas en caliente, o discos lógicos recién configurados o eliminados, etc.) y notifique a la capa intermedia SCSI de cualquier cambio detectado. Normalmente, la Utilidad de Configuración de Arreglos de HP (ya sea la GUI o la variante de línea de comandos) activa automáticamente un reescaneo; por lo tanto, para cambios en los discos lógicos, el usuario normalmente no debería tener que usar este atributo. Este atributo puede ser útil al conectar en caliente dispositivos como unidades de cinta, o cajas de almacenamiento completas que contengan discos lógicos preconfigurados.
/sys/class/scsi_host/host*/firmware_revision
Este atributo contiene la versión del firmware del Smart Array.
Por ejemplo:

# cd /sys/class/scsi_host/host4;
# cat firmware_revision;
7.14

Archivos de atributo de disco específicos de HPSA en /sys

/sys/class/scsi_disk/c:b:t:l/device/unique_id
Este atributo contiene un ID único de 32 dígitos hexadecimales para cada disco lógico.
Por ejemplo:

# cd /sys/class/scsi_disk/4:0:0:0/device;
# cat unique_id;
600508B1001044395355323037570F77

/sys/class/scsi_disk/c:b:t:l/device/raid_level
Este atributo contiene el nivel RAID de cada disco lógico.
Por ejemplo:

# cd /sys/class/scsi_disk/4:0:0:0/device;
# cat raid_level;
RAID 0

/sys/class/scsi_disk/c:b:t:l/device/lunid
Este atributo contiene el ID LUN de 16 dígitos hexadecimales (8 bytes) por el cual se puede direccionar un disco lógico o un dispositivo físico. c:b:t:l son el controlador, bus, destino y lun del dispositivo.

Por ejemplo:


# cd /sys/class/scsi_disk/4:0:0:0/device;
# cat lunid;
0x0000004000000000

Operaciones ioctl() soportadas

Para compatibilidad con aplicaciones escritas para el controlador cciss(4), muchas, pero no todas, de las ioctls soportadas por el controlador cciss(4) también son soportadas por el controlador hpsa. Las estructuras de datos utilizadas por estas ioctls se describen en el archivo fuente del kernel de Linux include/linux/cciss_ioctl.h.

CCISS_DEREGDISK
CCISS_REGNEWDISK
CCISS_REGNEWD
Estas tres ioctls hacen exactamente lo mismo, que es hacer que el controlador vuelva a escanear en busca de nuevos dispositivos. Esto hace exactamente lo mismo que escribir en el atributo de host específico de hpsa "rescan".
CCISS_GETPCIINFO
Devuelve el dominio, bus, dispositivo y función PCI, y el "ID de placa" (ID de subsistema PCI).
CCISS_GETDRIVVER
Devuelve la versión del controlador en tres bytes codificados como:

(major_version << 16) | (minor_version << 8) |
    (subminor_version)

CCISS_PASSTHRU
CCISS_BIG_PASSTHRU
Permite que los comandos "BMIC" y "CISS" se pasen al Smart Array. Estos son utilizados extensamente por la Utilidad de Configuración de Arreglos de HP, agentes de almacenamiento SNMP, etc. Vea cciss_vol_status en http://cciss.sf.net para algunos ejemplos.
