CHESVXX calcula la solución al sistema de ecuaciones lineales A * X = B para matrices

HE

Propósito

: 
!>
!>    CHESVXX usa la factorización de pivoteo diagonal para calcular la
!>    solución a un sistema complejo de ecuaciones lineales A * X = B, donde
!>    A es una matriz hermitiana N por N y X y B son matrices
!>    N por NRHS.
!>
!>    Si se solicita, se devuelven tanto cotas de error en norma como
!>    cotas de error máximo componente a componente.
!>    CHESVXX devolverá una solución con un error
!>    garantizado minúsculo (O(eps) donde eps es la precisión
!>    de trabajo de la máquina) a menos que la matriz esté muy mal
!>    condicionada, en cuyo caso se devuelve una advertencia. También se
!>    calculan y devuelven los números de condición relevantes.
!>
!>    CHESVXX acepta factorizaciones y factores de equilibrado
!>    proporcionados por el usuario; consulte las definiciones de las opciones FACT y EQUED.
!>    Resolver con refinamiento y usando una factorización de una llamada
!>    anterior a CHESVXX también producirá una solución con errores
!>    O(eps) o advertencias, pero no podemos hacer esa afirmación para
!>    factorizaciones y factores de equilibrado proporcionados por el usuario
!>    si difieren de lo que CHESVXX produciría por sí mismo.
!
>

Descripción

: 
!>
!>    Se realizan los siguientes pasos:
!>
!>    1. Si FACT = 'E', se calculan factores de escala reales para equilibrar
!>    el sistema:
!>
!>      diag(S)*A*diag(S)     *inv(diag(S))*X = diag(S)*B
!>
!>    Si el sistema se equilibra o no depende de la
!>    escala de la matriz A, pero si se usa el equilibrado, A se
!>    sobrescribe con diag(S)*A*diag(S) y B con diag(S)*B.
!>
!>    2. Si FACT = 'N' o 'E', se usa la descomposición LU para factorizar
!>    la matriz A (después del equilibrado si FACT = 'E') como
!>
!>       A = U * D * U**T,  si UPLO = 'U', o
!>       A = L * D * L**T,  si UPLO = 'L',
!>
!>    donde U (o L) es un producto de matrices de permutación y triangulares
!>    superiores (inferiores) unitarias, y D es hermitiana y diagonal por bloques
!>    con bloques diagonales de tamaño 1 por 1 y 2 por 2.
!>
!>    3. Si algún D(i,i)=0, de modo que D es exactamente singular, la
!>    rutina retorna con INFO = i. De lo contrario, se usa la forma
!>    factorizada de A para estimar el número de condición de la matriz A (vea
!>    el argumento RCOND). Si el recíproco del número de condición es
!>    menor que la precisión de la máquina, la rutina continúa de todos modos para resolver
!>    X y calcular las cotas de error como se describe a continuación.
!>
!>    4. Se resuelve el sistema de ecuaciones para X usando la forma
!>    factorizada de A.
!>
!>    5. De forma predeterminada (a menos que PARAMS(LA_LINRX_ITREF_I) esté establecido en cero),
!>    la rutina usará refinamiento iterativo para intentar obtener un error
!>    pequeño y cotas de error. El refinamiento calcula el residuo con al
!>    menos el doble de la precisión de trabajo.
!>
!>    6. Si se usó el equilibrado, la matriz X se premultiplica por
!>    diag(R) de modo que resuelva el sistema original antes
!>    del equilibrado.
!
> 
!>     Algunos parámetros opcionales se agrupan en el array PARAMS. Estos
!>     ajustes determinan cómo se realiza el refinamiento, pero a menudo
!>     los valores predeterminados son aceptables. Si los valores predeterminados son aceptables, los usuarios
!>     pueden pasar NPARAMS = 0, lo que evita que el código fuente acceda
!>     al argumento PARAMS.
!
>

Parámetro

s
FACT 
!>          FACT es CHARACTER*1
!>     Especifica si la forma factorizada de la matriz A se
!>     proporciona en la entrada y, si no es así, si la matriz A debe
!>     equilibrarse antes de ser factorizada.
!>       = 'F':  En la entrada, AF e IPIV contienen la forma factorizada de A.
!>               Si EQUED no es 'N', la matriz A ha sido
!>               equilibrada con los factores de escala dados por S.
!>               A, AF e IPIV no se modifican.
!>       = 'N':  La matriz A se copiará en AF y se factorizará.
!>       = 'E':  La matriz A se equilibrará si es necesario, luego
!>               se copiará en AF y se factorizará.
!
>

UPL

O 
!>          UPLO es CHARACTER*1
!>       = 'U':  Se almacena el triángulo superior de A;
!>       = 'L':  Se almacena el triángulo inferior de A.
!
>

N 
!>          N es INTEGER
!>     El número de ecuaciones lineales, es decir, el orden de la
!>     matriz A.  N >= 0.
!
>

NRH

S 
!>          NRHS es INTEGER
!>     El número de miembros independientes (lados derechos), es decir, el número de columnas
!>     de las matrices B y X.  NRHS >= 0.
!
>

A 
!>          A es un array COMPLEX, dimensión (LDA,N)
!>     La matriz hermitiana A.  Si UPLO = 'U', la parte triangular superior
!>     principal N por N de A contiene la parte triangular superior
!>     de la matriz A, y la parte estrictamente triangular inferior
!>     de A no se referencia.  Si UPLO = 'L', la parte triangular inferior
!>     principal N por N de A contiene la parte triangular inferior
!>     de la matriz A, y la parte estrictamente triangular superior
!>     de A no se referencia.
!>
!>     Al salir, si FACT = 'E' y EQUED = 'Y', A se sobrescribe con
!>     diag(S)*A*diag(S).
!> >

LDA


!>          LDA es INTEGER
!>     La dimensión principal del array A.  LDA >= max(1,N).
!> 


AF


!>          AF es un array COMPLEX, dimensión (LDAF,N)
!>     Si FACT = 'F', entonces AF es un argumento de entrada y en la entrada
!>     contiene la matriz diagonal por bloques D y los multiplicadores
!>     utilizados para obtener el factor U o L de la factorización A =
!>     U*D*U**H o A = L*D*L**H tal como lo calcula CHETRF.
!>
!>     Si FACT = 'N', entonces AF es un argumento de salida y en la salida
!>     devuelve la matriz diagonal por bloques D y los multiplicadores
!>     utilizados para obtener el factor U o L de la factorización A =
!>     U*D*U**H o A = L*D*L**H.
!> 


LDAF


!>          LDAF es INTEGER
!>     La dimensión principal del array AF.  LDAF >= max(1,N).
!> 


IPIV


!>          IPIV es un array INTEGER, dimensión (N)
!>     Si FACT = 'F', entonces IPIV es un argumento de entrada y en la entrada
!>     contiene detalles de los intercambios y la estructura por bloques
!>     de D, tal como lo determina CHETRF.  Si IPIV(k) > 0,
!>     entonces las filas y columnas k e IPIV(k) fueron intercambiadas y
!>     D(k,k) es un bloque diagonal de tamaño 1 por 1.  Si UPLO = 'U' y
!>     IPIV(k) = IPIV(k-1) < 0, entonces las filas y columnas k-1 y
!>     -IPIV(k) fueron intercambiadas y D(k-1:k,k-1:k) es un bloque
!>     diagonal de tamaño 2 por 2.  Si UPLO = 'L' y IPIV(k) = IPIV(k+1) < 0,
!>     entonces las filas y columnas k+1 y -IPIV(k) fueron intercambiadas
!>     y D(k:k+1,k:k+1) es un bloque diagonal de tamaño 2 por 2.
!>
!>     Si FACT = 'N', entonces IPIV es un argumento de salida y en la salida
!>     contiene detalles de los intercambios y la estructura por bloques
!>     de D, tal como lo determina CHETRF.
!> 


EQUED


!>          EQUED es CHARACTER*1
!>     Especifica la forma de equilibrado que se realizó.
!>       = 'N':  Sin equilibrado (siempre cierto si FACT = 'N').
!>       = 'Y':  Equilibrado tanto por filas como por columnas, es decir, A ha sido
!>               reemplazado por diag(S) * A * diag(S).
!>     EQUED es un argumento de entrada si FACT = 'F'; de lo contrario, es un
!>     argumento de salida.
!> 


S


!>          S es un array REAL, dimensión (N)
!>     Los factores de escala para A.  Si EQUED = 'Y', A se multiplica por
!>     diag(S) a la izquierda y a la derecha.  S es un argumento de entrada si FACT =
!>     'F'; de lo contrario, S es un argumento de salida.  Si FACT = 'F' y EQUED
!>     = 'Y', cada elemento de S debe ser positivo.  Si S es de salida, cada
!>     elemento de S es una potencia de la base. Si S es de entrada, cada elemento
!>     de S debería ser una potencia de la base para asegurar una solución
!>     confiable y estimaciones de error. El escalamiento por potencias de la base no causa
!>     errores de redondeo a menos que el resultado desborde por arriba o por abajo.
!>     Los errores de redondeo durante el escalamiento conducen a un refinamiento con una matriz que
!>     no es equivalente a la matriz de entrada, produciendo estimaciones de error
!>     que pueden no ser confiables.
!> 


B


!>          B es un array COMPLEX, dimensión (LDB,NRHS)
!>     En la entrada, la matriz del lado derecho B de tamaño N por NRHS.
!>     En la salida,
!>     si EQUED = 'N', B no es modificado;
!>     si EQUED = 'Y', B es sobrescrito por diag(S)*B;
!> 


LDB


!>          LDB es INTEGER
!>     La dimensión principal del array B.  LDB >= max(1,N).
!> 


X


!>          X es un array COMPLEX, dimensión (LDX,NRHS)
!>     Si INFO = 0, la matriz de solución X de tamaño N por NRHS del sistema
!>     original de ecuaciones.  Tenga en cuenta que A y B son modificados en la salida si
!>     EQUED .ne. 'N', y la solución al sistema equilibrado es
!>     inv(diag(S))*X.
!> 


LDX


!>          LDX es INTEGER
!>     La dimensión principal del array X.  LDX >= max(1,N).
!> 


RCOND


!>          RCOND es REAL
!>     Número de condición recíproco escalado.  Esta es una estimación del
!>     recíproco del número de condición de Skeel de la matriz A después del
!>     equilibrado (si se hizo).  Si esto es menor que la precisión de la máquina
!>     (en particular, si es cero), la matriz es singular
!>     hasta la precisión de trabajo.  Tenga en cuenta que el error puede ser pequeño incluso
!>     si este número es muy pequeño y la matriz parece mal
!>     condicionada.
!> 


RPVGRW


!>          RPVGRW es REAL
!>     Crecimiento recíproco del pivote.  En la salida, esto contiene el factor
!>     de crecimiento recíproco del pivote norm(A)/norm(U). Se
!>     usa la norma.  Si esto es mucho menor que 1, entonces la estabilidad de
!>     la factorización LU de la matriz A (equilibrada) podría ser pobre.
!>     Esto también significa que la solución X, los números de condición estimados
!>     y los límites de error podrían no ser confiables. Si la factorización falla con
!>     0<INFO<=N, entonces esto contiene el factor de crecimiento recíproco del pivote
!>     para las primeras INFO columnas de A.
!> 


BERR


!>          BERR es un array REAL, dimensión (NRHS)
!>     Error hacia atrás relativo componente a componente.  Este es el
!>     error hacia atrás relativo componente a componente de cada vector de solución X(j)
!>     (es decir, el cambio relativo más pequeño en cualquier elemento de A o B que
!>     hace que X(j) sea una solución exacta).
!> 


N_ERR_BNDS


!>          N_ERR_BNDS es INTEGER
!>     Número de límites de error a devolver para cada lado derecho
!>     y cada tipo (norma a norma o componente a componente).  Vea ERR_BNDS_NORM y
!>     ERR_BNDS_COMP más abajo.
!> 


ERR_BNDS_NORM


!>          ERR_BNDS_NORM es un array REAL, dimensión (NRHS, N_ERR_BNDS)
!>     Para cada lado derecho, este array contiene información sobre
!>     varios límites de error y números de condición correspondientes al
!>     error relativo norma a norma, que se define de la siguiente manera:
!>
!>     Error relativo norma a norma en el i-ésimo vector de solución:
!>             max_j (abs(XTRUE(j,i) - X(j,i)))
!>            ------------------------------
!>                  max_j abs(X(j,i))
!>
!>     El array está indexado por el tipo de información de error como se describe
!>     a continuación. Actualmente hay hasta tres piezas de información
!>     devueltas.
!>
!>     El primer índice en ERR_BNDS_NORM(i,:) corresponde al i-ésimo
!>     lado derecho.
!>
!>     El segundo índice en ERR_BNDS_NORM(:,err) contiene los siguientes
!>     tres campos:
!>     err = 1  booleano. Confiar en la respuesta si el
!>              recíproco del número de condición es menor que el umbral
!>              sqrt(n) * slamch('Epsilon').
!>
!>     err = 2  límite de error: El error hacia adelante estimado,
!>              casi con certeza dentro de un factor de 10 del error real
!>              siempre que la siguiente entrada sea mayor que el umbral
!>              sqrt(n) * slamch('Epsilon'). Este límite de error solo
!>              debe confiarse si el booleano anterior es verdadero.
!>
!>     err = 3  Recíproco del número de condición: Recíproco estimado del número de condición
!>              norma a norma.  Se compara con el umbral
!>              sqrt(n) * slamch('Epsilon') para determinar si la
!>              estimación de error es . Estos recíprocos de números de condición
!>              son 1 / (norm(Z^{-1},inf) * norm(Z,inf)) para alguna
!>              matriz Z escalada apropiadamente.
!>              Sea Z = S*A, donde S escala cada fila por una potencia de la
!>              base de modo que todas las sumas absolutas de filas de Z sean aproximadamente 1.
!>
!>     Vea Lapack Working Note 165 para más detalles y precauciones
!>     adicionales.
!> 


ERR_BNDS_COMP


!>          ERR_BNDS_COMP es un array REAL, dimensión (NRHS, N_ERR_BNDS)
!>     Para cada lado derecho, este array contiene información sobre
!>     varios límites de error y números de condición correspondientes al
!>     error relativo componente a componente, que se define de la siguiente manera:
!>
!>     Error relativo componente a componente en el i-ésimo vector de solución:
!>                    abs(XTRUE(j,i) - X(j,i))
!>             max_j ----------------------
!>                         abs(X(j,i))
!>
!>     El array está indexado por el lado derecho i (del cual el
!>     error relativo componente a componente depende), y el tipo de información
!>     de error como se describe a continuación. Actualmente hay hasta tres
!>     piezas de información devueltas para cada lado derecho. Si
!>     la precisión componente a componente no es solicitada (PARAMS(3) = 0.0), entonces
!>     ERR_BNDS_COMP no es accedido.  Si N_ERR_BNDS < 3, entonces como máximo
!>     se devuelven las primeras (:,N_ERR_BNDS) entradas.
!>
!>     El primer índice en ERR_BNDS_COMP(i,:) corresponde al i-ésimo
!>     lado derecho.
!>
!>     El segundo índice en ERR_BNDS_COMP(:,err) contiene los siguientes
!>     tres campos:
!>     err = 1  booleano. Confiar en la respuesta si el
!>              recíproco del número de condición es menor que el umbral
!>              sqrt(n) * slamch('Epsilon').
!>
!>     err = 2  límite de error: El error hacia adelante estimado,
!>              casi con certeza dentro de un factor de 10 del error real
!>              siempre que la siguiente entrada sea mayor que el umbral
!>              sqrt(n) * slamch('Epsilon'). Este límite de error solo
!>              debe confiarse si el booleano anterior es verdadero.
!>
!>     err = 3  Recíproco del número de condición: Recíproco estimado del número de condición
!>              componente a componente.  Se compara con el umbral
!>              sqrt(n) * slamch('Epsilon') para determinar si la
!>              estimación de error es . Estos recíprocos de números de condición
!>              son 1 / (norm(Z^{-1},inf) * norm(Z,inf)) para alguna
!>              matriz Z escalada apropiadamente.
!>              Sea Z = S*(A*diag(x)), donde x es la solución para el
!>              lado derecho actual y S escala cada fila de
!>              A*diag(x) por una potencia de la base de modo que todas las sumas absolutas de filas de Z sean aproximadamente 1.
!>
!>     Vea Lapack Working Note 165 para más detalles y precauciones
!>     adicionales.
!> 


NPARAMS


!>          NPARAMS es INTEGER
!>     Especifica el número de parámetros establecidos en PARAMS.  Si <= 0, el
!>     array PARAMS nunca es referenciado y se usan valores predeterminados.
!> 


PARAMS


!>          PARAMS es un array REAL, dimensión NPARAMS
!>     Especifica parámetros del algoritmo.  Si una entrada es < 0.0, entonces
!>     esa entrada será rellenada con el valor predeterminado utilizado para ese
!>     parámetro.  Solo se accede a las posiciones hasta NPARAMS; se usan valores predeterminados
!>     para los parámetros numerados más altamente.
!>
!>       PARAMS(LA_LINRX_ITREF_I = 1) : Si realizar refinamiento
!>            iterativo o no.
!>         Predeterminado: 1.0
!>            = 0.0:  No se realiza refinamiento, y no se calculan límites de error.
!>            = 1.0:  Usar el algoritmo de refinamiento de doble precisión,
!>                    posiblemente con cálculos de doble-precisión simple si el
!>                    entorno de compilación no soporta DOUBLE
!>                    PRECISION.
!>              (otros valores están reservados para uso futuro)
!>
!>       PARAMS(LA_LINRX_ITHRESH_I = 2) : Número máximo de cálculos de residuo
!>            permitidos para el refinamiento.
!>         Predeterminado: 10
!>         Agresivo: Establecer a 100 para permitir la convergencia usando factorizaciones
!>                     aproximadas o factorizaciones distintas de LU. Si                     la factorización utiliza una técnica diferente a
!>                     la eliminación de Gauss, las garantías en
!>                     err_bnds_norm y err_bnds_comp pueden dejar de ser
!>                     fiables.
!>
!>       PARAMS(LA_LINRX_CWISE_I = 3) : Bandera que determina si el código
!>            intentará encontrar una solución con un pequeño error relativo
!>            componente a componente en el algoritmo de doble precisión.
!>            Positivo es verdadero, 0.0 es falso.
!>         Predeterminado: 1.0 (intentar convergencia componente a componente)
!
>

INF
O

!>          INFO es INTEGER
!>       = 0:  Salida exitosa. La solución para cada segundo miembro está
!>         garantizada.
!>       < 0:  Si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>       > 0 y <= N:  U(INFO,INFO) es exactamente cero. La factorización
!>         ha sido completada, pero el factor U es exactamente singular, por
!>         lo que la solución y los límites de error no pudieron ser calculados. Se devuelve
!>         RCOND = 0.
!>       = N+J: La solución correspondiente al J-ésimo segundo miembro no está
!>         garantizada. Las soluciones correspondientes a otros segundos
!>         miembros K con K > J pueden no estar garantizadas también, pero
!>         solo se reporta el primer segundo miembro de ese tipo. Si no se solicita un pequeño
!>         error componente a componente (PARAMS(3) = 0.0) entonces
!>         el J-ésimo segundo miembro es el primero con un límite de error
!>         normativo que no está garantizado (el J más pequeño tal
!>         que ERR_BNDS_NORM(J,1) = 0.0). Por defecto (PARAMS(3) = 1.0)
!>         el J-ésimo segundo miembro es el primero con un límite de error
!>         normativo o componente a componente que no está garantizado (el J más pequeño
!>         tal que ERR_BNDS_NORM(J,1) = 0.0 o
!>         ERR_BNDS_COMP(J,1) = 0.0). Ver la definición de
!>         ERR_BNDS_NORM(:,1) y ERR_BNDS_COMP(:,1). Para obtener información
!>         sobre todos los segundos miembros, consultar ERR_BNDS_NORM o
!>         ERR_BNDS_COMP.

subroutine csysvxx (character fact, character uplo, integer n, integer nrhs, complex, dimension( lda, * ) a, integer lda, complex, dimension( ldaf, * ) af, integer ldaf, integer, dimension( * ) ipiv, character equed, real, dimension( * ) s, complex, dimension( ldb, * ) b, integer ldb, complex, dimension( ldx, * ) x, integer ldx, real rcond, real rpvgrw, real, dimension( * ) berr, integer n_err_bnds, real, dimension( nrhs, * ) err_bnds_norm, real, dimension( nrhs, * ) err_bnds_comp, integer nparams, real, dimension( * ) params, complex, dimension( * ) work, real, dimension( * ) rwork, integer

info)

CSYSVXX calcula la solución al sistema de ecuaciones lineales A * X = B para matrices simétricas

(SY)

Propósito

: 
!>
!>    CSYSVXX usa la factorización por pivoteo diagonal para calcular la
!>    solución a un sistema complejo de ecuaciones lineales A * X = B, donde
!>    A es una matriz simétrica N por N y X y B son matrices
!>    N por NRHS.
!>
!>    Si se solicita, se devuelven tanto los límites de error normativos como los de
!>    error máximo componente a componente. CSYSVXX devolverá una solución con un
!>    error garantizado diminuto (O(eps) donde eps es la precisión
!>    de máquina de trabajo) a menos que la matriz esté muy mal condicionada, en cuyo
!>    caso se devuelve una advertencia. Los números de condición relevantes también son
!>    calculados y devueltos.
!>
!>    CSYSVXX acepta factorizaciones y factores de equilibrado
!>    proporcionados por el usuario; ver las definiciones de las opciones FACT y EQUED.
!>    Resolver con refinamiento y usando una factorización de una llamada
!>    anterior a CSYSVXX también producirá una solución con errores
!>    O(eps) o advertencias, pero no podemos hacer esa afirmación para
!>    factorizaciones y factores de equilibrado proporcionados por el usuario generales
!>    si difieren de lo que CSYSVXX produciría por sí mismo.
!
>

Descripción

: 
!>
!>    Se realizan los siguientes pasos:
!>
!>    1. Si FACT = 'E', se calculan factores de escala reales para equilibrar
!>    el sistema:
!>
!>      diag(S)*A*diag(S)     *inv(diag(S))*X = diag(S)*B
!>
!>    Si el sistema se equilibra o no depende de la
!>    escala de la matriz A, pero si se usa el equilibrado, A es
!>    sobrescrito por diag(S)*A*diag(S) y B por diag(S)*B.
!>
!>    2. Si FACT = 'N' o 'E', se usa la descomposición LU para factorizar
!>    la matriz A (después del equilibrado si FACT = 'E') como
!>
!>       A = U * D * U**T,  si UPLO = 'U', o
!>       A = L * D * L**T,  si UPLO = 'L',
!>
!>    donde U (o L) es un producto de matrices de permutación y triangulares
!>    superiores (inferiores) unitarias, y D es simétrica y diagonal por bloques con
!>    bloques diagonales de tamaño 1 por 1 y 2 por 2.
!>
!>    3. Si algún D(i,i)=0, de modo que D es exactamente singular, entonces la
!>    rutina retorna con INFO = i. De lo contrario, la forma factorizada de A
!>    se usa para estimar el número de condición de la matriz A (ver
!>    el argumento RCOND).  Si el recíproco del número de condición es
!>    menor que la precisión de máquina, la rutina continúa igualmente para resolver
!>    para X y calcular los límites de error como se describe a continuación.
!>
!>    4. El sistema de ecuaciones se resuelve para X usando la forma factorizada
!>    de A.
!>
!>    5. Por defecto (a menos que PARAMS(LA_LINRX_ITREF_I) se establezca en cero),
!>    la rutina usará refinamiento iterativo para intentar obtener un
!>    pequeño error y límites de error.  El refinamiento calcula el residuo con
!>    al menos el doble de la precisión de trabajo.
!>
!>    6. Si se usó el equilibrado, la matriz X se premultiplica por
!>    diag(R) de modo que resuelva el sistema original antes
!>    del equilibrado.
!
> 
!>     Algunos parámetros opcionales están agrupados en el arreglo PARAMS.  Estas
!>     configuraciones determinan cómo se realiza el refinamiento, pero a menudo los
!>     valores predeterminados son aceptables.  Si los valores predeterminados son aceptables, los usuarios
!>     pueden pasar NPARAMS = 0 lo que evita que el código fuente acceda
!>     al argumento PARAMS.
!
>

Parámetro

s
FACT 
!>          FACT es CHARACTER*1
!>     Especifica si la forma factorizada de la matriz A es
!>     proporcionada en la entrada, y si no lo es, si la matriz A debe ser
!>     equilibrada antes de ser factorizada.
!>       = 'F':  En la entrada, AF e IPIV contienen la forma factorizada de A.
!>               Si EQUED no es 'N', la matriz A ha sido
!>               equilibrada con factores de escala dados por S.
!>               A, AF e IPIV no son modificados.
!>       = 'N':  La matriz A será copiada a AF y factorizada.
!>       = 'E':  La matriz A será equilibrada si es necesario, luego
!>               copiada a AF y factorizada.
!
>

UPL

O 
!>          UPLO es CHARACTER*1
!>       = 'U':  Se almacena el triángulo superior de A;
!>       = 'L':  Se almacena el triángulo inferior de A.
!
>

N 
!>          N es INTEGER
!>     El número de ecuaciones lineales, es decir, el orden de la
!>     matriz A.  N >= 0.
!
>

S 
!>          NRHS es INTEGER
!>     El número de segundos miembros, es decir, el número de columnas
!>     de las matrices B y X.  NRHS >= 0.
!
>

A 
!>          A es un arreglo COMPLEX, dimensión (LDA,N)
!>     La matriz simétrica A.  Si UPLO = 'U', la parte triangular superior
!>     principal N por N de A contiene la parte triangular superior
!>     de la matriz A, y la parte estrictamente triangular inferior
!>     de A no es referenciada.  Si UPLO = 'L', la parte
!>     triangular inferior principal N por N de A contiene la parte
!>     triangular inferior de la matriz A, y la parte estrictamente
!>     triangular superior de A no es referenciada.
!>

!>     diag(S)*A*diag(S).
!

A

!>     La dimensión principal del arreglo A.  LDA >= max(1,N).

F 
!>          AF es un arreglo COMPLEX, dimensión (LDAF,N)
!>     Si FACT = 'F', entonces AF es un argumento de entrada y en la entrada
!>     contiene la matriz diagonal por bloques D y los multiplicadores
!>     usados para obtener el factor U o L de la factorización A =
!>     U*D*U**T o A = L*D*L**T como lo calculó CSYTRF.
!>
!>     Si FACT = 'N', entonces AF es un argumento de salida y en la salida
!>     devuelve la matriz diagonal por bloques D y los multiplicadores
!>     usados para obtener el factor U o L de la factorización A =
!>     U*D*U**T o A = L*D*L**T.
!
>

LDA

F 
!>          LDAF es INTEGER
!>     La dimensión principal del arreglo AF.  LDAF >= max(1,N).
!
>

IPI

V 
!>          IPIV es un arreglo INTEGER, dimensión (N)
!>     Si FACT = 'F', entonces IPIV es un argumento de entrada y en la entrada
!>     contiene detalles de los intercambios y la estructura por
!>     bloques de D, como lo determinó CSYTRF.  Si IPIV(k) > 0,
!>     entonces las filas y columnas k e IPIV(k) fueron intercambiadas y
!>     D(k,k) es un bloque diagonal de tamaño 1 por 1.  Si UPLO = 'U' y
!>     IPIV(k) = IPIV(k-1) < 0, entonces las filas y columnas k-1 y
!>     -IPIV(k) fueron intercambiadas y D(k-1:k,k-1:k) es un bloque
!>     diagonal de tamaño 2 por 2.  Si UPLO = 'L' y IPIV(k) = IPIV(k+1) < 0,
!>     entonces las filas y columnas k+1 y -IPIV(k) fueron intercambiadas
!>     y D(k:k+1,k:k+1) es un bloque diagonal de tamaño 2 por 2.
!>
!>     Si FACT = 'N', entonces IPIV es un argumento de salida y en la salida
!>     contiene detalles de los intercambios y la estructura por
!>     bloques de D, como lo determinó CSYTRF.
!

D 
!>          EQUED es CHARACTER*1
!>     Especifica la forma de equilibrado que fueuno.
!>       = 'N':  Sin ecualización (siempre cierto si FACT = 'N').
!>       = 'Y':  Tanto la ecualización de filas como de columnas, es decir, A ha sido
!>               reemplazado por diag(S) * A * diag(S).
!>     EQUED es un argumento de entrada si FACT = 'F'; de lo contrario, es un
!>     argumento de salida.
!>

S

!>          S es un arreglo REAL, dimensión (N)
!>     Los factores de escala para A. Si EQUED = 'Y', A se multiplica por
!>     diag(S) a la izquierda y a la derecha. S es un argumento de entrada si FACT =
!>     'F'; de lo contrario, S es un argumento de salida. Si FACT = 'F' y EQUED
!>     = 'Y', cada elemento de S debe ser positivo. Si S es de salida, cada
!>     elemento de S es una potencia de la base. Si S es de entrada, cada elemento
!>     de S debe ser una potencia de la base para garantizar una solución
!>     fiable y estimaciones de error. El escalado por potencias de la base no causa
!>     errores de redondeo a menos que el resultado desborde por arriba o por abajo.
!>     Los errores de redondeo durante el escalado conducen a un refinamiento con una matriz que
!>     no es equivalente a la matriz de entrada, produciendo estimaciones de error
!>     que pueden no ser fiables.
!>

B

!>          B es un arreglo COMPLEX, dimensión (LDB,NRHS)
!>     En la entrada, la matriz del lado derecho B de dimensiones N-por-NRHS.
!>     En la salida,
!>     si EQUED = 'N', B no se modifica;
!>     si EQUED = 'Y', B se sobrescribe con diag(S)*B;
!>

LDB

!>          LDB es INTEGER
!>     La dimensión principal del arreglo B. LDB >= max(1,N).
!>

X

!>          X es un arreglo COMPLEX, dimensión (LDX,NRHS)
!>     Si INFO = 0, la matriz de solución X de dimensiones N-por-NRHS al sistema original
!>     de ecuaciones. Tenga en cuenta que A y B se modifican en la salida si
!>     EQUED .ne. 'N', y la solución al sistema ecualizado es
!>     inv(diag(S))*X.
!>

LDX

!>          LDX es INTEGER
!>     La dimensión principal del arreglo X. LDX >= max(1,N).
!>

RCOND

!>          RCOND es REAL
!>     Número de condición recíproco escalado. Esta es una estimación del
!>     recíproco del número de condición de Skeel de la matriz A después de
!>     la ecualización (si se hizo). Si esto es menor que la precisión
!>     de la máquina (en particular, si es cero), la matriz es singular
!>     a la precisión de trabajo. Tenga en cuenta que el error puede seguir siendo pequeño incluso
!>     si este número es muy pequeño y la matriz parece mal
!>     condicionada.
!>

RPVGRW

!>          RPVGRW es REAL
!>     Crecimiento recíproco del pivote. En la salida, esto contiene el factor de
!>     crecimiento recíproco del pivote norm(A)/norm(U). Se usa la
!>     norma. Si esto es mucho menor que 1, entonces la estabilidad de
!>     la factorización LU de la matriz A (ecualizada) podría ser deficiente.
!>     Esto también significa que la solución X, los números de condición estimados
!>     y los límites de error podrían no ser fiables. Si la factorización falla con
!>     0<INFO<=N, entonces esto contiene el factor de crecimiento recíproco del pivote
!>     para las primeras INFO columnas de A.
!>

BERR

!>          BERR es un arreglo REAL, dimensión (NRHS)
!>     Error hacia atrás relativo componente a componente. Este es el
!>     error hacia atrás relativo componente a componente de cada vector de solución X(j)
!>     (es decir, el cambio relativo más pequeño en cualquier elemento de A o B que
!>     hace que X(j) sea una solución exacta).
!>

N_ERR_BNDS

!>          N_ERR_BNDS es INTEGER
!>     Número de límites de error a devolver para cada lado derecho
!>     y cada tipo (en norma o componente a componente). Vea ERR_BNDS_NORM y
!>     ERR_BNDS_COMP más abajo.
!>

ERR_BNDS_NORM

!>          ERR_BNDS_NORM es un arreglo REAL, dimensión (NRHS, N_ERR_BNDS)
!>     Para cada lado derecho, este arreglo contiene información sobre
!>     varios límites de error y números de condición correspondientes al
!>     error relativo en norma, que se define de la siguiente manera:
!>
!>     Error relativo en norma en el i-ésimo vector de solución:
!>             max_j (abs(XTRUE(j,i) - X(j,i)))
!>            ------------------------------
!>                  max_j abs(X(j,i))
!>
!>     El arreglo se indexa por el tipo de información de error como se describe
!>     a continuación. Actualmente hay hasta tres piezas de información
!>     devueltas.
!>
!>     El primer índice en ERR_BNDS_NORM(i,:) corresponde al i-ésimo
!>     lado derecho.
!>
!>     El segundo índice en ERR_BNDS_NORM(:,err) contiene los siguientes
!>     tres campos:
!>     err = 1  booleano. Confiar en la respuesta si el
!>              recíproco del número de condición es menor que el umbral
!>              sqrt(n) * slamch('Epsilon').
!>
!>     err = 2  límite de error: El error hacia adelante estimado,
!>              casi ciertamente dentro de un factor de 10 del error real
!>              siempre que la siguiente entrada sea mayor que el umbral
!>              sqrt(n) * slamch('Epsilon'). Este límite de error solo debe
!>              ser confiado si el booleano anterior es verdadero.
!>
!>     err = 3  Recíproco del número de condición: Recíproco del número de condición en norma estimado.
!>              Se compara con el umbral
!>              sqrt(n) * slamch('Epsilon') para determinar si la estimación
!>              de error es . Estos recíprocos de los números de condición
!>              son 1 / (norm(Z^{-1},inf) * norm(Z,inf)) para alguna
!>              matriz Z escalada adecuadamente.
!>              Sea Z = S*A, donde S escala cada fila por una potencia de la
!>              base de modo que todas las sumas absolutas de filas de Z sean aproximadamente 1.
!>
!>     Vea la Nota de Trabajo de Lapack 165 para más detalles y precauciones
!>     adicionales.
!>

!>          ERR_BNDS_COMP es un arreglo REAL, dimensión (NRHS, N_ERR_BNDS)
!>     Para cada lado derecho, este arreglo contiene información sobre
!>     varios límites de error y números de condición correspondientes al
!>     error relativo componente a componente, que se define de la siguiente manera:
!>
!>     Error relativo componente a componente en el i-ésimo vector de solución:
!>                    abs(XTRUE(j,i) - X(j,i))
!>             max_j ----------------------
!>                         abs(X(j,i))
!>
!>     El arreglo se indexa por el lado derecho i (del cual depende el
!>     error relativo componente a componente), y el tipo de información de
!>     error como se describe a continuación. Actualmente hay hasta tres
!>     piezas de información devueltas para cada lado derecho. Si
!>     no se solicita precisión componente a componente (PARAMS(3) = 0.0), entonces
!>     no se accede a ERR_BNDS_COMP. Si N_ERR_BNDS < 3, entonces como máximo
!>     se devuelven las primeras entradas (:,N_ERR_BNDS).
!>
!>     El primer índice en ERR_BNDS_COMP(i,:) corresponde al i-ésimo
!>     lado derecho.
!>
!>     El segundo índice en ERR_BNDS_COMP(:,err) contiene los siguientes
!>     tres campos:
!>     err = 1  booleano. Confiar en la respuesta si el
!>              recíproco del número de condición es menor que el umbral
!>              sqrt(n) * slamch('Epsilon').
!>
!>     err = 2  límite de error: El error hacia adelante estimado,
!>              casi ciertamente dentro de un factor de 10 del error real
!>              siempre que la siguiente entrada sea mayor que el umbral
!>              sqrt(n) * slamch('Epsilon'). Este límite de error solo debe
!>              ser confiado si el booleano anterior es verdadero.
!>
!>     err = 3  Recíproco del número de condición: Recíproco del número de condición componente a componente estimado.
!>              Se compara con el umbral
!>              sqrt(n) * slamch('Epsilon') para determinar si la estimación
!>              de error es . Estos recíprocos de los números de condición
!>              son 1 / (norm(Z^{-1},inf) * norm(Z,inf)) para alguna
!>              matriz Z escalada adecuadamente.
!>              Sea Z = S*(A*diag(x)), donde x es la solución para el
!>              lado derecho actual y S escala cada fila de
!>              A*diag(x) por una potencia de la base de modo que todas las sumas absolutas de filas
!>              de Z sean aproximadamente 1.
!>
!>     Vea la Nota de Trabajo de Lapack 165 para más detalles y precauciones
!>     adicionales.
!>

NPARAMS

!>          NPARAMS es INTEGER
!>     Especifica el número de parámetros establecidos en PARAMS. Si <= 0, el

!>          PARAMS es un arreglo REAL, dimensión NPARAMS
!>     Especifica los parámetros del algoritmo. Si una entrada es < 0.0, entonces

!>    el sistema:

!>

!>    solución a un sistema real de ecuaciones lineales A * X = B, donde A
!>    es una matriz simétrica N por N y X y B son matrices N por NRHS.
!>
!>    Si se solicita, se devuelven tanto los límites de error en norma como
!>    los de error máximo componente a componente. SSYSVXX devolverá una
!>    solución con un error garantizado minúsculo (O(eps) donde eps es la
!>    precisión de la máquina de trabajo) a menos que la matriz esté muy mal
!>    condicionada, en cuyo caso se devuelve una advertencia. También se
!>    calculan y devuelven los números de condición relevantes.
!>
!>    SSYSVXX acepta factorizaciones y factores de equilibrado proporcionados
!>    por el usuario; consulte las definiciones de las opciones FACT y EQUED.
!>    Resolver con refinamiento y usando una factorización de una llamada
!>    anterior a SSYSVXX también producirá una solución con errores O(eps)
!>    o advertencias, pero no podemos hacer esa afirmación para
!>    factorizaciones y factores de equilibrado generales proporcionados por
!>    el usuario si difieren de lo que SSYSVXX produciría por sí mismo.
!>

!>    Se realizan los siguientes pasos:
!>

!>    el sistema:
!>
!>      diag(S)*A*diag(S)     *inv(diag(S))*X = diag(S)*B
!>
!>    Si el sistema se equilibra o no depende de la escala de la matriz A,
!>    pero si se usa el equilibrado, A se sobrescribe con diag(S)*A*diag(S)
!>    y B con diag(S)*B.

!>    la matriz A (después del equilibrado si FACT = 'E') como
!>

!>       A = L * D * L**T,  si UPLO = 'L',

!>    donde U (o L) es un producto de matrices de permutación y triangulares

!>    bloques con bloques diagonales de 1 por 1 y 2 por 2.

!>    que la precisión de la máquina, la rutina continúa igualmente para
!>    resolver X y calcular los límites de error como se describe a
!>    continuación.

ZHESVXX calcula la solución al sistema de ecuaciones lineales A * X = B para matrices

HE

Propósito

: 
!>
!>    ZHESVXX usa la factorización de pivoteo diagonal para calcular la
!>    solución a un sistema de ecuaciones lineales complejas*16 A * X = B, donde
!>    A es una matriz Hermitiana N-por-N y X y B son matrices
!>    N-por-NRHS.
!>
!>    Si se solicita, se devuelven tanto límites de error en norma como
!>    de error máximo componente a componente. ZHESVXX devolverá una solución con un
!>    error garantizado minúsculo (O(eps) donde eps es la precisión
!>    de máquina de trabajo) a menos que la matriz esté muy mal condicionada, en cuyo
!>    caso se devuelve una advertencia. También se calculan y devuelven los números de
!>    condición relevantes.
!>
!>    ZHESVXX acepta factorizaciones y factores de equilibrado
!>    proporcionados por el usuario; consulte las definiciones de las opciones FACT y EQUED.
!>    Resolver con refinamiento y usando una factorización de una llamada previa
!>    ZHESVXX también producirá una solución con errores o advertencias
!>    de O(eps), pero no podemos hacer esa afirmación para factorizaciones
!>    y factores de equilibrado proporcionados por el usuario en general
!>    si difieren de lo que ZHESVXX produciría por sí mismo.
!>

Descripción:

!>
!>    Se realizan los siguientes pasos:
!>
!>    1. Si FACT = 'E', se calculan factores de escala de doble precisión para equilibrar
!>    el sistema:
!>
!>      diag(S)*A*diag(S)     *inv(diag(S))*X = diag(S)*B
!>
!>    Si el sistema se equilibra o no depende de la
!>    escala de la matriz A, pero si se usa el equilibrado, A es
!>    sobrescrita por diag(S)*A*diag(S) y B por diag(S)*B.
!>
!>    2. Si FACT = 'N' o 'E', se usa la descomposición LU para factorizar
!>    la matriz A (después del equilibrado si FACT = 'E') como
!>
!>       A = U * D * U**T,  si UPLO = 'U', o
!>       A = L * D * L**T,  si UPLO = 'L',
!>
!>    donde U (o L) es un producto de matrices de permutación y triangulares
!>    superiores (inferiores) unitarias, y D es hermitiana y diagonal por bloques
!>    con bloques diagonales de tamaño 1x1 y 2x2.
!>
!>    3. Si algún D(i,i)=0, de modo que D es exactamente singular, entonces la
!>    rutina retorna con INFO = i. De lo contrario, la forma factorizada de A
!>    se usa para estimar el número de condición de la matriz A (ver
!>    el argumento RCOND).  Si el recíproco del número de condición es
!>    menor que la precisión de máquina, la rutina continúa igualmente para resolver
!>    para X y calcular límites de error como se describe a continuación.
!>
!>    4. Se resuelve el sistema de ecuaciones para X usando la forma factorizada
!>    de A.
!>
!>    5. Por defecto (a menos que PARAMS(LA_LINRX_ITREF_I) se establezca en cero),
!>    la rutina usará refinamiento iterativo para intentar obtener un error
!>    pequeño y límites de error.  El refinamiento calcula el residuo con al
!>    menos el doble de la precisión de trabajo.
!>
!>    6. Si se usó el equilibrado, la matriz X se premultiplica por
!>    diag(R) de modo que resuelva el sistema original antes del
!>    equilibrado.
!> 
!>     Algunos parámetros opcionales se agrupan en el arreglo PARAMS.  Estas
!>     configuraciones determinan cómo se realiza el refinamiento, pero a menudo
!>     los valores por defecto son aceptables.  Si los valores por defecto son aceptables, los usuarios
!>     pueden pasar NPARAMS = 0, lo que evita que el código fuente acceda
!>     al argumento PARAMS.
!>

NAME


ZSYSVXX - ZSYSVXX computes the solution to system of linear equations A * X = B for SY matrices


SYNOPSIS


   EXTERNAL ZSYSVXX
   ...
   call ZSYSVXX(FACT, UPLO, N, NRHS, A, LDA, AF, LDAF, IPIV, EQUED, S, B, LDB, X, LDX, RCOND, RPVGRW, BERR, N_ERR_BNDS, ERR_BNDS_NORM, ERR_BNDS_COMP, NPARAMS, PARAMS, WORK, RWORK, INFO)



DESCRIPTION



ZSYSVXX uses the diagonal pivoting factorization to compute the solution to a complex*16 system of linear equations A * X = B, where A is an N-by-N symmetric matrix and X and B are N-by-NRHS matrices.




If requested, both normwise and maximum componentwise error bounds are returned. ZSYSVXX will return a solution with a tiny guaranteed error (O(eps) where eps is the working machine precision) unless the matrix is very ill-conditioned, in which case a warning is returned. Relevant condition numbers also are calculated and returned.




ZSYSVXX accepts user-provided factorizations and equilibration factors; see the definitions of the FACT and EQUED options. Solving with refinement and using a factorization from a previous ZSYSVXX call will also produce a solution with either O(eps) errors or warnings, but we cannot make that claim for general user-provided factorizations and equilibration factors if they differ from what ZSYSVXX would itself produce.




The following steps are performed:



    

  1. 
If FACT = 'E', double precision scaling factors are computed to equilibrate the system:

      diag(S)*A*diag(S)     *inv(diag(S))*X = diag(S)*B

    
Whether or not the system will be equilibrated depends on the scaling of the matrix A, but if equilibration is used, A is overwritten by diag(S)*A*diag(S) and B by diag(S)*B.

    2. 

  2. 
If FACT = 'N' or 'E', the LU decomposition is used to factor the matrix A (after equilibration if FACT = 'E') as

      A = U * D * U**T,  if UPLO = 'U', or
  A = L * D * L**T,  if UPLO = 'L',

    
where U (or L) is a product of permutation and unit upper (lower) triangular matrices, and D is symmetric and block diagonal with 1-by-1 and 2-by-2 diagonal blocks.

    3. 

  3. 
If some D(i,i)=0, so that D is exactly singular, then the routine returns with INFO = i. Otherwise, the factored form of A is used to estimate the condition number of the matrix A (see argument RCOND). If the reciprocal of the condition number is less than machine precision, the routine still goes on to solve for X and compute error bounds as described below.

    4. 




The routine computes a solution X to the system A*X = B, and provides an estimate of the relative error in X computed in terms of the infinity norm.




The solution is computed by the following means:



    

  1. 
If PARAMS(LA_LINRX_ITREF_I) = 1.0, the solution is computed by iterative refinement.

    2. 

  2. 
Otherwise a direct solution is computed.

    3. 




(See LAPACK Working Note 176 for details.)

!>       = 'U':  Se almacena el triángulo superior de A;
!>       = 'L':  Se almacena el triángulo inferior de A.
!>

N

!>          N es INTEGER
!>     El número de ecuaciones lineales, es decir, el orden de la
!>     matriz A.  N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>     El número de miembros independientes, es decir, el número de columnas
!>     de las matrices B y X.  NRHS >= 0.
!>

A

!>          A es un array COMPLEX*16, dimensión (LDA,N)
!>     La matriz simétrica A.  Si UPLO = 'U', la parte triangular superior
!>     principal N-by-N de A contiene la parte triangular superior
!>     de la matriz A, y la parte estrictamente triangular inferior
!>     de A no se referencia.  Si UPLO = 'L', la parte triangular inferior
!>     principal N-by-N de A contiene la parte triangular inferior
!>     de la matriz A, y la parte estrictamente triangular superior
!>     de A no se referencia.
!>
!>     En la salida, si FACT = 'E' y EQUED = 'Y', A se sobrescribe con
!>     diag(S)*A*diag(S).
!>

LDA

!>          LDA es INTEGER
!>     La dimensión principal del array A.  LDA >= max(1,N).
!>

AF

!>          AF es un array COMPLEX*16, dimensión (LDAF,N)
!>     Si FACT = 'F', entonces AF es un argumento de entrada y en la entrada
!>     contiene la matriz diagonal por bloques D y los multiplicadores
!>     utilizados para obtener el factor U o L de la factorización A =
!>     U*D*U**T o A = L*D*L**T como lo calcula ZSYTRF.
!>
!>     Si FACT = 'N', entonces AF es un argumento de salida y en la salida
!>     devuelve la matriz diagonal por bloques D y los multiplicadores
!>     utilizados para obtener el factor U o L de la factorización A =
!>     U*D*U**T o A = L*D*L**T.
!>

LDAF

!>          LDAF es INTEGER
!>     La dimensión principal del array AF.  LDAF >= max(1,N).
!>

IPIV

!>          IPIV es un array INTEGER, dimensión (N)
!>     Si FACT = 'F', entonces IPIV es un argumento de entrada y en la entrada
!>     contiene detalles de los intercambios y la estructura
!>     por bloques de D, como lo determina ZSYTRF.  Si IPIV(k) > 0,
!>     entonces las filas y columnas k e IPIV(k) se intercambiaron y
!>     D(k,k) es un bloque diagonal de 1-by-1.  Si UPLO = 'U' y
!>     IPIV(k) = IPIV(k-1) < 0, entonces las filas y columnas k-1 y
!>     -IPIV(k) se intercambiaron y D(k-1:k,k-1:k) es un bloque
!>     diagonal de 2-by-2.  Si UPLO = 'L' y IPIV(k) = IPIV(k+1) < 0,
!>     entonces las filas y columnas k+1 y -IPIV(k) se intercambiaron
!>     y D(k:k+1,k:k+1) es un bloque diagonal de 2-by-2.
!>
!>     Si FACT = 'N', entonces IPIV es un argumento de salida y en la salida
!>     contiene detalles de los intercambios y la estructura
!>     por bloques de D, como lo determina ZSYTRF.
!>

EQUED

!>          EQUED es CHARACTER*1
!>     Especifica la forma de ecualizado que se realizó.
!>       = 'N':  Sin ecualizado (siempre cierto si FACT = 'N').
!>       = 'Y':  Ecualizado tanto de filas como de columnas, es decir, A ha sido
!>               reemplazada por diag(S) * A * diag(S).
!>     EQUED es un argumento de entrada si FACT = 'F'; de lo contrario, es un
!>     argumento de salida.
!>

S

!>          S es un array DOUBLE PRECISION, dimensión (N)
!>     Los factores de escala para A.  Si EQUED = 'Y', A se multiplica por
!>     diag(S) a la izquierda y a la derecha.  S es un argumento de entrada si FACT =
!>     'F'; de lo contrario, S es un argumento de salida.  Si FACT = 'F' y EQUED
!>     = 'Y', cada elemento de S debe ser positivo.  Si S es de salida, cada
!>     elemento de S es una potencia de la base. Si S es de entrada, cada elemento
!>     de S debe ser una potencia de la base para garantizar una solución
!>     y estimaciones de error fiables. El escalamiento por potencias de la base no causa
!>     errores de redondeo a menos que el resultado se desborde o se subdesborde.
!>     Los errores de redondeo durante el escalamiento conducen a un refinamiento con una matriz que
!>     no es equivalente a la matriz de entrada, produciendo estimaciones de error
!>     que pueden no ser fiables.
!>

B

!>          B es un array COMPLEX*16, dimensión (LDB,NRHS)
!>     En la entrada, la matriz de miembros independientes B de N-by-NRHS.
!>     En la salida,
!>     si EQUED = 'N', B no se modifica;
!>     si EQUED = 'Y', B se sobrescribe con diag(S)*B;
!>

LDB

!>          LDB es INTEGER
!>     La dimensión principal del array B.  LDB >= max(1,N).
!>

X

!>          X es un array COMPLEX*16, dimensión (LDX,NRHS)
!>     Si INFO = 0, la matriz de solución X de N-by-NRHS al sistema original
!>     de ecuaciones.  Tenga en cuenta que A y B se modifican en la salida si
!>     EQUED .ne. 'N', y la solución al sistema ecualizado es
!>     inv(diag(S))*X.
!>

LDX

!>          LDX es INTEGER
!>     La dimensión principal del array X.  LDX >= max(1,N).
!>

RCOND

!>          RCOND es DOUBLE PRECISION
!>     Número de condición recíproco escalado.  Esta es una estimación del
!>     recíproco del número de condición de Skeel de la matriz A después
!>     del ecualizado (si se hizo).  Si esto es menor que la precisión
!>     de la máquina (en particular, si es cero), la matriz es singular
!>     con respecto a la precisión de trabajo.  Tenga en cuenta que el error puede seguir siendo pequeño incluso
!>     si este número es muy pequeño y la matriz parece mal
!>     condicionada.
!>

RPVGRW

!>          RPVGRW es DOUBLE PRECISION
!>     Crecimiento recíproco del pivote.  En la salida, contiene el factor de
!>     crecimiento recíproco del pivote norm(A)/norm(U). Se utiliza la
!>     norma.  Si esto es mucho menor que 1, entonces la estabilidad de
!>     la factorización LU de la matriz A (ecualizada) podría ser deficiente.
!>     Esto también significa que la solución X, los números de condición
!>     estimados y los límites de error podrían no ser fiables. Si la factorización falla con
!>     0<INFO<=N, entonces contiene el factor de crecimiento recíproco del pivote
!>     para las primeras INFO columnas de A.
!>

BERR

!>          BERR es un array DOUBLE PRECISION, dimensión (NRHS)
!>     Error hacia atrás relativo componente a componente.  Este es el
!>     error hacia atrás relativo componente a componente de cada vector de solución X(j)
!>     (es decir, el cambio relativo más pequeño en cualquier elemento de A o B que
!>     hace que X(j) sea una solución exacta).
!>

N_ERR_BNDS

!>          N_ERR_BNDS es INTEGER
!>     Número de límites de error a devolver para cada miembro independiente
!>     y cada tipo (con norma o componente a componente).  Vea ERR_BNDS_NORM y
!>     ERR_BNDS_COMP más abajo.
!>

ERR_BNDS_NORM

!>          ERR_BNDS_NORM es un array DOUBLE PRECISION, dimensión (NRHS, N_ERR_BNDS)
!>     Para cada miembro independiente, este array contiene información sobre
!>     varios límites de error y números de condición correspondientes a la
!>     error relativo con norma, que se define de la siguiente manera:
!>
!>     Error relativo con norma en el i-ésimo vector de solución:
!>             max_j (abs(XTRUE(j,i) - X(j,i)))
!>            ------------------------------
!>                  max_j abs(X(j,i))
!>
!>     El array se indexa por el tipo de información de error como se describe
!>     a continuación. Actualmente se devuelven hasta tres piezas de información.
!>
!>     El primer índice en ERR_BNDS_NORM(i,:) corresponde al i-ésimo
!>     miembro independiente.
!>
!>     El segundo índice en ERR_BNDS_NORM(:,err) contiene los siguientes
!>     tres campos:
!>     err = 1  booleano. Confiar en la respuesta si el
!>              recíproco del número de condición es menor que el umbral
!>              sqrt(n) * dlamch('Epsilon').
!>
!>     err = 2  límite de error: El error hacia adelante estimado,
!>              casi con certeza dentro de un factor de 10 del error real
!>              siempre que la siguiente entrada sea mayor que el umbral
!>              sqrt(n) * dlamch('Epsilon'). Este límite de error solo
!>              debe confiarse si el booleano anterior es verdadero.
!>
!>     err = 3  Recíproco del número de condición: Recíproco del número de condición
!>              con norma estimado.  Se compara con el umbral
!>              sqrt(n) * dlamch('Epsilon') para determinar si la
!>              estimación de error es . Estos recíprocos de los números de
!>              condición son 1 / (norm(Z^{-1},inf) * norm(Z,inf)) para alguna
!>              matriz Z escalada adecuadamente.
!>              Sea Z = S*A, donde S escala cada fila por una potencia de la
!>              base de modo que todas las sumas absolutas de filas de Z sean aproximadamente 1.
!>
!>     Vea la Nota de Trabajo de Lapack 165 para más detalles y precauciones
!>     adicionales.
!>

ERR_BNDS_COMP

!>          ERR_BNDS_COMP es un array DOUBLE PRECISION, dimensión (NRHS, N_ERR_BNDS)
!>     Para cada miembro independiente, este array contiene información sobre
!>     varios límites de error y números de condición correspondientes a la
!>     error relativo componente a componente, que se define de la siguiente manera:
!>
!>     Error relativo componente a componente en el i-ésimo vector de solución:
!>                    abs(XTRUE(j,i) - X(j,i))
!>             max_j ----------------------
!>                         abs(X(j,i))
!>
!>     El array se indexa por el miembro independiente i (del cual
!>     depende el error relativo componente a componente), y el tipo de
!>     información de error como se describe a continuación. Actualmente se devuelven hasta tres
!>     piezas de información para cada miembro independiente. Si
!>     no se solicita precisión componente a componente (PARAMS(3) = 0.0), entonces
!>     no se accede a ERR_BNDS_COMP.  Si N_ERR_BNDS < 3, entonces se devuelven como máximo
!>     las primeras entradas (:,N_ERR_BNDS).
!>
!>     El primer índice en ERR_BNDS_COMP(i,:) corresponde al i-ésimo

!>     segundo miembro.
!>
!>     El segundo índice en ERR_BNDS_COMP(:,err) contiene los siguientes
!>     tres campos:
!>     err = 1  booleano. Confiar en la respuesta si el
!>              número de condición recíproco es menor que el umbral
!>              sqrt(n) * dlamch('Epsilon').
!>
!>     err = 2  límite de error: El error hacia adelante estimado,
!>              casi seguramente dentro de un factor de 10 del error real
!>      siempre que la siguiente entrada sea mayor que el umbral
!>              sqrt(n) * dlamch('Epsilon'). Este límite de error solo
!>              debe confiarse si el booleano anterior es verdadero.
!>
!>     err = 3  Número de condición recíproco: Número de condición recíproco
!>              estimado componente a componente. Se compara con el umbral
!>              sqrt(n) * dlamch('Epsilon') para determinar si la
!>              estimación de error es . Estos números de condición
!>              recíprocos son 1 / (norm(Z^{-1},inf) * norm(Z,inf)) para alguna
!>              matriz Z escalada adecuadamente.
!>              Sea Z = S*(A*diag(x)), donde x es la solución para el
!>              segundo miembro actual y S escala cada fila de
!>              A*diag(x) por una potencia de la base para que todas las sumas absolutas de fila
!>              de Z sean aproximadamente 1.
!>
!>     Véase la Nota de Trabajo de Lapack 165 para más detalles y precauciones
!>     adicionales.
!
>

NPARAM

S 
!>          NPARAMS es INTEGER
!>     Especifica el número de parámetros establecidos en PARAMS.  Si <= 0, el
!>     array PARAMS nunca se referencia y se usan los valores predeterminados.
!
>

PARAM

S 
!>          PARAMS es un array DOUBLE PRECISION, dimensión NPARAMS
!>     Especifica los parámetros del algoritmo.  Si una entrada es < 0.0, entonces
!>     esa entrada se rellenará con el valor predeterminado utilizado para ese
!>     parámetro.  Solo se accede a las posiciones hasta NPARAMS; se usan los
!>     valores predeterminados para los parámetros de número más alto.
!>
!>       PARAMS(LA_LINRX_ITREF_I = 1) : Si realizar refinamiento
!>            iterativo o no.
!>         Predeterminado: 1.0D+0

!>                     err_bnds_norm y err_bnds_comp pueden dejar de ser

!>
!>       PARAMS(LA_LINRX_CWISE_I = 3) : Bandera que determina si el código
!>            intentará encontrar una solución con pequeño error relativo
!>            componente a componente en el algoritmo de precisión doble.  Positivo

>

K

INF

O 
!>          INFO es INTEGER
!>       = 0:  Salida exitosa. La solución a cada segundo miembro está
