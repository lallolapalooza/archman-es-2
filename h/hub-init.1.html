NOMBRE

hub-init - Inicializa un repositorio git y añade un remoto apuntando a GitHub.

SINOPSIS

hub init -g

OPCIONES

-g

Después de inicializar el repositorio localmente, añade el remoto "origin" apuntando al repositorio "USUARIO/REPO" en GitHub.

USUARIO es tu nombre de usuario de GitHub, mientras que REPO es el nombre del directorio de trabajo actual.

EJEMPLOS

$ hub init -g
> git init
> git remote add origin git@github.com:USUARIO/REPO.git
