hwlocality_linux_libnuma_ulongs - Interoperabilidad con máscaras de tipo unsigned long de libnuma de Linux

Descripción Detallada

Esta interfaz ayuda a la conversión entre máscaras de tipo unsigned long de libnuma de Linux y conjuntos de CPUs y conjuntos de nodos de hwloc.

Nota

La topología topología debe coincidir con la máquina actual.

El comportamiento de libnuma no está definido si el kernel no es consciente de NUMA (cuando CONFIG_NUMA no está configurado en la configuración del kernel). Por lo tanto, esta utilidad y libnuma pueden no ser estrictamente compatibles en este caso, lo que puede detectarse comprobando si numa_available() devuelve -1.

Documentación de Funciones

int hwloc_cpuset_from_linux_libnuma_ulongs (hwloc_topology_t topología, hwloc_cpuset_t cpuset, const unsigned long * máscara, unsigned long maxnodo) [inline]

Convierte la matriz de máscaras unsigned long en el conjunto de CPUs de hwloc. máscara es una matriz de tipo unsigned long que se leerá. maxnodo contiene el número máximo de nodo que puede leerse en máscara.

Esta función puede usarse después de llamar a get_mempolicy o a cualquier otra función que tome una matriz de tipo unsigned long como parámetro de salida (y posiblemente un número máximo de nodo como parámetro de entrada).

Retorna

0 si tiene éxito.

-1 si hay un error, por ejemplo, si falla una reasignación interna.

int hwloc_cpuset_to_linux_libnuma_ulongs (hwloc_topology_t topología, hwloc_const_cpuset_t cpuset, unsigned long * máscara, unsigned long * maxnodo) [inline]

Convierte el conjunto de CPUs de hwloc cpuset en la matriz de máscaras unsigned long máscara. máscara es la matriz de tipo unsigned long que se rellenará. maxnodo contiene el número máximo de nodo que puede almacenarse en máscara. maxnodo se establecerá al número máximo de nodo encontrado, más uno.

Esta función puede usarse antes de llamar a set_mempolicy, mbind, migrate_pages o cualquier otra función que tome una matriz de tipo unsigned long y un número máximo de nodo como parámetro de entrada.

Retorna

0.

int hwloc_nodeset_from_linux_libnuma_ulongs (hwloc_topology_t topología, hwloc_nodeset_t nodeset, const unsigned long * máscara, unsigned long maxnodo) [inline]

Convierte la matriz de máscaras unsigned long en el conjunto de nodos NUMA de hwloc. máscara es una matriz de tipo unsigned long que se leerá. maxnodo contiene el número máximo de nodo que puede leerse en máscara.

Esta función puede usarse después de llamar a get_mempolicy o a cualquier otra función que tome una matriz de tipo unsigned long como parámetro de salida (y posiblemente un número máximo de nodo como parámetro de entrada).

Retorna

0 si tiene éxito.

-1 con errno establecido a ENOMEM si alguna reasignación interna falló.

Esta función puede usarse antes de llamar a set_mempolicy, mbind, migrate_pages o cualquier otra función que tome una matriz de tipo unsigned long y un número máximo de nodo como parámetro de entrada.
