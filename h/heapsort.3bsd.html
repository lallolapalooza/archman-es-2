NOMBRE

heapsort, mergesort — funciones de ordenación

BIBLIOTECA

biblioteca “libbsd”

SINOPSIS

#include <stdlib.h> (Ver libbsd(7) para el uso de include.)
int
heapsort(void *base, size_t nmemb, size_t size, int (*compar)(const void *, const void *));

int
mergesort(void *base, size_t nmemb, size_t size, int (*compar)(const void *, const void *));

DESCRIPCIÓN

La función heapsort() es una selección de ordenación modificada. La función mergesort() es una ordenación por mezcla modificada con búsqueda exponencial destinada a ordenar datos con orden preexistente.

La función heapsort() ordena un array de nmemb objetos, cuyo miembro inicial está apuntado por base. El tamaño de cada objeto se especifica por size. La función mergesort() se comporta de manera similar, pero requiere que size sea mayor que “sizeof(void *) / 2”.

Los contenidos del array base se ordenan en orden ascendente según una función de comparación apuntada por compar, que requiere dos argumentos apuntando a los objetos que se están comparando.

La función de comparación debe devolver un entero menor que, igual a, o mayor que cero si el primer argumento se considera respectivamente menor que, igual a, o mayor que el segundo.

El algoritmo implementado por heapsort() no es estable, es decir, si dos miembros se comparan como iguales, su orden en el array ordenado no está definido. El algoritmo mergesort() es estable.

La función heapsort() es una implementación del algoritmo “heapsort” de J.W.J. William, una variante de la selección de ordenación; en particular, véase el Algoritmo H de D.E. Knuth. Heapsort tiene un tiempo en el peor de los casos de O N lg N. Su única ventaja sobre qsort() es que utiliza casi ninguna memoria adicional; mientras que qsort() no asigna memoria, se implementa mediante recursión.

La función mergesort() requiere memoria adicional de tamaño nmemb * size bytes; solo debe usarse cuando el espacio no es una prioridad. La función mergesort() está optimizada para datos con orden preexistente; su peor caso de tiempo es O N lg N; su mejor caso es O N.

Normalmente, qsort() es más rápido que mergesort() es más rápido que heapsort(). La disponibilidad de memoria y el orden preexistente en los datos pueden hacer que esto no sea cierto.

VALORES DE RETORNO

Las funciones heapsort() y mergesort() devuelven el valor 0 si tienen éxito; de lo contrario, se devuelve el valor -1 y la variable global errno se establece para indicar el error.

ERRORES

Las funciones heapsort() y mergesort() tienen éxito a menos que:

[EINVAL]
El argumento size es cero, o, el argumento size para mergesort() es menor que “sizeof(void *) / 2”.
[ENOMEM]
Las funciones heapsort() o mergesort() no pudieron asignar memoria.
