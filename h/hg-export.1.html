hg-export(1)

Paquete: mercurial

Licencias: GPL

HG(EXPORT) HG(EXPORT)

NOMBRE

hg export - volcar la cabecera y las diferencias de uno o más conjuntos de cambios

SINOPSIS

hg export [OPCIÓN]... [-o ESPECIFICADOR_SALIDA] [-r] [REV]...

DESCRIPCIÓN

Imprime la cabecera del conjunto de cambios y las diferencias para una o más revisiones. Si no se proporciona ninguna revisión, se utiliza el padre del directorio de trabajo.

La información que se muestra en la cabecera del conjunto de cambios es: autor, fecha, nombre de la rama (si no es la predeterminada), hash del conjunto de cambios, padre(s) y comentario del commit.

Nota
hg export puede generar una salida de diferencias inesperada para conjuntos de cambios de fusión, ya que comparará el conjunto de cambios de fusión solo con su primer padre.

La salida puede ser a un archivo, en cuyo caso el nombre del archivo se proporciona utilizando una cadena de plantilla. Consulte hg help templates. Además de las palabras clave comunes de la plantilla, se admiten las siguientes reglas de formato:

%%

carácter literal "%"

%H

hash del conjunto de cambios (40 dígitos hexadecimales)

%N

número de parches que se están generando

%R

número de revisión del conjunto de cambios

%b

nombre base del repositorio que se exporta

%h

hash abreviado del conjunto de cambios (12 dígitos hexadecimales)

%m

primera línea del mensaje del commit (solo caracteres alfanuméricos)

%n

número de secuencia con relleno de ceros, comenzando en 1

%r

número de revisión del conjunto de cambios con relleno de ceros

\

carácter literal ""

Sin la opción -a/--text, export evitará generar diferencias de archivos que detecte como binarios. Con -a, export generará una diferencia de todos modos, probablemente con resultados indeseables.

Con -B/--bookmark, se seleccionan los conjuntos de cambios alcanzables por la marca dada.

Utilice la opción -g/--git para generar diferencias en el formato de diferencia extendida de git. Consulte hg help diffs para obtener más información.

Con la opción --switch-parent, la diferencia será contra el segundo padre. Puede ser útil para revisar una fusión.

Plantilla:

Las siguientes palabras clave son compatibles además de las palabras clave y funciones comunes de plantilla. Consulte también hg help templates.

diff
Cadena. Contenido de la diferencia.
parents
Lista de cadenas. Nodos padre del conjunto de cambios.

Ejemplos:

  • usar export e import para trasplantar una corrección de errores a la rama actual: 
    hg export -r 9353 | hg import -
  • exportar todos los conjuntos de cambios entre dos revisiones a un archivo con información de renombrado: 
    hg export --git -r 123:150 > changes.txt
  • dividir los cambios salientes en una serie de parches con nombres descriptivos: 
    hg export -r "outgoing()" -o "%n-%m.patch"

    Retorna 0 en caso de éxito.

OPCIONES

-B,--bookmark <BOOKMARK>
exportar solo los cambios alcanzables por la marca dada
-o,--output <FORMAT>
imprimir la salida a un archivo con nombre formateado
--switch-parent
diferenciar contra el segundo padre
-r,--rev <REV[+]>
revisiones a exportar
-a, --text
tratar todos los archivos como texto
-g, --git
usar el formato de diferencia extendida de git (PREDETERMINADO: diff.git)
--binary
generar diferencias binarias en modo git (predeterminado)
--nodates
omitir fechas de las cabeceras de las diferencias
-T,--template <TEMPLATE>
mostrar con plantilla

[+] la opción marcada se puede especificar varias veces
