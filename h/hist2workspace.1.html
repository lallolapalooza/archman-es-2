hist2workspace(1) Manual de Comandos Generales hist2workspace(1)

SINOPSIS

uso: hist2workspace [-h] [-v] [-vv] [-disable_binned_fit_optimization]

DESCRIPCIÓN

hist2workspace es una utilidad para crear áreas de trabajo RooFit/RooStats a partir de histogramas.

OPCIONES

-h
muestra este mensaje de ayuda y sale
-v
cambia el flujo de mensajes de HistFactory al nivel INFO
-vv
cambia el flujo de mensajes de HistFactory al nivel DEBUG
-disable_binned_fit_optimization
deshabilita la optimización de ajuste por bins utilizada en HistFactory desde ROOT 6.28.
