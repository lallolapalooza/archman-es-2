HXUNPIPE(1) Utilidades HTML-XML HXUNPIPE(1)

NOMBRE

hxunpipe - convierte la salida de hxpipe de nuevo al formato XML

SINOPSIS

hxunpipe [ -b ] [ archivo-o-URL ]

DESCRIPCIÓN

hxunpipe toma la salida de hxpipe(1) (o de onsgmls(1)) y la convierte de nuevo en marcas XML/SGML.

OPCIONES

Se soportan las siguientes opciones:

-b
Normalmente, hxunpipe asume que la entrada fue generada por hxpipe, es decir, la entrada puede contener entidades de caracteres pero nunca contendrá delimitadores SGML/XML (<>&"') que necesiten ser escapados. Sin embargo, cuando la entrada fue generada por (o)nsgmls, las entidades habrán sido expandidas y la entrada puede contener delimitadores SGML/XML. La opción -b hace que hxunpipe busque esos delimitadores y los escape: "<" como "&lt;", ">" como "&gt;", "&" como "&amp;", """ como "&quot;" y "'" como "&apos;".

OPERANDOS

Se soporta el siguiente operando:

archivo-o-URL
El nombre o URL de un archivo HTML. Si está ausente, se lee la entrada estándar en su lugar.

ESTADO DE SALIDA

Se devuelven los siguientes valores de salida:

0
Finalización exitosa.
> 0
Ocurrió un error en la entrada.

ENTORNO

Para usar un proxy para recuperar archivos remotos, establezca las variables de entorno http_proxy y ftp_proxy. Por ejemplo, http_proxy="http://localhost:8080/"

ERRORES

No todos los errores de sintaxis en la entrada son reconocidos.

hxunpipe actualmente solo puede recuperar archivos remotos a través de HTTP. No maneja archivos protegidos por contraseña, ni archivos cuyo contenido dependa de las "cookies" HTTP.

VER TAMBIÉN

hxpipe(1), onsgmls(1).
