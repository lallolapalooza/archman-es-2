NOMBRE

hub-gist - Crear e imprimir Gists de GitHub

SINOPSIS

hub gist create [-oc] [--public] [ARCHIVOS...]
hub gist show ID [NOMBRE_ARCHIVO]

COMANDOS

create

Crea un nuevo gist. Si no se especifican ARCHIVOS, el contenido se lee desde la entrada estándar.

show

Imprime el contenido de un gist. Si el gist contiene múltiples archivos, la operación fallará a menos que se especifique NOMBRE_ARCHIVO.

OPCIONES

--public

Hace que el nuevo gist sea público (por defecto: falso).

-o, --browse

Abre el nuevo gist en un navegador web.

-c, --copy

Copia la URL del nuevo gist al portapapeles en lugar de imprimirla.

EJEMPLOS

$ echo hola | hub gist create --public
$ hub gist create archivo1.txt archivo2.txt
# imprime un archivo específico dentro de un gist:
$ hub gist show ID archivo1.txt
