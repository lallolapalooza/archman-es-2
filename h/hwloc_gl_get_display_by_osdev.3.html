Descripción Detallada

Esta interfaz ofrece formas de recuperar información de topología sobre pantallas OpenGL.

Actualmente, solo está disponible la información de localidad de pantalla NVIDIA, utilizando la extensión NV-CONTROL X11 y la biblioteca NVCtrl.

Documentación de Funciones

Obtiene el puerto y dispositivo de pantalla OpenGL correspondientes al objeto OS de hwloc dado. Recupera el puerto (servidor) de pantalla OpenGL en port y el dispositivo (pantalla) en screen que corresponden al objeto de dispositivo OS de hwloc dado.

Devuelve

0 si tiene éxito.

-1 si no se pudo encontrar ninguno.

La topología topology no tiene necesariamente que coincidir con la máquina actual. Por ejemplo, la topología puede ser una importación XML de un host remoto. La detección de dispositivos de E/S y el componente GL deben estar habilitados en la topología.

hwloc_obj_t hwloc_gl_get_display_osdev_by_name (hwloc_topology_t topology, const char * name) [inline]

Obtiene el objeto de dispositivo OS de hwloc correspondiente a la pantalla OpenGL dada por name.

Devuelve

El objeto de dispositivo OS de hwloc que describe la pantalla OpenGL cuyo nombre es name, construido como ':puerto.dispositivo' tal como ':0.0'.

NULL si no se pudo encontrar ninguno.

La topología topology no tiene necesariamente que coincidir con la máquina actual. Por ejemplo, la topología puede ser una importación XML de un host remoto. La detección de dispositivos de E/S y el componente GL deben estar habilitados en la topología.

Nota

El objeto de dispositivo PCI correspondiente se puede obtener examinando el objeto padre del dispositivo OS (a menos que los dispositivos PCI estén filtrados).

hwloc_obj_t hwloc_gl_get_display_osdev_by_port_device (hwloc_topology_t topology, unsigned port, unsigned device) [inline]

Obtiene el objeto de dispositivo OS de hwloc correspondiente a la pantalla OpenGL dada por el índice de puerto y dispositivo.

Devuelve

El objeto de dispositivo OS de hwloc que describe la pantalla OpenGL cuyo puerto (servidor) es port y dispositivo (pantalla) es device.

NULL si no se pudo encontrar ninguno.

La topología topology no tiene necesariamente que coincidir con la máquina actual. Por ejemplo, la topología puede ser una importación XML de un host remoto. La detección de dispositivos de E/S y el componente GL deben estar habilitados en la topología.

Nota

El objeto de dispositivo PCI correspondiente se puede obtener examinando el objeto padre del dispositivo OS (a menos que los dispositivos PCI estén filtrados).
