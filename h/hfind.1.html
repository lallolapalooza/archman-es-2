NOMBRE

hfind - Buscar un valor hash en una base de datos de hashes

SINOPSIS

hfind [-i tipo_db ] [-f archivo_busqueda ] [-eq] archivo_db [hashes]

DESCRIPCIÓN

hfind busca valores hash en una base de datos utilizando un algoritmo de búsqueda binaria. Esto permite crear fácilmente una base de datos de hashes e identificar si un archivo es conocido o no. Funciona con la Biblioteca Nacional de Referencias de Software (NSRL) del NIST y la salida de 'md5sum'.

Antes de que la base de datos pueda ser utilizada por 'hfind', se debe crear un archivo de índice con la opción '-i'.

Esta herramienta es necesaria por eficiencia. La mayoría de las bases de datos basadas en texto no tienen entradas de longitud fija y a veces no están ordenadas. La herramienta hfind creará un archivo de índice que está ordenado y tiene entradas de longitud fija. Esto permite búsquedas rápidas utilizando un algoritmo de búsqueda binaria en lugar de una búsqueda lineal como 'grep'.

ARGUMENTOS

-i tipo_db
Crear un archivo de índice para la base de datos. Este paso debe realizarse antes de poder realizar una búsqueda. El argumento 'tipo_db' especifica el tipo de base de datos (es decir, nsrl-md5 o md5sum). Ver la sección de más abajo.
-f archivo_busqueda
Especificar la ubicación de un archivo que contiene un valor hash por línea. Estos hashes se buscarán en la base de datos.
-e
Modo extendido. Se imprime información adicional además del nombre. (No se aplica a todos los tipos de bases de datos de hash).
-q
Modo rápido. En lugar de mostrar la información correspondiente con el hash, solo muestra 0 si el hash no se encontró y 1 si se encontró. Si se utiliza esta bandera, entonces solo se puede dar un hash a la vez.
-V
Mostrar versión
archivo_db
La ubicación del archivo de la base de datos de hashes.
[hashes]
Los hashes a buscar. Si no se proporcionan en la línea de comandos, se utiliza STDIN. Si existen archivos de índice tanto para hashes SHA-1 como MD5, entonces ambos tipos de hashes se pueden proporcionar en tiempo de ejecución.

ARCHIVO DE ÍNDICE

hfind utiliza un archivo de índice para realizar una búsqueda binaria de un valor hash. Esto es mucho más rápido que usar 'grep', que realizará una búsqueda lineal. Antes de que se utilice una base de datos de hashes, se debe crear un archivo de índice correspondiente. Esto se hace con la opción '-i' de hfind.

El archivo de índice resultante se nombrará basándose en el nombre del archivo de la base de datos. El nombre tendrá el nombre original seguido del tipo de hash (sha1 o md5) seguido de '.idx'. Por ejemplo, crear un índice de hash MD5 de la NSRL del NIST resulta en 'NSRLFile.txt-md5.idx' y el índice SHA-1 resulta en 'NSRLFile.txt-sha1.idx'.

El archivo tiene dos columnas. Cada entrada está ordenada por la primera columna, que es el valor hash. La segunda columna tiene el desplazamiento de bytes de la entrada correspondiente en el archivo original. Por lo tanto, cuando se encuentra un hash en el índice, se registra el desplazamiento y luego 'hfind' busca la entrada en la base de datos original.

Los siguientes tipos de entrada son válidos. Para NSRL, se pueden usar 'nsrl-md5' y 'nsrl-sha1'. La diferencia es por qué valor hash se ordena el índice. El valor 'md5sum' también se puede usar para ordenar e indexar bases de datos "caseras". 'hfind' puede tomar datos en ambos formatos comunes:

MD5 (test.txt) = 76b1f4de1522c20b67acc132937cf82e

y

76b1f4de1522c20b67acc132937cf82e test.txt

EJEMPLOS

Para crear un archivo de índice MD5 para la NSRL del NIST:

# hfind -i nsrl-md5 /usr/local/hash/nsrl/NSRLFile.txt

Para buscar un valor en la NSRL:

# hfind /usr/local/hash/nsrl/NSRLFile.txt 76b1f4de1522c20b67acc132937cf82e

76b1f4de1522c20b67acc132937cf82e Hash Not Found

Incluso puedes hacer tanto SHA-1 como MD5 si quieres:

# hfind -i nsrl-sha1 /usr/local/hash/nsrl/NSRLFile.txt

# hfind /usr/local/hash/nsrl/NSRLFile.txt 76b1f4de1522c20b67acc132937cf82e 80001A80B3F1B80076B297CEE8805AAA04E1B5BA

76b1f4de1522c20b67acc132937cf82e Hash Not Found

80001A80B3F1B80076B297CEE8805AAA04E1B5BA thrdcore.cpp

Para crear una base de datos de binarios críticos de un sistema de confianza, usa 'md5sum':

# md5sum /bin/* /sbin/* /usr/bin/* /usr/bin/* /usr/local/bin/* /usr/local/sbin/* > system.md5

# hfind -i md5sum system.md5

Para buscar entradas, lo siguiente funcionará:

# hfind system.md5 76b1f4de1522c20b67acc132937cf82e

76b1f4de1522c20b67acc132937cf82e Hash Not Found

o

# md5sum -q /bin/* | hfind system.md5

928682269cd3edb1acdf9a7f7e606ff2 /bin/bash

<...>

o

# md5sum -q /bin/* > bin.md5

# hfind -f bin.md5 system.md5

928682269cd3edb1acdf9a7f7e606ff2 /bin/bash

<...>
