La forma habitual de añadir distancias

es: 
hwloc_distances_add_handle_t handle;
int err = -1;
handle = hwloc_distances_add_create(topology, "name", kind, 0);
if (handle) {
  err = hwloc_distances_add_values(topology, handle, nbobjs, objs, values, 0);
  if (!err)
    err = hwloc_distances_add_commit(topology, handle, flags);
}

int hwloc_distances_add_commit (hwloc_topology_t topology, hwloc_distances_add_handle_t handle, unsigned long

flags)

Confirmar una nueva estructura de distancias. Esta función finaliza la estructura de distancias y la inserta en la

topología.

Parámetro handle fue previamente devuelto por hwloc_distances_add_create(). Luego, los objetos y valores fueron especificados con hwloc_distances_add_values()

.

flags configura el comportamiento de la función usando un conjunto opcional unido con OR de hwloc_distances_add_flag_e. Puede usarse para solicitar el agrupamiento de objetos existentes basándose en

distancias.

En caso de error, la estructura de distancias temporal y su contenido son

destruidos.

Crear una nueva estructura de distancias vacía. Crea una estructura de distancias vacía para ser rellenada con hwloc_distances_add_values() y luego confirmada con hwloc_distances_add

_commit().

Parámetro name es opcional, puede ser NULL. De lo contrario, será copiado internamente y más tarde puede ser liberado por el

El tipo HWLOC_DISTANCES_KIND_HETEROGENEOUS_TYPES se establecerá automáticamente de acuerdo con los objetos que tienen diferentes tipos en hwloc_distances_add_values()

int hwloc_distances_add_values (hwloc_topology_t topology, hwloc_distances_add_handle_t handle, unsigned nbobjs, hwloc_obj_t * objs, hwloc_uint64_t * values, unsigned long

flags)

Especificar los objetos y valores en una nueva estructura de distancias vacía. Especificar los objetos y valores para una nueva estructura de distancias que fue devuelta como un manejador por hwloc_distances_add_create(). La estructura debe luego ser confirmada con hwloc_distances_add

_commit().

El número de objetos es nbobjs y el arreglo de objetos es objs. Los valores de distancia se almacenan como un arreglo de una dimensión en values. La distancia del objeto i al objeto j está en la posición

i*nbobjs+j.

2.

Los arreglos objs y values serán copiados internamente, pueden luego ser liberados por el

llamador.
