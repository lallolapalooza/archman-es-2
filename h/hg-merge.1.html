Paquete: mercurial

HG(MERGE) HG(MERGE)

NOMBRE

hg merge - fusionar otra revisión en el directorio de trabajo

SINOPSIS

hg merge [-P] [[-r] REV]

DESCRIPCIÓN

El directorio de trabajo actual se actualizará con todos los cambios realizados en la revisión solicitada desde el último predecesor común.

Los archivos que cambiaron entre cualquiera de los padres se marcarán como modificados para el próximo commit y se debe realizar un commit antes de permitir cualquier actualización adicional del repositorio. El próximo commit tendrá dos padres.

--tool se puede usar para especificar la herramienta de fusión utilizada para las fusiones de archivos. Anula la variable de entorno HGMERGE y sus archivos de configuración. Consulte hg help merge-tools para ver las opciones.

Si no se especifica ninguna revisión, el padre del directorio de trabajo es una revisión principal (head) y la rama actual contiene exactamente otra revisión principal, se fusionará con la otra revisión principal por defecto. De lo contrario, se debe proporcionar una revisión explícita con la que fusionarse.

Consulte hg help resolve para obtener información sobre cómo manejar conflictos de archivos.

Para deshacer una fusión no confirmada (uncommitted), use hg merge --abort que verificará una copia limpia del padre de fusión original, perdiendo todos los cambios.

Devuelve 0 en caso de éxito, 1 si hay archivos sin resolver.

OPCIONES

-f, --force
forzar una fusión incluyendo cambios pendientes (OBSOLETO)
-r,--rev <REV>
revisión a fusionar
-P, --preview
revisar revisiones a fusionar (no se realiza ninguna fusión)
--abort
abortar la fusión en curso
-t, --tool <TOOL>
especificar herramienta de fusión
