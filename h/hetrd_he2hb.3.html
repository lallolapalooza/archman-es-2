DOCUMENTACIÓN DE FUNCIÓN

subrutina chetrd_he2hb (carácter uplo, entero n, entero kd, complejo, dimensión( lda, * ) a, entero lda, complejo, dimensión( ldab, * ) ab, entero ldab, complejo, dimensión( * ) tau, complejo, dimensión( * ) work, entero lwork, entero info)

CHETRD_HE2HB

Propósito:

!>
!> CHETRD_HE2HB reduce una matriz Hermítica compleja A a forma de banda Hermítica compleja AB mediante una transformación de semejanza unitaria:
!> Q**H * A * Q = AB.
!>

Parámetros

UPLO 
!>          UPLO es CARACTER*1
!>          = 'U':  El triángulo superior de A está almacenado;
!>          = 'L':  El triángulo inferior de A está almacenado.
!>

N

!>          N es ENTERO
!>          El orden de la matriz A.  N >= 0.
!>

KD

!>          KD es ENTERO
!>          El número de superdiagonales de la matriz reducida si UPLO = 'U',
!>          o el número de subdiagonales si UPLO = 'L'.  KD >= 0.
!>          La matriz reducida se almacena en el array AB.
!>

A

!>          A es un array COMPLEJO, dimensión (LDA,N)
!>          En la entrada, la matriz Hermítica A.  Si UPLO = 'U', la parte
!>          superior triangular N-por-N de A contiene la parte superior
!>          triangular de la matriz A, y la parte estrictamente inferior
!>          triangular de A no se referencia. Si UPLO = 'L', la parte
!>          inferior triangular N-por-N de A contiene la parte inferior
!>          triangular de la matriz A, y la parte estrictamente superior
!>          triangular de A no se referencia.
!>          En la salida, si UPLO = 'U', la diagonal y la superdiagonal superior
!>          de A se sobrescriben con los elementos correspondientes de la
!>          matriz tridiagonal T, y los elementos por encima de la superdiagonal
!>          superior, junto con el array TAU, representan la matriz unitaria
!>          Q como un producto de reflectores elementales; si UPLO
!>          = 'L', la diagonal y la subdiagonal inferior de A se sobrescriben
!>          con los elementos correspondientes de la matriz tridiagonal
!>          T, y los elementos por debajo de la subdiagonal inferior, junto con
!>          el array TAU, representan la matriz unitaria Q como un producto
!>          de reflectores elementales. Ver Detalles Adicionales.
!>

LDA

!>          LDA es ENTERO
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

AB

!>          AB es un array COMPLEJO, dimensión (LDAB,N)
!>          En la salida, la parte superior o inferior de la matriz de banda Hermítica
!>          A, almacenada en las primeras KD+1 filas del array.
!>          La columna j de A se almacena en la columna j del array AB
!>          de la siguiente manera:
!>          si UPLO = 'U', AB(kd+1+i-j,j) = A(i,j) para max(1,j-kd)<=i<=j;
!>          si UPLO = 'L', AB(1+i-j,j)    = A(i,j) para j<=i<=min(n,j+kd).
!>

LDAB

!>          LDAB es ENTERO
!>          La dimensión principal del array AB.  LDAB >= KD+1.
!>

TAU

!>          TAU es un array COMPLEJO, dimensión (N-KD)
!>          Los factores escalares de los reflectores elementales (ver Detalles
!>          Adicionales).
!>

WORK

!>          WORK es un array COMPLEJO, dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, o si LWORK = -1,
!>          WORK(1) devuelve el tamaño de LWORK.
!>

LWORK

!>          LWORK es ENTERO
!>          La dimensión del array WORK, que debe calcularse
!>          mediante una consulta de espacio de trabajo.
!>          Si N <= KD+1, LWORK >= 1, de lo contrario LWORK = MAX(1, LWORK_QUERY).
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo del array WORK, devuelve
!>          este valor en la primera entrada del array WORK, y XERBLA no emite ningún mensaje de error
!>          relacionado con LWORK.
!>          LWORK_QUERY = N*KD + N*max(KD,FACTOPTNB) + 2*KD*KD
!>          donde FACTOPTNB es el bloqueo utilizado por el algoritmo QR o LQ
!>          (normalmente FACTOPTNB=128 es una buena opción; de lo contrario,
!>          establecer LWORK=-1 proporcionará el tamaño de WORK).
!>

INFO

!>          INFO es ENTERO
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el argumento i-ésimo tuvo un valor ilegal
!>

!>  Si UPLO = 'U', la matriz Q se representa como un producto de reflectores
!>  elementales
!>
!>     Q = H(k)**H . . . H(2)**H H(1)**H, donde k = n-kd.
!>
!>  Cada H(i) tiene la forma
!>
!>     H(i) = I - tau * v * v**H
!>
!>  donde tau es un escalar complejo, y v es un vector complejo con
!>  v(1:i+kd-1) = 0 y v(i+kd) = 1; conjg(v(i+kd+1:n)) se almacena en la salida en
!>  A(i,i+kd+1:n), y tau en TAU(i).
!>
!>  Si UPLO = 'L', la matriz Q se representa como un producto de reflectores
!>  elementales
!>
!>     Q = H(1) H(2) . . . H(k), donde k = n-kd.
!>
!>  Cada H(i) tiene la forma
!>
!>     H(i) = I - tau * v * v**H
!>
!>  donde tau es un escalar complejo, y v es un vector complejo con
!>  v(kd+1:i) = 0 y v(i+kd+1) = 1; v(i+kd+2:n) se almacena en la salida en
!>  A(i+kd+2:n,i), y tau en TAU(i).
!>
!>  El contenido de A en la salida se ilustra con los siguientes ejemplos
!>  con n = 5:
!>
!>  si UPLO = 'U':                       si UPLO = 'L':
!>
!>    (  ab  ab/v1  v1      v1     v1    )              (  ab                            )
!>    (      ab     ab/v2   v2     v2    )              (  ab/v1  ab                     )
!>    (             ab      ab/v3  v3    )              (  v1     ab/v2  ab              )
!>    (                     ab     ab/v4 )              (  v1     v2     ab/v3  ab       )
!>    (                            ab    )              (  v1     v2     v3     ab/v4 ab )
!>
!>  donde d y e denotan elementos diagonales y fuera de la diagonal de T, y vi
!>  denota
es un elemento del vector que define H(i). !> .fi

info)

ZHETRD_HE2H
B

Propósito
:



!>
!> ZHETRD_HE2HB reduce una matriz Hermitiana compleja A a una forma
!> banda-diagonal Hermitiana compleja AB mediante una transformación de
!> similitud unitaria:
!> Q**H * A * Q = AB.

!
>

Parámetro
s

UPLO

!>          UPLO es CHARACTER*1
!>          = 'U':  Se almacena el triángulo superior de A;
!>          = 'L':  Se almacena el triángulo inferior de A.
!
>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!
>

K
D

!>          KD es INTEGER
!>          El número de superdiagonales de la matriz reducida si UPLO = 'U',
!>          o el número de subdiagonales si UPLO = 'L'.  KD >= 0.
!>          La matriz reducida se almacena en el array AB.
!
>

A

!>          A es un array COMPLEX*16, dimensión (LDA,N)
!>          En la entrada, la matriz Hermitiana A.  Si UPLO = 'U', la
!>          parte triangular superior N-por-N principal de A contiene la
!>          parte triangular superior de la matriz A, y la parte
!>          triangular inferior estricta de A no se referencia.  Si
!>          UPLO = 'L', la parte triangular inferior N-por-N principal de
!>          A contiene la parte triangular inferior de la matriz A, y la
!>          parte triangular superior estricta de A no se referencia.
!>          En la salida, si UPLO = 'U', la diagonal y la primera
!>          superdiagonal de A se sobrescriben con los elementos
!>          correspondientes de la matriz tridiagonal T, y los elementos
!>          por encima de la primera superdiagonal, con el array TAU,
!>          representan la matriz unitaria Q como un producto de
!>          reflectores elementales; si UPLO = 'L', la diagonal y la
!>          primera subdiagonal de A se sobrescriben con los elementos
!>          correspondientes de la matriz tridiagonal T, y los elementos
!>          por debajo de la primera subdiagonal, con el array TAU,
!>          representan la matriz unitaria Q como un producto de
!>          reflectores elementales. Ver Detalles Adicionales.
!
>

LD
A

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!
>

A
B

!>          AB es un array COMPLEX*16, dimensión (LDAB,N)
!>          En la salida, el triángulo superior o inferior de la matriz
!>          banda Hermitiana A, almacenado en las primeras KD+1 filas
!>          del array.  La j-ésima columna de A se almacena en la
!>          j-ésima columna del array AB de la siguiente manera:
!>          si UPLO = 'U', AB(kd+1+i-j,j) = A(i,j) para max(1,j-kd)<=i<=j;
!>          si UPLO = 'L', AB(1+i-j,j)    = A(i,j) para j<=i<=min(n,j+kd).
!
>

LDA
B

!>          LDAB es INTEGER
!>          La dimensión principal del array AB.  LDAB >= KD+1.
!
>

TA
U

!>          TAU es un array COMPLEX*16, dimensión (N-KD)
!>          Los factores escalares de los reflectores elementales (ver
!>          Detalles Adicionales).
!
>

WOR
K

!>          WORK es un array COMPLEX*16, dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, o si LWORK = -1,
