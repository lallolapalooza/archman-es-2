hwloc_cpuset_t hwloc_obj::

El conjunto completo de CPU de procesadores de este objeto. Esto puede incluir no solo lo mismo que el campo cpuset, sino también algunas CPU para las que la información de topología es desconocida o incompleta, algunas CPU fuera de línea, y las CPU que se ignoran cuando el HWLOC_TOPOLOGY_FLAG_INCLUDE_DISALLOWED no está establecido. int hwloc_obj::

Índice vertical en la jerarquía. Para objetos normales, esta es la profundidad del nivel horizontal que contiene este objeto y sus primos del mismo tipo. Si la topología es simétrica, esto es igual a la profundidad del padre más uno, y también igual al número de enlaces padre/hijo desde el objeto raíz hasta

aquí.

Para objetos especiales (nodos NUMA, E/S y diversos) que no están en el árbol principal, este es un valor negativo especial que corresponde a su nivel dedicado, ver hwloc_get_type_depth() y hwloc_get_type_depth_e.
