NOMBRE

hub-submodule - Añade un submódulo de git para un repositorio de GitHub.

SINOPSIS

hub submodule add [-p] [OPCIONES] [USUARIO/]REPOSITORIO DESTINO

EJEMPLOS

$ hub submodule add jingweno/gh vendor/gh
> git submodule add git://github.com/jingweno/gh.git vendor/gh
