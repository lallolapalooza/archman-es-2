DSBGVX

Propósito:

DSBGVX calcula autovalores seleccionados y, opcionalmente, autovectores
de un problema de autovalores generalizado de bandas simétrico real,
de la forma A*x=(lambda)*B*x. Aquí se asume que A y B son simétricas
y de bandas, y B es también definida positiva. Los autovalores y
autovectores pueden ser seleccionados especificando todos los autovalores,
un rango de valores o un rango de índices para los autovalores deseados.

Parámetros

JOBZ 
JOBZ es CHARACTER*1
='N': calcular solo autovalores;
='V': calcular autovalores y autovectores.

RANGE

RANGE es CHARACTER*1
='A': se encontrarán todos los autovalores.
='V': se encontrarán todos los autovalores en el intervalo semiabierto (VL,VU]
se encontrarán.
='I': se encontrarán los autovalores del IL-ésimo al IU-ésimo.

UPLO

UPLO es CHARACTER*1
='U': se almacenan los triángulos superiores de A y B;
='L': se almacenan los triángulos inferiores de A y B.

N

N es un ENTERO
El orden de las matrices A y B. N >= 0.

KA

KA es un ENTERO
El número de superdiagonales de la matriz A si UPLO = 'U',
o el número de subdiagonales si UPLO = 'L'. KA >= 0.

KB

KB es un ENTERO
El número de superdiagonales de la matriz B si UPLO = 'U',
o el número de subdiagonales si UPLO = 'L'. KB >= 0.

AB

AB es un array DOUBLE PRECISION, dimensión (LDAB, N)
En la entrada, el triángulo superior o inferior de la matriz de banda simétrica
A, almacenado en las primeras ka+1 filas del array. La
columna j de A se almacena en la columna j del array AB
como sigue:
si UPLO = 'U', AB(ka+1+i-j,j) = A(i,j) para max(1,j-ka)<=i<=j;
si UPLO = 'L', AB(1+i-j,j) = A(i,j) para j<=i<=min(n,j+ka).

En la salida, el contenido de AB se destruye.

LDAB

LDAB es un ENTERO
La dimensión principal del array AB. LDAB >= KA+1.

BB

BB es un array DOUBLE PRECISION, dimensión (LDBB, N)
En la entrada, el triángulo superior o inferior de la matriz de banda simétrica
B, almacenado en las primeras kb+1 filas del array. La
columna j de B se almacena en la columna j del array BB
como sigue:
si UPLO = 'U', BB(ka+1+i-j,j) = B(i,j) para max(1,j-kb)<=i<=j;
si UPLO = 'L', BB(1+i-j,j) = B(i,j) para j<=i<=min(n,j+kb).

En la salida, el factor S de la factorización de Cholesky dividida
B = S**T*S, tal como retorna DPBSTF.

LDBB

LDBB es un ENTERO
La dimensión principal del array BB. LDBB >= KB+1.

Q

Q es un array DOUBLE PRECISION, dimensión (LDQ, N)
Si JOBZ = 'V', la matriz n por n utilizada en la reducción de
A*x = (lambda)*B*x a la forma estándar, es decir, C*x = (lambda)*x,
y consecuentemente C a la forma tridiagonal.
Si JOBZ = 'N', el array Q no se referencia.

LDQ

LDQ es un ENTERO
La dimensión principal del array Q. Si JOBZ = 'N',
LDQ >= 1. Si JOBZ = 'V', LDQ >= max(1,N).

VL

VL es DOUBLE PRECISION

Si RANGE='V', el límite inferior del intervalo a
buscar autovalores. VL < VU.
No se referencia si RANGE = 'A' o 'I'.

VU

VU es DOUBLE PRECISION

Si RANGE='V', el límite superior del intervalo a
buscar autovalores. VL < VU.
No se referencia si RANGE = 'A' o 'I'.

IL

IL es un ENTERO

Si RANGE='I', el índice del
autovalor más pequeño a retornar.
1 <= IL <= IU <= N, si N > 0; IL = 1 e IU = 0 si N = 0.
No se referencia si RANGE = 'A' o 'V'.

IU

IU es un ENTERO

Si RANGE='I', el índice del
autovalor más grande a retornar.
1 <= IL <= IU <= N, si N > 0; IL = 1 e IU = 0 si N = 0.
No se referencia si RANGE = 'A' o 'V'.

ABSTOL

ABSTOL es DOUBLE PRECISION
La tolerancia de error absoluto para los autovalores.
Un autovalor aproximado se acepta como convergido
cuando se determina que yace en un intervalo [a,b]
de ancho menor o igual a
ABSTOL + EPS * max( |a|,|b| ),
donde EPS es la precisión de la máquina. Si ABSTOL es menor o igual
a cero, entonces EPS*|T| se usará en su lugar,
donde |T| es la norma 1 de la matriz tridiagonal obtenida
al reducir A a forma tridiagonal.

Los autovalores se calcularán con la mayor precisión cuando ABSTOL
se establezca en el doble del umbral de subdesbordamiento 2*DLAMCH('S'), no cero.
Si esta rutina retorna con INFO>0, indicando que algunos
autovectores no convergieron, intente establecer ABSTOL en
2*DLAMCH('S').

M

M es un ENTERO
El número total de autovalores encontrados. 0 <= M <= N.
Si RANGE = 'A', M = N, y si RANGE = 'I', M = IU-IL+1.

W

W es un array DOUBLE PRECISION, dimensión (N)
Si INFO = 0, los autovalores en orden ascendente.

Z

Z es un array DOUBLE PRECISION, dimensión (LDZ, N)
Si JOBZ = 'V', entonces si INFO = 0, Z contiene la matriz Z de
autovectores, con la i-ésima columna de Z conteniendo el
autovector asociado con W(i). Los autovectores se
normalizan de modo que Z**T*B*Z = I.
Si JOBZ = 'N', entonces Z no se referencia.

LDZ

LDZ es un ENTERO
La dimensión principal del array Z. LDZ >= 1, y si
JOBZ = 'V', LDZ >= max(1,N).

WORK

WORK es un array DOUBLE PRECISION, dimensión (7*N)

IWORK

IWORK es un array ENTERO, dimensión (5*N)

IFAIL

IFAIL es un array ENTERO, dimensión (M)
Si JOBZ = 'V', entonces si INFO = 0, los primeros M elementos de
IFAIL son cero. Si INFO > 0, entonces IFAIL contiene los
índices de los autovalores que fallaron en converger.
Si JOBZ = 'N', entonces IFAIL no se referencia.

INFO

INFO es un ENTERO
= 0: salida exitosa
< 0: si INFO = -i, el i-ésimo argumento tenía un valor ilegal
<= N: si INFO = i, entonces i autovectores fallaron en converger.
Sus índices se almacenan en IFAIL.
> N: DPBSTF devolvió un código de error; es decir, !> si INFO = N + i, para 1 <= i <= N, entonces el menor !> principal principal de orden i de B no es positivo. !> La factorización de B no pudo completarse y !> no se calcularon ni autovalores ni autovectores. !
>

!> de un problema de eigenvalores generalizado hermitiano-definido positivo en banda,

!> autovectores pueden seleccionarse especificando todos los eigenvalores,

!
