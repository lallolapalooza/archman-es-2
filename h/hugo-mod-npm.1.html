NOMBRE

hugo-mod-npm - Varias utilidades de npm

SINOPSIS

hugo mod npm [comando] [flags]

DESCRIPCIÓN

Varias utilidades de npm (Node package manager).

OPCIONES

-h, --help[=false] ayuda para npm

OPCIONES HEREDADAS DE COMANDOS PADRE

--clock="" establece el reloj utilizado por Hugo, por ejemplo: --clock 2021-11-06T22:30:00.00+09:00

--config="" archivo de configuración (por defecto es hugo.yaml|json|toml)

--configDir="config" directorio de configuración

-d, --destination="" ruta del sistema de archivos donde escribir los archivos

-e, --environment="" entorno de compilación

--ignoreVendorPaths="" ignora cualquier _vendor para rutas de módulos que coincidan con el patrón Glob dado

--logLevel="" nivel de registro (debug|info|warn|error)

--noBuildLock[=false] no crea el archivo .hugo_build.lock

--quiet[=false] compila en modo silencioso

-M, --renderToMemory[=false] renderiza a memoria (principalmente útil cuando se ejecuta el servidor)

-s, --source="" ruta del sistema de archivos desde donde leer los archivos de forma relativa

--themesDir="" ruta del sistema de archivos para el directorio de temas

VER TAMBIÉN
