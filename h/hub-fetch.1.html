NOMBRE

hub-fetch - Añade remotos faltantes antes de realizar git fetch.

SINOPSIS

hub fetch USUARIO[,USUARIO2...]

EJEMPLOS

$ hub fetch --multiple jingweno mislav
> git remote add jingweno git://github.com/jingweno/REPO.git
> git remote add mislav git://github.com/mislav/REPO.git
> git fetch jingweno
> git fetch mislav
