Documentación del Tipo Enumeración

enum hwloc_distances_kind_e

Tipos de matrices de distancia. El atributo kind de struct hwloc_distances_s es un conjunto de tipos unidos con OR.

Cada matriz de distancia puede tener solo un tipo entre HWLOC_DISTANCES_KIND_FROM_*, que especifica de dónde proviene la información de distancia, y un tipo entre HWLOC_DISTANCES_KIND_MEANS_*, que especifica si los valores son latencias o anchos de banda.

Enumerador

HWLOC_DISTANCES_KIND_FROM_OS
Estas distancias se obtuvieron del sistema operativo o del hardware.
HWLOC_DISTANCES_KIND_FROM_USER
Estas distancias fueron proporcionadas por el usuario.
HWLOC_DISTANCES_KIND_MEANS_LATENCY
Los valores de distancia son similares a las latencias entre objetos. Los valores son más pequeños para objetos más cercanos, por lo tanto mínimos en la diagonal de la matriz (distancia entre un objeto y sí mismo). También podría ser el número de saltos de red entre objetos, etc.
HWLOC_DISTANCES_KIND_MEANS_BANDWIDTH
Los valores de distancia son similares a los anchos de banda entre objetos. Los valores son más altos para objetos más cercanos, por lo tanto máximos en la diagonal de la matriz (distancia entre un objeto y sí mismo). Tales valores son actualmente ignorados para la agrupación basada en distancias.
HWLOC_DISTANCES_KIND_HETEROGENEOUS_TYPES
Esta estructura de distancias cubre objetos de diferentes tipos. Esto puede aplicarse a la estructura 'NVLinkBandwidth' en presencia de un NVSwitch o puerto NVLink de un procesador POWER.

enum hwloc_distances_transform_e

Transformaciones de estructuras de distancias.

Enumerador

HWLOC_DISTANCES_TRANSFORM_REMOVE_NULL
Eliminar objetos NULL de la estructura de distancias. Cada objeto que fue reemplazado con NULL en el array objs es eliminado y el array values es actualizado en consecuencia.

Al menos 2 objetos deben permanecer, de lo contrario hwloc_distances_transform() devolverá -1 con errno establecido a EINVAL.

kind será actualizado con o sin HWLOC_DISTANCES_KIND_HETEROGENEOUS_TYPES de acuerdo con los objetos restantes.

HWLOC_DISTANCES_TRANSFORM_LINKS
Reemplazar los valores de ancho de banda con un número de enlaces. Usualmente todos los valores serán o bien 0 (sin enlace) o 1 (un enlace). Sin embargo, algunas matrices podrían obtener valores más grandes si algunos pares de pares están conectados por diferentes números de enlaces.

Los valores en la diagonal se establecen a 0.

Esta transformación solo se aplica a matrices de ancho de banda.

HWLOC_DISTANCES_TRANSFORM_MERGE_SWITCH_PORTS
Fusionar conmutadores con múltiples puertos en un solo objeto. Esto actualmente solo se aplica a NVSwitches donde las GPUs parecen estar conectadas a diferentes puertos del conmutador. Los puertos del conmutador deben ser objetos con el subtipo 'NVSwitch' como en la matriz NVLinkBandwidth.

Esta transformación reemplazará todos los puertos con solo el primero, ahora conectado a todas las GPUs. Los otros puertos son eliminados aplicando HWLOC_DISTANCES_TRANSFORM_REMOVE_NULL internamente.

HWLOC_DISTANCES_TRANSFORM_TRANSITIVE_CLOSURE
Aplicar un cierre transitivo a la matriz para conectar objetos a través de conmutadores. Todos los pares de GPUs serán reportados como directamente conectados en lugar de GPUs que solo están conectadas a conmutadores.

Los puertos del conmutador deben ser objetos con el subtipo 'NVSwitch' como en la matriz NVLinkBandwidth.

Documentación de Funciones

int hwloc_distances_get (hwloc_topology_t topology, unsigned * nr, struct hwloc_distances_s ** distances, unsigned long kind, unsigned long flags)

Recuperar matrices de distancia. Recuperar matrices de distancia de la topología en el array distances .

flags actualmente no se usa, debe ser 0.

kind sirve como un filtro. Si es 0, se devuelven todas las matrices de distancia. Si contiene algún HWLOC_DISTANCES_KIND_FROM_*, solo se devuelven las matrices de distancia cuyo tipo coincida con alguno de estos. Si contiene algún HWLOC_DISTANCES_KIND_MEANS_*, solo se devuelven las matrices de distancia cuyo tipo coincida con alguno de estos.

En la entrada, nr apunta al número de matrices de distancia que pueden almacenarse en distances. En la salida, nr apunta al número de matrices de distancia que fueron realmente encontradas, incluso si algunas de ellas no pudieron ser almacenadas en distances. Las matrices de distancia que no pudieron ser almacenadas son ignoradas, pero la funcción aún devuelve éxito (0). El llamador puede averiguarlo comparando el valor apuntado por nr antes y después de la llamada a la función.

Cada matriz de distancias devuelta en el arreglo distances debe ser liberada por el llamador usando hwloc_distances_release().

Devuelve

0 en caso de éxito, -1 en caso de error.

int hwloc_distances_get_by_depth (hwloc_topology_t topology, int depth, unsigned * nr, struct hwloc_distances_s ** distances, unsigned long kind, unsigned long flags)

Recupera las matrices de distancias para un objeto en una profundidad específica en la topología. Idéntico a hwloc_distances_get() con el filtro adicional depth .

Devuelve

0 en caso de éxito, -1 en caso de error.

int hwloc_distances_get_by_name (hwloc_topology_t topology, const char * name, unsigned * nr, struct hwloc_distances_s ** distances, unsigned long flags)

Recupera una matriz de distancias con el nombre dado. Usualmente solo una estructura de distancias puede coincidir con un nombre dado.

El nombre de la estructura más común es 'NUMALatency'. Otros incluyen 'XGMIBandwidth', 'XGMIHops', 'XeLinkBandwidth' y 'NVLinkBandwidth'.

Devuelve

0 en caso de éxito, -1 en caso de error.

int hwloc_distances_get_by_type (hwloc_topology_t topology, hwloc_obj_type_t type, unsigned * nr, struct hwloc_distances_s ** distances, unsigned long kind, unsigned long flags)

Recupera las matrices de distancias para objetos de un tipo específico. Idéntico a hwloc_distances_get() con el filtro adicional type .

Devuelve

0 en caso de éxito, -1 en caso de error.

const char * hwloc_distances_get_name (hwloc_topology_t topology, struct hwloc_distances_s * distances)

Obtiene una descripción de lo que contiene una estructura de distancias. Por ejemplo 'NUMALatency' para distancias NUMA proporcionadas por el hardware (ACPI SLIT), o NULL si se desconoce.

Devuelve

la cadena constante con el nombre de la estructura de distancias.

Nota

El nombre devuelto no debe ser liberado por el llamador, pertenece a la biblioteca hwloc.

void hwloc_distances_release (hwloc_topology_t topology, struct hwloc_distances_s * distances)

Libera una estructura de matriz de distancias previamente devuelta por hwloc_distances_get().

Nota

Esta función no es necesaria si la estructura se elimina con hwloc_distances_release_remove().

int hwloc_distances_transform (hwloc_topology_t topology, struct hwloc_distances_s * distances, enum hwloc_distances_transform_e transform, void * transform_attr, unsigned long flags)

Aplica una transformación a una estructura de distancias. Modifica una estructura de distancias que fue obtenida previamente con hwloc_distances_get() o una de sus variantes.

Esto modifica la copia local de las estructuras de distancias pero no modifica la información de distancias almacenada dentro de la topología (recuperada por otra llamada a hwloc_distances_get() o exportada a XML). Para hacer esto, se debe añadir una nueva estructura de distancias con el mismo nombre, tipo, objetos y valores (ver Añadir distancias entre objetos) y luego eliminar esta antigua con hwloc_distances_release_remove().

transform debe ser una de las transformaciones listadas en hwloc_distances_transform_e.

Estas transformaciones pueden modificar el contenido de los arreglos objs o values .

transform_attr debe ser NULL por ahora.

flags debe ser 0 por ahora.

Devuelve

0 en caso de éxito, -1 en caso de error, por ejemplo si los flags son inválidos.

Nota

Los objetos en el arreglo de distancias objs pueden ser directamente modificados in situ sin usar hwloc_distances_transform(). Se puede usar hwloc_get_obj_with_same_locality() para convertir fácilmente entre objetos similares de diferentes tipos.
