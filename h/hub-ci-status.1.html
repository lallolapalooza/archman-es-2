NOMBRE

hub-ci-status - Muestra el estado de las comprobaciones de GitHub para un commit.

SINOPSIS

hub ci-status [-v] [COMMIT]

OPCIONES

-v, --verbose

Imprime un informe detallado de todas las comprobaciones de estado y sus URLs.

-f, --format FORMATO

Imprime de forma bonita todas las comprobaciones de estado usando FORMATO (implica --verbose). Consulte la sección "FORMATOS BONITOS" de git-log(1) para obtener detalles adicionales sobre cómo se utilizan los marcadores de posición en el formato. Los marcadores de posición disponibles para las comprobaciones son:

%U: la URL de esta comprobación de estado

%S: estado de la comprobación (por ejemplo, "success", "failure")

%sC: establece el color en rojo, verde o amarillo, según el estado

%t: nombre de la comprobación de estado

--color[=CUÁNDO]

Habilita la salida con color incluso si stdout no es una terminal. CUÁNDO puede ser uno de "always" (por defecto para --color), "never" o "auto" (por defecto).

COMMIT

Un SHA de commit o un nombre de rama (por defecto: "HEAD").

Salidas y estados de salida posibles:

  • éxito, neutral: 0
  • fallo, error, action_required, cancelled, timed_out: 1
  • pendiente: 2
