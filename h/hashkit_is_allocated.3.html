hashkit_is_allocated(3)

Paquete: libmemcached-awesome

Licencias: BSD

HASHKIT_IS_ALLOCATED(3) libmemcached-awesome HASHKIT_IS_ALLOCATED(3)

NOMBRE

hashkit_is_allocated - Documentación de libhashkit

SINOPSIS

#include <libhashkit-1.0/hashkit.h>
Compilar y enlazar con -lhashkit
typedef struct hashkit_st hashkit_st
hashkit_st *hashkit_create(hashkit_st *hash)
Parámetros
hash -- dirección de memoria de una estructura hashkit_st; si se pasa un nullptr, la estructura se asignará dinámicamente por libhashkit
Devuelve
puntero a la estructura hashkit_st inicializada
hashkit_st *hashkit_clone(hashkit_st *destination, const hashkit_st *ptr)
Parámetros
  • destination -- dirección de memoria de una estructura hashkit_st; si se pasa un nullptr, la estructura se asignará dinámicamente por libhashkit
  • ptr -- puntero a la estructura hashkit_st a copiar
Devuelve
puntero a una estructura hashkit_st (destination, si no es nullptr), inicializada desde ptr
void hashkit_free(hashkit_st *hash)
Parámetros
hash -- puntero a una estructura hashkit_st inicializada
bool hashkit_is_allocated(const hashkit_st *hash)
Parámetros
hash -- puntero a una estructura hashkit_st inicializada
Devuelve
booleano, si la estructura hash fue asignada dinámicamente

DESCRIPCIÓN

La función hashkit_create() inicializa un objeto hashkit para su uso. Si pasas un argumento nullptr para hash, se asignará memoria para el objeto. Si especificas un bloque de memoria preasignado, este se inicializará para su uso.

La función hashkit_clone() inicializa un objeto hashkit de manera similar a hashkit_create(), pero en lugar de usar configuraciones predeterminadas, usará las configuraciones del objeto hashkit ptr.

La función hashkit_free() libera todos los recursos que están siendo consumidos por los objetos hashkit que fueron inicializados con hashkit_create() o hashkit_clone().

La función hashkit_is_allocated() informa si la memoria fue asignada para un objeto hashkit.

VALOR DE RETORNO

hashkit_create() y hashkit_clone() devolverán nullptr en caso de fallo o un puntero a hashkit_st en caso de éxito.

hashkit_is_allocated() devuelve verdadero si la memoria para el objeto hashkit fue asignada dentro de hashkit_create() o hashkit_clone(), de lo contrario, es falso y se trataba de memoria suministrada por el usuario.
