DESCRIPCIÓ

N

De forma predeterminada, hwloc-ps lista solo aquellos procesos actualmente en ejecución que están vinculados. Si -t se proporciona, los procesos que no están vinculados pero contienen al menos un hilo vinculado también se muestran, así como todos sus

hilos.

hwloc-ps muestra el identificador del proceso, la línea de comandos y la vinculación. La vinculación puede informarse como objetos o conjuntos de CPU (cpusets)

.

De forma predeterminada, las vinculaciones de los procesos están restringidas a la topología actualmente disponible. Si algunos procesos están vinculados a procesadores que no están disponibles para el proceso actual, se ignoran a menos que --disallowed se pro

porcione.

La salida es una lista simple. Si desea anotar la topología jerárquica con procesos para ver cómo están realmente distribuidos en la máquina, es posible que desee usar lstopo --ps en su lugar (que también solo muestra procesos que están vinculados)

.

El interruptor -a se puede usar para mostrar todos los procesos

, si
se desea.

EJEMPLO

S

Si un proceso está vinculado, aparece en la salida

predeterminada:


$ hwloc-ps

myprogram

Si un proceso está vinculado a dos núcleos de un paquete más grande, la salida mostrará estos núcleos. La opción --single-ancestor devolverá más bien el paquete incluso si en realidad es mayor que la vinculación aquí (el proceso no está vinculado a Core:0 de Package:0)

:


$ hwloc-ps
4863 Core:1 Core:2 myprogram
$ hwloc-ps --single-ancestor

myprogram

Ejemplos con procesos

MPI

En Linux, hwloc-ps también puede mostrar alguna variable de entorno específica del proceso al final de la línea. Esto es útil, por ejemplo, para identificar los rangos MPI entre los

procesos:


$ hwloc-ps --pid-cmd env=OMPI_COMM_WORLD_RANK
29093 PU:0 myprogram OMPI_COMM_WORLD_RANK=0
29094 PU:2 myprogram OMPI_COMM_WORLD_RANK=1
29095 PU:1 myprogram OMPI_COMM_WORLD_RANK=2
29096 PU:3 myprogram OMPI_COMM_WORLD_RANK=

3

Algunas variables de entorno específicas de MPI ampliamente utilizadas (OMPI_COMM_WORLD_RANK, PMIX_RANK, PMI_RANK y SLURM_PROCID) son realmente reconocidas directamente por hwloc-ps al solicitar el comando

mpirank:


$ hwloc-ps --pid-cmd mpirank
29093 PU:0 myprogram PMIX_RANK=0
29094 PU:2 myprogram PMIX_RANK=1
29095 PU:1 myprogram PMIX_RANK=2
29096 PU:3 myprogram

PMIX_RANK=3

Además de leer variables de entorno, hwloc-ps también puede agregar la salida de un programa personalizado. De nuevo, para leer el rango del proceso Open

MPI:


$ hwloc-ps --pid-cmd myscript
29093 PU:0 myprogram OMPI_COMM_WORLD_RANK=0

NAME

hwloc-ps - discover and display information about processes, their PUs, and their OS root pthreads

SYNOPSIS

hwloc-ps [options] [process_mask...]

OPTIONS

-a, --all
Display all processes, even those that do not have any PUs attached.
-h, --help
Print a usage message and exit.
-i, --io
Display I/O devices and memory attached to processes.
-p, --pthreads
Display OS root pthreads instead of processes.
-x, --xml
Display result in XML format.
-N, --numa
Display NUMA nodes in addition to other objects.
-l, --logical
Display logical processors instead of physical ones.
-m, --multiple
Display multiple levels of NUMA nodes.
-C, --children-depth
