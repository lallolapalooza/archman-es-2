NOMBRE

httpd - Servidor Apache Hypertext Transfer Protocol

SINOPSIS

httpd [ -d servidorroot ] [ -f config ] [ -C directiva ] [ -c directiva ] [ -D parametro ] [ -e nivel ] [ -E archivo ] [ -k iniciar|reiniciar|gracial|detener|detener-gracial ] [ -h ] [ -l ] [ -L ] [ -S ] [ -t ] [ -v ] [ -V ] [ -X ] [ -M ] [ -T ]

En sistemas Windows, los siguientes argumentos adicionales están disponibles:

httpd [ -k instalar|configurar|desinstalar ] [ -n nombre ] [ -w ]

RESUMEN

httpd es el programa servidor Apache HyperText Transfer Protocol (HTTP). Está diseñado para ser ejecutado como un proceso demonio autónomo. Cuando se utiliza de esta manera, creará un grupo de procesos hijos o hilos para manejar las solicitudes.

En general, httpd no debe invocarse directamente, sino que debe invocarse a través de apachectl en sistemas basados en Unix o como un servicio en Windows NT, 2000 y XP y como una aplicación de consola en Windows 9x y ME.

OPCIONES

-d servidorroot
Establece el valor inicial para la directiva ServerRoot a servidorroot. Esto puede ser anulado por la directiva ServerRoot en el archivo de configuración. El valor predeterminado es /usr/local/apache2.
-f config
Utiliza las directivas del archivo config al inicio. Si config no comienza con /, entonces se considera una ruta relativa a ServerRoot. El valor predeterminado es conf/httpd.conf.
-k iniciar|reiniciar|gracial|detener|detener-gracial
Señala a httpd que inicie, reinicie o detenga. Consulte Detener Apache httpd para obtener más información.
-C directiva
Procesa la directiva de configuración antes de leer los archivos de configuración.
-c directiva
Procesa la directiva de configuración después de leer los archivos de configuración.
-D parametro
Establece un parametro de configuración que puede ser utilizado con secciones <IfDefine> en los archivos de configuración para omitir o procesar comandos condicionalmente al inicio y reinicio del servidor. También puede usarse para establecer ciertos parámetros de inicio menos comunes, incluyendo -DNO_DETACH (evita que el proceso padre se desvincule) y -DFOREGROUND (evita que el proceso padre llame a setsid(), etc.).
-e nivel
Establece el LogLevel a nivel durante el inicio del servidor. Esto es útil para aumentar temporalmente la verbosidad de los mensajes de error para encontrar problemas durante el inicio.
-E archivo
Envía mensajes de error durante el inicio del servidor al archivo.
-h
Muestra un resumen de las opciones de línea de comandos disponibles.
-l
Muestra una lista de los módulos compilados en el servidor. Esto no mostrará los módulos cargados dinámicamente incluidos usando la directiva LoadModule.
-L
Muestra una lista de directivas proporcionadas por módulos estáticos, junto con los argumentos esperados y los lugares donde la directiva es válida. Las directivas proporcionadas por módulos compartidos no se muestran.
-M
Vuelca una lista de Módulos Estáticos y Compartidos cargados.
-S
Muestra la configuración analizada del archivo de configuración (actualmente solo muestra la configuración de los hosts virtuales).
-T (Disponible en la versión 2.3.8 y posteriores)
Omite la verificación de la raíz del documento al iniciar/reiniciar.
-t
Ejecuta pruebas de sintaxis para los archivos de configuración únicamente. El programa sale inmediatamente después de estas pruebas de análisis de sintaxis con un código de retorno de 0 (Sintaxis OK) o un código de retorno distinto de 0 (Error de Sintaxis). Si también se establece -D DUMP_VHOSTS, se imprimirán detalles de la configuración del host virtual. Si se establece -D DUMP_MODULES, se imprimirán todos los módulos cargados.
-v
Muestra la versión de httpd y luego sale.
-V
Muestra la versión y los parámetros de compilación de httpd y luego sale.
-X
Ejecuta httpd en modo de depuración. Solo se iniciará un trabajador y el servidor no se desvinculará de la consola.

Los siguientes argumentos solo están disponibles en la plataforma Windows:

-k instalar|configurar|desinstalar
Instala Apache httpd como un servicio de Windows NT; cambia las opciones de inicio para el servicio Apache httpd; y desinstala el servicio Apache httpd.
-n nombre
El nombre del servicio Apache httpd a señalar.
-w
Mantiene la ventana de la consola abierta en caso de error para que se pueda leer el mensaje de error.
