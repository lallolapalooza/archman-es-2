Exporta la topología a un archivo XML. Este archivo puede cargarse más tarde a través de hwloc_topology_se

Por defecto, se utiliza el formato de exportación más reciente, lo que significa que las versiones anteriores de hwloc (por ejemplo, v1.x) no podrán importarlo. Es posible exportar al formato XML específico de v1.x usando la bandera HWLOC_TOPOLOGY_EXPORT_XML_FLAG_V1 pero puede omitir algunos detalles sobre la topología. Si existe alguna posibilidad de que el archivo exportado pueda ser importado de nuevo por un proceso que use hwloc 1.x, se debe considerar detectarlo en tiempo de ejecución y usar el formato de exportación correspondiente

void hwloc_topology_set_userdata_export_callback (hwloc_topology_t topology, void(*)(void *reserved, hwloc_topology_t topology, hwloc_obj_t obj)

export_cb)

Set the application-specific callback for exporting object userdata. The object userdata pointer is not exported to XML by default because hwloc does not know what it

contains.

This function lets applications set export_cb to a callback function that converts this opaque userdata into an exportable

string.

export_cb is invoked during XML export for each object whose userdata pointer is not NULL. The callback should use hwloc_export_obj_userdata() or hwloc_export_obj_userdata_base64() to actually export something to XML (possibly multiple times per object)

.

export_cb may be set to NULL if userdata should not be exported to

XML.

void hwloc_topology_set_userdata_import_callback (hwloc_topology_t topology, void(*)(hwloc_topology_t topology, hwloc_obj_t obj, const char *name, const void *buffer, size_t length)

import_cb)

Set the application-specific callback for importing userdata. On XML import, userdata is ignored by default because hwloc does not know how to store it in

memory.

This function lets applications set import_cb to a callback function that will get the XML-stored userdata and store it in the object as expected by the

application.

import_cb is called during hwloc_topology_load() as many times as hwloc_export_obj_userdata() was called during export. The topology is not entirely setup yet. Object attributes are ready to consult, but links between objects are

not.

import_cb may be NULL if userdata should be ignored during

import.
