NOMBRE

heap2exec - genera un ejecutable independiente a partir de una imagen de *SML/NJ* heap.

SINOPSIS

heap2exec [ -32 | -64 ] [ MODOENLACE ] archivo

DESCRIPCIÓN

En el uso normal, SML/NJ representa un programa como un archivo de imagen de heap con un nombre de la forma foo.arquitectura-sistema_operativo. Heap2exec genera un ejecutable independiente a partir de una imagen de heap. Tienes la opción de especificar un modo de enlace preferido.

El valor predeterminado es enlazar estáticamente en FreeBSD y Linux.

Ten en cuenta que heap2exec es un componente *opcional* del proceso de instalación de SML/NJ que no se incluye por defecto. Edita el archivo config/targets antes de la instalación para incluirlo.

OPCIONES

-32

ejecuta la versión de 32 bits del programa (actualmente la predeterminada).

-64

ejecuta la versión de 64 bits del programa. Esta opción solo se aplica a la arquitectura x86-64 (también conocida como amd64).

-static, -linkwith-a

enlaza estáticamente el programa con el sistema de tiempo de ejecución. El enlace estático es el predeterminado en Linux y FreeBSD.

-dynamic, -linkwith-so

enlaza dinámicamente el programa con el sistema de tiempo de ejecución.

AUTOR

Heap2exec fue escrito por Matthias Blume.

VER TAMBIÉN

sml(1)

ERRORES

Heap2exec está limitado a las arquitecturas x86 y amd64 y a los sistemas operativos macOS, Linux y FreeBSD.
