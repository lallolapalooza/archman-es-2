CONVENCIONE

S

Se supone que la mayoría de los comandos de hub se ejecutan en el contexto de un repositorio git local existente. Hub detectará automáticamente el repositorio de GitHub al que pertenece el directorio de trabajo actual escaneando sus remotos

git.

En caso de que haya múltiples remotos git que apunten todos a GitHub, hub asume que el principal se llama "upstream", "github" u "origin", en ese orden de

preferencia.

Al trabajar con forks, se recomienda que el remoto git de tu propio fork se llame "origin" y que el remoto git del repositorio upstream se llame "upstream". Ver ⟨https://help.github.com/articles/configuring-a-remote-for-a-fork/

⟩

La rama predeterminada (usualmente "master") del repositorio actual se detecta

así: 
git symbolic-ref refs/remotes/origin/HE
A
D

donde origin es el nombre del remoto git del repositorio

upstream.

El destino al que se considera que se envía la rama actualmente comprobada depende de la configuración git config push.default . Si el valor es "upstream" o "tracking", la información de seguimiento de una rama se lee

así: 
git rev-parse --symbolic-full-name BRANCH@{upstrea
m
}

De lo contrario, hub escanea los remotos git para encontrar el primero para el que refs/remotes/REMOTE/BRANCH existe. Los remotos "origin", "github" y "upstream" se buscan al final porq

ue hub asume que es más probable que la rama actual se
envíe a tu fork en lugar del repositorio canónico.

CONFIGURACIÓ

N

Autenticación OAuth de

GitHub

Hub solicitará el nombre de usuario y contraseña de GitHub la primera vez que necesite acceder a la API y lo intercambiará por un token OAuth, que guarda en ~/.config

/hub.

Para evitar que se solicite, usa las variables de entorno GITHUB_USER y GITHUB_PASSWORD

.

Alternativamente, puedes proporcionar GITHUB_TOKEN, un token de acceso con permisos de repo. Esto no se escribirá en ~/.conf

ig/
hub.

HTTPS en lugar del protocolo

git

Si prefieres el protocolo HTTPS para las operaciones de git, puedes configurar hub para que genere todas las URLs con https: en lugar de git: o ssh

:: 
$ git config
--global hub.p
rotocol https

Esto afectará a clone, fork, remote add y otros comandos de hub que expanden re

ferencias abreviadas a URLs
de repositorios de GitHub.

Enterprise

HUB_CONFI

La ruta del archivo desde la que se lee y en la que se guarda la configuración de hub. Si XDG_CONFIG_HOME está presente, el valor predeterminado es $XDG_CONFIG_HOME/hub; de lo contrario es $HOME/.config/hub.
