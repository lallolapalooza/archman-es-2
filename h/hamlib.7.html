DESCRIPCIÓ

N

Las Ham Radio Control Libraries, abreviadas como Hamlib, son un esfuerzo de desarrollo para proporcionar una interfaz consistente a los programadores que desean incorporar el control de radios y rotadores en sus

programas.

Hamlib no es una aplicación de usuario completa, sino que es una capa de software destinada a facilitar enormemente el control de varios radios y otro hardware de estaciones de radioaficionados (shack). Hamlib permitirá a los autores de software como programas de registro, programas de comunicaciones digitales, o a aquellos que deseen desarrollar el software de control de radio definitivo, concentrarse en la interfaz de usuario y la función básica del programa en lugar del control de la radio. Hamlib consta de varias partes: la biblioteca de programación, los programas de utilidad y las interfaces de biblioteca a otros lenguajes de

programación.

La mayoría de los transceptores de radioaficionados más recientes permiten el control externo de sus funciones a través de una interfaz serie. Desafortunadamente, los comandos de control no siempre son consistentes a través de la línea de productos de un fabricante y cada línea de productos de un fabricante difiere enormemente de la de sus

competidores.

Hamlib intenta resolver este problema presentando un radio virtual al programador al proporcionar una interfaz para acciones como establecer la frecuencia de un Oscilador de Frecuencia Variable (VFO) dado, establecer el modo de operación, consultar al radio sobre su estado y configuración actuales, y dar a la aplicación una lista de las capacidades de un radio dado. Desafortunadamente, lo que puede lograrse con Hamlib está limitado por los radios mismos y algunos ofrecen una capacidad muy

limitada.

Otros dispositivos, como los rotadores de antena, pueden ser incluidos en el esquema de control de Hamlib. Otros desarrollos recientes incluyen servidores de interfaz de red y una capacidad de interfaz USB. Se proporcionan enlaces de lenguaje para C, C++, Perl, Python, Lua y TCL (habrá más)

.

Descripción

general

Hamlib es una biblioteca de interfaz frontal que proporciona una Interfaz de Programación de Aplicaciones (API) en lenguaje C a los programadores que desean integrar el control de radio o rotador en sus aplicaciones. Hamlib presenta un radio virtual o un rotador virtual que es una interfaz consistente para una aplicación a pesar de las amplias diferencias en las interfaces y capacidades de radios y

rotadores.

La biblioteca de interfaz frontal utiliza una serie de bibliotecas de interfaz trasera para traducir desde el interfaz frontal a los varios modelos individuales de radios y rotadores. Una biblioteca de interfaz trasera maneja la conversión de las variables del interfaz frontal al formato necesario por el dispositivo de radio o rotador que controla. Las bibliotecas de interfaz trasera se agrupan generalmente por fabricante y en algunos casos por un protocolo de control

común.

Hamlib también proporciona una biblioteca de interfaz para cada uno de varios lenguajes de guión comunes como Perl, Python, Lua, y TCL. Estos enlaces de lenguaje se generan mediante el uso de SWIG, un analizador/generador para interfaces de múltiples lenguajes a una biblioteca C. También se proporciona una interfaz en lenguaje C++ generada de forma

nativa.

Además de las APIs de C y complementarias, Hamlib también proporciona un par de demonios de red que proporcionan una API basada en comandos de texto para controlar un radio o rotador conectado a través de una conexión de redTCP/IP. Los demonios luego manejan la interfaz con la API C de

Hamlib.

Se puede controlar más de un tipo de dispositivo, radio o

rotador, a la vez, sin embargo, generalmente hay un lí
mite de un dispositivo por puerto serie u otro puerto.

Información del proyecto

Hamlib

El Proyecto Hamlib fue fundado por Frank Singleton, VK3FCS/KM5WS en julio de 2000. Poco después, Stephane Fillod, F8CFE, se unió a Frank en el proyecto Hamlib y el desarrollo de la API y su implementación condujo a un nivel razonable de madurez en unos años. Se alcanzó un hito importante cuando se lanzó Hamlib 1.2.0 en marzo de 2004. Las interfaces de la API y de la Interfaz Binaria de Aplicación (ABI) se han mantenido estables desde entonces hasta el lanzamiento de la versión 3.3 a mediados de 2018. La versión 4.0 marca un cambio importante en la ABI y ciertos cambios en la

API.

El desarrollo continúa a través de la serie de números de versión mayor 4.x y más allá. El lanzamiento de la 4.0 marca un cambio importante en la ABI con varios cambios para modos adicionales y demás que requerirán que los programas cliente que usan la ABI de C sean recompilados/re-enlazados, etc. Otros objetivos incluyen mejorar la documentación general (esta página del manual con más en progreso) y otras actualizaciones según sea

necesario.

El proyecto está alojado por SourceForge.net en la página del proyecto Hamlib. Dado que GitHub se ha convertido en un sitio de alojamiento de proyectos muy popular, Hamlib también tiene una página de proyecto dedicada en GitHub. GitHub también aloja el sitio web hamlib.org y la Wiki de Ha

mlib.

La discusión del desarrollo y la mayor parte del soporte al usuario tienen lugar en la lista de correo hamlib-developer. Aunque existen foros de discusión en SourceForge.net, rara vez se usan y no son leídos tan de cerca por los desarrolladores como la lista de

correo.

Para la gestión del código fuente, el proyecto utiliza Git, un rastreador de contenido distribuido y rápido. Entre sus características está que cada desarrollador tiene el historial completo de desarrollo de Hamlib disponible localmente. Para más información sobre el uso de Git, véase hamlib-gi

t(7).
Nota: mientras que un repositorio Git canónico está alojado en SourceForge, su disponibilidad no es esencial para el desarrollo continuo, aunque
los flujos de trabajo de desarrollo cambiarían temporalmente. Varios desar
rolladores encuentran que la interfaz web de GitHub es más fácil de usar y
últimamente el desarrollo se ha centrado en GitHub en lugar de SourceForge.

El código fuente de Hamlib se publica bajo dos licencias, la Licencia Pública General Menor (LGPL) versión 2.1 para la parte de la biblioteca, y la Licencia Pública General (GPL) versión 2 para los programas de

utilidad.

La LGPL permite que la biblioteca sea usada (enlazada) por programas independientemente de su licencia individual. Sin embargo, cualquier contribución al código fuente de la biblioteca permanece bajo una licencia copyleft, lo que significa que el código fuente de la biblioteca no puede usarse en violación de los términos de la LGPL (véase el archivo COPYING.LIB en el directorio principal del código fuente). clonación

El enfoque de Hamlib está en controlar radios que emplean un puerto y un protocolo de comandos para establecer frecuencia, modo, VFO, PTT, etc. La mayoría de los transceptores VHF/UHF no emplean dicha capacidad de control, pero sí proporcionan la posibilidad de clonar el contenido de la memoria de una radio a otra del mismo modelo. Un proyecto relacionado, Chirp, tiene como objetivo soportar radios con dicha capacidad de clonación. P

or favor, contacte con el proyecto Chir
p para obtener soporte de tales radios.
