NOMBRE

hub-alias - Muestra instrucciones del shell para envolver git.

SINOPSIS

hub alias [-s] [SHELL]

OPCIONES

-s

Genera un script de shell adecuado para eval.

SHELL

Especifica el tipo de shell (por defecto: variable de entorno "$SHELL").
