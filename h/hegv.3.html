CHEGV

Propósito:

!>
!> CHEGV calcula todos los valores propios, y opcionalmente, los vectores propios
!> de un problema de eigenvalor Hermitiano-definido generalizado complejo, de la forma
!> A*x=(lambda)*B*x,  A*Bx=(lambda)*x,  o B*A*x=(lambda)*x.
!> Aquí, se asume que A y B son Hermitianas y B es también
!> definida positiva.
!>

Parámetros

ITYPE 
!>          ITYPE es INTEGER
!>          Especifica el tipo de problema a resolver:
!>          = 1:  A*x = (lambda)*B*x
!>          = 2:  A*B*x = (lambda)*x
!>          = 3:  B*A*x = (lambda)*x
!>

JOBZ

!>          JOBZ es CHARACTER*1
!>          = 'N':  Calcular solo los valores propios;
!>          = 'V':  Calcular valores propios y vectores propios.
!>

UPLO

!>          UPLO es CHARACTER*1
!>          = 'U':  Se almacenan los triángulos superiores de A y B;
!>          = 'L':  Se almacenan los triángulos inferiores de A y B.
!>

N

!>          N es INTEGER
!>          El orden de las matrices A y B.  N >= 0.
!>

A

!>          A es un array COMPLEX, de dimensión (LDA, N)
!>          En la entrada, la matriz Hermitiana A. Si UPLO = 'U', la
!>          parte triangular superior N por N de A contiene la
!>          parte triangular superior de la matriz A. Si UPLO = 'L',
!>          la parte triangular inferior N por N de A contiene
!>          la parte triangular inferior de la matriz A.
!>
!>          En la salida, si JOBZ = 'V', entonces si INFO = 0, A contiene la
!>          matriz Z de vectores propios. Los vectores propios están normalizados
!>          de la siguiente manera:
!>          si ITYPE = 1 o 2, Z**H*B*Z = I;
!>          si ITYPE = 3, Z**H*inv(B)*Z = I.
!>          Si JOBZ = 'N', entonces en la salida, el triángulo superior (si UPLO='U')
!>          o el triángulo inferior (si UPLO='L') de A, incluyendo la
!>          diagonal, se destruye.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

B

!>          B es un array COMPLEX, de dimensión (LDB, N)
!>          En la entrada, la matriz Hermitiana definida positiva B.
!>          Si UPLO = 'U', la parte triangular superior N por N de B
!>          contiene la parte triangular superior de la matriz B.
!>          Si UPLO = 'L', la parte triangular inferior N por N de B
!>          contiene la parte triangular inferior de la matriz B.
!>
!>          En la salida, si INFO <= N, la parte de B que contiene la matriz se
!>          sobrescribe con el factor triangular U o L de la factorización de Cholesky
!>          B = U**H*U o B = L*L**H.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B.  LDB >= max(1,N).
!>

W

!>          W es un array REAL, de dimensión (N)
!>          Si INFO = 0, los valores propios en orden ascendente.
!>

WORK

!>          WORK es un array COMPLEX, de dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La longitud del array WORK.  LWORK >= max(1,2*N-1).
!>          Para eficiencia óptima, LWORK >= (NB+1)*N,
!>          donde NB es el tamaño del bloque para CHETRD devuelto por ILAENV.
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo del array WORK, devuelve
!>          este valor como la primera entrada del array WORK, y XERBLA no emite ningún mensaje de error
!>          relacionado con LWORK.
!>

RWORK

!>          RWORK es un array REAL, de dimensión (max(1, 3*N-2))
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>          > 0:  CPOTRF o CHEEV devolvieron un código de error:
!>             <= N:  si INFO = i, CHEEV no convergió;
!>                    i elementos fuera de la diagonal de una forma
!>                    tridiagonal intermedia no convergieron a cero;
!>             > N:   si INFO = N + i, para 1 <= i <= N, entonces el menor
!>                    principal principal de orden i de B no es positivo.
!>                    La factorización de B no pudo completarse y
!>                    no se calcularon valores propios ni vectores propios.
!>
