hwloc_obj_t hwloc_get_child_covering_cpuset (hwloc_topology_t topology, hwloc_const_cpuset_t set, hwloc_obj_t parent) [inline]

Obtener el hijo que cubre al menos el conjunto de CPU set.

Retorna

el hijo que cubre completamente el conjunto.

NULL si ningún hijo coincide o si set está vacío.

Nota

Esta función no puede funcionar si el padre no tiene un conjunto de CPU (objetos I/O o Varios).

hwloc_obj_t hwloc_get_next_obj_covering_cpuset_by_depth (hwloc_topology_t topology, hwloc_const_cpuset_t set, int depth, hwloc_obj_t prev) [inline]

Iterar sobre objetos de la misma profundidad que cubren al menos el conjunto de CPU set. La siguiente invocación debe pasar el valor de retorno anterior en prev para obtener el siguiente objeto que cubra al menos otra parte de set.

Retorna

el primer objeto a la profundidad depth que cubre al menos una parte del conjunto de CPU set si el objeto prev es NULL.

el siguiente si prev no es NULL.

NULL si no hay objeto siguiente.

Nota

Esta función no puede funcionar si los objetos a la profundidad dada no tienen conjuntos de CPU (objetos I/O o Varios).

hwloc_obj_t hwloc_get_next_obj_covering_cpuset_by_type (hwloc_topology_t topology, hwloc_const_cpuset_t set, hwloc_obj_type_t type, hwloc_obj_t prev) [inline]

Iterar sobre objetos del mismo tipo que cubren al menos el conjunto de CPU set. La siguiente invocación debe pasar el valor de retorno anterior en prev para obtener el siguiente objeto de tipo type que cubra al menos otra parte de set.

Retorna

el primer objeto de tipo type que cubre al menos una parte del conjunto de CPU set si el objeto prev es NULL.

el siguiente si prev no es NULL.

NULL si no hay objeto siguiente.

NULL si no hay profundidad para el tipo dado.

NULL si hay múltiples profundidades para el tipo dado, el llamador debe recurrir a hwloc_get_next_obj_covering_cpuset_by_depth().

Nota

Esta función no puede funcionar si los objetos del tipo dado no tienen conjuntos de CPU (objetos I/O o Varios).

hwloc_obj_t hwloc_get_obj_covering_cpuset (hwloc_topology_t topology, hwloc_const_cpuset_t set) [inline]

Obtener el objeto más bajo que cubre al menos el conjunto de CPU set.

Retorna

el objeto más bajo que cubre completamente el conjunto.

NULL si ningún objeto coincide o si set está vacío.
