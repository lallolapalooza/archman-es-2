NAME

hpcdtoppm

convert Photo CD image to PPM format

SYNOPSIS

hpcdtoppm [-nomip] [-ps|-eps|-psg|-epsg|-psd|-epsd] [-rotate] [-ycc] [-1|-Base/16|-256x384] [-2|-Base/4|-512x768] [-3|-Base|-1024x1536] [-4|-4Base|-2048x3072] [-5|-16Base|-4096x6144] [-6|-64Base|-8192x12288] [PhotoCDfile]

DESCRIPTION

Reads a Photo CD image file as input and writes a PPM image file as output.

The Photo CD format uses a different color space, RGB-IL, which is similar to YCbCr. This program converts that to standard RGB.

Photo CD images come in several resolutions. The base resolution is 2048x3072 pixels. Each higher resolution is twice the resolution in each dimension. The 64Base resolution is 8192x12288 pixels.

The program can also create Postscript output, which has several advantages: It is human readable. It does not require a special viewer. It can be scaled, rotated, and compressed.

OPTIONS

-nomip
Do not use mip-maps. The Photo CD format can contain several image resolutions in one file, called mip-maps. This option forces the use of the highest resolution image. This is the default behavior.
-ps
-eps
-psg
-epsg
-psd
-epsd
Generate Postscript output instead of PPM. The suffixes indicate the type of Postscript:
ps
Color Postscript.
eps
Color Encapsulated Postscript.
psg
Grayscale Postscript.
epsg
Grayscale Encapsulated Postscript.
psd
Dithered color Postscript.
epsd
Dithered color Encapsulated Postscript.
The default output is PPM.
-rotate
Rotate the image 90 degrees counter-clockwise. This is useful if the image is stored in portrait orientation but you want to display it in landscape.
-ycc
Write the image in a variation on PPM format in which the samples are YCC instead of RGB.
-1|-Base/16|-128x192
Extract the Base/16 image.
-2|-Base/4|-256x384
Extract the Base/4 image.
-3|-Base|-512x768
Extract the Base image.
-4|-4Base|-1024x1536
Extract the 4Base image.
-5|-16Base|-2048x3072
Extract the 16Base image.
-6|-64Base|-4096x6144
Extract the 64Base image. This resolution can be extracted from ProPhotoCD images only. The path of the 64Base extension files is derived from the path to the image file. This means that it doesn't work on stdin an the directory structure must be the very same as on the ProPhotoCD.

Postcript Output

For Postscript output (options -ps, -eps, -psg, -epsg, -psd, -epsg) you can define both the resolution and placement of the image. Both size and position are specified in points (1/72 inch).

The position of the image (where the origin is assumed to be at the lower left corner of the page) is controlled by the -pl and -pb options (applicable at all resolutions).

The size of color and grayscale images is changed with the -pw and -ph options. Every image pixel is mapped onto one Postscript pixel.

There are three modes of control for dithered Postscript:

Image size

(-pw and -ph)
Printer resolution
(-dpi)
Scaling factor
(-fak)

These three factors are interdependent, hence no more then two can be specified simultaneously. Using -dpi and the -pw/-ph options together often yields pleasing results. Even using the default values for these options will produce results differing from those obtained without use of the options.

Limitations

The program ignores read protection.

The -i option is not working correctly.

Available information obout the Photo-CD format is vague; this program was developed by trial-and-error after staring at hex-dumps. Please send bugs reports and patches to the author.
