HITEX(1) Manual de Comandos Generales HITEX(1)

NOMBRE

hitex - Salida HINT de TeX

SINOPSIS

hitex [opciones] [&formato] [archivo|\comandos]

DESCRIPCIÓN

Ejecuta el tipógrafo HiTeX en archivo, usualmente creando archivo.hnt. Si el argumento de archivo no tiene extensión, se le añadirá ".tex". En lugar de un nombre de archivo, se puede dar un conjunto de comandos HiTeX, el primero de los cuales debe empezar con una barra invertida. Con un argumento &formato, HiTeX usa un conjunto diferente de comandos precompilados, contenido en formato.fmt; usualmente es mejor usar la opción -fmt formato en su lugar.

HiTeX es una versión de TeX que crea archivos HINT. El formato de archivo HINT está diseñado para la lectura de documentos en pantalla. Usando un visor HINT (ver https://hint.userweb.mwn.de) para mostrar un archivo HINT, su contenido se adaptará dinámicamente al área de visualización disponible.

El uso típico de HiTeX es con formatos pregenerados. El comando hitex usa el equivalente al formato plain TeX, y el comando hilatex usa el equivalente al formato LaTeX. Para generar formatos, use el interruptor -ini.

El manejo de los argumentos de línea de comandos de HiTeX es similar al de otros programas TeX en la implementación de web2c.

HiTeX incorpora las extensiones e-TeX (ver etex(1)) si se usa con el interruptor -etex.

HiTeX incorpora las extensiones necesarias para LaTeX (ver latex(1)) si se usa con el interruptor -ltx.

OPCIONES

Esta versión de HiTeX entiende las siguientes opciones de línea de comandos.

-cnf-line cadena
Analiza cadena como una línea de configuración de texmf.cnf. Ver el manual de Kpathsea.
-compress
Habilita el uso de compresión para el archivo HINT. Los archivos comprimidos son más pequeños pero requieren descompresión al visualizarlos. Usar solo para archivos grandes si el tamaño del archivo es importante.
-empty-page
Al escribir libros, a menudo se insertan páginas vacías - por ejemplo, para comenzar capítulos en una página de la derecha. Estas páginas vacías son una molestia para la lectura en pantalla, donde no hay páginas de la izquierda o la derecha. Esta opción mantiene las páginas vacías en la salida.
-no-empty-page
Esta opción intenta eliminar las páginas vacías en la salida. Está configurada por defecto.
-etex
Habilita las extensiones e-TeX. Esta opción solo es efectiva en combinación con -ini. Ver etex(1).
-file-line-error
Imprime mensajes de error en el formato archivo:línea:error, similar a como muchos compiladores los formatean.
-no-file-line-error
Deshabilita la impresión de mensajes de error en el estilo archivo:línea:error.
-fmt formato
Usa formato como el nombre del formato a utilizar, en lugar del nombre por el cual se llamó a HiTeX o una línea %&.
-help
Imprime el mensaje de ayuda y sale.
-hint-debug máscara_de_bits
Establece las banderas de depuración del archivo HINT de acuerdo con la máscara_de_bits. Ver la opción -hint-debug-help para más detalles.
-hint-debug-help
Imprime una explicación de las banderas de depuración HINT y sale.
-hyphenate-first-word
TeX usualmente no intenta insertar puntos de separación de sílabas en la primera palabra de un párrafo. Si un archivo HINT debe mostrarse en un dispositivo muy pequeño, tales puntos de separación de sílabas podrían ser necesarios. Esta opción está habilitada por defecto y permite la generación de estos puntos de separación de sílabas.
-no-hyphenate-first-word
Deshabilita la inserción automática de puntos de separación de sílabas en la primera palabra de un párrafo. Solo se necesita si se requiere compatibilidad completa con TeX.
-ini
Inicia en modo INI, que se usa para volcar formatos. El modo INI puede usarse para componer, pero no se carga ningún formato, y pueden requerirse inicializaciones básicas como establecer códigos de categoría (catcodes).
-interaction modo
Establece el modo de interacción. El modo puede ser batchmode, nonstopmode, scrollmode, y errorstopmode. El significado de estos modos es el mismo que el de los comandos \ correspondientes.
-jobname nombre
Usa nombre para el nombre del trabajo, en lugar de derivarlo del nombre del archivo de entrada.
-kpathsea-debug máscara_de_bits
Establece las banderas de depuración de búsqueda de rutas de acuerdo con la máscara_de_bits. Ver el manual de Kpathsea para más detalles.
-ltx
Habilita las extensiones de LaTeX. Esta opción solo es efectiva en combinación con -ini. Ver latex(1).
-mfmode modo
Usa modo como el modo de Metafont al generar fuentes faltantes. Ver mf(1) para más detalles.
-mktex fmt
Habilita mktexfmt, donde fmt debe ser tex, tfm, fmt, o pk.
-no-mktex fmt
Deshabilita mktexfmt, donde fmt debe ser tex, tfm, fmt, o pk.
-output-directory directorio
Escribe los archivos de salida en directorio en lugar del directorio actual. Busca primero los archivos de entrada en directorio, luego a lo largo de la ruta de búsqueda normal.
-parse-first-line
Si la primera línea del archivo de entrada principal comienza con %&, la analiza para buscar un nombre de volcado.
-no-parse-first-line
Deshabilita el análisis de la primera línea del archivo de entrada principal.
-progname nombre
Finge ser el programa nombre. Esto afecta tanto al formato utilizado como a las rutas de búsqueda.
-resolution número
Al usar Metafont para generar fuentes pk faltantes, usa una resolución de número DPI. Ver mf(1) para más detalles.
-version
Imprime la información de la versión y sale.

ENTORNO

Ver la documentación de la biblioteca Kpathsea (por ejemplo, el nodo `Especificaciones de ruta') para obtener detalles precisos sobre cómo se usan las variables de entorno. La utilidad kpsewhich se puede usar para consultar los valores de las variables.

Una advertencia: en la mayoría de los formatos de HiTeX, no puedes usar ~ en un nombre de archivo que le des directamente a HiTeX, porque ~ es un carácter activo en TeX y, por lo tanto, se expande, no se toma como parte del nombre del archivo. Otros programas, como Metafont, no tienen este problema.

TEXMFOUTPUT
Normalmente, HiTeX coloca sus archivos de salida en el directorio actual. Si algún archivo de salida no se puede abrir allí, intenta abrirlo en el directorio especificado en la variable de entorno TEXMFOUTPUT. No hay un valor predeterminado para esa variable. Por ejemplo, si dices hitex paper y

el directorio actual no se puede escribir y TEXMFOUTPUT tiene el valor /tmp, HiTeX intenta crear /tmp/paper.log (y /tmp/paper.hnt, si se produce alguna salida). TEXMFOUTPUT también se comprueba en busca de archivos de entrada, ya que TeX a menudo genera archivos que luego necesitan ser leídos; para la entrada, no se agregan sufijos (como ``.tex'') por defecto, el nombre de entrada se verifica simplemente como se da.
TEXINPUTS
Ruta de búsqueda para archivos \input y \openin. Esto normalmente comienza con `.` , para que los archivos del usuario se encuentren antes que los archivos del sistema. Un componente de ruta vacío se reemplazará con las rutas definidas en el archivo texmf.cnf. Por ejemplo, establezca TEXINPUTS a ".:/home/user/tex:" para anteponer el directorio actual y "/home/user/tex" a la ruta de búsqueda estándar.
TEXFORMATS
Ruta de búsqueda para archivos de formato.
TFMFONTS
Ruta de búsqueda para archivos de métricas de fuentes (.tfm).
SOURCE_DATE_EPOCH
Si está establecido, su valor, tomado en segundos desde la época, se utilizará para la fecha de creación y como momento de referencia para los primitivos relacionados con el tiempo de LaTeX. Esto es útil para realizar compilaciones reproducibles.
FORCE_SOURCE_DATE
Si está establecido con el valor "1", los primitivos de TeX relacionados con el tiempo (\year, \month, \day, \time) también se inicializan a partir del valor de SOURCE_DATE_EPOCH. No se recomienda si existe alguna alternativa viable.

Se pueden consultar muchas, muchas más variables de entorno relacionadas con la búsqueda de rutas. Consulte el manual de Kpathsea.

ARCHIVOS

La ubicación de los archivos mencionados a continuación varía de un sistema a otro. Utilice la utilidad kpsewhich para encontrar sus ubicaciones.

*.tfm
Archivos de métricas para las fuentes de HiTeX.
*.fmt
Archivos de formato HiTeX preprocesados.
*.pk *.pfb
Archivos de fuentes utilizados por HiTeX.

NOTAS

Esta página del manual no pretende ser exhaustiva. La documentación completa de HiTeX se puede encontrar en el manual de usuario de HiTeX. Se puede encontrar información adicional en el manual de la biblioteca de Kpathsea y en HINT: El formato de archivo, que está disponible como libro o en formato electrónico en la página principal del proyecto HINT en https://hint.userweb.mwn.de.

ERRORES

Esta versión de HiTeX no maneja correctamente los espaciados (glues) y los kerning con un ancho que depende de \hsize o \vsize. De manera similar, cuando la disposición de las entradas de la tabla o las fórmulas matemáticas dependen de \hsize o \vsize, su salida puede estar distorsionada.

DISPONIBILIDAD

HiTeX debería compilarse en una gran variedad de arquitecturas de máquinas y sistemas operativos. HiTeX es parte de la distribución TeX Live.

La página principal de HiTeX se encuentra en https://hint.userweb.mwn.de. Allí encontrará software adicional, lo más importante son los visores de archivos HINT, e información adicional.
