DESCRIPCIÓN DETALLADA

Esta interfaz ofrece formas de convertir entre conjuntos de CPU hwloc y conjuntos de CPU de glibc, como los manipulados por sched_getaffinity() o pthread_attr_setaffinity_np().

Nota

El objeto topology debe coincidir con la máquina actual.

DOCUMENTACIÓN DE FUNCIONES

int hwloc_cpuset_from_glibc_sched_affinity (hwloc_topology_t topology, hwloc_cpuset_t hwlocset, const cpu_set_t * schedset, size_t schedsetsize) [inline]

Convierte el conjunto de CPU de afinidad sched de glibc schedset en el conjunto de CPU hwloc. Esta función puede usarse antes de llamar a sched_setaffinity o a cualquier otra función que acepte un cpu_set_t como parámetro de entrada.

schedsetsize debe ser sizeof(cpu_set_t) a menos que schedset se haya asignado dinámicamente con CPU_ALLOC.

Devuelve

0 si tiene éxito.

-1 con errno establecido a ENOMEM si alguna reasignación interna falló.
