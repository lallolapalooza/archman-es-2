NOMBRE

halp - Una herramienta CLI para obtener ayuda con herramientas CLI 🐙

SINOPSIS

halp [--check] [--no-version] [--no-help] [-c|--config] [-t|--timeout] [-v|--verbose] [-h|--help] [-V|--version] <COMANDO> [subcomandos]

DESCRIPCIÓN

Una herramienta CLI para obtener ayuda con herramientas CLI 🐙

OPCIONES

--check=ARG
Establece el argumento a comprobar
--no-version
Deshabilita la comprobación de la información de versión
--no-help
Deshabilita la comprobación de la información de ayuda
-c, --config=RUTA
Establece el archivo de configuración
También se puede especificar con la variable de entorno HALP_CONFIG.
-t, --timeout=S
Establece el tiempo de espera para el comando
-v, --verbose
Habilita el registro detallado
-h, --help
Imprime la ayuda
-V, --version
Imprime la versión
<COMANDO>
Comando o nombre del binario

SUBCOMANDOS

halp-plz(1)
Obtener ayuda adicional
