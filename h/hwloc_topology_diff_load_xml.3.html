Descripción

Detallada

Las aplicaciones que manipulan muchas topologías similares, por ejemplo una para cada nodo de un clúster homogéneo, pueden querer comprimir las topologías para reducir la huella de

memoria.

Este archivo ofrece una forma de manipular la diferencia entre topologías y exportar/importarla a/desde XML. La compresión puede lograrse almacenando una topología completa mientras que las demás solo se describen por sus diferencias con la primera. La topología real puede reconstruirse cuando sea necesario aplicando la diferencia precalculada a la topología de

referencia.

Esta interfaz está dirigida a nodos muy similares. Solo se admiten diferencias muy simples entre topologías, por ejemplo un cambio en el tamaño de la memoria, el nombre del objeto o algún atributo de información. Diferencias más complejas como añadir o eliminar objetos no pueden representarse en las estructuras de diferencia y por lo tanto devuelven errores. Las diferencias entre conjuntos de objetos o conjuntos permitidos a nivel de topología tampoco pueden

representarse.

Esto significa que no es necesario aplicar la diferencia al examinar la organización del árbol (cuántos niveles, cuántos objet

os por nivel, qué tipo de objetos, conjuntos de CPU y de nodos, etc.) y al enlazar a objetos. Sin embargo, la diferencia d
ebe aplicarse al examinar los atributos del objeto como el nombre, el tamaño de la memoria o los atributos de información.

int hwloc_topology_diff_build (hwloc_topology_t topology, hwloc_topology_t newtopology, unsigned long flags, hwloc_topology_diff_t *

diff)

Calcula la diferencia entre 2 topologías. La diferencia se almacena como una lista de entradas hwloc_topology_diff_t que comienza en diff. Se calcula realizando un recorrido en profundidad (depth-first) de ambos árboles de topología simultáneamente

.

Si la diferencia entre 2 objetos es demasiado compleja para ser representada (por ejemplo, si algunos objetos tienen tipos diferentes, o diferentes números de hijos), se encola una entrada de diff especial de tipo HWLOC_TOPOLOGY_DIFF_TOO_COMPLEX. El cálculo del diff no continúa por debajo de estos objetos. Por lo tanto, cada entrada de diff de este tipo significa que la diferencia entre dos subárboles no pudo ser

calculada.

0 si la diferencia puede ser representada correctamente.

0 con diff apuntando a NULL si no hay diferencia entre las

topologías.

1 si la diferencia es demasiado compleja (ver arriba). Algunas entradas en la lista serán de tipo HWLOC_TOPOLOGY_DIFF_TOO_COMPLEX
