int hwloc_obj_attr_snprintf (char *restrict string, size_t size, hwloc_obj_t obj, const char *restrict separator, int verbose)

Convierte los atributos de un objeto de topología dado en una forma legible para humanos. Los valores de los atributos se separan por separator.

Solo se imprimen los atributos principales en modo no detallado.

Si size es 0, string puede ser NULLde forma segura.

Devuelve

el número de caracteres que fueron realmente escritos si no se truncó, o el que se habría escrito (sin incluir el final \0).

int hwloc_obj_type_snprintf (char *restrict string, size_t size, hwloc_obj_t obj, int verbose)

Convierte el tipo de un objeto de topología dado en una forma legible para humanos. A diferencia de hwloc_obj_type_string(), esta función incluye atributos específicos del objeto (como la profundidad del Grupo, el tipo de Puente, o el tipo de dispositivo del SO) en la salida, y requiere que el llamador proporcione el búfer de salida.

Se garantiza que la salida sea la misma para todos los objetos de un mismo nivel de topología.

Si verbose es 1, se usan nombres de tipo más largos, por ejemplo L1Cache en lugar de L1.

La cadena de salida puede ser analizada de nuevo por hwloc_type_sscanf().

Si size es 0, string puede ser NULLde forma segura.

Devuelve

el número de caracteres que fueron realmente escritos si no se truncó, o el que se habría escrito (sin incluir el final \0).

const char * hwloc_obj_type_string (hwloc_obj_type_t type)

Devuelve una cadena constante del tipo de objeto. Esta función es la forma básica de convertir un tipo genérico en una cadena. La cadena de salida puede ser analizada de nuevo por hwloc_type_sscanf().

hwloc_obj_type_snprintf() puede devolver una salida más precisa para un objeto específico, pero requiere que el llamador proporcione el búfer de salida.

Devuelve

Una cadena constante que contiene el nombre del tipo de objeto o 'Unknown'.

int hwloc_type_sscanf (const char * string, hwloc_obj_type_t * typep, union hwloc_obj_attr_u * attrp, size_t attrsize)

Devuelve un tipo de objeto y sus atributos a partir de una cadena de tipo. Convierte cadenas como 'Package' o 'L1iCache' en los tipos correspondientes. La coincidencia no distingue entre mayúsculas y minúsculas, y solo se requiere que coincidan las primeras letras.

El tipo de objeto coincidente se establece en typep (que no puede ser NULL).

Los atributos específicos del tipo, por ejemplo el tipo de Caché, la profundidad de la Caché, la profundidad del Grupo, el tipo de Puente o el tipo de Dispositivo del SO, pueden devolverse en attrp. Los atributos que no se especifican en la cadena (por ejemplo 'Group' sin una profundidad, o 'L2Cache' sin un tipo de caché) se establecen a -1.

attrp solo se rellena si no es NULL y si su tamaño especificado en attrsize es lo suficientemente grande. Debe ser al menos tan grande como la unión hwloc_obj_attr_u.

Devuelve

0 si se identificó correctamente un tipo, de lo contrario -1.

Nota

Se garantiza que esta función coincida con cualquier cadena devuelta por hwloc_obj_type_string() o hwloc_obj_type_snprintf().

Esta es una versión extendida de la ahora obsoleta hwloc_obj_type_sscanf().

int hwloc_type_sscanf_as_depth (const char * string, hwloc_obj_type_t * typep, hwloc_topology_t topology, int * depthp)

Devuelve un tipo de objeto y la profundidad de su nivel a partir de una cadena de tipo. Convierte cadenas como 'Package' o 'L1iCache' en los tipos correspondientes y devuelve en depthp la profundidad del nivel correspondiente en la topología topology.

Si no hay ningún objeto de este tipo presente en la arquitectura subyacente, HWLOC_TYPE_DEPTH_UNKNOWN se devuelve.

Si existen múltiples niveles de este tipo (por ejemplo, si se da Group sin ninguna profundidad), la función puede devolver HWLOC_TYPE_DEPTH_MULTIPLE en su lugar.

El tipo de objeto coincidente se establece en typep si typep no es NULL.

Nota

Esta función es similar a hwloc_type_sscanf() seguido de hwloc_get_type_depth() pero también desambigua automáticamente múltiples niveles de grupos, etc.

Se garantiza que esta función coincida con cualquier cadena devuelta por hwloc_obj_type_string() o hwloc_obj_type_snprintf().
