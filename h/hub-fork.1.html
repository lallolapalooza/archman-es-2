NOMBRE

hub-fork - Crear una bifurcación (fork) del repositorio actual en GitHub y añadirle un remoto de git.

SINOPSIS

hub fork [--no-remote] [--remote-name REMOTE] [--org ORGANIZACIÓN]

OPCIONES

--no-remote

Omitir la adición de un remoto de git para la bifurcación.

--remote-name REMOTE

Establecer el nombre para el nuevo remoto de git.

--org ORGANIZACIÓN

Crear la bifurcación del repositorio dentro de esta organización.

EJEMPLOS

$ hub fork
[ repositorio bifurcado en GitHub ]
> git remote add -f USER git@github.com:USER/REPO.git
$ hub fork --org=ORGANIZACIÓN
[ repositorio bifurcado en GitHub dentro de la organización ORGANIZACIÓN ]
> git remote add -f ORGANIZATION git@github.com:ORGANIZATION/REPO.git
