NOMBRE

highvoltage - torres de transmisión de alto voltaje.

SINOPSIS

highvoltage [--display host:display.screen] [--visual visual] [--window] [--root] [--delay número] [--speed número] [--spacing número] [--count número]

DESCRIPCIÓN

Un vuelo pausado pasando por algunas torres de transmisión de alto voltaje. ¡Huele a ozono!

OPCIONES

--visual visual
Especifica qué visual usar. Los valores legales son el nombre de una clase visual o el ID numérico (decimal o hexadecimal) de un visual específico.
--window
Dibuja en una ventana recién creada. Esta es la opción predeterminada.
--root
Dibuja en la ventana raíz.
--delay número
Retraso por fotograma, en microsegundos. Predeterminado: 30000 (0.03 segundos).
--speed número
Velocidad de animación. 2.0 significa el doble de rápido, 0.5 significa la mitad de rápido.
--spacing número
Espacio entre torres. 2.0 significa el doble de distancia, 0.5 significa la mitad de distancia.
--count número
Número de torres renderizadas. 1 - 40. Predeterminado: 7.

AMBIENTE

DISPLAY
para obtener el host y el número de pantalla predeterminados.
XENVIRONMENT
para obtener el nombre de un archivo de recursos que anula los recursos globales almacenados en la propiedad RESOURCE_MANAGER.
XSCREENSAVER_WINDOW
El ID de la ventana a usar con --root.

VER TAMBIÉN

X(1), xscreensaver(1)
