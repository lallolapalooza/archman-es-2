NOMBRE

hypnowheel - dibuja patrones de espiral superpuestos y translúcidos

SINOPSIS

hypnowheel [--display host:display.screen] [--visual visual] [--window] [--root] [--window-id número] [--delay int] [--layers int] [--count int] [--twistiness float] [--speed float] [--wander] [--symmetric] [--fps]

DESCRIPCIÓN

Dibuja una serie de patrones de espiral superpuestos y translúcidos. La rigidez de sus espirales fluctúa hacia adentro y hacia afuera.

OPCIONES

--visual visual
Especifica qué visual usar. Los valores legales son el nombre de una clase visual, o el número de id (decimal o hexadecimal) de un visual específico.
--window
Dibuja en una ventana recién creada. Este es el valor predeterminado.
--root
Dibuja en la ventana raíz.
--window-id número
Dibuja en la ventana especificada.
--delay int
Retraso entre fotogramas, en microsegundos. Predeterminado 20000.
--layers int
Cuántas espirales diferentes dibujar a la vez. Predeterminado 4.
--count int
Cuántos brazos debe tener cada espiral. Predeterminado 11.
--twistiness float
Qué tan apretadas pueden llegar a ser las espirales, medido en rotaciones. Predeterminado 4.0 (cuatro vueltas completas).
--speed ratio
Menos de 1 para más lento, mayor que 1 para más rápido. Predeterminado 1.
--wander
Si se especifica, entonces los centros de las espirales vagarán, en lugar de que todas tengan el mismo origen.
--symmetric
Si se especifica, entonces cada par de espirales que giran a la izquierda y a la derecha serán imágenes especulares entre sí.
--fps
Muestra la velocidad de fotogramas actual, la carga de la CPU y el recuento de polígonos.

ENTORNO

DISPLAY
para obtener el host y el número de pantalla predeterminados.
XENVIRONMENT
para obtener el nombre de un archivo de recursos que anula los recursos globales almacenados en la propiedad RESOURCE_MANAGER.
XSCREENSAVER_WINDOW
El ID de la ventana a usar con --root.
