Descripción Detallada

Esta interfaz ofrece formas de recuperar información de topología sobre dispositivos OpenCL.

Actualmente, solo las implementaciones OpenCL de AMD y NVIDIA ofrecen información de localidad útil sobre sus dispositivos.

Documentación de Funciones

int hwloc_opencl_get_device_cpuset (hwloc_topology_t topology, cl_device_id device, hwloc_cpuset_t set) [inline]

Obtiene el conjunto de CPU de procesadores que están físicamente cerca del dispositivo OpenCL device. Almacena en set el conjunto de CPU que describe la localidad del dispositivo OpenCL device.

La topología topology y el dispositivo device deben coincidir con la máquina local. No se necesita la detección de dispositivos de E/S ni el componente OpenCL en la topología.

La función solo devuelve la localidad del dispositivo. Si se necesita más información sobre el dispositivo, se deben usar objetos del sistema operativo en su lugar, consulte hwloc_opencl_get_device_osdev() y hwloc_opencl_get_device_osdev_by_index().

Actualmente, esta función solo está implementada de manera significativa para Linux con la implementación OpenCL de AMD o NVIDIA; otros sistemas simplemente recibirán un conjunto de CPU completo.

Devuelve

0 si tiene éxito.

-1 en caso de error, por ejemplo, si no se pudo encontrar el dispositivo.

hwloc_obj_t hwloc_opencl_get_device_osdev (hwloc_topology_t topology, cl_device_id device) [inline]

Obtiene el objeto de dispositivo del sistema operativo hwloc correspondiente al dispositivo OpenCL deviceX.

Devuelve

El objeto de dispositivo del sistema operativo hwloc correspondiente al dispositivo OpenCL dado device.

NULL si no se pudo encontrar ninguno, por ejemplo, si no están disponibles los atributos OpenCL requeridos.

Actualmente, esta función solo funciona en dispositivos OpenCL de AMD y NVIDIA que admiten extensiones OpenCL relevantes. Se debe preferir hwloc_opencl_get_device_osdev_by_index() siempre que sea posible, es decir, cuando se conocen el índice de plataforma y el índice de dispositivo.

La topología topology y el dispositivo device deben coincidir con la máquina local. La detección de dispositivos de E/S y el componente OpenCL deben estar habilitados en la topología. Si no es así, la localidad del objeto aún se puede encontrar usando hwloc_opencl_get_device_cpuset().

Nota

Esta función no puede funcionar si los dispositivos PCI están filtrados.

El objeto de dispositivo PCI hwloc correspondiente se puede encontrar buscando el puntero padre del resultado (a menos que los dispositivos PCI estén filtrados).

hwloc_obj_t hwloc_opencl_get_device_osdev_by_index (hwloc_topology_t topology, unsigned platform_index, unsigned device_index) [inline]

Obtiene el objeto de dispositivo del sistema operativo hwloc correspondiente al dispositivo OpenCL para los índices dados.

Devuelve

El objeto de dispositivo del sistema operativo hwloc que describe el dispositivo OpenCL cuyo índice de plataforma es platform_index, y cuyo índice de dispositivo dentro de esta plataforma es device_index.

NULL si no hay ninguno.

La topología topology no tiene necesariamente que coincidir con la máquina actual. Por ejemplo, la topología puede ser una importación XML de un host remoto. La detección de dispositivos de E/S y el componente OpenCL deben estar habilitados en la topología.

Nota

El objeto de dispositivo PCI correspondiente se puede obtener buscando el objeto padre del dispositivo del sistema operativo (a menos que los dispositivos PCI estén filtrados).

int hwloc_opencl_get_device_pci_busid (cl_device_id device, unsigned * domain, unsigned * bus, unsigned * dev, unsigned * func) [inline]

Devuelve los IDs de dominio, bus y dispositivo del dispositivo OpenCL device. El dispositivo device debe coincidir con la máquina local.

Devuelve

0 si tiene éxito.

-1 en caso de error, por ejemplo, si no se pudo encontrar la información del dispositivo.
