hg-purge(1)

Paquete: mercurial

Licencias: GPL

HG(PURGE) HG(PURGE)

NOMBRE

hg purge - elimina archivos no rastreados por Mercurial

SINOPSIS

hg purge [OPCIÓN]... [DIR]...

DESCRIPCIÓN

Elimina archivos no conocidos por Mercurial. Esto es útil para probar cambios locales y no confirmados en un árbol de origen limpio.

Esto significa que purge eliminará lo siguiente por defecto:

  • Archivos desconocidos: archivos marcados con "?" por hg status
  • Directorios vacíos: de hecho, Mercurial ignora los directorios a menos que contengan archivos bajo gestión de control de código fuente

    Pero dejará intactos:

  • Archivos rastreados modificados y no modificados
  • Archivos ignorados (a menos que se especifique -i o --all)
  • Archivos nuevos añadidos al repositorio (con hg add)

    Las opciones --files y --dirs se pueden usar para dirigir purge a eliminar solo archivos, solo directorios o ambos. Si no se proporciona ninguna de estas opciones, se eliminarán ambos.

    Si se proporcionan directorios en la línea de comandos, solo se consideran los archivos en esos directorios.

    Ten cuidado con purge, ya que podrías eliminar irreversiblemente algunos archivos que olvidaste añadir al repositorio. Si solo quieres imprimir la lista de archivos que este programa eliminaría, usa la opción --print.

OPCIONES

-a, --abort-on-err
Aborta si ocurre un error
--all
Elimina también los archivos ignorados
-i, --ignored
Elimina solo archivos ignorados
--dirs
Elimina directorios vacíos
--files
Elimina archivos
-p, --print
Imprime nombres de archivo en lugar de eliminarlos
-0, --print0
Termina los nombres de archivo con NUL, para usar con xargs (implica -p/--print)
--confirm
Pregunta antes de eliminar permanentemente archivos
-I,--include <PATRÓN[+]>
Incluye nombres que coincidan con los patrones dados
-X,--exclude <PATRÓN[+]>
Excluye nombres que coincidan con los patrones dados

[+] La opción marcada se puede especificar varias veces

ALIASES

clean
