Descripción

detallada

El tipo hwloc_bitmap_t representa un conjunto de enteros (positivos o nulos). Un mapa de bits puede ser de tamaño infinito (todos los bits están establecidos después de algún punto). Un mapa de bits incluso puede estar completo si todos los bits están

establecidos.

hwloc utiliza mapas de bits para conjuntos de procesadores del SO (que pueden ser en realidad hilos de hardware) como hwloc_cpuset_t (un typedef para hwloc_bitmap_t), o conjuntos de nodos de memoria NUMA como hwloc_nodeset_t (también un typedef para hwloc_bitmap_t). Estos se utilizan para los campos cpuset y nodeset en la estructura hwloc_obj, ver Conjuntos de objetos (hwloc_cpuset_t

y hwloc_nodeset_t).

Tanto los conjuntos de CPU como los de nodos siempre están indexados por el número físico del SO. Sin embargo, los usuarios normalmente no deberían construir conjuntos de CPU y nodos manualmente (por ejemplo, con hwloc_bitmap_set()). En su lugar, se deben usar conjuntos de objetos existentes y combinarlos con hwloc_bitmap_or(), etc. Por ejemplo, enlazar el hilo actual a un par de núcleos puede realizarse

con: 
hwloc_obj_t core1 = ... , core2 = ... ;
hwloc_bitmap_t set = hwloc_bitmap_alloc();
hwloc_bitmap_or(set, core1->cpuset, core2->cpuset);
hwloc_set_cpubind(topology, set, HWLOC_CPUBIND_THREAD);
hwloc_bitmap_free(set)
;

Not

a
La mayoría de las funciones siguientes devuelven 0 en caso de éxito y -1 en caso de error. El caso de error habitual sería un fallo interno al reallocar/extender el almacenamiento del mapa de bits (errno se establecería en ENOMEM). Ver también Informe de errores en la API.

Hay varios ejemplos de uso de la API de mapas de bits dis

ponibles en el directorio doc/examples/ del árbol de
fuentes. Las pruebas de regresión como tests/hwloc/hw
loc_bitmap*.c también hacen un uso intensivo de esta API.

#define hwloc_bitmap_foreach_begin(id,

bitmap)

Macro de bucle que itera sobre el mapa de bits bitmap. El bucle debe comenzar con hwloc_bitmap_foreach_begin() y terminar con hwloc_bitmap_foreach_end() seguido de un ';

Parse a bitmap string as the default hwloc format and stores it in bitmap bitmap. Note that if the bitmap is a CPU or nodeset, the input string must contain physical indexes.

The input string should be a comma-separared list of hexadecimal 32-bit blocks. String '0xffffffff,0x6,0x2' is parsed as a bitmap containing all bits between 64 and 95, and bits 33, 34 and 1.

Returns

0 on success, -1 on error.

Stringify a bitmap into a newly allocated taskset-specific string. Note that if the bitmap is a CPU or nodeset, it contains physical indexes.
