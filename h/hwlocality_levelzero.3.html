hwlocality_levelzero - Interoperabilidad con la interfaz oneAPI Level Zero.

Descripción Detallada

Esta interfaz ofrece formas de recuperar información de topología sobre dispositivos gestionados por la API Level Zero, tanto para los dispositivos principales Core (API ZE) como para los dispositivos Sysman (API ZES).

Documentación de Funciones

int hwloc_levelzero_get_device_cpuset (hwloc_topology_t topology, ze_device_handle_t device, hwloc_cpuset_t set) [inline]

Obtiene el conjunto de CPU de los procesadores lógicos que están físicamente cerca del dispositivo Level Zero device. Almacena en set el conjunto de CPU que describe la localidad del dispositivo Level Zero device.

La topología topology y el dispositivo device deben coincidir con la máquina local. La biblioteca Level Zero debe haber sido inicializada con zeInit(). La detección de dispositivos de E/S y el componente Level Zero no son necesarios en la topología.

La función solo devuelve la localidad del dispositivo. Si se necesita más información sobre el dispositivo, se deben usar objetos del SO en su lugar, véase hwloc_levelzero_get_device_osdev().

Esta función actualmente solo está implementada de manera significativa para Linux; otros sistemas simplemente obtendrán un cpuset completo.

Devuelve

0 en caso de éxito.

-1 en caso de error, por ejemplo si la información del dispositivo no pudo ser encontrada.

Nota

zeDevicePciGetPropertiesExt() debe ser soportada, o se devolverá la localidad de toda la máquina.

hwloc_obj_t hwloc_levelzero_get_device_osdev (hwloc_topology_t topology, ze_device_handle_t device) [inline]

Obtiene el objeto de dispositivo del SO de hwloc correspondiente al dispositivo Level Zero device.

Devuelve

El objeto de dispositivo del SO de hwloc que describe el dispositivo Level Zero devicedado.

NULL si no se pudo encontrar ninguno.

La topología topology y el dispositivo dv_ind deben coincidir con la máquina local. La biblioteca Level Zero debe haber sido inicializada con zeInit(). La detección de dispositivos de E/S y el componente Level Zero deben estar habilitados en la topología. Si no, la localidad del objeto aún puede ser encontrada usando hwloc_levelzero_get_device_cpuset().

Nota

Si el dispositivo ZE de entrada es realmente un subdispositivo, entonces su padre (dispositivo raíz) es realmente traducido, es decir, se devuelve el dispositivo del SO principal de hwloc en lugar de uno de sus hijos.

El dispositivo PCI de hwloc correspondiente puede ser encontrado mirando el puntero padre del resultado (a menos que los dispositivos PCI sean filtrados).

zeDevicePciGetPropertiesExt() debe ser soportada.
