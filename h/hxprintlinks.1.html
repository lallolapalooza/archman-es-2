HXPRINTLINKS(1) Utilidades HTML-XML HXPRINTLINKS(1)

NOMBRE

hxprintlinks - añade una lista numerada de enlaces al final de un archivo HTML

SINOPSIS

hxprintlinks [ -b base ] archivo-o-URL

DESCRIPCIÓN

hxprintlinks añade una lista numerada de todas las URL (enlaces) encontradas en el archivo al final del archivo HTML.

OPCIONES

Se admiten las siguientes opciones:

-b base
Hace que las URL de la lista sean absolutas, utilizando base como URL base.

OOPERANDOS

Se admite el siguiente operando:

archivo-o-URL
El archivo sobre el que trabajar. Si el argumento está ausente, o si es - (un guion simple), el documento se lee de la entrada estándar.

VER TAMBIÉN

hxcopy(1)

ERRORES

La opción -b probablemente tiene un uso limitado. Hace que los enlaces de la lista generada sean absolutos, pero no cambia los otros enlaces. Para una solución más flexible, utilice hxcopy(1) sobre la salida de hxprintlinks. Por ejemplo, en lugar de


hxprintlinks -b http://example.org/base/ myfile.html

utilice


hxprintlinks myfile.html | hxcopy -i http://example.org/base -o .
