SINOPSIS

uso: hadd [-a] [-f] [-f[0-9]] [-fk] [-ff] [-k] [-L] [-Ltype] [-O] [-T]
[-v V] [-j J] [-dbg] [-d D] [-n N] [-cachesize CACHESIZE]
[-experimental-io-features EXPERIMENTAL_IO_FEATURES]
TARGET FUENTES

DESCRIPCIÓN

Este programa añadirá histogramas, árboles y otros objetos de una lista de archivos ROOT y los escribirá en un archivo ROOT de destino. El archivo de destino se crea nuevo y no debe existir, o si se proporciona -f ("forzar"), no debe ser uno de los archivos fuente.

OPCIONES

-a
Añadir al resultado
-f
Forzar sobrescritura del archivo de salida
-f[0-9]
Permite especificar el algoritmo de compresión i y el nivel j
del archivo de destino, pasando el número i*100 + j, por ejemplo, -f505. El
último dígito (j) se puede establecer de 0 = sin comprimir a 9 = muy
comprimido. El primer dígito (i) es 1 para ZLIB, 2 para LZMA, 4 para LZ4
y 5 para ZSTD. Los números recomendados son 101 (ZLIB), 207 (LZMA), 404
(LZ4), 505 (ZSTD). El valor predeterminado para esta bandera es 101
(kDefaultZLIB). Consulte la documentación de ROOT::RCompressionSetting y TFile::TFile
para más detalles.
-fk
Establece el archivo de destino para que contenga las cestas con la misma compresión
que los archivos de entrada (a menos que se especifique -O). Comprime los metadatos
utilizando el nivel de compresión especificado en la primera entrada o la
configuración de compresión después de fk (por ejemplo, 206 al usar -fk206)
-ff
El nivel de compresión utilizado es el especificado en la primera entrada
-k
Omitir archivos corruptos o inexistentes, no salir
-L
Leer la lista de objetos de FILE y fusionar o omitir aquellos
dependiendo del valor de "-Ltype". FILE debe contener un
nombre de objeto por línea, que no puede contener espacios en blanco o '/'. También
puede pasar nombres de TDirectory, que se aplican a todo el contenido del directorio.
Las líneas que comienzan con '#' se ignoran. Si se proporciona esta bandera,
"-Ltype" DEBE proporcionarse también.
-Ltype
Establece el tipo de operación realizada sobre los objetos listados en FILE
proporcionados con la bandera "-L". "SkipListed" omitirá todos los objetos listados;
"OnlyListed" solo fusionará esos objetos. Si se proporciona esta bandera,
"-L" debe proporcionarse también.
-O
Reoptimizar el tamaño de la cesta al fusionar TTree
-T
No fusionar Trees
-v
Establecer explícitamente el nivel de verbosidad: 0 solicita no mostrar nada, 99 es el
valor predeterminado
-j
Paralelizar la ejecución en 'J' procesos. Si no se especifica el número de procesos,
utiliza el máximo del sistema.
-dbg
Habilitar verbosidad. Si se especificó -j, no eliminar los archivos parciales
almacenados dentro del directorio de trabajo.
-d
Realizar la ejecución multiproceso parcial en el directorio especificado
DIRECTORIO
-n
Abrir como máximo 'N' archivos a la vez (usar 0 para solicitar usar el máximo del
sistema)
-cachesize
Redimensionar la caché de prelectura para acelerar las operaciones de E/S (usar 0 para
deshabilitar)
-experimental-io-features
Usado con un argumento proporcionado, habilita la característica experimental
correspondiente para los árboles de salida. Consulte ROOT::Experimental::EIOFeatures
TARGET
Archivo de destino
FUENTES
Archivos fuente
