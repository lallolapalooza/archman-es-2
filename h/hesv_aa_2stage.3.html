CHESV_AA_2STAGE calcula la solución al sistema de ecuaciones lineales A * X = B para matrices HE

Propósito:

!>
!> CHESV_AA_2STAGE calcula la solución a un sistema complejo de
!> ecuaciones lineales
!>    A * X = B,
!> donde A es una matriz hermitiana de N por N y X y B son matrices
!> de N por NRHS.
!>
!> Se utiliza el algoritmo de 2 etapas de Aasen para factorizar A como
!>    A = U**H * T * U,  si UPLO = 'U', o
!>    A = L * T * L**H,  si UPLO = 'L',
!> donde U (o L) es un producto de matrices de permutación y triangulares
!> superiores (inferiores) unitarias, y T es hermitiana y de banda.
!> La matriz T se factoriza luego con LU y pivoteo parcial.
!> La forma factorizada de A se utiliza entonces para resolver el
!> sistema de ecuaciones A * X = B.
!>
!> Esta es la versión bloqueada del algoritmo, que llama a BLAS de Nivel 3.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          = 'U':  Se almacena el triángulo superior de A;
!>          = 'L':  Se almacena el triángulo inferior de A.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de miembros independientes, es decir, el número de
!>          columnas de la matriz B.  NRHS >= 0.
!>

A

!>          A es un arreglo COMPLEX, dimensión (LDA,N)
!>          En la entrada, la matriz hermitiana A.  Si UPLO = 'U', la
!>          parte triangular superior de A de N por N contiene la parte
!>          triangular superior de la matriz A, y la parte triangular
!>          inferior estricta de A no se referencia.  Si UPLO = 'L', la
!>          parte triangular inferior de A de N por N contiene la parte
!>          triangular inferior de la matriz A, y la parte triangular
!>          superior estricta de A no se referencia.
!>
!>          En la salida, L se almacena debajo (o encima) de los bloques
!>          subdiagonales, cuando UPLO es 'L' (o 'U').
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del arreglo A.  LDA >= max(1,N).
!>

TB

!>          TB es un arreglo COMPLEX, dimensión (MAX(1,LTB)).
!>          En la salida, detalles de la factorización LU de la matriz de banda.
!>

LTB

!>          LTB es INTEGER
!>          El tamaño del arreglo TB. LTB >= MAX(1,4*N), utilizado
!>          internamente para seleccionar NB de modo que LTB >= (3*NB+1)*N.
!>
!>          Si LTB = -1, se asume una consulta de espacio de trabajo; la
!>          rutina solo calcula el tamaño óptimo de LTB,
!>          devuelve este valor como la primera entrada de TB, y
!>          XERBLA no emite ningún mensaje de error relacionado con LTB.
!>

IPIV

!>          IPIV es un arreglo INTEGER, dimensión (N)
!>          En la salida, contiene los detalles de los intercambios, es decir,
!>          la fila y columna k de A se intercambiaron con la
!>          fila y columna IPIV(k).
!>

IPIV2

!>          IPIV2 es un arreglo INTEGER, dimensión (N)
!>          En la salida, contiene los detalles de los intercambios, es decir,
!>          la fila y columna k de T se intercambiaron con la
!>          fila y columna IPIV(k).
!>

B

!>          B es un arreglo COMPLEX, dimensión (LDB,NRHS)
!>          En la entrada, la matriz de miembros independientes B.
!>          En la salida, la matriz solución X.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del arreglo B.  LDB >= max(1,N).
!>

WORK

!>          WORK es un espacio de trabajo COMPLEX de tamaño (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          El tamaño de WORK. LWORK >= MAX(1,N), utilizado internamente
!>          para seleccionar NB de modo que LWORK >= N*NB.
!>
!>          Si LWORK = -1, se asume una consulta de espacio de trabajo; la
!>          rutina solo calcula el tamaño óptimo del arreglo WORK,
!>          devuelve este valor como la primera entrada del arreglo WORK, y
!>          XERBLA no emite ningún mensaje de error relacionado con LWORK.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>          > 0:  si INFO = i, la factorización LU de banda falló en la i-ésima columna
!>
