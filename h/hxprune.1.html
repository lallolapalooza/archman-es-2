NOMBRE

hxprune - eliminar elementos marcados de un archivo HTML

SINOPSIS

hxprune [ -c clase ] [ -x ] [ archivo ]

DESCRIPCIÓN

hxprune elimina elementos especialmente marcados (con su contenido e hijos) de un archivo HTML. Por defecto, elimina elementos con un atributo de clase "exclude". El atributo de clase se analiza como una lista de palabras separadas por espacios en blanco y si una de esas palabras es "exclude", el elemento no se copia a la salida.

OPCIONES

Se admiten las siguientes opciones:

-c clase
Especificar una clase diferente a "exclude".
-x
Forzar que la salida sea en estilo XML, es decir, sin atributos cortos y con una barra (/) para marcar elementos vacíos.
