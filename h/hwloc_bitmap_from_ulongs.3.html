Descripción detallada

El tipo hwloc_bitmap_t representa un conjunto de enteros (positivos o nulos). Un mapa de bits puede ser de tamaño infinito (todos los bits están establecidos después de algún punto). Un mapa de bits incluso puede estar lleno si todos los bits están establecidos.

Los mapas de bits son utilizados por hwloc para conjuntos de procesadores del sistema operativo (que en realidad pueden ser hilos de hardware) como por hwloc_cpuset_t (un typedef para hwloc_bitmap_t), o conjuntos de nodos de memoria NUMA como hwloc_nodeset_t (también un typedef para hwloc_bitmap_t). Estos se utilizan para los campos cpuset y nodeset en la estructura hwloc_obj, ver Conjuntos de objetos (hwloc_cpuset_t y hwloc_nodeset_t).

Tanto los conjuntos de CPU como los de nodos siempre se indexan por el número físico del SO. Sin embargo, los usuarios generalmente no deben construir conjuntos de CPU y nodos manualmente (por ejemplo, con hwloc_bitmap_set()). En su lugar, deben usar los conjuntos de objetos existentes y combinarlos con hwloc_bitmap_or(), etc. Por ejemplo, enlazar el hilo actual en un par de núcleos puede realizarse con:

hwloc_obj_t core1 = ... , core2 = ... ;
hwloc_bitmap_t set = hwloc_bitmap_alloc();
hwloc_bitmap_or(set, core1->cpuset, core2->cpuset);
hwloc_set_cpubind(topology, set, HWLOC_CPUBIND_THREAD);
hwloc_bitmap_free(set);

Nota

La mayoría de las funciones a continuación devuelven 0 en éxito y -1 en caso de error. El caso de error habitual sería una falla interna para reasignar/extender el almacenamiento del mapa de bits (errno se establecería en ENOMEM). Ver también Informes de errores en la API.

Varios ejemplos de uso de la API de mapas de bits están disponibles en el directorio doc/examples/ en el árbol de fuentes. Las pruebas de regresión como tests/hwloc/hwloc_bitmap*.c también hacen un uso intensivo de esta API.

Documentación de definición de macros

#define hwloc_bitmap_foreach_begin(id, bitmap)

Macro de bucle que itera sobre el mapa de bits bitmap. El bucle debe comenzar con hwloc_bitmap_foreach_begin() y terminar con hwloc_bitmap_foreach_end() seguido de un ';'.

id es la variable del bucle; debe ser un unsigned int. La primera iteración establecerá id al índice más bajo en el mapa de bits. Las iteraciones sucesivas recorrerán, en orden, todos los índices restantes establecidos en el mapa de bits. Para ser específicos: cada iteración devolverá un valor para id tal que hwloc_bitmap_isset(bitmap, id) sea verdadero.

La aserción previene que el bucle sea infinito si el mapa de bits está infinitamente establecido.

#define hwloc_bitmap_foreach_end()

Fin de la macro de bucle que itera sobre un mapa de bits. Necesita un ';' de terminación.

int hwloc_bitmap_asprintf (char ** strp, hwloc_const_bitmap_t bitmap)

Convierte un mapa de bits a una cadena recién asignada en el formato hwloc predeterminado. Tenga en cuenta que si el mapa de bits es un conjunto de CPU o de nodos, contiene índices físicos.

Imprime los bits establecidos dentro de un mapa de bits como una lista separada por comas de bloques hexadecimales de 32 bits. Un mapa de bits que contiene los bits 1, 33, 34 y todos desde 64 hasta 95 se imprime como '0xffffffff,0x00000006,0x00000002'.

Devuelve

el número de caracteres que se escribieron (sin incluir el \0final).

-1 en caso de error, por ejemplo con errno establecido a ENOMEM si falla la asignación de la cadena de salida.

int hwloc_bitmap_clr (hwloc_bitmap_t bitmap, unsigned id)

Elimina el índice id del mapa de bits bitmap.

int hwloc_bitmap_clr_range (hwloc_bitmap_t bitmap, unsigned begin, int end)

Elimina los índices desde begin hasta end en el mapa de bits bitmap. Si end es -1, el rango es infinito.

int hwloc_bitmap_compare (hwloc_const_bitmap_t bitmap1, hwloc_const_bitmap_t bitmap2)

Compara los mapas de bits bitmap1 y bitmap2 en orden lexicográfico. Comparación lexicográfica de mapas de bits, comenzando por sus índices más altos. Compara los últimos índices primero, luego los segundos, etc. El mapa de bits vacío se considera menor que cualquier otro.

Devuelve

-1 si bitmap1 se considera menor que bitmap2.

1 si bitmap1 se considera mayor que bitmap2.

0 si los mapas de bits son iguales (a diferencia de hwloc_bitmap_compare_first()).

Por ejemplo, comparar los mapas de bits binarios 0011 y 0110 devuelve -1 (por lo tanto, 0011 se considera menor que 0110). Comparar 00101 y 01010 también devuelve -1.

Nota

Esto es diferente de la función inexistente hwloc_bitmap_compare_last() que solo compararía el índice más alto de cada mapa de bits.

int hwloc_bitmap_compare_first (hwloc_const_bitmap_t bitmap1, hwloc_const_bitmap_t bitmap2)

Compara los mapas de bits bitmap1 y bitmap2 usando su índice más bajo. Un mapa de bits se considera menor si su bit menos significativo es menor. El mapa de bits vacío se considera mayor que cualquier otro (porque su bit menos significativo no existe).

Devuelve

-1 si bitmap1 se considera menor que bitmap2.

1 si bitmap1 se considera mayor que bitmap2.

Por ejemplo, comparar los mapas de bits binarios 0011 y 0110 devuelve -1 (por lo tanto, 0011 se considera menor que 0110) porque el bit menos significativo de 0011 (0001) es menor que el bit menos significativo de 0110 (0010). Comparar 01001 y 00110 también devolvería -1 por la misma razón.

Devuelve

0 si los mapas de bits se consideran iguales, incluso si no lo son estrictamente. Solo necesitan tener el mismo bit menos significativo. Por ejemplo, comparar los mapas de bits binarios 0010 y 0110 devuelve 0 porque tienen el mismo bit menos significativo.

int hwloc_bitmap_list_asprintf (char ** strp, hwloc_const_bitmap_t bitmap)

Convierte un mapa de bits a una cadena de lista recién asignada. Nota que si el mapa de bits es un conjunto de CPU o de nodos, contiene índices físicos.

Las listas son índices o rangos separados por comas. Los rangos son índices separados por guiones. Un mapa de bits que contiene los bits 1, 33, 34 y todos de 64 a 95 se imprime como '1,33-34,64-95'. El último rango puede no tener un índice final si el mapa de bits está establecido infinitamente.

Devuelve

el número de caracteres que se escribieron (sin incluir el \0final).

-1 en caso de error, por ejemplo con errno establecido a ENOMEM en caso de fallo al asignar la cadena de salida.

Las listas son índices o rangos separados por comas. Los rangos son índices separados por guiones. Un mapa de bits que contiene los bits 1, 33, 34 y todos de 64 a 95 se imprime como '1,33-34,64-95'. El último rango puede no tener un índice final si el mapa de bits está establecido infinitamente.

el número de caracteres que se escribieron realmente si no se truncaron, o el número que se habrían escrito (sin incluir el \0final).

-1 en caso de error.

int hwloc_bitmap_nr_ulongs (hwloc_const_bitmap_t bitmap)

Devuelve el número de unsigned longs necesarios para almacenar el mapa de bits bitmap completamente. Este es el número de unsigned longs contiguos desde el primer bit del mapa de bits (incluso si no está establecido) hasta el último bit establecido. Esto es útil para conocer el parámetro nr que pasar a hwloc_bitmap_to_ulongs() (o qué llamadas a hwloc_bitmap_to_ith_ulong() se necesitan) para convertir completamente un mapa de bits en múltiples unsigned longs.

Cuando se llama sobre la salida de hwloc_topology_get_topology_cpuset(), el número devuelto es lo suficientemente grande para todos los conjuntos de CPU de la topología.

Devuelve

el número de unsigned longs necesarios.

-1 si el mapa de bits es infinito.

int hwloc_bitmap_sscanf (hwloc_bitmap_t bitmap, const char *restrict string)

La cadena de entrada debe ser una lista separada por comas de bloques hexadecimales de 32 bits. La cadena '0xffffffff,0x6,0x2' se analiza como un mapa de bits que contiene todos los bits entre 64 y 95, y los bits 33, 34 y 1.

Devuelve

0 en caso de éxito, -1 en caso de error.

Devuelve

el número de caracteres que se escribieron (sin incluir el \0 final).

int hwloc_bitmap_weight (hwloc_const_bitmap_t bitmap)

Calcula el "peso" del mapa de bits bitmap (es decir, el número de índices que están en el mapa de bits).

Devuelve

el número de índices que están en el mapa de bits.

-1 si el mapa de bits está infinitamente establecido.

int hwloc_bitmap_xor (hwloc_bitmap_t res, hwloc_const_bitmap_t bitmap1, hwloc_const_bitmap_t bitmap2)

Realiza una operación XOR en los mapas de bits bitmap1 y bitmap2 y almacena el resultado en el mapa de bits res. res puede ser el mismo que bitmap1 o bitmap2.

void hwloc_bitmap_zero (hwloc_bitmap_t bitmap)

Vacía el mapa de bits bitmap.
