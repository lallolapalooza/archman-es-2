NOMBRE

http - un servidor HTTP básico para alojar una carpeta de forma rápida y sencilla

SINOPSIS

http [OPCIONES] [DIRECTORIO]

DESCRIPCIÓN

Host These Things Please - un servidor HTTP básico para alojar una carpeta de forma rápida y sencilla.

La idea es crear un programa que pueda compilarse en un binario simple que se pueda usar desde la CLI de Linux para servir rápidamente el directorio actual a través de HTTP. Todo debe tener valores predeterminados razonables para que no tengas que pasar parámetros como el puerto a usar.

OPCIONES

[DIR]

Directorio a alojar. Debe existir.
Por defecto: directorio de trabajo actual.

-p --port [PUERTO]

Puerto en el que se ejecutará el servidor.
Debe estar entre 1 y 65.535. El valor 0 asignará un puerto aleatorio,
elegido por el sistema operativo.
Por defecto: primer puerto libre a partir del 8000.

-a --address [DIRECCIÓN]

IP a la que se enlazará el servidor.
Por defecto: 0.0.0.0.

-t --temp-dir [TEMP]

Directorio temporal a utilizar para almacenar los datos a escribir.
Solo es relevante si también se especifica --allow-write o si --no-encode
no está activado.
Por defecto: $TEMP.

--ssl [ARCHIVO-IDENTIDAD-TLS]

Archivo de identidad TLS a utilizar para cifrar.
La contraseña se toma de la variable de entorno HTTP_SSL_PASS, o está vacía
si dicha variable no existe.
Por defecto: Ninguno.

--gen-ssl

Genera un certificado TLS autofirmado de un solo uso
con openssl y úsalo para esta sesión.
La contraseña del certificado es una cadena vacía,
excepto en MacOS, donde es "password", ya que la biblioteca ssl de la
plataforma se niega a importar certificados sin contraseña.
Exclusivo con --ssl. Por defecto: falso.

--auth [USUARIO[:CONTRASEÑA]]

Datos para autenticación global.
Equivalente a --path-auth con una ruta raíz y las mismas credenciales.
Este argumento está obsoleto y será reemplazado por la versión actual de
--path-auth en la próxima versión que rompa la compatibilidad.
Utiliza --path-auth en nuevos diseños para evitar sorpresas.
Por defecto: Ninguno.

--gen-auth

Genera un conjunto de usuario:contraseña de un solo uso para autenticación global.
Funciona como si se hubiera especificado --auth con las credenciales generadas.
Este argumento está obsoleto y será reemplazado por la versión actual de
--gen-path-auth en la próxima versión que rompa la compatibilidad.
Utiliza --gen-path-auth en nuevos diseños para evitar sorpresas.
Exclusivo con --auth. Por defecto: falso.

--path-auth [RUTA=[USUARIO[:CONTRASEÑA]]]

Datos para autenticación por ruta.
La RUTA especificada requerirá las credenciales especificadas para acceder.
Si las credenciales no se especifican, la ruta tendrá la autenticación
desactivada, incluso si las rutas globales o padre tienen autenticación
especificada.
Estas pueden anidarse arbitrariamente.
RUTA se normaliza con barras, se elimina la barra inicial y final.
Especificar más de una vez la misma RUTA es un error.
Por defecto: vacío.

--gen-path-auth [RUTA]

Genera un conjunto de usuario:contraseña de un solo uso para la autenticación bajo RUTA.
El nombre de usuario consta de 6-12 caracteres alfanuméricos aleatorios,
mientras que la contraseña consta de 10-25 caracteres aleatorios de la
mayoría del conjunto imprimible ASCII.
Funciona como si se hubiera especificado --path-auth con RUTA
y las credenciales generadas.
Exclusivo con --path-auth con la misma RUTA. Por defecto: vacío.

--proxy [NOMBRE-ENCABEZADO:CIDR]

Trata NOMBRE-ENCABEZADO como un encabezado X-Forwarded-For de proxy
cuando la solicitud se origina desde una dirección dentro de la red
especificada por el CIDR.
Si el encabezado está configurado pero la solicitud no está en la red, se
ignora.
Se puede especificar cualquier cantidad de veces. Por defecto: ninguno.

--proxy-redir [NOMBRE-ENCABEZADO:CIDR]

Trata NOMBRE-ENCABEZADO como un encabezado X-Original-URL de proxy cuando
la solicitud se origina desde una dirección dentro de la red especificada
por el CIDR: esto solo se utiliza para encabezados 303 See Other
Location: al redirigir debido a un archivo de índice.
Se puede especificar cualquier cantidad de veces. Por defecto: ninguno.

-m --mime-type [EXTENSIÓN:TIPO-MIME]

Devuelve TIPO-MIME para archivos con EXTENSIÓN.
Si EXTENSIÓN está vacía, devuelve ese TIPO-MIME para archivos sin extensión.
El tipo MIME predeterminado es el devuelto por la crate mime_guess, si existe,
de lo contrario es "application/octet-stream" para archivos binarios o
"text/plain".
Se puede especificar cualquier cantidad de veces. Por defecto: ninguno.

--request-bandwidth [BYTES]

Limita el ancho de banda de cada solicitud a BYTES/segundo.
Se puede sufijar con prefijos binarios [KMGTPE] o prefijos SI [kmgtpe].
Cero deshabilita el límite.
Por defecto: 0.

-H --header [NOMBRE: VALOR]...

Agrega los encabezados especificados a todas las respuestas.
VALOR tiene los espacios en blanco iniciales recortados.

-s --no-follow-symlinks

No seguir enlaces simbólicos al solicitar acceso a archivos.
Si se solicita un enlace simbólico y esta bandera está activada, se tratará
como si no existiera.

-r --sandbox-symlinks

Restringe/aisla los enlaces simbólicos para que apunten solo a los descendientes
directos del directorio alojado.
Si se solicita un archivo fuera de la descendencia directa del directorio
alojado y esta bandera está activada, se tratará como si no existiera.

-w --allow-write

Permite operaciones de escritura.
Operaciones de escritura actualmente soportadas: PUT y DELETE.
Con PUT, los encabezados X-Last-Modified/X-OC-MTime se pueden especificar
en milisegundos/segundos desde la época, y esto se establecerá en el st_mtim
del archivo.
Esto está desactivado por defecto porque es muy probable que no sea algo
que quieras hacer.

-D --convenient-webdav

Permite solicitudes WebDAV MKCOL (crear directorio) y MOVE (renombrar).
Estas son solicitudes de escritura, por lo que no tienen efecto a menos que
se use -w. Desactivado por defecto.

-d --webdav

Maneja solicitudes WebDAV.
Desactivado por defecto. Sobrescribe -D.

-l --no-listings

No generar listados de directorios.
Tabla de comportamiento de --no-listings con --no-indices:
+------------+---------+---------+---------+---------+
|    Ruta    | Ninguno |   -i    |   -l    |  -l -i  |
+============+=========+=========+=========+=========+
| /tiene-idx |  index  | listing |  index  |   404   |
| /sin-idx   | listing | listing |   404   |   404   |
+------------+---------+---------+---------+---------+
Esto está desactivado por defecto porque es muy probable que sea para
fines de depuración.

-i --no-indices

No servir automáticamente el archivo index para directorios que lo contienen.
Esto está desactivado por defecto porque es muy probable que sea para
fines de depuración.

-e --no-encode

No codificar archivos del sistema de archivos.
Los archivos codificados se almacenan en el directorio temporal en lugar de
mantenerse en memoria.
Esto está desactivado por defecto porque es útil para reducir el uso de
ancho de banda.

--encoded-filesystem FS_LIMIT --encoded-generated GEN_LIMIT

Consume como máximo FS_LIMIT espacio para archivos del sistema de archivos
codificados (en TEMP) y como máximo GEN_LIMIT memoria para respuestas
generadas codificadas.
Los argumentos son un entero, opcionalmente seguido de k (kilobyte),
m (megabyte), g (gigabyte), t (terabyte) o p (petabyte) en mayúsculas
o minúsculas.
, opcionalmente seguido de b (no distingue mayúsculas de minúsculas). Esta cuota puede excederse temporalmente mientras se atiende una solicitud.

--encoded-prune

MAX_AGE 
Elimina datos codificados en caché con una antigüedad superior a MAX_AGE.
El argumento se da en segundos, opcionalmente seguido de s (segundos), m (minutos), h (horas) o d (días) (no distingue mayúsculas de
minúsculas)
.

-x --strip-extension

s 
Permite eliminar las extensiones de índice de las
rutas servidas: una solicitud a /file podría ser
servida por /file.[s]htm[l]. Por defecto es falso.

--404

FALLBACK-FILE 
Al devolver una respuesta 404 a un GET,
envía FALLBACK-FILE, en lugar
de una página de error generada, como cuerpo. FALLBACK-FILE es una ru
ta del sistema de archivos y no está sujeta a las restricciones -s/-r.

-q --quiet..

. 
Suprime cantidades crecientes de salida.
Especificar esta bandera N veces hará que:
  N == 0 – muestre toda
la salida N >= 1 – suprima las líneas de estado de servicio ("se sirvió algo a la IP") N >= 2 – supri
ma el inicio excepto los datos de autenticación, si los hay N >= 3 – suprima todos los mensajes de inicio

-Q

--quiet-time 
No antepone la marc
a de tiempo a las
líneas de registro.

-c

--no-colour 
No colorea
la salida d
e registro.

NOTA

S

Al devolver archivos desde el sistema de archivos, el ETag devuelto se basa en el sistema de archivos, el i-nodo y la hora de modificación

precisa.

Naturalmente, esto significa que al servir archivos desde sistemas de archivos con marcas de tiempo gruesas (como FAT con su resolución de 1s), los cambios pueden quedar ocultos para los agentes de usuario que usan ETag (si un archivo fue modificado a las 2023-02-12T01:00:00.100000000, un AU solicitó y almacenó en caché una respuesta para 2023-02-12T01:00:00.000000000, luego el archivo fue modificado de nuevo a las 2023-02-12T01:00:00.900000000, las solicitudes posteriores con If-None-Match: 2023-02-12T01:00:00.000000000 devolverán todas 304 Not Modified)

.

Esto no es realmente un gran problema, no uses FAT como un Sistema de Archivos de Alto Rendimiento (o recarga sin caché), y If-Modified-Since se ve afectado por est

o por diseño, en to
dos los back-ends.
