hg-identify(1)

Paquete: mercurial

Licencias: GPL

HG(IDENTIFY) HG(IDENTIFY)

NOMBRE

hg identify - identificar el directorio de trabajo o la revisión especificada

SINOPSIS

hg identify [-nibtB] [-r REV] [SOURCE]

DESCRIPCIÓN

Imprime un resumen que identifica el estado del repositorio en REV utilizando uno o dos identificadores de ancestro, seguido de un "+" si el directorio de trabajo tiene cambios no confirmados, el nombre de la rama (si no es la predeterminada), una lista de etiquetas y una lista de marcadores.

Cuando no se da REV, imprime un resumen del estado actual del repositorio, incluido el directorio de trabajo. Especificar -r. para obtener información del padre del directorio de trabajo sin escanear cambios no confirmados.

Especificar una ruta a la raíz del repositorio o a un paquete de Mercurial hará que la búsqueda opere en ese repositorio/paquete.

Plantilla:

Las siguientes palabras clave son compatibles además de las palabras clave y funciones comunes de plantillas. Ver también hg help templates.

sucio
Cadena. Carácter + que indica si el directorio de trabajo tiene cambios no confirmados.
id
Cadena. Uno o dos nodos, opcionalmente seguidos de +.
padres
Lista de cadenas. Nodos padres del cambio.

Ejemplos:

  • generar un identificador de compilación para el directorio de trabajo: 
    hg id --id > build-id.dat
  • encontrar la revisión correspondiente a una etiqueta: 
    hg id -n -r 1.3
  • comprobar la revisión más reciente de un repositorio remoto: 
    hg id -r tip https://www.mercurial-scm.org/repo/hg/

    Ver hg log para generar más información sobre revisiones específicas, incluidos los identificadores de hash completos.

    Retorna 0 si tiene éxito.

OPCIONES

-r,--rev <REV>
identificar la revisión especificada
-n, --num
mostrar el número de revisión local
-i, --id
mostrar el id de revisión global
-b, --branch
mostrar la rama
-t, --tags
mostrar etiquetas
-B, --bookmarks
mostrar marcadores
-e,--ssh <CMD>
especificar el comando ssh a usar
--remotecmd <CMD>
especificar el comando hg a ejecutar en el lado remoto
--insecure
no verificar el certificado del servidor (ignorando la configuración web.cacerts)
-T,--template <TEMPLATE>
mostrar con plantilla
