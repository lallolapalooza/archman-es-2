NAME

hashkit_set_distribution_function, hashkit_get_distribution_function - establecer y obtener la función hash de distribución de claves

SYNOPSIS

hashkit_return_t hashkit_set_distribution_function(const hashkit_st *hash, hashkit_hash_algorithm_t function)
hashkit_return_t hashkit_set_custom_distribution_function(const hashkit_st *hash, hashkit_hash_fn function, void *context)
Parameters
hash -- puntero a una estructura hashkit_st inicializada
function -- algoritmo de hash a usar como función hash de distribución
context -- puntero a un contexto opaco gestionado por el usuario para la función hash de distribución personalizada
hashkit_hash_algorithm_t hashkit_get_distribution_function(const hashkit_st *hash)
Parameters
hash -- puntero a una estructura hashkit_st inicializada
Returns
hashkit_hash_algorithm_t indicando el algoritmo hash de distribución actualmente establecido a usar

Estas funciones son utilizadas para establecer y obtener la función hash de distribución de claves.

DESCRIPTION

hashkit_set_distribution_function establece la función hash de distribución para la estructura hashkit_st. El argumento function debe ser uno de los algoritmos hash definidos en hashkit_hash_algorithm_t. Si se establece en HASHKIT_HASH_CUSTOM, entonces se debe llamar a hashkit_set_custom_distribution_function para proporcionar la función hash personalizada y su contexto.

hashkit_set_custom_distribution_function establece una función hash de distribución personalizada y un puntero a un contexto opaco que puede ser utilizado por la función hash personalizada.

hashkit_get_distribution_function devuelve el algoritmo hash de distribución actualmente configurado para la estructura hashkit_st.

RETURN VALUE

hashkit_set_distribution_function() y hashkit_set_custom_distribution_function() devuelven hashkit_return_t::HASHKIT_SUCCESS en caso de éxito.

hashkit_get_distribution_function() devuelve hashkit_hash_algorithm_t indicando la función hash de distribución utilizada.
