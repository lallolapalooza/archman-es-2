DESCRIPCIÓN DETALLADA

La mayoría de las funciones de la API de hwloc devuelven un valor entero. A menos que se documente lo contrario, devuelven 0 en caso de éxito y -1 en caso de error. Las funciones que devuelven un tipo de puntero devuelven NULL en caso de error.

errno se establecerá en un valor significativo siempre que sea posible. Esto incluye el usual EINVAL cuando se pasan parámetros de función inválidos o ENOMEM cuando falla una asignación interna. También se utilizan algunos valores específicos de errno, por ejemplo, para errores de vinculación como se documenta en Vinculación de CPU.

Algunos módulos describen los valores de retorno de sus funciones en su introducción, por ejemplo, en La API de bitmap.
