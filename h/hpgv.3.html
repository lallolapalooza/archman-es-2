subrutina chpgv (integer itype, character jobz, character uplo, integer n, complex, dimension( * ) ap, complex, dimension( * ) bp, real, dimension( * ) w, complex, dimension( ldz, * ) z, integer ldz, complex, dimension( * ) work, real, dimension( * ) rwork, integer

info)

CHPG

V

Propósito

: 
!>
!> CHPGV calcula todos los eigenvalores y, opcionalmente, los autovectores
!> de un problema de autovalores generalizado hermitiano-definido, de la forma
!> A*x=(lambda)*B*x,  A*Bx=(lambda)*x,  o B*A*x=(lambda)*x.
!> Aquí se asume que A y B son hermitianas, almacenadas en formato empaquetado,
!> y que B es también definida positiva.
!
>

Parámetro

s
ITYPE 
!>          ITYPE es INTEGER
!>          Especifica el tipo de problema a resolver:
!>          = 1:  A*x = (lambda)*B*x
!>          = 2:  A*B*x = (lambda)*x
!>          = 3:  B*A*x = (lambda)*x
!
>

JOB

Z 
!>          JOBZ es CHARACTER*1
!>          = 'N':  Calcular solo los eigenvalores;
!>          = 'V':  Calcular los eigenvalores y los autovectores.
!
>

UPL

O 
!>          UPLO es CHARACTER*1
!>          = 'U':  Se almacenan los triángulos superiores de A y B;
!>          = 'L':  Se almacenan los triángulos inferiores de A y B.
!
>

N 
!>          N es INTEGER
!>          El orden de las matrices A y B.  N >= 0.
!
>

A

P 
!>          AP es un arreglo COMPLEX, dimensión (N*(N+1)/2)
!>          A la entrada, el triángulo superior o inferior de la matriz hermitiana
!>          A, empaquetado por columnas en un arreglo lineal.  La j-ésima columna de A
!>          se almacena en el arreglo AP de la siguiente manera:
!>          si UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) para 1<=i<=j;
!>          si UPLO = 'L', AP(i + (j-1)*(2*n-j)/2) = A(i,j) para j<=i<=n.
!>
!>          A la salida, el contenido de AP se destruye.
!
>

B

P 
!>          BP es un arreglo COMPLEX, dimensión (N*(N+1)/2)
!>          A la entrada, el triángulo superior o inferior de la matriz hermitiana
!>          B, empaquetado por columnas en un arreglo lineal.  La j-ésima columna de B
!>          se almacena en el arreglo BP de la siguiente manera:
!>          si UPLO = 'U', BP(i + (j-1)*j/2) = B(i,j) para 1<=i<=j;
!>          si UPLO = 'L', BP(i + (j-1)*(2*n-j)/2) = B(i,j) para j<=i<=n.
!>
!>          A la salida, el factor triangular U o L de la factorización de Cholesky
!>          B = U**H*U o B = L*L**H, en el mismo formato de almacenamiento
!>          que B.
!
>

W 
!>          W es un arreglo REAL, dimensión (N)
!>          Si INFO = 0, los eigenvalores en orden ascendente.
!
>

Z 
!>          Z es un arreglo COMPLEX, dimensión (LDZ, N)
!>          Si JOBZ = 'V', entonces si INFO = 0, Z contiene la matriz Z de
!>          autovectores.  Los autovectores se normalizan de la siguiente manera:
!>          si ITYPE = 1 o 2, Z**H*B*Z = I;
!>          si ITYPE = 3, Z**H*inv(B)*Z = I.
!>          Si JOBZ = 'N', entonces Z no se referencia.
!
>

LD

Z 
!>          LDZ es INTEGER
!>          La dimensión principal del arreglo Z.  LDZ >= 1, y si
!>          JOBZ = 'V', LDZ >= max(1,N).
!
>

WOR

K 
!>          WORK es un arreglo COMPLEX, dimensión (max(1, 2*N-1))
!
>

RWOR

K 
!>          RWORK es un arreglo REAL, dimensión (max(1, 3*N-2))
!
>

INF

O 
!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>          > 0:  CPPTRF o CHPEV devolvió un código de error:
!>             <= N:  si INFO = i, CHPEV falló en converger;
!>                    i elementos fuera de la diagonal de una forma
!>                    tridiagonal intermedia no convergieron a cero;
!>             > N:   si INFO = N + i, para 1 <= i <= n, entonces el menor
!>                    principal principal de orden i de B no es positivo.
!>                    La factorización de B no pudo completarse y
!>                    no se calcularon eigenvalores ni autovectores.
!
>

SUBROUTINE DPPGV( ITYPE, JOBZ, UPLO, N, AP, BP, W, Z, LDZ, WORK, INFO )



DPPGV


Purpose:




!>
!> DPPGV computes all the eigenvalues and, optionally, the eigenvectors
!> of a real generalized symmetric-definite eigenproblem, of the form
!> A*x=(lambda)*B*x,  A*Bx=(lambda)*x,  or B*A*x=(lambda)*x.
!> Here A and B are assumed to be symmetric, stored in packed format,
!> and B is also positive definite.
!> 




Parameters


ITYPE

!>          ITYPE is INTEGER
!>          Specifies the problem type to be solved:
!>          = 1:  A*x = (lambda)*B*x
!>          = 2:  A*B*x = (lambda)*x
!>          = 3:  B*A*x = (lambda)*x
!> 


JOBZ


!>          JOBZ is CHARACTER*1
!>          = 'N':  Compute eigenvalues only;
!>          = 'V':  Compute eigenvalues and eigenvectors.
!> 


UPLO


!>          UPLO is CHARACTER*1
!>          = 'U':  Upper triangles of A and B are stored;
!>          = 'L':  Lower triangles of A and B are stored.
!> 


N


!>          N is INTEGER
!>          The order of the matrices A and B.  N >= 0.
!> 


AP


!>          AP is DOUBLE PRECISION array, dimension (N*(N+1)/2)
!>          On entry, the upper or lower triangle of the symmetric matrix
!>          A, packed columnwise in a linear array.  The j-th column of A
!>          is stored in the array AP as follows:
!>          if UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) for 1<=i<=j;
!>          if UPLO = 'L', AP(i + (j-1)*(2*n-j)/2) = A(i,j) for j<=i<=n.
!>
!>          On exit, the contents of AP are destroyed.
!> 


BP


!>          BP is DOUBLE PRECISION array, dimension (N*(N+1)/2)
!>          On entry, the upper or lower triangle of the symmetric matrix
!>          B, packed columnwise in a linear array.  The j-th column of B
!>          is stored in the array BP as follows:
!>          if UPLO = 'U', BP(i + (j-1)*j/2) = B(i,j) for 1<=i<=j;
!>          if UPLO = 'L', BP(i + (j-1)*(2*n-j)/2) = B(i,j) for j<=i<=n.
!>
!>          On exit, the triangular factor U or L from the Cholesky
!>          factorization B = U**T*U or B = L*L**T, in the same storage
!>          format as B.
!> 


W


!>          W is DOUBLE PRECISION array, dimension (N)
!>          If INFO = 0, the eigenvalues in ascending order.
!> 


Z


!>          Z is DOUBLE PRECISION array, dimension (LDZ, N)
!>          If JOBZ = 'V', then if INFO = 0, Z contains the matrix Z of
!>          eigenvectors.  The eigenvectors are normalized as follows:
!>          if ITYPE = 1 or 2, Z**T*B*Z = I;
!>          if ITYPE = 3, Z**T*inv(B)*Z = I.
!>          If JOBZ = 'N', then Z is not referenced.
!> 


LDZ


!>          LDZ is INTEGER
!>          The leading dimension of the array Z.  LDZ >= 1, and if
!>          JOBZ = 'V', LDZ >= max(1,N).
!> 


WORK


!>          WORK is DOUBLE PRECISION array, dimension (3*N)
!> 


INFO


!>          INFO is INTEGER
!>          = 0:  successful exit
!>          < 0:  if INFO = -i, the i-th argument had an illegal value
!>          > 0:  DPPTRF or DSPEV returned an error code:
!>             <= N:  if INFO = i, DSPEV failed to converge;
!>                    i off-diagonal elements of an intermediate
!>                    tridiagonal form did not converge to zero.
!>             > N:   if INFO = n + i, for 1 <= i <= n, then the leading
!>                    principal minor of order i of B is not positive.
!>                    The factorization of B could not be completed and
!>                    no eigenvalues or eigenvectors were computed.
!>
