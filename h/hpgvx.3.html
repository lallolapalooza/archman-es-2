CHPGV

Propósito

: 
!>
!> CHPGVX calcula autovalores seleccionados y, opcionalmente, autovectores
!> de un problema de autovalores generalizado hermitiano-definido, de la forma
!> A*x=(lambda)*B*x,  A*Bx=(lambda)*x,  o B*A*x=(lambda)*x.  Aquí se asume que A y
!> B son hermitianas, almacenadas en formato empaquetado, y que B es también
!> definida positiva.  Los autovalores y autovectores pueden ser seleccionados
!> especificando ya sea un rango de valores o un rango de índices para los
!> autovalores deseados.
!
>

Parámetro

s
ITYPE 
!>          ITYPE es INTEGER
!>          Especifica el tipo de problema a resolver:
!>          = 1:  A*x = (lambda)*B*x
!>          = 2:  A*B*x = (lambda)*x
!>          = 3:  B*A*x = (lambda)*x
!
>

JOB

Z 
!>          JOBZ es CHARACTER*1
!>          = 'N':  Calcular solo autovalores;
!>          = 'V':  Calcular autovalores y autovectores.
!
>

RANG

E 
!>          RANGE es CHARACTER*1
!>          = 'A': se encontrarán todos los autovalores;
!>          = 'V': se encontrarán todos los autovalores en el intervalo semiabierto (VL,VU];
!>          = 'I': se encontrarán los autovalores desde el IL-ésimo hasta el IU-ésimo.
!
>

UPL

O 
!>          UPLO es CHARACTER*1
!>          = 'U':  Se almacenan los triángulos superiores de A y B;
!>          = 'L':  Se almacenan los triángulos inferiores de A y B.
!
>

N 
!>          N es INTEGER
!>          El orden de las matrices A y B.  N >= 0.
!
>

A

P 
!>          AP es un array COMPLEX, dimensión (N*(N+1)/2)
!>          En la entrada, el triángulo superior o inferior de la matriz hermitiana
!>          A, empaquetado por columnas en un array lineal.  La j-ésima columna de A
!>          se almacena en el array AP de la siguiente manera:
!>          si UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) para 1<=i<=j;
!>          si UPLO = 'L', AP(i + (j-1)*(2*n-j)/2) = A(i,j) para j<=i<=n.
!>
!>          En la salida, el contenido de AP se destruye.
!
>

B

P 
!>          BP es un array COMPLEX, dimensión (N*(N+1)/2)
!>          En la entrada, el triángulo superior o inferior de la matriz hermitiana
!>          B, empaquetado por columnas en un array lineal.  La j-ésima columna de B
!>          se almacena en el array BP de la siguiente manera:
!>          si UPLO = 'U', BP(i + (j-1)*j/2) = B(i,j) para 1<=i<=j;
!>          si UPLO = 'L', BP(i + (j-1)*(2*n-j)/2) = B(i,j) para j<=i<=n.
!>
!>          En la salida, el factor triangular U o L de la factorización de Cholesky
!>          B = U**H*U o B = L*L**H, en el mismo formato de almacenamiento que B.
!
>

V

L 
!>          VL es REAL
!>
!>          Si RANGE='V', el límite inferior del intervalo en el que
!>          se buscarán los autovalores.  VL < VU.
!>          No se referencia si RANGE = 'A' o 'I'.
!
>

V

U 
!>          VU es REAL
!>
!>          Si RANGE='V', el límite superior del intervalo en el que
!>          se buscarán los autovalores.  VL < VU.
!>          No se referencia si RANGE = 'A' o 'I'.
!
>

I

L 
!>          IL es INTEGER
!>
!>          Si RANGE='I', el índice del
!>          autovalor más pequeño a devolver.
!>          1 <= IL <= IU <= N, si N > 0; IL = 1 e IU = 0 si N = 0.
!>          No se referencia si RANGE = 'A' o 'V'.
!
>

I

U 
!>          IU es INTEGER
!>
!>          Si RANGE='I', el índice del
!>          autovalor más grande a devolver.
!>          1 <= IL <= IU <= N, si N > 0; IL = 1 e IU = 0 si N = 0.
!>          No se referencia si RANGE = 'A' o 'V'.
!
>

ABSTO

L 
!>          ABSTOL es REAL
!>          La tolerancia de error absoluto para los autovalores.
!>          Un autovalor aproximado se acepta como convergido
!>          cuando se determina que yace en un intervalo [a,b]
!>          de ancho menor o igual a
!>
!>                  ABSTOL + EPS *   max( |a|,|b| ) ,
!>
!>          donde EPS es la precisión de la máquina.  Si ABSTOL es menor o
!>          igual a cero, entonces se usará  EPS*|T|  en su lugar,
!>          donde |T| es la norma 1 de la matriz tridiagonal obtenida
!>          al reducir AP a forma tridiagonal.
!>
!>          Los autovalores se calcularán con mayor precisión cuando ABSTOL se
!>          establezca al doble del umbral de desbordamiento inferior 2*SLAMCH('S'), no a cero.
!>          Si esta rutina retorna con INFO>0, indicando que algunos
!>          autovectores no convergieron, intente establecer ABSTOL a
!>          2*SLAMCH('S').
!
>

M 
!>          M es INTEGER
!>          El número total de autovalores encontrados.  0 <= M <= N.
!>          Si RANGE = 'A', M = N, y si RANGE = 'I', M = IU-IL+1.
!
>

W 
!>          W es un array REAL, dimensión (N)
!>          En la salida normal, los primeros M elementos contienen los autovalores
!>          seleccionados en orden ascendente.
!
>

Z 
!>          Z es un array COMPLEX, dimensión (LDZ, N)
!>          Si JOBZ = 'N', entonces Z no se referencia.
!>          Si JOBZ = 'V', entonces si INFO = 0, las primeras M columnas de Z
!>          contienen los autovectores ortonormales de la matriz A
!>          correspondientes a los autovalores seleccionados, con la i-ésima
!>          columna de Z conteniendo el autovector asociado con W(i).
!>          Los autovectores se normalizan de la siguiente manera:
!>          si ITYPE = 1 o 2, Z**H*B*Z = I;
!>          si ITYPE = 3, Z**H*inv(B)*Z = I.
!>
!>          Si un autovector no converge, entonces esa columna de Z
!>          contiene la última aproximación al autovector, y el
!>          índice del autovector se devuelve en IFAIL.
!>          Nota: el usuario debe asegurarse de que se proporcionen al menos max(1,M) columnas
!>          en el array Z; si RANGE = 'V', el valor exacto de M
!>          no se conoce de antemano y se debe usar una cota superior.
!
>

LD

Z 
!>          LDZ es INTEGER
!>          La dimensión principal del array Z.  LDZ >= 1, y si
!>          JOBZ = 'V', LDZ >= max(1,N).
!
>

WOR

K 
!>          WORK es un array COMPLEX, dimensión (2*N)
!
>

RWOR

K 
!>          RWORK es un array REAL, dimensión (7*N)
!
>

IWOR

K 
!>          IWORK es un array INTEGER, dimensión (5*N)
!
>

IFAI

L 
!>          IFAIL es un array INTEGER, dimensión (N)
!>          Si JOBZ = 'V', entonces si INFO = 0, los primeros M elementos de
!>          IFAIL son cero. Si INFO > 0, entonces IFAIL contiene los
!>          índices de los autovectores que no lograron converger.
!>          Si JOBZ = 'N', entonces IFAIL no se referencia.
!>

INFO

!>          INFO es un ENTERO
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tuvo un valor ilegal
!>          > 0:  CPPTRF o CHPEVX devolvieron un código de error:
!>             <= N:  si INFO = i, CHPEVX no logró converger;
!>                    i autovectores no lograron converger. Sus índices
!>                    se almacenan en el array IFAIL.
!>             > N:   si INFO = N + i, para 1 <= i <= n, entonces el menor
!>                    principal líder de orden i de B no es positivo.
!>                    La factorización de B no pudo completarse y
!>                    no se calcularon autovalores ni autovectores.
!>
