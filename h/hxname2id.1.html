HXNAME2ID(1) Utilidades HTML-XML HXNAME2ID(1)

NOMBRE

hxname2id - mueve algunos atributos NAME e ID de un A a su padre

SINOPSIS

hxname2id [ -x ] [ archivo ]

DESCRIPCIÓN

El comando hxname2id lee un archivo HTML y busca elementos que tengan un elemento A como primer hijo, sin texto intermedio más que espacios en blanco. Si ese elemento A tiene un atributo ID o NAME, se mueve al elemento padre y se elimina del A.

Dado que Netscape 4 no entiende los atributos ID, era una práctica común escribir <H2><A NAME="sect7">...</A></H2> en lugar de <H2 ID="sect7">. Este programa se puede usar para convertir archivos HTML antiguos a la nueva convención.

Otros programas de este conjunto, como hxmultitoc(1), requieren IDs en los encabezados en lugar de elementos A con atributos NAME. Por lo tanto, es útil ejecutar hxname2id antes de ejecutar hxmultitoc y programas similares. hxname2id se puede usar en una tubería (pipe).

OPCIONES

Se admiten las siguientes opciones:

-x
Utiliza convenciones XML: los elementos vacíos se escriben con una barra al final: <IMG />

OPERANDOS

Se admite el siguiente operando:

archivo
El nombre de un archivo HTML. Si está ausente, se lee la entrada estándar.

DIAGNÓSTICOS

Los siguientes valores de salida se devuelven:

0
Finalización exitosa.
> 0
Se produjo un error en el análisis del archivo HTML. hxname2id intentará corregir el error y producirá una salida de todos modos.

VER TAMBIÉN

asc2xml(1), hxmultitoc(1), hxnormalize(1), hxnum(1), hxtoc(1), xml2asc(1)

ERRORES

La recuperación de errores para HTML incorrecto es primitiva.
