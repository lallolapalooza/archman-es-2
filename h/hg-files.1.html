hg-files(1)

Paquete: mercurial

Licencias: GPL

HG(ARCHIVOS) HG(ARCHIVOS)

NOMBRE

hg files - lista archivos rastreados

SINOPSIS

hg files [OPCIÓN]... [ARCHIVO]...

DESCRIPCIÓN

Imprime los archivos bajo control de Mercurial en el directorio de trabajo o la revisión especificada para los archivos dados (excluyendo archivos eliminados). Los archivos se pueden especificar como nombres de archivo o conjuntos de archivos.

Si no se proporcionan archivos para que coincidan, este comando imprime los nombres de todos los archivos bajo control de Mercurial.

Plantilla:

Las siguientes palabras clave son compatibles además de las palabras clave y funciones comunes de plantilla. Ver también hg help templates.

flags
Cadena. Carácter que denota los bits de enlace simbólico y ejecutable del archivo.
path
Cadena. Ruta absoluta en el repositorio del archivo.
size
Entero. Tamaño del archivo en bytes.

Ejemplos:

  • lista todos los archivos bajo el directorio actual: 
    hg files .
  • muestra tamaños y flags para la revisión actual: 
    hg files -vr .
  • lista todos los archivos llamados README: 
    hg files -I "**/README"
  • lista todos los archivos binarios: 
    hg files "set:binary()"
  • encuentra archivos que contienen una expresión regular: 
    hg files "set:grep('bob')"
  • busca el contenido de archivos rastreados con xargs y grep: 
    hg files -0 | xargs -0 grep foo

    Ver hg help patterns y hg help filesets para más información sobre cómo especificar patrones de archivos.

    Devuelve 0 si se encuentra una coincidencia, 1 de lo contrario.

OPCIONES

-r,--rev <REV>
busca en el repositorio como está en REV
-0, --print0
termina los nombres de archivo con NUL, para usar con xargs
-I,--include <PATRÓN[+]>
incluye nombres que coincidan con los patrones dados
-X,--exclude <PATRÓN[+]>
excluye nombres que coincidan con los patrones dados
-T,--template <PLANTILLA>
muestra con plantilla
-S, --subrepos
recorre subrepositorios

[+] la opción marcada se puede especificar varias veces
