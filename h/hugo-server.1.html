NOMBRE

hugo-server - Inicia el servidor web embebido

SINOPSIS

hugo server [comando] [flags]

DESCRIPCIÓN

Hugo proporciona su propio servidor web que compila y sirve el sitio. Aunque hugo server tiene un alto rendimiento, es un servidor web con opciones limitadas.

Por defecto, hugo server escribirá y servirá archivos desde el disco, pero puedes renderizar a memoria usando la bandera --renderToMemory. Esto puede ser más rápido en algunos casos, pero consumirá más memoria.

Por defecto, hugo también vigilará tus archivos en busca de cualquier cambio que realices y reconstruirá el sitio automáticamente. Luego, recargará en vivo cualquier página de navegador abierta y les enviará el contenido más reciente. Dado que la mayoría de los sitios Hugo se compilan en una fracción de segundo, podrás guardar y ver tus cambios casi instantáneamente.

OPCIONES

--appendPort[=true] añade el puerto a baseURL

-b, --baseURL="" nombre del host (y ruta) a la raíz, p. ej., https://spf13.com/

--bind="127.0.0.1" interfaz a la que se conectará el servidor

-D, --buildDrafts[=false] incluye contenido marcado como borrador

-E, --buildExpired[=false] incluye contenido expirado

-F, --buildFuture[=false] incluye contenido con fecha de publicación en el futuro

--cacheDir="" ruta del sistema de archivos al directorio de caché

--cleanDestinationDir[=false] elimina archivos del destino que no se encuentren en directorios estáticos

-c, --contentDir="" ruta del sistema de archivos al directorio de contenido

--disableBrowserError[=false] no muestra errores de compilación en el navegador

--disableFastRender[=false] habilita la recompilación completa ante cambios

--disableKinds=[] deshabilita diferentes tipos de páginas (inicio, RSS, etc.)

--disableLiveReload[=false] vigila sin habilitar la recarga del navegador en vivo tras la recompilación

--enableGitInfo[=false] añade información de revisión de Git, fecha, autor y CODEOWNERS a las páginas

--forceSyncStatic[=false] copia todos los archivos cuando los archivos estáticos cambian.

--gc[=false] habilita la ejecución de algunas tareas de limpieza (elimina archivos de caché no utilizados) después de la compilación

-h, --help[=false] ayuda para server

--ignoreCache[=false] ignora el directorio de caché

-l, --layoutDir="" ruta del sistema de archivos al directorio de layouts

--liveReloadPort=-1 puerto para la recarga en vivo (p. ej., 443 en situaciones de proxy HTTPS)

--minify[=false] minimiza cualquier formato de salida soportado (HTML, XML, etc.)

-N, --navigateToChanged[=false] navega al archivo de contenido cambiado en la recarga del navegador en vivo

--noChmod[=false] no sincroniza el modo de permisos de los archivos

--noHTTPCache[=false] evita el caché HTTP

--noTimes[=false] no sincroniza la hora de modificación de los archivos

-O, --openBrowser[=false] abre el sitio en un navegador después de iniciar el servidor

--panicOnWarning[=false] entra en pánico ante el primer mensaje de advertencia (WARNING)

--poll="" establece un intervalo de sondeo, p. ej. --poll 700ms, para usar un enfoque basado en sondeo para vigilar cambios en el sistema de archivos

-p, --port=1313 puerto en el que escuchará el servidor

--pprof[=false] habilita el servidor pprof (puerto 8080)

--printI18nWarnings[=false] muestra traducciones faltantes

--printMemoryUsage[=false] muestra el uso de memoria en la pantalla a intervalos

--printPathWarnings[=false] muestra advertencias sobre rutas de destino duplicadas, etc.

--printUnusedTemplates[=false] muestra advertencias sobre plantillas no utilizadas.

--renderSegments=[] segmentos con nombre para renderizar (configurados en la configuración de segmentos)

--renderStaticToDisk[=false] sirve archivos estáticos desde el disco y archivos dinámicos desde la memoria

--templateMetrics[=false] muestra métricas sobre la ejecución de plantillas

--templateMetricsHints[=false] calcula algunas sugerencias de mejora cuando se combina con --templateMetrics

-t, --theme=[] temas a usar (ubicados en /themes/NOMBRE_TEMA/)

--tlsAuto[=false] genera y utiliza certificados confiables localmente.

--tlsCertFile="" ruta al archivo del certificado TLS

--tlsKeyFile="" ruta al archivo de la clave TLS

--trace="" escribe el rastreo en un archivo (no útil en general)

-w, --watch[=true] vigila el sistema de archivos en busca de cambios y recrea según sea necesario

OPCIONES HEREDADAS DE COMANDOS PADRE

--clock="" establece el reloj utilizado por Hugo, p. ej., --clock 2021-11-06T22:30:00.00+09:00

--config="" archivo de configuración (por defecto es hugo.yaml|json|toml)

--configDir="config" directorio de configuración

-d, --destination="" ruta del sistema de archivos para escribir archivos

-e, --environment="" entorno de compilación

--ignoreVendorPaths="" ignora cualquier _vendor para rutas de módulos que coincidan con el patrón Glob dado

--logLevel="" nivel de registro (debug|info|warn|error)

--noBuildLock[=false] no crea el archivo .hugo_build.lock

--quiet[=false] compila en modo silencioso

-M, --renderToMemory[=false] renderiza a memoria (principalmente útil al ejecutar el servidor)

-s, --source="" ruta del sistema de archivos para leer archivos relativos desde

--themesDir="" ruta del sistema de archivos al directorio de temas
