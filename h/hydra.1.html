HYDRA(1) Manual de comandos generales HYDRA(1)

NOMBRE

hydra - un cracker de inicio de sesión de red muy rápido que soporta muchos servicios diferentes

SINOPSIS

hydra
[[[-l LOGIN|-L ARCHIVO] [-p CONTRASEÑA|-P ARCHIVO|-x OPC -y]] | [-C ARCHIVO]]
[-e nsr] [-u] [-f|-F] [-M ARCHIVO] [-o ARCHIVO] [-b FORMATO]
[-t TAREAS] [-T TAREAS] [-w TIEMPO] [-W TIEMPO] [-m OPCIONES] [-s PUERTO]
[-c TIEMPO] [-S] [-O] [-4|6] [-I] [-vV] [-d]
servidor servicio [OPCIONES]

DESCRIPCIÓN

Hydra es un cracker de inicio de sesión paralelizado que soporta numerosos protocolos para atacar. Es fácil añadir nuevos módulos, además, es flexible y muy rápido.

Esta herramienta da a los investigadores y consultores de seguridad la posibilidad de mostrar lo fácil que sería obtener acceso no autorizado remotamente a un sistema.

Actualmente esta herramienta soporta:
adam6500 afp asterisk cisco cisco-enable cvs firebird ftp ftps http[s]-{head|get|post} http[s]-{get|post}-form http-proxy http-proxy-urlenum icq imap[s] irc ldap2[s] ldap3[-{cram|digest}md5][s] mssql mysql(v4) mysql5 ncp nntp oracle oracle-listener oracle-sid pcanywhere pcnfs pop3[s] postgres rdp radmin2 redis rexec rlogin rpcap rsh rtsp s7-300 sapr3 sip smb smtp[s] smtp-enum snmp socks5 ssh sshkey svn teamspeak telnet[s] vmauthd vnc xmpp

Para la mayoría de los protocolos se soporta SSL (ej. https-get, ftp-ssl, etc.). Si no se encuentran todas las bibliotecas necesarias durante la compilación, los servicios disponibles serán menores. Escriba "hydra" para ver lo que está disponible.

Opciones

objetivo
un objetivo a atacar, puede ser una dirección IPv4, dirección IPv6 o nombre DNS.
servicio
un servicio a atacar, ver la lista de protocolos disponibles
PARÁMETRO DE SERVICIO OPCIONAL
Algunos módulos tienen opciones opcionales u obligatorias. escriba "hydra -U
<nombre_servicio>"
para obtener ayuda sobre las opciones de un servicio.
-R
restaura una sesión previamente abortada. Requiere que se haya escrito un archivo hydra.restore. Las opciones se restauran, pero pueden ser modificadas estableciéndolas después de -R en la línea de comandos
-S
conectar vía SSL
-O
usar SSL v2 y v3 antiguo
-s PUERTO
si el servicio está en un puerto predeterminado diferente, definirlo aquí
-l LOGIN
o -L ARCHIVO iniciar sesión con el nombre LOGIN, o cargar varios inicios de sesión desde ARCHIVO
-p CONTRASEÑA
o -P ARCHIVO intentar la contraseña CONTRASEÑA, o cargar varias contraseñas desde ARCHIVO
-x min:max:conjunto_caracteres
generar contraseñas desde longitud min a max. conjunto_caracteres puede contener 1
para números, a para caracteres en minúsculas y A para mayúsculas.
Cualquier otro carácter añadido se pone en la lista.
Ejemplo: 1:2:a1%.
Las contraseñas generadas tendrán longitud de 1 a 2 y contendrán
letras minúsculas, números y/o signos de porcentaje y puntos.
-y
deshabilitar el uso de símbolos en el ataque por fuerza bruta -x, ver arriba
-e nsr
comprobaciones adicionales, "n" para contraseña nula, "s" intentar el inicio de sesión como contraseña, "r" intentar el inicio de sesión inverso como contraseña
-C ARCHIVO
formato separado por dos puntos "login:contraseña", en lugar de las opciones -L/-P
-u
por defecto Hydra comprueba todas las contraseñas para un inicio de sesión y luego prueba el siguiente inicio de sesión. Esta opción recorre las contraseñas, de modo que la primera contraseña se prueba en todos los inicios de sesión, luego la siguiente contraseña.
-f
salir después de la primera pareja login/contraseña encontrada (por host si es -M)
-F
salir después de la primera pareja login/contraseña encontrada para cualquier host (para usar con -M)
-M ARCHIVO
lista de servidores para ataques paralelos, una entrada por línea
-o ARCHIVO
escribir las parejas login/contraseña encontradas en ARCHIVO en lugar de stdout
-b FORMATO
especificar el formato para el ARCHIVO -o: text(predeterminado), json, jsonv1
-t TAREAS
ejecutar TAREAS conexiones en paralelo (predeterminado: 16)
-m OPCIONES
opciones específicas del módulo. Ver hydra -U <módulo> qué opciones están disponibles.
-w TIEMPO
define el tiempo máximo de espera en segundos para las respuestas (predeterminado: 32)
-W TIEMPO
define un tiempo de espera entre cada conexión que realiza una tarea. Esto solo tiene sentido si se utiliza un número bajo de tareas, ej. -t 1
-c TIEMPO
el tiempo de espera en segundos por intento de inicio de sesión en todos los hilos (-t 1 es recomendado) Esto solo tiene sentido si se utiliza un número bajo de tareas, ej. -t 1
-4 / -6
pref erir direcciones IPv4 (predeterminado) o IPv6
-v / -V
modo detallado / mostrar la combinación de inicio de sesión+contraseña para cada intento
-d
modo de depuración
-I
ignorar un archivo de restauración existente (no esperar 10 segundos)
-h, --help
Mostrar resumen de opciones.
