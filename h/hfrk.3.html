subrutina chfrk (character transr, character uplo, character trans, integer n, integer k, real alpha, complex, dimension( lda, * ) a, integer lda, real beta, complex, dimension( * )

c)

CHFRK realiza una operación de rango k hermitiana para una matriz en formato

RFP.

Propósito

: 
!>
!> Rutina similar a BLAS de Nivel 3 para C en formato RFP.
!>
!> CHFRK realiza una de las operaciones de rango--k hermitianas
!>
!>    C := alpha*A*A**H + beta*C,
!>
!> o
!>
!>    C := alpha*A**H*A + beta*C,
!>
!> donde alpha y beta son escalares reales, C es una matriz hermitiana
!> n--por--n y A es una matriz n--por--k en el primer caso y una
!> matriz k--por--n en el segundo caso.
!
>

Parámetro

s
TRANSR 
!>          TRANSR es CHARACTER*1
!>          = 'N':  Se almacena la Forma Normal de RFP A;
!>          = 'C':  Se almacena la Forma de Transpuesta-Conjugada de RFP A.
!
>

UPL

O 
!>          UPLO es CHARACTER*1
!>           Al entrar, UPLO especifica si se debe referenciar la parte
!>           superior o inferior triangular del array C como sigue:
!>
!>              UPLO = 'U' o 'u'   Solo se debe referenciar la parte
!>                                 superior triangular de C.
!>
!>              UPLO = 'L' o 'l'   Solo se debe referenciar la parte
!>                                 inferior triangular de C.
!>
!>           Sin cambios al salir.
!
>

TRAN

S 
!>          TRANS es CHARACTER*1
!>           Al entrar, TRANS especifica la operación a realizar como
!>           sigue:
!>
!>              TRANS = 'N' o 'n'   C := alpha*A*A**H + beta*C.
!>
!>              TRANS = 'C' o 'c'   C := alpha*A**H*A + beta*C.
!>
!>           Sin cambios al salir.
!
>

N 
!>          N es INTEGER
!>           Al entrar, N especifica el orden de la matriz C. N debe ser
!>           al menos cero.
!>           Sin cambios al salir.
!
>

K 
!>          K es INTEGER
!>           Al entrar con TRANS = 'N' o 'n', K especifica el número de
!>           columnas de la matriz A, y al entrar con TRANS = 'C' o 'c',
!>           K especifica el número de filas de la matriz A. K debe ser
!>           al menos cero.
!>           Sin cambios al salir.
!
>

ALPH

A 
!>          ALPHA es REAL
!>           Al entrar, ALPHA especifica el escalar alpha.
!>           Sin cambios al salir.
!
>

A 
!>          A es un array COMPLEX, dimensión (LDA,ka)
!>           donde KA
!>           es K cuando TRANS = 'N' o 'n', y es N en caso contrario. Antes
!>           de entrar con TRANS = 'N' o 'n', la parte principal N--por--K del
!>           array A debe contener la matriz A, de lo contrario la parte
!>           principal K--por--N del array A debe contener la matriz A.
!>           Sin cambios al salir.
!
>

LD

A 
!>          LDA es INTEGER
!>           Al entrar, LDA especifica la primera dimensión de A como se
!>           declara en el (sub)programa que llama. Cuando TRANS = 'N' o 'n'
!>           entonces LDA debe ser al menos max( 1, n ), de lo contrario LDA
!>           debe ser al menos max( 1, k ).
!>           Sin cambios al salir.
!
>

BET

A 
!>          BETA es REAL
!>           Al entrar, BETA especifica el escalar beta.
!>           Sin cambios al salir.
!
>

C 
!>          C es un array COMPLEX, dimensión (N*(N+1)/2)
!>           Al entrar, la matriz A en formato RFP. El formato RFP es
!>           descrito por TRANSR, UPLO y N. Tenga en cuenta que las partes
!>           imaginarias de los elementos diagonales no necesitan estar
!>           establecidas, se asume que son cero, y al salir se establecen
!>           a cero.
!
>

NAME


DSFRK, SSFRK, DSFRK, SSFRK, ZHFRK - performs a symmetric or
    Hermitian rank-k operation for matrix in RFP format.






SYNOPSIS

character(len=1) transr, uplo, trans
integer n, k, lda
double precision alpha, beta

double precision c( * )

character(len=1) transr, uplo, trans

real c( * )

subroutine zhfrk(transr, uplo, trans, n, k, alpha, a, lda, beta, c)
character(len=1) transr, uplo, trans

double precision alpha, beta

DESCRIPTION


The routines perform one of the symmetric rank-k operations for
    a matrix in RFP format.




subroutine   dsfrk (character transr, character uplo, character trans, integer n, integer   k, double precision alpha, double precision, dimension( lda, * ) a, integer lda,   double precision beta, double precision, dimension( * ) c)


DSFRK performs a symmetric rank-k operation for matrix in
    RFP format.


Purpose:




!>
!> Level 3 BLAS like routine for C in RFP Format.
!>
!> DSFRK performs one of the symmetric rank--k operations
!>
!>    C := alpha*A*A**T + beta*C,
!>
!> or
!>
!>    C := alpha*A**T*A + beta*C,
!>
!> where alpha and beta are real scalars, C is an n--by--n symmetric
!> matrix and A is an n--by--k matrix in the first case and a k--by--n
!> matrix in the second case.
!> 




Parameters


TRANSR

!>          TRANSR is CHARACTER*1
!>          = 'N':  The Normal Form of RFP A is stored;
!>          = 'T':  The Transpose Form of RFP A is stored.
!> 


UPLO


!>          UPLO is CHARACTER*1
!>           On  entry, UPLO specifies whether the upper or lower
!>           triangular part of the array C is to be referenced as
!>           follows:
!>
!>              UPLO = 'U' or 'u'   Only the upper triangular part of C
!>                                  is to be referenced.
!>
!>              UPLO = 'L' or 'l'   Only the lower triangular part of C
!>                                  is to be referenced.
!>
!>           Unchanged on exit.
!> 


TRANS


!>          TRANS is CHARACTER*1
!>           On entry, TRANS specifies the operation to be performed as
!>           follows:
!>
!>              TRANS = 'N' or 'n'   C := alpha*A*A**T + beta*C.
!>
!>              TRANS = 'T' or 't'   C := alpha*A**T*A + beta*C.
!>
!>           Unchanged on exit.
!> 


N


!>          N is INTEGER
!>           On entry, N specifies the order of the matrix C. N must be
!>           at least zero.
!>           Unchanged on exit.
!> 


K


!>          K is INTEGER
!>           On entry with TRANS = 'N' or 'n', K specifies the number
!>           of  columns of the matrix A, and on entry with TRANS = 'T'
!>           or 't', K specifies the number of rows of the matrix A. K
!>           must be at least zero.
!>           Unchanged on exit.
!> 


ALPHA


!>          ALPHA is DOUBLE PRECISION
!>           On entry, ALPHA specifies the scalar alpha.
!>           Unchanged on exit.
!> 


A


!>          A is DOUBLE PRECISION array, dimension (LDA,ka)
!>           where KA
!>           is K  when TRANS = 'N' or 'n', and is N otherwise. Before
!>           entry with TRANS = 'N' or 'n', the leading N--by--K part of
!>           the array A must contain the matrix A, otherwise the leading
!>           K--by--N part of the array A must contain the matrix A.
!>           Unchanged on exit.
!> 


LDA


!>          LDA is INTEGER
!>           On entry, LDA specifies the first dimension of A as declared
!>           in  the  calling  (sub)  program.   When  TRANS = 'N' or 'n'
!>           then  LDA must be at least  max( 1, n ), otherwise  LDA must
!>           be at least  max( 1, k ).
!>           Unchanged on exit.
!> 


BETA


!>          BETA is DOUBLE PRECISION
!>           On entry, BETA specifies the scalar beta.
!>           Unchanged on exit.
!> 


C


!>          C is DOUBLE PRECISION array, dimension (NT)
!>           NT = N*(N+1)/2. On entry, the symmetric matrix C in RFP
!>           Format. RFP Format is described by TRANSR, UPLO and N.
!>
