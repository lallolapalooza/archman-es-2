DESCRIPCIÓN DETALLADA

Esta interfaz ayuda a la conversión entre máscaras de bits de libnuma de Linux y conjuntos de CPUs y conjuntos de nodos de hwloc.

Nota

La topología topology debe coincidir con la máquina actual.

El comportamiento de libnuma no está definido si el kernel no es consciente de NUMA (cuando CONFIG_NUMA no está configurado en la configuración del kernel). Por lo tanto, esta utilidad y libnuma pueden no ser estrictamente compatibles en este caso, lo cual puede detectarse comprobando si numa_available() devuelve -1.

int hwloc_cpuset_from_linux_libnuma_bitmask (hwloc_topology_t topology, hwloc_cpuset_t cpuset, const struct bitmask * bitmask) [inline]

Convierte la máscara de bits de libnuma bitmask en el conjunto de CPUs de hwloc cpuset. Esta función puede usarse después de llamar a muchas funciones numa_ que utilizan una struct bitmask como parámetro de salida.

Retorna

0 si tiene éxito.

-1 con errno establecido en ENOMEM si alguna reasignación interna falló.

struct bitmask * hwloc_cpuset_to_linux_libnuma_bitmask (hwloc_topology_t topology, hwloc_const_cpuset_t cpuset) [inline]

Convierte el conjunto de CPUs de hwloc cpuset en la máscara de bits de libnuma devuelta. La máscara de bits devuelta debe liberarse más tarde con numa_bitmask_free.

Esta función puede usarse antes de llamar a muchas funciones numa_ que utilizan una struct bitmask como parámetro de entrada.

Retorna

una struct bitmask recién asignada, o NULL en caso de error.
