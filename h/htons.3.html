BYTEORDER(3) Manual de funciones de biblioteca BYTEORDER(3)

NOMBRE

htonl, htons, ntohl, ntohs - convertir valores entre orden de bytes del host y de red

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <arpa/inet.h>
uint32_t htonl(uint32_t hostlong);
uint16_t htons(uint16_t hostshort);
uint32_t ntohl(uint32_t netlong);
uint16_t ntohs(uint16_t netshort);

DESCRIPCIÓN

La función htonl() convierte el entero sin signo hostlong de orden de bytes del host a orden de bytes de red.

La función htons() convierte el entero corto sin signo hostshort de orden de bytes del host a orden de bytes de red.

La función ntohl() convierte el entero sin signo netlong de orden de bytes de red a orden de bytes del host.

La función ntohs() convierte el entero corto sin signo netshort de orden de bytes de red a orden de bytes del host.

En el i386, el orden de bytes del host es primero el byte menos significativo, mientras que el orden de bytes de red, tal como se usa en Internet, es primero el byte más significativo.
