hetrs(3)

NAME

hetrs - Computes the solution of a system of linear equations using the LUP decomposition of a general matrix

SYNOPSIS

subroutine hetrs( uplo, n, k, a, lda, ipiv, b, ldb, info )

DESCRIPTION

hetrs is a subroutine in LAPACK (Linear Algebra PACKage) that solves a complex Hermitian positive-definite matrix system of linear equations using the LUP decomposition. It computes the solution X for the equation AX = B, where A is a Hermitian positive-definite matrix that has been previously factorized into a lower triangular matrix L and an upper triangular matrix U by the hetrf routine, and P is a permutation matrix. The factorization is stored in the array a and the pivot information is stored in the array ipiv.

The arguments are:

  • uplo (character*1): Specifies whether the matrix A is upper ('U') or lower ('L') triangular.
  • n (integer): The order of the matrix A (N x N).
  • k (integer): The number of right-hand sides (number of columns in B).
  • a (complex*16, dimension (lda, *)): The LUP decomposition of the matrix A, computed by hetrf.
  • lda (integer): The leading dimension of the array a.
  • ipiv (integer, dimension (*)): The pivot indices, computed by hetrf.
  • b (complex*16, dimension (ldb, *)): The right-hand side matrix B. On exit, b is overwritten by the solution matrix X.
  • ldb (integer): The leading dimension of the array b.
  • info (integer): An output parameter. info = 0 if the solution was computed successfully. info < 0 if an error occurred.

DIAGNOSTICS

info < 0 indicates an error occurred:

  • info = -1: The 1st argument had an illegal value.
  • info = -2: The 2nd argument had an illegal value.
  • info = -3: The 3rd argument had an illegal value.
  • info = -4: The 4th argument had an illegal value.
  • info = -5: The 6th argument had an illegal value.
  • info = -7: The 8th argument had an illegal value.

EXAMPLE

This example solves the system AX = B, where A is a 3x3 Hermitian positive-definite matrix.

program hetrs_example
  implicit none
  integer, parameter :: n = 3
  integer, parameter :: k = 1
  complex*16 :: a(n,n)
  complex*16 :: b(n,k)
  integer :: ipiv(n)
  integer :: info
  integer :: i, j

  ! Define matrix A
  a(1,1) = (10.0, 0.0)
  a(2,1) = (-5.0, 3.0)
  a(3,1) = (2.0, -1.0)
  a(1,2) = (-5.0, -3.0)
  a(2,2) = (15.0, 0.0)
  a(3,2) = (1.0, 4.0)
  a(1,3) = (2.0, 1.0)
  a(2,3) = (1.0, -4.0)
  a(3,3) = (20.0, 0.0)

  ! Define right-hand side B
  b(1,1) = (1.0, 0.0)
  b(2,1) = (2.0, 0.0)
  b(3,1) = (3.0, 0.0)

  ! Compute the LUP decomposition of A
  call hetrf('U', n, a, n, ipiv, info)
  if (info /= 0) then
    print *, 'Error in hetrf: ', info
    stop
  end if

  ! Solve the system AX = B
  call hetrs('U', n, k, a, n, ipiv, b, n, info)
  if (info /= 0) then
    print *, 'Error in hetrs: ', info
    stop
  end if

  ! Print the solution X
  print *, 'Solution X:'
  do i = 1, n
    print '(A, I0, A, F8.4, A, F8.4, A)', 'X(', i, ', 1) = (', real(b(i,1)), ', ', aimag(b(i,1)), ')'
  end do

end program hetrs_example
