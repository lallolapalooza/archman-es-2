HXREMOVE(1) Utilidades HTML-XML HXREMOVE(1)

NOMBRE

hxremove - elimina elementos de un archivo XML mediante un selector CSS

SINOPSIS

hxremove [ -i ] [ -l idioma ] selectores

DESCRIPCIÓN

hxremove lee un documento XML bien formado desde la entrada estándar y lo escribe en la salida estándar sin ningún elemento que coincida con uno de los selectores CSS que se proporcionan como argumento. Por ejemplo:


hxremove ol li:first-child

elimina el primer elemento li (elemento de lista en XHTML) de cada ol (lista ordenada).

Si hay varios selectores, deben estar separados por comas. Por ejemplo:


hxremove p + ul, blockquote ol

elimina todos los elementos ul que siguen a un elemento p y también todos los elementos ol que son descendientes de un elemento blockquote.

hxremove asume que los selectores de clase (".foo") se refieren a un atributo llamado "class". Y asume que los selectores de ID ("#foo") se refieren a un atributo llamado "id".

Para manejar archivos HTML, primero conviértelos a XML bien formado, por ejemplo, con hxnormalize -x.

Comparar con hxselect, que elimina todo excepto los elementos seleccionados.

OPCIONES

Se admiten las siguientes opciones:

-i
Coincide sin distinguir mayúsculas y minúsculas. Útil para HTML y algunos otros lenguajes basados en SGML.
-l idioma
Establece el idioma predeterminado, en caso de que el elemento raíz no tenga un atributo xml:lang (predeterminado: ninguno). Ejemplo: -l es

OPERANDOS

Se admite el siguiente operando:

selectores
Uno o más selectores separados por comas. La mayoría de los selectores de CSS nivel 3 son compatibles.
