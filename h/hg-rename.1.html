hg-rename(1)

Paquete: mercurial

Licencias: GPL

HG(RENAME) HG(RENAME)

NOMBRE

hg rename - renombra archivos; equivalente de copiar + eliminar

SINOPSIS

hg rename [OPCIÓN]... FUENTE... DESTINO

DESCRIPCIÓN

Marca destino como copias de fuentes; marca fuentes para su eliminación. Si destino es un directorio, las copias se colocan en ese directorio. Si destino es un archivo, solo puede haber una fuente.

Por defecto, este comando copia el contenido de los archivos tal como existen en el directorio de trabajo. Si se invoca con -A/--after, la operación se registra, pero no se realiza ninguna copia.

Para deshacer el marcado de un archivo de destino como renombrado, usa --forget. Con esa opción, todos los argumentos (posicionales) dados se desmarcan como renombrados. El (los) archivo(s) de destino quedará(n) en su lugar (aún rastreado(s)). El (los) archivo(s) fuente no se restaurará(n). Ten en cuenta que hg rename --forget se comporta de la misma manera que hg copy --forget.

Este comando tiene efecto con la próxima confirmación por defecto.

Retorna 0 si tiene éxito, 1 si se encuentran errores.

OPCIONES

--forget
desmarcar un archivo de destino como renombrado
-A, --after
registrar un renombramiento que ya ha ocurrido
--at-rev <REV>
(des)marcar renombramientos en la revisión dada (EXPERIMENTAL)
-f, --force
mover forzosamente sobre un archivo gestionado existente
-I,--include <PATRÓN[+]>
incluir nombres que coincidan con los patrones dados
-X,--exclude <PATRÓN[+]>
excluir nombres que coincidan con los patrones dados
-n, --dry-run
no realizar acciones, solo imprimir la salida

[+] la opción marcada puede especificarse varias veces

ALIAS

move, mv
