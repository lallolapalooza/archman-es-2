DESCRIPCIÓ

N

Tenga en cuenta que hivexregedit es una herramienta de bajo nivel para manipular archivos de colmena directamente. Para fusionar o exportar cambios del registro a máquinas virtuales de Windows es mejor usar virt-win-re

g(1).

Dado un archivo binario local ("colmena"), hay dos modos. "--merge" importa (fusiona) cambios de un archivo en formato regedit en la colmena. Es similar a usar el interruptor "/s" en el regedit.exe de

Windows.

"--export" exporta una clave del Registro (recursivamente) al formato

regedit.

CODIFICACIÓ

N

"hivexregedit" espera que los archivos regedit ya hayan sido recodificados en la codificación local. Usualmente en hosts Linux, esto significa UTF-8 con finales de línea estilo Unix. Dado que los archivos regedit de Windows a menudo están en UTF-16LE con finales de línea estilo Windows, puede necesitar recodificar el archivo completo antes o después del

procesamiento.

Para recodificar un archivo del formato de Windows al de Linux (antes de procesarlo con la opción "--merge"), haría algo como

esto: 
iconv -f utf-16le -t utf-8 < win.reg | dos2unix > linux.
reg

Para ir en la dirección opuesta, después de usar "--export" y antes de enviar el archivo a un usuario de Windows, haga algo como

esto: 
unix2dos < linux.reg | iconv -f utf-8 -t utf-16le > win.
reg

Para más información sobre la codificación, consulte Win::Hivex::Reg

edit(3).

Si no está seguro sobre la codificación actual, use el comando file(1). Las versiones recientes de regedit.exe de Windows producen un archivo UTF-16LE con finales de línea estilo Windows (CRLF),

así: 
$ file software.reg
software.reg: Little-endian UTF-16 Unicode text, with very long lines,
with CRLF line
terminators

Este archivo necesitaría conversión antes de poder fusionarlo c

on "--m
erge".

Por ejemplo, dentro de la colmena de software, todas las claves se almacenan relativas a "HKEY_LOCAL_MACHINE\SOFTWARE". El formato de colmena en sí no almacena este prefijo, por lo que tiene que proporcionarlo basándose en conocimiento externo. (virt-win-reg(1), entre otras cosas, ya sabe sobre
