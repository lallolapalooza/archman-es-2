HXSELECT(1) Utilidades HTML-XML HXSELECT(1)

NOMBRE

hxselect - extrae elementos o atributos que coinciden con un selector (CSS)

SINOPSIS

hxselect [ -i ] [ -c ] [ -l idioma ] [ -s separador ] selectores

DESCRIPCIÓN

hxselect lee un documento XML bien formado y genera todos los elementos y atributos que coinciden con uno de los selectores CSS que se proporcionan como argumento. Por ejemplo:


hxselect ol li:first-child

selecciona el primer li (elemento de lista en XHTML) de un ol (lista ordenada).

Si hay varios selectores, deben estar separados por comas. Por ejemplo:


hxselect p + ul, blockquote ol

selecciona todos los elementos ul que siguen a un p y todos los elementos ol que son descendientes de un elemento blockquote.

El comando opera sobre la entrada estándar.

hxselect asume que los selectores de clase (".foo") se refieren a un atributo llamado "class" y que los selectores de ID ("#foo") se refieren a un atributo llamado "id".

Se soporta el selector experimental de nodo de atributo '::attr(nombre)' y selecciona el atributo de ese nombre.

Los comentarios y las instrucciones de procesamiento se ignoran, es decir, se leen pero nunca se escriben.

OPCIONES

Se admiten las siguientes opciones:

-i
Coincidencia sin distinción de mayúsculas y minúsculas. Útil para HTML y algunos otros lenguajes basados en SGML.
-c
Imprime solo el contenido. Sin -c, también se imprimen la etiqueta de inicio y fin del elemento coincidente; con -c solo se imprime el contenido del elemento coincidente. Si se selecciona un atributo en lugar de un elemento (selector ::attr()), solo se imprime el valor del atributo.
-l idioma
Establece el idioma predeterminado, en caso de que el elemento raíz no tenga un atributo xml:lang (predeterminado: ninguno). Ejemplo: -l es
-s separador
Una cadena que se imprimirá después de cada coincidencia (predeterminado: vacío). Acepta secuencias de escape tipo C. Ejemplo: -s ' \n' para imprimir un salto de línea después de cada coincidencia.

OPERANDOS

Se admite el siguiente operando:

selectores
Uno o más selectores separados por comas. Se admiten la mayoría de los selectores de CSS nivel 3, con la excepción de los selectores que requieren interacción (por ejemplo, ':active') o diseño (por ejemplo, ':first-line').

BUGS

Los selectores sin distinción de mayúsculas y minúsculas (opción -i) actualmente solo funcionan para caracteres ASCII ("a" coincide con "A"), no para otros caracteres ("ä" no coincide con "Ä").
