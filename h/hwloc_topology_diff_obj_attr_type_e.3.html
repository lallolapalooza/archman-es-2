Descripción Detallada

Las aplicaciones que manipulan muchas topologías similares, por ejemplo una para cada nodo de un clúster homogéneo, pueden querer comprimir las topologías para reducir el consumo de memoria.

Este archivo ofrece una forma de manipular la diferencia entre topologías y exportarla/importarla desde/a XML. La compresión se puede lograr almacenando una topología completamente mientras que las otras solo se describen por sus diferencias con la primera. La topología real puede ser reconstruida cuando sea necesaria aplicando la diferencia precalculada a la topología de referencia.

Esta interfaz se dirige a nodos muy similares. Solo se admiten diferencias muy simples entre topologías, por ejemplo, un cambio en el tamaño de la memoria, el nombre del objeto o algún atributo de información. Las diferencias más complejas, como agregar o eliminar objetos, no se pueden representar en las estructuras de diferencia y, por lo tanto, devuelven errores. Las diferencias entre conjuntos de objetos o conjuntos permitidos en toda la topología tampoco se pueden representar.

Esto significa que no es necesario aplicar la diferencia al mirar la organización del árbol (cuántos niveles, cuántos objetos por nivel, qué tipo de objetos, conjuntos de CPU y nodos, etc.) y al vincularse a objetos. Sin embargo, la diferencia debe aplicarse al mirar los atributos del objeto, como el nombre, el tamaño de la memoria o los atributos de información.

Documentación de funciones

int hwloc_topology_diff_apply (hwloc_topology_t topology, hwloc_topology_diff_t diff, unsigned long flags)

Aplica una diferencia de topología a una topología existente. flags es un conjunto OR'ed de hwloc_topology_diff_apply_flags_e.

La nueva topología se modifica en el lugar. hwloc_topology_dup() puede usarse para duplicarla antes de parchearla.

Si la diferencia no se puede aplicar en su totalidad, todos los elementos aplicados previamente se desaplican antes de devolver el valor.

Devuelve

0 si tiene éxito.

-N si la aplicación de la diferencia falló mientras se intentaba aplicar la N-ésima parte de la diferencia. Por ejemplo, se devuelve -1 si el primer elemento de diferencia no se pudo aplicar.

int hwloc_topology_diff_build (hwloc_topology_t topology, hwloc_topology_t newtopology, unsigned long flags, hwloc_topology_diff_t *diff)

Construye la diferencia entre dos topologías y la almacena en *diff. La topología antigua es topology y la topología nueva es newtopology.

flags es un conjunto OR'ed de hwloc_topology_diff_apply_flags_e.

Devuelve

0 si la diferencia se construyó completamente.

1 si la diferencia era demasiado compleja y no se pudo construir completa (por ejemplo, si se eliminaron o agregaron objetos). En este caso, *diff contendrá solo las partes de la diferencia que se pudieron construir antes de la parte compleja.

-N si ocurrió un error desconocido al procesar la N-ésima diferencia entre los objetos. Por ejemplo, -1 si el primer elemento de diferencia no se pudo construir.

Description

This enum defines the possible attribute types that may differ between two topology objects when computing a difference.

These values are not meant to be used directly by the user. They are part of the internal representation of topology differences.

The enum values HWLOC_TOPOLOGY_DIFF_OBJ_ATTR_TYPE_ICH_... are specific to the instruction cache and memory allocators.

Description

Compute the difference between 2 topologies. The difference is stored as a list of hwloc_topology_diff_t(3) entries starting at diff. It is computed by doing a depth-first traversal of both topology trees simultaneously.

If the difference between 2 objects is too complex to be represented (for instance if some objects have different types, or different numbers of children), a special diff entry of type HWLOC_TOPOLOGY_DIFF_TOO_COMPLEX is queued. The computation of the diff does not continue below these objects. So each such diff entry means that the difference between two subtrees could not be computed.

Returns

0 if the difference can be represented properly.

0 with diff pointing to NULL if there is no difference between the topologies.

1 if the difference is too complex (see above). Some entries in the list will be of type HWLOC_TOPOLOGY_DIFF_TOO_COMPLEX.

-1 on any other error.

Note

flags is currently not used. It should be 0.

The output diff has to be freed with hwloc_topology_diff_destroy().

The output diff can only be exported to XML or passed to hwloc_topology_diff_apply() if 0 was returned, i.e. if no entry of type HWLOC_TOPOLOGY_DIFF_TOO_COMPLEX is listed.

The output diff may be modified by removing some entries from the list. The removed entries should be freed by passing them to to hwloc_topology_diff_destroy() (possible as another list).

0 on success, -1 on error.

Compute the difference between 2 topologies. The difference is stored as a list of hwloc_topology_diff_t(3) entries starting at diff. It is computed by doing a depth-first traversal of both topology trees simultaneously.

If the difference between 2 objects is too complex to be represented (for instance if some objects have different types, or different numbers of children), a special diff entry of type HWLOC_TOPOLOGY_DIFF_TOO_COMPLEX is queued. The computation of the diff does not continue below these objects. So each such diff entry means that the difference between two subtrees could not be computed.

Returns

0 if the difference can be represented properly.

0 with diff pointing to NULL if there is no difference between the topologies.

1 if the difference is too complex (see above). Some entries in the list will be of type HWLOC_TOPOLOGY_DIFF_TOO_COMPLEX.

-1 on any other error.

Note

flags is currently not used. It should be 0.

The output diff has to be freed with hwloc_topology_diff_destroy().

The output diff can only be exported to XML or passed to hwloc_topology_diff_apply() if 0 was returned, i.e. if no entry of type HWLOC_TOPOLOGY_DIFF_TOO_COMPLEX is listed.

The output diff may be modified by removing some entries from the list. The removed entries should be freed by passing them to to hwloc_topology_diff_destroy() (possible as another list).
