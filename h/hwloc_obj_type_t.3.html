enum hwloc_obj_osdev_type_e

Tipo de un dispositivo de SO.

Enumerator

HWLOC_OBJ_OSDEV_BLOCK
Dispositivo de bloque del sistema operativo, o dispositivo de memoria no volátil. Por ejemplo 'sda' o 'dax2.0' en Linux.
HWLOC_OBJ_OSDEV_GPU
Dispositivo GPU del sistema operativo. Por ejemplo ':0.0' para una pantalla GL, 'card0' para un dispositivo DRM de Linux.
HWLOC_OBJ_OSDEV_NETWORK
Dispositivo de red del sistema operativo. Por ejemplo la interfaz 'eth0' en Linux.
HWLOC_OBJ_OSDEV_OPENFABRICS
Dispositivo openfabrics del sistema operativo. Por ejemplo el HCA InfiniBand 'mlx4_0', la interfaz Omni-Path 'hfi1_0', o el HCA Atos/Bull BXI 'bxi0' en Linux.
HWLOC_OBJ_OSDEV_DMA
Dispositivo de motor DMA del sistema operativo. Por ejemplo el canal DMA 'dma0chan0' en Linux.
HWLOC_OBJ_OSDEV_COPROC
Dispositivo coprocesador del sistema operativo. Por ejemplo 'opencl0d0' para un dispositivo OpenCL, 'cuda0' para un dispositivo CUDA.

enum hwloc_obj_type_t

Tipo de objeto de topología.

Nota

¡No confíe en el orden o la completitud de los valores, ya que pueden definirse nuevos en el futuro! Si necesita comparar tipos, utilice hwloc_compare_types() en su lugar.

Enumerator

HWLOC_OBJ_MACHINE
Máquina. Un conjunto de procesadores y memoria con coherencia de caché. Este tipo es siempre utilizado para el objeto raíz de una topología, y nunca se utiliza en ningún otro lugar. Por lo tanto, su padre es siempre NULL.
HWLOC_OBJ_PACKAGE
Paquete físico. El paquete físico que normalmente se inserta en un zócalo en la placa base. Un paquete de procesador generalmente contiene múltiples núcleos, y posiblemente algunas matrices (dies).
HWLOC_OBJ_CORE
Núcleo. Una unidad de computación (puede ser compartida por varias PU, también conocidas como procesadores lógicos).
HWLOC_OBJ_PU
Unidad de Procesamiento, o (Procesador) Lógico. Una unidad de ejecución (puede compartir un núcleo con algunos otros procesadores lógicos, por ejemplo, en el caso de un núcleo SMT). Este es el objeto más pequeño que representa recursos de CPU, no puede tener ningún hijo excepto objetos Misc.

Los objetos de este tipo siempre se reportan y, por lo tanto, pueden utilizarse como respaldo cuando otros no lo están.

HWLOC_OBJ_L1CACHE
Caché de Nivel 1 de Datos (o Unificada).
HWLOC_OBJ_L2CACHE
Caché de Nivel 2 de Datos (o Unificada).
HWLOC_OBJ_L3CACHE
Caché de Nivel 3 de Datos (o Unificada).
HWLOC_OBJ_L4CACHE
Caché de Nivel 4 de Datos (o Unificada).
HWLOC_OBJ_L5CACHE
Caché de Nivel 5 de Datos (o Unificada).

Cachés de Instrucciones (filtradas por defecto por el backend).

HWLOC_OBJ_L1ICACHE
Caché de Nivel 1 de Instrucciones.
HWLOC_OBJ_L2ICACHE
Caché de Nivel 2 de Instrucciones.
HWLOC_OBJ_L3ICACHE
Caché de Nivel 3 de Instrucciones.

Grupo de objetos. Usado para agrupar objetos arbitrarios que no encajan en el modelo jerárquico estándar. Por ejemplo, grupos de dispositivos para el mismo servicio de E/S.

HWLOC_OBJ_GROUP
Grupo.

Nodos NUMA. Este objeto representa un nodo NUMA o una política de memoria similar, y contiene memoria y/o procesadores.

HWLOC_OBJ_NUMANODE
Nodo NUMA.

Puente de E/S. Representa un puente de E/S (como un puente PCI-Host, un puente PCI-PCI, etc.) que conecta dos partes del árbol de topología.

HWLOC_OBJ_BRIDGE
Puente.

Dispositivo PCI. Representa un dispositivo conectado a un bus PCI.

HWLOC_OBJ_PCI_DEVICE
Dispositivo PCI.

Dispositivo del Sistema Operativo. Representa un dispositivo presentado al sistema operativo, que no es un dispositivo PCI estándar.

HWLOC_OBJ_OS_DEVICE
Dispositivo del SO.

Objeto misceláneo. Representa algo que no encaja en ningún otro tipo, como un puerto USB o un dispositivo serie.

HWLOC_OBJ_MISC
Misceláneo.

Caché de memoria. Representa un dispositivo de caché de memoria dedicado, como la caché de memoria del host de GPU.

HWLOC_OBJ_MEMCACHE
Caché de memoria.

Matriz (Die). Representa una matriz de silicio que contiene uno o más núcleos.

HWLOC_OBJ_DIE
Matriz.

Este valor se incrementará cuando se añadan nuevos tipos de objetos. Nunca debe ser utilizado directamente excepto para obtener el número total de tipos conocidos.

HWLOC_OBJ_TYPE_MAX
Máximo.

DOCUMENTACIÓN DE FUNCIÓN

int hwloc_compare_types (hwloc_obj_type_t type1, hwloc_obj_type_t type2)

Comparar dos tipos de objetos de topología.

Devuelve:

  • -1 si type1 es menor que type2.
  • 0 si type1 es igual que type2.
  • 1 si type1 es mayor que type2.
  • HWLOC_TYPE_UNORDERED si los tipos no pueden compararse (por ejemplo, si uno o ambos son HWLOC_OBJ_MISC).

Esta función es útil para ordenar listas de tipos de objetos, pero no debe usarse para comparar tipos para la igualdad si existe la posibilidad de que se utilicen valores desconocidos en el futuro.

Objetos de grupo. Objetos que no encajan en los anteriores pero que son detectados por hwloc y son útiles a tener en cuenta para la afinidad. Por ejemplo, algunos sistemas operativos exponen su agregación arbitraria de procesadores de esta manera. Y hwloc puede insertar tales objetos para agrupar nodos NUMA según sus distancias. HWLOC_OBJ_NUMANODE
Nodo NUMA. Un objeto que contiene memoria a la que los procesadores del host pueden acceder directamente y por bytes. Generalmente está cerca de algu
nos núcleos (los objetos correspondientes son descendientes del objeto de nodo NUMA en el árbol de hwloc). Es el objeto más pequeño que representa recursos de memoria, no puede tener ningún hijo excepto objetos Misc. Sin embargo, puede tener padres de tipo caché del lado de la memoria.

Los nodos NUMA pueden corresponder a diferentes tipos de memoria (DRAM, HBM, CXL-DRAM, etc.). Cuando hwloc es capaz de adivinar ese tipo, se especifica en el campo subtype del objeto. Véase también Atributos normales en la documentación

principal.

Siempre hay al menos un objeto de este tipo en la topología, incluso si la máquina no es

Los objetos de memoria no se enumeran en la lista principal de hijos, sino en la lista dedicada de hijos de

memoria.

Los nodos NUMA tienen una profundidad especial HWLOC_TYPE_DEPTH_NUMANODE en lugar de una profundidad normal como otros objetos en el árbol

principal.
