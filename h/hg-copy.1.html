hg-copy(1)

Paquete: mercurial

Licencias: GPL

HG(COPY) HG(COPY)

NOMBRE

hg copy - marcar archivos como copiados para el próximo commit

SINOPSIS

hg copy [OPCIÓN]... (FUENTE... DESTINO | --forget DESTINO...)

DESCRIPCIÓN

Marca destino como copias de los archivos fuente. Si destino es un directorio, las copias se colocan en ese directorio. Si destino es un archivo, fuente debe ser un único archivo.

Por defecto, este comando copia el contenido de los archivos tal como existen en el directorio de trabajo. Si se invoca con -A/--after, la operación se registra, pero no se realiza ninguna copia.

Para deshacer el marcado de un archivo destino como copiado, use --forget. Con esa opción, todos los argumentos posicionales dados se desmarcan como copias. Los archivos destino se dejarán en su lugar (aún rastreados). Tenga en cuenta que hg copy --forget se comporta igual que hg rename --forget.

Este comando entra en vigor con el próximo commit por defecto.

Devuelve 0 si tiene éxito, 1 si se encuentran errores.

OPCIONES

--forget
desmarcar un archivo destino como copiado
-A, --after
registrar una copia que ya ha ocurrido
--at-rev <REV>
(des)marcar copias en la revisión dada (EXPERIMENTAL)
-f, --force
copiar forzosamente sobre un archivo gestionado existente
-I,--include <PATRÓN[+]>
incluir nombres que coincidan con los patrones dados
-X,--exclude <PATRÓN[+]>
excluir nombres que coincidan con los patrones dados
-n, --dry-run
no realizar acciones, solo imprimir la salida

[+] la opción marcada se puede especificar varias veces

ALIAS
