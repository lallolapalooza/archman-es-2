hwlocality_nvml - Interoperabilidad con la Biblioteca de Gestión de NVIDIA (NVML)

Descripción detallada

Esta interfaz ofrece formas de obtener información topológica sobre dispositivos gestionados por la Biblioteca de Gestión de NVIDIA (NVML).

Documentación de funciones

int hwloc_nvml_get_device_cpuset (hwloc_topology_t topology, nvmlDevice_t device, hwloc_cpuset_t set) [inline]

Obtener el conjunto de CPU de procesadores que están físicamente cerca del dispositivo NVML device. Almacenar en set el conjunto de CPU que describe la localidad del dispositivo NVML device.

La topología topology y el dispositivo device deben coincidir con la máquina local. La detección de dispositivos de E/S y el componente NVML no son necesarios en la topología.

La función solo devuelve la localidad del dispositivo. Si se necesita más información sobre el dispositivo, se deben usar objetos del sistema operativo en su lugar, ver hwloc_nvml_get_device_osdev() y hwloc_nvml_get_device_osdev_by_index().

Esta función actualmente solo está implementada de forma útil para Linux; otros sistemas simplemente obtendrán un conjunto de CPU completo.

Devoluciones

0 si tiene éxito.

-1 si hay un error, por ejemplo, si no se pudo encontrar la información del dispositivo.

hwloc_obj_t hwloc_nvml_get_device_osdev (hwloc_topology_t topology, nvmlDevice_t device) [inline]

Obtener el objeto de dispositivo del sistema operativo de hwloc que corresponde al dispositivo NVML device.

Devoluciones

El objeto de dispositivo del sistema operativo de hwloc que describe el dispositivo NVML dado device.

NULL si no se pudo encontrar ninguno.

La topología topology y el dispositivo device deben coincidir con la máquina local. La detección de dispositivos de E/S y el componente NVML deben estar habilitados en la topología. De lo contrario, la localidad del objeto aún puede encontrarse usando hwloc_nvml_get_device_cpuset().

Nota

El objeto de dispositivo PCI correspondiente puede encontrarse mirando el puntero padre del resultado (a menos que los dispositivos PCI estén filtrados).

hwloc_obj_t hwloc_nvml_get_device_osdev_by_index (hwloc_topology_t topology, unsigned idx) [inline]

Obtener el objeto de dispositivo del sistema operativo de hwloc que corresponde al dispositivo NVML cuyo índice es idx.

Devoluciones

El objeto de dispositivo del sistema operativo de hwloc que describe el dispositivo NVML cuyo índice es idx.

NULL si no se pudo encontrar ninguno.

La topología topology no necesariamente tiene que coincidir con la máquina actual. Por ejemplo, la topología puede ser una importación XML de un host remoto. La detección de dispositivos de E/S y el componente NVML deben estar habilitados en la topología.

Nota

El objeto de dispositivo PCI correspondiente se puede obtener mirando el objeto padre del dispositivo del sistema operativo (a menos que los dispositivos PCI estén filtrados).
