Documentación de la Función

subrutina chetrf_rook (character uplo, integer n, complex, dimension( lda, * ) a, integer lda, integer, dimension( * ) ipiv, complex, dimension( * ) work, integer lwork, integer info)

CHETRF_ROOK calcula la factorización de una matriz hermitiana compleja indefinida utilizando el método de pivoteo diagonal Bunch-Kaufman acotado ("rook") (algoritmo bloqueado, llamando a BLAS de Nivel 3).

Propósito:

!>
!> CHETRF_ROOK calcula la factorización de una matriz hermitiana compleja A
!> utilizando el método de pivoteo diagonal Bunch-Kaufman acotado ().
!> La forma de la factorización es
!>
!>    A = U*D*U**T  o  A = L*D*L**T
!>
!> donde U (o L) es un producto de matrices de permutación y triangulares
!> superiores (inferiores) unitarias, y D es hermitiana y diagonal por bloques
!> con bloques diagonales de tamaño 1x1 y 2x2.
!>
!> Esta es la versión bloqueada del algoritmo, que llama a BLAS de Nivel 3.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          = 'U':  Se almacena el triángulo superior de A;
!>          = 'L':  Se almacena el triángulo inferior de A.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

A

!>          A es un arreglo COMPLEX, dimensión (LDA,N)
!>          En la entrada, la matriz hermitiana A.  Si UPLO = 'U', la parte
!>          triangular superior N por N inicial de A contiene la parte
!>          triangular superior de la matriz A, y la parte triangular
!>          inferior estricta de A no se referencia.  Si UPLO = 'L', la
!>          parte triangular inferior N por N inicial de A contiene la parte
!>          triangular inferior de la matriz A, y la parte triangular
!>          superior estricta de A no se referencia.
!>
!>          En la salida, la matriz diagonal por bloques D y los multiplicadores
!>          utilizados para obtener el factor U o L (ver más abajo para más detalles).
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del arreglo A.  LDA >= max(1,N).
!>

IPIV

!>          IPIV es un arreglo INTEGER, dimensión (N)
!>          Detalles de los intercambios y de la estructura por bloques de D.
!>
!>          Si UPLO = 'U':
!>             Solo se establecen los últimos KB elementos de IPIV.
!>
!>             Si IPIV(k) > 0, entonces las filas y columnas k e IPIV(k) fueron
!>             intercambiadas y D(k,k) es un bloque diagonal de tamaño 1x1.
!>
!>             Si IPIV(k) < 0 y IPIV(k-1) < 0, entonces las filas y
!>             columnas k e -IPIV(k) fueron intercambiadas y las filas y
!>             columnas k-1 e -IPIV(k-1) fueron intercambiadas,
!>             D(k-1:k,k-1:k) es un bloque diagonal de tamaño 2x2.
!>
!>          Si UPLO = 'L':
!>             Solo se establecen los primeros KB elementos de IPIV.
!>
!>             Si IPIV(k) > 0, entonces las filas y columnas k e IPIV(k)
!>             fueron intercambiadas y D(k,k) es un bloque diagonal de tamaño 1x1.
!>
!>             Si IPIV(k) < 0 y IPIV(k+1) < 0, entonces las filas y
!>             columnas k e -IPIV(k) fueron intercambiadas y las filas y
!>             columnas k+1 e -IPIV(k+1) fueron intercambiadas,
!>             D(k:k+1,k:k+1) es un bloque diagonal de tamaño 2x2.
!>

WORK

!>          WORK es un arreglo COMPLEX, dimensión (MAX(1,LWORK)).
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La longitud de WORK.  LWORK >= 1.  Para un mejor rendimiento
!>          LWORK >= N*NB, donde NB es el tamaño de bloque devuelto por ILAENV.
!>
!>          Si LWORK = -1, se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo del arreglo WORK, devuelve
!>          este valor como la primera entrada del arreglo WORK, y XERBLA no emite
!>          ningún mensaje de error relacionado con LWORK.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>          > 0:  si INFO = i, D(i,i) es exactamente cero.  La factorización
!>                se ha completado, pero la matriz diagonal por bloques D es
!>                exactamente singular, y ocurrirá una división por cero si se
!>                utiliza para resolver un sistema de ecuaciones.
!>

Más detalles:

!>
!>  Si UPLO = 'U', entonces A = U*D*U**T, donde
!>     U = P(n)*U(n)* ... *P(k)U(k)* ...,
!>  es decir, U es un producto de términos P(k)*U(k), donde k disminuye de n a
!>  1 en pasos de 1 o 2, y D es una matriz diagonal por bloques con bloques
!>  diagonales de tamaño 1x1 y 2x2 D(k).  P(k) es una matriz de permutación
!>  definida por IPIV(k), y U(k) es una matriz triangular superior unitaria, tal
!>  que si el bloque diagonal D(k) es de orden s (s = 1 o 2), entonces
!>
!>             (   I    v    0   )   k-s
!>     U(k) =  (   0    I    0   )   s
!>             (   0    0    I   )   n-k
!>                k-s   s   n-k
!>
!>  Si s = 1, D(k) sobrescribe A(k,k), y v sobrescribe A(1:k-1,k).
!>  Si s = 2, el triángulo superior de D(k) sobrescribe A(k-1,k-1), A(k-1,k),
!>  y A(k,k), y v sobrescribe A(1:k-2,k-1:k).
!>
!>  Si UPLO = 'L', entonces A = L*D*L**T, donde
!>     L = P(1)*L(1)* ... *P(k)*L(k)* ...,
!>  es decir, L es un producto de términos P(k)*L(k), donde k aumenta de 1 a
!>  n en pasos de 1 o 2, y D es una matriz diagonal por bloques con bloques
!>  diagonales de tamaño 1x1 y 2x2 D(k).  P(k) es una matriz de permutación
!>  definida por IPIV(k), y L(k) es una matriz triangular inferior unitaria, tal
!>  que si el bloque diagonal D(k) es de orden s (s = 1 o 2), entonces
!>
!>             (   I    0     0   )  k-1
!>     L(k) =  (   0    I     0   )  s
!>             (   0    v     I   )  n-k-s+1
!>                k-1   s  n-k-s+1
!>
!>  Si s = 1, D(k) sobrescribe A(k,k), y v sobrescribe A(k+1:n,k).
!>  Si s = 2, el triángulo inferior de D(k) sobrescribe A(k,k), A(k+1,k),
!>  y A(k+1,k+1), y v sobrescribe A(k+2:n,k:k+1).
!>
