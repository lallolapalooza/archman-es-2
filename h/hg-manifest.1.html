NOMBRE

hg manifest - mostrar el manifiesto del proyecto de la revisión actual o dada

SINOPSIS

hg manifest [-r REV]

DESCRIPCIÓN

Imprime una lista de archivos bajo control de versiones para la revisión dada. Si no se proporciona una revisión, se usa el primer padre del directorio de trabajo, o la revisión nula si no hay ninguna revisión registrada.

Con -v, imprime los permisos de archivo, bits de enlace simbólico y ejecutables. Con --debug, imprime los hashes de revisión de los archivos.

Si se especifica la opción --all, se imprime la lista de todos los archivos de todas las revisiones. Esto incluye archivos eliminados y renombrados.

Devuelve 0 si tiene éxito.

OPCIONES

-r,--rev <REV>
revisión a mostrar
--all
listar archivos de todas las revisiones
-T,--template <PLANTILLA>
mostrar con plantilla
