int hwloc_bitmap_singlify_per_core (hwloc_topology_t topology, hwloc_bitmap_t cpuset, unsigned which)

Elimina las PU de multihilo simultáneo de un conjunto de CPU. Para cada núcleo en topology, si cpuset contiene algunas PU de ese núcleo, modifica cpuset para mantener solo una PU para ese núcleo.

which especifica qué PU se mantendrá. Las PU se consideran en orden de índice físico. Si es 0, para cada núcleo, la función mantiene la primera PU que estaba originalmente establecida en cpuset.

Si which es mayor que el número de PU en un núcleo que estaban originalmente establecidas en cpuset, no se mantiene ninguna PU para ese núcleo.

Devuelve

0.

Nota

Las PU que no están debajo de un objeto Core se ignoran (por ejemplo, si la topología no contiene ningún objeto Core). Ninguna de ellas se elimina de cpuset.

unsigned hwloc_get_closest_objs (hwloc_topology_t topology, hwloc_obj_t src, hwloc_obj_t *restrict objs, unsigned max)

Realiza un recorrido en profundidad de la topología para encontrar y ordenar todos los objetos que están en la misma profundidad que src. Informa en objs hasta max los más cercanos físicamente a src.

Devuelve

el número de objetos devueltos en objs.

0 si src es un objeto de E/S.

Nota

Esta función requiere que el objeto src tenga un conjunto de CPU.

hwloc_obj_t hwloc_get_numanode_obj_by_os_index (hwloc_topology_t topology, unsigned os_index) [inline]

Devuelve el objeto de tipo HWLOC_OBJ_NUMANODE con os_index. Esta función es útil para convertir un conjunto de nodos en los objetos de nodo NUMA que contiene. Al recuperar la vinculación actual (por ejemplo, con hwloc_get_membind() con HWLOC_MEMBIND_BYNODESET), se puede iterar sobre los bits del conjunto de nodos resultante con hwloc_bitmap_foreach_begin(), y encontrar los nodos NUMA correspondientes con esta función.

Devuelve

el objeto de nodo NUMA, o NULL si ninguno coincide.

hwloc_obj_t hwloc_get_obj_below_array_by_type (hwloc_topology_t topology, int nr, hwloc_obj_type_t * typev, unsigned * idxv) [inline]

Encuentra un objeto debajo de una cadena de objetos especificados por tipos e índices. Esta es una versión generalizada de hwloc_get_obj_below_by_type().

Los arrays typev y idxv deben contener nr tipos e índices.

Comienza desde el objeto del sistema superior y recorre los arrays typev y idxv. Para cada par de tipo e índice lógico en los arrays, busca debajo del objeto encontrado previamente para encontrar el objeto de índice-ésimo del tipo dado. Los índices se especifican dentro del padre, no dentro de todo el sistema.

Por ejemplo, si nr es 3, typev contiene NODE, PACKAGE y CORE, y idxv contiene 0, 1 y 2, devuelve el tercer objeto núcleo debajo del segundo paquete debajo del primer nodo NUMA.

Devuelve

un objeto coincidente si existe, NULL en caso contrario.

Nota

Esta función requiere que todos estos objetos y el objeto raíz tengan un conjunto de CPU.

hwloc_obj_t hwloc_get_obj_below_by_type (hwloc_topology_t topology, hwloc_obj_type_t type1, unsigned idx1, hwloc_obj_type_t type2, unsigned idx2) [inline]

Encuentra un objeto debajo de otro objeto, ambos especificados por tipos e índices. Comienza desde el objeto del sistema superior y encuentra el objeto de tipo type1 e índice lógico idx1. Luego busca debajo de este objeto y encuentra otro objeto de tipo type2 e índice lógico idx2. Los índices se especifican dentro del padre, no dentro de todo el sistema.

Por ejemplo, si type1 es PACKAGE, idx1 es 2, type2 es CORE y idx2 es 3, devuelve el cuarto objeto núcleo debajo del tercer paquete.

Devuelve

un objeto coincidente si existe, NULL en caso contrario.

Nota

Esta función requiere que estos objetos tengan un conjunto de CPU.

hwloc_obj_t hwloc_get_obj_with_same_locality (hwloc_topology_t topology, hwloc_obj_t src, hwloc_obj_type_t type, const char * subtype, const char * nameprefix, unsigned long flags)

Devuelve un objeto de un tipo diferente con la misma localidad. Si el objeto fuente src es de tipo normal o de memoria, esta función devuelve un objeto de tipo type con los mismos conjuntos de CPU y de nodos, ya sea debajo o arriba en la jerarquía.

Si el objeto fuente src es un dispositivo PCI o un dispositivo del sistema operativo dentro de un dispositivo PCI, la función puede devolver ese dispositivo PCI u otro dispositivo del sistema operativo en el mismo padre PCI. Esto puede ser útil, por ejemplo, para convertir entre dispositivos del sistema operativo como 'nvml0' o 'rsmi1' usados en estructuras de distancia hacia el dispositivo PCI, o el dispositivo del sistema operativo de CUDA u OpenCL que corresponde a la misma tarjeta física.

Si no es NULL, el parámetro subtype solo selecciona objetos cuyo atributo subtype existe y es subtype (sin distinguir mayúsculas de minúsculas), por ejemplo 'OpenCL' o 'CUDA'.

Si no es NULL, el parámetro nameprefix solo selecciona objetos cuyo atributo name existe y comienza con nameprefix (sin distinguir mayúsculas de minúsculas), por ejemplo 'rsmi' para coincidir con 'rsmi0'.

Si coinciden varios objetos, se devuelve el primero.

Esta función no recorrerá la jerarquía a través de puentes, ya que la localidad PCI puede volverse diferente. Esta función tampoco puede convertir entre objetos normales/de memoria y objetos de E/S o Misc.

flags debe ser 0 por ahora.

Devuelve

Un objeto con localidad idéntica, coincidiendo con subtype y nameprefix si existe.

NULL si no se pudo encontrar ningún objeto coincidente, o si el objeto fuente y el tipo de destino son incompatibles, por ejemplo, al convertir entre objetos de CPU y de E/S.

Detailed Description

This function is deprecated. Use hwloc_get_obj_below_array_by_type instead.

Function Documentation

hwloc_get_obj_below_array_by_type

Returns the object of type HWLOC_OBJ_PU with os_index. This function is useful for converting a CPU set into the PU objects it contains. When retrieving the current binding (e.g. with hwloc_get_cpubind()), one may iterate over the bits of the resulting CPU set with hwloc_bitmap_foreach_begin(), and find the corresponding PUs with this function.

Returns

the PU object, or NULL if none matches.
