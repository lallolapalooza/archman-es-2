pueden querer

comprimir

las topologías para reducir la huella de memoria. Este archivo ofrece una forma de manipular la diferencia entre topologías y exportarla/importarla a/desde XML. La compresión

La topología real puede reconstruirse cuando realmente se necesita aplicando la diferencia precalculada a la topología de referencia. Esta interfaz apunta a nodos muy similares. Solo se admiten diferencias muy simples entre topologías, por ejemplo

un

cambio en el tamaño de la memoria, el nombre del objeto o algún atributo de información. Diferencias más complejas como añadir o eliminar objetos no pueden representarse en las estructuras de diferencia y por lo tanto devuelven errores. Las diferencias entre conjuntos de objetos o conjuntos permitidos a nivel de topología tampoco pueden representarse. Significa que no es necesario aplicar la diferencia al mirar la organización del árbol

(cuántos

Calcula la diferencia entre 2 topologías. La diferencia se almacena como una lista de entradas hwloc_topology_diff_t que comienza en diff. Se calcula realizando un recorrido en profundidad de ambos árboles de topología simultáneamente

Si la diferencia entre 2 objetos es demasiado compleja para ser representada (por ejemplo, si algunos objetos tienen tipos diferentes, o números diferentes de hijos), se encola una entrada de diff especial de tipo HWLOC_TOPOLOGY_DIFF_TOO_COMPLEX. El cálculo del diff no continúa por debajo de estos objetos. Así que cada entrada de diff de este tipo significa que la diferencia entre dos subárboles no pudo ser

calculada.
