hg-locate(1)

Paquete: mercurial

Licencias: GPL

HG(LOCATE) HG(LOCATE)

NOMBRE

hg locate - localizar archivos que coinciden con patrones específicos (OBSOLETO)

SINOPSIS

hg locate [OPCIÓN]... [PATRÓN]...

DESCRIPCIÓN

Imprime los archivos bajo control de Mercurial en el directorio de trabajo cuyos nombres coinciden con los patrones dados.

Por defecto, este comando busca en todos los directorios del directorio de trabajo. Para buscar solo en el directorio actual y sus subdirectorios, use "--include .".

Si no se proporcionan patrones para coincidir, este comando imprime los nombres de todos los archivos bajo control de Mercurial en el directorio de trabajo.

Si desea alimentar la salida de este comando al comando "xargs", use la opción -0 tanto para este comando como para "xargs". Esto evitará el problema de que "xargs" trate archivos individuales que contienen espacios en blanco como múltiples archivos.

Consulte hg help files para un comando más versátil.

Devuelve 0 si se encuentra una coincidencia, 1 en caso contrario.

OPCIONES

-r,--rev <REV>
buscar en el repositorio como está en REV
-0, --print0
termina los nombres de archivo con NUL, para usar con xargs
-f, --fullpath
imprime rutas completas desde la raíz del sistema de archivos
-I,--include <PATRÓN[+]>
incluye nombres que coincidan con los patrones dados
-X,--exclude <PATRÓN[+]>
excluye nombres que coincidan con los patrones dados

[+] La opción marcada se puede especificar varias veces
