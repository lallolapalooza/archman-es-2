HXADDID(1) Utilidades HTML-XML HXADDID(1)

NOMBRE

hxaddid - añade IDs a elementos seleccionados

SINOPSIS

hxaddid [ -x ] [--] elem|.clase|elem.clase [ archivo-o-URL ]

DESCRIPCIÓN

El comando hxaddid copia un archivo HTML o XML a la salida estándar, añadiendo IDs de elementos a los elementos o clases especificados.

Por ejemplo, dado la entrada


<p>Un párrafo sin ID</p>

El comando


hxaddid p

producirá la siguiente salida


<p id="un-parrafo">Un párrafo sin ID</p>

Si se especifica una clase usando .clase, los IDs solo se añadirán a los elementos que contengan esa clase. Y si se especifica un elemento y una clase usando elem.clase, los IDs solo se añadirán a los elementos especificados que contengan la clase especificada.

Si dos elementos generaran naturalmente el mismo ID, se añadirá un número al nombre del ID (comenzando por 0) para asegurar que los IDs sean únicos. Los IDs no se añadirán a los elementos coincidentes que ya contengan un ID.

OPCIONES

Se admiten las siguientes opciones:

-x
Utiliza convenciones XML: los elementos vacíos se escriben con una barra al final: <IMG />. También hace que el elemento coincida sensible a mayúsculas y minúsculas.

OPERANDOS

Se admiten los siguientes operandos:

elem
El nombre del elemento a seleccionar.
.clase
El nombre de la clase a seleccionar.
elem.clase
El nombre del elemento que contiene la clase a seleccionar.
archivo-o-URL
El nombre o URL de un archivo HTML o XHTML.

ESTADO DE SALIDA

Se devuelven los siguientes valores de salida:

0
Finalización exitosa.
> 0
Ocurrió un error en el análisis de uno de los archivos HTML o XML.

MEDIO AMBIENTE

Para usar un proxy para recuperar archivos remotos, establezca las variables de entorno http_proxy o ftp_proxy. Por ejemplo, http_proxy="http://localhost:8080/"

ERRORES

Asume UTF-8 como entrada. No expande entidades de caracteres. En su lugar, canalice la entrada a través de hxunent(1) y asc2xml(1) para convertirla a UTF-8.

hxaddid intenta primero generar IDs "legibles", formando el ID a partir de las letras y dígitos encontrados en el contenido del elemento y recurre a la generación de IDs arbitrarios si no encuentra suficientes. Sin embargo, el algoritmo en esta versión es primitivo y solo da resultados razonables para letras y dígitos ASCII.

Los archivos remotos (especificados con una URL) actualmente solo son compatibles con HTTP. Los archivos protegidos con contraseña o los archivos que dependen de las "cookies" HTTP no se manejan. (Puede usar herramientas como curl(1) o wget(1) para recuperar dichos archivos.)

VER TAMBIÉN

asc2xml(1), hxprune(1), hxnormalize(1), hxnum(1), hxtoc(1), hxunent(1), xml2asc(1), UTF-8 (RFC 2279)
