DESCRIPCIÓ

N

hexer es un editor de múltiples búferes para ver y manipular archivos binarios. No se puede (ni se debe) usar para editar dispositivos de bloque, porque intenta cargar el archivo completo en un búfer (debería funcionar para disquetes). Las características más importantes de hexer son: múltiples búferes, deshacer multinivel, edición de línea de comandos con autocompletado, expresiones regulares binarias (véase más abajo). La interfaz de usuario se mantiene similar a vi, así que si sabes cómo usar vi, te resultará

fácil
empezar.

EXPRESIONES

REGULARES

En esta sección se asume que estás familiarizado con las ER (expresiones regulares). En la mayoría de las aplicaciones (egrep, vi, ...) las ER funcionan sobre líneas, lo que significa que no es posible usar una ER que contenga un salto de línea (carácter de nueva línea). En hexer, el búfer no se divide en líneas distintas y un carácter de nueva línea se considera un carácter 'normal', ahora aquí está el problema: imagina buscar "a.*b" en un archivo de 5 MB, esto tomaría mucho tiempo (podría tardar hasta varios minutos en una máquina lenta). Por eso existe un límite maxmatch (un operador de repetición coincide con como máximo maxmatch ocurrencias de su operando). El valor por defecto de maxmatch es 1024, pero puede personalizarse usando el comando :set. Para expresiones simples (expresiones para las cuales la longitud de la coincidencia puede determinarse a partir de la expresión) es posible anular el límite maxmatch duplicando el operador '*' o '+', por ejemplo "a.**b" o "foo\(bar\)\+\+".
Ten en cuenta que los especificadores de contexto '^'/'$' (principio/final de una línea) y '\<'/'\>' (principio/final de una palabra) están disponibles y realmente hacen lo que esperas. Si no quieres que los átomos '.' y '[^...]' coincidan con el carácter de nueva línea, puedes establecer la opción specialnl usando el comando :set.
Para introducir un carácter especial, puedes usar las secuencias de escape '\'-estándar de C. Para introducir un carácter usando su código octal, usa un prefijo '\o' seguido de hasta tres dígitos octales. (Los escapes octales de estilo C no están soportados, porque '\0', ... '\9' se interpretan como referencias hacia atrás a subexpresiones de la ER.) Para introducir un carácter usando su código hexadecimal, escribe un prefijo '\x' seguido de hasta dos dígitos hexadecimales; los códigos decimales pueden introducirse usando un prefijo '\d' seguido de hasta tres dígitos decimales. Es posible introducir cadenas de códigos duplicando el especificador de base, por ejemplo "\xxfe ff 5a 7e" o "\oo276 277 132 176". Ten en cuenta que tal cadena se trata como un átomo, es decir, la ER "\xxff fe*" coincide con cualquier número (< maxmatch) de repeticiones de ff fe.
Es posible usar todo tipo de escapes '\'-de carácter (escapes que representan un solo carácter) dentro de rangos '[]'. Dentro de un rango, el 'o' que selecciona una base octal para el escape puede omitirse, ya que las referencias hacia atrás dentro de un rango no tienen sentido. Al especificar un número mínimo y/o máximo de repeticiones usando el operador '\{,}', los números pueden darse en decimal (sin prefijo), octal (prefijo '0') o hexadecimal (prefijo '0x'). Si no se especifica un número máximo y el operando no es una expresión simple, se encontrarán como máximo maxmatch coi

ncide
ncias.

CALCULADOR

A

Hexer proporciona una calculadora simple (myc) capaz de todas las operaciones disponibles en C. Para introducir un comando myc simplemente introduce un signo % (porcentaje) y una expresión en notación infija. Es posible usar paréntesis. myc entiende los siguientes operadores binarios infixos (de mayor a menor prioridad): ** (potencia), * (multiplicar), / (dividir), % (módulo), + (sumar), - (restar), << (desplazar a la izquierda), >> (desplazar a la derecha), < (menor que), <= (menor o igual), > (mayor que), >= (mayor o igual), == (igual), != (no igual), & (and aritmético), | (or aritmético), ^ (xor aritmético), && (and lógico), || (or lógico), = (asignar); y los siguientes operadores prefijos unarios: - (negar, menos unario), ! (not lógico), ~ (complemento a nivel de bits). myc conoce tres tipos de datos: booleano, entero (32 bits), flotante (64 bits, equivalente a double de C). En algunas plataformas esotéricas la precisión de entero y flotante puede ser diferente. Como en C, el resultado de una división depende de los tipos de datos de los operandos. Un entero dividido por un entero da un entero. Si quieres que el resultado sea un flotante, asegúrate de que uno de los operandos sea un flotante, por ejemplo escribe 4/7. en lugar de 4/7 o a/(b+0.) en lugar de a/b. La operación de potencia devuelve un flotante si el resultado es demasiado grande para caber en un entero. El resultado de un cálculo se almacena en las variables especiales $$ y $n donde n es el número

del c
omando.
