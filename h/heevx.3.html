!> CHEEVX calcula valores propios seleccionados y, opcionalmente, vectores propios
!> de una matriz hermitiana compleja A. Los valores propios y vectores propios pueden
!> ser seleccionados especificando ya sea un rango de valores o un rango de
!> índices para los valores propios deseados.

!>                 que se buscarán.

!>          UPLO es CHARACTER*1
!>          = 'U':  El triángulo superior de A está almacenado;
!>          = 'L':  El triángulo inferior de A está almacenado.

NAME

cheevx, dsyevx, ssyevx - computes selected eigenvalues and, optionally, eigenvectors of a complex Hermitian or real symmetric matrix, respectively.

SYNOPSIS

      SUBROUTINE CHEEVX( JOBZ, RANGE, UPLO, N, A, LDA, VL, VU, IL, IU,
                        ABSTOL, M, W, Z, LDZ, WORK, LWORK, RWORK, IFAIL,
                        INFO )
      SUBROUTINE DSYEVX( JOBZ, RANGE, UPLO, N, A, LDA, VL, VU, IL, IU,
                        ABSTOL, M, W, Z, LDZ, WORK, LWORK, IWORK, IFAIL,
                        INFO )
      SUBROUTINE SSYEVX( JOBZ, RANGE, UPLO, N, A, LDA, VL, VU, IL, IU,
                        ABSTOL, M, W, Z, LDZ, WORK, LWORK, IWORK, IFAIL,
                        INFO )

DESCRIPTION

The subroutines differ only by the data types of the arguments.

In general, the precision of the eigenvalue computation of a general matrix is determined by the precision of the input data and of intermediate computations. As a result, the LAPACK routines for complex Hermitian or real symmetric matrices are provided in three variations to permit the user to choose the most appropriate precision:

C
Double precision complex (i.e. complex16)
D
Double precision real
S
Single precision real

In the specification for the subroutine, the characters `c', `d', and `s' denote the data type, according to the above.

CHEEVX computes selected eigenvalues and, optionally, eigenvectors of a complex Hermitian matrix A, and the matrix Z of eigenvectors, if requested.

The subroutine calls the following LAPACK routines as workspace:

      DSYTRD or CHEQRD
      DSYGV or CHEGV
      DSYEVR or CHEEVR

If `RANGE' = 'I', then the task is to find the M eigenvalues (and the corresponding eigenvectors) in the range IL to IU. If `RANGE' = 'V', then the task is to find the M eigenvalues (and the corresponding eigenvectors) in the range VL to VU. If `RANGE' = 'A', then the task is to find all the eigenvalues (and the corresponding eigenvectors) of the matrix.

In each case, the subroutine first reduces the matrix A to tridiagonal form, then applies a preliminary eigenvalue computation. If `RANGE' = 'A' or 'V', the eigenvalues are sorted and separated into blocks. Then, for each block, the eigenvalues and eigenvectors are computed using DSYEVR or CHEEVR.

If `RANGE' = 'I', the eigenvalues are computed directly.

Finally, if `JOBZ' = 'V', the eigenvectors are computed.

OPTIONS

This section describes the options that the user may pass to the subroutines.

JOBZ

JOBZ is CHARACTER*1

          = 'N':  Compute eigenvalues only;
          = 'V':  Compute eigenvalues and eigenvectors.

RANGE

RANGE is CHARACTER*1

          = 'A': all eigenvalues will be found.
          = 'V': all eigenvalues in the half-open interval (VL,VU]
                 will be found.
          = 'I': the IL-th through IU-th eigenvalues will be found.

UPLO

UPLO is CHARACTER*1

          = 'U':  Upper triangle of A is stored;
          = 'L':  Lower triangle of A is stored.

N

N is INTEGER

          The order of the matrix A.  N >= 0.

A

CHEEVX 

          A is COMPLEX*16 array, dimension (LDA, N)
          On entry, the Hermitian matrix A.
          On exit, A is overwritten by values generated during the
          reduction to tridiagonal form.

DSYEVX 

          A is DOUBLE PRECISION array, dimension (LDA, N)
          On entry, the symmetric matrix A.
          On exit, the lower triangle (if UPLO='L') or the upper
          triangle (if UPLO='U') of A, including the diagonal, is
          destroyed.

SSYEVX 

          A is REAL array, dimension (LDA, N)
          On entry, the symmetric matrix A.
          On exit, the lower triangle (if UPLO='L') or the upper
          triangle (if UPLO='U') of A, including the diagonal, is
          destroyed.

LDA

LDA is INTEGER

          The leading dimension of the array A.
          For CHEEVX: LDA >= max(1,N).
          For DSYEVX and SSYEVX: LDA >= max(1,N).

VL, VU, IL, IU

VL, VU are DOUBLE PRECISION (for DSYEVX) or REAL (for SSYEVX) variables.

IL, IU are INTEGER variables.

          On entry, VL and VU specify the interval to be searched for
          eigenvalues, and IL and IU specify the indices of the
          eigenvalues to be found.
          If RANGE='V', VL and VU specify the lower and upper bounds
          of the interval.
          If RANGE='I', IL and IU specify the indices of the eigenvalues
          to be found.
          Not referenced if RANGE='A'.
          For DSYEVX and SSYEVX:
          If RANGE='V', VL < VU.
          If RANGE='I', 1 <= IL <= IU <= N, if N > 0; IL = 1 and IU = 0 if N = 0.
          For CHEEVX:
          If RANGE='V', VL and VU specify the lower and upper bounds
          of the interval. The interval is open on the left and closed
          on the right: (VL, VU].
          If RANGE='I', IL and IU specify the indices of the eigenvalues
          to be found. 1 <= IL <= IU <= N, if N > 0; IL = 1 and IU = 0 if N = 0.

ABSTOL

ABSTOL is DOUBLE PRECISION (for DSYEVX) or REAL (for SSYEVX) variable.

ABSTOL is INTEGER (for CHEEVX) - this is a typo and should be REAL.

          On entry, the minimum absolute tolerance to be used when
          reordering the eigenvalues to compute the eigenvectors. An
          eigenvalue W(i) is selected if, for example,
          RANGE='V', VL < W(i) <= VU, and if
          Z(i) is the corresponding eigenvector, then
          norm(A*Z(i) - W(i)*Z(i)) / norm(Z(i)) <= ABSTOL.
          See also ABSTOL in CHEEVR, DSYEVR, SSYEVR for more details.
          If ABSTOL is less than or equal to zero, then machine epsilon
          times the machine norm of the matrix will be used in its place.
          See also ABSTOL in CHEEVR, DSYEVR, SSYEVR for more details.
          Eigenvalues will be computed most accurately when ABSTOL is
          set to twice the underflow threshold, and norms of the
          eigenvectors are computed most accurately when ABSTOL is set
          to twice the machine precision. If this routine returns with
          INFO>0, indicating that some eigenvectors did not converge, try
          setting ABSTOL to twice the underflow threshold (for DSYEVX and
          SSYEVX) or twice the machine precision (for CHEEVX).
          See "LAPACK Working Notes" for details.

M

M is INTEGER

          The total number of eigenvalues found. 0 <= M <= N.

W

CHEEVX 

          W is COMPLEX*16 array, dimension (N)
          On normal exit, the first M elements of W contain the selected
          eigenvalues, sorted in ascending order.

DSYEVX 

          W is DOUBLE PRECISION array, dimension (N)
          On normal exit, the first M elements of W contain the selected
          eigenvalues, sorted in ascending order.

SSYEVX 

          W is REAL array, dimension (N)
          On normal exit, the first M elements of W contain the selected
          eigenvalues, sorted in ascending order.

Z

CHEEVX 

          Z is COMPLEX*16 array, dimension (LDZ, max(1,M))
          If JOBZ = 'V', then if INFO = 0, the first M columns of Z
          contain the orthonormal eigenvectors of the matrix A
          corresponding to the selected eigenvalues, with the i-th
          column of Z holding the eigenvector associated with W(i).
          If an eigenvector fails to converge, then that column of Z
          contains the latest approximation to the eigenvector, and the
          index of the eigenvector is returned in IFAIL.
          If JOBZ = 'N', then Z is not referenced.

DSYEVX 

          Z is DOUBLE PRECISION array, dimension (LDZ, max(1,M))
          If JOBZ = 'V', then if INFO = 0, the first M columns of Z
          contain the orthonormal eigenvectors of the matrix A
          corresponding to the selected eigenvalues, with the i-th
          column of Z holding the eigenvector associated with W(i).
          If an eigenvector fails to converge, then that column of Z
          contains the latest approximation to the eigenvector, and the
          index of the eigenvector is returned in IFAIL.
          If JOBZ = 'N', then Z is not referenced.

SSYEVX 

          Z is REAL array, dimension (LDZ, max(1,M))
          If JOBZ = 'V', then if INFO = 0, the first M columns of Z
          contain the orthonormal eigenvectors of the matrix A
          corresponding to the selected eigenvalues, with the i-th
          column of Z holding the eigenvector associated with W(i).
          If an eigenvector fails to converge, then that column of Z
          contains the latest approximation to the eigenvector, and the
          index of the eigenvector is returned in IFAIL.
          If JOBZ = 'N', then Z is not referenced.

Note: the user must ensure that at least max(1,M) columns are supplied in the array Z; if RANGE = 'V', the exact value of M is not known in advance and an upper bound must be used.

LDZ

LDZ is INTEGER

          The leading dimension of the array Z.
          For CHEEVX: LDZ >= 1, and if JOBZ = 'V', LDZ >= max(1,N).
          For DSYEVX and SSYEVX: LDZ >= 1, and if JOBZ = 'V', LDZ >= max(1,N).

WORK

CHEEVX 

          WORK is COMPLEX*16 array, dimension (MAX(1,LWORK))
          On exit, if INFO = 0, WORK(1) returns the optimal LWORK.

DSYEVX 

          WORK is DOUBLE PRECISION array, dimension (MAX(1,LWORK))
          On exit, if INFO = 0, WORK(1) returns the optimal LWORK.

SSYEVX 

          WORK is REAL array, dimension (MAX(1,LWORK))
          On exit, if INFO = 0, WORK(1) returns the optimal LWORK.

LWORK is INTEGER

          The length of the array WORK.
          For CHEEVX: LWORK >= 1, when N <= 1; otherwise 8*N.
          For DSYEVX and SSYEVX: LWORK >= 1, when N <= 1; otherwise 8*N.
          For optimal efficiency, LWORK >= (NB+3)*N,
          where NB is the max of the blocksize for DSYTRD and DORMTR
          returned by ILAENV.

If LWORK = -1, then a workspace query is assumed; the routine only calculates the optimal size of the WORK array, returns this value as the first entry of the WORK array, and no error message related to LWORK is issued by XERBLA.

RWORK

CHEEVX 

          RWORK is DOUBLE PRECISION array, dimension (max(1, 8*N))
          This argument is used for CHEEVX only.

IWORK

DSYEVX 

          IWORK is INTEGER array, dimension (5*N)

SSYEVX 

          IWORK is INTEGER array, dimension (5*N)

IFAIL

IFAIL is INTEGER array, dimension (N)

          If JOBZ = 'V', then if INFO = 0, the first M elements of
          IFAIL are zero.  If INFO > 0, then IFAIL contains the
          indices of the eigenvectors that failed to converge.
          If JOBZ = 'N', then IFAIL is not referenced.

INFO

INFO is INTEGER

          = 0:  successful exit
          < 0:  if INFO = -i, the i-th argument had an illegal value
          > 0:  if INFO = i, then i eigenvectors failed to converge.
                Their indices are stored in array IFAIL.

ZHEEVX calcula los eigenvalores y, opcionalmente, los autovectores izquierdo y/o derecho para matrices

HE

Propósito

: 
!>
!> ZHEEVX calcula los eigenvalores seleccionados y, opcionalmente, los autovectores
!> de una matriz hermitiana compleja A.  Los eigenvalores y autovectores pueden
!> seleccionarse especificando un rango de valores o un rango de
!> índices para los eigenvalores deseados.
!
>

Parámetro

s
JOBZ 
!>          JOBZ es CHARACTER*1
!>          = 'N':  Calcular solo los eigenvalores;
!>          = 'V':  Calcular los eigenvalores y los autovectores.
!
>

RANG

E 
!>          RANGE es CHARACTER*1
!>          = 'A': se encontrarán todos los eigenvalores.
!>          = 'V': se encontrarán todos los eigenvalores en el intervalo semiabierto (VL,VU]
!>          = 'I': se encontrarán los eigenvalores del IL-ésimo al IU-ésimo.
!
>

UPL

O 
!>          UPLO es CHARACTER*1
!>          = 'U':  Se almacena el triángulo superior de A;
!>          = 'L':  Se almacena el triángulo inferior de A.
!
>

N 
!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!
>

A 
!>          A es un array COMPLEX*16, dimensión (LDA, N)
!>          En la entrada, la matriz hermitiana A.  Si UPLO = 'U', la
!>          parte triangular superior principal N-por-N de A contiene la
!>          parte triangular superior de la matriz A.  Si UPLO = 'L',
!>          la parte triangular inferior principal N-por-N de A contiene
!>          la parte triangular inferior de la matriz A.
!>          En la salida, el triángulo inferior (si UPLO='L') o el triángulo
!>          superior (si UPLO='U') de A, incluyendo la diagonal, es
!>          destruido.
!
>

!>          La dimensión principal del array A.  LDA >= max(1,N).
!

!>          se buscarán los eigenvalores. VL < VU.
!>          No se referencia si RANGE = 'A' o 'I'.
!
>

V

U 
!>          VU es DOUBLE PRECISION
!>          Si RANGE='V', el límite superior del intervalo donde
!>          se buscarán los eigenvalores. VL < VU.

I

L 
!>          IL es INTEGER

!>          No se referencia si RANGE = 'A' o 'V'.

ABSTO

L 
!>          ABSTOL es DOUBLE PRECISION
!>          La abtolerancia absoluta de error para los eigenvalores.
!>          Un eigenvalor aproximado se acepta como convergido
!>          cuando se determina que yace en un intervalo [a,b]
!>          de ancho menor o igual a
!>
!>                  ABSTOL + EPS *   max( |a|,|b| ) ,
!>
!>          donde EPS es la precisión de la máquina. Si ABSTOL es menor o
!>          igual a cero, entonces se usará  EPS*|T|  en su lugar,
!>          donde |T| es la norma 1 de la matriz tridiagonal obtenida
!>      al reducir A a forma tridiagonal.
!>
!>          Los eigenvalores se calcularán con mayor precisión cuando ABSTOL
!>          se establezca al doble del umbral de desbordamiento inferior 2*DLAMCH('S'), no a cero.
!>          Si esta rutina retorna con INFO>0, indicando que algunos
!>      autovectores no convergieron, intente establecer ABSTOL a
!>          2*DLAMCH('S').
!>
!>          Ver  por Demmel y
!>          Kahan, LAPACK Working Note #3.
!
>

!>          M es INTEGER
!>          El número total de eigenvalores encontrados.  0 <= M <= N.

!>          contiene la última aproximación al autovector, y el
!>          índice del autovector se retorna en IFAIL.
!>          Si JOBZ = 'N', entonces Z no se referencia.
!>          Nota: el usuario debe asegurarse de que se proporcionen al menos max(1,M) columnas
!>          en el arreglo Z; si RANGE = 'V', el valor exacto de M
