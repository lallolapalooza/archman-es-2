NOMBRE

template - Generar, guardar y enviar plantillas de mensajes

SINOPSIS

template [-h|--help] <subcomandos>

DESCRIPCIÓN

Genera, guarda y envía plantillas de mensajes.

Una plantilla es una versión editable de un mensaje (cabeceras + cuerpo). Utiliza un lenguaje específico llamado MML que te permite adjuntar archivos o cifrar contenido. Este subcomando te permite gestionarlas.

Más información sobre MML en: https://crates.io/crates/mml-lib.

OPCIONES

-h, --help
Imprime la ayuda (ver un resumen con '-h')

SUBCOMANDOS

template-write(1)
Genera una plantilla para escribir un nuevo mensaje desde cero
template-reply(1)
Genera una plantilla para responder a un mensaje
template-forward(1)
Genera una plantilla para reenviar un mensaje
template-save(1)
Guarda una plantilla en una carpeta
template-send(1)
Envía una plantilla
template-help(1)
Imprime este mensaje o la ayuda del subcomando o subcomandos dados
