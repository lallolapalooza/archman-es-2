NOMBRE

hid-replay - Reproducción de dispositivos de entrada HID a través de uhid

SINOPSIS

hid-replay [--verbose] [NOMBRE_ARCHIVO]

OPCIONES

--verbose
Habilita la salida de depuración

DESCRIPCIÓN

hid-replay crea un dispositivo HID virtual basado en el archivo grabado, usualmente grabado por hid-recorder(1). Este dispositivo se comporta como si estuviera conectado físicamente al sistema. Todos los eventos del archivo grabado se reproducen en tiempo real.

hid-replay es una herramienta de depuración de bajo nivel. Utiliza el modelo del kernel uhid para crear el dispositivo y todos los datos son procesados por el módulo del kernel HID correspondiente al dispositivo.

hid-replay necesita poder escribir en /dev/uhid; normalmente esto significa que debe ejecutarse como root.

FORMATO DEL ARCHIVO

Los archivos compatibles con hid-replay tienen la siguiente sintaxis:

•
Las líneas de comentario # se ignoran al analizar
•
D: el índice del dispositivo, solo se usa al grabar múltiples dispositivos
•
R: La longitud del descriptor de reporte en bytes, seguida de los bytes del descriptor de reporte en hexadecimal
•
N: el nombre del dispositivo
•
P: ruta física
•
I: bus vendor_id product_id
•
E: marca de tiempo tamaño reporte en hexadecimal

PRECAUCIÓN

hid-replay es un inyector de eventos de muy bajo nivel. Para que el dispositivo virtual sea manejado por el módulo del kernel HID correcto, hid-replay simula que el dispositivo está en el bus original (USB, I2C o BT). Por lo tanto, si el módulo del kernel en uso tiene que escribir de vuelta al dispositivo, el kernel puede tener un error (oops) si el módulo intenta comunicarse directamente con la capa física.

Asegúrese de usar este programa con módulos HID amigables que confíen únicamente en las devoluciones de llamada genéricas de HID.

CÓDIGO DE SALIDA

hid-replay devuelve 1 en caso de error.

VER TAMBIÉN
