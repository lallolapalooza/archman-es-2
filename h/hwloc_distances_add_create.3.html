Descripción detallada

La forma habitual de añadir distancias es:

hwloc_distances_add_handle_t handle;
int err = -1;
handle = hwloc_distances_add_create(topology, "nombre", kind, 0);
if (handle) {
  err = hwloc_distances_add_values(topology, handle, nbobjs, objs, values, 0);
  if (!err)
    err = hwloc_distances_add_commit(topology, handle, flags);
}


Si err es 0 al final, entonces la adición fue exitosa.

typedef void* hwloc_distances_add_handle_t

Identificador para una nueva estructura de distancias durante su adición a la topología.

Documentación de tipos de enumeración

enum hwloc_distances_add_flag_e

Banderas para añadir nuevas distancias a una topología.

Enumerador

HWLOC_DISTANCES_ADD_FLAG_GROUP
Intenta agrupar objetos basándose en la nueva información de distancia proporcionada. La agrupación solo se realiza cuando la estructura de distancias contiene latencias, y cuando todos los objetos son del mismo tipo.
HWLOC_DISTANCES_ADD_FLAG_GROUP_INACCURATE
Si se agrupa, considera los valores de distancia como inexactos y relaja las comparaciones durante los algoritmos de agrupación. La precisión real puede ser modificada a través de la variable de entorno HWLOC_GROUPING_ACCURACY (ver Variables de Entorno).

Documentación de funciones

int hwloc_distances_add_commit (hwloc_topology_t topology, hwloc_distances_add_handle_t handle, unsigned long flags)

Confirma una nueva estructura de distancias. Esta función finaliza la estructura de distancias y la inserta en la topología.

El parámetro handle fue devuelto previamente por hwloc_distances_add_create(). Luego, los objetos y valores se especificaron con hwloc_distances_add_values().

flags configura el comportamiento de la función usando un conjunto opcional OR'ed de hwloc_distances_add_flag_e. Puede ser utilizado para solicitar la agrupación de objetos existentes basándose en las distancias.

En caso de error, la estructura temporal de distancias y su contenido se destruyen.

Retorna

0 en caso de éxito.

-1 en caso de error.

hwloc_distances_add_handle_t hwloc_distances_add_create (hwloc_topology_t topology, const char * name, unsigned long kind, unsigned long flags)

Crea una nueva estructura de distancias vacía. Crea una estructura de distancias vacía para ser rellenada con hwloc_distances_add_values() y luego confirmada con hwloc_distances_add_commit().

El parámetro name es opcional, puede ser NULL. De lo contrario, se copiará internamente y el llamador podrá liberarlo más tarde.

kind especifica el tipo de distancia como un conjunto OR'ed de hwloc_distances_kind_e. Solo se puede dar un tipo de significado y un tipo de procedencia si es apropiado (por ejemplo, HWLOC_DISTANCES_KIND_MEANS_BANDWIDTH y HWLOC_DISTANCES_KIND_FROM_USER). El tipo HWLOC_DISTANCES_KIND_HETEROGENEOUS_TYPES se establecerá automáticamente según los objetos que tengan tipos diferentes en hwloc_distances_add_values().

flags debe ser 0 por ahora.

Retorna

Un hwloc_distances_add_handle_t que luego deberá pasarse a hwloc_distances_add_values() y hwloc_distances_add_commit().

NULL en caso de error.

int hwloc_distances_add_values (hwloc_topology_t topology, hwloc_distances_add_handle_t handle, unsigned nbobjs, hwloc_obj_t * objs, hwloc_uint64_t * values, unsigned long flags)

Especifica los objetos y valores en una nueva estructura de distancias vacía. Especifica los objetos y valores para una nueva estructura de distancias que fue devuelta como identificador por hwloc_distances_add_create(). La estructura debe ser luego confirmada con hwloc_distances_add_commit().

El número de objetos es nbobjs y el array de objetos es objs. Los valores de distancia se almacenan como un array unidimensional en values. La distancia del objeto i al objeto j está en la posición i*nbobjs+j.

nbobjs debe ser al menos 2.

Los arrays objs y values se copiarán internamente, y el llamador podrá liberarlos más tarde.

En caso de error, la estructura temporal de distancias y su contenido se destruyen.

flags debe ser 0 por ahora.

Retorna

0 en caso de éxito.

-1 en caso de error.
