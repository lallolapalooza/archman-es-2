NOMBRE

halo - dibuja patrones circulares

SINOPSIS

halo [--display host:display.screen] [--foreground color] [--background color] [--window] [--root] [--window-id numero][--mono] [--install] [--visual visual] [--count int] [--delay usecs] [--mode seuss | ramp | random ] [--animate] [--colors entero] [--fps]

DESCRIPCIÓN

El programa halo dibuja patrones geniales basados en círculos.

OPCIONES

halo acepta las siguientes opciones:

--window
Dibuja en una ventana recién creada. Esta es la opción predeterminada.
--root
Dibuja en la ventana raíz.
--window-id numero
Dibuja en la ventana especificada.
--mono
Si se está en una pantalla a color, simula que se está en una pantalla monocromática.
--install
Instala un mapa de colores privado para la ventana.
--visual visual
Especifica qué visual usar. Los valores válidos son el nombre de una clase de visual, o el número de identificación (decimal o hexadecimal) de un visual específico.
--count entero
Cuántos círculos dibujar. El valor predeterminado es 0, lo que significa aleatorio.
--mode seuss | ramp | random
En el modo seuss, se dibujarán curvas rayadas alternas.

En el modo ramp, se dibujará una rampa de color.

random significa elegir el modo aleatoriamente.

--delay microsegundos
Cuánto retraso se introducirá entre los pasos de la animación. El valor predeterminado es 100000, o aproximadamente 0.1 segundos.
--colors entero
Cuántos colores usar. El valor predeterminado es 100.
--animate
Si se especifica, los puntos centrales de los círculos rebotarán. De lo contrario, los círculos se dibujarán una vez, se borrarán y se dibujará un nuevo conjunto de círculos.
--fps
Muestra la tasa de fotogramas actual y la carga de la CPU.

AMBIENTE

DISPLAY
para obtener el host y el número de pantalla predeterminados.
XENVIRONMENT
para obtener el nombre de un archivo de recursos que anula los recursos globales almacenados en la propiedad RESOURCE_MANAGER.
XSCREENSAVER_WINDOW
El ID de la ventana a usar con --root.
