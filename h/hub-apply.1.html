NOMBRE

hub-apply - Descarga un parche de GitHub y aplícalo localmente.

SINOPSIS

hub apply URL-DE-GITHUB

OPCIONES

URL-DE-GITHUB

Una URL a una solicitud de extracción o confirmación en GitHub.

EJEMPLOS

$ hub apply https://github.com/jingweno/gh/pull/55
> curl https://github.com/jingweno/gh/pull/55.patch -o /tmp/55.patch
> git apply /tmp/55.patch
