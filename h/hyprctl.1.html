NOMBRE

hyprctl - Utilidad para controlar partes de Hyprland desde una CLI o un script

SINOPSIS

hyprctl [(opt)flags] [comando] [(opt)args]

DESCRIPCIÓN

hyprctl es una utilidad para controlar algunas partes del compositor desde una CLI o un script.

COMANDOS DE CONTROL

dispatch

Llama a un despachador con un argumento.

Debe haber un argumento. Para despachadores sin parámetros, puede ser cualquier cosa.

Retorna: ok en caso de éxito, y un mensaje de error en caso de fallo.

Ejemplos:
hyprctl dispatch exec kitty

hyprctl dispatch pseudo x

keyword

Establece una palabra clave de configuración dinámicamente.

Retorna: ok en caso de éxito, y un mensaje de error en caso de fallo.

Ejemplos:
hyprctl keyword bind SUPER,0,pseudo

hyprctl keyword general:border_size 10

reload

Fuerza una recarga del archivo de configuración.

kill

Entra en modo de matar, donde puedes matar una aplicación haciendo clic en ella. Puedes salir presionando ESCAPE.

COMANDOS DE INFORMACIÓN

version

Imprime la versión de Hyprland, las flags, el commit y la rama de compilación.

monitors

Lista todas las salidas con sus propiedades.

workspaces

Lista todos los espacios de trabajo con sus propiedades.

clients

Lista todas las ventanas con sus propiedades.

devices

Lista todos los dispositivos de entrada conectados.

activewindow

Retorna el nombre de la ventana activa.

layers

Lista todas las capas.

splash

Retorna la pantalla de bienvenida aleatoria actual.

OPCIONES

--batch

Especifica un lote de comandos para ejecutar.

Ejemplo:
hyprctl --batch "keyword general:border_size 2 ; keyword general:gaps_out 20"

; separa los comandos.

-j

Genera información en JSON.
