Paquete: mercurial

Licencias: GPL

HG(COMMIT) HG(COMMIT)

NOMBRE

hg commit - confirma los archivos especificados o todos los cambios pendientes

SINOPSIS

hg commit [OPCIÓN]... [ARCHIVO]...

DESCRIPCIÓN

Confirma los cambios en los archivos dados en el repositorio. A diferencia de un SCM centralizado, esta operación es local. Consulta hg push para ver una forma de distribuir activamente tus cambios.

Si se omite una lista de archivos, se confirmarán todos los cambios informados por hg status.

Si estás confirmando el resultado de una fusión, no proporciones nombres de archivo ni filtros -I/-X.

Si no se especifica un mensaje de confirmación, Mercurial iniciará tu editor configurado donde podrás introducir un mensaje. En caso de que tu confirmación falle, encontrarás una copia de seguridad de tu mensaje en .hg/last-message.txt.

La opción --close-branch se puede usar para marcar la cabeza de la rama actual como cerrada. Cuando todas las cabezas de una rama estén cerradas, la rama se considerará cerrada y ya no se listará.

La opción --amend se puede usar para modificar el padre del directorio de trabajo con una nueva confirmación que contenga los cambios en el padre además de los informados actualmente por hg status, si los hay. El cambio anterior se almacena en un paquete de copia de seguridad en .hg/strip-backup (consulta hg help bundle y hg help unbundle sobre cómo restaurarlo).

El mensaje, el usuario y la fecha se toman de la confirmación modificada a menos que se especifiquen. Cuando no se especifica un mensaje en la línea de comandos, el editor se abrirá con el mensaje de la confirmación modificada.

No es posible modificar cambios públicos (consulta hg help phases) ni cambios que tengan hijos.

Consulta hg help dates para ver una lista de los formatos válidos para -d/--date.

Devuelve 0 si tiene éxito, 1 si no hay cambios.

Ejemplos:

  • confirmar todos los archivos que terminan en .py: 
    hg commit --include "set:**.py"
  • confirmar todos los archivos no binarios: 
    hg commit --exclude "set:binary()"
  • modificar la confirmación actual y establecer la fecha a ahora: 
    hg commit --amend --date now

OPCIONES

-A, --addremove
marcar nuevos/faltantes archivos como añadidos/eliminados antes de confirmar
--close-branch
marcar la cabeza de una rama como cerrada
--amend
modificar el padre del directorio de trabajo
-s, --secret
usar la fase secreta para confirmar
--draft
usar la fase draft para confirmar
-e, --edit
invocar editor en mensajes de confirmación
--force-close-branch
cerrar forzadamente una rama desde un cambio que no es cabeza (AVANZADO)
-i, --interactive
usar modo interactivo
-I,--include <PATRÓN[+]>
incluir nombres que coincidan con los patrones dados
-X,--exclude <PATRÓN[+]>
excluir nombres que coincidan con los patrones dados
-m,--message <TEXTO>
usar texto como mensaje de confirmación
-l,--logfile <ARCHIVO>
leer mensaje de confirmación desde archivo
-d,--date <FECHA>
registrar la fecha especificada como fecha de confirmación
-u,--user <USUARIO>
registrar el usuario especificado como confirmador
-S, --subrepos
recursar en subrepositorios

[+] la opción marcada se puede especificar varias veces
