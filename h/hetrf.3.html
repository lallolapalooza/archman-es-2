subrutina chetrf (character uplo, integer n, complex, dimension( lda, * ) a, integer lda, integer, dimension( * ) ipiv, complex, dimension( * ) work, integer lwork, integer info)

CHETRF

Propósito:

!>
!> CHETRF calcula la factorización de una matriz hermitiana compleja A
!> usando el método de pivote diagonal de Bunch-Kaufman. La forma de la
!> factorización es
!>
!>    A = U*D*U**H  o  A = L*D*L**H
!>
!> donde U (o L) es un producto de matrices de permutación y triangulares
!> unitarias superiores (inferiores), y D es hermitiana y de bloques
!> diagonales con bloques diagonales de 1x1 y 2x2.
!>
!> Esta es la versión bloqueada del algoritmo, que llama a BLAS de Nivel 3.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          = 'U': se almacena el triángulo superior de A;
!>          = 'L': se almacena el triángulo inferior de A.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

A

!>          A es un arreglo COMPLEX, dimensión (LDA,N)
!>          En la entrada, la matriz hermitiana A. Si UPLO = 'U', la parte
!>          triangular superior principal N por N de A contiene la parte
!>          triangular superior de la matriz A, y la parte estrictamente
!>          triangular inferior de A no se referencia. Si UPLO = 'L', la
!>          parte triangular inferior principal N por N de A contiene la
!>          parte triangular inferior de la matriz A, y la parte
!>          estrictamente triangular superior de A no se referencia.
!>
!>          En la salida, la matriz de bloques diagonales D y los
!>          multiplicadores usados para obtener el factor U o L (ver más
!>          abajo para más detalles).
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del arreglo A.  LDA >= max(1,N).
!>

IPIV

!>          IPIV es un arreglo INTEGER, dimensión (N)
!>          Detalles de los intercambios y de la estructura de bloques de D.
!>          Si IPIV(k) > 0, entonces las filas y columnas k e IPIV(k) fueron
!>          intercambiadas y D(k,k) es un bloque diagonal de 1x1.
!>          Si UPLO = 'U' y IPIV(k) = IPIV(k-1) < 0, entonces las filas y
!>          columnas k-1 y -IPIV(k) fueron intercambiadas y D(k-1:k,k-1:k)
!>          es un bloque diagonal de 2x2.  Si UPLO = 'L' y IPIV(k) =
!>          IPIV(k+1) < 0, entonces las filas y columnas k+1 y -IPIV(k) fueron
!>          intercambiadas y D(k:k+1,k:k+1) es un bloque diagonal de 2x2.
!>

WORK

!>          WORK es un arreglo COMPLEX, dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La longitud de WORK. LWORK >= 1. Para un mejor rendimiento
!>          LWORK >= N*NB, donde NB es el tamaño de bloque devuelto por ILAENV.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>          > 0:  si INFO = i, D(i,i) es exactamente cero. La factorización
!>                ha sido completada, pero la matriz de bloques diagonales D es
!>                exactamente singular, y ocurrirá una división por cero si se
!>                usa para resolver un sistema de ecuaciones.
!>

Autor

Univ. de Tennessee

Univ. de California Berkeley

Univ. de Colorado Denver

NAG Ltd.

Más detalles:

!>
!>  Si UPLO = 'U', entonces A = U*D*U**H, donde
!>     U = P(n)*U(n)* ... *P(k)U(k)* ...,
!>  es decir, U es un producto de términos P(k)*U(k), donde k disminuye de n a
!>  1 en pasos de 1 o 2, y D es una matriz de bloques diagonales con bloques
!>  diagonales de 1x1 y 2x2 D(k).  P(k) es una matriz de permutación
!>  definida por IPIV(k), y U(k) es una matriz triangular unitaria superior,
!>  tal que si el bloque diagonal D(k) es de orden s (s = 1 o 2), entonces
!>
!>             (   I    v    0   )   k-s
!>     U(k) =  (   0    I    0   )   s
!>             (   0    0    I   )   n-k
!>                k-s   s   n-k
!>
!>  Si s = 1, D(k) sobrescribe A(k,k), y v sobrescribe A(1:k-1,k).
!>  Si s = 2, el triángulo superior de D(k) sobrescribe A(k-1,k-1), A(k-1,k),
!>  y A(k,k), y v sobrescribe A(1:k-2,k-1:k).
!>
!>  Si UPLO = 'L', entonces A = L*D*L**H, donde
!>     L = P(1)*L(1)* ... *P(k)*L(k)* ...,
!>  es decir, L es un producto de términos P(k)*L(k), donde k aumenta de 1 a
!>  n en pasos de 1 o 2, y D es una matriz de bloques diagonales con bloques
!>  diagonales de 1x1 y 2x2 D(k).  P(k) es una matriz de permutación
!>  definida por IPIV(k), y L(k) es una matriz triangular unitaria inferior,
!>  tal que si el bloque diagonal D(k) es de orden s (s = 1 o 2), entonces
!>
!>             (   I    0     0   )  k-1
!>     L(k) =  (   0    I     0   )  s
!>             (   0    v     I   )  n-k-s+1
!>                k-1   s  n-k-s+1
!>
!>  Si s = 1, D(k) sobrescribe A(k,k), y v sobrescribe A(k+1:n,k).
!>  Si s = 2, el triángulo inferior de D(k) sobrescribe A(k,k), A(k+1,k),
!>  y A(k+1,k+1), y v sobrescribe A(k+2:n,k:k+1).
!>

Description


This routine uses the Bunch-Kaufman diagonal pivoting method to compute
    the factorization of a symmetric matrix.




CSYTRF


Purpose:




!>
!> CSYTRF computes the factorization of a complex symmetric matrix A using
!> the Bunch-Kaufman diagonal pivoting method. The form of the factorization is
!>
!>    A = U**T*D*U  or  A = L*D*L**T
!>
!> where U (or L) is a product of permutation and unit upper (lower)
!> triangular matrices, and D is symmetric and block diagonal with
!> 1-by-1 and 2-by-2 diagonal blocks.
!>
!> This is the blocked version of the algorithm, calling Level 3 BLAS.
!> 




Parameters


UPLO

!>          UPLO is CHARACTER*1
!>          = 'U':  Upper triangle of A is stored;
!>          = 'L':  Lower triangle of A is stored.
!> 


N


!>          N is INTEGER
!>          The order of the matrix A.  N >= 0.
!> 


A


!>          A is COMPLEX array, dimension (LDA,N)
!>          On entry, the symmetric matrix A. If UPLO = 'U', the leading
!>          N-by-N upper triangular part of A contains the upper
!>          triangular part of the matrix A, and the strictly lower
!>          triangular part of A is not referenced. If UPLO = 'L', the
!>          leading N-by-N lower triangular part of A contains the lower
!>          triangular part of the matrix A, and the strictly upper
!>          triangular part of A is not referenced.
!>
!>          On exit, the block diagonal matrix D and the multipliers used
!>          to obtain the factor U or L (see below for further details).
!> 


LDA


!>          LDA is INTEGER
!>          The leading dimension of the array A.  LDA >= max(1,N).
!> 


IPIV


!>          IPIV is INTEGER array, dimension (N)
!>          Details of the interchanges and the block structure of D.
!>          If IPIV(k) > 0, then rows and columns k and IPIV(k) were
!>          interchanged and D(k,k) is a 1-by-1 diagonal block.
!>          If UPLO = 'U' and IPIV(k) = IPIV(k-1) < 0, then rows and
!>          columns k-1 and -IPIV(k) were interchanged and D(k-1:k,k-1:k)
!>          is a 2-by-2 diagonal block.  If UPLO = 'L' and IPIV(k) =
!>          IPIV(k+1) < 0, then rows and columns k+1 and -IPIV(k) were
!>          interchanged and D(k:k+1,k:k+1) is a 2-by-2 diagonal block.
!> 


WORK


!>          WORK is COMPLEX array, dimension (MAX(1,LWORK))
!>          On exit, if INFO = 0, WORK(1) returns the optimal LWORK.
!> 


LWORK


!>          LWORK is INTEGER
!>          The length of WORK.  LWORK >=1.  For best performance
!>          LWORK >= N*NB, where NB is the block size returned by ILAENV.
!>
!>          If LWORK = -1, then a workspace query is assumed; the routine
!>          only calculates the optimal size of the WORK array, returns
!>          this value as the first entry of the WORK array, and no error
!>          message related to LWORK is issued by XERBLA.
!> 


INFO


!>          INFO is INTEGER
!>          = 0:  successful exit
!>          < 0:  if INFO = -i, the i-th argument had an illegal value
!>          > 0:  if INFO = i, D(i,i) is exactly zero.  The factorization
!>                has been completed, but the block diagonal matrix D is
!>                exactly singular, and division by zero will occur if it
!>                is used to solve a system of equations.
!> 




Author


Univ. of Tennessee

Univ. of California Berkeley


Univ. of Colorado Denver


NAG Ltd.




Further Details:




!>
!>  If UPLO = 'U', then A = U*D*U**T, where
!>     U = P(n)*U(n)* ... *P(k)U(k)* ...,
!>  i.e., U is a product of terms P(k)*U(k), where k decreases from n to
!>  1 in steps of 1 or 2, and D is a block diagonal matrix with 1-by-1
!>  and 2-by-2 diagonal blocks D(k).  P(k) is a permutation matrix as
!>  defined by IPIV(k), and U(k) is a unit upper triangular matrix, such
!>  that if the diagonal block D(k) is of order s (s = 1 or 2), then
!>
!>             (   I    v    0   )   k-s
!>     U(k) =  (   0    I    0   )   s
!>             (   0    0    I   )   n-k
!>                k-s   s   n-k
!>
!>  If s = 1, D(k) overwrites A(k,k), and v overwrites A(1:k-1,k).
!>  If s = 2, the upper triangle of D(k) overwrites A(k-1,k-1), A(k-1,k),
!>  and A(k,k), and v overwrites A(1:k-2,k-1:k).
!>
!>  If UPLO = 'L', then A = L*D*L**T, where
!>     L = P(1)*L(1)* ... *P(k)*L(k)* ...,
!>  i.e., L is a product of terms P(k)*L(k), where k increases from 1 to
!>  n in steps of 1 or 2, and D is a block diagonal matrix with 1-by-1
!>  and 2-by-2 diagonal blocks D(k).  P(k) is a permutation matrix as
!>  defined by IPIV(k), and L(k) is a unit lower triangular matrix, such
!>  that if the diagonal block D(k) is of order s (s = 1 or 2), then
!>
!>             (   I    0     0   )  k-1
!>     L(k) =  (   0    I     0   )  s
!>             (   0    v     I   )  n-k-s+1
!>                k-1   s  n-k-s+1
!>
!>  If s = 1, D(k) overwrites A(k,k), and v overwrites A(k+1:n,k).
!>  If s = 2, the lower triangle of D(k) overwrites A(k,k), A(k+1,k),
!>  and A(k+1,k+1), and v overwrites A(k+2:n,k:k+1).
!>
