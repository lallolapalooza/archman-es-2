CHESV_RK calcula la solución al sistema de ecuaciones lineales A * X = B para matrices SY

Propósito:

!> CHESV_RK calcula la solución a un sistema complejo de ecuaciones lineales
!> A * X = B, donde A es una matriz Hermitiana N-por-N
!> y X y B son matrices N-por-NRHS.
!>
!> Se utiliza el método de pivoteo diagonal de Bunch-Kaufman (rook)
!> acotado para factorizar A como
!>    A = P*U*D*(U**H)*(P**T),  si UPLO = 'U', o
!>    A = P*L*D*(L**H)*(P**T),  si UPLO = 'L',
!> donde U (o L) es una matriz triangular superior (o inferior) unitaria,
!> U**H (o L**H) es la conjugada de U (o L), P es una matriz de permutación,
!> P**T es la transpuesta de P, y D es Hermitiana y diagonal por bloques
!> con bloques diagonales de 1x1 y 2x2.
!>
!> Se llama a CHETRF_RK para calcular la factorización de una matriz Hermitiana
!> compleja. La forma factorizada de A se utiliza luego para resolver
!> el sistema de ecuaciones A * X = B llamando a la rutina BLAS3 CHETRS_3.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          Especifica si la parte triangular superior o inferior de la
!>          matriz Hermitiana A está almacenada:
!>          = 'U':  Se almacena el triángulo superior de A;
!>          = 'L':  Se almacena el triángulo inferior de A.
!>

N

!>          N es INTEGER
!>          El número de ecuaciones lineales, es decir, el orden de
!>          la matriz A.  N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de lados derechos, es decir, el número de columnas
!>          de la matriz B.  NRHS >= 0.
!>

A

!>          A es array de tipo COMPLEX, dimensión (LDA,N)
!>          En la entrada, la matriz Hermitiana A.
!>            Si UPLO = 'U': la parte triangular superior N-por-N
!>            de A contiene la parte triangular superior de la matriz A,
!>            y la parte estrictamente triangular inferior de A no
!>            se referencia.
!>
!>            Si UPLO = 'L': la parte triangular inferior N-por-N
!>            de A contiene la parte triangular inferior de la matriz A,
!>            y la parte estrictamente triangular superior de A no
!>            se referencia.
!>
!>          En la salida, si INFO = 0, el diagonal de la matriz
!>          diagonal por bloques D y los factores U o L calculados por
!>          CHETRF_RK:
!>            a) SÓLO los elementos diagonales de la matriz Hermitiana
!>               diagonal por bloques D en la diagonal de A, es decir,
!>               D(k,k) = A(k,k);
!>               (los elementos superdiagonales (o subdiagonales) de D
!>                se almacenan en la salida en el array E), y
!>            b) Si UPLO = 'U': factor U en la parte superdiagonal de A.
!>               Si UPLO = 'L': factor L en la parte subdiagonal de A.
!>
!>          Para más información, consulte la descripción de la rutina CHETRF_RK.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

E

!>          E es array de tipo COMPLEX, dimensión (N)
!>          En la salida, contiene la salida calculada por la rutina de
!>          factorización CHETRF_RK, es decir, los elementos superdiagonales
!>          (o subdiagonales) de la matriz Hermitiana diagonal por bloques D
!>          con bloques diagonales de 1x1 o 2x2, donde
!>          Si UPLO = 'U': E(i) = D(i-1,i), i=2:N, E(1) se establece a 0;
!>          Si UPLO = 'L': E(i) = D(i+1,i), i=1:N-1, E(N) se establece a 0.
!>
!>          NOTA: Para un bloque diagonal de 1x1 D(k), donde
!>          1 <= k <= N, el elemento E(k) se establece a 0 en ambos
!>          casos UPLO = 'U' o UPLO = 'L'.
!>
!>          Para más información, consulte la descripción de la rutina CHETRF_RK.
!>

IPIV

!>          IPIV es array de tipo INTEGER, dimensión (N)
!>          Detalles de los intercambios y la estructura de bloques de D,
!>          tal como determina CHETRF_RK.
!>
!>          Para más información, consulte la descripción de la rutina CHETRF_RK.
!>

B

!>          B es array de tipo COMPLEX, dimensión (LDB,NRHS)
!>          En la entrada, la matriz del lado derecho B de N-por-NRHS.
!>          En la salida, si INFO = 0, la matriz solución X de N-por-NRHS.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B.  LDB >= max(1,N).
!>

WORK

!>          WORK es array de tipo COMPLEX, dimensión ( MAX(1,LWORK) ).
!>          Array de trabajo utilizado en la etapa de factorización.
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La longitud de WORK.  LWORK >= 1. Para un rendimiento óptimo
!>          de la etapa de factorización, LWORK >= max(1,N*NB), donde NB es
!>          el tamaño de bloque óptimo para CHETRF_RK.
!>
!>          Si LWORK = -1, se asume una consulta de espacio de trabajo;
!>          la rutina solo calcula el tamaño óptimo del array WORK
!>          para la etapa de factorización, devuelve este valor como
!>          la primera entrada del array WORK, y XERBLA no emite ningún
!>          mensaje de error relacionado con LWORK.
!>

INFO

!>          INFO es INTEGER
!>          = 0: finalización exitosa
!>
!>          < 0: Si INFO = -k, el k-ésimo argumento tenía un valor ilegal
!>
!>          > 0: Si INFO = k, la matriz A es singular, porque:
!>                 Si UPLO = 'U': la columna k en la parte
!>                 triangular superior de A contiene todos ceros.
!>                 Si UPLO = 'L': la columna k en la parte
!>                 triangular inferior de A contiene todos ceros.
!>
!>               Por lo tanto, D(k,k) es exactamente cero, y los elementos
!>               superdiagonales de la columna k de U (o los elementos
!>               subdiagonales de la columna k de L) son todos ceros. La
!>               factorización se ha completado, pero la matriz diagonal
!>               por bloques D es exactamente singular, y ocurrirá una
!>               división por cero si se utiliza para resolver un sistema
!>               de ecuaciones.
!>
!>               NOTA: INFO solo almacena la primera ocurrencia
!>               de una singularidad; cualquier ocurrencia posterior de
!>               singularidad no se almacena en INFO, aunque la factorización
!>               siempre se completa.
!>

NAME

DSYSV_RK, SSYSV_RK — solve a real system of linear equations with a symmetric matrix using the rook-bounded Bunch-Kaufman diagonal pivoting method

SYNOPSIS

    SUBROUTINE DSYSV_RK( UPLO, N, NRHS, A, LDA, E, IPIV, B, LDB, WORK,
                         LWORK, INFO )
    CHARACTER(LEN=1) UPLO
    INTEGER          N, NRHS, LDA, LDB, LWORK, INFO
    DOUBLE PRECISION A( LDA, * ), E( * ), WORK( * )
    INTEGER          IPIV( * )

    SUBROUTINE SSYSV_RK( UPLO, N, NRHS, A, LDA, E, IPIV, B, LDB, WORK,
                         LWORK, INFO )
    CHARACTER(LEN=1) UPLO
    INTEGER          N, NRHS, LDA, LDB, LWORK, INFO
    REAL             A( LDA, * ), E( * ), WORK( * )
    INTEGER          IPIV( * )

DESCRIPTION

The routines DSYSV_RK and SSYSV_RK compute the solution to a real system of linear equations A * X = B, where A is an N-by-N symmetric matrix and X and B are N-by-NRHS matrices.

The bounded Bunch-Kaufman (rook) diagonal pivoting method is used to factor A as

A = P*U*D*(UT)*(PT), if UPLO = 'U', or

A = P*L*D*(LT)*(PT), if UPLO = 'L',

where U (or L) is unit upper (or lower) triangular matrix, UT (or LT) is the transpose of U (or L), P is a permutation matrix, PT is the transpose of P, and D is symmetric and block diagonal with 1-by-1 and 2-by-2 diagonal blocks.

DSYTRF_RK and SSYTRF_RK are called to compute the factorization of a real symmetric matrix. The factored form of A is then used to solve the system of equations A * X = B by calling BLAS3 routine DSYTRS_3 and SSYTRS_3.

A more detailed description of the algorithm is available in Reference [1].
