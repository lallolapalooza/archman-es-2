NOMBRE

hostapd - Autenticador IEEE 802.11 AP, IEEE 802.1X/WPA/WPA2/EAP/RADIUS

SINOPSIS

hostapd [-hdBKtv] [-P <archivo PID>] <archivo(s) de configuración>

DESCRIPCIÓN

Esta página del manual documenta brevemente el demonio hostapd.

hostapd es un demonio en espacio de usuario para servidores de acceso y autenticación. Implementa la gestión de puntos de acceso IEEE 802.11, autenticadores IEEE 802.1X/WPA/WPA2/EAP y servidor de autenticación RADIUS. La versión actual soporta Linux (controladores basados en Host AP, mac80211) y FreeBSD (net80211).

hostapd está diseñado para ser un programa "demonio" que se ejecuta en segundo plano y actúa como componente backend que controla la autenticación. hostapd soporta programas frontend separados y un ejemplo de frontend basado en texto, hostapd_cli, se incluye con hostapd.

OPCIONES

A continuación se incluye un resumen de las opciones. Para una descripción completa, ejecute hostapd desde la línea de comandos.

-h
Muestra el uso.
-d
Muestra más mensajes de depuración.
-dd
Muestra aún más mensajes de depuración.
-B
Ejecuta el demonio en segundo plano.
-P <archivo PID>
Ruta al archivo PID.
-K
Incluye datos de clave en los mensajes de depuración.
-t
Incluye marcas de tiempo en algunos mensajes de depuración.
-v
Muestra la versión de hostapd.

VER TAMBIÉN
