hivexml(1) Registro de Windows hivexml(1)

NOMBRE

hivexml - Convierte el archivo binario "hive" del Registro de Windows a XML

SINOPSIS

hivexml [-dk] archivo_hive > salida.xml

DESCRIPCIÓN

Este programa convierte un único archivo binario "hive" del Registro de Windows a un formato XML autodocumentado.

OPCIONES

-d
Habilita muchos mensajes de depuración. Si encuentra un archivo de Registro que este programa no puede analizar, por favor, habilite esta opción y publique la salida completa y el archivo de Registro en su informe de error.
-k
Continúa incluso si encontramos errores en el archivo de Registro. Esto salta cualquier parte del Registro que no podamos leer.
-u
Utiliza heurísticas para tolerar ciertos niveles de corrupción dentro de los hives.

Esto no es seguro, pero puede permitir exportar/fusionar claves/valores válidos en un hive que de otro modo estaría corrupto.
