NOMBRE

himalaya - CLI para gestionar correos electrónicos

SINOPSIS

himalaya [-c|--config] [-o|--output] [--debug] [--trace] [-h|--help] [-V|--version] [subcomandos]

DESCRIPCIÓN

CLI para gestionar correos electrónicos

OPCIONES

-c, --config=RUTA
Anula la ruta del archivo de configuración predeterminado.

Las rutas dadas se expanden en el shell y luego se canonicalizan (si corresponde). Si la primera ruta no apunta a un archivo válido, el asistente propondrá ayudarte en la creación del archivo de configuración. Otras rutas se fusionan con la primera, lo que te permite separar tu configuración pública de tu(s) privada(s).

También se puede especificar con la variable de entorno HIMALAYA_CONFIG.
-o, --output=FORMATO [predeterminado: plain]
Personaliza el formato de salida.

El formato de salida determina cómo mostrar la salida de los comandos en la terminal.

Los valores posibles son:

- json: la salida será en forma de un objeto compatible con JSON

- plain: la salida será en forma de texto plano o tabla, dependiendo del comando

[valores posibles: plain, json]

--debug
Habilita los registros con rastreo de spans.

Esto es lo mismo que ejecutar el comando con la variable de entorno `RUST_LOG=debug`.

--trace
Habilita registros detallados con traza de pila.

Esto es lo mismo que ejecutar el comando con las variables de entorno `RUST_LOG=trace` y `RUST_BACKTRACE=1`.

-h, --help
Imprime la ayuda (ve un resumen con '-h')
-V, --version
Imprime la versión
