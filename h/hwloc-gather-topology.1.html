NOMBRE

hwloc-gather-topology - Guarda los archivos relevantes de topología de Linux y x86, así como las salidas textual y XML de lstopo para uso posterior (posiblemente sin conexión)

SINOPSIS

hwloc-gather-topology [opciones] <ruta>

OPCIONES

--io
También guarda archivos relacionados con I/O. La recopilación puede ser mucho más lenta y el archivo generado puede ser mucho más grande.
--dmi
También guarda archivos relacionados con DMI/SMBIOS. La recopilación requiere acceso de root y el módulo del kernel dmi-sysfs debe estar cargado.
--dt
También guarda archivos de CPU de Device-Tree. Estos archivos no son necesarios para hwloc, pero pueden usarse para depurar lo que Linux expone en /sys.
--no-cpuid
No guarda el volcado de CPUID de x86 usando hwloc-gather-cpuid.
--keep
Conserva la copia temporal de los archivos volcados en lugar de destruirla.
--version
Informa la versión y sale.
-h --help
Muestra el mensaje de ayuda y sale.

DESCRIPCIÓN

hwloc-gather-topology guarda todos los archivos de topología relevantes en un archivo (<ruta>.tar.bz2), la salida de lstopo (<ruta>.output) y el XML de lstopo (<ruta>.xml). La utilidad, por ejemplo, almacena el archivo /proc/cpuinfo y todo el árbol de directorios /sys/devices/system/node/.

Estos archivos pueden usarse más tarde para explorar la topología de la máquina sin conexión. Una vez que el archivo tar se ha extraído, puede dársele, por ejemplo, a algunas utilidades de línea de comandos de hwloc a través de su opción --input. También es posible anular la topología predeterminada que la biblioteca hwloc leerá estableciendo la ruta extraída en la variable de entorno HWLOC_FSROOT.

El archivo y las salidas textual y XML de lstopo también pueden enviarse a los desarrolladores de hwloc para depurar problemas de forma remota.

hwloc-gather-topology es una herramienta específica de Linux, no se instala en otros sistemas operativos.

NOTA: hwloc-gather-topology recopila muchos detalles de hardware sobre la plataforma. Las salidas y el archivo tar no deben publicarse en listas o sitios web públicos a menos que esté claro que no contienen información sensible.

NOTA: La recopilación puede tardar varios minutos, especialmente en nodos grandes.

NOTA: Se recomienda encarecidamente leer la página de descripción general de hwloc(7) antes de leer esta página del manual.

EJEMPLOS

Para almacenar información de topología para usarla más tarde (posiblemente en un host diferente) por favor ejecute:


$ hwloc-gather-topology /tmp/mihost

Almacenará todos los archivos de topología relevantes en el archivo /tmp/mihost.tar.bz2, la salida de lstopo en el archivo /tmp/mihost.output y el XML de lstopo en el archivo /tmp/mihost.xml. Estos archivos pueden transferirse a otro host para análisis posterior/sin conexión y/o como entrada para varias utilidades de hwloc.

Para usar estos datos con las utilidades de hwloc, primero debe desempaquetar el archivo myhost.tar.bz2:


$ tar jxvf /tmp/mihost.tar.bz2

Ahora un nuevo directorio llamado mihost contiene todos los archivos de topología. Luego, pide a varias utilidades de hwloc que usen esta topología en lugar de la de la máquina real pasando --input mihost. Para mostrar la topología, simplemente ejecute:


$ lstopo --input ./mihost

No es necesario que la topología esté extraída en el directorio actual, también se admiten rutas absolutas o relativas:


$ lstopo --input /ruta/al/host/remoto/topologia/extraída/

Para ver cómo hwloc distribuiría 8 trabajos paralelos en el host original:


$ hwloc-distrib --input mihost --single 8

Para obtener los índices físicos correspondientes en el comando anterior:


$ hwloc-calc --input mihost --po --li -I pu $(hwloc-distrib --input mihost --single 8)

Cualquier programa puede, de hecho, anular la topología predeterminada con una dada archivada incluso si no tiene una opción --input. Se debe usar la variable de entorno HWLOC_FSROOT para hacer esto:


$ HWLOC_FSROOT=mihost hwloc-calc --po --li -I pu $(hwloc-distrib --single 8)

Todos estos comandos producirán la misma salida que si se ejecutaran directamente en el host en el que se recopiló originalmente la información de topología por el script hwloc-gather-topology.

VALOR DE RETORNO

Tras una ejecución exitosa, hwloc-gather-topology saldrá con el código 0.

hwloc-gather-topology devolverá un estado de salida distinto de cero si ocurre algún tipo de error, como (pero sin limitarse a) fallos al crear el archivo o los archivos de salida.
