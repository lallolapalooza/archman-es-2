HNSDV_CREATE_QP(3) Manual del programador de HNS HNSDV_CREATE_QP(3)

NOMBRE

hnsdv_create_qp - crea un par de colas (QP) específico de HNS

SINOPSIS

#include <infiniband/hnsdv.h>
struct ibv_qp *hnsdv_create_qp(struct ibv_context *context,
                               struct ibv_qp_init_attr_ex *qp_attr,
                               struct hnsdv_qp_init_attr *hns_attr);

DESCRIPCIÓN

hnsdv_create_qp() crea un par de colas (QP) específico de HNS con propiedades de controlador específicas.

ARGUMENTOS

Por favor, consulte la página del manual de ibv_create_qp_ex(3) para context y qp_attr.

hns_attr

struct hnsdv_qp_init_attr {
        uint64_t comp_mask;
        uint32_t create_flags;
        uint8_t congest_type;
        uint8_t reserved[3];
};
comp_mask
Máscara de bits que especifica qué campos de la estructura son válidos:
HNSDV_QP_INIT_ATTR_MASK_QP_CONGEST_TYPE:
    Valores válidos en congest_type. Permite establecer un algoritmo de control de congestión para QP.
create_flags
Habilita el QP de una característica.
congest_type
Tipo de algoritmo de control de congestión:

HNSDV_QP_CREATE_ENABLE_DCQCN: Notificación de Congestión Cuantificada de Centro de Datos HNSDV_QP_CREATE_ENABLE_LDCP: Protocolo de Control de Baja Latencia HNSDV_QP_CREATE_ENABLE_HC3: Control de Congestión Convergente de Huawei HNSDV_QP_CREATE_ENABLE_DIP: Notificación de Congestión Cuantificada basada en IP de Destino

VALOR DE RETORNO

hnsdv_create_qp() devuelve un puntero al QP creado; en caso de error, devolverá NULL y se establecerá errno.

VER TAMBIÉN
