Documentación de Tipo de Enumeración

enum hwloc_distances_kind_e

Tipos de matrices de distancia. El atributo kind de la estructura hwloc_distances_s es un conjunto OR de tipos.

Cada matriz de distancia puede tener solo un tipo entre HWLOC_DISTANCES_KIND_FROM_* que especifica de dónde provienen los datos de distancia, y un tipo entre HWLOC_DISTANCES_KIND_MEANS_* que especifica si los valores son latencias o anchos de banda.

Enumerador

HWLOC_DISTANCES_KIND_FROM_OS
Estas distancias se obtuvieron del sistema operativo o del hardware.
HWLOC_DISTANCES_KIND_FROM_USER
Estas distancias fueron proporcionadas por el usuario.
HWLOC_DISTANCES_KIND_MEANS_LATENCY
Los valores de distancia son similares a las latencias entre objetos. Los valores son menores para objetos más cercanos, por lo tanto, mínimos en la diagonal de la matriz (distancia entre un objeto y sí mismo). También podría ser el número de saltos de red entre objetos, etc.
HWLOC_DISTANCES_KIND_MEANS_BANDWIDTH
Los valores de distancia son similares a los anchos de banda entre objetos. Los valores son mayores para objetos más cercanos, por lo tanto, máximos en la diagonal de la matriz (distancia entre un objeto y sí mismo). Estos valores se ignoran actualmente para la agrupación basada en distancias.
HWLOC_DISTANCES_KIND_HETEROGENEOUS_TYPES
Esta estructura de distancias cubre objetos de diferentes tipos. Esto puede aplicarse a la estructura 'NVLinkBandwidth' en presencia de un NVSwitch o un puerto NVLink de procesador POWER.

enum hwloc_distances_transform_e

Transformaciones de estructuras de distancias.

Enumerador

HWLOC_DISTANCES_TRANSFORM_REMOVE_NULL
Eliminar objetos NULL de la estructura de distancias. Se elimina cada objeto que fue reemplazado por NULL en el array objs y se actualiza el array values en consecuencia.

Deben permanecer al menos 2 objetos, de lo contrario hwloc_distances_transform() devolverá -1 con errno establecido en EINVAL.

kind se actualizará con o sin HWLOC_DISTANCES_KIND_HETEROGENEOUS_TYPES según los objetos restantes.

HWLOC_DISTANCES_TRANSFORM_LINKS
Reemplazar valores de ancho de banda con un número de enlaces. Normalmente, todos los valores serán 0 (sin enlace) o 1 (un enlace). Sin embargo, algunas matrices podrían obtener valores mayores si algunos pares de nodos están conectados por diferentes números de enlaces.

Los valores en la diagonal se establecen en 0.

Esta transformación solo se aplica a matrices de ancho de banda.

HWLOC_DISTANCES_TRANSFORM_MERGE_SWITCH_PORTS
Fusionar switches con múltiples puertos en un solo objeto. Esto actualmente solo se aplica a NVSwitches donde las GPUs parecen conectadas a diferentes puertos de switch. Los puertos de switch deben ser objetos con el subtipo 'NVSwitch' como en la matriz NVLinkBandwidth.

Esta transformación reemplazará todos los puertos con solo el primero, ahora conectado a todas las GPUs. Otros puertos se eliminan aplicando HWLOC_DISTANCES_TRANSFORM_REMOVE_NULL internamente.

HWLOC_DISTANCES_TRANSFORM_TRANSITIVE_CLOSURE
Aplicar una clausura transitiva a la matriz para conectar objetos a través de switches. Se informará que todos los pares de GPUs están conectados directamente en lugar de que las GPUs solo estén conectadas a los switches.

Los puertos de switch deben ser objetos con el subtipo 'NVSwitch' como en la matriz NVLinkBandwidth.

DESCRIPTION

Distance matrices describe the locality of hardware objects to each other. For instance, they may describe the latency or bandwidth between NUMA nodes, or between different levels of the memory hierarchy.

The hwloc_distances_get_* functions retrieve these matrices. The nr parameter will be set to the number of matrices found. The distances parameter will point to an array of hwloc_distances_s structures. The caller must release the array (and the structures it points to) using hwloc_distances_release().

The kind parameter specifies which kinds of distances to retrieve. It must be a bitmask of HWLOC_DISTANCES_KIND_* flags.

The flags parameter can be used to specify additional parameters. It must be set to 0 for now.

The hwloc_distances_get_name() function returns a human-readable string describing the distances structure, for instance "NUMALatency".

hwloc_distances_release() releases the array of structures returned by a hwloc_distances_get_*() call. The function still returns success (0).

Each distance matrix returned in the distances array should be released by the caller using hwloc_distances_release().

int hwloc_distances_get (hwloc_topology_t topology, unsigned * nr, struct hwloc_distances_s ** distances, unsigned long kind, unsigned long flags)

Retrieve all available distance matrices in the topology. The caller may find out if the topology was modified by comparing the value pointed to by nr before and after the function call. If the value is the same, the topology is unchanged.

Returns

0 on success, -1 on error.

int hwloc_distances_get_by_depth (hwloc_topology_t topology, int depth, unsigned * nr, struct hwloc_distances_s ** distances, unsigned long kind, unsigned long flags)

Retrieve distance matrices for objects at a specific depth in the topology. Identical to hwloc_distances_get() with the additional depth filter.

Returns

0 on success, -1 on error.

int hwloc_distances_get_by_name (hwloc_topology_t topology, const char * name, unsigned * nr, struct hwloc_distances_s ** distances, unsigned long flags)

Retrieve a distance matrix with the given name. Usually only one distances structure may match a given name.

The name of the most common structure is 'NUMALatency'. Others include 'XGMIBandwidth', 'XGMIHops', 'XeLinkBandwidth', and 'NVLinkBandwidth'.

Returns

0 on success, -1 on error.

int hwloc_distances_get_by_type (hwloc_topology_t topology, hwloc_obj_type_t type, unsigned * nr, struct hwloc_distances_s ** distances, unsigned long kind, unsigned long flags)

Retrieve distance matrices for objects of a specific type. Identical to hwloc_distances_get() with the additional type filter.

Returns

0 on success, -1 on error.

const char * hwloc_distances_get_name (hwloc_topology_t topology, struct hwloc_distances_s * distances)

Get a description of what a distances structure contains. For instance 'NUMALatency' for hardware-provided NUMA distances (ACPI SLIT), or NULL if unknown.

Returns

the constant string with the name of the distance structure.

Note

The returned name should not be freed by the caller, it belongs to the hwloc library.

void hwloc_distances_release (hwloc_topology_t topology, struct hwloc_distances_s * distances)

Release a distance matrix structure previously returned by hwloc_distances_get().

Note

This function is not required if the structure is removed with hwloc_distances_release_remove().

int hwloc_distances_transform (hwloc_topology_t topology, struct hwloc_distances_s * distances, enum hwloc_distances_transform_e transform, void * transform_attr, unsigned long flags)

Apply a transformation to a distances structure. Modify a distances structure that was previously obtained with hwloc_distances_get() or one of its variants.

This modifies the local copy of the distances structures but does not modify the distances information stored inside the topology (retrieved by another call to hwloc_distances_get() or exported to XML). To do so, one should add a new distances structure with same name, kind, objects and values (see Add distances between objects) and then remove this old one with hwloc_distances_release_remove().

transform must be one of the transformations listed in hwloc_distances_transform_e.

These transformations may modify the contents of the objs or values arrays.

transform_attr must be NULL for now.

flags must be 0 for now.

Returns

0 on success, -1 on error for instance if flags are invalid.

Note

Objects in distances array objs may be directly modified in place without using hwloc_distances_transform(). One may use hwloc_get_obj_with_same_locality() to easily convert between similar objects of different types.
