hci(7) Administración del Sistema Linux hci(7)

Nombre

hci - Protocolo HCI de Bluetooth

SINÓPSIS

#include <sys/socket.h>
#include <bluetooth/bluetooth.h>
#include <bluetooth/hci.h>
hci_socket = socket(PF_BLUETOOTH, SOCK_RAW, BTPROTO_HCI);

DESCRIPCIÓN

Bluetooth Host Controller Interface (HCI) es el protocolo estándar para comunicarse con adaptadores Bluetooth. El protocolo HCI proporciona un método uniforme de comandos para que el Host acceda a las capacidades del Controlador y controle las conexiones con otros Controladores.

DIRECCIÓN DEL SOCKET

struct sockaddr_hci {
    sa_family_t    hci_family;
    unsigned short hci_dev;
    unsigned short hci_channel;
};

Valores posibles para hci_channel:

Define Valor Descripción
HCI_CHANNEL_RAW 0x00 Canal Raw - Usado para comunicación HCI cruda
HCI_CHANNEL_USER 0x01 Canal de usuario - Usado para comunicación HCI en el espacio de usuario (deshabilita el procesamiento del kernel)
HCI_CHANNEL_MONITOR 0x02 Canal de monitorización - Usado para monitorizar el tráfico HCI (btmon(1))
HCI_CHANNEL_CONTROL 0x03 Canal de control - Usado para administrar adaptadores locales (bluetoothd(7))
HCI_CHANNEL_LOGGING 0x04 Canal de registro - Usado para inyectar mensajes de registro (bluetoothd(7))

Ejemplo:

struct sockaddr_hci addr;
memset(&addr, 0, sizeof(addr));
addr.hci_family = AF_BLUETOOTH;
addr.hci_dev = HCI_DEV_NONE;
addr.hci_channel = HCI_CHANNEL_CONTROL;

OPCIONES DEL SOCKET

Las siguientes opciones de socket se pueden establecer utilizando setsockopt(2) y leer con getsockopt(2) con el nivel de socket establecido en SOL_BLUETOOTH o SOL_HCI (HCI_FILTER).

HCI_FILTER (desde Linux 2.6)

Filtro por eventos HCI, requiere que hci_channel esté establecido en HCI_CHANNEL_RAW, valores posibles:

struct hci_filter {
    uint32_t type_mask;
    uint32_t event_mask[2];
    uint16_t opcode;
};

Ejemplo:

struct hci_filter flt;
memset(&flt, 0, sizeof(flt));
flt.type_mask = 1 << BT_H4_EVT_PKT;
flt.event_mask[0] = 0xffffffff;
flt.event_mask[1] = 0xffffffff;
setsockopt(fd, SOL_HCI, HCI_FILTER, &flt, sizeof(flt));

BT_SNDBUF (desde Linux 5.16)

Establece el tamaño del búfer de envío, requiere que hci_channel esté establecido en HCI_CHANNEL_MONITOR, HCI_CHANNEL_CONTROL o HCI_CHANNEL_LOGGING.

El valor predeterminado es 1028.

Ejemplo:

uint16_t mtu = UINT16_MAX;
int err;
err = setsockopt(fd, SOL_BLUETOOTH, BT_SNDMTU, &mtu, sizeof(mtu));

BT_RCVBUF (desde Linux 5.16)

Establece el tamaño del búfer de recepción, requiere que hci_channel esté establecido en HCI_CHANNEL_MONITOR, HCI_CHANNEL_CONTROL o HCI_CHANNEL_LOGGING.

El valor predeterminado es 1028.

Ejemplo:

uint16_t mtu;
socklen_t len;
int err;
len = sizeof(mtu);
err = getsockopt(sock, SOL_BLUETOOTH, BT_RCVMTU, mtu, &len);
