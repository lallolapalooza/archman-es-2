HG(CAT) HG(CAT)

NOMBRE

hg cat - mostrar el contenido actual o una revisión dada de archivos

SINOPSIS

hg cat [OPCIÓN]... ARCHIVO...

DESCRIPCIÓN

Imprime los archivos especificados tal como estaban en la revisión dada. Si no se proporciona una revisión, se utiliza el padre del directorio de trabajo.

La salida puede ser a un archivo, en cuyo caso el nombre del archivo se da usando una cadena de plantilla. Consulte hg help templates. Además de las palabras clave de plantilla comunes, se admiten las siguientes reglas de formato:

%%

carácter literal "%"

%s

nombre base del archivo que se está imprimiendo

%d

nombre del directorio del archivo que se está imprimiendo, o '.' si está en la raíz del repositorio

%p

nombre de ruta relativo a la raíz del archivo que se está imprimiendo

%H

hash del changeset (40 dígitos hexadecimales)

%R

número de revisión del changeset

%h

hash del changeset en formato corto (12 dígitos hexadecimales)

%r

número de revisión del changeset con relleno de ceros

%b

nombre base del repositorio de exportación

\

carácter literal ""

Plantilla:

Las siguientes palabras clave son compatibles además de las palabras clave y funciones de plantilla comunes. Consulte también hg help templates.

data
Cadena. Contenido del archivo.
path
Cadena. Ruta del archivo absoluta del repositorio.

Devuelve 0 en caso de éxito.

OPCIONES

-o,--output <FORMATO>
imprimir salida al archivo con nombre formateado
-r,--rev <REV>
imprimir la revisión dada
--decode
aplicar cualquier filtro de decodificación coincidente
-I,--include <PATRÓN[+]>
incluir nombres que coincidan con los patrones dados
-X,--exclude <PATRÓN[+]>
excluir nombres que coincidan con los patrones dados
-T,--template <PLANTILLA>
mostrar con plantilla

[+] la opción marcada se puede especificar varias veces
