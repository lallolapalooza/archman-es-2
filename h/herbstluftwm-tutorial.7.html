TESELAD

O

Inicialmente hay un marco. Cada marco tiene uno de los dos tipos posibles

siguientes:
1.Sirve como un contenedor para ventanas, es decir, puede contener de cero hasta arbitrariamente muchas ventanas. Lanza varios terminales más para ver qué sucede: Si hay múltiples ventanas en un marco, están alineadas una debajo de la otra. Para cambiar este algoritmo de diseño, presiona Mod-space para recorrer todos los algoritmos de diseño disponibles para el marco
enfocado.
2.Un marco también puede dividirse en dos submarcos, que pueden alinearse uno al lado del otro o uno debajo del otro. Presiona Mod-o para dividir en una alineación horizontal. Para navegar al marco nuevo a la derecha del antiguo presiona Mod-l. Presiona Mod-u para dividir verticalmente. La navegación intuitiva es: 
      ⎧ h (o ←) ⎫                 ⎧ izquierda
      ⎪ j (o ↓)
⎪ significa ⎪ abajo Mod + ⎨ k (o ↑) ⎬ ═══════> enfo
car ⎨ arriba ⎩ l (o →) ⎭ ⎩ derecha

Para deshacer la división, puedes eliminar un marco con Mod-r. Para mover alguna ventana de un marco a uno de sus vecinos, usa el mismo atajo de teclado mientras mantienes presionada la tecla Shift presionado. No es posible redimensionar ventanas individuales, solo se pueden redimensionar marcos. El atajo de teclado correspondiente es el mismo manteniendo presionado Control. En resumen, es:

                    ⎧ h (o ←) ⎫                          ⎧ izquierda
      ⎧         ⎫   ⎪ j (o ↓) ⎪  significa  ⎧ enfocar marco  ⎫ ⎪ abajo
Mod + ⎨ Shift   ⎬ + ⎨ k (o ↑) ⎬  ═════> ⎨ mover ventana  ⎬ ⎨ arriba
      ⎩ Control ⎭   ⎩ l (o →) ⎭         ⎩ redimensionar marco ⎭ ⎩ derecha

Con esto, puedes definir un diseño personalizado. Se puede imprimir mediante el layout comando:

$ herbstclient layout
╾─┐ horizontal 50% selection=1
  ├─┐ vertical 70% selection=0
  │ ├─╼ vertical: 0x1400009
  │ └─╼ vertical:
  └─╼ max: 0x1a00009 [FOCUS]

Juega un poco con ello para entender cómo funciona. También puedes guardar el diseño de forma permanente usando el dump comando:

$ herbstclient dump
(split horizontal:0.500000:1
    (split vertical:0.700000:0
        (clients vertical:0 0x1400009)
        (clients vertical:0))
    (clients max:0 0x1a00009))
$ layout=$(herbstclient dump)

Y después de algunos cambios puedes volver al diseño original con el load comando:

$ herbstclient load "$layout"       # ¡ten en cuenta las comillas!

ETIQUETAS (O ESPACIOS DE TRABAJO O ESCRITORIOS VIRTUALES O ....)

Una etiqueta consiste en un nombre y un diseño de marcos con clientes en ella. Con el autostart predeterminado, hay nueve etiquetas nombradas del 1 al 9. Puedes cambiar a la i-ésima etiqueta usando Mod-i, por ejemplo, Mod-4 para cambiar a la etiqueta 4 o con el comando use 4. Una ventana puede moverse a la etiqueta i mediante Mod-Shift-i, es decir, con el move comando.

MONITORES

La noción de un monitor en herbstluftwm se trata de manera mucho más abstracta y general que en otros gestores de ventanas: Un monitor es simplemente una parte rectangular de tu pantalla que muestra exactamente una etiqueta en ella.

Inicialmente solo hay un monitor grande que abarca toda tu pantalla:

$ herbstclient list_monitors
0: 1440x900+0+0 with tag "1" [FOCUS]

La salida muestra que solo hay un monitor con índice 0 en la posición +0+0 de tamaño 1440x900 mostrando la etiqueta 1. En la mayoría de los casos, los monitores de herbstluftwm coincidirán con la lista de monitores físicos. Así que para añadir otro monitor físico, tienes que realizar varios pasos:

1.Habilitarlo, de modo que muestre una parte de tu pantalla. Puedes usar xrandr, xinerama o cualquier otra herramienta que prefieras.
2.Registrarlo en herbstluftwm: Supongamos que tu nuevo monitor tiene la resolución 1024x768 y está a la derecha de tu pantalla principal, entonces puedes activarlo mediante: 
$ herbstclient set_monitors 1440x900+0+0 1024x768+1440+0

Alternativamente, si xinerama o xrandr funciona para tu configuración, simplemente ejecuta:

$ herbstclient detect_monitors

Para una automatización aún mayor, puedes habilitar la configuración auto_detect_monitors. Para ejemplos más avanzados, mira el script de ejemplo q3terminal.sh , que implementa un monitor tipo terminal desplegable donde puedes poner cualquier aplicación que desees.
