NOMBRE

hdapsd - estacionar la unidad en caso de emergencia

SINOPSIS

hdapsd [-f|-r|-c <archivo_config>|-d <dispositivo>|-s <sensibilidad>|-a|-v|-b|-p|-t|-y|-H|-S|-L|-l|-V|-h]

OPCIONES

-c --cfgfile=<archivo_config>
Cargar configuración desde <archivo_config>. Solo disponible si hdapsd fue compilado con soporte para libconfig.
-d --device=<dispositivo>
<dispositivo> probablemente sea hda o sda. Se puede especificar varias veces para proteger múltiples dispositivos.
-f --force
Forzar la descarga de cabezales, incluso si el kernel piensa diferente (en unidades pre ATA7). Esto solo funciona cuando se añaden dispositivos manualmente (-d).
-r --force-rotational
Detectar automáticamente unidades como rotacionales, incluso si el kernel piensa que no lo son.
-s --sensitivity=<sensibilidad>
Qué tan sensible debe ser hdapsd a los movimientos. Por defecto es 15, valores más altos significan menos sensible.
-a --adaptive
Umbral adaptativo (aumento automático cuando se usan el teclado/ratón integrados).
-v --verbose
Obtener estadísticas detalladas.
-b --background
Ejecutar el proceso en segundo plano.
-p --pidfile[=<archivo_pid>]
Crear un archivo pid al ejecutar en segundo plano. Si no se especifica <archivo_pid>, se establece en /var/run/hdapsd.pid.
-t --dry-run
No estacionar la unidad realmente.
-y --poll-sysfs
Forzar el uso de la interfaz sysfs para el acelerómetro.
-H --hardware-logic
Utiliza la lógica de detección de caídas por hardware en lugar de la de software. Las opciones --sensitivity y --adaptive no tienen efecto en este modo.
-S --software-logic
Utiliza la lógica de detección de caídas por software incluso si la de hardware está disponible.
-L --no-leds
No parpadear los LEDs cuando se detecta un golpe.
-l --syslog
Registrar en syslog en lugar de stdout/stderr.
-V --version
Mostrar información de la versión y salir.
-h --help
Mostrar ayuda y salir.

Puedes enviar SIGUSR1 a hdapsd para desactivarlo durante 8 segundos.
