Descripción

Detallada

Las plataformas con memoria heterogénea requieren formas de decidir si un búfer debe asignarse en memoria 'rápida' (como HBM), memoria 'normal' (DDR) o incluso memoria 'lenta' pero de gran capacidad (memoria no volátil). Estos nodos de memoria se denominan 'Destinos' mientras que la CPU que accede a ellos se denomina el 'Iniciador'. El rendimiento del acceso depende de su localidad (plataformas NUMA) así como del rendimiento intrínseco de los destinos (plataformas heterogéneas)

.

Los siguientes atributos describen el rendimiento de los accesos a memoria desde un Iniciador a un Destino de memoria, por ejemplo su latencia o ancho de banda. Los Iniciadores que realizan estos accesos a memoria suelen ser algunas UPs o Núcleos (descritos como un conjunto de CPU). Por lo tanto, un Núcleo puede elegir dónde asignar un búfer de memoria comparando los atributos de diferentes nodos de memoria de destino

cercanos.

También hay algunos atributos que son de todo el sistema. Su valor no depende de un iniciador específico que realice un acceso. La Capacidad del nodo de memoria es un ejemplo de tal atributo sin

iniciador.

Una forma de usar esta API es comenzar con un conjunto de CPU que describa los Núcleos a los que está vinculado un programa. El mejor nodo NUMA de destino para asignar memoria en este programa en estos Núcleos puede obtenerse pasando este conjunto de CPU como un iniciador a hwloc_memattr_get_best_target() con el atributo de memoria relevante. Por ejemplo, si el código está limitado por la latencia, use el atributo

Latencia.

Un enfoque más flexible consiste en obtener la lista de nodos NUMA locales pasando este conjunto de CPU a hwloc_get_local_numanode_objs(). Los valores de atributos para estos nodos, si los hay, pueden luego obtenerse con hwloc_memattr_get_value() y compararse manualmente con los criterios

deseados.

Los atributos de memoria también se usan internamente para construir Niveles de Memoria que proporcionan una forma fácil de distinguir nodos NUMA de diferentes tipos, como se explica en Memoria Heter

ogénea.

Además de los niveles, hwloc define un conjunto de nodos 'predeterminados' desde donde deben hacerse las asignaciones normales de memoria (véase hwloc_topology_get_default_nodeset()). Esto también es útil para dividir la máquina en un conjunto de dominios NUMA no superpuestos, por ejemplo para vincular tareas por

dominio.

int hwloc_topology_get_default_nodeset (hwloc_topology_t topology, hwloc_nodeset_t nodeset, unsigned long

flags)

Devuelve el conjunto de nodos NUMA predeterminados. En máquinas con memoria heterogénea, algunos nodos NUMA se consideran los predeterminados, es decir, donde se deben hacer las asignaciones básicas. Estos son usualmente nodos

DRAM.

Otros nodos pueden estar reservados para uso específico (memoria de dispositivos de E/S, por ejemplo memoria de GPU), pequeños pero de alto rendimiento (HBM), memoria grande pero lenta (NVM), etc. Los búferes normalmente no deberían ser asignados de ahí a menos que se requiera

explícitamente.

Esta función rellena nodeset con los bits de los nodos NUMA considerados predeterminados

.

Se garantiza que estos nodos tienen conjuntos de CPU no intersectantes, es decir, los núcleos no pueden tener múltiples nodos NUMA locales. Por lo tanto, esto puede usarse para iterar sobre la plataforma dividida en localidades NUMA separadas, por ejemplo para enlazar una tarea por dominio

NUMA.

Cualquier núcleo que tuviera algún nodo(s) NUMA local en la topología inicial todavía debería tener uno en el nodeset predeterminado. Los casos extremos donde esto sería incorrecto consisten en plataformas asimétricas con nodos DRAM faltantes, o topologías que ya estaban restringidas a menos nodos

NUMA.

El nodeset devuelto puede ser pasado a hwloc_topology_restrict() con HWLOC_RESTRICT_FLAG_BYNODESET para remover todos los nodos no predeterminados de la topología. La topología resultante será más fácil de usar al iterar sobre (ahora homogéneos) nodos

NUMA.

Las heurísticas para encontrar nodos predeterminados se basan en niveles de memoria y subtipos (ver Memoria Heterogénea) así como en la suposición de que los proveedores de hardware listan los nodos predeterminados primero en las tablas de

hardware.
