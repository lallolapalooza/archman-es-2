    NAME

    hciattach - attach a HCI device to a specific UART or USB port

    SYNOPSIS

    hciattach <tty> <hci_dev> [ <baudrate> [ <flow_control> ] ]

    hciattach <usb_device> <hci_dev> [ <vendor>:<product> ]

    DESCRIPTION

    hciattach can be used to attach the Bluetooth controller to the specified serial port (UART) or USB port. The program is meant to be used by scripts, for example, by rc.d scripts during the system startup.

    The first form of the command is used for serial devices. The <tty> parameter is the serial port device name, such as /dev/ttyS0 or /dev/rfcomm0. The <hci_dev> parameter specifies the HCI device index for the new device. Typically this would be HCI0. The optional <baudrate> parameter specifies the serial connection baud rate. If omitted, a default baud rate is used. The optional <flow_control> parameter can be set to cts/rts to enable hardware flow control. By default, flow control is disabled.

    The second form of the command is used for USB devices. The <usb_device> parameter is the USB device path, such as /dev/usb/lp0 or /dev/bus/usb/001/002. The <hci_dev> parameter specifies the HCI device index for the new device. Typically this would be HCI0. The optional <vendor>:<product> parameters can be used to specify the vendor and product ID of the USB device. This is useful when there are multiple USB devices attached.

    OPTIONS

    There are no command line options for this program.

    EXAMPLES

    To attach HCI0 to the serial port /dev/ttyS0 with a baud rate of 115200 and hardware flow control:

    hciattach /dev/ttyS0 hci0 115200 cts/rts

    To attach HCI0 to the USB device /dev/usb/lp0:

    hciattach /dev/usb/lp0 hci0

    EXIT STATUS

    Returns 0 on success or a non-zero value in case of an error.
