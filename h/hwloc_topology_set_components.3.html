Descripción

Detallada

Estas funciones deben ser llamadas entre hwloc_topology_init() y hwloc_topology_load(). De lo contrario, devolverán -1 con errno establecido a EBUSY

.

Si ninguna de las siguientes funciones es llamada, el comportamiento por defecto es detectar todos los objetos de la máquina a los que el llamador tiene permitido

acceder.

Este comportamiento por defecto también puede ser modificado a través de variables de entorno si la aplicación no lo ha modificado ya. Establecer HWLOC_XMLFILE en el entorno fuerza el descubrimiento desde un archivo XML como si hwloc_topology_set_xml() hubiera sido llamada. Establecer HWLOC_SYNTHETIC fuerza una topología sintética como si hwloc_topology_set_synthetic() hubiera sido

llamada.

Finalmente, HWLOC_THISSYSTEM fuerza el valor de retorno de hwloc_topology_i

s_thiss
ystem().

int hwloc_topology_set_components (hwloc_topology_t restrict topology, unsigned long flags, const char *restrict

name)

Prevenir que un componente de descubrimiento sea usado para una topología. name es el nombre del componente de descubrimiento que no debe ser usado al cargar la topología topology. El nombre es una cadena como

'cuda'.

Para componentes con múltiples fases, también puede ser sufijado con el nombre de una fase, por ejemplo 'linux:

io'.

flags debería ser HWLOC_TOPOLOGY_COMPONENTS_FLAG_BLACKLIST

.

Esto puede ser usado para evitar partes costosas del proceso de descubrimiento. Por ejemplo, el descubrimiento específico de CUDA puede ser costoso y no necesario mientras que el descubrimiento genérico de E/S podría ser aún

útil.

int hwloc_topology_set_pid (hwloc_topology_t restrict topology, hwloc_pid_t

pid)

Cambiar desde qué proceso se ve la topología. En algunos sistemas, los procesos pueden tener diferentes vistas de la máquina, por ejemplo el conjunto de CPUs permitidas. Por defecto, hwloc expone la vista desde el proceso actual. Llamar a hwloc_topology_set_pid() permite hacer que exponga la topología de la máquina desde el punto de vista de otro

proceso.

int hwloc_topology_set_synthetic (hwloc_topology_t restrict topology, const char *restrict

description)

Habilitar topología sintética. Recopilar información de topología desde la descripción dada, una cadena separada por espacios de <tipo:número> describiendo el tipo de objeto y la aridad en cada nivel. Todos los tipos pueden ser omitidos (cadena de números separados por espacios) para que hwloc elija todos los tipos según topologías habituales. Ver también Topologías sintéticas

.

Establecer la variable de entorno HWLOC_SYNTHETIC también puede resultar en este

comportamiento.

Si description fue analizada correctamente y describe una configuración de topología válida, esta función devuelve 0. De lo co

ntrario se devuelve -1 y errno se establece a EINVAL.

Ten en cuenta que esta función no carga realmente la información de topología; solo le dice a hwloc desde dónde cargarla. Aún necesitarás invocar hwloc_topology_load() para cargar realmente la información de

topología.
