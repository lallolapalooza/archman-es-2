H2ROOT(1) Manual de comandos generales H2ROOT(1)

NOMBRE

h2root - convierte archivos HBOOK de PAW a archivos ROOT

SINOPSIS

h2root archivo.hbook archivo.root [comprimir] [tolower] [lrecl]

DESCRIPCIÓN

h2root te permite convertir tus histogramas o archivos ntuple de HBOOK/PAW a archivos ROOT. Para usar este programa, escribe el comando del script de shell:

h2root archivo.hbook archivo.root

Si no especificas el segundo parámetro, se generará automáticamente un nombre de archivo para ti. Si archivo.hbook tiene el formato archivo.hbook, entonces el archivo ROOT se llamará archivo.root.

Este programa convierte histogramas de HBOOK en objetos de ROOT de la clase TH1F. Los histogramas de perfil de HBOOK se convierten en histogramas de perfil de ROOT (ver clase TProfile). Los ntuples de fila y columna de HBOOK se convierten automáticamente en Árboles de ROOT (ver TTree). Algunos ntuples de columna de HBOOK pueden no ser completamente convertidos en caso de que una de las columnas sea un array con dimensiones fijas (ej. `var[6]') o sea un array multidimensional.

Los identificadores enteros de HBOOK se convierten en objetos nombrados de ROOT prefijando el identificador entero con la letra `h' si el identificador es un entero positivo y con `h_' si es un identificador entero negativo.

En el caso de ntuples de fila o columna, cada columna se convierte en una rama de un Árbol. Ten en cuenta que h2root es capaz de convertir archivos HBOOK que contengan varios niveles de subdirectorios. Una vez que hayas convertido tu archivo, puedes inspeccionarlo y dibujar histogramas o procesar ntuples usando el módulo interactivo de ROOT. También puedes usar el navegador de ROOT (ver TBrowser) para inspeccionar este archivo.

El capítulo Cómo leer un Árbol explica dos formas de leer un Árbol. ROOT incluye la función TTree::MakeCode para generar automáticamente el código para una función de análisis esqueleto. Con

OPCIONES

comprimir
= 1 por defecto (usar 0 para no comprimir)
tolower
= 1 por defecto (usar 0 para mantener las mayúsculas/minúsculas de los nombres de columna)
lrecl
= 0 por defecto (debe especificarse si es >8092)
