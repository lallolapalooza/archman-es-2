hwlocality_windows - Funciones auxiliares específicas de Windows

Descripción Detallada

Estas funciones consultan los grupos de procesadores de Windows. Estos grupos dividen el sistema operativo en conjuntos virtuales de hasta 64 PU vecinas. Los hilos y procesos solo pueden enlazarse dentro de un único grupo. Aunque los grupos de procesadores de Windows pueden exponerse en la jerarquía de hwloc como Grupos de hwloc, a menudo también se fusionan en objetos de hwloc existentes, como nodos NUMA o Paquetes. Esta API proporciona información explícita sobre los grupos de procesadores de Windows para que las aplicaciones sepan si el enlace a un conjunto grande de PUs puede fallar porque abarca varios grupos de procesadores de Windows.

Documentación de Funciones

int hwloc_windows_get_nr_processor_groups (hwloc_topology_t topology, unsigned long flags)

Obtiene el número de grupos de procesadores de Windows. flags debe ser 0 por ahora.

Devuelve

al menos 1 en caso de éxito.

-1 en caso de error, por ejemplo, si la topología no coincide con el sistema actual (por ejemplo, cargada de otra máquina a través de XML).

int hwloc_windows_get_processor_group_cpuset (hwloc_topology_t topology, unsigned pg_index, hwloc_cpuset_t cpuset, unsigned long flags)

Obtiene el conjunto de CPU de un grupo de procesadores de Windows. Obtiene el conjunto de PU incluidas en el grupo de procesadores especificado por pg_index. pg_index debe estar entre 0 y el valor devuelto por hwloc_windows_get_nr_processor_groups() menos 1.

flags debe ser 0 por ahora.

Devuelve

0 en caso de éxito.

-1 en caso de error, por ejemplo, si pg_index es inválido, o si la topología no coincide con el sistema actual (por ejemplo, cargada de otra máquina a través de XML).
