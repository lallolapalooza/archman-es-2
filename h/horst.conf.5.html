HORST.CONF(5) Manual de formatos de archivo HORST.CONF(5)

NOMBRE

horst.conf - archivo de configuración para horst(8)

SINOPSIS

/etc/horst.conf

DESCRIPCIÓN

El archivo /etc/horst.conf es el archivo de configuración predeterminado. El archivo de configuración consta de cero o más líneas. Cada línea debe ser VACÍA, COMENTARIO u OPCIÓN y debe terminar con un carácter de nueva línea ('\n', ASCII 0xa).

Las líneas VACÍAS deben tener cero o más espacios (' ', ASCII 0x20).

Las líneas COMENTARIO deben comenzar con un signo de almohadilla ('#', ASCII 0x23).

Las líneas OPCIÓN deben tener el siguiente formato:

opción[=valor]

Las opciones y sus valores aceptables se describen a continuación en la sección OPCIONES.

Las líneas que no coincidan con el formato descrito anteriormente harán que horst salga con un estado distinto de cero.

OPCIONES

canal=NÚMERO_CANAL
Establece el número de canal inicial al que sintoniza la radio horst al iniciar.
estancia_canal=MILISEGUNDOS
Establece el tiempo que horst escanea cada canal cuando se define channel_scan=1.
escaneo_canal
Hace que horst cambie/escanee canales automáticamente en orden numérico ascendente.
rondas_escaneo_canal=N
Establece el número de rondas que horst escanea el rango de canales cuando se define channel_scan=1. Cuando se alcanza N, horst sale con estado cero. Si N es un número negativo, horst escanea el rango de canales infinitamente.
canal_superior=NÚMERO_CANAL
Establece el canal más alto al que horst cambiará cuando se define channel_scan=1. Cuando se alcanza NÚMERO_CANAL, el siguiente canal será 1.
cliente=DIRECCIÓN_SERVIDOR
Ejecuta horst en modo cliente y se conecta a un servidor que se ejecuta en DIRECCIÓN_SERVIDOR.
tubería_control=RUTA_ARCHIVO
Acepta comandos de control en una tubería con nombre.
intervalo_visualización=MILISEGUNDOS
Establece el intervalo de actualización de la pantalla de la interfaz de usuario. Esta opción se puede utilizar para reducir el uso de CPU utilizando intervalos más largos.
vista_visualización=historial|essid|estadísticas|espectro
Establece la vista de visualización inicial.
filtrar_bssid=BSSID[,BSSID]...
Ignora todos los paquetes excepto los paquetes que pertenecen a BSSID.
filtrar_mac=DIRECCIÓN_MAC[,DIRECCIÓN_MAC]...
Ignora todos los paquetes excepto los paquetes que se originan en DIRECCIÓN_MAC.
modo_filtro=MODO[,MODO]...
Ignora todos los paquetes/nodos excepto los paquetes/nodos del modo MODO.
paquete_filtro=TIPO_PAQUETE[,TIPO_PAQUETE]...
Ignora todos los paquetes excepto los paquetes del tipo TIPO_PAQUETE.
interfaz=NOMBRE_INTERFAZ
Establece la interfaz inalámbrica que horst utiliza para monitorear el espectro de radio. Si la interfaz NOMBRE_INTERFAZ no está ya en modo monitor al iniciar, horst primero intenta poner la interfaz en modo monitor y si falla, se añade y utiliza una interfaz virtual de monitor temporal. El nombre de la interfaz virtual de monitor temporal tiene el formato horst[0-9]+. La interfaz virtual creada por horst se elimina al salir.
añadir_monitor
Añade siempre una interfaz de monitor virtual. No intentes configurar la interfaz existente en modo monitor.
nombres_mac=RUTA_ARCHIVO
El archivo que contiene una correspondencia entre direcciones MAC y nombres de host. El archivo puede ser un archivo de concesiones dhcp de dnsmasq o contener correspondencias en el formato "MAC<espacio>nombre" (por ejemplo, "00:01:02:03:04:05 test") línea por línea.
tiempo_espera_nodo=SEGUNDOS
Establece el tiempo después del cual se eliminarán los nodos si no se han recibido tramas de ellos.
archivo_salida=RUTA_ARCHIVO
Escribe información sobre cada paquete recibido en RUTA_ARCHIVO.
puerto=NÚMERO_PUERTO
Establece el puerto en el que escucha horst cuando se ejecuta en modo servidor o el puerto al que se conecta horst cuando se ejecuta en modo cliente.
silencioso

Hace que horst sea menos verboso y suprime la interfaz de usuario.
buffer_recepción=BYTES
Establece el tamaño del búfer de recepción. Esta opción se puede utilizar para ajustar el consumo de memoria y reducir la pérdida de paquetes bajo carga alta.
servidor

Ejecuta horst en modo servidor.
