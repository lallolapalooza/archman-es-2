NOMBRE

hg init - crea un nuevo repositorio en el directorio especificado

SINOPSIS

hg init [-e CMD] [--remotecmd CMD] [DEST]

DESCRIPCIÓN

Inicializa un nuevo repositorio en el directorio dado. Si el directorio dado no existe, será creado.

Si no se proporciona ningún directorio, se utilizará el directorio actual.

Es posible especificar una URL ssh:// como destino. Consulte hg help urls para obtener más información.

Devuelve 0 si tiene éxito.

OPCIONES

-e,--ssh <CMD>
especifica el comando ssh a utilizar
--remotecmd <CMD>
especifica el comando hg a ejecutar en el lado remoto
--insecure
no verifica el certificado del servidor (ignorando la configuración web.cacerts)
