NOMBRE


dsyevr - calcula los valores y, opcionalmente, los vectores propios de una matriz simétrica






SINOPSIS


    SUBROUTINE DSYEVR( JOBZ, RANGE, UPLO, N, A, LDA, VL, VU, IL, IU, ABSTOL,
                       M, W, Z, LDZ, ISUPPZ, WORK, LWORK, IWORK, LIWORK, INFO )

        CHARACTER          JOBZ, RANGE, UPLO
        INTEGER            IL, INFO, IU, LDA, LDZ, LIWORK, LWORK, M, N
        INTEGER            ISUPPZ( * )
        DOUBLE PRECISION   ABSTOL, VL, VU, W( * ), WORK( * )
        DOUBLE PRECISION   A( LDA, * )
        DOUBLE PRECISION   Z( LDZ, * )
        INTEGER            IWORK( * )







DESCRIPCIÓN


DSYEVR calcula valores propios seleccionados y, opcionalmente, vectores
    propios de una matriz real simétrica A. Los valores y vectores propios
    pueden ser seleccionados especificando un rango de valores o un rango de
    índices para los valores propios deseados. Las invocaciones con diferentes
    opciones para estos parámetros pueden resultar en el cálculo de valores
    propios y/o vectores propios ligeramente diferentes para la misma matriz. La
    razón de este comportamiento es que existe una variedad de algoritmos (cada
    uno funcionando mejor para un conjunto particular de opciones) con DSYEVR
    intentando seleccionar el mejor basado en los varios parámetros. En todos
    los casos, los valores calculados son precisos dentro de los límites de la
    aritmética de precisión finita.


DSYEVR primero reduce la matriz A a forma tridiagonal T con una
    llamada a DSYTRD. Luego, siempre que sea posible, DSYEVR llama a DSTEMR para
    calcular el espectro de valores propios utilizando Representaciones
    Relativamente Robustas. DSTEMR calcula valores propios por el algoritmo dqds,
    mientras que los vectores propios ortogonales se calculan a partir de varias
    representaciones L D L^T (también conocidas como Representaciones
    Relativamente Robustas). La ortogonalización de Gram-Schmidt se evita tanto
    como sea posible. Más específicamente, los varios pasos del algoritmo son los
    siguientes.


Para cada bloque no reducido (submatriz) de T,


       (a) Calcula T - sigma I = L D L^T, de modo que L y D
           definen todos los valores propios deseados con alta precisión relativa.
           Esto significa que pequeños cambios relativos en las entradas de D y L
           causan solo pequeños cambios relativos en los valores propios y
           vectores propios. La representación estándar (no factorizada) de la
           matriz tridiagonal T no tiene esta propiedad en general.
       (b) Calcula los valores propios con precisión adecuada.
           Si los vectores propios son deseados, el algoritmo alcanza precisión
           completa de los valores propios calculados justo antes de que los
           vectores correspondientes tengan que ser calculados, ver pasos c) y d).
       (c) Para cada cluster de valores propios cercanos, selecciona un nuevo
           shift cercano al cluster, encuentra una nueva factorización y refina
           los valores propios desplazados a precisión adecuada.
       (d) Para cada valor propio con una separación relativa suficientemente grande,
           calcula el vector propio correspondiente formando una factorización retorcida
           que revele rango. Vuelve al paso c) para cualquier cluster que quede.



La precisión deseada de la salida puede ser especificada por el
    parámetro de entrada ABSTOL.

DOUBLE PRECISION.

    pero las futuras versiones lo harán. Ver J. Barlow y J. Demmel,
    , LAPACK Working Note #7, para una discusión
    sobre qué matrices definen sus valores propios a alta precisión relativa.

NAME


dsyevr - Computes selected eigenvalues and, optionally, eigenvectors of a real symmetric matrix






SYNOPSIS


In Fortran:


    SUBROUTINE DSYEVR(JOBZ, RANGE, UPLO, N, A, LDA, VL, VU, IL, IU, ABSTOL,
                        M, W, Z, LDZ, ISUPPZ, WORK, LWORK, IWORK, LIWORK, INFO)


In C:


    extern void dsyevr_(integer *jobz, integer *range, integer *uplo, integer *n,
                        doubleprecision *a, integer *lda, doubleprecision *vl,
                        doubleprecision *vu, integer *il, integer *iu,
                        doubleprecision *abstol, integer *m, doubleprecision *w,
                        doubleprecision *z, integer *ldz, integer *isuppz,
                        doubleprecision *work, integer *lwork, integer *iwork,
                        integer *liwork, integer *info);






DESCRIPTION


The routine computes the eigenvalues and, optionally, eigenvectors of a real symmetric matrix A. The eigenvalues are sorted in increasing order.


The algorithm performs the following steps:


    

  1. Reduce the real symmetric matrix A to bidiagonal form T by an orthogonal similarity transformation:

    A = Q * T * Q^T
    
where Q is orthogonal.
    2. 

  2. Compute the eigenvalues and eigenvectors of the bidiagonal matrix T.
    3. 

  3. Transform the eigenvectors of T back to eigenvectors of A by multiplying with Q.
    4. 



The routine uses a variety of algorithms to compute the eigenvalues and eigenvectors, depending on the parameters specified.


The routine may fail to converge if the matrix is ill-conditioned or if the parameters are set incorrectly. In such cases, an error code is returned in the INFO parameter.


The routine may produce NaNs or infinities in environments that do not handle NaNs and infinities in the IEEE standard default manner.






PARAMETERS




JOBZ (CHARACTER*1)


Specifies whether to compute eigenvectors.


    

  • 'N': Compute eigenvalues only.
    • 

  • 'V': Compute eigenvalues and eigenvectors.
    • 



This parameter influences the choice of the algorithm and may alter the computed values.




RANGE (CHARACTER*1)


Specifies the range of eigenvalues to be computed.


    

  • 'A': All eigenvalues will be found.
    • 

  • 'V': All eigenvalues in the half-open interval (VL, VU] will be found.
    • 

  • 'I': The IL-th through IU-th eigenvalues will be found.
    • 



For RANGE = 'V' or 'I' and IU - IL < N - 1, DSTEBZ and DSTEIN are called.


This parameter influences the choice of the algorithm and may alter the computed values.




UPLO (CHARACTER*1)


Specifies whether the upper or lower triangle of A is stored.


    

  • 'U': Upper triangle of A is stored.
    • 

  • 'L': Lower triangle of A is stored.
    • 





N (INTEGER)


The order of the matrix A. N >= 0.




A (DOUBLE PRECISION array, dimension (LDA, N))


On entry, the symmetric matrix A. If UPLO = 'U', the leading N-by-N upper triangular part of A contains the upper triangular part of the matrix A. If UPLO = 'L', the leading N-by-N lower triangular part of A contains the lower triangular part of the matrix A.


On exit, the lower triangle (if UPLO='L') or the upper triangle (if UPLO='U') of A, including the diagonal, is destroyed.




LDA (INTEGER)


The leading dimension of the array A. LDA >= max(1, N).




VL (DOUBLE PRECISION)


If RANGE='V', the lower bound of the interval to be searched for eigenvalues. VL < VU.


Not referenced if RANGE = 'A' or 'I'.




VU (DOUBLE PRECISION)


If RANGE='V', the upper bound of the interval to be searched for eigenvalues. VL < VU.


Not referenced if RANGE = 'A' or 'I'.




IL (INTEGER)


If RANGE='I', the index of the smallest eigenvalue to be returned.


1 <= IL <= IU <= N, if N > 0; IL = 1 and IU = 0 if N = 0.


Not referenced if RANGE = 'A' or 'V'.




IU (INTEGER)


If RANGE='I', the index of the largest eigenvalue to be returned.


1 <= IL <= IU <= N, if N > 0; IL = 1 and IU = 0 if N = 0.


Not referenced if RANGE = 'A' or 'V'.




ABSTOL (DOUBLE PRECISION)


The absolute error tolerance for the eigenvalues. An approximate eigenvalue is accepted as converged when it is determined to lie in an interval [a,b] of width less than or equal to


ABSTOL + EPS * max( |a|,|b| ),

SSYEVR computes the eigenvalues and, optionally, the left and/or right eigenvectors for SY matrices


Purpose:




SSYEVR computes selected eigenvalues and, optionally, eigenvectors
of a real symmetric matrix A. Eigenvalues and eigenvectors can be
selected by specifying either a range of values or a range of indices
for the desired eigenvalues. Invocations with different choices for
these parameters may result in the computation of slightly different
eigenvalues and/or eigenvectors for the same matrix. The reason for
this behavior is that there exists a variety of algorithms (each
performing best for a particular set of options) with SSYEVR
attempting to select the best based on the various parameters. In all
cases, the computed values are accurate within the limits of finite
precision arithmetic.

SSYEVR first reduces the matrix A to tridiagonal form T with a call
to SSYTRD. Then, whenever possible, SSYEVR calls SSTEMR to compute
the eigenspectrum using Relatively Robust Representations. SSTEMR

eigenvectors are computed from various L D L^T representations

orthogonalization is avoided as far as possible. More specifically,

!>          , LAPACK Working Note #7, para una discusión
!>          de qué matrices definen sus eigenvalores con alta precisión
!>          relativa.
!>

M

!>          M es INTEGER
!>          El número total de eigenvalores encontrados.  0 <= M <= N.
!>          Si RANGE = 'A', M = N, y si RANGE = 'I', M = IU-IL+1.
!>

W

!>          W es un arreglo DOUBLE PRECISION, dimensión (N)
!>          Los primeros M elementos contienen los eigenvalores seleccionados en
!>          orden ascendente.
!>

Z

!>          Z es un arreglo COMPLEX*16, dimensión (LDZ, max(1,M))
!>          Si JOBZ = 'V', entonces si INFO = 0, las primeras M columnas de Z
!>          contienen los eigenvectores ortonormales de la matriz A
!>          correspondientes a los eigenvalores seleccionados, con la i-ésima
!>          columna de Z conteniendo el eigenvector asociado con W(i).
!>          Si JOBZ = 'N', entonces Z no es referenciado.
!>          Nota: el usuario debe asegurar que al menos max(1,M) columnas sean
!>          suministradas en el arreglo Z; si RANGE = 'V', el valor exacto de M
!>          no se conoce de antemano y debe usarse una cota superior.
!>          Suministrar N columnas siempre es seguro.
!>

LDZ

!>          LDZ es INTEGER
!>          La dimensión principal del arreglo Z.  LDZ >= 1, y si
!>          JOBZ = 'V', LDZ >= max(1,N).
!>

ISUPPZ

!>          ISUPPZ es un arreglo INTEGER, dimensión ( 2*max(1,M) )
!>          El soporte de los eigenvectores en Z, es decir, los índices
!>          que indican los elementos distintos de cero en Z. El i-ésimo eigenvector
!>          es distinto de cero solo en los elementos ISUPPZ( 2*i-1 ) a través de
!>          ISUPPZ( 2*i ). Esto es una salida de ZSTEMR (matriz tridiagonal).
!>          El soporte de los eigenvectores de A es típicamente
!>          1:N debido a las transformaciones unitarias aplicadas por ZUNMTR.
!>          Implementado solo para RANGE = 'A' o 'I' y IU - IL = N - 1
!>

WORK

!>          WORK es un arreglo COMPLEX*16, dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La longitud del arreglo WORK.
!>          Si N <= 1, LWORK >= 1, de lo contrario LWORK >= 2*N.
!>          Para eficiencia óptima, LWORK >= (NB+1)*N,
!>          donde NB es el máximo del tamaño de bloque para ZHETRD y para
!>          ZUNMTR como lo devuelve ILAENV.
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula los tamaños óptimos de los arreglos WORK, RWORK e
!>          IWORK, devuelve estos valores como las primeras entradas de
!>          los arreglos WORK, RWORK e IWORK, y XERBLA no emite ningún mensaje de error
!>          relacionado con LWORK o LRWORK o LIWORK.
!>

RWORK

!>          RWORK es un arreglo DOUBLE PRECISION, dimensión (MAX(1,LRWORK))
!>          En la salida, si INFO = 0, RWORK(1) devuelve el LRWORK
!>          óptimo (y mínimo).
!>

LRWORK

!>          LRWORK es INTEGER
!>          La longitud del arreglo RWORK.
!>          Si N <= 1, LRWORK >= 1, de lo contrario LRWORK >= 24*N.
!>
!>          Si LRWORK = -1, se asume una consulta de espacio de trabajo; la
!>          rutina solo calcula los tamaños óptimos de las matrices WORK, RWORK
!>          e IWORK, devuelve estos valores como las primeras entradas
!>          de las matrices WORK, RWORK e IWORK, y XERBLA no emite ningún mensaje de error
!>          relacionado con LWORK o LRWORK o LIWORK.
!
>

IWOR

K 
!>          IWORK es una matriz INTEGER, dimensión (MAX(1,LIWORK))
!>          Al salir, si INFO = 0, IWORK(1) devuelve el valor óptimo
!>          (y mínimo) de LIWORK.
!
>

LIWOR

K 
!>          LIWORK es INTEGER
!>          La dimensión de la matriz IWORK.
!>          Si N <= 1, LIWORK >= 1, de lo contrario LIWORK >= 10*N.
!>
!>          Si LIWORK = -1, se asume una consulta de espacio de trabajo; la
!>          rutina solo calcula los tamaños óptimos de las matrices WORK, RWORK
!>          e IWORK, devuelve estos valores como las primeras entradas
!>          de las matrices WORK, RWORK e IWORK, y XERBLA no emite ningún mensaje de error
!>          relacionado con LWORK o LRWORK o LIWORK.
!
>

INF

O

!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>          > 0:  Error interno
