Descripción detallada

Esta interfaz ofrece formas de obtener información de topología sobre dispositivos OpenFabrics (InfiniBand, Omni-Path, usNIC, etc).

Documentación de funciones

int hwloc_ibv_get_device_cpuset (hwloc_topology_t topology, struct ibv_device * ibdev, hwloc_cpuset_t set) [inline]

Obtener el conjunto de CPU de procesadores que están físicamente cerca del dispositivo ibdev. Almacenar en set el conjunto de CPU que describe la localidad del dispositivo OpenFabrics ibdev (InfiniBand, etc).

La topología topology y el dispositivo ibdev deben coincidir con la máquina local. La detección de dispositivos de E/S no es necesaria en la topología.

La función solo devuelve la localidad del dispositivo. Si se necesita más información sobre el dispositivo, se deben usar objetos del sistema operativo en su lugar, consulte hwloc_ibv_get_device_osdev() y hwloc_ibv_get_device_osdev_by_name().

Esta función solo está implementada de forma significativa para Linux; otros sistemas simplemente obtendrán un conjunto de CPU completo.

Devuelve

0 si la operación fue exitosa.

-1 si ocurrió un error, por ejemplo, si la información del dispositivo no se pudo encontrar.

hwloc_obj_t hwloc_ibv_get_device_osdev (hwloc_topology_t topology, struct ibv_device * ibdev) [inline]

Obtener el objeto de dispositivo del sistema operativo de hwloc que corresponde al dispositivo OpenFabrics ibdev.

Devuelve

El objeto de dispositivo del sistema operativo de hwloc que describe el dispositivo OpenFabrics ibdev (InfiniBand, etc).

NULL si no se pudo encontrar ninguno.

La topología topology y el dispositivo ibdev deben coincidir con la máquina local. La detección de dispositivos de E/S debe estar habilitada en la topología. Si no es así, la localidad del objeto aún se puede encontrar usando hwloc_ibv_get_device_cpuset().

Nota

El objeto de dispositivo PCI correspondiente se puede obtener mirando el objeto padre del dispositivo del sistema operativo.

hwloc_obj_t hwloc_ibv_get_device_osdev_by_name (hwloc_topology_t topology, const char * ibname) [inline]

Obtener el objeto de dispositivo del sistema operativo de hwloc que corresponde al dispositivo OpenFabrics llamado ibname.

Devuelve

El objeto de dispositivo del sistema operativo de hwloc que describe el dispositivo OpenFabrics (InfiniBand, Omni-Path, usNIC, etc) cuyo nombre es ibname (mlx5_0, hfi1_0, usnic_0, qib0, etc).

NULL si no se pudo encontrar ninguno.

El nombre ibname generalmente se obtiene de ibv_get_device_name().

La topología topology no necesariamente tiene que coincidir con la máquina actual. Por ejemplo, la topología puede ser una importación XML de un host remoto. La detección de dispositivos de E/S debe estar habilitada en la topología.

Nota

El objeto de dispositivo PCI correspondiente se puede obtener mirando el objeto padre del dispositivo del sistema operativo.
