NOMBRE

hugo - Construye tu sitio

SINOPSIS

hugo [flags]

DESCRIPCIÓN

hugo es el comando principal, utilizado para construir tu sitio Hugo.

Hugo es un Generador de Sitios Estáticos Rápido y Flexible construido con amor por spf13 y amigos en Go.

La documentación completa está disponible en https://gohugo.io/.

OPCIONES

-b, --baseURL="" nombre de host (y ruta) a la raíz, p. ej., https://spf13.com/

-D, --buildDrafts[=false] incluye contenido marcado como borrador

-E, --buildExpired[=false] incluye contenido expirado

-F, --buildFuture[=false] incluye contenido con fecha de publicación en el futuro

--cacheDir="" ruta del sistema de archivos al directorio de caché

--cleanDestinationDir[=false] elimina archivos del directorio de destino que no se encuentran en los directorios estáticos

--clock="" establece el reloj utilizado por Hugo, p. ej., --clock 2021-11-06T22:30:00.00+09:00

--config="" archivo de configuración (por defecto es hugo.yaml|json|toml)

--configDir="config" directorio de configuración

-c, --contentDir="" ruta del sistema de archivos al directorio de contenido

-d, --destination="" ruta del sistema de archivos donde escribir los archivos

--disableKinds=[] deshabilita diferentes tipos de páginas (inicio, RSS, etc.)

--enableGitInfo[=false] agrega información de revisión, fecha, autor y CODEOWNERS de Git a las páginas

-e, --environment="" entorno de construcción

--forceSyncStatic[=false] copia todos los archivos cuando cambia el directorio estático.

--gc[=false] habilita la ejecución de algunas tareas de limpieza (elimina archivos de caché no utilizados) después de la construcción

-h, --help[=false] ayuda para hugo

--ignoreCache[=false] ignora el directorio de caché

--ignoreVendorPaths="" ignora cualquier _vendor para rutas de módulos que coincidan con el patrón Glob proporcionado

-l, --layoutDir="" ruta del sistema de archivos al directorio de plantillas

--logLevel="" nivel de registro (debug|info|warn|error)

--minify[=false] minimiza cualquier formato de salida soportado (HTML, XML, etc.)

--noBuildLock[=false] no crea el archivo .hugo_build.lock

--noChmod[=false] no sincroniza el modo de permisos de los archivos

--noTimes[=false] no sincroniza la hora de modificación de los archivos

--panicOnWarning[=false] entra en pánico ante la primera advertencia registrada

--poll="" establece esto a un intervalo de sondeo, p. ej., --poll 700ms, para usar un enfoque basado en sondeo para observar cambios en el sistema de archivos

--printI18nWarnings[=false] muestra advertencias de traducciones faltantes

--printMemoryUsage[=false] muestra el uso de memoria en pantalla a intervalos

--printPathWarnings[=false] muestra advertencias sobre rutas de destino duplicadas, etc.

--printUnusedTemplates[=false] muestra advertencias sobre plantillas no utilizadas.

--quiet[=false] construye en modo silencioso

--renderSegments=[] segmentos con nombre para renderizar (configurados en la configuración de segmentos)

-M, --renderToMemory[=false] renderiza a memoria (principalmente útil al ejecutar el servidor)

-s, --source="" ruta del sistema de archivos desde donde leer archivos de forma relativa

--templateMetrics[=false] muestra métricas sobre la ejecución de plantillas

--templateMetricsHints[=false] calcula algunas sugerencias de mejora cuando se combina con --templateMetrics

-t, --theme=[] temas a usar (ubicados en /themes/NOMBRE_DEL_TEMA/)

--themesDir="" ruta del sistema de archivos al directorio de temas

--trace="" escribe el rastreo en archivo (no es útil en general)

-w, --watch[=false] observa el sistema de archivos en busca de cambios y recrea según sea necesario
