NOMBRE

hostname - Archivo de configuración del nombre de host local

SINOPSIS

/etc/hostname

DESCRIPCIÓN

El archivo /etc/hostname configura el nombre del sistema local. A menos que se anule como se describe en la siguiente sección, systemd(1) establecerá este nombre de host durante el arranque utilizando la llamada al sistema sethostname(2).

El archivo debe contener una única cadena de nombre de host terminada en nueva línea. Los comentarios (líneas que comienzan con un carácter "#") se ignoran. El nombre de host debe componerse de hasta 64 caracteres alfanuméricos en minúsculas del ASCII de 7 bits o guiones que forman un nombre de dominio DNS válido. Se recomienda que este nombre contenga solo una etiqueta, es decir, sin puntos. Los caracteres no válidos se filtrarán en un intento de hacer que el nombre sea válido, pero obviamente se recomienda utilizar un nombre válido y no depender de este filtrado.

Si el carácter signo de interrogación "?" aparece en el nombre de host, se sustituirá automáticamente por un carácter hexadecimal derivado del machine-id(5) cuando se aplique, de forma segura y determinista mediante hashing criptográfico. Ejemplo: "foobar-????-????" se expandirá automáticamente a "foobar-92a9-061c" o similar, dependiendo del ID de máquina local.

Puede usar hostnamectl(1) para cambiar el valor de este archivo durante el tiempo de ejecución desde la línea de comandos. Use systemd-firstboot(1) para inicializarlo en imágenes del sistema montadas (pero no arrancadas).

SEMÁNTICA DEL NOMBRE DE HOST

systemd(1) y las herramientas asociadas obtendrán el nombre de host de las siguientes maneras:

•Si el parámetro de línea de comandos del kernel systemd.hostname= especifica un nombre de host válido, systemd(1) lo usará para establecer el nombre de host durante el arranque temprano, vea kernel-command-line(7),
•De lo contrario, se utilizará el nombre de host "estático" especificado por /etc/hostname como se describe arriba.
•De lo contrario, se puede establecer un nombre de host transitorio durante el tiempo de ejecución, por ejemplo, basándose en información de un lease DHCP, vea systemd-hostnamed.service(8). Tanto NetworkManager[1] como systemd-networkd.service(8) lo permiten. Tenga en cuenta que systemd-hostnamed.service(8) da mayor prioridad al nombre de host estático, por lo que el nombre de host transitorio solo se utilizará si el nombre de host estático no está configurado.
•De lo contrario, se utilizará un nombre de host de reserva configurado en tiempo de compilación ("archlinux").

Efectivamente, el nombre de host estático tiene mayor prioridad que un nombre de host transitorio, que tiene mayor prioridad que el nombre de host de reserva. Los nombres de host transitorios son equivalentes, por lo que el establecimiento de un nuevo nombre de host transitorio hace que se olvide el nombre de host transitorio anterior. El nombre de host especificado en la línea de comandos del kernel es como un nombre de host transitorio, con la excepción de que tiene mayor prioridad cuando la máquina arranca. Tenga en cuenta también que estas son las semánticas implementadas por las herramientas de systemd, pero otros programas también pueden establecer el nombre de host.

HISTORIA

El formato simple de archivo de configuración de /etc/hostname se origina en Debian GNU/Linux.
