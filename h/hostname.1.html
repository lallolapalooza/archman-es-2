HOSTNAME(1) Comandos de usuario HOSTNAME(1)

NOMBRE

hostname - mostrar o establecer el nombre de host del sistema

SINOPSIS

hostname [OPCIÓN...] [NOMBRE]

DESCRIPCIÓN

Muestra o establece el nombre de host del sistema.

-a, --aliases
nombres de alias
-d, --domain
nombre de dominio DNS
-f, --fqdn, --long
nombre de host DNS o FQDN
-F, --file=ARCHIVO
establece el nombre de host o el nombre de dominio NIS desde ARCHIVO
-i, --ip-addresses
direcciones para el nombre de host
-s, --short
nombre de host corto
-y, --yp, --nis
nombre de dominio NIS/YP
-?, --help
dar esta lista de ayuda
--usage
dar un mensaje de uso corto
-V, --version
imprimir la versión del programa

Los argumentos obligatorios u opcionales para las opciones largas también son obligatorios u opcionales para cualquier opción corta correspondiente.
