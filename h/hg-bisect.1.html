hg-bisect(1)

Paquete: mercurial

Licencias: GPL

HG(BISECT) HG(BISECT)

NOMBRE

hg bisect - búsqueda de subdivisión de cambiosets

SINOPSIS

hg bisect [-gbsr] [-U] [-c CMD] [REV]

DESCRIPCIÓN

Este comando ayuda a encontrar los cambiosets que introducen problemas. Para usarlo, marque el changeset más antiguo que se sepa que exhibe el problema como malo, y luego marque el changeset más reciente que esté libre del problema como bueno. Bisect actualizará su directorio de trabajo para realizar pruebas (a menos que se especifique la opción -U/--noupdate). Una vez que haya realizado las pruebas, marque el directorio de trabajo como bueno o malo, y bisect actualizará a otro changeset candidato o anunciará que ha encontrado la revisión incorrecta.

Como atajo, también puede usar el argumento de revisión para marcar una revisión como buena o mala sin extraerla primero.

Si proporciona un comando, se utilizará para la bisección automática. La variable de entorno HG_NODE contendrá el ID del changeset que se está probando. El estado de salida del comando se utilizará para marcar las revisiones como buenas o malas: el estado 0 significa bueno, 125 significa omitir la revisión, 127 (comando no encontrado) abortará la bisección, y cualquier otro estado de salida distinto de cero significa que la revisión es mala.

Algunos ejemplos:

  • iniciar una bisección con la revisión incorrecta conocida 34 y la revisión correcta 12: 
    hg bisect --bad 34
hg bisect --good 12
  • avanzar la bisección actual marcando la revisión actual como buena o mala: 
    hg bisect --good
hg bisect --bad
  • marcar la revisión actual, o una revisión conocida, para ser omitida (por ejemplo, si esa revisión no es utilizable debido a otro problema): 
    hg bisect --skip
hg bisect --skip 23
  • omitir todos los cambiosets que no tocan los directorios foo o bar: 
    hg bisect --skip "!( file('path:foo') & file('path:bar') )"
  • olvidar la bisección actual: 
    hg bisect --reset
  • usar 'make && make tests' para encontrar automáticamente la primera revisión rota: 
    hg bisect --reset
hg bisect --bad 34
hg bisect --good 12
hg bisect --command "make && make tests"
  • ver todos los cambiosets cuyos estados ya son conocidos en la bisección actual: 
    hg log -r "bisect(pruned)"
  • ver el changeset que se está biseccionando actualmente (especialmente útil si se ejecuta con -U/--noupdate): 
    hg log -r "bisect(current)"
  • ver todos los cambiosets que participaron en la bisección actual: 
    hg log -r "bisect(range)"
  • incluso puedes obtener un bonito gráfico: 
    hg log --graph -r "bisect(range)"

    Consulte hg help revisions.bisect para obtener más información sobre el predicado bisect().

    Devuelve 0 en caso de éxito.

OPCIONES

-r, --reset
restablecer el estado de bisección
-g, --good
marcar changeset como bueno
-b, --bad
marcar changeset como malo
-s, --skip
omitir la prueba del changeset
-e, --extend
extender el rango de bisección
-c,--command <CMD>
usar comando para comprobar el estado del changeset
-U, --noupdate
no actualizar al destino
