HASH-EFI-SIG-LIST(1) Comandos de usuario HASH-EFI-SIG-LIST(1)

NOMBRE

hash-to-efi-sig-list - crear una entrada de lista de firmas EFI a partir de un binario

SINOPSIS

hash-to-efi-sig-list efi-binario [efi-binario ...] lista-de-firmas-efi

DESCRIPCIÓN

Produce un archivo EFI Signature List que contiene el hash sha256 del binario EFI proporcionado.

OPCIONES

ninguna

EJEMPLOS

Para crear una lista de firmas hash EFI en el archivo hash.esl a partir del binario HelloWorld.efi, haga:

hash-efi-sig-list HelloWorld.efi hash.esl

Este archivo hash ahora se puede colocar directamente (o como una actualización) en las variables db con UpdateVar.

VER TAMBIÉN

sign-efi-sig-list(1) para obtener detalles sobre cómo producir archivos de actualización autenticados para la variable db.
