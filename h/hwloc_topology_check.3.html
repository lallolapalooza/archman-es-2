int hwloc_topology_abi_check (hwloc_topology_t topology)

Verifica que la topología sea compatible con la biblioteca hwloc actual. Esto es útil al usar la misma estructura de topología (en memoria) en diferentes bibliotecas que puedan usar instalaciones de hwloc distintas (por ejemplo, si una biblioteca incluye una versión específica de hwloc, mientras que otra biblioteca usa una instalación de hwloc del sistema predeterminada).

Si todas las bibliotecas/programas usan la misma instalación de hwloc, esta función siempre devuelve éxito.

Devuelve

0 en caso de éxito.

-1 con errno establecido a EINVAL si es incompatible.

Nota

Si se comparte entre procesos con hwloc_shmem_topology_write(), la verificación correspondiente ya se realiza dentro de hwloc_shmem_topology_adopt().

void hwloc_topology_check (hwloc_topology_t topology)

Ejecuta comprobaciones internas en una estructura de topología. El programa se aborta si se detecta una inconsistencia en la topología dada.

Parámetros

topology es la topología que se va a comprobar

Nota

Esta rutina solo es útil para desarrolladores.

La topología de entrada debe haberse cargado previamente con hwloc_topology_load().

void hwloc_topology_destroy (hwloc_topology_t topology)

Termina y libera un contexto de topología.

Parámetros

topology es la topología que se va a liberar

int hwloc_topology_dup (hwloc_topology_t * newtopology, hwloc_topology_t oldtopology)

Duplica una topología. Toda la estructura de la topología, así como sus objetos, se duplican en una nueva.

Esto es útil para mantener una copia de seguridad mientras se modifica una topología.

Devuelve

0 en caso de éxito, -1 en caso de error.

Nota

Los datos de usuario de los objetos no se duplican ya que hwloc no sabe a qué apuntan. Los objetos de las topologías antigua y nueva apuntarán a los mismos datos de usuario.

int hwloc_topology_init (hwloc_topology_t * topologyp)

Asigna un contexto de topología.

Parámetros

topologyp se le asigna un puntero al contexto recién asignado.

Devuelve

0 en caso de éxito, -1 en caso de error.

int hwloc_topology_load (hwloc_topology_t topology)

Construye la topología real. Construye la topología real una vez inicializada con hwloc_topology_init() y ajustada con Configuración y Consulta de la Detección de Topología y Cambiando la Fuente del Descubrimiento de Topología rutinas. No se puede llamar a ninguna otra rutina antes usando este contexto de topología.

Parámetros

topology es la topología que se va a cargar con objetos.

Devuelve

0 en caso de éxito, -1 en caso de error.

Nota

En caso de fallo, la topología se reinicializa. Debe ser destruida con hwloc_topology_destroy() o configurarse y cargarse de nuevo.

Esta función solo puede llamarse una vez por topología.

El enlace del hilo o proceso actual puede cambiar temporalmente durante esta llamada, pero se restaurará antes de que retorne.
