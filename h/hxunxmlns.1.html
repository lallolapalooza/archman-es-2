HXUNXMLNS(1) Utilidades HTML-XML HXUNXMLNS(1)

NOMBRE

hxunxmlns - reemplaza los "nombres globales" XML por prefijos de Namespace

SINOPSIS

hxunxmlns [ -- ] [ archivo ]

DESCRIPCIÓN

hxunxmlns es lo inverso a hxxmlns(1). Convierte los nombres de elementos y atributos de la forma


<{URL1}foo {URL2}bar="...">

a


<foo xmlns="URL1" xmlns:x="URL2" x:bar="...">

Se reconoce el Namespace XML predefinido y se reemplaza por el prefijo "xml:".

DIAGNÓSTICOS

Los siguientes valores de salida son devueltos:

0
Finalización exitosa.
> 0
Ocurrió uno o más errores en el análisis del archivo.

VER TAMBIÉN

hxxmlns(1)

ERRORES

La recuperación de errores para XML incorrecto es primitiva.
