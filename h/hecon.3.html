CHECO

N

Propósito

: 
!>
!> CHECON estima el recíproco del número de condición de una matriz
!> hermitiana compleja A usando la factorización A = U*D*U**H o
!> A = L*D*L**H calculada por CHETRF.
!>
!> Se obtiene una estimación de norm(inv(A)), y el recíproco del
!> número de condición se calcula como RCOND = 1 / (ANORM * norm(inv(A))).
!
>

Parámetro

s
UPLO 
!>          UPLO es CHARACTER*1
!>          Especifica si los detalles de la factorización se almacenan
!>          como una matriz triangular superior o inferior.
!>          = 'U':  Triangular superior, la forma es A = U*D*U**H;
!>          = 'L':  Triangular inferior, la forma es A = L*D*L**H.
!
>

N 
!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!
>

A 
!>          A es un arreglo COMPLEX, dimensión (LDA,N)
!>          La matriz diagonal por bloques D y los multiplicadores usados
!>          para obtener el factor U o L tal como fueron calculados por CHETRF.
!
>

LD

A 
!>          LDA es INTEGER
!>          La dimensión principal del arreglo A.  LDA >= max(1,N).
!
>

IPI

V 
!>          IPIV es un arreglo INTEGER, dimensión (N)
!>          Detalles de los intercambios y la estructura por bloques de D
!>          tal como fueron determinados por CHETRF.
!
>

ANOR

M 
!>          ANORM es REAL
!>          La 1-norma de la matriz original A.
!
>

D 
!>          RCOND es REAL
!>          El recíproco del número de condición de la matriz A,
!>          calculado como RCOND = 1/(ANORM * AINVNM), donde AINVNM es una
!>          estimación de la 1-norma de inv(A) calculada en esta rutina.

>

Function: DSYCON






Function: DSYCON



**Purpose:**



!> DSYCON estimates the reciprocal of the condition number (in the
!> 1-norm) of a real symmetric matrix A using the factorization
!> A = U*D*U**T or A = L*D*L**T computed by DSYTRF.
!>
!> An estimate is obtained for norm(inv(A)), and the reciprocal of the
!> condition number is computed as RCOND = 1 / (ANORM * norm(inv(A))).
!>






**Parameters**


UPLO

!>          UPLO is CHARACTER*1
!>          Specifies whether the details of the factorization are stored
!>          as an upper or lower triangular matrix.
!>          = 'U':  Upper triangular, form is A = U*D*U**T;
!>          = 'L':  Lower triangular, form is A = L*D*L**T.
!>




N

!>          N is INTEGER
!>          The order of the matrix A.  N >= 0.
!>




A

!>          A is DOUBLE PRECISION array, dimension (LDA,N)
!>          The block diagonal matrix D and the multipliers used to
!>          obtain the factor U or L as computed by DSYTRF.
!>




LDA

!>          LDA is INTEGER
!>          The leading dimension of the array A.  LDA >= max(1,N).
!>




IPIV

!>          IPIV is INTEGER array, dimension (N)
!>          Details of the interchanges and the block structure of D
!>          as determined by DSYTRF.
!>




ANORM

!>          ANORM is DOUBLE PRECISION
!>          The 1-norm of the original matrix A.
!>




RCOND

!>          RCOND is DOUBLE PRECISION
!>          The reciprocal of the condition number of the matrix A,
!>          computed as RCOND = 1/(ANORM * AINVNM), where AINVNM is an
!>          estimate of the 1-norm of inv(A) computed in this routine.
!>




WORK

!>          WORK is DOUBLE PRECISION array, dimension (2*N)
!>




IWORK

!>          IWORK is INTEGER array, dimension (N)
!>




INFO

!>          INFO is INTEGER
!>          = 0:  successful exit
!>          < 0:  if INFO = -i, the i-th argument had an illegal value
!>
