CHESV_AA calcula la solución al sistema de ecuaciones lineales A * X = B para matrices

HE

Propósito

: 
!>
!> CHESV_AA calcula la solución a un sistema de ecuaciones lineales complejo
!>    A * X = B,
!> donde A es una matriz hermitiana de N por N y X y B son matrices
!> de N por NRHS.
!>
!> El algoritmo de Aasen se utiliza para factorizar A como
!>    A = U**H * T * U,  si UPLO = 'U', o
!>    A = L * T * L**H,  si UPLO = 'L',
!> donde U (o L) es un producto de matrices de permutación y triangulares
!> unitarias superiores (inferiores), y T es hermitiana y tridiagonal. La forma
!> factorizada de A se utiliza entonces para resolver el sistema de ecuaciones A * X = B.
!
>

Parámetro

s
UPLO 
!>          UPLO es CHARACTER*1
!>          = 'U':  Se almacena el triángulo superior de A;
!>          = 'L':  Se almacena el triángulo inferior de A.
!
>

N 
!>          N es INTEGER
!>          El número de ecuaciones lineales, es decir, el orden de la
!>          matriz A.  N >= 0.
!
>

NRH

S 
!>          NRHS es INTEGER
!>          El número de miembros derechos, es decir, el número de columnas
!>          de la matriz B.  NRHS >= 0.
!
>

A 
!>          A es un arreglo COMPLEX, dimensión (LDA,N)
!>          Al entrar, la matriz hermitiana A.  Si UPLO = 'U', la parte
!>          triangular superior principal de N por N de A contiene la parte
!>          triangular superior de la matriz A, y la parte estrictamente
!>          inferior de A no se referencia.  Si UPLO = 'L', la
!>          parte triangular inferior principal de N por N de A contiene la parte
!>          triangular inferior de la matriz A, y la parte estrictamente
!>          superior de A no se referencia.
!>
!>          Al salir, si INFO = 0, la matriz tridiagonal T y los
!>          multiplicadores utilizados para obtener el factor U o L de la
!>          factorización A = U**H*T*U o A = L*T*L**H tal como se calculan con
!>          CHETRF_AA.
!
>

LD

A 
!>          LDA es INTEGER
!>          La dimensión principal del arreglo A.  LDA >= max(1,N).
!
>

IPI

V 
!>          IPIV es un arreglo INTEGER, dimensión (N)
!>          Al salir, contiene los detalles de los intercambios, es decir,
!>          la fila y columna k de A se intercambiaron con la
!>          fila y columna IPIV(k).
!
>

B 
!>          B es un arreglo COMPLEX, dimensión (LDB,NRHS)
!>          Al entrar, la matriz de miembros derechos B de N por NRHS.
!>          Al salir, si INFO = 0, la matriz de solución X de N por NRHS.
!
>

LD

B 
!>          LDB es INTEGER
!>          La dimensión principal del arreglo B.  LDB >= max(1,N).
!
>

WOR

K 
!>          WORK es un arreglo COMPLEX, dimensión (MAX(1,LWORK))
!>          Al salir, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!
>

LWOR

K 
!>          LWORK es INTEGER
!>          La longitud de WORK.  LWORK >= MAX(1,2*N,3*N-2), y para un mejor
!>          rendimiento LWORK >= MAX(1,N*NB), donde NB es el tamaño de bloque
!>          óptimo para CHETRF.
!>
!>          Si LWORK = -1, se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo del arreglo WORK, devuelve
!>          este valor como la primera entrada del arreglo WORK, y XERBLA no emite
!>          ningún mensaje de error relacionado con LWORK.
!
>

INF

O 
!>          INFO es INTEGER
!>          = 0: salida exitosa
!>          < 0: si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>          > 0: si INFO = i, D(i,i) es exactamente cero.  La factorización
!>               se ha completado, pero la matriz diagonal por bloques D es
!>               exactamente singular, por lo que no se pudo calcular la solución.
!
>
