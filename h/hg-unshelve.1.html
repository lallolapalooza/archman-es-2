NOMBRE

hg unshelve - restaura un cambio guardado en el directorio de trabajo

SINOPSIS

hg unshelve [OPCIÓN]... [[-n] GUARDADO]

DESCRIPCIÓN

Este comando acepta un nombre opcional de un cambio guardado para restaurar. Si no se proporciona ninguno, se utiliza el cambio guardado más reciente.

Si se aplica un cambio guardado con éxito, el paquete que contiene los cambios guardados se mueve a una ubicación de copia de seguridad (.hg/shelve-backup).

Dado que puedes restaurar un cambio guardado sobre un commit arbitrario, es posible que al desguardar se produzca un conflicto entre tus cambios y los commits sobre los que estás desguardando. Si esto ocurre, debes resolver el conflicto, y luego usar --continue para completar la operación de desguardado. (El paquete no se moverá hasta que completes con éxito el desguardado.)

(Alternativamente, puedes usar --abort para abandonar un desguardado que cause un conflicto. Esto revierte los cambios desguardados y deja el paquete en su lugar.)

Si se realizó un cambio guardado sin procesar (sin las opciones interactivo, incluir y excluir) en una rama recién creada, restaurará la información de la rama en el directorio de trabajo.

Después de un desguardado exitoso, los cambios guardados se almacenan en un directorio de copia de seguridad. Solo se conservan las N copias de seguridad más recientes. N tiene un valor predeterminado de 10, pero puede ser anulado utilizando la opción de configuración shelve.maxbackups.

La marca de tiempo en segundos se utiliza para decidir el orden de las copias de seguridad. Se conservan más de maxbackups copias de seguridad si la misma marca de tiempo impide decidir el orden exacto de ellas, por seguridad.

Los cambios seleccionados se pueden desguardar con la opción --interactive. El directorio de trabajo se actualiza con los cambios seleccionados y solo los cambios no seleccionados permanecen guardados. Nota: Todo el guardado se aplica primero al directorio de trabajo antes de ejecutarse interactivamente. Esto provocará todos los conflictos entre el directorio de trabajo y el guardado, independientemente de qué cambios se desguardarán.

OPCIONES

-a, --abort
abortar una operación de desguardado incompleta
-c, --continue
continuar una operación de desguardado incompleta
-i, --interactive
usar modo interactivo (EXPERIMENTAL)
-k, --keep
conservar el guardado después de desguardar
-n,--name <NOMBRE>
restaurar el cambio guardado con el nombre dado
-t,--tool <VALOR>
especificar herramienta de fusión
--date <FECHA>
establecer fecha para commits temporales (OBSOLETO)
