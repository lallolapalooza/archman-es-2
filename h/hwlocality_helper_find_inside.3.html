NAME

hwlocality_helper_find_inside - find objects by CPU set and depth/type

SYNOPSIS

#include <hwloc.h>

hwloc_obj_t
hwloc_get_obj_inside_cpuset_by_depth(hwloc_topology_t topology,
                                     hwloc_const_cpuset_t set, int depth,
                                     unsigned idx);

hwloc_obj_t
hwloc_get_obj_inside_cpuset_by_type(hwloc_topology_t topology,
                                     hwloc_const_cpuset_t set,
                                     hwloc_obj_type_t type, unsigned idx);

DESCRIPTION

These functions find objects that are included in the given CPU set set.

hwloc_get_obj_inside_cpuset_by_depth() finds the idx-th object at the given depth that is included in the CPU set set.

hwloc_get_obj_inside_cpuset_by_type() finds the idx-th object of the given type that is included in the CPU set set.

The functions return the object if found, and NULL otherwise.

These functions are useful to restrict the traversal of the topology to a subset of the machines, e.g. to get the objects in the same locality as a specific set of PUs.

When searching by type, if the type is found at multiple depths, NULL is returned and the caller should fallback to hwloc_get_obj_inside_cpuset_by_depth(). This happens for objects like HWLOC_TYPE_BRIDGE and HWloc_TYPE_PCIDEVICE.

The caller may need to check the returned object's CPU set to ensure it is fully or partially contained within the input CPU set set, as these functions only check if the object's logical index is present in the input CPU set.

Objects with empty CPU sets are ignored (otherwise they would be considered included in any given set).

RETURN VALUES

hwloc_get_obj_inside_cpuset_by_depth

The object if any. The object's logical index among the objects included in the set if any.

-1 if the object is not included in the set.

Note

Objects with empty CPU sets are ignored (otherwise they would be considered included in any given set).

This function cannot work if obj does not have CPU sets (I/O objects).

hwloc_obj_t hwloc_get_obj_inside_cpuset_by_depth (hwloc_topology_t topology, hwloc_const_cpuset_t set, int depth, unsigned idx) [inline]

Return the (logically) idx -th object at depth depth included in CPU set set.

Returns

the object if any, NULL otherwise.

Note

Objects with empty CPU sets are ignored (otherwise they would be considered included in any given set).

This function cannot work if objects at the given depth do not have CPU sets (I/O or Misc objects).

hwloc_obj_t hwloc_get_obj_inside_cpuset_by_type (hwloc_topology_t topology, hwloc_const_cpuset_t set, hwloc_obj_type_t type, unsigned idx) [inline]

Return the idx -th object of type type included in CPU set set.

Returns

the object if any.

NULL if there is no such object.

NULL if there is no depth for given type.

NULL if there are multiple depths for given type, the caller should fallback to hwloc_get_obj_inside_cpuset_by_depth().

Note

Objects with empty CPU sets are ignored (otherwise they would be considered included in any given set).

This function cannot work if objects of the given type do not have CPU sets (I/O or Misc objects).
