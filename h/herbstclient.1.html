HERBSTCLIENT(1)   HERBSTCLIENT(1)

NOMBRE

herbstclient - envía comandos a una instancia de herbstluftwm en ejecución a través de X

SINOPSIS

herbstclient [OPCIONES] COMANDO [ARG...]

herbstclient [OPCIONES] [--wait|--idle] [FILTRO...]

DESCRIPCIÓN

Envía un COMANDO con sus argumentos (opcionales) ARG a una instancia de herbstluftwm(1) en ejecución a través de Xlib. Si el COMANDO tiene una salida, esta es impresa por herbstclient. Si la salida no termina con una nueva línea, se añade una nueva línea para mejorar la legibilidad.

Consulte herbstluftwm(1) para ver una lista de los COMANDOS disponibles y sus ARG.

Si se pasa --wait o --idle, entonces espera los hooks de herbstluftwm. El hook se imprime si coincide con el FILTRO opcional. Los FILTRO son expresiones regulares. Para ver una lista de los hooks disponibles, consulte herbstluftwm(1).

OPCIONES

-n, --no-newline

No imprime una nueva línea si la salida no termina con una nueva línea.

-0, --print0

Usa el carácter nulo como delimitador entre la salida de los hooks.

-l, --last-arg

Cuando se usa -i o -w, solo imprime el último argumento del hook.

-i, --idle

Espera hooks en lugar de ejecutar comandos.

-w, --wait

Igual que --idle, pero sale después del primer hook de --count.

-c, --count CUENTA

Permite que --wait salga después de recibir e imprimir CUENTA hooks. El valor predeterminado de CUENTA es 1.

-q, --quiet

No imprime mensajes de error si herbstclient no puede conectarse a la instancia de herbstluftwm en ejecución.

-v, --version

Imprime la versión de herbstclient. Para obtener la versión de herbstluftwm, use herbstclient version.

-h, --help

Imprime el uso de herbstclient con sus opciones de línea de comandos.

VARIABLES DE ENTORNO

DISPLAY

Especifica la DISPLAY a usar, es decir, dónde se ejecuta herbstluftwm(1).

ESTADO DE SALIDA

Devuelve el estado de salida de la ejecución del COMANDO en el servidor de herbstluftwm(1).

0

Éxito.

otro

Fallo. Consulte herbstluftwm(1) para ver una lista de códigos de error.
