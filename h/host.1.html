IDN SUPPORT

Internationalized Domain Names (IDN) are domain names that include characters that are not part of the standard ASCII character set. The host utility supports IDN by converting internationalized domain names into their ASCII Compatible Encoding (ACE) representation before performing DNS lookups. This functionality is enabled by default if the GNU libidn library is installed. The IDN support can be disabled by setting the IDN_DISABLE environment variable. IDN support is disabled if the variable is set when host runs.
