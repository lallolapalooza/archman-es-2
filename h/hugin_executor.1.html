NOMBRE

hugin_executor - unir un proyecto de hugin

SINOPSIS

hugin_executor [-h] [-a] [-s] [-t <num>] [-p <str>] [-d] input.pto

DESCRIPCIÓN

hugin_executor es una herramienta de línea de comandos, útil para unir proyectos en scripts de shell.

OPCIONES

-h, --help
Muestra el mensaje de ayuda.
-a, --assistant
Ejecutar el asistente.
-s, --stitching
Ejecutar la unión con el proyecto dado.
-t, --threads=num
Número de hilos utilizados.
-p, --prefix=str
Prefijo utilizado para la unión. Cuando no se especifica un prefijo, se utilizará el prefijo de salida encontrado en el diálogo de Preferencias de Hugin. El valor predeterminado para el prefijo de salida es el nombre del archivo (incluyendo la ruta) del archivo del proyecto.
-u, --user-defined-output=str
Usar comandos definidos por el usuario en el archivo dado.
-d, --dry-run
Solo imprime comandos.
