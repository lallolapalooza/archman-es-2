Propósito

!>
!>    CHERFSX mejora la solución calculada de un sistema de ecuaciones
!>    lineales cuando la matriz de coeficientes es hermitiana indefinida, y
!>    proporciona cotas de error y estimaciones de error hacia atrás para la
!>    solución. Además de la cota de error en norma, el código proporciona
!>    la cota de error máxima por componente si es posible. Véanse los
!>    comentarios de ERR_BNDS_NORM y ERR_BNDS_COMP para los detalles de las
!>    cotas de error.
!>
!>    El sistema original de ecuaciones lineales puede haber sido
!>    ecualizado antes de llamar a esta rutina, como se describe en los
!>    argumentos EQUED y S más abajo. En este caso, la solución y las
!>    cotas de error devueltas son para el sistema original sin ecualizar.
!
> 
!>     Algunos parámetros opcionales se agrupan en el array PARAMS. Estos
!>     ajustes determinan cómo se realiza el refinamiento, pero a menudo
!>     los valores por defecto son aceptables. Si los valores por defecto
!>     son aceptables, los usuarios pueden pasar NPARAMS = 0, lo que
!>     evita que el código fuente acceda al argumento PARAMS.
!
>

s

!>       = 'U':  Se almacena el triángulo superior de A;
!>       = 'L':  Se almacena el triángulo inferior de A.
!
>

D 
!>          EQUED es CHARACTER*1
!>     Especifica la forma de ecualización que se realizó en A
!>     antes de llamar a esta rutina. Esto es necesario para calcular
!>     la solución y las cotas de error correctamente.
!>       = 'N':  Sin ecualización
!>       = 'Y':  Ecualización tanto por filas como por columnas, es decir, A ha sido
!>               reemplazada por diag(S) * A * diag(S).
!>               El segundo miembro B ha sido cambiado en consecuencia.
!
>

!>          N es INTEGER
!>     El orden de la matriz A.  N >= 0.
!
>

!>     de las matrices B y X.  NRHS >= 0.
!

!>     La matriz hermitiana A.  Si UPLO = 'U', la parte triangular superior
!>     principal N-por-N de A contiene la parte triangular superior
!>     de la matriz A, y la parte estrictamente triangular inferior
!>     de A no se referencia.  Si UPLO = 'L', la parte triangular inferior
!>     principal N-por-N de A contiene la parte triangular inferior

!>     La forma factorizada de la matriz A.  AF contiene la matriz
!>     diagonal por bloques D y los multiplicadores utilizados para obtener el
!>     factor U o L de la factorización A = U*D*U**H o A =
!>     L*D*L**H tal como los calcula CHETRF.

>

!>          IPIV es un array INTEGER, dimensión (N)
!>     Detalles de los intercambios y la estructura por bloques de D
!>     tal como los determina CHETRF.

!>     Los factores de escala para A.  Si EQUED = 'Y', A se multiplica por
!>     diag(S) por la izquierda y por la derecha.  S es un argumento de entrada si FACT =
!>     'F'; de lo contrario, S es un argumento de salida.  Si FACT = 'F' y EQUED
!>     = 'Y', cada elemento de S debe ser positivo.  Si S es de salida, cada
!>     elemento de S es una potencia de la base. Si S es de entrada, cada elemento
!>     de S debería ser una potencia de la base para garantizar una solución
!>     y estimaciones de error fiables. El escalado por potencias de la base no causa

!

D

!>     recíproco del número de condición de Skeel de la matriz A después de
!>     la ecualización (si se hizo).  Si esto es menor que la precisión
!>     de la máquina (en particular, si es cero), la matriz es singular
!>     con respecto a la precisión de trabajo.  Nótese que el error puede ser pequeño incluso
!>     si este número es muy pequeño y la matriz parece mal
!>     condicionada.

!>     Error hacia atrás relativo por componente.  Este es el
!>     error hacia atrás relativo por componente de cada vector solución X(j)
!>     (es decir, el cambio relativo más pequeño en cualquier elemento de A o B que

N_ERR_BND

!>          N_ERR_BNDS es INTEGER
!>     Número de límites de error a devolver para cada segundo miembro
!>     y cada tipo (norma global o componente a componente). Véanse
!>     ERR_BNDS_NORM y ERR_BNDS_COMP más abajo.
!
>

ERR_BNDS_NOR

M 
!>          ERR_BNDS_NORM es un array REAL, dimensión (NRHS, N_ERR_BNDS)
!>     Para cada segundo miembro, este array contiene información sobre
!>     varios límites de error y números de condición correspondientes al
!>     error relativo norma global, que se define como sigue:
!>
!>     Error relativo norma global en el i-ésimo vector solución:
!>             max_j (abs(XTRUE(j,i) - X(j,i)))
!>            --------------------------------
!>                  max_j abs(X(j,i))
!>
!>     El array se indexa por el tipo de información de error descrito
!>     más abajo. Actualmente se devuelven hasta tres piezas de
!>     información.
!>
!>     El primer índice en ERR_BNDS_NORM(i,:) corresponde al i-ésimo
!>     segundo miembro.
!>
!>     El segundo índice en ERR_BNDS_NORM(:,err) contiene los siguientes
!>     tres campos:
!>     err = 1  booleano. Confiar en la respuesta si el
!>              número de condición recíproco es menor que el umbral
!>              sqrt(n) * slamch('Epsilon').
!>
!>     err = 2  límite de error: El error hacia adelante estimado,
!>              casi con certeza dentro de un factor de 10 del error
!>              verdadero siempre que la entrada siguiente sea mayor que
!>              el umbral sqrt(n) * slamch('Epsilon'). Este límite de
!>              error solo debe confiarse si el booleano anterior es
!>              verdadero.
!>
!>     err = 3  Número de condición recíproco: Número de condición
!>              recíproco norma global estimado. Se compara con el umbral
!>              sqrt(n) * slamch('Epsilon') para determinar si la
!>              estimación de error es . Estos números de condición
!>              recíprocos son 1 / (norm(Z^{-1},inf) * norm(Z,inf)) para
!>              alguna matriz Z escalada apropiadamente.
!>              Sea Z = S*A, donde S escala cada fila por una potencia de
!>              la base de modo que todas las sumas absolutas de filas de
!>              Z sean aproximadamente 1.
!>
!>     Véase Lapack Working Note 165 para más detalles y precauciones
!>     adicionales.
!
>

ERR_BNDS_COM

P 
!>          ERR_BNDS_COMP es un array REAL, dimensión (NRHS, N_ERR_BNDS)
!>     Para cada segundo miembro, este array contiene información sobre
!>     varios límites de error y números de condición correspondientes al
!>     error relativo componente a componente, que se define como sigue:
!>
!>     Error relativo componente a componente en el i-ésimo vector
!>     solución:
!>                    abs(XTRUE(j,i) - X(j,i))
!>             max_j ----------------------
!>                         abs(X(j,i))
!>
!>     El array se indexa por el segundo miembro i (del cual depende el
!>     error relativo componente a componente), y el tipo de información
!>     de error descrito más abajo. Actualmente se devuelven hasta tres
!>     piezas de información para cada segundo miembro. Si no se solicita
!>     precisión componente a componente (PARAMS(3) = 0.0), entonces no
!>     se accede a ERR_BNDS_COMP. Si N_ERR_BNDS < 3, entonces se
!>     devuelven como máximo las primeras entradas (:,N_ERR_BNDS).
!>
!>     El primer índice en ERR_BNDS_COMP(i,:) corresponde al i-ésimo
!>     segundo miembro.
!>
!>     El segundo índice en ERR_BNDS_COMP(:,err) contiene los siguientes
!>     tres campos:
!>     err = 1  booleano. Confiar en la respuesta si el
!>              número de condición recíproco es menor que el umbral
!>              sqrt(n) * slamch('Epsilon').
!>
!>     err = 2  límite de error: El error hacia adelante estimado,
!>              casi con certeza dentro de un factor de 10 del error
!>              verdadero siempre que la entrada siguiente sea mayor que
!>              el umbral sqrt(n) * slamch('Epsilon'). Este límite de
!>              error solo debe confiarse si el booleano anterior es
!>              verdadero.
!>
!>     err = 3  Número de condición recíproco: Número de condición
!>              recíproco componente a componente estimado. Se compara
!>              con el umbral sqrt(n) * slamch('Epsilon') para determinar
!>              si la estimación de error es . Estos números de condición
!>              recíprocos son 1 / (norm(Z^{-1},inf) * norm(Z,inf)) para
!>              alguna matriz Z escalada apropiadamente.
!>              Sea Z = S*(A*diag(x)), donde x es la solución para el
!>              segundo miembro actual y S escala cada fila de
!>              A*diag(x) por una potencia de la base de modo que todas
!>              las sumas absolutas de filas de Z sean aproximadamente 1.
!>
!>     Véase Lapack Working Note 165 para más detalles y precauciones
!>     adicionales.
!
>

Description:


ZSyrfsx computes the high condition number estimation for a system of
linear equations solved by Zsyrfs.


Purpose:


  ZSyrfsx routines compute the forward error, and estimate of the
  relative backward error, and interval error bounds for the
  solution of a system of linear equations.
  


This routine is an interface to the double-precision version Zsyrfs

DESCRIPCIÓN

La biblioteca her proporciona una serie de funciones de utilidad para la manipulación de cadenas y la codificación/decodificación Base64.

Funciones de manipulación de cadenas:

  • her_strdup: Duplica una cadena.
  • her_strndup: Duplica una cadena hasta un número específico de caracteres.
  • her_streq: Compara dos cadenas para igualdad.
  • her_strneq: Compara dos cadenas hasta un número específico de caracteres para igualdad.
  • her_strrev: Invierte una cadena.
  • her_strlower: Convierte una cadena a minúsculas.
  • her_strupper: Convierte una cadena a mayúsculas.
  • her_trim: Elimina los espacios en blanco iniciales y finales de una cadena.
  • her_trim_left: Elimina los espacios en blanco iniciales de una cadena.
  • her_trim_right: Elimina los espacios en blanco finales de una cadena.
  • her_str_replace: Reemplaza todas las ocurrencias de una subcadena con otra.
  • her_str_repeat: Repite una cadena un número específico de veces.
  • her_str_slice: Extrae una porción de una cadena.
  • her_str_split: Divide una cadena en un array de subcadenas basándose en un delimitador.
  • her_str_join: Une un array de cadenas en una sola cadena con un delimitador especificado.

Funciones de codificación/decodificación Base64:

  • her_base64_encode: Codifica datos binarios en una cadena Base64.
  • her_base64_decode: Decodifica una cadena Base64 en datos binarios.

VALOR DE RETORNO

Las funciones que devuelven cadenas asignan memoria dinámicamente para la cadena resultante. El llamante es responsable de liberar esta memoria usando free().

Las funciones de comparación (her_streq, her_strneq) devuelven 1 si las cadenas son iguales y 0 en caso contrario.

her_str_split devuelve un array de cadenas y establece el valor de count al número de elementos en el array. Devuelve NULL en caso de error.

her_str_join devuelve la cadena unida o NULL en caso de error.

her_base64_encode devuelve la cadena codificada o NULL en caso de error.

her_base64_decode devuelve los datos decodificados y establece output_length. Devuelve NULL en caso de error.
