Descripción Detallada

Esto incluye ayudas para manipular archivos cpumap del kernel de Linux, y equivalentes de hwloc a las llamadas del sistema Linux sched_setaffinity y sched_getaffinity.

Documentación de Funciones

int hwloc_linux_get_tid_cpubind (hwloc_topology_t topology, pid_t tid, hwloc_cpuset_t set)

Obtiene la vinculación actual del hilo tid. El conjunto de CPUs set (previamente asignado por el llamador) se rellena con la lista de PUs a las que el hilo estaba previamente vinculado.

El comportamiento es exactamente el mismo que la llamada del sistema Linux sched_getaffinity, pero usa un conjunto de CPUs de hwloc.

Retorna

0 en caso de éxito, -1 en caso de error.

Nota

Esto es equivalente a llamar a hwloc_get_proc_cpubind() con HWLOC_CPUBIND_THREAD como flags.

int hwloc_linux_get_tid_last_cpu_location (hwloc_topology_t topology, pid_t tid, hwloc_bitmap_t set)

Obtiene la última CPU física en la que se ejecutó el hilo tid. El conjunto de CPUs set (previamente asignado por el llamador) se rellena con la PU en la que el hilo se ejecutó por última vez.

Retorna

0 en caso de éxito, -1 en caso de error.

Nota

Esto es equivalente a llamar a hwloc_get_proc_last_cpu_location() con HWLOC_CPUBIND_THREAD como flags.

int hwloc_linux_read_path_as_cpumask (const char * path, hwloc_bitmap_t set)

Convierte una ruta de archivo cpumask del kernel de Linux en un conjunto de bits de hwloc set. Podría usarse al leer conjuntos de CPUs de atributos de sysfs como topología y cachés para procesadores, o local_cpus para dispositivos.

Retorna

0 en caso de éxito, -1 en caso de error.

Nota

Esta función ignora la variable de entorno HWLOC_FSROOT.

int hwloc_linux_set_tid_cpubind (hwloc_topology_t topology, pid_t tid, hwloc_const_cpuset_t set)

Vincula un hilo tid a las CPUs dadas en el conjunto set. El comportamiento es exactamente el mismo que la llamada del sistema Linux sched_setaffinity, pero usa un conjunto de CPUs de hwloc.

Retorna

0 en caso de éxito, -1 en caso de error.

Nota

Esto es equivalente a llamar a hwloc_set_proc_cpubind() con HWLOC_CPUBIND_THREAD como flags.
