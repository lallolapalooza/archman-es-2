CHPGVD

Propósito:

!>
!> CHPGVD calcula todos los eigenvalores y, opcionalmente, los eigenvectores
!> de un problema de eigenvalores generalizado hermitiano-definido complejo, de la forma
!> A*x=(lambda)*B*x,  A*Bx=(lambda)*x,  o B*A*x=(lambda)*x.  Aquí se asume que A y
!> B son hermitianos, almacenados en formato empaquetado, y que B es también
!> definido positivo.
!> Si se desean eigenvectores, se utiliza un algoritmo de divide y vencerás.
!>
!>

Parámetros

ITYPE 
!>          ITYPE es INTEGER
!>          Especifica el tipo de problema a resolver:
!>          = 1:  A*x = (lambda)*B*x
!>          = 2:  A*B*x = (lambda)*x
!>          = 3:  B*A*x = (lambda)*x
!>

JOBZ

!>          JOBZ es CHARACTER*1
!>          = 'N':  Calcula solo eigenvalores;
!>          = 'V':  Calcula eigenvalores y eigenvectores.
!>

UPLO

!>          UPLO es CHARACTER*1
!>          = 'U':  Se almacenan los triángulos superiores de A y B;
!>          = 'L':  Se almacenan los triángulos inferiores de A y B.
!>

N

!>          N es INTEGER
!>          El orden de las matrices A y B.  N >= 0.
!>

AP

!>          AP es un arreglo COMPLEX, dimensión (N*(N+1)/2)
!>          En la entrada, el triángulo superior o inferior de la matriz hermitiana
!>          A, empaquetado por columnas en un arreglo lineal.  La j-ésima columna de A
!>          se almacena en el arreglo AP de la siguiente manera:
!>          si UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) para 1<=i<=j;
!>          si UPLO = 'L', AP(i + (j-1)*(2*n-j)/2) = A(i,j) para j<=i<=n.
!>
!>          En la salida, el contenido de AP se destruye.
!>

BP

!>          BP es un arreglo COMPLEX, dimensión (N*(N+1)/2)
!>          En la entrada, el triángulo superior o inferior de la matriz hermitiana
!>          B, empaquetado por columnas en un arreglo lineal.  La j-ésima columna de B
!>          se almacena en el arreglo BP de la siguiente manera:
!>          si UPLO = 'U', BP(i + (j-1)*j/2) = B(i,j) para 1<=i<=j;
!>          si UPLO = 'L', BP(i + (j-1)*(2*n-j)/2) = B(i,j) para j<=i<=n.
!>
!>          En la salida, el factor triangular U o L de la factorización de Cholesky
!>          B = U**H*U o B = L*L**H, en el mismo formato de almacenamiento
!>          que B.
!>

W

!>          W es un arreglo REAL, dimensión (N)
!>          Si INFO = 0, los eigenvalores en orden ascendente.
!>

Z

!>          Z es un arreglo COMPLEX, dimensión (LDZ, N)
!>          Si JOBZ = 'V', entonces si INFO = 0, Z contiene la matriz Z de
!>          eigenvectores.  Los eigenvectores se normalizan de la siguiente manera:
!>          si ITYPE = 1 o 2, Z**H*B*Z = I;
!>          si ITYPE = 3, Z**H*inv(B)*Z = I.
!>          Si JOBZ = 'N', entonces Z no se referencia.
!>

LDZ

!>          LDZ es INTEGER
!>          La dimensión principal del arreglo Z.  LDZ >= 1, y si
!>          JOBZ = 'V', LDZ >= max(1,N).
!>

WORK

!>          WORK es un arreglo COMPLEX, dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK requerido.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del arreglo WORK.
!>          Si N <= 1,               LWORK >= 1.
!>          Si JOBZ = 'N' y N > 1, LWORK >= N.
!>          Si JOBZ = 'V' y N > 1, LWORK >= 2*N.
!>
!>          Si LWORK = -1, se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula los tamaños requeridos de los arreglos WORK, RWORK e
!>          IWORK, devuelve estos valores como las primeras entradas de
!>          los arreglos WORK, RWORK e IWORK, y XERBLA no emite ningún mensaje de error
!>          relacionado con LWORK o LRWORK o LIWORK.
!>

RWORK

!>          RWORK es un arreglo REAL, dimensión (MAX(1,LRWORK))
!>          En la salida, si INFO = 0, RWORK(1) devuelve el LRWORK requerido.
!>

LRWORK

!>          LRWORK es INTEGER
!>          La dimensión del arreglo RWORK.
!>          Si N <= 1,               LRWORK >= 1.
!>          Si JOBZ = 'N' y N > 1, LRWORK >= N.
!>          Si JOBZ = 'V' y N > 1, LRWORK >= 1 + 5*N + 2*N**2.
!>
!>          Si LRWORK = -1, se asume una consulta de espacio de trabajo; la
!>          rutina solo calcula los tamaños requeridos de los arreglos WORK, RWORK
!>          e IWORK, devuelve estos valores como las primeras entradas
!>          de los arreglos WORK, RWORK e IWORK, y XERBLA no emite ningún mensaje de error
!>          relacionado con LWORK o LRWORK o LIWORK.
!>

IWORK

!>          IWORK es un arreglo INTEGER, dimensión (MAX(1,LIWORK))
!>          En la salida, si INFO = 0, IWORK(1) devuelve el LIWORK requerido.
!>

LIWORK

!>          LIWORK es INTEGER
!>          La dimensión del arreglo IWORK.
!>          Si JOBZ  = 'N' o N <= 1, LIWORK >= 1.
!>          Si JOBZ  = 'V' y N > 1, LIWORK >= 3 + 5*N.
!>
!>          Si LIWORK = -1, se asume una consulta de espacio de trabajo; la
!>          rutina solo calcula los tamaños requeridos de los arreglos WORK, RWORK
!>          e IWORK, devuelve estos valores como las primeras entradas
!>          de los arreglos WORK, RWORK e IWORK, y XERBLA no emite ningún mensaje de error
!>          relacionado con LWORK o LRWORK o LIWORK.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>          > 0:  CPPTRF o CHPEVD devolvió un código de error:
!>             <= N:  si INFO = i, CHPEVD falló en converger;
!>                    i elementos fuera de la diagonal de una forma
!>                    tridiagonal intermedia no convergieron a cero;
!>             > N:   si INFO = N + i, para 1 <= i <= n, entonces el menor
!>                    principal principal de orden i de B no es positivo.
!>                    La factorización de B no pudo completarse y
!>                    no se calcularon eigenvalores ni eigenvectores.
!>
