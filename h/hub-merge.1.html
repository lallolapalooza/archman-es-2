NOMBRE

hub-merge - Fusiona una solicitud de extracción (pull request) localmente con un mensaje similar al botón de fusión de GitHub.

SINOPSIS

hub merge URL-SOLICITUD-ESTIRAMIENTO

Esto crea un commit de fusión local en la rama actual, pero no cambia realmente el estado de la solicitud de extracción. Sin embargo, la solicitud de extracción se cerrará automáticamente y se marcará como "fusionada" tan pronto como el commit de fusión recién creado se suba a la rama predeterminada del repositorio remoto.

EJEMPLOS

$ hub merge https://github.com/jingweno/gh/pull/73
> git fetch origin refs/pull/73/head
> git merge FETCH_HEAD --no-ff -m "Merge pull request #73 from jingweno/feature..."
