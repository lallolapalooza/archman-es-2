HOSTAPD_CLI(1) interfaz de línea de comandos de hostapd HOSTAPD_CLI(1)

NOMBRE

hostapd_cli - interfaz de línea de comandos de hostapd

SINOPSIS

hostapd_cli [-p<ruta>] [-i<nombre_interfaz>] [-a<ruta>] [-hvB] [comando..]

DESCRIPCIÓN

Esta página del manual documenta brevemente la utilidad hostapd_cli.

hostapd_cli es una interfaz de línea de comandos para el demonio hostapd.

hostapd es un demonio en espacio de usuario para puntos de acceso y servidores de autenticación. Implementa la gestión del punto de acceso IEEE 802.11, autenticadores IEEE 802.1X/WPA/WPA2/EAP y servidor de autenticación RADIUS. Para más información sobre hostapd, consulte la página del manual hostapd(8).

OPCIONES

A continuación se incluye un resumen de las opciones. Para obtener una descripción completa, ejecute hostapd_cli desde la línea de comandos.

-p<ruta>
Ruta para encontrar los sockets de control.

Por defecto: /var/run/hostapd

-i<nombre_interfaz>
Interfaz en la que escuchar.

Por defecto: la primera interfaz encontrada en la ruta del socket.

-a<ruta>
Ejecutar en modo demonio ejecutando el archivo de acción según los eventos de hostapd.
-B
Ejecutar un demonio en segundo plano.
-h
Mostrar uso.
-v
Mostrar la versión de hostapd_cli.

COMANDOS

A continuación se incluye un resumen de los comandos. Para obtener una descripción completa, ejecute hostapd_cli desde la línea de comandos.

mib
Obtener variables MIB (dot1x, dot11, radius).
sta <dirección>
Obtener variables MIB para una estación.
all_sta
Obtener variables MIB para todas las estaciones.
help
Obtener ayuda de uso.
interface [nombre_interfaz]
Mostrar interfaces/seleccionar interfaz.
level <nivel_depuracion>
Cambiar el nivel de depuración.
license
Mostrar la licencia completa de hostapd_cli.
quit
Salir de hostapd_cli.
