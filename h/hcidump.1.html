Nombre

hcidump - Analizar datos HCI

SINOPSIS

hcidump -h

hcidump [OPCIONES ...] [FILTROS]

DESCRIPCIÓN

hcidump(1) lee datos HCI brutos que provienen y van a un dispositivo Bluetooth (que puede ser especificado con la opción -i, por defecto es el primer dispositivo disponible) e imprime en pantalla comandos, eventos y datos de forma legible para humanos. Opcionalmente, el volcado puede ser escrito en un archivo en lugar de ser analizado, y el archivo de volcado puede ser analizado posteriormente.

OPCIONES

-i <hciX>
Los datos se leen de hciX, que debe ser el nombre de un dispositivo Bluetooth instalado. Si no se especifica, y si la opción -r no está configurada, los datos se leen del primer dispositivo Bluetooth disponible.
-l <longitud>, --snap-len=<longitud>
Establece la longitud máxima de los paquetes procesados a longitud.
-p <psm>, --psm=<psm>
Establece el multiplexor de servicio de protocolo por defecto a psm.
-m <id_comp>, --manufacturer=<id_comp>
Establece el ID de compañía por defecto para el fabricante a id_comp.
-w <archivo>, --save-dump=<archivo>
El resultado del análisis no se imprime en pantalla, en su lugar, los datos leídos del dispositivo se guardan en archivo. El archivo de volcado guardado puede ser analizado posteriormente con la opción -r.
-r <archivo>, --read-dump=<archivo>
Los datos no se leen de un dispositivo Bluetooth, sino de archivo. archivo se crea con la opción -t, --timestamp antepone una marca de tiempo a cada paquete.
-a, --ascii
Para cada paquete, no solo se muestra el tipo de paquete, sino también todos los datos en ASCII.
-x, --hex
Para cada paquete, no solo se muestra el tipo de paquete, sino también todos los datos en hexadecimal.
-X, --ext
Para cada paquete, no solo se muestra el tipo de paquete, sino también todos los datos en hexadecimal y ASCII.
-R, --raw
Para cada paquete, solo se muestran los datos brutos.
-C <psm>, --cmtp=<psm>
Establece el valor PSM para el Protocolo de Transporte de Mensajes CAPI.
-H <psm>, --hcrp=<psm>
Establece el valor PSM para el Canal de Control de Impresión (Hardcopy Control Channel).
-O <canal>, --obex=<canal>
Establece el valor del canal RFCOMM para el Protocolo de Intercambio de Objetos.
-P <canal>, --ppp=<canal>
Establece el valor del canal RFCOMM para el Protocolo Punto a Punto.
-D <archivo>, --pppdump=<archivo>
Extrae el tráfico PPP en formato pppdump.
-A <archivo>, --audio=<archivo>
Extrae datos de audio SCO.
-Y, --novendor
No muestra comandos ni eventos de proveedor y no muestra ningún código PIN ni clave de enlace en texto plano.
-h
Imprime información de uso y sale.

FILTROS

filter es una lista separada por espacios de categorías de paquetes: las categorías disponibles son lmp, hci, sco, l2cap, rfcomm, sdp, bnep, cmtp, hidp, hcrp, avdtp, avctp, obex, capi y ppp. Si se usan filtros, solo se vuelcan los paquetes que pertenecen a las categorías especificadas. Por defecto, se vuelcan todos los paquetes.
