subrutina chpr (carácter uplo, entero n, real alpha, complejo, dimensión(*) x, entero incx, complejo, dimensión(*) ap)

CHPR

Propósito:

!>
!> CHPR    realiza la operación de rango 1 Hermitiana
!>
!>    A := alpha*x*x**H + A,
!>
!> donde alpha es un escalar real, x es un vector de n elementos y A es una
!> matriz Hermitiana de n por n, suministrada en forma empacada.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>           En la entrada, UPLO especifica si la parte triangular superior o inferior
!>           de la matriz A se suministra en el array empacado AP de la siguiente manera:
!>
!>              UPLO = 'U' o 'u'   La parte triangular superior de A se
!>                                  suministra en AP.
!>
!>              UPLO = 'L' o 'l'   La parte triangular inferior de A se
!>                                  suministra en AP.
!>

N

!>          N es INTEGER
!>           En la entrada, N especifica el orden de la matriz A.
!>           N debe ser al menos cero.
!>

ALPHA

!>          ALPHA es REAL
!>           En la entrada, ALPHA especifica el escalar alpha.
!>

X

!>          X es un array COMPLEX, de dimensión al menos
!>           ( 1 + ( n - 1 )*abs( INCX ) ).
!>           Antes de la entrada, el array X incrementado debe contener el vector x
!>           de n elementos.
!>

INCX

!>          INCX es INTEGER
!>           En la entrada, INCX especifica el incremento para los elementos de
!>           X. INCX no debe ser cero.
!>

AP

!>          AP es un array COMPLEX, de dimensión al menos
!>           ( ( n*( n + 1 ) )/2 ).
!>           Antes de la entrada con  UPLO = 'U' o 'u', el array AP debe
!>           contener la parte triangular superior de la matriz Hermitiana
!>           empacada secuencialmente, columna por columna, de modo que AP( 1 )
!>           contiene a( 1, 1 ), AP( 2 ) y AP( 3 ) contienen a( 1, 2 )
!>           y a( 2, 2 ) respectivamente, y así sucesivamente. En la salida, el array
!>           AP se sobrescribe con la parte triangular superior de la
!>           matriz actualizada.
!>           Antes de la entrada con UPLO = 'L' o 'l', el array AP debe
!>           contener la parte triangular inferior de la matriz Hermitiana
!>           empacada secuencialmente, columna por columna, de modo que AP( 1 )
!>           contiene a( 1, 1 ), AP( 2 ) y AP( 3 ) contienen a( 2, 1 )
!>           y a( 3, 1 ) respectivamente, y así sucesivamente. En la salida, el array
!>           AP se sobrescribe con la parte triangular inferior de la
!>           matriz actualizada.
!>           Tenga en cuenta que las partes imaginarias de los elementos diagonales no
!>           necesitan ser establecidas, se asumen cero, y en la salida se
!>           establecen a cero.
!>
