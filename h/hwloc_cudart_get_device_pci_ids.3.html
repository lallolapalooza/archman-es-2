Descripción Detallada

Esta interfaz ofrece formas de recuperar información de topología sobre dispositivos CUDA al usar la API CUDA Runtime.

Documentación de Funciones

int hwloc_cudart_get_device_cpuset (hwloc_topology_t topology, int idx, hwloc_cpuset_t set) [inline]

Obtener el conjunto de CPU de procesadores que están físicamente cerca del dispositivo idx. Almacenar en set el conjunto de CPU que describe la localidad del dispositivo CUDA cuyo índice es idx.

La topología topology y el dispositivo idx deben coincidir con la máquina local. La detección de dispositivos de E/S y el componente CUDA no son necesarios en la topología.

La función solo devuelve la localidad del dispositivo. Si se necesita más información sobre el dispositivo, se deben usar objetos del sistema operativo en su lugar, consulte hwloc_cudart_get_device_osdev_by_index().

Esta función actualmente solo se implementa de forma significativa para Linux; otros sistemas simplemente obtendrán un conjunto de CPU completo.

Retorna

0 si tiene éxito.

-1 en caso de error, por ejemplo, si no se pudo encontrar la información del dispositivo.

hwloc_obj_t hwloc_cudart_get_device_osdev_by_index (hwloc_topology_t topology, unsigned idx) [inline]

Obtener el objeto de dispositivo OS de hwloc correspondiente al dispositivo CUDA cuyo índice es idx.

Retorna

El objeto de dispositivo OS de hwloc que describe el dispositivo CUDA cuyo índice es idx.

NULL si no se pudo encontrar ninguno.

La topología topology no necesariamente tiene que coincidir con la máquina actual. Por ejemplo, la topología puede ser una importación XML de un host remoto. La detección de dispositivos de E/S y el componente CUDA deben estar habilitados en la topología. De lo contrario, la localidad del objeto aún puede encontrarse usando hwloc_cudart_get_device_cpuset().

Nota

El objeto de dispositivo PCI correspondiente se puede obtener mirando el objeto padre del dispositivo OS (a menos que los dispositivos PCI estén filtrados).

Esta función es idéntica a hwloc_cuda_get_device_osdev_by_index().

int hwloc_cudart_get_device_pci_ids (hwloc_topology_t topology, int idx, int * domain, int * bus, int * dev) [inline]

Devolver los IDs de dominio, bus y dispositivo del dispositivo CUDA cuyo índice es idx. El índice de dispositivo idx debe coincidir con la máquina local.

Retorna

0 si tiene éxito.

-1 en caso de error, por ejemplo, si no se pudo encontrar la información del dispositivo.

hwloc_obj_t hwloc_cudart_get_device_pcidev (hwloc_topology_t topology, int idx) [inline]

Obtener el objeto de dispositivo PCI de hwloc correspondiente al dispositivo CUDA cuyo índice es idx.

Retorna

El objeto de dispositivo PCI de hwloc que describe el dispositivo CUDA cuyo índice es idx.

NULL si no se pudo encontrar ninguno.

La topología topology y el dispositivo idx deben coincidir con la máquina local. La detección de dispositivos de E/S debe estar habilitada en la topología topology. El componente CUDA no es necesario en la topología.
