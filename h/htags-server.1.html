NOMBRE

htags-server - un servidor web/cgi privado para htags

SINOPSIS

htags-server [-b dirección-ip][-u idioma][--retry[=n]][puerto]

DESCRIPCIÓN

Htags-server es un servidor web/cgi privado para el texto hipervinculado generado por htags(1).

Antes de usar este comando, deberías ejecutar htags(1). Luego puedes ejecutar htags-server en el mismo lugar. Puedes empezar a navegar en 'http://localhost:8000/' por defecto. Para detener el servidor, simplemente presiona 'CTRL-C'.

Se requiere Python 2/3 o Ruby con WEBrick. Por defecto, htags-server busca python primero, si no lo encuentra, busca ruby.

OPCIONES

Las siguientes opciones están disponibles:

-b, --bind dirección-ip
Especifica la dirección IP en la que htags-server escuchará. El valor por defecto es 127.0.0.1.
-u, --use idioma
Especifica el idioma a usar, que puede ser uno de: ´python´ y ´ruby´.
--retry[=n]
Si el puerto ya está en uso, reintenta n veces incrementando el número de puerto. El valor por defecto de n es 20.
puerto
Especifica el puerto en el que htags-server escuchará. Si quieres usar múltiples sesiones, debes usar un número único para cada htags-server. El valor por defecto es 8000.

EJEMPLOS

$ gtags
$ htags --suggest2
$ htags-server
Python2 http/cgi server
Serving HTTP on 127.0.0.1 port 8000 ...
(otra terminal)
$ firefox http://localhost:8000/
$ htags-server
Error: port 8000 already in use.
$ htags-server --retry
Warning: port 8000 already in use (skipped)
Please access at http://127.0.0.1:8001
Python2 http/cgi server
Serving HTTP on 127.0.0.1 port 8001 ...

DIAGNÓSTICO

Htags-server sale con un valor distinto de 0 si ocurrió un error, 0 en caso contrario.
