Descripción detallada

Cada tipo de objeto es Normal (es decir, hwloc_obj_type_is_normal() devuelve 1), o Memoria (es decir, hwloc_obj_type_is_memory() devuelve 1) o E/S (es decir, hwloc_obj_type_is_io() devuelve 1) o Varios (es decir, igual a HWLOC_OBJ_MISC). No puede ser de más de una de estas clases.

Ver también Clase de objeto en Términos y Definiciones.

Documentación de funciones

int hwloc_obj_type_is_cache (hwloc_obj_type_t type)

Comprueba si un tipo de objeto es una caché de CPU (Datos, Unificada o Instrucción). Las cachés del lado de memoria no son cachés de CPU.

Devuelve

1 si un objeto de tipo type es una Caché, 0 en caso contrario.

int hwloc_obj_type_is_dcache (hwloc_obj_type_t type)

Comprueba si un tipo de objeto es una caché de Datos o Unificada de CPU. Las cachés del lado de memoria no son cachés de CPU.

Devuelve

1 si un objeto de tipo type es una Caché de Datos o Unificada de CPU, 0 en caso contrario.

int hwloc_obj_type_is_icache (hwloc_obj_type_t type)

Comprueba si un tipo de objeto es una Caché de Instrucciones de CPU. Las cachés del lado de memoria no son cachés de CPU.

Devuelve

1 si un objeto de tipo type es una Caché de Instrucciones de CPU, 0 en caso contrario.

int hwloc_obj_type_is_io (hwloc_obj_type_t type)

Comprueba si un tipo de objeto es de E/S. Los objetos de E/S son objetos adjuntos a sus padres en la lista de hijos de E/S. Esto incluye actualmente Puentes, dispositivos PCI y de SO.

Devuelve

1 si un objeto de tipo type es un objeto de E/S, 0 en caso contrario.

int hwloc_obj_type_is_memory (hwloc_obj_type_t type)

Comprueba si un tipo de objeto es Memoria. Los objetos de Memoria son objetos adjuntos a sus padres en la lista de hijos de Memoria. Esto incluye actualmente nodos NUMA y cachés del lado de memoria.

Devuelve

1 si un objeto de tipo type es un objeto de Memoria, 0 en caso contrario.

int hwloc_obj_type_is_normal (hwloc_obj_type_t type)

Comprueba si un tipo de objeto es Normal. Los objetos Normal son objetos de la jerarquía principal de CPU (Máquina, Paquete, Núcleo, PU, cachés de CPU, etc.), pero no son nodos NUMA, dispositivos de E/S ni objetos Varios.

Están adjuntos a su padre como hijos Normales, no como hijos de Memoria, E/S o Varios.

Devuelve

1 si un objeto de tipo type es un objeto Normal, 0 en caso contrario.
