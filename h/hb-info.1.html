HB-INFO(1) Comandos de usuario HB-INFO(1)

NOMBRE

hb-info - página del manual para hb-info 12.2.0

DESCRIPCIÓN

Uso:

hb-info [OPCIÓN???] [ARCHIVO-DE-FUENTE]

Consulta información de la fuente.

Opciones de ayuda:

-h, --help
Mostrar opciones de ayuda
--help-all
Mostrar todas las opciones de ayuda
--help-face
Opciones para la cara de la fuente
--help-font
Opciones para la instancia de la fuente
--help-variations
Opciones para las variaciones de fuente utilizadas
--help-misc
Opciones misceláneas que afectan las consultas
--help-query
Opciones para consultar la instancia de la fuente

Opciones de cara de fuente:

--font-file=nombre-archivo
Establecer nombre de archivo de fuente
-y, --face-index=índice
Establecer índice de cara (por defecto: 0)
--face-loader=cargador
Establecer cargador de cara a utilizar (por defecto: ot)
Los cargadores de cara compatibles son: ot/ft
--list-face-loaders
Listar cargadores de cara disponibles y salir

Opciones de instancia de fuente:

--font-size=1/2 enteros o 'upem'
Tamaño de fuente (por defecto: upem)
--font-ppem=1/2 enteros
Establecer píxeles x,y por EM (por defecto: 0; deshabilitado)
--font-ptem=tamaño-de-punto
Establecer tamaño de punto de fuente (por defecto: 0; deshabilitado)
--font-bold=1/2 números; ej. 0.05
Establecer negrita sintética (por defecto: 0)
--font-grade=1/2 números; ej. 0.05
Establecer grado sintético (por defecto: 0)
--font-slant=inclinación ratio; ej. 0.2
Establecer inclinación sintética (por defecto: 0)
--font-funcs=impl
Establecer implementación de funciones de fuente a utilizar (por defecto: ot)
Las implementaciones de funciones de fuente compatibles son: ot/ft
--list-font-funcs
Listar funciones de fuente disponibles y salir
--ft-load-flags=entero
Establecer banderas de carga de FreeType (por defecto: 2)

Opciones de variaciones:

--named-instance=índice
Establecer índice de instancia nombrada (por defecto: ninguno)
--variations=lista
Lista separada por comas de variaciones de fuente
Las variaciones se establecen globalmente. El formato para especificar la configuración de variaciones sigue. Todos los valores válidos de font-variation-settings de CSS que no sean 'normal' e 'inherited' también se aceptan, aunque no se documentan a continuación.
El formato es una etiqueta, seguida opcionalmente por un signo igual, seguido por un número. Por ejemplo:
"wght=500" "slnt=-7.5"

Opciones misceláneas:

--direction=ltr/rtl/ttb/btt
Establecer dirección (por defecto: ltr)
--script=etiqueta ISO-15924; ej. 'Latn'
Establecer script (por defecto: ninguno)
--language=etiqueta BCP 47; ej. 'es'
Establecer idioma (por defecto: $LANG)
--ot-script=etiqueta; ej. 'latn'
Establecer etiqueta de script OpenType (por defecto: ninguna)
--ot-language=etiqueta; ej. 'ESP'
Establecer etiqueta de idioma OpenType (por defecto: ninguna)

Opciones de consulta:

-a, --all
Mostrar todo
--show-all
Mostrar toda la información corta (por defecto)
--show-face-count
Mostrar recuento de caras
--show-family
Mostrar nombre de familia
--show-subfamily
Mostrar nombre de subfamilia
--show-unique-name
Mostrar nombre único
--show-full-name
Mostrar nombre completo
--show-postscript-name
Mostrar nombre Postscript
--show-version
Mostrar versión
--show-technology
Mostrar tecnología
--show-unicode-count
Mostrar recuento de Unicode
--show-glyph-count
Mostrar recuento de glifos
--show-upem
Mostrar Unidades-Por-EM
--show-extents
Mostrar extensiones
--get-name=id de nombre; ej. '13'
Obtener nombre
--get-style=etiqueta de estilo; ej. 'wght'
Obtener estilo
--get-metric=etiqueta de métrica; ej. 'hasc'
Obtener métrica
--get-baseline=etiqueta de línea base; ej. 'hang'
Obtener línea base
--get-meta=etiqueta de metadatos; ej. 'dlng'
Obtener información de metadatos
--get-table=etiqueta de tabla; ej. 'cmap'
Obtener tabla de fuente
--list-all
Listar toda la información larga
--list-names
Listar nombres
--list-style
Listar estilo
--list-metrics
Listar métricas
--list-baselines
Listar líneas base
-l, --list-tables
Listar tablas
--list-unicodes
Listar caracteres
--list-glyphs
Listar glifos
--list-scripts
Listar scripts de diseño
--list-features
Listar características de diseño
--list-variations
Listar variaciones
--list-palettes
Listar colo

hb-info(1)

NAME

hb-info, hb-draw, hb-inspect - query font information

SYNOPSIS

hb-info [options] [font file]

hb-draw [options] [font file]

hb-inspect [options] [font file]

DESCRIPTION

These utilities query font files for various information.

If no font file is specified, the utilities will attempt to read from standard input.

hb-info

Query font information.

--show-all
Show all available information. This is the default.
--list-tables
List available OpenType tables.
--list-features
List available OpenType features.
--list-scripts
List available scripts.
--list-languages
List available languages.
--list-supported-scripts
List supported scripts.
--list-supported-languages
List supported languages.
--list-supported-languages=SCRIPT
List supported languages for a given script.
--list-gsub-features
List available GSUB features.
--list-gsub-features=SCRIPT
List available GSUB features for a given script.
--list-gsub-features=SCRIPT,LANGUAGE
List available GSUB features for a given script and language.
--list-gpos-features
List available GPOS features.
--list-gpos-features=SCRIPT
List available GPOS features for a given script.
--list-gpos-features=SCRIPT,LANGUAGE
List available GPOS features for a given script and language.
--list-meta
List meta information

Application Options:

-q, --quiet
Generate machine-readable output
--version
Show version numbers

Queries font file for various information. If no query option is specified, --show-all is assumed.

EXIT CODES

0: Success.
1: Option parsing failed.
2: Failed loading font face.
4: Failed setting font functions.

ENVIRONMENT

HB_FACE_LOADER=face-loader; Overrides the default face loader.
HB_FONT_FUNCS=font-funcs; Overrides the default font-funcs.

SEE ALSO

hb-view(1), hb-shape(1), hb-subset(1), hb-info(1)
