hwlocality_glibc_sched - Interoperabilidad con la afinidad de planificador de glibc

SINOPSIS

Descripción Detallada

Esta interfaz ofrece formas de convertir entre conjuntos de CPU de hwloc y conjuntos de CPU de glibc, como aquellos manipulados por sched_getaffinity() o pthread_attr_setaffinity_np().

Nota

El parámetro topología debe coincidir con la máquina actual.

Documentación de Funciones

int hwloc_cpuset_from_glibc_sched_affinity (hwloc_topology_t topología, hwloc_cpuset_t conjunto_hwloc, const cpu_set_t * conjunto_sched, size_t tamano_conjunto_sched) [inline]

Convierte el conjunto de CPU de afinidad de planificador de glibc conjunto_sched en el conjunto de CPU de hwloc. Esta función puede usarse antes de llamar a sched_setaffinity o cualquier otra función que tome un cpu_set_t como parámetro de entrada.

tamano_conjunto_sched debe ser sizeof(cpu_set_t) a menos que conjunto_sched haya sido asignado dinámicamente con CPU_ALLOC

Devuelve

0 si tiene éxito.

-1 con errno establecido a ENOMEM si alguna reasignación interna falló.
