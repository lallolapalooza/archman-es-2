subrutina chptri (character uplo, integer n, complex, dimension( * ) ap, integer, dimension( * ) ipiv, complex, dimension( * ) work, integer info)

CHPTRI

Propósito:

!>
!> CHPTRI calcula la inversa de una matriz hermitiana indefinida compleja
!> A en almacenamiento empaquetado usando la factorización A = U*D*U**H o
!> A = L*D*L**H calculada por CHPTRF.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          Especifica si los detalles de la factorización se almacenan
!>          como una matriz triangular superior o inferior.
!>          = 'U':  Triangular superior, la forma es A = U*D*U**H;
!>          = 'L':  Triangular inferior, la forma es A = L*D*L**H.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

AP

!>          AP es un arreglo COMPLEX, dimensión (N*(N+1)/2)
!>          En la entrada, la matriz diagonal por bloques D y los multiplicadores
!>          usados para obtener el factor U o L como fue calculado por CHPTRF,
!>          almacenados como una matriz triangular empaquetada.
!>
!>          En la salida, si INFO = 0, la inversa (hermitiana) de la matriz
!>          original, almacenada como una matriz triangular empaquetada. La j-ésima columna
!>          de inv(A) se almacena en el arreglo AP como sigue:
!>          si UPLO = 'U', AP(i + (j-1)*j/2) = inv(A)(i,j) para 1<=i<=j;
!>          si UPLO = 'L',
!>             AP(i + (j-1)*(2n-j)/2) = inv(A)(i,j) para j<=i<=n.
!>

IPIV

!>          IPIV es un arreglo INTEGER, dimensión (N)
!>          Detalles de los intercambios y la estructura por bloques de D
!>          como fue determinado por CHPTRF.
!>

WORK

!>          WORK es un arreglo COMPLEX, dimensión (N)
!>

INFO

!>          INFO es INTEGER
!>          = 0: salida exitosa
!>          < 0: si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>          > 0: si INFO = i, D(i,i) = 0; la matriz es singular y su
!>               inversa no pudo ser calculada.
!>
