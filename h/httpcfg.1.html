NOMBRE

httpcfg - Gestión de Certificados de Mono para HttpListener

SINOPSIS

httpcfg [opciones] certificado

DESCRIPCIÓN

Esta herramienta se utiliza para gestionar los certificados usados por la clase de servidor embebible HttpListener cuando HttpListener está configurado como un servidor HTTPS en lugar de HTTP.

Debe seleccionar una de las acciones posibles: añadir, eliminar o listar.

Al añadir un certificado (-add), debe proporcionar la siguiente información: un certificado (con el flag -cert), un archivo de clave privada (con el argumento -pvk, el nombre del archivo suele ser "key") y un número de puerto (con el flag -port).

Al eliminar un certificado (-del o -delete) necesita proporcionar el número de puerto.

PARÁMETROS

-add
Añade una nueva combinación de certificado/clave privada para ser utilizada en un puerto dado por la API HttpListener.
-del, -delete
Elimina los certificados asociados para el puerto especificado (debe especificarse por separado).
-list
Lista todos los certificados conocidos.
-port PUERTO
Especifica el puerto al que añadir certificados o del que eliminar certificados.
-pvk ARCHIVO
Especifica el archivo de clave privada.
-cert CERT
Especifica el archivo de certificado a usar.

EJEMPLOS

httpcfg -add -port 8081 -pvk myfile.pvk -cert MyCert

Para más detalles sobre cómo crear el archivo de certificado y la clave privada, consulte la siguiente página web:

http://www.mono-project.com/docs/web/using-clientcertificates-with-xsp/

ARCHIVOS

Los certificados se almacenan en el directorio ~/.mono/httplistener
