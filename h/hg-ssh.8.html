NOMBRE

hg-ssh - shell de inicio de sesión restringido de ssh para Mercurial

SINOPSIS

hg-ssh repositorios...

DESCRIPCIÓN

hg-ssh es un envoltorio para el acceso ssh a un conjunto limitado de repositorios de mercurial.

Para ser utilizado en ~/.ssh/authorized_keys con la opción "command", ver sshd(8): command="hg-ssh ruta/a/repo1 /ruta/a/repo2 ~/repo3 ~usuario/repo4" ssh-dss ... (probablemente junto con estas otras opciones útiles: no-port-forwarding,no-X11-forwarding,no-agent-forwarding)

Esto permite hacer pull/push sobre ssh desde/hacia los repositorios dados como argumentos.

Si todos sus repositorios son subdirectorios de un directorio común, puede permitir rutas más cortas con: command="cd ruta/a/mis/repositorios && hg-ssh repo1 subdir/repo2"

Puede usar coincidencia de patrones de su shell normal, por ejemplo: command="cd repos && hg-ssh user/thomas/* projects/{mercurial,foo}"

También puede añadir una bandera --read-only para permitir acceso de solo lectura a una clave, por ejemplo: command="hg-ssh --read-only repos/*"

ERRORES

Probablemente muchos, por favor publíquelos en la lista de correo (ver Recursos abajo) cuando los encuentre.
