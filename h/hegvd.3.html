CHEGVD

Propósito:

!>
!> CHEGVD calcula todos los valores propios, y opcionalmente, los vectores propios
!> de un problema de eigenhermitiano general complejo y definido, de la forma
!> A*x=(lambda)*B*x,  A*Bx=(lambda)*x,  o B*A*x=(lambda)*x. Aquí A y
!> B se asumen hermitianos y B también es positiva definida.
!> Si se desean vectores propios, utiliza un algoritmo de dividir y conquistar.
!>
!>

Parámetros

ITYPE 
!>          ITYPE es INTEGER
!>          Especifica el tipo de problema a resolver:
!>          = 1:  A*x = (lambda)*B*x
!>          = 2:  A*B*x = (lambda)*x
!>          = 3:  B*A*x = (lambda)*x
!>

JOBZ

!>          JOBZ es CHARACTER*1
!>          = 'N':  Calcula solo los valores propios;
!>          = 'V':  Calcula los valores propios y los vectores propios.
!>

UPLO

!>          UPLO es CHARACTER*1
!>          = 'U':  Los triángulos superiores de A y B están almacenados;
!>          = 'L':  Los triángulos inferiores de A y B están almacenados.
!>

N

!>          N es INTEGER
!>          El orden de las matrices A y B.  N >= 0.
!>

A

!>          A es un array COMPLEX, de dimensión (LDA, N)
!>          En la entrada, la matriz hermitiana A.  Si UPLO = 'U', la
!>          parte triangular superior N por N de A contiene la
!>          parte triangular superior de la matriz A.  Si UPLO = 'L',
!>          la parte triangular inferior N por N de A contiene
!>          la parte triangular inferior de la matriz A.
!>
!>          En la salida, si JOBZ = 'V', entonces si INFO = 0, A contiene la
!>          matriz Z de vectores propios.  Los vectores propios están normalizados
!>          de la siguiente manera:
!>          si ITYPE = 1 o 2, Z**H*B*Z = I;
!>          si ITYPE = 3, Z**H*inv(B)*Z = I.
!>          Si JOBZ = 'N', entonces en la salida, el triángulo superior (si UPLO='U')
!>          o el triángulo inferior (si UPLO='L') de A, incluyendo la
!>          diagonal, se destruye.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

B

!>          B es un array COMPLEX, de dimensión (LDB, N)
!>          En la entrada, la matriz hermitiana B.  Si UPLO = 'U', la
!>          parte triangular superior N por N de B contiene la
!>          parte triangular superior de la matriz B.  Si UPLO = 'L',
!>          la parte triangular inferior N por N de B contiene
!>          la parte triangular inferior de la matriz B.
!>
!>          En la salida, si INFO <= N, la parte de B que contiene la matriz está
!>          sobrescrita por el factor triangular U o L de la factorización de Cholesky
!>          B = U**H*U o B = L*L**H.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B.  LDB >= max(1,N).
!>

W

!>          W es un array REAL, de dimensión (N)
!>          Si INFO = 0, los valores propios en orden ascendente.
!>

WORK

!>          WORK es un array COMPLEX, de dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La longitud del array WORK.
!>          Si N <= 1,                LWORK >= 1.
!>          Si JOBZ  = 'N' y N > 1, LWORK >= N + 1.
!>          Si JOBZ  = 'V' y N > 1, LWORK >= 2*N + N**2.
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula los tamaños óptimos de los arrays WORK, RWORK y
!>          IWORK, devuelve estos valores como las primeras entradas de
!>          los arrays WORK, RWORK e IWORK, y XERBLA no emite ningún mensaje de error
!>          relacionado con LWORK o LRWORK o LIWORK.
!>

RWORK

!>          RWORK es un array REAL, de dimensión (MAX(1,LRWORK))
!>          En la salida, si INFO = 0, RWORK(1) devuelve el LRWORK óptimo.
!>

LRWORK

!>          LRWORK es INTEGER
!>          La dimensión del array RWORK.
!>          Si N <= 1,                LRWORK >= 1.
!>          Si JOBZ  = 'N' y N > 1, LRWORK >= N.
!>          Si JOBZ  = 'V' y N > 1, LRWORK >= 1 + 5*N + 2*N**2.
!>
!>          Si LRWORK = -1, entonces se asume una consulta de espacio de trabajo; la
!>          rutina solo calcula los tamaños óptimos de los arrays WORK, RWORK
!>          e IWORK, devuelve estos valores como las primeras entradas de
!>          los arrays WORK, RWORK e IWORK, y XERBLA no emite ningún mensaje de error
!>          relacionado con LWORK o LRWORK o LIWORK.
!>

IWORK

!>          IWORK es un array INTEGER, de dimensión (MAX(1,LIWORK))
!>          En la salida, si INFO = 0, IWORK(1) devuelve el LIWORK óptimo.
!>

LIWORK

!>          LIWORK es INTEGER
!>          La dimensión del array IWORK.
!>          Si N <= 1,                LIWORK >= 1.
!>          Si JOBZ  = 'N' y N > 1, LIWORK >= 1.
!>          Si JOBZ  = 'V' y N > 1, LIWORK >= 3 + 5*N.
!>
!>          Si LIWORK = -1, entonces se asume una consulta de espacio de trabajo; la
!>          rutina solo calcula los tamaños óptimos de los arrays WORK, RWORK
!>          e IWORK, devuelve estos valores como las primeras entradas de
!>          los arrays WORK, RWORK e IWORK, y XERBLA no emite ningún mensaje de error
!>          relacionado con LWORK o LRWORK o LIWORK.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>          > 0:  CPOTRF o CHEEVD devolvieron un código de error:
!>             <= N:  si INFO = i y JOBZ = 'N', entonces el algoritmo
!>                    falló en converger; i elementos fuera de la diagonal de una
!>                    forma tridiagonal intermedia no convergieron a
!>                    cero;
!>                    si INFO = i y JOBZ = 'V', entonces el algoritmo
!>                    falló en calcular un valor propio mientras trabajaba en la
!>                    submatriz que yacía en las filas y columnas INFO/(N+1)
!>                    hasta mod(INFO,N+1);
!>             > N:   si INFO = N + i, para 1 <= i <= N, entonces el menor principal
!>                    principal de orden i de B no es positivo.
!>                    La factorización de B no pudo completarse y
!>                    no se calcularon valores propios ni vectores propios.
!>

Detailed
  Description


ZHEGVD computes the eigenvalues and eigenvectors of a complex
    Hermitian positive definite generalized eigenvalue problem.


Given two complex Hermitian positive definite matrices A and B,
    ZHEGVD solves the generalized eigenvalue problem:


A*z = lambda*B*z


where lambda is an eigenvalue and z is the corresponding
    eigenvector.


ZHEGVD uses the divide and conquer algorithm to compute the
    eigenvalues and eigenvectors.


Arguments




JOBZ (input) CHARACTER*1
         ='E': Compute eigenvalues only.
         ='V': Compute eigenvalues and eigenvectors.
         If JOBZ ='V', then the eigenvectors C*x are returned in the array
         array VL or VR.






JOBVL (input) CHARACTER*1
         ='N': Do not compute the left eigenvectors of the matrix pair (A,B).
         ='L': Compute the left eigenvectors of the matrix pair (A,B).
         The eigenvectors are stored in the array VL. Only relevant if
         JOBZ ='V'.






JOBVR (input) CHARACTER*1
         ='N': Do not compute the right eigenvectors of the matrix pair (A,B).
         ='R': Compute the right eigenvectors of the matrix pair (A,B).
         The eigenvectors are stored in the array VR. Only relevant if
         JOBZ ='V'.






N (input) INTEGER
         The order of the matrices A and B. N >= 0.






A (input/output) COMPLEX*16 array, dimension (LDA, N)
         On entry, the upper triangular part of complex Hermitian matrix A.
         On exit, if JOBZ ='E', A is unchanged. If JOBZ ='V', the contents
         of A are destroyed.






LDA (input) INTEGER
         The leading dimension of A.






B (input/output) COMPLEX*16 array, dimension (LDB, N)
         On entry, the upper triangular part of complex Hermitian matrix B,
         which must be positive definite.
         On exit, B is destroyed.






LDB (input) INTEGER
         The leading dimension of B.






ALPHA (output) DOUBLE PRECISION array, dimension (N)
         If the j-th eigenvalue is computed, then ALPHA(j) contains the
         numerator of the j-th eigenvalue, lambda_j = ALPHA(j) / BETA(j).






BETA (output) DOUBLE PRECISION array, dimension (N)
         If the j-th eigenvalue is computed, then BETA(j) contains the
         denominator of the j-th eigenvalue, lambda_j = ALPHA(j) / BETA(j).






VL (output) COMPLEX*16 array, dimension (LDVL, N)
         If JOBVL ='L' and JOBZ ='V', then VL contains the left eigenvectors
         of the matrix pair (A,B). The j-th column VL(j) is the eigenvector
         corresponding to the j-th eigenvalue. Each eigenvector is normalized
         to have a Euclidean norm of 1.






LDVL (input) INTEGER
         The leading dimension of the array VL.






VR (output) COMPLEX*16 array, dimension (LDVR, N)
         If JOBVR ='R' and JOBZ ='V', then VR contains the right eigenvectors
         of the matrix pair (A,B). The j-th column VR(j) is the eigenvector
         corresponding to the j-th eigenvalue. Each eigenvector is normalized
         to have a Euclidean norm of 1.






LDVR (input) INTEGER
         The leading dimension of the array VR.






WORK (workspace) COMPLEX*16 array, dimension (LWORK)
         On exit, WORK(1) contains the minimum value of LWORK.






LWORK (input) INTEGER
         The dimension of the array WORK. LWORK >= 1.
         For optimal efficiency, LWORK is in the range LWORK >= max(2*N, N*log(N))
         and LWORK must be large enough for the workspace used by the QR
         algorithm and the divide and conquer algorithm.






RWORK (workspace) DOUBLE PRECISION array, dimension (LRWORK)
         On exit, RWORK(1) contains the minimum value of LRWORK.






LRWORK (input) INTEGER
         The dimension of the array RWORK. LRWORK >= 1.






IWORK (workspace) INTEGER array, dimension (LIWORK)
         On exit, IWORK(1) contains the minimum value of LIWORK.






LIWORK (input) INTEGER
         The dimension of the array IWORK. LIWORK >= 1.






INFO (output) INTEGER
         = 0:  Successful exit.






         > 0:  If INFO = i, and 1 <= i <= N, then the algorithm failed to
         converge; i off-diagonal elements of an intermediate tridiagonal
         matrix did not converge to zero.
         If INFO = N + i, then the algorithm failed to compute an eigenvalue
         while working on the submatrix lying in rows and columns INFO/(N+1)
         through mod(INFO,N+1);
         > N:   if INFO = N + i, for 1 <= i <= N, then the leading
         principal minor of order i of B is not positive.
         The factorization of B could not be completed and
         no eigenvalues or eigenvectors were computed.
