HGIGNORE(5) Manual de Mercurial HGIGNORE(5)

NOMBRE

hgignore - sintaxis de los archivos de ignorados de Mercurial

RESUMEN

El sistema Mercurial utiliza un archivo llamado .hgignore en el directorio raíz de un repositorio para controlar su comportamiento al buscar archivos que no está rastreando actualmente.

DESCRIPCIÓN

El directorio de trabajo de un repositorio Mercurial a menudo contendrá archivos que no deben ser rastreados por Mercurial. Estos incluyen archivos de copia de seguridad creados por editores y productos de compilación creados por compiladores. Estos archivos pueden ser ignorados listándolos en un archivo .hgignore en la raíz del directorio de trabajo. El archivo .hgignore debe crearse manualmente. Normalmente se pone bajo control de versiones, de modo que la configuración se propague a otros repositorios con push y pull.

Un archivo no rastreado se ignora si su ruta relativa al directorio raíz del repositorio, o cualquier prefijo de esa ruta, coincide con algún patrón en .hgignore.

Por ejemplo, supongamos que tenemos un archivo no rastreado, archivo.c, en a/b/archivo.c dentro de nuestro repositorio. Mercurial ignorará archivo.c si algún patrón en .hgignore coincide con a/b/archivo.c, a/b o a.

Además, un archivo de configuración de Mercurial puede referenciar un conjunto de archivos de ignorados por usuario o globales. Consulte la clave de configuración ignore en la sección [ui] de hg help config para obtener detalles sobre cómo configurar estos archivos.

Para controlar el manejo de archivos que Mercurial administra, muchos comandos admiten las opciones -I y -X; consulte hg help <comando> y hg help patterns para obtener detalles.

Los archivos que ya están rastreados no se ven afectados por .hgignore, incluso si aparecen en .hgignore. Un archivo no rastreado X puede añadirse explícitamente con hg add X, incluso si X sería excluido por un patrón en .hgignore.

SINTAXIS

Un archivo de ignorados es un archivo de texto plano que consiste en una lista de patrones, con un patrón por línea. Las líneas vacías se omiten. El carácter # se trata como un carácter de comentario, y el carácter \ se trata como un carácter de escape.

Mercurial admite varias sintaxis de patrones. La sintaxis predeterminada utilizada son expresiones regulares al estilo Python/Perl.

Para cambiar la sintaxis utilizada, use una línea de la siguiente forma:

syntax: NOMBRE

donde NOMBRE es uno de los siguientes:

regexp

Expresión regular, sintaxis Python/Perl.

glob

Glob al estilo de la shell.

rootglob

Una variante de glob que está enraizada (ver abajo).

La sintaxis elegida permanece en vigor al analizar todos los patrones siguientes, hasta que se selecciona otra sintaxis.

Ni los patrones glob ni los de expresión regular están enraizados. Un patrón de sintaxis glob de la forma *.c coincidirá con un archivo que termine en .c en cualquier directorio, y un patrón de expresión regular de la forma \.c$ hará lo mismo. Para enraizar un patrón de expresión regular, empiece con ^. Para obtener el mismo efecto con la sintaxis glob, tiene que usar rootglob.

Los subdirectorios pueden tener su propia configuración de .hgignore añadiendo subinclude:ruta/a/subdir/.hgignore al .hgignore raíz. Consulte hg help patterns para obtener detalles sobre subinclude: y include:.

Nota
Los patrones especificados en algo que no sea .hgignore siempre están enraizados. Consulte hg help patterns para obtener detalles.

EJEMPLO

Aquí hay un archivo de ignorados de ejemplo.

# usar sintaxis glob.
syntax: glob
*.elc
*.pyc
*~
# cambiar a sintaxis de expresión regular.
syntax: regexp
^\.pc/

DEPURACIÓN

Utilice el comando debugignore para ver si un archivo es ignorado y por qué, o para ver el patrón de ignorados combinado. Consulte hg help debugignore para obtener detalles.
