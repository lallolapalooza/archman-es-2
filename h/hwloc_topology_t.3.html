Documentación de tipos definidos

typedef struct hwloc_topology* hwloc_topology_t

Contexto de topología. Se inicializa con hwloc_topology_init() y se construye con hwloc_topology_load().

Documentación de funciones

int hwloc_topology_abi_check (hwloc_topology_t topology)

Verifica que la topología sea compatible con la biblioteca hwloc actual. Esto es útil al usar la misma estructura de topología (en memoria) en diferentes bibliotecas que pueden usar diferentes instalaciones de hwloc (por ejemplo, si una biblioteca incrusta una versión específica de hwloc, mientras que otra biblioteca utiliza una instalación global predeterminada de hwloc).

Si todas las bibliotecas/programas utilizan la misma instalación de hwloc, esta función siempre devuelve éxito.

Retorna

0 en caso de éxito.

-1 con errno establecido a EINVAL si es incompatible.

Nota

Si se comparte entre procesos con hwloc_shmem_topology_write(), la comprobación relevante ya se realiza dentro de hwloc_shmem_topology_adopt().

void hwloc_topology_check (hwloc_topology_t topology)

Ejecuta comprobaciones internas en una estructura de topología. El programa aborta si se detecta una inconsistencia en la topología dada.

Parámetros

topology es la topología a verificar

Nota

Esta rutina solo es útil para desarrolladores.

La topología de entrada debe haber sido previamente cargada con hwloc_topology_load().

void hwloc_topology_destroy (hwloc_topology_t topology)

Termina y libera un contexto de topología.

Parámetros

topology es la topología a liberar

int hwloc_topology_dup (hwloc_topology_t * newtopology, hwloc_topology_t oldtopology)

Duplica una topología. Toda la estructura de topología, así como sus objetos, se duplican en una nueva.

Esto es útil para mantener una copia de seguridad mientras se modifica una topología.

Retorna

0 en caso de éxito, -1 en caso de error.

Nota

Los userdata de los objetos no se duplican ya que hwloc no sabe a qué apuntan. Los objetos de las topologías antigua y nueva apuntarán al mismo userdata.

int hwloc_topology_init (hwloc_topology_t * topologyp)

Asigna un contexto de topología.

Parámetros

topologyp se asigna a un puntero al nuevo contexto asignado.

Retorna

0 en caso de éxito, -1 en caso de error.

int hwloc_topology_load (hwloc_topology_t topology)

Construye la topología real. Construye la topología real una vez inicializada con hwloc_topology_init() y ajustada con las rutinas de Configuración y Consulta de Detección de Topología y Cambio de la Fuente de Descubrimiento de Topología. No se pueden llamar otras rutinas anteriormente usando este contexto de topología.

Parámetros

topology es la topología a cargar con objetos.

Retorna

0 en caso de éxito, -1 en caso de error.

Nota

En caso de error, la topología se reinicializa. Debe ser destruida con hwloc_topology_destroy() o configurada y cargada de nuevo.

Esta función solo puede llamarse una vez por topología.

La vinculación del hilo o proceso actual puede cambiar temporalmente durante esta llamada, pero se restaurará antes de que devuelva.
