humanize_number(3bsd)

Paquete: libbsd

Licencias: custom

humanize_number(3bsd) 3bsd humanize_number(3bsd)

NOMBRE

dehumanize_number, humanize_number — formatea un número en un formato legible por humanos y viceversa

BIBLIOTECA

biblioteca “libbsd”

SINOPSIS

#include <stdlib.h> (Ver libbsd(7) para el uso de include.)
int
dehumanize_number(const char *str, int64_t *result);

int
humanize_number(char *buf, size_t len, int64_t number, const char *suffix, int scale, int flags);

DESCRIPCIÓN

La función humanize_number() formatea la cantidad de 64 bits con signo dada en number en el buffer. Se añade un espacio y luego el suffix al final. El buffer debe tener al menos len bytes de longitud.

Si el número formateado (incluyendo el suffix) fuera demasiado largo para caber en el buffer, entonces divide number por 1024 hasta que quepa. En este caso, añade el prefijo apropiado del diseño SI al suffix.

Los prefijos son:

Prefijo Descripción Multiplicador
k kilo 1024
M mega 1048576
G giga 1073741824
T tera 1099511627776
P peta 1125899906842624
E exa 1152921504606846976

len debe ser al menos 4 más la longitud del suffix, para asegurar que se genere un resultado útil en el buffer. Para usar un prefijo específico, especifíquelo como scale (Multiplicador = 1024 ^ scale). Esto no se puede combinar con ninguna de las banderas de scale de abajo.

Las siguientes banderas pueden pasarse en scale:

HN_AUTOSCALE
Formatea el buffer usando el menor multiplicador posible.
HN_GETSCALE
Devuelve el índice del prefijo (el número de veces que number debe dividirse para caber) en lugar de formatearlo en el buffer.

Las siguientes banderas pueden pasarse en flags:

HN_DECIMAL
Si el resultado final es menor que 10, muéstralo usando un dígito.
HN_NOSPACE
No pongas un espacio entre number y el prefijo.
HN_B
Usa 'B' (bytes) como prefijo si el resultado original no tiene prefijo.
HN_DIVISOR_1000
Divide number por 1000 en lugar de 1024.

La función dehumanize_number() analiza la cadena que representa un valor integral dado en str y almacena el valor numérico en el entero apuntado por result. La cadena proporcionada puede contener uno de los sufijos, que se interpretarán y se usarán para escalar su valor numérico asociado.

VALORES DE RETORNO

humanize_number() devuelve el número de caracteres almacenados en buffer (excluyendo el NUL terminador) en caso de éxito, o -1 en caso de fallo. Si se especifica HN_GETSCALE, se devolverá el índice del prefijo en su lugar.

dehumanize_number() devuelve 0 si la cadena se analizó correctamente. Se devuelve -1 para indicar un fallo y se almacena un código de error en errno.

ERRORES

dehumanize_number() fallará y no se almacenará ningún número en result si:

[EINVAL]
La cadena en str estaba vacía o llevaba un sufijo desconocido.
[ERANGE]
La cadena en str representaba un número que no cabía en result.

VER TAMBIÉN

humanize_number(9)

HISTORIA
