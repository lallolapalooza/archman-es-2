NOMBRE

hub-remote - Añadir un remoto de git para un repositorio de GitHub.

SINOPSIS

hub remote add [-p] [OPCIONES] USUARIO[/REPOSITORIO]
hub remote set-url [-p] [OPCIONES] NOMBRE USUARIO[/REPOSITORIO]

OPCIONES

-p

(Obsoleto) Usa el protocolo ssh: en lugar de git: para la URL del remoto. El protocolo ssh: escribible se usa automáticamente para los repositorios propios, remotos de GitHub Enterprise y repositorios privados o que se puedan empujar.

USUARIO[/REPOSITORIO]

Si USUARIO es "origin", ese valor se sustituirá por tu nombre de usuario de GitHub. REPOSITORIO por defecto es el nombre del directorio de trabajo actual.

EJEMPLOS

$ hub remote add jingweno
> git remote add jingweno git://github.com/jingweno/REPO.git
$ hub remote add origin
> git remote add origin git@github.com:USER/REPO.git
