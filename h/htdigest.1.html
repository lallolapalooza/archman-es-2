NOMBRE

htdigest - gestiona archivos de usuario para la autenticación digest

SINOPSIS

htdigest [ -c ] archivo_contraseñas dominio nombre_usuario

RESUMEN

htdigest se utiliza para crear y actualizar los archivos planos que almacenan nombres de usuario, dominio y contraseña para la autenticación digest de usuarios HTTP. Los recursos disponibles desde el servidor HTTP Apache pueden ser restringidos solo a los usuarios listados en los archivos creados por htdigest.

Esta página del manual solo lista los argumentos de la línea de comandos. Para obtener detalles sobre las directivas necesarias para configurar la autenticación digest en httpd, consulte el manual de Apache, que forma parte de la distribución de Apache o puede encontrarse en http://httpd.apache.org/.

OPCIONES

-c
Crea el archivo_contraseñas. Si archivo_contraseñas ya existe, se elimina primero.
archivo_contraseñas
Nombre del archivo que contendrá el nombre de usuario, dominio y contraseña. Si se proporciona -c, este archivo se creará si no existe, o se eliminará y recreará si ya existe.
dominio
El nombre del dominio al que pertenece el nombre de usuario. Consulte http://tools.ietf.org/html/rfc2617#section-3.2.1 para más detalles.
nombre_usuario
El nombre de usuario que se creará o actualizará en archivo_contraseñas. Si nombre_usuario no existe en este archivo, se añade una entrada. Si ya existe, la contraseña se cambia.

CONSIDERACIONES DE SEGURIDAD

Este programa no es seguro como ejecutable setuid. No lo convierta en setuid.
