HXEXTRACT(1) Utilidades HTML-XML HXEXTRACT(1)

NOMBRE

hxextract - extrae elementos seleccionados de un archivo HTML o XML

SINOPSIS

hxextract [ -h | -? ] [ -x ] [ -s texto ] [ -e texto ] [ -b base ] elemento-o-clase [ -c archivo-config | archivo-o-URL ]

DESCRIPCIÓN

hxextract imprime todos los elementos con un cierto nombre y/o clase.

La entrada debe estar bien formada, ya que no se aplican heurísticas de HTML.

OPCIONES

Se admiten las siguientes opciones:

-x
Utilizar convenciones de formato XML.
-s texto
Insertar texto al principio de la salida.
-e texto
Insertar texto al final de la salida.
-b base
Base de la URL
-c archivo-config
Leer líneas @chapter de archivo-config (las líneas deben ser del formato "@chapter nombre-archivo") y extraer elementos de cada uno de esos archivos.
-h, -?
Imprimir uso del comando.

OPERANDOS

Se admiten los siguientes operandos:

elemento-o-clase
El nombre de un elemento a extraer (por ejemplo, "H2"), o el nombre de una clase precedida por "." (por ejemplo, ".ejemplo") o una combinación de ambos (por ejemplo, "H2.ejemplo").
archivo-o-URL
Un nombre de archivo o una URL. Para leer de la entrada estándar, use "-".

ENTORNO

Para usar un proxy para recuperar archivos remotos, establezca las variables de entorno http_proxy y ftp_proxy. Por ejemplo, http_proxy="http://localhost:8080/"

ERRORES

Los archivos remotos (especificados con una URL) actualmente solo son compatibles con HTTP. Los archivos protegidos por contraseña o los archivos que dependen de "cookies" HTTP no se manejan. (Puede usar herramientas como curl(1) o wget(1) para recuperar dichos archivos.)
