NOMBRE

hwloc-diff - Calcular diferencias entre dos topologías XML

SINOPSIS

hwloc-diff [opciones] <entrada1.xml> <entrada2.xml>

hwloc-diff [opciones] <entrada1.xml> <entrada2.xml> <salida.xml>

OPCIONES

--refname <nombre>
Usar <nombre> como identificador para la topología de referencia en la salida XML de la diferencia. Está pensado para indicar qué topología debe usarse al aplicar la diferencia resultante. hwloc-patch puede usar ese nombre para cargar automáticamente el XML de topología de referencia relevante. Por defecto, se usa <entrada1.xml> sin su ruta completa.
--version
Informar de la versión y salir.
-h --help
Mostrar mensaje de ayuda y salir.

DESCRIPCIÓN

hwloc-diff calcula la diferencia entre dos topologías XML y almacena el resultado en <salida.xml>, si se proporciona, o lo imprime en la salida estándar en caso contrario.

La diferencia resultante puede ser aplicada posteriormente a otra topología con hwloc-patch.

hwloc-compress-dir puede ser utilizado para calcular las diferencias entre todos los archivos XML en un directorio.

NOTA: Si se exportaron datos definidos por el usuario específicos de alguna aplicación a los XML de entrada, estos serán ignorados y descartados de la salida, ya que hwloc no tiene forma de entenderlos y compararlos.

NOTA: Se recomienda encarecidamente leer la página de descripción general hwloc(7) antes de leer esta página del manual. La mayoría de los conceptos descritos en hwloc(7) se aplican directamente a la utilidad hwloc-diff.

EJEMPLOS

La operación de hwloc-diff se describe mejor a través de varios ejemplos.

Calcular la diferencia entre dos topologías XML y enviarla a la salida estándar:


$ hwloc-diff fourmi023.xml fourmi024.xml
Se encontraron 11 diferencias, exportando a la salida estándar
<?xml version="1.0" encoding="UTF-8"?>
...

Enviar la diferencia al archivo diff.xml en su lugar:


$ hwloc-diff fourmi023.xml fourmi024.xml diff.xml
Se encontraron 11 diferencias, exportando a diff.xml

Cuando la diferencia es demasiado compleja para ser representada:


$ hwloc-diff fourmi023.xml avakas-frontend1.xml
Se encontró 1 diferencia, incluyendo 1 demasiado compleja.
No se pueden exportar las diferencias a la salida estándar

Calcular directamente la diferencia entre dos topologías y aplicarla a otra:


$ hwloc-diff fourmi023.xml fourmi024.xml | hwloc-patch fourmi025.xml -

VALOR DE RETORNO

Tras una ejecución exitosa, hwloc-diff genera la diferencia. El valor de retorno es 0.

Si la diferencia es demasiado compleja para ser representada, se retorna un error y no se genera la salida.

hwloc-diff también retorna un valor distinto de cero si ocurre algún tipo de error, como (pero no limitado a) fallos al analizar la línea de comandos.
