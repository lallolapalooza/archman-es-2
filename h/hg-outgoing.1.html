NOMBRE

hg outgoing - mostrar cambios no encontrados en el destino

SINOPSIS

hg outgoing [-M] [-p] [-n] [-f] [-r REV]... [DEST]...

DESCRIPCIÓN

Muestra los cambios no encontrados en el repositorio de destino especificado o en la ubicación de envío predeterminada. Estos son los cambios que se enviarían si se solicitara un envío.

Consulte pull para conocer los detalles de los formatos de destino válidos.

Con -B/--bookmarks, se muestra el resultado de la comparación de marcadores entre los repositorios local y remoto. Con -v/--verbose, también se muestra el estado de cada marcador como se indica a continuación:

BM1               01234567890a added
BM2                            deleted
BM3               234567890abc advanced
BM4               34567890abcd diverged
BM5               4567890abcde changed

La acción que se tomará al enviar depende del estado de cada marcador:

añadido

el envío con -B lo creará

eliminado

el envío con -B lo eliminará

avanzado

el envío lo actualizará

divergente

el envío con -B lo actualizará

cambiado

el envío con -B lo actualizará

Desde el punto de vista del comportamiento de envío, los marcadores que existen solo en el repositorio remoto se tratan como eliminados, incluso si de hecho se añaden de forma remota.

Devuelve 0 si hay cambios salientes, 1 en caso contrario.

OPCIONES

-f, --force
ejecutar incluso cuando el destino no está relacionado
-r, --rev <REV[+]>
un cambio que se pretende incluir en el destino
-n, --newest-first
mostrar el registro más reciente primero
-B, --bookmarks
comparar marcadores
-b, --branch <BRANCH[+]>
una rama específica que le gustaría enviar
-p, --patch
mostrar parche
-g, --git
usar formato de diferencia extendido de git
-l, --limit <NUM>
limitar el número de cambios mostrados
-M, --no-merges
no mostrar fusiones
--stat
mostrar un resumen de los cambios estilo diffstat
-G, --graph
mostrar el DAG de revisión
--style <STYLE>
mostrar usando el archivo de mapa de plantillas (OBSOLETO)
-T, --template <TEMPLATE>
mostrar con plantilla
-e, --ssh <CMD>
especificar comando ssh a usar
--remotecmd <CMD>
especificar comando hg a ejecutar en el lado remoto
--insecure
no verificar el certificado del servidor (ignorando la configuración web.cacerts)
-S, --subrepos
recursar en subrepositorios

[+] la opción marcada se puede especificar varias veces
