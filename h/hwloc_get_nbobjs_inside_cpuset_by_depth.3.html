hwloc_obj_t hwloc_get_first_largest_obj_inside_cpuset (hwloc_topology_t topology, hwloc_const_cpuset_t set) [inline]

Obtener el primer objeto más grande incluido en el conjunto de CPU dado set.

Devuelve

el primer objeto que está incluido en set y cuyo padre no lo está.

NULL si no existe tal objeto.

Esto es conveniente para iterar sobre todos los objetos más grandes dentro de un conjunto de CPU haciendo un bucle que obtiene el primer objeto más grande y limpia su conjunto de CPU del conjunto de CPU restante.

int hwloc_get_largest_objs_inside_cpuset (hwloc_topology_t topology, hwloc_const_cpuset_t set, hwloc_obj_t *restrict objs, int max)

Obtener el conjunto de objetos más grandes que cubren exactamente un conjunto de CPU dado set.

Devuelve

el número de objetos devueltos en objs.

-1 si ningún conjunto de objetos puede cubrir ese conjunto de CPU.

unsigned hwloc_get_nbobjs_inside_cpuset_by_depth (hwloc_topology_t topology, hwloc_const_cpuset_t set, int depth) [inline]

Devolver el número de objetos en la profundidad depth incluidos en el conjunto de CPU set.

Devuelve

el número de objetos.

0 si la profundidad no es válida.

Nota

Los objetos con conjuntos de CPU vacíos se ignoran (de lo contrario se considerarían incluidos en cualquier conjunto dado).

Esta función no puede funcionar si los objetos en la profundidad dada no tienen conjuntos de CPU (objetos de E/S o Misc).

int hwloc_get_nbobjs_inside_cpuset_by_type (hwloc_topology_t topology, hwloc_const_cpuset_t set, hwloc_obj_type_t type) [inline]

Devolver el número de objetos de tipo type incluidos en el conjunto de CPU set.

Devuelve

el número de objetos.

0 si no hay objetos de ese tipo en la topología.

-1 si hay múltiples niveles de objetos de ese tipo, el llamador debería recurrir a hwloc_get_nbobjs_inside_cpuset_by_depth().

Nota

Los objetos con conjuntos de CPU vacíos se ignoran (de lo contrario se considerarían incluidos en cualquier conjunto dado).

Esta función no puede funcionar si los objetos del tipo dado no tienen conjuntos de CPU (objetos de E/S).

int hwloc_get_obj_index_inside_cpuset (hwloc_topology_t topology, hwloc_const_cpuset_t set, hwloc_obj_t obj) [inline]

Devolver el índice lógico entre los objetos incluidos en el conjunto de CPU set. Consultar todos los objetos en el mismo nivel que obj y dentro del conjunto de CPU set en el orden lógico, y devolver el índice de obj dentro de ellos. Si set cubre toda la topología, este es el índice lógico de obj. De lo contrario, es similar a un índice lógico dentro de la parte de la topología definida por el conjunto de CPU set.

Devuelve

<

el índice lógico entre los objetos incluidos en el conjunto si los hay.

-1 si el objeto no está incluido en el conjunto.

Nota

Los objetos con conjuntos de CPU vacíos se ignoran (de lo contrario, se considerarían incluidos en cualquier conjunto dado).

Esta función no puede funcionar si obj no tiene conjuntos de CPU (objetos de E/S).
