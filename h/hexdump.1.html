HEXDUMP(1) Comandos de usuario HEXDUMP(1)

NOMBRE

hexdump - muestra el contenido de archivos en hexadecimal, decimal, octal o ascii

SINOPSIS

hexdump opciones archivo ...

hd opciones archivo ...

DESCRIPCIÓN

La utilidad hexdump es un filtro que muestra los archivos especificados, o la entrada estándar si no se especifican archivos, en un formato especificado por el usuario.

OPCIONES

A continuación, los argumentos longitud y desplazamiento pueden ir seguidos de los sufijos multiplicadores KiB (=1024), MiB (=1024*1024), y así sucesivamente para GiB, TiB, PiB, EiB, ZiB y YiB (la parte "iB" es opcional, por ejemplo, "K" tiene el mismo significado que "KiB"), o los sufijos KB (=1000), MB (=1000*1000), y así sucesivamente para GB, TB, PB, EB, ZB y YB.

-b, --one-byte-octal

Visualización octal de un byte. Muestra el desplazamiento de entrada en hexadecimal, seguido de dieciséis bytes de datos de entrada, separados por espacios, con tres columnas y rellenos de cero, en octal, por línea.

-X, --one-byte-hex

Visualización hexadecimal de un byte. Muestra el desplazamiento de entrada en hexadecimal, seguido de dieciséis bytes de datos de entrada, separados por espacios, con dos columnas y rellenos de cero, en hexadecimal, por línea.

-c, --one-byte-char

Visualización de caracteres de un byte. Muestra el desplazamiento de entrada en hexadecimal, seguido de dieciséis caracteres de datos de entrada, separados por espacios, con tres columnas y rellenos de espacio, por línea.

-C, --canonical

Visualización canónica hex+ASCII. Muestra el desplazamiento de entrada en hexadecimal, seguido de dieciséis bytes hexadecimales de dos columnas separados por espacios, seguidos de los mismos dieciséis bytes en formato %_p encerrados entre caracteres |. Invocar el programa como hd implica esta opción.

-d, --two-bytes-decimal

Visualización decimal de dos bytes. Muestra el desplazamiento de entrada en hexadecimal, seguido de ocho unidades de dos bytes de datos de entrada, separadas por espacios, con cinco columnas y rellenos de cero, en decimal sin signo, por línea.

-e, --format cadena_formato

Especifica una cadena de formato que se utilizará para mostrar los datos.

-f, --format-file archivo

Especifica un archivo que contiene una o más cadenas de formato separadas por saltos de línea. Se ignoran las líneas vacías y las líneas cuyo primer carácter que no sea espacio en blanco sea una marca de almohadilla (#).

-L, --color[=cuándo]

Acepta unidades de color para la salida. El argumento opcional cuándo puede ser auto, never (nunca) o always (siempre). Si se omite el argumento cuándo, por defecto es auto. Los colores se pueden deshabilitar; para ver el valor predeterminado incorporado actual, consulte la salida de --help. Consulte también la subsección Colors y la sección COLORES a continuación.

-n, --length longitud

Interpreta solo longitud bytes de entrada.

-o, --two-bytes-octal

Visualización octal de dos bytes. Muestra el desplazamiento de entrada en hexadecimal, seguido de ocho cantidades de dos bytes de datos de entrada, separadas por espacios, con seis columnas y rellenos de cero, en octal, por línea.

-s, --skip desplazamiento

Omite desplazamiento bytes desde el principio de la entrada.

-v, --no-squeezing

La opción -v hace que hexdump muestre todos los datos de entrada. Sin la opción -v, cualquier número de grupos de líneas de salida que sean idénticas al grupo de líneas de salida inmediatamente anterior (excepto por los desplazamientos de entrada), se reemplazan con una línea que consiste en un solo asterisco.

-x, --two-bytes-hex

Visualización hexadecimal de dos bytes. Muestra el desplazamiento de entrada en hexadecimal, seguido de ocho cantidades de dos bytes de datos de entrada, separadas por espacios, con cuatro columnas y rellenos de cero, en hexadecimal, por línea.

-h, --help

Muestra el texto de ayuda y sale.

-V, --version

Muestra la versión y sale.

Para cada archivo de entrada, hexdump copia secuencialmente la entrada a la salida estándar, transformando los datos de acuerdo con las cadenas de formato especificadas por las opciones -e y -f, en el orden en que se especificaron.

FORMATOS

Una cadena de formato contiene cualquier número de unidades de formato, separadas por espacios en blanco. Una unidad de formato contiene hasta tres elementos: un recuento de iteración, un recuento de bytes y un formato.

El recuento de iteración es un entero positivo opcional, que por defecto es uno. Cada formato se aplica un número de veces igual al recuento de iteración.

El recuento de bytes es un entero positivo opcional. Si se especifica, define el número de bytes a interpretar por cada iteración del formato.

Si se especifica un recuento de iteración y/o un recuento de bytes, se debe colocar una barra inclinada única después del recuento de iteración y/o antes del recuento de bytes para desambiguarlos. Cualquier espacio en blanco antes o después de la barra inclinada se ignora.

El formato es obligatorio y debe estar rodeado de comillas (" "). Se interpreta como una cadena de formato estilo fprintf (consulte fprintf(3)), con las siguientes excepciones:

1.

Un asterisco (*) no se puede utilizar como ancho de campo o precisión.

2.

Se requiere un recuento de bytes o una precisión de campo para cada carácter de conversión s (a diferencia del valor predeterminado de fprintf(3) que imprime la cadena completa si la precisión no se especifica).

3.

Los caracteres de conversión h, l, n, p y q no son compatibles.

4.

Se admiten las secuencias de escape de un solo carácter descritas en el estándar C:
NULO \0
<carácter de alerta> \a
<retroceso> \b
<salto de página> \f
<nueva línea> \n
<retorno de carro> \r
<tabulación> \t
<tabulación vertical> \v

Cadenas de conversión

La utilidad hexdump también admite las siguientes cadenas de conversión adicionales.

_a[dox]

Muestra el desplazamiento de entrada, acumulado entre archivos de entrada, del siguiente byte a mostrar. Los caracteres añadidos d, o y x especifican la base de visualización como decimal, octal o hexadecimal respectivamente.

_A[dox]

Casi idéntico a la cadena de conversión _a, excepto que solo se realiza una vez, cuando se han procesado todos los datos de entrada.

_c

Muestra caracteres en el conjunto de caracteres predeterminado. Los caracteres no imprimibles se muestran en octal de tres caracteres y con relleno de cero, excepto aquellos que se pueden representar mediante notación de escape estándar (ver arriba), que se muestran como cadenas de dos caracteres.

_p

Muestra caracteres en el conjunto de caracteres predeterminado. Los caracteres no imprimibles se muestran como un solo '.'.

_u

Muestra caracteres US ASCII, con la excepción de que los caracteres de control se muestran utilizando los siguientes nombres en minúsculas. Los caracteres mayores que 0xff, hexadecimal, se muestran como cadenas hexadecimales.
