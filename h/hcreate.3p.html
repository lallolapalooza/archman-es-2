PRÓLOGO

Esta página de manual forma parte del Manual del Programador POSIX. La implementación de Linux de esta interfaz puede diferir (consulte la página de manual de Linux correspondiente para detalles del comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

hcreate, hdestroy, hsearch — gestionar tabla de búsqueda por hash

SINOPSIS

#include <search.h>
int hcreate(size_t nel);
void hdestroy(void);
ENTRY *hsearch(ENTRY item, ACTION action);

DESCRIPCIÓN

Las funciones hcreate(), hdestroy(), y hsearch() gestionarán tablas de búsqueda por hash.

La función hcreate() asignará espacio suficiente para la tabla, y la aplicación deberá asegurarse de que se llame antes de que se utilice hsearch(). El argumento nel es una estimación del número máximo de entradas que contendrá la tabla. Este número puede ser ajustado al alza por el algoritmo con el fin de obtener ciertas circunstancias matemáticamente favorables.

La función hdestroy() eliminará la tabla de búsqueda, y puede ser seguida por otra llamada a hcreate(). Después de la llamada a hdestroy(), los datos ya no pueden considerarse accesibles.

La función hsearch() es una rutina de búsqueda en tablas hash. Devolverá un puntero dentro de una tabla hash indicando la ubicación en la que se puede encontrar una entrada. El argumento item es una estructura de tipo ENTRY (definida en el encabezado <search.h> ) que contiene dos punteros: item.key apunta a la clave de comparación (un char *), y item.data (un void *) apunta a cualquier otro dato que se desee asociar con esa clave. La función de comparación utilizada por hsearch() es strcmp(). El argumento action es un miembro de un tipo enumeración ACTION que indica el destino de la entrada si no se puede encontrar en la tabla. ENTER indica que el elemento debe ser insertado en la tabla en un punto apropiado. FIND indica que no debe realizarse ninguna entrada. Una resolución sin éxito se indica mediante la devolución de un puntero nulo.

Estas funciones no necesitan ser seguras en entornos con hilos.

VALOR DE RETORNO

La función hcreate() devolverá 0 si no puede asignar espacio suficiente para la tabla; de lo contrario, devolverá un valor distinto de cero.

La función hdestroy() no devolverá ningún valor.

La función hsearch() devolverá un puntero nulo si la acción es FIND y el elemento no pudo ser encontrado, o si la acción es ENTER y la tabla está llena.

ERRORES

Las funciones hcreate() y hsearch() pueden fallar si:

ENOMEM
No hay suficiente espacio de almacenamiento disponible.

EJEMPLOS

El siguiente ejemplo lee cadenas seguidas de dos números y las almacena en una tabla hash, descartando duplicados. Luego lee cadenas, encuentra la entrada coincidente en la tabla hash y la imprime.

#include <stdio.h>
#include <search.h>
#include <string.h>
struct info {        /* Esta es la información almacenada en la tabla */
    int age, room;   /* además de la clave. */
};
#define NUM_EMPL    5000    /* Número de elementos en la tabla de búsqueda. */
int main(void)
{
    char string_space[NUM_EMPL*20];   /* Espacio para almacenar cadenas. */
    struct info info_space[NUM_EMPL]; /* Espacio para almacenar información de empleados. */
    char *str_ptr = string_space;     /* Siguiente espacio en string_space. */
    struct info *info_ptr = info_space;
                                      /* Siguiente espacio en info_space. */
    ENTRY item;
    ENTRY *found_item; /* Nombre a buscar en la tabla. */
    char name_to_find[30];
    int i = 0;
    /* Crear tabla; no se realiza ninguna comprobación de errores. */
    (void) hcreate(NUM_EMPL);
    while (scanf("%s%d%d", str_ptr, &info_ptr->age,
           &info_ptr->room) != EOF && i++ < NUM_EMPL) {
        /* Poner la información en la estructura, y la estructura en item. */
        item.key = str_ptr;
        item.data = info_ptr;
        str_ptr += strlen(str_ptr) + 1;
        info_ptr++;
        /* Poner item en la tabla. */
        (void) hsearch(item, ENTER);
    }
    /* Acceder a la tabla. */
    item.key = name_to_find;
    while (scanf("%s", item.key) != EOF) {
        if ((found_item = hsearch(item, FIND)) != NULL) {
            /* Si el item está en la tabla. */
            (void)printf("found %s, age = %d, room = %d\n",
                found_item->key,
                ((struct info *)found_item->data)->age,
                ((struct info *)found_item->data)->room);
        } else
            (void)printf("no such employee %s\n", name_to_find);
    }
    return 0;
}

USO EN APLICACIONES

Las funciones hcreate() y hsearch() pueden utilizar malloc() para asignar espacio.

    hcreate(3) - Manual de Arch Linux

    hcreate, hdestroy, hsearch - tablas hash

    SINOPSIS

    #include <stdlib.h>

typedef struct {
    const char *key;
    void *data;
} ENTRY;

typedef int (*comparison_fn_t)(const void *, const void *);

typedef struct hsearch_data *hsearch_pvoid_t;

hsearch_pvoid_t hcreate(size_t nel);
ENTRY *hsearch(ENTRY item, ACTION action);
int hdestroy(hsearch_pvoid_t);

    DESCRIPCIÓN

    La función hcreate crea una tabla hash con espacio para nel elementos. Devuelve un puntero a la estructura de tabla hash si la creación tiene éxito, o NULL en caso de error (por ejemplo, si nel es 0).

    La función hsearch busca en la tabla hash especificada por el puntero hsearch_pvoid_t devuelto por hcreate. La búsqueda se basa en el miembro key de la estructura ENTRY proporcionada. El miembro data de la estructura ENTRY se utiliza para enlazar datos arbitrarios con la clave.

    El argumento action determina qué acción se realiza:

    • ENTER: Si la clave ya existe, el puntero data se actualiza. Si la clave no existe, se inserta una nueva entrada.
    • FIND: Busca la clave. Si se encuentra, devuelve un puntero a la entrada. Si no se encuentra, devuelve NULL.
    • ENTER_REPLACE: Si la clave existe, el puntero data se actualiza. Si la clave no existe, se inserta una nueva entrada.

    La función hdestroy libera la memoria utilizada por la tabla hash especificada por hsearch_pvoid_t. No se deben realizar más operaciones en la tabla hash después de llamar a hdestroy.

    VALOR DE RETORNO

    hcreate: Devuelve un puntero opaco a la tabla hash si tiene éxito, o NULL en caso de error.

    hsearch: Devuelve un puntero a una estructura ENTRY si la entrada se encuentra o se inserta. Devuelve NULL si la acción es FIND y la entrada no se encuentra.

    hdestroy: Devuelve 0 si tiene éxito, o -1 en caso de error.

    ERRORES

    La asignación de memoria puede fallar, lo que provoca que hcreate devuelva NULL.

    EJEMPLOS

    El siguiente ejemplo muestra cómo utilizar hcreate, hsearch y hdestroy para crear y gestionar una tabla hash de cadenas de texto:

    #include <stdio.h>
#include <stdlib.h>

int main() {
    hsearch_pvoid_t handle;
    ENTRY item, *found_item;

    // Crear una tabla hash con capacidad para 100 elementos
    handle = hsearch(100);
    if (!handle) {
        perror("hcreate");
        return 1;
    }

    // Insertar algunos elementos
    item.key = "uno";
    item.data = (void *)1;
    hsearch(item, ENTER);

    item.key = "dos";
    item.data = (void *)2;
    hsearch(item, ENTER);

    // Buscar un elemento
    item.key = "uno";
    found_item = hsearch(item, FIND);
    if (found_item) {
        printf("Encontrado: %s -> %p\n", found_item->key, found_item->data);
    } else {
        printf("No encontrado: %s\n", item.key);
    }

    // Buscar un elemento que no existe
    item.key = "tres";
    found_item = hsearch(item, FIND);
    if (found_item) {
        printf("Encontrado: %s -> %p\n", found_item->key, found_item->data);
    } else {
        printf("No encontrado: %s\n", item.key);
    }

    // Destruir la tabla hash
    hdestroy(handle);

    return 0;
}

    USO EN APLICACIONES

    Estas funciones son útiles para implementar estructuras de datos de búsqueda rápida, como diccionarios o cachés, donde se necesita asociar claves con valores.

    JUSTIFICACIÓN

    Las tablas hash proporcionan un rendimiento promedio de O(1) para las operaciones de inserción, búsqueda y eliminación, lo que las convierte en una opción eficiente para muchas aplicaciones.

    DIRECCIONES FUTURAS

    Actualmente no hay planes específicos para futuras direcciones de desarrollo para estas funciones.
