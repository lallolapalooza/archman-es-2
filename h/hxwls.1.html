HXWLS(1) Utilidades HTML-XML HXWLS(1)

NOMBRE

hxwls - listar enlaces en un archivo HTML

SINOPSIS

hxwls [ -l ] [ -t ] [ -r ] [ -h ] [ -a ] [ -b base ] [ archivo ]

DESCRIPCIÓN

El comando hxwls lee un archivo HTML (entrada estándar por defecto) y muestra todos los enlaces que encuentra. La salida se escribe en stdout.

OPCIONES

Se soportan las siguientes opciones:

-l
Producir una lista larga. En lugar de solo la URI, hxwls imprime tres columnas: el nombre del elemento, el valor del atributo REL y la URI de destino.
-t
Producir una lista de tuplas. hxwls imprime cuatro columnas: la URI del documento en sí, el nombre del elemento, el valor del atributo REL y la URI de destino.
-r
Imprimir las URL relativas tal como están, sin convertirlas a URL absolutas.
-b base
Usar base como URL base inicial. Si hay un elemento <base> en el documento, este anulará la opción -b.
-h
Salida como HTML. La salida se listará en forma de elementos <a>.
-a
Convertir cualquier IRI (Identificador Internacionalizado de Recursos) a URIs que solo contengan ASCII. Esto hace que cualquier carácter no ASCII en la ruta de una URI se codifique como octetos escapados con % y los caracteres no ASCII en el nombre de dominio como punycode. (La codificación punycode solo está disponible si hxwls se compila con soporte libidn).

OPERANDOS

Se soporta el siguiente operando:

archivo
El nombre o la URL de un archivo HTML. Si está ausente, se lee la entrada estándar en su lugar.

DIAGNÓSTICOS

Se devuelven los siguientes valores de salida:

0
Finalización exitosa.
> 0
Ocurrió un error en el análisis del archivo HTML. hxwls intentará corregir el error y producirá salida de todos modos.

VER TAMBIÉN
