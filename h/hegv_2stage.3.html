subrutina chegv_2stage (integer itype, character jobz, character uplo, integer n, complex, dimension( lda, * ) a, integer lda, complex, dimension( ldb, * ) b, integer ldb, real, dimension( * ) w, complex, dimension( * ) work, integer lwork, real, dimension( * ) rwork, integer info)

CHEGV_2STAGE

Propósito:

!>
!> CHEGV_2STAGE calcula todos los eigenvalores y, opcionalmente, los eigenvectores
!> de un problema de eigenvalores generalizado hermitiano-definido complejo, de la forma
!> A*x=(lambda)*B*x,  A*Bx=(lambda)*x,  o B*A*x=(lambda)*x.
!> Aquí se asume que A y B son hermitianas y que B es también
!> definida positiva.
!> Esta rutina usa la técnica de 2 etapas para la reducción a tridiagonal
!> que mostró un mayor rendimiento en arquitecturas recientes y para tamaños
!> grandes N>2000.
!>

Parámetros

ITYPE 
!>          ITYPE es INTEGER
!>          Especifica el tipo de problema a resolver:
!>          = 1:  A*x = (lambda)*B*x
!>          = 2:  A*B*x = (lambda)*x
!>          = 3:  B*A*x = (lambda)*x
!>

JOBZ

!>          JOBZ es CHARACTER*1
!>          = 'N':  Calcula solo los eigenvalores;
!>          = 'V':  Calcula los eigenvalores y los eigenvectores.
!>                  No disponible en esta versión.
!>

UPLO

!>          UPLO es CHARACTER*1
!>          = 'U':  Se almacenan los triángulos superiores de A y B;
!>          = 'L':  Se almacenan los triángulos inferiores de A y B.
!>

N

!>          N es INTEGER
!>          El orden de las matrices A y B.  N >= 0.
!>

A

!>          A es un arreglo COMPLEX, dimensión (LDA, N)
!>          En la entrada, la matriz hermitiana A.  Si UPLO = 'U', la
!>          parte triangular superior de A de tamaño N por N contiene la
!>          parte triangular superior de la matriz A.  Si UPLO = 'L',
!>          la parte triangular inferior de A de tamaño N por N contiene
!>          la parte triangular inferior de la matriz A.
!>
!>          En la salida, si JOBZ = 'V', entonces si INFO = 0, A contiene la
!>          matriz Z de eigenvectores.  Los eigenvectores se normalizan
!>          de la siguiente manera:
!>          si ITYPE = 1 o 2, Z**H*B*Z = I;
!>          si ITYPE = 3, Z**H*inv(B)*Z = I.
!>          Si JOBZ = 'N', entonces en la salida el triángulo superior (si UPLO='U')
!>          o el triángulo inferior (si UPLO='L') de A, incluyendo la
!>          diagonal, se destruye.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del arreglo A.  LDA >= max(1,N).
!>

B

!>          B es un arreglo COMPLEX, dimensión (LDB, N)
!>          En la entrada, la matriz hermitiana definida positiva B.
!>          Si UPLO = 'U', la parte triangular superior de B de tamaño N por N
!>          contiene la parte triangular superior de la matriz B.
!>          Si UPLO = 'L', la parte triangular inferior de B de tamaño N por N
!>          contiene la parte triangular inferior de la matriz B.
!>
!>          En la salida, si INFO <= N, la parte de B que contiene la matriz es
!>          sobrescrita por el factor triangular U o L de la factorización
!>          de Cholesky B = U**H*U o B = L*L**H.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del arreglo B.  LDB >= max(1,N).
!>

W

!>          W es un arreglo REAL, dimensión (N)
!>          Si INFO = 0, los eigenvalores en orden ascendente.
!>

WORK

!>          WORK es un arreglo COMPLEX, dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La longitud del arreglo WORK. LWORK >= 1, cuando N <= 1;
!>          de lo contrario
!>          Si JOBZ = 'N' y N > 1, LWORK debe consultarse.
!>                                   LWORK = MAX(1, dimensión) donde
!>                                   dimensión = max(etapa1,etapa2) + (KD+1)*N + N
!>                                             = N*KD + N*max(KD+1,FACTOPTNB)
!>                                               + max(2*KD*KD, KD*NTHREADS)
!>                                               + (KD+1)*N + N
!>                                   donde KD es el tamaño de bloqueo de la reducción,
!>                                   FACTOPTNB es el bloqueo usado por el algoritmo QR o LQ,
!>                                   normalmente FACTOPTNB=128 es una buena elección
!>                                   NTHREADS es el número de hilos usados cuando
!>                                   la compilación con openMP está habilitada, de lo contrario =1.
!>          Si JOBZ = 'V' y N > 1, LWORK debe consultarse. Aún no disponible
!>
!>          Si LWORK = -1, se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo del arreglo WORK, devuelve
!>          este valor como la primera entrada del arreglo WORK, y no se emite
!>          ningún mensaje de error relacionado con LWORK por parte de XERBLA.
!>

RWORK

!>          RWORK es un arreglo REAL, dimensión (max(1, 3*N-2))
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>          > 0:  CPOTRF o CHEEV devolvió un código de error:
!>             <= N:  si INFO = i, CHEEV falló al converger;
!>                    i elementos fuera de la diagonal de una forma
!>                    tridiagonal intermedia no convergieron a cero;
!>             > N:   si INFO = N + i, para 1 <= i <= N, entonces el menor
!>                    principal principal de orden i de B no es positivo.
!>                    La factorización de B no pudo completarse y
!>                    no se calcularon eigenvalores ni eigenvectores.
!>

Description


SSYGV_2STAGE and ZHEGV_2STAGE compute all the
    eigenvalues, and optionally, the eigenvectors of a real/complex generalized
    symmetric definite eigenproblem, of the form




A*x=(lambda)*B*x,  A*Bx=(lambda)*x,  or B*A*x=(lambda)*x.





Here A and B are assumed to be symmetric/Hermitian and B is also
    positive definite. This routine uses the 2-stage technique for the reduction
    to tridiagonal, which shows higher performance on recent architectures and
    for large sizes N > 2000.


Possible values for ITYPE are:




1. A*x = (lambda)*B*x
2. A*B*x = (lambda)*x
3. B*A*x = (lambda)*x





SSYGV_2STAGE:




      The matrix A is REAL symmetric.
      The matrix B is REAL symmetric positive definite.
      The eigenvalues lambda are computed in ascending order.
      The eigenvectors are computed if JOBZ = 'V'.
      The eigenvectors are normalized such that:
        if ITYPE = 1 or 2, Z**T*B*Z = I
        if ITYPE = 3, Z**T*inv(B)*Z = I





ZHEGV_2STAGE:




      The matrix A is COMPLEX hermaphitian.
      The matrix B is COMPLEX hermaphitian positive definite.
      The eigenvalues lambda are computed in ascending order.
      The eigenvectors are computed if JOBZ = 'V'.
      The eigenvectors are normalized such that:
        if ITYPE = 1 or 2, Z**H*B*Z = I
        if ITYPE = 3, Z**H*inv(B)*Z = I









Arguments


ITYPE


!>          ITYPE is INTEGER
!>          Specifies the problem type to be solved:
!>          = 1:  A*x = (lambda)*B*x
!>          = 2:  A*B*x = (lambda)*x
!>          = 3:  B*A*x = (lambda)*x
!> 


JOBZ


!>          JOBZ is CHARACTER*1
!>          = 'N':  Compute eigenvalues only;
!>          = 'V':  Compute eigenvalues and eigenvectors.
!>                  Not available in this release.
!> 


UPLO


!>          UPLO is CHARACTER*1
!>          = 'U':  Upper triangles of A and B are stored;
!>          = 'L':  Lower triangles of A and B are stored.
!> 


N


!>          N is INTEGER
!>          The order of the matrices A and B.  N >= 0.
!> 


A


!>          A is REAL/COMPLEX*16 array, dimension (LDA, N)
!>          On entry, the symmetric/Hermitian matrix A.  If UPLO = 'U', the
!>          leading N-by-N upper triangular part of A contains the
!>          upper triangular part of the matrix A.  If UPLO = 'L',
!>          the leading N-by-N lower triangular part of A contains
!>          the lower triangular part of the matrix A.
!>
!>          On exit, if JOBZ = 'V', then if INFO = 0, A contains the
!>          matrix Z of eigenvectors.  The eigenvectors are normalized
!>          as follows:
!>          if ITYPE = 1 or 2, Z**T*B*Z = I (SSYGV) or Z**H*B*Z = I (ZHEGV);
!>          if ITYPE = 3, Z**T*inv(B)*Z = I (SSYGV) or Z**H*inv(B)*Z = I (ZHEGV).
!>          If JOBZ = 'N', then on exit the upper triangle (if UPLO='U')
!>          or the lower triangle (if UPLO='L') of A, including the
!>          diagonal, is destroyed.
!> 


LDA


!>          LDA is INTEGER
!>          The leading dimension of the array A.  LDA >= max(1,N).
!> 


B


!>          B is REAL/COMPLEX*16 array, dimension (LDB, N)
!>          On entry, the symmetric/Hermitian positive definite matrix B.
!>          If UPLO = 'U', the leading N-by-N upper triangular part of B
!>          contains the upper triangular part of the matrix B.
!>          If UPLO = 'L', the leading N-by-N lower triangular part of B
!>          contains the lower triangular part of the matrix B.
!>
!>          On exit, if INFO <= N, the part of B containing the matrix is
!>          overwritten by the triangular factor U or L from the Cholesky
!>          factorization B = U**T*U or B = L*L**T (SSYGV) or B = U**H*U or B = L*L**H (ZHEGV).
!> 


LDB


!>          LDB is INTEGER
!>          The leading dimension of the array B.  LDB >= max(1,N).
!> 


W


!>          W is REAL/DOUBLE PRECISION array, dimension (N)
!>          If INFO = 0, the eigenvalues in ascending order.
!>

Description

    

    
This routine reduces a generalized complex Hermitian-definite
        eigenvalue problem $Ax = \lambda Bx$ to the standard form $Uy = \lambda y$
        using the two-stage process.

    
This routine is called by chegv to compute the
        eigenvalues and eigenvectors of a complex Hermitian-definite
        generalized eigenvalue problem $Ax = \lambda Bx$.

    
The two-stage reduction is described in Further Details.

    
Overlapping block cyclic algorithms are used to perform the
        reduction. The algorithms are based on fine-grained tasks.

    
The reduction to condensed form is performed by the routine
        zhe2stage, and the solution of the condensed problem is
        performed by the routine zstekr.

    
The routine is designed to run on distributed-memory
        architectures.

    
This routine relies on the following routines:

    

    
    
        
  • zhe2stage: reduction to condensed form
    • 
        
  • zstekr: solution of the condensed problem
    • 
    

    

    
The routine returns the computed eigenvalues in D and
        SD, and the computed eigenvectors in U and SV.

    
The routine returns an error flag IERR. If
        IERR is zero, the routine completed successfully. If
        IERR is non-zero, an error occurred during the computation.

    
The routine is defined in the file zhegv_2stage.f.

!>     is upper triangular and $B_s$ is upper triangular. $B_s$ is then
!>     inverted and the condensed problem is solved.
