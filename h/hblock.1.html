HBLOCK(1) Comandos de usuario HBLOCK(1)

NOMBRE

hBlock - página manual de hBlock 3.5.1

SINOPSIS

hblock [OPCIÓN]...

DESCRIPCIÓN

hBlock es un script de shell compatible con POSIX que obtiene una lista de dominios que sirven anuncios, scripts de seguimiento y malware de múltiples fuentes y crea un archivo hosts, entre otros formatos, que evita que tu sistema se conecte a ellos.

OPCIONES

-O, --output <ARCHIVO|->, ${HBLOCK_OUTPUT_FILE}

Ubicación del archivo de salida.
Si es igual a "-", se imprime en stdout.
(por defecto: /etc/hosts)

-H, --header <ARCHIVO|integrado|ninguno|->, ${HBLOCK_HEADER_FILE}

Archivo que se incluirá al principio del archivo de salida.
Si es igual a "integrado", se usa el valor integrado.
Si es igual a "ninguno", se usa un valor vacío.
Si es igual a "-", se usa el contenido de stdin.
Si no se especifica y existe alguno de los siguientes archivos, se usa su contenido.
${XDG_CONFIG_HOME}/hblock/header
/etc/hblock/header
(por defecto: integrado)

-F, --footer <ARCHIVO|integrado|ninguno|->, ${HBLOCK_FOOTER_FILE}

Archivo que se incluirá al final del archivo de salida.
Si es igual a "integrado", se usa el valor integrado.
Si es igual a "ninguno", se usa un valor vacío.
Si es igual a "-", se usa el contenido de stdin.
Si no se especifica y existe alguno de los siguientes archivos, se usa su contenido.
${XDG_CONFIG_HOME}/hblock/footer
/etc/hblock/footer
(por defecto: integrado)

-S, --sources <ARCHIVO|integrado|ninguno|->, ${HBLOCK_SOURCES_FILE}

Archivo con URLs separadas por líneas utilizadas para generar la lista de bloqueo.
Si es igual a "integrado", se usa el valor integrado.
Si es igual a "ninguno", se usa un valor vacío.
Si es igual a "-", se usa el contenido de stdin.
Si no se especifica y existe alguno de los siguientes archivos, se usa su contenido.
${XDG_CONFIG_HOME}/hblock/sources.list
/etc/hblock/sources.list
(por defecto: integrado)

-A, --allowlist <ARCHIVO|integrado|ninguno|->, ${HBLOCK_ALLOWLIST_FILE}

Archivo con entradas separadas por líneas que se eliminarán de la lista de bloqueo.
Si es igual a "integrado", se usa el valor integrado.
Si es igual a "ninguno", se usa un valor vacío.
Si es igual a "-", se usa el contenido de stdin.
Si no se especifica y existe alguno de los siguientes archivos, se usa su contenido.
${XDG_CONFIG_HOME}/hblock/allow.list
/etc/hblock/allow.list
(por defecto: integrado)

-D, --denylist <ARCHIVO|integrado|ninguno|->, ${HBLOCK_DENYLIST_FILE}

Archivo con entradas separadas por líneas que se añadirán a la lista de bloqueo.
Si es igual a "integrado", se usa el valor integrado.
Si es igual a "ninguno", se usa un valor vacío.
Si es igual a "-", se usa el contenido de stdin.
Si no se especifica y existe alguno de los siguientes archivos, se usa su contenido.
${XDG_CONFIG_HOME}/hblock/deny.list
/etc/hblock/deny.list
(por defecto: integrado)

-R, --redirection <REDIRECCIÓN>, ${HBLOCK_REDIRECTION}

Redirección para todas las entradas en la lista de bloqueo.
(por defecto: 0.0.0.0)

-W, --wrap <NÚMERO>, ${HBLOCK_WRAP}

Dividir las líneas de la lista de bloqueo después de este número de entradas.
(por defecto: 1)

-T, --template <PLANTILLA>, ${HBLOCK_TEMPLATE}

Plantilla aplicada a cada entrada.
%D = <DOMINIO>, %R = <REDIRECCIÓN>
(por defecto: %R %D)

-C, --comment <COMENTARIO>, ${HBLOCK_COMMENT}

Carácter utilizado para comentarios.
(por defecto: #)

-l, --[no-]lenient, ${HBLOCK_LENIENT}

Coincidir con todas las entradas de las fuentes independientemente de su IP, en lugar de 0.0.0.0, 127.0.0.1, ::, ::1 o nada.
(por defecto: false)

-r, --[no-]regex, ${HBLOCK_REGEX}

Usar BREs de POSIX en la lista de permitidos en lugar de cadenas fijas.
(por defecto: false)

-f, --[no-]filter-subdomains, ${HBLOCK_FILTER_SUBDOMAINS}

No incluir subdominios cuando el dominio principal también está bloqueado. Útil para reducir el tamaño de la lista de bloqueo en casos como cuando el bloqueo DNS hace estos subdominios redundantes.
(por defecto: false)

-n, --retry <NÚMERO>, ${HBLOCK_RETRY}

Número de veces para reintentar una descarga fallida.
(por defecto: 0)

-c, --[no-]continue, ${HBLOCK_CONTINUE}

No abortar si ocurre un error de descarga.
(por defecto: false)

-p, --parallel, ${HBLOCK_PARALLEL}

Concurrencia máxima para descargas paralelas.
(por defecto: 4)

-q, --[no-]quiet, ${HBLOCK_QUIET}

Suprimir mensajes que no sean de error.
(por defecto: false)

-x, --color <auto|true|false>, ${HBLOCK_COLOR}

Colorear la salida.
(por defecto: auto)

-v, --version

Mostrar el número de versión y salir.

-h, --help

Mostrar esta ayuda y salir.
