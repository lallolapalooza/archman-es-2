DESCRIPCIÓ

N

Highlight convierte código fuente a HTML, XHTML, RTF, ODT, LaTeX, TeX, BBCode, marcado Pango, SVG, XTERM o secuencias de escape ANSI. Hay varios temas de color disponibles. Highlight reconoce palabras clave, números, cadenas, comentarios, símbolos y directivas de preprocesador. Soporta alrededor de 180 lenguajes de programación, que están definidos en scripts de

Lua.

Es fácilmente posible ampliar la base de datos de

lenguajes de programación y temas de color de hig
hlight. Consulte el archivo README para detalles.

    highlight.1.en

    NAME

    highlight - Syntax highlighter

    SYNOPSIS

    highlight [OPTIONS] [FILE]

    DESCRIPTION

    highlight is a command-line syntax highlighter that supports a wide range of programming languages. It can output highlighted code in various formats, including HTML, RTF, ANSI, and LaTeX.

    OPTIONS

    -O, --output=FORMAT
    Specify the output format. Supported formats include:
    • html: HTML output with CSS.
    • xhtml: XHTML output.
    • rtf: Rich Text Format output.
    • ansi: ANSI escape code output for terminal.
    • latex: LaTeX output.
    The default format is HTML.
    -S, --style=STYLE
    Specify the color style. This option is only applicable for formats that support styling (e.g., HTML, ANSI). Common styles include:
    • default
    • darkgray
    • ubuntudark
    • monokai
    • zenburn
    Use highlight --list-styles to see all available styles.
    -l, --list-languages
    List all supported programming languages.
    -L, --list-styles
    List all supported color styles.
    -i, --inline
    Use inline CSS for HTML output instead of an external stylesheet.
    -n, --no-semicolons
    Omit semicolons from output (e.g., in CSS). This is useful for certain template engines.
    -c, --code=LANG
    Specify the language of the input code. If not specified, highlight will try to auto-detect the language.
    -o, --output-file=FILE
    Write the output to the specified file instead of standard output.
    -h, --help
    Display a help message and exit.
    -v, --version
    Display version information and exit.

    ENVIRONMENT VARIABLES

    No specific environment variables are known to affect the behavior of highlight.

    HINTS

    • For best results with language auto-detection, ensure that the input file has a common file extension (e.g., .py for Python, .js for JavaScript).
    • You can pipe the output of another command to highlight: cat mycode.c | highlight -o ansi

    BUGS

    Report bugs to the project's issue tracker on GitLab.

    FILES

    highlight does not create or manage any specific configuration files by default.

    EXAMPLES

    # Highlight a Python file and output to HTML
highlight my_script.py

# Highlight a C++ file to ANSI format for terminal display
highlight -O ansi my_program.cpp

# Highlight a JavaScript file to RTF format
highlight -O rtf my_app.js

# Specify the language as Java and output to a file
highlight -c java -o output.html source_code.java

# List all supported languages
highlight --list-languages

    AUTHORS

    The highlight program was written by the developers listed on the project's GitLab page.
