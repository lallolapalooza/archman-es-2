hwloc_obj_t hwloc_get_cache_covering_cpuset (hwloc_topology_t topology, hwloc_const_cpuset_t set) [inline]

Obtener la primera caché de datos (o unificada) que cubre un conjunto de cpuset.

Retorna

una caché que cubre, o NULL si ninguna caché coincide.

Encuentra la profundidad de los objetos de caché que coinciden con el nivel y tipo de caché. Retorna la profundidad del nivel de topología que contiene objetos de caché cuyos atributos coinciden con cachelevel y cachetype.

Esta función es idéntica a llamar a hwloc_get_type_depth() con el tipo correspondiente como HWLOC_OBJ_L1ICACHE, excepto que también puede retornar una caché unificada al buscar una caché de instrucciones.

Retorna

la profundidad del nivel único de caché unificada coincidente si cachetype es HWLOC_OBJ_CACHE_UNIFIED.

la profundidad de un nivel de caché coincidente o un nivel de caché unificada si cachetype es HWLOC_OBJ_CACHE_DATA o HWLOC_OBJ_CACHE_INSTRUCTION.

la profundidad del nivel coincidente si cachetype es -1 pero solo un nivel coincide.

HWLOC_TYPE_DEPTH_MULTIPLE si cachetype es -1 pero varios niveles coinciden.

HWLOC_TYPE_DEPTH_UNKNOWN si ningún nivel de caché coincide.

hwloc_obj_t hwloc_get_shared_cache_covering_obj (hwloc_topology_t topology, hwloc_obj_t obj) [inline]

Obtener la primera caché de datos (o unificada) compartida entre un objeto y alguien más.

Retorna

una caché compartida.

NULL si ninguna caché coincide o si se proporciona un objeto inválido (por ejemplo, objeto de E/S).
