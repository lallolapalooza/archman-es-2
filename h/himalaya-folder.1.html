folder(1) Manual de Comandos Generales folder(1)

NOMBRE

folder - Crear, listar y purgar tus carpetas (también conocidas como buzones de correo)

SINOPSIS

folder [-h|--help] <subcomandos>

DESCRIPCIÓN

Crea, lista y purga tus carpetas (también conocidas como buzones de correo).

Una carpeta (también conocida como buzón de correo o directorio) es un contenedor de mensajes. Este subcomando te permite gestionarlas.

OPCIONES

-h, --help
Imprimir ayuda (ver un resumen con '-h')

SUBCOMANDOS

folder-add(1)
Crea la carpeta dada
folder-list(1)
Lista todas las carpetas
folder-expunge(1)
Expulsa la carpeta dada
folder-purge(1)
Pura la carpeta dada
folder-delete(1)
Elimina la carpeta dada
folder-help(1)
Imprime este mensaje o la ayuda del subcomando(s) dado(s)
