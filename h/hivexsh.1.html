hivexsh(1) Registro de Windows hivexsh(1)

NOMBRE

hivexsh - Shell para los archivos colmena del Registro de Windows

SINOPSIS

hivexsh [-opciones] [archivo_colmena]

DESCRIPCIÓN

Este programa proporciona un shell sencillo para navegar por los archivos 'colmena' del Registro de Windows. Utiliza la biblioteca hivex para acceder a estos archivos binarios.

Primero necesitará proporcionar un archivo colmena de un sistema operativo Windows. Los archivos colmena suelen ubicarse en "C:\Windows\System32\Config" y tienen nombres como "software", "system" etc (sin ninguna extensión de archivo). Para más información sobre los archivos colmena, lea hivex(3). Para información sobre cómo descargar archivos de máquinas virtuales, lea virt-cat(1) y guestfish(1).

Puede proporcionar el nombre del archivo colmena a examinar en la línea de comandos. Por ejemplo:

hivexsh software

O puede iniciar "hivexsh" sin ningún argumento, e inmediatamente usar el comando "load" para cargar una colmena:

$ hivexsh
Bienvenido a hivexsh, el shell interactivo de hivex para examinar
archivos colmena binarios del Registro de Windows.
Escriba: 'help' para ayuda con los comandos
      'quit' para salir del shell
> load software
software\>

Navegue por las claves de la colmena usando el comando "cd" , como si contuviera un sistema de archivos, y use "ls" para listar las subclaves de la clave actual. Los demás comandos se enumeran a continuación.

OPCIONES

-d
Habilita muchos mensajes de depuración. Si encuentra un archivo de Registro que este programa no puede analizar, habilite esta opción y publique la salida completa y el archivo colmena del Registro en su informe de error.
-f nombre_archivo
Lee los comandos de "nombre_archivo" en lugar de stdin. Para escribir un script de hivexsh, use: 
#!/usr/bin/hivexsh -f
-u
Utiliza heurísticas para tolerar ciertos niveles de corrupción dentro de las colmenas.

Esto no es seguro pero puede permitir exportar/fusionar claves/valores válidos en una colmena de otro modo corrupta.

-w
Si se proporciona esta opción, se permiten escrituras en la colmena (vea el comando "commit" más abajo, y la discusión sobre modificar colmenas en "ESCRIBIENDO EN ARCHIVOS COLMENA" en hivex(3)).

Nota importante: Incluso si especifica esta opción, no se escribe nada en la colmena a menos que llame al comando "commit". Si sale del shell sin confirmar, todos los cambios serán descartados.

Si no se proporciona esta opción, los comandos de escritura están deshabilitados.

COMANDOS

add nombre
Añade una subclave llamada "nombre" debajo del nodo actual. El nombre puede contener espacios y caracteres de puntuación, y no necesita estar entre comillas.

La nueva clave no tendrá subclaves ni valores (vea "setval").

No debe existir una subclave llamada "nombre", o este comando fallará. Para reemplazar una subclave existente, elimínela primero así:

cd nombre
del
cd ruta
Cambia a la subclave "ruta". Use barras invertidas al estilo Windows para separar los elementos de la ruta, y comience con una barra invertida para empezar desde la raíz de la colmena. Por ejemplo: 
cd \Classes\*

se mueve desde el nodo raíz, al nodo "Classes" , al nodo "*" . Si ya estaba en el nodo raíz, podría hacer esto en su lugar:

cd Classes\*

o incluso:

cd Classes
cd *

Los elementos de la ruta (nombres de nodo) se comparan sin distinguir mayúsculas de minúsculas, y caracteres como el espacio, "*", y "?" no tienen ninguna importancia especial.

"cd .." puede usarse para ir al directorio padre.

"cd" sin ningún argumento imprime la ruta actual.

Tenga cuidado con "cd \" ya que la biblioteca readline tiene un comportamiento no documentado donde pensará que la barra invertida final es una continuación (lee la siguiente línea de entrada y la añade). Ponga un espacio después de la barra invertida.

close | unload
Cierra la colmena actualmente cargada.

Si modificó la colmena, todas las escrituras no confirmadas se pierden cuando llama a este comando (o si el shell sale). Tiene que llamar a "commit" para escribir los cambios.

commit [nuevo_archivo]
Confirma los cambios en la colmena. Si se proporciona el parámetro opcional "nuevo_archivo" , entonces la colmena se escribe en ese archivo, de lo contrario el archivo original se sobrescribe.

Note que tiene que especificar el "-w" indicador, de lo contrario no se permiten escrituras.

del
Elimina el nodo actual y todo lo que hay debajo. El directorio actual se mueve un nivel hacia arriba (como si hiciera "cd ..") después de este comando.

No puede eliminar el nodo raíz.

exit | quit
Sale del shell.
load archivo_colmena
Carga la colmena binaria llamada "archivo_colmena". La colmena actualmente cargada, si la hay, se cierra. El directorio actual se cambia de vuelta al nodo raíz.
ls
Lista las subclaves de la clave del Registro de la colmena actual. Note que este comando no toma ningún argumento.
lsval [clave]
Lista los pares (clave, valor) de la clave del Registro de la colmena actual. Si no se da ningún argumento, se muestran todos los pares. Si "clave" se da, entonces se muestra el valor de la clave con ese nombre. Si "@" se da, entonces se muestra el valor de la clave predeterminada.
setval nrvals
Este comando reemplaza todos los pares (clave, valor) en el nodo actual con los valores en la entrada posterior. "nrvals" es el número de valores (es decir, pares (clave, valor)), y cualquier valor existente en este nodo se elimina. Así que "setval 0" simplemente elimina cualquier valor en el nodo actual.

El comando lee 2 * nrvals líneas de entrada, con cada par de líneas de entrada correspondiente a una clave y un valor a añadir.

Por ejemplo, el siguiente comando setval reemplaza lo que sea que esté en el nodo actual con dos pares (clave, valor). La clave predeterminada se establece a la cadena "abcd" codificada en UTF16-LE. El otro valor se llama "ANumber" y es un DWORD little-endian 0x12345678.

setval 2
@
string:abcd
ANumber
dword:12345678

La primera línea de cada par es la clave (la clave especial "@" significa la clave predeterminada, pero también puede usar una línea en blanco).

La segunda línea de cada par es el valor, que tiene un formato especial "tipo:valor" con los posibles tipos resumidos en la tabla a continuación:

none                 No se almacenan datos, y el tipo se establece a 0.
string:abc           "abc" se almacena como una cadena codificada en
                     UTF16-LE (tipo 1). Note que solo se admiten
                     cadenas ASCII de 7 bits como entrada.
expandstring:...     Igual que string pero con tipo 2.
dword:0x01234567     Un DWORD (tipo 4) con el valor hexadecimal
                     0x01234567. También puede usar decimal
                     u octall números aquí.
qword:0x0123456789abcdef
                     Un QWORD (tipo 11) con el valor hexadecimal
                     0x0123456789abcdef.  Aquí también puede usar
                     números decimales u octales.
hex:<tipo>:<hexbytes>
hex:1:41,00,42,00,43,00,44,00,00,00
                     Esta es la forma genérica de introducir cualquier
                     valor.  <tipo> es el tipo de valor entero.
                     <hexbytes> es una lista de pares de dígitos hexadecimales
                     que se tratan como bytes.
                     (Cualquier carácter que no sea un dígito hexadecimal se
                     ignora, por lo que puede separar los bytes con comas
                     o espacios si lo desea).
