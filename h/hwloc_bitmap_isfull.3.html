Detailed Description

The hwloc_bitmap_t type represents a set of integers (positive or null). A bitmap may be of infinite size (all bits are set after some point). A bitmap may even be full if all bits are set.

Bitmaps are used by hwloc for sets of OS processors (which may actually be hardware threads) as by hwloc_cpuset_t (a typedef for hwloc_bitmap_t), or sets of NUMA memory nodes as hwloc_nodeset_t (also a typedef for hwloc_bitmap_t). Those are used for cpuset and nodeset fields in the hwloc_obj structure, see Object Sets (hwloc_cpuset_t and hwloc_nodeset_t).

Both CPU and node sets are always indexed by OS physical number. However users should usually not build CPU and node sets manually (e.g. with hwloc_bitmap_set()). One should rather use existing object sets and combine them with hwloc_bitmap_or(), etc. For instance, binding the current thread on a pair of cores may be performed with:

hwloc_obj_t core1 = ... , core2 = ... ;
hwloc_bitmap_t set = hwloc_bitmap_alloc();
hwloc_bitmap_or(set, core1->cpuset, core2->cpuset);
hwloc_set_cpubind(topology, set, HWLOC_CPUBIND_THREAD);
hwloc_bitmap_free(set);

Note

Most functions below return 0 on success and -1 on error. The usual error case would be an internal failure to realloc/extend the storage of the bitmap (errno would be set to ENOMEM). See also Error reporting in the API.

Several examples of using the bitmap API are available under the doc/examples/ directory in the source tree. Regression tests such as tests/hwloc/hwloc_bitmap*.c also make intensive use of this API.

Macro Definition Documentation

#define hwloc_bitmap_foreach_begin(id, bitmap)

Loop macro iterating on bitmap bitmap. The loop must start with hwloc_bitmap_foreach_begin() and end with hwloc_bitmap_foreach_end() followed by a terminating ';'.

id is the loop variable; it should be an unsigned int. The first iteration will set id to the lowest index in the bitmap. Successive iterations will iterate through, in order, all remaining indexes set in the bitmap. To be specific: each iteration will return a value for id such that hwloc_bitmap_isset(bitmap, id) is true.

The assert prevents the loop from being infinite if the bitmap is infinitely set.

#define hwloc_bitmap_foreach_end()

End of loop macro iterating on a bitmap. Needs a terminating ';'.

See also

hwloc_bitmap_foreach_begin()

Typedef Documentation

typedef struct hwloc_bitmap_s * hwloc_bitmap_t

A pointer to a structure describing a bitmap. This is the main type for manipulating bitmaps. Users must not access the members of the structure directly. Use the provided functions instead.

typedef const struct hwloc_bitmap_s * hwloc_const_bitmap_t

A pointer to a constant bitmap structure. This is used for parameters to functions that do not modify the bitmap, to prevent accidental modifications.

Allocate a new empty bitmap. It will be empty.

Returns

A pointer to the allocated bitmap, or NULL in case of error.

hwloc_bitmap_t hwloc_bitmap_alloc_full (void)

Allocate a new bitmap that is full (all bits set). This may be useful if the user knows that the bitmap will eventually hold all bits anyway.

Returns

A pointer to the allocated bitmap, or NULL in case of error.

Free the bitmap. The bitmap must have been allocated with hwloc_bitmap_alloc() or hwloc_bitmap_alloc_full().

Duplicate the bitmap bitmap.

Returns

A pointer to the newly allocated bitmap, or NULL in case of error.

Copy the bitmap src into bitmap dst. dst must be already allocated.

Returns

0 on success, -1 on error (e.g. if dst is NULL).

int hwloc_bitmap_snprintf (char *restrict buf, size_t buflen, hwloc_const_bitmap_t bitmap)

Format the bitmap bitmap into the string buf. buf must be large enough to hold the string representation.

The string format is a comma-separated list of integers and ranges of integers. For instance, "0,1,4-9".

Returns

The number of characters that would have been written if buf was large enough, not counting the terminating NULL. Returns -1 if the bitmap could not be converted.

int hwloc_bitmap_asprintf (char **strp, hwloc_const_bitmap_t bitmap)

Format the bitmap bitmap into a string and store it in the location pointed to by strp. Memory will be allocated by this function. The caller is responsible for freeing the allocated memory using free().

Returns

The number of characters in the string, not counting the terminating NULL. Returns -1 if the bitmap could not be converted or if memory allocation failed.

int hwloc_bitmap_sscanf (hwloc_bitmap_t bitmap, const char *restrict string)

The string format is a comma-separated list of integers and ranges of integers. For instance, "0,1,4-9".

Returns

0 on success, -1 on error (e.g. if string is malformed or bitmap is NULL).

bitmap)

Mantiene un solo índice entre los establecidos en el mapa de bits bitmap. Puede ser útil antes de la vinculación para que el proceso no tenga la posibilidad de migrar entre múltiples procesadores en la máscara original. En lugar de ejecutar la tarea en cualquier PU dentro del conjunto de CPU dado, el programador del sistema operativo se verá obligado a ejecutarla en una sola de estas PUs. Evita una sobrecarga de migración y los "ping-pongs" de la línea de caché entre
