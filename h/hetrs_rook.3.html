subrutina chetrs_rook (character uplo, integer n, integer nrhs, complex, dimension( lda, * ) a, integer lda, integer, dimension( * ) ipiv, complex, dimension( ldb, * ) b, integer ldb, integer info)

CHETRS_ROOK calcula la solución a un sistema de ecuaciones lineales A * X = B para matrices HE usando la factorización obtenida con uno de los métodos de pivote diagonal acotado (máx. 2 intercambios)

Propósito:

!>
!> CHETRS_ROOK resuelve un sistema de ecuaciones lineales A*X = B con una
!> matriz hermitiana compleja A usando la factorización A = U*D*U**H o
!> A = L*D*L**H calculada por CHETRF_ROOK.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          Especifica si los detalles de la factorización se almacenan
!>          como una matriz triangular superior o inferior.
!>          = 'U':  Triangular superior, la forma es A = U*D*U**H;
!>          = 'L':  Triangular inferior, la forma es A = L*D*L**H.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de miembros independientes, es decir, el número de columnas
!>          de la matriz B.  NRHS >= 0.
!>

A

!>          A es un arreglo COMPLEX, dimensión (LDA,N)
!>          La matriz diagonal por bloques D y los multiplicadores usados para
!>          obtener el factor U o L como lo calcula CHETRF_ROOK.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del arreglo A.  LDA >= max(1,N).
!>

IPIV

!>          IPIV es un arreglo INTEGER, dimensión (N)
!>          Detalles de los intercambios y la estructura por bloques de D
!>          según lo determinado por CHETRF_ROOK.
!>

B

!>          B es un arreglo COMPLEX, dimensión (LDB,NRHS)
!>          En la entrada, la matriz de miembros independientes B.
!>          En la salida, la matriz solución X.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del arreglo B.  LDB >= max(1,N).
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>

NAME

DSYTRS_ROOK, SSYTRS_ROOK, ZHETRS_ROOK, ZSYTRS_ROOK - solve a system of linear equations with a symmetric or Hermitian matrix

  INTEGER IPIV(*)

  CHARACTER UPLO

  INTEGER IPIV(*)

DESCRIPTION

The subroutines DSYTRS_ROOK, SSYTRS_ROOK, ZHETRS_ROOK, and ZSYTRS_ROOK compute the solution to a system of linear equations A*X = B, where A is a real symmetric or complex Hermitian matrix, using the factorization computed by the routines DSYTRF_ROOK, SSYTRF_ROOK, ZHETRF_ROOK, or ZSYTRF_ROOK, respectively. The factorization is one of A = U*D*U**T or A = L*D*L**T (for symmetric matrices) or A = U*D*U**H or A = L*D*L**H (for Hermitian matrices), where U and L are transposed unitary matrices, and D is block diagonal with 1-by-1 and 2-by-2 diagonal matrices. These routines use bounded diagonal pivoting with partial pivoting to improve the accuracy and stability of the factorization.

The routines differ in the precision of the floating-point arithmetic used:

  • DSYTRS_ROOK uses double precision (64-bit).
  • SSYTRS_ROOK uses single precision (32-bit).
  • ZHETRS_ROOK uses double precision complex numbers.
  • ZSYTRS_ROOK uses double precision complex numbers.

DSYTRS_ROOK

Purpose:

!>
!> DSYTRS_ROOK solves a system of linear equations A*X = B with
!> a real symmetric matrix A using the factorization A = U*D*U**T or
!> A = L*D*L**T computed by DSYTRF_ROOK.
!>

Parameters

UPLO 
!>          UPLO is CHARACTER*1
!>          Specifies whether the details of the factorization are stored
!>          as an upper or lower triangular matrix.
!>          = 'U':  Upper triangular, form is A = U*D*U**T;
!>          = 'L':  Lower triangular, form is A = L*D*L**T.
!>

N

!>          N is INTEGER
!>          The order of the matrix A.  N >= 0.
!>

NRHS

!>          NRHS is INTEGER
!>          The number of right hand sides, i.e., the number of columns
!>          of the matrix B.  NRHS >= 0.
!>

A

!>          A is DOUBLE PRECISION array, dimension (LDA,N)
!>          The block diagonal matrix D and the multipliers used to
!>          obtain the factor U or L as computed by DSYTRF_ROOK.
!>

LDA

!>          LDA is INTEGER
!>          The leading dimension of the array A.  LDA >= max(1,N).
!>

IPIV

!>          IPIV is INTEGER array, dimension (N)
!>          Details of the interchanges and the block structure of D
!>          as determined by DSYTRF_ROOK.
!>

B

!>          B is DOUBLE PRECISION array, dimension (LDB,NRHS)
!>          On entry, the right hand side matrix B.
!>          On exit, the solution matrix X.
!>

LDB

!>          LDB is INTEGER
!>          The leading dimension of the array B.  LDB >= max(1,N).
!>

INFO

!>          INFO is INTEGER
!>          = 0:  successful exit
!>          < 0:  if INFO = -i, the i-th argument had an illegal value
!>
