hg-config(1)

Paquete: mercurial

Licencias: GPL

HG(CONFIG) HG(CONFIG)

NOMBRE

hg config - muestra la configuración combinada de todos los archivos hgrc

SINOPSIS

hg config [-u] [NOMBRE]...

DESCRIPCIÓN

Sin argumentos, imprime los nombres y valores de todos los elementos de configuración.

Con un argumento de la forma sección.nombre, imprime solo el valor de ese elemento de configuración.

Con múltiples argumentos, imprime los nombres y valores de todos los elementos de configuración con nombres de sección o sección.nombres coincidentes.

Con --edit, inicia un editor en el archivo de configuración a nivel de usuario. Con --global, edita el archivo de configuración a nivel de sistema. Con --local, edita el archivo de configuración a nivel de repositorio.

Con --source, se imprime la fuente (nombre de archivo y número de línea) para cada elemento de configuración.

Ver hg help config para más información sobre los archivos de configuración.

La bandera --non-shared se usa para editar el archivo de configuración .hg/hgrc-not-shared. Este archivo no se comparte entre directorios compartidos cuando se está en modo seguro de compartición.

Plantilla:

Las siguientes palabras clave son compatibles. Ver también hg help templates.

nombre
Cadena. Nombre de la configuración.
fuente
Cadena. Nombre del archivo y número de línea donde se define el elemento.
valor
Cadena. Valor de la configuración.

La bandera --shared se puede usar para editar el archivo de configuración del repositorio de origen compartido. Solo funciona cuando has compartido usando la función experimental de origen seguro.

Devuelve 0 en caso de éxito, 1 si NOMBRE no existe.

OPCIONES

-u, --untrusted
mostrar opciones de configuración no confiables
--exp-all-known
mostrar todas las opciones de configuración conocidas (EXPERIMENTAL)
-e, --edit
editar configuración del usuario
-l, --local
editar configuración del repositorio
--source
mostrar la fuente del valor de configuración
--shared
editar configuración de repositorio de origen compartido
--non-shared
editar configuración no compartida
-g, --global
editar configuración global
-T,--template <PLANTILLA>
mostrar con plantilla

ALIAS

showconfig, debugconfig
