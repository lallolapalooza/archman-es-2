DOCUMENTACION DE DEFINICION DE MACROS

#define HWLOC_API_VERSION 0x00020c00

Indica en tiempo de compilación qué versión de la API de hwloc se está utilizando. Este número se actualiza a (X<<16)+(Y<<8)+Z cuando un nuevo lanzamiento X.Y.Z modifica realmente la API.

Los usuarios pueden comprobar las características disponibles en tiempo de compilación utilizando este número (consulte ¿Cómo manejo los cambios de API?).

Nota

Esto no debe confundirse con HWLOC_VERSION, la versión de la biblioteca. Dos lanzamientos estables de la misma serie suelen tener la misma HWLOC_API_VERSION, aunque sus HWLOC_VERSION sean diferentes.

#define HWLOC_COMPONENT_ABI 7

Versión actual de la ABI de componentes y plugins (consulte hwloc/plugins.h)

DOCUMENTACION DE FUNCIONES

unsigned hwloc_get_api_version (void)

Indica en tiempo de ejecución qué versión de la API de hwloc se utilizó en tiempo de compilación. Debería ser HWLOC_API_VERSION si se ejecuta con la misma versión.

Retorna

el número de versión de tiempo de compilación.
