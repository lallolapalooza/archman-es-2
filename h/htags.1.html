HTAGS(1) Manual de Comandos Generales HTAGS(1)

NOMBRE

htags - generar un hipertexto a partir de un conjunto de archivos fuente

SINOPSIS

htags [-aDfFghInosTvw][-d ruta_db][-m nombre][-t titulo][dir]

DESCRIPCIÓN

Htags genera un hipertexto a partir de un conjunto de archivos fuente de C, Yacc, Java, PHP y ensamblador.

Antes de usar este comando, deberías ejecutar gtags(1) en el directorio raíz de un proyecto fuente. Luego puedes ejecutar htags en el mismo lugar. Htags crea un directorio llamado ´HTML´, y coloca un hipertexto en él. Puedes comenzar a navegar en ´HTML/index.html´.

Dado que htags genera un hipertexto estático mientras no se especifique ninguna opción -D o -f, puedes moverlo a cualquier lugar y navegarlo con cualquier navegador sin ningún servidor HTTP. Si usas la opción -D o -f, necesitas usar un servidor HTTP. Aunque cualquier servidor HTTP está disponible, se recomienda htags-server(1).

Este comando tiene muchísimas opciones. Si eres nuevo en htags, se recomienda usar la opción --suggest. Con esa opción, htags elige opciones populares en tu nombre.

OPCIONES

Las siguientes opciones están disponibles:

-a, --alfabetico
Crea un índice alfabético adecuado para un proyecto grande.
--auto-completado[=limite]
Habilita la función de autocompletado para el formulario de entrada. Si se especifica limite, el número de candidatos se limita a ese valor. Ten en cuenta que esta función requiere lenguaje javascript en tu navegador.
-C, --directorio dir
Cambia el directorio antes de realizar todo el trabajo, incluido el análisis de parámetros.
--precaucion
Muestra un mensaje de precaución en la página principal.
--cflow archivo_cflow
Añade un árbol de llamadas mediante cflow(1). archivo_cflow debe tener formato posix. Si usas GNU cflow, invoca el comando en el directorio raíz del proyecto con la opción --formato=posix. Esta opción está obsoleta; por favor usa --arbol-llamadas o --arbol-llamado en su lugar.
--arbol-llamadas archivo_llamadas
Añade un árbol de llamadas mediante cflow(1); archivo_llamadas debe tener formato posix. Si usas GNU cflow, invoca el comando en el directorio raíz del proyecto con la opción --formato=posix.
--arbol-llamado archivo_llamado
Añade un árbol de llamados mediante cflow(1); archivo_llamado debe tener formato posix. Si usas GNU cflow, invoca el comando en el directorio raíz del proyecto con las opciones --formato=posix y --inverso.
--colorear-linea-advertida
Usa color para resaltar las líneas advertidas.
--cvsweb url
Añade un enlace a cvsweb; url se usa como base de la URL. Cuando el directorio ´CVS´ existe en el directorio raíz del proyecto, el contenido de ´CVS/Repository´ se usa como la ruta relativa desde la base.
--cvsweb-cvsroot cvsroot
Especifica cvsroot en la URL de cvsweb.
-D, --dinamico
Genera una lista de etiquetas dinámicamente usando un programa CGI. Aunque esta opción disminuye tanto el tamaño como el tiempo de generación del hipertexto, necesitas iniciar un servidor HTTP.
-d, --ruta_db ruta_db
Especifica el directorio en el que existe ´GTAGS´. Por defecto es el directorio actual.
--deshabilitar-grep
Deshabilita grep en el formulario de búsqueda (-f, --formulario).
--deshabilitar-idutils
Deshabilita idutils en el formulario de búsqueda (-f, --formulario).
-F, --frame
Usa frames para la página principal.
-f, --formulario
Añade un formulario de búsqueda usando un programa CGI. Necesitas iniciar un servidor HTTP para ello.
--guia-fijo
Coloca una guía fija en la parte inferior de la pantalla del navegador.
--ruta-completa
Usa el nombre de ruta completo en el índice de archivos. Por defecto, usa solo el último componente de una ruta.
-g, --gtags
Ejecuta gtags(1) antes de iniciar el trabajo. Las opciones -v, -w y ruta_db se pasan a gtags.
--gtagsconf archivo
Establece la variable de entorno GTAGSCONF a archivo.
--gtagslabel etiqueta
Establece la variable de entorno GTAGSLABEL a etiqueta.
-h, --encabezado-func[=posicion]
Inserta un encabezado de función para cada función. Por defecto, htags no los genera. Puedes elegir la posición usando posicion, que permite ´antes´, ´derecha´ o ´después´ (por defecto).
--ayuda
Imprime un mensaje de uso.
--encabezado-html archivo
Inserta un registro de encabezado derivado de archivo en el encabezado HTML de cada archivo.
-I, --icono
Usa iconos en lugar de texto para algunos enlaces.
--insertar-pie-pagina archivo
Inserta un pie de página personalizado derivado de archivo antes de la etiqueta </body>.
--insertar-encabezado archivo
Inserta un encabezado personalizado derivado de archivo después de la etiqueta <body>.
--orden-elementos espec
Especifica el orden de los elementos en la página principal. El espec es una cadena que consta de signos de elementos en orden. Cada signo significa lo siguiente: ´c´: precaución; ´s´: formulario de búsqueda; ´m´: principales; ´d´: definiciones; ´f´: archivos; ´t´: árbol de llamadas. El valor predeterminado es ´csmdf´.
-m, --func-principal nombre
Especifica el nombre de la función de inicio; el valor predeterminado es ´main´.
--archivo-mapa
Genera el archivo ´MAP´.
-n, --numero-linea[=columnas]
Imprime números de línea. Por defecto, no imprime números de línea. El valor predeterminado de columnas es 4.
--sin-lista-ordenada
Los números no se dan en formato de lista.
-o, --otro
Recoge no solo los archivos fuente sino también otros archivos para el índice de archivos.
-s, --simbolo
Crea anclas no solo para definiciones y referencias, sino también para otros símbolos.
--mostrar-posicion
Imprime la cadena de posición por definición de función. La cadena puede ser interpretada por editores generales en UNIX. El valor predeterminado es falso.
--estadisticas
Imprime información de estadísticas.
--sugerir
Htags elige opciones populares en nombre de los principiantes. Es equivalente a -aghInosTxv --mostrar-posici

Vea también

gtags(1), gtags.conf(5), global(1), htags-server(1)

--suggest2
Htags elige opciones populares en nombre de los principiantes. Esta opción habilita las facilidades de marcos, AJAX y CGI además de las facilitadas por la --suggest opción. Es equivalente a --suggest -DfF --auto-completion --tree-view=filetree ahora.
-T, --table-flist[=filas]
Utiliza la etiqueta <table> para mostrar el índice de archivos. Opcionalmente puede especificar el número de filas; el valor por defecto es 5.
-t, --title título
Título del hipertexto. El valor por defecto es el último componente de la ruta del directorio actual.
--tabs columnas
Tabulaciones. El valor por defecto es 8.
--table-list
Utiliza la etiqueta <table> para mostrar la lista de etiquetas.
--tree-view[=tipo]
Utiliza vista de árbol para el índice de archivos. Tenga en cuenta que esta función requiere el lenguaje javascript en su navegador. Los valores posibles de tipo son los siguientes: treeview, filetree, treeview-red, treeview-black, treeview-gray, treeview-famfamfam. El valor por defecto es treeview.
-v, --verbose
Modo detallado.
--version
Muestra el número de versión.
-w, --warning
Imprime mensajes de advertencia.
dir
El directorio en el que se almacena el resultado de este comando. El valor por defecto es el directorio actual.

EJEMPLOS

$ gtags -v
$ htags -sanohITvt '¡Bienvenido al recorrido del código fuente de XXX!'
$ firefox HTML/index.html
$ htags --suggest2
$ htags-server >& log &
$ firefox http://127.0.0.1:8000

ARCHIVOS

´GTAGS´
Archivo de etiquetas para definiciones.
´GRTAGS´
Archivo de etiquetas para referencias.
´GPATH´
Archivo de etiquetas para archivos fuente.
´gtags.conf´, ´$HOME/.globalrc´
Datos de configuración para GNU Global. Véase gtags.conf(5).
´HTML/FILEMAP´
Archivo de mapeo para convertir el nombre de archivo en la ruta del archivo.
´HTML/GTAGSROOT´
Si este archivo existe, el programa CGI ´global.cgi´ establece la variable de entorno GTAGSROOT con el contenido de él. Si mueve el directorio ´HTML´ de su ubicación original, por favor cree este archivo.
´HTML/.htaccess´
Archivo de configuración local para Apache. Este archivo se genera cuando se -f o -D se especifican las opciones.
´HTML/index.html´
Archivo de inicio.
´HTML/MAP´
Archivo de mapeo para convertir el nombre de etiqueta en la ruta de la lista de etiquetas.
´HTML/style.css´
Archivo de hoja de estilo.
´/usr/local/share/gtags/style.css.tmpl´
La plantilla del archivo de hoja de estilo (´HTML/style.css´).

ENTORNO

Las siguientes variables de entorno afectan la ejecución de htags:

GTAGSCACHE
El tamaño de la caché B-tree. El valor por defecto es 50000000 (bytes).
GTAGSCONF
Archivo de configuración.
GTAGSLABEL
Etiqueta de configuración. El valor por defecto es ´default´.
HTAGS_OPTIONS
El valor de esta variable se inserta al principio de los argumentos.
TMPDIR
La ubicación utilizada para almacenar archivos temporales. El valor por defecto es ´/tmp´.
GTAGSFORCECPP
Si esta variable está establecida, cada archivo cuyo sufijo sea ´.h´ es tratado como un archivo fuente C++.

CONFIGURACIÓN

Las siguientes variables de configuración afectan la ejecución de htags:

datadir(cadena)
Directorio de datos compartidos. El valor por defecto es ´/usr/local/share´ pero puede cambiar el valor usando el script configure. Htags busca los archivos de plantilla en el directorio ´gtags´ en este directorio de datos.
include_file_suffixes(lista separada por comas)
Sufijos de archivos de inclusión. El valor por defecto es:
´h,hh,hxx,hpp,H,inc.php´.
langmap(lista separada por comas)
Mapeo de lenguajes. Cada mapa separado por comas consta del nombre del lenguaje, dos puntos y una lista de extensiones de archivo. El mapeo por defecto es:
´c:.c.h,yacc:.y,asm:.s.S,java:.java,cpp:.c++.cc.hh.cpp.cxx.hxx.hpp.C.H,php:.php.php3.phtml´.

DIAGNÓSTICOS

Htags sale con un valor distinto de 0 si ocurrió un error, 0 en caso contrario.

VÉASE TAMBIÉN

htags-server(1), global(1), gtags(1), gtags.conf(5).

Sistema de etiquetas de código fuente GNU Global
(http://www.gnu.org/software/global/).

ERRORES

El hipertexto generado es MUY GRANDE. Compruebe de antemano el espacio de su disco.

El soporte para PHP está lejos de ser completo.

Las -f y -D opciones generan programas CGI. Si abre el hipertexto al público, por favor reconozca los peligros de seguridad.

Htags no soporta analizadores de complementos.
