subrutina chpsv (caracter uplo, entero n, entero nrhs, complejo, dimensión( * ) ap, entero, dimensión( * ) ipiv, complejo, dimensión( ldb, * ) b, entero ldb, entero info)

CHPSV calcula la solución al sistema de ecuaciones lineales A * X = B para matrices DE OTRO TIPO

Propósito:

!>
!> CHPSV calcula la solución a un sistema complejo de ecuaciones lineales
!>    A * X = B,
!> donde A es una matriz Hermitiana N-por-N almacenada en formato empaquetado y X
!> y B son matrices N-por-NRHS.
!>
!> Se utiliza el método de pivoteo diagonal para factorizar A como
!>    A = U * D * U**H,  si UPLO = 'U', o
!>    A = L * D * L**H,  si UPLO = 'L',
!> donde U (o L) es un producto de permutación y matrices triangulares unitarias superiores (inferiores),
!> D es Hermitiana y diagonal por bloques con bloques diagonales de 1x1 y 2x2.  La forma factorizada de A se utiliza luego para
!> resolver el sistema de ecuaciones A * X = B.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          = 'U':  Se almacena el triángulo superior de A;
!>          = 'L':  Se almacena el triángulo inferior de A.
!>

N

!>          N es ENTERO
!>          El número de ecuaciones lineales, es decir, el orden de la
!>          matriz A.  N >= 0.
!>

NRHS

!>          NRHS es ENTERO
!>          El número de lados derechos, es decir, el número de columnas
!>          de la matriz B.  NRHS >= 0.
!>

AP

!>          AP es un array COMPLEX, dimensión (N*(N+1)/2)
!>          En la entrada, el triángulo superior o inferior de la matriz Hermitiana
!>          A, empaquetado por columnas en un array lineal.  La j-ésima columna de A
!>          se almacena en el array AP de la siguiente manera:
!>          si UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) para 1<=i<=j;
!>          si UPLO = 'L', AP(i + (j-1)*(2n-j)/2) = A(i,j) para j<=i<=n.
!>          Ver más abajo para más detalles.
!>
!>          En la salida, la matriz diagonal por bloques D y los multiplicadores utilizados
!>          para obtener el factor U o L de la factorización
!>          A = U*D*U**H o A = L*D*L**H tal como se calcula por CHPTRF, almacenados como
!>          una matriz triangular empaquetada en el mismo formato de almacenamiento que A.
!>

IPIV

!>          IPIV es un array ENTERO, dimensión (N)
!>          Detalles de los intercambios y la estructura de bloques de D, tal como
!>          se determina por CHPTRF.  Si IPIV(k) > 0, entonces las filas y columnas
!>          k y IPIV(k) se intercambiaron, y D(k,k) es un bloque diagonal de 1x1.
!>          Si UPLO = 'U' y IPIV(k) = IPIV(k-1) < 0,
!>          entonces las filas y columnas k-1 y -IPIV(k) se intercambiaron y
!>          D(k-1:k,k-1:k) es un bloque diagonal de 2x2.  Si UPLO = 'L' y
!>          IPIV(k) = IPIV(k+1) < 0, entonces las filas y columnas k+1 y
!>          -IPIV(k) se intercambiaron y D(k:k+1,k:k+1) es un bloque diagonal de 2x2.
!>

B

!>          B es un array COMPLEX, dimensión (LDB,NRHS)
!>          En la entrada, la matriz del lado derecho B de N x NRHS.
!>          En la salida, si INFO = 0, la matriz solución X de N x NRHS.
!>

LDB

!>          LDB es ENTERO
!>          La dimensión principal del array B.  LDB >= max(1,N).
!>

INFO

!>          INFO es ENTERO
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tuvo un valor ilegal
!>          > 0:  si INFO = i, D(i,i) es exactamente cero.  La factorización
!>                se ha completado, pero la matriz diagonal por bloques D es
!>                exactamente singular, por lo que la solución no pudo ser
!>                calculada.
!>

cspsv


 `cspsv` computes the solution to system of linear equations A * X = B for OTHER matrices


Purpose:




!> CSPSV computes the solution to a complex system of linear equations
!>    A * X = B,
!> where A is an N-by-N symmetric or Hermitian matrix stored in packed
!> format and X and B are N-by-NRHS matrices.
!>
!> The diagonal pivoting method is used to factor A as
!>    A = U * D * U**H,  if UPLO = 'U', or
!>    A = L * D * L**H,  if UPLO = 'L',
!> where U (or L) is a product of permutation and unit upper (lower)
!> triangular matrices, D is symmetric or Hermitian and block diagonal
!> with 1-by-1 and 2-by-2 diagonal blocks. The factored form of A is
!> then used to solve the system of equations A * X = B.
!>




Parameters




UPLO


!>          UPLO is CHARACTER*1
!>          = 'U':  Upper triangle of A is stored;
!>          = 'L':  Lower triangle of A is stored.
!>


N


!>          N is INTEGER
!>          The number of linear equations, i.e., the order of the
!>          matrix A.  N >= 0.
!>


NRHS


!>          NRHS is INTEGER
!>          The number of right hand sides, i.e., the number of columns
!>          of the matrix B.  NRHS >= 0.
!>


AP


!>          AP is COMPLEX array, dimension (N*(N+1)/2)
!>          On entry, the upper or lower triangle of the symmetric or
!>          Hermitian matrix A, packed columnwise in a linear array.
!>          The j-th column of A is stored in the array AP as follows:
!>          if UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) for 1<=i<=j;
!>          if UPLO = 'L', AP(i + (j-1)*(2n-j)/2) = A(i,j) for j<=i<=n.
!>          See below for further details.
!>
!>          On exit, the block diagonal matrix D and the multipliers used
!>          to obtain the factor U or L from the factorization
!>          A = U*D*U**H or A = L*D*L**H as computed by CSPTRF, stored as
!>          a packed triangular matrix in the same storage format as A.
!>


IPIV


!>          IPIV is INTEGER array, dimension (N)
!>          Details of the interchanges and the block structure of D, as
!>          determined by CSPTRF.  If IPIV(k) > 0, then rows and columns
!>          k and IPIV(k) were interchanged, and D(k,k) is a 1-by-1
!>          diagonal block.  If UPLO = 'U' and IPIV(k) = IPIV(k-1) < 0,
!>          then rows and columns k-1 and -IPIV(k) were interchanged and
!>          D(k-1:k,k-1:k) is a 2-by-2 diagonal block.  If UPLO = 'L' and
!>          IPIV(k) = IPIV(k+1) < 0, then rows and columns k+1 and
!>          -IPIV(k) were interchanged and D(k:k+1,k:k+1) is a 2-by-2
!>          diagonal block.
!>


B


!>          B is COMPLEX array, dimension (LDB,NRHS)
!>          On entry, the N-by-NRHS right hand side matrix B.
!>          On exit, if INFO = 0, the N-by-NRHS solution matrix X.
!>


LDB


!>          LDB is INTEGER
!>          The leading dimension of the array B.  LDB >= max(1,N).
!>


INFO


!>          INFO is INTEGER
!>          = 0:  successful exit
!>          < 0:  if INFO = -i, the i-th argument had an illegal value
!>          > 0:  if INFO = i, D(i,i) is exactly zero.  The factorization
!>                has been completed, but the block diagonal matrix D is
!>                exactly singular, so the solution could not be
!>                computed.
!>




Author


Univ. of Tennessee

Univ. of California Berkeley


Univ. of Colorado Denver


NAG Ltd.

!> when N = 4, UPLO = 'U':

!>
!>    a11 a12 a13 a14
