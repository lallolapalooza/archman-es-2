NOMBRE

hg serve - iniciar servidor web independiente

SINOPSIS

hg serve [OPCIÓN]...

DESCRIPCIÓN

Inicia un navegador de repositorios HTTP local y un servidor de pull. Puedes usar esto para compartir y navegar repositorios de forma ad-hoc. Se recomienda utilizar un servidor web real para servir un repositorio durante períodos de tiempo prolongados.

Ten en cuenta que el servidor no implementa control de acceso. Esto significa que, por defecto, cualquiera puede leer desde el servidor y nadie puede escribir en él por defecto. Establece la opción web.allow-push a * para permitir que cualquiera haga push al servidor. Deberías usar un servidor web real si necesitas autenticar usuarios.

Por defecto, el servidor registra los accesos en stdout y los errores en stderr. Usa las opciones -A/--accesslog y -E/--errorlog para registrar en archivos.

Para que el servidor elija un número de puerto libre para escuchar, especifica un número de puerto de 0; en este caso, el servidor imprimirá el número de puerto que utiliza.

Devuelve 0 en caso de éxito.

OPCIONES

-A,--accesslog <ARCHIVO>
nombre del archivo de registro de acceso al que escribir
-d, --daemon
ejecutar el servidor en segundo plano
--daemon-postexec <VALOR[+]>
utilizado internamente por el modo daemon
-E,--errorlog <ARCHIVO>
nombre del archivo de registro de errores al que escribir
-p,--port <PUERTO>
puerto en el que escuchar (por defecto: 8000)
-a,--address <DIR>
dirección en la que escuchar (por defecto: todas las interfaces)
--prefix <PREFIJO>
ruta prefijo desde la que servir (por defecto: raíz del servidor)
-n,--name <NOMBRE>
nombre a mostrar en las páginas web (por defecto: directorio de trabajo)
--web-conf <ARCHIVO>
nombre del archivo de configuración de hgweb (ver 'hg help hgweb')
--webdir-conf <ARCHIVO>
nombre del archivo de configuración de hgweb (OBSOLETO)
--pid-file <ARCHIVO>
nombre del archivo al que escribir el ID del proceso
--stdio
para clientes remotos (AVANZADO)
--cmdserver <MODO>
para clientes remotos (AVANZADO)
-t,--templates <PLANTILLA>
plantillas web a utilizar
--style <ESTILO>
estilo de plantilla a utilizar
-6, --ipv6
usar IPv6 en lugar de IPv4
--certificate <ARCHIVO>
archivo de certificado SSL
--print-url
iniciar e imprimir solo la URL
-S, --subrepos
recursar en subrepositorios

[+] la opción marcada puede especificarse varias veces
