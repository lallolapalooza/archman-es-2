NOMBRE

hugo-new-content - Crear contenido nuevo

SINOPSIS

hugo new content [ruta] [banderas]

DESCRIPCIÓN

Crea un nuevo archivo de contenido y establece automáticamente la fecha y el título. Intentará adivinar qué tipo de archivo crear basándose en la ruta proporcionada.

También puedes especificar el tipo con -k TIPO.

Si se proporcionan arquetipos en tu tema o sitio, se utilizarán.

Asegúrate de ejecutar esto dentro del directorio raíz de tu sitio.

OPCIONES

-b, --baseURL="" hostname (y ruta) a la raíz, por ejemplo https://spf13.com/

--cacheDir="" ruta del sistema de archivos al directorio de caché

-c, --contentDir="" ruta del sistema de archivos al directorio de contenido

--editor="" editar el contenido nuevo con este editor, si se proporciona

-f, --force[=false] sobrescribir el archivo si ya existe

-h, --help[=false] ayuda para contenido

-k, --kind="" tipo de contenido a crear

--renderSegments=[] segmentos con nombre a renderizar (configurados en la configuración de segmentos)

-t, --theme=[] temas a usar (ubicados en /themes/NOMBRE_DEL_TEMA/)

OPCIONES HEREDADAS DE COMANDAS PADRE

--clock="" establece el reloj utilizado por Hugo, por ejemplo --clock 2021-11-06T22:30:00.00+09:00

--config="" archivo de configuración (por defecto es hugo.yaml|json|toml)

--configDir="config" directorio de configuración

-d, --destination="" ruta del sistema de archivos donde escribir los archivos

-e, --environment="" entorno de compilación

--ignoreVendorPaths="" ignora cualquier _vendor para rutas de módulos que coincidan con el patrón Glob dado

--logLevel="" nivel de registro (debug|info|warn|error)

--noBuildLock[=false] no crear el archivo .hugo_build.lock

--quiet[=false] compilar en modo silencioso

-M, --renderToMemory[=false] renderizar a memoria (principalmente útil al ejecutar el servidor)

-s, --source="" ruta del sistema de archivos donde leer archivos relativamente desde

--themesDir="" ruta del sistema de archivos al directorio de temas
