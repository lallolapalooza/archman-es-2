subrutina chpmv (character uplo, integer n, complex alpha, complex, dimension(*) ap, complex, dimension(*) x, integer incx, complex beta, complex, dimension(*) y, integer

incy)

CHPM

V

Propósito

: 
!>
!> CHPMV  realiza la operación matriz-vector
!>
!>    y := alpha*A*x + beta*y,
!>
!> donde alpha y beta son escalares, x y y son vectores de n elementos y
!> A es una matriz hermítica de n por n, proporcionada en forma empaquetada.
!
>

Parámetro

s
UPLO 
!>          UPLO es CHARACTER*1
!>           En la entrada, UPLO especifica si se proporciona la parte
!>           triangular superior o inferior de la matriz A en el array
!>           empaquetado AP de la siguiente manera:
!>
!>              UPLO = 'U' o 'u'   Se proporciona la parte triangular
!>                                 superior de A en AP.
!>
!>              UPLO = 'L' o 'l'   Se proporciona la parte triangular
!>                                 inferior de A en AP.
!
>

N 
!>          N es INTEGER
!>           En la entrada, N especifica el orden de la matriz A.
!>           N debe ser al menos cero.
!
>

ALPH

A 
!>          ALPHA es COMPLEX
!>           En la entrada, ALPHA especifica el escalar alpha.
!
>

A

P 
!>          AP es un array COMPLEX, dimensión al menos
!>           ( ( n*( n + 1 ) )/2 ).
!>           Antes de la entrada con UPLO = 'U' o 'u', el array AP debe
!>           contener la parte triangular superior de la matriz hermítica
!>           empaquetada secuencialmente, columna por columna, de modo que AP( 1 )
!>           contiene a( 1, 1 ), AP( 2 ) y AP( 3 ) contienen a( 1, 2 )
!>           y a( 2, 2 ) respectivamente, y así sucesivamente.
!>           Antes de la entrada con UPLO = 'L' o 'l', el array AP debe
!>           contener la parte triangular inferior de la matriz hermítica
!>           empaquetada secuencialmente, columna por columna, de modo que AP( 1 )
!>           contiene a( 1, 1 ), AP( 2 ) y AP( 3 ) contienen a( 2, 1 )
!>           y a( 3, 1 ) respectivamente, y así sucesivamente.
!>           Nótese que las partes imaginarias de los elementos diagonales no
!>           necesitan establecerse y se asume que son cero.
!
>

X 
!>          X es un array COMPLEX, dimensión al menos
!>           ( 1 + ( n - 1 )*abs( INCX ) ).
!>           Antes de la entrada, el array X incrementado debe contener el
!>           vector x de n elementos.
!
>

INC

X 
!>          INCX es INTEGER
!>           En la entrada, INCX especifica el incremento para los elementos de
!>           X. INCX no debe ser cero.
!
>

BET

A 
!>          BETA es COMPLEX
!>           En la entrada, BETA especifica el escalar beta. Cuando BETA se
!>           proporciona como cero, entonces Y no necesita establecerse en la entrada.
!
>

Y 
!>          Y es un array COMPLEX, dimensión al menos
!>           ( 1 + ( n - 1 )*abs( INCY ) ).
!>           Antes de la entrada, el array Y incrementado debe contener el
!>           vector y de n elementos. En la salida, Y es sobrescrito por el
!>           vector y actualizado.
!
>

INC

Y 
!>          INCY es INTEGER
!>           En la entrada, INCY especifica el incremento para los elementos de
!>           Y. INCY no debe ser cero.
!
>

Auto
