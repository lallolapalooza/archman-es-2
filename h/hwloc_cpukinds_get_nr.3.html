frecuencias diferentes.

Esta

API expone las PUs idénticas en conjuntos llamados tipos de CPU. Cada PU de la topología solo puede estar en un solo tipo. El número de tipos se puede obtener con hwloc_cpukinds_get_nr(). Si la plataforma es

homogénea,

puede haber un solo tipo con todas las PUs. Si la plataforma o el sistema operativo no expone ninguna información sobre los núcleos de la CPU, puede que no haya ningún tipo. El índice del tipo que describe un conjunto de CPU dado (si existe, y no parcialmente) se

puede

obtener con hwloc_cpukinds_get_by_cpuset(). A partir del índice de un tipo, es posible recuperar información con hwloc_cpukinds_get_info

(): un valor

de eficiencia abstracto, y un array de atributos de información (por ejemplo, 'CoreType' y 'FrequencyMaxMHz', ver Tipos de CPU). Un valor de eficiencia más alto significa un rendimiento intrínseco mayor (y posiblemente una menor eficienci

a de

rendimiento/energía). Los tipos con valores de eficiencia más bajos se clasifican primero: Pasar 0 como kind_index a hwloc_cpukinds_get_info() devolverá información sobre el tipo de CPU con menor rendimiento pero mayor eficiencia energética. Valores de kind_index más altos devolverán más bien información sobre núcleos de alto rendimiento que consumen mucha energía. Cuando están disponibles, los valores de eficiencia se recopilan del sistema

operativo.

Si es así, cpukind_efficiency se establece en el array hwloc_topology_discovery_support [[51]]. Actualmente esto está disponible en Windows 10, Mac OS X (Darwin) y en algunas plataformas Linux donde la 'capacity' del núcleo se expone en sysfs. Si el sistema operativo no expone las eficiencias de los núcleos de

forma

nativa, hwloc intenta calcular las eficiencias comparando los tipos de CPU usando las frecuencias (en ARM), o los tipos de núcleo y las frecuencias (en otras arquitecturas). La variable de entorno HWLOC_CPUKINDS_RANKING puede usarse para cambiar esta heurística, ver Variables de entorno. Si hwloc no logra clasificar ningún tipo, por ejemplo po

rque el

sistema operativo no expone las eficiencias y las frecuencias de los núcleos, todos los tipos tendrán una eficiencia desconocida (-1 ), y no estarán indexados/ordenados de ningunamanera específica
