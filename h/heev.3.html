Documentación de la Función

subrutina cheev (character jobz, character uplo, integer n, complex, dimension( lda, * ) a, integer lda, real, dimension( * ) w, complex, dimension( * ) work, integer lwork, real, dimension( * ) rwork, integer info)

CHEEV calcula los eigenvalores y, opcionalmente, los eigenvectores izquierdos y/o derechos para matrices HE

Propósito:

!>
!> CHEEV calcula todos los eigenvalores y, opcionalmente, los eigenvectores de una
!> matriz hermitiana compleja A.
!>

Parámetros

JOBZ 
!>          JOBZ es CHARACTER*1
!>          = 'N':  Calcula solo los eigenvalores;
!>          = 'V':  Calcula los eigenvalores y los eigenvectores.
!>

UPLO

!>          UPLO es CHARACTER*1
!>          = 'U':  Se almacena el triángulo superior de A;
!>          = 'L':  Se almacena el triángulo inferior de A.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

A

!>          A es un array COMPLEX, dimensión (LDA, N)
!>          Al entrar, la matriz hermitiana A.  Si UPLO = 'U', la
!>          parte triangular superior principal N-por-N de A contiene la
!>          parte triangular superior de la matriz A.  Si UPLO = 'L',
!>          la parte triangular inferior principal N-por-N de A contiene
!>          la parte triangular inferior de la matriz A.
!>          Al salir, si JOBZ = 'V', entonces si INFO = 0, A contiene los
!>          eigenvectores ortonormales de la matriz A.
!>          Si JOBZ = 'N', entonces al salir el triángulo inferior (si UPLO='L')
!>          o el triángulo superior (si UPLO='U') de A, incluyendo la
!>          diagonal, es destruido.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

W

!>          W es un array REAL, dimensión (N)
!>          Si INFO = 0, los eigenvalores en orden ascendente.
!>

WORK

!>          WORK es un array COMPLEX, dimensión (MAX(1,LWORK))
!>          Al salir, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La longitud del array WORK.  LWORK >= max(1,2*N-1).
!>          Para una eficiencia óptima, LWORK >= (NB+1)*N,
!>          donde NB es el tamaño de bloque para CHETRD devuelto por ILAENV.
!>
!>          Si LWORK = -1, se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo del array WORK, devuelve
!>          este valor como la primera entrada del array WORK, y no se emite
!>          ningún mensaje de error relacionado con LWORK por XERBLA.
!>

RWORK

!>          RWORK es un array REAL, dimensión (max(1, 3*N-2))
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>          > 0:  si INFO = i, el algoritmo falló en converger; i
!>                elementos fuera de la diagonal de una forma tridiagonal
!>                intermedia no convergieron a cero.
!>
