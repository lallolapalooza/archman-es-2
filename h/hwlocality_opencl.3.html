DESCRIPCIÓN DETALLADA

Esta interfaz ofrece formas de obtener información de topología sobre dispositivos OpenCL.

Actualmente, solo las implementaciones OpenCL de AMD y NVIDIA ofrecen información útil de localidad sobre sus dispositivos.

DOCUMENTACIÓN DE LA FUNCIÓN

Obtiene el conjunto de CPU de procesadores que están físicamente cerca del dispositivo OpenCL dispositivo. Almacena en conjunto el conjunto de CPU que describe la localidad del dispositivo OpenCL dispositivo.

La topología topología y el dispositivo dispositivo deben corresponder a la máquina local. La detección de dispositivos de E/S y el componente OpenCL no son necesarios en la topología.

La función solo devuelve la localidad del dispositivo. Si se necesita más información sobre el dispositivo, se deben usar objetos del SO en su lugar, consulte hwloc_opencl_get_device_osdev() y hwloc_opencl_get_device_osdev_by_index().

Actualmente, esta función solo se implementa de manera significativa para Linux con la implementación OpenCL de AMD o NVIDIA; otros sistemas simplemente obtendrán un cpuset completo.

Devuelve

0 si tiene éxito.

-1 si ocurre un error, por ejemplo, si no se pudo encontrar el dispositivo.

hwloc_obj_t hwloc_opencl_get_device_osdev (hwloc_topology_t topología, cl_device_id dispositivo) [inline]

Obtiene el objeto de dispositivo del SO hwloc correspondiente al dispositivo OpenCL dispositivoX.

Devuelve

El objeto de dispositivo del SO hwloc correspondiente al dispositivo OpenCL dado dispositivo.

NULL si no se pudo encontrar ninguno, por ejemplo, si los atributos OpenCL requeridos no están disponibles.

Actualmente, esta función solo funciona en dispositivos OpenCL de AMD y NVIDIA que admiten extensiones OpenCL relevantes. Se debe preferir hwloc_opencl_get_device_osdev_by_index() siempre que sea posible, es decir, cuando se conozcan el índice de plataforma y el índice de dispositivo.

La topología topología y el dispositivo dispositivo deben corresponder a la máquina local. La detección de dispositivos de E/S y el componente OpenCL deben estar habilitados en la topología. De lo contrario, la localidad del objeto aún se puede encontrar utilizando hwloc_opencl_get_device_cpuset().

Nota

Esta función no puede funcionar si los dispositivos PCI están filtrados.

El objeto de dispositivo PCI correspondiente se puede encontrar buscando el puntero padre del resultado (a menos que los dispositivos PCI estén filtrados).

hwloc_obj_t hwloc_opencl_get_device_osdev_by_index (hwloc_topology_t topología, unsigned indice_plataforma, unsigned indice_dispositivo) [inline]

Obtiene el objeto de dispositivo del SO hwloc correspondiente al dispositivo OpenCL para los índices dados.

Devuelve

El objeto de dispositivo del SO hwloc que describe el dispositivo OpenCL cuyo índice de plataforma es indice_plataforma, y cuyo índice de dispositivo dentro de esta plataforma es indice_dispositivo.

NULL si no hay ninguno.

La topología topología no tiene necesariamente que corresponder a la máquina actual. Por ejemplo, la topología puede ser una importación XML de un host remoto. La detección de dispositivos de E/S y el componente OpenCL deben estar habilitados en la topología.

Nota

El objeto de dispositivo PCI correspondiente se puede obtener buscando el objeto padre del dispositivo del SO (a menos que los dispositivos PCI estén filtrados).

int hwloc_opencl_get_device_pci_busid (cl_device_id dispositivo, unsigned * dominio, unsigned * bus, unsigned * disp, unsigned * func) [inline]

Devuelve los IDs de dominio, bus y dispositivo del dispositivo OpenCL dispositivo. El dispositivo dispositivo debe corresponder a la máquina local.

Devuelve

0 si tiene éxito.

-1 si ocurre un error, por ejemplo, si no se pudo encontrar la información del dispositivo.
