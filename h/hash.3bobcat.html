FBB::Hash(3bobcat) Contenedores de hash de claves FBB::Hash(3bobcat)

NOMBRE

FBB::Hash - Varias clases de mapeo que utilizan hash

SINOPSIS

#include <bobcat/hash>

DESCRIPCIÓN

El grupo de clases de plantillas FBB:Hash ofrece mapeo basado en hash. Hay varias variantes disponibles, todas basadas en las funcionalidades que ofrece unordered_map.

El mapa hash que se ofrece en el contenedor unordered_map tiene una interfaz de construcción bastante compleja, y Hash es un intento de simplificar esta parte de su interfaz. En la práctica, el hash utiliza una clave textual, que puede basarse en std::string o char *, y las claves pueden usarse de forma sensible o insensible a mayúsculas y minúsculas. Hash simplemente requiere que sus usuarios especifiquen el tipo de valor del mapa, mientras que la clave puede ser char const * o std::string, utilizada de forma sensible o insensible a mayúsculas y minúsculas.

ESPACIO DE NOMBRES

FBB
Todos los constructores, miembros, operadores y manipuladores mencionados en esta página del manual están definidos en el espacio de nombres FBB.

HEREDA DE

std::unordered_map, utilizando varias instanciaciones.

TIPO

Todas las variantes definen value_type como el value_type correspondiente de unordered_map. En la práctica, un value_type define un std::pair<Key, Value>, donde Key representa el tipo de clave del hash y Value representa el tipo de valor del hash.

CONSTRUCTORES

Hay variantes de los contenedores FBB::Hash disponibles para claves char const * o std::string, utilizadas de forma sensible o insensible a mayúsculas y minúsculas.

Todas las variantes admiten construcción por defecto y por movimiento (así como asignación por movimiento), admiten construcción a partir de listas de inicialización y admiten construcción a partir de iteradores que definen un rango semiabierto de valores value_type.

Las siguientes variantes están disponibles (mostrando sus constructores por defecto). Value se refiere al tipo de valor almacenado en la tabla hash.

o
HashCharPtr<Value>():
esta tabla hash utiliza claves sensibles a mayúsculas y minúsculas de char const *;
o
HashCharCasePtr<Value>():
esta tabla hash utiliza claves char const * insensibles a mayúsculas y minúsculas;
o
HashString<Value>():
esta tabla hash utiliza claves sensibles a mayúsculas y minúsculas de std::string;
o
HashStringCase<Value>():
esta tabla hash utiliza claves std::string insensibles a mayúsculas y minúsculas;

OPERADOR SOBRECARGADO

Además del operador de índice heredado de unordered_map, los operadores de asignación por copia y por movimiento sobrecargados están disponibles para todos los contenedores Hash.

FUNCIONES MIEMBRO

Todos los miembros del contenedor unordered_map están disponibles, ya que Hash hereda de esta clase de plantilla.

EJEMPLO

    #include <iostream>
    #include <bobcat/hash>
    using namespace std;
    using namespace FBB;
    pair<char const *, size_t> ap[] =
    {
        pair<char const *, size_t>("one", 1),
        pair<char const *, size_t>("two", 2),
    };
    int main()
    {
        HashCharPtr<size_t> hcp;
        HashCharPtr<size_t> hcp2(ap, ap + 2);
        HashCharPtr<size_t> hcp3(hcp2);
        hcp = hcp2;
        cout << hcp2["one"] << endl;
    }
