NOMBRE

hugo-gen-chromastyles - Genera una hoja de estilo CSS para el resaltador de código Chroma

SINOPSIS

hugo gen chromastyles [flags] [args]

DESCRIPCIÓN

Genera una hoja de estilo CSS para el resaltador de código Chroma para un estilo dado. Esta hoja de estilo es necesaria si markup.highlight.noClasses está deshabilitado en la configuración.

Consulta https://xyproto.github.io/splash/docs/all.html para obtener una vista previa de los estilos disponibles

OPCIONES

-h, --help[=false] ayuda para chromastyles

--highlightStyle="" colores de primer plano y de fondo para las líneas resaltadas, por ejemplo, --highlightStyle "#fff000 bg:#000fff"

--lineNumbersInlineStyle="" colores de primer plano y de fondo para los números de línea en línea, por ejemplo, --lineNumbersInlineStyle "#fff000 bg:#000fff"

--lineNumbersTableStyle="" colores de primer plano y de fondo para los números de línea de tabla, por ejemplo, --lineNumbersTableStyle "#fff000 bg:#000fff"

--omitClassComments[=false] omitir prefijos de comentarios de clase CSS en el CSS generado

--omitEmpty[=false] omitir reglas CSS vacías (obsoleto, ya no es necesario)

--style="friendly" estilo del resaltador (ver https://xyproto.github.io/splash/docs/)

OPCIONES HEREDADAS DE COMANDOS PADRE

--clock="" establecer el reloj utilizado por Hugo, por ejemplo, --clock 2021-11-06T22:30:00.00+09:00

--config="" archivo de configuración (por defecto es hugo.yaml|json|toml)

--configDir="config" directorio de configuración

-d, --destination="" ruta del sistema de archivos donde escribir los archivos

-e, --environment="" entorno de compilación

--ignoreVendorPaths="" ignora cualquier ruta de módulo _vendor que coincida con el patrón Glob dado

--logLevel="" nivel de registro (debug|info|warn|error)

--noBuildLock[=false] no crear el archivo .hugo_build.lock

--quiet[=false] compilar en modo silencioso

-M, --renderToMemory[=false] renderizar a memoria (principalmente útil al ejecutar el servidor)

-s, --source="" ruta del sistema de archivos desde donde leer los archivos de forma relativa

--themesDir="" ruta del sistema de archivos del directorio de temas
