helpers.conf(5) Archivo de configuración de Slurm helpers.conf(5)

NOMBRE

helpers.conf - Archivo de configuración de Slurm para el plugin de características de helpers.

DESCRIPCIÓN

helpers.conf es un archivo ASCII que define los parámetros utilizados por el plugin de características de nodos "helpers" de Slurm. El archivo siempre se encontrará en el mismo directorio que slurm.conf.

PARÁMETROS

Los nombres de los parámetros no distinguen entre mayúsculas y minúsculas. Cualquier texto que siga a un carácter "#" en el archivo de configuración se trata como un comentario hasta el final de esa línea. El tamaño de cada línea en el archivo está limitado a 1024 caracteres. Los cambios en el archivo de configuración entran en vigor tras la reinicialización de los demonios de Slurm, la recepción de la señal SIGHUP por parte del demonio, o la ejecución del comando "scontrol reconfigure", a menos que se indique lo contrario.

AllowUserBoot=<usuario1>[,<usuario2>...]
Controla qué usuarios tienen permitido cambiar las características con este plugin. Por defecto, se permite a TODOS los usuarios.
BootTime=<tiempo>
Controla cuánto tiempo tiene un nodo para reiniciarse antes de que ocurra un tiempo de espera y se suponga un fallo. El valor por defecto es 300 segundos.
ExecTime=<tiempo>
Controla cuánto tiempo puede ejecutarse el programa Helper antes de que ocurra un tiempo de espera y se suponga un fallo. El valor por defecto es 10 segundos.
Feature=<cadena> Helper=<archivo> <Flags=<flags>
Define la(s) Característica(s) y un programa Helper correspondiente que informa y modifica el estado de la(s) característica(s). Se permiten múltiples entradas de Feature, una por cada característica y programa/script correspondiente. También se puede definir una lista separada por comas de características para un único Helper.

Las características se pueden definir por nodo creando un archivo único para cada nodo. El controlador debe tener un helpers.conf que enumere todas las características de helper posibles.

Actualmente se soportan las siguientes flags:
rebootless
Indica que la característica no requiere un reinicio del nodo. Si se establece, la activación de la característica no ejecutará el RebootProgram, el nodo simplemente registrará que el nodo se reinició a slurmctld sin un reinicio real.

Se puede crear un único helpers.conf que defina características para nodos específicos anteponiendo NodeName=<lista_nodos> al principio de la línea Feature. Una Feature no antepuesta con NodeName se aplicará a todos los nodos.

# helpers.conf
NodeName=n1_[1-10] Feature=a1,a2 Helper=/ruta/helper.sh
NodeName=n2_[1-10] Feature=b1,b2 Helper=/ruta/helper.sh
Feature=c1,c2 Helper=/ruta/helper.sh

Si una característica se define en helpers.conf y no se define en un nodo específico en helpers.conf, pero se define para ese nodo en slurm.conf, esa característica se trata como una característica modificable/rebootable por el controlador. Por ejemplo, si la característica fa se define en el nodo nodo1 en slurm.conf pero solo se lista en nodo2 en helpers.conf, la característica aún activará el reinicio del nodo si no está activa.

El Helper es un programa o script arbitrario que informa y modifica el conjunto de características en un nodo dado. Los helpers son específicos del sitio y no se incluyen con Slurm. Las características modificadas por los helpers requieren un reinicio del nodo utilizando el RebootProgram. El programa/script Helper debe ser ejecutable por el SlurmdUser. El mismo programa/script puede usarse para controlar múltiples características. slurmd ejecutará el Helper de una de las siguientes dos maneras:

1. Ejecutar sin argumentos para consultar el estado de las características del nodo. Debe devolver un código de salida de 0 e imprimir un superconjunto de las características esperadas por Slurm, o no imprimir nada. De lo contrario, el nodo será drenado.

2. Ejecutar con un único argumento de la característica a activar en el reinicio del nodo. En el caso de múltiples características, el script se llama varias veces.

MutuallyExclusive=<lista_caracteristicas>
Evita que ciertas características se especifiquen para el mismo trabajo. Puede haber múltiples entradas de MutuallyExclusive, cada una con su propia lista de características que son mutuamente exclusivas entre sí (es decir, las características en una línea solo son mutuamente exclusivas con otras características en la misma línea, pero no mutuamente exclusivas con características en otras líneas).

EJEMPLO

/etc/slurm/slurm.conf:
Para habilitar el plugin de helpers, slurm.conf debe tener la siguiente entrada:
NodeFeaturesPlugins=node_features/helpers
/etc/slurm/helpers.conf:
El siguiente ejemplo de helpers.conf demuestra que múltiples características pueden usar el mismo script Helper y que puede haber múltiples listas de características que son mutuamente exclusivas. Por ejemplo, con la siguiente configuración, un trabajo no puede solicitar "nps1" y "nps2", ni puede solicitar "mig=on" y "mig=off". Sin embargo, podría solicitar "nps1" y "mig=on" al mismo tiempo.
# helpers.conf
Feature=nps1,nps2,nps4 Helper=/usr/local/bin/nps
Feature=mig=on Helper=/usr/local/bin/mig
Feature=mig=off Helper=/usr/local/bin/mig
MutuallyExclusive=nps1,nps2,nps4
MutuallyExclusive=mig=on,mig=off
ExecTime=60
BootTime=60
AllowUserBoot=user1,user2
Script Helper de Ejemplo:
Los scripts Helper necesitan tener el bit ejecutable establecido y deben existir en los nodos, donde serán ejecutados por slurmd. Cuando el script helper es llamado sin argumentos, debe devolver las características que están actualmente activas para el nodo, con múltiples características separadas por nueva línea. Cuando el script helper es llamado con una característica a habilitar para el nodo, debe configurar el nodo de manera que la característica especificada se habilite cuando el nodo se reinicie. Este script de ejemplo simplemente escribe el nombre de la característica activa en un archivo, pero los scripts de producción probablemente serán más complejos.
#!/bin/bash
if [ "$1" = "nps1" ]; then
    echo "$1" > /etc/slurm/feature
elif [ "$1" = "nps2" ]; then
    echo "$1" > /etc/slurm/feature
elif [ "$1" = "nps4" ]; then
    echo "$1" > /etc/slurm/feature
else
    cat /etc/slurm/feature
fi
