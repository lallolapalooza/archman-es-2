Descripción Detallada

Hwloc usa mapas de bits para representar dos tipos distintos de conjuntos de objetos: conjuntos de CPU (hwloc_cpuset_t) y conjuntos de nodos NUMA (hwloc_nodeset_t). Estos tipos son ambos typedefs de un tipo de soporte común (hwloc_bitmap_t), y por lo tanto todas las funciones de mapa de bits de hwloc son aplicables tanto a hwloc_cpuset_t como a hwloc_nodeset_t (ver La API de mapas de bits).

La razón para tener dos tipos diferentes es que, aunque las acciones que uno quiere realizar sobre estos tipos son las mismas (por ejemplo, habilitar y deshabilitar elementos individuales en el conjunto/máscara), se usan en contextos muy diferentes: uno para especificar qué procesadores usar y otro para especificar qué nodos NUMA usar. Por lo tanto, la diferencia de nombres es realmente solo para reflejar la intención de dónde se usa el tipo.

Documentación de tipo definido

typedef hwloc_const_bitmap_t hwloc_const_cpuset_t

Un hwloc_cpuset_t no modificable.

typedef hwloc_const_bitmap_t hwloc_const_nodeset_t

Un hwloc_nodeset_t no modificable.

typedef hwloc_bitmap_t hwloc_cpuset_t

Un conjunto de CPU es un mapa de bits cuyos bits están establecidos de acuerdo con los índices de SO físicos de la CPU. Puede ser consultado y modificado con la API de mapas de bits como cualquier hwloc_bitmap_t (ver hwloc/bitmap.h).

Cada bit puede convertirse en un objeto PU usando hwloc_get_pu_obj_by_os_index().

typedef hwloc_bitmap_t hwloc_nodeset_t

Un conjunto de nodos es un mapa de bits cuyos bits están establecidos de acuerdo con los índices de SO físicos de los nodos de memoria NUMA. Puede ser consultado y modificado con la API de mapas de bits como cualquier hwloc_bitmap_t (ver hwloc/bitmap.h). Cada bit puede convertirse en un objeto de nodo NUMA usando hwloc_get_numanode_obj_by_os_index().

Al vincular memoria en un sistema sin ningún nodo NUMA, el único banco de memoria principal se considera como nodo NUMA #0.

Ver también Conversión entre conjuntos de CPU y conjuntos de nodos.
