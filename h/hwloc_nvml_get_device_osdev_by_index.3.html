Descripción Detallada

Esta interfaz ofrece formas de recuperar información de topología sobre dispositivos administrados por la Biblioteca de Gestión NVIDIA (NVML).

Documentación de la Función

int hwloc_nvml_get_device_cpuset (hwloc_topology_t topology, nvmlDevice_t device, hwloc_cpuset_t set) [inline]

Obtener el conjunto de CPU de los procesadores que están físicamente cerca del dispositivo NVML device. Almacenar en set el conjunto de CPU que describe la localidad del dispositivo NVML device.

La topología topology y el dispositivo device deben coincidir con la máquina local. La detección de dispositivos de E/S y el componente NVML no son necesarios en la topología.

La función solo devuelve la localidad del dispositivo. Si se necesita más información sobre el dispositivo, se deben usar objetos del sistema operativo en su lugar, ver hwloc_nvml_get_device_osdev() y hwloc_nvml_get_device_osdev_by_index().

Esta función actualmente solo está implementada de manera significativa para Linux; otros sistemas simplemente obtendrán un conjunto de CPU completo.

Devuelve

0 si tiene éxito.

-1 si ocurre un error, por ejemplo, si no se pudo encontrar información del dispositivo.

hwloc_obj_t hwloc_nvml_get_device_osdev (hwloc_topology_t topology, nvmlDevice_t device) [inline]

Obtener el objeto de dispositivo OS de hwloc que corresponde al dispositivo NVML device.

Devuelve

El objeto de dispositivo OS de hwloc que describe el dispositivo NVML dado device.

NULL si no se pudo encontrar ninguno.

La topología topology y el dispositivo device deben coincidir con la máquina local. La detección de dispositivos de E/S y el componente NVML deben estar habilitados en la topología. Si no, la localidad del objeto aún se puede encontrar usando hwloc_nvml_get_device_cpuset().

Nota

El objeto de dispositivo PCI correspondiente puede encontrarse buscando el puntero padre del resultado (a menos que los dispositivos PCI estén filtrados).

hwloc_obj_t hwloc_nvml_get_device_osdev_by_index (hwloc_topology_t topology, unsigned idx) [inline]

Obtener el objeto de dispositivo OS de hwloc que corresponde al dispositivo NVML cuyo índice es idx.

Devuelve

El objeto de dispositivo OS de hwloc que describe el dispositivo NVML cuyo índice es idx.

NULL si no se pudo encontrar ninguno.

La topología topology no tiene necesariamente que coincidir con la máquina actual. Por ejemplo, la topología puede ser una importación XML de un host remoto. La detección de dispositivos de E/S y el componente NVML deben estar habilitados en la topología.

Nota

El objeto de dispositivo PCI correspondiente se puede obtener buscando el objeto padre del dispositivo OS (a menos que los dispositivos PCI estén filtrados).
