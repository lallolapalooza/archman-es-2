int hwloc_distances_get_by_name (hwloc_topology_t topology, const char * name, unsigned * nr, struct hwloc_distances_s ** distances, unsigned long flags)

Recupera una matriz de distancias con el nombre dado. Usualmente solo una estructura de distancias puede coincidir con un nombre dado.

El nombre de la estructura más común es 'NUMALatency'. Otros incluyen 'XGMIBandwidth', 'XGMIHops', 'XeLinkBandwidth' y 'NVLinkBandwidth'.

Devuelve

0 en caso de éxito, -1 en caso de error.

const char * hwloc_distances_get_name (hwloc_topology_t topology, struct hwloc_distances_s * distances)

Obtiene una descripción de lo que contiene una estructura de distancias. Por ejemplo, 'NUMALatency' para las distancias NUMA proporcionadas por el hardware (ACPI SLIT), o NULL si es desconocido.

void hwloc_distances_release (hwloc_topology_t topology, struct hwloc_distances_s * distances)

Libera una estructura de matriz de distancias previamente devuelta por hwloc_distances_get().

Nota

int hwloc_distances_transform (hwloc_topology_t topology, struct hwloc_distances_s * distances, enum hwloc_distances_transform_e transform, void * transform_attr, unsigned long flags)

Aplica una transformación a una estructura de distancias. Modifica una estructura de distancias que fue obtenida previamente con hwloc_distances_get() o una de sus variantes.

Esto modifica la copia local de las estructuras de distancias pero no modifica la información de distancias almacenada dentro de la topología (obtenida por otra llamada a hwloc_distances_get() o exportada a XML). Para hacer esto, se debe añadir una nueva estructura de distancias con el mismo nombre, tipo, objetos y valores (ver Añadir distancias entre objetos) y luego eliminar la antigua con hwloc_distances_release_remove().

transform debe ser una de las transformaciones listadas en hwloc_distances_transform_e.

Estas transformaciones pueden modificar el contenido de los arreglos objs o values .

transform_attr debe ser NULL por ahora.

flags debe ser 0 por ahora.

Devuelve

0 en caso de éxito, -1 en caso de error, por ejemplo si los flags son inválidos.

Nota

Los objetos en el arreglo objs de distancias pueden ser modificados directamente en el lugar sin usar hwloc_distances_transform(). Se puede usar hwloc_get_obj_with_same_locality() para convertir fácilmente entre objetos similares de diferentes tipos.
