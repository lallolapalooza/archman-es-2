HG(STATUS) HG(STATUS)

NOMBRE

hg status - mostrar archivos modificados en el directorio de trabajo

SINOPSIS

hg status [OPCIÓN]... [ARCHIVO]...

DESCRIPCIÓN

Muestra el estado de los archivos en el repositorio. Si se dan nombres, solo se mostrarán los archivos que coincidan. Los archivos que están limpios, ignorados o que son origen de una operación de copia/movimiento, no se listan a menos que se especifiquen las opciones -c/--clean, -i/--ignored, -C/--copies o -A/--all. A menos que se den las opciones descritas con "mostrar solo...", se utilizan las opciones -mardu.

La opción -q/--quiet oculta los archivos no rastreados (desconocidos e ignorados) a menos que se soliciten explícitamente con -u/--unknown o -i/--ignored.

Nota
hg status puede parecer que no coincide con diff si han cambiado los permisos o ha ocurrido una fusión. El formato diff estándar no informa de cambios de permisos y diff solo informa de cambios relativos a un padre de fusión.

Si se da una revisión, se usa como revisión base. Si se dan dos revisiones, se muestran las diferencias entre ellas. La opción --change también puede usarse como atajo para listar los archivos modificados de una revisión a partir de su primer padre.

Los códigos utilizados para mostrar el estado de los archivos son:

M = modificado
A = añadido
R = eliminado
C = limpio
! = faltante (eliminado por comando no-hg, pero todavía rastreado)
? = no rastreado
I = ignorado
  = origen del archivo anterior (con --copies)

La opción -t/--terse abrevia la salida mostrando solo el nombre del directorio si todos los archivos en él comparten el mismo estado. La opción toma un argumento que indica los estados a abreviar: 'm' para 'modificado', 'a' para 'añadido', 'r' para 'eliminado', 'd' para 'borrado', 'u' para 'desconocido', 'i' para 'ignorado' y 'c' para limpio.

Solo abrevia los estados que se pasan. Tenga en cuenta que los archivos limpios e ignorados no se muestran con '--terse ic' a menos que también se utilicen las opciones -c/--clean e -i/--ignored.

La opción -v/--verbose muestra información cuando el repositorio está en un estado de fusión incompleta, archivado, rebase, etc. Puede tener este comportamiento activado por defecto habilitando la opción commands.status.verbose.

Puede omitir la visualización de algunos de estos estados configurando commands.status.skipstates a uno o más de: 'bisect', 'graft', 'histedit', 'merge', 'rebase', o 'unshelve'.

Plantilla:

Las siguientes palabras clave son compatibles además de las palabras clave y funciones comunes de plantillas. Ver también hg help templates.

ruta
Cadena. Ruta del archivo en el repositorio y de forma absoluta.
origen
Cadena. Ruta del archivo en el repositorio y de forma absoluta de donde proviene. Disponible si se especifica --copies.
estado
Cadena. Carácter que denota el estado del archivo.

Ejemplos:

  • mostrar cambios en el directorio de trabajo en relación con un changeset: 
    hg status --rev 9353
  • mostrar cambios en el directorio de trabajo en relación con el directorio actual (ver hg help patterns para más información): 
    hg status re:
  • mostrar todos los cambios, incluidas las copias, en un changeset existente: 
    hg status --copies --change 9353
  • obtener una lista de archivos añadidos separados por NUL, adecuada para xargs: 
    hg status -an0
  • mostrar más información sobre el estado del repositorio, abreviando rutas añadidas, eliminadas, modificadas, borradas y no rastreadas: 
    hg status -v -t mardu

    Devuelve 0 si tiene éxito.

OPCIONES

-A, --all
mostrar estado de todos los archivos
-m, --modified
mostrar solo archivos modificados
-a, --added
mostrar solo archivos añadidos
-r, --removed
mostrar solo archivos eliminados
-d, --deleted
mostrar solo archivos faltantes
-c, --clean
mostrar solo archivos sin cambios
-u, --unknown
mostrar solo archivos desconocidos (no rastreados)
-i, --ignored
mostrar solo archivos ignorados
-n, --no-status
ocultar prefijo de estado
-t,--terse <VALOR>
mostrar salida concisa (EXPERIMENTAL) (predeterminado: nada)
-C, --copies
mostrar origen de los archivos copiados (predeterminado: ui.statuscopies)
-0, --print0
terminar nombres de archivo con NUL, para usar con xargs
--rev <REV[+]>
mostrar diferencia con la revisión
--change <REV>
listar los archivos modificados de una revisión
-I,--include <PATRÓN[+]>
incluir nombres que coincidan con los patrones dados
-X,--exclude <PATRÓN[+]>
excluir nombres que coincidan con los patrones dados
-S, --subrepos
recorrer subrepositorios
-T,--template <PLANTILLA>
mostrar con plantilla

[+] la opción marcada puede especificarse varias veces
