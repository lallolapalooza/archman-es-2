Descripción detallada

Documentación del tipo de enumeración

enum hwloc_topology_export_xml_flags_e

Banderas para exportar topologías XML. Las banderas deben proporcionarse como un conjunto OR'ado para hwloc_topology_export_xml().

Enumerador

HWLOC_TOPOLOGY_EXPORT_XML_FLAG_V1
Exportar XML cargable por hwloc v1.x. Sin embargo, la exportación puede omitir algunos detalles sobre la topología.

Documentación de la función

int hwloc_export_obj_userdata (void * reserved, hwloc_topology_t topology, hwloc_obj_t obj, const char * name, const void * buffer, size_t length)

Exportar datos de usuario de algún objeto a XML. Esta función solo puede ser llamada desde dentro de la callback export() pasada a hwloc_topology_set_userdata_export_callback(). Puede ser invocada una o varias veces para exportar algunos datos de usuario a XML. El contenido del buffer de longitud length se almacena con el nombre opcional name.

Al importar este archivo XML, la callback import() (si está configurada) será llamada exactamente tantas veces como hwloc_export_obj_userdata() fue llamada durante la exportación. Recibirá los argumentos correspondientes de nombre, buffer y longitud.

reserved, topology y obj deben ser los primeros tres parámetros que se proporcionaron a la callback de exportación.

Solo se pueden exportar caracteres imprimibles a los atributos de cadena XML.

Si se exportan datos binarios, la aplicación debe primero codificar en caracteres imprimibles únicamente (o usar hwloc_export_obj_userdata_base64()). También debe tener en cuenta los problemas de portabilidad si la exportación puede ser reimportada en una arquitectura diferente.

Retorna

0 en caso de éxito.

-1 con errno establecido en EINVAL si se pasa un carácter no imprimible en name o buffer.

int hwloc_export_obj_userdata_base64 (void * reserved, hwloc_topology_t topology, hwloc_obj_t obj, const char * name, const void * buffer, size_t length)

Codificar y exportar algunos datos de usuario de objeto a XML. Esta función es similar a hwloc_export_obj_userdata() pero codifica el buffer de entrada en caracteres imprimibles antes de exportar. Al importar, la decodificación se realiza automáticamente antes de que los datos se proporcionen a la callback import() si existe alguna.

Esta función solo puede ser llamada desde dentro de la callback export() pasada a hwloc_topology_set_userdata_export_callback().

El nombre debe estar formado por caracteres imprimibles para la exportación a atributos de cadena XML.

La función no se encarga de los problemas de portabilidad si la exportación puede ser reimportada en una arquitectura diferente.

Retorna

0 en caso de éxito.

-1 con errno establecido en EINVAL si se pasa un carácter no imprimible en name.

void hwloc_free_xmlbuffer (hwloc_topology_t topology, char * xmlbuffer)

int hwloc_topology_export_xml (hwloc_topology_t topology, const char * xmlpath, unsigned long flags)

Exportar la topología en un archivo XML. Este archivo puede cargarse más tarde mediante hwloc_topology_set_xml().

Por defecto, se utiliza el formato de exportación más reciente, lo que significa que las versiones anteriores de hwloc (por ejemplo, v1.x) no podrán importarlo. Es posible exportar al formato XML específico de v1.x utilizando la bandera HWLOC_TOPOLOGY_EXPORT_XML_FLAG_V1, pero puede omitir algunos detalles sobre la topología. Si existe alguna posibilidad de que el archivo exportado sea importado posteriormente por un proceso que utiliza hwloc 1.x, se debe considerar detectarlo en tiempo de ejecución y utilizar el formato de exportación correspondiente.

flags es un conjunto OR'ado de hwloc_topology_export_xml_flags_e.

Retorna

0 en caso de éxito, o -1 en caso de error.

Nota

Vea también hwloc_topology_set_userdata_export_callback() para exportar datos de usuario específicos de la aplicación.

El puntero de datos de usuario específico de la topología se ignora al exportar a XML.

Solo se pueden exportar caracteres imprimibles a los atributos de cadena XML. Cualquier otro carácter, especialmente cualquier carácter no ASCII, se omitirá silenciosamente.

Si name es '-', la salida XML se envía al estándar de salida.
