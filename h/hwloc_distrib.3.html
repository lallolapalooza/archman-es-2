Documentación de la función

int hwloc_distrib (hwloc_topology_t topology, hwloc_obj_t * roots, unsigned n_roots, hwloc_cpuset_t * set, unsigned n, int until, unsigned long flags) [inline]

Distribuye n elementos sobre la topología bajo los raíces. El array set se llenará con n conjuntos de CPU distribuidos recursivamente de forma lineal sobre la topología bajo los objetos roots, hasta la profundidad until (que puede ser INT_MAX para distribuir hasta el nivel más fino).

n_roots suele ser 1 y roots solo contiene el objeto raíz de la topología para distribuir sobre toda la topología.

Esto es típicamente útil cuando una aplicación quiere distribuir n hilos sobre una máquina, dándole a cada uno la mayor cantidad de caché privada posible y manteniéndolos localmente en orden numérico.

El llamador puede querer llamar también a hwloc_bitmap_singlify() antes de enlazar un hilo para que no se mueva en absoluto.

flags debe ser 0 o un conjunto OR'ed de hwloc_distrib_flags_e.

Devuelve

0 si tiene éxito, -1 si hay un error.

Nota

En CPUs híbridas (o plataformas asimétricas), la distribución puede ser subóptima ya que el número de núcleos o PUs dentro de los paquetes o debajo de las cachés puede variar (el particionamiento recursivo de arriba hacia abajo ignora estos números hasta llegar a sus niveles). Por lo tanto, se recomienda distribuir solo dentro de un único dominio homogéneo. Por ejemplo, en una CPU con núcleos E eficientes energéticamente y núcleos P de alto rendimiento, se deberían distribuir por separado N tareas en núcleos E y M tareas en núcleos P en lugar de intentar distribuir directamente M+N tareas en todas las CPUs.

Esta función requiere que los objetos roots tengan un conjunto de CPU.
