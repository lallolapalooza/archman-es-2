HXINCL(1) Utilidades HTML-XML HXINCL(1)

NOMBRE

hxincl - expandir archivos HTML o XML incluidos

SINOPSIS

hxincl [ -x ] [ -f ] [ -s nombre=sustitución ] [ -s nombre=sustitución ]... [ -b base ] [ archivo-o-URL ]

hxincl -M objetivo [ -s nombre=sustitución ] [ -s nombre=sustitución ]... [ -b base ] [ -G ] [ archivo-o-URL ]

DESCRIPCIÓN

Sin -M, el comando hxincl copia un archivo HTML o XML a la salida estándar, buscando comentarios con una estructura determinada. Dicho comentario se reemplaza por el archivo cuyo nombre se da como atributo de la directiva. Por ejemplo:


...<!-- include "foo.html" -->...

será reemplazado por el contenido del archivo foo.html.

El comentario se reemplaza por


<!-- begin-include "foo.html" -->

antes del texto incluido y


<!-- end-include "foo.html" -->

después de él. Estos comentarios permiten ejecutar hxincl en el archivo resultante de nuevo para actualizar las inclusiones.

Se permiten comillas simples en lugar de comillas dobles. Y si el nombre del archivo no contiene espacios, las comillas también se pueden omitir.

Con -M, el comando hxincl genera una línea de dependencias adecuada para ser incluida en un Makefile. El objetivo es el objetivo de la regla del Makefile y hxincl listará después de los ':' todos los archivos que se incluyen, recursivamente. Por ejemplo, el resultado de


hxincl -M myfile.html inputfile

podría ser


myfile.html: foo.html bar.html

OPCIONES

Se admiten las siguientes opciones:

-x
Utiliza convenciones XML: los elementos vacíos se escriben con una barra al final: <IMG />.
-b base
Establece la URL base para resolver URLs relativas. Por defecto, el archivo dado como argumento es la URL base.
-f
Elimina los comentarios después de incluir los archivos. Esto significa que hxincl no se puede ejecutar posteriormente en el archivo resultante para actualizar las inclusiones. (Mnemotécnica: final o fijado).
-s nombre=sustitución
Incluye un archivo diferente al mencionado en la directiva. Si el comentario es 


<!-- include "nombre" -->

se incluye en su lugar el archivo sustitución. Y si el nombre del archivo en el comentario incluye una variable llamada nombre delimitada por %, por ejemplo,


<!-- include "xxx-%nombre%" -->

entonces %nombre% se reemplaza por sustitución y, por lo tanto, se incluye el archivo xxx-sustitución. La opción -s puede aparecer varias veces. Las variables delimitadas por % se expanden recursivamente, es decir, si el texto de sustitución contiene una variable, esa variable también se expande. Por ejemplo, si se dan las dos opciones -s nombre=%p1%.rrr y -s p1=subst, entonces "xxx-%nombre%" se expandirá a "xxx-subst.rrr".

-M objetivo
En lugar de generar el archivo de entrada con todas las inclusiones expandidas, genera solo la lista de todos los archivos que el archivo de entrada incluye, recursivamente, en forma de una regla adecuada para un Makefile. El objetivo se imprime como el objetivo de esa regla.
-G
Suprime los mensajes de error si no se encuentra un archivo para incluir. (Solo con -M.)

OPERANDOS

Se admite el siguiente operando:

archivo-o-URL
El nombre de un archivo HTML o XML o su URL. Si está ausente, se lee la entrada estándar en su lugar.

ESTADO DE SALIDA

Se devuelven los siguientes valores de salida:

0
Finalización exitosa.
> 0
Ocurrió un error en el análisis de uno de los archivos HTML o XML.

ENTORNO

Para utilizar un proxy para recuperar archivos remotos, establezca las variables de entorno http_proxy o ftp_proxy. Por ejemplo, http_proxy="http://localhost:8080/"

ERRORES CONOCIDOS

Asume UTF-8 como entrada. No expande entidades de caracteres. En su lugar, canalice la entrada a través de hxunent(1) y asc2xml(1) para convertirla a UTF-8.

Los archivos remotos (especificados con una URL) actualmente solo se admiten para HTTP. No se manejan archivos protegidos por contraseña ni archivos que dependan de "cookies" HTTP. (Puede usar herramientas como curl(1) o wget(1) para recuperar dichos archivos.)

VER TAMBIÉN
