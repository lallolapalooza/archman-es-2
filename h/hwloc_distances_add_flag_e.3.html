Descripción detallada

La forma habitual de añadir distancias es:

hwloc_distances_add_handle_t handle;
int err = -1;
handle = hwloc_distances_add_create(topology, "name", kind, 0);
if (handle) {
  err = hwloc_distances_add_values(topology, handle, nbobjs, objs, values, 0);
  if (!err)
    err = hwloc_distances_add_commit(topology, handle, flags);
}


Si err es 0 al final, entonces la adición fue exitosa.

Documentación de definiciones de tipos

typedef void* hwloc_distances_add_handle_t

Manejador para una nueva estructura de distancias durante su adición a la topología.

Documentación del tipo de enumeración

enum hwloc_distances_add_flag_e

Banderas para añadir nuevas distancias a una topología.

Enumerador

HWLOC_DISTANCES_ADD_FLAG_GROUP
Intenta agrupar objetos basándose en la información de distancias recién proporcionada. El agrupamiento solo se realiza cuando la estructura de distancias contiene latencias, y cuando todos los objetos son del mismo tipo.
HWLOC_DISTANCES_ADD_FLAG_GROUP_INACCURATE
Si se agrupa, considera los valores de distancia como inexactos y relaja las comparaciones durante los algoritmos de agrupamiento. La precisión real puede modificarse a través de la variable de entorno HWLOC_GROUPING_ACCURACY (ver Variables de entorno).

Documentación de funciones

int hwloc_distances_add_commit (hwloc_topology_t topology, hwloc_distances_add_handle_t handle, unsigned long flags)

Confirma una nueva estructura de distancias. Esta función finaliza la estructura de distancias y la inserta en la topología.

Parámetro handle fue previamente devuelto por hwloc_distances_add_create(). Luego, los objetos y valores fueron especificados con hwloc_distances_add_values().

flags configura el comportamiento de la función usando un conjunto opcional unión (OR) de hwloc_distances_add_flag_e. Puede usarse para solicitar el agrupamiento de objetos existentes basándose en distancias.

En caso de error, la estructura temporal de distancias y su contenido son destruidos.

Devuelve

0 en caso de éxito.

-1 en caso de error.

hwloc_distances_add_handle_t hwloc_distances_add_create (hwloc_topology_t topology, const char * name, unsigned long kind, unsigned long flags)

Crea una nueva estructura de distancias vacía. Crea una estructura de distancias vacía para ser llenada con hwloc_distances_add_values() y luego confirmada con hwloc_distances_add_commit().

Parámetro name es opcional, puede ser NULL. De lo contrario, será copiado internamente y más tarde puede ser liberado por el llamador.

kind especifica el tipo de distancia como un conjunto unión (OR) de hwloc_distances_kind_e. Solo se puede dar un tipo de significado y un tipo de procedencia si es apropiado (por ejemplo, HWLOC_DISTANCES_KIND_MEANS_BANDWIDTH y HWLOC_DISTANCES_KIND_FROM_USER). El tipo HWLOC_DISTANCES_KIND_HETEROGENEOUS_TYPES será automáticamente establecido de acuerdo con los objetos que tienen diferentes tipos en hwloc_distances_add_values().

flags debe ser 0 por ahora.

Devuelve

Un hwloc_distances_add_handle_t que luego debe ser pasado a hwloc_distances_add_values() y hwloc_distances_add_commit().

NULL en caso de error.

int hwloc_distances_add_values (hwloc_topology_t topology, hwloc_distances_add_handle_t handle, unsigned nbobjs, hwloc_obj_t * objs, hwloc_uint64_t * values, unsigned long flags)

Especifica los objetos y valores en una nueva estructura de distancias vacía. Especifica los objetos y valores para una nueva estructura de distancias que fue devuelta como un manejador por hwloc_distances_add_create(). La estructura debe luego ser confirmada con hwloc_distances_add_commit().

El número de objetos es nbobjs y el arreglo de objetos es objs. Los valores de distancia se almacenan como un arreglo unidimensional en values. La distancia del objeto i al objeto j está en la posición i*nbobjs+j.

nbobjs debe ser al menos 2.

Los arreglos objs y values serán copiados internamente, pueden luego ser liberados por el llamador.

En caso de error, la estructura temporal de distancias y su contenido son destruidos.

flags debe ser 0 por ahora.

Devuelve

0 en caso de éxito.

-1 en caso de error.
