Descripción detallada

Asegúrese de ver la figura en Términos y Definiciones que muestra un árbol de topología completo, incluyendo profundidades, relaciones hijo/hermano/primo, y un ejemplo de una topología asimétrica donde un paquete tiene menos cachés que sus compañeros.

hwloc_obj_t hwloc_get_ancestor_obj_by_depth (hwloc_topology_t topology, int depth, hwloc_obj_t obj) [inline]

Devuelve el objeto ancestro de obj con profundidad depth.

Retorna

el ancestro si existe.

NULL si no existe tal ancestro.

Nota

depth no debe ser la profundidad de objetos PU o NUMA ya que no son ancestros de ningún objeto (excepto Misc o I/O). Esta función espera más bien una profundidad intermedia, como la profundidad de Paquetes, Núcleos o Cachés.

hwloc_obj_t hwloc_get_ancestor_obj_by_type (hwloc_topology_t topology, hwloc_obj_type_t type, hwloc_obj_t obj) [inline]

Devuelve el objeto ancestro de obj con tipo type.

Retorna

el ancestro si existe.

NULL si no existe tal ancestro.

Nota

si existen múltiples ancestros que coinciden (por ejemplo, múltiples niveles de HWLOC_OBJ_GROUP), se devuelve el más bajo.

type no debe ser HWLOC_OBJ_PU o HWLOC_OBJ_NUMANODE ya que estos objetos no son ancestros de ningún objeto (excepto Misc o I/O). Esta función espera más bien un tipo de objeto intermedio, como HWLOC_OBJ_PACKAGE, HWLOC_OBJ_CORE, etc.

hwloc_obj_t hwloc_get_common_ancestor_obj (hwloc_topology_t topology, hwloc_obj_t obj1, hwloc_obj_t obj2) [inline]

Devuelve el objeto padre común a los objetos obj1 y obj2.

Retorna

el ancestro común.

Nota

Esta función no puede devolver NULL.

hwloc_obj_t hwloc_get_next_child (hwloc_topology_t topology, hwloc_obj_t parent, hwloc_obj_t prev) [inline]

Devuelve el siguiente hijo. Devuelve el siguiente hijo de la lista de hijos normales, luego de la lista de hijos de memoria, luego de la lista de hijos de I/O, luego de la lista de hijos de Misc.

Retorna

el primer hijo si prev es NULL.

el siguiente hijo si prev no es NULL.

NULL cuando no hay más hijos.

int hwloc_obj_is_in_subtree (hwloc_topology_t topology, hwloc_obj_t obj, hwloc_obj_t subtree_root) [inline]

Devuelve verdadero si obj está dentro del subárbol que comienza con el objeto ancestro subtree_root.

Retorna

1 si el objeto está en el subárbol, 0 en caso contrario.

Nota

Esta función no puede funcionar si los objetos obj y subtree_root no tienen conjuntos de CPU (objetos I/O o Misc).
