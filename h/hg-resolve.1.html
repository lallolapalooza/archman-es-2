Paquete: mercurial

Licencias: GPL

HG(RESOLVE) HG(RESOLVE)

NOMBRE

hg resolve - rehacer fusiones o establecer/ver el estado de fusión de archivos

SINOPSIS

hg resolve [OPCIÓN]... [ARCHIVO]...

DESCRIPCIÓN

Las fusiones con conflictos no resueltos a menudo son el resultado de fusiones no interactivas utilizando la configuración internal:merge, o una herramienta de fusión de línea de comandos como diff3. El comando resolve se utiliza para gestionar los archivos involucrados en una fusión, después de que se haya ejecutado hg merge, y antes de que se ejecute hg commit (es decir, el directorio de trabajo debe tener dos padres). Consulte hg help merge-tools para obtener información sobre la configuración de herramientas de fusión.

El comando resolve se puede utilizar de las siguientes maneras:

  • hg resolve [--re-merge] [--tool TOOL] ARCHIVO...: intenta volver a fusionar los archivos especificados, descartando cualquier intento de fusión anterior. No se realizan fusiones para archivos ya marcados como resueltos. Utilice --all/-a para seleccionar todos los archivos no resueltos. --tool se puede utilizar para especificar la herramienta de fusión utilizada para los archivos dados. Anula la variable de entorno HGMERGE y sus archivos de configuración. El contenido anterior del archivo se guarda con el sufijo .orig.
  • hg resolve -m [ARCHIVO]: marca un archivo como resuelto (por ejemplo, después de haber corregido manualmente los archivos). Por defecto, se marcan todos los archivos no resueltos.
  • hg resolve -u [ARCHIVO]...: marca un archivo como no resuelto. Por defecto, se marcan todos los archivos resueltos.
  • hg resolve -l: lista los archivos que tenían o todavía tienen conflictos. En la lista impresa, U = no resuelto y R = resuelto. Puede utilizar set:unresolved() o set:resolved() para filtrar la lista. Consulte hg help filesets para obtener detalles.
Nota
Mercurial no le permitirá confirmar archivos con conflictos de fusión no resueltos. Debe usar hg resolve -m ... antes de poder confirmar después de una fusión conflictiva.

Plantilla:

Las siguientes palabras clave son compatibles además de las palabras clave y funciones de plantillas comunes. Consulte también hg help templates.

mergestatus
Cadena. Carácter que denota conflictos de fusión, U o R.
path
Cadena. Ruta del archivo absoluta en el repositorio.

Devuelve 0 si tiene éxito, 1 si algún archivo falla en un intento de resolución.

OPCIONES

-a, --all
seleccionar todos los archivos no resueltos
-l, --list
listar el estado de los archivos que necesitan fusión
-m, --mark
marcar archivos como resueltos
-u, --unmark
marcar archivos como no resueltos
-n, --no-status
ocultar el prefijo de estado
--re-merge
volver a fusionar archivos
-t,--tool <HERRAMIENTA>
especificar herramienta de fusión
-I,--include <PATRON[+]>
incluir nombres que coincidan con los patrones dados
-X,--exclude <PATRON[+]>
excluir nombres que coincidan con los patrones dados
-T,--template <PLANTILLA>
mostrar con plantilla

[+] la opción marcada se puede especificar varias veces
