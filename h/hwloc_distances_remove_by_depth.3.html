Documentación de la Función

int hwloc_distances_release_remove (hwloc_topology_t topology, struct hwloc_distances_s * distances)

Liberar y eliminar la matriz de distancias dada de la topología. Esta función incluye una llamada a hwloc_distances_release().

Retorna

0 si tiene éxito, -1 si ocurre un error.

int hwloc_distances_remove (hwloc_topology_t topology)

Eliminar todas las matrices de distancias de una topología. Elimina todas las matrices de distancias, ya sean proporcionadas por el usuario o recopiladas a través del sistema operativo.

Si estas distancias se utilizaron para agrupar objetos, estos objetos de Grupo adicionales no se eliminan de la topología.

Retorna

0 si tiene éxito, -1 si ocurre un error.

int hwloc_distances_remove_by_depth (hwloc_topology_t topology, int depth)

Eliminar matrices de distancias para objetos en una profundidad específica en la topología. Idéntico a hwloc_distances_remove() pero solo se aplica a un nivel de la topología.

Retorna

0 si tiene éxito, -1 si ocurre un error.

Eliminar matrices de distancias para objetos de un tipo específico en la topología. Idéntico a hwloc_distances_remove() pero solo se aplica a un nivel de la topología.
