NOMBRE

helix - dibuja patrones de arte de cuerdas helicoidales

SINOPSIS

helix [--display host:display.screen] [--foreground color] [--background color] [--window] [--root] [--window-id numero][--mono] [--erase-speed usecs] [--erase-mode entero] [--delay segundos] [--install] [--visual visual] [--fps]

DESCRIPCIÓN

El programa helix dibuja patrones interesantes compuestos de segmentos de línea en colores aleatorios.

OPCIONES

helix acepta las siguientes opciones:

--window
Dibuja en una ventana recién creada. Esta es la opción predeterminada.
--root
Dibuja en la ventana raíz.
--window-id numero
Dibuja en la ventana especificada.
--mono
Si está en una pantalla a color, simula que está en una pantalla monocromática.
--delay segundos
Establece el número de segundos que la hélice permanecerá en la pantalla.
--subdelay microsegundos
Establece la cantidad de tiempo para pausar periódicamente mientras se dibuja.
--install
Instala un mapa de colores privado para la ventana.
--visual visual
Especifica qué visual usar. Los valores legales son el nombre de una clase visual, o el número de ID (decimal o hexadecimal) de un visual específico.
--fps
Muestra la velocidad de fotogramas actual y la carga de la CPU.

AMBIENTE

DISPLAY
para obtener el host y número de pantalla predeterminados.
XENVIRONMENT
para obtener el nombre de un archivo de recursos que anula los recursos globales almacenados en la propiedad RESOURCE_MANAGER.
XSCREENSAVER_WINDOW
El ID de ventana a usar con --root.

VER TAMBIÉN
