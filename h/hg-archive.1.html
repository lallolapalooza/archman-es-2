hg-archive(1)

Paquete: mercurial

Licencias: GPL

HG(ARCHIVE) HG(ARCHIVE)

NOMBRE

hg archive - crear un archivo sin versión de una revisión del repositorio

SINOPSIS

hg archive [OPCIÓN]... DEST

DESCRIPCIÓN

Por defecto, la revisión utilizada es la del padre del directorio de trabajo; usa -r/--rev para especificar una revisión diferente.

El tipo de archivo se detecta automáticamente basándose en la extensión del archivo (para anularlo, usa -t/--type).

Ejemplos:

  • crear un archivo zip que contenga la versión 1.0: 
    hg archive -r 1.0 proyecto-1.0.zip
  • crear un tarball excluyendo los archivos .hg: 
    hg archive proyecto.tar.gz -X ".hg*"

    Los tipos válidos son:

files

un directorio lleno de archivos (por defecto)

tar

archivo tar, sin comprimir

tbz2

archivo tar, comprimido usando bzip2

tgz

archivo tar, comprimido usando gzip

txz

archivo tar, comprimido usando lzma (solo en Python 3)

uzip

archivo zip, sin comprimir

zip

archivo zip, comprimido usando deflate

El nombre exacto del archivo o directorio de destino se da usando una cadena de formato; consulta hg help export para más detalles.

A cada miembro añadido a un archivo se le antepone un prefijo de directorio. Usa -p/--prefix para especificar una cadena de formato para el prefijo. El valor por defecto es el nombre base del archivo, con los sufijos eliminados.

Devuelve 0 en caso de éxito.

OPCIONES

--no-decode
no pasar archivos a través de decodificadores
-p,--prefix <PREFIJO>
prefijo de directorio para los archivos en el archivo
-r,--rev <REV>
revisión a distribuir
-t,--type <TIPO>
tipo de distribución a crear
-S, --subrepos
recorrer subrepositorios recursivamente
-I,--include <PATRON[+]>
incluir nombres que coincidan con los patrones dados
-X,--exclude <PATRON[+]>
excluir nombres que coincidan con los patrones dados

[+] la opción marcada puede especificarse varias veces
