NOMBRE

hmac256 - Calcular un MAC HMAC-SHA-256

SINOPSIS

hmac256 [--binary] clave [NOMBRE_ARCHIVO]

DESCRIPCIÓN

Esta es una implementación independiente de HMAC-SHA-256 utilizada para calcular un código de autenticación de mensaje HMAC-SHA-256. La herramienta se desarrolló originalmente como una segunda implementación para Libgcrypt para permitir la comparación con la implementación principal y para ser utilizada para comprobaciones de consistencia internas. No debe usarse para datos sensibles porque no se utilizan mecanismos para limpiar la pila, etc.

El código se ha escrito de manera muy portable y solo requiere que se proporcionen unas pocas definiciones estándar en un archivo config.h.

hmac256 se invoca comúnmente como

hmac256 "Esta es mi clave" foo.txt

Esto calcula el MAC sobre el archivo ‘foo.txt’ utilizando la clave proporcionada en la línea de comandos.

OPCIONES

hmac256 entiende estas opciones:

--binary
Imprimir el MAC como una cadena binaria. El valor predeterminado es imprimir el MAC codificado como dígitos hexadecimales en minúsculas.
--version
Imprimir la versión del programa y salir.
