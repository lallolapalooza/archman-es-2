FBB::HMacBuf(3bobcat) Calcular Resúmenes de Mensajes HMAC FBB::HMacBuf(3bobcat)

NOMBRE

FBB::HMacBuf - Calcula Resúmenes de Mensajes HMAC a partir de información insertada en un std::ostream

SINOPSIS

#include <bobcat/hmacbuf>
Opción de enlazado: -lbobcat -lcrypto

DESCRIPCIÓN

FBB::HMacBuf son objetos std::streambuf que pueden usarse para inicializar objetos std::ostream .

Toda la información insertada en un std::ostream así se usa para calcular un mensaje HMAC.

Todos los algoritmos de resumen de mensajes y cifrado definidos por la biblioteca OpenSSL que puedan seleccionarse por nombre pueden usarse en combinación con objetos HMacBuf .

Para los algoritmos de resumen de mensajes soportados actualmente, ejecute el comando

    openssl list -digest-commands
Para los algoritmos de cifrado de mensajes soportados actualmente, ejecute el comando 
    openssl list -cipher-commands
Los valores por defecto usados por los constructores de HMacBuf son el algoritmo de resumen sha256 y el algoritmo de cifrado aes-128-cbc .

ESPACIO DE NOMBRES

FBB
Todos los constructores, miembros, operadores y manipuladores mencionados en esta página del manual se definen en el espacio de nombres FBB.

HEREDA DE

std::streambuf

CONSTRUCTORES

o
HMacBuf():
El constructor por defecto define un objeto HmacBuf . Puede usarse una vez que un objeto HMacBuf construido de forma no predeterminada le haya sido asignado mediante movimiento;
o
HMacBuf(HMacBuf &&tmp):
El constructor por movimiento inicializa un objeto HmacBuf moviendo tmp al objeto HMacBuf actual;
o
HMacBuf(std::string const &key, char const *digest, size_t bufsize):
Este constructor inicializa el streambuf, configurándolo para el algoritmo de resumen de mensajes especificado con digest. Por ejemplo, para usar el algoritmo sha256 especifique "sha256".
El primer argumento del constructor define la clave a usar al calcular el resumen de mensaje HMAC. La longitud de la clave debe ser de 16 caracteres. Se lanza una excepción si se especifica una clave vacía.
El argumento bufsize especifica el tamaño (en bytes) del búfer interno usado por HMacBuf para almacenar temporalmente los caracteres entrantes. Un valor de 1024 debería ser adecuado para todos los casos normales;
o
HMacBuf(std::string const &key, char const *cipher = "aes-128-cbc", char const *digest = "sha256", size_t bufsize = 1024):
Como el constructor anterior, pero este ofrece valores por defecto para los algoritmos de cifrado y resumen y para el tamaño del búfer. Al especificar otro algoritmo de cifrado, la longitud de la clave debe cumplir el requisito del cifrado. Normalmente el nombre del cifrado contiene un número (como 128), que puede dividirse por 8 para obtener la longitud de clave requerida de los cifrados de longitud de clave fija.

OPERADOR SOBRECARGADO

o
HMacBuf &operator=(HMacBuf &&rhs):
El operador de asignación por movimiento mueve el objeto rhs HMacBuf al objeto actual;
o
std::ostream &operator<<(std::ostream &out, HMacBuf const &hmacbuf):
El operador de inserción es una función libre definida en el espacio de nombres FBB. Inserta un valor hash como una serie de valores mostrados en hexadecimal en el ostreamproporcionado. Vea el ejemplo siguiente para una ilustración.

FUNCIONES MIEMBRO

Todos los miembros de std::streambuf están disponibles, ya que FBB::HMacBuf hereda de esta clase.

o
std::string const &hash() const:
Este miembro devuelve el valor hash calculado por el objeto HMacBuf . Su valor solo está definido después de haber llamado a close(). El valor hash se devuelve en un objeto std::string . El miembro length() de esta cadena contiene el número de caracteres usados por el valor hash, y su miembro data() hace referencia a los caracteres del valor hash. Nótese que el valor de un carácter de un valor hash puede ser 0 (no confundir con ’0’).
Cuando se llama desde un objeto HMacBuf construido por defecto, se devuelve una cadena vacía;
o
void reset():
Este miembro reinicializa el cálculo del hmac del mensaje. Una vez calculado el hmac de un mensaje para, digamos, un flujo streamA , se puede llamar a este miembro, tras lo cual el hmac de un flujo streamB puede calcularse usando el mismo objeto HMacBuf .
No se realiza ninguna acción cuando se llama desde un objeto HMacBuf construido por defecto;
o
void eoi():
Se puede llamar a este miembro para completar el cálculo del resumen de mensajes. En lugar de llamar a este miembro, se puede usar el manipulador eoi (véase más abajo).

MANIPULADOR

o
FBB::eoi:
El manipulador eoi puede insertarse en el ostream para completar el cálculo del resumen. Si se inserta en un std::ostream plano, no ocurre nada.
eoi también puede llamarse como una función, recibiendo el flujo que usa el HMacBuf como su streambuf, pero debe llamarse de cualquier modo, ya que el propio objeto HMacBuf no puede decidir si ya se ha recibido toda la información para calcular el resumen o no. El enfoque general para calcular un hmac de mensaje es por tanto: 
    1. crear un objeto HMacBuf
    2. usarlo para crear un objeto std::ostream
    3. insertar información en el objeto ostream
    4. llamar al miembro eoi() del objeto HMacBuf o insertar eoi en el objeto ostream
    5. obtener/procesar el valor hash del objeto HMacBuf.

EJEMPLO

#include <fstream>
#include <iostream>
#include <bobcat/hmacbuf>
using namespace std;
using namespace FBB;
int main(int argc, char **argv)
try
{
                        // usando el algoritmo de resumen por defecto (sha256)
    if (argc == 1)
        throw Exception{} <<
                "Uso: arg1: clave de 16 bytes, arg2: archivo a procesar,\n"
                "     arg3 (opc) tamaño del búfer (por defecto 1024)";
    HMacBuf hmacbuf{ argv[1], "aes-128-cbc", "sha256",
                     argc == 3 ? 1024 : stoul(argv[3]) };
    HMacBuf empty;                              // Demo: un HMacBuf vacío
    empty = HMacBuf{ argv[1], "sha256", 100 };  // Demo: asignación por movimiento
    ostream out(&hmacbuf);              // el ostream que recibe la
                                        // entrada para calcular el hmac
    ifstream in{ argv[2] };             // el archivo a procesar
    out << in.rdbuf() << eoi;           // calcular el hmac
                                        // y mostrar el valor del hmac
    cout << "  valor hmac calculado: >" << hmacbuf << "<\n";
    in.seekg(0);                        // para ilustrar ’reset’: hacerlo
    hmacbuf.reset();                    // de nuevo
    out << in.rdbuf();
    eoi(out);                           // llamando a eoi como función
    cout << "valor hmac recalculado: >" << hmacbuf << "<\n";
}
catch(exception const &err)
{
    cout << err.what() << endl;
    return errno;
}
