HTC(1) Manual de comandos generales HTC(1)

NOMBRE

htc - cliente de httptunnel

SINOPSIS

htc [opciones] host[:puerto]

DESCRIPCIÓN

Esta página del manual documenta brevemente el comando htc.

htc establece una conexión httptunnel al PUERTO en HOST (el puerto por defecto es 8888). Cuando se establece una conexión, la E/S se redirige desde la fuente especificada por el interruptor --device o --forward-port al túnel.

OPCIONES

El programa sigue la sintaxis habitual de línea de comandos de GNU, con opciones largas que comienzan con dos guiones (`-'). A continuación se incluye un resumen de las opciones.

-h, --help
Muestra el resumen de las opciones.
-c, --content-length BYTES
usa solicitudes HTTP PUT de tamaño BYTES (se reconocen los sufijos k, M y G)
-d, --device DISPOSITIVO
usa DISPOSITIVO para entrada y salida
-F, --forward-port PUERTO
usa el puerto TCP PUERTO para entrada y salida
-k, --keep-alive SEGUNDOS
envía bytes de keepalive cada SEGUNDOS segundos (el valor por defecto es 5)
-M, --max-connection-age SEG
el tiempo máximo que una conexión permanecerá abierta es SEG segundos (el valor por defecto es 300)
-S, --strict-content-length
escribe siempre BYTES de Content-Length en las solicitudes
-A, --proxy-authorization USUARIO:CONTRASEÑA
autorización del proxy
--proxy-authorization-file ARCHIVO
archivo de autorización del proxy
-B, --proxy-buffer-size BYTES
asume un tamaño de búfer de proxy de BYTES bytes (se reconocen los sufijos k, M y G)
-P, --proxy NOMBREHOS[:PUERTO]
usa un proxy HTTP (el puerto por defecto es 8080)
-T, --timeout TIME
tiempo de espera, en milisegundos, antes de enviar relleno a un proxy con búfer
-U, --user-agent CADENA
especifica el valor de User-Agent en las solicitudes HTTP
-V, --version
muestra la información de la versión y sale
