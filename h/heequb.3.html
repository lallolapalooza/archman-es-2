!>          El orden de la matriz A. N >= 0.

NAME


ZSYEQUB — A routine to compute the scaling factors for a
    symmetric matrix.






SYNOPSIS


SUBROUTINE ZSYEQUB( UPLO, N, A, LDA, S, SCOND, AMAX, WORK, INFO )



CHARACTER * 1


UPLO



INTEGER


N, LDA, INFO



COMPLEX*16


A( LDA, * ), WORK( * )



DOUBLE PRECISION


S( * ), SCOND, AMAX



CHARACTER * 1


UPLO



INTEGER


N, LDA, INFO



DOUBLE PRECISION


S( * ), SCOND, AMAX



COMPLEX*16


A( LDA, * ), WORK( * )







Detailed Description


ZSYEQUB computes the scaling factors for a symmetric matrix
    A. The matrix A is scaled by a diagonal matrix D
    such that when the problem is transformed into:


$$ D A D x = D b $$


or


$$ A D y = b $$


where


$$ y = D x $$


the condition number of the matrix is improved.
    A is not modified by this routine. This routine is used for
    problems where the diagonal elements of A are very close to
    zero.


Arguments:


UPLO


          UPLO is CHARACTER*1
          = 'U': Upper triangle of A is stored and referenced.
          = 'L': Lower triangle of A is stored and referenced.



N


          N is INTEGER
          The number of rows and columns of the matrix A.  N >= 0.



A


          A is COMPLEX*16 array, dimension (LDA,N)
          The N-by-N symmetric matrix whose scaling factors are to be
          computed.



LDA


          LDA is INTEGER
          The leading dimension of the array A. LDA >= max(1,N).



S


          S is DOUBLE PRECISION array, dimension (N)
          If INFO = 0, S contains the scale factors for A.



SCOND


          SCOND is DOUBLE PRECISION
          If INFO = 0, S contains the ratio of the smallest S(i) to
          the largest S(i). If SCOND >= 0.1 and AMAX is neither too
          large nor too small, it is not worth scaling by S.



AMAX


          AMAX is DOUBLE PRECISION
          Largest absolute value of any matrix element. If AMAX is
          very close to overflow or very close to underflow, the
          matrix should be scaled.



WORK


          WORK is COMPLEX*16 array, dimension (2*N)



INFO


          INFO is INTEGER
          = 0:  successful exit
          < 0:  if INFO = -i, the i-th argument had an illegal value
          > 0:  if INFO = i, the i-th diagonal element is nonpositive.
