history(n) Comandos integrados de Tcl history(n)

NOMBRE

history - Manipular la lista de historial

SINOPSIS

history ?opción? ?arg arg ...?

DESCRIPCIÓN

El comando history realiza una de varias operaciones relacionadas con comandos ejecutados recientemente registrados en una lista de historial. Cada uno de estos comandos registrados se denomina un “evento”. Al especificar un evento al comando history, se pueden utilizar las siguientes formas:

[1]
Un número: si es positivo, se refiere al evento con ese número (todos los eventos se numeran a partir de 1). Si el número es negativo, selecciona un evento relativo al evento actual (-1 se refiere al evento anterior, -2 al anterior a ese, y así sucesivamente). El evento 0 se refiere al evento actual.
[2]
Una cadena: selecciona el evento más reciente que coincide con la cadena. Un evento se considera que coincide con la cadena si la cadena es la misma que los primeros caracteres del evento, o si la cadena coincide con el evento en el sentido del comando string match.

El comando history puede tener cualquiera de las siguientes formas:

history
Igual que history info, descrito a continuación.
history add comando ?exec?
Añade el argumento comando a la lista de historial como un nuevo evento. Si se especifica (o abrevia) exec, entonces el comando también se ejecuta y se devuelve su resultado. Si no se especifica exec, se devuelve una cadena vacía como resultado.
history change nuevoValor ?evento?
Reemplaza el valor registrado para un evento con nuevoValor. Evento especifica el evento a reemplazar y, por defecto, es el evento *actual* (no el evento -1). Este comando está destinado a ser utilizado en comandos que implementan nuevas formas de sustitución de historial y desean reemplazar el evento actual (que invoca la sustitución) con el comando creado a través de la sustitución. El valor de retorno es una cadena vacía.
history clear
Borra la lista de historial. El límite de conservación actual se mantiene. Los números de evento del historial se reinician.
history event ?evento?
Devuelve el valor del evento dado por evento. Evento por defecto es -1.
history info ?conteo?
Devuelve una cadena formateada (destinada a ser leída por humanos) que indica el número de evento y el contenido de cada uno de los eventos de la lista de historial, excepto el evento actual. Si se especifica conteo, solo se devuelven los conteo eventos más recientes.
history keep ?conteo?
Este comando se puede utilizar para cambiar el tamaño de la lista de historial a conteo eventos. Inicialmente, se conservan 20 eventos en la lista de historial. Si no se especifica conteo, se devuelve el límite de conservación actual.
history nextid
Devuelve el número del próximo evento que se registrará en la lista de historial. Es útil para cosas como imprimir el número de evento en los prompts de la línea de comandos.
history redo ?evento?
Reejecuta el comando indicado por evento y devuelve su resultado. Evento por defecto es -1. Este comando da como resultado la revisión del historial: vea a continuación para obtener más detalles.

REVISIÓN DEL HISTORIAL

Tcl anterior a la versión 8.0 tenía un complejo mecanismo de revisión del historial. El mecanismo actual es más limitado y las antiguas operaciones de historial substitute y words han sido eliminadas. (Como consuelo, se añadió la operación clear).

La opción de historial redo resulta en una "revisión del historial" mucho más simple. Cuando se invoca esta opción, el evento más reciente se modifica para eliminar el comando de historial y reemplazarlo con el resultado del comando de historial. Si desea rehacer un evento sin modificar el historial, utilice la operación event para obtener un evento y la operación add para agregarlo al historial y ejecutarlo.

PALABRAS CLAVE
