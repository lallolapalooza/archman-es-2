HXREF(1) Utilidades HTML-XML HXREF(1)

NOMBRE

hxref - genera referencias cruzadas dentro y entre archivos HTML

SINOPSIS

hxref [ -x ] [ -l ] [ -b base ] [ -i índice ] [ -- ] [ entrada [ salida ] ]

DESCRIPCIÓN

El comando hxref enlaza elementos inline a elementos DFN con el mismo contenido. Añade atributos ID donde sea necesario. Si el contenido de un DFN u otro elemento no es adecuado, el atributo TITLE puede ser usado para proporcionar el término a usar para las comparaciones.

Aquí hay un ejemplo:


<p>Una <dfn>caja-b</dfn> se define como...
<p>Por cada b hay una <em>caja-b</em>...

La salida de hxref será similar a esta:


<p>Una <dfn id="caja-b">caja-b</dfn> se define como...
<p>Por cada b hay una <a href="#caja-b"><em>caja-b</em></a>...

OPCIONES

Se soportan las siguientes opciones:

-x
Usa convenciones XML: los elementos vacíos se escriben con una barra al final: <IMG />
-b base
Establece el prefijo para las URLs generadas. Por defecto, base está vacío, lo que genera URLs como "#caja-b" arriba. Si base se establece a, por ejemplo, "http://xyz/", las URLs se verán como "http://xyz/#caja-b".
-i índice
Dirige a hxref a leer términos de un archivo base de datos antes de buscarlos en el documento y después almacena los términos que se encontraron en el mismo archivo. Los elementos DFN en el documento anulan los términos encontrados en índice. Esto permite que hxref se ejecute múltiples veces en diferentes archivos, para que los archivos se refieran entre sí. Puede ser necesario ejecutar los comandos dos veces para resolver todas las referencias cruzadas.
-l
Intenta usar información específica del idioma para emparejar instancias con sus definiciones. Actualmente, solo se soporta el inglés y las únicas reglas aplicadas son buscar sin una "s" final ("árboles" coincide con "árbol"), sin una "es" final ("jefes" coincide con "jefe") y con una "y" reemplazando una "ies" final ("recompensas" coincide con "recompensa"). hxref determina el idioma a partir de los atributos "lang" y "xml:lang" en el documento.

OPERANDOS

Se soportan los siguientes operandos:

entrada
El nombre de un archivo HTML. Si está ausente, se lee la entrada estándar en su lugar. El nombre especial "-" también indica la entrada estándar. La entrada puede ser una URL.
salida
El archivo donde escribir. Si está ausente, se usa la salida estándar. Esto *no* puede ser una URL.

DIAGNÓSTICO

Se devuelven los siguientes valores de salida:

0
Finalización exitosa.
> 0
Ocurrió un error en el análisis del archivo HTML. hxref intentará corregir el error y producir salida de todos modos.

VER TAMBIÉN

asc2xml(1), hxindex(1), hxnormalize(1), hxnum(1), hxtoc(1), xml2asc(1)

BUGS

La recuperación de errores para HTML incorrecto es primitiva.

El programa genera atributos ID, pero no genera etiquetas <a name=...>, por lo que los enlaces solo funcionan en navegadores que reconocen los atributos ID.

Las reglas para emparejar plurales en inglés son primitivas. No se usa un diccionario. Por ejemplo, "bees" se considerará un plural de "be".

Actualmente no hay forma de establecer el idioma por defecto para un documento cuando el elemento raíz no tiene un atributo "lang" o "xml:lang".

hxref intenta primero generar atributos ID "legibles", formando el ID a partir de las letras y dígitos encontrados en el contenido del elemento, y recurre a la generación de IDs arbitrarios si no encuentra suficientes. Sin embargo, el algoritmo en esta versión es primitivo y solo da resultados razonables para letras y dígitos ASCII.
