int hwloc_bitmap_singlify_per_core (hwloc_topology_t topology, hwloc_bitmap_t cpuset, unsigned

which)

Elimina las PU de multithreading simultáneo de un conjunto de CPU. Para cada núcleo en la topología, si cpuset contiene algunas PU de ese núcleo, modifica cpuset para mantener solo una PU para ese

núcleo.

which especifica qué PU se mantendrá. Las PU se consideran en orden de índice físico. Si es 0, para cada núcleo, la función mantiene

la primera PU que estaba originalmente establecida en cpuset.

Si which es mayor que el número de PU en un núcleo que estaban originalmente establecidas en cpuset, no se mantiene ninguna PU para ese

núcleo.

0
.

hwloc_obj_t hwloc_get_obj_below_array_by_type (hwloc_topology_t topology, int nr, hwloc_obj_type_t * typev, unsigned * idxv) [inline]

Encuentra un objeto debajo de una cadena de objetos especificados por tipos y índices. Esta es una versión generalizada de hwloc_get_obj_below_

by_type().

Los arrays typev y idxv deben contener nr tipos y

índices.

Comienza desde el objeto de sistema superior y recorre los arrays typev y idxv. Para cada par de tipo e índice lógico en los arrays, busca debajo del objeto previamente encontrado para encontrar el objeto de índice-ésimo del tipo dado. Los índices se especifican dentro del padre, no dentro de todo el

sistema.

Por ejemplo, si nr es 3, typev contiene NODE, PACKAGE y CORE, y idxv contiene 0, 1 y 2, devuelve el tercer objeto de núcleo debajo del segundo paquete debajo del primer nodo

NUMA.

contrario.

hwloc_obj_t hwloc_get_obj_with_same_locality (hwloc_topology_t topology, hwloc_obj_t src, hwloc_obj_type_t type, const char * subtype, const char * nameprefix, unsigned long

flags)

Devuelve un objeto de un tipo diferente con la misma localidad. Si el objeto fuente src es un tipo normal o de memoria, esta función devuelve un objeto de tipo type con los mismos conjuntos de CPU y de nodos, ya sea debajo o arriba en la

jerarquía.

Si el objeto fuente src es un dispositivo PCI o un dispositivo del SO dentro de un dispositivo PCI, la función puede devolver ese dispositivo PCI, u otro dispositivo del SO en el mismo padre PCI. Esto puede, por ejemplo, ser útil para convertir entre dispositivos del SO como 'nvml0' o 'rsmi1' usados en estructuras de distancia en el dispositivo PCI, o el dispositivo del SO de CUDA u OpenCL que corresponde a la misma tarjeta

física.

Si no es NULL, el parámetro subtype solo selecciona objetos cuyo atributo subtype existe y es subtype (sin distinguir mayúsculas de minúsculas), por ejemplo 'OpenCL' o

'CUDA'.

Si no es NULL, el parámetro nameprefix solo selecciona objetos cuyo atributo name existe y comienza con nameprefix (sin distinguir mayúsculas de minúsculas), por ejemplo 'rsmi' para coincidir con

'rsmi0'.

Si múltiples objetos coinciden, se devuelve el

primero.

Esta función no recorrerá la jerarquía a través de puentes ya que la localidad PCI puede volverse diferente. Esta función tampoco puede convertir entre objetos normales/de memoria y objetos de E/S o

Misc.

flags debe ser 0 por

ahora.
