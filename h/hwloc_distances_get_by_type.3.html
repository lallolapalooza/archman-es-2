Documentación del Tipo de Enumeración

enum hwloc_distances_kind_e

Clases de matrices de distancia. El atributo kind de la estructura hwloc_distances_s es un conjunto OR de clases.

Cada matriz de distancia puede tener solo una clase entre HWLOC_DISTANCES_KIND_FROM_* que especifica de dónde provienen las informaciones de distancia, y una clase entre HWLOC_DISTANCES_KIND_MEANS_* que especifica si los valores son latencias o anchos de banda.

Enumerador

HWLOC_DISTANCES_KIND_FROM_OS
Estas distancias se obtuvieron del sistema operativo o del hardware.
HWLOC_DISTANCES_KIND_FROM_USER
Estas distancias fueron proporcionadas por el usuario.
HWLOC_DISTANCES_KIND_MEANS_LATENCY
Los valores de distancia son similares a las latencias entre objetos. Los valores son menores para objetos más cercanos, por lo tanto, mínimos en la diagonal de la matriz (distancia entre un objeto y sí mismo). También podría ser el número de saltos de red entre objetos, etc.
HWLOC_DISTANCES_KIND_MEANS_BANDWIDTH
Los valores de distancia son similares a los anchos de banda entre objetos. Los valores son mayores para objetos más cercanos, por lo tanto, máximos en la diagonal de la matriz (distancia entre un objeto y sí mismo). Tales valores son actualmente ignorados para la agrupación basada en distancia.
HWLOC_DISTANCES_KIND_HETEROGENEOUS_TYPES
Esta estructura de distancias cubre objetos de diferentes tipos. Esto puede aplicarse a la estructura 'NVLinkBandwidth' en presencia de un NVSwitch o un puerto NVLink del procesador POWER.

enum hwloc_distances_transform_e

Transformaciones de estructuras de distancias.

Enumerador

HWLOC_DISTANCES_TRANSFORM_REMOVE_NULL
Elimina objetos NULL de la estructura de distancias. Cada objeto que fue reemplazado por NULL en el array objs se elimina y el array de valores se actualiza en consecuencia.

Deben permanecer al menos 2 objetos, de lo contrario hwloc_distances_transform() devolverá -1 con errno establecido en EINVAL.

kind se actualizará con o sin HWLOC_DISTANCES_KIND_HETEROGENEOUS_TYPES según los objetos restantes.

HWLOC_DISTANCES_TRANSFORM_LINKS
Reemplaza los valores de ancho de banda por un número de enlaces. Normalmente, todos los valores serán 0 (sin enlace) o 1 (un enlace). Sin embargo, algunas matrices podrían obtener valores más grandes si algunos pares de pares están conectados por diferentes números de enlaces.

Los valores en la diagonal se establecen en 0.

Esta transformación solo se aplica a matrices de ancho de banda.

HWLOC_DISTANCES_TRANSFORM_MERGE_SWITCH_PORTS
Fusiona switches con múltiples puertos en un solo objeto. Esto actualmente solo se aplica a NVSwitches donde las GPUs parecen conectadas a diferentes puertos del switch. Los puertos del switch deben ser objetos con el subtipo 'NVSwitch' como en la matriz NVLinkBandwidth.

Esta transformación reemplazará todos los puertos con solo el primero, ahora conectado a todas las GPUs. Otros puertos se eliminan aplicando HWLOC_DISTANCES_TRANSFORM_REMOVE_NULL internamente.

HWLOC_DISTANCES_TRANSFORM_TRANSITIVE_CLOSURE
Aplica un cierre transitivo a la matriz para conectar objetos a través de switches. Se informará que todos los pares de GPUs están conectados directamente en lugar de que las GPUs solo estén conectadas a switches.

Los puertos del switch deben ser objetos con el subtipo 'NVSwitch' como en la matriz NVLinkBandwidth.

int hwloc_distances_get (hwloc_topology_t topology, unsigned * nr, struct hwloc_distances_s ** distances, unsigned long kind, unsigned long flags)

Recupera matrices de distancia. Recupera matrices de distancia de la topología en el array distances.

flags no se utiliza actualmente, debería ser 0.

kind actúa como filtro. Si es 0, se devuelven todas las matrices de distancia. Si contiene algún HWLOC_DISTANCES_KIND_FROM_*, solo se devuelven las matrices de distancia cuyo kind coincida con alguno de ellos. Si contiene algún HWLOC_DISTANCES_KIND_MEANS_*, solo se devuelven las matrices de distancia cuyo kind coincida con alguno de ellos.

En la entrada, nr apunta al número de matrices de distancia que pueden almacenarse en distances. En la salida, nr apunta al número de matrices de distancia que se encontraron realmente, incluso si algunas de ellas no pudieron almacenarse en distances. int hwloc_distances_get_by_name (hwloc_topology_t topology, const char * name, unsigned * nr, struct hwloc_distances_s ** distances, unsigned long flags)

Recupera una matriz de distancias con el nombre dado. Usualmente solo una estructura de distancias puede coincidir con un nombre dado.

El nombre de la estructura más común es 'NUMALatency'. Otros incluyen 'XGMIBandwidth', 'XGMIHops', 'XeLinkBandwidth' y 'NVLinkBandwidth'.

Devuelve

0 en caso de éxito, -1 en caso de error.

const char * hwloc_distances_get_name (hwloc_topology_t topology, struct hwloc_distances_s * distances)

Obtiene una descripción de lo que contiene una estructura de distancias. Por ejemplo 'NUMALatency' para distancias NUMA proporcionadas por el hardware (ACPI SLIT), o NULL si es desconocido.

Devuelve

la cadena constante con el nombre de la estructura de distancias.

Nota

El nombre devuelto no debe ser liberado por el llamador, pertenece a la biblioteca hwloc.

void hwloc_distances_release (hwloc_topology_t topology, struct hwloc_distances_s * distances)

Libera una estructura de matriz de distancias previamente devuelta por hwloc_distances_get().

Nota

Esta función no es necesaria si la estructura se elimina con hwloc_distances_release_remove().

int hwloc_distances_transform (hwloc_topology_t topology, struct hwloc_distances_s * distances, enum hwloc_distances_transform_e transform, void * transform_attr, unsigned long flags)

Aplica una transformación a una estructura de distancias. Modifica una estructura de distancias que fue obtenida previamente con hwloc_distances_get() o una de sus variantes.

Esto modifica la copia local de las estructuras de distancias pero no modifica la información de distancias almacenada dentro de la topología (recuperada por otra llamada a hwloc_distances_get() o exportada a XML). Para hacer esto, se debe añadir una nueva estructura de distancias con el mismo nombre, tipo, objetos y valores (ver Añadir distancias entre objetos) y luego eliminar esta antigua con hwloc_distances_release_remove().

transform debe ser una de las transformaciones listadas en hwloc_distances_transform_e.

Estas transformaciones pueden modificar el contenido de los arrays objs o values .

transform_attr debe ser NULL por ahora.

flags debe ser 0 por ahora.

Devuelve

0 en caso de éxito, -1 en caso de error, por ejemplo si los flags son inválidos.

Nota

Los objetos en el array objs de distancias pueden ser modificados directamente en su lugar sin usar hwloc_distances_transform(). Se puede usar hwloc_get_obj_with_same_locality() para convertir fácilmente entre objetos similares de diferentes tipos.
