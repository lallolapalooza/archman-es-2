FBB::Hostname(3bobcat) Información del host FBB::Hostname(3bobcat)

NOMBRE

FBB::Hostname - Contiene información de nombre/dirección de un host

SINOPSIS

#include <bobcat/hostname>
Opción de enlazado: -lbobcat

DESCRIPCIÓN

Los objetos FBB::Hostname heredan de Hostent y ofrecen información sobre un host, como Hostent. Además de ser inicializados por un nombre de host o una dirección de host, también pueden ser inicializados por un objeto FBB::InetAddress. La mayoría de la funcionalidad de un objeto FBB::Hostname está disponible a través de su clase padre FBB::Hostent.

ESPACIO DE NOMBRES

FBB
Todos los constructores, miembros, operadores y manipuladores mencionados en esta página del manual están definidos en el espacio de nombres FBB.

HEREDA DE

FBB::Hostent

CONSTRUCTORES

o
Hostname():
El constructor por defecto inicializa un objeto FBB::Hostname vacío.
o
Hostname((std::string const &host)):
Este constructor inicializa un objeto FBB::Hostname a partir de una cadena que representa el nombre o la dirección decimal con puntos de un host. Se lanza un objeto FBB::Exception si la información del nombre del host no pudo ser recuperada.
o
Hostname(InetAddress const &inetAddress):
Este constructor inicializa un objeto FBB::Hostname a partir de un objeto InetAddress. Se lanza un objeto FBB::Exception si la información del nombre del host no pudo ser recuperada.

Se encuentran disponibles constructores y operadores de asignación de copia y movimiento.

FUNCIONES MIEMBRO

Todos los miembros de FBB::Hostent están disponibles, ya que FBB::Hostname hereda de esta clase. No hay miembros adicionales.

EJEMPLO

#include <iostream>
#include <bobcat/hostname>
#include <bobcat/exception>
using namespace std;
using namespace FBB;
int main(int argc, char **argv)
{
    while (true)
    {
        cout << "Introduce nombre o dirección:\n";
        string str;
        if (!getline(cin, str))
            return 0;
        if (str == "")
            break;
        try
        {
            Hostname h(str);
            cout << "Nombre oficial:\n";
                cout << h.hostname() << endl;
            cout << "Alias:\n";
            for (size_t idx = 0; idx < h.nAliases(); idx++)
                cout << h.alias(idx) << " ";
            cout << endl;
            cout << "Direcciones:\n";
            for (size_t idx = 0; idx < h.nAddresses(); idx++)
                cout << h.dottedDecimalAddress(idx) << " ";
            cout << endl;
        }
        catch (exception const &err)
        {
            cout << err.what() << endl;
        }
    }
}
