NOMBRE

hurlfmt - formatea archivos Hurl

SINOPSIS

hurlfmt [opciones] [ARCHIVO...]

DESCRIPCIÓN

hurlfmt formatea archivos Hurl y los convierte desde/a otros formatos.

Si no se especifica ARCHIVO, lee de la entrada estándar.

Por defecto, hurlfmt produce una versión formateada y coloreada del archivo hurl de entrada.


$ hurl hello.hurl
GET http://localhost:8000/hello


HTTP/1.0 200

hurlfmt puede usarse para convertir a otros formatos.


$ hurl hello.hurl --output json | jq
{
"entries": [
{
"request": {
"method": "GET",
"url": "http://localhost:8000/hello"
},
"response": {
"version": "HTTP/1.0",
"status": 200
}
}
]
}

hurlfmt también puede usarse para convertir un comando curl a Hurl


$ echo "curl http://localhost:8000/custom-headers -H 'Fruit:Raspberry'" | hurlfmt --in curl
GET http://localhost:8000/custom-headers
Fruit: Raspberry

OPCIONES

--check

Ejecutar en modo de verificación. Sale con 0 si la entrada está correctamente formateada, 1 en caso contrario.

Esto no puede usarse con --output.

Esta opción aún no es estable.

--color

Colorear la salida.

Esto no puede usarse con --in-place.

--in <FORMATO>

Especificar formato de entrada: hurl o curl.

--in-place

Modificar el archivo en el lugar.

Esto solo puede usarse con salida de texto.

--no-color

No colorear la salida.

--out <FORMATO>

Especificar formato de salida: hurl, json o html.

-o, --output <ARCHIVO>

Escribir la salida en ARCHIVO en lugar de stdout.

--standalone

Producir un archivo html completo con css en lugar de un fragmento html (por defecto).

Esto solo puede usarse con salida html.

-h, --help

Ayuda de uso.

-V, --version

Imprime información de la versión

CÓDIGOS DE SALIDA
