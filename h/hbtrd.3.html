CHBTR

D

Propósito

: 
!>
!> CHBTRD reduce una matriz de banda hermítica compleja A a una forma
!> tridiagonal simétrica real T mediante una transformación de
!> similitud unitaria:
!> Q**H * A * Q = T.
!
>

Parámetro

s
VECT 
!>          VECT es CHARACTER*1
!>          = 'N':  no formar Q;
!>          = 'V':  formar Q;
!>          = 'U':  actualizar una matriz X, formando X*Q.
!
>

UPL

O 
!>          UPLO es CHARACTER*1
!>          = 'U':  se almacena el triángulo superior de A;
!>          = 'L':  se almacena el triángulo inferior de A.
!
>

N 
!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!
>

K

D 
!>          KD es INTEGER
!>          El número de superdiagonales de la matriz A si UPLO = 'U',
!>          o el número de subdiagonales si UPLO = 'L'.  KD >= 0.
!
>

A

B 
!>          AB es un array COMPLEX, dimensión (LDAB,N)
!>          En la entrada, el triángulo superior o inferior de la matriz
!>          de banda hermítica A, almacenado en las primeras KD+1 filas
!>          del array.  La j-ésima columna de A se almacena en la j-ésima
!>          columna del array AB de la siguiente manera:
!>          si UPLO = 'U', AB(kd+1+i-j,j) = A(i,j) para max(1,j-kd)<=i<=j;
!>          si UPLO = 'L', AB(1+i-j,j)    = A(i,j) para j<=i<=min(n,j+kd).
!>          En la salida, los elementos diagonales de AB se sobrescriben
!>          con los elementos diagonales de la matriz tridiagonal T; si
!>          KD > 0, los elementos de la primera superdiagonal (si UPLO =
!>          'U') o de la primera subdiagonal (si UPLO = 'L') se
!>          sobrescriben con los elementos fuera de la diagonal de T; el
!>          resto de AB se sobrescribe con valores generados durante la
!>          reducción.
!
>

LDA

B 
!>          LDAB es INTEGER
!>          La dimensión principal del array AB.  LDAB >= KD+1.
!
>

D 
!>          D es un array REAL, dimensión (N)
!>          Los elementos diagonales de la matriz tridiagonal T.
!
>

E 
!>          E es un array REAL, dimensión (N-1)
!>          Los elementos fuera de la diagonal de la matriz tridiagonal T:
!>          E(i) = T(i,i+1) si UPLO = 'U'; E(i) = T(i+1,i) si UPLO = 'L'.
!
>

Q 
!>          Q es un array COMPLEX, dimensión (LDQ,N)
!>          En la entrada, si VECT = 'U', entonces Q debe contener una
!>          matriz X de N por N; si VECT = 'N' o 'V', entonces Q no
!>          necesita estar establecido.
!>
!>          En la salida:
!>          si VECT = 'V', Q contiene la matriz unitaria Q de N por N;
!>          si VECT = 'U', Q contiene el producto X*Q;
!>          si VECT = 'N', el array Q no se referencia.
!
>

LD

Q 
!>          LDQ es INTEGER
!>          La dimensión principal del array Q.
!>          LDQ >= 1, y LDQ >= N si VECT = 'V' o 'U'.
!
>

WOR

K 
!>          WORK es un array COMPLEX, dimensión (N)
!
>

INF

O 
!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!
>
