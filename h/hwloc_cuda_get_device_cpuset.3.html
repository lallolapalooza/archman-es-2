DESCRIPCIÓN DETALLADA

Esta interfaz ofrece formas de recuperar información de topología sobre dispositivos CUDA al utilizar la API del controlador CUDA.

DOCUMENTACIÓN DE FUNCIONES

int hwloc_cuda_get_device_cpuset (hwloc_topology_t topology, CUdevice cudevice, hwloc_cpuset_t set) [inline]

Obtiene el conjunto de CPU de procesadores que están físicamente cerca del dispositivo cudevice. Almacena en set el conjunto de CPU que describe la localidad del dispositivo CUDA cudevice.

La topología topology y el dispositivo cudevice deben corresponder a la máquina local. La detección de dispositivos de E/S y el componente CUDA no son necesarios en la topología.

La función solo devuelve la localidad del dispositivo. Si se necesita más información sobre el dispositivo, se deben usar objetos del SO en su lugar, ver hwloc_cuda_get_device_osdev() y hwloc_cuda_get_device_osdev_by_index().

Actualmente, esta función solo está implementada de manera significativa para Linux; otros sistemas simplemente obtendrán un cpuset completo.

Devuelve

0 si tiene éxito.

-1 si hay un error, por ejemplo, si no se pudo encontrar la información del dispositivo.

hwloc_obj_t hwloc_cuda_get_device_osdev (hwloc_topology_t topology, CUdevice cudevice) [inline]

Obtiene el objeto de dispositivo del SO de hwloc correspondiente al dispositivo CUDA cudevice.

Devuelve

El objeto de dispositivo del SO de hwloc que describe el dispositivo CUDA dado cudevice.

NULL si no se pudo encontrar ninguno.

La topología topology y el dispositivo cudevice deben corresponder a la máquina local. La detección de dispositivos de E/S y el componente CUDA deben estar habilitados en la topología. Si no es así, la localidad del objeto aún se puede encontrar usando hwloc_cuda_get_device_cpuset().

Nota

Esta función no puede funcionar si los dispositivos PCI están filtrados.

El objeto de dispositivo PCI de hwloc correspondiente se puede encontrar buscando en el puntero padre del resultado (a menos que los dispositivos PCI estén filtrados).

hwloc_obj_t hwloc_cuda_get_device_osdev_by_index (hwloc_topology_t topology, unsigned idx) [inline]

Obtiene el objeto de dispositivo del SO de hwloc correspondiente al dispositivo CUDA cuyo índice es idx.

Devuelve

El objeto de dispositivo del SO de hwloc que describe el dispositivo CUDA cuyo índice es idx.

NULL si no se pudo encontrar ninguno.

La topología topology no necesariamente tiene que corresponder a la máquina actual. Por ejemplo, la topología puede ser una importación XML de un host remoto. La detección de dispositivos de E/S y el componente CUDA deben estar habilitados en la topología.

Nota

El objeto de dispositivo PCI correspondiente se puede obtener buscando en el objeto padre del dispositivo del SO (a menos que los dispositivos PCI estén filtrados).

Esta función es idéntica a hwloc_cudart_get_device_osdev_by_index().

int hwloc_cuda_get_device_pci_ids (hwloc_topology_t topology, CUdevice cudevice, int * domain, int * bus, int * dev) [inline]

Devuelve los identificadores de dominio, bus y dispositivo del dispositivo CUDA cudevice. El dispositivo cudevice debe corresponder a la máquina local.

Devuelve

0 si tiene éxito.

-1 si hay un error, por ejemplo, si no se pudo encontrar la información del dispositivo.

hwloc_obj_t hwloc_cuda_get_device_pcidev (hwloc_topology_t topology, CUdevice cudevice) [inline]

Obtiene el objeto de dispositivo PCI de hwloc correspondiente al dispositivo CUDA cudevice.

Devuelve

El objeto de dispositivo PCI de hwloc que describe el dispositivo CUDA cudevice.

NULL si no se pudo encontrar ninguno.

La topología topology y el dispositivo cudevice deben corresponder a la máquina local. La detección de dispositivos de E/S debe estar habilitada en la topología topology. El componente CUDA no es necesario en la topología.
