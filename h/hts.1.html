HTS(1) Manual de comandos generales HTS(1)

NOMBRE

hts - servidor httptunnel

SINOPSIS

hts [opciones] [puerto]

DESCRIPCIÓN

Esta página del manual documenta brevemente el comando hts.

hts escucha las conexiones entrantes de httptunnel en el PUERTO (el puerto por defecto es 8888). Cuando se realiza una conexión, la E/S se redirige al destino especificado por el interruptor --device o --forward-port.

OPCIONES

El programa sigue la sintaxis habitual de línea de comandos de GNU, con opciones largas que comienzan con dos guiones (`-'). A continuación se incluye un resumen de las opciones.

-h, --help
Muestra un resumen de las opciones.
-c, --content-length BYTES
usa peticiones HTTP PUT de tamaño BYTES (se reconocen los sufijos k, M y G)
-d, --device DISPOSITIVO
usa DISPOSITIVO para entrada y salida
-F, --forward-port HOST:PUERTO
conéctate a PUERTO en HOST y úsalo para entrada y salida
-k, --keep-alive SEGUNDOS
envía bytes de mantenimiento cada SECUNDOS segundos (el valor por defecto es 5)
-M, --max-connection-age SEG
el tiempo máximo que una conexión permanecerá abierta es SEG segundos (el valor por defecto es 300)
-S, --strict-content-length
escribe siempre BYTES de Content-Length en las peticiones
-V, --version
muestra información de la versión y sale
-p, --pid-file UBICACIÓN
escribe un archivo PID en UBICACIÓN
