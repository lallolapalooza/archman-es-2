HXTOC(1) Utilidades HTML-XML HXTOC(1)

NOMBRE

hxtoc - inserta una tabla de contenido en un archivo HTML

SINOPSIS

hxtoc [ -x ] [ -l bajo ] [ -h alto ] [ -t ] [ -d ] [ -c clase ] [ -f ] [ archivo-o-URL ]

DESCRIPCIÓN

El comando hxtoc lee un archivo HTML, inserta atributos ID faltantes en todos los elementos H1 a H6 entre los niveles -l y -h (a menos que la opción -d esté activa, ver abajo). A menos que se dé la opción -t, también inserta elementos A con atributos NAME, porque los navegadores antiguos no reconocen los atributos ID como anclas de destino. La salida se escribe en stdout.

Si hay un comentario de la forma


<!--toc-->

o un par de comentarios


<!--begin-toc-->
...
<!--end-toc-->

entonces el comentario, o el par con todo lo que hay en medio, será reemplazado por una tabla de contenido, que consiste en una lista (UL) de enlaces a todas las cabeceras del documento.

El texto de las cabeceras se copia a esta tabla de contenido, incluyendo cualquier marca en línea, excepto que los atributos ID, las etiquetas DFN y las etiquetas SPAN con una CLASE de "index" se omiten (pero el contenido de los elementos se copia).

El texto copiado puede ser opcionalmente "aplanado" primero, ver opción -f.

Si una cabecera tiene un atributo CLASE con como valor (o uno de sus valores) la palabra clave "no-toc", entonces esa cabecera no aparecerá en la tabla de contenido.

OPCIONES

Se soportan las siguientes opciones:

-x
Usa convenciones XML: los elementos vacíos se escriben con una barra al final: <IMG />
-l bajo
Establece la cabecera numerada más baja que aparecerá en la tabla de contenido. Por defecto es 1 (es decir, H1).
-h alto
Establece la cabecera numerada más alta que aparecerá en la tabla de contenido. Por defecto es ilimitado.
-t
Normalmente, hxtoc añade tanto atributos ID como elementos A vacíos con un atributo NAME y CLASS="bctarget", para que los navegadores antiguos que no entienden ID todavía encuentren el objetivo. Con esta opción, los elementos A no se generarán.
-c clase
Los elementos UL generados en la tabla de contenido tendrán un atributo CLASE con el valor clase. El valor por defecto es "toc".
-d
Intenta usar elementos de sección como objetivos en la tabla de contenido en lugar de H1 a H6. Un elemento de sección es un elemento DIV, SECTION, ARTICLE, ASIDE o NAV que contiene al menos un elemento de encabezado (H1 a H6) o HGROUP. Al elemento de sección se le dará un ID si aún no lo tiene. Con esta opción, el nivel de cualquier H1 a H6 que sea la primera cabecera de un elemento de sección no se determina por su nombre, sino por la profundidad de anidamiento de los elementos de sección. (Cualquier H1 a H6 que no sea la primera cabecera de un elemento de sección todavía tiene su nivel implícito por su nombre.)
-f
Aplana el texto de la tabla de contenido. Sin -f, el contenido de los elementos de cabecera se copia a la tabla de contenido casi sin cambios, es decir, incluyendo cualquier elemento hijo y sus atributos (excepto los atributos ID, los elementos DFN y ciertas etiquetas SPAN, como se explicó anteriormente). Con -f, el contenido se aplana en su lugar: todos los elementos hijos se eliminan y solo se copia su contenido a la tabla de contenido. Además, los elementos con un atributo ALT, como IMG, se reemplazan por el contenido del atributo ALT. Excepción: las etiquetas BDO se copian sin cambios y los elementos con un atributo DIR se reemplazan por un SPAN con ese atributo DIR. (BDO y DIR pueden ocurrir en idiomas escritos de derecha a izquierda.)

OPERANDOS

Se soporta el siguiente operando:

archivo-o-URL
El nombre o URL de un archivo HTML. Si está ausente, se lee la entrada estándar en su lugar.

DIAGNÓSTICOS

Se devuelven los siguientes valores de salida:

0
Finalización exitosa.
> 0
Ocurrió un error en el análisis del archivo HTML. hxtoc intentará corregir el error y producir salida de todos modos.

VER TAMBIÉN

asc2xml(1), hxnormalize(1), hxnum(1), xml2asc(1)

ERRORES

La recuperación de errores para HTML incorrecto es primitiva.
