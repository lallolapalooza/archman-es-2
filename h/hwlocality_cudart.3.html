Descripción detallada

Esta interfaz ofrece formas de obtener información de topología sobre dispositivos CUDA al usar la API de CUDA Runtime.

Documentación de funciones

Obtiene el conjunto de CPU de procesadores que están físicamente cerca del dispositivo idx. Almacena en set el conjunto de CPU que describe la localidad del dispositivo CUDA cuyo índice es idx.

La topología topology y el dispositivo idx deben coincidir con la máquina local. La detección de dispositivos de E/S y el componente CUDA no son necesarios en la topología.

La función solo devuelve la localidad del dispositivo. Si se necesita más información sobre el dispositivo, se deben usar objetos del sistema operativo en su lugar, consulte hwloc_cudart_get_device_osdev_by_index().

Esta función está implementada actualmente de forma significativa solo para Linux; otros sistemas simplemente obtendrán un cpuset completo.

Devuelve

0 si tiene éxito.

-1 si hay un error, por ejemplo, si no se pudo encontrar la información del dispositivo.

hwloc_obj_t hwloc_cudart_get_device_osdev_by_index (hwloc_topology_t topology, unsigned idx) [inline]

Obtiene el objeto de dispositivo OS de hwloc correspondiente al dispositivo CUDA cuyo índice es idx.

Devuelve

El objeto de dispositivo OS de hwloc que describe el dispositivo CUDA cuyo índice es idx.

NULL si no se pudo encontrar ninguno.

La topología topology no necesita necesariamente coincidir con la máquina actual. Por ejemplo, la topología puede ser una importación XML de un host remoto. La detección de dispositivos de E/S y el componente CUDA deben estar habilitados en la topología. De lo contrario, la localidad del objeto aún puede encontrarse usando hwloc_cudart_get_device_cpuset().

Nota

El objeto de dispositivo PCI correspondiente se puede obtener examinando el objeto padre del dispositivo OS (a menos que los dispositivos PCI estén filtrados).

Esta función es idéntica a hwloc_cuda_get_device_osdev_by_index().

Devuelve los IDs de dominio, bus y dispositivo del dispositivo CUDA cuyo índice es idx. El índice de dispositivo idx debe coincidir con la máquina local.

Devuelve

0 si tiene éxito.

-1 si hay un error, por ejemplo, si no se pudo encontrar la información del dispositivo.

hwloc_obj_t hwloc_cudart_get_device_pcidev (hwloc_topology_t topology, int idx) [inline]

Obtiene el objeto de dispositivo PCI de hwloc correspondiente al dispositivo CUDA cuyo índice es idx.

Devuelve

El objeto de dispositivo PCI de hwloc que describe el dispositivo CUDA cuyo índice es idx.

NULL si no se pudo encontrar ninguno.

La topología topology y el dispositivo idx deben coincidir con la máquina local. La detección de dispositivos de E/S debe estar habilitada en la topología topology. El componente CUDA no es necesario en la topología.
