hwloc_const_cpuset_t hwloc_topology_get_allowed_cpuset (hwloc_topology_t topology)

Obtener el conjunto de CPU permitido.

Devuelve

el conjunto de CPU de los procesadores permitidos del sistema.

Nota

Esta función no puede devolver NULL.

Si el indicador de topología HWLOC_TOPOLOGY_FLAG_INCLUDE_DISALLOWED no se estableció, esto es idéntico a hwloc_topology_get_topology_cpuset(), lo que significa que todas las PU están permitidas.

Si se estableció HWLOC_TOPOLOGY_FLAG_INCLUDE_DISALLOWED, la aplicación de hwloc_bitmap_intersects() sobre el resultado de esta función y sobre el cpuset de un objeto verifica si hay PUs permitidas dentro de ese objeto. La aplicación de hwloc_bitmap_and() devuelve la lista de estas PUs permitidas.

El cpuset devuelto no se asigna de nuevo y, por lo tanto, no debe modificarse ni liberarse; se debe usar hwloc_bitmap_dup() para obtener una copia local.

hwloc_const_nodeset_t hwloc_topology_get_allowed_nodeset (hwloc_topology_t topology)

Obtener el conjunto de nodos permitido.

Devuelve

el conjunto de nodos de memoria permitida del sistema.

Nota

Esta función no puede devolver NULL.

Si el indicador de topología HWLOC_TOPOLOGY_FLAG_INCLUDE_DISALLOWED no se estableció, esto es idéntico a hwloc_topology_get_topology_nodeset(), lo que significa que todos los nodos NUMA están permitidos.

Si se estableció HWLOC_TOPOLOGY_FLAG_INCLUDE_DISALLOWED, la aplicación de hwloc_bitmap_intersects() sobre el resultado de esta función y sobre el nodeset de un objeto verifica si hay nodos NUMA permitidos dentro de ese objeto. La aplicación de hwloc_bitmap_and() devuelve la lista de estos nodos NUMA permitidos.

El nodeset devuelto no se asigna de nuevo y, por lo tanto, no debe modificarse ni liberarse; se debe usar hwloc_bitmap_dup() para obtener una copia local.

hwloc_const_cpuset_t hwloc_topology_get_complete_cpuset (hwloc_topology_t topology)

Obtener el conjunto completo de CPU.

Devuelve

el conjunto completo de CPU de los procesadores del sistema.

Nota

Esta función no puede devolver NULL.

El cpuset devuelto no se asigna de nuevo y, por lo tanto, no debe modificarse ni liberarse; se debe usar hwloc_bitmap_dup() para obtener una copia local.

Esto es equivalente a obtener el conjunto completo de CPU del objeto raíz.

hwloc_const_cpuset_t hwloc_topology_get_topology_cpuset (hwloc_topology_t topology)

Obtener el conjunto de CPU de la topología.

Devuelve

el conjunto de CPU de los procesadores del sistema para los que hwloc proporciona información de topología. Esto es equivalente al cpuset del objeto del sistema.

Nota

Esta función no puede devolver NULL.

El cpuset devuelto no se asigna de nuevo y, por lo tanto, no debe modificarse ni liberarse; se debe usar hwloc_bitmap_dup() para obtener una copia local.

Esto es equivalente a obtener el conjunto de CPU del objeto raíz.
