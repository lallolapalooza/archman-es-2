NOMBRE

hugin_lensdb - Herramienta para el mantenimiento de la base de datos de lentes

USO

hugin_lensdb [--recursive] --populate BASEPATH
Puebla la base de datos con información de todos los archivos pto en la BASEPATH dada. Con el interruptor --recursive se buscarán también todas las subcarpetas/directorios.
hugin_lensdb --compress
Comprime la base de datos reemplazando valores individuales con valores promediados.
hugin_lensdb --remove-lens=LENS
Elimina la lente dada de la base de datos.
hugin_lensdb --remove-camera=MAKER|MODEL
Elimina la cámara dada de la base de datos.
hugin_lensdb --export-database=FILENAME
Exporta datos de la base de datos a un archivo externo.
hugin_lensdb --import-from-file=FILENAME
Importa datos desde un archivo externo.
-h
Muestra la ayuda.
