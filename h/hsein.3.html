CHSEI

N

Propósito

: 
!>
!> CHSEIN usa iteración inversa para encontrar vectores propios derechos y/o
!> izquierdos especificados de una matriz Hessenberg superior compleja H.
!>
!> El vector propio derecho x y el vector propio izquierdo y de la matriz H
!> correspondientes a un valor propio w se definen por:
!>
!>              H * x = w * x,     y**h * H = w * y**h
!>
!> donde y**h denota la transpuesta conjugada del vector y.
!
>

Parámetro

s
SIDE 
!>          SIDE es CHARACTER*1
!>          = 'R': calcular solo vectores propios derechos;
!>          = 'L': calcular solo vectores propios izquierdos;
!>          = 'B': calcular tanto vectores propios derechos como izquierdos.
!
>

EIGSR

C 
!>          EIGSRC es CHARACTER*1
!>          Especifica la fuente de los valores propios suministrados en W:
!>          = 'Q': los valores propios se encontraron usando CHSEQR; por lo tanto, si
!>                 H tiene elementos subdiagonales cero, y por lo tanto es
!>                 triangular por bloques, se puede asumir que el j-ésimo valor propio
!>                 es un valor propio del bloque que contiene
!>                 la j-ésima fila/columna. Esta propiedad permite que CHSEIN
!>                 realice iteración inversa en un solo bloque diagonal.
!>          = 'N': no se hacen suposiciones sobre la correspondencia
!>                 entre valores propios y bloques diagonales. En este
!>                 caso, CHSEIN siempre debe realizar iteración inversa
!>                 usando toda la matriz H.
!
>

INIT

V 
!>          INITV es CHARACTER*1
!>          = 'N': no se suministran vectores iniciales;
!>          = 'U': los vectores iniciales suministrados por el usuario se almacenan en los arrays
!>                 VL y/o VR.
!
>

SELEC

T 
!>          SELECT es un array LOGICAL, dimensión (N)
!>          Especifica los vectores propios a calcular. Para seleccionar el
!>          vector propio correspondiente al valor propio W(j),
!>          SELECT(j) debe establecerse en .TRUE..
!
>

N 
!>          N es INTEGER
!>          El orden de la matriz H.  N >= 0.
!
>

H 
!>          H es un array COMPLEX, dimensión (LDH,N)
!>          La matriz Hessenberg superior H.
!>          Si se detecta un NaN en H, la rutina retornará con INFO=-6.
!
>

LD

H 
!>          LDH es INTEGER
!>          La dimensión principal del array H.  LDH >= max(1,N).
!
>

W 
!>          W es un array COMPLEX, dimensión (N)
!>          En la entrada, los valores propios de H.
!>          En la salida, las partes reales de W pueden haber sido alteradas ya que
!>          los valores propios cercanos se perturban ligeramente al buscar
!>          vectores propios independientes.
!
>

V

L 
!>          VL es un array COMPLEX, dimensión (LDVL,MM)
!>          En la entrada, si INITV = 'U' y SIDE = 'L' o 'B', VL debe
!>          contener vectores de inicio para la iteración inversa de los
!>          vectores propios izquierdos; el vector de inicio para cada vector propio
!>          debe estar en la misma columna en la que se almacenará
!>          el vector propio.
!>          En la salida, si SIDE = 'L' o 'B', los vectores propios izquierdos
!>          especificados por SELECT se almacenarán consecutivamente en las
!>          columnas de VL, en el mismo orden que sus valores propios.
!>          Si SIDE = 'R', VL no se referencia.
!
>

LDV

L 
!>          LDVL es INTEGER
!>          La dimensión principal del array VL.
!>          LDVL >= max(1,N) si SIDE = 'L' o 'B'; LDVL >= 1 en caso contrario.
!
>

V

R 
!>          VR es un array COMPLEX, dimensión (LDVR,MM)
!>          En la entrada, si INITV = 'U' y SIDE = 'R' o 'B', VR debe
!>          contener vectores de inicio para la iteración inversa de los
!>          vectores propios derechos; el vector de inicio para cada vector propio
!>          debe estar en la misma columna en la que se almacenará
!>          el vector propio.
!>          En la salida, si SIDE = 'R' o 'B', los vectores propios derechos
!>          especificados por SELECT se almacenarán consecutivamente en las
!>          columnas de VR, en el mismo orden que sus valores propios.
!>          Si SIDE = 'L', VR no se referencia.
!
>

LDV

R 
!>          LDVR es INTEGER
!>          La dimensión principal del array VR.
!>          LDVR >= max(1,N) si SIDE = 'R' o 'B'; LDVR >= 1 en caso contrario.
!
>

M

M 
!>          MM es INTEGER
!>          El número de columnas en los arrays VL y/o VR. MM >= M.
!
>

M 
!>          M es INTEGER
!>          El número de columnas en los arrays VL y/o VR requeridas para
!>          almacenar los vectores propios (= el número de elementos .TRUE. en
!>          SELECT).
!
>

WOR

K 
!>          WORK es un array COMPLEX, dimensión (N*N)
!
>

RWOR

K 
!>          RWORK es un array REAL, dimensión (N)
!
>

IFAIL

L 
!>          IFAILL es un array INTEGER, dimensión (MM)
!>          Si SIDE = 'L' o 'B', IFAILL(i) = j > 0 si el vector propio
!>          izquierdo en la i-ésima columna de VL (correspondiente al
!>          valor propio w(j)) falló en converger; IFAILL(i) = 0 si el
!>          vector propio convergió satisfactoriamente.
!>          Si SIDE = 'R', IFAILL no se referencia.
!
>

IFAIL

R 
!>          IFAILR es un array INTEGER, dimensión (MM)
!>          Si SIDE = 'R' o 'B', IFAILR(i) = j > 0 si el vector propio
!>          derecho en la i-ésima columna de VR (correspondiente al
!>          valor propio w(j)) falló en converger; IFAILR(i) = 0 si el
!>          vector propio convergió satisfactoriamente.
!>          Si SIDE = 'L', IFAILR no se referencia.
!
>

INF

O 
!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>          > 0:  si INFO = i, i es el número de vectores propios que
!>                fallaron en converger; ver IFAILL e IFAILR para más
!>                detalles.
!
>

Propósito

: 
!>
!> ZHSEIN usa iteración inversa para encontrar autovectores derechos y/o izquierdos
!> especificados de una matriz Hessenberg superior compleja H.
!>
!> El autovector derecho x y el autovector izquierdo y de la matriz H
!> correspondientes a un autovalor w se definen por:
!>
!>              H * x = w * x,     y**h * H = w * y**h
!>
!> donde y**h denota la transpuesta conjugada del vector y.
!
>

Parámetro

s
SIDE 
!>          SIDE es CHARACTER*1
!>          = 'R': calcular solo autovectores derechos;
!>          = 'L': calcular solo autovectores izquierdos;
!>          = 'B': calcular tanto autovectores derechos como izquierdos.
!
>

EIGSR

C 
!>          EIGSRC es CHARACTER*1
!>          Especifica el origen de los autovalores proporcionados en W:
!>          = 'Q': los autovalores se encontraron usando ZHSEQR; así, si
!>                 H tiene elementos subdiagonales cero, y por lo tanto es
!>                 triangular por bloques, entonces se puede asumir que el
!>                 j-ésimo autovalor es un autovalor del bloque que contiene
!>                 la j-ésima fila/columna. Esta propiedad permite que ZHSEIN
!>                 realice iteración inversa en solo un bloque diagonal.
!>          = 'N': no se hacen suposiciones sobre la correspondencia
!>                 entre autovalores y bloques diagonales. En este
!>                 caso, ZHSEIN siempre debe realizar iteración inversa
!>                 usando toda la matriz H.
!
>
