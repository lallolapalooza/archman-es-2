la clave para generar un hash

la longitud de la clave sin ningún byte nulo de terminación

DESCRIPCIÓN

Estas funciones se utilizan para establecer y recuperar las funciones hash de clave y de distribución.

VALOR DE RETORNO

hashkit_set_function(), hashkit_set_custom_function() y los equivalentes de distribución devuelven hashkit_return_t::HASHKIT_SUCCESS en caso de éxito.

hashkit_get_function() y hashkit_get_distribution_function() devuelven hashkit_hash_algorithm_t indicando la función hash utilizada.
