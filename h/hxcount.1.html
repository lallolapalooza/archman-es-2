HXCOUNT(1) Utilidades HTML-XML HXCOUNT(1)

NOMBRE

hxcount - cuenta elementos y atributos en archivos HTML o XML

SINOPSIS

hxcount [ archivo-o-URL ]

DESCRIPCIÓN

El comando hxcount cuenta el número de elementos y atributos de cada tipo que aparece en la entrada y imprime un informe en stdout.

OPERANDOS

Se soporta el siguiente operando:

archivo-o-URL
El nombre o URL de un archivo HTML o XML. Si está ausente, se lee la entrada estándar en su lugar.

ESTADO DE SALIDA

Se devuelven los siguientes valores de salida:

0
Finalización exitosa.
> 0
Ocurrió un error en el análisis del archivo HTML o XML. hxcount intentará recuperarse del error y producirá una salida de todos modos.

ENTORNO

Para usar un proxy para recuperar archivos remotos, configure las variables de entorno http_proxy y ftp_proxy. Por ejemplo, http_proxy="http://localhost:8080/"

ERRORES CONOCIDOS

No confíe en la salida si hubo errores en la entrada.

Los archivos remotos (especificados con una URL) actualmente solo se admiten para HTTP. No se manejan archivos protegidos con contraseña o archivos que dependen de las "cookies" HTTP. (Puede usar herramientas como curl(1) o wget(1) para recuperar dichos archivos.)

VER TAMBIÉN
