Documentación de la Función

subrutina cher2 (carácter uplo, entero n, complejo alpha, complejo, dimensión(*) x, entero incx, complejo, dimensión(*) y, entero incy, complejo, dimensión(lda,*) a, entero lda)

CHER2

Propósito:

!>
!> CHER2 realiza la operación hermítica de rango 2
!>
!>    A := alpha*x*y**H + conjg( alpha )*y*x**H + A,
!>
!> donde alpha es un escalar, x e y son vectores de n elementos y A es una
!> matriz hermítica de n por n.
!>

Parámetros

UPLO 
!>          UPLO es CARACTER*1
!>           A la entrada, UPLO especifica si la parte triangular superior o
!>           inferior del array A se va a referenciar como
!>           sigue:
!>
!>              UPLO = 'U' o 'u'   Sólo se referencia la parte triangular
!>                                  superior de A.
!>
!>              UPLO = 'L' o 'l'   Sólo se referencia la parte triangular
!>                                  inferior de A.
!>

N

!>          N es ENTERO
!>           A la entrada, N especifica el orden de la matriz A.
!>           N debe ser al menos cero.
!>

ALPHA

!>          ALPHA es COMPLEJO
!>           A la entrada, ALPHA especifica el escalar alpha.
!>

X

!>          X es un array COMPLEJO, de dimensión al menos
!>           ( 1 + ( n - 1 )*abs( INCX ) ).
!>           Antes de la entrada, el array incrementado X debe contener el
!>           vector x de n elementos.
!>

INCX

!>          INCX es ENTERO
!>           A la entrada, INCX especifica el incremento para los elementos de
!>           X. INCX no debe ser cero.
!>

Y

!>          Y es un array COMPLEJO, de dimensión al menos
!>           ( 1 + ( n - 1 )*abs( INCY ) ).
!>           Antes de la entrada, el array incrementado Y debe contener el
!>           vector y de n elementos.
!>

INCY

!>          INCY es ENTERO
!>           A la entrada, INCY especifica el incremento para los elementos de
!>           Y. INCY no debe ser cero.
!>

A

!>          A es un array COMPLEJO, de dimensión ( LDA, N )
!>           Antes de la entrada con UPLO = 'U' o 'u', la parte triangular
!>           superior líder de n por n del array A debe contener la parte
!>           triangular superior de la matriz hermítica y la parte
!>           triangular estrictamente inferior de A no se referencia. A la
!>           salida, la parte triangular superior del array A se sobrescribe
!>           con la parte triangular superior de la matriz actualizada.
!>           Antes de la entrada con UPLO = 'L' o 'l', la parte triangular
!>           inferior líder de n por n del array A debe contener la parte
!>           triangular inferior de la matriz hermítica y la parte
!>           triangular estrictamente superior de A no se referencia. A la
!>           salida, la parte triangular inferior del array A se sobrescribe
!>           con la parte triangular inferior de la matriz actualizada.
!>           Tenga en cuenta que las partes imaginarias de los elementos
!>           diagonales no necesitan estar establecidas, se asumen cero, y a
!>           la salida se establecen a cero.
!>

LDA

!>          LDA es ENTERO
!>           A la entrada, LDA especifica la primera dimensión de A tal como
!>           está declarada en el programa (sub)llamador. LDA debe ser al
!>           menos max( 1, n ).
!>
