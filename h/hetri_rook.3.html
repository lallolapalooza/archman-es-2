subrutina zhetri_rook (character uplo, integer n, complex*16, dimension( lda, * ) a, integer lda, integer, dimension( * ) ipiv, complex*16, dimension( * ) work, integer info)

ZHETRI_ROOK calcula la inversa de una matriz HE utilizando la factorización obtenida con el método de pivoteo diagonal acotado de Bunch-Kaufman ("rook").

Propósito:

!>
!> ZHETRI_ROOK calcula la inversa de una matriz Hermítica compleja indefinida
!> A utilizando la factorización A = U*D*U**H o A = L*D*L**H calculada por
!> ZHETRF_ROOK.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          Especifica si los detalles de la factorización se almacenan
!>          como una matriz triangular superior o inferior.
!>          = 'U':  Triangular superior, la forma es A = U*D*U**H;
!>          = 'L':  Triangular inferior, la forma es A = L*D*L**H.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

A

!>          A es un array COMPLEX*16, de dimensión (LDA,N)
!>          En la entrada, la matriz diagonal por bloques D y los multiplicadores
!>          utilizados para obtener el factor U o L, tal como fueron calculados por ZHETRF_ROOK.
!>
!>          En la salida, si INFO = 0, la inversa (Hermítica) de la matriz original.
!>          Si UPLO = 'U', se forma la parte triangular superior de la inversa y la parte de A
!>          debajo de la diagonal no se referencia; si UPLO = 'L', se forma la parte triangular
!>          inferior de la inversa y la parte de A por encima de la diagonal no se referencia.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

IPIV

!>          IPIV es un array INTEGER, de dimensión (N)
!>          Detalles de los intercambios y la estructura de bloques de D
!>          tal como fueron determinados por ZHETRF_ROOK.
!>

WORK

!>          WORK es un array COMPLEX*16, de dimensión (N)
!>

INFO

!>          INFO es INTEGER
!>          = 0: salida exitosa
!>          < 0: si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>          > 0: si INFO = i, D(i,i) = 0; la matriz es singular y su
!>               inversa no pudo ser calculada.
!>
