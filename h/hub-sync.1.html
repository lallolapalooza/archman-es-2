NOMBRE

hub-sync - Obtener objetos git de upstream y actualizar ramas locales.

SINOPSIS

hub sync [--color]

  • Si la rama local está desactualizada, avance rápido;
  • Si la rama local contiene trabajo no enviado (unpushed), advierte sobre ello;
  • Si la rama parece fusionada y su rama upstream fue eliminada, elimínela.

Si una rama local no tiene ninguna configuración upstream, pero tiene una rama con el mismo nombre en el remoto, trátela como su rama upstream.

OPCIONES

--color[=CUÁNDO]

Habilita la salida coloreada incluso si la salida estándar no es una terminal. CUÁNDO puede ser uno de "always" (siempre, valor por defecto para --color), "never" (nunca), o "auto" (automático, por defecto).
