Función

subrutina chetf2 (character uplo, integer n, complex, dimension( lda, * ) a, integer lda, integer, dimension( * ) ipiv, integer

info)

CHETF2 calcula la factorización de una matriz hermitiana compleja, usando el método de pivoteo diagonal (algoritmo sin bloqueo que llama a BLAS de Nivel 2)

.

Propósito

: 
!>
!> CHETF2 calcula la factorización de una matriz hermitiana compleja A
!> usando el método de pivoteo diagonal de Bunch-Kaufman:
!>
!>    A = U*D*U**H  o  A = L*D*L**H
!>
!> donde U (o L) es un producto de matrices de permutación y triangulares
!> unitarias superiores (inferiores), U**H es la transpuesta conjugada de U, y D es
!> hermitiana y bloque diagonal con bloques diagonales de 1x1 y 2x2.
!>
!> Esta es la versión sin bloqueo del algoritmo, llamando a BLAS de Nivel 2.
!
>

Parámetro

s
UPLO 
!>          UPLO es CHARACTER*1
!>          Especifica si se almacena la parte triangular superior o inferior de la
!>          matriz hermitiana A:
!>          = 'U':  Triangular superior
!>          = 'L':  Triangular inferior
!
>

N 
!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!
>

A 
!>          A es un arreglo COMPLEX, dimensión (LDA,N)
!>          En la entrada, la matriz hermitiana A.  Si UPLO = 'U', la parte
!>          triangular superior n x n principal de A contiene la parte
!>          triangular superior de la matriz A, y la parte estrictamente inferior
!>          de A no se referencia.  Si UPLO = 'L', la parte
!>          triangular inferior n x n principal de A contiene la parte
!>          triangular inferior de la matriz A, y la parte estrictamente superior
!>          de A no se referencia.
!>
!>          En la salida, la matriz bloque diagonal D y los multiplicadores usados
!>          para obtener el factor U o L (ver más abajo para más detalles).
!
>

LD

A 
!>          LDA es INTEGER
!>          La dimensión principal del arreglo A.  LDA >= max(1,N).
!
>

IPI

V 
!>          IPIV es un arreglo INTEGER, dimensión (N)
!>          Detalles de los intercambios y la estructura de bloque de D.
!>
!>          Si UPLO = 'U':
!>             Si IPIV(k) > 0, entonces las filas y columnas k e IPIV(k) fueron
!>             intercambiadas y D(k,k) es un bloque diagonal de 1x1.
!>
!>             Si IPIV(k) = IPIV(k-1) < 0, entonces las filas y columnas
!>             k-1 e -IPIV(k) fueron intercambiadas y D(k-1:k,k-1:k)
!>             es un bloque diagonal de 2x2.
!>
!>          Si UPLO = 'L':
!>             Si IPIV(k) > 0, entonces las filas y columnas k e IPIV(k) fueron
!>             intercambiadas y D(k,k) es un bloque diagonal de 1x1.
!>
!>             Si IPIV(k) = IPIV(k+1) < 0, entonces las filas y columnas
!>             k+1 e -IPIV(k) fueron intercambiadas y D(k:k+1,k:k+1)
!>             es un bloque diagonal de 2x2.
!
>

INF

O 
!>          INFO es INTEGER
!>          = 0: salida exitosa
!>          < 0: si INFO = -k, el k-ésimo argumento tenía un valor ilegal
!>          > 0: si INFO = k, D(k,k) es exactamente cero.  La factorización
!>               ha sido completada, pero la matriz bloque diagonal D es
!>               exactamente singular, y ocurrirá una división por cero si se
!>               usa para resolver un sistema de ecuaciones.
!
>

subroutine   zsytf2 (character uplo, integer n, complex*16, dimension( lda, * ) a, integer   lda, integer, dimension( * ) ipiv, integer 
info)

ZSYTF2 calcula la factorización de una matriz simétrica
    real indefinida, usando el método de pivoteo diagonal (algoritmo
  sin bloquear)
.

Propósito
:



!>
!> ZSYTF2 calcula la factorización de una matriz simétrica compleja A
!> usando el método de pivoteo diagonal de Bunch-Kaufman:
!>
!>    A = U*D*U**T  o  A = L*D*L**T
!>
!> donde U (o L) es un producto de matrices de permutación y triangulares
!> superiores (inferiores) unitarias, U**T es la transpuesta de U, y D es
!> simétrica y diagonal por bloques con bloques diagonales de tamaño
!> 1x1 y 2x2.
!>
!> Esta es la versión sin bloquear del algoritmo, que llama a BLAS de
!> Nivel 2.

!
>

Parámetro
s

UPLO

!>          UPLO es CHARACTER*1
!>          Especifica si se almacena la parte triangular superior o
!>          inferior de la matriz simétrica A:
!>          = 'U':  Triangular superior
!>          = 'L':  Triangular inferior
!
>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!
>

A

!>          A es un array COMPLEX*16, dimensión (LDA,N)
!>          En la entrada, la matriz simétrica A.  Si UPLO = 'U', la
!>          parte triangular superior n x n principal de A contiene la
!>          parte triangular superior de la matriz A, y la parte
!>          triangular inferior estricta de A no se referencia.  Si
!>          UPLO = 'L', la parte triangular inferior n x n principal de A
!>          contiene la parte triangular inferior de la matriz A, y la
!>          parte triangular superior estricta de A no se referencia.
!>
!>          En la salida, la matriz diagonal por bloques D y los
!>          multiplicadores usados para obtener el factor U o L (ver
!>          más abajo para más detalles).
!
>

LD
A

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!
>

IPI
V

!>          IPIV es un array INTEGER, dimensión (N)
!>          Detalles de los intercambios y la estructura por bloques de D.
!>
!>          Si UPLO = 'U':
!>             Si IPIV(k) > 0, entonces las filas y columnas k e IPIV(k)
!>             fueron intercambiadas y D(k,k) es un bloque diagonal 1x1.
!>
!>             Si IPIV(k) = IPIV(k-1) < 0, entonces las filas y columnas
!>             k-1 y -IPIV(k) fueron intercambiadas y D(k-1:k,k-1:k)
!>             es un bloque diagonal 2x2.
!>
!>          Si UPLO = 'L':
!>             Si IPIV(k) > 0, entonces las filas y columnas k e IPIV(k)
!>             fueron intercambiadas y D(k,k) es un bloque diagonal 1x1.
!>
!>             Si IPIV(k) = IPIV(k+1) < 0, entonces las filas y columnas
!>             k+1 y -IPIV(k) fueron intercambiadas y D(k:k+1,k:k+1)
!>             es un bloque diagonal 2x2.
!
>

INF
O

!>          INFO es INTEGER
!>          = 0: salida exitosa
!>          < 0: si INFO = -k, el k-ésimo argumento tenía un valor ilegal
!>          > 0: si INFO = k, D(k,k) es exactamente cero.  La
!>               factorización se ha completado, pero la matriz diagonal
!>               por bloques D es exactamente singular, y ocurrirá una
!>               división por cero si se usa para resolver un sistema de
!>               ecuaciones.

!
