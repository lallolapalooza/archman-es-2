HNSDV_IS_SUPPORTED(3) Manual del programador de HNS HNSDV_IS_SUPPORTED(3)

NOMBRE

hnsdv_is_supported - Comprueba si un dispositivo RDMA está implementado por el proveedor hns

SINOPSIS

#include <infiniband/hnsdv.h>
bool hnsdv_is_supported(struct ibv_device *device);

DESCRIPCIÓN

Las funciones hnsdv solo se pueden llamar si esta función devuelve true para el dispositivo RDMA.

ARGUMENTOS

device
Dispositivo RDMA a comprobar.

VALOR DE RETORNO

Devuelve true si el dispositivo está implementado por el proveedor hns.
