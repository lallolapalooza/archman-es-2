HLEDGER-UI(1) Manuales de usuario de hledger HLEDGER-UI(1)

NOMBRE

hledger-ui - interfaz de terminal (TUI) para hledger, una aplicación de contabilidad robusta y amigable en texto plano.

SINOPSIS

hledger-ui [OPCIONES] [ARGUMENTOS-CONSULTA]

o

hledger ui [OPCIONES] [ARGUMENTOS-CONSULTA]

DESCRIPCIÓN

Este manual es para la interfaz de terminal de hledger, versión 1.51. Consulte también el manual de hledger para conceptos comunes y formatos de archivo.

hledger es un conjunto de programas robusto, fácil de usar y multiplataforma para rastrear dinero, tiempo o cualquier otro producto, utilizando contabilidad por partida doble y un formato de archivo simple y editable. hledger está inspirado y es en gran medida compatible con ledger(1), y en gran medida interconvertible con beancount(1).

hledger-ui es la interfaz de terminal de hledger, que proporciona una interfaz de texto eficiente a pantalla completa para ver cuentas y transacciones, y algunas capacidades limitadas de entrada de datos. Es más fácil que la interfaz de línea de comandos de hledger, y a veces más rápida y conveniente que la interfaz web.

Al igual que hledger, lee desde (y añade a) un archivo de diario especificado por la variable de entorno LEDGER_FILE (con un valor predeterminado de $HOME/.hledger.journal); o puede especificar archivos con las opciones -f. También puede leer archivos timeclock, timedot o cualquier archivo CSV/SSV/TSV con un campo de fecha. (Ver hledger(1) -> Entrada para más detalles).

A diferencia de hledger, hledger-ui oculta todas las transacciones con fecha futura por defecto. Pueden mostrarse, junto con cualquier transacción periódica generada por reglas, al presionar la tecla F (o al iniciar con --forecast) para habilitar el "modo de pronóstico".

OPCIONES

Cualquier argumento se interpreta como una consulta de hledger que filtra los datos. hledger-ui proporciona las siguientes opciones:

Flags:
  -w --watch                observar cambios en datos y fechas y recargar
                            automáticamente
     --theme=TEMA           usar este tema de visualización personalizado (default,
                            greenterm, terminal, dark)
     --cash                 iniciar en la pantalla de cuentas de efectivo
     --bs                   iniciar en la pantalla de cuentas del balance general
     --is                   iniciar en la pantalla de cuentas del estado de resultados
     --all                  iniciar en la pantalla de todas las cuentas
     --register=EXPREGACT   iniciar en el registro de la cuenta (primera coincidencia)
     --change               mostrar saldos de período (cambios) al inicio en lugar
                            de saldos históricos
  -l --flat                 mostrar cuentas como una lista plana (predeterminado)
  -t --tree                 mostrar cuentas como un árbol

y también admite muchas de las opciones generales de hledger:

Flags generales de transformación de entrada/datos:
  -f --file=[FMT:]ARCHIVO      Leer datos del ARCHIVO, o desde la entrada estándar si ARCHIVO es -,
                            infiriendo el formato de la extensión o de un prefijo FMT:.
                            Se puede especificar más de una vez. Si no se especifica,
                            lee de $LEDGER_FILE o $HOME/.hledger.journal.
     --rules=ARCHIVREGLAS      Usar reglas definidas en este archivo de reglas para
                            convertir archivos CSV/SSV/TSV subsiguientes. Si no se especifica,
                            usa FILE.csv.rules para cada FILE.csv.
     --alias=A=B|/RGX/=RPL  transformar nombres de cuentas de A a B, o reemplazando
                            coincidencias de expresiones regulares
     --auto                 generar asientos adicionales aplicando reglas de asiento automático
                            ("=") a todas las transacciones
     --forecast[=PERIODO]    Generar transacciones adicionales de reglas periódicas
                            ("~"), desde después de la última transacción ordinaria
                            hasta dentro de 6 meses. O, durante el PERIODO especificado
                            (el igual es requerido). Las reglas de asiento automático
                            también se aplicarán a estas transacciones. En
                            hledger-ui, también hacer visibles las transacciones con fecha futura
                            al inicio.
  -I --ignore-assertions    no verificar aserciones de saldo por defecto
     --txn-balancing=...    cómo verificar que las transacciones estén balanceadas:
                            'old':   usar precisión de visualización global
                            'exact': usar precisión de transacción (predeterminado)
     --infer-costs          inferir asientos de capital de conversión a partir de costos
     --infer-equity         inferir costos a partir de asientos de capital de conversión
     --infer-market-prices  inferir precios de mercado a partir de costos
     --pivot=NOMBRETAG      usar un campo o etiqueta diferente como nombres de cuenta
  -s --strict               realizar verificaciones de errores adicionales (y anular -I)
     --verbose-tags         agregar etiquetas que indiquen datos generados/modificados
Flags generales de salida/informes (soportados por algunos comandos):
  -b --begin=FECHA          incluir asientos/transacciones en/después de esta fecha
  -e --end=FECHA            incluir asientos/transacciones antes de esta fecha
                            (con un intervalo de informe, se ajustará a
                            fin de subperíodo siguiente)
  -D --daily                informe multiperíodo con intervalo de 1 día
  -W --weekly               informe multiperíodo con intervalo de 1 semana
  -M --monthly              informe multiperíodo con intervalo de 1 mes
  -Q --quarterly            informe multiperíodo con intervalo de 1 trimestre
  -Y --yearly               informe multiperíodo con intervalo de 1 año
  -p --period=EXPPERIODO    establecer fecha de inicio, fecha de fin y/o intervalo de informe,
                            con más flexibilidad
     --today=FECHA          anular la fecha de hoy (afecta a las fechas relativas)
     --date2                usar/emparejar fechas secundarias en su lugar (obsoleto)
  -U --unmarked             incluir solo asientos/transacciones sin marcar
  -P --pending              incluir solo asientos/transacciones pendientes
  -C --cleared              incluir solo asientos/transacciones compensadas
                            (-U/-P/-C se pueden combinar)
  -R --real                 incluir solo asientos no virtuales
  -E --empty                Mostrar elementos cero, que normalmente están ocultos.
                            En hledger-ui & hledger-web, haz lo contrario.
     --depth=EXPDATOS       si un número (o -NUM): mostrar solo los NUM niveles superiores
                            de cuentas. Si REGEXP=NUM, solo aplicar el límite a
                            cuentas que coincidan con la expresión regular.
  -B --cost                 mostrar importes convertidos a su importe de costo/venta
  -V --market               Mostrar importes convertidos a su valor al final de período(s)
                            en su producto de valoración predeterminado.
                            Equivalente a --value=end.
  -X --exchange=PROD        Mostrar importes convertidos a su valor al final de período(s)
                            en el producto especificado.
                            Equivalente a --value=end,PROD.
     --value=CUANDO[,PROD]  mostrar importes convertidos a su valor en las
                            fechas especificadas en su producto de valoración
                            predeterminado o un producto especificado. CUANDO puede ser:
                            'then':     valor en las fechas de transacción
                            'end':      valor al final(es) del período
                            'now':      valor hoy
                            AAAA-MM-DD: valor en la fecha dada
  -c --commodity-style=S    anular el estilo de visualización de un producto.
                            Ej: -c '.' o -c '1.000,00 EUR'
     --pretty[=YN]          ¿Usar caracteres de dibujo de caja en la salida de texto? Puede ser
                            's'/'sí' o 'n'/'no'.
                            Si se especifica YN, se requiere el igual.
Flags generales de ayuda:
  -h --help                 mostrar ayuda de la línea de comandos
     --tldr                 mostrar ejemplos de comandos con tldr
     --info                 mostrar el manual con info
     --man                  mostrar el manual con man
     --version              mostrar información de la versión
     --debug=[1-9]          mostrar esta cantidad de salida de depuración (predeterminado: 1)
     --pager=YN             usar un paginador cuando sea necesario? s/sí (predeterminado) o n/no
     --color=YNA --colour   usar color ANSI? s/sí, n/no, o auto (predeterminado)

Con hledger-ui, la opción --debug envía la salida de depuración a un archivo hledger-ui.log en el directorio actual.

Si usas el shell bash, puedes autocompletar flags presionando TAB en la línea de comandos. Si esto no funciona, consulta Instalación > Completado del shell.

RATÓN

En la mayoría de las terminales modernas, puedes navegar por las pantallas con un ratón o un panel táctil:

•
Usa la rueda del ratón o el panel táctil para desplazarte hacia arriba y hacia abajo
•
Haz clic en los elementos de la lista para profundizar
•
Haz clic en el margen izquierdo (columna 0) para volver atrás.

TECLAS

Este sitio no está asociado de ninguna forma con Arch Linux ni afiliado a este proyecto. El contenido es únicamente una traducción de las páginas del manual de Arch publicadas en man.archlinux.org.

S

El teclado ofrece más control.

? muestra un cuadro de diálogo de ayuda que lista todas las teclas. (Algunas de estas también aparecen en la ayuda rápida en la parte inferior de cada pantalla.) Presiona ? de nuevo (o ESCAPE, o LEFT, o q) para cerrarlo. Las siguientes teclas funcionan en la mayoría de las pantallas:

Las teclas de cursor navegan: RIGHT o ENTER va más profundo, LEFT vuelve a la pantalla anterior, UP/DOWN/PGUP/PGDN/HOME/END se mueven hacia arriba y hacia abajo a través de las listas. También se admiten teclas de movimiento estilo Emacs (CTRL-p/CTRL-n/CTRL-f/CTRL-b) y estilo VI (k,j,l,h) .

(Consejo: la velocidad de movimiento está limitada por la tasa de repetición de tu teclado; para moverte más rápido, es posible que desees ajustarla. En una mac, la aplicación Karabiner es una forma de hacerlo.)

/ te permite establecer una consulta de filtro general que limita los datos mostrados, usando los mismos términos de consulta que en hledger y hledger-web. Mientras editas la consulta, puedes usar CTRL-a/e/d/k, BS, teclas de cursor; presiona ENTER para establecerla, o ESCAPEpara cancelarla. También hay teclas para ajustar rápidamente algunos filtros comunes como la profundidad de cuenta y el estado de la transacción (ver más abajo). BACKSPACE o DELETE elimina todos los filtros, mostrando todas las transacciones.

Como se mencionó anteriormente, por defecto hledger-ui oculta las transacciones futuras: tanto las transacciones ordinarias registradas en el diario como las transacciones periódicas generadas por regla. F alterna el modo de pronóstico, en el cual se muestran las transacciones futuras/pronosticadas.

Presionar SHIFT-DOWN estrecha el período del informe, y presionar SHIFT-UP lo expande de nuevo. Cuando está estrechado, el período actual del informe se muestra en la línea de encabezado; presionar SHIFT-LEFT o SHIFT-RIGHT se mueve al período anterior o siguiente, y presionar T establece el período como "hoy". Si estás usando -w/--watch y viendo un período estrechado que contiene hoy, la vista seguirá cualquier cambio en la fecha del sistema (moviéndose al período que contiene la nueva fecha). (Estas teclas solo funcionan con los períodos estándar de año/trimestre/mes/semana/día del calendario juliano; no se ven afectadas por un intervalo de informe personalizado especificado en la línea de comandos.)

También puedes especificar un período no estándar con / y una consulta date: ; en este caso, el período no es movible con las teclas de flecha.

(Consejo: las teclas de flecha con Shift no funcionan de forma predeterminada en todo software de terminal. Por ejemplo, en la Terminal de Apple, las teclas SHIFT-DOWN y SHIFT-UP deben configurarse de la siguiente manera: en las preferencias de Terminal, haz clic en Perfiles, selecciona tu perfil actual a la derecha, haz clic en Teclado a la derecha, haz clic en + y agrega esto para SHIFT-DOWN: \033[1;2B, haz clic en + y agrega esto para SHIFT-UP: \033[1;2A. En otras terminales (¿Windows Terminal?) podrías necesitar configurar SHIFT-RIGHT y SHIFT-LEFT para emitir \033[1;2C y \033[1;2D respectivamente.)

ESCAPE restablece el estado de la interfaz y salta de vuelta a la pantalla superior, restaurando el estado inicial de la aplicación al inicio. O, cancela la entrada de datos del minibuffer o el cuadro de diálogo de ayuda.

CTRL-l redibuja la pantalla y centra la selección si es posible (las selecciones cerca de la parte superior no se centrarán, ya que no hacemos scroll por encima de la parte superior).

g recarga desde el/los archivo(s) de datos y actualiza la pantalla actual y cualquier pantalla anterior. (Con archivos grandes, esto podría causar una pausa notable.)

I alterna la verificación de aserciones de saldo. Deshabilitar temporalmente las aserciones de saldo puede ser útil para la resolución de problemas. (Si hledger-ui se inició con una opción --pivot , volver a habilitar las aserciones de saldo con la tecla I también recarga el diario, como g.)

a ejecuta el comando add de hledger de la línea de comandos, y recarga el archivo actualizado. Esto permite alguna entrada de datos básica.

A es como a, pero ejecuta la herramienta hledger-iadd, que proporciona una interfaz de terminal. Esta tecla estará disponible si hledger-iadd está instalado en $path.

E ejecuta $HLEDGER_UI_EDITOR, o $EDITOR, o uno predeterminado (emacsclient -a "" -nw) en el archivo del diario. Con algunos editores (emacs, vi), el cursor se posicionará en la transacción actual cuando se invoque desde las pantallas de registro y transacción, y en la ubicación del error (si es posible) cuando se invoque desde la pantalla de error.

B alterna el modo de costo, mostrando montos convertidos a la moneda de su costo (ver manual de hledger > Informe de costos).

V alterna el modo de valor, mostrando montos convertidos a su valor de mercado (ver manual de hledger > Indicador de valoración). Más específicamente,

1.
Por defecto, la tecla V alterna mostrar el valor final (--value=end) activado o desactivado. La fecha de valoración será la fecha de fin del informe si se especifica, de lo contrario hoy.
2.
Si iniciaste hledger-ui con alguna otra valoración (como --value=then,EUR), la tecla V la alterna desactivada o activada.

Consejos de costo/valor: - Al mostrar el valor final, puedes cambiar la fecha de fin del informe sin reiniciar, presionando / y agregando una consulta como date:..YYYY-MM-DD. - Tanto el modo de costo como el modo de valor pueden estar activos, pero no ambos a la vez. El modo de costo tiene precedencia. - Aún no hay ningún indicador visual de que el modo de costo o valor esté activo, aparte de los valores de los montos.

q sale de la aplicación.

Las teclas adicionales específicas de pantalla se describen a continuación.

PANTALLAS

Al inicio, hledger-ui muestra una pantalla de menú por defecto. Desde aquí puedes navegar a otras pantallas usando las teclas de cursor: UP/DOWN para seleccionar, RIGHT para moverte a la pantalla seleccionada, LEFT para volver a la pantalla anterior. O puedes usar ESC para volver directamente a la pantalla de menú superior.

También puedes usar un indicador de línea de comandos para especificar una pantalla de inicio diferente (--cs, --bs, --is, --all, o --register=ACCT).

Pantalla de menú

Esta es la pantalla más superior. Desde aquí puedes navegar a varias pantallas que listan cuentas de varios tipos. Ten en cuenta que algunas de estas pueden no mostrar nada hasta que hayas configurado los tipos de cuenta.

Pantalla de cuentas de efectivo

Esta pantalla muestra cuentas de "efectivo" (es decir, activos líquidos) (como hledger balancesheet type:c). Siempre muestra saldos (saldos finales históricos en la fecha mostrada en la línea de título).

Pantalla de cuentas del balance general

Esta pantalla muestra cuentas de activos, pasivos y patrimonio (como hledger balancesheetequity). Siempre muestra saldos.

Pantalla de cuentas del estado de resultados

Esta pantalla muestra cuentas de ingresos y gastos (como hledger incomestatement). Siempre muestra cambios (cambios de saldo en el período mostrado en la línea de título).

Pantalla de todas las cuentas

Esta pantalla muestra todas las cuentas en tu diario (a menos que se filtren con una consulta; como hledger balance). Muestra saldos por defecto; puedes alternar la visualización de cambios con la tecla H .

Pantalla de registro

Esta pantalla muestra las transacciones que afectan a una cuenta particular. Cada línea representa una transacción, y muestra:

•
la(s) otra(s) cuenta(s) involucrada(s), en forma abreviada. (Si hay tanto asientos reales como virtuales, muestra solo las cuentas afectadas por asientos reales.)
•
el cambio general en el saldo de la cuenta actual; positivo para una entrada a esta cuenta, negativo para una salida.
•
el total acumulado después de la transacción. Con la tecla H puedes alternar entre
•
el total del período, que es solo de las transacciones mostradas
•
o el total histórico, que incluye cualquier transacción no mostrada antes del inicio del período del informe (y que coincida con la consulta de filtro si la hay). Este será el saldo histórico acumulado (lo que verías en el sitio web de un banco, por ejemplo) si no se ve perturbado por una consulta.

Ten en cuenta que esta pantalla combina los asientos en período de cada transacción en un solo elemento de línea, fechado con la fecha de transacción o asiento más temprana en el período (como el aregisterde hledger). Por lo tanto, las fechas de asiento personalizadas pueden causar que el saldo acumulado sea temporalmente inexacto. (Ver manual de hledger > aregister y fechas de asiento.)

Las transacciones que afectan a las subcuentas de esta cuenta se incluirán en el registro si la pantalla de cuentas está en modo árbol, o si está en modo lista pero esta cuenta tiene subcuentas que no se muestran debido a un límite de profundidad. En otras palabras, el registro siempre muestra las transacciones que contribuyen al saldo mostrado en la pantalla de cuentas. El modo árbol/modo lista se puede alternar con t aquí también.

U alterna el filtrado por estado sin marcar, mostrando u ocultando transacciones sin marcar. De manera similar, P alterna las transacciones pendientes, y

Pantalla de transacciones

Esta pantalla muestra una sola transacción, como una entrada de diario general, similar al comando print de hledger y al formato de diario (hledger_journal(5)).

Se muestran la(s) fecha(s) de la transacción y cualquier indicador de liquidación, código de transacción, descripción, comentarios, junto con todas las anotaciones de cuenta. Las transacciones simples tienen dos anotaciones, pero puede haber más (o en ciertos casos, menos).

ARRIBA y ABAJO avanzarán por todas las transacciones listadas en la pantalla del registro de cuentas anterior. En la barra de título, los números entre paréntesis muestran su posición dentro de ese registro de cuentas. Variarán según de qué registro de cuentas provenga (recuerde que la mayoría de las transacciones aparecen en varios registros de cuentas). El número #N que precede a estos es la posición de la transacción dentro del diario completo sin filtrar, que es un ID más estable (al menos hasta la próxima recarga).

En esta pantalla (y en la pantalla del registro), la tecla E abrirá su editor de texto con el cursor posicionado en la transacción actual si es posible.

Pantalla de errores

Esta pantalla aparecerá si hay un problema, como un error de análisis, cuando presione g para recargar. Una vez que haya solucionado el problema, presione g nuevamente para recargar y reanudar el funcionamiento normal. (O puede presionar escape para cancelar el intento de recarga).

MODO DE VIGILANCIA

Una de las mejores características de hledger-ui es el modo de recarga automática -w/--watch. Con esta bandera, actualizará la pantalla automáticamente cada vez que se guarden cambios en los archivos de datos.

Esto es muy útil al conciliar. Un buen flujo de trabajo es tener el registro en línea de su banco abierto en una ventana del navegador, como referencia; el archivo de diario abierto en una ventana del editor; y hledger-ui en modo de vigilancia en una ventana de terminal, por ejemplo:

$ hledger-ui --watch --register checking -C

A medida que marca elementos como liquidados en el editor, puede ver el efecto inmediatamente sin tener que cambiar de contexto. Esto deja más ancho de banda mental para su contabilidad. Por supuesto, aún puede interactuar con hledger-ui cuando sea necesario, por ejemplo, para activar o desactivar el modo de liquidación, o para explorar el historial.

Problemas con --watch

Sin embargo. Hay limitaciones/errores no resueltos con --watch:

•
Puede que no funcione en absoluto para usted, dependiendo de la plataforma o la configuración del sistema. En algunos sistemas Unix, aumentar los parámetros fs.inotify.max_user_watches o fs.file-max en /etc/sysctl.conf podría ayudar. (#836)
•
Puede que no detecte cambios realizados desde fuera de una máquina virtual, es decir, por un editor que se ejecuta en el sistema anfitrión.
•
Puede que no detecte cambios de archivos en ciertos sistemas de archivos menos comunes.
•
Puede usar una CPU y RAM crecientes con el tiempo, especialmente con archivos grandes. (Esto probablemente no sea específico de --watch, es posible que pueda reproducirlo presionando g repetidamente). (#1825)

Consejos/soluciones:

•
Si --watch no funciona para usted, presione g para recargar los datos manualmente.
•
Si --watch tiene fugas de recursos con el tiempo, cierre y reinicie (o suspenda y reanude) hledger-ui cuando no lo esté utilizando.
•
Al ejecutar hledger-ui dentro de una VM, también haga los cambios de archivo dentro de la VM.
•
Al trabajar con archivos montados desde otra máquina, asegúrese de que los relojes del sistema en ambas máquinas estén aproximadamente sincronizados.

AMBIENTE

LEDGER_FILE El archivo de diario principal a usar cuando no se especifica con -f/--file. Predeterminado: $HOME/.hledger.journal.

ERRORES

Damos la bienvenida a informes de errores en el rastreador de problemas de hledger (https://bugs.hledger.org), o en el chat o lista de correo de hledger (https://hledger.org/support).

Algunos problemas conocidos:

-f- no funciona (hledger-ui no puede leer de stdin).

--watch no es robusto, especialmente con archivos grandes (ver MODO DE VIGILANCIA arriba).

Si presiona g con archivos grandes, podría haber una pausa notable con la interfaz de usuario no responsiva.
