hostname(7) Manual de Información Miscelánea hostname(7)

NOMBRE

hostname - descripción de la resolución de nombres de host

DESCRIPCIÓN

Los nombres de host son dominios, donde un dominio es una lista jerárquica separada por puntos de subdominios; por ejemplo, la máquina "monet", en el subdominio "example" del dominio "com", se representaría como "monet.example.com".

Cada elemento del nombre de host debe tener entre 1 y 63 caracteres de longitud y el nombre de host completo, incluidos los puntos, no puede tener más de 253 caracteres de longitud. Los caracteres válidos para los nombres de host son letras del ASCII(7) de *a* a *z*, los dígitos del *0* al *9* y el guion (-). Un nombre de host no puede empezar con un guion.

Los nombres de host se utilizan a menudo con programas cliente y servidor de red, que generalmente deben traducir el nombre a una dirección para su uso. (Esta tarea la realiza generalmente getaddrinfo(3) o el obsoleto gethostbyname(3).)

Los nombres de host son resueltos por el framework NSS en glibc según la configuración de hosts en nsswitch.conf(5). El resolvedor de nombres basado en DNS (en el módulo de servicio NSS dns) los resuelve de la siguiente manera.

Si el nombre consta de un solo componente (es decir, no contiene puntos) y si la variable de entorno HOSTALIASES está establecida al nombre de un archivo, se busca en ese archivo alguna cadena que coincida con el nombre de host de entrada. El archivo debe constar de líneas compuestas por dos cadenas separadas por espacios en blanco, la primera de las cuales es el alias del nombre de host y la segunda es el nombre de host completo que se sustituirá por ese alias. Si se encuentra una coincidencia insensible a mayúsculas y minúsculas entre el nombre de host a resolver y el primer campo de una línea en el archivo, se busca el nombre sustituido sin más procesamiento.

Si el nombre de entrada termina con un punto, se elimina el punto final y se busca el nombre restante sin más procesamiento.

Si el nombre de entrada no termina con un punto, se busca examinando una lista de dominios hasta que se encuentre una coincidencia. La lista de búsqueda predeterminada incluye primero el dominio local, luego sus dominios padres con al menos 2 componentes de nombre (el más largo primero). Por ejemplo, en el dominio cs.example.com, el nombre lithium.cchem se verificará primero como lithium.cchem.cs.example y luego como lithium.cchem.example.com. No se intentará lithium.cchem.com, ya que solo queda un componente del dominio local. La ruta de búsqueda puede cambiarse de la predeterminada mediante un archivo de configuración de todo el sistema (ver resolver(5)).

VER TAMBIÉN

getaddrinfo(3), gethostbyname(3), nsswitch.conf(5), resolver(5), mailaddr(7), named(8)
