NOMBRE

htcacheclean - Limpia la caché del disco

SINOPSIS

htcacheclean [ -D ] [ -v ] [ -t ] [ -r ] [ -n ] [ -Rronda ] -pruta [ -llímite ] [ -Llímite ]

htcacheclean [ -n ] [ -t ] [ -i ] [ -Parchivopid ] [ -Rronda ] -dintervalo -pruta [ -llímite ] [ -Llímite ]

htcacheclean [ -v ] [ -Rronda ] -pruta [ -a ] [ -A ]

htcacheclean [ -D ] [ -v ] [ -t ] [ -Rronda ] -pruta url

RESUMEN

htcacheclean se utiliza para mantener el tamaño del almacenamiento en disco de mod_cache_disk dentro de un límite de tamaño dado, o un límite en el uso de inodos. Esta herramienta puede ejecutarse manualmente o en modo demonio. Cuando se ejecuta en modo demonio, duerme en segundo plano y comprueba el directorio de caché a intervalos regulares para eliminar el contenido almacenado en caché. Puedes detener el demonio limpiamente enviándole una señal TERM o INT. Cuando se ejecuta manualmente, se realiza una única comprobación del directorio de caché para eliminar el contenido almacenado en caché. Si se especifica una o más URLs, cada URL se eliminará de la caché, si está presente.

OPCIONES

-dintervalo
Se demoniza y repite la limpieza de la caché cada intervalo minutos. Esta opción es mutuamente excluyente con las opciones -D, -v y -r. Para apagar el demonio limpiamente, simplemente envíale una señal SIGTERM o SIGINT.
-D
Realiza una ejecución de prueba y no elimina nada. Esta opción es mutuamente excluyente con la opción -d. Al realizar una ejecución de prueba y eliminar directorios con -t, los inodos que se informan como eliminados en las estadísticas no pueden tener en cuenta los directorios eliminados y se marcarán como una estimación.
-v
Sé verboso e imprime estadísticas. Esta opción es mutuamente excluyente con la opción -d.
-r
Limpia a fondo. Esto asume que el servidor web Apache no se está ejecutando (de lo contrario, podrías obtener datos basura en la caché). Esta opción es mutuamente excluyente con la opción -d e implica la opción -t.
-n
Sé amable. Esto provoca un procesamiento más lento en favor de otros procesos. htcacheclean dormirá de vez en cuando para que (a) la E/S del disco se retrase y (b) el kernel pueda programar otros procesos en el ínterin.
-t
Elimina todos los directorios vacíos. Por defecto, solo se eliminan los archivos de caché, sin embargo, con algunas configuraciones, el gran número de directorios creados puede requerir atención. Si tu configuración requiere un número muy grande de directorios, hasta el punto de que el agotamiento de inodos o la tabla de asignación de archivos puedan ser un problema, se recomienda el uso de esta opción.
-pruta
Especifica ruta como el directorio raíz de la caché del disco. Este debería ser el mismo valor que se especifica con la directiva CacheRoot.
-Parchivopid
Especifica archivopid como el nombre del archivo al que escribir el ID del proceso cuando se demoniza.
-Rronda
Especifica ronda como la cantidad a redondear los tamaños, para compensar los tamaños de bloque del disco. Establecer en el tamaño de bloque de la partición de caché.
-llímite
Especifica límite como el tamaño total de la caché del disco. El valor se expresa en bytes por defecto (o adjuntando B al número). Adjunta K para Kbytes, M para MBytes o G para Gbytes.
-Llímite
Especifica límite como el límite total de inodos de la caché del disco. También se pueden usar sufijos K, M o G.
-i
Sé inteligente y ejecuta solo cuando haya habido una modificación de la caché del disco. Esta opción solo es posible junto con la opción -d.
-a
Lista las URLs actualmente almacenadas en la caché. Las variantes de la misma URL se listarán una vez por cada variante.
-A
Lista las URLs actualmente almacenadas en la caché, junto con sus atributos en el siguiente orden: url, tamaño de cabecera, tamaño de cuerpo, estado, versión de la entidad, fecha, caducidad, tiempo de solicitud, tiempo de respuesta, cuerpo presente, solicitud HEAD.

ELIMINANDO UNA URL ESPECÍFICA

Si a htcacheclean se le pasan una o más URLs, cada URL se eliminará de la caché. Si existen múltiples variantes de una URL, se eliminarán todas las variantes.

Cuando se va a eliminar una URL proxy inversa, la URL efectiva se construye a partir de la cabecera Host, el puerto, la ruta y la consulta. Ten en cuenta que el '?' en la URL siempre debe especificarse explícitamente, independientemente de si hay una cadena de consulta presente o no. Por ejemplo, al intentar eliminar la ruta / del servidor localhost, la URL a eliminar sería http://localhost:80/?.

LISTANDO URLS EN LA CACHE

Al pasar las opciones -a o -A a htcacheclean, las URLs dentro de la caché se listarán a medida que se encuentran, una URL por línea. La opción -A vuelca la entrada completa de la caché después de la URL, con los campos en el siguiente orden:

url
La URL de la entrada.
tamaño de cabecera
El tamaño de la cabecera en bytes.
tamaño de cuerpo
El tamaño del cuerpo en bytes.
estado
Estado de la respuesta cacheada.
versión de la entidad
El número de veces que esta entrada ha sido revalidada sin ser eliminada.
fecha
Fecha de la respuesta.
caducidad
Fecha de caducidad de la respuesta.
tiempo de solicitud
Tiempo de inicio de la solicitud.
tiempo de respuesta
Tiempo de fin de la solicitud.
cuerpo presente
Si es 0, no se almacena cuerpo con esta solicitud, 1 en caso contrario.
solicitud HEAD
Si es 1, la entrada contiene una solicitud HEAD cacheada sin cuerpo, 0 en caso contrario.

ESTADO DE SALIDA

htcacheclean devuelve un estado cero ("verdadero") si todas las operaciones fueron exitosas, 1 en caso contrario. Si se especifica una URL y la URL fue cacheada y eliminada con éxito, se devuelve 0, 2 en caso contrario. Si ocurrió un error durante la eliminación de la URL, se devuelve 1.
