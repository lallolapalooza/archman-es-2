NOMBRE

hunzip - comprimir y cifrar archivos de diccionario

SINOPSIS

hzip [-h] [-P contraseña] [archivo(s)]

DESCRIPCIÓN

hunzip es una pequeña utilidad para la compresión y cifrado de archivos de texto, especialmente para diccionarios ordenados. "hunzip nombre_archivo" crea el archivo comprimido "nombre_archivo.hz" sin eliminar el archivo original.

El algoritmo de compresión utiliza codificación Huffman de 16 bits y compresión de prefijo-sufijo orientada a líneas. Tiene una buena relación de compresión para listas de palabras ordenadas enormes.

OPCIONES

-h
Muestra una breve descripción de ayuda.
-P contraseña
Compresión cifrada con una contraseña de longitud arbitraria.

VER TAMBIÉN
