HYDROGEN(29) Comandos de usuario HYDROGEN(29)

NOMBRE

hydrogen - una caja de ritmos/secuenciador simple.

SINOPSIS

hydrogen [-v] [-h] -s archivo

DESCRIPCIÓN

Hydrogen 1.2.6 [http://www.hydrogen-music.org]. Copyright 2002-2008 Alessandro Cominu, Copyright 2008-2025 El equipo de desarrollo de hydrogen.

Hydrogen es una caja de ritmos avanzada para GNU/Linux. Su objetivo principal es aportar una programación de ritmos basada en patrones profesional, pero sencilla e intuitiva.

Hydrogen se distribuye SIN GARANTÍA ALGUNA. Es software libre y usted es bienvenido a redistribuirlo bajo ciertas condiciones. Consulte el archivo COPYING para más detalles.

OPCIONES

-P, --data RUTA - Usar una ruta de datos del sistema alternativa

-d, --driver CONTROLADOR_AUDIO - Usar el controlador de audio seleccionado (jack, alsa, oss)

-s, --song ARCHIVO - Cargar una canción (*.h2song) al arrancar

-p, --playlist ARCHIVO - Cargar una lista de reproducción (*.h2playlist) al arrancar

-k, --kit nombre_kit_bateria - Cargar un kit de batería al arrancar

-i, --install ARCHIVO - instalar un kit de batería (*.h2drumkit)

-O, --osc-port - Usar puerto OSC personalizado

-n, --nosplash - Ocultar la pantalla de presentación

-V[Nivel], --verbose[=Nivel] - Imprimir mucha información de depuración

Nivel, si está presente, puede ser None, Error, Warning, Info, Debug o 0xHHHH

-L, --log-file - Usar archivo de registro personalizado

-T, --log-timestamps - Añadir marcas de tiempo a todos los mensajes de registro

-v, --version - Mostrar información de la versión

-h, --help - Mostrar este mensaje de ayuda

ARCHIVOS

hydrogen.conf

Valores por defecto y configuraciones de inicio para Hydrogen.

data/*

Puede contener datos del usuario como kits de batería, patrones, listas de reproducción, canciones, ...

ENTORNO

LADSPA_PATH

Ruta a los plugins LADSPA.
