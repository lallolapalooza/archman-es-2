hosts(5) Manual de formatos de archivo hosts(5)

NOMBRE

hosts - búsqueda estática de nombres de host en tabla

SINOPSIS

/etc/hosts

DESCRIPCIÓN

Esta página del manual describe el formato del archivo /etc/hosts. Este archivo es un simple archivo de texto que asocia direcciones IP con nombres de host, una línea por dirección IP. Para cada host debe haber una única línea presente con la siguiente información:

dirección_IP nombre_host_canónico [alias...]

La dirección IP puede ser compatible con IPv4 o IPv6. Los campos de la entrada están separados por cualquier número de espacios en blanco y/o tabuladores. El texto desde un carácter "#" hasta el final de la línea es un comentario y se ignora. Los nombres de host solo pueden contener caracteres alfanuméricos, signos de menos ("-") y puntos ("."). Deben comenzar con un carácter alfabético y terminar con un carácter alfanumérico. Los alias opcionales proporcionan cambios de nombre, variaciones ortográficas, nombres de host más cortos o nombres de host genéricos (por ejemplo, localhost). Si es necesario, un host puede tener dos entradas separadas en este archivo; una para cada versión del Protocolo de Internet (IPv4 e IPv6).

El servidor BIND (Berkeley Internet Name Domain) implementa el servidor de nombres de Internet para sistemas UNIX. Aumenta o reemplaza el archivo /etc/hosts o la búsqueda de nombres de host, y libera a un host de depender de que /etc/hosts esté actualizado y completo.

En los sistemas modernos, aunque la tabla de hosts ha sido reemplazada por DNS, todavía se usa ampliamente para:

arranque
La mayoría de los sistemas tienen una pequeña tabla de hosts que contiene la información de nombres y direcciones de hosts importantes en la red local. Esto es útil cuando DNS no está funcionando, por ejemplo, durante el arranque del sistema.
NIS
Los sitios que usan NIS utilizan la tabla de hosts como entrada para la base de datos de hosts NIS. Aunque NIS se puede usar con DNS, la mayoría de los sitios NIS todavía usan la tabla de hosts con una entrada para todos los hosts locales como respaldo.
nodos aislados
Los sitios muy pequeños que están aislados de la red utilizan la tabla de hosts en lugar de DNS. Si la información local cambia raramente y la red no está conectada a Internet, DNS ofrece poca ventaja.

ARCHIVOS

/etc/hosts

NOTAS

Las modificaciones a este archivo normalmente surten efecto inmediatamente, excepto en casos donde el archivo es cacheado por las aplicaciones.

Notas históricas

RFC 952 dio el formato original para la tabla de hosts, aunque ha cambiado desde entonces.

Antes de la llegada de DNS, la tabla de hosts era la única forma de resolver nombres de host en Internet. De hecho, este archivo podía crearse a partir de la base de datos oficial de hosts mantenida en el Centro de Control de Información de Red (NIC), aunque a menudo se requerían cambios locales para ponerla al día con alias no oficiales y/o hosts desconocidos. El NIC ya no mantiene los archivos hosts.txt, aunque buscando en el momento de escribir (alrededor del 2000), hay archivos hosts.txt históricos en la WWW. Acabo de encontrar tres, de 92, 94 y 95.

EJEMPLOS

# Las siguientes líneas son deseables para hosts compatibles con IPv4
127.0.0.1       localhost
# 127.0.1.1 se usa a menudo para el FQDN de la máquina
127.0.1.1       thishost.example.org   thishost
192.168.1.10    foo.example.org        foo
192.168.1.13    bar.example.org        bar
146.82.138.7    master.debian.org      master
209.237.226.90  www.opensource.org
# Las siguientes líneas son deseables para hosts compatibles con IPv6
::1             localhost ip6-localhost ip6-loopback
ff02::1         ip6-allnodes
ff02::2         ip6-allrouters
