Descripción Detallada

El tipo hwloc_bitmap_t representa un conjunto de enteros (positivos o nulos). Un bitmap puede ser de tamaño infinito (todos los bits están establecidos después de cierto punto). Un bitmap incluso puede estar lleno si todos los bits están establecidos.

Los bitmaps son utilizados por hwloc para conjuntos de procesadores del sistema operativo (que en realidad pueden ser hilos de hardware) como hwloc_cpuset_t (un typedef para hwloc_bitmap_t), o conjuntos de nodos de memoria NUMA como hwloc_nodeset_t (también un typedef para hwloc_bitmap_t). Estos se usan para los campos cpuset y nodeset en la estructura hwloc_obj, ver Conjuntos de Objetos (hwloc_cpuset_t y hwloc_nodeset_t).

Tanto los conjuntos de CPU como los de nodos siempre están indexados por número físico del sistema operativo. Sin embargo, los usuarios generalmente no deberían construir conjuntos de CPU y nodos manualmente (por ejemplo, con hwloc_bitmap_set()). En su lugar, se deberían usar los conjuntos de objetos existentes y combinarlos con hwloc_bitmap_or(), etc. Por ejemplo, enlazar el hilo actual en un par de núcleos puede realizarse con:

hwloc_obj_t core1 = ... , core2 = ... ;
hwloc_bitmap_t set = hwloc_bitmap_alloc();
hwloc_bitmap_or(set, core1->cpuset, core2->cpuset);
hwloc_set_cpubind(topology, set, HWLOC_CPUBIND_THREAD);
hwloc_bitmap_free(set);

Nota

La mayoría de las funciones a continuación devuelven 0 en caso de éxito y -1 en caso de error. El caso de error habitual sería un fallo interno para reasignar/extender el almacenamiento del bitmap (errno se establecería en ENOMEM). Ver también Información de errores en la API.

Varios ejemplos de uso de la API de bitmap están disponibles en el directorio doc/examples/ del árbol de fuentes. Las pruebas de regresión como tests/hwloc/hwloc_bitmap*.c también hacen un uso intensivo de esta API.

Documentación de Definición de Macros

#define hwloc_bitmap_foreach_begin(id, bitmap)

Macro de bucle que itera sobre el bitmap bitmap. El bucle debe comenzar con hwloc_bitmap_foreach_begin() y terminar con hwloc_bitmap_foreach_end() seguido de un punto y coma final.

id es la variable del bucle; debe ser un unsigned int. La primera iteración establecerá id al índice más bajo en el bitmap. Las iteraciones sucesivas recorrerán, en orden, todos los índices restantes establecidos en el bitmap. Para ser específicos: cada iteración devolverá un valor para id tal que hwloc_bitmap_isset(bitmap, id) sea verdadero.

La aserción previene que el bucle sea infinito si el bitmap está infinitamente establecido.

#define hwloc_bitmap_foreach_end()

Fin del macro de bucle que itera sobre un bitmap. Necesita un punto y coma final.

int hwloc_bitmap_snprintf (char *restrict buf, size_t buflen, hwloc_const_bitmap_t bitmap)

Convierte el bitmap en una cadena, similar a printf().

El formato de la cadena es una lista de enteros separados por comas, posiblemente con guiones para rangos. Por ejemplo: "0,1,3-5,9".

Devuelve el número de caracteres que se habrían escrito si buf fuera lo suficientemente grande. Si el número de caracteres es mayor o igual a buflen, la cadena está truncada.

Devuelve un valor negativo en caso de error (por ejemplo, si el bitmap es demasiado grande para representarse en la cadena y el número de bits excedió el límite de representación interna del formato de cadena).

Ver también

hwloc_bitmap_asprintf(), hwloc_bitmap_sscanf(), hwloc_bitmap_list_snprintf(), hwloc_bitmap_taskset_snprintf()

int hwloc_bitmap_asprintf (char **strp, hwloc_const_bitmap_t bitmap)

Convierte el bitmap en una cadena asignada dinámicamente.

strp contendrá un puntero a la cadena recién asignada que representa el bitmap.

La cadena está en el mismo formato que hwloc_bitmap_snprintf().

El llamante debe liberar la cadena asignada con free(3).

Devuelve 0 en caso de éxito, -1 en caso de error (por ejemplo, si la asignación de memoria falla o si el bitmap es demasiado grande para ser representado).

int hwloc_bitmap_sscanf (hwloc_bitmap_t bitmap, const char *restrict string)

Analiza la cadena string y establece los bits correspondientes en bitmap.

El formato de la cadena es el mismo que el de hwloc_bitmap_snprintf().

Devuelve 0 en caso de éxito, -1 en caso de error (por ejemplo, si la cadena no está en el formato correcto o si los valores son demasiado grandes para el bitmap).

Si el bitmap ya contenía bits establecidos, estos se conservan.

int hwloc_bitmap_singlify (hwloc_bitmap_t

bitmap)

Mantiene un solo índice entre los establecidos en el mapa de bits bitmap. Puede ser útil antes de realizar el enlace (binding) para que el proceso no tenga la posibilidad de migrar entre múltiples procesadores en la máscara original. En lugar de ejecutar la tarea en cualquier PU dentro del conjunto de CPU dado, el programador del sistema operativo se verá forzado a ejecutarla en una sola de estas PUs.
