NOMBRE

htmldoc - convertir archivos fuente html en html, postscript o pdf.

SINOPSIS

htmldoc [opciones] archivo1.{html,md} [ ... archivoN.{html,md} ]

htmldoc [opciones] -

htmldoc [archivo.book]

DESCRIPCIÓN

Htmldoc(1) convierte archivos fuente HTML y Markdown en archivos HTML indexados, PostScript o Formato de Documento Portátil (PDF) que pueden ser vistos en línea o impresos. Sin opciones, se produce un documento HTML en la salida estándar.

La segunda forma de htmldoc lee la fuente HTML desde la entrada estándar, lo que le permite usar htmldoc como un filtro.

La tercera forma de htmldoc inicia una interfaz gráfica que le permite cambiar las opciones y generar documentos de forma interactiva.

ERRORES COMUNES

Hay dos tipos de archivos HTML: documentos estructurados que usan encabezados (H1, H2, etc.) que htmldoc llama "libros", y documentos no estructurados que no usan encabezados, a los que htmldoc llama "páginas web".

Un error muy común es intentar convertir una página web usando:

    htmldoc -f archivo.pdf archivo.html
que probablemente producirá un archivo PDF sin páginas. Para convertir archivos de páginas web, debe usar las opciones --webpage o --continuous en la línea de comandos o elegir Web Page o Continuous en la pestaña de entrada de la GUI.

OPCIONES

Las siguientes opciones de línea de comandos son soportadas por htmldoc:

--batch archivo.book
Genera el archivo de libro especificado sin abrir la GUI.
--bodycolor color
Especifica el color de fondo para todas las páginas.
--bodyfont {courier,helvetica,monospace,sans,serif,times}
--textfont {courier,helvetica,monospace,sans,serif,times}
Especifica el tipo de letra predeterminado para todo el texto normal.
--bodyimage archivo
Especifica la imagen de fondo que se repetirá en todas las páginas.
--book
Especifica que las fuentes HTML están estructuradas (encabezados, capítulos, etc.)
--bottom margen
Especifica el margen inferior en puntos (sin sufijo o ##pt), pulgadas (##in), centímetros (##cm) o milímetros (##mm).
--charset {cp-nnnn,iso-8859-1,...,iso-8859-15,utf-8}
Especifica el conjunto de caracteres a usar para la salida. Nota: el soporte para UTF-8 está limitado a los primeros 128 caracteres Unicode que se encuentran en la entrada.
--color
Especifica que la salida PostScript o PDF debe ser en color.
--continuous
Especifica que las fuentes HTML no están estructuradas (páginas web simples). No se insertan saltos de página entre cada archivo o URL en la salida.
--datadir directorio
Especifica la ubicación de los archivos de datos de htmldoc, normalmente /usr/share/htmldoc o C:/Program Files/HTMLDOC.
--duplex
Especifica que la salida debe formatearse para impresión a doble cara.
--effectduration {0.1...10.0}
Especifica la duración en segundos de los efectos de transición de página del PDF.
--embedfonts
Especifica que las fuentes deben incrustarse en la salida PDF y PostScript.
--encryption
Habilita el cifrado de archivos PDF.
--fontsize tamaño
Especifica el tamaño de fuente predeterminado para el texto del cuerpo.
--fontspacing espaciado
Especifica el espaciado de línea predeterminado para el texto del cuerpo. El espaciado de línea es un multiplicador del tamaño de fuente, por lo que un valor de 1.2 proporcionará un 20% adicional de espacio entre las líneas.
--footer fff
Establece el pie de página a usar en las páginas del cuerpo. Consulte la sección FORMATOS DE CABECERAS/PIES DE PÁGINA más abajo.
--format formato
-t formato
Especifica el formato de salida: epub, html, htmlsep (archivos HTML separados para cada encabezado en la tabla de contenido), ps o ps2 (PostScript Nivel 2), ps1 (PostScript Nivel 1), ps3 (PostScript Nivel 3), pdf11 (PDF 1.1/Acrobat 2.0), pdf12 (PDF 1.2/Acrobat 3.0), pdf o pdf13 (PDF 1.3/Acrobat 4.0), o pdf14 (PDF 1.4/Acrobat 5.0).
--gray
Especifica que la salida PostScript o PDF debe ser en escala de grises.
--header fff
Establece la cabecera de página a usar en las páginas del cuerpo. Consulte la sección FORMATOS DE CABECERAS/PIES DE PÁGINA más abajo.
--header1 fff
Establece la cabecera de página a usar en la primera página del cuerpo/capítulo. Consulte la sección FORMATOS DE CABECERAS/PIES DE PÁGINA más abajo.
--headfootfont fuente
Establece la fuente a usar en las cabeceras y pies de página.
--headfootsize tamaño
Establece el tamaño de la fuente a usar en las cabeceras y pies de página.
--headingfont tipo de letra
Establece el tipo de letra a usar para los encabezados.
--help
Muestra un resumen de las opciones de línea de comandos.
--helpdir directorio
Especifica la ubicación de los archivos de ayuda en línea de htmldoc, normalmente /usr/share/doc/htmldoc o C:/Program Files/HTMLDOC/DOC.
--hfimageN archivo
Especifica una imagen (numerada del 1 al 10) a usar en la cabecera o pie de página en un documento PostScript o PDF.
--jpeg[=calidad]
Establece el nivel de compresión JPEG a usar para imágenes grandes. Un valor de 0 deshabilita la compresión JPEG.
--left margen
Especifica el margen izquierdo en puntos (sin sufijo o ##pt), pulgadas (##in), centímetros (##cm) o milímetros (##mm).
--letterhead archivo
Especifica una imagen a usar como membrete en la cabecera o pie de página en un documento PostScript o PDF. Tenga en cuenta que necesita usar las opciones --header, --header1, y/o --footer con el parámetro L o usar los comentarios de página HTML correspondientes para mostrar la imagen del membrete en la cabecera o pie de página.
--linkcolor color
Establece el color de los enlaces.
--links
Habilita la generación de enlaces en archivos PDF (predeterminado).
--linkstyle {plain,underline}
Establece el estilo de los enlaces.
--logoimage archivo
Especifica una imagen a usar como logotipo en la cabecera o pie de página en un documento PostScript o PDF, y en la barra de navegación de un documento HTML. Tenga en cuenta que necesita usar las opciones --header, --header1, y/o --footer con el parámetro l o usar los comentarios de página HTML correspondientes para mostrar la imagen del logotipo en la cabecera o pie de página.

OPCIONES

--no-compression
Inhabilita la compresión de archivos PostScript o PDF.
--no-duplex
Inhabilita la impresión a doble cara.
--no-embedfonts

Especifica que las fuentes no deben incrustarse en la salida PDF y PostScript.
--no-encryption
Inhabilita el cifrado del documento.
--no-jpeg
Inhabilita la compresión JPEG de imágenes grandes.
--no-links
Inhabilita la generación de enlaces en un documento PDF.
--no-numbered
Inhabilita la numeración automática de encabezados.
--no-pscommands
Inhabilita la generación de comandos setpagedevice de PostScript.
--no-strict
Inhabilita la verificación estricta de la entrada HTML.
--no-title
Inhabilita la generación de una página de título.
--no-toc
Inhabilita la generación de una tabla de contenidos.
--numbered
Numera todos los encabezados de un documento.
--nup páginas
Establece el número de páginas que se colocan en cada página de salida. Los valores válidos son 1, 2, 4, 6, 9 y 16.
--outdir directorio
-d directorio
Especifica que la salida debe enviarse a un directorio en múltiples archivos. (No compatible con la salida PDF)
--outfile nombre_archivo
-f nombre_archivo
Especifica que la salida debe enviarse a un único archivo.
--owner-password contraseña
Establece la contraseña del propietario para archivos PDF cifrados.
--pageduration I{1.0...60.0}
Establece la duración de visualización de una página en un documento PDF.
--pageeffect efecto
Especifica el efecto de transición de página para todas las páginas; este atributo es ignorado por todos los visores de PDF de Adobe.
--pagelayout {single,one,twoleft,tworight}
Especifica la disposición inicial de las páginas para un archivo PDF.
--pagemode {document,outlines,fullscreen}
Especifica el modo de visualización inicial para un archivo PDF.
--path
Especifica una ruta de búsqueda de archivos en un documento.
--permissions permiso[,permiso,...]
Especifica los permisos del documento para archivos PDF cifrados. Se entienden los siguientes permisos: all, none, annotate, no-annotate, copy, no-copy, modify, no-modify, print y no-print. Separe múltiples permisos con comas.
--pre-indent distancia
Especifica la indentación del texto preformateado en puntos (sin sufijo o ##pt), pulgadas (##in), centímetros (##cm) o milímetros (##mm).
--pscommands
Especifica que los comandos setpagedevice de PostScript se incluyan en la salida.
--quiet
Suprime todos los mensajes, incluso los de error.
--referer url
Especifica la URL que se pasa en el campo Referer: de las solicitudes HTTP.
--right margen
Especifica el margen derecho en puntos (sin sufijo o ##pt), pulgadas (##in), centímetros (##cm) o milímetros (##mm).
--size tamaño_página
Especifica el tamaño de la página utilizando un nombre estándar o en puntos (sin sufijo o ##x##pt), pulgadas (##x##in), centímetros (##x##cm) o milímetros (##x##mm). Los tamaños estándar que se reconocen actualmente son "letter" (8.5x11in), "legal" (8.5x14in), "a4" (210x297mm) y "universal" (8.27x11in).
--strict
Habilita la verificación estricta de la entrada HTML.
--textcolor color
Especifica el color predeterminado de todo el texto.
--title
Habilita la generación de una página de título.
--titlefile nombre_archivo
--titleimage nombre_archivo
Especifica el archivo a utilizar para la página de título. Si el archivo es una imagen, entonces la página de título se genera automáticamente utilizando los metadatos del documento y la imagen del título.
--tocfooter fff
Establece el pie de página a utilizar en las páginas de la tabla de contenidos. Consulte la sección FORMATOS DE ENCABEZADO/PIE DE PÁGINA a continuación.
--tocheader fff
Establece el encabezado de página a utilizar en las páginas de la tabla de contenidos. Consulte la sección FORMATOS DE ENCABEZADO/PIE DE PÁGINA a continuación.
--toclevels niveles
Establece el número de niveles en la tabla de contenidos.
--toctitle cadena
Establece el título de la tabla de contenidos.
--top margen
Especifica el margen superior en puntos (sin sufijo o ##pt), pulgadas (##in), centímetros (##cm) o milímetros (##mm).
--user-password contraseña
Especifica la contraseña del usuario para el cifrado de archivos PDF.
--verbose
-v
Proporciona mensajes detallados.
--version
Muestra el número de versión actual.
--webpage
Especifica que las fuentes HTML no están estructuradas (páginas web simples). Se inserta un salto de página entre cada archivo o URL en la salida.

ESTADO DE SALIDA

Htmldoc devuelve un estado de salida distinto de cero si se producen errores, de lo contrario, devuelve cero.

FORMATOS DE ENCABEZADO/PIE DE PÁGINA

El encabezado y pie de página de cada página pueden contener hasta tres valores preformateados. Estos valores se especifican utilizando un solo carácter para la izquierda, el centro y la derecha de la página, lo que resulta en la notación fff mostrada anteriormente.

Cada carácter puede ser uno de los siguientes:

.
espacio en blanco
/
números de página arábigos n/N (1/3, 2/3, 3/3)
:
números de página de capítulo arábigos c/C (1/2, 2/2, 1/4, 2/4, ...)
1
números arábigos (1, 2, 3, ...)
a
letras minúsculas
A
letras mayúsculas
c
encabezado de capítulo actual
C
número de página de capítulo actual (arábigo)
d
fecha actual
D
fecha y hora actuales
h
encabezado actual
i
números romanos en minúscula
I
números romanos en mayúscula
l
imagen del logotipo
L
imagen del logotipo como membrete - la imagen se inserta en su tamaño máximo
t
texto del título
T
hora actual
u
nombre de archivo o URL actual

AMBIENTE

HTMLDOC busca varias variables de entorno que pueden anular los directorios predeterminados, mostrar información de depuración adicional y deshabilitar el modo CGI:

HTMLDOC_DATA
Esta variable de entorno especifica la ubicación de los directorios de datos y fuentes de htmldoc, normalmente /usr/share/htmldoc o C:/Program Files/HTMLDOC.
HTMLDOC_DEBUG
Esta variable de entorno habilita la información de depuración que se envía a stderr. El valor es una lista de cualquiera de las siguientes palabras clave separadas por espacios: "all", "links", "memory", "remotebytes", "table", "tempfiles" y/o "timing".
HTMLDOC_HELP
Esta variable de entorno especifica la ubicación del directorio de documentación de htmldoc, normalmente /usr/share/doc/htmldoc o C:/Program Files/HTMLDOC/doc.
HTMLDOC_NOCGI
Esta variable de entorno, cuando se establece (el valor no importa), deshabilita el modo CGI. Es muy útil para usar htmldoc en un servidor web desde un lenguaje de scripting o invocándolo desde un programa.

EJEMPLOS

EJEMPLOS

Crear un archivo PDF desde un sitio web:

    htmldoc --webpage -f ejemplo.pdf http://www.ejemplo.com/

Crear un libro PostScript desde un directorio de archivos HTML

    htmldoc --book -f ejemplo.pdf *.html
