HWINFO(8) Configuración del sistema HWINFO(8)

NOMBRE

hwinfo - sondear hardware

SINOPSIS

hwinfo [ OPCIONES ]

DESCRIPCIÓN

hwinfo se utiliza para sondear el hardware presente en el sistema. Se puede usar para generar un registro de resumen del sistema que luego se puede utilizar para soporte.

OPCIONES

Tenga en cuenta que ejecutar hwinfo sin ninguna opción es aproximadamente equivalente a 'hwinfo --all --log=-'.

--<ELEMENTO_HARDWARE>
Esta opción se puede dar más de una vez. Sondea un ELEMENTO_HARDWARE particular. Los elementos de hardware disponibles son:

all, arch, bios, block, bluetooth, braille, bridge, camera, cdrom, chipcard, cpu, disk, dsl, dvb, fingerprint, floppy, framebuffer, gfxcard, hub, ide, isapnp, isdn, joystick, keyboard, memory, mmc-ctrl, modem, monitor, mouse, netcard, network, partition, pci, pcmcia, pcmcia-ctrl, pppoe, printer, redasd, reallyall, scanner, scsi, smp, sound, storage-ctrl, sys, tape, tv, uml, usb, usb-ctrl, vbe, wlan, xen, zip

¡Tenga en cuenta que si esta opción falta, no se realizará ninguna sonda de hardware!

--short
Mostrar solo un resumen. Utilice esta opción además de una opción de sonda de hardware.
--listmd
Normalmente hwinfo no informa sobre dispositivos RAID. Añada esta opción para verlos.
--only NOMBRE_DEV
Esta opción se puede dar más de una vez. Si añade esta opción, solo se mostrarán las entradas de la lista de dispositivos que coincidan con NOMBRE_DEV. Tenga en cuenta que también debe especificar --<ELEMENTO_HARDWARE> para activar cualquier sonda de dispositivo.
--save-config ESPEC
Almacena la configuración para un dispositivo particular debajo de /var/lib/hardware. ESPEC puede ser un nombre de dispositivo, una UDI, o 'all'. Esta opción debe darse además de una opción de sonda de hardware.
--show-config UDI
Mostrar datos de configuración guardados para un dispositivo particular.
--map
Si los nombres de disco han cambiado (por ejemplo, después de una actualización del kernel) esto imprime una lista de mapeos de nombres de disco. Tenga en cuenta que debe haber usado --save-config en algún momento anterior para que esto funcione.
--debug N
Establece el nivel de depuración a N. La información de depuración solo se muestra en el archivo de registro. Si especifica un archivo de registro, el nivel de depuración se establece implícitamente en un valor razonable (N es una máscara de bits de indicadores individuales).
--verbose
Aumenta la verbosidad. Solo junto con --map.
--log ARCHIVO
Escribe la información del registro en ARCHIVO. No olvide especificar también --<ELEMENTO_HARDWARE> para activar cualquier sonda de dispositivo.
--dump-db N
Vuelca la base de datos de hardware. N es 0 para la base de datos externa en /var/lib/hardware, o 1 para la base de datos interna.
--version
Imprime la versión de libhd.
--help
Imprime el uso.

AMBIENTE

hwprobe puede contener una lista separada por comas de indicadores de sondeo precedidos por '+' o '-' para activarlos o desactivarlos. Para obtener una lista completa de los indicadores soportados, ejecute 'hwinfo -all' (nota: no '--all') y mire en la parte superior de la salida.

hwinfo también busca en /proc/cmdline una opción de hwprobe.

EJEMPLOS

- mostrar todos los discos
hwinfo --disk
- solo una vista general
hwinfo --short --block
- mostrar un disco particular
hwinfo --disk --only /dev/sdb
- guardar el estado de la configuración del disco
hwinfo --disk --save-config=all
- intentar 4 puertos de tarjeta gráfica para datos del monitor (predeterminado: 3)
hwprobe=bios.ddc.ports=4 hwinfo --monitor
- la detección del monitor ejecuta la BIOS de video para obtener los datos del monitor; vuelca un rastreo completo de la ejecución del código de la BIOS al registro
hwprobe=bios.ddc.ports=1,x86emu=trace:dump:trace.only=0:dump.only=0 hwinfo --monitor --log=foo

ARCHIVOS

/var/lib/hardware/hd.ids
Base de datos de hardware externa (en formato de texto legible). Pruebe la opción --dump-db para ver el formato.
/var/lib/hardware/udi
Directorio donde se almacenan los datos de configuración persistentes (ver la opción --save-config).

ERRORES

No todo el hardware puede ser detectado.

VER TAMBIÉN

Más documentación en /usr/share/doc/packages/hwinfo.
