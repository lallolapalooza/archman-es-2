hashkit_value(3)

Paquete: libmemcached-awesome

Licencias: BSD

HASHKIT_VALUE(3) libmemcached-awesome HASHKIT_VALUE(3)

NOMBRE

hashkit_value - Documentación de libhashkit

SINOPSIS

#include <libhashkit-1.0/hashkit.h>
Compilar y enlazar con -lhashkit
uint32_t hashkit_value(hashkit_st *hash, const char *key, size_t key_length)
Parámetros
  • hash -- puntero a una estructura hashkit_st inicializada
  • key -- la clave para generar un hash
  • key_length -- la longitud de la key sin ningún byte de terminación

DESCRIPCIÓN

La función hashkit_value() genera un valor hash de 32 bits a partir de la clave y la longitud de clave dadas. El argumento hash es un objeto hashkit inicializado, y el tipo de distribución y la función hash se utilizan desde este objeto mientras se genera el valor.

VALOR DE RETORNO

Un valor hash de 32 bits.
