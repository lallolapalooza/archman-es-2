NOMBRE

hexyl - un visor hexadecimal de línea de comandos

SINOPSIS

hexyl [OPCIONES] [ARCHIVO]

DESCRIPCIÓN

hexyl es un visor hexadecimal simple para la terminal. Utiliza una salida coloreada para distinguir diferentes categorías de bytes (bytes NUL, caracteres ASCII imprimibles, caracteres de espacio en blanco ASCII, otros caracteres ASCII y no ASCII).

ARGUMENTOS POSICIONALES

ARCHIVO
El archivo a mostrar. Si no se proporciona argumento ARCHIVO, se leerá desde la entrada estándar (STDIN).

OPCIONES

-n, --length N
Lee solo N bytes de la entrada. El argumento N también puede incluir una unidad con un prefijo decimal (kB, MB, ..) o un prefijo binario (kiB, MiB, ..), o puede especificarse utilizando un número hexadecimal.
Ejemplos:
Lee los primeros 64 bytes:
$ hexyl --length=64
Lee los primeros 4 kibibytes:
$ hexyl --length=4KiB
Lee los primeros 255 bytes (especificado usando un número hexadecimal):
$ hexyl --length=0xff
-c, --bytes N
Un alias para -n/--length.
-l N
Otro alias para -n/--length.
-s, --skip N
Omite los primeros N bytes de la entrada. El argumento N también puede incluir una unidad (ver --length para detalles). Un valor negativo es válido y buscará desde el final del archivo.
--block-size SIZE
Establece el tamaño de la unidad de bloque a SIZE (por defecto es 512).
Ejemplos:
Establece el tamaño del bloque a 1024 bytes:
$ hexyl --block-size=1024 --length=5block
Establece el tamaño del bloque a 4 kilobytes:
$ hexyl --block-size=4kB --length=2block
-v, --no-squeezing
Muestra todos los datos de entrada. De lo contrario, cualquier número de grupos de líneas de salida que serían idénticas al grupo de líneas precedente, se reemplaza con una línea que consta de un solo asterisco.
--color WHEN
Cuándo usar colores. El modo automático solo muestra colores si la salida se dirige a una terminal interactiva.
Valores posibles:
•
always (siempre, por defecto)
•
auto (automático)
•
never (nunca)
--border STYLE
Si dibujar un borde con caracteres Unicode, caracteres ASCII o ninguno en absoluto.
Valores posibles:
•
unicode (por defecto)
•
ascii
•
none (ninguno)
-o, --display-offset N
Añade N bytes a la posición del archivo mostrada. El argumento N también puede incluir una unidad (ver --length para detalles). Un valor negativo es válido y calcula un desplazamiento relativo al final del archivo.
-h, --help
Imprime información de ayuda.
-V, --version
Imprime información de versión.

NOTAS

Repositorio de fuente:
https://github.com/sharkdp/hexyl

EJEMPLOS

Mostrar un archivo dado:
$ hexyl small.png
Mostrar y ver un archivo dado en el paginador de terminal:
$ hexyl big.png | less -r
Mostrar los primeros 256 bytes de un archivo especial dado:
$ hexyl -n 256 /dev/urandom
