(positifs ou nuls). Un bitmap peutêtre de taille infinie (tous les bits sont définis après un
certain point). Un bitmap peutmême être complet si tous les bits sont définis. Les bitmaps

sont utilisés par

hwloc

pour les ensembles de processeurs du système d'exploitation (qui peuvent en fait être des fils d'exécution matériels) comme par hwloc_cpuset_t (un typedef pour hwloc_nodeset_t (également

un

typedef pour hwloc_bitmap_t). Ceux-ci sont utilisés pour les champs cpuset et nodeset dans la structure hwloc_obj, voir Ensembles d'objets (hwloc_cpuset_t et hwloc_nodeset_t). Les ensembles de CPU et de nœuds sont toujours indexés par le numéro physique du système d'exploitation. Cependant, les utilisateurs ne devraient généralement pas construire m

anuellement les

ensembles de CPU et de nœuds (par ex. avec hwloc_bitmap_set()). On devrait plutôt utiliser les ensembles d'objets existants et les combiner avec hwloc_bitmap_or(), etc. Par exemple, lier le fil d'exécution actuel à une paire de cœurs peut être effectué avec : hwloc_obj_t core1 = ... , core2 = ... ; hwloc_bitmap_t set = hwloc_bitmap_alloc()

int hwloc_bitmap_singlify (hwloc_bitmap_t

bitmap)

Mantiene un solo índice entre los establecidos en el mapa de bits bitmap. Puede ser útil antes de la vinculación para que el proceso no tenga la oportunidad de migrar entre múltiples procesadores en la máscara original. En lugar de ejecutar la tarea en cualquier PU dentro del conjunto de CPU dado, el programador del sistema operativo se verá obligado a ejecutarla en una sola de estas PUs. Evita una sobrecarga de migración y los "ping-pongs" de línea de caché entre

PUs.

Not

a
Esta función NO está destinada a distribuir múltiples procesos dentro de un solo conjunto de CPU. Siempre devuelve el mismo bit único cuando se llama varias veces con el mismo conjunto de entrada. hwloc_distrib() puede usarse para generar conjuntos de CPU para distribuir múltiples tareas bajo un solo objeto multi-PU.

Esta función no puede aplicarse directamente a un conjunto de objetos. Debe aplicarse a una copia (que puede obtenerse con hwloc_bi
