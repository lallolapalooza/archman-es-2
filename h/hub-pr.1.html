NOMBRE

hub-pr - Gestiona las Pull Requests de GitHub para el repositorio actual.

SINOPSIS

hub pr list [-s ESTADO] [-h HEAD] [-b BASE] [-o CLAVE_ORDENACION [-^]] [-f FORMATO] [-L LIMITE]
hub pr checkout NUMERO-PR [RAMA]
hub pr show [-uc] [-f FORMATO] [-h HEAD]
hub pr show [-uc] [-f FORMATO] NUMERO-PR

COMANDOS

list

Lista las Pull Requests en el repositorio actual.

checkout

Descarga el head de una Pull Request en una nueva rama.

Para actualizar la Pull Request con nuevos commits, usa git push.

show

Abre una página de Pull Request en un navegador web. Cuando no se especifica NUMERO-PR, se usa HEAD para buscar Pull Requests abiertas y por defecto se utiliza el nombre de la rama actual. Con --format, imprime información sobre la Pull Request en lugar de abrirla.

OPCIONES

-s, --state ESTADO

Filtra las Pull Requests por ESTADO. Los valores soportados son: "open" (por defecto), "closed", "merged", o "all".

-h, --head RAMA

Muestra las Pull Requests iniciadas desde la RAMA head especificada. El formato "PROPIETARIO:RAMA" debe usarse para las Pull Requests de forks.

-b, --base RAMA

Muestra las Pull Requests basadas en la RAMA especificada.

-f, --format FORMATO

Imprime la lista de Pull Requests de forma bonita usando el FORMATO especificado (por defecto: "%pC%>(8)%i%Creset %t% l%n"). Consulta la sección "FORMATOS DE SALIDA BONITA" de git-log(1) para obtener detalles sobre cómo se utilizan los marcadores en el formato. Los marcadores disponibles son:

%I: número de la Pull Request

%i: número de la Pull Request prefijado con "#"

%U: la URL de esta Pull Request

%S: estado ("open" o "closed")

%pS: estado de la Pull Request ("open", "draft", "merged", o "closed")

%sC: establece el color a rojo o verde, dependiendo del estado

%pC: establece el color según el estado de la Pull Request

%t: título

%l: etiquetas de colores

%L: etiquetas crudas, separadas por comas

%b: cuerpo

%B: rama base

%sB: SHA del commit base

%H: rama head

%sH: SHA del commit head

%sm: SHA del commit de fusión

%au: nombre de usuario del autor

%as: lista de asignados separada por comas

%rs: lista de revisores solicitados separada por comas

%Mn: número de hito

%Mt: título del hito

%cD: fecha de creación (solo día, sin hora)

%cr: fecha de creación, relativa

%ct: fecha de creación, marca de tiempo UNIX

%cI: fecha de creación, formato ISO 8601

%uD: fecha de actualización (solo día, sin hora)

%ur: fecha de actualización, relativa

%ut: fecha de actualización, marca de tiempo UNIX

%uI: fecha de actualización, formato ISO 8601

%mD: fecha de fusión (solo día, sin hora)

%mr: fecha de fusión, relativa

%mt: fecha de fusión, marca de tiempo UNIX

%mI: fecha de fusión, formato ISO 8601

%n: nueva línea

%%: un signo % literal

--color[=CUÁNDO]

Habilita la salida coloreada incluso si la salida estándar no es una terminal. CUÁNDO puede ser uno de "always" (por defecto para --color), "never", o "auto" (por defecto).

-o, --sort CLAVE

Ordena las Pull Requests mostradas por "created" (por defecto), "updated", "popularity", o "long-running".

-^, --sort-ascending

Ordena por fechas ascendentes en lugar de descendentes.

-L, --limit LIMITE

Muestra solo las primeras LIMITE Pull Requests.

-u, --url

Imprime la URL de la Pull Request en lugar de abrirla.

-c, --copy

Copia la URL de la Pull Request al portapapeles en lugar de abrirla.
