Descripción Detallada

Las plataformas con CPUs heterogéneas pueden tener algunos núcleos con características o frecuencias diferentes. Esta API expone las UP idénticas en conjuntos llamados tipos de CPU. Cada UP de la topología solo puede estar en un único tipo.

El número de tipos puede obtenerse con hwloc_cpukinds_get_nr(). Si la plataforma es homogénea, puede haber un único tipo con todas las UP. Si la plataforma o el sistema operativo no expone ninguna información sobre los núcleos de CPU, puede que no haya ningún tipo.

El índice del tipo que describe un conjunto de CPUs dado (si existe, y no parcialmente) puede obtenerse con hwloc_cpukinds_get_by_cpuset().

A partir del índice de un tipo, es posible recuperar información con hwloc_cpukinds_get_info(): un valor de eficiencia abstracto y una lista de atributos de información (por ejemplo, 'CoreType' y 'FrequencyMaxMHz', ver Tipos de CPU).

Un valor de eficiencia más alto significa un rendimiento intrínseco mayor (y posiblemente una menor eficiencia de rendimiento/potencia). Los tipos con valores de eficiencia más bajos se clasifican primero: Pasar 0 como kind_index a hwloc_cpukinds_get_info() devolverá información sobre el tipo de CPU con menor rendimiento pero mayor eficiencia energética. Valores más altos de kind_index devolverán información sobre núcleos de alto rendimiento que consumen mucha energía.

Cuando están disponibles, los valores de eficiencia se recopilan del sistema operativo. Si es así, cpukind_efficiency se establece en el array hwloc_topology_discovery_support . Actualmente esto está disponible en Windows 10, Mac OS X (Darwin) y en algunas plataformas Linux donde la 'capacity' del núcleo se expone en sysfs.

Si el sistema operativo no expone las eficiencias de los núcleos de forma nativa, hwloc intenta calcular las eficiencias comparando los tipos de CPU usando frecuencias (en ARM), o tipos de núcleo y frecuencias (en otras arquitecturas). La variable de entorno HWLOC_CPUKINDS_RANKING puede usarse para cambiar esta heurística, ver Variables de Entorno.

Si hwloc no logra clasificar ningún tipo, por ejemplo porque el sistema operativo no expone las eficiencias y las frecuencias de los núcleos, todos los tipos tendrán una eficiencia desconocida (-1), y no estarán indexados/ordenados de ninguna manera específica.

int hwloc_cpukinds_get_by_cpuset (hwloc_topology_t topology, hwloc_const_bitmap_t cpuset, unsigned long flags)

Obtiene el índice del tipo de CPU que contiene las CPUs listadas en cpuset. flags debe ser 0 por ahora.

Devuelve

El índice del tipo de CPU (entero positivo o 0) en caso de éxito.

-1 con errno establecido a EXDEV si cpuset está solo parcialmente incluido en algún tipo.

-1 con errno establecido a ENOENT si cpuset no está incluido en ningún tipo, ni siquiera parcialmente.

-1 con errno establecido a EINVAL si los parámetros son inválidos.

int hwloc_cpukinds_get_info (hwloc_topology_t topology, unsigned kind_index, hwloc_bitmap_t cpuset, int * efficiency, unsigned * nr_infos, struct hwloc_info_s ** infos, unsigned long flags)

Obtiene el conjunto de CPUs y la información sobre un tipo de CPU en la topología. kind_index identifica un tipo de CPU entre 0 y el número de tipos devuelto por hwloc_cpukinds_get_nr() menos 1.

Si no es NULL, el mapa de bits cpuset se rellenará con el conjunto de UP de este tipo.

El entero apuntado por efficiency, si no es NULL , se rellenará con la clasificación de este tipo de CPU en términos de eficiencia (ver arriba). Va desde 0 hasta el número de tipos (según lo informado por hwloc_cpukinds_get_nr()) menos 1.

Los tipos con menor eficiencia se informan primero.

Si hay un solo tipo en la topología, su eficiencia es 0. Si la eficiencia de algunos tipos de núcleos es desconocida, la eficiencia de todos los tipos se establece a -1, y los tipos se informan sin ningún orden específico.

La lista de atributos de información (por ejemplo, 'CoreType', 'FrequencyMaxMHz' o 'FrequencyBaseMHz', ver Tipos de CPU) y su longitud se devuelven en infos o nr_infos. La lista pertenece a la topología, no debe ser liberada ni modificada.

Si nr_infos o infos es NULL, no se devuelve ninguna información.

flags debe ser 0 por ahora.

Devuelve

0 en caso de éxito.

-1 con errno establecido a ENOENT si kind_index no coincide con ningún tipo de CPU.

-1 con errno establecido a EINVAL si los parámetros son inválidos.

int hwloc_cpukinds_get_nr (hwloc_topology_t topology, unsigned long flags)

Obtiene el número de tipos diferentes de núcleos de CPU en la topología. flags debe ser 0 por ahora.

Devuelve

El número de tipos de CPU (entero positivo) en caso de éxito.

0 si no se encontró información sobre los tipos.

-1 con errno establecido a EINVAL si flags es inválido.

int hwloc_cpukinds_register (hwloc_topology_t topology, hwloc_bitmap_t cpuset, int forced_efficiency, unsigned nr_infos, struct hwloc_info_s * infos, unsigned long flags)

Registra un tipo de CPU en la topología. Marca las UP listadas en cpuset como siendo del mismo tipo con respecto a los atributos dados.

forced_efficiency debe ser -1 si es desconocido. De lo contrario, es un valor de eficiencia abstracto para hacer cumplir la clasificación de todos los tipos si todos ellos tienen eficiencias válidas (y diferentes).

La lista infos de tamaño nr_infos puede usarse para proporcionar nombres e información de valores que describan este tipo de UP.

flags debe ser 0 por ahora.

Los parámetros cpuset e infos se duplicarán internamente, el llamador es responsable de liberarlos.

Si cpuset se superpone con algunos tipos existentes, estos podrían ser modificados o divididos. Por ejemplo, si el tipo existente A contiene las UP 0 y 1, y se registra otro tipo para las UP 1 y 2, habrá 3 tipos resultantes: el tipo existente A se restringe a solo la UP 0; el nuevo tipo B contiene solo la UP 1nformación de A y del tipo recién registrado; el nuevo tipo C contiene solo PU 2 y solo obtiene información del tipo recién registrado.

Nota

La eficiencia forced_efficiency proporcionada a esta función puede ser diferente de la que se informa posteriormente mediante hwloc_cpukinds_get_info() porque hwloc escalará los valores de eficiencia hacia abajo hasta un rango entre 0 y el número de tipos menos 1.

Devuelve

0 en caso de éxito.

-1 con errno establecido a EINVAL si algunos parámetros son inválidos, por ejemplo si cpuset es NULL o está vacío.
