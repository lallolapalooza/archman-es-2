hg-revert(1)

Paquete: mercurial

Licencias: GPL

HG(REVERTIR) HG(REVERTIR)

NOMBRE

hg revert - restaurar archivos a su estado de checkout

SINOPSIS

hg revert [OPCIÓN]... [-r REV] [NOMBRE]...

DESCRIPCIÓN

Nota
Para hacer checkout de revisiones anteriores, deberías usar hg update REV. Para cancelar una fusión no confirmada (y perder tus cambios), usa hg merge --abort.

Sin especificación de revisión, revierte los archivos o directorios especificados a los contenidos que tenían en el padre del directorio de trabajo. Esto restaura los contenidos de los archivos a un estado no modificado y desprogramado añade, elimina, copia y renombra. Si el directorio de trabajo tiene dos padres, debes especificar explícitamente una revisión.

Usando las opciones -r/--rev o -d/--date, revierte los archivos o directorios dados a sus estados de una revisión específica. Como revert no cambia los padres del directorio de trabajo, estos archivos aparecerán como modificados. Esto puede ser útil para "deshacer" uno o todos los cambios anteriores. Consulta hg backout para un método relacionado.

Los archivos modificados se guardan con un sufijo .orig antes de revertirlos. Para deshabilitar estas copias de seguridad, usa --no-backup. Es posible almacenar los archivos de copia de seguridad en un directorio personalizado relativo a la raíz del repositorio configurando la opción de configuración ui.origbackuppath.

Consulta hg help dates para una lista de formatos válidos para -d/--date.

Consulta hg help backout para una forma de revertir el efecto de un changeset anterior.

Retorna 0 en caso de éxito.

OPCIONES

-a, --all
revertir todos los cambios cuando no se proporcionan argumentos
-d,--date <FECHA>
revisión más reciente que coincide con la fecha
-r,--rev <REV>
revertir a la revisión especificada
-C, --no-backup
no guardar copias de seguridad de los archivos
-i, --interactive
seleccionar interactivamente los cambios
-I,--include <PATRÓN[+]>
incluir nombres que coincidan con los patrones dados
-X,--exclude <PATRÓN[+]>
excluir nombres que coincidan con los patrones dados
-n, --dry-run
no realizar acciones, solo imprimir la salida

[+] la opción marcada se puede especificar varias veces
