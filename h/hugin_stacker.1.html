NOMBRE

hugin_stacker - apila imágenes superpuestas en una única imagen

SINOPSIS

hugin_stacker [opciones] --modo=CADENA imágenes

DESCRIPCIÓN

hugin_stacker actúa sobre una pila de imágenes superpuestas y produce una imagen combinada y/o un conjunto de imágenes de salida enmascaradas.

hugin_stacker es útil para, por ejemplo:

  • eliminación automática de turistas (no solo turistas, también otros objetos en movimiento ;-))
  • reducción de ruido
  • visualización de movimiento
  • multiplicidad

OPCIONES

--modo
Selecciona el modo de apilamiento:
min|mínimo|más_oscuro
Selecciona el píxel más oscuro.
max|máximo|más_brillante
Selecciona el píxel más brillante.
avg|promedio|media
Calcula la media para cada posición.
mediana
Calcula la mediana para cada posición.
winsor
Calcula la media recortada de Winsor para cada posición. El parámetro puede establecerse con --winsor-trim=NÚMERO (predeterminado: 0.2).
sigma
Calcula la media recortada por sigma para cada posición. Ajusta con --max-sigma=NÚMERO (predeterminado: 2) y --max-iterations=NÚMERO (predeterminado: 5).

Parámetros adicionales

--salida=ARCHIVO
Establece el nombre del archivo de salida (si no se proporciona, se usa final.tif).
--compresión=valor
Establece la compresión de los archivos de salida. Para archivos jpeg, usa valores entre 0 y 100. Para archivos tiff, los valores válidos son: PACKBITS, DEFLATE, LZW.
--bigtiff
Escribe la salida en formato BigTIFF (solo con salida TIFF).

Enmascarar imágenes de entrada

--mask-input
Además de la salida apilada, hugin_stacker también puede enmascarar las imágenes de entrada (disponible solo para los modos de apilamiento mediana|winsor|clip). Este modo se activa con --mask-input. En este caso, primero se calcula la imagen apilada. Luego se comprueba cada píxel de cada imagen: si el valor de este píxel difiere más de la máscara sigma * desviación estándar de la media/mediana, este píxel se hace visible. Si está dentro del rango mencionado, el píxel se enmascara.
--mask-sigma=NÚMERO
establece el parámetro sigma para --mask-input. El valor predeterminado es 2.
--mask-suffix=CADENA
Genera una imagen de máscara separada para cada imagen de entrada con el nombre nombre_archivo_entradaCADENA. El valor predeterminado es "_mask".
--multi-layer-output
Genera un TIFF en capas con el nombre especificado con --salida. El archivo contiene la imagen promediada como capa 0 y todas las imágenes de entrada como capas adicionales con la máscara como se describe anteriormente.
