NOMBRE

completion - Imprime el script de completado para el shell dado a stdout

SINOPSIS

completion [-h|--help] <SHELL>

DESCRIPCIÓN

Imprime el script de completado para el shell dado a stdout.

Este comando te permite generar un script de completado para un shell dado. El script se imprime en la salida estándar. Si deseas guardarlo en un archivo, simplemente usa la redirección de Unix.

OPCIONES

-h, --help
Imprime la ayuda (ver un resumen con '-h')
<SHELL>
Shell para el que se generará el script de completado

[posibles valores: bash, elvish, fish, powershell, zsh]
