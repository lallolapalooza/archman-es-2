Descripción Detallada

Esta interfaz ofrece formas de recuperar información de topología sobre dispositivos CUDA al usar la API del controlador CUDA.

Documentación de Funciones

int hwloc_cuda_get_device_cpuset (hwloc_topology_t topology, CUdevice cudevice, hwloc_cpuset_t set) [inline]

Obtener el conjunto de CPU de procesadores que están físicamente cerca del dispositivo cudevice. Almacenar en set el conjunto de CPU que describe la localidad del dispositivo CUDA cudevice.

La topología topology y el dispositivo cudevice deben coincidir con la máquina local. La detección de dispositivos de E/S y el componente CUDA no son necesarios en la topología.

La función solo devuelve la localidad del dispositivo. Si se necesita más información sobre el dispositivo, se deben usar objetos del sistema operativo en su lugar, ver hwloc_cuda_get_device_osdev() y hwloc_cuda_get_device_osdev_by_index().

Esta función actualmente solo se implementa de manera significativa para Linux; otros sistemas simplemente obtendrán un cpuset completo.

Retorno

0 si tiene éxito.

-1 si ocurre un error, por ejemplo, si la información del dispositivo no pudo ser encontrada.

hwloc_obj_t hwloc_cuda_get_device_osdev (hwloc_topology_t topology, CUdevice cudevice) [inline]

Obtener el objeto de dispositivo del sistema operativo hwloc que corresponde al dispositivo CUDA cudevice.

Retorno

El objeto de dispositivo del sistema operativo hwloc que describe el dispositivo CUDA dado cudevice.

NULL si no se pudo encontrar ninguno.

La topología topology y el dispositivo cudevice deben coincidir con la máquina local. La detección de dispositivos de E/S y el componente CUDA deben estar habilitados en la topología. De lo contrario, la localidad del objeto aún puede ser encontrada usando hwloc_cuda_get_device_cpuset().

Nota

Esta función no puede funcionar si los dispositivos PCI están filtrados.

El objeto de dispositivo PCI correspondiente puede ser encontrado buscando en el puntero padre del resultado (a menos que los dispositivos PCI estén filtrados).

hwloc_obj_t hwloc_cuda_get_device_osdev_by_index (hwloc_topology_t topology, unsigned idx) [inline]

Obtener el objeto de dispositivo del sistema operativo hwloc que corresponde al dispositivo CUDA cuyo índice es idx.

Retorno

El objeto de dispositivo del sistema operativo hwloc que describe el dispositivo CUDA cuyo índice es idx.

NULL si no se pudo encontrar ninguno.

La topología topology no tiene necesariamente que coincidir con la máquina actual. Por ejemplo, la topología puede ser una importación XML de un host remoto. La detección de dispositivos de E/S y el componente CUDA deben estar habilitados en la topología.

Nota

El objeto de dispositivo PCI correspondiente puede obtenerse mirando el objeto padre del dispositivo del sistema operativo (a menos que los dispositivos PCI estén filtrados).

Esta función es idéntica a hwloc_cudart_get_device_osdev_by_index().

int hwloc_cuda_get_device_pci_ids (hwloc_topology_t topology, CUdevice cudevice, int * domain, int * bus, int * dev) [inline]

Devolver los IDs de dominio, bus y dispositivo del dispositivo CUDA cudevice. El dispositivo cudevice debe coincidir con la máquina local.

Retorno

0 si tiene éxito.

-1 si ocurre un error, por ejemplo, si la información del dispositivo no pudo ser encontrada.

hwloc_obj_t hwloc_cuda_get_device_pcidev (hwloc_topology_t topology, CUdevice cudevice) [inline]

Obtener el objeto de dispositivo PCI hwloc que corresponde al dispositivo CUDA cudevice.

Retorno

El objeto de dispositivo PCI hwloc que describe el dispositivo CUDA cudevice.

NULL si no se pudo encontrar ninguno.

La topología topology y el dispositivo cudevice deben coincidir con la máquina local. La detección de dispositivos de E/S debe estar habilitada en la topología topology. El componente CUDA no es necesario en la topología.
