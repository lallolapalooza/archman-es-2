int hwloc_bitmap_singlify (hwloc_bitmap_t

bitmap)

Mantiene un solo índice entre los establecidos en el mapa de bits bitmap. Puede ser útil antes de la vinculación para que el proceso no tenga la oportunidad de migrar entre múltiples procesadores en la máscara original. En lugar de ejecutar la tarea en cualquier PU dentro del conjunto de CPU dado, el programador del sistema operativo se verá obligado a ejecutarla en una sola de estas PUs. Esto evita la sobrecarga de migración y los "ping-pongs" de línea de caché entre

PUs.

Not

a
Esta función NO está destinada a distribuir múltiples procesos dentro de un solo conjunto de CPU. Siempre devuelve el mismo bit único cuando se llama varias veces con el mismo conjunto de entrada. hwloc_distrib() puede usarse para generar conjuntos de CPU para distribuir múltiples tareas bajo un solo objeto multi-PU.

Esta función no puede aplicarse directamente a un conjunto de objetos. Debe aplicarse a una copia (que puede obtenerse con hwloc_bi

tmap
_dup
