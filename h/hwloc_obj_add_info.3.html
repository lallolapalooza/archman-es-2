int hwloc_obj_add_info (hwloc_obj_t obj, const char * name, const char * value)

Añade el par nombre y valor dado a los atributos de información del objeto dado. El par de información se añade al array de información existente aunque ya exista otro par con el mismo nombre.

Las cadenas de entrada se copian antes de ser añadidas a las informaciones del objeto.

Devuelve

0 en caso de éxito, -1 en caso de error.

Nota

Esta función puede usarse para forzar colores de objeto en la salida gráfica de lstopo añadiendo 'lstopoStyle' como nombre y 'Background=#rrggbb' como valor. Consulte COLORES PERSONALIZADOS en la página del manual de lstopo(1) para más detalles.

Si name o value contienen caracteres no imprimibles, serán descartados al exportar a XML, consulte hwloc_topology_export_xml() en hwloc/export.h.

const char * hwloc_obj_get_info_by_name (hwloc_obj_t obj, const char * name) [inline]

Busca el nombre dado en las informaciones del objeto y devuelve el valor correspondiente. Si varios atributos de información coinciden con el nombre dado, solo se devuelve el primero.

Devuelve

Un puntero a la cadena de valor si existe.

NULL si no existe dicho atributo de información.

Nota

La cadena no debe ser liberada por el llamador, pertenece a la biblioteca hwloc.

int hwloc_obj_set_subtype (hwloc_topology_t topology, hwloc_obj_t obj, const char * subtype)

Establece (o reemplaza) el subtipo de un objeto. El subtipo dado subtype se copia internamente; el llamador es responsable de liberar el subtipo original si es necesario.

Si ya existe otro subtipo en el objeto obj, se reemplaza. El subtipo dado subtype puede ser NULL para eliminar el subtipo existente.

Nota

Esta función se destina principalmente a inicializar el subtipo de objetos añadidos por el usuario, como grupos con hwloc_topology_alloc_group_object().

Devuelve

0 en caso de éxito.

-1 con errno establecido a ENOMEM en caso de fallo al asignar memoria.
