NOMBRE

htsserver - servidor de navegador offline : copia sitios web a un directorio local

SINOPSIS

htsserver [ ruta/ ] [ palabra_clave valor [ palabra_clave valor .. ] ]

DESCRIPCIÓN

htsserver este programa es una interfaz web para httrack(1). , un copiador de sitios web, utilizado por webhttrack(1).

EJEMPLOS

htsserver /usr/share/httrack/ ruta $HOME/websites idioma 1

luego, navega por http://localhost:8080/

ARCHIVOS

/etc/httrack.conf

El archivo de configuración a nivel del sistema.

ENTORNO

HOME
Se utiliza si has definido en /etc/httrack.conf la línea ruta ~/websites/#

DIAGNÓSTICOS

Los errores/advertencias se informan en hts-log.txt ubicado en el directorio de destino.

ERRORES CONOCIDOS

Por favor, informa sobre errores a <bugs@httrack.com>. Incluye un ejemplo completo y autocontenido que permita reproducir el error, y menciona qué versión de (web)httrack estás utilizando. No olvides detallar las opciones utilizadas, la versión del sistema operativo y cualquier otra información que consideres necesaria.
