HYPRPICKER(1) Manual de Comandos Generales HYPRPICKER(1)

NOMBRE

hyprpicker — selector de color compatible con wlroots para Wayland

SINOPSIS

hyprpicker [-anh] [-f fmt]

DESCRIPCIÓN

La utilidad hyprpicker es un selector de color con soporte para varios formatos de salida. Cuando se invoca hyprpicker, el cursor se transforma en una lente de aumento, y hacer clic en cualquier píxel de la pantalla imprimirá el color de ese píxel en la salida estándar. El formato de salida predeterminado es hexadecimal, pero eso se puede configurar con la opción -f.

Las opciones son las siguientes:

-a, --autocopy
Copia automáticamente la salida de hyprpicker al portapapeles. Esta opción requiere que el comando wl-copy(1) esté instalado en el sistema.
-f fmt, --format=fmt
Selecciona el formato en el que se imprimirá el color de los píxeles seleccionados. El argumento fmt no distingue entre mayúsculas y minúsculas. Las opciones disponibles son:
cmyk
(“C% M% Y% K%”)
hex
(“#RRGGBB”)
rgb
(“R G B”)
hsl
(“H S% L%”)
hsv
(“H S% V%”)

El formato predeterminado es hex.

-n, --no-fancy
Deshabilita la salida coloreada. El comportamiento predeterminado es colorear la salida con el mismo color que el píxel seleccionado.
-h, --help
Muestra un mensaje de ayuda y sale del programa con éxito.

AMBIENTE

NO_COLOR
Si se establece, deshabilita la salida coloreada.

ESTADO DE SALIDA

La utilidad hyprpicker sale con 0 en caso de éxito, y >0 si ocurre un error.

EJEMPLOS

Obtener el color de un píxel:

$ hyprpicker

Obtener el color de un píxel en HSL, envuelto en una función CSS hsl():

$ hyprpicker -f hsl | sed 's/^/rgb(/; s/$/)/; y/ /,/'
