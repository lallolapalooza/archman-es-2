Los tipos con valores de eficiencia más bajos se clasifican primero: Pasar 0 como kind_index a hwloc_cpukinds_get_info() devolverá información sobre el tipo de CPU con menor rendimiento pero mayor eficiencia energética. Valores más altos de kind_index devolverán información sobre núcleos de alto rendimiento que consumen mucha energía. Cuando están disponibles, los valores de eficiencia se recopilan del sistema operativo. Si

es

así, cpukind_efficiency se establece en la matriz hwloc_topology_discovery_support [[51]]. Actualmente esto está disponible en Windows 10, Mac OS X (Darwin) y en algunas plataformas Linux donde la 'capacity' del núcleo se expone en sysfs. Si el sistema operativo no expone las eficiencias de los núcleos de forma

nativa,

hwloc intenta calcular las eficiencias comparando los tipos de CPU usando frecuencias (en ARM), o tipos de núcleos y frecuencias (en otras arquitecturas).
