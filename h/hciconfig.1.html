hciconfig(1) Administración del sistema Linux hciconfig(1)

Nombre

hciconfig - Configurar dispositivos Bluetooth

SINOPSIS

hciconfig -h

hciconfig [-a]

hciconfig [-a] hciX [COMANDO [PARÁMETROS]]

DESCRIPCIÓN

hciconfig(1) se utiliza para configurar dispositivos Bluetooth. hciX es el nombre de un dispositivo Bluetooth instalado en el sistema. Si no se proporciona hciX, hciconfig imprime el nombre e información básica sobre todos los dispositivos Bluetooth instalados en el sistema.

Si se proporciona hciX pero no se proporciona ningún comando, imprime información básica solo sobre el dispositivo hciX. La información básica es el tipo de interfaz, dirección BD, MTU ACL, MTU SCO, flags (activado, inicializado, en ejecución, crudo, escaneo de página activado, escaneo de consulta activado, consulta, autenticación activada, encriptación activada).

OPCIONES

-a, --all
Imprime características, tipo de paquete, política de enlace, modo de enlace, clase, Versión además de la información básica.
-h, --help
Muestra las opciones de ayuda

COMANDOS

up
Abre e inicializa el dispositivo HCI.
down
Cierra el dispositivo HCI.
reset
Reinicia el dispositivo HCI.
rstat
Reinicia los contadores de estadísticas.
auth
Habilita la autenticación (establece el dispositivo en modo de seguridad 3).
noauth
Deshabilita la autenticación.
encrypt
Habilita la encriptación (establece el dispositivo en modo de seguridad 3).
noencrypt
Deshabilita la encriptación.
secmgr
Habilita el gestor de seguridad (el soporte actual del kernel es limitado).
nosecmgr
Deshabilita el gestor de seguridad.
piscan
Habilita el escaneo de página y consulta.
noscan
Deshabilita el escaneo de página y consulta.
iscan
Habilita el escaneo de consulta, deshabilita el escaneo de página.
pscan
Habilita el escaneo de página, deshabilita el escaneo de consulta.
ptype [tipo]
Sin tipo, muestra los tipos de paquete actuales. De lo contrario, se establecen todos los tipos de paquete especificados por tipo. tipo es una lista separada por comas de tipos de paquete, donde los tipos de paquete posibles son DM1, DM3, DM5, DH1, DH3, DH5, HV1, HV2, HV3.
name [nombre]
Sin nombre, imprime el nombre local. De lo contrario, establece el nombre local a nombre.
class [clase]
Sin clase, imprime la clase del dispositivo. De lo contrario, establece la clase del dispositivo a clase. clase es un número hexadecimal de 24 bits que describe la clase del dispositivo, según se especifica en la sección 1.2 del documento Bluetooth Assigned Numbers.
voice [voz]
Sin voz, imprime la configuración de voz. De lo contrario, establece la configuración de voz a voz. voz es un número hexadecimal de 16 bits que describe la configuración de voz.
iac [iac]
Sin iac, imprime la configuración actual de IAC. De lo contrario, establece el IAC a iac.
inqtpl [nivel]
Sin nivel, imprime el nivel de potencia de transmisión de consulta actual. De lo contrario, establece el nivel de potencia de transmisión de consulta a nivel.
inqmode [modo]
Sin modo, imprime el modo de escaneo de consulta actual. De lo contrario, establece el modo de escaneo de consulta a modo.
modo Descripción
0 Consulta Estándar
1 Consulta con RSSI
2 Consulta con RSSI o Consulta Extendida
inqdata [datos]
Sin datos, imprime los datos de consulta actuales. De lo contrario, establece los datos de consulta a datos.
inqtype [tipo]
Sin tipo, imprime el tipo de escaneo de consulta actual. De lo contrario, establece el tipo de escaneo de consulta a tipo.
inqparams [ventana:intervalo]
Sin ventana:intervalo, imprime la ventana y el intervalo de escaneo de consulta. De lo contrario, establece la ventana de escaneo de consulta a ventana ranuras y el intervalo de escaneo de consulta a intervalo ranuras.
pageparms [ventana:intervalo]
Sin ventana:intervalo, imprime la ventana y el intervalo de escaneo de página. De lo contrario, establece la ventana de escaneo de página a ventana ranuras y el intervalo de escaneo de página a intervalo ranuras.
pageto [tiempo_de_espera]
Sin tiempo_de_espera, imprime el tiempo de espera de página. De lo contrario, establece el tiempo de espera de página tiempo_de_espera a ranuras.
afhmode [modo]
Sin modo, imprime el modo AFH actual. De lo contrario, establece el modo AFH a modo.
modo Descripción
0 Habilitar
1 Deshabilitar
sspmode [modo]
Sin modo, imprime el modo de Emparejamiento Simple actual. De lo contrario, establece el modo de Emparejamiento Simple a modo.
modo Descripción
0 Habilitar
1 Deshabilitar
aclmtu mtu:paquetes
Establece el MTU ACL a mtu bytes y el tamaño del búfer ACL a paquetes paquetes.
scomtu mtu:paquetes
Establece el MTU SCO a mtu bytes y el tamaño del búfer SCO a paquetes paquetes.
delkey <direccion_bd>
Este comando elimina la clave de enlace almacenada para direccion_bd del dispositivo.
oobdata
Obtiene los datos OOB locales (invalida los datos leídos previamente).
commands
Muestra los comandos soportados.
features
Muestra las características del dispositivo.
version
Muestra la información de la versión.
revision
Muestra la información de revisión.

Sin modo, imprime el modo de enlace. CENTRAL o PERIPHERAL significan, respectivamente, solicitar convertirse en central o permanecer periférico cuando llega una petición de conexión. La palabra clave adicional ACCEPT significa que las conexiones de banda base serán aceptadas incluso si no hay sockets AF_BLUETOOTH escuchando. modo es NONE o una lista separada por comas de palabras clave, donde las posibles palabras clave son CENTRAL y ACCEPT. NONE establece la política de enlace en el comportamiento predeterminado de permanecer periférico y no aceptar conexiones de banda base cuando no hay sockets AF_BLUETOOTH escuchando. Si ACCEPT está presente, el dispositivo aceptará conexiones de banda base incluso cuando no haya sockets AF_BLUETOOTH esc
