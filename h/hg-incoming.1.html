hg-incoming(1)

Paquete: mercurial

Licencias: GPL

HG(INCOMING) HG(INCOMING)

NOMBRE

hg incoming - mostrar cambios nuevos encontrados en el origen

SINOPSIS

hg incoming [-p] [-n] [-M] [-f] [-r REV]... [--bundle NOMBRE_ARCHIVO] [ORIGEN]

DESCRIPCIÓN

Muestra los cambios nuevos encontrados en la ruta/URL especificada o en la ubicación de extracción predeterminada. Estos son los cambios que se habrían extraído con hg pull en el momento en que ejecutó este comando.

Consulte pull para ver los detalles del formato de origen válido.

Con -B/--bookmarks, se muestra el resultado de la comparación de marcadores entre los repositorios locales y remotos. Con -v/--verbose, también se muestra el estado de cada marcador, como se indica a continuación:

BM1               01234567890a añadido
BM2               1234567890ab avanzado
BM3               234567890abc divergido
BM4               34567890abcd cambiado

La acción realizada localmente al extraer depende del estado de cada marcador:

añadido

pull lo creará

avanzado

pull lo actualizará

divergido

pull creará un marcador divergente

cambiado

el resultado depende de los cambios remotos

Desde el punto de vista del comportamiento de extracción, los marcadores que solo existen en el repositorio remoto se tratan como añadido, incluso si de hecho han sido eliminados localmente.

Para el repositorio remoto, usar --bundle evita descargar los cambios dos veces si la entrada se sigue de una extracción.

Ejemplos:

  • mostrar cambios entrantes con parches y descripción completa: 
    hg incoming -vp
  • mostrar cambios entrantes excluyendo fusiones, almacenar un paquete: 
    hg in -vpM --bundle incoming.hg
hg pull incoming.hg
  • listar brevemente los cambios dentro de un paquete: 
    hg in changes.hg -T "{desc|firstline}\n"

    Devuelve 0 si hay cambios entrantes, 1 en caso contrario.

OPCIONES

-f, --force
ejecutar incluso si el repositorio remoto no está relacionado
-n, --newest-first
mostrar primero el registro más nuevo
--bundle <ARCHIVO>
archivo donde almacenar los paquetes
-r,--rev <REV[+]>
un cambio remoto que se pretende añadir
-B, --bookmarks
comparar marcadores
-b,--branch <RAMA[+]>
una rama específica que le gustaría extraer
-p, --patch
mostrar parche
-g, --git
usar formato de diferencia extendido de git
-l,--limit <NUM>
limitar el número de cambios mostrados
-M, --no-merges
no mostrar fusiones
--stat
mostrar resumen de cambios estilo diffstat
-G, --graph
mostrar el DAG de revisiones
--style <ESTILO>
mostrar usando archivo de mapa de plantillas (OBSOLETO)
-T,--template <PLANTILLA>
mostrar con plantilla
-e,--ssh <CMD>
especificar comando ssh a usar
--remotecmd <CMD>
especificar comando hg a ejecutar en el lado remoto
--insecure
no verificar el certificado del servidor (ignorando la configuración web.cacerts)
-S, --subrepos
recorrer subrepositorios

[+] la opción marcada puede especificarse varias veces
