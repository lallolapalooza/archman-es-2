NOMBRE

hxtabletrans - transponer una tabla HTML o XHTML

SINOPSIS

hxtabletrans [ -c ] [ -x ] [ -v ] [ archivo o URL ]

DESCRIPCIÓN

hxtabletrans lee un archivo (o fragmento) HTML o XHTML, encuentra el primer elemento <table> y produce ese elemento con las filas y columnas transpuestas. Es decir, las filas se convierten en columnas y las columnas en filas.

Cualquier agrupación de filas con <thead>, <tbody> o <tfoot> se pierde. Tampoco se pierden comentarios fuera de las celdas.

OPCIONES

Se admiten las siguientes opciones:

-c
También intenta transponer el contenido de las celdas. Si una celda consiste únicamente en flechas horizontales o verticales y elipses (aparte de etiquetas y espacios en blanco), entonces esas flechas y elipses se reemplazan por sus contrapartes transpuestas. Por ejemplo, una flecha hacia la derecha se convierte en una flecha hacia abajo.
-x
Usa sintaxis XML. Los elementos vacíos se escriben con una barra (/) al final, por ejemplo: <br/>
-v
Muestra el número de versión y sale.

ERRORES

hxtabletrans debería comprobar si hay filas que tengan menos celdas que la fila más larga (teniendo en cuenta el efecto de los atributos colspan y rowspan) y crear las celdas omitidas, pero actualmente no lo hace. Por lo tanto, las tablas con filas de longitud desigual pueden no transponerse correctamente.

Las tablas anidadas no se transponen.
