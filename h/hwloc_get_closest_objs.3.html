int hwloc_bitmap_singlify_per_core (hwloc_topology_t topology, hwloc_bitmap_t cpuset, unsigned which)

Elimina las PU de multihilo simultáneo de un conjunto de CPUs. Para cada núcleo en la topología, si cpuset contiene algunas PUs de ese núcleo, modifica cpuset para mantener solo una PU por núcleo.

which especifica qué PU se mantendrá. Las PUs se consideran en orden de índice físico. Si es 0, para cada núcleo, la función mantiene la primera PU que estaba originalmente establecida en cpuset.

Si which es mayor que el número de PUs en un núcleo que estaban originalmente establecidas en cpuset, no se mantiene ninguna PU para ese núcleo.

Devuelve

0.

Nota

Las PUs que no están debajo de un objeto Núcleo se ignoran (por ejemplo, si la topología no contiene ningún objeto Núcleo). Ninguna de ellas se elimina de cpuset.

unsigned hwloc_get_closest_objs (hwloc_topology_t topology, hwloc_obj_t src, hwloc_obj_t *restrict objs, unsigned max)

Realiza un recorrido en profundidad de la topología para encontrar y ordenar todos los objetos que están a la misma profundidad que src. Reporta en objs hasta max objetos físicamente más cercanos a src.

Devuelve

el número de objetos devueltos en objs.

0 si src es un objeto de E/S.

Nota

Esta función requiere que el objeto src tenga un conjunto de CPUs.

hwloc_obj_t hwloc_get_numanode_obj_by_os_index (hwloc_topology_t topology, unsigned os_index) [inline]

Devuelve el objeto de tipo HWLOC_OBJ_NUMANODE con os_index. Esta función es útil para convertir un conjunto de nodos en los objetos de nodo NUMA que contienen. Al recuperar la vinculación actual (por ejemplo, con hwloc_get_membind() con HWLOC_MEMBIND_BYNODESET), uno puede iterar sobre los bits del conjunto de nodos resultante con hwloc_bitmap_foreach_begin(), y encontrar los nodos NUMA correspondientes con esta función.

Devuelve

el objeto de nodo NUMA, o NULL si ninguno coincide.

hwloc_obj_t hwloc_get_obj_below_array_by_type (hwloc_topology_t topology, int nr, hwloc_obj_type_t * typev, unsigned * idxv) [inline]

Encuentra un objeto debajo de una cadena de objetos especificados por tipos e índices. Esta es una versión generalizada de hwloc_get_obj_below_by_type().

Los arreglos typev e idxv deben contener nr tipos e índices.

Comienza desde el objeto raíz del sistema y recorre los arreglos typev e idxv. Para cada par de tipo e índice lógico en los arreglos, busca debajo del objeto encontrado previamente para encontrar el objeto del tipo dado con índice. Los índices se especifican dentro del padre, no dentro del sistema completo.

Por ejemplo, si nr es 3, typev contiene NODE, PACKAGE y CORE, e idxv contiene 0, 1 y 2, devuelve el tercer objeto núcleo debajo del segundo paquete debajo del primer nodo NUMA.

Devuelve

un objeto coincidente si existe, NULL en caso contrario.

Nota

Esta función requiere que todos estos objetos y el objeto raíz tengan un conjunto de CPUs.

hwloc_obj_t hwloc_get_obj_below_by_type (hwloc_topology_t topology, hwloc_obj_type_t type1, unsigned idx1, hwloc_obj_type_t type2, unsigned idx2) [inline]

Encuentra un objeto debajo de otro objeto, ambos especificados por tipos e índices. Comienza desde el objeto raíz del sistema y encuentra el objeto de tipo type1 e índice lógico idx1. Luego busca debajo de este objeto y encuentra otro objeto de tipo type2 e índice lógico idx2. Los índices se especifican dentro del padre, no dentro del sistema completo.

Por ejemplo, si type1 es PACKAGE, idx1 es 2, type2 es CORE e idx2 es 3, devuelve el cuarto objeto núcleo debajo del tercer paquete.

Devuelve

un objeto coincidente si existe, NULL en caso contrario.

Nota

Esta función requiere que estos objetos tengan un conjunto de CPUs.

hwloc_obj_t hwloc_get_obj_with_same_locality (hwloc_topology_t topology, hwloc_obj_t src, hwloc_obj_type_t type, const char * subtype, const char * nameprefix, unsigned long flags)

Devuelve un objeto de un tipo diferente con la misma localidad. Si el objeto de origen src es un tipo normal o de memoria, esta función devuelve un objeto de tipo type con los mismos conjuntos de CPU y nodo, ya sea debajo o encima en la jerarquía.

Si el objeto de origen src es un dispositivo PCI o de E/S dentro de un dispositivo PCI, la función puede devolver ese dispositivo PCI, u otro dispositivo de E/S en el mismo padre PCI. Esto puede ser útil, por ejemplo, para convertir entre dispositivos de E/S como 'nvml0' o 'rsmi1' utilizados en estructuras de distancia al dispositivo PCI, o el dispositivo de E/S CUDA o OpenCL que corresponden a la misma tarjeta física.

Si no es NULL, el parámetro subtype solo selecciona objetos cuyo atributo de subtipo existe y es subtype (sin distinción de mayúsculas y minúsculas), por ejemplo, 'OpenCL' o 'CUDA'.

Si no es NULL, el parámetro nameprefix solo selecciona objetos cuyo atributo de nombre existe y comienza con nameprefix (sin distinción de mayúsculas y minúsculas), por ejemplo, 'rsmi' para coincidir con 'rsmi0'.

Si coinciden varios objetos, se devuelve el primero.

Esta función no recorrerá la jerarquía a través de puentes ya que la localidad PCI puede ser diferente. Esta función tampoco puede convertir entre objetos normales/de memoria y objetos de E/S o Varios.

flags debe ser 0 por ahora.

Devuelve

Un objeto con localidad idéntica, que coincide con subtype y nameprefix si existe alguno.

NULL si no se pudo encontrar ningún objeto coincidente, o si el objeto de origen y el tipo de destino son incompatibles, por ejemplo, al convertir entre objetos de CPU y de E/S.

hwloc_obj_t hwloc_get_pu_obj_by_os_index (hwloc_topology_t topology, unsigned os_index) [inline]

Devuelve el objeto de tipo HWLOC_OBJ_PU con os_index. Esta función es útil para convertir un conjunto de PUs en los objetos de PU correspondientes. Cuando se recupera la vinculación actual (por ejemplo, con hwloc_get_cpubind() con HWLOC_CPUBIND_BYPUSET), uno puede iterar sobre los bits del conjunto de PUs resultante con hwloc_bitmap_foreach_begin(), y encontrar las PUs correspondientes con esta función.

Devuelve

la PU de destino, o NULL si ninguna coincide.

hwloc_get_pu_os_index

Devuelve el objeto de tipo HWLOC_OBJ_PU con el índice del sistema operativo os_index.

Esta función es útil para convertir un conjunto de CPU en los objetos PU que contiene. Al recuperar el enlace actual (por ejemplo, con hwloc_get_cpubind()), se puede iterar sobre los bits del conjunto de CPU resultante con hwloc_bitmap_foreach_begin() y encontrar los PUs correspondientes con esta función.

Retorna

el objeto PU, o NULL si ninguno coincide.
