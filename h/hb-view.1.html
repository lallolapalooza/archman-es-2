NOMBRE

hb-view - página del manual para hb-view 12.2.0

DESCRIPCIÓN

Uso:

hb-view [OPCIÓN???] [ARCHIVO-DE-FUENTE] [TEXTO]

Ver texto con la fuente dada.

Opciones de ayuda:

Mostrar opciones de ayuda
--help-all
Mostrar todas las opciones de ayuda

--help-font
Opciones para la instancia de la fuente
--help-variations
Opciones para las variaciones de fuente utilizadas
--help-text
Opciones para el texto de entrada
--help-text-context
Opciones para el texto de contexto de entrada

Opciones de cara de fuente:

--font-file=nombre-de-archivo
Establecer el nombre del archivo de fuente
-y, --face-index=índice
Establecer el índice de cara (por defecto: 0)
--face-loader=cargador
Establecer el cargador de cara a utilizar (por defecto: ot)
Los cargadores de cara compatibles son: ot/ft
--list-face-loaders
Listar los cargadores de cara disponibles y salir

Opciones de instancia de fuente:

--font-size=1/2 enteros o 'upem'
Tamaño de fuente (por defecto: 256)
--font-ppem=1/2 enteros
Establecer píxeles x,y por EM (por defecto: 0; deshabilitado)
--font-ptem=tamaño-de-punto
Establecer el tamaño en puntos de la fuente (por defecto: 0; deshabilitado)
--font-bold=1/2 números; ej. 0.05
Establecer negrita sintética (por defecto: 0)
--font-grade=1/2 números; ej. 0.05
Establecer grado sintético (por defecto: 0)
--font-slant=inclinación ratio; ej. 0.2
Establecer inclinación sintética (por defecto: 0)
--font-funcs=impl
Establecer la implementación de funciones de fuente a utilizar (por defecto: ot)
Las implementaciones de funciones de fuente compatibles son: ot/ft
--list-font-funcs
Listar las funciones de fuente disponibles y salir
--ft-load-flags=entero
Establecer las banderas de carga de FreeType (por defecto: 2)

Opciones de variaciones:

--named-instance=índice
Establecer el índice de instancia con nombre (por defecto: ninguno)
--variations=lista
Lista separada por comas de variaciones de fuente
Las variaciones se establecen globalmente. El formato para especificar la configuración de variaciones sigue. Todos los valores válidos de font-variation-settings de CSS, excepto 'normal' y 'inherited', también se aceptan, aunque no se documentan a continuación.
El formato es una etiqueta, seguida opcionalmente por un signo igual y luego un número. Por ejemplo:
"wght=500" "slnt=-7.5"

Opciones de texto:

Si no se proporciona texto, la entrada estándar se utiliza para la entrada.

--text=cadena
Establecer el texto de entrada
--text-file=nombre-de-archivo
Establecer el nombre del archivo de texto de entrada
-u, --unicodes=lista de números hexadecimales
Establecer los puntos de código Unicode de entrada
--single-par
Tratar el texto como un solo párrafo

Opciones de contexto textual:

--text-before=cadena

--text-after=cadena

--unicodes-before=lista de números hexadecimales
Establecer el contexto de puntos de código Unicode antes de cada línea
--unicodes-after=lista de números hexadecimales
Establecer el contexto de puntos de código Unicode después de cada línea

Ejemplos:

Ver un texto con la fuente por defecto:
hb-view --text="Hola Mundo"
Ver un texto con una fuente específica:
hb-view --font-file=./fonts/Arial.ttf --text="Hola Mundo"
Ver un texto con características específicas:
hb-view --font-file=./fonts/Arial.ttf --text="Hola Mundo" --features="kern=1"
Ver un texto en formato HTML:
hb-view --text="Hola Mundo" --output-format=html
Ver un texto y guardarlo en un archivo PNG:
hb-view --text="Hola Mundo" --output-format=png --output-file=hola.png
