Descripción detallada

Esta interfaz ofrece formas de recuperar información de topología sobre dispositivos OpenCL.

Solo las implementaciones OpenCL de AMD y NVIDIA ofrecen actualmente información útil de localidad sobre sus dispositivos.

Documentación de funciones

Obtener el conjunto de CPU de procesadores que están físicamente cerca del dispositivo OpenCL dispositivo. Almacenar en conjunto el conjunto de CPU que describe la localidad del dispositivo OpenCL dispositivo.

La topología topologia y el dispositivo dispositivo deben coincidir con la máquina local. La detección de dispositivos de E/S y el componente OpenCL no son necesarios en la topología.

La función solo devuelve la localidad del dispositivo. Si se necesita más información sobre el dispositivo, se deben usar objetos del sistema operativo en su lugar, consulte hwloc_opencl_get_device_osdev() y hwloc_opencl_get_device_osdev_by_index().

Actualmente, esta función solo se implementa de manera significativa para Linux con la implementación OpenCL de AMD o NVIDIA; otros sistemas simplemente obtendrán un conjunto de CPU completo.

Devuelve

0 si tiene éxito.

-1 si hay un error, por ejemplo, si no se pudo encontrar el dispositivo.

hwloc_obj_t hwloc_opencl_get_device_osdev (hwloc_topology_t topologia, cl_device_id dispositivo) [en línea]

Obtener el objeto de dispositivo del sistema operativo hwloc correspondiente al dispositivo OpenCL dispositivoX.

Devuelve

El objeto de dispositivo del sistema operativo hwloc correspondiente al dispositivo OpenCL dado dispositivo.

NULL si no se encontró ninguno, por ejemplo, si los atributos OpenCL requeridos no están disponibles.

Esta función actualmente solo funciona en dispositivos OpenCL de AMD y NVIDIA que admiten extensiones OpenCL relevantes. Se debe preferir hwloc_opencl_get_device_osdev_by_index() siempre que sea posible, es decir, cuando se conocen el índice de plataforma y el índice de dispositivo.

La topología topologia y el dispositivo dispositivo deben coincidir con la máquina local. La detección de dispositivos de E/S y el componente OpenCL deben estar habilitados en la topología. Si no es así, la localidad del objeto aún puede encontrarse utilizando hwloc_opencl_get_device_cpuset().

Nota

Esta función no puede funcionar si los dispositivos PCI están filtrados.

El objeto del dispositivo PCI correspondiente puede encontrarse mirando el puntero padre del resultado (a menos que los dispositivos PCI estén filtrados).

hwloc_obj_t hwloc_opencl_get_device_osdev_by_index (hwloc_topology_t topologia, unsigned indice_plataforma, unsigned indice_dispositivo) [en línea]

Obtener el objeto de dispositivo del sistema operativo hwloc correspondiente al dispositivo OpenCL para los índices dados.

Devuelve

El objeto de dispositivo del sistema operativo hwloc que describe el dispositivo OpenCL cuyo índice de plataforma es indice_plataforma, y cuyo índice de dispositivo dentro de esta plataforma es indice_dispositivo.

NULL si no hay ninguno.

La topología topologia no tiene que coincidir necesariamente con la máquina actual. Por ejemplo, la topología puede ser una importación XML de un host remoto. La detección de dispositivos de E/S y el componente OpenCL deben estar habilitados en la topología.

Nota

El objeto del dispositivo PCI correspondiente se puede obtener mirando el objeto padre del dispositivo del sistema operativo (a menos que los dispositivos PCI estén filtrados).

int hwloc_opencl_get_device_pci_busid (cl_device_id dispositivo, unsigned * dominio, unsigned * bus, unsigned * dev, unsigned * func) [en línea]

Devolver los IDs de dominio, bus y dispositivo del dispositivo OpenCL dispositivo. El dispositivo dispositivo debe coincidir con la máquina local.

Devuelve

0 si tiene éxito.

-1 si hay un error, por ejemplo, si no se pudo encontrar la información del dispositivo.
