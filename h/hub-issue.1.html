NOMBRE

hub-issue - Gestionar Issues de GitHub para el repositorio actual.

SINOPSIS

hub issue [-a ASIGNADO] [-c CREADOR] [-@ USUARIO] [-s ESTADO] [-f FORMATO] [-M HITOS] [-l ETIQUETAS] [-d FECHA] [-o CLAVE_ORDENACION [-^]] [-L LIMITE]
hub issue mostrar [-f FORMATO] NUMERO
hub issue crear [-oc] [-m MENSAJE|-F ARCHIVO] [--editar] [-a USUARIOS] [-M HITOS] [-l ETIQUETAS]
hub issue actualizar NUMERO [-m MENSAJE|-F ARCHIVO] [--editar] [-a USUARIOS] [-M HITOS] [-l ETIQUETAS] [-s ESTADO]
hub issue etiquetas [--color]
hub issue transferir NUMERO REPO

COMANDOS

Sin argumentos, muestra una lista de issues abiertas.

mostrar

Muestra un issue existente especificado por NUMERO.

crear

Abre un issue en el repositorio actual.

actualizar

Actualiza campos de un issue existente especificado por NUMERO. Usa --editar para editar el título y el mensaje interactivamente en el editor de texto.

etiquetas

Lista las etiquetas disponibles en este repositorio.

transferir

Transfiere un issue a otro repositorio.

OPCIONES

-a, --asignado ASIGNADO

En modo lista, muestra solo issues asignados a ASIGNADO.

-a, --asignar USUARIOS

Una lista separada por comas de nombres de usuario de GitHub para asignar al issue creado.

-c, --creador CREADOR

Muestra solo issues creados por CREADOR.

-@, --mencionado USUARIO

Muestra solo issues que mencionan a USUARIO.

-s, --estado ESTADO

Muestra issues con estado ESTADO (por defecto: "abierto").

-f, --formato FORMATO

Imprime el contenido de los issues de forma bonita usando el formato FORMATO (por defecto: "%sC%>(8)%i%Creset %t% l%n"). Consulta la sección "FORMATOS BONITOS" de git-log(1) para obtener información adicional sobre cómo se usan los marcadores de posición en el formato. Los marcadores de posición disponibles para los issues son:

%I: número del issue

%i: número del issue prefijado con "#"

%U: la URL de este issue

%S: estado (es decir, "abierto", "cerrado")

%sC: establece el color a rojo o verde, dependiendo del estado del issue.

%t: título

%l: etiquetas coloreadas

%L: etiquetas sin formato, separadas por comas

%b: cuerpo

%au: nombre de login del autor

%as: lista separada por comas de los asignados

%Mn: número del hito

%Mt: título del hito

%NC: número de comentarios

%Nc: número de comentarios entre paréntesis, o cadena vacía si es cero.

%cD: fecha de creación (solo día, sin hora)

%cr: fecha de creación, relativa

%ct: fecha de creación, marca de tiempo UNIX

%cI: fecha de creación, formato ISO 8601

%uD: fecha de actualización (solo día, sin hora)

%ur: fecha de actualización, relativa

%ut: fecha de actualización, marca de tiempo UNIX

%uI: fecha de actualización, formato ISO 8601

%n: nueva línea

%%: un signo % literal

--color[=CUANDO]

Habilita la salida coloreada incluso si stdout no es una terminal. CUANDO puede ser uno de "siempre" (por defecto para --color), "nunca", o "auto" (por defecto).

-m, --mensaje MENSAJE

El texto hasta la primera línea en blanco en MENSAJE se trata como el título del issue, y el resto se usa como descripción del issue en formato Markdown.

Cuando se pasan múltiples --mensaje, sus valores se concatenan con una línea en blanco entre ellos.

Cuando ni --mensaje ni --archivo se proporcionan a issue create, se abrirá un editor de texto para redactar el título y la descripción.

-F, --archivo ARCHIVO

Lee el título y la descripción del issue desde ARCHIVO. Pasa "-" para leer desde la entrada estándar en su lugar. Consulta --mensaje para las reglas de formato.

-e, --editar

Abre el título y la descripción del issue en un editor de texto antes de enviarlos. Esto se puede usar en combinación con --mensaje o --archivo.

-o, --navegar

Abre el nuevo issue en un navegador web.

-c, --copiar

Pone la URL del nuevo issue en el portapapeles en lugar de imprimirla.

-M, --hito NOMBRE

Muestra solo issues de un hito de GitHub con el nombre NOMBRE.

Al abrir un issue, añade este issue a un hito de GitHub con el nombre NOMBRE. Pasar el número del hito está obsoleto.

-l, --etiquetas ETIQUETAS

Muestra solo issues con ciertas etiquetas.

Al abrir un issue, añade una lista de etiquetas separada por comas a este issue.

-d, --desde FECHA

Muestra solo issues actualizados en o después de FECHA en formato ISO 8601.

-o, --ordenar CLAVE

Ordena los issues mostrados por "creados" (por defecto), "actualizados" o "comentarios".

-^ --ordenar-ascendente

Ordena por fechas ascendentes en lugar de descendentes.

-L, --limitar LIMITE

Muestra solo los primeros LIMITE issues.

--incluir-pulls

Incluye solicitudes de extracción (pull requests) además de issues.

--color

Habilita la salida coloreada para la lista de etiquetas.
