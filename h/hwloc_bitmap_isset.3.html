int hwloc_bitmap_singlify (hwloc_bitmap_t bitmap)

Mantiene un único índice entre los establecidos en el mapa de bits bitmap. Puede ser útil antes de enlazar para que el proceso no tenga la oportunidad de migrar entre varios procesadores en la máscara original. En lugar de ejecutar la tarea en cualquier PU dentro del conjunto de CPU dado, el planificador del sistema operativo se verá obligado a ejecutarla en una sola de estas PUs. Evita una sobrecarga de migración y el ping-pong de líneas de caché entre PUs.

Nota

Esta función NO está pensada para distribuir múltiples procesos dentro de un único conjunto de CPU. Siempre devuelve el mismo bit único cuando se llama varias veces sobre el mismo conjunto de entrada. hwloc_distrib() puede utilizarse para generar conjuntos de CPU para distribuir múltiples tareas bajo un único objeto multi-PU.

Esta función no se puede aplicar directamente a un conjunto de objetos. Debe aplicarse a una copia (que puede obtenerse con hwloc_bitmap_dup()).

int hwloc_bitmap_snprintf (char *restrict buf, size_t buflen, hwloc_const_bitmap_t bitmap)

Convierte un mapa de bits a una cadena en el formato hwloc por defecto. Tenga en cuenta que si el mapa de bits es un conjunto de CPU o de nodos, contiene índices físicos.

Imprime los bits establecidos dentro de un mapa de bits como una lista separada por comas de bloques hexadecimales de 32 bits. Un mapa de bits que contiene los bits 1, 33, 34 y todos los comprendidos entre 64 y 95 se imprime como '0xffffffff,0x00000006,0x00000002'.

Se pueden escribir hasta buflen caracteres en el búfer buf.

Si buflen es 0, buf puede ser NULL sin problemas.

Devuelve

el número de caracteres que se escribieron realmente si no se truncaron, o que se habrían escrito (sin incluir el \0 final).

-1 en caso de error.

int hwloc_bitmap_sscanf (hwloc_bitmap_t bitmap, const char *restrict string)

Analiza una cadena de mapa de bits en el formato hwloc por defecto y la almacena en el mapa de bits bitmap. Tenga en cuenta que si el mapa de bits es un conjunto de CPU o de nodos, la cadena de entrada debe contener índices físicos.

La cadena de entrada debe ser una lista de bloques hexadecimales de 32 bits separada por comas. La cadena '0xffffffff,0x6,0x2' se analiza como un mapa de bits que contiene todos los bits entre 64 y 95, y los bits 33, 34 y 1.

Devuelve

0 si tiene éxito, -1 en caso de error.

int hwloc_bitmap_taskset_asprintf (char ** strp, hwloc_const_bitmap_t bitmap)

Convierte un mapa de bits en una cadena recién asignada específica para taskset. Tenga en cuenta que si el mapa de bits es un conjunto de CPU o de nodos, contiene índices físicos.

El programa taskset manipula cadenas de mapas de bits que contienen un único número hexadecimal (posiblemente muy largo) que comienza con 0x. Un mapa de bits que contiene los bits 1, 33, 34 y todos los comprendidos entre 64 y 95 se imprime como '0xffffffff0000000600000002'.

Devuelve

el número de caracteres que se escribieron (sin incluir el \0 final).

-1 en caso de error, por ejemplo con errno establecido a ENOMEM en caso de fallo al asignar la cadena de salida.

El programa taskset manipula cadenas de mapas de bits que contienen un único número hexadecimal (posiblemente muy largo) que comienza con 0x. Un mapa de bits que contiene los bits 1, 33, 34 y todos los comprendidos entre 64 y 95 se imprime como '0xffffffff0000000600000002'.
