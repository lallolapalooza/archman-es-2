HOSTS.CONF(5) Manual de NUT HOSTS.CONF(5)

NOMBRE

hosts.conf - Control de acceso para programas CGI de Network UPS Tools

DESCRIPCIÓN

Los programas CGI (upsset.cgi(8), upsstats.cgi(8), upsimage.cgi(8)) utilizan este archivo para determinar si se les permite hablar con un host. Esto evita que visitantes aleatorios utilicen su servidor web para molestar a otros creando conexiones salientes.

NOTAS IMPORTANTES

•El contenido de este archivo debe ser ASCII puro (los códigos de caracteres que no estén en el rango se ignorarán con un mensaje de advertencia).
•Este archivo no contiene contraseñas. El monitoreo de solo lectura en NUT es anónimo, y el programa upsset(8) solicita credenciales en la sesión del navegador al comandar una UPS particular (el servidor web debe estar protegido, según lo informado al programa por el archivo upsset.conf(5)).

DIRECTIVAS

MONITOR ups descripción

El elemento ups tiene el formato nombre_ups[@nombre_host[:puerto]].

Para permitir conexiones a una UPS llamada "snoopy" en un sistema llamado "doghouse" que ejecuta upsd en el puerto 7877, se vería así:

MONITOR snoopy@doghouse:7877 "Joe Cool"

La descripción debe ser un solo elemento, por lo que si tiene espacios, debe estar entre comillas como se muestra arriba. El nombre_host predeterminado es "localhost".

VER TAMBIÉN

upsset.cgi(8), upsstats.cgi(8), upsimage.cgi(8)
