HNSDV_QUERY_DEVICE(3) Manual de Verbos Directos HNS HNSDV_QUERY_DEVICE(3)

NOMBRE

hnsdv_query_device - Consulta atributos específicos del dispositivo hns

SINOPSIS

#include <infiniband/hnsdv.h>
int hnsdv_query_device(struct ibv_context *context,
                       struct hnsdv_context *attrs_out);

DESCRIPCIÓN

hnsdv_query_device() consulta atributos específicos del dispositivo hns.

ARGUMENTOS

Por favor, consulte la página del manual de ibv_query_device(3) para context.

attrs_out

struct hnsdv_context {
        uint64_t comp_mask;
        uint64_t flags;
        uint8_t congest_type;
        uint8_t reserved[7];
};
comp_mask
Máscara de bits que especifica qué campos de la estructura son válidos:

HNSDV_CONTEXT_MASK_CONGEST_TYPE: Se admite el algoritmo de control de congestión.

congest_type
Máscara de bits de los algoritmos de control de congestión admitidos.

HNSDV_QP_CREATE_ENABLE_DCQCN: Notificación de Congestión Cuantificada de Centro de Datos HNSDV_QP_CREATE_ENABLE_LDCP: Protocolo de Control de Baja Latencia HNSDV_QP_CREATE_ENABLE_HC3: Control de Congestión Convergente de Huawei HNSDV_QP_CREATE_ENABLE_DIP: Notificación de Congestión Cuantificada basada en IP de Destino

VALOR DE RETORNO

hnsdv_query_device() devuelve 0 si tiene éxito, o el valor de errno si falla (lo que indica el motivo de la falla).

VER TAMBIÉN

ibv_query_device(3)

NOTAS

•
flags es un campo de salida y actualmente no tiene valores.
