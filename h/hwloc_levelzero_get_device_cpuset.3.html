hwlocality_levelzero - Interoperabilidad con la interfaz oneAPI Level Zero.

Descripción Detallada

Esta interfaz ofrece formas de obtener información de topología sobre dispositivos administrados por la API Level Zero, tanto para dispositivos principales (API ZE) como para dispositivos Sysman (API ZES).

Documentación de Funciones

int hwloc_levelzero_get_device_cpuset (hwloc_topology_t topology, ze_device_handle_t device, hwloc_cpuset_t set) [inline]

Obtiene el conjunto de CPU de procesadores lógicos que están físicamente cerca del dispositivo Level Zero device. Almacena en set el conjunto de CPU que describe la localidad del dispositivo Level Zero device.

La topología topology y el dispositivo device deben coincidir con la máquina local. La biblioteca Level Zero debe haber sido inicializada con zeInit(). La detección de dispositivos de E/S y el componente Level Zero no son necesarios en la topología.

La función solo devuelve la localidad del dispositivo. Si se necesita más información sobre el dispositivo, se deben usar objetos del sistema operativo en su lugar, ver hwloc_levelzero_get_device_osdev().

Esta función actualmente solo se implementa de manera significativa en Linux; otros sistemas simplemente obtendrán un conjunto de CPU completo.

Retorna

0 en caso de éxito.

-1 en caso de error, por ejemplo, si no se pudo encontrar la información del dispositivo.

Nota

zeDevicePciGetPropertiesExt() debe ser compatible, o se devolverá la localidad de toda la máquina.

hwloc_obj_t hwloc_levelzero_get_device_osdev (hwloc_topology_t topology, ze_device_handle_t device) [inline]

Obtiene el objeto de dispositivo del sistema operativo de hwloc correspondiente al dispositivo Level Zero device.

Retorna

El objeto de dispositivo del sistema operativo de hwloc que describe el dispositivo Level Zero dado device.

NULL si no se pudo encontrar ninguno.

La topología topology y el dispositivo dv_ind deben coincidir con la máquina local. La biblioteca Level Zero debe haber sido inicializada con zeInit(). La detección de dispositivos de E/S y el componente Level Zero deben estar habilitados en la topología. De lo contrario, la localidad del objeto aún se puede encontrar usando hwloc_levelzero_get_device_cpuset().

Nota

Si el dispositivo ZE de entrada es en realidad un subdispositivo, entonces su padre (dispositivo raíz) se traduce, es decir, se devuelve el dispositivo principal del sistema operativo de hwloc en lugar de uno de sus hijos.

El dispositivo PCI de hwloc correspondiente se puede encontrar buscando el puntero padre del resultado (a menos que los dispositivos PCI estén filtrados).

zeDevicePciGetPropertiesExt() debe ser compatible.
