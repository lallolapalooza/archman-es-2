NOMBRE

httpie

SINOPSIS

httpie

DESCRIPCIÓN

Interfaz de gestión para el propio HTTPie. https://httpie.io/docs#manager

Ten en cuenta que es posible que busques los comandos http/https para enviar peticiones HTTP. Este comando solo está disponible para gestionar los plugins de HTTPie y la configuración relacionada.

Si buscas las páginas del manual de los comandos http/https, prueba uno de los siguientes:
$ man http
$ man https

httpie cli exportar-argumentos

Exportar opciones disponibles para la CLI

-f, --formato

Formato en el que exportar.

httpie cli verificar-actualizaciones

Comprobar si hay actualizaciones

httpie cli sesiones actualizar

Actualiza la sesión HTTPie dada con el último diseño. Una lista de cambios entre diferentes versiones de sesiones se puede encontrar en la documentación oficial.

NOMBRE-DE-HOST

El host al que pertenece esta sesión.

NOMBRE-O-RUTA-DE-SESION

El nombre o la ruta de la sesión que se actualizará.

--enlazar-cookies

Enlaza cookies sin dominio al host al que pertenece la sesión.

httpie cli sesiones actualizar-todas

Actualiza todas las sesiones nombradas con el último diseño. Una lista de cambios entre diferentes versiones de sesiones se puede encontrar en la documentación oficial.

--enlazar-cookies

Enlaza cookies sin dominio al host al que pertenece la sesión.
