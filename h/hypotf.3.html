hypot(3) Manual de Funciones de Biblioteca hypot(3)

NOMBRE

hypot, hypotf, hypotl - función de distancia euclidiana

BIBLIOTECA

Biblioteca matemática (libm, -lm)

SINOPSIS

#include <math.h>
double hypot(double x, double y);
float hypotf(float x, float y);
long double hypotl(long double x, long double y);
Requisitos de Macro de Prueba de Funciones para glibc (ver feature_test_macros(7)):

hypot():

    _ISOC99_SOURCE || _POSIX_C_SOURCE >= 200112L
        || _XOPEN_SOURCE
        || /* Desde glibc 2.19: */ _DEFAULT_SOURCE
        || /* glibc <= 2.19: */ _BSD_SOURCE || _SVID_SOURCE

hypotf(), hypotl():

    _ISOC99_SOURCE || _POSIX_C_SOURCE >= 200112L
        || /* Desde glibc 2.19: */ _DEFAULT_SOURCE
        || /* glibc <= 2.19: */ _BSD_SOURCE || _SVID_SOURCE

DESCRIPCIÓN

Estas funciones devuelven sqrt(x*x+y*y). Esta es la longitud de la hipotenusa de un triángulo rectángulo con lados de longitud x e y, o la distancia del punto (x,y) desde el origen.

El cálculo se realiza sin desbordamiento o subdesbordamiento indebido durante los pasos intermedios del cálculo.

VALOR DEVUELTO

En caso de éxito, estas funciones devuelven la longitud de la hipotenusa de un triángulo rectángulo con lados de longitud x e y.

Si x o y es un infinito, se devuelve infinito positivo.

Si x o y es un NaN, y el otro argumento no es un infinito, se devuelve un NaN.

Si el resultado se desborda, ocurre un error de rango y las funciones devuelven HUGE_VAL, HUGE_VALF o HUGE_VALL, respectivamente.

Si ambos argumentos son subnormales y el resultado es subnormal, ocurre un error de rango y se devuelve el resultado correcto.

ERRORES

Ver math_error(7) para obtener información sobre cómo determinar si ha ocurrido un error al llamar a estas funciones.

Los siguientes errores pueden ocurrir:

Error de rango: desbordamiento del resultado
errno se establece en ERANGE. Se genera una excepción de punto flotante de desbordamiento (FE_OVERFLOW).
Error de rango: subdesbordamiento del resultado
Se genera una excepción de punto flotante de subdesbordamiento (FE_UNDERFLOW).
Estas funciones no establecen errno para este caso.

ATRIBUTOS

Para obtener una explicación de los términos utilizados en esta sección, ver attributes(7).

Interfaz Atributo Valor
hypot (), hypotf (), hypotl () Seguridad en hilos MT-Safe

ESTÁNDARES

C11, POSIX.1-2008.

HISTORIA

C99, POSIX.1-2001.

La variante que devuelve double también cumple con SVr4, 4.3BSD.

VER TAMBIÉN

cabs(3), sqrt(3)
