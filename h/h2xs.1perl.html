H2XS(1perl) Guía del Programador de Perl H2XS(1perl)

NOMBRE

h2xs - convierte archivos de cabecera C .h a extensiones Perl

SINOPSIS

h2xs [OPCIONES ...] [archivo_cabecera ... [librerias_adicionales]]

h2xs -h|-?|--help

DESCRIPCIÓN

h2xs construye una extensión Perl a partir de archivos de cabecera C. La extensión incluirá funciones que se pueden usar para recuperar el valor de cualquier declaración #define que estuviera en los archivos de cabecera C.

El nombre_modulo se usará para el nombre de la extensión. Si no se suministra nombre_modulo, se usará el nombre del primer archivo de cabecera, con el primer carácter en mayúscula.

Si la extensión pudiera necesitar librerías adicionales, estas deben incluirse aquí. El Makefile.PL de la extensión se encargará de comprobar si las librerías existen realmente y cómo deben cargarse. Las librerías adicionales deben especificarse en el formato -lm -lposix, etc., igual que en la línea de comandos de cc. Por defecto, el Makefile.PL buscará en la ruta de librerías determinada por Configure. Esa ruta se puede aumentar incluyendo argumentos de la forma -L/otra/ruta/libreria en el argumento de librerías adicionales.

A pesar de su nombre, h2xs también se puede usar para crear un módulo Perl puro esqueleto. Ver la opción -X.

OPCIONES

-A, --omit-autoload
Omite todas las facilidades de carga automática. Esto es lo mismo que -c pero también elimina la declaración "use AutoLoader" del archivo .pm.
-B, --beta-version
Usa un número de versión estilo alfa/beta. Hace que el número de versión sea "0.00_01" a menos que se especifique -v.
-C, --omit-changes
Omite la creación del archivo Changes y añade una sección HISTORY a la plantilla POD.
-F, --cpp-flags=addflags
Banderas adicionales a especificar al preprocesador C al escanear la cabecera para declaraciones de funciones. Escribe estas opciones en el Makefile.PL generado también.
-M, --func-mask=expresión regular
selecciona funciones/macros a procesar.
-O, --overwrite-ok
Permite que se sobrescriba un directorio de extensión preexistente.
-P, --omit-pod
Omite la sección POD generada automáticamente.
-X, --omit-XS
Omite la porción XS. Se usa para generar un módulo Perl puro esqueleto. "-c" y "-f" están implícitamente habilitados.
-a, --gen-accessors
Genera un método de acceso para cada elemento de estructuras y uniones. Los métodos generados se nombran según el nombre del elemento; devolverán el valor actual del elemento si se llama sin argumentos adicionales; y establecerán el elemento al valor suministrado (y devolverán el nuevo valor) si se llama con un argumento adicional. Las estructuras y uniones incrustadas se devuelven como un puntero en lugar de la estructura completa, para facilitar las llamadas encadenadas.

Todos estos métodos se aplican al tipo Ptr para la estructura; además, se construyen dos métodos para el tipo de estructura en sí: "_to_ptr" que devuelve un tipo Ptr que apunta a la misma estructura, y un método "new" para construir y devolver una nueva estructura, inicializada a ceros.

-b, --compat-version=version
Genera un archivo .pm que es retrocompatible con la versión de perl especificada.

Para versiones < 5.6.0, los cambios son:
- no uso de 'our' (usa 'use vars' en su lugar)
- no 'use warnings'

Especificar una versión de compatibilidad superior a la versión de perl que estás usando para ejecutar h2xs no tendrá efecto. Si no se especifica, h2xs usará por defecto la compatibilidad con la versión de perl que estés usando para ejecutar h2xs.

-c, --omit-constant
Omite constant() del archivo .xs y la AUTOLOAD especializada correspondiente del archivo .pm.
-d, --debugging
Activa los mensajes de depuración.
-e, --omit-enums=[expresión regular]
Si no se da expresión regular, omite todas las constantes definidas en una enumeración C. De lo contrario, omite solo aquellas constantes definidas en un enum cuyo nombre coincida con expresión regular.

Dado que expresión regular es opcional, asegúrate de que este interruptor va seguido de al menos otro interruptor si omites expresión regular y tienes argumentos pendientes como nombres de archivos de cabecera. Esto está bien:

h2xs -e -n Module::Foo foo.h

Esto no está bien:

h2xs -n Module::Foo -e foo.h

En este último caso, foo.h se toma como expresión regular.

-f, --force
Permite crear una extensión para una cabecera incluso si esa cabecera no se encuentra en los directorios de inclusión estándar.
-g, --global
Incluye código para almacenar de forma segura datos estáticos en el archivo .xs. Las extensiones que no usan datos estáticos pueden ignorar esta opción.
-h, -?, --help
Imprime el uso, la ayuda y la versión de esta h2xs y sale.
-k, --omit-const-func
Para argumentos de función declarados como "const", omite el atributo const en el código XS generado.
-m, --gen-tied-var
Experimental: para cada variable declarada en los archivos de cabecera, declara una variable perl del mismo nombre mágicamente enlazada a la variable C.
-n, --name=nombre_modulo
Especifica un nombre a usar para la extensión, por ejemplo, -n RPC::DCE
-o, --opaque-re=expresión regular
Usa el tipo de dato "opaco" para los tipos C que coinciden con la expresión regular, incluso si estos tipos son "typedef"-equivalentes a tipos de los typemaps. No debe usarse sin -x.

Esto puede ser útil ya que, por ejemplo, los tipos que son "typedef"-equivalentes a enteros pueden representar manejadores relacionados con el sistema operativo, y uno puede querer trabajar con estos manejadores de forma OO, como en "$handle->do_something()". Usa "-o ." si quieres manejar todos los tipos "typedef"ed como tipos opacos.

El tipo a coincidir se blanquea (excepto por las comas, que no tienen espacio antes de ellas, y los múltiples "*" que no tienen espacio entre ellos).

-p, --remove-prefix=prefijo
Especifica un prefijo que debe eliminarse de los nombres de función de Perl, por ejemplo, -p sec_rgy_ Esto configura la palabra clave XS PREFIX y elimina el prefijo de las funciones que se cargan automáticamente a través del mecanismo constant().
-s, --const-subs=sub1,sub2
Crea una subrutina perl para las macros especificadas en lugar de cargarlas automáticamente con la subrutina constant(). Se asume que estas macros tienen un tipo de retorno de char *, por ejemplo, -s sec_rgy_wildcard_name,sec_rgy_wildcard_sid.
-t, --default-type=tipo
Especifica el tipo interno que usa el mecanismo constant() para las macros. El valor predeterminado es IV (entero con signo). Actualmente, todas las macros encontradas durante el escaneo de la cabecera se asumirán que tienen este

EJEMPLOS
# Comportamiento predeterminado, la extensión es Rusers
h2xs rpcsvc/rusers
# Igual, pero la extensión es RUSERS
h2xs -n RUSERS rpcsvc/rusers
# La extensión es rpcsvc::rusers. Aún encuentra <rpcsvc/rusers.h>
h2xs rpcsvc::rusers
# La extensión es ONC::RPC.  Aún encuentra <rpcsvc/rusers.h>
h2xs -n ONC::RPC rpcsvc/rusers
# Sin constant() o AUTOLOAD
h2xs -c rpcsvc/rusers
# Crea plantillas para una extensión llamada RPC
h2xs -cfn RPC
# La extensión es ONC::RPC.
h2xs -cfn ONC::RPC
# La extensión es un módulo Perl puro sin código XS.
h2xs -X My::Module
# La extensión es Lib::Foo que funciona al menos con Perl5.005_03.
# Se crean constantes para todos los #defines y enums que h2xs puede encontrar
# en foo.h.
h2xs -b 5.5.3 -n Lib::Foo foo.h
# La extensión es Lib::Foo que funciona al menos con Perl5.005_03.
# Se crean constantes para todos los #defines pero solo para enums
# cuyos nombres no comienzan con 'bar_'.
h2xs -b 5.5.3 -e '^bar_' -n Lib::Foo foo.h
# Makefile.PL buscará la biblioteca -lrpc en
# el directorio adicional /opt/net/lib
h2xs rpcsvc/rusers -L/opt/net/lib -lrpc
# La extensión es DCE::rgynbase
# el prefijo "sec_rgy_" se elimina de los nombres de funciones perl
h2xs -n DCE::rgynbase -p sec_rgy_ dce/rgynbase
# La extensión es DCE::rgynbase
# el prefijo "sec_rgy_" se elimina de los nombres de funciones perl
# se crean subrutinas para sec_rgy_wildcard_name y
# sec_rgy_wildcard_sid
h2xs -n DCE::rgynbase -p sec_rgy_ \
-s sec_rgy_wildcard_name,sec_rgy_wildcard_sid dce/rgynbase
# Hacer XS sin defines en perl.h, pero con declaraciones de funciones
# visibles desde perl.h. El nombre de la extensión es perl1.
# Al escanear perl.h, definir -DEXT=extern -DdEXT= -DINIT(x)=
# Barras invertidas extra a continuación porque la cadena se pasa al shell.
# Tenga en cuenta que un directorio con archivos de cabecera de perl
#  se añadiría automáticamente a la ruta de inclusión.
h2xs -xAn perl1 -F "-DEXT=extern -DdEXT= -DINIT\(x\)=" perl.h
