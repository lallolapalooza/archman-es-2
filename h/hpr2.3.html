Documentación de la Función

subrutina chpr2 (character uplo, integer n, complex alpha, complex, dimension(*) x, integer incx, complex, dimension(*) y, integer incy, complex, dimension(*) ap)

CHPR2

Propósito:

!>
!> CHPR2  realiza la operación de rango 2 hermitiana
!>
!>    A := alpha*x*y**H + conjg( alpha )*y*x**H + A,
!>
!> donde alpha es un escalar, x y y son vectores de n elementos y A es una
!> matriz hermitiana de n por n, proporcionada en forma empaquetada.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>           En la entrada, UPLO especifica si se proporciona la parte
!>           triangular superior o inferior de la matriz A en el
!>           array empaquetado AP de la siguiente manera:
!>
!>              UPLO = 'U' o 'u'   Se proporciona la parte triangular
!>                                 superior de A en AP.
!>
!>              UPLO = 'L' o 'l'   Se proporciona la parte triangular
!>                                 inferior de A en AP.
!>

N

!>          N es INTEGER
!>           En la entrada, N especifica el orden de la matriz A.
!>           N debe ser al menos cero.
!>

ALPHA

!>          ALPHA es COMPLEX
!>           En la entrada, ALPHA especifica el escalar alpha.
!>

X

!>          X es un array COMPLEX, dimensión al menos
!>           ( 1 + ( n - 1 )*abs( INCX ) ).
!>           Antes de la entrada, el array X incrementado debe contener
!>           el vector x de n elementos.
!>

INCX

!>          INCX es INTEGER
!>           En la entrada, INCX especifica el incremento para los
!>           elementos de X. INCX no debe ser cero.
!>

Y

!>          Y es un array COMPLEX, dimensión al menos
!>           ( 1 + ( n - 1 )*abs( INCY ) ).
!>           Antes de la entrada, el array Y incrementado debe contener
!>           el vector y de n elementos.
!>

INCY

!>          INCY es INTEGER
!>           En la entrada, INCY especifica el incremento para los
!>           elementos de Y. INCY no debe ser cero.
!>

AP

!>          AP es un array COMPLEX, dimensión al menos
!>           ( ( n*( n + 1 ) )/2 ).
!>           Antes de la entrada con UPLO = 'U' o 'u', el array AP debe
!>           contener la parte triangular superior de la matriz
!>           hermitiana empaquetada secuencialmente, columna por columna,
!>           de modo que AP( 1 ) contiene a( 1, 1 ), AP( 2 ) y AP( 3 )
!>           contienen a( 1, 2 ) y a( 2, 2 ) respectivamente, y así
!>           sucesivamente. En la salida, el array AP es sobrescrito por
!>           la parte triangular superior de la matriz actualizada.
!>           Antes de la entrada con UPLO = 'L' o 'l', el array AP debe
!>           contener la parte triangular inferior de la matriz
!>           hermitiana empaquetada secuencialmente, columna por columna,
!>           de modo que AP( 1 ) contiene a( 1, 1 ), AP( 2 ) y AP( 3 )
!>           contienen a( 2, 1 ) y a( 3, 1 ) respectivamente, y así
!>           sucesivamente. En la salida, el array AP es sobrescrito por
!>           la parte triangular inferior de la matriz actualizada.
!>           Tenga en cuenta que las partes imaginarias de los elementos
!>           diagonales no necesitan establecerse, se asume que son cero,
!>           y en la salida se establecen en cero.
!>
