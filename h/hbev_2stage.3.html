NOMBRE

hbev_2stage - resuelve problemas de valores propios para matrices banda hermitianas complejas.

SINAPSIS

 SUBROUTINA HBEV_2STAGE ( JOBZ, UPLO, N, KD, AB, LDAB, W, Z, LDZ, WORK,
 LWORK, RWORK, INFO )
     CHARACTER * 1 JOBZ
     CHARACTER * 1 UPLO
     INTEGER N, KD, LDAB, LDZ, LWORK, INFO
     COMPLEX*16 AB( LDAB, * ), Z( LDZ, * ), WORK( * )
     DOUBLE PRECISION W( * ), RWORK( * )

DESCRIPCIÓN DETALLADA

La rutina HBEV_2STAGE calcula todos los valores propios y, opcionalmente, los vectores propios de una matriz banda hermita compleja A utilizando la técnica 2stage para la reducción a tridiagonal.

La técnica 2stage implementa una reducción paralela de la matriz banda A a una matriz tridiagonal T, preservando el espectro de A. La reducción se realiza en dos etapas:

  1. Una reducción de la matriz banda A a una matriz banda de mayor ancho de banda pero con más ceros.
  2. Una reducción de esta matriz banda a una matriz tridiagonal utilizando kernels optimizados para la memoria y de grano fino.

Esta técnica permite lograr un alto grado de paralelismo y eficiencia, especialmente en arquitecturas de memoria multinivel.

subroutine zhbev_2stage (character jobz, character uplo, integer n, integer kd, complex*16, dimension( ldab, * ) ab, integer ldab, double precision, dimension( * ) w, complex*16, dimension( ldz, * ) z, integer ldz, complex*16, dimension( * ) work, integer lwork, double precision, dimension( * ) rwork, integer info)

ZHBEV_2STAGE calcula los valores propios y, opcionalmente, los vectores propios de la matriz banda hermita ZHBEV_2STAGE

Propósito:

!>
!> ZHBEV_2STAGE calcula todos los valores propios y, opcionalmente, los vectores
!> propios de una matriz banda hermita compleja A utilizando la técnica 2stage
!> para la reducción a tridiagonal.
!>

Parámetros

JOBZ 
!>          JOBZ es CHARACTER*1
!>          = 'N':  Calcula solo los valores propios;
!>          = 'V':  Calcula valores propios y vectores propios.
!>                  No disponible en esta versión.
!>

UPLO

!>          UPLO es CHARACTER*1
!>          = 'U':  El triángulo superior de A está almacenado;
!>          = 'L':  El triángulo inferior de A está almacenado.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

KD

!>          KD es INTEGER
!>          El número de superdiagonales de la matriz A si UPLO = 'U',
!>          o el número de subdiagonales si UPLO = 'L'.  KD >= 0.
!>

AB

!>          AB es array COMPLEX*16, dimension (LDAB, N)
!>          En la entrada, el triángulo superior o inferior de la matriz banda
!>          hermita A, almacenado en las primeras KD+1 filas del array. La
!>          columna j de A se almacena en la columna j del array AB
!>          de la siguiente manera:
!>          si UPLO = 'U', AB(kd+1+i-j,j) = A(i,j) para max(1,j-kd)<=i<=j;
!>          si UPLO = 'L', AB(1+i-j,j)    = A(i,j) para j<=i<=min(n,j+kd).
!>
!>          En la salida, AB se sobrescribe con valores generados durante la
!>          reducción a forma tridiagonal. Si UPLO = 'U', la primera
!>          superdiagonal y la diagonal de la matriz tridiagonal T
!>          se devuelven en las filas KD y KD+1 de AB, y si UPLO = 'L',
!>          la diagonal y la primera subdiagonal de T se devuelven en las
!>          primeras dos filas de AB.
!>

LDAB

!>          LDAB es INTEGER
!>          La dimensión principal del array AB.  LDAB >= KD + 1.
!>

W

!>          W es array DOUBLE PRECISION, dimension (N)
!>          Si INFO = 0, los valores propios en orden ascendente.
!>

Z

!>          Z es array COMPLEX*16, dimension (LDZ, N)
!>          Si JOBZ = 'V', entonces si INFO = 0, Z contiene los vectores
!>          propios ortonormales de la matriz A, con la columna i de Z
!>          conteniendo el vector propio asociado a W(i).
!>          Si JOBZ = 'N', entonces Z no se referencia.
!>

LDZ

!>          LDZ es INTEGER
!>          La dimensión principal del array Z.  LDZ >= 1, y si
!>          JOBZ = 'V', LDZ >= max(1,N).
!>

WORK

!>          WORK es array COMPLEX*16, dimension LWORK
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La longitud del array WORK. LWORK >= 1, cuando N <= 1;
!>          de lo contrario
!>          Si JOBZ = 'N' y N > 1, LWORK debe ser consultado.
!>                                   LWORK = MAX(1, dimension) donde
!>                                   dimension = (2KD+1)*N + KD*NTHREADS
