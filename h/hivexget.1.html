NOMBRE

hivexget - Obtener subclave de un archivo binario de registro de Windows "hive"

SINOPSIS

hivexget archivo_hive '\Ruta\A\Subclave'
hivexget archivo_hive '\Ruta\A\Subclave' nombre

NOTA

Esta es una herramienta de bajo nivel. Para una forma más conveniente de navegar por el Registro de Windows en máquinas virtuales de Windows, consulte virt-win-reg(1). Para un formato regedit adecuado, utilice hivexregedit(1).

DESCRIPCIÓN

Este programa navega por un archivo binario de registro de Windows "hive" y extrae *o* todos los pares de datos (clave, valor) almacenados en esa subclave *o* solo el elemento de datos con nombre individual.

En la primera forma:

hivexget archivo_hive '\Ruta\A\Subclave'

"archivo_hive" es un registro binario de Windows, y "\Ruta\A\Subclave" es una ruta dentro de ese hive. *NB* la ruta es relativa a la parte superior de este hive, y *no* es la ruta completa como se usaría en Windows (por ejemplo, "HKEY_LOCAL_MACHINE\SYSTEM" no es una ruta válida).

Si la subclave existe, la salida lista todos los pares de datos debajo de esta subclave, en un formato similar a "regedit" en Windows.

En la segunda forma:

hivexget archivo_hive '\Ruta\A\Subclave' nombre

"archivo_hive" y la ruta son como se indicó anteriormente. "nombre" es el nombre del valor de interés (use "@" para el valor predeterminado).

El elemento de datos correspondiente se imprime "en bruto" (es decir, sin procesamiento ni escape) excepto:

1.
Si es una cadena, la convertiremos de Windows UTF-16 a UTF-8, si esta conversión es posible. La cadena se imprime con una única nueva línea al final.
2.
Si es un valor de cadena múltiple, cada cadena se imprime en una línea separada.
3.
Si es un valor numérico, se imprime como un número decimal.
