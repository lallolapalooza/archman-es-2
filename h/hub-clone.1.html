NOMBRE

hub-clone - Clonar un repositorio de GitHub.

SINOPSIS

hub clone [-p] [OPCIONES] [USUARIO/]REPOSITORIO [DESTINO]

OPCIONES

-p

(Obsoleto) Clonar repositorios privados a través de SSH.

[USUARIO/]REPOSITORIO

USUARIO por defecto es tu propio nombre de usuario de GitHub.

DESTINO

Nombre del directorio donde clonar (por defecto: REPOSITORIO).

PROTOCOLO UTILIZADO PARA CLONAR

El protocolo git: se utilizará para clonar repositorios públicos, mientras que el protocolo SSH se utilizará para repositorios privados y aquellos a los que tengas acceso de escritura. Alternativamente, hub puede configurarse para usar el protocolo HTTPS para todo. Consulta "HTTPS en lugar del protocolo git" y "HUB_PROTOCOL" de hub(1).

EJEMPLOS

$ hub clone rtomayko/ronn
> git clone git://github.com/rtomayko/ronn.git

VER TAMBIÉN
