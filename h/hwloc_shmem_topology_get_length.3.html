Estas funciones se utilizan para compartir una topología entre procesos duplicándola en un búfer de memoria compartida respaldado por un

archivo.

El proceso maestro debe obtener primero el tamaño de memoria compartida necesario para almacenar esta topología

con

hwloc_shmem_topology_get_length(). Luego debe encontrar un área de memoria virtual de ese tamaño que esté disponible en todos los procesos (direcciones virtuales idénticas en todos los procesos). En Linux, esto se puede hacer comparando los huecos encontrados en /proc/<pid>/maps para cada

proceso.

Una vez encontrada, debe abrir un archivo de destino para almacenar el búfer y pasarlo

a

hwloc_shmem_topology_write() junto con la dirección de memoria virtual y la longitud obtenidas anteriormente. Otros procesos pueden entonces adoptar esta topología compartida abriendo el mismo archivo y pasándolo

a

hwloc_shmem_topology_adopt() con exactamente la misma dirección de memoria virtual y longitud. Documentación
