DESCRIPCIÓN DETALLADA

Esta interfaz ofrece formas de recuperar información de topología sobre dispositivos gestionados por la Biblioteca de Gestión SMI de ROCm.

DOCUMENTACIÓN DE FUNCIONES

int hwloc_rsmi_get_device_cpuset (hwloc_topology_t topology, uint32_t dv_ind, hwloc_cpuset_t set) [inline]

Obtener el conjunto de CPU de procesadores lógicos que están físicamente cerca del dispositivo GPU AMD cuyo índice es dv_ind. Almacenar en set el conjunto de CPU que describe la localidad del dispositivo GPU AMD cuyo índice es dv_ind.

La topología topology y el dispositivo dv_ind deben coincidir con la máquina local. La detección de dispositivos de E/S y el componente ROCm SMI no son necesarios en la topología.

La función solo devuelve la localidad del dispositivo. Si se necesita más información sobre el dispositivo, se deben usar objetos del sistema operativo en su lugar, ver hwloc_rsmi_get_device_osdev() y hwloc_rsmi_get_device_osdev_by_index().

Actualmente, esta función solo se implementa de forma significativa para Linux; otros sistemas simplemente obtendrán un conjunto de CPU completo.

Retorna

0 si tiene éxito.

-1 si hay un error, por ejemplo, si la información del dispositivo no pudo ser encontrada.

hwloc_obj_t hwloc_rsmi_get_device_osdev (hwloc_topology_t topology, uint32_t dv_ind) [inline]

Obtener el objeto de dispositivo del sistema operativo de hwloc correspondiente al dispositivo GPU AMD, cuyo índice es dv_ind.

Retorna

El objeto de dispositivo del sistema operativo de hwloc que describe el GPU AMD dado, cuyo índice es dv_ind.

NULL si no se pudo encontrar ninguno.

La topología topology y el dispositivo dv_ind deben coincidir con la máquina local. La detección de dispositivos de E/S y el componente ROCm SMI deben estar habilitados en la topología. De lo contrario, la localidad del objeto aún puede encontrarse usando hwloc_rsmi_get_device_cpuset().

Nota

El objeto de dispositivo PCI correspondiente puede encontrarse buscando en el puntero padre del resultado (a menos que los dispositivos PCI estén filtrados).

hwloc_obj_t hwloc_rsmi_get_device_osdev_by_index (hwloc_topology_t topology, uint32_t dv_ind) [inline]

Obtener el objeto de dispositivo del sistema operativo de hwloc correspondiente al dispositivo GPU AMD cuyo índice es dv_ind.

Retorna

El objeto de dispositivo del sistema operativo de hwloc que describe el dispositivo GPU AMD cuyo índice es dv_ind.

NULL si no se pudo encontrar ninguno.

La topología topology no necesariamente tiene que coincidir con la máquina actual. Por ejemplo, la topología puede ser una importación XML de un host remoto. La detección de dispositivos de E/S y el componente ROCm SMI deben estar habilitados en la topología.

Nota

El objeto de dispositivo PCI correspondiente se puede obtener buscando en el objeto padre del dispositivo del sistema operativo (a menos que los dispositivos PCI estén filtrados).
