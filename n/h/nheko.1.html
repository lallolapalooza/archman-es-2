NHEKO(1) Manual de comandos generales NHEKO(1)

NOMBRE

nheko - Cliente de escritorio para Matrix usando Qt y C++17

SINOPSIS

nheko [OPCIONES]

DESCRIPCIÓN

La motivación detrás del proyecto es proporcionar una aplicación de escritorio nativa para Matrix que se sienta más como una aplicación de chat convencional (Element, Telegram, etc.) y menos como un cliente IRC.

OPCIONES

-h, --help

Muestra la ayuda sobre las opciones de la línea de comandos.

--help-all

Muestra la ayuda incluyendo las opciones específicas de Qt.

-v, --version

Muestra información de la versión.

--debug

Alias de --log-level trace.

-l, --log-level <nivel>

Establece el nivel de registro global, o una lista separada por comas de pares <componente>=<nivel>, o ambos. Por ejemplo, para establecer el nivel de registro predeterminado en warn pero deshabilitar el registro para el componente ui, pase warn,ui=off.

niveles: trace debug info warning error critical off

componentes: crypto db mtx net qml ui

Los niveles de registro también se pueden establecer en la variable de entorno NHEKO_LOG_LEVEL, utilizando la misma sintaxis. Será anulada por esta opción de línea de comandos.

-L, --log-type <tipo>

Establece el tipo de salida de registro. Se permite una lista separada por comas. El valor predeterminado es file,stderr.

tipos: file stderr none

El tipo de registro también se puede establecer en la variable de entorno NHEKO_LOG_TYPE, que será anulada por esta opción de línea de comandos.

-p <perfil>, --profile <perfil>

Crea un perfil único, lo que te permite iniciar sesión en varias cuentas al mismo tiempo e iniciar varias instancias de nheko. Usa default para iniciar con el perfil predeterminado.

-C, --compact

Permite reducir la base de datos, ya que las bases de datos LMDB no se reducen automáticamente cuando se eliminan datos. Posiblemente permite alguna recuperación en caso de corrupción de la base de datos.

PREGUNTAS FRECUENTES

¿Cómo agrego stickers y emojis personalizados?

Los stickers y emojis personalizados se organizan en paquetes de imágenes. Hay un paquete de imágenes de usuario al que solo tu cuenta tiene acceso y hay paquetes de imágenes de sala a los que todos en la sala en la que se definen pueden acceder. Puedes activar un paquete de imágenes de sala globalmente para usarlo en cualquier sala.

Para administrar paquetes de imágenes en nheko, ve a la configuración de la sala y entra en la Configuración de Stickers y Emoticonos. Verás el paquete Privado (tu paquete de imágenes de usuario) y podrás editarlo allí. El Shortcode es un identificador único que usas para seleccionar la imagen y el Body es el texto alternativo que se muestra en los clientes que no admiten imágenes (como la etiqueta alt en imágenes HTML).

Si tienes los permisos necesarios, puedes crear nuevos paquetes de sala con el botón en la parte inferior de la lista de paquetes de imágenes. Son iguales que el paquete de usuario pero puedes crear tantos como quieras y todos en la sala pueden usarlos. Podría ser una buena idea crear una sala adicional solo para tus paquetes de imágenes para facilitar el intercambio.

COMPLETADORES

Los completadores inician un popup con candidatos de completado cuando los escribes en la línea de entrada.

@

Abre el completador de nombres de usuario.

#

Abre el completador de salas.

:

Abre el selector de emojis. Los emojis Unicode se insertan directamente. Los emojis personalizados insertarán su código HTML en la línea de entrada. Puedes configurar emojis personalizados en la configuración de la sala.

ATAJOS DE TECLADO

Lista de salas

Ctrl-Arriba/Ctrl-Abajo

Navega dentro de la lista de salas.

Ctrl-W

Cierra la sala abierta actualmente.

Ctrl-K

Busca y selecciona salas de la lista de salas.

Alt-A, Ctrl-Shift-A

Selecciona la siguiente sala con actividad.

Cronología/Mensajería

RePág/AvPág

Desplaza la cronología por página.

Alt-Arriba/Alt-Abajo

Responde a un mensaje.

Arriba/Abajo

Edita un mensaje.

Ctrl-E

Edita el mensaje actualmente seleccionado como respuesta.

Alt-F

Reenvía el mensaje actualmente seleccionado como respuesta.

Ctrl-P/Ctrl-N

Vuelve a introducir el mensaje anterior/siguiente.

Ctrl-U

Elimina todo en la línea de entrada.

Ctrl-Izquierda/Ctrl-Derecha

Salta una palabra a la izquierda/derecha en la línea de entrada.

Shift-Enter

Inserta un salto de línea.

Enter

Envía el mensaje.

COMANDOS

Los comandos solo funcionan cuando se usan al principio del texto.

Mensajes personalizados

/me <mensaje>

Envía un mensaje como una mímica, donde se antepone tu nombre de usuario.

/react <texto>

Envía un mensaje como una reacción cuando estás respondiendo a un mensaje.

/md <mensaje>

Forza Markdown al enviar el mensaje actual.

/cmark <mensaje>

Deshabilita la mayoría de nuestras extensiones para cmark (CommonMark), incluyendo el comportamiento de salto de línea en la entrada = salto de línea en la salida, tachado y spoilers. Aún puedes forzar saltos de línea con 2 espacios o una barra invertida antes del final de la línea o insertar elementos HTML.

/plain <mensaje>

Forza texto plano al enviar el mensaje actual.

/rainbow <mensaje>

Envía un mensaje en colores de arcoíris.

/rainbowme <mensaje>

Envía un mensaje como una mímica de color arcoíris, donde se antepone tu nombre de usuario.

/notice <mensaje>

Envía un mensaje como una notificación.

/rainbownotice <notice>

Envía un mensaje como una notificación de color arcoíris.

Gestión de salas

/join <nombre_sala> [razón]

Únete a una sala. razón es opcional.

/knock <nombre_sala> [razón]

Pide unirse a una sala. razón es opcional.

/part, /leave [razón]

Abandona la sala actual. razón es opcional.

/invite <nombre_usuario> [razón]

Invita a un usuario a la sala actual. razón es opcional.

/kick <nombre_usuario> [razón]

Expulsa a un usuario de la sala actual. razón es opcional. Alternativamente, puedes expulsar al usuario al que estás respondiendo si omites el nombre_usuario.

/ban <nombre_usuario> [razón]

Banea a un usuario de la sala actual. razón es opcional. Alternativamente, puedes banear al usuario al que estás respondiendo si omites el nombre_usuario.

COMMANDS

/ban <username>

Bans a user from the current room.

/unban <username>

Unbans a user from the current room.

/kick <username>

Kicks a user from the current room.

/invite <username>

Invites a user to the current room.

/join <room_address>

Joins a room. room_address can be a room id or a Matrix URI.

/part [room_address]

Leaves the current room or the room specified by room_address.

/topic <new_topic>

Sets the topic of the current room.

/tag <tag_name> <room_id>

Adds the specified room to the specified tag.

/deltag <tag_name> <room_id>

Removes the specified room from the specified tag.

/tagrooms <tag_name>

Lists all rooms associated with the specified tag.

/search <query>

Searches for messages matching the query.

/set_power_level <user_id> <level>

Sets the power level for a user in the current room. The level must be an integer.

/send_custom_event <type> <content>

Sends a custom event. type is the event type (e.g. m.room.name) and content is a JSON string.

/devtools <event_id>

Opens the event in the devtools view.

/redact [event_id] [reason]

Redacts the event you are replying to, or the event specified by event_id.

/redact <username> [reason]

Redacts all visible messages of the specified user. You will run into rate limits quickly.

/redact <eventid> [reason]

Redacts a specific event. You can alternatively redact the event you are replying to by specifying neither an eventid nor username.

/roomnick <roomname>

Change your nickname in a single room.

/glitch <message>

Applies a glitch effect to the given message. Beware that this will break mentions, HTML, and some Markdown in your message.

/gradualglitch <message>

Applies a progressively more severe glitch effect to the message. Again, this will break mentions, HTML, and some Markdown.

Emoticons

/shrug [message]

Inserts ¯\_(ツ)_/¯ followed by an optional message.

/fliptable

Inserts (╯°□°)╯︵ ┻━┻

/unfliptable

Inserts ┯━┯╭( º _ º╭)

/sovietflip

Inserts ノ┬─┬ノ ︵ ( \\o°o)\\

User management

/ignore <username>

Ignore a user, invites from them are also rejected.

/unignore <username>

Stops ignoring a user.

Invite permission management

/blockinvites <username>|<roomid>|<servername>|all

Block all invites either by default ("all") or from a specific user or server or to a specific room.

/allowinvites <username>|<roomid>|<servername>|all

Allow all invites either by default ("all") or from a specific user or server or to a specific room.

Advanced

/clear-timeline

Removes all but the most recent messages from the currently rendered timeline and then refetches it from the server; can be used to fix some cache issues.

/reset-state

Fetches all the state events in the current room again; can be used to fix some cache issues.

/rotate-megolm-session

Rotates the encryption key used to send encrypted messages in a room.

/goto <address>

address can be one of:

<event ID>

Jumps to event with the specified ID and highlights it.

<message index>

Jumps to the message with the specified index and highlights it.

<Matrix URI>

Handles Matrix URI as if you clicked on it.

/converttodm

Converts a room to a direct conversation.

/converttoroom

Converts a direct conversation to a normal room.

MARKDOWN EXTENSIONS

newline (\n)

A single newline will be turned into <br> instead of a space.

~text~

Make text strikethrough. HTML putput: <del>text</del>

||spoiler warning|text||

Hide text and set an optional spoiler warning. Note that Nheko does not display the spoiler warning currently. HTML output: <span data-mx-spoiler="spoiler">text</span>

ENVIRONMENT

NHEKO_ALLOW_QML_DISK_CACHE

Nheko by default disables the qml disk cache to prevent crashes. This allows you to reenable it at your own risk.

FILES

Configuration file

${XDG_CONFIG_HOME:-~/.config}/nheko/nheko.conf

Log file

${XDG_CACHE_HOME:-~/.cache}/nheko/nheko/nheko.log

Database

${XDG_DATA_HOME:-~/.local/share}/nheko/nheko/*/data.mdb

Media cache

${XDG_CACHE_HOME:-~/.cache}/nheko/nheko/media_cache
