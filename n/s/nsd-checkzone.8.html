NOMBRE

nsd-checkzone - Comprobador de sintaxis de archivos de zona de NSD.

SINOPSIS

nsd-checkzone [-h] nombre_zona archivo_zona

DESCRIPCIÓN

nsd-checkzone lee un archivo de zona DNS y lo comprueba en busca de errores. Imprime los errores en stderr. En caso de fallo, sale con un estado de salida distinto de cero.

Esto se utiliza para comprobar los archivos antes de introducirlos en el demonio nsd(8).

OPCIONES

-h
Muestra la información de ayuda de uso y sale.
nombre_zona
El nombre de la zona a comprobar, por ejemplo, "ejemplo.com".
archivo_zona
El archivo a leer, por ejemplo, "zonas/ejemplo.com.zone.signed". Utilice "-" para leer desde stdin.
-p
Imprime el contenido de la zona en stdout si la zona es correcta. Imprime el contenido tal como ha sido analizado, no literalmente una copia de la entrada, sino tal como lo imprimen las rutinas de formato en NSD, muy parecido a como lo hace el comando nsd-control write.
-i <archivo_zona_antiguo>
Crea un IXFR a partir de las diferencias entre el archivo de zona antiguo y el archivo de zona nuevo. El argumento de la opción -i es el archivo de zona antiguo, el otro argumento de archivo_zona pasado es el archivo de zona nuevo.

La diferencia se calcula entre los dos archivos de zona manteniendo una versión de la zona en memoria y otra versión en un archivo temporal. El archivo temporal se encuentra en el directorio del archivo de zona. Aquí es donde se escribe el resultado, en un archivo con el nombre del archivo de zona, que termina en '.ixfr'. Aquí es donde NSD lo lee cuando los IXFR están configurados para la zona.

Los otros archivos ixfr existentes se renombran para convertirse en contenidos IXFR más antiguos para la zona, si existen tales archivos. Si el archivo de salida ya existe con el contenido correcto, no se crea un archivo nuevo. Se comprueba el contenido de la cabecera del archivo de salida para eso, si ya existe.

-n <número_ixfr>
El número de versiones de IXFR a almacenar, como máximo. Por defecto 5. Este es el número de archivos que se crean con contenido ixfr para la zona. Las versiones IXFR antiguas almacenadas se eliminan cuando se supera el número.
-s <tamaño_ixfr>
El número de bytes de almacenamiento a utilizar para los IXFR. Por defecto es 1048576. Si un IXFR es más grande, no se crea, y si la suma del almacenamiento IXFR lo excede, las versiones IXFR antiguas se eliminan.

VER TAMBIÉN

nsd(8), nsd-checkconf(8)
