nss(5) Manual de formatos de archivo nss(5)

NOMBRE

nss - archivo de configuración del conmutador de servicios de nombres

DESCRIPCIÓN

Cada llamada a una función que recupera datos de una base de datos del sistema, como la base de datos de contraseñas o grupos, es manejada por la implementación del Conmutador de Servicios de Nombres (Name Service Switch, NSS) en la biblioteca C de GNU. Los diversos servicios proporcionados se implementan mediante módulos independientes, cada uno de los cuales varía naturalmente mucho de los demás.

Las implementaciones predeterminadas que vienen con la biblioteca C de GNU son, por defecto, conservadoras y no utilizan datos inseguros. Esto puede ser muy costoso en algunas situaciones, especialmente cuando las bases de datos son grandes. Algunos módulos permiten al administrador del sistema solicitar la toma de atajos si se sabe que son seguros. Entonces es responsabilidad del administrador del sistema asegurarse de que la suposición sea correcta.

Existen otros módulos donde la implementación ha cambiado con el tiempo. Si una implementación solía sacrificar velocidad por consumo de memoria, podría crear problemas si la preferencia se cambia.

El archivo /etc/default/nss contiene una serie de asignaciones de variables. Cada variable controla el comportamiento de uno o más módulos NSS. Se ignoran los espacios en blanco. Las líneas que comienzan con '#' se tratan como comentarios.

Las variables actualmente reconocidas son:

NETID_AUTHORITATIVE = TRUE|FALSE
Si se establece en TRUE, el backend NIS para la función initgroups(3) aceptará la información del mapa NIS netid.byname como autoritaria. Esto puede acelerar significativamente la función si el mapa group.byname es grande. El contenido del mapa netid.byname se utiliza tal cual. El administrador del sistema debe asegurarse de que se genere correctamente.
SERVICES_AUTHORITATIVE = TRUE|FALSE
Si se establece en TRUE, el backend NIS para las funciones getservbyname(3) y getservbyname_r(3) asumirá que el mapa NIS services.byservicename existe y es autoritario, en particular que contiene ambas claves con /proto y sin /proto tanto para nombres de servicio primarios como para alias de servicio. El administrador del sistema debe asegurarse de que se genere correctamente.
SETENT_BATCH_READ = TRUE|FALSE
Si se establece en TRUE, el backend NIS para las funciones setpwent(3) y setgrent(3) leerá la base de datos completa de una vez y luego gestionará las solicitudes una por una desde la memoria con cada llamada correspondiente a getpwent(3) o getgrent(3) respectivamente. De lo contrario, cada llamada a getpwent(3) o getgrent(3) podría resultar en una comunicación de red con el servidor para obtener la siguiente entrada.

ARCHIVOS

/etc/default/nss

EJEMPLOS

La configuración predeterminada corresponde al siguiente archivo de configuración:


NETID_AUTHORITATIVE=FALSE
SERVICES_AUTHORITATIVE=FALSE
SETENT_BATCH_READ=FALSE
