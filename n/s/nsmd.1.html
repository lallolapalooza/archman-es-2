NSMD(1) Comandos de usuario NSMD(1)

NOMBRE

nsmd - página del manual para nsmd Versión 1.6.1

DESCRIPCIÓN

nsmd - Demonio y servidor para el 'New Session Manager'

Uso:

nsmd nsmd --help nsmd --version

OPCIONES

--help
Mostrar esta pantalla
--version
Mostrar versión
--osc-port númerodepuerto
Número de puerto OSC [Predeterminado: proporcionado por el sistema].
--session-root ruta
Ruta base para las sesiones [Predeterminado: $XDG_DATA_HOME/nsm/].
--load-session nombre
Cargar sesión existente [Ejemplo: "Mi Canción"].
--gui-url url
Conectar a gui heredado en ejecución [Ejemplo: osc.udp://miordenador.dominio.local:38356/].
--detach
Separarse de la consola.
--quiet
Suprimir mensajes excepto advertencias y errores.

nsmd puede ejecutarse sin interfaz gráfica con sesiones existentes. Para crear nuevas se recomienda usar una GUI como nsm-legacy-gui (incluida) o Agordejo (paquete separado)

VER TAMBIÉN

La documentación completa para NSM se mantiene como un sitio html en el directorio de documentación de su sistema. Por ejemplo:
xdg-open file:///usr/share/doc/new-session-manager/index.html

La documentación también se puede encontrar en línea en https://new-session-manager.jackaudio.org
