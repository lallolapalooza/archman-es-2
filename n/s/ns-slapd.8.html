NS-SLAPD(8) Manual del Administrador del Sistema NS-SLAPD(8)

NOMBRE

ns‐slapd - El demonio principal del Servidor de Directorio

SINOPSIS

ns‐slapd -D dir_config [-d nivel_depuracion] [-i archivo_pid] [-v] [-V]

DESCRIPCIÓN

ns‐slapd inicia el demonio del Servidor de Directorio LDAP.

OPCIONES

A continuación se incluye un resumen de las opciones:

-v
Muestra la versión del programa.
-D dir_config
Especifica el directorio de configuración que apunta a la instancia que se va a iniciar (por ejemplo, /etc/dirsrv/slapd‐localhost).
-d nivel_depuracion
Especifica el nivel de depuración que se utilizará.
-i archivo_pid
Especifica el archivo donde se almacenará el PID del proceso.
