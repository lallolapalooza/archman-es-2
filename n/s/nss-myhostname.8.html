NSS-MYHOSTNAME(8) nss-myhostname NSS-MYHOSTNAME(8)

NOMBRE

nss-myhostname, libnss_myhostname.so.2 - Resolución de nombres de host para el nombre de host del sistema configurado localmente

SINOPSIS

libnss_myhostname.so.2

DESCRIPCIÓN

nss-myhostname es un módulo plug-in para la funcionalidad del Servicio de Conmutación de Nombres (NSS) de la Biblioteca C de GNU (glibc), que proporciona principalmente resolución de nombres de host para el nombre de host del sistema configurado localmente, tal como lo devuelve gethostname(2). Los nombres de host precisos resueltos por este módulo son:

•El nombre de host local, configurado, se resuelve a todas las direcciones IP configuradas localmente, ordenadas según su ámbito, o — si no hay ninguna configurada — la dirección IPv4 127.0.0.2 (que está en el loopback local) y la dirección IPv6 ::1 (que es el host local).
•Los nombres de host "localhost" y "localhost.localdomain" (así como cualquier nombre de host que termine en ".localhost" o ".localhost.localdomain") se resuelven a las direcciones IP 127.0.0.1 y ::1.
•El nombre de host "_gateway" se resuelve a todas las direcciones del gateway de enrutamiento por defecto actuales, ordenadas por su métrica. Esto asigna un nombre de host estable al gateway actual, útil para referenciarlo independientemente del estado actual de la configuración de red.
•El nombre de host "_outbound" se resuelve a las direcciones IP locales IPv4 e IPv6 que probablemente se utilicen para la comunicación con otros hosts. Estas son las direcciones de origen preferidas de los gateways por defecto si se especifican, o determinadas solicitando una decisión de enrutamiento a los gateways por defecto configurados del kernel y luego utilizando las direcciones IP locales seleccionadas por esta decisión. Este nombre de host solo está disponible si hay al menos un gateway de enrutamiento por defecto local configurado. Esto asigna un nombre de host estable a las direcciones IP salientes locales, útil para referenciarlas independientemente del estado actual de la configuración de red.

Varios programas dependen de un nombre de host local siempre resoluble. Cuando se utilizan nombres de host dinámicos, esto se logra tradicionalmente parcheando /etc/hosts al mismo tiempo que se cambia el nombre de host. Esto es problemático ya que requiere un sistema de archivos /etc/ escribible y es frágil porque el administrador podría editar el archivo al mismo tiempo. Con nss-myhostname habilitado, cambiar /etc/hosts es innecesario y, en muchos sistemas, el archivo se vuelve completamente opcional.

Para activar los módulos NSS, agregue "myhostname" a la línea que comienza con "hosts:" en /etc/nsswitch.conf.

Se recomienda colocar "myhostname" después de "files" y antes de "dns". Esto resuelve nombres de host conocidos como "localhost" y los nombres de host de la máquina localmente. Es consistente con el comportamiento de nss-resolve y aún permite la anulación a través de /etc/hosts.

Tenga en cuenta que nss-myhostname (y nss-resolve) también resuelven en la otra dirección — desde direcciones IP adjuntas localmente a nombres de host. Si depende de que esa búsqueda sea proporcionada por DNS, es posible que desee ordenar las cosas de manera diferente.

EJEMPLO

Aquí hay un ejemplo de archivo /etc/nsswitch.conf que habilita nss-myhostname correctamente:

passwd:         files systemd
group:          files [SUCCESS=merge] systemd
shadow:         files systemd
gshadow:        files systemd
hosts:          mymachines resolve [!UNAVAIL=return] files myhostname dns
networks:       files
protocols:      db files
services:       db files
ethers:         db files
rpc:            db files
netgroup:       nis

Para probar, use la herramienta getent(1) de glibc:

$ getent ahosts `hostname`
::1       STREAM omega
::1       DGRAM
::1       RAW
127.0.0.2       STREAM
127.0.0.2       DGRAM
127.0.0.2       RAW

En este caso, el nombre de host local es omega.
