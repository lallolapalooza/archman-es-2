NSM-LEGACY-GUI(1) Comandos de usuario NSM-LEGACY-GUI(1)

NOMBRE

nsm-legacy-gui - página del manual para nsm-legacy-gui Versión 1.6.1

DESCRIPCIÓN

nsm-legacy-gui - GUI FLTK para el 'New Session Manager'

Uso:

nsm-legacy-gui nsm-legacy-gui --help

OPCIONES

--help
Mostrar esta pantalla
--nsm-url url
Conectarse a un nsmd en ejecución [Ejemplo: osc.udp://miordenador.localdomain:38356/].
--
Todo lo que siga a -- se pasará a nsmd como opciones del servidor. Ver nsmd --help .

Por compatibilidad con versiones anteriores, este ejecutable también existe como un enlace simbólico 'non-session-manager'
