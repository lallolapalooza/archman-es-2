NOMBRE

nslookup - consulta servidores de nombres de Internet de forma interactiva

SINOPSIS

nslookup [-opción] [nombre | -] [servidor]

DESCRIPCIÓN

nslookup es un programa para consultar servidores de nombres de dominio de Internet. nslookup tiene dos modos: interactivo y no interactivo. El modo interactivo permite al usuario consultar servidores de nombres para obtener información sobre varios hosts y dominios, o para imprimir una lista de hosts en un dominio. El modo no interactivo imprime solo el nombre y la información solicitada para un host o dominio.

ARGUMENTOS

Se entra en el modo interactivo en los siguientes casos:

a.
cuando no se proporcionan argumentos (se usa el servidor de nombres predeterminado);
b.
cuando el primer argumento es un guion (-) y el segundo argumento es el nombre de host o la dirección de Internet de un servidor de nombres.

Se utiliza el modo no interactivo cuando se proporciona como primer argumento el nombre de host o la dirección de Internet del host a buscar. El segundo argumento opcional especifica el nombre de host o la dirección de un servidor de nombres.

Las opciones también se pueden especificar en la línea de comandos si preceden a los argumentos y van prefijadas con un guion. Por ejemplo, para cambiar el tipo de consulta predeterminado a información de host, con un tiempo de espera inicial de 10 segundos, escriba:

nslookup -query=hinfo  -timeout=10

La opción -version hace que nslookup imprima el número de versión y salga inmediatamente.

COMANDOS INTERACTIVOS

host [servidor]
Este comando busca información para host utilizando el servidor predeterminado actual o utilizando servidor, si se especifica. Si host es una dirección de Internet y el tipo de consulta es A o PTR, se devuelve el nombre del host. Si host es un nombre y no tiene un punto final (.), se utiliza la lista de búsqueda para calificar el nombre.

Para buscar un host que no está en el dominio actual, agregue un punto al nombre.

servidor dominio | lserver dominio
Estos comandos cambian el servidor predeterminado a dominio; lserver utiliza el servidor inicial para buscar información sobre dominio, mientras que servidor utiliza el servidor predeterminado actual. Si no se puede encontrar una respuesta autorizada, se devuelven los nombres de los servidores que podrían tener la respuesta.
root
Este comando no está implementado.
finger
Este comando no está implementado.
ls
Este comando no está implementado.
view
Este comando no está implementado.
help
Este comando no está implementado.
?
Este comando no está implementado.
exit
Este comando sale del programa.
set palabra_clave[=valor]
Este comando se utiliza para cambiar la información de estado que afecta a las búsquedas. Las palabras clave válidas son:
all
Esta palabra clave imprime los valores actuales de las opciones de uso frecuente para set. También se imprime información sobre el servidor y host predeterminados actuales.
class=valor
Esta palabra clave cambia la clase de consulta a una de:
IN
la clase Internet
CH
la clase Chaos
HS
la clase Hesiod
ANY
comodín

La clase especifica el grupo de protocolos de la información. El valor predeterminado es IN; la abreviatura de esta palabra clave es cl.

nodebug
Esta palabra clave activa o desactiva la visualización del paquete de respuesta completo y de cualquier paquete de respuesta intermedio durante la búsqueda. El valor predeterminado para esta palabra clave es nodebug; la abreviatura de esta palabra clave es [no]deb.
nod2
Esta palabra clave activa o desactiva el modo de depuración. Esto muestra más información sobre lo que está haciendo nslookup. El valor predeterminado es nod2.
domain=nombre
Esta palabra clave establece la lista de búsqueda en nombre.
nosearch
Si la solicitud de búsqueda contiene al menos un punto, pero no termina con un punto final, esta palabra clave agrega los nombres de dominio de la lista de búsqueda de dominios a la solicitud hasta que se recibe una respuesta. El valor predeterminado es search.
port=valor
Esta palabra clave cambia el puerto predeterminado del servidor de nombres TCP/UDP a valor desde su valor predeterminado, el puerto 53. La abreviatura de esta palabra clave es po.
querytype=valor | type=valor
Esta palabra clave cambia el tipo de consulta de información a valor. Los valores predeterminados son A y luego AAAA; las abreviaturas de estas palabras clave son q y ty.

Tenga en cuenta que solo es posible especificar un tipo de consulta. Solo el comportamiento predeterminado busca ambos cuando no se especifica una alternativa.

norecurse
Esta palabra clave indica al servidor de nombres que consulte otros servidores si no tiene la información. El valor predeterminado es recurse; la abreviatura de esta palabra clave es [no]rec.
ndots=numero
Esta palabra clave establece el número de puntos (separadores de etiquetas) en un dominio que deshabilita la búsqueda. Los nombres absolutos siempre detienen la búsqueda.
retry=numero
Esta palabra clave establece el número de reintentos en numero.
timeout=numero
Esta palabra clave cambia el intervalo de tiempo de espera inicial para esperar una respuesta a numero, en segundos.
novc
Esta palabra clave indica que siempre se debe usar un circuito virtual al enviar solicitudes al servidor. novc es el valor predeterminado.
nofail
Esta palabra clave intenta el siguiente servidor de nombres si un servidor de nombres responde con SERVFAIL o una referencia (nofail), o termina la consulta (fail) ante dicha respuesta. El valor predeterminado es nofail.

VALORES DE RETORNO

nslookup retorna con un estado de salida de 1 si alguna consulta falló, y 0 en caso contrario.

SOPORTE IDN

Si nslookup ha sido compilado con soporte IDN (nombre de dominio internacionalizado), puede aceptar y mostrar nombres de dominio no ASCII. nslookup convierte adecuadamente la codificación de caracteres de un nombre de dominio antes de enviar una solicitud a un servidor DNS o mostrar una respuesta del servidor. Para desactivar el soporte IDN, defina la variable de entorno IDN_DISABLE. El soporte IDN está desactivado si la variable se establece cuando se ejecuta nslookup, o cuando la salida estándar no es una tty.
