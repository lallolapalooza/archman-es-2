NOMBRE

nsd-checkconf - verificador de archivos de configuración de NSD.

SINOPSIS

nsd-checkconf [-v] [-f] [-h] [-o opcion] [-z zonanombre] [-p patron] [-s nombredelacllave] [-t tlsauthname] archivoconfig

DESCRIPCIÓN

nsd-checkconf lee un archivo de configuración. Imprime errores de análisis en la salida estándar de error y realiza comprobaciones adicionales sobre el contenido. El formato del archivo de configuración se describe en nsd.conf(5).

La utilidad de este programa es comprobar un archivo de configuración en busca de errores antes de usarlo en nsd(8). Este programa también se puede utilizar para scripts de shell para acceder al archivo de configuración de nsd, utilizando las opciones -o y -z.

OPCIONES

-v
Después de leer, imprime las opciones en la salida estándar en formato de archivo de configuración. Sin esta opción, solo se informan errores de éxito o de análisis.
-f
Imprime la ruta completa cuando se usa con archivos, como con -o pidfile. Esto incluye el chroot en la forma en que se aplica al pidfile.
-h
Imprime la información de ayuda del uso y sale.
-o opcion
Devuelve solo esta opción del archivo de configuración. Esta opción se puede usar junto con las opciones -z y -p, o sin ellas para consultar la sección server. El valor especial zones imprime una lista de zonas configuradas. El valor especial patterns imprime una lista de patrones configurados.

Esta opción se puede utilizar para analizar el archivo de configuración desde la shell. Si se proporciona la opción -z, pero no se proporciona la opción -o, no se imprime nada.

-s nombredelacllave
Imprime el secreto de la clave (blob base64) configurado para esta clave en el archivo de configuración. Se utiliza para ayudar a los scripts de shell a analizar el archivo de configuración.
-t tls-auth
Imprime el nombre de dominio de autenticación configurado para esta cláusula tls-auth en el archivo de configuración. Se utiliza para ayudar a los scripts de shell a analizar el archivo de configuración.
-p patron
Devuelve la opción especificada con -o para el nombre de patrón dado.
-z zonanombre
Devuelve la opción especificada con -o para la zona 'zonanombre'.

Si no se proporciona esta opción, se utiliza la sección server del archivo de configuración.

Las opciones -o, -s y -z imprimen las opciones del archivo de configuración en la salida estándar.

ARCHIVOS

//etc/nsd/nsd.conf
Archivo de configuración predeterminado de NSD
