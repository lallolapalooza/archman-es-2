nslcd(8) Manual del Administrador del Sistema nslcd(8)

NOMBRE

nslcd - demonio del servicio de nombres LDAP local

SINOPSIS


nslcd
[opciones]

DESCRIPCIÓN

nslcd es un demonio que realizará consultas LDAP para procesos locales que deseen realizar búsquedas de nombres de usuario, grupo u otros (NSS) o realizar autenticación, autorización o modificación de contraseñas de usuario (PAM).

nslcd se configura a través de un archivo de configuración (ver nslcd.conf(5)).

Consulte el archivo README incluido para obtener información sobre la configuración del servidor LDAP.

OPCIONES

nslcd acepta las siguientes opciones:

-c, --check
Verifica si el demonio se está ejecutando. Esto hace que nslcd devuelva 0 si el demonio ya se está ejecutando y 1 si no es así.
-d, --debug
Habilita el modo de depuración. nslcd no se pondrá en segundo plano y enviará información de depuración detallada a stderr. nslcd manejará las conexiones como de costumbre. Esta opción es solo para fines de depuración. Especifique esta opción varias veces para incluir también un registro más detallado de la biblioteca LDAP.
-n, --nofork
No creará un proceso hijo ni se daemonizará y ejecutará nslcd en primer plano.
--help
Muestra una ayuda breve y sale.
-V, --version
Muestra información de la versión y sale.

SEÑALES

SIGTERM/SIGINT
Cancela cualquier consulta en curso y sale.
SIGUSR1
Hace que nslcd reintente cualquier conexión fallida al servidor LDAP, independientemente de las opciones reconnect_sleeptime y reconnect_retrytime.

ARCHIVOS

/etc/nslcd.conf - el archivo de configuración (ver nslcd.conf(5))

VER TAMBIÉN

nslcd.conf(5)
