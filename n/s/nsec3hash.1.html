nsec3hash(1)

Paquete: bind

Licencias: MPL2

NSEC3HASH(1) BIND 9 NSEC3HASH(1)

NOMBRE

nsec3hash - generar hash NSEC3

SINOPSIS

nsec3hash {sal} {algoritmo} {iteraciones} {dominio}

nsec3hash -r {algoritmo} {flags} {iteraciones} {sal} {dominio}

DESCRIPCIÓN

nsec3hash genera un hash NSEC3 basado en un conjunto de parámetros NSEC3. Esto puede usarse para verificar la validez de los registros NSEC3 en una zona firmada.

Si este comando se invoca como nsec3hash -r, toma los argumentos en orden, coincidiendo con los cuatro primeros campos de un registro NSEC3 seguido por el nombre de dominio: algoritmo, flags, iteraciones, sal, dominio. Esto lo hace conveniente para copiar y pegar una porción de un registro NSEC3 o NSEC3PARAM en una línea de comandos para confirmar la corrección de un hash NSEC3.

ARGUMENTOS

sal
Esta es la sal proporcionada al algoritmo de hash.
algoritmo
Este es un número que indica el algoritmo de hash. Actualmente, el único algoritmo de hash compatible para NSEC3 es SHA-1, que se indica con el número 1; en consecuencia, "1" es el único valor útil para este argumento.
flags
Esto se proporciona para compatibilidad con el formato de presentación de registros NSEC3, pero se ignora ya que las flags no afectan al hash.
iteraciones
Este es el número de veces adicionales que se debe realizar el hash.
dominio
Este es el nombre de dominio a hashear.

VER TAMBIÉN

Manual de Administración de BIND 9, RFC 5155 https://datatracker.ietf.org/doc/html/rfc5155.html.
