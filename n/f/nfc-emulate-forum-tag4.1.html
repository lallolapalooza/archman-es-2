NOMBRE

nfc-emulate-forum-tag4 — Herramienta de línea de comandos de demostración para la emulación de etiquetas NFC Forum tipo 4

SINOPSIS

nfc-emulate-forum-tag4 [-1] [archivo_entrada [archivo_salida]]

DESCRIPCIÓN

nfc-emulate-forum-tag4 es una herramienta de demostración que emula una etiqueta NFC Forum tipo 4 v2.0 (o v1.0) con contenido NDEF.

Se puede proporcionar -1 para forzar el comportamiento antiguo de la etiqueta NFC Forum tipo 4 versión 1.0.

archivo_entrada es el archivo que contiene el mensaje NDEF que desea compartir con el dispositivo iniciador compatible con NFC-Forum (por ejemplo, Nokia 6212 Classic para una etiqueta v1.0).

Si desea guardar un contenido compartido por el dispositivo iniciador, debemos proporcionar el argumento archivo_salida para indicar dónde se guardará el mensaje NDEF.

Este ejemplo utiliza la capacidad de hardware de PN532 para manejar tramas de bajo nivel ISO/IEC 14443-4 como RATS/ATS, WTX, etc.

Todos los dispositivos compatibles con NFC-Forum Tag Type 4 (Versión 2.0 o 1.0) pueden ser utilizados con este ejemplo en modo de lectura/escritura.

Si no se proporciona ningún argumento, hay disponible un archivo NDEF predeterminado.

NOTAS DE IMPLEMENTACIÓN

Puede especificar el mismo archivo_entrada y archivo_salida

IMPORTANTE

Solo los dispositivos equipados con PN532 pueden usar este ejemplo. (por ejemplo, placa de desarrollo PN532)

Los dispositivos ACR122 (como touchatag, etc.) pueden ser utilizados por este ejemplo, pero si algo sale mal, tendrá que desconectar/reconectar su dispositivo. Esto no es un error de libnfc, este problema se debe al MCU interno de ACR122 delante del chip NFC (PN532).

ERRORES

Por favor, informe de cualquier error en el rastreador de problemas de libnfc en: https://github.com/nfc-tools/libnfc/issues
