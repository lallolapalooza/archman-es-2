nfsiostat(8) Manual del Administrador del Sistema nfsiostat(8)

NOMBRE

nfsiostat - Emula iostat para puntos de montaje NFS usando /proc/self/mountstats

SINOPSIS

nfsiostat [[<intervalo>] [<contador>]] [<opciones>][<punto_montaje>]

DESCRIPCIÓN

El comando nfsiostat muestra estadísticas por punto de montaje del cliente NFS.

<intervalo>
especifica la cantidad de tiempo en segundos entre cada informe. El primer informe contiene estadísticas del tiempo transcurrido desde que se montó cada sistema de archivos. Cada informe subsiguiente contiene estadísticas recopiladas durante el intervalo desde el informe anterior.
<contador>
Si se especifica el parámetro <contador>, el valor de <contador> determina el número de informes generados con una separación de <intervalo> segundos. Si se especifica el parámetro de intervalo sin el parámetro <contador>, el comando genera informes continuamente.
<opciones>
Definidas a continuación
<punto_montaje>
Si se especifican uno o más nombres de <punto_montaje>, solo se mostrarán las estadísticas para estos puntos de montaje. De lo contrario, se listarán todos los puntos de montaje NFS en el cliente.
El significado de cada columna de la salida de nfsiostat es el siguiente:
- ops/s
Este es el número de operaciones por segundo.
- cola rpc
Esta es la longitud de la cola de espera.
- kB/s
Este es el número de kB escritos/leídos por segundo.
- kB/ops
Este es el número de kB escritos/leídos por cada operación.
- retrans
Este es el número de retransmisiones.
- RTT promedio (ms)
Esta es la duración desde el momento en que el kernel del cliente envía la solicitud RPC hasta el momento en que recibe la respuesta.
- exe promedio (ms)
Esta es la duración desde el momento en que el cliente NFS realiza la solicitud RPC a su kernel hasta que se completa la solicitud RPC, esto incluye el tiempo RTT anterior.
- cola promedio (ms)
Esta es la duración desde el momento en que el cliente NFS crea la tarea de solicitud RPC hasta el momento en que se transmite la solicitud.
- errores
Este es el número de operaciones que se completaron con un estado de error (estado < 0). Este recuento solo está disponible en kernels con la versión 1.1 o superior de las estadísticas de E/S RPC.
Tenga en cuenta que si se usa un intervalo como argumento para nfsiostat, se mostrará la diferencia con respecto al intervalo anterior, de lo contrario, los resultados serán desde el momento en que se montó el recurso compartido.

OPCIONES

-a o --attr
muestra estadísticas relacionadas con la caché de atributos
-d o --dir
muestra estadísticas relacionadas con operaciones de directorio
-h o --help
muestra el mensaje de ayuda y sale
-l LISTA o --list=LISTA
solo imprime estadísticas para los primeros LISTA puntos de montaje
-p o --page
muestra estadísticas relacionadas con la caché de páginas
-s o --sort
Ordena los puntos de montaje NFS por ops/segundo
--version
muestra el número de versión del programa y sale

ARCHIVOS

/proc/self/mountstats

VER TAMBIÉN

iostat(8), mountstats(8), nfsstat(8)
