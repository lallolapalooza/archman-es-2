NFSVIS(1) Manual de comandos generales NFSVIS(1)

NOMBRE

nfsvis - visualiza el rendimiento de las estadísticas de NFS

SINOPSIS

nfsvis [-V] [-c versión] [-m maxrate] [-s versión] [opciones de pmview]

DESCRIPCIÓN

nfsvis muestra un gráfico de barras tridimensional de las estadísticas de solicitudes NFS. La pantalla se actualiza con nuevos valores obtenidos del host o archivo de destino cada intervalo segundos (el valor predeterminado es 2 segundos).

Se muestran dos bloques de estadísticas: uno para el servidor NFS y otro para las solicitudes del cliente NFS. La altura de las barras es proporcional a la tasa a la que se procesan los diversos tipos de solicitudes.

nfsvis genera un archivo de configuración de pmview(1) y pasa la mayoría de las opciones de línea de comandos a pmview(1). Por lo tanto, las opciones de línea de comandos -A, -a, -C, -h, -n, -O, -p, -S, -t, -T, -Z y -z, y la interfaz de usuario se describen en la página del manual de pmview(1).

OPCIONES DE LÍNEA DE COMANDOS

Las opciones específicas de nfsvis son:

-c
Monitorizar métricas de cliente NFS de versión 2 o 3. El valor predeterminado es la versión 2.
-m
Utilizar maxrate como la tasa máxima de solicitudes NFS sobre todas las clases de solicitud, a partir de la cual se calcula la altura de las barras. Esto especifica efectivamente la altura a la que se recortarán las barras.
-s
Monitorizar métricas de servidor NFS de versión 2 o 3. El valor predeterminado es la versión 2.
-V
Modo detallado - mostrar el archivo de configuración de pmview(1) generado.

ARCHIVOS

$PCP_VAR_DIR/config/pmlogger/config.nfsvis
Un archivo de configuración de pmlogger(1) para las métricas de nfsvis.
$PCP_SHARE_DIR/lib/pmview-args
Procedimientos de shell para analizar las opciones de línea de comandos de pmview(1).

ENTORNO PCP

Las variables de entorno con el prefijo PCP_ se utilizan para parametrizar los nombres de archivos y directorios utilizados por PCP. En cada instalación, el archivo /etc/pcp.conf contiene los valores locales para estas variables. La variable $PCP_CONF se puede usar para especificar un archivo de configuración alternativo, como se describe en pcp.conf(4).
