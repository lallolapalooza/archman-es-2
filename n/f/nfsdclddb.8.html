nfsdclddb(8) Manual del Administrador del Sistema nfsdclddb(8)

NOMBRE

nfsdclddb - Herramienta para manipular la base de datos sqlite de nfsdcld

SINOPSIS

nfsdclddb [-h|--help]

nfsdclddb [-p|--path dbpath] fix-table-names [-h|--help]

nfsdclddb [-p|--path dbpath] downgrade-schema [-h|--help] [-v|--version a-version]

nfsdclddb [-p|--path dbpath] print [-h|--help] [-s|--summary]

DESCRIPCIÓN

El comando nfsdclddb se proporciona para realizar algunas manipulaciones en el esquema de la base de datos sqlite de nfsdcld y para imprimir el contenido de la base de datos.

Subcomandos

Los subcomandos válidos de nfsdclddb son:

fix-table-names
Una versión anterior de nfsdcld(8) contenía un error que corrompió los nombres de las tablas de épocas de reinicio. Este subcomando corregirá esos nombres de tabla.
downgrade-schema
Degradar el esquema de la base de datos. Actualmente, el esquema solo puede degradarse de la versión 4 a la versión 3.
print
Mostrar el contenido de la base de datos. Imprime la versión del esquema y los valores de las épocas actual y de recuperación. Si la opción -s|--summary no se proporciona, también imprime los clientes en las tablas de épocas de reinicio.

OPCIONES

Opciones válidas para todos los subcomandos

-h, --help
Mostrar el mensaje de ayuda y salir
-p dbpath, --path dbpath
Abrir la base de datos sqlite ubicada en dbpath en lugar de /var/lib/nfs/nfsdcld/main.sqlite. Esto es principalmente para propósitos de prueba.

Opciones específicas del subcomando downgrade-schema

-v a-version, --version a-version
La versión del esquema a la que degradar. Actualmente, el esquema solo puede degradarse a la versión 3.

Opciones específicas del subcomando print

-s, --summary
No listar los clientes en las tablas de épocas de reinicio en la salida.

NOTAS

El comando nfsdclddb no permitirá que los subcomandos fix-table-names o downgrade-schema se utilicen si nfsdcld(8) se está ejecutando.

ARCHIVOS

/var/lib/nfs/nfsdcld/main.sqlite
