NOMBRE

nfs-cat - Utilidad para leer un archivo de NFS

SINOPSIS

nfs-cat <URL_NFS>

DESCRIPCIÓN

nfs-cat es una utilidad para leer un archivo de un servidor NFS.

Ejemplo: Imprimir el contenido de un archivo:

$ nfs-cat nfs://127.0.0.1/data/tmp/foo.c
