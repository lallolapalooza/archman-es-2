NOMBRE

nfc-dep-target - Herramienta de demostración para poner el dispositivo NFC en modo D.E.P. de objetivo

SINOPSIS

nfc-dep-target

DESCRIPCIÓN

nfc-dep-target es una herramienta de demostración para poner un dispositivo NFC en modo objetivo D.E.P.

Este ejemplo escuchará a un iniciador D.E.P. e intercambiará un simple dato "Hola" con el iniciador.

Nota: este ejemplo está diseñado para funcionar con un iniciador D.E.P. controlado por nfc-dep-initiator.

ERRORES

Por favor, informe cualquier error en el rastreador de incidencias de libnfc en:
