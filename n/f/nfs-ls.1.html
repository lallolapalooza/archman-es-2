NOMBRE

nfs-ls - Utilidad para listar servidores, exportaciones y directorios NFS

SINOPSIS

nfs-ls [ OPCIONES ] <NFS-URL>

nfs-ls [-R --recursive] [-s --summary] [-D --discovery] [-? --help] [--usage]

DESCRIPCIÓN

nfs-ls es una utilidad para listar servidores, exportaciones o directorios NFS.

Ejemplo: Listar el contenido de un directorio en el servidor NFS

$ nfs-ls nfs://127.0.0.1/data/tmp
-rwxrwxr-x  1  1000  1000      1190802 a.out
-rwxr-xr-x  1  1000  1000           13 foo123.copy
-rwxrwxrwx  1  1000  1000            8 foo123.writtenx

OPCIONES

-s --summary

Imprime una línea de resumen al final de la salida.

-R --recursive

Listado recursivo de la URL especificada.

-D --discovery;

Esta opción se utiliza para descubrir servidores NFS locales y para listar las exportaciones de servidores específicos.

Cuando se usa con la URL 'nfs://', el comando intentará detectar todos los servidores NFS locales y listará sus IPs.

Cuando se usa con 'nfs://servidor', el comando listará todas las exportaciones en el servidor especificado.

Ejemplo: Descubrir y listar todos los servidores NFS locales

$ nfs-ls -D nfs://
nfs://10.10.10.10
nfs://10.0.0.10

Ejemplo: Listar las exportaciones de un servidor

$ nfs-ls -D nfs://10.10.10.10
nfs://10.10.10.10/foo
nfs://10.10.10.10/bar

-? --help

Muestra texto de ayuda básico.

--usage

Muestra texto de uso básico.
