NOMBRE

nfc-jewel - Herramienta de línea de comandos Jewel

SINOPSIS

nfc-jewel r|w DUMP

DESCRIPCIÓN

nfc-jewel es una herramienta Jewel que permite leer o escribir datos de una etiqueta a/desde un archivo DUMP.

La etiqueta Jewel de Broadcom, anteriormente Innovision, utiliza un archivo binario Dump para almacenar datos de todos los sectores.

¡Ten cuidado, ya que algunas partes de la memoria Jewel solo se pueden escribir una vez y algunas partes se utilizan como bits de bloqueo, así que por favor lee la documentación de la etiqueta antes de experimentar demasiado!

OPCIONES

r | w Realizar lectura desde ( r ) o escritura en ( w ) la tarjeta.

DUMP
Volcado de JeWel (JWD) utilizado para escribir (tarjeta a JWD) o (JWD a tarjeta).
