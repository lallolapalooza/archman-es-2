NFSMOUNT.CONF(5) Manual de formatos de archivo NFSMOUNT.CONF(5)

NOMBRE

nfsmount.conf - Archivo de configuración para montajes NFS

SINOPSIS

Archivo de configuración para montajes NFS que permite establecer opciones globalmente, por servidor o por punto de montaje.

DESCRIPCIÓN

El archivo de configuración consta de varios encabezados de sección seguidos de asignaciones de variables asociadas con esa sección. Un encabezado de sección se define por una cadena encerrada entre corchetes [ y ]. Las asignaciones de variables son sentencias de asignación que asignan valores a variables particulares usando el operador =, como en Proto=Tcp. Las variables que se pueden asignar son el conjunto de opciones de montaje específicas de NFS listadas en nfs(5) junto con las opciones de montaje independientes del sistema de archivos listadas en mount(8) y tres adiciones: Sloppy=True tiene el mismo efecto que la opción -s de mount, y Foreground=True y Background=True tienen el mismo efecto que bg y fg.

Las opciones en el archivo de configuración pueden darse en mayúsculas, minúsculas o una combinación de ambas y se convertirán a minúsculas antes de pasarlas al sistema de archivos.

Las opciones de montaje booleanas que no necesitan un signo de igual deben darse como "opción=True". En lugar de preceder una opción de este tipo con "no", su negación debe darse como "opción=False".

Las secciones se dividen en tres categorías básicas: Opciones globales, Opciones de servidor y Opciones de punto de montaje.

[ NFSMount_Global_Options ] - Esta sección con nombre estático define todas las opciones de montaje globales que se pueden aplicar a cada montaje NFS.

[ Server "Nombre_Servidor" ] - Esta sección define todas las opciones de montaje que deben usarse en los montajes a un servidor NFS particular. La cadena "Nombre_Servidor" debe ir entre comillas y ser una coincidencia exacta (ignorando mayúsculas y minúsculas) del nombre del servidor utilizado en el comando mount.

[ MountPoint "Punto_Montaje" ] - Esta sección define todas las opciones de montaje que deben usarse en un punto de montaje particular. La cadena "Punto_Montaje" debe ir entre comillas y ser una coincidencia exacta del punto de montaje utilizado en el comando mount. Aunque los nombres de ruta suelen distinguir entre mayúsculas y minúsculas, el nombre del Punto_Montaje se compara sin distinguir mayúsculas y minúsculas.

Las secciones se procesan en orden inverso al de la lista anterior, y cualquier opción vista previamente, ya sea en una sección anterior o en la línea de comandos, se ignorará al volver a verla.

EJEMPLOS

Estas son algunas líneas de ejemplo de cómo se definen las secciones y variables en el archivo de configuración.

[ NFSMount_Global_Options ]
Proto=Tcp

Se utilizará el protocolo TCP/IPv4 en cada montaje NFS.

[ Server "nfsserver.foo.com" ]
rsize=32k
wsize=32k
proto=udp6

Se utilizará un tamaño de bloque de 32k (32768 bytes) como tamaño de lectura y escritura en todos los montajes al servidor 'nfsserver.foo.com'. UDP/IPv6 es el protocolo a utilizar.

[ MountPoint "/export/home" ]
Background=True

Todos los montajes a la exportación '/export/home' se realizarán en segundo plano (es decir, de forma asíncrona).

ARCHIVOS

/usr/etc/nfsmount.conf
/usr/etc/nfsmount.conf.d/*.conf
/etc/nfsmount.conf
/etc/nfsmount.conf.d/*.conf

Archivos de configuración predeterminados para montajes NFS; las variables establecidas en el último archivo anulan las del archivo anterior.
