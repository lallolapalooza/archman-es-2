NOMBRE

nfsstat - listar estadísticas de NFS

SINOPSIS

nfsstat [OPCIÓN]...

DESCRIPCIÓN

nfsstat muestra estadísticas sobre la actividad del cliente y servidor NFS.

OPCIONES

-s, --server
Mostrar solo estadísticas del lado del servidor. El valor predeterminado es mostrar estadísticas tanto del servidor como del cliente.
-c, --client
Mostrar solo estadísticas del lado del cliente.
-n, --nfs
Mostrar solo estadísticas NFS. El valor predeterminado es mostrar información tanto de NFS como de RPC.
-2
Mostrar solo estadísticas de NFS v2. El valor predeterminado es mostrar solo información sobre las versiones de NFS que tienen recuentos distintos de cero.
-3
Mostrar solo estadísticas de NFS v3. El valor predeterminado es mostrar solo información sobre las versiones de NFS que tienen recuentos distintos de cero.
-4
Mostrar solo estadísticas de NFS v4. El valor predeterminado es mostrar solo información sobre las versiones de NFS que tienen recuentos distintos de cero.
-m, --mounts
Mostrar información sobre cada uno de los sistemas de archivos NFS montados.

Si se utiliza esta opción, se ignoran todas las demás opciones.

-r, --rpc
Mostrar solo estadísticas RPC.
-o instalación
Mostrar estadísticas para la instalación especificada, que debe ser una de las siguientes:
nfs
Información del protocolo NFS, dividida por llamada RPC.
rpc
Información general de RPC.
net
Estadísticas de la capa de red, como el número de paquetes recibidos, número de conexiones TCP, etc.
fh
Información de uso de la caché de manejadores de archivos del servidor, incluyendo el número total de búsquedas y el número de aciertos y fallos.
rc
Información de uso de la caché de respuestas a solicitudes del servidor, incluyendo el número total de búsquedas y el número de aciertos y fallos.
io
Información de uso de las estadísticas de E/S del servidor; bytes leídos y escritos.
ra
Información de uso de la caché de prelectura del servidor, incluyendo el tamaño de la caché ra, la profundidad de los aciertos de la caché ra y los fallos de la caché ra.
all
Mostrar todas las instalaciones anteriores.
-v, --verbose
Esto es equivalente a -o all.
-l, --list
Mostrar información en formato de lista.
-S, --since archivo
En lugar de mostrar estadísticas actuales, nfsstat importa estadísticas del archivo y muestra la diferencia entre estas y las estadísticas actuales. Los archivos de entrada válidos archivo pueden ser del tipo /proc/net/rpc/nfs (estadísticas crudas del cliente), /proc/net/rpc/nfsd (estadísticas crudas del servidor) o resultados guardados del propio nfsstat (estadísticas de cliente y/o servidor). Cualquier estadística que falte en un archivo de salida guardado de nfsstat se trata como cero.
-Z[intervalo], --sleep=[intervalo]
En lugar de mostrar estadísticas actuales y salir inmediatamente, nfsstat toma una instantánea de las estadísticas actuales y se pausa hasta que recibe SIGINT (normalmente desde Ctrl-C), momento en el que toma otra instantánea y muestra la diferencia entre ambas. Si se especifica intervalo, nfsstat mostrará el número de llamadas NFS realizadas desde el informe anterior. Las estadísticas se mostrarán repetidamente cada intervalo segundos.

EJEMPLOS

nfsstat -o all -234
Mostrar toda la información sobre todas las versiones de NFS.
nfsstat --verbose -234
Igual que el anterior.
nfsstat -o all
Mostrar toda la información sobre las versiones activas de NFS.
nfsstat --nfs --server -3
Mostrar estadísticas para el servidor NFS versión 3.
nfsstat -m
Mostrar información sobre los sistemas de archivos NFS montados.

VISUALIZACIÓN

La salida de Flags de la opción -m es la misma que las banderas pasadas al comando mount.

ARCHIVOS

/proc/net/rpc/nfsd
Interfaz basada en procfs a las estadísticas del servidor NFS del núcleo.
/proc/net/rpc/nfs
Interfaz basada en procfs a las estadísticas del cliente NFS del núcleo.
/proc/mounts
Interfaz basada en procfs a los sistemas de archivos montados.

VER TAMBIÉN

rpc.nfsd(8). nfs(5).

ERRORES

La salida predeterminada ha cambiado. Para obtener la salida predeterminada anterior, debe ejecutar nfsstat --auto -2.

La función de las opciones -v y -a ha cambiado. La opción -a está ahora reservada para uso futuro. La opción -v hace lo que solía hacer la opción -a, y las nuevas opciones -[234] reemplazan la opción -v.

La sección Visualización debería ser más completa.

Se pueden encontrar o reportar más errores en http://nfs.sf.net/.

Página de Manual

NOMBRE

nfsstat - Estadísticas del cliente y servidor NFS

SINOPSIS

nfsstat [-dunscv] [-o outfile]

DESCRIPCIÓN

nfsstat muestra estadísticas sobre la actividad del cliente y servidor NFS. También se puede usar para restablecer las estadísticas del kernel. Si no se especifica ninguna opción, se muestra una lista de estadísticas del cliente y del servidor.

OPCIONES

-d
Muestra estadísticas de cada dispositivo (solo para clientes NFS).
-u
Muestra estadísticas de cada usuario (solo para clientes NFS).
-n
Muestra estadísticas de red (por host) (solo para clientes NFS).
-s
Muestra estadísticas del servidor NFS.
-c
Muestra estadísticas del cliente NFS.
-v
Muestra estadísticas detalladas de RPC (solo para clientes NFS).
-o <outfile>
Escribe las estadísticas en el archivo especificado en lugar de la salida estándar. Si el archivo existe, se sobrescribe. Si el archivo es -, se escribe en la salida estándar.

VALOR DE RETORNO

nfsstat devuelve 0 si tiene éxito, y diferente de cero si ocurre un error.

EJEMPLOS

Para mostrar estadísticas del cliente y del servidor:

nfsstat

Para mostrar solo estadísticas del cliente:

nfsstat -c

Para mostrar solo estadísticas del servidor:

nfsstat -s

Para mostrar estadísticas del cliente por host:

nfsstat -n

Para restablecer todas las estadísticas del cliente y del servidor:

nfsstat -z
