nfs4_uid_to_name(3)

Paquete: nfsidmap

Licencias: GPL-2.0-or-later

nfs4_uid_to_name(3) Manual de funciones de biblioteca nfs4_uid_to_name(3)

NOMBRE

nfs4_uid_to_name, nfs4_gid_to_name, nfs4_name_to_uid, nfs4_name_to_gid, nfs4_init_name_mapping, nfs4_get_default_domain, nfs4_gss_princ_to_ids, nfs4_gss_princ_to_grouplist, nfs4_gss_princ_to_ids_ex, nfs4_gss_princ_to_grouplist_ex, nfs4_set_debug - rutinas de mapeo de ID utilizadas para NFSv4

SINOPSIS

#include <nfs4_idmap.h>

int nfs4_init_name_mapping(char *conffile);

int nfs4_get_default_domain(char *server, char *domain, size_t len);

int nfs4_uid_to_name(uid_t uid, char *domain, char *name, size_t len);

int nfs4_uid_to_owner(uid_t uid, char *domain, char *name, size_t len);

int nfs4_gid_to_name(gid_t gid, char *domain, char *name, size_t len);

int nfs4_gid_to_owner(gid_t gid, char *domain, char *name, size_t len);

int nfs4_name_to_uid(char *name, uid_t *uid);

int nfs4_name_to_gid(char *name, gid_t *gid);

int nfs4_owner_to_uid(char *name, uid_t *uid);

int nfs4_owner_to_gid(char *name, gid_t *gid);

int nfs4_gss_princ_to_ids(char *secname, char *princ, uid_t *uid, gid_t *gid);

int nfs4_gss_princ_to_grouplist(char *secname, char *princ, gid_t *groups, int *ngroups);

int nfs4_gss_princ_to_ids_ex(char *secname, char *princ, uid_t *uid, gid_t *gid, extra_mapping_params **ex);

int nfs4_gss_princ_to_grouplist_ex(char *secname, char *princ, gid_t *groups, int *ngroups, extra_mapping_params **ex);

void nfs4_set_debug(int dbg_level, void (*logger)(const char *, ...));


DESCRIPCIÓN

NFSv4 utiliza nombres del tipo usuario@dominio. Para escribir código que ayude al kernel a mapear uid's (como lo hace rpc.idmapd) o que procese ACL de NFSv4, necesitarás poder convertir entre nombres NFSv4 y uid's y gid's locales.

Las funciones nfs4_uid_to_name() y nfs4_gid_to_name(), dadas uid o gid y domain (como una cadena terminada en nulo), escriben el nombre nfsv4 correspondiente en el búfer proporcionado en name, que debe tener una longitud de al menos len.

Las funciones nfs4_uid_to_owner() y nfs4_gid_to_group_owner(), dadas uid o gid y domain (como una cadena terminada en nulo), escriben el nombre nfsv4 correspondiente en el búfer proporcionado en name, que debe tener una longitud de al menos len. Si no hay un mapeo válido de uid o gid a name, se devuelve la cadena numérica que representa uid o gid.

Las funciones nfs4_name_to_uid() y nfs4_name_to_gid(), dadas name (como una cadena terminada en nulo), devuelven el uid o gid correspondiente en el segundo parámetro.

Las funciones nfs4_owner_to_uid() y nfs4_group_owner_to_gid(), dadas name (como una cadena terminada en nulo), devuelven el uid o gid correspondiente en el segundo parámetro. Si no hay un mapeo válido de name a uid o gid, se devolverá el valor para el usuario o grupo "nadie" en su lugar.

La función nfs4_init_name_mapping() debe llamarse antes de utilizar cualquiera de estas funciones. Lee los valores predeterminados del archivo de configuración en la ruta proporcionada, generalmente "etc/idmapd.conf".

El argumento domain para las funciones de id-a-nombre está ahí para proporcionar una pista al asignador de nombres en el caso en que un id pueda mapearse a nombres en múltiples dominios. En la mayoría de los casos, este argumento debería ser simplemente el nombre devuelto en el argumento domain de nfs4_get_default_domain(), que debe llamarse con server establecido en NULL. El domain debe ser un búfer de longitud len. La constante NFS4_MAX_DOMAIN_LEN puede usarse para determinar un valor razonable para esa longitud.

La función nfs4_get_grouplist(), dado un name, rellena la matriz proporcionada groups con hasta *ngroups IDs de grupo correspondientes a los que pertenece el usuario name, estableciendo *ngroups en el número real de dichos grupos. Si el usuario pertenece a más de *ngroups grupos, se devuelve un error y el número real de grupos se almacena en *ngroups.

Las funciones nfs4_gss_princ_to_ids(), nfs4_gss_princ_to_grouplist(), nfs4_gss_princ_to_ids_ex(), y nfs4_gss_princ_to_grouplist_ex() se utilizan para convertir de un nombre principal gss (como el devuelto por gss_display_name()) a un uid y gid, o una lista de gids.

Finalmente, nfs4_set_debug() permite a la aplicación establecer un nivel de depuración para producir información de depuración adicional desde dentro de la biblioteca. La función logger opcional especifica una función de registro alternativa para llamar a los mensajes de depuración en lugar de la función interna predeterminada dentro de la biblioteca.

VALOR DE RETORNO

Todas las funciones devuelven 0 o, en caso de error, -ERRNO.
