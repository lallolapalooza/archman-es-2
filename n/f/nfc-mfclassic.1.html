NOMBRE

nfc-mfclassic - Herramienta de línea de comandos MIFARE Classic

SINOPSIS

nfc-mfclassic f|r|R|w|W a|A|b|B u|U<uid> DUMP [ CLAVES [f] ]

DESCRIPCIÓN

nfc-mfclassic es una herramienta MIFARE Classic que permite leer o escribir el archivo DUMP usando las claves MIFARE proporcionadas en el archivo CLAVES.

La etiqueta MIFARE Classic es una de las etiquetas RFID más utilizadas.

El firmware del controlador NFC soporta la autenticación, lectura y escritura desde/hacia etiquetas MIFARE Classic. Esta herramienta demuestra la velocidad de esta biblioteca y su facilidad de uso. Es posible leer y escribir el contenido completo de una etiqueta MIFARE Classic de 4KB en menos de 1 segundo. Utiliza un archivo binario MIFARE Dump (MFD) para almacenar las claves y los datos de todos los sectores.

Ten cuidado, ya que algunas partes de la memoria MIFARE Classic se utilizan para el acceso de lectura/escritura del resto de la memoria, ¡así que lee la documentación de la etiqueta antes de experimentar demasiado!

La opción f para formatear la tarjeta restablecerá todas las claves a FFFFFFFFFFFF, todos los datos a 00 y todas las ACL a los valores predeterminados.

La opción W permite escribir en tarjetas MIFARE especiales que pueden ser "desbloqueadas" para permitir la reescritura del bloque 0. Esto incluye el UID y los datos del fabricante. Ten cuidado al modificar los UID para establecer el BCC (checksum del UID) correcto. Actualmente, solo se admiten UID de 4 bytes.

De manera similar, la opción R permite una lectura "desbloqueada". Esto omite la autenticación y permite leer los datos de las claves A y B independientemente de las ACL.

Los errores de lectura/escritura en algunos bloques pueden ser considerados críticos o ignorados. Para detenerse al primer error, especifica las claves en minúsculas ( a o b ). Para ignorar dichos errores, utiliza mayúsculas ( A o B ).

Cuando se utilizan varias etiquetas delante de un lector, la opción U se puede usar para proporcionar el UID de la etiqueta que se va a leer o escribir. Añade el UID hexadecimal a la opción U. Por ejemplo, U01ab23cd para el UID de 4 bytes 0x01 0xab 0x23 0xcd. Usar el parámetro u en su lugar utilizará lo que libnfc decida, que generalmente es el UID más bajo.

*** Ten en cuenta que las opciones W y R solo funcionan en versiones especiales de tarjetas MIFARE 1K (clones chinos).

OPCIONES

f | r | R | w | W
Realiza el formateo ( f ) o la lectura desde ( r ) o lectura desbloqueada desde ( R ) o escritura a ( w ) o escritura desbloqueada a ( W ) la tarjeta.
a | A | b | B
Utiliza las claves MIFARE A o B. Detenerse en caso de error ( a | b ) o tolerar errores ( A | B ).
u | U
Utiliza el UID predeterminado ( u ) o proporciona un UID válido de 4 bytes ( U<uid> ).
DUMP
Archivo MIFARE Dump (MFD) utilizado para escribir (tarjeta a MFD) o (MFD a tarjeta)
CLAVES
Archivo MIFARE Dump (MFD) que contiene las claves (opcional). La parte de datos del volcado se ignora.
f
Forzar el uso del archivo de claves CLAVES incluso si el UID no coincide (opcional).
