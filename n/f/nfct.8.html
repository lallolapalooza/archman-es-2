NOMBRE

nfct - herramienta de línea de comandos para configurar con el sistema de seguimiento de conexiones

SINOPSIS

nfct comando subsistema [parámetros]

DESCRIPCIÓN

nfct es la herramienta de línea de comandos que le permite configurar el Sistema de Seguimiento de Conexiones.

COMANDOS

listar
Lista los objetos existentes.
añadir
Añade un nuevo objeto.
eliminar
Elimina un objeto.
obtener
Obtiene un objeto existente.
limpiar
Limpia la tabla de objetos de contabilidad.
deshabilitar
Este comando es para el subsistema helper. Permite deshabilitar la puesta en cola de paquetes al espacio de usuario para la inspección de helpers.
predeterminado-establecer
Este comando es para el subsistema timeout. Permite establecer tiempos de espera predeterminados de protocolo.
predeterminado-obtener
Este comando es para el subsistema timeout. Permite obtener los tiempos de espera predeterminados de protocolo.

SUBSISTEMAS

En el momento en que se escribió esta página del manual, los subsistemas admitidos son timeout y helper.

tiempo-de-espera
El subsistema tiempo-de-espera permite definir políticas de tiempo de espera de grano fino.
ayudante
El subsistema ayudante permite configurar ayudantes de espacio de usuario.
versión
Muestra la información de la versión.
ayuda
Muestra el mensaje de ayuda.

EJEMPLO

nfct añadir tiempo-de-espera prueba-tcp inet tcp establecido 100 cerrar 10 close_wait 10
Esto crea una política de tiempo de espera para tcp usando 100 segundos para el estado ESTABLISHED, 10 segundos para el estado CLOSE y 10 segundos para el estado CLOSE_WAIT.
Luego, puede adjuntar la política de tiempo de espera con el objetivo CT de iptables:
iptables -I PREROUTING -t raw -p tcp -j CT --timeout prueba-tcp
iptables -I OUTPUT -t raw -p tcp -j CT --timeout prueba-tcp
Puede probar esa política de tiempo de espera con:
conntrack -E -p tcp
Debería mostrar:
[ACTUALIZACIÓN] tcp 6 100 ESTABLISHED src=192.168.39.100 dst=57.126.1.20 sport=56463 dport=80 src=57.126.1.20 dst=192.168.39.100 sport=80 dport=56463 [ASEGURADO]
