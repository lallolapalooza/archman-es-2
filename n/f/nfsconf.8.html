NOMBRE

nfsconf - Consultar varias configuraciones de NFS

SINOPSIS

nfsconf --dump [-v|--verbose] [-f|--file infile.conf] [outfile]

nfsconf --entry [--arg subsection] section tag

nfsconf --get [-v|--verbose] [-f|--file infile.conf] [-a|--arg subsection] section tag

nfsconf --isset [-v|--verbose] [-f|--file infile.conf] [-a|--arg subsection] section tag

nfsconf --set [-v|--verbose] [-m|--modified Modificado por texto] [-f|--file infile.conf] [-a|--arg subsection] section tag value

nfsconf --unset [-v|--verbose] [-f|--file infile.conf] [-a|--arg subsection] section tag

DESCRIPCIÓN

El comando nfsconf se puede utilizar para probar y recuperar configuraciones de una serie de archivos de configuración de nfs-utils.

Modos

Los siguientes modos están disponibles:

-d, --dump
Imprime un volcado ordenado alfabéticamente de la configuración actual en formato de archivo de configuración. Acepta un nombre de archivo opcional en el que escribir la salida.
-e, --entry
recupera la entrada de configuración en lugar de su valor expandido actual
-i, --isset
Comprueba si una etiqueta específica tiene un valor establecido.
-g, --get
Imprime el valor actual de la etiqueta especificada.
-s, --set
Actualiza o añade una etiqueta y un valor al archivo de configuración en una sección especificada, creando la etiqueta, la sección y el archivo si es necesario. Si la sección se define como '#' entonces se añade un comentario al archivo. Si se establece un comentario con un nombre de etiqueta, se reemplaza cualquier comentario etiquetado existente con un nombre coincidente.
-u, --unset
Elimina la etiqueta especificada y su valor del archivo de configuración.

OPCIONES

Opciones válidas en todos los modos

-v, --verbose
Aumenta la verbosidad e imprime información de depuración.
-f, --file infile
Selecciona un archivo de configuración diferente para operar, por defecto es /etc/nfs.conf

Opciones solo válidas en los modos --entry, --get y --isset.

-a, --arg subsection
Selecciona una subsección específica

Opciones solo válidas en el modo --set.

-m, --modified "Modificado por nfsconf" Establece el texto en el comentario de fecha de modificación en el archivo. Establézcalo vacío para eliminarlo.

ESTADO DE SALIDA

Modo --isset

En este modo, el comando devolverá éxito (0) si la etiqueta seleccionada tiene un valor; cualquier otro código de salida indicará que el valor no está establecido o que ha ocurrido algún otro error.

en todos los demás modos

El éxito se indica con un estado de salida de cero; cualquier otro estado indica un error. Los mensajes de error se imprimen en stderr y el aumento de la verbosidad proporcionará explicaciones más detalladas si están disponibles.

EJEMPLOS

nfsconf -v --dump --file /tmp/testconf.conf sorted.conf
Comprueba si un nuevo archivo de configuración tiene errores de sintaxis e imprime una versión ordenada para facilitar la comparación con la configuración existente.
if ! nfsconf --isset gssd preferred-realm ; then echo 'No hay reino preferido configurado para gss'; fi
La herramienta permite probar fácilmente los valores de configuración desde scripts de shell; aquí comprobamos si se ha establecido un valor específico.
nfsconf --file /etc/nfsmount.conf --get --arg /home MountPoint background
Muestra el valor predeterminado para la opción background para montajes NFS de la ruta /home.
nfsconf --file /etc/nfs.conf --set nfsd debug 1
Habilita la depuración en nfsd
