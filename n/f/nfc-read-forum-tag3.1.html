NOMBRE

nfc-read-forum-tag3 - Extraer mensaje NDEF de una etiqueta NFC Forum Tipo 3

SINOPSIS

nfc-read-forum-tag3 [ -q ] -o ARCHIVO

DESCRIPCIÓN

nfc-read-forum-tag3 Esta utilidad extrae (si está disponible) mensajes NDEF contenidos en una etiqueta NFC Forum Tipo 3 a ARCHIVO.

OPCIONES

-o ARCHIVO : Salida del mensaje NDEF extraído a ARCHIVO (use -o - para salid a stdout).

-q : Modo silencioso, no mostrar información de análisis de bloque de atributos.

ERRORES

Por favor, reporte cualquier error en el rastreador de problemas de libnfc en:
https://github.com/nfc-tools/libnfc/issues
