NOMBRE

nfbpf_compile — genera código de bytes para usar con xt_bpf

SINOPSIS


nfbpf_compile [ TIPOENLACE ] PROGRAMA

TIPOENLACE := { EN10MB | RAW | SLIP | ... }

DESCRIPCIÓN

La utilidad nfbpf_compile ayuda a generar código de bytes BPF adecuado para pasar a la coincidencia bpf de iptables.

OPCIONES

TIPOENLACE
Tipo de encabezado de capa de enlace sobre el que operar. Este es un nombre tal como se define en <pcap/dlt.h> pero con el prefijo inicial DLT_ eliminado. Para usar con iptables, RAW debería ser la opción correcta (también es la opción predeterminada si no se especifica).
PROGRAMA
La expresión BPF a compilar, consulte pcap-filter(7) para una descripción del lenguaje.

ESTADO DE SALIDA

El programa devuelve 0 en caso de éxito, 1 en caso contrario.

EJEMPLO

Coincidir con paquetes TCP entrantes con un tamaño mayor a 100 bytes:


bpf=$(nfbpf_compile 'tcp and greater 100')
iptables -A INPUT -m bpf --bytecode "$bpf" -j ACCEPT

La descripción de la coincidencia bpf en iptables-extensions(8) enumera algunos ejemplos más.
