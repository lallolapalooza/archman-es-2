NOMBRE

nfc-emulate-forum-tag2 — Herramienta de demostración por línea de comandos para emulación de etiquetas NFC Forum tipo 2

SINOPSIS

nfc-emulate-forum-tag2

DESCRIPCIÓN

nfc-emulate-forum-tag2 es una herramienta de demostración que emula una etiqueta NFC Forum Tipo 2 con contenido NDEF.

Algunos dispositivos compatibles con NFC Forum Tipo 2 pueden ser utilizados con este ejemplo, solo en modo de lectura.

IMPORTANTE

Este ejemplo ha sido desarrollado utilizando hardware USB PN533 como objetivo y un teléfono Google Nexus S como iniciador.

Se sabe que NO funciona con Nokia 6212 Classic y podría fallar con varios dispositivos compatibles con NFC Forum debido a las siguientes razones:

- El objetivo emulado solo tiene un UID de 4 bytes, mientras que la mayoría de los dispositivos asumen que una etiqueta Tipo 2 siempre tiene un UID de 7 bytes (como una etiqueta Mifare Ultralight real);

- El chip está emulando una etiqueta ISO/IEC 14443-3, sin ningún asistente de hardware. Si el iniciador tiene tiempos de espera demasiado estrictos para la emulación basada en software (que suele ser el caso), este ejemplo fallará. Esto no es un error y no podemos hacer nada usando este hardware (PN531/PN533).

Los dispositivos ACR122 (como touchatag, etc.) pueden ser utilizados por este ejemplo, pero si algo sale mal, tendrá que desconectar y volver a conectar su dispositivo. Esto no es un error de libnfc, este problema se debe al MCU interno del ACR122 delante del chip NFC (PN532).

ERRORES

Por favor, reporte cualquier error en el rastreador de problemas de libnfc en: https://github.com/nfc-tools/libnfc/issues
