Nombre

nftables.service — Configuración de firewall estática con nftables.service

Descripción

Se proporciona un servicio systemd de nftables que permite configurar conjuntos de reglas de firewall estáticas basadas en un archivo de configuración.

Para usar este servicio, necesita crear el archivo de configuración principal en /etc/nftables/rules/main.nft. Una plantilla para esto puede ser copiada de /usr/share/doc/nftables/main.nft. Alternativamente, se podría usar `nft list ruleset >main.nft` para guardar la configuración activa (si la hay) en el archivo.

Una vez que la configuración de firewall estática deseada esté en su lugar, se puede probar ejecutando `systemctl start nftables.service`. Para habilitar el servicio al arrancar, ejecute `systemctl enable nftables.service`.
