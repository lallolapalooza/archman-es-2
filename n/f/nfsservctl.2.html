nfsservctl(2) Manual de llamadas al sistema nfsservctl(2)

NOMBRE

nfsservctl - interfaz de llamada al sistema al demonio nfs del kernel

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <linux/nfsd/syscall.h>
long nfsservctl(int cmd, struct nfsctl_arg *argp,
                union nfsctl_res *resp);

DESCRIPCIÓN

Nota: Desde Linux 3.1, esta llamada al sistema ya no existe. Ha sido reemplazada por un conjunto de archivos en el sistema de archivos nfsd; véase nfsd(7).


/*
 * Estos son los comandos entendidos por nfsctl().
 */
#define NFSCTL_SVC        0  /* Este es un proceso servidor.  */
#define NFSCTL_ADDCLIENT  1  /* Añadir un cliente NFS.  */
#define NFSCTL_DELCLIENT  2  /* Eliminar un cliente NFS.  */
#define NFSCTL_EXPORT     3  /* Exportar un sistema de archivos.  */
#define NFSCTL_UNEXPORT   4  /* Desexportar un sistema de archivos.  */
#define NFSCTL_UGIDUPDATE 5  /* Actualizar el mapa de UID/GID de un cliente
                                (solo en Linux 2.4.x y anteriores).  */
#define NFSCTL_GETFH      6  /* Obtener un identificador de archivo (usado por mountd(8))
                                (solo en Linux 2.4.x y anteriores).  */
struct nfsctl_arg {
    int                       ca_version;     /* salvaguarda */
    union {
        struct nfsctl_svc     u_svc;
        struct nfsctl_client  u_client;
        struct nfsctl_export  u_export;
        struct nfsctl_uidmap  u_umap;
        struct nfsctl_fhparm  u_getfh;
        unsigned int          u_debug;
    } u;
}
union nfsctl_res {
        struct knfs_fh          cr_getfh;
        unsigned int            cr_debug;
};

VALOR DEVUELTO

En caso de éxito, se devuelve cero. En caso de error, se devuelve -1 y la variable global errno se establece para indicar el error.

ESTÁNDARES

Linux.

HISTORIA

Eliminado en Linux 3.1. Eliminado en glibc 2.28.

VEASE TAMBIÉN

nfsd(7)
