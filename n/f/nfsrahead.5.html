NOMBRE

nfsrahead - Configura la prelectura para montajes NFS

SINOPSIS

nfsrahead [-F] [-d] <dispositivo>

DESCRIPCIÓN

nfsrahead es una herramienta destinada a ser utilizada con udev para establecer el parámetro read_ahead_kb de los montajes NFS, de acuerdo con el archivo de configuración (ver CONFIGURACIÓN). dispositivo es el número del dispositivo para el dispositivo subyacente NFS proporcionado por el kernel.

OPCIONES

-F
Envía mensajes a stderr en lugar de syslog
-d
Aumenta el nivel de depuración.

CONFIGURACIÓN

nfsrahead se configura en /etc/nfs.conf, en la sección titulada nfsrahead. Acepta las siguientes configuraciones.

nfs=<valor>
El valor de prelectura aplicado a montajes NFSv3.
nfs4=<valor>
El valor de prelectura aplicado a montajes NFSv4.
default=<valor>
La configuración por defecto cuando no se establece ninguna de las configuraciones anteriores.

EJEMPLO DE CONFIGURACIÓN

[nfsrahead]
nfs=15000 # prelectura de 15000 para montajes NFSv3
nfs4=16000 # prelectura de 16000 para montajes NFSv4
default=128 # el valor por defecto es 128

VER TAMBIÉN

mount.nfs(8), nfs(5), nfs.conf(5), udev(7), bcc-readahead(8)

ERRORES

Ningún error conocido.
