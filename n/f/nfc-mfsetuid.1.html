NOMBRE

nfc-mfsetuid - herramienta para establecer y recuperar el UID de tarjetas especiales MIFARE 1K

SINOPSIS

nfc-mfsetuid [ UID ]

DESCRIPCIÓN

nfc-mfsetuid es una herramienta MIFARE que permite establecer el UID en versiones especiales (clones chinos) de tarjetas Mifare 1K. También recuperará tarjetas dañadas a las que se les ha escrito datos inválidos en el bloque 0 (por ejemplo, un BCC incorrecto). Actualmente, solo se admite UID de 4 bytes. Especifique un UID de ocho caracteres hexadecimales o déjelo en blanco para el valor predeterminado '01234567'.

OPCIONES

-f Formatear. Borra todos los datos (establece a 0xFF) y restablece las ACL a los valores predeterminados.

-q Silencioso. Suprime la salida de comandos y respuestas.
