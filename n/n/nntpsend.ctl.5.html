NOMBRE

nntpsend.ctl - Lista de sitios para alimentar vía nntpsend

DESCRIPCIÓN

El archivo pathetc/nntpsend.ctl especifica la lista predeterminada de sitios que serán alimentados por nntpsend. Los comentarios comienzan con un signo de Libra ("#") y continúan hasta el final de la línea. Las líneas en blanco y los comentarios se ignoran. Todas las demás líneas deben consistir en cuatro campos separados por dos puntos.

El primer campo es el nombre del sitio tal como se especifica en el archivo newsfeeds.

El segundo campo debe ser el nombre de host o la dirección IP del sitio remoto.

El tercer campo, si no está vacío, especifica el tamaño de truncamiento predeterminado de la cabecera del archivo de lotes. Si este campo está vacío, no se realiza ningún truncamiento. Este campo puede tener el formato "maxsize-truncsize", en cuyo caso se pasa a shrinkfile como "-m maxsize -s truncsize"; de lo contrario, tiene el formato "truncsize", en cuyo caso se pasa como "-s truncsize".

El cuarto campo especifica algunas banderas predeterminadas que se pasan a innxmit. Tenga en cuenta que la bandera -a siempre se otorga a innxmit y no necesita aparecer aquí. Si no se proporciona ninguna bandera -t en este campo o en la línea de comandos de nntpsend, se proporcionará "-t 180" a innxmit.

Vea nntpsend(8) para un ejemplo del archivo de configuración de nntpsend.ctl.
