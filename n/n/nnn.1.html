NNN(1) General Commands Manual NNN(1)

NOMBRE

nnn — El gestor de archivos de terminal poco ortodoxo.

SINOPSIS

nnn [-aAcCdDeEfgHJKnQrRSuUVxh] [-b clave] [-F valor] [-l valor] [-p archivo] [-P clave] [-s nombre] [-t segs] [-T clave] [RUTA]

DESCRIPCIÓN

nnn (Nnn's Not Noice) es un fork optimizado en rendimiento y repleto de funciones de noice http://git.2f30.org/noice/ con integración perfecta al escritorio, navegación simplificada, modo de escritura para navegar con entrada automática de directorios, modo analizador de uso de disco, marcadores, contextos, lanzador de aplicaciones, atajos de navegación familiares, creación de subshells y mucho más. Sigue siendo un gestor de archivos simple y eficiente que no interfiere.

nnn abre el directorio de trabajo actual si no se especifica RUTA. Si se especifica RUTA y existe, nnn la abrirá. Si la RUTA no existe y termina en /, nnn intentará crear el árbol de directorios y la abrirá. De lo contrario, RUTA se considera una ruta a un archivo regular y nnn intenta crear el árbol de directorios completo hasta el archivo, abrir el directorio padre y preguntar si se crea el nuevo archivo en él con el nombre base del archivo.

ATAJOS DE TECLADO

Presiona ‘?’ en nnn para ver la lista de atajos de teclado.

OPCIONES

nnn admite las siguientes opciones:

-a
configuración automática de NNN_FIFO temporal (consultar la sección ENTORNO)

-A
desactivar la entrada automática al directorio en coincidencias de filtro únicas

-b clave
especificar clave de marcador para abrir

-B
usar bsdtar para archivos (por defecto: atool)

-c
indica que el abridor es un abridor solo por CLI (anula -e)

-C
esquema de 8 colores - colorea directorios por contexto, desactiva colores de archivo

-d
modo detallado

-D
muestra directorios en color de contexto con NNN_FCOLORS establecido

-e
abre archivos de texto en $VISUAL (o $EDITOR, alternativa vi) [preferiblemente CLI]

-E
usa $EDITOR para ediciones internas no separadas

-f
usa archivo de historial de readline

-F valor
modo de notificación fifo
0: notificar como previsualizador, 1: notificar como explorador

-g
usa filtros regex en lugar de coincidencia de subcadena

-H
muestra archivos ocultos

-i
muestra información del archivo actual en la barra de información (puede ser lento)

-J
desactiva el avance automático en la selección
(por ejemplo, seleccionar una entrada ya no moverá el cursor a la siguiente entrada)

-K
prueba colisión de atajos de teclado y sale

-l valor
número de líneas a mover por desplazamiento de la rueda del ratón

-n
inicia en modo de escritura para navegar

-o
abre archivos solo al presionar Enter

-p archivo
copia (o *selecciona*) la selección a un archivo, o a la salida estándar si archivo='-'

-P clave
especifica clave de plugin para ejecutar

-Q
desactiva confirmación al salir con múltiples contextos activos

-r
muestra progreso de cp, mv
(solo Linux, requiere *advcpmv*; ^T muestra el progreso en BSD/macOS)

-R
desactiva el rebote en los bordes (por ejemplo, presionar abajo estando en la última
entrada ya no moverá el cursor a la primera entrada y viceversa)

-s nombre
carga una sesión por nombre

-S
sesión persistente

-t segs
tiempo de inactividad en segundos para bloquear la terminal

-T clave
orden de clasificación (consultar la sección ORDENACIÓN)
claves: uso de disco 'a'parental / uso de disco 'd' / 'e'xtensión / 'r'everso / 's'ize / 't'iempo / 'v'ersión
poner en mayúscula para invertir (excepto 'r')

-u
usa la selección si está disponible, no pregunta para elegir entre la selección y la entrada resaltada

-U
muestra nombres de usuario y grupo en la barra de estado

-V
muestra la versión y sale

-x
muestra notificaciones al completar la copia, movimiento, eliminación de selección (requiere el plugin .ntfy)
copia la ruta al portapapeles del sistema al seleccionar (requiere el plugin .cbcp)
muestra el título xterm (si no está en modo selector)

-0
usa separador nulo (en lugar de nueva línea) para separar rutas de archivo en la salida del modo selector

-h
muestra la ayuda del programa y sale

CONFIGURACIÓN

No hay archivo de configuración. Los archivos asociados están en

${XDG_CONFIG_HOME:-$HOME/.config}/nnn/

La configuración se realiza utilizando algunas variables de entorno opcionales (establecer si las necesita). Consulte la sección ENTORNO.

nnn usa xdg-open (en Linux), open(1) (en macOS), cygstart en (Cygwin) y open en (Haiku) como abridor de escritorio. También es posible especificar un abridor personalizado. Consulte la sección ENTORNO.

CONTEXTOS

Abre múltiples ubicaciones con 4 contextos. El estado se muestra en la esquina superior izquierda:

- el contexto actual está en video inverso
- otros contextos activos están subrayados
- el resto están inactivos

Un nuevo contexto copia el estado del contexto anterior. Cada contexto puede tener su propio color. Consulte la sección ENTORNO.

SESIONES

Las sesiones son una forma de guardar y restaurar estados de trabajo. Una sesión almacena la configuración y los contextos. Las sesiones se pueden cargar en tiempo de ejecución o con una opción del programa.

- Cuando se carga una sesión en tiempo de ejecución, el último estado de trabajo se guarda automáticamente en un archivo de sesión dedicado de "sesión automática". La opción de sesión *restaurar* restauraría la "sesión automática".
- La opción de sesión persistente es global. Si se usa, la última sesión activa se actualizará con el estado final al salir del programa.
- La "sesión automática" se usa en modo de sesión persistente si no hay sesión activa.
- La lista de la entrada estándar y la apertura de un marcador por clave tienen una mayor prioridad que las opciones de sesión (-s/-S).

Todos los archivos de sesión se encuentran por nombre de sesión en el directorio

${XDG_CONFIG_HOME:-$HOME/.config}/nnn/sessions

"@" es el archivo de "sesión automática".

FILTROS

Los filtros son cadenas (o patrones regex) para encontrar entradas coincidentes en el directorio actual al instante (búsqueda mientras escribes). Las coincidencias no distinguen entre mayúsculas y minúsculas por defecto. El último filtro en cada contexto se conserva en tiempo de ejecución o en sesiones guardadas.
Cuando hay una coincidencia única y es un directorio, nnn entra automáticamente en el directorio. Usa la opción de programa relevante

RAM OPTION TO DISABLE

this.

Special keys at filter prompt:

-------- + ---------------------------------------
  Key    |                Function
-------- + ---------------------------------------
 ^char   | Usual keybind functionality
 Esc     | Exit filter prompt but skip dir refresh
 Alt+Esc | Unfilter, quit context
-------- + ---------------------------------------

Special keys at empty filter prompt:

------ + ---------------------------------------
  Key  |                Function
------ + ---------------------------------------
   ?   | Show help and config screen
   /   | Toggle between string and regex
   :   | Toggle case-sensitivity
  ^L   | Clear filter (if prompt is non-empty)
       | OR apply last filter
  Bksp | Stay at filter prompt and refresh dir
  Del  | Stay at filter prompt and refresh dir
------ + ---------------------------------------

Common regex use cases:

(1) To list all matches starting with the filter expression,
start the expression with a '^' (caret) symbol.
(2) Type '\.mkv' to list all MKV files.
(3) Use '.*' to match any character (sort of fuzzy search).
(4) Exclude filenames having 'nnn' (compiled with PCRE lib): '^(?!nnn)'

In the type-to-nav mode directories are opened in filter mode, allowing continuous navigation.

Additional special keys at empty filter prompt in type-to-nav mode:

------ + ------------------------
  Key  |         Function
------ + ------------------------
   '   | Go to first non-dir file
   +   | Toggle file selection
   ,   | Mark CWD
   -   | Go to last visited dir
   .   | Show hidden files
   ;   | Run a plugin by its key
   =   | Launch a GUI application
   >   | Export file list
   @   | Visit start dir
   ]   | Show command prompt
   `   | Visit /
   ~   | Go HOME
------ + ------------------------

ORDENACIÓN

nnn siempre mostrará primero los directorios, seguidos de los archivos. El orden de las cadenas de texto no distingue entre mayúsculas y minúsculas.

La clave de ordenación se puede establecer con la opción del programa -T, o interactivamente usando t o ^T. Las siguientes opciones están disponibles:

a
uso aparente del disco, qué tan grande parece ser el archivo, puede ser mayor que el uso real del disco en archivos dispersos.
d
uso del disco, cantidad de datos ocupados en el disco, un múltiplo del tamaño del bloque.
e
extensión del archivo.
r
invierte el orden actual (no disponible con -T).
s
tamaño del archivo, cantidad de datos almacenados en el archivo.
t
tiempo, esto depende del tipo de tiempo actualmente seleccionado que se puede cambiar usando la tecla T. Las opciones son:
a
acceso, última vez que se accedió al archivo.
c
cambio, última vez que se modificó la metadato del archivo (por ejemplo, permisos).
m
modificado, última vez que se modificó el contenido del archivo (predeterminado).
v
versión, ordena por nombre de archivo tratando los caracteres numéricos numéricamente. Por ejemplo: j1.png, j02.png, j3.png.
c
borrar, revertir al orden por nombre de archivo (no disponible con -T).
^T
alterna entre el orden por nombre de archivo/tamaño/tiempo (no disponible con -T).

La versión en mayúsculas de la opción (excepto r) invierte el orden predeterminado. Por defecto, las claves de ordenación por tiempo y tamaño se ordenan en orden descendente, y los campos alfabéticos se ordenan en orden ascendente. Por ejemplo, al usar la opción e, las entradas se ordenarán por extensión, en orden ascendente. Usar E resultaría en un orden descendente de las extensiones. Esto significa que e seguido de r es lo mismo que E.

SELECCIÓN

nnn permite la selección de archivos entre directorios y contextos.

Hay 3 grupos de combinaciones de teclas para añadir archivos a la selección:

(1) alternar selección del archivo resaltado
- deselecciona si '+' es visible antes de la entrada, de lo contrario, la añade a la selección
(2) añadir un rango de archivos a la selección
- repite la misma clave de rango en la misma entrada dos veces para borrar completamente la selección
(3) añadir todos los archivos en el directorio actual a la selección

Una selección puede ser editada, copiada, movida, eliminada, archivada o enlazada.

Las rutas absolutas de los archivos seleccionados se copian al archivo .selection en el directorio de configuración. El archivo de selección se comparte entre múltiples instancias del programa. Las selecciones de múltiples instancias no se fusionan. La última instancia que escribe en el archivo sobrescribe el contenido anterior. Si tienes 2 instancias de nnn *abiertas* en 2 paneles de un multiplexor de terminal, puedes seleccionar en un panel y usar la selección en el otro. La selección se borra en la instancia de nnn donde se realizó la selección al mover/eliminar (pero no al copiar).

nnn borra la selección después de una operación exitosa con la selección. Los plugins pueden definir el comportamiento individualmente.

Para editar la selección, usa la tecla _editar selección_. Editar no finaliza el modo de selección. Puedes añadir más archivos a la selección y editar la lista de nuevo. Si no hay ningún archivo seleccionado en la sesión actual, esta opción intenta listar el archivo de selección.

nnn puede mostrar el tamaño total de los archivos seleccionados no filtrados listados en un directorio. Para los directorios, solo se añade el tamaño del directorio por defecto. Para añadir el tamaño del contenido de un directorio, ordénalo por uso del disco (modo du).

BUSCAR Y LISTAR

Hay dos formas de buscar y listar:

- alimentar una lista de rutas de archivos como entrada
- buscar usando un plugin (por ejemplo, finder) y listar los resultados

Las rutas de los archivos deben estar separadas por NUL ('\0'). Las rutas pueden ser relativas al directorio actual o absolutas. Las rutas inválidas en la entrada se ignoran. El límite de procesamiento de entrada es de 16.384 rutas o 64 MiB (max_paths x max_path_len) de datos.

Para listar el flujo de entrada, inicia nnn escribiendo en su entrada estándar. Por ejemplo, para listar archivos en el directorio actual mayores de 1M:

find -maxdepth 1 -size +1M -print0 | nnn

o redirige una lista desde un archivo:

nnn < files.txt

Una útil función de shell bash/zsh para listar archivos por tipo mime en el directorio actual:

# para mostrar archivos de video, ejecuta: list video

list ()
{
    find . -maxdepth 1 | file -if- | grep "$1" | awk -F: '{printf "%s%c", $1, 0}' | nnn
}

Se creará un directorio temporal que contendrá enlaces simbólicos a las rutas dadas. Cualquier acción realizada sobre estos enlaces simbólicos se realizará solo sobre sus objetivos, después de lo cual podrían volverse inválidos.

> o l en un enlace simbólico en el directorio de listado te lleva al archivo objetivo. Presiona - para volver al directorio de listado. Presiona Enter para abrir el enlace simbólico.

El flujo de entrada de listado se puede guionizar. Se puede extender para seleccionar (opción -p) entradas de los resultados listados.

MARCADORES

Hay 2 formas (pueden usarse juntas) para gestionar marcadores.

(1) Claves de marcador: Ver NNN_BMS en la sección ENTORNO sobre cómo establecer las
claves de marcador.


La tecla de marcador seleccionar b lista todas las claves de marcador establecidas en NNN_BMS
en el prompt de marcadores.

(2) Marcadores enlazados simbólicamente: Se puede crear un marcador enlazado simbólicamente al directorio actual
con la tecla B (o manualmente en ~/.config/nnn/bookmarks).


Pulsar Enter en el prompt de marcadores te lleva a ese directorio.
Si NNN_BMS no está establecido, la tecla de marcador seleccionar lo abre directamente.

Al entrar en un marcador, el directorio donde se pulsó la tecla de marcador seleccionar se establece como el directorio anterior. Pulsa - para volver a él.

UNIDADES

La unidad mínima de tamaño de archivo es byte (B). El resto son K, M, G, T, P, E, Z, Y (potencias de 1024), igual que las unidades predeterminadas en ls.

ENTORNO

Se utilizan las variables de entorno SHELL, VISUAL (si no, EDITOR) y PAGER. Se admite una única combinación de argumentos para SHELL y PAGER.

NNN_OPTS: opciones binarias para nnn

export NNN_OPTS="cEnrx"

NNN_OPENER: especifica un abridor de archivos personalizado.

export NNN_OPENER=nuke

NOTA: nuke es un abridor de archivos disponible en el repositorio de
    plugins.

NNN_BMS: cadena de marcadores como pares clave_caracter:ubicacion separados por ;:

export NNN_BMS="d:$HOME/Docs;u:/home/user/Cam Uploads;D:$HOME/Downloads/"

Estos marcadores se listan en la pantalla de ayuda y configuración (tecla ?).

NNN_PLUG: plugins directamente ejecutables como pares clave_caracter:plugin separados por ;:

export NNN_PLUG='f:finder;o:fzopen;p:mocplay;d:diffs;t:nmount;v:imgview'

NOTAS:
1. Para ejecutar un plugin directamente, presiona ; seguido de la
    tecla.
2. Alternativamente, combínalo con Alt (es decir, Alt+tecla).
3. Para omitir la actualización del directorio después de ejecutar un plugin,
    antepón -.

export NNN_PLUG='p:-plugin'

plugins, añade ! antes del comando.
