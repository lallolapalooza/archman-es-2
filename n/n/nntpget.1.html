NOMBRE

nntpget - Obtener artículos de Usenet desde un servidor NNTP remoto

SINOPSIS

nntpget [-ov] [-f archivo] [-n gruposdenoticias] [-t cadenafecha] [-u archivo] host

DESCRIPCIÓN

nntpget se conecta al servidor NNTP en el host especificado y recupera artículos de él. Los Message-IDs de los artículos deseados se leen de la entrada estándar. Los artículos se envían a la salida estándar.

En lugar de leer Message-IDs de la salida estándar, las opciones -f, -n, -t y -u utilizan el comando "NEWNEWS", que puede no estar disponible en el servidor remoto. Solo una de las opciones -f, -t o -u puede ser dada al mismo tiempo; -n solo puede ser especificada si alguna de las otras tres opciones está en uso.

Si existen credenciales de autenticación para el servidor remoto en el archivo passwd.nntp en el directorio pathetc, entonces nntpget las utilizará para autenticarse.

OPCIONES

-f archivo
La lista de Message-IDs de los artículos se lee normalmente de la entrada estándar. Si se utiliza esta opción, se utiliza un comando "NEWNEWS" para recuperar todos los artículos más recientes que la fecha de modificación del archivo especificado.
-n gruposdenoticias
Si se utilizan las opciones -f, -t o -u, esta opción puede usarse para limitar las respuestas solo a los grupos de noticias (si los hay) cuyos nombres coinciden con la lista. El valor predeterminado es "*", es decir, se desean todos los grupos de noticias.

La lista gruposdenoticias puede contener varios patrones y caracteres wildmat. Por ejemplo "misc.*,!*.test" es una lista válida que se dará al comando "NEWNEWS".

-o
Esta opción solo puede usarse si el comando se ejecuta en el host donde se ejecuta el servidor innd. Si se utiliza esta opción, nntpget se conecta al host remoto especificado para recuperar artículos. Cualquier artículo no presente en la base de datos local history se descarga del sitio remoto y se ofrece al servidor local.

Los artículos no se escriben en la salida estándar. Solo se procesan los Message-IDs, si también se usa la opción -v.

-t cadenafecha
Si se utiliza esta opción, la cadenafecha especificada se usa como parámetro de hora y fecha para el comando "NEWNEWS". Solo se recuperan los artículos llegados al servidor remoto desde esa marca de tiempo.

La cadenafecha se especifica como "aaaaammdd hhmmss GMT" donde "aaaaa" es el año, "mm" el mes, "dd" el día del mes, "hh" las horas en el reloj de 24 horas, "mm" los minutos y "ss" los segundos. El token "GMT" especifica que la fecha y hora se dan en Tiempo Universal Coordinado.

-u archivo
Esta opción es similar a -f, excepto que si la transferencia tiene éxito, el archivo se actualizará con una línea de estadísticas, modificando su marca de tiempo para que pueda usarse en invocaciones posteriores.
-v
Si se utiliza esta opción con -o, el Message-ID de cada artículo se enviará a la salida estándar a medida que se procesa.
