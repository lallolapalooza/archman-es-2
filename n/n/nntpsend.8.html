NOMBRE

nntpsend - Envía artículos de Usenet a sitios remotos

SINOPSIS

nntpsend [-acDdlNnpr] [-P puerto] [-s tamaño] [-T tiempolímite] [-t tiempoespera] [-w retraso] [nombredelsitio fqdn] ...

DESCRIPCIÓN

nntpsend es una interfaz que invoca a innxmit para enviar artículos de Usenet a un sitio NNTP remoto. Los sitios a alimentar pueden especificarse proporcionando pares nombredelsitio fqdn en la línea de comandos. Si no se proporcionan dichos pares, nntpsend utiliza por defecto la información proporcionada en el archivo de configuración nntpsend.ctl. El nombredelsitio debe ser el nombre del sitio tal como se especifica en el archivo newsfeeds. El fqdn debe ser el nombre de host o la dirección IP del sitio remoto. Se lanza un innxmit para los sitios con noticias en cola. Todos los procesos innxmit se generan en segundo plano y el script espera a que todos finalicen antes de regresar. La salida se envía al archivo nntpsend.log en pathlog. Para evitar sobrecargar el sistema local, nntpsend espera cinco segundos antes de generar cada proceso hijo.

nntpsend espera que el archivo por lotes para un sitio se denomine nombredelsitio en pathoutgoing. Para evitar la corrupción de archivos por lotes, se utiliza shlock para "bloquear" estos archivos. Cuando se proporcionan pares nombredelsitio fqdn en la línea de comandos, las banderas proporcionadas en la línea de comandos describen completamente cómo operan innxmit y shrinkfile. Cuando no se proporcionan dichos pares en la línea de comandos, la información encontrada en nntpsend.ctl se convierte en las banderas por defecto para ese sitio. Cualquier bandera proporcionada en la línea de comandos anula las banderas por defecto para el sitio.

Una alternativa a nntpsend puede ser innduct, mencionado en la página del manual de innfeed(8).

OPCIONES

-D, -d
La bandera -D hace que nntpsend envíe la salida a stdout en lugar del archivo de registro nntpsend.log en pathlog. La bandera -d hace lo mismo y pasa -d a todas las invocaciones de innxmit, lo que a su vez hace que innxmit entre en modo de depuración.
-n
Si se utiliza la bandera -n, entonces nntpsend no utiliza shlock para bloquear el uso de nntpsend. Los archivos por lotes seguirán siendo bloqueados.
-s tamaño
Si se utiliza la bandera -s, entonces se invocará a shrinkfile para realizar una truncación de encabezado de tamaño bytes en el archivo por lotes y la bandera se le pasará.
-w retraso
Si se utiliza la bandera -w, entonces nntpsend espera retraso segundos después de vaciar el sitio antes de lanzar innxmit.
-a, -c, -l, -N, -P puerto, -p, -r, -T tiempolímite, -t tiempoespera
Las banderas -a, -c, -l, -P puerto, -p, -r, -T tiempolímite y -t tiempoespera se pasan al programa hijo innxmit. La bandera -N se pasa como bandera -s al programa hijo innxmit. Consulte innxmit(8) para más detalles.

Tenga en cuenta que si se utiliza la bandera -p, no se establece ninguna conexión ni se alimentan artículos al sitio remoto. Es útil que cron(8) invoque a nntpsend con esta bandera en caso de que un sitio no sea accesible durante un período prolongado.

EJEMPLOS

Con el siguiente archivo de configuración nntpsend.ctl:

nsavax:erehwon.nsavax.gov::-t60
group70:group70.org::
walldrug:walldrug.com:4m-1m:-T1800 -t300
kremvax:kremvax.cis:2m:

El comando "nntpsend" dará como resultado lo siguiente:

Sitename        Truncación      banderas de innxmit
nsavax          (ninguno)       -a -t60
group70         (ninguno)       -a -t180
walldrug        1m si >4m       -T1800 -t300
kremvax         2m              -t180

El comando "nntpsend -d -T1200" dará como resultado lo siguiente:

Sitename        Truncación      banderas de innxmit
nsavax          (ninguno)       -a -d -T1200 -t60
group70         (ninguno)       -a -d -T1200 -t180
walldrug        1m si >4m       -d -T1200 -t300
kremvax         2m              -d -T1200 -t180

El comando "nntpsend -s 5m -T1200 nsavax erehwon.nsavax.gov group70 group70.org" dará como resultado lo siguiente:

Sitename        Truncación      banderas de innxmit
nsavax          5m              -T1200 -t180
group70         5m              -T1200 -t180

Recuerde que -a siempre se proporciona cuando no hay límite de tamaño, y -t por defecto es 180.
