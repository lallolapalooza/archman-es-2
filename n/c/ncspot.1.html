  Un cliente de Spotify con ncurses escrito en Rust usando librespot

Crates.io] Gitter]

ncspot es un cliente de Spotify con ncurses escrito en Rust usando librespot. Está fuertemente inspirado en clientes de MPD con ncurses, como ncmpc. Mi motivación fue proporcionar una alternativa simple y amigable con los recursos al cliente oficial, así como dar soporte a plataformas que actualmente no tienen un cliente de Spotify, como los *BSD.

ncspot solo funciona con una cuenta premium de Spotify ya que ofrece características que no están disponibles para cuentas gratuitas.

Características

•
Soporte para pistas, álbumes, listas de reproducción, géneros, búsqueda...
•
Baja huella de recursos
•
Soporte para muchas plataformas
•
Atajos de teclado de Vim listos para usar
•
Socket IPC para control remoto

Instalación

ncspot está disponible en macOS (Homebrew), Windows (Scoop, WinGet), Linux (paquete nativo, Flathub y Snapcraft) y los BSD. Las instrucciones de instalación detalladas para cada plataforma se pueden encontrar aquí.

Configuración

Se puede proporcionar un archivo de configuración. La ubicación por defecto es ~/.config/ncspot. La información detallada de configuración se puede encontrar aquí.

Compilación

La compilación de ncspot requiere una instalación de Rust funcional y una instalación de Python 3. Para compilar ncspot, ejecuta cargo build. Para obtener instrucciones detalladas sobre cómo compilar ncspot, hay más información aquí.
