ncvalidator(1) Utilidades PnetCDF ncvalidator(1)

NOMBRE

ncvalidator - valida un archivo netCDF clásico contra los formatos de archivo CDF

SINOPSIS

ncvalidator [-x] [-t] [-q] [-h] archivo

DESCRIPCIÓN

ncvalidator comprueba la cabecera de un archivo netCDF para ver si se ajusta a los formatos de archivo CDF clásicos. Si el archivo de entrada es un archivo NetCDF válido, se imprimirá un mensaje de validación exitosa en la salida de la línea de comandos, por ejemplo, File "testfile.nc" is a valid NetCDF file. De lo contrario, se imprimirá un mensaje de error de NetCDF.

OPCIONES

-x
Repara el relleno de bytes nulos en la cabecera del archivo. El relleno de bytes nulos es requerido por las Especificaciones de Formato Clásico de NetCDF. PnetCDF impone este requisito, pero NetCDF nunca lo ha impuesto. Esta opción comprueba la cabecera en busca de ubicaciones donde se esperan bytes nulos y los reemplaza con bytes nulos si se encuentran bytes no nulos. El archivo reparado se ajustará a la especificación y permitirá que tanto las bibliotecas PnetCDF como NetCDF lean el archivo sin reportar el código de error NC_ENOTNC o NC_ENULLPAD. Tenga en cuenta que esta reparación se realiza in situ y es posible que los usuarios deseen hacer una copia de seguridad del archivo de entrada primero. Una vez reparado el archivo, se puede ejecutar el comando ncmpidiff para comparar el contenido de dos archivos.
-t
Activa el modo de trazado, imprimiendo el progreso de toda la validación de metadatos exitosa. Cuando se detecta un error, el trazado se detiene en la ubicación del error encontrado.
-q
Modo silencioso: no imprime nada en la salida de la línea de comandos. Cuando está en modo silencioso, los usuarios deben verificar el estado de salida. Vea abajo en "ESTADO DE SALIDA".
-h
Imprime las opciones de línea de comandos disponibles

ESTADO DE SALIDA

Un estado de salida de 0 significa que el archivo cumple con el formato de archivo CDF clásico, y 1 significa lo contrario. Tenga en cuenta que en el sistema basado en VMS, los valores del estado de salida se invierten.

VER TAMBIÉN

ncmpidump(1), pnetcdf(3)
