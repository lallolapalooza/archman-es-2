NOMBRE

ncftpbatch - Procesador de trabajos FTP por lotes individual

SINOPSIS

ncftpbatch -d

ncftpbatch -l

ncftpbatch -D

OPCIONES

Indicadores de línea de comandos:

-d
Inicia el procesamiento en segundo plano de trabajos FTP en el directorio $HOME/.ncftp/spool del usuario actual. Esto retorna inmediatamente, ya que se genera un proceso demonio y se ejecuta en segundo plano.
-l
Lista el contenido de la cola de trabajos del usuario.
-D
Esto es similar a -d, excepto que el proceso no se convierte en un demonio.

DESCRIPCIÓN

Este programa es responsable de procesar las solicitudes FTP en segundo plano. Normalmente solo lo ejecuta ncftp y no un ser humano manualmente, sin embargo, puede ejecutarlo para procesar manualmente la cola de trabajos FTP.

Los trabajos son archivos temporales escritos en el directorio $HOME/.ncftp/spool de un usuario y tienen un formato especial y una convención de nomenclatura de archivos (que contiene cuándo se debe ejecutar el trabajo). ncftp ejecuta este programa cuando lo necesita, pero si el demonio ncftpbatch muere inesperadamente, los trabajos que queden en la cola no se procesarán hasta que se ejecute otra instancia de ncftpbatch.

ncftpget y ncftpput también se pueden usar para enviar trabajos para procesamiento por lotes, utilizando el indicador de línea de comandos -b de esas utilidades. Si se desea, también puede crear manualmente los archivos temporales, aunque este procedimiento no se documenta aquí (consulte la página del manual de ncftpspooler para obtener más información sobre cómo hacerlo).

DIAGNÓSTICOS

ncftpbatch escribe en su propio archivo de registro, el archivo $HOME/.ncftp/spool/log. Este archivo debe examinarse para determinar si algún proceso ncftpbatch está trabajando activamente en los trabajos.
