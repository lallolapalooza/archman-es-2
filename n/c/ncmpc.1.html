NOMBRE

ncmpc - Documentación de ncmpc

DESCRIPCIÓN

Por defecto, ncmpc se conecta a la instancia local de MPD. Se puede seleccionar una instancia diferente de MPD utilizando las opciones de línea de comandos --host y --port, o estableciendo las variables de entorno MPD_HOST y MPD_PORT:

ncmpc --host=musicserver --port=44000

Puedes conectarte a un socket "local" estableciendo el host a una ruta de archivo (p. ej., "/run/mpd/socket"). Los sockets abstractos se pueden usar con un prefijo de "@" (p. ej., "@mpd").

Para usar una contraseña con MPD, establece MPD_HOST a password@host o usa la opción de línea de comandos --password. Los valores de la línea de comandos anulan los valores del entorno.

SINOPSIS

ncmpc [opciones]

OPCIONES

-?, --ayuda
Mostrar ayuda.
-V, --version
Mostrar información de la versión y configuración en tiempo de compilación.
-c, --colores
Habilitar colores.
-C, --sin-colores
Deshabilitar colores.
-m, --raton
Habilitar ratón.
--host=HOST
El host de MPD al que conectarse.
--port=PORT, -p PORT
El puerto al que conectarse.
-P, --contrasena=CONTRASENA
Usar contraseña al conectarse.
-f, --configuracion=ARCHIVO
Leer configuración desde el archivo.
-k, --archivo-teclas=ARCHIVO
Leer asignaciones de teclas desde el archivo.

CONFIGURACIÓN

Cuando ncmpc se inicia, intenta leer el archivo de configuración del usuario, $XDG_CONFIG_HOME/ncmpc/config (normalmente ~/.config/ncmpc/config). Si no se encuentra ningún archivo de configuración de usuario, ncmpc intenta cargar la configuración global desde $SYSCONFDIR/ncmpc/config (la ruta real se muestra en la salida de la opción --version). Un archivo de configuración de ejemplo ( config.sample) se incluye con ncmpc.

Conexión

host = HOST - El host de MPD al que conectarse.

port = PORT - El puerto al que conectarse.

password = PASSWORD - Usar contraseña al conectarse.

timeout = TIMEOUT - Intentar reconectar a mpd si no se recibe una respuesta a un comando dentro de TIMEOUT segundos. Especificar un valor en el archivo de configuración anula la variable de entorno "MPD_TIMEOUT". Si no se especifica ningún timeout en el archivo de configuración o en el entorno, el valor predeterminado es 5 segundos.

Interfaz

show-title-bar = yes|no - "no" permite ocultar la barra de título.

show-server-address = yes|no - "yes" muestra la dirección del servidor en la barra de título. Esto está deshabilitado por defecto porque la mayoría de la gente usa solo una instancia de MPD.

enable-mouse = yes|no - Habilitar soporte para ratón (si está habilitado en tiempo de compilación).

screen-list = PANTALLA1 PANTALLA2... - Una lista de pantallas para ciclar al usar los comandos screen-next (vinculado a "Tab" por defecto) y screen-prev ("Shift+Tab"). Las opciones válidas, si están habilitadas en tiempo de compilación, son:

help, playlist, browse, library, search, lyrics, outputs, chat, song, keydef

El valor por defecto es playlist browser, es decir, la tecla "Tab" solo cicla entre esas dos páginas.

library-page-tags = TAG1 TAG2 ... - Una lista de etiquetas para agrupar la página de la biblioteca. El valor por defecto es artist album.

search-mode = MODO - Modo de búsqueda por defecto para la pantalla de búsqueda. MODO debe ser uno de title, artist, album, filename, y artist+title, o un índice entero (0 para title, 1 para artist, etc.).

auto-center = yes|no - Habilitar/deshabilitar el modo de centrado automático. Cuando el modo de centrado automático está habilitado, ncmpc centra la pista actual en la ventana de la lista de reproducción.

scroll-offset = NUM - Mantener al menos NUM líneas por encima y por debajo del cursor en las ventanas de lista, si es posible.

find-show-last = yes|no - Mostrar la consulta más reciente en lugar de una línea en blanco para una búsqueda.

find-wrap = yes|no - Modo de búsqueda con envoltura.

wrap-around = yes|no - Movimiento del cursor con envoltura.

bell-on-wrap = yes|no - Hacer sonar el timbre cuando la búsqueda envuelve.

audible-bell = yes|no - Sonar el timbre audible en alertas.

visible-bell = yes|no - Timbre visible en alertas.

crossfade-time = TIEMPO_DE_CROSSFADE - Tiempo de crossfade predeterminado en segundos.

seek-time = NUM - Avanzar/retroceder NUM segundos.

lyrics-timeout = NUM - Deja de descargar letras de una canción después de que se alcance el tiempo de espera de NUM segundos, si NUM es mayor que cero.

jump-prefix-only = yes|no - Al usar el comando de salto, buscar por el prefijo de una entrada. Esto significa que escribir "m" comenzará en la primera entrada que empiece por "m".

lyrics-autosave = yes|no - Guardar automáticamente las letras después de recibirlas.

lyrics-show-plugin = yes|no - Mostrar el nombre del plugin utilizado para recibir las letras en la pantalla de letras.

text-editor = EDITOR - El editor de texto utilizado para editar letras.

chat-prefix = PREFIJO - Prefija los mensajes enviados con la pantalla de chat con PREFIJO. Por defecto, se prefijan con el nombre de usuario actual encerrado entre < y > y un espacio (es decir, "<nombre> ").

second-column = yes|no - Mostrar la duración de la canción en una segunda columna.

Pantalla

welcome-screen-list = yes|no - Mostrar una lista de las pantallas en la línea superior.

wide-cursor = yes|no - Hacer que el cursor ocupe todo el ancho de la pantalla.

hardware-cursor = yes|no - Usar el cursor de hardware de la terminal en lugar de colores invertidos.

hide-cursor = NUM - Ocultar el cursor de la lista de reproducción después de NUM segundos de inactividad.

scroll = yes|no - Desplazar el título si es demasiado largo para la pantalla.

scroll-sep = CADENA - El separador que se mostrará al final del título desplazado.

list-format = FORMATO_DE_CANCION - El formato utilizado para mostrar canciones en la ventana principal.

search-format = FORMATO_DE_CANCION - El formato utilizado para mostrar canciones en la ventana de búsqueda. Por defecto se utiliza list-format.

status-format = FORMATO_DE_CANCION - El formato utilizado para mostrar canciones en la línea de estado.

status-message-time = TIEMPO - El tiempo, en segundos, durante el cual se mostrarán los mensajes de estado.

display-time = yes|no - Mostrar la hora en la barra de estado cuando está inactivo.

timedisplay-type = elapsed|remaining|none - Establece si se debe mostrar el tiempo restante o transcurrido en la ventana de estado. El valor predeterminado es elapsed. none no muestra la hora en absoluto.

visible-bitrate = yes|no - Mostrar la tasa de bits en la barra de estado al reproducir una transmisión.

set-xterm-title = yes|no - Cambiar el título de XTerm (ncmpc no restaurará el título).

xterm-title-format = FORMATO DE CANCIÓN - El formato utilizado para el título de xterm cuando ncmpc está reproduciendo.

Colores

enable-colors = sí|no - Habilitar/deshabilitar colores. Por defecto es sí.

black, red, green, yellow, blue, magenta, cyan, white

Ejemplo:

color list = cyan

Los terminales modernos soportan hasta 256 colores, pero no están estandarizados. Puedes seleccionarlos especificando el número. Ejemplo:

color title = 42

El color de fondo se puede especificar después del color de texto separado por una barra. Puedes omitir el color de texto si solo quieres cambiar el color de fondo:

color title = white/blue
color title = /blue

El color none usa el color por defecto del terminal.

standout, underline, reverse, blink, dim, bold

Ejemplo:

color alert = red blink

color background = COLOR - Establece el color de fondo por defecto.

color title = COLOR[,ATTRIBUTE]... - Establece el color de texto y atributos para la fila de título, que muestra los nombres de las páginas.

color title-bold = COLOR[,ATTRIBUTE]... - Similar a title, pero se refiere a partes enfatizadas de la fila de título, es decir, las teclas de acceso rápido para cambiar a una página específica.

color line = COLOR - Establece el color de la línea en la segunda fila.

color line-flags = COLOR[,ATTRIBUTE]... - Establece el color de texto utilizado para indicar las banderas de mpd en la segunda fila.

color list = COLOR[,ATTRIBUTE]... - Establece el color de texto en el área principal de ncmpc.

color list-bold = COLOR[,ATTRIBUTE]... - Establece el color de texto en negrita en el área principal de ncmpc.

color browser-directory = COLOR[,ATTRIBUTE]... - Establece el color de texto utilizado para mostrar directorios en la ventana del navegador.

color browser-playlist = COLOR[,ATTRIBUTE]... - Establece el color de texto utilizado para mostrar listas de reproducción en la ventana del navegador.

color progressbar = COLOR[,ATTRIBUTE]... - Establece el color del indicador de progreso.

color progressbar-background = COLOR[,ATTRIBUTE]... - Establece el color del fondo del indicador de progreso.

color status-state = COLOR[,ATTRIBUTE]... - Establece el color de texto utilizado para mostrar el estado de mpd en la ventana de estado.

color status-song = COLOR[,ATTRIBUTE]... - Establece el color de texto utilizado para mostrar los nombres de las canciones en la ventana de estado.

color status-time = COLOR[,ATTRIBUTE]... - Establece el color de texto utilizado para mostrar la hora en la ventana de estado.

color alert = COLOR[,ATTRIBUTE]... - Establece el color de texto utilizado para mostrar alertas en la ventana de estado.

color input = COLOR[,ATTRIBUTE]... - Establece el color de texto de los controles de entrada de texto.

colordef COLOR = R, G, B - Redefine cualquiera de los colores base. Los valores RGB deben ser valores enteros entre 0 y 1000. Nota: ¡Solo algunos terminales permiten redefinir colores!

TECLAS

Cuando ncmpc se inicia, intenta leer las asignaciones de teclas definidas por el usuario del archivo $XDG_CONFIG_HOME/ncmpc/keys (generalmente ~/.config/ncmpc/keys). Si no se encuentran asignaciones de teclas definidas por el usuario, ncmpc intenta cargar las asignaciones de teclas globales desde $SYSCONFDIR/ncmpc/keys (la ruta real se muestra en la pantalla de ayuda).

Puedes ver las asignaciones de teclas de ncmpc presionando '1' (ayuda) cuando ncmpc está en ejecución. Para editar las asignaciones de teclas, presiona 'K' y usa el editor de teclas en ncmpc.

FORMATO DE CANCIÓN

Formato de visualización de canciones para el estado y la ventana de lista. Los delimitadores de metadatos son: %artist%, %albumartist%, %composer%, %performer%, %title%, %album%, %shortalbum%, %track%, %disc%, %genre%, %name%, %time%, %date%, %file%, %shortfile%.

Los operadores [] se utilizan para agrupar la salida de manera que si ninguno de los delimitadores de metadatos entre [ y ] coincide, entonces ninguno de los caracteres entre [ y ] se muestra; el texto literal siempre se muestra. & y | son operadores lógicos para y y o. # se utiliza para escapar caracteres.

Algunos ejemplos útiles para el formato son:

"%file%"

y:

"[[%artist% - ]%title%]|%file%"

Otro es:

"[%artist%|(artista n/a)] - [%title%|(título n/a)]"

TABLAS

Como característica experimental, la cola se puede mostrar como una tabla. Tenga en cuenta que esta característica es realmente experimental, y las versiones futuras pueden realizar cambios incompatibles.

Para configurar esto, agregue columnas al archivo de configuración, por ejemplo:

song-table-column = "Artista" "%artist%|%name%|%file%" min=20 fraction=2
song-table-column = "Título" "%title%" min=20 fraction=2
song-table-column = "Álbum" "%album%" min=10 fraction=1
song-table-column = "Tiempo" "%time%" min=8 fraction=0

Cada columna tiene una etiqueta, una cadena de formato que especifica qué se muestra, un ancho mínimo (en celdas de terminal) y una fracción que especifica cuánta parte del ancho excesivo se asignará a esta columna.

En el ejemplo anterior, la columna "Tiempo" tendrá un ancho fijo de 8 porque fraction=0.

PROTOCOLO CHAT

Si ncmpc ha sido compilado con soporte de "chat", utiliza el protocolo cliente a cliente disponible en MPD 0.17 o superior para comunicarse con otros clientes. Para recibir mensajes, se suscribe al canal con el nombre "chat" y muestra cualquier mensaje enviado allí tal cual. Cuando el usuario ingresa un mensaje, se antepone primero con el prefijo especificado por la opción chat-prefix (o el prefijo por defecto), y luego se envía al canal "chat" para que otros lo lean.

ERRORES

Nota ---

Dado que MPD usa UTF-8, ncmpc necesita convertir caracteres al juego de caracteres utilizado por el sistema local. Si obtiene errores de conversión de caracteres al ejecutar ncmpc, probablemente necesite configurar su local. Esto se hace configurando cualquiera de las variables de entorno LC_CTYPE, LANG o LC_ALL (LC_CTYPE solo afecta el manejo de caracteres).
