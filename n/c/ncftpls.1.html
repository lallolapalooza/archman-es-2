ncftpls(1) Manual de comandos generales ncftpls(1)

NOMBRE

ncftpls - programa de transferencia de archivos de Internet para scripts

SINOPSIS

ncftpls [opciones] ftp://url.style/host/path/name/

OPCIONES

Indicadores de línea de comandos:

-m
Usar un formato de lista legible por máquina, si el servidor lo admite. Esto requiere que el software del servidor admita las extensiones MLSD, y muchas implementaciones no tienen estas características.
-1
Formato más básico, un elemento por línea.
-l
Formato de lista larga.
-C
Formato de lista en columnas. Este es el formato de lista predeterminado.
-R
Recorrer recursivamente todos los subdirectorios al listar.
-a
Mostrar todos los archivos, si el servidor lo permite (como en "/bin/ls -a").
-i XX
Filtrar la lista (si el servidor lo admite) con el comodín XX.
-x -XX
Establecer los indicadores de ls a usar en el servidor.
-u XX
Usar el nombre de usuario XX en lugar de anónimo.
-p XX
Usar la contraseña XX con el nombre de usuario.
-P XX
Usar el número de puerto XX en lugar del puerto de servicio FTP predeterminado (21).
-d XX
Usar el archivo XX para el registro de depuración.
-t XX
Tiempo de espera después de XX segundos.
-E
Usar conexiones de datos regulares (PORT).
-F
Usar conexiones de datos pasivas (PASV). El valor predeterminado es usar pasivo, pero volver al modo regular si la conexión pasiva falla o expira.
-r XX
Volver a marcar un máximo de XX veces hasta conectarse al servidor FTP remoto.
-W XX
Enviar el comando FTP crudo XX después de iniciar sesión.
-X XX
Enviar el comando FTP crudo XX después de cada archivo transferido.
-Y XX
Enviar el comando FTP crudo XX antes de cerrar sesión.
Las opciones -W, -X y -Y son útiles para usuarios avanzados que necesitan ajustar el comportamiento en algunos servidores. Por ejemplo, los usuarios que acceden a mainframes pueden necesitar enviar algunos comandos SITE especiales para establecer la información del tamaño del bloque y el formato del registro.
Para estas opciones, puede usarlas varias veces cada una si necesita enviar varios comandos. Para la opción -X, puede usar la cookie %s para expandir el nombre del archivo que se transfirió.
-o XX
Establecer la opción avanzada XX.
Esta opción se usa principalmente para depuración. Establece el valor de una variable interna a un valor entero. Un ejemplo de uso sería: -o useFEAT=0,useCLNT=1 que, en este caso, deshabilita el uso del comando FEAT y habilita el comando CLNT. Las variables disponibles incluyen: usePASV, useSIZE, useMDTM, useREST, useNLST_a, useNLST_d, useFEAT, useMLSD, useMLST, useCLNT, useHELP_SITE, useSITE_UTIME, STATfileParamWorks, NLSTfileParamWorks, require20, allowProxyForPORT, doNotGetStartCWD.

DESCRIPCIÓN

El propósito de ncftpls es realizar listados de directorios remotos utilizando el Protocolo de Transferencia de Archivos sin entrar en una shell interactiva. Esto permite escribir scripts de shell u otros procesos desatendidos que puedan hacer FTP.

El comportamiento predeterminado es imprimir la lista del directorio en formato de columnas (es decir, ls -CF), pero eso no es muy útil para scripts. Este ejemplo utiliza el indicador -1, para imprimir un archivo por línea:

$ ncftpls -1 ftp://ftp.ncftp.com/pub/ncftp/

También puede hacer un "ls -l" remoto, usando "ncftpls -l". Si desea probar otros indicadores, debe usarlos con el indicador -x. Por ejemplo, si quisiera hacer un "ls -lrt" remoto, podría hacer esto:

$ ncftpls -x "-lrt" ftp://ftp.ncftp.com/pub/ncftp/

Por defecto, el programa intenta abrir el host remoto e iniciar sesión anónimamente, pero puede especificar información de nombre de usuario y contraseña como con ncftpget o ncftpput.

Tenga en cuenta que el estándar especifica que los nombres de ruta de URL son nombres de ruta relativos. Para FTP, esto significa que las URLs especifican nombres de ruta relativos desde el directorio de inicio, que para los inicios de sesión de usuario, suelen ser el directorio de inicio del usuario. Si desea usar nombres de ruta absolutos, necesita incluir una barra inclinada literal, usando el código "%2F" para un carácter "/". Ejemplos:

$ ncftpls -u linus ftp://ftp.kernel.org/%2Fusr/src/
$ ncftpls ftp://steve@ftp.apple.com/%2Fetc/

DIAGNÓSTICOS

ncftpls devuelve los siguientes valores de salida:

0
Éxito.
1
No se pudo conectar con el host remoto.
2
No se pudo conectar con el host remoto - tiempo de espera agotado.
3
Fallo en la transferencia.
4
Fallo en la transferencia - tiempo de espera agotado.
5
Fallo al cambiar de directorio.
6
Fallo al cambiar de directorio - tiempo de espera agotado.
7
URL mal formada.
8
Error de uso.
9
Error en el archivo de configuración de inicio de sesión.
10
Fallo en la inicialización de la biblioteca.
11
Fallo en la inicialización de la sesión.
