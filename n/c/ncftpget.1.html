ncftpget(1) Manual de comandos generales ncftpget(1)

NOMBRE

ncftpget - programa de transferencia de archivos de Internet para scripts

SINOPSIS

ncftpget [opciones] host-remoto directorio-local archivos-remotos...

ncftpget [opciones] nombre-marcador directorio-local archivos-remotos...

ncftpget -f login.cfg [opciones] directorio-local archivos-remotos...

ncftpget [opciones] ftp://host.estilo.url/ruta/nombre

ncftpget -c [opciones] host-remoto archivo-remoto > stdout

ncftpget -C [opciones] host-remoto archivo-remoto nombre-ruta-local

ncftpget -c [opciones] ftp://host.estilo.url/ruta/nombre > stdout

OPCIONES

Indicadores de línea de comandos:

-u XX
Usa el nombre de usuario XX en lugar de anónimo.
-p XX
Usa la contraseña XX con el nombre de usuario.
-P XX
Usa el número de puerto XX en lugar del puerto de servicio FTP predeterminado (21).
-j XX
Usa la cuenta XX como suplemento al nombre de usuario y contraseña (obsoleto).
-d XX
Usa el archivo XX para el registro de depuración.
-a
Usa el tipo de transferencia ASCII en lugar de binario.
-t XX
Tiempo de espera después de XX segundos.
-v/-V
Muestra (no muestra) medidores de progreso. El valor predeterminado es mostrar medidores de progreso si el flujo de salida es una TTY.
-f XX
Lee el archivo XX para obtener información del host, usuario y contraseña.
-c
Lee del host remoto y escribe localmente a la salida estándar.
-C
Lee del host remoto y escribe localmente a la ruta especificada.
-A
Añade a los archivos locales, en lugar de sobrescribirlos.
-z/-Z
Intenta (no intenta) reanudar transferencias. El valor predeterminado es intentar reanudar (-z).
-E
Usa conexiones de datos regulares (PORT).
-F
Usa conexiones de datos pasivas (PASV). El valor predeterminado es usar pasivas, pero volver a regulares si la conexión pasiva falla o caduca.
-DD
Elimina el archivo remoto después de descargarlo exitosamente.
-R
Modo recursivo; copia árboles de directorios completos.
-T
No uses el modo TAR automático sobre la marcha para descargar árboles de directorios completos. ncftpget usa TAR siempre que sea posible, ya que esto generalmente preserva los enlaces simbólicos y los permisos de archivo. El modo TAR también puede resultar en transferencias más rápidas para directorios que contienen muchos archivos pequeños, ya que se puede usar una única conexión de datos en lugar de una conexión de datos FTP para cada archivo pequeño. La desventaja de usar TAR es que fuerza la descarga de todo el directorio, incluso si ya habías descargado una porción anteriormente, por lo que es posible que desees usar esta opción si quieres reanudar la descarga de un directorio.
-r XX
Vuelve a marcar un máximo de XX veces hasta conectarse al servidor FTP remoto.
-b
Ejecuta en segundo plano (enviando un trabajo por lotes y luego generando ncftpbatch).
-bb
Similar a la opción -b, pero solo envía el trabajo por lotes. Necesitarás ejecutar ncftpbatch para que el trabajo por lotes sea procesado. Esto es útil si ya tienes un proceso ncftpbatch en ejecución, o deseas tener un mejor control de cuándo se procesan los trabajos por lotes.
Por ejemplo, si quisieras procesar tres archivos en segundo plano todos en el mismo servidor remoto, es más cortés usar un solo proceso ncftpbatch para procesar los tres trabajos secuencialmente, en lugar de tener tres procesos ncftpbatch abriendo tres sesiones FTP simultáneas al mismo servidor.
-B XX
Intenta establecer el tamaño del búfer del socket TCP/IP a XX bytes.
-W XX
Envía el comando FTP crudo XX después de iniciar sesión.
-X XX
Envía el comando FTP crudo XX después de cada archivo transferido.
-Y XX
Envía el comando FTP crudo XX antes de cerrar sesión.
Las opciones -W, -X y -Y son útiles para usuarios avanzados que necesitan ajustar el comportamiento en algunos servidores. Por ejemplo, los usuarios que acceden a mainframes pueden necesitar enviar comandos SITE especiales para establecer información de tamaño de bloque y formato de registro.
Para estas opciones, puedes usarlas varias veces cada una si necesitas enviar varios comandos. Para la opción -X, puedes usar la cookie %s para expandirla al nombre del archivo que fue transferido.
-o XX
Establece la opción avanzada XX.
Esta opción se usa principalmente para depuración. Establece el valor de una variable interna a un valor entero. Un uso de ejemplo sería: -o useFEAT=0,useCLNT=1 que en este caso, deshabilita el uso del comando FEAT y habilita el comando CLNT. Las variables disponibles incluyen: usePASV, useSIZE, useMDTM, useREST, useNLST_a, useNLST_d, useFEAT, useMLSD, useMLST, useCLNT, useHELP_SITE, useSITE_UTIME, STATfileParamWorks, NLSTfileParamWorks, require20, allowProxyForPORT, doNotGetStartCWD.

DESCRIPCIÓN

El propósito de ncftpget es realizar transferencias de archivos desde la línea de comandos sin entrar en un shell interactivo. Esto te permite escribir scripts de shell u otros procesos desatendidos que puedan realizar FTP. También es útil para usuarios avanzados que desean recuperar archivos desde la línea de comandos sin entrar en un programa FTP interactivo como ncftp.

Una característica particularmente útil de este programa es que puedes darle un localizador uniforme de recursos como único argumento y el programa descargará ese archivo. Luego puedes copiar y pegar desde tu navegador web o lector de noticias y usar esa URL. Ejemplo:

$ cd /tmp
$ ncftpget ftp://ftp.ncftp.com/pub/ncftp/ncftp.tar.Z
$ zcat ncftp.tar.Z | tar xf -

Por defecto, el programa intenta abrir el host remoto e iniciar sesión anónimamente, pero puedes especificar un nombre de usuario y contraseña. La opción -u se usa para especificar el nombre de usuario con el que iniciar sesión, y la opción -p se usa para especificar la contraseña. Si estás ejecutando el programa desde el shell, puedes omitir la opción -p y el programa te pedirá la contraseña.

No se recomienda el uso de las opciones -u y -p, porque tu información de cuenta queda expuesta a cualquiera que pueda ver tu script de shell o la información de tu proceso. Por ejemplo, alguien usando el programa ps podría ver tu contraseña mientras el programa se ejecuta.

Puedes usar la opción -f en su lugar para especificar un archivo con la información de la cuenta. Sin embargo, esto todavía no es seguro porque cualquiera que tenga acceso de lectura al archivo de información puede ver la información de la cuenta. Sin embargo, si decides usar la opción -f, el archivo debería verse algo así:

host sphygmomanometer.ncftp.com
user gleason
pass mypasswd

No olvides cambiar los permisos de este archivo para que nadie más pueda leerlos.

Por ejemplo, si está recuperando un archivo .TXT de un host basado en Windows a un sistema UNIX, podría usar la bandera -a que usaría el modo de transferencia ASCII para que el archivo creado en el sistema UNIX estuviera en el formato de texto UNIX en lugar del formato de texto MS-DOS.

Puede recuperar un árbol de directorios completo de archivos usando la bandera -R. Sin embargo, esto solo funcionará si el servidor FTP remoto es un servidor UNIX o emula la salida de lista de UNIX. Ejemplo:

$ ncftpget -R ftp.ncftp.com /tmp /pub/ncftp

Esto crearía una jerarquía /tmp/ncftp.

DIAGNÓSTICOS

ncftpget devuelve los siguientes valores de salida:

0
Éxito.
1
No se pudo conectar al host remoto.
2
No se pudo conectar al host remoto - tiempo de espera agotado.
3
La transferencia falló.
4
La transferencia falló - tiempo de espera agotado.
5
El cambio de directorio falló.
6
El cambio de directorio falló - tiempo de espera agotado.
7
URL mal formada.
8
Error de uso.
9
Error en el archivo de configuración de inicio de sesión.
10
El inicialización de la biblioteca falló.
11
La inicialización de la sesión falló.
