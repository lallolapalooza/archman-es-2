ncmpcpp(1) Manual de Comandos Generales ncmpcpp(1)

NOMBRE

ncmpcpp - Un cliente ncurses para Music Player Daemon (MPD).

SINOPSIS

ncmpcpp [opciones]

DESCRIPCIÓN

ncmpcpp es un cliente ncurses para MPD (Music Player Daemon), inspirado en ncmpc.

Lee más sobre MPD en http://www.musicpd.org

OPCIONES

Los argumentos obligatorios para las opciones largas también son obligatorios para las opciones cortas.

-h, --host=HOST
Conectarse al servidor en el host [localhost]
-p, --port=PUERTO
Conectarse al servidor en el puerto [6600]
--current-song[=FORMATO]
Imprimir la canción actual usando el formato dado y salir
-c, --config=ARCHIVO
Especificar archivo(s) de configuración
--ignore-config-errors
Ignorar opciones desconocidas e inválidas en los archivos de configuración
-b, --bindings=ARCHIVO
Especificar archivo(s) de atajos de teclado
-s, --screen <nombre>
Especificar la pantalla de inicio (<nombre> puede ser: ayuda, lista de reproducción, explorador, motor de búsqueda, biblioteca de música, editor de listas de reproducción, editor de etiquetas, salidas, visualizador, reloj)
-S, --slave-screen <nombre>
Especificar la pantalla esclava de inicio (<nombre> puede ser: ayuda, lista de reproducción, explorador, motor de búsqueda, biblioteca de música, editor de listas de reproducción, editor de etiquetas, salidas, visualizador, reloj)
-q, --quiet
Suprimir registros y salida excesiva
-?, --help
Mostrar ayuda.
-v, --version
Mostrar información de la versión.

CONFIGURACIÓN

Cuando ncmpcpp se inicia, intenta leer la configuración de los archivos $XDG_CONFIG_HOME/ncmpcpp/config y $HOME/.ncmpcpp/config. Si no se encuentra ninguna configuración, ncmpcpp usa su configuración predeterminada. Un archivo de configuración de ejemplo que contiene todos los valores predeterminados se proporciona con ncmpcpp y generalmente se puede encontrar en /usr/share/doc/ncmpcpp (la ubicación exacta puede depender de su sistema operativo o del prefijo de configuración).

Nota: Los valores de las opciones de configuración pueden estar entre comillas o no.
- Si están entre comillas, las comillas más a la izquierda y más a la derecha se tratan como delimitadores, por lo tanto, no es necesario escapar las comillas que use dentro del propio valor.
- Si no lo están, los caracteres de espacio en blanco entre = y el primer carácter imprimible del valor, así como los caracteres de espacio en blanco después del último carácter imprimible del valor, se eliminan.

Por lo tanto, la regla general es: si necesita espacios en blanco al principio o al final del valor, rodéelo con comillas. De lo contrario, no lo haga.

Nota: COLOR debe ser el nombre (no un número) de uno de los colores 1-8 de la sección FORMATO DE CANCIÓN.

Opciones de configuración admitidas:

ncmpcpp_directory = RUTA
Directorio para almacenar archivos relacionados con ncmpcpp. Cambiarlo es útil si desea almacenar todo en otro lugar y proporcionar una configuración de línea de comandos para una ubicación alternativa del archivo de configuración que la define al iniciar ncmpcpp.
lyrics_directory = RUTA
Directorio para almacenar letras descargadas. Por defecto es ~/.lyrics ya que otros clientes MPD (por ejemplo, ncmpc) también usan esa ubicación.
mpd_host = HOST
Conectarse a MPD que se ejecuta en el host/socket unix especificado. Cuando HOST comienza con '/', se asume que es un socket unix. Nota: la variable de entorno MPD_HOST anula esta configuración.
mpd_port = PUERTO
Conectarse a MPD en el puerto especificado. Nota: la variable de entorno MPD_PORT anula esta configuración.
mpd_password = CONTRASEÑA
Usar CONTRASEÑA para autenticarse a MPD.
mpd_music_dir = RUTA
Buscar archivos en el directorio especificado. Esto es necesario para que el editor de etiquetas funcione.

Establecer el tiempo de espera de conexión a MPD al valor dado.
mpd_crossfade_time = SEGUNDOS
Número predeterminado de segundos para el crossfade, si lo habilita ncmpcpp.
visualizer_data_source = UBICACIÓN
Fuente de datos para el visualizador. Para MPD será una salida fifo, para Mopidy una salida udpsink (ver el archivo de configuración de ejemplo para más detalles).
visualizer_output_name = NOMBRE
Nombre de la salida que proporciona datos para el visualizador. Necesario para mantener el sonido y la visualización sincronizados.
visualizer_in_stereo = sí/no
Debe establecerse en 'sí' si el formato de salida fifo se estableció en 44100:16:2.

Define el tipo de visualizador predeterminado (el espectro solo está disponible si ncmpcpp se compiló con soporte fftw).
visualizer_look = CADENA
Define el aspecto del visualizador (la cadena debe tener exactamente 2 caracteres de longitud: el primero es para la onda y el segundo para el espectro de frecuencia).

Utilice caracteres de bloque unicode de "símbolos para la computación heredada". Esto mejora el aspecto suave en terminales transparentes utilizando caracteres unicode especiales en lugar de invertir el color de fondo y primer plano en el borde inferior del espectro. Si esto provoca una salida ilegible en el borde inferior del espectro, puede cambiar la fuente o desactivar esta opción.

Para el visualizador de espectro, un valor entre 1 y 5 inclusive. Especificar un valor más grande hace que el visualizador mire una porción de tiempo más grande, lo que resulta en una salida de visualizador menos brusca.
visualizer_spectrum_gain = dB
Ganancia para el visualizador de espectro en dB, valores más grandes/pequeños mueven las barras hacia arriba/abajo.
visualizer_spectrum_hz_min = Hz
Para el visualizador de espectro, la frecuencia más a la izquierda del visualizador, debe ser menor que HZ MAX.

BINDINGS

Cuando ncmpcpp se inicia, intenta leer los atajos de teclado de los archivos $XDG_CONFIG_HOME/ncmpcpp/bindings y ~/.ncmpcpp/bindings. Si no encuentra ningún archivo de atajos, ncmpcpp utiliza los predeterminados. Un archivo de atajos de ejemplo con valores predeterminados se encuentra normalmente en /usr/share/doc/ncmpcpp (la ubicación exacta puede depender de su sistema operativo o del prefijo de configuración).

Puede ver los atajos de teclado actuales presionando F1.

FORMATO DE CANCIÓN

Para el formato de canción puede usar:


%l - duración
%f - nombre del archivo
%F - ruta completa del archivo
%D - directorio
%a - artista
%A - artista del álbum
%t - título
%b - álbum
%y - fecha
%n - número de pista (01/12 -> 01)
%N - información completa de la pista (01/12 -> 01/12)
%g - género
%c - compositor
%p - intérprete
%d - disco
%C - comentario
%P - prioridad
$R - alinear a la derecha

También puede ponerlos entre llaves {} y entonces solo se mostrarán si todos los valores solicitados están disponibles y/o definir un valor alternativo con {}|{}, por ejemplo, {%a - %t}|{%f} comprobará si las etiquetas de artista y título están disponibles y si lo están, las mostrará. De lo contrario, mostrará el nombre del archivo.

Nota: Si desea establecer un límite en la longitud máxima de una etiqueta, simplemente coloque el número apropiado entre el % y el carácter que define el tipo de etiqueta, por ejemplo, para que el álbum ocupe un máximo de 20 celdas de terminal, use %20b.

Nota: Un formato similar a "%a - %t" (es decir, sin llaves adicionales) es igual a "{%a - %t}", por lo que si falta una de las etiquetas, no obtendrá nada.

El texto puede tener un color diferente al de la ventana principal, por ejemplo, si desea que la duración sea verde, escriba $3%l$9.

Valores disponibles para los colores:


- 0 - color de ventana predeterminado (descarta todos los demás colores)
- 1 - negro
- 2 - rojo
- 3 - verde
- 4 - amarillo
- 5 - azul
- 6 - magenta
- 7 - cian
- 8 - blanco
- 9 - fin del color actual

Nota: los colores se pueden anidar, por lo que si escribe $2alguno$5texto$9, solo deshabilitará el uso del color azul y hará que el rojo sea el actual.

NOTA

Dado que MPD utiliza UTF-8, ncmpcpp necesita convertir los caracteres al conjunto de caracteres utilizado por el sistema local. Si obtiene errores de conversión de caracteres mientras ejecuta ncmpcpp, probablemente necesite configurar su locale. Esto se hace configurando las variables de entorno LANG y LC_ALL/LC_CTYPE (LC_CTYPE solo afecta el manejo de caracteres).
