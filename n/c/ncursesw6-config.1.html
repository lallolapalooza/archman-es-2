ncursesw6-config(1) Comandos de usuario ncursesw6-config(1)

NOMBRE

ncursesw6-config - utilidad de configuración para las bibliotecas ncurses

SINOPSIS

ncursesw6-config opción ...

ncursesw6-config --version

ncursesw6-config --help

DESCRIPCIÓN

Este programa de ayuda al desarrollo simplifica el proceso de configuración de aplicaciones contra un conjunto particular de bibliotecas ncurses.

OPCIONES

--prefix
informa el prefijo del paquete de ncurses.
--exec-prefix
informa el prefijo ejecutable de ncurses.
--cflags
informa las opciones del compilador C necesarias para compilar con ncurses.
--libs
informa las bibliotecas necesarias para enlazar con ncurses.
--abi-version
informa la versión ABI de ncurses.
--mouse-version
informa la versión de la interfaz de ratón de ncurses.
--bindir
informa el directorio que contiene los programas de ncurses.
--datadir
informa el directorio que contiene los datos de ncurses.
--includedir
informa el directorio que contiene los archivos de cabecera de ncurses.
--libdir
informa el directorio que contiene las bibliotecas de ncurses.
--mandir
informa el directorio que contiene las páginas man de ncurses.
--terminfo
informa la ruta de la base de datos TERMINFO terminfo, por ejemplo /usr/share/terminfo.
--terminfo-dirs
informa la ruta de búsqueda suplementaria de TERMINFO_DIRS para la base de datos terminfo, por ejemplo /usr/share/terminfo.
--termpath
informa la ruta de búsqueda suplementaria de TERMPATH para la base de datos termcap, si el soporte para termcap está configurado.

Las siguientes opciones harán que se ignoren todas las demás.

--help
muestra un mensaje de uso y sale con éxito.
--version
muestra la información de lanzamiento y fecha de parche de ncurses y sale con éxito.
