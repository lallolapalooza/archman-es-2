ncftpput(1) Manual de comandos generales ncftpput(1)

NOMBRE

ncftpput - programa de transferencia de archivos de Internet para scripts

SINOPSIS

ncftpput [opciones] host-remoto directorio-remoto archivos-locales...

ncftpput [opciones] nombre-marcador directorio-remoto archivos-locales...

ncftpput -f login.cfg [opciones] directorio-remoto archivos-locales...

ncftpput -c host-remoto nombre-ruta-remota < stdin

ncftpput -C host-remoto nombre-ruta-local nombre-ruta-remota

OPCIONES

Indicadores de línea de comandos:

-u XX
Utiliza el nombre de usuario XX en lugar de anónimo.
-p XX
Utiliza la contraseña XX con el nombre de usuario.
-P XX
Utiliza el número de puerto XX en lugar del puerto de servicio FTP predeterminado (21).
-j XX
Utiliza la cuenta XX además del nombre de usuario y la contraseña (obsoleto).
-d XX
Utiliza el archivo XX para el registro de depuración.
-a
Utiliza el tipo de transferencia ASCII en lugar de binario.
-m
Intenta crear el directorio de destino remoto antes de copiar.
-t XX
Tiempo de espera después de XX segundos.
-U XX
Utiliza el valor XX para la máscara umask.
-v/-V
Muestra (no muestra) medidores de progreso. El valor predeterminado es mostrar medidores de progreso si el flujo de salida es una TTY.
-f XX
Lee el archivo XX para obtener información del host, usuario y contraseña.
-c
Lee localmente desde la entrada estándar y escribe remotamente en la ruta especificada.
-C
Similar a -c, excepto que se especifica una ruta local.
-A
Anexa a los archivos remotos, en lugar de sobrescribirlos.
-T XX
Carga en archivos temporales con el prefijo XX.
-S XX
Carga en archivos temporales con el sufijo XX.
-R
Modo recursivo; copia árboles de directorios completos.
-r XX
Vuelve a marcar un máximo de XX veces hasta conectarse al servidor FTP remoto.
-z/-Z
Intenta (no intenta) reanudar transferencias. El valor predeterminado es *no* intentar reanudar (-Z).
-E
Utiliza conexiones de datos regulares (PORT).
-F
Utiliza conexiones de datos pasivas (PASV). El valor predeterminado es usar pasivo, pero volver a regular si la conexión pasiva falla o caduca.
-DD
Elimina el archivo local después de cargarlo con éxito.
-y
Intenta usar "SITE UTIME" para preservar las marcas de tiempo en el host remoto. No muchos servidores FTP remotos admiten esto, por lo que puede que no funcione.
-b
Se ejecuta en segundo plano (enviando un trabajo por lotes y luego generando ncftpbatch).
-bb
Similar a la opción -b, pero solo envía el trabajo por lotes. Deberá ejecutar ncftpbatch para que el trabajo por lotes se procese. Esto es útil si ya tiene un proceso ncftpbatch en ejecución, o desea tener un mejor control de cuándo se procesan los trabajos por lotes.
Por ejemplo, si quisiera procesar tres archivos en segundo plano, todos en el mismo servidor remoto, es más cortés usar un solo proceso ncftpbatch para procesar los tres trabajos secuencialmente, en lugar de tener tres procesos ncftpbatch abriendo tres sesiones FTP simultáneas al mismo servidor.
-B XX
Intenta establecer el tamaño del búfer del socket TCP/IP en XX bytes.
-W XX
Envía el comando FTP crudo XX después de iniciar sesión.
-X XX
Envía el comando FTP crudo XX después de transferir cada archivo.
-Y XX
Envía el comando FTP crudo XX antes de cerrar sesión.
Las opciones -W, -X y -Y son útiles para usuarios avanzados que necesitan ajustar el comportamiento en algunos servidores. Por ejemplo, los usuarios que acceden a mainframes podrían necesitar enviar comandos SITE especiales para establecer información de tamaño de bloque y formato de registro.
Para estas opciones, puede usarlas varias veces si necesita enviar múltiples comandos. Para la opción -X, puede usar la galleta %s para expandirla al nombre del archivo que se transfirió.
-o XX
Establece la opción avanzada XX.
Esta opción se usa principalmente para depuración. Establece el valor de una variable interna a un valor entero. Un ejemplo de uso sería: -o useFEAT=0,useCLNT=1 lo que en este caso, deshabilita el uso del comando FEAT y habilita el comando CLNT. Las variables disponibles incluyen: usePASV, useSIZE, useMDTM, useREST, useNLST_a, useNLST_d, useFEAT, useMLSD, useMLST, useCLNT, useHELP_SITE, useSITE_UTIME, STATfileParamWorks, NLSTfileParamWorks, require20, allowProxyForPORT, doNotGetStartCWD.

DESCRIPCIÓN

El propósito de ncftpput es realizar transferencias de archivos desde la línea de comandos sin entrar en un shell interactivo. Esto le permite escribir scripts de shell u otros procesos desatendidos que pueden hacer FTP. También es útil para usuarios avanzados que desean enviar archivos desde la línea de comandos del shell sin entrar en un programa FTP interactivo como ncftp.

Por defecto, el programa intenta abrir el host remoto e iniciar sesión anónimamente, pero puede especificar un nombre de usuario y contraseña. La opción -u se usa para especificar el nombre de usuario con el que iniciar sesión, y la opción -p se usa para especificar la contraseña. Si está ejecutando el programa desde el shell, puede omitir la opción -p y el programa le pedirá la contraseña.

No se recomienda usar las opciones -u y -p, porque su información de cuenta está expuesta a cualquiera que pueda ver su script de shell o la información de su proceso. Por ejemplo, alguien que use el programa ps podría ver su contraseña mientras se ejecuta el programa.

Puede usar la opción -f en su lugar para especificar un archivo con la información de la cuenta. Sin embargo, esto todavía no es seguro porque cualquiera que tenga acceso de lectura al archivo de información puede ver la información de la cuenta. No obstante, si elige usar la opción -f, el archivo debería verse algo así:

host sphygmomanometer.ncftp.com
user gleason
pass mypassword

No olvide cambiar los permisos de este archivo para que nadie más pueda leerlos.

La opción -d es muy útil cuando intenta diagnosticar por qué falla una transferencia de archivos. Imprime toda la conversación FTP en el archivo que especifique, por lo que puede tener una idea de lo que salió mal. Si especifica el nombre especial stdout como nombre del archivo de salida de depuración, la salida se imprimirá en la pantalla.

Usar el modo ASCII es útil cuando el formato de texto de su host difiere del del host remoto. Por ejemplo, si está enviando un archivo de texto desde un sistema UNIX a un host basado en Windows, podría usar el indicador -a, que usaría el modo de transferencia ASCII para que el archivo creado en la máquina Windows esté en su formato de texto nativo en lugar del formato de texto UNIX.

$ ncftpput -R pikachu.nintendo.co.jp /incoming /tmp/stuff

Esto creará una jerarquía /incoming/stuff en el host remoto.

Las opciones -T y -S son útiles cuando desea cargar un archivo en el host remoto, pero no desea usar el nombre del archivo de destino hasta que el archivo esté completo. Al usar estas opciones, no destruirá un archivo remoto con el mismo nombre hasta que su archivo haya terminado. Estas opciones también son útiles cuando un proceso remoto en el host remoto escanea un nombre de archivo específico, y no desea que ese proceso vea ese archivo hasta que sepa que se ha terminado de enviar. Aquí hay un ejemplo que carga el archivo /pub/incoming/README, usando el nombre de archivo /pub/incoming/README.tmp como nombre de archivo temporal:

$ ncftpput -S .tmp bowser.nintendo.co.jp /pub/incoming /a/README

Una forma ingeniosa de canalizar la salida de cualquier comando local a un archivo remoto es usar la opción -c, que indica que está usando stdin como entrada. El siguiente ejemplo muestra cómo hacer una copia de seguridad y almacenarla en una máquina remota:

$ tar cf - / | ncftpput -c sonic.sega.co.jp /usr/local/backup.tar

DIAGNÓSTICOS

ncftpput devuelve los siguientes valores de salida:

0
Éxito.
1
No se pudo conectar al host remoto.
2
No se pudo conectar al host remoto - tiempo de espera agotado.
3
Transferencia fallida.
4
Transferencia fallida - tiempo de espera agotado.
5
Cambio de directorio fallido.
6
Cambio de directorio fallido - tiempo de espera agotado.
7
URL mal formada.
8
Error de uso.
9
Error en el archivo de configuración de inicio de sesión.
10
Error de inicialización de la biblioteca.
11
Error de inicialización de la sesión.
