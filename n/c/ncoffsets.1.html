ncoffsets(1) Utilidades de PnetCDF ncoffsets(1)

NOMBRE

ncoffsets - imprime los desplazamientos de archivo de inicio/fin para variables netCDF

SINOPSIS

ncoffsets [-h] | [-x] | [-sgr] [-v var1[,...]] archivo

DESCRIPCIÓN

ncoffsets imprime la información de los desplazamientos de archivo de las variables definidas en un archivo netCDF dado. Los desplazamientos finales reportados son desplazamientos exclusivos, es decir, 1 byte más que el último byte ocupado por la variable. En otras palabras, el desplazamiento final es igual a la suma del desplazamiento de inicio y el tamaño de la variable. Para las variables de registro, solo se imprimen los desplazamientos del primer registro. Agregue la opción -r para imprimir los desplazamientos de todos los registros.

Si no se proporciona ningún argumento, se imprime información sobre el uso del comando.

OPCIONES

-v var1[,...]
La salida solo mostrará la información de desplazamiento para las variables especificadas. Se deben proporcionar los nombres de una o más variables en la lista separada por comas que no debe contener espacios ni otros caracteres de espacio en blanco. Las variables nombradas deben ser variables netCDF válidas en el archivo de entrada. El valor predeterminado, es decir, sin esta opción, es mostrar la información de desplazamiento para *todas* las variables almacenadas en el archivo de entrada.
-s
Imprime el tamaño de la variable en bytes. Para las variables de registro, solo se imprime el tamaño de un registro.
-g
Imprime el espacio en bytes desde la variable anterior. Para la primera variable definida, imprime el espacio desde el final de la cabecera del archivo. Para las variables de registro, no hay espacio entre registros.
-r
Genera la información de desplazamiento para todos los registros de las variables de registro seleccionadas. Sin esta opción, solo se imprimen los desplazamientos del primer registro.
-x
Verifica todas las variables de tamaño fijo en busca de espacios vacíos en el archivo entre dos variables adyacentes cualesquiera. Imprime "1" en la salida estándar si se encuentran espacios, "0" en caso contrario. Esta opción deshabilita todas las demás opciones.
-h
Imprime las opciones de línea de comandos disponibles.

EJEMPLOS

Imprime la información de desplazamiento de archivo para todas las variables en un archivo netCDF.

% ncoffsets -sg testfile.nc

netcdf testfile.nc {
// Formato de archivo: CDF-1
// Número de dimensiones: 4
// Número de variables: 4
// Número de atributos globales: 0
cabecera del archivo:
    tamaño   = 256 bytes
    extensión = 512 bytes
dimensiones:
    time = ILIMITADO // (actualmente 101)
    Z = 100
    Y = 100
    X = 100
variables de tamaño fijo:
    float  square(Y, X):
           desplazamiento de archivo de inicio =         512
           desplazamiento de archivo de fin =       40512
           tamaño en bytes     =       40000
           espacio desde var anterior =         256
    double cube(Z, Y, X):
           desplazamiento de archivo de inicio =       40512
           desplazamiento de archivo de fin =     8040512
           tamaño en bytes     =     8000000
           espacio desde var anterior =           0
variables de registro:
    double time(time):
           desplazamiento de archivo de inicio =     8040512    (registro 0)
           desplazamiento de archivo de fin =     8040520    (registro 0)
           tamaño en bytes     =           8    (de un registro)
           espacio desde var anterior =           0
    float  rec_var(time, Z, Y, X):
           desplazamiento de archivo de inicio =     8040520    (registro 0)
           desplazamiento de archivo de fin =    12040520    (registro 0)
           tamaño en bytes     =     4000000    (de un registro)
           espacio desde var anterior =           0
}
Comprueba si hay espacios entre dos variables adyacentes de tamaño fijo.
% ncoffsets -x testfile.nc
0
