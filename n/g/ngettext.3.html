NOMBRE

ngettext, dngettext, dcngettext - traduce un mensaje y elige la forma plural

SINOPSIS

#include <libintl.h>

char * ngettext (const char * msgid, const char * msgid_plural,
                 unsigned long int n);
char * dngettext (const char * domainname,
                  const char * msgid, const char * msgid_plural,
                  unsigned long int n);
char * dcngettext (const char * domainname,
                   const char * msgid, const char * msgid_plural,
                   unsigned long int n, int category);

DESCRIPCIÓN

Las funciones ngettext, dngettext y dcngettext intentan traducir una cadena de texto al idioma nativo del usuario, buscando la forma plural apropiada de la traducción en un catálogo de mensajes.

Las formas plurales son variantes gramaticales que dependen de un número. Algunos idiomas tienen dos formas, llamadas singular y plural. Otros idiomas tienen tres formas, llamadas singular, dual y plural. También hay idiomas con cuatro formas.

Las funciones ngettext, dngettext y dcngettext funcionan como las funciones gettext, dgettext y dcgettext, respectivamente. Además, eligen la forma plural apropiada, que depende del número n y del idioma del catálogo de mensajes donde se encontró la traducción.

En la configuración regional "C", o si ninguno de los catálogos utilizados contiene una traducción para msgid, las funciones ngettext, dngettext y dcngettext devuelven msgid si n == 1, o msgid_plural si n != 1.

VALOR DE RETORNO

Si se encontró una traducción en uno de los catálogos especificados, se convierte la forma plural apropiada al conjunto de códigos del idioma y se devuelve. La cadena resultante se asigna estáticamente y no debe ser modificada ni liberada. De lo contrario, se devuelve msgid o msgid_plural, como se describió anteriormente.

ERRORES

errno no se modifica.

ERRORES CONOCIDOS

El tipo de retorno debería ser const char *, pero es char * para evitar advertencias en código C anterior a ANSI C.

VER TAMBIÉN
