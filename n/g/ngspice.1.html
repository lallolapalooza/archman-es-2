NGSPICE(1) Manual general de comandos NGSPICE(1)

NOMBRE

ngspice - simulador de circuitos derivado de SPICE3f5

SINOPSIS

ngspice [opciones] [archivo ...]

DESCRIPCIÓN

Esta página de manual es solo una pequeña descripción general. La documentación principal de ngspice se encuentra en el Manual del usuario de ngspice, que está disponible en formato pdf o html.

OPCIONES

-n o --no-spiceinit
No intente cargar el archivo ".spiceinit" al inicio. Normalmente ngspice intenta encontrar el archivo en el directorio actual y, si no lo encuentra, en el directorio principal del usuario.
-t terminal o --term=terminal
El programa se está ejecutando en una terminal con el nombre mfb terminal.
-b o --batch
Ejecutar en modo batch. ngspice leerá la entrada estándar o el archivo de entrada especificado y realizará la simulación. Tenga en cuenta que si la entrada estándar no es una terminal, ngspice entrará en modo batch por defecto, a menos que se proporcione la opción -i.
-s o --server
Ejecutar en modo servidor. Esto es similar al modo batch, excepto que se utiliza un archivo temporal (rawfile) y luego se escribe en la salida estándar, precedido por una línea con un solo "@", después de que la simulación se complete. Este modo es utilizado por el demonio ngspice.
-i o --interactive
Ejecutar en modo interactivo. Esto es útil si la entrada estándar no es una terminal pero se desea el modo interactivo. Sin embargo, la finalización de comandos no está disponible a menos que la entrada estándar sea una terminal.
-r archivo_raw o --rawfile=archivo
Utilice archivo_raw como el archivo predeterminado en el que se guardan los resultados de la simulación.
-c archivo_circuito o --circuitfile=archivo_circuito
Utilice archivo_circuito como la entrada predeterminada del circuito.
-h o --help
Mostrar una ayuda detallada sobre los argumentos disponibles para el programa.
-v o --version
Mostrar el número de versión e información de derechos de autor del programa.
-a o --autorun
FIXME
-o archivo_salida o --output=archivo
Todos los registros generados durante una ejecución en modo batch (-b) se guardarán en archivo_salida.
-p o --pipe
Permitir que un programa (por ejemplo, xcircuit) actúe como una interfaz gráfica para ngspice a través de una tubería (pipe). Por lo tanto, ngspice asumirá que la tubería es una tty y permitirá ejecutar en modo interactivo.

Los argumentos adicionales se toman como diseños de entrada SPICE, que se leen y guardan. (Si se solicita el modo batch, se ejecutan inmediatamente).

ENTORNO

SPICE_LIB_DIR
SPICE_EXEC_DIR
SPICE_HOST
SPICE_BUGADDR
SPICE_EDITOR
SPICE_ASCIIRAWFILE predeterminado 0
Formato del archivo raw. 0 para binario y 1 para ascii.
SPICE_NEWS predeterminado $SPICE_LIB_DIR/news
Un archivo que se copia textualmente a stdout cuando ngspice se inicia en modo interactivo.
SPICE_MFBCAP predeterminado $SPICE_LIB_DIR/mfbcap
SPICE_HELP_DIR predeterminado $SPICE_LIB_DIR/helpdir
SPICE_SCRIPTS predeterminado $SPICE_LIB_DIR/scripts
En este directorio se buscará el archivo spinit.
SPICE_PATH predeterminado $SPICE_EXEC_DIR/ngspice

varias variables de entorno no documentadas específicas de ngspice:

NGSPICE_MEAS_PRECISION
SPICE_NO_DATASEG_CHECK

Variables de entorno comunes:

TERM LINES COLS DISPLAY HOME PATH EDITOR SHELL
POSIXLY_CORRECT

ARCHIVOS

$SPICE_LIB_DIR/scripts/spinit
El archivo de inicialización del sistema.
.spiceinit o $HOME/.spiceinit
El archivo de inicialización del usuario.
