NGETTEXT(1) Comandos de usuario NGETTEXT(1)

NOMBRE

ngettext - traduce mensaje y elige forma plural

SINOPSIS

ngettext [OPCIÓN] [DOMINIO DE TEXTO] MSGID MSGID-PLURAL COUNT

DESCRIPCIÓN

El programa ngettext traduce un mensaje en lenguaje natural al idioma del usuario, buscando la traducción en un catálogo de mensajes, y elige la forma plural apropiada, que depende del número COUNT y el idioma del catálogo de mensajes donde se encontró la traducción.

Muestra la traducción en idioma nativo de un mensaje textual cuya forma gramatical depende de un número.

Opciones y argumentos:

-d, --dominio=DOMINIO DE TEXTO
recupera el mensaje traducido del DOMINIO DE TEXTO
-c, --contexto=CONTEXTO
especifica el contexto para MSGID
-e
habilita la expansión de algunas secuencias de escape
-E
(ignorado por compatibilidad)
[DOMINIO DE TEXTO]
recupera el mensaje traducido del DOMINIO DE TEXTO
MSGID MSGID-PLURAL
traduce MSGID (singular) / MSGID-PLURAL (plural)
COUNT
elige la forma singular/plural basándose en este valor

Salida informativa:

-h, --help
muestra esta ayuda y sale
-V, --version
muestra información de la versión y sale

Si el parámetro DOMINIO DE TEXTO no se proporciona, el dominio se determina a partir de la variable de entorno TEXTDOMAIN. Si el catálogo de mensajes no se encuentra en el directorio habitual, se puede especificar otra ubicación con la variable de entorno TEXTDOMAINDIR. Directorio de búsqueda estándar: /usr/share/locale
