NOMBRE

npa-tool - muestra información sobre la tarjeta de identidad electrónica alemana (neuer Personalausweis, nPA).

SINOPSIS

npa-tool [OPCIONES]

DESCRIPCIÓN

La utilidad npa-tool se utiliza para mostrar la información almacenada en la tarjeta de identidad electrónica alemana (neuer Personalausweis, nPA), y para realizar algunas operaciones de escritura y verificación.

Se realiza el Control de Acceso Extendido versión 2 de acuerdo con el Documento 9303 de la OACI o el BSI TR-03110, de modo que también se puedan leer otras tarjetas de identidad y documentos de viaje legibles por máquina (MRTD).

OPCIONES

--help, -h

Imprime la ayuda y sale.

--version, -V

Imprime la versión y sale.

--reader arg, -r arg

Número del lector a utilizar. Por defecto, se utiliza el primer lector con una tarjeta presente. Si arg es un ATR, se elegirá el lector con una tarjeta coincidente.

--verbose, -v

Hace que npa-tool sea más detallado. Especifique este indicador varias veces para ser más detallado.

Establecimiento de conexión autenticado por contraseña (PACE)

--pin [CADENA], -p [CADENA]

Ejecuta PACE con el PIN (de transporte) de la tarjeta de identidad.

--puk [CADENA], -u [CADENA]

Ejecuta PACE con el PUK.

--can [CADENA], -c [CADENA]

Ejecuta PACE con el Número de Acceso a la Tarjeta (CAN).

--mrz [CADENA], -m [CADENA]

Ejecuta PACE con la Zona Legible por Máquina (MRZ). Introduce la MRZ sin saltos de línea.

--env

Especifica si se deben usar las variables de entorno PIN, PUK, CAN, MRZ y NEWPIN. Es posible que desee limpiar su entorno antes de habilitar esto. (por defecto=desactivado)

Gestión de PIN

--new-pin [CADENA], -N [CADENA]

Instala un nuevo PIN.

--resume, -R

Reanuda el PIN de la tarjeta de identidad (usa el CAN para activar el último intento). (por defecto=desactivado)

--unblock, -U

Desbloquea el PIN (usa el PUK para activar tres intentos más). (por defecto=desactivado)

Autenticación de Terminal (TA) y Autenticación de Chip (CA)

--cv-certificate NOMBRE_ARCHIVO, -C NOMBRE_ARCHIVO

Especifica el certificado verificable por tarjeta (CV) para crear una cadena de certificados. La opción se puede dar varias veces, en cuyo caso el orden es importante.

--cert-desc CADENA_HEX

Descripción del certificado para mostrar en la Autenticación de Terminal.

--chat CADENA_HEX

Especifica la Plantilla de Autorización del Titular de la Tarjeta (CHAT) a utilizar. Si no se proporciona, por defecto es la CHAT de la terminal. Usa 7F4C0E060904007F000703010203530103 para activar EAC en la CAT-C (Komfortleser).

--auxiliary-data CADENA_HEX, -A CADENA_HEX

Especifica los datos auxiliares de la terminal. Si no se proporcionan, el valor predeterminado se determina mediante la verificación de validez, edad e ID de comunidad.

--private-key NOMBRE_ARCHIVO, -P NOMBRE_ARCHIVO

Especifica la clave privada de la terminal.

--cvc-dir DIRECTORIO

Especifica dónde buscar el certificado de la Autoridad Certificadora Verificadora del País (CVCA). Si no se proporciona, por defecto es /home/fm/.local/etc/eac/cvc.

--x509-dir DIRECTORIO

Especifica dónde buscar el certificado X.509. Si no se proporciona, por defecto es /home/fm/.local/etc/eac/x509.

--disable-ta-checks

Desactiva la comprobación del período de validez de los certificados CV. (por defecto=desactivado)

--disable-ca-checks

Desactiva la autenticación pasiva. (por defecto=desactivado)

Leer y escribir grupos de datos

--read-dg1

Lee el grupo de datos 1: Tipo de documento.

--read-dg2

Lee el grupo de datos 2: Estado emisor.

--read-dg3

Lee el grupo de datos 3: Fecha de caducidad.

--read-dg4

Lee el grupo de datos 4: Nombre(s) de pila.

--read-dg5

Lee el grupo de datos 5: Apellido(s).

--read-dg6

Lee el grupo de datos 6: Nombre religioso/artístico.

--read-dg7

Lee el grupo de datos 7: Título académico.

--read-dg8

Lee el grupo de datos 8: Fecha de nacimiento.

--read-dg9

Lee el grupo de datos 9: Lugar de nacimiento.

--read-dg10

Lee el grupo de datos 10: Nacionalidad.

--read-dg11

Lee el grupo de datos 11: Sexo.

--read-dg12

Lee el grupo de datos 12: Datos opcionales.

--read-dg13

Lee el grupo de datos 13: Nombre de nacimiento.

--read-dg14

Lee el grupo de datos 14.

--read-dg15

Lee el grupo de datos 15.

--read-dg16

Lee el grupo de datos 16.

--read-dg17

Lee el grupo de datos 17: Lugar de residencia normal.

--read-dg18

Lee el grupo de datos 18: ID de comunidad.

--read-dg19

Lee el grupo de datos 19: Permiso de residencia I.

--read-dg20

Lee el grupo de datos 20: Permiso de residencia II.

--read-dg21

Lee el grupo de datos 21: Datos opcionales.

--write-dg17 CADENA_HEX

Escribe el grupo de datos 17: Lugar de residencia normal.

--write-dg18 CADENA_HEX

Escribe el grupo de datos 18: ID de comunidad.

--write-dg19 CADENA_HEX

Escribe el grupo de datos 19: Permiso de residencia I.

--write-dg20 CADENA_HEX

Escribe el grupo de datos 20: Permiso de residencia II.

--write-dg21 CADENA_HEX

Escribe el grupo de datos 21: Datos opcionales.

Verificación de validez, edad e ID de comunidad

--verify-validity AAAAmmdd

Verifica la validez del chip con una fecha de referencia.

--older-than AAAAmmdd

Verifica la edad con una fecha de referencia.

--verify-community CADENA_HEX

Verifica el ID de comunidad con un ID de referencia.

Opciones especiales, no siempre útiles

--break, -b

Fuerza el PIN, CAN o PUK. Usar junto con las opciones -p, -a o -u. (por defecto=desactivado)

--translate NOMBRE_ARCHIVO, -t NOMBRE_ARCHIVO

Especifica el archivo con APDUs de CADENA_HEX a enviar a través del canal seguro. (por defecto=`stdin')

--tr-03110v201

Fuerza la conformidad con BSI TR-03110 versión 2.01. (por defecto=desactivado)

--disable-all-checks

Desactiva todas las comprobaciones de datos de vuelo. (por defecto=desactivado)
