NPROXY(1) Servidor autoritativo de PowerDNS NPROXY(1)

NOMBRE

nproxy - proxy de notificación DNS

SINOPSIS

nproxy --powerdns-address DIRECCIÓN [OPCIÓN]... DIRECCIÓN...

DESCRIPCIÓN

nproxy es un demonio simple que lee consultas DNS NOTIFY en una dirección y las reenvía a un servidor de nombres 'interno' que procesará la notificación.

Su caso de uso es, por ejemplo, un servidor autoritativo privado dentro de una LAN con NAT o firewall donde nproxy se implementa en la DMZ.

El servidor autoritativo de PowerDNS tiene la opción trusted-notification-proxy que debe configurarse a la dirección especificada con --origin-address para aceptar estas notificaciones proxy.

nproxy también tiene una opción de comprobación de estado incorporada. Una consulta para 'pdns.nproxy.' con QType 'TXT' será respondida con una respuesta de "OK" (dentro del registro TXT. Cuando la consulta es para un registro A, se devuelve '1.2.3.4.'.

OPCIONES

--powerdns-address <DIRECCIÓN>
Dirección IP del servidor PowerDNS al que se reenviarán las notificaciones.
--chroot <RUTA>
chroot a RUTA para mayor seguridad.
--setuid <UID>
setuid a este UID numérico.
--setgid <GID>
setgid a este GID numérico.
--origin-address <DIRECCIÓN>
Establece la fuente de las notificaciones enviadas a PowerDNS a DIRECCIÓN. Por defecto, se utiliza la mejor dirección coincidente (elección del kernel).
--listen-address <DIRECCIÓN>
Direcciones IP en las que escuchar.
--listen-port <PUERTO>
Puerto de origen en el que escuchar, 53 por defecto.
-d,--daemon <ARG>
Establece ARG en 0 para deshabilitar la ejecución en segundo plano.
-v, --verbose
Sea verboso
