NOMBRE

nyx - monitor de estado de Tor en terminal

SINOPSIS

nyx [OPCIÓN]

DESCRIPCIÓN

Nyx es una interfaz de línea de comandos para Tor (https://www.torproject.org/), que proporciona información detallada en tiempo real sobre el reenvío para...


* uso de ancho de banda, CPU y memoria
* información de conexión
* configuración de tor
* registros de eventos
* etc

Como una interfaz de curses, Nyx es particularmente adecuada para conexiones ssh, terminales tty y aficionados a la línea de comandos para verificar el estado de tor.

Nyx se puede personalizar a través de un archivo de configuración ubicado en ~/.nyx/config. Para ver las opciones, consulte https://nyx.torproject.org/#configuration.

OPCIONES

-i, --interface [DIRECCIÓN:]PUERTO
puerto de control de tor al que debemos conectarnos (por defecto es 127.0.0.1:9051)
-s, --socket RUTA_SOCKET
socket de control de tor al que debemos conectarnos (por defecto es /var/run/tor/control)
-c, --config RUTA_CONFIGURACIÓN
preferencias de configuración del usuario (por defecto es ~/.nyx/config)
-d, --debug RUTA_LOG
escribe todos los registros de nyx en la ubicación dada
-l, --log EVENTOS
lista de eventos separados por comas para registrar
-v, --version
proporciona información de la versión
-h, --help
proporciona información de uso

ARCHIVOS

~/.nyx/config
Tu archivo de configuración personal de nyx
/usr/share/doc/nyx/nyxrc.sample
Archivo de configuración de ejemplo de nyxrc que documenta todas las opciones
