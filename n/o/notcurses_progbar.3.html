notcurses_progbar(3) Manual de funciones de la biblioteca notcurses_progbar(3)

NOMBRE

notcurses_progbar - widget de alto nivel para barras de progreso

SINOPSIS

#include <notcurses/notcurses.h>

struct ncprogbar;
#define NCPROGBAR_OPTION_RETROGRADE        0x0001u // proceder izquierda/abajo
typedef struct ncprogbar_options {
  uint32_t ulchannel; // canal superior-izquierdo. en el contexto de una barra de progreso,
  uint32_t urchannel; // "arriba" es la dirección hacia la que estamos progresando, y
  uint32_t blchannel; // "abajo" es la dirección de origen. para una barra monocromática
  uint32_t brchannel; // los cuatro canales deben ser iguales.
  uint64_t flags;
} ncprogbar_options;

struct ncprogbar* ncprogbar_create(struct ncplane* n, const ncprogbar_options* opts)

struct ncplane* ncprogbar_plane(struct ncprogbar* n)

int ncprogbar_set_progress(struct ncprogbar* n, double p)

double ncprogbar_progress(const struct ncprogbar* n)

void ncprogbar_destroy(struct ncprogbar* n)

DESCRIPCIÓN

Estas funciones dibujan barras de progreso en cualquiera de las cuatro direcciones. La medida de progreso es un double entre cero y uno, inclusive, proporcionado a ncprogbar_set_progress. Esto se escalará al tamaño del ncplane proporcionado n. El eje de progresión es el elemento más largo de la geometría del plano. Las barras horizontales avanzan hacia la derecha por defecto, y las barras verticales avanzan hacia arriba. Esto se puede cambiar con NCPROGBAR_OPTION_RETROGRADE.

NOTAS

ncprogbar_create toma posesión de n en todos los casos. En caso de fallo, n se destruirá inmediatamente. De lo contrario, es destruido por ncprogbar_destroy.

VALORES DE RETORNO

ncprogbar_plane devuelve el ncplane sobre el cual se dibuja la barra de progreso. ncprogbar_progress devuelve el progreso actual, un valor entre cero y uno, inclusive. No pueden fallar.

ncprogbar_set_progress devuelve -1 si p es menor que cero o mayor que uno, o si hay un error interno al redibujar la barra de progreso. Devuelve 0 en caso contrario.

ERRORES

Si la progresión es hacia la izquierda o hacia la derecha por defecto probablemente debería ser un aspecto de la configuración regional actual.

VER TAMBIÉN

notcurses(3), notcurses_plane(3), notcurses_visual(3)
