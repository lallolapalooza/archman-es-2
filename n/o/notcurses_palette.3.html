NOMBRE

notcurses_palette - operaciones sobre paletas de notcurses

SINOPSIS

#include <notcurses/notcurses.h>

typedef struct ncpalette {
  // Almacenamos los valores RGB como un canal normal
  uint32_t chans[NCPALETTESIZE];
} ncpalette;

bool notcurses_cantruecolor(const struct notcurses* nc);

ncpalette* ncpalette_new(struct notcurses* nc);

int ncpalette_use(struct notcurses* nc, const ncpalette* p);

int ncpalette_set_rgb8(ncpalette* p, int idx, int r, int g, int b);

int ncpalette_set(ncpalette* p, int idx, unsigned rgb);

int ncpalette_get(const ncpalette* p, int idx, uint32_t* palent);

int ncpalette_get_rgb8(const ncpalette* p, int idx, int* restrict r, int* restrict g, int* restrict b);

void ncpalette_free(ncpalette* p);

bool notcurses_canchangecolors(const struct notcurses* nc);

DESCRIPCIÓN

Algunos terminales solo admiten 256 colores, pero permiten que la paleta completa se especifique con colores RGB arbitrarios. En todos los casos, es más eficiente usar colores indexados, ya que es mucha menos información para escribir en el terminal. Si puedes limitarte a 256 colores, probablemente sea lo mejor.

Además, el color basado en paleta permite efectos de ciclado de color muy rápidos, ya que un solo comando puede afectar a muchas celdas en la pantalla.

VALORES DE RETORNO

Las funciones que devuelven int devuelven -1 en caso de error, o 0 en caso de éxito. El error siempre se debe a entradas no válidas. Las funciones que devuelven bool son predicados y devuelven el valor solicitado. Las funciones que devuelven formularios unsigned devuelven la entrada, modificada según lo solicitado.
