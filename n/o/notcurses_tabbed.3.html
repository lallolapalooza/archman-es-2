NOMBRE

notcurses_tabbed – widget de interfaz de pestañas

DESCRIPCIÓN

Un nctabbed es un widget con un área para mostrar datos y una barra con los nombres de las pestañas. A menos que no haya pestañas, exactamente una pestaña está "seleccionada" y exactamente una pestaña está "más a la izquierda". La pestaña seleccionada es la que controla el plano de contenido de la pestaña. La pestaña más a la izquierda es aquella cuyo encabezado es visible más a la izquierda. Cualquier pestaña puede ser movida hacia y desde cualquier lugar de la lista. Las pestañas pueden ser "rotadas", lo que en realidad significa que la pestaña más a la izquierda se desplaza. El widget solo se dibuja cuando se llaman nctabbed_redraw o ntabbed_create.

DISEÑO

El widget tiene una lista de pestañas en la parte superior o inferior, de 1 fila de grosor. La lista de pestañas contiene encabezados de pestañas (es decir, sus nombres), separados por el separador especificado en nctabbed_create o nctabbed_set_separator. Los canales para el encabezado de la pestaña seleccionada, otros encabezados de pestañas y el separador se pueden establecer de forma independiente entre sí. El separador de pestañas puede tener una longitud de 0, o ser NULL, en cuyo caso no hay un separador visible entre los encabezados de las pestañas. Se puede asegurar que la pestaña seleccionada sea visible al dibujarse (cambiando la pestaña más a la izquierda) llamando a nctabbed_ensure_selected_header_visible con un nombre muy largo. El resto del widget es un ncplane que aloja el contenido de la pestaña seleccionada (si lo hay).

EL CALLBACK DE LA PESTAÑA

El callback de la pestaña (de tipo tabcb) toma una pestaña, el plano de contenido de la pestaña y el puntero opaco dado a nctabbed_add o nctabbed_set_userptr. Se llama cuando se debe dibujar el contenido de la pestaña, es decir, cuando se redibuja todo el widget. Debe dibujar el contenido de la pestaña y posiblemente realizar otras acciones, pero no debe asumir nada sobre el estado actual del plano de contenido de la pestaña, ni debe modificar el estado del widget o de la pestaña.

VALORES DE RETORNO

nctabbed_create devuelve el widget recién creado, o NULL cuando la creación del widget falló. Esto destruye el ncplane que se le proporcionó incluso si falla.

nctabbed_selected y nctabbed_leftmost devuelven las pestañas seleccionada y más a la izquierda, respectivamente. Si no hay pestañas, estas devuelven NULL.

nctab_name devuelve el nombre de la pestaña. Esta no es una copia y no debe almacenarse, ya que se libera cuando se cambia el nombre de la pestaña o se elimina la pestaña.

nctabbed_next, nctabbed_prev y nctabbed_select devuelven la pestaña recién seleccionada.

nctabbed_separator devuelve el separador de pestañas. Esta no es una copia y no debe almacenarse, ya que se libera cuando se cambia el separador o se elimina el widget.

Las funciones que devuelven int devuelven -1 en caso de fallo.

NOMBRE

notcurses - API para la biblioteca notcurses

SINOPSIS

#include <notcurses/notcurses.h>

DESCRIPCIÓN

La biblioteca notcurses proporciona un conjunto de herramientas para escribir aplicaciones de terminales ricas en texto. Permite la creación de interfaces gráficas de usuario basadas en texto, la manipulación de píxeles y el manejo de entradas del usuario con un alto grado de control.

Las funciones principales incluyen la inicialización y finalización del subsistema notcurses, la creación y gestión de ventanas, la disposición de elementos en la pantalla y la respuesta a eventos de entrada.

VALORES DE RETORNO

Las funciones de notcurses devuelven valores específicos para indicar éxito o fallo. Generalmente, se utilizan códigos de retorno enteros (0 para éxito, negativo para error) o punteros NULL para indicar un fallo en la asignación o creación de recursos. Consulte la documentación de cada función para obtener detalles específicos sobre sus valores de retorno.
