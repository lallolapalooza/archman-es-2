NOP(1) Manual de comandos generales NOP(1)

NOMBRE

nop - imprimir bonito archivo de grafo

SINOPSIS

nop [ -p? ] [ archivos ]

DESCRIPCIÓN

nop lee un flujo de grafos e imprime cada uno en formato bonito (canónico) en stdout. Si no se proporcionan archivos, lee desde stdin.

OPCIONES

Se admiten las siguientes opciones:

-p
No producir salida; solo verificar la entrada para ver si es DOT válido.
-?
Imprimir información de uso.

ESTADO DE SALIDA

Si ocurrieron errores al procesar alguna entrada, como un archivo no encontrado o un archivo que contiene DOT ilegal, se devuelve EXIT_FAILURE. De lo contrario, se devuelve EXIT_SUCCESS.
