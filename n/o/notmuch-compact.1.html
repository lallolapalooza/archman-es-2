NOMBRE

notmuch-compact - compacta la base de datos de notmuch

SINOPSIS

notmuch compact [--quiet] [--backup=<directorio>]

DESCRIPCIÓN

El comando compact puede usarse para compactar la base de datos de notmuch. Esto puede tanto reducir el espacio requerido por la base de datos como mejorar el rendimiento de las búsquedas.

La base de datos compactada se construye en un directorio temporal y luego se mueve al lugar de la base de datos de origen. La base de datos original sin compactar se descarta, a menos que se utilice la opción --backup=<directorio>.

Tenga en cuenta que el bloqueo de escritura de la base de datos se mantendrá durante el proceso de compactación (que puede ser bastante largo) para proteger la integridad de los datos.

Las opciones soportadas para compact incluyen

--backup=<directorio>
Guarda la base de datos actual en el directorio proporcionado antes de reemplazarla con la base de datos compactada. El directorio de copia de seguridad no debe existir y debe residir en el mismo sistema de archivos montado que la base de datos actual.
--quiet
No informar el progreso de la compactación de la base de datos a stdout.

VER TAMBIÉN
