NAME

caca_conio_text_info - text attributes.

SYNOPSIS

#include <ncurses.h>

struct caca_conio_text_info {
    unsigned char attr;
    unsigned char color;
    unsigned char curx;
    unsigned char cury;
};

Detailed Description

This structure holds the text attributes and cursor position for the current window.
