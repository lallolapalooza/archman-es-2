notcurses_plot(3)

Paquete: notcurses

Licencias: Apache

notcurses_plot(3) Manual de funciones de la biblioteca notcurses_plot(3)

NOMBRE

notcurses_plot - widget de alto nivel para trazado de gráficos

SINOPSIS

#include <notcurses/notcurses.h>

#define NCPLOT_OPTION_LABELTICKSD   0x0001u
#define NCPLOT_OPTION_EXPONENTIALD  0x0002u
#define NCPLOT_OPTION_VERTICALI     0x0004u
#define NCPLOT_OPTION_NODEGRADE     0x0008u
#define NCPLOT_OPTION_DETECTMAXONLY 0x0010u
#define NCPLOT_OPTION_PRINTSAMPLE   0x0020u
typedef struct ncplot_options {
  // canales para los niveles máximo y mínimo.
  // interpola a través del dominio entre estos dos.
  uint64_t maxchannels;
  uint64_t minchannels;
  // estilo utilizado para las etiquetas (NCPLOT_OPTION_LABELTICKSD)
  uint16_t legendstyle;
  // pasar NCBLIT_DEFAULT se mapea a NCBLIT_8x1 (asumiendo
  // UTF8) o NCBLIT_1x1 (en un entorno ASCII)
  ncblitter_e gridtype;
  // la variable independiente puede ser un rango contiguo,
  // o un conjunto finito de claves. para un rango de tiempo, digamos la
  // hora anterior muestreada con resolución de segundos, la
  // variable independiente sería el rango [0..3600): 3600.
  // si rangex es 0, se establece dinámicamente al número
  // de columnas.
  int rangex;
  const char* title;   // título opcional
  uint64_t flags;      // campo de bits sobre NCPLOT_OPTION_*
} ncplot_options;

struct ncuplot* ncuplot_create(struct ncplane* n, const ncplot_options* opts, uint64_t miny, uint64_t maxy);

struct ncdplot* ncdplot_create(struct ncplane* n, const ncplot_options* opts, double miny, double maxy);

struct ncplane* ncuplot_plane(struct ncuplot* n);

struct ncplane* ncdplot_plane(struct ncdplot* n);

int ncuplot_add_sample(struct ncuplot* n, uint64_t x, uint64_t y);

int ncdplot_add_sample(struct ncdplot* n, uint64_t x, double y);

int ncuplot_set_sample(struct ncuplot* n, uint64_t x, uint64_t y);

int ncdplot_set_sample(struct ncdplot* n, uint64_t x, double y);

int ncuplot_sample(const struct ncuplot* n, uint64_t x, uint64_t* y);

int ncdplot_sample(const struct ncdplot* n, uint64_t x, double* y);

void ncuplot_destroy(struct ncuplot* n);

void ncdplot_destroy(struct ncdplot* n);

DESCRIPCIÓN

Estas funciones soportan histogramas. La variable independiente es siempre un uint64_t. Las muestras son uint64_ts (ncuplot) o doubles (ncdplot). Solo se conserva una ventana sobre las muestras en un momento dado, y esta ventana solo puede moverse hacia valores más grandes de la variable independiente. La ventana se mueve hacia adelante cada vez que se suministra un x mayor que el máximo de la ventana actual a add_sample o set_sample.

add_sample incrementa el valor actual correspondiente a este x en y. set_sample reemplaza el valor actual correspondiente a este x.

Si rangex es 0, o mayor que el plano delimitador soportará, se limita al espacio disponible. El dominio se puede especificar como miny y maxy, o se puede invocar la autodetección del dominio estableciendo ambos a 0. Si el dominio se especifica, las muestras fuera del dominio son un error y no contribuyen al gráfico. Suministrar un x por debajo de la ventana actual es un error y no tiene ningún efecto.

Los glifos de bloque más granulares significan más resolución en sus gráficos, pero pueden ser difíciles de diferenciar en tamaños de texto pequeños. Los octantes, sextantes y Braille permiten más resolución en la variable independiente. Puede ser difícil predecir cómo se verán los glifos Braille en una fuente determinada.

La misma estructura ncplot_options se puede utilizar con todos los tipos de ncplot. El campo flags es una máscara de bits compuesta por:

•
NCPLOT_OPTION_LABELTICKSD: Etiqueta las marcas del eje dependiente
•
NCPLOT_OPTION_EXPONENTIALD: Utiliza un eje dependiente exponencial
•
NCPLOT_OPTION_VERTICALI: Eje independiente vertical
•
NCPLOT_OPTION_NODEGRADE: Falla en lugar de degradar el blitter
•
NCPLOT_OPTION_DETECTMAXONLY: Detecta solo el dominio máximo, no el mínimo
•
NCPLOT_OPTION_PRINTSAMPLE: Imprime la muestra más reciente

Si se proporciona NCPLOT_OPTION_LABELTICKSD o NCPLOT_OPTION_PRINTSAMPLE, el campo legendstyle se utilizará para dar estilo a las etiquetas. De lo contrario, se ignora.

La etiqueta se imprime en la parte superior izquierda, inmediatamente a la derecha de la marca del eje superior (si se utilizó NCPLOT_OPTION_LABELTICKSD). La muestra más reciente se imprime enfrente de la etiqueta a lo largo del eje independiente (si se utilizó NCPLOT_OPTION_PRINTSAMPLE).

NOTAS

NCPLOT_OPTION_VERTICALI aún no está implementado.

VALORES DE RETORNO

create devolverá un error si miny es igual a maxy, pero ambos son distintos de cero. También devolverá un error si maxy < miny. Un gridtype inválido provocará un error.

plane devuelve el ncplane en el que se dibuja el gráfico. No puede fallar.
