NOMBRE

notcurses_capabilities - detección de capacidades en tiempo de ejecución

DESCRIPCIÓN

notcurses_detected_terminal devuelve una cadena de formato libre que describe la terminal detectada. La detección de la terminal tiene en cuenta cualquier base de datos de terminal especificada (ver notcurses_init(3)), las variables de entorno TERM, TERM_PROGRAM y TERM_PROGRAM_VERSION, la respuesta a una Cadena de Control de Dispositivo XTGETTCAP[TN], la respuesta a las secuencias de control de envío de atributos de dispositivo Primario, Secundario y Terciario, y la fase de la luna. No debe basar la lógica en esta respuesta; todas las propiedades relevantes de la terminal deben ser abstraídas por Notcurses. Esto solo está disponible para diagnóstico.

notcurses_supported_styles devuelve una máscara de bits que representa aquellos estilos para los que la terminal anuncia soporte.

notcurses_palette_size devuelve el tamaño de la paleta de la terminal, utilizado para el color indexado por paleta. Siempre devolverá al menos 1. Esto es independiente del soporte de TrueColor RGB. No se conoce ninguna terminal que soporte más de 256 colores indexados.

notcurses_cantruecolor devuelve true si la terminal anuncia soporte para RGB TrueColor. Tenga en cuenta que las API RGB de Notcurses se pueden usar incluso en ausencia de soporte RGB de la terminal (Notcurses mapeará los valores RGB a la paleta).

notcurses_canfade devuelve true si Notcurses tiene un medio por el cual puede efectuar fundidos.

notcurses_canchangecolor devuelve true si la terminal anuncia soporte para cambiar las entradas de su paleta.

notcurses_canopen_images devuelve true si Notcurses se compiló con soporte multimedia.

notcurses_canopen_video devuelve true si Notcurses se compiló con soporte multimedia capaz de decodificar videos.

notcurses_canutf8 devuelve true si la configuración regional configurada utiliza codificación UTF-8 y la configuración regional se cargó correctamente.

notcurses_canoctant devuelve true si las heurísticas sugieren que la terminal puede renderizar correctamente octantes Unicode 16. notcurses_cansextant devuelve true si las heurísticas sugieren que la terminal puede renderizar correctamente sextantes Unicode 13, y notcurses_canquadrant y notcurses_canhalfblock devuelven true si las heurísticas sugieren que la terminal puede renderizar correctamente cuadrantes y semibloques Unicode, respectivamente. notcurses_canbraille devuelve true si se espera que el Braille Unicode funcione en la terminal. Ninguna de estas funciones devuelve true a menos que se esté utilizando la codificación UTF-8.

notcurses_check_pixel_support devuelve una implementación de píxel no nula si se ha detectado soporte para mapas de bits (a través de cualquier mecanismo), y de lo contrario 0 (NCPIXEL_NONE). notcurses_canpixel reduce esto a un booleano.

NOTAS

Algunas terminales anuncian soporte para TrueColor, pero luego reducen o degradan de otra manera el RGB proporcionado. En este caso, notcurses_cantruecolor devolverá true, pero no estará disponible todo el espectro.
