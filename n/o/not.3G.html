NOMBRE

not - invierte lógicamente un vector booleano

DECLARACIÓN

bvec not(bvec x);

PARÁMETROS

x

Especifica el vector a invertir.

DESCRIPCIÓN

not invierte lógicamente el vector booleano x. Devuelve un nuevo vector booleano para el cual cada elemento i se calcula como !x[i].
