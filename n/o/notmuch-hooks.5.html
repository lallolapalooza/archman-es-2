notmuch-hooks(5)

Paquete: notmuch-runtime

Licencias: GPL3

NOTMUCH-HOOKS(5) notmuch NOTMUCH-HOOKS(5)

NOMBRE

notmuch-hooks - ganchos para notmuch

SINOPSIS

<directorio_de_ganchos>/{pre-new, post-new, post-insert}

DESCRIPCIÓN

Los ganchos son scripts (o ejecutables arbitrarios o enlaces simbólicos a ellos) que notmuch invoca antes y después de ciertas acciones. Estos scripts residen en un directorio definido según se describe en notmuch-config. Deben tener permisos de ejecución.

Los ganchos disponibles actualmente se describen a continuación.

pre-new
Este gancho es invocado por el comando notmuch-new antes de escanear o importar nuevos mensajes a la base de datos. Si este gancho sale con un estado distinto de cero, notmuch abortará el procesamiento posterior del comando notmuch-new.

Típicamente, este gancho se utiliza para obtener o entregar correo nuevo para importarlo a la base de datos.

post-new
Este gancho es invocado por el comando notmuch-new después de que se hayan importado nuevos mensajes a la base de datos y se hayan aplicado las etiquetas iniciales. El gancho no se ejecutará si ha habido algún error durante el escaneo o la importación.

Típicamente, este gancho se utiliza para realizar etiquetado adicional basado en consultas en los mensajes importados.

post-insert
Este gancho es invocado por el comando notmuch-insert después de que el mensaje ha sido entregado, añadido a la base de datos y se han aplicado las etiquetas iniciales. El gancho no se ejecutará si ha habido algún error durante la entrega del mensaje; lo que se considera entrega exitosa depende de la opción --keep.

Típicamente, este gancho se utiliza para realizar etiquetado adicional basado en consultas en los mensajes entregados.

VER TAMBIÉN

notmuch, notmuch-config, notmuch-count, notmuch-dump, notmuch-insert, notmuch-new, notmuch-reply, notmuch-restore, notmuch-search, notmuch-search-terms, notmuch-show, notmuch-tag
