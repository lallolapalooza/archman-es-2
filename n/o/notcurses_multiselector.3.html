NOMBRE

notcurses_multiselector - widget de alto nivel para seleccionar entre un conjunto

SINOPSIS

#include <notcurses/notcurses.h>

struct ncplane;
struct notcurses;
struct ncmultiselector;
struct ncmselector_item {
  const char* option;
  const char* desc;
};
typedef struct ncmultiselector_options {
  const char* title; // el título puede ser NULL, inhibiendo el elevador
  const char* secondary; // el secundario puede ser NULL
  const char* footer; // el pie de página puede ser NULL
  struct ncmselector_item* items; // elementos iniciales, estados
  // elemento predeterminado (seleccionado al inicio)
  unsigned defidx;
  // número máximo de opciones a mostrar a la vez
  unsigned maxdisplay;
  // opciones de estilo exhaustivas
  uint64_t opchannels;   // canales de opción
  uint64_t descchannels; // canales de descripción
  uint64_t titlechannels;// canales de título
  uint64_t footchannels; // canales secundarios y de pie de página
  uint64_t boxchannels;  // canales de borde
  uint64_t flags;        // campo de bits sobre NCMULTISELECTOR_OPTION_*
} ncmultiselector_options;

struct ncmultiselector* ncmultiselector_create(struct ncplane* n, const ncmultiselector_options* opts);

int ncmultiselector_selected(bool* selected, unsigned n);

struct ncplane* ncmultiselector_plane(struct ncmultiselector* n);

bool ncmultiselector_offer_input(struct ncmultiselector* n, const ncinput* nc);

void ncmultiselector_destroy(struct ncmultiselector* n);

DESCRIPCIÓN

Un widget multiselector presenta una lista de elementos (posiblemente más de los que se pueden mostrar a la vez). Facilita la elección de cero, uno o múltiples elementos de la lista. Los elementos se pueden seleccionar y deseleccionar antes de tomar una decisión final.

NOTAS

El ncplane n proporcionado a ncmultiselector_create no debe ser NULL. Será redimensionado libremente por el nuevo ncmultiselector.

ncmultiselector_selected devuelve el índice de la opción actualmente resaltada. Almacena en el mapa de bits n-ésimo apuntado por selected según las opciones seleccionadas actualmente.

ncmultiselector_plane devolverá el ncplane sobre el cual se dibuja el widget.

La entrada debe pasarse a través de ncmultiselector_offer_input para aprovechar los controles comunes. Manejará las flechas arriba y abajo, junto con AvPág y RePág. Si el ratón está habilitado, se manejarán la rueda del ratón y los clics del ratón en las flechas de desplazamiento.

ncmultiselector_destroy destruye el ncplane de soporte, al igual que ncmultiselector_create en caso de cualquier error.

Como no existen flags, la opción flags siempre debe ser 0.

VALORES DE RETORNO

ncmultiselector_create devuelve NULL en caso de error, en cuyo caso el ncplane proporcionado es destruido.

ncmultiselector_selected devuelve -1 si no hay elementos, o si n no es igual al número de elementos. De lo contrario, devuelve el índice de la opción actualmente resaltada y escribe un mapa de bits en selected basado en los elementos seleccionados.

VER TAMBIÉN

notcurses(3), notcurses_input(3), notcurses_plane(3) notcurses_selector(3)
