NOMBRE

notcurses_menu - operaciones sobre objetos ncmenu

SINOPSIS

#include <notcurses/notcurses.h>

struct ncmenu;
struct ncplane;
struct notcurses;
struct ncmenu_section {
  const char* name;   // Cadena c en utf-8
  struct ncmenu_item {
    const char* desc; // Elemento de menú en utf-8, NULL para separador horizontal
    ncinput shortcut; // Atajo, todos deben ser distintos
  }* items;
  int itemcount;
};
#define NCMENU_OPTION_BOTTOM 0x0001 // Fila inferior (en lugar de superior)
#define NCMENU_OPTION_HIDING 0x0002 // Ocultar el menú cuando no está desplegado
typedef struct ncmenu_options {
  struct ncmenu_section* sections; // 'sectioncount' menu_sections
  int sectioncount;         // debe ser positivo
  uint64_t headerchannels;  // estilo para la cabecera
  uint64_t sectionchannels; // estilo para las secciones
  uint64_t flags;           // campo de bits sobre NCMENU_OPTION_*
} ncmenu_options;

struct ncmenu* ncmenu_create(struct notcurses* nc, const menu_options* opts);

int ncmenu_unroll(struct ncmenu* n, int sectionidx);

int ncmenu_rollup(struct ncmenu* n);

int ncmenu_nextsection(struct ncmenu* n);

int ncmenu_prevsection(struct ncmenu* n);

int ncmenu_nextitem(struct ncmenu* n);

int ncmenu_previtem(struct ncmenu* n);

int ncmenu_item_set_status(struct ncmenu* n, const char* section, const char* item, bool enabled);

const char* ncmenu_selected(const struct ncmenu* n, ncinput* ni);

const char* ncmenu_mouse_selected(const struct ncmenu* n, const ncinput* click, ncinput* ni);

struct ncplane* ncmenu_plane(struct ncmenu* n);

bool ncmenu_offer_input(struct ncmenu* n, const ncinput* nc);

void ncmenu_destroy(struct ncmenu* n);

DESCRIPCIÓN

Una instancia de notcurses soporta barras de menú en la fila superior o inferior de un plano. Un menú se compone de secciones, que a su vez se componen de elementos. O bien no hay secciones visibles, y el menú está enrollado, o bien exactamente una sección está desenrollada. ncmenu_rollup pone un ncmenu en estado enrollado. ncmenu_unroll enrolla cualquier sección desenrollada y desenrolla la especificada. ncmenu_destroy elimina una barra de menú y libera todos los recursos asociados.

ncmenu_selected devuelve la descripción del elemento seleccionado, o NULL si no hay ninguna sección desenrollada, o ningún elemento válido seleccionado. ncmenu_mouse_selected devuelve el elemento seleccionado por un clic del ratón (descrito en click), que debe estar en la sección activamente desenrollada. En ambos casos, si hay un atajo para el elemento y ni no es NULL, ni se rellenará con el atajo.

El menú puede ser controlado enteramente por la aplicación, a través de llamadas directas a ncmenu_previtem, ncmenu_prevsection y similares, o los objetos ncinput pueden ser pasados a ncmenu_offer_input. En este último caso, el menú se autogestionará en gran medida. La aplicación debe gestionar la selección de elementos (normalmente a través de la tecla Enter y/o el clic del ratón) por sí misma, ya que el menú no puede llamar arbitrariamente a la aplicación. ncmenu_offer_input gestionará los clics para desenrollar secciones del menú, clics para descartar el menú, Escape para descartar el menú, izquierda y derecha para cambiar las secciones del menú, y arriba y abajo para cambiar los elementos del menú (estos últimos solo se consumen si hay una sección activamente desenrollada).

Los elementos pueden ser deshabilitados con ncmenu_item_set_status. Pase false para deshabilitar el elemento, o true para habilitarlo. Todos los elementos están habilitados por defecto. Un elemento deshabilitado no será devuelto con ncmenu_mouse_selected, ni se alcanzará con ncmenu_nextsection ni ncmenu_prevsection.

VALORES DE RETORNO

ncmenu_create devuelve NULL en caso de error, o un puntero a un nuevo ncmenu válido. Otras funciones devuelven un valor distinto de cero en caso de error, o cero en caso de éxito. Casi todos los errores se deben a parámetros inválidos.

ncmenu_offer_input devuelve true si el menú "consumió" la entrada, es decir, la encontró relevante y realizó una acción. De lo contrario, se devuelve false, y la ncinput debe considerarse irrelevante para el menú.
