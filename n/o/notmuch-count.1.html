NOMBRE

notmuch-count - cuenta mensajes que coinciden con los términos de búsqueda dados

SINOPSIS

notmuch count [opción ...] <término-de-búsqueda> ...

DESCRIPCIÓN

Cuenta los mensajes que coinciden con los términos de búsqueda.

El número de mensajes (o hilos) coincidentes se muestra en la salida estándar.

Si no se proporcionan términos de búsqueda, se mostrará un recuento de todos los mensajes (o hilos) en la base de datos.

Consulte notmuch-search-terms para obtener detalles sobre la sintaxis admitida para <términos-de-búsqueda>.

Las opciones admitidas para count incluyen:

--output=(mensajes|hilos|archivos)
mensajes
Muestra el número de mensajes coincidentes. Este es el valor predeterminado.
hilos
Muestra el número de hilos coincidentes.
archivos
Muestra el número de archivos asociados con mensajes coincidentes. Esto puede ser mayor que el número de mensajes coincidentes debido a duplicados (es decir, varios archivos con el mismo message-id).
--exclude=(verdadero|falso)
Especifica si se omiten o no los mensajes que coinciden con search.exclude_tags del recuento (el valor predeterminado).
--batch
Lee consultas de un archivo (stdin por defecto), una por línea, y muestra el número de mensajes (o hilos) coincidentes en la salida estándar, uno por línea. En una línea de entrada vacía se mostrará el recuento de todos los mensajes (o hilos) de la base de datos. Esta opción no es compatible con la especificación de términos de búsqueda en la línea de comandos.
--lastmod
Añade lastmod (contador para el número de actualizaciones de la base de datos) y UUID a la salida. Los valores de lastmod solo son comparables entre bases de datos con el mismo UUID.
--input=<nombre-archivo>
Lee la entrada del archivo dado, en lugar de stdin. Implica --batch.
