notcurses_tree(3) Manual de funciones de biblioteca notcurses_tree(3)

NOMBRE

notcurses_tree - datos jerárquicos de alto nivel basados en líneas

SINOPSIS

#include <notcurses/notcurses.h>

struct nctree;
struct ncplane;
typedef struct nctree_item {
  void* curry;
  struct nctree_item* subs;
  unsigned subcount;
} nctree_item;
typedef struct nctree_options {
  const nctree_item* items; // array de nctree_item de nivel superior
  unsigned count;           // tamaño de |items|
  int (*nctreecb)(struct ncplane*, void*, int); // callback de ítem
  int indentcols;           // columnas para indentar por jerarquía
  uint64_t flags;           // campo de bits de NCTREE_OPTION_*
} nctree_options;

struct nctree* nctree_create(struct ncplane* n, const nctree_options* opts);

struct ncplane* nctree_plane(struct nctree* n);

int nctree_redraw(struct nctree* n);

bool nctree_offer_input(struct nctree* n, const ncinput* ni);

void* nctree_focused(struct nctree* n);

void* nctree_next(struct nctree* n);

void* nctree_prev(struct nctree* n);

void* nctree_goto(struct nctree* n, const int* path, int* failpath);

int nctree_add(struct nctree* n, const unsigned* path, const nctree_item* add);

int nctree_del(struct nctree* n, const unsigned* path);

void nctree_destroy(struct nctree* n);

DESCRIPCIÓN

nctrees organizan elementos jerárquicos y permiten navegarlos. Cada elemento puede tener sub-elementos arbitrarios. Los elementos pueden colapsarse y expandirse. La visualización soporta desplazamiento y búsqueda.

Un nctree no puede estar vacío. count debe ser no cero, y items no debe ser NULL. La función de callback nctreecb tampoco debe ser NULL.

La función de callback nctreecb se llama en los elementos del árbol cuando el árbol se redibuja. Se llamará en cada elemento visible y en cualquier elemento que se haya ocultado. Si el elemento está recién ocultado, el argumento ncplane será NULL. Si el elemento está recién visible, el argumento ncplane será un plano vacío. Si el elemento ya era visible, el argumento ncplane será el mismo plano pasado anteriormente. Si el elemento no ha cambiado desde la última vez que se invocó el callback, no es necesario cambiar el plano y el callback puede retornar inmediatamente. De lo contrario, el plano debería ser dibujado por el callback. Las filas no utilizadas deberían ser recortadas usando ncplane_resize. Si el plano se expande en el callback, será encogido de nuevo por el widget. El parámetro int indica la distancia desde el elemento enfocado. Si el parámetro es negativo, el elemento está antes del elemento enfocado; un parámetro positivo implica que el elemento sigue al elemento enfocado; el elemento enfocado en sí mismo recibe cero.

nctree_goto, nctree_add y nctree_del usan el concepto de ruta. Una ruta es un array de valores unsigned, terminado por UINT_MAX, con cada valor sucesivo indexando en la jerarquía hasta ese momento. El nodo raíz del nctree siempre tiene una ruta de 2 elementos: [0, UINT_MAX].

VALORES DE RETORNO

nctree_create retorna NULL para opciones inválidas. Esto incluye un campo items o nctreecb NULL, o un campo count cero.

nctree_next y nctree_prev ambos retornan el puntero curry del elemento recién enfocado. nctree_focused retorna el puntero curry del elemento ya enfocado.

nctree_goto retorna el puntero curry del elemento recién enfocado. Si path es inválido, el primer nivel de jerarquía inválido se escribe en failpath y se retorna NULL. Si path es válido, el valor -1 se escribe en failpath. Dado que es posible que un puntero curry sea NULL, se debe verificar failpath antes de asumir que la operación falló.

nctree_add y nctree_del ambos retornan -1 para una path inválida, y 0 en caso contrario.

NOTAS

nctree comparte muchas propiedades con notcurses_reel. A diferencia de este último, los nctrees soportan niveles jerárquicos arbitrarios.

nctree solía manejar solo datos estáticos, pero nctree_add y nctree_del se agregaron en Notcurses 3.0.1.
