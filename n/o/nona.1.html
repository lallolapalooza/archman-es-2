NOMBRE

nona - Unir una imagen panorámica

SINOPSIS

nona [opciones] -o archivo_salida archivo_proyecto (archivos de imagen)

DESCRIPCIÓN

nona utiliza la función de transformación de PanoTools, la unión en sí es bastante simple, no se realiza ningún desvanecimiento de costuras.

Solo se admiten los interpoladores de PanoTools que no son antialiasing.

Los siguientes formatos de salida (opción n de la línea de script p de PanoTools) son compatibles:

JPEG, TIFF, PNG: Formatos de imagen única sin mezcla desvanecida
JPEG_m, TIFF_m, PNG_m: múltiples archivos tiff
TIFF_multilayer: Archivos tiff multilapa, legibles por The Gimp 2.0

OPCIONES

Opciones generales:

-c
Crear imágenes de coordenadas (solo salida TIFF_m)
-v
Silencioso, no mostrar indicadores de progreso
-d
Mostrar salida detallada para el procesamiento de la GPU
-g
Realizar el remapeo de la imagen en la GPU

Las siguientes opciones se pueden utilizar para anular la configuración en el archivo de proyecto:

-i num
Remapear solo la imagen con el número num (se puede especificar varias veces)
-m str
Establecer el formato del archivo de salida (TIFF, TIFF_m, TIFF_multilayer, EXR, EXR_m, JPEG, JPEG_m, PNG, PNG_m)
-r ldr/hdr
Establecer el modo de salida:
ldr - mantener la profundidad de bits y la respuesta originales
hdr - fusionar a hdr
-e exposicion
Establecer la exposición para el modo ldr
-p TIPO
Tipo de píxel de la salida. Puede ser uno de:
UINT8 entero sin signo de 8 bits
UINT16 entero sin signo de 16 bits
INT16 entero con signo de 16 bits
UINT32 entero sin signo de 32 bits
INT32 entero con signo de 32 bits
FLOAT punto flotante de 32 bits
-z|--compression
Establecer el tipo de compresión. Opciones posibles para la salida tiff:
NONE sin compresión
PACKBITS compresión packbits
LZW compresión LZW
DEFLATE compresión deflate
Para la salida JPEG, establecer el número de calidad
--ignore-exposure
No corregir la exposición. (Esto no funciona con el modificador -e)
--save-intermediate-images
Guarda también las imágenes intermedias (solo cuando la salida es TIFF, PNG o JPEG)
--intermediate-suffix=SUFIJO
Sufijo para las imágenes intermedias
--create-exposure-layers
Crear todas las capas de exposición (esto siempre usará TIFF)
--clip-exposure[=corte inferior:corte superior]
Enmascarar automáticamente todos los píxeles oscuros y brillantes. Opcionalmente, puede especificar los límites para el corte inferior y superior (especificar en el rango 0...1, relativo al rango completo)
