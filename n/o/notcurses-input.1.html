NOMBRE

notcurses-input - Lee y muestra eventos de entrada

SINOPSIS

notcurses-input [-v] [-m]

DESCRIPCIÓN

notcurses-input lee desde stdin y decodifica la entrada a stdout, incluyendo eventos sintetizados y eventos del ratón. Para salir, genera EOF (normalmente Ctrl+'d').

Cada evento se imprimirá en una línea única. Liderando esa línea hay una serie de indicadores de modificadores:

•
'A'/'a': Se presionó o no se presionó Alt.
•
'C'/'c': Se presionó o no se presionó Ctrl.
•
'S'/'s': Se presionó o no se presionó Shift.
•
'U'/'u': Se presionó o no se presionó Super
•
'M'/'m': Se presionó o no se presionó Meta.
•
'H'/'h': Se presionó o no se presionó Hyper.
•
'X'/'x': Se activó o no Bloq Mayús.
•
'#'/'.': Se activó o no Bloq Num.
•
'L'/'R'/'P'/'u': La tecla fue una liberación, repetición, pulsación, o de tipo desconocido.

Por defecto, los eventos del ratón están habilitados.

OPCIONES

-v: Aumenta la verbosidad. -m: Inhibe los eventos del ratón.

NOTAS

Los eventos del ratón solo se generan para pulsaciones y liberaciones de botones, y para el movimiento mientras un botón está mantenido presionado.
