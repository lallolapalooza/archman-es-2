notcurses_metric(3)

Paquete: notcurses

Licencias: Apache

notcurses_metric(3) Manual de Funciones de Biblioteca notcurses_metric(3)

NOMBRE

notcurses_metric - salida numérica de ancho fijo con sufijos métricos

SINOPSIS

#include <notcurses/notcurses.h>

#define NCPREFIXCOLUMNS 7
#define NCIPREFIXCOLUMNS 8
#define NCBPREFIXCOLUMNS 9
#define NCPREFIXSTRLEN (NCPREFIXCOLUMNS + 1)
#define NCIPREFIXSTRLEN (NCIPREFIXCOLUMNS + 1)
#define NCBPREFIXSTRLEN (NCBPREFIXCOLUMNS + 1)
#define NCMETRICFWIDTH(x, cols) ((int)(strlen(x) - ncstrwidth(x) + (cols)))
#define NCPREFIXFMT(x) NCMETRICFWIDTH((x), NCPREFIXCOLUMNS), (x)
#define NCIPREFIXFMT(x) NCMETRIXFWIDTH((x), NCIPREFIXCOLUMNS), (x)
#define NCBPREFIXFMT(x) NCMETRICFWIDTH((x), NCBPREFIXCOLUMNS), (x)

const char* ncnmetric(uintmax_t val, size_t s, uintmax_t decimal, char* buf, int omitdec, unsigned mult, int uprefix);

static inline const char* ncqprefix(uintmax_t val, uintmax_t decimal, char* buf, int omitdec);

static inline const char* nciprefix(uintmax_t val, uintmax_t decimal, char* buf, int omitdec);

static inline const char* ncbprefix(uintmax_t val, uintmax_t decimal, char* buf, int omitdec);

DESCRIPCIÓN

ncnmetric (y las funciones auxiliares nc[qib]prefix) aceptan enteros no negativos muy grandes (o muy pequeños) y preparan una salida formateada de ancho máximo utilizando sufijos métricos. El sufijo puede representar cantidades arbitrarias de crecimiento, pero está diseñado para 1000 (NCPREFIX) o 1024 (NCIPREFIX). 1024 se utiliza para "unidades digitales de información", es decir, kibibytes y gibibits. ncnmetric soporta los sufijos grandes KMGTPEZY (Kilo, Mega, Giga, Tera, Peta, Exa, Zetta y Yotta) y los sufijos pequeños mμnpfazy (mili, micro, nano, pico, femto, atto, zepto y yocto). Esto cubre el rango de 1e24 (un septillón) a 1e-24, suficiente para todos los valores posibles de un uintmax_t de 64 bits.

val es el valor que se está mostrando, escalado por decimal. decimal será típicamente 1; para representar valores menores que 1, decimal debe ser mayor que val. La salida se escribirá en buf, que debe ser al menos:

•
NCPREFIXSTRLEN + 1 bytes para un valor basado en 1000
•
NCIPREFIXSTRLEN + 1 bytes para un valor basado en 1024
•
NCBPREFIXSTRLEN + 1 bytes para un valor basado en 1024 con un sufijo 'i'

s es el tamaño máximo de salida, incluyendo '\0', utilizado de la misma manera que snprintf(3) (que es llamado por ncnmetric).

Se proporcionan tres funciones auxiliares para simplificar estos casos comunes:

// Mega, kilo, gigafoo. Usa NCPREFIXSTRLEN + 1 y NCPREFIXCOLUMNS.
static inline const char*
ncqprefix(uintmax_t val, uintmax_t decimal, char* buf, int omitdec){
  return ncnmetric(val, decimal, buf, omitdec, 1000, '\0');
}
// Mibi, kebi, gibibytes sin sufijo 'i'. Usa NCIPREFIXSTRLEN + 1.
static inline const char*
nciprefix(uintmax_t val, uintmax_t decimal, char* buf, int omitdec){
  return ncnmetric(val, decimal, buf, omitdec, 1024, '\0');
}
// Mibi, kebi, gibibytes. Usa NCBPREFIXSTRLEN + 1 y NCBPREFIXCOLUMNS.
static inline const char*
ncbprefix(uintmax_t val, uintmax_t decimal, char* buf, int omitdec){
  return ncnmetric(val, decimal, buf, omitdec, 1024, 'i');
}

Si omitdec no es cero, el punto decimal y el mantisa se omitirán si todos los dígitos a mostrar serían cero. El punto decimal tiene en cuenta la configuración regional actual (ver setlocale(3) y localeconv(3)). mult es el múltiplo relativo para cada sufijo. uprefix, si no es cero, se usará como sufijo después de cualquier sufijo métrico.

El número máximo de columnas no está directamente relacionado con el número máximo de bytes, ya que Unicode no se mapea necesariamente a caracteres de un solo byte (incluido el sufijo 'μ' micro). Las definiciones correspondientes para la longitud máxima de columna son:

•
NCPREFIXCOLUMNS (7)
•
NCIPREFIXCOLUMNS (8)
•
NCBPREFIXCOLUMNS (9)

En general, la salida de ancho máximo tendrá la forma CCC.mmMu, donde C son dígitos de la característica (hasta ceil(log10(mult)) dígitos), el punto decimal sigue, m son dígitos de la mantisa (hasta 2), M es el sufijo métrico y u es el uprefix. La salida de ancho mínimo tendrá la forma C. Esta forma mínima puede ocurrir si omitdec no es cero y se pasa un valor de una sola columna como 5 para val.

Se proporcionan tres definiciones más para simplificar la salida formateada de ancho fijo utilizando los resultados de ncnmetric. Cada una de estas macros acepta un buffer de caracteres que contiene el resultado de la llamada, y se expanden a *dos* argumentos:

•
NCPREFIXFMT(x)
•
NCIPREFIXFMT(x)
•
NCBPREFIXFMT(x)

Estos se pueden usar en, por ejemplo, el siguiente torpe ejemplo:

**ncplane_printf(n, "%*s", NCPREFIXFMT(buf));**

para asegurar que la salida tenga siempre un ancho de NCPREFIXCOLUMNS.

VALORES DE RETORNO

NULL si los parámetros de entrada no eran válidos, o si notcurses_init no se ha llamado con éxito. De lo contrario, un puntero a buf, relleno con la salida formateada.

EJEMPLOS

ncnmetric(0, INT_MAX, buf, 0, 1000, '\0'): "0.00".

ncnmetric(0, INT_MAX, buf, 1, 1000, '\0'): "0".

ncnmetric(1023, INT_MAX, buf, 1, 1000, '\0'): "1.02K".

ncnmetric(1023, INT_MAX, buf, 1, 1024, 'i'): "1023".

ncnmetric(1024, INT_MAX, buf, 1, 1024, 'i'): "1Ki".

ncnmetric(4096, INT_MAX, buf, 0, 1024, 'i'): "4.00Ki".

ncnmetric(0x7fffffffffffffff, INT_MAX, buf, 0, 1000, '\0'): "9.22E".

ncnmetric(0xffffffffffffffff, INT_MAX, buf, 0, 1000, '\0'): "18.45E".

ERRORES

Esta función es difícil de entender y tiene demasiados argumentos.

Si UTF-8 está disponible, se usará 'μ' (U+00B5 SEÑAL DE MICRO) en lugar de 'u' (U+0075 LETRA LATINA PEQUEÑA U) para el prefijo 'micro-'. Esto se determina mediante notcurses_init/ncdirect_init. Una vez detectado UTF-8, se utiliza durante la vida del proceso. La alternativa requeriría aceptar una struct notcurses (y un cambio de API asociado).
