NOMBRE

notcurses-tester - Pruebas unitarias de Notcurses

SINOPSIS

notcurses-tester [-p datadir] [-lN]

DESCRIPCIÓN

notcurses-tester ejecuta las varias cientos de pruebas unitarias incluidas con Notcurses. Requiere varios archivos de datos instalados junto con Notcurses; si estos se encuentran en una ubicación irregular, proporcione -p.

OPCIONES

-p ruta: Busca archivos de datos en la ruta especificada.

-lN: Habilita diagnósticos/registros en el nivel N. N debe estar entre -1 y 7.

NOTAS

Las variables de entorno TERM y LANG válidas son necesarias para el correcto funcionamiento de notcurses-tester.
