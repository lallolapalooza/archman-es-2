NOMBRE

notcurses_selector - widget de alto nivel para seleccionar de un conjunto

SINÓPSIS

#include <notcurses/notcurses.h>

struct ncplane;
struct notcurses;
struct ncselector;
struct ncselector_item {
  const char* option;
  const char* desc;
};
typedef struct ncselector_options {
  const char* title; // el título puede ser NULL, inhibiendo el elevador
  const char* secondary; // secundario puede ser NULL
  const char* footer; // pie de página puede ser NULL
  struct ncselector_item* items; // elementos y descripciones iniciales
  // elemento predeterminado (seleccionado al inicio)
  unsigned defidx;
  // número máximo de opciones a mostrar a la vez
  unsigned maxdisplay;
  // opciones de estilo exhaustivas
  uint64_t opchannels;   // canales de opción
  uint64_t descchannels; // canales de descripción
  uint64_t titlechannels;// canales de título
  uint64_t footchannels; // canales secundarios y de pie de página
  uint64_t boxchannels;  // canales de borde
  uint64_t flags;        // campo de bits sobre NCSELECTOR_OPTION_*
} ncselector_options;

struct ncselector* ncselector_create(struct ncplane* n, const ncselector_options* opts);

int ncselector_additem(struct ncselector* n, const struct ncselector_item* item);

int ncselector_delitem(struct ncselector* n, const char* item);

const char* ncselector_selected(const struct ncselector* n);

struct ncplane* ncselector_plane(struct ncselector* n);

const char* ncselector_previtem(struct ncselector* n);

const char* ncselector_nextitem(struct ncselector* n);

bool ncselector_offer_input(struct ncselector* n, const ncinput* nc);

void ncselector_destroy(struct ncselector* n, char item);**

DESCRIPCIÓN

Un widget selector presenta una lista de elementos (posiblemente más de los que se pueden mostrar a la vez). Facilita la elección de cero o un elemento de la lista.

NOTAS

El ncplane n proporcionado a ncselector_create no debe ser NULL. Será redimensionado libremente por el nuevo ncselector y, por lo tanto, no puede ser el plano estándar. ncselector_selected devuelve la opción actualmente seleccionada. ncselector_additem y ncselector_delitem permiten agregar y eliminar elementos sobre la marcha (se puede proporcionar un conjunto estático de elementos en la llamada a ncselector_create). El plano subyacente se redimensionará según sea necesario para los cambios de elementos.

ncselector_nextitem y ncselector_previtem seleccionan la opción siguiente (abajo) o anterior (arriba), desplazándose si es necesario. Es seguro llamar a estas funciones incluso si no hay opciones presentes.

ncselector_plane devolverá el ncplane en el que se dibuja el widget.

Aunque el ncselector puede ser impulsado completamente por código cliente, la entrada se puede pasar a través de ncselector_offer_input para aprovechar los controles comunes. Manejará las flechas arriba y abajo, junto con Página arriba y Página abajo. Si el ratón está habilitado, se manejarán la rueda del ratón y los clics del ratón en las flechas de desplazamiento.

ncselector_destroy destruye el ncplane subyacente, al igual que ncselector_create en caso de cualquier error.

Como no existen banderas, la opción flags siempre debe ser 0.

VALORES DE RETORNO

ncselector_create devuelve NULL en caso de error, en cuyo caso el ncplane pasado es destruido.

ncselector_selected devuelve una referencia a la parte option del ncselector_item seleccionado. Si no hay elementos, devuelve NULL.

ncselector_previtem y ncselector_nextitem devuelven referencias a la parte option del ncselector_item recién seleccionado. Si no hay elementos, devuelven NULL.

VER TAMBIÉN
