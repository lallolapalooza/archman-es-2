notcurses_fade(3) Manual de funciones de la biblioteca notcurses_fade(3)

NOMBRE

notcurses_fade - desvanecer `ncplanes` dentro y fuera

SINOPSIS

#include <notcurses/notcurses.h>

struct ncfadectx;
// Llamado para cada delta realizado en un desvanecimiento sobre ncp. Si se devuelve algo que no sea 0,
// la operación de desvanecimiento cesa inmediatamente y ese valor se propaga. Si se proporciona y no es NULL,
// los desvanecedores no llamarán a notcurses_render() por sí mismos.
typedef int (*fadecb)(struct notcurses* nc, struct ncplane* ncp,
                      const struct timespec*, void* curry);

bool notcurses_canfade(const struct notcurses* nc);

int ncplane_fadeout(struct ncplane* n, const struct timespec* ts, fadecb fader, void* curry);

int ncplane_fadein(struct ncplane* n, const struct timespec* ts, fadecb fader, void* curry);

int ncplane_pulse(struct ncplane* n, const struct timespec* ts, fadecb fader, void* curry);

struct ncfadectx* ncfadectx_setup(struct ncplane* n);

int ncfadectx_iterations(const struct ncfadectx* nctx);

int ncplane_fadeout_iteration(struct ncplane* n, struct ncfadectx* nctx, int iter, fadecb fader, void* curry);

int ncplane_fadein_iteration(struct ncplane* n, struct ncfadectx* nctx, int iter, fadecb fader, void* curry);

void ncfadectx_free(struct ncfadectx* nctx);

DESCRIPCIÓN

ncplane_fadeout, ncplane_fadein y ncplane_pulse son APIs simples para desvanecer planos dentro y fuera. Los desvanecimientos requieren soporte de RGB o soporte de reprogramación de paleta de la terminal (el método RGB es preferido y se usará siempre que sea posible). El parámetro ts especifica la cantidad total de tiempo para la operación de desvanecimiento. La operación en sí es adaptable al tiempo (es decir, si se retrasa, omitirá iteraciones; si avanza demasiado rápido, dormirá).

Estos son envoltorios alrededor de la API más flexible ncfadectx. Cree un ncfadectx con ncfadectx_setup. El número de cambios de estado posibles (iteraciones) se puede acceder con ncfadectx_iterations. Un estado se puede alcanzar con ncplane_fadeout_iteration o ncplane_fadein_iteration. Finalmente, destruya el ncfadectx con ncfadectx_free.

VALORES DE RETORNO

ncplane_fadeout_iteration y ncplane_fadein_iteration propagarán cualquier valor de retorno distinto de cero del callback fader.

ERRORES

La reprogramación de paleta puede afectar a otros contenidos de la terminal de formas complejas. Esto no es un problema cuando se utiliza el método RGB.

VER TAMBIÉN

clock_nanosleep(2), notcurses(3), notcurses_plane(3)
