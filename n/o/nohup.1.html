NOHUP(1) Comandos de usuario NOHUP(1)

NOMBRE

nohup - ejecuta un comando inmune a cuelgues, con salida a un no-tty

SINOPSIS

nohup COMANDO [ARG]...
nohup OPCIÓN

DESCRIPCIÓN

Ejecuta COMANDO, ignorando las señales de cuelgue.

--help
muestra esta ayuda y sale
--version
muestra información de la versión y sale

Si la entrada estándar es una terminal, redirígela desde un archivo no legible. Si la salida estándar es una terminal, añádela a 'nohup.out' si es posible, a '$HOME/nohup.out' en caso contrario. Si el error estándar es una terminal, redirígelo a la salida estándar. Para guardar la salida en ARCHIVO, usa 'nohup COMANDO > ARCHIVO'.

Es posible que tu shell tenga su propia versión de nohup, que generalmente reemplaza a la versión descrita aquí. Consulta la documentación de tu shell para obtener detalles sobre las opciones que soporta.

Estatus de salida:

125
si el comando nohup en sí falla
126
si COMANDO se encuentra pero no se puede invocar
127
si COMANDO no se encuentra
-
el estatus de salida de COMANDO en caso contrario
