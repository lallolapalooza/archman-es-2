NOMBRE

nouveau - Driver de video NVIDIA

SINOPSIS

Section "Device"
  Identifier "nombredev"
  Driver "nouveau"
  ...
EndSection

DESCRIPCIÓN

nouveau es un driver de Xorg para tarjetas de video NVIDIA. El driver soporta aceleración 2D y proporciona soporte para las siguientes profundidades de framebuffer: (15,) 16 y 24. Se soportan visualizaciones TrueColor para estas profundidades.

DETALLES DE CONFIGURACIÓN

Por favor, consulta xorg.conf(5) para detalles generales de configuración. Esta sección solo cubre los detalles de configuración específicos de este driver.

El driver autodetecta el tipo de chipset y la cantidad de memoria de video presente para todos los chips.

Se soportan las siguientes Opciones del driver:

Option "HWCursor" "booleano"
Habilita o deshabilita el cursor de hardware. Por defecto: activado.
Option "AccelMethod" "cadena"
Especifica el método de aceleración. Uno de "none", o "exa". Por defecto: exa.
Option "NoAccel" "booleano"
Deshabilita o habilita la aceleración. Por defecto: la aceleración está habilitada.
Option "ShadowFB" "booleano"
Habilita o deshabilita el uso de la capa de framebuffer en sombra. Por defecto: desactivado.
Option "WrappedFB" "booleano"
Habilita o deshabilita wfb, solo afecta a nv50+. Útil para algunas configuraciones heredadas donde se percibe una alta latencia de renderizado. Por defecto: wfb está deshabilitado.
Option "GLXVBlank" "booleano"
Sincroniza clientes GLX a VBlank. Útil donde el tearing es un problema, perjudicial si la GPU no es lo suficientemente rápida para seguir la tasa de refresco del monitor. Por defecto: activado.
Option "ZaphodHeads" "cadena"
Especifica las salidas randr a usar con el modo zaphod para una instancia de driver particular. Si usas esta opción, debes usar esta opción para todas las instancias del driver.
Por ejemplo: Option "ZaphodHeads" "LVDS,VGA-0" asignará las salidas de xrandr LVDS y VGA-0 a esta instancia del driver.
Option "PageFlip" "booleano"
Habilita el page flipping de DRI2. Por defecto: activado.
Option "SwapLimit" "entero"
Establece el número máximo permitido de swaps pendientes en OpenGL de doble buffer para una ventana antes de que un cliente sea bloqueado.
Un valor de 1 corresponde a doble buffer. Un valor de 2 corresponde a triple buffer. Valores más altos pueden permitir una mayor tasa de frames, pero también aumentan el lag para aplicaciones interactivas, por ejemplo, juegos. Nouveau actualmente soporta de forma fiable un valor máximo de 2 en XOrg 1.12+. Se permite un ajuste máximo de 2 en servidores x más antiguos, pero romperá la conformidad con la especificación OML_sync_control de OpenML y causará el fallo de software que depende del comportamiento de tiempo de presentación correcto tal como se define en esa especificación.
Por defecto: 1.
Option "DRI" "entero"
Define el nivel máximo de DRI a habilitar. Los valores válidos son 2 o 3. La aceleración exa respetará el nivel máximo si es soportado. Por defecto: 2.
