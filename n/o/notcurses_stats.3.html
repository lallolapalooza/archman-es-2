NOMBRE

notcurses_stats - estadísticas de tiempo de ejecución de notcurses

SINOPSIS

#include <notcurses/notcurses.h>

typedef struct ncstats {
  // estadísticas puramente crecientes
  uint64_t renders;          // ejecuciones exitosas de ncpile_render()
  uint64_t writeouts;        // ejecuciones exitosas de ncpile_rasterize()
  uint64_t failed_renders;   // renders abortados, debería ser 0
  uint64_t failed_writeouts; // escrituras abortadas
  uint64_t raster_bytes;     // bytes emitidos a ttyfp
  int64_t raster_max_bytes;  // max bytes emitidos para un frame
  int64_t raster_min_bytes;  // min bytes emitidos para un frame
  uint64_t render_ns;        // nanosegundos gastados renderizando
  int64_t render_max_ns;     // max ns gastados para un frame
  int64_t render_min_ns;     // min ns gastados para un frame
  uint64_t raster_ns;        // nanosegundos gastados rasterizando
  int64_t raster_max_ns;     // max ns gastados en raster para un frame
  int64_t raster_min_ns;     // min ns gastados en raster para un frame
  uint64_t writeout_ns;      // ns gastados escribiendo frames al terminal
  int64_t writeout_max_ns;   // max ns gastados escribiendo un frame
  int64_t writeout_min_ns;   // min ns gastados escribiendo un frame
  uint64_t cellelisions;     // celdas elididas completamente
  uint64_t cellemissions;    // celdas emitidas
  uint64_t fgelisions;       // recuento de elisión de color FG RGB
  uint64_t fgemissions;      // emisiones de color FG RGB
  uint64_t bgelisions;       // recuento de elisión de color BG RGB
  uint64_t bgemissions;      // emisiones de color BG RGB
  uint64_t defaultelisions;  // se emitió el color predeterminado
  uint64_t defaultemissions; // se elidió el color predeterminado
  uint64_t refreshes;        // refrescos (redibujados no optimizados)
  uint64_t sprixelemissions; // recuento de dibujo de sprixel
  uint64_t sprixelelisions;  // recuento de elisión de sprixel
  uint64_t sprixelbytes;     // bytes de sprixel emitidos
  uint64_t appsync_updates;  // actualizaciones sincronizadas con la aplicación
  uint64_t input_events;     // eventos de entrada recibidos o sintetizados
  uint64_t input_errors;     // errores al procesar entrada
  uint64_t hpa_gratuitous;   // HPAs gratuitas emitidas
  uint64_t cell_geo_changes; // cambios de geometría de celda (redimensionamientos)
  uint64_t pixel_geo_changes;// cambios de geometría de píxel (redimensionamiento de fuente)
  // estado actual -- estos pueden disminuir
  uint64_t fbbytes;          // bytes dedicados a los framebuffers
  unsigned planes;           // planos actualmente en existencia
} ncstats;

ncstats* notcurses_stats_alloc(struct notcurses* nc);

void notcurses_stats(struct notcurses* nc, ncstats* stats);

void notcurses_stats_reset(struct notcurses* nc, ncstats* stats);

DESCRIPCIÓN

notcurses_stats_alloc asigna un objeto ncstats. Esto debe usarse en lugar de asignar el objeto en el código del cliente, para estar preparado ante posibles ampliaciones de la estructura en futuras versiones de Notcurses.

notcurses_stats adquiere una instantánea atómica de las estadísticas, principalmente relacionadas con notcurses_render(3). notcurses_stats_reset hace lo mismo, pero también reinicia todas las estadísticas acumulativas (las estadísticas inmediatas como fbbytes no se reinician).

renders es el número de llamadas exitosas a notcurses_render(3) o ncpile_render_to_buffer(3). failed_renders es el número de llamadas infructuosas a estas funciones. failed_renders debería ser 0; no se espera que los renders fallen excepto en circunstancias excepcionales. Si notcurses_render(3) falla al escribir un frame en el terminal, se cuenta como un render fallido.

raster_max_bytes y raster_min_bytes rastrean el número máximo y mínimo de bytes utilizados para rasterizar un frame. Un estado dado de Notcurses no se corresponde con un número único de bytes; el tamaño también depende del estado actual del terminal. Como primera aproximación, el tiempo que un terminal tarda en procesar y reflejar un frame depende del tamaño del frame rasterizado.

render_ns, render_max_ns y render_min_ns rastrean la cantidad total de tiempo invertido en renderizar frames en nanosegundos. El renderizado tiene lugar en ncpile_render (llamado por notcurses_render(3) y ncpile_render_to_buffer). Este paso es independiente del terminal.

raster_ns, raster_max_ns y raster_min_ns rastrean la cantidad total de tiempo invertido en rasterizar frames en nanosegundos. La rasterización tiene lugar en ncpile_raster (llamado por notcurses_raster(3) y ncpile_render_to_buffer). Este paso depende de las definiciones del terminal. El mismo frame podría no rasterizarse en los mismos bytes para diferentes terminales.

writeout_ns, writeout_max_ns y writeout_min_ns rastrean la cantidad total de tiempo invertido en escribir frames al terminal. Esto tiene lugar en ncpile_rasterize (llamado por notcurses_render(3)).

cellemissions refleja el número de EGC escritos en el terminal. cellelisions refleja el número de celdas que no fueron escritas, debido a la detección de daños.

refreshes es el número de veces que notcurses_refresh se ha ejecutado correctamente.

fbbytes es el número total de bytes dedicados a los framebuffers en todo el contexto de struct notcurses. planes es el número de planos en el contexto. Ninguna de estas estadísticas puede llegar a 0, debido al plano estándar obligatorio.

sprixelemissions es el número de dibujos de sprixel. sprixelelisions es el número de veces que un sprixel fue elidido, esencialmente, el número de veces que un sprixel apareció en un frame renderizado sin dibujarlo de nuevo. sprixelbytes es el número de bytes utilizados para el dibujo de sprixel. No incluye operaciones de movimiento/eliminación, ni glifos utilizados para borrar sprixels.

input_errors es el número de errores al procesar la entrada, por ejemplo, secuencias de control mal formadas o UTF-8 inválido (ver utf8(7)).

hpa_gratuitous es el número de secuencias de control hpa (posición horizontal absoluta, ver terminfo(5)) emitidas donde no eran estrictamente necesarias. Esto se hace para hacer frente a ambigüedades fundamentales con respecto al ancho de los glifos. En general, no es posible saber cuán ancho será un glifo renderizado en una combinación dada de fuente, motor de renderizado de fuentes y terminal. De hecho, ni siquiera es posible saber cuántos glifos resultarán de una secuencia de EGC. Como resultado, Notcurses a veces emite controles hpa "gratuitos".

cell_geo_changes es el número de cambios en la geometría de celda del área visible. La geometría de celda cambia cada vez que el área visible se redimensiona sin un cambio correspondiente en la geometría celda-píxel. pixel_geo_changes es el número de cambios en la geometría de píxel de las celdas (es decir, la altura y el ancho de cada celda), y cambia cada vez que cambia el tamaño de la fuente. Ambos pueden cambiar al mismo tiempo si, por ejemplo, un terminal experimenta un cambio de tamaño de fuente sin cambiar su tamaño total.

NOTAS

Las operaciones de renderizado infructuosas no contribuyen a las estadísticas de tiempo de renderizado.

Los mapas de bits del framebuffer de Linux no se escriben a través del dispositivo de terminal, sino directamente en el framebuffer mapeado en memoria (ver mmap(2)). Los bytes utilizados para los gráficos del framebuffer son, por lo tanto, independientes de los bytes escritos en el terminal. Esto explica por qué sprixelbytes puede ser sorprendente dado el valor de raster_bytes.

VALORES DE RETORNO

Ni notcurses_stats ni notcurses_stats_reset pueden fallar. Ninguna devuelve valor. notcurses_stats_alloc devuelve un objeto ncstats válido en caso de éxito, o NULL en caso de fallo de asignación.

VER TAMBIÉN

mmap(2), notcurses(3), notcurses_render(3), terminfo(5), utf8(7)

NAME

notcurses_stats - retrieve statistics from notcurses

SYNOPSIS

#include <notcurses/notcurses.h>

    struct notcurses_stats *notcurses_stats_alloc(const struct notcurses *nc);
    void notcurses_stats_free(struct notcurses_stats *stats);
    int notcurses_stats_next(struct notcurses_stats *stats);
    enum notcurses_stats_field notcurses_stats_field(const struct notcurses_stats *stats);
    const char *notcurses_stats_name(const struct notcurses_stats *stats);
    int notcurses_stats_value(const struct notcurses_stats *stats);
    int notcurses_stats_set_value(struct notcurses_stats *stats, int val);
    int notcurses_stats_max_value(const struct notcurses_stats *stats);

DESCRIPTION

The notcurses(3) library makes available a number of statistics regarding its internal state. These statistics are intended to help in the debugging and optimization of notcurses applications.

A struct notcurses_stats object is allocated by notcurses_stats_alloc(3), which takes a pointer to the notcurses(3) context. This object is a cursor, that can be advanced using notcurses_stats_next(3). Each call to notcurses_stats_next(3) advances the cursor to the next statistic. The statistics are provided in a fixed order, and once notcurses_stats_next(3) has returned 0, all statistics have been iterated. It is not specified whether the statistics are available before any notcurses rendering has occurred.

The cursor is freed using notcurses_stats_free(3). The statistics available are enumerated by enum notcurses_stats_field. The functions notcurses_stats_field(3), notcurses_stats_name(3), notcurses_stats_value(3), notcurses_stats_set_value(3), and notcurses_stats_max_value(3) provide access to the current statistic under the cursor.

notcurses_stats_field returns the enum value for the current statistic.

notcurses_stats_name returns the C-string name of the current statistic. These names are not localized.

notcurses_stats_value returns the current value of the statistic. For most statistics, this is a count of some event. For others, it is a duration, in nanoseconds. The units are generally specified in the name of the statistic.

notcurses_stats_set_value sets the value of the current statistic to val. This is primarily intended for testing purposes, to manually inject specific statistic values. The return value is 0 on success, and -1 on failure. Not all statistics can be set.

notcurses_stats_max_value returns the maximum value achieved by the statistic since the creation of the struct notcurses_stats object. This is only meaningful for statistics that increment over time. For statistics that are reset, this value is meaningless.

Statistics are available for:

  • Input event processing.
  • Rendering operations.
  • Buffer manipulation.
  • Event queue depth.
  • Input queue depth.
  • Subpixel rendering statistics.
  • Terminal capabilities usage.
  • The timing of various internal operations.

The exact list of available statistics is subject to change between notcurses(3) versions.

NOTES

The statistics are only meaningful when collected over a period of time. A single call to notcurses_stats_next(3) will likely return 0 for most statistics.

The order of statistics is stable between runs of the same notcurses(3) version.

RETURN VALUES

Functions returning int return 0 on success, and -1 on failure, unless otherwise noted. Functions returning a pointer return NULL on failure.
