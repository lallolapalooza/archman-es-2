NOLOGIN(8) Administración del Sistema NOLOGIN(8)

NOMBRE

nologin - rechaza cortésmente un inicio de sesión

SINOPSIS

nologin [-V] [-h]

DESCRIPCIÓN

nologin muestra un mensaje indicando que una cuenta no está disponible y sale con un valor distinto de cero. Está diseñado como un campo de shell de reemplazo para denegar el acceso de inicio de sesión a una cuenta.

Si el archivo /etc/nologin.txt existe, nologin muestra su contenido al usuario en lugar del mensaje predeterminado.

El estado de salida devuelto por nologin es siempre 1.

OPCIONES

-c, --command comando

--init-file

-i --interactive

--init-file archivo

-i, --interactive

-l, --login

--noprofile

--norc

--posix

--rcfile archivo

-r, --restricted

Estas opciones de línea de comandos del shell se ignoran para evitar errores en nologin.

-h, --help

Muestra el texto de ayuda y sale.

-V, --version

Muestra la versión y sale.

NOTAS

nologin es una forma por cuenta de deshabilitar el inicio de sesión (generalmente utilizado para cuentas del sistema como http o ftp). nologin utiliza /etc/nologin.txt como fuente opcional para un mensaje no predeterminado, el acceso de inicio de sesión siempre se rechaza independientemente del archivo.

El módulo PAM pam_nologin(8) generalmente evita que todos los usuarios que no sean root inicien sesión en el sistema. La funcionalidad de pam_nologin(8) se controla mediante /var/run/nologin o el archivo /etc/nologin.

HISTORIA

El comando nologin apareció en 4.4BSD.
