NOMBRE

notmuch-restore - restaura las etiquetas del archivo dado (ver notmuch dump)

SINOPSIS

notmuch restore [--accumulate] [--format=(auto|batch-tag|sup)] [--input=<nombre_archivo>]

DESCRIPCIÓN

Restaura las etiquetas del archivo dado (ver notmuch-dump).

La entrada se lee del nombre de archivo dado, si existe, o de la entrada estándar.

Las opciones admitidas para restore incluyen

--accumulate
Se aplica la unión de las etiquetas existentes y nuevas, en lugar de reemplazar las etiquetas de cada mensaje a medida que se leen del archivo de volcado.
--format=(sup|batch-tag|auto)
Notmuch restore admite dos formatos de volcado de texto plano, con cada línea especificando un id de mensaje y un conjunto de etiquetas. Para detalles de los formatos reales, ver notmuch-dump.
sup
El formato de archivo de volcado sup se elige específicamente para ser compatible con el formato de los archivos producidos por sup-dump. Por lo tanto, si anteriormente ha estado utilizando sup para el correo, el comando notmuch restore le proporciona una forma de importar todas sus etiquetas (o etiquetas como las llama sup).
batch-tag
El formato de volcado batch-tag está diseñado para ser más robusto frente a ids de mensaje malformados y etiquetas que contienen espacios en blanco o caracteres que no son de ascii(7). Ver notmuch-dump para obtener detalles sobre este formato.

notmuch restore actualiza las marcas de maildir según los cambios de etiquetas si la opción de configuración maildir.synchronize_flags está habilitada. Ver notmuch-config para más detalles.

auto
Esta opción (la predeterminada) intenta adivinar el formato a partir de la entrada. Para una entrada correctamente formada en cualquiera de los formatos admitidos, esta heurística, basada en el hecho de que el formato batch-tag no contiene paréntesis, debería ser precisa.
--include=(config|properties|tags)
Controla qué tipo de metadatos se restauran.
config
Restaura datos de configuración en la base de datos. Cada línea de configuración comienza con "#@ ", seguido de un par clave-valor separado por espacios. Tanto la clave como el valor se codifican en hexadecimal si es necesario.
properties
Restaura metadatos (clave,valor) por mensaje. Cada línea comienza con "#= ", seguido de un id de mensaje y una lista separada por espacios de pares clave=valor. Los ids, claves y valores se codifican en hexadecimal si es necesario. Ver notmuch-properties para más detalles.
tags
Restaura metadatos por mensaje, específicamente etiquetas. Ver format arriba para más detalles.

El valor predeterminado es restaurar todos los tipos de datos disponibles. La opción se puede especificar varias veces para seleccionar algún subconjunto.

--input=<nombre_archivo>
Lee la entrada del archivo dado en lugar de la entrada estándar.
