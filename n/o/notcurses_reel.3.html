NOMBRE

notcurses_reel - widget de alto nivel para datos jerárquicos

SINOPSIS

#include <notcurses/notcurses.h>

#define NCREEL_OPTION_INFINITESCROLL 0x0001
#define NCREEL_OPTION_CIRCULAR       0x0002
struct ncreel;
struct ncplane;
struct nctablet;
typedef struct ncreel_options {
  // notcurses puede dibujar un borde alrededor del ncreel, y también
  // alrededor de las tabletas componentes. inhibir bordes estableciendo todos
  // los bits válidos en las máscaras. inhibir bordes parcialmente estableciendo
  // bits individuales en las máscaras. los valores de attr y pair apropiados
  // se usarán para dar estilo a los bordes. las tabletas enfocadas y
  // las no enfocadas pueden tener estilos diferentes. puedes en su lugar
  // dibujar tus propios bordes, o prescindir de ellos por completo.
  unsigned bordermask; // campo de bits; los 1s no se dibujarán
  uint64_t borderchan; // atributos usados para el borde del ncreel
  unsigned tabletmask; // campo de bits para bordes de tabletas
  uint64_t tabletchan; // canal de estilo de borde de tableta
  uint64_t focusedchan;// canal de estilo de borde de tableta enfocada
  uint64_t flags;      // campo de bits sobre NCREEL_OPTION_*
} ncreel_options;

struct ncreel* ncreel_create(struct ncplane* nc, const ncreel_options* popts);

struct ncplane* ncreel_plane(struct ncreel* nr);

typedef int (tabletcb)(struct nctablet t, bool cliptop);

struct nctablet* ncreel_add(struct ncreel* nr, struct nctablet* after, struct nctablet* before, tabletcb cb, void* opaque);

int ncreel_tabletcount(const struct ncreel* nr);

int ncreel_del(struct ncreel* nr, struct nctablet* t);

int ncreel_redraw(struct ncreel* nr);

struct nctablet* ncreel_focused(struct ncreel* nr);

struct nctablet* ncreel_next(struct ncreel* nr);

struct nctablet* ncreel_prev(struct ncreel* nr);

bool ncreel_offer_input(struct ncreel* nr, const ncinput* ni);

void ncreel_destroy(struct ncreel* nr);

void* nctablet_userptr(struct nctablet* t);

struct ncplane* nctablet_plane(struct nctablet* t);

DESCRIPCIÓN

Un ncreel es un widget para la visualización y manipulación de datos jerárquicos, destinado a hacer un uso efectivo del área de visualización mientras soporta teclados, ratones e interfaces hápticas. Una serie de nctablets se ordenan en un cilindro virtual; las tabletas pueden crecer y encogerse libremente. Moverse entre las tabletas hace "girar" el cilindro. Los ncreel soportan bordes opcionales alrededor del reel y/o las tabletas.

ncreel_redraw organiza las tabletas, invocando el tabletcb definido por cada una. Invocará las callbacks solo de aquellas tabletas actualmente visibles. Esta función debería ser llamada siempre que los datos dentro de una tableta necesiten ser refrescados. El valor de retorno de esta callback es el número de líneas dibujadas en el ncplane. La tableta se ampliará o reducirá según sea necesario para reflejar este valor de retorno.

A menos que el reel esté desprovisto de tabletas, siempre hay una tableta "enfocada" (la primera tableta añadida a un reel vacío se convierte en enfocada). La tableta enfocada puede cambiar a través de ncreel_next y ncreel_prev. Si se llama a ncreel_del en la tableta enfocada, y queda al menos otra tableta, alguna tableta recibe el foco.

Llamar a funciones que cambian el reel, incluyendo ncreel_next, ncreel_prev, ncreel_del y ncreel_add, llama implícitamente a ncreel_redraw. Este comportamiento no debe ser confiado, ya que es probable que desaparezca.

DISEÑO

Cuando el usuario invoca ncreel_redraw, Notcurses no puede asumir que conoce el tamaño de ninguna tableta; una o más podrían haber cambiado desde el último dibujo. Solo después de una callback, ncreel_redraw sabe cuántas filas ocupará una tableta.

Una operación de redibujo comienza con la tableta enfocada. Su callback se invoca con un plano tan grande como el reel, es decir, la tableta enfocada puede ocupar todo el reel, excluyendo cualquier otra tableta. La tableta enfocada se mantendrá donde estaba, si es posible; el crecimiento podría obligarla a moverse. Ahora hay una tableta fijada en su lugar, y cero, una o dos áreas de espacio vacío. Las tabletas se disponen sucesivamente en estos espacios hasta que el reel se llena.

En general, si el reel no está lleno, las tabletas se dibujarán hacia arriba, pero en esto no se debe confiar.

LA CALLBACK DE TABLETA

La callback de tableta (de tipo tabletcb) se llama con un ncplane y un bool. La función callback no debería confiar en la posición absoluta del plano, ya que podría ser movido. El bool indica si el plano debe ser rellenado desde abajo o desde arriba (esto solo es significativo si el plano es insuficientemente grande para contener todos los datos disponibles de la tableta). La callback no debe redimensionar el plano (será redimensionado tras el retorno). La callback debe devolver el número de filas utilizadas (es perfectamente válido usar cero filas), o un número negativo si hubo un error.

Devolver más filas que las disponibles en el plano es un error.

VALORES DE RETORNO

ncreel_focused, ncreel_prev y ncreel_next devuelven la tableta enfocada, a menos que no existan tabletas, en cuyo caso devuelven NULL.

ncreel_add devuelve la nctablet recién añadida.

ERRORES

No puedo decidir si debo exigir al usuario que llame explícitamente a ncreel_redraw. Hacerlo significa que los cambios se pueden agrupar sin un redibujo, pero también complica las cosas tanto para mí como para el usuario.
