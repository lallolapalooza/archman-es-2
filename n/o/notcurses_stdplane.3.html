NOMBRE

notcurses_stdplane - adquirir el ncplane estándar

SINOPSIS

#include <notcurses/notcurses.h>

struct ncplane* notcurses_stdplane(struct notcurses* nc);

const struct ncplane* notcurses_stdplane_const(const struct notcurses* nc);

static inline struct ncplane* notcurses_stddim_yx(struct notcurses* nc, unsigned* restrict y, unsigned* restrict x);

static inline const struct ncplane* notcurses_stddim_yx_const(const struct notcurses* nc, unsigned* restrict y, unsigned* restrict x);

int notcurses_enter_alternate_screen(struct notcurses* nc);

int notcurses_leave_alternate_screen(struct notcurses* nc);

DESCRIPCIÓN

notcurses_stdplane devuelve un manejador para el ncplane estándar del contexto nc. El plano estándar siempre existe y tiene siempre el mismo tamaño que la pantalla. Es un error llamar a ncplane_destroy(3), ncplane_resize(3), o ncplane_move(3) sobre el plano estándar, pero se puede mover libremente a lo largo del eje z.

El cursor virtual del plano estándar se inicializa en su celda más arriba y más a la izquierda, a menos que se proporcione NCOPTION_PRESERVE_CURSOR (ver notcurses_init(3)), en cuyo caso se colocará dondequiera que estuviera el cursor real del terminal al arrancar.

notcurses_stddim_yx proporciona la misma función, pero además escribe las dimensiones del plano estándar (y por lo tanto el área realmente dibujable) en cualquier parámetro no NULL entre y y x.

notcurses_stdplane_const permite que un const notcurses se utilice de forma segura.

Un evento de redimensionamiento no invalida estas referencias. Se pueden utilizar hasta que se llame a notcurses_stop(3) en el nc asociado.

notcurses_enter_alternate_screen y notcurses_leave_alternate_screen solo tienen significado si el terminal implementa la "pantalla alternativa" a través de las capacidades smcup y rmcup de terminfo(5) (ver la discusión de NCOPTION_NO_ALTERNATE_SCREEN en notcurses_init(3)). Si no se está utilizando actualmente la pantalla alternativa, y suponiendo que es compatible, notcurses_enter_alternate_screen cambiará a la pantalla alternativa. Esto redibuja el contenido, reposiciona el cursor y generalmente hace que el desplazamiento (scrollback) no esté disponible. El plano estándar tendrá el desplazamiento deshabilitado al pasar a la pantalla alternativa.

VALORES DE RETORNO

notcurses_enter_alternate_screen devolverá -1 si la pantalla alternativa no está disponible. Tanto esta función como notcurses_leave_alternate_screen devolverán -1 en caso de fallo de E/S.

Otras funciones no pueden fallar cuando se les proporciona un struct notcurses válido. Siempre devolverán un puntero válido al plano estándar.

VER TAMBIÉN

notcurses(3), notcurses_init(3), notcurses_plane(3), notcurses_stop(3), terminfo(5)
