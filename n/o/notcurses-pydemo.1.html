NOMBRE

notcurses-pydemo - Verifica que los envoltorios de Python de notcurses funcionan

SINOPSIS

notcurses-pydemo

DESCRIPCIÓN

notcurses-pydemo genera una salida estilizada en la terminal conectada utilizando el módulo de Python notcurses. Esta salida es un medio mínimo para verificar que el módulo está correctamente instalado y puede ser utilizado en el entorno actual.

Para una demostración más completa, consulta notcurses-demo(1).

OPCIONES

NOTAS

Notcurses solo admite Python 3.
