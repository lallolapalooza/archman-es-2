NOMBRE

notcurses_reader - widget de alto nivel para recopilar entrada

SINOPSIS

#include <notcurses/notcurses.h>

struct ncplane;
struct ncreader;
struct notcurses;
#define NCREADER_OPTION_HORSCROLL 0x0001
#define NCREADER_OPTION_VERSCROLL 0x0002
#define NCREADER_OPTION_NOCMDKEYS 0x0004
#define NCREADER_OPTION_CURSOR    0x0008
typedef struct ncreader_options {
  uint64_t tchannels; // canales usados para entrada
  uint32_t tattrword; // atributos usados para entrada
  uint64_t flags;     // campo de bits sobre NCREADER_OPTION_*
} ncreader_options;

struct ncreader* ncreader_create(struct notcurses* nc, const ncreader_options* opts);

int ncreader_clear(struct ncreader* n);

struct ncplane* ncreader_plane(struct ncreader* n);

int ncreader_move_left(struct ncreader* n);

int ncreader_move_right(struct ncreader* n);

int ncreader_move_up(struct ncreader* n);

int ncreader_move_down(struct ncreader* n);

int ncreader_write_egc(struct ncreader* n, const char* egc);

bool ncreader_offer_input(struct ncreader* n, const ncinput* ni);

char* ncreader_contents(const struct ncreader* n);

void ncreader_destroy(struct ncreader* n, char contents);**

DESCRIPCIÓN

El widget ncreader soporta entrada libre, multilínea. Soporta navegación con las teclas de flecha y desplazamiento. Mientras que la porción visible del ncreader siempre tiene el mismo tamaño (definido por el ncplane proporcionado), el texto real que soporta esta región visible puede crecer arbitrariamente si el desplazamiento está habilitado.

Se admiten las siguientes banderas de opciones:

•
NCREADER_OPTION_HORSCROLL: El área visual estará respaldada por un plano que puede crecer arbitrariamente en ancho.
•
NCREADER_OPTION_VERSCROLL: El área visual estará respaldada por un plano que puede crecer arbitrariamente en altura.
•
NCREADER_OPTION_NOCMDKEYS: Los atajos de teclado típicos (ver abajo) no serán honrados.
•
NCREADER_OPTION_CURSOR: El cursor de la terminal se hará visible durante la vida del ncreader, y su ubicación será gestionada.

El contenido del ncreader se puede recuperar con ncreader_contents.

El ncreader consta de al menos un ncplane (el área de edición visible). Si el ncreader soporta desplazamiento, constará de dos ncplanes, uno de los cuales se mantendrá fuera del área de renderizado (y por lo tanto será invisible). ncreader_plane siempre devuelve el plano visible.

ncreader_clear descarta toda la entrada del ncreader, restaurándolo a la misma condición prístina en la que fue devuelto por ncreader_create.

A diferencia de los manejadores de entrada de la mayoría de los widgets, ncreader_offer_input consumirá la mayoría de las entradas. Las teclas de flecha navegan. Retroceso consume el EGC a la izquierda del cursor, si existe. Intro salta a la primera columna de la siguiente línea (si el cursor ya está en la última línea, el plano debe tener el desplazamiento habilitado, o el cursor no avanzará, aunque Intro aún se consumirá). De lo contrario, la mayoría de las entradas se reproducirán en el ncreader (aunque ver NOTAS a continuación).

Todo el contenido del ncreader se devuelve de ncreader_contents, conservando los espacios en blanco.

Los atajos de teclado "estilo Emacs", similares a los soportados por readline(3) y la mayoría de los shells, se admiten a menos que se proporcione NCREADER_OPTION_NOCMDKEYS a ncreader_create.

NOTAS

El soporte para NCREADER_OPTION_VERSCROLL aún no está implementado.

ncreader no almacena en búfer las entradas para ensamblar EGCs a partir de ellas. Si las entradas se van a procesar como EGCs (como debería ser), el llamador tendría que ensamblar los clústeres de grafemas. Por supuesto, todavía no existe ninguna API a través de la cual se puedan suministrar EGCs multipunto a ncreader.

Todavía no hay soporte para el ajuste de palabras. Esto probablemente vendrá en el futuro.
