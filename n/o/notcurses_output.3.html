DESCRIPCIÓN

Estas funciones escriben Clústeres de Grafemas Extensos (EGC) en los struct ncplane especificados. Se admiten las siguientes entradas:

•
ncplane_putc(): escribe una sola nccell (ver notcurses_cell(3))
•
ncplane_putchar(): escribe un solo carácter ASCII de 7 bits
•
ncplane_putwc(): escribe un solo wchar_t (siguiendo la conversión UTF-8)
•
ncplane_putwegc(): escribe un solo EGC de una matriz de wchar_t
•
ncplane_putegc(): escribe un solo EGC de una matriz UTF-8
•
ncplane_putstr(): escribe un conjunto de EGCs de una matriz UTF-8
•
ncplane_putwstr(): escribe un conjunto de EGCs de una matriz de wchar_t
•
ncplane_vprintf(): salida formateada usando va_list
•
ncplane_printf(): salida formateada usando argumentos variádicos
•
ncplane_puttext(): texto multilínea, con saltos de línea, alineado

Todas estas funciones utilizan el estilo activo del ncplane, excepto notcurses_putc(), que utiliza el estilo de la nccell. Las funciones que aceptan un solo EGC esperan una serie de wchar_t terminada por L'\0' o una serie de char UTF-8 terminada por '\0'. El EGC debe estar bien formado y no contener saltos de clúster. Para obtener más información, consulte Unicode® Standard Annex #29. Las funciones que aceptan un conjunto de EGCs deben consistir en una serie de EGCs bien formados, separados por saltos de clúster, terminados por el terminador NUL apropiado.

Se rechazan los caracteres de control, a excepción de dos: una tabulación horizontal ('\t', 0x09) y un salto de línea ('\n', 0x0a) cuando el plano de salida está en modo de desplazamiento. Se rechazará un salto de línea fuera del modo de desplazamiento. Una tabulación avanzará hasta la siguiente parada de tabulación, rellenando el espacio intermedio con espacios. Las paradas de tabulación están separadas por ocho columnas, y el primer carácter de cada línea es una parada de tabulación.

Estas funciones escriben en la ubicación actual del cursor del ncplane. Aparte de ncplane_puttext(), no se mueven a la siguiente línea al alcanzar el extremo derecho del plano contenedor. Si no se puede mostrar todo el contenido, mostrarán tanto como sea posible.

Cada una de estas funciones base tiene dos formas adicionales:

•
ncplane_putc_aligned(), etc.: acepta una fila y un tipo de alineación
•
ncplane_putc_yx(), etc.: acepta una fila y columna

Si un parámetro posicional es -1, no se realizará ningún movimiento en ese eje. Pasar -1, -1 a, por ejemplo, ncplane_putc_yx() equivale a llamar a la forma base. Estas funciones se implementan moviendo el cursor y luego realizando la salida. Los dos pasos son atómicos en caso de éxito (no es posible que otro llamador mueva el cursor entre el momento en que se posiciona y el momento en que comienza la salida), y por lo tanto, estas funciones generalmente deberían preferirse a una llamada explícita a ncplane_cursor_move_yx().

DEVOLUCIONES

ncplane_cursor_move_yx() devuelve -1 en caso de error (coordenada inválida) o 0 en caso de éxito.

Para las funciones de salida, una devolución negativa indica un error en las entradas. De lo contrario, se devuelve el número de columnas de pantalla de salida. Es totalmente posible obtener una devolución corta, si no había espacio suficiente para generar todas las EGC.
