NOMBRE

nsm-legacy-gui - página del manual para nsm-legacy-gui Versión 1.6.1

DESCRIPCIÓN

nsm-legacy-gui - GUI FLTK para el 'New Session Manager'

Uso:

nsm-legacy-gui nsm-legacy-gui --help

OPCIONES

--help
Mostrar esta pantalla
--nsm-url url
Conectarse a un nsmd en ejecución [Ejemplo: osc.udp://miordenador.localdominio:38356/].
--
Todo lo que siga a -- se pasará a nsmd como opciones del servidor. Ver nsmd --help .

Por compatibilidad con versiones anteriores, este ejecutable también existe como enlace simbólico 'non-session-manager'

VER TAMBIÉN

La documentación completa de NSM se mantiene como un sitio html en tu directorio de documentación del sistema. Por ejemplo:
xdg-open file:///usr/share/doc/new-session-manager/index.html

La documentación también se puede encontrar en línea en https://new-session-manager.jackaudio.org
