NOTIFY-SEND(1) Comandos de usuario NOTIFY-SEND(1)

NOMBRE

notify-send - un programa para enviar notificaciones de escritorio

SINOPSIS

notify-send [OPCIONES] {resumen} [cuerpo]

DESCRIPCIÓN

Con notify-send puedes enviar notificaciones de escritorio al usuario a través de un demonio de notificaciones desde la línea de comandos. Estas notificaciones se pueden usar para informar al usuario sobre un evento o mostrar alguna forma de información sin interponerse en el camino del usuario.

OPCIONES

-?, --help

Muestra la ayuda y sale.

-a, --app-name=NOMBRE_APP

Especifica el nombre de la aplicación para la notificación.

-A, --action=[NOMBRE=]Texto...

Especifica las acciones a mostrar al usuario. Implica --wait para esperar la entrada del usuario. Puede establecerse varias veces. El NOMBRE de la acción se emite a la salida estándar. Si no se especifica NOMBRE, se utiliza el índice numérico de la opción (empezando por 1).

-u, --urgency=NIVEL

Especifica el nivel de urgencia (bajo, normal, crítico).

-t, --expire-time=TIEMPO

La duración, en milisegundos, para que la notificación aparezca en pantalla.

No todas las implementaciones utilizan este parámetro. GNOME Shell y Notify OSD lo ignoran siempre, mientras que Plasma lo ignora para notificaciones con el nivel de urgencia crítico.

-i, --icon=ICONO

Especifica un nombre de archivo de icono o un icono predefinido a mostrar.

-c, --category=TIPO[,TIPO...]

Especifica la categoría de la notificación.

-h, --hint=TIPO:NOMBRE:VALOR

Especifica datos adicionales básicos a pasar. Los tipos válidos son BOOLEAN, INT, DOUBLE, STRING, BYTE y VARIANT.

-p, --print-id

Imprime el ID de la notificación.

-r, --replace-id=ID_REEMPLAZAR

El ID de la notificación a reemplazar.

-w, --wait

Espera a que la notificación se cierre antes de salir. Si el expire-time está establecido, se utilizará como tiempo máximo de espera.

-e, --transient

Muestra una notificación transitoria. Las notificaciones transitorias omitirán la capacidad de persistencia del servidor, si la hubiera. Y por lo tanto, no se conservarán hasta que el usuario las reconozca.

VER TAMBIÉN

La especificación de notificaciones de escritorio en https://specifications.freedesktop.org/notification-spec/.
