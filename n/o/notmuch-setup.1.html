notmuch-setup(1)

NOTMUCH-SETUP(1) notmuch NOTMUCH-SETUP(1)

NOMBRE

notmuch-setup - primeros pasos con notmuch

SINOPSIS

notmuch [opción ...] comando [arg ...]

DESCRIPCIÓN

Notmuch es un programa basado en línea de comandos para indexar, buscar, leer y etiquetar grandes colecciones de mensajes de correo electrónico.

Esta página describe cómo empezar a usar notmuch desde la línea de comandos y ofrece una breve descripción general de los comandos disponibles. Para más información sobre, por ejemplo, notmuch show, consulte la página del manual notmuch-show, también accesible a través de notmuch help show

La forma más rápida de empezar con Notmuch es simplemente invocar el comando notmuch sin argumentos, lo que le guiará interactivamente a través del proceso de indexación de su correo.

NOTA

OPCIONES

Las opciones globales soportadas para notmuch incluyen:

--help [nombre-del-comando]
Imprime una sinopsis de los comandos disponibles y sale. Con un nombre de comando opcional, muestra la página del manual para ese subcomando.
--version
Imprime la versión instalada de notmuch y sale.
--config=ARCHIVO
Especifica el archivo de configuración a usar. Esto anula cualquier archivo de configuración especificado por NOTMUCH_CONFIG. La cadena vacía es un valor permitido y a veces útil de ARCHIVO, que indica a notmuch que utilice únicamente metadatos de configuración de la base de datos.
--uuid=HEX
Obliga a que el UUID de la base de datos (un identificador único que persiste hasta que la base de datos se compacta, por ejemplo) sea HEX; sale con un error si no lo es. Esto es útil para detectar cambios en los recuentos de modificación de mensajes. Puede encontrar este UUID usando, por ejemplo, notmuch count --lastmod

Todas las opciones globales, excepto --config, también pueden especificarse después del comando. Por ejemplo, notmuch subcomando --uuid=HEX es equivalente a notmuch --uuid=HEX subcomando.

COMANDOS

CONFIGURACIÓN

El comando notmuch setup se utiliza para configurar Notmuch para su primer uso (o para reconfigurarlo más tarde).

El comando de configuración le pedirá su nombre completo, su dirección de correo electrónico principal, cualquier dirección de correo electrónico alternativa que utilice y el directorio que contiene sus archivos de correo. Sus respuestas se escribirán en un archivo de configuración en NOTMUCH_CONFIG (si está establecido) o en ${HOME}/.notmuch-config . Este archivo de configuración se creará con comentarios descriptivos, lo que facilitará su edición manual posterior para cambiar la configuración. O puede ejecutar notmuch setup de nuevo para cambiar la configuración.

El directorio de correo que especifique puede contener cualquier número de subdirectorios y debe contener principalmente solo archivos con mensajes de correo electrónico individuales (por ejemplo, los archivos maildir o mh son perfectos). Si hay otros archivos no relacionados con el correo (como índices mantenidos por otros programas de correo), notmuch hará todo lo posible para detectarlos e ignorarlos.

Invocar notmuch sin ningún argumento de comando ejecutará setup si el comando setup no se ha completado previamente.

OTROS COMANDOS

Varios de los comandos de notmuch aceptan términos de búsqueda con una sintaxis común. Consulte notmuch-search-terms para obtener más detalles sobre la sintaxis admitida.

Los comandos notmuch-search, notmuch-show, notmuch-address y notmuch-count se utilizan para consultar la base de datos de correo electrónico.

El comando notmuch-reply es útil para preparar una plantilla para una respuesta de correo electrónico.

El comando notmuch-tag es el único comando disponible para manipular el contenido de la base de datos.

Los comandos notmuch-dump y notmuch-restore se pueden utilizar para crear un volcado textual de las etiquetas de correo electrónico con fines de copia de seguridad y para restaurar a partir de dicho volcado.

El comando notmuch-config se puede utilizar para obtener o establecer configuraciones en el archivo de configuración de notmuch.

COMANDOS EXTERNOS

Si el comando dado no es conocido por notmuch, notmuch intenta ejecutar el comando externo notmuch-<subcomando> en PATH en su lugar. Esto permite a los usuarios tener sus propias herramientas relacionadas con notmuch para ser ejecutadas a través del comando notmuch. Por diseño, esto no permite que los propios comandos de notmuch sean anulados mediante comandos externos. La variable de entorno NOTMUCH_CONFIG se establecerá de acuerdo con --config, si este último está presente.

ENTORNO

Las siguientes variables de entorno se pueden usar para controlar el comportamiento de notmuch.

NOTMUCH_CONFIG
Especifica la ubicación del archivo de configuración de notmuch. Consulte notmuch-config para obtener detalles.
NOTMUCH_DATABASE
Especifica la ubicación de la base de datos de notmuch. Consulte notmuch-config para obtener detalles.
NOTMUCH_PROFILE
Selecciona entre las configuraciones de notmuch. Consulte notmuch-config para obtener detalles.

NOTMUCH-SETUP.1

establece el entorno de notmuch

SYNOPSIS

notmuch setup [--key=file] [--email=email]

DESCRIPTION

notmuch setup es un script para ayudar a configurar el entorno de notmuch.

Actualmente, se utiliza para configurar los parámetros del cliente de correo PGP/MIME.

El script no realiza ninguna acción para los usuarios que ya tienen estos parámetros configurados.

El script primero intentará obtener la dirección de correo electrónico del usuario (el valor de user.email de la configuración de Git, si está disponible), y la clave de cifrado del usuario (buscando en la clave pública de GPG). Si la configuración de Git no está disponible, o si se proporciona el argumento --email, se utiliza el valor proporcionado por el argumento --email.

Si no se puede determinar una clave GPG, o si se proporciona el argumento --key, se utiliza la clave especificada por el argumento --key.

Si se determina que la dirección de correo electrónico y la clave GPG son adecuadas, el script configurará los siguientes parámetros de notmuch:

user.email
Esta configuración se establece en la dirección de correo electrónico determinada.
pgp.key
Esta configuración se establece en la clave GPG determinada.

Tenga en cuenta que las configuraciones de notmuch se guardan en el archivo de configuración de notmuch ($HOME/.config/notmuch/config).

OPTIONS

--key=file
Especifica la clave GPG que se utilizará. Si no se especifica, el script intentará encontrar automáticamente una clave GPG adecuada.
--email=email
Especifica la dirección de correo electrónico que se utilizará. Si no se especifica, el script intentará obtenerla de la configuración de Git. Tenga en cuenta que la dirección de correo electrónico debe coincidir con la clave GPG especificada (o la clave GPG determinada).

ENVIRONMENT

NOTMUCH_TALLOC_REPORT
Ubicación donde escribir un informe de uso de memoria de talloc. Consulte talloc_enable_leak_report_full en talloc(3) para obtener más información.
NOTMUCH_DEBUG_QUERY
Si se establece en un valor no vacío, la biblioteca notmuch imprimirá (en stderr) las consultas Xapian que construye.
