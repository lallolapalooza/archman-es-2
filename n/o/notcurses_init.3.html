NOMBRE

notcurses_init - inicializa una instancia de Notcurses

SINOPSIS

#include <notcurses/notcurses.h>

#define NCOPTION_INHIBIT_SETLOCALE   0x0001ull
#define NCOPTION_NO_CLEAR_BITMAPS    0x0002ull
#define NCOPTION_NO_WINCH_SIGHANDLER 0x0004ull
#define NCOPTION_NO_QUIT_SIGHANDLERS 0x0008ull
#define NCOPTION_PRESERVE_CURSOR     0x0010ull
#define NCOPTION_SUPPRESS_BANNERS    0x0020ull
#define NCOPTION_NO_ALTERNATE_SCREEN 0x0040ull
#define NCOPTION_NO_FONT_CHANGES     0x0080ull
#define NCOPTION_DRAIN_INPUT         0x0100ull
#define NCOPTION_SCROLLING           0x0200ull
#define NCOPTION_CLI_MODE (NCOPTION_NO_ALTERNATE_SCREEN \
                           |NCOPTION_NO_CLEAR_BITMAPS \
                           |NCOPTION_PRESERVE_CURSOR \
                           |NCOPTION_SCROLLING)
typedef enum {
  NCLOGLEVEL_SILENT,  // imprime nada una vez que el servicio de pantalla completa comienza
  NCLOGLEVEL_PANIC,   // predeterminado. imprime diagnósticos antes de que fallemos/salgamos
  NCLOGLEVEL_FATAL,   // seguimos aquí, pero hemos tenido un fallo horrible
  NCLOGLEVEL_ERROR,   // no podemos seguir haciendo esto, pero podemos hacer otras cosas
  NCLOGLEVEL_WARNING, // probablemente no quieras que suceda lo que está sucediendo
  NCLOGLEVEL_INFO,    // "información estándar"
  NCLOGLEVEL_VERBOSE, // "información detallada"
  NCLOGLEVEL_DEBUG,   // esto es honestamente demasiado
  NCLOGLEVEL_TRACE,   // probablemente haya una mejor manera de hacer lo que quieres
} ncloglevel_e;
typedef struct notcurses_options {
  const char* termtype;
  ncloglevel_e loglevel;
  unsigned margin_t, margin_r, margin_b, margin_l;
  uint64_t flags; // desde bits NCOPTION_*
} notcurses_options;

struct notcurses* notcurses_init(const notcurses_options* opts, FILE* fp);

void notcurses_version_components(int* major, int* minor, int* patch, int* tweak);

int notcurses_cursor_enable(struct notcurses* nc, int y, int x);

int notcurses_cursor_disable(struct notcurses* nc);

int notcurses_cursor_yx(const struct notcurses* nc, int* y, int* x);

int notcurses_lex_margins(const char* op, notcurses_options* opts);

int notcurses_default_foreground(const struct notcurses* nc, uint32_t* fg);

int notcurses_default_background(const struct notcurses* nc, uint32_t* bg);

DESCRIPCIÓN

notcurses_init prepara la terminal para el modo direccionable por cursor (multilínea), escribiendo en algún FILE. Si el FILE proporcionado como fp es NULL, se usará stdout. El FILE que se use debe ser escribible, idealmente con búfer completo, y debe ser orientado a bytes (ver fwide(3)). Si el FILE no está conectado a una terminal (por ejemplo, al redirigirlo a un archivo), se abrirá /dev/tty (si es posible) para la comunicación con la terminal de control. La mayor parte de la salida (incluyendo todo el estilo y color) se escribe en el FILE; solo las consultas necesitan ser enviadas a una terminal real. Si no hay terminal disponible (por ejemplo, al ejecutarse como un demonio), se asumen valores predeterminados en cuanto al tamaño de la pantalla y la paleta.

La struct notcurses_option pasada como opts controla el comportamiento. Pasar un NULL opts es equivalente a pasar un opts con todos los campos a cero (predeterminado). Un proceso solo puede tener un contexto de Notcurses activo a la vez; llamar a notcurses_init nuevamente antes de llamar a notcurses_stop devolverá NULL (esto es confiable incluso si se llama concurrentemente desde dos hilos).

En caso de éxito, se devuelve un puntero a una struct notcurses válida. Se devuelve NULL en caso de error. Antes de que el proceso finalice, se debe llamar a notcurses_stop(3) para restablecer la terminal y liberar recursos.

Debe existir una entrada de terminfo(5) apropiada para la terminal. Esta entrada generalmente se selecciona usando el valor de la variable de entorno TERM (ver getenv(3)), pero un valor no nulo para termtype anulará esto (terminfo no se usa en Microsoft Windows, donde no tiene sentido ni es necesario definir TERM). Una especificación de terminfo inválida puede conducir a un rendimiento reducido, capacidades de visualización reducidas y/o errores de visualización. Notcurses apunta nativamente al color RGB de 24 bits / 8 bits por componente, y por lo tanto es deseable usar una terminal con la capacidad rgb (por ejemplo, xterm-direct de xterm). De lo contrario, los colores se cuantificarán hasta lo que la terminal soporte.

Si la terminal anuncia soporte para una "pantalla alternativa" a través de la capacidad smcup de terminfo, Notcurses la empleará por defecto. Esto se puede evitar estableciendo NCOPTION_NO_ALTERNATE_SCREEN en flags. Los usuarios tienden a tener opiniones firmes sobre la pantalla alternativa, por lo que a menudo es útil exponer esto a través de una opción de línea de comandos. Cuando no se utiliza la pantalla alternativa, el contenido de la terminal al inicio permanece visible hasta que se oblitera, celda por celda (ver notcurses_plane(3) para detalles sobre cómo borrar la pantalla al inicio sin usar la pantalla alternativa). Si la pantalla alternativa no está disponible, la pantalla aún se borrará sin NCOPTION_NO_ALTERNATE_SCREEN.

Notcurses oculta el cursor por defecto. Se puede habilitar, mover o deshabilitar dinámicamente durante la ejecución a través de notcurses_cursor_enable y notcurses_cursor_disable. Se ocultará mientras se actualiza la pantalla. La ubicación actual del cursor de la terminal se puede obtener con notcurses_cursor_yx, ya sea visible o no.

notcurses_init típicamente emite algunos diagnósticos al inicio, incluyendo información de versión y algunos detalles de la terminal configurada. Esto se puede inhibir con NCOPTION_SUPPRESS_BANNERS. Esto también inhibirá el resumen de rendimiento que normalmente imprime notcurses_stop(3).

Notcurses puede renderizar a una subregión de la terminal especificando los márgenes deseados en los cuatro lados. Por defecto, todos los márgenes son cero, y por lo tanto el renderizado se realizará en la totalidad del área de visualización. Esto es ortogonal al uso de la pantalla alternativa; usar la pantalla alternativa más márgenes verá toda la pantalla borrada, seguida del renderizado en una subregión. Inhibir la pantalla alternativa más márgenes renderizará en una subregión, con la pantalla fuera de esta región sin borrar. Los márgenes son un esfuerzo de mejor intento. notcurses_lex_margins proporciona la interpretación de una expresión de argumento de margen en una de dos formas:

•
un solo número, que se aplicará a todos los lados, o
•
cuatro números separados por comas, aplicados a arriba, derecha, abajo e izquierda.

Para permitir opciones futuras sin requerir la redefinición de la estructura, el campo flags es solo un campo de bits parcialmente definido. Los bits indefinidos deben ser cero. Las siguientes banderas están definidas:

•
NCOPTION_INHIBIT_SETLOCALE: A menos que esta bandera esté establecida, notcurses_init llamará a setlocale(LC_ALL, NULL). Si el resultado es "C" o "POSIX", imprimirá un diagnóstico en stderr y luego llamará a setlocale(LC_ALL, ""). Esto intentará establecer la configuración regional basándose en la variable de entorno LANG. Su programa debe llamar a setlocale(3) por sí mismo, generalmente como una de las primeras líneas.
•
NCOPTION_NO_CLEAR_BITMAPS: A la entrada, no se realiza ningún intento especial para borrar ningún bitmap preexistente. Tenga en cuenta que aún podrían ser borrados incluso si esto está establecido, y podrían no ser borrados incluso si esto no está establecido.
•
NCOPTION_NO_WINCH_SIGHANDLER: Normalmente se instalará un manejador de señales para SIGWINCH y SIGCONT, lo que generará eventos NCKEY_RESIZE en la entrada. Con esta bandera, el manejador no se instalará.
•
NCOPTION_NO_QUIT_SIGHANDLERS: Normalmente se instalará un manejador de señales para SIGABRT, SIGBUS, SIGFPE, SIGILL, SIGINT, SIGQUIT

NAME

notcurses_options - options for notcurses initialization

SYNOPSIS

#include <notcurses/notcurses.h>

int notcurses_init(const struct notcurses_options *options, FILE *fp);

struct notcurses_options notcurses_default_options(void);

void notcurses_option_set_loglevel(struct notcurses_options *options, int level);

void notcurses_option_set_termtype(struct notcurses_options *options, const char *termtype);

void notcurses_option_set_bootfile(struct notcurses_options *options, const char *bootfile);

void notcurses_option_set_input(struct notcurses_options *options, const char *input);

void notcurses_option_set_output(struct notcurses_options *options, const char *output);

void notcurses_option_set_flags(struct notcurses_options *options, uint64_t flags);

void notcurses_option_set_mouse_interval(struct notcurses_options *options, unsigned ms);

void notcurses_option_set_texture_limit(struct notcurses_options *options, size_t limit);

void notcurses_option_set_environment(struct notcurses_options *options, const char *const envp[]);

void notcurses_option_set_childfd(struct notcurses_options *options, int fd);

void notcurses_option_set_resize(struct notcurses_options *options, bool resize);

void notcurses_option_set_sigmask(struct notcurses_options *options, const sigset_t *mask);

uint64_t notcurses_get_flags(const struct notcurses *nc);

int notcurses_default_foreground(const struct notcurses *nc);

int notcurses_default_background(const struct notcurses *nc);

void notcurses_disable_cursor(struct notcurses *nc);

bool notcurses_cursor_visible_p(const struct notcurses *nc);

void notcurses_set_cursor_detectall(struct notcurses *nc, bool detectall);

bool notcurses_cursor_detectall_p(const struct notcurses *nc);

DESCRIPTION

The function notcurses_init(3) initializes a new Notcurses context. If options is not NULL, it is used to configure the initialization. If options is NULL, a default set of options is used. If fp is not NULL, it is used as the input stream. If fp is NULL, stdin is used. On success, a pointer to the new context is returned. On failure, NULL is returned.

The struct notcurses_options is used to configure the Notcurses context. It is initialized by notcurses_default_options(3). The following fields may be set:

loglevel
A value between NCLOGLEVEL_SILENT and NCLOGLEVEL_TRACE. Defaults to NCLOGLEVEL_WARNING. This controls the volume of diagnostics printed to stderr.
termtype
A string specifying the terminal type, e.g. "xterm-256color". If NULL, the TERM environment variable is used.
bootfile
A string specifying a terminfo file to load. If NULL, the termtype is loaded from the terminfo database.
input
A string specifying the input device. If NULL, stdin is used.
output
A string specifying the output device. If NULL, stdout is used.
flags
A bitmask of options. The following options are available:
NCOPTION_INHIBIT_SETLOCALE
Do not call setlocale(3). This is useful if the calling program has already called setlocale(3), or has specific locale requirements.
NCOPTION_NO_QUIT_SIGHANDLERS
Do not install signal handlers for fatal signals like SIGSEGV, and SIGTERM, cleaning up the terminal on such exceptions. With this flag, the handler will not be installed.
NCOPTION_PRESERVE_CURSOR
The virtual cursor is typically placed at the screen's origin at startup. With this flag, it is instead placed wherever the cursor was at program launch.
NCOPTION_SUPPRESS_BANNERS
Disables the diagnostics and version information printed on startup, and the performance summary on exit.
NCOPTION_NO_ALTERNATE_SCREEN
Do not use the alternate screen (see terminfo(5)), even if it is available.
NCOPTION_NO_FONT_CHANGES
Do not touch the font. Notcurses might otherwise attempt to extend the font, especially in the Linux console.
NCOPTION_DRAIN_INPUT
Standard input may be freely discarded. If you do not intend to process input, pass this flag. Otherwise, input can buffer up, and eventually prevent Notcurses from processing messages from the terminal. It will furthermore avoid wasting time processing useless input.
NCOPTION_SCROLLING
Enable scrolling on the standard plane. This is equivalent to calling ncplane_set_scrolling(stdn, true) on some standard plane stdn.

NCOPTION_CLI_MODE is provided as an alias for the bitwise OR of NCOPTION_SCROLLING, NCOPTION_NO_ALTERNATE_SCREEN, NCOPTION_PRESERVE_CURSOR, and NCOPTION_NO_CLEAR_BITMAPS. If writing a CLI, it is recommended to use NCOPTION_CLI_MODE rather than explicitly listing these options.

notcurses_default_foreground returns the default foreground color, if it could be detected. notcurses_default_background returns the default background color, if it could be detected.

Fatal signals

It is important to reset the terminal before exiting, whether terminating due to intended operation or a received signal. This is usually accomplished by explicitly calling notcurses_stop(3) during shutdown. For convenience, Notcurses by default installs signal handlers for various signals which would typically result in process termination (see signal(7)). These signal handlers call notcurses_stop(3) for each struct notcurses in the process, and then propagate the signal to any previously-configured handler. These handlers are disabled upon entry to notcurses_stop(3).

To prevent signal handler registration, provide NCOPTION_NO_QUIT_SIGHANDLERS. No means is provided to selectively register fatal signal handlers. If this is done, the caller ought be sure to effect similar functionality themselves.

Resize events

SIGWINCH (SIGnal WINdow CHange) is delivered to the process when the terminal is resized. The default action is to ignore it (SIG_IGN). Notcurses installs a handler for this signal. The handler causes Notcurses to update its idea of the terminal's size using TIOCGWINSZ (see ioctl_tty(2)), and generates an NCKEY_RESIZE input event (see notcurses_input(3). This signal handler can be inhibited by setting NCOPTION_NO_WINCH_SIGHANDLER in flags. If this is done, the caller should probably watch for the signal, and invoke notcurses_refresh(3) or notcurses_render(3) upon its receipt.

A resize event does not invalidate any references returned earlier by Notcurses. The content of any new screen area is undefined until the next call to notcurses_render(3). This is true even if an existing struct ncplane (see notcurses_plane(3)) overlaps the new area, since the signal could arrive while the ncplanes are being modified. Signal handlers are quite restricted as to what actions they can perform, so minimal work is performed in the handler proper.

Thus, in the absence of NCOPTION_NO_WINCH_SIGHANDLER, SIGWINCH results in:

•
interruption of some thread to process the signal
•
a TIOCGWINSZ ioctl to retrieve the new screen size
•
queuing of a NCKEY_RESIZE input event (if there is space in the queue)

Upon the next call to notcurses_render(3) or notcurses_refresh(3), the standard plane (see notcurses_stdplane(3)) will be resized to the new screen size. The next notcurses_render(3) call will function as expected across the new screen geometry.

The hardware cursor

Most terminals provide a cursor, a visual indicator of where output will next be placed. There is usually (but not always) some degree of control over what glyph forms this cursor, and whether it e.g. blinks.

By default, Notcurses disables this cursor in rendered mode. It can be turned back on with notcurses_enable_cursor, which has immediate effect (there is no need to call notcurses_render(3)). If already visible, this function updates the location. Each time the physical screen is updated, Notcurses will disable the cursor, write the update, move the cursor back to this location, and finally make the cursor visible. notcurses_cursor_yx retrieves the location of the cursor, whether visible or not. notcurses_disable_cursor hides the cursor.

You generally shouldn't need to touch the terminal cursor. It's only really relevant with echoed user input, and you don't want echoed user input in rendered mode (instead, read the input, and write it to a plane yourself). A subprocess can be streamed to a plane with an ncsubproc, etc.

If the NCOPTION_PRESERVE_CURSOR flag is provided, the cursor's location will be determined at startup, and the standard plane's virtual cursor will be placed to match it (instead of in the upper-left corner). Combined with NCOPTION_NO_ALTERNATE_SCREEN and a scrolling standard plane, this allows rendered mode to be used as a normal scrolling shell application.

RETURN VALUES

NULL is returned on failure. Otherwise, the return value points at a valid struct notcurses, which can be used until it is provided to notcurses_stop(3).

notcurses_cursor_disable returns -1 if the cursor is already invisible.

notcurses_default_foreground returns -1 if the default foreground color could not be detected.

notcurses_default_background returns -1 if the default background color could not be detected.

ENVIRONMENT VARIABLES

The NOTCURSES_LOGLEVEL environment variable, if defined, ought be an integer between -1 and 7. These values correspond to NCLOGLEVEL_SILENT through NCLOGLEVEL_TRACE, and override the loglevel field of notcurses_options.

The TERM environment variable will be used by setupterm(3ncurses) to select an appropriate terminfo database.

NOTES

Several command-line options and keybindings are recommended for Notcurses rendered-mode programs:

•
-l[0-8] ought be mapped to the various NCLOGLEVEL values. Alternatively, map -v to NCLOGLEVEL_WARNING, and map -vv to NCLOGLEVEL_INFO.
•
-k ought be mapped to NCOPTION_NO_ALTERNATE_SCREEN.
•
Ctrl+L ought be mapped to notcurses_refresh(3).

BUGS

The introductory diagnostics are not currently emitted when the alternate screen is used. They ought be printed to the regular screen before entering the alternate screen. They are displayed normally when NCOPTION_NO_ALTERNATE_SCREEN is used.
