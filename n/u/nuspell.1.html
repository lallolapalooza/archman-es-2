NUSPELL(1) Comandos de usuario NUSPELL(1)

NOMBRE

nuspell - Herramienta de línea de comandos para la corrección ortográfica.

SINOPSIS

nuspell [-d nombre_diccionario] [OPCIÓN]... [ARCHIVO]...

nuspell -D|--ayuda|--version

DESCRIPCIÓN

Comprueba la ortografía de cada ARCHIVO. Si no se especifica ningún ARCHIVO, comprueba la entrada estándar. El texto de la entrada se segmenta primero en palabras con un algoritmo que reconoce la puntuación y luego se comprueba cada palabra.

OPCIONES

-d, --diccionario=di_CT
Usa el diccionario di_CT. Solo se admite uno. Un diccionario consta de dos archivos con extensiones .dic y .aff. La opción -d acepta ya sea el nombre del diccionario sin la extensión del nombre de archivo, generalmente una etiqueta de idioma, o una ruta (con barra) al archivo .aff, incluida la extensión del nombre de archivo. Cuando solo se da un nombre, se buscará entre la lista de diccionarios en los directorios predeterminados (ver opción -D). Cuando se proporciona una ruta a .aff, solo se considera el diccionario bajo la ruta. Cuando -d no está presente, la herramienta CLI intenta cargar un diccionario utilizando la etiqueta de idioma de la configuración regional activa.
-D, --listar-diccionarios
Imprime las rutas de búsqueda y los diccionarios disponibles y sale.
--codificación=ENC
Establece la codificación tanto de entrada como de salida.
--codificación-entrada=ENC
Establece la codificación de entrada, por defecto es la configuración regional activa.
--codificación-salida=ENC
Establece la codificación de salida, por defecto es la configuración regional activa.
--ayuda
Imprime una ayuda breve.
--version
Imprime el número de versión.

ESTADO DE SALIDA

Devuelve un error si la sintaxis del argumento es inválida, si el diccionario no se puede cargar o si algún archivo de entrada no se puede abrir. De lo contrario, se ha realizado la corrección ortográfica y se devuelve éxito.

ENTORNO

DICCIONARIO
Especifica el diccionario, lo mismo que la opción -d.
RUTA_DIC
Ruta a un directorio adicional para buscar diccionarios.

ADVERTENCIAS

La herramienta CLI está destinada principalmente a ser utilizada interactivamente por humanos. La entrada es texto plano y la salida es mayoritariamente texto plano con algunos símbolos y palabras que están destinados a ser leídos por humanos y no por máquinas. El formato de la salida no está estrictamente definido y puede cambiar, por lo tanto, no es legible por máquinas. Otros programas deben utilizar directamente la biblioteca C++ que tiene una API estable.

EJEMPLOS

nuspell -d en_US archivo.txt
nuspell -d ../../subdir/di_CT.aff
