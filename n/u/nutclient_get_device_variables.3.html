nutclient_get_device_variables(3)

Paquete: nut

LIBNUTCLIENT_VARIABL(3) Manual de NUT LIBNUTCLIENT_VARIABL(3)

NOMBRE

libnutclient_variables, nutclient_get_device_variables, nutclient_get_device_rw_variables, nutclient_has_device_variable, nutclient_get_device_variable_description, nutclient_get_device_variable_values, nutclient_set_device_variable_value, nutclient_set_device_variable_values - Funciones relacionadas con variables en la biblioteca de acceso de alto nivel del cliente de Network UPS Tools

SINOPSIS

        #include <nutclient.h>
        typedef void* NUTCLIENT_t;
        typedef char** strarr;
        strarr nutclient_get_device_variables(NUTCLIENT_t client,
                const char* dev);
        strarr nutclient_get_device_rw_variables(NUTCLIENT_t client,
                const char* dev);
        int nutclient_has_device_variable(NUTCLIENT_t client,
                const char* dev, const char* var);
        char* nutclient_get_device_variable_description(NUTCLIENT_t client,
                const char* dev, const char* var);
        strarr nutclient_get_device_variable_values(NUTCLIENT_t client,
                const char* dev, const char* var);
        void nutclient_set_device_variable_value(NUTCLIENT_t client,
                const char* dev, const char* var, const char* value);
        void nutclient_set_device_variable_values(NUTCLIENT_t client,
                const char* dev, const char* var, const strarr values);

DESCRIPCIÓN

Estas funciones permiten gestionar las variables de los dispositivos.

•La función nutclient_get_device_variables() recupera la lista de nombres de variables para un dispositivo.

El strarr devuelto debe ser liberado por strarr_free (ver libnutclient_general(3)).

•La función nutclient_get_device_rw_variables recupera la lista de nombres de variables de lectura-escritura para un dispositivo.

El strarr devuelto debe ser liberado por strarr_free (ver libnutclient_general(3)).

•La función nutclient_has_device_variable comprueba si la variable especificada es compatible con el dispositivo.

Devuelve 1 si es compatible y 0 si no lo es.

•La función nutclient_get_device_variable_description recupera la descripción de la variable, si existe.

La cadena devuelta debe ser liberada por free(3).

•La función nutclient_get_device_variable_values devuelve los valores de la variable (generalmente solo uno).

El strarr devuelto debe ser liberado por strarr_free (ver libnutclient_general(3)).

•La función nutclient_set_device_variable_value pretende establecer el valor de la variable especificada.
•La función nutclient_set_device_variable_values pretende establecer múltiples valores de la variable especificada.

Argumentos comunes:

•dev es el nombre del dispositivo.
•var es el nombre de la variable.
•value es el valor de la variable.
•values es el array de valores de la variable.
