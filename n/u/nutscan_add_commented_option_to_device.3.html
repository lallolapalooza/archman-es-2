nutscan_add_commented_option_to_device(3)

Paquete: nut

Licencias: GPL-2.0-or-later AND GPL-3.0-or-later

NUTSCAN_ADD_OPTION_T(3) Manual de NUT NUTSCAN_ADD_OPTION_T(3)

NOMBRE

nutscan_add_option_to_device, nutscan_add_commented_option_to_device - Añadir datos de opción al dispositivo especificado.

SINOPSIS

        #include <nut-scan.h>
        /* Añadir datos de opción habilitada al dispositivo especificado. */
        void nutscan_add_option_to_device(
                nutscan_device_t * device,
                char * option_name,
                char * value);
        /* Desde la versión 2.5.0 de libnutscan:
         * Añadir datos de opción al dispositivo especificado con una etiqueta de comentario opcional
         * para opciones sugeridas, pero no habilitadas actualmente para uso real. */
        void nutscan_add_commented_option_to_device(
                nutscan_device_t * device,
                char * option_name,
                char * value,
                char * comment_tag);

DESCRIPCIÓN

El tipo nutscan_device_t contiene las siguientes variables:

nutscan_device_type_t   type;
char *          driver;
char *          alt_driver_names;
char *          port;
nutscan_options_t       opt;
struct nutscan_device * prev;
struct nutscan_device * next;

Esta es una lista doblemente enlazada de dispositivos. Cada device se describe por su tipo, el nombre de su driver, su puerto y cualquier cantidad de datos opcionales.

La función nutscan_add_option_to_device() añade un dato opcional en el device dado. Los datos opcionales consisten en un option_name y un value asociado, y opcionalmente un comment_tag. Se almacenan copias del option_name, value y comment_tag en el device, por lo que el llamador puede realizar free(3) de forma segura de todas las cadenas originales usadas como argumentos.


Nota

Un valor no nulo para comment_tag hace que la opción no esté habilitada para su uso actual. Dependiendo del formato de salida, puede ser completamente ignorado, o mostrado como un comentario con este valor como prefijo (se puede pasar una cadena de longitud cero "\0" para no tener prefijo).

Estas opciones y sus valores pueden ser sometidos a comprobaciones de integridad y reportados como advertencias por el despachador nutscan_display_sanity_check() y sus métodos relacionados que implementan la lógica de comprobaciones particulares. Esto se utiliza, por ejemplo, al generar sugerencias de contenido para un archivo ups.conf con el método nutscan_display_ups_conf_with_sanity_check().

NOTAS

Técnicamente, la función está definida actualmente en el archivo nutscan-device.h.
