NOMBRE

nutscan_scan_avahi - Escanear la red en busca de servicios NUT a través de mDNS

SINOPSIS

        #include <nut-scan.h>
        #include <unistd.h> /* useconds_t */
        nutscan_device_t * nutscan_scan_avahi(useconds_t usec_timeout);

DESCRIPCIÓN

La función nutscan_scan_avahi() intenta detectar el servicio NUT a través de mDNS y sus dispositivos asociados. Utiliza la biblioteca Avahi para hacerlo.

DEBE llamar a nutscan_init(3) antes de usar esta función.

Esta función puede consultar direcciones IP potenciales utilizando el protocolo NUT, y en este caso espera hasta usec_timeout microsegundos antes de considerar que una dirección IP no responde.

VALOR DE RETORNO

La función nutscan_scan_avahi() devuelve un puntero a una estructura nutscan_device_t que contiene todos los dispositivos encontrados.

Devuelve NULL si ocurre un error o si no se encuentra ningún dispositivo.
