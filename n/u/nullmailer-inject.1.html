nullmailer-inject(1) Manual de comandos generales nullmailer-inject(1)

NOMBRE

nullmailer-inject - Reformatea e inyecta un mensaje en la cola.

SINOPSIS

nullmailer-inject [-a] [-b] [-e] [-f remitente] [-h] [destinatario [destinatario ...]]

DESCRIPCIÓN

Este programa lee un mensaje de correo electrónico de la entrada estándar, reforma su encabezado para cumplir con RFC822 y envía el mensaje resultante a la cola.

CAMPOS DE ENCABEZADO

Las siguientes líneas se analizan para obtener direcciones de destinatario: To, Cc, Bcc, Apparently-To, Resent-To, Resent-Cc y Resent-Bcc.

Las siguientes líneas de dirección del remitente se analizan y reescriben: Sender, From, Reply-To, Return-Path, Return-Receipt-To, Errors-To, Resent-Sender, Resent-From y Resent-Reply-To. Si el campo de encabezado Return-Path está presente y contiene una sola dirección, sus contenidos se utilizarán para establecer la dirección del remitente del sobre.

Si el mensaje contiene alguno de los siguientes campos, se trata como un mensaje reenviado: Resent-Sender, Resent-From, Resent-Reply-To, Resent-To, Resent-Cc, Resent-Bcc, Resent-Date, Resent-Message-ID. Si el mensaje se reenvía, solo se examinan para obtener direcciones los campos de destinatario prefijados con Resent-.

Cualquier ocurrencia de Bcc, Resent-Bcc, Return-Path o Content-Length se descarta después de ser analizada (si es necesario).

Si al encabezado le falta el campo Message-Id, se genera una cadena única y se agrega al mensaje. Si al encabezado le falta el campo Date, la fecha y hora local actual en formato RFC822 se agrega al mensaje. Si el mensaje no tiene campos To o Cc, la siguiente línea se agrega al mensaje:

Cc: lista de destinatarios no mostrada: ;

LISTAS DE DIRECCIONES

Se espera que las listas de direcciones sigan la sintaxis establecida en RFC822. La siguiente es una explicación simplificada de la sintaxis.

Una lista de direcciones es una lista de direcciones separadas por comas. Una dirección individual puede tener una de las siguientes tres formas: usuario@fqdn, comentario<usuario@fqdn>, o frase:lista-de-direcciones;. Cualquiera de las dos primeras formas puede usarse dentro de la lista de direcciones de la tercera forma. Cualquier palabra que contenga caracteres especiales debe colocarse entre comillas dobles y los caracteres especiales deben ir precedidos de una barra inversa. Los comentarios pueden colocarse entre direcciones entre paréntesis. Todos los comentarios se ignoran.

Las listas de direcciones se reformatean a medida que se analizan para facilitar su posterior análisis cuando el mensaje llega al(los) destinatario(s). Si a una dirección le falta un fqdn, nullmailer-inject agrega uno.

OPCIONES

-a
Utilizar solo los argumentos de la línea de comandos como direcciones de destinatario. Ignorar las líneas de encabezado del destinatario.
-b
Utilizar tanto los argumentos de la línea de comandos como los datos del encabezado del mensaje como direcciones de destinatario.
-e
Utilizar los argumentos de la línea de comandos (si los hay) o los datos del encabezado del mensaje (si no hay argumentos) como direcciones de destinatario.
-f remitente
Establecer la dirección del remitente del sobre a remitente.
-h
Utilizar solo los datos del encabezado del mensaje como direcciones de destinatario.
-n
No poner en cola el mensaje, sino imprimir el contenido reformateado en la salida estándar.
-v
Imprimir el sobre (direcciones del remitente y destinatario) precediendo al mensaje cuando se imprime el mensaje en la salida estándar.

VALOR DE RETORNO

Sale con 0 si tuvo éxito, de lo contrario imprime un mensaje diagnóstico en el error estándar y sale con 1.

ENTORNO

La variable de entorno NULLMAILER_FLAGS se analiza y el comportamiento de nullmailer-inject se modifica si están presentes alguna de las siguientes letras:

c
Utilizar el estilo "dirección (comentario)" en el campo From generado en lugar del estilo predeterminado "comentario <dirección>"
f
Ignorar y eliminar cualquier línea de encabezado From e insertar siempre una generada.
i
Ignorar y eliminar cualquier línea de encabezado Message-Id.
s
Ignorar y eliminar cualquier línea de encabezado Return-Path.
t
Insertar una línea To que contenga una lista de los destinatarios si el encabezado no contiene un campo To o Cc. Si se determina que el mensaje es un mensaje reenviado (ver arriba), se agrega un campo Resent-To si el encabezado no contiene un campo Resent-To o Resent-Cc.

El nombre de usuario se establece mediante NULLMAILER_USER, MAILUSER, USER o LOGNAME, el que aparezca primero. Si ninguno de los anteriores está configurado, el nombre se toma del archivo de contraseñas, o se establece en unknown si eso falla.

El nombre de host se establece mediante el valor canonizado de NULLMAILER_HOST, MAILHOST o HOSTNAME, el que aparezca primero, o el archivo de control defaulthost si ninguno de los anteriores está configurado (ver abajo).

El nombre completo del usuario se establece mediante NULLMAILER_NAME, MAILNAME, NAME, o el nombre de usuario anterior, el que aparezca primero.

El nombre de usuario y host del remitente del sobre por defecto son el usuario y el nombre de host establecidos anteriormente, pero pueden ser sobrescritos por NULLMAILER_SUSER y NULLMAILER_SHOST.

Si NULLMAILER_QUEUE está configurado, el programa nombrado se utiliza en lugar de nullmailer-queue para poner en cola el mensaje formateado.

ARCHIVOS DE CONTROL

Al leer los siguientes archivos, se lee una sola línea y se eliminan todos los caracteres de espacio en blanco iniciales y finales.

defaultdomain
El contenido de este archivo se agrega a cualquier nombre de host que no contenga un punto (excepto localhost), incluidos defaulthost e idhost. Por defecto, el valor del archivo de control me, si existe, de lo contrario el nombre literal defaultdomain.
defaulthost
El contenido de este archivo se agrega a cualquier dirección a la que le falte un nombre de host. Por defecto, el valor del archivo de control me, si existe, de lo contrario el nombre literal defaulthost.
idhost
El contenido de este archivo se utiliza al construir la cadena message-id para el mensaje. Por defecto, el valor canonizado de defaulthost.
me
El nombre de host completamente calificado de la computadora que ejecuta nullmailer. Por defecto, el nombre literal me.
