NUTSCAN_SCAN_IPMI(3) Manual de NUT NUTSCAN_SCAN_IPMI(3)

NOMBRE

nutscan_scan_ipmi - Escanea dispositivos IPMI locales.

SINOPSIS

        #include <nut-scan.h>
        nutscan_device_t * nutscan_scan_ipmi(
                const char * startIP,
                const char * stopIP,
                nutscan_ipmi_t * sec);
        nutscan_device_t * nutscan_scan_ip_range_ipmi(
                nutscan_ip_range_list_t * irl,
                nutscan_ipmi_t * sec);

DESCRIPCIÓN

Las funciones nutscan_scan_ipmi() y nutscan_scan_ip_range_ipmi() intentan detectar dispositivos gestionables por IPMI.

Si start_ip para la primera o irl para la segunda son NULL, la función respectiva busca una PSU local.

De lo contrario, busca hosts remotos que sirvan protocolos IPMI e intentará autenticarse usando los datos de la estructura sec.

La primera emite una solicitud IPMI en cada IP dentro del rango de startIP a stopIP, donde startIP es obligatorio y stopIP es opcional (se escanea una dirección startIP si stopIP es NULL); mientras que la segunda puede recorrer varios rangos de direcciones IP representados por una estructura nutscan_ip_range_list_t.

Estos argumentos de IP pueden ser direcciones IPv4 o IPv6 o nombres de host.

DEBE llamar a nutscan_init(3) antes de usar esta función.

ERRORES

El diseño o la implementación de esta función pueden ser incompletos: hasta hace poco, esta página de manual indicaba que aún no estaba implementada. El código fuente está presente, aunque algunos bloques están comentados o ocultos con #if 0.

VALOR DE RETORNO

La función nutscan_scan_ipmi() aún no está implementada.
