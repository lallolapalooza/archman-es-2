NOMBRE

nutscan_ip_ranges_iter_inc - Avanzar en la iteración de un rango de direcciones IP utilizando una estructura `nutscan_ip_range_list_iter_t`.

SINOPSIS

        #include <nut-scan.h>
        char * nutscan_ip_ranges_iter_inc(nutscan_ip_range_list_iter_t *irliter);

DESCRIPCIÓN

La función nutscan_ip_ranges_iter_inc() puede recorrer un iterador del objeto auxiliar nutscan_ip_range_list_iter_t especificado, preparado por nutscan_ip_ranges_iter_init(3) a partir de una estructura nutscan_ip_range_list_t.

Esta función omite el trabajo si:

•el puntero de la estructura es NULL (se devuelve NULL);
•la lista de rangos IP de la estructura apuntada es NULL (se devuelve NULL),
•el puntero del iterador de rangos IP de la estructura apuntada es NULL (se devuelve NULL).

Devuelve la siguiente dirección IP del rango de direcciones IP registrado actualmente iterado, o cambia la iteración al siguiente rango si no quedan direcciones en el actual. El llamante NO DEBE liberar esta cadena mientras itera.

NOTAS

Técnicamente, la función está definida actualmente en el archivo nutscan-ip.h.

VER TAMBIÉN
