NOMBRE

nutscan_scan_nut_simulation - Escanea tu directorio sysconfig en busca de dispositivos de simulación NUT.

SINOPSIS

        #include <nut-scan.h>
        #include <unistd.h> /* useconds_t */
        nutscan_device_t * nutscan_scan_nut_simulation();

DESCRIPCIÓN

La función nutscan_scan_nut_simulation() intenta detectar dispositivos de simulación NUT disponibles, buscando archivos *.dev y *.seq en tu directorio "sysconfig".

DEBES llamar a nutscan_init(3) antes de usar esta función.

ERRORES

Actualmente, esta función utiliza la ubicación integrada del directorio "sysconfig" y no considera una anulación con la variable de entorno NUT_CONFPATH aceptada por la mayor parte de la base de código de NUT.

VALOR DE RETORNO

La función nutscan_scan_nut_simulation() devuelve un puntero a una estructura nutscan_device_t que contiene todos los dispositivos encontrados o NULL si ocurre un error o no se encuentra ningún dispositivo.
