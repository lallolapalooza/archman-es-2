LIBNUTCLIENT_GENERAL(3) Manual de NUT LIBNUTCLIENT_GENERAL(3)

NOMBRE

libnutclient_general, nutclient_destroy, strarr_alloc, strarr_free - Funciones generales y de utilidad en la biblioteca de acceso a cliente de alto nivel de Network UPS Tools

SINOPSIS

        #include <nutclient.h>
        typedef void* NUTCLIENT_t;
        void nutclient_destroy(NUTCLIENT_t client);
        typedef char** strarr;
        strarr strarr_alloc(unsigned short count);
        void strarr_free(strarr arr);

DESCRIPCIÓN

La función nutclient_destroy() destruye un objeto de conexión NUTCLIENT_t o derivado (como NUTCLIENT_TCP_t) y libera la memoria asignada.

•El tipo strarr representa un array de cadenas C (array de punteros a char). El array siempre debe terminar con un puntero NULL.

Las cadenas apuntadas deben ser asignadas por (x)calloc o (x)strdup.

•La función strarr_alloc() asigna un array strarr con el número especificado de punteros de cadena (no inicializados).

Se añade otro puntero adicional establecido a NULL al final del array.

•La función strarr_free libera un array strarr. También libera todas las cadenas apuntadas.

Argumentos comunes:

•dev es el nombre del dispositivo.
