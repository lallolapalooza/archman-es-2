NUTSCAN_SCAN_NUT(3) Manual de NUT NUTSCAN_SCAN_NUT(3)

NOMBRE

nutscan_scan_nut - Escanea la red en busca de servicios NUT disponibles.

SINOPSIS

        #include <nut-scan.h>
        #include <unistd.h> /* useconds_t */
        nutscan_device_t * nutscan_scan_nut(
                const char * startIP,
                const char * stopIP,
                const char * port,
                useconds_t usec_timeout);
        nutscan_device_t * nutscan_scan_ip_range_nut(
                nutscan_ip_range_list_t * irl,
                const char * port,
                useconds_t usec_timeout);

DESCRIPCIÓN

Las funciones nutscan_scan_nut() y nutscan_scan_ip_range_nut() intentan detectar servicios NUT disponibles y sus dispositivos asociados. La primera emite una solicitud NUT en cada IP desde startIP hasta stopIP, donde startIP es obligatorio y stopIP es opcional (se escanea una dirección startIP si stopIP es NULL); mientras que la segunda puede recorrer varios rangos de direcciones IP representados por una estructura nutscan_ip_range_list_t.

Estos argumentos IP pueden ser direcciones IPv4 o IPv6 o nombres de host.

DEBE llamar a nutscan_init(3) antes de usar esta función.

Se puede pasar un número de puerto específico, o NULL para usar el puerto NUT por defecto.

Esta función espera hasta usec_timeout microsegundos antes de considerar que una dirección IP no responde a las consultas NUT.

VALOR DE RETORNO

La función nutscan_scan_nut() devuelve un puntero a una estructura nutscan_device_t que contiene todos los dispositivos encontrados o NULL si ocurre un error o no se encuentra ningún dispositivo.
