NUTSCAN_SCAN_USB(3) Manual de NUT NUTSCAN_SCAN_USB(3)

NOMBRE

nutscan_scan_usb - Escanea dispositivos USB compatibles con NUT.

SINOPSIS

        #include <nut-scan.h>
        nutscan_device_t * nutscan_scan_usb(nutscan_usb_t * scanopts);

Nota

Antes de la versión 2.5.0 de libnutscan no había argumento:

nutscan_device_t * nutscan_scan_usb(void);

Después de la actualización de la API para tener un argumento, la actividad por defecto equivalente se puede lograr pasando un valor NULL para el argumento.

DESCRIPCIÓN

La función nutscan_scan_usb() intenta detectar dispositivos USB compatibles con NUT.

El argumento scanopts contiene opciones de activación sobre los valores que se informarían en la sección de dispositivo generada. Actualmente se refieren a detalles del enlace físico que pueden cambiar con el tiempo (por ejemplo, reenumeración USB debido a reconexiones de software o hardware); vea nut-scan.h para detalles actuales:

/* Estructura de opciones de escaneo USB */
typedef struct nutscan_usb {
    /* Los valores relacionados con el enlace de hardware a continuación no son
     * fiables para la coincidencia en tiempo de ejecución (pueden cambiar con
     * el tiempo), pero pueden ser útiles si, por ejemplo, el "serial" no
     * está disponible o no es único */
    int report_bus;
    int report_busport;
    int report_device;
    /* El valor no se utiliza actualmente para la coincidencia de dispositivos,
     * pero podría usarse más adelante, y está disponible desde el descubrimiento */
    int report_bcdDevice;
} nutscan_usb_t;

DEBE llamar a nutscan_init(3) antes de usar esta función.

VALOR DE RETORNO

La función nutscan_scan_usb() devuelve un puntero a una estructura nutscan_device_t que contiene todos los dispositivos encontrados o NULL si ocurre un error o no se encuentra ningún dispositivo.
