null(4) Manual de controladores de dispositivos null(4)

NOMBRE

null, zero - sumidero de datos

DESCRIPCIÓN

Los datos escritos en los archivos especiales /dev/null y /dev/zero son descartados.

Las lecturas de /dev/null siempre devuelven fin de archivo (es decir, read(2) devuelve 0), mientras que las lecturas de /dev/zero siempre devuelven bytes que contienen ceros (caracteres '\0').

Estos dispositivos suelen crearse con:


mknod -m 666 /dev/null c 1 3
mknod -m 666 /dev/zero c 1 5
chown root:root /dev/null /dev/zero

ARCHIVOS

/dev/null
/dev/zero

NOTAS

Si estos dispositivos no son escribibles y legibles por todos los usuarios, muchos programas se comportarán de forma extraña.

Desde Linux 2.6.31, las lecturas de /dev/zero son interrumpibles por señales. (Este cambio se realizó para ayudar con las latencias deficientes en lecturas grandes de /dev/zero).

VER TAMBIÉN

chown(1), mknod(1), full(4)
