NOMBRE

nutscan - biblioteca de descubrimiento de dispositivos de Network UPS Tools (NUT)

DESCRIPCIÓN

La biblioteca nutscan de Network UPS Tools (NUT) proporciona las mismas funcionalidades de descubrimiento que también ofrece nut-scanner(8).

Permite el descubrimiento de dispositivos NUT compatibles (USB, SNMP, Eaton XML/HTTP e IPMI) y servidores NUT (ya sea usando Avahi o el método de conexión clásico).

FUNCIONES DE DESCUBRIMIENTO

Primero, incluye el archivo de cabecera requerido:

#include <nut-scan.h>

Luego, para descubrir nuevos dispositivos, usa la función apropiada:

•nutscan_scan_usb(3) para dispositivos USB compatibles,
•nutscan_scan_snmp(3) para agentes SNMP compatibles,
•nutscan_scan_xml_http_range(3) para la tarjeta de gestión de red Eaton,
•nutscan_scan_nut(3) para servidores NUT (upsd), usando el método clásico (búsqueda de puerto),
•nutscan_scan_avahi(3) para servidores NUT (upsd), usando el método mDNS (Avahi),
•nutscan_scan_ipmi(3) para fuentes de alimentación IPMI compatibles.

Todas estas funciones devuelven una lista de dispositivos encontrados, usando la estructura nutscan_device_t. Esta estructura se describe en nutscan_add_device_to_device(3).

También se proporcionan funciones auxiliares para mostrar datos en formatos estándar:

•nutscan_display_parsable(3) para salida analizable,
•nutscan_display_ups_conf(3) para el estilo ups.conf,
•nutscan_display_ups_conf_with_sanity_check(3) para el estilo ups.conf con comentarios sobre posibles problemas de configuración (si los hay).

MANEJO DE ERRORES

Actualmente no existe un mecanismo específico para el manejo de errores.
