NUTSCAN_INIT(3) Manual de NUT NUTSCAN_INIT(3)

NOMBRE

nutscan_init - Inicializa la biblioteca nutscan.

SINOPSIS

        #include <nut-scan.h>
        void nutscan_init(void);

DESCRIPCIÓN

La función nutscan_init() debe llamarse al menos una vez antes de usar cualquier otra función de la biblioteca nutscan.

Actualiza las siguientes variables globales que pueden ser utilizadas por el usuario de la biblioteca nutscan para saber qué métodos de escaneo están disponibles en tiempo de ejecución.

Esto depende de las bibliotecas adicionales instaladas en el sistema:

•nutscan_avail_avahi = 1: El escaneo AVAHI NUT está disponible
•nutscan_avail_ipmi = 1: El escaneo IPMI está disponible
•nutscan_avail_nut = 1: El método NUT "antiguo" está disponible
•nutscan_avail_nut_simulation = 1: El método de dispositivos de simulación NUT está disponible
•nutscan_avail_snmp = 1: El método SNMP está disponible
•nutscan_avail_usb = 1: El método USB está disponible
•nutscan_avail_xml_http = 1: El método XML HTTP está disponible

Tenga en cuenta que si una método se informa como no disponible por estas variables, la llamada a la función nutscan_scan_* correspondiente siempre devolverá NULL.

NOTAS

Técnicamente, la función se define actualmente en el archivo nutscan-init.h.
