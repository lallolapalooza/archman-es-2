nullmailer-queue(8) Manual del Administrador del Sistema nullmailer-queue(8)

NOMBRE

nullmailer-queue - inserta mensajes de correo en la cola

SINOPSIS

nullmailer-queue

DESCRIPCIÓN

Este programa lee un mensaje de correo formateado desde la entrada estándar y lo inyecta de forma segura en la cola de correo saliente.

Se espera que los datos enviados a la entrada estándar tengan el siguiente formato: una línea que contiene el remitente del sobre, una o más líneas que contienen los destinatarios, una única línea en blanco y, a continuación, el contenido del mensaje exactamente como debe ser transmitido al destino. Todas las líneas terminan con un único carácter de salto de línea. Todas las direcciones deben contener un nombre de dominio totalmente calificado.

VALOR DE RETORNO

Sale con 0 si ha puesto el mensaje en cola correctamente. Si no ha podido poner el mensaje en cola, sale con 1 e imprime un mensaje de error en la salida estándar.

ARCHIVOS DE CONTROL

adminaddr
Si este archivo no está vacío, todos los destinatarios de usuarios en "localhost" (la cadena literal) o en el nombre de host canónico (del archivo de control me) se remapean a esta dirección. Esto se proporciona para permitir que los demonios locales puedan enviar correo electrónico a "alguien@localhost" y que llegue a un destino sensato en lugar de ser rechazado por su host de retransmisión. Para enviar a múltiples direcciones, póngalas todas en una sola línea separadas por una coma.
allmailfrom
Si este archivo no está vacío, su contenido anulará el remitente del sobre en todos los mensajes.

OTROS ARCHIVOS

/var/spool/nullmailer/queue
El directorio al que se mueven los mensajes completados.
/var/spool/nullmailer/tmp
El directorio en el que se forman temporalmente los mensajes.
/var/spool/nullmailer/trigger
Una tubería utilizada para activar nullmailer-send para que comience inmediatamente a enviar el mensaje desde la cola.

VER TAMBIÉN

nullmailer-inject(1), nullmailer-send(8)

LIMITACIONES

Este programa debería imponer límites de longitud de mensaje configurables a nivel de sistema.
