NUTSCAN_ADD_IP_RANGE(3) Manual de NUT NUTSCAN_ADD_IP_RANGE(3)

NOMBRE

nutscan_add_ip_range - Añade una entrada con un rango de direcciones IP (direcciones de inicio y fin) a una estructura `nutscan_ip_range_list_t`.

SINOPSIS

        #include <nut-scan.h>
        /* Un rango de direcciones IP: */
        typedef struct nutscan_ip_range_s {
                char * start_ip;
                char * end_ip;
                struct nutscan_ip_range_s * next;
        } nutscan_ip_range_t;
        /* Lista de rangos de direcciones IP y datos auxiliares: */
        typedef struct nutscan_ip_range_list_s {
                nutscan_ip_range_t * ip_ranges;         /* Lista enlazada real de entradas, primera entrada */
                nutscan_ip_range_t * ip_ranges_last;    /* Puntero al final de la lista para adiciones más rápidas */
                size_t ip_ranges_count;                 /* Contador de entradas añadidas */
        } nutscan_ip_range_list_t;
        size_t nutscan_add_ip_range(
                nutscan_ip_range_list_t *irl,
                char * start_ip,
                char * end_ip);

DESCRIPCIÓN

La función nutscan_add_ip_range() puede crear y añadir una entrada nutscan_ip_range_t basada en las entradas proporcionadas a la estructura nutscan_ip_range_list_t especificada. Se devuelve la cantidad resultante de entradas en la estructura, o 0 en caso de errores no fatales.

Esta función omite el trabajo si:

•el puntero a la estructura es NULL (se devuelve 0);
•no se proporcionó ni start_ip ni end_ip, es decir, ambos tienen valores NULL (se devuelve la longitud actual de la lista de la estructura);
•falló la asignación de la entrada (fatal).

Si solo se proporcionó uno de los valores de start_ip o end_ip (no NULL), se crea un rango de una sola dirección con ambas direcciones establecidas al mismo valor de puntero.

La estructura debe inicializarse antes de su uso mediante nutscan_init_ip_ranges().

El llamador debe liberar el contenido de la estructura después de completar su uso llamando a nutscan_free_ip_ranges() (después de lo cual la estructura puede ser reutilizada para una nueva lista), y liberar explícitamente el objeto de la estructura en sí si fue asignado dinámicamente (por ejemplo, llamando a nutscan_init_ip_ranges(NULL)).

NOTAS

Técnicamente, la función está definida actualmente en el archivo nutscan-ip.h.

Actualmente no hay comprobaciones de entradas duplicadas o superpuestas, por lo que las mismas direcciones IP y rangos completos de direcciones IP pueden añadirse a la lista (y eventualmente serían escaneados) muchas veces.
