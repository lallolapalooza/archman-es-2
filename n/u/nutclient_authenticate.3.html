nutclient_authenticate(3)

Paquete: nut

Licencias: GPL-2.0-or-later AND GPL-3.0-or-later

LIBNUTCLIENT_MISC(3) Manual NUT LIBNUTCLIENT_MISC(3)

NOMBRE

libnutclient_misc, nutclient_authenticate, nutclient_logout, nutclient_device_login, nutclient_get_device_num_logins, nutclient_device_master, nutclient_device_forced_shutdown - Funciones misceláneas en la biblioteca de acceso de cliente de alto nivel de Network UPS Tools

SINOPSIS

        #include <nutclient.h>
        typedef void* NUTCLIENT_t;
        void nutclient_authenticate(
                NUTCLIENT_t client,
                const char* login, const char* passwd);
        void nutclient_logout(NUTCLIENT_t client);
        void nutclient_device_login(NUTCLIENT_t client, const char* dev);
        int nutclient_get_device_num_logins(NUTCLIENT_t client, const char* dev);
        void nutclient_device_primary(NUTCLIENT_t client, const char* dev);
        /* Nombre OBSOLETO: */
        void nutclient_device_master(NUTCLIENT_t client, const char* dev);
        void nutclient_device_forced_shutdown(NUTCLIENT_t client, const char* dev);

DESCRIPCIÓN

•La función nutclient_authenticate() autentica al usuario.
•login es el nombre de usuario.
•passwd es la contraseña del usuario.
•La función nutclient_logout() se desconecta de forma elegante del servidor.
•La función nutclient_device_login() registra el hecho de que un sistema está consumiendo energía de este UPS.
•La función nutclient_get_device_num_logins() recupera el número de clientes que se han registrado para este dispositivo.
•Las funciones nutclient_device_master() y nutclient_device_primary() (nota: la primera está obsoleta desde NUT v2.8.0 en favor de la segunda) aseguran que las funciones en modo primario como FSD estén disponibles si es necesario.
•La función nutclient_device_forced_shutdown() establece la bandera de "apagado forzado" (FSD) en el dispositivo.

Argumentos comunes:

•dev es el nombre del dispositivo.
