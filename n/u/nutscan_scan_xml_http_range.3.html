NUTSCAN_SCAN_XML_HTT(3) Manual de NUT NUTSCAN_SCAN_XML_HTT(3)

NOMBRE

nutscan_scan_xml_http_range - Escanea la red en busca de dispositivos XML/HTTP.

SINOPSIS

        #include <nut-scan.h>
        #include <unistd.h> /* useconds_t */
        nutscan_device_t * nutscan_scan_xml_http_range(
                const char * start_ip,
                const char * end_ip,
                useconds_t usec_timeout,
                nutscan_xml_t * sec)
        nutscan_device_t * nutscan_scan_ip_range_xml_http(
                nutscan_ip_range_list_t * irl,
                useconds_t usec_timeout,
                nutscan_xml_t * sec)

DESCRIPCIÓN

Las funciones nutscan_scan_xml_http_range() y nutscan_scan_ip_range_xml_http() intentan detectar dispositivos compatibles con NUT XML/HTTP.

Si start_ip para la primera o irl para la segunda son NULL, la función respectiva lo hace emitiendo un mensaje de difusión en todas las interfaces de red actualmente configuradas.

De lo contrario, la primera consulta cada IP dentro del rango de start_ip a stop_ip, , donde startIP es obligatorio y stopIP es opcional (se escanea una dirección startIP si stopIP es NULL); mientras que la segunda puede recorrer varios rangos de direcciones IP representados por una estructura nutscan_ip_range_list_t.

Estos argumentos IP pueden ser direcciones IPv4 o IPv6 o nombres de host.

Espera hasta usec_timeout microsegundos para obtener una respuesta de los posibles dispositivos.

DEBES llamar a nutscan_init(3) antes de usar esta función.

VALOR DE RETORNO

La función nutscan_scan_xml_http_range() devuelve un puntero a una estructura nutscan_device_t que contiene todos los dispositivos encontrados o NULL si ocurre un error o no se encuentra ningún dispositivo.
