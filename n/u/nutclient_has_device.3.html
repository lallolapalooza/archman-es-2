LIBNUTCLIENT_DEVICES(3) Manual de NUT LIBNUTCLIENT_DEVICES(3)

NOMBRE

libnutclient_devices, nutclient_get_devices, nutclient_has_device, nutclient_get_device_description - Funciones relacionadas con dispositivos en la biblioteca de acceso de alto nivel de Network UPS Tools

SINOPSIS

        #include <nutclient.h>
        typedef void* NUTCLIENT_t;
        typedef char** strarr;
        strarr nutclient_get_devices(NUTCLIENT_t client);
        int nutclient_has_device(NUTCLIENT_t client, const char* dev);
        char* nutclient_get_device_description(NUTCLIENT_t client, const char* dev);

DESCRIPCIÓN

Estas funciones permiten gestionar dispositivos.

•La función nutclient_get_devices() recupera la lista de dispositivos supervisados por un cliente.

El strarr devuelto debe ser liberado por strarr_free (ver libnutclient_general(3)).

•La función nutclient_has_device() comprueba si un dispositivo está siendo supervisado por un cliente.
•La función nutclient_get_device_description() recupera la descripción del dispositivo.

La cadena de descripción devuelta debe ser liberada por free(3).

Argumentos comunes:

•dev es el nombre del dispositivo.
