NUTSCAN_SCAN_SNMP(3) Manual de NUT NUTSCAN_SCAN_SNMP(3)

NOMBRE

nutscan_scan_snmp - Escanea la red en busca de dispositivos SNMP.

SINOPSIS

        #include <nut-scan.h>
        #include <unistd.h> /* useconds_t */
        nutscan_device_t * nutscan_scan_snmp(
                const char * start_ip,
                const char * stop_ip,
                useconds_t timeout,
                nutscan_snmp_t * sec);
        nutscan_device_t * nutscan_scan_ip_range_snmp(
                nutscan_ip_range_list_t * irl,
                useconds_t usec_timeout,
                nutscan_snmp_t * sec);

DESCRIPCIÓN

Las funciones nutscan_scan_snmp() y nutscan_scan_ip_range_snmp() intentan detectar dispositivos SNMP compatibles con NUT. La primera realiza consultas SNMP en cada IP dentro del rango de start_ip a stop_ip, donde startIP es obligatorio y stopIP es opcional (se escanea una única dirección startIP si stopIP es NULL); mientras que la segunda puede recorrer varios rangos de direcciones IP representados por una estructura nutscan_ip_range_list_t.

Estos argumentos IP pueden ser direcciones o nombres de host IPv4 o IPv6.

Debe llamar a nutscan_init(3) antes de usar esta función.

Esta función espera hasta timeout microsegundos antes de considerar que una dirección IP no responde a las consultas SNMP.

Se debe pasar una estructura nutscan_snmp_t válida a esta función.

La estructura nutscan_snmp_t contiene los siguientes miembros, que deben rellenarse según se describe a continuación:

char * 'community';
char * 'secLevel';
char * 'secName';
char * 'authPassword';
char * 'privPassword';
char * 'authProtocol';
char * 'privProtocol';

Si community no es NULL, se envían solicitudes SNMP v1 usando esta community.

Si community es NULL y secLevel es NULL, se selecciona SNMP v1 y community se establece en "public".

En los demás casos, se utiliza SNMP v3. secLevel puede ser uno de SNMP_SEC_LEVEL_NOAUTH, SNMP_SEC_LEVEL_AUTHNOPRIV o SNMP_SEC_LEVEL_AUTHPRIV. secName es el nombre de seguridad y debe ser no NULL.

Si secLevel se establece en SNMP_SEC_LEVEL_AUTHNOPRIV, authPassword debe ser no NULL.

Si secLevel se establece en SNMP_SEC_LEVEL_AUTHPRIV, authPassword y privPassword deben ser no NULL.

Si authProtocol es NULL, se utiliza el protocolo MD5. De lo contrario, puede establecer authProtocol en "MD5" o "SHA".

Si privProtocol es NULL, se utiliza el protocolo DES. De lo contrario, puede establecer privProtocol en "AES" o "DES".

peername y handle se utilizan internamente y no necesitan inicialización.

VALOR DE RETORNO

La función nutscan_scan_snmp() devuelve un puntero a una estructura nutscan_device_t que contiene todos los dispositivos encontrados o NULL si ocurre un error o no se encuentra ningún dispositivo.
