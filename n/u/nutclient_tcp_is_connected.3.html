nutclient_tcp_is_connected(3)

Paquete: nut

Licencias: GPL-2.0-or-later AND GPL-3.0-or-later

LIBNUTCLIENT_TCP(3) Manual de NUT LIBNUTCLIENT_TCP(3)

NOMBRE

libnutclient_tcp, nutclient_tcp_create_client, nutclient_tcp_is_connected, nutclient_tcp_disconnect, nutclient_tcp_reconnect, nutclient_tcp_set_timeout, nutclient_tcp_get_timeout - Función relacionada con el protocolo TCP para la biblioteca de acceso de alto nivel de Network UPS Tools

SINOPSIS

        #include <nutclient.h>
        #include <cstdint> /* uint16_t */
        #include <ctime> /* time_t */
        typedef NUTCLIENT_t NUTCLIENT_TCP_t;
        NUTCLIENT_TCP_t nutclient_tcp_create_client(
                const char* host, uint16_t port);
        int nutclient_tcp_is_connected(NUTCLIENT_TCP_t client);
        void nutclient_tcp_disconnect(NUTCLIENT_TCP_t client);
        int nutclient_tcp_reconnect(NUTCLIENT_TCP_t client);
        void nutclient_tcp_set_timeout(NUTCLIENT_TCP_t client, time_t timeout);
        time_t nutclient_tcp_get_timeout(NUTCLIENT_TCP_t client);

DESCRIPCIÓN

Estas funciones permiten gestionar las conexiones a upsd(8) utilizando el protocolo TCP de NUT.

•La función nutclient_tcp_create_client() crea el contexto NUTCLIENT_TCP_t y tiene la intención de conectarse a upsd en host y port.

El contexto debe liberarse con nutclient_destroy().

•host puede ser un nombre de servidor o una dirección IPv4 o IPv6 válida como "localhost", "127.0.0.1" o "::1".
•port es un puerto TCP válido, generalmente 3493.
•La función nutclient_tcp_is_connected() comprueba si la conexión es válida.
•La función nutclient_tcp_disconnect() fuerza la desconexión de la conexión especificada.
•La función nutclient_tcp_reconnect() fuerza la reconexión de una conexión, desconectándola si es necesario.
•La función nutclient_tcp_set_timeout() establece la duración del tiempo de espera para las operaciones de E/S.
•La función nutclient_tcp_get_timeout() recupera la duración del tiempo de espera para las operaciones de E/S.

Los valores de timeout se especifican en segundos; utilice valores negativos para bloqueo.
