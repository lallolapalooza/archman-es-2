NUTSCAN_STRINGIFY_IP(3) Manual de NUT NUTSCAN_STRINGIFY_IP(3)

NOMBRE

nutscan_stringify_ip_ranges - Recopila el contenido de una estructura `nutscan_ip_range_list_t` en un búfer de cadena que puede ser impreso posteriormente en los registros.

SINOPSIS

        #include <nut-scan.h>
        const char * nutscan_stringify_ip_ranges(nutscan_ip_range_list_t *irl);

DESCRIPCIÓN

La función nutscan_stringify_ip_ranges() puede recorrer una estructura nutscan_ip_range_list_t para informar su contenido: el recuento de elementos de la lista y una lista separada por comas con cada elemento como un solo token (si start_ip==end_ip en ese rango) o un rango como start_ip .. end_ip.

Devuelve un puntero a un búfer estático interno que sería sobrescrito por llamadas posteriores, pero que el llamador no tiene que liberar.


Advertencia

¡Los llamadores deben usar semáforos si acceden a esta función en un contexto multihilo!

NOTAS

Técnicamente, la función está definida actualmente en el archivo nutscan-ip.h.

VER TAMBIÉN
