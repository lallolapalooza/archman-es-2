nutclient_has_device_command(3)

Paquete: nut

LIBNUTCLIENT_COMMAND(3) Manual de NUT LIBNUTCLIENT_COMMAND(3)

NOMBRE

libnutclient_commands, nutclient_get_device_commands, nutclient_has_device_command, nutclient_get_device_command_description, nutclient_execute_device_command - Funciones relacionadas con comandos instantáneos en la biblioteca de acceso de alto nivel de Network UPS Tools

SINOPSIS

        #include <nutclient.h>
        typedef void* NUTCLIENT_t;
        typedef char** strarr;
        strarr nutclient_get_device_commands(
                NUTCLIENT_t client,
                const char* dev);
        int nutclient_has_device_command(
                NUTCLIENT_t client,
                const char* dev, const char* cmd);
        char* nutclient_get_device_command_description(
                NUTCLIENT_t client,
                const char* dev, const char* cmd);
        void nutclient_execute_device_command(
                NUTCLIENT_t client,
                const char* dev, const char* cmd,
                const char* param="");

DESCRIPCIÓN

Estas funciones permiten gestionar comandos instantáneos de dispositivos.

•La función nutclient_get_device_commands() recupera la lista de nombres de comandos para un dispositivo.

El strarr devuelto debe liberarse con strarr_free.

•La función nutclient_has_device_command comprueba si el comando especificado es compatible con el dispositivo.

Devuelve 1 si es compatible y 0 si no lo es.

•La función nutclient_get_device_command_description recupera la descripción del comando, si la hay.

La cadena devuelta debe liberarse con free(3) (ver libnutclient_general(3)).

•La función nutclient_execute_device_command pretende ejecutar el comando instantáneo, con un parámetro opcional.

Argumentos comunes:

•dev es el nombre del dispositivo.
•cmd es el nombre del comando instantáneo.
