NAMEI(1) Comandos de usuario NAMEI(1)

NOMBRE

namei - sigue una ruta hasta encontrar un punto terminal

SINOPSIS

namei [opciones] ruta...

DESCRIPCIÓN

namei interpreta sus argumentos como rutas a cualquier tipo de archivo Unix (enlaces simbólicos, archivos, directorios, etc.). namei sigue entonces cada ruta hasta encontrar un punto final (un archivo, un directorio, un nodo de dispositivo, etc.). Si encuentra un enlace simbólico, muestra el enlace y comienza a seguirlo, indentando la salida para mostrar el contexto.

Este programa es útil para encontrar problemas de "demasiados niveles de enlaces simbólicos".

Para cada línea de salida, namei utiliza los siguientes caracteres para identificar el tipo de archivo encontrado:

   f: = la ruta que se está resolviendo actualmente
    d = directorio
    l = enlace simbólico (se muestra tanto el enlace como su contenido)
    s = socket
    b = dispositivo de bloques
    c = dispositivo de caracteres
    p = FIFO (tubería con nombre)
    - = archivo regular
    ? = algún tipo de error

namei imprime un mensaje informativo cuando se excede el número máximo de enlaces simbólicos que este sistema puede tener.

OPCIONES

-l, --long

Utiliza el formato de listado largo (igual que -m -o -v).

-m, --modes

Muestra los bits de modo de cada tipo de archivo al estilo de ls(1), por ejemplo 'rwxr-xr-x'.

-n, --nosymlinks

No seguir enlaces simbólicos.

-o, --owners

Muestra el nombre del propietario y del grupo de cada archivo.

-v, --vertical

Alinea verticalmente los modos y los propietarios.

-x, --mountpoints

Muestra los directorios de puntos de montaje con una 'D' en lugar de una 'd'.

-Z, --context

Muestra el contexto de seguridad del archivo o "?" si no está disponible. El soporte para contextos de seguridad es opcional y no tiene por qué compilarse en el binario de namei.

-h, --help

Muestra el texto de ayuda y sale.

-V, --version

Muestra la versión y sale.
