native2ascii(1) Herramientas de Internacionalización native2ascii(1)

NOMBRE

native2ascii - Crea aplicaciones localizables convirtiendo un archivo con caracteres en cualquier codificación de caracteres compatible a una con escapes ASCII y/o Unicode o viceversa.

SINOPSIS

native2ascii [ archivo_entrada ] [ archivo_salida ]
archivo_entrada
El archivo codificado que se convertirá a ASCII.
archivo_salida
El archivo ASCII convertido.

DESCRIPCIÓN

El comando native2ascii convierte archivos codificados compatibles con el Entorno de Ejecución de Java (JRE) a archivos codificados en ASCII, utilizando la notación de escapes Unicode (\uxxxx) para todos los caracteres que no forman parte del conjunto de caracteres ASCII. Este proceso es necesario para los archivos de propiedades que contienen caracteres que no están en los conjuntos de caracteres ISO-8859-1. La herramienta también puede realizar la conversión inversa.

Si se omite el valor de archivo_salida, se utilizará la salida estándar para la salida. Si, además, se omite el valor de archivo_entrada, se utilizará la entrada estándar para la entrada.

OPCIONES

-reverse

Realiza la operación inversa: Convierte un archivo codificado en ISO-8859-1 con escapes Unicode a un archivo en cualquier codificación de caracteres compatible con el JRE.
-encoding nombre_codificacion

Especifica el nombre de la codificación de caracteres que se utilizará en el procedimiento de conversión. Si esta opción no está presente, se utilizará la codificación de caracteres predeterminada (según lo determine el método java.nio.charset.Charset.defaultCharset). La cadena nombre_codificacion debe ser el nombre de una codificación de caracteres compatible con el JRE. Consulte Codificaciones Soportadas en http://docs.oracle.com/javase/8/docs/technotes/guides/intl/encoding.doc.html
-Jopción

Pasa opción a la Máquina Virtual Java (JVM), donde opción es una de las opciones descritas en la página de referencia para el lanzador de aplicaciones Java. Por ejemplo, -J-Xms48m establece la memoria de inicio en 48 MB. Consulte java(1).
