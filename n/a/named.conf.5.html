NOMBRE

named.conf - archivo de configuración para **named**

SINOPSIS

named.conf

DESCRIPCIÓN

named.conf es el archivo de configuración para named <#std-iscman-named>.

Para una documentación completa sobre las sentencias de configuración, consulte la sección de Referencia de Configuración en el Manual de Referencia del Administrador de BIND 9.

Las sentencias se encierran entre llaves y terminan con un punto y coma. Las cláusulas de las sentencias también terminan con un punto y coma. Se admiten los estilos de comentario habituales:

Estilo C: /* */

Estilo C++: // hasta el final de la línea

Estilo Unix: # hasta el final de la línea
