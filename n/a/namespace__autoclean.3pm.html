namespace::autoclean(3) Documentación de Perl contribuida por el usuario namespace::autoclean(3)

NOMBRE

namespace::autoclean - Mantén las importaciones fuera de tu espacio de nombres

VERSIÓN

versión 0.31

SINOPSIS

package Foo;
use namespace::autoclean;
use Some::Package qw/imported_function/;
sub bar { imported_function('stuff') }
# más tarde:
Foo->bar;               # funciona
Foo->imported_function; # fallará. imported_function se limpió después de la compilación

DESCRIPCIÓN

Cuando importas una función a un paquete de Perl, naturalmente también estará disponible como un método.

El pragma "namespace::autoclean" eliminará todos los símbolos importados al final del ciclo de compilación del paquete actual. Las funciones llamadas en el propio paquete seguirán siendo enlazadas por su nombre, pero no aparecerán como métodos en tu clase o instancias.

Este módulo es muy similar a namespace::clean, excepto que limpiará todas las funciones importadas, sin importar si las importaste antes o después de usar el pragma. Tampoco tocará nada que parezca un método.

Si estás escribiendo un exportador y quieres limpiar después de ti mismo (y de tus compañeros), puedes usar el modificador "-cleanee" para especificar qué paquete limpiar:

package My::MooseX::namespace::autoclean;
use strict;
use namespace::autoclean (); # sin limpieza, solo carga
sub import {
    namespace::autoclean->import(
      -cleanee => scalar(caller),
    );
}

QUÉ SE LIMPIA Y QUÉ NO

"namespace::autoclean" dejará intacto todo lo que considere un método. Para clases Moose, esto se basa en el método "get_method_list" de Class::MOP::Class. Para clases no-Moose, todo lo definido dentro del paquete se identificará como un método. Esto debería coincidir con la definición de método de Moose. Adicionalmente, las subrutinas mágicas instaladas por overload no se limpiarán.

PARÁMETROS

-also => [ ELEMENTO | EXPRESIÓN_REGULAR | SUB, .. ]

-also => ELEMENTO

-also => EXPRESIÓN_REGULAR

-also => SUB

A veces no quieres limpiar solo las importaciones, sino también las funciones auxiliares que utilizas en tus métodos. El modificador "-also" se puede usar para declarar una lista de funciones que deben eliminarse además de cualquier importación:

use namespace::autoclean -also => ['some_function', 'another_function'];

Si solo una función necesita ser limpiada adicionalmente, el modificador "-also" también acepta una cadena simple:

use namespace::autoclean -also => 'some_function';

En algunas situaciones, podrías desear una solución de limpieza más *poderosa*.

El modificador "-also" puede tomar una expresión regular o una referencia a código para hacer coincidir los nombres de funciones locales a limpiar.

use namespace::autoclean -also => qr/^_/
use namespace::autoclean -also => sub { $_ =~ m{^_} };
use namespace::autoclean -also => [qr/^_/ , qr/^hidden_/ ];
use namespace::autoclean -also => [sub { $_ =~ m/^_/ or $_ =~ m/^hidden/ }, sub { uc($_) == $_ } ];

-except => [ ELEMENTO | EXPRESIÓN_REGULAR | SUB, .. ]

-except => ELEMENTO

-except => EXPRESIÓN_REGULAR

-except => SUB

Esto toma exactamente las mismas opciones que "-also", excepto que todo lo que coincida *no* será limpiado.

ADVERTENCIAS

Cuando se usa con clases Moo, la heurística utilizada para verificar métodos no funcionará correctamente para métodos de roles consumidos en tiempo de compilación.

package My::Class;
use Moo;
use namespace::autoclean;
# Mal, los métodos consumidos se limpiarán
BEGIN { with 'Some::Role' }
# Bien, los métodos del rol se mantendrán
with 'Some::Role';

Adicionalmente, la detección de métodos puede no funcionar correctamente en clases Mouse en versiones de perl anteriores a la 5.10.
