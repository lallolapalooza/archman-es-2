NANO(1) General Commands Manual NANO(1)

NAME

nano - Nano's ANOther text editor, inspired by Pico

SYNOPSIS

nano [options] [[+line[,column]] file]...

nano [options] [[+[crCR]{/|?}string] file]...

NOTICE

Since version 8.0, to be newcomer friendly, ^F starts a forward search, ^B starts a backward search, M-F searches the next occurrence forward, and M-B searches the next occurrence backward. If you want those keystrokes to do what they did before version 8.0, add the following lines at the end of your nanorc file:

bind ^F forward main
bind ^B back main
bind M-F formatter main
bind M-B linter main

DESCRIPTION

nano is a small and friendly text editor. It copies the look and feel of Pico, but is free software, and implements several features that Pico lacks, such as: opening multiple files, scrolling per line, undo/redo, syntax coloring, line numbering, and soft-wrapping overlong lines.

When giving a filename on the command line, the cursor can be put on a specific line by adding the line number with a plus sign (+) before the filename, and even in a specific column by adding it with a comma. Negative numbers count from the end of the file or line.

The cursor can be put on the first or last occurrence of a specific string by specifying that string after +/ or +? before the filename. The string can be made case sensitive and/or caused to be interpreted as a regular expression by inserting c and/or r after the + sign. These search modes can be explicitly disabled by using the uppercase variant of those letters: C and/or R. When the string contains spaces, it needs to be enclosed in quotes. To give an example: to open a file at the first occurrence of the word "Foo", you would do:

nano +c/Foo file

As a special case: if instead of a filename a dash (-) is given, nano will read data from standard input.

EDITING

Entering text and moving around in a file is straightforward: typing the letters and using the normal cursor movement keys. Commands are entered by using the Control (^) and the Alt or Meta (M-) keys. Typing ^K deletes the current line and puts it in the cutbuffer. Consecutive ^Ks put all deleted lines together in the cutbuffer. Any cursor movement or executing any other command causes the next ^K to overwrite the cutbuffer. A ^U pastes the current contents of the cutbuffer at the current cursor position.

When a more precise piece of text needs to be cut or copied, you can mark its start with ^6, move the cursor to its end (the marked text is highlighted), and then use ^K to cut it, or M-6 to copy it to the cutbuffer. You can also save the marked text to a file with ^O, or spell check it with ^T^T.

On some terminals, text can be selected also by holding down Shift while using the arrow keys. Holding down the Ctrl or Alt key too increases the stride. Any cursor movement without Shift being held cancels such a selection.

Any valid Unicode code point can be inserted into the buffer by typing M-V followed by the hexadecimal digits of the code point (concluded with <Space> or <Enter> when it are fewer than six digits). A literal control code (except ^J) can be inserted by typing M-V followed by the pertinent keystroke.

The two lines at the bottom of the screen show some important commands; the built-in help (^G) lists all the available ones. The default key bindings can be changed via a nanorc file — see nanorc(5).

OPTIONS

-A, --smarthome
Make the Home key smarter. When Home is pressed anywhere but at the very beginning of non-whitespace characters on a line, the cursor jumps to that beginning (either forwards or backwards). If the cursor is already at that position, it jumps to the true beginning of the line.
-B, --backup
When saving a file, back up the previous version of it, using the current filename suffixed with a tilde (~).
-C directory, --backupdir=directory
Make and keep not just one backup file, but make and keep a uniquely numbered one every time a file is saved — when backups are enabled (-B). The uniquely numbered files are stored in the specified directory.
-D, --boldtext
For the interface, use bold instead of reverse video. This can be overridden for specific elements by setting the options titlecolor, statuscolor, promptcolor, minicolor, keycolor, numbercolor, and/or selectedcolor in your nanorc file. See nanorc(5).
-E, --tabstospaces
Convert each typed tab to spaces — to the number of spaces that a tab at that position would take up. (Note: pasted tabs are not converted.)
-F, --multibuffer
Read a file into a new buffer by default.
-G, --locking
Use vim-style file locking when editing files.
-H, --historylog
Save the last hundred search strings and replacement strings and executed commands, so they can be easily reused in later sessions.
-I, --ignorercfiles
Don't look at the system's nanorc nor at the user's nanorc.
-J number, --guidestripe=number
Draw a vertical stripe at the given column, to help judge the width of the text. (The color of the stripe can be changed with set stripecolor in your nanorc file.)
-K, --rawsequences
Interpret escape sequences directly, instead of asking ncurses to translate them. (If you need this option to get some keys to work properly, it means that the terminfo terminal description that is used does not fully match the actual behavior of your terminal. This can happen when you ssh into a BSD machine, for example.) Using this option disables nano's mouse support.
-L, --nonewlines
Don't automatically add a newline when a text does not end with one. (This can cause you to save non-POSIX text files.)
-M, --trimblanks
Snip trailing whitespace from the wrapped line when automatic hard-wrapping occurs or when text is justified.
-N, --noconvert
Disable automatic conversion of files from DOS/Mac format.
-O, --bookstyle
When justifying, treat any line that starts with whitespace as the beginning of a paragraph (unless auto-indenting is on).
-P, --positionlog
For the 200 most recent files, log the last position of the cursor, and place it at that position again upon reopening such a file. Also save and restore the positions of any anchors.

"expresión regular", --quotestr="expresión regular"
Establece la expresión regular para hacer coincidir la parte de citación de una línea. El valor predeterminado es "^([ \t]*([!#%:;>|}]|//))+". (Tenga en cuenta que \t representa un Tab real). Esto permite rejustificar bloques de texto citado al componer correos electrónicos y reajustar bloques de comentarios de línea al escribir código fuente.
-R, --restricted
Modo restringido: no leer ni escribir en ningún archivo que no se especifique en la línea de comandos. Esto significa: no leer ni escribir archivos de historial; no permitir la suspensión; no permitir la corrección ortográfica; no permitir añadir o anteponer texto a un archivo, ni guardarlo con un nombre diferente si ya tiene uno; y no crear archivos de copia de seguridad. El modo restringido también se puede activar invocando nano con cualquier nombre que comience con 'r' (por ejemplo, "rnano").
-S, --softwrap
Muestra en varias filas de pantalla las líneas que exceden el ancho de la pantalla. (Puede hacer que este ajuste de línea suave ocurra en los espacios en blanco en lugar de bruscamente en el borde de la pantalla, usando también --atblanks).
-T número, --tabsize=número
Establece el tamaño (ancho) de una tabulación a número de columnas. El valor de número debe ser mayor que 0. El valor predeterminado es 8.
-U, --quickblank
Hace que los mensajes de la barra de estado desaparezcan después de 1 pulsación de tecla en lugar de después de 20. Tenga en cuenta que la opción -c (--constantshow) anula esto. Cuando la opción --minibar o --zero está activa, --quickblank hace que un mensaje desaparezca después de 0.8 segundos en lugar de después de los 1.5 segundos predeterminados.
-V, --version
Muestra el número de versión actual y sale.
-W, --wordbounds
Detecta los límites de palabras de manera diferente al tratar los caracteres de puntuación como parte de una palabra.
-X "caracteres", --wordchars="caracteres"
Especifica qué otros caracteres (además de los alfanuméricos normales) deben considerarse parte de una palabra. Al usar esta opción, probablemente querrá omitir -W (--wordbounds).
-Y nombre, --syntax=nombre
Especifica el nombre de la resaltación de sintaxis a usar de entre las definidas en los archivos nanorc.
-Z, --zap
Permite que una tecla de retroceso o suprimir sin modificar borre la región marcada (en lugar de un solo carácter, y sin afectar al búfer de corte).
-a, --atblanks
Al realizar ajuste de línea suave, ajusta las líneas en los espacios en blanco en lugar de siempre en el borde de la pantalla.
-b, --breaklonglines
Ajusta automáticamente la línea actual cuando se vuelve demasiado larga. (Esta opción es lo opuesto a -w (--nowrap) — la última especificada es la que tiene efecto).
-c, --constantshow
Informa constantemente la posición del cursor en la barra de estado. Tenga en cuenta que esto anula la opción -U (--quickblank).
-d, --rebinddelete
Interpreta las teclas Suprimir y Retroceso de manera diferente para que tanto Retroceso como Suprimir funcionen correctamente. Solo debe usar esta opción cuando en su sistema Retroceso actúe como Suprimir o Suprimir actúe como Retroceso.
-e, --emptyline
No usa la línea debajo de la barra de título, dejándola completamente en blanco.
-f archivo, --rcfile=archivo
Lee solo este archivo para establecer las opciones de nano, en lugar de leer los archivos nanorc del sistema y del usuario.
-g, --showcursor
Hace que el cursor sea visible en el explorador de archivos (colocándolo en el elemento resaltado) y en el visor de ayuda. Útil para usuarios de braille y personas con baja visión.
-h, --help
Muestra un resumen de las opciones de línea de comandos disponibles y sale.
-i, --autoindent
Indenta automáticamente una línea recién creada con el mismo número de tabulaciones y/o espacios que la línea anterior (o que la siguiente si la línea anterior es el inicio de un párrafo).
-j, --jumpyscrolling
Desplaza el contenido del búfer por medio pantalla en lugar de por línea.
-k, --cutfromcursor
Hace que el comando 'Cortar Texto' (normalmente ^K) corte desde la posición actual del cursor hasta el final de la línea, en lugar de cortar la línea completa.
-l, --linenumbers
Muestra números de línea a la izquierda del área de texto. (Cualquier línea con un ancla recibe adicionalmente una marca en el margen).
-m, --mouse
Habilita el soporte del ratón, si está disponible para su sistema. Cuando está habilitado, los clics del ratón se pueden usar para colocar el cursor, establecer la marca (con doble clic) y ejecutar atajos. El ratón funciona en el Sistema de Ventanas X, y en la consola cuando gpm está en ejecución. El texto todavía se puede seleccionar arrastrando manteniendo presionada la tecla Shift.
-n, --noread
Trata cualquier nombre dado en la línea de comandos como un archivo nuevo. Esto permite a nano escribir en tuberías con nombre: comienza con un búfer en blanco y escribe en la tubería cuando el usuario guarda el "archivo". De esta manera, nano se puede usar como editor en combinación con, por ejemplo, gpg sin tener que escribir primero datos confidenciales en el disco.
-o directorio, --operatingdir=directorio
Cambia al directorio dado y permite leer y escribir archivos solo en este directorio y sus subdirectorios.
-p, --preserve
Conserva las secuencias XOFF y XON (^S y ^Q) para que sean capturadas por la terminal (deteniendo y reanudando la salida). Tenga en cuenta que la opción -/ (--modernbindings) anula esto.
-q, --indicator
Muestra una "barra de desplazamiento" en el lado derecho de la ventana de edición. Muestra la posición de la vista en el búfer y cuánto del búfer cubre la vista.
-r número, --fill=número
Establece el ancho objetivo para justificar y ajustar automáticamente líneas largas en este número de columnas. Si el valor es 0 o menor, el ajuste ocurre en el ancho de la pantalla menos número de columnas, permitiendo que el punto de ajuste varíe junto con el ancho de la pantalla si la pantalla se redimensiona. El valor predeterminado es -8.
-s "programa [argumento ...]", --speller="programa [argumento ...]"
Usa este comando para realizar la corrección ortográfica y de errores, en lugar de usar el corrector integrado que llama a hunspell(1) o spell(1).
-t, --saveonexit
Guarda un búfer modificado sin preguntar (al salir con ^X).
-u, --unix
Guarda un archivo por defecto en formato Unix. Esto anula el comportamiento predeterminado de nano de guardar un archivo en el formato que tenía. (Esta opción no tiene efecto cuando también usa --noconvert).
-v, --view
Solo visualiza el archivo y no permite la edición: modo de solo lectura. Este modo permite al usuario abrir también otros archivos para visualizarlos, a menos que también se especifique --restricted.
-w, --nowrap
No ajusta automáticamente la línea actual cuando se vuelve demasiado larga. Este es el comportamiento predeterminado. (Esta opción es lo opuesto a -b (--breaklonglines) — la última especificada es la que tiene efecto).
-x, --nohelp
No muestra las dos líneas de ayuda en la parte inferior de la pantalla.
-y, --afterends
Hace que Ctrl+Derecha y Ctrl+Suprimir se detengan en los finales de palabra en lugar de en los comienzos.
-z, --listsyntaxes
Lista los nombres de las sintaxis disponibles y sale.
-!, --magic
Cuando ni el nombre del archivo ni su primera línea dan una pista, intenta usar libmagic para determinar la sintaxis aplicable.
-@, --colonparsing
Cuando un nombre de archivo dado en la línea de comandos termina en dos puntos seguidos de dígitos y este archivo no existe, se eliminan los dos puntos seguidos de dígitos y se entienden los dígitos como un número de línea. Si el nombre de archivo recortado tampoco existe, repite el proceso y entiende los dos números obtenidos como número de línea y columna. Pero si el nombre de archivo doblemente recortado tampoco existe, entonces olvida el recorte y acepta el nombre de archivo original tal cual. Para deshabilitar este análisis de dos puntos para algún archivo, usa +1 o similar antes del nombre de archivo relevante.
-%, --stateflags
Utiliza la esquina superior derecha de la pantalla para mostrar algunas banderas de estado: I cuando la indentación automática está activada, M cuando la marca está activada, L cuando se ajustan líneas largas (rompiendo líneas largas), R cuando se está grabando una macro y S cuando se ajustan líneas suaves. Cuando el búfer se ha modificado, se muestra un asterisco (*) después del nombre del archivo en el centro de la barra de título.
-_, --minibar
Suprime la barra de título y en su lugar muestra información sobre el búfer actual en la parte inferior de la pantalla, en el espacio de la barra de estado. En esta "minibarra" se muestra el nombre del archivo a la izquierda, seguido de un asterisco si el búfer ha sido modificado. A la derecha se muestran el número de línea y columna actuales, el código del carácter debajo del cursor (en formato Unicode: U+xxxx), las mismas banderas que se muestran con --stateflags, y un porcentaje que expresa qué tan lejos está el cursor dentro del archivo (línea por línea). Cuando un archivo se carga
ded o guardado, y también al cambiar entre búferes, el número de líneas en el búfer se muestra después del nombre del archivo. Este número se borra al presionar la siguiente tecla, o se reemplaza con un contador [i/n] cuando hay varios búferes abiertos. Los números de línea más columna y el código del carácter se muestran solo cuando se usa --constantshow, y se pueden activar o desactivar con M-C. Las banderas de estado se muestran solo cuando se usa --stateflags.
-0, --zero
Oculta todos los elementos de la interfaz (barra de título, barra de estado y líneas de ayuda) y utiliza todas las filas de la terminal para mostrar el contenido del búfer. La barra de estado aparece solo cuando hay un mensaje significativo, y desaparece después de 1.5 segundos o al presionar la siguiente tecla. Con M-Z se puede alternar la barra de título y la barra de estado. Con M-X las líneas de ayuda.
-/, --modernbindings
Utiliza enlaces de teclas similares a los que usan la mayoría de los programas modernos: ^X corta, ^C copia, ^V pega, ^Z deshace, ^Y rehace, ^F busca hacia adelante, ^G busca siguiente, ^S guarda, ^O abre un archivo, ^Q sale, y (cuando la terminal lo permite) ^H muestra ayuda. Además, ^A establece la marca, ^R realiza reemplazos, ^D busca anterior, ^P muestra la posición, ^T va a una línea, ^W escribe un archivo, y ^E ejecuta un comando. Ten en cuenta que esto anula la opción -p (--preserve).

INTERRUPTORES

Varias de las opciones anteriores se pueden activar y desactivar también mientras nano se está ejecutando. Por ejemplo, M-L activa o desactiva el ajuste de línea duro para líneas largas, M-S activa o desactiva el ajuste de línea suave, M-N activa o desactiva los números de línea, M-M activa o desactiva el ratón, M-I la auto-indentación, y M-X las líneas de ayuda. Consulta al final del texto de ayuda de ^G para obtener una lista completa.

El interruptor M-X es especial: funciona en todos los menús excepto en el visor de ayuda y el linter. Todos los demás interruptores funcionan solo en el menú principal.

ARCHIVOS

Cuando se especifica --rcfile, nano lee solo el archivo especificado para configurar sus opciones, sintaxis y enlaces de teclas. Sin esa opción, nano lee dos archivos de configuración: primero el archivo nanorc del sistema (si existe), y luego el archivo nanorc del usuario (si existe), ya sea ~/.nanorc o $XDG_CONFIG_HOME/nano/nanorc o ~/.config/nano/nanorc, el que se encuentre primero. Consulta nanorc(5) para obtener más información sobre el contenido posible de esos archivos.

Consulta /usr/share/nano/ y /usr/share/nano/extra/ para ver las definiciones de resaltado de sintaxis disponibles.

NOTAS

La suspensión está habilitada por defecto, accesible a través de ^T^Z. (Si deseas que un simple ^Z suspenda nano, añade bind ^Z suspend main a tu nanorc.)

En una solicitud de Sí/No, ^Y se puede usar para "Sí", ^N para "No", y ^A para "Todo". Estos enlaces no listados funcionan en cualquier localidad.

Cuando quieras copiar texto marcado de nano al portapapeles del sistema, consulta uno de los ejemplos en la página del manual de nanorc(5).

Si no se especifica ningún comando alternativo de corrector ortográfico en la línea de comandos ni en ninguno de los archivos nanorc, nano busca uno en la variable de entorno SPELL.

En algunos casos, nano intenta volcar el búfer a un archivo de emergencia. Esto ocurre principalmente si nano recibe una señal SIGHUP o SIGTERM o se queda sin memoria. Escribe el búfer en un archivo llamado nano.save si el búfer no tenía nombre previamente, o añade un sufijo ".save" al nombre del archivo actual. Si ya existe un archivo de emergencia con ese nombre en el directorio actual, añade ".save" más un número (por ejemplo, ".save.1") al nombre del archivo actual para hacerlo único. En modo multibúfer, nano escribe todos los búferes abiertos en sus respectivos archivos de emergencia.

Si tienes alguna pregunta sobre cómo usar nano en alguna situación específica, puedes preguntar en help-nano@gnu.org.

ERRORES

La grabación y reproducción de macros de teclado solo funciona correctamente en un emulador de terminal, no en una consola Linux (VT), porque esta última no distingue por defecto las teclas de flecha modificadas de las no modificadas.

Por favor, informa de cualquier otro error que encuentres en:
https://savannah.gnu.org/bugs/?group=nano.

Cuando nano falla, guarda cualquier búfer modificado en archivos .save de emergencia. Si puedes reproducir el fallo y quieres obtener un volcado (backtrace), define la variable de entorno NANO_NOCATCH.
