NOMBRE

nameif - nombra interfaces de red basándose en direcciones MAC

SINOPSIS

nameif [-c archivo_config] [-s]
nameif [-c archivo_config] [-s] {interfaz direccion_mac}

DESCRIPCIÓN

nameif renombra interfaces de red basándose en direcciones MAC. Cuando no se proporcionan argumentos, se lee /etc/mactab. Cada línea de este archivo contiene un nombre de interfaz y una dirección MAC Ethernet. Se permiten comentarios que comiencen con #. De lo contrario, se procesan las interfaces especificadas en la línea de comandos. nameif busca la interfaz con la dirección MAC dada y la renombra al nombre proporcionado.

Cuando se proporciona el argumento -s, todos los mensajes de error se envían a syslog.

Cuando se proporciona el argumento -c con un nombre de archivo, se lee ese archivo en lugar de /etc/mactab.

NOTAS

nameif debería ejecutarse antes de que la interfaz esté activa, de lo contrario, fallará.

ARCHIVOS

/etc/mactab

ERRORES

Actualmente solo funciona para Ethernet.
