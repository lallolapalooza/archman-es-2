NOMBRE

naptime.bt - Rastrea llamadas de suspensión voluntaria. Usa bpftrace/eBPF.

SINOPSIS

naptime.bt

DESCRIPCIÓN

Esta herramienta rastrea las suspensiones de aplicaciones y puede ser utilizada para depurar latencias altas que pueden ser causadas por suspensiones deliberadas insertadas en rutinas de aplicaciones, especialmente scripts de administración.

Esta herramienta funciona rastreando la llamada al sistema nanosleep(2) usando los puntos de rastreo de llamadas al sistema.

Dado que esto utiliza BPF, solo el usuario root puede usar esta herramienta.

REQUISITOS

CONFIG_BPF y bpftrace.

EJEMPLOS

Rastrear suspensiones de aplicaciones a través de nanosleep(2):
# naptime.bt

CAMPOS

TIEMPO
Una marca de tiempo en formato HH:MM:SS.
PPID
ID del proceso padre.
PCOMM
Nombre del proceso padre.
PID
El ID del proceso que está suspendido.
COMM
El nombre del proceso que está suspendido.
SEGUNDOS
La duración solicitada de la suspensión.

SOBRECARGA

Se espera que las llamadas a nanosleep(2) sean de baja frecuencia (<< 100/s), por lo que se espera que la sobrecarga de esta herramienta sea insignificante.

FUENTE

Esta herramienta se originó en el libro "BPF Performance Tools", publicado por Addison Wesley (2019):

http://www.brendangregg.com/bpf-performance-tools-book.html

Consulte el libro para obtener más documentación sobre esta herramienta.

Esta versión está en el repositorio de bpftrace:

https://github.com/bpftrace/bpftrace

Busque también en la distribución de bpftrace un archivo complementario _examples.txt que contenga ejemplos de uso, salida y comentarios para esta herramienta.
