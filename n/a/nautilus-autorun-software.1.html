NOMBRE

nautilus-autorun-software - herramienta auxiliar

SINOPSIS

nautilus-autorun-software uri-de-montaje

DESCRIPCIÓN

nautilus-autorun-software es una herramienta auxiliar para el escritorio GNOME para iniciar software desde medios con archivos Autostart.

Es el manejador por defecto de "x-content/unix-software" para el escritorio GNOME.

VER TAMBIÉN

Los archivos Autostart se describen en https://specifications.freedesktop.org/autostart-spec/autostart-spec-latest.html

ERRORES

Los informes de errores se pueden encontrar y presentar en https://gitlab.gnome.org/GNOME/nautilus/issues
