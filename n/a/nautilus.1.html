Nautilus(1) Manual de comandos generales Nautilus(1)

NOMBRE

nautilus - un gestor de archivos para GNOME

SINOPSIS

nautilus [opciones] URIs...

DESCRIPCIÓN

nautilus es un gestor de archivos, diseñado para el entorno de escritorio GNOME.

--version
Mostrar la versión del programa.
-w, --new-window
Abrir siempre una nueva ventana para navegar por las URIs especificadas.
-q, --quit
Salir de Nautilus.
-s, --select
Seleccionar la URI especificada en la carpeta padre.
-h, --help
Mostrar un resumen de las opciones.
Otras opciones estándar de GNOME no listadas aquí también son compatibles.

VER TAMBIÉN

La documentación se puede acceder presionando F1 en la aplicación o a través del menú de la aplicación.

Para más información, visite el sitio web https://apps.gnome.org/Nautilus

ERRORES

Los informes de errores se pueden encontrar y enviar en https://gitlab.gnome.org/GNOME/nautilus/issues
