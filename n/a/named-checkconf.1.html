NOMBRE

named-checkconf - herramienta de verificación de sintaxis del archivo de configuración de named

SINOPSIS

named-checkconf [-achjklvz] [-p [-x ]] [-t directorio] {archivo}

DESCRIPCIÓN

named-checkconf verifica la sintaxis, pero no la semántica, de un archivo de configuración de named <#std-iscman-named>. El archivo, junto con todos los archivos incluidos por él, se analiza y se verifica si hay errores de sintaxis. Si no se especifica ningún archivo, se lee /etc/named.conf por defecto.

Nota: los archivos que named <#std-iscman-named> lee en contextos de análisis separados, como rndc.conf o rndc.key, no son leídos automáticamente por named-checkconf. Los errores de configuración en estos archivos pueden hacer que named <#std-iscman-named> no se ejecute, incluso si named-checkconf tuvo éxito. Sin embargo, named-checkconf puede ejecutarse en estos archivos explícitamente.

OPCIONES

-a
No comprueba los algoritmos de claves DNSSEC de dnssec-policy contra los compatibles con el proveedor criptográfico. Esto es útil al comprobar un named.conf destinado a ejecutarse en otra máquina con posiblemente un conjunto diferente de algoritmos de claves DNSSEC compatibles.
-h
Esta opción imprime el resumen de uso y sale.
-j
Al cargar un archivo de zona, esta opción instruye a named <#std-iscman-named> a leer el journal si existe.
-k
Comprueba las claves DNSSEC de dnssec-policy contra los archivos de claves en el directorio-claves. Esto es útil al comprobar un named.conf para asegurar que una política DNSSEC coincide con las claves existentes.
-l
Esta opción lista todas las zonas configuradas. Cada línea de salida contiene el nombre de la zona, la clase (por ejemplo, IN), la vista y el tipo (por ejemplo, primaria o secundaria).
-c
Esta opción especifica que solo se debe comprobar la configuración "central". Esto suprime la carga de módulos de plugins y hace que todos los parámetros de las sentencias plugin se ignoren.
-i
Esta opción ignora las advertencias sobre opciones obsoletas.
-p
Esta opción imprime el named.conf <#std-iscman-named.conf> y los archivos incluidos en forma canónica si no se detectaron errores. Consulte también la opción -x.
-t directorio
Esta opción instruye a named <#std-iscman-named> a hacer chroot al directorio, de modo que las directivas include en el archivo de configuración se procesen como si fueran ejecutadas por un named <#std-iscman-named> chrooted de forma similar.
-v
Esta opción imprime la versión del programa named-checkconf y sale.
-x
Al imprimir los archivos de configuración en forma canónica, esta opción oculta los secretos compartidos reemplazándolos con cadenas de signos de interrogación (?). Esto permite compartir el contenido de named.conf <#std-iscman-named.conf> y archivos relacionados - por ejemplo, al enviar informes de errores - sin comprometer datos privados. Esta opción no se puede usar sin -p.
-z
Esta opción realiza una carga de prueba de todas las zonas de tipo primary encontradas en named.conf <#std-iscman-named.conf>.
archivo
Esto indica el nombre del archivo de configuración que se va a comprobar. Si no se especifica, por defecto es /etc/named.conf.

VALORES DE RETORNO

named-checkconf devuelve un estado de salida de 1 si se detectaron errores y 0 en caso contrario.

VER TAMBIÉN
