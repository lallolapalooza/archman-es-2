NOMBRE

natpmpc - Cliente de prueba y configurador de mapeo de la biblioteca NAT-PMP.

SINOPSIS

Mostrar la dirección IP pública:
natpmpc

Añadir un mapeo de puerto:
natpmpc -a <puerto público> <puerto privado> <protocolo> [duración]

DESCRIPCIÓN

Para eliminar un mapeo, configúralo con una duración de 0 segundos. Para eliminar todos los mapeos de tu máquina, usa 0 como puerto privado y duración.
