NOMBRE

named-nzd2nzf - convierte una base de datos NZD a formato de texto NZF

SINOPSIS

named-nzd2nzf {nombre_archivo}

DESCRIPCIÓN

named-nzd2nzf convierte una base de datos NZD a formato NZF y la imprime en la salida estándar. Esto puede usarse para revisar la configuración de zonas que fueron añadidas a named <#std-iscman-named> a través de rndc addzone <#cmdoption-rndc-arg-addzone>. También puede usarse para restaurar el antiguo formato de archivo al revertir a una versión anterior de BIND.

ARGUMENTOS

nombre_archivo
Este es el nombre del archivo .nzd cuyos contenidos deben ser impresos.
