NOMBRE

nms2dlf - convierte archivos de registro SMTP del Netscape Messaging Server al DLF de correo electrónico

SINOPSIS

nms2dlf STDIN STDOUT

DESCRIPCIÓN

Este programa convierte el archivo de registro del Netscape Messaging Server generado por el servicio SMTP al DLF de correo electrónico.

Para procesar correctamente el archivo de registro, debe activar el registro de los siguientes módulos:

- SMTP-Accept
- SMTP-Deliver
- Error-Handler
- Mailbox-Deliver (Debe estar habilitado)

LIMITACIONES

Este convertidor DLF fue desarrollado para Netscape Messaging Server versión 4.1. Otras versiones pueden o no funcionar. Póngase en contacto con los desarrolladores de LogReport si tiene problemas con este convertidor.

Puede encontrar información sobre el formato de registro utilizado por Netscape Messaging Server en la siguiente URL:

http://developer.netscape.com/docs/manuals/messaging/41/ag/logging.htm

No todos los mensajes están documentados. Y encontramos errores en la documentación. Los campos msgID y mailFrom están invertidos tanto en SMTP-Accept como en SMTP-Deliver con respecto a lo que describe la documentación.

CONFIGURACIÓN DEL REGISTRO DEL MÓDULO MAILBOX-DELIVER

Descubrimos que no hay registros del módulo Mailbox-Delivery por defecto. Para solucionar este problema, asegúrese de hacer lo siguiente:

1.
Vaya al MTA o Message Store del Netscape Messaging Server 4
2.
Conviértase en el usuario del servidor de correo (normalmente no debería ser root, sino un usuario como mailsrv o el que se definió en el momento de la instalación; verifique la propiedad de los archivos en su instancia del servidor de correo, por ejemplo)
3.
Vaya a la ubicación correcta, algo como: server-root/msg-instance

Por ejemplo, podría ser: /usr/netscape/server4/msg-mymailserver

4.
Ejecute:
$ ./configutil -o service.smtp.mailbox-deliver.log -v yes
OK SET
5.
Luego conviértase en root, vaya de nuevo a su directorio de instancia como: /usr/netscape/server4/msg-mymailserver y ejecute:
# ./stop-msg smtp
/usr/netscape/server4: Deteniendo el demonio SMTP 16279 .... hecho: 16279
# ./start-msg smtp
/usr/netscape/server4: Iniciando el demonio SMTP ..... hecho: 10820

Y entonces comenzará a ver líneas que se parecerán a las siguientes:

[19/Jul/2002:08:31:54 +0200] amail2 smtpd[10820]: \
General Notice: SMTP-Accept:GZHGT501.C01:<200207190632.g6J6W7Y01389@\
esmtp.orangemail.ch>:[192.168.30.2]:192.168.30.2: \
<newsletter@gamezone.com>:19514:1:<hmarmy@orangemail.ch>
[19/Jul/2002:08:31:54 +0200] amail2 smtpd[10820]: General Notice: \
Mailbox-Deliver:GZHGT501.C01:<200207190632.g6J6W7Y01389@\
esmtp.orangemail.ch>:19516:1:hmarmy;

Si esto no se hizo, la línea con el patrón Mailbox-Deliver anterior no estará presente y el programa dará resultados incorrectos. Se mostrará una advertencia en el registro de errores.

EJEMPLOS

Para procesar un registro tal como lo produce Netscape Messaging Server

$ nms2dlf < mail.log

nms2dlf rara vez se usará por sí solo, sino que es más probable que sea llamado por lr_log2report:

$ lr_log2report nms < /var/log/mail.log
