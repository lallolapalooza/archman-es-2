NOMBRE

nm - listar símbolos de archivos objeto

SINOPSIS

nm [-A|-o|--print-file-name]
[-a|--debug-syms]
[-B|--format=bsd]
[-C|--demangle[=estilo]]
[-D|--dynamic]
[-fformato|--format=formato]
[-g|--extern-only]
[-h|--help]
[--ifunc-chars=CARACTERES]
[-j|--format=just-symbols]
[-l|--line-numbers] [--inlines]
[-n|-v|--numeric-sort]
[-P|--portability]
[-p|--no-sort]
[-r|--reverse-sort]
[-S|--print-size]
[-s|--print-armap]
[-t base|--radix=base]
[-u|--undefined-only]
[-U|--defined-only]
[-V|--version]
[-W|--no-weak]
[-X 32_64]
[--no-demangle]
[--no-recurse-limit|--recurse-limit]]
[--plugin nombre]
[--size-sort]
[--special-syms]
[--synthetic]
[--target=nombre-bfd]
[--unicode=método]
[--with-symbol-versions]
[--without-symbol-versions]
[archivo-objeto...]

DESCRIPCIÓN

GNU nm lista los símbolos de los archivos objeto archivo-objeto.... Si no se listan archivos objeto como argumentos, nm asume que el archivo es a.out.

Para cada símbolo, nm muestra:

  • El valor del símbolo, en la base seleccionada por las opciones (ver abajo), o hexadecimal por defecto.
  • El tipo del símbolo. Al menos los siguientes tipos se utilizan; otros también se utilizan, dependiendo del formato del archivo objeto. Si es minúscula, el símbolo suele ser local; si es mayúscula, el símbolo es global (externo). Sin embargo, hay unos pocos símbolos en minúscula que se muestran para símbolos globales especiales ("u", "v" y "w").
"A"
El valor del símbolo es absoluto y no cambiará con enlaces posteriores.
"B"
"b"
El símbolo está en la sección de datos BSS. Esta sección típicamente contiene datos inicializados a cero o sin inicializar, aunque el comportamiento exacto depende del sistema.
"C"
"c"
El símbolo es común. Los símbolos comunes son datos sin inicializar. Al enlazar, pueden aparecer múltiples símbolos comunes con el mismo nombre. Si el símbolo está definido en algún lugar, los símbolos comunes se tratan como referencias indefinidas. El carácter minúscula c se utiliza cuando el símbolo está en una sección especial para comunes pequeños.
"D"
"d"
El símbolo está en la sección de datos inicializados.
"G"
"g"
El símbolo está en una sección de datos inicializados para objetos pequeños. Algunos formatos de archivo objeto permiten un acceso más eficiente a objetos de datos pequeños, como una variable entera global frente a una matriz global grande.
"i"
Para archivos con formato PE, esto indica que el símbolo está en una sección específica de la implementación de DLLs.

Para archivos con formato ELF, esto indica que el símbolo es una función indirecta. Esta es una extensión de GNU al conjunto estándar de tipos de símbolos ELF. Indica un símbolo que, si se hace referencia a él mediante una relocalización, no se evalúa a su dirección, sino que debe invocarse en tiempo de ejecución. La ejecución en tiempo de ejecución devolverá el valor a utilizar en la relocalización.

Nota: la visualización real de los símbolos para símbolos indirectos de GNU está controlada por la opción de línea de comandos --ifunc-chars. Si se ha proporcionado esta opción, el primer carácter de la cadena se usará para símbolos de función indirecta globales. Si la cadena contiene un segundo carácter, se utilizará para símbolos de función indirecta locales.

"I"
El símbolo es una referencia indirecta a otro símbolo.
"N"
El símbolo es un símbolo de depuración.
"n"
El símbolo está en una sección de solo lectura que no es de datos, ni de código, ni de depuración.
"p"
El símbolo está en una sección de desenrollado de pila.
"R"
"r"
El símbolo está en una sección de datos de solo lectura.
"S"
"s"
El símbolo está en una sección de datos sin inicializar o inicializada a cero para objetos pequeños.
"T"
"t"
El símbolo está en la sección de texto (código).
"U"
El símbolo es indefinido.
"u"
El símbolo es un símbolo global único. Esta es una extensión de GNU al conjunto estándar de enlaces de símbolos ELF. Para un símbolo de este tipo, el enlazador dinámico se asegurará de que solo se utilice un símbolo con este nombre y tipo en todo el proceso.
"V"
"v"
El símbolo es un objeto débil. Cuando un símbolo definido débil se enlaza con un símbolo definido normal, se utiliza el símbolo definido normal sin errores. Cuando se enlaza un símbolo indefinido débil y el símbolo no está definido, el valor del símbolo débil se convierte en cero sin errores. En algunos sistemas, las mayúsculas indican que se ha especificado un valor predeterminado.
"W"
"w"
El símbolo es un símbolo débil que no ha sido etiquetado específicamente como símbolo de objeto débil. Cuando un símbolo definido débil se enlaza con un símbolo definido normal, se utiliza el símbolo definido normal sin errores. Cuando se enlaza un símbolo indefinido débil y el símbolo no está definido, el valor del símbolo se determina de manera específica del sistema sin errores. En algunos sistemas, las mayúsculas indican que se ha especificado un valor predeterminado.
"-"
El símbolo es un símbolo stabs en un archivo objeto a.out. En este caso, los siguientes valores impresos son el campo "other" de stabs, el campo "desc" de stabs y el tipo "stab". Los símbolos stabs se utilizan para almacenar información de depuración.
"?"
El tipo del símbolo es desconocido o específico del formato del archivo objeto.
•
El nombre del símbolo. Si un símbolo tiene información de versión asociada, se muestra la información de versión. Si el símbolo versionado no está definido o está oculto para el enlazador, la cadena de versión se muestra como un sufijo del nombre del símbolo, precedido por un carácter @. Por ejemplo foo@VER_1. Si la versión es la versión predeterminada que se utilizará al resolver referencias no versionadas al símbolo, se muestra como un sufijo precedido por dos caracteres @. Por ejemplo foo@@VER_2.

OPCIONES

Las formas largas y cortas de las opciones, que se muestran aquí como alternativas, son equivalentes.

-A
-o
--print-file-name
Precede cada símbolo con el nombre del archivo de entrada (o miembro del archivo) en el que se encontró, en lugar de identificar el archivo de entrada una sola vez, antes de todos sus símbolos.
-a
--debug-syms
Muestra todos los símbolos, incluso los símbolos solo para depurador; normalmente estos no se listan.
-B
Lo mismo que --format=bsd (por compatibilidad con el nm de MIPS).
-C
--demangle[=estilo]
Decodifica (demangle) nombres de símbolos de bajo nivel a nombres de nivel de usuario. Además de eliminar el guion bajo inicial agregado por el sistema, esto hace que los nombres de funciones de C++ sean legibles. Diferentes compiladores tienen diferentes estilos de mangling. El argumento opcional del estilo de demangling se puede usar para elegir un estilo de demangling apropiado para su compilador.
--no-demangle
No demangle nombres de símbolos de bajo nivel. Este es el valor predeterminado.
--recurse-limit
--no-recurse-limit
--recursion-limit
--no-recursion-limit
Habilita o deshabilita un límite en la cantidad de recursividad realizada al demanglear cadenas. Dado que los formatos de mangling de nombres permiten un nivel infinito de recursividad, es posible crear cadenas cuya decodificación agote la cantidad de espacio en la pila disponible en la máquina host, desencadenando un fallo de memoria. El límite intenta evitar que esto suceda restringiendo la recursividad a 2048 niveles de anidamiento.

El valor predeterminado es que este límite esté habilitado, pero puede ser necesario deshabilitarlo para demanglear nombres verdaderamente complicados. Tenga en cuenta, sin embargo, que si el límite de recursividad está deshabilitado, es posible el agotamiento de la pila y se rechazarán los informes de errores sobre tal evento.

-D
--dynamic
Muestra los símbolos dinámicos en lugar de los símbolos normales. Esto solo es significativo para objetos dinámicos, como ciertos tipos de bibliotecas compartidas.
-f formato
--format=formato
Usa el formato de salida formato, que puede ser "bsd", "sysv", "posix" o "just-symbols". El valor predeterminado es "bsd". Solo el primer carácter de formato es significativo; puede ser mayúscula o minúscula.
-g
--extern-only
Muestra solo símbolos externos.
-h
--help
Muestra un resumen de las opciones de nm y sale.
--ifunc-chars=CARACTERES
Al mostrar símbolos de función indirecta de GNU, nm usará por defecto el carácter "i" tanto para funciones indirectas locales como para funciones indirectas globales. La opción --ifunc-chars permite al usuario especificar una cadena que contiene uno o dos caracteres. El primer carácter se usará para los símbolos de función indirecta global y el segundo carácter, si está presente, se usará para los símbolos de función indirecta local.
j
Lo mismo que --format=just-symbols.
-l
--line-numbers
Para cada símbolo, usa información de depuración para intentar encontrar un nombre de archivo y número de línea. Para un símbolo definido, busca el número de línea de la dirección del símbolo. Para un símbolo indefinido, busca el número de línea de una entrada de reubicación que se refiere al símbolo. Si se puede encontrar información del número de línea, imprímela después de la otra información del símbolo.
--inlines
Cuando la opción -l está activa, si la dirección pertenece a una función que fue inlinada, esta opción hace que se imprima también la información fuente de todos los ámbitos contenedores hasta la primera función no inlinada. Por ejemplo, si "main" inlina "callee1" que inlina "callee2", y la dirección es de "callee2", también se imprimirá la información fuente de "callee1" y "main".
-n
-v
--numeric-sort
Ordena los símbolos numéricamente por sus direcciones, en lugar de alfabéticamente por sus nombres.
-p
--no-sort
No se molesta en ordenar los símbolos en ningún orden; imprímelos en el orden en que se encuentran.
-P
--portability
Usa el formato de salida estándar POSIX.2 en lugar del formato predeterminado. Equivalente a -f posix.
-r
--reverse-sort
Invierte el orden del ordenamiento (ya sea numérico o alfabético); que el último venga primero.
-S
--print-size
Imprime tanto el valor como el tamaño de los símbolos definidos para el estilo de salida "bsd". Esta opción no tiene efecto para formatos de objeto que no registran tamaños de símbolos, a menos que también se use --size-sort, en cuyo caso se mostrará un tamaño calculado.
-s
--print-armap
Al listar símbolos de miembros de archivo, incluye el índice: un mapa (almacenado en el archivo por ar o ranlib) de qué módulos contienen definiciones para qué nombres.
-t base
--radix=base
Usa base como la base para imprimir los valores de los símbolos. Debe ser d para decimal, o para octal, o x para hexadecimal.
-u
--undefined-only
Muestra solo símbolos indefinidos (aquellos externos a cada archivo objeto). Por defecto, se muestran tanto los símbolos definidos como los indefinidos.
-U
--defined-only
Muestra solo símbolos definidos para cada archivo objeto. Por defecto, se muestran tanto los símbolos definidos como los indefinidos.
-V
--version
Muestra el número de versión de nm y sale.
-X
Esta opción se ignora por compatibilidad con la versión AIX de nm. Toma un parámetro que debe ser la cadena 32_64. El modo predeterminado de nm de AIX corresponde a -X 32, que no es compatible con el nm de GNU.
--plugin nombre
Carga el plugin llamado nombre para agregar soporte para tipos de destino adicionales. Esta opción solo está disponible si la cadena de herramientas se compiló con soporte de plugins habilitado.

Si no se proporciona --plugin, pero el soporte de plugins está habilitado, entonces nm itera sobre los archivos en ${libdir}/bfd-plugins en orden alfabético y se utiliza el primer plugin que reclama el objeto en cuestión.

Tenga en cuenta que este directorio de búsqueda de plugins *no* es el que utiliza la opción -plugin de ld. Para que nm utilice el plugin del enlazador, debe copiarse en el directorio ${libdir}/bfd-plugins. Para compilaciones basadas en GCC, el plugin del enlazador se llama liblto_plugin.so.0.0.0. Para compilaciones basadas en Clang, se llama LLVMgold.so. El plugin de GCC siempre es retrocompatible con versiones anteriores, por lo que es suficiente copiar solo el más nuevo.

--size-sort
Ordena los símbolos por tamaño. Para objetos ELF, los tamaños de los símbolos se leen del ELF; para otros tipos de objetos, los tamaños de los símbolos se calculan como la diferencia entre el valor del símbolo y el valor del símbolo con el siguiente valor más alto. Si se utiliza el formato de salida "bsd", se imprime el tamaño del símbolo en lugar del valor, y debe usarse -S para que se impriman tanto el tamaño como el valor.

Nota: esta opción no funciona si se ha habilitado --undefined-only, ya que los símbolos indefinidos no tienen tamaño.

--special-syms
Muestra símbolos que tienen un significado especial específico del objetivo. Estos símbolos son generalmente utilizados por el objetivo para algún procesamiento especial y no son normalmente útiles cuando se incluyen en las listas de símbolos normales. Por ejemplo, para objetivos ARM, esta opción omitiría los símbolos de mapeo utilizados para marcar las transiciones entre código ARM, código THUMB y datos.
--synthetic
Incluye símbolos sintéticos en la salida. Estos son símbolos especiales creados por el enlazador para varios propósitos. No se muestran por defecto ya que no forman parte del código fuente original del binario.
--unicode=[default|invalid|locale|escape|hex|highlight]
Controla la visualización de caracteres multibyte codificados en UTF-8 en cadenas. El valor predeterminado (--unicode=default) es no darles ningún tratamiento especial. La opción --unicode=locale muestra la secuencia en la configuración regional actual, que puede o no admitirla. Las opciones --unicode=hex y --unicode=invalid las muestran como secuencias de bytes hexadecimales encerradas entre corchetes angulares o llaves.

La opción --unicode=escape las muestra como secuencias de escape (\uxxxx) y la opción --unicode=highlight las muestra como secuencias de escape resaltadas en rojo (si es compatible con el dispositivo de salida). La coloración está destinada a llamar la atención sobre la presencia de secuencias unicode donde podrían no esperarse.

-W
--no-weak
No muestra símbolos débiles.
--with-symbol-versions
--without-symbol-versions
Habilita o deshabilita la visualización de versiones de símbolos

OPCIONES

--symbol-versionsymbol-version-string
Esta opción no se utiliza en esta versión de nm. La información de versión del símbolo se muestra como un sufijo al nombre del símbolo, precedido por un carácter @. Por ejemplo foo@VER_1. Si la versión es la versión por defecto a utilizar al resolver referencias no versionadas al símbolo, entonces se muestra como un sufijo precedido por dos caracteres @. Por ejemplo foo@@VER_2. Por defecto, se muestra la información de versión del símbolo.
--target=bfdname
Especifica un formato de código de objeto distinto del formato predeterminado de su sistema.
@archivo
Lee las opciones de la línea de comandos del archivo archivo. Las opciones leídas se insertan en lugar de la opción original @archivo. Si archivo no existe o no se puede leer, la opción se tratará literalmente y no se eliminará.

Las opciones en archivo están separadas por espacios en blanco. Se puede incluir un carácter de espacio en blanco en una opción rodeando toda la opción con comillas simples o dobles. Se puede incluir cualquier carácter (incluido una barra invertida) prefijando el carácter a incluir con una barra invertida. El archivo puede contener además opciones adicionales @archivo; dichas opciones se procesarán recursivamente.
