NOMBRE

nmsstore2dlf - convierte los archivos de registro IMAP o POP del Netscape Messaging Server al DLF msgstore de Lire

SINOPSIS

nmsstore2dlf

DESCRIPCIÓN

Este programa convierte los archivos de registro del Netscape Messaging Server generados por los servicios IMAP o POP al DLF msgstore de Lire.

LIMITACIONES

Para que este analizador proporcione información útil, se recomienda configurar los registros de NMS 4 al nivel adecuado. Para solucionar este problema, asegúrese de haber realizado lo siguiente.

Vaya al Almacén de Mensajes del Netscape Messaging Server 4.

Conviértase en el usuario del Servidor de Correo (generalmente no debería ser root, sino típicamente un usuario como mailsrv o el que se definió en el momento de la instalación, verifique la propiedad de los archivos en su instancia del servidor de mensajes, por ejemplo).

Vaya a la ubicación correcta, algo como:
server-root/msg-instance

Por ejemplo, podría ser:
/usr/netscape/server4/msg-mymailserver

Haga:

$ ./configutil -o logfile.pop.loglevel -v Informational
OK SET
$ ./configutil -o logfile.imap.loglevel -v Informational
OK SET

Luego conviértase en root, vaya nuevamente a su directorio de instancia como:
/usr/netscape/server4/msg-mymailserver

y haga:

# ./stop-msg pop
/mailserv1fs/netscape/server4: Deteniendo el demonio POP3 24789 .... listo: 24789
# ./start-msg pop
/mailserv1fs/netscape/server4: Iniciando el demonio POP3 .... listo: 17509

EJEMPLOS

Para procesar un registro tal como lo produce Netscape Messaging Server:

$ nmsstore2dlf < ns-store.log

nmsstore2dlf se usará raramente por sí solo, sino que es más probable que sea llamado por lr_log2report:

$ lr_log2report nmsstore < /var/log/ns-store.log > report
