NMBLOOKUP(1) Comandos de usuario NMBLOOKUP(1)

NOMBRE

nmblookup - cliente NetBIOS sobre TCP/IP utilizado para buscar nombres NetBIOS

SINOPSIS

nmblookup [-M|--master-browser] [--recursion] [-S|--status] [-r|--root-port] [-A|--lookup-by-ip] [-B|--broadcast=DIRECCION-BROADCAST] [-U|--unicast=DIRECCION-UNICAST] [-T|--translate] [-f|--flags] [-?|--help] [--usage] [-d|--debuglevel=NIVEL-DE-DEBUG] [--debug-stdout] [--configfile=ARCHIVO-DE-CONFIGURACION] [--option=nombre=valor] [-l|--log-basename=ARCHIVO-DE-LOG] [--leak-report] [--leak-report-full] [-R|--name-resolve=ORDEN-RESOLUCION-NOMBRES] [-O|--socket-options=OPCIONES-SOCKET] [-m|--max-protocol=MAXPROTOCOLO] [-n|--netbiosname=NOMBRE-NETBIOS] [--netbios-scope=SCOPE] [-W|--workgroup=GRUPO-TRABAJO] [--realm=REALM] {nombre}

DESCRIPCIÓN

Esta herramienta forma parte del conjunto samba(7).

nmblookup se utiliza para consultar nombres NetBIOS y mapearlos a direcciones IP en una red utilizando consultas NetBIOS sobre TCP/IP. Las opciones permiten que las consultas de nombres se dirijan a un área de difusión IP específica o a una máquina específica. Todas las consultas se realizan a través de UDP.

OPCIONES

-M|--master-browser

Busca un navegador maestro buscando el nombre NetBIOS con el tipo 0x1d. Si nombre es "-", entonces realiza una búsqueda en el nombre especial __MSBROWSE__. Tenga en cuenta que para usar el nombre "-", debe asegurarse de que "-" no se analice como un argumento, por ejemplo, use: nmblookup -M -- -.

--recursion

Establece el bit de deseo de recursión en el paquete para realizar una búsqueda recursiva. Esto se usa cuando se envía una consulta de nombre a una máquina que ejecuta un servidor WINS y el usuario desea consultar los nombres en el servidor WINS. Si este bit no está establecido, se utiliza el código de procesamiento NetBIOS normal (que responde a difusión) en una máquina en su lugar. Consulte RFC1001, RFC1002 para obtener detalles.

-S|--status

Una vez que la consulta de nombre haya devuelto una dirección IP, realice también una consulta de estado de nodo. Una consulta de estado de nodo devuelve los nombres NetBIOS registrados por un host.

-r|--root-port

Intente vincularse al puerto UDP 137 para enviar y recibir datagramas UDP. La razón de esta opción es un error en Windows 95 donde ignora el puerto de origen del paquete solicitante y solo responde al puerto UDP 137. Desafortunadamente, en la mayoría de los sistemas UNIX se necesita privilegios de root para vincularse a este puerto, y además, si el demonio nmbd(8) se está ejecutando en esta máquina, también se vincula a este puerto.

-A|--lookup-by-ip

Interpreta nombre como una dirección IP y realiza una consulta de estado de nodo en esta dirección.

-B|--broadcast <dirección de broadcast>

Envía la consulta a la dirección de difusión dada. Sin esta opción, el comportamiento predeterminado de nmblookup es enviar la consulta a la dirección de difusión de las interfaces de red, ya sea auto-detectada o definida en el parámetro interfaces del archivo smb.conf(5).

-U|--unicast <dirección de unicast>

Realiza una consulta unicast a la dirección o host especificado dirección de unicast. Esta opción (junto con la opción -R) es necesaria para consultar un servidor WINS.

-T|--translate

Esto provoca que cualquier dirección IP encontrada en la búsqueda se busque a través de una búsqueda inversa de DNS para obtener un nombre DNS, y se imprima antes de cada par de

dirección IP .... nombre NetBIOS

que es la salida normal.

-f|--flags

Muestra qué banderas se aplican al nombre que se ha buscado. Las respuestas posibles son cero o más de: Respuesta, Autoritaria, Truncada, Deseo_Recursión, Recursión_Disponible, Difusión.

nombre

Este es el nombre NetBIOS que se está consultando. Dependiendo de las opciones anteriores, puede ser un nombre NetBIOS o una dirección IP. Si es un nombre NetBIOS, los diferentes tipos de nombres se pueden especificar añadiendo '#<tipo>' al nombre. Este nombre también puede ser '*', lo que devolverá todos los nombres registrados dentro de un área de difusión.

-d|--debuglevel=nivel

nivel es un entero de 0 a 10. El valor predeterminado si no se especifica este parámetro es 1 para aplicaciones cliente.

Cuanto mayor sea este valor, más detalles se registrarán en los archivos de registro sobre las actividades del servidor. En el nivel 0, solo se registrarán errores críticos y advertencias serias. El nivel 1 es un nivel razonable para el uso diario: genera una pequeña cantidad de información sobre las operaciones realizadas.

Los niveles superiores a 1 generarán una cantidad considerable de datos de registro y solo deben usarse al investigar un problema. Los niveles superiores a 3 están diseñados solo para que los usen los desarrolladores y generan enormes cantidades de datos de registro, la mayoría de los cuales son extremadamente crípticos.

Tenga en cuenta que la especificación de este parámetro aquí anulará el parámetro nivel de registro en el archivo /etc/samba/smb.conf.

--debug-stdout

Esto redirigirá la salida de depuración a STDOUT. Por defecto, todos los clientes están registrando en STDERR.

--configfile=<archivo de configuración>

El archivo especificado contiene los detalles de configuración requeridos por el cliente. La información en este archivo puede ser general para cliente y servidor o solo proporcionar opciones específicas del cliente, como client smb encrypt. Consulte /etc/samba/smb.conf para obtener más información. El nombre del archivo de configuración predeterminado se determina en tiempo de compilación.

--option=<nombre>=<valor>

Establezca la opción smb.conf(5) "<nombre>" en el valor "<valor>" desde la línea de comandos. Esto anula los valores predeterminados compilados y las opciones leídas del archivo de configuración. Si un nombre o un valor incluye un espacio, envuelva todo --option=nombre=valor entre comillas.

-l|--log-basename=directorio-de-registro

Nombre base del directorio para los archivos de registro/depuración. Se añadirá la extensión ".nombreprograma" (por ejemplo, log.smbclient, log.smbd, etc.). El cliente nunca elimina el archivo de registro.

--leak-report

Habilita el informe de fugas de talloc al salir.

--leak-report-full

Habilita el informe completo de fugas de talloc al salir.

-V|--version

Imprime el número de versión del programa.

-R|--name-resolve=ORDEN-RESOLUCION-NOMBRES

Esta opción se utiliza para determinar qué servicios de nombres y en qué orden resolver nombres de host a direcciones IP. La opción toma una cadena separada por espacios de diferentes opciones de resolución de nombres. Lo mejor es encerrar todo --name-resolve=ORDEN-RESOLUCION-NOMBRES entre comillas.

Las opciones son: "lmhosts", "host", "wins" y "bcast". Hacen que los nombres se resuelvan de la siguiente manera:

•lmhosts: Busca una dirección IP en el archivo lmhosts de Samba. Si la línea en lmhosts no tiene un tipo de nombre asociado con el nombre NetBIOS (consulte lmhosts(5) para obtener detalles), entonces cualquier tipo de nombre coincide para la búsqueda.
•host: Realiza una resolución estándar de nombres de host a direcciones IP, utilizando las búsquedas del sistema /etc/hosts, NIS o DNS. Este método de resolución de nombres depende del sistema operativo; por ejemplo, en IRIX o Solaris, esto puede ser controlado por el archivo /etc/nsswitch.conf). Tenga en cuenta que este método solo se usa si el tipo de nombre NetBIOS que se consulta es el tipo de nombre 0x20 (servidor), de lo contrario, se ignora.
•wins: Consulta un nombre con la dirección IP especificada en el parámetro servidor wins. Si no se ha especificado ningún servidor WINS, este método se ignorará.
•bcast: Realiza una difusión en cada una de las interfaces locales conocidas listadas en el parámetro interfaces. Este es el método de resolución de nombres menos confiable, ya que depende de que el host de destino esté en una subred conectada localmente.
Si este parámetro no está configurado, se utilizará el orden de resolución de nombres definido en el parámetro del archivo /etc/samba/smb.conf (orden de resolución de nombres).

El orden predeterminado es lmhosts, host, wins, bcast. Sin este parámetro o cualquier entrada en el parámetro orden de resolución de nombres del archivo /etc/samba/smb.conf, los métodos de resolución de nombres se intentarán en este orden.

-O|--socket-options=OPCIONES-SOCKET

Opciones de socket TCP que se establecerán en el socket del cliente. Consulte el parámetro de opciones de socket en la página del manual de /etc/samba/smb.conf para ver la lista de opciones válidas.

OPTIONS

-V|--version

Print version information.

-d|--debuglevel=DEBUGLEVEL

The value of DEBUGLEVEL is an integer from 0 to 10. This is the level at which Samba will log messages. A level of 0 means no logging, and a level of 10 means that all messages will be logged. The default value for this parameter is 0.

The log level can also be set using the smb.conf(5) file.

-l|--log-basename=LOGFILEBASE

Base name for log files. The default is log., where is the name of the program (e.g. log.nmblookup). Log files are always created in /var/log/samba/.

-s|--configfile=CONFIGFILE

The value of CONFIGFILE is the name of the configuration file which Samba can use. If this is not given, Samba will try to use /etc/samba/smb.conf.

-P|--protocol=PROTOCOL

This option allows you to specify the protocol that nmblookup will use to communicate with the server. The possible values are: SMB, SSL, TCPIP, and NB_TCP. The default value is NB_TCP.

-U|--remote-name=REMOTE NAME

The value of REMOTE NAME is the NetBIOS name of the server to query.

-R|--remote-ip=REMOTE IP

The value of REMOTE IP is the IP address of the server to query.

-S|--signing=REQUIRED|DISABLED|AUTO

This option allows you to control the signing of the SMB protocol. If set to REQUIRED, the client will only connect to servers that sign all SMB traffic. If set to DISABLED, the client will not attempt to sign any SMB traffic. If set to AUTO, the client will attempt to sign SMB traffic if the server supports it. The default value is AUTO.

-k|--kerberos

This option allows you to use Kerberos authentication instead of the default NTLM authentication.

-N|--no-pass

Do not ask for a password.

-E|--encrypt

Encrypt password.

-i|--ipaddr=IPAddress

IP address to use when binding to a socket.

-p|--port=PORT

Port to use for connecting to the server.

-O|--socket-options=SPECIAL_OPTIONS

Allows you to specify some special socket options. Valid options are:

TCP_NODELAY, SO_KEEPALIVE, SO_RCVBUF=size, SO_SNDBUF=size.

x-protocol=MAXPROTOCOL

The value of the parameter (a string) is the highest protocol level that will be supported by the client.

Note that specifying this parameter here will override the client max protocol parameter in the /etc/samba/smb.conf file.

-n|--netbiosname=NETBIOSNAME

This option allows you to override the NetBIOS name that Samba uses for itself. This is identical to setting the netbios name parameter in the /etc/samba/smb.conf file. However, a command line setting will take precedence over settings in /etc/samba/smb.conf.

--netbios-scope=SCOPE

This specifies a NetBIOS scope that nmblookup will use to communicate with when generating NetBIOS names. For details on the use of NetBIOS scopes, see rfc1001.txt and rfc1002.txt. NetBIOS scopes are very rarely used, only set this parameter if you are the system administrator in charge of all the NetBIOS systems you communicate with.

-W|--workgroup=WORKGROUP

Set the SMB domain of the username. This overrides the default domain which is the domain defined in smb.conf. If the domain specified is the same as the servers NetBIOS name, it causes the client to log on using the servers local SAM (as opposed to the Domain SAM).

Note that specifying this parameter here will override the workgroup parameter in the /etc/samba/smb.conf file.

-r|--realm=REALM

Set the realm for the domain.

Note that specifying this parameter here will override the realm parameter in the /etc/samba/smb.conf file.

-?|--help

Print a summary of command line options.

--usage

Display brief usage message.

EXAMPLES

nmblookup can be used to query a WINS server (in the same way nslookup is used to query DNS servers). To query a WINS server, nmblookup must be called like this:

nmblookup -U server -R 'name'

For example, running :

nmblookup -U samba.org -R 'IRIX#1B'

would query the WINS server samba.org for the domain master browser (1B name type) for the IRIX workgroup.
