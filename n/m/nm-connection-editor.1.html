NOMBRE

nm-connection-editor - editor de conexiones de red para NetworkManager

SINOPSIS

nm-connection-editor [ OPCIONES ]

DESCRIPCIÓN

nm-connection-editor es una aplicación basada en GTK para añadir, eliminar y modificar conexiones de red almacenadas por NetworkManager. NetworkManager debe estar en ejecución para que se puedan añadir, eliminar o modificar conexiones de red.

OPCIONES

-t, --tipo=<tipo>
Tipo de conexión a crear o mostrar. Los valores son nombres de configuración de NetworkManager, por ejemplo "802-3-ethernet", "802-11-wireless", "bridge", "bond", "infiniband", "vlan", etc. No hace nada si no se proporciona --crear o --mostrar.
-s, --mostrar
Expande o colapsa la lista de redes para resaltar el tipo de conexión de red dado por --tipo.
-c, --crear
Crea una nueva conexión del tipo dado por --tipo y permite al usuario modificar los detalles de la conexión.
-e, --editar=<uuid>
Muestra la ventana de edición de conexiones de red para la conexión con el UUID dado.

VER TAMBIÉN

nmcli(1), NetworkManager(8), nm-applet(1).
