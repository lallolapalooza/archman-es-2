NMTUI(1) Manual de comandos generales NMTUI(1)

NOMBRE

nmtui - Interfaz de usuario de texto para controlar NetworkManager

SINOPSIS

nmtui-edit | nmtui edit {nombre | id}

nmtui-connect | nmtui connect {nombre | uuid | dispositivo | SSID}

nmtui-hostname | nmtui hostname

DESCRIPCIÓN

nmtui es una aplicación TUI basada en curses para interactuar con NetworkManager. Al iniciar nmtui, se le pide al usuario que elija la actividad a realizar, a menos que se haya especificado como primer argumento.

Las actividades admitidas son:

edit

Muestra un editor de conexiones que admite añadir, modificar, ver y eliminar conexiones. Proporciona una funcionalidad similar a nm-connection-editor.

connect

Muestra una lista de conexiones disponibles, con la opción de activarlas o desactivarlas. Proporciona una funcionalidad similar a nm-applet.

hostname

Establece el nombre de host del sistema.

Correspondiente a las actividades anteriores, nmtui también viene con binarios llamados nmtui-edit, nmtui-connect y nmtui-hostname para omitir la selección de las actividades.

VER TAMBIÉN

nmcli(1), nm-applet(1), nm-connection-editor(1), NetworkManager(8).
