NDCTL-START-SCRUB(1) Manual de ndctl NDCTL-START-SCRUB(1)

NOMBRE

ndctl start-scrub - iniciar una operación de limpieza de rango de direcciones (ARS)

SINOPSIS

ndctl start-scrub [<id-bus> <id-bus2> ... <id-busN>] [<opciones>]

DESCRIPCIÓN

La limpieza de rango de direcciones de NVDIMM (NVDIMM Address Range Scrub - ARS) es una capacidad proporcionada por el firmware de la plataforma que permite al software del sistema descubrir errores de memoria. Permite que el software del sistema evite de forma preventiva accesos que podrían provocar eventos de manejo de errores de memoria no corregibles y, de lo contrario, permite enumerar los errores de memoria.

El kernel proporciona un archivo sysfs (scrub) que, al escribirse la cadena "1\n", inicia una operación ARS. La operación ndctl start-scrub inicia una ARS en todos los buses especificados, y el kernel procede a limpiar cada región de dirección de memoria persistente en los buses especificados.

EJEMPLO

Inicia una limpieza en todos los buses nddimm del sistema. El informe de listado JSON solo incluye los buses que admiten operaciones ARS.

# ndctl start-scrub
[
  {
    "provider":"nfit_test.1",
    "dev":"ndbus3",
    "scrub_state":"active"
  },
  {
    "provider":"nfit_test.0",
    "dev":"ndbus2",
    "scrub_state":"active"
  }
]

Al especificar un bus individual, o si solo hay un bus en el sistema, el comando informa si el soporte ARS está disponible.

# ndctl start-scrub e820
error starting scrub: Operation not supported

OPCIONES

-v, --verbose

Emite mensajes de depuración para el proceso de inicio de ARS
