NDCTL-ENABLE-REGION(1) Manual de ndctl NDCTL-ENABLE-REGION(1)

NOMBRE

ndctl-enable-region - habilita la(s) región(es) dada(s) y todos los namespaces descendientes

SINOPSIS

ndctl enable-region <región> [<opciones>]

DESCRIPCIÓN

Se registra un dispositivo REGION genérico para cada rango PMEM / conjunto de intercalación. LIBNVDIMM proporciona un controlador integrado para estos dispositivos REGION. Este controlador es responsable de analizar las etiquetas de namespace e instanciar namespaces PMEM para cada conjunto coherente de etiquetas.

OPCIONES

<región>

Un nombre de dispositivo regionX, o un número de identificación de región. Restringe la operación a la(s) región(es) especificada(s). La palabra clave all se puede especificar para indicar la falta de cualquier restricción, sin embargo, esto es lo mismo que no proporcionar la opción --region en absoluto.

-b, --bus=

Un número de identificación de bus, o una cadena de proveedor (por ejemplo, "ACPI.NFIT"). Restringe la operación al(los) bus(es) especificado(s). La palabra clave all se puede especificar para indicar la falta de cualquier restricción, sin embargo, esto es lo mismo que no proporcionar la opción --bus en absoluto.
