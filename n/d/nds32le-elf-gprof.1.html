NOMBRE

gprof - mostrar datos de perfil de gráfico de llamadas

SINOPSIS

gprof [ -[abcDhilLrsTvwxyz] ] [ -[ABCeEfFJnNOpPqQRStZ][nombre] ]
[ -I directorios ] [ -d[num] ] [ -k desde/a ]
[ -m conteo-minimo ] [ -R archivo-mapeo ] [ -t longitud-tabla ]
[ --[no-]fuente-anotada[=nombre] ]
[ --[no-]conteo-ejecucion[=nombre] ]
[ --[no-]perfil-plano[=nombre] ] [ --[no-]grafico[=nombre] ]
[ --[no-]tiempo=nombre] [ --todas-lineas ] [ --breve ]
[ --depuracion[=nivel] ] [ --ordenamiento-funciones ]
[ --ordenamiento-archivo archivo-mapeo ] [ --ruta-directorio=directorios ]
[ --mostrar-funciones-no-usadas ] [ --formato-archivo=nombre ]
[ --info-archivo ] [ --ayuda ] [ --linea ] [ --nombres-archivo-inline ]
[ --conteo-minimo=n ] [ --no-estatico ] [ --imprimir-ruta ]
[ --archivos-separados ] [ --grafico-llamadas-estatico ] [ --suma ]
[ --longitud-tabla=len ] [ --tradicional ] [ --version ]
[ --ancho=n ] [ --ignorar-no-funciones ]
[ --desenrollar[=ESTILO] ] [ --no-desenrollar ]

[ archivo-imagen ] [ archivo-perfil ... ]

DESCRIPCIÓN

"gprof" produce un perfil de ejecución de programas en C, Pascal o Fortran77. El efecto de las rutinas llamadas se incorpora en el perfil de cada llamador. Los datos del perfil se obtienen del archivo de perfil del gráfico de llamadas (gmon.out por defecto), que es creado por programas compilados con la opción -pg de "cc", "pc" y "f77". La opción -pg también enlaza versiones de las rutinas de biblioteca que están compiladas para perfilado. "Gprof" lee el archivo objeto dado (por defecto "a.out") y establece la relación entre su tabla de símbolos y el perfil del gráfico de llamadas de gmon.out. Si se especifican más de un archivo de perfil, la salida de "gprof" muestra la suma de la información del perfil en los archivos de perfil dados.

"Gprof" calcula la cantidad de tiempo dedicado en cada rutina. Luego, estos tiempos se propagan a lo largo de los bordes del gráfico de llamadas. Se descubren ciclos y las llamadas a un ciclo se hacen para compartir el tiempo del ciclo.

Varias formas de salida están disponibles a partir del análisis.

El perfil plano muestra cuánto tiempo pasó su programa en cada función y cuántas veces se llamó a esa función. Si simplemente desea saber qué funciones consumen la mayor parte del tiempo, aquí se indica de forma concisa.

El gráfico de llamadas muestra, para cada función, qué funciones la llamaron, qué otras funciones llamó, y cuántas veces. También hay una estimación de cuánto tiempo se dedicó en las subrutinas de cada función. Esto puede sugerir lugares donde podría intentar eliminar llamadas a funciones que consumen mucho tiempo.

El listado de fuente anotada es una copia del código fuente del programa, etiquetado con el número de veces que se ejecutó cada línea del programa.

OPCIONES

Estas opciones especifican cuál de varios formatos de salida debe producir "gprof".

Muchas de estas opciones toman un symspec opcional para especificar funciones a incluir o excluir. Estas opciones se pueden especificar múltiples veces, con diferentes symspecs, para incluir o excluir conjuntos de símbolos.

La especificación de cualquiera de estas opciones anula los valores predeterminados (-p -q), que imprimen un perfil plano y un análisis del gráfico de llamadas para todas las funciones.

"-A[symspec]"
"--fuente-anotada[=symspec]"
La opción -A hace que "gprof" imprima código fuente anotado. Si se especifica symspec, imprima la salida solo para los símbolos coincidentes.
"-b"
"--breve"
Si se proporciona la opción -b, "gprof" no imprime los textos explicativos que intentan explicar el significado de todos los campos en las tablas. Esto es útil si tiene la intención de imprimir la salida, o está cansado de ver los textos explicativos.
"-B"
La opción -B hace que "gprof" imprima el análisis del gráfico de llamadas.
"-C[symspec]"
"--conteo-ejecucion[=symspec]"
La opción -C hace que "gprof" imprima un recuento de funciones y el número de veces que se llamó a cada una. Si se especifica symspec, imprima el recuento solo para los símbolos coincidentes.

Si el archivo de datos del perfil contiene registros de conteo de bloques básicos, la especificación de la opción -l, junto con -C, hará que se cuenten y muestren los conteos de ejecución de bloques básicos.

"-i"
"--info-archivo"
La opción -i hace que "gprof" muestre información resumida sobre el archivo(s) de datos del perfil y luego salga. Se muestra el número de registros de histograma, gráfico de llamadas y conteo de bloques básicos.
"-I directorios"
"--ruta-directorio=directorios"
La opción -I especifica una lista de directorios de búsqueda en los que encontrar archivos fuente. La variable de entorno GPROF_PATH también puede usarse para transmitir esta información. Se usa principalmente para la salida de fuente anotada.
"-J[symspec]"
"--no-fuente-anotada[=symspec]"
La opción -J hace que "gprof" no imprima código fuente anotado. Si se especifica symspec, "gprof" imprime código fuente anotado, pero excluye los símbolos coincidentes.
"-L"
"--imprimir-ruta"
Normalmente, los nombres de archivo fuente se imprimen suprimiendo el componente de ruta. La opción -L hace que "gprof" imprima la ruta completa de los nombres de archivo fuente, que se determina a partir de la información de depuración simbólica en el archivo imagen y es relativa al directorio en el que se invocó el compilador.
"-p[symspec]"
"--perfil-plano[=symspec]"
La opción -p hace que "gprof" imprima un perfil plano. Si se especifica symspec, imprima el perfil plano solo para los símbolos coincidentes.
"-P[symspec]"
"--no-perfil-plano[=symspec]"
La opción -P hace que "gprof" suprima la impresión de un perfil plano. Si se especifica symspec, "gprof" imprime un perfil plano, pero excluye los símbolos coincidentes.
"-q[symspec]"
"--grafico[=symspec]"
La opción -q hace que "gprof" imprima el análisis del gráfico de llamadas. Si se especifica symspec, imprima el gráfico de llamadas solo para los símbolos coincidentes y sus hijos.
"-Q[symspec]"
"--no-grafico[=symspec]"
La opción -Q hace que "gprof" suprima la impresión del gráfico de llamadas. Si se especifica symspec, "gprof" imprime un gráfico de llamadas, pero excluye los símbolos coincidentes.
"-t"
"--longitud-tabla=num"
La opción -t hace que se listen las num líneas fuente más activas en cada archivo fuente cuando la anotación fuente está habilitada. El valor predeterminado es 10.
"-y"
"--archivos-separados"
Esta opción solo afecta a la salida de fuente anotada. Normalmente, "gprof" imprime los archivos fuente anotados en la salida estándar. Si se especifica esta opción, la fuente anotada para un archivo llamado ruta/nombrearchivo se genera en el archivo nombrearchivo-ann. NAME

gprof - display profiling information

SYNOPSIS

gprof [-aAbcdefhilLlmrRsTvwx] [-Idirectory] [-kfrom/to] [-mnum] [-nsymspec] [-Nsymspec] [-ooutfile] [-Oname] [-s] [-Sfilename] [-usymspec] [-Wsymspec] [-xsymspec] [--help] [--version] [--all-lines] [--demangle[=style]] [--file-ordering map_file] [--function-ordering] [--help] [--inline-file-names] [--min-count=num] [--no-demangle] [--no-static] [--traditional] [--verbose] [--version] [--width=width] [--ignore-non-functions] [--debug[=num]] [--display-unused-functions] [--external-symbol-table=filename] [--static-call-graph] [program [gmon.data ...]]

DESCRIPTION

gprof analyzes program execution profiling data. It uses information gathered by the compiler (using the -pg flag) and instrumented run-time object files (gmon.out files) to produce a report that shows how much time was spent in each function, and how many times each function was called. The report includes a flat profile, a call graph, and annotated source code (if available).

gprof can also generate function ordering information to optimize program performance.

The report is printed to standard output.

OPTIONS

The options can be broadly divided into the following categories:

Output Control Options

"-b"
"--brief"
Print less information to standard output. Specifically, do not print the flat profile.
"-c"
"--static-call-graph"
The -c option causes the call graph of the program to be augmented by a heuristic which examines the text space of the object file and identifies function calls in the binary machine code. Since normal call graph records are only generated when functions are entered, this option identifies children that could have been called, but never were. Calls to functions that were not compiled with profiling enabled are also identified, but only if symbol table entries are present for them. Calls to dynamic library routines are typically not found by this option. Parents or children identified via this heuristic are indicated in the call graph with call counts of 0.
"-d[num]"
"--debug[=num]"
The -d num option specifies debugging options. If num is not specified, enable all debugging.
"-e symspec"
"--exclude=symspec"
Suppress the printing of information about functions matching symspec. This option does not prevent the function from being listed as a child of any functions that call it, but its index number will be shown as [not printed]. More than one -e option may be given. This option replaces the older -e, -E, -f, and -F options.
"-E symspec"
"--exclude-time=symspec"
This option works like --exclude, but time spent in the function (and children that were not called from anywhere else), will not be used to compute the percentages-of-time for the call graph.
"-f symspec"
"--flat-profile=symspec"
Print only the flat profile information for functions matching symspec.
"-F symspec"
"--call-graph=symspec"
Print only the call graph information for functions matching symspec.
"-h"
"--help"
The -h option prints command line usage.
"-I directory"
"--add-source-path=directory"
Add directory to the list of directories that gprof searches for source files. This is useful when the source files are not in the same directory as the executable.
"-l"
"--line"
The -l option enables line-by-line profiling, which causes histogram hits to be charged to individual source code lines, instead of functions. This feature only works with programs compiled by older versions of the "gcc" compiler. Newer versions of "gcc" are designed to work with the "gcov" tool instead.

If the program was compiled with basic-block counting enabled, this option will also identify how many times each line of code was executed. While line-by-line profiling can help isolate where in a large function a program is spending its time, it also significantly increases the running time of gprof, and magnifies statistical inaccuracies.

"-L"
"--print-source-path"
Print the source path along with the source file name.
"-m num"
"--min-count=num"
This option affects execution count output only. Symbols that are executed less than num times are suppressed.
"-Oname"
"--file-format=name"
Selects the format of the profile data files. Recognized formats are auto (the default), bsd, 4.4bsd, magic, and prof (not yet supported).
"-r[symspec]"
"--flat-profile[=symspec]"
Print a flat profile, showing the total time spent in each function. If symspec is specified, print tally, but exclude matching symbols.
"-s"
"--sum"
The -s option causes gprof to summarize the information in the profile data files it read in, and write out a profile data file called gmon.sum, which contains all the information from the profile data files that gprof read in. The file gmon.sum may be one of the specified input files; the effect of this is to merge the data in the other input files into gmon.sum.

Eventually you can run gprof again without -s to analyze the cumulative data in the file gmon.sum.

"-T"
"--traditional"
The -T option causes gprof to print its output in "traditional" BSD style.
"-u symspec"
"--untouched[=symspec]"
The -u option causes gprof not to print a tally of functions and the number of times each was called. If symspec is specified, print tally, but exclude matching symbols.
"-v"
"--version"
The -v flag causes gprof to print the current version number, and then exit.
"-W symspec"
"--all-symbols[=symspec]"
The -W option causes gprof not to print a tally of functions and the number of times each was called. If symspec is specified, print tally, but exclude matching symbols.
"-w width"
"--width=width"
Sets width of output lines to width. Currently only used when printing the function index at the bottom of the call graph.
"-x symspec"
"--exec-time[=symspec]"
The -x option causes gprof to print a tally of functions and the number of times each was called. If symspec is specified, print tally, but exclude matching symbols.
"--all-lines"
This option affects annotated source output only. By default, only the lines at the beginning of a basic-block are annotated. If this option is specified, every line in a basic-block is annotated by repeating the annotation for the first line. This behavior is similar to "tcov"'s -a.
"--demangle[=style]"
"--no-demangle"
These options control whether C++ symbol names should be demangled when printing output. The default is to demangle symbols. The "--no-demangle" option may be used to turn off demangling. Different compilers have different mangling styles. The optional demangling style argument can be used to choose an appropriate demangling style for your compiler.

Analysis Options

"-a"
"--no-static"
The -a option causes gprof to suppress the printing of statically declared (private) functions. (These are functions whose names are not listed as global, and which are not visible outside the file/function/block where they were defined.) Time spent in these functions, calls to/from them, etc., will all be attributed to the function that was loaded directly before it in the executable file. This option affects both the flat profile and the call graph.
"-c"
"--static-call-graph"
The -c option causes the call graph of the program to be augmented by a heuristic which examines the text space of the object file and identifies function calls in the binary machine code. Since normal call graph records are only generated when functions are entered, this option identifies children that could have been called, but never were. Calls to functions that were not compiled with profiling enabled are also identified, but only if symbol table entries are present for them. Calls to dynamic library routines are typically not found by this option. Parents or children identified via this heuristic are indicated in the call graph with call counts of 0.
"-D"
"--ignore-non-functions"
The -D option causes gprof to ignore symbols which are not known to be functions. This option will give more accurate profile data on systems where it is supported (Solaris and HPUX for example).
"-k from/to"
The -k option allows you to delete from the call graph any arcs from symbols matching symspec from to those matching symspec to.
"-l"
"--line"
The -l option enables line-by-line profiling, which causes histogram hits to be charged to individual source code lines, instead of functions. This feature only works with programs compiled by older versions of the "gcc" compiler. Newer versions of "gcc" are designed to work with the "gcov" tool instead.

If the program was compiled with basic-block counting enabled, this option will also identify how many times each line of code was executed. While line-by-line profiling can help isolate where in a large function a program is spending its time, it also significantly increases the running time of gprof, and magnifies statistical inaccuracies.

"--inline-file-names"
This option causes gprof to print the source file after each symbol in both the flat profile and the call graph. The full path to the file is printed if used with the -L option.
"-m num"
"--min-count=num"
This option affects execution count output only. Symbols that are executed less than num times are suppressed.
"-nsymspec"
"--time=symspec"
The -n option causes gprof, in its call graph analysis, to only propagate times for symbols matching symspec.
"-Nsymspec"
"--no-time=symspec"
The -n option causes gprof, in its call graph analysis, not to propagate times for symbols matching symspec.
"-r map_file"
"--file-ordering map_file"
The --file-ordering option causes gprof to print a suggested .o link line ordering for the program based on profiling data. This option suggests an ordering which may improve paging, tlb and cache behavior for the program on systems which do not support arbitrary ordering of functions in an executable.

Use of the -a argument is highly recommended with this option.

The map_file argument is a pathname to a file which provides function name to object file mappings. The format of the file is similar to the output of the program "nm".

c-parse.o:00000000 T yyparse
c-parse.o:00000004 C yyerrflag
c-lang.o:00000000 T maybe_objc_method_name
c-lang.o:00000000 T print_lang_statistics
c-lang.o:00000000 T recognize_objc_keyword
c-decl.o:00000000 T print_lang_identifier
c-decl.o:00000000 T print_lang_type
...

To create a map_file with GNU "nm", type a command like "nm --extern-only --defined-only -v --print-file-name program-name".

"-Sfilename"
"--external-symbol-table=filename"
The -S option causes gprof to read an external symbol table file, such as /proc/kallsyms, rather than read the symbol table from the given object file (the default is "a.out"). This is useful for profiling kernel modules.
"-z"
"--display-unused-functions"
If you give the -z option, gprof will mention all functions in the flat profile, even those that were never called, and that had no time spent in them. This is useful in conjunction with the -c option for discovering which routines were never called.

Miscellaneous Options

"-d[num]"
"--debug[=num]"
The -d num option specifies debugging options. If num is not specified, enable all debugging.
"-h"
"--help"
The -h option prints command line usage.
"-Oname"
"--file-format=name"
Selects the format of the profile data files. Recognized formats are auto (the default), bsd, 4.4bsd, magic, and prof (not yet supported).
"-r"
"--function-ordering"
The --function-ordering option causes gprof to print a suggested function ordering for the program based on profiling data. This option suggests an ordering which may improve paging, tlb and cache behavior for the program on systems which support arbitrary ordering of functions in an executable.

The exact details of how to force the linker to place functions in a particular order is system dependent and out of the scope of this manual.

"-s"
"--sum"
The -s option causes gprof to summarize the information in the profile data files it read in, and write out a profile data file called gmon.sum, which contains all the information from the profile data files that gprof read in. The file gmon.sum may be one of the specified input files; the effect of this is to merge the data in the other input files into gmon.sum.

Eventually you can run gprof again without -s to analyze the cumulative data in the file gmon.sum.

"-v"
"--version"
The -v flag causes gprof to print the current version number, and then exit.

Deprecated Options

These options have been replaced with newer versions that use symspecs.

"-e function_name"
The -e function option tells gprof to not print information about the function function_name (and its children...) in the call graph. The function will still be listed as a child of any functions that call it, but its index number will be shown as [not printed]. More than one -e option may be given; only one function_name may be indicated with each -e option.
"-E function_name"
The "-E function" option works like the "-e" option, but time spent in the function (and children who were not called from anywhere else), will not be used to compute the percentages-of-time for the call graph. More than one -E option may be given; only one function_name may be indicated with each -E option.
"-f function_name"
The -f function option causes
 "Li">"gprof" para limitar el grafo de llamadas a la función nombre_funcion y sus hijos (y los hijos de sus hijos...). Se puede especificar más de una opción -f; solo se puede indicar un nombre_funcion con cada opción -f.
"-F nombre_funcion"
La opción -F funcion funciona como la opción "-f", pero solo el tiempo dedicado a la función y sus hijos (y sus hijos...) se utilizará para determinar el tiempo total y los porcentajes de tiempo para el grafo de llamadas. Se puede especificar más de una opción -F; solo se puede indicar un nombre_funcion con cada opción -F. La opción -F anula la opción -E.

ERRORES

Se muestra la granularidad del muestreo, pero sigue siendo, en el mejor de los casos, estadística. Suponemos que el tiempo de cada ejecución de una función se puede expresar como el tiempo total de la función dividido por el número de veces que se llama a la función. Por lo tanto, el tiempo propagado a lo largo de los arcos del grafo de llamadas a los padres de la función es directamente proporcional al número de veces que se atraviesa dicho arco.

Los padres que no están perfilados aparecerán como invocados espontáneamente en la lista del grafo de llamadas, y su tiempo no se propagará más allá. Del mismo modo, los capturadores de señales, aunque estén perfilados, aparecerán como espontáneos (aunque por razones más oscuros). Cualquier hijo perfilado de un capturador de señales debería tener su tiempo propagado correctamente, a menos que el capturador de señales se haya invocado durante la ejecución de la rutina de perfilado, en cuyo caso todo está perdido.

El programa perfilado debe llamar a "exit"(2) o retornar normalmente para que la información de perfilado se guarde en el archivo gmon.out.
