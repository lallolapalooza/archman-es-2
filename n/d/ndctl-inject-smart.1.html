NOMBRE

ndctl-inject-smart - realiza operaciones de umbral/inyección smart en un DIMM

SINOPSIS

ndctl inject-smart <dimm> [<opciones>]

DESCRIPCIÓN

Se registra un objeto de dispositivo DIMM genérico, llamado /dev/nmemX, para cada dispositivo de memoria indicado en la tabla ACPI NFIT u otro mecanismo de descubrimiento de recursos NVDIMM de la plataforma.

ndctl-inject-smart se puede usar para establecer umbrales smart e inyectar atributos smart.

EJEMPLOS

Establecer el umbral de temperatura del controlador y el umbral de repuestos para DIMM-0 en 32C, el umbral de repuestos en 8, y habilitar la alarma de repuestos.

ndctl inject-smart --ctrl-temperature-threshold=32 --spares-threshold=8 --spares-alarm nmem0

Inyectar un valor de temperatura de medios de 52 y el indicador de estado de salud fatal para DIMM-0

ndctl inject-smart --media-temperature=52 --health=fatal nmem0

OPCIONES

-b, --bus=

Un número de ID de bus o una cadena de proveedor (por ejemplo, "ACPI.NFIT"). Restringe la operación a los buses especificados. La palabra clave all se puede especificar para indicar la ausencia de cualquier restricción; sin embargo, esto es lo mismo que no proporcionar la opción --bus.

-m, --media-temperature=

Inyecta <valor> para el atributo smart de temperatura de medios.

-M, --media-temperature-threshold=

Establece <valor> para el umbral smart de temperatura de medios.

--media-temperature-alarm=

Habilita o deshabilita la alarma smart de temperatura de medios. Las opciones son on u off.

--media-temperature-uninject

Elimina cualquier temperatura de medios previamente inyectada.

-c, --ctrl-temperature=

Inyecta <valor> para el atributo smart de temperatura del controlador.

-C, --ctrl-temperature-threshold=

Establece <valor> para el umbral smart de temperatura del controlador.

--ctrl-temperature-alarm=

Habilita o deshabilita la alarma smart de temperatura del controlador. Las opciones son on u off.

--ctrl-temperature-uninject

Elimina cualquier temperatura del controlador previamente inyectada.

-s, --spares=

Inyecta <valor> para el atributo smart de repuestos.

-S, --spares-threshold=

Establece <valor> para el umbral smart de repuestos.

--spares-alarm=

Habilita o deshabilita la alarma smart de repuestos. Las opciones son on u off.

--spares-uninject

Elimina cualquier porcentaje de repuestos previamente inyectado.

-f, --fatal

Establece el indicador para simular el estado de salud fatal.

--fatal-uninject

Elimina el indicador de estado de salud fatal.

-U, --unsafe-shutdown

Establece el indicador para simular un apagado inseguro en el próximo encendido.

--unsafe-shutdown-uninject

Elimina el indicador de apagado inseguro.

-N, --uninject-all

Elimina todos los campos/valores smart posibles, independientemente de si se inyectaron previamente o no.

-v, --verbose

Emite mensajes de depuración para el proceso de inyección de errores.

-u, --human

Formatea los números que representan tamaños de almacenamiento o desplazamientos como cadenas legibles por humanos con unidades en lugar de los datos numéricos brutos predeterminados que son amigables para la máquina. Convierte otros campos numéricos en cadenas hexadecimales.
