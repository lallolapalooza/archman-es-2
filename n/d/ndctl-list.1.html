NDCTL-LIST(1) Manual de ndctl NDCTL-LIST(1)

NOMBRE

ndctl-list - volcar la topología y atributos de los dispositivos nvdimm de la plataforma en json

SINOPSIS

ndctl list [<opciones>]

Recorre todos los buses nvdimm del sistema y lista todos los dispositivos conectados junto con algunos de sus atributos principales.

Se pueden especificar opciones para limitar la salida a dispositivos de una clase determinada. Las clases son buses, dimms, regiones y namespaces. Por defecto, ndctl list sin opciones es equivalente a:

ndctl list --namespaces --bus=all --region=all

EJEMPLO

# ndctl list --buses --namespaces
{
  "provider":"nfit_test.1",
  "dev":"ndbus2",
  "namespaces":[
    {
      "dev":"namespace9.0",
      "mode":"raw",
      "size":33554432,
      "blockdev":"pmem9"
    }
  ]
}
{
  "provider":"nfit_test.0",
  "dev":"ndbus1"
}
{
  "provider":"e820",
  "dev":"ndbus0",
  "namespaces":[
    {
      "dev":"namespace0.0",
      "mode":"fsdax",
      "size":8589934592,
      "blockdev":"pmem0"
    }
  ]
}

OPCIONES

-r, --region=

Un nombre de dispositivo regionX, o un número de ID de región. Restringe la operación a la(s) región(es) especificada(s). La palabra clave all puede especificarse para indicar la ausencia de cualquier restricción, sin embargo, esto es lo mismo que no proporcionar una opción --region en absoluto.

-b, --bus=

Un número de ID de bus, o una cadena de proveedor (por ejemplo, "ACPI.NFIT"). Restringe la operación al(los) bus(es) especificado(s). La palabra clave all puede especificarse para indicar la ausencia de cualquier restricción, sin embargo, esto es lo mismo que no proporcionar una opción --bus en absoluto.

-d, --dimm=

Un nombre de dispositivo nmemX, o un número de ID de dimm. El número de ID de dimm aquí es X en nmemX. Filtra la lista por dispositivos que hacen referencia al dimm dado. Por ejemplo, para ver todos los namespaces compuestos por capacidad de almacenamiento en nmem0:
# ndctl list --dimm=nmem0 --namespaces

-n, --namespace=

Un nombre de dispositivo namespaceX.Y, o una tupla de región de namespace más ID X.Y. Limita la lista de namespaces al único dispositivo identificado si está presente.

-m, --mode=

Filtra la lista por el modo (raw, fsdax, sector o devdax) del(los) namespace(s).

-U, --numa-node=

Filtra la lista por nodo numa

-B, --buses

Incluye información del bus en la lista

-D, --dimms

Incluye información del dimm en la lista
{
  "dev":"nmem0",
  "id":"cdab-0a-07e0-ffffffff",
  "handle":0,
  "phys_id":0,
  "security:":"disabled"
}

-H, --health

Incluye información de salud del dimm en la lista. Por ejemplo:
{
  "dev":"nmem0",
  "health":{
    "health_state":"non-critical",
    "temperature_celsius":23,
    "spares_percentage":75,
    "alarm_temperature":true,
    "alarm_spares":true,
    "temperature_threshold":40,
    "spares_threshold":5,
    "life_used_percentage":5,
    "shutdown_state":"clean"
  }
}

-F, --firmware

Incluye información de firmware en la lista, incluyendo el estado y la capacidad de activación del firmware en tiempo de ejecución:
# ndctl list -BDF
[
  {
    "provider":"nfit_test.0",
    "dev":"ndbus2",
    "scrub_state":"idle",
    "firmware":{
      "activate_method":"suspend",
      "activate_state":"idle"
    },
    "dimms":[
      {
        "dev":"nmem1",
        "id":"cdab-0a-07e0-ffffffff",
        "handle":0,
        "phys_id":0,
        "security":"disabled",
        "firmware":{
          "current_version":0,
          "can_update":true
        }
      },
...
]

-X, --device-dax

Incluye detalles de device-dax ("daxregion") cuando un namespace está en modo "devdax".
{
  "dev":"namespace0.0",
  "mode":"devdax",
  "size":4225761280,
  "uuid":"18ae1bbb-bb62-4efc-86df-4a5caacb5dcc",
  "daxregion":{
    "id":0,
    "size":4225761280,
    "align":2097152,
    "devices":[
      {
        "chardev":"dax0.0",
        "size":4225761280
      }
    ]
  }
}

-R, --regions

Incluye información de región en la lista

-N, --namespaces

Incluye información de namespace en la lista. La información de namespace se lista por defecto si no se especifican otras opciones al comando.

-i, --idle

Incluye dispositivos inactivos (no habilitados) en la lista

-c, --configured

Incluye dispositivos configurados (namespaces de tamaño distinto de cero) independientemente de si están habilitados o no. Otros dispositivos además de los namespaces siempre se consideran "configurados".

-C, --capabilities

Incluye las capacidades de región en la lista, es decir, modos de namespace admitidos y propiedades variables como tamaños de sector y alineaciones.

-M, --media-errors

Incluye errores de medios (bloques defectuosos) en la lista. Tenga en cuenta que la propiedad badblock_count se incluye en la lista por defecto cuando el recuento no es cero, de lo contrario se oculta. Además, si el namespace está en modo sector, la lista de badblocks no se incluye y la propiedad badblock_count puede incluir bloques que se encuentran en metadatos o capacidad no utilizada en el namespace. Convierta un namespace de sector a modo raw para listar los desplazamientos precisos de badblocks.
{
  "dev":"namespace7.0",
  "mode":"raw",
  "size":33554432,
  "blockdev":"pmem7",
  "badblock_count":17,
  "badblocks":[
    {
      "offset":4,
      "length":1
    },
    {
      "offset":32768,
      "length":8
    },
    {
      "offset":65528,
      "length":8
    }
  ]
}

-v, --verbose

Aumenta la verbosidad de la salida. Esto se puede especificar varias veces para ser aún más detallado en la salida de información y miscelánea, y se puede utilizar para anular las banderas omitidas para mostrar información específica.
•-v Además de la salida predeterminada de namespaces habilitados, muestra el nodo numa, el uuid_raw y los errores de medios de bloque defectuoso.
•-vv Todo lo que proporciona -v, más habilita automáticamente --dimms, --buses y --regions.
•-vvv Todo lo que proporciona -vv, más --health, --capabilities, --idle y --firmware. :: La verbosidad también se puede delimitar por tipo de objeto. Por ejemplo, para listar solo regiones con capacidades e información de errores de medios.
# ndctl list -Ru -vvv -r 0
{
  "dev":"region0",
  "size":"4.00 GiB (4.29 GB)",

  "type":"pmem",
  "numa_node":0,
  "target_node":2,

        512,

-u, --human

VARIABLES DE ENTORNO

NDCTL_LIST_LINT

Un error en la salida de "ndctl list" debe ser corregido con cuidado para otras herramientas que puedan haber desarrollado una dependencia del comportamiento erróneo. La variable NDCTL_LIST_LINT es una opción para aplicar correcciones, y no para regresar por defecto el comportamiento enviado previamente. Esta variable de entorno aplica las siguientes correcciones:
•Corregir "ndctl list -Rv" para mostrar solo objetos de región y no incluir objetos de namespace. ::
