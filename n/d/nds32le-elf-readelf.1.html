DESCRIPCIÓN

readelf muestra información sobre uno o más archivos objeto en formato ELF. Las opciones controlan qué información particular se muestra.

archivoelf... son los archivos objeto a examinar. Se soportan archivos ELF de 32 y 64 bits, así como archivos que contienen archivos ELF.

Este programa realiza una función similar a objdump, pero entra en más detalle y existe independientemente de la biblioteca BFD, por lo que si hay un error en BFD, readelf no se verá afectado.

OPCIONES

Las formas largas y cortas de las opciones, que se muestran aquí como alternativas, son equivalentes. Se debe proporcionar al menos una opción además de -v o -H.

-a
--all
Equivalente a especificar --file-header, --program-headers, --sections, --symbols, --relocs, --dynamic, --notes, --version-info, --arch-specific, --unwind, --section-groups e --histogram.

Nota: esta opción no activa --use-dynamic en sí misma, por lo que si esa opción no está presente en la línea de comandos, no se mostrarán los símbolos dinámicos ni las relocalizaciones dinámicas.

-h
--file-header
Muestra la información contenida en la cabecera ELF al principio del archivo.
-l
--program-headers
--segments
Muestra la información contenida en las cabeceras de segmento del archivo, si las tiene.
--quiet
Suprime el diagnóstico de "sin símbolos".
-S
--sections
--section-headers
Muestra la información contenida en las cabeceras de sección del archivo, si las tiene.
-g
--section-groups
Muestra la información contenida en los grupos de secciones del archivo, si los tiene.
-t
--section-details
Muestra la información detallada de la sección. Implica -S.
-s
--symbols
--syms
Muestra las entradas en la tabla de símbolos de la sección del archivo, si la tiene. Si un símbolo tiene información de versión asociada, esta se muestra también. La cadena de versión se muestra como un sufijo al nombre del símbolo, precedido por un carácter @. Por ejemplo, foo@VER_1. Si la versión es la versión predeterminada a utilizar al resolver referencias no versionadas al símbolo, se muestra como un sufijo precedido por dos caracteres @. Por ejemplo, foo@@VER_2.
--dyn-syms
Muestra las entradas en la sección de tabla de símbolos dinámicos del archivo, si la tiene. El formato de salida es el mismo que el formato usado por la opción --syms.
--lto-syms
Muestra el contenido de las tablas de símbolos LTO en el archivo.
--sym-base=[0|8|10|16]
Fuerza a que el campo de tamaño de la tabla de símbolos use la base dada. Cualquier opción no reconocida se tratará como 0. --sym-base=0 representa el comportamiento predeterminado y heredado. Esto mostrará los tamaños como decimales para números menores que 100000. Para tamaños de 100000 o mayores, se usará notación hexadecimal con un prefijo 0x. --sym-base=8 dará los tamaños de los símbolos en octal. --sym-base=10 siempre dará los tamaños de los símbolos en decimal. --sym-base=16 siempre dará los tamaños de los símbolos en hexadecimal con un prefijo 0x.
--demangle[=estilo]
Decodifica (demangle) nombres de símbolos de bajo nivel a nombres de usuario. Esto hace que los nombres de funciones C++ sean legibles. Diferentes compiladores tienen diferentes estilos de mangling. El argumento opcional del estilo de demangling se puede usar para elegir un estilo de demangling apropiado para su compilador.
--no-demangle
No decodificar nombres de símbolos de bajo nivel. Este es el valor predeterminado.
--recurse-limit
--no-recurse-limit
--recursion-limit
--no-recursion-limit
Habilita o deshabilita un límite en la cantidad de recursión realizada al demanglar cadenas. Dado que los formatos de mangling de nombres permiten un nivel infinito de recursión, es posible crear cadenas cuya decodificación agote la cantidad de espacio de pila disponible en la máquina host, provocando un fallo de memoria. El límite intenta evitar que esto suceda restringiendo la recursión a 2048 niveles de anidamiento.

El valor predeterminado es que este límite esté habilitado, pero deshabilitarlo puede ser necesario para demanglar nombres realmente complicados. Tenga en cuenta, sin embargo, que si el límite de recursión está deshabilitado, es posible agotar la pila y cualquier informe de error sobre tal evento será rechazado.

-U método
--unicode=método
Usa el método de decodificación de caracteres no ASCII especificado. Las opciones válidas son: none, c, cpp, dollar, locale. El valor predeterminado es locale.
-X
--extra-sym-info
--no-extra-sym-info
Muestra información adicional de símbolos cuando se usan las opciones --symbols o --dyn-syms. El comportamiento predeterminado es no mostrar esta información adicional.
-n
--notes
Muestra la información de las secciones de notas del archivo, si las tiene.
-r
--relocs
Muestra la información de las relocalizaciones del archivo, si las tiene.
-u
--unwind
Muestra la información de la tabla de desenrollado del archivo, si la tiene.
-d
--dynamic
Muestra la información de la sección dinámica del archivo, si la tiene.
-V
--version-info
Muestra la información de versiones del archivo, si la tiene.
-A
--arch-specific
Muestra información específica de la arquitectura del archivo, si la tiene.
-D
--use-dynamic
Muestra la información de la sección dinámica del archivo, en lugar de la sección de tabla de símbolos. Esto es útil para ver los símbolos que se exportan del archivo.
-L
--lint
--enable-checks
Realiza una serie de comprobaciones en el archivo ELF para verificar su conformidad con el estándar ELF. Se imprimen mensajes de advertencia si se encuentran problemas.
-x <número o nombre>
--hex-dump=<número o nombre>
Vuelca el contenido de una sección en formato hexadecimal. El <número o nombre> especifica la sección que se va a volcar.
-p <número o nombre>
--string-dump=<número o nombre>
Vuelca el contenido de una sección de cadenas en formato de cadena imprimible. El <número o nombre> especifica la sección que se va a volcar.
-R <número o nombre>
--relocated-dump=<número o nombre>
Vuelca el contenido de una sección de relocalizaciones en formato de cadena. El <número o nombre> especifica la sección que se va a volcar.
-z
--decompress
Descomprime secciones comprimidas (por ejemplo, secciones `.zdebug*`).
-c
--archive-index
Muestra el índice del archivo dentro de un archivo de biblioteca (ar).
-w[lLiaprmfFsoORtUuTgAck]
--debug-dump[=rawline,=decodedline,=info,=abbrev,=pubnames,=aranges,=macro,=frames,=frames-interp,=str,=str-offsets,=loc,=Ranges,=pubtypes,=trace_info,=trace_abbrev,=trace_aranges,=gdb_index,=addr,=cu_index,=links]
Muestra información de depuración DWARF. La opción puede ir seguida de uno o más especificadores separados por comas para seleccionar qué partes de la información de depuración se mostrarán.
-wK
--debug-dump=follow-links
Sigue los enlaces de inclusión de archivos de origen al mostrar información de depuración.
-wN
--debug-dump=no-follow-links
No sigue los enlaces de inclusión de archivos de origen al mostrar información de depuración.
-wD
--debug-dump=use-debuginfod
Usa el servicio debuginfod para obtener información de depuración de fuentes remotas.
-wE
--debug-dump=do-not-use-debuginfod
No usa el servicio debuginfod para obtener información de depuración.
-P
--process-links
Procesa enlaces simbólicos en las tablas de símbolos.
--dwarf-depth=n
Limita la profundidad de recursión al procesar la información DWARF a n niveles.
--dwarf-start=n
Comienza a procesar la información DWARF a partir del nivel n. Útil para saltarse la información de las unidades de compilación externas.
--ctf=sección
Muestra la sección CTF (Common Type Format) especificada.
--ctf-parent=sección
Muestra la sección CTF padre de la sección especificada.
--ctf-symbols=sección
Muestra los símbolos de la sección CTF especificada.
--ctf-strings=sección
Muestra las cadenas de la sección CTF especificada.
--sframe=sección
Muestra la sección SFrame (Stack Frame) especificada.
-I
--histogram
Muestra un histograma de los tipos de secciones del archivo.
-v
--version
Muestra la información de la versión de readelf.
-W
--wide
Asegura que la salida no se trunque horizontalmente. Es decir, imprime todas las columnas que serían truncadas por la anchura de la terminal.
-T
--silent-truncation
No emite un mensaje de aviso si las cadenas de la tabla de símbolos se truncan.
-H
--help
Muestra un mensaje de ayuda y sale.

-U [d|i|l|e|x|h]
Controla la visualización de caracteres no ASCII en nombres de identificadores. Por defecto (--unicode=locale o --unicode=default) se tratan como caracteres multibyte y se muestran en la configuración regional actual. Todas las demás versiones de esta opción tratan los bytes como valores codificados en UTF-8 y intentan interpretarlos. Si no se pueden interpretar o si se usa la opción --unicode=invalid, se muestran como una secuencia de bytes hexadecimales, encerrados entre llaves.

Usar la opción --unicode=escape mostrará los caracteres como secuencias de escape unicode (\uxxxx). Usar --unicode=hex mostrará los caracteres como secuencias de bytes hexadecimales encerradas entre corchetes angulares.

Usar --unicode=highlight mostrará los caracteres como secuencias de escape unicode pero también los resaltará en rojo, asumiendo que el dispositivo de salida soporta el coloreado. El coloreado está destinado a llamar la atención sobre la presencia de secuencias unicode cuando podrían no ser esperadas.

-X
--extra-sym-info
Al mostrar detalles de símbolos, incluye información adicional que normalmente no se presenta. Actualmente, esto solo añade el nombre de la sección a la que hace referencia el campo de índice del símbolo, si lo hay. En el futuro se podría mostrar más información cuando esta opción esté habilitada.

Habilitar esta opción habilita efectivamente la opción --wide también, al menos cuando se muestra información de símbolos.

--no-extra-sym-info
Deshabilita el efecto de la opción --extra-sym-info. Esta es la opción predeterminada.
-e
--headers
Muestra todas las cabeceras del archivo. Equivalente a -h -l -S.
-n
--notes
Muestra el contenido de los segmentos y/o secciones NOTE, si existen.
-r
--relocs
Muestra el contenido de la sección de reubicación del archivo, si tiene alguna.
-u
--unwind
Muestra el contenido de la sección de desenrollado del archivo, si tiene alguna. Actualmente solo se soportan las secciones de desenrollado para archivos ELF IA64, así como las tablas de desenrollado ARM (".ARM.exidx" / ".ARM.extab"). Si el soporte aún no está implementado para tu arquitectura, puedes intentar mostrar el contenido de la sección .eh_frames usando las opciones --debug-dump=frames o --debug-dump=frames-interp.
-d
--dynamic
Muestra el contenido de la sección dinámica del archivo, si tiene alguna.
-V
--version-info
Muestra el contenido de las secciones de versión en el archivo, si existen.
-A
--arch-specific
Muestra información específica de la arquitectura en el archivo, si existe alguna.
-D
--use-dynamic
Al mostrar símbolos, esta opción hace que readelf use las tablas hash de símbolos en la sección dinámica del archivo, en lugar de las secciones de tabla de símbolos.

Al mostrar reubicaciones, esta opción hace que readelf muestre las reubicaciones dinámicas en lugar de las reubicaciones estáticas.

-L
--lint
--enable-checks
Muestra mensajes de advertencia sobre posibles problemas con los archivos que se están examinando. Si se usa solo, se examinará todo el contenido de los archivos. Si se usa con una de las opciones de volcado, los mensajes de advertencia solo se producirán para las cosas que se están mostrando.
-x <número o nombre>
--hex-dump=<número o nombre>
Muestra el contenido de la sección indicada como bytes hexadecimales. Un número identifica una sección particular por su índice en la tabla de secciones; cualquier otra cadena identifica todas las secciones con ese nombre en el archivo objeto.
-R <número o nombre>
--relocated-dump=<número o nombre>
Muestra el contenido de la sección indicada como bytes hexadecimales. Un número identifica una sección particular por su índice en la tabla de secciones; cualquier otra cadena identifica todas las secciones con ese nombre en el archivo objeto. El contenido de la sección se reubicará antes de mostrarlo.
-p <número o nombre>
--string-dump=<número o nombre>
Muestra el contenido de la sección indicada como cadenas imprimibles. Un número identifica una sección particular por su índice en la tabla de secciones; cualquier otra cadena identifica todas las secciones con ese nombre en el archivo objeto.
-z
--decompress
Solicita que las secciones que se están mostrando con las opciones x, R o p se descompriman antes de ser mostradas. Si las secciones no están comprimidas, se muestran tal cual.
-c
--archive-index
Muestra la información del índice de símbolos del archivo contenida en la parte de cabecera de los archivos binarios. Realiza la misma función que el comando t de ar, pero sin usar la biblioteca BFD.

--debug-dump[=rawline,=decodedline,=info,=abbrev,=pubnames,=aranges,=macro,=frames,=frames-interp,=str,=str-offsets,=loc,=Ranges,=pubtypes,=trace_info,=trace_abbrev,=trace_aranges,=gdb_index,=addr,=cu_index,=links,=follow-links]

Muestra el contenido de cualquier sección de depuración seleccionada que se encuentre en archivos de información de depuración separados y enlazados. Esto puede resultar en la visualización de múltiples versiones de la misma sección de depuración si existe en más de un archivo.

Esto podría llevar tiempo en resolverse. Este comportamiento se puede deshabilitar mediante la opción de depuración =do-not-use-debuginfod.

--wide
Do not break output lines to fit into 80 columns. By default readelf breaks section header and segment listing lines for 64-bit ELF files, so that they fit into 80 columns. --dwarf-depth=n
Limit the dump of the ".debug_info" section to n children. This is only useful with --debug-dump=info. The default is to print all DIEs; the special value 0 for n will also have this effect.

With a non-zero value for n, DIEs at or deeper than n levels will not be printed. The range for n is zero-based.

--dwarf-start=n
Print only DIEs beginning with the DIE numbered n. This is only useful with --debug-dump=info.

If specified, this option will suppress printing of any header information and all DIEs before the DIE numbered n. Only siblings and children of the specified DIE will be printed.

This can be used in conjunction with --dwarf-depth.

--process-links
Display the contents of non-debug sections found in separate debuginfo files that are linked to the main file. This option automatically implies the -wK option, and only sections requested by other command line options will be displayed.
--ctf[=section]
Display the contents of the specified CTF section. CTF sections themselves contain many subsections, all of which are displayed in order.

By default, display the name of the section named .ctf, which is the name emitted by ld.

--ctf-parent=member
If the CTF section contains ambiguously-defined types, it will consist of an archive of many CTF dictionaries, all inheriting from one dictionary containing unambiguous types. This member is by default named .ctf, like the section containing it, but it is possible to change this name using the "ctf_link_set_memb_name_changer" function at link time. When looking at CTF archives that have been created by a linker that uses the name changer to rename the parent archive member, --ctf-parent can be used to specify the name used for the parent.
--ctf-symbols=section
--ctf-strings=section
Specify the name of another section from which the CTF file can inherit strings and symbols. By default, the ".symtab" and its linked string table are used.

If either of --ctf-symbols or --ctf-strings is specified, the other must be specified as well.

--histogram
Display a histogram of bucket list lengths when displaying the contents of the symbol tables.
--silent-truncation
Normally when readelf is displaying a symbol name, and it has to truncate the name to fit into an 80 column display, it will add a suffix of "[...]" to the name. This command line option disables this behaviour, allowing 5 more characters of the name to be displayed and restoring the old behaviour of readelf (prior to release 2.35).
--help
Display the command-line options understood by readelf.
@file
Read command-line options from file. The options read are inserted in place of the original @file option. If file does not exist, or cannot be read, then the option will be treated literally, and not removed.

Options in file are separated by whitespace. A whitespace character may be included in an option by surrounding the entire option in either single or double quotes. Any character (including a backslash) may be included by prefixing the character to be included with a backslash. The file may itself contain additional @file options; any such options will be processed recursively.
