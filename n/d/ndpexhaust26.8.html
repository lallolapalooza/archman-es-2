NOMBRE

ndpexhaust26

SINOPSIS

ndpexhaust26 [-acpPTUrRm] [-s direccionip6origen] interface redobjetivo

OPCIONES

 -a      añade una cabecera hop-by-hop con router alert
 -c      no calcula el checksum para ahorrar tiempo
 -p      envía solicitudes Echo ICMPv6
 -P      envía respuestas Echo ICMPv6
 -T      envía ICMPv6 Time-to-live-exceeded
 -U      envía ICMPv6 Unreachable (sin ruta)
 -r      aleatoriza el origen de tu prefijo /64
 -R      aleatoriza completamente el origen
 -m      genera un paquete de tamaño máximo
 -s direccionip6origen  usa esta como dirección IPv6 de origen
Inunda la red /64 objetivo con mensajes de error ICMPv6 TooBig.
Esta versión de la herramienta es muchas veces más efectiva que ndpexhaust6.
