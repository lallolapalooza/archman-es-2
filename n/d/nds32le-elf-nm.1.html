NOMBRE

nm - listar símbolos de archivos objeto

SINOPSIS

nm [-A|-o|--print-file-name]
[-a|--debug-syms]
[-B|--format=bsd]
[-C|--demangle[=estilo]]
[-D|--dynamic]
[-fformato|--format=formato]
[-g|--extern-only]
[-h|--help]
[--ifunc-chars=CARACTERES]
[-j|--format=just-symbols]
[-l|--line-numbers] [--inlines]
[-n|-v|--numeric-sort]
[-P|--portability]
[-p|--no-sort]
[-r|--reverse-sort]
[-S|--print-size]
[-s|--print-armap]
[-t raíz|--radix=raíz]
[-u|--undefined-only]
[-U|--defined-only]
[-V|--version]
[-W|--no-weak]
[-X 32_64]
[--no-demangle]
[--no-recurse-limit|--recurse-limit]]
[--plugin nombre]
[--size-sort]
[--special-syms]
[--synthetic]
[--target=nombre_bfd]
[--unicode=método]
[--with-symbol-versions]
[--without-symbol-versions]
[archivo_objeto...]

DESCRIPCIÓN

GNU nm lista los símbolos de los archivos objeto archivo_objeto.... Si no se listan archivos objeto como argumentos, nm asume el archivo a.out.

Para cada símbolo, nm muestra:

  • El valor del símbolo, en la raíz seleccionada por las opciones (ver abajo), o hexadecimal por defecto.
  • El tipo del símbolo. Al menos los siguientes tipos se utilizan; otros también, dependiendo del formato del archivo objeto. Si es minúscula, el símbolo es usualmente local; si es mayúscula, el símbolo es global (externo). Sin embargo, hay algunos símbolos en minúscula que se muestran para símbolos globales especiales ("u", "v" y "w").
"A"
El valor del símbolo es absoluto y no se modificará por enlaces posteriores.
"B"
"b"
El símbolo está en la sección de datos BSS. Esta sección típicamente contiene datos inicializados a cero o no inicializados, aunque el comportamiento exacto depende del sistema.
"C"
"c"
El símbolo es común. Los símbolos comunes son datos no inicializados. Al enlazar, pueden aparecer múltiples símbolos comunes con el mismo nombre. Si el símbolo está definido en algún lugar, los símbolos comunes se tratan como referencias indefinidas. El carácter minúscula c se usa cuando el símbolo está en una sección especial para comunes pequeños.
"D"
"d"
El símbolo está en la sección de datos inicializados.
"G"
"g"
El símbolo está en una sección de datos inicializados para objetos pequeños. Algunos formatos de archivo objeto permiten un acceso más eficiente a objetos de datos pequeños, como una variable entera global en comparación con un array global grande.
"i"
Para archivos con formato PE, esto indica que el símbolo está en una sección específica para la implementación de DLLs.

Para archivos con formato ELF, esto indica que el símbolo es una función indirecta. Esta es una extensión de GNU al conjunto estándar de tipos de símbolos ELF. Indica un símbolo que, si se referencia por una relocalización, no evalúa a su dirección, sino que debe invocarse en tiempo de ejecución. La ejecución en tiempo de ejecución devolverá el valor a usar en la relocalización.

Nota: la visualización real de símbolos para símbolos indirectos de GNU está controlada por la opción de línea de comandos --ifunc-chars. Si se ha proporcionado esta opción, el primer carácter de la cadena se usará para símbolos de función indirecta global. Si la cadena contiene un segundo carácter, ese se usará para símbolos de función indirecta locales.

"I"
El símbolo es una referencia indirecta a otro símbolo.
"N"
El símbolo es un símbolo de depuración.
"n"
El símbolo está en una sección de solo lectura que no es de datos, ni código, ni depuración.
"p"
El símbolo está en una sección de desenrollado de pila.
"R"
"r"
El símbolo está en una sección de datos de solo lectura.
"S"
"s"
El símbolo está en una sección de datos no inicializados o inicializados a cero para objetos pequeños.
"T"
"t"
El símbolo está en la sección de texto (código).
"U"
El símbolo es indefinido.
"u"
El símbolo es un símbolo global único. Esta es una extensión de GNU al conjunto estándar de enlaces de símbolos ELF. Para un símbolo de este tipo, el enlazador dinámico se asegurará de que en todo el proceso solo se utilice un símbolo con este nombre y tipo.
"V"
"v"
El símbolo es un objeto débil. Cuando un símbolo definido débil se enlaza con un símbolo definido normal, se usa el símbolo definido normal sin errores. Cuando un símbolo indefinido débil se enlaza y el símbolo no está definido, el valor del símbolo débil se convierte en cero sin errores. En algunos sistemas, las mayúsculas indican que se ha especificado un valor predeterminado.
"W"
"w"
El símbolo es un símbolo débil que no ha sido etiquetado específicamente como un símbolo de objeto débil. Cuando un símbolo definido débil se enlaza con un símbolo definido normal, se usa el símbolo definido normal sin errores. Cuando un símbolo indefinido débil se enlaza y el símbolo no está definido, el valor del símbolo se determina de manera específica del sistema sin errores. En algunos sistemas, las mayúsculas indican que se ha especificado un valor predeterminado.
"-"
El símbolo es un símbolo stabs en un archivo objeto a.out. En este caso, los siguientes valores impresos son el campo other de stabs, el campo desc de stabs, y el tipo de stab. Los símbolos Stabs se usan para almacenar información de depuración.
"?"
El tipo de símbolo es desconocido o específico del formato del archivo objeto.
•
El nombre del símbolo. Si un símbolo tiene información de versión asociada, entonces se muestra la información de versión. Si el símbolo versionado es indefinido o está oculto al enlazador, la cadena de versión se muestra como un sufijo al nombre del símbolo, precedido por un carácter @. Por ejemplo, foo@VER_1. Si la versión es la versión predeterminada a usar al resolver referencias no versionadas al símbolo, entonces se muestra como un sufijo precedido por dos caracteres @. Por ejemplo, foo@@VER_2.

OPCIONES

Las formas largas y cortas de las opciones, que se muestran aquí como alternativas, son equivalentes.

-A
-o
--print-file-name
Anteponer a cada símbolo el nombre del archivo de entrada (o miembro del archivo) en el que se encontró, en lugar de identificar el archivo de entrada una sola vez, antes de todos sus símbolos.
-a
--debug-syms
Mostrar todos los símbolos, incluso los de depuración; normalmente no se muestran.
-B
Lo mismo que --format=bsd (para compatibilidad con el nm de MIPS).
-C
--demangle[=estilo]
Decodificar (demangle) los nombres de símbolos de bajo nivel en nombres de nivel de usuario. Además de eliminar cualquier guion bajo inicial agregado por el sistema, esto hace que los nombres de funciones de C++ sean legibles. Diferentes compiladores tienen diferentes estilos de mangling. El argumento opcional de estilo de demangling puede usarse para elegir un estilo de demangling apropiado para su compilador.
--no-demangle
No decodificar nombres de símbolos de bajo nivel. Esta es la opción predeterminada.
=permalink href="#recurse">--recurse-limit
href="#no~2">--no-recurse-limit
href="#recursion">--recursion-limit
href="#no~3">--no-recursion-limit
Habilita o deshabilita un límite en la cantidad de recursión realizada al desmanglear cadenas. Dado que los formatos de mangling de nombres permiten un nivel infinito de recursión, es posible crear cadenas cuya decodificación agote la cantidad de espacio de pila disponible en la máquina anfitriona, desencadenando una falla de memoria. El límite intenta evitar que esto suceda restringiendo la recursión a 2048 niveles de anidamiento.

El valor predeterminado es que este límite esté habilitado, pero deshabilitarlo puede ser necesario para desmanglear nombres verdaderamente complicados. Sin embargo, tenga en cuenta que si el límite de recursión está deshabilitado, es posible el agotamiento de la pila y cualquier informe de error sobre tal evento será rechazado.

href="#D">-D
href="#dynamic">--dynamic
Muestra los símbolos dinámicos en lugar de los símbolos normales. Esto solo es significativo para objetos dinámicos, como ciertos tipos de bibliotecas compartidas.
href="#f">-f formato
href="#format=">--format=formato
Usa el formato de salida formato, que puede ser "bsd", "sysv", "posix" o "just-symbols". El valor predeterminado es "bsd". Solo el primer carácter de formato es significativo; puede ser mayúscula o minúscula.
href="#g">-g
href="#extern">--extern-only
Muestra solo símbolos externos.
href="#h">-h
href="#help">--help
Muestra un resumen de las opciones de nm y sale.
href="#ifunc">--ifunc-chars=CHARS
Al mostrar símbolos de funciones indirectas de GNU, nm usará por defecto el carácter "i" tanto para funciones indirectas locales como para funciones indirectas globales. La opción --ifunc-chars permite al usuario especificar una cadena que contiene uno o dos caracteres. El primer carácter se usará para símbolos de funciones indirectas globales y el segundo carácter, si está presente, se usará para símbolos de funciones indirectas locales.
href="#j">j
Lo mismo que --format=just-symbols.
href="#l">-l
href="#line">--line-numbers
Para cada símbolo, utiliza información de depuración para intentar encontrar un nombre de archivo y un número de línea. Para un símbolo definido, busca el número de línea de la dirección del símbolo. Para un símbolo indefinido, busca el número de línea de una entrada de reubicación que hace referencia al símbolo. Si se puede encontrar información del número de línea, imprímela después de la otra información del símbolo.
href="#inlines">--inlines
Cuando la opción -l está activa, si la dirección pertenece a una función que fue inlined, entonces esta opción hace que la información de origen para todos los ámbitos contenedores hasta la primera función no inlined también se imprima. Por ejemplo, si "main" inlines "callee1" que inlines "callee2", y la dirección es de "callee2", la información de origen para "callee1" y "main" también se imprimirá.
href="#n">-n
href="#v">-v
href="#numeric">--numeric-sort
Ordena los símbolos numéricamente por sus direcciones, en lugar de alfabéticamente por sus nombres.
href="#p">-p
href="#no~4">--no-sort
No molestar en ordenar los símbolos en ningún orden; imprímelos en el orden en que se encuentran.
href="#P">-P
href="#portability">--portability
Utiliza el formato de salida estándar POSIX.2 en lugar del formato predeterminado. Equivalente a -f posix.
href="#r">-r
href="#reverse">--reverse-sort
Invierte el orden del ordenamiento (ya sea numérico o alfabético); deja que el último venga primero.
href="#S">-S
href="#print~2">--print-size
Imprime tanto el valor como el tamaño de los símbolos definidos para el estilo de salida "bsd". Esta opción no tiene efecto para formatos de objeto que no registran tamaños de símbolos, a menos que también se use --size-sort, en cuyo caso se mostrará un tamaño calculado.

Tenga en cuenta que esta opción no tiene efecto para formatos de objeto que no registran tamaños de símbolos, a menos que --size-sort se use también, en cuyo caso se mostrará un tamaño calculado.

href="#s">-s
href="#print~3">--print-armap
Al listar símbolos de miembros de archivo, incluya el índice: un mapa (almacenado en el archivo por ar o ranlib) de qué módulos contienen definiciones para qué nombres.
href="#t">-t base
href="#radix=">--radix=base
Usa base como la base para imprimir los valores de los símbolos. Debe ser d para decimal, o para octal, o x para hexadecimal.
href="#u">-u
href="#undefined">--undefined-only
Muestra solo símbolos indefinidos (aquellos externos a cada archivo objeto). Por defecto, se muestran ambos símbolos, definidos e indefinidos.
href="#U">-U
href="#defined">--defined-only
Muestra solo símbolos definidos para cada archivo objeto. Por defecto, se muestran ambos símbolos, definidos e indefinidos.
href="#V">-V
href="#version">--version
Muestra el número de versión de nm y sale.
href="#X">-X
Esta opción se ignora por compatibilidad con la versión AIX de nm. Toma un parámetro que debe ser la cadena 32_64. El modo predeterminado de nm de AIX corresponde a -X 32, que no es compatible con el nm de GNU.
href="#plugin">--plugin nombre
Carga el plugin llamado nombre para agregar soporte para tipos de destino adicionales. Esta opción solo está disponible si la cadena de herramientas se ha compilado con el soporte de plugins habilitado.

Si no se proporciona --plugin, pero se ha habilitado el soporte de plugins, entonces nm itera sobre los archivos en ${libdir}/bfd-plugins en orden alfabético y se usa el primer plugin que reclama el objeto en cuestión.

Tenga en cuenta que este directorio de búsqueda de plugins no es el utilizado por la opción -plugin de ld. Para que nm utilice el plugin del enlazador, debe copiarse en el directorio ${libdir}/bfd-plugins. Para compilaciones basadas en GCC, el plugin del enlazador se llama liblto_plugin.so.0.0.0. Para compilaciones basadas en Clang, se llama LLVMgold.so. El plugin GCC siempre es compatible con versiones anteriores, por lo que es suficiente con copiar el más reciente.

href="#size">--size-sort
Ordena los símbolos por tamaño. Para objetos ELF, los tamaños de los símbolos se leen del ELF; para otros tipos de objetos, los tamaños de los símbolos se calculan como la diferencia entre el valor del símbolo y el valor del símbolo con el siguiente valor más alto. Si se utiliza el formato de salida "bsd", se imprime el tamaño del símbolo en lugar del valor, y debe usarse -S para imprimir tanto el tamaño como el valor.

Nota: esta opción no funciona si se ha habilitado --undefined-only, ya que los símbolos indefinidos no tienen tamaño.

href="#special">--special-syms
Muestra símbolos que tienen un significado especial específico del objetivo. Estos símbolos se utilizan normalmente para algún procesamiento especial por parte del objetivo y normalmente no son útiles cuando se incluyen en las listas de símbolos normales. Por ejemplo, para los objetivos ARM, esta opción omitiría los símbolos de mapeo utilizados para marcar transiciones entre código ARM, código THUMB y datos.
href="#synthetic">--synthetic
Incluye símbolos sintéticos en la salida. Estos son símbolos especiales creados por el enlazador para diversos propósitos. No se muestran por defecto ya que no forman parte del código fuente original del binario.
href="#unicode=">--unicode=[default|invalid|locale|escape|hex|highlight]
Controla la visualización de caracteres multibyte codificados en UTF-8 en cadenas. El valor predeterminado (--unicode=default) es no darles ningún tratamiento especial. La opción --unicode=locale muestra la secuencia en la configuración regional actual, que puede o no admitirlos. Las opciones --unicode=hex y --unicode=invalid las muestran como secuencias de bytes hexadecimales encerradas entre corchetes angulares o llaves.

La opción --unicode=escape las muestra como secuencias de escape (\\uxxxx) y la opción --unicode=highlight las muestra como secuencias de escape resaltadas en rojo (si el dispositivo de salida lo admite). El coloreado tiene la intención de llamar la atención sobre la presencia de secuencias unicode donde no se esperan.

NAME

nds32le-elf-nm ‐ list symbols from object files

SYNOPSIS

nds32le-elf-nm [-A] [-a] [-B] [--debug-syms] [-e] [-f format] [-g] [-H] [--no-sort] [-l] [-n] [-o] [--defined-only] [-P] [-p] [--size-sort] [-S] [-t radix] [-v] [--vert] [-r] [-X] [-x] [objfile...]

DESCRIPTION

The nds32le-elf-nm utility displays the symbols from each object file specified. If no object file is specified, the symbols from the archive file a.out are used.

The default output format is:

symbol-name symbol-type symbol-value

The nds32le-elf-nm utility sorts the symbols by symbol name. It can also sort them by address or size, or it can print them in the order they appear in the object file.

The symbol-type is usually a character which indicates the section the symbol is in, or the type of the symbol. Common symbol types are:

U
Undefined symbol.
A
Absolute symbol.
T
Symbol in the text (code) section.
D
Symbol in the data section.
B
Symbol in the BSS (uninitialized data) section.
C
Common symbol.
W
Weak symbol.
I
Indirect symbol.
-
Some other section.

The symbol-value is the address or offset of the symbol.

OPTIONS

-A
-a
Do not discard non-global symbols.
-B
Same as nds32le-elf-objdump, print symbols in traditional SVR4-like format.
--debug-syms
Print debugging symbols, not normal symbols.
-e
Print the symbol table of an object file for each input file.
-f format
Display the input object file format.
-g
Print only global symbols.
-H
--no-sort
Do not sort the symbols.
-l
Set the default output format to plain text with no versioning.
-n
Set the default output format to plain text with no versioning.
-o
Set the default output format to plain text with no versioning.
--defined-only
Print only defined symbols.
-P
Print the unmangled names of C++ symbols.
-p
Do not display the symbol version information.
--size-sort
Sort symbols by size.
-S
Set the default output format to plain text with no versioning.
-t radix
Display the symbol values in the specified radix. Valid values for radix are d for decimal, o for octal, x for hexadecimal, i for input radix (default), and a for address radix.
-v
Display the version of nds32le-elf-nm and exit.
--vert
-r
Sort symbols according to their addresses.
-X
Display the symbol version information.
-x
Display the symbol version information.
foo@VER_1
If the version is the default version to be used when resolving unversioned references to the symbol then it is displayed as a suffix preceded by two @ characters. For example foo@@VER_2. By default, symbol version information is displayed.
--target=bfdname
Specify an object code format other than your system's default format.
@file
Read command-line options from file. The options read are inserted in place of the original @file option. If file does not exist, or cannot be read, then the option will be treated literally, and not removed.

Options in file are separated by whitespace. A whitespace character may be included in an option by surrounding the entire option in either single or double quotes. Any character (including a backslash) may be included by prefixing the character to be included with a backslash. The file may itself contain additional @file options; any such options will be processed recursively.
