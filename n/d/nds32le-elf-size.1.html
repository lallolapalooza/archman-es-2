Paquete: nds32le-elf-binutils

Licencias: GPL

SIZE(1) GNU Development Tools SIZE(1)

NOMBRE

size - lista tamaños de secciones y tamaño total de archivos binarios

SINOPSIS

size [-A|-B|-G|--format=compatibilidad]
[--help]
[-d|-o|-x|--radix=numero]
[--common]
[-t|--totals]
[--target=nombrebfd] [-V|--version]
[-f]
[archivoobj...]

DESCRIPCIÓN

La utilidad GNU size lista los tamaños de las secciones y el tamaño total para cada uno de los archivos binarios archivoobj en su lista de argumentos. Por defecto, se genera una línea de salida por cada archivo o por cada módulo si el archivo es un archivo.

archivoobj... son los archivos a examinar. Si no se especifica ninguno, se utilizará el archivo "a.out" en su lugar.

OPCIONES

Las opciones de la línea de comandos tienen los siguientes significados:

-A
-B
-G
--format=compatibilidad
Usando una de estas opciones, puedes elegir si la salida de GNU size se parece a la salida de System V size (usando -A, o --format=sysv), o a la de Berkeley size (usando -B, o --format=berkeley). El valor por defecto es el formato de una línea similar al de Berkeley. Alternativamente, puedes elegir la salida en formato GNU (usando -G, o --format=gnu), que es similar al formato de salida de Berkeley, pero los tamaños se cuentan de forma diferente.

Aquí hay un ejemplo del formato Berkeley (por defecto) de salida de size:

$ size --format=Berkeley ranlib size
   text    data     bss     dec     hex filename
 294880   81920   11592  388392   5ed28 ranlib
 294880   81920   11888  388688   5ee50 size

La salida estilo Berkeley cuenta los datos de solo lectura en la columna "text", no en la columna "data"; las columnas "dec" y "hex" muestran la suma de las columnas "text", "data" y "bss" en decimal y hexadecimal respectivamente.

El formato GNU cuenta los datos de solo lectura en la columna "data", no en la columna "text", y solo muestra la suma de las columnas "text", "data" y "bss" una vez, en la columna "total". La opción --radix se puede usar para cambiar la base numérica para todas las columnas. Aquí están los mismos datos mostrados con convenciones GNU:

$ size --format=GNU ranlib size
      text       data        bss      total filename
    279880      96920      11592     388392 ranlib
    279880      96920      11888     388688 size

Estos son los mismos datos, pero mostrados más cerca de las convenciones de System V:

$ size --format=SysV ranlib size
ranlib  :
section         size         addr
.text         294880         8192
.data          81920       303104
.bss           11592       385024
Total         388392


size  :
section         size         addr
.text         294880         8192
.data          81920       303104
.bss           11888       385024
Total         388688
--help
-h
-H
-?
Muestra un resumen de los argumentos y opciones aceptables.
-d
-o
-x
--radix=numero
Usando una de estas opciones, puedes controlar si el tamaño de cada sección se da en decimal (-d, o --radix=10); octal (-o, o --radix=8); o hexadecimal (-x, o --radix=16). En --radix=numero, solo los tres valores (8, 10, 16) son soportados. El tamaño total siempre se da en dos bases; decimal y hexadecimal para la salida de -d o -x, o octal y hexadecimal si estás usando -o.
--common
Imprime el tamaño total de los símbolos comunes en cada archivo. Cuando se usa el formato Berkeley o GNU, estos se incluyen en el tamaño bss.
-t
--totals
Muestra los totales de todos los objetos listados (solo en modo formato Berkeley o GNU).
--target=nombrebfd
Especifica que el formato del código objeto para archivoobj es nombrebfd. Esta opción puede no ser necesaria; size puede reconocer automáticamente muchos formatos.
-v
-V
--version
Muestra el número de versión de size.
-f
Ignorada. Esta opción es utilizada por otras versiones del programa size, pero no es soportada por la versión de GNU Binutils.
@archivo
Lee las opciones de la línea de comandos desde archivo. Las opciones leídas se insertan en lugar de la opción @archivo original. Si archivo no existe, o no se puede leer, entonces la opción se tratará literalmente y no se eliminará.

Las opciones en archivo están separadas por espacios en blanco. Un carácter de espacio en blanco puede incluirse en una opción rodeando la opción completa con comillas simples o dobles. Cualquier carácter (incluido una barra invertida) puede incluirse anteponiendo el carácter a incluir con una barra invertida. El archivo puede contener opciones adicionales @archivo; tales opciones se procesarán recursivamente.

nds32le-elf-size(1)

nds32le-elf-size es un programa que muestra el tamaño de las secciones de los archivos objeto.

DESCRIPCIÓN

nds32le-elf-size es una utilidad que se utiliza para mostrar el tamaño de las secciones de los archivos objeto especificados. Los archivos objeto pueden ser archivos ejecutables, bibliotecas compartidas, archivos objeto de compilación previa, etc. El tamaño de cada sección se imprime en bytes.

La salida de nds32le-elf-size se utiliza a menudo para determinar la cantidad de espacio que utilizan las diferentes partes de un programa. Esto puede ser útil para optimizar el tamaño del código y de los datos, así como para depurar problemas relacionados con el tamaño de los archivos.

OPCIONES

nds32le-elf-size acepta las siguientes opciones:

  • -h, --help: Muestra un mensaje de ayuda y sale.
  • -V, --version: Muestra información sobre la versión y sale.
  • -A, --print-file-names: Imprime los nombres de los archivos objeto antes de sus secciones.
  • -B, --format=formato: Imprime las secciones en el formato especificado. Los formatos admitidos son berkeley y sysv.
  • -t, --totals: Imprime un total para cada archivo objeto.
  • -o, --option=opción: Especifica una opción adicional para el procesamiento.

Para más detalles sobre las opciones, consulta la página del manual de size.

VER TAMBIÉN

nm(1), objdump(1), readelf(1)
