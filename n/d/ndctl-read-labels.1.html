NOMBRE

ndctl-read-labels - leer el área de etiquetas de un dimm o un conjunto de dimms

SINOPSIS

ndctl read-labels <nmem0> [<nmem1>..<nmemN>] [<opciones>]

DESCRIPCIÓN

El área de etiquetas del namespace es una pequeña partición persistente de capacidad disponible en algunos dispositivos NVDIMM. El área de etiquetas se utiliza para aprovisionar uno o más namespaces a partir de regiones. Este comando vuelca los datos binarios crudos del área de etiquetas de un dimm a stdout o a un archivo. En el caso de múltiples dimms, los datos se concatenan.

OPCIONES

<dispositivo(s) de memoria>

Un nombre de dispositivo nmemX, o un número de ID de dimm. Restringe la operación a los dimm especificados. La palabra clave all puede especificarse para indicar la falta de cualquier restricción, sin embargo, esto es lo mismo que no proporcionar una opción --dimm.

-s, --size=

Limita la operación al número de bytes dado. Un tamaño de 0 indica operar sobre toda la capacidad de la etiqueta.

-O, --offset=

Inicia la operación en el desplazamiento dado dentro del área de etiquetas.

-b, --bus=

Un número de ID de bus, o una cadena de proveedor (por ejemplo, "ACPI.NFIT"). Restringe la operación a los buses especificados. La palabra clave all puede especificarse para indicar la falta de cualquier restricción, sin embargo, esto es lo mismo que no proporcionar una opción --bus.

-v

Activa los mensajes de depuración detallados en la biblioteca (si ndctl fue compilado con registro y depuración habilitados).

-I, --index

Limita el alcance de la operación de etiquetas solo al área del bloque de índice. Esto es útil para determinar si el área de etiquetas del dimm está inicializada. Tenga en cuenta que esta opción y --size/--offset son mutuamente excluyentes.

-o, --output

archivo de salida

-j, --json

analiza los datos de la etiqueta en json asumiendo el formato de la Especificación del Namespace NVDIMM.

-u, --human

habilita la salida json y convierte los formatos numéricos a cadenas legibles por humanos, por ejemplo, muestra el tamaño en términos de "KB", "MB", "GB", etc. en lugar de números enteros con signo de 64 bits según el formato de intercambio JSON (implica --json).
