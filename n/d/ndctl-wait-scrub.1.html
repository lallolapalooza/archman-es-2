NDCTL-WAIT-SCRUB(1) Manual de ndctl NDCTL-WAIT-SCRUB(1)

NOMBRE

ndctl-wait-scrub - espera a que se complete una operación de Fregado de Rango de Direcciones (ARS)

SINOPSIS

ndctl wait-scrub [<id-bus> <id-bus2> ... <id-busN>] [<opciones>]

DESCRIPCIÓN

El Fregado de Rango de Direcciones (ARS) de NVDIMM es una capacidad proporcionada por el firmware de la plataforma que permite al software del sistema descubrir errores de memoria. Permite que el software del sistema evite de forma preventiva los accesos que podrían conducir a eventos de manejo de errores de memoria no corregibles, y de lo contrario, permite enumerar los errores de memoria.

El kernel proporciona un archivo sysfs capaz de POLL(2) (scrub) para indicar el estado de ARS. El archivo scrub mantiene un recuento continuo de las ejecuciones de ARS que han tenido lugar. Mientras una ejecución actual está en progreso, se emite un carácter + junto con el recuento actual. La operación ndctl wait-scrub espera a que scrub, en todos los buses especificados, indique que no está en progreso al menos una vez.

EJEMPLO

Espera el fregado en todos los buses nvdimm del sistema. El informe de listado en formato json al final solo incluye los buses que admiten operaciones ARS.

# ndctl wait-scrub
[
  {
    "provider":"nfit_test.1",
    "dev":"ndbus3",
    "scrub_state":"idle"
  },
  {
    "provider":"nfit_test.0",
    "dev":"ndbus2",
    "scrub_state":"idle"
  }
]

Al especificar un bus individual, o si solo hay un bus en el sistema, el comando informa si el soporte ARS está disponible.

# ndctl wait-scrub e820
error waiting for scrub completion: Operation not supported

OPCIONES

-v, --verbose

Emite mensajes de depuración para el proceso de espera de ARS
