NDCTL-READ-INFOBLOCK(1) Manual de ndctl NDCTL-READ-INFOBLOCK(1)

NOMBRE

ndctl-read-infoblock - lee y opcionalmente analiza el bloque de información de un espacio de nombres

SINOPSIS

ndctl read-infoblock <namespace0.0> [<namespace1.0>..<namespaceN.Y>] [<opciones>]

DESCRIPCIÓN

Como se describe en la sección de teoría de operación de ndctl-create-namespace(1), la capacidad bruta de un espacio de nombres puede encapsular una personalidad, o modo de operación. Específicamente, el modo puede establecerse en uno de "sector", "fsdax" y "devdax". Cada uno de esos modos está definido por un formato de bloque de información que identifica únicamente el modo de operación. El comando read-infoblock conoce la ubicación (relativa al inicio del espacio de nombres) y la definición de campos de esas estructuras de datos.

Tenga en cuenta que a diferencia de una tabla de particiones, el bloque de información no se expone por defecto, por lo que el espacio de nombres debe deshabilitarse antes de que se pueda acceder al bloque de información.

EJEMPLO

ndctl disable-namespace namespace0.0
disabled 1 namespace
ndctl read-infoblock -j namespace0.0
[
  {
    "dev":"namespace0.0",
    "signature":"NVDIMM_PFN_INFO",
    "uuid":"56b11990-66b1-4d91-9cac-ca084c051259",
    "parent_uuid":"00000000-0000-0000-0000-000000000000",
    "flags":0,
    "version":"1.3",
    "dataoff":69206016,
    "npfns":1031680,
    "mode":2,
    "start_pad":0,
    "end_trunc":0,
    "align":2097152
  }
]

OPCIONES

<espacio(s) de nombres>

Uno o más nombres de dispositivo namespaceX.Y. La palabra clave all se puede especificar para operar en cada espacio de nombres del sistema, opcionalmente filtrado por ID de bus (ver opción --bus=), o ID de región (ver opción --region=).

-V, --verify

Intenta validar que el bloque de información es autoconsistente validando la suma de verificación incrustada, y que los formatos de bloque de información que contienen un atributo parent-uuid también coinciden con el uuid base del espacio de nombres.

-o, --output

Archivo de salida

-j, --json

Analiza los datos del bloque de información en json.

-u, --human

Habilita la salida json y convierte los formatos numéricos en cadenas legibles por humanos, por ejemplo, muestra el tamaño en términos de "KB", "MB", "GB", etc. en lugar de números con signo de 64 bits según el formato de intercambio JSON (implica --json).

-r, --region=

Un nombre de dispositivo regionX, o un número de identificación de región. Restringe la operación a la(s) región(es) especificada(s). La palabra clave all se puede especificar para indicar la falta de restricción, sin embargo, esto es lo mismo que no suministrar la opción --region en absoluto.
