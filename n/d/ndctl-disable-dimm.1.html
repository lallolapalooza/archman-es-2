NDCTL-DISABLE-DIMM(1) Manual de ndctl NDCTL-DISABLE-DIMM(1)

NOMBRE

ndctl-disable-dimm - desactiva uno o varios DIMMs inactivos

SINOPSIS

ndctl disable-dimm <dimm> [<opciones>]

DESCRIPCIÓN

Se registra un objeto genérico de dispositivo DIMM, llamado /dev/nmemX, por cada dispositivo de memoria indicado en la tabla ACPI NFIT u otro mecanismo de descubrimiento de recursos NVDIMM de la plataforma. El núcleo LIBNVDIMM proporciona un controlador integrado para estos dispositivos DIMM. El controlador es responsable de determinar si el DIMM implementa un área de etiqueta de espacio de nombres e inicializar la copia en memoria del núcleo de esos datos de etiqueta.

El núcleo realiza modificaciones en tiempo de ejecución de esos datos cuando se toman acciones de aprovisionamiento de espacio de nombres y bloquea activamente el espacio de usuario para que no inicie cambios de datos de etiqueta mientras el DIMM está activo en cualquier región. Desactivar un DIMM, después de que todas las regiones de las que es miembro hayan sido desactivadas, permite al espacio de usuario actualizar manualmente los datos de etiqueta para que se consuman cuando el DIMM se active la próxima vez.

OPCIONES

<dimm>

Un nombre de dispositivo nmemX, o un número de ID de dimm. Restringe la operación a los dimm especificados. La palabra clave all puede especificarse para indicar la ausencia de cualquier restricción; sin embargo, esto es lo mismo que no proporcionar ninguna opción --dimm.

-b, --bus=

Un número de ID de bus, o una cadena de proveedor (por ejemplo, "ACPI.NFIT"). Restringe la operación a los buses especificados. La palabra clave all puede especificarse para indicar la ausencia de cualquier restricción; sin embargo, esto es lo mismo que no proporcionar ninguna opción --bus.
