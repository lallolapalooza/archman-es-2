NOMBRE

ndctl-init-labels - inicializa el área de etiquetas del namespace en un DIMM o conjunto de DIMMs

SINOPSIS

ndctl init-labels <nmem0> [<nmem1>..<nmemN>] [<opciones>]

DESCRIPCIÓN

El área de etiquetas del namespace es una pequeña partición persistente de capacidad disponible en algunos dispositivos NVDIMM. El área de etiquetas se utiliza para aprovisionar uno o más namespaces a partir de regiones. A partir de la v4.10, el kernel respetará las etiquetas para subdividir la PMEM si todos los DIMMs en un conjunto de interleaving / región tienen un bloque de índice de namespace válido.

Este comando se puede utilizar para inicializar el bloque de índice de namespace si está ausente o reinicializarlo si está dañado. Tenga en cuenta que la reinicialización destruye efectivamente todas las etiquetas de namespace existentes en el DIMM.

EJEMPLO

Encontrar los DIMMs que componen una región dada:

# ndctl list -RD --region=region1
{
  "dimms":[
    {
      "dev":"nmem0",
      "id":"8680-56341200"
    }
  ],
  "regions":[
    {
      "dev":"region1",
      "size":268435456,
      "available_size":0,
      "type":"pmem",
      "mappings":[
        {
          "dimm":"nmem0",
          "offset":13958643712,
          "length":268435456
        }
      ]
    }
  ]
}

Deshabilitar esa región para que el área de etiquetas del DIMM pueda ser escrita desde el espacio de usuario:

# ndctl disable-region region1

Inicializar etiquetas:

# ndctl init-labels nmem0

Rehabilitar la región:

# ndctl enable-region region1

Crear un namespace en esa región:

# ndctl create-namespace --region=region1

OPCIONES

<dispositivo(s) de memoria>

Un nombre de dispositivo nmemX, o un número de ID de dimm. Restringe la operación a los dimms especificados. La palabra clave all puede ser especificada para indicar la falta de cualquier restricción, sin embargo esto es lo mismo que no suministrar una opción --dimm.

-s, --size=

Limita la operación al número dado de bytes. Un tamaño de 0 indica operar sobre la capacidad total de etiquetas.

-O, --offset=

Comienza la operación en el desplazamiento dado dentro del área de etiquetas.

-b, --bus=

Un número de ID de bus, o una cadena de proveedor (por ejemplo, "ACPI.NFIT"). Restringe la operación a los bus especificados. La palabra clave all puede ser especificada para indicar la falta de cualquier restricción, sin embargo esto es lo mismo que no suministrar una opción --bus.

-v

Activa los mensajes de depuración detallados en la biblioteca (si ndctl fue compilado con registro y depuración habilitados).

-f, --force

Fuerza la inicialización del espacio de etiquetas incluso si parece haber un índice de namespace existente / válido. Advertencia, esto destruirá todos los namespaces definidos en el dimm.

-V, --label-version

Inicializa con una versión específica de etiquetas de la especificación de etiquetas de namespace. Por defecto es 1.1
