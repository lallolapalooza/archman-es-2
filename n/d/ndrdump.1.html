NDRDUMP(1) Herramientas de administración del sistema NDRDUMP(1)

NOMBRE

ndrdump - Analizador y volcado de paquetes DCE/RPC

SINOPSIS

ndrdump [-c contexto] {tubería} {formato} {entrada|salida|estructura} {nombre_archivo}

ndrdump [tubería]

ndrdump

DESCRIPCIÓN

ndrdump intenta analizar el nombre_archivo especificado utilizando el analizador de Samba para la tubería y el formato especificados. El tercer argumento debe ser entrada, salida o estructura, dependiendo de si los datos deben analizarse como una solicitud, una respuesta o una estructura pública.

Ejecutar ndrdump sin argumentos listará las tuberías para las que hay analizadores disponibles.

Ejecutar ndrdump con un argumento listará las funciones y las estructuras públicas que Samba puede analizar para la tubería especificada.

La función principal de ndrdump es depurar las funciones internas de análisis DCE/RPC de Samba. El archivo que se analiza suele ser uno exportado por la función "Exportar bytes de paquete seleccionados" de Wireshark.

El argumento de contexto se puede utilizar para cargar datos de contexto del paquete de solicitud al analizar paquetes de respuesta (como longitudes de arreglos).
