NOMBRE

strip - descarta símbolos y otros datos de los archivos objeto

SINOPSIS

strip [-F bfdname |--target=bfdname]
[-I bfdname |--input-target=bfdname]
[-O bfdname |--output-target=bfdname]
[-s|--strip-all]
[-S|-g|-d|--strip-debug]
[--strip-dwo]
[-K nombre-simbolo|--keep-symbol=nombre-simbolo]
[-M|--merge-notes][--no-merge-notes]
[-N nombre-simbolo |--strip-symbol=nombre-simbolo]
[-w|--wildcard]
[-x|--discard-all] [-X |--discard-locals]
[-R nombre-seccion |--remove-section=nombre-seccion]
[--keep-section=patron-seccion]
[--remove-relocations=patron-seccion]
[--strip-section-headers]
[-o archivo] [-p|--preserve-dates]
[-D|--enable-deterministic-archives]
[-U|--disable-deterministic-archives]
[--keep-section-symbols]
[--keep-file-symbols]
[--only-keep-debug]
[-v |--verbose] [-V|--version]
[--help] [--info]
archivo-objeto...

DESCRIPCIÓN

GNU strip descarta todos los símbolos de los archivos objeto archivo-objeto. La lista de archivos objeto puede incluir archivos. Se debe proporcionar al menos un archivo objeto.

strip modifica los archivos nombrados en sus argumentos, en lugar de escribir copias modificadas bajo nombres diferentes.

OPCIONES

-F bfdname
--target=bfdname
Trata el archivo-objeto original como un archivo con el formato de código objeto bfdname, y lo reescribe en el mismo formato.
--help
Muestra un resumen de las opciones de strip y sale.
--info
Muestra una lista que indica todas las arquitecturas y formatos de objeto disponibles.
-I bfdname
--input-target=bfdname
Trata el archivo-objeto original como un archivo con el formato de código objeto bfdname.
-O bfdname
--output-target=bfdname
Reemplaza archivo-objeto con un archivo en el formato de salida bfdname.
-R nombre-seccion
--remove-section=nombre-seccion
Elimina cualquier sección llamada nombre-seccion del archivo de salida, además de las secciones que de otra manera serían eliminadas. Esta opción se puede dar varias veces. Nota: usar esta opción de forma inapropiada puede hacer que el archivo de salida sea inutilizable. El carácter comodín * puede darse al final de nombre-seccion. Si es así, se eliminará cualquier sección que comience con nombre-seccion.

Si el primer carácter de patron-seccion es el signo de exclamación (!), las secciones coincidentes no se eliminarán aunque un uso anterior de --remove-section en la misma línea de comandos las eliminaría de otra manera. Por ejemplo:

--remove-section=.text.* --remove-section=!.text.foo

eliminará todas las secciones que coincidan con el patrón '.text.*', pero no eliminará la sección '.text.foo'.

--keep-section=patron-seccion
Al eliminar secciones del archivo de salida, conserva las secciones que coinciden con patron-seccion.
--remove-relocations=patron-seccion
Elimina las reubicaciones del archivo de salida para cualquier sección que coincida con patron-seccion. Esta opción se puede dar varias veces. Nota: usar esta opción de forma inapropiada puede hacer que el archivo de salida sea inutilizable. Se aceptan caracteres comodín en patron-seccion. Por ejemplo: 
--remove-relocations=.text.*

eliminará las reubicaciones para todas las secciones que coincidan con el patrón '.text.*'.

Si el primer carácter de patron-seccion es el signo de exclamación (!), las reubicaciones de las secciones coincidentes no se eliminarán aunque un uso anterior de --remove-relocations en la misma línea de comandos causaría que las reubicaciones se eliminaran de otra manera. Por ejemplo:

--remove-relocations=.text.* --remove-relocations=!.text.foo

eliminará todas las reubicaciones para las secciones que coincidan con el patrón '.text.*', pero no eliminará las reubicaciones para la sección '.text.foo'.

--strip-section-headers
Descarta las cabeceras de sección. Esta opción es específica de los archivos ELF. Implica --strip-all y --merge-notes.
-s
--strip-all
Elimina todos los símbolos.
-g
-S
-d
--strip-debug
Elimina solo los símbolos de depuración.
--strip-dwo
Elimina el contenido de todas las secciones DWARF .dwo, dejando intactas las secciones de depuración restantes y todos los símbolos. Consulte la descripción de esta opción en la sección objcopy para obtener más información.
--strip-unneeded
Elimina todos los símbolos que no son necesarios para el procesamiento de reubicaciones, además de los símbolos y secciones de depuración eliminados por --strip-debug.
-K nombre-simbolo
--keep-symbol=nombre-simbolo
Al eliminar símbolos, conserva el símbolo nombre-simbolo aunque normalmente sería eliminado. Esta opción se puede dar varias veces.
-M
--merge-notes
--no-merge-notes
Para archivos ELF, intenta (o no intenta) reducir el tamaño de las secciones de tipo SHT_NOTE eliminando notas duplicadas. Por defecto, se intenta esta reducción a menos que se elimine información de depuración o DWO.
-N nombre-simbolo
--strip-symbol=nombre-simbolo
Elimina el símbolo nombre-simbolo del archivo de origen. Esta opción se puede dar varias veces y se puede combinar con otras opciones de strip, excepto con -K.
-o archivo
Coloca la salida eliminada en archivo, en lugar de reemplazar el archivo existente. Cuando se usa este argumento, solo se puede especificar un argumento archivo-objeto.
-p
--preserve-dates
Conserva las fechas de acceso y modificación del archivo.
-D
--enable-deterministic-archives
Opera en modo determinista. Al copiar miembros de archivos y escribir el índice del archivo, usa cero para UID, GID, marcas de tiempo, y usa modos de archivo consistentes para todos los archivos.

Si binutils se configuró con --enable-deterministic-archives, entonces este modo está activado por defecto. Se puede desactivar con la opción -U, abajo.

-U
--disable-deterministic-archives
No opera en modo determinista. Esto

OPTIONS

-D
Esta es la inversa de la opción -U, anterior: al copiar miembros de archivo y escribir el índice de archivo, utiliza sus valores reales de UID, GID, marca de tiempo y modo de archivo.
-U
Esta es la inversa de la opción -D, anterior: al copiar miembros de archivo y escribir el índice de archivo, utiliza sus valores reales de UID, GID, marca de tiempo y modo de archivo.
-w
--wildcard
Permite expresiones regulares en los symbolname utilizados en otras opciones de línea de comandos. Los operadores de signo de interrogación (?), asterisco (*), barra invertida (\) y corchetes ([]) se pueden usar en cualquier parte del nombre del símbolo. Si el primer carácter del nombre del símbolo es el signo de exclamación (!), entonces el sentido del interruptor se invierte para ese símbolo. Por ejemplo: 
-w -K !foo -K fo*
hará que strip solo conserve los símbolos que comienzan con las letras "fo", pero que descarte el símbolo "foo".
-x
--discard-all
Elimina los símbolos no globales.
-X
--discard-locals
Elimina los símbolos locales generados por el compilador (Estos suelen comenzar con L o .).
--keep-section-symbols
Al eliminar un archivo, quizás con --strip-debug o --strip-unneeded, conserva cualquier símbolo que especifique nombres de sección, que de otro modo se eliminarían.
--keep-file-symbols
Al eliminar un archivo, quizás con --strip-debug o --strip-unneeded, conserva cualquier símbolo que especifique nombres de archivos fuente, que de otro modo se eliminarían.
--only-keep-debug
Elimina un archivo, vaciando el contenido de cualquier sección que no sería eliminada por --strip-debug y dejando intactas las secciones de depuración. En archivos ELF, esto también conserva todas las secciones de notas en la salida.

Nota: Las cabeceras de sección de las secciones eliminadas se conservan, incluyendo sus tamaños, pero el contenido de la sección se descarta. Las cabeceras de sección se conservan para que otras herramientas puedan emparejar el archivo de información de depuración con el ejecutable real, incluso si ese ejecutable ha sido reubicado a un espacio de direcciones diferente.

La intención es que esta opción se utilice junto con --add-gnu-debuglink para crear un ejecutable de dos partes. Uno un binario eliminado que ocupará menos espacio en RAM y en una distribución, y el segundo un archivo de información de depuración que solo se necesitará si se requieren capacidades de depuración. El procedimiento sugerido para crear estos archivos es el siguiente:

1.<Enlace el ejecutable como de costumbre. Suponiendo que se llama>
"foo" entonces...
1.<Ejecute "objcopy --only-keep-debug foo foo.dbg" para>
crear un archivo que contenga la información de depuración.
1.<Ejecute "objcopy --strip-debug foo" para crear un>
ejecutable eliminado.
1.<Ejecute "objcopy --add-gnu-debuglink=foo.dbg foo">
para agregar un enlace a la información de depuración en el ejecutable eliminado.

Nota: la elección de ".dbg" como extensión para el archivo de información de depuración es arbitraria. Además, el paso "--only-keep-debug" es opcional. También puede hacer esto:

1.<Enlace el ejecutable como de costumbre.>
1.<Copie "foo" a "foo.full">
1.<Ejecute "strip --strip-debug foo">
1.<Ejecute "objcopy --add-gnu-debuglink=foo.full foo">

es decir, el archivo al que apunta --add-gnu-debuglink puede ser el ejecutable completo. No tiene que ser un archivo creado por el interruptor --only-keep-debug.

Nota: este interruptor solo está diseñado para usarse en archivos completamente enlazados. No tiene sentido usarlo en archivos objeto donde la información de depuración puede ser incompleta. Además, la característica gnu_debuglink actualmente solo admite la presencia de un nombre de archivo que contenga información de depuración, no múltiples nombres de archivo en base de uno por archivo objeto.

-V
--version
Muestra el número de versión de strip.
-v
--verbose
Salida detallada: lista todos los archivos objeto modificados. En el caso de los archivos, strip -v lista todos los miembros del archivo.
@file
Lee las opciones de línea de comandos de file. Las opciones leídas se insertan en lugar de la opción original @file. Si file no existe, o no se puede leer, entonces la opción se tratará literalmente y no se eliminará.

Las opciones en file están separadas por espacios en blanco. Se puede incluir un carácter de espacio en blanco en una opción rodeando toda la opción entre comillas simples o dobles. Se puede incluir cualquier carácter (incluyendo una barra invertida) anteponiendo a ese carácter la barra invertida. El file puede contener a su vez opciones adicionales de @file; dichas opciones se procesarán recursivamente.
