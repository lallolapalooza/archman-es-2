NOMBRE

ndctl-write-labels - escribir datos en el área de etiqueta de un dimm

SINOPSIS

ndctl write-labels <nmem> [-i <archivo>]

DESCRIPCIÓN

El área de etiqueta del namespace es una pequeña partición persistente de capacidad disponible en algunos dispositivos NVDIMM. El área de etiqueta se utiliza para aprovisionar uno o más namespaces a partir de regiones. Lee datos del archivo de entrada o de stdin y los escribe en el dispositivo <nmem> especificado. Tenga en cuenta que el dispositivo no debe estar activo en ninguna región, de lo contrario, el kernel no permitirá el acceso de escritura al área de datos de etiqueta del dispositivo.

OPCIONES

<dispositivo(s) de memoria>

Un nombre de dispositivo nmemX o un número de ID de dimm. Restringe la operación a los dimm especificados. La palabra clave all puede especificarse para indicar la ausencia de restricciones, sin embargo, esto es lo mismo que no proporcionar ninguna opción --dimm.

-s, --size=

Limita la operación al número de bytes dado. Un tamaño de 0 indica que se opere sobre la capacidad total de la etiqueta.

-O, --offset=

Inicia la operación en el desplazamiento dado dentro del área de etiqueta.

-b, --bus=

Un número de ID de bus o una cadena de proveedor (por ejemplo, "ACPI.NFIT"). Restringe la operación a los bus especificados. La palabra clave all puede especificarse para indicar la ausencia de restricciones, sin embargo, esto es lo mismo que no proporcionar ninguna opción --bus.

-v

Activa los mensajes de depuración detallados en la biblioteca (si ndctl se compiló con registro y depuración habilitados).

-i, --input

archivo de entrada

VER TAMBIÉN

UEFI NVDIMM Label Protocol http://www.uefi.org/sites/default/files/resources/UEFI_Spec_2_7.pdf
