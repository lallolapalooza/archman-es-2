NOMBRE

ndctl-check-labels - determinar si los dimms dados tienen un bloque de índice de namespace válido

SINOPSIS

ndctl check-labels <nmem0> [<nmem1>..<nmemN>] [<opciones>]

DESCRIPCIÓN

El área de etiqueta del namespace es una pequeña partición persistente de capacidad disponible en algunos dispositivos NVDIMM. El área de etiqueta se utiliza para aprovisionar uno o más namespaces desde regiones. Además de verificar si un área de etiqueta tiene un bloque de índice válido, la ejecución de este comando en modo detallado informa la razón por la cual el bloque de índice se considera inválido.

OPCIONES

<dispositivo(s) de memoria>

Un nombre de dispositivo nmemX, o un número de ID de dimm. Restringe la operación a los dimm especificados. La palabra clave all puede especificarse para indicar la ausencia de cualquier restricción; sin embargo, esto es lo mismo que no proporcionar ninguna opción --dimm.

-s, --size=

Limita la operación al número de bytes dado. Un tamaño de 0 indica que se opere sobre toda la capacidad de etiqueta.

-O, --offset=

Inicia la operación en el desplazamiento dado dentro del área de etiqueta.

-b, --bus=

Un número de ID de bus, o una cadena de proveedor (por ejemplo, "ACPI.NFIT"). Restringe la operación a los buses especificados. La palabra clave all puede especificarse para indicar la ausencia de cualquier restricción; sin embargo, esto es lo mismo que no proporcionar ninguna opción --bus.

-v

Activa mensajes de depuración detallados en la biblioteca (si ndctl se compiló con registro y depuración habilitados).
