NOMBRE

ndctl-zero-labels - pone a cero el área de etiquetas en un dimm o conjunto de dimms

SINOPSIS

ndctl zero-labels <nmem0> [<nmem1>..<nmemN>] [<opciones>]

DESCRIPCIÓN

El área de etiquetas de namespace es una pequeña partición persistente de capacidad disponible en algunos dispositivos NVDIMM. El área de etiquetas se utiliza para aprovisionar uno o más namespaces a partir de regiones. Este comando restablece el dispositivo a su estado predeterminado eliminando todas las etiquetas.

OPCIONES

<dispositivo(s) de memoria>

Un nombre de dispositivo nmemX, o un número de ID de dimm. Restringe la operación a los dimms especificados. La palabra clave all se puede especificar para indicar la ausencia de cualquier restricción, sin embargo, esto es lo mismo que no proporcionar una opción --dimm.

-s, --size=

Limita la operación al número de bytes dado. Un tamaño de 0 indica operar sobre toda la capacidad de la etiqueta.

-O, --offset=

Inicia la operación en el desplazamiento dado dentro del área de etiquetas.

-b, --bus=

Un número de ID de bus, o una cadena de proveedor (por ejemplo, "ACPI.NFIT"). Restringe la operación a los buses especificados. La palabra clave all se puede especificar para indicar la ausencia de cualquier restricción, sin embargo, esto es lo mismo que no proporcionar una opción --bus.

-v

Activa los mensajes de depuración detallados en la biblioteca (si ndctl fue compilado con registro y depuración habilitados).
