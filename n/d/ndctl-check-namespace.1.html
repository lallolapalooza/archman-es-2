NOMBRE

ndctl-check-namespace - verifica la consistencia de los metadatos del namespace

SINOPSIS

ndctl check-namespace <namespace> [<opciones>]

DESCRIPCIÓN

Un namespace en modo sector tendrá metadatos sobre él para describir la Tabla de Traducción de Bloques (BTT) del kernel. El comando check-namespace se puede usar para verificar la consistencia de estos metadatos y, opcionalmente, también intentar repararlos si tiene suficiente información para hacerlo.

El namespace que se está verificando debe estar deshabilitado antes de iniciar una verificación en él como medida de precaución. La opción --force puede anular esto.

EJEMPLOS

Verificar un namespace (solo informar errores)

ndctl disable-namespace namespace0.0
ndctl check-namespace namespace0.0

Verificar un namespace y realizar reparaciones si es posible

ndctl disable-namespace namespace0.0
ndctl check-namespace --repair namespace0.0

OPCIONES

-R, --repair

Realiza reparaciones de metadatos si es posible. Sin esta opción, el contenido bruto del namespace no se modificará.

-L, --rewrite-log

Regenera el registro BTT y lo escribe en el medio. Esto se puede usar para convertir del formato de relleno antiguo (anterior a 4.15), que era incompatible con otras implementaciones de BTT, al formato actualizado. Esto requiere que se proporcione la opción --repair. 
ADVERTENCIA: No interrumpa esta operación ya que puede causar una corrupción de metadatos irrecuperable. Se recomienda encarecidamente crear una copia de seguridad del namespace bruto antes de intentar esto.

-f, --force

A menos que se especifique esta opción, una operación de check-namespace fallará si el namespace está actualmente activo. Especificar --force hace que el namespace se deshabilite antes de la verificación.

-v, --verbose

Emite mensajes de depuración para el proceso de verificación del namespace.

-r, --region=

Un nombre de dispositivo regionX, o un número de ID de región. Restringe la operación a la(s) región(es) especificada(s). La palabra clave all se puede especificar para indicar la ausencia de cualquier restricción, sin embargo, esto es lo mismo que no proporcionar la opción --region en absoluto.

-b, --bus=

Un número de ID de bus, o una cadena de proveedor (por ejemplo, "ACPI.NFIT"). Restringe la operación al(los) bus(es) especificado(s). La palabra clave all se puede especificar para indicar la ausencia de cualquier restricción, sin embargo, esto es lo mismo que no proporcionar la opción --bus en absoluto.
