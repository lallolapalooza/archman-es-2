NOMBRE

ndctl-monitor - Monitorea los eventos inteligentes de los objetos nvdimm

SINOPSIS

ndctl monitor [<opciones>]

DESCRIPCIÓN

Ndctl monitor se utiliza para monitorear los eventos inteligentes de los objetos nvdimm y volcar las notificaciones en formato json a syslog, salida estándar o un archivo de registro.

Los objetos a monitorear y los eventos inteligentes a notificar se pueden seleccionar configurando opciones y/o archivos de configuración con sufijo .conf en /etc/ndctl.conf.d

Tanto los valores en el archivo de configuración como en las opciones funcionarán. Si hay un conflicto, los valores en las opciones anularán los valores en el archivo de configuración. Cualquier valor actualizado en el archivo de configuración surtirá efecto solo después de reiniciar el proceso de monitor.

EJEMPLOS

Ejecutar un monitor como un demonio para monitorear DIMMs en el bus "nfit_test.1"

ndctl monitor --bus=nfit_test.1 --daemon

Ejecutar un monitor como un comando de un solo disparo y volcar las notificaciones a /var/log/ndctl.log

ndctl monitor --log=/var/log/ndctl.log

Ejecutar un demonio de monitor como un servicio del sistema

systemctl start ndctl-monitor.service

OPCIONES

-b, --bus=

Un número de ID de bus o una cadena de proveedor (por ejemplo, "ACPI.NFIT"). Restringe la operación al(los) bus(es) especificado(s). La palabra clave all puede especificarse para indicar la ausencia de cualquier restricción, sin embargo, esto es lo mismo que no proporcionar la opción --bus.

-d, --dimm=

Un nombre de dispositivo nmemX o un número de ID de dimm. Restringe la operación al(los) dimm(s) especificado(s). La palabra clave all puede especificarse para indicar la ausencia de cualquier restricción, sin embargo, esto es lo mismo que no proporcionar la opción --dimm.

-r, --region=

Un nombre de dispositivo regionX o un número de ID de región. Restringe la operación a la(s) región(es) especificada(s). La palabra clave all puede especificarse para indicar la ausencia de cualquier restricción, sin embargo, esto es lo mismo que no proporcionar la opción --region.

-n, --namespace=

Un nombre de dispositivo namespaceX.Y o una tupla de región de espacio de nombres más ID X.Y.

-l, --log=

Envía mensajes de registro al destino especificado.
•"<archivo>": Envía mensajes de registro al <archivo> especificado. Cuando fopen() no puede abrir <archivo>, los mensajes de registro se reenviarán a syslog.
•"syslog": Envía mensajes a syslog.
•"standard": Envía mensajes a la salida estándar.

El destino de registro predeterminado es syslog si se especifica "--daemon", de lo contrario es standard. Tenga en cuenta que la salida estándar y la ruta relativa para <archivo> no funcionarán si se especifica "--daemon".

-c, --config-file=

Proporciona los archivos de configuración a utilizar. Esto anula la configuración predeterminada que generalmente se encuentra en /etc/ndctl.conf.d

--daemon

Ejecuta un monitor como un demonio.

-D, --dimm-event=

Nombre de un evento de salud inteligente de los siguientes:
•"dimm-spares-remaining": El valor de Bloques de Repuesto Restantes ha caído por debajo del umbral preprogramado.
•"dimm-media-temperature": El valor de Temperatura de Medios NVDIMM ha superado el umbral preprogramado.
•"dimm-controller-temperature": El valor de Temperatura del Controlador NVDIMM ha superado el umbral preprogramado.
•"dimm-health-state": El Estado de Salud Normal NVDIMM ha cambiado
•"dimm-unclean-shutdown": El Estado de Último Apagado NVDIMM fue un apagado incompleto.

El monitor intentará habilitar los bits de control de alarma para todos los eventos especificados.

-p, --poll=

Encuesta e informa el estado/evento cada <n> segundos.

-u, --human

Muestra la notificación del monitor en formato json amigable para humanos en lugar del formato json predeterminado amigable para máquinas.

-v, --verbose

Emite mensajes de depuración adicionales al registro.
