RANLIB(1) Herramientas de desarrollo GNU RANLIB(1)

NOMBRE

ranlib - genera un índice para un archivo

SINOPSIS

ranlib [--plugin nombre] [-DhHvVt] archivo

DESCRIPCIÓN

ranlib genera un índice del contenido de un archivo y lo almacena en el archivo. El índice enumera cada símbolo definido por un miembro de un archivo que sea un archivo objeto relocable.

Puede usar nm -s o nm --print-armap para listar este índice.

Un archivo con dicho índice acelera la vinculación a la biblioteca y permite que las rutinas de la biblioteca se llamen entre sí sin importar su ubicación en el archivo.

El programa ranlib de GNU es otra forma de ar de GNU; ejecutar ranlib es completamente equivalente a ejecutar ar -s.

OPCIONES

-h
-H
--help
Muestra información de uso para ranlib.
-v
-V
--version
Muestra el número de versión de ranlib.
-D
Opera en modo determinista. La cabecera del miembro del archivo mapa de símbolos mostrará cero para el UID, GID y la marca de tiempo. Cuando se usa esta opción, múltiples ejecuciones producirán archivos de salida idénticos.

Si binutils fue configurado con --enable-deterministic-archives, entonces este modo está activado por defecto. Se puede deshabilitar con la opción -U, descrita a continuación.

-t
Actualiza la marca de tiempo del mapa de símbolos de un archivo.
-U
No opere en modo determinista. Esta es la inversa de la opción -D, anterior: el índice del archivo obtendrá valores reales de UID, GID, marca de tiempo y modo de archivo.

Si binutils fue configurado *sin* --enable-deterministic-archives, entonces este modo está activado por defecto.

@archivo
Lee las opciones de la línea de comandos desde archivo. Las opciones leídas se insertan en lugar de la opción original @archivo. Si archivo no existe, o no se puede leer, entonces la opción se tratará literalmente y no se eliminará.

Las opciones en archivo están separadas por espacios en blanco. Un carácter de espacio en blanco puede incluirse en una opción rodeando toda la opción con comillas simples o dobles. Cualquier carácter (incluido una barra invertida) puede incluirse anteponiendo el carácter a incluir con una barra invertida. El archivo puede contener en sí mismo opciones adicionales @archivo; cualquier opción de este tipo se procesará recursivamente.

VER TAMBIÉN

ar(1), nm(1), y las entradas Info para binutils.
