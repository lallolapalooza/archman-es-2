NDISASM(1) El Proyecto Netwide Assembler NDISASM(1)

NOMBRE

ndisasm - el Netwide Disassembler, un desensamblador de archivos binarios 80x86

SINOPSIS

ndisasm [ -o origen ] [ -s punto_sincronizacion [...]] [ -a | -i ] [ -b bits ] [ -u ] [ -e len_encabezado ] [ -p vendor ] [ -k offset,longitud [...] ] archivo_entrada

DESCRIPCIÓN

El comando ndisasm genera una lista de desensamblado del archivo binario archivo_entrada y la dirige a la salida estándar (stdout).

OPCIONES

-h

Hace que ndisasm salga inmediatamente, después de mostrar un resumen de sus opciones de invocación.

-r|-v

Hace que ndisasm salga inmediatamente, después de mostrar su número de versión.

-o origen

Especifica la dirección de carga teórica del archivo. Esta opción hace que ndisasm obtenga las direcciones que lista en el margen izquierdo, y las direcciones de destino de los saltos y llamadas relativos al PC, correctamente.

-s punto_sincronizacion

Especifica manualmente una dirección de sincronización, de modo que ndisasm no genere ninguna instrucción de máquina que abarque bytes en ambos lados de la dirección. Por lo tanto, la instrucción que comienza en esa dirección se desensamblará correctamente.

-e len_encabezado

Especifica un número de bytes a descartar del principio del archivo antes de comenzar el desensamblado. Esto no cuenta para el cálculo del desplazamiento del desensamblado: la primera instrucción *desensamblada* se mostrará comenzando en la dirección de carga dada.

-k offset,longitud

Especifica que se deben omitir longitud bytes, comenzando desde el desplazamiento de desensamblado offset, sin generar ninguna salida. Los bytes omitidos aún cuentan para el cálculo del desplazamiento del desensamblado.

-a|-i

Habilita el modo de sincronización automática (o inteligente), en el que ndisasm intentará adivinar dónde se debe realizar la sincronización, examinando las direcciones de destino de los saltos y llamadas relativas que desensambla.

-b bits

Especifica el modo de 16, 32 o 64 bits. El valor predeterminado es el modo de 16 bits.

-u

Especifica el modo de 32 bits, de forma más compacta que usando '–b 32'.

-p vendor

Prefiere instrucciones según lo definido por vendor en caso de conflicto. Los nombres de vendor conocidos incluyen intel, amd, cyrix e idt. El valor predeterminado es intel.

RESTRICCIONES

ndisasm solo desensambla archivos binarios: no tiene conocimiento de la información de encabezado presente en archivos objeto o ejecutables. Si desea desensamblar un archivo objeto, probablemente debería usar objdump(1).

El modo de sincronización automática no curará necesariamente todos sus problemas de sincronización: solo se puede colocar un marcador de sincronización automáticamente si se encuentra una instrucción de salto o llamada que lo refiera *antes* de que ndisasm desensamble esa parte del código. Además, si se producen saltos o llamadas espurios como resultado del desensamblado de datos que no son código máquina, los marcadores de sincronización pueden colocarse en lugares extraños. Siéntase libre de desactivar la sincronización automática y volver a hacerlo manualmente si es necesario.
