nl_types.h(0p) Manual del Programador POSIX nl_types.h(0p)

PROLOG

Esta página del manual forma parte del Manual del Programador POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual de Linux correspondiente para obtener detalles sobre el comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

nl_types.h — tipos de datos

SINOPSIS

#include <nl_types.h>

DESCRIPCIÓN

El archivo de cabecera <nl_types.h> definirá al menos los siguientes tipos:

nl_catd
Utilizado por las funciones de catálogo de mensajes catopen(), catgets() y catclose() para identificar un descriptor de catálogo.
nl_item
Utilizado por nl_langinfo() para identificar elementos de datos langinfo. Los valores de los objetos de tipo nl_item se definen en <langinfo.h>.

El archivo de cabecera <nl_types.h> definirá al menos los siguientes constantes simbólicas:

NL_SETD
Utilizado por gencat cuando no se especifica ninguna directiva $set en un archivo fuente de texto de mensajes. Esta constante se puede pasar como el valor de set_id en llamadas posteriores a catgets() (es decir, para recuperar mensajes del conjunto de mensajes predeterminado). El valor de NL_SETD depende de la implementación.
NL_CAT_LOCALE
Valor que debe pasarse como argumento oflag a catopen() para garantizar que la selección del catálogo de mensajes dependa de la categoría de localización LC_MESSAGES, en lugar de depender directamente de la variable de entorno LANG.

Se declararán las siguientes funciones y también pueden definirse como macros. Se proporcionarán prototipos de función.

int       catclose(nl_catd);
char     *catgets(nl_catd, int, int, const char *);
nl_catd   catopen(const char *, int);
