nload(1) Herramientas de monitoreo de red nload(1)

NOMBRE

nload - muestra el uso actual de la red

SINOPSIS

nload [-a periodo] [-i escala_maxima] [-m] [-o escala_maxima] [-t intervalo] [-u h|H|b|B|k|K|m|M|g|G] [-U h|H|b|B|k|K|m|M|g|G] [dispositivos]

nload --help|-h

DESCRIPCIÓN

nload es una aplicación de consola que monitorea el tráfico de red y el uso de ancho de banda en tiempo real. Visualiza el tráfico entrante y saliente utilizando dos gráficos y proporciona información adicional como la cantidad total de datos transferidos y el uso de red mínimo/máximo.

USO

Al ejecutar nload, puedes cambiar entre los dispositivos (que le diste a nload en la línea de comandos o que fueron detectados automáticamente) presionando las teclas de flecha izquierda y derecha. Si se proporciona el parámetro de línea de comandos -m, las teclas de flecha cambian tantos dispositivos hacia adelante y atrás como haya mostrados en la pantalla. Si quieres salir, hazlo presionando 'q' o 'Ctrl+C'.

Para atajos de teclado adicionales, consulta las secciones VENTANA PRINCIPAL y VENTANA DE OPCIONES a continuación.

OPCIONES

A continuación se incluye un resumen de las opciones compatibles con nload.

-a periodo
Establece la duración en segundos de la ventana de tiempo para el cálculo del promedio. El valor predeterminado es 300.
-i escala_maxima
Especifica la marca del 100% en kBit/s del gráfico que indica el uso de ancho de banda entrante. Se ignora si escala_maxima es 0 o si se proporciona el interruptor -m. El valor predeterminado para escala_maxima es 10240.
-m
Muestra múltiples dispositivos a la vez; no muestra los gráficos de tráfico.
-o escala_maxima
Igual que -i pero para el gráfico que indica el uso de ancho de banda saliente.
-t intervalo
Determina el intervalo de actualización de la pantalla en milisegundos. El valor predeterminado de intervalo es 500.

TENGA EN CUENTA: Especificar intervalos de actualización más cortos que aproximadamente 100 milisegundos hace que el cálculo del tráfico sea muy impreciso. La pantalla también puede parpadear usando intervalos de actualización tan cortos. nload intenta compensar esto realizando mediciones de tiempo adicionales, pero esto puede no tener éxito siempre.

-u h|H|b|B|k|K|m|M|g|G
Establece el tipo de unidad utilizado para la visualización de los números de tráfico. h significa legible por humanos (automático), b Bit/s, k kBit/s, m MBit/s y g GBit/s. Las letras mayúsculas significan las unidades correspondientes en Bytes (en lugar de Bits). El valor predeterminado es k.
-U h|H|b|B|k|K|m|M|g|G
Igual que -u, pero para una cantidad de datos, por ejemplo, Bit, kByte, GBit, etc. (sin "/s"). El valor predeterminado es M.
dispositivos
Dispositivos de red a utilizar. El valor predeterminado es "all", lo que significa mostrar todos los dispositivos detectados automáticamente.
-h, --help
Muestra un breve resumen de estas opciones de línea de comandos.

VENTANA PRINCIPAL

Después de iniciarse, nload comienza a monitorear los dispositivos de red especificados en la línea de comandos o, si no se especificó ninguno, el dispositivo predeterminado. En este modo, los siguientes atajos de teclado están disponibles.

'FlechaDerecha', 'FlechaAbajo', 'RePag', 'Intro', 'Tab'
Cambia la visualización al siguiente dispositivo de red, o, cuando se inicia con el indicador -m, a la siguiente página de dispositivos.
'FlechaIzquierda', 'FlechaArriba', 'AvPag'
Cambia la visualización al dispositivo de red anterior, o, cuando se inicia con el indicador -m, a la página anterior de dispositivos.
'F2'
Muestra la ventana de opciones (ver sección VENTANA DE OPCIONES a continuación).
'F5'
Guarda la configuración actual en el archivo de configuración del usuario.
'F6'
Recarga la configuración desde los archivos de configuración.
'q', 'Ctrl+C'
Sale de nload.

VENTANA DE OPCIONES

Los parámetros proporcionados a nload en la línea de comandos se pueden ajustar en tiempo de ejecución presionando la tecla 'F2'. Aparece una pequeña ventana en la parte superior de la pantalla, que enumera la configuración disponible.

'F2'
Muestra/oculta la ventana de opciones.
'FlechaIzquierda', 'FlechaDerecha', 'Inicio', 'Fin'
Navega dentro de los campos de edición.
'FlechaArriba', 'FlechaAbajo', 'Intro'
Navega entre la configuración.
'AvPag', 'RePag', 'Tab'
Alterna entre los diferentes valores posibles para el campo actual.
'+' / '-'
Cambia a la página siguiente / anterior de configuración.

ARCHIVOS

/etc/nload.conf
Archivo de configuración para todo el sistema.
$(HOME)/.nload
Archivo de configuración específico del usuario (anula la configuración general del sistema).
/sys/class/net/*/* /proc/net/dev
son leídos por nload al ejecutarse en Linux para obtener los datos de tráfico de red.

nload

Monitor de tráfico de red en tiempo real

NOMBRE

nload ‒ monitor de tráfico de red en tiempo real

SINOPSIS

nload [-a] [-b] [-c <num>] [-d <num>] [-i <num>] [-m] [-o <num>] [-P] [-q] [-t <num>] [-U <unit>] [-V] [-h] [<interfaz>...]

DESCRIPCIÓN

nload es una utilidad para monitorizar el uso del ancho de banda de la red. Muestra el tráfico de red en la pantalla en tiempo real.

Para cada interfaz de red, nload muestra:

  • Tráfico entrante y saliente.
  • Velocidad de transmisión de entrada y salida.
  • Número de paquetes entrantes y salientes.
  • Número de errores de entrada y salida.

nload muestra los datos en dos gráficos. El gráfico de la izquierda muestra el tráfico entrante, y el gráfico de la derecha muestra el tráfico saliente.

OPCIONES

-a, --display-as-is
No escalar los gráficos para que se ajusten a la pantalla.
-b, --bytes
Mostrar el tráfico en bytes en lugar de paquetes.
-c, --num-charts <num>
Número de gráficos que se mostrarán. El valor predeterminado es 2.
-d, --decay <num>
Tiempo de decaimiento para los promedios. El valor predeterminado es 50.
-i, --interfaces <num>
Número de interfaces para mostrar. El valor predeterminado es 1.
-m, --print-totals
Imprimir estadísticas totales de todas las interfaces.
-o, --output <num>
Mostrar tráfico de salida. El valor predeterminado es 1.
-P, --current-average
Mostrar la media actual en lugar de la media general.
-q, --quiet
Modo silencioso. No se muestra ninguna salida.
-t, --update-time <num>
Tiempo de actualización en milisegundos. El valor predeterminado es 500.
-U, --unit <unit>
Unidad para mostrar el tráfico. Las opciones son B, K, M, G, T, P, E, Z, Y (bytes, kilobytes, megabytes, etc.).
-V, --version
Mostrar información de la versión.
-h, --help
Mostrar mensaje de ayuda.

ARCHIVO DE CONFIGURACIÓN

nload puede leer opciones de un archivo de configuración. El archivo de configuración se busca en el siguiente orden:

  1. $XDG_CONFIG_HOME/nload.conf
  2. $HOME/.nload.conf

Las opciones en el archivo de configuración deben estar en formato de una opción por línea. Por ejemplo:

# Archivo de configuración de nload
unit K
update-time 1000
num-charts 3

EDITOR DE LÍNEA DE COMANDOS

nload usa el editor de línea de comandos de la biblioteca de programación GNU Readline. Esto significa que puedes usar la mayoría de las combinaciones de teclas de emacs o vi para editar la línea de comandos.

EJEMPLO

Para monitorizar el tráfico de la interfaz eth0 y mostrar el tráfico en kilobytes, usa el siguiente comando:

nload -U K eth0
