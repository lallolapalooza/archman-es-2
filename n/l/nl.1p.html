NL(1P) Manual del Programador POSIX NL(1P)

PROLOGO

Esta página del manual forma parte del Manual del Programador POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual de Linux correspondiente para detalles del comportamiento en Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

nl — filtro de numeración de líneas

SINOPSIS

nl [-p] [-b tipo] [-d delimitador] [-f tipo] [-h tipo] [-i incremento] [-l num]
    [-n formato] [-s sep] [-v numini] [-w ancho] [archivo]

DESCRIPCION

La utilidad nl leerá líneas del archivo nombrado o de la entrada estándar si no se nombra ningún archivo y reproducirá las líneas a la salida estándar. Las líneas se numerarán a la izquierda. Se puede proporcionar funcionalidad adicional de acuerdo con las opciones del comando en vigor.

La utilidad nl considera el texto que lee en términos de páginas lógicas. La numeración de líneas se reiniciará al comienzo de cada página lógica. Una página lógica consta de una cabecera, un cuerpo y una sección de pie. Las secciones vacías son válidas. Diferentes opciones de numeración de líneas están disponibles de forma independiente para la cabecera, el cuerpo y el pie (por ejemplo, sin numeración de líneas de cabecera y pie, pero numerando solo las líneas en blanco del cuerpo).

Los inicios de las secciones de página lógica se indicarán mediante líneas de entrada que no contienen nada más que los siguientes caracteres delimitadores:

Línea Inicio de
\:\:\: Cabecera
\:\: Cuerpo
\: Pie

A menos que se especifique lo contrario, nl asumirá que el texto que se está leyendo está en un solo cuerpo de página lógica.

OPCIONES

La utilidad nl cumplirá con el volumen de Definiciones Base de POSIX.1‐2017, Sección 12.2, Directrices de sintaxis de utilidades. Solo se puede nombrar un archivo.

Se admitirán las siguientes opciones:

-b tipo
Especificar qué líneas del cuerpo de la página lógica se numerarán. Los tipos reconocidos y su significado son:
a
Numerar todas las líneas.
t
Numerar solo las líneas no vacías.
n
Sin numeración de líneas.
pcadena
Numerar solo las líneas que contengan la expresión regular básica especificada en cadena.

El tipo predeterminado para el cuerpo de la página lógica es t (se numeran las líneas de texto).

-d delimitador
Especificar los caracteres delimitadores que indican el inicio de una sección de página lógica. Estos se pueden cambiar de los caracteres predeterminados "\:" a dos caracteres especificados por el usuario. Si se introduce solo un carácter, el segundo carácter seguirá siendo el carácter predeterminado ':'.
-f tipo
Especificar lo mismo que b tipo excepto para el pie. El predeterminado para el pie de página lógico es n (sin líneas numeradas).
-h tipo
Especificar lo mismo que b tipo excepto para la cabecera. El tipo predeterminado para la cabecera de página lógica es n (sin líneas numeradas).
-i incremento
Especificar el valor de incremento utilizado para numerar las líneas de la página lógica. El valor predeterminado será 1.
-l num
Especificar el número de líneas en blanco que se considerarán como una. Por ejemplo, -l 2 resulta en que solo se numere la segunda línea en blanco adyacente (si se establece la opción apropiada -h a, -b a o -f a). El valor predeterminado será 1.
-n formato
Especificar el formato de numeración de líneas. Los valores reconocidos son: ln, justificado a la izquierda, supresión de ceros iniciales; rn, justificado a la derecha, supresión de ceros iniciales; rz, justificado a la derecha, conservación de ceros iniciales. El formato predeterminado será rn (justificado a la derecha).
-p
Especificar que la numeración no se reiniciará en los delimitadores de página lógica.
-s sep
Especificar los caracteres utilizados para separar el número de línea y la línea de texto correspondiente. El sep predeterminado será un <tab>.
-v numini
Especificar el valor inicial utilizado para numerar las líneas de la página lógica. El valor predeterminado será 1.
-w ancho
Especificar el número de caracteres que se utilizarán para el número de línea. El ancho predeterminado será 6.

OPERANDOS

Se admitirá el siguiente operando:

archivo
Una ruta de un archivo de texto a numerar.

ENTRADA ESTÁNDAR

La entrada estándar se utilizará si no se especifica ningún operando archivo, y se utilizará si el operando archivo es '-' y la implementación trata el '-' como entrada estándar. De lo contrario, no se utilizará la entrada estándar. Consulte la sección ARCHIVOS DE ENTRADA.

ARCHIVOS DE ENTRADA

El archivo de entrada será un archivo de texto.

VARIABLES DE ENTORNO

Las siguientes variables de entorno afectarán la ejecución de nl:

LANG
Proporcionar un valor predeterminado para las variables de internacionalización que no están establecidas o están vacías. (Consulte el volumen de Definiciones Base de POSIX.1‐2017, Sección 8.2, Variables de internacionalización para la precedencia de las variables de internacionalización utilizadas para determinar los valores de las categorías de localización).
LC_ALL
Si se establece en un valor de cadena no vacío, anulará los valores de todas las demás variables de internacionalización.
LC_COLLATE

Determinar la localización para el comportamiento de rangos, clases de equivalencia y elementos de collating multicarácter dentro de expresiones regulares.
LC_CTYPE
Determinar la localización para la interpretación de secuencias de bytes de datos de texto como caracteres (por ejemplo, caracteres de un solo byte frente a caracteres multibyte en argumentos y archivos de entrada), el comportamiento de las clases de caracteres dentro de expresiones regulares y para decidir qué caracteres están en la clase de caracteres graph (para las opciones -b t, -f t y -h t).
LC_MESSAGES

Determinar la localización que debe utilizarse para afectar el formato y el contenido de los mensajes de diagnóstico escritos en la salida de error estándar.
NLSPATH
Determinar la ubicación de los catálogos de mensajes para el procesamiento de LC_MESSAGES.

EVENTOS ASINCRONOS

Predeterminado.

SALIDA ESTÁNDAR

La salida estándar contendrá las líneas de entrada con los números de línea apropiados insertados, según lo determinado por las opciones. La salida estándar tendrá la misma precisión de bits que la entrada estándar.

SALIDA DE ERROR ESTÁNDAR

Se utilizará para mensajes de diagnóstico.

ESTADO DE SALIDA

Los siguientes valores de salida se devolverán:

0
Se ha completado correctamente.
>0
Se ha producido un error.

EJEMPLOS

Para numerar todas las líneas de un archivo llamado document.txt, utilizando el formato predeterminado (numeración justificada a la derecha, ceros iniciales suprimidos, separador de tabulación, ancho de 6 caracteres), escriba:

nl -b a document.txt

Para numerar solo las líneas que contienen la cadena "error" en un archivo llamado input.log y no reiniciar la numeración en las páginas, escriba:

nl -p "error" -b pinput.log

Para numerar todas las líneas de un archivo llamado main.c, suprimiendo ceros iniciales y utilizando un espacio como separador, escriba:

nl -n ln -s " " main.c

NAME

nl

line numbering filter

SYNOPSIS

nl [Option...] [file ...]

DESCRIPTION

The nl utility shall read the specified input files, number the lines, and write the results to the standard output. The nl utility is intended to be used as a filter to number lines from a file or standard input.

The numbering options specify how the lines are numbered. The default numbering increments lines by 1, starts at line 1, and uses the default format for numbering. The default action is to number all lines. The default text line separators are:

    \"\n"
    \"\n\n"
    \"\n\n\n"

The default header line separators are:

    \"\n"
    \"\n\n"

The default footer line separators are:

    \"\n"
    \"\n\n"

The nl utility shall number lines within logical pages. A logical page consists of a header, a body, and a footer. The nl utility numbers lines in the header and footer sections only if the -h or -f options are specified, respectively.

The default behavior is to number all lines in the body of a logical page. The -ba option enables numbering for all lines in the logical page (header, body, and footer). The -bd option disables numbering for all lines in the logical page (header, body, and footer). The -bt option enables numbering for all lines in the body of a logical page.

Numbering within a logical page starts at the beginning of the page. The line numbering continues from page to page unless the -i option is reset to 0, or the -v option is specified.

The nl utility shall separate the fields of the output lines by the separator string specified by the -d option. The default separator is a tab.

The width of the line number field is 6, right-justified, preceded by spaces. The -w option can change this width.

The nl utility shall determine which lines to number based on the following criteria:

Lines not to be numbered
Lines that contain only spaces and tabs.
Lines to be numbered
All other lines.

The -n option determines the format of the line number.

OPTIONS

The nl utility shall conform to the Base Definitions volume of POSIX.1‐2017, Section 12.2, Utility Syntax Guidelines.

The following options shall be supported:

-ba
Number all lines. This is the default setting.
-bd
Number no lines. Lines containing only white space characters are not numbered.
-be
Number non-blank lines. Lines that contain characters other than whitespace are numbered.
-bn
Number no lines. This is the default.
-bt
Number non-blank lines. Lines that contain characters other than whitespace are numbered.
-f string
Specify the file separator string. The default is a newline.
-h string
Specify the header separator string. The default is a newline.
-i number
Set the increment value for line numbering. The default is 1. If -i 0 is specified, numbering is not reset for subsequent logical pages.
-l number
Set the number of non-empty lines to be considered as one line for numbering purposes. The default is 1.
-n format
Specify the line numbering format. The format shall be one of the following:
ln
Number lines left-justified.
rn
Number lines right-justified. This is the default.
rz
Number lines right-justified, with leading zeros.
-o number
Set the next line number to use. The default is 1.
-w number
Set the width of the line number field to number. The default is 6.
-v number
Set the line number to use for the first line of each logical page. The default is 1. If -i 0 is specified, numbering is not reset for subsequent logical pages.
-d string
Specify the separator string between the line number and the line text. The default is a tab character.

OPERANDS

The following operands shall be supported:

file
A pathname of a file to be processed. If no file operands are specified, or if a file is a hyphen (-), the standard input shall be used.

STDIN

The standard input shall be used only if no file operands are specified or if a file operand is -.

INPUT FILES

The standard input or the specified files shall be text files.

ENVIRONMENT VARIABLES

The following environment variables shall be supported:

LC_ALL, LC_CTYPE, LC_MESSAGES
These variables shall affect the execution of nl as described in the Base Definitions volume of POSIX.1‐2017, Section 12.3, Locale Categories.
NL_SETN
This variable shall be used to determine the default set number. If not set, it defaults to 1.
NL_CATMSG
This variable shall be used to determine the default message catalog. If not set, it defaults to the standard system catalog.

ASYNCHRONOUS EVENTS

Default.

STDOUT

The standard output shall be a text file in the following format:

"%s%s%s", <line number>, <separator>, <input line>

where <line number> is one of the following numeric formats:

%6d
When the rn format is used (the default; see -n).
%06d
When the rz format is used.
%-6d
When the ln format is used.
<empty>
When line numbers are suppressed for a portion of the page; the <separator> is also suppressed.

In the preceding list, the number 6 is the default width; the -w option can change this value.

STDERR

The standard error shall be used only for diagnostic messages.

OUTPUT FILES

None.

EXTENDED DESCRIPTION

None.

EXIT STATUS

The following exit values shall be returned:

 0
Successful completion.
>0
An error occurred.

CONSEQUENCES OF ERRORS

Default.

The following sections are informative.

APPLICATION USAGE

In using the -d delim option, care should be taken to escape characters that have special meaning to the command interpreter.

EXAMPLES

The command:

nl -v 10 -i 10 -d \!+ file1

numbers file1 starting at line number 10 with an increment of 10. The logical page delimiter is "!+". Note that the '!' has to be escaped when using csh as a command interpreter because of its history substitution syntax. For ksh and sh the escape is not necessary, but does not do any harm.
