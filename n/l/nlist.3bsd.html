NOMBRE

nlist — recupera la lista de nombres de la tabla de símbolos de un archivo ejecutable

BIBLIOTECA

biblioteca “libbsd”

SINOPSIS

#include <nlist.h> (Ver libbsd(7) para el uso de include.)
int
nlist(const char *filename, struct nlist *nl);

DESCRIPCIÓN

La función nlist() recupera entradas de la lista de nombres de la tabla de símbolos de un archivo ejecutable (ver elf(5)). El argumento nl se establece para referenciar el principio de la lista. La lista se limpia de datos binarios e inválidos; si una entrada en la lista de nombres es válida, n_type y n_value para la entrada se copian en la lista referenciada por nl. No se copian otros datos. La última entrada de la lista es siempre NULL.

VALORES DE RETORNO

Se devuelve el número de entradas inválidas si tiene éxito; de lo contrario, si el archivo filename no existe o no es ejecutable, o si el puntero nl es NULL, el valor devuelto es -1.

VER TAMBIÉN

elf(5)

HISTORIA

Una función nlist() apareció en Versión 6 de AT&T UNIX.
