nl_langinfo(3) Manual de Funciones de Biblioteca nl_langinfo(3)

NOMBRE

nl_langinfo, nl_langinfo_l - consultar información de idioma y localización

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <langinfo.h>
char *nl_langinfo(nl_item item);
char *nl_langinfo_l(nl_item item, locale_t locale);
Requisitos de macro de prueba de características para glibc (ver feature_test_macros(7)):

nl_langinfo_l():

    Desde glibc 2.24:
        _POSIX_C_SOURCE >= 200809L
    glibc 2.23 y anteriores:
        _POSIX_C_SOURCE >= 200112L

DESCRIPCIÓN

Las funciones nl_langinfo() y nl_langinfo_l() proporcionan acceso a la información de localización de una manera más flexible que localeconv(3). nl_langinfo() devuelve una cadena que es el valor correspondiente a item en la localización global actual del programa. nl_langinfo_l() devuelve una cadena que es el valor correspondiente a item para la localización identificada por el objeto de localización locale, que fue creado previamente por newlocale(3). Se pueden consultar elementos individuales y adicionales de las categorías de localización.

Ejemplos de los elementos de localización que se pueden especificar en item usando las constantes definidas en <langinfo.h> son:

CODESET (LC_CTYPE)
Devuelve una cadena con el nombre de la codificación de caracteres utilizada en la localización seleccionada, como "UTF-8", "ISO-8859-1" o "ANSI_X3.4-1968" (más conocido como US-ASCII). Esta es la misma cadena que se obtiene con "locale charmap". Para obtener una lista de nombres de codificación de caracteres, intente "locale -m" (ver locale(1)).
D_T_FMT (LC_TIME)
Devuelve una cadena que se puede usar como cadena de formato para strftime(3) para representar la hora y la fecha de una manera específica de la localización (especificación de conversión %c).
D_FMT (LC_TIME)
Devuelve una cadena que se puede usar como cadena de formato para strftime(3) para representar una fecha de una manera específica de la localización (especificación de conversión %x).
T_FMT (LC_TIME)
Devuelve una cadena que se puede usar como cadena de formato para strftime(3) para representar una hora de una manera específica de la localización (especificación de conversión %X).
AM_STR (LC_TIME)
Devuelve una cadena que representa el prefijo para la hora ante meridiem (antes del mediodía, "AM"). (Utilizado en la especificación de conversión %p de strftime(3).)
PM_STR (LC_TIME)
Devuelve una cadena que representa el prefijo para la hora post meridiem (antes de la medianoche, "PM"). (Utilizado en la especificación de conversión %p de strftime(3).)
T_FMT_AMPM (LC_TIME)
Devuelve una cadena que se puede usar como cadena de formato para strftime(3) para representar una hora en formato a.m. o p.m. de una manera específica de la localización (especificación de conversión %r).
ERA (LC_TIME)
Devuelve la descripción de la era, que contiene información sobre cómo se cuentan y muestran los años para cada era en una localización. Cada segmento de descripción de era tendrá el formato:
dirección:desplazamiento:fecha_inicio:fecha_fin:nombre_era:formato_era
según las definiciones siguientes:
dirección
Un carácter "+" o "-". El "+" significa que los años aumentan desde la fecha_inicio hacia la fecha_fin, "-" significa lo contrario.
desplazamiento
El año de la época de la fecha_inicio.
fecha_inicio
Una fecha en el formato aaaa/mm/dd, donde aaaa, mm y dd son los números del año, mes y día respectivamente del inicio de la era.
fecha_fin
La fecha de finalización de la era, en el mismo formato que la fecha_inicio, o uno de los dos valores especiales "-*" (menos infinito) o "+*" (más infinito).
nombre_era
El nombre de la era, correspondiente a la especificación de conversión %EC de strftime(3).
formato_era
El formato del año en la era, correspondiente a la especificación de conversión %EY de strftime(3).
Los segmentos de descripción de era están separados por punto y coma. La mayoría de las localizaciones no definen este valor. Ejemplos de localizaciones que sí definen este valor son las localizaciones japonesa y tailandesa.
ERA_D_T_FMT (LC_TIME)
Devuelve una cadena que se puede usar como cadena de formato para strftime(3) para una representación alternativa de la hora y la fecha en una manera específica de la localización (especificación de conversión %Ec).
ERA_D_FMT (LC_TIME)
Devuelve una cadena que se puede usar como cadena de formato para strftime(3) para una representación alternativa de una fecha en una manera específica de la localización (especificación de conversión %Ex).
ERA_T_FMT (LC_TIME)
Devuelve una cadena que se puede usar como cadena de formato para strftime(3) para una representación alternativa de una hora en una manera específica de la localización (especificación de conversión %EX).
DAY_{1–7} (LC_TIME)
Devuelve el nombre del n-ésimo día de la semana. [Advertencia: esto sigue la convención estadounidense DAY_1 = Domingo, no la convención internacional (ISO 8601) de que el lunes es el primer día de la semana.] (Utilizado en la especificación de conversión %A de strftime(3)).
ABDAY_{1–7} (LC_TIME)
Devuelve el nombre abreviado del n-ésimo día de la semana. (Utilizado en la especificación de conversión %a de strftime(3)).
MON_{1–12} (LC_TIME)
Devuelve el nombre del n-ésimo mes. (Utilizado en la especificación de conversión %B de strftime(3)).
ABMON_{1–12} (LC_TIME)
Devuelve el nombre abreviado del n-ésimo mes. (Utilizado en la especificación de conversión %b de strftime(3)).
RADIXCHAR (LC_NUMERIC)
Devuelve el carácter radix (punto decimal, coma decimal, etc.).
THOUSEP (LC_NUMERIC)
Devuelve el carácter separador de miles (grupos de tres dígitos).
YESEXPR (LC_MESSAGES)
Devuelve una expresión regular que se puede usar con la función regex(3) para reconocer una respuesta positiva a una pregunta de sí/no.
NOEXPR (LC_MESSAGES)
Devuelve una expresión regular que se puede usar con la función regex(3) para reconocer una respuesta negativa a una pregunta de sí/no.
CRNCYSTR (LC_MONETARY)
nl_langinfo_l(3) — Arch Linux

NOMBRE

nl_langinfo, nl_langinfo_l - obtener información específica del idioma

BIBLIOTECA

Library C Standard (library C Standard)

Library GNU lib C (library GNU lib C)

SINOPSIS

#include <langinfo.h>

char *nl_langinfo(nl_item item);

char *nl_langinfo_l(nl_item item, locale_t locale);

DESCRIPCIÓN

La función nl_langinfo() recupera información sobre la configuración regional actual.

La función nl_langinfo_l() es la versión internacionalizada de nl_langinfo() . Recupera información sobre la configuración regional representada por el objeto de configuración regional locale.

El argumento item es una macro que especifica el elemento de información sobre la configuración regional deseado. Los valores posibles para item se definen en el archivo de encabezado <langinfo.h>. La lista anterior cubre solo algunos ejemplos de elementos que se pueden solicitar. Para obtener una lista más detallada, consulte The GNU C Library Reference Manual.

Los elementos para los que se puede solicitar información incluyen:

ABDAY_1
Nombre abreviado del primer día de la semana (por ejemplo, "Lun").
ABDAY_2
Nombre abreviado del segundo día de la semana (por ejemplo, "Mar").
...
YESEXPR
Expresión regular que coincide con las respuestas "sí" (por ejemplo, "[yY]").
NOEXPR
Expresión regular que coincide con las respuestas "no" (por ejemplo, "[nN]").
CODESET
Nombre del conjunto de códigos utilizado en esta configuración regional (por ejemplo, "UTF-8").
D_FMT
Formato de fecha para date(1) (por ejemplo, "%a %b %e %H:%M:%S %Y").
D_T_FMT
Formato de fecha y hora para date(1) (por ejemplo, "%a %d %b %Y %r %Z").
D_AM_PM
Cadena vacía o que contiene el marcador AM y PM separado por un carácter de nueva línea (por ejemplo, "AM\nPM").
T_FMT
Formato de hora para date(1) (por ejemplo, "%H:%M:%S").
T_FMT_AMPM
Formato de hora para date(1) que utiliza un reloj de 12 horas con un marcador AM/PM (por ejemplo, "%I:%M:%S %p").
CRNCYSTR
Símbolo de la moneda, precedido por "-" si el símbolo debe aparecer antes del valor, "+" si el símbolo debe aparecer después del valor, o "." si el símbolo debe reemplazar el carácter radix.

La lista anterior cubre solo algunos ejemplos de elementos que se pueden solicitar. Para obtener una lista más detallada, consulte The GNU C Library Reference Manual.

VALOR DEVUELTO

En caso de éxito, estas funciones devuelven un puntero a una cadena que es el valor correspondiente a item en la configuración regional especificada.

Si setlocale() no ha seleccionado ninguna configuración regional para la categoría apropiada, nl_langinfo() devuelve un puntero a la cadena correspondiente en la configuración regional "C". Lo mismo ocurre con nl_langinfo_l() si locale especifica una configuración regional donde los datos de langinfo no están definidos.

Si item no es válido, se devuelve un puntero a una cadena vacía.

El puntero devuelto por estas funciones puede apuntar a datos estáticos que pueden ser sobrescritos, o el puntero en sí puede invalidarse, por una llamada posterior a nl_langinfo(), nl_langinfo_l() o setlocale(). Las mismas declaraciones se aplican a nl_langinfo_l() si el objeto de configuración regional al que se hace referencia en locale es liberado o modificado por freelocale() o newlocale().

POSIX especifica que la aplicación no puede modificar la cadena devuelta por estas funciones.

NOTAS

El comportamiento de nl_langinfo_l() no está definido si locale es el objeto de configuración regional especial LC_GLOBAL_LOCALE o no es un identificador de objeto de configuración regional válido.

EJEMPLOS

El siguiente programa establece el tipo de carácter y la configuración regional numérica de acuerdo con el entorno y consulta el conjunto de caracteres de la terminal y el carácter radix.

#include <langinfo.h>
#include <locale.h>
#include <stdio.h>
#include <stdlib.h>
int
main(void)
{
    setlocale(LC_CTYPE, "");
    setlocale(LC_NUMERIC, "");
    printf("%s\n", nl_langinfo(CODESET));
    printf("%s\n", nl_langinfo(RADIXCHAR));
    exit(EXIT_SUCCESS);
}
