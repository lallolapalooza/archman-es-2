nl_langinfo(3) Manual de funciones de biblioteca nl_langinfo(3)

NOMBRE

nl_langinfo, nl_langinfo_l - consultar información sobre el idioma y la configuración regional

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <langinfo.h>
char *nl_langinfo(nl_item item);
char *nl_langinfo_l(nl_item item, locale_t locale);
Requisitos de macro de prueba de características para glibc (consulte feature_test_macros(7)):

nl_langinfo_l():

    Desde glibc 2.24:
        _POSIX_C_SOURCE >= 200809L
    glibc 2.23 y anteriores:
        _POSIX_C_SOURCE >= 200112L

DESCRIPCIÓN

Las funciones nl_langinfo() y nl_langinfo_l() proporcionan acceso a la información de configuración regional de una manera más flexible que localeconv(3). nl_langinfo() devuelve una cadena que es el valor correspondiente a item en la configuración regional global actual del programa. nl_langinfo_l() devuelve una cadena que es el valor correspondiente a item para la configuración regional identificada por el objeto de configuración regional locale, que se creó previamente con newlocale(3). Se pueden consultar elementos individuales y adicionales de las categorías de configuración regional.

Ejemplos de los elementos de configuración regional que se pueden especificar en item utilizando las constantes definidas en <langinfo.h> son:

CODESET (LC_CTYPE)
Devuelve una cadena con el nombre de la codificación de caracteres utilizada en la configuración regional seleccionada, como "UTF-8", "ISO-8859-1" o "ANSI_X3.4-1968" (mejor conocida como US-ASCII). Esta es la misma cadena que se obtiene con "locale charmap". Para obtener una lista de nombres de codificación de caracteres, intente "locale -m" (consulte locale(1)).
D_T_FMT (LC_TIME)
Devuelve una cadena que se puede utilizar como cadena de formato para strftime(3) para representar la hora y la fecha de forma específica de la configuración regional (especificación de conversión %c).
D_FMT (LC_TIME)
Devuelve una cadena que se puede utilizar como cadena de formato para strftime(3) para representar una fecha de forma específica de la configuración regional (especificación de conversión %x).
T_FMT (LC_TIME)
Devuelve una cadena que se puede utilizar como cadena de formato para strftime(3) para representar una hora de forma específica de la configuración regional (especificación de conversión %X).
AM_STR (LC_TIME)
Devuelve una cadena que representa el prefijo para la hora ante meridiem (antes del mediodía, "AM"). (Se utiliza en la especificación de conversión %p de strftime(3)).
PM_STR (LC_TIME)
Devuelve una cadena que representa el prefijo para la hora post meridiem (antes de la medianoche, "PM"). (Se utiliza en la especificación de conversión %p de strftime(3)).
T_FMT_AMPM (LC_TIME)
Devuelve una cadena que se puede utilizar como cadena de formato para strftime(3) para representar una hora en formato a.m. o p.m. de forma específica de la configuración regional (especificación de conversión %r).
ERA (LC_TIME)
Devuelve una descripción de era, que contiene información sobre cómo se cuentan y muestran los años para cada era en una configuración regional. Cada segmento de descripción de era tendrá el formato:
direccion:desplazamiento:fecha_inicio:fecha_fin:nombre_era:formato_era
según las siguientes definiciones:
direccion
Un carácter "+" o "-". El "+" significa que los años aumentan desde la fecha_inicio hacia la fecha_fin, "-" significa lo contrario.
desplazamiento
El año de la época de la fecha_inicio.
fecha_inicio
Una fecha en el formato aaaa/mm/dd, donde aaaa, mm y dd son los números de año, mes y día respectivamente del inicio de la era.
fecha_fin
La fecha de finalización de la era, en el mismo formato que la fecha_inicio, o uno de los dos valores especiales "-*" (infinito negativo) o "+*" (infinito positivo).
nombre_era
El nombre de la era, correspondiente a la especificación de conversión %EC de strftime(3).
formato_era
El formato del año en la era, correspondiente a la especificación de conversión %EY de strftime(3).
Los segmentos de descripción de era están separados por punto y coma. La mayoría de las configuraciones regionales no definen este valor. Ejemplos de configuraciones regionales que sí definen este valor son las configuraciones regionales japonesa y tailandesa.
ERA_D_T_FMT (LC_TIME)
Devuelve una cadena que se puede utilizar como cadena de formato para strftime(3) para una representación alternativa de la hora y la fecha en una configuración regional específica (especificación de conversión %Ec).
ERA_D_FMT (LC_TIME)
Devuelve una cadena que se puede utilizar como cadena de formato para strftime(3) para una representación alternativa de una fecha en una configuración regional específica (especificación de conversión %Ex).
ERA_T_FMT (LC_TIME)
Devuelve una cadena que se puede utilizar como cadena de formato para strftime(3) para una representación alternativa de una hora en una configuración regional específica (especificación de conversión %EX).
DAY_{1–7} (LC_TIME)
Devuelve el nombre del n-ésimo día de la semana. [Advertencia: esto sigue la convención de EE. UU. DAY_1 = domingo, no la convención internacional (ISO 8601) de que el lunes es el primer día de la semana.] (Se utiliza en la especificación de conversión %A de strftime(3)).
ABDAY_{1–7} (LC_TIME)
Devuelve el nombre abreviado del n-ésimo día de la semana. (Se utiliza en la especificación de conversión %a de strftime(3)).
MON_{1–12} (LC_TIME)
Devuelve el nombre del n-ésimo mes. (Se utiliza en la especificación de conversión %B de strftime(3)).
ABMON_{1–12} (LC_TIME)
Devuelve el nombre abreviado del n-ésimo mes. (Se utiliza en la especificación de conversión %b de strftime(3)).
RADIXCHAR (LC_NUMERIC)
Devuelve el carácter del radix (punto decimal, coma decimal, etc.).
THOUSEP (LC_NUMERIC)
Devuelve el carácter separador de miles (grupos de tres dígitos).
YESEXPR (LC_MESSAGES)
Devuelve una expresión regular que se puede utilizar con la función regex(3) para reconocer una respuesta afirmativa a una pregunta de sí/no.
NOEXPR (LC_MESSAGES)
Devuelve una expresión regular que se puede utilizar con la función regex(3) para reconocer una respuesta negativa a una pregunta de sí/no.

NAME

nl_langinfo, nl_langinfo_l - query language and character information

LIBRARY

Standard C library (libc, -lc)

SYNOPSIS

#include <langinfo.h>

char *nl_langinfo(nl_item item);
#include <locale.h>
char *nl_langinfo_l(nl_item item, locale_t locale);

DESCRIPTION

The nl_langinfo() and nl_langinfo_l() functions return a pointer to a string describing the current locale setting corresponding to item. The item argument is a symbolic constant defined in <langinfo.h>.

The nl_langinfo_l() function is like nl_langinfo() but operates on a user-specified locale object referred to by locale. The special locale object LC_GLOBAL_LOCALE is equivalent to the current locale of the calling thread. (See newlocale(3) for details of locale objects).

The values of item are defined in <langinfo.h> and correspond to the items defined by POSIX.1-2008 for the localeconv(3) function. The following is a list of some common items:

CRNCYSTR (LC_MONETARY)
Return the currency symbol, preceded by "-" if the symbol should appear before the value, "+" if the symbol should appear after the value, or "." if the symbol should replace the radix character.

The above list covers just some examples of items that can be requested. For a more detailed list, consult The GNU C Library Reference Manual.

RETURN VALUE

On success, these functions return a pointer to a string which is the value corresponding to item in the specified locale.

If no locale has been selected by setlocale(3) for the appropriate category, nl_langinfo() return a pointer to the corresponding string in the "C" locale. The same is true of nl_langinfo_l() if locale specifies a locale where langinfo data is not defined.

If item is not valid, a pointer to an empty string is returned.

The pointer returned by these functions may point to static data that may be overwritten, or the pointer itself may be invalidated, by a subsequent call to nl_langinfo(), nl_langinfo_l(), or setlocale(3). The same statements apply to nl_langinfo_l() if the locale object referred to by locale is freed or modified by freelocale(3) or newlocale(3).

POSIX specifies that the application may not modify the string returned by these functions.

ATTRIBUTES

For an explanation of the terms used in this section, see attributes(7).

Interface Attribute Value
nl_langinfo () Thread safety MT-Safe locale

STANDARDS

POSIX.1-2008.

HISTORY

POSIX.1-2001, SUSv2.

NOTES

The behavior of nl_langinfo_l() is undefined if locale is the special locale object LC_GLOBAL_LOCALE or is not a valid locale object handle.

EXAMPLES

The following program sets the character type and the numeric locale according to the environment and queries the terminal character set and the radix character.

#include <langinfo.h>
#include <locale.h>
#include <stdio.h>
#include <stdlib.h>
int
main(void)
{
    setlocale(LC_CTYPE, "");
    setlocale(LC_NUMERIC, "");
    printf("%s\n", nl_langinfo(CODESET));
    printf("%s\n", nl_langinfo(RADIXCHAR));
    exit(EXIT_SUCCESS);
}
