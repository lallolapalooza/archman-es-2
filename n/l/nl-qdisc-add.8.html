nl-qdisc(8) Manual del Administrador del Sistema nl-qdisc(8)

NOMBRE

nl-qdisc-{add|list|delete} - Gestionar disciplinas de cola

SINOPSIS

nl-qdisc-add --dev dev --parent id [OPCIONES] tipo-qdisc [QDISC]

nl-qdisc-delete [ --interactive ] [OPCIONES]

nl-qdisc-list [OPCIONES]

DESCRIPCIÓN

Las herramientas nl-qdisc permiten gestionar y configurar disciplinas de cola (qdiscs) en el kernel.

OPCIONES

-h o --help
Imprime el texto de ayuda en la consola y sale.
-v o --version
Imprime la información de la versión en la consola y sale.
-q o --quiet
No imprime notificaciones informales sobre las acciones realizadas en la consola. Por defecto, se imprimirá una breve descripción de cada qdisc añadido/actualizado/eliminado en la consola. Esta opción deshabilita este comportamiento.
-d o --dev=DEV
Dispositivo de red al que está adjunto el qdisc.
-p o --parent=ID
Identificador del qdisc/clase padre al que está adjunto este qdisc. El identificador se puede especificar como classid, nombre o uno de los valores especiales "root" o "ingress".
-i o --id=ID
Identificador del qdisc. Se puede especificar como classid o nombre.

Opciones de nl-qdisc-add

--update
Actualiza el qdisc si ya existe, de lo contrario, intentar añadir un qdisc que ya existe resultará en un error. Esto no incluye cambiar el tipo del qdisc, usa --replace si deseas hacerlo.
--replace
Reemplaza o actualiza el qdisc si ya existe. Mismo comportamiento que --update pero reemplazará completamente el qdisc si ya existe.
--update-only
Actualiza un qdisc existente pero no lo crea si no existe.
--replace-only
Actualiza o reemplaza un qdisc existente pero no lo crea si no existe.

Opciones de nl-qdisc-delete

--interactive
El modo interactivo requiere confirmación del usuario para cada qdisc eliminado. Imprimirá una solicitud para cada qdisc que coincida con el filtro proporcionado y requiere que el usuario responda 's'í o 'n'o.
--yes
Hace que la respuesta por defecto para las solicitudes interactivas sea 's'í. Esta opción también es necesaria para eliminar todos los qdiscs en todos los dispositivos de red.
-k o --kind=TIPO
Elimina solo qdiscs de este tipo.

Opciones de nl-qdisc-list

--details
Muestra información detallada para cada qdisc listado.
--stats
Muestra información de estadísticas para cada qdisc listado. Esta opción también activará automáticamente la información detallada.
-r o --recursive
Lista todos los objetos TC adjuntos recursivamente a todos los qdiscs que coinciden con el filtro.
-k o --kind=TIPO
Lista solo qdiscs de este tipo.

USO

Añadir un qdisc raíz HTB con el id "5:":

nl-qdisc-add --dev eth0 --parent root --id 5: htb

Listar todos los qdiscs en eth0 e imprimir datos estadísticos:

nl-qdisc-list --stats --dev eth0

Eliminar el qdisc "5:":

nl-qdisc-delete --id 5:
