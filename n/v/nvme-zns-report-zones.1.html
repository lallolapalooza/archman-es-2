NOMBRE

nvme-zns-report-zones - Recupera y muestra la estructura de datos Report Zones

SINOPSIS

nvme zns report-zones <dispositivo> [--namespace-id=<NUM> | -n <NUM>]
                                 [--start-lba=<NUM_ION> | -s <NUM_ION>]
                                 [--descs=<NUM> | -d <NUM>]
                                 [--state=<NUM> | -S <NUM>]
                                 [--extended | -e]
                                 [--partial | -p]
                                 [--verbose | -v]
                                 [--output-format=<fmt> | -o <fmt>]

DESCRIPCIÓN

Para el dispositivo NVMe dado, envía el comando Zone Management Receive con la Acción de Recepción de Zona establecida en Report Zones o Extended Report Zones, dependiendo de la opción extended.

El parámetro <dispositivo> es obligatorio y puede ser el dispositivo de caracteres NVMe (ej: /dev/nvme0) o un dispositivo de bloque de namespace (ej: /dev/nvme0n1).

En caso de éxito, la estructura de datos devuelta por el dispositivo se decodificará y se mostrará de una de varias maneras.

OPCIONES

-n <NUM>, --namespace-id=<NUM>

Usa el ID de namespace proporcionado para el comando. Si no se proporciona, se usará el ID de namespace del dispositivo de bloque. Si el comando se emite a un dispositivo que no es de bloque, el parámetro es obligatorio.

-s <lba>, --start-lba=<lba>

El LBA de inicio de la zona para comenzar el informe.

-d <NUM>, --descs=<NUM>

El número de descriptores a solicitar en el informe.

-S <NUM>, --state=<NUM>

El estado de las zonas a solicitar en el informe. Los valores conocidos incluyen:
Valor Definición
0 Lista todas las zonas (por defecto)
1 Estado Vacío
2 Estado Abierto Implícitamente
3 Estado Abierto Explícitamente
4 Estado Cerrado
5 Estado Lleno
6 Estado Solo Lectura
7 Estado Desconectado

-e, --extended

Solicita usar la opción Extended Report Zones. Los datos extendidos no se decodifican.

-p, --partial

Si se establece, el dispositivo devolverá el número de zonas que coinciden con el estado en lugar del número de zonas devueltas en el informe.

-v, --verbose

Aumenta el nivel de detalle de la información en la salida.

-o <fmt>, --output-format=<fmt>

Establece el formato del informe en normal, json, o binary. Solo se puede usar un formato de salida a la vez.

EJEMPLOS

•Hace que el programa interprete el informe para 16 zonas y muestre los campos conocidos en un formato legible por humanos: 
# nvme zns report-zones /dev/nvme0 -n 1 -d 16
•Muestra la salida en formato json con detalles adicionales: 
# nvme zns report-zones /dev/nvme0 -n 1 -d 16 -o json
