NVME-LIST-CTRL(1) Manual de NVMe NVME-LIST-CTRL(1)

NOMBRE

nvme-list-ctrl - Envía la lista de identificaciones de controladores NVMe, devuelve el resultado y la estructura

SINOPSIS

nvme list-ctrl <dispositivo> [--cntid=<cntid> | -c <cntid>]
                        [--namespace-id=<nsid> | -n <nsid>]
                        [--output-format=<fmt> | -o <fmt>] [--verbose | -v]

DESCRIPCIÓN

Para el dispositivo NVMe dado, envía un comando de identificación para la lista de controladores y proporciona el resultado y la estructura devuelta. Esto utiliza el modo 12h o 13h dependiendo del identificador de namespace solicitado.

El parámetro <dispositivo> es obligatorio y puede ser el dispositivo de caracteres NVMe (ej: /dev/nvme0) o un dispositivo de bloque de namespace (ej: /dev/nvme0n1). El controlador de inicio en la lista siempre comienza con 0 a menos que se proporcione la opción '--cntid' para anularlo.

En caso de éxito, se imprime el array de controladores para cada índice e identificador de controlador.

OPCIONES

-c <cntid>, --cntid=<cntid>

Recupera la estructura de la lista de identificación comenzando con el ID de controlador dado.

-n <nsid>, --namespace-id=<nsid>

Si se proporciona, solicitará los controladores adjuntos al namespace especificado. Si no se proporciona ningún namespace, o se establece en 0, el comando solicita la lista de controladores para todo el subsistema, estén o no adjuntos a namespaces.

-o <fmt>, --output-format=<fmt>

Establece el formato del informe en normal, json o binary. Solo se puede usar un formato de salida a la vez.

-v, --verbose

Aumenta el nivel de detalle de la información en la salida.
