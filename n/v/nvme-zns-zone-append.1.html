NOMBRE

nvme-zns-zone-append - Envía un comando de escritura NVMe, proporciona resultados

SINOPSIS

nvme-zns-zone-append <dispositivo> [--namespace-id=<NUM> | -n <NUM>]
                                [--zslba=<IONUM> | -s <IONUM>]
                                [--data-size=<IONUM> | -z <IONUM>]
                                [--metadata-size=<IONUM> | -y <IONUM>]
                                [--data=<ARCHIVO> | -d <ARCHIVO>]
                                [--metadata=<ARCHIVO> | -M <ARCHIVO>]
                                [--limited-retry | -l]
                                [--force-unit-access | -f]
                                [--ref-tag=<NUM> | -r <NUM>]
                                [--app-tag-mask=<NUM> | -m <NUM>]
                                [--app-tag=<NUM> | -a <NUM>]
                                [--prinfo=<NUM> | -p <NUM>]

DESCRIPCIÓN

El comando zone append escribe los bloques lógicos especificados por el comando en el medio desde el búfer de datos proporcionado. Usará stdin por defecto si no proporcionas un archivo.

En caso de éxito, el programa informará el LBA que se asignó a los datos para la operación de append.

OPCIONES

-n <NUM>, --namespace-id=<NUM>

Usa el ID de namespace proporcionado para el comando. Si no se proporciona, se usará el ID de namespace del dispositivo de bloques. Si el comando se emite a un dispositivo que no es de bloques, el parámetro es requerido.

-s <IONUM>, --zslba=<IONUM>, -z <IONUM>, --data-size=<IONUM>

Tamaño de los datos, en bytes.

-y <IONUM>, --metadata-size=<IONUM>

Tamaño de los metadatos en bytes.

-d <ARCHIVO>, --data=<ARCHIVO>

Archivo de datos que proporciona los datos a escribir. Si no se proporciona ninguno, el contenido se envía desde STDIN.

-M <ARCHIVO>, --metadata=<ARCHIVO>

Archivo de metadatos, si es necesario.

-l, --limited-retry

Establece la bandera de reintento limitado.

-f, --force-unit-access

Establece la bandera de acceso forzado a la unidad.

-r <NUM>, --ref-tag=<NUM>

Reftag opcional cuando se usa con información de protección.

-m <NUM>, --app-tag-mask=<NUM>

Máscara de etiqueta de aplicación opcional cuando se usa con información de protección.

-a <NUM>, --app-tag=<NUM>

Etiqueta de aplicación opcional cuando se usa con información de protección.

-p <NUM>, --prinfo=<NUM>

Definición del campo de Información de Protección.

EJEMPLOS

•Anexa los datos "hola mundo" en 4k de bloques en la zona que comienza en el bloque 0 para el namespace 1: 
# echo "hola mundo" | nvme zns zone-append /dev/nvme0 -n 1 -s 0 -z 4k
