NOMBRE

nvme-seagate-get-host-tele - Recupera la Telemetría Iniciada por el Host de Seagate en formato de volcado hexadecimal (predeterminado) o binario

SINOPSIS

nvme seagate get-host-tele <dispositivo> [OPCIONES]

DESCRIPCIÓN

Esto solo funcionará en dispositivos Seagate que soporten esta función. No todos los comandos funcionan en todas las familias de productos.

El parámetro <dispositivo> es obligatorio y puede ser un dispositivo de carácter NVMe (ej: /dev/nvme0) o un dispositivo de bloque (ej: /dev/nvme0n1).

OPCIONES

-n <NUM>, --namespace-id=<NUM>

namespace deseado

-i <NUM>, --log_specific=<NUM>

1 - el controlador capturará Datos que representan el estado interno del controlador en el momento en que se procesa el comando. 0 - el controlador no actualizará los Datos Iniciados por el Host de Telemetría.

-b, --raw-binary

salida en formato crudo (binario)

EJEMPLOS

Obtener el registro de telemetría iniciado por el host en formato hexdump o binario para el dispositivo especificado.

# nvme seagate get-host-tele /dev/nvme0
