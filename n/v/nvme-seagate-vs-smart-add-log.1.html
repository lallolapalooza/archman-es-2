NOMBRE

nvme-seagate-vs-smart-add-log - Recuperar información SMART extendida específica del proveedor Seagate

SINOPSIS

nvme seagate vs-smart-add-log <dispositivo> [OPCIONES]

DESCRIPCIÓN

Para el dispositivo NVMe dado, envía la solicitud de registro del proveedor Seagate y guarda el resultado en un archivo o vuelca el contenido en la salida estándar.

El parámetro <dispositivo> es obligatorio y puede ser el dispositivo de caracteres NVMe (ej: /dev/nvme0) o un dispositivo de bloque de namespace (ej: /dev/nvme0n1).

El contenido del registro puede estar asociado al controlador, en cuyo caso el parámetro de namespace se ignora.

Existen dos registros, página 0xC4 (página de registro SMART extendida) y página 0xCF (página de registro SMART de supercondensador DRAM)

Este comando solo funcionará en dispositivos Seagate que soporten esta característica. No todos los comandos funcionan en todas las familias de productos.

OPCIONES

-l <NUM>, --log=<NUM>

Número de registro, página 0xC4 (página de registro SMART extendida) y página 0xCF (página de registro SMART de supercondensador DRAM)

-n <NUM>, --namespace-id=<NUM>

Número de namespace

-o <ARCHIVO>, --output-file=<ARCHIVO>

Salida en formato binario. Por defecto, volcado en formato texto a la salida estándar

EJEMPLOS

Obtener la información SMART extendida específica del proveedor para el dispositivo especificado.

# nvme seagate vs-smart-add-log /dev/nvme0
