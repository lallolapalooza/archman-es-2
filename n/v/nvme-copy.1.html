NOMBRE

nvme-copy - Envía un comando NVMe Simple Copy, proporciona resultados

SINOPSIS

nvme-copy <dispositivo> [--sdlba=<sdlba> | -d <sdlba>]
                        [--blocks=<nlb-list,> | -b <nlb-list,>]
                        [--slbs=<slbas,> | -s <slbas,>]
                        [--snsids=<snsids,> | -N <snsids,>]
                        [--sopts=<sopts,> | -O <sopts,>]
                        [--limited-retry | -l]
                        [--force-unit-access | -f]
                        [--prinfow=<prinfow> | -p <prinfow>]
                        [--prinfor=<prinfor> | -P <prinfor>]
                        [--ref-tag=<reftag> | -r <reftag>]
                        [--expected-ref-tags=<reftag,> | -R <reftag,>]
                        [--app-tag=<apptag> | -a <apptag>]
                        [--expected-app-tags=<apptag,> | -A <apptag,>]
                        [--app-mask=<appmask> | -m <appmask>]
                        [--expected-app-masks=<appmask,> | -M <appmask,>]
                        [--dir-type=<type> | -T <type>]
                        [--dir-spec=<spec> | -S <spec>]
                        [--format=<entry-format> | -F <entry-format>]
                        [--output-format=<fmt> | -o <fmt>] [--verbose | -v]
                        [--timeout=<timeout> | -t <timeout>]

DESCRIPCIÓN

El comando Copy es utilizado por el host para copiar datos de uno o más rangos de bloques lógicos de origen a un rango de bloques lógicos consecutivo de destino.

OPCIONES

-d <sdlba>, --sdlba=<sdlba>

Dirección de 64 bits del primer bloque lógico de destino

-b <nlb-list,>, --blocks=<nlb-list,>

Lista separada por comas del número de bloques en cada rango

-s <slbas,>, --slbs=<slbas,>

Lista separada por comas de los bloques de inicio en cada rango

--snsids=<snsids,>, -N <snsids,>

Lista separada por comas de los identificadores de espacio de nombres de origen en cada rango

--sopts=<sopts,>, -O <sopts,>

Lista separada por comas de las opciones de origen en cada rango

-l, --limited-retry

Establece el indicador de reintento limitado.

-f, --force-unit-access

Establece el indicador de acceso forzado a la unidad.

-p <prinfow>, --prinfow=<prinfow>

Definición de escritura del campo de Información de Protección.

-P <prinfor>, --prinfor=<prinfor>

Definición de lectura del campo de Información de Protección.

-r <reftag>, --ref-tag=<reftag>

Etiqueta de referencia inicial de lba.

-R <reftag,>, --expected-ref-tags=<reftag,>

Etiquetas de referencia de lba esperadas (lista separada por comas).

-a <apptag>, --app-tag=<apptag>

etiqueta de aplicación de lba

-A <apptag,>, --expected-app-tags=<apptag,>

etiquetas de aplicación de lba esperadas (lista separada por comas)

-m <appmask>, --app-mask=<appmask>

máscara de etiqueta de lba

-M <appmask,>, --expected-app-masks=<appmask,>

máscaras de etiqueta de lba esperadas (lista separada por comas)

-T <type>, --dir-type=<type>

Tipo de directiva opcional. nvme-cli solo verifica que el valor esté en el rango definido para el tipo de directiva, aunque la especificación NVMe (1.3a) define solo una directiva, 01h, para los identificadores de flujo de escritura.

-S <spec>, --dir-spec=<spec>

Campo opcional para especificidades de directiva. Cuando se usa con flujos de escritura, este valor se define como el identificador del flujo de escritura. nvme-cli no validará si el flujo solicitado está dentro de las capacidades del controlador.

-F <entry-format>, --format=<entry-format>

formato de entrada de rango de origen

-o <fmt>, --output-format=<fmt>

Establece el formato de informe en normal, json o binary. Solo se puede usar un formato de salida a la vez.

-v, --verbose

Aumenta el nivel de detalle de la información en la salida.

-t <timeout>, --timeout=<timeout>

Anula el valor de tiempo de espera predeterminado. En milisegundos.
