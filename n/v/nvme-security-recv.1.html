NOMBRE

nvme-security-recv - Comando Security Recv

SINOPSIS

nvme security-recv <dispositivo> [--size=<tamaño> | -x <tamaño>]
                        [--secp=<protocolo-seguridad> | -p <protocolo-seguridad>]
                        [--spsp=<protocolo-específico> | -s <protocolo-específico>]
                        [--nssf=<específico-nvme> | -N <específico-nvme>]
                        [--al=<longitud-asignación> | -t <longitud-asignación>]
                        [--namespace-id=<nsid> | -n <nsid>] [--raw-binary | -b]
                        [--output-format=<fmt> | -o <fmt>] [--verbose | -v]
                        [--timeout=<timeout>]

DESCRIPCIÓN

El comando Security Receive transfiere el estado y el resultado de los datos de uno o más comandos Security Send que se enviaron previamente al controlador.

La asociación entre un comando Security Receive y los comandos Security Send anteriores depende del Protocolo de Seguridad. El formato de los datos a transferir depende del Protocolo de Seguridad. Consulte SPC-4 para obtener detalles del Protocolo de Seguridad.

Cada comando Security Receive devuelve los datos apropiados que corresponden a un comando Security Send, según las reglas del Protocolo de Seguridad. Los datos del comando Security Receive pueden no conservarse si hay una pérdida de comunicación entre el controlador y el host, o si ocurre un reinicio del controlador.

OPCIONES

-n <nsid>, --namespace-id=<nsid>

Dirigirse a un espacio de nombres específico para este comando de seguridad.

-N <nssf>, --nssf=<nssf>

Campo específico de seguridad NVMe. Si se utiliza el protocolo de seguridad EAh asignado para uso NVMe, el campo específico de seguridad NVMe indica el destino del búfer de memoria de respuesta.

-x <tamaño>, --size=<tamaño>

Tamaño del búfer a asignar. Al éxito, se imprimirá en STDOUT.

-p <protocolo-seguridad>, --secp=<protocolo-seguridad>

Protocolo de Seguridad: Este campo especifica el protocolo de seguridad según se define en SPC-4. El controlador fallará el comando con Parámetro Inválido indicado si se especifica un valor reservado del Protocolo de Seguridad.

-s <protocolo-específico-seguridad>, --spsp=<protocolo-específico-seguridad>

Específico de SP: El valor de este campo es específico del Protocolo de Seguridad según se define en SPC-4.

-t <longitud-asignación>, --al=<longitud-asignación>

Longitud de Asignación: El valor de este campo es específico del Protocolo de Seguridad según se define en SPC-4.

-b, --raw-binary

Imprimir el búfer sin procesar en stdout. Por defecto, se imprime en hexadecimal.

-o <fmt>, --output-format=<fmt>

Establece el formato de informe en normal, json o binary. Solo se puede usar un formato de salida a la vez.

-v, --verbose

Aumenta el nivel de detalle de la información en la salida.

--timeout=<timeout>

Anula el valor de tiempo de espera predeterminado. En milisegundos.
