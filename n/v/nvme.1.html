NVME(1) Manual de NVMe NVME(1)

NOMBRE

nvme - la utilidad de interfaz de línea de comandos para almacenamiento NVMe (nvme-cli)

SINOPSIS

plugin incorporado:

nvme <comando> <dispositivo> [<argumentos>]

plugins de extensión:

nvme <plugin> <comando> <dispositivo> [<argumentos>]

DESCRIPCIÓN

NVM-Express es una interfaz de controlador de host rápida y escalable diseñada para abordar las necesidades no solo de las unidades de estado sólido basadas en PCI Express, sino también de NVMe-oF (sobre tejidos).

Este programa nvme es una utilidad de espacio de usuario para proporcionar herramientas conformes a los estándares para unidades NVM-Express. Se creó específicamente para Linux, ya que se basa en los IOCTL definidos por el controlador del kernel principal.

COMANDOS NVME

La utilidad tiene subcomandos para todos los comandos de administración y E/S definidos en la especificación y para mostrar los registros del controlador. También hay una opción para enviar comandos completamente arbitrarios. Para obtener una lista de los comandos disponibles, ejecute "nvme help".
