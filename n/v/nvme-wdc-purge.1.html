NOMBRE

nvme-wdc-purge - Envía un comando específico del proveedor WDC de NVMe Purge, devuelve el resultado

SINOPSIS

nvme wdc purge <dispositivo>

DESCRIPCIÓN

Para el dispositivo NVMe proporcionado, envía un comando específico del proveedor WDC Purge y proporciona el resultado.

El parámetro <dispositivo> es obligatorio y puede ser el dispositivo de caracteres NVMe (ej: /dev/nvme0) o un dispositivo de bloque de namespace (ej: /dev/nvme0n1).

Esto solo funcionará en dispositivos WDC que soporten esta característica. Los resultados para cualquier otro dispositivo no están definidos.

En caso de éxito devuelve 0, código de error en caso contrario.

OPCIONES

Aún no hay opciones.

EJEMPLOS

•Haz que el programa emita el Comando Único del Proveedor WDC Purge: 
# nvme wdc purge /dev/nvme0n1

NVME

Parte del conjunto de utilidades nvme-user.
