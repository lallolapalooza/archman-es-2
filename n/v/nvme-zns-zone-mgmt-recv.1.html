NOMBRE

nvme-zns-zone-mgmt-recv - Comando de recepción de gestión de zonas

SINOPSIS

nvme zns zone-mgmt-recv <dispositivo> [--namespace-id=<NUM> | -n <NUM>]
                        [--start-lba=<LBA> | -s <LBA>]
                        [--data-len=<NUM>, -l <NUM>]
                        [--zra=<NUM>, -z <NUM>] [--zrasf=<NUM>, -a <NUM>]
                        [--zra-spec-feat, -f] [--output-format=<fmt>, -o <fmt>]

DESCRIPCIÓN

Para el dispositivo NVMe dado, emite el comando de recepción de gestión de zonas con la acción de recepción solicitada y parámetros adicionales específicos de la acción. Esta es la interfaz genérica proporcionada para la compatibilidad hacia adelante, ya que se crean nuevas acciones de las que este programa no es consciente en el momento de su desarrollo. Como tal, este es un comando genérico que no realiza ninguna decodificación adicional para tipos específicos de datos recibidos. Esto solo informará los datos como un volcado hexadecimal o binario.

OPCIONES

-n <NUM>, --namespace-id=<NUM>

Utiliza el id de namespace proporcionado para el comando. Si no se proporciona, se utilizará el id de namespace del dispositivo de bloque. Si el comando se emite a un dispositivo que no es de bloque, el parámetro es obligatorio.

-s <lba>, --start-lba=<lba>

El LBA de inicio de la zona a gestionar y recibir.

-l <NUM> --data-len=<NUM> Longitud del búfer de datos recibidos

-z <NUM>, --zra=<NUM>

Acción de Recepción de Zona

-a <NUM> --zrasf=<NUM> Campo específico de la acción de recepción de zona

-f, --zra-spec-feat

Habilita las características específicas de la acción de recepción de zona

-o <fmt>, --output-format=<fmt>

Formato de salida: normal|json|binary

EJEMPLOS

• Volcado hexadecimal de todas las zonas del informe 
# nvme zns zone-mgmt-recv /dev/nvme0 -n 1 -s 0 -z 0 -a 0 -l 4k
• Volcado binario de todas las zonas del informe 
# nvme zns zone-mgmt-recv /dev/nvme0 -n 1 -s 0 -z 0 -a 0 -o -l 4k binary > report.out
