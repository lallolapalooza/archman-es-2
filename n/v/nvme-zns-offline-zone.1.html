NVME-ZNS-OFFLINE-(1) Manual de NVMe NVME-ZNS-OFFLINE-(1)

NOMBRE

nvme-zns-offline-zone - Deshabilita una o todas las zonas

SINOPSIS

nvme zns offline-zone <dispositivo> [--namespace-id=<NUMERO> | -n <NUMERO>]
                                                [--start-lba=<LBA> | -s <LBA>]
                                                [--select-all | -a]
                                                [--timeout=<tiempo_espera> | -t <tiempo_espera>]

DESCRIPCIÓN

Para el dispositivo NVMe proporcionado, emite el comando Zone Management Send con la acción "Offline Zone". Esto transicionará la zona al estado deshabilitado.

El parámetro <dispositivo> es obligatorio y puede ser el dispositivo de caracteres NVMe (ej: /dev/nvme0) o un dispositivo de bloque de espacio de nombres (ej: /dev/nvme0n1).

OPCIONES

-n <NUMERO>, --namespace-id=<NUMERO>

Utiliza el ID de espacio de nombres proporcionado para el comando. Si no se proporciona, se utilizará el ID de espacio de nombres del dispositivo de bloque. Si el comando se emite a un dispositivo que no es de bloque, el parámetro es obligatorio.

-s <lba>, --start-lba=<lba>

El LBA de inicio de la zona a deshabilitar.

-a, --select-all

Selecciona todas las zonas para esta acción.

-t <tiempo_espera>, --timeout=<tiempo_espera>

Anula el valor de tiempo de espera predeterminado. En milisegundos.

EJEMPLOS

•Deshabilita todas las zonas en el espacio de nombres 1: 
# nvme zns offline-zone /dev/nvme0 -a -n 1
