NOMBRE

nvme-sndk-vs-temperature-stats - Muestra estadísticas relacionadas con la temperatura

SINOPSIS

nvme sndk vs-temperature-stats <dispositivo>

DESCRIPCIÓN

Para el dispositivo NVMe dado, muestra estadísticas de temperatura.

El parámetro <dispositivo> es un dispositivo de carácter NVMe obligatorio (ej: /dev/nvme0).

Esto solo funcionará en dispositivos Sandisk que soporten esta característica. Los resultados para cualquier otro dispositivo no están definidos.

Estado y descripción esperados:

Estadística Descripción
La temperatura compuesta actual temperatura del dispositivo
Umbral de TEMPeratura compuesta de advertencia temperatura de sobrecalentamiento
Umbral de TEMPeratura compuesta crítica temperatura de sobrecalentamiento crítico
Estado de soporte de limitación térmica iniciada por el dispositivo 0 = no soportado, 1 = soportado
Soporte de gestión térmica controlada por el host 0 = no soportado, 1 = soportado
Temperatura de gestión térmica 1 (limitación ligera) temperatura para iniciar limitación ligera
Contador de transición de temperatura de gestión térmica 1 # de veces que se cambió a limitación ligera
Tiempo total de temperatura de gestión térmica 1 # de segundos pasados en limitación ligera
Temperatura de gestión térmica 2 (limitación pesada) temperatura para iniciar limitación pesada
Contador de transición de temperatura de gestión térmica 2 # de veces que se cambió a limitación pesada
Tiempo total de temperatura de gestión térmica 2 # de segundos pasados en limitación pesada
Umbral de apagado térmico temperatura de apagado del dispositivo

En caso de éxito devuelve 0, código de error en caso contrario.

EJEMPLOS

• Muestra las estadísticas de temperatura para el dispositivo: 
# nvme sndk vs-temperature-stats /dev/nvme0
