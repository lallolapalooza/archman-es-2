NOMBRE

nvme-admin-passthru - Envía un comando de administración arbitrario, devuelve resultados

SINOPSIS

nvme-admin-passthru <dispositivo> [--opcode=<opcode> | -O <opcode>]
                        [--flags=<flags> | -f <flags>] [-rsvd=<rsvd> | -R <rsvd>]
                        [--namespace-id=<nsid> | -n <nsid>] [--cdw2=<cdw2> | -2 <cdw2>]
                        [--cdw3=<cdw3> | -3 <cdw3>] [--cdw10=<cdw10> | -4 <cdw10>]
                        [--cdw11=<cdw11> | -5 <cdw11>] [--cdw12=<cdw12> | -6 <cdw12>]
                        [--cdw13=<cdw13> | -7 <cdw13>] [--cdw14=<cdw14> | -8 <cdw14>]
                        [--cdw15=<cdw15> | -9 <cdw15>]
                        [--data-len=<data-len> | -l <data-len>]
                        [--metadata-len=<len> | -m <len>]
                        [--input-file=<file> | -i <file>]
                        [--read | -r] [--write | -w]
                        [--timeout=<timeout> | -t <timeout>]
                        [--show-command | -s]
                        [--dry-run | -d]
                        [--raw-binary | -b]
                        [--prefill=<prefill> | -p <prefill>]
                        [--latency | -T]
                        [--output-format=<fmt> | -o <fmt>] [--verbose | -v]

DESCRIPCIÓN

Envía un comando de administración NVMe arbitrario y devuelve los resultados aplicables. Esto puede ser simplemente el resultado y estado del comando, o también puede incluir un búfer si el comando devuelve uno. Este comando no interpreta los opcodes ni las opciones.

El parámetro <dispositivo> es obligatorio y puede ser tanto el dispositivo de caracteres NVMe (ej: /dev/nvme0), como un dispositivo de bloque de namespace (ej: /dev/nvme0n1).

En caso de éxito, la estructura devuelta (si es aplicable) puede ser devuelta de varias maneras dependiendo de las banderas de las opciones; la estructura puede ser impresa por el programa como un volcado hexadecimal, o puede ser devuelta como un búfer crudo impreso a stdout para que otro programa lo analice.

OPCIONES

-O <opcode>, --opcode=<opcode>

El opcode NVMe a enviar al dispositivo en el comando. Argumento requerido ya que este parámetro es obligatorio.

-f <flags>, --flags=<flags>

Las banderas del comando NVMe a enviar al dispositivo en el comando.

-R <rsvd>, --rsvd=<rsvd>

El valor para el campo reservado en el comando.

-n <nsid>, --namespace-id=<nsid>

El valor para el ns-id en el comando.

-[2-9] <cdw>, --cdw[2-3,10-15]=<cdw>

Especifica el valor del dword del comando para esa entrada especificada en el comando.

-r, --read, -w, --write

Utilizado para la dirección de datos del comando y es requerido para comandos que envían/reciben datos. No use read y write al mismo tiempo.

-i <archivo>, --input-file=<archivo>

Si el comando es un comando de salida de datos (escritura), use este archivo para rellenar el búfer enviado al dispositivo. Si no se proporciona archivo, se asume que se usa STDIN.

-l <data-len>, --data-len=<data-len>

La longitud de datos para el búfer utilizado para este comando.

-m <data-len>, --metadata-len=<data-len>

La longitud de metadatos para el búfer utilizado para este comando.

-s, --show-cmd

Imprime el comando a ser enviado.

-d, --dry-run

No envíe realmente el comando. Si desea usar la opción --dry-run, la opción --show-cmd *debe* establecerse. De lo contrario, la opción --dry-run será *ignorada*.

-b, --raw-binary

Imprime el búfer devuelto crudo a stdout si el comando devuelve una estructura.

-p, --prefill

Pre-rellena el búfer con un valor de byte predeterminado. Por defecto es 0. Esto puede ser útil si los datos que está escribiendo son más cortos que el búfer requerido, y necesita rellenarlo con un valor conocido. También puede ser útil si necesita confirmar si un dispositivo está sobrescribiendo un búfer para un comando de entrada de datos.

-T, --latency

Imprime la latencia que tomó el IOCTL (en us).

-o <fmt>, --output-format=<fmt>

Establece el formato de informe a *normal*, *json* o *binary*. Solo se puede usar un formato de salida a la vez.

-v, --verbose

Aumenta el nivel de detalle de la información en la salida.

-t <timeout>, --timeout=<timeout>

Anula el valor de tiempo de espera predeterminado. En milisegundos.

EJEMPLOS

•Lo siguiente ejecutará el comando de administración con opcode=6 y cdw10=1, lo que corresponde a un comando de identificación del controlador. Este ejemplo requiere que el parámetro data-len sea 4096, que es el tamaño de la estructura devuelta. La opción -r se usa porque es un comando de entrada de datos. 
# nvme admin-passthru /dev/nvme0 --opcode=06 --data-len=4096 --cdw10=1 -r
•O si desea guardar esa estructura en un archivo: 
# nvme admin-passthru /dev/nvme0 --opcode=06 --data-len=4096 --cdw10=1 -r -b > id_ns.raw
