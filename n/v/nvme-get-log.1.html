NOMBRE

nvme-get-log - Recupera una página de registro de un dispositivo NVMe

SINOPSIS

nvme get-log <dispositivo> [--log-id=<id-log> | -i <id-log>]
                        [--log-len=<longitud-log> | -l <longitud-log>]
                        [--aen=<aen> | -a <aen>]
                        [--namespace-id=<nsid> | -n <nsid>]
                        [--raw-binary | -b]
                        [--lpo=<offset> | -L <offset>]
                        [--lsp=<campo> | -s <campo>]
                        [--lsi=<campo> | -S <campo>]
                        [--rae | -r]
                        [--csi=<identificador-conjunto-comando> | -y <identificador-conjunto-comando>]
                        [--ot=<tipo-offset> | -O <tipo-offset>]
                        [--xfer-len=<longitud> | -x <longitud>]
                        [--output-format=<fmt> | -o <fmt>] [--verbose | -v]

DESCRIPCIÓN

Recupera una página de registro NVMe arbitraria de un dispositivo NVMe y proporciona la estructura devuelta.

El parámetro <dispositivo> es obligatorio y puede ser el dispositivo de caracteres NVMe (ej: /dev/nvme0) o un dispositivo de bloque de espacio de nombres (ej: /dev/nvme0n1).

En caso de éxito, la estructura de registro devuelta se puede devolver de varias maneras, dependiendo de las opciones; la estructura puede mostrarse en hexadecimal por el programa o el búfer crudo se puede imprimir en stdout para que otro programa lo analice.

OPCIONES

-l <longitud-log>, --log-len=<longitud-log>

Asigna un búfer de tamaño <longitud-log> bytes y solicita que se devuelvan tantos bytes en el comando NVMe construido. Este parámetro es obligatorio.

-i <id-log>, --log-id=<id-log>

Establece el ID de registro solicitado del comando en <id-log>. Predeterminado a 0.

-a <aen>, --aen=<aen>

Campo de conveniencia para extraer información de registro basada en un resultado de notificación de evento asíncrono. Esto anulará log-id y log-len, si se establecen.

-n <nsid>, --namespace-id=<nsid>

Establece el valor nsid del comando en el nsid dado. Predeterminado a 0xffffffff si no se proporciona. Esta opción puede no afectar nada dependiendo de la página de registro, que puede ser específica o no de un espacio de nombres.

-b, --raw-binary

Imprime el búfer de registro crudo en stdout.

-L <offset>, --lpo=<offset>

El offset de la página de registro especifica la ubicación dentro de una página de registro desde donde comenzar a devolver datos. Está alineado en Dword y es de 64 bits.

-s <campo>, --lsp=<campo>

El campo especificado del registro LID.

-S <campo>, --lsi=<campo>

El campo especificado del registro LSI.

-r, --rae

Habilita la notificación de evento asíncrono (AEN). Cuando esta opción está habilitada, el dispositivo generará una notificación de evento asíncrono cuando se cumpla el evento solicitado. El dispositivo enviará una notificación al host. El comando de registro de lectura se puede usar para recuperar la información de la notificación.

-y <identificador-conjunto-comando>, --csi=<identificador-conjunto-comando>

El identificador del conjunto de comandos para las operaciones del comando Get Log Page. Si no se especifica, se utiliza el valor predeterminado de 0x00. Esto se utiliza para recuperar páginas de registro específicas del conjunto de comandos.

-O <tipo-offset>, --ot=<tipo-offset>

El tipo de offset del registro. El valor predeterminado es 0. Consulte la especificación NVMe para ver los valores admitidos.

-x <longitud>, --xfer-len=<longitud>

Establece la longitud de transferencia para las operaciones de transferencia de datos. Esto puede ser útil para controlar la cantidad de datos recuperados en una sola operación, especialmente para páginas de registro grandes.

-o <fmt>, --output-format=<fmt>

El formato de salida. El valor predeterminado es `text`. Los formatos admitidos son `text`, `json` y `binary`.

-v, --verbose

Habilita la salida detallada.

EJEMPLOS

Obtener la página de registro SMART (ID 0x02) de longitud 1024 bytes de
/dev/nvme0:
# nvme get-log /dev/nvme0 -i 0x02 -l 1024

Obtener la página de registro de errores (ID 0x01) en formato binario crudo
de /dev/nvme0n1:
# nvme get-log /dev/nvme0n1 -i 0x01 -l 512 -b

Obtener la lista de páginas de registro soportadas de /dev/nvme0:
# nvme get-log /dev/nvme0 -i 0x00 -l 512

nvme-get-log.1.en

NAME

nvme-get-log - retrieves log pages from an NVMe device

SYNOPSIS

nvme get-log [-a] [-H] [-h] [-l <log_len>] [-i <log_id>] [-f <log_fmt>] [-r] [-y <csi>] [-O] [-x <length>] [-o <fmt>] [-v] [--add-field] [--hex-only] [--help] [--log-len <log_len>] [--log-id <log_id>] [--log-fmt <log_fmt>] [--rae] [--csi <csi>] [--ot] [--xfer-len <length>] [--output-format <fmt>] [--verbose] [nvme-device]

DESCRIPTION

The NVMe Get Log Page command is used to retrieve log pages from an NVMe device. This command supports retrieving a number of predefined log pages as well as custom log pages defined by the controller.

OPTIONS

-a, --add-field

Adds fields to the existing log page.

-H, --hex-only

Dump the log page in hex only. No interpretation is done by the program.

-h, --help

Provide basic help message.

-l <log_len>, --log-len <log_len>

The length of the log page to be returned. If not specified, the program will attempt to read the maximum size supported by the controller.

-i <log_id>, --log-id <log_id>

The identifier of the log page to be returned. The identifier is a number from 0x00 to 0xFF. The special value 0xFF is reserved for the SMART log page.

-f <log_fmt>, --log-fmt <log_fmt>

This field specifies the format of the log page. This is expected to be a decimal or hex number.

-r, --rae

Retain an Asynchronous Event.

-y <command_set_identifier>, --csi=<command_set_identifier>

This field specifies the identifier of command set. if not issued, NVM Command Set will be selected.

-O, --ot

This field specifies the offset type. If set to false, the Log Page Offset Lower field and the Log Page Offset Upper field specify the byte offset into the log page to be returned. If set to true, the Log Page Offset Lower field and the Log Page Offset Upper field specify the index into the list of data structures in the log page to be returned. The default is byte offset. If the option is specified the index mode is used.

-x <length>

--xfer-len <length>: Specify the read chunk size. The length argument is expected to be a multiple of 4096. The default size is 4096.

-o <fmt>, --output-format=<fmt>

Set the reporting format to normal, json or binary. Only one output format can be used at a time.

-v, --verbose

Increase the information detail in the output.

EXAMPLES

•Get 512 bytes from log page 2 
# nvme get-log /dev/nvme0 --log-id=2 --log-len=512

The above example will get log page 2 (SMART), and request 512 bytes. On success, the returned log will be dumped in hex and not interpreted by the program.

•Have the program return the raw log page in binary: 
# nvme get-log /dev/nvme0 -log-id=2 --log-len=512 --raw-binary > log_page_2.raw
# nvme get-log /dev/nvme0 -i 2 -l 512 -b > log_page_2.raw

It is not a good idea to not redirect stdout when using this mode.
