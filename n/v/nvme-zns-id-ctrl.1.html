NOMBRE

nvme-zns-id-ctrl - Envía el comando Identify Controller del conjunto de comandos Zoned de NVMe, devuelve el resultado y la estructura

SINOPSIS

nvme zns id-ctrl <dispositivo> [--output-format=<fmt> | -o <fmt>]

DESCRIPCIÓN

Para el dispositivo NVMe dado, envía el comando Identify Controller del conjunto de comandos Zoned de NVMe y proporciona el resultado y la estructura devuelta.

El parámetro <dispositivo> es obligatorio y puede ser tanto el dispositivo de caracteres NVMe (ej: /dev/nvme0), como un dispositivo de bloque de espacio de nombres (ej: /dev/nvme0n1).

En caso de éxito, la estructura de datos devuelta por el dispositivo se decodificará y se mostrará de una de las siguientes maneras.

OPCIONES

-o <fmt>, --output-format=<fmt>

Establece el formato de informe a normal, json o binary. Solo se puede usar un formato de salida a la vez.

EJEMPLOS

•Hace que el programa interprete el buffer devuelto y muestre los campos conocidos en un formato legible por humanos: 
# nvme zns id-ctrl /dev/nvme0
•Muestra la salida en formato json 
# nvme zns id-ctrl /dev/nvme0 -o json
