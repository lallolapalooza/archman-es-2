NOMBRE

nvme-id-ns - Envía el comando NVMe Identify Namespace, devuelve el resultado y la estructura

SINOPSIS

nvme id-ns <dispositivo> [--vendor-specific | -v] [--raw-binary | -b]
                        [--namespace-id=<nsid> | -n <nsid>] [--force]
                        [--human-readable | -H]
                        [--output-format=<fmt> | -o <fmt>] [--verbose | -v]

DESCRIPCIÓN

Para el dispositivo NVMe proporcionado, envía un comando identify-namespace y proporciona el resultado y la estructura devuelta.

El parámetro <dispositivo> es obligatorio y puede ser el dispositivo de caracteres NVMe (ej: /dev/nvme0) o un dispositivo de bloque de namespace (ej: /dev/nvme0n1). Si se proporciona el dispositivo de caracteres, la opción '--namespace-id' es obligatoria, de lo contrario utilizará el ns-id del namespace del dispositivo de bloque que se abrió. Para dispositivos de bloque, el ns-id utilizado puede ser anulado con la misma opción.

En caso de éxito, la estructura puede ser devuelta de varias maneras dependiendo de las opciones; la estructura puede ser analizada por el programa o el buffer crudo puede ser impreso en la salida estándar.

OPCIONES

-n <nsid>, --namespace-id=<nsid>

Recupera la estructura identify-namespace para el nsid dado. Esto es requerido para los dispositivos de caracteres, o anula el nsid del bloque si se proporciona. Si el controlador soporta la capacidad de gestión de namespaces y se proporciona 0xFFFFFFFF, entonces el controlador devuelve la estructura identify-namespace que especifica capacidades comunes entre namespaces para el controlador.

--force

Solicita al controlador que devuelva la estructura identify-namespace incluso si el namespace no está adjunto al controlador. Esto es válido solo para controladores de revisión 1.2 o posterior. Los controladores de revisión inferior a esta pueden interpretar el comando incorrectamente.

-b, --raw-binary

Imprime el buffer crudo en la salida estándar. La estructura no es analizada por el programa. Esto anula las opciones vendor-specific y human-readable.

-V, --vendor-specific

Además de analizar los campos conocidos, esta opción volcará la región específica del proveedor de la estructura en hexadecimal con interpretación ASCII.

-H, --human-readable

Esta opción analizará y formateará muchos de los campos de bits en formatos legibles por humanos.

-o <fmt>, --output-format=<fmt>

Establece el formato de reporte a normal, json o binary. Solo se puede usar un formato de salida a la vez.

-v, --verbose

Aumenta el nivel de detalle de la información en la salida.

EJEMPLOS

•Que el programa interprete el buffer devuelto y muestre los campos conocidos en un formato legible por humanos: 
# nvme id-ns /dev/nvme0n1
•Si se utiliza el dispositivo de caracteres o se anula el ID del namespace: 
# nvme id-ns /dev/nvme0 -n 1
# nvme id-ns /dev/nvme0n1 -n 1
# nvme id-ns /dev/nvme0 --namespace-id=1
•Además de mostrar los campos conocidos, hacer que el programa muestre el campo específico del proveedor: 
# nvme id-ns /dev/nvme0n1 --vendor-specific
# nvme id-ns /dev/nvme0n1 -V

Lo anterior volcará el buffer 'vs' en hexadecimal ya que no sabe cómo interpretarlo.

•Que el programa devuelva la estructura cruda en binario: 
# nvme id-ns /dev/nvme0n1 --raw-binary > id_ns.raw
# nvme id-ns /dev/nvme0n1 -b > id_ns.raw

Probablemente sea una mala idea no redirigir la salida estándar al usar este modo.

•Alternativamente, puede que desee enviar los datos a otro programa que pueda analizar el buffer crudo. 
# nvme id-ns /dev/nvme0n1 --raw-binary | nvme_parse_id_ns

El programa de análisis en el ejemplo anterior puede ser un programa que muestre la estructura de la manera que desee. El siguiente programa es un ejemplo de este tipo que lo analizará y podrá aceptar la salida a través de una tubería ('|'), como se muestra en el ejemplo anterior, o puede hacer 'cat' de un buffer de salida guardado.

/* Archivo: nvme_parse_id_ns.c */
#include <linux/nvme.h>
#include <stdio.h>
#include <unistd.h>
int main(int argc, char **argv)
{
        unsigned char buf[sizeof(struct nvme_id_ns)];
        struct nvme_id_ns *ns = (struct nvme_id_ns *)buf;
        if (read(STDIN_FILENO, buf, sizeof(buf)))
                return 1;
        printf("nsze : %#llx\n", ns->nsze);
        printf("ncap : %#llx\n", ns->ncap);
        return 0;
}
