NOMBRE

nvme-zns-set-zone-desc - Establecer datos de descriptor extendido para una zona

SINOPSIS

nvme zns set-zone-desc <dispositivo> [--namespace-id=<NUMERO> | -n <NUMERO>]
                        [--start-lba=<NUMERO_IO>, -s <NUMERO_IO>]
                        [--zrwaa | -r]
                        [--data=<ARCHIVO>, -d <ARCHIVO>]
                        [--timeout=<tiempo_espera> | -t <tiempo_espera>]

DESCRIPCIÓN

Para el dispositivo NVMe dado, emite el comando Zone Management Send con la acción Set Zone Descriptor Extensions. La entrada será por defecto la entrada estándar. Alternativamente, los datos pueden provenir de un archivo que se puede especificar. La longitud de los datos se calculará automáticamente a partir de la identificación del namespace zns.

OPCIONES

-n <NUMERO>, --namespace-id=<NUMERO>

Usa el id de namespace proporcionado para el comando. Si no se proporciona, se usará el id de namespace del dispositivo de bloque. Si el comando se emite a un dispositivo que no es de bloque, el parámetro es obligatorio.

-s <lba>, --start-lba=<lba>

El LBA de inicio de la zona a gestionar.

-r, --zrwaa

Asigna el área de escritura aleatoria de zona a la zona.

-d <ARCHIVO>, --data=<ARCHIVO>

Archivo opcional para los datos (por defecto stdin)

-t <tiempo_espera>, --timeout=<tiempo_espera>

Anula el valor de tiempo de espera predeterminado. En milisegundos.

EJEMPLOS

•Escribe "hello world" en el descriptor de zona para el primer zona del namespace 1 (requiere que el dispositivo soporte datos extendidos de zona lo suficientemente grandes) 
# echo "hello world" | nvme zns set-zone-desc /dev/nvme0 -n 1 -s 0
