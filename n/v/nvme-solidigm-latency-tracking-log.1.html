NOMBRE

nvme-solidigm-latency-tracking-log - Habilitar/Recuperar Registro de Seguimiento de Latencia

SINOPSIS

nvme solidigm latency-tracking-log <dispositivo> [--enable | -e] [--disable | -d]
                                              [--read | -r] [--write | -w]
                                              [--type <valor> | -t <valor>]
                                              [--output-format=<fmt> | -o <fmt>]

DESCRIPCIÓN

Habilita, deshabilita o recupera el registro de seguimiento de latencia de Solidigm para el dispositivo NVMe dado. Este registro proporciona información detallada sobre las latencias de E/S.

El parámetro <dispositivo> es obligatorio y puede ser tanto el dispositivo de caracteres NVMe (ej: /dev/nvme0), como un dispositivo de bloque de espacio de nombres (ej: /dev/nvme0n1).

OPCIONES

-e, --enable

Habilita el seguimiento de latencia antes de recuperar el registro.

-d, --disable

Deshabilita el seguimiento de latencia después de recuperar el registro.

-r, --read

Recupera estadísticas de latencia de lectura (por defecto si no se especifica ni --read ni --write).

-w, --write

Recupera estadísticas de latencia de escritura.

-t <valor>, --type <valor>

Especifica el tipo de registro a recuperar. Los valores válidos dependen de las capacidades del dispositivo.

-o <fmt>, --output-format=<fmt>

Establece el formato del informe a normal, json, o binary. Solo se puede usar un formato de salida a la vez.

EJEMPLOS

•Habilitar el seguimiento de latencia y recuperar el registro de latencia de lectura: 
# nvme solidigm latency-tracking-log /dev/nvme0 --enable --read
•Recuperar el registro de latencia de escritura en formato JSON: 
# nvme solidigm latency-tracking-log /dev/nvme0 --write -o json
•Deshabilitar el seguimiento de latencia después de recuperar el registro: 
# nvme solidigm latency-tracking-log /dev/nvme0 --disable
•Especificar un tipo de registro al recuperar estadísticas de latencia: 
# nvme solidigm latency-tracking-log /dev/nvme0 --type 1 --read
