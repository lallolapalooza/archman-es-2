NOMBRE

nvme-sndk-cu-smart-log - Envía el Comando Único del Vendedor Sandisk cu-smart-log de NVMe, devuelve el resultado

SINOPSIS

nvme sndk cu-smart-log <dispositivo> [--output-format=<normal|json> -o <normal|json>]
                        [--uuid-index=<indice-uuid> | -u <indice-uuid>]

DESCRIPCIÓN

Para el dispositivo NVMe dado, recupera y formatea la página de log 0xCA Única del Vendedor Sandisk.

El parámetro <dispositivo> es obligatorio y puede ser el dispositivo de carácter NVMe (ej: /dev/nvme0) o el dispositivo de bloque (ej: /dev/nvme0n1).

Esto solo funcionará en dispositivos Sandisk que soporten esta característica. Los resultados para cualquier otro dispositivo no están definidos.

En caso de éxito devuelve 0, código de error en caso contrario.

OPCIONES

-o <fmt>, --output-format=<fmt>

Establece el formato de reporte a normal o json. Solo se puede usar un formato de salida a la vez. Por defecto es normal.

-u <indice-uuid>, --uuid-index=<indice-uuid>

Establece el índice uuid de la página de log a recuperar. Por defecto es 0 si no se proporciona.

EJEMPLOS

•Hace que el programa emita el Comando del plugin Sandisk cu-smart-log: 
# nvme sndk cu-smart-log /dev/nvme0
