NVME-SET-FEATURE(1) Manual NVMe NVME-SET-FEATURE(1)

NOMBRE

nvme-set-feature - Establece una característica NVMe, devuelve los resultados aplicables

SINOPSIS

nvme set-feature <dispositivo> [--namespace-id=<nsid> | -n <nsid>]
                        [--feature-id=<fid> | -f <fid>] [--value=<value> | -V <value>]
                        [--uuid-index=<uuid-index> | -U <uuid_index>]
                        [--data-len=<data-len> | -l <data-len>]
                        [--data=<data-file> | -d <data-file>] [--save | -s]
                        [--output-format=<fmt> | -o <fmt>] [--verbose | -v]
                        [--cdw12=<cdw12> | -c <cdw12>]
                        [--timeout=<timeout> | -t <timeout>]

DESCRIPCIÓN

Envía un comando de administración NVMe Set Feature y devuelve los resultados aplicables. Esto puede ser el valor de la característica, o también puede incluir una estructura de característica si la característica lo requiere (por ejemplo, Tipo de Rango LBA).

El parámetro <dispositivo> es obligatorio y puede ser el dispositivo de caracteres NVMe (por ejemplo, /dev/nvme0) o un dispositivo de bloque de espacio de nombres (por ejemplo, /dev/nvme0n1).

En caso de éxito, se muestra el valor enviado al dispositivo.

OPCIONES

-n <nsid>, --namespace-id=<nsid>

Establece la característica para el nsid dado. Esto es opcional y la mayoría de las características no utilizan este valor.

El id de la característica a enviar con el comando. El valor proporcionado debe estar en hexadecimal.

-l <data-len>, --data-len=<data-len>

La longitud de los datos para el búfer enviado para esta característica. La mayoría de las características conocidas no utilizan este valor. Las excepciones son el Tipo de Rango LBA y el identificador del host.

-d <data-file>, --data=<data-file>

El archivo de datos para el búfer enviado para esta característica. La mayoría de las características conocidas no utilizan este valor. Las excepciones son el Tipo de Rango LBA y el identificador del host. Esto, por defecto, usa STDIN para que se puedan canalizar archivos y `echo`.

-V <value>, --value=<value>

El valor para el comando dword 11, el valor al que desea establecer la característica.

-s, --save

Guarda el atributo para que persista a través de todos los estados de energía y reinicios.

-U <uuid-index>, --uuid-index=<uuid-index>

Índice UUID

-o <fmt>, --output-format=<fmt>

Use el formato de salida especificado. El valor puede ser binario, json, o raw.

-v, --verbose

Habilita la salida detallada.

-c <cdw12>, --cdw12=<cdw12>

Comando Dword 12.

-t <timeout>, --timeout=<timeout>

Tiempo de espera para el comando en segundos.

EJEMPLOS

Establece la característica "Number of Queues" (0x07) a 16 (0x10) para el
dispositivo /dev/nvme0:
# nvme set-feature /dev/nvme0 -f 0x07 -V 0x10

Guarda la característica "Volatile Write Cache" (0x06) en activado (1) para el
dispositivo /dev/nvme0:
# nvme set-feature /dev/nvme0 -f 0x06 -V 1 -s

Establece el tipo de rango LBA para el namespace 1 en /dev/nvme0, utilizando
datos de un archivo:
# nvme set-feature /dev/nvme0 -n 1 -f 0x03 -l 32 -d lba_range_data.bin

Obtiene el identificador del host para el dispositivo /dev/nvme0:
# nvme get-feature /dev/nvme0 -f 0x81

nvme-set-feature(1) — NVMe

NAME

nvme-set-feature - Set a feature on an NVMe controller or namespace

SYNOPSIS

nvme set-feature [<generic options>] [<transport-specific options>] [<path>] -f <feature_id> [-l <length>] [-U <uuid>] [-V <value>]

DESCRIPTION

Given an NVMe device path, this command writes a specific feature value to the device. The feature id and value are specified using the command line arguments.

The supported features depend on the controller and firmware version.

The command format is flexible enough that it can be used to set most features. The following options are available:

OPTIONS

<path>
Specifies the NVMe device to operate on. This can be a device node like /dev/nvme0 or /dev/nvme0n1.
-f <feature_id>, --feature-id=<feature_id>
The identifier for the feature to set. This can be specified as a decimal or hexadecimal number. Some common feature IDs include:

• 0x01: Arbitration Burst

• 0x02: High Priority Reference Burst

• 0x03: Interrupt Coalescing

• 0x04: Interrupt Mask

• 0x05: Feature Value Preservation

• 0x06: Volatile Write Cache

• 0x07: Number Of Queues

• 0x08: Write Atomicity

• 0x09: Async Event Configuration

• 0x0A: Power State Transition Latency Data

• 0x0C: Temperature Threshold

• 0x0D: Sanitize Settings

• 0x0E: Error Recovery Settings

• 0x7F: Host Behavior Enhancements

• 0x81: Host Identifier

• 0xC0 - 0xFF: Vendor Specific Features

-l <length>, --length=<length>
The length of the data to be written for the feature. This is typically used for variable-length features like Host Identifier.
-U <uuid>, --uuid=<uuid>
The UUID to be written. This is used in conjunction with the Host Identifier feature (0x81) to set a specific UUID.
-V <value>, --value=<value>
The value to be written for the specified feature. This can be a decimal or hexadecimal number. For some features, the value might be composed of multiple fields, which need to be combined appropriately.
-o <fmt>, --output-format=<fmt>
Set the reporting format to normal, json or binary. Only one output format can be used at a time.
-v, --verbose
Increase the information detail in the output.
-c <cdw12>, --cdw12=<cdw12>
The value for command dword 12, if applicable.
-t <timeout>, --timeout=<timeout>
Override default timeout value. In milliseconds.

EXAMPLES

•Sets the Power State (PS) to 1 in feature id 2: 
# nvme set-feature /dev/nvme0 -f 2 /dev/nvme0n1 -V 0x1
•Sets the host id to the ascii string. 
# echo "abcdefgh" | nvme set-feature /dev/nvme0 -f 0x81 -l 8

nvme set-feature /dev/nvme0 -f 0x81 -l 8 -U 0x1
