NOMBRE

nvme-ocp-telemetry-string-log - Recuperar la página de registro de cadena de telemetría OCP

SINOPSIS

nvme ocp telemetry-string-log <dispositivo>
                        [--output-format=<fmt> | -o <fmt>]
                        [--output-file=<archivo> | -f <archivo>]

DESCRIPCIÓN

Para el dispositivo NVMe dado, recuperar la página de registro de cadena de telemetría OCP

El parámetro <dispositivo> es obligatorio y puede ser el dispositivo de caracteres NVMe (ej: /dev/nvme0) o el dispositivo de bloque (ej: /dev/nvme0n1).

Esto solo funcionará en dispositivos compatibles con OCP que admitan esta función. Los resultados para cualquier otro dispositivo no están definidos.

En caso de éxito devuelve 0, código de error en caso contrario.

OPCIONES

-o <fmt>, --output-format=<fmt>

Esta opción establecerá el formato de informe en normal, json o binario. Solo se puede utilizar un formato de salida a la vez.

-f <archivo>, --output-file=<archivo>

Nombre de la ruta del archivo donde se guardarán los datos de salida binarios.

EJEMPLOS

•Hacer que el programa emita un comando telemetry-string-log para obtener los datos del registro del archivo bin. 
# nvme ocp telemetry-string-log /dev/nvme0n1
