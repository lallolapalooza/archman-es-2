NVME-WRITE(1) Manual de NVMe NVME-WRITE(1)

NOMBRE

nvme-write - Envía un comando de escritura NVMe, proporciona resultados

SINOPSIS

nvme-write <dispositivo> [--start-block=<slba> | -s <slba>]
                        [--block-count=<nlb> | -c <nlb>]
                        [--block-size=<tamaño> | -b <tamaño>]
                        [--data-size=<tamaño> | -z <tamaño>]
                        [--metadata-size=<tamaño> | -y <tamaño>]
                        [--ref-tag=<reftag> | -r <reftag>]
                        [--data=<archivo-datos> | -d <archivo-datos>]
                        [--metadata=<archivo-metadatos> | -M <archivo-metadatos>]
                        [--prinfo=<prinfo> | -p <prinfo>]
                        [--app-tag-mask=<appmask> | -m <appmask>]
                        [--app-tag=<apptag> | -a <apptag>]
                        [--limited-retry | -l] [--force-unit-access | -f]
                        [--dir-type=<tipo> | -T <tipo>]
                        [--dir-spec=<spec> | -S <spec>] [--dsm=<dsm> | -D <dsm>]
                        [--show-command | -V] [--dry-run | -w] [--latency | -t]
                        [--storage-tag<storage-tag> | -g <storage-tag>]
                        [--storage-tag-check | -C] [--force]
                        [--output-format=<fmt> | -o <fmt>] [--verbose | -v]
                        [--timeout=<timeout>]

DESCRIPCIÓN

El comando Write escribe los bloques lógicos especificados por el comando en el medio desde el búfer de datos proporcionado. Usará la entrada estándar por defecto si no se proporciona un archivo.

OPCIONES

-s <slba>, --start-block=<slba>

Bloque de inicio.

-c, --block-count

El número de bloques a transferir. Este es un valor basado en ceros para alinearse con el uso de este campo por parte del kernel (es decir, 0 significa transferir 1 bloque).

-b <tamaño>, --block-size=<tamaño>

Si se especifica, el tamaño lógico del bloque en bytes, con metasize describiendo también el tamaño de metadatos para un bloque individual. De lo contrario, se descubre mediante la identificación del espacio de nombres.

-z <tamaño>, --data-size=<tamaño>

Tamaño de los datos, en bytes.

-y <tamaño>, --metadata-size=<tamaño>

Tamaño de los metadatos en bytes.

-d <archivo-datos>, --data=<archivo-datos>

Archivo de datos. Si no se proporciona ninguno, los contenidos se envían desde STDIN.

-M <archivo-metadatos>, --metadata=<archivo-metadatos>

Archivo de metadatos, si es necesario.

-p <prinfo>, --prinfo=<prinfo>

Definición del campo Información de Protección.
Bit Descripción
3 PRACT: Acción de Información de Protección. Cuando se establece en 1, PI se elimina/inserta en lectura/escritura cuando el tamaño de metadatos del formato del bloque es 8. Cuando se establece en 0, los metadatos se pasan.
2:0 PRCHK: Comprobación de Información de Protección:
2 Establecer en 1 habilita la comprobación de la etiqueta de guardia
1 Establecer en 1 habilita la comprobación de la etiqueta de aplicación
0 Establecer en 1 habilita la comprobación de la etiqueta de referencia

-r <reftag>, --ref-tag=<reftag>

Etiqueta de referencia opcional cuando se usa con información de protección.

-m <appmask>, --app-tag-mask=<appmask>

Máscara de etiqueta de aplicación opcional cuando se usa con información de protección.

-a <apptag>, --app-tag=<apptag>

Etiqueta de aplicación opcional cuando se usa con información de protección.

-l, --limited-retry

Establece la bandera de reintento limitado.

-f, --force-unit-access

Establece la bandera de acceso forzado a la unidad.

-T <tipo>, --dir-type=<tipo>

Tipo de directiva opcional. `nvme-cli` solo valida que el valor esté en el rango definido para el tipo de directiva, aunque la especificación NVMe (1.3a) define solo una directiva, 01h, para identificadores de flujo de escritura.

-S <spec>, --dir-spec=<spec>

Campo opcional para especificaciones de directiva. Cuando se usa con flujos de escritura, este valor se define como el identificador del flujo de escritura. `nvme-cli` no validará que el flujo solicitado esté dentro de las capacidades del controlador.

-D <dsm>, --dsm=<dsm>

Los atributos opcionales de gestión del conjunto de datos para este comando. El argumento para esto son los 8 bits menos significativos del campo DSM en un comando de escritura; los 16 bits más significativos del campo provienen del campo específico de la directiva, si se usa. Esto puede usarse para establecer atributos para los LBA que se están escribiendo, como la frecuencia de acceso, el tipo, la latencia, entre otras cosas, así como tipos aún por definir. Consulte la especificación NVMe para obtener un desglose detallado de cómo usar este campo.

-V, --show-cmd

Imprime el comando que se enviará.

-w, --dry-run

No envía realmente el comando. Si se desea usar la opción --dry-run, la opción --show-cmd *debe* establecerse. De lo contrario, la opción --dry-run se *ignora*.

-t, --latency

Imprime la latencia que tomó la llamada IOCTL (en microsegundos).

-g <storage-tag>, --storage-tag=<storage-tag>

Etiqueta de Almacenamiento Lógico Esperada de Tamaño Variable (ELBST).

-C, --storage-tag-check

Esta bandera habilita la comprobación del campo Etiqueta de Almacenamiento como parte del procesamiento de protección de datos de extremo a extremo.

--force

Ignora que el espacio de nombres esté actualmente ocupado y realiza la operación a pesar de ello.

-o <fmt>, --output-format=<fmt>

Establece el formato de informe en *normal*, *json* o *binary*. Solo se puede usar un formato de salida a la vez.

-v, --verbose

Aumenta el nivel de detalle de la información en la salida.

--timeout=<timeout>

Anula el valor de tiempo de espera predeterminado. En milisegundos.
