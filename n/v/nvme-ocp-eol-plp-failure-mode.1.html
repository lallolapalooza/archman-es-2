nvme-ocp-eol-plp-failure-mode(1)

NVME-OCP-EOL-PLP() NVME-OCP-EOL-PLP()

NOMBRE

nvme-ocp-eol-plp-failure-mode - Define e imprime el modo de fallo del circuito EOL o PLP

SINOPSIS

nvme ocp eol-plp-failure-mode <dispositivo> [--mode=<modo> | -m <modo>]
                        [--no-uuid | -n] [--save | -s]
                        [--sel=<select> | -S <select>]

DESCRIPCIÓN

Define el modo de fallo del circuito EOL o PLP. Sin argumentos, imprime el modo actual.

El parámetro <dispositivo> es obligatorio y puede ser tanto el dispositivo de caracteres NVMe (ej: /dev/nvme0) como el dispositivo de bloque (ej: /dev/nvme0n1).

Esto solo funcionará en dispositivos compatibles con OCP que soporten esta característica. Los resultados para cualquier otro dispositivo no están definidos.

En caso de éxito devuelve 0, código de error en caso contrario.

OPCIONES

-m <modo>, --mode=<modo>

Establece el modo de fallo del circuito EOL o PLP a [0-3] (0: por defecto, 1: rom, 2: wtm o 3: normal). Solo se puede usar un modo a la vez. El valor por defecto es rom.

-n, --no-uuid

No intente detectar automáticamente el índice UUID para este comando (requerido para soporte de OCP 1.0 antiguo)

-s, --save

Guarda el atributo para que persista a través de todos los estados de energía y reinicios.

-s <select>, --sel=<select>

Seleccionar (SEL): Este campo especifica qué valor de los atributos se devuelve en los datos proporcionados:
Seleccionar Descripción
0 Actual
1 Por defecto
2 Guardado
3 Capacidades soportadas
4-7 Reservado

EJEMPLOS

•Haga que el programa emita un eol-plp-failure-mode para recuperar las características de obtención 0xC2. 
# nvme ocp eol-plp-failure-mode /dev/nvme0
