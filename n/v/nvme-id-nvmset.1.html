NOMBRE

nvme-id-nvmset - Envía la lista de identificación NVMe NVM Set, devuelve el resultado y la estructura

SINOPSIS

nvme id-nvmset <dispositivo> [--nvmset_id=<id> | -i <id>]
                        [--output-format=<fmt> | -o <fmt>] [--verbose | -v]

DESCRIPCIÓN

Para el dispositivo NVMe dado, envía un comando de identificación de lista de NVM Set NVMe y proporciona el resultado y la estructura devuelta.

El parámetro <dispositivo> es obligatorio y puede ser el dispositivo de caracteres NVMe (ej: /dev/nvme0), o un dispositivo de bloque de namespace (ej: /dev/nvme0n1).

En caso de éxito, la estructura puede devolverse de varias maneras dependiendo de las banderas de opción; la estructura puede ser analizada por el programa o el buffer crudo puede imprimirse en la salida estándar.

OPCIONES

-i <id>, --nvmset_id=<id>

Este campo especifica el identificador del NVM Set. Si se proporciona, el identificador del NVM set cuya entrada debe estar en los datos del resultado será mayor o igual a este valor.

-o <fmt>, --output-format=<fmt>

Establece el formato de reporte a normal, json o binary. Solo se puede usar un formato de salida a la vez.

-v, --verbose

Aumenta el nivel de detalle de la información en la salida.

EJEMPLOS

•Hacer que el programa interprete el buffer devuelto y muestre los campos conocidos en un formato legible por humanos: 
# nvme id-nvmset /dev/nvme0
•Hacer que el programa devuelva la estructura cruda en formato binario: 
# nvme id-nvmset /dev/nvme0 --output-format=binary > id_nvmset.raw
# nvme id-nvmset /dev/nvme0 -o binary > id_nvmset.raw

Probablemente sea una mala idea no redirigir la salida estándar al usar este modo.

•Alternativamente, puede que desee enviar los datos a otro programa que pueda analizar el buffer crudo. 
# nvme id-nvmset /dev/nvme0 -o binary | nvme_parse_id_nvmset

El programa de análisis en el ejemplo anterior puede ser un programa que muestre la estructura de la manera que prefiera. El siguiente programa es un ejemplo de este tipo que lo analizará y puede aceptar la salida a través de una tubería, '|', como se muestra en el ejemplo anterior, o puede concatenar ('cat') un buffer de salida guardado.
