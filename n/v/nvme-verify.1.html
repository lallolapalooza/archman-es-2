NOMBRE

nvme-verify - Envía un comando NVMe Verify, devuelve resultados

SINOPSIS

nvme-verify <dispositivo> [--namespace-id=<nsid> | -n <nsid>]
                        [--start-block=<slba> | -s <slba>]
                        [--block-count=<nlb> | -c <nlb>] [--limited-retry | -l]
                        [--force-unit-access | -f]
                        [--prinfo=<prinfo> | -p <prinfo>]
                        [--ref-tag=<reftag> | -r <reftag>]
                        [--app-tag-mask=<appmask> | -m <appmask>]
                        [--app-tag=<apptag> | -a <apptag>]
                        [--storage-tag<storage-tag> | -S <storage-tag>]
                        [--storage-tag-check | -C]
                        [--output-format=<fmt> | -o <fmt>] [--verbose | -v]
                        [--timeout=<timeout> | -t <timeout>]

DESCRIPCIÓN

El comando Verify verifica la integridad de la información almacenada leyendo datos y metadatos.

OPCIONES

-n <nsid>, --namespace-id=<nsid>

ID de Namespace a usar en el comando.

-s <slba>, --start-block=<slba>

Dirección del bloque de inicio.

-c <nlb>, --block-count=<nlb>

Número de bloques lógicos a verificar.

-l, --limited-retry

Establece el indicador de reintento limitado.

-f, --force-unit-access

Establece el indicador de acceso forzado a la unidad.

-p <prinfo>, --prinfo=<prinfo>

Definición del campo de Información de Protección.
Bit Descripción
3 PRACT: Acción de Información de Protección. Cuando se establece en 1, PI se extrae/inserta en lectura/escritura cuando el tamaño de metadatos del formato de bloque es 8. Cuando se establece en 0, se pasan los metadatos.
2:0 PRCHK: Verificación de Información de Protección:
2 Establecer en 1 habilita la verificación de la etiqueta de guarda
1 Establecer en 1 habilita la verificación de la etiqueta de aplicación
0 Establecer en 1 habilita la verificación de la etiqueta de referencia

-r <reftag>, --ref-tag=<reftag>

Etiqueta de referencia opcional cuando se usa con información de protección.

-m <appmask>, --app-tag-mask=<appmask>

Máscara de etiqueta de aplicación opcional cuando se usa con información de protección.

-a <apptag>, --app-tag=<apptag>

Etiqueta de aplicación opcional cuando se usa con información de protección.

-S <storage-tag>, --storage-tag=<storage-tag>

Etiqueta de Almacenamiento Lógico Esperada de Tamaño Variable (ELBST).

-C, --storage-tag-check

Este indicador habilita la verificación del campo Etiqueta de Almacenamiento como parte de la operación Verify.

-o <fmt>, --output-format=<fmt>

Establece el formato de informe a normal, json o binary. Solo se puede usar un formato de salida a la vez.

-v, --verbose

Aumenta el nivel de detalle de la información en la salida.

-t <timeout>, --timeout=<timeout>

Anula el valor de tiempo de espera predeterminado. En milisegundos.
