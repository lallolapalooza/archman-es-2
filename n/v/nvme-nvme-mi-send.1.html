NOMBRE

nvme-nvme-mi-send - Envía un comando NVMe-MI Send al dispositivo especificado

SINOPSIS

nvme nvme-mi-send <dispositivo> [--opcode=<código_operación> | -O <código_operación>]
                        [--namespace-id=<nsid> | -n <nsid>]
                        [--data-len=<longitud_datos> | -l <longitud_datos>]
                        [--nmimt=<tipo_mensaje_mi> | -m <tipo_mensaje_mi>]
                        [--nmd0=<nmd0> | -0 <nmd0>] [--nmd1=<nmd1> | -1 <nmd1>]
                        [--input-file=<archivo> | -i <archivo>]
                        [--output-format=<formato> | -o <formato>] [--verbose | -v]

DESCRIPCIÓN

Envía un comando NVMe-MI Send al dispositivo especificado, y devuelve los resultados.

El parámetro <dispositivo> es obligatorio y puede ser tanto el dispositivo de caracteres NVMe (ej: /dev/nvme0) como el dispositivo de bloques (ej: /dev/nvme0n1).

En caso de éxito devuelve 0, código de error en caso contrario.

OPCIONES

-O <código_operación>, --opcode=<código_operación>

El código de operación NVMe-MI a enviar al dispositivo en el comando. Argumento requerido ya que este parámetro es obligatorio.

-n <nsid>, --namespace-id=<nsid>

El valor para el ns-id en el comando.

-l <longitud_datos>, --data-len=<longitud_datos>

La longitud de los datos para el búfer utilizado en este comando.

-m <tipo_mensaje_mi>, --nmimt=<tipo_mensaje_mi>

El valor para el tipo de mensaje NVMe-MI en el comando.

-0 <nmd0>, --nmd0=<nmd0>

El valor para el dword 0 de la solicitud de gestión NVMe en el comando.

-1 <nmd1>, --nmd1=<nmd1>

El valor para el dword 1 de la solicitud de gestión NVMe en el comando.

-i <archivo>, --input-file=<archivo>

Si el comando es un comando de salida de datos (escritura), usa este archivo para rellenar el búfer enviado al dispositivo. Si no se proporciona archivo, se asume STDIN.

-o <formato>, --output-format=<formato>

Establece el formato de informe a normal, json o binary. Solo se puede usar un formato de salida a la vez.

-v, --verbose

Aumenta el detalle de la información en la salida.

EJEMPLOS

•Hacer que el programa emita un nvme-mi-send para ejecutar la escritura VPD. 
# nvme nvme-mi-send /dev/nvme0n1 -O 6 -m 1 -0 0 -1 0x100 -l 256 -i vpd.bin
