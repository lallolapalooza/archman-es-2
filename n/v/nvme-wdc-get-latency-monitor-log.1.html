NOMBRE

nvme-wdc-get-latency-monitor-log - Muestra los datos de la página del registro del monitor de latencia en formato legible para humanos

SINOPSIS

nvme wdc get-latency-monitor-log <dispositivo> [--output-format=<normal|json> -o <normal|json>]

DESCRIPCIÓN

Para el dispositivo NVMe dado, los datos de la página del registro del monitor de latencia.

El parámetro <dispositivo> es el dispositivo de carácter NVMe obligatorio (ej: /dev/nvme0).

Esto solo funcionará en dispositivos WDC que soporten esta página de registro. Los resultados para cualquier otro dispositivo no están definidos.

En caso de éxito devuelve 0, código de error en caso contrario.

OPCIONES

-o <fmt>, --output-format=<fmt>

Establece el formato de reporte a normal o json. Solo se puede usar un formato de salida a la vez. El predeterminado es normal.

EJEMPLOS

•Muestra el registro del monitor de latencia para el dispositivo: 
# nvme wdc get-latency-monitor-log /dev/nvme0
