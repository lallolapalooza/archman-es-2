NOMBRE

nvme-micron-smart-add-log - Recupera estadísticas NAND (modelos 2200) o información SMART extendida (modelos compatibles con OCP) del dispositivo micron especificado

SINOPSIS

nvme micron vs-smart-add-log <dispositivo> -f <json|normal>

DESCRIPCIÓN

Este comando imprime información NAND (bytes totales escritos, recuento de bloques defectuosos y fallos de borrado, etc.) para el dispositivo micron dado si es del controlador modelo 2200. Para controladores compatibles con OCP, este comando imprime datos de salud SMART extendidos junto con información NAND (si está disponible).

El parámetro <dispositivo> es obligatorio y puede ser tanto el dispositivo de caracteres NVMe (ej: /dev/nvme0), como un dispositivo de bloque de namespace (ej: /dev/nvme0n1).

La opción -f controla el formato de los datos de salida mostrados según el valor de la opción. Si el valor de la opción es json (que está habilitado por defecto), los datos de salida se imprimen en formato JSON. Si el valor de la opción es normal, la salida se muestra en formato no JSON.

Esto solo funcionará en dispositivos Micron de números de modelo 54XX y controladores compatibles con OCP. Es posible que se agregue soporte para nuevos dispositivos posteriormente.

OPCIONES

-f <json|normal>

Controla el formato de la salida mostrada.

EJEMPLOS

• Recuperar datos SMART NAND/extendidos y mostrarlos en formato json 
# nvme micron vs-nand-stats /dev/nvme0
* Recuperar datos SMART NAND/extendidos y mostrarlos en formato no json
+

# nvme micron vs-nand-stats /dev/nvme0 -f normal
