NOMBRE

nvme-intel-internal-log - Recupera el registro interno del dispositivo Intel y lo guarda en un archivo.

SINOPSIS

'nvme intel internal-log ' <dispositivo> [--log=<NUM>, -l <NUM>]
                [--region=<NUM>, r <NUM>]
                [--nlognum=<NUM>, m <NUM>]
                [--namespace-id=<NUM>, -n <NUM>]
                [--output-file=<ARCHIVO>, -o <ARCHIVO>]

DESCRIPCIÓN

Para el dispositivo NVMe dado, envía la solicitud de registro de dispositivo específica del proveedor Intel y guarda el resultado en un archivo.

El parámetro <dispositivo> es obligatorio y puede ser tanto el dispositivo de caracteres NVMe (ej: /dev/nvme0), como un dispositivo de bloque de namespace (ej: /dev/nvme0n1). Si se utiliza el dispositivo de caracteres, el parámetro de ID de namespace es obligatorio.

Esto solo funcionará en dispositivos Intel que soporten esta característica, que incluye (pero no se limita a) todos los controladores de la familia Intel DC P3xxx. Los resultados para cualquier otro dispositivo no están definidos.

OPCIONES

-l <NUM>, --log=<NUM>

Tipo de registro: 0, 1 o 2 para nlog, registro de eventos y registro de aserción, respectivamente.

-n <NUM>, --namespace-id=<NUM>

Namespace a utilizar.

-o <ARCHIVO>, --output-file=<ARCHIVO>

Archivo de salida; por defecto es el nombre del dispositivo proporcionado.

-r <NUM>, --region=<NUM>

Selecciona qué región principal recuperar el registro. -1 para todas las disponibles, si es compatible con el dispositivo.

-m <NUM>, --nlognum=<NUM>

Cuando se utiliza con nlog, especifica qué nlog leer. -1 para todos, si es compatible con el dispositivo.

EJEMPLOS

•Obtiene el nlog del dispositivo y lo guarda en el archivo por defecto: 
# nvme intel internal-log /dev/nvme0 --namespace-id=1 --log=0
•Obtiene el registro de eventos del dispositivo y lo guarda en un archivo definido: 
# nvme intel internal-log /dev/nvme0 --namespace-id=1 --log=1 --output-file=MiGranRegistroDeEventos
