NOMBRE

nvme-sndk-vs-internal-log - Recupera el registro interno del firmware del dispositivo sndk y lo guarda en un archivo.

SINOPSIS

nvme sndk vs-internal-log <dispositivo> [--output-file=<ARCHIVO>, -o <ARCHIVO>]
                        [--transfer-size=<TAMAÑO>, -s <TAMAÑO>]
                        [--data-area=<ÁREA DE DATOS>, -d <ÁREA_DE_DATOS>]
                        [--file-size=<TAMAÑO DEL ARCHIVO>, -f <TAMAÑO DEL ARCHIVO>]
                        [--offset=<DESPLAZAMIENTO>, -e <DESPLAZAMIENTO>]
                        [--type=<TIPO>, -t <tipo>] [--verbose, -v]

DESCRIPCIÓN

Para el dispositivo NVMe dado, envía la solicitud de registro interno específico del proveedor sndk y guarda el resultado en un archivo.

El parámetro <dispositivo> es un dispositivo de caracteres NVMe obligatorio (ej: /dev/nvme0).

Esto solo funcionará en dispositivos Sandisk que soporten esta característica. Los resultados para cualquier otro dispositivo no están definidos.

OPCIONES

-o <ARCHIVO>, --output-file=<ARCHIVO>

Archivo de salida; por defecto es el número de serie del dispositivo seguido del sufijo "internal_fw_log<fecha>_<hora>.bin"

-s <TAMAÑO>, --transfer-size=<TAMAÑO>

Tamaño de transferencia; por defecto es 0x10000 (65536 decimal) bytes

-d <ÁREA DE DATOS>, --data-area=<ÁREA DE DATOS>

Área de datos DUI a recuperar. Se recuperarán las áreas de datos DUI desde 1 hasta <ÁREA DE DATOS>. Este parámetro actualmente solo se soporta en los dispositivos SN340, SN640, SN730 y SN840.

-f <TAMAÑO DEL ARCHIVO>, --file-size=<TAMAÑO DEL ARCHIVO>

Especifica el tamaño deseado del archivo de datos comenzando en el desplazamiento proporcionado. Esto permite al usuario recuperar los datos en varios archivos más pequeños del tamaño proporcionado. Este parámetro actualmente solo se soporta en el dispositivo SN340.

-e <DESPLAZAMIENTO>, --offset=<DESPLAZAMIENTO>

Especifica el desplazamiento de datos en el que comenzar a recuperar los datos. Este parámetro se usa en combinación con el parámetro de tamaño de archivo para recuperar los datos en varios archivos más pequeños. Este parámetro actualmente solo se soporta en el dispositivo SN340.

-t <TIPO>, --type=<TIPO>

Especifica el tipo de telemetría: NONE, HOST o CONTROLLER. Este parámetro se utiliza para obtener la página de registro de telemetría generada por el host o iniciada por el controlador. Si no se especifica o se especifica "none", el comando devolverá los datos de registro E6 por defecto. Este parámetro actualmente solo se soporta en los dispositivos SN640 y SN840.

-v <VERBOSO>, --verbose=<VERBOSO>

Proporciona mensajes de depuración adicionales para ciertas unidades.

EJEMPLOS

•Obtiene el registro interno del firmware del dispositivo y lo guarda en un archivo por defecto en el directorio actual (ej: STM00019F3F9_internal_fw_log_20171127_095704.bin): 
# nvme sndk vs-internal-log /dev/nvme0
•Obtiene el registro interno del firmware del dispositivo y lo guarda en un archivo definido en el directorio actual (ej: test.bin): 
# nvme sndk vs-internal-log /dev/nvme0 -o test.bin
•Obtiene el registro interno del firmware del dispositivo y lo guarda en un archivo con ruta (ej: /tmp/test): 
# nvme sndk vs-internal-log /dev/nvme0 -o /tmp/test
•Obtiene el registro interno del firmware del dispositivo transfiriendo los datos en fragmentos de 64k y lo guarda en un archivo por defecto en el directorio actual (ej: STM00019F3F9_internal_fw_log_20171127_100754.bin): 
# nvme sndk vs-internal-log /dev/nvme0 -s 0x10000
•Obtiene el registro interno del firmware del dispositivo transfiriendo los datos en fragmentos de 16k y lo guarda en un archivo por defecto en el directorio actual (ej: STM00019F3F9_internal_fw_log_20171127_100950.bin): 
# nvme sndk vs-internal-log /dev/nvme0 -s 16384
•Obtiene el registro interno del firmware hasta el área de datos 3 del dispositivo en 3 archivos de 0x1000000 bytes: 
# nvme sndk vs-internal-log /dev/nvme0 -d 3 -f 0x1000000 -t 0x0000000 -o /tmp/sn340_dui_data_1.bin
# nvme sndk vs-internal-log /dev/nvme0 -d 3 -f 0x1000000 -t 0x1000000 -o /tmp/sn340_dui_data_2.bin
# nvme sndk vs-internal-log /dev/nvme0 -d 3 -f 0x1000000 -t 0x2000000 -o /tmp/sn340_dui_data_3.bin
•Obtiene la página de registro de telemetría del host hasta el área de datos 3 del dispositivo y la almacena en el archivo host-telem-log-da3.bin: 
# nvme sndk vs-internal-log /dev/nvme1 -t host -o host-telem-log-da3.bin -d 3
•Obtiene la página de registro de telemetría del controlador hasta el área de datos 3 del dispositivo y la almacena en el archivo ctlr-telem-log-da3.bin: 
# nvme sndk vs-internal-log /dev/nvme1 -t controller -o ctlr-telem-log-da3.bin -d 3
