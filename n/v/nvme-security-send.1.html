NOMBRE

nvme-security-send - Comando Security Send

SINOPSIS

nvme security-send <dispositivo> [--file=<archivo> | -f <archivo>]
                        [--secp=<protocolo-seguridad> | -p <protocolo-seguridad>]
                        [--spsp=<protocolo-específico> | -s <protocolo-específico>]
                        [--tl=<longitud-transferencia> | -t <longitud-transferencia>]
                        [--nssf=<nvme-específico> | -N <nvme-específico>]
                        [--namespace-id=<nsid> | -n <nsid>]
                        [--output-format=<fmt> | -o <fmt>] [--verbose | -v]
                        [--timeout=<timeout>]

DESCRIPCIÓN

El comando Security Send se utiliza para transferir datos del protocolo de seguridad al controlador. La estructura de datos transferida al controlador como parte de este comando contiene comandos específicos del protocolo de seguridad que serán ejecutados por el controlador. La estructura de datos transferida también puede contener datos o parámetros asociados con los comandos del protocolo de seguridad. El estado y los datos que deben devolverse al host para los comandos del protocolo de seguridad enviados con un comando Security Send se recuperan con el comando Security Receive.

La asociación entre un comando Security Send y un comando Security Receive posterior depende del campo Security Protocol, según se define en SPC-4.

OPCIONES

-n <nsid>, --namespace-id=<nsid>

Dirigirse a un espacio de nombres específico para este comando de seguridad.

-N <nssf>, --nssf=<nssf>

Campo específico de seguridad NVMe. Si se utiliza el protocolo de seguridad EAh asignado para uso NVMe, el campo específico de seguridad NVMe indica el búfer de memoria de respuesta de destino.

-f <archivo>, --file=<archivo>

Ruta al archivo utilizado como carga útil del protocolo de seguridad. Argumento requerido.

-p <protocolo-seguridad>, --secp=<protocolo-seguridad>

Protocolo de Seguridad: Este campo especifica el protocolo de seguridad según se define en SPC-4. El controlador fallará el comando indicando Parámetro Inválido si se especifica un valor reservado del Protocolo de Seguridad.

-s <protocolo-específico-seguridad>, --spsp=<protocolo-específico-seguridad>

Específico de SP: El valor de este campo es específico del Protocolo de Seguridad según se define en SPC-4.

-t <longitud-transferencia>, --tl=<longitud-transferencia>

Longitud de Transferencia: El valor de este campo es específico del Protocolo de Seguridad según se define en SPC-4.

-o <fmt>, --output-format=<fmt>

Establecer el formato de reporte a normal, json o binary. Solo se puede usar un formato de salida a la vez.

-v, --verbose

Aumentar el nivel de detalle de la información en la salida.

--timeout=<timeout>

Anular el valor de tiempo de espera predeterminado. En milisegundos.
