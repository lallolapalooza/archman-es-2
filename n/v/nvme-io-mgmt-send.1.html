NOMBRE

nvme-io-mgmt-send - Comando de envío de gestión de I/O

SINTAXIS

nvme io-mgmt-send <dispositivo> [--namespace-id=<NUM> | -n <NUM>]
                        [--mos=<NUM> | -s <NUM>] [--mo=<NUM> | -m <NUM>]
                        [--data=<ARCHIVO> | -d <ARCHIVO>]
                        [--data-len=<NUM> | -l <NUM>]
                        [--output-format=<fmt> | -o <fmt>] [--verbose | -v]
                        [--timeout=<timeout> | -t <timeout>]

DESCRIPCIÓN

Para el dispositivo NVMe dado, emite el comando I/O Management Send con la operación de gestión solicitada (mo) y el parámetro específico de la operación de gestión (mos). Esta es la interfaz genérica proporcionada para la compatibilidad futura a medida que se agregan nuevas operaciones de las cuales este programa no es consciente en el momento de su desarrollo. Como tal, este es un comando genérico que no proporciona parámetros de conveniencia para producir la carga útil binaria.

OPCIONES

-n <NUM>, --namespace-id=<NUM>

Utiliza el ID de namespace proporcionado para el comando. Si no se proporciona, se utilizará el ID de namespace del dispositivo de bloque. Si el comando se emite a un dispositivo que no es de bloque, el parámetro es obligatorio.

-d <ARCHIVO>, --data=<ARCHIVO>

Archivo desde el cual leer la carga útil. Si no se especifica, los datos se leerán del flujo de entrada estándar.

-l <NUM>, --data-len=<NUM>

Longitud del búfer de datos de la carga útil.

-m <NUM>, --mo <NUM>

Operación de gestión a realizar.

-s <NUM>, --mos=<NUM>

Parámetro específico de la operación de gestión.

-o <fmt>, --output-format=<fmt>

Establece el formato de informe en normal, json o binary. Solo se puede usar un formato de salida a la vez.

-v, --verbose

Aumenta el nivel de detalle de la información en la salida.

-t <timeout>, --timeout=<timeout>

Anula el valor de tiempo de espera predeterminado. En milisegundos.
