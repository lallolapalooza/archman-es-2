NOMBRE

nvme-dsm - Envía NVMe Data Set Management, devuelve resultados

SINOPSIS

nvme dsm <dispositivo> [--namespace-id=<nsid> | -n <nsid>]
                        [--ctx-attrs=<lista-atributos,> | -a <lista-atributos,>]
                        [--blocks=<lista-bloques,> | -b <lista-bloques,>]
                        [--slbs=<lista-slba,> | -s <lista-slba,>]
                        [--ad=<deallocate> | -d <deallocate>]
                        [--idw=<write> | -w <write>] [--idr=<read> | -r <read>]
                        [--cdw11=<cdw11> | -c <cdw11>]
                        [--output-format=<fmt> | -o <fmt>] [--verbose | -v]
                        [--timeout=<timeout> | -t <timeout>]

DESCRIPCIÓN

Para el dispositivo NVMe dado, envía un comando Data Set Management y proporciona el resultado y la estructura devuelta.

El parámetro <dispositivo> es obligatorio y puede ser el dispositivo de caracteres NVMe (ej: /dev/nvme0) o un dispositivo de bloque de namespace (ej: /dev/nvme0n1). Si se proporciona el dispositivo de caracteres, la opción '--namespace-id' es obligatoria, de lo contrario utilizará el ns-id del namespace para el dispositivo de bloque que abriste. Para dispositivos de bloque, el ns-id utilizado puede ser anulado con la misma opción.

Debes especificar al menos uno de los valores para la lista de rangos. Si las listas de rangos proporcionadas no tienen el mismo número de elementos, los valores predeterminados para los restantes en el rango se establecerán en 0.

El dword de comando 11 puede proporcionarse en la línea de comandos. Para mayor comodidad, los atributos actualmente definidos (desasignar, lectura/escritura integral) para una gestión de conjuntos de datos tienen flags. Si se especifica cdw11, esto anulará cualquier configuración que las flags puedan haber proporcionado.

OPCIONES

-n <nsid>, --namespace-id=<nsid>

Envía el comando con el nsid solicitado. Esto es obligatorio para los dispositivos de caracteres, o anula el nsid del bloque si se proporciona.

-a <lista-atributos,>, --ctx-attrs=<lista-atributos>

Lista separada por comas de los atributos de contexto en cada rango.

-b <lista-bloques,>, --blocks=<lista-bloques,>

Lista separada por comas del número de bloques en cada rango.

-s <lista-slba,>, --slbs=<lista-slba,>

Lista separada por comas del bloque de inicio en cada rango.

-d <deallocate>, --ad=<deallocate>

Atributo Desasignar.

-w <write>, --idw=<write>

Atributo Conjunto de Datos Integral para Escritura.

-r <read>, --idr=<read>

Atributo Conjunto de Datos Integral para Lectura.

-c <cdw11>, --cdw11=<cdw11>

Todos los atributos del dword de comando 11. Usar exclusivamente en lugar de especificar atributos individuales.

-o <fmt>, --output-format=<fmt>

Establece el formato de informe en normal, json o binary. Solo se puede usar un formato de salida a la vez.

-v, --verbose

Aumenta el nivel de detalle de la información en la salida.

-t <timeout>, --timeout=<timeout>

Anula el valor de tiempo de espera predeterminado. En milisegundos.
