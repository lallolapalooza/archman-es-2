NOMBRE

nvme-dir-receive - Envía un comando de recepción de directiva, devuelve los resultados aplicables

SINOPSIS

nvme dir-receive <dispositivo> [--namespace-id=<nsid> | -n <nsid>]
                        [--data-len=<data-len> | -l <data-len>]
                        [--dir-type=<dtype> | -D <dtype>]
                        [--dir-spec=<dspec> | -S <dspec>]
                        [--dir-oper=<doper> | -O <doper>]
                        [--req-resource=<nsr> | -r <nsr>]
                        [--human-readable | -H] [--raw-binary | -b]
                        [--output-format=<fmt> | -o <fmt>] [--verbose | -v]
                        [--timeout=<timeout> | -t <timeout>]

DESCRIPCIÓN

Envía un comando de administración de recepción de directiva NVMe y devuelve los resultados aplicables. Esto puede ser la combinación del tipo de directiva y la operación, así como el número de recursos solicitados si la operación específica lo necesita.

El parámetro <dispositivo> es obligatorio y puede ser el dispositivo de caracteres NVMe (ej: /dev/nvme0) o un dispositivo de bloque de namespace (ej: /dev/nvme0n1).

En caso de éxito, la estructura de parámetros de la directiva devuelta (si es aplicable) se devuelve de una de varias maneras dependiendo de las marcas de opción; la estructura puede ser analizada por el programa e impreso en un formato legible si es una estructura conocida, mostrada en hexadecimal, o el búfer crudo puede ser impreso a stdout para que otro programa lo analice.

OPCIONES

-n <nsid>, --namespace-id=<nsid>

Recupera la característica para el nsid dado. Esto es opcional y la mayoría de las características no utilizan este valor.

-D <dtype>, --dir-type=<dtype>

Tipo de directiva

-S <dspec>, --dir-spec=<dspec>

Específico de la directiva

-O <doper>, --dir-oper=<doper>

Operación de directiva

-r <nsr>, --req-resource=<nsr>

Cantidad de recursos solicitados por la directiva
Seleccionar Descripción
0 Actual
1 Predeterminado
2 Guardado
3 Capacidades admitidas
4–7 Reservado

-l <data-len>, --data-len=<data-len>

La longitud de los datos para el búfer devuelto para esta característica. La mayoría de las características conocidas no utilizan este valor. La excepción es el tipo de rango LBA.

-b, --raw-binary

Imprime el búfer de recepción crudo en stdout si el comando devuelve una estructura.

-H, --human-readable

Imprime el búfer de recepción decodificado en stdout si el comando devuelve una estructura.

-o <fmt>, --output-format=<fmt>

Establece el formato de informe en normal, json o binary. Solo se puede usar un formato de salida a la vez.

-v, --verbose

Aumenta el nivel de detalle de la información en la salida.

-t <timeout>, --timeout=<timeout>

Anula el valor de tiempo de espera predeterminado. En milisegundos.

EJEMPLOS

•Identificar los tipos de directiva admitidos: 
# nvme dir-receive /dev/nvme0 --dir-type 0 --dir-oper 1 --human-readable
•Obtener los parámetros de directiva de flujo: 
# nvme dir-receive /dev/nvme0 --dir-type 1 --dir-oper 1 --human-readable
•Asignar 3 flujos para el namespace 1 
# nvme dir-receive /dev/nvme0n1 --dir-type 1 --dir-oper 3 --req-resource 3 --human-readable
•Obtener el estado de la directiva de flujos: 
# nvme dir-receive /dev/nvme0 --dir-type 1 --dir-oper 2 --human-readable

Probablemente sea una mala idea no redirigir stdout al usar este modo.
