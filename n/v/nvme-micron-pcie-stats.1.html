NOMBRE

nvme-micron-pcie-stats - Recupera estadísticas de errores pcie para el dispositivo micron dado

SINOPSIS

nvme micron vs-pcie-stats <dispositivo>

DESCRIPCIÓN

Este comando imprime información de errores corregibles y no corregibles pcie para el dispositivo micron dado.

El parámetro <dispositivo> es obligatorio y puede ser el dispositivo de caracteres NVMe (ej. /dev/nvme0) o un dispositivo de bloque de espacio de nombres (ej. /dev/nvme0n1).

Esto solo funcionará en dispositivos Micron con números de modelo 54XX. Se puede añadir soporte para nuevos dispositivos posteriormente.

OPCIONES

Ninguna

EJEMPLOS

•Recuperar información de errores PCIe 
# nvme micron vs-pcie-stats /dev/nvme0
