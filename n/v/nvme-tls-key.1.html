NOMBRE

nvme-tls-key - Gestionar claves PSK de NVMe TLS

SINOPSIS

nvme tls-key [--keyring=<nombre> | -k <nombre>]
                        [--keytype=<tipo> | -t <tipo>]
                        [--keyfile=<archivo> | -f <archivo>]
                        [--importar | -i] [--exportar | -e]
                        [--revocar=<descripción>| -r <descripción>]
                        [--verbose | -v]

DESCRIPCIÓN

Importar, exportar o eliminar claves precompartidas (PSK) de NVMe TLS del almacén de claves del sistema. Cuando se proporciona la opción --exportar, todas las PSK de NVMe TLS se exportan en el formato

<descripciones> <psk>

donde <descripción> es la descripción de la clave del archivo exportado y <psk> son los datos de la clave en el formato de intercambio PSK NVMeTLSkey-1:01:<datos codificados en base64>:. Cada clave se exporta en una sola línea. Cuando se proporciona la opción --importar, los datos de la clave se leen en el mismo formato y se importan en el almacén de claves del kernel.

OPCIONES

-k <nombre>, --keyring=<nombre>

Nombre del almacén de claves en el que se debe almacenar la clave TLS retenida. El valor predeterminado es .nvme.

-t <tipo>, --keytype=<tipo>

Tipo de clave para la clave TLS resultante. El valor predeterminado es psk.

-f <archivo>, --keyfile=<archivo>

Archivo desde el que leer las claves o al que escribir las claves en lugar de la entrada estándar / salida estándar.

-i, --importar

Leer los datos de la clave del archivo especificado por --keyfile o de la entrada estándar si no está presente.

-e, --exportar

Escribir los datos de la clave en el archivo especificado por --keyfile o en la salida estándar si no está presente.

-r <descripción>, --revocar=<descripción>

Revocar una clave de un almacén de claves.

-v, --verbose

Aumentar el nivel de detalle de la información en la salida.

EJEMPLOS

•Crear una nueva clave TLS e insertarla directamente en el almacén de claves .nvme: 
# nvme gen-tls-key -i -n hostnqn0 -c subsys0
NVMeTLSkey-1:01:/b9tVz2OXJVISnoFgrPAygyS86XYJWkAapQeULns6PMpM8wv:
Inserted TLS key 26b3260e
•Exportar la clave creada previamente del almacén de claves del kernel y guardarla en un archivo 
# nvme tls-key -e -f nvme-tls-keys.txt
•Exportar/listar todas las claves del almacén de claves .nvme usando nvme y keyctl 
# nvme tls-key --exportar
NVMe0R01 hostnqn0 subsys0 NVMeTLSkey-1:01:/b9tVz2OXJVISnoFgrPAygyS86XYJWkAapQeULns6PMpM8wv:
# keyctl show
Session Keyring
 573249525 --alswrv      0     0  keyring: _ses
 353599402 --alswrv      0 65534   \_ keyring: _uid.0
 475911922 ---lswrv      0     0   \_ keyring: .nvme
 649274894 --als-rv      0     0       \_ psk: NVMe0R01 hostnqn0 subsys0
•Revocar una clave usando la descripción y verificando la operación con keyctl 
# nvme tls-key --revocar="NVMe0R01 hostnqn0 subsys0"
# keyctl show
Session Keyring
 573249525 --alswrv      0     0  keyring: _ses
 353599402 --alswrv      0 65534   \_ keyring: _uid.0
 475911922 ---lswrv      0     0   \_ keyring: .nvme
649274894: key inaccessible (Key has been revoked)
•Importar de nuevo la clave generada previamente desde el archivo y verificar con keyctl 
# nvme tls-key --importar -f nvme-tls-keys.txt
# keyctl show
Session Keyring
