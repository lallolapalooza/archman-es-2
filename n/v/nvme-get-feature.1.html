NOMBRE

nvme-get-feature - Obtiene una característica NVMe, devuelve los resultados aplicables

SINOPSIS

nvme get-feature <dispositivo> [--namespace-id=<nsid> | -n <nsid>]
                        [--feature-id=<fid> | -f <fid>]
                        [--uuid-index=<uuid-index> | -U <uuid_index>]
                        [--data-len=<data-len> | -l <data-len>]
                        [--sel=<select> | -s <select>]
                        [--raw-binary | -b] [--cdw11=<cdw11> | -c <cdw11>]
                        [--human-readable | -H] [--changed | -C]
                        [--output-format=<fmt> | -o <fmt>] [--verbose | -v]
                        [--timeout=<timeout> | -t <timeout>]

DESCRIPCIÓN

Envía un comando de administración NVMe Get Feature y devuelve los resultados aplicables. Este puede ser el valor de la característica, o puede incluir también una estructura de característica si la característica lo requiere (por ejemplo, Tipo de rango LBA).

El parámetro <dispositivo> es obligatorio y puede ser tanto el dispositivo de caracteres NVMe (por ejemplo, /dev/nvme0), como un dispositivo de bloque de espacio de nombres (por ejemplo, /dev/nvme0n1).

En caso de éxito, la estructura de la característica devuelta (si es aplicable) puede devolverse de varias maneras según las banderas de opción; la estructura puede ser analizada por el programa e impresa en un formato legible si es una estructura conocida, mostrada en hexadecimal, o el búfer bruto puede imprimirse en stdout para que otro programa lo analice.

NAME

nvme-get-feature - Retrieve a feature and its value from an NVMe device

SYNOPSIS

nvme get-feature <device> [-f <feature-id>] [-e <error-log-entry>] [-l <data-len>] [-u <uuid-index>] [-c <cdw11>] [-H] [-C] [-b] [-o <fmt>] [-v] [-t <timeout>]

DESCRIPTION

Retrieves a specific NVMe device feature and its associated values.

The features themselves are identified by a feature-id. The list of features and their ids can be found in the NVMe specification.

The following is a table of common feature ids:

ID Name
1 Interrupt Coalescing
2 Interrupt Moderation
3 Number of Queues
4 Arbitration
5 Volatile Write Cache
6 Save
7 Supported capabilities
4-7 Reserved

-f <feature-id>, --feature-id=<feature-id>

The specific feature to retrieve.

-e <error-log-entry>, --error-log-entry=<error-log-entry>

If retrieving the generic error log, this is the specific entry to retrieve.

-U <uuid-index>, --uuid-index=<uuid-index>

UUID Index of the feature

-l <data-len>, --data-len=<data-len>

The data length for the buffer returned for this feature. Most known features do not use this value. The exception is LBA Range Type

-c <cdw11>, --cdw11=<cdw11>

The value for command dword 11, if applicable.

-b, --raw-binary

Print the raw feature buffer to stdout if the feature returns a structure.

-H, --human-readable

This option will parse and format many of the bit fields into human-readable formats.

-C, --changed

This option will show feature changed.

-o <fmt>, --output-format=<fmt>

Set the reporting format to normal, json or binary. Only one output format can be used at a time.

-v, --verbose

Increase the information detail in the output.

-t <timeout>, --timeout=<timeout>

Override default timeout value. In milliseconds.

EXAMPLES

•Retrieves the feature for Number of Queues, or feature id 7: 
# nvme get-feature /dev/nvme0 -f 7
•The following retrieves the feature for the LBA Range Type, which implicitly requires a buffer and will be printed to the screen in human readable format: 
# nvme get-feature /dev/nvme0 -f 3
•Retrieves the feature for the some vendor specific feature and specifically requesting a buffer be allocate for this feature, which will be displayed to the user in as a hex dump: 
# nvme get-feature /dev/nvme0 -f 0xc0 -l 512

Get feature with UUID index

# nvme get-feature /dev/nvme0 -f 0xc0 -l 512 -U 0x1
•The following retrieves the feature for the LBA Range Type, which implicitly requires a buffer and will be saved to a file in its raw format: 
# nvme get-feature /dev/nvme0 -f 3 --raw-binary > lba_range.raw

It is probably a bad idea to not redirect stdout when using this mode.
