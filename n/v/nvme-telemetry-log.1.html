NOMBRE

nvme telemetry-log - Recupera una página de registro de Telemetry Host-Initiated de un dispositivo NVMe

SINOPSIS

nvme telemetry-log <dispositivo> [--output-file=<archivo> | -O <archivo>]
                        [--host-generate=<gen> | -g <gen>]
                        [--output-format=<fmt> | -o <fmt>] [--verbose | -v]

DESCRIPCIÓN

Recupera una página de registro de Telemetry Host-Initiated de un dispositivo NVMe y proporciona la estructura devuelta.

El parámetro <dispositivo> es obligatorio y puede ser el dispositivo de caracteres NVMe (ej: /dev/nvme0) o un dispositivo de bloque de namespace (ej: /dev/nvme0n1).

En caso de éxito, la estructura de registro devuelta estará en formato binario crudo únicamente con la opción --output-file, la cual es obligatoria.

OPCIONES

-O <archivo>, --output-file=<archivo>

Nombre del archivo en el que se guardarán los datos binarios crudos.

-g <gen>, --host-generate=<gen>

Si se establece en 1, el controlador capturará los datos de Telemetry Host-Initiated que representan el estado interno del controlador en el momento en que se procesa el comando asociado Get Log Page. Si se establece en 0, el controlador no actualizará estos datos.

-d <da>, --data-area=<da>

Recupera el área de datos específica solicitada. Las entradas válidas son 1,2,3,4. Si esta opción no se especifica, el valor predeterminado es 3, ya que el área de datos 4 podría no ser compatible.

-o <fmt>, --output-format=<fmt>

Establece el formato de informe en normal, json o binary. Solo se puede utilizar un formato de salida a la vez.

-v, --verbose

Aumenta el nivel de detalle de la información en la salida.

EJEMPLOS

•Recuperar datos de Telemetry Host-Initiated en telemetry_log.bin 
# nvme telemetry-log /dev/nvme0 --output-file=telemetry_log.bin
