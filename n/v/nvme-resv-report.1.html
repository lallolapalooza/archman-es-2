NOMBRE

nvme-resv-report - Envía el Informe de Reserva NVMe, analiza el resultado

SINOPSIS

nvme resv-report <dispositivo> [--namespace-id=<nsid> | -n <nsid>]
                        [--numd=<num-dwords> | -d <num-dwords>] [--eds | -e]
                        [--raw-binary | -b]
                        [--output-format=<fmt> | -o <fmt>] [--verbose | -v]
                        [--timeout=<timeout> | -t <timeout>]

DESCRIPCIÓN

El comando de Informe de Reserva devuelve una estructura de datos de Estado de Reserva a la memoria del host que describe el estado de registro y reserva de un namespace.

El tamaño de la estructura de datos de Estado de Reserva es una función del número de controladores en el Subsistema NVM que están asociados con hosts que son registrantes del namespace (es decir, existe una estructura de datos de Controlador Registrado para cada controlador de este tipo).

OPCIONES

-n <nsid>, --namespace-id=<nsid>

Recupera la estructura de informe de reserva para el nsid dado. Esto es necesario para los dispositivos de caracteres o anula el nsid del bloque si se proporciona.

-d <num-dwords>, --numd=<num-dwords>

Especifica el número de Dwords de la estructura de Estado de Reserva a transferir. Por defecto es 4k.

-e, --eds

Solicita Estructura de Datos Extendida: Si este bit se establece en 1, el controlador devuelve la Estructura de Datos Extendida.

-b, --raw-binary

Imprime el búfer sin procesar en stdout. El programa no analiza la estructura.

-o <fmt>, --output-format=<fmt>

Establece el formato de informe en normal, json o binary. Solo se puede usar un formato de salida a la vez.

-v, --verbose

Aumenta el detalle de la información en la salida.

-t <timeout>, --timeout=<timeout>

Anula el valor de tiempo de espera predeterminado. En milisegundos.
