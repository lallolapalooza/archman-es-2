NOMBRE

nvme-connect - Conectarse a un controlador de Fabrics.

SINOPSIS

nvme connect [--transport=<trtype> | -t <trtype>]
                        [--nqn=<subnqn> | -n <subnqn>]
                        [--traddr=<traddr> | -a <traddr>]
                        [--trsvcid=<trsvcid> | -s <trsvcid>]
                        [--host-traddr=<traddr> | -w <traddr>]
                        [--host-iface=<iface> | -f <iface>]
                        [--hostnqn=<hostnqn> | -q <hostnqn>]
                        [--hostid=<hostid> | -I <hostid>]
                        [--config=<filename> | -J <filename>]
                        [--dhchap-secret=<secret> | -S <secret>]
                        [--dhchap-ctrl-secret=<secret> | -C <secret>]
                        [--nr-io-queues=<#> | -i <#>]
                        [--nr-write-queues=<#> | -W <#>]
                        [--nr-poll-queues=<#> | -P <#>]
                        [--queue-size=<#> | -Q <#>]
                        [--keep-alive-tmo=<#> | -k <#>]
                        [--reconnect-delay=<#> | -c <#>]
                        [--ctrl-loss-tmo=<#> | -l <#>] [--tos=<#> | -T <#>]
                        [--keyring=<keyring>] [--tls-key=<tls-key>]
                        [--tls-key-identity=<identity>]
                        [--duplicate-connect | -D] [--disable-sqflow ]
                        [--hdr-digest | -g] [--data-digest | -G] [--tls]
                        [--concat] [--dump-config | -O] [--application=<id>]
                        [--output-format=<fmt> | -o <fmt>] [--verbose | -v]

DESCRIPCIÓN

Crea una conexión de transporte a un sistema remoto (especificado por --traddr y --trsvcid) y crea un controlador NVMe over Fabrics para el subsistema NVMe especificado por la opción --nqn.

OPCIONES

-t <trtype>, --transport=<trtype>

Este campo especifica la red de fabric utilizada para una red NVMe-over-Fabrics. Los valores de cadena actuales incluyen:
Valor Definición
rdma La red de fabric es una red rdma (RoCE, iWARP, Infiniband, rdma básico, etc.)
fc EN DESARROLLO La red de fabric es una red Fibre Channel.
tcp La red de fabric es una red TCP/IP.
loop Conectarse a un objetivo NVMe over Fabrics en el host local

-n <subnqn>, --nqn <subnqn>

Este campo especifica el nombre del subsistema NVMe al que conectarse.

-a <traddr>, --traddr=<traddr>

Este campo especifica la dirección de red del Controlador. Para transportes que utilizan direccionamiento IP (por ejemplo, rdma), esta debería ser una dirección basada en IP (ej. IPv4).

-s <trsvcid>, --trsvcid=<trsvcid>

Este campo especifica el ID del servicio de transporte. Para transportes que utilizan direccionamiento IP (por ejemplo, rdma), este campo es el número de puerto. Por defecto, el número de puerto IP para el transporte RDMA es 4420.

-w <traddr>, --host-traddr=<traddr>

Este campo especifica la dirección de red utilizada en el host para conectarse al Controlador. Para TCP, esto establece la dirección de origen en el socket.

-f <iface>, --host-iface=<iface>

Este campo especifica la interfaz de red utilizada en el host para conectarse al Controlador (por ejemplo, IP eth1, enp2s0, enx78e7d1ea46da). Esto fuerza la conexión a realizarse en una interfaz específica en lugar de dejar que el sistema decida.

-q <hostnqn>, --hostnqn=<hostnqn>

Anula el Host NQN predeterminado que identifica el Host NVMe. Si esta opción no se especifica, el valor predeterminado se lee primero de /etc/nvme/hostnqn. Si ese no existe, el NQN autogenerado del módulo del kernel del Host NVMe se utiliza a continuación. El Host NQN identifica de forma única el Host NVMe.

-I <hostid>, --hostid=<hostid>

UUID (Identificador Único Universal) a descubrir que debe ser formateado.

-J <filename>, --config=<filename>

Utiliza el archivo de configuración JSON especificado en lugar del archivo predeterminado /etc/nvme/config.json o *ninguno* para no leer un archivo de configuración existente. El formato del archivo de configuración JSON está documentado en https://github.com/linux-nvme/libnvme/blob/master/doc/config-schema.json

-S <secret>, --dhchap-secret=<secret>

Secreto de autenticación NVMe In-band; necesita estar en formato ASCII según lo especificado en la sección 8.13.5.8 de NVMe 2.0 Representación de secreto.

-C <secret>, --dhchap-ctrl-secret=<secret>

Secreto del controlador de autenticación NVMe In-band para autenticación bidireccional; necesita estar en formato ASCII según lo especificado en la sección 8.13.5.8 de NVMe 2.0 Representación de secreto. Si no está presente, no se intentará la autenticación bidireccional.

-i <#>, --nr-io-queues=<#>

Anula el número predeterminado de colas de E/S creadas por el controlador.

-W <#>, --nr-write-queues=<#>

Añade colas adicionales que se utilizarán para E/S de escritura.

-P <#>, --nr-poll-queues=<#>

Añade colas adicionales que se utilizarán para E/S de latencia sensible de sondeo.

-Q <#>, --queue-size=<#>

Anula el número predeterminado de elementos en las colas de E/S creadas por el controlador.

-k <#>, --keep-alive-tmo=<#>

Anula el tiempo de espera de mantenimiento de conexión predeterminado (en segundos).

-c <#>, --reconnect-delay=<#>

Anula el retraso predeterminado (en segundos) antes de que se intente reconectar después de una pérdida de conexión.

-l <#>, --ctrl-loss-tmo=<#>

Anula el período de tiempo de espera de pérdida del controlador predeterminado (en segundos). Este es el tiempo máximo que el kernel intentará reconectar, donde cada reintento se emitirá después de reconnect-delay segundos.

-T <#>, --tos=<#>

Tipo de servicio para la conexión (TCP)

--keyring=<keyring>

Llavero para la búsqueda de claves TLS, ya sea el ID de clave o el nombre del llavero.

--tls-key=<tls-key>

Clave TLS para la conexión (TCP), ya sea la clave TLS en formato de intercambio o el ID de clave. Se recomienda encarecidamente no proporcionar la clave TLS a través de la línea de comandos debido a problemas de seguridad. En su lugar, en situaciones de producción, la clave debe cargarse en el almacén de claves con nvme tls --import y solo se utilizarán las opciones --tls. El kernel seleccionará la clave coincidente.

--tls-key-identity=<identity>

La identidad utilizada para la clave tls. Si no se proporciona ninguna, la clave tls proporcionada a través de la línea de comandos se considera una clave de configuración y se cargará una clave derivada en el llavero.

-D, --duplicate-connect

Permite conexiones duplicadas entre el mismo host de transporte y el puerto del subsistema.

--disable-sqflow

Deshabilita el control de flujo de SQ para omitir la actualización del timbre de puerta de cola de envío al enviar completados de nvme.

-g, --hdr-digest

Genera/verifica el digest de cabecera (TCP).

-G, --data-digest

Genera/verifica el digest de datos (TCP).

--tls

Habilita el cifrado TLS (TCP).

--concat

Habilita la concatenación segura (TCP).

-O, --dump-config

Imprime el archivo de configuración JSON resultante en la salida estándar.

--context <STR>

Establece el contexto de ejecución en <STR>. Esto permite coordinar la gestión de los recursos globales.

nvme-connect(1)

NAME

nvme-connect - Connect to an NVMe subsystem

SYNOPSIS

nvme connect [-a address] [-s subnqn] [-i interface] [-t transport type] [-w wire format] [-v]

DESCRIPTION

The NVMe utility is used to manage NVMe targets and may be used to connect to an NVMe subsystem. This command will attempt to establish a connection to the specified subsystem.

OPTIONS

-a address, --address address
Address of the NVMe host.
-s subnqn, --subnqn subnqn
The NVM Qualifier Name (NQN) of the subsystem to connect to.
-i interface, --interface interface
The interface to use for the connection.
-t transport, --transport transport
The transport type to use for the connection. Default is `rdma`.
-w wire format, --wire-format wire format
The wire format to use for the connection.
-v verbose, --verbose
Increase the information detail in the output.

EXAMPLES

•Connect to a subsystem named nqn.2014-08.com.example:nvme:nvm-subsystem-sn-d78432 on the IP4 address 192.168.1.3. Port 4420 is used by default: 
# nvme connect --transport=rdma --traddr=192.168.1.3 \
--nqn=nqn.2014-08.com.example:nvme:nvm-subsystem-sn-d78432
