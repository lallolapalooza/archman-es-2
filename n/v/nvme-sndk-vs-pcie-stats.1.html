NOMBRE

nvme-sndk-vs-pcie-stats - Envía el comando NVMe sndk vs-pcie-stats, devuelve el resultado

SINOPSIS

nvme sndk vs-pcie-stats <dispositivo>

DESCRIPCIÓN

Para el dispositivo NVMe dado, envía el comando único sndk vs-pcie-stats y devuelve los datos de estadísticas pcie.

El parámetro <dispositivo> es obligatorio y puede ser el dispositivo de carácter NVMe (ej: /dev/nvme0).

Esto solo funcionará en dispositivos Sandisk que soporten esta función. Los resultados para cualquier otro dispositivo no están definidos.

En caso de éxito devuelve 0, código de error en caso contrario.

OPCIONES

-o <fmt>, --output-format=<fmt>

Establece el formato de reporte a normal o json. Solo se puede usar un formato de salida a la vez. El valor predeterminado es normal.

EJEMPLOS

• Hacer que el programa emita el comando sndk vs-pcie-stats:

# nvme sndk vs-pcie-stats /dev/nvme0
