NOMBRE

nvme-get-lba-status - Obtener el estado LBA del dispositivo NVMe

SINOPSIS

nvme get-lba-status <dispositivo> [--namespace-id=<nsid> | -n <nsid>]
                        [--start-lba=<slba> | -s <slba>]
                        [--max-dw=<max-dw> | -m <max-dw>]
                        [--action=<action-type> | -a <action-type>]
                        [--range-len=<range-len> | -l <range-len>]
                        [--timeout=<timeout> | -t <timeout>]
                        [--output-format=<fmt> | -o <fmt>] [--verbose | -v]

DESCRIPCIÓN

Para el dispositivo NVMe dado, envía un comando de administración nvme Get LBA Status y proporciona los resultados.

El parámetro <dispositivo> es obligatorio y puede ser el dispositivo de caracteres NVMe (ej: /dev/nvme0) o un dispositivo de bloque de namespace (ej: /dev/nvme0n1).

En caso de éxito, la estructura de datos de obtención de LBA devuelta puede ser devuelta de varias maneras dependiendo de las opciones; la estructura puede ser analizada por el programa e impresa en un formato legible o el búfer crudo puede ser impreso a stdout para que otro programa lo analice.

OPCIONES

-n <nsid>, --namespace-id=<nsid>

Envía el comando Get LBA Status para el nsid especificado. Esto puede usarse para anular el valor predeterminado para el dispositivo de caracteres (no especificado) o el dispositivo de bloque (resultado de NVME_IOCTL_ID).

-s <slba>, --start-lba=<slba>

Dirección de 64 bits del LBA inicial (SLBA) del primer bloque lógico abordado.

-m <max-dw>, --max-dw=<max-dw>

El Número Máximo de Dwords (MNDW) especifica el número máximo de dwords a devolver.

-a <action-type>, --action=<action-type>

El Tipo de Acción (ATYPE) especifica el mecanismo que utiliza para determinar los Descriptores de Estado LBA.

-l <range-len>, --range-len=<range-len>

La Longitud del Rango (RL) especifica la longitud del rango de LBAs contiguos que comienzan en SLBA.

-t <timeout>, --timeout=<timeout>

Anula el valor de tiempo de espera predeterminado. En milisegundos.

-o <fmt>, --output-format=<fmt>

Establece el formato de reporte a normal, json o binary. Solo se puede usar un formato de salida a la vez.

-v, --verbose

Aumenta el detalle de la información en la salida.

EJEMPLOS

•Obtener el Estado LBA del dispositivo usando todos los valores predeterminados: 
# nvme get-lba-status /dev/nvme0n1
•Obtener el Estado LBA del namespace 1 desde SLBA 10 para el máximo de Dwords de 0x1000: 
# nvme get-lba-status /dev/nvme0 --namespace-id=1 --start-lba=10 --max-dw=0x1000
