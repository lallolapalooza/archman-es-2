NVME-SANITIZE(1) Manual de NVMe NVME-SANITIZE(1)

NOMBRE

nvme-sanitize - Envía el comando NVMe Sanitize, devuelve el resultado

SINOPSIS

nvme sanitize <dispositivo> [--no-dealloc | -d] [--oipbp | -i]
                        [--owpass=<contador-pasadas-sobreescritura> | -n <contador-pasadas-sobreescritura>]
                        [--ause | -u] [--sanact=<accion> | -a <accion>]
                        [--ovrpat=<patron-sobreescritura> | -p <patron-sobreescritura>]
                        [--emvs | -e] [--force]
                        [--output-format=<fmt> | -o <fmt>] [--verbose | -v]

DESCRIPCIÓN

Para el dispositivo NVMe dado, envía un comando Sanitize y proporciona el resultado.

El parámetro <dispositivo> es el dispositivo de caracteres NVMe obligatorio (ej: /dev/nvme0).

En caso de éxito devuelve 0, código de error en caso contrario.

OPCIONES

-d, --no-dealloc

No Deallocar Después de Sanitizar: Si se establece, el controlador no deallocará ningún bloque lógico como resultado de completar con éxito la operación de sanitización. Si se borra, el controlador debería deallocar bloques lógicos como resultado de completar con éxito la operación de sanitización. Este bit será ignorado si el campo Acción de Sanitización se establece en 001b (es decir, Salir del Modo de Fallo).

-i, --oipbp

Invertir Patrón de Sobreescritura Entre Pasadas: Si se establece, el Patrón de Sobreescritura se invertirá entre pasadas. Si se borra, el patrón de sobreescritura no se invertirá entre pasadas. Este bit será ignorado a menos que el campo Acción de Sanitización se establezca en 011b (es decir, Sobreescritura).

-n <contador-pasadas-sobreescritura>, --owpass=<contador-pasadas-sobreescritura>

Contador de Pasadas de Sobreescritura: Este campo especifica el número de pasadas de sobreescritura (es decir, cuántas veces se sobrescribirá el medio) utilizando los datos del campo Patrón de Sobreescritura de este comando. Un valor de 0 especifica 16 pasadas de sobreescritura. Este campo será ignorado a menos que el campo Acción de Sanitización se establezca en 011b (es decir, Sobreescritura).

-u, --ause

Permitir Salida de Sanitización Sin Restricciones: Si se establece, la operación de sanitización se realiza en modo de finalización sin restricciones. Si se borra, la operación de sanitización se realiza en modo de finalización restringido. Este bit será ignorado si el campo Acción de Sanitización se establece en 001b (es decir, Salir del Modo de Fallo).

-a <accion>, --sanact=<accion>

Acción de Sanitización:
Valor Definición
0x00 Reservado
0x01 | exit-failure Salir del Modo de Fallo
0x02 | start-block-erase Iniciar una operación de sanitización de Borrado de Bloques
0x03 | start-overwrite Iniciar una operación de sanitización de Sobreescritura
0x04 | start-crypto-erase Iniciar una operación de sanitización de Borrado Criptográfico
0x05 | exit-media-verification Salir del Estado de Verificación de Medios

-p <patron-sobreescritura>, --ovrpat=<patron-sobreescritura>

Patrón de Sobreescritura: Este campo se ignora a menos que el campo Acción de Sanitización en el Comando DWORD 10 esté establecido en 011b (es decir, Sobreescritura). Este campo especifica un patrón de 32 bits que se utiliza para la operación de sanitización de Sobreescritura.

-e, --emvs

Entrar en Estado de Verificación de Medios: Si se establece, el estado de Verificación de Medios se entrará si el procesamiento de sanitización se completa con éxito. Si se borra, este bit no tendrá ningún efecto. Si el campo SANACT no especifica el inicio de una operación de sanitización (es decir, se establece en cualquier valor que no sea 010b, 011b o 100b), este bit será ignorado por el controlador.

--force

Ignora que el espacio de nombres está actualmente ocupado y realiza la operación a pesar de ello.

-o <fmt>, --output-format=<fmt>

Establece el formato de informe en normal, json o binary. Solo se puede usar un formato de salida a la vez.

-v, --verbose

Aumenta el nivel de detalle de la información en la salida.

EJEMPLOS

•Hacer que el programa emita el Comando de Sanitización: 
# nvme sanitize /dev/nvme0 -a 0x02
# nvme sanitize /dev/nvme0 --sanact=0x01
# nvme sanitize /dev/nvme0 --sanact=start-overwrite
