NOMBRE

nvme-wdc-vs-error-reason-identifier - Recupera el campo del identificador de razón de error del registro de telemetría del dispositivo WDC

SINOPSIS

nvme wdc vs-error-reason-identifier <dispositivo> [--log-id=<NUM>, -i <NUM>] [--file=<ARCHIVO>, -o <ARCHIVO>]

DESCRIPCIÓN

Para el dispositivo NVMe proporcionado, recupera el campo del identificador de razón de error del registro de telemetría, ya sea del registro generado por el host o iniciado por el controlador. La opción de registro de telemetría iniciado por el controlador debe estar habilitada para recuperar el id de razón de error para esa página de registro.

El parámetro <dispositivo> es obligatorio y debe ser el dispositivo de carácter NVMe (ej: /dev/nvme0).

Esto solo funcionará en dispositivos WDC que soporten esta función. Los resultados para cualquier otro dispositivo no están definidos.

En caso de éxito devuelve 0, código de error en caso contrario.

OPCIONES

-i <id>, --log-id=<id>

Especifica el ID del registro de telemetría del identificador de razón de error a recuperar. Usa el ID 7 para la página de registro generada por el host. Usa el ID 8 para la página de registro iniciada por el controlador. El valor predeterminado es 7/generado por el host.

-o <ARCHIVO>, --output-file=<ARCHIVO>

Archivo de salida; el valor predeterminado es "<número de serie del dispositivo>_error_reason_identifier_host_<fecha>_<hora>.bin" para el registro generado por el host o "<número de serie del dispositivo>_error_reason_identifier_ctlr_<fecha>_<hora>.bin" para el registro iniciado por el controlador.

EJEMPLOS

•Recupera el identificador de razón de error generado por el host y lo guarda en el archivo host_gen_error_reason_id.bin. 
# nvme wdc vs-error-reason-identifier /dev/nvme0 -i 7 -o host_gen_error_reason_id.bin
•Recupera el identificador de razón de error iniciado por el controlador y lo guarda en el archivo ctlr_init_error_reason_id.bin. 
# nvme wdc vs-error-reason-identifier /dev/nvme0 -i 8 -o ctlr_init_error_reason_id.bin
