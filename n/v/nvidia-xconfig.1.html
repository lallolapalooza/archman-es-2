nvidia-xconfig(1) Manual de Comandos Generales nvidia-xconfig(1)

NOMBRE

nvidia-xconfig - manipular archivos de configuración X para el controlador NVIDIA

SINOPSIS

nvidia-xconfig [ opciones ]

DESCRIPCIÓN

nvidia-xconfig es una herramienta destinada a proporcionar control básico sobre las opciones de configuración disponibles en el controlador X de NVIDIA.

nvidia-xconfig realiza sus operaciones en varios pasos:

1)
Se encuentra el archivo de configuración X del sistema y se lee en memoria. Si no se encuentra ningún archivo de configuración, nvidia-xconfig genera uno desde cero utilizando la configuración predeterminada; en este caso, nvidia-xconfig escribirá la configuración en /etc/X11/xorg.conf
2)
La configuración en memoria se modifica para admitir el controlador NVIDIA. Esto consiste en cambiar el controlador de pantalla a "nvidia", eliminar los comandos para cargar los módulos "GLcore" y "dri", y agregar el comando para cargar el módulo "glx".
3)
La configuración en memoria se modifica según las opciones especificadas en la línea de comandos. Consulte el README de NVIDIA para obtener una descripción de las opciones del archivo de configuración X de NVIDIA. Tenga en cuenta que nvidia-xconfig no realiza ninguna validación de las opciones del archivo de configuración X solicitadas en la línea de comandos; la validación de las opciones del archivo de configuración X se deja para el controlador X de NVIDIA.
4)
La configuración se vuelve a escribir en el archivo del que se leyó. Se crea una copia de seguridad de la configuración original con el sufijo ".backup". Por ejemplo, si su configuración X es /etc/X11/xorg.conf, entonces nvidia-xconfig la copiará a /etc/X11/xorg.conf.backup antes de escribir la nueva configuración. La opción --post-tree (-T) se puede usar para imprimir la nueva configuración en la salida estándar en formato de árbol en su lugar. Esta opción es útil para ver lo que hará nvidia-xconfig mientras deja intacta la configuración original.

El código fuente de nvidia-xconfig está publicado bajo la GPL y está disponible aquí:


⟨ https://download.nvidia.com/XFree86/nvidia-xconfig/ ⟩

Se aceptan parches.

OPCIONES

-c XCONFIG, --xconfig=XCONFIG
Use XCONFIG como archivo de configuración X de entrada; si no se especifica esta opción, se utilizará la misma ruta de búsqueda que utiliza el servidor X para encontrar el archivo de configuración X.
-o SALIDA-XCONFIG, --output-xconfig=SALIDA-XCONFIG
Use SALIDA-XCONFIG como archivo de configuración X de salida; si no se especifica esta opción, el nombre del archivo de configuración X de entrada también se utilizará como nombre del archivo de configuración X de salida.
-s, --silent
Ejecutar en silencio; no se imprimirán mensajes en stdout, excepto por mensajes de advertencia y error en stderr.
-t, --tree
Leer el archivo de configuración X, imprimir los datos de configuración X en formato de árbol en la salida estándar y salir.
-v, --version
Imprimir la versión de nvidia-xconfig y salir.
-h, --help
Imprimir información de uso para las opciones comunes de la línea de comandos y salir.
-A, --advanced-help
Imprimir información de uso para las opciones comunes de la línea de comandos, así como para las opciones avanzadas, y luego salir.

OPCIONES AVANZADAS

--acpid-socket-path=RUTA-SOCKET-ACPID, --no-acpid-socket-path
Establezca esta opción para especificar una ruta alternativa al socket del demonio ACPI (acpid) de Linux, que el controlador X de NVIDIA utilizará para conectarse a acpid.
--add-argb-glx-visuals, --no-add-argb-glx-visuals
Habilita o deshabilita la compatibilidad con la representación OpenGL en ventanas y pixmaps ARGB de 32 bits.
--allow-glx-with-composite, --no-allow-glx-with-composite
Habilita o deshabilita la opción de configuración X "AllowGLXWithComposite".
--busid=BUSID, --no-busid
Esta opción escribe el BusID especificado en la sección de dispositivo del archivo de configuración X. Si hay varias secciones de dispositivo, agrega el campo BusID a cada una de ellas. Para agregar el BusID solo a un dispositivo o sección de pantalla específica, use las opciones '--device' o '--screen'.
--preserve-busid, --no-preserve-busid
Por defecto, nvidia-xconfig conserva el BusID existente en el archivo de configuración X solo si hay varias pantallas X configuradas para el servidor X. Use '--preserve-busid' o '--no-preserve-busid' para forzar que el BusID se conserve o no se conserve, anulando el comportamiento predeterminado.
--cool-bits=COOL-BITS, --no-cool-bits
Habilita o deshabilita la opción de configuración X "Coolbits". La configuración de esta opción habilitará la compatibilidad en la extensión X NV-CONTROL para manipular la configuración del reloj de la GPU y el control del ventilador de la GPU. El valor predeterminado es 0. Para el control del ventilador, establézcalo en 4. ADVERTENCIA: esto puede causar daños al sistema y anular las garantías.
--composite, --no-composite
Habilita o deshabilita la extensión X "Composite".
--connected-monitor=MONITOR-CONECTADO, --no-connected-monitor
Habilita o deshabilita la opción de configuración X "ConnectedMonitor"; la configuración de esta opción fuerza al controlador X a comportarse como si los dispositivos de pantalla especificados estuvieran conectados a la GPU.
--connect-to-acpid, --no-connect-to-acpid
Habilita o deshabilita la opción de configuración X "ConnectToAcpid". Si esta opción está configurada, el controlador X de NVIDIA intentará conectarse al demonio ACPI (acpid) de Linux. Configure esta opción en desactivado para evitar que el controlador X intente conectarse a acpid.
--constant-dpi, --no-constant-dpi
Habilita o deshabilita la opción de configuración X "ConstantDPI", que controla si el controlador X de NVIDIA mantiene un valor constante de puntos por pulgada (DPI) al recalcular el tamaño reportado en milímetros de la pantalla X cuando XRandR cambia el tamaño en píxeles de la pantalla X.
--custom-edid=EDID-PERSONALIZADO, --no-custom-edid
Habilita o deshabilita la opción de configuración X "CustomEDID"; la configuración de esta opción fuerza al controlador X a usar el EDID especificado. Esta opción es una lista separada por punto y coma de pares de nombres de dispositivos de pantalla y nombres de archivo; por ejemplo, "CRT-0:mp\did.bin". Tenga en cuenta que siempre se debe especificar un nombre de dispositivo de pantalla, incluso si solo se especifica un EDID.
--dac-8bit, --no-dac-8bit
La mayoría de las tarjetas Quadro utilizan por defecto una tabla de consulta (LUT) de color de 10 bits; la configuración de esta opción en VERDADERO fuerza a estas tarjetas gráficas a usar una (LUT) de 8 bits.
-d PROFUNDIDAD, --depth=PROFUNDIDAD
Establezca la profundidad predeterminada en PROFUNDIDAD; los valores válidos para PROFUNDIDAD son 8, 15, 16, 24 y 30.
--device=DISPOSITIVO
La utilidad nvidia-xconfig opera sobre uno o más dispositivos en el archivo de configuración X. Si se especifica esta opción, se utilizará el dispositivo llamado DISPOSITIVO en el archivo de configuración X. Si no se especifica esta opción, se utilizarán todos los dispositivos dentro del archivo de configuración X.
--disable-glx-root-clipping, --no-disable-glx-root-clipping

Este sitio no está asociado de ninguna forma con Arch Linux ni afiliado a este proyecto. El contenido es únicamente una traducción de las páginas del manual de Arch publicadas en man.archlinux.org.

Deshabilita o habilita el recorte de renderizado OpenGL a la ventana raíz a través de la opción de configuración X "DisableGLXRootClipping".
--damage-events, --no-damage-events
Utiliza eventos a nivel de sistema operativo para notificar al servidor X cuando un cliente de renderizado directo ha realizado un renderizado que necesita ser compuesto en la pantalla. Mejora el rendimiento al usar GLX con la extensión de composición.
--preserve-driver-name
Por defecto, nvidia-xconfig cambia el controlador de pantalla a "nvidia" para todas las pantallas X configuradas; esta opción preserva el nombre del controlador existente de cada pantalla X.
--egpu, --no-egpu
Habilita o deshabilita la opción de configuración X "AllowExternalGpus".
-a, --enable-all-gpus
Elimina todas las pantallas X existentes en la configuración actual, y luego configura una pantalla X en cada GPU de tu sistema.
--exact-mode-timings-dvi, --no-exact-mode-timings-dvi
Fuerza la inicialización del servidor X con los tiempos exactos especificados en ModeLine.
-E ARCHIVO, --extract-edids-from-file=ARCHIVO
Extrae cualquier bloque de bytes EDID en bruto contenido en el archivo de registro X especificado LOG; los bytes EDID en bruto son impresos por el controlador X de NVIDIA en el registro X en hexadecimal cuando el registro detallado está habilitado con la opción de línea de comandos del servidor X "-logverbose 6". Los EDID extraídos se escriben como datos binarios en archivos individuales. Estos archivos pueden ser utilizados posteriormente por el controlador X de NVIDIA a través de la opción de configuración X "CustomEDID".
--extract-edids-output-file=NOMBREARCHIVO
Cuando se utiliza la opción '--extract-edids-from-file', nvidia-xconfig escribe cualquier EDID extraído en un archivo, típicamente "edid.bin" en el directorio actual. Utiliza esta opción para especificar un nombre de archivo alternativo. Ten en cuenta que nvidia-xconfig, si es necesario, agregará un número único al nombre del archivo EDID para evitar sobrescribir archivos existentes (por ejemplo, "edid.bin.1" si "edid.bin" ya existe).
--flatpanel-properties=PROPIEDADES-FLATPANEL, --no-flatpanel-properties
Establece las propiedades del panel plano. Las propiedades admitidas son 'dithering' y 'ditheringmode'. Consulta el LEAME de NVIDIA 'Apéndice B. Opciones de Configuración X' para obtener más detalles sobre los valores y la sintaxis posibles.
--flip, --no-flip
Habilita o deshabilita el volteo de OpenGL
--force-generate
Fuerza la generación de un nuevo archivo de configuración X, ignorando cualquier archivo de configuración X del sistema existente. Esto no se recomienda normalmente, ya que elementos como el protocolo del ratón, la disposición del teclado, las rutas de las fuentes, etc., son configurados por tu distribución de Unix. Aunque nvidia-xconfig puede intentar inferir estos valores, es mejor utilizar el archivo de configuración X de tu distribución de Unix como base para cualquier cosa que nvidia-xconfig cree.
--force-stereo-flipping, --no-force-stereo-flipping
Normalmente, el volteo estéreo solo se realiza cuando hay un drawable estéreo visible. Esta opción fuerza el volteo estéreo incluso cuando no hay drawables estéreo visibles.
--handle-special-keys=CUANDO, --no-handle-special-keys
Especifica cuándo el servidor X debe usar el controlador de teclado incorporado para procesar combinaciones de teclas especiales (como Ctrl+Alt+Retroceso); consulta la página del manual de configuración X para obtener detalles. El valor de CUANDO puede ser 'Always', 'Never' o 'WhenNeeded'.
--include-implicit-metamodes, --no-include-implicit-metamodes
Habilita o deshabilita la opción de configuración X "IncludeImplicitMetaModes".
--keyboard=TECLADO
Al generar un nuevo archivo de configuración X (lo que ocurre cuando no se encuentra ningún archivo de configuración X del sistema o se especifica la opción '--force-generate'), utiliza TECLADO como tipo de teclado, en lugar de intentar sondear el sistema para determinar el tipo de teclado. Para obtener una lista de los tipos de teclado posibles, consulta la opción '--keyboard-list'.
--keyboard-driver=DRIVER
En la mayoría de los casos, nvidia-xconfig puede determinar automáticamente el controlador de teclado correcto a utilizar (ya sea 'kbd' o 'keyboard'). Utiliza esta opción para anular lo que nvidia-xconfig detecta. Normalmente, si estás utilizando un servidor X de X.Org, usa 'kdb'; si estás utilizando un servidor X de XFree86, usa 'keyboard'.
--keyboard-list
Imprime en la salida estándar los tipos de teclado disponibles reconocidos por la opción '--keyboard', y luego sale.
--layout=DISTRIBUCION
La utilidad nvidia-xconfig opera sobre un Server Layout dentro del archivo de configuración X. Si se especifica esta opción, se utilizará la distribución llamada DISTRIBUCION en el archivo de configuración X. Si no se especifica esta opción, se utilizará la primera distribución de servidor en el archivo de configuración X.
--mode=MODO
Añade el modo especificado a la lista de modos.
--mode-debug, --no-mode-debug
Habilita o deshabilita la opción de configuración X "ModeDebug"; cuando está habilitada, esta opción hace que el controlador X imprima detalles detallados sobre la validación de modos en el archivo de registro X.
--mode-list=LISTAMODOS
Elimina todos los modos existentes de la lista de modos de la configuración X y añade los especificados en la cadena LISTAMODOS.
--remove-mode=MODO
Elimina el modo especificado de la lista de modos.
--metamodes=METAMODOS
Añade la opción de configuración X MetaMode con el valor METAMODOS, que reemplazará cualquier opción MetaMode existente en el archivo de configuración X.
--mouse=RATON
Al generar un nuevo archivo de configuración X (lo que ocurre cuando no se encuentra ningún archivo de configuración X del sistema o se especifica la opción '--force-generate'), utiliza RATON como tipo de ratón, en lugar de intentar sondear el sistema para determinar el tipo de ratón. Para obtener una lista de los tipos de ratón posibles, consulta la opción '--mouse-list'.
--mouse-list
Imprime en la salida estándar los tipos de ratón disponibles reconocidos por la opción '--mouse', y luego sale.
--multisample-compatibility, --no-multisample-compatibility
Habilita o deshabilita el uso de búferes multisample frontales y traseros separados.
--nvidia-cfg-path=RUTA
La biblioteca nvidia-cfg se utiliza para comunicarse con el módulo del kernel de NVIDIA para consultar propiedades básicas de cada GPU en el sistema. Esta biblioteca normalmente solo es utilizada por nvidia-xconfig al configurar múltiples pantallas X. Esta opción indica a nvidia-xconfig dónde buscar esta biblioteca (en caso de que no pueda encontrarla por sí sola). Normalmente, esta opción no debería ser necesaria.
--only-one-x-screen
Deshabilita todas las pantallas X excepto una.
--overlay, --no-overlay
Habilita o deshabilita la opción de configuración X "Overlay".
--cioverlay, --no-cioverlay
Habilita o deshabilita la superposición de índice de color.
--overlay-default-visual, --no-overlay-default-visual
Habilita o deshabilita la opción de configuración X "OverlayDefaultVisual".
--transparent-index=INDICE, --no-transparent-index
Píxel a utilizar como transparente al usar superposiciones de índice de color. Los valores válidos para INDICE-TRANSPARENTE son 0-255.
-T, --post-tree
Al igual que la opción '--tree', pero pasa por el proceso completo de aplicar cualquier actualización solicitada por el usuario a la configuración X, antes de imprimir la configuración final en la salida estándar en formato de árbol. Efectivamente, esta opción simplemente hace que la configuración se imprima en la salida estándar como un árbol en lugar de escribir los resultados en un archivo.
--power-connector-check, --no-power-connector-check
Deshabilita o habilita la opción de configuración X "NoPowerConnectorCheck".
--probe-all-gpus, --no-probe-all-gpus
Deshabilita o habilita la opción de configuración X "ProbeAllGpus".
--query-gpu-info
Imprime información sobre todas las GPUs NVIDIA reconocidas en el sistema.
--registry-dwords=DWORDS-REGISTRO, --no-registry-dwords
Habilita o deshabilita la opción de configuración X "RegistryDwords".
--render-accel, --no-render-accel
Habilita o deshabilita la opción de configuración X "RenderAccel".
--render-extension, --no-render-extension
Deshabilita o habilita la opción de configuración X "NoRenderExtension".

OPCIONES

--allow-hmd=PERMITIR-HMD, --no-allow-hmd
Habilita o deshabilita la opción de configuración X "AllowHMD".
--prime, --no-prime
Habilita PRIME para el archivo de configuración X generado. No se puede ejecutar con --no-busid o --no-allow-empty-initial-configuration. En un sistema con más de 1 GPU, especifique la GPU a utilizar para PRIME con --busid o se seleccionará la primera disponible. Tenga en cuenta que para habilitar PRIME es necesario ejecutar "xrandr --setprovideroutputsource modesetting NVIDIA-0" y "xrandr --auto" después de la finalización.

EJEMPLOS

nvidia-xconfig
Lee un archivo de configuración X existente y lo adapta para usar el controlador NVIDIA. Si no se encuentra ningún archivo de configuración X, se crea uno nuevo en /etc/X11/xorg.conf con la configuración predeterminada.
nvidia-xconfig --post-tree --metamode-orientation=clone
Lee el archivo de configuración X existente, agrega la opción MetaModeOrientation y luego imprime el archivo de configuración resultante en la salida estándar en formato de árbol. El archivo de configuración no se modifica.
nvidia-xconfig --enable-all-gpus
Examina el sistema y configura una pantalla X para cada dispositivo de pantalla que encuentra.
nvidia-xconfig --mode=1600x1200
Agrega un modo de 1600x1200 a una configuración X existente.
nvidia-xconfig --mode-list=1600x1200 1280x1024
Elimina los modos existentes del archivo de configuración X, reemplazándolos con "1600x1200" y "1280x1024".
nvidia-xconfig --metamodes=1024x768 +0+0, 1024x768 +1024+0
Agrega el MetaMode "1024x768 +0+0, 1024x768 +1024+0" al archivo de configuración X existente, reemplazando cualquier opción de configuración X de MetaModes existente.
nvidia-xconfig --only-one-x-screen --sli=Auto
Configura el servidor X para que tenga una sola pantalla X que utilice SLI cuando esté disponible.
