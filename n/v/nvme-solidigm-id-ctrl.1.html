NVME-SOLIDIGM-ID-(1) Manual NVMe NVME-SOLIDIGM-ID-(1)

NOMBRE

nvme-solidigm-id-ctrl - Envía el comando NVMe Identify Controller, devuelve el resultado y la estructura

SINOPSIS

nvme solidigm id-ctrl <dispositivo> [--raw-binary | -b] [--vendor-specific | -V]
                              [--output-format=<fmt> | -o <fmt>] [--human-readable | -H]
                              [--verbose | -v] [--timeout=<seconds> | -t <seconds>]

DESCRIPCIÓN

Este comando es una extensión específica de Solidigm para el comando NVMe Identify Controller. Envía un comando NVMe Identify Controller al dispositivo especificado y proporciona el resultado y la estructura devuelta.

El parámetro <dispositivo> es obligatorio y puede ser tanto el dispositivo de caracteres NVMe (ej: /dev/nvme0) como un dispositivo de bloque de namespace (ej: /dev/nvme0n1).

Este comando incluye todas las opciones disponibles en el comando genérico nvme id-ctrl, incluyendo: - --raw-binary o -b - --vendor-specific o -V - --output-format=<fmt> o -o <fmt> - --human-readable o -H - --verbose o -v - --timeout=<seconds> o -t <seconds>

Para un uso detallado y opciones, consulte la documentación de nvme id-ctrl.

EJEMPLOS

•Envía el comando Identify Controller e interpreta la salida: 
# nvme solidigm id-ctrl /dev/nvme0
•Imprime la salida sin procesar en stdout: 
# nvme solidigm id-ctrl /dev/nvme0 --raw-binary
•Imprime la salida en formato JSON: 
# nvme solidigm id-ctrl /dev/nvme0 -o json
•Muestra los campos específicos del vendedor: 
# nvme solidigm id-ctrl /dev/nvme0 --vendor-specific
# nvme solidigm id-ctrl /dev/nvme0 -V
•Utiliza la salida legible por humanos: 
# nvme solidigm id-ctrl /dev/nvme0 --human-readable
# nvme solidigm id-ctrl /dev/nvme0 -H
