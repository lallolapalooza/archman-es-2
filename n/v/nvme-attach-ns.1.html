NOMBRE

nvme-attach-ns - Envía el comando NVMe attach namespace, devuelve el resultado.

SINOPSIS

nvme attach-ns <dispositivo> [--namespace-id=<nsid> | -n <nsid>]
                        [--controllers=<lista-ctrl,> | -c <lista-ctrl,>]
                        [--output-format=<fmt> | -o <fmt>] [--verbose | -v]

DESCRIPCIÓN

Para el dispositivo NVMe proporcionado, envía el comando nvme namespace attach para el identificador de namespace proporcionado, adjuntándolo a la lista de identificadores de controlador proporcionados.

El parámetro <dispositivo> es un dispositivo de carácter NVMe obligatorio (ej: /dev/nvme0) pero no un dispositivo de bloque de namespace (ej: /dev/nvme0n1).

OPCIONES

-n <nsid>, --namespace-id=<nsid>

El identificador de namespace a adjuntar pero que aún no está adjunto.

-c <lista-ctrl,>, --controllers=<lista-ctrl,>

La lista separada por comas de identificadores de controlador a los que adjuntar el namespace. Si no se proporciona una lista, el namespace se adjuntará al controlador <dispositivo> utilizado para este comando.

-o <fmt>, --output-format=<fmt>

Establece el formato de reporte a normal, json o binary. Solo se puede usar un formato de salida a la vez.

-v, --verbose

Aumenta el detalle de la información en la salida.

EJEMPLOS

Adjuntar el namespace 2 a los controladores con id 0x21 y 0x22:
# nvme attach-ns /dev/nvme1 -n 0x2 -c 0x21,0x22
Adjuntar el namespace 3 a nvme0:
# nvme attach-ns /dev/nvme0 -n 3
