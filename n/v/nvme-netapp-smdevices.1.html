NOMBRE

nvme-netapp-smdevices - Muestra información para cada ruta NVMe a un volumen E-Series

SINOPSIS

nvme netapp smdevices [--output-format=<fmt> | -o <fmt>] [--verbose | -v]

DESCRIPCIÓN

Muestra información específica del proveedor para cada ruta NVMe a un espacio de nombres E-Series conectado actualmente al host. Las rutas E-Series se identifican a partir de los nodos NVMe en /dev enviando un Identify Controller.

OPCIONES

-o <fmt>, --output-format=<fmt>

Establece el formato de informe en normal (predeterminado), column o json. Solo se puede usar un formato de salida a la vez.

-v, --verbose

Muestra información adicional de los dispositivos E-Series en el host.

EJEMPLOS

•Muestra información, en un formato basado en columnas, para cada ruta a un espacio de nombres E-Series. 
# nvme netapp smdevices -o column
