NOMBRE

nvme-resv-release - Liberar una reserva nvme

SINOPSIS

nvme resv-release <dispositivo> [--namespace-id=<nsid> | -n <nsid>]
                        [--crkey=<crkey> | -c <crkey>]
                        [--rtype=<rtype> | -t <rtype>]
                        [--rrela=<rrela> | -a <rrela>] [--iekey | -i]
                        [--output-format=<fmt> | -o <fmt>] [--verbose | -v]
                        [--timeout=<timeout>]

DESCRIPCIÓN

El comando Reservation Release se utiliza para liberar o borrar una reserva mantenida en un namespace.

OPCIONES

-n <nsid>, --namespace-id=<nsid>

Anula el campo nsid. Si se utiliza el dispositivo de carácter de administración, este parámetro es obligatorio.

-c <crkey>, --crkey=<crkey>

Clave de Reserva Actual (Current Reservation Key): Si la Acción de Registro de Reserva es 001b (es decir, Anular Registro de Clave de Reserva) o 010b (es decir, Reemplazar Clave de Reserva), entonces este campo contiene la clave de reserva actual asociada al host. Para todos los demás valores de la Acción de Registro de Reserva, este campo está reservado. El controlador ignora el valor de este campo cuando el bit Ignore Existing Key (IEKEY) se establece en ‘1’.

-t <rtype>, --rtype=<rtype>

Tipo de Reserva: Este campo especifica el tipo de reserva que se va a crear.
Valor Definición
0h Reservado
1h Reserva de Solo Escritura Exclusiva
2h Reserva de Acceso Exclusivo
3h Reserva de Solo Escritura - Solo Registrantes
4h Reserva de Acceso Exclusivo - Solo Registrantes
5h Reserva de Solo Escritura - Todos los Registrantes
6h Reserva de Acceso Exclusivo - Todos los Registrantes
07h-FFh Reservado

-a <rrela>, --rrela=<rrela>

Acción de Liberación de Reserva: Este campo especifica la acción de registro que se realiza con el comando.
Valor Definición
0 Liberar
1 Borrar
2-7 Reservado

-i, --iekey

Ignorar Clave Existente: Si este bit se establece en 1, la comprobación de Clave de Reserva Actual (CRKEY) se deshabilita y el comando se ejecutará correctamente independientemente del valor del campo CRKEY.

Opción indicadora, por defecto es 0.

-o <fmt>, --output-format=<fmt>

Establece el formato de informe en normal, json o binary. Solo se puede utilizar un formato de salida a la vez.

-v, --verbose

Aumenta el nivel de detalle de la información en la salida.

--timeout=<timeout>

Anula el valor de tiempo de espera predeterminado. En milisegundos.
