NOMBRE

nvme-solidigm-vs-fw-activate-history - Obtener el registro del historial de activación del firmware

SINOPSIS

nvme solidigm vs-fw-activate-history <dispositivo> [OPCIONES]

DESCRIPCIÓN

Este comando recupera el registro del historial de activación del firmware para dispositivos NVMe de Solidigm. Se redirige al plugin OCP para compatibilidad.

OPCIONES

-o <fmt>, --output-format=<fmt>

Establece el formato del informe en normal o json. Solo se puede usar un formato de salida a la vez. El valor predeterminado es normal.

EJEMPLOS

•Imprimir el registro del historial de activación del firmware en formato normal: 
# nvme solidigm vs-fw-activate-history /dev/nvme0
•Imprimir el registro del historial de activación del firmware en formato JSON: 
# nvme solidigm vs-fw-activate-history /dev/nvme0 -o json
