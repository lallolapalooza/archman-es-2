NOMBRE

nvme-resv-register - Registrar una reserva nvme

SINOPSIS

nvme resv-register <dispositivo> [--namespace-id=<nsid> | -n <nsid>]
                        [--crkey=<crkey> | -c <crkey>]
                        [--nrkey=<nrkey> | -k <nrkey>]
                        [--rrega=<rrega> | -r <rrega>]
                        [--cptpl=<cptpl> | -p <cptpl>] [--iekey | -i]
                        [--output-format=<fmt> | -o <fmt>] [--verbose | -v]
                        [--timeout=<timeout> | -t <timeout>]

DESCRIPCIÓN

El comando Reservation Register se utiliza para registrar, anular el registro o reemplazar una clave de reserva.

OPCIONES

-n <nsid>, --namespace-id=<nsid>

Anula el campo nsid. Si se utiliza el dispositivo de caracteres de administración, este parámetro es obligatorio.

-c <crkey>, --crkey=<crkey>

Clave de Reserva Actual: Si la Acción de Registro de Reserva es 001b (es decir, Anular Registro de Clave de Reserva) o 010b (es decir, Reemplazar Clave de Reserva), este campo contiene la clave de reserva actual asociada con el host. Para todos los demás valores de Acción de Registro de Reserva, este campo está reservado. El controlador ignora el valor de este campo cuando el bit Ignorar Clave Existente (IEKEY) se establece en '1'.

-k <nrkey>, --nrkey=<nrkey>

Nueva Clave de Reserva: Si la Acción de Registro de Reserva es 000b (es decir, Registrar Clave de Reserva) o 010b (es decir, Reemplazar Clave de Reserva), este campo contiene la nueva clave de reserva asociada con el host. Para todos los demás valores de Acción de Registro de Reserva, este campo está reservado.

-p <cptpl>, --cptpl=<cptpl>

Cambiar el estado de Persistencia a través de Pérdida de Energía: Este campo permite modificar el estado de Persistencia a través de Pérdida de Energía asociado con el namespace como un efecto secundario del procesamiento de este comando.
Valor Definición
0 Sin cambio en el estado PTPL
1 Reservado
2 Establecer el estado PTPL en '0'. Las reservas se liberan y los registrantes se borran al encender.
3 Establecer el estado PTPL en '1'. Las reservas y los registrantes persisten a través de una pérdida de energía.

-r <rrega>, --rrega=<rrega>

Acción de Registro de Reserva: Este campo especifica la acción de registro que se realiza mediante el comando.
Valor Definición
0 Registrar Clave de Reserva
1 Anular Registro de Clave de Reserva
2 Reemplazar Clave de Reserva
3-7 Reservado

-i, --iekey

Ignorar Clave Existente: Si este bit se establece en 1, la verificación de Clave de Reserva Actual (CRKEY) se deshabilita y el comando tendrá éxito independientemente del valor del campo CRKEY.

Opción de indicador, por defecto es 0.

-o <fmt>, --output-format=<fmt>

Establece el formato de reporte en normal, json o binary. Solo se puede usar un formato de salida a la vez.

-v, --verbose

Aumenta el detalle de la información en la salida.

-t <timeout>, --timeout=<timeout>

Anula el valor de tiempo de espera predeterminado. En milisegundos.
