NOMBRE

nvme-solidigm-clear-pcie-correctable-errors - Borrar contadores de errores corregibles de PCIe

SINOPSIS

nvme solidigm clear-pcie-correctable-errors <dispositivo> [--no-uuid | -n]

DESCRIPCIÓN

Este comando es una redirección al comando del plugin OCP para borrar contadores de errores corregibles de PCIe. Para un uso detallado y opciones, por favor, consulte la documentación de nvme ocp clear-pcie-correctable-error-counters.

El parámetro <dispositivo> es obligatorio y puede ser tanto el dispositivo de carácter NVMe (ej: /dev/nvme0) como el dispositivo de bloque (ej: /dev/nvme0n1).

OPCIONES

-n, --no-uuid

No intente detectar automáticamente el índice UUID para este comando (requerido para soporte antiguo OCP 1.0). Esta opción es necesaria para dispositivos que no soportan OCP 2.0 o NVMe 1.4.

EJEMPLOS

•Borrar contadores de errores corregibles de PCIe para el dispositivo: 
# nvme solidigm clear-pcie-correctable-errors /dev/nvme0
•Borrar contadores de errores corregibles de PCIe para un dispositivo OCP 1.0: 
# nvme solidigm clear-pcie-correctable-errors /dev/nvme0 --no-uuid
