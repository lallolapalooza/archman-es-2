NOMBRE

nvme-sndk-vs-cloud-log - Envía un Comando Único del Fabricante sndk vs-cloud-log, devuelve el resultado

SINOPSIS

nvme sndk vs-cloud-log <dispositivo> [--output-format=<normal|json> -o <normal|json>]
                        [--namespace-id=<nsid> | -n <nsid>]

DESCRIPCIÓN

Para el dispositivo NVMe dado, envía un Comando Único del Fabricante sndk vs-cloud-log y proporciona el registro de estado/salud.

El parámetro <dispositivo> es obligatorio y puede ser el dispositivo de caracteres NVMe (ej: /dev/nvme0) o el dispositivo de bloque (ej: /dev/nvme0n1).

Esto solo funcionará en dispositivos Sandisk que soporten esta característica. Los resultados para cualquier otro dispositivo son indefinidos.

En caso de éxito devuelve 0, código de error en caso contrario.

OPCIONES

-o <fmt>, --output-format=<fmt>

Establece el formato de reporte a normal o json. Solo se puede usar un formato de salida a la vez. Por defecto es normal.

-n <nsid>, --namespace-id=<nsid>

Establece el valor nsid del comando al nsid dado. Por defecto es 0xffffffff si no se proporciona. Esta opción puede no afectar a nada dependiendo de la página de registro, que puede o no ser específica de un espacio de nombres.

EJEMPLOS

•Hace que el programa emita el Comando Único del Fabricante sndk vs-cloud-log: 
# nvme sndk vs-cloud-log /dev/nvme0
