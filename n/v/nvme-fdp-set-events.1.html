NOMBRE

nvme-fdp-set-events - Habilita o deshabilita eventos FDP

SINOPSIS

nvme fdp set-events <dispositivo> [--namespace-id=<NUM> | -n <NUM>]
                        [--placement-handle=<NUM> | -p <NUM>] [--enable | -e]
                        [--event-types=<NUM,> | -t <NUM,>]

DESCRIPCIÓN

Para el dispositivo NVMe dado, habilita o deshabilita una lista de tipos de eventos para ser generados para la referencia del Handle de Unidad de Recuperación por el Handle de Colocación especificado.

OPCIONES

-n <NUM>, --namespace-id=<NUM>

Identificador de namespace.

-b, --raw-binary

Imprime el buffer crudo en el flujo de salida estándar.

-o <fmt>, --output-format=<fmt>

Establece el formato de reporte a normal, json, o binary. Solo se puede usar un formato de salida a la vez.
