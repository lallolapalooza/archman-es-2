NOMBRE

nvme-wdc-vs-device-waf - Calcula el factor de amplificación de escritura del dispositivo e imprime resultados TLC y SLC

SINOPSIS

nvme wdc vs-device-waf <dispositivo> [--output-format=<normal|json> -o <normal|json>]
                        [--namespace-id=<nsid> | -n <nsid>]

DESCRIPCIÓN

Para el dispositivo NVMe dado, calcula el factor de amplificación de escritura TLC y SLC del dispositivo.

El parámetro <dispositivo> es obligatorio y puede ser tanto el dispositivo de caracteres NVMe (ej: /dev/nvme0) como el dispositivo de bloque (ej: /dev/nvme0n1).

Esto solo funcionará en dispositivos WDC que soporten esta funcionalidad. Los resultados para cualquier otro dispositivo no están definidos.

En caso de éxito devuelve 0, código de error en caso contrario.

OPCIONES

-o <fmt>, --output-format=<fmt>

Establece el formato de informe a normal o json. Solo se puede usar un formato de salida a la vez. El valor predeterminado es normal.

-n <nsid>, --namespace-id=<nsid>

Establece el valor nsid del comando al nsid dado. El valor predeterminado es 0xffffffff si no se proporciona. Esta opción puede no tener efecto dependiendo de la página de registro, que puede ser específica o no de un espacio de nombres.

EJEMPLOS

•Hacer que el programa emita el comando del plugin WDC vs-device-waf: 
# nvme wdc vs-device-waf /dev/nvme0
