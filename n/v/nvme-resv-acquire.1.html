NOMBRE

nvme-resv-acquire - Adquirir una reserva nvme

SINOPSIS

nvme resv-acquire <dispositivo> [--namespace-id=<nsid> | -n <nsid>]
                        [--crkey=<crkey> | -c <crkey>]
                        [--prkey=<prkey> | -p <prkey>]
                        [--rtype=<rtype> | -t <rtype>]
                        [--racqa=<racqa> | -a <racqa>] [--iekey | -i]
                        [--output-format=<fmt> | -o <fmt>] [--verbose | -v]
                        [--timeout=<timeout>]

DESCRIPCIÓN

El comando Reservation Acquire se utiliza para adquirir una reserva en un namespace, para anular una reserva en posesión sobre un namespace y para abortar una reserva en posesión sobre un namespace.

OPCIONES

-n <nsid>, --namespace-id=<nsid>

Anula el campo nsid. Si se utiliza el dispositivo de carácter de administración, este parámetro es obligatorio.

-c <crkey>, --crkey=<crkey>

Clave de Reserva Actual (Current Reservation Key): El campo especifica la clave de reserva actual asociada al host. Si el bit IEKEY está establecido en '1' en el comando, la verificación CRKEY tiene éxito independientemente del valor de este campo.

-p <prkey>, --prkey=<prkey>

Clave de Preemptión de Reserva (Preempt Reservation Key): Si la Acción de Adquisición de Reserva se establece en 001b (es decir, Preempt) o 010b (es decir, Preempt y Abort), este campo especifica la clave de reserva que se anulará del namespace. Para todos los demás valores de Acción de Adquisición de Reserva, este campo está reservado.

-t <rtype>, --rtype=<rtype>

Tipo de Reserva (Reservation Type): Este campo especifica el tipo de reserva que se creará.
Valor Definición
0h Reservado
1h Reserva de Exclusividad de Escritura
2h Reserva de Acceso Exclusivo
3h Reserva de Exclusividad de Escritura - Solo Registrados
4h Reserva de Acceso Exclusivo - Solo Registrados
5h Reserva de Exclusividad de Escritura - Todos los Registrados
6h Reserva de Acceso Exclusivo - Todos los Registrados
07h-FFh Reservado

-a <racqa>, --racqa=<racqa>

Acción de Adquisición de Reserva (Reservation Acquire Action): Este campo especifica la acción que se realiza con el comando.
Valor Definición
0 Adquirir
1 Preemptir
2 Preemptir y Abortar
3-7 Reservado

-i, --iekey

Ignorar Clave Existente (Ignore Existing Key): Si este bit se establece en 1, se deshabilita la verificación de la Clave de Reserva Actual (CRKEY) y el comando deberá tener éxito independientemente del valor del campo CRKEY.

Opción indicadora, por defecto es 0.

-o <fmt>, --output-format=<fmt>

Establece el formato de informe en normal, json o binary. Solo se puede usar un formato de salida a la vez.

-v, --verbose

Aumenta el detalle de la información en la salida.

--timeout=<timeout>

Anula el valor de tiempo de espera predeterminado. En milisegundos.
