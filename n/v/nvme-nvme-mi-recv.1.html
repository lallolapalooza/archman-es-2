NOMBRE

nvme-nvme-mi-recv - Envía un comando NVMe-MI Receive al dispositivo especificado

SINOPSIS

nvme nvme-mi-recv <dispositivo> [--opcode=<código_operación> | -O <código_operación>]
                        [--namespace-id=<nsid> | -n <nsid>]
                        [--data-len=<longitud_datos> | -l <longitud_datos>]
                        [--nmimt=<tipo_mensaje_mi> | -m <tipo_mensaje_mi>]
                        [--nmd0=<nmd0> | -0 <nmd0>] [--nmd1=<nmd1> | -1 <nmd1>]
                        [--input-file=<archivo> | -i <archivo>]
                        [--output-format=<formato> | -o <formato>] [--verbose | -v]

DESCRIPCIÓN

Envía un comando NVMe-MI Receive al dispositivo especificado, devuelve los resultados.

El parámetro <dispositivo> es obligatorio y puede ser el dispositivo de caracteres NVMe (ej: /dev/nvme0) o el dispositivo de bloques (ej: /dev/nvme0n1).

En caso de éxito devuelve 0, código de error en caso contrario.

OPCIONES

-O <código_operación>, --opcode=<código_operación>

El código de operación NVMe-MI a enviar al dispositivo en el comando. Argumento requerido ya que este parámetro es obligatorio.

-n <nsid>, --namespace-id=<nsid>

El valor para el ns-id en el comando.

-l <longitud_datos>, --data-len=<longitud_datos>

La longitud de los datos para el búfer utilizado para este comando.

-m <tipo_mensaje_mi>, --nmimt=<tipo_mensaje_mi>

El valor para el tipo de mensaje NVMe-MI en el comando.

-0 <nmd0>, --nmd0=<nmd0>

El valor para la palabra 0 de la solicitud de gestión NVMe en el comando.

-1 <nmd1>, --nmd1=<nmd1>

El valor para la palabra 1 de la solicitud de gestión NVMe en el comando.

-i <archivo>, --input-file=<archivo>

Si el comando es un comando de salida de datos (escritura), utilice este archivo para rellenar el búfer enviado al dispositivo. Si no se proporciona ningún archivo, se asume que se utilizará STDIN.

-o <formato>, --output-format=<formato>

Establece el formato de informe en normal, json o binary. Solo se puede usar un formato de salida a la vez.

-v, --verbose

Aumenta el detalle de la información en la salida.

EJEMPLOS

•Hacer que el programa emita un nvme-mi-recv para ejecutar la lectura de VPD. 
# nvme nvme-mi-recv /dev/nvme0n1 -O 5 -m 1 -0 0 -1 0x100 -l 256
