NOMBRE

nvme-wdc-get-dev-capabilities-log - Envía el comando del plugin nvme wdc get-dev-capabilities-log, devuelve la salida del registro analizada

SINOPSIS

nvme wdc get-dev-capabilities-log <dispositivo> [--output-format=<fmt> | -o <fmt>]

DESCRIPCIÓN

Para el dispositivo NVMe dado, envía un comando del plugin WDC get-dev-capabilities-log y muestra los datos del registro de capacidades del dispositivo. La opción --output-format formateará la salida según se especifique.

El parámetro <dispositivo> es obligatorio y puede ser el dispositivo de caracteres NVMe (ej: /dev/nvme0).

Esto solo funcionará en dispositivos WDC que soporten esta página de registro. Los resultados para cualquier otro dispositivo no están definidos.

En caso de éxito, devuelve los datos analizados de la página de registro de capacidades del dispositivo; de lo contrario, devuelve un código de error.

OPCIONES

-o <fmt>, --output-format=<fmt>

Establece el formato de reporte a normal o json. Solo se puede usar un formato de salida a la vez. El valor por defecto es normal.

EJEMPLOS

•Hace que el programa emita el comando del plugin WDC get-dev-capabilities-log: 
# nvme wdc get-dev-capabilities-log /dev/nvme0
