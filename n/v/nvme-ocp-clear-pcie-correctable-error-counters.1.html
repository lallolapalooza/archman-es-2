NOMBRE

nvme-ocp-clear-pcie-correctable-error-counters - Limpiar los contadores de errores corregibles de PCIe

SINOPSIS

nvme ocp clear-pcie-correctable-error-counters <dispositivo> [--no-uuid | -n]

DESCRIPCIÓN

Para el dispositivo NVMe dado, limpia los contadores de errores corregibles de PCIe.

El parámetro <dispositivo> es obligatorio y puede ser el dispositivo de carácter NVMe (ej: /dev/nvme0) o el dispositivo de bloque (ej: /dev/nvme0n1).

Este comando sin opciones añadidas, intentará detectar automáticamente los parámetros del comando. Esto funcionará correctamente o fallará con elegancia para los dispositivos que soporten UUID para Información Específica del Fabricante (NVMe 1.4 o posterior, OCP 2.0 requiere NVMe 1.4b). Para los dispositivos que no soporten OCP 2.0 el comando fallará con elegancia, a menos que se proporcione la opción --no-uuid.

Para dispositivos OCP 1.0 (antes de NVMe 1.4) se requiere la opción --no-uuid. Cuando se proporciona la opción --no-uuid, los resultados para dispositivos anteriores a NVMe 1.4 sin soporte OCP son indefinidos.

En caso de éxito devuelve 0, código de error en caso contrario.

OPCIONES

-n, --no-uuid

No intente detectar automáticamente el índice UUID para este comando (requerido para soporte antiguo de OCP 1.0)

EJEMPLOS

•Limpia el registro de contadores de errores corregibles de PCIe para el dispositivo: 
# nvme ocp clear-pcie-correctable-error-counters /dev/nvme0
