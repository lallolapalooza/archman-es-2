NOMBRE

nvme-wdc-vs-smart-add-log - Envía un Comando Único del Proveedor WDC vs-smart-add-log, devuelve el resultado

SINOPSIS

nvme wdc vs-smart-add-log <dispositivo> [--interval=<NUM>, -i <NUM>]
                        [--output-format=<normal|json> -o <normal|json>]
                        [--log-page-version=<NUM>, -l <NUM>]
                        [--log-page-mask=<LIST>, -p <LIST>]
                        [--namespace-id=<nsid> | -n <nsid>]

DESCRIPCIÓN

Para el dispositivo NVMe dado, envía un Comando Único del Proveedor WDC vs-smart-add-log y proporciona el registro inteligente adicional.

El parámetro <dispositivo> es obligatorio y puede ser el dispositivo de carácter NVMe (ej: /dev/nvme0) o el dispositivo de bloque (ej: /dev/nvme0n1).

Esto solo funcionará en dispositivos WDC que soporten esta característica. Los resultados para cualquier otro dispositivo no están definidos.

En caso de éxito devuelve 0, código de error en caso contrario.

OPCIONES

-i <NUM>, --interval=<NUM>

Devuelve las estadísticas de un intervalo específico, por defecto 14. Este parámetro solo es válido para la página de registro 0xC1 y se ignora para todas las demás páginas de registro.

-o <fmt>, --output-format=<fmt>

Establece el formato de informe a normal o json. Solo se puede usar un formato de salida a la vez. Por defecto es normal.

-l <NUM>, --log-page-version=<NUM>

Versión de la Página de Registro: 0 = proveedor, 1 = WDC. Este parámetro solo es válido para la página de registro 0xC0 y se ignora para todas las demás páginas de registro.

-p <LIST>, --log-page-mask=<LIST>

Proporciona una lista separada por comas de las páginas de registro deseadas para mostrar. Los valores posibles son 0xc0, 0xc1, 0xca, 0xd0. Nota: No todas las páginas son compatibles con todas las unidades. El valor predeterminado es mostrar todas las páginas de registro compatibles.

-n <nsid>, --namespace-id=<nsid>

Establece el valor nsid del comando al nsid dado. Por defecto es 0xffffffff si no se proporciona. Esta opción puede no afectar a nada dependiendo de la página de registro, que puede o no ser específica de un espacio de nombres.

Valores válidos de Intervalo y descripción :-

Valor Descripción
1 Conjunto acumulado más reciente de cinco (5) minutos.
2-12 Conjuntos acumulados anteriores de cinco (5) minutos.
13 El conjunto total acumulado de los conjuntos 1 a 12 que contienen la hora anterior de estadísticas acumuladas.
14 El conjunto estadístico acumulado desde el encendido.
15 El conjunto estadístico acumulado durante toda la vida útil del dispositivo.

EJEMPLOS

• Hace que el programa emita un Comando Único del Proveedor WDC vs-smart-add-log con el intervalo predeterminado (14): 
# nvme wdc vs-smart-add-log /dev/nvme0
• Hace que el programa emita un Comando Único del Proveedor WDC vs-smart-add-log solo para la página de registro 0xCA: 
# nvme wdc vs-smart-add-log /dev/nvme0 -p 0xCA
• Hace que el programa emita un Comando Único del Proveedor WDC vs-smart-add-log para las páginas de registro 0xC0 y 0xCA: 
# nvme wdc vs-smart-add-log /dev/nvme0 -p 0xCA,0xC0
