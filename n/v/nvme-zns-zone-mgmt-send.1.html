NOMBRE

nvme-zns-zone-mgmt-send - Comando de envío de gestión de zona

SINOPSIS

nvme zns zone-mgmt-send <dispositivo> [--namespace-id=<NUM> | -n <NUM>]
                        [--start-lba=<IONUM>, -s <IONUM>] [--zsaso, -o]
                        [--select-all, -a] [--zsa=<NUM>, -z <NUM>]
                        [--data-len=<IONUM>, -l <IONUM>]
                        [--data=<ARCHIVO>, -d <ARCHIVO>]
                        [--timeout=<timeout> | -t <timeout>]

DESCRIPCIÓN

Para el dispositivo NVMe dado, emite el comando Zone Management Send con la acción de envío solicitada. Si el envío requiere datos adicionales, puede especificar la longitud de los datos. Si se requieren datos, la entrada será stdin por defecto. Alternativamente, los datos pueden provenir de un archivo que puede ser especificado.

OPCIONES

-n <NUM>, --namespace-id=<NUM>

Utilice el ID de espacio de nombres proporcionado para el comando. Si no se proporciona, se utilizará el ID de espacio de nombres del dispositivo de bloques. Si el comando se emite a un dispositivo que no es de bloques, el parámetro es obligatorio.

-s <lba>, --start-lba=<lba>

El LBA de inicio de la zona a gestionar y enviar.

-l <NUM>, --data-len=<NUM>

Longitud del búfer de datos de envío.

-o, --zsaso

Opción específica de acción de envío de zona.

-a, --select-all

Envía el comando a todas las zonas.

-z <NUM>, --zsa=<NUM>

Acción de envío de zona.

-l <IONUM>, --data-len=<IONUM>

Longitud del búfer si se requieren datos.

-d <ARCHIVO>, --data=<ARCHIVO>

Archivo opcional para datos (stdin por defecto).

-t <timeout>, --timeout=<timeout>

Anula el valor de tiempo de espera predeterminado. En milisegundos.

EJEMPLOS

•Enviar un comando de gestión de zona con la acción establecida en 1 (cerrar zona) al espacio de nombres 1, primera zona: 
# nvme zns zone-mgmt-send /dev/nvme0 -n 1 -s 0 -z 1
•Escribir "hola mundo" en el descriptor de zona para el espacio de nombres 1, primera zona (requiere que el dispositivo soporte una zona de datos extendida lo suficientemente grande) 
# echo "hola mundo" | nvme zns zone-mgmt-send /dev/nvme0 -n 1 -s 0 -z 0x10
