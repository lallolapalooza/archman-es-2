NOMBRE

nvme-sndk-cloud-boot-SSD-version - Muestra la versión de Cloud Boot SSD del plugin sndk

SINOPSIS

nvme sndk cloud-boot-SSD-version <dispositivo>

DESCRIPCIÓN

Para el dispositivo NVMe dado, este comando muestra la versión actual de Cloud Hyperscale Boot (si es compatible con el dispositivo).

El parámetro <dispositivo> es un dispositivo de caracteres NVMe obligatorio (ej: /dev/nvme0).

En caso de éxito devuelve 0, código de error en caso contrario.

EJEMPLOS

•Muestra la versión de SSD de arranque en la nube para el dispositivo: 
# nvme sndk cloud-boot-SSD-version /dev/nvme0

NVME

Parte del conjunto nvme-user.
