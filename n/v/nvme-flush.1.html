NOMBRE

nvme-flush - Comando de vaciado.

SINOPSIS

nvme flush <dispositivo> [--namespace-id=<nsid> | -n <nsid>]
                        [--output-format=<fmt> | -o <fmt>] [--verbose | -v]

DESCRIPCIÓN

El comando Flush deberá confirmar los datos y metadatos asociados con el(los) namespace(s) especificado(s) en medios no volátiles. El vaciado se aplica a todos los comandos completados antes de la presentación del comando Flush. El controlador también puede vaciar datos y/o metadatos adicionales de cualquier namespace.

OPCIONES

-n <nsid>, --namespace-id=<nsid>

Especifica el ID de namespace opcional para este comando. Por defecto es 0xffffffff, indicando vaciado para todos los namespaces.

-o <fmt>, --output-format=<fmt>

Establece el formato de informe a normal, json o binary. Solo se puede usar un formato de salida a la vez.

-v, --verbose

Aumenta el detalle de la información en la salida.
