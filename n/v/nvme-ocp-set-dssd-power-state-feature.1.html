NOMBRE

nvme-ocp-set-dssd-power-state-feature - Establecer el estado de energía DSSD

SINOPSIS

nvme ocp set-dssd-power-state-feature <dispositivo>
                        [--power-state=<fmt> | -p <fmt>] [--no-uuid | -n]
                        [--save | -s]

DESCRIPCIÓN

Para el dispositivo NVMe dado, recupera la característica de estado de energía DSSD de OCP.

El parámetro <dispositivo> es obligatorio y puede ser tanto el dispositivo de caracteres NVMe (ej: /dev/nvme0) como el dispositivo de bloques (ej: /dev/nvme0n1).

Esto solo funcionará en dispositivos compatibles con OCP que soporten esta característica. Los resultados para cualquier otro dispositivo no están definidos.

En caso de éxito devuelve 0, código de error en caso contrario.

OPCIONES

-p <fmt>, --power-state=<fmt>

Estado de energía DSSD a establecer en vatios.

EJEMPLOS

• Hace que el programa emita un comando set-dssd-power-state-feature para establecer el Estado de Energía DSSD en vatios.

# nvme ocp set-dssd-power-state-feature /dev/nvme0 -p <valor> -s <valor> -n <valor>
