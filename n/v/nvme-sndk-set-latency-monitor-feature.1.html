nvme-sndk-set-latency-monitor-feature(1)

Paquete: nvme-cli

Licencias: GPL-2.0-or-later

NVME-SNDK-SET-LAT(1) Manual NVMe NVME-SNDK-SET-LAT(1)

NOMBRE

nvme-sndk-set-latency-monitor-feature - Establecer las opciones de la función de monitor de latencia NVMe sndk

SINOPSIS

nvme sndk set-latency-monitor-feature <dispositivo>
                        [--active_bucket_timer_threshold=<NUM> | -t <NUM>]
                        [--active_threshold_a=<NUM> | -a <NUM>]
                        [--active_threshold_b=<NUM> | -b <NUM>]
                        [--active_threshold_c=<NUM> | -c <NUM>]
                        [--active_threshold_d=<NUM> | -d <NUM>]
                        [--active_latency_config=<NUM> | -f <NUM>]
                        [--active_latency_minimum_window=<NUM> | -w <NUM>]
                        [--debug_log_trigger_enable=<NUM> | -r <NUM>]
                        [--discard_debug_log=<NUM> | -l <NUM>]
                        [--latency_monitor_feature_enable=<NUM> | -e <NUM>]

DESCRIPCIÓN

Para el dispositivo NVMe dado, este comando establece las opciones de la función de monitor de latencia (si es compatible con el dispositivo).

El parámetro <dispositivo> es un dispositivo de caracteres NVMe obligatorio (ej: /dev/nvme0).

Los resultados de la configuración se pueden verificar con el comando get-latency-monitor-log.

En caso de éxito devuelve 0, de lo contrario, un código de error.

OPCIONES

-t <NUM>, --active_bucket_timer_threshold=<NUM>

El valor que carga el umbral del temporizador de cubeta activa; el valor predeterminado es 07E0h.

-a <NUM>, --active_threshold_a=<NUM>

El valor que se carga en el Umbral Activo A; el valor predeterminado es 05h.

-b <NUM>, --active_threshold_b=<NUM>

El valor que se carga en el Umbral Activo B; el valor predeterminado es 13h.

-c <NUM>, --active_threshold_c=<NUM>

El valor que se carga en el Umbral Activo C; el valor predeterminado es 1Eh.

-d <NUM>, --active_threshold_d=<NUM>

El valor que se carga en el Umbral Activo D; el valor predeterminado es 2Eh.

-f <NUM>, --active_latency_config=<NUM>

El valor que se carga en la Configuración de Latencia Activa. Esto configura cómo se actualizan tanto la Marca de Latencia Activa como los Campos de Latencia Medida Activa en una base de contador por comando de E/S (Lectura, Escritura, Desasignación); el valor predeterminado es 0FFFh.

-w <NUM>, --active_latency_minimum_window=<NUM>

El valor que se carga en la Ventana Mínima de Latencia Activa; el valor predeterminado es 0Ah.

-r <NUM>, --debug_log_trigger_enable=<NUM>

El valor que se carga en la Habilitación del Disparador de Registro de Depuración; cuando se establece en 1b, la primera vez que se incrementa la combinación de cubeta/contador se activa un registro de depuración. Cuando se borra a 0b, no se activará un registro de depuración cuando se incremente la combinación de cubeta/contador.

-l <NUM>, --discard_debug_log=<NUM>

Descartar Registro de Depuración. Cuando se borra a 00h, el registro de depuración, si existe, no se borrará. Cuando se establece en 01h, el registro de depuración se descartará para que se pueda activar otro registro. Todos los campos en la estructura de datos de Establecer Funciones son válidos. Cuando se establece en 02h, el registro de depuración se descartará para que se pueda activar otro registro. Ninguno de los otros campos de la estructura de datos de Establecer Funciones son válidos.

-e <NUM>, --latency_monitor_feature_enable=<NUM>

Habilitación de la Función de Monitor de Latencia; cuando se establece en 01h, la Función de Monitor de Latencia está habilitada. Cuando se borra a 00h, la Función de Monitor de Latencia está deshabilitada.

EJEMPLOS

•Establecer las opciones de la función de monitor de latencia NVMe sndk habilitada con valores predeterminados: 
# nvme sndk set-latency-monitor-feature /dev/nvme0 -e 1
•Establecer las opciones de la función de monitor de latencia NVMe sndk deshabilitada con valores predeterminados: 
# nvme sndk set-latency-monitor-feature /dev/nvme0 -e 0
•Establecer las opciones de la función de monitor de latencia NVMe sndk habilitada con valores específicos: 
# nvme sndk set-latency-monitor-feature /dev/nvme0 --active_bucket_timer_threshold=1 \
            --active_threshold_a=0x0 \
            --active_threshold_b=0x1 \
            --active_threshold_c=0x2 \
            --active_threshold_d=0x3 \
            --active_latency_config=0xfff \
            --active_latency_minimum_window=0 \
            --debug_log_trigger_enable=0 \
            --discard_debug_log=0 \
            --latency_monitor_feature_enable=0x1
