NOMBRE

nvme-io-passthru - Envía un comando IO arbitrario, devuelve resultados

SINOPSIS

nvme-io-passthru <dispositivo> [--opcode=<opcode> | -O <opcode>]
                        [--flags=<flags> | -f <flags>] [-rsvd=<rsvd> | -R <rsvd>]
                        [--namespace-id=<nsid> | -n <nsid>] [--cdw2=<cdw2> | -2 <cdw2>]
                        [--cdw3=<cdw3> | -3 <cdw3>] [--cdw10=<cdw10> | -4 <cdw10>]
                        [--cdw11=<cdw11> | -5 <cdw11>] [--cdw12=<cdw12> | -6 <cdw12>]
                        [--cdw13=<cdw13> | -7 <cdw13>] [--cdw14=<cdw14> | -8 <cdw14>]
                        [--cdw15=<cdw15> | -9 <cdw15>]
                        [--data-len=<data-len> | -l <data-len>]
                        [--metadata-len=<len> | -m <len>]
                        [--read | -r] [--write | -w]
                        [--input-file=<file> | -i <file>]
                        [--metadata=<file> | -M <file>]
                        [--timeout=<timeout> | -t <timeout>] [--show-command | -s]
                        [--dry-run | -d] [--raw-binary | -b]
                        [--prefill=<prefill> | -p <prefill>]
                        [--latency | -T]
                        [--output-format=<fmt> | -o <fmt>] [--verbose | -v]

DESCRIPCIÓN

Envía un comando IO NVMe arbitrario y devuelve los resultados aplicables. Esto puede ser simplemente el resultado y estado del comando, o también puede incluir un buffer si el comando devuelve uno. Este comando no realiza ninguna interpretación de los opcodes ni de las opciones.

El parámetro <dispositivo> es obligatorio y puede ser tanto el dispositivo de caracteres NVMe (ej: /dev/nvme0), como un dispositivo de bloque de namespace (ej: /dev/nvme0n1).

En caso de éxito, la estructura devuelta (si es aplicable) puede ser devuelta de varias maneras dependiendo de los flags de las opciones; la estructura puede ser impresa por el programa como un volcado hexadecimal, o puede ser devuelta como un buffer crudo impreso a stdout para que otro programa lo analice.

OPCIONES

-O <opcode>, --opcode=<opcode>

El opcode NVMe a enviar al dispositivo en el comando. Argumento requerido ya que este parámetro es obligatorio.

-f <flags>, --flags=<flags>

Los flags del comando NVMe a enviar al dispositivo en el comando.

-R <rsvd>, --rsvd=<rsvd>

El valor para el campo reservado en el comando.

-n <nsid>, --namespace-id=<nsid>

El valor para el ns-id en el comando. Por defecto es 0.

-[2-9] <cdw>, --cdw[2-3,10-15]=<cdw>

Especifica el valor del dword del comando para esa entrada especificada en el comando.

-r, --read, -w, --write

Usado para la dirección de datos del comando y requerido para comandos que envían/reciben datos. No usar read y write al mismo tiempo.

-i <archivo>, --input-file=<archivo>

Si el comando es un comando de salida de datos (escritura), usa este archivo para llenar el buffer enviado al dispositivo. Si no se da archivo, se asume que se usa STDIN. Si el comando es un comando de entrada de datos (lectura), los datos devueltos por el dispositivo se guardarán aquí.

-M <archivo>, --metadata=<archivo>

Si el comando es un comando de salida de datos (escritura), usa este archivo para llenar el buffer de metadatos enviado al dispositivo. Si no se da archivo, se asume que se usa STDIN. Si el comando es un comando de entrada de datos (lectura), los metadatos devueltos por el dispositivo se guardarán aquí.

-l <data-len>, --data-len=<data-len>

La longitud de datos para el buffer utilizado para este comando.

-m <data-len>, --metadata-len=<data-len>

La longitud de metadatos para el buffer utilizado para este comando.

-s, --show-cmd

Imprime el comando a ser enviado.

-d, --dry-run

No envía realmente el comando. Si se quiere usar la opción --dry-run, la opción --show-cmd *debe* ser establecida. De lo contrario, la opción --dry-run será *ignorada*.

-b, --raw-binary

Imprime el buffer devuelto crudo a stdout si el comando devuelve datos o una estructura.

-p <prefill>, --prefill <prefill>

Pre-llena el buffer con un valor de byte predeterminado. Por defecto es 0. Esto puede ser útil si los datos que estás escribiendo son más cortos que el buffer requerido y necesitas rellenarlo con un valor conocido. También puede ser útil si necesitas confirmar si un dispositivo está sobrescribiendo un buffer en un comando de entrada de datos.

-T, --latency

Imprime la latencia que tomó el IOCTL (en us).

-o <fmt>, --output-format=<fmt>

Establece el formato de reporte a *normal*, *json* o *binary*. Solo se puede usar un formato de salida a la vez.

-v, --verbose

Aumenta el nivel de detalle de la información en la salida.

-t <timeout>, --timeout=<timeout>

Sobrescribe el valor de tiempo de espera predeterminado. En milisegundos.

EJEMPLOS

nvme io-passthru /dev/nvme0n1 --opcode=2 --namespace-id=1 --data-len=4096 --read --cdw10=0 --cdw11=0 --cdw12=0x70000 --raw-binary
