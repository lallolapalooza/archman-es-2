NOMBRE

nvme-ocp-get-dssd-power-state-feature - Obtener el estado de alimentación DSSD

SINOPSIS

nvme ocp get-dssd-power-state-feature <dispositivo>
                        [--sel=<selección> | -S <selección>] [--all | -a]
                        [--no-uuid | -n]

DESCRIPCIÓN

Para el dispositivo NVMe dado, recupera el estado de alimentación DSSD OCP. Pasar --all llama a NVMe Get Feature tres veces, devolviendo los tres valores: actual, predeterminado y guardado.

El parámetro <dispositivo> es obligatorio y puede ser el dispositivo de caracteres NVMe (ej: /dev/nvme0) o el dispositivo de bloques (ej: /dev/nvme0n1).

Esto solo funcionará en dispositivos compatibles con OCP que soporten esta característica. Los resultados para cualquier otro dispositivo no están definidos.

En caso de éxito devuelve 0, código de error en caso contrario.

OPCIONES

-S <selección>, --sel=<selección>

Selección (SEL): Este campo especifica qué valor de los atributos se devolverá en los datos proporcionados:
Selección Descripción
0 Actual
1 Predeterminado
2 Guardado
3 Capacidades soportadas
4-7 Reservado

-a, --all

Mostrar los 3 valores a la vez: Estado de alimentación DSSD actual, Estado de alimentación DSSD predeterminado y Estado de alimentación DSSD guardado.

-n, --no-uuid

No intente detectar automáticamente el índice UUID para este comando (requerido para la compatibilidad con OCP 1.0 antiguo).

EJEMPLOS

•Haga que el programa emita un comando get-dssd-power-state-feature para obtener el estado de alimentación DSSD actual en vatios. 
# nvme ocp get-dssd-power-state-feature /dev/nvme0 -S 0
•Haga que el programa emita un comando get-dssd-power-state-feature para obtener los tres estados de alimentación DSSD en vatios. 
# nvme ocp get-dssd-power-state-feature /dev/nvme0 -a
