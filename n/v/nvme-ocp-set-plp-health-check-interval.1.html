nvme-ocp-set-plp-health-check-interval(1)

Paquete: nvme-cli

Licencias: GPL-2.0-or-later

NVME-OCP-SET-PLP() NVME-OCP-SET-PLP()

NOMBRE

nvme-ocp-set-plp-health-check-interval - Define y establece el intervalo de verificación de salud de PLP

SINOPSIS

nvme ocp set-plp-health-check-interval <dispositivo> [--plp_health_interval=<plp_health_interval> | -p <plp_health_interval>] [--save | -s] [--no-uuid | -n]

DESCRIPCIÓN

Define el intervalo de verificación de salud de PLP. Sin argumentos, imprime el modo actual.

El parámetro <dispositivo> es obligatorio y puede ser el dispositivo de caracteres NVMe (ej: /dev/nvme0) o el dispositivo de bloque (ej: /dev/nvme0n1).

Esto solo funcionará en dispositivos compatibles con OCP que soporten esta característica. Los resultados para cualquier otro dispositivo no están definidos.

En caso de éxito devuelve 0, código de error en caso contrario.

OPCIONES

-p <plp_health_interval>, --plp_health_interval=<plp_health_interval>

Establece el intervalo de verificación de salud de PLP [31:16]

-n, --no-uuid

No intentes detectar automáticamente el índice UUID para este comando (requerido para el soporte antiguo de OCP 1.0)

-s, --save

Guarda el atributo para que persista a través de todos los estados de energía y reinicios.

EJEMPLOS

• Haz que el programa emita un comando set-plp-health-check-interval para recuperar las características establecidas 0xC6. 
# nvme ocp eol-plp-failure-mode /dev/nvme0
