nvme-ocp-internal-log(1)

Paquete: nvme-cli

Licencias: GPL-2.0-or-later

NVME-OCP-INTERNAL() NVME-OCP-INTERNAL()

NOMBRE

nvme-ocp-internal-log - Recupera condicionalmente el registro de Telemetría Iniciada por el Host 07h, el registro de Cadenas OCP C9h de un dispositivo NVMe o de una ruta de archivo especificada por el usuario. Toma los registros recuperados y los decodifica en un formato de salida legible por humanos especificado por el usuario.

SINOPSIS

nvme ocp internal-log <dispositivo>
                        [--telemetry-log=<archivo> | -l <archivo>]
                        [--string-log=<archivo> | -s <archivo>]
                        [--output-file=<archivo> | -f <archivo>]
                        [--output-format=<fmt> | -o <fmt>]
                        [--data-area=<da> | -a <da>]
                        [--telemetry-type=<tipo> | -t <tipo>]

DESCRIPCIÓN

Recupera condicionalmente el registro de Telemetría Iniciada por el Host 07h, el registro de Cadenas OCP C9h de un dispositivo NVMe o de una ruta de archivo especificada por el usuario. Toma los registros recuperados y los decodifica (o) analiza en un formato de salida legible por humanos especificado por el usuario.

El parámetro <dispositivo> es obligatorio y puede ser el dispositivo de caracteres NVMe (ej: /dev/nvme0) o un dispositivo de bloque de namespace (ej: /dev/nvme0n1).

Esto solo funcionará en dispositivos compatibles con OCP que soporten esta característica. Los resultados para cualquier otro dispositivo no están definidos.

En caso de éxito devuelve 0, código de error en caso contrario.

OPCIONES

-l <archivo>, --telemetry-log=<archivo>

Nombre del archivo de datos binarios sin procesar de Telemetría Iniciada por el Host existente a utilizar. Si no se especifica una ruta, se realizará una recuperación en vivo de la carga útil en <dispositivo>.

-s <archivo>, --string-log=<archivo>

Nombre del archivo de datos binarios sin procesar del Registro de Cadenas OCP existente a utilizar. Si no se especifica una ruta, se realizará una recuperación en vivo de la carga útil en <dispositivo>.

-f <archivo>, --output-file=<archivo>

Nombre de la ruta de archivo utilizada como prefijo para los archivos binarios de registro de telemetría y cadenas, junto con el archivo de salida analizado legible por humanos.

-o <fmt>, --output-format=<fmt>

Establece el formato del informe en normal, json. Solo se puede usar un formato de salida a la vez, el valor predeterminado es json.

-a <da>, --data-area=<da>

Recupera el área de datos específica solicitada. Las entradas válidas son 1, 2, 3 o 4. Si esta opción no se especifica, el valor predeterminado es 1.

-t <tipo>, --telemetry-type=<tipo>

Establece el tipo de telemetría en host, host0, host1 o controller. Si se establece en host1, el controlador capturará los datos de Telemetría Iniciada por el Host que representan el estado interno del controlador en el momento en que se procesa el comando Get Log Page asociado. Si se establece en host0, el controlador no actualizará estos datos.

EJEMPLOS

•Recupera tanto del Registro de Cadenas OCP como del Registro de Telemetría Iniciada por el Host desde el dispositivo. Decodifica el área de datos predeterminada(s) en el formato predeterminado y muestra en la consola. 
# nvme ocp internal-log /dev/nvme0
•Recupera datos de Telemetría Iniciada por el Host, lee el Registro de Cadenas OCP localmente. Decodifica el área de datos predeterminada(s) en el formato predeterminado. 
# nvme ocp internal-log /dev/nvme0 --string-log=ocp_string_log.bin
 --output-file=output_file.json
•Recupera el Registro de Cadenas OCP, lee el Registro de Telemetría Iniciada por el Host localmente. Decodifica las áreas de datos 1 y 2, y muestra en formato json. 
# nvme ocp internal-log /dev/nvme0 --telemetry-log=host_telemetry.bin
 --output-format=json --output-file=output_file.json --data-area=2
•Lee tanto el Registro de Cadenas OCP como el Registro de Telemetría Iniciada por el Host localmente. Decodifica las áreas de datos 1 y 2, y muestra en formato de texto normal. 
# nvme ocp internal-log /dev/nvme0 --string-log=ocp_string_log.bin
 --telemetry-log=host_telemetry.bin --output-format=normal
 --output-file=output_file.txt --data-area=2
