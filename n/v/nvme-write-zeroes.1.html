NOMBRE

nvme-write-zeroes - Envía un comando NVMe de escritura de ceros, devuelve resultados

SINOPSIS

nvme-write-zeroes <dispositivo> [--start-block=<slba> | -s <slba>]
                        [--block-count=<nlb> | -c <nlb>]
                        [--ref-tag=<reftag> | -r <reftag>]
                        [--prinfo=<prinfo> | -p <prinfo>]
                        [--app-tag-mask=<appmask> | -m <appmask>]
                        [--app-tag=<apptag> | -a <apptag>] [--deac | -d]
                        [--limited-retry | -l] [--force-unit-access | -f]
                        [--namespace-id=<nsid> | -n <nsid>]
                        [--storage-tag<storage-tag> | -S <storage-tag>]
                        [--storage-tag-check<storage-tag-check> | -C <storage-tag-check>]
                        [--dir-type=<dtype> | -T <dtype>]
                        [--dir-spec=<dspec> | -D <dspec>] [--namespace-zeroes | -Z]
                        [--output-format=<fmt> | -o <fmt>] [--verbose | -v]
                        [--timeout=<timeout> | -t <timeout>]

DESCRIPCIÓN

El comando Write Zeroes se utiliza para establecer un rango de bloques lógicos a 0.

OPCIONES

-s <slba>, --start-block=<slba>

Bloque de inicio.

-c <nlb>, --block-count=<nlb>

Número de bloques lógicos a escribir ceros.

-p <prinfo>, --prinfo=<prinfo>

Definición del campo Información de Protección.
Bit Descripción
3 PRACT: Acción de Información de Protección. Cuando se establece en 1, la PI se elimina/inserta en la lectura/escritura cuando el tamaño de metadatos del formato de bloque es 8. Cuando se establece en 0, los metadatos se pasan.
2:0 PRCHK: Comprobación de Información de Protección:
2 Establecido en 1 habilita la comprobación de la etiqueta guardián
1 Establecido en 1 habilita la comprobación de la etiqueta de aplicación
0 Establecido en 1 habilita la comprobación de la etiqueta de referencia

-r <reftag>, --ref-tag=<reftag>

Etiqueta de referencia opcional cuando se utiliza con información de protección.

-m <appmask>, --app-tag-mask=<appmask>

Máscara de etiqueta de aplicación opcional cuando se utiliza con información de protección.

-a <apptag>, --app-tag=<apptag>

Etiqueta de aplicación opcional cuando se utiliza con información de protección.

-l, --limited-retry

Establece la bandera de reintento limitado.

-d, --deac

Establece el bit DEAC, solicitando que el controlador desasigne los bloques lógicos.

-f, --force-unit-access

Establece la bandera de acceso forzado a la unidad.

-n <nsid>, --namespace-id=<nsid>

ID de namespace utilizada en el comando.

-S <storage-tag>, --storage-tag=<storage-tag>

Etiqueta de Almacenamiento de Bloque Lógico de Tamaño Variable (LBST).

-C <storage-tag-check>, --storage-tag-check=<storage-tag-check>

Este bit especifica que el campo de Etiqueta de Almacenamiento se comprobará como parte del procesamiento de protección de datos de extremo a extremo.

-T <dtype>, --dir-type=<dtype>

Tipo de directiva

-D <dspec>, --dir-spec=<dspec>

Específico de la directiva

-Z, --namespace-zeroes

Si se establece, entonces el controlador borrará todos los bloques lógicos a cero en todo el namespace.

-o <fmt>, --output-format=<fmt>

Establece el formato de informe en normal, json o binary. Solo se puede utilizar un formato de salida a la vez.

-v, --verbose

Aumenta el detalle de la información en la salida.

-t <timeout>, --timeout=<timeout>

Anula el valor de tiempo de espera predeterminado. En milisegundos.
