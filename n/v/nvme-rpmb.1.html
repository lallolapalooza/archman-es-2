NOMBRE

nvme-rpmb - Envía comandos RPMB a un dispositivo NVMe

SINOPSIS

nvme rpmb <dispositivo> [--cmd=<comando> | -c <comando>]
                        [--msgfile=<archivo-datos> | -f <archivo-datos>]
                        [--keyfile=<archivo-clave> | -g <archivo-clave>]
                        [--key=<clave> | -k <clave>] [--msg=<datos> | -d <datos>]
                        [--address=<desplazamiento> | -o <desplazamiento>]
                        [--blocks=<sectores de 512 bytes> | -b <sectores>]
                        [--target=<id-objetivo> | -t <id>]
                        [--output-format=<formato> | -o <formato>] [--verbose | -v]

DESCRIPCIÓN

Para el dispositivo NVMe especificado, envía un comando nvme rpmb y proporciona los resultados.

El parámetro <dispositivo> es obligatorio y se debe especificar el dispositivo de caracteres NVMe (ej: /dev/nvme0). Si el dispositivo dado soporta objetivos RPMB, el comando dado con la opción --cmd o -c se enviará al controlador. Si el dispositivo NVMe dado no soporta objetivos RPMB, se imprimirá un mensaje indicando lo mismo junto con los valores de los registros del controlador relacionados con RPMB.

OPCIONES

-c <comando>, --cmd=<comando>

Comando RPMB a enviar al dispositivo. Puede ser uno de los siguientes: 
info          - imprime información sobre los objetivos RPMB soportados y
                el acceso y los tamaños totales. No se requieren argumentos
                adicionales.
program-key   - programa la 'clave' especificada con la opción -k o la clave
                leída del archivo especificado con la opción --keyfile en el
                objetivo RPMB especificado con las opciones --target o -t.
                Según la especificación, esta es una acción única que no se
                puede deshacer.
read-counter  - Lee el 'contador de escrituras' del objetivo RPMB especificado.
                El valor del contador leído se imprime en STDOUT.
read-config   - Lee 512 bytes del bloque de datos de configuración del
                dispositivo del objetivo RPMB especificado del dispositivo
                NVMe. Los datos leídos se escriben en el archivo de entrada
                especificado con la opción --msgfile o -f.
write-config  - Escribe 512 bytes del bloque de datos de configuración del
                dispositivo desde el archivo especificado con las opciones
                --msgfile o -f en el objetivo RPMB especificado con las
                opciones --target o -t.
read-data     - Soporta la lectura de datos autenticada desde el objetivo
                RPMB especificado (opción --target o -t) en el desplazamiento
                dado especificado con la opción --address o -o, utilizando la
                clave especificada mediante las opciones --keyfile o -k. Se
                deben indicar las opciones --blocks o -o para leer la cantidad
                de datos a leer en bloques de 512 bytes.
write-data    - Soporta la escritura de datos autenticada en el objetivo
                RPMB especificado (opción --target o -t) en el desplazamiento
                dado especificado con la opción --address o -o, utilizando la
                clave especificada mediante las opciones --keyfile o -k. Se
                deben indicar las opciones --blocks o -o para indicar la
                cantidad de datos a escribir en bloques de 512 bytes.
Para los comandos de transferencia de datos (lectura/escritura), si el tamaño
especificado no está dentro del tamaño total soportado por un objetivo, la
solicitud falla sin enviarla al dispositivo. El objetivo RPMB 0 se utiliza como
objetivo predeterminado si no se especifica --target o -t. Se utiliza 0x0 como
desplazamiento predeterminado si no se especifica la opción -address o -o.

-t <objetivo>, --target=<objetivo>

ID del objetivo RPMB. Debe ser uno de los objetivos RPMB soportados según lo informado por el comando info. Si no se proporciona nada, se usa el valor predeterminado 0 como objetivo RPMB.

-k <clave>, --key=<clave>, -g <archivo-clave>, --keyfile=<archivo-clave>

Clave de autenticación a utilizar para los comandos de lectura/escritura. Debe haber sido programada previamente por el comando program-key para el objetivo dado. La clave se puede especificar en la línea de comandos usando las opciones --key o -k. La clave también se puede especificar usando el argumento de archivo especificado con las opciones --keyfile o -g.

-f <archivo-datos>, --msgfile=<archivo-datos>

Nombre del archivo a utilizar para los comandos de transferencia de datos (lectura o escritura). Para el comando de lectura, si se especifica un archivo existente, se agregará al final.

-d <datos>, --msg=<datos>

Estas opciones proporcionan los datos en la propia línea de comandos.

-o <desplazamiento>, --address=<desplazamiento>

El desplazamiento (en sectores de 512 bytes desde 0) a utilizar para los comandos de transferencia de datos (lectura o escritura) para un objetivo RPMB especificado.

-b, --blocks=<sectores>

El tamaño en sectores de 512 bytes a utilizar para los comandos de transferencia de datos (lectura o escritura) para un objetivo RPMB especificado.

-o <formato>, --output-format=<formato>

Establece el formato de informe en normal, json o binary. Solo se puede usar un formato de salida a la vez.

-v, --verbose

Aumenta el nivel de detalle de la información en la salida.

EJEMPLOS

•Imprime información de soporte RPMB de un dispositivo NVMe 
# nvme rpmb /dev/nvme0 --cmd=info
•Programa SecretKey como clave de autenticación para el objetivo 1 
# nvme rpmb /dev/nvme0 --cmd=program-key -key='SecretKey' --target=1
•Lee el contador de escrituras actual del objetivo RPMB 0 
# nvme rpmb /dev/nvme0 --cmd=read-counter --target=0
•Lee el bloque de datos de configuración del objetivo 2 en el archivo config.bin 
# nvme rpmb /dev/nvme0 --cmd=read-config --target=2 -f config.bin
•Escribe 200 bloques (de 512 bytes) desde input.bin en el objetivo 0 
# nvme rpmb /dev/nvme0 -c write-data -t 0 -f input.bin -b 200 -k 'SecretKey'
•Lee 200 bloques (de 512 bytes) desde el objetivo 2, en el desplazamiento 0x100 y guarda los
•datos en output.bin 
# nvme rpmb /dev/nvme0 -c read-data -t 2 -f out.bin -b 200 -o 0x100
