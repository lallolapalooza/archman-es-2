NOMBRE

nvme-micron-nand-stats - Recupera estadísticas NAND de un dispositivo Micron dado

SINOPSIS

nvme micron vs-nand-stats <dispositivo>

DESCRIPCIÓN

Este comando imprime información NAND (bytes totales escritos, conteo de bloques defectuosos, fallos de borrado, etc.) para el dispositivo Micron dado.

El parámetro <dispositivo> es obligatorio y puede ser el dispositivo de caracteres NVMe (ej: /dev/nvme0) o un dispositivo de bloque de espacio de nombres (ej: /dev/nvme0n1).

Esto solo funcionará en dispositivos Micron con números de modelo 54XX. El soporte para nuevos dispositivos puede añadirse posteriormente.

OPCIONES

Ninguna

EJEMPLOS

•Recuperar información de estadísticas NAND 
# nvme micron vs-nand-stats /dev/nvme0
