NVME-SMART-LOG(1) Manual NVMe NVME-SMART-LOG(1)

NOMBRE

nvme-smart-log - Envía una solicitud de página de registro SMART NVMe, devuelve el resultado y el registro

SINOPSIS

nvme smart-log <dispositivo> [--namespace-id=<nsid> | -n <nsid>]
                        [--raw-binary | -b]
                        [--output-format=<fmt> | -o <fmt>] [--verbose | -v]

DESCRIPCIÓN

Recupera la página de registro SMART NVMe de un dispositivo NVMe y proporciona la estructura devuelta.

El parámetro <dispositivo> es obligatorio y puede ser tanto el dispositivo de caracteres NVMe (ej: /dev/nvme0), como un dispositivo de bloque de namespace (ej: /dev/nvme0n1).

En caso de éxito, la estructura de registro inteligente devuelta puede ser devuelta de varias maneras dependiendo de las opciones; la estructura puede ser analizada por el programa e impresa en un formato legible, o el buffer crudo puede ser impreso en la salida estándar para que otro programa lo analice.

OPCIONES

-n <nsid>, --namespace-id=<nsid>

Recupera el registro SMART para el nsid dado. Esto es opcional y su éxito puede depender de las capacidades del dispositivo para proporcionar este registro por namespace (ver la Identificación del Controlador NVMe para esta capacidad). El nsid predeterminado a usar es 0xffffffff para el registro SMART global del dispositivo.

-b, --raw-binary

Imprime el buffer crudo del registro SMART en la salida estándar.

-o <fmt>, --output-format=<fmt>

Establece el formato de informe a normal, json o binary. Solo se puede usar un formato de salida a la vez.

-v, --verbose

Aumenta el nivel de detalle de la información en la salida.

EJEMPLOS

•Imprime la página de registro SMART en un formato legible por humanos: 
# nvme smart-log /dev/nvme0
•Imprime el registro SMART crudo en un archivo: 
# nvme smart-log /dev/nvme0 --raw-binary > smart_log.raw

Probablemente sea una mala idea no redirigir la salida estándar al usar este modo.
