NVME-MICRON-SELECTIVE-DOWNLOAD(1) Manual NVMe NVME-MICRON-SELECTIVE-DOWNLOAD(1)

NOMBRE

nvme-micron-selective-download - Realiza una descarga selectiva de firmware que permite al usuario seleccionar qué binario de firmware actualizar para los dispositivos 9200. Esto requiere un ciclo de energía una vez que se completa la actualización.

SINOPSIS

nvme micron selective-download <dispositivo> [--fw=<ARCHIVO>, -f <ARCHIVO>]
                        [--select=<flag>, -s <flag>]

DESCRIPCIÓN

Este comando utiliza comandos NVMe específicos del proveedor Micron para descargar la imagen de firmware dada al dispositivo 9200 para actualizar porciones seleccionadas o todas las porciones de la imagen de firmware.

El parámetro <dispositivo> es obligatorio y puede ser el dispositivo de caracteres NVMe (ej: /dev/nvme0) o un dispositivo de bloque de namespace (ej: /dev/nvme0n1).

Esto solo funcionará en dispositivos Micron de número de modelo 9200. Se puede agregar soporte para nuevos dispositivos posteriormente. Los resultados para cualquier otro dispositivo no están definidos.

OPCIONES

-f <ARCHIVO>, --fw=<ARCHIVO>

nombre del archivo de la imagen de firmware

-s <flag>, --select=<flag>

bandera que tiene los siguientes valores

OOB

Esto actualiza el firmware OOB y principal "

EEP

Esto actualiza la eeprom y el firmware principal "

ALL

Esto actualiza la eeprom, OOB y el firmware principal";

EJEMPLOS

● Actualizar firmware OOB y principal 
# nvme micron selective-download /dev/nvme0 --fw=firmware_bin --select=OOB
# nvme micron selective-download /dev/nvme0 -f firmware_bin -s OOB
● Actualizar firmware OOB y principal 
# nvme micron selective-download /dev/nvme0 --fw=firmware_bin --select=EEP
# nvme micron selective-download /dev/nvme0 -f firmware_bin --s EEP
● Actualizar eeprom, OOB y firmware principal 
# nvme micron selective-download /dev/nvme0 --fw=firmware_bin --select=ALL
# nvme micron selective-download /dev/nvme0 -f firmware_bin --s ALL
