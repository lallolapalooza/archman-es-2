NOMBRE

nvme-dim - Envía el comando Discovery Information Management a uno o varios Controladores de Descubrimiento.

SINOPSIS

nvme dim [--tarea=<tarea> | -t <tarea>] [--nqn=<nqn> | -n <nqn>]
                        [--dispositivo=<dispositivo> | -d <dispositivo>]
                        [--formato-salida=<fmt> | -o <fmt>] [--detallado | -v]

DESCRIPCIÓN

Envía el comando Discovery Information Management (DIM) a uno o varios Controladores de Descubrimiento. El comando DIM permite realizar dos tipos de tareas: registrar o anular el registro.

El comando DIM se utiliza para registrarse explícitamente con los Controladores de Descubrimiento (DC), especialmente con los Controladores de Descubrimiento Centrales (CDC). Los CDC mantienen una base de datos (DB) de todos los Hosts y Subsistemas de Almacenamiento en una red. La tarea de registro se utiliza para añadir un host a la DB del CDC. La tarea de anular el registro se utiliza para eliminar un host de la DB del CDC.

Durante una operación de registro, el host enviará información obligatoria como el NQN y el ID del Host, así como el nombre de host del Host y la versión del Sistema Operativo que está ejecutando. También hay un Nombre Simbólico de Host opcional que se puede registrar con el CDC.

Este comando solo se puede aplicar a conexiones de DC existentes creadas previamente con el comando nvme-discover(1) utilizando la opción --persistente.

OPCIONES

-t <tarea>, --tarea <tarea>

La tarea a realizar: "registrar" o "anular el registro".

-n <subnqn>, --nqn <nqn>

El comando DIM se enviará al Controlador de Descubrimiento (DC) que coincida con este NQN. Se puede proporcionar una lista de NQNs separados por comas para aplicar el comando a más de un DC.

-d <dispositivo>, --dispositivo <dispositivo>

El comando DIM se enviará a los Controladores de Descubrimiento (DC) asociados con este identificador de dispositivo NVMe. Se puede proporcionar una lista de identificadores de dispositivo separados por comas para aplicar el comando a más de un DC.

-o <fmt>, --formato-salida=<fmt>

Establece el formato de informe en normal, json o binario. Solo se puede usar un formato de salida a la vez.

-v, --detallado

Aumenta el nivel de detalle de la información en la salida.

EJEMPLOS

•Registrarse en el Controlador de Descubrimiento Central (CDC) llamado nqn.1988-11.com.dell:SFSS:1:20220118125153e8: 
# nvme dim --tarea=registrar --nqn=nqn.1988-11.com.dell:SFSS:1:20220118125153e8
•Anular el registro del Controlador de Descubrimiento Central (CDC) asociado con nvme4 
# nvme dim --tarea=anular el registro --dispositivo=nvme4
