NOMBRE

nvme-dir-send - Emite un comando directive send de NVMe, devuelve los resultados aplicables

SINOPSIS

nvme dir-send <dispositivo> [--namespace-id=<nsid> | -n <nsid>]
                        [--data-len=<data-len> | -l <data-len>]
                        [--dir-type=<dtype> | -D <dtype>]
                        [--dir-spec=<dspec> | -S <dspec>]
                        [--dir-oper=<doper> | -O <doper>]
                        [--endir=<endir> | -e <endir>]
                        [--target-dir=<tdir> | -T <tdir>]
                        [--human-readable | -H] [--raw-binary | -b]
                        [--output-format=<fmt> | -o <fmt>] [--verbose | -v]
                        [--timeout=<timeout> | -t <timeout>]

DESCRIPCIÓN

Envía un comando admin NVMe Directive Send y devuelve los resultados aplicables. Esto puede ser la combinación del tipo de directiva y la operación, así como la directiva de destino y su estado de habilitación/deshabilitación de la operación, si la operación específica lo necesita.

El parámetro <dispositivo> es obligatorio y puede ser el dispositivo de caracteres NVMe (ej: /dev/nvme0) o un dispositivo de bloque de namespace (ej: /dev/nvme0n1).

En caso de éxito, la estructura de parámetros de la directiva devuelta (si aplica) se devuelve de una de varias maneras dependiendo de las opciones; la estructura puede ser analizada por el programa y mostrada en hexadecimal, o el buffer crudo puede ser impreso a stdout para que otro programa lo analice.

OPCIONES

-n <nsid>, --namespace-id=<nsid>

Recupera la característica para el nsid dado. Esto es opcional y la mayoría de las características no utilizan este valor.

-D <dtype>, --dir-type=<dtype>

Tipo de directiva

-S <dspec>, --dir-spec=<dspec>

Específico de la directiva

-O <doper>, --dir-oper=<doper>

Operación de la directiva

-T <tdir>, --target-dir=<nsr>

Directiva de destino de la operación

-e <endir>, --endir=<endir>

Habilitar (1) o deshabilitar (0) la operación de la directiva de destino
Seleccionar Descripción
0 Actual
1 Por defecto
2 Guardado
3 Capacidades soportadas
4–7 Reservado

-l <data-len>, --data-len=<data-len>

La longitud de los datos para el buffer devuelto para esta característica. La mayoría de las características conocidas no utilizan este valor. La excepción es el Tipo de Rango LBA

-b, --raw-binary

Imprime el buffer de recepción crudo a stdout si el comando devuelve una estructura.

-H, --human-readable

obsoleto; no hace nada, así que usa la opción --verbose en su lugar.

-o <fmt>, --output-format=<fmt>

Establece el formato de informe en normal, json o binary. Solo se puede usar un formato de salida a la vez.

-v, --verbose

Aumenta el nivel de detalle de la información en la salida.

-t <timeout>, --timeout=<timeout>

Anula el valor de tiempo de espera predeterminado. En milisegundos.

EJEMPLOS

•Habilitar la directiva de streams : 
# nvme dir-send /dev/nvme0n1 --dir-type 0 --dir-oper 1 --target-dir 1 --endir 1
•Deshabilitar la directiva de streams : 
# nvme dir-send /dev/nvme0n1 --dir-type 0 --dir-oper 1 --target-dir 1 --endir 0
•Liberar todos los recursos de streams asignados : 
# nvme dir-send /dev/nvme0n1 --dir-type 1 --dir-oper 2
•Liberar el stream ID 3 : 
# nvme dir-send /dev/nvme0 --dir-type 1 --dir-oper 1 --dir-spec 3

Probablemente sea una mala idea no redirigir stdout al usar este modo.
