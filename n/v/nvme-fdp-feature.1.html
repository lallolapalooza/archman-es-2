NOMBRE

nvme-fdp-feature - Mostrar o cambiar la característica de Colocación Flexible de Datos (FDP)

SINOPSIS

nvme fdp <dispositivo> [--endgrp-id=<NUM> | -e <NUM>]
                [--enable-conf-idx=<NUM> | -c <NUM>]
                [--disable | -d]
                [--verbose | -v]

DESCRIPCIÓN

Para el dispositivo NVMe dado, configurar y gestionar la característica de Colocación Flexible de Datos (FDP).

Este comando se puede utilizar para mostrar la configuración actual de la característica FDP o para cambiarla.

 Si no se proporcionan las opciones `--enable-conf-idx` o `--disable`, se muestra la configuración actual.

Si se proporcionan las opciones --enable-conf-idx o --disable, la configuración se cambia en consecuencia. El dispositivo puede rechazar el cambio si hay un espacio de nombres.

El parámetro <dispositivo> es obligatorio y debe ser un dispositivo de caracteres NVMe (ej: /dev/nvme0)

OPCIONES

-e <NUM>, --endgrp-id=<NUM>

Especificar el ID del grupo de resistencia. Esta opción es obligatoria si el dispositivo admite grupos de resistencia.

-c <NUM>, --enable-conf-idx=<NUM>

Habilitar la característica FDP con la configuración especificada. El índice de configuración coincide con la posición listada por nvme-fdp-config(1).

-d, --disable

Deshabilitar la configuración actual de la característica FDP.

-v, --verbose

Aumentar la verbosidad de la salida.

VER TAMBIÉN

nvme-list-endgrp(1) nvme-fdp-config(1)
