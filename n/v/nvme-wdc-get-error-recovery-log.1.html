NOMBRE

nvme-wdc-get-error-recovery-log - Envía el comando del plugin NVMe WDC get-error-recovery-log, devuelve la salida del log analizada

SINOPSIS

nvme wdc get-error-recovery-log <dispositivo> [--output-format=<normal|json>
-o <normal|json>]

DESCRIPCIÓN

Para el dispositivo NVMe dado, envía un comando del plugin WDC get-error-recovery-log y muestra los datos del log de recuperación de errores. La opción --output-format formateará la salida según lo especificado.

El parámetro <dispositivo> es obligatorio y puede ser el dispositivo de caracteres NVMe (ej: /dev/nvme0).

Esto solo funcionará en dispositivos WDC que soporten esta página de log. Los resultados para cualquier otro dispositivo no están definidos.

En caso de éxito, devuelve los datos analizados de la página de log de recuperación de errores; de lo contrario, devuelve un código de error.

OPCIONES

-o <fmt>, --output-format=<fmt>

Establece el formato de reporte a normal o json. Solo se puede usar un formato de salida a la vez. El valor por defecto es normal.

EJEMPLOS

•Hace que el programa emita el comando del plugin WDC get-error-recovery-log : 
# nvme wdc get-error-recovery-log /dev/nvme0
