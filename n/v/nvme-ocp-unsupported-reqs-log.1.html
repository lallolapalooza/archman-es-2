NOMBRE

nvme-ocp-unsupported-reqs-log - Recupera la página de registro de requisitos no admitidos de un dispositivo OCP compatible dado

SINOPSIS

nvme ocp unsupported-reqs-log <dispositivo> [--output-format=<formato> | -o <formato>]

DESCRIPCIÓN

Para el dispositivo NVMe dado, envía un comando unsupported-reqs-log y proporciona la página de registro de requisitos no admitidos.

El parámetro <dispositivo> es obligatorio y puede ser el dispositivo de caracteres NVMe (ej: /dev/nvme0) o el dispositivo de bloques (ej: /dev/nvme0n1).

Esto solo funcionará en dispositivos compatibles con OCP que admitan esta característica. Los resultados para cualquier otro dispositivo no están definidos.

En caso de éxito devuelve 0, código de error en caso contrario.

OPCIONES

-o <formato>, --output-format=<formato>

Esta opción establecerá el formato de informe a normal, json o binario. Solo se puede usar un formato de salida a la vez.

EJEMPLOS

•Hace que el programa emita un comando unsupported-reqs-log para recuperar la página de registro 0xC5. 
# nvme ocp unsupported-reqs-log /dev/nvme0
