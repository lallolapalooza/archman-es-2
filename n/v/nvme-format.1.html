NOMBRE

nvme-format - Formatear un dispositivo NVMe

SINOPSIS

nvme format <dispositivo> [--namespace-id=<nsid> | -n <nsid>]
                        [--lbaf=<lbaf> | -l <lbaf>]
                        [--block-size=<tamaño de bloque> | -b <tamaño de bloque>]
                        [--ses=<ses> | -s <ses>] [--pil=<pil> | -p <pil>]
                        [--pi=<pi> | -i <pi>] [--ms=<ms> | -m <ms>]
                        [--reset | -r] [--force]
                        [--timeout=<timeout> | -t <timeout>]
                        [--output-format=<fmt> | -o <fmt>] [--verbose | -v]

DESCRIPCIÓN

Para el dispositivo NVMe dado, envía un comando de administración de formato de Namespace NVMe y proporciona los resultados.

El parámetro <dispositivo> es obligatorio y puede ser tanto el dispositivo de caracteres NVMe (ej: /dev/nvme0), como un dispositivo de bloque de namespace (ej: /dev/nvme0n1). Si se proporciona el dispositivo de caracteres, y el controlador no soporta el formateo de namespaces particulares (bit 0 de ID_CTRL.FNA habilitado), entonces todos los namespaces serán formateados. Si FNA está deshabilitado, entonces el identificador del namespace debe especificarse con la opción namespace-id; especifique un valor de 0xffffffff para enviar el formato a todos los namespaces. Si se proporciona el dispositivo de bloque, el identificador del namespace será por defecto el ID del namespace del dispositivo de bloque dado, pero puede ser reemplazado con la misma opción.

Nota, el sufijo numérico en el dispositivo de caracteres, por ejemplo el *0* en /dev/nvme0, NO indica que este manejador de dispositivo sea el controlador padre de ningún namespace con el mismo sufijo. El número del manejador del namespace puede provenir del identificador del subsistema, que es independiente del identificador del controlador. No asuma ninguna relación particular de dispositivo basándose en sus nombres. Si lo hace, puede borrar irrevocablemente datos en un dispositivo no deseado.

En caso de éxito, el programa emitirá automáticamente el ioctl BLKRRPART para forzar el reescaneo de los namespaces. Si el driver es lo suficientemente reciente, esto actualizará automáticamente el tamaño físico del bloque. Si no es lo suficientemente reciente, necesitará eliminar y re-escanear su dispositivo de alguna otra manera para que el nuevo tamaño de bloque sea visible, si el tamaño se cambió con este comando.

OPCIONES

-n <nsid>, --namespace-id=<nsid>

Envía el comando de formato para el nsid especificado. Esto puede usarse para reemplazar el valor por defecto tanto para el dispositivo de caracteres (no especificado) como para el dispositivo de bloque (resultado de NVME_IOCTL_ID).

-l <lbaf>, --lbaf=<lbaf>

Formato LBA: Este campo especifica el formato LBA a aplicar a los medios NVM. Corresponde a los formatos LBA indicados en el comando Identify Namespace. Entra en conflicto con el argumento --block-size. Por defecto es 0.

-b <tamaño de bloque>, --block-size=<tamaño de bloque>

Tamaño de Bloque: Este campo se utiliza para especificar el tamaño de bloque objetivo al que formatear. Se escanearán los valores lba posibles y se seleccionará el de menor número para la operación de formato. Entra en conflicto con el argumento --lbaf.

-s <ses>, --ses=<ses>

Configuración de Borrado Seguro: Este campo especifica si se debe realizar un borrado seguro como parte del formato y el tipo de la operación de borrado seguro. El borrado se aplica a todos los datos del usuario, independientemente de su ubicación (ej: dentro de un LBA expuesto, dentro de una caché, dentro de LBAs desasignados, etc.). Por defecto es 0.
Valor Definición
0 No se solicita operación de borrado seguro
1 Borrado de Datos de Usuario: Todos los datos del usuario deben ser borrados, el contenido de los datos del usuario después del borrado es indeterminado (ej: los datos del usuario pueden ser rellenados con ceros, unos, etc.). El controlador puede realizar un borrado criptográfico cuando se solicita un Borrado de Datos de Usuario si todos los datos del usuario están cifrados.
2 Borrado Criptográfico: Todos los datos del usuario deben ser borrados criptográficamente. Esto se logra eliminando la clave de cifrado.
3-7 Reservado

-p <pil>, --pil=<pil>

Ubicación de Información de Protección: Si se establece en '1' y la información de protección está habilitada, entonces la información de protección se transfiere como los primeros bytes de metadatos. Si se pone a '0' y la información de protección está habilitada, entonces la información de protección se transfiere como los últimos bytes de metadatos. Por defecto es 0.

-i <pi>, --pi=<pi>

Información de Protección: Este campo especifica si la protección de datos de extremo a extremo está habilitada y el tipo de información de protección. Por defecto es 0.
Valor Definición
0 La información de protección no está habilitada
1 La información de protección está habilitada, Tipo 1
2 La información de protección está habilitada, Tipo 2
3 La información de protección está habilitada, Tipo 3
4-7 Reservado

-m <ms>, --ms=<ms>

Configuración de Metadatos: Este campo se establece en '1' si los metadatos se transfieren como parte de un LBA de datos extendido. Este campo se pone a '0' si los metadatos se transfieren como parte de un búfer separado. Los metadatos pueden incluir información de protección, basándose en el campo Protección de Información (PI). Por defecto es 0.

-r, --reset

Emite un reinicio después de un formato exitoso. Debe usar el dispositivo de caracteres para esto.

--force

Simplemente envía el comando inmediatamente sin advertir de las implicaciones.

-t <timeout>, --timeout=<timeout>

Reemplaza el valor de tiempo de espera por defecto de 600,000. En milisegundos.

-o <fmt>, --output-format=<fmt>

Establece el formato de reporte a *normal*, *json* o *binary*. Solo se puede usar un formato de salida a la vez.

-v, --verbose

Aumenta el nivel de detalle de la información en la salida.

EJEMPLOS

•Formatea el dispositivo usando todos los valores por defecto: 
# nvme format /dev/nvme0n1
•Formatea el namespace 1 con configuración de borrado seguro de datos de usuario e información de protección: 
# nvme format /dev/nvme0 --namespace-id=1 --ses=1 --pi=1
