NOMBRE

nvme-create-ns - Envía un comando de gestión de namespace NVMe para crear un namespace, devuelve los resultados.

SINOPSIS

nvme create-ns <dispositivo> [--nsze=<nsze> | -s <nsze>]
                        [--ncap=<ncap> | -c <ncap>]
                        [--flbas=<flbas> | -f <flbas>]
                        [--dps=<dps> | -d <dps>]
                        [--nmic=<nmic> | -m <nmic>]
                        [--anagrp-id=<anagrpid> | -a <anagrpid>]
                        [--nvmset-id=<nvmsetid> | -i <nvmsetid>]
                        [--endg-id=<endgid> | -e <endgid>]
                        [--csi=<identificador_conjunto_comandos> | -y <identificador_conjunto_comandos>]
                        [--lbstm=<lbstm> | -l <lbstm>]
                        [--nphndls=<nphndls> | -n <nphndls>]
                        [--block-size=<tamaño-bloque> | -b <tamaño-bloque>]
                        [--timeout=<timeout> | -t <timeout>]
                        [--nsze-si=<nsze-si> | -S <nsze-si>]
                        [--ncap-si=<ncap-si> | -C <ncap-si>]
                        [--azr | -z]
                        [--rar=<rar> | -r <rar>]
                        [--ror=<ror> | -O <ror>]
                        [--rnumzrwa=<rnumzrwa> | -u <rnumzrwa>]
                        [--phndls=<lista-handles-colocacion,> | -p <lista-handles-colocacion,>]
                        [--output-format=<fmt> | -o <fmt>] [--verbose | -v]

DESCRIPCIÓN

Para el dispositivo NVMe proporcionado, envía un comando de gestión de namespace para crear el namespace con la configuración solicitada. En caso de éxito, se devuelve el identificador de namespace asignado por el controlador.

El parámetro <dispositivo> es obligatorio y puede ser el dispositivo de caracteres NVMe (ej: /dev/nvme0) o un dispositivo de bloque de namespace (ej: /dev/nvme0n1).

OPCIONES

-s, --nsze

El tamaño del namespace.

-c, --ncap

La capacidad del namespace.

-f, --flbas

La configuración del tamaño del bloque lógico formateado del namespace. Entra en conflicto con el argumento --block-size.

-d, --dps

La configuración de protección de datos.

-m, --nmic

Capacidades de multipath y compartición del namespace.

-a, --anagrp-id

Identificador del Grupo ANA. Si este valor es 0h, especifica que el controlador determina el valor a utilizar.

-i <nvmsetid>, --nvmset-id=<nvmsetid>

Este campo especifica el identificador del Conjunto NVM.

-e <endgid>, --endg-id=<endgid>

Este campo especifica el identificador del grupo de resistencia.

-y <identificador_conjunto_comandos>, --csi=<identificador_conjunto_comandos>

Este campo especifica el identificador del conjunto de comandos. Si no se emite, se seleccionará el Conjunto de Comandos NVM.

-l <lbstm>, --lbstm=<lbstm>

Máscara de etiqueta de almacenamiento de bloque lógico para protección de extremo a extremo.

-n <nphndls>, --nphndls=<nphndls>

Número de Handles de Colocación incluidos en la Lista de Handles de Colocación. Si la capacidad de Colocación Flexible de Datos no es compatible o no está habilitada en el Grupo de Resistencia especificado, el controlador ignorará este campo.

-b, --block-size

Tamaño de bloque de destino con el que se debe formatear el nuevo namespace. Se escanearán los valores FLBAS potenciales y se seleccionará el número más bajo para la operación create-ns. Entra en conflicto con el argumento --flbas.

-S, --nsze-si

El tamaño del namespace (NSZE) en unidades SI estándar (alineado en límites de 1MiB, a menos que el controlador recomiende un valor diferente, ver granularidad del namespace). El valor con sufijo SI se divide por el tamaño de LBA del namespace para establecerlo como NSZE. Si el valor no tiene sufijo, se establece igual que la opción nsze.

-C, --ncap-si

La capacidad del namespace (NCAP) en unidades SI estándar (alineado en límites de 1MiB, a menos que el controlador recomiende un valor diferente, ver granularidad del namespace). El valor con sufijo SI se divide por el tamaño de LBA del namespace para establecerlo como NCAP. Si el valor no tiene sufijo, se establece igual que la opción ncap.

-z, --azr

Asignar Recursos ZRWA. Si se establece en 1, el namespace se creará con el número de recursos ZRWA especificado en el campo RNUMZRWA de esta estructura de datos. Si se borra a 0, no se asignarán recursos ZRWA al namespace que se va a crear.

-r <rar>, --rar=<rar>

Recursos Activos Solicitados. Este campo especifica el número de recursos activos que se asignarán al namespace creado.

-O <ror>, --ror=<ror>

Recursos Abiertos Solicitados. Este campo especifica el número de recursos abiertos que se asignarán al namespace creado.

-u <rnumzrwa>, --rnumzrwa=<rnumzrwa>

Número Solicitado de Recursos ZRWA. Este campo especifica el número de recursos ZRWA que se asignarán al namespace creado.

-p <lista-handles-colocacion,>, --phndls=<lista-handles-colocacion,>

La lista separada por comas de Identificadores de Handle de Unidad de Recuperación que se asociarán con cada Handle de Colocación.

-o <fmt>, --output-format=<fmt>

Establece el formato de informe en normal, json o binary. Solo se puede usar un formato de salida a la vez.

-v, --verbose

Aumenta el detalle de la información en la salida.

-t <timeout>, --timeout=<timeout>

Anula el valor de tiempo de espera predeterminado de 120.000. En milisegundos.

EJEMPLOS

•Crear un namespace: 
# nvme create-ns /dev/nvme0 --nsze 11995709440 --ncap 1199570940 --flbas 0 --dps 0 --nmic 0
# nvme create-ns /dev/nvme0 --nsze-si 6.14T --ncap 1199570940 --flbas 0 --dps 0 --nmic 0
