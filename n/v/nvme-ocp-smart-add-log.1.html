NOMBRE

nvme-ocp-smart-add-log - Recupera información extendida SMART del dispositivo OCP dado

SINOPSIS

nvme ocp smart-add-log <dispositivo> [--output-format=<fmt> | -o <fmt>] [--output-format-version=<version>]

DESCRIPCIÓN

Para el dispositivo NVMe proporcionado, envía un comando smart-add-log y proporciona el registro SMART adicional.

El parámetro <dispositivo> es obligatorio y puede ser el dispositivo de caracteres NVMe (ej: /dev/nvme0) o el dispositivo de bloque (ej: /dev/nvme0n1).

Esto solo funcionará en dispositivos compatibles con OCP que soporten esta característica. Los resultados para cualquier otro dispositivo no están definidos.

EXPERIMENTAL. La opción --output-format-version se puede establecer en 2 para generar nombres de campo para las salidas que sean más fáciles de procesar mediante scripts. Tenga en cuenta que esto es experimental y los nombres de los campos están sujetos a cambios.

En caso de éxito devuelve 0, código de error en caso contrario.

OPCIONES

-o <fmt>, --output-format=<fmt>

Establece el formato de reporte a normal o json. Solo se puede usar un formato de salida a la vez. El valor predeterminado es normal.

--output-format-version=<version>

Establece las etiquetas de campo en el formato de reporte a 1 (el original) o 2. El valor predeterminado es 1. Tenga en cuenta que esto es experimental.

EJEMPLOS

•Hace que el programa emita un comando smart-add-log para recuperar la página de registro 0xC0. 
# nvme ocp smart-add-log /dev/nvme0
