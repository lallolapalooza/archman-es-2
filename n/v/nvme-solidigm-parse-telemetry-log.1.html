NOMBRE

nvme-solidigm-parse-telemetry-log - Analiza y muestra el registro de telemetría de Solidigm

SINOPSIS

nvme solidigm parse-telemetry-log <dispositivo> [OPCIONES]

DESCRIPCIÓN

Recupera, analiza y muestra el registro de telemetría para el dispositivo NVMe de Solidigm dado. Este comando proporciona información detallada sobre los datos de telemetría del dispositivo, lo que puede ser útil para diagnósticos y análisis de rendimiento.

El parámetro <dispositivo> es obligatorio y puede ser el dispositivo de caracteres NVMe (ej: /dev/nvme0) o un dispositivo de bloque de namespace (ej: /dev/nvme0n1).

OPCIONES

-g <num>, --host-generate=<num>

Controla cuándo generar un nuevo informe iniciado por el host. El valor predeterminado *1* genera un nuevo informe iniciado por el host, el valor *0* provoca la recuperación de un registro existente. Los valores válidos son 0 y 1.

-c, --controller-init

Recopilar el informe generado por el controlador.

-d <num>, --data-area=<num>

Seleccionar qué área de datos de telemetría informar. El valor predeterminado es 1, o 3 si se especifica un archivo de configuración. Las opciones válidas son 1, 2, 3, 4.

-j <archivo>, --config-file=<archivo>

Especificar un archivo de configuración JSON para el análisis personalizado del registro de telemetría.

-s <archivo>, --source-file=<archivo>

Especifica un archivo binario que contiene un volcado del registro de telemetría para analizar en lugar de recuperar el registro de un dispositivo. Cuando se utiliza esta opción, no se debe proporcionar ningún argumento de dispositivo.

EJEMPLOS

•Recuperar y analizar el registro de telemetría con opciones predeterminadas: 
# nvme solidigm parse-telemetry-log /dev/nvme0
•Recuperar un registro de telemetría existente sin generar uno nuevo: 
# nvme solidigm parse-telemetry-log /dev/nvme0 -g 0
•Analizar un área de datos específica del registro de telemetría: 
# nvme solidigm parse-telemetry-log /dev/nvme0 -d 2
•Usar un archivo de configuración personalizado para el análisis: 
# nvme solidigm parse-telemetry-log /dev/nvme0 -j config.json
•Analizar un registro de telemetría desde un archivo binario: 
# nvme solidigm parse-telemetry-log -s telemetry_dump.bin

SALIDA

El comando produce el registro de telemetría analizado en formato JSON a la salida estándar.
