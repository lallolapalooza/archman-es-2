NOMBRE

nvme-wdc-drive-resize - Envía el comando específico del proveedor WDC NVMe para redimensionar la unidad, devuelve el resultado.

SINOPSIS

nvme wdc drive-resize <dispositivo> [--size=<sz> | -s <sz>]

DESCRIPCIÓN

Para el dispositivo NVMe dado, envía un comando WDC Resize específico del proveedor.

El parámetro <dispositivo> es obligatorio y puede ser el dispositivo de caracteres NVMe (ej: /dev/nvme0) o un dispositivo de bloque de espacio de nombres (ej: /dev/nvme0n1).

Esto solo funcionará en dispositivos WDC que soporten esta función. Los resultados para cualquier otro dispositivo son indefinidos.

En caso de éxito devuelve 0, código de error en caso contrario.

OPCIONES

-s <sz>, --size=<sz>

El nuevo tamaño (en GB) al que se redimensionará la unidad.

EJEMPLOS

· Hacer que el programa emita el Comando Específico del Proveedor WDC Resize: 
# nvme wdc drive-resize /dev/nvme0n1 --size=100
