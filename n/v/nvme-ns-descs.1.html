NVME-NS-DESCS(1) Manual de NVMe NVME-NS-DESCS(1)

NOMBRE

nvme-ns-descs - Envía identificación NVMe para una lista de estructuras de descriptor de identificación de namespace, devuelve el resultado y la estructura

SINOPSIS

nvme ns-descs <dispositivo> [--namespace-id=<nsid> | -n <nsid>] [--raw-binary | -b]
                        [--output-format=<fmt> | -o <fmt>] [--verbose | -v]

DESCRIPCIÓN

Para el dispositivo NVMe dado, envía un comando de identificación para una lista de estructuras de descriptor de identificación de namespace y proporciona el resultado y la estructura devuelta.

El parámetro <dispositivo> es obligatorio y puede ser el dispositivo de carácter NVMe (ej: /dev/nvme0) o un dispositivo de bloque de namespace (ej: /dev/nvme0n1). Si se proporciona el dispositivo de carácter, la opción '--namespace-id' es obligatoria, de lo contrario, utilizará el ns-id del namespace para el dispositivo de bloque que abrió. Para dispositivos de bloque, el ns-id utilizado puede ser anulado con la misma opción.

En caso de éxito, la estructura puede ser devuelta de varias maneras dependiendo de las opciones; la estructura puede ser analizada por el programa o el búfer crudo puede imprimirse en la salida estándar.

OPCIONES

-n <nsid>, --namespace-id=<nsid>

Recupera la estructura de descriptor de identificación de namespace para el nsid dado. Esto es obligatorio para los dispositivos de carácter, o anula el nsid de bloque si se proporciona.

-b, --raw-binary

Imprime el búfer crudo en la salida estándar. La estructura no es analizada por el programa.

-o <fmt>, --output-format=<fmt>

Establece el formato de reporte a normal, json o binary. Solo se puede usar un formato de salida a la vez.

-v, --verbose

Aumenta el detalle de la información en la salida.

EJEMPLOS

•Si usa el dispositivo de carácter o anula el namespace #2: 
# nvme ns-descs /dev/nvme0 -n 1
# nvme ns-descs /dev/nvme0n1 -n 2
# nvme ns-descs /dev/nvme0 --namespace-id=1
•Haga que el programa devuelva la estructura cruda en binario: 
# nvme ns-descs /dev/nvme0n1 --raw-binary > ns_descs.raw
# nvme ns-descs /dev/nvme0n1 -b > ns_descs.raw

Probablemente sea una mala idea no redirigir la salida estándar al usar este modo.
