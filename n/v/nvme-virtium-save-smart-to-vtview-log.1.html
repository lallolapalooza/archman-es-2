NOMBRE

nvme-virtium-save-smart-to-vtview-log - Guarda periódicamente los atributos SMART en un archivo de registro (formato csv).

SINOPSIS

nvme virtium save-smart-to-vtview-log <dispositivo> [--run-time=<NUM> | -r <NUM>]
                        [--freq=<NUM> | -f <NUM>]
                        [--output-file=<ARCHIVO> | -o <ARCHIVO>]
                        [--test-name=<NOMBRE> | -n <NOMBRE>]

DESCRIPCIÓN

Este comando automatiza el proceso de recopilación de datos SMART periódicamente y guarda los datos en un formato listo para analizar. Cada entrada se guarda con una marca de tiempo y en formato csv. Los usuarios pueden usar Excel para analizar los datos. Algunos ejemplos de casos de uso son la recopilación de datos SMART para caracterización de temperatura, datos para calcular la resistencia o la recopilación de datos SMART durante una prueba o durante el funcionamiento normal.

El parámetro <dispositivo> es obligatorio y puede ser el dispositivo de caracteres NVMe (ej: /dev/nvme0) o un dispositivo de bloque de namespace (ej: /dev/nvme0n1).

Al tener éxito, el comando genera un archivo de registro, que contiene una entrada para identificar el dispositivo (características y configuración actuales) y entradas periódicas de datos SMART.

Este comando se ejecuta durante el tiempo especificado por la opción <run-time>, y recopila datos SMART con la frecuencia especificada por la opción <freq>. Si no se especifica el nombre del archivo de salida, este comando generará un nombre de archivo que incluirá la cadena del modelo y el número de serie del dispositivo.

Si se especifica la opción test-name, se registrará en el archivo de registro y se utilizará como parte del nombre del archivo de registro.

OPCIONES

-r <NUM>, --run-time=<NUM>

(opcional) Número de horas para registrar datos (por defecto = 20 horas)

-f <NUM>, --freq=<NUM>

(opcional) Con qué frecuencia desea registrar datos SMART (0.25 = 15', 0.5 = 30', 1 = 1 hora, 2 = 2 horas, etc.). Por defecto = 10 horas.

-o <ARCHIVO>, --output-file=<ARCHIVO>

(opcional) Nombre del archivo de registro (dale un nombre que sea fácil de recordar sobre qué trata la prueba). También puedes dejarlo en blanco, el nombre del archivo se generará como <cadena del modelo>-<número de serie>-<nombre de la prueba>.txt.

-n <NOMBRE>, --test-name=<NOMBRE>

(opcional) Nombre de la prueba que está realizando. Utilizamos esta cadena como parte del nombre del archivo de registro.

EJEMPLOS

•Caracterización de temperatura: 
# nvme virtium save-smart-to-vtview-log /dev/tuDispositivo --run-time=100 --record-frequency=0.25 --test-name=burn-in-at-(-40)
•Prueba de resistencia: 
# nvme virtium save-smart-to-vtview-log /dev/tuDispositivo --run-time=100 --record-frequency=1 --test-name=Endurance-test-JEDEG-219-workload
•Solo registro: El registro por defecto se ejecuta durante 20 horas y registra cada 10 horas. 
# nvme virtium save-smart-to-vtview-log /dev/tuDispositivo
