NOMBRE

nvme-dapustor-smart-log-add - Envía una solicitud de página de registro SMART adicional de NVMe DapuStor, devuelve el resultado y el registro

SINOPSIS

nvme dapustor smart-log-add <dispositivo> [--namespace-id=<nsid> | -n <nsid>]
                        [--raw-binary | -b] [--json | -j]

DESCRIPCIÓN

Recupera la página de registro SMART adicional de NVMe DapuStor del dispositivo y proporciona la estructura devuelta.

El parámetro <dispositivo> es obligatorio y puede ser el dispositivo de caracteres NVMe (ej: /dev/nvme0) o un dispositivo de bloque de namespace (ej: /dev/nvme0n1).

En caso de éxito, la estructura de registro SMART devuelta puede ser devuelta de varias maneras, dependiendo de las opciones; la estructura puede ser analizada por el programa e impresa en un formato legible, o el buffer bruto puede ser impreso en stdout para que otro programa lo analice.

OPCIONES

-n <nsid>, --namespace-id=<nsid>

Recupera el registro SMART adicional para el nsid dado. Esto es opcional y su éxito puede depender de las capacidades del dispositivo para proporcionar este registro por namespace (ver NVMe Identify Controller para esta capacidad). El nsid predeterminado a usar es 0xffffffff para el registro SMART global del dispositivo.

-b, --raw-binary

Imprime el buffer bruto del registro SMART adicional de DapuStor en stdout.

-j, --json

Vuelca la salida en formato json.

EJEMPLOS

•Imprime la página de registro SMART adicional de DapuStor en un formato legible por humanos: 
# nvme dapustor smart-log-add /dev/nvme0
•Imprime el registro SMART adicional de DapuStor en crudo a un archivo: 
# nvme dapustor smart-log-add /dev/nvme0 --raw-binary > smart_log.raw

Probablemente sea una mala idea no redirigir stdout cuando se usa este modo.
