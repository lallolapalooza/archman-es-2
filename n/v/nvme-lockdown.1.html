NOMBRE

nvme-lockdown - Envía un comando NVMe Lockdown para prohibir o permitir la ejecución de un comando

SINOPSIS

nvme-lockdown <dispositivo> [--ofi=<ofi> | -O <ofi>]
                        [--ifc=<ifc> | -f <ifc>]
                        [--prhbt=<prhbt> | -p <prhbt>]
                        [--scp=<scp> | -s <scp>]
                        [--uuid=<UUID_Index> | -U <UUID_Index>]
                        [--output-format=<fmt> | -o <fmt>] [--verbose | -v]
                        [--timeout=<timeout> | -t <timeout>]

DESCRIPCIÓN

El comando Lockdown se utiliza para controlar la capacidad de bloqueo de comandos y funciones, que configura la prohibición o el permiso de ejecución del comando especificado o del comando Set Features dirigido a un identificador de función específico.

OPCIONES

-O <ofi>, --ofi=<ofi>

El Opcode o Identificador de Función (OFI) especifica el código de operación del comando o el Identificador de Función de Set Features identificado por el campo Scope.

-f <ifc>, --ifc=<ifc>

El campo Interfaz (INF) identifica las interfaces afectadas por este comando.

-p <prhbt>, --prhbt=<prhbt>

El bit de Prohibición (PRHBT) especifica si se prohíbe o se permite el código de operación del comando o el Identificador de Función de Set Features especificado por este comando.

-s <scp>, --scp=<scp>

El campo Scope (SCP) especifica el contenido del campo Opcode o Identificador de Función.

-U <UUID_Index>, --uuid=<UUID_Index>

Índice UUID - Si este campo se establece en un valor distinto de cero, entonces el valor de este campo es el índice de un UUID en la Lista de UUID utilizada por el comando. Si este campo se borra a 0h, entonces no se especifica ningún índice de UUID.

-o <fmt>, --output-format=<fmt>

Establece el formato de informe en normal, json o binary. Solo se puede utilizar un formato de salida a la vez.

-v, --verbose

Aumenta el nivel de detalle de la información en la salida.

-t <timeout>, --timeout=<timeout>

Anula el valor de tiempo de espera predeterminado. En milisegundos.
