NOMBRE

nvme-compare - Envía un comando NVMe Compare, proporciona resultados

SINOPSIS

nvme-compare <dispositivo> [--start-block=<slba> | -s <slba>]
                        [--block-count=<nlb> | -c <nlb>]
                        [--block-size=<tamaño> | -b <tamaño>]
                        [--data-size=<tamaño> | -z <tamaño>]
                        [--metadata-size=<tamañometa> | -y <tamañometa>]
                        [--ref-tag=<reftag> | -r <reftag>]
                        [--data=<archivo-datos> | -d <archivo-datos>]
                        [--metadata=<meta> | -M <meta>]
                        [--prinfo=<prinfo> | -p <prinfo>]
                        [--app-tag-mask=<mascara-app> | -m <mascara-app>]
                        [--app-tag=<apptag> | -a <apptag>]
                        [--limited-retry | -l]
                        [--force-unit-access | -f]
                        [--dir-type=<tipo> | -T <tipo>]
                        [--dir-spec=<espec> | -S <espec>]
                        [--dsm=<dsm> | -D <dsm>]
                        [--show-command | -V]
                        [--dry-run | -w]
                        [--latency | -t]
                        [--storage-tag=<etiqueta-almacenamiento> | -g <etiqueta-almacenamiento>]
                        [--storage-tag-check | -C]
                        [--force]
                        [--output-format=<fmt> | -o <fmt>] [--verbose | -v]
                        [--timeout=<timeout>]

DESCRIPCIÓN

El comando Compare lee los bloques lógicos especificados por el comando del medio y compara los datos leídos con un búfer de datos de comparación transferido como parte del comando. Si los datos leídos del controlador y el búfer de datos de comparación son equivalentes sin errores de descomparación, el comando se completa con éxito. Si hay alguna descomparación, el comando se completa con un error de Falla de Comparación. Si se proporciona metadatos, también se realiza una comparación para los metadatos.

OPCIONES

-s <slba>, --start-block=<slba>

Dirección de 64 bits del primer bloque a acceder.

-c <nlb>, --block-count=<nlb>

Número de bloques a acceder (base cero).

-b <tamaño>, --block-size=<tamaño>

Si se especifica, el tamaño del bloque lógico en bytes, con el tamaño de metadatos describiendo también el tamaño de metadatos para un bloque individual. Descubierto por identificar el espacio de nombres de lo contrario.

-z <tamaño>, --data-size=<tamaño>

Tamaño de los datos a comparar en bytes.

-y <tamañometa>, --metadata-size=<tamañometa>

Tamaño de los metadatos a transferir en bytes.

-r <reftag>, --ref-tag=<reftag>

Etiqueta de Referencia para Información de Protección

-d <archivo-datos>, --data=<archivo-datos>

Archivo de datos.

-M <meta>, --metadata=<meta>

Archivo de metadatos.

-p <prinfo>, --prinfo=<prinfo>

Información de Protección y campo de verificación.
Bit Descripción
3 PRACT: Acción de Información de Protección. Cuando se establece en 1, PI se elimina/inserta en lectura/escritura cuando el tamaño de metadatos del formato del bloque es 8. Cuando se establece en 0, los metadatos se pasan.
2:0 PRCHK: Verificación de Información de Protección:
2 Establecer en 1 habilita la verificación de la etiqueta de guardia
1 Establecer en 1 habilita la verificación de la etiqueta de aplicación
0 Establecer en 1 habilita la verificación de la etiqueta de referencia

-m <mascara-app>, --app-tag-mask=<mascara-app>

Máscara de Etiqueta de Aplicación para Información de Protección

-a <apptag>, --app-tag=<apptag>

Etiqueta de Aplicación para Información de Protección

-l, --limited-retry

Número de intentos limitados al medio.

-f, --force-unit-access

Opción FUA para garantizar que los datos se almacenen en el medio.

-T <tipo>, --dir-type=<tipo>

Tipo de directiva opcional. La utilidad nvme-cli solo impone que el valor esté dentro del rango definido para el tipo de directiva, aunque la especificación NVMe (1.3a) define solo una directiva, 01h, para identificadores de flujo de escritura.

-S <espec>, --dir-spec=<espec>

Campo opcional para detalles de la directiva. Cuando se usa con flujos de escritura, este valor se define como el identificador del flujo de escritura. La utilidad nvme-cli no validará si el flujo solicitado está dentro de las capacidades del controlador.

-D <dsm>, --dsm=<dsm>

Los atributos opcionales de administración del conjunto de datos para este comando. El argumento para esto son los 8 bits menos significativos del campo DSM en un comando de escritura; los 16 bits más significativos del campo provienen del campo específico de la directiva, si se usa. Esto puede usarse para establecer atributos para los LBA que se están escribiendo, como frecuencia de acceso, tipo, latencia, entre otras cosas, así como tipos aún por definir. Consulte la especificación NVMe para obtener un desglose detallado de cómo usar este campo.

-V, --show-cmd

Imprime el comando que se enviará.

-w, --dry-run

No envíe el comando realmente. Si desea usar la opción --dry-run, la opción --show-cmd *debe* establecerse. De lo contrario, la opción --dry-run se *ignorará*.

-t, --latency

Imprime la latencia que tomó la llamada IOCTL (en µs).

-g <etiqueta-almacenamiento>, --storage-tag=<etiqueta-almacenamiento>

Etiqueta de Almacenamiento Lógico Esperada de Tamaño Variable (ELBST).

-C, --storage-tag-check

Esta bandera habilita la verificación del campo Etiqueta de Almacenamiento como parte del procesamiento de protección de datos de extremo a extremo.

--force

Ignora que el espacio de nombres esté actualmente ocupado y realiza la operación a pesar de ello.

-o <fmt>, --output-format=<fmt>

Establece el formato de informe en normal, json o binary. Solo se puede usar un formato de salida a la vez.

-v, --verbose

Aumenta el detalle de la información en la salida.

--timeout=<timeout>

Anula el valor de tiempo de espera predeterminado. En milisegundos.
