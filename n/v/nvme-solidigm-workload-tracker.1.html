NOMBRE

nvme-solidigm-workload-tracker - Captura en tiempo real de muestras del rastreador de carga de trabajo

SINOPSIS

nvme solidigm workload-tracker <dispositivo> [--uuid-index=<id> | -U <id>]
                                      [--enable | -e] [--disable | -d]
                                      [--sample-time=<tiempo> | -s <tiempo>]
                                      [--type=<tipo> | -t <tipo>]
                                      [--run-time=<segundos> | -r <segundos>]
                                      [--flush-freq=<conteo> | -f <conteo>]
                                      [--wall-clock | -w]
                                      [--trigger-field=<campo> | -T <campo>]
                                      [--trigger-threshold=<valor> | -V <valor>]
                                      [--trigger-on-delta | -D]
                                      [--trigger-on-latency | -L]
                                      [--verbose | -v]

DESCRIPCIÓN

Captura y muestra muestras en tiempo real del rastreador de carga de trabajo para el dispositivo NVMe Solidigm dado. Este comando permite la monitorización y el análisis de las características de la carga de trabajo del dispositivo.

El parámetro <dispositivo> es obligatorio y puede ser el dispositivo de caracteres NVMe (ej: /dev/nvme0) o un dispositivo de bloque de espacio de nombres (ej: /dev/nvme0n1).

OPCIONES

-U <id>, --uuid-index=<id>

Especifica el índice UUID (0-127) para el comando.

-e, --enable

Habilita el rastreador de carga de trabajo antes de capturar muestras.

-d, --disable

Deshabilita el rastreador de carga de trabajo después de capturar muestras.

-s <tiempo>, --sample-time=<tiempo>

Establece el intervalo de muestreo. Los valores válidos son: default, 1ms, 5ms, 10ms, 50ms, 100ms, 500ms, 1s, 5s, 10s, 30s, 1m, 5m, 10m, 30m, 1h.

-t <tipo>, --type=<tipo>

Establece el tipo de rastreador. Los tipos válidos son: Base, CmdQ, Pattern, RandSeq, Throttle, Power, Defrag.

-r <segundos>, --run-time=<segundos>

Limita el tiempo de captura de ejecución en segundos.

-f <conteo>, --flush-freq=<conteo>

Número de muestras (1 a 126) a esperar antes de extraer los datos. El valor predeterminado es 100 muestras.

-w, --wall-clock

Registra la marca de tiempo actual cuando se recuperó la entrada.

-T <campo>, --trigger-field=<campo>

Nombre del campo para detener el disparador.

-V <valor>, --trigger-threshold=<valor>

Valor del campo para disparar la detención del muestreo.

-D, --trigger-on-delta

Dispara por delta para detener el muestreo.

-L, --trigger-on-latency

Utiliza el rastreador de latencia para disparar la detención del muestreo.

-v, --verbose

Aumenta la verbosidad del registro. Se puede usar múltiples veces.

EJEMPLOS

•Habilitar el rastreador de carga de trabajo y capturar muestras: 
# nvme solidigm workload-tracker /dev/nvme0 --enable
•Capturar muestras del rastreador de carga de trabajo con un intervalo de 1 ms durante 60 segundos: 
# nvme solidigm workload-tracker /dev/nvme0 --enable --sample-time=1ms --run-time=60
•Deshabilitar el rastreador de carga de trabajo: 
# nvme solidigm workload-tracker /dev/nvme0 --disable
•Habilitar el rastreador de carga de trabajo y capturar muestras con un tiempo de muestreo y tipo específicos: 
# nvme solidigm workload-tracker /dev/nvme0 --enable --sample-time=1ms --type=Base
•Capturar muestras del rastreador de Energía con un intervalo de 10 segundos durante 5 minutos: 
# nvme solidigm workload-tracker /dev/nvme0 --enable --type=Power --sample-time=10s --run-time=300
