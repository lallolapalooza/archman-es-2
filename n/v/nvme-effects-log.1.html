NVME-EFFECTS-LOG(1) Manual de NVMe NVME-EFFECTS-LOG(1)

NOMBRE

nvme-effects-log - Envía una solicitud de página de registro de efectos de comandos NVMe, devuelve el resultado y el registro

SINOPSIS

nvme effects-log <dispositivo> [--human-readable | -H] [--raw-binary | -b]
                        [--output-format=<fmt> | -o <fmt>] [--verbose | -v]
                        [--timeout=<timeout> | -t <timeout>]

DESCRIPCIÓN

Recupera la página de registro de efectos de comandos NVMe de un dispositivo NVMe y proporciona la estructura devuelta.

El parámetro <dispositivo> es obligatorio y debe ser el dispositivo de caracteres NVMe (ej: /dev/nvme0).

En caso de éxito, la estructura de registro de efectos de comandos devuelta se imprimirá para cada comando que sea compatible.

OPCIONES

-H, --human-readable

Esta opción analizará y formateará muchos de los campos de bits en un formato legible para humanos.

-b, --raw-binary

Esta opción imprimirá el búfer sin procesar en la salida estándar. El programa no analizará la estructura. Esto anula la opción legible para humanos.

-o <fmt>, --output-format=<fmt>

Establece el formato de informe en normal, json o binary. Solo se puede usar un formato de salida a la vez.

-v, --verbose

Aumenta el detalle de la información en la salida.

-t <timeout>, --timeout=<timeout>

Anula el valor de tiempo de espera predeterminado. En milisegundos.

EJEMPLOS

• Imprime la página de registro de efectos en un formato legible para humanos: 
# nvme effects-log /dev/nvme0
• Haz que el programa devuelva la estructura sin procesar en binario: 
# nvme effects-log /dev/nvme0 --raw-binary > effects_log.raw
# nvme effects-log /dev/nvme0 -b > effects_log.raw
