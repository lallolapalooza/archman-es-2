nvidia-modprobe(1) Manual de Comandos Generales nvidia-modprobe(1)

NOMBRE

nvidia-modprobe - Carga el módulo del kernel de NVIDIA y crea los archivos de dispositivo de NVIDIA.

SINOPSIS

nvidia-modprobe [opciones]
nvidia-modprobe [opciones] --create-nvidia-device-file=NUMERO-MENOR
nvidia-modprobe [opciones] --module-instance=INSTANCIA-MODULO

DESCRIPCIÓN

La utilidad nvidia-modprobe es utilizada por los componentes del controlador NVIDIA en el espacio de usuario para asegurarse de que el módulo del kernel de NVIDIA esté cargado, que los archivos de dispositivo de NVIDIA estén presentes y para configurar ciertas configuraciones en tiempo de ejecución en el kernel. Estas facilidades normalmente son proporcionadas por sistemas de configuración de distribuciones Linux como udev. Cuando sea posible, se recomienda utilizar los mecanismos nativos de su distribución Linux para gestionar la carga de módulos del kernel, la creación de archivos de dispositivo y la configuración de runtime del kernel. Esta utilidad se proporciona como una solución alternativa para funcionar directamente en un modo independiente de la distribución.

Cuando se instala por nvidia-installer, nvidia-modprobe se instala con el bit setuid root.

Los usuarios normalmente no necesitarán ejecutar nvidia-modprobe manualmente: los componentes del controlador NVIDIA en el espacio de usuario lo ejecutarán (fork(2)/exec(3)) cuando sea necesario.

Cuando se ejecuta sin opciones, nvidia-modprobe cargará el módulo del kernel de NVIDIA y luego saldrá. Cuando se especifica la opción --module-instance en sistemas con múltiples módulos del kernel de NVIDIA, nvidia-modprobe cargará el módulo del kernel de NVIDIA correspondiente y luego saldrá. Cuando se especifica la opción --create-nvidia-device-file, nvidia-modprobe también creará el archivo de dispositivo solicitado.

El código fuente de nvidia-modprobe está disponible aquí:
⟨ https://download.nvidia.com/XFree86/nvidia-modprobe/ ⟩

OPCIONES

-v, --version
Imprime la versión de la utilidad y sale.
-h, --help
Imprime información de uso para las opciones de la línea de comandos y sale.
-c NUMERO-MENOR, --create-nvidia-device-file=NUMERO-MENOR
Crea el archivo de dispositivo NVIDIA con el número menor dado; esta opción se puede especificar varias veces para crear múltiples archivos de dispositivo NVIDIA.

OPCIONES AVANZADAS

-u, --unified-memory
Carga el módulo del kernel de Memoria Unificada de NVIDIA o crea archivos de dispositivo para él, en lugar del módulo del kernel de NVIDIA.
-m, --modeset
Carga el módulo del kernel de modeset de NVIDIA y crea su archivo de dispositivo.
-s, --nvswitch
Carga el módulo del kernel de NVIDIA y crea los archivos de dispositivo NVSwitch para cada número menor especificado usando la bandera -c.
-l, --nvlink
Carga el módulo del kernel de NVIDIA y crea el archivo de dispositivo de control NVLink.
-f ARCHIVO-DISPOSITIVO-CAPACIDAD-NVIDIA, --nvidia-capability-device-file=ARCHIVO-DISPOSITIVO-CAPACIDAD-NVIDIA
Crea los archivos de dispositivo de capacidad NVIDIA con la ruta del archivo /proc de capacidad dada. Esta opción se puede especificar varias veces para crear múltiples archivos de dispositivo de capacidad NVIDIA.
-a, --auto-online-movable
Habilita la configuración del kernel `online_movable` para plataformas (como Grace Hopper) que añaden y ponen en línea memoria de GPU al kernel.

EJEMPLOS

nvidia-modprobe
Ejecuta `/sbin/modprobe nvidia`
nvidia-modprobe -c 0 -c 1
Ejecuta `/sbin/modprobe nvidia` y crea `/dev/nvidia0` y `/dev/nvidia1`
nvidia-modprobe -i 0
Ejecuta `/sbin/modprobe nvidia0`
