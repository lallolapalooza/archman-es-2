NOMBRE

nvme-boot-part-log - Recupera una página de registro de partición de arranque de un dispositivo NVMe

SINOPSIS

nvme boot-part-log <dispositivo> [--lsp=<campo> | -s <campo>]
                        [--output-file=<archivo> | -f <archivo>]
                        [--output-format=<fmt> | -o <fmt>] [--verbose | -v]

DESCRIPCIÓN

Recupera una página de registro de Partición de Arranque de un dispositivo NVMe y proporciona la estructura devuelta.

El parámetro <dispositivo> es obligatorio y puede ser tanto el dispositivo de caracteres NVMe (ej: /dev/nvme0), como un dispositivo de bloque de namespace (ej: /dev/nvme0n1).

En caso de éxito, la estructura de registro devuelta estará en formato binario crudo *únicamente* con la opción --output-file, la cual es obligatoria.

OPCIONES

-s <campo>, --lsp=<campo>

El campo especificado del registro LID.

-f <archivo>, --output-file=<archivo>

Nombre del archivo al que se guardarán los datos binarios crudos.

-o <fmt>, --output-format=<fmt>

Establece el formato de reporte a normal, json o binary. Solo se puede usar un formato de salida a la vez.

-v, --verbose

Aumenta el nivel de detalle de la información en la salida.

EJEMPLOS

•Recuperar datos de Partición de Arranque en boot_part_log.bin 
# nvme boot-part-log /dev/nvme0 --output-file=boot_part_log.bin
