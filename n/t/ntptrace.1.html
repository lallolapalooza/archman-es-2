ntptrace(1) Comandos de usuario ntptrace(1)

NOMBRE

ntptrace - Rastrea los peers de un servidor NTP

SINOPSIS

ntptrace [-flags] [-flag [valor]] [--option-name[[=| ]valor]] [host]

DESCRIPCIÓN

ntptrace es un script de perl que utiliza la utilidad ntpq para seguir la cadena de servidores NTP desde un host dado hasta la fuente de tiempo primaria. Para que ntptrace funcione correctamente, cada uno de estos servidores debe implementar el Protocolo de Control y Monitoreo NTP especificado en RFC 1305 y habilitar los paquetes NTP Modo 6.

Si no se proporcionan argumentos, ntptrace comienza con localhost. Aquí hay un ejemplo de la salida de ntptrace:


% ntptrace localhost: estrato 4, desplazamiento 0.0019529, distancia de sincronización 0.144135
server2ozo.com: estrato 2, desplazamiento 0.0124263, distancia de sincronización 0.115784 usndh.edu:
estrato 1, desplazamiento 0.0019298, distancia de sincronización 0.011993, refid 'WWVB'

En cada línea, los campos son (de izquierda a derecha): el nombre del host, el estrato del host, el desplazamiento de tiempo entre ese host y el host local (según lo medido por ntptrace; esta es la razón por la que no siempre es cero para "localhost"), la distancia de sincronización del host y (solo para servidores de estrato 1) el identificador del reloj de referencia. Todos los tiempos se dan en segundos. Tenga en cuenta que el estrato es el recuento de saltos del servidor a la fuente primaria, mientras que la distancia de sincronización es el error estimado con respecto a la fuente primaria. Estos términos están definidos con precisión en RFC-1305.

OPCIONES

-n, --numeric

Imprime direcciones IP en lugar de nombres de host.

Muestra los hosts en formato numérico de cuatro puntos en lugar de convertirlos a los nombres de host canónicos.

-m número, --max-hosts=número

Número máximo de peers a rastrear. Esta opción toma un número entero como argumento. El número predeterminado para esta opción es:
99

Esta opción no ha sido completamente documentada.

-r cadena, --host=cadena

Host remoto único. La cadena predeterminada para esta opción es:
127.0.0.1

Esta opción no ha sido completamente documentada.

-?, --help

Muestra información de uso y sale.
-!, --more-help

Pasa la información de uso extendida a través de un paginador.
-v [{v|c|n --version [{v|c|n}]}]

Muestra la versión del programa y sale. El modo predeterminado es `v', una versión simple. El modo `c' imprimirá información de derechos de autor y `n' imprimirá el aviso de derechos de autor completo.
