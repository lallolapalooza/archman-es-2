ntp-wait(1) Comandos de Usuario ntp-wait(1)

NOMBRE

ntp-wait - Esperar a que ntpd estabilice el reloj del sistema

SINOPSIS

ntp-wait [-indicadores] [-indicador [valor]] [--nombre-opcion[[=| ]valor]]

Todos los argumentos deben ser opciones.

DESCRIPCIÓN

ntp-wait enviará como máximo num-tries consultas a ntpd(8), durmiendo durante secs-between-tries después de cada retorno de estado que indique que ntpd aún no ha producido un reloj del sistema sincronizado y estable.

ntp-wait lo hará silenciosamente, a menos que se proporcione el indicador -v. Esto puede ser útil al arrancar, para retrasar la secuencia de arranque hasta que ntpd -g haya ajustado la hora.

OPCIONES

-n número, --tries=número

Número de veces que se comprobará ntpd. Esta opción toma un número entero como argumento. El número por defecto para esta opción es:
100


El número máximo de veces que comprobaremos ntpd para ver si
ha podido sincronizar y estabilizar el reloj del sistema.

-s secs-between-tries, --sleep=secs-between-tries

Cuánto tiempo dormir entre intentos. Esta opción toma un número entero como argumento. El valor secs-between-tries por defecto para esta opción es:
6


Dormiremos durante secs-between-tries después de cada consulta
a ntpd que devuelva "la hora aún no es estable".

-v, --verbose

Ser verboso.


Por defecto, ntp-wait es silencioso.
Con esta opción, ntp-wait proporcionará información de estado.

-?, --help

Mostrar información de uso y salir.
-!, --more-help

Pasar la información de uso extendida a través de un paginador.
-v [{v|c|n --version [{v|c|n}]}]

Mostrar la versión del programa y salir. El modo por defecto es `v', una versión simple. El modo `c' imprimirá información de copyright y `n' imprimirá el aviso de copyright completo.

ESTADO DE SALIDA

Se devolverá uno de los siguientes valores de salida:

0 (EXIT_SUCCESS)

Ejecución exitosa del programa.
1 (EXIT_FAILURE)

La operación falló o la sintaxis del comando no fue válida.
70 (EX_SOFTWARE)
