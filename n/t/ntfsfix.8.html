NTFSFIX(8) Manual del Administrador del Sistema NTFSFIX(8)

NOMBRE

ntfsfix - corrige errores comunes y fuerza a Windows a comprobar NTFS

SINOPSIS

ntfsfix [opciones] dispositivo

DESCRIPCIÓN

ntfsfix es una utilidad que corrige algunos problemas fundamentales de NTFS. ntfsfix NO es una versión de Linux de chkdsk. Solo repara algunas inconsistencias fundamentales de NTFS, reinicia el archivo de registro de NTFS y programa una comprobación de consistencia de NTFS para el primer arranque en Windows.

Puede ejecutar ntfsfix en un volumen NTFS si cree que fue dañado por Windows o de alguna otra manera y no se puede montar.

OPCIONES

A continuación se presenta un resumen de todas las opciones que acepta ntfsfix. Casi todas las opciones tienen dos nombres equivalentes. El nombre corto va precedido de - y el nombre largo va precedido de --. Las opciones de una sola letra, que no toman argumento, se pueden combinar en un solo comando, por ejemplo, -fv es equivalente a -f -v. Las opciones con nombre largo se pueden abreviar a cualquier prefijo único de su nombre.

-b, --clear-bad-sectors
Borra la lista de sectores defectuosos. Esto es útil después de clonar un disco antiguo con sectores defectuosos a un disco nuevo.
-d, --clear-dirty
Borra el indicador de volumen sucio si el volumen puede ser corregido y montado. Si la opción no está presente o el volumen no se puede corregir, se establece el indicador de volumen sucio para solicitar una comprobación del volumen en el próximo montaje.
-h, --help
Muestra una lista de opciones con una breve descripción de cada una.
-n, --no-action
No escribe nada, solo muestra lo que se habría hecho.
-V, --version
Muestra el número de versión, copyright y licencia.

ERRORES

No se conocen problemas con ntfsfix. Si encuentra un error, envíe un correo electrónico describiendo el problema al equipo de desarrollo:
ntfs-3g-devel@lists.sf.net
