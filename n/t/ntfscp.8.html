NTFSCP(8) Manual del Administrador del Sistema NTFSCP(8)

NOMBRE

ntfscp - copia un archivo a un volumen NTFS.

SINOPSIS

ntfscp [opciones] dispositivo archivo_origen destino

DESCRIPCIÓN

ntfscp copiará un archivo a un volumen NTFS. destino puede ser un archivo o un directorio. En caso de que destino sea un directorio especificado por nombre, entonces archivo_origen se copiará dentro de este directorio; en caso de que destino sea un directorio especificado por número de inodo, se creará un atributo de datos sin nombre para este inodo y archivo_origen se copiará en él (ADVERTENCIA: es inusual tener flujos de datos sin nombre en los directorios, piénselo dos veces antes de especificar un directorio por su número de inodo).

OPCIONES

A continuación se presenta un resumen de todas las opciones que acepta ntfscp. Casi todas las opciones tienen dos nombres equivalentes. El nombre corto va precedido de - y el nombre largo va precedido de --. Las opciones de una sola letra que no toman un argumento pueden combinarse en un solo comando, por ejemplo, -fv es equivalente a -f -v. Las opciones con nombre largo pueden abreviarse a cualquier prefijo único de su nombre.

-a, --atributo NUM
Escribe en este atributo.
-i, --inodo
Trata destino como número de inodo.
-m, --min-fragmentos
Minimiza la fragmentación al asignar espacio al atributo. Esto es útil principalmente al crear archivos grandes.
-N, --nombre-atributo NOMBRE
Escribe en el atributo con este nombre.
-n, --sin-accion
Utilice esta opción para realizar una prueba antes de la operación de copia real. El volumen se abrirá en modo de solo lectura y no se realizarán escrituras.
-f, --forzar
Esto anulará algunos valores predeterminados sensatos, como no trabajar con un volumen montado. Utilice esta opción con precaución.
-h, --ayuda
Muestra una lista de opciones con una breve descripción de cada una.
-q, --silencioso
Suprime algunos mensajes de depuración/advertencia/error.
-t, --marca-tiempo
Copia la hora de modificación de archivo_origen a destino. Esto no es compatible con --nombre-atributo y --atributo.
-V, --version
Muestra el número de versión, derechos de autor y licencia de ntfscp.
-v, --verboso
Muestra más mensajes de depuración/advertencia/error.

FLUJOS DE DATOS

Todos los datos en NTFS se almacenan en flujos, que pueden tener nombres. Un archivo puede tener más de un flujo de datos, pero exactamente uno debe no tener nombre. El tamaño de un archivo es el tamaño de su flujo de datos sin nombre. Normalmente, cuando no se especifica el nombre del flujo, se accede al flujo de datos sin nombre. Si desea acceder a un flujo de datos con nombre, debe añadir ":nombre_flujo" al nombre del archivo. Por ejemplo: al abrir "algun.mp3:artista" se abrirá el flujo "artista" en "algun.mp3". Pero Windows normalmente le impide acceder a flujos de datos con nombre, por lo que necesitará usar un programa como FAR o las utilidades de Cygwin para acceder a ellos.

EJEMPLOS

Copiar nuevo_boot.ini desde /home/usuario como boot.ini a la raíz de un volumen NTFS /dev/hda1:

ntfscp /dev/hda1 /home/usuario/nuevo_boot.ini boot.ini

Copiar miarchivo a C:\algun\ruta\miarchivo:flujo (asumiendo que la letra C corresponde a /dev/hda1 en Windows):

ntfscp -N flujo /dev/hda1 miarchivo /algun/ruta

ERRORES

No se conocen problemas con ntfscp. Si encuentra un error, envíe un correo electrónico describiendo el problema al equipo de desarrollo:
ntfs-3g-devel@lists.sf.net
