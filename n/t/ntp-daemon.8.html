NOMBRE

ntp-daemon - servicio NTP (Network Time Protocol) de ntpd-rs

SINOPSIS

ntp-daemon [-c ruta] [-l nivel_de_registro]

ntp-daemon -h

ntp-daemon -v

DESCRIPCIÓN

ntp-daemon es el demonio del servicio Network Time Protocol (NTP) para ntpd-rs, una implementación NTP con un enfoque en la seguridad y la estabilidad. El ntp-deamon puede ser configurado tanto como cliente NTP como servidor NTP. El demonio también funciona con el protocolo Network Time Security (NTS). Los detalles de la configuración del demonio y los detalles de implementación se pueden encontrar en ntp.toml(5), donde también se explican varios conceptos del ntp-daemon.

OPCIONES

-c ruta, --config=ruta
La ruta del archivo de configuración para el ntp-daemon donde se almacenan los ajustes para la configuración de ntpd-rs. Si no se especifica, el archivo de configuración predeterminado es /etc/ntpd-rs/ntp.toml.
-h, --help
Muestra las instrucciones de uso.
-l nivel_de_registro, --log-level=nivel_de_registro
Cambia qué mensajes de registro se registran en la salida estándar. Los niveles de registro disponibles son trace, debug, info, warn y error (de menor a mayor prioridad). Solo se mostrarán los mensajes con la prioridad dada y superiores. El nivel de registro predeterminado es info.
-v, --version
Muestra la información de la versión.

VER TAMBIÉN
