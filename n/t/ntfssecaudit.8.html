NOMBRE

ntfssecaudit - Auditoría de datos de seguridad NTFS

SINOPSIS

ntfssecaudit [opciones] argumentos

Donde opciones es una combinación de:

-a auditoría completa de datos de seguridad (solo Linux)
-b copia de seguridad de ACLs
-e ajuste de parámetros extra de copia de seguridad (en conjunción con -s)
-h visualización de descriptores de seguridad hexadecimales guardados en un archivo
-r recursión en un directorio
-s ajuste de ACLs de copia de seguridad
-u obtención de una propuesta de mapeo de usuario
-v verboso (muy verboso si se establece dos veces)

y argumentos definen los parámetros y el conjunto de archivos sobre los que se actúa.

Escribir secaudit sin argumentos mostrará un resumen de las opciones disponibles.

DESCRIPCIÓN

ntfssecaudit muestra la propiedad y los permisos de un conjunto de archivos en un sistema de archivos NTFS, y verifica su consistencia. Puede iniciarse solo en modo terminal (no hay interfaz gráfica de usuario disponible).

Cuando se requiere un volumen, este debe estar desmontado, y el comando debe ser emitido como root. El volumen puede ser un dispositivo de bloques (es decir, una partición de disco) o un archivo de imagen.

Al actuar sobre un directorio o volumen, el comando puede producir una gran cantidad de información. Por lo tanto, se recomienda redirigir la salida a un archivo o canalizarla a un editor de texto para su examen.

OPCIONES

A continuación se muestran las combinaciones válidas de opciones y argumentos que acepta ntfssecaudit. Todos los argumentos indicados son obligatorios y deben ser únicos (si se utilizan comodines, deben resolverse en un único nombre).

-h archivo
Muestra en un formato legible por humanos los descriptores de seguridad hexadecimales guardados en archivo. Esto se puede usar para convertir una salida verbosa en una salida muy verbosa.
-a[rv] volumen
Audita el volumen: todos los datos de seguridad globales en volumen se escanean y se muestran los errores. Si está presente la opción -r, todos los archivos y directorios también se escanean y se verifican sus relaciones con los datos de seguridad globales. Esto puede producir muchos datos.

Esta opción no es efectiva en volúmenes formateados para versiones antiguas de NTFS (anteriores a NTFS 3.0). Dichos volúmenes no tienen datos de seguridad globales.

Cuando se señalan errores, es aconsejable reparar el volumen con una herramienta apropiada (como chkdsk en Windows).

[-v] volumen archivo
Muestra los parámetros de seguridad de archivo: su modo Linux interpretado (indicadores rwx en octal) y ACL de Posix[1], su clave de seguridad si existe, y su descriptor de seguridad si la salida es verbosa.
-r[v] volumen directorio
Muestra los parámetros de seguridad de todos los archivos y subdirectorios en directorio: su modo Linux interpretado (indicadores rwx en octal) y ACL de Posix[1], su clave de seguridad si existe, y su descriptor de seguridad si la salida es verbosa.
-b[v] volumen [directorio]
Extrae recursivamente a la salida estándar las ACLs NTFS de los archivos en volumen y directorio.
-s[ev] volumen [archivo-copia-seguridad]
Establece las ACLs NTFS según lo indicado en archivo-copia-seguridad o en la entrada estándar. Los datos de entrada deben haber sido creados en Linux. Con la opción -e, también establece parámetros extra (actualmente atributos de Windows).
volumen perms archivo
Establece los parámetros de seguridad del archivo a perms. Perms es el modo solicitado por Linux (indicadores rwx, expresados en forma octal como en chmod) o una ACL de Posix[1] (expresada como en setfacl -m). Esto establece una nueva ACL que es efectiva para Linux y Windows.
-r[v] volumen perms directorio
Establece los parámetros de seguridad de todos los archivos y subdirectorios en directorio a perms. Perms es el modo solicitado por Linux (indicadores rwx, expresados en forma octal como en chmod), o una ACL de Posix[1] (expresada como en setfacl -m). Esto establece nuevas ACLs que son efectivas para Linux y Windows.
[-v] archivo-montado
Muestra los parámetros de seguridad de archivo-montado: su modo Linux interpretado (indicadores rwx en octal) y ACL de Posix[1], su clave de seguridad si existe, y su descriptor de seguridad si la salida es verbosa. Este es un caso especial que actúa sobre un archivo (o directorio) montado y no requiere ser root. La interpretación de la ACL de Posix solo se puede mostrar si se proporciona la ruta completa a archivo-montado desde la raíz del árbol de archivos global.
-u[v] archivo-montado
Muestra un contenido propuesto para un archivo de mapeo de usuario, basado en los parámetros de propiedad establecidos por Windows en archivo-montado, asumiendo que este archivo fue creado en Windows por el usuario que debería ser mapeado al usuario actual de Linux. La información mostrada debe copiarse al archivo .NTFS-3G/UserMapping, donde .NTFS-3G es un subdirectorio oculto de la raíz de la partición para la que se definirá el mapeo. Esto hará que la propiedad de los archivos creados en esa partición sea la misma que la del archivo-montado original.

NOTA

[1] siempre que la opción ACL POSIX se seleccionara en tiempo de compilación. Una especificación de ACL Posix se ve así "[d:]{ugmo}:[id]:[perms],..." donde id es un id numérico de usuario o grupo, y perms un dígito octal o un conjunto de las letras r, w y x.

Ejemplo: "u::7,g::5,o:0,u:510:rwx,g:500:5,d:u:510:7"

EJEMPLOS

Auditar los datos de seguridad globales en /dev/sda1

ntfssecaudit -ar /dev/sda1

Mostrar la propiedad y los parámetros de permisos para los archivos en el directorio /audio/music en el dispositivo /dev/sda5, excluyendo subdirectorios:

ntfssecaudit /dev/sda5 /audio/music

Establecer todos los archivos en el directorio /audio/music en el dispositivo /dev/sda5 como escribibles por el propietario y de solo lectura para todos:

ntfssecaudit -r /dev/sda5 644 /audio/music

CÓDIGOS DE SALIDA

ntfssecaudit sale con un valor de 0 cuando no se detectó ningún error, y con un valor de 1 cuando se detectó un error.

NAME

ntfssecaudit - NTFS security audit tool

SYNOPSIS

ntfssecaudit [ options ] device

DESCRIPTION

ntfssecaudit is a tool to audit the security of an NTFS partition. It checks for common security misconfigurations and provides a report on potential vulnerabilities.

OPTIONS

-h, --help
Show help message and exit.
-v, --verbose
Enable verbose output.
-o, --output FILE
Write report to FILE.

NOTE

This tool requires root privileges to access the device.

EXAMPLES

Audit the NTFS partition on /dev/sda1 and save the report to report.txt: 

sudo ntfssecaudit -o report.txt /dev/sda1

EXIT CODES

0
Success.
1
An error occurred.

KNOWN ISSUES

None known at this time.
