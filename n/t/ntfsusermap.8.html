NTFSUSERMAP(8) Manual del Administrador del Sistema NTFSUSERMAP(8)

NOMBRE

ntfsusermap - NTFS Construcción de un Archivo de Mapeo de Usuarios

SINOPSIS

ntfsusermap dispositivo-sistema-windows [otro-dispositivo-ntfs...]

Donde dispositivo-sistema-windows es el dispositivo que contiene el sistema Windows cuyos usuarios se mapearán al sistema Linux actual.

Y otro-dispositivo-ntfs es otro dispositivo que contiene archivos a los que se accederá tanto desde el Windows mencionado anteriormente como desde el sistema Linux actual.

El comando ntfsusermap debe iniciarse como root, y los dispositivos designados no deben estar montados.

Escribir ntfsusermap sin argumentos mostrará un resumen de los argumentos del comando.

DESCRIPCIÓN

ntfsusermap crea el archivo que define el mapeo de cuentas de Windows a inicios de sesión de Linux para los usuarios que poseen archivos que deberían ser visibles tanto desde Windows como desde Linux.

Se basa en archivos existentes creados en Windows, intentando localizar archivos significativos y preguntando qué usuario o grupo de Linux debería poseerlos. Cuando se solicita un propietario o grupo de Linux, la respuesta puede ser:

- la uid o gid (numérica o simbólica) del propietario o grupo de Linux del archivo.

En esa situación, no se seleccionarán más archivos con el mismo propietario de Windows.
- o ninguna respuesta, cuando no se pueda definir el propietario o grupo.
En esa situación, otro archivo propiedad del mismo usuario o grupo de Windows puede ser seleccionado más tarde para definir un mapeo.

Los mapeos para usuarios estándar de Windows, como "Administrator" o "All Users", se definen implícitamente. Como consecuencia, nunca se debe definir un mapeo de usuario como root de Linux.

Cuando no quedan más archivos significativos, ntfsusermap crea el archivo de mapeo en el archivo UserMapping en el directorio actual. Este archivo debe moverse al directorio oculto .NTFS-3G en la raíz de todos los sistemas de archivos NTFS que se compartirán entre Windows y Linux. Esto requiere que el sistema de archivos esté montado, pero el archivo creado no se tendrá en cuenta si no está presente en el momento del montaje, lo que significa que el sistema de archivos debe desmontarse y montarse de nuevo para que el nuevo archivo de mapeo se tenga en cuenta.

OPCIONES

No se definen opciones para ntfsusermap.

EJEMPLOS

Mapear los usuarios definidos en el sistema Windows presente en /dev/sda1 :

ntfsusermap /dev/sda1

CÓDIGOS DE SALIDA

ntfsusermap sale con un valor de 0 cuando no se detecta ningún error, y con un valor de 1 cuando se detecta un error.
