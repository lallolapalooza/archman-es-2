NTFSDECRYPT(8) Manual del Administrador del Sistema NTFSDECRYPT(8)

NOMBRE

ntfsdecrypt - Descifra o actualiza archivos NTFS cifrados según EFS

SINOPSIS

ntfsdecrypt [opciones] -k clave.pfx dispositivo archivo

DESCRIPCIÓN

ntfsdecrypt descifra un archivo de un dispositivo desmontado e imprime los datos descifrados en la salida estándar. También puede actualizar un archivo cifrado sin cambiar la clave de cifrado.

El cifrado de archivos NTFS (conocido como EFS) utiliza un cifrado de dos niveles: primero, el contenido del archivo se cifra con una clave simétrica aleatoria, y luego esta clave simétrica se cifra con las claves públicas de cada uno de los usuarios autorizados a descifrar el archivo (cifrados de clave pública RSA).

Actualmente se implementan tres modos de cifrado simétrico en ntfsdecrypt: DESX (una variante de DES), 3DES (triple DES) y AES_256 (una variante de AES).

Todas las claves simétricas cifradas se almacenan junto con el archivo en un atributo extendido especial llamado "$LOGGED_UTILITY_STREAM". Normalmente, se permite que al menos dos usuarios lean el archivo: su propietario y el administrador de recuperación, que es capaz de descifrar todos los archivos de una empresa. Al hacer copias de seguridad de un archivo cifrado, es importante también hacer copias de seguridad del $LOGGED_UTILITY_STREAM correspondiente, de lo contrario, el archivo no podrá descifrarse, ni siquiera por el administrador de recuperación. Tenga en cuenta también que los archivos cifrados son ligeramente más grandes de lo aparente, y la opción "efs_raw" debe utilizarse al hacer copias de seguridad de archivos cifrados con ntfs-3g.

Cuando ntfsdecrypt se utiliza para actualizar un archivo, las claves y el $LOGGED_UTILITY_STREAM se mantienen sin cambios, por lo que se debe designar un único archivo de clave.

Nota: El cifrado EFS solo está disponible en las versiones profesionales de Windows.

OPCIONES

A continuación se presenta un resumen de todas las opciones que acepta ntfsdecrypt. Casi todas las opciones tienen dos nombres equivalentes. El nombre corto va precedido de - y el nombre largo va precedido de --. Las opciones de una sola letra, que no toman argumentos, se pueden combinar en un solo comando, por ejemplo, -fv equivale a -f -v. Las opciones con nombres largos se pueden abreviar a cualquier prefijo único de su nombre.

-i, --inodo NUM
Muestra o actualiza el contenido de un archivo designado por su número de inodo en lugar de su nombre.
-e, --cifrar
Actualiza un archivo cifrado existente y obtiene el nuevo contenido de la entrada estándar. Se debe designar el archivo de clave pública y privada completo, ya que la clave simétrica se mantiene sin cambios, por lo que se necesita la clave privada para extraerla.
-f, --forzar
Esto anulará algunas configuraciones predeterminadas sensatas, como no usar un volumen montado. Utilice esta opción con precaución.
-k, --archivo-clave key.pfx
Define el archivo que contiene las claves pública y privada en formato PKCS#12. Este archivo obviamente contiene las claves de uno de los usuarios autorizados a descifrar o actualizar el archivo. Debe extraerse de Windows en formato PKCS#12 (su sufijo habitual es .p12 o .pfx), y está protegido por una contraseña que debe introducirse para que se puedan extraer las claves. Este puede ser el archivo de clave de cualquier usuario autorizado a leer el archivo, incluido el del administrador de recuperación.
-h, --ayuda
Muestra una lista de opciones con una breve descripción de cada una.
-q, --silencioso
Suprime algunos mensajes de depuración/advertencia/error.
-V, --version
Muestra el número de versión, derechos de autor y licencia de ntfsdecrypt.
-v, --verboso
Muestra más mensajes de depuración/advertencia/error.

EJEMPLOS

Muestra el contenido del archivo hamlet.doc en el directorio Documents de la raíz del sistema de archivos NTFS en el dispositivo /dev/sda1

ntfsdecrypt -k foo.key /dev/sda1 Documents/hamlet.doc

Actualiza el archivo hamlet.doc

ntfsdecrypt -k foo.key /dev/sda1 Documents/hamlet.doc < new.doc
