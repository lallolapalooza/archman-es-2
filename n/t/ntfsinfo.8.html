NTFSINFO(8) Manual del Administrador del Sistema NTFSINFO(8)

NOMBRE

ntfsinfo - volcar atributos de un archivo

SINOPSIS

ntfsinfo [opciones] dispositivo

DESCRIPCIÓN

ntfsinfo volcará los atributos del inodo numero-de-inodo o el archivo ruta-nombrearchivo y/o información sobre el mft (opción -m). Ejecute ntfsinfo sin argumentos para obtener una lista completa de opciones.

OPCIONES

A continuación se presenta un resumen de todas las opciones que acepta ntfsinfo. Casi todas las opciones tienen dos nombres equivalentes. El nombre corto va precedido de - y el nombre largo va precedido de --. Cualquier opción de una sola letra que no tome un argumento puede combinarse en un solo comando, por ejemplo, -fv es equivalente a -f -v. Las opciones con nombre largo pueden abreviarse a cualquier prefijo único de su nombre.

-F, --archivo ARCHIVO
Mostrar información sobre este archivo
-f, --forzar
Esto anulará algunas configuraciones predeterminadas razonables, como no sobrescribir un archivo existente. Use esta opción con precaución.
-h, --ayuda
Mostrar una lista de opciones con una breve descripción de cada una.
-i, --inodo NUM
Mostrar información sobre este inodo.
-m, --mft
Mostrar información sobre el volumen.
-q, --silencioso
Producir menos salida.
-t, --notime
No mostrar marcas de tiempo en la salida.
-v, --verboso
Aumentar la cantidad de salida que imprime ntfsinfo.
-V, --version
Mostrar el número de versión, derechos de autor y licencia.

ERRORES

No se conocen problemas con ntfsinfo. Si encuentra un error, envíe un correo electrónico describiendo el problema al equipo de desarrollo:
ntfs-3g-devel@lists.sf.net
