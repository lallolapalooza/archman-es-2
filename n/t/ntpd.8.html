NOMBRE

ntpd — Demonio del Protocolo de Tiempo de Red

SINOPSIS

ntpd [-dnv] [-f archivo] [-p archivo]

DESCRIPCIÓN

El demonio ntpd sincroniza el reloj local con uno o más servidores NTP remotos o sensores de timedelta locales. ntpd también puede actuar como servidor NTP, redistribuyendo la hora local. Implementa la versión 4 del Protocolo de Tiempo de Red, según se describe en la RFC 5905, y la versión 3 del Protocolo de Tiempo de Red, según se describe en la RFC 1305. La hora también se puede obtener de servidores HTTPS TLS para reducir el impacto de los ataques man-in-the-middle NTP no autenticados.

Las opciones son las siguientes:

-d
No demonizar. Si se especifica esta opción, ntpd se ejecutará en primer plano y registrará en stderr.
-f archivo
Utilizar archivo como archivo de configuración, en lugar del predeterminado /etc/ntpd.conf.
-n
Modo de prueba de configuración. Solo comprueba la validez del archivo de configuración.

ntpd permanecerá en primer plano hasta 15 segundos esperando la respuesta de uno de los servidores NTP configurados.

-v
Esta opción permite a ntpd enviar mensajes de prioridad DEBUG a syslog.
-p archivo
Escribir el pid en archivo

ntpd utiliza la llamada al sistema adjtime(2) para corregir el tiempo del sistema local sin causar saltos de tiempo. Los ajustes de 32ms y mayores se registran utilizando syslog(3). El valor umbral se elige para evitar que la deriva del reloj local inunde los archivos de registro. Si ntpd se inicia con la opción -d o -v, todas las llamadas a adjtime(2) se registrarán.

ntpd realiza esfuerzos para verificar y corregir la hora al arrancar si se configuran y satisfacen restricciones o si los servidores o sensores de confianza devuelven resultados, y si el reloj no se está moviendo hacia atrás.

Después de sincronizar el reloj local, ntpd ajusta la frecuencia del reloj utilizando la llamada al sistema adjfreq(2) para compensar la deriva sistemática.

ntpd se inicia al arrancar por defecto a través de ntpd_flags en /etc/rc.conf. Consulte rc(8) y rc.conf(8) para obtener más información sobre el proceso de arranque y la habilitación de demonios.

Cuando ntpd se inicia, lee la configuración de su archivo de configuración, típicamente ntpd.conf(5), y su deriva de reloj inicial de /var/db/ntpd.drift. La deriva del reloj se escribe periódicamente en el archivo de deriva a partir de entonces.

ARCHIVOS

/etc/ntpd.conf
Archivo de configuración predeterminado.
/var/db/ntpd.drift
Archivo de deriva.
/var/run/ntpd.sock
Archivo de socket para la comunicación con ntpctl(8).

VER TAMBIÉN

date(1), adjfreq(2), adjtime(2), ntpd.conf(5), ntpctl(8), rc(8), rc.conf(8), rdate(8)

ESTÁNDARES

David L. Mills, Network Time Protocol (Version 3): Specification, Implementation and Analysis, RFC 1305, Marzo de 1992.

David L. Mills, Jim Martin, Jack Burbank, y William Kasch, Network Time Protocol Version 4: Protocol and Algorithms Specification, RFC 5905, Junio de 2010.
