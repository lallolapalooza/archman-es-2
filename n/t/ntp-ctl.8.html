NOMBRE

ntp-ctl - cliente de gestión para el proceso ntpd-rs ntp-daemon

SINOPSIS

ntp-ctl validate [-c ruta]

ntp-ctl status [-f formato] [-c ruta]

ntp-ctl force-sync [-c ruta]

ntp-ctl -h

ntp-ctl -v

DESCRIPCIÓN

El cliente de gestión ntp-ctl permite la gestión de algunos aspectos del demonio ntpd-rs. Actualmente, el cliente de gestión solo permite mostrar el estado actual del demonio y validar un archivo de configuración para su uso con el demonio.

OPCIONES

-c ruta, --config=ruta
Ruta al archivo de configuración desde el cual se obtendrá la dirección del socket de observación. Si no se especifica, por defecto es /etc/ntpd-rs/ntp.toml.
-f formato, --format=formato
El formato de salida para el comando status. Si no se especifica, por defecto es plain. Alternativamente, el formato prometheus está disponible para mostrar la salida en un formato compatible con OpenMetrics/Prometheus.
-h, --help
Muestra las instrucciones de uso.
-v, --version
Muestra la información de la versión.

COMANDOS

validate
Comprueba si la configuración especificada (o /etc/ntpd-rs/ntp.toml por defecto) es válida.
status
Devuelve información de estado sobre el estado actual del ntp-daemon al que se conecta el cliente.
force-sync
Ejecuta interactivamente una única sincronización de tu reloj. Este comando puede usarse para hacer una sincronización puntual con las fuentes de tiempo configuradas en tu archivo de configuración. Este comando nunca debe usarse sin validación por un operador humano.

VER TAMBIÉN
