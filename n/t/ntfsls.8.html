NTFSLS(8) Manual del Administrador del Sistema NTFSLS(8)

NOMBRE

ntfsls - listar el contenido de directorios en un sistema de archivos NTFS

SINOPSIS

ntfsls [opciones] dispositivo

ntfsls [ -a | --all ] [ -F | --classify ] [ -f | --force ] [ -h | --help ] [ -i | --inode ] [ -l | --long ] [ -p | --path RUTA ] [ -q | --quiet ] [ -s | --system ] [ -V | --version ] [ -v | --verbose ] [ -x | --dos ] dispositivo

DESCRIPCIÓN

ntfsls se utiliza para listar información sobre los archivos especificados por la opción RUTA (el directorio raíz por defecto). DISPOSITIVO es el archivo especial correspondiente al dispositivo (por ejemplo, /dev/hdXX) o un archivo de imagen NTFS.

OPCIONES

A continuación se presenta un resumen de todas las opciones que ntfsls acepta. Casi todas las opciones tienen dos nombres equivalentes. El nombre corto va precedido de - y el nombre largo va precedido de --. Las opciones de una sola letra que no toman argumento se pueden combinar en un solo comando, por ejemplo, -fv equivale a -f -v. Las opciones con nombres largos se pueden abreviar a cualquier prefijo único de su nombre.

-a, --all
Muestra todos los archivos. Si esta opción no se especifica, no se mostrarán los nombres de archivo en el espacio de nombres POSIX.
-F, --classify
Añade un indicador (uno de */=@|) a las entradas.
-f, --force
Fuerza la ejecución. Por ejemplo, es necesario para ejecutar en una partición NTFS almacenada en un archivo normal.
-h, --help
Imprime la información de uso de ntfsls y sale.
-i, --inode
Imprime el número de inodo de cada archivo. Este es el número de referencia MFT en la terminología NTFS.
-l, --long
Utiliza un formato de listado largo.
-p, --path RUTA
El directorio cuyo contenido se va a listar o el archivo (incluida la ruta) sobre el que se va a mostrar información.
-q, --quiet
Suprime algunos mensajes de depuración/advertencia/error.
-R, --recursive
Muestra el contenido de todos los directorios debajo del directorio especificado.
-s, --system
A menos que se especifique esta opción, no se listarán todos los archivos que comiencen con un signo de dólar, ya que estos suelen ser archivos del sistema.
-v, --verbose
Muestra más mensajes de depuración/advertencia/error.
-V, --version
Imprime el número de versión de ntfsls y sale.
-x, --dos
Muestra nombres de archivo cortos, es decir, archivos en el espacio de nombres DOS, en lugar de nombres de archivo largos, es decir, archivos en el espacio de nombres WIN32.

ERRORES

No se conocen problemas con ntfsls. Si encuentra un error, envíe un correo electrónico describiendo el problema al equipo de desarrollo:
ntfs-3g-devel@lists.sf.net
