ntp_gettime(3) Manual de funciones de la biblioteca ntp_gettime(3)

NOMBRE

ntp_gettime, ntp_gettimex - obtener parámetros de tiempo (interfaz del demonio NTP)

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <sys/timex.h>
int ntp_gettime(struct ntptimeval *ntv);
int ntp_gettimex(struct ntptimeval *ntv);

DESCRIPCIÓN

Ambas APIs devuelven información al llamador a través del argumento ntv, una estructura del siguiente tipo:


struct ntptimeval {
    struct timeval time;    /* Hora actual */
    long maxerror;          /* Error máximo */
    long esterror;          /* Error estimado */
    long tai;               /* Desplazamiento TAI */
    /* Bytes de relleno adicionales que permiten la expansión futura */
};

Los campos de esta estructura son los siguientes:

time
La hora actual, expresada como una estructura timeval:

struct timeval {
    time_t      tv_sec;   /* Segundos desde la Época */
    suseconds_t tv_usec;  /* Microsegundos */
};

maxerror
Error máximo, en microsegundos. Este valor puede ser inicializado por ntp_adjtime(3) y se incrementa periódicamente (en Linux: cada segundo), pero se limita a un límite superior (la constante del kernel NTP_PHASE_MAX, con un valor de 16.000).
esterror
Error estimado, en microsegundos. Este valor puede ser establecido a través de ntp_adjtime(3) para contener una estimación de la diferencia entre el reloj del sistema y la hora verdadera. Este valor no se utiliza dentro del kernel.
tai
Desplazamiento TAI (Tiempo Internacional Atómico).

ntp_gettime() devuelve una estructura ntptimeval en la que se rellenan los campos time, maxerror y esterror.

ntp_gettimex() realiza la misma tarea que ntp_gettime(), pero también devuelve información en el campo tai.

VALOR DE RETORNO

Los valores de retorno para ntp_gettime() y ntp_gettimex() son los de adjtimex(2). Dado un puntero de argumento correcto, estas funciones siempre tienen éxito.
