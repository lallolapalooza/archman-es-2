BYTEORDER(3) Manual de funciones de biblioteca BYTEORDER(3)

NOMBRE

htonl, htons, ntohl, ntohs - convierte valores entre el orden de bytes del host y el orden de bytes de la red

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <arpa/inet.h>
uint32_t htonl(uint32_t hostlong);
uint16_t htons(uint16_t hostshort);
uint32_t ntohl(uint32_t netlong);
uint16_t ntohs(uint16_t netshort);

DESCRIPCIÓN

La función htonl() convierte el entero sin signo hostlong del orden de bytes del host al orden de bytes de la red.

La función htons() convierte el entero corto sin signo hostshort del orden de bytes del host al orden de bytes de la red.

La función ntohl() convierte el entero sin signo netlong del orden de bytes de la red al orden de bytes del host.

La función ntohs() convierte el entero corto sin signo netshort del orden de bytes de la red al orden de bytes del host.

En i386, el orden de bytes del host es primero el byte menos significativo, mientras que el orden de bytes de la red, tal como se usa en Internet, es primero el byte más significativo.

ATTRIBUTES

Para obtener una explicación de los términos utilizados en esta sección, consulte attributes(7).

Interfaz Atributo Valor
htonl (), htons (), ntohl (), ntohs () Seguridad de hilos MT-Safe
