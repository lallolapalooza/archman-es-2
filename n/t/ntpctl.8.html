ntpctl(8)

Paquete: openntpd

Licencias: BSD

NTPCTL(8) Manual del Administrador del Sistema NTPCTL(8)

NOMBRE

ntpctl — controla el demonio del Protocolo de Tiempo de Red

SINOPSIS

ntpctl -s all | peers | Sensors | status

DESCRIPCIÓN

El programa ntpctl muestra información sobre el demonio en ejecución del ntpd(8).

Las opciones son las siguientes:

-s all | peers | Sensors | status
Se utiliza para mostrar información sobre el demonio en ejecución. Las palabras clave pueden abreviarse.

all muestra todos los datos disponibles.

peers muestra la siguiente información sobre cada par: peso, nivel de confianza, estrato, número de segundos hasta la próxima sondeo, intervalo de sondeo en segundos, y desfase, retraso de red y fluctuación de red en milisegundos. Cuando el reloj del sistema está sincronizado con un par, se muestra un asterisco a la izquierda de la columna de peso para ese par.

Sensors muestra la siguiente información sobre cada sensor: peso, estado de "bueno" del sensor, estrato, y desfase y la corrección configurada en milisegundos. Cuando el reloj del sistema está sincronizado con un sensor, se muestra un asterisco a la izquierda de la columna de peso para ese sensor.

status muestra el estado de los pares y sensores, y si el reloj del sistema está sincronizado. Cuando el reloj del sistema está sincronizado, se muestra el estrato. Cuando el reloj del sistema no está sincronizado, se muestra el desfase del reloj del sistema, tal como lo informa la llamada al sistema adjtime(2). Cuando se establece la restricción mediana, se muestra el desfase con la hora local.

ARCHIVOS

/var/run/ntpd.sock
Archivo de socket para la comunicación con ntpd(8).

VER TAMBIÉN

adjtime(2), ntpd.conf(5), ntpd(8)

HISTORIAL

El programa ntpctl apareció por primera vez en OpenBSD 5.5.
