NOMBRE

ntfslabel - mostrar/cambiar la etiqueta de un sistema de archivos ntfs

SINOPSIS

ntfslabel [opciones] dispositivo [nueva-etiqueta]

DESCRIPCIÓN

ntfslabel mostrará o cambiará la etiqueta del sistema de archivos en el sistema de archivos ntfs ubicado en dispositivo. También puede cambiar el número de serie del dispositivo.

Si el argumento opcional nueva-etiqueta no está presente, y no hay ninguna opción presente, ntfslabel simplemente mostrará la etiqueta actual del sistema de archivos.

Si el argumento opcional nueva-etiqueta está presente, entonces ntfslabel establecerá la etiqueta del sistema de archivos a nueva-etiqueta. Las etiquetas de los sistemas de archivos NTFS pueden tener hasta 128 caracteres Unicode; si nueva-etiqueta es más larga que 128 caracteres Unicode, ntfslabel la truncará e imprimirá un mensaje de advertencia.

También es posible establecer la etiqueta del sistema de archivos usando la opción -L de mkntfs(8) durante la creación del sistema de archivos.

OPCIONES

A continuación se presenta un resumen de todas las opciones que acepta ntfslabel. Casi todas las opciones tienen dos nombres equivalentes. El nombre corto va precedido de - y el nombre largo va precedido de --. Las opciones de una sola letra, que no toman un argumento, se pueden combinar en un solo comando, por ejemplo, -fv es equivalente a -f -v. Las opciones con nombre largo se pueden abreviar a cualquier prefijo único de su nombre.

-f, --force
Esto anulará algunos valores predeterminados sensatos, como no trabajar con un volumen montado. Use esta opción con precaución.
-h, --help
Muestra una lista de opciones con una breve descripción de cada una.
--new-serial[=ssssssssssssssss], o
--new-half-serial[=ssssssss]
Establece un nuevo número de serie en el dispositivo, ya sea el valor del argumento, o uno aleatorio si no se proporciona ningún argumento. El número de serie es un número de 64 bits, representado como un número hexadecimal de dieciséis dígitos, utilizado para identificar el dispositivo durante el proceso de montaje. Como consecuencia, dos dispositivos con el mismo número de serie no pueden montarse al mismo tiempo en el mismo ordenador. Este no es el UUID del volumen utilizado por Windows para localizar archivos que se han movido a otro volumen.

La opción --new-half-serial solo cambia la parte superior del número de serie, manteniendo la parte inferior que utiliza Windows sin cambios. En este caso, el argumento opcional es un número hexadecimal de ocho dígitos.

-n, --no-action
No escribir realmente en el disco.
-q, --quiet
Reduce la cantidad de salida al mínimo.
-v, --verbose
Aumenta la cantidad de salida que imprime ntfslabel. Se muestran la etiqueta y el número de serie.
-V, --version
Muestra el número de versión, derechos de autor y licencia de ntfslabel.

ERRORES

No se conocen problemas con ntfslabel. Si encuentra un error, envíe un correo electrónico describiendo el problema al equipo de desarrollo:
ntfs-3g-devel@lists.sf.net
