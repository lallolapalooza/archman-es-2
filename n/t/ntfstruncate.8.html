NTFSTRUNCATE(8) Manual del Administrador del Sistema NTFSTRUNCATE(8)

NOMBRE

ntfstruncate - truncar un archivo en un volumen NTFS

SINOPSIS

ntfstruncate [opciones] dispositivo archivo [tipo-atributo [nombre-atributo]] nueva-longitud

DESCRIPCIÓN

ntfstruncate trunca (o extiende) un atributo especificado perteneciente a un archivo o directorio, a una longitud especificada.

OPCIONES

A continuación se presenta un resumen de todas las opciones que ntfstruncate acepta. Casi todas las opciones tienen dos nombres equivalentes. El nombre corto va precedido de - y el nombre largo va precedido de --. Las opciones de una sola letra que no toman argumento pueden combinarse en un solo comando, por ejemplo, -fv es equivalente a -f -v. Los nombres largos de las opciones pueden abreviarse a cualquier prefijo único de su nombre.

-f, --force
Esto anulará algunas configuraciones predeterminadas sensatas, como no usar un volumen montado. Use esta opción con precaución.
-h, --help
Muestra una lista de opciones con una breve descripción de cada una.
-l
Muestra información de licencia.
-n, --no-action
Simula el truncamiento sin escribir realmente en el dispositivo.
-q, --quiet
Suprime algunos mensajes de depuración/advertencia/error.
-v, --verbose
Muestra más mensajes de depuración/advertencia/error.
-V, --version
Muestra el número de versión, los derechos de autor y la licencia de ntfstruncate.
tipo-atributo
Define un tipo de atributo particular para ser truncado (solo uso avanzado). Por defecto, el atributo $DATA sin nombre (el contenido de un archivo plano) será truncado. El atributo debe especificarse por un número en decimal o hexadecimal:
Hex Decimal Nombre
0x10 16 "$STANDARD_INFORMATION"
0x20 32 "$ATTRIBUTE_LIST"
0x30 48 "$FILE_NAME"
0x40 64 "$OBJECT_ID"
0x50 80 "$SECURITY_DESCRIPTOR"
0x60 96 "$VOLUME_NAME"
0x70 112 "$VOLUME_INFORMATION"
0x80 128 "$DATA"
0x90 144 "$INDEX_ROOT"
0xA0 160 "$INDEX_ALLOCATION"
0xB0 176 "$BITMAP"
0xC0 192 "$REPARSE_POINT"
0xD0 208 "$EA_INFORMATION"
0xE0 224 "$EA"
0xF0 240 "$PROPERTY_SET"
0x100 256 "$LOGGED_UTILITY_STREAM"
nombre-atributo
Define el nombre del tipo de atributo particular a truncar (solo uso avanzado).
nueva-longitud
Especifica el tamaño objetivo del archivo. Se redondeará a un múltiplo del tamaño del clúster. Se puede añadir un sufijo K, M, G, T, P o E para indicar un factor multiplicador de una potencia de 1000. De forma similar, se puede añadir un sufijo Ki, Mi, Gi, Ti, Pi o Ei para indicar un factor multiplicador de una potencia de 1024.

EJEMPLOS

Cambiar el tamaño del archivo database.db ubicado en el directorio Data, en la raíz de un sistema de archivos NTFS, a 100MB.

ntfstruncate /dev/sda1 Data/database.db 100M

ERRORES

No se conocen problemas con ntfstruncate. Si encuentra un error, por favor envíe un correo electrónico describiendo el problema al equipo de desarrollo:
ntfs-3g-devel@lists.sf.net
