nbd_can_meta_context(3) LIBNBD nbd_can_meta_context(3)

NOMBRE

nbd_can_meta_context - ¿admite el servidor un contexto meta específico?

SINOPSIS

#include <libnbd.h>
int nbd_can_meta_context (
      struct nbd_handle *h, const char *metacontext
    );

DESCRIPCIÓN

Devuelve verdadero si el servidor admite el contexto meta dado (ver nbd_add_meta_context(3)). Devuelve falso si el servidor no lo admite. Es posible que este comando falle si se solicitaron contextos meta pero falta o falló un intento de NBD_OPT_SET_META_CONTEXT durante la negociación de opciones.

Si el servidor admite el filtrado de estado de bloque (ver nbd_can_block_status_payload(3), esta función debe devolver verdadero para cualquier nombre de filtro que se pase a nbd_block_status_filter(3).

El único parámetro es el nombre del contexto de metadatos, por ejemplo "LIBNBD_CONTEXT_BASE_ALLOCATION". <libnbd.h> incluye constantes definidas para contextos de espacio de nombres conocidos que comienzan con "LIBNBD_CONTEXT_", pero puede pasar libremente otros contextos.

Esta llamada no bloquea, ya que devuelve datos que se guardan en el manejador del apretón de manos del protocolo NBD.

VALOR DE RETORNO

Esta llamada devuelve un valor booleano.

ERRORES

En caso de error, se devuelve -1.

Consulte "MANEJO DE ERRORES" en libnbd(3) para obtener más detalles sobre el error.

Los siguientes parámetros no deben ser NULL: "h", "metacontext". Para más información, consulte "Parámetros no nulos" en libnbd(3).

ESTADO DEL MANEJADOR

nbd_can_meta_context se puede llamar cuando el manejador está en los siguientes estados:

┌─────────────────────────────────────┬─────────────────────────┐
│ Manejador creado, antes de conectar │ ❌ error │
│ Conectando │ ❌ error │
│ Conectando y apretón de manos (opt_mode) │ ✅ permitido │
│ Conectado al servidor │ ✅ permitido │
│ Conexión cerrada │ ✅ permitido │
│ Manejador muerto │ ❌ error │
└─────────────────────────────────────┴─────────────────────────┘

VERSIÓN

Esta función apareció por primera vez en libnbd 1.0.

Si necesita probar si esta función está disponible en tiempo de compilación, verifique si el siguiente macro está definido:

#define LIBNBD_HAVE_NBD_CAN_META_CONTEXT 1
