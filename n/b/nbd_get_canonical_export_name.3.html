nbd_get_canonical_export_name(3)

Paquete: libnbd

Licencias: LGPL-2.1-or-later

nbd_get_canonical_export_name(3) LIBNBD nbd_get_canonical_export_name(3)

NOMBRE

nbd_get_canonical_export_name - devuelve el nombre canónico de exportación, si el servidor tiene uno

SINOPSIS

#include <libnbd.h>
char * nbd_get_canonical_export_name (
         struct nbd_handle *h
       );

DESCRIPCIÓN

El protocolo NBD permite a un servidor informar un nombre canónico de exportación opcional, que puede diferir de la solicitud del cliente (establecida por nbd_set_export_name(3) o nbd_connect_uri(3)). Esta función accede a cualquier nombre devuelto por el servidor; puede ser el mismo que la solicitud del cliente, pero es más probable que difiera cuando el cliente solicitó una conexión al nombre de exportación predeterminado (una cadena vacía "").

Es poco probable que algunos servidores informen un nombre canónico a menos que el cliente lo haya indicado específicamente, a través de nbd_set_full_info(3).

VALOR DE RETORNO

Esta llamada devuelve una cadena. El llamador debe liberar la cadena devuelta para evitar una fuga de memoria.

ERRORES

En caso de error, se devuelve "NULL".

Consulte "MANEJO DE ERRORES" en libnbd(3) para obtener más detalles sobre cómo obtener detalles adicionales del error.

Los siguientes parámetros no deben ser NULL: "h". Para más información, consulte "Parámetros no NULL" en libnbd(3).

ESTADO DEL MANEJADOR

nbd_get_canonical_export_name puede llamarse cuando el manejador se encuentra en los siguientes estados:

┌─────────────────────────────────────┬─────────────────────────┐
│ Manejador creado, antes de conectar   │ ❌ error                │
│ Conectando                          │ ❌ error                │
│ Conectando y haciendo handshake (opt_mode) │ ✅ permitido              │
│ Conectado al servidor             │ ✅ permitido              │
│ Conexión cerrada                 │ ✅ permitido              │
│ Manejador muerto                     │ ❌ error                │
└─────────────────────────────────────┴─────────────────────────┘

VERSIÓN

Esta función apareció por primera vez en libnbd 1.4.

Si necesita probar si esta función está disponible en tiempo de compilación, verifique si está definido el siguiente macro:

#define LIBNBD_HAVE_NBD_GET_CANONICAL_EXPORT_NAME 1

EJEMPLO

Este ejemplo también está disponible como examples/server-flags.c en el código fuente de libnbd.

/* Este ejemplo muestra cómo conectarse a un servidor NBD
 * e imprimir las banderas de exportación.
 *
 * Puedes probarlo con nbdkit así:
 *
 * nbdkit -U - memory 1M \
 *   --run './server-flags $unixsocket'
 */
#include <stdio.h>
#include <stdlib.h>
#include <stdbool.h>
#include <libnbd.h>
int
main (int argc, char *argv[])
{
  struct nbd_handle *nbd;
  char *str;
  int flag;
  if (argc != 2) {
    fprintf (stderr, "%s socket\n", argv[0]);
    exit (EXIT_FAILURE);
  }
  /* Crear el manejador libnbd. */
  nbd = nbd_create ();
  if (nbd == NULL) {
    fprintf (stderr, "%s\n", nbd_get_error ());
    exit (EXIT_FAILURE);
  }
  /* Solicitar información completa. */
#if LIBNBD_HAVE_NBD_SET_FULL_INFO /* Añadido en 1.4 */
  if (nbd_set_full_info (nbd, true) == -1) {
    fprintf (stderr, "%s\n", nbd_get_error ());
    exit (EXIT_FAILURE);
  }
#endif
  /* Conectarse al servidor NBD a través de un
   * socket de dominio Unix.
   */
  if (nbd_connect_unix (nbd, argv[1]) == -1) {
    fprintf (stderr, "%s\n", nbd_get_error ());
    exit (EXIT_FAILURE);
  }
  /* Ver si el servidor proporcionó detalles adicionales,
   * usando funciones añadidas en 1.4
   */
#if LIBNBD_HAVE_NBD_GET_EXPORT_DESCRIPTION
  str = nbd_get_canonical_export_name (nbd);
  if (str)
    printf ("nombre_canonico = %s\n", str);
  free (str);
  str = nbd_get_export_description (nbd);
  if (str)
    printf ("descripcion = %s\n", str);
  free (str);
#endif
  /* Leer e imprimir las banderas. */
#define PRINT_FLAG(flag_fn)                     \
  flag = flag_fn (nbd);                         \
  if (flag == -1) {                             \
    fprintf (stderr, "%s\n", nbd_get_error ()); \
    exit (EXIT_FAILURE);                        \
  }                                             \
  printf (#flag_fn " = %s\n",                   \
          flag ? "true" : "false");
  PRINT_FLAG (nbd_can_cache);
  PRINT_FLAG (nbd_can_df);
  PRINT_FLAG (nbd_can_flush);
  PRINT_FLAG (nbd_can_fua);
  PRINT_FLAG (nbd_can_multi_conn);
  PRINT_FLAG (nbd_can_trim);
  PRINT_FLAG (nbd_can_zero);
#if LIBNBD_HAVE_NBD_CAN_FAST_ZERO
  /* Añadido en 1.2 */
  PRINT_FLAG (nbd_can_fast_zero);
#endif
#if LIBNBD_HAVE_NBD_CAN_BLOCK_STATUS_PAYLOAD
  /* Añadido en 1.18 */
  PRINT_FLAG (nbd_can_block_status_payload);
#endif
  PRINT_FLAG (nbd_is_read_only);
  PRINT_FLAG (nbd_is_rotational);
  /* Cerrar el manejador libnbd. */
  nbd_close (nbd);
  exit (EXIT_SUCCESS);
}
