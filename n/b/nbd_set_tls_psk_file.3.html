nbd_set_tls_psk_file(3)

Paquete: libnbd

Licencias: LGPL-2.1-or-later

nbd_set_tls_psk_file(3) LIBNBD nbd_set_tls_psk_file(3)

NOMBRE

nbd_set_tls_psk_file - establece el nombre del archivo de Claves Precompartidas (PSK) TLS

SINOPSIS

#include <libnbd.h>
int nbd_set_tls_psk_file (
      struct nbd_handle *h, const char *filename
    );

DESCRIPCIÓN

Establece el nombre del archivo de Claves Precompartidas (PSK) TLS. Esto se utiliza si se intenta autenticar con el servidor usando una clave precompartida. No hay un valor predeterminado, por lo que si no se establece, la autenticación PSK no se puede utilizar para conectarse al servidor.

Esta función se puede llamar independientemente de si TLS es compatible o no, pero no tendrá ningún efecto a menos que también se utilice nbd_set_tls(3) para solicitar o requerir TLS.

VALOR DE RETORNO

Si la llamada es exitosa, la función devuelve 0.

ERRORES

En caso de error, se devuelve -1.

Consulte "MANEJO DE ERRORES" en libnbd(3) para obtener más detalles sobre el error.

Los siguientes parámetros no deben ser NULL: "h", "filename". Para más información, consulte "Parámetros no nulos" en libnbd(3).

ESTADO DEL MANEJADOR

nbd_set_tls_psk_file puede llamarse cuando el manejador está en el siguiente estado:

┌─────────────────────────────────────┬─────────────────────────┐
│ Manejador creado, antes de conectar │ ✅ permitido              │
│ Conectando                          │ ❌ error                │
│ Conectando y estableciendo handshake (opt_mode) │ ❌ error                │
│ Conectado al servidor             │ ❌ error                │
│ Conexión cerrada                │ ❌ error                │
│ Manejador muerto                         │ ❌ error                │
└─────────────────────────────────────┴─────────────────────────┘

VERSIÓN

Esta función apareció por primera vez en libnbd 1.0.

Si necesita probar si esta función está disponible en tiempo de compilación, compruebe si el siguiente macro está definido:

#define LIBNBD_HAVE_NBD_SET_TLS_PSK_FILE 1

EJEMPLO

Este ejemplo también está disponible como examples/encryption.c en el código fuente de libnbd.

/* Un ejemplo que muestra cómo conectarse a un servidor que está
 * utilizando cifrado TLS.
 *
 * Esto requiere nbdkit y psktool de gnutls.
 *
 * Tanto libnbd como nbdkit soportan TLS-PSK, que es una forma de cifrado
 * más fácil de implementar. (Por supuesto, el cifrado basado en certificados
 * también es compatible, pero es más difícil crear un ejemplo autocontenido).
 */
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <unistd.h>
#include <libnbd.h>
#define TMPDIR "/tmp/XXXXXX"
#define KEYS "keys.psk"
#define USERNAME "alice"
static char dir[] = TMPDIR;
static char keys[] = TMPDIR "/" KEYS;
static char cmd[] =
  "psktool -u " USERNAME " -p " TMPDIR "/" KEYS;
/* Elimina el archivo de claves temporal cuando el programa
 * sale.
 */
static void
cleanup_keys (void)
{
  unlink (keys);
  rmdir (dir);
}
/* Crea el archivo de claves temporal para compartir con el
 * servidor.
 */
static void
create_keys (void)
{
  size_t i;
  if (mkdtemp (dir) == NULL) {
    perror ("mkdtemp");
    exit (EXIT_FAILURE);
  }
  i = strlen (cmd) - strlen (TMPDIR) - strlen (KEYS) - 1;
  memcpy (&cmd[i], dir, strlen (TMPDIR));
  memcpy (keys, dir, strlen (TMPDIR));
  if (system (cmd) != 0) {
    fprintf (stderr, "El comando psktool falló\n");
    exit (EXIT_FAILURE);
  }
  atexit (cleanup_keys);
}
int
main (int argc, char *argv[])
{
  struct nbd_handle *nbd;
  char buf[512];
  create_keys ();
  /* Crea el manejador libnbd. */
  nbd = nbd_create ();
  if (nbd == NULL) {
    fprintf (stderr, "%s\n", nbd_get_error ());
    exit (EXIT_FAILURE);
  }
  /* Habilita TLS en el cliente. */
  if (nbd_set_tls (nbd, LIBNBD_TLS_REQUIRE) == -1) {
    fprintf (stderr, "%s\n", nbd_get_error ());
    exit (EXIT_FAILURE);
  }
  /* Habilita TLS-PSK y pasa el nombre del archivo de claves. */
  if (nbd_set_tls_psk_file (nbd, keys) == -1) {
    fprintf (stderr, "%s\n", nbd_get_error ());
    exit (EXIT_FAILURE);
  }
  /* Establece el nombre de usuario local para la autenticación. */
  if (nbd_set_tls_username (nbd, USERNAME) == -1) {
    fprintf (stderr, "%s\n", nbd_get_error ());
    exit (EXIT_FAILURE);
  }
  /* Ejecuta nbdkit como un subproceso, habilitando y requiriendo
   * cifrado TLS-PSK.
   */
  char *args[] = {
    "nbdkit", "-s", "--exit-with-parent",
    "--tls", "require", "--tls-psk", keys,
    "pattern", "size=1M", NULL
  };
  if (nbd_connect_command (nbd, args) == -1) {
    fprintf (stderr, "%s\n", nbd_get_error ());
    exit (EXIT_FAILURE);
  }
  /* Lee el primer sector. */
  if (nbd_pread (nbd, buf, sizeof buf, 0, 0) == -1) {
    fprintf (stderr, "%s\n", nbd_get_error ());
    exit (EXIT_FAILURE);
  }
  /* Las conexiones TLS deben cerrarse. */
  if (nbd_shutdown (nbd, 0) == -1) {
    fprintf (stderr, "%s\n", nbd_get_error ());
    exit (EXIT_FAILURE);
  }
  /* Cierra el manejador libnbd. */
  nbd_close (nbd);
  exit (EXIT_SUCCESS);
}
