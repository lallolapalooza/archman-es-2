nbd_clear_meta_contexts(3) LIBNBD nbd_clear_meta_contexts(3)

NOMBRE

nbd_clear_meta_contexts - restablecer la lista de contextos meta solicitados

SINOPSIS

#include <libnbd.h>
int nbd_clear_meta_contexts (
      struct nbd_handle *h
    );

DESCRIPCIÓN

Durante la conexión, libnbd puede negociar cero o más contextos de metadatos con el servidor. Los contextos de metadatos son características (como "base:allocation") que describen la información devuelta por el comando nbd_block_status_64(3) (para "base:allocation" esto es si los bloques de datos están asignados, son cero o dispersos).

Este comando restablece la lista de contextos meta a solicitar a una lista vacía, para ser repoblada mediante el uso posterior de nbd_add_meta_context(3). Es útil principalmente cuando se selecciona el modo de negociación de opciones (ver nbd_set_opt_mode(3)), para alterar la lista de contextos intentados entre consultas de exportación subsiguientes.

VALOR DE RETORNO

Si la llamada es exitosa, la función devuelve 0.

ERRORES

En caso de error, se devuelve -1.

Consulte "MANEJO DE ERRORES" en libnbd(3) para obtener más detalles sobre el error.

Los siguientes parámetros no deben ser NULL: "h". Para más información, consulte "Parámetros no nulos" en libnbd(3).

ESTADO DEL MANEJADOR

nbd_clear_meta_contexts se puede llamar cuando el manejador se encuentra en los siguientes estados:

┌─────────────────────────────────────┬─────────────────────────┐
│ Manejador creado, antes de conectar   │ ✅ permitido              │
│ Conectando                          │ ❌ error                │
│ Conectando y handshake (opt_mode) │ ✅ permitido              │
│ Conectado al servidor             │ ❌ error                │
│ Conexión cerrada                   │ ❌ error                │
│ Manejador muerto                    │ ❌ error                │
└───────────────────────────────────────┴─────────────────────────┘

VERSIÓN

Esta función apareció por primera vez en libnbd 1.6.

Si necesita probar si esta función está disponible en tiempo de compilación, compruebe si el siguiente macro está definido:

#define LIBNBD_HAVE_NBD_CLEAR_META_CONTEXTS 1
