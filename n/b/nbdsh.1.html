NOMBRE

nbdsh - shell de dispositivo de bloque de red (NBD)

SINOPSIS

$ nbdsh
Bienvenido a nbdsh, la shell para interactuar con
servidores de Network Block Device (NBD).
El módulo 'nbd' ya ha sido importado y hay
un manejador NBD abierto llamado 'h'.
nbd> h.connect_command(["nbdkit", "-s", "memory", "1G"])
nbd> h.get_size()
1073741824
nbd> buf = b"hola, mundo"
nbd> h.pwrite(buf, 0)
nbd> exit()

DESCRIPCIÓN

nbdsh es una shell cliente basada en Python para acceder a servidores de Network Block Device (NBD).

Para obtener documentación sobre la API de libnbd, abra la shell y escriba:

help(nbd)

EJEMPLOS

Imprimir el tamaño de una exportación NBD

La opción -u se conecta a una URI NBD. La opción -c permite ejecutar sentencias Python únicas desde la línea de comandos. La combinación de estas dos opciones permite imprimir el tamaño en bytes de una exportación NBD:

$ nbdsh -u nbd://localhost -c 'print(h.get_size())'
1073741824

Hexdump del sector de arranque de una exportación NBD

Usando -c - puede alimentar un programa Python completo a la entrada estándar de nbdsh:

nbdsh -c - <<'EOF'
from subprocess import *
h.connect_uri("nbd://localhost")
bootsect = h.pread(512, 0)
p = Popen("hexdump -C", shell=True, stdin=PIPE)
p.stdin.write(bootsect)
EOF

OPCIONES

-h
--help
Muestra una breve ayuda de la línea de comandos y sale.
--base-allocation
Solicita el uso del contexto meta "base:allocation", que es el contexto más común utilizado con nbd_block_status_64(3). Esto es equivalente a llamar "h.set_meta_context(nbd.CONTEXT_BASE_ALLOCATION)" en la shell antes de conectarse, y funciona incluso cuando se combina con "--uri" (mientras que intentar lo mismo con "-c" sería demasiado tarde).
-c 'COMANDO ...'
--command 'COMANDO ...'
En lugar de iniciar una shell interactiva, ejecuta un comando. Esta opción se puede especificar varias veces para ejecutar múltiples comandos.
-c -
--command -
Lee la entrada estándar y la ejecuta como un comando.
-n
No crea el manejador implícito "h".
--opt-mode
Solicita que el modo de opciones esté habilitado, lo que proporciona un control detallado sobre la negociación de opciones después de contactar inicialmente con el servidor pero antes de usar realmente la exportación. Esto es equivalente a llamar "h.set_opt_mode(True)" en la shell antes de conectarse, y funciona incluso cuando se combina con "--uri" (mientras que intentar lo mismo con "-c" sería demasiado tarde).
-u URI
--uri URI
Conéctese a la URI NBD dada. Esto es equivalente al comando "h.connect_uri(URI)" en la shell.

Tenga en cuenta que la conexión se crea antes de procesar cualquier comando "-c", lo que impide el uso de comandos de configuración como "h.add_meta_context("NOMBRE")" desde la línea de comandos cuando se combina con esta opción. Las opciones "--opt-mode" y "--base-allocation" se pueden usar para que esta situación sea más fácil de manejar.

-v
--verbose
Habilita los mensajes detallados de libnbd. Esto tiene el mismo efecto que establecer la variable de entorno "LIBNBD_DEBUG=1"
-V
--version
Muestra el nombre y la versión del paquete y sale.

NOTAS

Ejemplos de nbdsh

Hay algunos scripts de ejemplo de nbdsh en el repositorio de código fuente de libnbd bajo sh/examples o consulte https://gitlab.com/nbdkit/libnbd/tree/master/sh/examples.

Usar libnbd directamente desde Python

nbdsh es conveniente para la creación de scripts en línea de comandos, pero no tiene que usarlo. En su lugar, puede escribir un programa o módulo Python ordinario que importe el módulo "nbd":

#!/usr/bin/python3
import nbd
h = nbd.NBD()
h.connect_uri("nbd://localhost")

Hay algunos scripts de ejemplo de Python en el repositorio de código fuente de libnbd bajo python/examples o consulte https://gitlab.com/nbdkit/libnbd/tree/master/python/examples.
