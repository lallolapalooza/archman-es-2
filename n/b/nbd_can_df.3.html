nbd_can_df(3)

Paquete: libnbd

Licencias: LGPL-2.1-or-later

nbd_can_df(3) LIBNBD nbd_can_df(3)

NOMBRE

nbd_can_df - ¿el servidor soporta el flag don't fragment en pread?

SINOPSIS

#include <libnbd.h>
int nbd_can_df (
      struct nbd_handle *h
    );

DESCRIPCIÓN

Devuelve true si el servidor soporta lecturas estructuradas con la capacidad de solicitar una lectura no fragmentada (ver nbd_pread_structured(3), nbd_aio_pread_structured(3)). Devuelve false si el servidor carece de lecturas estructuradas o si no soporta una solicitud de lectura no fragmentada.

Esta llamada no bloquea, ya que devuelve datos que se guardan en el manejador del apretón de manos del protocolo NBD.

VALOR DE RETORNO

Esta llamada devuelve un valor booleano.

ERRORES

En caso de error se devuelve -1.

Consulte "MANEJO DE ERRORES" en libnbd(3) para saber cómo obtener más detalles sobre el error.

Los siguientes parámetros no deben ser NULL: "h". Para más información, consulte "Parámetros no nulos" en libnbd(3).

ESTADO DEL MANEJADOR

nbd_can_df puede ser llamado cuando el manejador se encuentra en los siguientes estados:

┌─────────────────────────────────────┬─────────────────────────┐
│ Manejador creado, antes de conectar │ ❌ error │
│ Conectando │ ❌ error │
│ Conectando y apretón de manos (opt_mode) │ ✅ permitido │
│ Conectado al servidor │ ✅ permitido │
│ Conexión cerrada │ ✅ permitido │
│ Manejador muerto │ ❌ error │
└─────────────────────────────────────┴─────────────────────────┘

VERSIÓN

Esta función apareció por primera vez en libnbd 1.0.

Si necesita probar si esta función está disponible en tiempo de compilación, compruebe si el siguiente macro está definido:

#define LIBNBD_HAVE_NBD_CAN_DF 1

EJEMPLO

Este ejemplo también está disponible como examples/server-flags.c en el código fuente de libnbd.

/* Este ejemplo muestra cómo conectarse a un servidor NBD
 * e imprimir las banderas de exportación.
 *
 * Puedes probarlo con nbdkit así:
 *
 * nbdkit -U - memory 1M \
 *   --run './server-flags $unixsocket'
 */
#include <stdio.h>
#include <stdlib.h>
#include <stdbool.h>
#include <libnbd.h>
int
main (int argc, char *argv[])
{
  struct nbd_handle *nbd;
  char *str;
  int flag;
  if (argc != 2) {
    fprintf (stderr, "%s socket\n", argv[0]);
    exit (EXIT_FAILURE);
  }
  /* Crear el manejador de libnbd. */
  nbd = nbd_create ();
  if (nbd == NULL) {
    fprintf (stderr, "%s\n", nbd_get_error ());
    exit (EXIT_FAILURE);
  }
  /* Solicitar información completa. */
#if LIBNBD_HAVE_NBD_SET_FULL_INFO /* Añadido en 1.4 */
  if (nbd_set_full_info (nbd, true) == -1) {
    fprintf (stderr, "%s\n", nbd_get_error ());
    exit (EXIT_FAILURE);
  }
#endif
  /* Conectar al servidor NBD a través de un
   * socket de dominio Unix.
   */
  if (nbd_connect_unix (nbd, argv[1]) == -1) {
    fprintf (stderr, "%s\n", nbd_get_error ());
    exit (EXIT_FAILURE);
  }
  /* Ver si el servidor proporcionó detalles adicionales,
   * usando funciones añadidas en 1.4
   */
#if LIBNBD_HAVE_NBD_GET_EXPORT_DESCRIPTION
  str = nbd_get_canonical_export_name (nbd);
  if (str)
    printf ("canonical_name = %s\n", str);
  free (str);
  str = nbd_get_export_description (nbd);
  if (str)
    printf ("description = %s\n", str);
  free (str);
#endif
  /* Leer e imprimir las banderas. */
#define PRINT_FLAG(flag_fn)                     \
  flag = flag_fn (nbd);                         \
  if (flag == -1) {                             \
    fprintf (stderr, "%s\n", nbd_get_error ()); \
    exit (EXIT_FAILURE);                        \
  }                                             \
  printf (#flag_fn " = %s\n",                   \
          flag ? "true" : "false");
  PRINT_FLAG (nbd_can_cache);
  PRINT_FLAG (nbd_can_df);
  PRINT_FLAG (nbd_can_flush);
  PRINT_FLAG (nbd_can_fua);
  PRINT_FLAG (nbd_can_multi_conn);
  PRINT_FLAG (nbd_can_trim);
  PRINT_FLAG (nbd_can_zero);
#if LIBNBD_HAVE_NBD_CAN_FAST_ZERO
  /* Añadido en 1.2 */
  PRINT_FLAG (nbd_can_fast_zero);
#endif
#if LIBNBD_HAVE_NBD_CAN_BLOCK_STATUS_PAYLOAD
  /* Añadido en 1.18 */
  PRINT_FLAG (nbd_can_block_status_payload);
#endif
  PRINT_FLAG (nbd_is_read_only);
  PRINT_FLAG (nbd_is_rotational);
  /* Cerrar el manejador de libnbd. */
  nbd_close (nbd);
  exit (EXIT_SUCCESS);
}

NAME

nbd-client - Network Block Device (NBD) client

SYNOPSIS

nbd-client [options] host [exportname]

nbd-client -c | --connect [options] host [exportname]

nbd-client -d | --disconnect [exportname]

nbd-client -l | --list [host]

nbd-client -L | --show-info [host]

nbd-client -V | --version

nbd-client -h | --help

DESCRIPTION

The nbd-client command is used to connect to a Network Block Device (NBD) server and export its block devices over the network. It allows you to treat a remote block device as if it were a local device.

OPTIONS

-c, --connect
Connect to the NBD server. This is the default action if no other action is specified.
-d, --disconnect
Disconnect from the NBD server for the specified export name. If no export name is given, it disconnects from all NBD devices.
-l, --list
List the available exports on the NBD server. If a host is specified, list exports from that host; otherwise, list exports from the default NBD server.
-L, --show-info
Show information about the NBD server and its exports. If a host is specified, show info from that host; otherwise, show info from the default NBD server.
-n, --nbds-max <number>
Set the maximum number of NBD devices that can be created. Default is 16.
-N, --partition <number>
Specify the partition number to connect to. If not specified, the first available partition is used.
-p, --port <number>
Specify the port number to connect to. Default is 11333.
-s, --swap
Use the connected NBD device as a swap device.
-t, --timeout <seconds>
Set the connection timeout in seconds.
-u, --user <user>
Specify the user to connect as (for authentication).
-f, --fwd-device <device>
Forward I/O operations for the NBD device to another local device.
-e, --exportname <name>
Specify the export name to connect to. This is often a path or identifier on the server.
-k, --key <keyfile>
Specify a key file for authentication.
-a, --async
Use asynchronous I/O operations.
-m, --minimum-size <size>
Set the minimum size of the exported device. The device will be padded to this size if it's smaller.
-M, --max-size <size>
Set the maximum size of the exported device. This is useful to prevent the client from seeing a larger device than intended.
-I, --max-connections <number>
Set the maximum number of simultaneous connections allowed to the exported device.
-v, --verbose
Enable verbose output.
-V, --version
Display version information and exit.
-h, --help
Display a help message and exit.

ERRORS

The nbd-client command will return an appropriate exit code to indicate success or failure. Common errors include connection refused, authentication failure, and invalid export name.

HANDLE STATE

The nbd-client utility handles the state of the NBD connection, including establishing and terminating connections, and managing the mapping of remote exports to local block devices.

VERSION

Display version information and exit.

EXAMPLE

To connect to an NBD server at 192.168.1.100, exporting a device named "my_export", and making it available as /dev/nbd0:

nbd-client 192.168.1.100 my_export /dev/nbd0

To disconnect from all NBD devices:

nbd-client -d

To list available exports on a server:

nbd-client -l 192.168.1.100
