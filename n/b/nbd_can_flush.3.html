nbd_can_flush(3)

Paquete: libnbd

Licencias: LGPL-2.1-or-later

nbd_can_flush(3) LIBNBD nbd_can_flush(3)

NOMBRE

nbd_can_flush - ¿el servidor soporta el comando flush?

SINOPSIS

#include <libnbd.h>
int nbd_can_flush (
      struct nbd_handle *h
    );

DESCRIPCIÓN

Devuelve verdadero si el servidor soporta el comando flush (ver nbd_flush(3), nbd_aio_flush(3)). Devuelve falso si el servidor no lo soporta.

Esta llamada no bloquea, porque devuelve datos que se guardan en el handle del apretón de manos del protocolo NBD.

VALOR DE RETORNO

Esta llamada devuelve un valor booleano.

ERRORES

En caso de error se devuelve -1.

Consulte "MANEJO DE ERRORES" en libnbd(3) para saber cómo obtener más detalles del error.

Los siguientes parámetros no deben ser NULL: "h". Para más información consulte "Parámetros no nulos" en libnbd(3).

ESTADO DEL HANDLE

nbd_can_flush puede ser llamado cuando el handle se encuentra en los siguientes estados:

┌─────────────────────────────────────┬─────────────────────────┐
│ Handle creado, antes de conectar │ ❌ error                │
│ Conectando                          │ ❌ error                │
│ Conectando y apretón de manos (opt_mode) │ ✅ permitido              │
│ Conectado al servidor             │ ✅ permitido              │
│ Conexión cerrada                   │ ✅ permitido              │
│ Handle muerto                         │ ❌ error                │
└─────────────────────────────────────┴─────────────────────────┘

VERSIÓN

Esta función apareció por primera vez en libnbd 1.0.

Si necesita probar si esta función está disponible en tiempo de compilación compruebe si el siguiente macro está definido:

#define LIBNBD_HAVE_NBD_CAN_FLUSH 1

EJEMPLO

Este ejemplo también está disponible como examples/server-flags.c en el código fuente de libnbd.

/* Este ejemplo muestra cómo conectarse a un servidor NBD
 * e imprimir los flags de exportación.
 *
 * Puedes probarlo con nbdkit así:
 *
 * nbdkit -U - memory 1M \
 *   --run './server-flags $unixsocket'
 */
#include <stdio.h>
#include <stdlib.h>
#include <stdbool.h>
#include <libnbd.h>
int
main (int argc, char *argv[])
{
  struct nbd_handle *nbd;
  char *str;
  int flag;
  if (argc != 2) {
    fprintf (stderr, "%s socket\n", argv[0]);
    exit (EXIT_FAILURE);
  }
  /* Crear el handle de libnbd. */
  nbd = nbd_create ();
  if (nbd == NULL) {
    fprintf (stderr, "%s\n", nbd_get_error ());
    exit (EXIT_FAILURE);
  }
  /* Solicitar información completa. */
#if LIBNBD_HAVE_NBD_SET_FULL_INFO /* Añadido en 1.4 */
  if (nbd_set_full_info (nbd, true) == -1) {
    fprintf (stderr, "%s\n", nbd_get_error ());
    exit (EXIT_FAILURE);
  }
#endif
  /* Conectarse al servidor NBD a través de un
   * socket de dominio Unix.
   */
  if (nbd_connect_unix (nbd, argv[1]) == -1) {
    fprintf (stderr, "%s\n", nbd_get_error ());
    exit (EXIT_FAILURE);
  }
  /* Ver si el servidor proporcionó detalles adicionales,
   * usando funciones añadidas en 1.4
   */
#if LIBNBD_HAVE_NBD_GET_EXPORT_DESCRIPTION
  str = nbd_get_canonical_export_name (nbd);
  if (str)
    printf ("canonical_name = %s\n", str);
  free (str);
  str = nbd_get_export_description (nbd);
  if (str)
    printf ("description = %s\n", str);
  free (str);
#endif
  /* Leer e imprimir los flags. */
#define PRINT_FLAG(flag_fn)                     \
  flag = flag_fn (nbd);                         \
  if (flag == -1) {                             \
    fprintf (stderr, "%s\n", nbd_get_error ()); \
    exit (EXIT_FAILURE);                        \
  }                                             \
  printf (#flag_fn " = %s\n",                   \
          flag ? "true" : "false");
  PRINT_FLAG (nbd_can_cache);
  PRINT_FLAG (nbd_can_df);
  PRINT_FLAG (nbd_can_flush);
  PRINT_FLAG (nbd_can_fua);
  PRINT_FLAG (nbd_can_multi_conn);
  PRINT_FLAG (nbd_can_trim);
  PRINT_FLAG (nbd_can_zero);
#if LIBNBD_HAVE_NBD_CAN_FAST_ZERO
  /* Añadido en 1.2 */
  PRINT_FLAG (nbd_can_fast_zero);
#endif
#if LIBNBD_HAVE_NBD_CAN_BLOCK_STATUS_PAYLOAD
  /* Añadido en 1.18 */
  PRINT_FLAG (nbd_can_block_status_payload);
#endif
  PRINT_FLAG (nbd_is_read_only);
  PRINT_FLAG (nbd_is_rotational);
  /* Cerrar el handle de libnbd. */
  nbd_close (nbd);
  exit (EXIT_SUCCESS);
}

DESCRIPTION

La función nbd_can_flush comprueba si el servidor NBD conectado a conn soportará la exportación de la operación de vaciado de caché (ver nbd_flush(3)).

Si el servidor soporta la operación, la función devolverá 1, de lo contrario, devolverá 0.

EXAMPLE

Aquí hay un pequeño programa que comprueba si el dispositivo NBD conectado a conn soporta vaciado de caché:


// ...
NBD_CONNECTION *conn = nbd_connect_simple ("localhost", "10809", NULL, NULL);
if (conn == NULL) {
    // Manejar error
    exit (EXIT_FAILURE);
}

if (nbd_can_flush (conn)) {
    printf ("El dispositivo NBD soporta vaciado de caché.\n");
} else {
    printf ("El dispositivo NBD NO soporta vaciado de caché.\n");
}

nbd_close (conn);
// ...
