nbd_set_export_name(3)

Paquete: libnbd

Licencias: LGPL-2.1-or-later

nbd_set_export_name(3) LIBNBD nbd_set_export_name(3)

NOMBRE

nbd_set_export_name - establece el nombre de exportación

SINOPSIS

#include <libnbd.h>
int nbd_set_export_name (
      struct nbd_handle *h, const char *export_name
    );

DESCRIPCIÓN

Algunos servidores NBD pueden servir múltiples imágenes de disco ("exportaciones"). La exportación es elegida por el cliente, solicitando un nombre de exportación durante la fase de negociación. La exportación por defecto es la cadena vacía "".

Algunos servidores NBD ignoran esto y sirven el mismo contenido sin importar. Esto solo es relevante cuando se conecta a servidores que utilizan el protocolo newstyle, ya que el protocolo oldstyle no admitía nombres de exportación.

El protocolo NBD limita los nombres de exportación a 4096 bytes, pero los servidores pueden no admitir la longitud completa. La codificación de los nombres de exportación es siempre UTF-8.

Cuando el modo de opciones no está en uso, el nombre de exportación debe establecerse antes de iniciar una conexión. Sin embargo, cuando nbd_set_opt_mode(3) ha habilitado el modo de opciones, es posible cambiar el nombre de exportación antes de nbd_opt_go(3). En particular, el uso de nbd_opt_list(3) durante la negociación se puede utilizar para determinar un nombre que el servidor probablemente acepte, y nbd_opt_info(3) se puede utilizar para obtener detalles sobre una exportación antes de conectarse.

Esta llamada puede omitirse si se utiliza nbd_connect_uri(3) para conectarse a una URI que incluya un nombre de exportación.

VALOR DE RETORNO

Si la llamada es exitosa, la función devuelve 0.

ERRORES

En caso de error, se devuelve -1.

Consulte "MANEJO DE ERRORES" en libnbd(3) para obtener más detalles sobre el error.

Los siguientes parámetros no deben ser NULL: "h", "export_name". Para más información, consulte "Parámetros no nulos" en libnbd(3).

ESTADO DEL MANEJADOR

Se puede llamar a nbd_set_export_name cuando el manejador se encuentra en los siguientes estados:

┌─────────────────────────────────────┬─────────────────────────┐
│ Manejador creado, antes de conectar    │ ✅ permitido              │
│ Conectando                           │ ❌ error                │
│ Conectando y handshake (opt_mode)  │ ✅ permitido              │
│ Conectado al servidor                │ ❌ error                │
│ Conexión cerrada                   │ ❌ error                │
│ Manejador inactivo                 │ ❌ error                │
└─────────────────────────────────────┴─────────────────────────┘

VERSIÓN

Esta función apareció por primera vez en libnbd 1.0.

Si necesita probar si esta función está disponible en tiempo de compilación, compruebe si el siguiente macro está definido:

#define LIBNBD_HAVE_NBD_SET_EXPORT_NAME 1
