nbd_opt_starttls(3) LIBNBD nbd_opt_starttls(3)

NOMBRE

nbd_opt_starttls - solicitar al servidor que inicie TLS

SINOPSIS

#include <libnbd.h>
int nbd_opt_starttls (
      struct nbd_handle *h
    );

DESCRIPCIÓN

Solicita que el servidor inicie una conexión TLS segura, enviando "NBD_OPT_STARTTLS". Esto solo se puede usar si nbd_set_opt_mode(3) habilitó el modo de opciones; además, si usa nbd_set_tls(3) para solicitar algo que no sea el valor predeterminado de "LIBNBD_TLS_DISABLE", libnbd ya habrá intentado una conexión TLS antes de permitirle el control sobre la negociación de opciones. Este comando está deshabilitado si nbd_supports_tls(3) informa falso.

Esta función es principalmente útil para probar casos límite en la gestión del servidor; en particular, el uso indebido de esta función, junto con un servidor que no es cuidadoso al restablecer comandos con estado como nbd_opt_structured_reply(3), podría resultar en un agujero de seguridad (ver CVE-2021-3716 contra nbdkit, por ejemplo). Por lo tanto, cuando la seguridad es una preocupación, debe preferir usar en su lugar nbd_set_tls(3) con "LIBNBD_TLS_REQUIRE" y dejar que libnbd negocie TLS automáticamente.

Esta función devuelve verdadero si el servidor responde con éxito, falso si el servidor responde con un error, y falla solo si el servidor no responde (por ejemplo, por pérdida de conexión, que puede incluir cuando el servidor rechaza las credenciales proporcionadas durante el apretón de manos TLS). Tenga en cuenta que el protocolo NBD documenta que solicitar TLS después de que ya está habilitado es un error del cliente; la mayoría de los servidores fallarán graciosamente una segunda solicitud, pero eso no degrada una sesión TLS que ya se ha establecido, como informa nbd_get_tls_negotiated(3).

VALOR DE RETORNO

Esta llamada devuelve un valor booleano.

ERRORES

En caso de error se devuelve -1.

Consulte "MANEJO DE ERRORES" en libnbd(3) para obtener más detalles sobre el error.

Los siguientes parámetros no deben ser NULL: "h". Para más información, consulte "Parámetros no nulos" en libnbd(3).

ESTADO DEL MANEJADOR

Se puede llamar a nbd_opt_starttls cuando el manejador está en el siguiente estado:

┌─────────────────────────────────────┬─────────────────────────┐
│ Manejador creado, antes de conectar   │ ❌ error                │
│ Conectando                          │ ❌ error                │
│ Conectando y apretón de manos (opt_mode) │ ✅ permitido              │
│ Conectado al servidor             │ ❌ error                │
│ Conexión cerrada                   │ ❌ error                │
│ Manejador muerto                    │ ❌ error                │
└─────────────────────────────────────┴─────────────────────────┘

VERSIÓN

Esta función apareció por primera vez en libnbd 1.16.

Si necesita probar si esta función está disponible en tiempo de compilación, compruebe si el siguiente macro está definido:

#define LIBNBD_HAVE_NBD_OPT_STARTTLS 1
