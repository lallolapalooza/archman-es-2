nbd_get_version(3) LIBNBD nbd_get_version(3)

NOMBRE

nbd_get_version - devuelve la versión de la biblioteca

SINOPSIS

#include <libnbd.h>
const char * nbd_get_version (
               struct nbd_handle *h
             );

DESCRIPCIÓN

Devuelve la versión de libnbd. Esto se devuelve como una cadena en el formato "mayor.menor.lanzamiento" donde cada uno de mayor, menor y lanzamiento es un entero pequeño positivo. Por ejemplo:

    menor
      ↓
   "1.0.3"
    ↑   ↑
mayor   lanzamiento
mayor = 0
El número mayor fue 0 para las primeras versiones experimentales de libnbd, donde todavía teníamos una API inestable.
mayor = 1
El número mayor es 1 para las versiones de libnbd con una API y ABI estables a largo plazo. No se prevé que el número mayor sea distinto de 1.
menor = 0, 2, ... (par)
El número menor es par para los lanzamientos estables.
menor = 1, 3, ... (impar)
El número menor es impar para las versiones de desarrollo. Tenga en cuenta que las nuevas APIs añadidas en una versión de desarrollo siguen siendo experimentales y sujetas a cambios en esa rama hasta que aparezcan en un lanzamiento estable.
lanzamiento
El número de lanzamiento se incrementa para cada lanzamiento en una rama particular.

VALOR DE RETORNO

Esta llamada devuelve una cadena asignada estáticamente, válida durante la vida del proceso o hasta que libnbd sea descargada por dlclose(3). No intente liberar la cadena.

ERRORES

Esta función no falla.

Los siguientes parámetros no deben ser NULL: "h". Para más información vea "Parámetros no nulos" en libnbd(3).

VERSIÓN

Esta función apareció por primera vez en libnbd 1.0.

Si necesita probar si esta función está disponible en tiempo de compilación, compruebe si está definido el siguiente macro:

#define LIBNBD_HAVE_NBD_GET_VERSION 1

VER TAMBIÉN

nbd_create(3), nbd_get_package_name(3), libnbd(3).
