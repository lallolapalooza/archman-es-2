nbd_set_private_data(3)

Paquete: libnbd

Licencias: LGPL-2.1-or-later

nbd_set_private_data(3) LIBNBD nbd_set_private_data(3)

NOMBRE

nbd_set_private_data - establece los datos privados por manejador

SINOPSIS

#include <libnbd.h>
uintptr_t nbd_set_private_data (
            struct nbd_handle *h, uintptr_t private_data
          );

DESCRIPCIÓN

Los manejadores contienen un campo de datos privados para que las aplicaciones lo usen para cualquier propósito. Esta función establece el valor de este campo y devuelve el valor anterior (o 0 si no se había establecido previamente).

Al llamar a libnbd desde C, el tipo de este campo es "uintptr_t" para que pueda usarse para almacenar un entero sin signo o un puntero.

En bindings que no son de C, se puede usar para almacenar un entero sin signo.

Libnbd no utiliza ni interpreta el valor en absoluto (excepto para devolverlo cuando llamas a nbd_get_private_data(3)). En particular, si el valor es un puntero, no se libera cuando se cierra el manejador.

VALOR DE RETORNO

Esta llamada devuelve un "uintptr_t".

ERRORES

Esta función no falla.

Los siguientes parámetros no deben ser NULL: "h". Para más información, consulta "Parámetros no nulos" en libnbd(3).

VERSIÓN

Esta función apareció por primera vez en libnbd 1.8.

Si necesitas comprobar si esta función está disponible en tiempo de compilación, verifica si el siguiente macro está definido:

#define LIBNBD_HAVE_NBD_SET_PRIVATE_DATA 1

VER TAMBIÉN

nbd_create(3), nbd_get_private_data(3), libnbd(3).
