nbd_trim(3) LIBNBD nbd_trim(3)

NOMBRE

nbd_trim - enviar comando trim al servidor NBD

SINOPSIS

#include <libnbd.h>
int nbd_trim (
      struct nbd_handle *h, uint64_t count,
      uint64_t offset, uint32_t flags
    );

DESCRIPCIÓN

Emite un comando trim al servidor NBD, que si es soportado por el servidor causa que se cree un hueco en el almacenamiento de respaldo comenzando en "offset" y terminando en "offset" + "count" - 1. La llamada retorna cuando el comando ha sido reconocido por el servidor, o si hay un error. Nota que esto generalmente retornará un error si nbd_can_trim(3) es falso o nbd_is_read_only(3) es verdadero.

Nota que no todos los servidores pueden soportar un "count" de 4GiB o mayor; nbd_get_extended_headers_negotiated(3) indica qué servidores interpretarán una solicitud mayor a 32 bits. El protocolo NBD aún no tiene una forma para que un cliente aprenda si el servidor aplicará un tamaño máximo de trim aún menor, aunque una extensión futura podría agregar una restricción visible en nbd_get_block_size(3).

El parámetro "flags" puede ser 0 para no usar flags, o puede contener "LIBNBD_CMD_FLAG_FUA" significando que el servidor no debe retornar hasta que los datos hayan sido confirmados en almacenamiento permanente (si eso es soportado - algunos servidores no pueden hacer esto, ver nbd_can_fua(3)).

Por defecto, libnbd rechazará intentos de usar esta función con parámetros que probablemente resulten en fallo del servidor, como solicitar un flag de comando desconocido. La función nbd_set_strict_mode(3) puede ser usada para alterar qué escenarios deben esperar una respuesta del servidor en lugar de fallar rápidamente.

VALOR DE RETORNO

Si la llamada es exitosa, la función retorna 0.

ERRORES

En caso de error, se retorna -1.

Consulte "MANEJO DE ERRORES" en libnbd(3) para obtener más detalles sobre el error.

Los siguientes parámetros no deben ser NULL: "h". Para más información, consulte "Parámetros no-NULL" en libnbd(3).

ESTADO DEL MANEJADOR

nbd_trim puede ser llamado cuando el manejador está en el siguiente estado:

┌─────────────────────────────────────┬─────────────────────────┐
│ Manejador creado, antes de conectar │ ❌ error                │
│ Conectando                          │ ❌ error                │
│ Conectando y handshake (opt_mode) │ ❌ error                │
│ Conectado al servidor             │ ✅ permitido            │
│ Conexión cerrada                   │ ❌ error                │
│ Manejador muerto                    │ ❌ error                │
└───────────────────────────────────────┴─────────────────────────┘

VERSIÓN

Esta función apareció por primera vez en libnbd 1.0.

Si necesita probar si esta función está disponible en tiempo de compilación, verifique si el siguiente macro está definido:

#define LIBNBD_HAVE_NBD_TRIM 1
