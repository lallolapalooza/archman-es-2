nbd_set_uri_allow_transports(3)

Paquete: libnbd

Licencias: LGPL-2.1-or-later

nbd_set_uri_allow_transports(3) LIBNBD nbd_set_uri_allow_transports(3)

NOMBRE

nbd_set_uri_allow_transports - establece los transportes permitidos en las URIs NBD

SINOPSIS

#include <libnbd.h>
int nbd_set_uri_allow_transports (
      struct nbd_handle *h, uint32_t mask
    );

DESCRIPCIÓN

Establece qué transportes están permitidos para aparecer en las URIs NBD. El valor predeterminado es permitir cualquier transporte.

El parámetro "mask" puede contener cualquiera de las siguientes banderas ORed juntas:

"LIBNBD_ALLOW_TRANSPORT_TCP" = 0x1
"LIBNBD_ALLOW_TRANSPORT_UNIX" = 0x2
"LIBNBD_ALLOW_TRANSPORT_VSOCK" = 0x4
"LIBNBD_ALLOW_TRANSPORT_SSH" = 0x8

Para mayor comodidad, la constante "LIBNBD_ALLOW_TRANSPORT_MASK" está disponible para describir todos los transportes reconocidos por esta compilación de libnbd. Una versión futura de la biblioteca puede añadir nuevas banderas.

VALOR DEVUELTO

Si la llamada es exitosa, la función devuelve 0.

ERRORES

En caso de error, se devuelve -1.

Consulte "MANEJO DE ERRORES" en libnbd(3) para obtener más detalles sobre el error.

Los siguientes parámetros no deben ser NULL: "h". Para más información, consulte "Parámetros no nulos" en libnbd(3).

ESTADO DEL MANEJADOR

nbd_set_uri_allow_transports puede ser llamada cuando el manejador se encuentra en el siguiente estado:

┌─────────────────────────────────────┬─────────────────────────┐
│ Manejador creado, antes de conectar   │ ✅ permitido              │
│ Conectando                          │ ❌ error                │
│ Conectando y handshake (opt_mode) │ ❌ error                │
│ Conectado al servidor             │ ❌ error                │
│ Conexión cerrada                 │ ❌ error                │
│ Manejador muerto                   │ ❌ error                │
└─────────────────────────────────────┴─────────────────────────┘

VERSIÓN

Esta función apareció por primera vez en libnbd 1.2.

Si necesita probar si esta función está disponible en tiempo de compilación, compruebe si el siguiente macro está definido:

#define LIBNBD_HAVE_NBD_SET_URI_ALLOW_TRANSPORTS 1

VER TAMBIÉN

nbd_connect_uri(3), nbd_create(3), nbd_set_uri_allow_tls(3), libnbd(3).
