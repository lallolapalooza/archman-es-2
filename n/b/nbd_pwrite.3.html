nbd_pwrite(3)

Paquete: libnbd

Licencias: LGPL-2.1-or-later

nbd_pwrite(3) LIBNBD nbd_pwrite(3)

NOMBRE

nbd_pwrite - escribir en el servidor NBD

SINOPSIS

#include <libnbd.h>
int nbd_pwrite (
      struct nbd_handle *h, const void *buf, size_t count,
      uint64_t offset, uint32_t flags
    );

DESCRIPCIÓN

Emite un comando de escritura al servidor NBD, escribiendo los datos en "buf" al rango que comienza en "offset" y termina en "offset" + "count" - 1. NBD solo puede escribir todo o nada usando esta llamada. La llamada retorna cuando el comando ha sido confirmado por el servidor, o hay un error. Tenga en cuenta que esto generalmente retornará un error si nbd_is_read_only(3) es verdadero.

Tenga en cuenta que libnbd impone por defecto un búfer de escritura máximo igual al menor entre 64MiB o cualquier tamaño de carga útil máximo anunciado por el servidor; los intentos de exceder esto generalmente resultarán en un error "ERANGE" del lado del cliente, en lugar de una desconexión del lado del servidor. El límite real se puede obtener con nbd_get_block_size(3).

El parámetro "flags" puede ser 0 para no usar flags, o puede contener "LIBNBD_CMD_FLAG_FUA" lo que significa que el servidor no debe retornar hasta que los datos hayan sido confirmados en el almacenamiento permanente (si eso es compatible - algunos servidores no pueden hacer esto, ver nbd_can_fua(3)). Para conveniencia, a menos que nbd_set_strict_flags(3) se haya utilizado para deshabilitar "LIBNBD_STRICT_AUTO_FLAG", libnbd ignora la presencia o ausencia del flag "LIBNBD_CMD_FLAG_PAYLOAD_LEN" en "flags", mientras utiliza correctamente el flag en la comunicación según si se negociaron cabeceras extendidas.

Por defecto, libnbd rechazará intentos de usar esta función con parámetros que probablemente resulten en un fallo del servidor, como solicitar un flag de comando desconocido. La función nbd_set_strict_mode(3) puede ser utilizada para alterar qué escenarios deben esperar una respuesta del servidor en lugar de fallar rápidamente.

VALOR DE RETORNO

Si la llamada es exitosa, la función retorna 0.

ERRORES

En caso de error, se retorna -1.

Consulte "MANEJO DE ERRORES" en libnbd(3) para saber cómo obtener más detalles del error.

Los siguientes parámetros no deben ser NULL: "h", "buf". Para más información consulte "Parámetros no nulos" en libnbd(3).

ESTADO DEL MANEJADOR

nbd_pwrite puede ser llamada cuando el manejador se encuentra en el siguiente estado:

┌─────────────────────────────────────┬─────────────────────────┐
│ Manejador creado, antes de conectar │ ❌ error │
│ Conectando │ ❌ error │
│ Conectando y estableciendo enlace (opt_mode) │ ❌ error │
│ Conectado al servidor │ ✅ permitido │
│ Conexión cerrada │ ❌ error │
│ Manejador muerto │ ❌ error │
└─────────────────────────────────────┴─────────────────────────┘

VERSIÓN

Esta función apareció por primera vez en libnbd 1.0.

Si necesita probar si esta función está disponible en tiempo de compilación, compruebe si está definido el siguiente macro:

#define LIBNBD_HAVE_NBD_PWRITE 1

EJEMPLO

Este ejemplo también está disponible como examples/reads-and-writes.c en el código fuente de libnbd.

/* Este ejemplo muestra cómo realizar lecturas y escrituras síncronas
 * aleatoriamente sobre el primer megabyte de un servidor
 * NBD. Tenga en cuenta que esto destruirá cualquier contenido existente
 * en el servidor NBD.
 *
 * Para probarlo con nbdkit y un disco en memoria:
 *
 * nbdkit -U - memory 1M \
 *     --run './simple-reads-and-writes $unixsocket'
 */
#include <stdio.h>
#include <stdlib.h>
#include <stdint.h>
#include <inttypes.h>
#include <assert.h>
#include <time.h>
#include <libnbd.h>
int
main (int argc, char *argv[])
{
  struct nbd_handle *nbd;
  char buf[512];
  size_t i;
  int64_t exportsize;
  uint64_t offset;
  srand (time (NULL));
  if (argc != 2) {
    fprintf (stderr, "%s socket\n", argv[0]);
    exit (EXIT_FAILURE);
  }
  /* Crear el manejador de libnbd. */
  nbd = nbd_create ();
  if (nbd == NULL) {
    fprintf (stderr, "%s\n", nbd_get_error ());
    exit (EXIT_FAILURE);
  }
  /* Conectarse al servidor NBD a través de un
   * socket de dominio Unix.
   */
  if (nbd_connect_unix (nbd, argv[1]) == -1) {
    fprintf (stderr, "%s\n", nbd_get_error ());
    exit (EXIT_FAILURE);
  }
  /* Obtener el tamaño del disco y comprobar
   * que es lo suficientemente grande.
   */
  exportsize = nbd_get_size (nbd);
  if (exportsize == -1) {
    fprintf (stderr, "%s\n", nbd_get_error ());
    exit (EXIT_FAILURE);
  }
  assert (exportsize >= sizeof buf);
  /* Comprobar que el servidor es escribible. */
  if (nbd_is_read_only (nbd) == 1) {
    fprintf (stderr, "%s: "
             "error: esta exportación NBD es de solo lectura\n",
             argv[0]);
    exit (EXIT_FAILURE);
  }
  for (i = 0; i < sizeof buf; ++i)
    buf[i] = rand ();
  /* 1000 escrituras. */
  for (i = 0; i < 1000; ++i) {
    offset = rand () % (exportsize - sizeof buf);
    if (nbd_pwrite (nbd, buf, sizeof buf,
                    offset, 0) == -1) {
      fprintf (stderr, "%s\n", nbd_get_error ());
      exit (EXIT_FAILURE);
    }
  }
  /* 1000 lecturas y escrituras. */
  for (i = 0; i < 1000; ++i) {
    offset = rand () % (exportsize - sizeof buf);
    if (nbd_pread (nbd, buf, sizeof buf,
                   offset, 0) == -1) {
      fprintf (stderr, "%s\n", nbd_get_error ());
      exit (EXIT_FAILURE);
    }
    offset = rand () % (exportsize - sizeof buf);
    if (nbd_pwrite (nbd, buf, sizeof buf,
                    offset, 0) == -1) {
      fprintf (stderr, "%s\n", nbd_get_error ());
      exit (EXIT_FAILURE);
    }
  }
  /* Envía un cierre ordenado al servidor. */
  if (nbd_shutdown (nbd, 0) == -1) {
    fprintf (stderr, "%s\n", nbd_get_error ());
    exit (EXIT_FAILURE);
  }
  nbd_close (nbd);
  exit (EXIT_SUCCESS);
}

libnbd Manual nbd_pwrite(3)

NAME

nbd_pwrite — write data to an NBD export at a specific offset

SYNOPSIS

#include <libnbd.h>
int nbd_pwrite(NBD_CONTEXT *ctx, const char *export_name,
               uint64_t offset, const void *buf, size_t count,
               int flags, NBD_ASYNC_HANDLE **handle);

DESCRIPTION

The nbd_pwrite function is used to write data from the buffer buf of size count to the NBD export named export_name, starting at the specified offset.

If export_name is NULL, then the default export is used (see nbd_connect_to_server(3)).

The flags argument can be 0 or any of the following values, OR-ed together:

NBD_RETRY_CONNECTION
If the connection is lost, try to reconnect automatically. This flag should only be used if the server supports reconnecting (e.g. by using nbd_server_set_export_options in the server).
NBD_RETRY_CONNECT_DELAY
Wait before retrying the connection. This flag should only be used in conjunction with NBD_RETRY_CONNECTION.

If handle is not NULL, the call is asynchronous. The operation is started, and nbd_pwrite returns immediately. The handle *handle is populated with an opaque value representing the ongoing operation. You must later call nbd_async_complete to wait for the operation to finish and get its return value. This handle must be freed with nbd_async_destroy when no longer needed.

If handle is NULL, the call is synchronous. The function blocks until the operation is complete and returns the result.

The nbd_pwrite function only supports block-aligned writes and reads.

RETURN VALUE

On success, nbd_pwrite returns 0. On failure, it returns a negative error code.

ERRORS

See nbd_error_code(3) for a description of the error codes returned by this function.

HANDLE STATE

If the call is asynchronous, the handle passed to nbd_pwrite must not be NULL. It is an opaque pointer to an NBD_ASYNC_HANDLE structure. When the operation completes, nbd_async_complete will return 0 on success, or a negative error code on failure.

If the call is synchronous, the return value of nbd_pwrite will be 0 on success, or a negative error code on failure.

VERSION

This function is available in libnbd version 1.16 and later.

EXAMPLE

A synchronous example:

NBD_CONTEXT *ctx;
char data[] = "hello world";
int r;

ctx = nbd_connect_simple("127.0.0.1", NULL);
if (ctx == NULL) {
    fprintf(stderr, "failed to create context\n");
    exit(1);
}

r = nbd_pwrite(ctx, NULL, 1024, data, strlen(data), 0, NULL);
if (r < 0) {
    fprintf(stderr, "nbd_pwrite failed: %s\n", nbd_strerror(r));
    nbd_disconnect(ctx);
    exit(1);
}

nbd_disconnect(ctx);
exit(0);

An asynchronous example:

NBD_CONTEXT *ctx;
NBD_ASYNC_HANDLE *handle;
char data[] = "hello world";
int r;

ctx = nbd_connect_simple("127.0.0.1", NULL);
if (ctx == NULL) {
    fprintf(stderr, "failed to create context\n");
    exit(1);
}

r = nbd_pwrite(ctx, NULL, 1024, data, strlen(data), 0, &handle);
if (r < 0) {
    fprintf(stderr, "nbd_pwrite failed: %s\n", nbd_strerror(r));
    nbd_disconnect(ctx);
    exit(1);
}

// Do other work here ...

r = nbd_async_complete(handle);
if (r < 0) {
    fprintf(stderr, "nbd_pwrite operation failed: %s\n", nbd_strerror(r));
}

nbd_async_destroy(handle);
nbd_disconnect(ctx);
exit(0);
