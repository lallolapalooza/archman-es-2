nbd_aio_in_flight(3)

Paquete: libnbd

Licencias: LGPL-2.1-or-later

nbd_aio_in_flight(3) LIBNBD nbd_aio_in_flight(3)

NOMBRE

nbd_aio_in_flight - comprobar cuántos comandos aio siguen en vuelo

SINOPSIS

#include <libnbd.h>
int nbd_aio_in_flight (
      struct nbd_handle *h
    );

DESCRIPCIÓN

Devuelve el número de comandos aio en vuelo que todavía están esperando una respuesta del servidor antes de que puedan ser retirados. Si esto devuelve un valor distinto de cero al solicitar una desconexión del servidor (ver nbd_aio_disconnect(3) y nbd_shutdown(3)), libnbd no intenta esperar a que esos comandos se completen con gracia; si el servidor abandona comandos mientras se cierra, nbd_aio_command_completed(3) informará de esos comandos como fallidos con un estado de "ENOTCONN".

VALOR DEVUELTO

Esta llamada devuelve un entero ≥ 0.

ERRORES

En caso de error, se devuelve -1.

Consulte "MANEJO DE ERRORES" en libnbd(3) para saber cómo obtener más detalles del error.

Los siguientes parámetros no deben ser NULL: "h". Para más información, consulte "Parámetros no nulos" en libnbd(3).

ESTADO DEL MANGO

nbd_aio_in_flight se puede llamar cuando el mango está en los siguientes estados:

┌─────────────────────────────────────┬─────────────────────────┐
│ Mango creado, antes de conectar   │ ❌ error                │
│ Conectando                          │ ❌ error                │
│ Conectando & handshake (opt_mode) │ ❌ error                │
│ Conectado al servidor             │ ✅ permitido              │
│ Conexión cerrada                   │ ✅ permitido              │
│ Mango muerto                         │ ✅ permitido              │
└────────────────────────────────────────┴─────────────────────────┘

VERSIÓN

Esta función apareció por primera vez en libnbd 1.0.

Si necesita probar si esta función está disponible en tiempo de compilación, compruebe si el siguiente macro está definido:

#define LIBNBD_HAVE_NBD_AIO_IN_FLIGHT 1

EJEMPLO

Este ejemplo también está disponible como examples/aio-connect-read.c en el código fuente de libnbd.

/* Este ejemplo muestra cómo usar la API de bajo nivel AIO (asíncrona)
 * para conectarse a un servidor y leer el disco.
 *
 * Aquí hay algunas formas de probar este ejemplo:
 *
 * nbdkit -U - linuxdisk . \
 *   --run './aio-connect-read $unixsocket'
 *
 * nbdkit -U - floppy . \
 *   --run './aio-connect-read $unixsocket'
 *
 * nbdkit -U - pattern size=1M \
 *   --run './aio-connect-read $unixsocket'
 */
#include <stdio.h>
#include <stdlib.h>
#include <stdint.h>
#include <inttypes.h>
#include <errno.h>
#include <assert.h>
#include <libnbd.h>
#define NR_SECTORS 32
#define SECTOR_SIZE 512
struct data {
  uint64_t offset;
  char sector[SECTOR_SIZE];
};
static int
hexdump (void *user_data, int *error)
{
  struct data *data = user_data;
  FILE *pp;
  if (*error) {
    errno = *error;
    perror ("falló la lectura");
    exit (EXIT_FAILURE);
  }
  printf ("sector en el offset 0x%" PRIx64 ":\n",
          data->offset);
  pp = popen ("hexdump -C", "w");
  if (pp == NULL) {
    perror ("popen: hexdump");
    exit (EXIT_FAILURE);
  }
  fwrite (data->sector, SECTOR_SIZE, 1, pp);
  pclose (pp);
  printf ("\n");
  /* Devolver 1 de la devolución de llamada retira automáticamente
   * el comando.
   */
  return 1;
}
static struct data data[NR_SECTORS];
int
main (int argc, char *argv[])
{
  struct nbd_handle *nbd;
  size_t i;
  if (argc != 2) {
    fprintf (stderr, "%s socket\n", argv[0]);
    exit (EXIT_FAILURE);
  }
  /* Crear el mango libnbd. */
  nbd = nbd_create ();
  if (nbd == NULL) {
    fprintf (stderr, "%s\n", nbd_get_error ());
    exit (EXIT_FAILURE);
  }
  /* Conectarse al servidor NBD a través de un socket de dominio Unix.
   * Esto solo inicia la conexión.
   */
  if (nbd_aio_connect_unix (nbd, argv[1]) == -1) {
    fprintf (stderr, "%s\n", nbd_get_error ());
    exit (EXIT_FAILURE);
  }
  /* Esperar a que la conexión se complete. El uso de
   * nbd_poll aquí es solo como ejemplo. También podrías
   * integrarlo con poll(2), glib o cualquier otro bucle
   * principal. Lee libnbd(3) y el archivo fuente lib/poll.c.
   */
  while (!nbd_aio_is_ready (nbd)) {
    if (nbd_poll (nbd, -1) == -1) {
      fprintf (stderr, "%s\n", nbd_get_error ());
      exit (EXIT_FAILURE);
    }
  }
  assert (nbd_get_size (nbd) >= NR_SECTORS * SECTOR_SIZE);
  /* Emitir comandos de lectura para los NR sectores iniciales. */
  for (i = 0; i < NR_SECTORS; ++i) {
    data[i].offset = i * SECTOR_SIZE;
    /* La devolución de llamada (hexdump) se llama cuando el comando
     * se completa. El búfer debe seguir existiendo mientras
     * el comando se ejecuta.
     */
    if (nbd_aio_pread (nbd, data[i].sector, SECTOR_SIZE,
                       data[i].offset,
                       (nbd_completion_callback) {
                         .callback = hexdump,
                         .user_data = &data[i],
                       }, 0) == -1) {
      fprintf (stderr, "%s\n", nbd_get_error ());
      exit (EXIT_FAILURE);
    }
  }
  /* Ejecutar el bucle principal hasta que todos los comandos se
   * hayan completado y retirado. Nuevamente, el uso de nbd_poll
   * aquí es solo como ejemplo.
   */
  while (nbd_aio_in_flight (nbd) > 0) {
    if (nbd_poll (nbd, -1) == -1) {
      fprintf (stderr, "%s\n", nbd_get_error ());
      exit (EXIT_FAILURE);
    }
  }
  /* Cerrar el mango libnbd. */
  nbd_close (nbd);
  exit (EXIT_SUCCESS);
}

nbd_aio_in_flight

NOMBRE

nbd_aio_in_flight - comprobar el número de operaciones asíncronas pendientes

SINOPSIS

#include <libnbd.h>

unsigned int nbd_aio_in_flight (NBD_CONTEXT *ctx);

DESCRIPCIÓN

El manejador ctx no debe ser nulo.

Esta función devuelve el número de operaciones asíncronas pendientes asociadas con el contexto ctx. Una operación asíncrona se considera pendiente desde el momento en que se llama a una función de operación asíncrona (como nbd_aio_read o nbd_aio_connect) hasta el momento en que se llama a su función de devolución de llamada asociada.

VALOR DE RETORNO

Devuelve el número de operaciones asíncronas pendientes.

ERRORES

No hay errores específicos.

ESTADO DEL MANEJADOR

No hay requisitos específicos sobre el estado del manejador, aparte de que no debe ser nulo.

VERSIÓN

Esta función está disponible en todas las versiones de libnbd.

EJEMPLO

unsigned int pending;

// ... iniciar un contexto NBD y una operación asíncrona ...

pending = nbd_aio_in_flight (ctx);
if (pending > 0) {
    printf ("%u operaciones asíncronas pendientes\n", pending);
}
