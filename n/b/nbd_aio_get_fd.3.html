NOMBRE

nbd_aio_get_fd - devuelve el descriptor de archivo asociado a esta conexión

SINOPSIS

#include <libnbd.h>
int nbd_aio_get_fd (
      struct nbd_handle *h
    );

DESCRIPCIÓN

Devuelve el descriptor de archivo subyacente asociado a esta conexión. Puedes usarlo para comprobar si el descriptor de archivo está listo para leer o escribir y llamar a nbd_aio_notify_read(3) o nbd_aio_notify_write(3). Ver también nbd_aio_get_direction(3). No hagas nada más con el descriptor de archivo.

VALOR DE RETORNO

Esta llamada devuelve un descriptor de archivo.

ERRORES

En caso de error, se devuelve -1.

Consulte "MANEJO DE ERRORES" en libnbd(3) para obtener más detalles sobre el error.

Los siguientes parámetros no deben ser NULL: "h". Para más información, consulte "Parámetros no NULL" en libnbd(3).

VERSIÓN

Esta función apareció por primera vez en libnbd 1.0.

Si necesitas comprobar si esta función está disponible en tiempo de compilación, comprueba si el siguiente macro está definido:

#define LIBNBD_HAVE_NBD_AIO_GET_FD 1

VER TAMBIÉN

nbd_aio_get_direction(3), nbd_aio_notify_read(3), nbd_aio_notify_write(3), nbd_create(3), libnbd(3).
