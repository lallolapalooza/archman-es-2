nbd_set_tls_username(3)

Paquete: libnbd

Licencias: LGPL-2.1-or-later

nbd_set_tls_username(3) LIBNBD nbd_set_tls_username(3)

NOMBRE

nbd_set_tls_username - establecer el nombre de usuario TLS

SINOPSIS

#include <libnbd.h>
int nbd_set_tls_username (
      struct nbd_handle *h, const char *username
    );

DESCRIPCIÓN

Establece el nombre de usuario del cliente TLS. Esto se usa si la autenticación con PSK sobre TLS está habilitada. Si no se establece, se utiliza el nombre de usuario local.

Esta función se puede llamar independientemente de si TLS es compatible, pero no tendrá ningún efecto a menos que también se utilice nbd_set_tls(3) para solicitar o requerir TLS.

VALOR DE RETORNO

Si la llamada es exitosa, la función devuelve 0.

ERRORES

En caso de error, se devuelve -1.

Consulte "MANEJO DE ERRORES" en libnbd(3) para obtener más detalles sobre cómo obtener más información sobre el error.

Los siguientes parámetros no deben ser NULL: "h", "username". Para más información, consulte "Parámetros no NULL" en libnbd(3).

ESTADO DEL MANEJADOR

nbd_set_tls_username se puede llamar cuando el manejador está en el siguiente estado:

┌─────────────────────────────────────┬─────────────────────────┐
│ Manejador creado, antes de conectar │ ✅ permitido             │
│ Conectando                          │ ❌ error               │
│ Conectando y haciendo handshake (opt_mode) │ ❌ error               │
│ Conectado al servidor             │ ❌ error               │
│ Conexión cerrada                 │ ❌ error               │
│ Manejador inactivo                 │ ❌ error               │
└─────────────────────────────────────┴─────────────────────────┘

VERSIÓN

Esta función apareció por primera vez en libnbd 1.0.

Si necesita comprobar si esta función está disponible en tiempo de compilación, compruebe si el siguiente macro está definido:

#define LIBNBD_HAVE_NBD_SET_TLS_USERNAME 1

EJEMPLO

Este ejemplo también está disponible como examples/encryption.c en el código fuente de libnbd.

/* Un ejemplo que muestra cómo conectarse a un servidor que está
 * utilizando cifrado TLS.
 *
 * Esto requiere nbdkit y psktool de gnutls.
 *
 * Tanto libnbd como nbdkit soportan TLS-PSK, que es una
 * forma de cifrado más fácil de implementar. (Por supuesto,
 * el cifrado basado en certificados también es compatible, pero
 * es más difícil hacer un ejemplo autocontenido).
 */
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <unistd.h>
#include <libnbd.h>
#define TMPDIR "/tmp/XXXXXX"
#define KEYS "keys.psk"
#define USERNAME "alice"
static char dir[] = TMPDIR;
static char keys[] = TMPDIR "/" KEYS;
static char cmd[] =
  "psktool -u " USERNAME " -p " TMPDIR "/" KEYS;
/* Eliminar el archivo de claves temporal cuando el programa
 * salga.
 */
static void
cleanup_keys (void)
{
  unlink (keys);
  rmdir (dir);
}
/* Crear el archivo de claves temporal para compartir con el
 * servidor.
 */
static void
create_keys (void)
{
  size_t i;
  if (mkdtemp (dir) == NULL) {
    perror ("mkdtemp");
    exit (EXIT_FAILURE);
  }
  i = strlen (cmd) - strlen (TMPDIR) - strlen (KEYS) - 1;
  memcpy (&cmd[i], dir, strlen (TMPDIR));
  memcpy (keys, dir, strlen (TMPDIR));
  if (system (cmd) != 0) {
    fprintf (stderr, "psktool command failed\n");
    exit (EXIT_FAILURE);
  }
  atexit (cleanup_keys);
}
int
main (int argc, char *argv[])
{
  struct nbd_handle *nbd;
  char buf[512];
  create_keys ();
  /* Crear el manejador de libnbd. */
  nbd = nbd_create ();
  if (nbd == NULL) {
    fprintf (stderr, "%s\n", nbd_get_error ());
    exit (EXIT_FAILURE);
  }
  /* Habilitar TLS en el cliente. */
  if (nbd_set_tls (nbd, LIBNBD_TLS_REQUIRE) == -1) {
    fprintf (stderr, "%s\n", nbd_get_error ());
    exit (EXIT_FAILURE);
  }
  /* Habilitar TLS-PSK y pasar el nombre del archivo de claves. */
  if (nbd_set_tls_psk_file (nbd, keys) == -1) {
    fprintf (stderr, "%s\n", nbd_get_error ());
    exit (EXIT_FAILURE);
  }
  /* Establecer el nombre de usuario local para la autenticación. */
  if (nbd_set_tls_username (nbd, USERNAME) == -1) {
    fprintf (stderr, "%s\n", nbd_get_error ());
    exit (EXIT_FAILURE);
  }
  /* Ejecutar nbdkit como un subproceso, habilitando y requiriendo
   * cifrado TLS-PSK.
   */
  char *args[] = {
    "nbdkit", "-s", "--exit-with-parent",
    "--tls", "require", "--tls-psk", keys,
    "pattern", "size=1M", NULL
  };
  if (nbd_connect_command (nbd, args) == -1) {
    fprintf (stderr, "%s\n", nbd_get_error ());
    exit (EXIT_FAILURE);
  }
  /* Leer el primer sector. */
  if (nbd_pread (nbd, buf, sizeof buf, 0, 0) == -1) {
    fprintf (stderr, "%s\n", nbd_get_error ());
    exit (EXIT_FAILURE);
  }
  /* Las conexiones TLS deben cerrarse. */
  if (nbd_shutdown (nbd, 0) == -1) {
    fprintf (stderr, "%s\n", nbd_get_error ());
    exit (EXIT_FAILURE);
  }
  /* Cerrar el manejador de libnbd. */
  nbd_close (nbd);
  exit (EXIT_SUCCESS);
}

NAME

nbd_set_tls_username - Set the TLS username for the connection

SYNOPSIS

#include <libnbd.h>

int nbd_set_tls_username(NbdHandle *handle, const char *username);

DESCRIPTION

Set the TLS username for the connection specified by handle. This function is used to authenticate with the TLS server. The username must be a null-terminated string. If username is NULL, any previously set username is cleared.

RETURN VALUE

On success, 0 is returned. On error, -1 is returned and errno is set appropriately.

ERRORS

errno
Set to EINVAL if handle is NULL or if username is not a null-terminated string.
errno
Set to EFAULT if username is not within the accessible address space.

HANDLE STATE

The handle must be in the NBD_STATE_INIT state. Calling this function in any other state will result in an error.

VERSION

This function was introduced in version 1.16 of libnbd.

EXAMPLE

Setting the TLS username for a connection: 


    NbdHandle *handle = nbd_create();
    if (!handle) {
        // Handle error
    }

    if (nbd_set_tls_username(handle, "my_username") == -1) {
        // Handle error
    }

    // ... continue with connection setup ...

    nbd_shutdown(handle);
    nbd_destroy(handle);
