nbd_pread(3)

Paquete: libnbd

Licencias: LGPL-2.1-or-later

nbd_pread(3) LIBNBD nbd_pread(3)

NOMBRE

nbd_pread - leer desde el servidor NBD

SINOPSIS

#include <libnbd.h>
int nbd_pread (
      struct nbd_handle *h, void *buf, size_t count,
      uint64_t offset, uint32_t flags
    );

DESCRIPCIÓN

Emite un comando de lectura al servidor NBD para el rango que comienza en "offset" y termina en "offset" + "count" - 1. NBD solo puede leer todo o nada con esta llamada. La llamada retorna cuando los datos se han leído completamente en "buf" o si hay un error. Ver también nbd_pread_structured(3), si se requiere una visibilidad más fina de las respuestas del servidor, o si se desea usar "LIBNBD_CMD_FLAG_DF".

Tenga en cuenta que libnbd actualmente impone un búfer de lectura máximo de 64MiB, incluso si el servidor permitiera un búfer más grande en una sola transacción; los intentos de exceder esto resultarán en un error "ERANGE". El servidor puede imponer un límite menor, que se puede conocer con nbd_get_block_size(3).

El parámetro "flags" debe ser 0 por ahora (existe para futuras extensiones del protocolo NBD).

Tenga en cuenta que si este comando falla, y nbd_get_pread_initialize(3) retorna verdadero, entonces libnbd sanitizó "buf", pero no se especifica si el contenido de "buf" se leerá como cero o como resultados parciales del servidor. Si nbd_get_pread_initialize(3) retorna falso, entonces libnbd no sanitizó "buf", y el contenido no está definido en caso de fallo.

Por defecto, libnbd rechazará los intentos de usar esta función con parámetros que probablemente resulten en un fallo del servidor, como solicitar una bandera de comando desconocida. La función nbd_set_strict_mode(3) puede usarse para alterar qué escenarios deben esperar una respuesta del servidor en lugar de fallar rápidamente.

VALOR DE RETORNO

Si la llamada es exitosa, la función retorna 0.

ERRORES

En caso de error, se retorna -1.

Consulte "MANEJO DE ERRORES" en libnbd(3) para obtener más detalles sobre el error.

Los siguientes parámetros no deben ser NULL: "h", "buf". Para más información, ver "Parámetros no nulos" en libnbd(3).

ESTADO DEL MANEJADOR

nbd_pread puede ser llamado cuando el manejador está en el siguiente estado:

┌─────────────────────────────────────┬─────────────────────────┐
│ Manejador creado, antes de conectar │ ❌ error                │
│ Conectando                          │ ❌ error                │
│ Conectando y handshake (opt_mode) │ ❌ error                │
│ Conectado al servidor             │ ✅ permitido              │
│ Conexión cerrada                 │ ❌ error                │
│ Manejador muerto                  │ ❌ error                │
└─────────────────────────────────────┴─────────────────────────┘

VERSIÓN

Esta función apareció por primera vez en libnbd 1.0.

Si necesita probar si esta función está disponible en tiempo de compilación, verifique si está definida la siguiente macro:

#define LIBNBD_HAVE_NBD_PREAD 1

EJEMPLO

Este ejemplo también está disponible como examples/fetch-first-sector.c en el código fuente de libnbd.

/* Este ejemplo muestra cómo conectarse a un servidor NBD
 * y obtener e imprimir el primer sector (generalmente el
 * sector de arranque o la tabla de particiones o el superbloque
 * del sistema de archivos).
 *
 * Puedes probarlo con nbdkit de esta manera:
 *
 * nbdkit -U - floppy . \
 *   --run './fetch-first-sector $unixsocket'
 *
 * El plugin floppy de nbdkit crea un disco MBR, por lo que
 * el primer sector es la tabla de particiones.
 */
#include <stdio.h>
#include <stdlib.h>
#include <libnbd.h>
int
main (int argc, char *argv[])
{
  struct nbd_handle *nbd;
  char buf[512];
  FILE *pp;
  if (argc != 2) {
    fprintf (stderr, "%s socket\n", argv[0]);
    exit (EXIT_FAILURE);
  }
  /* Crear el manejador libnbd. */
  nbd = nbd_create ();
  if (nbd == NULL) {
    fprintf (stderr, "%s\n", nbd_get_error ());
    exit (EXIT_FAILURE);
  }
  /* Conectarse al servidor NBD a través de un
   * socket de dominio Unix.
   */
  if (nbd_connect_unix (nbd, argv[1]) == -1) {
    fprintf (stderr, "%s\n", nbd_get_error ());
    exit (EXIT_FAILURE);
  }
  /* Leer el primer sector de forma síncrona. */
  if (nbd_pread (nbd, buf, sizeof buf, 0, 0) == -1) {
    fprintf (stderr, "%s\n", nbd_get_error ());
    exit (EXIT_FAILURE);
  }
  /* Cerrar el manejador libnbd. */
  nbd_close (nbd);
  /* Imprimir el primer sector. */
  pp = popen ("hexdump -C", "w");
  if (pp == NULL) {
    perror ("popen: hexdump");
    exit (EXIT_FAILURE);
  }
  fwrite (buf, sizeof buf, 1, pp);
  pclose (pp);
  exit (EXIT_SUCCESS);
}
