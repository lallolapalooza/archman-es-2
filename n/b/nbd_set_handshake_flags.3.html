nbd_set_handshake_flags(3)

Paquete: libnbd

Licencias: LGPL-2.1-or-later

nbd_set_handshake_flags(3) LIBNBD nbd_set_handshake_flags(3)

NOMBRE

nbd_set_handshake_flags - controla el uso de banderas de saludo

SINOPSIS

#include <libnbd.h>
int nbd_set_handshake_flags (
      struct nbd_handle *h, uint32_t flags
    );

DESCRIPCIÓN

Por defecto, libnbd intenta negociar todas las banderas de saludo posibles que también sean compatibles con el servidor, ya que omitir una bandera de saludo puede impedir el uso de otras funcionalidades como el cifrado TLS o las respuestas estructuradas. Sin embargo, para pruebas de integración, puede ser útil reducir el conjunto de banderas compatibles con el cliente para probar que un servidor en particular puede manejar varios clientes que cumplían con versiones anteriores de la especificación NBD.

El argumento "flags" es una máscara de bits, que incluye cero o más de las siguientes banderas de saludo:

"LIBNBD_HANDSHAKE_FLAG_FIXED_NEWSTYLE" = 1
El servidor maneja elegantemente las solicitudes de opciones desconocidas del cliente, en lugar de desconectarse. Sin esta bandera, un cliente no puede solicitar de forma segura el uso de extensiones como el cifrado TLS o las respuestas estructuradas, ya que la solicitud puede hacer que un servidor antiguo desconecte la conexión.
"LIBNBD_HANDSHAKE_FLAG_NO_ZEROES" = 2
Si el cliente se ve obligado a usar "NBD_OPT_EXPORT_NAME" en lugar del preferido "NBD_OPT_GO", esta bandera permite al servidor enviar menos bytes de relleno de ceros a través de la conexión.

Para mayor comodidad, la constante "LIBNBD_HANDSHAKE_FLAG_MASK" está disponible para describir todas las banderas compatibles con esta compilación de libnbd. Futuras extensiones de NBD pueden añadir más banderas, que a su vez pueden estar habilitadas por defecto en versiones más recientes de libnbd. Como tal, al intentar deshabilitar solo un bit específico, es más prudente llamar primero a nbd_get_handshake_flags(3) y modificar ese valor, en lugar de establecer ciegamente una constante.

VALOR DE RETORNO

Si la llamada tiene éxito, la función devuelve 0.

ERRORES

En caso de error, se devuelve -1.

Consulte "MANEJO DE ERRORES" en libnbd(3) para saber cómo obtener más detalles del error.

Los siguientes parámetros no deben ser NULL: "h". Para más información, consulte "Parámetros no nulos" en libnbd(3).

ESTADO DEL MANEJADOR

nbd_set_handshake_flags se puede llamar cuando el manejador está en el siguiente estado:

┌─────────────────────────────────────┬─────────────────────────┐
│ Manejador creado, antes de conectar │ ✅ permitido              │
│ Conectando                          │ ❌ error                │
│ Conectando y saludando (opt_mode) │ ❌ error                │
│ Conectado al servidor             │ ❌ error                │
│ Conexión cerrada                   │ ❌ error                │
│ Manejador muerto                    │ ❌ error                │
└─────────────────────────────────────┴─────────────────────────┘

VERSIÓN

Esta función apareció por primera vez en libnbd 1.2.

Si necesita probar si esta función está disponible en tiempo de compilación, compruebe si el siguiente macro está definido:

#define LIBNBD_HAVE_NBD_SET_HANDSHAKE_FLAGS 1
