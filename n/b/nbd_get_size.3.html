nbd_get_size(3)

Paquete: libnbd

Licencias: LGPL-2.1-or-later

nbd_get_size(3) LIBNBD nbd_get_size(3)

NOMBRE

nbd_get_size - devuelve el tamaño de la exportación

SINOPSIS

#include <libnbd.h>
int64_t nbd_get_size (
          struct nbd_handle *h
        );

DESCRIPCIÓN

Devuelve el tamaño en bytes de la exportación NBD.

Tenga en cuenta que esta llamada falla con "EOVERFLOW" para un servidor poco probable que anuncie un tamaño que no cabe en un entero con signo de 64 bits.

La opción --size de nbdinfo(1) es una forma de acceder a esta API desde scripts de shell.

Esta llamada no bloquea, porque devuelve datos que se guardan en el manejador del handshake del protocolo NBD.

VALOR DE RETORNO

Esta llamada devuelve un entero con signo de 64 bits ≥ 0.

ERRORES

En caso de error, se devuelve -1.

Consulte "MANEJO DE ERRORES" en libnbd(3) para obtener más detalles sobre el error.

Los siguientes parámetros no deben ser NULL: "h". Para más información, consulte "Parámetros no nulos" en libnbd(3).

ESTADO DEL MANEJADOR

nbd_get_size puede ser llamado cuando el manejador está en los siguientes estados:

┌─────────────────────────────────────┬─────────────────────────┐
│ Manejador creado, antes de conectar │ ❌ error                │
│ Conectando                          │ ❌ error                │
│ Conectando y negociando (opt_mode) │ ✅ permitido              │
│ Conectado al servidor             │ ✅ permitido              │
│ Conexión cerrada                   │ ✅ permitido              │
│ Manejador muerto                    │ ❌ error                │
└───────────────────────────────────────┴─────────────────────────┘

VERSIÓN

Esta función apareció por primera vez en libnbd 1.0.

Si necesita probar si esta función está disponible en tiempo de compilación, compruebe si el siguiente macro está definido:

#define LIBNBD_HAVE_NBD_GET_SIZE 1

EJEMPLO

Este ejemplo también está disponible como examples/get-size.c en el código fuente de libnbd.

/* Este ejemplo muestra cómo conectarse a un servidor NBD
 * y leer el tamaño del disco.
 *
 * Puedes probarlo con nbdkit así:
 *
 * nbdkit -U - memory 1M \
 *   --run './get-size $unixsocket'
 */
#include <stdio.h>
#include <stdlib.h>
#include <stdint.h>
#include <inttypes.h>
#include <libnbd.h>
int
main (int argc, char *argv[])
{
  struct nbd_handle *nbd;
  int64_t size;
  if (argc != 2) {
    fprintf (stderr, "%s socket\n", argv[0]);
    exit (EXIT_FAILURE);
  }
  /* Crear el manejador libnbd. */
  nbd = nbd_create ();
  if (nbd == NULL) {
    fprintf (stderr, "%s\n", nbd_get_error ());
    exit (EXIT_FAILURE);
  }
  /* Conectarse al servidor NBD a través de un
   * socket de dominio Unix.
   */
  if (nbd_connect_unix (nbd, argv[1]) == -1) {
    fprintf (stderr, "%s\n", nbd_get_error ());
    exit (EXIT_FAILURE);
  }
  /* Leer el tamaño en bytes e imprimirlo. */
  size = nbd_get_size (nbd);
  if (size == -1) {
    fprintf (stderr, "%s\n", nbd_get_error ());
    exit (EXIT_FAILURE);
  }
  printf ("%s: size = %" PRIi64 " bytes\n",
          argv[1], size);
  /* Cerrar el manejador libnbd. */
  nbd_close (nbd);
  exit (EXIT_SUCCESS);
}
