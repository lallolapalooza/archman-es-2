nbd_opt_list_meta_context_queries(3) LIBNBD nbd_opt_list_meta_context_queries(3)

NOMBRE

nbd_opt_list_meta_context_queries - lista contextos meta disponibles, usando una lista de consultas explícita

SINOPSIS

#include <libnbd.h>
typedef struct {
  int (*callback) (void *user_data, const char *name);
  void *user_data;
  void (*free) (void *user_data);
} nbd_context_callback;
int nbd_opt_list_meta_context_queries (
      struct nbd_handle *h, char **queries,
      nbd_context_callback context_callback
    );

DESCRIPCIÓN

Solicita que el servidor liste los contextos meta disponibles asociados con la exportación especificada previamente por la llamada más reciente a nbd_set_export_name(3) o nbd_connect_uri(3), y con una lista explícita de consultas proporcionada como parámetro (ver nbd_opt_list_meta_context(3) si deseas reutilizar una lista de consultas implícita en su lugar). Esto solo se puede usar si nbd_set_opt_mode(3) habilitó el modo de opciones.

El protocolo NBD permite a un cliente decidir cuántas consultas hacer al servidor. Para esta función, la lista es explícita en el parámetro "queries". Cuando la lista está vacía, un servidor normalmente responderá con todos los contextos que soporta; cuando la lista no está vacía, el servidor responderá solo con los contextos soportados que coincidan con la solicitud del cliente. Ten en cuenta que una respuesta del servidor puede estar codificada para representar varios contextos factibles dentro de una sola cadena, en lugar de múltiples cadenas por cada nombre de contexto real que tendría éxito durante nbd_opt_go(3); por lo tanto, todavía es necesario usar nbd_can_meta_context(3) después de conectarse para ver qué contextos se soportan realmente.

La función "context" se llama una vez por respuesta del servidor, con cualquier "user_data" pasado a esta función, y con "name" proporcionado por el servidor. Recuerda que no es seguro llamar a nbd_add_meta_context(3) mientras estás en el contexto de la función de devolución de llamada; en su lugar, tu código debe copiar cualquier "name" necesario para uso posterior una vez que esta función se complete. Actualmente, el valor de retorno de la función de devolución de llamada se ignora, aunque se debe evitar un retorno de -1.

Para mayor comodidad, cuando esta función tiene éxito, devuelve el número de respuestas devueltas por el servidor.

No todos los servidores entienden esta solicitud, e incluso cuando se entiende, el servidor puede enviar intencionalmente una lista vacía porque no soporta el contexto solicitado, o puede encontrar un error después de entregar resultados parciales. Por lo tanto, esta función puede tener éxito incluso cuando no se informan contextos, o puede fallar pero tener una lista no vacía. Igualmente, el protocolo NBD no especifica un límite superior para el número de respuestas que pueden ser anunciadas, por lo que el código cliente debe ser consciente de que un servidor puede enviar una lista extensa.

VALOR DE RETORNO

Esta llamada devuelve un entero ≥ 0.

ERRORES

En caso de error, se devuelve -1.

Consulte "MANEJO DE ERRORES" en libnbd(3) para obtener más detalles sobre el error.

Los siguientes parámetros no deben ser NULL: "h", "queries". Para más información, consulte "Parámetros no nulos" en libnbd(3).

ESTADO DEL MANEJADOR

nbd_opt_list_meta_context_queries puede ser llamado cuando el manejador se encuentra en el siguiente estado:

┌─────────────────────────────────────┬─────────────────────────┐
│ Manejador creado, antes de conectar │ ❌ error                │
│ Conectando                          │ ❌ error                │
│ Conectando & handshake (opt_mode) │ ✅ permitido              │
│ Conectado al servidor             │ ❌ error                │
│ Conexión cerrada                 │ ❌ error                │
│ Manejador muerto                  │ ❌ error                │
└─────────────────────────────────────┴─────────────────────────┘

VERSIÓN

Esta función apareció por primera vez en libnbd 1.16.

Si necesita probar si esta función está disponible en tiempo de compilación, compruebe si está definido el siguiente macro:

#define LIBNBD_HAVE_NBD_OPT_LIST_META_CONTEXT_QUERIES 1
