nbd_opt_list_meta_context(3)

Paquete: libnbd

nbd_opt_list_meta_context(3) LIBNBD nbd_opt_list_meta_context(3)

NOMBRE

nbd_opt_list_meta_context - lista los contextos meta disponibles, utilizando una lista de consultas implícita

SINOPSIS

#include <libnbd.h>
typedef struct {
  int (*callback) (void *user_data, const char *name);
  void *user_data;
  void (*free) (void *user_data);
} nbd_context_callback;
int nbd_opt_list_meta_context (
      struct nbd_handle *h,
      nbd_context_callback context_callback
    );

DESCRIPCIÓN

Solicita que el servidor liste los contextos meta asociados con la exportación previamente especificada por la llamada más reciente a nbd_set_export_name(3) o nbd_connect_uri(3), y con una lista de consultas de llamadas anteriores a nbd_add_meta_context(3) (ver nbd_opt_list_meta_context_queries(3) si desea proporcionar una lista de consultas explícita). Esto solo se puede utilizar si nbd_set_opt_mode(3) habilitó el modo de opciones.

El protocolo NBD permite a un cliente decidir cuántas consultas enviar al servidor. En lugar de tomar esa lista de consultas como parámetro para esta función, libnbd reutiliza la lista actual de contextos meta solicitados establecida por nbd_add_meta_context(3); puede usar nbd_clear_meta_contexts(3) para configurar una lista de consultas diferente. Cuando la lista está vacía, un servidor generalmente responderá con todos los contextos que soporta; cuando la lista no está vacía, el servidor responderá solo con los contextos soportados que coincidan con la solicitud del cliente. Tenga en cuenta que una respuesta del servidor podría estar codificada para representar varios contextos factibles dentro de una única cadena, en lugar de múltiples cadenas por cada nombre de contexto real que tendría éxito durante nbd_opt_go(3); por lo tanto, aún es necesario utilizar nbd_can_meta_context(3) después de la conexión para ver qué contextos se soportan realmente.

La función "context" se llama una vez por respuesta del servidor, con cualquier "user_data" pasado a esta función, y con "name" proporcionado por el servidor. Recuerde que no es seguro llamar a nbd_add_meta_context(3) desde dentro del contexto de la función de devolución de llamada; en su lugar, su código debe copiar cualquier "name" necesario para uso posterior después de que esta función se complete. Actualmente, el valor de retorno de la función de devolución de llamada se ignora, aunque se debe evitar un retorno de -1.

Para mayor comodidad, cuando esta función tiene éxito, devuelve el número de respuestas devueltas por el servidor.

No todos los servidores entienden esta solicitud, e incluso cuando se entiende, el servidor puede enviar intencionalmente una lista vacía porque no soporta el contexto solicitado, o puede encontrar un error después de entregar resultados parciales. Por lo tanto, esta función puede tener éxito incluso cuando no se informan contextos, o puede fallar pero tener una lista no vacía. Del mismo modo, el protocolo NBD no especifica un límite superior para el número de respuestas que pueden anunciarse, por lo que el código del cliente debe ser consciente de que un servidor puede enviar una lista larga.

VALOR DE RETORNO

Esta llamada devuelve un entero ≥ 0.

ERRORES

En caso de error, se devuelve -1.

Consulte "MANEJO DE ERRORES" en libnbd(3) para obtener más detalles sobre el error.

Los siguientes parámetros no deben ser NULL: "h". Para más información, consulte "Parámetros no NULL" en libnbd(3).

ESTADO DEL MANEJADOR

nbd_opt_list_meta_context se puede llamar cuando el manejador está en el siguiente estado:

┌─────────────────────────────────────┬─────────────────────────┐
│ Manejador creado, antes de conectar   │ ❌ error                │
│ Conectando                          │ ❌ error                │
│ Conectando y handshake (opt_mode) │ ✅ permitido             │
│ Conectado al servidor             │ ❌ error                │
│ Conexión cerrada                   │ ❌ error                │
│ Manejador muerto                    │ ❌ error                │
└─────────────────────────────────────┴─────────────────────────┘

VERSIÓN

Esta función apareció por primera vez en libnbd 1.6.

Si necesita probar si esta función está disponible en tiempo de compilación, verifique si la siguiente macro está definida:

#define LIBNBD_HAVE_NBD_OPT_LIST_META_CONTEXT 1
