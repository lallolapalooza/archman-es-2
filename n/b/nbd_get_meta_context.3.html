nbd_get_meta_context(3)

nbd_get_meta_context(3) LIBNBD nbd_get_meta_context(3)

NOMBRE

nbd_get_meta_context - devuelve la solicitud de contexto meta i'ésima

SINOPSIS

#include <libnbd.h>
char * nbd_get_meta_context (
         struct nbd_handle *h, size_t i
       );

DESCRIPCIÓN

Durante la conexión, libnbd puede negociar cero o más contextos de metadatos con el servidor. Los contextos de metadatos son características (como "base:allocation") que describen la información devuelta por el comando nbd_block_status_64(3) (para "base:allocation", esto es si los bloques de datos están asignados, son ceros o dispersos).

Este comando devuelve la solicitud de contexto meta i'ésima, tal como se añadió con nbd_add_meta_context(3), y está limitada por nbd_get_nr_meta_contexts(3).

VALOR DE RETORNO

Esta llamada devuelve una cadena. El llamador debe liberar la cadena devuelta para evitar una fuga de memoria.

ERRORES

En caso de error se devuelve "NULL".

Consulte "MANEJO DE ERRORES" en libnbd(3) para saber cómo obtener más detalles sobre el error.

Los siguientes parámetros no deben ser NULL: "h". Para más información, consulte "Parámetros no NULL" en libnbd(3).

VERSIÓN

Esta función apareció por primera vez en libnbd 1.6.

Si necesita comprobar si esta función está disponible en tiempo de compilación, compruebe si la siguiente macro está definida:

#define LIBNBD_HAVE_NBD_GET_META_CONTEXT 1

VER TAMBIÉN

nbd_add_meta_context(3), nbd_block_status_64(3), nbd_can_meta_context(3), nbd_clear_meta_contexts(3), nbd_create(3), nbd_get_nr_meta_contexts(3), libnbd(3).
