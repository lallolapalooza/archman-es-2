Paquete: libnbd

nbd_aio_cache(3) LIBNBD nbd_aio_cache(3)

NOMBRE

nbd_aio_cache - enviar comando de caché (prelectura) al servidor NBD

SINOPSIS

#include <libnbd.h>
typedef struct {
  int (*callback) (void *user_data, int *error);
  void *user_data;
  void (*free) (void *user_data);
} nbd_completion_callback;
int64_t nbd_aio_cache (
          struct nbd_handle *h, uint64_t count,
          uint64_t offset,
          nbd_completion_callback completion_callback,
          uint32_t flags
        );

DESCRIPCIÓN

Emitir el comando de caché (prelectura) al servidor NBD.

Para comprobar si el comando se completó, llame a nbd_aio_command_completed(3). O proporcione la opcional "completion_callback" que se invocará como se describe en "Callbacks de finalización" en libnbd(3).

Otros parámetros se comportan como se documenta en nbd_cache(3).

Por defecto, libnbd rechazará los intentos de usar esta función con parámetros que probablemente resulten en un fallo del servidor, como solicitar un flag de comando desconocido. La función nbd_set_strict_mode(3) se puede usar para modificar qué escenarios esperarán una respuesta del servidor en lugar de fallar rápidamente.

VALOR DE RETORNO

Esta llamada devuelve la cookie de 64 bits del comando. La cookie es ≥ 1. Las cookies son únicas (por handle de libnbd, no globalmente).

ERRORES

En caso de error, se devuelve -1.

Consulte "MANEJO DE ERRORES" en libnbd(3) para obtener más detalles sobre el error.

Los siguientes parámetros no deben ser NULL: "h". Para más información, consulte "Parámetros no NULL" en libnbd(3).

ESTADO DEL MANEJADOR

nbd_aio_cache se puede llamar cuando el manejador se encuentra en el siguiente estado:

┌─────────────────────────────────────┬─────────────────────────┐
│ Manejador creado, antes de conectar │ ❌ error                │
│ Conectando                          │ ❌ error                │
│ Conectando y handshake (opt_mode) │ ❌ error                │
│ Conectado al servidor             │ ✅ permitido            │
│ Conexión cerrada                   │ ❌ error                │
│ Manejador muerto                   │ ❌ error                │
└─────────────────────────────────────┴─────────────────────────┘

VERSIÓN

Esta función apareció por primera vez en libnbd 1.0.

Si necesita probar si esta función está disponible en tiempo de compilación, compruebe si está definido el siguiente macro:

#define LIBNBD_HAVE_NBD_AIO_CACHE 1
