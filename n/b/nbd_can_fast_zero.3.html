nbd_can_fast_zero(3)

Paquete: libnbd

Licencias: LGPL-2.1-or-later

nbd_can_fast_zero(3) LIBNBD nbd_can_fast_zero(3)

NOMBRE

nbd_can_fast_zero - ¿soporta el servidor el flag fast zero?

SINOPSIS

#include <libnbd.h>
int nbd_can_fast_zero (
      struct nbd_handle *h
    );

DESCRIPCIÓN

Devuelve verdadero si el servidor soporta el uso del flag "LIBNBD_CMD_FLAG_FAST_ZERO" para el comando zero (ver nbd_zero(3), nbd_aio_zero(3)). Devuelve falso si el servidor no lo soporta.

Esta llamada no bloquea, porque devuelve datos que se guardan en el handle desde el handshake del protocolo NBD.

VALOR DE RETORNO

Esta llamada devuelve un valor booleano.

ERRORES

En caso de error se devuelve -1.

Consulte "MANEJO DE ERRORES" en libnbd(3) para obtener más detalles sobre el error.

Los siguientes parámetros no deben ser NULL: "h". Para más información consulte "Parámetros no nulos" en libnbd(3).

ESTADO DEL HANDLE

nbd_can_fast_zero puede ser llamada cuando el handle se encuentra en los siguientes estados:

┌─────────────────────────────────────┬─────────────────────────┐
│ Handle creado, antes de conectar │ ❌ error                │
│ Conectando                          │ ❌ error                │
│ Conectando y handshake (opt_mode) │ ✅ permitido              │
│ Conectado al servidor             │ ✅ permitido              │
│ Conexión cerrada                │ ✅ permitido              │
│ Handle muerto                         │ ❌ error                │
└─────────────────────────────────────┴─────────────────────────┘

VERSIÓN

Esta función apareció por primera vez en libnbd 1.2.

Si necesita probar si esta función está disponible en tiempo de compilación compruebe si el siguiente macro está definido:

#define LIBNBD_HAVE_NBD_CAN_FAST_ZERO 1

EJEMPLO

Este ejemplo también está disponible como examples/server-flags.c en el código fuente de libnbd.

/* This example shows how to connect to an NBD
 * server and print the export flags.
 *
 * You can test it with nbdkit like this:
 *
 * nbdkit -U - memory 1M \
 *   --run './server-flags $unixsocket'
 */
#include <stdio.h>
#include <stdlib.h>
#include <stdbool.h>
#include <libnbd.h>
int
main (int argc, char *argv[])
{
  struct nbd_handle *nbd;
  char *str;
  int flag;
  if (argc != 2) {
    fprintf (stderr, "%s socket\n", argv[0]);
    exit (EXIT_FAILURE);
  }
  /* Create the libnbd handle. */
  nbd = nbd_create ();
  if (nbd == NULL) {
    fprintf (stderr, "%s\n", nbd_get_error ());
    exit (EXIT_FAILURE);
  }
  /* Request full information. */
#if LIBNBD_HAVE_NBD_SET_FULL_INFO /* Added in 1.4 */
  if (nbd_set_full_info (nbd, true) == -1) {
    fprintf (stderr, "%s\n", nbd_get_error ());
    exit (EXIT_FAILURE);
  }
#endif
  /* Connect to the NBD server over a
   * Unix domain socket.
   */
  if (nbd_connect_unix (nbd, argv[1]) == -1) {
    fprintf (stderr, "%s\n", nbd_get_error ());
    exit (EXIT_FAILURE);
  }
  /* See if the server provided extra details,
   * using functions added in 1.4
   */
#if LIBNBD_HAVE_NBD_GET_EXPORT_DESCRIPTION
  str = nbd_get_canonical_export_name (nbd);
  if (str)
    printf ("canonical_name = %s\n", str);
  free (str);
  str = nbd_get_export_description (nbd);
  if (str)
    printf ("description = %s\n", str);
  free (str);
#endif
  /* Read and print the flags. */
#define PRINT_FLAG(flag_fn)                     \
  flag = flag_fn (nbd);                         \
  if (flag == -1) {                             \
    fprintf (stderr, "%s\n", nbd_get_error ()); \
    exit (EXIT_FAILURE);                        \
  }                                             \
  printf (#flag_fn " = %s\n",                   \
          flag ? "true" : "false");
  PRINT_FLAG (nbd_can_cache);
  PRINT_FLAG (nbd_can_df);
  PRINT_FLAG (nbd_can_flush);
  PRINT_FLAG (nbd_can_fua);
  PRINT_FLAG (nbd_can_multi_conn);
  PRINT_FLAG (nbd_can_trim);
  PRINT_FLAG (nbd_can_zero);
#if LIBNBD_HAVE_NBD_CAN_FAST_ZERO
  /* Added in 1.2 */
  PRINT_FLAG (nbd_can_fast_zero);
#endif
#if LIBNBD_HAVE_NBD_CAN_BLOCK_STATUS_PAYLOAD
  /* Added in 1.18 */
  PRINT_FLAG (nbd_can_block_status_payload);
#endif
  PRINT_FLAG (nbd_is_read_only);
  PRINT_FLAG (nbd_is_rotational);
  /* Close the libnbd handle. */
  nbd_close (nbd);
  exit (EXIT_SUCCESS);
}

SYNOPSIS

#include <libnbd.h>

int nbd_can_fast_zero (NBD_CLIENT *client);

DESCRIPTION

La función nbd_can_fast_zero comprueba si el servidor nbd conectado a client admite la operación de cero rápido. La operación de cero rápido permite al cliente solicitar al servidor que ponga a cero partes del disco remoto. Esto se puede usar, por ejemplo, para inicializar un disco o para liberar espacio en disco en almacenamiento con asignación dinámica.

RETURN VALUE

nbd_can_fast_zero devuelve 1 si la operación de cero rápido es compatible, 0 en caso contrario. En caso de error, devuelve -1 y el error se puede obtener con nbd_get_last_error.

HANDLE STATE

La operación solo puede realizarse si el cliente nbd está en el estado NBD_STATE_CONNECTED.

VERSION

Esta función está disponible en libnbd versión 1.8.

EXAMPLE

#include <libnbd.h>
#include <stdio.h>

int main(void) {
    NBD_CLIENT *client = nbd_connect_uri("nbd:example.com:10809");
    if (!client) {
        fprintf(stderr, "Failed to connect to server: %s\n", nbd_get_last_error());
        return 1;
    }

    if (nbd_can_fast_zero(client)) {
        printf("Server supports fast zero.\n");
    } else {
        printf("Server does not support fast zero.\n");
    }

    nbd_disconnect(client);
    return 0;
}
