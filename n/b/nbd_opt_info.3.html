NOMBRE

nbd_opt_info - solicitar al servidor información sobre una exportación

SINOPSIS

#include <libnbd.h>
int nbd_opt_info (
      struct nbd_handle *h
    );

DESCRIPCIÓN

Solicita que el servidor proporcione información sobre el nombre de exportación especificado previamente por la llamada más reciente a nbd_set_export_name(3) o nbd_connect_uri(3). Esto solo se puede utilizar si nbd_set_opt_mode(3) habilitó el modo de opciones.

Si tiene éxito, funciones como nbd_is_read_only(3) y nbd_get_size(3) informarán detalles sobre esa exportación. Si nbd_set_request_meta_context(3) está configurado (el valor predeterminado) y se negociaron respuestas estructuradas o encabezados extendidos, también es válido usar nbd_can_meta_context(3) después de esta llamada. Sin embargo, puede ser más eficiente borrar esa configuración y utilizar manualmente nbd_opt_list_meta_context(3) con su enfoque de devolución de llamada, para conocer qué contextos admite una exportación. En general, si se llama a nbd_opt_go(3) a continuación, esa llamada probablemente tendrá éxito con los detalles permaneciendo iguales, aunque esto no está garantizado por todos los servidores.

No todos los servidores entienden esta solicitud, e incluso cuando se entiende, el servidor puede fallar la solicitud, incluso cuando una nbd_opt_go(3) correspondiente tendría éxito.

VALOR DE RETORNO

Si la llamada tiene éxito, la función devuelve 0.

ERRORES

En caso de error, se devuelve -1.

Consulte "MANEJO DE ERRORES" en libnbd(3) para obtener más detalles sobre el error.

Los siguientes parámetros no deben ser NULL: "h". Para obtener más información, consulte "Parámetros no nulos" en libnbd(3).

ESTADO DEL MANEJADOR

Se puede llamar a nbd_opt_info cuando el manejador se encuentra en el siguiente estado:

┌─────────────────────────────────────┬─────────────────────────┐
│ Manejador creado, antes de conectar │ ❌ error                │
│ Conectando                          │ ❌ error                │
│ Conectando y handshake (opt_mode) │ ✅ permitido              │
│ Conectado al servidor             │ ❌ error                │
│ Conexión cerrada                   │ ❌ error                │
│ Manejador muerto                    │ ❌ error                │
└─────────────────────────────────────┴─────────────────────────┘

VERSIÓN

Esta función apareció por primera vez en libnbd 1.4.

Si necesita probar si esta función está disponible en tiempo de compilación, compruebe si está definido el siguiente macro:

#define LIBNBD_HAVE_NBD_OPT_INFO 1
