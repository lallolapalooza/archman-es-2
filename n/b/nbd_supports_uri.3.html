nbd_supports_uri(3)

Paquete: libnbd

Licencias: LGPL-2.1-or-later

nbd_supports_uri(3) LIBNBD nbd_supports_uri(3)

NOMBRE

nbd_supports_uri - verdadero si libnbd fue compilado con soporte para URIs NBD

SINOPSIS

#include <libnbd.h>
int nbd_supports_uri (
      struct nbd_handle *h
    );

DESCRIPCIÓN

Devuelve verdadero si libnbd fue compilado con libxml2, lo cual es necesario para soportar URIs NBD, o falso si no.

VALOR DE RETORNO

Esta llamada devuelve un valor booleano.

ERRORES

Esta función no falla.

Los siguientes parámetros no deben ser NULL: "h". Para más información véase "Parámetros no NULL" en libnbd(3).

VERSIÓN

Esta función apareció por primera vez en libnbd 1.0.

Si necesitas comprobar si esta función está disponible en tiempo de compilación, comprueba si la siguiente macro está definida:

#define LIBNBD_HAVE_NBD_SUPPORTS_URI 1

VER TAMBIÉN

nbd_aio_connect_uri(3), nbd_connect_uri(3), nbd_create(3), nbd_get_uri(3), nbd_is_uri(3), libnbd(3).
