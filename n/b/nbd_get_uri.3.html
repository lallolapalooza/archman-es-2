nbd_get_uri(3) LIBNBD nbd_get_uri(3)

NOMBRE

nbd_get_uri - construye una URI NBD para una conexión

SINOPSIS

#include <libnbd.h>
char * nbd_get_uri (
         struct nbd_handle *h
       );

DESCRIPCIÓN

Esto hace un esfuerzo máximo para construir una URI NBD que podría ser usada para conectarse de vuelta al mismo servidor (usando nbd_connect_uri(3)).

En algunos casos, no hay suficiente información en el manejador para crear exitosamente una URI (p.ej., si te conectaste con nbd_connect_socket(3)). En tales casos, la llamada devuelve "NULL" y información diagnóstica adicional está disponible a través de nbd_get_errno(3) y nbd_get_error(3) como de costumbre.

Incluso si se devuelve una URI, no se garantiza que funcione y puede que no sea óptima.

La opción --uri de nbdinfo(1) es una forma de acceder a esta API desde scripts de shell.

VALOR DE RETORNO

Esta llamada devuelve una cadena. El llamador debe liberar la cadena devuelta para evitar una fuga de memoria.

ERRORES

En caso de error se devuelve "NULL".

Consulte "MANEJO DE ERRORES" en libnbd(3) para saber cómo obtener más detalles del error.

Los siguientes parámetros no deben ser NULL: "h". Para más información, consulte "Parámetros no nulos" en libnbd(3).

ESTADO DEL MANEJADOR

nbd_get_uri puede ser llamado cuando el manejador está en los siguientes estados:

┌─────────────────────────────────────┬─────────────────────────┐
│ Manejador creado, antes de conectar │ ❌ error                │
│ Conectando                          │ ✅ permitido              │
│ Conectando & haciendo handshake (opt_mode) │ ✅ permitido              │
│ Conectado al servidor             │ ✅ permitido              │
│ Conexión cerrada                   │ ✅ permitido              │
│ Manejador muerto                     │ ✅ permitido              │
└───────────────────────────────────────┴─────────────────────────┘

VERSIÓN

Esta función apareció por primera vez en libnbd 1.8.

Si necesita probar si esta función está disponible en tiempo de compilación, verifique si la siguiente macro está definida:

#define LIBNBD_HAVE_NBD_GET_URI 1
