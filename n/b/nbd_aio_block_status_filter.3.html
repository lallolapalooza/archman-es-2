NOMBRE

nbd_aio_block_status_filter - enviar comando de estado de bloque filtrado al servidor NBD

SINAPSIS

#include <libnbd.h>
typedef struct {
  int (*callback) (void *user_data,
                   const char *metacontext,
                   uint64_t offset, nbd_extent *entries,
                   size_t nr_entries, int *error);
  void *user_data;
  void (*free) (void *user_data);
} nbd_extent64_callback;
typedef struct {
  int (*callback) (void *user_data, int *error);
  void *user_data;
  void (*free) (void *user_data);
} nbd_completion_callback;
int64_t nbd_aio_block_status_filter (
          struct nbd_handle *h, uint64_t count,
          uint64_t offset, char **contexts,
          nbd_extent64_callback extent64_callback,
          nbd_completion_callback completion_callback,
          uint32_t flags
        );

DESCRIPCIÓN

Enviar un comando de estado de bloque filtrado al servidor NBD.

Para verificar si el comando se completó, llame a nbd_aio_command_completed(3). O proporcione el "completion_callback" opcional, que se invocará como se describe en "Callbacks de finalización" en libnbd(3).

Otros parámetros se comportan como se documenta en nbd_block_status_filter(3).

Por defecto, libnbd rechazará los intentos de usar esta función con parámetros que probablemente resulten en un fallo del servidor, como solicitar una bandera de comando desconocida. La función nbd_set_strict_mode(3) se puede usar para alterar qué escenarios deben esperar una respuesta del servidor en lugar de fallar rápidamente.

VALOR DE RETORNO

Esta llamada devuelve la cookie de 64 bits del comando. La cookie es ≥ 1. Las cookies son únicas (por manejador libnbd, no globalmente).

ERRORES

En caso de error, se devuelve -1.

Consulte "MANEJO DE ERRORES" en libnbd(3) para obtener más detalles sobre el error.

Los siguientes parámetros no deben ser NULL: "h", "contexts". Para más información, consulte "Parámetros no nulos" en libnbd(3).

ESTADO DEL MANEJADOR

nbd_aio_block_status_filter se puede llamar cuando el manejador está en el siguiente estado:

┌─────────────────────────────────────┬─────────────────────────┐
│ Manejador creado, antes de conectar │ ❌ error │
│ Conectando │ ❌ error │
│ Conectando y estableciendo apretón de manos (opt_mode) │ ❌ error │
│ Conectado al servidor │ ✅ permitido │
│ Conexión cerrada │ ❌ error │
│ Manejador inactivo │ ❌ error │
└─────────────────────────────────────┴─────────────────────────┘

VERSIÓN

Esta función apareció por primera vez en libnbd 1.18.

Si necesita probar si esta función está disponible en tiempo de compilación, verifique si el siguiente macro está definido:

#define LIBNBD_HAVE_NBD_AIO_BLOCK_STATUS_FILTER 1
