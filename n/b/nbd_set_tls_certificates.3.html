nbd_set_tls_certificates(3)

Paquete: libnbd

Licencias: LGPL-2.1-or-later

nbd_set_tls_certificates(3) LIBNBD nbd_set_tls_certificates(3)

NOMBRE

nbd_set_tls_certificates - establece la ruta al directorio de certificados TLS

SINOPSIS

#include <libnbd.h>
int nbd_set_tls_certificates (
      struct nbd_handle *h, const char *dir
    );

DESCRIPCIÓN

Establece la ruta al directorio de certificados TLS. Si no se establece y se utiliza TLS, se utilizará un valor predeterminado compilado en el código. Para el usuario root, es "/etc/pki/libnbd/". Para usuarios no root, es "$HOME/.pki/libnbd" y "$HOME/.config/pki/libnbd". Si ninguno de estos directorios se puede encontrar, se utilizan las CA de confianza del sistema.

Esta función se puede llamar independientemente de si TLS es compatible o no, pero no tendrá ningún efecto a menos que también se utilice nbd_set_tls(3) para solicitar o requerir TLS.

VALOR DE RETORNO

Si la llamada es exitosa, la función devuelve 0.

ERRORES

En caso de error, se devuelve -1.

Consulte "MANEJO DE ERRORES" en libnbd(3) para obtener más detalles sobre el error.

Los siguientes parámetros no deben ser NULL: "h", "dir". Para más información, consulte "Parámetros no NULL" en libnbd(3).

ESTADO DEL MANEJADOR

nbd_set_tls_certificates se puede llamar cuando el manejador se encuentra en el siguiente estado:

┌─────────────────────────────────────┬─────────────────────────┐
│ Manejador creado, antes de conectar │ ✅ permitido              │
│ Conectando                          │ ❌ error                │
│ Conectando y handshake (modo_opt) │ ❌ error                │
│ Conectado al servidor             │ ❌ error                │
│ Conexión cerrada                 │ ❌ error                │
│ Manejador inactivo                │ ❌ error                │
└─────────────────────────────────────┴─────────────────────────┘

VERSIÓN

Esta función apareció por primera vez en libnbd 1.0.

Si necesita comprobar si esta función está disponible en tiempo de compilación, compruebe si el siguiente macro está definido:

#define LIBNBD_HAVE_NBD_SET_TLS_CERTIFICATES 1

VEA TAMBIÉN

nbd_create(3), nbd_set_tls(3), libnbd(3).
