nbd_get_tls_negotiated(3)

Paquete: libnbd

nbd_get_tls_negotiated(3) LIBNBD nbd_get_tls_negotiated(3)

NOMBRE

nbd_get_tls_negotiated - averiguar si se negoció TLS en una conexión

SINOPSIS

#include <libnbd.h>
int nbd_get_tls_negotiated (
      struct nbd_handle *h
    );

DESCRIPCIÓN

Después de conectarse, puede llamar a esto para averiguar si la conexión está utilizando TLS.

Esto es normalmente útil solo si establece el modo de solicitud TLS a "LIBNBD_TLS_ALLOW" (ver nbd_set_tls(3)), porque en este modo intentamos usar TLS pero volvemos a no cifrado si no estaba disponible. Esta función le dirá si se negoció TLS o no.

En modo "LIBNBD_TLS_REQUIRE" (el más seguro), la conexión habría fallado si no se hubiera podido negociar TLS. Con el modo "LIBNBD_TLS_DISABLE", TLS no se intenta automáticamente; pero si el servidor NBD utiliza el modo menos común "SELECTIVETLS", esta función informa si una llamada manual a nbd_opt_starttls(3) habilitó TLS o si la conexión sigue siendo texto plano.

VALOR DE RETORNO

Esta llamada devuelve un valor booleano.

ERRORES

En caso de error, se devuelve -1.

Consulte "MANEJO DE ERRORES" en libnbd(3) para saber cómo obtener más detalles sobre el error.

Los siguientes parámetros no deben ser NULL: "h". Para más información, consulte "Parámetros no nulos" en libnbd(3).

ESTADO DEL MANEJADOR

nbd_get_tls_negotiated se puede llamar cuando el manejador está en los siguientes estados:

┌─────────────────────────────────────┬─────────────────────────┐
│ Manejador creado, antes de conectar │ ❌ error                │
│ Conectando                          │ ❌ error                │
│ Conectando y haciendo handshake (opt_mode) │ ✅ permitido              │
│ Conectado al servidor             │ ✅ permitido              │
│ Conexión cerrada                │ ✅ permitido              │
│ Manejador muerto                         │ ❌ error                │
└─────────────────────────────────────┴─────────────────────────┘

VERSIÓN

Esta función apareció por primera vez en libnbd 1.2.

Si necesita probar si esta función está disponible en tiempo de compilación, compruebe si el siguiente macro está definido:

#define LIBNBD_HAVE_NBD_GET_TLS_NEGOTIATED 1

VER TAMBIÉN

nbd_create(3), nbd_get_tls(3), nbd_opt_starttls(3), nbd_set_tls(3), libnbd(3).
