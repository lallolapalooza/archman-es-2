nbd_opt_extended_headers(3) LIBNBD nbd_opt_extended_headers(3)

NOMBRE

nbd_opt_extended_headers - solicitar al servidor que habilite encabezados extendidos

SINOPSIS

#include <libnbd.h>
int nbd_opt_extended_headers (
      struct nbd_handle *h
    );

DESCRIPCIÓN

Solicita que el servidor utilice encabezados extendidos, enviando "NBD_OPT_EXTENDED_HEADERS". Esto solo puede usarse si nbd_set_opt_mode(3) habilitó el modo de opciones; además, libnbd solicita esto automáticamente por defecto a menos que use nbd_set_request_extended_headers(3) o nbd_set_request_structured_replies(3) antes de conectar. Esta función es útil principalmente para pruebas de integración de casos de esquina en el manejo del servidor.

Esta función devuelve verdadero si el servidor responde con éxito, falso si el servidor responde con un error, y falla solo si el servidor no responde (como en una pérdida de conexión). Tenga en cuenta que algunos servidores fallan una segunda solicitud como redundante; libnbd asume que una vez que una solicitud ha tenido éxito, los encabezados extendidos son compatibles (como se ve en nbd_get_extended_headers_negotiated(3)) independientemente de si las llamadas posteriores a esta función devuelven falso. Si esta función devuelve verdadero, se implícita el uso de respuestas estructuradas.

VALOR DE RETORNO

Esta llamada devuelve un valor booleano.

ERRORES

En caso de error se devuelve -1.

Consulte "MANEJO DE ERRORES" en libnbd(3) para obtener más detalles sobre el error.

Los siguientes parámetros no deben ser NULL: "h". Para más información, consulte "Parámetros no nulos" en libnbd(3).

ESTADO DEL MANEJADOR

nbd_opt_extended_headers puede ser llamado cuando el manejador se encuentra en el siguiente estado:

┌─────────────────────────────────────┬─────────────────────────┐
│ Mananejador creado, antes de conectar │ ❌ error │
│ Conectando │ ❌ error │
│ Conectando y haciendo handshake (opt_mode) │ ✅ permitido │
│ Conectado al servidor │ ❌ error │
│ Conexión cerrada │ ❌ error │
│ Mananejador muerto │ ❌ error │
└─────────────────────────────────────┴─────────────────────────┘

VERSIÓN

Esta función apareció por primera vez en libnbd 1.18.

Si necesita probar si esta función está disponible en tiempo de compilación verifique si el siguiente macro está definido:

#define LIBNBD_HAVE_NBD_OPT_EXTENDED_HEADERS 1
