nbd_can_multi_conn(3)

Paquete: libnbd

Licencias: LGPL-2.1-or-later

nbd_can_multi_conn(3) LIBNBD nbd_can_multi_conn(3)

NOMBRE

nbd_can_multi_conn - ¿el servidor soporta multi-conn?

SINOPSIS

#include <libnbd.h>
int nbd_can_multi_conn (
      struct nbd_handle *h
    );

DESCRIPCIÓN

Devuelve verdadero si el servidor soporta multi-conn. Devuelve falso si el servidor no lo soporta.

No es seguro abrir múltiples handles conectándose al mismo servidor si vas a escribir en el servidor y este no anuncia soporte para multi-conn. La forma segura de comprobar esto es abrir una conexión, verificar que este flag es verdadero, y luego abrir conexiones adicionales según sea necesario.

Esta llamada no bloquea, porque devuelve datos que se guardan en el handle desde el handshake del protocolo NBD.

VALOR DE RETORNO

Esta llamada devuelve un valor booleano.

ERRORES

En caso de error, se devuelve -1.

Consulte "MANEJO DE ERRORES" en libnbd(3) para obtener más detalles sobre el error.

Los siguientes parámetros no deben ser NULL: "h". Para más información, consulte "Parámetros no nulos" en libnbd(3).

ESTADO DEL HANDLE

nbd_can_multi_conn puede ser llamada cuando el handle está en los siguientes estados:

┌─────────────────────────────────────┬─────────────────────────┐
│ Handle creado, antes de conectar  │ ❌ error                │
│ Conectando                          │ ❌ error                │
│ Conectando y handshake (opt_mode) │ ✅ permitido             │
│ Conectado al servidor             │ ✅ permitido             │
│ Conexión cerrada                 │ ✅ permitido             │
│ Handle muerto                       │ ❌ error                │
└─────────────────────────────────────┴─────────────────────────┘

VERSIÓN

Esta función apareció por primera vez en libnbd 1.0.

Si necesitas probar si esta función está disponible en tiempo de compilación, comprueba si el siguiente macro está definido:

#define LIBNBD_HAVE_NBD_CAN_MULTI_CONN 1

EJEMPLO

Este ejemplo también está disponible como examples/server-flags.c en el código fuente de libnbd.

/* Este ejemplo muestra cómo conectarse a un servidor NBD
 * e imprimir los flags de exportación.
 *
 * Puedes probarlo con nbdkit de esta manera:
 *
 * nbdkit -U - memory 1M \
 *   --run './server-flags $unixsocket'
 */
#include <stdio.h>
#include <stdlib.h>
#include <stdbool.h>
#include <libnbd.h>
int
main (int argc, char *argv[])
{
  struct nbd_handle *nbd;
  char *str;
  int flag;
  if (argc != 2) {
    fprintf (stderr, "%s socket\n", argv[0]);
    exit (EXIT_FAILURE);
  }
  /* Crear el handle de libnbd. */
  nbd = nbd_create ();
  if (nbd == NULL) {
    fprintf (stderr, "%s\n", nbd_get_error ());
    exit (EXIT_FAILURE);
  }
  /* Solicitar información completa. */
#if LIBNBD_HAVE_NBD_SET_FULL_INFO /* Añadido en 1.4 */
  if (nbd_set_full_info (nbd, true) == -1) {
    fprintf (stderr, "%s\n", nbd_get_error ());
    exit (EXIT_FAILURE);
  }
#endif
  /* Conectarse al servidor NBD a través de un
   * socket de dominio Unix.
   */
  if (nbd_connect_unix (nbd, argv[1]) == -1) {
    fprintf (stderr, "%s\n", nbd_get_error ());
    exit (EXIT_FAILURE);
  }
  /* Ver si el servidor proporcionó detalles adicionales,
   * utilizando funciones añadidas en 1.4
   */
#if LIBNBD_HAVE_NBD_GET_EXPORT_DESCRIPTION
  str = nbd_get_canonical_export_name (nbd);
  if (str)
    printf ("canonical_name = %s\n", str);
  free (str);
  str = nbd_get_export_description (nbd);
  if (str)
    printf ("description = %s\n", str);
  free (str);
#endif
  /* Leer e imprimir los flags. */
#define PRINT_FLAG(flag_fn)                     \
  flag = flag_fn (nbd);                         \
  if (flag == -1) {                             \
    fprintf (stderr, "%s\n", nbd_get_error ()); \
    exit (EXIT_FAILURE);                        \
  }                                             \
  printf (#flag_fn " = %s\n",                   \
          flag ? "true" : "false");
  PRINT_FLAG (nbd_can_cache);
  PRINT_FLAG (nbd_can_df);
  PRINT_FLAG (nbd_can_flush);
  PRINT_FLAG (nbd_can_fua);
  PRINT_FLAG (nbd_can_multi_conn);
  PRINT_FLAG (nbd_can_trim);
  PRINT_FLAG (nbd_can_zero);
#if LIBNBD_HAVE_NBD_CAN_FAST_ZERO
  /* Añadido en 1.2 */
  PRINT_FLAG (nbd_can_fast_zero);
#endif
#if LIBNBD_HAVE_NBD_CAN_BLOCK_STATUS_PAYLOAD
  /* Añadido en 1.18 */
  PRINT_FLAG (nbd_can_block_status_payload);
#endif
  PRINT_FLAG (nbd_is_read_only);
  PRINT_FLAG (nbd_is_rotational);
  /* Cerrar el handle de libnbd. */
  nbd_close (nbd);
  exit (EXIT_SUCCESS);
}

VER TAMBIÉN

nbd_create(3), nbd_opt_info(3), "Llamadas a flags" en libnbd(3), "Multi-conn" en libnbd(3), libnbd(3).

nbd-client.3 - Manual de nbdsendclient

SINOPSIS

nbd-client [-b] [<servidor> [<puerto>]] [<opciones>]

DESCRIPCIÓN

El programa nbd-client es una implementación de cliente para el protocolo NBD (Network Block Device). Permite conectar un dispositivo de bloque de red y montarlo en el sistema local. Este cliente puede conectarse a cualquier servidor NBD que implemente el protocolo NBD.

OPCIONES

--host <servidor>
Especifica el nombre del host o la dirección IP del servidor NBD.
--port <puerto>
Especifica el número de puerto del servidor NBD. El valor predeterminado es 10809.
-d, --device <dispositivo>
Especifica el dispositivo NBD que se va a utilizar en el sistema local (por ejemplo, /dev/nbd0).
-s, --size <tamaño>
Especifica el tamaño del dispositivo NBD en bytes. Si no se especifica, se intenta obtener de forma interactiva.
-r, --readonly
Conecta el dispositivo en modo de solo lectura.
-k, --key <clave>
Especifica la clave secreta para la autenticación con el servidor NBD.
-c, --connect
Conecta el dispositivo y sale. Sin esta opción, el cliente entra en modo interactivo.
-u, --disconnect
Desconecta el dispositivo NBD.
-t, --timeout <segundos>
Establece un tiempo de espera para las operaciones de red en segundos.
-n, --nbds-max <número>
Establece el número máximo de dispositivos NBD que se pueden utilizar localmente.
-i, --export-name <nombre_exportación>
Especifica el nombre de la exportación en el servidor NBD a la que conectarse.
-v, --version
Muestra la información de la versión y sale.
-h, --help
Muestra un mensaje de ayuda y sale.

EJEMPLOS

Conectarse a un servidor NBD en el host "myserver" y montar la exportación "myexport" en /dev/nbd0:

nbd-client --host myserver --export-name myexport /dev/nbd0

Conectarse a un servidor NBD en 192.168.1.100 en el puerto 10809 y montar en modo de solo lectura:

nbd-client --host 192.168.1.100 --port 10809 -r /dev/nbd1

Desconectar el dispositivo /dev/nbd0:

nbd-client -u /dev/nbd0

ERRORES

Los errores se imprimirán en la salida de error estándar (stderr).

MANEJO DE ESTADO

El cliente maneja los estados de conexión y desconexión del dispositivo NBD. En caso de error de red o interrupción, el cliente intentará reconectarse si es posible, o informará del error.

VERSIÓN

La versión actual del cliente NBD.

EJEMPLO

Vea la sección de EJEMPLOS.
