nbd_add_meta_context(3) LIBNBD nbd_add_meta_context(3)

NOMBRE

nbd_add_meta_context - solicitar al servidor que negocie un contexto de metadatos

SINOPSIS

#include <libnbd.h>
int nbd_add_meta_context (
      struct nbd_handle *h, const char *name
    );

DESCRIPCIÓN

Durante la conexión, libnbd puede negociar cero o más contextos de metadatos con el servidor. Los contextos de metadatos son características (como "base:allocation") que describen la información devuelta por el comando nbd_block_status_64(3) (para "base:allocation", esto indica si los bloques de datos están asignados, son cero o dispersos).

Esta llamada añade un contexto de metadatos a la lista que se va a negociar. Puede llamarla tantas veces como sea necesario. La lista está inicialmente vacía cuando se crea el manejador; puede comprobar el contenido de la lista con nbd_get_nr_meta_contexts(3) y nbd_get_meta_context(3), o limpiarla con nbd_clear_meta_contexts(3).

El protocolo NBD limita los nombres de contexto de metadatos a 4096 bytes, pero los servidores pueden no admitir la longitud completa. La codificación de los nombres de contexto de metadatos es siempre UTF-8.

No todos los servidores admiten todos los contextos de metadatos. Para saber si un contexto se negoció realmente, llame a nbd_can_meta_context(3) después de conectarse.

El único parámetro es el nombre del contexto de metadatos, por ejemplo "LIBNBD_CONTEXT_BASE_ALLOCATION". <libnbd.h> incluye constantes definidas que empiezan por "LIBNBD_CONTEXT_" para algunos contextos conocidos, pero puede pasar otros contextos libremente.

Otros contextos de metadatos son específicos del servidor, pero incluyen "qemu:dirty-bitmap:..." y "qemu:allocation-depth" para qemu-nbd (véase las opciones -B y -A de qemu-nbd).

VALOR DE RETORNO

Si la llamada es exitosa, la función devuelve 0.

ERRORES

En caso de error, se devuelve -1.

Consulte "MANEJO DE ERRORES" en libnbd(3) para obtener más detalles sobre el error.

Los siguientes parámetros no deben ser NULL: "h", "name". Para más información, consulte "Parámetros no nulos" en libnbd(3).

ESTADO DEL MANEJADOR

nbd_add_meta_context puede llamarse cuando el manejador se encuentra en los siguientes estados:

┌─────────────────────────────────────┬─────────────────────────┐
│ Manejador creado, antes de conectar   │ ✅ permitido              │
│ Conectando                          │ ❌ error                │
│ Conectando y handshake (opt_mode) │ ✅ permitido              │
│ Conectado al servidor             │ ❌ error                │
│ Conexión cerrada                   │ ❌ error                │
│ Manejador muerto                    │ ❌ error                │
└─────────────────────────────────────┴─────────────────────────┘

VERSIÓN

Esta función apareció por primera vez en libnbd 1.0.

Si necesita probar si esta función está disponible en tiempo de compilación, compruebe si el siguiente macro está definido:

#define LIBNBD_HAVE_NBD_ADD_META_CONTEXT 1
