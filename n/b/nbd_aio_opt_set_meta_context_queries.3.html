nbd_aio_opt_set_meta_context_queries(3)

Paquete: libnbd

Licencias: LGPL-2.1-or-later

nbd_aio_opt_set_meta_context_queries(3) LIBNBD nbd_aio_opt_set_meta_context_queries(3)

NOMBRE

nbd_aio_opt_set_meta_context_queries - seleccionar contextos meta específicos, con lista de consultas explícita

SINOPSIS

#include <libnbd.h>
typedef struct {
  int (*callback) (void *user_data, const char *name);
  void *user_data;
  void (*free) (void *user_data);
} nbd_context_callback;
typedef struct {
  int (*callback) (void *user_data, int *error);
  void *user_data;
  void (*free) (void *user_data);
} nbd_completion_callback;
int nbd_aio_opt_set_meta_context_queries (
      struct nbd_handle *h, char **queries,
      nbd_context_callback context_callback,
      nbd_completion_callback completion_callback
    );

DESCRIPCIÓN

Solicita que el servidor proporcione todos los contextos meta reconocidos pasados a través de "queries", junto con la exportación previamente especificada por la llamada más reciente a nbd_set_export_name(3) o nbd_connect_uri(3). Esto solo se puede usar si nbd_set_opt_mode(3) habilitó el modo de opciones. Normalmente, esta función es redundante, ya que nbd_opt_go(3) realiza automáticamente la misma tarea si las respuestas estructuradas o las cabeceras extendidas ya se han negociado. Pero el control manual sobre las solicitudes de contexto meta puede ser útil para pruebas detalladas de cómo un servidor maneja secuencias de negociación inusuales. A menudo, el uso de esta función se acopla con nbd_set_request_meta_context(3) para omitir la solicitud automática de contexto que normalmente realiza nbd_opt_go(3).

Para determinar cuándo se completa la solicitud, espere a que nbd_aio_is_connecting(3) devuelva falso. O proporcione la "completion_callback" opcional, que se invocará como se describe en "Callbacks de finalización" en libnbd(3), excepto que se retira automáticamente independientemente del valor de retorno. Tenga en cuenta que detectar si el servidor devuelve un error (como se hace con el valor de retorno de su contraparte síncrona) solo es posible con un callback de finalización.

VALOR DE RETORNO

Esta llamada devuelve un entero ≥ 0.

ERRORES

En caso de error, se devuelve -1.

Consulte "MANEJO DE ERRORES" en libnbd(3) para obtener más detalles sobre el error.

Los siguientes parámetros no deben ser NULL: "h", "queries". Para más información, consulte "Parámetros no nulos" en libnbd(3).

ESTADO DEL MANEJADOR

nbd_aio_opt_set_meta_context_queries se puede llamar cuando el manejador se encuentra en el siguiente estado:

┌─────────────────────────────────────┬─────────────────────────┐
│ Manejador creado, antes de conectar │ ❌ error                │
│ Conectando                          │ ❌ error                │
│ Conectando y handshaking (opt_mode) │ ✅ permitido              │
│ Conectado al servidor             │ ❌ error                │
│ Conexión cerrada                 │ ❌ error                │
│ Manejador muerto                      │ ❌ error                │
└─────────────────────────────────────┴─────────────────────────┘

VERSIÓN

Esta función apareció por primera vez en libnbd 1.16.

Si necesita comprobar si esta función está disponible en tiempo de compilación, compruebe si la siguiente macro está definida:

#define LIBNBD_HAVE_NBD_AIO_OPT_SET_META_CONTEXT_QUERIES 1

nbd-client(8) - cliente de dispositivo de bloque de red

nbd-client es un cliente para el dispositivo de bloque de red (NBD). Permite montar dispositivos de almacenamiento remotos a través de la red.

Sintaxis

nbd-client <servidor> <puerto> /dev/nbdX [-S <servidor>] [-p <puerto>] [-N <exportacion>] [-b <tamano_bloque>] [-B <tamano_prefijo>] [-t <tiempo_espera>] [-u] [-C <socket_de_control>] [-o <opciones>]
nbd-client -d /dev/nbdX [-C <socket_de_control>]

Opciones

  • <servidor>: La dirección IP o el nombre de host del servidor NBD.
  • <puerto>: El número de puerto en el que se ejecuta el servidor NBD.
  • /dev/nbdX: El dispositivo de bloque de red local que se creará (por ejemplo, /dev/nb0).
  • -S <servidor>: Especifica el servidor NBD.
  • -p <puerto>: Especifica el puerto del servidor NBD.
  • -N <exportacion>: Especifica el nombre de la exportación en el servidor NBD.
  • -b <tamano_bloque>: Establece el tamaño del bloque para las solicitudes NBD.
  • -B <tamano_prefijo>: Establece el tamaño del prefijo para las solicitudes NBD.
  • -t <tiempo_espera>: Establece el tiempo de espera en segundos para las operaciones.
  • -u: Utiliza una conexión Unix domain socket en lugar de TCP/IP.
  • -C <socket_de_control>: Especifica la ruta al socket de control para la comunicación con el demonio nbd.
  • -o <opciones>: Pasa opciones adicionales al controlador NBD.
  • -d /dev/nbdX: Desconecta el dispositivo NBD especificado.

Ejemplos

Conectar a un servidor NBD y montar una exportación:

nbd-client 192.168.1.100 10809 /dev/nb0 -N my_export

Desconectar un dispositivo NBD:

nbd-client -d /dev/nb0
