nbd_set_handle_name(3)

Paquete: libnbd

Licencias: LGPL-2.1-or-later

nbd_set_handle_name(3) LIBNBD nbd_set_handle_name(3)

NOMBRE

nbd_set_handle_name - establece el nombre del manejador

SINOPSIS

#include <libnbd.h>
int nbd_set_handle_name (
      struct nbd_handle *h, const char *handle_name
    );

DESCRIPCIÓN

Los manejadores tienen un nombre que es único dentro del proceso actual. El nombre del manejador se utiliza en la salida de depuración.

Los nombres de los manejadores se generan normalmente de forma automática y tienen el formato "nbd1", "nbd2", etc., pero opcionalmente puede usar esta llamada para dar a los manejadores un nombre que sea significativo para su aplicación, para facilitar la comprensión de la salida de depuración.

VALOR DE RETORNO

Si la llamada es exitosa, la función devuelve 0.

ERRORES

En caso de error, se devuelve -1.

Consulte "MANEJO DE ERRORES" en libnbd(3) para obtener más detalles sobre el error.

Los siguientes parámetros no deben ser NULL: "h", "handle_name". Para más información, consulte "Parámetros no NULL" en libnbd(3).

VERSIÓN

Esta función apareció por primera vez en libnbd 1.0.

Si necesita comprobar si esta función está disponible en tiempo de compilación, verifique si el siguiente macro está definido:

#define LIBNBD_HAVE_NBD_SET_HANDLE_NAME 1

VEASE TAMBIÉN

nbd_create(3), nbd_get_handle_name(3), libnbd(3).
