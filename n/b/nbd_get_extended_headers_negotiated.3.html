nbd_get_extended_headers_negotiated(3) LIBNBD nbd_get_extended_headers_negotiated(3)

NOMBRE

nbd_get_extended_headers_negotiated - comprueba si se están utilizando encabezados extendidos

SINOPSIS

#include <libnbd.h>
int nbd_get_extended_headers_negotiated (
      struct nbd_handle *h
    );

DESCRIPCIÓN

Después de conectar, puede llamar a esta función para saber si la conexión está utilizando encabezados extendidos. Tenga en cuenta que esta configuración es persistente; puede devolver verdadero incluso después de que un segundo nbd_opt_extended_headers(3) devuelva falso porque el servidor detectó una solicitud duplicada.

Cuando no se utilizan encabezados extendidos, los comandos se limitan a una longitud de 32 bits, incluso cuando la API libnbd utiliza un parámetro de 64 bits para expresar la longitud. Pero incluso cuando se admiten encabezados extendidos, el servidor puede imponer otros límites, visibles a través de nbd_get_block_size(3).

Tenga en cuenta que cuando se negocian encabezados extendidos, debe preferir el uso de nbd_block_status_64(3) en lugar de nbd_block_status(3) si alguno de los metacontextos que solicitó a través de nbd_add_meta_context(3) podría devolver valores de estado de 64 bits; sin embargo, todos los metacontextos conocidos cubiertos por las constantes actuales de "LIBNBD_CONTEXT_*" solo devuelven estados de 32 bits.

VALOR DE RETORNO

Esta llamada devuelve un valor booleano.

ERRORES

En caso de error, se devuelve -1.

Consulte "MANEJO DE ERRORES" en libnbd(3) para obtener más detalles sobre el error.

Los siguientes parámetros no deben ser NULL: "h". Para más información, consulte "Parámetros no NULL" en libnbd(3).

ESTADO DEL MANEJADOR

nbd_get_extended_headers_negotiated se puede llamar cuando el manejador se encuentra en los siguientes estados:

┌─────────────────────────────────────┬─────────────────────────┐
│ Manejador creado, antes de conectar │ ❌ error                │
│ Conectando                          │ ❌ error                │
│ Conectando y en proceso de handshake (opt_mode) │ ✅ permitido              │
│ Conectado al servidor             │ ✅ permitido              │
│ Conexión cerrada                │ ✅ permitido              │
│ Manejador inactivo                         │ ❌ error                │
└─────────────────────────────────────┴─────────────────────────┘

VERSIÓN

Esta función apareció por primera vez en libnbd 1.18.

Si necesita probar si esta función está disponible en tiempo de compilación, compruebe si está definido el siguiente macro:

#define LIBNBD_HAVE_NBD_GET_EXTENDED_HEADERS_NEGOTIATED 1
