nbd_connect_socket(3) LIBNBD nbd_connect_socket(3)

NOMBRE

nbd_connect_socket - conectar directamente a un socket conectado

SINOPSIS

#include <libnbd.h>
int nbd_connect_socket (
      struct nbd_handle *h, int sock
    );

DESCRIPCIÓN

Pasa un socket conectado "sock" a través del cual libnbd se comunicará con el servidor NBD.

El llamador es responsable de crear y conectar este socket por algún método, antes de pasarlo a libnbd.

Si esta llamada retorna sin error, la propiedad del socket se transfiere a libnbd. Libnbd cerrará el socket cuando se cierre el manejador. El llamador no debe usar el socket de ninguna manera.

Esta llamada retorna cuando se ha realizado la conexión. Por defecto, esto procede hasta la fase de transmisión, pero nbd_set_opt_mode(3) puede usarse para control manual sobre la negociación de opciones realizada antes de la fase de transmisión.

VALOR DE RETORNO

Si la llamada es exitosa, la función retorna 0.

ERRORES

En caso de error, se retorna -1.

Consulte "MANEJO DE ERRORES" en libnbd(3) para saber cómo obtener más detalles sobre el error.

Los siguientes parámetros no deben ser NULL: "h". Para más información, consulte "Parámetros no NULL" en libnbd(3).

ESTADO DEL MANEJADOR

nbd_connect_socket puede ser llamado cuando el manejador está en el siguiente estado:

┌─────────────────────────────────────┬─────────────────────────┐
│ Manejador creado, antes de conectar │ ✅ permitido             │
│ Conectando                          │ ❌ error                │
│ Conectando y handshake (opt_mode) │ ❌ error                │
│ Conectado al servidor             │ ❌ error                │
│ Conexión cerrada                   │ ❌ error                │
│ Manejador muerto                    │ ❌ error                │
└─────────────────────────────────────┴─────────────────────────┘

VERSIÓN

Esta función apareció por primera vez en libnbd 1.2.

Si necesita probar si esta función está disponible en tiempo de compilación, compruebe si el siguiente macro está definido:

#define LIBNBD_HAVE_NBD_CONNECT_SOCKET 1
