nbd_set_tls_hostname(3) LIBNBD nbd_set_tls_hostname(3)

NOMBRE

nbd_set_tls_hostname - establece el nombre de host TLS

SINOPSIS

#include <libnbd.h>
int nbd_set_tls_hostname (
      struct nbd_handle *h, const char *hostname
    );

DESCRIPCIÓN

Establece el nombre de host del servidor TLS. Esto se utiliza con preferencia al nombre de host proporcionado al conectarse (por ejemplo, a través de nbd_connect_tcp(3)), o cuando no hay un nombre de host explícito en absoluto (nbd_connect_unix(3)). Puede ser útil cuando se conecta a un proxy que está reenviando los datos al servidor final, para especificar el nombre del servidor final para que se pueda verificar el certificado del servidor.

Esta función puede llamarse independientemente de si TLS es compatible, pero no tendrá ningún efecto a menos que nbd_set_tls(3) también se utilice para solicitar o requerir TLS.

VALOR DE RETORNO

Si la llamada tiene éxito, la función devuelve 0.

ERRORES

En caso de error, se devuelve -1.

Consulte "MANEJO DE ERRORES" en libnbd(3) para obtener más detalles sobre el error.

Los siguientes parámetros no deben ser NULL: "h", "hostname". Para obtener más información, consulte "Parámetros no NULL" en libnbd(3).

ESTADO DEL MANEJADOR

nbd_set_tls_hostname puede llamarse cuando el manejador se encuentra en el siguiente estado:

┌─────────────────────────────────────┬─────────────────────────┐
│ Manejador creado, antes de conectar │ ✅ permitido             │
│ Conectando                          │ ❌ error                │
│ Conectando y estableciendo enlace (opt_mode) │ ❌ error                │
│ Conectado al servidor             │ ❌ error                │
│ Conexión cerrada                 │ ❌ error                │
│ Manejador muerto                        │ ❌ error                │
└─────────────────────────────────────┴─────────────────────────┘

VERSIÓN

Esta función apareció por primera vez en libnbd 1.22.

Si necesita probar si esta función está disponible en tiempo de compilación, compruebe si está definido el siguiente macro:

#define LIBNBD_HAVE_NBD_SET_TLS_HOSTNAME 1
