nbd_opt_list(3) LIBNBD nbd_opt_list(3)

NOMBRE

nbd_opt_list - solicita al servidor que liste todas las exportaciones durante la negociación

SINOPSIS

#include <libnbd.h>
typedef struct {
  int (*callback) (void *user_data, const char *name,
                   const char *description);
  void *user_data;
  void (*free) (void *user_data);
} nbd_list_callback;
int nbd_opt_list (
      struct nbd_handle *h,
      nbd_list_callback list_callback
    );

DESCRIPCIÓN

Solicita al servidor que liste todas las exportaciones que soporta. Esto solo se puede usar si nbd_set_opt_mode(3) habilitó el modo de opciones.

La función "list" se llama una vez por cada exportación anunciada, con cualquier "user_data" pasado a esta función, y con "name" y "description" suministrados por el servidor. Muchos servidores omiten las descripciones, en cuyo caso "description" será una cadena vacía. Recuerda que no es seguro llamar a nbd_set_export_name(3) dentro del contexto de la función de devolución de llamada; en su lugar, tu código debe copiar cualquier "name" necesario para su uso posterior después de que esta función se complete. Actualmente, el valor de retorno de la función de devolución de llamada se ignora, aunque se debe evitar un retorno de -1.

Para mayor comodidad, cuando esta función tiene éxito, devuelve el número de exportaciones que fueron anunciadas por el servidor.

No todos los servidores entienden esta solicitud, e incluso cuando se entiende, el servidor podría enviar intencionalmente una lista vacía para evitar ser una fuga de información, podría encontrar un error después de entregar resultados parciales, o podría negarse a responder más de una consulta por conexión para evitar negociaciones que no se resuelvan. Por lo tanto, esta función puede tener éxito incluso cuando no se informan exportaciones, o puede fallar pero tener una lista no vacía. Del mismo modo, el protocolo NBD no especifica un límite superior para el número de exportaciones que podrían anunciarse, por lo que el código del cliente debe ser consciente de que un servidor puede enviar una lista extensa.

Para nbd-server(1) necesitarás permitir que los clientes realicen solicitudes de lista agregando "allowlist=true" a la sección "[generic]" de /etc/nbd-server/config. Para qemu-nbd(8), una descripción se establece con -D.

VALOR DE RETORNO

Esta llamada devuelve un entero ≥ 0.

ERRORES

En caso de error, se devuelve -1.

Consulte "MANEJO DE ERRORES" en libnbd(3) para obtener más detalles sobre el error.

Los siguientes parámetros no deben ser NULL: "h". Para más información, consulte "Parámetros no NULL" en libnbd(3).

ESTADO DEL MANEJADOR

nbd_opt_list se puede llamar cuando el manejador está en el siguiente estado:

┌─────────────────────────────────────┬─────────────────────────┐
│ Manejador creado, antes de conectar │ ❌ error │
│ Conectando │ ❌ error │
│ Conectando y handshake (opt_mode) │ ✅ permitido │
│ Conectado al servidor │ ❌ error │
│ Conexión cerrada │ ❌ error │
│ Manejador muerto │ ❌ error │
└─────────────────────────────────────┴─────────────────────────┘

VERSIÓN

Esta función apareció por primera vez en libnbd 1.4.

Si necesitas probar si esta función está disponible en tiempo de compilación, comprueba si está definido el siguiente macro:

#define LIBNBD_HAVE_NBD_OPT_LIST 1

EJEMPLO

Este ejemplo también está disponible como examples/list-exports.c en el código fuente de libnbd.

/* Este ejemplo muestra cómo listar exportaciones NBD.
 *
 * Para probar esto con qemu-nbd:
 *   $ qemu-nbd -x "hello" -t -k /tmp/sock disk.img
 *   $ ./run examples/list-exports /tmp/sock
 *   [0] hello
 *   ¿Qué exportación conectar (-1 para salir)? 0
 *   Conectando a hello ...
 *   /tmp/sock: hello: tamaño = 2048 bytes
 *
 * Para probar esto con nbdkit (requiere 1.22):
 *   $ nbdkit -U /tmp/sock sh - <<\EOF
 *   case $1 in
 *     list_exports) echo NAMES; echo foo; echo foobar ;;
 *     open) echo "$3" ;;
 *     get_size) echo "$2" | wc -c ;;
 *     pread) echo "$2" | dd bs=1 skip=$4 count=$3 ;;
 *     *) exit 2 ;;
 *   esac
 *   EOF
 *   $ ./run examples/list-exports /tmp/sock
 *   [0] foo
 *   [1] foobar
 *   ¿Qué exportación conectar (-1 para salir)? 1
 *   Conectando a foobar ...
 *   /tmp/sock: foobar: tamaño = 7 bytes
 */
#include <stdio.h>
#include <stdlib.h>
#include <stdbool.h>
#include <stdint.h>
#include <string.h>
#include <inttypes.h>
#include <errno.h>
#include <libnbd.h>
struct export_list {
  int i;
  char **names;
};
/* Función de devolución de llamada para nbd_opt_list */
static int
list_one (void *opaque, const char *name,
          const char *description)
{
  struct export_list *l = opaque;
  char **names;
  printf ("[%d] %s\n", l->i, name);
  if (*description)
    printf ("  (%s)\n", description);
  names = realloc (l->names,
                   (l->i + 1) * sizeof *names);
  if (!names) {
    perror ("realloc");
    exit (EXIT_FAILURE);
  }
  names[l->i] = strdup (name);
  if (!names[l->i]) {
    perror ("strdup");
    exit (EXIT_FAILURE);
  }
  l->names = names;
  l->i++;
  return 0;
}
int
main (int argc, char *argv[])
{
  struct nbd_handle *nbd;
  int i;
  const char *name;
  int64_t size;
  struct export_list list = { 0 };
  if (argc != 2) {
    fprintf (stderr, "%s socket\n", argv[0]);
    exit (EXIT_FAILURE);
  }
  /* Crear el manejador libnbd. */
  nbd = nbd_create ();
  if (nbd == NULL) {
    fprintf (stderr, "%s\n", nbd_get_error ());
    exit (EXIT_FAILURE);
  }
  /* Establecer modo de opciones. */
  nbd_set_opt_mode (nbd, true);
  /* Conectarse al servidor NBD a través de un
   * socket de dominio Unix. Si no
   * terminamos en modo de opciones, entonces un
   * listado no es posible.
   */
  if (nbd_connect_unix (nbd, argv[1]) == -1) {
    fprintf (stderr, "%s\n", nbd_get_error ());
    exit (EXIT_FAILURE);
  }
  if (!nbd_aio_is_negotiating (nbd)) {
    fprintf (stderr, "El servidor no soporta "
             "el listado de exportaciones.\n");
    exit (EXIT_FAILURE);
  }
  /* Imprimir la lista de exportaciones. */
  if (nbd_opt_list (nbd,
                    (nbd_list_callback) {
                      .callback = list_one,
                      .user_data = &list, }) == -1) {
    fprintf (stderr, "%s\n", nbd_get_error ());
    exit (EXIT_FAILURE);
  }
  /* Mostrar la lista de exportaciones. */
  printf ("¿Qué exportación conectar? ");
  if (scanf ("%d", &i) != 1) exit (EXIT_FAILURE);
  if (i == -1) {
    if (nbd_opt_abort (nbd) == -1) {
      fprintf (stderr, "%s\n", nbd_get_error ());
      exit (EXIT_FAILURE);
    }
    nbd_close (nbd);
    exit (EXIT_SUCCESS);
  }
  if (i < 0 || i >= list.i) {
    fprintf (stderr, "índice %d fuera de rango", i);
    exit (EXIT_FAILURE);
  }
  name = list.names[i];
  printf ("Conectando a %s ...\n", name);
  /* Reanudar la conexión a la exportación elegida. */
  if (nbd_set_export_name (nbd, name) == -1 ||
      nbd_opt_go (nbd) == -1) {
    fprintf (stderr, "%s\n", nbd_get_error ());
    exit (EXIT_FAILURE);
  }
  /* Obtener el tamaño de la exportación. */
  size = nbd_get_size (nbd);
  if (size == -1) {
    fprintf (stderr, "%s\n", nbd_get_error ());
    exit (EXIT_FAILURE);
  }
  printf ("%s: %s: tamaño = %" PRId64 " bytes\n",
          argv[1], name, size);
  /* Liberar las exportaciones para la lista. */
  for (i = 0; i < list.i; ++i) {
    free (list.names[i]);
  }
  free (list.names);
  /* Cerrar el manejador NBD. */
  nbd_close (nbd);
  exit (EXIT_SUCCESS);
}

nbd_opt_list(3) — libnbd-1.22.5

NAME

nbd_opt_list, nbd_aio_opt_list - List available options

SYNOPSIS

#include <libnbd.h>

int
nbd_opt_list (NBD_STATE_T *nbd, const char *name,
              struct nbd_opt_list *list);
int
nbd_aio_opt_list (NBD_STATE_T *nbd, const char *name,
                  struct nbd_opt_list *list,
                  nbd_completion_callback *callback,
                  void *user_data);

DESCRIPTION

These functions query the NBD server for a list of available export names, and their metadata options. The server must support the NBD_OPT_EXPORT_NAMES option for these functions to work.

The name parameter is the name of the export to query. If it is NULL, then information about all exports on the server is returned.

list is an output parameter. On success, it will contain a list of available export names and their options. The caller is responsible for freeing the memory allocated for list->names and the strings within it using nbd_opt_list_free().

The nbd_aio_opt_list function is the asynchronous version of nbd_opt_list. It takes additional parameters callback and user_data. When the operation completes, the callback function is called with user_data and the result of the operation.

RETURN VALUE

On success, nbd_opt_list and nbd_aio_opt_list return 0. On error, they return -1.

ERRORS

See nbd_get_error(3).

HANDLE STATE

nbd_opt_list and nbd_aio_opt_list can be called when the NBD handle is in the NBD_STATE_CONNECTED or NBD_STATE_HANDSHAKE state.

VERSION

This function appeared in libnbd version 1.2.

EXAMPLE

#include <libnbd.h>
#include <stdio.h>
#include <stdlib.h>
#include <inttypes.h>

int
main (int argc, char **argv)
{
  NBD_STATE_T *nbd;
  struct nbd_opt_list list = { 0 };
  int i;
  int64_t size;
  const char *name;

  if (argc != 2) {
    fprintf (stderr, "Usage: %s <uri>\n", argv[0]);
    exit (EXIT_FAILURE);
  }

  nbd = nbd_create ();
  if (!nbd) {
    fprintf (stderr, "nbd_create failed: %s\n", nbd_get_error ());
    exit (EXIT_FAILURE);
  }

  if (nbd_connect_uri (nbd, argv[1]) < 0) {
    fprintf (stderr, "nbd_connect_uri failed: %s\n", nbd_get_error ());
    exit (EXIT_FAILURE);
  }

  /* Get the export name. */
  name = nbd_get_export_name (nbd);
  if (!name) {
    fprintf (stderr, "nbd_get_export_name failed: %s\n", nbd_get_error ());
    exit (EXIT_FAILURE);
  }

  /* List available options. */
  if (nbd_opt_list (nbd, name, &list) < 0) {
    fprintf (stderr, "nbd_opt_list failed: %s\n", nbd_get_error ());
    exit (EXIT_FAILURE);
  }

  /* Print the available options. */
  printf ("%s: Options for export %s:\n", argv[1], name);
  for (i = 0; i < list.i; i++) {
    printf ("  - %s\n", list.names[i]);
  }

  /* Read the size in bytes and print it. */
  size = nbd_get_size (nbd);
  if (size == -1) {
    fprintf (stderr, "%s\n", nbd_get_error ());
    exit (EXIT_FAILURE);
  }
  printf ("%s: %s: size = %" PRIi64 " bytes\n",
          argv[1], name, size);

  /* Close the libnbd handle. */
  nbd_close (nbd);

  /* Free the list of options. */
  nbd_opt_list_free (&list);

  exit (EXIT_SUCCESS);
}
