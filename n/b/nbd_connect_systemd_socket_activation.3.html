nbd_connect_systemd_socket_activation(3)

Paquete: libnbd

Licencias: LGPL-2.1-or-later

nbd_connect_systemd_socket_activation(3) LIBNBD nbd_connect_systemd_socket_activation(3)

NOMBRE

nbd_connect_systemd_socket_activation - conectar usando activación de socket de systemd

SINOPSIS

#include <libnbd.h>
int nbd_connect_systemd_socket_activation (
      struct nbd_handle *h, char **argv
    );

DESCRIPCIÓN

Ejecuta el comando como un subproceso y se conecta a él usando la activación de socket de systemd.

Esto es especialmente útil para ejecutar qemu-nbd(1) como un subproceso de libnbd, por ejemplo, para usarlo para abrir archivos qcow2.

Para ejecutar nbdkit como un subproceso, se puede usar esta función, o nbd_connect_command(3).

Para ejecutar nbd-server(1) como un subproceso, no se puede usar esta función, se debe usar nbd_connect_command(3).

Activación de socket

Libnbd hará un fork del comando "argv" y le pasará un socket NBD usando variables de entorno especiales "LISTEN_*" (como se define en el protocolo de activación de sockets de systemd).

┌─────────┬─────────┐    ┌───────────────┐
│ programa │ libnbd  │    │  qemu-nbd o  │
│         │         │    │  otro servidor │
│         │ socket ╍╍╍╍╍╍╍╍▶             │
└─────────┴─────────┘    └───────────────┘

Cuando se cierra el manejador NBD, el subproceso servidor se mata.

Nombre del socket

El protocolo de activación de sockets te permite opcionalmente darle un nombre al socket. Si se usa, el nombre se pasa al servidor NBD a través de la variable de entorno "LISTEN_FDNAMES". Para proporcionar un nombre de socket, llama a nbd_set_socket_activation_name(3) antes de llamar a la función de conexión.

Esta llamada regresa cuando se ha realizado la conexión. Por defecto, esto procede hasta la fase de transmisión, pero nbd_set_opt_mode(3) puede usarse para un control manual sobre la negociación de opciones realizada antes de la fase de transmisión.

VALOR DE RETORNO

Si la llamada es exitosa, la función devuelve 0.

ERRORES

En caso de error, se devuelve -1.

Consulta "MANEJO DE ERRORES" en libnbd(3) para saber cómo obtener más detalles sobre el error.

Los siguientes parámetros no deben ser NULL: "h", "argv". Para más información, consulta "Parámetros no nulos" en libnbd(3).

ESTADO DEL MANEJADOR

nbd_connect_systemd_socket_activation puede ser llamado cuando el manejador está en el siguiente estado:

┌─────────────────────────────────────┬─────────────────────────┐
│ Manejador creado, antes de conectar │ ✅ permitido              │
│ Conectando                          │ ❌ error                │
│ Conectando y handshake (opt_mode) │ ❌ error                │
│ Conectado al servidor             │ ❌ error                │
│ Conexión cerrada                   │ ❌ error                │
│ Manejador muerto                      │ ❌ error                │
└─────────────────────────────────────┴─────────────────────────┘

VERSIÓN

Esta función apareció por primera vez en libnbd 1.2.

Si necesitas probar si esta función está disponible en tiempo de compilación, verifica si el siguiente macro está definido:

#define LIBNBD_HAVE_NBD_CONNECT_SYSTEMD_SOCKET_ACTIVATION 1

EJEMPLO

Este ejemplo también está disponible como examples/open-qcow2.c en el código fuente de libnbd.

/* Este ejemplo muestra cómo usar qemu-nbd
 * para abrir un archivo qcow2 local.
 */
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <libnbd.h>
int
main (int argc, const char *argv[])
{
  const char *filename;
  struct nbd_handle *nbd;
  char buf[512];
  FILE *fp;
  if (argc != 2) {
    fprintf (stderr, "open-qcow2 file.qcow2\n");
    exit (EXIT_FAILURE);
  }
  filename = argv[1];
  /* Crear el manejador libnbd. */
  nbd = nbd_create ();
  if (nbd == NULL) {
    fprintf (stderr, "%s\n", nbd_get_error ());
    exit (EXIT_FAILURE);
  }
  /* Ejecutar qemu-nbd como un subproceso usando
   * activación de socket de systemd.
   */
  char *args[] = {
    "qemu-nbd", "-f", "qcow2",
    (char *)filename,
    NULL
  };
  if (nbd_connect_systemd_socket_activation (nbd,
                                             args) == -1) {
    fprintf (stderr, "%s\n", nbd_get_error ());
    exit (EXIT_FAILURE);
  }
  /* Leer el primer sector y mostrarlo. */
  if (nbd_pread (nbd, buf, sizeof buf, 0, 0) == -1) {
    fprintf (stderr, "%s\n", nbd_get_error ());
    exit (EXIT_FAILURE);
  }
  fp = popen ("hexdump -C", "w");
  if (fp == NULL) {
    perror ("popen: hexdump");
    exit (EXIT_FAILURE);
  }
  fwrite (buf, sizeof buf, 1, fp);
  pclose (fp);
  /* Cerrar el manejador libnbd. */
  nbd_close (nbd);
  exit (EXIT_SUCCESS);
}
