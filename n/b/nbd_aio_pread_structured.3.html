nbd_aio_pread_structured(3) LIBNBD nbd_aio_pread_structured(3)

NOMBRE

nbd_aio_pread_structured - leer desde el servidor NBD

SINOPSIS

#include <libnbd.h>
typedef struct {
  int (*callback) (void *user_data, const void *subbuf,
                   size_t count, uint64_t offset,
                   unsigned status, int *error);
  void *user_data;
  void (*free) (void *user_data);
} nbd_chunk_callback;
typedef struct {
  int (*callback) (void *user_data, int *error);
  void *user_data;
  void (*free) (void *user_data);
} nbd_completion_callback;
int64_t nbd_aio_pread_structured (
          struct nbd_handle *h, void *buf, size_t count,
          uint64_t offset,
          nbd_chunk_callback chunk_callback,
          nbd_completion_callback completion_callback,
          uint32_t flags
        );

DESCRIPCIÓN

Emite un comando de lectura al servidor NBD.

Para comprobar si el comando se completó, llame a nbd_aio_command_completed(3). O proporcione el "completion_callback" opcional que se invocará como se describe en "Callbacks de finalización" en libnbd(3).

Tenga en cuenta que debe asegurarse de que "buf" sea válido hasta que el comando se haya completado. Además, si el parámetro "error" del "completion_callback" se establece o si nbd_aio_command_completed(3) informa de un fallo, y si nbd_get_pread_initialize(3) devuelve verdadero, entonces libnbd ha sanitizado "buf", pero no se especifica si los contenidos de "buf" se leerán como cero o como resultados parciales del servidor. Si nbd_get_pread_initialize(3) devuelve falso, entonces libnbd no sanitizó "buf", y los contenidos no están definidos en caso de fallo.

Otros parámetros se comportan como se documenta en nbd_pread_structured(3).

Por defecto, libnbd rechazará los intentos de usar esta función con parámetros que probablemente resulten en un fallo del servidor, como solicitar una bandera de comando desconocida. La función nbd_set_strict_mode(3) puede usarse para alterar qué escenarios deben esperar una respuesta del servidor en lugar de fallar rápidamente.

VALOR DE RETORNO

Esta llamada devuelve la cookie de 64 bits del comando. La cookie es ≥ 1. Las cookies son únicas (por manejador libnbd, no globalmente).

ERRORES

En caso de error, se devuelve -1.

Consulte "MANEJO DE ERRORES" en libnbd(3) para saber cómo obtener más detalles sobre el error.

Los siguientes parámetros no deben ser NULL: "h", "buf". Para más información, consulte "Parámetros no nulos" en libnbd(3).

ESTADO DEL MANEJADOR

nbd_aio_pread_structured puede llamarse cuando el manejador está en el siguiente estado:

┌─────────────────────────────────────┬─────────────────────────┐
│ Manejador creado, antes de conectar │ ❌ error                │
│ Conectando                          │ ❌ error                │
│ Conectando y handshake (opt_mode) │ ❌ error                │
│ Conectado al servidor             │ ✅ permitido            │
│ Conexión cerrada                   │ ❌ error                │
│ Manejador muerto                      │ ❌ error                │
└─────────────────────────────────────┴─────────────────────────┘

VERSIÓN

Esta función apareció por primera vez en libnbd 1.0.

Si necesita probar si esta función está disponible en tiempo de compilación, compruebe si el siguiente macro está definido:

#define LIBNBD_HAVE_NBD_AIO_PREAD_STRUCTURED 1

nbd_aio_pread_structured

nbd_aio_pread_structured - Leer datos de forma asíncrona y estructurada

Sintaxis

#include <libnbd.h>

int nbd_aio_pread_structured (NBD_T *nbd,
                              uint64_t offset,
                              struct nbd_structured_buf *buffers,
                              size_t num_buffers,
                              int flags,
                              nbd_completion_callback callback,
                              void *callback_data);

Descripción

nbd_aio_pread_structured intenta leer datos de forma asíncrona desde el dispositivo nbd en offset. La cantidad y la ubicación de los datos a leer se especifican mediante la matriz buffers.

Cada elemento de la matriz buffers es una estructura nbd_structured_buf: 

struct nbd_structured_buf {
    void *buf;
    size_t count;
    uint64_t offset;
};

Cada miembro buf en buffers debe apuntar a un búfer válido con al menos count bytes de tamaño. El miembro offset se utiliza para indicar dónde se deben escribir los datos dentro del búfer asignado. Si offset es 0, los datos se escribirán al principio del búfer.

El número total de bytes solicitados es la suma de todos los miembros count en la matriz buffers.

Los flags se pasan directamente al servidor nbd. Ver nbd_pread para más detalles.

Cuando la operación se completa, callback se invoca con callback_data. El parámetro result pasado a callback es 0 si tuvo éxito, o un código de error negativo si falla.

No todos los servidores nbd admiten la lectura estructurada. Si el servidor no lo admite, entonces nbd_aio_pread_structured devolverá -EOPNOTSUPP.

Ejemplo

// Búfer para almacenar los datos leídos
char buf1[1024];
char buf2[512];

// Estructuras de búfer
struct nbd_structured_buf buffers[] = {
    { .buf = buf1, .count = sizeof(buf1), .offset = 0 },
    { .buf = buf2, .count = sizeof(buf2), .offset = 1024 }, // Offset en el disco
};

// Función de devolución de llamada para manejar el resultado
void my_callback(int result, void *callback_data) {
    if (result == 0) {
        // Datos leídos correctamente
        printf("Lectura completada con éxito.\n");
    } else {
        fprintf(stderr, "Error al leer: %d\n", result);
    }
}

// Realizar la lectura asíncrona
int ret = nbd_aio_pread_structured(nbd_handle, 0, buffers, 2, 0, my_callback, NULL);
if (ret && ret != -EINPROGRESS) {
    fprintf(stderr, "Error al iniciar la lectura asíncrona: %d\n", ret);
}
