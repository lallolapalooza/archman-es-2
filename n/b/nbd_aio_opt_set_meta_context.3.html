Paquete: libnbd

Licencias: LGPL-2.1-or-later

nbd_aio_opt_set_meta_context(3) LIBNBD nbd_aio_opt_set_meta_context(3)

NOMBRE

nbd_aio_opt_set_meta_context - seleccionar contextos meta específicos, con lista de consulta implícita

SINOPSIS

#include <libnbd.h>
typedef struct {
  int (*callback) (void *user_data, const char *name);
  void *user_data;
  void (*free) (void *user_data);
} nbd_context_callback;
typedef struct {
  int (*callback) (void *user_data, int *error);
  void *user_data;
  void (*free) (void *user_data);
} nbd_completion_callback;
int nbd_aio_opt_set_meta_context (
      struct nbd_handle *h,
      nbd_context_callback context_callback,
      nbd_completion_callback completion_callback
    );

DESCRIPCIÓN

Solicita que el servidor proporcione todos los contextos meta reconocidos registrados a través de llamadas anteriores a nbd_add_meta_context(3), junto con la exportación especificada previamente por la llamada más reciente a nbd_set_export_name(3) o nbd_connect_uri(3). Esto solo se puede usar si nbd_set_opt_mode(3) habilitó el modo de opciones. Normalmente, esta función es redundante, ya que nbd_opt_go(3) realiza automáticamente la misma tarea si ya se han negociado respuestas estructuradas o encabezados extendidos. Pero el control manual sobre las solicitudes de contexto meta puede ser útil para pruebas detalladas de cómo un servidor maneja secuencias de negociación inusuales. A menudo, el uso de esta función se acopla con nbd_set_request_meta_context(3) para evitar la solicitud de contexto automática que normalmente realiza nbd_opt_go(3).

Para determinar cuándo se completa la solicitud, espere hasta que nbd_aio_is_connecting(3) devuelva false. O proporcione el opcional "completion_callback" que se invocará según se describe en "Callbacks de finalización" en libnbd(3), excepto que se retira automáticamente independientemente del valor de retorno. Tenga en cuenta que detectar si el servidor devuelve un error (como se hace con el valor de retorno de su contraparte síncrona) solo es posible con un callback de finalización.

VALOR DE RETORNO

Esta llamada devuelve un entero ≥ 0.

ERRORES

En caso de error, se devuelve -1.

Consulte "MANEJO DE ERRORES" en libnbd(3) para obtener más detalles sobre el error.

Los siguientes parámetros no deben ser NULL: "h". Para obtener más información, consulte "Parámetros no nulos" en libnbd(3).

ESTADO DEL MANEJADOR

nbd_aio_opt_set_meta_context se puede llamar cuando el manejador se encuentra en el siguiente estado:

┌─────────────────────────────────────┬─────────────────────────┐
│ Manejador creado, antes de conectar │ ❌ error                │
│ Conectando                          │ ❌ error                │
│ Conectando y handshake (opt_mode) │ ✅ permitido              │
│ Conectado al servidor             │ ❌ error                │
│ Conexión cerrada                   │ ❌ error                │
│ Manejador muerto                    │ ❌ error                │
└─────────────────────────────────────┴─────────────────────────┘

VERSIÓN

Esta función apareció por primera vez en libnbd 1.16.

Si necesita probar si esta función está disponible en tiempo de compilación, verifique si está definido el siguiente macro:

#define LIBNBD_HAVE_NBD_AIO_OPT_SET_META_CONTEXT 1

nbd_aio_opt_set_meta_context(3)

nbd_aio_opt_set_meta_context - Establece el contexto de metadatos para una solicitud de E/S asíncrona.

Sintaxis

#include <libnbd.h>

void nbd_aio_opt_set_meta_context(NBD_AIO *aio, void *meta_context);

Descripción

La función nbd_aio_opt_set_meta_context se utiliza para asociar un contexto de metadatos definido por el usuario con una solicitud de E/S asíncrona (aio). Este contexto puede ser cualquier puntero a datos que el usuario necesite recuperar cuando se complete la solicitud de E/S. Es una forma de pasar información personalizada a través de la pila de E/S.

Parámetros

  • aio: Un puntero a la estructura NBD_AIO que representa la solicitud de E/S asíncrona.
  • meta_context: Un puntero void* al contexto de metadatos que se asociará con la solicitud. Puede ser NULL si no se necesita ningún contexto.

Valor de retorno

Esta función no devuelve ningún valor.

Uso

Normalmente, llamarías a esta función inmediatamente después de crear una solicitud de E/S asíncrona pero antes de enviarla. Por ejemplo:


NBD_AIO *aio;
MyCustomMetadata *my_meta = malloc(sizeof(MyCustomMetadata));
// Rellenar my_meta ...

aio = nbd_aio_new(nbd_handle);
nbd_aio_opt_set_meta_context(aio, my_meta);
nbd_aio_read(aio, offset, length, callback, user_data);
// ...

Cuando se complete la devolución de llamada de nbd_aio_read, podrás acceder a my_meta a través de los datos pasados a la devolución de llamada (si se implementó correctamente para recuperar el contexto).

nbd_aio_new(3), nbd_aio_read(3), nbd_aio_write(3)
