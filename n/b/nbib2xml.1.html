SINOPSIS

DESCRIPCIÓN

El conjunto de programas bibutils interconvierte entre varios formatos de bibliografía usando el Metadata Object Description Schema (MODS)[2]versión 3.1 de la Biblioteca del Congreso[1]. Por ejemplo, se pueden convertir archivos en formato RIS a Bibtex realizando dos transformaciones: RIS->MODS->Bibtex.

CONVERSIÓN A MODS

Resumen

Comando Descripción
bib2xml convierte bibtex a MODS
biblatex2xml convierte biblatex a MODS
copac2xml convierte referencias en formato COPAC[3]a MODS
ebi2xml convierte EBI XML a MODS
end2xml convierte EndNote (formato Refer) a MODS
endx2xml convierte EndNote XML a MODS
isi2xml convierte ISI web of science a MODS
med2xml convierte referencias XML de Pubmed a MODS
nbib2xml convierte referencias en formato nbib de Pubmed a MODS
modsclean un conversor de MODS a MODS
ris2xml convierte formato RIS a MODS
wordbib2xml convierte XML de bibliografía de Word2007 a MODS

Opciones comunes para la conversión a MODS

Varias banderas disponibles para los programas end2xml, endx2xml, bib2xml, ris2xml, med2xml, y copac2xml. La mayoría de las opciones tienen una versión corta y una larga.

-h --help muestra la ayuda
-v --version muestra la versión
-a --add-refcount agrega "_#", donde # es el recuento de referencias al id de referencia
-s --single-refperfile coloca una referencia por archivo nombrado según el número de referencia
-i --input-encoding interpreta el archivo de entrada usando el conjunto de caracteres solicitado (úsese sin argumento para la lista actual derivada de los conjuntos de caracteres en www.kostis.net[4]) unicode es ahora una opción de conjunto de caracteres
-u --unicode-characters codifica los caracteres unicode directamente en el archivo en lugar de como entidades XML
-un --unicode-no-bom igual que -u, pero no incluye una marca de orden de bytes
-x --xml-entities codifica los caracteres unicode como entidades XML (opuesto a -u)
-nl --no-latex no convierte combinaciones de caracteres estilo latex
-s --single-refperfile una referencia por archivo de salida
-d --drop-key no incluye la clave de cita en el campo de id de mods
-c --corporation-file con un argumento que especifica un archivo que contiene una lista de nombres de corporaciones que se colocarán en <name type="corporate"></name> en lugar de type="personal" y elimina la manipulación de nombres
-a --asis con un argumento que especifica un archivo que contiene una lista de nombres que se tratarán literalmente
-nt --nosplit-title no divide los títulos en pares TÍTULO/SUBTÍTULO
--verbose salida detallada
--debug salida muy detallada (principalmente para depuración)

bib2xml

bib2xml convierte un archivo de referencias en formato bibtex a un archivo de bibliografía intermedio XML. Especifique los archivos a convertir en la línea de comandos. Los archivos que contienen cadenas de sustitución de bibtex deben especificarse antes de los archivos donde se especifican las sustituciones (o en el mismo archivo antes de su uso). Si no se especifican archivos, la información de bibtex se leerá de la entrada estándar.

bib2xml bibtex_file.bib > archivo_salida.xml

biblatex2xml

biblatex2xml convierte un archivo de referencias en formato biblatex (no confundir con bibtex) a un archivo de bibliografía intermedio XML MODS.

biblatex2xml biblatex_file.bib > archivodesalida.xml

copac2xml

copac2xml convierte un archivo de referencias en formato COPAC a un archivo de bibliografía intermedio XML MODS.

end2xml

end2xml convierte un archivo de referencias en formato endnote de texto a un archivo de bibliografía intermedio XML. Este programa no funcionará en la biblioteca binaria; el archivo debe exportarse primero. Los formatos etiquetados de Endnote (exportación en formato "Refer") se parecen al Ejemplo 1, «Ejemplo de archivo en formato refer». Hay instrucciones muy buenas para asegurarse de que está exportando correctamente en http://www.sonnysoftware.com/endnoteimport.html[5]

El uso para end2xml es el mismo que para bib2xml.

end2xml archivo_endnote.end > archivo_salida.xml

ebi2xml

ebi2xml convierte un archivo XML de EBI a un archivo de bibliografía intermedio XML MODS.

endx2xml

endx2xml convierte un archivo exportado de EndNote-XML a un archivo de bibliografía intermedio XML MODS. Este programa no funcionará en la biblioteca binaria; el archivo debe exportarse primero.

isi2xml

isi2xml convierte un archivo de referencias en formato ISI-web-of-science a un archivo de bibliografía intermedio XML.

El uso para isi2xml es el mismo que para bib2xml.

isi2xml archivo_entrada.isi > archivo_salida.xml

ris2xml

ris2xml convierte un archivo de referencias en formato RIS a un archivo de bibliografía intermedio XML. El uso de ris2xml es igual que el de end2xml y bib2xml

ris2xml archivo_ris.ris >	archivo_salida.xml

wordbib2xml

wordbib2xml convierte un archivo de referencias en formato Word2007 a un archivo de bibliografía intermedio XML.

Opciones Comunes al Convertir desde MODS

Nota que --output-encoding se refiere al archivo de entrada

-h --help mostrar ayuda
-v --version mostrar versión
-o --output-encoding interpretar el archivo de entrada como usando el conjunto de caracteres solicitado (usar sin argumento para la lista actual derivada de los conjuntos de caracteres en www.kostis.net[4]) unicode es ahora una opción de conjunto de caracteres
-s --single-refperfile poner una referencia por nombre de archivo según el número de referencia
-nb --no-bom no escribir Byte Order Mark si se escribe UTF8

xml2bib

xml2bib convierte la bibliografía XML de MODS a un archivo de referencia con formato bibtex. El uso de xml2bib es como el de otras herramientas

xml2bib xml_file.xml > output_file.bib

Dado que el formato de referencia BibTeX es bastante flexible y parece tener el mayor número de preferencias personales, también ha acumulado una serie de opciones específicas que no están disponibles para otros formatos.

A partir de la versión 3.24, la salida de xml2bib utiliza etiquetas en minúsculas y tipos de referencia en mayúsculas y minúsculas para una mejor interacción con otro software. El comportamiento anterior con etiquetas/tipos de referencia en mayúsculas se puede generar utilizando el modificador de línea de comandos -U/--uppercase.

Opciones específicas de xml2bib:

-fc --finalcomma agregar coma final en la salida bibtex para aquellos que la deseen
-sd --singledash usar un guion en lugar de dos (guion más largo en latex) entre números en la salida de páginas
-b --brackets usar corchetes en lugar de comillas alrededor de los datos de los campos
-w --whitespace agregar espacios en blanco para embellecer la salida
-U --uppercase usar todas las mayúsculas para etiquetas (nombres de campos) y tipos de referencia (comportamiento anterior a la versión 3.24)
-sk --strictkey usar solo caracteres alfanuméricos para las claves de citación bibtex

xml2ads

xml2ads convierte la bibliografía XML de MODS al formato de referencia de la base de datos Astrofísica (ADS) del Smithsonian Astrophysical Observatory (SAO)/National Aeronautics and Space Administration (NASA) (que es muy similar al estilo Endnote etiquetado). El uso de xml2ads es como el de otras herramientas

xml2ads xml_file.xml > output_file.ads

xml2ris

xml2ris convierte la bibliografía XML de MODS a un archivo de bibliografía con formato RIS. El uso de xml2ris es como el de otras herramientas

xml2ris xml_file.xml > output_file.ris

xml2end

xml2end convierte la bibliografía XML de MODS a un archivo de bibliografía de Endnote etiquetado (formato refer). El uso de xml2end es como el de otras herramientas

xml2end xml_file.xml >  output_file.end

xml2wordbib

xml2wordbib convierte la bibliografía XML de MODS a un archivo de bibliografía XML con formato Word 2007. El uso de xml2wordbib es como el de otras herramientas

xml2wordbib xml_file.xml >  output_file.word.xml

xml2wordbib se llamaba xml2word en versiones de bibutils anteriores a la 3.40. Se renombró para evitar confusiones con otras herramientas. Esperemos que esto no rompa demasiados scripts ya en uso.

Ejemplo 1. Archivo de ejemplo de formato refer

%0 Journal Article
%A C. D. Putnam
%A C. S. Pikaard
%D 1992
%T Cooperative binding of the Xenopus RNA polymerase I
   transcription factor xUBF to repetitive ribosomal gene enhancers
%J Mol Cell Biol
%V 12
%P 4970-4980
%F Putnam1992
