Paquete: libnbd

nbd_connect_command(3) LIBNBD nbd_connect_command(3)

NOMBRE

nbd_connect_command - conectar a un comando de servidor NBD

SINÓPSIS

#include <libnbd.h>
int nbd_connect_command (
      struct nbd_handle *h, char **argv
    );

DESCRIPCIÓN

Ejecuta el comando como un subproceso y se conecta a él a través de stdin/stdout. Esto es para usar con servidores NBD que pueden comportarse como clientes inetd, como nbdkit(1) usando la opción -s/--single, y nbd-server(1) con el número de puerto establecido en 0.

Para ejecutar qemu-nbd(1), usa en su lugar nbd_connect_systemd_socket_activation(3).

Subproceso

Libnbd creará un fork del comando "argv" y le pasará el socket NBD usando los descriptores de archivo 0 y 1 (stdin/stdout):

┌─────────┬─────────┐    ┌────────────────┐
│ programa │ libnbd  │    │   Servidor NBD   │
│         │         │    │       (argv)   │
│         │ socket ╍╍╍╍╍╍╍╍▶ stdin/stdout │
└─────────┴─────────┘    └────────────────┘

Cuando se cierre el handle de NBD, el subproceso del servidor será terminado.

Esta llamada retorna cuando se ha realizado la conexión. Por defecto, esto procede hasta la fase de transmisión, pero nbd_set_opt_mode(3) puede usarse para control manual sobre la negociación de opciones realizada antes de la fase de transmisión.

VALOR DE RETORNO

Si la llamada es exitosa, la función retorna 0.

ERRORES

En caso de error, se retorna -1.

Consulte "MANEJO DE ERRORES" en libnbd(3) para obtener más detalles sobre el error.

Los siguientes parámetros no deben ser NULL: "h", "argv". Para más información, consulte "Parámetros no nulos" en libnbd(3).

ESTADO DEL HANDLE

nbd_connect_command puede ser llamada cuando el handle está en el siguiente estado:

┌─────────────────────────────────────┬─────────────────────────┐
│ Handle creado, antes de conectar │ ✅ permitido              │
│ Conectando                          │ ❌ error                │
│ Conectando y handshake (opt_mode) │ ❌ error                │
│ Conectado al servidor             │ ❌ error                │
│ Conexión cerrada                   │ ❌ error                │
│ Handle muerto                       │ ❌ error                │
└─────────────────────────────────────┴─────────────────────────┘

VERSIÓN

Esta función apareció por primera vez en libnbd 1.0.

Si necesita probar si esta función está disponible en tiempo de compilación, compruebe si el siguiente macro está definido:

#define LIBNBD_HAVE_NBD_CONNECT_COMMAND 1

EJEMPLO

Este ejemplo también está disponible como examples/connect-command.c en el código fuente de libnbd.

/* Este ejemplo muestra cómo ejecutar un servidor NBD
 * (nbdkit) como subproceso de libnbd.
 */
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <libnbd.h>
int
main (int argc, char *argv[])
{
  struct nbd_handle *nbd;
  char wbuf[512], rbuf[512];
  size_t i;
  /* Crear el handle de libnbd. */
  nbd = nbd_create ();
  if (nbd == NULL) {
    fprintf (stderr, "%s\n", nbd_get_error ());
    exit (EXIT_FAILURE);
  }
  /* Ejecutar nbdkit como subproceso. */
  char *args[] = {
    "nbdkit",
    /* Debes usar ‘-s’ (que le indica a nbdkit que sirva
     * una única conexión en stdin/stdout).
     */
    "-s",
    /* Se recomienda usar ‘--exit-with-parent’
     * para asegurar que nbdkit siempre se limpie incluso
     * si el programa principal falla.
     */
    "--exit-with-parent",
    /* Usar esto para habilitar la depuración de nbdkit. */
    "-v",
    /* El nombre del plugin de nbdkit - este es un disco en RAM. */
    "memory", "size=1M",
    /* Usar NULL para terminar la lista de argumentos. */
    NULL
  };
  if (nbd_connect_command (nbd, args) == -1) {
    fprintf (stderr, "%s\n", nbd_get_error ());
    exit (EXIT_FAILURE);
  }
  /* Escribir algunos datos aleatorios en el primer sector. */
  for (i = 0; i < sizeof wbuf; ++i)
    wbuf[i] = i % 13;
  if (nbd_pwrite (nbd, wbuf, sizeof wbuf, 0, 0) == -1) {
    fprintf (stderr, "%s\n", nbd_get_error ());
    exit (EXIT_FAILURE);
  }
  /* Leer el primer sector de nuevo. */
  if (nbd_pread (nbd, rbuf, sizeof rbuf, 0, 0) == -1) {
    fprintf (stderr, "%s\n", nbd_get_error ());
    exit (EXIT_FAILURE);
  }
  /* Cerrar el handle de libnbd. */
  nbd_close (nbd);
  /* Lo que se leyó debe ser exactamente lo mismo que lo que
   * se escribió.
   */
  if (memcmp (rbuf, wbuf, sizeof rbuf) != 0) {
    fprintf (stderr, "FALLÓ: "
             "los datos leídos no coinciden con los datos escritos\n");
    exit (EXIT_FAILURE);
  }
  exit (EXIT_SUCCESS);
}

nbd_connect_command(3)

nbd_connect_command

nbd_connect_command - connect to an NBD server using a command

NAME

nbd_connect_command - connect to an NBD server using a command

SYNOPSIS

int nbd_connect_command(struct nbd_handle *nbd, const char *uri, void *cookie, nbd_completion_callback callback, void *userdata);

DESCRIPTION

Connects to an NBD server specified by uri. This function is asynchronous. When the connection is established or fails, callback is called with userdata as its argument. cookie is an opaque pointer that will be passed to the callback function.

RETURN VALUE

On success, 0 is returned. On error, -1 is returned and errno is set.

ERRORS

The following error codes are defined:

EINVAL
Invalid arguments.
ENOMEM
Out of memory.
EBUSY
The NBD handle is already in use.
EPERM
Permission denied.
EHOSTDOWN
Host is down.
ECONNREFUSED
Connection refused.
ETIMEDOUT
Connection timed out.
EPROTO
Protocol error.

HANDLE STATE

This function changes the state of the NBD handle to connecting.

VERSION

This function was introduced in version 1.20 of libnbd.

EXAMPLE


#include <libnbd.h>
#include <stdio.h>
#include <errno.h>

void connect_callback(struct nbd_handle *nbd, void *userdata) {
    int *error = userdata;
    if (nbd_get_error(nbd) == 0) {
        printf("Connected successfully!\n");
        *error = 0;
    } else {
        fprintf(stderr, "Connection failed: %s\n", nbd_get_error_message(nbd));
        *error = 1;
    }
}

int main() {
    struct nbd_handle *nbd = nbd_create();
    if (!nbd) {
        fprintf(stderr, "Failed to create NBD handle: %s\n", strerror(errno));
        return 1;
    }

    int error = -1; // Initialize with an error state
    nbd_connect_command(nbd, "nbd:example.com", NULL, connect_callback, &error);

    // In a real application, you would typically have an event loop here
    // to process events and wait for the callback. For this simple example,
    // we'll just spin until the error status is updated.
    while (error == -1) {
        nbd_poll_events(nbd, 1000); // Wait for 1 second for events
    }

    if (error == 0) {
        // Connection was successful, proceed with NBD operations
        // ...
    }

    nbd_shutdown(nbd);
    nbd_destroy(nbd);
    return error;
}
