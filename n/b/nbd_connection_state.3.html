NOMBRE

nbd_connection_state - devuelve una cadena que describe el estado de la conexión

SINOPSIS

#include <libnbd.h>
const char * nbd_connection_state (
               struct nbd_handle *h
             );

DESCRIPCIÓN

Devuelve una cadena descriptiva para el estado de la conexión. Esto puede ser usado para depuración o solución de problemas, pero no debes depender del estado de las conexiones ya que puede cambiar en futuras versiones.

VALOR DE RETORNO

Esta llamada devuelve una cadena asignada estáticamente, válida durante la vida del proceso o hasta que libnbd sea descargada por dlclose(3). No debes intentar liberar la cadena.

ERRORES

En caso de error se devuelve "NULL".

Consulta "MANEJO DE ERRORES" en libnbd(3) para saber cómo obtener más detalles del error.

Los siguientes parámetros no deben ser NULL: "h". Para más información consulta "Parámetros no NULL" en libnbd(3).

VERSIÓN

Esta función apareció por primera vez en libnbd 1.0.

Si necesitas comprobar si esta función está disponible en tiempo de compilación, comprueba si el siguiente macro está definido:

#define LIBNBD_HAVE_NBD_CONNECTION_STATE 1

VER TAMBIÉN

nbd_create(3), libnbd(3).
