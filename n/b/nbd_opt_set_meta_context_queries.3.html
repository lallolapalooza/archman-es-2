nbd_opt_set_meta_context_queries(3) LIBNBD nbd_opt_set_meta_context_queries(3)

NOMBRE

nbd_opt_set_meta_context_queries - seleccionar contextos meta específicos, usando una lista de consultas explícita

SINOPSIS

#include <libnbd.h>
typedef struct {
  int (*callback) (void *user_data, const char *name);
  void *user_data;
  void (*free) (void *user_data);
} nbd_context_callback;
int nbd_opt_set_meta_context_queries (
      struct nbd_handle *h, char **queries,
      nbd_context_callback context_callback
    );

DESCRIPCIÓN

Solicita que el servidor suministre todos los contextos meta reconocidos pasados a través de "queries", junto con la exportación previamente especificada por la llamada más reciente a nbd_set_export_name(3) o nbd_connect_uri(3). Esto solo se puede utilizar si nbd_set_opt_mode(3) habilitó el modo de opciones. Normalmente, esta función es redundante, ya que nbd_opt_go(3) realiza automáticamente la misma tarea si ya se han negociado respuestas estructuradas o cabeceras extendidas. Pero el control manual sobre las solicitudes de contexto meta puede ser útil para pruebas detalladas de cómo un servidor maneja secuencias de negociación inusuales. A menudo, el uso de esta función se acopla con nbd_set_request_meta_context(3) para evitar la solicitud automática de contexto que normalmente realiza nbd_opt_go(3).

El protocolo NBD permite a un cliente decidir cuántas consultas realizar al servidor. Esta función toma una lista explícita de consultas; para reutilizar una lista implícita, véase nbd_opt_set_meta_context(3). Dado que esta función está diseñada principalmente para probar servidores, libnbd no impide su uso en una lista vacía o cuando nbd_set_request_structured_replies(3) ha deshabilitado las respuestas estructuradas, para observar el comportamiento del servidor.

La función "context" se llama una vez por respuesta del servidor, con cualquier "user_data" pasado a esta función, y con "name" proporcionado por el servidor. Además, cada nombre de servidor permanecerá visible a través de nbd_can_meta_context(3) hasta el próximo intento de nbd_set_export_name(3) o nbd_opt_set_meta_context(3), así como las llamadas a nbd_opt_go(3) o nbd_opt_info(3) que desencadenan una solicitud automática de contexto meta. Recuerde que no es seguro llamar a ninguna API de "nbd_*" desde dentro del contexto de la función de devolución de llamada. Actualmente, el valor de retorno de la devolución de llamada se ignora, aunque se debe evitar un retorno de -1.

Como conveniencia, cuando esta función tiene éxito, devuelve el número de respuestas devueltas por el servidor.

No todos los servidores entienden esta solicitud, e incluso cuando se entiende, el servidor podría intencionalmente enviar una lista vacía porque no soporta el contexto solicitado, o podría encontrar un error después de entregar resultados parciales. Por lo tanto, esta función puede tener éxito incluso cuando no se informan contextos, o puede fallar pero tener una lista no vacía.

VALOR DE RETORNO

Esta llamada devuelve un entero ≥ 0.

ERRORES

En caso de error, se devuelve -1.

Consulte "MANEJO DE ERRORES" en libnbd(3) para obtener más detalles sobre el error.

Los siguientes parámetros no deben ser NULL: "h", "queries". Para más información, consulte "Parámetros no NULL" en libnbd(3).

ESTADO DEL MANEJADOR

nbd_opt_set_meta_context_queries puede ser llamado cuando el manejador se encuentra en el siguiente estado:

┌─────────────────────────────────────┬─────────────────────────┐
│ Manejador creado, antes de conectar  │ ❌ error                │
│ Conectando                          │ ❌ error                │
│ Conectando y handshake (opt_mode) │ ✅ permitido             │
│ Conectado al servidor             │ ❌ error                │
│ Conexión cerrada                   │ ❌ error                │
│ Manejador muerto                    │ ❌ error                │
└─────────────────────────────────────┴─────────────────────────┘

VERSIÓN

Esta función apareció por primera vez en libnbd 1.16.

Si necesita probar si esta función está disponible en tiempo de compilación, compruebe si el siguiente macro está definido:

#define LIBNBD_HAVE_NBD_OPT_SET_META_CONTEXT_QUERIES 1
