nbd_can_block_status_payload(3)

Paquete: libnbd

Licencias: LGPL-2.1-or-later

nbd_can_block_status_payload(3) LIBNBD nbd_can_block_status_payload(3)

NOMBRE

nbd_can_block_status_payload - ¿admite el servidor el flag de carga útil de estado de bloque?

SINÓPSIS

#include <libnbd.h>
int nbd_can_block_status_payload (
      struct nbd_handle *h
    );

DESCRIPCIÓN

Devuelve verdadero si el servidor admite el uso del flag "LIBNBD_CMD_FLAG_PAYLOAD_LEN" para permitir el filtrado del comando de estado de bloque (ver nbd_block_status_filter(3)). Devuelve falso si el servidor no lo admite. Tenga en cuenta que esto nunca devolverá verdadero si nbd_get_extended_headers_negotiated(3) es falso.

Esta llamada no bloquea, ya que devuelve datos que se guardan en el manejador desde el apretón de manos del protocolo NBD.

VALOR DE RETORNO

Esta llamada devuelve un valor booleano.

ERRORES

En caso de error se devuelve -1.

Consulte "MANEJO DE ERRORES" en libnbd(3) para saber cómo obtener más detalles sobre el error.

Los siguientes parámetros no deben ser NULL: "h". Para más información, consulte "Parámetros no nulos" en libnbd(3).

ESTADO DEL MANEJADOR

nbd_can_block_status_payload se puede llamar cuando el manejador se encuentra en los siguientes estados:

┌─────────────────────────────────────┬─────────────────────────┐
│ Manejador creado, antes de conectar   │ ❌ error                │
│ Conectando                          │ ❌ error                │
│ Conectando y apretando manos (opt_mode) │ ✅ permitido              │
│ Conectado al servidor             │ ✅ permitido              │
│ Conexión cerrada                │ ✅ permitido              │
│ Manejador inactivo                         │ ❌ error                │
└─────────────────────────────────────┴─────────────────────────┘

VERSIÓN

Esta función apareció por primera vez en libnbd 1.18.

Si necesita probar si esta función está disponible en tiempo de compilación compruebe si el siguiente macro está definido:

#define LIBNBD_HAVE_NBD_CAN_BLOCK_STATUS_PAYLOAD 1

EJEMPLO

Este ejemplo también está disponible como examples/server-flags.c en el código fuente de libnbd.

/* Este ejemplo muestra cómo conectarse a un servidor NBD
 * e imprimir los flags de exportación.
 *
 * Puedes probarlo con nbdkit así:
 *
 * nbdkit -U - memory 1M \
 *   --run './server-flags $unixsocket'
 */
#include <stdio.h>
#include <stdlib.h>
#include <stdbool.h>
#include <libnbd.h>
int
main (int argc, char *argv[])
{
  struct nbd_handle *nbd;
  char *str;
  int flag;
  if (argc != 2) {
    fprintf (stderr, "%s socket\n", argv[0]);
    exit (EXIT_FAILURE);
  }
  /* Crear el manejador de libnbd. */
  nbd = nbd_create ();
  if (nbd == NULL) {
    fprintf (stderr, "%s\n", nbd_get_error ());
    exit (EXIT_FAILURE);
  }
  /* Solicitar información completa. */
#if LIBNBD_HAVE_NBD_SET_FULL_INFO /* Añadido en 1.4 */
  if (nbd_set_full_info (nbd, true) == -1) {
    fprintf (stderr, "%s\n", nbd_get_error ());
    exit (EXIT_FAILURE);
  }
#endif
  /* Conectarse al servidor NBD a través de
   * un socket de dominio Unix.
   */
  if (nbd_connect_unix (nbd, argv[1]) == -1) {
    fprintf (stderr, "%s\n", nbd_get_error ());
    exit (EXIT_FAILURE);
  }
  /* Ver si el servidor proporcionó detalles adicionales,
   * usando funciones añadidas en 1.4
   */
#if LIBNBD_HAVE_NBD_GET_EXPORT_DESCRIPTION
  str = nbd_get_canonical_export_name (nbd);
  if (str)
    printf ("canonical_name = %s\n", str);
  free (str);
  str = nbd_get_export_description (nbd);
  if (str)
    printf ("description = %s\n", str);
  free (str);
#endif
  /* Leer e imprimir los flags. */
#define PRINT_FLAG(flag_fn)                     \
  flag = flag_fn (nbd);                         \
  if (flag == -1) {                             \
    fprintf (stderr, "%s\n", nbd_get_error ()); \
    exit (EXIT_FAILURE);                        \
  }                                             \
  printf (#flag_fn " = %s\n",                   \
          flag ? "true" : "false");
  PRINT_FLAG (nbd_can_cache);
  PRINT_FLAG (nbd_can_df);
  PRINT_FLAG (nbd_can_flush);
  PRINT_FLAG (nbd_can_fua);
  PRINT_FLAG (nbd_can_multi_conn);
  PRINT_FLAG (nbd_can_trim);
  PRINT_FLAG (nbd_can_zero);
#if LIBNBD_HAVE_NBD_CAN_FAST_ZERO
  /* Añadido en 1.2 */
  PRINT_FLAG (nbd_can_fast_zero);
#endif
#if LIBNBD_HAVE_NBD_CAN_BLOCK_STATUS_PAYLOAD
  /* Añadido en 1.18 */
  PRINT_FLAG (nbd_can_block_status_payload);
#endif
  PRINT_FLAG (nbd_is_read_only);
  PRINT_FLAG (nbd_is_rotational);
  /* Cerrar el manejador de libnbd. */
  nbd_close (nbd);
  exit (EXIT_SUCCESS);
}

SYNOPSIS


#include <libnbd.h>

int nbd_can_block_status_payload(NBD_CONNECTION *conn, int *can_block_status);

DESCRIPTION

The nbd_can_block_status_payload function checks if the NBD server connected to conn supports the block status payload extension.

This extension allows the server to send block status information (e.g. for TRIM/DISCARD operations) back to the client.

If the server supports this extension, can_block_status will be set to 1. Otherwise, it will be set to 0.

This function is asynchronous. You must call nbd_next_request to process the reply from the server.

RETURN VALUE

On success, nbd_can_block_status_payload returns 0 and sets can_block_status to 1 or 0.

On failure, it returns -1 and sets an error code accessible via nbd_get_errno.

ERRORS

nbd_get_errno can return the following error codes:

EINVAL
conn is not a valid NBD connection.
EFAULT
can_block_status is NULL.
EPROTO
The NBD server sent a reply that could not be parsed.
ECONNREFUSED
The connection to the NBD server was refused.
ECONNRESET
The connection to the NBD server was reset.
ETIMEDOUT
The connection to the NBD server timed out.

HANDLE STATE

This function does not change the state of the handle conn.

VERSION

This function was introduced in libnbd 1.10.

EXAMPLE


int can_block_status;
int ret;

ret = nbd_can_block_status_payload(conn, &can_block_status);
if (ret == -1) {
    fprintf(stderr, "Failed to check block status payload support: %s\n", strerror(nbd_get_errno(NULL)));
    exit(EXIT_FAILURE);
}

// Process the reply from the server.
while (nbd_next_request(conn) == 0) {
    // Handle the reply
}

if (can_block_status) {
    printf("Server supports block status payload.\n");
} else {
    printf("Server does not support block status payload.\n");
}
