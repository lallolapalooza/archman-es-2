nbd_close(3)

Paquete: libnbd

Licencias: LGPL-2.1-or-later

nbd_create(3) LIBNBD nbd_create(3)

NOMBRE

nbd_create, nbd_close, nbd_get_error, nbd_get_errno - crear manejadores libnbd y obtener errores

SINOPSIS

#include <libnbd.h>
struct nbd_handle *nbd;
struct nbd_handle *nbd_create (void);
void nbd_close (struct nbd_handle *nbd);
const char *nbd_get_error (void);
int nbd_get_errno (void);

DESCRIPCIÓN

struct nbd_handle es una estructura opaca que describe un manejador cliente NBD y la conexión a un servidor NBD.

Creación de un manejador libnbd

nbd_create crea un nuevo manejador. Devuelve un puntero a la estructura opaca del manejador.

En caso de error, devuelve "NULL". Consulte "MANEJO DE ERRORES" en libnbd(3) para obtener más detalles sobre el error.

Cierre de un manejador

nbd_close cierra el manejador, cerrando y liberando cualquier recurso asociado.

El estado final de cualquier comando que no haya sido retirado (ya sea por nbd_aio_command_completed(3) o por una devolución de llamada de finalización de bajo nivel que devuelva 1) se pierde.

Esta función no es segura de llamar mientras otro hilo esté usando cualquier API "nbd_*" en el mismo manejador. Esta función puede bloquearse en el caso de que esperemos a un subproceso (por ejemplo, uno creado con nbd_connect_command(3)).

Obtención del último mensaje de error en el hilo

nbd_get_error devuelve el mensaje de error más reciente en el hilo actual. El mensaje de error solo es válido si se llama inmediatamente después de la llamada fallida, desde el mismo hilo. La cadena de error devuelta será liberada la próxima vez que se llame a cualquier API de libnbd desde el mismo hilo, por lo que si necesita conservarla, debe hacer una copia.

Nunca debería devolver "NULL" siempre que se haya producido un error en la llamada de libnbd inmediatamente anterior en el hilo actual.

nbd_get_errno devuelve el "errno" más reciente en el hilo actual. No todos los errores tienen errnos correspondientes, por lo que incluso si ha habido un error, esto puede devolver 0. Los códigos de error son los estándar de "<errno.h>".

Consulte "MANEJO DE ERRORES" en libnbd(3) para una mayor discusión sobre cómo funciona el manejo de errores en libnbd.

EJEMPLO

#include <libnbd.h>
main ()
{
  struct nbd_handle *nbd;
  nbd = nbd_create ();
  if (nbd == NULL) {
    fprintf (stderr, "%s\n", nbd_get_error ());
    nbd_close (nbd);
    exit (EXIT_FAILURE);
  }
  nbd_close (nbd);
  exit (EXIT_SUCCESS);
}

VERSIÓN

Todas estas funciones estaban presentes en libnbd 1.0.
