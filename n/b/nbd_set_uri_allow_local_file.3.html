nbd_set_uri_allow_local_file(3)

nbd_set_uri_allow_local_file(3) LIBNBD nbd_set_uri_allow_local_file(3)

NOMBRE

nbd_set_uri_allow_local_file - establecer los transportes permitidos en las URI NBD

SINOPSIS

#include <libnbd.h>
int nbd_set_uri_allow_local_file (
      struct nbd_handle *h, bool allow
    );

DESCRIPCIÓN

Permite que las URI NBD hagan referencia a archivos locales. Esto está *deshabilitado* por defecto.

Actualmente, esta configuración solo controla si se permite el parámetro "tls-psk-file" en las URI NBD.

VALOR DE RETORNO

Si la llamada es exitosa, la función devuelve 0.

ERRORES

En caso de error, se devuelve -1.

Consulte "MANEJO DE ERRORES" en libnbd(3) para obtener más detalles sobre el error.

Los siguientes parámetros no deben ser NULL: "h". Para más información, consulte "Parámetros no NULL" en libnbd(3).

ESTADO DEL MANEJADOR

nbd_set_uri_allow_local_file puede llamarse cuando el manejador está en el siguiente estado:

┌─────────────────────────────────────┬─────────────────────────┐
│ Mananejador creado, antes de conectar   │ ✅ permitido              │
│ Conectando                          │ ❌ error                │
│ Conectando & handshake (opt_mode) │ ❌ error                │
│ Conectado al servidor             │ ❌ error                │
│ Conexión cerrada                 │ ❌ error                │
│ Mananejador muerto                  │ ❌ error                │
└─────────────────────────────────────┴─────────────────────────┘

VERSIÓN

Esta función apareció por primera vez en libnbd 1.2.

Si necesita probar si esta función está disponible en tiempo de compilación, compruebe si el siguiente macro está definido:

#define LIBNBD_HAVE_NBD_SET_URI_ALLOW_LOCAL_FILE 1

VER TAMBIÉN

nbd_connect_uri(3), nbd_create(3), libnbd(3).
