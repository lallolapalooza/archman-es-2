nbd_set_request_meta_context(3) LIBNBD nbd_set_request_meta_context(3)

NOMBRE

nbd_set_request_meta_context - controlar si la conexión solicita automáticamente contextos meta

SINOPSIS

#include <libnbd.h>
int nbd_set_request_meta_context (
      struct nbd_handle *h, bool request
    );

DESCRIPCIÓN

Esta función controla si el acto de conectarse a una exportación (todas las llamadas "nbd_connect_*" cuando nbd_set_opt_mode(3) es falso, o nbd_opt_go(3) y nbd_opt_info(3) cuando el modo de opción está habilitado) también intentará emitir NBD_OPT_SET_META_CONTEXT cuando el servidor soporte respuestas estructuradas o cabeceras extendidas y se hayan registrado contextos mediante nbd_add_meta_context(3). La configuración predeterminada es verdadera; sin embargo, el paso adicional de negociar contextos meta no siempre es deseable: realizar tanto info como go en la misma exportación funciona sin necesidad de renegociar contextos en la segunda llamada; las pruebas de integración de otros servidores pueden beneficiarse de la invocación manual de nbd_opt_set_meta_context(3) en otros momentos de la secuencia de negociación; e incluso cuando solo se usa nbd_opt_info(3), puede ser más rápido recopilar los resultados del servidor confiando en la función de devolución de llamada pasada a nbd_opt_list_meta_context(3) que una serie de llamadas de post-procesamiento a nbd_can_meta_context(3).

Tenga en cuenta que este control no tiene ningún efecto si el servidor no negocia respuestas estructuradas o cabeceras extendidas, o si el cliente no solicitó ningún contexto a través de nbd_add_meta_context(3). Establecer este control en falso puede provocar fallos en nbd_block_status(3).

VALOR DE RETORNO

Si la llamada es exitosa, la función devuelve 0.

ERRORES

En caso de error, se devuelve -1.

Consulte "MANEJO DE ERRORES" en libnbd(3) para obtener más detalles sobre el error.

Los siguientes parámetros no deben ser NULL: "h". Para más información consulte "Parámetros no NULL" en libnbd(3).

ESTADO DEL MANEJADOR

Se puede llamar a nbd_set_request_meta_context cuando el manejador se encuentra en los siguientes estados:

┌─────────────────────────────────────┬─────────────────────────┐
│ Manejador creado, antes de conectar │ ✅ permitido            │
│ Conectando                         │ ❌ error              │
│ Conectando y handshake (opt_mode) │ ✅ permitido            │
│ Conectado al servidor             │ ❌ error              │
│ Conexión cerrada                   │ ❌ error              │
│ Manejador muerto                    │ ❌ error              │
└─────────────────────────────────────┴─────────────────────────┘

VERSIÓN

Esta función apareció por primera vez en libnbd 1.16.

Si necesita probar si esta función está disponible en tiempo de compilación, compruebe si el siguiente macro está definido:

#define LIBNBD_HAVE_NBD_SET_REQUEST_META_CONTEXT 1
