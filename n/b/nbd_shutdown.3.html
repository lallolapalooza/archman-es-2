nbd_shutdown(3)

Paquete: libnbd

Licencias: LGPL-2.1-or-later

nbd_shutdown(3) LIBNBD nbd_shutdown(3)

NOMBRE

nbd_shutdown - desconectar del servidor NBD

SINOPSIS

#include <libnbd.h>
int nbd_shutdown (
      struct nbd_handle *h, uint32_t flags
    );

DESCRIPCIÓN

Emitir el comando de desconexión al servidor NBD. Esta es una forma educada de decirle al servidor que nos vamos, pero desde el punto de vista del cliente no tiene ventaja sobre cerrar abruptamente la conexión (ver nbd_close(3)).

Esta función funciona independientemente de si el manejador está listo para la transmisión de comandos. Si se necesita un control más detallado, ver nbd_aio_opt_abort(3) y nbd_aio_disconnect(3).

El argumento "flags" es una máscara de bits, que incluye cero o más de las siguientes banderas de apagado:

"LIBNBD_SHUTDOWN_ABANDON_PENDING" = 0x10000
Si hay alguna solicitud pendiente que aún no se ha enviado al servidor (ver nbd_aio_in_flight(3)), abandónalas sin enviarlas al servidor, en lugar de la práctica habitual de emitir esos comandos antes de informar al servidor de la intención de desconectar.

Para mayor comodidad, la constante "LIBNBD_SHUTDOWN_MASK" está disponible para describir todas las banderas de apagado reconocidas por esta compilación de libnbd. Una versión futura de la biblioteca puede añadir nuevas banderas.

VALOR DE RETORNO

Si la llamada es exitosa, la función retorna 0.

ERRORES

En caso de error, se retorna -1.

Consulte "MANEJO DE ERRORES" en libnbd(3) para obtener más detalles sobre el error.

Los siguientes parámetros no deben ser NULL: "h". Para más información, ver "Parámetros no nulos" en libnbd(3).

ESTADO DEL MANEJADOR

nbd_shutdown puede ser llamado cuando el manejador está en los siguientes estados:

┌─────────────────────────────────────┬─────────────────────────┐
│ Manejador creado, antes de conectar │ ❌ error                │
│ Conectando                          │ ❌ error                │
│ Conectando y handshake (opt_mode) │ ✅ permitido              │
│ Conectado al servidor             │ ✅ permitido              │
│ Conexión cerrada                 │ ❌ error                │
│ Manejador muerto                      │ ❌ error                │
└─────────────────────────────────────┴─────────────────────────┘

VERSIÓN

Esta función apareció por primera vez en libnbd 1.0.

Si necesita probar si esta función está disponible en tiempo de compilación, compruebe si el siguiente macro está definido:

#define LIBNBD_HAVE_NBD_SHUTDOWN 1

EJEMPLO

Este ejemplo también está disponible como examples/reads-and-writes.c en el código fuente de libnbd.

/* Este ejemplo muestra cómo realizar lecturas
 * y escrituras síncronas aleatoriamente sobre el primer megabyte de un
 * servidor NBD. Tenga en cuenta que esto destruirá cualquier contenido existente
 * en el servidor NBD.
 *
 * Para probarlo con nbdkit y un disco en memoria:
 *
 * nbdkit -U - memory 1M \
 *     --run './simple-reads-and-writes $unixsocket'
 */
#include <stdio.h>
#include <stdlib.h>
#include <stdint.h>
#include <inttypes.h>
#include <assert.h>
#include <time.h>
#include <libnbd.h>
int
main (int argc, char *argv[])
{
  struct nbd_handle *nbd;
  char buf[512];
  size_t i;
  int64_t exportsize;
  uint64_t offset;
  srand (time (NULL));
  if (argc != 2) {
    fprintf (stderr, "%s socket\n", argv[0]);
    exit (EXIT_FAILURE);
  }
  /* Crear el manejador libnbd. */
  nbd = nbd_create ();
  if (nbd == NULL) {
    fprintf (stderr, "%s\n", nbd_get_error ());
    exit (EXIT_FAILURE);
  }
  /* Conectar al servidor NBD a través de un
   * socket de dominio Unix.
   */
  if (nbd_connect_unix (nbd, argv[1]) == -1) {
    fprintf (stderr, "%s\n", nbd_get_error ());
    exit (EXIT_FAILURE);
  }
  /* Obtener el tamaño del disco y comprobar
   * que es lo suficientemente grande.
   */
  exportsize = nbd_get_size (nbd);
  if (exportsize == -1) {
    fprintf (stderr, "%s\n", nbd_get_error ());
    exit (EXIT_FAILURE);
  }
  assert (exportsize >= sizeof buf);
  /* Comprobar que el servidor es escribible. */
  if (nbd_is_read_only (nbd) == 1) {
    fprintf (stderr, "%s: "
             "error: esta exportación NBD es de solo lectura\n",
             argv[0]);
    exit (EXIT_FAILURE);
  }
  for (i = 0; i < sizeof buf; ++i)
    buf[i] = rand ();
  /* 1000 escrituras. */
  for (i = 0; i < 1000; ++i) {
    offset = rand () % (exportsize - sizeof buf);
    if (nbd_pwrite (nbd, buf, sizeof buf,
                    offset, 0) == -1) {
      fprintf (stderr, "%s\n", nbd_get_error ());
      exit (EXIT_FAILURE);
    }
  }
  /* 1000 lecturas y escrituras. */
  for (i = 0; i < 1000; ++i) {
    offset = rand () % (exportsize - sizeof buf);
    if (nbd_pread (nbd, buf, sizeof buf,
                   offset, 0) == -1) {
      fprintf (stderr, "%s\n", nbd_get_error ());
      exit (EXIT_FAILURE);
    }
    offset = rand () % (exportsize - sizeof buf);
    if (nbd_pwrite (nbd, buf, sizeof buf,
                    offset, 0) == -1) {
      fprintf (stderr, "%s\n", nbd_get_error ());
      exit (EXIT_FAILURE);
    }
  }
  /* Envía un cierre ordenado al servidor. */
  if (nbd_shutdown (nbd, 0) == -1) {
    fprintf (stderr, "%s\n", nbd_get_error ());
    exit (EXIT_FAILURE);
  }
  nbd_close (nbd);
  exit (EXIT_SUCCESS);
}
