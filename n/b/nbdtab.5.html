NOMBRE

/etc/nbdtab - archivo de configuración para nbd-client

SINOPSIS

/etc/nbdtab

DESCRIPCIÓN

Este archivo permite configurar conexiones predefinidas para nbd-client. Puede contener múltiples definiciones, una por línea, cada una de las cuales contiene cuatro campos separados por espacios.

Para conectar un dispositivo especificado en el archivo nbdtab, ejecute nbd-client(8) con el nombre corto de ese dispositivo como único argumento. Luego buscará la información requerida en nbdtab y establecerá la conexión.

Los campos están separados entre sí por cualquier número de espacios o tabulaciones; los registros están separados entre sí por caracteres de nueva línea. El archivo también puede contener cualquier número de comentarios, que comienzan con un carácter '#' y continúan hasta el final de la línea o el final del archivo, lo que ocurra primero.

CAMPOS

El archivo contiene los siguientes campos:

1.
El nombre corto del archivo de dispositivo. Es decir, debe contener el nombre del dispositivo sin la parte inicial /dev/; por ejemplo, podría decir nbd0.
2.
El nombre de host (en caso de un socket TCP) o el nombre de archivo (en caso de un socket de dominio Unix) en el que el servidor está escuchando.
3.
El nombre de la exportación tal como la exporta nbd-server.
4.
Opciones adicionales. Este campo es opcional (nunca mejor dicho), y no es necesario que aparezca en un archivo si no se necesitan opciones. Las opciones reconocidas por nbd-client(8) se especifican a continuación, en la sección "Opciones". Cualquier opción desconocida en este campo producirá una advertencia por parte de nbd-client, a menos que vaya precedida por un carácter de guion bajo ('_'); el guion bajo está específicamente reservado para uso local, o para personalización de la distribución.

OPCIONES

Cada opción de línea de comandos de nbd-client que permite configurar opciones específicas para un nodo de dispositivo particular tiene una opción correspondiente en el archivo nbdtab, y viceversa; donde esto no sea así, es un error.

Las opciones individuales en este campo deben separarse entre sí por el carácter de coma.

bs=tamaño de bloque
El tamaño del bloque para esta exportación. Si no se utiliza esta opción, se utilizará el valor predeterminado del kernel en su lugar.

Corresponde a la opción -b en la línea de comandos.

cacertfile=archivo de certificado
El archivo de certificado CA para TLS. Corresponde a la opción -A en la línea de comandos.
certfile=archivo de certificado
El archivo de certificado para TLS. Corresponde a la opción -F en la línea de comandos.
conns=número
El número de conexiones a utilizar para este dispositivo. Corresponde a la opción -C en la línea de comandos; consulte nbd-client(8) para más detalles sobre esa opción.
keyfile=archivo de clave
El archivo de clave privada para TLS. Corresponde a la opción -K en la línea de comandos.
no_optgo
Deshabilita el uso de NBD_OPT_GO en la conversación. Corresponde a la opción -g en la línea de comandos.
persist
Persiste la conexión, utilizando la semántica de la opción de línea de comandos -p.
port=número de puerto
El puerto en el que comunicarse con nbd-server. Por defecto, es el puerto asignado por IANA para NBD, 10809.
priority=cadena de prioridad GnuTLS La cadena de prioridad GnuTLS a utilizar. Corresponde a la opción -y en la línea de comandos.
swap
Optimizar para swap; -s.
timeout=tiempo de espera
El tiempo de espera. Si esta opción no se especifica, no se configura ningún tiempo de espera.

Corresponde a la opción -t en la línea de comandos.

tlshostname=nombre de host TLS
El nombre de host para fines TLS; -H
unix
Utiliza un socket de dominio Unix para conectarse al servidor; -u.

VER TAMBIÉN

nbd-server (1), nbd-client (8), nbd-trdump (8)

EJEMPLOS

Un archivo nbdtab simple podría verse así:

# espacio de swap, llamado "swapexport" en el servidor
# optimizar para swap, y reintentar la conexión tras la desconexión.
nbd0 nbdserver.example.com swapexport swap,persist
# otra exportación, llamada "data" en el servidor. Sin opciones para esta.
nbd1 nbdserver.example.com data
