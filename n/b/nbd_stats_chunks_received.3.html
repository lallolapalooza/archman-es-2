NOMBRE

nbd_stats_chunks_received - estadísticas de fragmentos recibidos en la conexión hasta ahora

SINOPSIS

#include <libnbd.h>
uint64_t nbd_stats_chunks_received (
           struct nbd_handle *h
         );

DESCRIPCIÓN

Devuelve el número de fragmentos que el cliente ha recibido del servidor, donde un fragmento es un grupo de bytes delimitado por un número mágico que no se puede subdividir sin romper el protocolo.

Este número no se relaciona necesariamente con el número de llamadas a la API realizadas, ni con el número de paquetes TCP recibidos en la conexión.

VALOR DE RETORNO

Esta llamada devuelve un contador.

ERRORES

Esta función no falla.

Los siguientes parámetros no deben ser NULL: "h". Para más información consulte "Parámetros no NULL" en libnbd(3).

VERSIÓN

Esta función apareció por primera vez en libnbd 1.16.

Si necesita probar si esta función está disponible en tiempo de compilación, compruebe si el siguiente macro está definido:

#define LIBNBD_HAVE_NBD_STATS_CHUNKS_RECEIVED 1

VER TAMBIÉN

nbd_create(3), nbd_get_structured_replies_negotiated(3), nbd_stats_bytes_received(3), nbd_stats_bytes_sent(3), nbd_stats_chunks_sent(3), libnbd(3).
