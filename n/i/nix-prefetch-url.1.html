Nombre

nix-prefetch-url - copia un archivo desde una URL a la tienda e imprime su hash

Sintaxis

nix-prefetch-url url [hash] [--type hashAlgo] [--print-path] [--unpack] [--name name]

Descripción

El comando nix-prefetch-url descarga el archivo referenciado por la URL url, imprime su hash criptográfico y lo copia a la tienda Nix. El nombre del archivo en la tienda es hash-nombreBase, donde nombreBase es todo lo que sigue a la última barra en url.

Este comando es solo una conveniencia para los escritores de expresiones Nix. A menudo, una expresión Nix recupera alguna distribución fuente de la red utilizando la expresión fetchurl contenida en Nixpkgs. Sin embargo, fetchurl requiere un hash criptográfico. Si no conoces el hash, tendrías que descargar el archivo primero, y luego fetchurl lo descargaría de nuevo cuando construyas tu expresión Nix. Dado que fetchurl utiliza el mismo nombre para el archivo descargado que nix-prefetch-url, la descarga redundante puede ser evitada.

Si se especifica hash, entonces no se realiza una descarga si la tienda Nix ya contiene un archivo con el mismo hash y nombre base. De lo contrario, el archivo se descarga y se señala un error si el hash real del archivo no coincide con el hash especificado.

Este comando imprime el hash en la salida estándar. El hash se imprime en base-32 a menos que se especifique --type md5, en cuyo caso se imprime en base-16. Adicionalmente, si se utiliza la opción --print-path, también se imprime la ruta del archivo descargado en la tienda Nix.

Opciones

•
--type hashAlgo
Utiliza el algoritmo de hash criptográfico especificado, que puede ser uno de md5, sha1, sha256, y sha512. El valor predeterminado es sha256.
•
--print-path
Imprime la ruta de la tienda del archivo descargado en la salida estándar.
•
--unpack
Desempaqueta el archivo (que debe ser un archivo tar o zip) y agrega el resultado a la tienda Nix. El hash resultante se puede usar con funciones como fetchzip o fetchFromGitHub de Nixpkgs.
•
--executable
Establece el bit de ejecución en el archivo descargado.
•
--name name
Anula el nombre del archivo en la tienda Nix. Por defecto, este es hash-nombreBase, donde nombreBase es el último componente de url. Anular el nombre es necesario cuando nombreBase contiene caracteres que no están permitidos en las rutas de la tienda Nix.

Ejemplos

$ nix-prefetch-url ftp://ftp.gnu.org/pub/gnu/hello/hello-2.10.tar.gz
0ssi1wpaf7plaswqqjwigppsg5fyh99vdlb9kzl7c9lng89ndq1i
$ nix-prefetch-url --print-path mirror://gnu/hello/hello-2.10.tar.gz
0ssi1wpaf7plaswqqjwigppsg5fyh99vdlb9kzl7c9lng89ndq1i
/nix/store/3x7dwzq014bblazs7kq20p9hyzz0qh8g-hello-2.10.tar.gz
$ nix-prefetch-url --unpack --print-path https://github.com/NixOS/patchelf/archive/0.8.tar.gz
079agjlv0hrv7fxnx9ngipx14gyncbkllxrp9cccnh3a50fxcmy7
/nix/store/19zrmhm3m40xxaw81c8cqm6aljgrnwj2-0.8.tar.gz
