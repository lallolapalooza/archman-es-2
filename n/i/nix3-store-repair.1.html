Advertencia
Este programa es experimental y su interfaz está sujeta a cambios.

Nombre

nix store repair - reparar rutas del store

Sinopsis

nix store repair [opción…] instalables…

Ejemplos

•
Reparar una ruta del store, después de determinar que está corrupta:
# nix store verify /nix/store/yb5q57zxv6hgqql42d5r8b5k5mcq6kay-hello-2.10
path '/nix/store/yb5q57zxv6hgqql42d5r8b5k5mcq6kay-hello-2.10' was
modified! expected hash
'sha256:1hd5vnh6xjk388gdk841vflicy8qv7qzj2hb7xlyh8lpb43j921l', got
'sha256:1a25lf78x5wi6pfkrxalf0n13kdaca0bqmjqnp7wfjza2qz5ssgl'
# nix store repair /nix/store/yb5q57zxv6hgqql42d5r8b5k5mcq6kay-hello-2.10

Descripción

Este comando intenta “reparar” las rutas del store especificadas por instalables redescargándolas usando los sustitutos disponibles. Si no hay sustitutos disponibles, entonces la reparación no es posible.

Advertencia

Durante la reparación, hay una ventana de tiempo muy pequeña durante la cual la ruta antigua (si existe) se mueve y se reemplaza por la nueva. Si la reparación se interrumpe en medio, el sistema puede quedar en un estado roto (por ejemplo, si la ruta contiene un componente crítico del sistema como la Biblioteca C de GNU).

Opciones

•
--stdin
Lee los instalables desde la entrada estándar. No se aplica ningún instalable predeterminado.

Opciones comunes de evaluación

•
--arg nombre expresión
Pasa el valor expresión como el argumento nombre a las funciones de Nix.
•
--arg-from-file nombre ruta
Pasa el contenido del archivo ruta como el argumento nombre a las funciones de Nix.
•
--arg-from-stdin nombre
Pasa el contenido de stdin como el argumento nombre a las funciones de Nix.
•
--argstr nombre cadena
Pasa la cadena cadena como el argumento nombre a las funciones de Nix.
•
--debugger
Inicia un entorno interactivo si la evaluación falla.
•
--eval-store url-del-store
La URL del Nix store a usar para la evaluación, es decir, para almacenar derivaciones (.drv) y las entradas referenciadas por ellas.
•
--impure
Permite el acceso a rutas y repositorios mutables.
•
--include / -I ruta
Añade ruta a las entradas de la ruta de búsqueda usadas para resolver rutas de búsqueda
Esta opción puede darse múltiples veces.
Las rutas añadidas a través de -I tienen precedencia sobre el ajuste de configuración nix-path y la variable de entorno NIX_PATH.
•
--override-flake ref-original ref-resuelto
Anula los registros de flake, redirigiendo ref-original a ref-resuelto.

Opciones comunes relacionadas con flakes

•
--commit-lock-file
Confirma los cambios en el archivo de bloqueo del flake.
•
--inputs-from flake-url
Usa las entradas del flake especificado como entradas de registro.
•
--no-registries
No permite búsquedas en los registros de flakes.
OBSOLETO
Usa --no-use-registries en su lugar.
•
--no-update-lock-file
No permite ninguna actualización del archivo de bloqueo del flake.
•
--no-write-lock-file
No escribe el archivo de bloqueo del flake recién generado.
•
--output-lock-file ruta-del-archivo-de-bloqueo-del-flake
Lee el archivo de bloqueo dado en lugar de flake.lock dentro del flake de nivel superior.
•
--override-input ruta-de-entrada flake-url
Anula una entrada de flake específica (por ejemplo, dwarffs/nixpkgs). Esto implica --no-write-lock-file.
•
--recreate-lock-file
Recrea el archivo de bloqueo del flake desde cero.
OBSOLETO
Usa nix flake update en su lugar.
•
--reference-lock-file ruta-del-archivo-de-bloqueo-del-flake
Lee el archivo de bloqueo dado en lugar de flake.lock dentro del flake de nivel superior.
•
--update-input ruta-de-entrada
Actualiza una entrada de flake específica (ignorando su entrada anterior en el archivo de bloqueo).
OBSOLETO
Usa nix flake update en su lugar.

Opciones relacionadas con el registro

•
--log-format formato
Establece el formato de los mensajes de registro. Formatos válidos son "json" y "raw".
•
--verbose / -v
Aumenta la verbosidad de la salida. Esto es equivalente a --log-format raw y aumenta el nivel de registro a "info".
Esta opción puede darse múltiples veces.
•
--quiet / -q
Disminuye la verbosidad de la salida. Esto es equivalente a --log-format raw y disminuye el nivel de registro a "warn".
Esta opción puede darse múltiples veces.
•
--no-warn-output-destinations
No muestra advertencias sobre la no disponibilidad de destinos de salida (por ejemplo, si no se puede acceder a un archivo).

Solución de problemas

Si el comando falla, Nix intentará mostrar una traza de error y una traza de pila para ayudarte a depurar el problema. Puedes usar la opción --debugger para iniciar un depurador interactivo si la evaluación falla.

La recuperación de rutas corruptas puede ser un proceso delicado. Si el comando nix store repair no puede reparar la ruta, puede que necesites eliminarla manualmente del store (con nix store delete) y volver a descargarla.

Opciones relacionadas con el registro

•
--debug
Establece el nivel de verbosidad del registro en «debug».
•
--log-format formato
Establece el formato de la salida del registro; uno de raw, internal-json, bar o bar-with-logs.
•
--print-build-logs / -L
Imprime los registros de compilación completos en el error estándar.
•
--quiet
Disminuye el nivel de verbosidad del registro.
•
--verbose / -v
Aumenta el nivel de verbosidad del registro.

Opciones globales varias

•
--help
Muestra información de uso.
•
--offline
Deshabilita los sustitutos y considera todos los archivos descargados previamente como actualizados.
•
--option nombre valor
Establece la configuración de Nix nombre a valor (anulando nix.conf).
•
--refresh
Considera todos los archivos descargados previamente como desactualizados.
•
--repair
Durante la evaluación, reescribe los archivos faltantes o corruptos en el Nix store. Durante la compilación, recompila las rutas de Nix store faltantes o corruptas.
•
--version
Muestra información de la versión.

Opciones que cambian la interpretación de instalables

•
--all
Aplica la operación a cada ruta de Nix store.
•
--derivation
Opera en la derivación de Nix store en lugar de sus salidas.
•
--expr expresión
Interpreta los instalables como rutas de atributos relativas a la expresión de Nix expresión.
•
--file / -f archivo
Interpreta los instalables como rutas de atributos relativas a la expresión de Nix almacenada en archivo. Si archivo es el carácter -, entonces se leerá una expresión de Nix de la entrada estándar. Implica --impure.
•
--recursive / -r
Aplica la operación al cierre de las rutas especificadas.
