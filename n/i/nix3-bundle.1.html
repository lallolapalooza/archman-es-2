nix3-bundle(1)

Paquete: nix

Licencias: LGPL-2.1-only

nix3-bundle(1) Manual de Comandos Generales nix3-bundle(1)

Advertencia
Este programa es experimental y su interfaz está sujeta a cambios.

Nombre

nix bundle - empaqueta una aplicación para que funcione fuera de la tienda Nix

Sinopsis

nix bundle [opción…] instalable

Ejemplos

•
Empaqueta Hello:
# nix bundle nixpkgs#hello
# ./hello
Hello, world!
•
Empaqueta una versión específica de Nix:
# nix bundle github:NixOS/nix/e3ddffb27e5fc37a209cfd843c6f7f6a9460a8ec
# ./nix --version
nix (Nix) 2.4pre20201215_e3ddffb
•
Empaqueta un Hello usando un empaquetador específico:
# nix bundle --bundler github:NixOS/bundlers#toDockerImage nixpkgs#hello
# docker load < hello-2.10.tar.gz
# docker run hello-2.10:latest hello
Hello, world!

Descripción

nix bundle, por defecto, empaqueta el cierre del instalable en un único ejecutable autoextraíble. Consulta la página principal de bundlers para más detalles.

Nota

Este comando solo funciona en Linux.

Atributos de salida del flake

Si no se proporciona ningún atributo de salida del flake, nix bundle intenta los siguientes atributos de salida del flake:

•
bundlers.<sistema>.default

Si se proporciona un nombre de atributo, nix bundle intenta los siguientes atributos de salida del flake:

•
bundlers.<sistema>.<nombre>

Empaquetadores

Un empaquetador se especifica mediante un atributo de salida del flake llamado bundlers.<sistema>.<nombre>. Tiene este aspecto:

bundlers.x86_64-linux = rec {
  identity = drv: drv;
  blender_2_79 = drv: self.packages.x86_64-linux.blender_2_79;
  default = identity;
};

Un empaquetador debe ser una función que acepte un valor arbitrario (típicamente una derivación o una definición de aplicación) y devuelva una derivación.

Opciones

•
--bundler url-del-flake
Usa un empaquetador personalizado en lugar del predeterminado (github:NixOS/bundlers).
•
--out-link / -o ruta
Anula el nombre del enlace simbólico al resultado de la compilación. Por defecto, es el nombre base de la aplicación.

Opciones comunes de evaluación

•
--arg nombre expresión
Pasa el valor expresión como el argumento nombre a las funciones de Nix.
•
--arg-from-file nombre ruta
Pasa el contenido del archivo ruta como el argumento nombre a las funciones de Nix.
•
--arg-from-stdin nombre
Pasa el contenido de la entrada estándar como el argumento nombre a las funciones de Nix.
•
--argstr nombre cadena
Pasa la cadena cadena como el argumento nombre a las funciones de Nix.
•
--debugger
Inicia un entorno interactivo si la evaluación falla.
•
--eval-store url-tienda
La URL de la tienda Nix a usar para la evaluación, es decir, para almacenar derivaciones (.drv) y las entradas referenciadas por ellas.
•
--impure
Permite el acceso a rutas y repositorios mutables.
•
--include / -I ruta
Añade ruta a las entradas de la ruta de búsqueda utilizadas para resolver las rutas de búsqueda
Esta opción se puede dar varias veces.
Las rutas añadidas a través de -I tienen prioridad sobre la configuración de nix-path y la variable de entorno NIX_PATH.
•
--override-flake ref-original ref-resuelto
Anula los registros de flakes, redirigiendo ref-original a ref-resuelto.

Opciones comunes relacionadas con flakes

•
--commit-lock-file
Confirma los cambios en el archivo de bloqueo del flake.
•
--inputs-from url-del-flake
Utiliza las entradas del flake especificado como entradas de registro.
•
--no-registries
No permite búsquedas en los registros de flakes.
OBSOLETO
Usa --no-use-registries en su lugar.
•
--no-update-lock-file
No permite ninguna actualización del archivo de bloqueo del flake.
•
--no-write-lock-file
No escribe el archivo de bloqueo recién generado del flake.
•
--output-lock-file ruta-del-archivo-de-bloqueo-del-flake
Escribe el archivo de bloqueo dado en lugar de flake.lock dentro del flake de nivel superior.
•
--override-input ruta-de-entrada url-del-flake
Anula una entrada de flake específica (por ejemplo, dwarffs/nixpkgs). Esto implica --no-write-lock-file

Opciones relacionadas con flakes

•
--commit-lockfile
Commit the updated lock file to the flake source tree.
•
--commit-unlock-for input-path
Unlock a specific flake input, allowing it to be updated. Similar to --update-input but commits the lock file afterwards.
•
--eval-cache path
Use the specified Nix store as the evaluation cache.
•
--impure
Enable impure evaluation. This is required to use --file or to access inputs that are not part of the flake lock file.
•
--recreate-lock-file
Recrea el archivo de bloqueo del flake desde cero.
OBSOLETO
Use nix flake update en su lugar.
•
--reference-lock-file ruta-de-bloqueo-flake
Lee el archivo de bloqueo dado en lugar de flake.lock dentro del flake de nivel superior.
•
--update-input ruta-de-entrada
Actualiza una entrada específica del flake (ignorando su entrada anterior en el archivo de bloqueo).
OBSOLETO
Use nix flake update en su lugar.

Opciones relacionadas con el registro

•
--debug
Establece el nivel de verbosidad del registro en 'debug'.
•
--log-format formato
Establece el formato de la salida del registro; uno de raw, internal-json, bar o bar-with-logs.
•
--print-build-logs / -L
Imprime los registros de compilación completos en la salida estándar de error.
•
--quiet
Disminuye el nivel de verbosidad del registro.
•
--verbose / -v
Aumenta el nivel de verbosidad del registro.

Opciones globales varias

•
--help
Muestra información de uso.
•
--offline
Deshabilita sustitutos y considera todos los archivos descargados previamente como actualizados.
•
--option nombre valor
Establece la configuración de Nix nombre en valor (anulando nix.conf).
•
--refresh
Considera todos los archivos descargados previamente como no actualizados.
•
--repair
Durante la evaluación, reescribe archivos faltantes o corruptos en el Nix store. Durante la compilación, recompila rutas de tienda faltantes o corruptas.
•
--version
Muestra información de la versión.

Opciones que cambian la interpretación de instalables

•
--expr expr
Interpreta instalables como rutas de atributos relativas a la expresión Nix expr.
•
--file / -f archivo
Interpreta instalables como rutas de atributos relativas a la expresión Nix almacenada en archivo. Si archivo es el carácter -, entonces se leerá una expresión Nix de la entrada estándar. Implica --impure.

Nota

Ver man nix.conf para anular la configuración con flags de línea de comandos.
