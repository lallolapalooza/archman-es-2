NILFS-RESIZE(8) Manual del Administrador del Sistema NILFS-RESIZE(8)

NOMBRE

nilfs-resize - redimensionar el volumen del sistema de archivos NILFS

SINOPSIS

nilfs-resize [opciones] dispositivo [tamaño]

DESCRIPCIÓN

El programa nilfs-resize redimensionará los sistemas de archivos NILFS2. Se puede usar para ampliar o reducir un sistema de archivos montado ubicado en dispositivo. Esta función solo está disponible en el kernel que soporta el redimensionamiento en línea. El redimensionamiento para sistemas de archivos desmontados no está soportado en este momento.

El parámetro tamaño especifica el nuevo tamaño solicitado del sistema de archivos. El tamaño del sistema de archivos nunca puede ser mayor que el tamaño de la partición. Opcionalmente, el parámetro tamaño puede ir seguido de uno de los siguientes designadores de unidad: ´s´, ´K´, ´M´, ´G´, o ´T´, para sectores de 512 bytes, kilobytes, megabytes, gigabytes o terabytes, respectivamente. Si no se especifica el parámetro tamaño, se usará por defecto el tamaño de la partición.

Este programa no manipula el tamaño de las particiones. Si desea ampliar un sistema de archivos, debe asegurarse de poder ampliar primero el tamaño de la partición subyacente. Esto se puede hacer usando fdisk(8) eliminando la partición y recreándola con un tamaño mayor o usando lvextend(8), si está utilizando el gestor de volúmenes lógicos lvm(8)

Si desea reducir una partición nilfs2, primero use nilfs-resize para reducir el tamaño del sistema de archivos. Luego puede usar fdisk(8) para reducir el tamaño de la partición. Al reducir el tamaño de la partición, asegúrese de no hacerla más pequeña que el nuevo tamaño del sistema de archivos nilfs2.

Este comando solo es válido para sistemas de archivos NILFS2 montados, y fallará si el dispositivo no tiene montajes activos.
