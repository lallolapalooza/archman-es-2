nix3-flake-clone(1) Manual de Comandos Generales nix3-flake-clone(1)

Advertencia
Este programa es experimental y su interfaz está sujeta a cambios.

Nombre

nix flake clone - clonar repositorio de flake

Sinopsis

nix flake clone [opción…] url-flake

Ejemplos

•
Consultar el código fuente del flake dwarffs y compilarlo:
# nix flake clone dwarffs --dest dwarffs
# cd dwarffs
# nix build

Descripción

Este comando realiza un clon de Git o Mercurial del repositorio que contiene el código fuente del flake url-flake.

Opciones

•
--dest / -f ruta
Clonar el flake en la ruta dest.

Opciones comunes de evaluación

•
--arg nombre expresión
Pasar el valor expresión como el argumento nombre a las funciones Nix.
•
--arg-from-file nombre ruta
Pasar el contenido del archivo ruta como el argumento nombre a las funciones Nix.
•
--arg-from-stdin nombre
Pasar el contenido de la entrada estándar como el argumento nombre a las funciones Nix.
•
--argstr nombre cadena
Pasar la cadena cadena como el argumento nombre a las funciones Nix.
•
--debugger
Iniciar un entorno interactivo si la evaluación falla.
•
--eval-store url-tienda
La URL de la tienda Nix a usar para la evaluación, es decir, para almacenar las derivaciones (.drv files) y las entradas referenciadas por ellas.
•
--impure
Permitir el acceso a rutas y repositorios mutables.
•
--include / -I ruta
Añadir ruta a las entradas de búsqueda utilizadas para resolver rutas de búsqueda
Esta opción puede darse varias veces.
Las rutas añadidas a través de -I tienen prioridad sobre la configuración nix-path y la variable de entorno NIX_PATH.
•
--override-flake ref-original ref-resuelto
Sobrescribir los registros de flakes, redirigiendo ref-original a ref-resuelto.

Opciones comunes relacionadas con flakes

•
--commit-lock-file
Confirmar cambios en el archivo de bloqueo del flake.
•
--inputs-from url-flake
Usar las entradas del flake especificado como entradas de registro.
•
--no-registries
No permitir búsquedas en los registros de flakes.
OBSOLETO
Usar --no-use-registries en su lugar.
•
--no-update-lock-file
No permitir ninguna actualización del archivo de bloqueo del flake.
•
--no-write-lock-file
No escribir el nuevo archivo de bloqueo generado del flake.
•
--output-lock-file ruta-flake-lock
Escribir el archivo de bloqueo dado en lugar de flake.lock dentro del flake principal.
•
--override-input ruta-entrada url-flake
Sobrescribir una entrada de flake específica (ej. dwarffs/nixpkgs). Esto implica --no-write-lock-file.
•
--recreate-lock-file
Recrear el archivo de bloqueo del flake desde cero.
OBSOLETO
Usar nix flake update en su lugar.
•
--reference-lock-file ruta-flake-lock
Leer el archivo de bloqueo dado en lugar de flake.lock dentro del flake principal.
•
--update-input ruta-entrada
Actualizar una entrada de flake específica (ignorando su entrada anterior en el archivo de bloqueo).
OBSOLETO
Usar nix flake update en su lugar.

Opciones relacionadas con el registro de eventos

•
--debug
Establecer el nivel de verbosidad del registro a 'debug'.
•
--log-format formato
Establecer el formato de la salida del registro; uno de raw, internal-json, bar o bar-with-logs.
•
--print-build-logs
/ -L
Imprime los registros de compilación completos en la salida de error estándar.
•
--quiet
Disminuye el nivel de verbosidad del registro.
•
--verbose / -v
Aumenta el nivel de verbosidad del registro.

Opciones globales misceláneas

•
--help
Muestra información de uso.
•
--offline
Deshabilita los sustitutos y considera todos los archivos descargados previamente como actualizados.
•
--option nombre valor
Establece la configuración de Nix nombre en valor (anulando nix.conf).
•
--refresh
Considera todos los archivos descargados previamente como desactualizados.
•
--repair
Durante la evaluación, reescribe los archivos faltantes o corruptos en el Nix store. Durante la compilación, recompila las rutas del Nix store faltantes o corruptas.
•
--version
Muestra información de la versión.

Nota

Ver man nix.conf para anular la configuración con flags de línea de comandos.
