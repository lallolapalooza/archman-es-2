nix3-store-ping(1) Manual de comandos generales nix3-store-ping(1)

Advertencia
Este programa es experimental y su interfaz está sujeta a cambios.

Nombre

nix store ping - probar si se puede acceder a una tienda

Sinopsis

nix store ping [opción…]

Ejemplos

•
Probar si la conexión a una tienda Nix remota a través de SSH funciona:
# nix store info --store ssh://mac1
•
Probar si una URL es una caché binaria válida:
# nix store info --store https://cache.nixos.org
•
Probar si el demonio Nix está activo y en funcionamiento:
# nix store info --store daemon

Descripción

Este comando prueba si se puede acceder a una tienda Nix particular (especificada por el argumento --store url). Lo que esto significa depende del tipo de tienda. Por ejemplo, para una tienda SSH significa que Nix puede conectarse a la máquina especificada.

Si el comando tiene éxito, Nix devuelve un código de salida de 0 y no imprime ninguna salida.

Opciones

•
--json
Producir salida en formato JSON, adecuada para el consumo por otro programa.

Opciones relacionadas con el registro

•
--debug
Establecer el nivel de verbosidad del registro a 'debug'.
•
--log-format formato
Establecer el formato de la salida del registro; uno de raw, internal-json, bar o bar-with-logs.
•
--print-build-logs / -L
Imprimir registros de compilación completos en la salida de error estándar.
•
--quiet
Disminuir el nivel de verbosidad del registro.
•
--verbose / -v
Aumentar el nivel de verbosidad del registro.

Opciones globales varias

•
--help
Mostrar información de uso.
•
--offline
Deshabilitar sustitutos y considerar todos los archivos descargados previamente como actualizados.
•
--option nombre valor
Establecer la configuración de Nix nombre a valor (anulando nix.conf).
•
--refresh
Considerar todos los archivos descargados previamente como no actualizados.
•
--version
Mostrar información de la versión.

Nota

Ver man nix.conf para anular la configuración con indicadores de línea de comandos.
