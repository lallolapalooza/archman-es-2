NIKOLA(1) Comandos de usuario NIKOLA(1)

NOMBRE

Nikola - Generador de sitios estáticos y blogs

SINOPSIS

Crear un sitio vacío (con un asistente de configuración):

nikola init mi_sitio

(Puedes crear un sitio con archivos de demostración con nikola init --demo mi_sitio)

Crear una publicación (dentro del directorio mi_sitio):

nikola new_post

Construir el sitio:

nikola build

Iniciar el servidor de prueba y abrir un navegador:

nikola serve -b

DESCRIPCIÓN

Nikola es un generador de sitios web y blogs estáticos. La explicación muy breve es que toma algunos textos que has escrito y los utiliza para crear una carpeta llena de archivos HTML. Si subes esa carpeta a un servidor, tendrás un sitio web bastante completo, hecho con poco esfuerzo.

Su objetivo original es crear blogs, pero admite la mayoría de los tipos de sitios y puede usarse como un CMS (Sistema de Gestión de Contenidos), siempre que lo que presentes al usuario sea tu propio contenido en lugar de algo que genere el usuario.

Nikola puede hacer:

  • Un blog
  • El sitio de tu empresa
  • Tu sitio personal
  • El sitio de un proyecto de software
  • El sitio de un libro

Dado que los sitios basados en Nikola no ejecutan ningún código en el servidor, no hay forma de procesar la entrada del usuario en formularios.

Nikola no puede hacer:

  • Twitter
  • Facebook
  • Un rastreador de incidencias
  • Realmente nada con formularios (¡excepto comentarios!)

Ten en cuenta que "estático" no significa aburrido. Puedes tener animaciones, diapositivas o cualquier cosa llamativa de CSS/HTML5 que te guste. Solo significa que todo ese HTML ya está generado antes de ser subido. Por otro lado, los sitios de Nikola tenderán a tener mucho contenido. En lo que Nikola es bueno es en sacar a la luz lo que escribes.

COMANDOS

Los comandos más básicos necesarios para empezar son:

nikola help
obtener una lista de comandos o ayuda para un comando
nikola version [--check]
imprimir el número de versión
nikola init [-d|--demo] [-q|--quiet] carpeta
inicializar un nuevo sitio
nikola build
construir un sitio
nikola new_post
crear una nueva publicación
nikola new_page
crear una nueva página
nikola status [--list-drafts] [--list-modified] [--list-scheduled]
mostrar el estado del sitio y del despliegue
nikola check [-v] (-l [--find-sources] [-r] | -f [--clean-files])
comprobar enlaces rotos o archivos desconocidos
nikola deploy [[preset [preset...]]
desplegar el sitio usando la configuración DEPLOY_COMMANDS
nikola github_deploy [-m MENSAJE_COMMIT]`
desplegar el sitio en GitHub Pages
nikola serve [-p PUERTO] [-a DIRECCION] [-d|--detach] [-b|--browser] [-6|--ipv6]
iniciar el servidor web de desarrollo
nikola auto [-p PUERTO] [-a DIRECCION] [-b|--browser] [-6|--ipv6]
iniciar el servidor web de desarrollo con reconstrucciones y recargas automáticas
nikola plugin [opciones]
gestionar plugins del Índice de Plugins ( https://plugins.getnikola.com/ )
nikola theme [opciones]
gestionar temas del Índice de Temas ( https://themes.getnikola.com/ )

Usa nikola help para obtener una lista de todos los comandos.
