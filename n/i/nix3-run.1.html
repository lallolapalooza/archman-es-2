nix3-run(1)

Paquete: nix

Licencias: LGPL-2.1-only

nix3-run(1) Manual de Comandos Generales nix3-run(1)

Advertencia
Este programa es experimental y su interfaz está sujeta a cambios.

Nombre

nix run - ejecuta una aplicación Nix

Sinopsis

nix run [opción…] instalable argumentos…

Ejemplos

•
Ejecuta la aplicación predeterminada del flake blender-bin:
# nix run blender-bin
•
Ejecuta una aplicación no predeterminada del flake blender-bin:
# nix run blender-bin#blender_2_83
Consejo: puedes encontrar las aplicaciones proporcionadas por este flake ejecutando nix flake show blender-bin.
•
Ejecuta vim desde el flake nixpkgs:
# nix run nixpkgs#vim
Ten en cuenta que vim (en el momento de escribir esta página) no es una aplicación sino un paquete. Por lo tanto, Nix ejecuta el archivo epónimo del paquete vim.
•
Ejecuta vim con argumentos:
# nix run nixpkgs#vim -- --help

Descripción

nix run construye y ejecuta instalable, que debe evaluarse como una app o una derivación Nix regular.

Si instalable se evalúa como una app (ver más abajo), ejecuta el programa especificado por la definición de la app.

Si instalable se evalúa como una derivación, intentará ejecutar el programa <out>/bin/<nombre>, donde out es la ruta de salida principal del almacén de la derivación, y nombre es el primero de los siguientes que exista:

  • El atributo meta.mainProgram de la derivación.
  • El atributo pname de la derivación.
  • La parte del nombre del valor del atributo name de la derivación.

Por ejemplo, si name está establecido a hello-1.10, nix run ejecutará $out/bin/hello.

Atributos de salida de Flake

Si no se proporciona ningún atributo de salida de flake, nix run intenta los siguientes atributos de salida de flake:

  • apps.<sistema>.default
  • packages.<sistema>.default

Si se proporciona un nombre de atributo, nix run intenta los siguientes atributos de salida de flake:

  • apps.<sistema>.<nombre>
  • packages.<sistema>.<nombre>
  • legacyPackages.<sistema>.<nombre>

Apps

Una app se especifica mediante un atributo de salida de flake llamado apps.<sistema>.<nombre>. Tiene este aspecto:

apps.x86_64-linux.blender_2_79 = {
  type = "app";
  program = "${self.packages.x86_64-linux.blender_2_79}/bin/blender";
};

Los únicos atributos admitidos son:

  • type (requerido): Debe estar establecido a app.
  • program (requerido): La ruta completa del ejecutable a ejecutar. Debe residir en el almacén de Nix.

Opciones

Opciones comunes de evaluación

•
--arg nombre expresión
Pasa el valor expresión como argumento nombre a las funciones de Nix.
•
--arg-from-file nombre ruta
Pasa el contenido del archivo ruta como argumento nombre a las funciones de Nix.
•
--arg-from-stdin nombre
Pasa el contenido de la entrada estándar como argumento nombre a las funciones de Nix.
•
--argstr nombre cadena
Pasa la cadena cadena como argumento nombre a las funciones de Nix.
•
--debugger
Inicia un entorno interactivo si la evaluación falla.
•
--eval-store url-almacen
La URL del almacén de Nix a utilizar para la evaluación, es decir, para almacenar derivaciones (.drv) y las entradas referenciadas por ellas.
•
--impure
Permite el acceso a rutas y repositorios mutables.
•
--include / -I ruta
Añade ruta a las entradas de ruta de búsqueda utilizadas para resolver rutas de búsqueda
Esta opción se puede proporcionar varias veces.
Las rutas añadidas a través de -I tienen prioridad sobre el ajuste de configuración nix-path y la variable de entorno NIX_PATH.
•
--override-flake ref-original ref-resuelto
Sobrescribe los registros de flakes, redirigiendo ref-original a ref-resuelto.

Opciones comunes relacionadas con Flakes

•
--commit-lock-file
Confirma los cambios en el archivo de bloqueo del flake.
•
--inputs-from flake-url
Utiliza las entradas del flake especificado como entradas de registro.
•
--no-registries
No permite búsquedas en los registros de flakes.
OBSOLETO
Utiliza --no-use-registries en su lugar.
•
--no-update-lock-file
No permite ninguna actualización del archivo de bloqueo del flake.
•
--no-write-lock-file
No escribe ningún archivo de bloqueo.
•
--offline
No realiza ninguna operación de red.
•
--rebuild-accessed-flake-inputs
Reconstruye todos los inputs de flake a los que se accede (incluso si están en el almacén).
•
--refresh-lock-file
Actualiza el archivo de bloqueo del flake con los inputs más recientes.
•
--substitute-urls urls
Establece la lista de URLs de sustitución a usar.
Este ajuste anula la configuración substitutes y la variable de entorno NIX_SUBSTITUTE_URLS.
•
--substituters urls
Establece la lista de substituters a usar.
Este ajuste anula la configuración substituters y la variable de entorno NIX_SUBSTITUTERS.
•
--system system
Establece el sistema de destino para las búsquedas de flakes.
•
--use-flake-inputs flake-url
Utiliza las entradas del flake especificado como entradas de registro.
•
--use-registries
Permite búsquedas en los registros de flakes.
•
--accept-flake-config
Permite usar la configuración de flakes (por ejemplo, registros de flakes).
Esto está habilitado por defecto cuando se usa la opción --impure.
•
--rebuild-flake-inputs
Reconstruye todos los inputs de flake a los que se accede (incluso si están en el almacén).
•
--write-lock-file
Escribe el archivo de bloqueo del flake.
•
--lock-file path
Archivo de bloqueo del flake a utilizar.

Opciones genéricas comunes de comandos

•
--show-trace
Muestra el rastreo de error completo si se produce un error.
•
--version
Muestra la versión de Nix y sale.
•
--extra-substituters urls
Define substituters adicionales que se añadirán a la lista de substituters especificada por la configuración de Nix.
•
--trusted-public-keys keys
Establece una lista de claves públicas de confianza para la verificación de sustitutos.
•
--log-format format
Establece el formato de los mensajes de registro.
•
--no-new-derivations
No crea nuevas derivaciones. Si la entrada no se encuentra en el almacén, falla con un error.
•
--nix-log
Escribe el registro de Nix en un archivo en lugar de stderr.
•
--override-input name installable
Sobrescribe una entrada de flake.
•
--profile path
Permite especificar un perfil de sistema de archivos para la operación.
•
--quiet / -q
Suprime la salida informativa.
•
--read-only-store
Asegura que el almacén de Nix no se modifique.
•
--realise-narrowly
Realiza solo las derivaciones que son necesarias para el resultado solicitado.
•
--replicating-policy policy
Establece la política de replicación para la operación de sustitución.
•
--retry-limit limit
Establece el número de reintentos para las operaciones de red.
•
--retain-missing-users
No falla si el usuario no está presente en el sistema.
•
--strict
Falla en caso de cualquier error de análisis o validación.
•
--system-features features
Establece las características del sistema para la evaluación.
•
--tarball-ttl duration
Establece el tiempo de vida de los tarballs descargados.
•
--use-xdg-cache
Utiliza la caché XDG para la información del registro.
•
--verbose / -v
Aumenta la verbosidad de la salida.
•
--working-dir path
Establece el directorio de trabajo para la operación.

Use nix flake update en su lugar.

--reference-lock-file ruta-archivo-bloqueo
Lea el archivo de bloqueo dado en lugar de flake.lock dentro de la flake de nivel superior.
•
--update-input ruta-entrada
Actualice una entrada de flake específica (ignorando su entrada anterior en el archivo de bloqueo).
DEPRECADO
Use nix flake update en su lugar.

Opciones relacionadas con el registro

•
--debug
Establezca el nivel de verbosidad del registro en 'debug'.
•
--log-format formato
Establezca el formato de salida del registro; uno de raw, internal-json, bar o bar-with-logs.
•
--print-build-logs / -L
Imprima los registros de compilación completos en la salida de error estándar.
•
--quiet
Disminuya el nivel de verbosidad del registro.
•
--verbose / -v
Aumente el nivel de verbosidad del registro.

Opciones globales varias

•
--help
Muestre la información de uso.
•
--offline
Deshabilite los sustitutos y considere todos los archivos descargados previamente como actualizados.
•
--option nombre valor
Establezca la configuración de Nix nombre en valor (anulando nix.conf).
•
--refresh
Considere todos los archivos descargados previamente como desactualizados.
•
--repair
Durante la evaluación, reescriba los archivos faltantes o corruptos en el almacén de Nix. Durante la compilación, recompila las rutas de almacén faltantes o corruptas.
•
--version
Muestre la información de la versión.

Opciones que cambian la interpretación de los instalables

•
--expr expr
Interprete instalables como rutas de atributos relativas a la expresión de Nix expr.
•
--file / -f archivo
Interprete instalables como rutas de atributos relativas a la expresión de Nix almacenada en archivo. Si archivo es el carácter -, entonces se leerá una expresión de Nix de la entrada estándar. Implica --impure.

Nota

Consulte man nix.conf para anular la configuración con indicadores de línea de comandos.
