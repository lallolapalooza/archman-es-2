nix3-help(1) Manual de Comandos Generales nix3-help(1)

Advertencia
Este programa es experimental y su interfaz está sujeta a cambios.

Nombre

nix help - mostrar ayuda sobre nix o un subcomando específico

Sinopsis

nix help [opción…] subcomando…

Ejemplos

•
Mostrar ayuda sobre nix en general:
# nix help
•
Mostrar ayuda sobre un subcomando específico:
  # nix help flake info

Opciones

Opciones relacionadas con el registro de actividad

•
--debug
Establece el nivel de verbosidad del registro en ‘debug’.
•
--log-format formato
Establece el formato de salida del registro; uno de raw, internal-json, bar o bar-with-logs.
•
--print-build-logs / -L
Imprime los registros de compilación completos en la salida de error estándar.
•
--quiet
Disminuye el nivel de verbosidad del registro.
•
--verbose / -v
Aumenta el nivel de verbosidad del registro.

Opciones globales varias

•
--help
Muestra información de uso.
•
--offline
Deshabilita los sustitutos y considera todos los archivos descargados previamente como actualizados.
•
--option nombre valor
Establece la configuración de Nix nombre en valor (anulando nix.conf).
•
--refresh
Considera todos los archivos descargados previamente como no actualizados.
•
--version
Muestra información de la versión.

Nota

Consulta man nix.conf para anular los ajustes de configuración con flags de línea de comandos.
