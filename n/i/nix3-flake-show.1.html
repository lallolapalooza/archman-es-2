nix flake show - muestra las salidas proporcionadas por un flake

Descripción

Este comando muestra los atributos de salida proporcionados por el flake especificado por la referencia del flake url-del-flake. Estos son los atributos de nivel superior en las salidas del flake, así como los atributos de nivel inferior para algunas salidas estándar (por ejemplo, packages o checks).

Con --json, la salida está en una representación JSON adecuada para el procesamiento automático por otras herramientas.

Opciones

•
--all-systems
Muestra el contenido de las salidas para todos los sistemas.
•
--json
Produce la salida en formato JSON, adecuada para su consumo por otro programa.
•
--legacy
Muestra el contenido de la salida legacyPackages.

Opciones comunes de evaluación

•
--arg nombre expresión
Pasa el valor expresión como el argumento nombre a las funciones de Nix.
•
--arg-from-file nombre ruta
Pasa el contenido del archivo ruta como el argumento nombre a las funciones de Nix.
•
--arg-from-stdin nombre
Pasa el contenido de stdin como el argumento nombre a las funciones de Nix.
•
--argstr nombre cadena
Pasa la cadena cadena como el argumento nombre a las funciones de Nix.
•
--debugger
Inicia un entorno interactivo si la evaluación falla.
•
--eval-store url-tienda
La URL de la tienda Nix a utilizar para la evaluación, es decir, para almacenar derivaciones (archivos .drv) y las entradas referenciadas por ellas.
•
--impure
Permite el acceso a rutas y repositorios mutables.
•
--include / -I ruta
Añade ruta a las entradas de la ruta de búsqueda utilizadas para resolver rutas de búsqueda
Esta opción se puede dar varias veces.
Las rutas añadidas a través de -I tienen prioridad sobre la configuración nix-path y la variable de entorno NIX_PATH.
•
--override-flake ref-original ref-resuelto
Anula los registros de flakes, redirigiendo ref-original a ref-resuelto.

Opciones comunes relacionadas con flakes

•
--commit-lock-file
Confirma los cambios en el archivo de bloqueo del flake.
•
--inputs-from url-del-flake
Utiliza las entradas del flake especificado como entradas de registro.
•
--no-registries
No permite búsquedas en los registros de flakes.
OBSOLETO
Usa --no-use-registries en su lugar.
•
--no-update-lock-file
No permite ninguna actualización del archivo de bloqueo del flake.
•
--no-write-lock-file
No escribe el archivo de bloqueo recién generado del flake.
•
--output-lock-file ruta-archivo-de-bloqueo-flake
Escribe el archivo de bloqueo dado en lugar de flake.lock dentro del flake de nivel superior.

NAME

nix3-flake-show — Show information about a flake

SYNOPSIS

nix flake show [option...] [flake-url]

EXAMPLES

Show information about the current flake:

 $ nix flake show
 # or explicitly
 $ nix flake show .#

Show information about the NixOS/nixpkgs flake:

 $ nix flake show nixpkgs

Show information about a specific attribute path:

 $ nix flake show nixpkgs --attr nixos.packages.x86_64-linux.git

Show the NixOS configuration module for the current flake:

 $ nix flake show .#nixosConfigurations.myhost

DESCRIPTION

Show information about a flake, such as its attributes and their outputs.

The flake is identified by the optional flake-url argument. If not given, it defaults to the current flake (i.e. the flake described by the flake registry entry for the current directory, which is usually the flake in the current directory).

The output is structured hierarchically. For each output defined in the flake, it shows the corresponding attribute path and a description of the output.

OPTIONS

The following options are available:

•
--accept-flake-config
Allow flakes to configure the Nix interpreter.
DEPRECATED
This option is no longer necessary, as the flake configuration has been moved to the new Nix CLI.
•
--attr attr-path
Show only the attribute at the given attr-path.
•
--commit-lockfile
Commit the updated lock file to the Git repository.
•
--exclude glob
Exclude attributes matching the given glob pattern.
•
--extra-dep flake-url
Add a flake URL that will be evaluated but not stored in the lock file.
•
--file path
Evaluate the flake in path instead of the default flake.nix.
•
--flake-root path
Use the flake described by path as the flake-root.
•
--include glob
Include only attributes matching the given glob pattern.
•
--json
Print the result as JSON.
•
--log-format format
Set the format of log output; one of raw, internal-json, bar or bar-with-logs.
•
--no-link-lock-file
Do not create a flake.lock file if it doesn't exist.
•
--no-nixpkgs-fallback
Disable the fallback to nixpkgs for inputs that are not explicitly defined.
•
--override-input input-path flake-url
Override a specific flake input (e.g. dwarffs/nixpkgs). This implies --no-write-lock-file.
•
--recreate-lock-file
Recreate the flake’s lock file from scratch.
DEPRECATED
Use nix flake update instead.
•
--reference-lock-file flake-lock-path
Read the given lock file instead of flake.lock within the top-level flake.
•
--update-input input-path
Update a specific flake input (ignoring its previous entry in the lock file).
DEPRECATED
Use nix flake update instead.

Logging-related options

•
--debug
Set the logging verbosity level to ‘debug’.
•
--log-format format
Set the format of log output; one of raw, internal-json, bar or bar-with-logs.
•
--print-build-logs / -L
Print full build logs on standard error.
•
--quiet
Decrease the logging verbosity level.
•
--verbose / -v
Increase the logging verbosity level.

Miscellaneous global options

•
--help
Show usage information.
•
--offline
Disable substituters and consider all previously downloaded files up-to-date.
•
--option name value
Set the Nix configuration setting name to value (overriding nix.conf).
•
--refresh
Consider all previously downloaded files out-of-date.
•
--repair
During evaluation, rewrite missing or corrupted files in the Nix store. During building, rebuild missing or corrupted store paths.
•
--version
Show version information.

Note

See man nix.conf for overriding configuration settings with command line flags.
