Advertencia
Este programa es experimental y su interfaz está sujeta a cambios.

Nombre

nix store copy-log - copia los registros de construcción entre almacenes Nix

Sinopsis

nix store copy-log [opción…] instalables…

Ejemplos

•
Para copiar el registro de construcción del paquete hello desde https://cache.nixos.org al almacén local:
# nix store copy-log --from https://cache.nixos.org --eval-store auto nixpkgs#hello
Puedes verificar que el registro está disponible localmente:
# nix log --substituters '' nixpkgs#hello
(La bandera --substituters '' evita consultar https://cache.nixos.org por el registro.)
•
Para copiar el registro de una derivación de almacén específica a través de SSH:
# nix store copy-log --to ssh-ng://machine /nix/store/ilgm50plpmcgjhcp33z6n4qbnpqfhxym-glibc-2.33-59.drv

Descripción

nix store copy-log copia los registros de construcción entre dos almacenes Nix. El almacén de origen se especifica usando --from y el de destino usando --to. Si uno de ellos se omite, por defecto se usa el almacén local.

Opciones

•
--from uri-almacen
URL del almacén Nix de origen.
•
--stdin
Lee los instalables de la entrada estándar. No se aplica ningún instalable por defecto.
•
--to uri-almacen
URL del almacén Nix de destino.

Opciones comunes de evaluación

•
--arg nombre expr
Pasa el valor expr como el argumento nombre a las funciones Nix.
•
--arg-from-file nombre ruta
Pasa el contenido del archivo ruta como el argumento nombre a las funciones Nix.
•
--arg-from-stdin nombre
Pasa el contenido de la entrada estándar como el argumento nombre a las funciones Nix.
•
--argstr nombre cadena
Pasa la cadena cadena como el argumento nombre a las funciones Nix.
•
--debugger
Inicia un entorno interactivo si la evaluación falla.
•
--eval-store url-almacen
La URL del almacén Nix a usar para la evaluación, es decir, para almacenar derivaciones (.drv) y las entradas referenciadas por ellas.
•
--impure
Permite el acceso a rutas y repositorios mutables.
•
--include / -I ruta
Añade ruta a las entradas de la ruta de búsqueda utilizadas para resolver rutas de búsqueda
Esta opción se puede dar varias veces.
Las rutas añadidas a través de -I tienen prioridad sobre la configuración nix-path y la variable de entorno NIX_PATH.
•
--override-flake ref-original ref-resuelto
Sobrescribe los registros de flake, redirigiendo ref-original a ref-resuelto.

Opciones comunes relacionadas con flakes

•
--commit-lock-file
Confirma los cambios en el archivo lock del flake.
•
--inputs-from flake-url
Utiliza las entradas del flake especificado como entradas de registro.
•
--no-registries
No permite búsquedas en los registros de flake.
OBSOLETO
Usa --no-use-registries en su lugar.
•
--no-update-lock-file
No permite ninguna actualización del archivo lock del flake.
•
--no-write-lock-file
No escribe el archivo lock del flake recién generado.
•
--output-lock-file ruta-lock-flake
Escribe el archivo lock dado en lugar de flake.lock dentro del flake de nivel superior.
•
--override-input ruta-entrada flake-url
Sobrescribe una entrada de flake específica (por ejemplo, dwarffs/nixpkgs). Esto implica --no-write-lock-file.
•
--recreate-lock-file
Recrea el archivo lock del flake desde cero.
OBSOLETO
Usa nix flake update en su lugar.
•
--reference-lock-file ruta-lock-flake
Lee el archivo lock dado en lugar de flake.lock dentro del flake de nivel superior.

NAME

nix3-flake-update - Update a flake's inputs

SYNOPSIS

nix3-flake-update [-q | --quiet] [-v | --verbose] [--option name value] [--help] [--version] [--offline] [--refresh] [--repair] [--debug] [--log-format format] [-L | --print-build-logs] [--update-input input-path] [flake-url]

EXAMPLES

Update a flake in the current directory: 
$ nix3-flake update
Update a specific flake input (e.g., 'nixpkgs'): 
$ nix3-flake update --update-input nixpkgs
Update a flake from a remote Git repository: 
$ nix3-flake update github:NixOS/nixpkgs
Update a flake and force a rebuild of all dependencies: 
$ nix3-flake update --refresh

DESCRIPTION

The nix3-flake-update command updates the inputs of a flake, writing the updated flake reference to the lock file. This command is a deprecated alias for nix flake update.

If a flake-url is provided, the command operates on that flake. Otherwise, it operates on the flake in the current directory (i.e. ./flake.nix).

Options related to updating flakes

--update-input input-path
Update a specific flake input (ignoring its previous entry in the lock file).
DEPRECATED
Use nix flake update instead.

Logging-related options

•
--debug
Set the logging verbosity level to ‘debug’.
•
--log-format format
Set the format of log output; one of raw, internal-json, bar or bar-with-logs.
•
--print-build-logs / -L
Print full build logs on standard error.
•
--quiet
Decrease the logging verbosity level.
•
--verbose / -v
Increase the logging verbosity level.

Miscellaneous global options

•
--help
Show usage information.
•
--offline
Disable substituters and consider all previously downloaded files up-to-date.
•
--option name value
Set the Nix configuration setting name to value (overriding nix.conf).
•
--refresh
Consider all previously downloaded files out-of-date.
•
--repair
During evaluation, rewrite missing or corrupted files in the Nix store. During building, rebuild missing or corrupted store paths.
•
--version
Show version information.

Options that change the interpretation of installables

•
--expr expr
Interpret installables as attribute paths relative to the Nix expression expr.
•
--file / -f file
Interpret installables as attribute paths relative to the Nix expression stored in file. If file is the character -, then a Nix expression will be read from standard input. Implies --impure.

Note

See man nix.conf for overriding configuration settings with command line flags.
