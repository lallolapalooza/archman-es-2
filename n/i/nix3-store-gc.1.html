nix3-store-gc(1) Manual de comandos generales nix3-store-gc(1)

Advertencia
Este programa es experimental y su interfaz está sujeta a cambios.

Nombre

nix store gc - realiza la recolección de basura en una tienda Nix

Sinopsis

nix store gc [opción…]

Ejemplos

•
Eliminar rutas inalcanzables en la tienda Nix:
# nix store gc
•
Eliminar hasta 1 gigabyte de basura:
# nix store gc --max 1G

Descripción

Este comando elimina las rutas inalcanzables en la tienda Nix.

Opciones

•
--dry-run
Muestra lo que este comando haría sin hacerlo.
•
--max n
Detenerse después de liberar n bytes de espacio en disco.

Opciones relacionadas con el registro

•
--debug
Establece el nivel de verbosidad del registro en ‘debug’.
•
--log-format formato
Establece el formato de la salida del registro; una de raw, internal-json, bar o bar-with-logs.
•
--print-build-logs / -L
Imprime los registros de compilación completos en la salida de error estándar.
•
--quiet
Disminuye el nivel de verbosidad del registro.
•
--verbose / -v
Aumenta el nivel de verbosidad del registro.

Opciones globales varias

•
--help
Muestra información de uso.
•
--offline
Deshabilita los sustitutos y considera que todos los archivos descargados previamente están actualizados.
•
--option nombre valor
Establece la configuración de Nix nombre en valor (anulando nix.conf).
•
--refresh
Considera que todos los archivos descargados previamente están desactualizados.
•
--version
Muestra información de la versión.

Nota

Ver man nix.conf para anular la configuración con indicadores de línea de comandos.
