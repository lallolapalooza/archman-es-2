nix3-nar-dump-path(1) Manual de Comandos Generales nix3-nar-dump-path(1)

Advertencia
Este programa es experimental y su interfaz está sujeta a cambios.

Nombre

nix nar dump-path - serializar una ruta a stdout en formato NAR

Sinopsis

nix nar dump-path [opción…] ruta

Ejemplos

•
Para serializar el directorio foo como un Archivo Nix (NAR):
# nix nar pack ./foo > foo.nar

Descripción

Este comando genera un archivo Archivo Nix (NAR) que contiene la serialización de ruta, la cual debe contener únicamente archivos regulares, directorios y enlaces simbólicos. El NAR se escribe en la salida estándar.

Opciones

Opciones relacionadas con el registro

•
--debug
Establece el nivel de verbosidad del registro en 'debug'.
•
--log-format formato
Establece el formato de salida del registro; uno de raw, internal-json, bar o bar-with-logs.
•
--print-build-logs / -L
Imprime los registros de construcción completos en la salida de error estándar.
•
--quiet
Disminuye el nivel de verbosidad del registro.
•
--verbose / -v
Aumenta el nivel de verbosidad del registro.

Opciones globales varias

•
--help
Muestra información de uso.
•
--offline
Deshabilita los sustitutos y considera que todos los archivos descargados previamente están actualizados.
•
--option nombre valor
Establece la configuración de Nix nombre a valor (anulando nix.conf).
•
--refresh
Considera que todos los archivos descargados previamente están desactualizados.
•
--version
Muestra información de la versión.

Nota

Consulte man nix.conf para anular la configuración con indicadores de línea de comandos.
