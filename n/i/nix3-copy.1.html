nix3-copy(1) Manual de Comandos Generales nix3-copy(1)

Advertencia
Este programa es experimental y su interfaz está sujeta a cambios.

Nombre

nix copy - copiar rutas entre almacenes Nix

Sinopsis

nix copy [opción…] instalables…

Ejemplos

•
Copiar Firefox desde el almacén local a una caché binaria en /tmp/cache:
# nix copy --to file:///tmp/cache $(type -p firefox)
Observe el file:// - sin él, el destino es un almacén chroot, no una caché binaria.
•
Copiar todas las rutas de almacén de una caché binaria local en /tmp/cache al almacén local:
# nix copy --all --from file:///tmp/cache
•
Copiar todo el cierre del sistema NixOS actual a otra máquina vía SSH:
# nix copy --substitute-on-destination --to ssh://server /run/current-system
La opción -s hace que la máquina remota intente sustituir rutas de almacén faltantes, lo que puede ser más rápido si el enlace entre la máquina local y la remota es más lento que el enlace entre la máquina remota y sus sustitutos (por ejemplo, https://cache.nixos.org).
•
Copiar un cierre desde otra máquina vía SSH:
# nix copy --from ssh://server /nix/store/a6cnl93nk1wxnq84brbbwr6hxw9gp2w9-blender-2.79-rc2
•
Copiar Hello a una caché binaria en un bucket de Amazon S3:
# nix copy --to s3://my-bucket?region=eu-west-1 nixpkgs#hello
o a un sistema de almacenamiento compatible con S3:
# nix copy --to s3://my-bucket?region=eu-west-1&endpoint=example.com nixpkgs#hello
Tenga en cuenta que esto solo funciona si Nix está compilado con soporte AWS.
•
Copiar un cierre desde /nix/store al almacén chroot /tmp/nix/nix/store:
# nix copy --to /tmp/nix nixpkgs#hello --no-check-sigs

Descripción

nix copy copia cierres de rutas de almacén entre dos almacenes Nix. El almacén de origen se especifica usando --from y el destino usando --to. Si uno de ellos se omite, se usa el almacén local por defecto.

Opciones

•
--from uri-almacen
URL del almacén Nix de origen.
•
--no-check-sigs
No requerir que las rutas estén firmadas por claves de confianza.
•
--stdin
Leer instalables desde la entrada estándar. No se aplica ningún instalable por defecto.
•
--substitute-on-destination / -s
Si se deben intentar sustitutos en el almacén de destino (solo compatible con almacenes SSH).
•
--to uri-almacen
URL del almacén Nix de destino.

Opciones comunes de evaluación

•
--arg nombre expr
Pasar el valor expr como argumento nombre a las funciones Nix.
•
--arg-from-file nombre ruta
Pasar el contenido del archivo ruta como argumento nombre a las funciones Nix.
•
--arg-from-stdin nombre
Pasar el contenido de stdin como argumento nombre a las funciones Nix.
•
--argstr nombre cadena
Pasar la cadena cadena como argumento nombre a las funciones Nix.
•
--debugger
Iniciar un entorno interactivo si la evaluación falla.
•
--eval-store url-almacen
La URL del almacén Nix a utilizar para la evaluación, es decir, para almacenar derivaciones (.drv) y las entradas a las que hacen referencia.
•
--impure
Permitir el acceso a rutas y repositorios mutables.
•
--include / -I ruta
Añadir ruta a las entradas de ruta de búsqueda utilizadas para resolver rutas de búsqueda
Esta opción se puede dar varias veces.
Las rutas añadidas a través de -I tienen prioridad sobre la configuración nix-path y la variable de entorno NIX_PATH.
•
--override-flake ref-original ref-resuelto
Anular los registros de flakes, redirigiendo ref-original a ref-resuelto.

Opciones comunes relacionadas con flakes

•
--commit-lock-file
Confirmar cambios en el archivo de bloqueo del flake.
•
--inputs-from flake-url
Usar las entradas del flake especificado como entradas de registro.
•
--no-registries
No permitir búsquedas en los registros de flakes.
OBSOLETO
Usar --no-use-registries en su lugar.
•
--no-update-lock-file
No permitir ninguna actualización del archivo de bloqueo del flake.
•
--no-write-lock-file
No escribir t

nix3-copy(1) — Arch Linux man pages

NAME

nix copy — Copiar el contenido de las salidas de Nix a otra ubicación.

SYNOPSIS

nix copy [--option name value]...

nix copy [-h | --help]

nix copy {--all | --derivation | --expr expr | -f | --file file | --no-recursive | -L | --print-build-logs | -v | --verbose}...

nix copy [--debug | --log-format format | --quiet]...

nix copy [--output-lock-file flake-lock-path | --override-input input-path flake-url | --recreate-lock-file | --reference-lock-file flake-lock-path | --update-input input-path]...

nix copy [--offline | --refresh | --repair]...

nix copy [--version]

nix copy store-path-or-url...

Examples

Copiar un conjunto de salidas en el almacén Nix a un registro remoto:

nix copy /nix/store/some-hash-foo /nix/store/some-hash-bar -r foo@https://example.com/foo.nar

Copiar todas las salidas de la vaina actual a un registro remoto:

nix copy . -r foo@https://example.com/foo.nar

Copiar todas las salidas de la vaina actual a un registro remoto, recreando el archivo flake.lock en el proceso:

nix copy . --recreate-lock-file -r foo@https://example.com/foo.nar

Description

Copiar contenido de salida de Nix a una ubicación remota (por ejemplo, un registro de Nix). Las ubicaciones remotas se especifican en forma de una URL de vaina. Una vaina puede tener uno o más registros configurados. El objeto de la copia es el contenido del almacén, que luego se transfiere a la ubicación remota.

En el caso de las vainas, la vaina de destino puede proporcionar un registro especificado como nombre@url. Si sólo se proporciona una url, se tratará como un registro llamado "" (cadena vacía).

Cuando se especifican varias ubicaciones de destino, el contenido del almacén se copiará en cada una de ellas.

Esta operación es idempotente: si el contenido deseado ya existe en el destino, Nix no lo volverá a copiar.

Options

•
--all
Realizar la operación en cada ruta de almacén.
•
--derivation
Operar en la derivación de almacén en lugar de sus salidas.
•
--expr expr
Interpretar los elementos instalables como rutas de atributos relativas a la expresión Nix expr.
•
--file / -f file
Interpretar los elementos instalables como rutas de atributos relativas a la expresión Nix almacenada en file. Si file es el carácter -, se leerá una expresión Nix desde la entrada estándar. Implica --impure.
•
--help
Mostrar información de uso.
•
--no-recursive
Aplicar la operación sólo a las rutas especificadas.
•
--offline
Desactivar los sustitutos y considerar todos los archivos descargados previamente como actualizados.
•
--option name value
Establecer el parámetro de configuración de Nix name en value (anulando nix.conf).
•
--output-lock-file flake-lock-path
Escribir el archivo de bloqueo dado en lugar de flake.lock dentro de la vaina de nivel superior.
•
--override-input input-path flake-url
Anular una entrada específica de la vaina (por ejemplo, dwarffs/nixpkgs). Esto implica --no-write-lock-file.
•
--print-build-logs / -L
Imprimir los registros de compilación completos en el error estándar.
•
--quiet
Disminuir el nivel de verbosidad del registro.
•
--refresh
Considerar todos los archivos descargados previamente como obsoletos.
•
--recreate-lock-file
Recrear el archivo de bloqueo de la vaina desde cero.
DEPRECADO
Usar nix flake update en su lugar.
•
--reference-lock-file flake-lock-path
Leer el archivo de bloqueo dado en lugar de flake.lock dentro de la vaina de nivel superior.
•
--repair
Durante la evaluación, reescribir archivos faltantes o corruptos en el almacén de Nix. Durante la construcción, reconstruir rutas de almacén faltantes o corruptas.
•
--update-input input-path
Actualizar una entrada específica de la vaina (ignorando su entrada anterior en el archivo de bloqueo).
DEPRECADO
Usar nix flake update en su lugar.
•
--verbose / -v
Aumentar el nivel de verbosidad del registro.
•
--version
Mostrar información de la versión.

Opciones relacionadas con el registro

•
--debug
Establecer el nivel de verbosidad del registro en 'debug'.
•
--log-format format
Establecer el formato de la salida del registro; uno de raw, internal-json, bar o bar-with-logs.
•
--print-build-logs / -L
Imprimir los registros de compilación completos en el error estándar.
•
--quiet
Disminuir el nivel de verbosidad del registro.
•
--verbose / -v
Aumentar el nivel de verbosidad del registro.

Opciones globales varias

•
--help
Mostrar información de uso.
•
--offline
Desactivar los sustitutos y considerar todos los archivos descargados previamente como actualizados.
•
--option name value
Establecer el parámetro de configuración de Nix name en value (anulando nix.conf).
•
--refresh
Considerar todos los archivos descargados previamente como obsoletos.
•
--repair
Durante la evaluación, reescribir archivos faltantes o corruptos en el almacén de Nix. Durante la construcción, reconstruir rutas de almacén faltantes o corruptas.
•
--version
Mostrar información de la versión.

Opciones que cambian la interpretación de elementos instalables

•
--all
Aplicar la operación a cada ruta de almacén.
•
--derivation
Operar en la derivación de almacén en lugar de sus salidas.
•
--expr expr
Interpretar elementos instalables como rutas de atributos relativas a la expresión Nix expr.
•
--file / -f file
Interpretar elementos instalables como rutas de atributos relativas a la expresión Nix almacenada en file. Si file es el carácter -, entonces se leerá una expresión Nix desde la entrada estándar. Implica --impure.
•
--no-recursive
Aplicar la operación a las rutas especificadas solamente.

Nota
