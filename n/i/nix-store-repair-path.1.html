Nombre

nix --repair-path - redescarga la ruta del sustituto

Sintaxis

nix-store --repair-path rutas…

Descripción

La operación --repair-path intenta "reparar" las rutas especificadas redescargándolas utilizando los sustitutos disponibles. Si no hay sustitutos disponibles, la reparación no es posible.

Advertencia

Durante la reparación, existe una ventana de tiempo muy pequeña durante la cual la ruta antigua (si existe) se mueve para ser reemplazada por la nueva ruta. Si la reparación se interrumpe en medio, el sistema puede quedar en un estado dañado (por ejemplo, si la ruta contiene un componente crítico del sistema como la biblioteca C de GNU).

Ejemplo

$ nix-store --verify-path /nix/store/dj7a81wsm1ijwwpkks3725661h3263p5-glibc-2.13
La ruta `/nix/store/dj7a81wsm1ijwwpkks3725661h3263p5-glibc-2.13' ha sido modificada!
  hash esperado `2db57715ae90b7e31ff1f2ecb8c12ec1cc43da920efcbe3b22763f36a1861588',
  obtenido `481c5aa5483ebc97c20457bb8bca24deea56550d3985cda0027f67fe54b808e4'
$ nix-store --repair-path /nix/store/dj7a81wsm1ijwwpkks3725661h3263p5-glibc-2.13
descargando ruta `/nix/store/d7a81wsm1ijwwpkks3725661h3263p5-glibc-2.13'...
…
