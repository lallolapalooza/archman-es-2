nix3-flake-init(1) Manual de comandos generales nix3-flake-init(1)

Advertencia
Este programa es experimental y su interfaz está sujeta a cambios.

Nombre

nix flake init - crea un flake en el directorio actual a partir de una plantilla

Sinopsis

nix flake init [opción…]

Ejemplos

•
Crea un flake usando la plantilla por defecto:
# nix flake init
•
Lista las plantillas disponibles:
# nix flake show templates
•
Crea un flake a partir de una plantilla específica:
# nix flake init -t templates#simpleContainer

Descripción

Este comando crea un flake en el directorio actual copiando los archivos de una plantilla. No sobrescribirá archivos existentes. La plantilla por defecto es templates#templates.default, pero esto puede ser anulado usando -t.

Definiciones de plantillas

Un flake puede declarar plantillas a través de su atributo de salida templates. Una plantilla tiene los siguientes atributos:

  • description: Una descripción de una línea de la plantilla, en sintaxis CommonMark.
  • path: La ruta del directorio a copiar.
  • welcomeText: Un bloque de texto markdown para mostrar cuando un usuario inicializa un nuevo flake basado en esta plantilla.

Aquí hay un ejemplo:

outputs = { self }: {
  templates.rust = {
    path = ./rust;
    description = "Un proyecto simple de Rust/Cargo";
    welcomeText = ''
      # Plantilla simple de Rust/Cargo
      ## Uso previsto
      El uso previsto de este flake es...
      ## Más información
      - [Lenguaje Rust](https://www.rust-lang.org/)
      - [Rust en el Wiki de NixOS](https://wiki.nixos.org/wiki/Rust)
      - ...
    '';
  };
  templates.default = self.templates.rust;
}

Opciones

•
--template / -t plantilla
La plantilla a usar.

Opciones comunes de evaluación

•
--arg nombre exp
Pasa el valor exp como el argumento nombre a las funciones de Nix.
•
--arg-from-file nombre ruta
Pasa el contenido del archivo ruta como el argumento nombre a las funciones de Nix.
•
--arg-from-stdin nombre
Pasa el contenido de stdin como el argumento nombre a las funciones de Nix.
•
--argstr nombre cadena
Pasa la cadena cadena como el argumento nombre a las funciones de Nix.
•
--debugger
Inicia un entorno interactivo si la evaluación falla.
•
--eval-store url-tienda
La URL de la tienda Nix a usar para la evaluación, es decir, para almacenar derivaciones (.drv files) y las entradas referenciadas por ellas.
•
--impure
Permite el acceso a rutas mutables y repositorios.
•
--include / -I ruta
Añade ruta a las entradas de la ruta de búsqueda utilizadas para resolver rutas de búsqueda (lookup paths)
Esta opción puede darse varias veces.
Las rutas añadidas a través de -I tienen prioridad sobre la configuración nix-path y la variable de entorno NIX_PATH.
•
--override-flake ref-original ref-resuelto
Anula los registros de flakes, redirigiendo ref-original a ref-resuelto.

Opciones relacionadas con el registro

•
--debug
Establece el nivel de verbosidad del registro a 'debug'.
•
--log-format formato
Establece el formato de la salida del registro; uno de raw, internal-json, bar o bar-with-logs.
•
--print-build-logs / -L
Imprime los registros de compilación completos en la salida estándar de error.
•
--quiet
Disminuye el nivel de verbosidad del registro.
•
--verbose / -v
Aumenta el nivel de verbosidad del registro.

Opciones globales varias

•
--help
Muestra información de uso.
•
--offline
Deshabilita los sustitutos y considera todos los archivos descargados previamente como actualizados.
•
--option nombre valor
Establece la opción de configuración de Nix nombre a valor (anulando nix.conf).
•
--refresh
Considera todos los archivos descargados previamente como no actualizados.
•
--repair
Durante la evaluación, reescribe archivos faltantes o corruptos en la tienda Nix. Durante la compilación, recompila rutas de la tienda faltantes o corruptas.
•
--version
Muestra información de la versión.
