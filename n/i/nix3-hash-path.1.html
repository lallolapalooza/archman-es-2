nix3-hash-path(1) Manual de Comandos Generales nix3-hash-path(1)

Advertencia
Este programa es experimental y su interfaz está sujeta a cambios.

Nombre

nix hash path - imprime el hash criptográfico de la serialización NAR de una ruta

Sinopsis

nix hash path [opción…] rutas…

Opciones

•
--algo algoritmo-hash
Algoritmo de hash (md5, sha1, sha256 o sha512).
•
--base16
Imprime el hash en formato base-16.
•
--base32
Imprime el hash en formato base-32 (específico de Nix).
•
--base64
Imprime el hash en formato base-64.
•
--format formato-hash
Formato del hash (base16, nix32, base64, sri). Por defecto: sri.
•
--mode método-ingesta-archivo
Cómo calcular el hash de la entrada. Uno de:
  • nar (por defecto): Serializa la entrada como un Archivo Nix y lo pasa a la función de hash.
  • flat: Asume que la entrada es un único archivo y lo pasa directamente a la función de hash.
•
--sri
Imprime el hash en formato SRI.
•
--type algoritmo-hash
Algoritmo de hash (md5, sha1, sha256 o sha512).

Opciones relacionadas con el registro

•
--debug
Establece el nivel de verbosidad del registro a 'debug'.
•
--log-format formato
Establece el formato de salida del registro; uno de raw, internal-json, bar o bar-with-logs.
•
--print-build-logs / -L
Imprime los registros completos de construcción en la salida de error estándar.
•
--quiet
Disminuye el nivel de verbosidad del registro.
•
--verbose / -v
Aumenta el nivel de verbosidad del registro.

Opciones globales varias

•
--help
Muestra información de uso.
•
--offline
Deshabilita los sustitutos y considera que todos los archivos descargados previamente están actualizados.
•
--option nombre valor
Establece la configuración de Nix nombre a valor (anulando nix.conf).
•
--refresh
Considera que todos los archivos descargados previamente están desactualizados.
•
--version
Muestra información de la versión.

Nota

Consulta man nix.conf para anular la configuración con indicadores de línea de comandos.
