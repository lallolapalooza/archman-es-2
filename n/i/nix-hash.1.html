nix-hash(1)

Paquete: nix

Licencias: LGPL-2.1-only

nix-hash(1) Manual de Comandos Generales nix-hash(1)

Nombre

nix-hash - calcula el hash criptográfico de una ruta

Sinopsis

nix-hash [--flat] [--base32] [--truncate] [--type hashAlgo] ruta…

nix-hash [--to-base16|--to-base32|--to-base64|--to-sri] [--type hashAlgo] hash…

Descripción

El comando nix-hash calcula el hash criptográfico del contenido de cada ruta y lo imprime en la salida estándar. Por defecto, calcula un hash MD5, pero también hay otros algoritmos de hash disponibles. El hash se imprime en hexadecimal. Para generar el mismo hash que nix-prefetch-url, debes especificar múltiples argumentos, ver más abajo para un ejemplo.

El hash se calcula sobre una serialización de cada ruta: una descarga del árbol del sistema de archivos con raíz en la ruta. Esto permite que directorios y enlaces simbólicos sean hasheados, así como archivos regulares. La descarga está en el formato Archivo Nix (NAR) producido por nix-store --dump. Por lo tanto, nix-hash ruta produce el mismo hash criptográfico que nix-store --dump ruta | md5sum.

Opciones

•
--flat
Imprime el hash criptográfico del contenido de cada archivo regular ruta. Es decir, en lugar de calcular el hash del Archivo Nix (NAR) de ruta, [calcula directamente el hash]((@docroot@/store/file-system-object/content-address.md#serial-flat) ruta tal cual. Esto requiere que ruta resuelva a un archivo regular en lugar de un directorio. El resultado es idéntico al producido por los comandos GNU md5sum y sha1sum.
•
--base16
Imprime el hash en una representación hexadecimal (por defecto).
•
--base32
Imprime el hash en una representación base-32 en lugar de hexadecimal. Esta representación base-32 es más compacta y puede usarse en expresiones Nix (como en llamadas a fetchurl).
•
--base64
Similar a –base32, pero imprime el hash en una representación base-64, que es más compacta que la base-32.
•
--sri
Imprime el hash en formato SRI con codificación base-64. El tipo de algoritmo de hash se antepondrá a la cadena del hash, seguido de un guion (-) y el cuerpo del hash en base-64.
•
--truncate
Trunca hashes más largos que 160 bits (como SHA-256) a 160 bits.
•
--type hashAlgo
Usa el algoritmo de hash criptográfico especificado, que puede ser uno de md5, sha1, sha256, y sha512.
•
--to-base16
No hashea nada, pero convierte la representación de hash base-32 hash a hexadecimal.
•
--to-base32
No hashea nada, pero convierte la representación de hash hexadecimal hash a base-32.
•
--to-base64
No hashea nada, pero convierte la representación de hash hexadecimal hash a base-64.
•
--to-sri
No hashea nada, pero convierte la representación de hash hexadecimal hash a SRI.

Ejemplos

Calculando el mismo hash que nix-prefetch-url:

$ nix-prefetch-url file://<(echo test)
1lkgqb6fclns49861dwk9rzb6xnfkxbpws74mxnx01z9qyv1pjpj
$ nix-hash --type sha256 --flat --base32 <(echo test)
1lkgqb6fclns49861dwk9rzb6xnfkxbpws74mxnx01z9qyv1pjpj

Calculando hashes:

$ mkdir test
$ echo "hello" > test/world
$ nix-hash test/ (hash MD5; por defecto)
8179d3caeff1869b5ba1744e5a245c04
$ nix-store --dump test/ | md5sum (para comparar)
8179d3caeff1869b5ba1744e5a245c04  -
$ nix-hash --type sha1 test/
e4fd8ba5f7bbeaea5ace89fe10255536cd60dab6
$ nix-hash --type sha1 --base16 test/
e4fd8ba5f7bbeaea5ace89fe10255536cd60dab6
$ nix-hash --type sha1 --base32 test/
nvd61k9nalji1zl9rrdfmsmvyyjqpzg4
$ nix-hash --type sha1 --base64 test/
5P2Lpfe76upazon+ECVVNs1g2rY=
$ nix-hash --type sha1 --sri test/
sha1-5P2Lpfe76upazon+ECVVNs1g2rY=
$ nix-hash --type sha256 --flat test/
error: reading file `test/': Is a directory
$ nix-hash --type sha256 --flat test/world
5891b5b522d5df086d0ff0b110fbd9d21bb4fc7163af34d08286a2e846f6be03

Convirtiendo entre hexadecimal, base-32, base-64 y SRI:

$ nix-hash --type sha1 --to-base32 e4fd8ba5f7bbeaea5ace89fe10255536cd60dab6
nvd61k9nalji1zl9rrdfmsmvyyjqpzg4
$ nix-hash --type sha1 --to-base16 nvd61k9nalji1zl9rrdfmsmvyyjqpzg4
e4fd8ba5f7bbeaea5ace89fe10255536cd60dab6
$ nix-hash --type sha1 --to-base64 e4fd8ba5f7bbeaea5ace89fe10255536cd60dab6
5P2Lpfe76upazon+ECVVNs1g2rY=
$ nix-hash --type sha1 --to-sri nvd61k9nalji1zl9rrdfmsmvyyjqpzg4
sha1-5P2Lpfe76upazon+ECVVNs1g2rY=
$ nix-hash --to-base16 sha1-5P2Lpfe76upazon+ECVVNs1g2rY=
e4fd8ba5f7bbeaea5ace89fe10255536cd60dab6
