nix3-upgrade-nix(1) Manual de comandos generales nix3-upgrade-nix(1)

Advertencia
Este programa es experimental y su interfaz está sujeta a cambios.

Nombre

nix upgrade-nix - actualizar Nix a la última versión estable

Sinopsis

nix upgrade-nix [opción…]

Ejemplos

•
Actualizar Nix a la versión estable declarada en Nixpkgs:
# nix upgrade-nix
•
Actualizar Nix en un perfil específico:
# nix upgrade-nix --profile ~alice/.local/state/nix/profiles/profile

Descripción

Este comando actualiza Nix a la versión estable.

Por defecto, la última versión estable está definida por Nixpkgs, en nix-fallback-paths.nix y se actualiza manualmente. Puede que no sea siempre la última versión etiquetada.

Por defecto, localiza el directorio que contiene el binario nix en la variable de entorno $PATH. Si ese directorio es un perfil de Nix, actualizará el paquete nix en ese perfil a la última versión binaria estable.

No puedes usar este comando para actualizar Nix en el perfil del sistema de un sistema NixOS (es decir, si nix se encuentra en /run/current-system).

Opciones

•
--dry-run
Muestra lo que haría este comando sin hacerlo.
•
--nix-store-paths-url url
La URL del archivo que contiene las rutas del almacén de la última versión de Nix.
•
--profile / -p perfil-dir
La ruta al perfil de Nix que se va a actualizar.

Opciones relacionadas con el registro

•
--debug
Establece el nivel de verbosidad del registro en ‘debug’.
•
--log-format formato
Establece el formato de la salida del registro; uno de raw, internal-json, bar o bar-with-logs.
•
--print-build-logs / -L
Imprime los registros de compilación completos en la salida de error estándar.
•
--quiet
Disminuye el nivel de verbosidad del registro.
•
--verbose / -v
Aumenta el nivel de verbosidad del registro.

Opciones globales varias

•
--help
Muestra información de uso.
•
--offline
Deshabilita los sustitutos y considera que todos los archivos descargados previamente están actualizados.
•
--option nombre valor
Establece la opción de configuración de Nix nombre a valor (anulando nix.conf).
•
--refresh
Considera que todos los archivos descargados previamente están desactualizados.
•
--version
Muestra información de la versión.

Nota

Consulta man nix.conf para anular la configuración con indicadores de línea de comandos.
