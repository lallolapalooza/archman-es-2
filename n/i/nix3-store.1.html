Advertencia
Este programa es experimental y su interfaz está sujeta a cambios.

Nombre

nix store - manipular una tienda Nix

Sinopsis

nix store [opción…] subcomando

donde subcomando es uno de los siguientes:

  • nix store add - Añadir un archivo o directorio a la tienda Nix
  • nix store add-file - Obsoleto. Usar nix store add --mode flat en su lugar.
  • nix store add-path - Alias obsoleto para nix store add.
  • nix store cat - Imprimir el contenido de un archivo en la tienda Nix en stdout
  • nix store copy-log - Copiar registros de compilación entre tiendas Nix
  • nix store copy-sigs - Copiar firmas de rutas de tienda desde sustitutos
  • nix store delete - Eliminar rutas de la tienda Nix
  • nix store diff-closures - Mostrar qué paquetes y versiones se han añadido y eliminado entre dos cierres
  • nix store dump-path - Serializar una ruta de tienda a stdout en formato NAR
  • nix store gc - Realizar recolección de basura en una tienda Nix
  • nix store info - Probar si se puede acceder a una tienda
  • nix store ls - Mostrar información sobre una ruta en la tienda Nix
  • nix store make-content-addressed - Reescribir una ruta o cierre a forma direccionada por contenido
  • nix store optimise - Reemplazar archivos idénticos en la tienda por enlaces duros
  • nix store path-from-hash-part - Obtener una ruta de tienda a partir de su parte de hash
  • nix store ping - Probar si se puede acceder a una tienda
  • nix store prefetch-file - Descargar un archivo en la tienda Nix
  • nix store repair - Reparar rutas de tienda
  • nix store sign - Firmar rutas de tienda con una clave local
  • nix store verify - Verificar la integridad de las rutas de tienda

Opciones

Opciones relacionadas con el registro

•
--debug
Establece el nivel de verbosidad del registro en 'debug'.
•
--log-format formato
Establece el formato de salida del registro; uno de raw, internal-json, bar o bar-with-logs.
•
--print-build-logs / -L
Imprime los registros de compilación completos en la salida de error estándar.
•
--quiet
Disminuye el nivel de verbosidad del registro.
•
--verbose / -v
Aumenta el nivel de verbosidad del registro.

Opciones globales varias

•
--help
Muestra información de uso.
•
--offline
Desactiva los sustitutos y considera todos los archivos descargados previamente como actualizados.
•
--option nombre valor
Establece la configuración de Nix nombre en valor (anulando nix.conf).
•
--refresh
Considera todos los archivos descargados previamente como no actualizados.
•
--version
Muestra información de la versión.

Nota

Consulta man nix.conf para anular la configuración con indicadores de línea de comandos.
