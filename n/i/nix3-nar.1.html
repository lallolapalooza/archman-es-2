nix3-nar(1) Manual de comandos generales nix3-nar(1)

Advertencia
Este programa es experimental y su interfaz está sujeta a cambios.

Nombre

nix nar - crear o inspeccionar archivos NAR

Sinopsis

nix nar [opción…] subcomando

donde subcomando es uno de los siguientes:

  • nix nar cat - imprime el contenido de un archivo dentro de un archivo NAR en stdout
  • nix nar dump-path - serializa una ruta a stdout en formato NAR
  • nix nar ls - muestra información sobre una ruta dentro de un archivo NAR
  • nix nar pack - serializa una ruta a stdout en formato NAR

Descripción

nix nar proporciona varios subcomandos para crear e inspeccionar Archivos Nix (NARs).

Formato de archivo

Para la definición del formato de archivo Nix Archive, consulte dentro del capítulo de protocolos del manual.

Opciones

Opciones relacionadas con el registro

•
--debug
Establece el nivel de verbosidad del registro en ‘debug’.
•
--log-format formato
Establece el formato de la salida del registro; uno de raw, internal-json, bar o bar-with-logs.
•
--print-build-logs / -L
Imprime los registros de compilación completos en la salida de error estándar.
•
--quiet
Disminuye el nivel de verbosidad del registro.
•
--verbose / -v
Aumenta el nivel de verbosidad del registro.

Opciones globales varias

•
--help
Muestra información de uso.
•
--offline
Deshabilita los sustitutos y considera todos los archivos descargados previamente como actualizados.
•
--option nombre valor
Establece la configuración de Nix nombre a valor (anulando nix.conf).
•
--refresh
Considera todos los archivos descargados previamente como desactualizados.
•
--version
Muestra información de la versión.

Nota

Consulte man nix.conf para anular la configuración con indicadores de línea de comandos.
