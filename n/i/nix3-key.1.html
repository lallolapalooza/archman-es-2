nix3-key(1)

Paquete: nix

nix3-key(1) Manual de comandos generales nix3-key(1)

Advertencia
Este programa es experimental y su interfaz está sujeta a cambios.

Nombre

nix key - generar y convertir claves de firma de Nix

Sinopsis

nix key [opción…] subcomando

donde subcomando es uno de los siguientes:

  • nix key convert-secret-to-public - generar una clave pública para verificar rutas de la tienda a partir de una clave secreta leída de la entrada estándar
  • nix key generate-secret - generar una clave secreta para firmar rutas de la tienda

Opciones

Opciones relacionadas con el registro

•
--debug
Establece el nivel de verbosidad del registro en 'debug'.
•
--log-format formato
Establece el formato de la salida del registro; uno de raw, internal-json, bar o bar-with-logs.
•
--print-build-logs / -L
Imprime registros de compilación completos en el error estándar.
•
--quiet
Disminuye el nivel de verbosidad del registro.
•
--verbose / -v
Aumenta el nivel de verbosidad del registro.

Opciones globales misceláneas

•
--help
Muestra información de uso.
•
--offline
Deshabilita los sustitutos y considera todos los archivos descargados previamente como actualizados.
•
--option nombre valor
Establece la configuración de Nix nombre en valor (anulando nix.conf).
•
--refresh
Considera todos los archivos descargados previamente como desactualizados.
•
--version
Muestra información de la versión.

Nota

Ver man nix.conf para anular la configuración con indicadores de línea de comandos.
