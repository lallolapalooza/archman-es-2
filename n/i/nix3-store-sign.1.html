Advertencia
Este programa es experimental y su interfaz está sujeta a cambios.

Nombre

nix store sign - firma rutas del store con una clave local

Sinopsis

nix store sign [opción…] instalables…

Opciones

•
--key-file / -k archivo
Archivo que contiene la clave secreta de firma.
•
--stdin
Lee los instalables de la entrada estándar. No se aplica ningún instalable predeterminado.

Opciones comunes de evaluación

•
--arg nombre expr
Pasa el valor expr como el argumento nombre a las funciones de Nix.
•
--arg-from-file nombre ruta
Pasa el contenido del archivo ruta como el argumento nombre a las funciones de Nix.
•
--arg-from-stdin nombre
Pasa el contenido de stdin como el argumento nombre a las funciones de Nix.
•
--argstr nombre cadena
Pasa la cadena cadena como el argumento nombre a las funciones de Nix.
•
--debugger
Inicia un entorno interactivo si la evaluación falla.
•
--eval-store url-del-store
La URL del store de Nix a utilizar para la evaluación, es decir, para almacenar derivaciones (.drv archivos) y las entradas referenciadas por ellas.
•
--impure
Permite el acceso a rutas y repositorios mutables.
•
--include / -I ruta
Añade ruta a las entradas de la ruta de búsqueda utilizadas para resolver rutas de búsqueda
Esta opción puede darse varias veces.
Las rutas añadidas a través de -I tienen prioridad sobre la configuración nix-path y la variable de entorno NIX_PATH.
•
--override-flake ref-original ref-resuelto
Sobrescribe los registros de flake, redirigiendo ref-original a ref-resuelto.

Opciones comunes relacionadas con flakes

•
--commit-lock-file
Confirma los cambios en el archivo de bloqueo del flake.
•
--inputs-from url-del-flake
Usa las entradas del flake especificado como entradas de registro.
•
--no-registries
No permite búsquedas en los registros de flakes.
OBSOLETO
Usa --no-use-registries en su lugar.
•
--no-update-lock-file
No permite ninguna actualización del archivo de bloqueo del flake.
•
--no-write-lock-file
No escribe el archivo de bloqueo recién generado del flake.
•
--output-lock-file ruta-del-archivo-de-bloqueo-del-flake
Escribe el archivo de bloqueo dado en lugar de flake.lock dentro del flake de nivel superior.
•
--override-input ruta-de-entrada url-del-flake
Sobrescribe una entrada de flake específica (por ejemplo, dwarffs/nixpkgs). Esto implica --no-write-lock-file.
•
--recreate-lock-file
Recrea el archivo de bloqueo del flake desde cero.
OBSOLETO
Usa nix flake update en su lugar.
•
--reference-lock-file ruta-del-archivo-de-bloqueo-del-flake
Lee el archivo de bloqueo dado en lugar de flake.lock dentro del flake de nivel superior.
•
--update-input ruta-de-entrada
Actualiza una entrada de flake específica (ignorando su entrada anterior en el archivo de bloqueo).
OBSOLETO
Usa nix flake update en su lugar.

Opciones relacionadas con el registro

•
--debug
Establece el nivel de verbosidad del registro en 'debug'.
•
--log-format formato
Establece el formato de la salida del registro; una de raw, internal-json, bar o bar-with-logs.
•
--print-build-logs / -L
Imprime los registros completos de compilación en el error estándar.
•
--quiet
Disminuye la verbosidad del registro.

NAME

nix-index - build or query the Nix expression search index

SYNOPSIS

nix-index [option...]

DESCRIPTION

This command builds or queries the Nix expression search index. The index is a database of Nix attribute paths and the store paths they resolve to. It allows for fast lookups of Nix derivations given their attribute path, and vice versa.

The index is built by scanning all Nix expressions in $NIX_PATH (or, if that is unset, in ~/.nix-defexpr). It is stored in ~/.nix-index. The index is usually built on the fly when an expression is accessed for the first time.

If the index is absent or out of date, nix-index will rebuild it.

There are no subcommands. All functionality is accessed via command line options.

Options for building the index

•
--build-dir dir
The directory in which to build the index. Default is ~/.nix-index.
•
--read-only
Build the index in memory, but don't write it to disk. This is useful for temporary indexes.
•
--ignore-path path
Ignore the given path when building the index. This option can be used multiple times.
•
--include-path path
Include the given path when building the index. This option can be used multiple times.
•
--refresh
Force a rebuild of the index, even if it's not out of date.
•
--gc-args args
Passes the given arguments to `nix-collect-garbage` when building the index. This is useful for cleaning up the Nix store before building the index.

Options for querying the index

•
--query query
Query the index for the given attribute path. The output will be the store path corresponding to the attribute path.
•
--attribute attrpath
Query the index for the given attribute path. The output will be the store path corresponding to the attribute path.
•
--path path
Query the index for the given store path. The output will be the attribute path corresponding to the store path.
•
--regex regex
Query the index for attribute paths matching the given regular expression. The output will be a list of attribute paths.
•
--name name
Query the index for attribute paths whose name matches the given string. This is a convenience option that is equivalent to --regex ".*/name$".

General options

•
--verbose / -v
Increase the logging verbosity level.

Miscellaneous global options

•
--help
Show usage information.
•
--offline
Disable substituters and consider all previously downloaded files up-to-date.
•
--option name value
Set the Nix configuration setting name to value (overriding nix.conf).
•
--refresh
Consider all previously downloaded files out-of-date.
•
--repair
During evaluation, rewrite missing or corrupted files in the Nix store. During building, rebuild missing or corrupted store paths.
•
--version
Show version information.

Options that change the interpretation of installables

•
--all
Apply the operation to every store path.
•
--derivation
Operate on the store derivation rather than its outputs.
•
--expr expr
Interpret installables as attribute paths relative to the Nix expression expr.
•
--file / -f file
Interpret installables as attribute paths relative to the Nix expression stored in file. If file is the character -, then a Nix expression will be read from standard input. Implies --impure.
•
--recursive / -r
Apply operation to closure of the specified paths.

Note

See man nix.conf for overriding configuration settings with command line flags.
