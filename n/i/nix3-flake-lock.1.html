nix3-flake-lock(1) Manual de Comandos Generales nix3-flake-lock(1)

Advertencia
Este programa es experimental y su interfaz está sujeta a cambios.

Nombre

nix flake lock - crear entradas faltantes en el archivo de bloqueo

Sintaxis

nix flake lock [opción…] url-del-flake

Ejemplos

•
Crear el archivo de bloqueo para el flake en el directorio actual:
# nix flake lock
advertencia: creando archivo de bloqueo '/home/myself/repos/testflake/flake.lock':
• Entrada añadida 'nix':
  'github:NixOS/nix/9fab14adbc3810d5cc1f88672fde1eee4358405c' (2023-06-28)
• Entrada añadida 'nixpkgs':
  'github:NixOS/nixpkgs/3d2d8f281a27d466fa54b469b5993f7dde198375' (2023-06-30)
•
Añadir entradas faltantes al archivo de bloqueo para un flake en un directorio diferente:
# nix flake lock ~/repos/another
advertencia: actualizando archivo de bloqueo '/home/myself/repos/another/flake.lock':
• Entrada añadida 'nixpkgs':
  'github:NixOS/nixpkgs/3d2d8f281a27d466fa54b469b5993f7dde198375' (2023-06-30)
Nota
Al intentar referirse a un flake en un subdirectorio, escriba ./otro en lugar de otro. De lo contrario, Nix intentará buscar el flake en el registro.

Descripción

Este comando añade entradas a el archivo de bloqueo de un flake (flake.lock) para que contenga un bloqueo para cada entrada de flake especificada en flake.nix. Las entradas existentes del archivo de bloqueo no se actualizan.

Si desea actualizar las entradas de bloqueo existentes, utilice nix flake update

Opciones

Opciones comunes de evaluación

•
--arg nombre expresión
Pasa el valor expresión como argumento nombre a las funciones de Nix.
•
--arg-from-file nombre ruta
Pasa el contenido del archivo ruta como argumento nombre a las funciones de Nix.
•
--arg-from-stdin nombre
Pasa el contenido de la entrada estándar como argumento nombre a las funciones de Nix.
•
--argstr nombre cadena
Pasa la cadena cadena como argumento nombre a las funciones de Nix.
•
--debugger
Inicia un entorno interactivo si la evaluación falla.
•
--eval-store url-del-almacén
La URL del almacén de Nix a utilizar para la evaluación, es decir, para almacenar derivaciones (.drv) y las entradas referenciadas por ellas.
•
--impure
Permite el acceso a rutas y repositorios mutables.
•
--include / -I ruta
Añade ruta a las entradas de la ruta de búsqueda utilizadas para resolver rutas de búsqueda
Esta opción se puede dar varias veces.
Las rutas añadidas a través de -I tienen prioridad sobre la configuración nix-path y la variable de entorno NIX_PATH.
•
--override-flake ref-original ref-resuelto
Sobrescribe los registros de flakes, redirigiendo ref-original a ref-resuelto.

Opciones comunes relacionadas con flakes

•
--commit-lock-file
Confirma los cambios en el archivo de bloqueo del flake.
•
--inputs-from url-del-flake
Utiliza las entradas del flake especificado como entradas de registro.
•
--no-registries
No permite búsquedas en los registros de flakes.
OBSOLETO
Utilice --no-use-registries en su lugar.
•
--no-update-lock-file
No permite ninguna actualización del archivo de bloqueo del flake.
•
--output-lock-file ruta-del-archivo-de-bloqueo
Escribe el archivo de bloqueo dado en lugar de flake.lock dentro del flake de nivel superior.
•
--override-input ruta-de-la-entrada url-del-flake
Sobrescribe una entrada de flake específica (por ejemplo, dwarffs/nixpkgs). Esto implica --no-write-lock-file.
•
--recreate-lock-file
Recrea el archivo de bloqueo del flake desde cero.
OBSOLETO
Utilice nix flake update en su lugar.
•
--reference-lock-file ruta-del-archivo-de-bloqueo
Lee el archivo de bloqueo dado en lugar de flake.lock dentro del flake de nivel superior.
•
--update-input ruta-de-la-entrada
Actualiza una entrada de flake específica (ignorando su entrada anterior en el archivo de bloqueo).
OBSOLETO
Utilice nix flake update en su lugar.

Opciones relacionadas con el registro de mensajes

•
--debug
Muestra mensajes de depuración.
•
--no-debug
No muestra mensajes de depuración.
•
--log-format formato
El formato de los mensajes de registro es raw, json, o pretty.
•
--verbose / -v
Aumenta la verbosidad del registro.
Esta opción se puede dar varias veces.
•
--quiet / -q
Disminuye la verbosidad del registro.
Esta opción se puede dar varias veces.
•
--show-trace
Muestra información detallada de rastreo si la evaluación falla.

Configuración centralizada

Las siguientes opciones pueden ser establecidas en el archivo de configuración de Nix (nix.conf):

•
commit-lock-file
•
flake-registry
•
flake-use-registries
•
flake-no-update-lock-file
•
flake-output-lock-file
•
flake-recreate-lock-file
•
flake-reference-lock-file
