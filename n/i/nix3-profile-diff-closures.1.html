nix3-profile-diff-closures(1) Manual de Comandos Generales nix3-profile-diff-closures(1)

Advertencia
Este programa es experimental y su interfaz está sujeta a cambios.

Nombre

nix profile diff-closures - muestra la diferencia de clausura entre cada versión de un perfil

Sinopsis

nix profile diff-closures [opción•]

Ejemplos

•
Mostrar qué cambió entre cada versión del perfil del sistema NixOS:
# nix profile diff-closures --profile /nix/var/nix/profiles/system
Versión 13 -> 14:
acpi-call: 2020-04-07-5.8.13 → 2020-04-07-5.8.14
aws-sdk-cpp: -6723.1 KiB
…
Versión 14 -> 15:
acpi-call: 2020-04-07-5.8.14 → 2020-04-07-5.8.16
attica: -996.2 KiB
breeze-icons: -78713.5 KiB
brotli: 1.0.7 → 1.0.9, +44.2 KiB

Descripción

Este comando muestra la diferencia entre las clausuras de versiones consecutivas de un perfil. Consulte nix store diff-closures para más detalles.

Opciones

•
--profile ruta
El perfil sobre el que operar.

Opciones relacionadas con el registro

•
--debug
Establece el nivel de verbosidad del registro en 'debug'.
•
--log-format formato
Establece el formato de salida del registro; uno de raw, internal-json, bar o bar-with-logs.
•
--print-build-logs / -L
Imprime los registros de construcción completos en la salida de error estándar.
•
--quiet
Disminuye el nivel de verbosidad del registro.
•
--verbose / -v
Aumenta el nivel de verbosidad del registro.

Opciones globales varias

•
--help
Muestra información de uso.
•
--offline
Deshabilita los sustitutos y considera todos los archivos descargados previamente como actualizados.
•
--option nombre valor
Establece la configuración de Nix nombre a valor (anulando nix.conf).
•
--refresh
Considera todos los archivos descargados previamente como no actualizados.
•
--version
Muestra información de la versión.

Nota

Consulte man nix.conf para anular la configuración con flags de línea de comandos.
