nix3-fmt(1)

Paquete: nix

Licencias: LGPL-2.1-only

nix3-fmt(1) Manual de comandos generales nix3-fmt(1)

Advertencia
Este programa es experimental y su interfaz está sujeta a cambios.

Nombre

nix fmt - reformatea tu código con el estilo estándar

Sinopsis

nix fmt [opción•] args•

Ejemplos

Con nixpkgs-fmt:

# flake.nix
{
  outputs = { nixpkgs, self }: {
    formatter.x86_64-linux = nixpkgs.legacyPackages.x86_64-linux.nixpkgs-fmt;
  };
}
  • Formatea el flake actual: $ nix fmt
  • Formatea una carpeta o archivo específico: $ nix fmt ./carpeta ./archivo.nix

Con nixfmt:

# flake.nix
{
  outputs = { nixpkgs, self }: {
    formatter.x86_64-linux = nixpkgs.legacyPackages.x86_64-linux.nixfmt;
  };
}
•
Formatea archivos específicos: $ nix fmt ./archivo1.nix ./archivo2.nix

Con Alejandra:

# flake.nix
{
  outputs = { nixpkgs, self }: {
    formatter.x86_64-linux = nixpkgs.legacyPackages.x86_64-linux.alejandra;
  };
}
  • Formatea el flake actual: $ nix fmt
  • Formatea una carpeta o archivo específico: $ nix fmt ./carpeta ./archivo.nix

Descripción

nix fmt reescribirá todos los archivos Nix (*.nix) a un formato canónico utilizando el formateador especificado en tu flake.

Opciones

Opciones comunes de evaluación

•
--arg nombre expresión
Pasa el valor expresión como argumento nombre a las funciones de Nix.
•
--arg-from-file nombre ruta
Pasa el contenido del archivo ruta como argumento nombre a las funciones de Nix.
•
--arg-from-stdin nombre
Pasa el contenido de stdin como argumento nombre a las funciones de Nix.
•
--argstr nombre cadena
Pasa la cadena cadena como argumento nombre a las funciones de Nix.
•
--debugger
Inicia un entorno interactivo si la evaluación falla.
•
--eval-store url-tienda
La URL de la tienda Nix a utilizar para la evaluación, es decir, para almacenar derivaciones (archivos .drv) y las entradas referenciadas por ellas.
•
--impure
Permite el acceso a rutas y repositorios mutables.
•
--include / -I ruta
Añade ruta a las entradas de la ruta de búsqueda utilizadas para resolver rutas de búsqueda
Esta opción puede darse varias veces.
Las rutas añadidas a través de -I tienen prioridad sobre la configuración nix-path y la variable de entorno NIX_PATH.
•
--override-flake ref-original ref-resuelto
Sobrescribe los registros de flakes, redirigiendo ref-original a ref-resuelto.

Opciones comunes relacionadas con flakes

•
--commit-lock-file
Confirma los cambios en el archivo de bloqueo del flake.
•
--inputs-from flake-url
Utiliza las entradas del flake especificado como entradas de registro.
•
--no-registries
No permite búsquedas en los registros de flakes.
OBSOLETO
Utiliza --no-use-registries en su lugar.
•
--no-update-lock-file
No permite ninguna actualización del archivo de bloqueo del flake.
•
--no-write-lock-file
No escribe el archivo de bloqueo del flake recién generado.
•
--output-lock-file ruta-flake-lock
Escribe el archivo de bloqueo dado en lugar de flake.lock dentro del flake de nivel superior.
•
--override-input ruta-entrada flake-url
Sobrescribe una entrada de flake específica (por ejemplo, dwarffs/nixpkgs). Esto implica --no-write-lock-file.
•
--recreate-lock-file
Recrea el archivo de bloqueo del flake desde cero.
OBSOLETO
Utiliza nix flake update en su lugar.
•
--reference-lock-file ruta-flake-lock
Lee el archivo de bloqueo dado en lugar de flake.lock dentro del flake de nivel superior.
•
--update-input ruta-entrada
Actualiza una entrada de flake específica (ignorando su entrada anterior en el archivo de bloqueo).
OBSOLETO
Utiliza nix flake update en su lugar.

Opciones relacionadas con el registro

•
--debug
Establece el nivel de verbosidad del registro en "debug".
•
--log-format formato
Establece el formato de salida del registro; uno de raw, internal-json, bar o bar-with-logs.
•
--print-build-logs / -L
Imprime los registros de compilación completos en la salida estándar de error.
•
--quiet
Disminuye el nivel de verbosidad del registro.
•
--verbose / -v
Aumenta el nivel de verbosidad del registro.

Opciones globales varias

•
--help
Muestra información de uso.
•
--offline
Desactiva los sustitutos y considera que todos los archivos descargados previamente están actualizados.
•
--option nombre valor
Establece la configuración de Nix nombre en valor (anulando nix.conf).
•
--refresh
Considera que todos los archivos descargados previamente están desactualizados.
•
--repair
Durante la evaluación, reescribe los archivos faltantes o corruptos en la tienda de Nix. Durante la compilación, recompila las rutas de la tienda faltantes o corruptas.
•
--version
Muestra información de la versión.

Opciones que cambian la interpretación de instalables

•
--expr expr
Interpreta instalables como rutas de atributos relativas a la expresión de Nix expr.
•
--file / -f archivo
Interpreta instalables como rutas de atributos relativas a la expresión de Nix almacenada en archivo. Si archivo es el carácter -, entonces se leerá una expresión de Nix de la entrada estándar. Implica --impure.

Nota

Consulta man nix.conf para anular la configuración con indicadores de línea de comandos.
