nix3-store-delete(1)

Paquete: nix

Licencias: LGPL-2.1-only

nix3-store-delete(1) Manual de comandos generales nix3-store-delete(1)

Advertencia
Este programa es experimental y su interfaz está sujeta a cambios.

Nombre

nix store delete - eliminar rutas del almacén Nix

Sinopsis

nix store delete [opción…] instalables…

Ejemplos

•
Eliminar una ruta de almacén específica:
# nix store delete /nix/store/yb5q57zxv6hgqql42d5r8b5k5mcq6kay-hello-2.10

Descripción

Este comando elimina las rutas del almacén especificadas por instalables, pero solo si es seguro hacerlo; es decir, cuando la ruta no es alcanzable desde una raíz del recolector de basura. Esto significa que solo puedes eliminar rutas que también serían eliminadas por nix store gc. Por lo tanto, nix store delete es una versión más específica de nix store gc.

Con la opción --ignore-liveness, la alcanzabilidad desde las raíces se ignora. Sin embargo, la ruta aún no se eliminará si hay otras rutas en el almacén que la refieran (es decir, que dependan de ella).

Opciones

•
--ignore-liveness
No comprueba si las rutas son alcanzables desde una raíz.
•
--stdin
Lee los instalables desde la entrada estándar. No se aplica ningún instalable predeterminado.

Opciones comunes de evaluación

•
--arg name expr
Pasa el valor expr como argumento name a las funciones de Nix.
•
--arg-from-file name path
Pasa el contenido del archivo path como argumento name a las funciones de Nix.
•
--arg-from-stdin name
Pasa el contenido de la entrada estándar como argumento name a las funciones de Nix.
•
--argstr name string
Pasa la cadena string como argumento name a las funciones de Nix.
•
--debugger
Inicia un entorno interactivo si la evaluación falla.
•
--eval-store store-url
La URL del almacén Nix a utilizar para la evaluación, es decir, para almacenar derivaciones (.drv) y las entradas referenciadas por ellas.
•
--impure
Permite el acceso a rutas y repositorios mutables.
•
--include / -I path
Añade path a las entradas de la ruta de búsqueda utilizadas para resolver rutas de búsqueda
Esta opción se puede dar varias veces.
Las rutas añadidas a través de -I tienen prioridad sobre la configuración nix-path y la variable de entorno NIX_PATH.
•
--override-flake original-ref resolved-ref
Anula los registros de flake, redirigiendo original-ref a resolved-ref.

Opciones comunes relacionadas con flakes

•
--commit-lock-file
Confirma los cambios en el archivo de bloqueo del flake.
•
--inputs-from flake-url
Utiliza las entradas del flake especificado como entradas de registro.
•
--no-registries
No permite búsquedas en los registros de flakes.
OBSOLETO
Utiliza --no-use-registries en su lugar.
•
--no-update-lock-file
No permite ninguna actualización del archivo de bloqueo del flake.
•
--no-write-lock-file
No escribe el archivo de bloqueo recién generado del flake.
•
--output-lock-file flake-lock-path
Escribe el archivo de bloqueo dado en lugar de flake.lock dentro del flake de nivel superior.
•
--override-input input-path flake-url
Anula una entrada de flake específica (por ejemplo, dwarffs/nixpkgs). Esto implica --no-write-lock-file.
•
--recreate-lock-file
Recrea el archivo de bloqueo del flake desde cero.
OBSOLETO
Utiliza nix flake update en su lugar.
•
--reference-lock-file flake-lock-path
Lee el archivo de bloqueo dado en lugar de flake.lock dentro del flake de nivel superior.
•
--update-input input-path
Actualiza una entrada de flake específica (ignorando su entrada anterior en el archivo de bloqueo).
OBSOLETO
Utiliza nix flake update en su lugar.
