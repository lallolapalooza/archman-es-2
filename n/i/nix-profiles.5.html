Perfiles

Un directorio que contiene enlaces simbólicos a perfiles gestionados por nix-env y nix profile:

  • $XDG_STATE_HOME/nix/profiles para usuarios regulares
  • $NIX_STATE_DIR/profiles/per-user/root si el usuario es root

Un perfil es un directorio de enlaces simbólicos a archivos en el almacén de Nix.

Diseño del sistema de archivos

Los perfiles se versionan de la siguiente manera. Al usar un perfil llamado ruta, ruta es un enlace simbólico a ruta-N-link, donde N es la versión del perfil. A su vez, ruta-N-link es un enlace simbólico a una ruta en el almacén de Nix. Por ejemplo:

$ ls -l ~alice/.local/state/nix/profiles/profile*
lrwxrwxrwx 1 alice users 14 Nov 25 14:35 /home/alice/.local/state/nix/profiles/profile -> profile-7-link
lrwxrwxrwx 1 alice users 51 Oct 28 16:18 /home/alice/.local/state/nix/profiles/profile-5-link -> /nix/store/q69xad13ghpf7ir87h0b2gd28lafjj1j-profile
lrwxrwxrwx 1 alice users 51 Oct 29 13:20 /home/alice/.local/state/nix/profiles/profile-6-link -> /nix/store/6bvhpysd7vwz7k3b0pndn7ifi5xr32dg-profile
lrwxrwxrwx 1 alice users 51 Nov 25 14:35 /home/alice/.local/state/nix/profiles/profile-7-link -> /nix/store/mp0x6xnsg0b8qhswy6riqvimai4gm677-profile

Cada uno de estos enlaces simbólicos es una raíz para el recolector de basura de Nix.

El contenido de la ruta del almacén correspondiente a cada versión del perfil es un árbol de enlaces simbólicos a los archivos de los paquetes instalados, por ejemplo:

Cada versión del perfil contiene un archivo de manifiesto: - manifest.nix utilizado por nix-env. - manifest.json utilizado por nix profile (experimental).

Enlace de perfil de usuario

Un enlace simbólico al perfil actual del usuario:

  • ~/.nix-profile
  • $XDG_STATE_HOME/nix/profile si use-xdg-base-directories está configurado como true.

Por defecto, este enlace simbólico apunta a:

  • $XDG_STATE_HOME/nix/profiles/profile para usuarios regulares
  • $NIX_STATE_DIR/profiles/per-user/root/profile para root

La variable de entorno PATH debería incluir el subdirectorio /bin del enlace del perfil (por ejemplo, ~/.nix-profile/bin) para que el entorno del usuario sea visible para el usuario. El instalador configura esto por defecto, a menos que habilite use-xdg-base-directories.
