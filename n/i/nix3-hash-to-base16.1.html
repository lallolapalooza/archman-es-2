nix3-hash-to-base16(1) Manual de Comandos Generales nix3-hash-to-base16(1)

Advertencia
Este programa es experimental y su interfaz está sujeta a cambios.

Nombre

nix hash to-base16 - convertir un hash a representación base-16 (obsoleto, use nix hash convert en su lugar)

Sinopsis

nix hash to-base16 [opción…] cadenas…

Opciones

•
--type algoritmo-hash
Algoritmo de hash (md5, sha1, sha256 o sha512). Puede omitirse para hashes SRI.

Opciones relacionadas con el registro

•
--debug
Establece el nivel de verbosidad del registro a 'debug'.
•
--log-format formato
Establece el formato de la salida del registro; uno de raw, internal-json, bar o bar-with-logs.
•
--print-build-logs / -L
Imprime los registros de compilación completos en la salida de error estándar.
•
--quiet
Disminuye el nivel de verbosidad del registro.
•
--verbose / -v
Aumenta el nivel de verbosidad del registro.

Opciones globales varias

•
--help
Muestra información de uso.
•
--offline
Deshabilita los sustitutos y considera todos los archivos descargados previamente como actualizados.
•
--option nombre valor
Establece la configuración de Nix nombre a valor (anulando nix.conf).
•
--refresh
Considera todos los archivos descargados previamente como no actualizados.
•
--version
Muestra información de la versión.

Nota

Consulte man nix.conf para anular la configuración con indicadores de línea de comandos.
