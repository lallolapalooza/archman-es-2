Nombre

nix store copy-sigs - copiar firmas de rutas de almacenamiento de sustitutos

Sinopsis

nix store copy-sigs [opción…] instalables…

Opciones

•
--stdin
Leer instalables desde la entrada estándar. No se aplica ningún instalable por defecto.
•
--substituter / -s uri-almacenamiento
Copiar firmas del almacenamiento especificado.

Opciones comunes de evaluación

•
--arg nombre expresión
Pasar el valor expresión como argumento nombre a las funciones de Nix.
•
--arg-from-file nombre ruta
Pasar el contenido del archivo ruta como argumento nombre a las funciones de Nix.
•
--arg-from-stdin nombre
Pasar el contenido de la entrada estándar como argumento nombre a las funciones de Nix.
•
--argstr nombre cadena
Pasar la cadena cadena como argumento nombre a las funciones de Nix.
•
--debugger
Iniciar un entorno interactivo si la evaluación falla.
•
--eval-store url-almacenamiento
La URL del almacenamiento de Nix a utilizar para la evaluación, es decir, para almacenar derivaciones (.drv archivos) y las entradas a las que hacen referencia.
•
--impure
Permitir acceso a rutas mutables y repositorios.
•
--include / -I ruta
Añadir ruta a las entradas de la ruta de búsqueda utilizadas para resolver rutas de búsqueda
Esta opción se puede proporcionar varias veces.
Las rutas añadidas a través de -I tienen prioridad sobre la configuración nix-path y la variable de entorno NIX_PATH .
•
--override-flake ref-original ref-resuelto
Sobrescribir los registros de flakes, redirigiendo ref-original a ref-resuelto.

Opciones comunes relacionadas con flakes

•
--commit-lock-file

--inputs-from flake-url
Utilizar las entradas del flake especificado como entradas de registro.
•
--no-registries
No permitir búsquedas en los registros de flakes.

Utilizar --no-use-registries en su lugar.
•
--no-update-lock-file
No permitir ninguna actualización del archivo de bloqueo del flake.
•
--no-write-lock-file
No escribir el archivo de bloqueo recién generado del flake.
•
--output-lock-file ruta-bloqueo-flake
Escribir el archivo de bloqueo dado en lugar de flake.lock dentro del flake de nivel superior.
•
--override-input ruta-entrada flake-url
Sobrescribir una entrada de flake específica (por ejemplo, dwarffs/nixpkgs). Esto implica --no-write-lock-file.
•
--recreate-lock-file
Recrear el archivo de bloqueo del flake desde cero.
OBSOLETO
Utilizar nix flake update en su lugar.
•
--reference-lock-file ruta-bloqueo-flake
Leer el archivo de bloqueo dado en lugar de flake.lock dentro del flake de nivel superior.
•
--update-input ruta-entrada
Actualizar una entrada de flake específica (ignorando su entrada anterior en el archivo de bloqueo).
OBSOLETO
Utilizar nix flake update en su lugar.

NIX3-STORE-COPY-SIGS(1)

Nix manual

SYNOPSIS

  nix3-store-copy-sigs [--help | -? | --version]

DESCRIPTION

This is an internal command.

Copies signatures from one store path to another. This is primarily used for updating the signature of a store path from the original store path if the latter is available.

OPTIONS

Logging options

•
--quiet / -q
Decrease the logging verbosity level.
•
--verbose / -v
Increase the logging verbosity level.

Miscellaneous global options

•
--help
Show usage information.
•
--offline
Disable substituters and consider all previously downloaded files up-to-date.
•
--option name value
Set the Nix configuration setting name to value (overriding nix.conf).
•
--refresh
Consider all previously downloaded files out-of-date.
•
--repair
During evaluation, rewrite missing or corrupted files in the Nix store. During building, rebuild missing or corrupted store paths.
•
--version
Show version information.

Options that change the interpretation of installables

•
--all
Apply the operation to every store path.
•
--derivation
Operate on the store derivation rather than its outputs.
•
--expr expr
Interpret installables as attribute paths relative to the Nix expression expr.
•
--file / -f file
Interpret installables as attribute paths relative to the Nix expression stored in file. If file is the character -, then a Nix expression will be read from standard input. Implies --impure.
•
--recursive / -r
Apply operation to closure of the specified paths.

Note

See man nix.conf for overriding configuration settings with command line flags.
