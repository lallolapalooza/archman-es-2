nix3-build(1)

Paquete: nix

Licencias: LGPL-2.1-only

nix3-build(1) Manual de Comandos Generales nix3-build(1)

Advertencia
Este programa es experimental y su interfaz está sujeta a cambios.

Nombre

nix build - construir una derivación o obtener una ruta de almacén

Sinopsis

nix build [opción…] instalables…

Ejemplos

•
Construir el paquete por defecto del flake en el directorio actual:
# nix build
•
Construir y ejecutar GNU Hello desde el flake de nixpkgs:
# nix build nixpkgs#hello
# ./result/bin/hello
Hello, world!
•
Construir GNU Hello y Cowsay, dejando dos enlaces simbólicos de resultado:
# nix build nixpkgs#hello nixpkgs#cowsay
# ls -l result*
lrwxrwxrwx 1 … result -> /nix/store/v5sv61sszx301i0x6xysaqzla09nksnd-hello-2.10
lrwxrwxrwx 1 … result-1 -> /nix/store/rkfrm0z6x6jmi7d3gsmma4j53h15mg33-cowsay-3.03+dfsg2
•
Construir GNU Hello e imprimir la ruta de almacén resultante.
# nix build nixpkgs#hello --print-out-paths
/nix/store/v5sv61sszx301i0x6xysaqzla09nksnd-hello-2.10
•
Construir una salida específica:
# nix build nixpkgs#glibc.dev
# ls -ld ./result-dev
lrwxrwxrwx 1 … ./result-dev -> /nix/store/dkm3gwl0xrx0wrw6zi5x3px3lpgjhlw4-glibc-2.32-dev
•
Construir todas las salidas:
# nix build "nixpkgs#openssl^*" --print-out-paths
/nix/store/gvad6v0cmq1qccmc4wphsazqbj0xzjsl-openssl-3.0.13-bin
/nix/store/a07jqdrc8afnk8r6f3lnhh4gvab7chk4-openssl-3.0.13-debug
/nix/store/yg75achq89wgqn2fi3gglgsd77kjpi03-openssl-3.0.13-dev
/nix/store/bvdcihi8c88fw31cg6gzzmpnwglpn1jv-openssl-3.0.13-doc
/nix/store/gjqcvq47cmxazxga0cirspm3jywkmvfv-openssl-3.0.13-man
/nix/store/7nmrrad8skxr47f9hfl3xc0pfqmwq51b-openssl-3.0.13
•
Construir el atributo build.x86_64-linux de la expresión Nix (no-flake) release.nix:
# nix build --file release.nix build.x86_64-linux
•
Construir una configuración de sistema NixOS desde un flake, y hacer que un perfil apunte al resultado:
# nix build --profile /nix/var/nix/profiles/system \
  ~/my-configurations#nixosConfigurations.machine.config.system.build.toplevel
(Esto es esencialmente lo que hace nixos-rebuild.)
•
Construir una expresión especificada en la línea de comandos:
# nix build --impure --expr \
  'with import <nixpkgs> {};
   runCommand "foo" {
     buildInputs = [ hello ];
   }
   "hello > $out"'
# cat ./result
Hello, world!
Nótese que se necesita --impure porque estamos utilizando <nixpkgs>, lo cual depende de la variable de entorno $NIX_PATH.
•
Obtener una ruta de almacén de los sustitutos configurados, si aún no existe:
# nix build /nix/store/rkfrm0z6x6jmi7d3gsmma4j53h15mg33-cowsay-3.03+dfsg2

Descripción

nix build construye los instalables especificados. Los instalables que se resuelven a derivaciones se construyen (o se sustituyen si es posible). Los instalables de ruta de almacén se sustituyen.

A menos que se especifique --no-link, después de una construcción exitosa, crea enlaces simbólicos a las rutas de almacén de los instalables. Estos enlaces simbólicos tienen el prefijo ./result por defecto; esto se puede anular usando la opción --out-link. Cada enlace simbólico tiene un sufijo -<N>-<nombre_salida>, donde N es el índice del instalable (con el instalable más a la izquierda teniendo el índice 0), y nombre_salida es el nombre simbólico de la salida de la derivación (por ejemplo, bin, dev o lib). Se omite -<N> si N = 0, y se omite -<nombre_salida> si nombre_salida = out (denotando la salida por defecto).

Opciones

•
--dry-run
Muestra lo que haría este comando sin hacerlo.
•
--json
Produce salida en formato JSON, adecuado para ser consumido por otro programa.
•
--no-link
No crear enlaces simbólicos a los resultados de la construcción.
•
--out-link / -o ruta
Usa ruta como prefijo para los enlaces simbólicos a los resultados de la construcción. Por defecto es result.
•
--print-out-paths
Imprime las rutas de salida resultantes
•
--profile ruta
El perfil sobre el que operar.
•
--rebuild
Reconstruye un paquete ya construido y compara el resultado con las rutas de almacén existentes.
•
--stdin
Lee instalables desde la entrada estándar. No se aplica ningún instalable por defecto.

Opciones comunes de evaluación

•
--arg nombre expr
Pasa el valor expr como argumento nombre a las funciones de Nix.
•
--arg-from-file nombre ruta
Pasa el contenido del archivo ruta como argumento nombre a las funciones de Nix.
•
--arg-from-stdin nombre
Pasa el contenido de la entrada estándar como argumento nombre a las funciones de Nix.
•
--argstr nombre cadena
Pasa la cadena cadena como argumento nombre a las funciones de Nix.
•
--debugger
Inicia un entorno interactivo si la evaluación falla.
•
--eval-store url-tienda
La URL de la tienda Nix a utilizar para la evaluación, es decir, para almacenar derivaciones (.drv) y las entradas a las que hacen referencia.
•
--impure
Permitir el acceso a rutas y repositorios mutables.
•
--include / -I ruta

Options

General options
--allow-fallback-to-public-substituters / --no-allow-fallback-to-public-substituters
Allow Nix to fall back to public substituters when private substituters fail.
--allow-hotplug / --no-allow-hotplug
Allow Nix to install and use drivers that are not part of the current system.
--allow-unsafe-native-code / --no-allow-unsafe-native-code
Allow running "native" binaries that might not be reproducible or could contain security vulnerabilities.
--build-parallel-limit limit
Maximum number of running build processes.
--builders builders
List of builders to use for remote builds.
--cache-exclude host
Exclude the specified host from caching builds.
--check-cache-signature / --no-check-cache-signature
Check the signature of remote cache entries.
--compress-lock-file / --no-compress-lock-file
Compress the lock file.
--compressor compressor
Compression algorithm to use for store paths. Defaults to `zstd`.
--config config-file
Path to Nix configuration file.
--cores cores
Number of CPU cores to use for building. Defaults to the number of available cores.
--flake-check-dry-run
Only check flake outputs, don't build or download anything.
--flake-registry flake-registry-path
Path to the flake registry file.
--impure / --pure
Allow/disallow impure derivations.
--insecure-experimental-features features
Enable experimental features (use with caution).
--json
Print results in JSON format.
--keep-failed
Do not garbage collect failed builds.
--keep-going / -k
Continue evaluating/building other dependencies even if one fails.
--log-filter filter
Filter log output based on the provided filter expression.
--max-silent seconds
Maximum time to remain silent before printing an ellipsis.
--no-build-output
Do not print the output of build steps.
--no-executables / --no-no-executables
Do not build or use executables.
--no-new-date
Do not update the timestamps of built files.
--no-substituters / --no-no-substituters
Disable substituters.
--no-tls-verify / --no-no-tls-verify
Disable TLS verification for substituters and sources.
-I path
Add path to search path entries used to resolve lookup paths
This option may be given multiple times.
Paths added through -I take precedence over the nix-path configuration setting and the NIX_PATH environment variable.
--override-flake original-ref resolved-ref
Override the flake registries, redirecting original-ref to resolved-ref.

Common flake-related options

--commit-lock-file
Commit changes to the flake’s lock file.
--inputs-from flake-url
Use the inputs of the specified flake as registry entries.
--no-registries
Don’t allow lookups in the flake registries.
DEPRECATED
Use --no-use-registries instead.
--no-update-lock-file
Do not allow any updates to the flake’s lock file.
--no-write-lock-file
Do not write the flake’s newly generated lock file.
--output-lock-file flake-lock-path
Write the given lock file instead of flake.lock within the top-level flake.
--override-input input-path flake-url
Override a specific flake input (e.g. dwarffs/nixpkgs). This implies --no-write-lock-file.
--recreate-lock-file
Recreate the flake’s lock file from scratch.
DEPRECATED
Use nix flake update instead.
--reference-lock-file flake-lock-path
Read the given lock file instead of flake.lock within the top-level flake.
--update-input input-path
Update a specific flake input (ignoring its previous entry in the lock file).
DEPRECATED
Use nix flake update instead.

Logging-related options

--debug
Set the logging verbosity level to ‘debug’.
--log-format format
Set the format of log output; one of raw, internal-json, bar or bar-with-logs.
--print-build-logs / -L
Print full build logs on standard error.
--quiet
Decrease the logging verbosity level.
--verbose / -v
Increase the logging verbosity level.

Miscellaneous global options

--help
Show usage information.
--offline
Disable substituters and consider all previously downloaded files up-to-date.
--option name value
Set the Nix configuration setting name to value (overriding nix.conf).
--refresh
Consider all previously downloaded files out-of-date.
--repair
During evaluation, rewrite missing or corrupted files in the Nix store. During building, rebuild missing or corrupted store paths.
--version
Show version information.

Options that change the interpretation of installables

--expr expr
Interpret installables as attribute paths relative to the Nix expression expr.
--file / -f file
Interpret installables as attribute paths relative to the Nix expression stored in file. If file is the character -, then a Nix expression will be read from standard input. Implies --impure.

Note

See man nix.conf for overriding configuration settings with command line flags.
