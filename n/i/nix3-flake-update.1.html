nix3-flake-update(1)

Paquete: nix

Licencias: LGPL-2.1-only

nix3-flake-update(1) Manual de Comandos Generales nix3-flake-update(1)

Advertencia
Este programa es experimental y su interfaz está sujeta a cambios.

Nombre

nix flake update - actualiza el archivo de bloqueo de flakes

Sinopsis

nix flake update [opción…] entradas…

Ejemplos

•
Actualizar todas las entradas (es decir, recrear el archivo de bloqueo desde cero):
# nix flake update
warning: actualizando el archivo de bloqueo '/home/yo/repos/testflake/flake.lock':
• Entrada 'nix' actualizada:
  'github:NixOS/nix/9fab14adbc3810d5cc1f88672fde1eee4358405c' (2023-06-28)
→ 'github:NixOS/nix/8927cba62f5afb33b01016d5c4f7f8b7d0adde3c' (2023-07-11)
• Entrada 'nixpkgs' actualizada:
  'github:NixOS/nixpkgs/3d2d8f281a27d466fa54b469b5993f7dde198375' (2023-06-30)
→ 'github:NixOS/nixpkgs/a3a3dda3bacf61e8a39258a0ed9c924eeca8e293' (2023-07-05)
•
Actualizar solo una entrada individual:
# nix flake update nixpkgs
warning: actualizando el archivo de bloqueo '/home/yo/repos/testflake/flake.lock':
• Entrada 'nixpkgs' actualizada:
  'github:NixOS/nixpkgs/3d2d8f281a27d466fa54b469b5993f7dde198375' (2023-06-30)
→ 'github:NixOS/nixpkgs/a3a3dda3bacf61e8a39258a0ed9c924eeca8e293' (2023-07-05)
•
Actualizar solo una entrada de un flake en un directorio diferente:
# nix flake update nixpkgs --flake ~/repos/another
warning: actualizando el archivo de bloqueo '/home/yo/repos/another/flake.lock':
• Entrada 'nixpkgs' actualizada:
  'github:NixOS/nixpkgs/3d2d8f281a27d466fa54b469b5993f7dde198375' (2023-06-30)
→ 'github:NixOS/nixpkgs/a3a3dda3bacf61e8a39258a0ed9c924eeca8e293' (2023-07-05)
Nota
Al intentar referenciar un flake en un subdirectorio, escribe ./another en lugar de another. De lo contrario, Nix intentará buscar el flake en el registro.

Descripción

Este comando actualiza las entradas en un archivo de bloqueo (flake.lock). Por defecto, se actualizan todas las entradas. Si el archivo de bloqueo aún no existe, se creará. Si las entradas aún no están en el archivo de bloqueo, se añadirán.

A diferencia de otros comandos nix flake, nix flake update toma una lista de nombres de entradas a actualizar como argumentos posicionales y opera en el flake del directorio actual. Puedes pasar una URL de flake diferente con --flake para anular ese valor predeterminado.

El comando relacionado nix flake lock también crea archivos de bloqueo y añade entradas faltantes, pero es más seguro ya que nunca actualizará las entradas ya existentes en el archivo de bloqueo.

Opciones

•
--flake url-del-flake
El flake sobre el que operar. Por defecto es el directorio actual.

Opciones comunes de evaluación

•
--arg nombre expresión
Pasa el valor expresión como argumento nombre a las funciones de Nix.
•
--arg-from-file nombre ruta
Pasa el contenido del archivo ruta como argumento nombre a las funciones de Nix.
•
--arg-from-stdin nombre
Pasa el contenido de stdin como argumento nombre a las funciones de Nix.
•
--argstr nombre cadena
Pasa la cadena cadena como argumento nombre a las funciones de Nix.
•
--debugger
Inicia un entorno interactivo si la evaluación falla.
•
--eval-store url-tienda
La URL de la tienda Nix a utilizar para la evaluación, es decir, para almacenar derivaciones (.drv) y las entradas referenciadas por ellas.
•
--impure
Permite el acceso a rutas y repositorios mutables.
•
--include / -I ruta
Añade ruta a las entradas de la ruta de búsqueda utilizadas para resolver rutas de búsqueda
Esta opción se puede dar varias veces.
Las rutas añadidas a través de -I tienen precedencia sobre la configuración nix-path y la variable de entorno NIX_PATH.
•
--override-flake ref-original ref-resuelto
Anula los registros de flakes, redirigiendo ref-original a ref-resuelto.

Opciones comunes relacionadas con flakes

•
--commit-lock-file
Confirma los cambios en el archivo de bloqueo del flake.
•
--inputs-from url-del-flake
Utiliza las entradas del flake especificado como entradas del registro.
•
--no-registries
No permite búsquedas en los registros de flakes.
OBSOLETO
Usa --no-use-registries en su lugar.
•
--output-lock-file ruta-archivo-bloqueo
Escribe el archivo de bloqueo dado en lugar de flake.lock dentro del flake de nivel superior.
•
--override-input ruta-entrada url-del-flake
Anula una entrada de flake específica (p. ej., dwarffs/nixpkgs). Esto implica --no-write-lock-file.
•
--recreate-lock-file
Recrea el archivo de bloqueo del flake desde cero.
OBSOLETO
Usa nix flake update en su lugar.

Nix flake options

•
--extra-dep path
Add an extra flake input that is not referenced in the flake. This is useful for adding inputs that are only used by commands like nix build.
•
--flake path
Use the flake specified by path.
•
--impure
Run the evaluation in impure mode. This means that inputs not explicitly mentioned in the flake are allowed, as well as access to the Nix language's builtins.
•
--override-flake path-to-flake-input replacement-flake-path
Overrides a flake input to point to a different flake.
•
--reference-lock-file flake-lock-path
Read the given lock file instead of flake.lock within the top-level flake.
•
--update-input input-path
Update a specific flake input (ignoring its previous entry in the lock file).
DEPRECATED
Use nix flake update instead.

Opciones relacionadas con el registro

•
--debug
Establece el nivel de verbosidad del registro a 'debug'.
•
--log-format format
Establece el formato de la salida del registro; uno de raw, internal-json, bar o bar-with-logs.
•
--print-build-logs / -L
Imprime los registros de compilación completos en la salida de error estándar.
•
--quiet
Disminuye el nivel de verbosidad del registro.
•
--verbose / -v
Aumenta el nivel de verbosidad del registro.

Opciones globales varias

•
--help
Muestra información de uso.
•
--offline
Deshabilita los sustitutos y considera que todos los archivos descargados previamente están actualizados.
•
--option name value
Establece la configuración de Nix name a value (anulando nix.conf).
•
--refresh
Considera que todos los archivos descargados previamente están obsoletos.
•
--repair
Durante la evaluación, reescribe archivos faltantes o corruptos en el almacén de Nix. Durante la compilación, recompila rutas de almacén faltantes o corruptas.
•
--version
Muestra información de la versión.

Nota

Ver man nix.conf para anular la configuración con opciones de línea de comandos.
