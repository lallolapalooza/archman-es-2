nix3-develop(1)

nix3-develop(1) Manual de Comandos Generales nix3-develop(1)

Advertencia
Este programa es experimental y su interfaz está sujeta a cambios.

Nombre

nix develop - ejecuta un shell bash que proporciona el entorno de compilación de una derivación

Sinopsis

nix develop [opción…] instalable

Ejemplos

•
Inicia un shell con el entorno de compilación del paquete predeterminado de la flake en el directorio actual:
# nix develop
Los comandos típicos para ejecutar dentro de este shell son:
# configurePhase
# buildPhase
# installPhase
Alternativamente, puedes ejecutar directamente las herramientas de compilación que utiliza tu proyecto, por ejemplo, para un proyecto Unix típico:
# ./configure --prefix=$out
# make
# make install
•
Ejecuta una fase de compilación particular directamente:
# nix develop --unpack
# nix develop --configure
# nix develop --build
# nix develop --check
# nix develop --install
# nix develop --installcheck
•
Inicia un shell con el entorno de compilación de GNU Hello:
# nix develop nixpkgs#hello
•
Registra un entorno de compilación en un perfil:
# nix develop --profile /tmp/my-build-env nixpkgs#hello
•
Utiliza un entorno de compilación previamente registrado en un perfil:
# nix develop /tmp/my-build-env
•
Reemplaza todas las ocurrencias de la ruta de almacenamiento correspondiente a glibc.dev con un directorio escribible:
# nix develop --redirect nixpkgs#glibc.dev ~/my-glibc/outputs/dev
Ten en cuenta que esto es útil si estás ejecutando un shell nix develop para nixpkgs#glibc en ~/my-glibc y quieres compilar otro paquete contra él.
•
Ejecuta una serie de comandos de script:
# nix develop --command bash -c "mkdir build && cmake .. && make"

Descripción

nix develop inicia un shell bash que proporciona un entorno de compilación interactivo casi idéntico al que Nix usaría para compilar el instalable. Dentro de este shell, las variables de entorno y las funciones de shell están configuradas para que puedas compilar tu paquete de forma interactiva e incremental.

Nix determina el entorno de compilación construyendo una versión modificada de la derivación instalable que solo registra el entorno inicializado por stdenv y sale. Este entorno de compilación puede ser registrado en un perfil usando --profile.

El prompt utilizado por el shell bash se puede personalizar estableciendo las opciones bash-prompt, bash-prompt-prefix y bash-prompt-suffix en nix.conf o en el atributo nixConfig de la flake.

Atributos de salida de Flake

Si no se proporciona un atributo de salida de flake, nix develop intenta los siguientes atributos de salida de flake:

  • devShells.<system>.default
  • packages.<system>.default

Si se proporciona un *nombre* de salida de flake, nix develop intenta los siguientes atributos de salida de flake:

  • devShells.<system>.<name>
  • packages.<system>.<name>
  • legacyPackages.<system>.<name>

Opciones

•
--build
Ejecuta la fase build.
•
--check
Ejecuta la fase check.
•
--command / -c comando argumentos
En lugar de iniciar un shell interactivo, inicia el comando y los argumentos especificados.
•
--configure
Ejecuta la fase configure.
•
--ignore-environment / -i
Limpia todo el entorno (excepto aquellos especificados con --keep).
•
--install
Ejecuta la fase install.
•
--installcheck
Ejecuta la fase installcheck.
•
--keep / -k nombre
Conserva la variable de entorno nombre.
•
--phase nombre-fase
La fase de stdenv a ejecutar (por ejemplo, build o configure).
•
--profile ruta
El perfil sobre el que operar.
•
--redirect instalable dir-salidas
Redirige una ruta de almacenamiento a una ubicación mutable.
•
--unpack
Ejecuta la fase unpack.
•
--unset / -u nombre
Elimina la variable de entorno nombre.

Opciones comunes de evaluación

•
--arg nombre expresión
Pasa el valor expresión como argumento nombre a las funciones de Nix.
•
--arg-from-file nombre ruta
Pasa el contenido del archivo ruta como argumento nombre a las funciones de Nix.
•
--arg-from-stdin nombre
Pasa el contenido de stdin como argumento nombre a las funciones de Nix.
•
--argstr nombre cadena
Pasa la cadena cadena como argumento nombre a las funciones de Nix.
•
