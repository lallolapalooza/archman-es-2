nix3-profile-remove(1) Manual de Comandos Generales nix3-profile-remove(1)

Advertencia
Este programa es experimental y su interfaz está sujeta a cambios.

Nombre

nix profile remove - eliminar paquetes de un perfil

Sintaxis

nix profile remove [opción…] elementos…

Ejemplos

•
Eliminar un paquete por nombre:
# nix profile remove hello
•
Eliminar todos los paquetes:
# nix profile remove --all
•
Eliminar paquetes por expresión regular:
# nix profile remove --regex '.*vim.*'
•
Eliminar un paquete por ruta del store:
# nix profile remove /nix/store/rr3y0c6zyk7kjjl8y19s4lsrhn4aiq1z-hello-2.10

Descripción

Este comando elimina un paquete de un perfil.

Opciones

•
--all
Coincidir con todos los paquetes en el perfil.
•
--profile ruta
El perfil sobre el que operar.
•
--regex patrón
Una expresión regular para coincidir con uno o más paquetes en el perfil.

Opciones comunes de evaluación

•
--arg nombre expresión
Pasa el valor expresión como el argumento nombre a las funciones de Nix.
•
--arg-from-file nombre ruta
Pasa el contenido del archivo ruta como el argumento nombre a las funciones de Nix.
•
--arg-from-stdin nombre
Pasa el contenido de la entrada estándar como el argumento nombre a las funciones de Nix.
•
--argstr nombre cadena
Pasa la cadena cadena como el argumento nombre a las funciones de Nix.
•
--debugger
Inicia un entorno interactivo si la evaluación falla.
•
--eval-store url-del-store
La URL del store de Nix a utilizar para la evaluación, es decir, para almacenar derivaciones (archivos .drv) y las entradas referenciadas por ellas.
•
--impure
Permitir el acceso a rutas y repositorios mutables.
•
--include / -I ruta
Añade ruta a las entradas de la ruta de búsqueda utilizadas para resolver rutas de búsqueda
Esta opción se puede dar varias veces.
Las rutas añadidas a través de -I tienen prioridad sobre la configuración nix-path y la variable de entorno NIX_PATH.
•
--override-flake ref-original ref-resuelto
Anula los registros de flakes, redirigiendo ref-original a ref-resuelto.

Opciones relacionadas con el registro de eventos

•
--debug
Establece el nivel de verbosidad del registro a 'debug'.
•
--log-format formato
Establece el formato de salida del registro; uno de raw, internal-json, bar o bar-with-logs.
•
--print-build-logs / -L
Imprime los registros de compilación completos en la salida de error estándar.
•
--quiet
Disminuye el nivel de verbosidad del registro.
•
--verbose / -v
Aumenta el nivel de verbosidad del registro.

Opciones globales varias

•
--help
Muestra información de uso.
•
--offline
Desactiva los sustitutos y considera todos los archivos previamente descargados como actualizados.
•
--option nombre valor
Establece la opción de configuración de Nix nombre a valor (anulando nix.conf).
•
--refresh
Considera todos los archivos previamente descargados como obsoletos.
•
--repair
Durante la evaluación, reescribe archivos faltantes o corruptos en el Nix store. Durante la compilación, recompila rutas de store faltantes o corruptas.
•
--version
Muestra información de versión.

Nota

Consulta man nix.conf para anular la configuración con indicadores de línea de comandos.
