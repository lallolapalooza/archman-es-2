Paquete: nix

Licencias: LGPL-2.1-only

nix3-repl(1) Manual de Comandos Generales nix3-repl(1)

Advertencia
Este programa es experimental y su interfaz está sujeta a cambios.

Nombre

nix repl - iniciar un entorno interactivo para evaluar expresiones Nix

Sinopsis

nix repl [opción…] instalables…

Ejemplos

•
Mostrar todos los comandos especiales dentro del REPL:
# nix repl
nix-repl> :?
•
Evaluar algunas expresiones Nix simples:
# nix repl
nix-repl> 1 + 2
3
nix-repl> map (x: x * 2) [1 2 3]
[ 2 4 6 ]
•
Interactuar con Nixpkgs en el REPL:
# nix repl --file example.nix
Cargando instalable ''...
Se añadieron 3 variables.
# nix repl --expr '{a={b=3;c=4;};}'
Cargando instalable ''...
Se añadió 1 variable.
# nix repl --expr '{a={b=3;c=4;};}' a
Cargando instalable ''...
Se añadió 1 variable.
# nix repl --extra-experimental-features 'flakes' nixpkgs
Cargando instalable 'flake:nixpkgs#'...
Se añadieron 5 variables.
nix-repl> legacyPackages.x86_64-linux.emacs.name
"emacs-27.1"
nix-repl> :q
# nix repl --expr 'import <nixpkgs>{}'
Cargando instalable ''...
Se añadieron 12439 variables.
nix-repl> emacs.name
"emacs-27.1"
nix-repl> emacs.drvPath
"/nix/store/lp0sjrhgg03y2n0l10n70rg0k7hhyz0l-emacs-27.1.drv"
nix-repl> drv = runCommand "hello" { buildInputs = [ hello ]; } "hello; hello > $out"
nix-repl> :b drv
esta derivación produjo las siguientes salidas:
out -> /nix/store/0njwbgwmkwls0w5dv9mpc1pq5fj39q0l-hello
nix-repl> builtins.readFile drv
"Hello, world!\n"
nix-repl> :log drv
Hello, world!

Descripción

Este comando proporciona un entorno interactivo para evaluar expresiones Nix. (REPL son las siglas de ‘read–eval–print loop’ o bucle leer-evaluar-imprimir.)

Al inicio, carga las expresiones Nix llamadas archivos y las añade al ámbito léxico. Puedes cargar archivos adicionales usando el comando :l <nombre_archivo>, o recargar todos los archivos usando :r.

Opciones

•
--stdin
Lee instalables de la entrada estándar. No se aplica ningún instalable por defecto.

Opciones comunes de evaluación

•
--arg nombre expr
Pasa el valor expr como argumento nombre a las funciones Nix.
•
--arg-from-file nombre ruta
Pasa el contenido del archivo ruta como argumento nombre a las funciones Nix.
•
--arg-from-stdin nombre
Pasa el contenido de stdin como argumento nombre a las funciones Nix.
•
--argstr nombre cadena
Pasa la cadena cadena como argumento nombre a las funciones Nix.
•
--debugger
Inicia un entorno interactivo si la evaluación falla.
•
--eval-store url-tienda
La URL de la tienda Nix a usar para la evaluación, es decir, para almacenar derivaciones (.drv) y las entradas referenciadas por ellas.
•
--impure
Permite el acceso a rutas y repositorios mutables.
•
--include / -I ruta
Añade ruta a las entradas de la ruta de búsqueda utilizadas para resolver rutas de búsqueda.
Esta opción se puede dar varias veces.
Las rutas añadidas a través de -I tienen precedencia sobre la configuración de nix-path y la variable de entorno NIX_PATH.
•
--override-flake ref-original ref-resuelto
Sobrescribe los registros de flaky, redirigiendo ref-original a ref-resuelto.

Opciones comunes relacionadas con flakes

•
--commit-lock-file
Confirma los cambios en el archivo de bloqueo del flake.
•
--inputs-from url-flake
Usa las entradas del flake especificado como entradas de registro.
•
--no-registries
No permite búsquedas en los registros de flakes.
OBSOLETO
Usa --no-use-registries en su lugar.
•
--no-update-lock-file
No permite ninguna actualización del archivo de bloqueo del flake.
•
--no-write-lock-file
No escribe el archivo de bloqueo recién generado del flake.
•
--output-lock-file ruta-archivo-bloqueo-flake
Escribe el archivo de bloqueo dado en lugar de flake.lock dentro del flake de nivel superior.
•
--override-input ruta-entrada url-flake
Sobrescribe una entrada específica del flake (por ejemplo, dwarffs/nixpkgs). Esto implica --no-write-lock-file.
•
--recreate-lock-file
Recrea el archivo de bloqueo del flake desde cero.
OBSOLETO
Usa nix flake update en su lugar.
•
--reference-lock-file ruta-archivo-bloqueo-flake
Lee el archivo de bloqueo dado en su lugar.

Name

nix3-flake-update - update inputs in a flake

Synopsis


nix3-flake-update [--help | -h] [--version] [--option name value] [--file | -f file] [--expr expr] [--impure] [--system system] [--extra-dep extra-dep] [--debug] [--log-format format] [--quiet | -q] [--verbose | -v] [--print-build-logs | -L] [--offline] [--refresh] [--repair] [--update-input input-path] {installable ...}

Examples

Update the flake.lock file for the current flake:

$ nix3-flake update

Update a specific flake input:

$ nix3-flake update --update-input url2raw

Description

This command updates flake inputs. If no arguments are given, it updates all inputs specified in the flake.lock file.

Options

•
--help
Show usage information.
•
--version
Show version information.
•
--option name value
Set the Nix configuration setting name to value (overriding nix.conf).
•
--file / -f file
Interpret installables as attribute paths relative to the Nix expression stored in file. If file is the character -, then a Nix expression will be read from standard input. Implies --impure.
•
--expr expr
Interpret installables as attribute paths relative to the Nix expression expr.
•
--impure
Don't allow access to the Nix search path and guarantee that the result is not dependent on the user's Nix profile.
•
--system system
The system for which to build the flake. Defaults to $(uname -m)-$(uname -s).
•
--extra-dep extra-dep
Add an extra flake input reference, which should be a flake URL. This is useful for referencing flakes that are not direct dependencies of the flake being evaluated. For example, --extra-dep=nixpkgs=github:NixOS/nixpkgs/nixpkgs-unstable.
•
--update-input input-path
Update a specific flake input (ignoring its previous entry in the lock file).
DEPRECATED
Use nix flake update instead.

Logging-related options

•
--debug
Set the logging verbosity level to ‘debug’.
•
--log-format format
Set the format of log output; one of raw, internal-json, bar or bar-with-logs.
•
--print-build-logs / -L
Print full build logs on standard error.
•
--quiet
Decrease the logging verbosity level.
•
--verbose / -v
Increase the logging verbosity level.

Miscellaneous global options

•
--help
Show usage information.
•
--offline
Disable substituters and consider all previously downloaded files up-to-date.
•
--option name value
Set the Nix configuration setting name to value (overriding nix.conf).
•
--refresh
Consider all previously downloaded files out-of-date.
•
--repair
During evaluation, rewrite missing or corrupted files in the Nix store. During building, rebuild missing or corrupted store paths.
•
--version
Show version information.

Options that change the interpretation of installables

•
--expr expr
Interpret installables as attribute paths relative to the Nix expression expr.
•
--file / -f file
Interpret installables as attribute paths relative to the Nix expression stored in file. If file is the character -, then a Nix expression will be read from standard input. Implies --impure.

Note

See man nix.conf for overriding configuration settings with command line flags.
