NICOTINE+(1) Manual de Comandos Generales NICOTINE+(1)

NOMBRE

nicotine - cliente gráfico para la red peer-to-peer Soulseek

SINOPSIS

nicotine [opciones]

DESCRIPCIÓN

Nicotine+ es una aplicación gráfica que permite a los usuarios interactuar con la red peer-to-peer Soulseek.

OPCIONES

-c <archivo>, --config=<archivo>
Utiliza <archivo> como archivo de configuración. Si <archivo> no existe, se creará un nuevo archivo de configuración vacío.
-u <directorio>, --user-data=<directorio>
Utiliza <directorio> como directorio para datos de usuario y plugins. Si <directorio> no existe, se creará un nuevo directorio vacío.
-h, --help
Muestra la ayuda del comando y sale.
-s, --hidden
Inicia el programa sin mostrar la ventana.
-b <ip>, --bindip=<ip>
Vincula los sockets a la <ip> dada (útil para VPN).
-l <puerto>, --port=<puerto>
Escucha en el puerto dado. Anula la configuración del rango de puertos.
-r, --rescan
Escanea de nuevo los archivos compartidos.
-n, --headless
Inicia el programa en modo sin cabeza (sin GUI).
-v, --version
Muestra el número de versión y sale.

ESTADO DE SALIDA

El estado de salida regular del programa es 0.
Si las dependencias requeridas no están presentes, el estado de salida es 1.
Si la lista de argumentos dada no se puede analizar, el estado de salida es 2.

ARCHIVOS

~/.config/nicotine/config
El archivo de configuración.
~/.local/share/nicotine/
Otros archivos personales como descargas, compartidos y registros.

ENTORNO

Las siguientes variables de entorno están disponibles al ejecutar el programa.

NICOTINE_GTK_VERSION
La versión principal de GTK a usar, si está instalada. Los valores posibles son 4 o 3.
NICOTINE_LIBADWAITA
Si habilitar libadwaita (tema de GNOME), si está instalada. Los valores posibles son 1 o 0.

AUTOR

Equipo de Nicotine+ https://nicotine-plus.org/
