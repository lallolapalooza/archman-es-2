Descripción

Este comando muestra información sobre el flake especificado por la referencia de flake url-flake. Resuelve la referencia de flake usando el registro de flakes, lo descarga e imprime algunos metadatos. Esto incluye:

  • URL Resuelto: Si url-flake es un identificador de flake, entonces esta es la referencia de flake que especifica su ubicación real, buscada en el registro de flakes.
  • URL Bloqueado: Una referencia de flake que contiene un hash de commit o de contenido y, por lo tanto, identifica de forma única una versión específica de flake.
  • Descripción: Una descripción de una línea del flake, tomada del campo description en flake.nix.
  • Ruta: La ruta de la tienda que contiene el código fuente del flake.
  • Revisión: El hash del commit de Git o Mercurial del flake bloqueado.
  • Revisiones: El número de ancestros del commit de Git o Mercurial del flake bloqueado. Tenga en cuenta que esto no está disponible para flakes de github.
  • Última modificación: Para flakes de Git o Mercurial, esta es la hora del commit del commit del flake bloqueado; para flakes de archivo tar, es la marca de tiempo más reciente de cualquier archivo dentro del tarball.
  • Entradas: Las entradas del flake con sus entradas correspondientes en el archivo de bloqueo.

Con --json, la salida es un objeto JSON con los siguientes campos:

  • original y originalUrl: La referencia de flake especificada por el usuario (url-flake) en un conjunto de atributos y en formato de URL.
  • resolved y resolvedUrl: La referencia de flake resuelta (ver arriba) en un conjunto de atributos y en formato de URL.
  • locked y lockedUrl: La referencia de flake bloqueada (ver arriba) en un conjunto de atributos y en formato de URL.
  • description: Ver Descripción arriba.
  • path: Ver Ruta arriba.
  • revision: Ver Revisión arriba.
  • revCount: Ver Revisiones arriba.
  • lastModified: Ver Última modificación arriba.
  • locks: El contenido de flake.lock.

Opciones

•
--json
Produce la salida en formato JSON, adecuada para ser consumida por otro programa.

--arg nombre expresión

Synopsis

Examples

Get metadata about the nixpkgs flake:

$ nix flake metadata nixpkgs

Get metadata about a specific revision of the nixpkgs flake:

$ nix flake metadata nixpkgs#22.11

Get metadata about a flake located locally in a subdirectory:

$ nix flake metadata ./my-flake

Get metadata about a flake located locally in a subdirectory with a custom flake-lock file:

$ nix flake metadata --reference-lock-file ./my-flake-lock.json ./my-flake

Description

This command outputs metadata about a flake. This command is primarily useful for debugging and introspection, and is not intended to be used directly by end-users. It is used internally by nix build, nix run, etc.

The command evaluates the flake given by flake-url and prints information about its inputs, outputs, and attributes.

The flake-url can be any valid flake reference, including a local path (e.g. ./my-flake), a git repository (e.g. github:NixOS/nixpkgs), or an Nix registry reference (e.g. nixpkgs).

Options

Common flake-related options

•
--commit-lock-file
Commit changes to the flake’s lock file.
•
--inputs-from flake-url
Use the inputs of the specified flake as registry entries.
•
--no-registries
Don’t allow lookups in the flake registries.
DEPRECATED
Use --no-use-registries instead.
•
--no-update-lock-file
Do not allow any updates to the flake’s lock file.
•
--no-write-lock-file
Do not write the flake’s newly generated lock file.
•
--output-lock-file flake-lock-path
Write the given lock file instead of flake.lock within the top-level flake.
•
--override-input input-path flake-url
Override a specific flake input (e.g. dwarffs/nixpkgs). This implies --no-write-lock-file.
•
--recreate-lock-file
Recreate the flake’s lock file from scratch.
DEPRECATED
Use nix flake update instead.
•
--reference-lock-file flake-lock-path
Read the given lock file instead of flake.lock within the top-level flake.
•
--update-input input-path
Update a specific flake input (ignoring its previous entry in the lock file).
DEPRECATED
Use nix flake update instead.
