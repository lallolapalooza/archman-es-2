nix3-flake-new(1) Manual de Comandos Generales nix3-flake-new(1)

Advertencia
Este programa es experimental y su interfaz está sujeta a cambios.

Nombre

nix flake new - crear una flake en el directorio especificado a partir de una plantilla

Sinopsis

nix flake new [opción…] dir-destino

Ejemplos

•
Crear una flake usando la plantilla predeterminada en el directorio hola:
# nix flake new hola
•
Listar plantillas disponibles:
# nix flake show templates
•
Crear una flake a partir de una plantilla específica en el directorio hola:
# nix flake new hola -t templates#trivial

Descripción

Este comando crea una flake en el directorio dir-destino, que no debe existir previamente. Es equivalente a:

# mkdir dir-destino
# cd dir-destino
# nix flake init

Opciones

•
--template / -t plantilla
La plantilla a usar.

Opciones comunes de evaluación

•
--arg nombre exp
Pasa el valor exp como el argumento nombre a las funciones Nix.
•
--arg-from-file nombre ruta
Pasa el contenido del archivo ruta como el argumento nombre a las funciones Nix.
•
--arg-from-stdin nombre
Pasa el contenido de la entrada estándar como el argumento nombre a las funciones Nix.
•
--argstr nombre cadena
Pasa la cadena cadena como el argumento nombre a las funciones Nix.
•
--debugger
Inicia un entorno interactivo si la evaluación falla.
•
--eval-store url-store
La URL del almacén Nix a utilizar para la evaluación, es decir, para almacenar derivaciones (.drv) y las entradas referenciadas por ellas.
•
--impure
Permite el acceso a rutas y repositorios mutables.
•
--include / -I ruta
Añade ruta a las entradas de la ruta de búsqueda utilizada para resolver rutas de búsqueda
Esta opción puede darse varias veces.
Las rutas añadidas a través de -I tienen prioridad sobre la configuración nix-path y la variable de entorno NIX_PATH.
•
--override-flake ref-original ref-resuelto
Anula los registros de flakes, redirigiendo ref-original a ref-resuelto.

Opciones relacionadas con el registro

•
--debug
Establece el nivel de verbosidad del registro a 'debug'.
•
--log-format formato
Establece el formato de la salida del registro; uno de raw, internal-json, bar o bar-with-logs.
•
--print-build-logs / -L
Imprime los registros de construcción completos en la salida de error estándar.
•
--quiet
Disminuye el nivel de verbosidad del registro.
•
--verbose / -v
Aumenta el nivel de verbosidad del registro.

Opciones globales varias

•
--help
Muestra información de uso.
•
--offline
Desactiva los sustitutos y considera todos los archivos descargados previamente como actualizados.
•
--option nombre valor
Establece la configuración de Nix nombre a valor (anulando nix.conf).
•
--refresh
Considera todos los archivos descargados previamente como no actualizados.
•
--repair
Durante la evaluación, reescribe archivos faltantes o corruptos en el almacén Nix. Durante la construcción, reconstruye rutas de almacén faltantes o corruptas.
•
--version
Muestra información de la versión.

Nota

Consulta man nix.conf para anular la configuración con indicadores de línea de comandos.
