Paquete: nix

nix3-profile-upgrade(1) Manual de Comandos Generales nix3-profile-upgrade(1)

Advertencia
Este programa es experimental y su interfaz está sujeta a cambios.

Nombre

nix profile upgrade - actualizar paquetes utilizando su flake más reciente

Sinopsis

nix profile upgrade [opción…] elementos…

Ejemplos

•
Actualizar todos los paquetes que fueron instalados usando una referencia de flake desbloqueada:
# nix profile upgrade --all
•
Actualizar un paquete específico por su nombre:
# nix profile upgrade hello
•
Actualizar todos los paquetes que incluyen 'vim' en su nombre:
# nix profile upgrade --regex '.*vim.*'

Descripción

Este comando actualiza un paquete previamente instalado en un perfil de Nix, obteniendo y evaluando la última versión del flake desde el cual se instaló el paquete.

Advertencia

Esto solo funciona si utilizaste una referencia de flake *desbloqueada* en el momento de la instalación, p.ej., nixpkgs#hello. No funciona si utilizaste una referencia de flake *bloqueada* (p.ej., github:NixOS/nixpkgs/13d0c311e3ae923a00f734b43fd1d35b47d8943a#hello), ya que en ese caso la "última versión" es siempre la misma.

Opciones

•
--all
Coincidir con todos los paquetes en el perfil.
•
--profile ruta
El perfil sobre el cual operar.
•
--regex patrón
Una expresión regular para coincidir con uno o más paquetes en el perfil.

Opciones comunes de evaluación

•
--arg nombre exp
Pasa el valor exp como el argumento nombre a las funciones de Nix.
•
--arg-from-file nombre ruta
Pasa el contenido del archivo ruta como el argumento nombre a las funciones de Nix.
•
--arg-from-stdin nombre
Pasa el contenido de stdin como el argumento nombre a las funciones de Nix.
•
--argstr nombre cadena
Pasa la cadena cadena como el argumento nombre a las funciones de Nix.
•
--debugger
Inicia un entorno interactivo si la evaluación falla.
•
--eval-store url-tienda
La URL de la tienda Nix a utilizar para la evaluación, es decir, para almacenar derivaciones (.drv) y las entradas referenciadas por ellas.
•
--impure
Permitir acceso a rutas y repositorios mutables.
•
--include / -I ruta
Añade ruta a las entradas de ruta de búsqueda utilizadas para resolver rutas de búsqueda
Esta opción se puede dar varias veces.
Las rutas añadidas a través de -I tienen prioridad sobre la configuración nix-path y la variable de entorno NIX_PATH.
•
--override-flake ref-original ref-resuelto
Sobrescribe los registros de flakes, redirigiendo ref-original a ref-resuelto.

Opciones comunes relacionadas con flakes

•
--commit-lock-file
Confirma los cambios en el archivo de bloqueo del flake.
•
--inputs-from flake-url
Utiliza las entradas del flake especificado como entradas de registro.
•
--no-registries
No permite búsquedas en los registros de flakes.
OBSOLETO
Utiliza --no-use-registries en su lugar.
•
--no-update-lock-file
No permite ninguna actualización del archivo de bloqueo del flake.
•
--no-write-lock-file
No escribe el archivo de bloqueo recién generado del flake.
•
--output-lock-file ruta-flake-lock
Escribe el archivo de bloqueo dado en lugar de flake.lock dentro del flake de nivel superior.
•
--override-input ruta-entrada flake-url
Sobrescribe una entrada de flake específica (p.ej., dwarffs/nixpkgs). Esto implica --no-write-lock-file.
•
--recreate-lock-file
Recrea el archivo de bloqueo del flake desde cero.
OBSOLETO
Utiliza nix flake update en su lugar.
•
--reference-lock-file ruta-flake-lock
Lee el archivo de bloqueo dado en lugar de flake.lock dentro del flake de nivel superior.
•
--update-input ruta-entrada
Actualiza una entrada de flake específica

Opciones relacionadas con el registro

•
--debug
Establece el nivel de verbosidad del registro a 'debug'.
•
--log-format formato
Establece el formato de la salida del registro; uno de raw, internal-json, bar o bar-with-logs.
•
--print-build-logs / -L
Imprime los registros de construcción completos en la salida estándar de error.
•
--quiet
Disminuye el nivel de verbosidad del registro.
•
--verbose / -v
Aumenta el nivel de verbosidad del registro.

Opciones globales varias

•
--help
Muestra información de uso.
•
--offline
Deshabilita los sustitutos y considera todos los archivos descargados previamente como actualizados.
•
--option nombre valor
Establece la configuración de Nix nombre a valor (anulando nix.conf).
•
--refresh
Considera todos los archivos descargados previamente como no actualizados.
•
--repair
Durante la evaluación, reescribe archivos faltantes o corruptos en la tienda de Nix. Durante la construcción, reconstruye rutas de tienda faltantes o corruptas.
•
--version
Muestra información de la versión.

Opciones que cambian la interpretación de instalables

•
--expr expr
Interpreta instalables como rutas de atributos relativas a la expresión Nix expr.
•
--file / -f archivo
Interpreta instalables como rutas de atributos relativas a la expresión Nix almacenada en archivo. Si archivo es el carácter -, entonces se leerá una expresión Nix de la entrada estándar. Implica --impure.

Nota

Consulta man nix.conf para anular la configuración con flags de línea de comandos.
