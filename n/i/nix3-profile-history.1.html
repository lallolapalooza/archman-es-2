nix3-profile-history(1)

Paquete: nix

Licencias: LGPL-2.1-only

nix3-profile-history(1) Manual de Comandos Generales nix3-profile-history(1)

Advertencia
Este programa es experimental y su interfaz está sujeta a cambios.

Nombre

nix profile history - muestra todas las versiones de un perfil

Sintaxis

nix profile history [opción•]

Ejemplos

•
Mostrar los cambios entre cada versión de tu perfil predeterminado:
# nix profile history
Versión 508 (2020-04-10):
flake:nixpkgs#legacyPackages.x86_64-linux.awscli: ∅ -> 1.17.13
Versión 509 (2020-05-16) <- 508:
flake:nixpkgs#legacyPackages.x86_64-linux.awscli: 1.17.13 -> 1.18.211

Descripción

Este comando muestra qué paquetes se añadieron, eliminaron o actualizaron entre versiones subsiguientes de un perfil. Solo muestra paquetes de nivel superior, no dependencias; para eso, usa nix profile diff-closures.

La adición de un paquete a un perfil se denota por la cadena ∅ -> versión, mientras que la eliminación se denota por versión -> ∅.

Opciones

•
--profile ruta
El perfil sobre el que operar.

Opciones comunes de evaluación

•
--arg nombre expresión
Pasa el valor expresión como argumento nombre a las funciones de Nix.
•
--arg-from-file nombre ruta
Pasa el contenido del archivo ruta como argumento nombre a las funciones de Nix.
•
--arg-from-stdin nombre
Pasa el contenido de stdin como argumento nombre a las funciones de Nix.
•
--argstr nombre cadena
Pasa la cadena cadena como argumento nombre a las funciones de Nix.
•
--debugger
Inicia un entorno interactivo si la evaluación falla.
•
--eval-store url-tienda
La URL de la tienda Nix a utilizar para la evaluación, es decir, para almacenar derivaciones (.drv archivos) y las entradas referenciadas por ellas.
•
--impure
Permite el acceso a rutas y repositorios mutables.
•
--include / -I ruta
Añade ruta a las entradas de la ruta de búsqueda utilizadas para resolver rutas de búsqueda.
Esta opción puede darse varias veces.
Las rutas añadidas a través de -I tienen prioridad sobre la configuración de nix-path y la variable de entorno NIX_PATH .
•
--override-flake ref-original ref-resuelto
Sobrescribe los registros de flake, redirigiendo ref-original a ref-resuelto.

Opciones relacionadas con el registro de eventos

•
--debug
Establece el nivel de verbosidad del registro a 'debug'.
•
--log-format formato
Establece el formato de salida del registro; uno de raw, internal-json, bar o bar-with-logs.
•
--print-build-logs / -L
Imprime los registros de compilación completos en la salida de error estándar.
•
--quiet
Disminuye el nivel de verbosidad del registro.
•
--verbose / -v
Aumenta el nivel de verbosidad del registro.

Opciones globales varias

•
--help
Muestra información de uso.
•
--offline
Deshabilita los sustitutos y considera todos los archivos descargados previamente como actualizados.
•
--option nombre valor
Establece la configuración de Nix nombre a valor (anulando nix.conf).
•
--refresh
Considera todos los archivos descargados previamente como no actualizados.
•
--repair
Durante la evaluación, reescribe los archivos faltantes o corruptos en la tienda Nix. Durante la compilación, recompila las rutas de la tienda faltantes o corruptas.
•
--version
Muestra información de la versión.

Nota

Ver man nix.conf para anular la configuración con indicadores de línea de comandos.
