NOMBRE

nih-dbus-tool - Generador de código de enlace D-Bus

SINOPSIS

nih-dbus-tool [OPCIONES]... [-o ARCHIVO] [ARCHIVO.XML]
nih-dbus-tool [OPCIONES]... -o ARCHIVO --system|--session --dest=NOMBRE RUTA-OBJETO

DESCRIPCIÓN

VISIÓN GENERAL

El formato de introspección de D-Bus es un documento XML que describe las interfaces implementadas por un objeto particular, incluyendo los métodos y señales de esa interfaz junto con sus argumentos y las propiedades de esa interfaz.

Un único documento describe un único objeto, representado por la etiqueta raíz <node>. Las interfaces implementadas por ese objeto se especifican mediante etiquetas <interface> dentro de él. Los métodos, señales y propiedades definidos por la interfaz se describen mediante las etiquetas <method>, <signal> y <property> dentro de la interfaz. Los argumentos de los métodos y señales se definen mediante etiquetas <arg> dentro de ellos. Los nombres y otros valores se especifican como atributos de la etiqueta.

Propiedades adicionales para herramientas o software externos pueden darse en etiquetas <annotation>. Estas pueden aparecer dentro de interfaces, métodos, señales, propiedades y argumentos. nih-dbus-tool hace uso de muchas de estas. *Nota: las anotaciones de argumento son una extensión de nih-dbus-tool al formato.*

El analizador de nih-dbus-tool es razonablemente liberal, para permitir la expansión futura del formato de introspección de D-Bus. Cualquier etiqueta, atributo o anotación desconocida, o cualquier etiqueta que no esté en una ubicación esperada, será ignorada con una advertencia. Sin embargo, una etiqueta de nodo raíz faltante, atributos faltantes, valores de atributo ilegales o inválidos, o un formato XML no bien formado resultarán en un error.

Los datos de caracteres y los comentarios no se consideran parte de la descripción y no se analizan.
