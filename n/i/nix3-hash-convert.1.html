Paquete: nix

Licencias: LGPL-2.1-only

nix3-hash-convert(1) Manual de Comandos Generales nix3-hash-convert(1)

Advertencia
Este programa es experimental y su interfaz está sujeta a cambios.

Nombre

nix hash convert - convertir entre formatos de hash

Sinopsis

nix hash convert [opción…] hashes…

Ejemplos

•
Convertir un hash a nix32 (una codificación base-32 con un conjunto de caracteres específico de Nix).
$ nix hash convert --hash-algo sha1 --to nix32 800d59cfcd3c05e900cb4e214be48f6b886a08df
vw46m23bizj4n8afrc0fj19wrp7mj3c0
•
Convertir un hash al formato sri que incluye una especificación de algoritmo:
# nix hash convert --hash-algo sha1 800d59cfcd3c05e900cb4e214be48f6b886a08df
sha1-gA1Zz808BekAy04hS+SPa4hqCN8=
o con un formato --to explícito:
# nix hash convert --hash-algo sha1 --to sri 800d59cfcd3c05e900cb4e214be48f6b886a08df
sha1-gA1Zz808BekAy04hS+SPa4hqCN8=
•
Verificar el formato de entrada del hash:
# nix hash convert --hash-algo sha256 --from nix32 ungWv48Bz+pBQUDeXa4iI7ADYaOWF3qctBD/YfIAFa0=
error: el hash de entrada 'ungWv48Bz+pBQUDeXa4iI7ADYaOWF3qctBD/YfIAFa0=' no tiene el formato esperado '--from nix32'
# nix hash convert --hash-algo sha256 --from nix32 1b8m03r63zqhnjf7l5wnldhh7c134ap5vpj0850ymkq1iyzicy5s
sha256-ungWv48Bz+pBQUDeXa4iI7ADYaOWF3qctBD/YfIAFa0=

Descripción

nix hash convert convierte hashes de una codificación a otra.

Opciones

•
--from formato-hash
Formato de hash (base16, nix32, base64, sri).
•
--hash-algo hash-algo
Algoritmo de hash (md5, sha1, sha256, o sha512). Puede omitirse para hashes SRI.
•
--to formato-hash
Formato de hash (base16, nix32, base64, sri). Predeterminado: sri.

Opciones relacionadas con el registro

•
--debug
Establecer el nivel de verbosidad del registro a 'debug'.
•
--log-format formato
Establecer el formato de la salida del registro; uno de raw, internal-json, bar o bar-with-logs.
•
--print-build-logs / -L
Imprimir registros de compilación completos en la salida de error estándar.
•
--quiet
Disminuir el nivel de verbosidad del registro.
•
--verbose / -v
Aumentar el nivel de verbosidad del registro.

Opciones globales varias

•
--help
Mostrar información de uso.
•
--offline
Desactivar sustitutos y considerar todos los archivos descargados previamente como actualizados.
•
--option nombre valor
Establecer la configuración de Nix nombre a valor (anulando nix.conf).
•
--refresh
Considerar todos los archivos descargados previamente como no actualizados.
•
--version
Mostrar información de la versión.

Nota

Ver man nix.conf para anular la configuración con indicadores de línea de comandos.
