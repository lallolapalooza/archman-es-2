nix3-store-prefetch-file(1)

Paquete: nix

Licencias: LGPL-2.1-only

nix3-store-prefetch-file(1) Manual de Comandos Generales nix3-store-prefetch-file(1)

Advertencia
Este programa es experimental y su interfaz está sujeta a cambios.

Nombre

nix store prefetch-file - descarga un archivo en la tienda Nix

Sinopsis

nix store prefetch-file [opción…] url

Ejemplos

•
Descargar un archivo a la tienda Nix:
# nix store prefetch-file https://releases.nixos.org/nix/nix-2.3.10/nix-2.3.10.tar.xz
Descargado 'https://releases.nixos.org/nix/nix-2.3.10/nix-2.3.10.tar.xz' en
'/nix/store/vbdbi42hgnc4h7pyqzp6h2yf77kw93aw-source' (hash
'sha256-qKheVd5D0BervxMDbt+1hnTKE2aRWC8XCAwc0SeHt6s=').
•
Descargar un archivo y obtener el hash SHA-512:
# nix store prefetch-file --json --hash-type sha512 \
  https://releases.nixos.org/nix/nix-2.3.10/nix-2.3.10.tar.xz \
| jq -r .hash
sha512-6XJxfym0TNH9knxeH4ZOvns6wElFy3uahunl2hJgovACCMEMXSy42s69zWVyGJALXTI+86tpDJGlIcAySEKBbA==

Descripción

Este comando descarga el archivo url a la tienda Nix. Imprime la ruta de la tienda resultante y el hash criptográfico del contenido del archivo.

El componente de nombre de la ruta de la tienda por defecto es el último componente de url, pero esto puede ser anulado usando --name.

Opciones

•
--executable
Hace que el archivo resultante sea ejecutable. Tenga en cuenta que esto hace que el hash resultante sea un hash NAR en lugar de un hash de archivo plano.
•
--expected-hash hash
El hash esperado del archivo.
•
--hash-type tipo-hash
Algoritmo de hash (md5, sha1, sha256 o sha512).
•
--json
Produce salida en formato JSON, adecuada para su consumo por otro programa.
•
--name nombre
Anula el componente de nombre de la ruta de la tienda resultante. Por defecto es el nombre base de url.
•
--unpack
Desempaqueta el archivo (que debe ser un tarball o un archivo zip) y agrega el resultado a la tienda Nix.

Opciones relacionadas con el registro

•
--debug
Establece el nivel de verbosidad del registro a 'debug'.
•
--log-format formato
Establece el formato de la salida del registro; uno de raw, internal-json, bar o bar-with-logs.
•
--print-build-logs / -L
Imprime los registros de compilación completos en la salida de error estándar.
•
--quiet
Disminuye el nivel de verbosidad del registro.
•
--verbose / -v
Aumenta el nivel de verbosidad del registro.

Opciones globales varias

•
--help
Muestra información de uso.
•
--offline
Deshabilita los sustitutos y considera todos los archivos descargados previamente como actualizados.
•
--option nombre valor
Establece la configuración de Nix nombre a valor (anulando nix.conf).
•
--refresh
Considera todos los archivos descargados previamente como no actualizados.
•
--version
Muestra información de la versión.

Nota

Consulte man nix.conf para anular la configuración con indicadores de línea de comandos.
