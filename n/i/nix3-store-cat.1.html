nix3-store-cat(1) Manual de Comandos Generales nix3-store-cat(1)

Advertencia
Este programa es experimental y su interfaz está sujeta a cambios.

Nombre

nix store cat - imprime en stdout el contenido de un archivo en el almacén Nix

Sinopsis

nix store cat [opción…] ruta

Ejemplos

•
Mostrar el contenido de un archivo en una caché binaria:
# nix store cat --store https://cache.nixos.org/ \
  /nix/store/0i2jd68mp5g6h2sa5k9c85rb80sn8hi9-hello-2.10/bin/hello | hexdump -C | head -n1
00000000  7f 45 4c 46 02 01 01 00  00 00 00 00 00 00 00 00  |.ELF............|

Descripción

Este comando imprime en la salida estándar el contenido del archivo regular ruta en un almacén Nix. ruta puede ser una ruta de nivel superior del almacén o cualquier archivo dentro de una ruta del almacén.

Opciones

Opciones relacionadas con el registro

•
--debug
Establece el nivel de verbosidad del registro a ‘debug’.
•
--log-format formato
Establece el formato de la salida del registro; uno de raw, internal-json, bar o bar-with-logs.
•
--print-build-logs / -L
Imprime los registros de compilación completos en el error estándar.
•
--quiet
Disminuye el nivel de verbosidad del registro.
•
--verbose / -v
Aumenta el nivel de verbosidad del registro.

Opciones globales varias

•
--help
Muestra información de uso.
•
--offline
Deshabilita los sustitutos y considera todos los archivos descargados previamente como actualizados.
•
--option nombre valor
Establece la configuración de Nix nombre a valor (anulando nix.conf).
•
--refresh
Considera todos los archivos descargados previamente como no actualizados.
•
--version
Muestra información de la versión.

Nota

Ver man nix.conf para anular la configuración con indicadores de línea de comandos.
