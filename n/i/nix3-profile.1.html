Advertencia
Este programa es experimental y su interfaz está sujeta a cambios.

Nombre

nix profile - gestionar perfiles de Nix

Sinopsis

nix profile [opción…] subcomando

donde subcomando es uno de los siguientes:

  • nix profile diff-closures - mostrar la diferencia de cierres entre cada versión de un perfil
  • nix profile history - mostrar todas las versiones de un perfil
  • nix profile install - instalar un paquete en un perfil
  • nix profile list - listar paquetes instalados
  • nix profile remove - eliminar paquetes de un perfil
  • nix profile rollback - revertir a la versión anterior o a una versión especificada de un perfil
  • nix profile upgrade - actualizar paquetes utilizando su flake más reciente
  • nix profile wipe-history - eliminar versiones no actuales de un perfil

Descripción

nix profile permite crear y gestionar perfiles de Nix. Un perfil de Nix es un conjunto de paquetes que se pueden instalar y actualizar independientemente unos de otros. Los perfiles de Nix tienen versiones, lo que permite revertirlos fácilmente.

Archivos

Perfiles

Un directorio que contiene enlaces a perfiles gestionados por nix-env y nix profile:

  • $XDG_STATE_HOME/nix/profiles para usuarios normales
  • $NIX_STATE_DIR/profiles/per-user/root si el usuario es root

Un perfil es un directorio de enlaces simbólicos a archivos en el almacén de Nix.

Disposición del sistema de archivos

Los perfiles tienen versiones de la siguiente manera. Al utilizar un perfil llamado ruta, ruta es un enlace simbólico a ruta-N-link, donde N es la versión del perfil. A su vez, ruta-N-link es un enlace simbólico a una ruta en el almacén de Nix. Por ejemplo:

$ ls -l ~alice/.local/state/nix/profiles/profile*
lrwxrwxrwx 1 alice users 14 Nov 25 14:35 /home/alice/.local/state/nix/profiles/profile -> profile-7-link
lrwxrwxrwx 1 alice users 51 Oct 28 16:18 /home/alice/.local/state/nix/profiles/profile-5-link -> /nix/store/q69xad13ghpf7ir87h0b2gd28lafjj1j-profile
lrwxrwxrwx 1 alice users 51 Oct 29 13:20 /home/alice/.local/state/nix/profiles/profile-6-link -> /nix/store/6bvhpysd7vwz7k3b0pndn7ifi5xr32dg-profile
lrwxrwxrwx 1 alice users 51 Nov 25 14:35 /home/alice/.local/state/nix/profiles/profile-7-link -> /nix/store/mp0x6xnsg0b8qhswy6riqvimai4gm677-profile

Cada uno de estos enlaces simbólicos es una raíz para el recolector de basura de Nix.

Cada versión de perfil contiene un archivo de manifiesto: - manifest.nix utilizado por nix-env. - manifest.json utilizado por nix profile (experimental).

Enlace de perfil de usuario

Un enlace simbólico al perfil actual del usuario:

  • ~/.nix-profile
  • $XDG_STATE_HOME/nix/profile si use-xdg-base-directories está establecido en true.

Por defecto, este enlace simbólico apunta a:

  • $XDG_STATE_HOME/nix/profiles/profile para usuarios normales
  • $NIX_STATE_DIR/profiles/per-user/root/profile para root

La variable de entorno PATH debería incluir el subdirectorio /bin del enlace del perfil (por ejemplo, ~/.nix-profile/bin) para que el entorno del usuario sea visible para el usuario. El instalador configura esto por defecto, a menos que habilite use-xdg-base-directories.

Compatibilidad de perfil

Advertencia

Una vez que haya utilizado nix profile ya no podrá utilizar nix-env sin antes eliminar $XDG_STATE_HOME/nix/profiles/profile

Una vez que haya instalado un paquete con nix profile, recibirá el siguiente mensaje de error al usar nix-env:

$ nix-env -f '<nixpkgs>' -iA 'hello'
error: nix-env
profile '/home/alice/.local/state/nix/profiles/profile' is incompatible with 'nix-env'; please use 'nix profile' instead

Para migrar de vuelta a nix-env puede eliminar su perfil actual:

Advertencia

Esto eliminará los paquetes instalados anteriormente, así que es posible que desee hacer una copia de seguridad de esta información antes de ejecutar el comando.

 $ rm -rf "${XDG_STATE_HOME-$HOME/.local/state}/nix/profiles/profile"

Logging options

Imprime los registros de compilación completos en el error estándar.
•
--quiet

•
--verbose / -v

Opciones globales misceláneas

•
--help
Muestra información de uso.
•
--offline
Deshabilita los sustitutos y considera todos los archivos descargados previamente como actualizados.
•
--option nombre valor
Establece la configuración de Nix nombre a valor (anulando nix.conf).
•
--refresh
Considera todos los archivos descargados previamente como desactualizados.
•
--version
Muestra información de la versión.
