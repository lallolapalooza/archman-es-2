NILFS-CLEAN(8) Manual del Administrador del Sistema NILFS-CLEAN(8)

NOMBRE

nilfs-clean - ejecuta el recolector de basura en el sistema de archivos NILFS

SINOPSIS

nilfs-clean [opciones] [dispositivo]

DESCRIPCIÓN

El programa nilfs-clean se comunica con el programa nilfs_cleanerd(8) y controla la ejecución de la recolección de basura (GC) en sistemas de archivos NILFS2. Se puede utilizar para ejecutar manualmente la recolección de basura de un sistema de archivos montado en dispositivo para aumentar el espacio libre.

Si se especifica un comando de GC mediante una de las siguientes opciones (es decir, las opciones ´-c´, ´-s´, ´-r´ y ´-l´), el comando se envía y se realiza en el programa nilfs_cleanerd(8). Si no se especifican comandos, nilfs-clean simplemente activa una limpieza de una sola pasada.

Cuando se omite dispositivo, nilfs-clean selecciona un sistema de archivos NILFS2 activo en el sistema.

Este comando solo es válido para sistemas de archivos NILFS2 montados y fallará si el dispositivo no tiene montajes activos.

OPCIONES

-b, --break, --stop
Detiene la recolección de basura.
-c, --reload[=archivo_config]
Solicita la recarga del archivo de configuración para el proceso de limpieza. Si se proporciona un archivo de configuración opcional, el programa nilfs_cleanerd(8) lee el archivo y la configuración del limpiador se restablece a la información contenida en él. Si no se proporciona ningún argumento, se recargará un archivo de configuración seleccionado por nilfs_cleanerd(8).
-l, --status
Muestra el estado del limpiador.
-h, --help
Muestra el mensaje de ayuda y sale.
-m, --min-reclaimable-blocks=CANTIDAD[%]
Especifica el número mínimo de bloques recuperables en un segmento antes de que pueda ser limpiado. Si el argumento va seguido de un signo de porcentaje, representa la proporción de bloques en un segmento. Este argumento solo tendrá efecto si el indicador use_set_suinfo está establecido en el archivo de configuración.
-p, --protection-period=intervalo
Establece el período de protección para una ejecución de limpieza. El parámetro intervalo es un valor entero y especifica el tiempo mínimo que se conservarán los datos eliminados o sobrescritos en el sistema de archivos. Valores más pequeños aumentarán el espacio libre generado por la recolección de basura. Opcionalmente, el parámetro intervalo puede ir seguido de uno de los siguientes especificadores de unidad: ´s´, ´m´, ´h´, ´d´, ´w´, ´M´ o ´Y´, para segundos, minutos, horas, días, semanas, meses o años, respectivamente.
-q, --quit
Apaga el demonio limpiador.
-r, --resume
Reanuda la recolección de basura.
-s, --suspend
Suspende la recolección de basura. Tenga en cuenta que si los usuarios suspenden manualmente la recolección de basura con esta opción, no se reiniciará automáticamente hasta que el usuario reanude la recolección de basura.
-S, --speed=CANTIDAD[/SEGUNDOS]
Establece la velocidad de recolección de basura para una ejecución de limpieza.
-v, --verbose
Modo detallado.
-V, --version
Muestra la versión y sale.
