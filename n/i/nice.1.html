NICE(1) Comandos de usuario NICE(1)

NOMBRE

nice - ejecuta un programa con una prioridad de planificación modificada

SINOPSIS

nice [OPCIÓN] [COMANDO [ARG]...]

DESCRIPCIÓN

Ejecuta COMANDO con una cortesía (niceness) ajustada, que afecta la planificación de procesos. Sin COMANDO, imprime la cortesía actual. Los valores de cortesía van de -20 (más favorable para el proceso) a 19 (menos favorable para el proceso).

Los argumentos obligatorios para las opciones largas también son obligatorios para las opciones cortas.

-n, --adjustment=N
añade el entero N a la cortesía (por defecto 10)
--help
muestra esta ayuda y sale
--version
muestra información de la versión y sale

Tu shell puede tener su propia versión de nice, que generalmente reemplaza a la versión descrita aquí. Consulta la documentación de tu shell para obtener detalles sobre las opciones que soporta.

Estado de salida:

125
si el comando nice falla
126
si COMANDO se encuentra pero no puede ser invocado
127
si COMANDO no se puede encontrar
-
el estado de salida de COMANDO en caso contrario
