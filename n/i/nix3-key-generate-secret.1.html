Advertencia
Este programa es experimental y su interfaz está sujeta a cambios.

Nombre

nix key generate-secret - genera una clave secreta para firmar rutas del store

Sinopsis

nix key generate-secret [opción…]

Ejemplos

•
Generar una nueva clave secreta:
# nix key generate-secret --key-name cache.example.org-1 > ./secret-key
Luego podemos usar esta clave para firmar la clausura del paquete Hello:
# nix build nixpkgs#hello
# nix store sign --key-file ./secret-key --recursive ./result
Finalmente, podemos verificar las rutas del store usando la clave pública correspondiente:
# nix store verify --trusted-public-keys $(nix key convert-secret-to-public < ./secret-key) ./result

Descripción

Este comando genera una nueva clave secreta Ed25519 para firmar rutas del store y la imprime en la salida estándar. Usa nix key convert-secret-to-public para obtener la clave pública correspondiente para verificar rutas del store firmadas.

El argumento obligatorio --key-name especifica un nombre de clave (como cache.example.org-1). Se utiliza para buscar claves en el cliente cuando verifica firmas. Puede ser cualquier cosa, pero se sugiere usar el nombre de host de su caché (por ejemplo, cache.example.org) con un sufijo que denote el número de la clave (que se incrementará cada vez que necesite revocar una clave).

Formato

Tanto las claves secretas como las públicas se representan como el nombre de la clave seguido de una codificación base-64 de los datos de la clave Ed25519, por ejemplo:

cache.example.org-0:E7lAO+MsPwTFfPXsdPtW8GKui/5ho4KQHVcAGnX+Tti1V4dUxoVoqLyWJ4YESuZJwQ67GVIksDt47og+tPVUZw==

Identificador de la clave (por ejemplo, cache.example.org-1).
