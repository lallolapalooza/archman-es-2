nix3-log(1)

Paquete: nix

Licencias: LGPL-2.1-only

nix3-log(1) Manual de Comandos Generales nix3-log(1)

Advertencia
Este programa es experimental y su interfaz está sujeta a cambios.

Nombre

nix log - muestra el registro de compilación de los paquetes o rutas especificadas, si está disponible

Sinopsis

nix log [opción…] instalable

Ejemplos

•
Obtener el registro de compilación de GNU Hello:
# nix log nixpkgs#hello
•
Obtener el registro de compilación de una ruta de tienda específica:
# nix log /nix/store/lmngj4wcm9rkv3w4dfhzhcyij3195hiq-thunderbird-52.2.1
•
Obtener un registro de compilación de una caché binaria específica:
# nix log --store https://cache.nixos.org nixpkgs#hello

Descripción

Este comando imprime el registro de una compilación anterior del instalable en la salida estándar.

Nix busca registros de compilación en dos lugares:

  • En el directorio /nix/var/log/nix/drvs, que contiene los registros de las derivaciones compiladas localmente.
  • En las cachés binarias listadas en la configuración substituters. Los registros deben llamarse <cache>/log/<nombre-base-de-la-ruta-de-tienda>, donde ruta-de-tienda es una derivación, por ejemplo https://cache.nixos.org/log/dvmig8jgrdapvbyxb1rprckdmdqx08kv-hello-2.10.drv. Para rutas de tienda que no son derivaciones, Nix primero intentará determinar la derivación obteniendo el archivo .narinfo para esta ruta de tienda.

Opciones

Opciones comunes de evaluación

•
--arg nombre expr
Pasa el valor expr como argumento nombre a las funciones de Nix.
•
--arg-from-file nombre ruta
Pasa el contenido del archivo ruta como argumento nombre a las funciones de Nix.
•
--arg-from-stdin nombre
Pasa el contenido de stdin como argumento nombre a las funciones de Nix.
•
--argstr nombre cadena
Pasa la cadena cadena como argumento nombre a las funciones de Nix.
•
--debugger
Inicia un entorno interactivo si la evaluación falla.
•
--eval-store url-tienda
La URL de la tienda Nix a utilizar para la evaluación, es decir, para almacenar derivaciones (.drv archivos) y las entradas referenciadas por ellas.
•
--impure
Permite el acceso a rutas y repositorios mutables.
•
--include / -I ruta
Añade ruta a las entradas de ruta de búsqueda utilizadas para resolver rutas de búsqueda
Esta opción puede darse varias veces.
Las rutas añadidas a través de -I tienen prioridad sobre la configuración de nix-path y la variable de entorno NIX_PATH.
•
--override-flake ref-original ref-resoluta
Anula los registros de flakes, redirigiendo ref-original a ref-resoluta.

Opciones comunes relacionadas con flakes

•
--commit-lock-file
Confirma los cambios en el archivo de bloqueo del flake.
•
--inputs-from url-flake
Utiliza las entradas del flake especificado como entradas del registro.
•
--no-registries
No permite búsquedas en los registros de flakes.
OBSOLETO
Usa --no-use-registries en su lugar.
•
--no-update-lock-file
No permite ninguna actualización del archivo de bloqueo del flake.
•
--no-write-lock-file
No escribe el archivo de bloqueo recién generado del flake.
•
--output-lock-file ruta-bloqueo-flake
Escribe el archivo de bloqueo dado en lugar de flake.lock dentro del flake de nivel superior.
•
--override-input ruta-entrada url-flake
Anula una entrada específica del flake (por ejemplo, dwarffs/nixpkgs). Esto implica --no-write-lock-file.
•
--recreate-lock-file
Recrea el archivo de bloqueo del flake desde cero.
OBSOLETO
Usa nix flake update en su lugar.
•
--reference-lock-file ruta-bloqueo-flake
Lee el archivo de bloqueo dado en lugar de flake.lock dentro del flake de nivel superior.
•
--update-input ruta-entrada
Actualiza una entrada específica del flake (ignorando su entrada anterior en el archivo de bloqueo).
OBSOLETO
Usa nix flake update en su lugar.

Miscellaneous global options

•
--help
Show usage information.
•
--offline
Disable substituters and consider all previously downloaded files up-to-date.
•
--option name value
Set the Nix configuration setting name to value (overriding nix.conf).
•
--refresh
Consider all previously downloaded files out-of-date.
•
--repair
During evaluation, rewrite missing or corrupted files in the Nix store. During building, rebuild missing or corrupted store paths.
•
--version
Show version information.

Options that change the interpretation of installables

•
--expr expr
Interpret installables as attribute paths relative to the Nix expression expr.
•
--file / -f file
Interpret installables as attribute paths relative to the Nix expression stored in file. If file is the character -, then a Nix expression will be read from standard input. Implies --impure.

Note

See man nix.conf for overriding configuration settings with command line flags.
