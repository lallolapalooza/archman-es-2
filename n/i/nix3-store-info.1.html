nix3-store-info(1) Manual de Comandos Generales nix3-store-info(1)

Advertencia
Este programa es experimental y su interfaz está sujeta a cambios.

Nombre

nix store info - prueba si se puede acceder a un store

Sinopsis

nix store info [opción…]

Ejemplos

•
Prueba si la conexión a un store Nix remoto a través de SSH funciona:
# nix store info --store ssh://mac1
•
Prueba si una URL es un caché binario válido:
# nix store info --store https://cache.nixos.org
•
Prueba si el demonio de Nix está en funcionamiento:
# nix store info --store daemon

Descripción

Este comando prueba si se puede acceder a un Nix store particular (especificado por el argumento --store url). Lo que esto significa depende del tipo de store. Por ejemplo, para un store SSH, significa que Nix puede conectarse a la máquina especificada.

Si el comando tiene éxito, Nix devuelve un código de salida de 0 y no imprime ninguna salida.

Opciones

•
--json
Produce salida en formato JSON, adecuada para ser consumida por otro programa.

Opciones relacionadas con el registro

•
--debug
Establece el nivel de verbosidad del registro a 'debug'.
•
--log-format formato
Establece el formato de la salida del registro; una de raw, internal-json, bar o bar-with-logs.
•
--print-build-logs / -L
Imprime los registros de compilación completos en la salida estándar de error.
•
--quiet
Disminuye el nivel de verbosidad del registro.
•
--verbose / -v
Aumenta el nivel de verbosidad del registro.

Opciones globales varias

•
--help
Muestra información de uso.
•
--offline
Deshabilita los sustitutos y considera todos los archivos descargados previamente como actualizados.
•
--option nombre valor
Establece la configuración de Nix nombre a valor (anulando nix.conf).
•
--refresh
Considera todos los archivos descargados previamente como no actualizados.
•
--version
Muestra información de la versión.

Nota

Ver man nix.conf para anular la configuración con flags de línea de comandos.
