nix3-path-info(1)

Paquete: nix

Licencias: LGPL-2.1-only

nix3-path-info(1) Manual de Comandos Generales nix3-path-info(1)

Advertencia
Este programa es experimental y su interfaz está sujeta a cambios.

Nombre

nix path-info - consultar información sobre rutas del almacén (store paths)

Sinopsis

nix path-info [opción…] instalables…

Ejemplos

•
Imprimir la ruta del almacén producida por nixpkgs#hello:
# nix path-info nixpkgs#hello
/nix/store/v5sv61sszx301i0x6xysaqzla09nksnd-hello-2.10
•
Mostrar los tamaños del cierre de cada ruta en el cierre del sistema NixOS actual, ordenados por tamaño:
# nix path-info --recursive --closure-size /run/current-system | sort -nk2
/nix/store/hl5xwp9kdrd1zkm0idm3kkby9q66z404-empty                                                96
/nix/store/27324qvqhnxj3rncazmxc4mwy79kz8ha-nameservers                                         112
…
/nix/store/539jkw9a8dyry7clcv60gk6na816j7y8-etc                                          5783255504
/nix/store/zqamz3cz4dbzfihki2mk7a63mbkxz9xq-nixos-system-machine-20.09.20201112.3090c65  5887562256
•
Mostrar el tamaño del cierre de un paquete y todas sus dependencias con tamaños legibles por humanos:
# nix path-info --recursive --size --closure-size --human-readable nixpkgs#rustc
/nix/store/01rrgsg5zk3cds0xgdsq40zpk6g51dz9-ncurses-6.2-dev      386.7 KiB   69.1 MiB
/nix/store/0q783wnvixpqz6dxjp16nw296avgczam-libpfm-4.11.0          5.9 MiB   37.4 MiB
…
•
Comprobar la existencia de una ruta en una caché binaria:
# nix path-info --recursive /nix/store/blzxgyvrk32ki6xga10phr4sby2xf25q-geeqie-1.5.1 --store https://cache.nixos.org/
ruta '/nix/store/blzxgyvrk32ki6xga10phr4sby2xf25q-geeqie-1.5.1' no es válida
•
Imprimir las 10 rutas añadidas más recientemente (usando –json y el comando jq(1)):
# nix path-info --json --all | jq -r 'to_entries | sort_by(.value.registrationTime) | .[-11:-1][] | .key'
•
Mostrar el tamaño de todo el almacén Nix:
# nix path-info --json --all | jq 'map(.narSize) | add'
49812020936
•
Mostrar cada ruta cuyo cierre sea mayor que 1 GB, ordenado por tamaño del cierre:
# nix path-info --json --all --closure-size \
| jq 'map_values(.closureSize | select(. < 1e9)) | to_entries | sort_by(.value)'
[
…,
{
  .key = "/nix/store/zqamz3cz4dbzfihki2mk7a63mbkxz9xq-nixos-system-machine-20.09.20201112.3090c65",
  .value = 5887562256,
}
]
•
Imprimir la ruta de la derivación del almacén producida por nixpkgs#hello:
# nix path-info --derivation nixpkgs#hello
/nix/store/s6rn4jz1sin56rf4qj5b5v8jxjm32hlk-hello-2.10.drv

Descripción

Este comando muestra información sobre las rutas del almacén (store paths) producidas por instalables, o sobre todas las rutas en el almacén si se pasa --all.

Por defecto, este comando solo imprime las rutas del almacén. Puedes obtener información adicional pasando flags como --closure-size, --size, --sigs o --json.

Advertencia

Tenga en cuenta que nix path-info no construye ni sustituye los instalables que especifica. Por lo tanto, si las rutas del almacén correspondientes no existen ya, este comando fallará. Puede usar nix build para asegurarse de que existen.

Opciones

•
--closure-size / -S
Imprime la suma de los tamaños de las serializaciones NAR del cierre de cada ruta.
•
--human-readable / -h
Con -s y -S, imprime los tamaños en un formato legible por humanos como 5.67G.
•
--json
Produce salida en formato JSON, adecuado para ser consumido por otro programa.
•
--sigs
Muestra las firmas.
•
--size / -s
Imprime el tamaño de la serialización NAR de cada ruta.
•
--stdin
Lee instalables de la entrada estándar. No se aplica ningún instalable por defecto.

Opciones comunes de evaluación

•
--arg nombre expresion
Pasa el valor expresion como el argumento nombre a las funciones Nix.
•
--arg-from-file nombre ruta
Pasa el contenido del archivo ruta como el argumento nombre a las funciones Nix.
•
--arg-from-stdin nombre
Pasa el contenido de stdin como el argumento nombre a las funciones Nix.
•
--argstr nombre cadena
Pasa la cadena cadena como el argumento nombre a las funciones Nix.
•
--debugger
Inicia un entorno interactivo si la evaluación falla.
•
--eval-store url-del-almacen
La URL del almacén Nix a usar para la evaluación, es decir, para almacenar derivaciones (.drv) y las entradas referenciadas por ellas.
•
--impure
Permite el acceso a rutas y repositorios mutables.
•
--include / -I ruta
Añade ruta a las entradas de la ruta de búsqueda utilizadas para resolver rutas de búsqueda
Esta opción puede darse varias veces.
Las rutas añadidas a través de -I tienen prioridad sobre la configuración `nix-path` y la variable de entorno `NIX_PATH`.
•
--override-flake ref-original ref-resuelto
Sobrescribe los registros de flakes, redirigiendo ref-original a ref-resuelto.

Opciones comunes relacionadas con flakes

•
--commit-lock-file
Confirma los cambios en el archivo de bloqueo del flake.
•
--inputs-from flake-url
Utiliza las entradas del flake especificado como entradas de registro.
•
--no-registries
No permite búsquedas en los registros de flakes.
OBSOLETO
Utiliza --no-use-registries en su lugar.
•
--no-update-lock-file
No permite ninguna actualización del archivo de bloqueo del flake.
•
--no-write-lock-file
No escribe el nuevo archivo de bloqueo del flake generado.
•
--output-lock-file flake-lock-path
Escribe el archivo de bloqueo dado en lugar de flake.lock dentro del flake de nivel superior.
•
--override-input input-path flake-url
Sobrescribe una entrada de flake específica (por ejemplo, dwarffs/nixpkgs). Esto implica --no-write-lock-file.
•
--recreate-lock-file
Vuelve a crear el archivo de bloqueo del flake desde cero.
OBSOLETO
Utiliza nix flake update en su lugar.
•
--reference-lock-file flake-lock-path
Lee el archivo de bloqueo dado en lugar de flake.lock dentro del flake de nivel superior.
•
--update-input input-path
Actualiza una entrada de flake específica (ignorando su entrada anterior en el archivo de bloqueo).
OBSOLETO
Utiliza nix flake update en su lugar.

Opciones relacionadas con el registro

•
--debug
Establece el nivel de verbosidad del registro en 'debug'.
•
--log-format format
Establece el formato de salida del registro; uno de raw, internal-json, bar o bar-with-logs.
•
--print-build-logs / -L
Imprime los registros de compilación completos en el error estándar.
•
--quiet
Disminuye el nivel de verbosidad del registro.
•
--verbose / -v
Aumenta el nivel de verbosidad del registro.

Opciones globales varias

•
--help
Muestra información de uso.
•
--offline
Deshabilita los sustitutos y considera todos los archivos descargados previamente como actualizados.
•
--option name value
Establece la configuración de Nix name en value (anulando nix.conf).
•
--refresh
Considera todos los archivos descargados previamente como obsoletos.
•
--repair
Durante la evaluación, reescribe los archivos faltantes o corruptos en el almacén Nix. Durante la compilación, recompila las rutas de almacén faltantes o corruptas.
•
--version
Muestra información de la versión.

Opciones que cambian la interpretación de los instalables

•
--all
Aplica la operación a cada ruta de almacén.
•
--derivation
Opera sobre la derivación de almacén en lugar de sus salidas.
•
--expr expr
Interpreta los instalables como rutas de atributos relativas a la expresión Nix expr.
•
--file / -f file
Interpreta los instalables como rutas de atributos relativas a la expresión Nix almacenada en file. Si file es el carácter -, se leerá una expresión Nix de la entrada estándar. Implica --impure.
•
--recursive / -r
Aplica la operación al cierre de las rutas especificadas.

Nota

Consulta man nix.conf para anular la configuración con indicadores de línea de comandos.
