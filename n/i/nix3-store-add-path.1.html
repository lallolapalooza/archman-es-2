nix3-store-add-path(1) Manual de Comandos Generales nix3-store-add-path(1)

Advertencia
Este programa es experimental y su interfaz está sujeto a cambios.

Nombre

nix store add-path - Alias obsoleto para nix store add.

Sinopsis

nix store add-path [opción…] ruta

Opciones

•
--dry-run
Muestra lo que este comando haría sin hacerlo.
•
--hash-algo algoritmo-hash
Algoritmo de hash (md5, sha1, sha256, o sha512).
•
--mode metodo-direccionamiento-contenido
Cómo calcular la dirección de contenido del objeto de la tienda. Una de:
  • nar (el valor predeterminado): Serializa la entrada como un Archivo Nix y lo pasa a la función hash.
  • flat: Asume que la entrada es un solo archivo y lo pasa directamente a la función hash.
  • text: Similar a flat, pero se utiliza para derivaciones serializadas en el objeto de la tienda y builtins.toFile. Solo para casos de uso avanzados; para uso regular, prefiere nar y flat.
•
--name / -n nombre
Sobrescribe el componente de nombre de la ruta de la tienda. Por defecto, es el nombre base de ruta.

Opciones relacionadas con el registro

•
--debug
Establece el nivel de verbosidad del registro en 'debug'.
•
--log-format formato
Establece el formato de la salida del registro; uno de raw, internal-json, bar o bar-with-logs.
•
--print-build-logs / -L
Imprime los registros de compilación completos en la salida de error estándar.
•
--quiet
Disminuye el nivel de verbosidad del registro.
•
--verbose / -v
Aumenta el nivel de verbosidad del registro.

Opciones globales varias

•
--help
Muestra la información de uso.
•
--offline
Deshabilita los sustitutos y considera que todos los archivos descargados previamente están actualizados.
•
--option nombre valor
Establece la configuración de Nix nombre a valor (anulando nix.conf).
•
--refresh
Considera todos los archivos descargados previamente como desactualizados.
•
--version
Muestra la información de la versión.

Nota

Consulta man nix.conf para anular la configuración con indicadores de línea de comandos.
