Advertencia
Este programa es experimental y su interfaz está sujeta a cambios.

Nombre

nix profile wipe-history - eliminar versiones no actuales de un perfil

Sinopsis

nix profile wipe-history [opción•]

Ejemplos

•
Eliminar todas las versiones del perfil predeterminado con más de 100 días:
# nix profile wipe-history --profile /tmp/profile --older-than 100d
eliminando versión de perfil 515
eliminando versión de perfil 514

Descripción

Este comando elimina versiones no actuales de un perfil, haciendo imposible revertir a esas versiones. Por defecto, se eliminan todas las versiones no actuales. Con --older-than Nd, se eliminan todas las versiones no actuales con más de N días.

Opciones

•
--dry-run
Muestra lo que haría este comando sin hacerlo.
•
--older-than antigüedad
Elimina versiones con más antigüedad que la especificada. antigüedad debe tener el formato Nd, donde N denota un número de días.
•
--profile ruta
El perfil sobre el que operar.

Opciones relacionadas con el registro

•
--debug
Establece el nivel de verbosidad del registro a 'debug'.
•
--log-format formato
Establece el formato de salida del registro; uno de raw, internal-json, bar o bar-with-logs.
•
--print-build-logs / -L
Imprime los registros de compilación completos en la salida estándar de error.
•
--quiet
Disminuye el nivel de verbosidad del registro.
•
--verbose / -v
Aumenta el nivel de verbosidad del registro.

Opciones globales varias

•
--help
Muestra información de uso.
•
--offline
Deshabilita los sustitutos y considera que todos los archivos descargados previamente están actualizados.
•
--option nombre valor
Establece la configuración de Nix nombre a valor (anulando nix.conf).
•
--refresh
Considera que todos los archivos descargados previamente están desactualizados.
•
--version
Muestra información de la versión.

Nota

Consulte man nix.conf para anular la configuración con flags de línea de comandos.
