Advertencia
Este programa es experimental y su interfaz está sujeta a cambios.

Nombre

nix profile list - listar paquetes instalados

Sinopsis

nix profile list [opción•]

Ejemplos

•
Mostrar qué paquetes están instalados en el perfil predeterminado:
# nix profile list
Nombre:               gdb
Atributo de flake:    legacyPackages.x86_64-linux.gdb
URL de flake original: flake:nixpkgs
URL de flake fijado:   github:NixOS/nixpkgs/7b38b03d76ab71bdc8dc325e3f6338d984cc35ca
Rutas de store:        /nix/store/indzcw5wvlhx6vwk7k4iq29q15chvr3d-gdb-11.1
Nombre:               blender-bin
Atributo de flake:    packages.x86_64-linux.default
URL de flake original: flake:blender-bin
URL de flake fijado:   github:edolstra/nix-warez/91f2ffee657bf834e4475865ae336e2379282d34?dir=blender
Rutas de store:        /nix/store/i798sxl3j40wpdi1rgf391id1b5klw7g-blender-bin-3.1.2
Tenga en cuenta que puede reconstruir inequívocamente un paquete de un perfil a través de su URL de flake fijada y atributo de flake, por ejemplo.
# nix build github:edolstra/nix-warez/91f2ffee657bf834e4475865ae336e2379282d34?dir=blender#packages.x86_64-linux.default
construirá el paquete blender-bin mostrado arriba.

Descripción

Este comando muestra qué paquetes están actualmente instalados en un perfil. Para cada paquete instalado, muestra la siguiente información:

  • Nombre: Un nombre único utilizado para identificar inequívocamente el paquete en las invocaciones de nix profile remove y nix profile upgrade.
  • Índice: Un entero que puede usarse para identificar inequívocamente el paquete en las invocaciones de nix profile remove y nix profile upgrade. (Obsoleto, se eliminará en una versión futura en favor de Nombre.)
  • Atributo de flake: La ruta del atributo de salida del flake que proporciona el paquete (por ejemplo, packages.x86_64-linux.hello).
  • URL de flake original: La referencia de flake original (“no fijada”) especificada por el usuario cuando el paquete se instaló por primera vez a través de nix profile install.
  • URL de flake fijada: La referencia de flake fijada a la que se resolvió la referencia de flake original.
  • Rutas de store: La(s) ruta(s) de store del paquete.

Opciones

•
--json
Produce salida en formato JSON, adecuada para el consumo por otro programa.
•
--profile ruta
El perfil sobre el que operar.

Opciones comunes de evaluación

•
--arg nombre expresión
Pasa el valor expresión como argumento nombre a las funciones de Nix.
•
--arg-from-file nombre ruta
Pasa el contenido del archivo ruta como argumento nombre a las funciones de Nix.
•
--arg-from-stdin nombre
Pasa el contenido de stdin como argumento nombre a las funciones de Nix.
•
--argstr nombre cadena
Pasa la cadena cadena como argumento nombre a las funciones de Nix.
•
--debugger
Inicia un entorno interactivo si la evaluación falla.
•
--eval-store url-store
La URL del store de Nix a utilizar para la evaluación, es decir, para almacenar derivaciones (.drv) y las entradas referenciadas por ellas.
•
--impure
Permite el acceso a rutas y repositorios mutables.
•
--include / -I ruta
Añade ruta a las entradas de la ruta de búsqueda utilizadas para resolver rutas de búsqueda
Esta opción puede darse varias veces.
Las rutas añadidas a través de -I tienen prioridad sobre la configuración nix-path y la variable de entorno NIX_PATH.
•
--override-flake ref-original ref-resuelto
Anula los registros de flakes, redirigiendo ref-original a ref-resuelto.

Opciones relacionadas con el registro

•
--debug
Establece el nivel de verbosidad del registro en ‘debug’.
•
--log-format formato
Establece el formato de la salida del registro; uno de raw, internal-json, bar o bar-with-logs.
•
--print-build-logs / -L
Imprime los registros de construcción completos en la salida de error estándar.
•
--quiet
Disminuye el nivel de verbosidad del registro.
•
--verbose / -v
Aumenta el nivel de verbosidad del registro.

Opciones globales varias

•
--help
Muestra información de uso.
•
--offline
Deshabilita los sustitutos y considera todos los archivos descargados previamente como actualizados.
•
--option nombre valor
Establece el valor de una opción de Nix.
•
--override-input name path
Anula la entrada de un flake.
•
--substituters urls
Establece las URLs de los sustitutos a utilizar.
•
--system system
El sistema para el que se evaluarán las salidas (por ejemplo, ‘x86_64-linux’ o ‘aarch64-darwin’).
•
--tarball-package tarball
Instala un paquete desde un tarball de Nix.
•
--version
Muestra la versión de Nix y sale.
•
--working-dir path
El directorio de trabajo para la evaluación.
