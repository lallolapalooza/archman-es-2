NILFS_CLEANERD(8) Manual del Administrador del Sistema NILFS_CLEANERD(8)

NOMBRE

nilfs_cleanerd - recolector de basura de NILFS2

SINOPSIS

nilfs_cleanerd [-hV]

nilfs_cleanerd [opciones] dispositivo [directorio]

DESCRIPCIÓN

nilfs_cleanerd es un demonio del sistema que recupera espacio en disco de un sistema de archivos NILFS2 encontrado en dispositivo.

El argumento opcional directorio especifica el punto de montaje donde opera el demonio. Debe ser un montaje r/w.

Este programa puede ser invocado automáticamente por mount.nilfs2(8) o manualmente por un administrador. Sin embargo, se recomienda a los usuarios invocar nilfs_cleanerd a través de mount.nilfs2(8) o mount(8) y detenerlo a través de umount.nilfs2(8) o umount(8) para evitar inconsistencias de estado entre las herramientas de administración.

nilfs_cleanerd muestra su ID de proceso (pid) a la salida estándar cuando se inicia.

OPCIONES

-V, --version
Muestra la versión y sale.
-h, --help
Muestra el mensaje de ayuda y sale.
-c archivo, --conf=archivo
Especifica el archivo de configuración.
-p intervalo, --protection-period=intervalo
Anula el período de protección con el número de segundos especificado.

SEÑALES

nilfs_cleanerd reacciona a un conjunto de señales. Puede enviar una señal a nilfs_cleanerd usando el PID mostrado por el comando mount (o en /etc/mtab):

# mount -t nilfs2

/dev/sdb1 en /nilfs tipo nilfs2 (rw,gcpid=PID)
# kill -SEÑAL PID
SIGHUP
Esto permite a nilfs_cleanerd realizar una reinicialización. El archivo de configuración (por defecto es /etc/nilfs_cleanerd.conf) será releído.
SIGTERM
nilfs_cleanerd saldrá limpiamente.
SIGUSR1, SIGUSR2
Reservadas para uso futuro. Actualmente hacen que nilfs_cleanerd muera.

ARCHIVOS

/etc/nilfs_cleanerd.conf
Archivo de configuración para nilfs_cleanerd. Consulte nilfs_cleanerd.conf(5) para obtener detalles.

AUTOR

Koji Sato

DISPONIBILIDAD

nilfs_cleanerd es parte del paquete nilfs-utils y está disponible en https://nilfs.sourceforge.io.

VER TAMBIÉN

nilfs(8), mount.nilfs2(8), umount.nilfs2(8), nilfs_cleanerd.conf(5).
