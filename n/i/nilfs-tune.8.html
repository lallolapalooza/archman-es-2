NILFS-TUNE(8) Manual del Administrador del Sistema NILFS-TUNE(8)

NOMBRE

nilfs-tune - ajustar parámetros sintonizables del sistema de archivos en el sistema de archivos NILFS

SINOPSIS

nilfs-tune [opciones] dispositivo

DESCRIPCIÓN

nilfs-tune es una utilidad para modificar parámetros sintonizables del sistema de archivos en el sistema de archivos NILFS2 en dispositivo.

Este comando es válido para sistemas de archivos NILFS2 inactivos. Modificar montajes activos puede causar daños graves.

OPCIONES

-f
Forzar la modificación incluso si el sistema de archivos especificado está montado.
-i intervalo
Establecer el intervalo de confirmación del segmento.
-m max_bloques
Establecer el umbral de la cantidad de datos de la construcción del segmento.
-l
Listar el contenido de la superbloque del sistema de archivos, incluidos los valores actuales de los parámetros que se pueden establecer a través de este programa.
-L etiqueta_volumen
Establecer la etiqueta del volumen del sistema de archivos. Las etiquetas de los sistemas de archivos NILFS2 pueden tener un máximo de 80 bytes. Si la etiqueta_volumen es más larga que 80 bytes, nilfs-tune la truncará. La etiqueta del volumen se puede usar en mount(8) y /etc/fstab(5) (y posiblemente en otros) especificando LABEL=etiqueta_volumen en lugar de un nombre de dispositivo especial de bloque como /dev/sda5.
-O [^]característica[,...]
Establecer o borrar las características (opciones) indicadas del sistema de archivos en el sistema de archivos. Se pueden borrar o establecer varias características del sistema de archivos separándolas con comas. Las características del sistema de archivos prefijadas con un carácter de intercalación ('^') se borrarán del superbloque del sistema de archivos; las características del sistema de archivos sin prefijo se añadirán al sistema de archivos.
La siguiente característica del sistema de archivos se puede establecer o borrar utilizando nilfs-tune:
recuento_bloques
Habilitar el recuento de bloques por punto de control. Después de establecer esta opción, se debe ejecutar fsck en el sistema de archivos para que los recuentos sean correctos, pero aún no hay una herramienta fsck disponible, lo siento.
-U UUID
Establecer el identificador universalmente único (UUID) del sistema de archivos a UUID. El formato del UUID es una serie de dígitos hexadecimales separados por guiones, así: "c1b9d5a2-f162-11cf-9ece-0020afc76f16".
-h
Mostrar mensaje de ayuda y salir.
