Nombre

nix flake info - mostrar metadatos de flake

Sinopsis

Descripción

Este comando muestra información sobre el flake especificado por la referencia de flake flake-url. Resuelve la referencia del flake usando el registro de flakes, lo descarga e imprime algunos metadatos. Esto incluye:

  • URL Resuelto: Si flake-url es un identificador de flake, esta es la referencia de flake que especifica su ubicación real, buscada en el registro de flakes.
  • URL Bloqueado: Una referencia de flake que contiene un hash de commit o de contenido y, por lo tanto, identifica de forma única una versión específica del flake.
  • Descripción: Una descripción de una línea del flake, tomada del campo description en flake.nix.
  • Ruta: La ruta del store que contiene el código fuente del flake.
  • Revisión: El hash del commit de Git o Mercurial del flake bloqueado.
  • Revisiones: El número de ancestros del commit de Git o Mercurial del flake bloqueado. Tenga en cuenta que esto no está disponible para flakes de github.
  • Última mod.: Para flakes de Git o Mercurial, este es el tiempo del commit del commit del flake bloqueado; para flakes de archivo tar, es la marca de tiempo más reciente de cualquier archivo dentro del archivo tar.
  • Entradas: Las entradas del flake con sus entradas correspondientes del archivo de bloqueo.

Con --json, la salida es un objeto JSON con los siguientes campos:

  • original y originalUrl: La referencia de flake especificada por el usuario (flake-url) en un conjunto de atributos y representación de URL.
  • resolved y resolvedUrl: La referencia de flake resuelta (ver arriba) en un conjunto de atributos y representación de URL.
  • locked y lockedUrl: La referencia de flake bloqueada (ver arriba) en un conjunto de atributos y representación de URL.
  • description: Ver Descripción arriba.
  • path: Ver Ruta arriba.
  • revision: Ver Revisión arriba.
  • revCount: Ver Revisiones arriba.
  • lastModified: Ver Última mod. arriba.
  • locks: El contenido de flake.lock.

Opciones

•
--json
Produce salida en formato JSON, adecuada para el consumo por otro programa.

Opciones comunes de evaluación

•
--arg nombre expr
Pasa el valor expr como argumento nombre a las funciones de Nix.
•
--arg-from-file nombre ruta
Pasa el contenido del archivo ruta como argumento nombre a las funciones de Nix.
•
--arg-from-stdin nombre
Pasa el contenido de stdin como argumento nombre a las funciones de Nix.
•
--argstr nombre cadena
Pasa la cadena cadena como argumento nombre a las funciones de Nix.
•
--debugger
Inicia un entorno interactivo si la evaluación falla.
•
--eval-store store-url
La URL del store de Nix a utilizar para la evaluación, es decir, para almacenar derivaciones (.drv) y entradas referenciadas por ellas.
•
--impure
Permite el acceso a rutas y repositorios mutables.
•
--include / -I ruta
Añade ruta a las entradas de la ruta de búsqueda utilizadas para resolver rutas de búsqueda.
Esta opción se puede proporcionar varias veces.
Las rutas añadidas a través de -I tienen prioridad sobre el ajuste de configuración nix-path y la variable de entorno NIX_PATH.
•
--override-flake ref-original ref-resuelta
Anula los registros de flakes, redirigiendo ref-original a ref-resuelta.

Opciones comunes relacionadas con flakes

•
--commit-lock-file
Confirmar cambios en el archivo de bloqueo de flake.
•
--inputs-from flake-url
Utilizar las entradas del flake especificado como entradas de registro.
•
--no-registries
No permitir búsquedas en los registros de flakes.
OBSOLETO
Utilizar --no-use-registries en su lugar.
•
--no-update-lock-file
No permitir ninguna actualización del archivo de bloqueo de flake.
•
--no-write-lock-file
No escribir el archivo de bloqueo de flake recién generado.
•
--output-lock-file ruta-archivo-bloqueo-flake
Escribir el archivo de bloqueo proporcionado en lugar de flake.lock dentro del flake de nivel superior.
•
--override-input ruta-entrada flake-url
Anular una entrada de flake específica (por ejemplo, dwarffs/nixpkgs). Esto implica --no-write-lock-file.
•
--recreate-lock-file
Recrear el archivo de bloqueo de flake desde cero.
OBSOLETO
Utilizar nix flake update en su lugar.
•
--reference-lock-file ruta-archivo-bloqueo-flake
Leer el archivo de bloqueo proporcionado en lugar de flake.lock dentro del flake de nivel superior.
•
--update-input ruta-entrada
Actualizar una entrada de flake específica (ignorando su entrada anterior en el archivo de bloqueo).
OBSOLETO
Utilizar nix flake update en su lugar.

Opciones relacionadas con el registro

•
--debug
Establecer el nivel de verbosidad del registro en 'debug'.
•
--log-format formato
Establecer el formato de la salida del registro; uno de raw, internal-json, bar o bar-with-logs.
•
--print-build-logs / -L
Imprimir registros de compilación completos en la salida estándar de error.
•
--quiet
Disminuir el nivel de verbosidad del registro.
•
--verbose / -v
Aumentar el nivel de verbosidad del registro.

Opciones globales varias

•
--help
Mostrar información de uso.
•
--offline
Deshabilitar sustitutos y considerar todos los archivos descargados previamente como actualizados.
•
--option nombre valor
Establecer la configuración de Nix nombre en valor (anulando nix.conf).
•
--refresh
Considerar todos los archivos descargados previamente como no actualizados.
•
--repair
Durante la evaluación, reescribir archivos faltantes o corruptos en la tienda Nix. Durante la compilación, recompilar rutas de tienda faltantes o corruptas.
•
--version
Mostrar información de la versión.

Nota

Ver man nix.conf para anular la configuración con indicadores de línea de comandos.
