NETCAP:(8) Utilidades de administración del sistema NETCAP:(8)

NOMBRE

netcap - un programa para ver capacidades

SINOPSIS

netcap

DESCRIPCIÓN

netcap es un programa que imprime un informe de las capacidades del proceso. Si la aplicación está utilizando sockets de la familia tcp, udp, raw o packet Y tiene alguna capacidad, aparecerá en el informe. Si el proceso tiene capacidades parciales, se examina más a fondo para ver si tiene un conjunto de límites abiertos. Si se descubre que esto es cierto, se añade un símbolo '+'. Si el proceso tiene capacidades ambientales, se añade un símbolo '@'.

Algunos directorios en el sistema de archivos /proc son de solo lectura para root. El programa intentará acceder e informar lo que pueda. Pero si no sale nada, intente cambiarse al usuario root y vuelva a ejecutar este programa.

VER TAMBIÉN

pscap(8), filecap(8), capabilities(7), netstat(8).
