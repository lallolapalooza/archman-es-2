NEWLOCALE(3P) Manual de Programador POSIX NEWLOCALE(3P)

PROLOG

Esta página del manual forma parte del Manual de Programador POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual de Linux correspondiente para conocer los detalles del comportamiento en Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

newlocale — crear o modificar un objeto de localización

SINOPSIS

#include <locale.h>
locale_t newlocale(int category_mask, const char *locale,
    locale_t base);

DESCRIPCIÓN

La función newlocale() creará un nuevo objeto de localización o modificará uno existente. Si el argumento base es (locale_t)0, se creará un nuevo objeto de localización. No se especifica si el objeto de localización apuntado por base será modificado, o liberado y se creará un nuevo objeto de localización.

El argumento category_mask especifica las categorías de localización que se establecerán o modificarán. Los valores para category_mask se construirán mediante una operación OR inclusiva de bits de las constantes simbólicas LC_CTYPE_MASK, LC_NUMERIC_MASK, LC_TIME_MASK, LC_COLLATE_MASK, LC_MONETARY_MASK y LC_MESSAGES_MASK, o cualquiera de los valores de máscara definidos por la implementación en <locale.h>.

Para cada categoría con el bit correspondiente establecido en category_mask, se utilizarán los datos del nombre de localización indicado por locale. En el caso de modificar un objeto de localización existente, los datos del nombre de localización indicado por locale reemplazarán los datos existentes dentro del objeto de localización. Si se crea un objeto de localización completamente nuevo, los datos de todas las secciones no solicitadas por category_mask se tomarán de la localización predeterminada.

Los siguientes valores predefinidos de locale se definen para todas las configuraciones de category_mask:

"POSIX"
Especifica el entorno mínimo para la traducción del lenguaje C, denominado localización POSIX.
"C"
Equivalente a "POSIX".
""
Especifica un entorno nativo definido por la implementación. Esto corresponde al valor de las variables de entorno asociadas, LC_* y LANG; véase el volumen de Definiciones Base de POSIX.1‐2017, Capítulo 7, Localización y Capítulo 8, Variables de Entorno.

Si el argumento base no es (locale_t)0 y la llamada a la función newlocale() tiene éxito, el contenido de base no se especifica. Las aplicaciones deben asegurarse de dejar de usar base como objeto de localización antes de llamar a newlocale(). Si la llamada a la función falla y el argumento base no es (locale_t)0, el contenido de base permanecerá válido y sin cambios.

El comportamiento no está definido si el argumento base es el objeto de localización especial LC_GLOBAL_LOCALE, o no es un identificador válido de objeto de localización y no es (locale_t)0.

VALOR DE RETORNO

Al completarse con éxito, la función newlocale() devolverá un identificador que el llamante podrá usar en llamadas posteriores a duplocale(), freelocale() y otras funciones que toman un argumento locale_t.

En caso de fallo, la función newlocale() devolverá (locale_t)0 y establecerá errno para indicar el error.

ERRORES

La función newlocale() fallará si:

ENOMEM
No hay suficiente memoria disponible para crear el objeto de localización o cargar los datos de localización.
EINVAL
El category_mask contiene un bit que no corresponde a una categoría válida.
ENOENT
Para cualquiera de las categorías en category_mask, los datos de localización no están disponibles.

La función newlocale() puede fallar si:

EINVAL
El argumento locale no es un puntero de cadena válido.

EJEMPLOS

Construcción de un Objeto de Localización a partir de Diferentes Localizaciones

El siguiente ejemplo muestra la construcción de una localización donde los datos de la categoría LC_CTYPE provienen de una localización loc1 y los datos de la categoría LC_TIME de una localización loc2:

#include <locale.h>
...
locale_t loc, new_loc;
/* Obtener los datos de "loc1". */
loc = newlocale (LC_CTYPE_MASK, "loc1", (locale_t)0);
if (loc == (locale_t) 0)
    abort ();
/* Obtener los datos de "loc2". */
new_loc = newlocale (LC_TIME_MASK, "loc2", loc);
if (new_loc != (locale_t) 0)
    /* No abortamos si esto falla. En este caso, esto
       simplemente utilizó el objeto de localización sin cambios. */
    loc = new_loc;
...

Liberar un Objeto de Localización

El siguiente ejemplo muestra un fragmento de código para liberar un objeto de localización creado por newlocale():

#include <locale.h>
...
/* Cada objeto de localización asignado con newlocale() debe
 * liberarse usando freelocale():
 */
locale_t loc;
/* Obtener la localización. */
loc = newlocale (LC_CTYPE_MASK | LC_TIME_MASK, "locname", (locale_t)0);
/* ... Usar el objeto de localización ... */
...
/* Liberar los recursos del objeto de localización. */
freelocale (loc);

USO DE APLICACIÓN

Los identificadores de objetos de localización creados por la función newlocale() deben ser liberados mediante una llamada correspondiente a freelocale(), o usarse como localización base para otra llamada a newlocale().

El objeto de localización especial LC_GLOBAL_LOCALE no debe pasarse como argumento base, incluso cuando es devuelto por la función uselocale().
