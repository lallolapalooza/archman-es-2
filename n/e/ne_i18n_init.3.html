ne_i18n_init(3)

Paquete: neon

Licencias: LGPL-2.0-or-later

NE_I18N_INIT(3) Referencia de la API de neon NE_I18N_INIT(3)

NOMBRE

ne_i18n_init - funciones para inicializar soporte de internacionalización

SINOPSIS

#include <ne_i18n.h>

void ne_i18n_init(const char *encoding);

DESCRIPCIÓN

La función ne_i18n_init se puede usar para habilitar el soporte para mensajes traducidos en la biblioteca neon. El parámetro encoding, si no es NULL, especifica la codificación de caracteres requerida para las cadenas traducidas generadas. Si es NULL, se usará la codificación de caracteres apropiada para la configuración regional del proceso.

Esta llamada solo es estrictamente necesaria si:

1. neon se ha instalado en un prefijo diferente al de la implementación de gettext en la que depende para fines de i18n, o
2.el llamador requiere que los mensajes traducidos estén en una codificación de caracteres particular.

Si ne_i18n_init nunca se llama, los catálogos de mensajes no se encontrarán si se aplica el caso (a) (y, por lo tanto, se usarán mensajes de error en inglés), y se utilizará la codificación de caracteres predeterminada especificada por la configuración regional del proceso. La biblioteca funcionará correctamente de lo contrario.

Tenga en cuenta que la codificación utilizada es una configuración global del proceso, por lo que los resultados pueden ser inesperados si otros usuarios de neon dentro del proceso llaman a ne_i18n_init con un parámetro de codificación diferente.
