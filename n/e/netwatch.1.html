NOMBRE

Netwatch - Monitor de Protocolo de Internet Ethernet

SINOPSIS

netwatch [ -h ] [-b] [-i dd.dd.dd.dd] [-m dd.dd.dd.dd] [-n] [ - t] [ -e ethnum ] [ -c archivo_config_red ]

DESCRIPCIÓN

Netwatch examina todos los paquetes que viajan por una ethernet y analiza los paquetes IP. La información se totaliza según los hosts de origen y destino. Una pantalla de ncurses indica un estado de lista doble para todos los hosts. La pantalla izquierda se refiere a los hosts LOCALES. La lista derecha se refiere a los hosts REMOTOS. Es posible examinar estadísticas (recuentos) sobre el número de paquetes, bytes, tipo de servicio IP y último host de comunicación para cada host. Utilice las teclas de flecha (izquierda y derecha) para cambiar la pantalla.

OPCIONES

-e ethnum
ethnum es el nombre del dispositivo ethernet con el que se intentará ejecutar netwatch. (por ejemplo, -e eth1 selecciona el dispositivo eth1 en lugar del dispositivo predeterminado eth0).
-c archivo_config_red
selecciona el nombre del archivo que contiene la información de ifconfig. Tenga en cuenta que esto no es necesario ya que netwatch utilizará la información de ruta de /proc/net para construir toda la información necesaria (sin usar NINGÚN archivo de configuración).
-b
Para un puente transparente, ignore cada dos paquetes... (kernels anteriores)
-i dd.dd.dd.dd
Falsifica una dirección de internet local para la máquina "actual"... (útil para crear una red local falsa para monitorizar cuando se combina con la opción -m)
-m dd.dd.dd.dd
Falsifica la máscara de red que se utiliza para la evaluación de la red local
-n
No resuelva nombres (solo muestre direcciones)
-h
Información de ayuda simple
-t
Inicia Netwatch en Modo TOP (retraso de inicio de 30 segundos)

COMANDOS DE USUARIO

La siguiente descripción intentará aclarar qué teclas entiende netwatch. Es importante saber que el programa depende del modo. Esto significa que los comandos pueden cambiar dependiendo del modo actual. El modo principal es el modo de lista doble. En este modo, use

<tab>
tecla - cambia la pantalla de desplazamiento a la otra lista (listas dobles). Busque CLAVE.
<izquierda>
tecla - Cambia las opciones de visualización (moviéndose hacia la izquierda entre las opciones)
<derecha>
tecla - Cambia las opciones de visualización (moviéndose hacia la derecha entre las opciones)
<arriba>
tecla - Desplaza a la página de host anterior en la lista actual (ver CLAVE) Cambia las opciones de visualización (moviéndose hacia la derecha entre las opciones)
<abajo>
tecla - Desplaza a la página de host siguiente en la lista actual (ver CLAVE)
h
tecla - muestra la pantalla de ayuda
t
tecla - Activa/desactiva el modo TOP (donde la actualización cada 30 segundos muestra los hosts más activos)
c
tecla - Borra los recuentos para todos los hosts
n
tecla - Limpia las tablas de hosts remotos y locales
N
tecla - Limpia la tabla de hosts remotos O locales (depende de cuál esté actual)
L
tecla - Produce un LOG de las entradas de visualización actuales (REMOTO o LOCAL)
b
tecla - Activa/desactiva la visualización de entradas AZULES (ANTIGUAS)
d
tecla - Activa/desactiva la visualización de entradas de DOMINIO (Consultas al Servidor de Nombres)
w
tecla - Entra en modo WATCH para ver estadísticas de ENRUTAMIENTO y paquetes de HOST
<F10>, <FIN>
o tecla q - Sale del programa
