Nemo(1) Manual de comandos generales Nemo(1)

NOMBRE

nemo - el gestor de archivos de Cinnamon

SINOPSIS

nemo [opciones] URIs...

DESCRIPCIÓN

Esta página del manual documenta brevemente el comando nemo.

Nemo es el gestor de archivos del escritorio Cinnamon.

OPCIONES

Nemo sigue la sintaxis habitual de línea de comandos de GNU, con opciones largas que comienzan con dos guiones (`-'). A continuación se incluye un resumen de las opciones.

-g
--geometry=GEOMETRÍA
Crea la ventana inicial con la geometría dada.
-t
--tabs
Abre las URIs en pestañas.
--existing-window
Abre las URIs en una ventana existente.
-n
--no-default-window
Crea ventanas solo para las URIs especificadas explícitamente.
--fix-cache
Repara la caché de miniaturas del usuario; esto puede ser útil si tienes problemas con las miniaturas de los archivos. Debe ejecutarse como root.
--debug
Habilita el código de depuración. Uso de ejemplo: 'NEMO_DEBUG=Actions nemo --debug'. Usa NEMO_DEBUG=all para más temas.
-q
--quit
Sale de Nemo.
--help
Muestra un resumen de las opciones.
--version
Muestra la versión de Nemo.
Otras opciones estándar de GNOME no listadas aquí también son compatibles.

NOTA SOBRE EL USUARIO ROOT

Normalmente, nemo y nemo-desktop tratan la ejecución como usuario root como algo especial, con ciertas restricciones y cambios en la interfaz de usuario. Este comportamiento puede eludirse a través de una clave de gsettings. Puedes usar el siguiente comando para habilitar/deshabilitar esta anulación:

gsettings set org.nemo.preferences treat-root-as-normal true|false
