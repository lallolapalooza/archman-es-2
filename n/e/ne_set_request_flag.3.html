ne_set_request_flag(3)

Paquete: neon

Licencias: LGPL-2.0-or-later

NE_SET_REQUEST_FLAG(3) Referencia de la API de neon NE_SET_REQUEST_FLAG(3)

NOMBRE

ne_set_request_flag, ne_get_request_flag - establecer y recuperar flags por solicitud

SINOPSIS

#include <ne_request.h>

void ne_set_request_flag(ne_request *req, ne_request_flag flag, int value);

int ne_get_request_flag(ne_request *req, ne_request_flag flag);

DESCRIPCIÓN

La función ne_set_request_flag habilita o deshabilita un flag por solicitud. Pasar un argumento value distinto de cero habilita el flag, y cero lo deshabilita.

Los siguientes flags están definidos:

NE_REQFLAG_EXPECT100

habilita este flag para usar la característica "Expect: 100-continue" de HTTP/1.1, que permite al servidor procesar las cabeceras de la solicitud sin leer el cuerpo completo de la solicitud. Esto ahorra tiempo y ancho de banda si el servidor presenta un desafío de autenticación (lo que requiere que se reenvíe la solicitud), pero tiene problemas de interoperabilidad con algunos servidores antiguos.

NE_REQFLAG_IDEMPOTENT

deshabilita este flag si la solicitud usa un método no idempotente como POST

NE_REQFLAG_1XXTIMEOUT (habilitado por defecto)

deshabilita este flag para desactivar el tiempo de espera general al leer respuestas provisionales (1xx);

VALOR DE RETORNO

La función ne_get_request_flag devuelve cero si un flag está deshabilitado, menos que cero si el flag no es compatible, o mayor que cero si el flag está habilitado.

VER TAMBIÉN

ne_request_create.
