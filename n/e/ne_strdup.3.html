NE_MALLOC(3) Referencia de la API de neon NE_MALLOC(3)

NOMBRE

ne_malloc, ne_calloc, ne_realloc, ne_strdup, ne_strndup, ne_oom_callback - envolturas de asignación de memoria

SINOPSIS

#include <ne_alloc.h>

void *ne_malloc(size_t size);

void *ne_calloc(size_t size);

void *ne_realloc(void *ptr, size_t len);

char *ne_strdup(const char *s);

char *ne_strndup(const char *s, size_t size);

void ne_oom_callback(void (*callback)(void));

DESCRIPCIÓN

Las funciones ne_malloc, ne_calloc, ne_realloc, ne_strdup y ne_strdnup proporcionan envolturas para las funciones equivalentes de la biblioteca estándar de C. Las envolturas proporcionan la garantía adicional de que si el equivalente de la biblioteca C devuelve NULL cuando no hay memoria disponible, se llamará a una llamada de retorno opcional y luego la biblioteca llamará a abort().

ne_oom_callback registra una llamada de retorno que se invocará si se detecta un error de falta de memoria.

NOTAS

Si el sistema operativo utiliza la asignación de memoria optimista, las rutinas de asignación de memoria de la biblioteca C no devolverán NULL, por lo que no es posible manejar fallos de asignación de memoria de forma elegante.
