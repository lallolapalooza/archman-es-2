NOMBRE

ne_has_support - determinar el estado de soporte de una función

SINOPSIS

#include <ne_utils.h>

int ne_has_support(int feature);

DESCRIPCIÓN

La función ne_has_support se puede utilizar para determinar si una característica opcional particular, dada por el código de característica feature, está soportada. Los siguientes códigos de característica están disponibles:

NE_FEATURE_SSL

Indica soporte para SSL/TLS

NE_FEATURE_ZLIB

Indica soporte para respuestas comprimidas

NE_FEATURE_IPV6

Indica soporte para IPv6

NE_FEATURE_LFS

Indica soporte para archivos grandes

NE_FEATURE_SOCKS

Indica soporte para SOCKSv5

NE_FEATURE_TS_SSL

Indica soporte para inicialización SSL segura para hilos — véase ne_sock_init

NE_FEATURE_GSSAPI

Indica soporte para autenticación Negotiate vía GSSAPI

NE_FEATURE_LIBPXY

Indica soporte para libproxy (en ne_session_system_proxy)

VALOR DE RETORNO

ne_has_support devuelve un valor distinto de cero si la característica dada está soportada, o cero en caso contrario.

HISTORIA

Las constantes NE_FEATURE_GSSAPI y NE_FEATURE_LIBPXY solo están disponibles en neon 0.34.0 y posteriores.

VER TAMBIÉN

ne_version_match(3), ne_sock_init(3)
