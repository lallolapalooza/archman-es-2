NOMBRE

netctl-auto - Controlar la selección automática de perfiles netctl inalámbricos

SINOPSIS

netctl-auto {COMANDO} ...

netctl-auto {--ayuda | --version}

DESCRIPCIÓN

netctl-auto puede usarse para controlar la selección automática de perfiles de red ofrecida por el archivo netctl-auto@.service. Ver netctl.special(7) para detalles sobre el archivo de servicio.

OPCIONES

Se entienden los siguientes comandos:

list

Lista todos los perfiles que están actualmente disponibles para selección automática. Los perfiles activos se marcarán con un ‘*’, los perfiles deshabilitados se marcarán con un ‘!’.

switch-to [PERFIL]

Cambiar al perfil de red especificado en la línea de comandos. El perfil especificado se habilitará si es necesario, el estado de todos los demás perfiles no se modifica. Este comando no fuerza a netctl-auto a usar el perfil especificado. Si ocurre una desconexión, netctl-auto puede seleccionar un perfil alternativo.

is-active [PERFIL]

Comprobar si el perfil de red especificado en la línea de comandos está activo. Imprime el estado actual.

enable [PERFIL]

Habilitar un perfil de red previamente deshabilitado para selección automática. Cada vez que se inicia el servicio netctl-auto, todos los perfiles disponibles se habilitan por defecto.

disable [PERFIL]

Deshabilitar el perfil especificado para selección automática. Esto solo tendrá efecto hasta que el servicio netctl-auto se detenga. Para excluir permanentemente un perfil de la selección automática, use la opción ExcludeAuto=yes en el perfil.

enable-all

Habilitar todos los perfiles para selección automática.

disable-all

Deshabilitar todos los perfiles para selección automática.

is-enabled [PERFIL]

Comprobar si el perfil especificado está habilitado para el servicio netctl-auto que se está ejecutando actualmente. Imprime el estado de habilitación actual.

start [INTERFAZ]

Iniciar la selección automática de perfiles en la interfaz especificada.

Este comando no debe ser invocado directamente, use el siguiente comando en su lugar:

    systemctl start netctl-auto@<interfaz>

stop [INTERFAZ]

Detener la selección automática de perfiles en la interfaz especificada. Esto desconectará el perfil actualmente activo en la interfaz.

Este comando no debe ser invocado directamente, use el siguiente comando en su lugar:

    systemctl stop netctl-auto@<interfaz>

CÓDIGO DE SALIDA

En caso de éxito se devuelve 0, en caso contrario un código de error no nulo.

ENTORNO

$NETCTL_DEBUG

Si está configurado como "yes", se genera salida de depuración.

VER TAMBIÉN

netctl(1), netctl.profile(5), netctl.special(7)
