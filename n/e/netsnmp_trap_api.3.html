netsnmp_trap_api(3)

Paquete: net-snmp

Licencias: BSD

NETSNMP_TRAP_API(3) Net-SNMP NETSNMP_TRAP_API(3)

NOMBRE

send_easy_trap, send_trap_vars, send_v2trap - enviar TRAPs o INFORMs desde un módulo MIB de Net-SNMP

SINOPSIS

#include <net-snmp/agent/agent_trap.h>

void send_easy_trap(int trap, int specific);

void send_trap_vars(int trap, int specific, struct variable_list *vars);

void send_v2trap(struct variable_list *vars);

DESCRIPCIÓN

Estas tres rutinas pueden ser utilizadas para enviar trampas desde un módulo MIB dentro del agente Net-SNMP (incluyendo un subagente AgentX).

send_easy_trap() envía una trampa SNMPv1 (o su equivalente SNMPv2) a la lista de destinos de trampas configurados (o "sumideros"), utilizando los valores proporcionados para el tipo genérico de trampa y el valor específico de la trampa.

send_trap_vars() es similar, pero añade la lista de enlaces de variables proporcionada a las trampas que se envían.

send_v2trap() utiliza la lista de enlaces de variables proporcionada para formar una trampa SNMPv2, que se envía a los sumideros capaces de SNMPv2 en la lista configurada. Se envía un INFORM equivalente a la lista configurada de sumideros de inform. Se omiten los sumideros que solo pueden manejar trampas SNMPv1.

Las diversas llamadas "send_trap()" te permiten especificar trampas en diferentes formatos. Y las diversas directivas "trapsink" te permiten especificar destinos para recibir diferentes formatos. Pero *todas* las trampas se envían a *todos* los destinos, independientemente de cómo se especificaron.

Es decir, es
                                         ___  trapsink
                                        /
    send_easy_trap ___  [  Trampa      ] ____  trap2sink
                    ___  [ Generador  ]
    send_v2trap    /     [            ] ----- informsink
                                        ____
                                              trapsess
*No*
     send_easy_trap  ------------------->  trapsink
     send_v2trap     ------------------->  trap2sink
     ????            ------------------->  informsink
     ????            ------------------->  trapsess

ADVERTENCIAS

Estas rutinas se utilizan para enviar las trampas inmediatamente cuando se llaman. La invocación en el momento apropiado se deja al programador del módulo MIB.
