NEARBYINT(3P) Manual del programador POSIX NEARBYINT(3P)

PROLOGO

Esta página del manual forma parte del Manual del programador POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual de Linux correspondiente para obtener detalles sobre el comportamiento en Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

nearbyint, nearbyintf, nearbyintl — funciones de redondeo de punto flotante

SINOPSIS

#include <math.h>
double nearbyint(double x);
float nearbyintf(float x);
long double nearbyintl(long double x);

DESCRIPCIÓN

La funcionalidad descrita en esta página de referencia está alineada con el estándar ISO C. Cualquier conflicto entre los requisitos descritos aquí y el estándar ISO C es involuntario. Este volumen de POSIX.1-2017 remite al estándar ISO C.

Estas funciones redondearán su argumento a un valor entero en formato de punto flotante, utilizando la dirección de redondeo actual y sin levantar la excepción de punto flotante inexacta.

VALOR DE RETORNO

Al completarse con éxito, estas funciones devolverán el valor entero redondeado. El resultado tendrá el mismo signo que x.

Si x es NaN, se devolverá un NaN.

Si x es ±0, se devolverá ±0.

Si x es ±Inf, se devolverá x.

ERRORES

No se definen errores.

Las siguientes secciones son informativas.

USO DE APLICACIÓN

El valor entero devuelto por estas funciones no tiene por qué ser representable como un intmax_t. El valor de retorno debe comprobarse antes de asignarlo a un tipo entero para evitar los resultados indefinidos de un desbordamiento entero.
