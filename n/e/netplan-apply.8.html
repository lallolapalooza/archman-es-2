NOMBRE

netplan-apply - aplica la configuración de los archivos YAML de Netplan a un sistema en ejecución

SINOPSIS

netplan [--debug] apply -h|--help

netplan [--debug] apply

DESCRIPCIÓN

netplan apply aplica la configuración actual de Netplan a un sistema en ejecución.

El proceso funciona de la siguiente manera:

1.
La configuración del backend se genera a partir de los archivos YAML de Netplan.
2.
Los backends apropiados (systemd-networkd(8) o NetworkManager(8)) se invocan para activar las interfaces configuradas.
3.
netplan apply itera sobre las interfaces que todavía están caídas, las desvincula de sus controladores y las vuelve a vincular. Esto da a las reglas de renombrado de udev(7) la oportunidad de ejecutarse.
4.
Si se han reasignado dispositivos, los backends apropiados se vuelven a invocar en caso de que se puedan hacer más coincidencias.

Para obtener información sobre el paso de generación, consulte netplan-generate(8). Para obtener detalles sobre el formato del archivo de configuración, consulte netplan(5).

OPCIONES

-h, --help
Imprime ayuda básica.
--debug
Imprime la salida de depuración durante el proceso.

PROBLEMAS CONOCIDOS

netplan apply no eliminará dispositivos virtuales como puentes y enlaces que se hayan creado, incluso si ya no se describen en la configuración de Netplan. Esto se debe a que Netplan opera sin estado y no es consciente de los dispositivos virtuales definidos previamente.

Esto se puede resolver eliminando manualmente el dispositivo virtual (por ejemplo, ip link delete dev bond0) y luego ejecutando netplan apply, reiniciando o creando una copia de seguridad temporal del estado YAML en /etc/netplan antes de modificar la configuración y pasando este estado a Netplan (por ejemplo, mkdir -p /tmp/netplan_state_backup/etc && cp -r /etc/netplan /tmp/netplan_state_backup/etc/ y luego ejecutando netplan apply --state /tmp/netplan_state_backup).

VER TAMBIÉN

netplan(5), netplan-generate(8), netplan-try(8), udev(7), systemd-networkd.service(8), NetworkManager(8)
