NOMBRE

ne_status - estructura de estado HTTP

SINOPSIS

#include <ne_utils.h>
typedef struct {
    int major_version;
    int minor_version;
    int code;
    int klass;
    char *reason_phrase;
} ne_status;

DESCRIPCIÓN

El tipo ne_status representa el estado de una respuesta HTTP; se utiliza en los mensajes de respuesta que dan un resultado de la solicitud. Los campos major_version y minor_version indican la versión del protocolo compatible con el servidor que emite la respuesta. El campo code indica el código de estado del resultado (entre 100 y 599 inclusive), y el campo klass indica la clase, que es igual al dígito más significativo del estado. El campo reason_phrase proporciona una cadena de texto legible por humanos que describe el estado, la cual es puramente informativa (y opcional); cualquier interpretación del estado de la respuesta debe hacerse utilizando los campos klass y/o code.

Hay cinco clases de códigos de estado de respuesta definidos para HTTP/1.1 (ver RFC 9110 ẞ15[1]):

1xx

Respuesta informativa.

2xx

Éxito: la operación se realizó correctamente.

3xx

Redirección.

4xx

Error del cliente: la solicitud realizada fue incorrecta de alguna manera.

5xx

Error del servidor.

NOTAS

El campo klass se llama “klass” y no “class” para que la cabecera pueda ser utilizada desde un programa C++, en el cual “class” es una palabra reservada.
