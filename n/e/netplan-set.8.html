NOMBRE

netplan-set - escribe fragmentos de configuración YAML de Netplan en un archivo

SINOPSIS

netplan [--debug] set -h|--help

netplan [--debug] set [--root-dir=ROOT_DIR] [--origin-hint=ORIGIN_HINT] [clave=valor]

DESCRIPCIÓN

netplan set [clave=valor] escribe un par clave/valor dado o un subárbol YAML en un archivo YAML en /etc/netplan/ y valida su formato.

Puedes especificar un valor único como: "[network.]ethernets.eth0.addresses=[1.2.3.4/24, 5.6.7.8/24]" o un subárbol completo como: "[network.]ethernets.eth0={dhcp4: true, dhcp6: true}".

Para detalles sobre el formato del archivo de configuración, consulta netplan(5).

OPCIONES

-h, --help
Imprime ayuda básica.
--debug
Imprime salida de depuración durante el proceso.
--root-dir
Escribe los archivos YAML en esta raíz en lugar de /.
--origin-hint
Especifica un nombre para el archivo de configuración, p. ej.: 70-netplan-set => /etc/netplan/70-netplan-set.yaml.

VER TAMBIÉN

netplan(5), netplan-get(8), netplan-dbus(8)
