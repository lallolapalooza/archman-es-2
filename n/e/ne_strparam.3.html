NOMBRE

ne_strparam - codificación de valor de parámetro extendido HTTP

SINOPSIS

#include <ne_string.h>

char *ne_strparam(const char *charset, const char *lang, const char *value);

DESCRIPCIÓN

La función ne_strparam se puede utilizar para codificar un valor de parámetro extendido para una cabecera HTTP, según se define en RFC 5987. La función toma como argumentos el valor a codificar, utilizando un juego de caracteres MIME charset dado, y una etiqueta de idioma lang. La codificación de parámetro extendido se utiliza en las especificaciones del protocolo HTTP para permitir la incrustación sencilla de caracteres especiales (como comillas, separadores o caracteres no ASCII) en los valores de las cabeceras.

De acuerdo con RFC 5987, el argumento charset debe ser "UTF-8" o "IS0-8859-1", pero el argumento lang puede ser NULL.

VALOR DE RETORNO

El valor de retorno es uno de los siguientes:

NULL

si el parámetro value es un "parámetro regular" y no necesita codificación extendida

no NULL

la codificación del valor de entrada como parámetro extendido como una cadena asignada por malloc y terminada en NUL

HISTORIA

ne_strparam está disponible en neon 0.32.0 y versiones posteriores.

VER TAMBIÉN
