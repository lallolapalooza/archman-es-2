ne_addr_error(3)

Paquete: neon

Licencias: LGPL-2.0-or-later

NE_ADDR_RESOLVE(3) Referencia de la API de neon NE_ADDR_RESOLVE(3)

NOMBRE

ne_addr_resolve, ne_addr_result, ne_addr_first, ne_addr_next, ne_addr_error, ne_addr_canonical, ne_addr_destroy - funciones para resolver nombres de host a direcciones

SINOPSIS

#include <ne_socket.h>

ne_sock_addr *ne_addr_resolve(const char *hostname, int flags);

int ne_addr_result(const ne_sock_addr *addr);

const ne_inet_addr *ne_addr_first(ne_sock_addr *addr);

const ne_inet_addr *ne_addr_next(ne_sock_addr *addr);

char *ne_addr_error(const ne_sock_addr *addr, char *buffer, size_t bufsiz);

const char *ne_addr_canonical(const ne_sock_addr *addr);

void ne_addr_destroy(ne_sock_addr *addr);

DESCRIPCIÓN

La función ne_addr_resolve resuelve el hostname proporcionado, devolviendo un objeto ne_sock_addr que representa la dirección (o direcciones) asociada con el nombre de host. El parámetro flags debe ser cero, o si se usa NE_ADDR_CANON, se determinará el nombre canónico para el nombre de host.

El hostname pasado a ne_addr_resolve puede ser un nombre de host DNS (por ejemplo, "www.example.com") o un quad cuádruple IPv4 (por ejemplo, "192.0.34.72"); o, en sistemas que soportan IPv6, una dirección hexadecimal IPv6, que puede estar entre corchetes, por ejemplo, "[::1]".

Para determinar si el nombre de host se resolvió con éxito, se utiliza la función ne_addr_result, que devuelve un valor distinto de cero si ocurrió un error. Si ocurrió un error, la función ne_addr_error puede ser utilizada, la cual copiará la cadena de error en un buffer dado (de tamaño bufsiz).

Las funciones ne_addr_first y ne_addr_next se usan para recuperar las direcciones de Internet asociadas con un objeto de dirección que ha sido resuelto con éxito. ne_addr_first devuelve la primera dirección; ne_addr_next devuelve la siguiente dirección después de la llamada más reciente a ne_addr_next o ne_addr_first, o NULL si no hay más direcciones. El puntero ne_inet_addr devuelto por estas funciones puede ser pasado a ne_sock_connect para conectar un socket.

Si se usó la bandera NE_ADDR_CANON con ne_addr_resolve, el nombre de host canónico se puede recuperar usando ne_addr_canonical.

Después de que el objeto de dirección haya sido utilizado, debe ser destruido usando ne_addr_destroy.

VALOR DE RETORNO

ne_addr_resolve devuelve un puntero a un objeto de dirección, y nunca NULL. ne_addr_error devuelve el parámetro buffer.

EJEMPLOS

El siguiente código imprime el conjunto de direcciones asociadas con el nombre de host www.google.com.

ne_sock_addr *addr;
char buf[256];
addr = ne_addr_resolve("www.google.com", 0);
if (ne_addr_result(addr)) {
    printf("No se pudo resolver www.google.com: %s\n",
           ne_addr_error(addr, buf, sizeof buf));
} else {
    const ne_inet_addr *ia;
    printf("www.google.com:");
    for (ia = ne_addr_first(addr); ia != NULL; ia = ne_addr_next(addr)) {
        printf(" %s", ne_iaddr_print(ia, buf, sizeof buf));
    }
    putchar('\n');
}
ne_addr_destroy(addr);
