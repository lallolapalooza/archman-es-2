netdb.h(0p) Manual del Programador POSIX netdb.h(0p)

PROLOGO

Esta página del manual forma parte del Manual del Programador POSIX. La implementación de Linux de esta interfaz puede diferir (consulte la página del manual de Linux correspondiente para conocer los detalles del comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

netdb.h — definiciones para operaciones de base de datos de red

SINOPSIS

#include <netdb.h>

DESCRIPCION

La cabecera <netdb.h> puede definir el tipo in_port_t y el tipo in_addr_t como se describe en <netinet/in.h>.

La cabecera <netdb.h> definirá la estructura hostent, que incluirá al menos los siguientes miembros:

char   *h_name       Nombre oficial del host.
char  **h_aliases    Un puntero a un array de punteros a
                     nombres de host alternativos, terminados por un
                     puntero nulo.
int     h_addrtype   Tipo de dirección.
int     h_length     La longitud, en bytes, de la dirección.
char  **h_addr_list  Un puntero a un array de punteros a direcciones de red
                     (en orden de bytes de red) para el host,
                     terminado por un puntero nulo.

La cabecera <netdb.h> definirá la estructura netent, que incluirá al menos los siguientes miembros:

char     *n_name      Nombre oficial y completo (incluido el
                      dominio) del host.
char    **n_aliases   Un puntero a un array de punteros a
                      nombres de red alternativos, terminados por un
                      puntero nulo.
int       n_addrtype  El tipo de dirección de la red.
uint32_t  n_net       El número de red, en orden de bytes del host.

La cabecera <netdb.h> definirá el tipo uint32_t como se describe en <inttypes.h>.

La cabecera <netdb.h> definirá la estructura protoent, que incluirá al menos los siguientes miembros:

char   *p_name     Nombre oficial del protocolo.
char  **p_aliases  Un puntero a un array de punteros a
                   nombres de protocolo alternativos, terminados por
                   un puntero nulo.
int     p_proto    El número de protocolo.

La cabecera <netdb.h> definirá la estructura servent, que incluirá al menos los siguientes miembros:

char   *s_name     Nombre oficial del servicio.
char  **s_aliases  Un puntero a un array de punteros a
                   nombres de servicio alternativos, terminados por
                   un puntero nulo.
int     s_port     Un valor que, al convertirse a uint16_t,
                   produce el número de puerto en orden de bytes de red
                   en el que reside el servicio.
char   *s_proto    El nombre del protocolo a utilizar al
                   contactar el servicio.

La cabecera <netdb.h> definirá la constante simbólica IPPORT_RESERVED con el valor del número de puerto de Internet reservado más alto.

Estructura de información de dirección

La cabecera <netdb.h> definirá la estructura addrinfo, que incluirá al menos los siguientes miembros:

int               ai_flags      Banderas de entrada.
int               ai_family     Familia de direcciones del socket.
int               ai_socktype   Tipo de socket.
int               ai_protocol   Protocolo del socket.
socklen_t         ai_addrlen    Longitud de la dirección del socket.
struct sockaddr  *ai_addr       Dirección del socket del socket.
char             *ai_canonname  Nombre canónico de la ubicación del servicio.
struct addrinfo  *ai_next       Puntero al siguiente en la lista.

La cabecera <netdb.h> definirá las siguientes constantes simbólicas que se evalúan a constantes enteras de bits distintos para su uso en el campo flags de la estructura addrinfo:

AI_PASSIVE
La dirección del socket está destinada a bind().
AI_CANONNAME
Solicitud de nombre canónico.
AI_NUMERICHOST
Devolver la dirección numérica del host como nombre.
AI_NUMERICSERV
Inhibir la resolución del nombre del servicio.
AI_V4MAPPED
Si no se encuentran direcciones IPv6, consultar direcciones IPv4 y devolverlas al llamador como direcciones IPv6 mapeadas a IPv4.
AI_ALL
Consultar tanto direcciones IPv4 como IPv6.
AI_ADDRCONFIG
Consultar solo direcciones IPv4 cuando hay configurada una dirección IPv4; consultar solo direcciones IPv6 cuando hay configurada una dirección IPv6.

La cabecera <netdb.h> definirá las siguientes constantes simbólicas que se evalúan a constantes enteras de bits distintos para su uso en el argumento flags de getnameinfo():

NI_NOFQDN
Solo se devuelve la porción del nombre de nodo del FQDN para hosts locales.
NI_NUMERICHOST
Se devuelve la forma numérica de la dirección del nodo en lugar de su nombre.
NI_NAMEREQD
Devolver un error si no se puede localizar el nombre del nodo en la base de datos.
NI_NUMERICSERV
Se devuelve la forma numérica de la dirección del servicio en lugar de su nombre.
NI_NUMERICSCOPE

Para direcciones IPv6, se devuelve la forma numérica del identificador de ámbito en lugar de su nombre.
NI_DGRAM
Indica que el servicio es un servicio de datagramas (SOCK_DGRAM).

Errores de información de dirección

La cabecera <netdb.h> definirá las siguientes constantes simbólicas para su uso como valores de error para getaddrinfo() y getnameinfo(). Los valores serán adecuados para su uso en directivas de preprocesamiento #if.

EAI_AGAIN
El nombre no pudo ser resuelto en este momento. Intentos futuros pueden tener éxito.
EAI_BADFLAGS
Las banderas tenían un valor inválido.
EAI_FAIL
Ocurrió un error no recuperable.
EAI_FAMILY
La familia de direcciones no fue reconocida o la longitud de la dirección fue inválida para la familia especificada.
EAI_MEMORY
Hubo un fallo de asignación de memoria.
EAI_NONAME
El nombre no se resuelve para los parámetros proporcionados.

Se establece NI_NAMEREQD y no se puede localizar el nombre del host, o tanto nodename como servname eran nulos.

EAI_SERVICE
El servicio proporcionado no fue reconocido para el tipo de socket especificado.
EAI_SOCKTYPE
El tipo de socket pretendido no fue reconocido.
EAI_SYSTEM
Ocurrió un error del sistema. El código de error se puede encontrar en errno.
EAI_OVERFLOW
Un búfer de argumento se desbordó.

Las siguientes se declararán como funciones y también pueden definirse como macros. Se proporcionarán prototipos de función.

void              endhostent(void);
void              endnetent(void);
void              endprotoent(void);
void              endservent(void);
void              freeaddrinfo(struct addrinfo *);
const char       *gai_strerror(int);
int               getaddrinfo(const char *restrict, const char *restrict,
                      const struct addrinfo *restrict,
                      struct addrinfo **res

PROLOG

Este documento describe las funciones de la biblioteca de red proporcionadas por POSIX.

NOMBRE

netdb.h - definiciones de la biblioteca de red

SINOPSIS

#include <netdb.h>

DESCRIPCIÓN

El archivo de cabecera <netdb.h> define varias estructuras y funciones para la manipulación de bases de datos de red, incluyendo información sobre hosts, redes, protocolos y servicios.

Las siguientes funciones están disponibles:

     struct hostent    *gethostbyaddr(const void *, socklen_t, int);
     struct hostent    *gethostbyname(const char *);
     struct hostent    *gethostent(void);
     int                getnameinfo(const struct sockaddr *restrict, socklen_t,
                           char *restrict, socklen_t, char *restrict,
                           socklen_t, int);
     struct netent     *getnetbyaddr(uint32_t, int);
     struct netent     *getnetbyname(const char *);
     struct netent     *getnetent(void);
     struct protoent   *getprotobyname(const char *);
     struct protoent   *getprotobynumber(int);
     struct protoent   *getprotoent(void);
     struct servent    *getservbyname(const char *, const char *);
     struct servent    *getservbyport(int, const char *);
     struct servent    *getservent(void);
     void               sethostent(int);
     void               setnetent(int);
     void               setprotoent(int);
     void               setservent(int);

La inclusión del archivo de cabecera <netdb.h> también puede hacer visibles todos los símbolos de <netinet/in.h>, <sys/socket.h> y <inttypes.h>.
