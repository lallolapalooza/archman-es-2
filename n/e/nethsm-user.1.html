NOMBRE

nethsm-user - Operar sobre usuarios de un dispositivo

SINOPSIS

nethsm user [-a|--auth-passphrase-file] [-c|--config] [-l|--label] [-u|--user] [-h|--help] <subcomandos>

DESCRIPCIÓN

Operar sobre usuarios de un dispositivo

Permite añadir y eliminar usuarios, obtener información sobre ellos, establecer sus contraseñas y establecer o anular etiquetas para ellos.

Los usuarios pueden existir en ámbitos específicos: a nivel de sistema o en espacios de nombres (ver "nethsm namespace"). El uso de un espacio de nombres se indica mediante un prefijo en el nombre de usuario (por ejemplo, el nombre de usuario "namespace1~user1" indica que el usuario está en "namespace1"). Los usuarios en un espacio de nombres solo pueden ser administrados por usuarios en el rol de "Administrador" en ese mismo espacio de nombres. Los usuarios a nivel de sistema solo pueden ser administrados por usuarios a nivel de sistema en el rol de "Administrador".

OPCIONES

-a, --auth-passphrase-file <ARCHIVO_CONTRASENA_AUTENTICACION>
La ruta a un archivo que contiene una contraseña para la autenticación

La contraseña proporcionada en el archivo debe ser la del usuario elegido para el comando.

Esta opción puede proporcionarse varias veces, lo cual es necesario para comandos que requieren varios roles a la vez. Con varios archivos de contraseñas, el orden importa, ya que los archivos se asignan al usuario respectivo proporcionado por la opción "--user".

También se puede especificar con la variable de entorno NETHSM_AUTH_PASSPHRASE_FILE.
-c, --config <CONFIG>
La ruta a un archivo de configuración personalizado

Si se especifica, se utiliza el archivo de configuración personalizado en lugar de la ubicación predeterminada del archivo de configuración.

También se puede especificar con la variable de entorno NETHSM_CONFIG.
-l, --label <ETIQUETA>
Una etiqueta que identifica de forma única un dispositivo en el archivo de configuración

Debe proporcionarse si hay más de un dispositivo configurado en el archivo de configuración.

También se puede especificar con la variable de entorno NETHSM_LABEL.
-u, --user <USUARIO>
Un nombre de usuario que se utiliza para un comando

Puede proporcionarse si no hay ningún nombre de usuario configurado en el archivo de configuración para un dispositivo. Debe proporcionarse si hay varios nombres de usuario del mismo rol de destino configurados en el archivo de configuración para un dispositivo.

Esta opción puede proporcionarse varias veces, lo cual es necesario para comandos que requieren varios roles a la vez.

También se puede especificar con la variable de entorno NETHSM_USER.
-h, --help
Imprimir ayuda (ver un resumen con '-h')
