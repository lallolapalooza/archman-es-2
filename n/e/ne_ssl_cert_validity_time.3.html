ne_ssl_cert_validity_time(3)

Paquete: neon

Licencias: LGPL-2.0-or-later

NE_SSL_CERT_CMP(3) Referencia de la API de neon NE_SSL_CERT_CMP(3)

NOMBRE

ne_ssl_cert_cmp, ne_ssl_cert_free, ne_ssl_cert_digest, ne_ssl_cert_hdigest, ne_ssl_cert_validity, ne_ssl_cert_validity_time - funciones para operar sobre objetos de certificado

SINOPSIS

#include <ne_header.h>

int ne_ssl_cert_cmp(const ne_ssl_certificate *c1, const ne_ssl_certificate *c2);

void ne_ssl_cert_free(ne_ssl_certificate *cert);

int ne_ssl_cert_digest(const ne_ssl_certificate *c1, char *digest);

char *ne_ssl_cert_hdigest(const ne_ssl_certificate *c1, unsigned int flags);

void ne_ssl_cert_validity_time(const ne_ssl_certificate *cert, time_t *from, time_t *until);

void ne_ssl_cert_validity(const ne_ssl_certificate *cert, char *from, char *until);

DESCRIPCIÓN

La función ne_ssl_cert_cmp se puede utilizar para comparar dos objetos de certificado; devuelve cero si se refieren al mismo certificado y un valor distinto de cero en caso contrario.

La función ne_ssl_cert_free se puede utilizar para destruir un objeto de certificado cuando ya no es necesario.

La función ne_ssl_cert_digest escribe una huella digital legible por humanos como una cadena terminada en NUL en el búfer digest proporcionado, con el formato "aa:bb...:ff". El búfer digest debe tener al menos NE_SSL_DIGESTLEN bytes de longitud.

La función ne_ssl_cert_hdigest devuelve una huella digital legible por humanos para el objeto de certificado. El parámetro flags especifica las opciones de formato hash como si se pasaran a ne_strhash. La cadena devuelta está asignada con malloc y debe liberarse después de su uso.

La función ne_ssl_cert_validity_time recupera tanto el tiempo desde el cual el certificado es válido como hasta cuándo. Cada tiempo se devuelve a través de los parámetros from y until, que se escriben como (time_t)-1 si alguno de los tiempos no se puede representar como un valor time_t. La función ne_ssl_cert_validity escribe de manera similar los tiempos de validez en los búferes de cadena proporcionados, utilizando el formato de fecha estilo RFC 1123 (no localizado). Los parámetros de salida deben tener al menos NE_SSL_VDATELEN bytes de longitud. Cualquiera de los parámetros se puede pasar como NULL.

VALOR DE RETORNO

ne_ssl_cert_cmp devuelve 0 si los certificados son los mismos, y un valor distinto de cero en caso contrario. ne_ssl_cert_digest devuelve 0 si tiene éxito o un valor distinto de cero si hay un error. El valor de retorno de ne_ssl_cert_hdigest es una cadena asignada con malloc terminada en NUL, o NULL si no se puede crear el hash.

HISTORIA

ne_ssl_cert_hdigest está disponible en neon 0.32.0 y posteriores.
