ne_buffer_finish(3)

Paquete: neon

Licencias: LGPL-2.0-or-later

NE_BUFFER_DESTROY(3) Referencia de la API de neon NE_BUFFER_DESTROY(3)

NOMBRE

ne_buffer_destroy, ne_buffer_finish - destruir un objeto buffer

SINOPSIS

#include <ne_string.h>

void ne_buffer_destroy(ne_buffer *buf);

char *ne_buffer_finish(ne_buffer *buf);

DESCRIPCIÓN

ne_buffer_destroy libera toda la memoria asociada con el buffer. ne_buffer_finish libera la estructura del buffer, pero no la cadena real almacenada en el buffer, la cual se devuelve y debe ser liberada con free() por el llamante.

Cualquier uso del objeto buffer después de llamar a cualquiera de estas funciones produce un comportamiento indefinido.

VALOR DE RETORNO

ne_buffer_finish devuelve la cadena almacenada en el buffer, que fue asignada con malloc.

EJEMPLOS

Un ejemplo de uso de ne_buffer_finish; la función duplicate devuelve una cadena compuesta por n copias de str:

static char *duplicate(int n, const char *str)
{
  ne_buffer *buf = ne_buffer_create();
  while (n--) {
    ne_buffer_zappend(buf, str);
  }
  return ne_buffer_finish(buf);
}

VER TAMBIÉN

ne_buffer, ne_buffer_create, ne_buffer_zappend
