ne_buffer_concat(3)

Paquete: neon

Licencias: LGPL-2.0-or-later

NE_BUFFER_APPEND(3) Referencia de la API de neon NE_BUFFER_APPEND(3)

NOMBRE

ne_buffer_append, ne_buffer_zappend, ne_buffer_qappend, ne_buffer_concat, ne_buffer_snprintf - añadir datos a un búfer de cadena

SINOPSIS

#include <ne_string.h>

void ne_buffer_append(ne_buffer *buf, const char *string, size_t len);

void ne_buffer_zappend(ne_buffer *buf, const char *string);

void ne_buffer_qappend(ne_buffer *buf, const char *string, size_t len);

void ne_buffer_concat(ne_buffer *buf, ...);

size_t ne_buffer_snprintf(ne_buffer *buf, size_t max, const char *format, ...);

DESCRIPCIÓN

Las funciones ne_buffer_append y ne_buffer_zappend añaden una cadena al final de un búfer; extendiendo el búfer según sea necesario. El len pasado a ne_buffer_append especifica la longitud de la cadena a añadir; no debe haber un terminador NUL en los primeros len bytes de la cadena. A ne_buffer_zappend se le debe pasar una cadena terminada en NUL.

La función ne_buffer_qappend se comporta de manera similar a ne_buffer_append, excepto que los caracteres no ASCII o los caracteres de control ASCII se escapan usando escapado hexadecimal estilo C. Por ejemplo, la cadena C "foo<TAB>bar", donde TAB representa el carácter ASCII 9, se añadiría como "foo\x09bar". Los bytes NUL dentro de la longitud especificada también se escapan. Esta función es útil para hacer que las cadenas de fuentes no confiables sean seguras para el registro o la salida en una interfaz de usuario.

La función ne_buffer_concat toma una lista de argumentos de longitud variable; cada argumento debe ser un puntero char * a una cadena terminada en NUL. Se debe proporcionar un puntero NULL como último argumento para marcar el final de la lista. Las cadenas se añaden al búfer en el orden dado. Ninguna de las cadenas pasadas a ne_buffer_concat se modifica.

La función ne_buffer_snprintf se comporta como snprintf, añadiendo la cadena de salida formateada según el parámetro format. Se escriben como máximo max bytes, incluido el terminador NUL final.

VALOR DE RETORNO

La función ne_buffer_snprintf devuelve el número de bytes añadidos *excluyendo* el terminador NUL final.

EJEMPLOS

El siguiente código imprimirá "Hello, world. And goodbye.".

ne_buffer *buf = ne_buffer_create();
ne_buffer_zappend(buf, "Hello");
ne_buffer_concat(buf, ", world. ", "And ", NULL);
ne_buffer_snprintf(buf, 10, "%s.", "goodbye");
puts(buf->data);
ne_buffer_destroy(buf);

VER TAMBIÉN
