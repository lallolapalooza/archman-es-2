NOMBRE

netplan-get - leer la configuración YAML combinada de Netplan

SINOPSIS

netplan [--debug] get -h|--help

netplan [--debug] get [--root-dir=ROOT_DIR] [key]

DESCRIPCIÓN

netplan get key lee todos los archivos YAML de /{etc,lib,run}/netplan/*.yaml y devuelve una vista combinada de la configuración actual.

Puedes especificar all como clave (la predeterminada) para obtener el árbol YAML completo o extraer un subárbol especificando una clave anidada como: [network.]ethernets.eth0.

Para detalles del formato del archivo de configuración, consulta netplan(5).

OPCIONES

-h, --help
Imprime ayuda básica.
--debug
Imprime salida de depuración durante el proceso.
--root-dir
Lee los archivos YAML desde esta raíz en lugar de /.

VER TAMBIÉN

netplan(5), netplan-set(8), netplan-dbus(8)
