ef_expand_file(3) Manual de funciones de la biblioteca ef_expand_file(3)

NOMBRE

ef_expand_file, del_ExpandFile, ef_last_error, ef_list_expansions, new_ExpandFile - expandir nombres de archivo que contienen ~usuario/$entorno y expresiones comodín

SINOPSIS

#include <libtecla.h>
ExpandFile *new_ExpandFile(void);
ExpandFile *del_ExpandFile(ExpandFile *ef);
FileExpansion *ef_expand_file(ExpandFile *ef,
                              const char *path,
                              int pathlen);
int ef_list_expansions(FileExpansion *result, FILE *fp,
                       int term_width);
const char *ef_last_error(ExpandFile *ef);

DESCRIPCIÓN

La función ef_expand_file() es parte de la biblioteca tecla (ver la página del manual libtecla(3)). Expande un nombre de archivo especificado, convirtiendo las expresiones ~usuario/ y ~/ al principio del nombre de archivo a los directorios de inicio correspondientes, reemplazando $variabledeentorno con el valor de la variable de entorno correspondiente, y luego, si hay comodines, haciendo coincidir estos con los nombres de archivo existentes. Las barras invertidas en el nombre de archivo de entrada se interpretan como un escape de cualquier significado especial de los caracteres que les siguen. Solo las barras invertidas que están precedidas por barras invertidas se conservan en el nombre de archivo expandido.

En presencia de comodines, la lista devuelta de nombres de archivo solo incluye los nombres de los archivos existentes que coinciden con los comodines. De lo contrario, se devuelve el nombre de archivo original después de la expansión de las expresiones tilde y dólar, y el resultado no se comprueba con los archivos existentes. Esto imita el comportamiento de globbing de archivos del shell tcsh de Unix.

Los comodines admitidos y sus significados son:

  *        -  Coincide con cualquier secuencia de cero o más caracteres.
  ?        -  Coincide con cualquier carácter individual.
  [chars]  -  Coincide con cualquier carácter individual que aparezca en
              'chars'. Si 'chars' contiene una expresión de la forma a-b,
              entonces cualquier carácter entre a y b, incluyendo a y b,
              coincide. El carácter '-' pierde su significado especial
              como especificador de rango cuando aparece al principio de
              la secuencia de caracteres. El carácter ']' también pierde
              su significado como terminador de la expresión de rango si
              aparece inmediatamente después de '[' de apertura, momento
              en el que se trata como uno de los caracteres del rango. Si
              desea que tanto '-' como ']' formen parte del rango, el '-'
              debería ir primero y el ']' segundo.
  [^chars] -  Lo mismo que [chars] excepto que coincide con cualquier
              carácter individual que no aparezca en 'chars'.

Tenga en cuenta que los comodines nunca coinciden con el punto inicial en los nombres de archivo que comienzan con '.'. El punto inicial debe especificarse explícitamente en el nombre de archivo. Esto imita nuevamente el comportamiento de globbing de la mayoría de los shells de Unix, y su lógica se basa en el hecho de que en Unix, los archivos con nombres que comienzan con '.' suelen ser archivos de configuración ocultos, que no son listados por defecto por el comando ls.

El siguiente es un ejemplo completo de cómo usar la función de expansión de archivos.

  #include <stdio.h>
  #include <libtecla.h>
  int main(int argc, char *argv[])
  {
    ExpandFile *ef;      /* El objeto de recursos de expansión */
    char *filename;      /* El nombre de archivo que se está expandiendo */
    FileExpansion *expn; /* Los resultados de la expansión */
    int i;
    ef = new_ExpandFile();
    if(!ef)
      return 1;
    for(arg = *(argv++); arg; arg = *(argv++)) {
      if((expn = ef_expand_file(ef, arg, -1)) == NULL) {
        fprintf(stderr, "Error expandiendo %s (%s).\n", arg,
                         ef_last_error(ef));
      } else {
        printf("%s coincide con los siguientes archivos:\n", arg);
        for(i=0; i<expn->nfile; i++)
          printf(" %s\n", expn->files[i]);
      }
    }
    ef = del_ExpandFile(ef);
    return 0;
  }

Se proporcionan descripciones de las funciones utilizadas anteriormente:

  ExpandFile *new_ExpandFile(void)

Esta función crea los recursos utilizados por la función ef_expand_file(). En particular, mantiene la memoria que se utiliza para registrar la matriz de nombres de archivo coincidentes que se devuelve por ef_expand_file(). Esta matriz se expande según sea necesario, por lo que no hay un límite incorporado en el número de archivos que se pueden hacer coincidir.

  ExpandFile *del_ExpandFile(ExpandFile *ef)

Esta función elimina los recursos que fueron devueltos por una llamada previa a new_ExpandFile(). Siempre devuelve NULL (es decir, un objeto eliminado). No hace nada si el argumento ef es NULL.

Un contenedor del siguiente tipo es devuelto por ef_expand_file().

  typedef struct {
    int exists;   /* Verdadero si los archivos en files[] existen */
    int nfile;    /* El número de archivos en files[] */
    char **files; /* Una matriz de 'nfile' nombres de archivo. */
  } FileExpansion;
  FileExpansion *ef_expand_file(ExpandFile *ef,
                                const char *path,
                                int pathlen)

La función ef_expand_file() realiza la expansión de nombres de archivo, como se documenta al principio de esta sección. Su primer argumento es un objeto de recursos devuelto por new_ExpandFile(). Se pasa un puntero al inicio del nombre de archivo que se va a hacer coincidir a través del argumento path. Debe ser una cadena normal terminada en NUL, pero a menos que se pase una longitud de -1 en pathlen, solo se utilizarán los primeros pathlen caracteres en la expansión del nombre de archivo. Si la longitud se especifica como -1, se expandirá toda la cadena.

La función devuelve un puntero a un contenedor cuyos contenidos son los resultados de la expansión. Si no hubo comodines en el nombre de archivo, el miembro nfile será 1, y el miembro exists debe consultarse si es importante saber si el archivo expandido existe actualmente o no. Si hubo comodines, entonces la matriz contenida files[] contendrá los nombres de los nfile archivos existentes que coincidieron con el nombre de archivo con comodines, y el miembro exists tendrá el valor 1. Tenga en cuenta que el contenedor devuelto pertenece al objeto ef especificado, y su contenido cambiará en cada llamada, por lo que si necesita conservar los resultados de más de una llamada a ef_expand_file(), debería hacer una copia privada de los resultados devueltos o crear múltiples objetos de expansión de archivos a través de múltiples llamadas a new_ExpandFile().

En caso de error, se devuelve NULL, y una explicación del error se puede determinar llamando a ef_last_error(ef).

  const char *ef_last_error(ExpandFile *ef)

Esta función devuelve el mensaje que describe el error que ocurrió en la última llamada a ef_expand_file(), para el objeto de recursos dado (ExpandFile *ef).

  int ef_list_expansions(FileExpansion *result, FILE *fp,
                         int terminal_width);

La función ef_list_expansions() proporciona una forma conveniente de listar las expansiones de nombres de archivo devueltas por ef_expand_file(). Al igual que el comando ls de Unix, organiza los nombres de archivo en columnas de ancho igual, cada columna teniendo el ancho del archivo más grande. El número de columnas utilizadas está determinado así por la longitud del nombre de archivo más largo y el ancho de terminal especificado. Tenga cuidado, ya que los nombres de archivo que son más largos que el ancho de terminal especificado se imprimen sin ser truncados, por lo que puede ocurrir una salida más larga que el ancho de terminal especificado. La lista se escribe en el flujo stdio especificado por el argumento fp.

SEGURIDAD DE HILOS

En programas multihilo, debe utilizar la versión libtecla_r.a de la biblioteca. Esta utiliza funciones reentrantes POSIX donde estén disponibles (de ahí el sufijo _r), y deshabilita las características que dependen de funciones del sistema no reentrantes. Actualmente no hay características deshabilitadas en este módulo.

Utilizando la versión libtecla_r.a de la biblioteca, es seguro utilizar las facilidades de este módulo en múltiples hilos, siempre que cada hilo utilice un objeto ExpandFile asignado por separado. En otras palabras, si dos hilos quieren hacer expansión de archivos, cada uno debería llamar a new_ExpandFile() para asignar sus propios objetos de expansión de archivos.
