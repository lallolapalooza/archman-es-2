NEON-CONFIG(1) Referencia de la API de neon NEON-CONFIG(1)

NOMBRE

neon-config - script que proporciona información sobre la copia instalada de la biblioteca neon

SINOPSIS

neon-config [--prefix] [[--cflags] | [--libs] | [--la-file] | [--support feature] | [--help] | [--version]]

DESCRIPCIÓN

El script neon-config proporciona información sobre una copia instalada de la biblioteca neon. Las opciones --cflags y --libs indican cómo compilar y enlazar una aplicación contra la biblioteca; las opciones --version y --support pueden ayudar a determinar si la biblioteca cumple con los requisitos de la aplicación.

OPCIONES

--cflags

Imprime las banderas que deben pasarse al compilador C al compilar archivos objeto, cuando los archivos objeto utilizan archivos de encabezado de neon.

--libs

Imprime las banderas que deben pasarse al enlazador al enlazar una aplicación que utiliza la biblioteca neon.

--la-file

Imprime la ubicación del script de biblioteca libtool, libneon.la, que puede usarse para enlazar contra neon por aplicaciones que usan libtool.

--version

Imprime la versión de la biblioteca.

--prefix dir

Si se da dir; reubica la salida de --cflags y --libs como si neon se hubiera instalado en el directorio prefijo dado. De lo contrario, imprime el prefijo de instalación de la biblioteca.

--support feature

El script finaliza con éxito si la característica es compatible con la biblioteca.

--help

Imprime el mensaje de ayuda; incluye una lista de características conocidas y si son compatibles o no.

EJEMPLO

A continuación se muestra un fragmento de Makefile que podría usarse para compilar una aplicación contra una biblioteca neon instalada, cuando el script neon-config se puede encontrar en $PATH.

CFLAGS = `neon-config --cflags`
LIBS = `neon-config --libs`
OBJECTS = myapp.o
TARGET = myapp
$(TARGET): $(OBJECTS)
	$(CC) $(LDFLAGS) -o $(TARGET) $(OBJECTS) $(LIBS)
myapp.o: myapp.c
	$(CC) $(CFLAGS) -c myapp.c -o myapp.o
