NOMBRE

netkey-tool - utilidad administrativa para tarjetas Netkey E4

SINOPSIS

netkey-tool [OPCIONES] [COMANDO]

DESCRIPCIÓN

La utilidad netkey-tool se puede usar desde la línea de comandos para realizar algunas operaciones con tarjetas inteligentes de tarjetas NetKey E4 que no se pueden realizar fácilmente con otras herramientas de OpenSC, como cambiar PIN locales, almacenar certificados en archivos de certificados NetKey E4 vacíos o mostrar el valor inicial del PUK.

OPCIONES

--help, -h

Muestra un breve mensaje de ayuda.

--pin pin, -p pin

Especifica el valor actual del PIN global.

--puk pin, -u pin

Especifica el valor actual del PUK global.

--pin0 pin, -0 pin

Especifica el valor actual del PIN local0 (también conocido como PIN local).

--pin1 pin, -1 pin

Especifica el valor actual del PIN local1 (también conocido como PUK local).

--reader arg, -r arg

Número del lector a utilizar. Por defecto, se utiliza el primer lector con una tarjeta presente. Si arg es un ATR, se elegirá el lector con una tarjeta coincidente.

-v

Hace que netkey-tool sea más detallado. Esta opción se puede especificar varias veces para aumentar la verbosidad.

FORMATO DEL PIN

Con -p, -u, -0 o -1 se puede especificar uno de los PIN de las tarjetas. Puede usar cadenas de texto ASCII simples (por ejemplo, 123456) o una cadena hexadecimal (por ejemplo, 31:32:33:34:35:36). Una cadena hexadecimal debe consistir exactamente en n números hexadecimales de 2 dígitos separados por n-1 dos puntos. De lo contrario, se interpretará como una cadena ASCII. Por ejemplo: :12:34: y 1:2:3:4 son ambos PIN de longitud 7, mientras que 12:34 y 01:02:03:04 son PIN de longitud 2 y 4.

COMANDOS

Cuando se usa sin opciones ni comandos, netkey-tool mostrará información sobre los PIN y certificados de las tarjetas inteligentes. Esto no cambiará su tarjeta en ningún aspecto (suponiendo que no haya errores en netkey-tool). En particular, se investigan los contadores de intentos restantes de los PIN sin realizar verificaciones de PIN reales.

Si especifica el PIN global a través de la opción --pin, netkey-tool también mostrará el valor inicial del PUK global de la tarjeta. Si se cambió su PUK global, netkey-tool seguirá mostrando su valor inicial. No hay forma de recuperar un PUK global perdido una vez que se ha cambiado. Tampoco hay forma de mostrar el valor inicial de su PUK global sin conocer el valor actual de su PIN global.

Para la mayoría de los comandos que netkey-tool puede ejecutar, debe especificar un PIN. Una excepción notable es el comando nullpin, pero este comando solo se puede ejecutar una vez en la vida útil de una tarjeta NetKey E4.

cert número nombre_archivo

Este comando leerá uno de los certificados de su tarjeta (según lo especificado por número) y guardará este certificado en el archivo nombre_archivo en formato PEM. Los certificados de una tarjeta NetKey E4 se pueden leer sin PIN, por lo que no necesita especificar uno.

cert nombre_archivo número

Este comando leerá el primer certificado codificado en PEM del archivo nombre_archivo y lo almacenará en el archivo de certificado de su tarjeta inteligente número. Es posible que algunos de los archivos de certificado de su tarjeta inteligente sean de solo lectura, por lo que esto no funcionará con todos los valores de número. Si un archivo de certificado se puede escribir, debe especificar un PIN para poder cambiarlo. Si intenta usar este comando sin especificar un PIN, netkey-tool le indicará cuál se necesita.

change {pin | puk | pin0 | pin1} nuevo-pin

Esto cambia el valor del PIN especificado al nuevo valor dado. Debe especificar el valor actual del PIN u otro PIN para poder hacerlo y si no especifica uno correcto, netkey-tool le indicará cuál se necesita.

nullpin pin-inicial

Este comando solo se puede ejecutar si el PIN global de su tarjeta está en estado de pin nulo. No hay forma de volver al estado de pin nulo una vez que ha cambiado su PIN global. No necesita un PIN para ejecutar el comando nullpin. Después de un comando nullpin exitoso, netkey-tool mostrará el valor PUK inicial de su tarjeta.

unblock {pin | pin0 | pin1}

Esto desbloquea el PIN especificado. Debe especificar otro PIN para poder hacerlo y si no especifica uno correcto, netkey-tool le indicará cuál se necesita.
