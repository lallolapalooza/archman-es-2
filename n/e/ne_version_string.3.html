NE_VERSION_MATCH(3) Referencia de la API de neon NE_VERSION_MATCH(3)

NOMBRE

ne_version_match, ne_version_string - versionado de la biblioteca

SINOPSIS

#include <ne_utils.h>

int ne_version_match(int major, int minor);

const char *ne_version_string(void);

DESCRIPCIÓN

La función ne_version_match devuelve un valor distinto de cero si la versión de la biblioteca no es de la versión principal major, o si la versión menor es inferior a minor. Para las versiones 0.x de neon, se asume que cada versión menor es incompatible con cualquier otra versión menor.

La función ne_version_string devuelve una cadena que indica la versión de la biblioteca.

EJEMPLOS

Para requerir neon 1.x, versión 1.2 o posterior:

if (ne_version_match(1, 2)) {
    printf("Versión de la biblioteca obsoleta: se requiere 1.2, se encontró %s.",
           ne_version_string());
    exit(1);
}
