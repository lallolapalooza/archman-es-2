NOMBRE

netplan-dbus - demonio para acceder a la funcionalidad de Netplan a través de una API D-Bus

SINOPSIS

netplan-dbus

DESCRIPCIÓN

netplan-dbus es un demonio D-Bus, que proporciona io.netplan.Netplan en el bus del sistema. El objeto /io/netplan/Netplan proporciona una interfaz io.netplan.Netplan, que ofrece los siguientes métodos:

•
Apply() -> b: llama a netplan apply y devuelve un estado de éxito o fallo.
•
Generate() -> b: llama a netplan generate y devuelve un estado de éxito o fallo.
•
Info() -> a(sv): devuelve un diccionario "Features -> as", que contiene una matriz de todas las banderas de características disponibles.
•
Config() -> o: prepara un nuevo objeto de configuración como /io/netplan/Netplan/config/<ID>, copiando el estado actual de /{etc,run,lib}/netplan/*.yaml.

Los objetos /io/netplan/Netplan/config/<ID> proporcionan una interfaz io.netplan.Netplan.Config, que ofrece los siguientes métodos:

•
Get() -> s: llama a netplan get --root-dir=/run/netplan/config-ID all y devuelve la configuración YAML fusionada del estado del objeto de configuración dado
•
Set(s:CONFIG_DELTA, s:ORIGIN_HINT) -> b: llama a netplan set --root-dir=/run/netplan/config-ID --origin-hint=ORIGIN_HINT CONFIG_DELTA

CONFIG_DELTA puede ser algo como: network.ethernets.eth0.dhcp4=true y ORIGIN_HINT puede ser algo como: 70-snapd (entonces escribirá la configuración en 70-snapd.yaml). Una vez que se llama a Set() en un objeto de configuración, todos los demás objetos de configuración actuales y futuros quedan invalidados y no pueden volver a llamar a Set() o Try()/Apply(), debido a este estado pendiente modificado. Después de que el objeto de configuración modificado sea rechazado a través de Cancel(), los demás objetos de configuración vuelven a ser válidos. Si el objeto de configuración modificado es aceptado a través de Apply(), los objetos de configuración creados recientemente serán válidos, mientras que los estados anteriores permanecerán inválidos.

•
Try(u:TIMEOUT_SEC) -> b: reemplaza la configuración principal de Netplan con el estado de este objeto de configuración y llama a netplan try --timeout=TIMEOUT_SEC.
•
Cancel() -> b: rechaza un intento de Try() en curso en este objeto de configuración y/o descarta el objeto de configuración.
•
Apply() -> b: reemplaza la configuración principal de Netplan con el estado de este objeto de configuración y llama a netplan apply.

Para obtener información sobre la funcionalidad Apply()/Try()/Get()/Set(), consulte netplan-apply(8)/netplan-try(8)/netplan-get(8)/netplan-set(8) respectivamente. Para obtener detalles sobre el formato del archivo de configuración, consulte netplan(5).

VER TAMBIÉN

netplan(5), netplan-apply(8), netplan-try(8), netplan-get(8), netplan-set(8)
