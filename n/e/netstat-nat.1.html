NOMBRE

netstat-nat - Mostrar las conexiones NAT en un firewall iptables de linux

SINOPSIS

netstat-nat [opciones]

DESCRIPCIÓN

netstat-nat muestra las conexiones NAT gestionadas por netfilter/iptables que vienen con los kernels de linux > 2.4.x.

El programa lee su información de '/proc/net/ip_conntrack' o '/proc/net/nf_conntrack', que es el almacenamiento temporal de conntrack de netfilter.

OPCIONES

-h
muestra la ayuda
-n
no resolver IPs/puertos a nombres de host/puerto
-p <protocolo>
mostrar conexiones NAT con selección de protocolo (ver /etc/protocols)
-s <host de origen>
mostrar conexiones por IP/nombre de host de origen
-d <host de destino>
mostrar conexiones por IP/nombre de host de destino
-S
mostrar conexiones SNAT
-D
mostrar conexiones DNAT
-L
mostrar solo conexiones al propio cuadro NAT (no muestra SNAT ni DNAT)
-R
mostrar solo conexiones enrutadas a través del cuadro NAT (no muestra SNAT ni DNAT)
-x
vista extendida de nombres de host
-r <origen|destino|puerto-origen|puerto-destino|estado>
ordenar conexiones
-o
sin encabezado de salida
-N
mostrar información de conexión del cuadro NAT (solo válido con SNAT y DNAT)
-v
imprime la versión

ARCHIVOS

/proc/net/ip_conntrack o /proc/net/nf_conntrack
