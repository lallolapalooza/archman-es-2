NOMBRE

nethsm-key - Operar con las claves de un dispositivo

SINOPSIS

nethsm key [-a|--auth-passphrase-file] [-c|--config] [-l|--label] [-u|--user] [-h|--help] <subcomandos>

DESCRIPCIÓN

Operar con las claves de un dispositivo

Admite todas las operaciones criptográficas relevantes (descifrar, cifrar, firmar), manejo de certificados, importación, generación y gestión de ACL.

Las claves pueden existir en ámbitos específicos: a nivel de sistema o en espacios de nombres (ver "nethsm namespace"). Mientras que los usuarios a nivel de sistema solo tienen acceso a las claves del sistema, los usuarios con espacios de nombres solo tienen acceso a las claves de su propio espacio de nombres.

OPCIONES

-a, --auth-passphrase-file <ARCHIVO_CONTRASEÑA_AUTENTICACIÓN>
La ruta a un archivo que contiene una contraseña para la autenticación

La contraseña proporcionada en el archivo debe ser la del usuario elegido para el comando.

Esta opción puede proporcionarse varias veces, lo cual es necesario para comandos que requieren varios roles a la vez. Con múltiples archivos de contraseña, el orden importa, ya que los archivos se asignan al usuario respectivo proporcionado por la opción "--user".

También se puede especificar con la variable de entorno NETHSM_AUTH_PASSPHRASE_FILE.
-c, --config <CONFIGURACIÓN>
La ruta a un archivo de configuración personalizado

Si se especifica, se utiliza el archivo de configuración personalizado en lugar de la ubicación predeterminada del archivo de configuración.

También se puede especificar con la variable de entorno NETHSM_CONFIG.
-l, --label <ETIQUETA>
Una etiqueta que identifica de forma única un dispositivo en el archivo de configuración

Debe proporcionarse si hay más de un dispositivo configurado en el archivo de configuración.

También se puede especificar con la variable de entorno NETHSM_LABEL.
-u, --user <USUARIO>
Un nombre de usuario que se utiliza para un comando

Se puede proporcionar si no hay un nombre de usuario configurado en el archivo de configuración para un dispositivo. Debe proporcionarse si hay varios nombres de usuario del mismo rol de destino configurados en el archivo de configuración para un dispositivo.

Esta opción puede proporcionarse varias veces, lo cual es necesario para comandos que requieren varios roles a la vez.

También se puede especificar con la variable de entorno NETHSM_USER.
-h, --help
Imprimir ayuda (ver un resumen con '-h')
