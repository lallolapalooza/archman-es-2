netsnmp_agent_api(3)

Paquete: net-snmp

Licencias: BSD

NETSNMP_AGENT_API(3) Net-SNMP NETSNMP_AGENT_API(3)

NOMBRE

netsnmp_agent_api - incrustar un agente en una aplicación externa

SINOPSIS

#include <net-snmp/net-snmp-config.h>
#include <net-snmp/net-snmp-includes.h>
#include <net-snmp/agent/net-snmp-agent-includes.h>
int
main (int argc, char *argv[])
{
  int agentx_subagent = 1;  /* Cambiar si eres un agente maestro.  */
  snmp_enable_stderrlog();
  /*  Si somos un subagente AgentX...  */
  if (agentx_subagent) {
      /* ...nos convertimos en un cliente AgentX.  */
      netsnmp_ds_set_boolean(NETSNMP_DS_APPLICATION_ID,
                             NETSNMP_DS_AGENT_ROLE, 1);
  }
  init_agent("tuaplicacion");
  /*  Inicializar el código de tu MIB aquí.  */
  init_my_mib_code();
  /*  `tuaplicacion' se usará para leer los archivos tuaplicacion.conf.  */
  init_snmp("tuaplicacion");
  /*  Si vamos a ser un agente maestro SNMP...  */
  if (!agentx_subagent)
      init_master_agent();  /*  Escuchar en el puerto por defecto (161).  */
  /*  Tu bucle principal aquí...  */
  while (whatever) {
      /* si usas select(), mira snmp_api(3) */
      /*     --- O ---  */
      agent_check_and_process(0); /* 0 == no bloquear */
  }
  /*  A la hora de apagar:  */
  snmp_shutdown("tuaplicacion");
}
Luego:
$(CC) ... `net-snmp-config --agent-libs`

DESCRIPCIÓN

Nuestro objetivo es crear una interfaz fácil de usar para el paquete Net-SNMP de modo que pueda tomar código que ha escrito y que ha sido diseñado para ser un módulo MIB de Net-SNMP e incrustarlo en una aplicación externa donde puede optar por ser un agente maestro SNMP o un subagente AgentX utilizando el mismo código del módulo MIB. Nuestra sugerencia es que utilice nuestro (u otro) agente SNMP como agente maestro AgentX y opte por ser un subagente AgentX que luego se conecta al maestro.

El paquete Net-SNMP proporciona un par de bibliotecas que permiten la fácil incrustación de un agente SNMP o AgentX en un paquete de software externo. AgentX es un protocolo extensible diseñado para permitir que múltiples subagentes SNMP se ejecuten en una sola máquina bajo un único agente maestro SNMP. Está definido en la RFC 2741.

Necesitará realizar algunas tareas para lograr esto. En primer lugar, deberá inicializar tanto la biblioteca SNMP como la biblioteca del agente SNMP. Como se indicó anteriormente, esto se hace de manera ligeramente diferente dependiendo de si va a actuar como agente maestro o como subagente AgentX.

CONFIGURACIÓN

Si tiene la intención de operar como un subagente AgentX, deberá haber configurado el paquete Net-SNMP con soporte AgentX (que está activado por defecto, así que simplemente no lo desactive).

Adicionalmente, deberá enlazar con las bibliotecas Net-SNMP (use la salida de "net-snmp-config --agent-libs" para obtener una lista de bibliotecas) y llamar a subagent_pre_init() como se indicó anteriormente.

COMPILACIÓN

Para poder utilizar cualquiera de las API anteriores, deberá enlazar al menos con las cuatro bibliotecas mencionadas anteriormente.

FUNCIONES

dónde encontrar más información sobre ellas. Ciertamente no es una lista completa de lo que está disponible en todas las bibliotecas Net-SNMP.

snmp_enable_stderrlog()
Registra la salida de error del agente SNMP en el flujo de error estándar.
netsnmp_ds_set_boolean()
Por favor, consulte la página del manual de default_store(3) para más información sobre esta API.
init_agent(char *name)
Inicializa el agente incrustado. Esto debe llamarse antes de la llamada a init_snmp(). name se utiliza para indicar qué archivo .conf leer cuando se llama a init_snmp() más tarde.
init_snmp(char *name)
Inicializa la biblioteca SNMP. Tenga en cuenta que una de las cosas que hará será leer archivos de configuración en un esfuerzo por configurar su aplicación. Intentará leer los archivos de configuración nombrados por la cadena name que pasó. Se puede utilizar para configurar el control de acceso, por ejemplo. Consulte las páginas del manual de netsnmp_config_api(3), snmp_config(5), y snmpd.conf(5) para obtener más detalles sobre este tema.
init_master_agent(void)
Inicializa el agente maestro y hace que escuche las solicitudes SNMP en su puerto UDP por defecto de 161.
agent_check_and_process(int block)
Esto comprueba la llegada de paquetes en el puerto SNMP y los procesa si se encuentran algunos. Si block es distinto de cero, la llamada a la función se bloqueará hasta que llegue un paquete o se deba ejecutar una alarma (ver snmp_alarm(3)). El valor de retorno de esta función es un entero positivo si se procesaron paquetes, cero si ocurrió una alarma y -1 si ocurrió un error.
snmp_shutdown(char *name);
Esto apaga el agente, guardando cualquier almacenamiento persistente necesario, etc.
