nextup(3) Manual de funciones de biblioteca nextup(3)

NOMBRE

nextup, nextupf, nextupl, nextdown, nextdownf, nextdownl - devuelven el siguiente número de punto flotante en dirección a infinito positivo/negativo

BIBLIOTECA

Biblioteca matemática (libm, -lm)

SINOPSIS

#define _GNU_SOURCE     /* Ver feature_test_macros(7) */
#include <math.h>
double nextup(double x);
float nextupf(float x);
long double nextupl(long double x);
double nextdown(double x);
float nextdownf(float x);
long double nextdownl(long double x);

DESCRIPCIÓN

Las funciones nextup(), nextupf() y nextupl() devuelven el siguiente número de punto flotante representable mayor que x.

Si x es el número negativo representable más pequeño del tipo correspondiente, estas funciones devuelven -0. Si x es +0 o -0, el valor devuelto es el número positivo representable más pequeño del tipo correspondiente.

Si x es infinito positivo, el valor devuelto es infinito positivo. Si x es infinito negativo, el valor devuelto es el número negativo finito representable más grande del tipo correspondiente.

Si x es NaN, el valor devuelto es NaN.

El valor devuelto por nextdown(x) es -nextup(-x), y de forma similar para los otros tipos.

VALOR DE RETORNO

Ver DESCRIPCIÓN.

ATRIBUTOS

Para una explicación de los términos usados en esta sección, ver attributes(7).

Interfaz Atributo Valor
nextup (), nextupf (), nextupl (), nextdown (), nextdownf (), nextdownl () Seguridad en hilos MT-Safe

ESTÁNDARES

Estas funciones se describen en IEEE Std 754-2008 - Standard for Floating-Point Arithmetic e ISO/IEC TS 18661.

HISTORIA

glibc 2.24.
