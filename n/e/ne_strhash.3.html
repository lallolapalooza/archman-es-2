ne_strhash(3)

Paquete: neon

Licencias: LGPL-2.0-or-later

NE_STRHASH(3) Referencia de la API de neon NE_STRHASH(3)

NOMBRE

ne_strhash, ne_vstrhash - interfaz de hash de cadenas

SINOPSIS

#include <ne_string.h>

char *ne_strhash(unsigned int flags, ...);

char *ne_vstrhash(unsigned int flags, va_list ap);

DESCRIPCIÓN

Las funciones ne_strhash y ne_vstrhash se pueden utilizar para crear hashes. La lista de argumentos varargs debe ser cadenas const char * seguidas de un terminador NULL. El argumento flags debe seleccionar exactamente un algoritmo de hash de la lista siguiente, que opcionalmente se puede combinar con OR bit a bit con una de las opciones de formato. El hash se calcula para la concatenación de la lista de argumentos, sin separadores.

Algoritmos de hash

Los siguientes algoritmos de hash están disponibles:

NE_HASH_MD5

MD5

NE_HASH_SHA256

SHA-256 (SHA-2)

NE_HASH_SHA512

SHA-512 (SHA-2)

NE_HASH_SHA256_256

SHA-512/256 (SHA-2)

Opciones de formato

Por defecto, el hash se devuelve como una cadena de caracteres hexadecimales en minúsculas. Las siguientes opciones de formato están disponibles:

NE_HASH_COLON

pares hex con dos puntos, p. ej. "aa:11:22..."

NE_HASH_SPACE

pares hex separados por espacios, p. ej. "aa 11 22..."

VALOR DE RETORNO

El valor de retorno es la representación hexadecimal ASCII del hash como una cadena asignada con malloc, terminada en NUL, o NULL si el hash no se puede crear. La longitud de la cadena está determinada por el algoritmo de hash (y las opciones de formato utilizadas). El soporte para los algoritmos de hash es específico del conjunto de herramientas SSL con el que se compila neon. Algunos sistemas restringirán aún más la disponibilidad de hashes en tiempo de ejecución, por ejemplo, debido al modo FIPS.

HISTORIA

ne_strhash y ne_vstrhash están disponibles en neon 0.32.0 y versiones posteriores.
