NOMBRE

netctl.special - Unidades especiales de systemd de netctl

SINOPSIS

netctl.service, netctl-auto.service, netctl-ifplugd.service, netctl-wait-online.service

DESCRIPCIÓN

Junto con netctl vienen algunas unidades de systemd que no se controlan a través del comando netctl. Se pueden usar a través de la utilidad systemctl de systemd.

UNIDADES ESPECIALES

netctl.service

Cuando se inicia, esta unidad intenta iniciar los perfiles que se estaban ejecutando cuando la unidad se detuvo por última vez. En algunos casos, la interfaz a la que se vincula un perfil podría aún no estar disponible cuando netctl.service intente activar un perfil. Una solución simple y rudimentaria es hacer:
echo "[[ -t 0 ]] || sleep 3" > /etc/netctl/interfaces/<interfaz>
chmod 755 /etc/netctl/interfaces/<interfaz>
Una solución más concisa es habilitar primero un perfil a través de netctl
y luego deshabilitarlo nuevamente a través de systemctl:
netctl enable <perfil>
systemctl disable netctl@<perfil>
De esta manera, el archivo de configuración de la unidad para el perfil
permanece, mientras que el perfil no está habilitado.

netctl-sleep.service

Cuando se habilita, esta unidad almacena y detiene los perfiles de red activos antes de que la máquina entre en suspensión. Después de que el sistema se reanuda, los perfiles almacenados previamente se reinician.

netctl-auto@<interfaz>.service

Esta unidad emite un escaneo en la interfaz para la que se utiliza e intenta iniciar un perfil para una red que encuentra. Está dirigida a interfaces inalámbricas. Los valores específicos del perfil para WPADriver se ignoran, pero es posible especificar WPADriver= en un hook de interfaz (/etc/netctl/interfaces/<interfaz>).

Use netctl-auto(1) en lugar de netctl(1) para controlar la selección automática de perfiles al usar esta unidad.

netctl-ifplugd@<interfaz>.service

Esta unidad inicia ifplugd en la interfaz para la que se utiliza. Intentará iniciar un perfil netctl cada vez que se conecte un cable a la interfaz y detendrá el perfil cuando se desconecte el cable. Tenga en cuenta que esta unidad no proporciona network.target.

netctl-wait-online.service

Cuando se activa, esta unidad espera a que todos los perfiles netctl habilitados se conecten. Habilitar esta unidad hace que network-online.target solo se alcance una vez que todos los perfiles netctl habilitados estén completamente conectados. El tiempo máximo, en segundos, para esperar a los perfiles se puede pasar a esta unidad a través de TIMEOUT_ONLINE=. El valor predeterminado es 120. Si ocurre un tiempo de espera, el servicio entra en estado de error.

VER TAMBIÉN

netctl(1), netctl-auto(1), netctl.profile(5)
