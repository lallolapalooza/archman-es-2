NOMBRE

nethsm-config-get-tls-csr - Obtener una solicitud de firma de certificado para el certificado TLS

SINOPSIS

nethsm config get tls-csr [-f|--force] [-o|--output] [-a|--auth-passphrase-file] [-c|--config] [-l|--label] [-u|--user] [-h|--help] <NOMBRE_COMUN> [NOMBRE_ORG] [UNIDAD_ORG] [LOCALIDAD] [ESTADO] [PAIS] [EMAIL]

DESCRIPCIÓN

Obtener una solicitud de firma de certificado para el certificado TLS

La Solicitud de Firma de Certificado (CSR) PKCS#10 se devuelve en formato Privacy-enhanced Electronic Mail (PEM). A menos que se elija un archivo de salida específico, el certificado se devuelve en la salida estándar.

Como mínimo, se debe proporcionar el atributo "Nombre Común" (CN) para la CSR.

Requiere la autenticación de un usuario a nivel de sistema en el rol de "Administrador".

OPCIONES

-f, --force
Escribir en el archivo de salida incluso si ya existe
También se puede especificar con la variable de entorno NETHSM_FORCE.
-o, --output <SALIDA>
La ruta opcional a un archivo específico donde se escribe el certificado
También se puede especificar con la variable de entorno NETHSM_CONFIG_TLS_CSR_OUTPUT_FILE.
-a, --auth-passphrase-file <ARCHIVO_CONTRASEÑA_AUTENTICACIÓN>
La ruta a un archivo que contiene una contraseña para la autenticación

La contraseña proporcionada en el archivo debe ser la del usuario elegido para el comando.

Esta opción se puede proporcionar varias veces, lo cual es necesario para comandos que requieren varios roles a la vez. Con varios archivos de contraseña, el orden importa, ya que los archivos se asignan al usuario respectivo proporcionado por la opción "--user".

También se puede especificar con la variable de entorno NETHSM_AUTH_PASSPHRASE_FILE.
-c, --config <CONFIGURACIÓN>
La ruta a un archivo de configuración personalizado

Si se especifica, se utiliza el archivo de configuración personalizado en lugar de la ubicación predeterminada del archivo de configuración.

También se puede especificar con la variable de entorno NETHSM_CONFIG.
-l, --label <ETIQUETA>
Una etiqueta que identifica de forma única un dispositivo en el archivo de configuración

Debe proporcionarse si hay más de un dispositivo configurado en el archivo de configuración.

También se puede especificar con la variable de entorno NETHSM_LABEL.
-u, --user <USUARIO>
Un nombre de usuario que se utiliza para un comando

Se puede proporcionar si no hay ningún nombre de usuario configurado en el archivo de configuración para un dispositivo. Debe proporcionarse si hay varios nombres de usuario del mismo rol de destino configurados en el archivo de configuración para un dispositivo.

Esta opción se puede proporcionar varias veces, lo cual es necesario para comandos que requieren varios roles a la vez.

También se puede especificar con la variable de entorno NETHSM_USER.
-h, --help
Imprimir ayuda (ver un resumen con '-h')
<NOMBRE_COMUN>
El atributo obligatorio "Nombre Común" (CN) para la CSR

Un nombre de dominio completamente calificado (FQDN) que debe ser asegurado utilizando la CSR.

También se puede especificar con la variable de entorno NETHSM_TLS_CSR_COMMON_NAME.
[NOMBRE_ORG]
El atributo opcional "Nombre de la Organización" (O) para la CSR

Normalmente, el nombre legal de una empresa o entidad y debe incluir sufijos como S.L., S.A., o Corp.

También se puede especificar con la variable de entorno NETHSM_TLS_CSR_ORG_NAME.
[UNIDAD_ORG]
El atributo opcional "Unidad Organizacional" (OU) para la CSR

Departamento/división interna de la organización.

También se puede especificar con la variable de entorno NETHSM_TLS_CSR_ORG_UNIT.
[LOCALIDAD]
El atributo opcional "Localidad" (L) para la CSR

Nombre de la ciudad, pueblo, aldea, etc.

También se puede especificar con la variable de entorno NETHSM_TLS_CSR_LOCALITY.
[ESTADO]
El atributo opcional "Estado" (ST) para la CSR

Provincia, región, condado o estado.

También se puede especificar con la variable de entorno NETHSM_TLS_CSR_STATE.
[PAIS]
El atributo opcional "País" (C) para la CSR

El código ISO de dos letras para el país donde se encuentra la "Organización" (O).

También se puede especificar con la variable de entorno NETHSM_TLS_CSR_COUNTRY.
[EMAIL]
El atributo opcional "Dirección de Correo Electrónico" (EMAIL) para la CSR

El contacto de la organización, generalmente del administrador del certificado o del departamento de TI.

También se puede especificar con la variable de entorno NETHSM_TLS_CSR_EMAIL.
