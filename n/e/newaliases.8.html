Paquete: opensmtpd

Licencias: custom

NEWALIASES(8) Manual del Administrador del Sistema NEWALIASES(8)

NOMBRE

newaliases — reconstruye los alias de correo

SINOPSIS

newaliases [-f archivo]

DESCRIPCIÓN

La utilidad newaliases hace visibles los cambios en el archivo de alias de correo para smtpd(8). Debe ejecutarse cada vez que se modifique el archivo aliases(5). La ubicación del archivo de alias se define en smtpd.conf(5) y, por defecto, es /etc/smtpd/aliases.

Las opciones son las siguientes:

-f archivo
Utiliza archivo como archivo de configuración, en lugar del predeterminado /etc/smtpd/smtpd.conf.

Si se utilizan archivos de base de datos (db), newaliases es equivalente a ejecutar makemap(8) de la siguiente manera:

# makemap -t aliases /etc/smtpd/aliases

Si se utilizan archivos de texto plano, newaliases es equivalente a ejecutar smtpctl(8) de la siguiente manera:

# smtpctl update table aliases

ARCHIVOS

/etc/smtpd/aliases
Lista de alias de correo de usuarios locales.
/etc/smtpd/virtual
Lista de alias de hosts virtuales.

ESTADO DE SALIDA

La utilidad newaliases sale con 0 si tiene éxito y con >0 si ocurre un error.

VER TAMBIÉN

smtpd.conf(5), makemap(8), smtpctl(8), smtpd(8)

HISTORIA

El comando newaliases apareció por primera vez en OpenBSD 4.6 como reemplazo del comando equivalente que se enviaba con sendmail.
