NOMBRE

netplan-ip - obtener información de IP (como concesiones DHCP) del sistema

SINOPSIS

netplan [--debug] ip -h|--help

netplan [--debug] ip COMANDO [--root-dir=ROOT_DIR] ARGUMENTOS

DESCRIPCIÓN

netplan ip obtiene información de IP (como concesiones DHCP) del sistema.

COMANDOS DHCP

leases INTERFAZ
Muestra las concesiones de IP DHCP.

Ejemplo: netplan ip leases enp5s0

OPCIONES

-h, --help
Imprime ayuda básica.
--debug
Imprime la salida de depuración durante el proceso.
--root-dir
Lee archivos YAML desde esta raíz en lugar de /.

VER TAMBIÉN

netplan(5), netplan-get(8), netplan-status(8)
