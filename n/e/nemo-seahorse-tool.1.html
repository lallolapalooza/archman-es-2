NOMBRE

nemo-seahorse-tool - Cifrado de archivos PGP/GnuPG para Nemo

SINOPSIS

nemo-seahorse-tool [ OPCIÓN... ]

DESCRIPCIÓN

Seahorse es una aplicación de GNOME para gestionar claves de cifrado. seahorse-tool te permite cifrar, descifrar o firmar archivos. Está integrado en el menú contextual de Nemo, pero también se puede usar desde la línea de comandos.

OPCIONES

Opciones de ayuda

-?, --help
Muestra un resumen de todas las opciones y sale.
--usage
Muestra un breve mensaje de uso y sale.

Opciones de aplicación

-i ARCHIVO, --importar ARCHIVO
Importa claves del ARCHIVO.
-e ARCHIVO, --cifrar ARCHIVO
Cifra el ARCHIVO.
-s ARCHIVO, --firmar ARCHIVO
Firma el ARCHIVO con la clave predeterminada.
-n ARCHIVO, --cifrar-firmar ARCHIVO
Cifra y firma el ARCHIVO con la clave predeterminada.
-d ARCHIVO, --descifrar ARCHIVO
Descifra el ARCHIVO cifrado.
-v ARCHIVO, --verificar ARCHIVO
Verifica la firma del ARCHIVO.
-T, --lista-uri
Lee una lista de URIs de la entrada estándar.
--version
Muestra información de la versión y sale.
-h, --help
Muestra las opciones de ayuda.

Opciones adicionales

Además, se aplican las opciones habituales de línea de comandos de GTK+ y GNOME. Consulte la salida de --help para obtener más detalles.
