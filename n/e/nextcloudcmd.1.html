NEXTCLOUDCMD(1) Manual del Cliente Nextcloud NEXTCLOUDCMD(1)

NOMBRE

nextcloudcmd - Herramienta cliente de línea de comandos de Nextcloud.

SINOPSIS

nextcloudcmd [OPCIONES...] dir_origen url_nextcloud

DESCRIPCIÓN

nextcloudcmd es la herramienta de línea de comandos utilizada para la utilidad de escritorio de sincronización de archivos de nextCloud.

A diferencia del cliente GUI de nextcloud(1), nextcloudcmd realiza solo una ejecución de sincronización y luego sale. Al hacerlo, nextcloudcmd reemplaza el binario ocsync utilizado para el mismo propósito en versiones anteriores.

Una ejecución de sincronización sincroniza un directorio local único utilizando un recurso compartido WebDAV en un servidor remoto de nextCloud.

Para invocar el cliente de línea de comandos, proporcione el repositorio local y el remoto: El primer parámetro es el directorio local. El segundo parámetro es la URL del servidor.

NOTA:

Antes de la versión 1.6 de nextcloudcmd, la herramienta solo aceptaba owncloud:// u ownclouds:// en lugar de http:// y https:// como esquema. Ver Ejemplos para más detalles.

OPCIONES

--path
Sobrescribe la carpeta raíz remota predeterminada a una subcarpeta específica en el servidor (ejemplo: /Documents sincronizaría la subcarpeta Documents en el servidor)
--user, -u <usuario>
Usa usuario como nombre de inicio de sesión.
--password, -p <contraseña>
Usa contraseña como contraseña.
-n
Usa netrc(5) para el inicio de sesión.
--non-interactive
No preguntar nada.
--silent, --s
Inhibe la salida detallada del registro.
--trust
Confía en cualquier certificado SSL, incluso en los inválidos.
--httpproxy http://[usuario@contraseña:]<servidor>:<puerto>
Usa servidor como proxy HTTP.
--exclude <archivo>
Archivo de lista de exclusión
--unsyncedfolders <archivo>
Archivo que contiene la lista de carpetas no sincronizadas (sincronización selectiva)
--max-sync-retries <n>
Reintentos máximo n veces (por defecto 3)
-h
Sincroniza archivos ocultos, no los ignora

EJEMPLO

Para sincronizar el directorio de nextCloud Music con el directorio local media/music a través de un proxy que escucha en el puerto 8080 en la máquina de la puerta de enlace 192.168.178.1, la línea de comandos sería:

$ nextcloudcmd --httpproxy http://192.168.178.1:8080 --path /Music \
              $HOME/media/music \
              https://servidor/nextcloud

nextcloudcmd solicitará el nombre de usuario y la contraseña, a menos que se hayan especificado en la línea de comandos o se haya pasado -n (ver netrc(5)).
