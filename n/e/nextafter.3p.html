NEXTAFTER(3P) Manual de Programador de POSIX NEXTAFTER(3P)

PROLOG

Esta página del manual forma parte del Manual de Programador de POSIX. La implementación de Linux de esta interfaz puede diferir (consulte la página del manual de Linux correspondiente para obtener detalles sobre el comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

nextafter, nextafterf, nextafterl, nexttoward, nexttowardf, nexttowardl — siguiente número de punto flotante representable

SINOPSIS

#include <math.h>
double nextafter(double x, double y);
float nextafterf(float x, float y);
long double nextafterl(long double x, long double y);
double nexttoward(double x, long double y);
float nexttowardf(float x, long double y);
long double nexttowardl(long double x, long double y);

DESCRIPCIÓN

La funcionalidad descrita en esta página de referencia está alineada con el estándar ISO C. Cualquier conflicto entre los requisitos descritos aquí y el estándar ISO C es no intencional. Este volumen de POSIX.1-2017 remite al estándar ISO C.

Las funciones nextafter(), nextafterf() y nextafterl() calcularán el siguiente valor de punto flotante representable después de x en la dirección de y. Por lo tanto, si y es menor que x, nextafter() devolverá el mayor número de punto flotante representable menor que x. Las funciones nextafter(), nextafterf() y nextafterl() devolverán y si x es igual a y.

Las funciones nexttoward(), nexttowardf() y nexttowardl() serán equivalentes a las funciones nextafter() correspondientes, excepto que el segundo parámetro tendrá el tipo long double y las funciones devolverán y convertido al tipo de la función si x es igual a y.

Una aplicación que desee verificar situaciones de error debe establecer errno a cero y llamar a feclearexcept(FE_ALL_EXCEPT) antes de llamar a estas funciones. Al regresar, si errno no es cero o fetestexcept(FE_INVALID | FE_DIVBYZERO | FE_OVERFLOW | FE_UNDERFLOW) no es cero, ha ocurrido un error.

VALOR DE RETORNO

Al completarse con éxito, estas funciones devolverán el siguiente valor de punto flotante representable después de x en la dirección de y.

Si x==y, se devolverá y (del tipo de x).

Si x es finito y el valor correcto de la función se desbordaría, ocurrirá un error de rango y se devolverá ±HUGE_VAL, ±HUGE_VALF, y ±HUGE_VALL (con el mismo signo que x) según corresponda para el tipo de retorno de la función.

Si x o y es NaN, se devolverá un NaN.

Si x!=y y el valor correcto de la función es subnormal, cero o se queda corto, ocurrirá un error de rango, y se devolverá
el valor correcto de la función (si es representable) o
0.0.

ERRORES

Estas funciones fallarán si:

Error de Rango
El valor correcto se desborda.

Si la expresión entera (math_errhandling & MATH_ERRNO) no es cero, entonces errno se establecerá a [ERANGE]. Si la expresión entera (math_errhandling & MATH_ERREXCEPT) no es cero, entonces se activará la excepción de punto flotante de desbordamiento.

Error de Rango
El valor correcto es subnormal o se queda corto.

Si la expresión entera (math_errhandling & MATH_ERRNO) no es cero, entonces errno se establecerá a [ERANGE]. Si la expresión entera (math_errhandling & MATH_ERREXCEPT) no es cero, entonces se activará la excepción de punto flotante de quedarse corto.

USO DE LA APLICACIÓN

En caso de error, las expresiones (math_errhandling & MATH_ERRNO) y (math_errhandling & MATH_ERREXCEPT) son independientes entre sí, pero al menos una de ellas debe ser distinta de cero.

Cuando se incluye <tgmath.h>, tenga en cuenta que el tipo de retorno de nextafter() depende de la tipificación genérica deducida de ambos argumentos, mientras que el tipo de retorno de nexttoward() depende solo de la tipificación genérica del primer argumento.

Sección 3 del manual de Linux

NOMBRE

nextafter, nexttoward, nextafterf, nexttowardf, nextafterl, nexttowardl - devolver el siguiente valor de punto flotante en una dirección dada

DESCRIPCIÓN

Las funciones nextafter() y nexttoward() devuelven el valor de punto flotante que está más cerca de x en la dirección de y. Estas funciones devuelven x si x es igual a y. Si x es el valor máximo de punto flotante representable y y es mayor, devuelven x. Si x es el valor mínimo de punto flotante representable y y es menor, devuelven x. Si x o y son NaN, devuelven NaN. Si la diferencia entre x e y es demasiado pequeña para ser representada, la función puede devolver y.

Las versiones f y l realizan la misma función pero para tipos de punto flotante float y long double respectivamente.

VALOR DE RETORNO

Las funciones devuelven el siguiente valor de punto flotante en la dirección especificada.

ERRORES

No se definen errores específicos para estas funciones.
