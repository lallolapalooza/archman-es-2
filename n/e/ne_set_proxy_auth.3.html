ne_set_proxy_auth(3)

Paquete: neon

Licencias: LGPL-2.0-or-later

NE_SET_SERVER_AUTH(3) referencia de la API de neon NE_SET_SERVER_AUTH(3)

NOMBRE

ne_set_server_auth, ne_set_proxy_auth, ne_forget_auth - registrar callbacks de autenticación

SINOPSIS

#include <ne_auth.h>

typedef int (*ne_auth_creds)(void *userdata, const char *realm, int attempt, char *username, char *password);

void ne_set_server_auth(ne_session *session, ne_auth_creds callback, void *userdata);

void ne_set_proxy_auth(ne_session *session, ne_auth_creds callback, void *userdata);

void ne_forget_auth(ne_session *session);

DESCRIPCIÓN

El tipo de callback ne_auth_creds define una función que se invoca cuando un servidor o servidor proxy requiere autenticación de usuario para una solicitud particular. La cadena realm es proporcionada por el servidor. El valor de attempt es un contador que indica el número de veces que la solicitud ha sido reintentada con diferentes credenciales de autenticación. La primera vez que se invoca el callback para una solicitud particular, attempt será cero.

Para reintentar la solicitud utilizando nuevas credenciales de autenticación, el callback debe devolver cero, y los búferes username y password deben contener cadenas terminadas en NULO. La constante NE_ABUFSIZ indica el tamaño de estos búferes.


Consejo

Si solo desea permitir al usuario un intento para ingresar credenciales, utilice el valor del parámetro attempt como valor de retorno del callback.

Para abortar la solicitud, el callback debe devolver un valor distinto de cero; en cuyo caso, el contenido de los búferes username y password se ignora.

La función ne_forget_auth se puede utilizar para descartar las credenciales de autenticación almacenadas en caché.

EJEMPLOS

/* Función que solicita una línea de entrada del usuario: */
extern char *prompt_for(const char *prompt);
static int
my_auth(void *userdata, const char *realm, int attempts,
        char *username, char *password)
{
   strncpy(username, prompt_for("Nombre de usuario: "), NE_ABUFSIZ);
   strncpy(password, prompt_for("Contraseña: "), NE_ABUFSIZ);
   return attempts;
}
int main(...)
{
   ne_session *sess = ne_session_create(...);
   ne_set_server_auth(sess, my_auth, NULL);
   /* ... */
}
