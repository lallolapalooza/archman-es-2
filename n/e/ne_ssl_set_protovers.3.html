NE_SSL_SET_PROTOVERS(3) Referencia de la API de neon NE_SSL_SET_PROTOVERS(3)

NOMBRE

ne_ssl_set_protovers - establece la versión mínima o máxima del protocolo SSL/TLS de la sesión

SINOPSIS

#include <ne_session.h>

int ne_ssl_set_protovers(ne_session *sess, enum ne_ssl_protocol min, enum ne_ssl_protocol max);

DESCRIPCIÓN

La función ne_ssl_set_protovers establece la versión mínima y/o máxima de SSL/TLS. Se puede especificar la versión mínima y/o máxima como NE_SSL_PROTO_UNSPEC, en cuyo caso no se impone ningún límite.

VALOR DE RETORNO

La función ne_ssl_set_protovers devuelve cero si tiene éxito o un valor distinto de cero si hay un error. Los errores incluyen un rango inválido (mínimo mayor que máximo), o si la versión del protocolo no es compatible con el conjunto de herramientas SSL/TLS en uso, o si SSL/TLS no se está utilizando para la sesión.

HISTORIA

ne_ssl_set_protovers está disponible en neon 0.34.0 y versiones posteriores.

VéASE TAMBIÉN

ne_ssl_proto_name, ne_session_create.
