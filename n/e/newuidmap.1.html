NEWUIDMAP(1) Comandos de usuario NEWUIDMAP(1)

NOMBRE

newuidmap - establece el mapeo de uid de un espacio de nombres de usuario

SINOPSIS

newuidmap pid uid loweruid count [uid loweruid count [ ... ]]

DESCRIPCIÓN

El comando newuidmap establece /proc/[pid]/uid_map basándose en los argumentos de su línea de comandos y los uids permitidos. La delegación de subuid se puede gestionar a través de /etc/subuid o a través del módulo subid NSS configurado. Estas opciones son mutuamente excluyentes.

Tenga en cuenta que el usuario root no está exento del requisito de una entrada válida en /etc/subuid.

Después del argumento pid, newuidmap espera conjuntos de 3 enteros:

uid

Inicio del rango de UIDs dentro del espacio de nombres de usuario.

loweruid

Inicio del rango de UIDs fuera del espacio de nombres de usuario.

count

Longitud de los rangos (tanto dentro como fuera del espacio de nombres de usuario).

newuidmap verifica que el llamante sea el propietario del proceso indicado por pid y que para cada uno de los conjuntos anteriores, cada uno de los UIDs en el rango [loweruid, loweruid+count) esté permitido al llamante de acuerdo con /etc/subuid antes de establecer /proc/[pid]/uid_map.

Tenga en cuenta que newuidmap solo puede usarse una vez para un proceso dado.

En lugar de un ID de proceso entero, el primer argumento puede especificarse como fd:N, donde el entero N es el número de descriptor de archivo para el descriptor de archivo abierto del proceso llamante para el directorio /proc/[pid]. En este caso, newuidmap usará openat(2) para abrir el archivo uid_map bajo ese directorio, evitando un TOCTTOU en caso de que el proceso termine y el pid sea reutilizado inmediatamente.

OPCIONES

Actualmente no hay opciones para el comando newuidmap.

ARCHIVOS

/etc/subuid

Lista de IDs de usuario subordinados.

/proc/[pid]/uid_map

Mapeo de uids entre espacios de nombres de usuario.

VER TAMBIÉN

login.defs(5), newusers(8), subuid(5), useradd(8), usermod(8), userdel(8).
