ne_iaddr_reverse(3)

Paquete: neon

Licencias: LGPL-2.0-or-later

NE_IADDR_MAKE(3) Referencia de la API de neon NE_IADDR_MAKE(3)

NOMBRE

ne_iaddr_make, ne_iaddr_cmp, ne_iaddr_print, ne_iaddr_typeof, ne_iaddr_parse, ne_iaddr_raw, ne_iaddr_reverse, ne_iaddr_free - funciones para manipular direcciones de red

SINOPSIS

#include <ne_socket.h>
typedef enum {
    ne_iaddr_ipv4 = 0,
    ne_iaddr_ipv6
} ne_iaddr_type;

ne_inet_addr *ne_iaddr_make(ne_iaddr_type type, const unsigned char *raw);

int ne_iaddr_cmp(const ne_inet_addr *ia1, const ne_inet_addr *ia2);

char *ne_iaddr_print(const ne_inet_addr *ia, char *buffer, size_t bufsiz);

ne_iaddr_type ne_iaddr_typeof(const ne_inet_addr *ia);

ne_inet_addr *ne_iaddr_parse(const char *address, ne_iaddr_type type);

unsigned char *ne_iaddr_raw(const ne_inet_addr *ia, unsigned char *buffer);

int ne_iaddr_reverse(const ne_inet_addr *ia, char *buffer, size_t buflen);

void ne_iaddr_free(const ne_inet_addr *ia);

DESCRIPCIÓN

ne_iaddr_make crea un objeto ne_inet_addr a partir de una dirección de red binaria cruda; por ejemplo, los cuatro bytes 0x7f 0x00 0x00 0x01 representan la dirección IPv4 127.0.0.1. El objeto devuelto es adecuado para pasarlo a ne_sock_connect. Una dirección IPv4 binaria contiene cuatro bytes; una dirección IPv6 binaria contiene dieciséis bytes; las direcciones pasadas deben estar en orden de bytes de red.

ne_iaddr_cmp compara dos objetos de direcciones de red; devuelve cero solo si son idénticos. Los objetos no necesitan tener el mismo tipo de dirección; si las direcciones no son del mismo tipo, el valor de retorno se garantiza que sea distinto de cero.

ne_iaddr_print imprime una representación de cadena legible por humanos de una dirección de red en un búfer, por ejemplo, la cadena "127.0.0.1".

ne_iaddr_typeof devuelve el tipo del objeto de dirección de red dado.

ne_iaddr_parse analiza una representación de cadena de una dirección de red (como "127.0.0.1") y crea un objeto de dirección de red para representar la dirección analizada.

ne_iaddr_raw escribe la representación de bytes crudos de una dirección de red en el búfer proporcionado. Los bytes se escriben en orden de bytes de red; el búfer debe tener la longitud adecuada para el tipo de dirección (4 bytes para una dirección IPv4, 16 bytes para una dirección IPv6).

ne_iaddr_reverse realiza una consulta de nombre inversa en el objeto de dirección, escribiendo el (primer) nombre de host asociado con la dirección IP en el búfer proporcionado. Si el nombre de host es más largo que el búfer, se truncará silenciosamente; en caso de éxito, la cadena escrita en el búfer siempre estará terminada en NUL.

ne_iaddr_free libera la memoria asociada con un objeto de dirección de red.

VALOR DE RETORNO

ne_iaddr_make devuelve NULL si el tipo de dirección pasado no es compatible (por ejemplo, en una plataforma que no admite IPv6).

ne_iaddr_print devuelve el puntero buffer, y nunca NULL.

ne_iaddr_parse devuelve un objeto de dirección de red en caso de éxito, o NULL en caso de error al analizar el parámetro address.

ne_iaddr_reverse devuelve cero en caso de éxito o un valor distinto de cero si no hay ningún nombre de host asociado con la dirección.

ne_iaddr_raw devuelve el parámetro buffer, y nunca NULL.

EJEMPLOS

El siguiente ejemplo conecta un socket al puerto 80 en la dirección 127.0.0.1.

unsigned char addr[] = "\0x7f\0x00\0x00\0x01";
ne_inet_addr *ia;
ia = ne_iaddr_make(ne_iaddr_ipv4, addr);
if (ia != NULL) {
    ne_socket *sock = ne_sock_connect(ia, 80);
    ne_iaddr_free(ia);
    /* ... */
} else {
    /* ... */
}
