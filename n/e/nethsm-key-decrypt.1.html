NOMBRE

nethsm-key-decrypt - Descifra un mensaje usando una clave

SINOPSIS

nethsm key decrypt [-f|--force] [-i|--initialization-vector] [-o|--output] [-a|--auth-passphrase-file] [-c|--config] [-l|--label] [-u|--user] [-h|--help] <ID_CLAVE> <MENSAJE> [MODO_DESCIFRADO]

DESCRIPCIÓN

Descifra un mensaje usando una clave

El modo de descifrado elegido debe coincidir con la clave de destino y el vector de inicialización (si es aplicable) debe ser idéntico al utilizado para el cifrado.

Los usuarios de todo el sistema en el rol de "Operador" solo pueden descifrar mensajes usando claves de todo el sistema. Los usuarios con espacios de nombres en el rol de "Operador" solo pueden descifrar mensajes usando claves de su propio espacio de nombres.

Requiere autenticación de un usuario en el rol de "Operador" que tenga acceso (ver "nethsm key tag" y "nethsm user tag") a la clave de destino.

OPCIONES

-f, --force
Escribe en el archivo de salida incluso si ya existe
También se puede especificar con la variable de entorno NETHSM_FORCE.
-i, --initialization-vector <VECTOR_INICIALIZACION>
La ruta a un archivo que contiene el vector de inicialización (IV) para el descifrado simétrico.

El IV solo se puede usar al elegir el descifrado simétrico (es decir, con "AesCbc").

También se puede especificar con la variable de entorno NETHSM_KEY_DECRYPT_IV.
-o, --output <SALIDA>
La ruta a un archivo específico donde escribir el mensaje descifrado
También se puede especificar con la variable de entorno NETHSM_KEY_DECRYPT_OUTPUT.
-a, --auth-passphrase-file <ARCHIVO_CONTRASENA_AUTENTICACION>
La ruta a un archivo que contiene una contraseña para la autenticación.

La contraseña proporcionada en el archivo debe ser la del usuario elegido para el comando.

Esta opción se puede proporcionar varias veces, lo cual es necesario para comandos que requieren varios roles a la vez. Con varios archivos de contraseña, el orden importa, ya que los archivos se asignan al usuario respectivo proporcionado por la opción "--user".

También se puede especificar con la variable de entorno NETHSM_AUTH_PASSPHRASE_FILE.
-c, --config <CONFIGURACION>
La ruta a un archivo de configuración personalizado.

Si se especifica, se utiliza el archivo de configuración personalizado en lugar de la ubicación predeterminada del archivo de configuración.

También se puede especificar con la variable de entorno NETHSM_CONFIG.
-l, --label <ETIQUETA>
Una etiqueta que identifica de forma única un dispositivo en el archivo de configuración.

Debe proporcionarse si hay más de un dispositivo configurado en el archivo de configuración.

También se puede especificar con la variable de entorno NETHSM_LABEL.
-u, --user <USUARIO>
Un nombre de usuario que se utiliza para un comando.

Se puede proporcionar si no hay un nombre de usuario configurado en el archivo de configuración para un dispositivo. Debe proporcionarse si hay varios nombres de usuario del mismo rol de destino configurados en el archivo de configuración para un dispositivo.

Esta opción se puede proporcionar varias veces, lo cual es necesario para comandos que requieren varios roles a la vez.

También se puede especificar con la variable de entorno NETHSM_USER.
-h, --help
Imprime la ayuda (ver un resumen con '-h')
<ID_CLAVE>
El ID de la clave a utilizar para el descifrado.
También se puede especificar con la variable de entorno NETHSM_KEY_ID.
<MENSAJE>
La ruta a un mensaje cifrado para descifrar.
También se puede especificar con la variable de entorno NETHSM_KEY_DECRYPT_MESSAGE.
[MODO_DESCIFRADO]
El modo de descifrado a utilizar.

Uno de ["AesCbc", "OaepMd5", "OaepSha1", "OaepSha224", "OaepSha256", "OaepSha384", "OaepSha512", "Pkcs1", "Raw"] (por defecto es "Raw").

También se puede especificar con la variable de entorno NETHSM_KEY_DECRYPT_MODE.
