netlink(3) Manual de funciones de biblioteca netlink(3)

NOMBRE

netlink - Macros de Netlink

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <asm/types.h>
#include <linux/netlink.h>
int NLMSG_ALIGN(size_t size);
int NLMSG_LENGTH(size_t size);
int NLMSG_SPACE(size_t size);
void *NLMSG_DATA(struct nlmsghdr *nlh);
struct nlmsghdr *NLMSG_NEXT(struct nlmsghdr *nlh, int size);
int NLMSG_OK(struct nlmsghdr *nlh, int size);
int NLMSG_PAYLOAD(struct nlmsghdr *nlh, int size);

DESCRIPCIÓN

<linux/netlink.h> define varias macros estándar para acceder o crear un datagrama Netlink. Son similares en espíritu a las macros definidas en cmsg(3) para datos auxiliares. El búfer pasado hacia y desde un socket Netlink solo debe accederse utilizando estas macros.

NLMSG_ALIGN()
Redondea el tamaño de un mensaje Netlink hacia arriba para alinearlo correctamente.
NLMSG_LENGTH()
Dado el tamaño de la carga útil, size, esta macro devuelve el tamaño alineado para almacenarlo en el campo nlmsg_len del nlmsghdr.
NLMSG_SPACE()
Devuelve el número de bytes que ocuparía un mensaje Netlink con una carga útil de size.
NLMSG_DATA()
Devuelve un puntero a la carga útil asociada con el nlmsghdr pasado.
NLMSG_NEXT()
Obtiene el siguiente nlmsghdr en un mensaje multipart. El llamante debe verificar si el nlmsghdr actual no tenía NLMSG_DONE establecido; esta función no devuelve NULL al final. El argumento size es una expresión lvalue que contiene el tamaño restante del búfer del mensaje. Esta macro lo decrementa por el tamaño de la cabecera del mensaje.
NLMSG_OK()
Devuelve verdadero si el mensaje Netlink no está truncado y tiene un formato adecuado para su análisis.
NLMSG_PAYLOAD()
Devuelve el tamaño de la carga útil asociada con el nlmsghdr.

VERSIONES

A menudo es mejor usar Netlink a través de libnetlink que a través de la interfaz de bajo nivel del kernel.

ESTÁNDARES

Linux.
