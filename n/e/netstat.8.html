NETSTAT(8) Manual de Administrador de Sistemas de Linux NETSTAT(8)

NOMBRE

netstat - Imprime conexiones de red, tablas de enrutamiento, estadísticas de interfaces, conexiones de masquerading y membresías de multicast

SINOPSIS

netstat [opciones_familia_direccion] [--tcp|-t] [--udp|-u] [--udplite|-U] [--sctp|-S] [--raw|-w] [--l2cap|-2] [--rfcomm|-f] [--listening|-l] [--all|-a] [--numeric|-n] [--numeric-hosts] [--numeric-ports] [--numeric-users] [--symbolic|-N] [--extend|-e[--extend|-e]] [--timers|-o] [--program|-p] [--verbose|-v] [--continuous|-c] [--wide|-W]

netstat {--route|-r} [opciones_familia_direccion] [--extend|-e[--extend|-e]] [--verbose|-v] [--numeric|-n] [--numeric-hosts] [--numeric-ports] [--numeric-users] [--continuous|-c]

netstat {--interfaces|-i} [--all|-a] [--extend|-e[--extend|-e]] [--verbose|-v] [--program|-p] [--numeric|-n] [--numeric-hosts] [--numeric-ports] [--numeric-users] [--continuous|-c]

netstat {--groups|-g} [--numeric|-n] [--numeric-hosts] [--numeric-ports] [--numeric-users] [--continuous|-c]

netstat {--masquerade|-M} [--extend|-e] [--numeric|-n] [--numeric-hosts] [--numeric-ports] [--numeric-users] [--continuous|-c]

netstat {--statistics|-s} [--tcp|-t] [--udp|-u] [--udplite|-U] [--sctp|-S] [--raw|-w]

netstat {--version|-V}

netstat {--help|-h}

opciones_familia_direccion:

[-4|--inet] [-6|--inet6] [--protocol={inet,inet6,unix,ipx,ax25,netrom,ddp,bluetooth, ... } ] [--unix|-x] [--inet|--ip|--tcpip] [--ax25] [--x25] [--rose] [--ash] [--bluetooth] [--ipx] [--netrom] [--ddp|--appletalk] [--econet|--ec]

NOTAS

Este programa está mayormente obsoleto. El reemplazo para netstat es ss. El reemplazo para netstat -r es ip route. El reemplazo para netstat -i es ip -s link. El reemplazo para netstat -g es ip maddr.

DESCRIPCIÓN

Netstat imprime información sobre el subsistema de red de Linux. El tipo de información que se imprime está controlado por el primer argumento, de la siguiente manera:

(ninguno)

Por defecto, netstat muestra una lista de sockets abiertos. Si no se especifica ninguna familia de direcciones, se imprimirán los sockets activos de todas las familias de direcciones configuradas.

--route, -r

Muestra las tablas de enrutamiento del kernel. Ver la descripción en route(8) para más detalles. netstat -r y route -e producen la misma salida.

--groups, -g

Muestra información de membresía de grupos de multicast para IPv4 e IPv6.

--interfaces, -i

Muestra una tabla de todas las interfaces de red.

--masquerade, -M

Muestra una lista de conexiones enmascaradas.

--statistics, -s

Muestra estadísticas resumidas para cada protocolo.

OPCIONES

--verbose, -v

Informa al usuario sobre lo que está sucediendo siendo verboso. Especialmente imprime información útil sobre familias de direcciones no configuradas.

--wide, -W

No trunca direcciones IP utilizando una salida tan ancha como sea necesario. Esto es opcional por ahora para no romper scripts existentes.

--numeric, -n

Muestra direcciones numéricas en lugar de intentar determinar nombres simbólicos de host, puerto o usuario.

--numeric-hosts

Muestra direcciones de host numéricas pero no afecta la resolución de nombres de puerto o usuario.

--numeric-ports

Muestra números de puerto numéricos pero no afecta la resolución de nombres de host o usuario.

--numeric-users

Muestra IDs de usuario numéricos pero no afecta la resolución de nombres de host o puerto.

--protocol=familia, -A

Especifica las familias de direcciones (quizás mejor descritas como protocolos de bajo nivel) para las cuales se mostrarán las conexiones. familia es una lista separada por comas (',') de palabras clave de familia de direcciones como inet, inet6, unix, ipx, ax25, netrom, econet, ddp, y bluetooth. Esto tiene el mismo efecto que usar las opciones --inet|-4, --inet6|-6, --unix|-x, --ipx, --ax25, --netrom, --ddp, y --bluetooth.

La familia de direcciones inet (IPv4) incluye sockets de protocolo raw, udp, udplite y tcp.

La familia de direcciones bluetooth (IPv4) incluye sockets de protocolo l2cap y rfcomm.

-c, --continuous

Esto hará que netstat imprima la información seleccionada continuamente cada segundo.

-e, --extend

Muestra información adicional. Utilice esta opción dos veces para obtener el máximo detalle.

-o, --timers

Incluye información relacionada con temporizadores de red.

-p, --program

Muestra el PID y el nombre del programa al que pertenece cada socket. Se muestra un guion si el socket pertenece al kernel (por ejemplo, un servicio del kernel, o el proceso ha salido pero el socket aún no ha terminado de cerrarse).

-l, --listening

Muestra solo los sockets en escucha. (Estos se omiten por defecto).

-a, --all

Muestra tanto los sockets en escucha como los que no lo están. Con la opción --interfaces, muestra las interfaces que no están activas

-F

Imprime información de enrutamiento de la FIB. (Esto es lo predeterminado).

-C

Imprime información de enrutamiento de la caché de enrutamiento.

SALIDA

Conexiones de Internet activas (TCP, UDP, UDPLite, raw)

Proto

El protocolo (tcp, udp, udpl, raw) utilizado por el socket.

Recv-Q

Establecido: El recuento de bytes no copiados por el programa de usuario conectado a este socket. En escucha: Desde el Kernel 2.6.18, esta columna contiene la cola syn actual.

Sen

Establecido: El recuento de bytes en la cola de transmisión que aún no han sido enviados por el programa de usuario.

Dirección Local

La dirección y el número de puerto de la dirección local. Si la opción --numeric (o -n) está activa, entonces las direcciones se imprimen en formato numérico.

Dirección Remota

La dirección y el número de puerto de la dirección remota. Si la opción --numeric (o -n) está activa, entonces las direcciones se imprimen en formato numérico.

Estado

El estado del socket como TCP_ESTABLISHED, TCP_LISTEN, TCP_SYN_SENT, TCP_SYN_RECV, TCP_FIN_WAIT1, TCP_FIN_WAIT2, TCP_TIME_WAIT, TCP_CLOSE, TCP_CLOSE_WAIT, TCP_LAST_ACK, TCP_NEW_SYN_RECV, o desconocido.

PID/Nombre del programa

El ID del proceso y el nombre del programa al que pertenece el socket.

Interfaz

La interfaz de red que se utiliza para la conexión.

Salida de --extend -e

Con la opción -e, también se imprimen el usuario propietario del socket, y el Inode del socket. Con -ee, también se imprimen el tiempo de inicio y el tiempo de vida restante del socket, junto con la información del temporizador de transmisión.

EJEMPLOS

Mostrar todas las conexiones TCP activas y los sockets en escucha en formato numérico:

netstat -ant

Mostrar todos los sockets (TCP, UDP, y UNIX domain sockets) en escucha:

netstat -a

Mostrar todas las conexiones TCP y UDP con la información del programa:

netstat -tulap

Mostrar la tabla de enrutamiento:

netstat -r

Mostrar estadísticas de interfaces:

netstat -i

Mostrar estadísticas de interfaces en formato extendido:

netstat -ie

Mostrar estadísticas de protocolos:

netstat -s

Mostrar estadísticas de protocolo TCP:

netstat -st

VER TAMBIÉN

ss(8), ip(8), route(8)

d-Q

Establecido: El número de bytes no confirmados por el host remoto. En escucha: Desde el Kernel 2.6.18 esta columna contiene el tamaño máximo de la cola de syn.

Dirección Local

Dirección y número de puerto del extremo local del socket. A menos que se especifique la opción --numeric (-n), la dirección del socket se resuelve a su nombre de host canónico (FQDN) y el número de puerto se traduce al nombre de servicio correspondiente.

Dirección Remota

Dirección y número de puerto del extremo remoto del socket. Análogo a "Dirección Local".

Estado

El estado del socket. Dado que no hay estados en modo raw y generalmente no hay estados usados en UDP y UDPLite, esta columna puede dejarse en blanco. Normalmente puede ser uno de varios valores:

ESTABLECIDO
El socket tiene una conexión establecida.
SYN_SENT
El socket está intentando activamente establecer una conexión.
SYN_RECV
Se ha recibido una solicitud de conexión desde la red.
FIN_WAIT1
El socket está cerrado y la conexión se está cerrando.
FIN_WAIT2
La conexión está cerrada y el socket está esperando un cierre del extremo remoto.
TIME_WAIT
El socket está esperando después del cierre para manejar paquetes que aún están en la red.
CLOSE
El socket no se está utilizando.
CLOSE_WAIT
El extremo remoto ha cerrado, esperando que el socket se cierre.
LAST_ACK
El extremo remoto ha cerrado y el socket está cerrado. Esperando confirmación.
LISTEN
El socket está escuchando conexiones entrantes. Dichos sockets no se incluyen en la salida a menos que especifique la opción --listening (-l) o --all (-a).
CLOSING
Ambos sockets están cerrados pero todavía no hemos enviado todos nuestros datos.
UNKNOWN
El estado del socket es desconocido.

Usuario

El nombre de usuario o el id de usuario (UID) del propietario del socket.

PID/Nombre del programa

Par separado por barras del ID de proceso (PID) y el nombre del proceso que posee el socket. --program hace que esta columna se incluya. También necesitará privilegios de superusuario para ver esta información en sockets que no posea. Esta información de identificación aún no está disponible para sockets IPX.

Temporizador

Temporizador TCP asociado a este socket. El formato es timer(a/b/c). El temporizador es uno de los siguientes valores:

off
No hay ningún temporizador establecido para este socket.
on
El temporizador de retransmisión está activo para el socket.
keepalive
El temporizador de keepalive está activo para el socket.
timewait
La conexión se está cerrando y el temporizador timewait está activo para el socket.

Los valores entre corchetes:

a
Valor del temporizador.
b
Número de retransmisiones enviadas.
c
Número de keepalives enviados.

Sockets Activos de Dominio UNIX

Proto

El protocolo (generalmente unix) utilizado por el socket.

RefCnt

El contador de referencias (es decir, procesos adjuntos a través de este socket).

Flags

Las flags mostradas son SO_ACCEPTON (mostrado como ACC), SO_WAITDATA (W) o SO_NOSPACE (N). SO_ACCECPTON se utiliza en sockets no conectados si sus procesos correspondientes están esperando una solicitud de conexión. Las otras flags no son de interés normal.

Tipo

Hay varios tipos de acceso a sockets:

SOCK_DGRAM
El socket se utiliza en modo Datagrama (sin conexión).
SOCK_STREAM
Este es un socket de flujo (conexión).
SOCK_RAW
El socket se utiliza como un socket raw.
SOCK_RDM
Este sirve mensajes entregados de forma fiable.
SOCK_SEQPACKET
Este es un socket de paquetes secuenciales.
SOCK_PACKET
Socket de acceso a interfaz raw.
DESCONOCIDO
Quién sabe lo que nos traerá el futuro, ¡simplemente rellena aquí :-)

Estado

Este campo contendrá una de las siguientes palabras clave:

FREE
El socket no está asignado.
LISTENING
El socket está escuchando una solicitud de conexión. Dichos sockets solo se incluyen en la salida si especifica la opción --listening (-l) o --all (-a).
CONNECTING
El socket está a punto de establecer una conexión.
CONNECTED
El socket está conectado.
DISCONNECTING
El socket se está desconectando.
(vacío)
El socket no está conectado a otro.
DESCONOCIDO
Este estado nunca debería ocurrir.

PID/Nombre del programa

ID de proceso (PID) y nombre del proceso que tiene el socket abierto. Más información disponible en la sección Conexiones activas de Internet escrita anteriormente.

Ruta

Este es el nombre de ruta en el que se adjuntaron los procesos correspondientes al socket.

ARCHIVOS

/etc/services -- El archivo de traducción de servicios

/proc -- Punto de montaje para el sistema de archivos proc, que da acceso a la información de estado del kernel a través de los siguientes archivos.

/proc/net/dev -- información del dispositivo

/proc/net/raw -- información de sockets raw

/proc/net/tcp -- información de sockets TCP

/proc/net/udp -- información de sockets UDP

/proc/net/udplite -- información de sockets UDPLite

/proc/net/igmp -- información de multicast IGMP

/proc/net/unix -- información de sockets de dominio Unix

/proc/net/ipx -- información de sockets IPX

/proc/net/ax25 -- información de sockets AX25

/proc/net/appletalk -- información de sockets DDP (appletalk)

/proc/net/nr -- información de sockets NET/ROM

/proc/net/route -- información de enrutamiento IP

/proc/net/ax25_route -- información de enrutamiento AX25

/proc/net/ipx_route -- información de enrutamiento IPX

/proc/net/nr_nodes -- lista de nodos NET/ROM

/proc/net/nr_neigh -- vecinos NET/ROM

/proc/net/ip_masquerade -- conexiones enmascaradas

/sys/kernel/debug/bluetooth/l2cap -- información L2CAP de Bluetooth

/sys/kernel/debug/bluetooth/rfcomm -- conexiones seriales de Bluetooth

/proc/net/snmp -- estadísticas

BUGS

Ocasionalmente puede aparecer información extraña si un socket cambia mientras se visualiza. Esto es poco probable que ocurra.
