newlocale(3) Manual de Funciones de Biblioteca newlocale(3)

NOMBRE

newlocale, freelocale - crear, modificar y liberar un objeto de localización

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <locale.h>
locale_t newlocale(int category_mask, const char *locale,
                   locale_t base);
void freelocale(locale_t locobj);
Requisitos de Macro de Prueba de Funciones para glibc (ver feature_test_macros(7)):

newlocale(), freelocale():

    Desde glibc 2.10:
        _XOPEN_SOURCE >= 700
    Antes de glibc 2.10:
        _GNU_SOURCE

DESCRIPCIÓN

La función newlocale() crea un nuevo objeto de localización, o modifica uno existente, devolviendo una referencia al objeto nuevo o modificado como resultado de la función. Si la llamada crea un nuevo objeto o modifica uno existente se determina por el valor de base:

•
Si base es (locale_t) 0, se crea un nuevo objeto.
•
Si base se refiere a un objeto de localización existente válido (es decir, un objeto devuelto por una llamada anterior a newlocale() o duplocale(3)), entonces ese objeto se modifica con la llamada. Si la llamada tiene éxito, el contenido de base no se especifica (en particular, el objeto al que se refiere base puede ser liberado y se puede crear uno nuevo). Por lo tanto, el llamador debe asegurarse de dejar de usar base antes de la llamada a newlocale(), y posteriormente debería referirse al objeto modificado a través de la referencia devuelta como resultado de la función. Si la llamada falla, el contenido de base permanece válido y sin cambios.

Si base es el objeto de localización especial LC_GLOBAL_LOCALE (ver duplocale(3)), o no es (locale_t) 0 y no es un manejador de objeto de localización válido, el comportamiento no está definido.

El argumento category_mask es una máscara de bits que especifica las categorías de localización que se establecerán en un objeto de localización recién creado o se modificarán en uno existente. La máscara se construye mediante un OR bit a bit de las constantes LC_ADDRESS_MASK, LC_CTYPE_MASK, LC_COLLATE_MASK, LC_IDENTIFICATION_MASK, LC_MEASUREMENT_MASK, LC_MESSAGES_MASK, LC_MONETARY_MASK, LC_NUMERIC_MASK, LC_NAME_MASK, LC_PAPER_MASK, LC_TELEPHONE_MASK y LC_TIME_MASK. Alternativamente, la máscara se puede especificar como LC_ALL_MASK, que es equivalente a hacer un OR de todas las constantes anteriores.

Para cada categoría especificada en category_mask, los datos de localización de locale se utilizarán en el objeto devuelto por newlocale(). Si se está creando un nuevo objeto de localización, los datos para todas las categorías no especificadas en category_mask se toman de la localización predeterminada ("POSIX").

Los siguientes valores preestablecidos de locale están definidos para todas las categorías que se pueden especificar en category_mask:

"POSIX"
Un entorno de localización mínimo para programas en lenguaje C.
"C"
Equivalente a "POSIX".
""
Un entorno nativo definido por la implementación que corresponde a los valores de las variables de entorno LC_* y LANG (ver locale(7)).

freelocale()

La función freelocale() desasigna los recursos asociados con locobj, un objeto de localización devuelto previamente por una llamada a newlocale() o duplocale(3). Si locobj es LC_GLOBAL_LOCALE o no es un manejador de objeto de localización válido, los resultados no están definidos.

Una vez que se ha liberado un objeto de localización, el programa no debe hacer ningún uso adicional del mismo.

VALOR DE RETORNO

En caso de éxito, newlocale() devuelve un manejador que se puede usar en llamadas a duplocale(3), freelocale() y otras funciones que toman un argumento locale_t. En caso de error, newlocale() devuelve (locale_t) 0, y establece errno para indicar el error.

ERRORES

EINVAL
Uno o más bits en category_mask no corresponden a una categoría de localización válida.
EINVAL
locale es NULL.
ENOENT
locale no es un puntero de cadena que se refiera a una localización válida.
ENOMEM
Memoria insuficiente para crear un objeto de localización.

ESTANDARES

POSIX.1-2008.

HISTORIAL

glibc 2.3.

NOTAS

Cada objeto de localización creado por newlocale() debe ser desasignado usando freelocale().

EJEMPLOS

El programa a continuación toma hasta dos argumentos de línea de comandos, que cada uno identifica una localización. El primer argumento es obligatorio y se utiliza para establecer la categoría LC_NUMERIC en un objeto de localización creado usando newlocale(). El segundo argumento de línea de comandos es opcional; si está presente, se utiliza para establecer la categoría LC_TIME del objeto de localización.

Habiendo creado e inicializado el objeto de localización, el programa lo aplica usando uselocale(3), y luego prueba el efecto de los cambios de localización mediante:

(1)
Mostrar un número de punto flotante con parte fraccionaria. Esta salida se verá afectada por la configuración de LC_NUMERIC. En muchas localizaciones de idiomas europeos, la parte fraccionaria del número se separa de la parte entera usando una coma, en lugar de un punto.
(2)
Mostrar la fecha. El formato y el idioma de la salida se verán afectados por la configuración de LC_TIME.

Las siguientes sesiones de shell muestran algunos ejemplos de ejecución de este programa.

Establecer la categoría LC_NUMERIC a fr_FR (francés):


$ ./a.out fr_FR;
123456,789
Fri Mar  7 00:25:08 2014

Establecer la categoría LC_NUMERIC a fr_FR (francés), y la categoría LC_TIME a it_IT (italiano):


$ ./a.out fr_FR it_IT;
123456,789
ven 07 mar 2014 00:26:01 CET

Especificar la configuración de LC_TIME como una cadena vacía, lo que hace que el valor se tome de la configuración de la variable de entorno (que, aquí, especifica mi_NZ, Maorí de Nueva Zelanda):


$ LC_ALL=mi_NZ ./a.out fr_FR ""
123456,789
Te Paraire, te 07 o Poutū-te-rangi, 2014 00:38:44 CET

EXAMPLES

The following program demonstrates the use of newlocale():

#include <err.h>
#include <locale.h>
#include <stdio.h>
#include <stdlib.h>
#include <time.h>
#include <time.h>

int
main(int argc, char *argv[])
{
    locale_t loc, nloc;
    time_t t;
    struct tm *tm;
    char buf[100];
    size_t s;
    double d = 123456.789;

    /* Create a new locale object representing the default C locale.  */
    loc = newlocale(LC_ALL_MASK, "C", (locale_t) 0);
    if (loc == (locale_t) 0)
        err(EXIT_FAILURE, "newlocale");

    /* Set the new locale for this thread.  */
    uselocale(loc);

    /* Test effect of LC_NUMERIC.  */
    printf("%8.3f\n", d);
    /* Test effect of LC_TIME.  */
    t = time(NULL);
    tm = localtime(&t);
    if (tm == NULL)
        err(EXIT_FAILURE, "localtime");
    s = strftime(buf, sizeof(buf), "%c", tm);
    if (s == 0)
        err(EXIT_FAILURE, "strftime");
    printf("%s\n", buf);

    /* If a second argument is provided, create a new locale object
       based on the specified locale string and replace the current
       locale with it.  Free the old locale object.  */
    if (argc > 2) {
        nloc = newlocale(LC_TIME_MASK, argv[2], loc);
        if (nloc == (locale_t) 0)
            err(EXIT_FAILURE, "newlocale");
        loc = nloc;
    }
    /* Apply the newly created locale to this thread.  */
    uselocale(loc);
    /* Test effect of LC_NUMERIC.  */
    printf("%8.3f\n", 123456.789);
    /* Test effect of LC_TIME.  */
    t = time(NULL);
    tm = localtime(&t);
    if (tm == NULL)
        err(EXIT_FAILURE, "time");
    s = strftime(buf, sizeof(buf), "%c", tm);
    if (s == 0)
        err(EXIT_FAILURE, "strftime");
    printf("%s\n", buf);
    /* Free the locale object.  */
    uselocale(LC_GLOBAL_LOCALE);    /* So 'loc' is no longer in use */
    freelocale(loc);
    exit(EXIT_SUCCESS);
}
