DESCRIPCIÓN

Estas funciones definen un subconjunto de la API que se puede utilizar para gestionar sesiones SNMP individuales en una aplicación multihilo. Excepto snmp_sess_session(), estas funciones son versiones de sesión única de la API tradicional de la biblioteca SNMP.

Tenga en cuenta que estas funciones utilizan un puntero opaco (handle en los prototipos anteriores) para identificar una sesión individual en lugar de un puntero session (como en la API tradicional).

snmp_sess_init() prepara una estructura `snmp_session` que contiene información de transporte y común que se utilizará para un conjunto de transacciones SNMP. Después de que esta estructura se pase a snmp_sess_open() para crear una sesión SNMP, la estructura ya no se utiliza. En su lugar, el puntero opaco devuelto por snmp_sess_open() se utiliza para referirse a esa sesión en adelante.

Las sesiones SNMP que se crean con snmp_sess_open() no se ven afectadas por, y NO DEBEN UTILIZARSE CON, snmp_select_info(), snmp_read(), snmp_timeout() ni snmp_close(). Más bien, se deben utilizar las funciones equivalentes de sesión única descritas aquí.

snmp_sess_init() y snmp_sess_open() toman como entrada un puntero a un objeto de estructura `snmp_session`. Esta estructura contiene información para un conjunto de transacciones que compartirán características de transporte similares. snmp_sess_session() toma el manejador de sesión opaco y devuelve un puntero a su `struct snmp_session` asociado.

snmp_sess_send() y snmp_sess_async_send() toman cada una un parámetro pdu, que apunta a un objeto `struct snmp_pdu` que contiene información que describe una transacción que se realizará a través de una sesión abierta.

Consulte snmp_api.h para ver las definiciones de estas estructuras.

Con la llamada snmp_sess_async_send(), snmp_sess_read invocará la función de devolución de llamada especificada cuando se reciba la respuesta.

snmp_sess_select_info(), snmp_sess_read() y snmp_sess_timeout() proporcionan una interfaz para el uso de la llamada al sistema select(2) para que las transacciones SNMP de una sesión individual puedan ocurrir de forma asíncrona.

A snmp_sess_select_info() se le pasa la información que se habría pasado a select(2) en ausencia de SNMP. Por ejemplo, esto podría incluir descriptores de archivo asociados con el bucle principal de una aplicación gráfica. Esta información se modifica para que SNMP obtenga el servicio que requiere de la llamada a select(2). En este caso, numfds, fdset y timeout corresponden a los argumentos nfds, readfds y timeout de select(2), respectivamente. La única excepción es que `timeout` siempre debe apuntar a un `struct timeval` asignado (pero quizás no inicializado) (no puede ser NULL como para select(2)). Si `timeout` se hubiera pasado como NULL, block se establece en true, y `timeout` se trata como indefinido. La misma regla se aplica al regresar de snmp_select_info().

Después de llamar a snmp_sess_select_info(), se debe llamar a select(2) con los datos devueltos. Cuando regrese, se debe llamar a snmp_sess_read() con el fd_set devuelto por select(2). Esto leerá cualquier entrada del socket SNMP de esta sesión. Si select(2) expira (es decir, devuelve cero), se debe llamar a snmp_sess_timeout() para ver si ha expirado el tiempo de espera en la sesión SNMP.

snmp_sess_synch_response es una rutina de conveniencia que enviará la solicitud, esperará la respuesta y la procesará antes de devolver. Consulte las descripciones de snmp_sess_send , snmp_sess_read etc. para obtener detalles.

DIAGNÓSTICO

El estado de retorno de error de snmp_sess_open() se indica mediante la devolución de un puntero NULL. El estado de retorno de error de snmp_sess_close() y snmp_sess_send() se indica mediante un valor de retorno de 0. Un estado exitoso devolverá 1.

Se puede obtener más información utilizando snmp_sess_error() para ver qué tipo de error ha ocurrido. Esta función devuelve la variable SNMP snmp_errno, el valor de la variable del sistema errno y una interpretación en cadena de ambas variables. La cadena debe ser liberada después de su uso por el llamador.

Para los errores devueltos por snmp_sess_open(), utilice la función correspondiente snmp_error() en lugar de snmp_sess_error().

NAME

netsnmp_sess_api - Net-SNMP session API

SYNOPSIS

#include <net-snmp/net-snmp-includes.h>

Session management functions for the Net-SNMP library.

DESCRIPTION

This API provides functions for creating, opening, closing, and managing Net-SNMP sessions. These sessions are used to communicate with SNMP agents on remote hosts.

Key functions include:

netsnmp_open_session
Opens a new SNMP session with the specified parameters.
netsnmp_close_session
Closes an existing SNMP session.
netsnmp_session_peer_addr
Retrieves the peer address of the session.
netsnmp_session_peer_port
Retrieves the peer port of the session.
netsnmp_session_get_peername
Gets the peer name associated with the session.
netsnmp_sess_api_version
Returns the version of the session API.

DIAGNOSTICS

Errors are returned as integer codes or through specific error handling functions. Common error codes include:

SNMPERR_UNKNOWN_PDU
SNMPERR_TIMEOUT
