NOMBRE

nemo-connect-server - Acceder a un servidor remoto

SINOPSIS

nemo-connect-server [opciones] [URI]

DESCRIPCIÓN

Esta página del manual documenta brevemente el comando nemo-connect-server.

Nemo Connect Server es el gestor de conexión para el escritorio GNOME.

Puedes usar el gestor de archivos para acceder a un servidor remoto, ya sea un sitio FTP, un recurso compartido de Windows, un servidor WebDav o un servidor SSH.

OPCIONES

Nemo sigue la sintaxis habitual de línea de comandos de GNU, con opciones largas que empiezan con dos guiones (`-'). A continuación se incluye un resumen de las opciones.

--help
Mostrar un resumen de las opciones.
--version
Mostrar la versión.
También se admiten otras opciones estándar de GNOME que no se enumeran aquí.

VER TAMBIÉN

La documentación de Nemo Connect Server se puede encontrar en el menú "Ayuda" o pulsando la tecla F1. Nemo también tiene un sitio web en http://www.gnome.org/projects/nemo/
