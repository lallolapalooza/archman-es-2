NOMBRE

neomutt - El Agente de Usuario de Correo (MUA) de NeoMutt

SINTAXIS

neomutt [-Enx] [-e comando] [-F config] [-H borrador] [-i incluir] [-b direccion] [-c direccion] [-s asunto] [-a archivo] ... [--] direccion ...
neomutt [-nx] [-e comando] [-F config] [-b direccion] [-c direccion] [-s asunto] [-a archivo] ... [--] direccion ... < mensaje
neomutt [-nRy] [-e comando] [-F config] [-f buzon] [-m tipo]
neomutt [-n] [-e comando] [-F config] -A alias
neomutt [-n] [-e comando] [-F config] -B
neomutt [-n] [-e comando] [-F config] -D [-S] [-O]
neomutt [-n] [-e comando] [-F config] -d nivel -l archivo
neomutt [-n] [-e comando] [-F config] -G
neomutt [-n] [-e comando] [-F config] -g servidor
neomutt [-n] [-e comando] [-F config] -p

neomutt [-n] [-e comando] [-F config] -z [-f buzon]
neomutt -v[v]

DESCRIPCIÓN

NeoMutt es un programa pequeño pero muy potente basado en texto para leer y enviar correo electrónico bajo sistemas operativos Unix, incluyendo soporte para terminales en color, MIME, OpenPGP y un modo de ordenación en árbol.

Nota: Esta página del manual ofrece una breve descripción general de las opciones de línea de comandos de NeoMutt. Deberías encontrar una copia del manual completo en /usr/share/doc/neomutt, en formato de texto plano, HTML y/o PDF.

OPCIONES

--
Argumento especial que fuerza a NeoMutt a detener el análisis de opciones y tratar los argumentos restantes como direcciones incluso si comienzan con un guion
-A alias
Imprime una versión expandida del alias dado a la salida estándar y sale
-a archivo
Adjunta uno o más archivos a un mensaje (debe ser la última opción). Agrega cualquier dirección después del argumento '--', por ejemplo:
neomutt -a imagen.jpg -- direccion1 
neomutt -a imagen.jpg *.png -- direccion1 direccion2
-b direccion
Especifica un destinatario de copia carbón oculta (Bcc)
-C
Habilita operaciones criptográficas en los casos en que están deshabilitadas por defecto. Estos incluyen:
  • Modo por lotes.
  • Envío de un mensaje pospuesto.
  • Reenvío de un mensaje.
-c direccion
Especifica un destinatario de copia carbón (Cc)
-D
Vuelca todas las variables de configuración como pares 'nombre=valor' a la salida estándar
-D -D
-DD Similar a -D, pero solo muestra la configuración que ha cambiado
-D -O
Similar a -D, pero muestra documentación en una línea
-D -S
Similar a -D, pero oculta el valor de las variables sensibles
-d nivel
Registra la salida de depuración en un archivo (por defecto es "~/.neomuttdebug0"). El nivel puede variar de 1 a 5 y afecta la verbosidad (se recomienda un valor de 2)
Usar esta opción junto con -l es útil para registrar el proceso inicial de inicio (antes de leer cualquier configuración y, por lo tanto, $debug_level y $debug_file)
-E
Edita el borrador (-H) o el archivo de inclusión (-i) durante la composición del mensaje
-e comando
Especifica un comando a ejecutar después de leer los archivos de configuración
-F config
Especifica un archivo de inicialización alternativo para leer, ver la sección ARCHIVOS a continuación para una lista de archivos de configuración regulares
-f buzon
Especifica un buzón (como se define con el comando mailboxes) para cargar
-G
Inicia NeoMutt con una lista de grupos de noticias suscritos
-g servidor
Similar a -G, pero comienza en el servidor de noticias especificado
-H borrador
Especifica un archivo de borrador que contiene la cabecera y el cuerpo para usar al enviar un mensaje. Si borrador es “-”, entonces los datos se leen de la entrada estándar. Se espera que el archivo de borrador contenga solo un correo electrónico RFC822 — cabeceras y un cuerpo. Aunque no es un archivo mbox, si está presente una línea de "From " de mbox, se descartará silenciosamente. Los archivos de borrador se procesan de la misma manera en modo interactivo y por lotes; no se pasan sin procesar. Por ejemplo, los archivos de borrador cifrados se descifrarán.
-h
Imprime este mensaje de ayuda y sale
-i incluir
Especifica un archivo de inclusión para ser incrustado en el cuerpo de un mensaje
-l archivo
Especifica un archivo para la salida de depuración (por defecto "~/.neomuttdebug0")
Esto anula la configuración de $debug_file y NeoMutt mantiene hasta cinco registros de depuración ({ archivo | $debug_file | ~/.neomuttdebug }[0-4]) antes de sobrescribir el archivo más antiguo
-m tipo
Especifica un formato de tipo de buzón predeterminado para las carpetas de nueva creación
El tipo es MH, MMDF, Maildir o mbox (sin distinción entre mayúsculas y minúsculas)
-n
No leer el archivo de configuración del sistema
-p
Reanuda un mensaje pospuesto anterior, si lo hay
-Q variable

neomutt(1)

NEOMUTT - un cliente de correo electrónico basado en texto

NOMBRE

neomutt - un cliente de correo electrónico basado en texto

SINOPSIS

neomutt [-A proveedor] [-a archivo adjunto] [-b] [-c cc] [-d archivo de buzón] [-e comando] [-F archivo de configuración] [-f archivo de buzón] [-H] [-h] [-i] [-l archivo de buzón] [-m proveedor] [-n] [-p archivo de buzón] [-q] [-r] [-s asunto] [-T] [-t] [-u] [-V] [-v] [-x archivo adjunto] [destinatario...]

DESCRIPCIÓN

neomutt es un cliente de correo electrónico de línea de comandos. Se basa en Mutt y proporciona una interfaz de usuario amigable para la lectura y escritura de correo electrónico, incluyendo soporte para IMAP, POP3 y otros protocolos.

Admite varias funciones como filtrado, carpetas, búsqueda, cifrado PGP/GPG, etc.

Consulte la documentación de Neomutt para obtener una descripción completa de sus funciones y configuración.

OPCIONES

-A, --account proveedor

Selecciona una cuenta de correo específico para usar.

-a, --attach archivo adjunto

Adjunta un archivo a un nuevo correo electrónico. Puede especificar varios argumentos -a.

-b, --blind-carbon-copy

Agrega el destinatario al campo CCO (copia carbón ciega) del correo electrónico.

-c, --cc cc

Agrega el destinatario al campo CC (copia carbón) del correo electrónico.

-d, --default-path archivo de buzón

Establece la ruta por defecto para los archivos de buzón.

-e, --exec comando

Ejecuta un comando de Neomutt después de la inicialización.

-F, --config-file archivo de configuración

Utiliza el archivo de configuración especificado en lugar del predeterminado.

-f, --folder archivo de buzón

Abre el archivo de buzón especificado.

-H, --display-hook

Muestra los ganchos de pantalla definidos.

-h, --help

Muestra un mensaje de ayuda y sale.

-i, --include

Incluye el contenido del correo electrónico original cuando se responde.

-l, --list-folder archivo de buzón

Lista los archivos de buzón en el directorio especificado.

-m, --mailboxes proveedor

Conéctate a un servidor de correo usando el proveedor especificado.

-n, --no-index

No genera un índice de carpetas.

-p, --print-folder archivo de buzón

Imprime el contenido del archivo de buzón especificado.

-q, --quit

Sale de Neomutt.

-r, --read-only

Abre los archivos de buzón en modo de solo lectura.

-s, --subject asunto

Establece el asunto de un nuevo correo electrónico.

-T, --display-macros

Muestra las macros definidas.

-t, --read-receipt

Solicita un recibo de lectura para el correo electrónico.

-u, --user-agent

Muestra la cadena del agente de usuario utilizada por Neomutt.

-V, --version

Muestra la información de la versión y sale.

-v, --verbose

Habilita la salida detallada para la depuración.

-x, --send-raw archivo adjunto

Envía el correo electrónico crudo del archivo especificado.

destinatario...

Direcciones de correo electrónico de los destinatarios principales del correo electrónico.

ENTORNO

NEOMUTT_HOME: Especifica el directorio donde se almacenan los archivos de configuración y datos de Neomutt. Si no se establece, se utiliza el directorio predeterminado (normalmente $HOME/.config/neomutt o $HOME/.neomutt).

COLORTERM: Determina el nivel de soporte de color de Neomutt. Puede ser truecolor, 24bit, 8bit o false.

ARCHIVOS

$HOME/.config/neomutt/neomuttrc

Archivo de configuración principal de Neomutt. Si no existe, se busca $HOME/.neomutt/neomuttrc.

$HOME/.config/neomutt/colors

Archivo de configuración de colores de Neomutt.

$HOME/.config/neomutt/sidebar.config

Archivo de configuración para la barra lateral.

$HOME/.mail/

Directorio predeterminado para almacenar archivos de buzón.

ERRORES

Informe de errores en https://github.com/neomutt/neomutt/issues.
