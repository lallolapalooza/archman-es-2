NOMBRE

nethsm-system - Realizar acciones del sistema para un dispositivo

SINOPSIS

nethsm system [-a|--auth-passphrase-file] [-c|--config] [-l|--label] [-u|--user] [-h|--help] <subcomandos>

DESCRIPCIÓN

Realizar acciones del sistema para un dispositivo

OPCIONES

-a, --auth-passphrase-file <ARCHIVO_CONTRASEÑA_AUTENTICACIÓN>
La ruta a un archivo que contiene una frase de contraseña para autenticación

La frase de contraseña proporcionada en el archivo debe ser la del usuario elegido para el comando.

Esta opción se puede proporcionar varias veces, lo cual es necesario para comandos que requieren varios roles a la vez. Con varios archivos de frase de contraseña, el orden importa, ya que los archivos se asignan al respectivo usuario proporcionado por la opción "--user".

También se puede especificar con la variable de entorno NETHSM_AUTH_PASSPHRASE_FILE.
-c, --config <CONFIGURACIÓN>
La ruta a un archivo de configuración personalizado

Si se especifica, se utiliza el archivo de configuración personalizado en lugar de la ubicación del archivo de configuración predeterminada.

También se puede especificar con la variable de entorno NETHSM_CONFIG.
-l, --label <ETIQUETA>
Una etiqueta que identifica de forma única un dispositivo en el archivo de configuración

Debe proporcionarse si hay más de un dispositivo configurado en el archivo de configuración.

También se puede especificar con la variable de entorno NETHSM_LABEL.
-u, --user <USUARIO>
Un nombre de usuario que se utiliza para un comando

Se puede proporcionar si no hay ningún nombre de usuario configurado en el archivo de configuración para un dispositivo. Debe proporcionarse si varios nombres de usuario del mismo rol de destino están configurados en el archivo de configuración para un dispositivo.

Esta opción se puede proporcionar varias veces, lo cual es necesario para comandos que requieren varios roles a la vez.

También se puede especificar con la variable de entorno NETHSM_USER.
-h, --help
Imprimir ayuda (ver un resumen con '-h')
