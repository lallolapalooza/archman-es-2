ne_get_error(3)

Paquete: neon

Licencias: LGPL-2.0-or-later

NE_GET_ERROR(3) Referencia de la API de neon NE_GET_ERROR(3)

NOMBRE

ne_get_error, ne_set_error - manejo de errores para sesiones HTTP

SINOPSIS

#include <ne_session.h>

const char *ne_get_error(ne_sesssion *session);

void ne_set_error(ne_sesssion *session, const char *format, ...);

DESCRIPCIÓN

La cadena de error de la sesión se utiliza para almacenar cualquier información de error legible por humanos asociada con cualquier error que ocurra durante el uso de la sesión HTTP.

La función ne_get_error devuelve la cadena de error de la sesión actual. Esta cadena solo persiste hasta que es cambiada por una operación posterior en la sesión. Si la localización se habilitó en el momento de la compilación y, si es necesario, se habilitó en tiempo de ejecución usando ne_i18n_init, la cadena devuelta puede haber sido traducida a la configuración regional actual del usuario.

La función ne_set_error se puede usar para establecer una nueva cadena de error de sesión, utilizando una interfaz de cadena de formato estilo printf.

VALOR DE RETORNO

ne_set_error devuelve una cadena constante terminada en NULO. En la configuración regional inglesa predeterminada, la cadena devuelta *no* tendrá un punto al final.

EJEMPLOS

Recuperar la cadena de error actual:

ne_session *sess = ne_session_create(...);
...
printf("El error fue: %s\n", ne_get_error(sess));

Establecer una nueva cadena de error:

ne_session *sess = ne_session_create(...);
...
ne_set_error(sess, "La respuesta carece de la cabecera %s", "unacadenamuy}\n ");
