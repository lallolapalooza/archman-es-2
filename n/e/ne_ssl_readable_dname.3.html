Licencias: LGPL-2.0-or-later

NE_SSL_DNAME(3) Referencia de la API de neon NE_SSL_DNAME(3)

NOMBRE

ne_ssl_readable_dname, ne_ssl_dname_cmp - manejo de nombres distinguidos SSL

SINOPSIS

#include <ne_ssl.h>

const char *ne_ssl_readable_dname(const ne_ssl_dname *dname);

int ne_ssl_dname_cmp(const ne_ssl_dname *dn1, const ne_ssl_dname *dn2);

DESCRIPCIÓN

La función ne_ssl_readable_dname crea una cadena de una sola línea y legible por humanos a partir de un objeto ne_ssl_dname. La cadena devuelta está asignada por malloc() y debe ser liberada con free() por el llamador.

La función ne_ssl_dname_cmp compara dos nombres distinguidos y devuelve cero si son iguales, o distinto de cero en caso contrario.

VALOR DE RETORNO

ne_ssl_readable_dname devuelve una cadena asignada con malloc y nunca devuelve NULL.

EJEMPLOS

Consulte ne_ssl_cert_subject para ver un ejemplo de uso de ne_ssl_readable_dname.
