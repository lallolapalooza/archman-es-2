NOMBRE

nethsm-key-generate - Generar una nueva clave

SINOPSIS

nethsm key generate [-L|--length] [-k|--key-id] [-t|--tags] [-a|--auth-passphrase-file] [-c|--config] [-l|--label] [-u|--user] [-h|--help] [TIPO_CLAVE] [MECANISMOS_CLAVE]

DESCRIPCIÓN

Generar una nueva clave

El tipo de clave y la lista de mecanismos de clave proporcionados deben coincidir: * "Rsa" requiere uno de [RsaDecryptionRaw, RsaDecryptionPkcs1, RsaDecryptionOaepMd5, RsaDecryptionOaepSha1, RsaDecryptionOaepSha224, RsaDecryptionOaepSha256, RsaDecryptionOaepSha384, RsaDecryptionOaepSha512, RsaSignaturePkcs1, RsaSignaturePssMd5, RsaSignaturePssSha1, RsaSignaturePssSha224, RsaSignaturePssSha256, RsaSignaturePssSha384, RsaSignaturePssSha512] * "Curve25519" requiere uno de [EdDsaSignature] * "EcP256", "EcP384" y "EcP521" requieren uno de [EcdsaSignature] * "Generic" requiere al menos uno de [AesDecryptionCbc, AesEncryptionCbc]

Los usuarios de todo el sistema con el rol de "Administrador" generan claves de todo el sistema. Los usuarios con espacios de nombres y el rol de "Administrador" generan claves en su propio espacio de nombres.

Nota: Aunque asignar etiquetas a la nueva clave es opcional, ¡es muy recomendable, ya que no hacerlo significa que todos los usuarios en el mismo ámbito tienen acceso a ella!

Requiere autenticación de un usuario en el rol de "Administrador".

OPCIONES

-L, --length <LONGITUD>
La longitud en bits opcional de la clave generada

Si no se proporciona ninguna, se elige una por defecto.

También se puede especificar con la variable de entorno NETHSM_KEY_BIT_LENGTH.
-k, --key-id <ID_CLAVE>
Un ID único opcional asignado a la clave generada

Si no se proporciona ninguno, se genera uno genérico para la clave.

También se puede especificar con la variable de entorno NETHSM_KEY_ID.
-t, --tags <ETIQUETAS>
Una lista opcional de etiquetas asignadas a la clave generada

Las etiquetas en las claves se utilizan para otorgar acceso a esas claves a los usuarios que tienen las mismas etiquetas.

También se puede especificar con la variable de entorno NETHSM_KEY_TAGS.
-a, --auth-passphrase-file <ARCHIVO_CONTRASEÑA_AUTENTICACION>
La ruta a un archivo que contiene una frase de contraseña para la autenticación

La frase de contraseña proporcionada en el archivo debe ser la del usuario elegido para el comando.

Esta opción se puede proporcionar varias veces, lo cual es necesario para comandos que requieren varios roles a la vez. Con varios archivos de frase de contraseña, el orden importa, ya que los archivos se asignan al usuario respectivo proporcionado por la opción "--user".

También se puede especificar con la variable de entorno NETHSM_AUTH_PASSPHRASE_FILE.
-c, --config <CONFIGURACION>
La ruta a un archivo de configuración personalizado

Si se especifica, se utiliza el archivo de configuración personalizado en lugar de la ubicación predeterminada del archivo de configuración.

También se puede especificar con la variable de entorno NETHSM_CONFIG.
-l, --label <ETIQUETA>
Una etiqueta que identifica de forma única un dispositivo en el archivo de configuración

Debe proporcionarse si hay más de un dispositivo configurado en el archivo de configuración.

También se puede especificar con la variable de entorno NETHSM_LABEL.
-u, --user <USUARIO>
Un nombre de usuario que se utiliza para un comando

Se puede proporcionar si no hay un nombre de usuario configurado en el archivo de configuración para un dispositivo. Debe proporcionarse si hay varios nombres de usuario del mismo rol de destino configurados en el archivo de configuración para un dispositivo.

Esta opción se puede proporcionar varias veces, lo cual es necesario para comandos que requieren varios roles a la vez.

También se puede especificar con la variable de entorno NETHSM_USER.
-h, --help
Imprime la ayuda (ver un resumen con '-h')
[TIPO_CLAVE]
El tipo de clave opcional a generar

¡El tipo de clave debe coincidir con los mecanismos de clave elegidos!

Uno de ["Curve25519", "EcP256", "EcP384", "EcP521", "Generic", "Rsa"] (el valor predeterminado es "Curve25519").

También se puede especificar con la variable de entorno NETHSM_KEY_TYPE.
[MECANISMOS_CLAVE]
Los mecanismos proporcionados por la clave generada

¡Los mecanismos de clave deben coincidir con el tipo de clave elegido!

Al menos uno de ["AesDecryptionCbc", "AesEncryptionCbc", "EcdsaSignature", "EdDsaSignature", "RsaDecryptionOaepMd5", "RsaDecryptionOaepSha1", "RsaDecryptionOaepSha224", "RsaDecryptionOaepSha256", "RsaDecryptionOaepSha384", "RsaDecryptionOaepSha512", "RsaDecryptionPkcs1", "RsaDecryptionRaw", "RsaSignaturePkcs1", "RsaSignaturePssMd5", "RsaSignaturePssSha1", "RsaSignaturePssSha224", "RsaSignaturePssSha256", "RsaSignaturePssSha384", "RsaSignaturePssSha512"] (el valor predeterminado es "EdDsaSignature").

También se puede especificar con la variable de entorno NETHSM_KEY_MECHANISMS.
