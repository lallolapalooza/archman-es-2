NOMBRE

netplan-status - consultar el estado de red del sistema en ejecución

SINOPSIS

netplan [--debug] status -h|--help

netplan [--debug] status [interfaz]

DESCRIPCIÓN

netplan status [interfaz] consulta la configuración de red actual y la muestra en formato legible para humanos.

Puede especificar interfaz para mostrar el estado de una interfaz específica.

Actualmente, netplan status depende de systemd-networkd como fuente de datos e intentará iniciarlo si no está enmascarado.

OPCIONES

-h, --help
Imprime ayuda básica.
--debug
Imprime salida de depuración durante el proceso.
-a, --all
Muestra todos los datos de la interfaz, incluidas las inactivas.
--diff
Analiza y muestra las diferencias entre la configuración actual del sistema y las definiciones de red presentes en los archivos YAML. La configuración analizada incluye direcciones IP, rutas, direcciones MAC, direcciones DNS, dominios de búsqueda e interfaces de red faltantes.

El formato de salida es similar a las herramientas de diff populares como diff y git diff. La configuración presente solo en el sistema (y, por lo tanto, ausente en el YAML de Netplan) se mostrará con un signo + y se resaltará en verde. La configuración presente solo en Netplan (y, por lo tanto, ausente en el sistema) se mostrará con un signo - y se resaltará en rojo. Lo mismo se aplica a las interfaces de red.

--diff-only
Igual que --diff pero omite toda la información que no sea una diferencia.
--root-dir
Lee los archivos YAML desde esta raíz en lugar de /.
--verbose
Muestra información adicional.
-f FORMATO, --format FORMATO
Salida en formato legible por máquina json o yaml.

VER TAMBIÉN

netplan(5), netplan-get(8), netplan-ip(8)
