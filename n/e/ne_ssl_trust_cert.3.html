ne_ssl_trust_cert(3)

Paquete: neon

Licencias: LGPL-2.0-or-later

NE_SSL_TRUST_CERT(3) Referencia de la API de neon NE_SSL_TRUST_CERT(3)

NOMBRE

ne_ssl_trust_cert, ne_ssl_trust_default_ca - funciones para indicar que los certificados son confiables

SINOPSIS

#include <ne_session.h>

void ne_ssl_trust_cert(ne_session *session, const ne_ssl_certificate *cert);

void ne_ssl_trust_default_ca(ne_session *session);

DESCRIPCIÓN

Para indicar que un certificado dado es confiable para el usuario, el objeto certificado puede ser pasado a ne_ssl_trust_cert. El objeto certificado se duplica internamente y posteriormente puede ser destruido.

La biblioteca SSL utilizada por neon puede incluir un conjunto predeterminado de certificados de CA; llamar a la función ne_ssl_trust_default_ca indicará que estas CA son confiables para el usuario.

EJEMPLOS

Cargar el certificado CA almacenado en /path/to/cacert.pem:

ne_session *sess = ne_session_create(...);
ne_ssl_certificate *cert = ne_ssl_cert_read("/path/to/cacert.pem");
if (cert) {
   ne_ssl_trust_cert(sess, cert);
   ne_ssl_cert_free(cert);
} else {
   printf("No se pudo cargar el certificado CA: %s\n", ne_get_error(sess));
}

HISTORIA

ne_ssl_trust_default_ca no es seguro llamarlo para sesiones no SSL en versiones de neon anteriores a la 0.33.0. En la versión 0.33.0 y posteriores, esta función no tiene efecto para sesiones no SSL.

VER TAMBIÉN

ne_session_create, ne_ssl_cert_read, ne_ssl_cert_import, ne_ssl_cert_free
