nextafter(3) Manual de funciones de biblioteca nextafter(3)

NOMBRE

nextafter, nextafterf, nextafterl, nexttoward, nexttowardf, nexttowardl - manipulación de números de punto flotante

BIBLIOTECA

Biblioteca matemática (libm, -lm)

SINOPSIS

#include <math.h>
double nextafter(double x, double y);
float nextafterf(float x, float y);
long double nextafterl(long double x, long double y);
double nexttoward(double x, long double y);
float nexttowardf(float x, long double y);
long double nexttowardl(long double x, long double y);
Requisitos de Macro de Prueba de Funciones para glibc (ver feature_test_macros(7)):

nextafter():

    _ISOC99_SOURCE || _POSIX_C_SOURCE >= 200112L
        || _XOPEN_SOURCE >= 500
        || /* Desde glibc 2.19: */ _DEFAULT_SOURCE
        || /* glibc <= 2.19: */ _BSD_SOURCE || _SVID_SOURCE

nextafterf(), nextafterl():

    _ISOC99_SOURCE || _POSIX_C_SOURCE >= 200112L
        || /* Desde glibc 2.19: */ _DEFAULT_SOURCE
        || /* glibc <= 2.19: */ _BSD_SOURCE || _SVID_SOURCE

nexttoward(), nexttowardf(), nexttowardl():

    _XOPEN_SOURCE >= 600 || _ISOC99_SOURCE
        || _POSIX_C_SOURCE >= 200112L

DESCRIPCIÓN

Las funciones nextafter(), nextafterf() y nextafterl() devuelven el siguiente valor de punto flotante representable después de x en la dirección de y. Si y es menor que x, estas funciones devolverán el número representable más grande menor que x.

Si x es igual a y, las funciones devuelven y.

Las funciones nexttoward(), nexttowardf() y nexttowardl() hacen lo mismo que las funciones nextafter() correspondientes, excepto que tienen un segundo argumento de tipo long double.

VALOR DE RETORNO

En caso de éxito, estas funciones devuelven el siguiente valor de punto flotante representable después de x en la dirección de y.

Si x es igual a y, se devuelve y (convertido al mismo tipo que x).

Si x o y es un NaN, se devuelve un NaN.

Si x es finito y el resultado desbordaría, ocurre un error de rango y las funciones devuelven HUGE_VAL, HUGE_VALF o HUGE_VALL, respectivamente, con el signo matemático correcto.

Si x no es igual a y, y el resultado correcto de la función sería subnormal, cero o estaría por debajo del límite (underflow), ocurre un error de rango y se devuelve el valor correcto (si se puede representar) o 0.0.

ERRORES

Ver math_error(7) para obtener información sobre cómo determinar si ha ocurrido un error al llamar a estas funciones.

Los siguientes errores pueden ocurrir:

Error de rango: desbordamiento del resultado
errno se establece en ERANGE. Se genera una excepción de punto flotante de desbordamiento (FE_OVERFLOW).
Error de rango: el resultado es subnormal o está por debajo del límite (underflow)
errno se establece en ERANGE. Se genera una excepción de punto flotante de subdesbordamiento (FE_UNDERFLOW).

ATRIBUTOS

Para obtener una explicación de los términos utilizados en esta sección, ver attributes(7).

Interfaz Atributo Valor
nextafter (), nextafterf (), nextafterl (), nexttoward (), nexttowardf (), nexttowardl () Seguridad de hilos MT-Safe

ESTÁNDARES

C11, POSIX.1-2008.

Esta función está definida en IEC 559 (y en el apéndice con funciones recomendadas en IEEE 754/IEEE 854).

HISTORIA

C99, POSIX.1-2001.

ERRORES CONOCIDOS

En glibc 2.5 y anteriores, estas funciones no generan una excepción de punto flotante de subdesbordamiento (FE_UNDERFLOW) cuando ocurre un subdesbordamiento.

Antes de glibc 2.23, estas funciones no establecían errno.
