NOMBRE

nethsm-openpgp-sign - Crear una firma OpenPGP para un mensaje

SINOPSIS

nethsm openpgp sign [-f|--force] [-o|--output] [-a|--auth-passphrase-file] [-c|--config] [-l|--label] [-u|--user] [-h|--help] <ID_CLAVE> <MENSAJE>

DESCRIPCIÓN

Crear una firma OpenPGP para un mensaje

La firma se escribe en la salida estándar (stdout), a menos que se proporcione una ruta específica a un archivo.

Los usuarios de todo el sistema en el rol de "Operador" solo pueden crear firmas OpenPGP para un mensaje utilizando claves de todo el sistema. Los usuarios con espacios de nombres en el rol de "Operador" solo pueden crear firmas OpenPGP para un mensaje utilizando claves de su propio espacio de nombres.

Requiere la autenticación de un usuario en el rol de "Operador" que tenga acceso a la clave de destino (ver "nethsm key tag" y "nethsm user tag").

OPCIONES

-f, --force
Escribir en el archivo de salida aunque ya exista
También se puede especificar con la variable de entorno NETHSM_FORCE.
-o, --output <SALIDA>
La ruta opcional a un archivo de salida específico
También se puede especificar con la variable de entorno NETHSM_OPENPGP_SIGNATURE_OUTPUT_FILE.
-a, --auth-passphrase-file <ARCHIVO_CONTRASEÑA_AUTENTICACIÓN>
La ruta a un archivo que contiene una contraseña para la autenticación

La contraseña proporcionada en el archivo debe ser la del usuario elegido para el comando.

Esta opción se puede proporcionar varias veces, lo cual es necesario para comandos que requieren varios roles a la vez. Con varios archivos de contraseñas, el orden importa, ya que los archivos se asignan al usuario respectivo proporcionado por la opción "--user".

También se puede especificar con la variable de entorno NETHSM_AUTH_PASSPHRASE_FILE.
-c, --config <CONFIGURACIÓN>
La ruta a un archivo de configuración personalizado

Si se especifica, se utiliza el archivo de configuración personalizado en lugar de la ubicación predeterminada del archivo de configuración.

También se puede especificar con la variable de entorno NETHSM_CONFIG.
-l, --label <ETIQUETA>
Una etiqueta que identifica de forma única un dispositivo en el archivo de configuración

Debe proporcionarse si hay más de un dispositivo configurado en el archivo de configuración.

También se puede especificar con la variable de entorno NETHSM_LABEL.
-u, --user <USUARIO>
Un nombre de usuario que se utiliza para un comando

Se puede proporcionar si no hay ningún nombre de usuario configurado en el archivo de configuración para un dispositivo. Debe proporcionarse si hay varios nombres de usuario del mismo rol de destino configurados en el archivo de configuración para un dispositivo.

Esta opción se puede proporcionar varias veces, lo cual es necesario para comandos que requieren varios roles a la vez.

También se puede especificar con la variable de entorno NETHSM_USER.
-h, --help
Imprimir ayuda (ver un resumen con '-h')
<ID_CLAVE>
El ID de la clave a usar
También se puede especificar con la variable de entorno NETHSM_KEY_ID.
<MENSAJE>
La ruta a un mensaje para el cual crear una firma
También se puede especificar con la variable de entorno NETHSM_OPENPGP_SIGNATURE_MESSAGE.
