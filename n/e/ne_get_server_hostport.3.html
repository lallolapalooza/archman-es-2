ne_get_server_hostport(3)

Paquete: neon

Licencias: LGPL-2.0-or-later

NE_SET_USERAGENT(3) Referencia de la API de neon NE_SET_USERAGENT(3)

NOMBRE

ne_set_useragent, ne_set_read_timeout, ne_set_connect_timeout, ne_get_scheme, ne_get_server_hostport - propiedades comunes para sesiones HTTP

SINOPSIS

#include <ne_session.h>

void ne_set_useragent(ne_session *session, const char *product);

void ne_set_read_timeout(ne_session *session, int timeout);

void ne_set_connect_timeout(ne_session *session, int timeout);

const char *ne_get_scheme(ne_sesssion *session);

const char *ne_get_server_hostport(ne_sesssion *session);

DESCRIPCIÓN

La cabecera de solicitud User-Agent se utiliza para identificar el software que generó la solicitud con fines estadísticos o de depuración. neon no envía una cabecera User-Agent a menos que se llame a ne_set_useragent. A ne_set_useragent se le debe pasar una cadena de producto que cumpla con la gramática de token de producto de RFC2616; con el formato "Producto/Versión".

Cuando neon lee de un socket, por defecto la operación de lectura expirará después de 60 segundos y la solicitud fallará dando un error NE_TIMEOUT. Para configurar este intervalo de tiempo de espera, llame a ne_set_read_timeout proporcionando el número deseado de segundos como parámetro timeout.

Cuando se está estableciendo una conexión a un servidor, normalmente solo se aplicará el manejo del tiempo de espera TCP del sistema. Para configurar un tiempo de espera específico (y probablemente más corto), se puede utilizar ne_set_connect_timeout, proporcionando el número deseado de segundos como parámetro timeout. Si se pasa 0, se utilizará el comportamiento predeterminado de usar el tiempo de espera TCP del sistema.

El esquema utilizado para crear inicialmente la sesión será devuelto por ne_get_scheme.

El par host:puerto asociado con la sesión será devuelto por ne_get_server_hostport; por ejemplo, www.ejemplo.com:8080. Tenga en cuenta que el :puerto se omitirá si se utiliza el puerto predeterminado para el esquema.

EJEMPLOS

Establecer una cadena de user-agent:

ne_session *sess = ne_session_create(...);
ne_set_useragent(sess, "MiAplicacion/2.1");

Establecer un tiempo de espera de lectura de 30 segundos:

ne_session *sess = ne_session_create(...);
ne_set_read_timeout(sess, 30);
