NOMBRE

news2mail - Script de canal para enviar noticias por correo electrónico

SINOPSIS

news2mail

DESCRIPCIÓN

news2mail se ejecuta como un proceso de canal bajo innd. Se configura como un feed de canal en newsfeeds, con diferentes listas de correo como entradas de embudo que apuntan a él (ver abajo); news2mail espera el token de un artículo seguido de una secuencia de nombres de lista.

news2mail utiliza el archivo de configuración pathetc/news2mail.cf para mapear los nombres de las listas de correo a direcciones de correo electrónico. news2mail hace que el agente de transporte de correo (generalmente sendmail, como se establece en el parámetro mta en inn.conf) ponga en cola los mensajes para su posterior entrega (para evitar ataques de denegación de servicio por publicaciones masivas). Debe ejecutar "sendmail -q" periódicamente para procesar la cola.

ARCHIVO DE CONFIGURACIÓN

El formato del archivo de configuración es simple: los comentarios (que comienzan con un signo de almohadilla "#") y las líneas en blanco se ignoran. Todas las demás líneas tienen dos o tres campos. El primero es el nombre de la lista y es lo que usa innd (es decir, el campo del sitio de la entrada en el archivo newsfeeds). El segundo campo es la dirección de correo electrónico real a la que se enviará el artículo. El tercer campo es opcional: establece la dirección del remitente del sobre (por ejemplo, la dirección de un miembro de la lista; si no se establece, por defecto es el usuario "news").

En los mensajes de correo electrónico, el cuerpo del campo de encabezado Para tendrá la dirección de la lista de correo (es decir, el segundo campo). Además, news2mail elimina la mayoría de los campos de encabezado del artículo antes de enviarlo por correo.

En newsfeeds, el feed del canal debería verse así:

news2mail!:!*:Ac,Tc,Wn*:<pathbin>/news2mail

y para cada lista de correo, solo tiene que agregar a newsfeeds una entrada de lista como:

list-big-red-ants/lists.ucsd.edu\
    :!*,rec.pets.red-ants\
    :Ap,Tm:news2mail!

Tenga en cuenta el uso de "Ap" y la exclusión del dominio del propietario de la lista para proteger a la lista de recibir comentarios de nuevos suscriptores de la lista. El nombre del sitio utilizado en la entrada de newfeeds para una lista de correo (arriba "list-big-red-ants") debe ser el mismo que el primer campo en una entrada en news2mail.cf. Por ejemplo:

# nombre-newsfeeds   lista-a-dirección      [dirección-remitente-lista]
list-big-red-ants  ants@lists.ucsd.edu  news+ants@news.server.org

ARCHIVOS

pathbin/news2mail
El programa Perl en sí utilizado para enviar noticias por correo electrónico.
pathetc/news2mail.cf
El archivo de configuración que especifica el mapeo a utilizar para el envío.

ERRORES

El programa news2mail se configura como un canal canalizado en newsfeeds, lo que implica que las coincidencias múltiples deben manejarse como una sola. Las alimentaciones canalizadas con múltiples coincidencias resultarán en una sola llamada al script. Por lo tanto, como solo se envía un correo, las publicaciones cruzadas no se manejan correctamente actualmente en cuanto a la dirección del remitente del sobre (que luego, por defecto, es el usuario "news").
