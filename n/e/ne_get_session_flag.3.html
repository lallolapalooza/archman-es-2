ne_get_session_flag(3)

Paquete: neon

Licencias: LGPL-2.0-or-later

NE_SET_SESSION_FLAG(3) referencia de la API de neon NE_SET_SESSION_FLAG(3)

NOMBRE

ne_set_session_flag, ne_get_session_flag - establecer y recuperar indicadores de sesión

SINOPSIS

#include <ne_request.h>

void ne_set_session_flag(ne_session *sess, ne_session_flag flag, int value);

int ne_get_session_flag(ne_session *sess, ne_session_flag flag);

DESCRIPCIÓN

La función ne_set_session_flag habilita o deshabilita un indicador de sesión. Pasar un argumento value distinto de cero habilita el indicador, y cero lo deshabilita.

Los siguientes indicadores están definidos:

NE_SESSFLAG_PERSIST (activado por defecto)

deshabilitar este indicador para evitar el uso de conexiones persistentes

NE_SESSFLAG_ICYPROTO (desactivado por defecto)

habilitar este indicador para habilitar el soporte para respuestas "ICY" de estilo ShoutCast no HTTP

NE_SESSFLAG_SSLv2

este indicador se ignora

NE_SESSFLAG_RFC4918 (desactivado por defecto)

habilitar este indicador para habilitar el soporte para características WebDAV solo RFC4918; perdiendo compatibilidad con versiones anteriores con servidores RFC2518

NE_SESSFLAG_CONNAUTH (desactivado por defecto)

habilitar este indicador si se utiliza un esquema de autenticación HTTP basado en conexión que viola la RFC

NE_SESSFLAG_TLS_SNI (activado por defecto)

deshabilitar este indicador si se utiliza un servidor que no soporta correctamente la extensión SNI de TLS

NE_SESSFLAG_EXPECT100 (desactivado por defecto)

habilitar este indicador para habilitar el indicador de solicitud NE_REQFLAG_EXPECT100 para nuevas solicitudes

NE_SESSFLAG_SHAREPOINT (desactivado por defecto)

habilitar este indicador para usar varias soluciones alternativas para mejorar la interoperabilidad con SharePoint

NE_SESSFLAG_STRICT (activado por defecto)

deshabilitar este indicador para analizar mensajes HTTP/1.1 sin los requisitos estrictos introducidos en RFC 7230 y posteriores

VALOR DE RETORNO

La función ne_get_session_flag devuelve cero si un indicador está deshabilitado, menos que cero si el indicador no es compatible, o mayor que cero si el indicador está habilitado.

VER TAMBIÉN

ne_session_create, ne_set_request_flag.
