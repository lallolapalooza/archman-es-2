ne_ssl_clicert_encrypted(3)

Paquete: neon

Licencias: LGPL-2.0-or-later

NE_SSL_CLIENT_CERT(3) Referencia de la API de neon NE_SSL_CLIENT_CERT(3)

NOMBRE

ne_ssl_clicert_read, ne_ssl_clicert_import, ne_ssl_clicert_fromuri, ne_ssl_clicert_name, ne_ssl_clicert_encrypted, ne_ssl_clicert_decrypt, ne_ssl_clicert_owner, ne_ssl_clicert_free - manejo de certificados de cliente SSL

SINOPSIS

#include <ne_ssl.h>

ne_ssl_client_cert *ne_ssl_clicert_read(const char *filename);

ne_ssl_client_cert *ne_ssl_clicert_import(const unsigned char *filename, size_t buflen);

ne_ssl_client_cert *ne_ssl_clicert_fromuri(const char *uri, unsigned flags);

const char *ne_ssl_clicert_name(const ne_ssl_client_cert *ccert);

int ne_ssl_clicert_encrypted(const ne_ssl_client_cert *ccert);

int ne_ssl_clicert_decrypt(ne_ssl_client_cert *ccert, const char *password);

const ne_ssl_certificate *ne_ssl_clicert_owner(const ne_ssl_client_cert *ccert);

void ne_ssl_clicert_free(ne_ssl_client_cert *ccert);

DESCRIPCIÓN

La función ne_ssl_clicert_read lee un certificado de cliente de un archivo con formato PKCS#12 y devuelve un objeto ne_ssl_client_cert. La función ne_ssl_clicert_import lee un certificado de cliente de un búfer de memoria utilizando el formato PKCS#12. La función ne_ssl_clicert_fromuri carga un certificado de cliente desde una URI. Los esquemas de URI admitidos se definen por el kit de herramientas SSL/TLS y pueden incluir las URIs PKCS#11[1].

Un objeto ne_ssl_client_cert representa tanto un certificado de cliente como la clave privada asociada; el término "certificado de cliente" se utiliza aquí para referirse a este par. Un objeto de certificado de cliente cargado por cualquiera de las funciones anteriores puede estar en uno de dos estados: cifrado o descifrado. La función ne_ssl_clicert_encrypted devolverá un valor distinto de cero si el certificado de cliente está en el estado cifrado.

Un certificado de cliente debe estar en el estado descifrado antes de asociarse con una sesión. ne_ssl_clicert_decrypt se puede usar para descifrar un certificado de cliente utilizando la contraseña adecuada. Esta función solo debe llamarse si el objeto está en el estado cifrado; si el descifrado falla, el estado del certificado no cambia, por lo que el descifrado se puede intentar más de una vez utilizando diferentes contraseñas.

A un certificado de cliente se le puede dar un "nombre amigable" cuando se crea; ne_ssl_clicert_name devolverá este nombre (o NULL si no se especificó ningún nombre amigable). ne_ssl_clicert_name se puede usar cuando el certificado de cliente está en estado cifrado o descifrado, y devolverá la misma cadena durante la vida útil del objeto.

La función ne_ssl_clicert_owner devuelve la parte del certificado del certificado de cliente; solo debe llamarse si el certificado de cliente está en el estado descifrado.

Cuando el objeto del certificado de cliente ya no es necesario, se debe usar la función ne_ssl_clicert_free para destruirlo.

VALOR DE RETORNO

ne_ssl_clicert_read, ne_ssl_clicert_import y ne_ssl_clicert_fromuri devuelven un objeto de certificado de cliente, o NULL si el certificado no se pudo leer/importar. ne_ssl_clicert_encrypted devuelve cero si el objeto está en el estado descifrado, o un valor distinto de cero si está en el estado cifrado. ne_ssl_clicert_name devuelve una cadena de nombre amigable terminada en NUL, o NULL. ne_ssl_clicert_owner devuelve un objeto de certificado.

EJEMPLOS

El siguiente código lee un certificado de cliente y lo descifra si es necesario, luego lo carga en una sesión HTTP.

ne_ssl_client_cert *ccert;
ccert = ne_ssl_clicert_read("/ruta/a/client.p12");
if (ccert == NULL) {
   /* manejar error... */
} else if (ne_ssl_clicert_encrypted(ccert)) {
   char *password = prompt_for_password();
   if (ne_ssl_clicert_decrypt(ccert, password)) {
      /* ¡no se pudo descifrar! manejar error... */
   }
}
ne_ssl_set_clicert(sess, ccert);

HISTORIA

ne_ssl_clicert_import se añadió en neon 0.30.0. ne_ssl_clicert_fromuri se añadió en neon 0.35.0.
