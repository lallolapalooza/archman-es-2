NOMBRE

netserver - un servidor de referencia de rendimiento de red

SINOPSIS

netserver [-4] [-6] [-d] [-h] [-L nombre,familia] [-p puerto] [-v verbosidad] [-V]

DESCRIPCIÓN

Netserver escucha las conexiones de una referencia de netperf y responde en consecuencia. Puede ser ejecutado desde inetd o como un demonio independiente (con la opción -p). Si se ejecuta desde inetd, no se debe usar la opción -p.

OPCIONES

-4
Utiliza direccionamiento AF_INET (también conocido como IPv4) para las conexiones de control y posiblemente de datos.
-6
Utiliza direccionamiento AF_INET6 (también conocido como IPv6) para las conexiones de control y posiblemente de datos.
-d
Aumenta la cantidad de salida de depuración mostrada durante una prueba (posiblemente a expensas del rendimiento).
-h
Muestra una cadena de uso y sale.
-L nombre,familia
Establece el nombre local y/o la familia de direcciones para el socket utilizado para la conexión de control.
-p puerto
Escucha en el puerto especificado. Esto se utiliza cuando se ejecuta como un demonio independiente.
-v verbosidad
Establece el nivel de verbosidad para la prueba.
-V
Muestra la versión de netperf y sale.

ERRORES

No se conocen errores en este momento. Si crees haber encontrado un error, por favor repórtalo a netperf-talk@netperf.org o a netperf-feedback@netperf.org.
