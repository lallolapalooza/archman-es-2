ne_ssl_cert_issuer(3)

Paquete: neon

Licencias: LGPL-2.0-or-later

NE_SSL_CERT_IDENTITY(3) Referencia de la API de neon NE_SSL_CERT_IDENTITY(3)

NOMBRE

ne_ssl_cert_identity, ne_ssl_cert_signedby, ne_ssl_cert_issuer, ne_ssl_cert_subject - funciones para acceder a las propiedades del certificado

SINOPSIS

#include <ne_ssl.h>

const char *ne_ssl_cert_identity(const ne_ssl_certificate *cert);

const ne_ssl_certificate *ne_ssl_cert_signedby(const ne_ssl_certificate *cert);

const ne_ssl_dname *ne_ssl_cert_subject(const ne_ssl_certificate *cert);

const ne_ssl_dname *ne_ssl_cert_issuer(const ne_ssl_certificate *cert);

DESCRIPCIÓN

La función ne_ssl_cert_identity recupera la "identidad" de un certificado; para un certificado de servidor SSL, esta será el nombre de host para el cual se emitió el certificado. En la jerga de PKI, la identidad es el atributo de nombre común del nombre distinguido del sujeto del certificado.

Las funciones ne_ssl_cert_subject y ne_ssl_cert_issuer se pueden usar para acceder a los objetos que representan el nombre distinguido del sujeto y del emisor de un certificado, respectivamente.

Si un objeto de certificado forma parte de una cadena de certificados, entonces ne_ssl_cert_signedby se puede usar para encontrar el certificado que firmó un certificado particular. Para un certificado autofirmado o un certificado para el cual no está disponible la cadena completa, esta función devolverá NULL.

VALOR DE RETORNO

Se garantiza que ne_ssl_cert_issuer y ne_ssl_cert_subject nunca devolverán NULL. ne_ssl_cert_identity puede devolver NULL si el certificado no tiene una "identidad" específica. ne_ssl_cert_signedby puede devolver NULL como se describe anteriormente.

EJEMPLOS

La siguiente función podría usarse para mostrar información sobre un certificado dado:

void dump_cert(const ne_ssl_certificate *cert) {
  const char *id = ne_ssl_cert_identity(cert);
  char *dn;
  if (id) 
    printf("El certificado se emitió para '%s'.\n", id);
  dn = ne_ssl_readable_dname(ne_ssl_cert_subject(cert));
  printf("Sujeto: %s\n", dn);
  free(dn);
  dn = ne_ssl_readable_dname(ne_ssl_cert_issuer(cert));
  printf("Emisor: %s\n", dn);
  free(dn);
}
