Licencias: LGPL-2.0-or-later

NE_SSL_PROTO_NAME(3) Referencia de la API de neon NE_SSL_PROTO_NAME(3)

NOMBRE

ne_ssl_proto_name - Mapeo de versión de protocolo SSL/TLS a nombre

SINOPSIS

#include <ne_ssl.h>

const char *ne_ssl_proto_name(enum ne_ssl_protocol proto);

DESCRIPCIÓN

La función ne_ssl_proto_name devuelve un nombre legible para una constante de versión SSL/TLS. El conjunto de versiones actualmente son los siguientes:

NE_SSL_PROTO_UNSPEC

versión no especificada/desconocida

NE_SSL_PROTO_SSL3

SSL v3

NE_SSL_PROTO_TLS_1_0

TLS v1.0

NE_SSL_PROTO_TLS_1_1

TLS v1.1

NE_SSL_PROTO_TLS_1_2

TLS v1.2

NE_SSL_PROTO_TLS_1_3

TLS v1.3

VALOR DE RETORNO

La función ne_ssl_proto_name siempre devuelve una cadena no NULL, incluso si la constante de versión no es válida.

HISTORIA

ne_ssl_proto_name está disponible en neon 0.34.0 y posteriores.

VER TAMBIÉN

ne_ssl_set_protovers
