NOMBRE

nethsm-key-sign - Firmar un mensaje con una clave

SINOPSIS

nethsm key sign [-f|--force] [-o|--output] [-a|--auth-passphrase-file] [-c|--config] [-l|--label] [-u|--user] [-h|--help] <ID_CLAVE> <TIPO_FIRMA> <MENSAJE>

DESCRIPCIÓN

Firmar un mensaje con una clave

La clave objetivo debe estar equipada con los mecanismos de clave relevantes para la firma. El tipo de firma elegido debe coincidir con el tipo de clave y los mecanismos de clave de destino.

Si no se elige un archivo de salida específico, la firma se escribe en la salida estándar (stdout).

Los usuarios del sistema en el rol de "Operador" solo pueden crear firmas para mensajes utilizando claves del sistema. Los usuarios con espacio de nombres en el rol de "Operador" solo pueden crear firmas para mensajes utilizando claves en su propio espacio de nombres.

Requiere la autenticación de un usuario en el rol de "Operador" con acceso (ver "nethsm key tag" y "nethsm user tag") a la clave de destino.

OPCIONES

-f, --force
Escribir en el archivo de salida incluso si ya existe
También se puede especificar con la variable de entorno NETHSM_FORCE.
-o, --output <SALIDA>
La ruta opcional a un archivo específico donde se escribe la firma
También se puede especificar con la variable de entorno NETHSM_KEY_SIGNATURE_OUTPUT_FILE.
-a, --auth-passphrase-file <ARCHIVO_CONTRASEÑA_AUTENTICACIÓN>
La ruta a un archivo que contiene una contraseña para la autenticación

La contraseña proporcionada en el archivo debe ser la del usuario seleccionado para el comando.

Esta opción se puede proporcionar varias veces, lo cual es necesario para comandos que requieren múltiples roles a la vez. Con múltiples archivos de contraseña, el orden importa, ya que los archivos se asignan al usuario respectivo proporcionado por la opción "--user".

También se puede especificar con la variable de entorno NETHSM_AUTH_PASSPHRASE_FILE.
-c, --config <CONFIGURACIÓN>
La ruta a un archivo de configuración personalizado

Si se especifica, se utiliza el archivo de configuración personalizado en lugar de la ubicación predeterminada del archivo de configuración.

También se puede especificar con la variable de entorno NETHSM_CONFIG.
-l, --label <ETIQUETA>
Una etiqueta que identifica de forma única un dispositivo en el archivo de configuración

Debe proporcionarse si hay más de un dispositivo configurado en el archivo de configuración.

También se puede especificar con la variable de entorno NETHSM_LABEL.
-u, --user <USUARIO>
Un nombre de usuario que se utiliza para un comando

Se puede proporcionar si no hay un nombre de usuario configurado en el archivo de configuración para un dispositivo. Debe proporcionarse si hay varios nombres de usuario del mismo rol de destino configurados en el archivo de configuración para un dispositivo.

Esta opción se puede proporcionar varias veces, lo cual es necesario para comandos que requieren múltiples roles a la vez.

También se puede especificar con la variable de entorno NETHSM_USER.
-h, --help
Imprimir ayuda (ver un resumen con '-h')
<ID_CLAVE>
El ID de la clave a utilizar para firmar el mensaje
También se puede especificar con la variable de entorno NETHSM_KEY_ID.
<TIPO_FIRMA>
El tipo de firma a utilizar para la firma

Uno de ["EcdsaP256", "EcdsaP384", "EcdsaP521", "EdDsa", "Pkcs1", "PssMd5", "PssSha1", "PssSha224", "PssSha256", "PssSha384", "PssSha512"]

También se puede especificar con la variable de entorno NETHSM_KEY_SIGNATURE_TYPE.
<MENSAJE>
La ruta a un mensaje para el cual crear una firma
También se puede especificar con la variable de entorno NETHSM_KEY_SIGNATURE_MESSAGE.
