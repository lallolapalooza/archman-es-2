NOMBRE

ne_read_response_to_fd, ne_read_response_to_buffer - leer el cuerpo de una respuesta

SINOPSIS

#include <ne_request.h>

int ne_read_response_to_fd(ne_request *req, int fd);

int ne_read_response_to_buffer(ne_request *req, char *data, size_t *buflen);

DESCRIPCIÓN

Para leer el cuerpo de una respuesta HTTP se pueden usar las funciones ne_read_response_to_fd y ne_read_response_to_buffer. Estas funciones son envoltorios para ne_read_response_block y solo deben llamarse después de que ne_begin_request se haya llamado con éxito para la solicitud.

La función ne_read_response_to_fd escribe el contenido del cuerpo de la respuesta en el descriptor de archivo pasado como parámetro fd.

La función ne_read_response_to_buffer escribe el contenido del cuerpo de la respuesta en el búfer pasado como parámetro buf, cuya longitud se pasa a través del parámetro *buflen. En caso de éxito, *buflen se actualiza con el número de bytes escritos en el búfer.

Después de que el cuerpo de la respuesta se haya leído con éxito, se debe llamar a ne_end_request. Si ocurre un fallo mientras se lee el cuerpo de la respuesta, la conexión debe cerrarse usando ne_close_connection.

VALOR DE RETORNO

Ambas funciones devuelven cero en caso de éxito, o un código de error NE_* en caso de fallo. La función ne_read_response_to_buffer devuelve NE_FAILED si la longitud del mensaje de respuesta es mayor que la longitud del búfer.

HISTORIA

ne_read_response_to_buffer está disponible en neon 0.36.0 y posteriores.
