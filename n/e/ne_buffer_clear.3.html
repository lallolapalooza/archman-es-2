ne_buffer_clear(3)

Paquete: neon

Licencias: LGPL-2.0-or-later

NE_BUFFER_CLEAR(3) Referencia de la API de neon NE_BUFFER_CLEAR(3)

NOMBRE

ne_buffer_clear, ne_buffer_grow, ne_buffer_altered - limpiar, expandir o marcar como alterado un búfer de cadena

SINOPSIS

#include <ne_string.h>

void ne_buffer_clear(ne_buffer *buf);

void ne_buffer_altered(ne_buffer *buf);

void ne_buffer_grow(ne_buffer *buf, size_t size);

DESCRIPCIÓN

La función ne_buffer_clear establece la cadena almacenada en buf como la cadena vacía ("").

La función ne_buffer_altered debe usarse después de que la cadena almacenada en el búfer buf sea modificada directamente en lugar de usar ne_buffer_append, ne_buffer_zappend o ne_buffer_concat.

La función ne_buffer_grow asegura que se asignen al menos size bytes para la cadena; esto se puede usar si se va a añadir una gran cantidad de datos al búfer y puede resultar en una asignación de memoria más eficiente.
