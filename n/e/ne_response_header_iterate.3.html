ne_response_header_iterate(3)

Paquete: neon

Licencias: LGPL-2.0-or-later

NE_GET_RESPONSE_HEAD(3) Referencia de la API de neon NE_GET_RESPONSE_HEAD(3)

NOMBRE

ne_get_response_header, ne_response_header_iterate - funciones para acceder a las cabeceras de respuesta

SINOPSIS

#include <ne_request.h>

const char *ne_get_response_header(ne_request *request, const char *name);

void *ne_response_header_iterate(ne_request *request, void *cursor, const char **name, const char **value);

DESCRIPCIÓN

Para recuperar el valor de un campo de cabecera de respuesta, se puede usar la función ne_get_response_header, a la que se le proporciona el nombre de la cabecera a devolver.

Para iterar sobre todas las cabeceras de respuesta devueltas, se puede usar la función ne_response_header_iterate. Esta función toma un parámetro cursor que debe ser NULL para recuperar la primera cabecera. La función almacena el nombre y el valor de la siguiente cabecera en los parámetros name y value, y devuelve un nuevo puntero cursor que puede pasarse a ne_response_header_iterate para recuperar la siguiente cabecera.

VALOR DEVUELTO

ne_get_response_header devuelve una cadena, o NULL si no se proporcionó ninguna cabecera con ese nombre. Si se utiliza durante el procesamiento de la solicitud, el puntero del valor devuelto solo es válido hasta la siguiente llamada a ne_begin_request, o bien, hasta que se destruya el objeto de solicitud.

Del mismo modo, el cursor, los nombres y los valores devueltos por ne_response_header_iterate solo son válidos hasta la siguiente llamada a ne_begin_request o hasta que se destruya el objeto de solicitud.

EJEMPLOS

El siguiente código mostrará el valor de la cabecera Last-Modified para un recurso:

ne_request *req = ne_request_create(sess, "GET", "/foo.txt");
if (ne_request_dispatch(req) == NE_OK) {
    const char *mtime = ne_get_response_header(req, "Last-Modified");
    if (mtime) {
        printf("/foo.txt tiene el valor last-modified %s\n", mtime);
    }
}
ne_request_destroy(req);

VER TAMBIÉN

ne_request_create, ne_request_destroy.
