NOMBRE

net-snmp-config - devuelve información sobre las bibliotecas y binarios de net-snmp instalados

SINOPSIS

net-snmp-config [OPCIONES]

DESCRIPCIÓN

El script de shell net-snmp-config está diseñado para recuperar información de configuración sobre las bibliotecas y binarios que manejan el Protocolo Simple de Gestión de Red (SNMP), compilados desde el paquete fuente net-snmp. La información es particularmente útil para aplicaciones que necesitan enlazarse con las bibliotecas SNMP y, por lo tanto, deben conocer cualquier otra biblioteca que también deba enlazarse.

OPCIONES

--version
muestra el número de versión de net-snmp
--indent-options
muestra las opciones de indentación del Estilo de Codificación
--debug-tokens
muestra un ejemplo de línea de comandos para buscar en el código fuente una lista de tokens de depuración disponibles

Comandos de configuración SNMP:

--create-snmpv3-user [-ro] [-a authpass] [-x privpass]
[-X DES|AES] [-A MD5|SHA|SHA-512|SHA-384|SHA-256|SHA-224] [nombre de usuario]

Estas opciones producen los diversos flags de compilación necesarios al construir aplicaciones SNMP externas:

--base-cflags
lista los flags de compilación adicionales necesarios para aplicaciones externas (excluye -I. y flags de advertencia de desarrollador adicionales, si los hay)
--cflags
lista los flags de compilación adicionales necesarios
--libs
lista las bibliotecas necesarias para construir aplicaciones
--agent-libs
lista las bibliotecas necesarias para construir subagentes
--netsnmp-libs
lista las bibliotecas específicas de netsnmp
--external-libs
lista las bibliotecas necesarias para las bibliotecas de netsnmp
--netsnmp-agent-libs
lista las bibliotecas de agente específicas de netsnmp

--external-agent-libs lista las bibliotecas necesarias para las bibliotecas de netsnmp

Compilación automatizada de subagentes (produce un archivo binario OUTPUTNAME): [Esta característica no ha sido probada extensamente, úsela bajo su propio riesgo.]

--compile-subagent NOMBRE_SALIDA [--norm] [--cflags flags]
[--ldflags flags] mibmodule1.c [...]]
--norm
deja el archivo .c generado para que sea leído.
--cflags flags
flags c adicionales a usar (p. ej. -I...).
--ldflags flags
flags ld adicionales a usar (p. ej. -L... -l...).
Detalles sobre cómo se compiló el paquete net-snmp:
--configure-options
Muestra los argumentos originales de configuración
--snmpd-module-list
Muestra los módulos compilados en el agente
--prefix
Muestra el prefijo de instalación
