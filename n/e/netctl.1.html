NOMBRE

netctl - Controlar el gestor de perfiles de red netctl

SINOPSIS

netctl {COMANDO} [PERFIL]

netctl [--help | --version]

DESCRIPCIÓN

netctl puede ser utilizado para inspeccionar y controlar el estado de los servicios systemd del gestor de perfiles de red.

OPCIONES

Se entienden los siguientes comandos:

list

Lista todos los perfiles disponibles. Los perfiles en línea se marcarán con un ‘*’, de lo contrario, los perfiles activos se marcarán con un ‘+’.

store

Guarda qué perfiles están actualmente activos.

restore

Carga los perfiles que estuvieron activos durante la última invocación de ‘store’.

stop-all

Detiene todos los perfiles de red activos.

start [PERFIL]

Inicia el perfil de red especificado en la línea de comandos.

stop [PERFIL]

Detiene el perfil de red especificado en la línea de comandos.

restart [PERFIL]

Reinicia el perfil de red especificado en la línea de comandos. Si aún no está iniciado, se iniciará.

switch-to [PERFIL]

Inicia el perfil de red especificado en la línea de comandos después de detener todos los perfiles que se refieren a la misma interfaz.

is-active [PERFIL]

Comprueba si el perfil de red especificado en la línea de comandos está activo. Muestra el estado actual.

status [PERFIL]

Muestra información de estado en tiempo de ejecución concisa sobre un perfil, seguida de sus datos de registro más recientes del journal.

enable [PERFIL]

Habilita la unidad systemd para el perfil especificado. Esto creará un archivo de configuración de unidad. Si el archivo ya existe, el comando falla. Ningún otro perfil que no sea el especificado se habilitará. Los cambios en las opciones generales en una especificación de perfil no se propagarán automáticamente al archivo de configuración de la unidad. Después de tales cambios, es necesario ‘reenable’ el perfil.

disable [PERFIL]

Deshabilita la unidad systemd para el perfil especificado. Esto eliminará el archivo creado por ‘enable’ incluso si fue personalizado, así que tenga cuidado.

reenable [PERFIL]

Vuelve a habilitar la unidad systemd para el perfil especificado. Esto es efectivamente una combinación de ‘disable’ y ‘enable’.

is-enabled [PERFIL]

Comprueba si la unidad systemd para el perfil especificado está habilitada. Muestra el estado de habilitación actual.

edit [PERFIL]

Abre el archivo del perfil especificado en un editor. Esto no vuelve a habilitar, reiniciar ni verificar ningún perfil.

verify [PERFIL]

Comprueba el archivo del perfil especificado en busca de errores de sintaxis. Si no se encuentran errores, no se produce ninguna salida.

wait-online [PERFIL]

Espera hasta que la interfaz del perfil tenga una dirección IP enrutable de algún tipo.

ESTADO DE SALIDA

En caso de éxito se devuelve 0, en caso contrario un código de error distinto de cero.

ENTORNO

$NETCTL_DEBUG

Si se establece en "yes", se genera una salida de depuración.

El valor de esta variable es independiente del valor de la variable con el mismo nombre en los perfiles.

$NETCTL_STATE_FILE

La ubicación del archivo de estado. Por defecto es /var/lib/netctl/netctl.state.

VER TAMBIÉN

netctl-auto(1), netctl.profile(5), netctl.special(7), systemctl(1)
