NEXTCLOUD(1) Manual del cliente de Nextcloud NEXTCLOUD(1)

NOMBRE

nextcloud - Utilidad de escritorio para la sincronización de archivos.

SINOPSIS

nextcloud [OPCIONES...]

DESCRIPCIÓN

El cliente Nextcloud es una utilidad de escritorio para la sincronización de archivos. Sincroniza archivos en su computadora local, tableta o dispositivo de mano con un servidor Nextcloud. Si realiza un cambio en los archivos de un dispositivo, el cambio se propaga a todos los demás dispositivos sincronizados que utilizan los clientes de sincronización de escritorio.

Normalmente, inicia el cliente haciendo clic en el icono del escritorio o iniciándolo desde el menú de la aplicación cliente. Después de iniciarlo, aparece un icono de Nextcloud en la bandeja del sistema de la computadora o en su tableta o dispositivo de mano.

OPCIONES

Tiene la opción de iniciar su cliente de escritorio Nextcloud con el comando nextcloud. Se admiten las siguientes opciones:

nextcloud -h o nextcloud --help
Muestra todas las opciones del comando.

Las otras opciones son:

--logwindow
Abre una ventana que muestra la salida del registro.
--logfile <nombre_archivo>
Escribe la salida del registro en el archivo especificado. Para escribir en stdout, especifique - como nombre de archivo.
--logdir <nombre>
Escribe la salida de registro de cada sincronización en un archivo nuevo en el directorio especificado.
--logexpire <horas>
Elimina los registros de más de las horas especificadas. Este comando se usa con --logdir.
--logflush
Borra (vacía) el archivo de registro después de cada acción de escritura.
--logdebug
También muestra mensajes de nivel de depuración en el registro (equivalente a establecer la variable de entorno QT_LOGGING_RULES="qt.*=true;*.debug=true").
--confdir <nombre_directorio>
Utiliza el directorio de configuración especificado.
--background
Inicia la aplicación en segundo plano (es decir, sin abrir el diálogo principal).

ARCHIVO DE CONFIGURACIÓN

El cliente Nextcloud lee un archivo de configuración. Puede localizar este archivo de configuración de la siguiente manera:

En distribuciones de Linux:
$HOME/.config/Nextcloud/nextcloud.cfg
En sistemas Microsoft Windows:
%APPDATA%\Nextcloud\nextcloud.cfg
En sistemas macOS:
$HOME/Library/Preferences/Nextcloud/nextcloud.cfg

El archivo de configuración contiene ajustes utilizando el formato de archivo .ini de Microsoft Windows. Puede sobrescribir los cambios utilizando el diálogo de configuración de Nextcloud.

NOTA:

Tenga cuidado al realizar cambios en el archivo de configuración del cliente Nextcloud. Los ajustes incorrectos pueden producir resultados no deseados.

Algunos valores interesantes que se pueden establecer en el archivo de configuración son:

Sección [Nextcloud]
Variable Por defecto Significado
remotePollInterval 30000 Especifica el tiempo de sondeo para el repositorio remoto en milisegundos.
forceSyncInterval 7200000 La duración de inactividad después de la cual se activará automáticamente una ejecución de sincronización.
fullLocalDiscoveryInterval 3600000 El intervalo después del cual la próxima sincronización realizará un descubrimiento local completo.
notificationRefreshInterval 300000 Especifica el intervalo predeterminado para comprobar las notificaciones del servidor en milisegundos.
Sección [General]
Variable Por defecto Significado
chunkSize 10000000 (10 MB) Especifica el tamaño de fragmento de los archivos subidos en bytes. El cliente ajustará dinámicamente este tamaño dentro de los límites máximo y mínimo (ver más abajo).
forceLoginV2 false Si el cliente debe forzar el nuevo flujo de inicio de sesión, aunque algunas circunstancias puedan requerir el flujo antiguo.
minChunkSize 5000000 (5 MB) Especifica el tamaño mínimo de fragmento de los archivos subidos en bytes.
maxChunkSize 5000000000 (5000 MB) Especifica el tamaño máximo de fragmento de los archivos subidos en bytes.
targetChunkUploadDuration 60000 (1 minuto) Duración objetivo en milisegundos para las cargas de fragmentos. El cliente ajusta el tamaño del fragmento hasta que cada carga de fragmento tarde aproximadamente este tiempo. Establecer en 0 para deshabilitar el dimensionamiento dinámico de fragmentos.
promptDeleteAllFiles false Si se debe mostrar un aviso de la interfaz de usuario para confirmar si se detectó que todos los archivos y carpetas fueron eliminados.
timeout 300 El tiempo de espera para las conexiones de red en segundos.
moveToTrash false Si los archivos eliminados no localmente deben moverse a la papelera en lugar de eliminarse por completo.
showExperimentalOptions false Si se deben mostrar opciones experimentales que aún están en proceso de prueba en la interfaz de usuario. Activar esto no habilita el comportamiento experimental por sí solo. Habilita opciones de interfaz de usuario que se pueden usar para optar por funciones experimentales.
showMainDialogAsNormalWindow false Si el diálogo principal debe mostrarse como una ventana normal, incluso si hay iconos en la bandeja disponibles.
Sección [Proxy]
Variable Default Significado
host 127.0.0.1 La dirección del servidor proxy.
port 8080 El puerto donde el proxy está escuchando.
type 2 0 para Proxy del Sistema.
1 para Proxy SOCKS5.
2 para Sin Proxy.
3 para Proxy HTTP(S).
