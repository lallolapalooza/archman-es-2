ne_set_session_flag(3)

Paquete: neon

Licencias: LGPL-2.0-or-later

NE_SET_SESSION_FLAG(3) referencia de la API de neon NE_SET_SESSION_FLAG(3)

NOMBRE

ne_set_session_flag, ne_get_session_flag - establecer y recuperar banderas de sesión

SINOPSIS

#include <ne_request.h>

void ne_set_session_flag(ne_session *sess, ne_session_flag flag, int value);

int ne_get_session_flag(ne_session *sess, ne_session_flag flag);

DESCRIPCIÓN

La función ne_set_session_flag habilita o deshabilita una bandera de sesión. Pasar un argumento value distinto de cero habilita la bandera, y cero la deshabilita.

Las siguientes banderas están definidas:

NE_SESSFLAG_PERSIST (activada por defecto)

desactivar esta bandera para prevenir el uso de conexiones persistentes

NE_SESSFLAG_ICYPROTO (desactivada por defecto)

habilitar esta bandera para habilitar el soporte de respuestas de estilo "ICY" de ShoutCast no HTTP

NE_SESSFLAG_SSLv2

esta bandera se ignora

NE_SESSFLAG_RFC4918 (desactivada por defecto)

habilitar esta bandera para habilitar el soporte de funciones WebDAV solo RFC4918; perdiendo retrocompatibilidad con servidores RFC2518

NE_SESSFLAG_CONNAUTH (desactivada por defecto)

habilitar esta bandera si se utiliza un esquema de autenticación HTTP basado en conexión que viola RFC

NE_SESSFLAG_TLS_SNI (activada por defecto)

desactivar esta bandera si se utiliza un servidor que no soporta correctamente la extensión TLS SNI

NE_SESSFLAG_EXPECT100 (desactivada por defecto)

habilitar esta bandera para habilitar la bandera de solicitud NE_REQFLAG_EXPECT100 para nuevas solicitudes

NE_SESSFLAG_SHAREPOINT (desactivada por defecto)

habilitar esta bandera para usar varias soluciones alternativas para mejorar la interoperabilidad con SharePoint

NE_SESSFLAG_STRICT (activada por defecto)

desactivar esta bandera para analizar mensajes HTTP/1.1 sin los requisitos estrictos introducidos en RFC 7230 y posteriores

VALOR DE RETORNO

La función ne_get_session_flag devuelve cero si una bandera está deshabilitada, menos de cero si la bandera no es compatible, o mayor que cero si la bandera está habilitada.

VER TAMBIÉN

ne_session_create, ne_set_request_flag.
