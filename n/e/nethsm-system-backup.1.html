NOMBRE

nethsm-system-backup - Realiza una copia de seguridad del almacén de claves de un dispositivo

SINOPSIS

nethsm system backup [-f|--force] [-o|--output] [-a|--auth-passphrase-file] [-c|--config] [-l|--label] [-u|--user] [-h|--help]

DESCRIPCIÓN

Realiza una copia de seguridad del almacén de claves de un dispositivo.

Escribe una copia de seguridad cifrada en un archivo en el directorio de trabajo actual, con el nombre de la etiqueta del dispositivo en el archivo de configuración y la hora actual. Opcionalmente, se puede proporcionar un archivo de salida específico.

Nota: ¡Requiere haber establecido la contraseña de copia de seguridad previamente con "nethsm config set backup-passphrase"!

Requiere la autenticación de un usuario a nivel de sistema en el rol "Backup".

OPCIONES

-f, --force
Escribe en el archivo de salida aunque ya exista.
También se puede especificar con la variable de entorno NETHSM_FORCE.
-o, --output <SALIDA>
La ruta opcional a un archivo de salida específico.
También se puede especificar con la variable de entorno NETHSM_BACKUP_OUTPUT_FILE.
-a, --auth-passphrase-file <ARCHIVO_CONTRASEÑA_AUTENTICACION>
La ruta a un archivo que contiene una contraseña para la autenticación.

La contraseña proporcionada en el archivo debe ser la del usuario elegido para el comando.

Esta opción se puede proporcionar varias veces, lo cual es necesario para comandos que requieren varios roles a la vez. Con varios archivos de contraseña, el orden importa, ya que los archivos se asignan al respectivo usuario proporcionado por la opción "--user".

También se puede especificar con la variable de entorno NETHSM_AUTH_PASSPHRASE_FILE.
-c, --config <CONFIGURACION>
La ruta a un archivo de configuración personalizado.

Si se especifica, se utiliza el archivo de configuración personalizado en lugar de la ubicación predeterminada del archivo de configuración.

También se puede especificar con la variable de entorno NETHSM_CONFIG.
-l, --label <ETIQUETA>
Una etiqueta que identifica de forma única un dispositivo en el archivo de configuración.

Debe proporcionarse si hay más de un dispositivo configurado en el archivo de configuración.

También se puede especificar con la variable de entorno NETHSM_LABEL.
-u, --user <USUARIO>
Un nombre de usuario que se utiliza para un comando.

Se puede proporcionar si no hay un nombre de usuario configurado en el archivo de configuración para un dispositivo. Debe proporcionarse si se configuran varios nombres de usuario del mismo rol de destino en el archivo de configuración para un dispositivo.

Esta opción se puede proporcionar varias veces, lo cual es necesario para comandos que requieren varios roles a la vez.

También se puede especificar con la variable de entorno NETHSM_USER.
-h, --help
Imprime la ayuda (ver un resumen con '-h').
