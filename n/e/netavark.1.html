netavark.1(1) Manual de Comandos Generales netavark.1(1)

% netavark(1)

NOMBRE

netavark - Configura un espacio de nombres de red dado para su uso por un contenedor

SINOPSIS

netavark [opciones] comando ruta del espacio de nombres de red

DESCRIPCIÓN

Netavark configura un espacio de nombres de red según una configuración leída desde STDIN. La configuración tiene formato JSON.

OPCIONES GLOBALES

--file, -f

En lugar de leer desde STDIN, lee la configuración a aplicar desde el archivo dado. -f - también puede usarse para indicar la lectura desde STDIN.

COMANDOS

netavark setup

El comando setup configura el espacio de nombres de red dado con la configuración dada, creando las interfaces y reglas de firewall necesarias.

netavark teardown

El comando teardown es el inverso del comando setup, deshaciendo cualquier configuración aplicada. Algunas interfaces pueden no ser eliminadas (las interfaces de puente, por ejemplo, no se eliminarán).

FORMATO DE CONFIGURACIÓN

La configuración aceptada es la misma para setup y teardown. Tiene formato JSON.

El formato es https://github.com/containers/podman/blob/cd7b48198c38c5028540e85dc72dd3406f4318f0/libpod/network/types/network.go#L164-L173 pero también enviaremos un array de Redes que incluye todas las definiciones de red (https://github.com/containers/podman/blob/cd7b48198c38c5028540e85dc72dd3406f4318f0/libpod/network/types/network.go#L32-L62) TODO: Transcribir la configuración aquí en un formato tabular agradable

EJEMPLO

netavark setup /run/user/1000/podman/netns/d11d1f9c499d

netavark -f /run/podman/828b0508ae64.conf teardown /run/podman/netns/828b0508ae64
