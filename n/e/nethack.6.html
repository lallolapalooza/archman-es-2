NETHACK(6) Manual de Juegos NETHACK(6)

NOMBRE

nethack - Explorando las Mazmorras de la Maldad

SINOPSIS

nethack [ -d directorio ] [ -n ] [ -p profesion ] [ -r raza ] [ -[DX] ] [ -u nombredejugador ] [ -dec ] [ -ibm ] [ --showpaths ] [ --version[:paste] ]

nethack [ -d directorio ] -s [ -v ] [ -p profesion ] [ -r raza ] [ nombresdejugador ]

DESCRIPCIÓN

NetHack es un juego tipo Dungeons & Dragons(tm) orientado a la pantalla. La pantalla de terminal estándar y la estructura de comandos se parecen a rogue.

Existen otras opciones de visualización, más gráficas, para la mayoría de las plataformas.

Para empezar, realmente solo necesitas conocer dos comandos. El comando ? te dará una lista de los comandos disponibles (así como otra información) y el comando / identificará las cosas que ves en la pantalla.

Para ganar el juego (en contraposición a simplemente jugar para superar las puntuaciones altas de otros jugadores) debes localizar el Amuleto de Yendor, que está en algún lugar debajo del nivel 20 de la mazmorra, y sacarlo. Pocas personas logran esto; la mayoría nunca lo hacen. Aquellos que lo han conseguido pasan a la historia como héroes entre héroes, y luego encuentran formas de hacer el juego aún más difícil. Consulta la sección de Conducta de la Guía si este juego se te ha hecho demasiado fácil.

Cuando el juego termina, ya sea por tu muerte, por abandono o por escapar de las cuevas, NetHack te dará (un fragmento de) la lista de los mejores puntuadores. La puntuación se basa en muchos aspectos de tu comportamiento, pero una estimación aproximada se obtiene tomando la cantidad de oro que has encontrado en la cueva más cuatro veces tu experiencia (real). Las piedras preciosas pueden valer mucho oro cuando se llevan a la salida. Hay una penalización del 10% por dejarte morir.

La variable de entorno NETHACKOPTIONS se puede usar para inicializar muchas opciones de tiempo de ejecución. El comando ? proporciona una descripción de estas opciones y su sintaxis. (Las opciones de línea de comandos -dec y -ibm son equivalentes a las opciones de tiempo de ejecución decgraphics y ibmgraphics descritas allí, y se proporcionan únicamente por conveniencia en sistemas que admiten varios tipos de terminales.)

Debido a que la lista de opciones puede ser muy larga (particularmente al especificar caracteres gráficos), las opciones también pueden incluirse en un archivo de configuración. El predeterminado se encuentra en tu directorio de inicio y se llama .nethackrc en sistemas Unix. En otros sistemas, el predeterminado puede ser diferente, generalmente NetHack.cnf. En DOS o Windows, el nombre es defaults.nh, mientras que en Macintosh o BeOS, es NetHack Defaults. La ubicación del archivo de configuración se puede especificar estableciendo NETHACKOPTIONS a una cadena que consista en un carácter @ seguido del nombre del archivo.

La opción -u nombredejugador proporciona la respuesta a la pregunta "¿Quién eres?". Anula cualquier nombre del archivo de opciones o configuración, USER, LOGNAME o getlogin(), que de lo contrario se intentarán en orden. Si ninguno de estos proporciona un nombre útil, se le pedirá al jugador que ingrese uno. Los nombres de jugador (junto con los uid) se utilizan para identificar los archivos guardados, por lo que puedes tener varios juegos guardados bajo diferentes nombres. Por el contrario, debes usar el nombre de jugador apropiado para restaurar un juego guardado.

Se puede usar un sufijo de nombredejugador para especificar la profesión, raza, alineación y/o género del personaje. La sintaxis completa del nombre de jugador que incluye un sufijo es "nombre-ppp-rrr-aaa-ggg". "ppp" son al menos las primeras tres letras de la profesión (esto también se puede especificar usando una opción separada -p profesion). "rrr" son al menos las primeras tres letras de la raza del personaje (esto también se puede especificar usando una opción separada -r raza). "aaa" son al menos las primeras tres letras de la alineación del personaje, y "ggg" son al menos las primeras tres letras del género del personaje. Cualquiera de las partes del sufijo puede omitirse.

-p profesion se puede usar para determinar la profesión del personaje, también conocida como el rol. Puedes especificar el nombre masculino o femenino del rol del personaje, o los primeros tres caracteres del rol como abreviatura. Se ha conservado -p @ para solicitar explícitamente que se elija un rol aleatorio. Puede ser necesario entrecomillarlo con una barra invertida (\@) si @ es el carácter de "matar" (ver "stty") para la terminal, para evitar que se borre la línea de entrada actual.

Del mismo modo, -r raza se puede usar para solicitar explícitamente que se elija una raza.

Omitir cualquiera de estas características resultará en que se te pedirá durante el inicio del juego la información.

La opción -s sola imprimirá la lista de tus puntuaciones en la versión actual. Un -v inmediatamente posterior informará sobre todas las versiones presentes en el archivo de puntuaciones. El -s también puede ir seguido de los argumentos -p y -r para imprimir solo las puntuaciones de roles y razas particulares. También puede ir seguido de uno o más nombres de jugador para imprimir las puntuaciones de los jugadores mencionados, por 'all' para imprimir todas las puntuaciones, o por un número para imprimir esa cantidad de puntuaciones altas.

La opción -n suprime la impresión de cualquier noticia del administrador del juego.

La opción -D o -X iniciará el juego en un modo especial de descubrimiento sin puntuación. -D, si el jugador es el administrador del juego, iniciará en modo de depuración (mago) en su lugar.

La opción -d, que debe ser el primer argumento si aparece, proporciona un directorio que servirá como área de juego. Anula el valor de NETHACKDIR, HACKDIR, o el directorio especificado por el administrador del juego durante la compilación (generalmente /usr/games/lib/nethackdir). Esta opción suele ser útil solo para el administrador del juego. El área de juego debe contener varios archivos auxiliares, como archivos de ayuda, la lista de los mejores puntuadores y un subdirectorio save donde se guardan los juegos.

--showpaths se puede usar para que NetHack muestre dónde espera encontrar varios archivos de configuración.

--version se puede usar para que NetHack muestre la información de la versión con la que fue compilado y luego salga. Esto incluirá el hash del commit de git si la información estaba disponible cuando se compiló el juego. En algunas plataformas, como Windows y Mac OS X, se puede usar una variación --version:paste para que NetHack muestre la información de la versión, luego salga, mientras también deja una copia de la información de la versión en el portapapeles para su posible inserción en cosas como informes de errores.

AUTORES

Jay Fenlason (+ Kenny Woodland, Mike Thome y Jon Payne) escribieron el hack original, muy parecido a rogue (pero lleno de errores).

Andries Brouwer deformó continuamente sus fuentes hasta convertirlas en un juego completamente diferente.

Mike Stephenson ha continuado la perversión de las fuentes, añadiendo varias clases de personajes distorsionados y trampas sádicas con la ayuda de muchas personas extrañas que residen en ese lugar entre los mundos, la Zona de Usenet. Un número de estos maleantes están inmortalizados en el rol histórico de deshonor y varios otros lugares.

El resultado desordenado ahora se llama NetHack, para denotar su desarrollo por parte de Usenet. Andries Brouwer ha hecho esta solicitud para la distinción, ya que puede que eventualmente publique una nueva versión propia.

ARCHIVOS

Las opciones de configuración en tiempo de ejecución se discutieron anteriormente y usan un nombre específico de plataforma para un archivo en una ubicación específica de plataforma. Para Unix, el nombre es '.nethackrc' en el directorio de inicio del usuario.

Todos los demás archivos están en el directorio del área de juego, normalmente /usr/games/lib/nethackdir. Si DLB se definió durante la compilación, los archivos de datos y los niveles especiales estarán dentro de un archivo más grande, normalmente nhdat, en lugar de ser archivos separados.

nethack El programa en sí.
data, oracles, rumors Archivos de datos utilizados por NetHack.
quest.dat, bogusmon Más archivos de datos.
engrave, epitaph, tribute Aún más archivos de datos.

para cómo mostrar monstruos, objetos y
características del mapa.
options Archivo de datos que contiene una descripción de la configuración
de las opciones de compilación.
help, hh Archivos de datos de ayuda.
cmdhelp, opthelp, wizhelp Archivos de datos de ayuda adicionales.
*.lev Niveles especiales predefinidos.
dungeon Archivo de control para niveles especiales.
history Una breve historia de NetHack.

nethack(6) — NetHack 3.6.7

NAME

nethack ― a dungeon exploration game

SYNOPSIS

nethack [-d directory] [-f file] [-p string] [-r string] [-s string]

DESCRIPTION

NetHack is a fantasy game of exploration, combat, and magic. The player assumes the role of an adventurer who explores the dangerous dungeon of Doom, seeking the Amulet of Yendor.

The player has the ability to move, fight monsters, cast spells, eat food, wear armor, wield weapons, and much more. The game world is generated procedurally, meaning that each game is different.

The game is controlled by a series of commands, which can be typed as single keystrokes or by using a more verbose command syntax.

COMMANDS

The following are some of the more common commands:

h j k l y u b n
Movement commands (left, down, up, right, down-left, down-right, up-left, up-right).
s
Search for traps and secret doors.
o
Open a door.
c
Close a door.
a
Apply an item (e.g., a crowbar, a key).
i
Show inventory.
d
Drop an item.
e
Eat food.
q
Quaff a potion.
r
Read a scroll or spellbook.
w
Wield a weapon.
W
Wear armor.
T
Take off armor.
P
Put on an accessory (ring, amulet).
R
Remove an accessory.
p
Pay shopkeeper.
b
Bash a door or chest.
f
Fight monster without moving.
t
Throw an item.
x
Swap weapon.
a
Apply an item.
X
Examine something.
?
Help screen.
O
Set options.
v
Version information.
Q
Quit game.

OPTIONS

NetHack supports a variety of options that can be set in the .nethackrc file or by using the O command in the game.

OPTIONS_FILE
Specifies the location of the NetHack configuration file.
SHOW_FAILURES
Shows monsters that missed you.
SHOW_EXITS
Shows dungeon exits.
SHOW_RATES
Shows rates for various actions.

FILES

The NetHack game stores various files in its data directory. The default location is usually /var/games/nethack, but it can be overridden by the NETHACKDIR or HACKDIR environment variables.

logfile
An extended list of games played (optional).
xlogfile
A more detailed version of 'logfile' (also optional).
paniclog
Record of exceptional conditions discovered during program execution.
xlock.nn
Description of dungeon level 'nn' of active game 'x' if there's a limit on the number of simultaneously active games.
UUcccccc.nn
Alternate form for dungeon level 'nn' of active game by user 'UU' playing character named 'cccccc' when there's no limit on number of active games.
perm
Lock file for xlock.0 or UUcccccc.0.
bonesDD.nn
Descriptions of the ghost and belongings of a deceased adventurer who met his or her demise on level 'nn'.
save/
A subdirectory containing saved games.
sysconf
System-wide options. Required if program is built with 'SYSCF' option enabled, ignored if not.

The location of 'sysconf' is specified at build time and can't be changed except by updating source file "config.h" and rebuilding the program.

In a perfect world, 'paniclog' would remain empty.

ENVIRONMENT

USER or LOGNAME
Your login name.
HOME
Your home directory.
SHELL
Your shell.
TERM
The type of your terminal.
HACKPAGER or PAGER
Replacement for default pager.
MAIL
Mailbox file.
MAILREADER
Replacement for default reader (probably /bin/mail or /usr/ucb/mail).
NETHACKDIR or HACKDIR
Playground.
NETHACKOPTIONS
String predefining several NetHack options.

If the same option is specified in both NETHACKOPTIONS and .nethackrc, the value assigned in NETHACKOPTIONS takes precedence.

SHOPTYPE and SPLEVTYPE can be used in debugging (wizard) mode. DEBUGFILES can be used if the program was built with 'DEBUG' enabled.
