NOMBRE

ne_token, ne_qtoken - tokenizadores de cadenas

SINOPSIS

#include <ne_string.h>

char *ne_token(char **str, char sep);

char *ne_qtoken(char **str, char sep, const char *quotes);

DESCRIPCIÓN

ne_token y ne_qtoken tokenizan la cadena en la ubicación almacenada en el puntero str. Cada vez que se llama a la función, devuelve el siguiente token y modifica el puntero str para que apunte al resto de la cadena, o NULL si no hay más tokens en la cadena. Un token está delimitado por el carácter separador sep; si se utiliza ne_qtoken, se omiten los segmentos entrecomillados de la cadena al buscar un separador. Un segmento entrecomillado está encerrado entre un par de uno de los caracteres dados en la cadena quotes.

La cadena que se está tokenizando se modifica cada vez que se llama a la función de tokenización; reemplazando el siguiente carácter separador con un terminador NUL.

EJEMPLOS

La siguiente función imprime cada token de una cadena separada por comas list, que se modifica en su lugar:

static void splitter(char *list)
{
  do {
    printf("Token: %s\n", ne_token(&list, ','));
  while (list);
}
