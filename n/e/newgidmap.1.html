NEWGIDMAP(1) Comandos de usuario NEWGIDMAP(1)

NOMBRE

newgidmap - establece el mapeo de gid de un espacio de nombres de usuario

SINOPSIS

newgidmap pid gid lowergid count [gid lowergid count [ ... ]]

DESCRIPCIÓN

newgidmap establece /proc/[pid]/gid_map basándose en sus argumentos de línea de comandos y los gids permitidos. La delegación de subgids se puede gestionar a través de /etc/subgid o a través del módulo subid NSS configurado. Estas opciones son mutuamente excluyentes.

Tenga en cuenta que el grupo raíz no está exento del requisito de una entrada válida en /etc/subgid.

Después del argumento pid, newgidmap espera conjuntos de 3 enteros:

gid

Principio del rango de GIDs dentro del espacio de nombres de usuario.

lowergid

Principio del rango de GIDs fuera del espacio de nombres de usuario.

count

Longitud de los rangos (tanto dentro como fuera del espacio de nombres de usuario).

newgidmap verifica que el llamante sea el propietario del proceso indicado por pid y que para cada uno de los conjuntos anteriores, cada uno de los GIDs en el rango [lowergid, lowergid+count) esté permitido al llamante según /etc/subgid antes de establecer /proc/[pid]/gid_map.

Tenga en cuenta que newgidmap solo puede usarse una vez para un proceso determinado.

En lugar de un ID de proceso entero, el primer argumento puede especificarse como fd:N, donde N es el número de descriptor de archivo para el descriptor de archivo abierto del proceso llamante para el directorio /proc/[pid]. En este caso, newgidmap usará openat(2) para abrir el archivo gid_map bajo ese directorio, evitando un TOCTTOU en caso de que el proceso termine y el pid se reutilice inmediatamente.

OPCIONES

Actualmente no hay opciones para el comando newgidmap.

ARCHIVOS

/etc/subgid

Lista de IDs de grupo subordinados del usuario.

/proc/[pid]/gid_map

Mapeo de gids entre espacios de nombres de usuario.

VER TAMBIÉN

login.defs(5), newusers(8), subgid(5), useradd(8), userdel(8), usermod(8).
