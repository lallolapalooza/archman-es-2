NOMBRE

nemo-desktop - Proveedor del escritorio de Nemo

SINOPSIS

nemo-desktop [opciones] URIs...

DESCRIPCIÓN

Esta página del manual documenta brevemente el comando nemo-desktop.

Nemo es el gestor de archivos para el escritorio Cinnamon.

OPCIONES

Nemo-desktop sigue la sintaxis habitual de línea de comandos de GNU, con opciones largas que comienzan con dos guiones (`-'). A continuación se incluye un resumen de las opciones.

--debug
Habilita el código de depuración. Uso de ejemplo: 'NEMO_DEBUG=Desktop,Actions nemo-desktop --debug'. Utiliza NEMO_DEBUG=all para más temas.
--quit
Salir de Nemo.
--help
Mostrar un resumen de las opciones.
--version
Mostrar la versión de Nemo.
También se admiten otras opciones estándar de GNOME no listadas aquí.

NOTA SOBRE EL USUARIO ROOT

Normalmente, nemo y nemo-desktop tratan la ejecución como usuario root como algo especial, con ciertas restricciones y cambios en la interfaz de usuario. Este comportamiento se puede omitir a través de una clave gsettings. Puedes usar el siguiente comando para habilitar/deshabilitar esta anulación:

gsettings set org.nemo.preferences treat-root-as-normal true|false
