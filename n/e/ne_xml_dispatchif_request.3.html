ne_xml_dispatchif_request(3)

Paquete: neon

Licencias: LGPL-2.0-or-later

NE_XML_PARSE_RESPONS(3) Referencia de la API de neon NE_XML_PARSE_RESPONS(3)

NOMBRE

ne_xml_parse_response, ne_xml_dispatch_request, ne_xml_dispatchif_request - funciones auxiliares para analizar respuestas XML

SINOPSIS

#include <ne_xmlreq.h>

int ne_xml_parse_response(ne_request *req, ne_xml_parser *parser);

int ne_xml_dispatch_request(ne_request *req, ne_xml_parser *parser);

int ne_xml_dispatchif_request(ne_request *req, ne_xml_parser *parser, ne_accept_response acceptor, void *userdata);

DESCRIPCIÓN

La función ne_xml_parse_response lee el cuerpo de una respuesta HTTP y lo procesa utilizando el analizador XML proporcionado. La función debe llamarse después de que ne_begin_request haya devuelto éxito para la solicitud, y luego invoca ne_read_response_block hasta que se haya leído todo el cuerpo de la respuesta. Tras un retorno exitoso, se debe llamar a ne_end_request para finalizar el procesamiento de la respuesta.

Las funciones ne_xml_dispatch_request y ne_xml_dispatchif_request son equivalentes a llamar a ne_request_dispatch para enviar una solicitud HTTP y procesar la respuesta, analizando el cuerpo de la respuesta utilizando el analizador XML proporcionado bajo ciertas condiciones:

•Para ne_xml_dispatch_request, cualquier respuesta de clase 2xx con un tipo de contenido XML.
•Para ne_xml_dispatchif_request, si la función de devolución de llamada acceptor devuelve un valor distinto de cero, y la respuesta utiliza un tipo de contenido XML.

En ambos casos, se siguen las reglas de RFC 7303[1] para identificar tipos de contenido XML, es decir, text/xml, application/xml, o cualquier otro tipo de contenido que termine en el sufijo +xml. El parámetro userdata se pasa a la función acceptor.

Para las tres funciones:

•el analizador XML se invoca repetidamente hasta que se alcanza el final del documento.
•si ocurre un error durante el análisis XML, la cadena de error de la sesión se establece para describir el error de análisis, y la conexión se termina sin continuar procesando la respuesta.

VALOR DE RETORNO

Todas las funciones documentadas aquí devuelven cero en caso de éxito, o un código de error NE_* en caso de fallo.

HISTORIA

ne_xml_dispatchif_request está disponible en neon 0.36.0 y posteriores.

VER TAMBIÉN
