NOMBRE

ne_redirect_register, ne_redirect_location - Manejo de redirecciones de peticiones HTTP

SINOPSIS

#include <ne_redirect.h>

void ne_redirect_register(ne_session *sess);

const ne_uri *ne_redirect_location(ne_session *sess);

DESCRIPCIÓN

La función ne_redirect_register registra el manejo de redirecciones para la sesión. Si se procesa una respuesta de redirección válida (con código de estado 3xx), la petición fallará con el código de error NE_REDIRECT. La ubicación de la redirección se puede obtener entonces usando ne_redirect_location.

Si se procesó una redirección, la función ne_redirect_location devuelve la URI de destino de la redirección.

VALOR DE RETORNO

ne_redirect_location devuelve NULL si aún no se ha procesado ninguna petición, si la petición actual no fue una redirección, o si la ubicación de la redirección no pudo ser analizada o resuelta. En caso contrario, devuelve un puntero a un objeto ne_uri, que permanece válido hasta que se cree otra petición para la sesión.
