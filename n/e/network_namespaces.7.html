network_namespaces(7) Manual de Información Miscelánea network_namespaces(7)

NOMBRE

network_namespaces - visión general de los namespaces de red de Linux

DESCRIPCIÓN

Los namespaces de red proporcionan aislamiento de los recursos del sistema asociados con la red: dispositivos de red, pilas de protocolos IPv4 e IPv6, tablas de enrutamiento IP, reglas de firewall, el directorio /proc/net (que es un enlace simbólico a /proc/pid/net), el directorio /sys/class/net, varios archivos bajo /proc/sys/net, números de puerto (sockets), etc. Además, los namespaces de red aíslan el namespace de sockets abstractos de dominio UNIX (ver unix(7)).

Un dispositivo de red físico puede residir en exactamente un namespace de red. Cuando un namespace de red se libera (es decir, cuando el último proceso en el namespace termina), sus dispositivos de red físicos se mueven de vuelta al namespace de red inicial (no al namespace del padre del proceso).

Un par de dispositivos de red virtual (veth(4)) proporciona una abstracción similar a una tubería que se puede usar para crear túneles entre namespaces de red, y se puede usar para crear un puente a un dispositivo de red físico en otro namespace. Cuando un namespace se libera, los dispositivos veth(4) que contiene se destruyen.

El uso de namespaces de red requiere un kernel que esté configurado con la opción CONFIG_NET_NS.
