NOMBRE

ne_get_request_target - recuperar el objetivo de la solicitud

SINOPSIS

#include <ne_request.h>

const ne_uri *ne_get_request_target(ne_request *req);

DESCRIPCIÓN

ne_get_request_target devuelve la URI del objetivo de la solicitud como un puntero a un objeto ne_uri. El "recurso objetivo" de una solicitud se define según la Sección 7.1 de RFC 9110[1] y se deriva de los parámetros utilizados para crear la solicitud con ne_request_create y los parámetros utilizados para crear la sesión con ne_session_create.

VALOR DE RETORNO

La función ne_get_request_target devuelve una ne_uri, o NULL si no fue posible crear la URI de destino. Esto último solo puede ocurrir si la ruta utilizada para crear el objeto de solicitud no era una ruta URI válida. Tenga en cuenta que el campo path del objeto devuelto puede ser una cadena vacía si se utiliza la forma de autoridad de la URI.

HISTORIA

ne_get_request_target está disponible en neon 0.34.0 y posteriores.

VER TAMBIÉN

ne_request_create, ne_session_create.
