NOMBRE

nethsm-openpgp-add - Añadir un certificado OpenPGP para una clave

SINOPSIS

nethsm openpgp add [-t|--time] [-v|--version] [--can-sign] [--cannot-sign] [-a|--auth-passphrase-file] [-c|--config] [-l|--label] [-u|--user] [-h|--help] <ID_CLAVE> <ID_USUARIO>

DESCRIPCIÓN

Añadir un certificado OpenPGP para una clave

Crea un certificado OpenPGP para una clave existente. El certificado creado se añade entonces como certificado de la clave (ver "nethsm key cert import").

Los usuarios de todo el sistema en los roles de "Administrador" y "Operador" solo pueden añadir certificados OpenPGP para claves de todo el sistema. Los usuarios de espacio de nombres en los roles de "Administrador" y "Operador" solo pueden añadir certificados OpenPGP para claves en su propio espacio de nombres.

Requiere la autenticación de un usuario en el rol de "Operador", que tenga acceso a la clave de destino (ver "nethsm key tag" y "nethsm user tag"). Adicionalmente, se necesita la autenticación de un usuario en el rol de "Administrador" para importar el certificado.

OPCIONES

-t, --time <TIEMPO>
La hora de creación opcional del certificado (por defecto es ahora)
También puede especificarse con la variable de entorno NETHSM_OPENPGP_CREATED_AT.
-v, --version <VERSIÓN>
La versión de OpenPGP con la que se crea el certificado (por defecto es "4")

Uno de ["4", "6"].

También puede especificarse con la variable de entorno NETHSM_OPENPGP_VERSION.
--can-sign
Establece la bandera de clave de firma (por defecto está establecida)

Si se utiliza esta opción, la clave se crea con una clave componente que tiene la bandera de clave de firma establecida.

También puede especificarse con la variable de entorno NETHSM_OPENPGP_CERT_GENERATE_CAN_SIGN.
--cannot-sign
Borra la bandera de clave de firma

Si se utiliza esta opción, la clave se crea sin una clave componente que tenga la bandera de clave de firma establecida.

También puede especificarse con la variable de entorno NETHSM_OPENPGP_CERT_GENERATE_CANNOT_SIGN.
-a, --auth-passphrase-file <ARCHIVO_CONTRASENA>
La ruta a un archivo que contiene una contraseña para la autenticación

La contraseña proporcionada en el archivo debe ser la del usuario elegido para el comando.

Esta opción se puede proporcionar varias veces, lo cual es necesario para comandos que requieren múltiples roles a la vez. Con múltiples archivos de contraseña, el orden importa, ya que los archivos se asignan al usuario respectivo proporcionado por la opción "--user".

También puede especificarse con la variable de entorno NETHSM_AUTH_PASSPHRASE_FILE.
-c, --config <CONFIGURACION>
La ruta a un archivo de configuración personalizado

Si se especifica, se utiliza el archivo de configuración personalizado en lugar de la ubicación predeterminada del archivo de configuración.

También puede especificarse con la variable de entorno NETHSM_CONFIG.
-l, --label <ETIQUETA>
Una etiqueta que identifica de forma única un dispositivo en el archivo de configuración

Debe proporcionarse si se configuran varios dispositivos en el archivo de configuración.

También puede especificarse con la variable de entorno NETHSM_LABEL.
-u, --user <USUARIO>
Un nombre de usuario que se utiliza para un comando

Puede proporcionarse si no hay un nombre de usuario configurado en el archivo de configuración para un dispositivo. Debe proporcionarse si se configuran varios nombres de usuario del mismo rol de destino en el archivo de configuración para un dispositivo.

Esta opción se puede proporcionar varias veces, lo cual es necesario para comandos que requieren múltiples roles a la vez.

También puede especificarse con la variable de entorno NETHSM_USER.
-h, --help
Imprimir ayuda (ver un resumen con '-h')
<ID_CLAVE>
El ID de la clave a usar
También puede especificarse con la variable de entorno NETHSM_KEY_ID.
<ID_USUARIO>
El ID de usuario a usar para la clave
También puede especificarse con la variable de entorno NETHSM_OPENPGP_USERID.
