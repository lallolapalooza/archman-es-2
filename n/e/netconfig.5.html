NETCONFIG(5) Manual de Formatos de Archivos NETCONFIG(5)

NOMBRE

netconfig — base de datos de configuración de red

SINOPSIS

/etc/netconfig

DESCRIPCIÓN

El archivo netconfig define una lista de "nombres de transporte", describiendo su semántica y protocolo. En FreeBSD, este archivo solo es utilizado por el código de la biblioteca RPC.

Las entradas tienen el siguiente formato:

id_red semántica indicadores familia nombre_protocolo dispositivo bibliotecas

Las entradas consisten en los siguientes campos:

id_red
El nombre del transporte descrito.
semántica
Describe la semántica del transporte. Puede ser uno de los siguientes:
tpi_clts
Transporte sin conexión.
tpi_cots
Transporte orientado a conexión.
tpi_cots_ord
Transporte orientado a conexión y ordenado.
tpi_raw
Una conexión cruda.
indicadores
Este campo está en blanco (especificado por "-"), o contiene una "v", que significa visible para la función getnetconfig(3).
familia
La familia de protocolos del transporte. Actualmente puede ser una de las siguientes:
inet6
La familia de protocolos IPv6 (PF_INET6).
inet
La familia de protocolos IPv4 (PF_INET).
loopback
La familia de protocolos PF_LOCAL.
nombre_protocolo
El nombre del protocolo utilizado para este transporte. Actualmente puede ser udp, tcp o vacío.
dispositivo
Este campo está siempre vacío en FreeBSD.
bibliotecas
Este campo está siempre vacío en FreeBSD.

El orden de las entradas en este archivo determinará qué transporte será preferido por el código de la biblioteca RPC, dado una coincidencia en un tipo de red especificado. Por ejemplo, si un archivo de configuración de red de ejemplo se viera así:

udp6       tpi_clts      v     inet6    udp     -       -
tcp6       tpi_cots_ord  v     inet6    tcp     -       -
udp        tpi_clts      v     inet     udp     -       -
tcp        tpi_cots_ord  v     inet     tcp     -       -
rawip      tpi_raw       -     inet      -      -       -
local      tpi_cots_ord  -     loopback  -      -       -

entonces, al usar el tipo de red udp en llamadas a la función de la biblioteca RPC (ver rpc(3)), el código primero intentará udp6, y luego udp.

getnetconfig(3) y las funciones asociadas analizarán este archivo y devolverán estructuras del siguiente formato:

struct netconfig {
    char *nc_netid;              /* ID de red */
    unsigned long nc_semantics;  /* Semántica (ver abajo) */
    unsigned long nc_flag;       /* Indicadores (ver abajo) */
    char *nc_protofmly;          /* Familia de protocolos */
    char *nc_proto;              /* Nombre del protocolo */
    char *nc_device;             /* Ruta del dispositivo de red (no utilizado) */
    unsigned long nc_nlookups;   /* Número de bibliotecas de búsqueda (no utilizado) */
    char **nc_lookups;           /* Nombres de las bibliotecas (no utilizado) */
    unsigned long nc_unused[9];  /* reservado */
};

ARCHIVOS

/etc/netconfig
 

VER TAMBIÉN

getnetconfig(3), getnetpath(3)
