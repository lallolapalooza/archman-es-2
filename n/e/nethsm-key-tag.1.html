NOMBRE

nethsm-key-tag - Etiquetar una clave

SINOPSIS

nethsm key tag [-a|--auth-passphrase-file] [-c|--config] [-l|--label] [-u|--user] [-h|--help] <ID_CLAVE> <ETIQUETA>

DESCRIPCIÓN

Etiquetar una clave

Las etiquetas se utilizan para otorgar acceso a claves para usuarios del rol "Operador". Si un usuario y una clave están etiquetados con la misma etiqueta, el usuario obtiene acceso a esa clave. Como las claves existen a nivel de sistema o en un espacio de nombres, los usuarios del rol "Operador" deben estar en el mismo ámbito que la clave para que esto tenga efecto.

Nota: Las etiquetas en las claves deben crearse antes de crear etiquetas en los usuarios.

Los usuarios a nivel de sistema del rol "Administrador" solo pueden etiquetar claves a nivel de sistema. Los usuarios con espacio de nombres del rol "Administrador" solo pueden etiquetar claves en su propio espacio de nombres.

Requiere autenticación de un usuario del rol "Administrador".

OPCIONES

-a, --auth-passphrase-file <ARCHIVO_CONTRASEÑA_AUTENTICACIÓN>
La ruta a un archivo que contiene una contraseña para la autenticación

La contraseña proporcionada en el archivo debe ser la del usuario elegido para el comando.

Esta opción puede proporcionarse varias veces, lo cual es necesario para comandos que requieren varios roles a la vez. Con varios archivos de contraseñas, el orden importa, ya que los archivos se asignan al usuario respectivo proporcionado por la opción "--user".

También se puede especificar con la variable de entorno NETHSM_AUTH_PASSPHRASE_FILE.
-c, --config <CONFIGURACIÓN>
La ruta a un archivo de configuración personalizado

Si se especifica, se utiliza el archivo de configuración personalizado en lugar de la ubicación predeterminada del archivo de configuración.

También se puede especificar con la variable de entorno NETHSM_CONFIG.
-l, --label <ETIQUETA_DISPOSITIVO>
Una etiqueta que identifica de forma única un dispositivo en el archivo de configuración

Debe proporcionarse si hay más de un dispositivo configurado en el archivo de configuración.

También se puede especificar con la variable de entorno NETHSM_LABEL.
-u, --user <USUARIO>
Un nombre de usuario que se utiliza para un comando

Se puede proporcionar si no hay ningún nombre de usuario configurado en el archivo de configuración para un dispositivo. Debe proporcionarse si hay varios nombres de usuario del mismo rol de destino configurados en el archivo de configuración para un dispositivo.

Esta opción puede proporcionarse varias veces, lo cual es necesario para comandos que requieren varios roles a la vez.

También se puede especificar con la variable de entorno NETHSM_USER.
-h, --help
Imprimir ayuda (ver un resumen con '-h')
<ID_CLAVE>
El ID de la clave a la que se añade una etiqueta
También se puede especificar con la variable de entorno NETHSM_KEY_ID.
<ETIQUETA>
La etiqueta que se añade a la clave
También se puede especificar con la variable de entorno NETHSM_KEY_TAG.
