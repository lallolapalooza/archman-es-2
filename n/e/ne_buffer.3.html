NOMBRE

ne_buffer - manejo de búfer de cadenas

SINOPSIS

#include <ne_string.h>
typedef struct {
    char *data;
    size_t used;
    size_t length;
} ne_buffer;

DESCRIPCIÓN

El tipo ne_buffer representa un búfer de memoria expandible para contener cadenas terminadas en NUL. El campo data apunta al principio de la cadena, cuya longitud está dada por el campo used. El tamaño actual de la memoria asignada está dado por el campo length. No se recomienda manipular directamente los campos de un búfer. El puntero data puede cambiar cuando el búfer se modifica.

Un búfer se crea usando ne_buffer_create o ne_buffer_ncreate, y se destruye usando ne_buffer_destroy o ne_buffer_finish. Las funciones ne_buffer_append, ne_buffer_zappend y ne_buffer_concat se utilizan para agregar datos a un búfer.

Si la cadena referenciada por el puntero data se modifica directamente (en lugar de usar una de las funciones enumeradas anteriormente), se debe llamar a ne_buffer_altered.
