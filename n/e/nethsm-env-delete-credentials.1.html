NOMBRE

nethsm-env-delete-credentials - Eliminar credenciales de un dispositivo

SINOPSIS

nethsm env delete credentials [-a|--auth-passphrase-file] [-c|--config] [-l|--label] [-u|--user] [-h|--help] <NOMBRE>

DESCRIPCIÓN

Elimina las credenciales de un dispositivo.

OPCIONES

-a, --auth-passphrase-file <ARCHIVO_CONTRASEÑA_AUTORIZACION>
La ruta a un archivo que contiene una contraseña para la autenticación.

La contraseña proporcionada en el archivo debe ser la del usuario elegido para el comando.

Esta opción puede proporcionarse varias veces, lo que es necesario para comandos que requieren múltiples roles a la vez. Con múltiples archivos de contraseñas, el orden importa, ya que los archivos se asignan al usuario respectivo proporcionado por la opción "--user".

También puede especificarse con la variable de entorno NETHSM_AUTH_PASSPHRASE_FILE.
-c, --config <CONFIG>
La ruta a un archivo de configuración personalizado.

Si se especifica, se utiliza el archivo de configuración personalizado en lugar de la ubicación predeterminada del archivo de configuración.

También puede especificarse con la variable de entorno NETHSM_CONFIG.
-l, --label <ETIQUETA>
Una etiqueta que identifica de forma única un dispositivo en el archivo de configuración.

Debe proporcionarse si hay más de un dispositivo configurado en el archivo de configuración.

También puede especificarse con la variable de entorno NETHSM_LABEL.
-u, --user <USUARIO>
Un nombre de usuario que se utiliza para un comando.

Puede proporcionarse si no se ha configurado ningún nombre de usuario en el archivo de configuración para un dispositivo. Debe proporcionarse si hay varios nombres de usuario del mismo rol de destino configurados en el archivo de configuración para un dispositivo.

Esta opción puede proporcionarse varias veces, lo que es necesario para comandos que requieren múltiples roles a la vez.

También puede especificarse con la variable de entorno NETHSM_USER.
-h, --help
Imprime la ayuda (ver un resumen con '-h').
<NOMBRE>
El nombre de usuario que coincide con las credenciales que se van a eliminar.
También puede especificarse con la variable de entorno NETHSM_USER_NAME.
