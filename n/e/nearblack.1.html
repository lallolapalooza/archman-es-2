NOMBRE

nearblack - Convierte bordes casi negros/blancos a negros.

SINOPSIS

Uso: nearblack [--help] [--long-usage] [--help-general]
                 [-of <formato_salida>] [--quiet] [-co <NOMBRE>=<VALOR>]...
                 [-o <archivo_salida>]
                 [[-white]|[-color <c1,c2,c3...cn>]...]
                 [-nb <píxeles_no_negros>] [-near <distancia>] [-setalpha] [-setmask]
                 [-alg floodfill|twopasses]
                 <archivo_entrada>

DESCRIPCIÓN

Esta utilidad escanea una imagen e intenta establecer todos los píxeles que son casi o exactamente negros, blancos o uno o más colores personalizados alrededor del collar a negro o blanco. Esto se usa a menudo para "arreglar" fotos aéreas comprimidas con pérdida para que los píxeles de color puedan tratarse como transparentes al crear mosaicos. El formato de salida debe usar compresión sin pérdidas si no se establece una banda alfa o una banda de máscara.

--help
Mostrar este mensaje de ayuda y salir
--help-general
Proporciona un breve mensaje de uso para las opciones genéricas de línea de comandos de GDAL y sale.
-o <archivo_salida>
El nombre del archivo de salida que se creará.
-of <formato>
Selecciona el formato de salida. Si no se especifica, el formato se deduce de la extensión. Usa el nombre corto del formato (GTiff para GeoTIFF, por ejemplo).
-co <NOMBRE>=<VALOR>
Pasa una opción de creación al controlador del formato de salida. Se pueden listar múltiples opciones -co. Consulta la documentación específica del formato de los Controladores ráster para conocer las opciones de creación legales para cada formato.

Solo es válido al crear un archivo nuevo.

-white
Busca píxeles casi blancos (255) en lugar de píxeles casi negros.
-color <c1>,<c2>,<c3>...<cn>
Busca píxeles cercanos a los colores especificados. Se puede especificar varias veces. Cuando se especifica -color, los píxeles que se consideran collar se establecen en 0.
-near <distancia>
Selecciona qué tan lejos de negro, blanco o colores personalizados pueden estar los valores de los píxeles y aún así considerarse cercanos a negro, blanco o color personalizado. El valor predeterminado es 15.
-nb <píxeles_no_negros>
Número de píxeles consecutivos no negros que se pueden encontrar antes de renunciar a la búsqueda hacia adentro. El valor predeterminado es 2.
-setalpha
Añade una banda alfa si se especifica el archivo de salida y el archivo de entrada tiene 3 bandas, o establece la banda alfa del archivo de salida si se especifica y el archivo de entrada tiene 4 bandas, o establece la banda alfa del archivo de entrada si tiene 4 bandas y no se especifica ningún archivo de salida. La banda alfa se establece en 0 en el collar de la imagen y en 255 en el resto.
-setmask
Añade una banda de máscara al archivo de salida, o añade una banda de máscara al archivo de entrada si aún no la tiene y no se especifica ningún archivo de salida. La banda de máscara se establece en 0 en el collar de la imagen y en 255 en el resto.
-alg twopasses|floodfill
Añadido en la versión 3.8.

Selecciona el algoritmo a aplicar.

twopasses usa un paso de arriba a abajo seguido de un paso de abajo a arriba. Este es el único algoritmo implementado antes de GDAL 3.8. Puede fallar con áreas cóncavas. El algoritmo procesa la imagen línea por línea. Se realiza un escaneo "hacia adentro" desde cualquiera de los extremos, estableciendo píxeles en negro o blanco hasta que se hayan encontrado al menos "píxeles_no_negros" píxeles que estén a más de "distancia" niveles de gris de distancia del negro, blanco o colores personalizados, momento en el cual el escaneo se detiene. Los píxeles casi negros, blancos o de color personalizado se establecen a negro o blanco. El algoritmo también escanea de arriba a abajo y de abajo a arriba para identificar hendiduras en la parte superior o inferior.

-q
Suprime el monitor de progreso y otra salida que no sea de error.
<archivo_entrada>
El archivo de entrada. Cualquier formato compatible con GDAL, cualquier número de bandas, normalmente bandas Byte de 8 bits.

Todo el procesamiento se realiza en 8 bits (Bytes).

Si se omite el archivo de salida, los resultados procesados se escribirán de nuevo en el archivo de entrada, que debe admitir actualizaciones.

API C

Esta utilidad también se puede llamar desde C con GDALNearblack().
