NET-SERVER(1p) Documentación de Perl aportada por el usuario NET-SERVER(1p)

NOMBRE

net-server - Módulo base de inicio de Net::Server

SINOPSIS

net-server [tipo base] [argumentos de servidor net]
net-server PreFork ipv '*'
net-server HTTP
net-server HTTP app foo.cgi
net-server HTTP app foo.cgi app /=bar.cgi
net-server HTTP port 8080 port 8443/ssl ipv '*' server_type PreFork --SSL_key_file=my.key --SSL_cert_file=my.crt access_log_file STDERR

DESCRIPCIÓN

El programa net-server proporciona una forma sencilla de probar código y probar parámetros de conexión de puertos. Aunque el servidor en ejecución puede ser lo suficientemente robusto para producción, se anticipa que este binario solo se utilizará para pruebas básicas de puertos de net-server, actuando como un simple servidor de eco o para ejecutar scripts de desarrollo como CGI.

OPCIONES

"tipo base"
El primer argumento puede ser un sabor de Net::Server. Esto se proporciona como una forma abreviada de escribir server_type "ServerFlavor". Adicionalmente, esto permite que tipos como HTTP y PSGI, que no son tipos base verdaderos de Net::Server, subclasen otros tipos de servidor a través de un argumento adicional server_type. 
net-server PreFork
net-server HTTP  # se convierte en un servidor HTTP en el sabor Fork
net-server HTTP server_type PreFork  # servidor HTTP preforking
"puerto"
Puerto en el que enlazar. El valor predeterminado es 80 si se ejecuta un servidor HTTP como root, 8080 si se ejecuta un servidor HTTP como no root, o 20203 en caso contrario.

Se pueden dar varios valores para enlazar a varios puertos. Todos los métodos para especificar atributos de puerto enumerados en Net::Server y Net::Server::Proto están disponibles aquí.

net-server port 20201
net-server port 20202
net-server port 20203/IPv6
"host"
Host en el que enlazar. El valor predeterminado es *. Se enlazará a un socket IPv4 si se proporciona una dirección IPv4. Se enlazará a un socket IPv6 si se proporciona una dirección IPv6 (requiere la instalación de IO::Socket::INET6).

Si se proporciona un nombre de host y "ipv" todavía está establecido en 4, se creará un socket IPv4. Si se proporciona un nombre de host y "ipv" está establecido en 6, se creará un socket IPv6. Si se proporciona un nombre de host y "ipv" está establecido en \* (predeterminado), se realizará una búsqueda y se enlazarán todas las direcciones IPv4 o IPv6 disponibles. El parámetro "ipv" se puede establecer directamente, o pasar en el puerto, o además se puede pasar como parte del nombre de host.

net-server host localhost
net-server host localhost/IPv4

Hay muchas más opciones disponibles. Por favor, consulte la documentación de Net::Server.
