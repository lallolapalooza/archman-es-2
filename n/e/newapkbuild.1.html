newapkbuild(1) Manual de Comandos Generales newapkbuild(1)

NOMBRE

newapkbuild - generar un nuevo APKBUILD

SINOPSIS

newapkbuild opciones... [nombre_paquete[-version_paquete] | url_fuente]

DESCRIPCIÓN

newapkbuild genera un nuevo APKBUILD para usar con abuild(1). nombre_paquete especifica el nombre del paquete, si no está ya especificado con -n. Si va seguido de un guion (-) y una cadena de versión válida version_paquete, especifica adicionalmente la versión del paquete.

newapkbuild intentará detectar automáticamente el sistema de compilación inspeccionando el directorio fuente si se especifica url_fuente, y escribirá las instrucciones de compilación típicas para ese sistema de compilación. Si no especifica la URL fuente, o desea anular la detección automática, puede especificar el sistema de compilación con la opción apropiada. Si no se especifica url_fuente ni ninguna opción, el archivo APKBUILD generado no contendrá ninguna instrucción de compilación.

OPCIONES

-a

Especifica que el paquete utiliza autotools.

-C

Especifica que el paquete utiliza CMake. CMake se añadirá a los makedepends.

-c

Hace que newapkbuild copie además un script init.d, un archivo conf.d y scripts de pre e post-instalación de ejemplo al directorio APKBUILD. Esto le permite tener un inicio rápido para paquetes daemon. Consulte la sección ARCHIVOS para más detalles.

-d DESC

Especifica la descripción (pkgdesc=) para el nuevo paquete.

-e, -y

Especifica que el paquete utiliza un sistema de compilación Python PEP517. gpep517, setuptools y wheel de Python se añadirán a los makedepends.

-f

Fuerza a newapkbuild a sobrescribir un APKBUILD existente, si ya existe uno en el directorio del paquete.

-h

Muestra información de uso.

-l LICENCIA

Especifica la licencia bajo la cual se distribuye el nuevo paquete. Esto debe coincidir con un Identificador SPDX.

-m

Especifica que el paquete utiliza Meson. Meson se añadirá a los makedepends.

-n NOMBRE

Especifica el nombre del nuevo paquete. Se creará un nuevo directorio llamado NOMBRE en el directorio actual, con el archivo APKBUILD.

-p

Especifica que el paquete utiliza un archivo Perl Makefile.PL. Se usará la plantilla CPAN y Perl se añadirá a los depends.

-r

Especifica que el paquete utiliza Cargo. Cargo se añadirá a los makedepends.

-s

Crea una URL automática de SourceForge para el paquete basada en su nombre y versión. Esto solo es válido si se especifica nombre_paquete-version_paquete en la línea de comandos.

-u URL

Especifica la página web (url=) para el nuevo paquete. Esto no debe ser la URL del paquete fuente; debe ser la página web principal del proyecto.

ARCHIVOS

Todos los archivos generados se colocarán en un directorio nombre_paquete dentro del directorio de trabajo actual, creándose nombre_paquete si no existe.

APKBUILD

newapkbuild creará un APKBUILD con los detalles recopilados de la invocación de newapkbuild y la introspección de la fuente del paquete descargada si se proporciona url_fuente. Para más información sobre APKBUILD y su formato, consulte APKBUILD(5).

nombre_paquete.initd

Si se proporciona -c, newapkbuild creará nombre_paquete.initd con datos de ejemplo para ayudar en la creación de un script init.d para un daemon.

nombre_paquete.confd

Si se proporciona -c, newapkbuild creará nombre_paquete.confd para ayudar en la creación de un archivo conf.d para un daemon, utilizado por los scripts init.d. Los archivos conf.d se utilizan para configurar scripts init.d; para más información, consulte openrc(8) y rc_config(3).

nombre_paquete.pre-install

Si se proporciona -c, newapkbuild creará nombre_paquete.pre-install, cuyo contenido será ejecutado por apk(8) antes de instalar el paquete.

nombre_paquete.post-install

Si se proporciona -c, newapkbuild creará nombre_paquete.post-install, cuyo contenido será ejecutado por apk(8) después de que el paquete se instale correctamente. Para más información sobre los hooks de instalación de apk, consulte el manual de apk(8).

EJEMPLOS

newapkbuild \
	-n sharutils \
	-d "Utilidades para manipular archivos shell" \
	-l "GPL-3.0+" \
	-u "https://www.gnu.org/software/sharutils/" \
	-a \
	"https://ftp.gnu.org/gnu/sharutils/sharutils-4.15.2.tar.xz"
