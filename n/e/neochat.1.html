NEOCHAT(1) Manual de Usuario de NeoChat NEOCHAT(1)

neochat

NOMBRE

neochat - Cliente para interactuar con el protocolo de mensajería matrix

SINOPSIS

neochat [URI]

DESCRIPCIÓN

neochat es una aplicación de chat para el protocolo matrix que funciona tanto en escritorio como en móvil.

OPCIONES

URI

La URI de matrix para un usuario o una sala. Ej: matrix:u/usuario:ejemplo.org y matrix:r/root:ejemplo.org. Esto hará que NeoChat intente abrir la sala o conversación dada.

REPORTE DE ERRORES

Puede reportar errores y solicitudes de características en https://bugs.kde.org/enter_bug.cgi?product=NeoChat&component=General

VER TAMBIÉN


Una lista de preguntas frecuentes sobre Matrix https://matrix.org/faq/
