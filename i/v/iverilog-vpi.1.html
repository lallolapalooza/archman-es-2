NOMBRE

iverilog-vpi - Frontal de compilación para módulos VPI

SINOPSIS

iverilog-vpi [opciones] archivo-fuente...

DESCRIPCIÓN

iverilog-vpi es una herramienta para simplificar la compilación de módulos VPI para su uso con Icarus Verilog. Toma una lista de archivos fuente C o C++ en la línea de comandos y genera como salida un módulo VPI enlazado. Consulte la página del manual vvp(1) para obtener una descripción de cómo el módulo enlazado es cargado por una simulación.

Por defecto, la salida se nombra según el primer archivo fuente. Por ejemplo, si el primer archivo fuente se llama foo.c, la salida se convierte en foo.vpi.

OPCIONES

iverilog-vpi acepta las siguientes opciones:

-lbiblioteca
Incluir la biblioteca nombrada en el enlace del módulo VPI. Esto permite que los módulos VPI referencien bibliotecas externas adicionales.
-Ldirectorio
Añadir directorio a la lista de directorios que serán buscados para archivos de biblioteca.
-Idirectorio
Añadir directorio a la lista de directorios que serán buscados para archivos de cabecera.
-Ddefinición
Definir una macro llamada definición.
--nombre=nombre
Normalmente, el módulo VPI de salida se nombrará según el primer archivo fuente pasado al comando. Esta opción establece el nombre (sin el sufijo .vpi) del módulo vpi de salida.

OPCIONES SOLO PARA PC

Cuando se compila como un programa nativo de Windows (usando la cadena de herramientas MinGW), por defecto iverilog-vpi intentará localizar las herramientas MinGW necesarias para compilar un módulo VPI en la ruta del sistema (tal como se establece en la variable de entorno PATH). Como alternativa, el usuario puede especificar la ubicación de las herramientas MinGW a través de la siguiente opción.

-mingw=ruta
Indicar al programa la raíz del conjunto de herramientas del compilador MinGW. El tiempo de ejecución vvp se compila con este compilador, y este es el compilador que iverilog-vpi espera utilizar para compilar su código fuente. Si esta opción acompaña a una lista de archivos, se aplicará solo a la compilación actual. Si esta opción se proporciona por sí sola, iverilog-vpi guardará la ruta en el registro y utilizará esa ruta con preferencia a la ruta del sistema para operaciones posteriores, evitando la necesidad de especificarla en la línea de comandos cada vez.

OPCIONES INFORMACIONALES

iverilog-vpi incluye indicadores adicionales para que los gurús de Makefile puedan echar un vistazo a la configuración de la instalación de iverilog. De esta manera, se pueden escribir Makefiles que manejen compilaciones VPI complejas de forma nativa y sin codificar valores que dependan del sistema y la instalación. Si se utilizan, estas opciones deben usarse una a la vez y sin ninguna otra opción o directiva.

--directorio-instalacion
Imprimir el directorio de instalación para módulos VPI.
--cflags
Imprimir las opciones del compilador (CFLAGS o CXXFLAGS) necesarias para compilar código fuente destinado a un módulo VPI.
--ldflags
Imprimir las opciones del enlazador (LDFLAGS) necesarias para enlazar un módulo VPI.
--ldlibs
Imprimir las bibliotecas (LDLIBS) necesarias para enlazar un módulo VPI.

Ejemplo de archivo makefile GNU que aprovecha estas opciones:

CFLAGS = -Wall -O $(CFLAGS_$@)
VPI_CFLAGS := $(shell iverilog-vpi --cflags)
CFLAGS_messagev.o = $(VPI_CFLAGS)
CFLAGS_fifo.o = $(VPI_CFLAGS)
messagev.o fifo.o: transport.h
messagev.vpi: messagev.o fifo.o
iverilog-vpi $^
