DESCRIPCIÓ

N

Los objetos FBB::IFilterBuf pueden usarse como un std::streambuf para objetos std::istream, filtrando la información producida por dichos objetos. Debido a

que

IFilterBuf es un streambuf, su miembro underflow se llama automáticamente cuando se solicitan operaciones de lectura desde el objeto de flujo usando el IFilterBuf como su streambuf. Si no hay caracteres disponibles actualmente (es decir, srcBegin == srcEnd, véase la descripción del miembro filter más abajo), entonces filter se llama, el cual puede almacenar caracteres en un búfer (local) de como máximo maxSize caracteres (véase la descripción del constructor de IFilterBuf más abajo). Una vez que este búfer ha sido llenado, filter actualiza los punteros *srcBegin y *srcEnd de modo que apunten a, respectivamente, la ubicación del primer carácter en el búfer local y más allá de la ubicación del último carácter en el búfer local. La cl

ase

IFilterBuf fue diseñada teniendo en mente el BIO de openSSL (cf. bio(3ssl)). Dado que el concepto de BIO fue desarrollado en el contexto del lenguaje de programación C, los BIOs no soportan flujos de C++. No obstante, el concepto de un dispositivo de filtrado es atractivo, y es ofrecido por la clase FBB::IFilterBuf. Además del fi

ltrado,

IFilterBuf ofrece una gestión flexible del búfer interno: las clases derivadas pueden devolver caracteres al búfer interno hasta alcanzar el comienzo del búfer, pero pueden luego continuar añadiendo caracteres al búfer hasta que este haya alcanzado su tamaño máximo. Este tamaño máximo está definido por el parámetro maxSize del constructor (véase más abajo). La cl

ase

virtual bool

El miembro
filter está declarado como un miembro virtual puro: las clases derivadas deben sobreescribir filter con su propia implementación. Los objetos de las clases derivadas son responsables de obtener información (de cualquier cantidad) del dispositivo con el que interactúan. Esta información es
luego pasada al
IFilterBuf mediante dos punteros, que apuntan respectivamente al primer carácter disponible y más allá del último carácter disponible. Los caracteres indicados por este rango son posteriormente transferidos por el objeto IFilterBuf a su propio búfer, desde donde son luego recuperados (o a donde pueden ser devueltos) por la aplicación. El miem
bro
filter permite a las implementaciones filtrar y/o modificar la información obtenida por este miembro. La sección EJEMPLO más abajo proporciona un ejemplo que filtra un conjunto configurable de caracteres de un std::istream proporcionado. Las clases de Bobcat ISymCryptStreambuf(3bobcat) e IBase64Buf(3bobcat) proporcionan ejemplos adicionales de clases derivadas de IFilterBuf. El miem

filter debería devolver false si no hay (más) información disponible. Debería devolver true si hay información disponible, en cuyo caso *srcBegin y *srcEnd deberían apuntar a, respectivamente, el primer carácter y más allá del último carácter hecho disponible por filter; o

EJEMPL

O

Aquí hay una clase, derivada de IFilterBuf, que filtra un conjunto predefinido de caracteres. Se usa dos veces para filtrar dígitos y vocales, ilustrando el encadenamiento de objetos IFilt

erBuf. 
#include <iostream>
#include <fstream>
#include <istream>
#include <string>
#include <bobcat/ifilterbuf>
using namespace std;
using namespace FBB;
class CharFilterStreambuf: public IFilterBuf
{
    istream &         // flujo del que leer
    string d_rmChars;      // caracteres a eliminar
    string d_buffer;       // caracteres almacenados localmente
    size_t const d_maxSize = 100;
    public:
        CharFilterStreambuf(istream &in, string const &rmChars);
    private:
        bool filter(char const **srcBegin,
                    char const **srcEnd) override;
};
CharFilterStreambuf::CharFilterStreambuf(istream &in,
                                         string const &rmChars)
:
    d_in(in),
    d_rmChars(rmChars)
{
    setBuffer();        // necesario si peek() debe devolver el 1º
}                       // carácter disponible desde el principio
bool CharFilterStreambuf::filter(char const **srcBegin,
                                 char const **srcEnd)
{
    d_buffer.clear();
    while (d_buffer.size() != d_maxSize)
    {
        char ch;
        if (not d_in.get(ch))
            break;
        if (d_rmChars.find(ch) != string::npos) // se encontró el carácter a eliminar
            continue;
        d_buffer.push_back(ch);
    }
    if (d_buffer.empty())
        return false;
    *srcBegin = d_buffer.data();
    *srcEnd = d_buffer.data() + d_buffer.size();
    return true;
}
int main(int argc, char **argv)
{
    if (argc == 1)
    {
        cout << "arg[1]: archivo a procesar, arg[2]: archivo procesado\n";
        return 0;
    }
    ifstream in{ argv[1] };
    CharFilterStreambuf buf1(in, "1234567890");
    istream in1(&buf1);
    CharFilterStreambuf buf2(in1, "AEIOUaeiou");
    istream in2(&buf2);
    ofstream out{ argv[2] };
    out << in2.rdbuf();
}
