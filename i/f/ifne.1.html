NOMBRE

ifne - Ejecutar comando si la entrada estándar no está vacía

SINOPSIS


ifne [-n] comando

DESCRIPCIÓN

ifne ejecuta el siguiente comando si y solo si la entrada estándar no está vacía.

OPCIONES

-n
Operación inversa. Ejecutar el comando si la entrada estándar está vacía.

Tenga en cuenta que si la entrada estándar no está vacía, se pasará a través de ifne en este caso.

EJEMPLO


find . -name core | ifne mail -E 'set escape' -s "Archivos core encontrados" root
