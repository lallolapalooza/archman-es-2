ifplugstatus(8) Manual del Administrador del Sistema ifplugstatus(8)

NOMBRE

ifplugstatus - Una herramienta de detección de conexión de red

SINOPSIS

ifplugstatus [opciones] [INTERFACE]

DESCRIPCIÓN

ifplugstatus es una utilidad que puede utilizarse para detectar el estado del enlace de un dispositivo Ethernet local de Linux, de forma muy similar a como funcionan mii-diag, mii-tool y ethtool. De hecho, soporta las tres API diferentes que utilizan estas tres herramientas. Además, soporta la comprobación de enlaces con la bandera de interfaz IFF_RUNNING, que la mayoría de los controladores modernos (no solo Ethernet) soportan, y la comprobación del estado de asociación con la API de extensiones inalámbricas para dispositivos WLAN.

Las API se prueban en el siguiente orden:

Primero la API más nueva: SIOCETHTOOL (también conocida como API de ethtool)

Segundo la API más antigua: SIOCGMIIREG (también conocida como API de mii-diag)

Luego la API de WLAN: extensiones inalámbricas (también conocida como API de iwconfig)

Seguido de la API más limpia: IFF_RUNNING (también conocida como API de ifconfig)

La API más antigua (SIOCPRIV también conocida como API de mii-tool) no se prueba ya que es obsoleta.

ifplugstatus puede utilizarse en scripts de shell ya que devuelve el estado actual como valor de retorno. Es especialmente útil para detectar las API disponibles en el controlador de red utilizado. (Opción -v)

OPCIONES

Puede especificar un dispositivo Ethernet en la línea de comandos. De lo contrario, ifplugstatus comprobará todas las interfaces de red disponibles.

-a | --auto
Habilita la interfaz automáticamente antes de consultar (por defecto: desactivado)
-h | --help
Muestra la ayuda
-q | --quiet
Disminuye la verbosidad en uno. Si la verbosidad es < 0, no se mostrará texto, solo el valor de retorno es relevante; si la verbosidad es = 0, se mostrará un estado conciso; si la verbosidad es > 0, se devolverá información detallada sobre la API utilizada. (Por defecto, la verbosidad es 0)
-v | --verbose
Aumenta la verbosidad en uno. Ver opción -q.
-V | --version
Muestra la versión

VALORES DE RETORNO

0 Éxito

1 Fallo

2 Detección de conexión de red (solo disponible cuando se especifica una interfaz)

3 Desconectado (lo mismo aquí)
