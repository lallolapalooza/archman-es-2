if_indextoname(3) Manual de funciones de la biblioteca if_indextoname(3)

NOMBRE

if_nametoindex, if_indextoname - mapeos entre nombres de interfaz de red e índices

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <net/if.h>
unsigned int if_nametoindex(const char *ifname);
char *if_indextoname(unsigned int ifindex, char *ifname);

DESCRIPCIÓN

La función if_nametoindex() devuelve el índice de la interfaz de red correspondiente al nombre ifname.

La función if_indextoname() devuelve el nombre de la interfaz de red correspondiente al índice de interfaz ifindex. El nombre se coloca en el búfer apuntado por ifname. El búfer debe permitir el almacenamiento de al menos IF_NAMESIZE bytes.

VALOR DE RETORNO

En caso de éxito, if_nametoindex() devuelve el número de índice de la interfaz de red; en caso de error, se devuelve 0 y se establece errno para indicar el error.

En caso de éxito, if_indextoname() devuelve ifname; en caso de error, se devuelve NULL y se establece errno para indicar el error.

ERRORES

if_nametoindex() puede fallar y establecer errno si:

ENODEV
No se encontró ninguna interfaz con el nombre dado.

if_indextoname() puede fallar y establecer errno si:

ENXIO
No se encontró ninguna interfaz para el índice.

if_nametoindex() y if_indextoname() también pueden fallar debido a cualquiera de los errores especificados para socket(2) o ioctl(2).
