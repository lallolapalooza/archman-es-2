NOMBRE

ifs - dibuja imágenes de sistemas de funciones iteradas giratorias y colisionantes

SINOPSIS

ifs [--display host:display.screen] [--visual visual] [--window] [--root] [--window-id número] [--no-db] [--delay número] [--detail número] [--colors número] [--functions número] [--iterate | --recurse] [--no-rotate] [--no-scale] [--no-translate] [--fps]

DESCRIPCIÓN

El programa ifs dibuja imágenes de sistemas de funciones iteradas giratorias y colisionantes.

OPCIONES

--visual visual
Especifica qué visual usar. Los valores legales son el nombre de una clase de visual, o el número de id (decimal o hexadecimal) de un visual específico.
--window
Dibuja en una ventana recién creada. Este es el comportamiento por defecto.
--root
Dibuja en la ventana raíz.
--window-id número
Dibuja en la ventana especificada.
--no-db
Deshabilita el doble buffer.
--delay número
Retardo por fotograma, en microsegundos. Por defecto: 20000
--colors número
Número de colores a usar. Por defecto: 200
--detail número
En modo --iterate, número de veces que se iterarán las funciones de forma aleatoria, en miles. En modo --recurse, número de veces que se aplicarán las funciones (profundidad de recursión) antes de dibujar cada punto. Por defecto: 9
--functions número
Número de funciones a iterar. Por defecto: 3
--iterate
Calcula iterando la aplicación de las funciones en orden aleatorio, generalmente más rápido que --recurse. Este es el comportamiento por defecto.
--recurse
Calcula aplicando recursivamente todas las combinaciones de las funciones. Este es el comportamiento histórico y puede producir un resultado más limpio que --iterate.
--no-rotate
Deshabilita el componente de rotación de las funciones.
--no-scale
Deshabilita el componente de escalado de las funciones.
--no-translate
Deshabilita el componente de traslación variable de las funciones.
--no-multi
Desactiva el modo multicolor, solo se usa un color para colorear todo el conjunto.
--fps
Muestra la tasa de fotogramas actual y la carga de la CPU.

AMBIENTE

DISPLAY
para obtener el host y el número de display por defecto.
XENVIRONMENT
para obtener el nombre de un archivo de recursos que anula los recursos globales almacenados en la propiedad RESOURCE_MANAGER.
XSCREENSAVER_WINDOW
El ID de la ventana a usar con --root.

VER TAMBIÉN

X(1), xscreensaver(1), ifs(6)
