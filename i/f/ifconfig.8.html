DESCRIPCIÓ

N

Ifconfig se utiliza para configurar las interfaces de red residentes en el kernel. Se utiliza en el momento del arranque para configurar las interfaces según sea necesario. Después de eso, generalmente solo es necesario cuando se está depurando o cuando se necesita ajustar el

sistema.

Si no se proporcionan argumentos, ifconfig muestra el estado de las interfaces actualmente activas. Si se proporciona un único argumento de interfaz, muestra solo el estado de la interfaz dada; si se proporciona un único argumento -a, muestra el estado de todas las interfaces, incluso

las que están caídas. De lo c
ontrario, configura una interfaz.

Familias de

Direcciones

Si el primer argumento después del nombre de la interfaz se reconoce como el nombre de una familia de direcciones soportada, esa familia de direcciones se utiliza para decodificar y mostrar todas las direcciones de protocolo. Las familias de direcciones soportadas actualmente incluyen inet (TCP/IP, por defecto), inet6 (IPv6), ax25 (Radio Paquetes AMPR), ddp (Appletalk Fase 2), ipx (Novell IPX) y netrom (Radio Paquetes AMPR). Todos los números proporcionados como partes en la notación decimal punteada de IPv4 pueden ser decimales, octales o hexadecimales, como se especifica en el estándar ISO C (es decir, un 0x o 0X inicial

implica hexadecimal; de lo contrario, un '0' inicial implica octal; de lo contrario, el número se interpreta como
decimal). El uso de números hexadecimales y octales no es compatible con la RFC y por lo tanto se desaconseja su uso.

S

Desde la versión del kernel 2.2 ya no hay estadísticas explícitas de interfaz para las interfaces alias. Las estadísticas impresas para la dirección original se comparten con todas las direcciones alias en el mismo dispositivo. Si quieres estadísticas por dirección, deberías añadir reglas de contabilidad explícitas para la dirección usando el comando iptables(8)

ERRORE

S

Ifconfig usa el método de acceso ioctl para obtener la información completa de la dirección, lo que limita las direcciones de hardware a 8 bytes. Debido a que la dirección de hardware de Infiniband tiene 20 bytes, solo los primeros 8 bytes se muestran correctamente. Por favor, use el comando ip link del paquete iproute2 para mostrar información de la capa de enlace, incluyendo la dirección de

hardware.

Aunque las direcciones appletalk

DDP e IPX se mostrarán, no puede
n ser alteradas por este comando.
