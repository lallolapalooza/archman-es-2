NOMBRE

ifuse - Monta directorios de un dispositivo iOS localmente usando fuse.

SINOPSIS

ifuse PUNTO_MONTAJE [OPCIONES]

DESCRIPCIÓN

Monta directorios de un dispositivo iOS localmente usando fuse. Por defecto, se monta el directorio de medios; las opciones permiten montar también el contenedor sandbox de una aplicación, la carpeta de documentos de una aplicación o incluso el sistema de archivos raíz en dispositivos con jailbreak.

Ejemplo:

$ ifuse /media/iPhone --root

Esto monta el sistema de archivos raíz del primer dispositivo conectado en este ordenador en el directorio /media/iPhone.

Los usuarios normales pueden desmontar montajes fuse usando "fusermount -u PUNTO_MONTAJE".

OPCIONES

-o opt,[opt...]
opciones de montaje.
-u, --udid UDID
monta un dispositivo específico por UDID.
-n, --network
conéctate a un dispositivo de red.
-h, --help
imprime información de uso.
-V, --version
imprime la versión.
-d, --debug
habilita la depuración de la comunicación de libimobiledevice.
--documents IDAPP
monta la carpeta 'Documents' de la aplicación identificada por IDAPP.
--container IDAPP
monta la raíz del sandbox de una aplicación identificada por IDAPP.
--list-apps
lista las aplicaciones instaladas que tienen el intercambio de archivos habilitado.
--root
monta el sistema de archivos raíz (se requiere un dispositivo con jailbreak).
