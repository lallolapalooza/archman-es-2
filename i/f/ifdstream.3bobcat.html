FBB::IFdStream(3bobcat) Flujo de entrada de descriptor de archivo FBB::IFdStream(3bobcat)

NOMBRE

FBB::Ifdstream - Flujo de entrada inicializado por un descriptor de archivo

SINOPSIS

#include <bobcat/ifdstream> (al usar FBB::IFdStream
#include <bobcat/ifdstreams> (al usar FBB::IFdStreamS

Opción de enlace: -lbobcat

DESCRIPCIÓN

Los objetos FBB::IFdStream se utilizan para extraer información de dispositivos cuyos descriptores de archivo están disponibles.

Los objetos FBB::IFdStreamS operan como objetos FBB::IFdStream pero utilizan objetos FBB::Selector para verificar si hay información disponible en el descriptor de archivo del objeto antes de leer información del descriptor de archivo.

Los descriptores de archivo no están definidos en el contexto de C++, pero pueden usarse en sistemas operativos que soportan el concepto. Tenga en cuenta que el uso de descriptores de archivo introduce dependencias del sistema operativo.

Tenga en cuenta que los sockets pueden usarse como descriptores de archivo.

ESPACIO DE NOMBRES

FBB
Todos los constructores, miembros, operadores y manipuladores mencionados en esta página del manual están definidos en el espacio de nombres FBB.

HEREDA DE

std::istream

CONSTRUCTORES

o
IFdStream(int fd, size_t n = 1):
El constructor inicializa el objeto para leer del descriptor fd, utilizando un búfer de tamaño n, que por defecto tiene tamaño 1.
Use IFdStreamS(int fd, size_t n = 1) para construir un objeto IFdStreamS.

Los constructores de copia y movimiento (y los operadores de asignación) no están disponibles.

FUNCIONES MIEMBRO

Todos los miembros de std::istream están disponibles, ya que FBB::IFdStream(S) hereda de esta clase. No hay miembros adicionales.

EJEMPLO

Consulte la página del manual de clientsocket(3bobcat) para ver un ejemplo de cómo usar IFdStream.

ARCHIVOS

VER TAMBIÉN

bobcat(7), ifdbuf(3bobcat), ofdstream(3bobcat), selector(3bobcat)

ERRORES

El objeto IFdStream(S) utiliza un IFdBuf(S) para su std::streambuf. Este búfer está asociado con el descriptor de archivo pasado al constructor de IFdStream(S). Cuando el objeto IFdStream(S) sale del ámbito, el dispositivo (archivo, socket, etc.) al que se pasó el descriptor de archivo en el constructor de IFdStream(S) **no** se cierra.
