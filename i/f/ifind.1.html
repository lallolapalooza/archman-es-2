IFIND(1) Manual de Comandos Generales IFIND(1)

NOMBRE

ifind - Encuentra la estructura de metadatos que ha asignado una unidad de disco o nombre de archivo dado.

SINOPSIS

ifind [-avVl] [-f tipo_fs] [-d unidad_datos] [-n archivo] [-p inodo_padre] [-z ZONA] [-i tipo_img] [-o offset_img] [-b tam_sect_dev] imagen [imágenes]

DESCRIPCIÓN

ifind encuentra la estructura de metadatos que tiene unidad_datos asignada como unidad de datos o que tiene un nombre de archivo dado. En algunos casos, cualquiera de las estructuras puede no estar asignada y aun así encontrará los resultados.

ARGUMENTOS

Hay varios argumentos obligatorios y opcionales. Los nombres de los archivos de imagen deben especificarse cada vez:

[imagen [imágenes]]
La imagen de disco o partición a leer, cuyo formato se especifica con '-i'. Se pueden dar varios nombres de archivo de imagen si la imagen está dividida en múltiples segmentos. Si solo se da un archivo de imagen y su nombre es el primero de una secuencia (por ejemplo, indicado por terminar en '.001'), los segmentos de imagen subsiguientes se incluirán automáticamente.

También debe especificar qué está buscando e incluir uno de los siguientes:

-d unidad_datos
Encuentra la estructura de metadatos que tiene asignada una unidad de datos (bloque, clúster, etc.) dada.
-n archivo
Encuentra la estructura de metadatos a la que apunta el nombre de archivo dado.
-p inodo_padre
Encuentra las entradas MFT no asignadas en una imagen NTFS que tienen el inodo dado como padre. Se puede usar con '-l y -z'.

También hay varios argumentos opcionales:

-a
Encuentra todas las estructuras de metadatos (solo funciona cuando se busca con una unidad_datos).
-f tipo_fs
Especifica el tipo de sistema de archivos. Usa '-f list' para listar los tipos de sistemas de archivos compatibles. Si no se da, se utilizan métodos de autodetección.
-l
Lista los detalles de cada archivo encontrado con '-p', como 'fls -l'.
-i tipo_img
Identifica el tipo de archivo de imagen, como raw. Usa '-i list' para listar los tipos compatibles. Si no se da, se utilizan métodos de autodetección.
-o offset_img
El desplazamiento de sector donde comienza el sistema de archivos en la imagen.
-b tam_sect_dev
El tamaño, en bytes, de los sectores del dispositivo subyacente. Si no se da, se utiliza el valor en el formato de imagen (si existe) o se asumen 512 bytes.
-v
Salida detallada a stderr.
-V
Mostrar versión.
-z ZONA
Si se hubieran dado '-p -l', esto establecerá la zona horaria para las horas correctas.

EJEMPLOS

# ifind -f fat -d 456 fat-img.dd

# ifind -f linux-ext2 -n "/etc/" linux-img.dd

# ifind -f ntfs -p 5 -l -z EST5EDT ntfs-img.dd
