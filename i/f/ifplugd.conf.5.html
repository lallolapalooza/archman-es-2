NOMBRE

ifplugd.conf - archivo de configuración de ifplugd

SINOPSIS

/etc/ifplugd/ifplugd.conf

DESCRIPCIÓN

ifplugd.conf es el archivo de configuración de ifplugd. Es un script de shell que es interpretado por el script de inicio que arranca el demonio. Debe ser usado para establecer variables de entorno que son interpretadas por el script de inicio:

OPCIONES

INTERFACES
Especifica las interfaces de red a monitorizar. Debe contener una lista de nombres de interfaces de red separada por espacios. La mayoría de los usuarios probablemente usarán "eth0" aquí, sin embargo, puede agregar interfaces adicionales para monitorizar más de un dispositivo. También se admite un valor especial: "auto" habilitará una detección más o menos funcional de los dispositivos de red disponibles. Esto no le satisfará cuando use la carga automática de módulos de red, ya que no puede detectar dispositivos de red que no están cargados actualmente.
ARGS
Argumentos de línea de comandos adicionales para la invocación de ifplugd. Vea ifplugd(8) para más información.
ARGSiface
Si se especifica para una interfaz, esta variable tiene prioridad sobre ARGS. Esto puede ser útil si hay más de un dispositivo de red presente.
