if(3perl) Guía de referencia para programadores de Perl if(3perl)

NOMBRE

if - "use" un módulo de Perl si una condición se cumple

SINOPSIS

use if CONDICION, "MODULO", ARGUMENTOS;
no  if CONDICION, "MODULO", ARGUMENTOS;

DESCRIPCIÓN

"use if"

El módulo "if" se usa para cargar condicionalmente otro módulo. La construcción:

use if CONDICION, "MODULO", ARGUMENTOS;

... cargará "MODULO" solo si "CONDICION" se evalúa como verdadera; no tiene efecto si "CONDICION" se evalúa como falsa. (El nombre del módulo, asumiendo que contiene al menos un "::", debe entrecomillarse cuando 'use strict "subs";' está en vigor.) Si la CONDICION se evalúa como verdadera, entonces la línea anterior tiene el mismo efecto que:

use MODULO ARGUMENTOS;

Por ejemplo, la función charinfo del módulo Unicode::UCD usa dos funciones de Unicode::Normalize solo si se cumple una cierta condición:

use if defined &DynaLoader::boot_DynaLoader,
    "Unicode::Normalize" => qw(getCombinClass NFD);

Supongamos que quieres que "ARGUMENTOS" sea una lista vacía, es decir, que tenga el efecto de:

use MODULO ();

No puedes hacer esto con la pragma "if"; sin embargo, puedes lograr exactamente este efecto, en tiempo de compilación, con:

BEGIN { require MODULO if CONDICION }

"no if"

La construcción "no if" se usa principalmente para desactivar categorías de advertencias cuando esas categorías producirían una salida superflua bajo versiones especificadas de perl.

Por ejemplo, la categoría "redundant" de advertencias se introdujo en Perl-5.22. Esta advertencia marca ciertas instancias de argumentos superfluos a "printf" y "sprintf". Pero si tu código se ejecutaba sin advertencias en versiones anteriores de perl y no te importan las advertencias "redundant" en versiones más recientes, puedes llamar:

use warnings;
no if $] >= 5.022, q|warnings|, qw(redundant);
my $test    = { fmt  => "%s", args => [ qw( x y ) ] };
my $result  = sprintf $test->{fmt}, @{$test->{args}};

La construcción "no if" asume que un módulo o pragma ha implementado correctamente un método unimport() -- pero la mayoría de los módulos y pragmas no lo han hecho. Eso explica por qué la construcción "no if" tiene una aplicabilidad limitada.

ERRORES

La implementación actual no permite la especificación de la versión requerida del módulo.

VER TAMBIÉN

Module::Requires se puede usar para cargar condicionalmente uno o más módulos, con restricciones basadas en la versión del módulo. A diferencia de "if", sin embargo, Module::Requires no es un módulo principal.

Module::Load::Conditional proporciona una serie de funciones que puedes usar para consultar qué módulos están disponibles y luego cargar uno o más de ellos en tiempo de ejecución.

El módulo provide de CPAN se puede usar para seleccionar uno de varios módulos posibles para cargar basándose en la versión de Perl que se está ejecutando.
