NOMBRE

ifdata - obtener información de la interfaz de red sin analizar la salida de ifconfig

SINOPSIS


ifdata
[opciones] {interfaz}

DESCRIPCIÓN

ifdata se puede usar para verificar la existencia de una interfaz de red o para obtener información sobre la interfaz, como su dirección IP. A diferencia de ifconfig o ip, ifdata tiene una salida simple de analizar diseñada para ser utilizada fácilmente por un script de shell.

OPCIONES

-h
Imprime un resumen de ayuda.
-e
Comprueba si la interfaz existe, sale con valor distinto de cero si no es así.
-p
Imprime toda la configuración de la interfaz.
-pe
Imprime "sí" o "no" si la interfaz existe o no.
-pa
Imprime la dirección IPv4 de la interfaz.
-pn
Imprime la máscara de red de la interfaz.
-pN
Imprime la dirección de red de la interfaz.
-pb
Imprime la dirección de broadcast de la interfaz.
-pm
Imprime la MTU de la interfaz.

Las siguientes opciones son solo para Linux.

-ph
Imprime la dirección de hardware de la interfaz. Sale con un código de error si no hay una dirección de hardware para la interfaz de red dada.
-pf
Imprime las banderas de la interfaz.
-si
Imprime todas las estadísticas de entrada de la interfaz.
-sip
Imprime el número de paquetes de entrada.
-sib
Imprime el número de bytes de entrada.
-sie
Imprime el número de errores de entrada.
-sid
Imprime el número de paquetes de entrada descartados.
-sif
Imprime el número de desbordamientos FIFO de entrada.
-sic
Imprime el número de paquetes de entrada comprimidos.
-sim
Imprime el número de paquetes multicast de entrada.
-so
Imprime todas las estadísticas de salida de la interfaz.
-sop
Imprime el número de paquetes de salida.
-sob
Imprime el número de bytes de salida.
-soe
Imprime el número de errores de salida.
-sod
Imprime el número de paquetes de salida descartados.
-sof
Imprime el número de desbordamientos FIFO de salida.
-sox
Imprime el número de colisiones de salida.
-soc
Imprime el número de pérdidas de portadora de salida.
-som
Imprime el número de paquetes multicast de salida.
-bips
Imprime el número de bytes de tráfico entrante medido en un segundo.
-bops
Imprime el número de bytes de tráfico saliente medido en un segundo.
