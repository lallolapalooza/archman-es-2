if(n) Comandos integrados de Tcl if(n)

NOMBRE

if - Ejecuta scripts condicionalmente

SINOPSIS

if expr1 ?then? body1 elseif expr2 ?then? body2 elseif ... ?else? ?bodyN?

DESCRIPCIÓN

El comando if evalúa expr1 como una expresión (de la misma manera que expr evalúa su argumento). El valor de la expresión debe ser booleano (un valor numérico, donde 0 es falso y cualquier otro valor es verdadero, o un valor de cadena como true o yes para verdadero y false o no para falso); si es verdadero, se ejecuta body1 pasándolo al intérprete Tcl. De lo contrario, se evalúa expr2 como una expresión y si es verdadero, se ejecuta body2, y así sucesivamente. Si ninguna de las expresiones se evalúa como verdadera, se ejecuta bodyN. Los argumentos then y else son palabras opcionales para hacer el comando más fácil de leer. Puede haber cualquier número de cláusulas elseif, incluido cero. BodyN también puede omitirse siempre que else también se omita. El valor de retorno del comando es el resultado del script de cuerpo que se ejecutó, o una cadena vacía si ninguna de las expresiones fue distinta de cero y no hubo bodyN.

EJEMPLOS

Una condición simple:

if {$vbl == 1} { puts "vbl es uno" }

Con una cláusula else:

if {$vbl == 1} {
    puts "vbl es uno"
} else {
    puts "vbl no es uno"
}

Con una cláusula elseif también:

if {$vbl == 1} {
    puts "vbl es uno"
} elseif {$vbl == 2} {
    puts "vbl es dos"
} else {
    puts "vbl no es uno ni dos"
}

Recuerda, las expresiones pueden ser de varias líneas, pero en ese caso puede ser una buena idea usar la palabra clave opcional then para mayor claridad:

if {
    $vbl == 1
    || $vbl == 2
    || $vbl == 3
} then {
    puts "vbl es uno, dos o tres"
}

VER TAMBIÉN

PALABRAS CLAVE
