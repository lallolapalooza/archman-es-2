if_nameindex(3) Manual de Funciones de Biblioteca if_nameindex(3)

NOMBRE

if_nameindex, if_freenameindex - obtener nombres e índices de interfaces de red

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <net/if.h>
struct if_nameindex *if_nameindex(void);
void if_freenameindex(struct if_nameindex *ptr);

DESCRIPCIÓN

La función if_nameindex() devuelve una matriz de estructuras if_nameindex, cada una que contiene información sobre una de las interfaces de red en el sistema local. La estructura if_nameindex contiene al menos las siguientes entradas:


unsigned int if_index;  /* Índice de la interfaz (1, 2, ...) */
char        *if_name;   /* Nombre terminado en nulo ("eth0", etc.) */

El campo if_index contiene el índice de la interfaz. El campo if_name apunta al nombre de la interfaz terminado en nulo. El final de la matriz se indica con una entrada con if_index establecido a cero y if_name establecido a NULL.

La estructura de datos devuelta por if_nameindex() se asigna dinámicamente y debe liberarse usando if_freenameindex() cuando ya no sea necesaria.

VALOR DE RETORNO

En caso de éxito, if_nameindex() devuelve un puntero a la matriz; en caso de error, se devuelve NULL y se establece errno para indicar el error.

ERRORES

if_nameindex() puede fallar y establecer errno si:

ENOBUFS
Recursos insuficientes disponibles.

if_nameindex() también puede fallar por cualquiera de los errores especificados para socket(2), bind(2), ioctl(2), getsockname(2), recvmsg(2), sendto(2), o malloc(3).

ATRIBUTOS

Para obtener una explicación de los términos utilizados en esta sección, consulte attributes(7).

Interfaz Atributo Valor
if_nameindex (), if_freenameindex () Seguridad de hilos MT-Safe

ESTANDARES

POSIX.1-2008, RFC 3493.

HISTORIAL

glibc 2.1. POSIX.1-2001. BSDi.

Antes de glibc 2.3.4, la implementación solo admitía interfaces con direcciones IPv4. El soporte para interfaces que no tienen direcciones IPv4 solo está disponible en núcleos que admiten netlink.

EJEMPLOS

El siguiente programa demuestra el uso de las funciones descritas en esta página. Un ejemplo de la salida que este programa podría producir es la siguiente:


$ ./a.out;
1: lo
2: wlan0
3: em1

Fuente del programa

#include <net/if.h>
#include <stdio.h>
#include <stdlib.h>
#include <unistd.h>
int
main(void)
{
    struct if_nameindex *if_ni, *i;
    if_ni = if_nameindex();
    if (if_ni == NULL) {
        perror("if_nameindex");
        exit(EXIT_FAILURE);
    }
    for (i = if_ni; !(i->if_index == 0 && i->if_name == NULL); i++)
        printf("%u: %s\n", i->if_index, i->if_name);
    if_freenameindex(if_ni);
    exit(EXIT_SUCCESS);
}
