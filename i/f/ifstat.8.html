IFSTAT(8) Linux IFSTAT(8)

NOMBRE

ifstat - utilidad práctica para leer estadísticas de interfaces de red

SINOPSIS


ifstat [ OPCIONES ] [ LISTA_INTERFACES ]

LISTA_INTERFACES := LISTA_INTERFACES | interfaz

DESCRIPCIÓN

ifstat imprime ordenadamente estadísticas de interfaces de red. La utilidad mantiene registros de los datos mostrados previamente en archivos de historial y, por defecto, solo muestra la diferencia entre la última y la llamada actual. La ubicación de los archivos de historial es por defecto /tmp/.ifstat.u$UID pero puede ser sobrescrita con la variable de entorno IFSTAT_HISTORY. De manera similar, la ubicación por defecto para xstat (estadísticas extendidas) es /tmp/.<nombre_xstat>_ifstat.u$UID.

OPCIONES

-h, --help
Muestra un resumen de las opciones.
-V, --version
Muestra la versión del programa.
-a, --ignore
Ignora el archivo de historial.
-d, --scan=SEGUNDOS
Muestra estadísticas de muestra cada SECUNDOS segundos.
-e, --errors
Muestra errores.
-n, --nooutput
No muestra ninguna salida. Solo actualiza el archivo de historial.
-r, --reset
Reinicia el historial.
-s, --noupdate
No actualiza el archivo de historial.
-t, --interval=SEGUNDOS
Reporta el promedio de los últimos SECUNDOS segundos.
-z, --zeros
Muestra entradas con actividad cero.
-j, --json
Muestra los resultados en formato JSON
-p, --pretty
Si se combina con --json, imprime la salida de forma legible.
-x, --extended=TIPO
Muestra estadísticas extendidas del TIPO. Los tipos soportados son:


cpu_hits - Cuenta solo paquetes que pasaron por la CPU.

ENTORNO

IFSTAT_HISTORY
Si está configurada, su valor se interpreta como la ruta alternativa del archivo de historial.
