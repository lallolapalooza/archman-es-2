NOMBRE

isql, iusql - Herramientas de línea de comandos SQL interactivas de unixODBC

SINOPSIS

isql DSN [USUARIO [CONTRASEÑA]] [opciones]

iusql DSN [USUARIO [CONTRASEÑA]] [opciones]

iusql "CadenaDeConexión" [opciones]

DESCRIPCIÓN

isql y iusql son herramientas de línea de comandos que permiten a los usuarios ejecutar SQL de forma interactiva o por lotes.

Las herramientas proporcionan varias funciones útiles, incluyendo una opción para generar la salida envuelta en una tabla HTML.

iusql es lo mismo que isql pero incluye soporte integrado de Unicode. Algunas fuentes de datos solo funcionan con iusql. Una diferencia importante entre las dos herramientas es que isql se conecta usando SQLConnect y iusql se conecta usando SQLDriverConnect.

ARGUMENTOS

DSN
El Nombre de Fuente de Datos (DSN) utilizado para conectarse a la base de datos SQL. unixODBC busca el DSN especificado en /etc/odbc.ini y $HOME/.odbc.ini, teniendo prioridad el último.

Al buscar en los archivos de configuración, unixODBC busca un nombre simple. Si el DSN comienza con un punto y coma, se trata como una cadena de conexión. La cadena de conexión puede contener un DSN y/o otros parámetros separados por punto y coma.

USUARIO
Especifica el usuario o rol de la base de datos bajo el cual debe realizarse la conexión.

Este parámetro anula cualquier UID especificado en los archivos de configuración de la fuente de datos.

CONTRASEÑA
Contraseña requerida para acceder a la base de datos para el USUARIOespecificado.

Este parámetro anula cualquier CONTRASEÑA especificada en los archivos de configuración de la fuente de datos.

Al usar iusql, las contraseñas que contengan puntos y comas deben escaparse con llaves (corchetes curvos) y terminarse con un punto y coma. Consulte la sección de ejemplos más abajo para la sintaxis.

"CadenaDeConexión"
Una cadena de conexión que comience con DSN=, DRIVER= o FILEDSN= se pasará sin cambios a SQLDriverConnect. Esta opción permite el uso de una sintaxis más compleja en una cadena de conexión de lo que sería posible usando solo DSN, UID y PWD.

También (y esta era la razón principal de su inclusión) permite que las contraseñas contengan puntos y comas sin tener que añadir una sintaxis de escape compleja al código existente.

OPCIONES

-b
Ejecutar 'isql' en modo de lote no interactivo. En este modo, 'isql' procesa desde la entrada estándar, esperando un comando SQL por línea.
-dDELIMITADOR
Delimitar las columnas con el delimitadorespecificado.
-xHEX
Delimitar las columnas con el carácter representado en hexadecimal por HEX. El código hexadecimal debe estar en el formato 0xNN (por ejemplo, 0x09 para el carácter TAB).
-w
Formatear el resultado como una tabla HTML.
-c
Mostrar los nombres de las columnas en la primera fila. Esta opción solo puede usarse con las opciones -d o -x .
-mNÚM
Limitar el ancho de visualización de las columnas a NÚM caracteres.
-lLOCALIDAD
Establecer la localidad de caracteres a LOCALIDAD.
-q
Envolver los campos de texto entre comillas dobles.
-3
Usar llamadas de la versión 3 de ODBC.
-n
Procesar múltiples líneas de SQL, terminadas con el comando GO.
-e
Usar SQLExecDirect en lugar de Prepare.
-k
Usar SQLDriverConnect.
-v
Habilitar el modo verboso, describiendo completamente todos los errores. Esta opción es útil para depurar.
-i
Habilitar el modo no verboso, el texto de ayuda desaparece pero no desactiva indicaciones como la opción -b.
--version
Mostrar la versión del programa.
-LNÚM
Establecer el número máximo de caracteres mostrados de un campo de texto a NÚM. El valor por defecto es 300 caracteres.

COMANDOS

Esta sección describe brevemente algunos comandos en tiempo de ejecución de isql y iusql .

help

Listar todas las tablas en la base de datos.

help tabla

Listar todas las columnas en la tabla.

help help

Listar todas las opciones de ayuda.

EJEMPLOS

Un DSN simple:
$ iusql WebDB MyID MyPWD -w -b < My.sql

Se conecta al DSN WebDB como usuario MyID con la contraseña MyPWD, luego ejecuta los comandos en el archivo My.sql y devuelve los resultados envueltos en una tabla HTML.

Cada línea en My.sql debe contener solo un comando SQL, excepto la última línea, que debe estar en blanco (a menos que se especifique la opción -n ).

Un DSN en una cadena de conexión:

Observe el punto y coma inicial en la cadena de conexión.

$ iusql ";DSN=WebDB" MyID MyPWD -w -b < My.sql

Las opciones en el DSN pueden ser anuladas en la cadena de conexión:

$ iusql ";DSN=WebDB;Driver=PostgreSQL ODBC;UID=MyID;PASSWORD=secret;Debug=1;CommLog=1" -v
Un DSN de cadena:

Un DSN de cadena puede proporcionarse en su totalidad, sin ninguna referencia a un archivo DSN:

$ iusql ";Driver=PostgreSQL Unicode;UID=MyID;PASSWORD=secret" -v
Una contraseña que contiene un punto y coma (iusql):
$ iusql WebDB MyID '{My;PWD};'
$ iusql 'DSN=WebDB;UID=MyID;PWD={My;PWD};'

SOLUCIÓN DE PROBLEMAS

Mensajes de error crípticos

Vuelva a ejecutar isql o iusql con el indicador -v para obtener más información de los errores, y/o habilite el modo Trace en odbcinst.ini.

Definición de controlador ausente

Compruebe que el nombre del controlador especificado por la entrada Driver en la definición de la fuente de datos odbc.ini está presente en odbcinst.ini y coincide exactamente con el [nombre de sección]de odbcinst.ini.

Controlador no cargable o incompatible

Si el controlador ODBC está correctamente especificado para la fuente de datos, es posible que el controlador no sea cargable. Compruebe que no haya confusiones entre controladores Unicode y ANSI, y verifique las rutas de los controladores en el [nombre de sección] de odbcinst.ini.

Fuentes de datos Unicode con clientes ANSI

Algunas fuentes de datos son solo Unicode y requieren el uso de iusql. Si isql informa

  [IM002][unixODBC][Driver Manager]Data source name not found and no default driver specified
  [ISQL]ERROR: Could not SQLConnect
pero la fuente de datos y el controlador requeridos son listados por 
  odbcinst -q -d
y 
  odbcinst -q -s

NAME

iusql — Interactive SQL interface for unixODBC

SYNOPSIS

iusql [option…] [DSN] [uid username] [pwd password]

DESCRIPTION

The iusql command provides an interactive SQL interface to the unixODBC driver manager. It allows the user to connect to an ODBC data source and execute SQL statements.

ARGUMENTS

DSN
The Data Source Name to connect to. This can be a DSN defined in the odbc.ini file or a connection string.
uid
The username for connecting to the data source.
pwd
The password for connecting to the data source.

OPTIONS

-A
Prompt for connection attributes.
-D
Prompt for DSN.
-F
Force connection to DSN.
-H
Set the SQL HELPINFO environment variable.
-L
List available DSNs.
-P
Prompt for password.
-S
Prompt for SQL Server name.
-T
Trace.
-V
Version information.
-X
Trace ALL.
-h
Help message.
-q
Quiet mode.
-v
Verbose mode.

COMMANDS

Within the interactive interface, the following commands are available:

quit
Exit the program.
help
Show help message.
list
List available DSNs.
set
Set connection attributes.

Any line not starting with a recognized command is treated as an SQL statement.

EXAMPLES

Connect to a DSN named 'my_database' using username 'user' and password 'pass':

$ iusql my_database uid user pwd pass

List available DSNs:

$ iusql -L

Connect to a DSN and prompt for password:

$ iusql my_database uid user -P

TROUBLESHOOTING

If you encounter issues, ensure that your ODBC configuration (e.g., /etc/odbc.ini) is correct and that the necessary drivers are installed.

FILES

/etc/odbc.ini

System-wide Data Source Name (DSN) definitions. See odbc.ini(5) for more information.

$HOME/.odbc.ini

User-specific Data Source Name (DSN) definitions. See odbc.ini(5) for more information.
