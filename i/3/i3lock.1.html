DESCRIPCIÓ

N

i3lock es un bloqueador de pantalla simple como slock. Después de iniciarlo, verá una pantalla en blanco (puede configurar el color/una imagen). Puede volver a su pantalla introduciendo su

contraseña.

La opción -d (--dpms) fue eliminada de i3lock en la versión 2.8. Había bastantes
 casos de uso que no se abordaban correctamente, y bastantes errores alrededor d
e esa característica. Aunque las características no se eliminan normalmente de i
3 y sus herramientas, sentimos la necesidad de hacer una excepción en este caso.



Los usuarios que deseen habilitar DPMS explícitamente solo cuando su pantalla esté bloqueada pueden usar un script de envoltura 
alrededor de i3lock como el siguiente:

#!/bin/sh
revert() {
  xset dpms 0 0 0
}
trap revert HUP INT TERM
xset +dpms dpms 5 5 5
i3lock -n

revert

La opción -I (--inactivity-timeout=segundos) fue eliminada porque solo tiene sentido con 
DPMS.
