NOMBRE

i3-nagbar - muestra una barra de error en la parte superior de tu pantalla

SINOPSIS

i3-nagbar [-m <mensaje>] [-b <botón> <acción>] [-B <botón> <acción>] [-t advertencia|error] [-f <fuente>] [-v] [-p]

OPCIONES

-v, --version

Muestra el número de versión y sale.

-h, --help

Muestra un mensaje de ayuda corto y sale.

-t, --type tipo

Muestra un mensaje de advertencia o error. Esto solo cambia el esquema de colores para i3-nagbar. Por defecto: error.

-m, --message mensaje

Muestra mensaje como texto a la izquierda de i3-nagbar.

-f, --font fuente

Selecciona la fuente que se está utilizando.

-b, --button botón acción

Crea un botón con el texto botón. La acción son los comandos del shell que serán ejecutados por este botón. Se pueden definir múltiples botones. Lanzará los comandos del shell dentro de un emulador de terminal, usando i3-sensible-terminal.

-B, --button-no-terminal botón acción

Igual que lo anterior, pero ejecutará los comandos del shell directamente, sin lanzar un emulador de terminal.

-p, --primary

Siempre abre i3-nagbar en el monitor principal. Por defecto, se abre en el monitor enfocado.

DESCRIPCIÓN

i3-nagbar es utilizado por i3 para informarte sobre errores en tu archivo de configuración (por ejemplo). Si bien estos errores se registran en el archivo de registro (si existe), el pasado ha demostrado que los usuarios no son conscientes de su archivo de registro o no lo revisan después de modificar el archivo de configuración.

EJEMPLO

i3-nagbar -m '¡Tienes un error en tu archivo de configuración de i3!' \
-b 'editar configuración' 'i3-sensible-editor ~/.config/i3/config'
