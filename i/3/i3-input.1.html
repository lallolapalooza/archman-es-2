I3-INPUT(1) Manual de i3 I3-INPUT(1)

NOMBRE

i3-input - tomar interactivamente un comando para el gestor de ventanas i3

SINOPSIS

i3-input [-s <socket>] [-F <formato>] [-l <límite>] [-P <mensaje>] [-f <fuente>] [-v]

DESCRIPCIÓN

i3-input es una herramienta para tomar comandos (o partes de un comando) compuestos por el usuario y enviárselos a i3. Esto es útil, por ejemplo, para el comando mark/goto.

Puedes presionar Escape para cerrar i3-input sin enviar ningún comando.

OPCIONES

-s <socket>

Especifica la ruta al socket IPC de i3 (no debería ser necesario usar esta opción, i3-input determinará la ruta por sí mismo).

-F <formato>

Cada ocurrencia de "%s" en la cadena <formato> se reemplaza por la entrada del usuario, y el resultado se envía a i3 como un comando. El valor predeterminado es "%s".

-l <límite>

Establece la longitud máxima permitida de la entrada del usuario a <límite> caracteres. i3-input ejecutará automáticamente el comando cuando la entrada del usuario alcance esa longitud.

-P <mensaje>

Muestra la cadena <mensaje> delante del campo de texto de entrada del usuario. El mensaje no se incluye en la entrada/comando del usuario.

-f <fuente>

Utiliza la fuente principal de X11 especificada (usa xfontsel para elegir una fuente).

-v

Muestra la versión y sale.

EJEMPLOS

Marcar un contenedor con un solo carácter:

i3-input -F 'mark %s' -l 1 -P 'Marcar: '

Ir al contenedor marcado con el ejemplo anterior:

i3-input -F '[con_mark="%s"] focus' -l 1 -P 'Ir a: '

ENTORNO

I3SOCK

i3-input maneja las diferentes fuentes de rutas de socket en el siguiente orden:

• Variable de entorno I3SOCK
• I3SOCK se sobrescribe con el parámetro -s, si se especifica
• si ninguno está disponible, i3-input lee la ruta del socket de la propiedad X11, que es la forma recomendada
• si todo falla, i3-input intenta /tmp/i3-ipc.sock

La ruta del socket es necesaria para conectarse a i3 y emitir realmente el comando.
