I3(1) Manual de i3 I3(1)

NOMBRE

i3 - un gestor de ventanas en mosaico mejorado

SINOPSIS

i3 [-a] [-c configfile] [-C] [-d all] [-v] [-V]

OPCIONES

-a

Desactiva el arranque automático.

-c

Especifica una ruta de archivo de configuración alternativa.

-C

Comprueba la validez del archivo de configuración y sale.

-d all

Activa el registro de depuración. El parámetro all está presente por razones históricas.

-v

Muestra el número de versión (y la fecha del último commit).

-V

Modo verboso.

--force-xinerama

Usa Xinerama en lugar de RandR. Esta opción solo debe usarse si estás atascado con el antiguo controlador propietario de nVidia (anterior a 302.17) que no soporta RandR.

--get-socketpath

Obtiene la ruta del socket IPC de i3 desde X11, la imprime y luego sale.

--shmlog-size <limit>

Limita el tamaño del log SHM de i3 a <limit> bytes. Establecer esto en 0 desactiva el registro SHM por completo. El valor predeterminado es 0 bytes.

--replace

Reemplaza un gestor de ventanas existente.

DESCRIPCIÓN

INTRODUCCIÓN

i3 fue creado porque wmii, nuestro gestor de ventanas favorito en ese momento, no proporcionaba algunas características que queríamos (por ejemplo, soporte multi-monitor bien implementado), tenía algunos errores, no progresaba desde hacía bastante tiempo y no era fácil de modificar (los comentarios/documentación del código fuente estaban completamente ausentes). Aun así, creemos que los desarrolladores y colaboradores de wmii hicieron un gran trabajo. Gracias por inspirarnos a crear i3.

Ten en cuenta que i3 está dirigido principalmente a usuarios avanzados y desarrolladores.

NOTA IMPORTANTE PARA LOS USUARIOS DEL CONTROLADOR BINARIO DE nVidia

Si estás usando el controlador gráfico binario de nVidia (también conocido como blob) anterior a la versión 302.17, necesitas usar el flag --force-xinerama (en tu ~/.xsession) al iniciar i3, así:

exec i3 --force-xinerama -V >>~/.i3/i3log 2>&1

Consulta también docs/multi-monitor para la explicación completa.

TERMINOLOGÍA

Árbol

i3 mantiene tu diseño en una estructura de datos de árbol.

Ventana

Una ventana X11, como la ventana del navegador Firefox o un emulador de terminal.

Ventana flotante

Una ventana que "flota" sobre otras ventanas. i3 usa este estilo para mostrar ventanas X11 con el tipo "dialog", como los cuadros de diálogo "Print" u "Open File" en muchas aplicaciones GUI. El uso de ventanas flotantes puede ajustarse finamente con el comando for_window (consulta la guía de usuario HTML).

Contenedor dividido

Un contenedor dividido contiene múltiples otros contenedores divididos o ventanas.

Los contenedores pueden usarse en varios diseños. El modo predeterminado se llama "default" y simplemente redimensiona cada cliente por igual para que quepa.

Área de trabajo

Un área de trabajo es un conjunto de contenedores. Otros gestores de ventanas llaman a esto "Escritorios Virtuales".

En i3, cada área de trabajo está asignada a una pantalla virtual específica. Por defecto, la pantalla 1 tiene el área de trabajo 1, la pantalla 2 tiene el área de trabajo 2, y así sucesivamente... Sin embargo, cuando creas un nuevo área de trabajo (simplemente cambiando a él), se le asignará la pantalla en la que te encuentres.

Salida

Usando XRandR, puedes tener una pantalla X11 abarcando múltiples monitores reales. Además, puedes configurarlos en modo clonación o con posiciones (el monitor 1 está a la izquierda del monitor 2).

i3 usa la API de RandR para consultar qué salidas están disponibles y qué pantallas están conectadas a estas salidas.

ASIGNACIONES DE TECLAS

Aquí hay una breve descripción general de las asignaciones de teclas predeterminadas:

Mod1+Enter

Abre una nueva ventana de emulador de terminal.

Mod1+d

Abre dmenu para iniciar cualquier aplicación escribiendo (parte de) su nombre.

j/k/l/;

Teclas de dirección (izquierda, abajo, arriba, derecha). Están en tu fila de inicio (mira la marca en tu tecla "j"). Alternativamente, puedes usar las teclas de cursor.

Mod1+<dirección>

Enfoca la ventana en <dirección>.

Mod1+Shift+<dirección>

Mueve la ventana hacia <dirección>.

Mod1+<número>

Cambia al área de trabajo <número>.

Mod1+Shift+<número>

Mueve la ventana al área de trabajo <número>.

Mod1+f

Alterna el modo de pantalla completa.

Mod1+s

Activa el diseño apilado para el contenedor actual.

Mod1+e

Activa el diseño predeterminado para el contenedor actual.

Mod1+w

Activa el diseño con pestañas para el contenedor actual.

Mod1+Shift+Space

Alterna entre mosaico/flotante para el contenedor actual.

Mod1+Space

Selecciona el primer contenedor en mosaico si el contenedor actual es flotante, y viceversa.

Mod1+Shift+q

Cierra la ventana actual. Esto es equivalente a "hacer clic en el botón de cerrar", lo que significa una solicitud cortés a la aplicación para cerrar esta ventana. Por ejemplo, Firefox guardará su sesión ante dicha solicitud. Si la aplicación no lo soporta, la ventana será forzada a cerrarse y lo que suceda depende de la aplicación.

Mod1+Shift+r

Reinicia i3 en el lugar. Tu diseño se conservará.

Mod1+Shift+e

Sale de i3.

ARCHIVOS

~/.config/i3/config (o ~/.i3/config)

Al iniciar, i3 busca archivos de configuración en el siguiente orden:

1.~/.config/i3/config (o $XDG_CONFIG_HOME/i3/config si está definido)
2.~/.i3/config
3./etc/xdg/i3/config (o $XDG_CONFIG_DIRS/i3/config si está definido)
4./etc/i3/config

Puedes especificar una ruta personalizada usando la opción -c.

Configuración de ejemplo.

# Archivo de configuración de i3 (v4)
# Fuente para los títulos de las ventanas. También será usada por la barra a menos que se use una fuente diferente en el bloque bar {} de abajo.
# Esta fuente está ampliamente instalada, proporciona muchos glifos Unicode, renderizado de texto de derecha a izquierda y escalabilidad en pantallas retina/hidpi (gracias a pango).
font pango:DejaVu Sans Mono 8
# Antes de i3 v4.8, recomendábamos esta como predeterminada:
# font -misc-fixed-medium-r-normal--13-120-75-75-C-70-iso10646-1
# La fuente de arriba es muy eficiente en espacio, es decir, se ve bien, nítida y clara en tamaños pequeños. Sin embargo, su cobertura de glifos Unicode es limitada, el viejo renderizado de fuentes X core no soporta texto de derecha a izquierda y al ser una fuente de mapa de bits, no escala en pantallas retina/hidpi.
# usa Ratón+Mod1 para arrastrar ventanas flotantes a la posición deseada
floating_modifier Mod1
# inicia una terminal
bindsym Mod1+Return exec /usr/bin/urxvt
# cierra la ventana enfocada
bindsym Mod1+Shift+q kill
# inicia dmenu (un lanzador de programas)
bindsym Mod1+d exec /usr/bin/dmenu_run
# cambia el enfoque
bindsym Mod1+j focus left
bindsym Mod1+k focus down
bindsym Mod1+l focus up
bindsym Mod1+semicolon focus right
# alternativamente, puedes usar las teclas de cursor:
bindsym Mod1+Left focus left
bindsym Mod1+Down focus down
bindsym Mod1+Up focus up
bindsym Mod1+Right focus right
# mueve la ventana enfocada
bindsym Mod1+Shift+j move left
bindsym Mod1+Shift+k move down
bindsym Mod1+Shift+l move up
bindsym Mod1+Shift+semicolon move right
# alternativamente, puedes usar las teclas de cursor:
bindsym Mod1+Shift+Left move left
bindsym Mod1+Shift+Down move down
bindsym Mod1+Shift+Up move up
bindsym Mod1+Shift+Right move right
# divide en orientación horizontal
bindsym Mod1+h split h
# divide en orientación vertical
bindsym Mod1+v split v
# entra en modo pantalla completa para el contenedor enfocado
bindsym Mod1+f fullscreen toggle
# cambia el diseño del contenedor (apilado, con pestañas, predeterminado)
bindsym Mod1+s layout stacking
bindsym Mod1+w layout tabbed
bindsym Mod1+e layout default
# alternar entre mosaico / flotante
bindsym Mod1+Shift+space floating toggle
# cambiar el foco entre ventanas en mosaico / flotantes
bindsym Mod1+space focus mode_toggle
# enfocar el contenedor padre
bindsym Mod1+a focus parent
# enfocar el contenedor hijo
#bindsym Mod1+d focus child
# cambiar al área de trabajo
bindsym Mod1+1 workspace 1
bindsym Mod1+2 workspace 2
# ..
# mover el contenedor enfocado al área de trabajo
bindsym Mod1+Shift+1 move workspace 1
bindsym Mod1+Shift+2 move workspace 2
# ...
# recargar el archivo de configuración
bindsym Mod1+Shift+c reload
# reiniciar i3 en el lugar (conserva tu diseño/sesión, se puede usar para actualizar i3)
bindsym Mod1+Shift+r restart
# salir de i3 (cierra tu sesión X)
bindsym Mod1+Shift+e exit
# mostrar botones de áreas de trabajo más una línea de estado generada por i3status
bar {
    status_command i3status
}

~/.xsession

Este archivo es donde debes configurar tus configuraciones regionales (locales) e iniciar i3. Es ejecutado por tu gestor de inicio de sesión (xdm, slim, gdm, ...) tan pronto como inicias sesión.

xsession de ejemplo.

# Desactivar que DPMS apague la pantalla
xset -dpms
xset s off
# Desactivar la campana (bell)
xset -b
# Habilitar el "zapping" (C-A-<Bksp> mata X)
setxkbmap -option terminate:ctrl_alt_bksp
# Forzar configuraciones regionales (locales) correctas desde el principio:
# LC_ALL no está definido ya que sobreescribe todo
# LANG=de_DE.UTF-8 se usa, excepto para:
# LC_MESSAGES=C nunca traduce la salida del programa
# LC_TIME=en_DK lleva a una salida de fecha/hora yyyy-mm-dd hh:mm
unset LC_ALL
export LANG=de_DE.UTF-8
export LC_MESSAGES=C
export LC_TIME=en_DK.UTF-8
# Usar XToolkit en aplicaciones java
export AWT_TOOLKIT=XToolkit
# Establecer el color de fondo
xsetroot -solid "#333333"
# Habilitar volcados de núcleo (core dumps) en caso de que algo salga mal
ulimit -c unlimited
# Iniciar i3 y registrar en ~/.local/share/i3/log
mkdir -p ~/.local/share/i3
echo "Starting at $(date)" >> ~/.local/share/i3/log
exec /usr/bin/i3 -V -d all >> ~/.local/share/i3/log

ENTORNO

I3SOCK

Esta variable sobreescribe la ruta del socket IPC (consulta la guía de usuario para la ubicación por defecto). El socket IPC es usado por programas externos como i3-msg(1), i3bar(1) o scripts hechos por el usuario.
