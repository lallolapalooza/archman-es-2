I3BAR(1) Manual de i3 I3BAR(1)

NOMBRE

i3bar - barra de estado y espacios de trabajo basada en xcb

SINOPSIS

i3bar [-b id_barra] [-s ruta_socket] [-t] [-h] [-v] [-V]

ADVERTENCIA

i3bar será invocado automáticamente por i3 para cada bloque de configuración bar.

Iniciarlo manualmente generalmente no es lo que quieres hacer.

¡Has sido advertido!

OPCIONES

-s, --socket ruta_socket

Sobrescribe la ruta al socket IPC de i3.

-b, --bar_id id_barra

Especifica el ID de la barra para el cual obtener la configuración de i3. Por defecto, i3bar utilizará el primer bloque de barra tal como está configurado en i3.

-t, --transparency

Habilita la transparencia (colores RGBA)

-h, --help

Muestra un mensaje de ayuda corto y sale.

-v, --version

Muestra el número de versión y sale.

-V

Sé verboso.

DESCRIPCIÓN

i3bar muestra una barra en la parte inferior (o superior) de tu(s) monitor(es) que contiene botones de cambio de espacio de trabajo y una línea de estado generada por i3status(1) o similar. Es invocado automáticamente (y configurado a través de) i3.

i3bar admite el uso de un protocolo JSON para establecer la línea de estado, consulta https://i3wm.org/docs/i3bar-protocol.html

Desde i3 4.23, i3bar admite otro protocolo JSON para establecer botones de espacio de trabajo. Consulta https://i3wm.org/docs/i3bar-workspace-protocol.html.

ENTORNO

I3SOCK

Se utiliza como respaldo para la ruta del socket IPC de i3 si ninguno de los argumentos de la línea de comandos está presente ni la propiedad I3_SOCKET_PATH está establecida en la ventana raíz de X11.

EJEMPLOS

Nada que ver aquí, siga adelante. Como se mencionó anteriormente, no debes ejecutar i3bar manualmente.

En su lugar, consulta la documentación de i3, especialmente la Guía del Usuario.

VER TAMBIÉN

i3status(1), j4status(1) o conky(1) para programas que generan una línea de estado.

dzen2(1) o xmobar(1) para programas similares a i3bar.
