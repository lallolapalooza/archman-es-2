NOMBRE

i3blocks - Un generador de feeds para barras de estado basadas en texto

SINOPSIS

i3blocks [OPCIÓN]...

DESCRIPCIÓN

El comando i3blocks(1) genera una línea de estado para i3bar(1). Planifica líneas de comandos descritas en un archivo de configuración simple en intervalos de tiempo especificados, tras la recepción de señales o en clics.

OPCIONES

-h

Muestra el mensaje de ayuda y sale.

-c ARCHIVO_CONFIG

Especifica una ruta alternativa al archivo de configuración.

-v

Aumenta el nivel de registro. Esta opción es acumulativa. Por defecto, solo se muestran errores fatales en la barra de estado. Al pasar esta opción una vez, también se mostrarán mensajes de error. Usar -vv y más, mostrará más salida de depuración en la salida estándar.

CONFIGURACIÓN

i3blocks debe definirse como el comando de línea de estado del bloque bar descrito en tu archivo de configuración de i3(1):

bar {
  status_command i3blocks
}

Por defecto, i3blocks busca un archivo de configuración en el siguiente orden (ten en cuenta que /etc puede ir prefijado con /usr/local dependiendo de las banderas de compilación):

1.$XDG_CONFIG_HOME/i3blocks/config (o ~/.config/i3blocks/config)
2.~/.i3blocks.conf
3.$XDG_CONFIG_DIRS/i3blocks/config (o /etc/xdg/i3blocks/config)
4./etc/i3blocks.conf

Para el contenido del archivo de configuración, por favor, consulta el sitio web de i3blocks: https://vivien.github.io/i3blocks
