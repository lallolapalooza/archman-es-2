I3-MSG(1) Manual de i3 I3-MSG(1)

NOMBRE

i3-msg - enviar mensajes al gestor de ventanas i3

SINOPSIS

i3-msg [-q] [-v] [-h] [-s socket] [-t type] [-r] [mensaje]

OPCIONES

-q, --quiet

Solo envía el mensaje ipc y suprime la salida de la respuesta.

-v, --version

Muestra el número de versión y sale.

-h, --help

Muestra un mensaje de ayuda corto y sale.

-s, --socket ruta_socket

i3-msg usará la variable de entorno I3SOCK o la ruta del socket dada aquí. Si ambas fallan, intentará obtener la información del socket de la ventana raíz y luego intentará /tmp/i3-ipc.sock antes de salir con un error.

-t tipo

Envía un mensaje ipc, ver abajo. Esta opción por defecto es "command".

-m, --monitor

En lugar de salir inmediatamente después de recibir el primer evento suscrito, espera indefinidamente a todos ellos. Solo se puede usar con "-t subscribe". Ver el tipo de mensaje IPC "subscribe" abajo para más detalles.

-r, --raw

Muestra la respuesta JSON cruda en lugar de formatear los errores (para comandos) o mostrar el contenido del archivo de configuración de nivel superior (para GET_CONFIG).

mensaje

Envía un mensaje ipc, ver abajo.

TIPOS DE MENSAJE IPC

command

La carga útil del mensaje es un comando para i3 (como los comandos que puedes enlazar a teclas en el archivo de configuración) y se ejecutará directamente después de recibirlo.

get_workspaces

Obtiene los espacios de trabajo actuales. La respuesta será una lista de espacios de trabajo codificada en JSON.

get_outputs

Obtiene las salidas actuales. La respuesta será una lista de salidas codificada en JSON (ver la sección de respuesta de docs/ipc, por ejemplo en https://i3wm.org/docs/ipc.html#_receiving_replies_from_i3).

get_tree

Obtiene el árbol de diseño. i3 utiliza una estructura de datos en árbol que incluye cada contenedor. La respuesta será el árbol codificado en JSON.

get_marks

Obtiene una lista de marcas (identificadores para contenedores para saltar fácilmente a ellos más tarde). La respuesta será una lista de marcas de ventana codificada en JSON.

get_bar_config

Obtiene la configuración (como un mapa JSON) de la barra de espacio de trabajo con el ID dado. Si no se proporciona ningún ID, se devolverá en su lugar una matriz con todos los IDs de barra configurados.

get_binding_modes

Obtiene una lista de modos de enlace configurados.

get_version

Obtiene la versión de i3. La respuesta será un diccionario codificado en JSON con la versión principal, secundaria, de parche y la versión legible por humanos.

get_config

Obtiene la configuración de i3 cargada actualmente.

send_tick

Envía un tick a todas las conexiones IPC que se suscriben a eventos de tick.

subscribe

La carga útil del mensaje describe los eventos a los que suscribirse. Al recibirlos, cada evento se volcará como un objeto codificado en JSON. Ver la opción -m para monitorización continua.

DESCRIPCIÓN

i3-msg es una implementación de ejemplo para un cliente que utiliza la interfaz IPC de socket Unix a i3.

Estado de salida:

0: si OK, 1: si la sintaxis es inválida o no se puede conectar al socket ipc 2: si i3 devolvió un error al procesar su(s) comando(s)

EJEMPLOS

# Usar un borde de 1px para el cliente actual
i3-msg "border 1pixel"
# Puedes omitir las comillas
i3-msg border normal
# Volcar el árbol de diseño
i3-msg -t get_tree
# Monitorizar cambios en las ventanas
i3-msg -t subscribe -m '[ "window" ]'

ENTORNO

I3SOCK

Si no se especifica un socket IPC en la línea de comandos, esta variable se usa para determinar la ruta, en la que se espera el socket de dominio Unix, al que conectarse a i3.
