NOMBRE

iecset - Establecer o volcar los bits de estado IEC958

SINOPSIS

iecset [opciones] [cmd arg...]

DESCRIPCIÓN

iecset es una pequeña utilidad para establecer o volcar los bits de estado IEC958 (o lo que se conoce como "S/PDIF") de la tarjeta de sonido especificada a través de la API de control de ALSA.

Cuando iecset se inicia sin argumentos excepto las opciones, mostrará el estado actual de IEC958 en un formato legible. Cuando se proporcionan comandos en los argumentos, se analizan y se actualizan los bits de estado de IEC958. El estado resultante también se muestra.

Los comandos consisten en la directiva del comando y el argumento. Como argumento booleano, se permiten yes, no, true, false o un número de dígito.

EJEMPLOS

iecset -Dhw:1
Muestra los bits de estado actuales de IEC958 en la segunda tarjeta. Esto es equivalente a -c 1.
iecset -x
Muestra los bits de estado actuales de IEC958 en el estilo de los argumentos para el stream PCM. La cadena de salida se puede pasar al tipo PCM iec958 (o spdif) como argumento opcional.
iecset pro off audio off
Establece el estado actual en modo consumidor y activa el bit no audio. El estado modificado también se mostrará.

OPCIONES

-D dispositivo
Especifica el nombre del dispositivo del control a abrir
-c tarjeta
Especifica el índice de la tarjeta a abrir. Equivalente a -Dhw:x.
-n índice
Especifica el índice del elemento de control IEC958, en caso de que tenga múltiples dispositivos IEC958 y necesite elegir uno de ellos.
-x
Vuelca el estado en el formato de bytes AESx.
-i
Lee las secuencias de comandos desde stdin. Cada línea contiene un solo comando.

COMANDOS

profesional <bool>
El modo profesional (true) o modo consumidor (false).
audio <bool>
El modo audio (true) o modo no audio (false).
tasa <int>
La frecuencia de muestreo en Hz.
énfasis <int>
El énfasis: 0 = ninguno, 1 = 50/15us, 2 = CCITT.
bloqueo <bool>
Bloqueo de tasa: bloqueado (true), desbloqueado (false). Este comando es solo para el modo profesional.
bits_muestra <int>
Bits de muestra: 2 = 20 bits, 4 = 24 bits, 6 = indefinido. Este comando es solo para el modo profesional.
longitud_palabra <int>
Longitud de palabra: 0 = No, 2 = 22-18 bits, 4 = 23-19 bits, 5 = 24-20 bits, 6 = 20-16 bits. Este comando es solo para el modo profesional.
categoría <int>
Categoría: el valor está entre 0 y 0x7f. Este comando es solo para el modo consumidor.
derechos_autor <bool>
Derechos de autor: con derechos de autor (true), sin derechos de autor (false). Este comando es solo para el modo consumidor.
original <boo>
Bandera original: original (true), 1ª generación (false). Este comando es solo para el modo consumidor.
