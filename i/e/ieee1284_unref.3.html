IEEE1284_REF(3) Funciones IEEE1284_REF(3)

NOMBRE

ieee1284_ref, ieee1284_unref - modificar el contador de referencias de un puerto

SINOPSIS

#include <ieee1284.h>

int ieee1284_ref(struct parport *port);

int ieee1284_unref(struct parport *port);

DESCRIPCIÓN

Si desea liberar la lista de puertos de ieee1284_find_ports pero abrir un puerto más tarde, necesitará evitar que sea destruido en ieee1284_free_ports. Cada puerto tiene un contador de referencias, y puede usar ieee1284_ref para incrementarlo y ieee1284_unref para decrementarlo.

Si utiliza ieee1284_ref en cualquier etapa, debe llamar posteriormente a ieee1284_unref para ceder la referencia adicional. Si no lo hace, los recursos asociados con el puerto no se limpiarán.

Si no ha utilizado previamente ieee1284_ref en un puerto, no debe utilizar ieee1284_unref en él.

VALOR DE RETORNO

Estas funciones devuelven el número de referencias mantenidas después del incremento o decremento.

VER TAMBIÉN
