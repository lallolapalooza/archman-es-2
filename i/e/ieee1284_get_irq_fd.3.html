ieee1284_get_irq_fd(3)

Paquete: libieee1284

Licencias: GPL-2.0-or-later

IEEE1284_GET_IRQ_FD(3) Funciones IEEE1284_GET_IRQ_FD(3)

NOMBRE

ieee1284_get_irq_fd, ieee1284_clear_irq - notificación de interrupción

SINOPSIS

#include <ieee1284.h>

int ieee1284_get_irq_fd(struct parport *port);

int ieee1284_clear_irq(struct parport *port, unsigned int *count);

DESCRIPCIÓN

Si el puerto tiene una línea de interrupción configurada y el tipo de puerto admite la notificación de interrupciones, es posible obtener un descriptor de archivo que se pueda utilizar para select(2) o poll(2). Cualquier evento (legible, escribible o excepción) significa que se ha activado una interrupción. No se pueden realizar otras operaciones que no sean select o poll en el descriptor de archivo.

El puerto debe estar abierto para poder llamar a ieee1284_get_irq_fd, y debe estar reclamado al usar select o poll.

El llamador no debe cerrar el descriptor de archivo, y no puede usarlo en absoluto cuando el puerto no está reclamado.

Cuando se ha detectado una interrupción, el llamador debe llamar a ieee1284_clear_irq para borrar la condición de interrupción, momento en el cual el número de interrupciones generadas se puede obtener proporcionando un count no nulo (NULL).

VALOR DEVUELTO

Para ieee1284_get_irq_fd: Si el valor devuelto es negativo, entonces es un código de error que se enumera a continuación. De lo contrario, es un descriptor de archivo válido.

E1284_NOTAVAIL

No hay ningún descriptor de archivo de este tipo disponible.

E1284_INVALIDPORT

El parámetro port es inválido (por ejemplo, quizás el port no está abierto).

Para ieee1284_clear_irq:

E1284_OK

La interrupción ha sido borrada. Si count no era NULL, el recuento de interrupciones se ha almacenado atómicamente en count y se ha reiniciado.

E1284_NOTAVAIL

El parámetro count no era NULL pero la cuenta de interrupciones no es compatible con este tipo de puerto. La interrupción ha sido borrada.

E1284_SYS

Hubo un problema al borrar la interrupción.

E1284_INVALIDPORT

El parámetro port es inválido (por ejemplo, quizás el port no está reclamado).
