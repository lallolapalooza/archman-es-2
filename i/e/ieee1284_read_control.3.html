ieee1284_read_control(3)

Paquete: libieee1284

Licencias: GPL-2.0-or-later

IEEE1284_CONTROL(3) Funciones IEEE1284_CONTROL(3)

NOMBRE

ieee1284_read_control, ieee1284_write_control, ieee1284_frob_control, ieee1284_do_nack_handshake - manipular líneas de control

SINOPSIS

#include <ieee1284.h>

int ieee1284_read_control(struct parport *port);

void ieee1284_write_control(struct parport *port, unsigned char ct);

void ieee1284_frob_control(struct parport *port, unsigned char mask, unsigned char val);

int ieee1284_do_nack_handshake(struct parport *port, unsigned char ct_before, unsigned char ct_after, struct timeval *timeout);

DESCRIPCIÓN

Hay cuatro líneas de control, tres de las cuales suelen estar invertidas en los puertos tipo PC. Donde difieren, libieee1284 opera sobre los valores IEEE 1284, no sobre los valores invertidos tipo PC. Las líneas de control se representan mediante la siguiente enumeración:

enum ieee1284_control_bits
{
  C1284_NSTROBE   = 0x01,
  C1284_NAUTOFD   = 0x02,
  C1284_NINIT     = 0x04,
  C1284_NSELECTIN = 0x08,
  /* Para convertir esos valores en valores de registro tipo PC, usa esto: */
  C1284_INVERTED = (C1284_NSTROBE|
                    C1284_NAUTOFD|
                    C1284_NSELECTIN),
};

Todas estas funciones actúan sobre el puerto paralelo asociado con port, el cual debe estar reclamado.

Los valores actuales en las líneas de control están disponibles llamando a ieee1284_read_control y pueden establecerse llamando a ieee1284_write_control.

Para ajustar los valores en un conjunto de líneas de control, usa ieee1284_frob_control. El efecto de esto se puede expresar como: ctr = ((ctr & ~mask) ^ val); es decir, los bits en mask se desactivan y luego los de val se invierten.

La función especial ieee1284_do_nack_handshake es para responder muy rápidamente en un protocolo donde el periférico establece nAck y el host debe responder estableciendo una línea de control. Su operación, que depende de que la máquina host sepa qué interrupción genera nAck, es la siguiente:

1.Establece las líneas de control como se indica en ct_before.
2.Espera la interrupción de nAck. Si timeout expira, devuelve E1284_TIMEDOUT.
3.Establece las líneas de control como se indica en ct_after.

En Linux, usando el controlador ppdev, esto es realizado por el controlador del dispositivo en el kernel, y por lo tanto es más rápido de lo que normalmente es posible en una biblioteca de espacio de usuario.

VALOR DE RETORNO

El valor de retorno de ieee1284_read_control, si es no negativo, es un número que representa el valor en las líneas de control.

Códigos de error posibles para ieee1284_read_control:

E1284_NOTAVAIL

Las líneas de control de este puerto no son accesibles por la aplicación.

E1284_INVALIDPORT

El parámetro port es inválido (por ejemplo, quizás no esté reclamado).

Códigos de error posibles para ieee1284_do_nack_handshake:

E1284_OK

El handshake fue exitoso.

E1284_NOTAVAIL

Esta operación no está disponible en este tipo de puerto o sistema. Esto podría ser porque las interrupciones del puerto no están disponibles, o porque el controlador del dispositivo subyacente no soporta la operación.

E1284_INVALIDPORT

El parámetro port es inválido (por ejemplo, quizás no esté reclamado).
