IEEE1284_SET_TIMEOUT(3) Funciones IEEE1284_SET_TIMEOUT(3)

NOMBRE

ieee1284_set_timeout - modificar el tiempo de espera de inactividad

SINOPSIS

#include <ieee1284.h>

struct timeval *ieee1284_set_timeout(struct parport *port, struct timeval *timeout);

DESCRIPCIÓN

Esta función establece un nuevo valor para el tiempo de espera de inactividad (utilizado para las funciones de transferencia de bloques) y devuelve el valor anterior.

El port debe estar reclamado.

El parámetro timeout puede ser NULL, en cuyo caso el valor anterior no se modifica.

VALOR DE RETORNO

Esta función devuelve un puntero a una estructura timeval que representa el valor anterior. Utiliza el mismo almacenamiento que la estructura port, y por lo tanto no es válido después de cerrar el puerto.

NOTAS

Tenga en cuenta que este es un tiempo de espera de inactividad, no un tiempo de espera absoluto. Durante una transferencia de datos, si el periférico está inactivo durante el tiempo especificado, el host se rinde.

También es consultivo; no se garantiza que la transferencia se complete nunca.
