IEEE1284_DATA(3) Funciones IEEE1284_DATA(3)

NOMBRE

ieee1284_read_data, ieee1284_write_data, ieee1284_data_dir, ieee1284_wait_data - controlar las líneas de datos

SINOPSIS

#include <ieee1284.h>

int ieee1284_read_data(struct parport *port);

void ieee1284_write_data(struct parport *port, unsigned char dt);

int ieee1284_data_dir(struct parport *port, int reverse);

int ieee1284_wait_data(struct parport *port, unsigned char mask, unsigned char val, struct timeval *timeout);

DESCRIPCIÓN

Estas funciones manipulan las líneas de datos del puerto paralelo asociado con port (el cual debe haber sido reclamado usando ieee1284_claim(3)). Las líneas se representan por un número de 8 bits (una línea por bit) y una dirección. Las líneas de datos se controlan como un grupo; pueden ser todas controladas por el host (dirección hacia adelante) o no (dirección hacia atrás). Cuando el periférico las controla, el host no debe hacerlo.

Para ieee1284_data_dir, el parámetro reverse debe ser cero para encender los controladores de las líneas de datos y distinto de cero para apagarlos. Algunos tipos de puerto pueden no ser capaces de apagar los controladores de las líneas de datos.

Establecer las líneas de datos puede tener efectos secundarios en algunos tipos de puerto (por ejemplo, algunos puertos Amiga pulsan nStrobe).

ieee1284_wait_data espera, hasta el timeout, a que los bits de datos especificados en mask tengan los valores correspondientes en val.

VALOR DEVUELTO

ieee1284_read_data devuelve el número de 8 bits que representa las líneas de datos, a menos que no sea posible devolver dicho valor con este tipo de puerto, en cuyo caso devuelve un código de error. Posibles códigos de error:

E1284_NOTAVAIL

Las líneas de datos bidireccionales no están disponibles en este sistema.

E1284_INVALIDPORT

El parámetro port es inválido (quizás no ha sido reclamado, por ejemplo).

E1284_SYS

Hubo un error a nivel del sistema operativo y errno se ha establecido en consecuencia.

E1284_TIMEDOUT

Ha transcurrido el timeout.

Mientras que ieee1284_read_data puede devolver E1284_NOTAVAIL en su primera invocación en el puerto, si no lo hace, no podrá hacerlo hasta que se llame a ieee1284_close para ese puerto.
