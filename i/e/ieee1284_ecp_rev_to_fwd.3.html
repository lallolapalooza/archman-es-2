IEEE1284_ECP_FWD_TO_(3) Funciones IEEE1284_ECP_REV_TO_FWD(3)

NOMBRE

ieee1284_ecp_fwd_to_rev, ieee1284_ecp_rev_to_fwd - Cambio de dirección ECP

SINOPSIS

int ieee1284_ecp_fwd_to_rev(struct parport *port);

int ieee1284_ecp_rev_to_fwd(struct parport *port);

DESCRIPCIÓN

Estas funciones se utilizan para cambiar las direcciones cuando se está en modo ECP. Al negociar el modo ECP, la dirección es hacia adelante (en otras palabras, del host al periférico). Use ieee1284_ecp_fwd_to_rev para cambiar de avance a reversa, y ieee1284_ecp_rev_to_fwd para cambiar de reversa a avance.

Actúan sobre el puerto paralelo asociado con port, que debe estar reclamado.

VALOR DE RETORNO

E1284_OK

Dirección cambiada con éxito.

E1284_NOTIMPL

El port carece de la capacidad requerida. Esto podría deberse a una limitación de esta versión de libieee1284 o a una limitación de hardware.

E1284_INVALIDPORT

El parámetro port es inválido (por ejemplo, quizás el port no está reclamado).
