IEEE1284_GET_DEVICEI(3) Funciones IEEE1284_GET_DEVICEI(3)

NOMBRE

ieee1284_get_deviceid - recuperar un ID de dispositivo IEEE 1284

SINOPSIS

#include <ieee1284.h>

ssize_t ieee1284_get_deviceid(struct parport *port, int daisy, int flags, char *buffer, size_t len);

DESCRIPCIÓN

Esta función sirve para recuperar el ID de dispositivo IEEE 1284 del dispositivo especificado. El dispositivo se especifica mediante el puerto al que está conectado, y opcionalmente una dirección (daisy) en la cadena de dispositivos en margarita de ese puerto.

daisy debe ser -1 para indicar que el dispositivo no participa en una cadena margarita IEEE 1284.3, lo que significa que es el último (o único) dispositivo en el puerto, o debe ser un número de 0 a 3 inclusive para indicar que tiene la dirección especificada en la cadena margarita (0 es el más cercano al puerto).

El parámetro flags debe ser una unión a nivel de bits de cualquier bandera que el programa desee utilizar. Las banderas disponibles son:

F1284_FRESH

Garantiza un ID de dispositivo fresco. No se utilizará un ID en caché o proporcionado por el sistema operativo.

El buffer proporcionado debe tener al menos len bytes de longitud, y contendrá el ID del dispositivo, incluido el campo de longitud inicial de dos bytes y un byte de terminación cero en caso de retorno exitoso, o tanto de lo anterior como quepa en el búfer.

VALOR DE RETORNO

Un valor de retorno menor que cero indica un error como se detalla a continuación. De lo contrario, el valor de retorno es el número de bytes del buffer que se han llenado. Un valor de retorno igual a la longitud del búfer indica que el ID del dispositivo puede ser más largo de lo que el búfer puede admitir.

E1284_NOID

El dispositivo no proporcionó un ID de dispositivo IEEE 1284 cuando se le consultó (quizás por el sistema operativo si no se especificó F1284_FRESH).

E1284_NOTIMPL

Una o más de las banderas proporcionadas no son compatibles en esta implementación, o si no se proporcionaron banderas, esta función no está implementada para este tipo de puerto o este tipo de sistema. Esto también puede devolverse si se especifica una dirección de cadena margarita pero los IDs de dispositivo de cadena margarita aún no son compatibles.

E1284_NOTAVAIL

Se especificó F1284_FRESH y la biblioteca no puede acceder al puerto para interrogar al dispositivo.

E1284_NOMEM

No hay suficiente memoria.

E1284_INIT

Hubo un problema al inicializar el puerto.

E1284_INVALIDPORT

El parámetro port es inválido.

NOTAS

A menos que se proporcione la bandera F1284_FRESH, la biblioteca intentará encontrar el ID del dispositivo de la manera menos intrusiva posible. Primero preguntará al sistema operativo si lo conoce, y luego intentará preguntarle directamente al dispositivo. Debido a esto, el ID del dispositivo puede estar parcialmente calculado (el campo de longitud, por ejemplo) o incluso parcialmente ausente si el sistema operativo solo ha recordado algunas partes del ID. Para garantizar que está obteniendo los bytes que envió el dispositivo, use F1284_FRESH. Tenga en cuenta que el sistema operativo puede permitir que cualquier usuario inspeccione los IDs de dispositivo que proporciona, mientras que el acceso a dispositivos suele estar más restringido.

El campo de longitud inicial de dos bytes es un entero sin signo de 16 bits big-endian proporcionado por el dispositivo y puede no ser preciso. En particular, está destinado a indicar la longitud de toda la cadena, incluido el propio campo de longitud; sin embargo, algunos fabricantes excluyen el campo de longitud o simplemente establecen el campo de longitud en un número arbitrario mayor que la longitud del ID.
