NOMBRE

iec16022 - programa para generar códigos de barras 2d

SINOPSIS

iec16022 [opciones]

DESCRIPCIÓN

Esta página del manual documenta brevemente el comando iec16022.

iec16022 genera códigos de barras 2d que cumplen con el estándar ISO/IEC 16022 (que también se conoce como Data Matrix y Semacode).

OPCIONES

Estos programas siguen la sintaxis habitual de la línea de comandos de GNU, con opciones largas que comienzan con dos guiones (`-'). A continuación se incluye un resumen de las opciones.

-s, --size AnxAl
Establece el tamaño del código de barras generado.
-c, --barcode texto
Especifica el texto que se codificará.
--ecc 000|050|080|100|140|200
Establece el tipo de ecc a utilizar (predeterminado: 200).
-i, --infile archivo
Lee los datos de entrada desde un archivo.
-o, --outfile archivo
Guarda la salida en un archivo (en lugar de la salida estándar).
-f, --format Texto|UTF-8|EPS|Bin|Hex|Stamp|PNG
Establece el tipo de salida.
-?, --help
Muestra un resumen de las opciones.
--usage
Muestra una breve descripción general de las opciones.

EJEMPLO

Para producir un código de barras DataMatrix para "foobar" en formato PNG, necesita los siguientes argumentos:

iec16022 -f PNG -c foobar -o foobar.png
