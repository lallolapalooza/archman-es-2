IRPIPE(1) Comandos de usuario IRPIPE(1)

NOMBRE

irpipe - herramienta para enviar datos a lircd a través del dispositivo del kernel /dev/irpipe.

SINOPSIS

irpipe [opciones] <archivo

irpipe --read [opciones] >archivo

irpipe --filter [opciones] <infile >outfile

DESCRIPCIÓN

irpipe está diseñado para alimentar datos a lircd(8) a través de un dispositivo /dev/irpipe. Es una herramienta para introducir datos de prueba en lircd de una manera idéntica a los datos reales de los dispositivos /dev/lirc.

irpipe utiliza dos formatos: texto y binario. El formato binario se documenta en la página del manual de lirc(4). El formato de texto es el definido en mode2(1).

El controlador irpipe permite al usuario establecer las características devueltas por la llamada de sistema (ioctl) LIRC_GET_FEATURES. Estas se documentan en lirc(4).

El dispositivo del kernel irpipe a menudo no está compilado en las versiones empaquetadas de lirc. Ver [CONTROLADOR DEL KERNEL] más abajo.

OPCIONES

-d --device=driver
Establece el dispositivo del kernel, el valor predeterminado es /dev/irpipe0.
-b --bin2text
Convierte datos binarios a texto.
-t --text2bin
Convierte datos de texto a binario.
-s --add-sync
Añade una sincronización inicial larga a la salida convertida. Esto a menudo es necesario para que lircd pueda decodificar los datos, en particular si las teclas no se repiten.
-f --filter
Envía datos desde stdin a stdout
-r --read
Envía datos desde el dispositivo del kernel a stdout. Esta opción es experimental y no ha sido probada.
-l--length=bits
Establece la longitud de la señal del dispositivo del kernel. Esto solo tiene sentido en la emulación de dispositivos LIRCCODE.
-F--features=bitmask
Establece la máscara de bits de características, tal como la devuelve la llamada de sistema LIRC_GET_FEATURES. Ver lirc(4) para más información.
-h --help
Muestra un resumen de uso.
-v --version
Muestra la versión.

CONTROLADOR DEL KERNEL

La herramienta irpipe está diseñada para funcionar con el controlador del kernel irpipe, aunque la opción --filter funciona sin él. Este controlador a menudo no está compilado en las versiones empaquetadas. Si este es el caso, el controlador se puede compilar a partir de las fuentes en el directorio drivers/irpipe. Esto requiere tener instaladas las fuentes del kernel. El archivo drivers/irpipe/README proporciona información sobre cómo compilar e instalar el controlador.
