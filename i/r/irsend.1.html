IRSEND(1) Comandos de usuario IRSEND(1)

NOMBRE

irsend - programa básico de LIRC para enviar comandos infrarrojos

SINOPSIS

irsend [opciones] enviar_una_vez <remoto> <código> [código...]
irsend [opciones] enviar_inicio <remoto> <código>
irsend [opciones] enviar_parada <remoto> <código>
irsend [opciones] listar <remoto> <código>
irsend [opciones] establecer_transmisores <num> [num...]
irsend [opciones] simular <paquete de pulsación de botón >

DESCRIPCIÓN

Solicita al demonio lircd que envíe uno o más comandos CIR (Consumer Infra-Red). Esto está destinado al control remoto de dispositivos electrónicos como cajas de TV, equipos HiFi, etc.

irsend soporta seis subcomandos:

enviar_una_vez        - envía uno o más códigos una vez
enviar_inicio       - inicia la repetición de un código.
enviar_parada        - detiene la repetición de un código.
listar             - lista los elementos remotos configurados
establecer_transmisores  - establece los transmisores activos
simular           - simula un evento IR

remoto es el nombre de un control remoto, como se describe en el archivo de configuración de lircd.

código es el nombre de una tecla del control remoto de remoto, tal como aparece en el archivo de configuración lircd.conf.

num es el número del transmisor del dispositivo de hardware.

Para el comando listar, remoto y/o código pueden estar vacíos:

listar   ""    ""   - lista todos los nombres de control remoto configurados
listar remoto  ""   - lista todos los códigos de remoto
listar remoto código  - lista solo código de remoto

El comando simular solo funciona si se ha habilitado explícitamente en lircd usando la opción --allow-simulate. El paquete de pulsación de botón requerido debe formatearse como un mensaje de difusión de socket documentado en lircd(8).

OPCIONES

-h --ayuda
Muestra el resumen de uso.
-v --versión
Muestra la versión.
-d --dispositivo=dispositivo
Usa el socket de lircd dado [/var/run/lirc/lircd].
-a --direccion=host[:puerto]
Conéctate a lircd en esta dirección.
-# --cuenta=n
Envía el comando n veces.

ENTORNO

LIRC_SOCKET_PATH
El socket de lircd al que conectarse, por defecto es un valor codificado en la ruta /var/run/lirc/lircd

ARCHIVOS

/etc/lirc/lircd.conf
Archivo de configuración predeterminado de lircd. Debe contener todos los controles remotos, sus códigos infrarrojos y los detalles de temporización y forma de onda correspondientes.

DIAGNÓSTICOS

Si lircd no se está ejecutando (o a /var/run/lirc/lircd le faltan permisos de escritura), irsend se aborta con los siguientes diagnósticos:

"irsend: no se pudo conectar al socket"
"irsend: Conexión rechazada" (o "Permiso denegado").

EJEMPLOS

irsend LISTAR DenonTuner ""
irsend ENVIAR_UNA_VEZ  DenonTuner PROG-SCAN
irsend ENVIAR_UNA_VEZ  OnkyoAmpli VOL-UP VOL-UP VOL-UP VOL-UP
irsend ENVIAR_INICIO OnkyoAmpli VOL-DOWN ; sleep 3
irsend ENVIAR_PARADA  OnkyoAmpli VOL-DOWN
irsend ESTABLECER_TRANSMISORES 1
irsend ESTABLECER_TRANSMISORES 1 3 4
irsend SIMULAR "0000000000000476 00 OK TECHNISAT_ST3004S"

CARGA DE CONTROLADORES

Los controladores se cargan dinámicamente. El directorio utilizado para esto se determina por (prioridad decreciente):

  • La variable de entorno LIRC_PLUGINDIR.
  • La entrada 'plugindir' en la sección [lircd] del archivo lirc_options.conf.
  • Un valor predeterminado codificado (/usr/lib/lirc/plugins).
