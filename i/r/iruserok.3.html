Las funciones iruserok() y ruserok() son utilizadas por los servidores para autenticar a clientes que solicitan servicio con rcmd(). The *ahost se establece al nombre estándar del host y se establece una conexión con un servidor que reside en el puerto de Internet conocido inport. Si la conexión tiene éxito, se devuelve al llamante un socket en el dominio de Internet de tipo SOCK_STREAM, y se le da

El proceso de control devolverá la salida de diagnóstico del comando (unidad 2) en este canal, y también aceptará bytes en este canal como números de señal UNIX, para ser reenviados al grupo de procesos del comando. Si fd2p es 0, entonces stderr (unidad 2 del comando remoto) se hará igual que stdout y no se hace ninguna provisión para enviar señales arbitrarias al proceso remoto, aunque puede ser capaz de atraer su atención usando datos fuera de banda.
