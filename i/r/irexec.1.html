IREXEC(1) Comandos de usuario IREXEC(1)

NOMBRE

irexec - ejecuta programas con una sola pulsación de botón

SINOPSIS

irexec [opciones] [archivo_config]

DESCRIPCIÓN

irexec ejecuta comandos en una señal IR decodificada por lircd, el demonio LIRC. Utiliza un archivo de configuración lircrc donde se ejecutan las entradas config =. Por ejemplo, dado el siguiente fragmento de archivo de configuración:

    begin
        prog   = irexec
        button = KEY_RED
        config = echo "KEY_RED"
    end

irexec imprimirá en la terminal KEY_RED cuando se pulse el botón correspondiente en un mando a distancia. El comando es un comando arbitrario de shell ejecutado de forma asíncrona; irexec no espera a que se complete.

ARGUMENTOS

archivo_config
Archivo de configuración lircrc. irexec solo utiliza las entradas con prog = irexec. La ruta por defecto es ~/.config/lircrc.

OPCIONES

-h, --help
Mostrar resumen de uso
-v, --version
Mostrar versión
-d, --daemon
Hace que irexec se bifurque al segundo plano. En este caso, se debe proporcionar un archivo de configuración en la línea de comandos, ya que irexec no podrá encontrar ningún directorio personal.
-D, --loglevel [nivel]
Determina la cantidad de información de registro. [nivel] puede ser un nivel simbólico de syslog: error, warning, info, notice o debug. LIRC también define tres niveles adicionales: trace, trace y trace2, que proporcionan aún más mensajes (trace2 es el que más información da). Sin embargo, en el registro, estos mensajes se marcan como debug. Por defecto, no se realiza ningún registro.
-n, --name <nombre>
Utiliza este nombre de programa en lugar del valor por defecto irexec como identificador en el archivo lircd.conf.

ENTORNO

LIRC_SOCKET_PATH
Ruta al socket de lircd del que lee irexec; por defecto es /var/run/lirc/lircd.

ARCHIVOS

~/.config/lircrc
Archivo de configuración por defecto
/etc/lirc/lircrc
Archivo de configuración utilizado por el servicio systemd de irexec.
~/.cache/irexec.log
Registro de depuración. Establecer la variable de entorno XDG_CACHE_HOME reubica este archivo a $XDG_CACHE_HOME/irexec.log.

NOTAS

Hasta la versión 0.9.1, irexec esperaba a que el programa ejecutado terminara. Por lo tanto, los archivos de configuración antiguos a menudo incluyen un '&' añadido a la cadena de comandos para evitar quedarse atascado en el comando. Esto no es necesario en la versión 0.9.2+, que no puede esperar a que el comando se complete.

irexec debería ejecutarse como un servicio. El directorio contrib contiene un archivo .desktop que podría colocarse en ~/.local/autostart. Hacerlo crea un servicio que puede ser manejado por herramientas de escritorio regulares como gnome-tweak-tool en todos los escritorios principales. Si se requieren comandos restringidos como apagar la máquina, se puede usar sudo(8) para permitir a los usuarios normales ejecutar dichos comandos.

Una alternativa es utilizar el servicio systemd irexec.service, que se ejecuta como root (y puede ejecutarse en paralelo con el servicio de escritorio). Ejecutarse como root tiene graves implicaciones de seguridad. Consulte la Guía de Configuración en la documentación html.
