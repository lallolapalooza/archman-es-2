irsimreceive(1) Comandos de usuario irsimreceive(1)

NOMBRE

irsimreceive - Decodifica datos de duraciones IR.

SINOPSIS

irsimreceive [opciones] <archivo de configuración> <archivo de datos>

DESCRIPCIÓN

Esta es una herramienta de prueba simple que decodifica datos de duración en archivo de datos usando un archivo de configuración tipo lircd.conf. Los datos mostrados tienen el mismo formato que en el socket de salida de lircd.

OPCIONES

-U, --plugindir <directorio>
Carga controladores desde <directorio>.
-v , --version
Imprime la versión y sale.
-h , --help
Imprime el mensaje de ayuda.

ARCHIVOS

~/.cache/irsimreceive.log
Registro de depuración. Establecer la variable de entorno XDG_CACHE_HOME reubica este archivo a $XDG_CACHE_HOME/irsimreceive.log. La cantidad de registro respeta la variable de entorno LIRC_LOGLEVEL, que por defecto es el valor de depuración en la sección [lircd] de lirc_options.conf.

VER TAMBIÉN

La documentación para lirc se mantiene en páginas html. Se encuentran en el directorio html/ dentro del directorio de documentación.
