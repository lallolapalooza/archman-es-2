FBB::IRandStream(3bobcat) Flujo de entrada de números aleatorios FBB::IRandStream(3bobcat)

NOMBRE

FBB::IRandStream - Flujo de entrada que produce números aleatorios

SINOPSIS

#include <bobcat/irandstream>
Opción de enlace: -lbobcat

DESCRIPCIÓN

Los objetos FBB::IRandStream se pueden usar para extraer números aleatorios en un rango dado de un flujo.

ESPACIO DE NOMBRES

FBB
Todos los constructores, miembros, operadores y manipuladores mencionados en esta página del manual están definidos en el espacio de nombres FBB.

HEREDA DE

std::istream,
FBB::RandBuffer (privado)

CONSTRUCTORES

o
IRandStream(int max):
Este constructor FBB::IRandStream() inicializa el generador aleatorio. Se utiliza la semilla predeterminada (es decir, 1) para la función srand(3), lo que significa que cada nueva ejecución del programa generará la misma secuencia de valores aleatorios. Se proporciona otro constructor (ver más abajo) cuando esto no se considera apropiado. Se devuelven valores aleatorios entre 1 y max (inclusive).
o
IRandStream(int min, int max):
Este constructor FBB::IRandStream() inicializa el generador aleatorio. Se utiliza la semilla predeterminada (es decir, 1) para la función srand(3), lo que significa que cada nueva ejecución del programa generará la misma secuencia de valores aleatorios. Se proporciona otro constructor (ver más abajo) cuando esto no se considera apropiado. Se devuelven valores aleatorios entre min y max (inclusive).
o
IRandStream(int min, int max, size_t seed):
Este constructor FBB::IRandStream() inicializa el generador aleatorio. La semilla se utiliza para inicializar el generador de números aleatorios. Para iniciar el generador aleatorio en un punto impredecible, se podría usar time(0). Se devuelven valores aleatorios entre min y max (inclusive).

Los constructores de copia y movimiento (y los operadores de asignación) no están disponibles.

MIEMBROS HEREDADOS

Dado que la clase utiliza derivación pública de std::istream, se pueden usar todos los miembros de esta clase.

EJEMPLO

#include <iostream>
#include <bobcat/irandstream>
using namespace std;
using namespace FBB;
int main(int argc, char **argv)
{
    if (argc == 1)
        cout << "\n"
                "Mostrando un valor aleatorio entre 1 y 1000 (inclusive).\n"
                "Si desea más valores, especifique el número de\n"
                "valores solicitados como primer argumento del programa\n"
                "En llamadas repetidas se generan los mismos números\n\n";
    IRandStream in(1000);
    for (size_t count = argc == 1? 1 : stoul(argv[1]); count--; )
    {
        size_t random;
        in >> random;
        cout << random << endl;
    }
}
