IRPTY(1) Comandos de usuario IRPTY(1)

NOMBRE

irpty - Controlador de tty pseudo.

SINOPSIS

irpty [opciones] archivo_config -- programa [args ...]

DESCRIPCIÓN

irpty se conecta a lircd para recibir códigos infrarrojos y los convierte en pulsaciones de teclas. Por ejemplo, escribe irpty ~/.config/lircrc -- workbone para controlar el programa reproductor de CD workbone. Por supuesto, primero tendrás que crear un archivo de configuración adecuado para este propósito. La cadena de configuración se pasará a la aplicación deseada. Ten en cuenta que puedes usar secuencias de escape para especificar caracteres no imprimibles. Consulta la descripción del formato del archivo .lircrc para obtener más detalles.

OPCIONES

-h --help
muestra el resumen de uso
-V --version
muestra la versión
-e --no-echo
deshabilita el eco
-i --ignore-eof
ignora EOF
-n --non-interactive
fuerza el modo no interactivo
-v --verbose
modo detallado

VER TAMBIÉN

La documentación de lirc se mantiene en páginas html. Se encuentran en el directorio html/ dentro del directorio de documentación.
