IRK(1) Comandos IRK(1)

NOMBRE

irk - programa de prueba para irkerd

SINOPSIS

irk [objetivo] [mensaje texto]

DESCRIPCIÓN

irk es un programa de prueba simple para irkerd(8). Construirá un objeto JSON simple y lo pasará al demonio que se ejecuta en localhost.

OPCIONES

irk toma las siguientes opciones:

objetivo

Qué servidor y canal unirse para anunciar el mensaje. Si no comienza con "irc:", antepondrá "irc://chat.freenode.net/" al argumento antes de pasarlo directamente a irkerd. Este argumento se pasa como el parámetro "to" en el objeto JSON.

mensaje

Qué mensaje enviar al objetivo especificado anteriormente. Si la cadena es "-", el mensaje se leerá de la entrada estándar, con los saltos de línea eliminados.

LIMITACIONES

irk no tiene uso de línea de comandos y puede estar plagado de errores.

irk no sabe cómo hablar con su VCS favorito. Generalmente querrá usar irkerhook(1) en su lugar.

irk también tiene todas las limitaciones de irkerd.

VER TAMBIÉN

irkerhook(1),

AUTOR

Eric S. Raymond <esr@snark.thyrsus.com>. Consulte la página del proyecto en http://www.catb.org/~esr/irker para obtener actualizaciones y otros recursos, incluido un script de hook de repositorio instalable.
