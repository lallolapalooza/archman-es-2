irdb-get(1) Comandos de usuario irdb-get(1)

NOMBRE

irdb-get - listar, buscar y descargar archivos de configuración de lirc.

SINOPSIS

irdb-get update

irdb-get find <cadena>

irdb-get info <id>

irdb-get download <id>

irdb-get list [patrón]

irdb-get find-driver <cadena>

irdb-get yaml-config

irdb-get <-h|--help|-v|--version>

DESCRIPCIÓN

irdb-get puede listar, buscar y descargar archivos de configuración remotos de lirc. Funciona descargando un archivo índice, haciendo que todas las operaciones, excepto la descarga real, sean locales.

Las entradas en el índice se identifican por un id. Dicho id tiene el formato dir/remote, por ejemplo, x10/ati_remote_wonder_III

COMANDOS

update
Descarga el índice del repositorio remoto.
find <cadena>
Lista todas las entradas en el archivo índice que coincidan con <cadena>. La coincidencia se realiza utilizando la sintaxis de coincidencia de shell regular (es decir, no regex).
find-driver <cadena>
Lista todas las entradas en el índice con un controlador dado. La coincidencia es exacta, sin comodines.
info <id>
Imprime información adicional sobre una entrada dada.
download <id>
Descarga el archivo de configuración para una entrada dada. El nombre del archivo se imprime en la salida estándar.
list <patrón>
Lista las entradas que coinciden con <patrón>. <patrón> tiene el formato dir/remote, por ejemplo, x10/ati* o */ati_remote_wonder* .

La primera palabra en la lista es algo como -RL- donde las letras representan:

R
Configuración en bruto.
T
El control remoto tiene información de temporización, es decir, se puede utilizar con dispositivos de captura genéricos.
L
El control remoto tiene un archivo de configuración lircmd.
P
El control remoto tiene una foto.
yaml-config
Imprime un archivo YAML en la salida estándar que mapea los controladores a archivos remotos con el atributo driver correspondiente. El formato no es estable y se utiliza principalmente para lirc-setup(1).

OPCIONES

-h , --help
Imprime el mensaje de ayuda.
-v , --version
Imprime la información de la versión.

AMBIENTE

LIRC_REMOTES_URL
La URL base utilizada al descargar archivos de configuración, por defecto es https://sourceforge.net/p/lirc-remotes/code/ci/master/tree.
LIRC_REMOTES_LIST
URL de un archivo que lista todos los controles remotos, como lo crea lirc-lsremotes(1). Por defecto es http://lirc-remotes.sourceforge.net/remotes.list.
LIRC_IRDB_CACHE_ID
Si está definido, reemplaza la fecha que de otro modo se imprimiría en la salida de yaml-config. Ignorado para otros comandos. Útil para compilaciones reproducibles junto con XDG_CACHE_HOME.
XDG_CACHE_HOME
Si está definido, reubica el archivo de lista de controles remotos descargados y cacheados a $XDG_CACHE_HOME/remotes.list, ver ARCHIVOS.

ARCHIVOS

~/.cache/remotes.list
El archivo índice descargado bajo demanda o mediante el comando update.
