Irssi(1) Manual de Comandos Generales Irssi(1)

NOMBRE

Irssi - un cliente IRC modular para UNIX

SINOPSIS

irssi [--config=RUTA] [--home=RUTA] [-dv!?] [-c servidor] [-p puerto] [-n apodo] [-w contraseña] [-h nombrehost]

DESCRIPCIÓN

Irssi es un cliente de Internet Relay Chat modular; es altamente extensible y muy seguro. Siendo un cliente de pantalla completa, basado en termcap con muchas características, Irssi es fácilmente extensible a través de scripts y módulos.

OPCIONES

--config=ARCHIVO
usar ARCHIVO en lugar de ~/.irssi/config
--home=RUTA
RUTA especifica el directorio de inicio de Irssi; el valor predeterminado es ~/.irssi
-c, --connect=SERVIDOR
conectar a SERVIDOR
-w, --password=CONTRASEÑA
usar CONTRASEÑA para la autenticación.
-p, --port=PUERTO
conectar automáticamente al PUERTO en el servidor.
-!, --noconnect
deshabilitar la conexión automática de servidores
-n, --nick=APODO
especificar APODO como tu apodo
-h, --hostname=NOMBREHOST
usar NOMBREHOST para tu sesión de IRC
-v, --version
mostrar la versión de Irssi
-?, --help
mostrar un mensaje de ayuda

VER TAMBIÉN

Irssi tiene una buena cantidad de documentación disponible; consulta /HELP o busca en línea en https://irssi.org

ARCHIVOS

~/.irssi/config
archivo de configuración personal
~/.irssi/config.autosave
guardado automático del archivo de configuración personal cuando se modificó externamente
~/.irssi/default.theme
tema predeterminado de irssi
~/.irssi/away.log
mensajes registrados en estado de ausencia
~/.irssi/scripts/
directorio predeterminado de scripts
~/.irssi/scripts/autorun/
directorio que contiene enlaces a scripts que deben cargarse automáticamente al inicio
~/.irssi/startup
archivo que contiene una lista de comandos para ejecutar al inicio
