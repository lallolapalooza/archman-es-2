Paquete: ruby-irb

Licencias: RUBY, BSD-2

IRB(1) 1 (guía de referencia del programador de ruby) IRB(1)

NOMBRE

irb — Shell interactivo de Ruby

SINOPSIS

irb [--version] [-dfUw] [-I directorio] [-r biblioteca] [-E externo[:interno]] [-W[nivel]] [--[sin]inspect] [--[sin]multiline] [--[sin]singleline] [--[sin]echo] [--[sin]colorize] [--[sin]autocomplete] [--[sin]verbose] [--prompt modo] [--prompt-mode modo] [--inf-ruby-mode] [--simple-prompt] [--noprompt] [--tracer] [--back-trace-limit n] [--] [archivo_programa] [argumento ...]

DESCRIPCIÓN

irb es el entorno REPL (bucle de leer-evaluar-imprimir) para programas Ruby.

OPCIONES

--version
Imprime la versión de irb.
-E externo[:interno]
 
--encoding externo[:interno]
Igual que `ruby -E'. Especifica el(los) valor(es) predeterminado(s) para las codificaciones externas y la codificación interna. Los valores deben separarse con dos puntos (:).

Puedes omitir el de las codificaciones internas, entonces el valor (Encoding.default_internal) será `nil`.

-I ruta
Igual que `ruby -I'. Especifica el directorio de $LOAD_PATH.
-U
Igual que `ruby -U'. Establece el valor predeterminado para las codificaciones internas (Encoding.default_internal) a `UTF-8`.
-d
Igual que `ruby -d'. Establece $DEBUG a verdadero.
-f
Suprime la lectura de ~/.irbrc.
-w
Igual que `ruby -w'.
-W
Igual que `ruby -W'.
-h
 
--help
Imprime un resumen de las opciones.
-r biblioteca
Igual que `ruby -r'. Hace que irb cargue la biblioteca usando require.
--inspect
Usa `inspect' para la salida (predeterminado excepto en modo bc).
--noinspect
No usa inspect para la salida.
--multiline
Usa el módulo editor multilínea.
--nomultiline
No usa el módulo editor multilínea.
--singleline
Usa el módulo editor de una sola línea.
--nosingleline
No usa el módulo editor de una sola línea.
--extra-doc-dir
Añade un directorio de documentación adicional para el diálogo de documentación.
--echo
Muestra el resultado (predeterminado).
--noecho
No muestra el resultado.
--echo-on-assignment
Muestra el resultado en las asignaciones.
--noecho-on-assignment
No muestra el resultado en las asignaciones.
--truncate-echo-on-assignment
Muestra el resultado truncado en las asignaciones (predeterminado).
--colorize
Usa colorización.
--nocolorize
No usa colorización.
--autocomplete
Usa autocompletado.
--noautocomplete
No usa autocompletado.
--regexp-completor
Usa autocompletado basado en expresiones regulares.
--type-completor
Usa autocompletado basado en tipos.
--verbose
Muestra detalles.
--noverbose
No muestra detalles.
--prompt modo
 
--prompt-mode modo
Cambia el modo de prompt. Los modos de prompt predefinidos son `default', `simple', `xmp' y `inf-ruby'.
--inf-ruby-mode
Usa un prompt apropiado para el modo inf-ruby en emacs. Suprime --multiline y --singleline.
--simple-prompt
Hace los prompts simples.
--noprompt
Modo sin prompt.
--tracer
Muestra el rastro de cada ejecución de comandos.
--back-trace-limit n
Muestra la traza de pila superior n y la inferior n. El valor predeterminado es 16.

ENTORNO

IRB_LANG
La configuración regional utilizada para irb.
IRBRC
La ruta al archivo de inicialización personal.
XDG_CONFIG_HOME
irb respeta XDG_CONFIG_HOME. Si está configurado y IRBRC no está configurado, carga $XDG_CONFIG_HOME/irb/irbrc como archivo de inicialización personal.
RI_PAGER
El comando especificado para paginar la salida de RI.

Este sitio no está asociado de ninguna forma con Arch Linux ni afiliado a este proyecto. El contenido es únicamente una traducción de las páginas del manual de Arch publicadas en man.archlinux.org.

d se usaría como paginador.
PAGER
El comando especificado se usaría como paginador si RI_PAGER no está definido.
VISUAL
Su valor se usaría para abrir archivos mediante el comando edit.
EDITOR
Su valor se usaría para abrir archivos mediante el comando edit si VISUAL no está definido.
NO_COLOR
Asignarle un valor desactiva la colorización.
IRB_USE_AUTOCOMPLETE
Asignar false a esta variable desactiva el autocompletado.
IRB_COMPLETOR
Comportamiento del autocompletado. Los valores permitidos son regexp o type

También irb depende de las mismas variables que ruby(1).

ARCHIVOS

~/.irbrc
Inicialización personal de irb. Si IRBRC está definido, se lee $IRBRC en su lugar. Si IRBRC no está definido y XDG_CONFIG_HOME está definido, $XDG_CONFIG_HOME/irb/irbrc se carga.

EJEMPLOS

% irb
irb(main):001:0> 1 + 1
2
irb(main):002:0> def t(x)
irb(main):003:1> x + 1
irb(main):004:1> end
=> :t
irb(main):005:0> t(3)
=> 4
irb(main):006:0> if t(3) == 4
irb(main):007:1> p :ok
irb(main):008:1> end
:ok
=> :ok
irb(main):009:0> quit
%
