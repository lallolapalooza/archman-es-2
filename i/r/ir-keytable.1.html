IR-KEYTABLE(1) Comandos de usuario IR-KEYTABLE(1)

NOMBRE

ir-keytable - una herramienta multifuncional para manejar mandos a distancia.

SINOPSIS

ir-keytable [OPCIÓN]...

DESCRIPCIÓN

ir-keytable es una herramienta que lista dispositivos de mando a distancia, carga mapas de teclas rc, prueba eventos y ajusta otras opciones del mando a distancia.

En lugar de cargar un mapa de teclas rc, también es posible configurar decodificadores de protocolo y establecer directamente las asignaciones de scancode a keycode de rc.

Nota: Necesitas tener permisos de lectura en /dev/input para que la mayoría de las opciones funcionen.

OPCIONES

-a, --auto-load=ARCHIVO_DE_CONFIGURACIÓN
Carga automáticamente mapas de teclas, basándose en un archivo de configuración. Solo funciona con --sysdev.
-c, --clear
Borra las asignaciones de scancode a keycode.
-D, --delay=RETRASO
Establece el retraso antes de repetir una pulsación de tecla.
-k, --set-key=CLAVE_ESCANEO
Establece la asignación de scancode a keycode.
-p, --protocol=PROTOCOLO
Lista de protocolos del kernel o protocolo BPF separados por comas para habilitar. Todos los demás protocolos se deshabilitan.
-e, --parameter=PARÁMETRO
Lista de parámetros para el protocolo BPF separados por comas.
-P, --period=PERÍODO
Establece el período para repetir una pulsación de tecla.
-r, --read
Lee y muestra la asignación actual de scancode a keycode.
-s, --sysdev=DISPOSITIVO_SISTEMA
Dispositivo rc a controlar, por defecto es rc0 si no se especifica.
-t, --test
prueba si el dispositivo rc está generando eventos
-v, --verbose
Habilita mensajes de depuración.
-w, --write=MAPA_DE_TECLAS
Lee los protocolos y la asignación de scancode a keycode desde el archivo MAPA_DE_TECLAS y los habilita en el dispositivo rc.
-?, --help
Imprime el mensaje de ayuda
--usage
Da un breve mensaje de uso
-V, --version
imprime la versión de v4l2-utils

Los argumentos obligatorios u opcionales para las opciones largas también son obligatorios u opcionales para cualquier opción corta correspondiente. Las opciones se pueden combinar entre sí.

Los argumentos de las opciones son:

DISPOSITIVO_SISTEMA
el dispositivo rc tal como se encuentra en /sys/class/rc
MAPA_DE_TECLAS
un archivo de mapa de teclas toml con una lista de protocolos y asignaciones de scancode a keycode. El formato se describe en rc_keymap(5).
CLAVE_ESCANEO
un conjunto de pares de valores scancode1=keycode1,scancode2=keycode2..
PROTOCOLO
Lista de protocolos del kernel a habilitar separados por comas (no distingue mayúsculas de minúsculas). Los protocolos del kernel soportados son: nec, rc-5, rc-6, jvc, sony, sanyo, rc-5-sz, sharp, mce-kbd, xmp, imon, rc-mm, other, all. También puede ser un protocolo BPF, por ejemplo manchester, pulse_distance, pulse_length. Si no coincide con ninguno de estos, se toma como la ruta del decodificador BPF a cargar.
PARÁMETROS
Lista de parámetros para el protocolo BPF que se está cargando, separados por comas. Tienen el formato nombre=valor, donde valor es un número.
RETRASO
Retraso antes de repetir una pulsación de tecla
PERÍODO
Período para repetir una pulsación de tecla
ARCHIVO_DE_CONFIGURACIÓN
archivo de configuración que asocia un nombre de controlador/mapa de teclas con un archivo de mapa de teclas

ESTADO DE SALIDA

En caso de éxito, devuelve 0. De lo contrario, devolverá el código de error.

EJEMPLOS

Para listar todos los dispositivos de mando a distancia conectados:
ir-keytable

Para limpiar la asignación de keycode y usar una más nueva:
ir-keytable -c -w /etc/rc_keymaps/nec_terratec_cinergy_xs.toml

Para añadir más códigos a la tabla existente:
ir-keytable -w /etc/rc_keymaps/nec_terratec_cinergy_xs.toml

Para leer la asignación actual de scancode a keycode en el segundo mando a distancia:
ir-keytable -s rc1 -r

Para habilitar el protocolo NEC y cargar un protocolo BPF, con un parámetro para el protocolo BPF:
ir-keytable -p nec,pulse_distance -e pulse_header=9000

Si no sabes qué protocolo usa un mando, puede ser útil probar primero con todos los decodificadores del kernel habilitados. El protocolo decodificado y los scancodes se mostrarán en la salida:
ir-keytable -c -p all -t
