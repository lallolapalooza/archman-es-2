IRCAT(1) Comandos de usuario IRCAT(1)

NOMBRE

ircat - imprime cadenas al presionar botones

SINOPSIS

ircat [opciones] <prog>

DESCRIPCIÓN

Este programa imprime cadenas de configuración a la salida estándar. Se puede usar para proporcionar entrada de control remoto a scripts y para depurar su archivo .lircrc.

El argumento para el programa es el nombre del programa, tal como aparece en las entradas `prog` en .lircrc.

-h --help
Muestra el resumen de uso.
-v --version
Muestra la versión.
-c --config=<archivo>
Establece el archivo de configuración.

EJEMPLOS

Si .lircrc contiene:

begin
        prog = myprog
        button = KEY_CHANNELUP
        config = next_file
end

entonces

$ ircat myprog

imprimirá "next_file" (seguido de una nueva línea) cada vez que se presione el botón asociado a KEY_CHANNELUP.

ENTORNO

LIRC_SOCKET_PATH
El socket de salida de lircd(8) utilizado para recuperar datos. Por defecto es /var/run/lirc/lircd

VER TAMBIÉN
