ids2ngram(1)

Paquete: sunpinyin

Licencias: LGPL

IDS2NGRAM(1) Documentación de Perl contribuida por el usuario IDS2NGRAM(1)

NOMBRE

ids2ngram - genera un archivo de datos n-gram a partir de un archivo ids

SINOPSIS

ids2ngram [opción]... archivo_ids...

DESCRIPCIÓN

ids2ngram genera un archivo idngram, que es un array ordenado [id1,..,idN,freq] a partir de archivos de flujo de id binarios. Aquí, los archivos de flujo de id siempre se generan por mmseg o slmseg. Básicamente, encuentra todas las ocurrencias de tuplas de n palabras (es decir, la tupla de (id1,..,idN)), y ordena estas tuplas por el orden lexicográfico de los ids que componen las tuplas, luego las escribe en el archivo de salida especificado.

ENTRADA

El archivo de entrada se presenta como un flujo de id binario, que se ve así:
[id0,...,idX]

OPCIONES

Todas las siguientes opciones son obligatorias.

-n,--NMax N
Genera el resultado de N-grama. ids2ngram solo admite uni-grama, bi-grama y tri-grama, por lo que cualquier número no en el rango de 1..3 no es válido.
-s,--swap archivo_intercambio
Especifica el archivo temporal intermedio.
-o, --out archivo_salida
Especifica el archivo idngram resultante, por ejemplo, el array de [id1, ..., idN, freq]
-p, --para N
Especifica los elementos máximos de n-grama por párrafo. ids2ngram escribe en el archivo temporal por párrafo. Cada vez que escribe un párrafo, libera la memoria correspondiente asignada para él. Cuando el sistema de su computadora lo permite, se sugiere un N mayor. Esto puede acelerar la velocidad de procesamiento debido a menos I/O.

EJEMPLO

El siguiente ejemplo utilizará tres archivos de flujo de id de entrada idsfile[1,2,3] para generar el archivo idngram all.id3gram. Cada párrafo (tamaño de mapa interno o tamaño de hash) sería 1024000, usando el archivo de intercambio para resultados temporales. Todos los resultados de párrafos temporales se fusionarán para obtener el resultado final.

ids2ngram -n 3 -s /tmp/swap -o all.id3gram -p 1024000 idsfile1 idsfile2 idsfile3
