NOMBRE

idmap_rid - Backend de idmap_rid de Samba para Winbind

DESCRIPCIÓN

El backend idmap_rid proporciona una forma de utilizar un esquema de mapeo algorítmico para mapear UIDs/GIDs y SIDs. En este caso no se requiere base de datos, ya que el mapeo es determinista.

Actualmente, debe haber una configuración explícita de idmap para cada dominio que deba utilizar el backend idmap_rid, utilizando rangos disjuntos.

NOTA: El backend idmap_rid NO puede utilizarse como backend predeterminado. Normalmente se necesita definir un rango de idmap predeterminado escribible, utilizando un backend como tdb o ldap que pueda crear ids de Unix, para poder mapear los SIDs BUILTIN y otros dominios, y también para poder crear mapeos de grupos. Consulte el ejemplo a continuación.

OPCIONES IDMAP

rango = bajo - alto

Define el rango de uid y gid coincidente disponible para el cual el backend es autoritativo. Tenga en cuenta que el rango actúa como un filtro. Si el UID o GID determinado algorítmicamente cae fuera del rango, se ignoran y el mapeo correspondiente se descarta. Está destinado a evitar superposiciones accidentales de UID/GID entre IDs locales y definidos remotamente.

rid_base = ENTERO

Define el entero base utilizado para construir SIDs a partir de un UID o un GID, y para rebasar el UID o GID a obtener de un SID. Esto significa que los SIDs con un RID inferior al RID base son filtrados. El valor predeterminado es no restringir los rids permitidos en absoluto, es decir, un valor de rid_base de 0.

El uso de este parámetro está obsoleto.

LAS FÓRMULAS DE MAPEADO

El ID de Unix para un RID se calcula de la siguiente manera:

ID = RID - BASE_RID + LOW_RANGE_ID.

Correspondientemente, la fórmula para calcular el RID para un ID de Unix dado es esta:

RID = ID + BASE_RID - LOW_RANGE_ID.

EJEMPLOS

Este ejemplo muestra cómo configurar dos dominios con idmap_rid, el dominio principal y un dominio de confianza, dejando el esquema de mapeo de id predeterminado en tdb. El ejemplo también demuestra el uso del parámetro rid_base para el dominio de confianza.

[global]
security = domain
workgroup = MAIN
idmap config * : backend        = tdb
idmap config * : range          = 1000000-1999999
idmap config MAIN : backend     = rid
idmap config MAIN : range       = 10000 - 49999
idmap config TRUSTED : backend  = rid
idmap config TRUSTED : range    = 50000 - 99999
idmap config TRUSTED : base_rid = 500000
