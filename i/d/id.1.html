ID(1) Comandos de usuario ID(1)

NOMBRE

id - imprime las IDs de usuario y grupo reales y efectivas

SINOPSIS

id [OPCIÓN]... [USUARIO]...

DESCRIPCIÓN

Imprime información de usuario y grupo para cada USUARIO especificado, o (cuando se omite USUARIO) para el proceso actual.

-a
ignorar, por compatibilidad con otras versiones
-Z, --contexto
imprime solo el contexto de seguridad del proceso
-g, --grupo
imprime solo la ID de grupo efectiva
-G, --grupos
imprime todas las IDs de grupo
-n, --nombre
imprime un nombre en lugar de un número, para -u,-g,-G
-r, --real
imprime la ID real en lugar de la ID efectiva, con -u,-g,-G
-u, --usuario
imprime solo la ID de usuario efectiva
-z, --cero
delimita las entradas con caracteres NUL, no con espacios en blanco; no permitido en el formato predeterminado
--ayuda
muestra esta ayuda y sale
--version
muestra información de versión y sale

Sin ninguna OPCIÓN, imprime un conjunto útil de información identificada.
