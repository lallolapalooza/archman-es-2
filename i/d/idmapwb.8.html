NOMBRE

idmapwb.so - plugin de mapeo de ID de winbind para cifs-utils

DESCRIPCIÓN

Este plugin permite que las utilidades en cifs-utils funcionen conjuntamente con la instalación de winbind de la suite Samba. Maneja varias funciones, incluyendo el mapeo de UID y GID a SID y viceversa.

Las utilidades generalmente se configuran para usar el plugin correcto creando un enlace simbólico en /etc/cifs-utils/idmap-plugin que apunte al plugin correcto que desea utilizar.

Este plugin requiere que winbindd(8) esté configurado y ejecutándose correctamente.

VER TAMBIÉN

getcifsacl(1), setcifsacl(1), cifs.idmap(8), samba(7), smb.conf(5), winbindd(8)
