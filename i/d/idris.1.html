NOMBRE

idris - un lenguaje de programación funcional puro de propósito general con tipos dependientes.

SINOPSIS

idris [ opciones] [ARCHIVOS]

DESCRIPCIÓN

Idris es un lenguaje de programación funcional puro de propósito general con tipos dependientes. Los tipos dependientes permiten que los tipos sean predicados sobre valores, lo que significa que algunos aspectos del comportamiento de un programa pueden especificarse con precisión en el tipo. Está compilado, con evaluación ansiosa. Sus características están influenciadas por Haskell y ML.

+ Tipos dependientes completos con correspondencia de patrones dependientes

+ Expresiones de caso simples, cláusulas where, regla with

+ Vinculaciones de let y lambda con correspondencia de patrones

+ Sobrecarga a través de Interfaces (similar a las clases de tipo), comprensiones Monad

+ notación do, corchetes idiomáticos

+ Conveniencias sintácticas para listas, tuplas, pares dependientes

+ Verificación de totalidad

+ Tipos coinductivos

+ Sintaxis que depende de la indentación, sintaxis extensible

+ Demostración de teoremas basada en tácticas (influenciada por Coq)

+ Universos acumulativos

+ Interfaz de función externa simple

+ Entorno interactivo estilo Hugs

Es importante tener en cuenta que Idris es, ante todo, una herramienta de investigación y un proyecto. Por lo tanto, las herramientas proporcionadas y los programas resultantes creados no deben considerarse necesariamente listos para producción ni para uso industrial.

OPCIONES


--nobanner Suprime el banner
-q,--quiet Verbosity silenciosa
--ide-mode Ejecuta el REPL de Idris con sintaxis legible por máquina
--ide-mode-socket Elige un socket para que el modo IDE escuche
--ideslave Versión obsoleta de --ide-mode
--ideslave-socket Versión obsoleta de --ide-mode-socket
--log NIVEL Nivel de registro de depuración
--logging-categories CATS
Categorías de registro separadas por dos puntos. Usa --listlogcats
para ver la lista.
--nobasepkgs No usar el paquete base dado
--noprelude No usar el preludio dado
--nobuiltins No usar las funciones integradas
--check Solo verificar tipos, no iniciar el REPL
-o,--output ARCHIVO Especificar archivo de salida
--interface Generar archivos de interfaz a partir de ExportLists
--typeintype Desactivar la verificación del universo
--total Requerir que las funciones sean totales por defecto
--warnpartial Advertir sobre funciones parciales no declaradas
--warnreach Advertir sobre argumentos accesibles pero inaccesibles
--listlogcats Mostrar categorías de registro
--link Mostrar banderas de enlace
--listlibs Mostrar bibliotecas instaladas
--libdir Mostrar directorio de bibliotecas
--include Mostrar las banderas de inclusión
--V2 Verbosity máxima
--V1 Verbosity más alta
-V,--V0,--verbose Verbosity alta
--ibcsubdir ARCHIVO Escribir archivos IBC en un subdirectorio
-i,--idrispath ARG Añadir directorio a la lista de rutas de importación
--sourcepath ARG Añadir directorio a la lista de rutas de búsqueda de fuentes
-p,--package ARG Añadir paquete como dependencia
--port PUERTO Puerto TCP del REPL
--build IPKG Construir paquete
--install IPKG Instalar paquete
--repl IPKG Iniciar REPL, solo para ejecutables
--clean IPKG Limpiar paquete
--mkdoc IPKG Generar IdrisDoc para el paquete
--checkpkg IPKG Verificar paquete solo
--testpkg IPKG Ejecutar pruebas para el paquete
-S,--codegenonly No realizar más compilación de la salida del generador de código
-c,--compileonly Compilar a archivos objeto en lugar de un ejecutable
--codegen OBJETIVO Seleccionar generador de código: C, Javascript, Node y
bytecode se incluyen con Idris
--cg-opt ARG Argumentos para pasar al generador de código
-e,--eval EXPR Evaluar una expresión sin iniciar el REPL
--execute Ejecutar como idris
--exec EXPR Ejecutar como idris
-X,--extension EXT Activar extensión de lenguaje (TypeProviders o
ErrorReflection)
--partial-eval Activar evaluación parcial
--target TRIPLE Si es compatible, el generador de código tendrá como objetivo el triple nombrado.
--cpu CPU Si es compatible, el generador de código tendrá como objetivo la CPU nombrada
por ejemplo, corei7 o cortex-m3.
--color,--colour Forzar salida con colores
--nocolor,--nocolour Desactivar salida con colores
--optimise-nat-like-types,--optimize-nat-like-types
Compilar tipos similares a Nat en enteros grandes
--no-optimise-nat-like-types,--no-optimize-nat-like-types
No compilar tipos similares a Nat en enteros grandes
--consolewidth ANCHO Seleccionar ancho de consola: auto, infinito, nat
--highlight Emitir resaltado de código fuente
--no-tactic-deprecation-warnings
Desactivar advertencias de depreciación para el antiguo sublenguaje de
tácticas
-v,--version Imprimir información de la versión
-h,--help Mostrar este texto de ayuda
