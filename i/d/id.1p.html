DESCRIPCIÓ

N

Si no se proporciona el operando usuario, la utilidad id escribirá en la salida estándar los identificadores de usuario y de grupo y los nombres de usuario y de grupo correspondientes del proceso que la invoca. Si los identificadores efectivo y real no coinciden, se escribirán ambos. Si el sistema subyacente admite múltiples grupos (vea la descripción de {NGROUPS_MAX} en el volumen de Interfaces del Sistema de POSIX.1‐2017), también se escribirán las afiliaciones de grupo suplementarias del proceso que la

invoca.

Si se proporciona un operando usuario y el proceso tiene los privilegios adecuados, se escribirán los identificadores de usuario y de grupo del usuario seleccionado. En este caso, se asumirá que los identificadores efectivos son idénticos a los rea

les. Si el usuario seleccionado tiene más de una membresía de grupo permitida listada en la base de datos de gru
pos, estas se escribirán de la misma manera que los grupos suplementarios descritos en el párrafo anterior.
