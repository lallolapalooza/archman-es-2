IDN(1) Comandos de usuario IDN(1)

NOMBRE

idn - Herramienta de línea de comandos para Nombres de Dominio Internacionalizados

SINOPSIS

idn [OPCIÓN]... [CADENAS]...

DESCRIPCIÓN

Nombres de Dominio Internacionalizados (IDN) convierte CADENAS, o la entrada estándar.

Interfaz de línea de comandos para la biblioteca de nombres de dominio internacionalizados.

Se espera que todas las cadenas estén codificadas en el juego de caracteres preferido utilizado por su configuración regional. Use --debug para averiguar cuál es este juego de caracteres. Puede anular el juego de caracteres utilizado estableciendo la variable de entorno CHARSET.

Para procesar una cadena que comienza con '-', por ejemplo '-foo', use '--' para indicar el final de los parámetros, como en: idn --quiet -a -- -foo

Los argumentos obligatorios para las opciones largas también son obligatorios para las opciones cortas.

-h, --help
Imprime la ayuda y sale
-V, --version
Imprime la versión y sale
-s, --stringprep
Prepara la cadena según el perfil nameprep
-d, --punycode-decode
Decodifica Punycode
-e, --punycode-encode
Codifica Punycode
-a, --idna-to-ascii
Convierte a ACE según IDNA (modo predeterminado)
-u, --idna-to-unicode
Convierte de ACE según IDNA
--allow-unassigned
Activa/desactiva el indicador AllowUnassigned de IDNA (desactivado por defecto)
--usestd3asciirules
Activa/desactiva el indicador UseSTD3ASCIIRules de IDNA (desactivado por defecto)
--no-tld
No comprueba si la cadena tiene reglas específicas de TLD. Solo para --idna-to-ascii y --idna-to-unicode
-n, --nfkc
Normaliza la cadena según NFKC de Unicode v3.2
-p, --profile=CADENA
Usa el perfil de stringprep de cadena especificado. Perfiles de stringprep válidos: Nameprep iSCSI Nodeprep Resourceprep trace SASLprep
--debug
Imprime información de depuración
--quiet
Operación silenciosa
