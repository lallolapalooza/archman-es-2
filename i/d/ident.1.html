IDENT(1) Manual de Comandos Generales IDENT(1)

NOMBRE

ident - identifica cadenas de palabras clave RCS en archivos

SINOPSIS

ident [ -q ] [ -V ] [ archivo ... ]

DESCRIPCIÓN

ident busca todas las instancias del patrón $palabra_clave: texto $ en los archivos nombrados o, si no se nombra ningún archivo, la entrada estándar.

Estos patrones normalmente son insertados automáticamente por el comando RCS co(1), pero también pueden ser insertados manualmente. La opción -q suprime la advertencia que se da si no hay patrones en un archivo. La opción -V imprime el número de versión de RCS.

ident funciona en archivos de texto, así como en archivos objeto y dumps. Por ejemplo, si el programa C en f.c contiene

#include <stdio.h>
static char const rcsid[] =
"$Id: f.c,v 5.4 1993/11/09 17:40:15 eggert Exp $";
int main() { return printf("%s\n", rcsid) == EOF; }

y f.c se compila en f.o, entonces el comando

ident f.c f.o

mostrará

f.c:
    $Id: f.c,v 5.4 1993/11/09 17:40:15 eggert Exp $
f.o:
    $Id: f.c,v 5.4 1993/11/09 17:40:15 eggert Exp $

Si un programa C define una cadena como rcsid arriba pero no la usa, lint(1) puede quejarse, y algunos compiladores C eliminarán la cadena. La solución más fiable es hacer que el programa use la cadena rcsid, como se muestra en el ejemplo anterior.

ident encuentra todas las instancias del patrón $palabra_clave: texto $, incluso si palabra_clave no es realmente una palabra clave soportada por RCS. Esto le proporciona información sobre palabras clave no estándar como $XConsortium$.

El patrón normalmente requiere dos puntos y un espacio inmediatamente después de la palabra clave y un espacio inmediatamente antes del $ final, pero para compatibilidad con Subversion 1.2 (y posteriores), ident también reconocerá el patrón $palabra_clave:: texto $ (es decir, dos puntos y un espacio) y el patrón $palabra_clave:: texto #$ (asimismo, con un hash antes del $ final). Estas son la sintaxis de palabra clave de ancho fijo. En resumen, los tres patrones reconocidos son:

$palabra_clave: texto $
$palabra_clave:: texto $
$palabra_clave:: texto #$

PALABRAS CLAVE

Aquí está la lista de palabras clave mantenidas actualmente por co(1). Todas las horas se dan en Tiempo Universal Coordinado (UTC, a veces llamado GMT) por defecto, pero si los archivos fueron extraídos con la opción -zzona de co, las horas se dan con un indicador de zona horaria numérico adjunto.

$Author$
El nombre de inicio de sesión del usuario que registró la revisión.
$Date$
La fecha y hora en que se registró la revisión.
$Header$
Una cabecera estándar que contiene el nombre completo del archivo RCS, el número de revisión, la fecha y hora, el autor, el estado y el casillero (si está bloqueado).
$Id$
Igual que $Header$, excepto que el nombre del archivo RCS no tiene componentes de directorio.
$Locker$
El nombre de inicio de sesión del usuario que bloqueó la revisión (vacío si no está bloqueado).
$Log$
El mensaje de registro suministrado durante el registro. Para los propósitos de ident, esto es equivalente a $RCSfile$.
$Name$
El nombre simbólico utilizado para extraer la revisión, si existe.
$RCSfile$
El nombre del archivo RCS sin componentes de directorio.
$Revision$
El número de revisión asignado a la revisión.
$Source$
El nombre completo del archivo RCS.
$State$
El estado asignado a la revisión con la opción -s de rcs(1) o ci(1).

co(1) representa los siguientes caracteres en los valores de palabras clave mediante secuencias de escape para mantener las cadenas de palabras clave bien formadas.

carácter	secuencia de escape
tab	\t
nueva línea	\n
espacio	\040
$	\044
\	\\
