NOMBRE

idmap_tdb - Backend de idmap de Samba para Winbind

DESCRIPCIÓN

El plugin idmap_tdb es el backend predeterminado utilizado por winbindd para almacenar tablas de mapeo SID/uid/gid.

A diferencia de los backends de solo lectura como idmap_rid, es un backend asignador: esto significa que necesita asignar nuevas IDs de usuario y grupo para crear nuevos mapeos.

OPCIONES IDMAP

range = bajo - alto

Define el rango coincidente de uid y gid disponible para el cual el backend es autoritativo.

EJEMPLOS

Este ejemplo muestra cómo se usa tdb como el backend de idmap predeterminado. Este rango configurado se utiliza para la asignación de uid y gid.

[global]
# "backend = tdb" es redundante aquí ya que es el predeterminado
idmap config * : backend = tdb
idmap config * : range = 1000000-2000000
