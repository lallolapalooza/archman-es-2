idn2_to_ascii_4i(3)

Paquete: libidn2

Licencias: GPL2, LGPL3

idn2_to_ascii_4i(3) libidn2 idn2_to_ascii_4i(3)

NOMBRE

idn2_to_ascii_4i - función de la API

SINOPSIS

#include <idn2.h>

int idn2_to_ascii_4i(const uint32_t * input, size_t inlen, char * output, int flags);

ARGUMENTOS

const uint32_t * input
cadena de entrada Unicode (UCS-4) terminada en cero.
size_t inlen
número de elementos en input.
char * output
cadena de salida terminada en cero que debe tener espacio para al menos 63 caracteres más el cero terminador.
int flags
banderas opcionales idn2_flags para modificar el comportamiento.

DESCRIPCIÓN

La operación ToASCII toma una secuencia de puntos de código Unicode que componen una etiqueta de dominio y la transforma en una secuencia de puntos de código en el rango ASCII (0..7F). Si ToASCII tiene éxito, la secuencia original y la secuencia resultante son etiquetas equivalentes.

Es importante notar que la operación ToASCII puede fallar. ToASCII falla si alguno de sus pasos falla. Si algún paso de la operación ToASCII falla en alguna etiqueta de un nombre de dominio, ese nombre de dominio NO DEBE usarse como un nombre de dominio internacionalizado. El método para manejar este fallo es específico de la aplicación.

Las entradas para ToASCII son una secuencia de puntos de código.

ToASCII nunca altera una secuencia de puntos de código que son todos en el rango ASCII desde el principio (aunque podría fallar). Aplicar la operación ToASCII múltiples veces tiene el mismo efecto que aplicarla solo una vez.

El comportamiento predeterminado de esta función (cuando las banderas son cero) es aplicar las reglas de IDNA2008 sin las enmiendas TR46. Dado que el procesamiento no transicional de TR46 es hoy en día ubicuo, cuando no esté seguro, se recomienda llamar a esta función con las banderas IDN2_NONTRANSITIONAL y IDN2_NFC_INPUT para compatibilidad con otro software.

ADVERTENCIA

Con la versión 2.1.1 hasta antes de la versión 2.3.5, esta función estaba deprecada en favor de idn2_to_ascii_4i2(). Todavía le animamos a que utilice idn2_to_ascii_4i2() cuando sea apropiado.

RETORNA

En caso de conversión exitosa, se devuelve IDN2_OK; si la etiqueta de salida hubiera sido demasiado larga, se devuelve IDN2_TOO_BIG_LABEL, o se devuelve otro código de error.
