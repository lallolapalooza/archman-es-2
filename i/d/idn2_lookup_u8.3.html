idn2_lookup_u8(3) libidn2 idn2_lookup_u8(3)

NOMBRE

idn2_lookup_u8 - función de la API

SINOPSIS

#include <idn2.h>

int idn2_lookup_u8(const uint8_t * src, uint8_t ** lookupname, int flags);

ARGUMENTOS

const uint8_t * src
cadena de entrada terminada en cero en UTF-8 en forma normalizada Unicode NFC.
uint8_t ** lookupname
variable de salida recién asignada con el nombre a buscar en el DNS.
int flags
opcional idn2_flags para modificar el comportamiento.

DESCRIPCIÓN

Realiza la conversión de cadena de búsqueda IDNA2008 en el nombre de dominio src, como se describe en la sección 5 de RFC 5891. Tenga en cuenta que la cadena de entrada debe estar codificada en UTF-8 y en forma NFC de Unicode.

Pase IDN2_NFC_INPUT en flags para convertir la entrada a forma NFC antes de un procesamiento adicional. IDN2_TRANSITIONAL y IDN2_NONTRANSITIONAL ya implican IDN2_NFC_INPUT.

Pase IDN2_ALABEL_ROUNDTRIP en flags para convertir cualquier etiqueta A de entrada a etiquetas U y realizar pruebas adicionales. Esto es predeterminado desde la versión 2.2. Para desactivar este comportamiento, pase IDN2_NO_ALABEL_ROUNDTRIP

Pase IDN2_TRANSITIONAL para habilitar el procesamiento transicional de Unicode TR46, y IDN2_NONTRANSITIONAL para habilitar el procesamiento no transicional de Unicode TR46.

Se pueden especificar varias banderas mediante un OR binario entre ellas.

Después de la versión 2.0.3: IDN2_USE_STD3_ASCII_RULES desactivado por defecto. Anteriormente eliminábamos caracteres no-STD3 de cadenas de dominio como _443._tcp.example.com, o IPs 1.2.3.4/24 proporcionadas a las funciones de libidn2. Esta fue una regresión inesperada para las aplicaciones que cambiaban de libidn y, por lo tanto, ya no se aplica por defecto. Use IDN2_USE_STD3_ASCII_RULES para volver a habilitar ese comportamiento.

Después de la versión 0.11: lookupname puede ser NULL para probar la búsqueda de src sin asignar memoria.

RETORNA

En caso de conversión exitosa, se devuelve IDN2_OK; si el dominio de salida o alguna etiqueta hubieran sido demasiado grandes, se devuelve IDN2_TOO_BIG_DOMAIN o IDN2_TOO_BIG_LABEL, o se devuelve otro código de error.
