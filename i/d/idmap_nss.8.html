IDMAP_NSS(8) Herramientas de Administración del Sistema IDMAP_NSS(8)

NOMBRE

idmap_nss - Backend de idmap_nss de Samba para Winbind

DESCRIPCIÓN

El plugin idmap_nss proporciona un medio para mapear usuarios y grupos de Unix a cuentas de Windows. Esto proporciona un medio simple para asegurar que el SID de un usuario de Unix llamado jsmith se informe como el asignado a DOMAIN\jsmith, lo cual es necesario para informar los ACLs en archivos e impresoras almacenados en un servidor miembro de Samba.

OPCIONES IDMAP

range = bajo - alto

Define el rango de UID y GID correspondiente para el cual el backend es autoritativo. Tenga en cuenta que el rango actúa como un filtro. Los UID o GID devueltos por los módulos NSS que caen fuera del rango se ignoran y los mapas correspondientes se descartan. Está destinado a evitar solapamientos accidentales de UID/GID entre IDs locales y definidos remotamente.

use_upn = <sí | no>

Algunos módulos NSS pueden devolver y manejar UPNs y/o nombres de inicio de sesión de nivel inferior (por ejemplo, DOMAIN\usuario o usuario@REALM).

Si este parámetro está habilitado, los nombres devueltos por NSS se analizarán y el espacio de nombres resultante se utilizará como el espacio de nombres autoritativo en lugar del nombre de dominio IDMAP. Además, se enviarán nombres de inicio de sesión de nivel inferior a NSS en lugar del nombre de usuario simple para dar a los módulos NSS una pista sobre el dominio correcto del usuario.

Predeterminado: no

EJEMPLOS

Este ejemplo muestra cómo usar idmap_nss para obtener los IDs de cuenta locales para su propio dominio (SAMBA) de NSS, mientras se asignan nuevos mapeos para el dominio predeterminado (*) y cualquier dominio de confianza.

[global]
idmap config * : backend = tdb
idmap config * : range = 1000000-1999999
idmap config SAMBA : backend  = nss
idmap config SAMBA : range = 1000-999999
