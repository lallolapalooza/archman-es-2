NOMBRE

idn2_to_unicode_8z4z - Función de la API

SINOPSIS

#include <idn2.h>

int idn2_to_unicode_8z4z(const char * input, uint32_t ** output, G_GNUC_UNUSED int flags);

ARGUMENTOS

const char * input
Cadena de entrada terminada en cero en formato UTF-8.
uint32_t ** output
Cadena de salida UTF-32/UCS-4 recién asignada.
G_GNUC_UNUSED int flags
Actualmente no utilizado.

DESCRIPCION

Convierte un nombre de dominio posiblemente codificado en ACE en formato UTF-8 a una cadena UTF-32 (decodificación punycode). El búfer de salida estará terminado en cero y debe ser liberado por el llamador.


output puede ser NULL para probar la búsqueda de input sin asignar memoria.
