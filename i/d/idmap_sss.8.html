NOMBRE

idmap_sss - Backend idmap_sss de SSSD para Winbind

DESCRIPCIÓN

El módulo idmap_sss proporciona una forma de llamar a SSSD para mapear UIDs/GIDs y SIDs. No se requiere ninguna base de datos en este caso, ya que el mapeo lo realiza SSSD.

OPCIONES IDMAP

rango = bajo - alto

Define el rango coincidente disponible de UID y GID para el cual el backend es autoritativo.

EJEMPLOS

Este ejemplo muestra cómo configurar idmap_sss como el módulo de mapeo predeterminado.

[global]
security = ads
workgroup = <NOMBRE_CORTO_DOMINIO_AD>
idmap config <NOMBRE_CORTO_DOMINIO_AD> : backend        = sss
idmap config <NOMBRE_CORTO_DOMINIO_AD> : range          = 200000-2147483647
idmap config * : backend        = tdb
idmap config * : range          = 100000-199999

Reemplace <NOMBRE_CORTO_DOMINIO_AD> con el nombre de dominio NetBIOS del dominio AD. Si se deben utilizar varios dominios AD, cada dominio necesita una línea de configuración de idmap con backend = sss y una línea con un rango adecuado.

Dado que Winbind requiere un backend predeterminado escribible y idmap_sss es de solo lectura, el ejemplo incluye backend = tdb como predeterminado.
