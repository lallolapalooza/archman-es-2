NOMBRE

idevicepair - Administra los emparejamientos del host con dispositivos y usbmuxd.

SINOPSIS

idevicepair [OPCIONES] COMANDO

DESCRIPCIÓN

Administra los emparejamientos del host con dispositivos y usbmuxd.

OPCIONES

-u, --udid UDID
dirigirse a un dispositivo específico por UDID.
-w, --wireless
realizar emparejamiento inalámbrico (ver NOTA).
-n, --network
conectarse a un dispositivo de red (ver NOTA).
-d, --debug
habilitar la depuración de comunicación.
-h, --help
imprime información de uso.
-v, --version
imprime información de versión.

COMANDOS

systembuid
imprime el buid del sistema del host usbmuxd.
hostid
imprime el ID del host para el dispositivo de destino.
pair
empareja el dispositivo con este host.
validate
valida si el dispositivo está emparejado con este host.
unpair
desempareja el dispositivo con este host.
list
lista los dispositivos emparejados con este host.

NOTA

El emparejamiento a través de la red (emparejamiento inalámbrico) solo es compatible con los dispositivos Apple TV. Para realizar un emparejamiento inalámbrico, necesita usar el modificador de línea de comandos -w.

Asegúrese de poner el dispositivo en modo de emparejamiento primero abriendo Ajustes > Mandos a distancia y Dispositivos > App Mando a distancia y Dispositivos.

El dispositivo emparejable se hará visible con un UDID especial, y luego podrá ejecutar idevicepair de esta manera:

idevicepair -u fffc8:ab:cd:12:34:56fff -w pair

idevicepair le pedirá entonces el PIN que muestra el dispositivo y continuará con el emparejamiento una vez introducido.

Tenga en cuenta que el emparejamiento inalámbrico no es compatible actualmente en Linux.
