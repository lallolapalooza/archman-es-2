idna_strerror(3)

Paquete: libidn

Licencias: GPL3, LGPL

idna_strerror(3) libidn idna_strerror(3)

NOMBRE

idna_strerror - función de la API

SINOPSIS

#include <idna.h>

const char * idna_strerror(Idna_rc rc);

ARGUMENTOS

Idna_rc rc
un código de retorno Idna_rc.

DESCRIPCIÓN

Convierte un entero de código de retorno a una cadena de texto. Esta cadena se puede usar para mostrar un mensaje de diagnóstico al usuario.

IDNA_SUCCESS

Operación exitosa. Este valor siempre se garantiza que sea cero, los restantes solo se garantizan que tengan valores distintos de cero, para fines de comparación lógica.

IDNA_STRINGPREP_ERROR

Error durante la preparación de la cadena.

IDNA_PUNYCODE_ERROR

Error durante la operación de punycode.

IDNA_CONTAINS_NON_LDH

Para IDNA_USE_STD3_ASCII_RULES, indica que la cadena contiene caracteres ASCII no LDH.

IDNA_CONTAINS_MINUS

Para IDNA_USE_STD3_ASCII_RULES, indica que la cadena contiene un guion-menos (U+002D) al principio o al final.

IDNA_INVALID_LENGTH

La cadena de salida final no está dentro del rango (inclusivo) de 1 a 63 caracteres.

IDNA_NO_ACE_PREFIX

La cadena no contiene el prefijo ACE (para ToUnicode).

IDNA_ROUNDTRIP_VERIFY_ERROR

La operación ToASCII sobre la cadena de salida no es igual a la entrada.

IDNA_CONTAINS_ACE_PREFIX

La entrada contiene el prefijo ACE (para ToASCII).

IDNA_ICONV_ERROR

Error de conversión de codificación de caracteres.

IDNA_MALLOC_ERROR

No se pudo asignar el búfer (esto suele ser un error fatal).

IDNA_DLOPEN_ERROR

No se pudo cargar la DSO libcidn (solo se usa internamente en libc).

Valor de retorno: Devuelve un puntero a una cadena asignada estáticamente que contiene una descripción del error con el código de retorno rc.
