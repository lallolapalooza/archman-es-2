NOMBRE

idna_to_ascii_4i - Función de la API

SINOPSIS

#include <idna.h>

int idna_to_ascii_4i(const uint32_t * in, size_t inlen, char * out, int flags);

ARGUMENTOS

const uint32_t * in
matriz de entrada con puntos de código unicode.
size_t inlen
longitud de la matriz de entrada con puntos de código unicode.
char * out
cadena de salida terminada en cero que debe tener espacio para al menos 63 caracteres más el cero terminador.
int flags
un valor de Idna_flags, por ejemplo, IDNA_ALLOW_UNASSIGNED o IDNA_USE_STD3_ASCII_RULES.

DESCRIPCIÓN

La operación ToASCII toma una secuencia de puntos de código Unicode que forman una etiqueta de dominio y la transforma en una secuencia de puntos de código en el rango ASCII (0..7F). Si ToASCII tiene éxito, la secuencia original y la secuencia resultante son etiquetas equivalentes.

Es importante tener en cuenta que la operación ToASCII puede fallar. ToASCII falla si falla alguno de sus pasos. Si algún paso de la operación ToASCII falla en alguna etiqueta de un nombre de dominio, ese nombre de dominio NO DEBE utilizarse como nombre de dominio internacionalizado. El método para manejar este fallo es específico de la aplicación.

Las entradas para ToASCII son una secuencia de puntos de código, el bandera AllowUnassigned y la bandera UseSTD3ASCIIRules. La salida de ToASCII es, o bien una secuencia de puntos de código ASCII, o bien una condición de fallo.

ToASCII nunca altera una secuencia de puntos de código que están todos en el rango ASCII para empezar (aunque podría fallar). Aplicar la operación ToASCII varias veces tiene exactamente el mismo efecto que aplicarla solo una vez.

Valor de retorno: Devuelve 0 en caso de éxito, o un código de error Idna_rc.
