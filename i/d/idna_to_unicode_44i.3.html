idna_to_unicode_44i(3) libidn idna_to_unicode_44i(3)

NOMBRE

idna_to_unicode_44i - función de la API

SINOPSIS

#include <idna.h>

int idna_to_unicode_44i(const uint32_t * in, size_t inlen, uint32_t * out, size_t * outlen, int flags);

ARGUMENTOS

const uint32_t * in
array de entrada con puntos de código unicode.
size_t inlen
longitud del array de entrada con puntos de código unicode.
uint32_t * out
array de salida con puntos de código unicode.
size_t * outlen
en la entrada, tamaño máximo del array de salida con puntos de código unicode, en la salida, tamaño real del array de salida con puntos de código unicode.
int flags
un valor de Idna_flags, p. ej., IDNA_ALLOW_UNASSIGNED o IDNA_USE_STD3_ASCII_RULES.

DESCRIPCIÓN

La operación ToUnicode toma una secuencia de puntos de código Unicode que forman una etiqueta de dominio y devuelve una secuencia de puntos de código Unicode. Si la secuencia de entrada es una etiqueta en formato ACE, el resultado es una etiqueta internacionalizada equivalente que no está en formato ACE; de lo contrario, la secuencia original se devuelve sin cambios.

ToUnicode nunca falla. Si algún paso falla, la secuencia de entrada original se devuelve inmediatamente en ese paso.

El decodificador Punycode nunca puede generar más puntos de código que los de entrada, pero Nameprep sí puede, y por lo tanto ToUnicode también. Tenga en cuenta que el número de octetos necesarios para representar una secuencia de puntos de código depende de la codificación de caracteres particular utilizada.

Las entradas para ToUnicode son una secuencia de puntos de código, el flag AllowUnassigned y el flag UseSTD3ASCIIRules. La salida de ToUnicode es siempre una secuencia de puntos de código Unicode.

Valor de retorno: Devuelve una condición de error Idna_rc, pero solo debe usarse con fines de depuración. El buffer de salida siempre está garantizado para contener los datos correctos según la especificación (sin errores inducidos por malloc). ¡NB! Esto significa que normalmente se ignora el código de retorno de esta función, ya que verificarlo implica romper el estándar.
