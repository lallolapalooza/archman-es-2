Paquete: libidn2

Licencias: GPL2, LGPL3

idn2_register_ul(3) libidn2 idn2_register_ul(3)

NOMBRE

idn2_register_ul - función de la API

SINOPSIS

#include <idn2.h>

int idn2_register_ul(const char * ulabel, const char * alabel, char ** insertname, int flags);

ARGUMENTOS

const char * ulabel
cadena de entrada codificada en locale terminada en nulo, o NULL.
const char * alabel
cadena de entrada codificada en ACE (xn--) terminada en nulo, o NULL.
char ** insertname
variable de salida recién asignada con el nombre a registrar en el DNS.
int flags
opcionales idn2_flags para modificar el comportamiento.

DESCRIPCIÓN

Realiza la conversión de cadena de registro IDNA2008 en las etiquetas de dominio ulabel y alabel , según se describe en la sección 4 de RFC 5891. Tenga en cuenta que se asume que la ulabel de entrada está codificada en el sistema de codificación predeterminado de la configuración regional, y esta función la transcodificará a UTF-8 y la normalizará a NFC.

Se recomienda proporcionar tanto ulabel como alabel para una mejor comprobación de errores, pero proporcionar solo una de ellas funcionará. Pasar solo alabel es mejor que solo ulabel . Consulte la sección 4 de RFC 5891 para obtener más información.

Después de la versión 0.11: insertname puede ser NULL para probar la conversión de src sin asignar memoria.

DEVUELVE

En caso de conversión exitosa, se devuelve IDN2_OK; cuando las etiquetas ulabel y alabel proporcionadas no coinciden, se devuelve IDN2_UALABEL_MISMATCH; cuando alguna de las etiquetas de entrada es demasiado larga, se devuelve IDN2_TOO_BIG_LABEL; cuando alabel no parece ser una etiqueta A válida, se devuelve IDN2_INVALID_ALABEL; cuando la conversión de locale a UTF-8 de ulabel falló, se devuelve IDN2_ICONV_FAIL, o se devuelve algún otro código de error.
