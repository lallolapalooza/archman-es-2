idmapd.conf(5) Manual de Formatos de Archivo idmapd.conf(5)

NOMBRE

idmapd.conf - archivo de configuración para libnfsidmap

SINOPSIS

Archivo de configuración para libnfsidmap. Utilizado por idmapd y svcgssd para mapear nombres NFSv4 a y desde identificadores.

DESCRIPCIÓN

El archivo de configuración idmapd.conf consta de varias secciones, iniciadas por cadenas de la forma [General] y [Mapping]. Cada sección puede contener líneas de la forma

  variable = valor

Las secciones reconocidas y sus variables reconocidas son las siguientes:

Variables de la sección [General]

Verbosity
Nivel de verbosidad de la depuración (Predeterminado: 0)
Domain
El nombre de dominio NFSv4 local. Un dominio NFSv4 es un espacio de nombres con un mapeo único de nombre de usuario<->UID y nombre de grupo<->GID. (Predeterminado: nombre de dominio DNS completamente calificado del host)
No-Strip
En entornos de múltiples dominios, algunos servidores NFS añadirán el dominio de gestión de identidades al propietario (owner) y al grupo propietario (owner_group) en lugar de un dominio NFSv4 real. Esta opción puede facilitar las búsquedas en dichos entornos. Si se establece en un valor distinto de "none", el complemento nsswitch pasará primero el nombre a la función de búsqueda de contraseñas/grupos sin quitar el dominio. Si ese mapeo falla, el complemento intentará de nuevo usando el método antiguo (comparando el dominio en la cadena con el valor de Domain, quitándolo si coincide, y pasando el nombre corto resultante a la función de búsqueda). Los valores válidos son "user", "group", "both" y "none". (Predeterminado: "none")
Reformat-Group
Winbind tiene una peculiaridad por la cual hacer una búsqueda de grupo en formato UPN (p. ej. staff@americas.example.com) hará que el grupo se muestre con el prefijo del dominio completo en mayúsculas (p. ej. AMERICAS.EXAMPLE.COM\staff) en lugar del formato de nombre netbios familiar (p. ej. AMERICAS\staff). Establecer esta opción en true hace que el nombre se reformatee antes de pasarlo a la función de búsqueda de grupos para sortear esto. Esta configuración se ignora a menos que No-Strip esté establecido en "both" o "group". (Predeterminado: "false")
Local-Realms
Una lista separada por comas de nombres de reinos de Kerberos que pueden considerarse equivalentes al nombre de reino local. Por ejemplo, los usuarios juser@ORDER.EDU y juser@MAIL.ORDER.EDU pueden considerarse el mismo usuario en el Domain especificado. (Predeterminado: el nombre de reino predeterminado del host)
Nota: Si se especifica un valor aquí, el reino local predeterminado debe incluirse también.

Variables de la sección [Mapping]

Nobody-User
Nombre de usuario local a utilizar cuando no se puede completar un mapeo.
Nobody-Group
Nombre de grupo local a utilizar cuando no se puede completar un mapeo.

Variables de la sección [Translation]

Method
Una lista ordenada, separada por comas, de métodos de mapeo (complementos) a usar al mapear entre nombres NFSv4 e IDs locales. Cada método especificado se prueba en orden hasta que se encuentra un mapeo, o no quedan más métodos para probar. Los métodos incluidos en la distribución predeterminada incluyen "nsswitch", "umich_ldap" y "static". (Predeterminado: nsswitch)
GSS-Methods
Una lista opcional ordenada, separada por comas, de métodos de mapeo (complementos) a usar al mapear entre nombres autenticados por GSS e IDs locales. (Predeterminado: la misma lista especificada para Method)

Variables de la sección [Static]

El método de traducción "static" utiliza una lista estática de nombres autenticados por GSS a nombres de usuario locales. Las entradas en la lista son de la forma:

 principal@REALM = nombreusuariolocal

Variables de la sección [REGEX]

Si se especifica el método de traducción "regex", las siguientes variables dentro de la sección [REGEX] se usan para mapear entre nombres NFS4 e IDs locales.

User-Regex
Expresión regular que no distingue mayúsculas de minúsculas que extrae el nombre de usuario local de un nombre NFSv4. Se pueden concatenar múltiples expresiones con '|'. Se usará la primera coincidencia. No hay valor predeterminado. Una expresión regular básica para el dominio DOMAIN.ORG y el reino MY.DOMAIN.ORG sería: 
^DOMAIN\([^@]+)@MY.DOMAIN.ORG$
Group-Regex
Expresión regular que no distingue mayúsculas de minúsculas que extrae el nombre de grupo local de un nombre NFSv4. Se pueden concatenar múltiples expresiones con '|'. Se usará la primera coincidencia. No hay valor predeterminado. Una expresión regular básica para el dominio DOMAIN.ORG y el reino MY.DOMAIN.ORG sería: 
^([^@]+)@DOMAIN.ORG@MY.DOMAIN.ORG$|^DOMAIN\([^@]+)@MY.DOMAIN.ORG$
Prepend-Before-User
Cadena constante a poner antes de un nombre de usuario local al construir un nombre NFSv4. Usualmente es el nombre corto del dominio seguido de '´. (Predeterminado: ninguno)
Append-After-User
Cadena constante a poner después de un nombre de usuario local al construir un nombre NFSv4. Usualmente es '@' seguido del reino predeterminado. (Predeterminado: ninguno)
Prepend-Before-Group
Cadena constante a poner antes de un nombre de grupo local al construir un nombre NFSv4. Usualmente no se usa. (Predeterminado: ninguno)
Append-After-Group
Cadena constante a poner antes de un nombre de grupo local al construir un nombre NFSv4. Usualmente es '@' seguido del nombre del dominio seguido de otro '@' y el reino predeterminado. (Predeterminado: ninguno)
Group-Name-Prefix
Cadena constante que se antepone a un nombre de grupo local al convertirlo a un nombre NFSv4. Si un nombre de grupo NFSv4 tiene este prefijo, se elimina al convertirlo a un nombre de grupo local. Con esto, los nombres de grupo de un directorio central pueden acortarse para una unidad organizativa aislada si todos los grupos tienen un prefijo común. (Predeterminado: ninguno)
Group-Name-No-Prefix-Regex
Expresión regular que no distingue mayúsculas de minúsculas para excluir grupos de añadir y eliminar el prefijo establecido por Group-Name-Prefix. La expresión regular debe coincidir tanto con los nombres de grupo remotos como locales. Se pueden concatenar múltiples expresiones con '|'. (Predeterminado: ninguno)

Variables de la sección [UMICH_SCHEMA]

Si se especifica el método de traducción "umich_ldap", se usan las siguientes variables dentro de la sección [UMICH_SCHEMA].

LDAP_server
Nombre o dirección del servidor LDAP (Requerido si se usa UMICH_LDAP)
LDAP_base
Base de búsqueda LDAP absoluta. (Requerido si se usa UMICH_LDAP)
LDAP_people_base
Base de búsqueda LDAP absoluta para cuentas de personas. (Predeterminado: el valor de LDAP_base )
LDAP_group_base
Base de búsqueda LDAP absoluta para cuentas de grupos. (Predeterminado: el valor de LDAP_base valor)
LDAP_canonicalize_name
Si se debe realizar la canonización de nombres en el nombre proporcionado como LDAP_server (Predeterminado: "true")
LDAP_follow_referrals
Si se deben seguir las referencias LDAP. (Predeterminado: "true")
LDAP_use_ssl
Establezca en "true" para habilitar la comunicación SSL con el servidor LDAP. (Predeterminado: "false")
LDAP_ca_cert
Ubicación de un certificado CA de confianza utilizado cuando SSL está habilitado (Requerido si LDAP_use_ssl es true y LDAP_tls_reqcert no está establecido en never)
LDAP_tls_reqcert
Controla el comportamiento de validación del certificado del servidor LDAP. Puede tomar los mismos valores que el ajuste TLS_REQCERT de ldap.conf(5). (Predeterminado: "hard")
LDAP_timeout_seconds
Número de segundos antes de que se agote el tiempo de espera de una solicitud LDAP (Predeterminado: 4)
LDAP_sasl_mech
Mecanismo SASL a utilizar para la autenticación SASL. Requerido si se va a utilizar la autenticación SASL (Predeterminado: Ninguno)
LDAP_realm
Dominio SASL a utilizar para la autenticación SASL. (Predeterminado: Ninguno)
LDAP_sasl_authcid
Identidad de autenticación a utilizar para la autenticación SASL. (Predeterminado: Ninguno)
LDAP_sasl_authzid
Identidad de autorización a utilizar para la autenticación SASL. (Predeterminado: Ninguno)
LDAP_sasl_secprops
Propiedades de seguridad de Cyrus SASL. Puede tomar los mismos valores que sasl_secprops de ldap.conf(5).
LDAP_sasl_canonicalize
Especifica si el nombre de host del servidor LDAP debe ser canonizado. Si se establece en yes, la biblioteca LDAP realizará una búsqueda inversa de host. Si esto no se establece, se utilizará el valor predeterminado de la biblioteca LDAP. (Predeterminado: Ninguno)
LDAP_sasl_krb5_ccname
Ruta al caché de credenciales de Kerberos. Si no se establece, se utilizará el valor de la variable de entorno KRB5CCNAME. Si la variable de entorno no está establecida, se utilizará el mecanismo predeterminado de la biblioteca de Kerberos. Se utilizará.
NFSv4_person_objectclass
El nombre de la clase de objeto para cuentas de personas en su esquema LDAP local (Predeterminado: NFSv4RemotePerson)
NFSv4_name_attr
El nombre del atributo de su esquema local a utilizar para los nombres de usuario NFSv4 (Predeterminado: NFSv4Name)
NFSv4_uid_attr
El nombre del atributo de su esquema local a utilizar para uidNumber (Predeterminado: uidNumber)
GSS_principal_attr
El nombre del atributo de su esquema local para los nombres de Principal GSSAPI (Predeterminado: GSSAuthName)
NFSv4_acctname_attr
El nombre del atributo de su esquema local a utilizar para los nombres de cuenta (Predeterminado: uid)
NFSv4_group_objectclass
El nombre de la clase de objeto para cuentas de grupos en su esquema LDAP local (Predeterminado: NFSv4RemoteGroup)
NFSv4_gid_attr
El nombre del atributo de su esquema local a utilizar para gidNumber (Predeterminado: gidNumber)
NFSv4_group_attr
El nombre del atributo de su esquema local a utilizar para los nombres de grupo NFSv4 (Predeterminado: NFSv4Name)
LDAP_use_memberof_for_groups
Algunos servidores LDAP hacen un mejor trabajo con la indexación al buscar a través de todos los grupos buscando al usuario en la lista memberuid. Otros, como el directorio SunOne, esa búsqueda puede tardar minutos si hay miles de grupos. Por lo tanto, establecer LDAP_use_memberof_for_groups en true en el archivo de configuración utilizará las listas memberof de la cuenta y buscará solo en esos grupos para obtener los gids. (Predeterminado: false)
NFSv4_member_attr
Si LDAP_use_memberof_for_groups es true, este es el atributo a buscar. (Predeterminado: memberUid)
NFSv4_grouplist_filter
Un filtro de búsqueda opcional para determinar la pertenencia a un grupo. (Sin predeterminado)

EJEMPLOS

Un archivo /etc/idmapd.conf de ejemplo:

[General]
Verbosity = 0
Domain = domain.org
Local-Realms = DOMAIN.ORG,MY.DOMAIN.ORG,YOUR.DOMAIN.ORG
[Mapping]
Nobody-User = nfsnobody
Nobody-Group = nfsnobody
[Translation]
Method = umich_ldap,regex,nsswitch
GSS-Methods = umich_ldap,regex,static
[Static]
johndoe@OTHER.DOMAIN.ORG = johnny
[Regex]
User-Regex = ^DOMAIN\([^@]+)@DOMAIN.ORG$
Group-Regex = ^([^@]+)@DOMAIN.ORG@DOMAIN.ORG$|^DOMAIN\([^@]+)@DOMAIN.ORG$
Prepend-Before-User = DOMAIN 
Append-After-User = @DOMAIN.ORG
Append-After-Group = @domain.org@domain.org
Group-Name-Prefix = sales-
Group-Name-No-Prefix-Regex = -personal-group$
[UMICH_SCHEMA]
LDAP_server = ldap.domain.org
LDAP_base = dc=org,dc=domain
