NOMBRE

idna_to_unicode_8zlz - función de la API

SINOPSIS

#include <idna.h>

int idna_to_unicode_8zlz(const char * input, char ** output, int flags);

ARGUMENTOS

const char * input
cadena UTF-8 terminada en nulo.
char ** output
puntero a una cadena de salida recién asignada codificada en el conjunto de caracteres del locale actual.
int flags
un valor Idna_flags, por ejemplo, IDNA_ALLOW_UNASSIGNED o IDNA_USE_STD3_ASCII_RULES.

DESCRIPCIÓN

Convierte un nombre de dominio posiblemente codificado en ACE en formato UTF-8 a una cadena codificada en el conjunto de caracteres del locale actual. El nombre de dominio puede contener varias etiquetas, separadas por puntos. El llamador debe liberar el búfer de salida.

Valor de retorno: Devuelve IDNA_SUCCESS si tiene éxito, o un código de error.
