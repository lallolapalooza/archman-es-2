RPC.IDMAPD(8) Manual del Administrador del Sistema RPC.IDMAPD(8)

NOMBRE

rpc.idmapd — Mapeador de IDs/Nombres de NFSv4

SINOPSIS

rpc.idmapd [-h] [-f] [-v] [-C] [-S] [-p ruta] [-c ruta]

DESCRIPCIÓN

rpc.idmapd es el demonio de mapeo de ID/nombre de NFSv4. Proporciona funcionalidad al cliente y servidor del kernel de NFSv4, con los que se comunica a través de llamadas externas (upcalls), traduciendo los IDs de usuario y grupo a nombres, y viceversa.

El sistema deriva la parte de usuario de la cadena realizando una búsqueda en la contraseña o en el grupo. El mecanismo de búsqueda está configurado en /etc/idmapd.conf

Por defecto, la parte de dominio de la cadena es el nombre de dominio DNS del sistema. También se puede especificar en /etc/idmapd.conf si el sistema tiene múltiples conexiones de red, o si el nombre de dominio DNS del sistema no coincide con el nombre del dominio del realm de Kerberos del sistema.

Cuando el dominio no se especifica en /etc/idmapd.conf, se consultará al servidor DNS local para obtener el registro de texto _nfsv4idmapdomain. Si el registro existe, se utilizará como dominio. Cuando el registro no existe, se utilizará la parte del dominio del nombre de dominio DNS.

Tenga en cuenta que en los kernels más recientes, solo el servidor NFSv4 utiliza rpc.idmapd. El cliente NFSv4 utiliza en su lugar nfsidmap(8), y solo recurre a rpc.idmapd si hubo un problema al ejecutar el programa nfsidmap(8).

Las opciones son las siguientes:

-h
Muestra el mensaje de uso.
-v
Aumenta el nivel de verbosidad (se puede especificar varias veces).
-f
Ejecuta rpc.idmapd en primer plano e imprime toda la salida en la terminal.
-p ruta
Especifica la ubicación del sistema de archivos de tuberías RPC (RPC pipefs) como ruta. El valor por defecto es "/var/lib/nfs/rpc_pipefs".
-c ruta
Utiliza el archivo de configuración ruta. Esta opción está obsoleta.
-C
Solo cliente: no realiza mapeo de IDs para ningún servidor NFS, incluso si se detecta uno.
-S
Solo servidor: no realiza mapeo de IDs para ningún cliente NFS, incluso si se detecta uno.

ARCHIVOS DE CONFIGURACIÓN

rpc.idmapd reconoce el siguiente valor de la sección [general] del archivo de configuración /etc/nfs.conf:

pipefs-directory
Equivalente a -p.

Todos los demás ajustes relacionados con el mapeo de IDs se encuentran en el archivo de configuración /etc/idmapd.conf.

EJEMPLOS

rpc.idmapd -f -vvv

Ejecuta rpc.idmapd imprimiendo todos los mensajes en la consola y con un nivel de verbosidad de 3.

ARCHIVOS

/etc/idmapd.conf, /etc/nfs.conf

VER TAMBIÉN

idmapd.conf(5), nfs.conf(5), nfsidmap(8)
