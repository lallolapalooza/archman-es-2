IDENT(8) Documentación de InterNetNews IDENT(8)

NOMBRE

ident - resolución de ident para nnrpd

SINOPSIS

ident [-p puerto] [-t]

DESCRIPCIÓN

Este programa intenta resolver nombres de usuario para nnrpd utilizando el protocolo ident para consultar el host remoto. Se contacta con el host remoto usando IPv4 o IPv6, dependiendo del protocolo utilizado para la conexión NNTP entrante.

OPCIONES

-p puerto
Si se proporciona esta opción, se intenta contactar con identd en el puerto remoto especificado (que puede ser una especificación numérica o simbólica). Los valores no numéricos se buscarán utilizando getservbyname(3). El valor predeterminado es el resultado de "getservbyname("ident")" si está disponible, o el puerto 113 en caso contrario.
-t
Si se proporciona esta opción, la identidad devuelta nunca tendrá una parte de dominio. Es decir, si el servidor remoto devuelve un resultado que contiene un carácter "@", ident trunca la respuesta en el "@". Esto es útil para permitir que el parámetro default-domain en readers.conf reemplace el dominio proporcionado por el host remoto (particularmente si la parte de dominio proporcionada es un nombre de máquina local no calificado en lugar de un nombre de dominio completo).

EJEMPLO

El siguiente fragmento de readers.conf(5) indica a nnrpd que confíe en la información ident para los hosts en una red local, pero que reemplace el dominio devuelto de la consulta ident:

auth LAN {
    hosts: "192.168/16"
    res: "ident -t"
    default-domain: "internal.example.com"
}
access LAN {
    users: "*@internal.example.com"
    newsgroups: example.*
}

Se concede acceso a los grupos example.* para todos los usuarios de la red local cuyas máquinas respondan a las consultas ident.
