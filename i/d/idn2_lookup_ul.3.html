NOMBRE

idn2_lookup_ul - función de API

SINOPSIS

#include <idn2.h>

int idn2_lookup_ul(const char * src, char ** lookupname, int flags);

ARGUMENTOS

const char * src
cadena de entrada codificada en locale terminada en nulo.
char ** lookupname
variable de salida recién asignada con el nombre a buscar en DNS.
int flags
opcional idn2_flags para modificar el comportamiento.

DESCRIPCIÓN

Realiza la conversión de cadena de búsqueda IDNA2008 en el nombre de dominio src, como se describe en la sección 5 de RFC 5891. Tenga en cuenta que se asume que la entrada está codificada en el sistema de codificación predeterminado del locale, y esta función la transcodificará a UTF-8 y la normalizará en NFC.

Pase IDN2_ALABEL_ROUNDTRIP en flags para convertir cualquier etiqueta A de entrada en etiquetas U y realizar pruebas adicionales. Esto es el valor predeterminado desde la versión 2.2. Para desactivar este comportamiento, pase IDN2_NO_ALABEL_ROUNDTRIP

Pase IDN2_TRANSITIONAL para habilitar el procesamiento transicional de Unicode TR46, y IDN2_NONTRANSITIONAL para habilitar el procesamiento no transicional de Unicode TR46.

Se pueden especificar varios flags mediante el operador OR binario (|), por ejemplo IDN2_ALABEL_ROUNDTRIP | IDN2_NONTRANSITIONAL.

El flag IDN2_NFC_INPUT siempre está habilitado en esta función.

Después de la versión 0.11: lookupname puede ser NULL para probar la búsqueda de src sin asignar memoria.

VALOR DE RETORNO

En caso de conversión exitosa, se devuelve IDN2_OK; si la conversión del locale a UTF-8 falla, se devuelve IDN2_ICONV_FAIL; si el dominio de salida o alguna etiqueta fuera demasiado larga, se devuelve IDN2_TOO_BIG_DOMAIN o IDN2_TOO_BIG_LABEL, o se devuelve otro código de error.
