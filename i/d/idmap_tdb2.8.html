NOMBRE

idmap_tdb2 - Backend de idmap_tdb2 de Samba para Winbind

DESCRIPCIÓN

El plugin idmap_tdb2 es un sustituto del backend idmap_tdb por defecto utilizado por winbindd para almacenar tablas de mapeo SID/uid/gid en entornos en clúster con Samba y CTDB.

En contraste con backends de solo lectura como idmap_rid, es un backend de asignación: Esto significa que necesita asignar nuevos IDs de usuario y grupo para crear nuevos mapeos.

OPCIONES IDMAP

range = bajo - alto

Define el rango de uid y gid coincidente disponible para el cual el backend es autoritativo.

script

Esta opción se puede usar para configurar un programa externo para realizar mapeos de ID en lugar de usar el contador tdb. Los mapeos se almacenan entonces en la base de datos de mapeo de id tdb2. Para más detalles, véase la sección SOBRE EL SCRIPT DE IDMAP más abajo.

SCRIPT DE IDMAP

El backend de mapeo de id tdb2 soporta un programa externo para realizar mapeos de ID a través de la opción de smb.conf idmap config * : script o su forma heredada obsoleta idmap : script.

Los mapeos obtenidos por el script se almacenan en la base de datos tdb2 de mapeo de id en lugar de los mapeos creados por los contadores de id incrementales. Por lo tanto, es importante que el script cubra el rango completo de SIDs que se pueden pasar para el mapeo de SID a ID de Unix, ya que de lo contrario los SIDs no mapeados por el script podrían ser mapeados a IDs que previamente habían sido mapeados por el script.

El script debe aceptar las siguientes opciones de línea de comandos.

SIDTOID S-1-xxxx
IDTOSID UID xxxx
IDTOSID GID xxxx

Y debe devolver una de las siguientes respuestas como una sola línea de texto.

UID:yyyy
GID:yyyy
SID:yyyy
ERR:yyyy

EJEMPLOS

Este ejemplo muestra cómo se utiliza tdb2 como backend de mapeo de id por defecto.

[global]
idmap config * : backend = tdb2
idmap config * : range = 1000000-2000000

Este ejemplo muestra cómo se utiliza tdb2 como backend de mapeo de id por defecto utilizando un programa externo a través del parámetro script:

[global]
idmap config * : backend = tdb2
idmap config * : range = 1000000-2000000
idmap config * : script = /usr/local/samba/bin/idmap_script.sh
