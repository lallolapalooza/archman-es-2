NOMBRE

idmap_script - Backend de idmap_script de Samba para Winbind

DESCRIPCIÓN

El plugin idmap_script es un sustituto del backend idmap_tdb2 utilizado por winbindd para almacenar tablas de mapeo SID/uid/gid en entornos agrupados con Samba y CTDB. Es un backend de solo lectura que utiliza un script para realizar el mapeo.

Fue desarrollado a partir del backend idmap_tdb2 y no almacena mapeos de SID/uid/gid en un TDB, ya que la caché de winbind (winbind_cache) almacenará los mapeos una vez que se proporcionen.

OPCIONES DE IDMAP

range = bajo - alto

Define el rango coincidente de uid y gid disponible para el cual el backend es autoritativo.

script

Esta opción se puede usar para configurar un programa externo para realizar mapeos de ID.

SCRIPT DE IDMAP

El backend de script idmap admite un programa externo para realizar mapeos de ID a través de la opción idmap config * : script de /etc/samba/smb.conf o su forma heredada y obsoleta idmap : script.

El script debe aceptar las siguientes opciones de línea de comandos.

SIDTOID S-1-xxxx
IDTOSID UID xxxx
IDTOSID GID xxxx
IDTOSID XID xxxx

Y debe devolver una de las siguientes respuestas como una sola línea de texto.

UID:yyyy
GID:yyyy
XID:yyyy
SID:ssss
ERR:yyyy

XID indica que el ID devuelto debe ser tanto un UID como un GID. Es decir, solicita un ID_TYPE_BOTH, pero depende en última instancia del script si puede o no cumplir esa solicitud. Puede optar por devolver solo un mapeo de UID o GID.

EJEMPLOS

Este ejemplo muestra cómo se utiliza script como el backend de idmap predeterminado utilizando un programa externo a través del parámetro script:

[global]
idmap config * : backend = script
idmap config * : range = 1000000-2000000
idmap config * : script = /usr/local/samba/bin/idmap_script.sh

Esto muestra un script simple para realizar parcialmente la tarea:

#!/bin/sh
#
# Descomenta esto si quieres algo de registro
#echo $@ >> /tmp/idmap.sh.log
if [ "$1" == "SIDTOID" ]
then
	# Nota. El número devuelto debe estar dentro del rango definido
	#echo "Enviando UID:1000005" >> /tmp/idmap.sh.log
	echo "UID:1000005"
	exit 0
else
	#echo "Enviando ERR: No tengo idea de qué hacer" >> /tmp/idmap.sh.log
	echo "ERR: No tengo idea de qué hacer"
	exit 1
fi

Está claro que este script no es suficiente, ya que probablemente debería usar wbinfo para determinar si un SID entrante es un SID de usuario o grupo y luego buscar el mapeo en una tabla o usar algún otro mecanismo para mapear SIDs a UIDs, etc.

Tenga en cuenta que el script se llama con la variable de entorno _NO_WINBINDD establecida en 1. Esto evita llamadas recursivas a winbind desde el script, tanto a través de llamadas explícitas a wbinfo como a través de llamadas implícitas a través de nss_winbind. Por ejemplo, una llamada a ls -l podría desencadenar tal recursión infinita.

Es seguro llamar a wbinfo -n y wbinfo -s desde dentro de un script de idmap. Para hacerlo, el script debe anular la variable de entorno _NO_WINBINDD justo antes de la llamada a wbinfo y volver a establecerla en 1 justo después de que wbinfo haya devuelto para protegerse contra la recursión.
