idn2_strerror_name(3)

Paquete: libidn2

Licencias: GPL2, LGPL3

idn2_strerror_name(3) libidn2 idn2_strerror_name(3)

NOMBRE

idn2_strerror_name - función de la API

SINOPSIS

#include <idn2.h>

const char * idn2_strerror_name(int rc);

ARGUMENTOS

int rc
código de retorno de otra función de libidn2.

DESCRIPCIÓN

Convierte el código de error interno de libidn2 a una cadena correspondiente a los símbolos internos del archivo de encabezado. Por ejemplo, idn2_strerror_name(IDN2_MALLOC) devolverá la cadena "IDN2_MALLOC".

El llamador no debe intentar liberar la cadena devuelta.

Valor de retorno: Una cadena correspondiente al símbolo del código de error.
