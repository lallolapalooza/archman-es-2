IDN2(1) Comandos de usuario IDN2(1)

NOMBRE

idn2 - Herramienta de conversión de nombres de dominio internacionalizados de Libidn2

SINOPSIS

idn2 [OPCIÓN]... [CADENAS]...

DESCRIPCIÓN

La herramienta idn2 convierte dominios DNS de UTF-8 a la forma de codificación compatible con ASCII (ACE), tal como se usa en el protocolo DNS. El formato de codificación es el formato de Nombres de Dominio Internacionalizados (IDNA2008/TR46).

Convierte nombres de dominio internacionalizados (IDNA2008) de CADENAS, o de la entrada estándar.

Interfaz de línea de comandos para la implementación IDNA2008 de Libidn2.

Se espera que todas las cadenas estén codificadas en el conjunto de caracteres de la configuración regional.

Para procesar una cadena que comienza con `-', por ejemplo `-foo', use `--' para señalar el final de los parámetros, como en `idn2 --quiet -- -foo'.

Los argumentos obligatorios para las opciones largas también son obligatorios para las opciones cortas.

-h, --help
Imprime la ayuda y sale
-V, --version
Imprime la versión y sale
-d, --decode
Decodifica (punycode) el nombre de dominio
-l, --lookup
Busca el nombre de dominio (predeterminado)
-r, --register
Registra la etiqueta
-T, --tr46t
Habilita el procesamiento transicional TR46
-N, --tr46nt
Habilita el procesamiento no transicional TR46
--no-tr46
Deshabilita el procesamiento TR46
--usestd3asciirules
Habilita las reglas ASCII STD3
--no-alabelroundtrip
Deshabilita el recorrido A-label para búsquedas
--debug
Imprime información de depuración
--quiet
Operación silenciosa
