NOMBRE

idna_to_ascii_lz - función de la API

SINOPSIS

#include <idna.h>

int idna_to_ascii_lz(const char * input, char ** output, int flags);

ARGUMENTOS

const char * input
cadena de entrada terminada en cero codificada en el conjunto de caracteres del locale actual.
char ** output
puntero a una cadena de salida recién asignada.
int flags
un valor de Idna_flags, por ejemplo, IDNA_ALLOW_UNASSIGNED o IDNA_USE_STD3_ASCII_RULES.

DESCRIPCIÓN

Convierte un nombre de dominio en la codificación del locale a una cadena ASCII. El nombre de dominio puede contener varias etiquetas, separadas por puntos. El llamador debe liberar el búfer de salida.

Valor de retorno: Devuelve IDNA_SUCCESS en caso de éxito, o un código de error.
