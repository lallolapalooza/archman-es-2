IDMAP_HASH(8) Herramientas de administración del sistema IDMAP_HASH(8)

NOMBRE

idmap_hash - NO USE ESTE BACKEND

DESCRIPCIÓN

NO USE ESTE PLUGIN El plugin idmap_hash implementa un algoritmo de hash utilizado para mapear SIDs de usuarios y grupos de dominio a uids y gids de 31 bits, respectivamente. Este plugin también implementa la API nss_info y puede ser utilizado para soportar archivos locales de mapeo de nombres si se habilita a través de los parámetros "winbind normalize names" y "winbind nss info" en /etc/samba/smb.conf. El módulo divide el rango en subrangos para cada dominio que está siendo manejado por la configuración de idmap. El módulo necesita el rango completo de UID y GID para poder mapear todos los SIDs. El valor más bajo para el rango debe ser el ID más pequeño disponible en el sistema. Normalmente es 1000. El ID más alto debe establecerse en 2147483647. Un rango más pequeño provocará problemas debido al algoritmo de hash utilizado. El rango general para mapear todos los SIDs es 0 - 2147483647. Cualquier rango menor que 0 - 2147483647 filtrará algunos SIDs. Como normalmente solo podemos empezar con 1000, no podemos mapear 1000 SIDs. Esto ya puede provocar problemas. Cuanto menor sea el rango, menos SIDs se podrán mapear. No recomendamos el uso de este plugin. Se eliminará en una futura versión de Samba.

OPCIONES IDMAP

name_map

Especifica la ruta absoluta al archivo de mapeo de nombres utilizado por la API nss_info. Las entradas en el archivo tienen el formato "nombre_unix = nombre_dominio_calificado". Se soporta el mapeo de nombres de usuario y grupo.

EJEMPLOS

El siguiente ejemplo utiliza el plugin idmap_hash para la información de idmap y nss_info.

[global]
idmap config * : backend = hash
idmap config * : range = 1000-2147483647
winbind nss info = hash
winbind normalize names = yes
idmap_hash:name_map = /etc/samba/name_map.cfg
