idn2_to_ascii_lz(3) libidn2 idn2_to_ascii_lz(3)

NOMBRE

idn2_to_ascii_lz - Función de la API

SINOPSIS

#include <idn2.h>

int idn2_to_ascii_lz(const char * input, char ** output, int flags);

ARGUMENTOS

const char * input
cadena de entrada UTF-8 terminada en nulo.
char ** output
puntero a la cadena de salida recién asignada.
int flags
opcional idn2_flags para modificar el comportamiento.

DESCRIPCIÓN

Convierte un nombre de dominio en la codificación local a una cadena ASCII utilizando las reglas de IDNA2008. El nombre de dominio puede contener varias etiquetas, separadas por puntos. El llamador debe liberar el búfer de salida.

El comportamiento predeterminado de esta función (cuando los flags son cero) es aplicar las reglas de IDNA2008 sin las enmiendas TR46. Dado que el procesamiento no transicional de TR46 es hoy en día ubicuo, cuando no esté seguro, se recomienda llamar a esta función con los flags IDN2_NONTRANSITIONAL y IDN2_NFC_INPUT para compatibilidad con otro software.

RETORNA

IDN2_OK en caso de éxito, o código de error. Igual que se describe en la documentación de idn2_lookup_ul().
