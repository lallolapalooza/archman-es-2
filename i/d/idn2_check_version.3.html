idn2_check_version(3)

Paquete: libidn2

Licencias: GPL2, LGPL3

idn2_check_version(3) libidn2 idn2_check_version(3)

NOMBRE

idn2_check_version - función de la API

SINOPSIS

#include <idn2.h>

const char * idn2_check_version(const char * req_version);

ARGUMENTOS

const char * req_version
cadena de versión a comparar, o NULL.

DESCRIPCIÓN

Verifica la versión de la biblioteca IDN2. Esta función también se puede utilizar para leer la versión del código de la biblioteca utilizada. Consulte IDN2_VERSION para una cadena req_version adecuada, corresponde a la versión del archivo de cabecera idn2.h. Normalmente, estos dos números de versión coinciden, pero si está utilizando una aplicación compilada contra una versión anterior de libidn2 con una biblioteca compartida más reciente de libidn2, serán diferentes.

Valor de retorno: Comprueba que la versión de la biblioteca sea como mínimo la dada como cadena en req_version y devuelve la cadena de versión real de la biblioteca; devuelve NULL si la condición no se cumple. Si se pasa NULL a esta función, no se realiza ninguna comprobación y solo se devuelve la cadena de versión.
