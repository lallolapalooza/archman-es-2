NOMBRE

idn2_to_unicode_lzlz - Función de la API

SINOPSIS

#include <idn2.h>

int idn2_to_unicode_lzlz(const char * input, char ** output, int flags);

ARGUMENTOS

const char * input
Cadena de entrada terminada en nulo codificada en el conjunto de caracteres del entorno local actual.
char ** output
Cadena de salida recién asignada en el conjunto de caracteres del entorno local actual.
int flags
Actualmente no utilizado.

DESCRIPCIÓN

Convierte un nombre de dominio posiblemente codificado en ACE en el conjunto de caracteres del entorno local a una cadena codificada en el conjunto de caracteres del entorno local actual (decodificación punycode). El búfer de salida estará terminado en nulo y debe ser liberado por el llamador.


output puede ser NULL para probar la búsqueda de input sin asignar memoria.
