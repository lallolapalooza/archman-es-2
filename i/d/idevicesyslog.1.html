Solicita un logarchive del dispositivo. Se escribirá en formato tar en PATH. Para redirigir la salida a otro proceso, use - como PATH. A continuación se muestran algunas opciones para restringir los datos de los mensajes de registro.

Para ver el logarchive en un visor de registros compatible, puede redirigir los datos de salida a tar y hacer que los extraiga en un nuevo

directorio:

mkdir test.logarchive && tools/idevicesyslog archive - |tar -C test.logarchive

VALUE
Hora de inicio de los datos de registro como marca de tiempo UNIX. Los mensajes anteriores se
descartarán.
--age-limit
VALUE
Edad máxima de los datos de registro, supuestamente en número de
días.
--size-limit
VALUE
Limita el tamaño del archivo. La unidad es desconocida actualmente, así que siéntase libre de
experimentar.
Tenga en cuenta que el dispositivo generalmente solo tiene un búfer de unos minutos, por lo que las opciones podrían no tener el efecto deseado. Esto no es un
error.

Cuando se especifica, el registro comenzará tan pronto como se encuentre un mensaje de registro que contenga la cadena dada. Vea también -T, --untrigger. Los otros filtros todavía se aplican, pero los mensajes

STRING
detener el registro al coincidir con STRING

Cuando se especifica, el registro se detendrá tan pronto como se encuentre un mensaje de registro que contenga la cadena dada. Vea también -t, --trigger. Los otros filtros todavía se aplican, pero los mensajes filtrados obviamente solo se imprimen antes de que el registro se

detenga.
