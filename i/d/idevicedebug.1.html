NOMBRE

idevicedebug - Interactúa con el servicio debugserver de un dispositivo.

SINOPSIS

idevicedebug [OPCIONES] COMANDO

DESCRIPCIÓN

Interactúa con el servicio de depuración de un dispositivo. Actualmente, el único comando implementado es "run", que permite la ejecución de aplicaciones para desarrolladores y la supervisión de la salida estándar (stdout) y el error estándar (stderr) del proceso.

OPCIONES

-u, --udid UDID
selecciona un dispositivo específico por su UDID.
-n, --network
conéctate a un dispositivo de red.
-e, --env NOMBRE=VALOR
establece la variable de entorno NOMBRE con el VALOR.
-d, --debug
habilita la depuración de la comunicación.
-h, --help
muestra información de uso.
-v, --version
muestra información de la versión.

COMANDOS

run IDENTIFICADOR_BUNDLE [ARGUMENTOS...]
ejecuta la aplicación con IDENTIFICADOR_BUNDLE y argumentos opcionales [ARGUMENTOS...] en el dispositivo.
