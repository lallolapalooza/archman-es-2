id_t(3type) id_t(3type)

NOMBRE

pid_t, uid_t, gid_t, id_t — identificador de proceso/usuario/grupo

BIBLIOTECA

Biblioteca C estándar (libc)

SINOPSIS

#include <sys/types.h>
typedef /* ... */ pid_t;
typedef /* ... */ uid_t;
typedef /* ... */ gid_t;
typedef /* ... */ id_t;

DESCRIPCIÓN

pid_t es un tipo utilizado para almacenar IDs de proceso, IDs de grupo de procesos y IDs de sesión. Es un tipo de entero con signo.

uid_t es un tipo utilizado para almacenar IDs de usuario. Es un tipo entero.

gid_t es un tipo utilizado para almacenar IDs de grupo. Es un tipo entero.

id_t es un tipo utilizado para almacenar un identificador general. Es un tipo entero que puede utilizarse para contener un pid_t, uid_t o gid_t.

ESTÁNDARES

POSIX.1-2024.

HISTORIA

POSIX.1-2001.

NOTAS

Las siguientes cabeceras también proporcionan pid_t: <fcntl.h>, <sched.h>, <signal.h>, <spawn.h>, <sys/msg.h>, <sys/sem.h>, <sys/shm.h>, <sys/wait.h>, <termios.h>, <time.h>, <unistd.h>, y <utmpx.h>.

Las siguientes cabeceras también proporcionan uid_t: <pwd.h>, <signal.h>, <stropts.h>, <sys/ipc.h>, <sys/stat.h>, y <unistd.h>.

Las siguientes cabeceras también proporcionan gid_t: <grp.h>, <pwd.h>, <signal.h>, <stropts.h>, <sys/ipc.h>, <sys/stat.h>, y <unistd.h>.

La siguiente cabecera también proporciona id_t: <sys/resource.h>.
