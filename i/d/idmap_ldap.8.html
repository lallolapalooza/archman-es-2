NOMBRE

idmap_ldap - Backend de idmap_ldap de Samba para Winbind

DESCRIPCIÓN

El plugin idmap_ldap proporciona un medio para que Winbind almacene y recupere tablas de mapeo SID/uid/gid en un servicio de directorio LDAP. En contraste con backends de solo lectura como idmap_rid, es un backend de asignación: esto significa que necesita asignar nuevos IDs de usuario y grupo para crear nuevos mapeos.

OPCIONES DE IDMAP

ldap_base_dn = DN

Define el sufijo base del directorio a usar para las entradas de mapeo SID/uid/gid. Si no se define, idmap_ldap usará por defecto la opción "ldap idmap suffix" de /etc/samba/smb.conf.

ldap_user_dn = DN

Define el DN de usuario a usar para la autenticación. El secreto para autenticar a este usuario debe almacenarse con net idmap secret (ver net(8)). Si está ausente, se usarán las credenciales ldap de la configuración de ldap passdb, y si estas también están ausentes, se realizará una conexión anónima como último recurso.

ldap_url = ldap://servidor/

Especifica el servidor LDAP a usar para las entradas de mapa SID/uid/gid. Si no se define, idmap_ldap asumirá que se usará ldap://localhost/.

range = bajo - alto

Define el rango de uid y gid coincidente disponible para el cual el backend es autoritativo.

EJEMPLOS

El siguiente ejemplo muestra cómo se utiliza un directorio ldap como backend de idmap por defecto. También configura el rango de idmap y el sufijo del directorio base. El secreto para ldap_user_dn debe establecerse con "net idmap secret '*' contraseña".

[global]
idmap config * : backend      = ldap
idmap config * : range        = 1000000-1999999
idmap config * : ldap_url     = ldap://localhost/
idmap config * : ldap_base_dn = ou=idmap,dc=example,dc=com
idmap config * : ldap_user_dn = cn=idmap_admin,dc=example,dc=com

Este ejemplo muestra cómo ldap puede usarse como un backend de solo lectura, mientras que tdb es el backend por defecto utilizado para almacenar los mapeos. Añade una configuración explícita para un dominio DOM1, que usa el backend de idmap ldap. Tenga en cuenta que se utiliza un rango disjunto del rango por defecto.

[global]
# "backend = tdb" es redundante aquí ya que es el predeterminado
idmap config * : backend = tdb
idmap config * : range = 1000000-1999999
idmap config DOM1 : backend = ldap
idmap config DOM1 : range = 2000000-2999999
idmap config DOM1 : read only = yes
idmap config DOM1 : ldap_url = ldap://servidor/
idmap config DOM1 : ldap_base_dn = ou=idmap,dc=dom1,dc=example,dc=com
idmap config DOM1 : ldap_user_dn = cn=idmap_admin,dc=dom1,dc=example,dc=com

NOTA

Para poder usar la autenticación contra servidores ldap, puede que necesite proporcionar un DN y una contraseña. Para evitar exponer la contraseña en texto plano en el archivo de configuración, la almacenamos en una tienda de seguridad. El comando "net idmap " se utiliza para almacenar un secreto para el DN especificado en un dominio de idmap específico.
