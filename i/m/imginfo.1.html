NOMBRE

imginfo - Utilidad de información de imagen

SINOPSIS

imginfo [opciones]

DESCRIPCIÓN

El comando imginfo muestra información sobre una imagen. Por favor, utilice el modificador de línea de comandos --help y el Manual de Referencia del Software JasPer para más información.

MANUAL EN LÍNEA

Para obtener información detallada sobre el software JasPer, consulte el Manual de JasPer en línea, disponible en: https://jasper-software.github.io/jasper-manual

SITIO WEB DEL SOFTWARE JASPER

Para obtener información adicional sobre el software JasPer, consulte el sitio web del software JasPer en: https://jasper-software.github.io/jasper

VER TAMBIÉN

jasper(1), imgcmp(1), jiv(1).
