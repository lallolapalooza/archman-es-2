NOMBRE

imv - archivo de configuración de imv

DESCRIPCIÓN

imv puede personalizarse con este archivo de configuración, cambiando su comportamiento predeterminado, combinaciones de teclas y apariencia.

El archivo de configuración de imv es un archivo estilo ini, con múltiples configuraciones de clave = valor, separadas en varias '[secciones]'.

OPCIONES

La sección [options] acepta las siguientes configuraciones:

background = <código-hex|checks>

Establece el fondo en imv. Puede ser un código de color hexadecimal de 6 dígitos o checks para un fondo a cuadros. Predeterminado: 000000

fullscreen = <true|false>

Inicia imv en pantalla completa. Predeterminado: false.

width = <ancho>

Ancho inicial de la ventana de imv. Predeterminado: 1280.

height = <altura>

Altura inicial de la ventana de imv. Predeterminado: 720.

initial_pan = <factor_pan_x> <factor_pan_y>

Factor de posición inicial de paneo/enfoque de las imágenes abiertas. Un valor de 50 representa el punto medio de la imagen (50%). Predeterminado: 50 50

list_files_at_exit = <true|false>

Imprime los archivos abiertos en stdout al salir, cada uno en una línea separada. Predeterminado: false.

loop_input = <true|false>

Vuelve a la primera imagen después de ver la última. Predeterminado: true.

overlay = <true|false>

Inicia con la superposición visible. Predeterminado: false.

overlay_font = <tipografía:tamaño>

Utiliza la fuente especificada en la superposición. Predeterminado: Monospace:24.

overlay_text = <texto>

Utiliza el texto proporcionado como texto de la superposición. El texto proporcionado se expande con el shell, por lo que se puede usar la salida de comandos (por ejemplo, $(ls)). Las variables de entorno también se pueden usar, incluidas las que son accesibles para el comando exec de imv.

overlay_text_color = <código-hex>

Establece el color del texto en la superposición. Es un código de color hexadecimal de 6 dígitos. Predeterminado: ffffff.

overlay_text_alpha = <código-hex>

Establece el alfa del texto en la superposición. Es un código de color hexadecimal de 2 dígitos. Predeterminado: ff.

overlay_background_color = <código-hex>

Establece el color del fondo de la superposición. Es un código de color hexadecimal de 6 dígitos. Predeterminado: 000000.

overlay_background_alpha = <código-hex>

Establece el alfa del fondo de la superposición. Es un código de color hexadecimal de 2 dígitos. Predeterminado: c3.

overlay_position_bottom = <true|false>

Muestra la superposición en la parte inferior de la ventana de imv, en lugar de la superior.

recursively = <true|false>

Carga las rutas de entrada recursivamente. Predeterminado: false.

scaling_mode = <none|shrink|full|crop>

Establece el modo de escalado a utilizar. none mostrará cada imagen en su tamaño real. shrink escalará la imagen hacia abajo para que quepa dentro de la ventana. full escalará tanto hacia arriba como hacia abajo la imagen para que quepa perfectamente dentro de la ventana. crop escalará y recortará la imagen para llenar la ventana. Predeterminado: full.

slideshow_duration = <duración>

Inicia imv en modo de presentación de diapositivas y establece el tiempo para mostrar cada imagen en segundos. Predeterminado: 0, es decir, sin presentación de diapositivas.

suppress_default_binds = <true|false>

Deshabilita las combinaciones de teclas integradas de imv para que no entren en conflicto con las personalizadas. Predeterminado: false.

title_text = <texto>

Utiliza el texto proporcionado como título de la ventana. El texto proporcionado se expande con el shell, por lo que se puede usar la salida de comandos: $(ls), así como variables de entorno, incluidas las accesibles para el comando exec de imv.

upscaling_method = <linear|nearest_neighbour>

Utiliza el método especificado para escalar imágenes hacia arriba. Predeterminado: linear.

ÁLIAS

La sección [aliases] permite añadir alias para los comandos integrados de imv. Por ejemplo, x = close añadiría un comando x que simplemente ejecuta el comando close. Cualquier argumento proporcionado a un alias se añade al comando configurado por el alias.

COMBINACIONES DE TECLAS

La sección [binds] permite añadir combinaciones de teclas personalizadas a imv.

Las combinaciones de teclas tienen el formato combinación de teclas = comando. Una combinación de teclas puede consistir en varias teclas en sucesión. Se pueden definir varios comandos para una única combinación de teclas separando cada comando con un ;. Se respetan las comillas simples y dobles, así como el escape con una barra invertida, para permitir el correcto entrecomillado de los comandos del shell.

Teclas individuales como q son solo eso: q = quit enlaza la tecla q con el comando quit.

Las teclas modificadoras se pueden especificar prefijándolas: Ctrl+q, Meta+f, Shift+G. Si se desean varias teclas modificadoras, se especifican en el orden Ctrl+Meta+Shift. Cuando el nombre de una tecla es más de un carácter, o se usa un modificador, debe encerrarse entre < y >, por ejemplo: <Ctrl+q>.

Se pueden especificar varias teclas en sucesión listándolas en orden: gg = goto 1 enlazará dos pulsaciones de la tecla g para saltar a la primera imagen, y <Ctrl+a>p = exec echo hi enlazará la secuencia de teclas Ctrl+a seguida de p para ejecutar el comando del shell echo hi.

Muchas teclas, como < y >, tienen nombres especiales. En X11, estas se pueden encontrar fácilmente con el comando xev(1). Por ejemplo, ! se llama exclam, < se llama less, > se llama greater.

Una lista completa de keysyms también se puede encontrar en la mayoría de los sistemas con el comando dumpkeys -l.
