NOMBRE

imvirt - detecta varias virtualizaciones

SINOPSIS

imvirt

DESCRIPCIÓN

Esta página del manual documenta brevemente el script imvirt. imvirt intenta detectar si se ejecuta en una máquina física o en una virtualizada. Si detecta que es virtualizada, también intenta averiguar qué tecnología de virtualización se utiliza.

USO

imvirt no necesita argumentos. Pero actualmente existe una restricción si no llamas a este script con el usuario administrativo root, ya que imvirt también utiliza dmidecode para determinar la tecnología de virtualización utilizada. dmidecode en sí mismo necesita privilegios de root para acceder a /dev/mem. Por lo tanto, debes envolver imvirt con sudo si deseas detectar todas las tecnologías de virtualización.

VER TAMBIÉN

dmidecode(8)
