NOMBRE

img_cat - Muestra el contenido de un archivo de imagen.

SINOPSIS

img_cat [-i imgtype] [-b tamaño_sector_dev] [-s sector_inicio] [-e sector_fin] [-vV] imagen [imágenes]

DESCRIPCIÓN

img_cat muestra el contenido de un archivo de imagen. Los archivos de imagen que no son crudos (raw) tendrán datos incrustados y metadatos. img_cat solo mostrará los datos. Esto le permite convertir un formato incrustado a crudo o calcular el hash MD5 de los datos canalizando la salida a la herramienta adecuada.

ARGUMENTOS

-i imgtype
Identifica el tipo de archivo de imagen, como raw o aff. Use '-i list' para listar los tipos soportados. Si no se proporciona, se utilizan métodos de autodetección.
-b tamaño_sector_dev
El tamaño, en bytes, de los sectores del dispositivo subyacente. Si no se proporciona, se utiliza el valor en el formato de imagen (si existe) o se asumen 512 bytes.
-s sector_inicio
El número de sector desde el que empezar.
-e sector_fin
El número de sector hasta el que parar.
-v
Salida detallada de sentencias de depuración a stderr
-V
Muestra la versión
imagen [imágenes]
La imagen de disco o partición a leer, cuyo formato se especifica con '-i'. Se pueden dar varios nombres de archivo de imagen si la imagen está dividida en varios segmentos. Si solo se da un archivo de imagen y su nombre es el primero de una secuencia (por ejemplo, indicado por terminar en '.001'), los segmentos de imagen subsiguientes se incluirán automáticamente.
