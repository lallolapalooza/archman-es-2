IMGSIZE(1) Documentación de Perl aportada por el usuario IMGSIZE(1)

NOMBRE

imgsize - lee las dimensiones de una imagen en varios formatos populares

USO

imgsize [ -r | -a | -f fmt ] archivo [ archivo ... ]

DESCRIPCIÓN

Una tarea sencilla para obtener el tamaño de una imagen proporcionada en la línea de comandos. Todo el trabajo real lo realiza Image::Size.

ARGUMENTOS REQUERIDOS

imgsize espera nombres de archivo en la línea de comandos. Si se proporcionan varios archivos, el nombre del archivo se incluirá en la salida:

% imgsize dot.gif
width="16" height="16"
% imgsize dot.gif dash.gif
dot.gif: width="16" height="16"
dash.gif: width="32" height="8"

OPCIONES

Por defecto, el ancho y el alto se devuelven como atributos para una etiqueta IMG en HTML, esencialmente "width="40" height="30"" o similar. Las siguientes opciones se pueden utilizar para devolver formatos alternativos (todos informan primero el ancho y luego el alto):

"-r"
Devuelve datos en formato "raw" (crudo). Solo los números separados por un solo espacio.
"-a"
Devuelve una lista de atributos estilo Perl adecuada para pasar al método img() del módulo CGI (ver CGI).
"-f" fmt
Pasa la cadena especificada en fmt a "sprintf" y por lo tanto la utiliza para formatear los resultados a su gusto. A "sprintf" se le pasarán dos números, por lo que cualquier otra directiva de formato se perderá. Los números se pasan primero como ancho y luego como alto.
