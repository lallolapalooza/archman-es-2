NOMBRE

imgcmp - Utilidad de comparación de imágenes

SINOPSIS

imgcmp [opciones]

DESCRIPCIÓN

El comando imgcmp compara dos imágenes de la misma geometría con respecto a una métrica dada. Por favor, use el interruptor de línea de comandos --help y el Manual de Referencia del Software JasPer para más información.

MANUAL EN LÍNEA

Para obtener información detallada sobre el software JasPer, consulte el Manual en Línea de JasPer, que está disponible en: https://jasper-software.github.io/jasper-manual

SITIO WEB DEL SOFTWARE JASPER

Para obtener información adicional sobre el software JasPer, consulte el sitio web del software JasPer en: https://jasper-software.github.io/jasper
