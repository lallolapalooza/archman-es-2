FBB::ImmapStream(3bobcat) std::istream usando FBB::MmapBuf como streambuf FBB::ImmapStream(3bobcat)

NOMBRE

FBB::ImmapStream - Stream de entrada usando mmap(2) a través de FBB::MmapBuf

SINOPSIS

#include <bobcat/immapstream>

Opción de enlace: -lbobcat

DESCRIPCIÓN

Los objetos FBB::ImmapStream se utilizan para extraer información de archivos que se ponen a disposición en el espacio de direcciones virtual del proceso que llama. El uso del espacio de direcciones virtual se maneja mediante la clase FBB::MmapBuf (clase std::streambuf) heredada privadamente por la clase.

Al mapear archivos en el espacio de direcciones virtual del proceso, el tiempo requerido para procesar dichos archivos generalmente se reduce drásticamente.

Se lanza una std::exception y se escribe un mensaje de error en cerr si la clase base FBB::MmapBuf no puede determinar el tamaño del archivo especificado, o cuando el (des)mapeo no se puede realizar.

NAMESPACE

FBB
Todos los constructores, miembros, operadores y manipuladores mencionados en esta página del manual están definidos en el espacio de nombres FBB.

HEREDA DE

std::istream, privadamente de FBB::MmapBuf.

CONSTRUCTORES

o
ImmapStream():
El constructor predeterminado simplemente construye un objeto ImmapStream vacío. Para convertirlo en un objeto utilizable, use la asignación de movimiento;
o
IOmmapStream(std::string const &fname, char const *bufSize = 0):
El constructor inicializa el objeto ImmapStream para un archivo llamado fname.

Por defecto, bfImmapStream) utiliza un tamaño de búfer de mapeo de 10 veces el tamaño de página estándar (cf. sysconf(3) y el miembro pageSize a continuación). El tamaño del búfer de mapeo también se puede especificar usando el parámetro bufSize. Para especificarlo, use un valor seguido de K, M, o G, que representan respectivamente 1024, 1024 * 1024 y 1024 * 1024 * 1024 bytes. El tamaño final del búfer es al menos igual al tamaño de página estándar. Cuando se especifica un valor mayor, el tamaño del búfer utilizado se establece en especificado / pageSize * pageSize.)

El constructor de movimiento y el operador de asignación de movimiento están disponibles.
El constructor de copia y el operador de asignación de copia no están disponibles.

FUNCIONES MIEMBRO

Todos los miembros de std::istream están disponibles, ya que FBB::ImmapStream hereda de esa clase.

o
size_t bufSize() const:
devuelve el tamaño del búfer t(mmap) utilizado;
o
size_t fileSize() const:
devuelve el tamaño del archivo especificado.
o
size_t pageSize() const:
devuelve el tamaño de página más pequeño utilizado por t(mmap).
