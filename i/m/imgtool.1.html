IMGTOOL(1) Herramienta de manipulación de imágenes de medios MESS IMGTOOL(1)

NOMBRE

imgtool - Herramienta de manipulación de imágenes de medios MESS

SINOPSIS

imgtool create formato imagen [opción ...]
imgtool dir formato imagen [ruta]
imgtool get formato imagen archivo [nuevo_nombre] [--filter=filtro] [--fork=fork]
imgtool put formato imagen archivo ... [nuevo_nombre] [opción ...] [--filter=filtro] [--fork=fork]
imgtool getall formato imagen [ruta] [--filter=filtro]
imgtool del formato imagen archivo ...
imgtool mkdir formato imagen directorio
imgtool rmdir formato imagen directorio ...
imgtool readsector|writesector formato imagen pista cabeza sector archivo
imgtool identify imagen
imgtool listformats|listfilters
imgtool listdriveroptions formato

DESCRIPCIÓN

imgtool es una herramienta para el mantenimiento y la manipulación de imágenes de disco y otros tipos de imágenes con las que los usuarios de MESS necesitan trabajar. Las funciones incluyen la recuperación y el almacenamiento de archivos, así como la verificación y validación de CRC. Los archivos de imagen también pueden estar dentro de archivos .zip.

OPCIONES

create
Crea una imagen. Se pueden especificar parámetros opcionales específicos de la imagen; consulte el comando imgtool listdriveroptions para obtener una lista completa.
dir
Lista el contenido de una imagen.
get
Obtiene un solo archivo de una imagen. Se puede especificar un filtro para convertir formatos de archivo personalizados a ASCII; consulte el comando imgtool listfilters para obtener una lista completa. El archivo se puede renombrar opcionalmente.
put
Coloca archivo(s) en una imagen (se admiten comodines y renombramiento). Se proporcionan filtros para convertir archivos ASCII a formatos de archivo personalizados; consulte el comando imgtool listfilters para obtener una lista completa.
getall
Obtiene todos los archivos de una imagen. Se pueden especificar filtros para convertir formatos de archivo personalizados a ASCII; consulte el comando imgtool listfilters para obtener una lista completa.
del
Elimina un archivo en una imagen.
mkdir
Crea un directorio en una imagen.
rmdir
Elimina directorios en una imagen.
readsector
Extrae el contenido de un sector único de una imagen a un archivo.
writesector
Escribe el contenido de un archivo en un sector específico de una imagen.
identify
Intenta reconocer el formato de un archivo de imagen.
listformats
Lista todos los formatos de archivo de imagen compatibles con imgtool.
listfilters
Lista todos los filtros compatibles con imgtool. Los filtros son un medio para procesar datos que se escriben o se leen de una imagen de cierta manera.
listdriveroptions
Lista todas las opciones específicas del formato para los comandos imgtool put y imgtool create.

EJEMPLOS

imgtool dir coco_jvc_rsdos myimageinazip.zip

imgtool get coco_jvc_rsdos myimage.dsk myfile.bin mynewfile.txt

imgtool getall coco_jvc_rsdos myimage.dsk
