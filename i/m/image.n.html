image(n) Comandos incorporados de Tk image(n)

NOMBRE

image - Crear y manipular imágenes

SINOPSIS

image opción ?arg arg ...?

DESCRIPCIÓN

El comando image se utiliza para crear, eliminar y consultar imágenes. Puede tener varias formas diferentes, dependiendo del argumento opción. Las formas legales son:

image create tipo ?nombre? ?opción valor ...?
Crea una nueva imagen y un comando con el mismo nombre y devuelve su nombre. tipo especifica el tipo de imagen, que debe ser uno de los tipos actualmente definidos (por ejemplo, bitmap). nombre especifica el nombre de la imagen; si se omite, Tk elige un nombre de la forma imagex, donde x es un entero. Puede haber cualquier número de pares opción-valor, que proporcionan opciones de configuración para la nueva imagen. El conjunto legal de opciones se define por separado para cada tipo de imagen; véase más abajo los detalles de las opciones para los tipos de imagen incorporados. Si ya existe una imagen con el nombre dado, se reemplaza por la nueva imagen y cualquier instancia de esa imagen se redibujará con el nuevo contenido. Es importante tener en cuenta que el comando image sobrescribirá silenciosamente cualquier procedimiento que pueda estar definido actualmente con el nombre dado, así que elija el nombre sabiamente. Se recomienda usar un espacio de nombres separado para los nombres de imagen (por ejemplo, ::img::logo, ::img::large).
image delete ?nombre nombre ...?
Elimina cada una de las imágenes nombradas y devuelve una cadena vacía. Si hay instancias de las imágenes mostradas en widgets, las imágenes no se eliminarán realmente hasta que se liberen todas las instancias. Sin embargo, se eliminará la asociación entre las instancias y el gestor de imágenes. Las instancias existentes conservarán sus tamaños, pero se redibujarán como áreas vacías. Si una imagen eliminada se recrea con otra llamada a image create, las instancias existentes usarán la nueva imagen.
image height nombre
Devuelve una cadena decimal que indica la altura de la imagen nombre en píxeles.
image inuse nombre
Devuelve un valor booleano que indica si la imagen dada por nombre está o no en uso por algún widget.
image names
Devuelve una lista que contiene los nombres de todas las imágenes existentes.
image type nombre
Devuelve el tipo de imagen nombre (el valor del argumento tipo a image create cuando se creó la imagen).
image types
Devuelve una lista cuyos elementos son todos los tipos de imagen válidos (es decir, todos los valores que se pueden suministrar para el argumento tipo a image create).
image width nombre
Devuelve una cadena decimal que indica el ancho de la imagen nombre en píxeles.

Es posible que estén disponibles operaciones adicionales (por ejemplo, escribir la imagen en un archivo) como subcomandos del comando de instancia de imagen. Consulte la página del manual del tipo de imagen particular para obtener detalles.

TIPOS DE IMAGEN INCORPORADOS

Los siguientes tipos de imagen están definidos por Tk, por lo que estarán disponibles en cualquier aplicación Tk. Las aplicaciones o extensiones individuales pueden definir tipos adicionales.

bitmap
Cada píxel de la imagen muestra un color de primer plano, un color de fondo, o nada. Consulte la entrada del manual bitmap para obtener más información.
photo
Muestra una variedad de imágenes a todo color, utilizando tramado para aproximar los colores en pantallas con capacidades de color limitadas. Consulte la entrada del manual photo para obtener más información.

VER TAMBIÉN
