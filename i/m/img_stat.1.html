NOMBRE

img_stat - Muestra detalles de un archivo de imagen

SINOPSIS

img_stat [-i imgtype] [-b tamaño_sector_disp] [-tvV] imagen [imágenes]

DESCRIPCIÓN

img_stat muestra los detalles asociados con un archivo de imagen. La salida de este comando es específica del formato de imagen. Como mínimo, se proporcionará el tamaño y el rango de bytes de cada archivo para los formatos de imagen divididos.

ARGUMENTOS

-i imgtype
Identifica el tipo de archivo de imagen, como raw. Usa '-i list' para listar los tipos soportados. Si no se proporciona, se utilizan métodos de autodetectarción.
-b tamaño_sector_disp
El tamaño, en bytes, de los sectores del dispositivo subyacente. Si no se proporciona, se utiliza el valor en el formato de imagen (si existe) o se asume 512 bytes.
-t
Muestra solo el tipo de imagen.
-v
Salida detallada de declaraciones de depuración a stderr
-V
Muestra la versión
imagen [imágenes]
La imagen de disco o partición a leer, cuyo formato se proporciona con '-i'. Se pueden proporcionar varios nombres de archivo de imagen si la imagen está dividida en varios segmentos. Si solo se proporciona un archivo de imagen, y su nombre es el primero de una secuencia (por ejemplo, si termina en '.001'), los segmentos de imagen subsiguientes se incluirán automáticamente.
