NOMBRE

io_uring_submit_and_wait_reg - Configura y registra regiones de espera fijas

SINOPSIS

#include <liburing.h>
int io_uring_submit_and_wait_reg(struct io_uring *ring,
                                 struct io_uring_cqe **cqe_ptr,
                                 unsigned wait_nr,
                                 int reg_index);

DESCRIPCIÓN

La función io_uring_submit_and_wait_reg(3) envía las peticiones previamente preparadas en el anillo ring y espera wait_nr completaciones usando el índice de espera registrado de reg_index. Tras un retorno exitoso, los eventos de completación se almacenan en el array cqe_ptr.

Esta función funciona de manera similar a io_uring_submit_and_wait_min_timeout(3), ya que admite todas las características de esa función auxiliar, pero en lugar de pasar toda la información en una estructura que necesita ser copiada, hace referencia a un índice de espera registrado para el cual la región de espera registrada previamente contiene información sobre cómo se debe realizar la espera. Esto incluye información como el tiempo de espera general, el tiempo de espera mínimo a utilizar, etc. Consulte io_uring_setup_reg_wait(3) para obtener detalles sobre las regiones de espera registradas.

El uso de regiones de espera registradas tiene menos sobrecarga que otros métodos de espera, ya que no es necesario copiar datos.

Es válido usar esta función puramente para esperar eventos, incluso si no se deben enviar nuevas peticiones.

VALOR DE RETORNO

En caso de éxito, io_uring_submit_and_wait_reg(3) devuelve el número de nuevas peticiones enviadas. En caso de fallo, devuelve -errno. Si el kernel no admite esta funcionalidad, se devolverá -EINVAL. Si no se envían eventos y la operación de espera expira, se devolverá -ETIME.
