NOMBRE

io_uring_buf_ring_init - Inicializa un anillo de búferes

SINOPSIS

#include <liburing.h>
void io_uring_buf_ring_init(struct io_uring_buf_ring *br);

DESCRIPCIÓN

io_uring_buf_ring_init(3) inicializa br para que esté listo para ser utilizado. Puede llamarse después de io_uring_register_buf_ring(3) pero debe llamarse antes de que el anillo de búferes se utilice de cualquier otra manera.

VALOR DE RETORNO

Ninguno

NOTAS

A menos que se necesite una configuración manual, se recomienda usar io_uring_setup_buf_ring(3) ya que proporciona una forma más sencilla de configurar un anillo de búferes proporcionado.

VER TAMBIÉN
