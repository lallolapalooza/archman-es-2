NOMBRE

io_uring_register_file_alloc_range - establece el rango para asignaciones de archivos fijos

SINOPSIS

#include <liburing.h>
int io_uring_register_file_alloc_range(struct io_uring *ring,
                                       unsigned off,
                                       unsigned len);

DESCRIPCIÓN

La función io_uring_register_file_alloc_range(3) establece el rango permitido para las asignaciones de índices de archivos fijos dentro del núcleo. Cuando se utilizan solicitudes que pueden instanciar un nuevo archivo fijo con IORING_FILE_INDEX_ALLOC , la aplicación está pidiendo al núcleo que asigne un nuevo descriptor de archivo fijo en lugar de pasar un valor específico para uno. Por defecto, el núcleo elegirá cualquier descriptor de archivo fijo disponible dentro del rango disponible. Al llamar a esta función con off establecido en el desplazamiento inicial y len establecido en el número de descriptores, la aplicación puede limitar los descriptores asignados a ese rango particular. Esto permite efectivamente a la aplicación reservar un rango solo para asignaciones dinámicas, y el resto se utilizará para valores específicos.

La aplicación debe haber registrado una tabla de archivos fijos con anticipación, por ejemplo, a través de io_uring_register_files(3) o io_uring_register_files_sparse(3).

Disponible desde la versión 6.0.

VALOR DE RETORNO

En caso de éxito, io_uring_register_file_alloc_range(3) devuelve 0. En caso de error, devuelve -errno.
