NOMBRE

io_uring_register_sync_cancel - emitir una solicitud de cancelación síncrona

SINOPSIS

#include <liburing.h>
int io_uring_register_sync_cancel(struct io_uring *ring,
                                  struct io_uring_sync_cancel_reg *reg);

DESCRIPCIÓN

La función io_uring_register_sync_cancel(3) realiza una solicitud de cancelación síncrona basada en los parámetros especificados en reg.

El argumento reg debe rellenarse con la información adecuada para la solicitud de cancelación. Tiene el siguiente aspecto:


struct io_uring_sync_cancel_reg {
    __u64 addr;
    __s32 fd;
    __u32 flags;
    struct __kernel_timespec timeout;
    __u8 opcode;
    __u8 pad[7];
    __u64 pad2[3];
};

Los argumentos reflejan en gran medida lo que soportan las funciones de preparación asíncrona, véase io_uring_prep_cancel(3) para más detalles. De manera similar, el valor de retorno es el mismo. La excepción es el argumento timeout, que puede utilizarse para limitar el tiempo que el kernel esperará a que las cancelaciones sean exitosas. Si los valores tv_sec y tv_nsec se establecen en algo distinto de -1UL, entonces indican un tiempo de espera relativo tras el cual las cancelaciones deben completarse.

Los valores pad deben rellenarse con ceros.

VALOR DE RETORNO

Véase io_uring_prep_cancel(3) para obtener detalles sobre el valor de retorno. Si timeout se establece para indicar un tiempo de espera, se devolverá -ETIME si se supera. Si se establece un valor desconocido en la solicitud, o si los valores de relleno no se borran a cero, se devolverá -EINVAL.
