NOMBRE

io_queue_run - Gestionar solicitudes de E/S completadas

SINOPSIS

#include <errno.h>

#include <libaio.h>

int io_queue_run(io_context_t ctx);

DESCRIPCIÓN

io_queue_run() intenta leer todos los eventos de la cola de finalización para el contexto aio especificado por ctx.

VALORES DE RETORNO

Puede devolver 0 si no hay eventos disponibles. Fallará con -ENOSYS si no está implementado.

ERRORES

EFAULT
iocbs referenciaba datos fuera del espacio de direcciones accesible del programa.
EINVAL
ctx se refiere a un contexto aio no inicializado, el iocb apuntado por iocbs contiene un iocb inicializado incorrectamente.
ENOSYS
No implementado.
