ioctl_userfaultfd(2) Manual de Llamadas al Sistema ioctl_userfaultfd(2)

NOMBRE

ioctl_userfaultfd - crear un descriptor de archivo para manejar fallos de página en el espacio de usuario

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <linux/userfaultfd.h>  /* Definición de constantes UFFD* */
#include <sys/ioctl.h>
int ioctl(int fd, int op, ...);

DESCRIPCIÓN

Se pueden realizar varias operaciones ioctl(2) en un objeto userfaultfd (creado por una llamada a userfaultfd(2)) utilizando llamadas de la forma:


ioctl(fd, op, argp);

En la anterior, fd es un descriptor de archivo que apunta a un objeto userfaultfd, op es una de las operaciones listadas a continuación, y argp es un puntero a una estructura de datos específica para op.

Las diversas operaciones ioctl(2) se describen a continuación. Las operaciones UFFDIO_API, UFFDIO_REGISTER y UFFDIO_UNREGISTER se utilizan para *configurar* el comportamiento de userfaultfd. Estas operaciones permiten al llamante elegir qué características se habilitarán y qué tipos de eventos se entregarán a la aplicación. Las operaciones restantes son operaciones de *rango*. Estas operaciones permiten a la aplicación que llama resolver eventos de fallo de página.

UFFDIO_API(2const)
UFFDIO_REGISTER(2const)
UFFDIO_UNREGISTER(2const)
UFFDIO_COPY(2const)
UFFDIO_MOVE(2const)
UFFDIO_ZEROPAGE(2const)
UFFDIO_WAKE(2const)
UFFDIO_WRITEPROTECT(2const)
UFFDIO_CONTINUE(2const)
UFFDIO_POISON(2const)

VALOR DE RETORNO

Al éxito, se devuelve 0. En caso de error, se devuelve -1 y la variable errno se establece para indicar el error.

ERRORES

Los siguientes errores generales pueden ocurrir para todas las operaciones descritas anteriormente:

EFAULT
argp no apunta a una dirección de memoria válida.
EINVAL
(Para todas las operaciones excepto UFFDIO_API.) El objeto userfaultfd aún no ha sido habilitado (mediante la operación UFFDIO_API).

ESTANDARES

Linux.

EJEMPLOS

Ver userfaultfd(2).

VER TAMBIÉN

ioctl(2), mmap(2), userfaultfd(2)
