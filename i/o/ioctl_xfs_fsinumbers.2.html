NOMBRE

ioctl_xfs_fsinumbers - extraer una lista de números de inodo válidos de un sistema de archivos XFS

SINOPSIS

#include <xfs/xfs_fs.h>

int ioctl(int fd, XFS_IOC_FSINUMBERS, struct xfs_fsop_bulkreq *arg);

DESCRIPCIÓN

Consulta información de asignación de inodos de un sistema de archivos XFS. Está destinado a ser llamado iterativamente para obtener el conjunto completo de inodos. Estos ioctls utilizan struct xfs_fsop_bulkreq para configurar una transferencia masiva con el kernel:


struct xfs_fsop_bulkreq {
	__u64   *lastip;
	__s32   count;
	void    *ubuffer;
	__s32   *ocount;
};

lastip apunta a un valor que recibirá el número del "último inodo." Este debe establecerse en uno menos que el número del primer inodo para el que el llamador solicita información, o cero para comenzar con el primer inodo del sistema de archivos. Después de la llamada, este valor se establecerá en el número del último inodo para el que se proporciona información. Este campo no se actualizará si ocount es NULL.

count es el número de elementos en la matriz ubuffer y, por lo tanto, el número de grupos de inodos para los que se debe devolver información de asignación.

ocount apunta a un valor que recibirá el número de registros devueltos. Un valor de salida de cero significa que no quedan más grupos de inodos para enumerar. Si este valor es NULL, ni ocount ni lastip se actualizarán.

ubuffer apunta a un búfer de memoria donde se copiará la información del grupo de inodos. Este búfer debe ser una matriz de struct xfs_inogrp que se describe a continuación. La matriz debe tener al menos count elementos.


struct xfs_inogrp {
	__u64   xi_startino;
	__s32   xi_alloccount;
	__u64   xi_allocmask;
}

Esta estructura describe la información de uso de inodos para un grupo de 64 números de inodos consecutivos. Los campos son los siguientes:

xi_startino es el primer número de inodo de este grupo.

xi_alloccount es el número de bits que están establecidos en xi_allocmask. Este es el número de inodos asignados en este grupo.

xi_allocmask es una máscara de bits de inodos asignados en este grupo de inodos. La máscara de bits tiene 64 bits de largo, y el bit menos significativo corresponde al inodo xi_startino.

VALOR DE RETORNO

En caso de error, se devuelve -1 y se establece errno para indicar el error.

ERRORES

Los códigos de error pueden ser uno o más de los siguientes, pero no se limitan a ellos:

EFAULT
El kernel no pudo copiar al búfer del espacio de usuario.
EFSBADCRC
La validación de la suma de verificación de metadatos falló durante la consulta.
EFSCORRUPTED
Se encontró corrupción de metadatos durante la consulta.
EINVAL
Uno de los argumentos no era válido.
EIO
Se encontró un error de E/S durante la consulta.
ENOMEM
No había suficiente memoria para realizar la consulta.

CONFORMIDAD

Esta API es específica del sistema de archivos XFS en el kernel de Linux.
