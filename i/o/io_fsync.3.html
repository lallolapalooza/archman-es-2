io_fsync(3) AIO de Linux io_fsync(3)

NOMBRE

io_fsync - Sincroniza el estado completo en memoria de un archivo con el disco

SINOPSIS

#include <errno.h>

#include <libaio.h>

int io_fsync(io_context_t ctx, struct iocb *iocb, io_callback_t cb, int fd);

struct iocb {
	void		*data;
	unsigned	key;
	short		aio_lio_opcode;
	short		aio_reqprio;
	int		aio_fildes;
};

typedef void (*io_callback_t)(io_context_t ctx, struct iocb *iocb, long res, long res2);

DESCRIPCIÓN

Al tratar con operaciones asíncronas, a veces es necesario alcanzar un estado consistente. Esto significaría para AIO que uno quiere saber si una solicitud determinada o un grupo de solicitudes fueron procesadas. Esto podría hacerse esperando la notificación enviada por el sistema después de que la operación terminara, pero esto a veces significaría desperdiciar recursos (principalmente tiempo de cómputo).

Llamar a esta función fuerza todas las operaciones de I/O puestas en cola en el momento de la llamada a la función que operan en el descriptor de archivo iocb->io_fildes a pasar al estado de finalización de I/O síncrona. La función io_fsync() retorna inmediatamente, pero la notificación a través del método descrito en io_callback ocurrirá solo después de que todas las solicitudes para este descriptor de archivo hayan terminado y el archivo esté sincronizado. Esto también significa que las solicitudes para este mismo descriptor de archivo que se ponen en cola después de la solicitud de sincronización no se ven afectadas.

VALORES DE RETORNO

Retorna 0, de lo contrario retorna errno.

ERRORES

EFAULT
iocbs hizo referencia a datos fuera del espacio de direcciones accesible del programa.
EINVAL
ctx se refiere a un contexto aio no inicializado, el iocb apuntado por iocbs contiene un iocb inicializado incorrectamente,
EBADF
El iocb contiene un descriptor de archivo que no existe.
EINVAL
El archivo especificado en el iocb no soporta la operación de io dada.
