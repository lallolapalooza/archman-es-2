NOMBRE

io_submit - Enviar peticiones de io

SINOPSIS

#include <errno.h>

#include <libaio.h>

int io_submit(io_context_t ctx, long nr, struct iocb *iocbs[]);

struct iocb {
	void		*data;
	unsigned	key;
	short		aio_lio_opcode;
	short		aio_reqprio;
	int		aio_fildes;
};

DESCRIPCIÓN

io_submit() envía nr iocbs para su procesamiento en un contexto de io dado, ctx.

La función io_submit() puede usarse para encolar un número arbitrario de peticiones de lectura y escritura a la vez. Las peticiones pueden ser todas para el mismo archivo, todas para archivos diferentes o cualquier combinación intermedia.

io_submit() obtiene las nr peticiones del array al que apunta iocbs. La operación a realizar está determinada por el miembro aio_lio_opcode en cada elemento de iocbs. Si este campo es IO_CMD_PREAD se encola una operación de lectura, similar a una llamada a io_prep_pread para este elemento del array (excepto que la forma en que se señala la terminación es diferente, como veremos más adelante). Si el miembro aio_lio_opcode es IO_CMD_PWRITE se encola una operación de escritura. De lo contrario, aio_lio_opcode debe ser IO_CMD_NOP, en cuyo caso este elemento de iocbs simplemente se ignora. Esta "operación" es útil en situaciones donde se tiene un array fijo de elementos struct iocb de los cuales solo unos pocos necesitan ser manejados a la vez. Otra situación es cuando la llamada io_submit(3) fue cancelada antes de que todas las peticiones fueran procesadas y las peticiones restantes tienen que ser reemitidas.

Los otros miembros de cada elemento del array apuntado por iocbs deben tener valores adecuados para la operación, como se describe en la documentación de io_prep_pread(3) y io_prep_pwrite(3) anteriormente.

La función regresa inmediatamente después de haber encolado todas las peticiones. En caso de éxito, io_submit() devuelve el número de iocbs enviados correctamente. De lo contrario, se devuelve -error, donde error es uno de los valores Exxx definidos en la sección Errores.

Si se detecta un error, el comportamiento es indefinido.

Operaciones asíncronas simultáneas que utilizan el mismo iocb producen resultados indefinidos.

ERRORES

EFAULT
iocbs referenció datos fuera del espacio de direcciones accesible del programa.
EINVAL
ctx se refiere a un contexto aio no inicializado, el iocb apuntado por iocbs contiene un iocb mal inicializado,
EBADF
El iocb contiene un descriptor de archivo que no existe.
EINVAL
El archivo especificado en el iocb no soporta la operación de io dada.
