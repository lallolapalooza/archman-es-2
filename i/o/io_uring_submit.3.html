NOMBRE

io_uring_submit - envía solicitudes a la cola de envío

SINOPSIS

#include <liburing.h>
int io_uring_submit(struct io_uring *ring);

DESCRIPCIÓN

La función io_uring_submit(3) envía los siguientes eventos a la cola de envío perteneciente a ring.

Después de que el llamador obtenga una entrada de cola de envío (SQE) con io_uring_get_sqe(3) y prepare la SQE utilizando una de las utilidades proporcionadas, puede enviarse con io_uring_submit(3).

VALOR DE RETORNO

En caso de éxito, io_uring_submit(3) devuelve el número de entradas de cola de envío enviadas, si SQPOLL no se utiliza. Si se utiliza SQPOLL, el valor de retorno puede informar un número mayor de entradas enviadas de las que realmente se han enviado. Si el usuario requiere información precisa sobre cuántas entradas de cola de envío se han enviado correctamente, mientras se utiliza SQPOLL, el usuario debe recurrir a enviar repetidamente una única entrada de cola de envío. En caso de fallo, devuelve -errno.

NOTAS

Para cualquier solicitud que pase datos en una estructura, esos datos deben permanecer válidos hasta que la solicitud se haya enviado correctamente. No es necesario que permanezcan válidos hasta la finalización. Una vez que una solicitud se ha enviado, el estado dentro del kernel es estable. Los kernels muy tempranos (5.4 y anteriores) requerían que el estado permaneciera estable hasta que ocurriera la finalización. Las aplicaciones pueden probar este comportamiento inspeccionando el flag IORING_FEAT_SUBMIT_STABLE devuelto por io_uring_queue_init_params(3). En general, las páginas del manual para las utilidades de preparación individuales tendrán una nota que mencione este hecho también, si es requerido para el comando dado.
