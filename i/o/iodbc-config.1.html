NOMBRE

iodbc-config - script para obtener información sobre la versión instalada de iODBC

SINOPSIS

iodbc-config [--prefijo[=DIR]] [--exec-prefijo[=DIR]] [--version] [--cflags] [--libs] [--static-libs] [--libtool-libs] [--odbcini] [--odbcinstini]

DESCRIPCIÓN

iodbc-config es una herramienta que se utiliza para configurar y determinar las opciones del compilador y del enlazador que deben utilizarse para compilar y enlazar programas que utilizan iODBC.

OPCIONES

iodbc-config acepta las siguientes opciones:

--version
Imprime la versión actualmente instalada de iODBC en la salida estándar.
--cflags
Imprime las opciones del compilador que son necesarias para compilar un programa iODBC.
--libs
Imprime las opciones del enlazador que son necesarias para enlazar un programa iODBC utilizando bibliotecas dinámicas (si son compatibles).
--static-libs
Imprime las opciones del enlazador que son necesarias para enlazar un programa iODBC utilizando bibliotecas estáticas.
--libtool-libs
Imprime las opciones del enlazador que son necesarias para enlazar un programa iODBC en un entorno libtool.
--odbcini
Imprime la ruta del archivo odbc.ini a nivel de sistema.
--odbcinstini
Imprime la ruta del archivo odbcinst.ini a nivel de sistema.
--prefijo[=PREFIJO]
Si se especifica, utiliza PREFIJO en lugar del prefijo de instalación con el que se compiló iODBC al calcular la salida para las opciones --cflags y --libs. Esta opción también se utiliza para el prefijo de ejecución si no se especificó --exec-prefijo. Esta opción debe especificarse antes de cualquier opción --libs o --cflags.

Si no se especifica PREFIJO, la opción --prefijo muestra dónde está instalado iODBC actualmente.

--exec-prefijo=PREFIJO
Si se especifica, utiliza PREFIJO en lugar del prefijo de ejecución de instalación con el que se compiló iODBC al calcular la salida para las opciones --cflags y --libs. Esta opción debe especificarse antes de cualquier opción --libs o --cflags.

EJEMPLOS

Para compilar un programa que llama a la API de iODBC, asegúrate de que el programa iodbc-config pueda encontrarse en la variable de entorno PATH, antes de utilizar el siguiente fragmento de Makefile:

    CFLAGS=`iodbc-config --cflags`
    LDLIBS=`iodbc-config --libs`
    iodbctest: iodbctest.c
	    cc $(CFLAGS) -o iodbctest iodbctest.c $(LDLIBS)
