NOMBRE

io_uring_prep_cmd_sock - prepara una solicitud de comando para un socket

SINOPSIS

#include <liburing.h>
void io_uring_prep_cmd_sock(struct io_uring_sqe *sqe,
                            int cmd_op,
                            int fd,
                            int level,
                            int optname,
                            void *optval,
                            int optlen);

DESCRIPCIÓN

La función io_uring_prep_cmd_sock(3) prepara una solicitud de comando para un socket. La entrada de la cola de envío sqe se configura para utilizar el descriptor de archivo de socket al que apunta fd para iniciar una operación de comando definida por cmd_op.

Esta es una función genérica y cada comando tiene sus propios valores individuales de level, optname, optval. optlen define el tamaño apuntado por optval.

Comandos disponibles

SOCKET_URING_OP_SIOCINQ
Devuelve la cantidad de datos sin leer en cola en el búfer de recepción. El socket no debe estar en estado LISTEN, de lo contrario, se devolverá un error -EINVAL en el campo res de CQE. Los siguientes argumentos no se utilizan para este comando: level, optname, optval y optlen.

Un valor de retorno negativo significa un error.

Para más información sobre este comando, por favor consulte unix(7).

Disponible desde 6.7.

SOCKET_URING_OP_SIOCOUTQ
Devuelve la cantidad de datos no enviados en la cola de envío del socket. El socket no debe estar en estado LISTEN, de lo contrario, se devolverá un error -EINVAL en el campo res de CQE. Los siguientes argumentos no se utilizan para este comando: level, optname, optval y optlen.

Un valor de retorno negativo significa un error.

Para más información sobre este comando, por favor consulte unix(7).

SOCKET_URING_OP_GETSOCKOPT
Comando para obtener opciones para el socket al que se refiere el descriptor de archivo de socket fd. Los argumentos son similares a la llamada al sistema getsockopt(2).

El comando SOCKET_URING_OP_GETSOCKOPT está limitado al nivel SOL_SOCKET.

A diferencia de la llamada al sistema getsockopt(2), el valor actualizado de optlen se devuelve en el campo res de CQE, en caso de éxito. En caso de fallo, CQE res contiene un número de error negativo.

SOCKET_URING_OP_SETSOCKOPT
Comando para establecer opciones para el socket al que se refiere el descriptor de archivo de socket fd. Los argumentos son similares a la llamada al sistema setsockopt(2).

Disponible desde 6.7.

NOTAS

El bloque de memoria apuntado por optval debe ser válido/estar vivo hasta que se devuelva el CQE.

VALOR DE RETORNO

Depende del comando.

ERRORES

El campo res de CQE contendrá el resultado de la operación.
