NOMBRE

io_uring_close_ring_fd - cerrar un descriptor de archivo de anillo y usarlo solo a través de un índice registrado

SINOPSIS

#include <liburing.h>
int io_uring_close_ring_fd(struct io_uring *ring);

DESCRIPCIÓN

io_uring_close_ring_fd(3) cierra el descriptor de archivo del anillo, que debe haber sido registrado previamente. El archivo permanecerá abierto, pero accesible solo a través del índice registrado, no a través de ningún descriptor de archivo. Las llamadas posteriores a liburing continuarán funcionando, utilizando el descriptor del anillo registrado.

El kernel debe soportar IORING_FEAT_REG_REG_RING.

Las bibliotecas que deben evitar interrumpir el uso de descriptores de archivo por parte de sus usuarios, y que deben seguir funcionando incluso frente a close_range(2) y similares, pueden usar io_uring_close_ring_fd(3) para trabajar con liburing sin tener ningún descriptor de archivo abierto.

NOTAS

Cada hilo que quiera hacer uso de io_uring debe registrar el descriptor de archivo. Una biblioteca que pueda ser llamada desde hilos arbitrarios puede necesitar detectar cuándo se llama en un hilo previamente desconocido y crear y registrar un anillo para ese hilo.

VALOR DE RETORNO

Devuelve 1 si tiene éxito, o -errno en caso de error.
