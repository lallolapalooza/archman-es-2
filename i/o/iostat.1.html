El comando iostat genera informes que pueden utilizarse para cambiar la configuración del sistema y equilibrar mejor la carga de entrada/salida entre los discos físicos. El primer informe

El informe consiste en una fila de encabezado de CPU seguida de una fila de estadísticas de CPU. En sistemas multiprocesador, las estadísticas de CPU se calculan a nivel de sistema como promedios entre todos los procesadores. Si se especifica el parámetro count, el valor de count determina el número de informes generados con un intervalo de interval segundos. Si se especifica el parámetro interval sin el parámetro count, el comando iostat genera informes continuam

El segundo informe generado por el comando iostat es el informe de utilización de dispositivos. El informe de dispositivos proporciona estadísticas por dispositivo físico o partición. Los dispositivos de bloque y las particiones para los que se desean mostrar estadísticas pueden introducirse en la línea de comandos. Si no se introduce ningún dispositivo ni partición, se muestran estadísticas de todos los dispositivos utilizados por el sistema, siempre que el núcleo mantenga estadísticas para ellos. Si se proporciona la palabra clave ALL en la línea de comandos, se muestran estadísticas de todos los dispositivos definidos por el sistema, incluidos aquellos que nunca se han utilizado. Las tasas de transferencia se muestran en bloques de 1024 bytes de forma predeterminada, a menos que la variable de entorno POSIXLY_CORRECT esté establecida, en cuyo caso se utilizan bloques de 512 bytes. ERRORE

S

El sistema de archivos /proc debe estar montado para que iostat func

ione.

Los núcleos anteriores a la versión 2.6.x ya no son

compatibles.

Aunque iostat muestra unidades correspondientes a kilobytes (kB), megabytes (MB)..., en realidad usa kibibytes

(kiB), mebibytes (MiB)... Un kibibyte es igual a 10
24 bytes, y un mebibyte es igual a 1024 kibibytes.
