NOMBRE

io_uring_get_probe - obtener instancia de sondeo

SINOPSIS

#include <liburing.h>
io_uring_probe *io_uring_get_probe(void);

DESCRIPCIÓN

La función io_uring_get_probe(3) devuelve una estructura io_uring_probe asignada al llamante. El llamante es responsable de liberar la estructura con la función io_uring_free_probe(3).

NOTAS

Versiones anteriores del kernel de Linux no admiten el sondeo. Si el kernel no admite el sondeo, esta función devolverá NULL.

VALOR DE RETORNO

En caso de éxito, devuelve una estructura io_uring_probe asignada, de lo contrario, devuelve NULL.

VER TAMBIÉN

io_uring_free_probe(3)
