NOMBRE

io_uring_prep_msg_ring_fd - enviar un descriptor directo a otro anillo

SINOPSIS

#include <liburing.h>
void io_uring_prep_msg_ring_fd(struct io_uring_sqe *sqe,
                        int fd,
                        int source_fd,
                        int target_fd,
                        __u64 data,
                        unsigned int flags);
void io_uring_prep_msg_ring_fd_alloc(struct io_uring_sqe *sqe,
                        int fd,
                        int source_fd,
                        __u64 data,
                        unsigned int flags);

DESCRIPCIÓN

io_uring_prep_msg_ring_fd(3) prepara una entrada de cola de envío (SQE) para enviar un descriptor de archivo directo a otro anillo. La entrada de la cola de envío sqe se configura para usar el descriptor de archivo fd, que debe identificar un contexto io_uring de destino, para enviar el descriptor de archivo registrado localmente con valor source_fd al anillo de destino en el índice target_fd y pasando data como datos de usuario en la entrada de cola de completado (CQE) de destino con las banderas modificadoras de solicitud establecidas por flags. Actualmente no hay modificadores de bandera válidos, este campo debe contener 0.

io_uring_prep_msg_ring_fd_alloc(3) es similar a io_uring_prep_msg_ring_fd(3), pero no especifica un índice de destino para el descriptor directo. En su lugar, este índice se asigna en el anillo de destino y se devuelve en el campo res de la CQE.

VALOR DE RETORNO

Ninguno

ERRORES

Estos son los errores que se informan en el campo res de la CQE.

-ENOMEM
El kernel no pudo asignar memoria para la solicitud.
-EINVAL
Uno de los campos establecidos en la SQE era inválido.
-EINVAL
El anillo de destino es idéntico al anillo de origen.
-EBADFD
El descriptor pasado en fd no se refiere a un descriptor de archivo io_uring, o el anillo está en un estado deshabilitado.
-EOVERFLOW
El kernel no pudo completar una CQE en el anillo de destino. Esto puede ocurrir si el anillo CQ de destino está en un estado de desbordamiento y el kernel no pudo asignar memoria para una nueva entrada CQE.
-ENFILE
La tabla de descriptores directos en el anillo de destino estaba llena, no se pudieron asignar nuevos descriptores con éxito.
