NAME

ioctl_xfs_bulkstat, XFIOC_BULKSTAT - XFS_BULKSTAT ioctl, for bulk stat data.

SYNOPSIS

#include <sys/ioctl.h>

int ioctl(int fd, XFIOC_BULKSTAT, struct xfs_bulkstat *arg);

DESCRIPTION

The XFIOC_BULKSTAT ioctl retrieves filesystem metadata status.

The fd argument is a file descriptor referring to a file within the XFS filesystem. The arg argument is a pointer to a struct xfs_bulkstat structure.

This structure is defined as:

struct xfs_bulkstat {
    __u64   bs_count;   /* number of items in the array */
    __u64   bs_limit;   /* size of the array */
    __u64   bs_reserved;/* reserved for future use */
    struct xfs_stat_info *bs_data; /* pointer to array of xfs_stat_info */
};

The caller must initialize bs_limit to the number of items in the array pointed to by bs_data. The bs_count field is then filled with the number of items returned.

The structure referenced by bs_data is an array of struct xfs_stat_info structures, which is defined as:

struct xfs_stat_info {
    __u64   stat_version; /* version of this structure */
    __u64   stat_ino;     /* inode number */
    __u64   stat_nioct;   /* number of data blocks */
    __u64   stat_aextents;/* number of allocated extents */
    __u64   stat_filetype;/* file type (see below) */
    __u32   stat_nlink;   /* number of links */
    __s32   stat_projname;/* project name if applicable */
    __u32   stat_blksize; /* block size */
    __u32   stat_flags;   /* flags */
    __u64   stat_rtextents;/* number of real extents */
    __u64   stat_nextents;/* number of (possibly) shared extents */
    __u64   stat_blocks;  /* number of used blocks */
    __u64   stat_size;    /* size in bytes */
    __u64   stat_magic;   /* magic number */
    __u32   stat_crc;     /* CRC of this structure */
    __u32   stat_bsick;   /* sick flags */
    __u32   stat_bs_checked; /* checked sick flags */
};

The fields in xfs_stat_info are:

  • stat_version: Version of the xfs_stat_info structure. Must be 1.
  • stat_ino: Inode number.
  • stat_nioct: Number of data blocks.
  • stat_aextents: Number of allocated extents.
  • stat_filetype: File type. See stat_filetype field below.
  • stat_nlink: Number of links.
  • stat_projname: Project name ID, if applicable. Otherwise -1.
  • stat_blksize: Block size of the filesystem.
  • stat_flags: Filesystem flags.
  • stat_rtextents: Number of real extents.
  • stat_nextents: Number of (possibly) shared extents.
  • stat_blocks: Number of used blocks.
  • stat_size: Size in bytes.
  • stat_magic: Magic number (XFS_STAT_INFO_MAGIC).
  • stat_crc: CRC of this structure.
  • stat_bsick: Sick flags indicating potential corruption.
  • stat_bs_checked: Flags indicating which sick flags have been checked.

The stat_filetype field can be one of the following:

  • XFS_DT_UNKNOWN
  • XFS_DT_REGULAR
  • XFS_DT_DIR
  • XFS_DT_SYMLINK
  • XFS_DT_BLKDEV
  • XFS_DT_CHRDEV
  • XFS_DT_FIFO
  • XFS_DT_SOCK

RETURN VALUE

On success, 0 is returned.

On failure, -1 is returned, and errno is set appropriately.

XFS INODE METADATA HEALTH REPORTING

The stat_bsick and stat_bs_checked fields provide information about the health of the inode's metadata. The following interpretations apply:

•
If a given sick flag is set in bs_checked, then the corresponding sick flag in bs_sick indicates whether that part of the metadata is considered sick.
•
If a given sick flag is not set in bs_checked, then the f metadata has been checked and is not faulty.
•
If a given sick flag is not set in bs_checked, then no conclusion can be made.

The following flags apply to these fields:

XFS_BS_SICK_INODE
The inode's record itself.
XFS_BS_SICK_BMBTD
File data extent mappings.
XFS_BS_SICK_BMBTA
Extended attribute extent mappings.
XFS_BS_SICK_BMBTC
Copy on Write staging extent mappings.
XFS_BS_SICK_DIR
Directory information.
XFS_BS_SICK_XATTR
Extended attribute data.
XFS_BS_SICK_SYMLINK
Symbolic link target.
XFS_BS_SICK_PARENT
Parent pointers.
XFS_BS_SICK_DIRTREE
Directory is the source of corruption in the directory tree.

ERRORS

Error codes can be one of, but are not limited to, the following:

EFAULT
The kernel was not able to copy into the userspace buffer.
EFSBADCRC
Metadata checksum validation failed while performing the query.
EFSCORRUPTED
Metadata corruption was encountered while performing the query.
EINVAL
One of the arguments was not valid.
EIO
An I/O error was encountered while performing the query.
ENOMEM
There was insufficient memory to perform the query.

CONFORMING TO

This API is specific to XFS filesystem on the Linux kernel.
