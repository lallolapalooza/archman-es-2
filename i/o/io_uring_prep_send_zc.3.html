NOMBRE

io_uring_prep_send_zc - preparar una solicitud de envío de copia cero

SINOPSIS

#include <liburing.h>
void io_uring_prep_send_zc(struct io_uring_sqe *sqe,
                           int sockfd,
                           const void *buf,
                           size_t len,
                           int flags,
                           unsigned zc_flags);
void io_uring_prep_send_zc_fixed(struct io_uring_sqe *sqe,
                                 int sockfd,
                                 const void *buf,
                                 size_t len,
                                 int flags,
                                 unsigned zc_flags);
                                 unsigned buf_index);

DESCRIPCIÓN

La función io_uring_prep_send_zc(3) prepara una solicitud de envío de copia cero. La entrada de la cola de envío sqe se configura para usar el descriptor de archivo sockfd para comenzar a enviar los datos desde buf de tamaño len bytes con los indicadores modificadores de envío flags y los indicadores modificadores de copia cero zc_flags.

La función io_uring_prep_send_zc_fixed(3) funciona igual que io_uring_prep_send_zc(3), excepto que requiere el uso de búferes que se han registrado con io_uring_register_buffers(3). Los argumentos buf y len deben estar dentro de una región especificada por buf_index en el búfer registrado previamente. El búfer no necesita estar alineado con el inicio del búfer registrado.

Consulte io_uring_prep_send(3) para obtener una descripción de los indicadores que se pueden establecer en el campo ioprio de la SQE. Además de esos, el envío de copia cero también admite el establecimiento de IORING_SEND_ZC_REPORT_USAGE. Si se establece, el campo res de la CQE notificará el número de bytes que se copiaron en lugar de enviarse con copia cero. Un valor de 0 indica éxito. Si el valor es IORING_NOTIF_USAGE_ZC_COPIED, entonces se copiaron datos.

Tenga en cuenta que el uso de IOSQE_IO_LINK con este tipo de solicitud requiere el establecimiento de MSG_WAITALL en el argumento flags, ya que un envío corto no se considera una condición de error sin eso.

Estas funciones preparan una solicitud de envío asíncrona de copia cero send(2). Consulte esa página del manual para obtener detalles. Para obtener detalles sobre la naturaleza de copia cero, consulte io_uring_enter(2).

VALOR DE RETORNO

Ninguno

ERRORES

El campo res de la CQE contendrá el resultado de la operación. Consulte la página del manual relacionada para obtener detalles sobre los valores posibles. Tenga en cuenta que donde las llamadas al sistema síncronas devolverán -1 en caso de error y establecerán errno en el valor de error real, io_uring nunca usa errno. En su lugar, devuelve el errno negado directamente en el campo res de la CQE.
