NOMBRE

io_uring_prep_fixed_fd_install - prepara una solicitud de instalación de descriptor de archivo fijo

SINOPSIS

#include <liburing.h>
void io_uring_prep_fixed_fd_install(struct io_uring_sqe *sqe,
                                    int fd,
                                    unsigned int flags);

DESCRIPCIÓN

El ayudante io_uring_prep_fixed_fd_install(3) prepara la instalación de un descriptor de archivo fijo. La entrada de la cola de envío sqe se configura para instalar el descriptor de archivo directo/fijo fd con los indicadores especificados de instalación de archivo flags.

Un caso de uso de los descriptores de archivo directos/fijos es convertir un descriptor de archivo regular en uno directo, reduciendo la sobrecarga de cualquier solicitud que necesite acceder a este archivo. Este ayudante proporciona una forma de ir en la dirección opuesta, convirtiendo un descriptor directo en un descriptor de archivo regular que luego puede ser utilizado por llamadas al sistema regulares que toman un descriptor de archivo normal. Esto puede ser útil si no existe un descriptor de archivo regular para este descriptor directo. Ya sea porque se instanció directamente como un descriptor fijo, o porque el archivo regular se cerró con close(2) después de ser convertido en un descriptor directo.

Tras el retorno exitoso de esta solicitud, existen tanto un descriptor de archivo normal como uno fijo para el mismo archivo. Cualquiera de ellos puede ser utilizado para acceder al archivo. Cualquiera de ellos puede ser cerrado sin afectar al otro.

flags puede ser cero, o establecerse en IORING_FIXED_FD_NO_CLOEXEC para indicar que el nuevo descriptor de archivo regular no debe cerrarse durante exec. Por defecto, se establecerá O_CLOEXEC en el descriptor nuevo en caso contrario. Establecer este campo en cualquier valor que no sea esos dos dará como resultado que la solicitud falle con -EINVAL en el campo res del CQE.

VALOR DE RETORNO

Ninguno

ERRORES

El campo res del CQE contendrá el resultado de la operación, que en este caso será el valor del nuevo descriptor de archivo regular. En caso de fallo, se devolverá un valor negativo.
