NOMBRE

io_uring_wait_cqe_timeout - espera un evento de finalización de io_uring con tiempo de espera

SINOPSIS

#include <liburing.h>
int io_uring_wait_cqe_timeout(struct io_uring *ring,
                              struct io_uring_cqe **cqe_ptr,
                              struct __kernel_timespec *ts);

DESCRIPCIÓN

La función io_uring_wait_cqe_timeout(3) espera a que haya una finalización de IO disponible desde la cola perteneciente al parámetro ring, esperando si es necesario o hasta que expire el tiempo de espera ts. Si un evento ya está disponible en el anillo al ser invocada, no se producirá ninguna espera.

El parámetro cqe_ptr se rellena en caso de éxito.

Si se especifica ts y se utiliza un kernel anterior sin IORING_FEAT_EXT_ARG, la aplicación no necesita llamar a io_uring_submit(3) antes de llamar a io_uring_wait_cqes(3). Para kernels más recientes con este indicador de característica activado, no hay un envío implícito al esperar una solicitud.

Si ts es NULL, esto se comporta como io_uring_wait_cqe(3), ya que esperará indefinidamente a un evento.

VALOR DE RETORNO

En caso de éxito, io_uring_wait_cqe_timeout(3) devuelve 0 y el parámetro cqe_ptr se rellena. En caso de error, devuelve -errno. El valor de retorno indica el resultado de la espera de un CQE y no tiene relación con el resultado del CQE en sí. Si ocurre un tiempo de espera agotado, devolverá -ETIME.

VER TAMBIÉN

io_uring_submit(3), io_uring_wait_cqes(3), io_uring_wait_cqe(3)
