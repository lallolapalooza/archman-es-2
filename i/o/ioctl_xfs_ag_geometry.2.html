NOMBRE

ioctl_xfs_ag_geometry - consulta información de geometría de grupo de asignación de XFS

SINOPSIS

#include <xfs/xfs_fs.h>

int ioctl(int fd, XFS_IOC_AG_GEOMETRY, struct xfs_ag_geometry *arg);

DESCRIPCIÓN

Este ioctl de XFS recupera la información de geometría para un grupo de asignación dado. La información de geometría se transmite en una estructura de la siguiente forma:


struct xfs_ag_geometry {
	uint32_t  ag_number;
	uint32_t  ag_length;
	uint32_t  ag_freeblks;
	uint32_t  ag_icount;
	uint32_t  ag_ifree;
	uint32_t  ag_sick;
	uint32_t  ag_checked;
	uint32_t  ag_flags;
	uint64_t  ag_reserved[12];
};
ag_number
El llamador debe establecer este campo al índice del grupo de asignación sobre el que el llamador desea obtener información.
ag_length
La longitud del grupo de asignación se devuelve en este campo, en unidades de bloques del sistema de archivos.
ag_freeblks
El número de bloques libres en el grupo de asignación se devuelve en este campo, en unidades de bloques del sistema de archivos.
ag_icount
El número de registros de inodo asignados en este grupo de asignación se devuelve en este campo.
ag_ifree
El número de registros de inodo no utilizados (del espacio asignado) en este grupo de asignación se devuelve en este campo.
ag_flags
El llamador puede establecer este campo para cambiar el comportamiento operativo del ioctl. Actualmente no hay flags definidos, por lo que este campo debe ser cero.
ag_reserved
Todos los campos reservados se establecerán a cero al regresar.

Los campos ag_sick y ag_checked indican la salud relativa de varios metadatos del grupo de asignación:

•
Si un flag de "enfermo" dado está establecido en ag_sick, entonces esa pieza de metadato ha sido observada como dañada. El mismo bit estará establecido en ag_checked.
•
Si un flag de "enfermo" dado está establecido en ag_checked y no está establecido en ag_sick, entonces esa pieza de metadato ha sido verificada y no es defectuosa.
•
Si un flag de "enfermo" dado no está establecido en ag_checked, entonces no se puede hacer ninguna conclusión.

Los siguientes flags se aplican a estos campos:

XFS_AG_GEOM_SICK_SB
Superbloque del grupo de asignación.
XFS_AG_GEOM_SICK_AGF
Cabecera del espacio libre.
XFS_AG_GEOM_SICK_AGFL
Lista de reserva de espacio libre.
XFS_AG_GEOM_SICK_AGI
Cabecera de inodos.
XFS_AG_GEOM_SICK_BNOBT o XFS_AG_GEOM_SICK_CNTBT
Árboles B de espacio libre.
XFS_AG_GEOM_SICK_INOBT o XFS_AG_GEOM_SICK_FINOBT
Árboles B de inodos.
XFS_AG_GEOM_SICK_RMAPBT
Árbol B de mapeo inverso.
XFS_AG_GEOM_SICK_REFCNTBT
Árbol B de recuento de referencias.

VALOR DE RETORNO

En caso de error, se devuelve -1 y errno se establece para indicar el error.

ERRORES

Los códigos de error pueden ser, entre otros, los siguientes:

EFSBADCRC
La validación de la suma de verificación de metadatos falló durante la consulta.
EFSCORRUPTED
Se encontró corrupción de metadatos durante la consulta.
EINVAL
El número de grupo de asignación especificado no es válido para este sistema de archivos.
EIO
Se encontró un error de E/S durante la consulta.

CONFORMIDAD CON

Esta API es específica del sistema de archivos XFS en el kernel de Linux.
