IOCTL-XFS-INUMBERS(2) Manual de llamadas al sistema IOCTL-XFS-INUMBERS(2)

NOMBRE

ioctl_xfs_inumbers - consulta información de asignación para grupos de inodos XFS

SINOPSIS

#include <xfs/xfs_fs.h>

int ioctl(int fd, XFS_IOC_INUMBERS, struct xfs_inumbers_req *arg);

DESCRIPCIÓN

Consulta información de asignación de inodos para grupos de inodos XFS. Este ioctl utiliza struct xfs_inumbers_req para configurar una transferencia masiva desde el kernel:


struct xfs_inumbers_req {
	struct xfs_bulk_ireq    hdr;
	struct xfs_inumbers     inumbers[];
};

Ver más abajo la definición de la estructura xfs_inumbers.


struct xfs_bulk_ireq {
	uint64_t                ino;
	uint32_t                flags;
	uint32_t                icount;
	uint32_t                ocount;
	uint32_t                agno;
	uint64_t                reserved[5];
};

hdr describe la información a consultar. El diseño y el comportamiento se documentan en la página del manual de ioctl_xfs_bulkstat(2) y no se discutirán más aquí.

inumbers es un array de struct xfs_inumbers que se describe a continuación. El array debe tener al menos icount elementos.


struct xfs_inumbers {
	uint64_t                xi_startino;
	uint64_t                xi_allocmask;
	uint8_t                 xi_alloccount;
	uint8_t                 xi_version;
	uint8_t                 xi_padding[6];
};

Esta estructura describe la información de uso de inodos para un grupo de 64 números de inodo consecutivos.

xi_startino es el primer número de inodo de este grupo.

xi_allocmask es una máscara de bits que indica qué inodos en este grupo están asignados. Para aclarar, el bit N está establecido si el inodo xi_startino+N está asignado.

xi_alloccount es el número de inodos en este grupo que están asignados. Esto debe ser igual al recuento de bits de (xi_allocmask).

xi_version es la versión de esta estructura de datos. El kernel la establecerá en XFS_INUMBERS_VERSION_V5.

xi_padding[6] se pone a cero.

VALOR DE RETORNO

En caso de error, se devuelve -1 y errno se establece para indicar el error.

ERRORES

Los códigos de error pueden ser uno o varios de los siguientes, entre otros:

EFAULT
El kernel no pudo copiar al búfer del espacio de usuario.
EFSBADCRC
La validación de la suma de verificación de metadatos falló durante la consulta.
EFSCORRUPTED
Se encontró corrupción de metadatos durante la consulta.
EINVAL
Uno de los argumentos no era válido.
EIO
Se encontró un error de E/S durante la consulta.
ENOMEM
No había memoria suficiente para realizar la consulta.

CONFORMIDAD

Esta API es específica del sistema de archivos XFS en el kernel de Linux.

VER TAMBIÉN

ioctl(2), ioctl_xfs_bulkstat(2).
