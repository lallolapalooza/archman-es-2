ioctl_xfs_getparents(2)

Paquete: xfsprogs

Licencias: GPL-2.0-only, LGPL-2.1-only

IOCTL-XFS-GETPARENTS(2) Manual de Llamadas al Sistema IOCTL-XFS-GETPARENTS(2)

NOMBRE

ioctl_xfs_getparents - consulta la información de los padres de un directorio en XFS

SINOPSIS

#include <xfs/xfs_fs.h>

int ioctl(int fd, XFS_IOC_GETPARENTS, struct xfs_getparents *arg);

int ioctl(int fd, XFS_IOC_GETPARENTS_BY_HANDLE, struct xfs_getparents_by_handle *arg);

DESCRIPCIÓN

Este comando se utiliza para recuperar los punteros a los padres del directorio, ya sea del archivo actualmente abierto o de un manejador de archivo. Los punteros a los padres apuntan hacia arriba en el árbol de directorios desde un archivo hijo hacia los directorios padres. Cada entrada en un directorio padre debe tener un puntero a padre correspondiente en el hijo.

Los programas que llaman a esta función deben asignar un búfer de memoria grande e inicializar una cabecera con la siguiente forma:


struct xfs_getparents {
	struct xfs_attrlist_cursor  gp_cursor;
	__u16                       gp_iflags;
	__u16                       gp_oflags;
	__u32                       gp_bufsize;
	__u64                       __pad;
	__u64                       gp_buffer;
};
struct xfs_getparents {
	struct xfs_handle           gph_handle;
	struct xfs_getparents       gph_request;
};

El campo gp_cursor sigue el progreso de la iteración a través de los punteros a los padres. Los programas que llaman a esta función deben inicializarlo a cero antes de la primera llamada al sistema y no deben tocarlo después de eso.

El campo gp_iflags controla el comportamiento de la operación de consulta y proporciona más información sobre el resultado de la operación. Actualmente no hay banderas de entrada definidas; este campo debe ser cero.

El campo gp_oflags contiene información sobre la consulta en sí. Las posibles banderas de salida son:

XFS_GETPARENTS_OFLAG_ROOT
El archivo consultado era el directorio raíz.
XFS_GETPARENTS_OFLAG_DONE
No hay más punteros a los padres para consultar.

El campo __pad debe ser cero.

El campo gp_bufsize debe establecerse al tamaño del búfer, en bytes.

El campo gp_buffer debe apuntar a un búfer de salida para los registros de punteros a los padres.

Los registros de punteros a los padres se devuelven en la siguiente forma:


struct xfs_getparents_rec {
	struct xfs_handle           gpr_parent;
	__u16                       gpr_reclen;
	char                        gpr_name[];
};

El campo gpr_parent es un manejador de archivo que se puede utilizar para abrir el directorio padre.

El campo gpr_reclen se establecerá al número de bytes utilizados por este registro padre.

El arreglo gpr_name se establecerá a una secuencia de bytes terminada en NULL que representa el nombre de archivo almacenado en el puntero al padre. Si el nombre es una cadena de longitud cero, el archivo consultado no tiene padres.

PROGRAMA DE EJEMPLO

Los programas que llaman a esta función deben asignar un búfer de memoria grande, inicializar la estructura de cabecera a ceros, establecer gp_bufsize al tamaño del búfer y llamar al ioctl. La bandera XFS_GETPARENTS_OFLAG_DONE se establecerá en gp_flags cuando no haya más punteros a los padres para leer. El siguiente código es un ejemplo de uso de XFS_IOC_GETPARENTS:

#include <stdio.h>
#include <string.h>
#include <errno.h>
#include <xfs/linux.h>
#include <xfs/xfs.h>
#include <xfs/xfs_types.h>
#include <xfs/xfs_fs.h>
int main() {
	struct xfs_getparents gp = { };
	struct xfs_getparents_rec *gpr;
	int error, fd;
	gp.gp_buffer = (uintptr_t)malloc(65536);
	if (!gp.gp_buffer) {
		perror("malloc");
		return 1;
	}
	gp->gp_bufsize = 65536;
	fd = open("/mnt/test/foo.txt", O_RDONLY | O_CREAT);
	if (fd  == -1)
		return errno;
	do {
		error = ioctl(fd, XFS_IOC_GETPARENTS, gp);
		if (error)
			return error;
		for (gpr = xfs_getparents_first_rec(&gp);
		     gpr != NULL;
		     gpr = xfs_getparents_next_rec(&gp, gpr)) {
			if (gpr->gpr_name[0] == 0)
				break;
			printf("inode		= %llu\n",
					gpr->gpr_parent.ha_fid.fid_ino);
			printf("generation	= %u\n",
					gpr->gpr_parent.ha_fid.fid_gen);
			printf("name		= \"%s\"\n\n",
					gpr->gpr_name);
		}
	} while (!(gp.gp_flags & XFS_GETPARENTS_OFLAG_DONE));
	return 0;
}

VALOR DE RETORNO

En caso de error, se devuelve -1, y errno se establece para indicar el error.

ERRORES

Los códigos de error pueden ser uno de los siguientes, pero no se limitan a ellos:

EFSBADCRC
La validación de la suma de comprobación de los metadatos falló al realizar la consulta.
EFSCORRUPTED
Se encontró corrupción de metadatos al realizar la consulta.
EINVAL
Uno o más de los argumentos especificados no es válido.
EMSGSIZE
El búfer de registros no era lo suficientemente grande como para almacenar ni siquiera un registro.
ENOMEM
No hay suficiente memoria para recuperar los punteros a los padres.
EOPNOTSUPP
No se admiten las reparaciones del objeto de metadatos solicitado.
EROFS
El sistema de archivos es de solo lectura y se solicitó una reparación.
ESHUTDOWN
El sistema de archivos se ha apagado debido a errores anteriores.
EIO
Se encontró un error de E/S al realizar la consulta.

CONFORME A

Esta API es específica del sistema de archivos XFS en el kernel de Linux.
