NOMBRE

io_uring_prep_msg_ring - enviar un mensaje a otro anillo

SINOPSIS

#include <liburing.h>
void io_uring_prep_msg_ring(struct io_uring_sqe *sqe,
                        int fd,
                        unsigned int len,
                        __u64 data,
                        unsigned int flags);
void io_uring_prep_msg_ring_cqe_flags(struct io_uring_sqe *sqe,
                        int fd,
                        unsigned int len,
                        __u64 data,
                        unsigned int flags,
                        unsigned int cqe_flags);

DESCRIPCIÓN

io_uring_prep_msg_ring(3) prepara el envío de un CQE a un descriptor de archivo io_uring. La entrada de la cola de envío sqe se configura para usar el descriptor de archivo fd, que debe identificar un contexto io_uring, para publicar un CQE en ese anillo donde el campo res del CQE de destino contendrá el contenido de len y el user_data de data con los indicadores modificadores de solicitud establecidos por flags. Actualmente no hay modificadores de indicadores válidos, este campo debe contener 0.

El anillo de destino puede ser cualquier anillo al que el usuario tenga acceso, incluso el propio anillo. Esta solicitud se puede utilizar para pasar mensajes simples a otro anillo, lo que permite transferir 32+64 bits de datos a través de los campos len y data. El caso de uso puede ser cualquier cosa, desde simplemente despertar a alguien que espera en el anillo de destino, hasta pasar mensajes entre los dos anillos.

io_uring_prep_msg_ring_cqe_flags(3) es similar a io_uring_prep_msg_ring(3). Pero tiene un parámetro adicional cqe_flags, que se utiliza para establecer el campo flags en el lado del CQE. De esta manera, puede establecer el campo de indicadores del CQE cqe->flags al enviar un mensaje. Tenga en cuenta que io_uring podría potencialmente establecer bits adicionales en este campo.

VALOR DE RETORNO

Ninguno

ERRORES

Estos son los errores que se informan en el campo res del CQE.

-ENOMEM
El kernel no pudo asignar memoria para la solicitud.
-EINVAL
Uno de los campos establecidos en el SQE era inválido.
-EBADFD
El descriptor pasado en fd no se refiere a un descriptor de archivo io_uring, o el anillo está en un estado deshabilitado.
-EOVERFLOW
El kernel no pudo completar un CQE en el anillo de destino. Esto puede suceder si el anillo CQ de destino está en un estado de desbordamiento y el kernel no pudo asignar memoria para una nueva entrada CQE.
