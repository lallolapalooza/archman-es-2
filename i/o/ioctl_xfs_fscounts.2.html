IOCTL-XFS-FSCOUNTS(2) Manual de llamadas al sistema IOCTL-XFS-FSCOUNTS(2)

NOMBRE

ioctl_xfs_fscounts - consulta la información de contadores de resumen de XFS

SINOPSIS

#include <xfs/xfs_fs.h>

int ioctl(int fd, XFS_IOC_FSCOUNTS, struct xfs_fsop_counts *arg);

DESCRIPCIÓN

Consulta los contadores de resumen brutos del sistema de archivos. A diferencia de statvfs(3), los valores devueltos aquí son los valores brutos, que no reflejan ninguna alteración o límite establecido por las cuotas de proyecto. La información del contador se transmite en una estructura de la siguiente forma:


struct xfs_fsop_counts {
	__u64   freedata;
	__u64   freertx;
	__u64   freeino;
	__u64   allocino;
};

Los campos de esta estructura son los siguientes:

freedata es el número de bloques libres del sistema de archivos en el dispositivo de datos.

freertx es el número de extensiones libres en el dispositivo de tiempo real.

freeino es el número de registros de inodo que no están en uso dentro del espacio que se les ha asignado.

allocino es el número de registros de inodo para los que se ha asignado espacio.

VALOR DE RETORNO

En caso de error, se devuelve -1 y se establece errno para indicar el error.

ERRORES

Los códigos de error pueden ser uno de los siguientes, pero no se limitan a ellos:

EFSBADCRC
La validación de la suma de comprobación de metadatos falló al realizar la consulta.
EFSCORRUPTED
Se encontró corrupción de metadatos al realizar la consulta.
EINVAL
El número de grupo de asignación especificado no es válido para este sistema de archivos.
EIO
Se encontró un error de E/S al realizar la consulta.

CONFORME A

Esta API es específica del sistema de archivos XFS en el kernel de Linux.
