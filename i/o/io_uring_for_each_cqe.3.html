NOMBRE

io_uring_for_each_cqe - iterar sobre eventos de finalización pendientes

SINOPSIS

#include <liburing.h>
io_uring_for_each_cqe(struct io_uring *ring,
                      unsigned head,
                      struct io_uring_cqe *cqe) { }

DESCRIPCIÓN

El macro io_uring_for_each_cqe(3) es una ayuda macro que itera sobre los eventos de finalización que pertenecen a ring usando head como un iterador temporal, y apunta cqe a cada evento pendiente al iterar.

Esta ayuda proporciona una forma eficiente de iterar sobre todos los eventos pendientes en el anillo, y luego avanzar el anillo CQ llamando a io_uring_cq_advance(3) con el número de CQEs consumidos cuando se termina. Dado que actualizar el estado del anillo CQ visible por el kernel implica una escritura ordenada, hacerlo una vez para un número de eventos es más eficiente que manejar cada finalización por separado y llamar a io_uring_cqe_seen(3) para cada uno de ellos.

EJEMPLO

void handle_cqes(struct io_uring *ring)
{
	struct io_uring_cqe *cqe;
	unsigned head;
	unsigned i = 0;
	io_uring_for_each_cqe(ring, head, cqe) {
		/* manejar la finalización */
		printf("cqe: %d\n", cqe->res);
		i++;
	}
	io_uring_cq_advance(ring, i);
}
