io_getevents(3)

Paquete: libaio

Licencias: LGPL-2.0-or-later

io_getevents(3) Linux AIO io_getevents(3)

NOMBRE

io_getevents, aio_pgetevents - Leer eventos resultantes de solicitudes io

SINOPSIS

#include <errno.h>

#include <libaio.h>

struct iocb {
	void		*data;
	unsigned	key;
	short		aio_lio_opcode;
	short		aio_reqprio;
	int		aio_fildes;
};

struct io_event {
        unsigned        PADDED(data, __pad1);
        unsigned        PADDED(obj,  __pad2);
        unsigned        PADDED(res,  __pad3);
        unsigned        PADDED(res2, __pad4);
};

int io_getevents(io_context_t ctx, long nr, struct io_event *events[], struct timespec *timeout);
int io_pgetevents(io_context_t ctx, long nr, struct io_event *events[], struct timespec *timeout, sigset_t *sigmask);

DESCRIPCIÓN

Intenta leer hasta nr eventos de la cola de finalización para el aio_context especificado por ctx.

VALORES DE RETORNO

Puede devolver 0 si no hay eventos disponibles y el tiempo de espera especificado por 'when' ha transcurrido, donde when == NULL especifica un tiempo de espera infinito. Tenga en cuenta que el tiempo de espera apuntado por 'when' es relativo y se actualizará si no es NULL y la operación se bloquea. Fallará con ENOSYS si no está implementado.

io_pgetevents()

La relación entre io_getevents() y io_pgetevents() es análoga a la relación entre select(2) y pselect(2): similar a pselect(2), pgetevents() permite a una aplicación esperar de forma segura hasta que ocurra un evento de finalización de aio o hasta que se capture una señal.

La siguiente llamada a io_pgetevents():


ret = io_pgetevents(ctx, min_nr, nr, events, timeout, sigmask);

es equivalente a ejecutar *atmicamente* las siguientes llamadas:


sigset_t origmask;
pthread_sigmask(SIG_SETMASK, &sigmask, &origmask);
ret = io_getevents(ctx, min_nr, nr, events, timeout);
pthread_sigmask(SIG_SETMASK, &origmask, NULL);

Vea la descripción de pselect(2) para una explicación de por qué io_pgetevents() es necesario.

Si el argumento sigmask se especifica como NULL, no se realiza ninguna manipulación de la máscara de señales (y, por lo tanto, io_pgetevents() se comporta igual que io_getevents()).

ERRORES

EINVAL
Si ctx es inválido, si min_nr está fuera de rango, si nr está fuera de rango, si when está fuera de rango.
EFAULT
Si alguna de la memoria especificada es inválida.
