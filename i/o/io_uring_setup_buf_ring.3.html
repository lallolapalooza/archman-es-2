NOMBRE

io_uring_setup_buf_ring - configurar y registrar un anillo de búferes para búferes proporcionados

SINOPSIS

#include <liburing.h>
struct io_uring_buf_ring *io_uring_setup_buf_ring(struct io_uring *ring,
                                                  unsigned int nentries,
                                                  int bgid,
                                                  unsigned int flags,
                                                  int *err);

DESCRIPCIÓN

La función io_uring_setup_buf_ring(3) registra un anillo de búferes compartido para ser usado con búferes proporcionados. Para los tipos de solicitud que lo soportan, los búferes proporcionados se entregan al anillo y uno es seleccionado por una solicitud si tiene IOSQE_BUFFER_SELECT establecido en las flags de la SQE, cuando la solicitud está lista para recibir datos. Esto permite tanto una propiedad clara de la vida útil del búfer, como una forma de tener más operaciones de lectura/recepción en vuelo que búferes disponibles.

El argumento ring debe ser un puntero al anillo para el cual se está registrando el anillo de búferes proporcionados, nentries es el número de entradas solicitadas en el anillo de búferes. Este argumento debe ser una potencia de 2 en tamaño, y puede ser de hasta 32768. bgid es el ID del grupo de búferes elegido, flags son banderas modificadoras para la operación, y *err es un puntero a un entero para el valor de error si alguna parte de la asignación y registro del anillo falla.

El argumento flags puede establecerse en uno de los siguientes valores:

IOU_PBUF_RING_INC
Los búferes en este anillo se pueden consumir incrementalmente. Con el consumo parcial, cada finalización de un ID de búfer dado continuará donde lo dejó el anterior, o desde el principio si aún no se han visto finalizaciones. Cuando se esperan más finalizaciones para un ID de búfer dado, la CQE tendrá IORING_CQE_F_BUF_MORE establecido en el miembro flags. Disponible desde la versión 6.12.

En segundo plano, esta función utiliza io_uring_register_buf_ring(3) para registrar el anillo, y se encarga de la asignación del anillo en lugar de dejar que la aplicación lo codifique.

Para anular el registro y liberar un ID de grupo de búferes configurado con esta función, la aplicación debe llamar a io_uring_free_buf_ring(3).

Disponible desde la versión 5.19.

VALOR DE RETORNO

En caso de éxito, io_uring_setup_buf_ring(3) devuelve un puntero al anillo de búferes. En caso de fallo, devuelve NULL y establece *err a -errno.

NOTAS

Tenga en cuenta que incluso si el kernel soporta esta característica, el registro de un anillo de búferes proporcionados puede fallar con -EINVAL si el host es una arquitectura de 32 bits y la memoria que se pasa reside en memoria alta.
