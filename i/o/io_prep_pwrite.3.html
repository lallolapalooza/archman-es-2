NOMBRE

io_prep_pwrite - Configura iocb para escrituras asíncronas

SINOPSIS

#include <errno.h>

#include <libaio.h>

inline void io_prep_pwrite(struct iocb *iocb, int fd, void *buf, size_t count, long long offset);

struct iocb {
	void		*data;
	unsigned	key;
	short		aio_lio_opcode;
	short		aio_reqprio;
	int		aio_fildes;
};

DESCRIPCIÓN

io_prep_write() es una función de conveniencia para configurar escrituras paralelas.

Se escriben los primeros iocb->u.c.nbytes = count bytes del archivo para el que iocb->aio_fildes = fd es un descriptor, desde el búfer que comienza en iocb->u.c.buf = buf. La escritura comienza en la posición absoluta ioc->u.c.offset = offset en el archivo.

Esta función devuelve el control inmediatamente. Para programar la operación, se debe llamar a la función io_submit(3).

Las operaciones asíncronas simultáneas que utilizan el mismo iocb producen resultados indefinidos.

VALORES DE RETORNO

Ninguno.

ERRORES

Ninguno.
