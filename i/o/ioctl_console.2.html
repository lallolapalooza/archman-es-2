NOMBRE

ioctl_console - ioctls para terminales de consola y consolas virtuales

SINOPSIS

#include <sys/ioctl.h>
int ioctl(int fd, unsigned long op, ...);

VALOR DE RETORNO

En caso de éxito, se devuelve 0 (excepto donde se indique). En caso de error, se devuelve -1 y se establece errno para indicar el error.

ESTÁNDARES

Linux.

ADVERTENCIAS

No considere esta página del manual como documentación de los ioctls de la consola de Linux. Esto se proporciona solo para los curiosos, como alternativa a la lectura del código fuente. Los ioctls son internos de Linux no documentados, que pueden ser cambiados sin previo aviso. (Y de hecho, esta página describe más o menos la situación a partir de la versión del kernel 1.1.94; hay muchas diferencias menores y no tan menores con versiones anteriores.)

Muy a menudo, los ioctls se introducen para la comunicación entre el kernel y un programa específico muy conocido (fdisk, hdparm, setserial, tunelp, loadkeys, selection, setfont, etc.), y su comportamiento se modificará cuando sea requerido por este programa en particular.

NAME

ioctl_console - control de consola

SYNOPSIS

#include <sys/ioctl.h>

DESCRIPTION

El comando ioctl, llamado en un descriptor de archivo que se refiere a un dispositivo de consola (generalmente /dev/tty0 o un dispositivo tty real como /dev/tty1), se utiliza para controlar varias características del dispositivo.

La llamada al sistema ioctl toma tres argumentos:

int fd: el descriptor de archivo del dispositivo de consola.

unsigned long request: el código de solicitud específico de la consola.

...: datos adicionales para la solicitud, si los hay.

Hay muchas solicitudes ioctl definidas para dispositivos de consola. Algunas de las más comunes incluyen:

  • KDGKBMODE: Obtiene el modo del teclado.
  • KDSKBMODE: Establece el modo del teclado. Los modos comunes son K_UNICODE (predeterminado), K_XLATE (traduce las teclas según la tabla de mapeo del teclado) y K_RAW (raw keycodes).
  • KDGETKMAP: Obtiene el mapa del teclado.
  • KDSETKMAP: Establece el mapa del teclado.
  • KDGKBENT: Obtiene una entrada específica del mapa del teclado.
  • KDSKBENT: Establece una entrada específica del mapa del teclado.
  • KDGKBDIACR: Obtiene los códigos de acción de entrada del teclado para caracteres diacríticos.
  • KDSKBDIACR: Establece los códigos de acción de entrada del teclado para caracteres diacríticos.
  • KDGKBACCPTR: Obtiene la estructura de aceleración del puntero del teclado.
  • KDSKBACCPTR: Establece la estructura de aceleración del puntero del teclado.
  • VT_OPENQRY: Consulta la siguiente VT (consola virtual) libre.
  • VT_GETMODE: Obtiene el modo de la consola virtual.
  • VT_SETMODE: Establece el modo de la consola virtual.
  • VT_GETSTATE: Obtiene el estado de las consolas virtuales.
  • VT_SENDSIG: Envía una señal a un proceso que se ejecuta en una consola virtual específica.
  • CON_GET_TYPE: Obtiene el tipo de consola.
  • CON_GET_FLAGS: Obtiene las banderas de la consola.
  • TIOCLINETERM: Borra la línea actual en la consola.
  • TIOCGWINSZ: Obtiene el tamaño de la ventana (terminal).
  • TIOCSWINSZ: Establece el tamaño de la ventana (terminal).

Consulte la documentación del kernel de Linux (a menudo disponible en /usr/src/linux/Documentation/admin-guide/devices.txt o en línea) para obtener una lista completa de las solicitudes ioctl admitidas y sus argumentos.

Estas solicitudes generalmente requieren privilegios de superusuario (root) para ser ejecutadas.

RETURN VALUE

En caso de éxito, ioctl devuelve 0. En caso de error, devuelve -1 y errno se establece para indicar el error.

STANDARDS

Estas llamadas ioctl son específicas del kernel de Linux y no forman parte de ningún estándar POSIX.

CAVEATS

El uso de llamadas ioctl directamente puede ser peligroso si no se hace correctamente. Manipular la configuración de la consola puede llevar a un estado inutilizable si se cometen errores. La mayoría de las aplicaciones de usuario no necesitan interactuar directamente con estas llamadas ioctl.

Se necesita acceso de root para la mayoría de las solicitudes ioctl de consola.
