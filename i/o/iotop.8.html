IOTOP(8) Manual del Administrador del Sistema IOTOP(8)

NOMBRE

iotop - monitor simple de E/S similar a top

SINOPSIS

iotop [OPCIONES]

DESCRIPCIÓN

iotop observa la información de uso de E/S disponible en el kernel de Linux (requiere 2.6.20 o posterior) y muestra una tabla del uso actual de E/S por procesos o hilos en el sistema. Como mínimo, deben estar habilitadas las opciones CONFIG_TASK_DELAY_ACCT, CONFIG_TASK_IO_ACCOUNTING, CONFIG_TASKSTATS y CONFIG_VM_EVENT_COUNTERS en la configuración de compilación de su kernel de Linux.

Ejecutar iotop como usuario no root es posible añadiendo la capacidad NET_ADMIN. Esto se puede hacer, por ejemplo:

$ sudo setcap 'cap_net_admin+eip' <ruta-a>/iotop

Tenga en cuenta que esto también permitirá a otros usuarios ejecutarlo y obtener acceso a información que normalmente no debería estar disponible para ellos.

iotop muestra columnas para el ancho de banda de E/S de lectura y escritura por cada proceso/hilo durante el período de muestreo. También muestra el porcentaje de tiempo que el hilo/proceso pasó mientras intercambiaba memoria (swapping) y mientras esperaba E/S. Para cada proceso, se muestra su prioridad de E/S (clase/nivel).

Además, el ancho de banda total de E/S de lectura y escritura durante el período de muestreo se muestra en la parte superior de la interfaz. Los valores Total DISK READ (Lectura Total de Disco) y Total DISK WRITE (Escritura Total de Disco) representan el ancho de banda total de lectura y escritura entre los procesos y los hilos del kernel por un lado, y el subsistema de dispositivos de bloque del kernel por el otro. Mientras que los valores Current DISK READ (Lectura Actual de Disco) y Current DISK WRITE (Escritura Actual de Disco) representan los anchos de banda correspondientes para la E/S de disco actual entre el subsistema de dispositivos de bloque del kernel y el hardware subyacente (HDD, SSD, etc.). Por lo tanto, los valores Total y Current pueden no ser iguales en ningún momento dado debido al almacenamiento en caché de datos y a la reorganización de operaciones de E/S que ocurren dentro del kernel de Linux.

Use las flechas izquierda y derecha para seleccionar la columna de ordenación, r o espacio para invertir el orden de clasificación, o para alternar la opción --only (esto usa los valores visibles de la columna GRAPH o la columna IO en caso de que la columna GRAPH esté oculta), p para alternar la opción --processes, a para ciclar entre las opciones --accumulated, --accum-bw y el funcionamiento normal, i para cambiar la prioridad de un hilo o del hilo de un proceso, f para cambiar el filtrado por UID/PID (opciones --user y --pid), 1-9 para alternar la visibilidad de la columna respectiva, 0 para mostrar todas las columnas, flechas arriba/abajo, teclas av-pág/re-pág/inicio/fin para desplazarse y q para salir. Cualquier tecla no reconocida será ignorada.

Todos los procesos o hilos que han salido se muestran en gris durante el mismo tiempo que es visible en la columna GRAPH o 3 segundos cuando está oculta. Los puntos de datos inválidos en la columna GRAPHS se muestran invertidos o con la letra x (ver opción --dead-x y acceso directo x). Al usar caracteres unicode, cada posición contiene dos puntos de datos y solo las posiciones con dos puntos de datos inválidos se invierten.

Es posible que los hilos de un proceso tengan una prioridad diferente a la de su proceso principal. Esto se muestra con ! en la columna PRIO del proceso principal, por ejemplo !be/4.

La actividad de los hilos siempre se agrega y se muestra dentro del proceso principal.

Al mostrar hilos, siempre aparecen debajo de su proceso principal y se ordenan de la misma manera que los procesos.

Hay dos formas de cambiar la prioridad de E/S de un proceso o hilo: presione i y use las flechas para seleccionar el proceso o hilo de los visibles en pantalla, o presione i y escriba su TID (PID y TID tienen el mismo valor para el proceso principal). Luego use tab y las flechas para cambiar el valor de prioridad y confirme con enter. Los accesos directos esc o q cancelarán este modo.

Para cambiar los filtros de UID y PID, presione f y use tab para seleccionar el campo UID o PID, luego escriba el ID numérico o n para eliminar el filtro y confirme con enter. El filtrado siempre se realiza por TID porque es único. Tenga en cuenta que para el proceso principal, el PID es el mismo que el TID. Los accesos directos esc o q cancelarán este modo.

A partir del kernel de Linux 5.14.x, task_delayacct es configurable en tiempo de ejecución y está desactivado por defecto. Esta configuración se puede cambiar en modo interactivo con el acceso directo Ctrl-T. En modo batch, se imprime una advertencia cuando la configuración está DESACTIVADA. Desde la línea de comandos se puede habilitar con:

$ sudo sysctl kernel.task_delayacct=1

y deshabilitar de nuevo con:

$ sudo sysctl kernel.task_delayacct=0

Es recomendable mantener esta opción desactivada cuando no esté usando este o otro programa de monitoreo, ya que cuando está habilitada tiene algún efecto en el rendimiento del sistema.

OPCIONES

-v, --version
Mostrar el número de versión y salir
-h, --help
Mostrar información de uso y salir
-H, --help-type=TIPO
Establece el tipo de ayuda interactiva que se muestra. Los valores aceptados para TIPO son none, win e inline.
-o, --only
Mostrar solo los procesos o hilos que realmente están realizando E/S, en lugar de mostrar todos los procesos o hilos. Esto se puede alternar dinámicamente presionando o
--no-only
Mostrar todos los procesos o hilos
-b, --batch
Activar el modo no interactivo. Útil para registrar el uso de E/S a lo largo del tiempo
-n NUM, --iter=NUM
Establecer el número de iteraciones antes de salir (nunca salir por defecto). Esto es más útil en modo no interactivo
-d SEC, --delay=SEC
Establecer el retraso entre iteraciones en segundos (1 segundo por defecto). Acepta valores no enteros como 1.1 segundos
-p PID, --pid=PID
Un ID de proceso/hilo a monitorizar (todos por defecto)
-u USUARIO, --user=USUARIO
Un ID de usuario a monitorizar (todos por defecto). El valor siempre se resolverá primero a menos que vaya precedido por +, en cuyo caso se trata únicamente numéricamente. Los valores que no se resuelven pero que parecen numéricos se usan como numéricos
-P, --processes
Mostrar solo procesos. Normalmente iotop muestra procesos y todos los hilos
--no-processes
Mostrar procesos y todos los hilos
-a, --accumulated
Mostrar E/S acumulada en lugar de ancho de banda. En este modo, iotop muestra la cantidad de E/S que los procesos han realizado desde que el proceso o iotop comenzaron. Tenga en cuenta que esta opción y --accum-bw son exclusivas y se desactivarán mutuamente
--no-accumulated
Mostrar ancho de banda (útil al cambiar el archivo de configuración con --write)
-A, --accum-bw
Mostrar E/S acumulada como ancho de banda para todo el período de muestreo. En este modo, iotop muestra la cantidad de E/S por segundo para todo el período desde que el proceso o iotop comenzaron. Tenga en cuenta que esta opción y --accumulated son exclusivas y se desactivarán mutuamente
--no-accum-bw
Mostrar ancho de banda (útil al cambiar el archivo de configuración con --write)
-k, --kilobytes
Usar kilobytes en lugar de una unidad amigable para humanos. Este modo es útil al programar el modo batch de iotop. En lugar de elegir la unidad más apropiada, iotop mostrará todos los tamaños en kilobytes
--no-kilobytes
Usar unidades amigables para humanos
-t, --time
Añadir una marca de tiempo en cada línea (implica --batch). Cada línea será precedida por la hora actual
-c, --fullcmdline
Muestra
ruta completa del archivo y parámetros de los procesos
--no-fullcmdline
Mostrar solo los nombres de los procesos
-1, --hide-pid
Ocultar la columna PID/TID
--show-pid
Mostrar la columna PID/TID
-2, --hide-prio
Ocultar la columna PRIO
--show-prio
Mostrar la columna PRIO
-3, --hide-user
Ocultar la columna USER
--show-user
Mostrar la columna USER
-4, --hide-read
Ocultar la columna DISK READ
--show-read
Mostrar la columna DISK READ
-5, --hide-write
Ocultar la columna DISK WRITE
--show-write
Mostrar la columna DISK WRITE
-6, --hide-swapin
Ocultar la columna SWAPIN
--show-swapin
Mostrar la columna SWAPIN
-7, --hide-io
Ocultar la columna IO
--show-io
Mostrar la columna IO
-8, --hide-graph
Ocultar la columna GRAPH
--show-graph
Mostrar la columna GRAPH
-9, --hide-command
Ocultar la columna COMMAND
--show-command
Mostrar la columna COMMAND
-g TYPE, --grtype=TYPE
Establecer la fuente de datos de la columna GRAPH. Los valores aceptados para TYPE son io, r, w, rw y sw.
-R, --reverse-graph
Invertir la dirección del GRÁFICO - mostrar los valores más recientes en el lado derecho
--no-reverse-graph
No invertir la dirección del GRÁFICO - mostrar los valores más recientes en el lado izquierdo
-q, --quiet
Suprimir los encabezados antes de cada ejecución (implica --batch). Esta opción puede especificarse hasta tres veces para suprimir la salida de diferentes líneas de encabezado:
-q
los nombres de las columnas solo se imprimen en la primera iteración,
-qq
los nombres de las columnas nunca se imprimen,
-qqq
el resumen de E/S nunca se imprime
-x, --dead-x
Mostrar procesos/hilos finalizados con la letra x en lugar de fondo invertido
--no-dead-x
Mostrar procesos/hilos finalizados con fondo invertido
-e, --hide-exited
Ocultar procesos finalizados
--show-exited
Mostrar procesos finalizados
-l, --no-color
No colorear los valores
--color
Colorear los valores. Esto anulará el efecto de la variable de entorno NO_COLOR cuando se especifique explícitamente en la línea de comandos.
-T, --hide-time
No mostrar el reloj de tiempo en la esquina superior derecha
--show-time
Mostrar el reloj de tiempo en la esquina superior derecha
--si
Usar unidades SI de 1000 al imprimir valores. El valor predeterminado es no SI 1024
--no-si
Usar unidades no SI de 1024 al imprimir valores
--threshold=1..10
Establecer el umbral para cambiar a la siguiente unidad. El valor predeterminado es 2
--ascii
Deshabilitar el uso de Unicode
--unicode
Usar caracteres de dibujo Unicode
-N, --inverse
Usar interfaz inversa (negro sobre blanco)
--filter=REGEX
Filtrar procesos por TID y COMMAND. Esto solo mostrará los procesos donde TID o COMMAND coincidan con el REGEX.
-W, --write
Fusionar las opciones anteriores con la configuración actual, guardar la configuración y salir. Tenga en cuenta que todas las opciones posteriores a esta serán ignoradas.

ATAJOS DE TECLADO

q, Q
Salir
W
Guardar la configuración actual en el archivo de configuración en un lugar que cumpla con la Especificación de Directorio Base XDG. La ruta respectiva se crea en caso de que no exista. En caso de error al crear o acceder al archivo de configuración, el error se ignora silenciosamente y la configuración no se guarda.
$XDG_CONFIG_HOME/iotop/iotoprc - si la variable de entorno XDG_CONFIG_HOME está definida.
$HOME/.config/iotop/iotoprc - si la variable de entorno XDG_CONFIG_HOME no está definida pero HOME lo está.
.config/iotop/iotoprc - si ni XDG_CONFIG_HOME ni HOME están definidos.
D
Restablecer todos los valores a sus valores predeterminados
<espacio>, r
Alternar el orden de clasificación
<inicio>
Desplazarse hasta la parte superior de la lista
<fin>
Desplazarse hasta la parte inferior de la lista
<re-pág>
Desplazarse una pantalla hacia arriba
<av-pág>
Desplazarse una pantalla hacia abajo
<arriba>
Desplazarse una línea hacia arriba
<abajo>
Desplazarse una línea hacia abajo
<derecha>
Ordenar por la siguiente columna
<izquierda>
Ordenar por la columna anterior
<esc>
Cancelar la selección de ionice o filtro. En caso de que solo esté abierta la ventana de ayuda, entonces cerrarla
o, O
Alternar la visualización de solo procesos con actividad de E/S
p, P
Alternar la visualización de procesos/hilos
a, A
Ciclar entre mostrar valores acumulados/ancho de banda acumulado/actuales
?
Alternar la visualización de ayuda en línea
h, H
Alternar la visualización de ayuda de la ventana
c, C
Alternar la visualización de la línea de comandos completa
1, 2, 3, 4, 5, 6, 7, 8, 9
Alternar la visualización de la columna (el número de columna corresponde al atajo)
0
Mostrar todas las columnas
g, G
Ciclar la fuente del GRÁFICO (IO=IO, R=DISK READ , W=DISK WRITE, R+W=DISK READ+DISK WRITE, SW=SWAPIN). Usar g ciclará hacia adelante y G ciclará hacia atrás.
R
Alternar la dirección inversa del GRÁFICO
i, I
Aplicar IOnice a un proceso/hilo (depende del modo de visualización de procesos/hilos)
f, F
Cambiar los filtros UID y PID
u, U
Alternar el uso de caracteres Unicode/ASCII para el gráfico pseudo
l, L
Alternar el coloreo de los valores
n, N
Alternar la interfaz inversa (negro sobre blanco)
x, X
Alternar el modo de visualización de procesos/hilos finalizados entre la letra x y fondo invertido
e, E
Alternar la visualización de procesos finalizados
T
Alternar la visualización del reloj de tiempo en la esquina superior derecha
s, S
Alternar la congelación de la recopilación de datos
Ctrl-B, b
Alternar unidades SI
Ctrl-R, t
Ciclar el umbral de la unidad
Ctrl-T
Alternar el sysctl del kernel task_delayacct
Ctrl-L
Redibujar la pantalla
/
Cambiar la expresión regular de búsqueda. Mientras se edita la expresión regular de búsqueda, hay un indicador junto a ella que muestra si la expresión es válida. La búsqueda se confirma con <intro> o se cancela con <esc>.

Lista de atajos en el editor:

<esc>
Cancelar la edición y eliminar el filtro de expresión regular
<intro>
Confirmar la expresión regular actual y salir del modo de edición. En caso de que la expresión regular esté vacía o sea inválida, coincidirá con todo.
Alt/Meta-<retroceso>, Ctrl-W
Eliminar una palabra desde el cursor hacia la izquierda
Alt/Meta-D
Eliminar una palabra desde el cursor hacia la derecha
Alt/Meta-B, Ctrl-<izquierda>
Mover el cursor al principio de la palabra a la izquierda
Alt/Meta-F, Ctrl-<derecha>
Mover el cursor después del final de la palabra a la derecha
Ctrl-A, <inicio>
Mover el cursor a la posición más a la izquierda
Ctrl-E, <fin>
Mover el cursor después del último carácter
Ctrl-B, <izquierda>
Mover el cursor a la izquierda
Ctrl-F, <derecha>
Mover el cursor a la derecha
Ctrl-H, <retroceso>
Eliminar el carácter a la izquierda del cursor
Ctrl-D, <supr>
Eliminar el carácter bajo el cursor
Ctrl-K

Ctrl-U

[cualquier-otra-tecla]
Los caracteres no imprimibles se ignoran. Los caracteres normales se insertan antes del carácter bajo el cursor. Las secuencias UTF-8 se analizan y se tratan como un solo carácter. Los caracteres combinantes de Unicode se añadirán al carácter bajo el cursor.

ENTORNO

NO_COLOR
Según la recomendación de https://www.no-color.org/ iotop respeta el contenido de la variable de entorno NO_COLOR y cuando se establece en una cadena no vacía, se suprime toda la salida con color.
HOME, XDG_CONFIG_HOME
Se utilizan para determinar la ruta del archivo de configuración. Véase el atajo W para más detalles.
IOTOP_NO_RENICE
Desactiva el atajo i . El usuario no podrá cambiar los valores nice de los procesos.
