FBB::IOmmapStream(3bobcat) std::istream usando FBB::MmapBuf como streambuf FBB::IOmmapStream(3bobcat)

NOMBRE

FBB::IOmmapStream - Flujo de entrada usando mmap(2) a través de FBB::MmapBuf

SINOPSIS

#include <bobcat/iommapstream>

Opción de enlazado: -lbobcat

DESCRIPCIÓN

Los objetos FBB::IOmmapStream se utilizan para leer o escribir información en archivos que se ponen a disposición en el espacio de direcciones virtuales del proceso que los invoca. El uso del espacio de direcciones virtuales lo gestiona la clase heredada de forma privada FBB::MmapBuf (std::streambuf ).

Al mapear archivos en el espacio de direcciones virtuales del proceso, el tiempo necesario para procesar dichos archivos se reduce drásticamente en la mayoría de los casos.

Se lanza una excepción std::exception y se escribe un mensaje de error en cerr si la clase base FBB::MmapBuf no puede determinar el tamaño del archivo especificado, o cuando no se puede realizar el (des)mapeo.

ESPACIO DE NOMBRES

FBB
Todos los constructores, miembros, operadores y manipuladores mencionados en esta página de manual se definen en el espacio de nombres FBB.

HEREDA DE

std::iostream, y de forma privada de FBB::MmapBuf.

CONSTRUCTORES

o
IOmmapStream():
El constructor por defecto simplemente construye un objeto IOmmapStream vacío. Para convertirlo en un objeto utilizable, use la asignación por movimiento;
o
IOmmapStream(std::string const &fname, char const *bufSize = 0, std::ios::openmode openMode = std::ios::out | std::ios::in, mode_t mode = 0644):
El constructor inicializa el objeto IOmmapStream para un archivo llamado fname.

El parámetro openMode especifica cómo se utiliza fname . Se admiten los modos estándar ios::in, ios::out, ios::trunc, ios::app, y ios::ate .

Por defecto, IOmmapStream usa un tamaño de búfer de mapeo de 10 veces el tamaño de página estándar (véase sysconf(3)y el miembro pageSize más abajo). El tamaño del búfer de mapeo también se puede especificar usando el parámetro bufSize . Para especificarlo, use un valor seguido de K, M, o G, que representan, respectivamente, 1024, 1024 * 1024 y 1024 * 1024 * 1024 bytes. El tamaño final del búfer es al menos igual al tamaño de página estándar. Cuando se especifica un valor más grande, el tamaño de búfer utilizado se establece en especificado / pageSize * pageSize.

El parámetro mode especifica el modo de acceso de usuario/grupo/otros que se utiliza cuando el archivo es creado por MmapBuf. Su valor por defecto especifica acceso de lectura/escritura para el usuario y de lectura para los demás. )

El constructor por movimiento y el operador de asignación por movimiento están disponibles.
El constructor de copia y el operador de asignación por copia no están disponibles.

FUNCIONES MIEMBRO

Todos los miembros de std::istream están disponibles, ya que FBB::IOmmapStream hereda de esa clase.

o
size_t bufSize() const:
devuelve el tamaño del búfer (mmap) utilizado;
o
size_t fileSize() const:
devuelve el tamaño actual del archivo utilizado. El tamaño se actualiza a un tamaño mayor cuando se escribe más allá del tamaño actual del archivo. Una vez que el objeto IOmmapStream deja de existir, el tamaño del archivo utilizado se modifica al valor actual de fileSize .
o
size_t pageSize() const:
devuelve el tamaño de página más pequeño utilizado por t(mmap).
