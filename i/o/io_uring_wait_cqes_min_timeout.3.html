NOMBRE

io_uring_wait_cqes_min_timeout - espera por completados con tiempo de espera mínimo y por lotes

SINOPSIS

#include <liburing.h>
int io_uring_wait_cqes_min_timeout(struct io_uring *ring,
                                   struct io_uring_cqe **cqe_ptr,
                                   unsigned wait_nr,
                                   struct __kernel_timespec *ts,
                                   unsigned int min_wait_usec,
                                   sigset_t *sigmask);

DESCRIPCIÓN

La función io_uring_wait_cqes_min_timeout(3) espera por completados de la cola de envío que pertenece a ring y espera por wait_nr eventos de completado, o hasta que expire el tiempo de espera ts. Los eventos de completado se almacenan en el array cqe_ptr. Si no es cero, min_wait_usec denota un tiempo de espera para el lote wait_nr.

El sigmask especifica el conjunto de señales a bloquear. Si se establece, es equivalente a ejecutar atómicamente las siguientes llamadas:


sigset_t origmask;
pthread_sigmask(SIG_SETMASK, &sigmask, &origmask);
ret = io_uring_wait_cqes_min_timeout(ring, cqe, wait_nr, ts, min_wait, NULL);
pthread_sigmask(SIG_SETMASK, &origmask, NULL);

Esto funciona como io_uring_submit_and_wait_min_timeout(3) excepto que no envía solicitudes. Consulte esa página del manual para obtener una descripción de cómo funciona la espera con tiempo mínimo.

Disponible desde la versión 6.12.

VALOR DE RETORNO

En caso de éxito, io_uring_wait_cqes_min_timeout(3) devuelve 0. En caso de fallo, devuelve -errno. Si el kernel no soporta esta funcionalidad, se devolverá -EINVAL. Consulte la nota sobre la marca de característica. El caso de fallo más común es no recibir un completado dentro del tiempo de espera especificado; en este caso se devuelve -ETIME.
