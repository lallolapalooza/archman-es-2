NOMBRE

io_uring_register_clock - configurar fuente de reloj para espera de eventos

SINOPSIS

#include <liburing.h>
int io_uring_register_clock(struct io_uring *ring,
                            struct io_uring_clock_register *arg);

DESCRIPCIÓN

La función io_uring_register_clock(3) registra qué fuente de reloj se utilizará en io_uring, cuando una aplicación espera completar eventos. El argumento ring debe apuntar al anillo en cuestión, y el argumento arg debe ser un puntero a una struct io_uring_clock_register .

El argumento arg debe completarse con la información correspondiente. Se ve así:


struct io_uring_clock_register {
    __u32 clockid;
    __u32 __resv[3];
};

El campo clockid debe contener la fuente del reloj, siendo las fuentes válidas:

CLOCK_MONOTONIC
un reloj a nivel de sistema no modificable que representa el tiempo monotónico.
CLOCK_BOOTTIME
Un reloj a nivel de sistema no modificable que es idéntico a CLOCK_MONOTONIC, excepto que también incluye cualquier tiempo en que el sistema está suspendido.

Ver clock_gettime(3) para más detalles.

Los campos __resv deben rellenarse con ceros.

Disponible desde la versión 6.12.

VALOR DE RETORNO

En caso de éxito, io_uring_register_clock(3) devuelve 0. En caso de error, devuelve -errno.
