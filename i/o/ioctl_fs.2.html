ioctl_fs(2) Manual de llamadas al sistema ioctl_fs(2)

NOMBRE

ioctl_fs - operaciones del sistema de archivos

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <linux/fs.h>  /* Definición de constantes de operación */
#include <sys/ioctl.h>
int ioctl(int fd, unsigned long op, ...);

DESCRIPCIÓN

Los siguientes valores de op están disponibles.

Compartir datos de un archivo con otro archivo

FICLONE(2const)
FICLONERANGE(2const)
FIDEDUPERANGE(2const)

Operaciones para banderas de inodo

FS_IOC_GETFLAGS(2const)
FS_IOC_SETFLAGS(2const)

Obtener o establecer una etiqueta del sistema de archivos

FS_IOC_GETFSLABEL(2const)
FS_IOC_SETFSLABEL(2const)

Obtener y/o limpiar banderas de página

PAGEMAP_SCAN(2const)

VALOR DE RETORNO

En caso de éxito, se devuelve un valor no negativo. En caso de error, se devuelve -1 y errno se establece para indicar el error.

ESTÁNDARES

Linux.

VER TAMBIÉN

ioctl(2)
