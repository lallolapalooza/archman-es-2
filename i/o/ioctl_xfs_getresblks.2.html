ioctl_xfs_getresblks(2)

IOCTL-XFS-GETRESBLKS(2) Manual de llamadas al sistema IOCTL-XFS-GETRESBLKS(2)

NOMBRE

ioctl_xfs_getresblks - consultar y establecer información de reserva de espacio libre de XFS

SINOPSIS

#include <xfs/xfs_fs.h>

int ioctl(int fd, XFS_IOC_GET_RESBLKS, struct xfs_fsop_resblks *arg);
int ioctl(int fd, XFS_IOC_SET_RESBLKS, struct xfs_fsop_resblks *arg);

DESCRIPCIÓN

Consulta o establece la información de reserva de espacio libre. Estos bloques son reservados por el sistema de archivos como último intento para prevenir fallos en la actualización de metadatos debido a espacio insuficiente. Solo el administrador del sistema puede usar estas llamadas ioctl, ya que anular los valores predeterminados es extremadamente peligroso.

Esta funcionalidad está destinada únicamente al uso por parte de los desarrolladores del sistema de archivos XFS.

La información de reserva se transmite en una estructura de la siguiente forma:


struct xfs_fsop_resblks {
	__u64  resblks;
	__u64  resblks_avail;
};

resblks es el número de bloques que el sistema de archivos intentará mantener para prevenir situaciones críticas de falta de espacio.

resblks_avail es el número de bloques reservados restantes.

VALOR DE RETORNO

En caso de error, se devuelve -1 y errno se establece para indicar el error.

ERRORES

Los códigos de error pueden ser, entre otros, los siguientes:

EFSBADCRC
La validación de la suma de verificación de metadatos falló al realizar la consulta.
EFSCORRUPTED
Se encontró corrupción de metadatos al realizar la consulta.
EINVAL
El número de grupo de asignación especificado no es válido para este sistema de archivos.
EIO
Se encontró un error de E/S al realizar la consulta.
EPERM
El llamador no tiene permiso para llamar a esta ioctl.

CONFORMIDAD

Esta API es específica del sistema de archivos XFS en el kernel de Linux.
