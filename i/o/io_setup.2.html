io_setup(2) Manual de llamadas al sistema io_setup(2)

NOMBRE

io_setup - crear un contexto de E/S asíncrono

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

Opcionalmente, Biblioteca de E/S asíncrona (libaio, -laio); véase VERSIONS.

SINTAXIS

#include <linux/aio_abi.h>          /* Define los tipos necesarios */
long io_setup(unsigned int nr_events, aio_context_t *ctx_idp);

Nota: No hay un envoltorio de glibc para esta llamada al sistema; véase VERSIONS.

DESCRIPCIÓN

Nota: esta página describe la interfaz de llamada al sistema directa de Linux. La función envoltorio proporcionada por libaio utiliza un tipo diferente para el argumento ctx_idp. Véase VERSIONS.

La llamada al sistema io_setup() crea un contexto de E/S asíncrona adecuado para procesar concurrentemente nr_events operaciones. El argumento ctx_idp no debe apuntar a un contexto AIO que ya exista y debe inicializarse a 0 antes de la llamada. Tras la creación exitosa del contexto AIO, se rellena *ctx_idp con el manejador resultante.

VALOR DE RETORNO

En caso de éxito, io_setup() devuelve 0. Para el retorno en caso de error, véase VERSIONS.

ERRORES

EAGAIN
El nr_events especificado excede el límite de eventos disponibles, como se define en /proc/sys/fs/aio-max-nr (véase proc(5)).
EFAULT
Se pasa un puntero inválido para ctx_idp.
EINVAL
ctx_idp no está inicializado, o el nr_events especificado excede los límites internos. nr_events debe ser mayor que 0.
ENOMEM
Recursos del kernel insuficientes disponibles.
ENOSYS
io_setup() no está implementado en esta arquitectura.

VERSIONS

glibc no proporciona un envoltorio para esta llamada al sistema. Podría invocarla usando syscall(2). Pero en su lugar, probablemente querrá usar el envoltorio io_setup() proporcionado por libaio.

Tenga en cuenta que el envoltorio de la función libaio usa un tipo diferente (io_context_t *) para el argumento ctx_idp. Tenga en cuenta también que el envoltorio de libaio no sigue las convenciones habituales de la biblioteca C para indicar errores: en caso de error devuelve un número de error negado (el negativo de uno de los valores listados en ERRORS). Si la llamada al sistema se invoca a través de syscall(2), entonces el valor de retorno sigue las convenciones habituales para indicar un error: -1, con errno establecido a un valor (positivo) que indica el error.

ESTANDARES

Linux.

HISTORIA

Linux 2.5.

VER TAMBIÉN

io_cancel(2), io_destroy(2), io_getevents(2), io_submit(2), aio(7)
