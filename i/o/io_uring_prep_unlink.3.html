NOMBRE

io_uring_prep_unlinkat - prepara una solicitud de unlinkat

SINOPSIS

#include <fcntl.h>
#include <unistd.h>
#include <liburing.h>
void io_uring_prep_unlinkat(struct io_uring_sqe *sqe,
                            int dirfd,
                            const char *path,
                            int flags);
void io_uring_prep_unlink(struct io_uring_sqe *sqe,
                          const char *path,
                          int flags);

DESCRIPCIÓN

La función io_uring_prep_unlinkat(3) prepara una solicitud de unlinkat. La entrada de la cola de envío (submission queue entry, sqe) se configura para usar el descriptor de archivo del directorio apuntado por dirfd para iniciar una operación de unlinkat sobre la ruta identificada por path y utilizando las banderas (flags) dadas en flags.

La función io_uring_prep_unlink(3) prepara una solicitud de unlink. La entrada de la cola de envío (sqe) se configura para iniciar una operación de unlinkat sobre la ruta identificada por path en relación con el directorio de trabajo actual y utilizando las banderas dadas en flags.

Estas funciones preparan una solicitud asíncrona de unlinkat(2) o unlink(2). Consulte esas páginas del manual para obtener detalles.

VALOR DE RETORNO

Ninguno

ERRORES

El campo res del CQE contendrá el resultado de la operación. Consulte la página del manual relacionada para obtener detalles sobre los valores posibles. Tenga en cuenta que mientras que las llamadas al sistema síncronas devolverán -1 en caso de error y establecerán errno con el valor real del error, io_uring nunca usa errno. En su lugar, devuelve el errno negado directamente en el campo res del CQE.

NOTAS

Al igual que con cualquier solicitud que pase datos en una estructura, esos datos deben permanecer válidos hasta que la solicitud se haya enviado con éxito. No es necesario que permanezcan válidos hasta la finalización. Una vez que se ha enviado una solicitud, el estado dentro del kernel es estable. Los primeros kernels (5.4 y anteriores) requerían que el estado fuera estable hasta que ocurriera la finalización. Las aplicaciones pueden probar este comportamiento inspeccionando el indicador IORING_FEAT_SUBMIT_STABLE devuelto por io_uring_queue_init_params(3).

VER TAMBIÉN
