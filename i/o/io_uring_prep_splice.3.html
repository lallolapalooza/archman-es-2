NOMBRE

io_uring_prep_splice - prepara una solicitud de splice

SINOPSIS

#include <fcntl.h>
#include <liburing.h>
void io_uring_prep_splice(struct io_uring_sqe *sqe,
                          int fd_in,
                          int64_t off_in,
                          int fd_out,
                          int64_t off_out,
                          unsigned int nbytes,
                          unsigned int splice_flags);

DESCRIPCIÓN

La función io_uring_prep_splice(3) prepara una solicitud de splice. La entrada de la cola de envío sqe se configura para usar como entrada el descriptor de archivo fd_in en el desplazamiento off_in, conectando datos al descriptor de archivo en fd_out y en el desplazamiento off_out. Se deben conectar nbytes bytes de datos entre los dos descriptores. splice_flags son indicadores modificadores para la operación. Ver splice(2) para los indicadores genéricos de splice.

Si el descriptor fd_out, IOSQE_FIXED_FILE puede establecerse en el SQE para indicarlo. Para el archivo de entrada, el específico de io_uring SPLICE_F_FD_IN_FIXED puede establecerse en splice_flags y fd_in dado como un desplazamiento de archivo registrado.

Si fd_in se refiere a una tubería, off_in se ignora y debe establecerse en -1.

Si fd_in no se refiere a una tubería y off_in es -1, entonces se leen nbytes de fd_in comenzando desde el desplazamiento de archivo, que se incrementa por el número de bytes leídos.

Si fd_in no se refiere a una tubería y off_in no es -1, entonces el desplazamiento inicial de fd_in será off_in.

Las mismas reglas se aplican a fd_out y off_out.

Esta función prepara una solicitud de splice(2) asíncrona. Ver esa página de manual para más detalles.

VALOR DE RETORNO

Ninguno

ERRORES

El campo res de la CQE contendrá el resultado de la operación. Ver la página de manual relacionada para detalles sobre valores posibles. Tenga en cuenta que donde las llamadas al sistema sincrónicas devolverán -1 en caso de fallo y establecerán errno al valor de error real, io_uring nunca usa errno. En su lugar, devuelve el errno negado directamente en el campo res de la CQE.

VER TAMBIÉN

io_uring_get_sqe(3), io_uring_submit(3), io_uring_register(2), splice(2)

NOTAS

Tenga en cuenta que incluso si fd_in o fd_out se refieren a una tubería, la operación de splice aún puede fallar con EINVAL si uno de los fd no admite explícitamente la operación splice, por ejemplo, leer desde una terminal no es compatible desde el kernel 5.7 hasta el 5.11.
