NAME

ioctl_xfs_fsbulkstat - consultar información para un grupo de nodos XFS

SYNOPSIS

#include <xfs/xfs_fs.h>

int ioctl(int fd, XFS_IOC_FSBULKSTAT, struct xfs_fsop_bulkreq *arg);


int ioctl(int fd, XFS_IOC_FSBULKSTAT_SINGLE, struct xfs_fsop_bulkreq *arg);

DESCRIPTION

Consultar información de estado para un grupo de nodos XFS.

NOTA: Este ioctl ha sido superado. Por favor, consulte la página de manual ioctl_xfs_bulkstat(2) para obtener información sobre su reemplazo.

Estos ioctls usan struct xfs_fsop_bulkreq para configurar una transferencia masiva con el kernel:


struct xfs_fsop_bulkreq {
	__u64             *lastip;
	__s32             count;
	void              *ubuffer;
	__s32             *ocount;
};

lastip apunta a un valor que recibirá el número del "último nodo". Esto no puede ser NULL. Para FSBULKSTAT, esto debe establecerse en uno menos que el número del primer nodo para el cual el llamante desea información, o en cero para comenzar con el primer nodo del sistema de archivos. Para FSBULKSTAT_SINGLE, esto debe establecerse en el número del nodo para el cual el llamante desea información. Después de la llamada, este valor se establecerá en el número del último nodo para el cual se proporcionó información. Este campo no se actualizará si ocount es NULL.

count es el número de elementos en el array ubuffer y, por lo tanto, el número de nodos para los cuales se deben devolver información de estado. Este valor debe establecerse en 1 para FSBULKSTAT_SINGLE.

ocount apunta a un valor que recibirá el número de registros devueltos. Si este valor es NULL, ni ocount ni lastip se actualizarán.

ubuffer apunta a un búfer de memoria en el cual se copiará la información de estado del nodo. Este búfer debe ser un array de struct xfs_bstat que se describe a continuación. El array debe tener al menos count elementos.


struct xfs_bstat {
	__u64             bs_ino;
	__u16             bs_mode;
	__u16             bs_nlink;
	__u32             bs_uid;
	__u32             bs_gid;
	__u32             bs_rdev;
	__s32             bs_blksize;
	__s64             bs_size;
	struct xfs_bstime bs_atime;
	struct xfs_bstime bs_mtime;
	struct xfs_bstime bs_ctime;
	int64_t           bs_blocks;
	__u32             bs_xflags;
	__s32             bs_extsize;
	__s32             bs_extents;
	__u32             bs_gen;
	__u16             bs_projid_lo;
	__u16             bs_forkoff;
	__u16             bs_projid_hi;
	uint16_t          bs_sick;
	uint16_t          bs_checked;
	unsigned char     bs_pad[2];
	__u32             bs_cowextsize;
	__u32             bs_dmevmask;
	__u16             bs_dmstate;
	__u16             bs_aextents;
};

Los miembros de la estructura son los siguientes:

bs_ino es el número de nodo para este registro.

bs_mode es el tipo de archivo y el modo.

bs_nlink es el número de enlaces duros a este nodo.

bs_uid es el identificador de usuario.

bs_gid es el identificador de grupo.

bs_rdev es el identificador de dispositivo codificado si se trata de un archivo especial.

bs_blksize es el tamaño de un bloque de datos para este archivo, en unidades de bytes.

bs_size es el tamaño del archivo, en bytes.

bs_atime es la última vez que se accedió a este archivo.

bs_mtime es la última vez que se modificaron los contenidos de este archivo.

bs_ctime es la última vez que se modificó este registro de nodo.

bs_blocks es el número de bloques del sistema de archivos asignados a este archivo, incluyendo metadatos.

bs_xflags contiene las banderas extendidas que se establecen en este nodo. Estas banderas son los mismos valores que los definidos en la sección BANDERAS DE NODO XFS de la página de manual ioctl_xfs_fsgetxattr(2).

bs_extsize es la sugerencia de tamaño de extensión para este archivo, en bytes.

bs_extents es el número de mapeos de almacenamiento asociados con los datos de este archivo.

bs_gen es el número de generación del registro de nodo.

bs_projid_lo son los 16 bits inferiores del identificador de proyecto.

bs_forkoff es el desplazamiento de la horquilla de atributos en el registro de nodo, en bytes.

bs_projid_hi son los 16 bits superiores del identificador de proyecto.

bs_pad[6] está inicializado a cero.

bs_cowextsize es la sugerencia de tamaño de extensión de escritura sobre copia para este archivo, en bytes.

bs_dmevmask no se usa en Linux.

bs_dmstate no se usa en Linux.

bs_aextents es el número de mapeos de almacenamiento asociados con los atributos extendidos de este archivo.

Los campos bs_sick y bs_checked indican la salud relativa de varios metadatos del nodo:

•
Si una bandera de enfermedad dada está establecida en bs_sick, entonces esa parte de los metadatos se ha observado que está dañada. La misma bit debería establecerse en bs_checked.
•
Si una bandera de enfermedad dada está establecida en bs_checked pero no está establecida en bs_sick, entonces esa parte de los metadatos se ha verificado y no está defectuosa.
•
Si una bandera de enfermedad dada no está establecida en bs_checked, entonces no se puede hacer ninguna conclusión.

Las siguientes banderas se aplican a estos campos:

XFS_BS_SICK_INODE
El registro del nodo en sí.
XFS_BS_SICK_BMBTD
Mapas de extensiones de datos del archivo.
XFS_BS_SICK_BMBTA
Mapas de extensiones de atributos extendidos.
XFS_BS_SICK_BMBTC
Mapas de extensiones de estadiación de escritura sobre copia.
XFS_BS_SICK_DIR
Información de directorio.
XFS_BS_SICK_XATTR
Datos de atributos extendidos.
XFS_BS_SICK_SYMLINK
Objeto de enlace simbólico.
XFS_BS_SICK_PARENT
Apuntadores de padre.
XFS_BS_SICK_DIRTREE
El directorio es la fuente de corrupción en el árbol de directorios.

RETURN VALUE

En caso de error, se devuelve -1 y errno se establece para indicar el error.

ERRORS

Los códigos de error pueden ser uno de, pero no se limitan a, los siguientes:

EFAULT
El kernel no pudo copiar en el búfer del espacio de usuario.
EFSBADCRC
La validación de suma de comprobación de metadatos falló durante la consulta.
EFSCORRUPTED
Se encontró corrupción de metadatos durante la consulta.
EINVAL
Uno de los argumentos no era válido.
EIO
Se encontró un error de E/S durante la consulta.
ENOMEM
No había memoria suficiente para realizar la consulta.

CONFORMING TO

Esta API es específica para el sistema de archivos XFS en el kernel Linux.
