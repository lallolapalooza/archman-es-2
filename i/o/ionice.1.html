    ionice(1)

    NOMBRE

    ionice - leer o establecer la clase de E/S y la prioridad del planificador de E/S

    SINOPSIS

    ionice [-c clase] [-n nivel] [comando [argumentos...]]

    ionice -p pid

    DESCRIPCIÓN

    ionice es un programa para leer o establecer las prioridades de E/S de un proceso.

    Si no se especifica ningún comando, ionice configura la clase de E/S y la prioridad para el proceso actual (lo que afecta a los procesos futuros creados por él). Si se proporciona una opción -p, ionice obtiene la clase y prioridad de E/S del proceso con el PID dado.

    Las clases de E/S disponibles son:

    idle: El proceso no consumirá ninguna banda ancha de disco si otro proceso necesita banda ancha de disco. La prioridad se ignora.

    best-effort: Los procesos que se ejecutan en esta clase se les da una banda ancha de disco garantizada. Los niveles de prioridad van del 0 (más alto) al 7 (más bajo).

    real-time: Los procesos que se ejecutan en esta clase obtienen acceso prioritario al disco. Los procesos en la clase best-effort nunca obtendrán acceso al disco si hay un proceso en la clase real-time esperando. Los niveles de prioridad van del 0 (más alto) al 7 (más bajo).

    La clase none o 0 también puede usarse y se traduce a idle.

    La clase 1 se traduce a best-effort y la clase 2 se traduce a real-time.

    La prioridad por defecto para las clases best-effort y real-time es 4.

    La clase idle no tiene niveles de prioridad.

    Solo el usuario root puede asignar procesos a las clases best-effort y real-time. Además, solo el usuario root puede asignar procesos a niveles de prioridad más altos que los de su propia clase.

    La opción -p muestra la clase y la prioridad del proceso especificado por pid.

    La opción -c especifica la clase de E/S para el proceso especificado. Los valores permitidos son 0, 1, 2 o idle, best-effort, real-time.

    La opción -n especifica el nivel de prioridad para las clases best-effort y real-time. Los valores permitidos son de 0 a 7.

    Vea man 2 ionice para obtener más detalles.

    EJEMPLOS

    Establecer la clase de E/S a idle para el comando my_command:

    ionice -c 3 my_command

    Establecer la clase de E/S a best-effort con prioridad 2 para el comando my_command:

    ionice -c 2 -n 2 my_command

    Ver la clase y prioridad de E/S del proceso 1234:

    ionice -p 1234
