NOMBRE

io_uring_register_ring_fd - registrar un descriptor de fichero del anillo

SINOPSIS

#include <liburing.h>
int io_uring_register_ring_fd(struct io_uring *ring);

DESCRIPCIÓN

io_uring_register_ring_fd(3) registra el descriptor de fichero del anillo.

Cada vez que se llama a io_uring_enter(2) para enviar solicitudes o esperar compleciones, el kernel debe obtener una referencia al descriptor de fichero. Si la aplicación que utiliza io_uring es multihilo, la tabla de ficheros se marca como compartida y la obtención y liberación de la referencia del contador del descriptor de fichero es más costosa que para una aplicación no multihilo.

De forma similar a como io_uring permite el registro de ficheros, esto permite el registro del descriptor de fichero del propio anillo. Esto reduce la sobrecarga de la llamada al sistema io_uring_enter(2).

Si una aplicación que utiliza liburing es multihilo, entonces una aplicación debe llamar a esta función para registrar el descriptor del anillo cuando se configura un anillo. Véase NOTAS para restricciones cuando un anillo se comparte.

Disponible desde el kernel 5.18.

NOTAS

Cuando el descriptor del anillo se registra, se almacena internamente en la estructura struct io_uring. Para aplicaciones que comparten un anillo entre hilos, por ejemplo, un hilo que realiza envíos y otro que recupera eventos, esta optimización no se puede utilizar ya que cada hilo puede tener un índice diferente para el descriptor de fichero del anillo registrado.

VALOR DE RETORNO

Devuelve 1 en caso de éxito, indicando que se registró un descriptor de fichero, o -errno en caso de error.

VER TAMBIÉN
