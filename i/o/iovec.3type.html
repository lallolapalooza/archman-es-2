iovec(3type) iovec(3type)

NOMBRE

iovec - Estructura de datos de E/S de vectores

BIBLIOTECA

Biblioteca estándar C (libc)

SINOPSIS

#include <sys/uio.h>
struct iovec {
    void   *iov_base;  /* Dirección de inicio */
    size_t  iov_len;   /* Tamaño de la memoria apuntada por 
iov_base. */
};

DESCRIPCIÓN

Describe una región de memoria, comenzando en la dirección iov_base y con el tamaño de iov_len bytes. Las llamadas al sistema utilizan arrays de esta estructura, donde cada elemento del array representa una región de memoria, y el array completo representa un vector de regiones de memoria. El número máximo de estructuras iovec en ese array está limitado por IOV_MAX (definido en <limits.h>, o accesible a través de la llamada sysconf(_SC_IOV_MAX)).

ESTÁNDARES

POSIX.1-2024.

HISTORIA

POSIX.1-2001.

NOTAS

La siguiente cabecera también proporciona este tipo: <sys/socket.h>.

VER TAMBIÉN

process_madvise(2), readv(2)
