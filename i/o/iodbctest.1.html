iodbctest(1) Gestor de controladores iODBC iodbctest(1)

NOMBRE

iodbctest, iodbctestw - Programas de demostración de iODBC

SINOPSIS

iodbctest ["DSN=xxxx[;UID=xxxx][;PWD=xxxx][;OPT=valor]"]
iodbctestw ["DSN=xxxx[;UID=xxxx][;PWD=xxxx][;OPT=valor]"]

DESCRIPCIÓN

Los programas iodbctest y iodbtestw son programas de ejemplo ODBC sencillos, que muestran la potencia de la API ODBC para conectarse a cualquier base de datos habilitada para ODBC, emitir comandos SQL y recuperar los resultados de las consultas.

El programa iodbctest utiliza las llamadas estándar de la API ODBC para conectarse utilizando cualquier DSN, pero recupera todos los resultados en modo ASCII.

El programa iodbctestw utiliza las llamadas de la API Unicode ODBC para conectarse utilizando cualquier DSN y recupera todos los resultados en modo Unicode.

OPCIONES

El programa iodbctest utiliza la función SQLDriverConnect para establecer una conexión utilizando cualquier controlador ODBC compatible disponible. Esto permite al usuario anular cualquier atributo de conexión ODBC en la cadena DSN.

Las cadenas de conexión deben comenzar con un atributo DSN=xxx o DRIVER=xxxx, seguido opcionalmente por otros atributos DSN separados por punto y coma, por ejemplo:

DSN=ora9;UID=scott;PWD=tiger;DATABASE=ora9u

Cualquier atributo requerido para una conexión adecuada que no se introduzca en la cadena de conexión DSN, debe estar presente en el archivo odbc.ini.

Si la cadena de conexión se pasa como argumento al programa iodbctest, la cadena debe entrecomillarse ya que la mayoría de los intérpretes de comandos utilizan el punto y coma como separador de comandos. Si la cadena de conexión se introduce en el prompt interactivo, no se deben usar comillas.

Después de establecer una conexión exitosa, se le pide al usuario un comando SQL para enviarlo a la base de datos. Un comando SQL no puede extenderse por varias líneas.

Si el comando SQL devuelve uno o más conjuntos de resultados, cada conjunto de resultados se recupera utilizando búferes de caracteres y se muestra en una tabla.

Además, el programa iodbctest entiende algunos comandos especiales:

calificadores

Muestra una lista de calificadores utilizando la llamada de catálogo SQLTables.
propietarios

Muestra una lista de propietarios utilizando la llamada de catálogo SQLTables.
tablas

Muestra una lista de tablas utilizando la llamada de catálogo SQLTables.
tipos

Muestra una lista de tipos de tablas utilizando la llamada de catálogo SQLTables.
tiposdedatos

Muestra una lista de tipos de datos utilizando la llamada de catálogo SQLGetTypeInfo.
reconectar

Realiza una desconexión/reconexión con la información guardada durante la primera SQLDriverConnect.
salir (o exit)

Sale del programa y regresa al shell.

EJEMPLOS

Inicia el programa iodbctest y obtén una lista de DSN antes de establecer una conexión:

    $ iodbctest
    OpenLink ODBC Demonstration program
    This program shows an interactive SQL processor
    Enter ODBC connect string (? shows list): ?
    DSN                              | Driver
    -----------------------------------------------------------------
    ora9                             | OpenLink Generic ODBC Driver
    mysql                            | OpenLink Generic ODBC Driver
    mysqllite                        | OpenLink Lite for MySQL
    myodbc                           | MyODBC Driver
    pgsql                            | OpenLink Generic ODBC Driver
    tds                              | OpenLink Generic ODBC Driver
    Enter ODBC connect string (? shows list): DSN=ora9;PWD=tiger
    Driver: 05.20.0316 OpenLink Generic ODBC Driver (oplodbc.so)
    SQL>

Conéctate a una instancia de Oracle 9 que se haya configurado previamente en el archivo odbc.ini:

    $ iodbctest "DSN=ora9;UID=scott;PWD=tiger"
    iODBC Demonstration program
    This program shows an interactive SQL processor
    Driver: 05.20.0316 OpenLink Generic ODBC Driver (oplodbc.so)
    SQL>select * from emp
    ID               |NAME
    -----------------+-------------------------------------------
    1                |Record 1
    2                |Record 2
    2                |Record 3
     result set 1 returned 3 rows.
    SQL> quit
