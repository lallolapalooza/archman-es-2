DESCRIPCIÓ

N

La función ioctl() realizará una variedad de funciones de control en dispositivos STREAMS. Para dispositivos que no son STREAMS, las funciones realizadas por esta llamada no están especificadas. El argumento request y un tercer argumento opcional (de tipo variable) se pasarán e interpretarán por la parte apropiada del STREAM asociado con fildes

.

El argumento fildes es un descriptor de archivo abierto que se refiere a un

dispositivo.

El argumento request selecciona la función de control a realizar y dependerá del dispositivo STREAMS al que se

dirige.

El argumento arg representa información adicional que es necesaria para este dispositivo STREAMS específico para realizar la función solicitada. El tipo de arg depende de la solicitud de control particular, pero será un entero o un puntero a una estructura de datos específica del

dispositivo.

Los comandos ioctl() aplicables a STREAMS, sus argumentos y las condiciones de error que se aplican a cada comando individual se describen a

continuación.

Los siguientes comandos ioctl(), con valores de error indicados, son aplicables a todos los archivos

STREAMS:

Esta solicitud permite al proceso establecer el tiempo que la cabecera del STREAM debe retrasar cuando se está cerrando un STREAM y hay datos en las colas de escritura. Antes de cerrar cada módulo o controlador, si hay datos en su cola de escritura, la cabecera del STREAM se retrasará durante el tiempo especificado para permitir que los datos se vacíen. Si, después del retraso, los datos siguen presentes, se eliminarán. El argumento arg es un puntero a un entero que especifica el número de milisegundos de retraso, redondeado hacia arriba al valor válido más cercano. Si no se realiza I_SETCLTIME en un STREAM, se usa un intervalo de tiempo de espera predeterminado definido por la implementación.
