NOMBRE

io_prep_fsync - Sincroniza el estado completo en memoria de un archivo con el disco

SINOPSIS

#include <errno.h>

#include <libaio.h>

static inline void io_prep_fsync(struct iocb *iocb, int fd);

struct iocb {
	void		*data;
	unsigned	key;
	short		aio_lio_opcode;
	short		aio_reqprio;
	int		aio_fildes;
};

DESCRIPCIÓN

Esta es una función de conveniencia en línea para configurar un iocbv para una solicitud FSYNC.

Se configura el archivo para el cual

iocb->aio_fildes = fd
es un descriptor con el comando 
iocb->aio_lio_opcode = IO_CMD_FSYNC

La función io_prep_fsync() configurará una operación IO_CMD_FSYNC para forzar asincrónicamente todas las operaciones de I/O asociadas con el archivo indicado por el descriptor de archivo aio_fildes (miembro de la estructura iocb referenciada por el argumento iocb) y encoladas en el momento de la llamada a io_submit() al estado de completado de I/O sincronizada. La llamada a la función regresará cuando la solicitud de sincronización haya sido iniciada o encolada al archivo o dispositivo (incluso cuando los datos no puedan ser sincronizados inmediatamente).

Todas las operaciones de I/O actualmente encoladas se completarán como si se hubiera realizado una llamada a fsync(2); es decir, según lo definido para la completación de integridad de archivo de I/O sincronizada. Si la operación encolada por io_prep_fsync() falla, entonces, al igual que con fsync(2), no se garantiza que las operaciones de I/O pendientes se hayan completado.

Si io_prep_fsync() tiene éxito, entonces solo se garantiza que la I/O que estaba encolada en el momento de la llamada a io_submit(3) se forzará al estado de completado relevante. La completación de I/O subsiguiente en el descriptor de archivo no se garantiza que se complete de manera sincronizada.

Esta función regresa inmediatamente. Para programar la operación, se debe llamar a la función io_submit(3).

Las operaciones asincrónicas simultáneas que utilizan el mismo iocb producen resultados indefinidos.

VALORES DE RETORNO

Ninguno.

ERRORES

Ninguno.
