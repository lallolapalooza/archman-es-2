NOMBRE

io_cancel - Cancelar solicitudes de E/S

SINOPSIS

#include <errno.h>

#include <libaio.h>

int io_cancel(io_context_t ctx, struct iocb *iocb);

struct iocb {
	void		*data; /* Devolver en el evento de finalización de E/S */
	unsigned	key;	/* Para usar en la identificación de solicitudes de E/S */
	short		aio_lio_opcode;
	short		aio_reqprio; 	/* No utilizado */
	int		aio_fildes;
};

DESCRIPCIÓN

Intenta cancelar un iocb previamente pasado a io_submit(3). Si la operación se cancela con éxito, el evento resultante se copia en la memoria apuntada por resultado sin ser colocado en la cola de finalización.

Cuando una o más solicitudes se procesan de forma asíncrona, puede ser útil en algunas situaciones cancelar una operación seleccionada, p. ej., si queda claro que los datos escritos ya no son correctos y tendrían que ser sobrescritos pronto. Como ejemplo, suponga una aplicación que escribe datos en archivos en una situación en la que los nuevos datos entrantes tendrían que escribirse en un archivo que será actualizado por una solicitud en cola.

VALORES DE RETORNO

Se devuelve 0 si la operación es exitosa, de lo contrario, devuelve errno.

ERRORES

EFAULT
Si alguna de las estructuras de datos apuntadas es inválida.
EINVAL
Si el aio_context especificado por ctx es inválido.
EAGAIN
Si el iocb especificado no se canceló.
ENOSYS
Si no está implementado.
