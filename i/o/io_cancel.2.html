io_cancel(2) Manual de llamadas al sistema io_cancel(2)

NOMBRE

io_cancel - cancelar una operación de E/S asíncrona pendiente

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

Alternativamente, biblioteca de E/S asíncrona (libaio, -laio); ver VERSIONS.

SINOPSIS

#include <linux/aio_abi.h>    /* Definición de tipos necesarios */
#include <sys/syscall.h>      /* Definición de constantes SYS_* */
#include <unistd.h>
int syscall(SYS_io_cancel, aio_context_t ctx_id, struct iocb *iocb,
            struct io_event *result);

DESCRIPCIÓN

Nota: esta página describe la interfaz de llamada al sistema Linux sin procesar. La función de envoltura proporcionada por libaio utiliza un tipo diferente para el argumento ctx_id. Ver VERSIONS.

La llamada al sistema io_cancel() intenta cancelar una operación de E/S asíncrona enviada previamente con io_submit(2). El argumento iocb describe la operación a cancelar y el argumento ctx_id es el contexto AIO al que se envió la operación. Si la operación se cancela con éxito, el evento se copiará en la memoria apuntada por result sin colocarse en la cola de finalización.

VALOR DE RETORNO

En caso de éxito, io_cancel() devuelve 0. Para el retorno de error, ver VERSIONS.

ERRORES

EAGAIN
El iocb especificado no fue cancelado.
EFAULT
Una de las estructuras de datos apunta a datos inválidos.
EINVAL
El contexto AIO especificado por ctx_id es inválido.
ENOSYS
io_cancel() no está implementado en esta arquitectura.

VERSIÓNES

Probablemente querrás usar la función de envoltura io_cancel() proporcionada por libaio.

Ten en cuenta que la función de envoltura de libaio utiliza un tipo diferente (io_context_t) para el argumento ctx_id. Ten en cuenta también que la envoltura de libaio no sigue las convenciones habituales de la biblioteca C para indicar errores: en caso de error, devuelve un número de error negado (el negativo de uno de los valores listados en ERRORS). Si la llamada al sistema se invoca a través de syscall(2), el valor de retorno sigue las convenciones habituales para indicar un error: -1, con errno establecido en un valor (positivo) que indica el error.

ESTÁNDARES

Linux.

HISTORIA

Linux 2.5.
