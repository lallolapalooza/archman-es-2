NOMBRE

io_uring_prep_linkat - prepara una solicitud linkat

SINOPSIS

#include <fcntl.h>
#include <unistd.h>
#include <liburing.h>
void io_uring_prep_linkat(struct io_uring_sqe *sqe,
                          int olddirfd,
                          const char *oldpath,
                          int newdirfd,
                          const char *newpath,
                          int flags);
void io_uring_prep_link(struct io_uring_sqe *sqe,
                        const char *oldpath,
                        const char *newpath,
                        int flags);

DESCRIPCIÓN

La función io_uring_prep_linkat(3) prepara una solicitud linkat. La entrada de la cola de envío sqe se configura para usar el descriptor de archivo del directorio antiguo señalado por olddirfd y la ruta antigua señalada por oldpath con el descriptor de archivo del nuevo directorio señalado por newdirfd y la nueva ruta señalada por newpath y utilizando las banderas especificadas en flags.

La función io_uring_prep_link(3) prepara una solicitud link. La entrada de la cola de envío sqe se configura para usar la ruta antigua señalada por oldpath y la nueva ruta señalada por newpath, ambas relativas al directorio de trabajo actual y utilizando las banderas especificadas en flags.

Estas funciones preparan una solicitud asíncrona de linkat(2) o link(2). Consulte esas páginas del manual para obtener más detalles.

VALOR DE RETORNO

Ninguno

ERRORES

El campo res de la CQE contendrá el resultado de la operación. Consulte la página del manual relacionada para obtener detalles sobre los posibles valores. Tenga en cuenta que donde las llamadas al sistema síncronas devolverán -1 en caso de fallo y establecerán errno al valor de error real, io_uring nunca utiliza errno. En su lugar, devuelve el errno negado directamente en el campo res de la CQE.

NOTAS

Al igual que con cualquier solicitud que pase datos en una estructura, esos datos deben permanecer válidos hasta que la solicitud se haya enviado correctamente. No es necesario que permanezcan válidos hasta la finalización. Una vez que se ha enviado una solicitud, el estado en el kernel es estable. Los primeros kernels (5.4 y anteriores) requerían que el estado fuera estable hasta que ocurriera la finalización. Las aplicaciones pueden probar este comportamiento inspeccionando la bandera IORING_FEAT_SUBMIT_STABLE devuelta por io_uring_queue_init_params(3).
