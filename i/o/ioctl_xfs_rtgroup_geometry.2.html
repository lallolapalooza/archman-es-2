NOMBRE

ioctl_xfs_rtgroup_geometry - consultar información de geometría del grupo en tiempo real de XFS

SINOPSIS

#include <xfs/xfs_fs.h>

int ioctl(int fd, XFS_IOC_RTGROUP_GEOMETRY, struct xfs_rtgroup_geometry *arg);

DESCRIPCIÓN

Este ioctl de XFS recupera la información de geometría de un grupo en tiempo real dado. La información de geometría se transmite en una estructura de la siguiente forma:


struct xfs_rtgroup_geometry {
	__u32  rg_number;
	__u32  rg_length;
	__u32  rg_sick;
	__u32  rg_checked;
	__u32  rg_flags;
	__u32  rg_reserved[27];
};
rg_number
El llamador debe establecer este campo con el índice del grupo en tiempo real sobre el que el llamador desea obtener información.
rg_length
La longitud del grupo en tiempo real se devuelve en este campo, en unidades de bloques del sistema de archivos. rg_flags El llamador puede establecer este campo para cambiar el comportamiento operativo del ioctl. Actualmente no se definen flags, por lo que este campo debe ser cero.
rg_reserved y rg_pad
Todos los campos reservados se establecerán a cero al regresar.

Los campos rg_sick y rg_checked indican la salud relativa de varios metadatos del grupo en tiempo real:

•
Si un flag de error dado está establecido en rg_sick, entonces esa pieza de metadatos ha sido observada como dañada. El mismo bit estará establecido en rg_checked.
•
Si un flag de error dado está establecido en rg_checked y no está establecido en rg_sick, entonces esa pieza de metadatos ha sido comprobada y no es defectuosa.
•
Si un flag de error dado no está establecido en rg_checked, no se puede hacer ninguna conclusión.

Los siguientes flags se aplican a estos campos:

XFS_RTGROUP_GEOM_SICK_SUPER
Superbloque del grupo en tiempo real.
XFS_RTGROUP_GEOM_SICK_BITMAP
Mapa de bits en tiempo real para este grupo.
XFS_RTGROUP_GEOM_SICK_SUMMARY
Resumen en tiempo real para este grupo.
XFS_RTGROUP_GEOM_SICK_RTRMAPBT
Árbol B de mapeo inverso para este grupo.

VALOR DE RETORNO

En caso de error, se devuelve -1 y se establece errno para indicar el error.

ERRORES

Los códigos de error pueden ser, entre otros, los siguientes:

EFSBADCRC
La validación de la suma de verificación de metadatos falló al realizar la consulta.
EFSCORRUPTED
Se encontraron metadatos corruptos al realizar la consulta.
EINVAL
El número de grupo en tiempo real especificado no es válido para este sistema de archivos.
EIO
Se encontró un error de E/S al realizar la consulta.

CONFORMIDAD CON

Esta API es específica del sistema de archivos XFS en el kernel de Linux.
