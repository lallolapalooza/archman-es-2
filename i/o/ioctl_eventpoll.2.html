ioctl_eventpoll(2) Manual de llamadas al sistema ioctl_eventpoll(2)

NOMBRE

ioctl_eventpoll, EPIOCSPARAMS, EPIOCGPARAMS - operaciones de ioctl() para descriptores de archivo epoll

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <sys/epoll.h>  /* Definición de las constantes EPIOC* */
#include <sys/ioctl.h>
int ioctl(int fd, EPIOCSPARAMS, const struct epoll_params *argp);
int ioctl(int fd, EPIOCGPARAMS, struct epoll_params *argp);
#include <sys/epoll.h>
struct epoll_params {
    uint32_t  busy_poll_usecs;   /* Número de microsegundos para sondeo intensivo */
    uint16_t  busy_poll_budget;  /* Paquetes máximos por sondeo */
    uint8_t   prefer_busy_poll;  /* Preferencia booleana */
    /* Rellena la estructura hasta un múltiplo de 64 bits */
    uint8_t   __pad;             /* Debe ser cero */
};

DESCRIPCIÓN

EPIOCSPARAMS
Establece la estructura epoll_params para configurar la operación de epoll. Consulte la descripción de la estructura a continuación para saber qué configuración se admite.
EPIOCGPARAMS
Obtiene la configuración actual de epoll_params.

Todas las operaciones descritas anteriormente deben realizarse en un descriptor de archivo epoll, que se puede obtener mediante una llamada a epoll_create(2) o epoll_create1(2).

La estructura epoll_params

argp.busy_poll_usecs indica el número de microsegundos durante los cuales la pila de red realizará sondeos intensivos. Durante este período de tiempo, el dispositivo de red se sondeará repetidamente en busca de paquetes. Este valor no puede exceder INT_MAX.

argp.busy_poll_budget indica el número máximo de paquetes que la pila de red recuperará en cada intento de sondeo. Este valor no puede exceder NAPI_POLL_WEIGHT (que es 64 a partir de Linux 6.9), a menos que el proceso se ejecute con CAP_NET_ADMIN.

argp.prefer_busy_poll es un campo booleano y debe ser 0 (deshabilitado) o 1 (habilitado). Si está habilitado, esto indica a la pila de red que el sondeo intensivo es el método preferido para procesar datos de red y que la pila de red debe dar a la aplicación la oportunidad de realizar sondeos intensivos. Sin esta opción, los sistemas muy ocupados pueden continuar realizando el procesamiento de red a través del método normal de IRQs que activan softIRQ y NAPI.

argp.__pad debe ser cero.

VALOR DE RETORNO

En caso de éxito, se devuelve 0. En caso de error, se devuelve -1 y errno se establece para indicar el error.

ERRORES

EOPNOTSUPP
El kernel no se compiló con soporte para sondeo intensivo.
EINVAL
fd no es un descriptor de archivo válido.
EINVAL
argp.__pad no es cero.
EINVAL
argp.busy_poll_usecs excede INT_MAX.
EINVAL
argp.prefer_busy_poll no es 0 ni 1.
EPERM
El proceso se está ejecutando sin CAP_NET_ADMIN y el argp.busy_poll_budget especificado excede NAPI_POLL_WEIGHT.
EFAULT
argp es una dirección inválida.

ESTÁNDARES

Linux.

HISTORIA

Linux 6.9. glibc 2.40.

EJEMPLOS

/* Código para establecer los parámetros de epoll para habilitar el sondeo intensivo */
int epollfd = epoll_create1(0);
struct epoll_params params;
if (epollfd == -1) {
    perror("epoll_create1");
    exit(EXIT_FAILURE);
}
memset(&params, 0, sizeof(struct epoll_params));
params.busy_poll_usecs = 25;
params.busy_poll_budget = 8;
params.prefer_busy_poll = 1;
if (ioctl(epollfd, EPIOCSPARAMS, &params) == -1) {
    perror("ioctl");
    exit(EXIT_FAILURE);
}
/* Código para mostrar cómo recuperar la configuración actual */
memset(&params, 0, sizeof(struct epoll_params));
if (ioctl(epollfd, EPIOCGPARAMS, &params) == -1) {
    perror("ioctl");
    exit(EXIT_FAILURE);
}
/* La estructura params ahora contiene los parámetros actuales */
fprintf(stderr, "epoll usecs: %lu\n", params.busy_poll_usecs);
fprintf(stderr, "epoll packet budget: %u\n", params.busy_poll_budget);
fprintf(stderr, "epoll prefer busy poll: %u\n", params.prefer_busy_poll);
