NOMBRE

io_uring_register_buffers - registrar búferes para operaciones de búferes fijos

SINOPSIS

#include <liburing.h>
int io_uring_register_buffers(struct io_uring *ring,
                              const struct iovec *iovecs,
                              unsigned nr_iovecs);
int io_uring_register_buffers_tags(struct io_uring *ring,
                                   const struct iovec *iovecs,
                                   const __u64 *tags,
                                   unsigned nr);
int io_uring_register_buffers_sparse(struct io_uring *ring,
                                     unsigned nr_iovecs);
int io_uring_register_buffers_update_tag(struct io_uring *ring,
                                         unsigned off,
                                         const struct iovec *iovecs,
                                         const __u64 *tags,
                                         unsigned nr);

DESCRIPCIÓN

La función io_uring_register_buffers(3) registra nr_iovecs búferes definidos por la matriz iovecs pertenecientes a ring.

La función io_uring_register_buffers_tags(3) se comporta igual que la función io_uring_register_buffers(3) pero además toma el parámetro tags. Ver IORING_REGISTER_BUFFERS2 para la descripción del etiquetado de recursos.

La función io_uring_register_buffers_sparse(3) registra nr_iovecs búferes vacíos pertenecientes a ring. Estos búferes deben actualizarse antes de su uso, por ejemplo, usando io_uring_register_buffers_update_tag(3).

Una vez que el llamante ha registrado los búferes, estos pueden ser utilizados con una de las funciones de búferes fijos.

Los búferes registrados son una optimización útil en conjunción con lecturas y escrituras O_DIRECT, donde se mapea el rango especificado en el kernel una vez al registrar el búfer, en lugar de hacer un mapeo y desmapeo para cada IO cada vez que se realiza una operación de IO en esa región. Adicionalmente, también evita la manipulación de los recuentos de referencia de páginas para cada IO.

La función io_uring_register_buffers_update_tag(3) actualiza los búferes registrados con nuevos, ya sea convirtiendo una entrada dispersa en una real o reemplazando una entrada existente. off es el desplazamiento en el que comenzar la actualización, nr es el número de búferes definidos por la matriz iovecs pertenecientes a ring. tags apunta a una matriz de etiquetas. Ver IORING_REGISTER_BUFFERS2 para la descripción del etiquetado de recursos.

VALOR DE RETORNO

En caso de éxito, io_uring_register_buffers(3), io_uring_register_buffers_tags(3) y io_uring_register_buffers_sparse(3) devuelven 0. io_uring_register_buffers_update_tag(3) devuelve el número de búferes actualizados. En caso de error, devuelven -errno.
