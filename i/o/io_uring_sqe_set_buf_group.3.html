NOMBRE

io_uring_sqe_set_buf_group - establece el grupo de búferes para un evento de cola de sumisión

SINOPSIS

#include <liburing.h>
void io_uring_sqe_set_buf_group(struct io_uring_sqe *sqe,
                                int bgid);

DESCRIPCIÓN

La función io_uring_sqe_set_buf_group(3) establece el buf_group asociado de sqe a bgid.

Después de que el llamador ha solicitado una entrada de cola de sumisión (SQE) con io_uring_get_sqe(3), pueden asociar un buf_group con la SQE utilizada para operaciones multishot.

Ninguno
