io_set_callback(3) Linux AIO io_set_callback(3)

NOMBRE

io_set_callback - Configurar la función de devolución de llamada de finalización de E/S

SINOPSIS

#include <errno.h>

#include <libaio.h>

static inline void io_set_callback(struct iocb *iocb, io_callback_t cb);

struct iocb {
	void		*data;
	unsigned	key;
	short		aio_lio_opcode;
	short		aio_reqprio;
	int		aio_fildes;
};

typedef void (*io_callback_t)(io_context_t ctx, struct iocb *iocb, long res, long res2);

DESCRIPCIÓN

La devolución de llamada no se realiza si el llamador utiliza eventos brutos de io_getevents(3), solo con las utilidades de la biblioteca.

VALORES DE RETORNO

Ninguno.

ERRORES

Ninguno.
