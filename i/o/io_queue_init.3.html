io_queue_init(3) Linux AIO io_queue_init(3)

NOMBRE

io_queue_init - Inicializa la máquina de estados de E/S asíncrona

SINOPSIS

#include <errno.h>

#include <libaio.h>

int io_queue_init(int maxevents, io_context_t *ctx);

DESCRIPCIÓN

io_queue_init() intenta crear un contexto aio capaz de recibir al menos maxevents eventos. ctx debe apuntar a un contexto aio que ya exista y debe inicializarse a 0 antes de la llamada. Si la operación es exitosa, *cxtp se rellena con el manejador resultante.

VALORES DEVUELTOS

En caso de éxito, io_queue_init() devuelve 0. De lo contrario, se devuelve -error, donde error es uno de los valores Exxx definidos en la sección ERRORES.

ERRORES

EFAULT
iocbs hizo referencia a datos fuera del espacio de direcciones accesible del programa.
EINVAL
maxevents es <= 0 o ctx es una ubicación de memoria inválida.
ENOSYS
No implementado.
EAGAIN
maxevents > max_aio_reqs donde max_aio_reqs es un valor ajustable.
