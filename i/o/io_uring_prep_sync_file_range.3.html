NOMBRE

io_uring_prep_sync_file_range - prepara una solicitud sync_file_range

SINOPSIS

#include <fcntl.h>
#include <liburing.h>
void io_uring_prep_sync_file_range(struct io_uring_sqe *sqe,
                                   int fd,
                                   unsigned len,
                                   __u64 offset,
                                   int flags);

DESCRIPCIÓN

La función io_uring_prep_sync_file_range(3) prepara una solicitud sync_file_range. La entrada de la cola de envío sqe se configura para utilizar el descriptor de archivo fd al que se deben sincronizar len bytes comenzando desde el desplazamiento offset y con los modificadores de banderas en el argumento flags.

Esta función prepara una solicitud asíncrona de sync_file_range(2). Consulte esa página del manual para obtener detalles sobre los argumentos.

VALOR DE RETORNO

Ninguno

ERRORES

El campo res del CQE contendrá el resultado de la operación. Consulte la página del manual relacionada para obtener detalles sobre los valores posibles. Tenga en cuenta que donde las llamadas al sistema síncronas devolverán -1 en caso de fallo y establecerán errno al valor de error real, io_uring nunca utiliza errno. En su lugar, devuelve el errno negado directamente en el campo res del CQE.

VER TAMBIÉN

io_uring_get_sqe(3), io_uring_submit(3), sync_file_range(2)
