NOMBRE

io_uring_prep_link_timeout - una solicitud de tiempo de espera para sqes enlazados

SINOPSIS

#include <liburing.h>
void io_uring_prep_link_timeout(struct io_uring_sqe *sqe,
                                struct __kernel_timespec *ts,
                                unsigned flags);

DESCRIPCIÓN

La función io_uring_prep_link_timeout(3) prepara una solicitud de tiempo de espera para sqes enlazados. La entrada de la cola de envío (submission queue entry, sqe) sqe se configura con el tiempo de espera especificado por ts. El argumento flags contiene modificadores flags para el comportamiento de tiempo de espera de la solicitud.

El argumento ts debe completarse con la información apropiada para el tiempo de espera. Tiene el siguiente aspecto:


struct __kernel_timespec {
    __kernel_time64_t tv_sec;
    long long tv_nsec;
};

El argumento flags puede contener:

IORING_TIMEOUT_ABS
El valor especificado en ts es un valor absoluto en lugar de uno relativo.
IORING_TIMEOUT_BOOTTIME
Se debe usar la fuente de reloj boottime.
IORING_TIMEOUT_REALTIME
Se debe usar la fuente de reloj realtime.
IORING_TIMEOUT_ETIME_SUCCESS
Considerar un tiempo de espera expirado como un éxito en términos de la finalización publicada.

Es inválido crear una cadena (sqes enlazados) que consista únicamente en una solicitud de tiempo de espera de enlace. Si todas las solicitudes de la cadena se completan antes del tiempo de espera, la solicitud de tiempo de espera de enlace se cancela. Al expirar el tiempo de espera, todas las solicitudes no completadas de la cadena se cancelan.

VALOR DE RETORNO

Ninguno

ERRORES

Estos son los errores que se informan en el campo res de la CQE. En caso de éxito, se devuelve 0.

-ETIME
Se produjo el tiempo de espera especificado y activó el evento de finalización.
-EINVAL
Uno de los campos configurados en la SQE era inválido. Por ejemplo, se proporcionaron dos fuentes de reloj, o los segundos o nanosegundos del tiempo de espera especificado eran < 0.
-EFAULT
io_uring no pudo acceder a los datos especificados por ts.
-ECANCELED
El tiempo de espera se canceló porque todas las solicitudes enviadas se completaron con éxito o una de las solicitudes resultó en un fallo.
-ENOENT
La solicitud a la que estaba enlazado el tiempo de espera de enlace ya se completó y no se pudo encontrar cuando expiró el temporizador.
