ioctl_fat(2) Manual de llamadas al sistema ioctl_fat(2)

NOMBRE

ioctl_fat - manipulación del sistema de archivos FAT

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <sys/ioctl.h>
int ioctl(int fd, unsigned long op, ...);

DESCRIPCIÓN

La llamada al sistema ioctl(2) se puede utilizar para leer y escribir metadatos de sistemas de archivos FAT que no son accesibles mediante otras llamadas al sistema. Los siguientes valores de op están disponibles.

Lectura y establecimiento de atributos de archivo

FAT_IOCTL_GET_ATTRIBUTES(2const)
FAT_IOCTL_SET_ATTRIBUTES(2const)

Lectura del ID del volumen

FAT_IOCTL_GET_VOLUME_ID(2const)

Lectura de nombres cortos de un directorio

VFAT_IOCTL_READDIR_BOTH(2const)
VFAT_IOCTL_READDIR_SHORT(2const)

VALOR DE RETORNO

En caso de éxito, se devuelve un valor no negativo. En caso de error, se devuelve -1 y se establece errno para indicar el error.

ERRORES

ENOTTY
El descriptor de archivo fd no se refiere a un objeto en un sistema de archivos FAT.

ESTÁNDARES

Linux.

VER TAMBIÉN

ioctl(2)
