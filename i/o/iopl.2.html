iopl(2) Manual de llamadas al sistema iopl(2)

NOMBRE

iopl - cambiar el nivel de privilegio de E/S

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <sys/io.h>
[[deprecated]] int iopl(int level);

DESCRIPCIÓN

iopl() cambia el nivel de privilegio de E/S del hilo llamante, según lo especificado por los dos bits menos significativos de level.

El nivel de privilegio de E/S para un hilo normal es 0. Los permisos se heredan de los padres a los hijos.

Esta llamada está obsoleta, es significativamente más lenta que ioperm(2), y solo se proporciona para servidores X más antiguos que requieren acceso a los 65536 puertos de E/S. Es principalmente para la arquitectura i386. En muchas otras arquitecturas no existe o siempre devolverá un error.

VALOR DE RETORNO

En caso de éxito, se devuelve cero. En caso de error, se devuelve -1 y errno se establece para indicar el error.

ERRORES

EINVAL
level es mayor que 3.
ENOSYS
Esta llamada no está implementada.
EPERM
El hilo llamante tiene privilegios insuficientes para llamar a iopl(); se requiere la capacidad CAP_SYS_RAWIO para elevar el nivel de privilegio de E/S por encima de su valor actual.

VERSIÓNES

glibc2 tiene un prototipo tanto en <sys/io.h> como en <sys/perm.h>. Evite este último, solo está disponible en i386.

ESTÁNDARES

Linux.

HISTORIA

Antes de Linux 5.5, iopl() permitía al hilo deshabilitar las interrupciones mientras se ejecutaba en un nivel de privilegio de E/S más alto. Esto probablemente bloqueará el sistema y no se recomienda.

Antes de Linux 3.7, en algunas arquitecturas (como i386), los permisos se heredaban por el hijo producido por fork(2) y se conservaban a través de execve(2). Este comportamiento cambió inadvertidamente en Linux 3.7 y no se restablecerá.

VER TAMBIÉN

ioperm(2), outb(2), capabilities(7)
