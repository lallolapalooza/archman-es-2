NOMBRE

io.elementary.code - editor de texto que trabaja para ti

SINOPSIS

io.elementary.code [OPCIÓN...] [ARCHIVO...]

DESCRIPCIÓN

Code es el editor de texto que trabaja para ti. Guarda automáticamente tus archivos, lo que significa que siempre están actualizados. Además, recuerda tus pestañas para que nunca pierdas tu lugar, incluso entre sesiones.

Hazlo tuyo. Code está escrito desde cero para ser extensible. Mantenlo súper ligero y simple, o instala extensiones para convertir Code en un IDE completo; es tu elección. Y con un puñado de preferencias útiles, puedes ajustar el comportamiento y la interfaz a tu gusto.

Es elementary. Code está hecho para ser el editor de texto perfecto para elementary OS, lo que significa que sigue de cerca los altos estándares de diseño, velocidad y consistencia. Es atractivo, pero no distrae.

Funciona con tu lenguaje. Ya sea que estés creando código en Vala, escribiendo scripts con PHP, o marcando cosas en HTML, Code te cubre. Experimenta el resaltado de sintaxis completo con casi todos los lenguajes de programación, scripting y marcado.

OPCIONES

-t, --new-tab
Abrir una nueva pestaña.
-n, --new-window
Abrir una nueva ventana.
-h, --help
Mostrar un mensaje de ayuda y salir.
-v, --version
Imprimir información de la versión y salir.
--display=MOSTRAR
Pantalla X a usar.
