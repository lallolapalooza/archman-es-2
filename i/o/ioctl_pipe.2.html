ioctl_pipe(2) Manual de llamadas al sistema ioctl_pipe(2)

NOMBRE

ioctl_pipe - operaciones de ioctl() para el mecanismo de notificación general

SINOPSIS

#include <linux/watch_queue.h>  /* Definición de IOC_WATCH_QUEUE_* */
#include <sys/ioctl.h>
int ioctl(int pipefd, IOC_WATCH_QUEUE_SET_SIZE, int size);
int ioctl(int pipefd, IOC_WATCH_QUEUE_SET_FILTER,
          struct watch_notification_filter *filter);

DESCRIPCIÓN

Las siguientes operaciones de ioctl(2) se proporcionan para configurar los parámetros de la cola de notificación general. La cola de notificación se construye sobre una pipe(2) abierta con el flag O_NOTIFICATION_PIPE.

IOC_WATCH_QUEUE_SET_SIZE (desde Linux 5.8)
Preasigna memoria para el buffer de la tubería para que pueda contener size mensajes de notificación. Actualmente, size debe estar entre 1 y 512.
IOC_WATCH_QUEUE_SET_FILTER (desde Linux 5.8)
El filtro de la cola de vigilancia puede limitar los eventos que se reciben. Los filtros se pasan en una struct watch_notification_filter y cada filtro se describe mediante una estructura struct watch_notification_type_filter.

struct watch_notification_filter {
        __u32   nr_filters;
        __u32   __reserved;
        struct watch_notification_type_filter filters[];
};
struct watch_notification_type_filter {
        __u32   type;
        __u32   info_filter;
        __u32   info_mask;
        __u32   subtype_filter[8];
};

VER TAMBIÉN

pipe(2), ioctl(2)
