IJS-CONFIG(1) Manual de comandos generales IJS-CONFIG(1)

NOMBRE

ijs-config - script para obtener información sobre la versión instalada de ijs

SINOPSIS

ijs-config [--prefix[=DIR]] [--exec-prefix[=DIR]] [--version] [--libs] [--cflags]

DESCRIPCIÓN

ijs-config es un programa que se utiliza para determinar las banderas del compilador y del enlazador que se deben utilizar para compilar y enlazar programas que utilizan IJS.

OPCIONES

Este programa sigue la sintaxis habitual de línea de comandos de GNU, con opciones largas que comienzan con dos guiones (`-'). A continuación se incluye un resumen de las opciones.

--help
Muestra un resumen de las opciones. Esto puede listar opciones adicionales avanzadas de configuración de paquetes que no se detallan en esta página del manual.
--version
Muestra la versión de libijs instalada.
--libs
Imprime las banderas del enlazador que son necesarias para enlazar un programa de IJS.
--cflags
Imprime las banderas del compilador que son necesarias para compilar un programa de IJS.
--prefix=PREFIX
Si se especifica, utiliza PREFIX en lugar del prefijo de instalación con el que se compiló IJS al calcular la salida para las opciones --cflags y --libs. Esta opción también se utiliza para el prefijo de ejecución si no se especificó --exec-prefix. Esta opción debe especificarse antes de cualquier opción --libs o --cflags.
--exec-prefix=PREFIX
Si se especifica, utiliza PREFIX en lugar del prefijo de ejecución de instalación con el que se compiló IJS al calcular la salida para las opciones --cflags y --libs. Esta opción debe especificarse antes de cualquier opción --libs o --cflags.
