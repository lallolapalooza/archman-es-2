ijq(1) Manual de Comandos Generales ijq(1)

NOMBRE

ijq - jq interactivo

SINOPSIS

ijq [-cnsrRMSV] [-f archivo] [filtro] [archivos ...]

DESCRIPCIÓN

ijq es un reemplazo casi directo para jq que te permite ver interactivamente los resultados de tu filtro mientras lo construyes.

ijq contiene dos paneles y un campo de entrada: el panel izquierdo son los datos de entrada originales sin modificar y el panel derecho contiene la salida filtrada. Cuando hayas terminado, presiona Enter o Ctrl-C para salir. La salida filtrada se escribirá en la salida estándar y el filtro se escribirá en el error estándar.

ijq mantiene un historial de filtros utilizados, a menos que se deshabilite con la opción -H. Borra todo el texto en el campo del filtro para explorar cualquier historial disponible.

Si se omite archivos, ijq lee los datos de la entrada estándar.

Todas las opciones reflejan sus contrapartes en jq. Las opciones son:

-c

Utiliza salida compacta en lugar de salida con formato (pretty-printed).

-n

No lee ninguna entrada. Útil para usar ijq como calculadora o para construir datos JSON desde cero.

-s

Lee toda la entrada en una sola matriz y aplica el filtro dado.

-r

Si la salida del filtro es una cadena, se escribirá directamente en la salida estándar en lugar de ser formateada como una cadena JSON con comillas. Útil para usar ijq en un pipeline con otros programas que esperan entrada de cadena normal.

-R

No analiza la entrada como JSON, sino que pasa cada línea de entrada al filtro como una cadena. Si se combina con -s, toda la entrada se pasa al filtro como una única cadena larga.

-M

Deshabilita la salida a color.

-S

Muestra los campos de cada objeto con los campos en orden ordenado.

-f archivo

Lee el filtro desde archivo. Cuando se utiliza esta opción, todos los argumentos posicionales (si los hay) se interpretan como archivos de entrada.

ijq tiene algunas opciones que influyen en su configuración y disposición inicial. Están diseñadas para evitar conflictos con jq. Si jq agrega en el futuro una opción que entre en conflicto con alguna de estas, podrían cambiar aquí.

-H archivo

Especifica la ruta para almacenar el historial. Si se establece en '' (-H ''), el historial no se capturará.

-hide-input-pane

Oculta el panel de visualización de entrada (izquierdo), que muestra la entrada original.

ATAJOS DE TECLADO

Shift + Arriba, Shift + Izquierda

Enfoca el panel de visualización de entrada (izquierdo).

Shift + Derecha

Enfoca el panel de visualización de salida (derecho).

Shift + Abajo

Enfoca el campo de entrada de texto.

Tab

Cuando el campo de entrada de texto tiene el foco, navega entre la lista de autocompletado. Cuando uno de los paneles de visualización tiene el foco, alterna entre las diferentes vistas.

Shift-Tab

Similar a Tab, pero se mueve en la dirección opuesta.

Ctrl-A

Cuando el campo de entrada de texto tiene el foco, mueve el cursor al principio de la entrada. Cuando uno de los paneles de visualización tiene el foco, establece el desplazamiento de columna a 0.

Ctrl-E

Cuando el campo de entrada de texto tiene el foco, mueve el cursor al final de la entrada. Cuando uno de los paneles de visualización tiene el foco, establece el desplazamiento de columna para ver la línea visible más larga.

Ctrl-F

Cuando el campo de entrada de texto tiene el foco, mueve el cursor un carácter hacia adelante. Cuando uno de los paneles de visualización tiene el foco, desplaza hacia abajo una página.

Ctrl-B

Cuando el campo de entrada de texto tiene el foco, mueve el cursor un carácter hacia atrás. Cuando uno de los paneles de visualización tiene el foco, desplaza hacia arriba una página.

Ctrl-D

Cuando el campo de entrada de texto tiene el foco, elimina el carácter debajo del cursor. Cuando uno de los paneles de visualización tiene el foco, desplaza hacia abajo media página.

Ctrl-U

Cuando el campo de entrada de texto tiene el foco, elimina todo el texto desde el cursor hasta el principio del campo. Cuando uno de los paneles de visualización tiene el foco, desplaza hacia arriba media página.

Ctrl-O

Alterna la visibilidad del panel de visualización de entrada (izquierdo).

u, d, f, b

Cuando uno de los paneles de visualización tiene el foco, desplaza una media/página completa hacia arriba/abajo.

Izquierda, Abajo, Arriba, Derecha h, j, k, l

Cuando uno de los paneles de visualización tiene el foco, mueve la vista a la izquierda/abajo/arriba/derecha.

Enter

Cierra ijq. Escribe el contenido del panel de salida en stdout y el filtro de entrada actual en stderr. El filtro de entrada actual también se guarda en el archivo de historial.

Ctrl-C

Sale de ijq inmediatamente, descartando todo el estado.
