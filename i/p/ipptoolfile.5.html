NOMBRE

ipptoolfile - formato de archivo de ipptool

DESCRIPCIÓN

El ipptool(1) programa acepta archivos de texto plano de formato libre que describen una o más solicitudes IPP. Los comentarios comienzan con el carácter "#" y continúan hasta el final de la línea. Cada solicitud está encerrada entre llaves, por ejemplo:

    # Este es un comentario
    {
      # El nombre de la prueba
      NAME "Print PDF File"
      # La solicitud a enviar
      OPERATION Print-Job
      GROUP operation-attributes-tag
      ATTR charset attributes-charset utf-8
      ATTR language attributes-natural-language en
      ATTR uri printer-uri $uri
      ATTR name requesting-user-name $user
      ATTR mimeMediaType document-format application/pdf
      GROUP job-attributes-tag
      ATTR collection media-col {
        # Papel plano tamaño carta de EE. UU. de la bandeja "main"
        MEMBER collection media-size {
          MEMBER integer x-dimension 21590
          MEMBER integer y-dimension 27940
        }
        MEMBER integer media-top-margin 423
        MEMBER integer media-bottom-margin 423
        MEMBER integer media-left-margin 423
        MEMBER integer media-right-margin 423
        MEMBER keyword media-source "main"
        MEMBER keyword media-type "stationery"
      }
      FILE testfile.pdf
      # La respuesta esperada
      STATUS successful-ok
      EXPECT job-id OF-TYPE integer WITH-VALUE >0
      EXPECT job-uri OF-TYPE uri
    }
    {
      # El nombre de la prueba
      NAME "Wait for Job to Complete"
      # La solicitud a enviar
      OPERATION Get-Job-Attributes
      GROUP operation-attributes-tag
      ATTR charset attributes-charset utf-8
      ATTR language attributes-natural-language en
      ATTR uri printer-uri $uri
      ATTR integer job-id $job-id
      ATTR name requesting-user-name $user
      # La respuesta esperada
      STATUS successful-ok
      EXPECT job-id OF-TYPE integer WITH-VALUE $job-id
      EXPECT job-uri OF-TYPE uri
      EXPECT job-state OF-TYPE enum WITH-VALUE >5 REPEAT-NO-MATCH
      EXPECT job-originating-user-name OF-TYPE name WITH-VALUE "$user"
      # Mostrar el estado del trabajo hasta que se complete...
      DISPLAY job-state
      DISPLAY job-state-reasons
    }

DIRECTIVAS DE NIVEL SUPERIOR

Las siguientes directivas pueden usarse fuera de un test:

{ test }
Define una prueba.
DEFINE nombre-variable valor
Define la variable con el nombre dado al valor especificado. Esto es equivalente a especificar -d nombre-variable=valor en la ipptool(8) línea de comandos.
DEFINE-DEFAULT nombre-variable valor
Define la variable con el nombre dado al valor especificado si aún no tiene un valor.
FILE-ID "identificador"
Especifica una cadena de identificación para el archivo actual.
IGNORE-ERRORS yes
IGNORE-ERRORS no
Especifica si, de forma predeterminada, ipptool(8) ignorará los errores y continuará con las pruebas siguientes.
INCLUDE "nombre-archivo"
INCLUDE <nombre-archivo>
Incluye otro archivo de prueba. La primera forma incluye un archivo relativo al archivo de prueba actual, mientras que la segunda forma incluye un archivo del directorio de inclusión de ipptool(8) .
INCLUDE-IF-DEFINED nombre "nombre-archivo"
INCLUDE-IF-DEFINED nombre <nombre-archivo>
Incluye otro archivo de prueba si la variable con el nombre dado está definida. La primera forma incluye un archivo relativo al archivo de prueba actual, mientras que la segunda forma incluye un archivo del directorio de inclusión de ipptool(8) .
INCLUDE-IF-NOT-DEFINED nombre "nombre-archivo"
INCLUDE-IF-NOT-DEFINED nombre <nombre-archivo>
Incluye otro archivo de prueba si la variable con el nombre dado no está definida. La primera forma incluye un archivo relativo al archivo de prueba actual, mientras que la segunda forma incluye un archivo del directorio de inclusión de ipptool(8) .
SKIP-IF-DEFINED nombre-variable
SKIP-IF-NOT-DEFINED nombre-variable
Especifica que el resto del archivo de prueba debe omitirse cuando la variable está o no está definida.
STOP-AFTER-INCLUDE-ERROR no
STOP-AFTER-INCLUDE-ERROR yes
Especifica si las pruebas se detendrán después de un error en un archivo incluido.
TRANSFER auto
Especifica que las pruebas usarán, de forma predeterminada, "Transfer-Encoding: chunked" para solicitudes con archivos adjuntos y "Content-Length:" para solicitudes sin archivos adjuntos.
TRANSFER chunked
Especifica que las pruebas usarán, de forma predeterminada, la cabecera HTTP/1.1 "Transfer-Encoding: chunked". Esta es la predeterminada y es equivalente a especificar -c en la ipptool(8) línea de comandos. El soporte para solicitudes chunked es necesario para la conformidad con todas las versiones de IPP.
TRANSFER length
Especifica que las pruebas usarán, de forma predeterminada, la cabecera HTTP/1.0 "Content-Length:". Esto es equivalente a especificar -l en la ipptool(8) línea de comandos. El soporte para solicitudes con longitud de contenido es necesario para la conformidad con todas las versiones de IPP.
VERSION 1.0
VERSION 1.1
VERSION 2.0
VERSION 2.1
VERSION 2.2
Especifica el número de versión de IPP predeterminado a usar para las pruebas siguientes.

DIRECTIVAS DE PRUEBA

Las siguientes directivas se entienden dentro de un test:

ATTR etiqueta-fuera-de-banda nombre-atributo
ATTR etiqueta nombre-atributo valor(es)
Añade un atributo a la solicitud de prueba. Las etiquetas fuera de banda (admin-define, delete-attribute, no-value, not-settable, unknown, unsupported) no tienen valor. Los valores para otras etiquetas están delimitados por el carácter coma (",") - escape las comas usando el carácter "\". Los atributos y valores comunes se enumeran en el registro IPP de IANA - ver las referencias más abajo.
ATTR collection nombre-atributo { MEMBER etiqueta nombre-miembro valor(es) ... } [ ... ,{ ... } ]
Añade un atributo de colección a la solicitud de prueba. Los atributos miembro siguen la misma sintaxis que los atributos normales y pueden ser a su vez colecciones anidadas. Se pueden proporcionar múltiples valores de colección según sea necesario, separados por comas.
COMPRESSION deflate
COMPRESSION gzip
COMPRESSION none
Usa la compresión especificada en los datos del documento que siguen a los atributos en una solicitud Print-Job o Send-Document.
DELAY segundos[,repeat-seconds]
Especifica un retraso en segundos antes de que se ejecute esta prueba. Si se especifican dos valores, el segundo valor se usa como el retraso entre pruebas repetidas. Se usa un intervalo de repetición predeterminado de 5 segundos si no se proporciona esta directiva.
DISPLAY attribute-name
Especifica que el valor del atributo con nombre debe mostrarse como parte del informe de la prueba.
EXPECT attribute-name [ predicate(s) ]
EXPECT ?attribute-name predicate(s)
EXPECT !attribute-name
Especifica que la respuesta debe/puede/no debe incluir el atributo con nombre. Se pueden agregar requisitos adicionales como predicados - consulte la sección "EXPECT PREDICATES" para obtener más información sobre los predicados. Los nombres de atributos pueden especificar atributos miembro separando el nombre del atributo y el nombre del miembro con la barra inclinada, por ejemplo "media-col/media-size/x-dimension".
EXPECT-ALL attribute-name [ predicate(s) ]
EXPECT-ALL ?attribute-name predicate(s)
Especifica que la respuesta debe/puede incluir el atributo con nombre y que todas las ocurrencias de ese atributo deben coincidir con los predicados dados.
FILE filename
Especifica un archivo para incluir al final de la solicitud. Esto se usa típicamente al enviar un archivo de prueba de impresión.
GROUP tag
Especifica la etiqueta de grupo para los atributos posteriores en la solicitud.
IGNORE-ERRORS yes
IGNORE-ERRORS no
Especifica si ipptool(8) ignorará errores y continuará con pruebas posteriores.
MONITOR-PRINTER-STATE [ printer-uri ] { EXPECT attribute-name [ predicate(s) ] }
Especifica pruebas de monitoreo del estado de la impresora para ejecutar en paralelo con la operación de prueba. Las pruebas de monitoreo se ejecutarán hasta que todas las EXPECT condiciones se satisfagan o la operación de prueba principal haya completado, lo que ocurra primero.
NAME "literal string"
Especifica el nombre legible para humanos de la prueba.
OPERATION operation-code
Especifica la operación a realizar.
PASS-IF-DEFINED variable-name
PASS-IF-NOT-DEFINED variable-name
Especifica que la prueba actual debe aprobarse automáticamente cuando la variable está o no está definida.
PAUSE "message"
Muestra el mensaje proporcionado y espera a que el usuario presione una tecla para continuar.
REQUEST-ID number
REQUEST-ID random
Especifica el valor de request-id a usar en la solicitud, ya sea un entero o la palabra "random" para usar un valor generado aleatoriamente (el predeterminado).
RESOURCE path
Especifica una ruta de recurso alternativa que se usa para la solicitud HTTP POST. El predeterminado es el recurso de la URI proporcionada al ipptool(8) programa.
SKIP-IF-DEFINED variable-name
SKIP-IF-NOT-DEFINED variable-name
Especifica que la prueba actual debe omitirse cuando la variable está o no está definida.
SKIP-PREVIOUS-ERROR yes
SKIP-PREVIOUS-ERROR no
Especifica si ipptool(8) omitirá la prueba actual si la prueba anterior resultó en un error/fallo.
STATUS status-code [ predicate ]
Especifica un valor de código de estado de respuesta esperado. Se pueden agregar requisitos adicionales como predicados - consulte la sección "STATUS PREDICATES" para obtener más información sobre los predicados.
TEST-ID "identifier"
Especifica una cadena de identificador para la prueba actual.
TRANSFER auto
Especifica que esta prueba usará "Transfer-Encoding: chunked" si tiene un archivo adjunto o "Content-Length:" de lo contrario.
TRANSFER chunked
Especifica que esta prueba usará el encabezado HTTP/1.1 "Transfer-Encoding: chunked".
TRANSFER length
Especifica que esta prueba usará el encabezado HTTP/1.0 "Content-Length:".
VERSION 1.0
VERSION 1.1
VERSION 2.0
VERSION 2.1
VERSION 2.2
Especifica el número de versión de IPP a usar para esta prueba.

EXPECT PREDICATES

Los siguientes predicados se entienden después de la EXPECT directiva de prueba:

COUNT number
Requiere que el EXPECT atributo tenga el número especificado de valores.
DEFINE-MATCH variable-name
Define la variable a "1" cuando la EXPECT condición coincide. Un efecto secundario de este predicado es que este EXPECT nunca fallará una prueba.
DEFINE-NO-MATCH variable-name
Define la variable a "1" cuando la EXPECT condición no coincide. Un efecto secundario de este predicado es que este EXPECT nunca fallará una prueba.
DEFINE-VALUE variable-name
Define la variable al valor del atributo cuando la EXPECT condición coincide. Un efecto secundario de este predicado es que este EXPECT nunca fallará una prueba.
DISPLAY-MATCH "message"
Muestra el mensaje especificado cuando la EXPECT condición coincide.
IF-DEFINED variable-name
Hace que las EXPECT condiciones se apliquen solo si la variable especificada está definida.
IF-NOT-DEFINED variable-name
Hace que las EXPECT condiciones se apliquen solo si la variable especificada no está definida.
IN-GROUP tag
Requiere que el EXPECT atributo esté en la etiqueta de grupo especificada.
OF-TYPE tag[(limits)|tag|...]
Requiere que el EXPECT atributo use una de las etiquetas de valor especificadas. La mayoría de las etiquetas de valor también admiten la especificación de límites en paréntesis, por ejemplo "name(42)" permitiría cadenas nameWith/WithoutLanguage de hasta 42 octetos de longitud, "name(4:MAX)" permitiría cadenas nameWith/WithoutLanguage entre 4 y 255 octetos de longitud, y "integer(-273:MAX)" permitiría enteros entre -273 y 2147483647.
REPEAT-LIMIT number

Especifica el número máximo de veces a repetir si se REPEAT-MATCH o REPEAT-NO-MATCH predicado está especificado. El valor predeterminado es 1000.
REPEAT-MATCH
REPEAT-NO-MATCH
Especifica que la prueba actual debe repetirse cuando la EXPECT condición coincide o no coincide.
SAME-COUNT-AS attribute-name
Requiere que el EXPECT atributo tenga el mismo número de valores que el atributo paralelo especificado.
WITH-ALL-HOSTNAMES "literal string"
WITH-ALL-HOSTNAMES "/regular expression/"
Requiere que todos los valores URI contengan un nombre de host coincidente.
WITH-ALL-RESOURCES "literal string"
WITH-ALL-RESOURCES "/regular expression/"
Requiere que todos los valores URI contengan un recurso coincidente (incluyendo la barra inclinada inicial /).
WITH-ALL-SCHEMES "literal string"
WITH-ALL-SCHEMES "/regular expression/"
Requiere que todos los valores URI contengan un esquema coincidente.
WITH-ALL-VALUES "literal string"
Requiere que todos los valores del EXPECT atributo coincidan con la cadena literal. Las comparaciones distinguen mayúsculas y minúsculas.
WITH-ALL-VALUES <number
WITH-ALL-VALUES =número
WITH-ALL-VALUES >número
WITH-ALL-VALUES número[,...,número]
Requiere que todos los valores del atributo EXPECT coincidan con el(los) número(s) o la comparación numérica. Al comparar valores de rango de enteros, los operadores "<" y ">" solo verifican el límite superior del rango.
WITH-ALL-VALUES "false"
WITH-ALL-VALUES "true"
Requiere que todos los valores del atributo EXPECT coincidan con el valor booleano proporcionado.
WITH-ALL-VALUES "/expresión regular/"
Requiere que todos los valores del atributo EXPECT coincidan con la expresión regular, la cual debe cumplir con la sintaxis de expresiones regulares POSIX. Las comparaciones distinguen entre mayúsculas y minúsculas.
WITH-DISTINCT-VALUES
Requiere que todos los valores del atributo EXPECT sean únicos. Las comparaciones distinguen entre mayúsculas y minúsculas. Solo los atributos charset, collection, enum, integer, keyword, mimeMediaType, naturalLanguage, rangeOfInteger, resolution, uriScheme soportan este predicado.
WITH-HOSTNAME "cadena literal"
WITH-HOSTNAME "/expresión regular/"
Requiere que al menos un valor URI contenga un nombre de host coincidente.
WITH-RESOURCE "cadena literal"
WITH-RESOURCE "/expresión regular/"
Requiere que al menos un valor URI contenga un recurso coincidente (incluyendo la barra diagonal inicial).
WITH-SCHEME "cadena literal"
WITH-SCHEME "/expresión regular/"
Requiere que al menos un valor URI contenga un esquema coincidente.
WITH-VALUE "cadena literal"
Requiere que al menos un valor del atributo EXPECT coincida con la cadena literal. Las comparaciones distinguen entre mayúsculas y minúsculas.
WITH-VALUE <número
WITH-VALUE =número
WITH-VALUE >número
WITH-VALUE número[,...,número]
Requiere que al menos un valor del atributo EXPECT coincida con el(los) número(s) o la comparación numérica. Al comparar valores de rango de enteros, los operadores "<" y ">" solo verifican el límite superior del rango.
WITH-VALUE "false"
WITH-VALUE "true"
Requiere que al menos un valor del atributo EXPECT coincida con el valor booleano proporcionado.
WITH-VALUE "/expresión regular/"
Requiere que al menos un valor del atributo EXPECT coincida con la expresión regular, la cual debe cumplir con la sintaxis de expresiones regulares POSIX. Las comparaciones distinguen entre mayúsculas y minúsculas.
WITH-VALUE-FROM nombre de atributo
Requiere que el(los) valor(es) del atributo EXPECT coincida(n) con el(los) valor(es) del atributo especificado. Por ejemplo, "EXPECT job-sheets WITH-VALUE-FROM job-sheets-supported" requiere que el valor "job-sheets" esté listado como un valor del atributo "job-sheets-supported".

NAME


ipptoolfile — IPP Tool test file format






DESCRIPTION


ipptool(8) can be used to test IPP servers using
    commands described in a file. This document describes the format of these
    command files.


Command files are UTF-8 encoded text files. Each line in the file
    represents a command, a directive, or a comment. Lines starting with the '#'
    character are comments and are ignored. Empty lines are also ignored.


The following directives are supported:



  
DEFINE name value

  
Defines a variable named name with the specified value.
      Variable names can contain letters, digits, and hyphens. The value
      can be any string. See also the VARIABLES section.

  
DEFINE_GROUP name tag

  
Defines a variable named name with the specified group tag.
      See also the TAGS section.

  
DEFINE_VALUE name tag

  
Defines a variable named name with the specified value tag.
      See also the TAGS section.

  
END

  
Stops processing the test file.

  
EXPECT [ - | + ] tag [ name
      ] [ value ]

  
Adds an expected attribute to the response. The optional - or
      + prefixes indicate that the attribute MUST NOT be present or MUST
      be present, respectively. If no prefix is given, the attribute MAY be
      present. If the name is omitted, any attribute with the specified
      tag is matched. If the value is omitted, any value is
      matched.

  
LOGLEVEL level

  
Sets the logging level. Supported levels are error, warn,
      info, debug, debug1, debug2, and
      debug3.

  
MESSAGE message

  
Prints the specified message to standard output.

  
REMOTE_LOGLEVEL level

  
Sets the remote logging level. Supported levels are the same as for
      LOGLEVEL.

  
REMOTE_LOG_TARGET target

  
Sets the remote logging target. The default is "ipp://localhost:631/".

  
REQUEST [ operation ] [ group
      ] [ name=value ... ]

  
Sends an IPP request. The operation defaults to
      Print-Job. The group defaults to
      operation-attributes-tag. See also the TAGS section.

  
RESPONSE [ operation ] [ group
      ] [ name=value ... ]

  
Sends an IPP request and expects a specific response. The operation
      defaults to Print-Job. The group defaults to
      operation-attributes-tag.

  
SUPPRESS [ - | + ] tag [
      name ]

  
Suppresses checking for the specified attribute. The optional - or
      + prefixes indicate that the attribute MUST NOT be present or MUST
      be present, respectively. If no prefix is given, the attribute MAY be
      present. If the name is omitted, all attributes with the specified
      tag are suppressed.

  
WAIT seconds

  
Waits for the specified number of seconds.




The following operations are supported:


    Cancel-Job
    Cancel-Subscription
    Create-Printer
    Create-Job
    Get-Attributes
    Get-Notifications
    Get-Printer-Attributes
    Pause-Printer
    Print-Job
    Print-Get-File
    Print-Set-File
    Purge-Jobs
    Ready-To-Print
    Reject-Job
    Restart-Printer
    Send-Document
    Send-File
    Set-Attributes
    Set-Printer-Attributes
    Shutdown
    Start-Printer
    Ublack
    Uclose-Job
    Ucreate-Media-Source
    Ucreate-Resource
    Udelete-Media-Source
    Udelete-Resource
    Uget-Active-Jobs
    Uget-Media-Source-Attributes
    Uget-Resource-Attributes
    Uindex
    Uopen-Job
    Uprint-Media-Source
    Uprint-Resource
    Uput-File
    Ureject-Job
    Urenew-Subscription
    Usubscribe
    Uupdate-Resource
    Uget-Notifications

The following status codes are supported:


    successful-ok

VARIABLES


The ipptool(8) program maintains a list of variables that
    can be used in any literal string or attribute value by specifying
    "$variable-name". Aside from variables defined using the
    -d option or DEFINE directive, the following pre-defined
    variables are available:



  
$$

  
Inserts a single "$" character.

  
$ENV[name]

  
Inserts the value of the named environment variable, or an empty string if
      the environment variable is not defined.

  
$date-current

  
Inserts the current date and time using the ISO-8601 format
      ("yyyy-mm-ddThh:mm:ssZ").

  
$date-start

  
Inserts the starting date and time using the ISO-8601 format
      ("yyyy-mm-ddThh:mm:ssZ").

  
$filename

  
Inserts the filename provided to ipptool(8) with the -f
      option.

  
$filetype

  
Inserts the MIME media type for the filename provided to ipptool(8)
      with the -f option.

  
$hostname

  
Inserts the hostname from the URI provided to ipptool(8).

  
$job-id

  
Inserts the last "job-id" attribute value returned in a test
      response or 0 if no "job-id" attribute has been seen.

  
$job-uri

  
Inserts the last "job-uri" attribute value returned in a test
      response or an empty string if no "job-uri" attribute has been
      seen.

  
$notify-subscription-id

  
Inserts the last "notify-subscription-id" attribute value
      returned in a test response or 0 if no "notify-subscription-id"
      attribute has been seen.

  
$port

  
Inserts the port number from the URI provided to ipptool(8).

  
$resource

  
Inserts the resource path from the URI provided to ipptool(8).

  
$scheme

  
Inserts the scheme from the URI provided to ipptool(8).

  
$uri

  
Inserts the URI provided to ipptool(8).

  
$uriuser

  
Inserts the username from the URI provided to ipptool(8), if
    any.

  
$user

  
Inserts the current user's login name.
