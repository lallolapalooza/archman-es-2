DESCRIPCIÓ

N

El demonio ipmi_sim emula un simulador de BMC IPMI al que se puede acceder usando el protocolo LAN IPMI 1.5 o 2.0, o a través de varios protocolos serie. Es útil de forma independiente para prototipado, se puede usar con una máquina virtual como QEMU para proporcionar un emulador de BMC IPMI, y se puede usar para implementar un BMC real (donde ya no es tanto un simulador) ipmi_sim soporta todas las capacidades de autenticación del protocolo IPMI

LAN.

ipmi_sim soporta múltiples direcciones IP para tolerancia a fallos. Tenga en cuenta que los mensajes que llegan por una dirección siempre se envían de vuelta por la misma dirección por la que

llegaron.

Serial Over LAN

(SOL)

ipmi_sim implementa Serial Over LAN para conectar una conexión RMCP+ a un puerto serie Unix estándar. Esto se configura en el archivo de configuración ipmi_lan(5)

.

Una interfaz SOL se realiza por MC. Así que si el MC está configurado como un no-BMC, puede definir una interfaz SOL en él y funcionará si enruta los comandos a ese MC. Es un poco extraño, pero funciona. Solo se soporta la interfaz 1 en este

momento.

Una interfaz SOL también puede mantener un historial que se conserva aunque no haya nada conectado a la interfaz SOL desde la LAN. Así que si quiere ver qué ha pasado en el puerto serie, puede conectarse a la interfaz 2 y esta volcará el historial. El historial es opcionalmente persistente, si el programa termina normalmente y se reinicia, el historial se restaura si está configurado para

hacerlo.

Una interfaz SOL puede crear un FRU en

el MC para permitirle obtener el
historial a través de la interfaz FRU.
