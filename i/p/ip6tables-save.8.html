IPTABLES-SAVE(8) iptables 1.8.11 IPTABLES-SAVE(8)

NOMBRE

iptables-save — volcar reglas de iptables

ip6tables-save — volcar reglas de iptables

SINOPSIS

iptables-save [-M modprobe] [-c] [-t tabla] [-f archivo]

ip6tables-save [-M modprobe] [-c] [-t tabla] [-f archivo]

DESCRIPCIÓN

iptables-save e ip6tables-save se utilizan para volcar el contenido de la Tabla IP o IPv6 en un formato fácilmente analizable, ya sea a STDOUT o a un archivo especificado.

-M, --modprobe modprobe
Especifica la ruta al programa modprobe(8). Por defecto, iptables-save inspeccionará /proc/sys/kernel/modprobe para determinar la ruta del ejecutable.
-f, --file archivo
Especifica un nombre de archivo para registrar la salida. Si no se especifica, iptables-save registrará en STDOUT.
-c, --counters
Incluye los valores actuales de todos los contadores de paquetes y bytes en la salida.
-t, --table nombretabla
Restringe la salida a una sola tabla. Si el kernel está configurado con carga automática de módulos, se intentará cargar el módulo apropiado para esa tabla si aún no está presente.
Si no se especifica, la salida incluye todas las tablas disponibles. No se realiza carga de módulos, por lo que para incluir una tabla específica en la salida, el módulo respectivo (algo como iptable_mangle o ip6table_raw) debe cargarse primero.

ERRORES

Ninguno conocido desde la versión iptables-1.2.1
