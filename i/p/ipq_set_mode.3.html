ipq_set_mode(3)

Paquete: iptables

Licencias: GPL-2.0-only

IPQ_SET_MODE(3) Manual del programador de Linux IPQ_SET_MODE(3)

NOMBRE

ipq_set_mode — establece el modo de cola ip_queue

SINOPSIS

#include <linux/netfilter.h>
#include <libipq.h>

int ipq_set_mode(const struct ipq_handle *h, uint8_t mode, size_t range);

DESCRIPCIÓN

La función ipq_set_mode envía un mensaje al módulo ip_queue del kernel, especificando si solo los metadatos del paquete, o tanto los metadatos como los datos del paquete, deben copiarse al espacio de usuario.

El parámetro h es un manejador de contexto que previamente debe haber sido devuelto con éxito por una llamada a ipq_create_handle.

El parámetro mode debe ser uno de:

IPQ_COPY_META
Copia solo los metadatos del paquete al espacio de usuario.
IPQ_COPY_PACKET
Copia los metadatos del paquete y los datos del paquete al espacio de usuario.

El parámetro range se utiliza para especificar cuántos bytes de los datos se copiarán al espacio de usuario. Solo es válido para el modo IPQ_COPY_PACKET y, de lo contrario, se ignora. El valor máximo útil para range es 65535 (valores mayores serán limitados a este valor por ip_queue).

ipq_set_mode se utiliza normalmente inmediatamente después de ipq_create_handle para habilitar el flujo de paquetes al espacio de usuario.

Tenga en cuenta que, dado que el transporte de mensajes Netlink subyacente no tiene conexión, el módulo ip_queue no sabe que una aplicación de usuario está lista para comunicarse hasta que recibe un mensaje como este.

VALOR DE RETORNO

En caso de fallo, se devuelve -1.
En caso de éxito, se devuelve un valor positivo distinto de cero.

ERRORES

En caso de fallo, un mensaje de error descriptivo estará disponible a través de la función ipq_errstr.

DIAGNÓSTICOS

Puede ocurrir un fallo relativamente común si el módulo ip_queue no está cargado. En este caso, el siguiente fragmento de código:

status = ipq_set_mode(h, IPQ_COPY_META, 0);
if (status < 0) {
	ipq_perror("myapp");
	ipq_destroy_handle(h);
	exit(1);
}

generaría la siguiente salida:

myapp: Failed to send netlink message: Connection refused

ERRORES CONOCIDOS

Ninguno conocido.
