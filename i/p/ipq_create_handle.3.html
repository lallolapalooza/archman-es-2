ipq_create_handle(3)

Paquete: iptables-nft

Licencias: GPL-2.0-only

IPQ_CREATE_HANDLE(3) Manual del programador de Linux IPQ_CREATE_HANDLE(3)

NOMBRE

ipq_create_handle, ipq_destroy_handle — crear y destruir manejadores de libipq.

SINOPSIS

#include <linux/netfilter.h>
#include <libipq.h>

struct ipq_handle *ipq_create_handle(uint32_t flags, uint32_t protocol);
int ipq_destroy_handle(struct ipq_handle *h);

DESCRIPCIÓN

La función ipq_create_handle inicializa libipq para una aplicación, intenta enlazar al socket Netlink utilizado por ip_queue y devuelve un manejador de contexto opaco. Debería ser la primera función de libipq que llame una aplicación. El manejador devuelto se utilizará en todas las llamadas posteriores a la biblioteca que requieran un parámetro de manejador.

El parámetro flags no se utiliza actualmente y debe establecerse en cero por la aplicación para compatibilidad futura.

El parámetro protocol se utiliza para especificar el protocolo de los paquetes que se pondrán en cola. Los valores válidos son NFPROTO_IPV4 para IPv4 y NFPROTO_IPV6 para IPv6. Actualmente, solo un protocolo puede estar en cola a la vez para un manejador.

La función ipq_destroy_handle libera los recursos asignados por ipq_create_handle y debe usarse cuando el manejador ya no sea requerido por la aplicación.

VALORES DEVUELTOS

En caso de éxito, ipq_create_handle devuelve un puntero a un manejador de contexto.
En caso de fallo, se devuelve NULL.

En caso de éxito, ipq_destroy_handle devuelve cero.
En caso de fallo, se devuelve -1.

ERRORES

En caso de fallo, un mensaje de error descriptivo estará disponible a través de la función ipq_errstr.

ERRORES

Ninguno conocido.
