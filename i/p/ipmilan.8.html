ipmilan(8) Convertidor de Interfaz de Sistema a LAN IPMI ipmilan(8)

NOMBRE

ipmilan - Convertidor de Interfaz de Sistema a LAN IPMI

SINOPSIS

ipmilan [-c archivo_config] [-i dispositivo_ipmi] [-d] [-n]

DESCRIPCIÓN

El demonio ipmilan permite que una interfaz de sistema IPMI que utiliza el controlador de dispositivo OpenIPMI sea accedida utilizando el protocolo LAN IPMI 1.5 o 2.0.

ipmilan soporta las capacidades completas de autenticación del protocolo LAN IPMI.

ipmilan soporta múltiples direcciones IP para tolerancia a fallos. Ten en cuenta que los mensajes que llegan por una dirección siempre se envían de vuelta por la misma dirección por la que llegaron.

OPCIONES

-c archivo-config
Establece el archivo de configuración a uno diferente del predeterminado /etc/ipmi_lan.conf
-n
Impide que el demonio se bifurque y se desvincule de la terminal de control. Esto es útil para ejecutarlo desde init.
-d
Activa la depuración a la salida estándar. Generalmente tienes que usar -n con esto.

CONFIGURACIÓN

La configuración se realiza a través del archivo /etc/ipmi_lan.conf. Se puede especificar un archivo con otro nombre o ruta usando la opción -c. Consulta la página del manual del archivo de configuración de ipmi_lan para más detalles.

SEGURIDAD

ipmilan implementa la seguridad normal de IPMI. El valor predeterminado es no permitir el acceso a nadie, por lo que el valor predeterminado es bastante seguro, pero ten cuidado con lo que añades, ya que se trata de acceso para controlar tu máquina. No se recomiendan las autorizaciones straight y none, probablemente deberías ceñirte a md2 o md5.

SEÑALES

SIGHUP
ipmilan debería manejar SIGHUP y releer sus archivos de configuración. Sin embargo, actualmente no lo hace. Puede que lo haga en el futuro, por ahora tendrás que matarlo y reiniciarlo. Los clientes deberían manejar la reconexión en este caso. Si no lo hacen, están defectuosos.

SALIDA DE ERRORES

Al inicio, toda la salida de errores va a stderr. Después de eso, toda la salida de errores va a syslog.

ARCHIVOS

/etc/ipmi_lan.conf

VER TAMBIÉN

ipmi_lan(5),ipmi_ui(1),openipmish(1)

PROBLEMAS CONOCIDOS

Actualmente, ipmilan no implementa la escritura del archivo de configuración. Se aceptan comandos IPMI para cambiar las opciones de configuración, pero la escritura permanente de los cambios no funciona actualmente.
