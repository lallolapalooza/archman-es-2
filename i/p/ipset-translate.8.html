IPSET-TRANSLATE(8) Manual del Administrador del Sistema IPSET-TRANSLATE(8)

NOMBRE

ipset-translate — herramienta de traducción para migrar de ipset a nftables

DESCRIPCIÓN

Esta herramienta permite a los administradores del sistema traducir un archivo de conjuntos de IP dado a nftables(8).

El único comando disponible es:

•
ipset-translate restore < archivo.ipt

USO

La herramienta ipset-translate lee un archivo de conjuntos de IP en la sintaxis producida por ipset(8) save. No se realizan modificaciones en los conjuntos, esta herramienta es un conversor de texto.

EJEMPLOS

Ejemplos de operación básica.

Traducción de un solo comando, asumiendo el archivo original:

create test1 hash:ip,port family inet counters timeout 300 hashsize 1024 maxelem 65536 bucketsize 12 initval 0xb5c4be5d
add test1 1.1.1.1,udp:20
add test1 1.1.1.1,21
create test2 hash:ip,port family inet hashsize 1024 maxelem 65536 bucketsize 12 initval 0xb5c4be5d

lo que resulta en la siguiente traducción:

root@machine:~# ipset-translate restore < file.ipt
add set inet global test1 { type ipv4_addr . inet_proto . inet_service; counter; timeout 300s; size 65536; }
add element inet global test1 { 1.1.1.1 . udp . 20 }
add element inet global test1 { 1.1.1.1 . tcp . 21 }
add set inet global test2 { type ipv4_addr . inet_proto . inet_service; size 65536; }

LIMITACIONES

Es posible que algunas opciones de conjuntos de IP no sean compatibles porque aún no están implementadas en nftables(8).

A diferencia de nftables(8), los conjuntos de IP no están asociados a una tabla específica. La utilidad de traducción asume que los conjuntos se crean en una tabla cuyo nombre es global y la familia es inet. Es posible que desee actualizar la traducción resultante para usar un nombre de tabla y una familia diferentes para sus conjuntos.

Para obtener información actualizada sobre esto, diríjase a https://wiki.nftables.org/.
