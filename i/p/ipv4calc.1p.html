NOMBRE

ipv4calc - Calcula elementos IPv4 a partir de una dirección.

SINOPSIS

ipv4calc [ --network | --broadcast | --netmask | 
           --address | --cidr ] dir

DESCRIPCIÓN

Si se especifica una opción, ipv4calc calcula el elemento solicitado a partir de la dirección y lo imprime en la salida estándar.

Si se especifican varias opciones, solo se imprime la primera.

Si no se especifican opciones, el programa imprime la parte de host de la dirección, la red y la dirección de broadcast deducidas de la dirección dada.

Si la dirección no contiene una máscara de red o una longitud de máscara, se asume la predeterminada.
