NOMBRE

ip-sr - gestión de Segment Routing IPv6

SINOPSIS


ip sr { COMANDO | help }

ip sr hmac show

ip sr hmac set IDCLAVE ALGORITMO

ip sr tunsrc show

ip sr tunsrc set DIRECCION

DESCRIPCIÓN

El comando ip sr se utiliza para configurar parámetros internos de Segment Routing IPv6 (SRv6).

Estos parámetros incluyen el mapeo entre una clave HMAC y su algoritmo de hashing y secreto asociado, y la dirección IPv6 a utilizar como origen para paquetes encapsulados.

El comando ip sr hmac set solicita una "contraseña" terminada en nueva línea que se utilizará como secreto HMAC para el ID de clave correspondiente. Esta "contraseña" *no* se estira y se utiliza directamente como clave HMAC. Por lo tanto, *debe* tener suficiente entropía para ser utilizada como clave. Por ejemplo, un uso correcto sería utilizar una contraseña generada con head -c 32 /dev/random | base64 -w 0.

Una "contraseña" en blanco elimina el mapeo.

Los algoritmos actualmente soportados para ALGORITMO son sha1 y sha256.

Si la fuente del túnel se establece en la dirección :: (que es la predeterminada), se seleccionará una dirección de la interfaz de salida. Como esta operación puede afectar al rendimiento, se recomienda establecer una dirección no predeterminada.

EJEMPLOS

Configurar un mapeo HMAC para el ID de clave 42 y el algoritmo de hashing SHA-256

# ip sr hmac set 42 sha256

Establecer la dirección fuente del túnel a 2001:db8::1

# ip sr tunsrc set 2001:db8::1

VER TAMBIÉN

ip-route(8)

ERRORES

ip sr hmac set no estira la contraseña.
