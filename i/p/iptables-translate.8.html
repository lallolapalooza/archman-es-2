iptables-translate(8)

Paquete: iptables-nft

Licencias: GPL-2.0-only

IPTABLES-TRANSLATE(8) Manual del Administrador del Sistema IPTABLES-TRANSLATE(8)

NOMBRE

iptables-translate — herramienta de traducción para migrar de iptables a nftables

ip6tables-translate — herramienta de traducción para migrar de ip6tables a nftables

ebtables-translate — herramienta de traducción para migrar de ebtables a nftables

arptables-translate — herramienta de traducción para migrar de arptables a nftables

DESCRIPCIÓN

Existe un conjunto de herramientas para ayudar al administrador del sistema a traducir un conjunto de reglas dado de iptables(8), ip6tables(8), ebtables(8) y arptables(8) a nftables(8).

Los comandos disponibles son:

•
iptables-translate
•
iptables-restore-translate
•
ip6tables-translate
•
ip6tables-restore-translate
•
ebtables-translate
•
arptables-translate

USO

Toman como entrada la sintaxis original de iptables(8)/ip6tables(8)/ebtables(8)/arptables(8) y generan la sintaxis nativa de nftables(8).

La herramienta iptables-restore-translate lee un conjunto de reglas en la sintaxis producida por iptables-save(8). Del mismo modo, la herramienta ip6tables-restore-translate lee uno producido por ip6tables-save(8). No se producen modificaciones en el conjunto de reglas, estas herramientas son solo convertidores de texto.

iptables-translate lee una línea de comandos como si hubiera sido introducida en iptables(8), y ip6tables-translate lee un comando como si hubiera sido introducido en ip6tables(8).

EJEMPLOS

Ejemplos de operación básica.

Traducción de un solo comando:

root@machine:~# iptables-translate -A INPUT -p tcp --dport 22 -m conntrack --ctstate NEW -j ACCEPT
nft add rule ip filter INPUT tcp dport 22 ct state new counter accept
root@machine:~# ip6tables-translate -A FORWARD -i eth0 -o eth3 -p udp -m multiport --dports 111,222 -j ACCEPT
nft add rule ip6 filter FORWARD iifname eth0 oifname eth3 meta l4proto udp udp dport { 111,222} counter accept

Traducción de un conjunto de reglas completo:

root@machine:~# iptables-save > save.txt
root@machine:~# cat save.txt
# Generated by iptables-save v1.6.0 on Sat Dec 24 14:26:40 2016
*filter
:INPUT ACCEPT [5166:1752111]
:FORWARD ACCEPT [0:0]
:OUTPUT ACCEPT [5058:628693]
-A FORWARD -p tcp -m tcp --dport 22 -m conntrack --ctstate NEW -j ACCEPT
COMMIT
# Completed on Sat Dec 24 14:26:40 2016
root@machine:~# iptables-restore-translate -f save.txt
# Translated by iptables-restore-translate v1.6.0 on Sat Dec 24 14:26:59 2016
add table ip filter
add chain ip filter INPUT { type filter hook input priority 0; }
add chain ip filter FORWARD { type filter hook forward priority 0; }
add chain ip filter OUTPUT { type filter hook output priority 0; }
add rule ip filter FORWARD tcp dport 22 ct state new counter accept
root@machine:~# iptables-restore-translate -f save.txt > ruleset.nft
root@machine:~# nft -f ruleset.nft
root@machine:~# nft list ruleset
table ip filter {
	chain INPUT {
		type filter hook input priority 0; policy accept;
	}
	chain FORWARD {
		type filter hook forward priority 0; policy accept;
		tcp dport ssh ct state new counter packets 0 bytes 0 accept
	}
	chain OUTPUT {
		type filter hook output priority 0; policy accept;
	}
}

LIMITACIONES

Algunas extensiones (pocas) pueden no ser compatibles (o no serlo completamente) por cualquier motivo (por ejemplo, se consideraron obsoletas o no tuvimos tiempo de trabajar en ellas).

No hay traducción disponible para arptables(8).

Para obtener información actualizada sobre esto, por favor diríjase a https://wiki.nftables.org/.
