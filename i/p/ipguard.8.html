CIÓN
ipguard escucha la red en busca de paquetes ARP. Todos los pares MAC-IP permitidos están listados en el archivo 'ethers'. Si recibe un par MAC-IP que no está listado en el archivo 'ethers', enviará una respuesta ARP con una dirección falsa configurada. Esto evitará que un host no permitido funcione correctamente en el segmento Ethernet
local.

    NAME

    ipguard - IP address firewall

    SYNOPSIS

    ipguard [-f] [-c configfile]

    DESCRIPTION

    ipguard is an IP address firewall that can block unwanted IP addresses. It uses the Linux kernel's netfilter framework to intercept network packets and decide whether to allow or deny them based on predefined rules.

    The firewall rules are loaded from a configuration file, which specifies which IP addresses or ranges should be blocked.

    OPTIONS

    -f
    Run in the foreground. By default, ipguard daemonizes.
    -c configfile
    Specify an alternative configuration file. The default configuration file is /etc/ipguard.conf.

    EXAMPLES

    To start ipguard with the default configuration file: 

    # ipguard

    To run ipguard in the foreground for debugging: 

    # ipguard -f

    To use a custom configuration file: 

    # ipguard -c /etc/my_ipguard.conf

    TIPS

    • Ensure your configuration file has the correct syntax. Each line should contain an IP address or a CIDR notation for a network range.
    • Regularly review and update your blocklist to keep it effective.
    • Consider using a tool to automatically update the blocklist with known malicious IP addresses.

    SIGNALS

    SIGHUP
    Reload the configuration file.
    SIGTERM
    Terminate the daemon gracefully.

    FILES

    /etc/ipguard.conf
    Default configuration file for ipguard.
    /var/run/ipguard.pid
    Process ID file.
