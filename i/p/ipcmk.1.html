IPCMK(1) Comandos de usuario IPCMK(1)

NOMBRE

ipcmk - crea varios recursos IPC

SINOPSIS

ipcmk [opciones]

DESCRIPCIÓN

ipcmk permite crear objetos de comunicación interprocesos (IPC) POSIX y System V: segmentos de memoria compartida, colas de mensajes y semáforos (arrays para System V).

OPCIONES

Los recursos se pueden especificar con estas opciones:

-M, --shmem tamaño

Crea un segmento de memoria compartida de tamaño bytes. El argumento tamaño puede ir seguido de los sufijos multiplicadores KiB (=1024), MiB (=1024*1024), y así sucesivamente para GiB, etc. (la parte "iB" es opcional, por ejemplo, "K" tiene el mismo significado que "KiB") o los sufijos KB (=1000), MB (=1000*1000), y así sucesivamente para GB, etc.

-m, --posix-shmem tamaño

Crea un segmento de memoria compartida POSIX de tamaño bytes. El argumento tamaño puede ir seguido de los sufijos multiplicadores KiB (=1024), MiB (=1024*1024), y así sucesivamente para GiB, etc. (la parte "iB" es opcional, por ejemplo, "K" tiene el mismo significado que "KiB") o los sufijos KB (=1000), MB (=1000*1000), y así sucesivamente para GB, etc.

-Q, --queue

Crea una cola de mensajes.

-q, --posix-mqueue

Crea una cola de mensajes POSIX.

-S, --semaphore número

Crea un array de semáforos con número de elementos.

-s, --posix-semaphore

Crea un semáforo con nombre POSIX.

-n, --name nombre

Nombre del objeto IPC POSIX. Esta opción es obligatoria para objetos IPC POSIX.

Otras opciones son:

-p, --mode modo

Permisos de acceso para el recurso. El valor predeterminado es 0644.

-h, --help

Muestra el texto de ayuda y sale.

-V, --version

Muestra la versión y sale.
