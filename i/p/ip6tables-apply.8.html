NOMBRE

iptables-apply — una forma más segura de actualizar iptables remotamente

SINOPSIS

iptables-apply [-hV] [-t tiempo_espera] [-w archivo_guardado] {[archivo_reglas]|-c [comando_ejecutar]}

DESCRIPCIÓN

iptables-apply intentará aplicar un nuevo archivo de reglas (tal como lo genera iptables-save, leído por iptables-restore) o ejecutar un comando para configurar iptables y luego preguntará al usuario si los cambios están bien. Si las nuevas reglas de iptables cortan la conexión existente, el usuario no podrá responder afirmativamente. En este caso, el script revertirá a las reglas de iptables de trabajo anteriores después de que expire el tiempo de espera.

Las reglas aplicadas con éxito también se pueden escribir en un archivo_guardado y posteriormente usarse para revertir a este estado. Esto puede usarse para implementar un mecanismo de "guardar la última configuración válida" al experimentar con un script de configuración de iptables: iptables-apply -w /etc/iptables/iptables.rules -c /etc/iptables/iptables.run

Cuando se llama como ip6tables-apply, el script usará ip6tables-save/-restore y los valores predeterminados de IPv6 en su lugar. El valor predeterminado para archivo_reglas es '/etc/iptables/iptables.rules'.

OPCIONES

-t segundos, --timeout segundos
Establece el tiempo de espera en segundos después del cual el script revertirá al conjunto de reglas anterior (predeterminado: 10).
-w archivo_guardado, --write archivo_guardado
Especifica el archivo_guardado donde se escribirán las reglas aplicadas con éxito (el valor predeterminado si se proporciona una cadena vacía es: /etc/iptables/iptables.rules).
-c comando_ejecutar, --command comando_ejecutar
Ejecuta el comando comando_ejecutar para configurar iptables en lugar de aplicar un archivo de reglas (predeterminado: /etc/iptables/iptables.run).
-h, --help
Muestra información de uso.
-V, --version
Muestra información de la versión.

VER TAMBIÉN

iptables-restore(8), iptables-save(8), iptables(8).
