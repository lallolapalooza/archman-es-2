DESCRIPCIÓ

N

La utilidad ipcrm eliminará cero o más colas de mensajes, conjuntos de semáforos o segmentos de memoria compartida. Las instalaciones de comunicación entre procesos que se eliminarán se especifican mediante las

opciones.

Solo se permitirá a un usuario con los privilegios adecuados eliminar una instalación de comunicación entre procesos que no fue creada por ni pertenece al usuario que invoca ipc

r
m.

S

La utilidad ipcrm deberá cumplir con el volumen de Definiciones Base de POSIX.1‐2017, Sección 12.2, Directrices de Sintaxis de

Utilidades.

Se deberán soportar las siguientes

opciones:
-qmsg

Eliminar el identificador de cola de mensajes msgid del sistema y destruir la cola de mensajes y la estructura de datos asociada con
ella.

Eliminar el identificador de memoria compartida shmid del sistema. El segmento de memoria compartida y la estructura de datos asociada con él deberán ser destruidos después del último

Eliminar el identificador de semáforo semid del sistema y destruir el conjunto de semáforos y la estructura de datos asociada con

-Mshmk

Eliminar el identificador de memoria compartida, creado con la clave shmkey, del sistema. El segmento de memoria compartida y la estructura de datos asociada con él deberán ser destruidos después del último
