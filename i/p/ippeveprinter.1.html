NOMBRE

ippeveprinter - una aplicación de impresora IPP Everywhere para cups

SINOPSIS

ippeveprinter [ --help ] [ --no-web-forms ] [ --pam-service service ] [ --version ] [ -2 ] [ -A ] [ -D device-uri ] [ -F output-type/subtype ] [ -K keypath ] [ -M manufacturer ] [ -P filename.ppd ] [ -V ipp-version ] [ -a filename.conf ] [ -c command ] [ -d spool-directory ] [ -f type/subtype[,...] ] [ -i iconfile.png ] [ -k ] [ -l location ] [ -m model ] [ -n hostname ] [ -p port ] [ -r subtype[,subtype] ] [ -s speed[,color-speed] ] [ -v[vvv] ] service-name

DESCRIPCIÓN

ippeveprinter es un servidor simple del Protocolo de Impresión por Internet (IPP) que cumple con la especificación IPP Everywhere (PWG 5100.14). Puede utilizarse para probar software de cliente o actuar como un servidor de impresión muy básico que ejecuta un comando para cada trabajo que se imprime.

OPCIONES

El siguiente programa reconoce las opciones ippeveprinter:

--help
Muestra el uso del programa.
--no-web-forms
Deshabilita los formularios de la interfaz web utilizados para actualizar los niveles de medios y suministros.
--pam-service service
Establece el nombre del servicio PAM. El servicio predeterminado es "cups".
--version
Muestra la versión de CUPS.
-2
Informa el soporte para impresión a dos caras (dúplex).
-A
Habilita la autenticación para la impresora creada. ippeveprinter usa PAM para autenticar credenciales HTTP Basic.
-D device-uri
Establece el URI del dispositivo para la salida de impresión. El URI puede ser un nombre de archivo, un directorio, o un URI de socket de red de la forma "socket://DIRECCIÓN[:PUERTO]" (donde el número de puerto predeterminado es 9100). Al especificar un directorio, ippeveprinter creará un archivo de salida usando el ID y el nombre del trabajo.
-F output-type/subtype[,...]
Especifica el tipo MIME de medio de salida. El predeterminado es "application/postscript" cuando se -P se especifica la opción.
-M manufacturer
Establece el fabricante de la impresora. El predeterminado es "Example".
-P filename.ppd
Carga los atributos de la impresora desde el archivo PPD especificado. Esta opción se utiliza típicamente en conjunto con el ippeveps(7) comando de impresora ("-c ippeveps").
-V 1.1
-V 2.0
Especifica la versión máxima de IPP a informar. 2.0 es la predeterminada.
-c command
Ejecuta el comando especificado para cada documento que se imprime. Si "command" no es una ruta absoluta ("/ruta/al/comando"), ippeveprinter busca el comando en el subdirectorio "command" del directorio binario de CUPS, típicamente /usr/lib/cups/command o /usr/libexec/cups/command. El cups-config(1) comando se puede usar para descubrir el directorio binario correcto ("cups-config --serverbin"). Además, la variable de entorno CUPS_SERVERBIN se puede usar para sobreescribir la ubicación predeterminada de este directorio - ver la cups(1) página man para más detalles.
-d spool-directory
Especifica el directorio que contendrá los archivos de impresión. El predeterminado es un directorio bajo el directorio temporal actual del usuario.
-f type/subtype[,...]
Especifica una lista de tipos MIME de medios que el servidor aceptará. El predeterminado depende del tipo de impresora creada.
-i iconfile.png
Especifica el archivo de icono de la impresora para el servidor. El archivo debe ser una imagen en formato PNG. El predeterminado es una imagen PNG proporcionada internamente.
-k
Mantiene los documentos de impresión en el directorio de cola en lugar de borrarlos.
-l location
Especifica la cadena de ubicación legible por humanos que informa el servidor. El predeterminado es la cadena vacía.
-m model
Especifica el nombre del modelo de la impresora. El predeterminado es "Printer".
-n hostname
Especifica el nombre de host que informa el servidor. El predeterminado es el nombre devuelto por el hostname(1) comando.
-p port
Especifica el número de puerto en el que escuchar. El predeterminado es un número específico del usuario de 8000 a 8999.
-r off
Deshabilita completamente los anuncios de servicio DNS-SD.
-r subtype[,subtype]
Especifica el(los) subtipo(s) DNS-SD a anunciar. Separe múltiples subtipos con una coma. El predeterminado es "_print".
-s speed[,color-speed]
Especifica la velocidad de la impresora en páginas por minuto. Si se especifican dos números y el segundo número es mayor que cero, el servidor informará soporte para impresión en color. El predeterminado es "10,0".
-v[vvv]
Sé (muy) verboso al registrar actividad en la salida de error estándar.

ESTADO DE SALIDA

El ippeveprinter programa devuelve 1 si no puede procesar los argumentos de la línea de comandos o registrar el servicio IPP. De lo contrario ippeveprinter se ejecutará continuamente hasta que se termine.

CONFORME A

El ippeveprinter programa es único de CUPS y cumple con la especificación IPP Everywhere (PWG 5100.14).

ENTORNO

ippeveprinter agrega variables de entorno que comienzan con "IPP_" para todos los atributos de Trabajo IPP en la solicitud de impresión. Por ejemplo, al ejecutar un comando para un Trabajo IPP que contiene el atributo de Plantilla de Trabajo "media", la variable de entorno "IPP_MEDIA" se establecerá al valor de ese atributo.

Además, todos los atributos de Descripción de Impresora IPP "xxx-default" y "pwg-xxx" se agregan al entorno. Por ejemplo, la variable de entorno "IPP_MEDIA_DEFAULT" se establecerá al valor predeterminado para el atributo de Plantilla de Trabajo "media".

Los valores enumerados se convierten a sus equivalentes de palabra clave. Por ejemplo, un atributo de Plantilla de Trabajo "print-quality" con un valor enum de 3 se convertirá en la variable de entorno "IPP_PRINT_QUALITY" con un valor de "draft". Esta conversión de cadena solo ocurre para atributos estándar de Plantilla de Trabajo, actualmente "finishings", "orientation-requested", y "print-quality".

Finalmente, la variable de entorno "CONTENT_TYPE" contiene el tipo MIME de medio del documento que se está imprimiendo, la variable de entorno "DEVICE_URI" contiene el URI del dispositivo como se especificó con la opción "-D", la variable de entorno "OUTPUT_FORMAT" contiene el tipo MIME de medio de salida, y la variable de entorno "PPD" contiene el nombre de archivo PPD como se especificó con la opción "-P".

SALIDA ESTÁNDAR

Los comandos de impresión pueden enviar mensajes de vuelta a ippeveprinter en la salida de error estándar con uno de los siguientes prefijos:

ATTR: atributo=valor[ atributo=valor]
Establece los atributos nombrados a los valores dados. Actualmente, solo se pueden establecer los atributos de estado de trabajo "job-impressions" y "job-impressions-completed", y los atributos de estado de impresora "marker-xxx", "printer-alert", "printer-alert-description", "printer-supply" y "printer-supply-description".
DEBUG: Mensaje de depuración
Registra un mensaje de depuración si se han especificado al menos dos -v.
ERROR: Mensaje de error
Registra un mensaje de error y copia el mensaje al atributo "job-state-message".
INFO: Mensaje informativo
Registra un mensaje informativo/de progreso si se ha especificado -v y copia el mensaje al atributo "job-state-message", a menos que se haya informado de un error.
STATE: palabra clave[,palabra clave,...]
Establece el atributo "printer-state-reasons" de la impresora a las palabras clave listadas.
STATE: -palabra clave[,palabra clave,...]
Elimina las palabras clave listadas del atributo "printer-state-reasons" de la impresora.
STATE: +palabra clave[,palabra clave,...]
Añade las palabras clave listadas al atributo "printer-state-reasons" de la impresora.

EJEMPLOS

Ejecuta ippeveprinter con un nombre de servicio de Mi Impresora Genial:

    ippeveprinter "Mi Impresora Genial"

Ejecuta el comando file(1) cada vez que se envía un trabajo al servidor:

    ippeveprinter -c /usr/bin/file "Mi Impresora Genial"
