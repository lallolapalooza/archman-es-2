IPYTHON(1) Manual de comandos generales IPYTHON(1)

NOMBRE

ipython - Herramientas para la computación interactiva en Python.

SINOPSIS

ipython [opciones] archivos...

ipython subcomando [opciones]...

DESCRIPCIÓN

Un shell interactivo de Python con historial automático (entrada y salida), introspección dinámica de objetos, configuración más fácil, autocompletado de comandos, acceso al shell del sistema, integración con herramientas de computación numérica y científica, notebook web, consola Qt, y más.

Para más información sobre cómo usar IPython, consulta 'ipython --help', o 'ipython --help-all' para ver todas las opciones de línea de comandos disponibles.

VARIABLES DE ENTORNO

IPYTHONDIR

Esta es la ubicación donde IPython almacena todos sus archivos de configuración. El valor predeterminado es $HOME/.ipython si IPYTHONDIR no está definido.

Puedes ver el valor calculado de IPYTHONDIR con `ipython locate`.

ARCHIVOS

IPython utiliza varios archivos de configuración almacenados en perfiles dentro de IPYTHONDIR. Para generar los archivos de configuración predeterminados y comenzar a configurar IPython, ejecuta 'ipython profile create', y edita los archivos '*_config.py' ubicados en IPYTHONDIR/profile_default.

AUTORES

IPython está escrito por el Equipo de Desarrollo de IPython https://github.com/ipython/ipython.
