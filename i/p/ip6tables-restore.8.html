IPTABLES-RESTORE(8) iptables 1.8.11 IPTABLES-RESTORE(8)

NOMBRE

iptables-restore — Restaurar tablas de IP

ip6tables-restore — Restaurar tablas de IPv6

SINOPSIS

iptables-restore [-chntvV] [-w segundos] [-M modprobe] [-T nombre] [archivo]

ip6tables-restore [-chntvV] [-w segundos] [-M modprobe] [-T nombre] [archivo]

DESCRIPCIÓN

iptables-restore e ip6tables-restore se utilizan para restaurar las tablas de IP e IPv6 a partir de datos especificados en STDIN o en archivo. Utilice la redirección de I/O proporcionada por su shell para leer desde un archivo o especifique archivo como argumento.

-c, --counters
Restaura los valores de todos los contadores de paquetes y bytes.
-h, --help
Imprime un resumen corto de las opciones.
-n, --noflush
No vaciar el contenido previo de la tabla. Si no se especifica, ambos comandos vacían (eliminan) todo el contenido previo de la tabla respectiva.
-t, --test
Solo analiza y construye el conjunto de reglas, pero no lo confirma.
-v, --verbose
Imprime información de depuración adicional durante el procesamiento del conjunto de reglas. Especifique varias veces para aumentar el nivel de depuración.
-V, --version
Imprime el número de versión del programa.
-w, --wait [segundos]
Espera el bloqueo de xtables. Para evitar que se ejecuten múltiples instancias del programa simultáneamente, se intentará obtener un bloqueo exclusivo al iniciar. Por defecto, el programa saldrá si no se puede obtener el bloqueo. Esta opción hará que el programa espere (indefinidamente o por los segundos opcionales) hasta que se pueda obtener el bloqueo exclusivo.
-M, --modprobe modprobe
Especifica la ruta al programa modprobe(8). Por defecto, iptables-restore inspeccionará /proc/sys/kernel/modprobe para determinar la ruta del ejecutable.
-T, --table nombre
Restaura solo la tabla con el nombre especificado, incluso si el flujo de entrada contiene otras.

ERRORES

Ninguno conocido desde la versión iptables-1.2.1
