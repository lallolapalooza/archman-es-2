ipc(2) Manual de llamadas al sistema ipc(2)

NOMBRE

ipc - Llamadas al sistema de IPC de System V

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <linux/ipc.h>        /* Definición de constantes necesarias */
#include <sys/syscall.h>      /* Definición de constantes SYS_* */
#include <unistd.h>
int syscall(SYS_ipc, unsigned int call, int first,
            unsigned long second, unsigned long third, void *ptr,
            long fifth);

Nota: glibc no proporciona un envoltorio para ipc(), lo que hace necesario el uso de syscall(2).

DESCRIPCIÓN

ipc() es un punto de entrada común del kernel para las llamadas de IPC de System V para mensajes, semáforos y memoria compartida. call determina qué función de IPC invocar; los demás argumentos se pasan a la llamada apropiada.

Los programas de espacio de usuario deben llamar a las funciones apropiadas por sus nombres habituales. Solo los implementadores de la biblioteca estándar y los hackers del kernel necesitan conocer ipc().

VERSIÓNES

En algunas arquitecturas —por ejemplo, x86-64 y ARM— no existe la llamada al sistema ipc(); en su lugar, msgctl(2), semctl(2), shmctl(2), etc., se implementan realmente como llamadas al sistema separadas.

ESTÁNDARES

Linux.

VER TAMBIÉN

msgctl(2), msgget(2), msgrcv(2), msgsnd(2), semctl(2), semget(2), semop(2), semtimedop(2), shmat(2), shmctl(2), shmdt(2), shmget(2), sysvipc(7)
