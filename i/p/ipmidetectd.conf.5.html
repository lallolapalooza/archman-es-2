NOMBRE

ipmidetectd.conf - archivo de configuración de ipmidetectd

DESCRIPCIÓN

El archivo de configuración ipmidetectd.conf configura el demonio ipmidetectd.

El archivo de configuración por defecto que se carga es /etc/freeipmi//ipmidetectd.conf.

Las opciones de configuración que se pueden especificar en el archivo de configuración se enumeran a continuación. Cada opción de configuración debe listarse en una línea separada. Los argumentos de una opción se separan por cualquier cantidad de espacios en blanco. Múltiples argumentos también se separan por espacios en blanco. Los comentarios se pueden marcar usando el carácter de almohadilla ("#") y las líneas se pueden continuar en la siguiente usando una barra invertida ("\").

OPCIONES DE CONFIGURACIÓN DE IPMIDETECTD

ipmiping_period num
Especifica el período de tiempo en milisegundos en el que se deben enviar pings IPMI de forma regular. El valor por defecto es 15000.
ipmidetectd_server_port port
Especifica el puerto alternativo por defecto en el que el servidor ipmidetectd debe escuchar las solicitudes. El valor por defecto es 9225.
host string[:port]
Especifica un host o dirección IP al que el demonio ipmidetectd debe enviar pings IPMI. Se puede especificar tantas veces como sea necesario. Se puede especificar un puerto opcional. Puede aceptar rangos de hosts como entrada. Consulte SOPORTE DE RANGOS DE HOST en ipmidetect(8) para obtener información sobre los formatos de rangos. Si especifica una dirección IPv6 y un puerto, use el formato [DIRECCIÓN]:PUERTO.
