NOMBRE

iptunnel - crea, cambia, elimina y muestra túneles configurados

SINOPSIS

iptunnel [<operación>] [<argumentos>]

NOTA

Este programa está obsoleto. Por favor, usa ip tunnel en su lugar, y consulta ip-tunnel(8) para más información.

DESCRIPCIÓN

El comando iptunnel crea túneles configurados para enviar y recibir paquetes IPv6 o IPv4 que están encapsulados como la carga útil de un datagrama IPv4.

El comando iptunnel puede realizar una de las siguientes operaciones:

create - crea una interfaz de túnel, que deberás configurar posteriormente.

change - cambia una interfaz de túnel existente.

delete - elimina una interfaz de túnel. Debes deshabilitar el túnel antes de poder eliminarlo.

show - muestra los atributos del túnel (nombre, puntos finales del túnel, siguiente salto para paquetes tunelizados).
