DESCRIPCIÓ

N

La dirección es una dirección de protocolo (IPv4 o IPv6) adjunta a un dispositivo de red. Cada dispositivo debe tener al menos una dirección para usar el protocolo correspondiente. Es posible tener varias direcciones diferentes adjuntas a un dispositivo. Estas direcciones no se distinguen, por lo que el término alias no es del todo apropiado para ellas y no lo usamos en este

documento.

El comando ip address muestra las direcciones y sus propiedades, añade nuevas direcciones y borra las

antiguas.

ip address add - añadir una nueva dirección de

protocolo.

red.

Si se especifica una dirección de par, la dirección local no puede tener una longitud de prefijo. El prefijo de red se asocia con el par en lugar de con la dirección
local.
