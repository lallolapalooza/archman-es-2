NOMBRE

ip-ioam - IPv6 In-situ OAM (IOAM)

SINOPSIS


ip ioam { COMANDO | help }

ip ioam namespace show

ip ioam namespace add ID [ data DATA32 ] [ wide DATA64 ]

ip ioam namespace del ID

ip ioam schema show

ip ioam schema add ID DATA

ip ioam schema del ID

ip ioam namespace set ID schema { ID | none }

ip ioam monitor

DESCRIPCIÓN

El comando ip ioam se utiliza para configurar parámetros internos de IPv6 In-situ OAM (IOAM6), concretamente los espacios de nombres (namespaces) y esquemas (schemas) de IOAM.

Estos parámetros también incluyen el mapeo entre un espacio de nombres IOAM y un esquema IOAM.

El comando ip ioam monitor muestra los datos IOAM recibidos.

EJEMPLOS

Configurar un espacio de nombres IOAM (ID = 1) con datos (32 bits) y datos amplios (64 bits)

# ip ioam namespace add 1 data 0xdeadbeef wide 0xcafec0caf00dc0de

Vincular un esquema IOAM existente (ID = 7) a un espacio de nombres IOAM existente (ID = 1)

# ip ioam namespace set 1 schema 7
