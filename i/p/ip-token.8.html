NOMBRE

ip-token - soporte para identificadores de interfaz tokenizados

SINOPSIS


ip token { COMANDO | help }

ip token set TOKEN dev DEV

ip token del dev DEV

ip token get [ dev DEV ]

ip token [ list ]

DESCRIPCION

El soporte de identificadores de interfaz tokenizados IPv6 se utiliza para asignar direcciones de parte de host bien conocidas a nodos, mientras se sigue obteniendo un prefijo de red global a partir de los anuncios del router. El objetivo principal de los identificadores tokenizados son las plataformas de servidor donde las direcciones suelen configurarse manualmente, en lugar de usar DHCPv6 o SLAAC. Al utilizar identificadores tokenizados, los hosts aún pueden determinar su prefijo de red mediante SLAAC, pero se les puede renumerar más fácilmente de forma automática si su prefijo de red cambia [1]. Los identificadores de interfaz tokenizados IPv6 se describen en el borrador [1]: <draft-chown-6man-tokenised-ipv6-identifiers-02>.

ip token set - establecer un token de interfaz

establece el token de interfaz en el kernel.

TOKEN
la dirección del token del identificador de interfaz.
dev DEV
la interfaz de red.

ip token del - eliminar un token de interfaz

elimina el token de interfaz del kernel.

dev DEV
la interfaz de red.

ip token get - obtener el token de interfaz del kernel

muestra un identificador de interfaz tokenizado de un dispositivo de red particular. Argumentos: coinciden con los argumentos de ip token set pero se debe omitir el TOKEN.

ip token list - listar todos los tokens de interfaz

lista todos los identificadores de interfaz tokenizados para las interfaces de red del kernel.
