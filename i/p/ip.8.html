Los nombres de todos los objetos pueden escribirse en forma completa o abreviada, por ejemplo address puede abreviarse como addr o simplemente a.

COMANDO

Especifica la acción a realizar sobre el objeto. El conjunto de acciones posibles depende del tipo de objeto. Como regla general, es posible añadir, eliminar y mostrar (o listar ) objetos, pero algunos objetos no permiten todas estas operaciones o tienen algunos comandos adicionales. El comando help está disponible para todos los objetos. Imprime una lista de los comandos disponibles y las convenciones de sintaxis de los argumentos.

Si no se proporciona ningún comando, se asume un comando predeterminado. Normalmente es list o, si los objetos de esta clase no se pueden listar, help.

ENTORNO

COLORFGBG
Si está definido, su valor se utiliza para detectar si el fondo es oscuro o claro y usar colores de contraste para él.

La variable de entorno COLORFGBG normalmente contiene dos o tres valores separados por punto y coma; queremos el último valor en cualquier caso. Si este valor es 0-6 o 8, elija colores adecuados para un fondo oscuro:

COLORFGBG=";0" ip -c a

ESTADO DE SALIDA

El estado de salida es 0 si el comando fue exitoso y 1 si hay un error de sintaxis. Si el kernel informó de un error, el estado de salida es 2.

EJEMPLOS

ip addr

Muestra las direcciones asignadas a todas las interfaces de red.

ip neigh

Muestra la tabla de vecinos actual en el kernel.

ip link set x up

Activa la interfaz x.

ip link set x down

Desactiva la interfaz x.

ip route

Muestra la tabla de rutas.
