NAME

ip - mostrar / manipular rutas, dispositivos de red, interfaces y túneles

SYNOPSIS


ip [ OPTIONS ] OBJECT { COMMAND | help }

ip [ -force ] -batch filename

OBJECT := { address | addrlabel | fou | help | ila | ioam | l2tp | link | macsec | maddress | monitor | mptcp | mroute | mrule | neighbor | neighbour | netconf | netns | nexthop | ntable | ntbl | route | rule | sr | tap | tcpmetrics | token | tunnel | tuntap | vrf | xfrm }

OPTIONS := { -V[ersion] | -h[uman-readable] | -s[tatistics] | -d[etails] | -r[esolve] | -iec | -f[amily] { inet | inet6 | link } | -4 | -6 | -B | -0 | -l[oops] { maximum-addr-flush-attempts } | -o[neline] | -rc[vbuf] [size] | -t[imestamp] | -ts[hort] | -n[etns] name | -N[umeric] | -a[ll] | -c[olor] | -br[ief] | -j[son] | -p[retty] }

OPTIONS

-V, -Version
Imprimir la versión de la utilidad ip y salir.
-h, -human, -human-readable
mostrar estadísticas con valores legibles para humanos seguidos de un sufijo.
-b, -batch <FILENAME>
Leer comandos desde el archivo proporcionado o desde la entrada estándar y ejecutarlos. El primer error causará la terminación de ip.
-force
No terminar ip ante errores en modo por lotes. Si hubo errores durante la ejecución de los comandos, el código de retorno de la aplicación será no cero.
-s, -stats, -statistics
Mostrar más información. Si la opción aparece dos veces o más, la cantidad de información aumenta. Por regla general, la información son estadísticas o algunos valores de tiempo.
-d, -details
Mostrar información más detallada.
-l, -loops <COUNT>
Especificar el número máximo de iteraciones que la lógica de 'limpieza de direcciones ip' intentará antes de rendirse. El valor predeterminado es 10. Cero (0) significa iterar hasta que todas las direcciones se eliminen.
-f, -family <FAMILY>
Especifica la familia de protocolo a utilizar. El identificador de familia de protocolo puede ser uno de inet, inet6, bridge, mpls o link. Si esta opción no está presente, la familia de protocolo se deduce de otros argumentos. Si el resto de la línea de comandos no da suficiente información para deducir la familia, ip se recurre al predeterminado, habitualmente inet o any. link es un identificador especial de familia que significa que no se involucra ningún protocolo de red.
-4
atajo para -family inet.
-6
atajo para -family inet6.
-B
atajo para -family bridge.
-M
atajo para -family mpls.
-0
atajo para -family link.
-o, -oneline
mostrar cada registro en una sola línea, reemplazando los saltos de línea con el carácter '\'. Esto es conveniente cuando se desea contar registros con wc(1) o grep(1) el resultado.
-r, -resolve
usar el resolver de nombres del sistema para imprimir nombres DNS en lugar de direcciones de host.
-n, -netns <NETNS>
cambia ip al espacio de nombres de red especificado NETNS. En realidad solo simplifica la ejecución de:

ip netns exec NETNS ip [ OPTIONS ] OBJECT { COMMAND | help }

a

ip -n[etns] NETNS [ OPTIONS ] OBJECT { COMMAND | help }

-N, -Numeric
Imprimir el número de protocolo, alcance, campo ds, etc. directamente en lugar de convertirlo en un nombre legible para humanos.
-a, -all
ejecuta el comando especificado sobre todos los objetos, depende si el comando soporta esta opción.
-c[color][={always|auto|never}
Configurar la salida de colores. Si el parámetro se omite o es always, la salida de colores se habilita independientemente del estado de stdout. Si el parámetro es auto, se verifica que stdout sea un terminal antes de habilitar la salida de colores. Si el parámetro es never, la salida de colores se deshabilita. Si se especifica múltiples veces, la última tiene prioridad. Esta bandera se ignora si también se da -json.

La paleta de colores utilizada puede verse influenciada por la variable de entorno COLORFGBG (ver ENVIRONMENT).

-t, -timestamp
mostrar la hora actual al usar la opción monitor.
-ts, -tshort
Como -timestamp, pero usar formato más corto.
-rc, -rcvbuf<SIZE>
Establecer el tamaño del búfer de recepción del socket netlink, predeterminado a 1MB.
-iec
mostrar tasas legibles para humanos en unidades IEC (por ejemplo, 1Ki = 1024).
-br, -brief
Mostrar solo información básica en formato tabular para una mejor legibilidad. Esta opción actualmente solo está soportada por los comandos ip addr show , ip link show & ip neigh show .
-j, -json
Mostrar resultados en Notación de Objetos JavaScript (JSON).
-p, -pretty
El formato JSON predeterminado es compacto y más eficiente para analizar pero difícil para la mayoría de los usuarios de leer. Esta bandera añade sangrías para la legibilidad.
-echo
Solicitar al kernel que envíe la configuración aplicada de vuelta.

IP - COMMAND SYNTAX

OBJECT

address
- dirección de protocolo (IP o IPv6) en un dispositivo.
addrlabel
- configuración de etiqueta para la selección de dirección de protocolo.
fou
- Configuración del puerto de recepción Foo-over-UDP.
ila
- gestionar direcciones de localizador de identificador (ILA).
ioam
- gestionar espacios de nombres IOAM y esquemas IOAM.
l2tp
- túnel Ethernet sobre IP (L2TPv3).
link
- dispositivo de red.
macsec
- configuración de dispositivo MACsec.
maddress
- dirección de multicast.
monitor
- vigila los mensajes de netlink.
mptcp
- gestiona el administrador de rutas MPTCP.
mroute
- entrada de la caché de enrutamiento multidifusión.
mrule
- regla en la base de datos de políticas de enrutamiento multidifusión.
neighbour
- gestiona las entradas de la caché ARP o NDISC.
netconf
- monitorización de la configurización de red.
netns
- gestiona los espacios de nombres de red.
nexthop
- gestiona los objetos de siguiente salto (nexthop).
ntable
- gestiona el funcionamiento de la caché de vecinos.
route
- entrada de la tabla de enrutamiento.
rule
- regla en la base de datos de políticas de enrutamiento.
sr
- gestiona el enrutamiento por segmentos IPv6.
stats
- gestiona y muestra estadísticas de interfaces.
tcp_metrics/tcpmetrics
- gestiona las métricas TCP.
token
- gestiona los identificadores de interfaz tokenizados.
tunnel
- túnel sobre IP.
tuntap
- gestiona los dispositivos TUN/TAP.
vrf
- gestiona los dispositivos virtuales de enrutamiento y reenvío.
xfrm
- gestiona las políticas IPSec.

Los nombres de todos los objetos pueden escribirse en forma completa o abreviada, por ejemplo address puede abreviarse como addr o simplemente a.

COMANDO

Especifica la acción a realizar sobre el objeto. El conjunto de acciones posibles depende del tipo de objeto. Como regla general, es posible añadir, eliminar y mostrar (o listar ) objetos, pero algunos objetos no permiten todas estas operaciones o tienen algunos comandos adicionales. El comando help está disponible para todos los objetos. Imprime una lista de los comandos disponibles y las convenciones de sintaxis de los argumentos.

Si no se proporciona ningún comando, se asume un comando predeterminado. Normalmente es list o, si los objetos de esta clase no se pueden listar, help.

ENTORNO

COLORFGBG
Si está definido, su valor se utiliza para detectar si el fondo es oscuro o claro y usar colores de contraste para él.

La variable de entorno COLORFGBG normalmente contiene dos o tres valores separados por punto y coma; queremos el último valor en cualquier caso. Si este valor es 0-6 o 8, elija colores adecuados para un fondo oscuro:

COLORFGBG=";0" ip -c a

ESTADO DE SALIDA

El estado de salida es 0 si el comando fue exitoso y 1 si hay un error de sintaxis. Si el kernel informó de un error, el estado de salida es 2.

EJEMPLOS

ip addr

Muestra las direcciones asignadas a todas las interfaces de red.

ip neigh

Muestra la tabla de vecinos actual en el kernel.

ip link set x up

Activa la interfaz x.

ip link set x down

Desactiva la interfaz x.

ip route

Muestra la tabla de rutas.
