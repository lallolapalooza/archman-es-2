ipq_destroy_handle(3)

Paquete: iptables

Licencias: GPL-2.0-only

IPQ_CREATE_HANDLE(3) Manual del programador de Linux IPQ_CREATE_HANDLE(3)

NOMBRE

ipq_create_handle, ipq_destroy_handle — crear y destruir manejadores de libipq.

SINOPSIS

#include <linux/netfilter.h>
#include <libipq.h>

struct ipq_handle *ipq_create_handle(uint32_t flags, uint32_t protocol);
int ipq_destroy_handle(struct ipq_handle *h);

DESCRIPCIÓN

La función ipq_create_handle inicializa libipq para una aplicación, intenta vincularse al socket Netlink utilizado por ip_queue y devuelve un manejador de contexto opaco. Debería ser la primera función de libipq que llame una aplicación. El manejador devuelto se utilizará en todas las llamadas posteriores a la biblioteca que requieran un parámetro de manejador.

El parámetro flags no se utiliza actualmente y la aplicación debe establecerlo en cero para compatibilidad futura.

El parámetro protocol se utiliza para especificar el protocolo de los paquetes que se van a poner en cola. Los valores válidos son NFPROTO_IPV4 para IPv4 y NFPROTO_IPV6 para IPv6. Actualmente, solo se puede poner en cola un protocolo a la vez para un manejador.

La función ipq_destroy_handle libera los recursos asignados por ipq_create_handle y debe usarse cuando la aplicación ya no necesite el manejador.

VALORES DEVUELTOS

En caso de éxito, ipq_create_handle devuelve un puntero a un manejador de contexto.
En caso de error, devuelve NULL.

En caso de éxito, ipq_destroy_handle devuelve cero.
En caso de error, devuelve -1.

ERRORES

En caso de error, un mensaje descriptivo estará disponible a través de la función ipq_errstr.

ERRORES CONOCIDOS

Ninguno conocido.
