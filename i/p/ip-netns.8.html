Un espacio de nombres de red es lógicamente otra copia de la pila de red, con sus propias rutas, reglas de firewall y dispositivos de red. Por defecto, un proceso hereda su espacio de nombres de red de su padre. Inicialmente, todos los procesos comparten el mismo espacio de nombres de red

predeterminado del proceso init.

Por convención, un espacio de nombres de red con nombre es un objeto en /var/run/netns/ NAME que se puede abrir. El descriptor de archivo resultante

de abrir

/var/run/netns/ NAME hace referencia al espacio de nombres de red especificado. Mantener ese descriptor de archivo abierto mantiene vivo el espacio de nombres de red. El descriptor de archivo se puede usar con la llamada al sistema

setns(2)

para cambiar el espacio de nombres de red asociado a una

tarea.

Para las aplicaciones que son conscientes de los espacios de nombres de red, la convención es buscar primero los archivos de configuración de red globales en /etc/netns/ NA

conf.

ip netns exec automatiza el manejo de esta convención de archivos de configuración para aplicaciones que no son conscientes de los espacios de nombres de red, creando un espacio de nombres de montaje y montando por enlace todos los archivos de configuración de cada espacio de nombres de red en su ubicación tradicional en /etc.ip netns list - muestra todos los espacios de nombres de red con nombre Este comando muestra todos los espacios de nombres de red en /var/run/netns ip netns add NAME - crea un nuevo espacio de nombres de red con nombre Si NAME está disponible en /var/run/netns, este comando crea un nuevo espacio de nombres de red y le asigna

NAME.

ip netns set NAME NETNSID - asigna un id a un espacio de nombres de red
par
Este comando asigna un id a un espacio de nombres de red par. Este id es válido solo en el espacio de nombres de red actual. Si se especifica la palabra clave "auto", se elegirá un nsid disponible. Este id será usado por el kernel en algunos mensajes netlink. Si no se asigna un id cuando el kernel lo necesita, será asignado automáticamente por el kernel. Una vez asignado, no
es posible cambiarlo.
ip netns identify [PID] - informa los nombres de los espacios de nombres de red para el
proceso
Este comando recorre /var/run/netns y encuentra todos los nombres de espacios de nombres de red para el espacio de nombres de red del proceso especificado; si PID no se especifica, se usará el proceso
actual.
ip netns pids NAME - informa los procesos en el espacio de nombres de red con
nombre
Este comando recorre proc y encuentra todos los procesos que tienen el espacio de nombres de red con nombre como su espacio de nombres de red
principal.
