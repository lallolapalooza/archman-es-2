DESCRIPCIÓ

N

La utilidad ipcs escribirá información sobre las instalaciones de comunicación entre procesos

activas.

Sin opciones, la información se escribirá en formato corto para las colas de mensajes, los segment

os de memoria compartida y los conjuntos de semáforos que están actualmente activos en el sistema.
De lo contrario, la información que se muestra está controlada por las opciones especificadas.

OPCIONE

S

La utilidad ipcs se ajustará al Volumen de Definiciones Básicas de POSIX.1‐2017, Sección 12.2, Directrices de Sintaxis

de Utilidades.

La utilidad ipcs acepta las siguientes

opciones:
-
q
Escribe información sobre las colas de mensajes
activas.
-
m
Escribe información sobre los segmentos de memoria compartida
activos.
-
s
Escribe información
sobre los conjuntos d
e semáforos activos.

Si se especifica -q, -m o -s, solo se escribirá información sobre esas instalaciones. Si no se especifica ninguna de estas tres, se escribirá información sobre las tres, sujeto a las siguientes

opciones:
-
a
Usa todas las opciones de impresión. (Esta es una notación abreviada para -b, -c, -o, -p y -t.
)
-
b
Escribe información sobre el tamaño máximo permitido. (Número máximo de bytes en los mensajes de la cola para las colas de mensajes, tamaño de los segmentos para la memoria compartida y número de semáforos en cada conjunto para los semáforos.
)
-
c
Escribe el nombre de usuario y de grupo del creador; véase más
abajo.
-
o
Escribe información sobre el uso pendiente. (Número de mensajes en la cola y número total de bytes en los mensajes de la cola para las colas de mensajes, y número de procesos conectados a los segmentos de memoria compartida.
)
-
p
Escribe información sobre el número de proceso. (ID del último proceso que envió un mensaje y ID del último proceso que recibió un mensaje en las colas de mensajes, ID del proceso creador, y ID del último proceso que se conectó o desconectó de los segmentos de memoria compartida.
)
-
t
Escribe información de tiempo. (Hora de la última operación de control que cambió los permisos de acceso para todas las instalaciones, hora de la última msgsnd() y msgrcv() operaciones en las colas de mensajes, hora de la última shmat() y shmdt() operaciones en la memoria compartida, y hora de la última semop() operac

CLAVE

La clave utilizada como argumento para msgget(), semget() o shmget() para crear la entrada de la instalación.
Nota:
La clave de un segmento de memoria compartida se cambia a IPC_PRIVATE cuando el segmento ha sido eliminado hasta que todos los procesos adjuntos al segmento lo desvinculen.

Este campo se escribirá utilizando el formato 0x%x.

MODO (todos)
Los modos de acceso y las banderas de la instalación. El modo constará de 11 caracteres que se interpretarán de la siguiente manera.

El primer carácter será:

S
Si un proceso está esperando en una operación msgsnd().
-
Si lo anterior no es cierto.

El segundo carácter será:

R
Si un proceso está esperando en una operación msgrcv().
C o -
Si el segmento de memoria compartida asociado debe borrarse cuando se ejecuta la primera operación de adjunción.
-
Si ninguna de las anteriores es cierta.

Los siguientes nueve caracteres se interpretarán como tres conjuntos de tres bits cada uno. El primer conjunto se refiere a los permisos del propietario; el siguiente a los permisos de otros en el grupo de usuarios de la entrada de la instalación; y el último a todos los demás. Dentro de cada conjunto, el primer carácter indica permiso de lectura, el segundo carácter indica permiso de escritura o alteración de la entrada de la instalación, y el último carácter es un guion ('-').

Los permisos se indicarán de la siguiente manera:

r
Si se concede permiso de lectura.
w
Si se concede permiso de escritura.
a
Si se concede permiso de alteración.
-
Si no se concede el permiso indicado.

El primer carácter que sigue a los permisos especifica si existe un método de acceso alternativo o adicional asociado con la instalación. Si no hay ningún método de acceso alternativo o adicional asociado con la instalación, se escribirá un único espacio; de lo contrario, se escribirá otro carácter imprimible.

PROPIETARIO (todos)
El nombre de usuario del propietario de la entrada de la instalación. Si el nombre de usuario del propietario se encuentra en la base de datos de usuarios, se escribirán al menos las primeras ocho posiciones de columna del nombre utilizando el formato %s. De lo contrario, se escribirá el ID de usuario del propietario utilizando el formato %d.
GRUPO (todos)
El nombre del grupo del propietario de la entrada de la instalación. Si el nombre del grupo del propietario se encuentra en la base de datos de grupos, se escribirán al menos las primeras ocho posiciones de columna del nombre utilizando el formato %s. De lo contrario, se escribirá el ID del grupo del propietario utilizando el formato %d.

Las siguientes nueve columnas solo se escribirán para colas de mensajes:

CREADOR (a,c)
El nombre de usuario del creador de la entrada de la instalación. Si el nombre de usuario del creador se encuentra en la base de datos de usuarios, se escribirán al menos las primeras ocho posiciones de columna del nombre utilizando el formato %s. De lo contrario, se escribirá el ID de usuario del creador utilizando el formato %d.
CGRUPO (a,c)
El nombre del grupo del creador de la entrada de la instalación. Si el nombre del grupo del creador se encuentra en la base de datos de grupos, se escribirán al menos las primeras ocho posiciones de columna del nombre utilizando el formato %s. De lo contrario, se escribirá el ID del grupo del creador utilizando el formato %d.
CBYTES (a,o)
El número de bytes en mensajes actualmente pendientes en la cola de mensajes asociada. Este campo se escribirá utilizando el formato %d.
QNUM (a,o)
El número de mensajes actualmente pendientes en la cola de mensajes asociada. Este campo se escribirá utilizando el formato %d.
QBYTES (a,b)
El número máximo de bytes permitidos en mensajes pendientes en la cola de mensajes asociada. Este campo se escribirá utilizando el formato %d.
LSPID (a,p)
El ID del proceso del último proceso que envió un mensaje a la cola asociada. Este campo se escribirá utilizando el formato:
"%d", <pid>

donde <pid> es 0 si no se ha enviado ningún mensaje a la cola de mensajes correspondiente; de lo contrario, <pid> será el ID del proceso del último proceso que envió un mensaje a la cola.

LRPID (a,p)
El ID del proceso del último proceso que recibió un mensaje de la cola asociada. Este campo se escribirá utilizando el formato:
"%d", <pid>

donde <pid> es 0 si no se ha recibido ningún mensaje de la cola de mensajes correspondiente; de lo contrario, <pid> será el ID del proceso del último proceso que recibió un mensaje de la cola.

STIME (a,t)
La hora en que se envió el último mensaje a la cola asociada. Si se ha enviado un mensaje a la cola de mensajes correspondiente, se escribirán la hora, el minuto y el segundo de la última vez que se envió un mensaje a la cola utilizando el formato %d:%2.2d:%2.2d. De lo contrario, se escribirá el formato " no-entry".
RTIME (a,t)
La hora en que se recibió el último mensaje de la cola asociada. Si se ha recibido un mensaje de la cola de mensajes correspondiente, se escribirán la hora, el minuto y el segundo de la última vez que se recibió un mensaje de la cola utilizando el formato %d:%2.2d:%2.2d. De lo contrario, se escribirá el formato " no-entry".

Las siguientes ocho columnas solo se escribirán para segmentos de memoria compartida.

CREADOR (a,c)
El usuario del creador de la entrada de la instalación. Si el nombre de usuario del creador se encuentra en la base de datos de usuarios, se escribirán al menos las primeras ocho posiciones de columna del nombre utilizando el formato %s. De lo contrario, se escribirá el ID de usuario del creador utilizando el formato %d.
CGRUPO (a,c)
El nombre del grupo del creador de la entrada de la instalación. Si el nombre del grupo del creador se encuentra en la base de datos de grupos, se escribirán al menos las primeras ocho posiciones de columna del nombre utilizando el formato %s. De lo contrario, se escribirá el ID del grupo del creador utilizando el formato %d.
NATTCH (a,o)
El número de procesos adjuntos al segmento de memoria compartida asociado. Este campo se escribirá utilizando el formato %d.
SEGSZ (a,b)
El tamaño del segmento de memoria compartida asociado. Este campo se escribirá utilizando el formato %d.
CPID (a,p)
El ID del proceso creador de la entrada de memoria compartida. Este campo se escribirá utilizando el formato %d.
LPID (a,p)
El ID del proceso del último proceso que adjuntó o desvinculó el segmento de memoria compartida. Este campo se escribirá utilizando el formato:
"%d", <pid>

donde <pid> es 0 si ningún proceso ha adjuntado el segmento de memoria compartida correspondiente; de lo contrario, <pid> será el ID del proceso del último proceso que adjuntó o desvinculó el segmento.

ATIME (a,t)
La hora en que se completó la última adjunción al segmento de memoria compartida asociado. Si el segmento de memoria compartida correspondiente se ha adjuntado alguna vez, se escribirán la hora, el minuto y el segundo de la última vez que se adjuntó el segmento utilizando el formato %d:%2.2d:%2.2d. De lo contrario, se escribirá el formato " no-entry".
DTIME (a,t)
La hora en que se completó la última desvinculación del segmento de memoria compartida asociado. Si el segmento de memoria compartida correspondiente se ha desvinculado alguna vez, se escribirán la hora, el minuto y el segundo de la última vez que se desvinculó el segmento utilizando el formato %d:%2.2d:%2.2d. De lo contrario, se escribirá el formato " no-entry".

Las siguientes cuatro columnas solo se escribirán para conjuntos de semáforos:

CREADOR (a,c)
El usuario del creador de la entrada de la instalación. Si el nombre de usuario del creador se encuentra en la base de datos de usuarios, se escribirán al menos las primeras ocho posiciones de columna del nombre utilizando el formato %s. De lo contrario, se escribirá el ID de usuario del creador utilizando el formato %d.

De lo contrario, se escribirá el ID del grupo del creador utilizando el formato %d.
