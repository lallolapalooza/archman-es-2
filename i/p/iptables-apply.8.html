NOMBRE

iptables-apply — una forma más segura de actualizar iptables remotamente

SINOPSIS

iptables-apply [-hV] [-t tiempo_de_espera] [-w archivo_de_guardado] {[archivo_reglas]|-c [comando_ejecutar]}

DESCRIPCIÓN

iptables-apply intentará aplicar un nuevo archivo de reglas (tal como lo genera iptables-save, leído por iptables-restore) o ejecutar un comando para configurar iptables y luego pedirá al usuario si los cambios son correctos. Si las nuevas reglas de iptables cortan la conexión existente, el usuario no podrá responder afirmativamente. En este caso, el script revertirá a las reglas de iptables anteriores que funcionaban después de que expire el tiempo de espera.

Las reglas aplicadas con éxito también pueden escribirse en un archivo de guardado y utilizarse más tarde para revertir a ese estado. Esto se puede usar para implementar un mecanismo de "guardar la última configuración buena" al experimentar con un script de configuración de iptables: iptables-apply -w /etc/iptables/iptables.rules -c /etc/iptables/iptables.run

Cuando se llama como ip6tables-apply, el script utilizará ip6tables-save/-restore y los valores predeterminados de IPv6 en su lugar. El valor predeterminado para archivo_reglas es '/etc/iptables/iptables.rules'.

OPCIONES

-t segundos, --timeout segundos
Establece el tiempo de espera en segundos después del cual el script revertirá al conjunto de reglas anterior (predeterminado: 10).
-w archivo_de_guardado, --write archivo_de_guardado
Especifica el archivo de guardado donde se escribirán las reglas aplicadas con éxito (predeterminado si se proporciona una cadena vacía: /etc/iptables/iptables.rules).
-c comando_ejecutar, --command comando_ejecutar
Ejecuta el comando comando_ejecutar para configurar iptables en lugar de aplicar un archivo de reglas (predeterminado: /etc/iptables/iptables.run).
-h, --help
Muestra la información de uso.
-V, --version
Muestra la información de la versión.

VER TAMBIÉN

iptables-restore(8), iptables-save(8), iptables(8).
