Paquete: iptables

Licencias: GPL-2.0-only

IPQ_ERRSTR(3) Manual del programador de Linux IPQ_ERRSTR(3)

NOMBRE

ipq_errstr, ipq_perror — rutinas de manejo de errores de libipq

SINOPSIS

#include <linux/netfilter.h>
#include <libipq.h>

char *ipq_errstr(void);
void ipq_perror(const char *s);

DESCRIPCIÓN

La función ipq_errstr devuelve un mensaje de error descriptivo basado en el valor actual de la variable interna ipq_errno. Todas las funciones de la API de libipq establecen esta variable interna al fallar.

La función ipq_perror imprime un mensaje de error en stderr correspondiente al valor actual de la variable interna ipq_error y la variable global errno (si está establecida). El mensaje de error va precedido por la cadena s proporcionada por la aplicación. Si s es NULL, el mensaje de error va precedido por la cadena "ERROR".

VALOR DE RETORNO

ipq_errstr devuelve un mensaje de error como se describe arriba.
