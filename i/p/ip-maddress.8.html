NOMBRE

ip-maddress - gestión de direcciones multicast

SINOPSIS


ip [ OPCIONES ] maddress { COMANDO | help }

ip maddress { add | del } MULTIADDR dev NOMBRE

ip maddress show [ dev NOMBRE ]

DESCRIPCIÓN

Los objetos maddress son direcciones multicast.

ip maddress show - listar direcciones multicast

dev NOMBRE (por defecto)
el nombre del dispositivo.
ip maddress add - añadir una dirección multicast
ip maddress delete - eliminar una dirección multicast

Estos comandos adjuntan/desadjuntan una dirección multicast estática de capa de enlace para escuchar en la interfaz. Tenga en cuenta que es imposible unirse a grupos multicast de protocolo de forma estática. Este comando solo gestiona direcciones de capa de enlace.

dirección DIRECCIONLL (por defecto)
la dirección multicast de capa de enlace.
dev NOMBRE
el dispositivo al que unirse/salir de esta dirección multicast.
