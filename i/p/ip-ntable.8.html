NOMBRE

ip-ntable - configuración de la tabla de vecinos

SINOPSIS


ip [ OPCIONES ] ntable { COMANDO | help }

ip ntable change name NOMBRE [ dev DEV ] [ thresh1 VAL ] [ thresh2 VAL ] [ thresh3 VAL ] [ gc_int MSEC ] [ base_reachable MSEC ] [ retrans MSEC ] [ gc_stale MSEC ] [ delay_probe MSEC ] [ queue LEN ] [ app_probs VAL ] [ ucast_probes VAL ] [ mcast_probes VAL ] [ mcast_reprobes VAL ] [ anycast_delay MSEC ] [ proxy_delay MSEC ] [ proxy_queue LEN ] [ locktime MSEC ]

ip ntable show [ dev DEV ] [ name NOMBRE ]

DESCRIPCIÓN

ip ntable controla los parámetros de las tablas de vecinos.

ip ntable show - listar las tablas de vecinos ip

Este comando muestra los parámetros y estadísticas de la tabla de vecinos.

dev DEV
solo listar la tabla adjunta a este dispositivo.
name NOMBRE
solo lista la tabla con el nombre dado.

ip ntable change - modificar parámetro de tabla

Este comando permite modificar parámetros de la tabla como temporizadores y longitudes de cola.

name NOMBRE
el nombre de la tabla a modificar.
dev DEV
el nombre del dispositivo para modificar los valores de la tabla.

EJEMPLOS

ip ntable show dev eth0

Muestra los parámetros de la tabla de vecinos (ARP IPv4 y ndisc IPv6) en el dispositivo eth0.

ip ntable change name arp_cache queue 8 dev eth0

Cambia el número de paquetes puestos en cola mientras se resuelve la dirección de su valor predeterminado (3) a 8 paquetes.
