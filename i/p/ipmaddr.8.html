NOMBRE

ipmaddr - añade, cambia, elimina y muestra direcciones multicast

SINOPSIS

ipmaddr [<operación>] [<argumentos>]

NOTA

Este programa está obsoleto. Por favor, usa ip maddr en su lugar, y consulta ip-maddress(8) para más información.

DESCRIPCIÓN

El comando ipmaddr puede realizar una de las siguientes operaciones:

add - añadir una dirección multicast

change - cambiar una dirección multicast

del - eliminar una dirección multicast

show - listar direcciones multicast

VER TAMBIÉN

ip-maddress(8), ip(8)
