NOMBRE

ip-stats - administrar y mostrar estadísticas de interfaz

SINOPSIS


ip stats { COMANDO | help }

ip stats show [ dev DEV ] [ group GRUPO [ subgroup SUBGRUPO [ suite SUITE ] ... ] ... ] ...

ip stats set dev DEV l3_stats { on | off }

DESCRIPCIÓN

ip stats set
se utiliza para activar o desactivar la recopilación de un conjunto de estadísticas de hardware determinado en un dispositivo de red dado. Los siguientes conjuntos de estadísticas son compatibles:


l3_stats Las estadísticas L3 reflejan el tráfico que tiene lugar en un dispositivo HW en un objeto que corresponde al dispositivo de red de software dado.

ip stats show
se utiliza para mostrar estadísticas en un dispositivo de red dado, o para volcar estadísticas en todos los dispositivos de red. Por defecto, se solicitan todas las estadísticas. Es posible filtrar qué estadísticas se solicitan utilizando las palabras clave group y subgroup.

Es posible especificar varios grupos, o varios subgrupos para un grupo. Cuando no se proporcionan subgrupos para un grupo, se solicitan todos los subgrupos.

Los siguientes grupos son reconocidos:

group link - Estadísticas de enlace. El mismo conjunto que "ip -s link show" muestra.

group offload - Un grupo que contiene una serie de estadísticas orientadas al hardware. Véase más abajo los subgrupos individuales dentro de este grupo.

group xstats - Estadísticas extendidas. Un subgrupo identifica el tipo de dispositivo de red para mostrar las estadísticas.

group xstats_slave - Estadísticas extendidas para el esclavo de un dispositivo de red de un tipo dado. Un subgrupo identifica el tipo de dispositivo de red maestro.

group afstats - Un grupo para estadísticas de dispositivos de red específicas de la familia de direcciones.

subgrupos de group offload:

subgroup cpu_hit - El conjunto de estadísticas cpu_hit es útil en dispositivos de red de hardware. Las estadísticas link en estos dispositivos reflejan tanto el tráfico del plano de datos de hardware como el de software. Las estadísticas cpu_hit entonces solo reflejan el tráfico del plano de datos de software.

subgroup hw_stats_info - Este conjunto no incluye estadísticas de tráfico, sino que comunica el estado de otras estadísticas. A través de este subgrupo, es posible descubrir si una estadística dada estaba habilitada y, si lo estaba, si algún controlador de dispositivo realmente configuró su dispositivo para recopilar estas estadísticas. Por ejemplo, l3_stats estaba habilitado en el siguiente caso, pero ningún controlador lo ha instalado:

# ip stats show dev swp1 group offload subgroup hw_stats_info
56: swp1: group offload subgroup hw_stats_info
l3_stats on used off

Después de añadir una dirección L3 al dispositivo de red, el contador se instalará:

# ip addr add dev swp1 192.0.2.1/28
# ip stats show dev swp1 group offload subgroup hw_stats_info
56: swp1: group offload subgroup hw_stats_info
l3_stats on used on

subgroup l3_stats - Estas estadísticas reflejan el tráfico L3 que tiene lugar en HW en un objeto que corresponde al dispositivo de red. Tenga en cuenta que este conjunto está deshabilitado por defecto y debe ser habilitado primero a través de ip stats set.

Por ejemplo:

# ip stats show dev swp2.200 group offload subgroup l3_stats
112: swp2.200: group offload subgroup l3_stats on used on
RX: bytes packets errors dropped mcast
8900 72 2 0 3
TX: bytes packets errors dropped
7176 58 0 0

Observe cómo la información de l3_stats para el grupo seleccionado también forma parte del volcado.

subgrupos de group xstats y group xstats_slave:

subgroup bridge - Varias estadísticas en puentes y sus esclavos.

suite stp - Estadísticas STP
suite mcast - Estadísticas IGMP / MLD
suite vlan - Estadísticas de tráfico por VLAN

subgroup bond [ suite 802.3ad ] - Estadísticas para el tráfico LACP en dispositivos bond y sus esclavos.

subgrupos de group afstats:

subgroup mpls - Estadísticas para el tráfico MPLS visto en el dispositivo de red. Por ejemplo:

# ip stats show dev veth01 group afstats subgroup mpls
3: veth01: group afstats subgroup mpls
RX: bytes packets errors dropped noroute
0 0 0 0 0
TX: bytes packets errors dropped
216 2 0 0

EJEMPLOS

# ip stats set dev swp1 l3_stats on

Habilita la recopilación de estadísticas HW L3 en swp1.

# ip stats show group offload

Muestra todas las estadísticas de descarga en todos los dispositivos de red.

# ip stats show dev swp1 group link

Muestra las estadísticas de enlace en el dispositivo de red dado.
