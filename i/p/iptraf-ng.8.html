IPTRAF-NG(8) Manual del Administrador del Sistema IPTRAF-NG(8)

NOMBRE

iptraf - Monitor Interactivo de LAN IP en Color

SINOPSIS

iptraf-ng { [ -f ] [ { -i interfaz | -g | -d interfaz | -s interfaz | -z interfaz | -l interfaz } [ -t tiempo_espera ] [ -B [ -L archivo_registro ] ] ] | [ -h ] }

DESCRIPCIÓN

iptraf-ng es un monitor de LAN IP basado en ncurses que genera diversas estadísticas de red, incluyendo información de TCP, recuentos de UDP, información de ICMP y OSPF, información de carga de Ethernet, estadísticas de nodos, errores de suma de comprobación IP y otros.

Si se emite el comando iptraf-ng sin opciones de línea de comandos, el programa se inicia en modo interactivo, con las diversas funciones accesibles a través del menú principal.

OPCIONES

Estas opciones también se pueden pasar al comando:

-i interfaz
inicia inmediatamente el monitor de tráfico IP en la interfaz especificada, o en todas las interfaces si se especifica "-i all"
-g
inicia inmediatamente las estadísticas generales de la interfaz
-d interfaz
permite iniciar inmediatamente el detalle en la interfaz indicada (interfaz)
-s interfaz
permite monitorizar inmediatamente el tráfico TCP y UDP en la interfaz especificada (interfaz)
-z interfaz
muestra los recuentos de paquetes por tamaño en la interfaz especificada
-l interfaz
inicia el monitor de estaciones LAN en la interfaz especificada, o en todas las interfaces LAN si se especifica "-l all"
-t tiempo_espera
indica a IPTraf-ng que ejecute la función especificada durante solo tiempo_espera minutos. Esta opción solo se usa con uno de los parámetros anteriores.
-B
redirige la salida estándar a /dev/null, cierra la entrada estándar y pone el programa en segundo plano. Solo se puede usar con uno de los parámetros de invocación de funciones anteriores. Envíe una señal USR2 al proceso en segundo plano para terminarlo.
-L archivo_registro
permite especificar un nombre de archivo de registro alternativo. El nombre del archivo de registro predeterminado se basa en la interfaz seleccionada (estadísticas detalladas de la interfaz, estadísticas de servicios TCP/UDP, desglose de tamaño de paquetes), o en la instancia de la función (monitor de tráfico IP, monitor de estaciones LAN). Si no se especifica una ruta, el archivo de registro se coloca en /var/log/iptraf-ng
-f
borra todos los bloqueos y contadores, haciendo que esta instancia de IPTraf-ng piense que es la primera en ejecutarse. Esto solo debe usarse para recuperarse de una terminación anormal o un fallo del sistema.
-h
muestra un resumen de comandos

SEÑALES


SIGUSR1 - rota los archivos de registro mientras el programa se ejecuta
SIGUSR2 - termina un proceso IPTraf-ng ejecutándose en segundo plano.

ARCHIVOS


/var/log/iptraf-ng/*.log - archivo de registro
/var/lib/iptraf-ng/* - archivos de datos importantes de IPTraf-ng
