NOMBRE

ip-mroute - gestión de la caché de enrutamiento multicast

SINOPSIS


ip mroute show [ [ to ] PREFIJO ] [ from PREFIJO ] [ iif DISPOSITIVO ] [ table ID_TABLA ]

DESCRIPCIÓN

Los objetos mroute son entradas de la caché de enrutamiento multicast creadas por un demonio de enrutamiento multicast a nivel de usuario (por ejemplo, pimd o mrouted).

Debido a las limitaciones de la interfaz actual con el motor de enrutamiento multicast, es imposible modificar los objetos mroute administrativamente, por lo que solo podemos mostrarlos. Esta limitación se eliminará en el futuro.

ip mroute show - listar entradas de la caché mroute

to PREFIJO (por defecto)
el prefijo que selecciona las direcciones multicast de destino a listar.
iif NOMBRE
la interfaz en la que se reciben los paquetes multicast.
from PREFIJO
el prefijo que selecciona las direcciones IP de origen de la ruta multicast.
table ID_TABLA
el ID de tabla que selecciona la tabla multicast. Puede ser local, main, default, all o un número.
