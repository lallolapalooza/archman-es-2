NOMBRE

ip-fou - configuración de puertos de recepción Foo-over-UDP

ip-gue - configuración de puertos de recepción Generic UDP Encapsulation

SINOPSIS


ip [ OPCIONES ] fou { COMANDO | help }

ip fou add port PUERTO { gue | ipproto PROTO } [ local IFADDR ] [ peer IFADDR ] [ peer_port PUERTO ] [ dev IFNAME ]
ip fou del port PUERTO [ local IFADDR ] [ peer IFADDR ] [ peer_port PUERTO ] [ dev IFNAME ]
ip fou show

DESCRIPCIÓN

Los comandos ip fou se utilizan para crear y eliminar puertos de recepción para Foo-over-UDP (FOU) y Generic UDP Encapsulation (GUE).

Foo-over-UDP permite encapsular paquetes de un protocolo IP directamente sobre UDP. El receptor infiere el protocolo de un paquete recibido en un puerto UDP FOU como el protocolo configurado para el puerto.

Generic UDP Encapsulation (GUE) encapsula paquetes de un protocolo IP dentro de UDP y una cabecera de encapsulación. La cabecera de encapsulación contiene el número de protocolo IP para el paquete encapsulado.

Al crear un puerto de recepción FOU o GUE, el número de puerto se especifica en el argumento PUERTO. Si se utiliza FOU, el número de protocolo IP asociado al puerto se especifica en el argumento PROTO. Puede vincular un puerto a una dirección/interfaz local, especificando la dirección en el argumento IFADDR local o el dispositivo en el argumento IFNAME. Si desea conectar el puerto, puede especificar la dirección del par en el argumento IFADDR del par y el puerto del par en el argumento PORT peer_port.

Un puerto de recepción FOU o GUE se elimina especificando PUERTO en el comando de eliminación, así como la dirección/interfaz local o la dirección/puerto del par (si está configurado).

EJEMPLOS

Configurar un puerto de recepción FOU para GRE enlazado al puerto 7777

# ip fou add port 7777 ipproto 47

Configurar un puerto de recepción FOU para IPIP enlazado al puerto 8888

# ip fou add port 8888 ipproto 4

Configurar un puerto de recepción GUE enlazado al puerto 9999

# ip fou add port 9999 gue

Eliminar el puerto de recepción GUE enlazado al puerto 9999

# ip fou del port 9999

Configurar un puerto de recepción FOU para GRE enlazado a 1.2.3.4:7777

# ip fou add port 7777 ipproto 47 local 1.2.3.4
