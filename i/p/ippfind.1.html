CÓDIGO DE SAATUS

ippfind devuelve 0 si el resultado de todas las expresiones procesadas es verdadero, 1 si el resultado de alguna expresión procesada es falso, 2 si el examen o alguna consulta o resolución falló, 3 si se especificó una opción no definida o una expresión no válida, y 4 si se quedó sin memoria.

ENTORNO

Al ejecutar un programa, ippfind establece las siguientes variables de entorno para el registro del servicio coincidente:

IPPFIND_SERVICE_DOMAIN
Nombre de dominio, p. ej., "example.com.", "local.", etc.
IPPFIND_SERVICE_HOSTNAME
Nombre de dominio completamente calificado, p. ej., "printer.example.com.", "printer.local.", etc.
IPPFIND_SERVICE_NAME
Nombre de la instancia del servicio, p. ej., "My Fine Printer".
IPPFIND_SERVICE_PORT
Número de puerto del servidor, típicamente 631 para IPP y 80 para HTTP.
IPPFIND_SERVICE_REGTYPE
Tipo de registro DNS-SD, p. ej., "_ipp._tcp", "_http._tcp", etc.
IPPFIND_SERVICE_SCHEME
Esquema URI para el tipo de registro DNS-SD, p. ej., "ipp", "http", etc.
IPPFIND_SERVICE_URI
URI del servicio, p. ej., "ipp://printer.local./ipp/print", "http://printer.local./", etc.
IPPFIND_TXT_KEY
Valores del registro TXT KEY (en mayúsculas).

EJEMPLOS

Para mostrar el estado de todas las impresoras IPP registradas en su red, ejecute:

    ippfind --ls

De manera similar, para enviar una página de prueba PostScript a cada impresora PostScript, ejecute:

    ippfind --txt-pdl application/postscript --exec ipptool
      -f onepage-letter.ps '{}' print-job.test \;
