NOMBRE

ip-addrlabel - gestión de etiquetas de direcciones de protocolo

SINOPSIS


ip addrlabel { COMANDO | help }

ip addrlabel { add | del } prefix PREFIX [ dev DEV ] [ label NÚMERO ]

ip addrlabel { list | flush }

DESCRIPCIÓN

Las etiquetas de direcciones IPv6 se utilizan para la selección de direcciones; se describen en RFC 3484. La precedencia es gestionada por el espacio de usuario, y solo la etiqueta se almacena en el kernel.

ip addrlabel add - añadir una etiqueta de dirección

añade una entrada de etiqueta de dirección al kernel.

prefix PREFIX
dev DEV
la interfaz de salida.
label NÚMERO
la etiqueta para el prefijo. 0xffffffff está reservado.

ip addrlabel del - eliminar una etiqueta de dirección

elimina una entrada de etiqueta de dirección del kernel. Argumentos: coinciden con los argumentos de ip addrlabel add pero la etiqueta no es requerida.

ip addrlabel list - listar etiquetas de dirección

lista las entradas actuales de etiquetas de dirección en el kernel.

ip addrlabel flush - vaciar etiquetas de dirección

vacía todas las etiquetas de dirección en el kernel. Esto no restaura ningún ajuste predeterminado.
