NOMBRE

ip-tcp_metrics - gestión de métricas TCP

SINOPSIS


ip [ OPCIONES ] tcp_metrics { COMANDO | help }

ip tcp_metrics { show | flush } SELECTOR

ip tcp_metrics delete [ address ] DIRECCION

SELECTOR := [ [ address ] PREFIJO ]

DESCRIPCIÓN

ip tcp_metrics se utiliza para manipular entradas en el núcleo que conservan información TCP para destinos IPv4 e IPv6. Las entradas se crean cuando los sockets TCP desean compartir información para destinos y se almacenan en una caché indexada por la dirección de destino. La información guardada puede incluir valores para métricas (obtenidos inicialmente de rutas), TSVAL reciente para fines de reciclaje de TIME-WAIT, estado para la función Fast Open, etc. Por razones de rendimiento, la caché no puede crecer por encima del límite configurado y las entradas más antiguas se reemplazan con información nueva, a veces se recuperan y se utilizan para nuevos destinos. El núcleo nunca elimina entradas, solo se pueden vaciar con esta herramienta.

ip tcp_metrics show - mostrar entradas en caché

address PREFIJO (por defecto)
Prefijo o dirección IPv4/IPv6. Si no se proporciona prefijo, se muestran todas las entradas.

La salida puede contener la siguiente información:

age <S.MMM>sec - tiempo transcurrido desde que se creó, reinició o actualizó la entrada con métricas de sockets. La entrada se reinicia y se actualiza al usarse con métricas de la ruta si las métricas no se actualizan en la última hora. No todos los valores en caché reinician la edad al actualizarse.

cwnd <N> - valor de la métrica CWND

fo_cookie <CADENA-HEX> - valor de la cookie recibido en SYN-ACK para ser utilizado por Fast Open en los próximos SYN

fo_mss <N> - valor de MSS recibido en SYN-ACK para ser utilizado por Fast Open en los próximos SYN

fo_syn_drops <N>/<S.MMM>sec ago - Número de caídas de SYN de Fast Open salientes iniciales con datos detectadas al monitorear el SYN-ACK recibido después de la retransmisión de SYN. Los segundos muestran el tiempo transcurrido desde la última caída de SYN y, junto con el recuento de caídas, se pueden usar para deshabilitar Fast Open durante algún tiempo.

reordering <N> - valor de la métrica de reordenamiento

rtt <N>us - valor de la métrica RTT

rttvar <N>us - valor de la métrica RTTVAR

ssthresh <SSTHRESH> - valor de la métrica SSTHRESH

tw_ts <TSVAL>/<SEC>sec ago - TSVAL reciente y los segundos transcurridos desde que se guardó en el socket TIME-WAIT

ip tcp_metrics delete - eliminar entrada única

address DIRECCION (por defecto)
Dirección IPv4/IPv6. La dirección es un argumento obligatorio.

ip tcp_metrics flush - vaciar entradas

Este comando vacía las entradas seleccionadas por algún criterio.

Este comando tiene los mismos argumentos que show.

EJEMPLOS

ip tcp_metrics show address 192.168.0.0/24

Muestra las entradas para destinos de la subred

ip tcp_metrics show 192.168.0.0/24

Lo mismo, pero la palabra clave address es opcional

ip tcp_metrics

Mostrar todas las entradas es la acción por defecto

ip tcp_metrics delete 192.168.0.1

Elimina la entrada para 192.168.0.1 de la caché.

ip tcp_metrics flush 192.168.0.0/24

Elimina las entradas para destinos de la subred

ip tcp_metrics flush all

Elimina todas las entradas de la caché

ip -6 tcp_metrics flush all

Elimina todas las entradas IPv6 de la caché, manteniendo las entradas IPv4.
