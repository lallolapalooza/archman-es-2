NOMBRE

iptables-xml — Convertir el formato de iptables-save a XML

SINOPSIS

iptables-xml [-c] [-v]

DESCRIPCIÓN

iptables-xml se utiliza para convertir la salida de iptables-save a un formato XML fácilmente manipulable a STDOUT. Utilice la redirección de I/O proporcionada por su shell para escribir en un archivo.

-c, --combine
combinar reglas consecutivas con las mismas coincidencias pero diferentes objetivos. iptables actualmente no admite más de un objetivo por coincidencia, por lo que esto lo simula recopilando los objetivos de las reglas de iptables consecutivas en una etiqueta de acción, pero solo cuando las coincidencias de la regla son idénticas. Las acciones de terminación como RETURN, DROP, ACCEPT y QUEUE no se combinan con objetivos posteriores.
-v, --verbose
Salida de comentarios xml que contienen la línea de iptables de la cual se deriva el XML

iptables-xml realiza una conversión mecánica a un formato xml muy expresivo; las únicas consideraciones semánticas son para los objetivos -g y -j para discriminar entre <call> <goto> y <nane-of-target> ya que ayuda a los scripts de procesamiento de xml si pueden distinguir entre un objetivo como SNAT y otra cadena.

Alguna salida de ejemplo es:

<iptables-rules>
<table name="mangle">
<chain name="PREROUTING" policy="ACCEPT" packet-count="63436" byte-count="7137573">
<rule>
<conditions>
<match>
<p>tcp</p>
</match>
<tcp>
<sport>8443</sport>
</tcp>
</conditions>
<actions>
<call>
<check_ip/>
</call>
<ACCEPT/>
</actions>
</rule>
</chain>
</table> </iptables-rules>

La conversión del formato XML a iptables-save puede realizarse utilizando el script iptables.xslt y xsltproc, o un programa personalizado que utilice libxsltproc o similar; de la siguiente manera:

xsltproc iptables.xslt my-iptables.xml | iptables-restore

ERRORES

Ninguno conocido en el momento del lanzamiento de iptables-1.3.7
