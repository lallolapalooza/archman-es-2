NOMBRE

ipmidetect.conf - especificar valores predeterminados alternativos para la biblioteca ipmidetect

DESCRIPCIÓN

A través de un archivo de configuración, los administradores del sistema pueden anular los valores predeterminados utilizados en la función de API ipmidetect_load_data(3).

El archivo de configuración se almacena en /etc/freeipmi//ipmidetect.conf.

OPCIONES DE CONFIGURACIÓN

Las siguientes son una lista de opciones de configuración que se pueden especificar en el archivo de configuración. Cada opción de configuración debe estar en una línea separada. Los argumentos de una opción se separan por cualquier cantidad de espacio en blanco. Múltiples argumentos también se separan por espacio en blanco. Los comentarios se pueden marcar usando el carácter de signo de almohadilla ("#"), y las líneas se pueden continuar en la siguiente usando la barra invertida ("\").

nombres_host host1 host2 host3 ...
Especificar el nombre de host del servidor al que conectarse. Se pueden listar múltiples nombres de host hasta un máximo de 8.
puerto num
Especificar el puerto.
duracion_tiempo_espera segundos
Especificar la duración del tiempo de espera en segundos.
