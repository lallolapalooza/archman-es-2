Autenticación - Par de claves

RSA

La función de autenticación de iperf3 requiere un par de claves RSA. La clave pública se utiliza para cifrar el token de autenticación que contiene las credenciales del usuario, mientras que la clave privada se utiliza para descifrar el token de autenticación. La clave privada debe estar en formato PEM y además no debe tener una contraseña establecida. La clave pública debe estar en formato PEM y usar la codificación SubjectPrefixKeyInfo. correcto:
> openssl genrsa -des3 -out private.pem 2048

> openssl rsa -in private.pem -outform PEM -pubout -out public.
