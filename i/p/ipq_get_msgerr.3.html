ipq_get_msgerr(3)

Paquete: iptables

Licencias: GPL-2.0-only

IPQ_MESSAGE_TYPE(3) Manual del programador de Linux IPQ_MESSAGE_TYPE(3)

NOMBRE

ipq_message_type, ipq_get_packet, ipq_getmsgerr — consultar mensajes de la cola

SINOPSIS

#include <linux/netfilter.h>
#include <libipq.h>

int ipq_message_type(const unsigned char *buf);
ipq_packet_msg_t *ipq_get_packet(const unsigned char *buf);
int ipq_get_msgerr(const unsigned char *buf);

DESCRIPCIÓN

La función ipq_message_type devuelve el tipo de mensaje de cola devuelto al espacio de usuario a través de ipq_read.

ipq_message_type siempre debe llamarse después de una llamada exitosa a ipq_read para determinar si el mensaje es un mensaje de paquete o un mensaje de error. El parámetro buf debe ser los mismos datos obtenidos de la llamada anterior a ipq_read.

ipq_message_type devolverá uno de los siguientes valores:

NLMSG_ERROR
Un mensaje de error generado por el transporte Netlink.
IPQM_PACKET
Un mensaje de paquete que contiene metadatos del paquete y datos opcionales de la carga útil del paquete.

La función ipq_get_packet debe llamarse si ipq_message_type devuelve IPQM_PACKET. El parámetro buf debe apuntar a los mismos datos utilizados para la llamada a ipq_message_type. El puntero devuelto por ipq_get_packet apunta a un mensaje de paquete, que se declara de la siguiente manera:

typedef struct ipq_packet_msg {
	unsigned long packet_id;        /* ID del paquete en cola */
	unsigned long mark;             /* Valor de marca Netfilter */
	long timestamp_sec;             /* Tiempo de llegada del paquete (segundos) */
	long timestamp_usec;            /* Tiempo de llegada del paquete (+ microsegundos) */
	unsigned int hook;              /* Hook de Netfilter por el que entró */
	char indev_name[IFNAMSIZ];      /* Nombre de la interfaz de entrada */
	char outdev_name[IFNAMSIZ];     /* Nombre de la interfaz de salida */
	unsigned short hw_protocol;     /* Protocolo de hardware (orden de red) */
	unsigned short hw_type;         /* Tipo de hardware */
	unsigned char hw_addrlen;       /* Longitud de la dirección de hardware */
	unsigned char hw_addr[8];       /* Dirección de hardware */
	size_t data_len;                /* Longitud de los datos del paquete */
	unsigned char payload[0];       /* Datos opcionales del paquete */
} ipq_packet_msg_t;

Cada uno de estos campos puede ser leído por la aplicación. Si el modo de cola es IPQ_COPY_PACKET y el valor data_len es mayor que cero, los contenidos de la carga útil del paquete se pueden acceder en la memoria que sigue a la estructura ipq_packet_msg_t hasta un rango de data_len.

El campo packet_id contiene un identificador de paquete que se utilizará al llamar a ipq_set_verdict.

La función ipq_get_msgerr debe llamarse si ipq_message_type devuelve NLMSG_ERROR. El parámetro buf debe apuntar a los mismos datos utilizados para la llamada a ipq_message_type. El valor devuelto por ipq_get_msgerr es establecido por el código del kernel de nivel superior y corresponde a los valores estándar de errno.
