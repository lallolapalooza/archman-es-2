IGZIP(1) Comandos de usuario IGZIP(1)

NOMBRE

igzip - comprimir o descomprimir archivos similar a gzip

SINOPSIS

igzip [opciones] [archivos de entrada]

DESCRIPCIÓN

Comprime o descomprime archivos similar a gzip utilizando la biblioteca ISA-L de descompresión rápida.

Los archivos .gz de salida son compatibles con gzip y [RFC-1952].

Las opciones son similares a gzip excepto que --keep es el valor predeterminado.

OPCIONES

-h, --help
ayuda, imprime este mensaje
-#
usa el nivel de compresión # con 0 <= # <= 3
-o
<archivo> archivo de salida
-c, --stdout
escribe a stdout
-d, --decompress
descomprime archivo
-z, --compress
comprime archivo (predeterminado)
-f, --force
sobrescribe la salida sin preguntar
--rm
elimina los archivos fuente después de la (des)compresión exitosa
-k, --keep
mantiene los archivos fuente (predeterminado)
-S, --suffix <.suf>
sufijo a usar mientras se (des)comprime
-V, --version
muestra el número de versión
-v, --verbose
modo detallado
-N, --name
guarda/usa el nombre y la marca de tiempo del archivo al comprimir/descomprimir
-n, --no-name
no guarda/usa el nombre y la marca de tiempo del archivo al comprimir/descomprimir
-t, --test
prueba la integridad del archivo comprimido
-T, --threads <n>
usa n hilos para comprimir si están habilitados
-q, --quiet
suprime las advertencias

si no hay archivo de entrada, o cuando el archivo de entrada es - , lee la entrada estándar

EJEMPLOS

Crea los archivos comprimidos file1.gz y file2.gz y mantiene file1 y file2.

igzip file1 file2

Compresión y descompresión por tubería (piped).

igzip -c file.txt | igzip -d -c -

Compresión en streaming desde la salida de tar, nivel de compresión 2.

tar cf - dir1 | igzip -2 > dir1.tar.gz
