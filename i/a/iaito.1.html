IAITO(1) Manual de Comandos Generales IAITO(1)

NOMBRE

iaito - página del manual para iaito

SINOPSIS

iaito [opciones] nombre_archivo

DESCRIPCIÓN

Una GUI Qt y C++ para el framework de ingeniería inversa radare2. Iaito es la continuación de Iaito antes de la bifurcación de radare2 / rizin para mantener radare2 como backend.
- Enfocado en soportar la última versión de radare2.
- Recomendado el uso de bibliotecas instaladas en el sistema.
- Integración más estrecha entre r2 y la interfaz de usuario.

OPCIONES

-h, --help
Muestra la ayuda sobre las opciones de la línea de comandos.
--help-all
Muestra la ayuda incluyendo las opciones específicas de Qt.
-v, --version
Muestra la información de la versión.
-A, --analysis <nivel>
Abre el archivo automáticamente y opcionalmente inicia el análisis. Requiere especificar el nombre del archivo. Puede ser un valor entre 0 y 2: 0 = sin análisis, 1 = aaa, 2 = aaaa (experimental)
-F, --format <nombre>
Forzar el uso de un formato de archivo específico (plugin bin).
-B, --base <dirección_base>
Carga el binario en una dirección base específica.
-i <archivo>
Ejecuta el archivo de script.
-w, --writemode
Abre el archivo en modo de escritura.
--pythonhome <PYTHONHOME>
PYTHONHOME a usar para el intérprete de Python embebido.
--no-output-redirect
Deshabilita la redirección de salida. Parte de la salida en el widget de consola no será visible. Use esta opción cuando depure un error o bloqueo y la redirección de salida esté causando que se pierdan algunos mensajes.
--no-plugins
No cargar plugins.
--no-iaito-plugins
No cargar plugins de Iaito.
--no-r2-plugins
No cargar plugins de radare2.

Argumentos:

nombre_archivo
Nombre del archivo a abrir. Si no se especifica, se mostrará el diálogo de selección de archivo.
