NOMBRE

iasecc-tool - muestra información sobre la tarjeta IAS/ECC

SINOPSIS

iasecc-tool [OPCIONES]

DESCRIPCIÓN

La utilidad iasecc-tool se utiliza para mostrar información sobre las tarjetas inteligentes IAS/ECC v1.0.1.

OPCIONES

--reader arg,

Número del lector a utilizar. Por defecto, se utiliza el primer lector con una tarjeta presente. Si arg es un ATR, se elegirá el lector con una tarjeta coincidente.

--list-applications,

Obtiene la lista de aplicaciones en la tarjeta.

--aid hex-aid,

Selecciona hex-aid antes de procesar.

--list-sdos sdo-type,

Lista los SDO del sdo-type dado, presentes en la aplicación predeterminada o seleccionada.

--verbose, -v

Hace que cardos-tool sea más detallado. Especifique esta opción varias veces para habilitar la salida de depuración en la biblioteca opensc.

--wait, -w

Hace que iasecc-tool espere a que se inserte el token en el lector.
