IZAMAX

Propósito:

!>
!>    IZAMAX encuentra el índice del primer elemento que tiene máximo |Re(.)| + |Im(.)|
!>

Parámetros

N 
!>          N es ENTERO
!>         número de elementos en el vector(es) de entrada
!>

ZX

!>          ZX es un array COMPLEX*16, dimensión ( 1 + ( N - 1 )*abs( INCX ) )
!>

INCX

!>          INCX es ENTERO
!>         espaciado de almacenamiento entre elementos de ZX
