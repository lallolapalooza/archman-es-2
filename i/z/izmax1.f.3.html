función entera izmax1 (entero n, complejo*16, dimensión(*) zx, entero incx)

IZMAX1 encuentra el índice del primer elemento del vector de valor absoluto máximo.

Propósito

!>
!> IZMAX1 encuentra el índice del primer elemento del vector de valor absoluto máximo.
!>
!> Basado en IZAMAX de BLAS Nivel 1.
!> El cambio es usar el valor absoluto 'genuino'.
!>

Parámetros

N 
!>          N es ENTERO
!>          El número de elementos en el vector ZX.
!>

ZX

!>          ZX es un array de tipo COMPLEX*16, de dimensión (N)
!>          El vector ZX. La función IZMAX1 devuelve el índice de su primer
!>          elemento de valor absoluto máximo.
!>

INCX

!>          INCX es ENTERO
!>          El espaciado entre valores sucesivos de ZX. INCX >= 1.
!>
