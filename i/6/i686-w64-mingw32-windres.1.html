OPTIONS

--no-use-temp-file
Utiliza popen, no un archivo temporal, para leer la salida del preprocesador. Este es el comportamiento predeterminado.
-h
--help
Imprime un resumen de uso.

--version
Imprime el número de versión de windres.
--yydebug
Si windres se compila con "YYDEBUG" definido como 1, esto activará la depuración del analizador sintáctico.
@file
Lee las opciones de la línea de comandos desde file. Las opciones leídas se insertan en lugar de la opción @file original. Si file no existe, o no se puede leer, entonces la opción se tratará literalmente y no se eliminará.

Las opciones en file están separadas por espacios en blanco. Se puede incluir un carácter de espacio en blanco en una opción rodeando toda la opción con comillas simples o dobles. Se puede incluir cualquier carácter (incluido una barra invertida) prefijando el carácter a incluir con una barra invertida. El file puede contener opciones adicionales @file; todas esas opciones se procesarán recursivamente.
