WINDMC(1) Herramientas de desarrollo GNU WINDMC(1)

NOMBRE

windmc - genera recursos de mensajes de Windows

SINOPSIS

windmc [opciones] archivo-de-entrada

DESCRIPCIÓN

windmc lee definiciones de mensajes de un archivo de entrada (.mc) y las traduce en un conjunto de archivos de salida. Los archivos de salida pueden ser de cuatro tipos:

"h"
Un archivo de cabecera C que contiene las definiciones de mensajes.
"rc"
Un archivo de recursos compilable por la herramienta windres .
"bin"
Uno o más archivos binarios que contienen los datos de recursos para un idioma de mensaje específico.
"dbg"
Un archivo de inclusión C que asigna los identificadores de mensajes a su nombre simbólico.

La descripción exacta de estos diferentes formatos está disponible en la documentación de Microsoft.

Cuando windmc convierte del formato "mc" al formato "bin" , "rc", "h"y opcionalmente "dbg" , actúa como el Compilador de Mensajes de Windows.

OPCIONES

-a
--ascii_in
Especifica que el archivo de entrada especificado es ASCII. Este es el comportamiento predeterminado.
-A
--ascii_out
Especifica que los mensajes en los archivos de salida "bin" deben estar en formato ASCII.
-b
--binprefix
Especifica que los nombres de archivo "bin" deben tener el prefijo del nombre base del archivo de origen.
-c
--customflag
Establece el bit de cliente en todos los identificadores de mensajes.
-C página-de-código
--codepage_in página-de-código
Establece la página de código predeterminada a usar para convertir el archivo de entrada a UTF16. La predeterminada es la página de código 1252.
-d
--decimal_values
Muestra las constantes en el archivo de cabecera en decimal. El valor predeterminado es usar salida hexadecimal.
-e ext
--extension ext
La extensión para el archivo de cabecera. La extensión predeterminada es .h.
-F destino
--target destino
Especifica el formato BFD a usar para un archivo bin como salida. Este es un nombre de destino BFD; puede usar la opción --help para ver una lista de destinos admitidos. Normalmente windmc usará el formato predeterminado, que es el primero de la lista mostrada por la opción --help .
-h ruta
--headerdir ruta
El directorio de destino del archivo de cabecera generado. El directorio predeterminado es el directorio actual.
-H
--help
Muestra una lista de opciones de línea de comandos y luego sale.
-m caracteres
--maxlength caracteres
Indica a windmc que genere una advertencia si la longitud de algún mensaje excede el número especificado.
-n
--nullterminate
Termina el texto del mensaje en los archivos "bin" con cero. Por defecto, se terminan con CR/LF.
-o
--hresult_use
Aún no implementado. Indica a "windmc" que genere un archivo de cabecera OLE2, usando definiciones HRESULT. Se usan códigos de estado si no se especifica la bandera.
-O página-de-código
--codepage_out página-de-código
Establece la página de código predeterminada a usar para generar archivos de texto. La predeterminada es la página de código 1252.
-r ruta
--rcdir ruta
El directorio de destino para el script "rc" generado y los archivos "bin" generados que el script del compilador de recursos incluye. El directorio predeterminado es el directorio actual.
-u
--unicode_in
Especifica que el archivo de entrada es UTF16.
-U
--unicode_out
Especifica que los mensajes en el archivo de salida "bin" deben estar en formato UTF16. Este es el comportamiento predeterminado.
-v
--verbose
Activa el modo detallado.
-V
--version
Imprime el número de versión de windmc.
-x ruta
--xdgb ruta
La ruta del archivo de inclusión C "dbg" que asigna los identificadores de mensajes a su nombre simbólico. No se genera tal archivo sin especificar la opción.
@archivo
Lee las opciones de línea de comandos desde archivo. Las opciones leídas se insertan en lugar de la opción original @archivo . Si archivo no existe o no se puede leer, la opción se tratará literalmente y no se eliminará.

Las opciones en archivo están separadas por espacios en blanco. Un carácter espacio en blanco puede incluirse en una opción rodeando la opción completa con comillas simples o dobles. Cualquier carácter (incluida una barra invertida) puede incluirse anteponiendo al carácter que se desea incluir una barra invertida. El archivo puede contener opciones adicionales @archivo ; cualquier opción de este tipo se procesará recursivamente.

VÉASE TAMBIÉN

las entradas Info de binutils.
