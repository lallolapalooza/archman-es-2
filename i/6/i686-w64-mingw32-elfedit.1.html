Paquete: mingw-w64-binutils

ELFEDIT(1) Herramientas de desarrollo GNU ELFEDIT(1)

NOMBRE

elfedit - actualizar la cabecera ELF y la propiedad de programa de archivos ELF

SINOPSIS

elfedit [--input-mach=machine]
[--input-type=type]
[--input-osabi=osabi]
[--input-abiversion=version]
--output-mach=machine
--output-type=type
--output-osabi=osabi
--output-abiversion=version
--enable-x86-feature=feature
--disable-x86-feature=feature
[-v|--version]
[-h|--help]
elffile...

DESCRIPCIÓN

elfedit actualiza la cabecera ELF y la propiedad de programa de archivos ELF que tienen el tipo de máquina ELF y el tipo de archivo coincidentes. Las opciones controlan cómo y qué campos de la cabecera ELF y la propiedad de programa deben actualizarse.

elffile... son los archivos ELF que se actualizarán. Se admiten archivos ELF de 32 bits y de 64 bits, así como archivos que contienen archivos ELF.

OPCIONES

Las formas largas y cortas de las opciones, mostradas aquí como alternativas, son equivalentes. Debe indicarse al menos una de las opciones --output-mach, --output-type, --output-osabi, --output-abiversion, --enable-x86-feature y --disable-x86-feature .

--input-mach=machine
Establece el tipo de máquina ELF de entrada coincidente a machine. Si --input-mach no se especifica, coincidirá con cualquier tipo de máquina ELF.

Los tipos de máquina ELF admitidos son i386, IAMCU, L1OM, K1OM y x86-64.

--output-mach=machine
Cambia el tipo de máquina ELF en la cabecera ELF a machine. Los tipos de máquina ELF admitidos son los mismos que para --input-mach.
--input-type=type
Establece el tipo de archivo ELF de entrada coincidente a type. Si --input-type no se especifica, coincidirá con cualquier tipo de archivo ELF.

Los tipos de archivo ELF admitidos son rel, exec y dyn.

--output-type=type
Cambia el tipo de archivo ELF en la cabecera ELF a type. Los tipos ELF admitidos son los mismos que para --input-type.
--input-osabi=osabi
Establece el OSABI del archivo ELF de entrada coincidente a osabi. Si --input-osabi no se especifica, coincidirá con cualquier OSABI ELF.

Los OSABI ELF admitidos son none, HPUX, NetBSD, GNU, Linux (alias para GNU), Solaris, AIX, Irix, FreeBSD, TRU64, Modesto, OpenBSD, OpenVMS, NSK, AROS y FenixOS.

--output-osabi=osabi
Cambia el OSABI ELF en la cabecera ELF a osabi. Los OSABI ELF admitidos son los mismos que para --input-osabi.
--input-abiversion=version
Establece el ABIVERSION del archivo ELF de entrada coincidente a version. version debe estar entre 0 y 255. Si --input-abiversion no se especifica, coincidirá con cualquier ABIVERSION ELF.
--output-abiversion=version
Cambia el ABIVERSION ELF en la cabecera ELF a version. version debe estar entre 0 y 255.
--enable-x86-feature=feature
Establece el bit de feature en la propiedad de programa en archivos ELF exec o dyn con tipos de máquina i386 o x86-64. Las características admitidas son ibt, shstk, lam_u48 y lam_u57.
--disable-x86-feature=feature
Borra el bit de feature en la propiedad de programa en archivos ELF exec o dyn con tipos de máquina i386 o x86-64. Las características admitidas son las mismas que para --enable-x86-feature.

Nota: --enable-x86-feature y --disable-x86-feature solo están disponibles en hosts con soporte de mmap .

-v
--version
Muestra el número de versión de elfedit.
-h
--help
Muestra las opciones de línea de comandos que reconoce elfedit.
@file
Lee las opciones de línea de comandos desde file. Las opciones leídas se insertan en lugar de la opción original @file . Si file no existe o no se puede leer, la opción se tratará literalmente y no se eliminará.

Las opciones en file se separan mediante espacios en blanco. Un carácter en blanco puede incluirse en una opción rodeando toda la opción con comillas simples o dobles. Cualquier carácter (incluida una barra invertida) puede incluirse anteponiendo al carácter que se desea incluir una barra invertida. El file puede contener opciones adicionales @file ; dichas opciones se procesarán recursivamente.

VÉASE TAMBIÉN

readelf(1), y las entradas de Info de binutils.
