gprof - mostrar datos de perfil de grafo de llamadas

DESCRIPCIÓN

"gprof" produce un perfil de ejecución de programas C, Pascal o Fortran77. El efecto de las rutinas llamadas se incorpora en el perfil de cada llamador. Los datos de perfil se toman del archivo de perfil de grafo de llamadas (gmon.out por defecto) que se crea con programas compilados con la opción -pg de "cc", "pc" y "f77". La opción -pg también enlaza versiones de las rutinas de la biblioteca que están compiladas para perfilado. "Gprof" lee el archivo objeto dado (el predeterminado es "a.out") y establece la relación entre su tabla de símbolos y el perfil de grafo de llamadas de gmon.out. Si se especifican más de un archivo de perfil, la salida de "gprof" muestra la suma de la información de perfil de los archivos de perfil dados.

"Gprof" calcula la cantidad de tiempo gastado en cada rutina. Luego, estos tiempos se propagan a lo largo de los bordes del grafo de llamadas. Se descubren ciclos y las llamadas a un ciclo se hacen para compartir el tiempo del ciclo.

Varios formatos de salida están disponibles a partir del análisis.

El perfil plano muestra cuánto tiempo pasó tu programa en cada función y cuántas veces se llamó a esa función. Si solo quieres saber qué funciones consumen la mayor parte del tiempo de ejecución, aquí se indica concisamente.

El grafo de llamadas muestra, para cada función, qué funciones la llamaron, qué otras funciones llamó y cuántas veces. También hay una estimación de cuánto tiempo se gastó en las subrutinas de cada función. Esto puede sugerir lugares donde podrías intentar eliminar llamadas a funciones que usan mucho tiempo.

La fuente anotada es una copia del código fuente del programa, etiquetada con el número de veces que se ejecutó cada línea del programa.

OPCIONES

Estas opciones especifican cuál de los varios formatos de salida debería producir "gprof".

Muchas de estas opciones toman un symspec opcional para especificar funciones a incluir o excluir. Estas opciones se pueden especificar múltiples veces, con diferentes symspecs, para incluir o excluir conjuntos de símbolos.

La especificación de cualquiera de estas opciones anula los valores predeterminados (-p -q), que imprimen un perfil plano y análisis de grafo de llamadas para todas las funciones.

"-A[symspec]"
"--fuente-anotada[=symspec]"
La opción -A hace que "gprof" imprima código fuente anotado. Si se especifica symspec, imprima la salida solo para los símbolos coincidentes.
"-b"
"--breve"
Si se proporciona la opción -b, "gprof" no imprime los textos explicativos excesivos que intentan explicar el significado de todos los campos en las tablas. Esto es útil si tienes la intención de imprimir la salida, o estás cansado de ver los textos explicativos.
"-B"
La opción -B hace que "gprof" imprima el análisis del grafo de llamadas.
"-C[symspec]"
"--conteo-ejecuciones[=symspec]"
La opción -C hace que "gprof" imprima un recuento de funciones y el número de veces que cada una fue llamada. Si se especifica symspec, imprima el recuento solo para los símbolos coincidentes.

Si el archivo de datos de perfil contiene registros de conteo de bloques básicos, la especificación de la opción -l, junto con -C, hará que los conteos de ejecución de bloques básicos se recopilen y muestren.

"-i"
"--info-archivo"
La opción -i hace que "gprof" muestre información de resumen sobre el archivo(s) de datos de perfil y luego salga. Se muestra el número de registros de histograma, grafo de llamadas y conteo de bloques básicos.
"-I directorios"
"--ruta-directorio=directorios"
La opción -I especifica una lista de directorios de búsqueda en los que encontrar archivos fuente. La variable de entorno GPROF_PATH también se puede usar para transmitir esta información. Se utiliza principalmente para la salida de fuente anotada.
"-J[symspec]"
"--no-fuente-anotada[=symspec]"
La opción -J hace que "gprof" no imprima código fuente anotado. Si se especifica symspec, "gprof" imprime la fuente anotada, pero excluye los símbolos coincidentes.
"-L"
"--imprimir-ruta"
Normalmente, los nombres de archivo de origen se imprimen suprimiendo el componente de ruta. La opción -L hace que "gprof" imprima la ruta completa de los nombres de archivo de origen, que se determina a partir de la información de depuración simbólica en el archivo imagen y es relativa al directorio en el que se invocó el compilador.
"-p[symspec]"
"--perfil-plano[=symspec]"
La opción -p hace que "gprof" imprima un perfil plano. Si se especifica symspec, imprima el perfil plano solo para los símbolos coincidentes.
"-P[symspec]"
"--no-perfil-plano[=symspec]"
La opción -P hace que "gprof" suprima la impresión de un perfil plano. Si se especifica symspec, "gprof" imprime un perfil plano, pero excluye los símbolos coincidentes.
"-q[symspec]"
"--grafo[=symspec]"
La opción -q hace que "gprof" imprima el análisis del grafo de llamadas. Si se especifica symspec, imprima el grafo de llamadas solo para los símbolos coincidentes y sus hijos.
"-Q[symspec]"
"--no-grafo[=symspec]"
La opción -Q hace que "gprof" suprima la impresión del grafo de llamadas. Si se especifica symspec, "gprof" imprime un grafo de llamadas, pero excluye los símbolos coincidentes.
"-t"
"--longitud-tabla=num"
La opción -t hace que las num líneas de origen más activas en cada archivo de origen se listen cuando la anotación de origen está habilitada. El valor predeterminado es 10.
"-y"
"--archivos-separados"
Esta opción solo afecta la salida de fuente anotada. Normalmente, "gprof" imprime archivos fuente anotados en la salida estándar. Si se especifica esta opción, la fuente anotada para un archivo llamado ruta/nombre_archivo se genera en el archivo nombre_archivo-ann. Si el sistema de archivos subyacente truncara nombre_archivo-ann de modo que sobrescribiera el nombre_archivo original, "gprof" generará la fuente anotada en el archivo nombre_archivo.ann en su lugar (si el nombre de archivo original tiene una extensión, esa extensión se reemplaza por .ann).

OPCIONES

"-f nombre_funcion"
La opción -f nombre_funcion se utiliza con "gprof" para limitar el grafo de llamadas a la función nombre_funcion y sus hijos (y los hijos de sus hijos...). Se pueden proporcionar varias opciones -f; solo se puede indicar un nombre_funcion con cada opción -f.
"-F nombre_funcion"
La opción -F nombre_funcion funciona de manera similar a la opción "-f", pero solo el tiempo empleado en la función y sus hijos (y los hijos de sus hijos...) se utilizará para determinar el tiempo total y los porcentajes de tiempo del grafo de llamadas. Se pueden proporcionar varias opciones -F; solo se puede indicar un nombre_funcion con cada opción -F. La opción -F anula la opción -E.

ERRORES

Se muestra la granularidad del muestreo, pero sigue siendo, en el mejor de los casos, estadística. Asumimos que el tiempo de cada ejecución de una función puede expresarse como el tiempo total de la función dividido por el número de veces que se llama a la función. Por lo tanto, el tiempo propagado a lo largo de los arcos del grafo de llamadas hacia los padres de la función es directamente proporcional al número de veces que se recorre ese arco.

Los padres que no están perfilados tendrán el tiempo de sus hijos perfilados propagado a ellos, pero aparecerán como invocados espontáneamente en la lista del grafo de llamadas, y su tiempo no se propagará más. De manera similar, los capturadores de señales, aunque perfilados, aparecerán como espontáneos (aunque por razones más oscuras). Cualquier hijo perfilado de un capturador de señales debería tener su tiempo propagado correctamente, a menos que el capturador de señales se haya invocado durante la ejecución de la rutina de perfilado, en cuyo caso se pierde todo.

El programa perfilado debe llamar a "exit"(2) o retornar normalmente para que la información de perfilado se guarde en el archivo gmon.out.
