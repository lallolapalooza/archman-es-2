ICEWM-THEME(5) Estándares, Entornos y Macros ICEWM-THEME(5)

NOMBRE

icewm-theme - archivo de configuración de tema de icewm

SINOPSIS

$ICEWM_PRIVCFG/theme
$XDG_CONFIG_HOME/icewm/theme
$HOME/.icewm/theme
/usr/etc/icewm/theme
/usr/share/icewm/theme

DESCRIPCIÓN

El archivo theme contiene el nombre del tema predeterminado. Al iniciarse, icewm lee este archivo para obtener el nombre del tema, a menos que icewm se haya iniciado con la opción --theme. Cada vez que se selecciona un tema diferente desde el Menú de icewm, el archivo de tema se sobrescribe con el nombre del tema seleccionado.

FORMATO

Este archivo de tema contiene la palabra clave "Theme", seguida de un signo igual, seguido de una cadena entre comillas dobles con el nombre del tema. El nombre del tema es el nombre del directorio del tema, seguido de una barra, seguido del archivo del tema.

Por lo general, el archivo del tema es simplemente default.theme, pero un tema puede tener alternativas. Las alternativas son pequeños ajustes de un tema. Estos se especifican en su propio archivo .theme, que reemplaza a default.theme.

Si no existe ningún archivo de tema, icewm usará la configuración predeterminada de "Theme="icedesert/default.theme"".

EJEMPLOS

A continuación se muestra un archivo de tema. Los comentarios indican que icewm(1) mantiene un historial de configuraciones de tema anteriores.

Theme="CrystalBlue/default.theme"
#Theme="icedesert/default.theme"
##Theme="default/default.theme"

ARCHIVOS

Las ubicaciones del archivo theme son las siguientes:

$ICEWM_PRIVCFG/theme
$XDG_CONFIG_HOME/icewm/theme
$HOME/.icewm/theme
/usr/etc/icewm/theme
/usr/share/icewm/theme

Las ubicaciones se buscan en el orden indicado; el primer archivo encontrado se lee y el resto se ignora.

VER TAMBIÉN

icewm(1), icewm-preferences(5), icewm-prefoverride(5).
