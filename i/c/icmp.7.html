DESCRIPCIÓ

N

Este módulo de protocolo del kernel implementa el Protocolo de Mensajes de Control de Internet definido en el RFC 792. Se utiliza para señalizar condiciones de error y para diagnóstico. El usuario no interactúa directamente con este módulo; en su lugar, este se comunica con los otros protocolos en el kernel y estos pasan los errores ICMP a las capas de aplicación. El módulo ICMP del kernel también responde a peticiones

ICMP.

Un protocolo de usuario puede recibir paquetes ICMP para todos los sockets locales abriendo un socket crudo (raw) con el protocolo IPPROTO_ICMP. Véase raw(7) para más información. Los tipos de paquetes ICMP pasados al socket pueden ser filtrados usando la opción de socket ICMP_FILTER. Los paquetes ICMP son siempre procesados por el kernel también, incluso cuando se pasan a un socket de

usuario.

Linux limita la tasa de paquetes de error ICMP a cada destino. ICMP_REDIRECT y ICMP_DEST_UNREACH también están limitados por la ruta de destino de los paquetes

entrantes.

Interfaces

de

/proc ICMP soporta un conjunto de interfaces de /proc para configurar algunos parámetros globales de IP. Los parámetros pueden ser accedidos leyendo o escribiendo archivos en el directorio /proc/sys/net/ipv4/. La mayoría de estos parámetros son limitaciones de tasa para tipos ICMP específicos. Linux 2.2 usa un filtro de cubo de fichas (token bucket) para limitar los ICMP. El valor es el tiempo de espera en jiffies hasta que el filtro de cubo de fichas se limpia después de una ráfaga. Un jiffy es una unidad dependiente del sistema, usualmente 10ms en i386 y alrededor de 1ms en alpha e

ia64.

NOTA

S

Dado que muchas otras implementaciones no soportan sockets crudos (raw) IPPROTO_ICMP, esta característica no debería ser usada en programas

portables.

Los paquetes ICMP_REDIRECT no se envían cuando Linux no está actuando como un router. También son aceptados solo desde la puerta de enlace antigua definida en la tabla de enrutamiento y las rutas de redirección expiran después de algún

tiempo.

La marca de tiempo de 64 bits devuelta por ICMP_TIMESTAMP está en milisegundos desde la época, 1970-01-01 00:00:00 +0000 (UTC)

.

Linux ICMP usa internamente un socket crudo (raw) para enviar ICMP. Este socket crudo puede aparecer en la salida de netstat(8) con

un inod
o cero.
