El archivo de configuración icmconf se utiliza para configurar el mantenimiento del programa realizado por icmbuild(1). Utiliza varias directivas que determinan cómo se realiza el mantenimiento del programa o de la

biblioteca.

Las directivas de Icmconf están orientadas hacia la construcción de programas C++, pero el mantenimiento de programas en otros lenguajes (por ejemplo, C) también se puede configurar

fácilmente.

El script icmbuild(1) ignora las líneas vacías y las líneas cuyos primeros caracteres no en blanco son dos barras diagonales consecutivas (//) o que comienzan con un carácter almohadilla (#). Las líneas largas se pueden dividir en varias líneas escribiendo un cará

cter barra invertida final en las líneas
que continúan en la siguiente línea.

DEPENDENCIAS DE

CLASE

Las utilidades make tradicionales recompilan todas las fuentes dependientes una vez que se modifican los archivos de cabecera. Al desarrollar programas C++ esto casi nunca es necesario, ya que añadir nuevas funciones miembro a las clases no requiere que recompile los archivos fuente ya existentes. La recompilación es necesaria cuando se altera la organización de los miembros de datos de las

clases.

Para manejar las dependencias de las clases de una manera más sensata, icmake(1) comprueba las dependencias de las clases utilizando sus programas de soporte icm-dep, visitando las clases listadas en el archivo CLASSES si se especificó la directiva USE_ALL de icmconf. Si un directorio mencionado en el archivo CLASSES contiene un archivo con un nombre igual al nombre especificado en el parámetro USE_ALL, entonces todas las fuentes de las clases que dependen de esa clase en particular también se recompilan. En la práctica, esto significa que cuando cambia la organización de datos de una clase solo necesita tocar ese directorio el archivo cuyo nombre fue especificado por la directiva USE_ALL. Por ejemplo, si su clase se llama Data, sus fuentes están en el subdirectorio ./data, y se especificó #define USE_ALL "a", entonces después de modificar la organización de datos de la clase Data solo necesita emitir el comando touch data/a. Posteriormente, en la siguiente llamada a icmbuild todas las fuentes en ./data, así como todas las fuentes en directorios cuyos archivos de cabecera incluyen data.h, también se

recompilan.

Del mismo modo, si se usó #define SPCH o (obsoleto) #define PRECOMP, se realiza una acción similar para las cabeceras precompiladas: si un archivo local que es (directa o indirectamente) incluido por archivos de cabecera internos ha cambiado, entonces el archivo de Cabecera Precompilada Única (SPCH) se recompila (o (obsoleto), habiendo especificado PRECOMP las cabeceras de clase modificadas se recompilan)

.

El script icmbuild(1) en sí no inspecciona estas dependencias, sino que llama a los programas de soporte icm-spch y icm-dep para realizar las pruebas necesarias. Los resúmenes de uso de estos programas se escriben en el flujo de salida estándar al llamar, respectivamente icmake -S y icmake -d

.
