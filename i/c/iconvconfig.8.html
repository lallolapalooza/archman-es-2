iconvconfig(8) Manual del Administrador del Sistema iconvconfig(8)

NOMBRE

iconvconfig - crea la caché de configuración del módulo iconv

SINOPSIS

iconvconfig [opciones] [directorio]...

DESCRIPCIÓN

La función iconv(3) utiliza internamente módulos gconv para convertir hacia y desde un conjunto de caracteres. Se utiliza un archivo de configuración para determinar los módulos necesarios para una conversión. Cargar y analizar dicho archivo de configuración ralentizaría los programas que utilizan iconv(3), por lo que se emplea un mecanismo de caché.

El programa iconvconfig lee los archivos de configuración de módulos iconv y escribe un archivo de caché de configuración de módulos gconv de carga rápida.

Además de los módulos gconv proporcionados por el sistema, el usuario puede especificar directorios de módulos gconv personalizados con la variable de entorno GCONV_PATH. Sin embargo, la caché de configuración de módulos iconv solo se utiliza cuando la variable de entorno GCONV_PATH no está establecida.

OPCIONES

--nostdlib
No buscar en el directorio gconv predeterminado del sistema, solo en los directorios proporcionados en la línea de comandos.
--output=archivo_salida
-o archivo_salida
Usar archivo_salida para la salida en lugar de la ubicación de caché predeterminada del sistema.
--prefix=ruta
Establecer el prefijo que se antepondrá a las rutas del sistema. Véase ARCHIVOS, a continuación. Por defecto, el prefijo está vacío. Si se establece el prefijo en foo, el archivo de configuración del módulo gconv se leerá de foo/usr/lib/gconv/gconv-modules y la caché se escribirá en foo/usr/lib/gconv/gconv-modules.cache.
--help
-?
Imprimir un resumen de uso y salir.
--usage
Imprimir un resumen de uso corto y salir.
--version
-V
Imprimir el número de versión, la licencia y la exención de garantía de iconv.

ESTADO DE SALIDA

Cero si la operación es exitosa, distinto de cero si hay errores.

ARCHIVOS

/usr/lib/gconv
Ruta habitual predeterminada de los módulos gconv.
/usr/lib/gconv/gconv-modules
Archivo de configuración habitual predeterminado del sistema de módulos gconv.
/usr/lib/gconv/gconv-modules.cache
Caché habitual predeterminada del sistema de configuración de módulos gconv.

Dependiendo de la arquitectura, los archivos anteriores pueden estar ubicados en directorios con el prefijo de ruta /usr/lib64.

VER TAMBIÉN

iconv(1), iconv(3)
