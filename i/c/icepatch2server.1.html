NOMBRE

icepatch2server - El servidor IcePatch2.

SINOPSIS

icepatch2server <directorio de datos>

DESCRIPCIÓN

El servidor IcePatch2. La documentación completa para icepatch2server está disponible en línea en:
https://doc.zeroc.com/ice/3.7/ice-services/icepatch2/running-the-icepatch2-server

OPCIONES

-h, --help

Muestra un mensaje de ayuda.
-v, --version
Muestra la versión de Ice.
--daemon

Ejecutar como demonio.
--pidfile ARCHIVO

Escribe el ID del proceso en ARCHIVO.
--noclose

No cerrar los descriptores de archivo abiertos.
--nochdir

No cambiar el directorio de trabajo actual.

VER TAMBIÉN

icepatch2calc(1), icepatch2client(1)
