ICEWM-MENU(5) Estándares, Entornos y Macros ICEWM-MENU(5)

NOMBRE

icewm-menu - archivo de configuración de menú de icewm

SINOPSIS

$ICEWM_PRIVCFG/menu
$XDG_CONFIG_HOME/icewm/menu
$HOME/.icewm/menu
/usr/etc/icewm/menu
/usr/share/icewm/menu

DESCRIPCIÓN

El archivo menu es responsable de configurar la mayor parte del menú raíz y el menú de inicio de icewm(1).

Un menú que da acceso a las aplicaciones; usualmente personalizado por el usuario. El programa icewm-menu-fdo(1) genera un menú predeterminado que contiene la mayoría de las aplicaciones de escritorio del sistema. Programas similares son xdg_menu(1), mmaker(1), xde-menu(1) y xdgmenumaker(1).

FORMATO

El archivo contiene líneas con la siguiente sintaxis:

prog "título" icono programa opciones
Especifica un programa a ejecutar cuando se selecciona el elemento del menú.
restart "título" icono programa opciones
Especifica un programa para reemplazar el gestor de ventanas cuando se selecciona el elemento del menú. Esto es para lanzar otros gestores de ventanas desde icewm(1).
runonce "título" icono "[nombre][.clase]" programa opciones
Especifica un programa a ejecutar cuando se selecciona el elemento del menú; sin embargo, si una ventana del nombre y clase especificados está presente, el programa no se ejecutará de nuevo.
menu "título" icono { # elementos contenidos }
Especifica un submenú. Las líneas que aparecen entre las llaves pueden ser cualquier elemento de menú descrito aquí.
menufile "título" icono "nombre_archivo"
Especifica un archivo del cual recopilar elementos de submenú (líneas) y colocarlos en este punto del menú.
menuprog "título" icono programa opciones
Especifica un programa que imprimirá los elementos del submenú en la salida estándar, los cuales serán recopilados y colocados en el submenú en este punto.
menuprogreload "título" icono tiempo_espera programa opciones
Similar a menuprog, pero después de al menos tiempo_espera segundos el menú se regenera.
include "nombre_archivo"
Lee entradas adicionales del archivo nombre_archivo
includeprog programa opciones
Lee entradas adicionales de la salida de programa opciones.
separator
Un separador para los elementos del menú.

Donde

prog, restart, runonce, menu, menufile, menuprog, menuprogreload, include, includeprog, separator
Estas son palabras clave de cadena literal.
"título"
Esta es la cadena de título asociada con el elemento del menú que se muestra en el menú. Cuando el título contiene espacios, el título debe estar rodeado por comillas dobles ("").
icono
Es el nombre del archivo de icono (con o sin extensión) o la ruta completa a un archivo de icono.
"[nombre][.clase]"
nombre es el nombre del recurso de una ventana lanzada por programa y clase es la clase del recurso de la ventana. Solo uno de nombre o clase necesita especificarse. Esto se usa para determinar si el programa ya se está ejecutando y se usa con la palabra clave runonce.
programa opciones
programa es el nombre del ejecutable o la ruta completa del archivo ejecutable que se ejecutará en respuesta a la selección del elemento del menú. Cuando se usa con la palabra clave menuprog, el programa debe imprimir en la salida estándar el contenido del menú y se usa para menús dinámicos.

opciones son las opciones y argumentos pasados al programa literalmente.

nombre_archivo
nombre_archivo es el nombre del archivo relativo a uno de los directorios de configuración de icewm(1), o la ruta completa a un archivo. El archivo se usa con la palabra clave menufile y especifica el archivo del cual leer más elementos del menú.

EJEMPLOS

A continuación se muestra el archivo menu de ejemplo que se distribuye con icewm(1):

# Este es un ejemplo para el archivo de definición de menú de IceWM.
#
# Coloque sus variantes en /usr/etc/icewm o en $HOME/.icewm
# ya que las modificaciones a este archivo se descartarán cuando usted
# (re)instale icewm.
#
prog xterm xterm xterm
prog rxvt xterm rxvt -bg black -cr green -fg white -C -fn 9x15 -sl 500
prog fte fte fte
prog NEdit nedit nedit
prog Mozilla mozilla mozilla
prog XChat xchat xchat
prog Gimp gimp gimp
separator
menuprog "Desktop Apps" folder icewm-menu-fdo
menufile Programs folder programs
menufile Tool_bar folder toolbar

ARCHIVOS

Las ubicaciones para el archivo menu son las siguientes:

$ICEWM_PRIVCFG/menu
$XDG_CONFIG_HOME/icewm/menu
$HOME/.icewm/menu
/usr/etc/icewm/menu
/usr/share/icewm/menu

Las ubicaciones se buscan en el orden listado; el primer archivo encontrado se lee y el resto se ignora.
