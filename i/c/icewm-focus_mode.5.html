icewm-focus_mode(5)

Paquete: icewm

Licencias: LGPL-2.0-only

ICEWM-FOCUS_MODE(5) Estándares, Entornos y Macros ICEWM-FOCUS_MODE(5)

NOMBRE

icewm-focus_mode - archivo de configuración del modo de enfoque de icewm

SINOPSIS

$ICEWM_PRIVCFG/focus_mode
$XDG_CONFIG_HOME/icewm/focus_mode
$HOME/.icewm/focus_mode
/usr/etc/icewm/focus_mode
/usr/share/icewm/focus_mode

DESCRIPCIÓN

Define el valor inicial para "FocusMode". Su valor predeterminado es "FocusMode=1" (Clic para enfocar). Esto se puede cambiar a través del menú. icewm guardará la elección del menú Enfoque en este archivo.

FORMATO

El archivo contiene una sola línea con la asignación de preferencias para FocusMode.

EJEMPLOS

Este es mi archivo focus_mode:

FocusMode=2

ARCHIVOS

Las ubicaciones del archivo focus_mode son las siguientes:

$ICEWM_PRIVCFG/focus_mode
$XDG_CONFIG_HOME/icewm/focus_mode
$HOME/.icewm/focus_mode
/usr/share/icewm/focus_mode
/usr/local/share/icewm/focus_mode

Las ubicaciones se buscan en el orden indicado; el primer archivo encontrado se lee y el resto se ignora.

VER TAMBIÉN

icewm(1), icewm-preferences(5).
