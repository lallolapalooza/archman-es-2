ICEWM-ENV(5) Estándares, Entornos y Macros ICEWM-ENV(5)

NOMBRE

icewm-env - archivo de configuración del entorno de icewm

SINOPSIS

$ICEWM_PRIVCFG/env
$XDG_CONFIG_HOME/icewm/env
$HOME/.icewm/env
/usr/etc/icewm/env
/usr/share/icewm/env

DESCRIPCIÓN

icewm-session(1) carga variables de entorno adicionales del archivo env antes de hacer cualquier otra cosa. Estas variables se propagan luego a todos los demás procesos, incluido icewm(1), a través de su entorno.

FORMATO

Cada línea se somete a expansión de shell POSIX mediante wordexp(3). Las líneas de comentarios que comienzan con un signo de almohadilla ("#") se ignoran. icewm-session(1) cargará aquellas líneas expandidas que contengan un nombre, seguido de un signo igual, seguido del valor (que puede estar vacío).

La palabra unset inicia una línea con nombres que se eliminarán del entorno.

EJEMPLOS

# Esto es un comentario.
# Y otro.
XDG_CURRENT_DESKTOP="ICEWM"
XDG_MENU_PREFIX="unexicon-"
START_DATE=`date`
START_FROM=`pwd`

ARCHIVOS

icewm-session(1) busca el archivo env en las siguientes ubicaciones:

$ICEWM_PRIVCFG/env
$XDG_CONFIG_HOME/icewm/env
$HOME/.icewm/env
/usr/etc/icewm/env
/usr/share/icewm/env

Las ubicaciones se buscan en el orden indicado; se lee el primer archivo encontrado y el resto se ignora.

VER TAMBIÉN

icewm(1), icewm-session(1), icewm-startup(5).
