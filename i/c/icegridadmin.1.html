icegridadmin(1) Manual de comandos generales icegridadmin(1)

NOMBRE

icegridadmin - La utilidad administrativa de línea de comandos de IceGrid.

SINOPSIS

icegridadmin [opciones]

DESCRIPCIÓN

La utilidad icegridadmin es una herramienta de línea de comandos para administrar un dominio IceGrid. La implementación de una aplicación con esta utilidad requiere un archivo XML que defina los descriptores. La documentación completa de icegridadmin está disponible en línea en:
https://doc.zeroc.com/ice/3.7/ice-services/icegrid/icegridadmin-command-line-tool

OPCIONES

-h, --help

Muestra la ayuda del programa.
-v, --version

Muestra la versión de Ice.
-e COMANDOS

Ejecuta COMANDOS.
-d, --debug

Imprime mensajes de depuración.
-s, --server

Inicia icegridadmin como servidor (para analizar archivos XML).
-i, --instanceName

Conéctate al registro con el nombre de instancia dado.
-H, --host

Conéctate al registro en el host dado.
-P, --port

Conéctate al registro que se ejecuta en el puerto dado.
-u, --username

Inicia sesión con el nombre de usuario dado.
-p, --password

Inicia sesión con la contraseña dada.
-S, --ssl

Autentícate a través de SSL.
-r, --replica NAME

Conéctate a la réplica NAME.

VER TAMBIÉN

icegriddb(1), icegridnode(1), icegridregistry(1)
