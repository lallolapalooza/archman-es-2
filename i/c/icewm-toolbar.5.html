NOMBRE

icewm-toolbar - archivo de configuración de la barra de herramientas de icewm

SINOPSIS

$ICEWM_PRIVCFG/toolbar
$XDG_CONFIG_HOME/icewm/toolbar
$HOME/.icewm/toolbar
/usr/etc/icewm/toolbar
/usr/share/icewm/toolbar

DESCRIPCIÓN

El archivo toolbar es responsable de configurar los iconos de aplicaciones de inicio rápido que se colocan en el panel de icewm(1). Contiene nombres de aplicaciones de inicio rápido con iconos para la barra de tareas. Cada línea no vacía y que no sea un comentario comienza con la palabra clave prog. Después de uno o más espacios, sigue un nombre, que se muestra en una información sobre herramientas (tooltip) cada vez que el cursor del ratón se detiene sobre el icono de la barra de herramientas. Este nombre puede ser una cadena entre comillas dobles. Luego sigue el nombre del icono a utilizar sin extensiones. Este icono se mostrará en la barra de herramientas. El último componente es una línea de comando de shell que se ejecutará cada vez que el usuario presione el icono en la barra de herramientas. Por ejemplo, la siguiente línea en toolbar creará un botón con la información sobre herramientas "Mozilla Firefox" con el icono firefox que inicia firefox(1) al hacer clic:

prog  "Mozilla Firefox"  firefox  /usr/bin/firefox --private-window

FORMATO

El formato del archivo contiene una de las siguientes sintaxis de línea:

prog "título" icono programa opciones

Donde,

prog
La cadena literal prog.
"título"
El título del elemento de la barra de herramientas, que aparecerá como información sobre herramientas para el botón del programa, encerrado entre comillas dobles (""").
icono
El icono a mostrar en el botón de la barra de herramientas. Puede especificarse como un solo guion ("-") cuando no se proporciona ningún icono. Cuando no se proporciona ningún icono, el texto título se mostrará en el botón en lugar del icono.
programa
El programa ejecutable (ruta completa o nombre ejecutable) a ejecutar cuando se presione el botón.
opciones
Opciones y argumentos que se pasan a programa.

Las líneas que comienzan con una almohadilla ("#") son líneas de comentario. Las líneas de comentario y las líneas en blanco se ignoran.

Tenga en cuenta que todas las palabras clave de icewm-menu(5) también están permitidas aquí.

EJEMPLOS

A continuación se muestra un ejemplo que coloca varios botones de barra de herramientas en el panel de icewm(1):

prog "Administrador de Archivos" file-manager.png pcmanfm
prog "Navegador Web" web-browser.png /usr/lib/firefox/firefox
prog "Terminal" terminal.png roxterm
prog "Editor Gráfico" text-editor.png gvim -f
prog "Calculadora" accessories-calculator.png calculator
prog "Ejecutar Comando" gtk-execute.png xde-run
prog "Red" gtk-network.png pcmanfm ~/Network
prog "Cerrar Sesión" system-log-out.png xde-logout

ARCHIVOS

Las ubicaciones para el archivo toolbar son las siguientes:

$ICEWM_PRIVCFG/toolbar
$XDG_CONFIG_HOME/icewm/toolbar
$HOME/.icewm/toolbar
/usr/etc/icewm/toolbar
/usr/share/icewm/toolbar

Las ubicaciones se buscan en el orden indicado; el primer archivo encontrado se lee y el resto se ignora.
