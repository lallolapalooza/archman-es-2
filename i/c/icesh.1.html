DESCRIPCIÓ

N

icesh proporciona dos tipos de

comandos:
1. Comandos para interactuar directamente con
icewm:
Estos se enumeran en la sección "ACCIONES DEL GESTOR" más abajo. Son fáciles de usar, porque no requieren seleccionar una o más ventanas. Por ejemplo, "icesh restart" reiniciará icewm y "icesh clients" lista las aplicaciones gestionadas por
icewm.
2. Comandos que operan sobre una selección de
ventanas:
Véase la sección "ACCIONES DE VENTANA" más abajo. Por ejemplo, "icesh close" es una solicitud para cerrar una ventana, ¿pero cuál? Ahora icesh convertirá el puntero del ratón en una cruz. Haga clic en una ventana y se enviará una solicitud de cierre a esa aplicación.

El poder de icesh radica en su capacidad para seleccionar programáticamente una o más ventanas y operar sobre esa selección. Esto puede usarse en scripts y en icewm-keys(5) para definir sus propias teclas rápidas de gestión de ventanas. Por ejemplo, para cerrar inmediatamente todas las ventanas xterm haga "icesh -c xterm

close".

Hay una docena de "OPCIONES DE SELECCIÓN" para seleccionar ventanas. Comienzan con un '-' o un '+'. El '-' inicia una nueva selección, mientras que el '+' añade más ventanas a una selección

existente.

Esta selección de ventanas puede reducirse mediante "OPCIONES DE FILTRADO". Estas eliminan las ventanas no deseadas de la selección actual. Se pueden dar múltiples opciones de filtrado. Por ejemplo, "icesh -c xterm -W this close" cerrará solo aquellos xterm que se muestran en el espacio de trabajo actual. Los xterm de otros espacios de trabajo se filtran mediante la opción de f

iltro
"-W t
his".

No hay límite al número de comandos, selecciones, filtros y acciones que puede dar a un único comando ice

sh. Se procesan y evalúan uno por uno de izquierda a derecha. Esto convierte a icesh en un pequeño le
nguaje de programación declarativo. Eche un vistazo a algunos ejemplos cerca del final de este documento.

CONDICIONALES

Icesh soporta expresiones "if-then-else". La sintaxis completa es:

if selection
then
    actions
elif selection
then
    actions
else
    actions
end

Donde "selection" es una secuencia de opciones de selección y filtrado, que se evalúa como true cuando no está vacía. Es decir, si una o más ventanas cumplieron la condición. Si está vacía, la cláusula "actions" se ignora y se intenta o se toma la cláusula "elif" o "else" subsiguiente. Cada cláusula es opcional.

Siempre que una condición de selección se evalúa como false, la selección de ventanas que existía antes de la cláusula "if" se restaura inmediatamente. Esto también ocurre después de una cláusula "end".

EXPRESIONES

Algunas de las acciones de ventana requieren uno o dos argumentos EXPRESSION.

EXPRESSION ::= SYMBOL | EXPRESSION { "+" | "|" | "-" } SYMBOL

Esto indica que una expresión es un SYMBOL o una expresión que se combina con un operador con un SYMBOL. En otras palabras, una expresión es una secuencia de símbolos, que se combinan usando operadores, donde un operador puede ser un signo más, una barra vertical o un signo menos.

Cada SYMBOL puede ser un número o un símbolo nombrado de uno de los siguientes dominios aplicables, dependiendo del contexto en el que se utilice:
