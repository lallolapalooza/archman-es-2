ICMD(1) Manual de comandos generales ICMD(1)

NOMBRE

imv, icp - Renombrar o copiar un archivo editando el nombre de destino utilizando GNU readline.

SINOPSIS

imv [OPCIÓN] ARCHIVO...

icp [OPCIÓN] ARCHIVO...

DESCRIPCIÓN

Esta página del manual describe los comandos icmd, imv y icp.

imv es un programa para renombrar interactivamente un solo archivo. Lo hace permitiendo editar el nombre del archivo en línea con GNU readline. Esto es muy similar a usar mv(1) y editar el nombre del archivo en la línea de comandos del shell, con una excepción: el nombre del archivo no tiene que escribirse dos veces.

El programa imv normalmente ejecuta mv(1) para realizar el renombramiento real. Sin embargo, esto se puede cambiar con la opción --command.

icp es idéntico a imv excepto que un archivo se copia con cp(1) en su lugar. Ambos comandos son enlaces simbólicos al comando icmd.

OPCIONES

Estos programas siguen la sintaxis habitual de línea de comandos de GNU, con opciones largas que comienzan con dos guiones (`-').

Todas las opciones, excepto las que se enumeran a continuación, se pasan a mv, cp o al comando especificado con --command.

--command=ARCHIVO
Especifica el comando a ejecutar en lugar de los predeterminados `mv' o `cp'. No es necesario especificar el nombre del directorio de ARCHIVO si ARCHIVO se encuentra en la ruta actual (según lo establecido por la variable de entorno $PATH).

Se asume que el comando especificado acepta el mismo conjunto de opciones cortas y largas que requieren un argumento que mv o cp. Si no es así, debe especificar esas opciones con --arg-options (ver más abajo). Tenga en cuenta también que --arg-options no es necesario siempre que especifique la opción y el valor de la opción en una sola palabra, como `--suffix=bak' en lugar de `--suffix bak' al pasar opciones adicionales a mv a través de imv.

--arg-options=OPCIÓN[,OPCIÓN...]
Especifica qué opciones separadas por comas para mv, cp o el comando especificado con --command requieren un argumento. Las opciones pueden ser cortas (por ejemplo, -S) así como largas (por ejemplo, --suffix). La lista predeterminada para mv es `t,S,reply,suffix,target-directory', y la lista para cp es `t,S,Z,no-preserve,sparse,suffix,context,target-directory'. (Estas listas son completas y correctas para GNU Coreutils 5.97.)

Esta lista es necesaria porque icmd necesita saber qué argumentos especificados en la línea de comandos son archivos para mover/copiar, o valores de opción (siguiendo una opción).

--pass-through
Ejecuta mv/cp (o el comando especificado con --command) si se especifican dos o más argumentos. De esta manera, imv/icp se puede usar como un alias para mv/cp (ver más abajo).
--help
Muestra un resumen de las opciones.
--version
Muestra información de la versión y sale.

EJEMPLOS

Usar imv como un alias de Bash para mv:
alias mv=imv --pass-through -i
