DESCRIPCIÓ

N

icewmbg puede asignar un color o una imagen al fondo de escritorio de X11. Se admiten formatos de imagen comunes. Cada espacio de trabajo de icewm(1) puede tener su propio

fondo.

Cuando la imagen de fondo cambia, se puede notificar a icewmbg para que actualice el fondo. Al cambiar de espacio de trabajo, comprueba la hora de modificación del archivo de imagen. Si ha cambiado, recarga la

imagen.

icewmbg admite la semitransparencia. Se pueden configurar imágenes de fondo y colores semitransparentes

.

Utiliza RandR o Xinerama para admitir fondos en todos los monitores conectados. Cuando los monitores aparecen/desaparecen o cambian su resolución, icewmbg se ajustará. Admite una opción para un gran fondo que abarque todos los

monitores.

Actualizará la propiedad "_ICEWMBG_IMAGE" de la ventana raíz con la ruta de la imagen de fondo cada vez que cambie el fondo del

escritorio.

icewmbg se inicia automáticamente mediante icewm-session(1). Si solo hay un fondo para todos los espacios de trabajo, icewmbg puede concluir que puede salir de forma segura después de establecer el fondo del esc

ritorio, para liberar su memoria del sistema. Si el tamaño de la pantalla cambia, ic
ewm intentará entonces reiniciar icewmbg, preferiblemente a través de icewm-session.

ESPECÍFICAS

Cuando se pueden dar varios valores para imágenes o colores, se separan con comas. Cada uno de estos valores puede ir entre comillas dobles. Si FILE es un directorio, se utilizan todas las imágenes de ese directorio en orden alfabético. Si el valor comienza con un signo de exclamación, como en !FILE, las imágenes del directorio FILE se permutan aleatoriamente. Los nombres de archivo de imagen o de directorio pueden tener comodines de glob(7), o pueden comenzar con un tilde o una variable de

entorno.

PREFERENCIA

S

Por defecto icewmbg carga la configuración desde el archivo de preferencias de icewm(1). Consulte icewm-preferences(5) para más detalles. La configuración leída

es: 
DesktopBackgroundCenter    - Mostrar el fondo de escritorio centrado
DesktopBackgroundScaled    - Mostrar el fondo de escritorio escalado
DesktopBackgroundColor     - Color(es) del fondo de escritorio
DesktopBackgroundImage     - Imagen(es) del fondo de escritorio
ShuffleBackgroundImages    - Barajar la lista de imágenes de fondo
SupportSemitransparency    - Soporte para terminales semitransparentes
DesktopTransparencyColor   - Color(es) de fondo semitransparente
DesktopTransparencyImage   - Imagen(es) de fondo semitransparente
DesktopBackgroundMultihead - Un fondo para todos los monitores
CycleBackgroundsPeriod     - Segundos entre ciclos de
fondos

Si estos ajustes están establecidos en el archivo de preferencias, pueden ser anulados por el tema en el archivo de valores predeterminados del tema. Para forzar un ajuste concreto, establezca en su lugar en el archivo prefoverride. Consulte icewm-prefo

verri
de(5).

Cada espacio de trabajo puede tener una imagen única. Especifique varias imágenes en DesktopBackgroundImage separadas por comas. Ove al menos un directorio con imágenes. Las imágenes se asignan a cada espacio de trabajo en el orden dado. Cuando IceWM cambia de espacio de trabajo, el icewmbg en ejecución adaptará el fondo de
