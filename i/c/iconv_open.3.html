iconv_open(3) Manual de funciones de biblioteca iconv_open(3)

NOMBRE

iconv_open - asignar descriptor para la conversión de conjuntos de caracteres

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <iconv.h>
iconv_t iconv_open(const char *tocode, const char *fromcode);

DESCRIPCIÓN

La función iconv_open() asigna un descriptor de conversión adecuado para convertir secuencias de bytes de la codificación de caracteres fromcode a la codificación de caracteres tocode.

Los valores permitidos para fromcode y tocode, así como las combinaciones soportadas, dependen del sistema. Para la biblioteca GNU C, los valores permitidos se enumeran con el comando iconv --list, y se soportan todas las combinaciones de los valores listados. Además, la biblioteca GNU C y la biblioteca GNU libiconv soportan los siguientes dos sufijos:

//TRANSLIT
Cuando la cadena "//TRANSLIT" se añade a tocode, se activa la transliteración. Esto significa que cuando un carácter no se puede representar en el conjunto de caracteres de destino, se puede aproximar mediante uno o varios caracteres de apariencia similar.
//IGNORE
Cuando la cadena "//IGNORE" se añade a tocode, los caracteres que no se pueden representar en el conjunto de caracteres de destino se descartan silenciosamente.

El descriptor de conversión resultante se puede utilizar con iconv(3) tantas veces como sea necesario. Sigue siendo válido hasta que se libere usando iconv_close(3).

Un descriptor de conversión contiene un estado de conversión. Después de su creación con iconv_open(), el estado está en el estado inicial. Usar iconv(3) modifica el estado de conversión del descriptor. Para devolver el estado al estado inicial, use iconv(3) con NULL como argumento inbuf.

VALOR DE RETORNO

En caso de éxito, iconv_open() devuelve un descriptor de conversión recién asignado. En caso de fallo, devuelve (iconv_t) -1 y establece errno para indicar el error.

ERRORES

Los siguientes errores pueden ocurrir, entre otros:

EINVAL
La conversión de fromcode a tocode no está soportada por la implementación.
