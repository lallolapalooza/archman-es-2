ICEHELP(1) Comandos de usuario ICEHELP(1)

NOMBRE

icehelp - un navegador HTML muy simple

SINOPSIS

icehelp [OPCIONES] ARCHIVO

DESCRIPCIÓN

icehelp es un navegador HTML muy simple, que es utilizado por icewm(1) para mostrar el Manual de IceWM y las páginas del manual.

El documento se puede navegar con las teclas de cursor, las teclas de navegación y una barra de desplazamiento. Para encontrar texto, presione "Ctrl+F" para una ventana de búsqueda. Presione la tecla de función "F3" para repetir una búsqueda.

La esquina superior derecha muestra un botón que abre un menú. Este menú también se puede abrir haciendo clic con el botón derecho del ratón.

ARGUMENTOS

ARCHIVO
Especifica el archivo a navegar. También puede ser la URL de un sitio web.

OPCIONES

OPCIONES ESPECÍFICAS

-B
Muestra la página del manual de icewmbg de IceWM.
-b, --bugs
Muestra los informes de errores de IceWM (de forma primitiva).
-f, --faq
Muestra el FAQ y el Howto de IceWM.
-g
Muestra el sitio web de Github de IceWM.
-i, --icewm
Muestra la página del manual de icewm de IceWM.
-m, --manual
Muestra el Manual de IceWM (por defecto).
-s
Muestra la página del manual de icesound de IceWM.
-t, --theme
Muestra el Howto de temas de IceWM.
-w, --website
Muestra el sitio web de IceWM.

OPCIONES GENERALES

-d, --display=PANTALLA
Usa PANTALLA para conectarte al servidor X. Si esta opción falta entonces PANTALLA se lee de la variable de entorno "DISPLAY".
--sync
Usa un modo de comunicación síncrono más lento con el servidor X11.
-h, --help
Imprime una breve declaración de uso en stdout y sale.
-V, --version
Imprime la versión del programa en stdout y sale.
-C, --copying
Imprime los permisos de copia en stdout para el programa y sale.

ERRORES

Por favor, reporta errores en https://github.com/bbidulock/icewm/issues.
