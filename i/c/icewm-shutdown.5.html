ICEWM-SHUTDOWN(5) Estándares, Entornos y Macros ICEWM-SHUTDOWN(5)

NOMBRE

icewm-shutdown - archivo de configuración de apagado de icewm

SINOPSIS

$ICEWM_PRIVCFG/shutdown
$XDG_CONFIG_HOME/icewm/shutdown
$HOME/.icewm/shutdown
/usr/etc/icewm/shutdown
/usr/share/icewm/shutdown

DESCRIPCIÓN

Contiene comandos que se ejecutarán al apagar icewm. Este es un script ejecutable con comandos que se ejecutarán en la última etapa de terminación de icewm. Típicamente pueden deshacer algunos de los efectos del script de startup. Es ejecutado por icewm-session(1) cuando icewm termina.

ARCHIVOS

Las ubicaciones para el archivo shutdown son las siguientes:

$ICEWM_PRIVCFG/shutdown
$XDG_CONFIG_HOME/icewm/shutdown
$HOME/.icewm/shutdown
/usr/etc/icewm/shutdown
/usr/share/icewm/shutdown

Las ubicaciones se buscan en el orden listado; el primer archivo encontrado se lee y el resto se ignora.

VER TAMBIÉN

icewm-session(1), icewm-startup(5).
