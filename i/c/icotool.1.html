DESCRIPCIÓ

N

Esta página de manual describe el comando

icotool.

El programa icotool convierte y crea archivos de iconos (.ico) y cursores (.cur). En este momento, los iconos solo pueden crearse desde archivos PNG y extraerse en archivos PNG. Esto se hace usando

libpng.

Los archivos de iconos y cursores se utilizan principalmente en la plataforma Microsoft Windows(R). Cada archivo de iconos o cursores puede contener múltiples imágenes de varias resoluciones y con diferente número de colores. Los archivos de cursores se diferencian de los archivos de iconos en que también contienen información sobre el punto de referencia (hotspot) de cada

imagen.

Las versiones recientes de Microsoft Internet Explorer utilizan iconos para pequeños logotipos de sitios. El navegador busca un archivo llamado favicon.ico de un sitio web y utiliza las imágenes de este archivo para representar el sitio en menús y listas de sitios. (Este archivo se coloca en el directorio raíz del sitio web, como cualquier otro archivo.) Navegadores como Galeon han copiado este comportamiento y ahora también buscan archivos .ico y los utilizan para logotipos de

sitios.

Dado que cada archivo de icono o cursor puede contener múltiples imágenes de diferentes dimension

es y profundidad, una conversión puede resultar en la creación de múltiples archivos PNG. Corres
pondientemente, se pueden especificar múltiples archivos PNG al crear un archivo de icono/cursor.

OPCIONE

S

Estos programas siguen la sintaxis habitual de la línea de comandos de GNU, con opciones largas que comienzan con dos guiones (`-')

.
-x,
--extract
Esta opción le indica a icotool que se deben extraer las imágenes de todos los archivos de icono/cursor dados en la línea de comandos. Se pueden usar opciones de filtro (ver más abajo) para controlar qué imágenes se
extraerán.
-l,
--list
Esta opción le indica a icotool que se deben listar las imágenes en todos los archivos de icono/cursor dados. La salida se verá algo así:


--icon --index=1 --width=16 --height=16 --bit-depth=4 --palette-size=16
--icon --index=2 --width=32 --height=32 --bit-depth=8

--palette-size=
256
-c,
--create
Esta opción le indica a icotool que cree un archivo de icono/cursor usando todos los archivos PNG dados en la línea de comandos, en el orden en que fueron especificados. El número de bits por píxel usado en el archivo de icono/cursor dependerá del número de colores usados en el archivo PNG. (Si la imagen PNG tiene una paleta indexada, no significa necesariamente que se usará la misma paleta en el archivo de icono/cursor creado.
)
-i, --index=
N
Al listar o extraer archivos, esta opción le indica a icotool que liste o extraiga solo la N-ésima imagen en cada archivo. La primera imagen tiene el índice 1.

Esta opción no ti

ene efecto en el
modo de creación.
-w, --width=PÍXEL
ES
Similar a --index, pero esta opción permite que se haga coincidir el ancho de la imagen. Esta opción no tiene efecto en el modo de
creación.
-h, --height=PÍXEL
ES
Similar a --index, pero esta opción permite que se haga coincidir la altura de la imagen. Esta opción no tiene efecto en el modo de
creación.
-b, --bit-depth=CUEN
TA
Similar a --index, pero esta opción permite que se haga coincidir el número de bits por píxel en la imagen. Los valores válidos son 1, 2, 4, 8, 16, 24 y 32.

En el modo de creación, esta opción le permitirá especificar una profundidad de bits mínima para las imágenes en el archivo de icono. Si

proporciona la opción una vez, se aplicará a todos los archivos de entrada. Si la especifica múltiples veces, se aplicará a todos los
archivos de entrada que sigan a una opción particular; en ese caso, debería especificar una profundidad de bits para todas las imágenes.
-p, --palette-size=PÍXEL
ES
Similar a --index, pero esta opción permite que se haga coincidir el número de colores en la paleta de la imagen. Las imágenes con 24 o 32 bits en archivos de icono/cursor no tienen una paleta y, por lo tanto, tendrán un tamaño de paleta igual a 0.

Esta opción no ti

ene efecto en el
modo de creación.
-X, --hotspot-x=COO
RD
Similar a --index, pero esta opción permite que se haga coincidir la coordenada x del punto de referencia (hotspot). Esta opción solo tiene efecto en archivos de cursores.

En el modo de creación, esto puede usarse para especificar la coordenada x del punto de referencia. Si proporciona la opción una

vez, se aplicará a todos los archivos de entrada. Si la especifica múltiples veces, se aplicará a todos los archivos de entrada q
ue sigan a una opción particular; en ese caso, debería especificar una coordenada de punto de referencia para todas las imágenes.
-Y, --hotspot-y=COO
RD
Similar a --index, pero esta opción permite que se haga coincidir la coordenada y del punto de referencia (hotspot). Esta opción solo tiene efecto en archivos de cursores.

En el modo de creación, esto puede usarse para especificar la coordenada y del punto de referencia. Si proporciona la opción una

vez, se aplicará a todos los archivos de entrada. Si la especifica múltiples veces, se aplicará a todos los archivos de entrada q
ue sigan a una opción particular; en ese caso, debería especificar una coordenada de punto de referencia para todas las imágenes.
--ic
on
Esta opción especifica que solo se deben listar o extraer archivos de iconos. En el modo de creación, esta opción puede usarse para especificar que se debe crear un icono (en lugar de un cursor). (Esto es lo predeterminado en el modo de creación.
)
--curs
or
Esta opción especifica que solo se deben listar o extraer archivos de cursores. En el modo de creación, esto puede usarse para especificar que se debe crear un cursor (en lugar de un icono)
.
-t, --alpha-threshold=NIV
EL
Especifica el nivel alfa máximo en la imagen PNG para las porciones que deberían volverse transparentes en el icono creado. El valor predeterminado es 127. Esto solo se usa al crear archivos de
iconos.
-o, --output=RU
TA
En el modo de extracción, esta opción especifica un directorio donde se deben crear los archivos extraídos. Si RUTA no existe, se asume que se refiere a un archivo inexistente. La primera imagen que coincida se extraerá al archivo con ese nombre.

En el modo de creación, esta opción especifica el nombre del archivo de salida. Lo predeterminado es escribir los datos binarios a la salida estándar (lo cual icotool rechazará si la salida estándar es la terminal)

.

Si RUTA es `-', entonces toda la salida se imprimirá a la salida

estándar.

Esta opción no ti

ene efecto en el
modo de listado.

--raw=ARCHIVO

EJEMPLO

S

Listar todas las imágenes en el archivo `demo.ico':
$ icotool -l demo.ico
--icon --index=1 --width=16 --height=16 --bit-depth=4 --palette-size=16
--icon --index=2 --width=32 --height=32 --bit-depth=4 --palette-size=16
--icon --index=3 --width=48 --height=48 --bit-depth=4 --palette-size=16
--icon --index=4 --width=16 --height=16 --bit-depth=8 --palette-size=256
--icon --index=5 --width=32 --height=32 --bit-depth=8 --palette-size=256
--icon --index=6 --width=48 --height=48 --bit-depth=8 --palette-size=25

6

Listar solo las imágenes de 16 colores en `demo.ico':
$ icotool -l --palette-size=16 demo.ico
--icon --index=1 --width=16 --height=16 --bit-depth=4 --palette-size=16
--icon --index=2 --width=32 --height=32 --bit-depth=4 --palette-size=16
--icon --index=3 --width=48 --height=48 --bit-depth=4 --palette-size=1

6

Extraer todas las imágenes al directorio actual, nombrando los archivos de destino `demo.ico_I_WxHxD.xpm':
$ icotool -x -o . demo.ico
$ ls *.png
demo_1_16x16x4.png demo_3_48x48x4.png demo_5_32x32x8.png
demo_2_32x32x4.png demo_4_16x16x8.png demo_6_48x48x8.

png

Extraer todos los iconos de 256 coloresen imágenes en todos los archivos .ico en el directorio actual, colocando las imágenes extraídas en `img/'
$ icotool -x -o img/ -p 256 *.

ico

Crear un icono llamado `favicon.ico' con dos imágenes:
$ icotool -c -o favico
