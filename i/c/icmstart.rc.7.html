icmstart.rc(7) Archivo de recursos de icmstart icmstart.rc(7)

NOMBRE

icmstart.rc - El archivo de recursos de icmstart(1)

DESCRIPCIÓN

El archivo icmstart.rc especifica los archivos que serán instalados por icmstart(1).

Se encuentra un icmstart.rc predeterminado en /etc/icmake/icmstart.rc, pero si existe $HOME/.icmake/icmstart.rc entonces este último archivo es utilizado por icmstart(1). $HOME/.icmake/icmstart.rc a su vez es anulado al especificar una opción -c al invocar icmstart(1).

El archivo de recursos predeterminado contiene las siguientes especificaciones, preparando para la construcción de un programa C++ usando icmbuild(1):

    CLASSES
    icmconf
    P  main.cc 
    P  main.ih 
    Pb usage.cc
    Pb version.cc
    P ? scanner 
    P ? parser
El archivo icmstart.rc puede contener:
o
líneas vacías, que se ignoran;
o
líneas que comienzan con un carácter de almohadilla (#), también ignoradas;
o
un modo de instalación opcional seguido de una especificación de origen-destino.

MODO DE INSTALACIÓN

Un modo de instalación consiste en una combinación de:

o
ya sea una P (no instalar con icmstart xxx library) o una L (no instalar con icmstart xxx program);
o
una D, indicando que el origen también debe instalarse por defecto, es decir, si no se especificó `program’ o `library’ como segundo argumento;
o
una b, indicando que el archivo no debe ser instalado si se especificó la opción -b (instalación básica) al llamar a icmstart;
o
Siguiendo el carácter opcional P, L, D, o b, un signo de interrogación opcional (?) delimitado por espacios. Si se especifica, la instalación del archivo o directorio debe ser confirmada por el usuario.

ESPECIFICACIONES DE ORIGEN-DESTINO

Las siguientes especificaciones de origen-destino se pueden usar en un archivo icmstart.rc (usando esqueletos abajo para referirse al directorio de archivos de esqueleto de icmstart):

o
origen
un archivo llamado origen debe existir en esqueletos. Se instala en el directorio de destino `destino’ que se especifica al llamar a icmstart(1). Ejemplo: 
    CLASSES
esqueletos/CLASSES se instala como destino/CLASSES;
o
espec_ruta
si `espec_ruta’ no comienza con una barra, debe existir en esqueletos. Se instala como `espec_ruta’ en el directorio de destino especificado al llamar a icmstart(1). Ejemplo: 
    dir/archivo
esqueletos/archivo se instala como destino/dir/archivo;
o
/espec_ruta o ~/espec_ruta
el carácter ~ se expande al directorio de inicio del usuario. El último elemento de `espec_ruta’ se instala en el directorio de destino especificado al llamar a icmstart(1). Ejemplo: 
    ~/.icmake/archivo
$HOME/.icmake/archivo se instala como destino/archivo

Cuando las especificaciones de origen anteriores van seguidas de una especificación de destino espec_destino (una especificación de archivo o directorio no absoluto) entonces la especificación de origen se instala como destino/espec_destino debajo del directorio de destino especificado al llamar a icmstart(1). Ejemplos:

    CLASSES CLASSES             # esqueletos/CLASSES se instala como 
                                #   destino/CLASSES
    dir/archivo dir/archivo     # esqueletos/dir/archivo se instala como
                                #   destino/dir/archivo
    ~/.icmake/archivo .icmake/archivo # $HOME/.icmake/archivo se instala como 
                                #   destino/.icmake/archivo
Icmstart convierte las especificaciones de destino a rutas absolutas. Si estas rutas absolutas no comienzan con la ruta absoluta de destino, entonces se muestra un mensaje de error y icmstart finaliza.

ARCHIVOS

Las rutas mencionadas son solo sugerentes y pueden depender de la instalación:

o
/usr/share/icmake/icmconf: ejemplo de un archivo de configuración de icmbuild;
o
/usr/share/icmake/CLASSES: ejemplo de un archivo CLASSES de icmbuild;
o
/usr/share/icmake/icmstart.rc: archivo de recursos de esqueleto predeterminado.
