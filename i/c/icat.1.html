ICAT(1) Manual de comandos generales ICAT(1)

NOMBRE

icat - Muestra el contenido de un archivo basándose en su número de inodo.

SINOPSIS

icat [-hrsvV] [-f tipo_fs ] [-i tipo_img ] [-o offset_img ] [-b tamaño_sector_dev] imagen [imágenes] inodo

DESCRIPCIÓN

icat abre la imagen o imágenes especificadas y copia el archivo con el número de inodo especificado a la salida estándar.

ARGUMENTOS

-f tipo_fs
Especifica el tipo de sistema de archivos. Usa '-f list' para listar los tipos de sistemas de archivos compatibles. Si no se especifica, se utilizan métodos de autodetección.
-h
Omite los huecos en archivos dispersos, de modo que la información de dirección absoluta se pierde. Esta opción ahorra espacio al copiar archivos dispersos.
-r
Utiliza técnicas de recuperación de archivos si el archivo está eliminado.
-s
Incluye el espacio sobrante (slack space) en la salida.
-i tipo_img
Identifica el tipo de archivo de imagen, como raw. Usa '-i list' para listar los tipos compatibles. Si no se especifica, se utilizan métodos de autodetección.
-o offset_img
El desplazamiento del sector donde comienza el sistema de archivos en la imagen.
-b tamaño_sector_dev
El tamaño, en bytes, de los sectores del dispositivo subyacente. Si no se especifica, se utiliza el valor del formato de imagen (si existe) o se asume 512 bytes.
-v
Habilita el modo detallado, la salida se dirige a stderr.
-V
Muestra la versión.
imagen [imágenes]
La imagen de disco o partición de la que leer, cuyo formato se especifica con '-i'. Se pueden dar varios nombres de archivo de imagen si la imagen está dividida en varios segmentos. Si solo se da un archivo de imagen y su nombre es el primero de una secuencia (por ejemplo, si termina en '.001'), los segmentos de imagen posteriores se incluirán automáticamente.
inodo
Número de inodo. icat concatena el contenido de todos los archivos especificados.
