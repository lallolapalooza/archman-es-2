PROLOG

Esta página del manual forma parte del Manual de Programador POSIX. La implementación de Linux de esta interfaz puede diferir (consulte la página del manual de Linux correspondiente para conocer los detalles del comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

iconv.h — instalación de conversión de conjuntos de códigos

SINOPSIS

#include <iconv.h>

DESCRIPCIÓN

El archivo de cabecera <iconv.h> definirá los siguientes tipos:

iconv_t
Identifica la conversión de un conjunto de códigos a otro.
size_t
Como se describe en <sys/types.h>.

Las siguientes se declararán como funciones y también podrán definirse como macros. Se proporcionarán prototipos de funciones.

size_t  iconv(iconv_t, char **restrict, size_t *restrict,
            char **restrict, size_t *restrict);
int     iconv_close(iconv_t);
iconv_t iconv_open(const char *, const char *);
