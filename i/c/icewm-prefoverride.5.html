ICEWM-PREFOVERRIDE(5) Estándares, Entornos y Macros ICEWM-PREFOVERRIDE(5)

NOMBRE

icewm-prefoverride - Archivo de preferencias para anular tema

SINOPSIS

$ICEWM_PRIVCFG/prefoverride
$XDG_CONFIG_HOME/icewm/prefoverride
$HOME/.icewm/prefoverride
/usr/etc/icewm/prefoverride
/usr/share/icewm/prefoverride

DESCRIPCIÓN

Configuraciones que anulan la configuración de un tema. Algunas de las preferencias de icewm que controlan la apariencia pueden ser establecidas por el tema. Sin embargo, las configuraciones en este archivo prefoverride las anulan. Es seguro dejar este archivo vacío inicialmente. Tenga en cuenta que este archivo está destinado a preferencias personalizables y algunas configuraciones de inicio de icewm no se pueden establecer aquí, como "Splash".

ARCHIVOS

Las ubicaciones para el archivo prefoverride son las siguientes:

$ICEWM_PRIVCFG/prefoverride
$XDG_CONFIG_HOME/icewm/prefoverride
$HOME/.icewm/prefoverride
/usr/etc/icewm/prefoverride
/usr/share/icewm/prefoverride

Las ubicaciones se buscan en el orden indicado; se lee el primer archivo encontrado y se ignoran los demás.

VER TAMBIÉN

icewm(1), icewm-preferences(5).
