NOMBRE

icegridregistry - El servidor de registro de IceGrid.

SINOPSIS

icegridregistry [opciones] [comando...]

DESCRIPCIÓN

El registro de IceGrid es un repositorio centralizado de información, incluyendo aplicaciones desplegadas y objetos conocidos. Un registro puede estar opcionalmente colocalizado con un nodo de IceGrid, lo que conserva recursos y puede ser conveniente durante el desarrollo y las pruebas. El servidor de registro es implementado por el ejecutable icegridregistry. La documentación completa para icegridregistry está disponible en línea en:
https://doc.zeroc.com/ice/3.7/ice-services/icegrid/icegrid-server-reference/icegridregistry

OPCIONES

-h, --help

Muestra un mensaje de ayuda.
-v, --version
Muestra la versión de Ice.
--daemon

Ejecutar como un demonio.
--pidfile FILE

Escribe el ID del proceso en FILE.
--noclose

No cerrar los descriptores de archivo abiertos.
--nochdir

No cambiar el directorio de trabajo actual.
--nowarn

No imprimir advertencias de seguridad.
--readonly

Iniciar el registro maestro en modo de solo lectura.

TP --initdb-from-replica REPLICA
Inicializar la base de datos del registro desde la réplica dada.
