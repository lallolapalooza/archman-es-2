entero función icmax1 (entero n, complejo, dimensión(*) cx, entero incx)

ICMAX1 encuentra el índice del primer elemento del vector de valor absoluto máximo.

Propósito:

!>
!> ICMAX1 encuentra el índice del primer elemento del vector de valor absoluto máximo.
!>
!> Basado en ICAMAX de Level 1 BLAS.
!> El cambio es usar el valor absoluto 'genuino'.
!>

Parámetros

N 
!>          N es ENTERO
!>          El número de elementos en el vector CX.
!>

CX

!>          CX es un array COMPLEJO, dimensión (N)
!>          El vector CX. La función ICMAX1 devuelve el índice de su primer
!>          elemento de valor absoluto máximo.
!>

INCX

!>          INCX es ENTERO
!>          El espaciado entre valores sucesivos de CX. INCX >= 1.
!>
