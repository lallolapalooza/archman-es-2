icepatch2calc(1) Manual de Comandos Generales icepatch2calc(1)

NOMBRE

icepatch2calc - Herramienta IcePatch2 para comprimir archivos y calcular sumas de verificación.

SINOPSIS

icepatch2calc [opciones] directorio_datos [archivo...]

DESCRIPCIÓN

Herramienta IcePatch2 para comprimir archivos y calcular sumas de verificación. La documentación completa para icepatch2calc está disponible en línea en:
https://doc.zeroc.com/ice/3.7/ice-services/icepatch2/using-icepatch2calc

OPCIONES

-h, --help

Muestra un mensaje de ayuda.
-v, --version
Muestra la versión de Ice.
-z, --compress

Normalmente, icepatch2calc escanea el directorio de datos y comprime un archivo solo si no existe una versión comprimida, o si la versión comprimida de un archivo tiene una fecha de modificación anterior a la de la versión sin comprimir. Si especifica -z, la herramienta vuelve a escanear y a comprimir todo el directorio de datos, independientemente de las marcas de tiempo de los archivos. Esta opción es útil si sospecha que las marcas de tiempo en el directorio de datos pueden ser incorrectas.
-Z, --no-compress

Esta opción le permite crear un archivo de suma de verificación del lado del cliente. No utilice esta opción al crear el archivo de suma de verificación para el servidor; la opción es para crear un archivo IcePatch2.sum del lado del cliente para actualizaciones de software en medios de distribución.
-i, --case-insensitive

Esta opción no permite nombres de archivo que difieren solo en mayúsculas/minúsculas. (Se imprimirá un mensaje de error si icepatch2calc encuentra archivos que difieren solo en mayúsculas/minúsculas). Esto es particularmente útil para servidores Unix con clientes Windows, ya que Windows ignora las mayúsculas/minúsculas en los nombres de archivo y, por lo tanto, dichos archivos se reemplazarían mutuamente en el cliente Windows.
-V, --verbose

Esta opción imprime un mensaje de progreso para cada archivo que se comprime y para cada suma de verificación que se calcula.

VER TAMBIÉN

icepatch2client(1), icepatch2server(1)
