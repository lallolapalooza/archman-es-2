NOMBRE

icewm-keys - archivo de configuración de teclas de icewm

SINOPSIS

$ICEWM_PRIVCFG/keys
$XDG_CONFIG_HOME/icewm/keys
$HOME/.icewm/keys
/usr/etc/icewm/keys
/usr/share/icewm/keys

DESCRIPCIÓN

El "keys" archivo define combinaciones de teclas globales para iniciar aplicaciones. Una combinación de teclas tiene tres partes: la palabra key, una cadena entre comillas dobles con una combinación de teclas X11 y un programa con sus argumentos. Estos están separados por uno o más espacios. Se permiten líneas vacías. Las líneas de comentario comienzan con almohadilla.

Por ejemplo, lo siguiente define una tecla rápida para reiniciar icewm:

key "Ctrl+Shift+r"      icesh restart

Consulte la salida de "xmodmap -pk" para obtener una lista de los muchos nombres de pulsaciones que puede usar en las definiciones de teclas de icewm. Desde la versión 3.4.0 de IceWM, las combinaciones no solo pueden definirse por su nombre de pulsación, sino también por su etiqueta de tecla. Además, la tecla con mayúsculas ahora también es definible. Por ejemplo, la tecla con + y = se puede vincular de cualquiera de las siguientes cuatro maneras, que son idénticas:

key "Ctrl+Shift+equal"  xterm
key "Ctrl+Shift+="      xterm
key "Ctrl+plus"         xterm
key "Ctrl++"            xterm

Para vincular el ratón, use "Pointer_Button1" para el botón 1, y así sucesivamente. Esto solo funciona cuando el ratón está sobre la ventana raíz. Vea ejemplos a continuación.

A veces puede querer iniciar una aplicación solo una vez. Para esto, use la palabra clave "runonce" , que acepta un argumento de recurso adicional.

El comando "icesh keys" le indica a icewm que recargue este archivo.

FORMATO

La sintaxis del keys archivo es la siguiente:

key "key_combination" program options

Donde,

key
La palabra key comienza la definición de una combinación de teclas.
key_combination
Una combinación de modificadores y una tecla, como "Ctrl+Alt+Delete". Los modificadores válidos son Alt, AltGr, Ctrl, Hyper, Meta, Shift, Super. Cada modificador debe ir seguido de un solo signo más. La tecla es o bien un nombre de pulsación o una etiqueta de tecla. En lugar de una tecla, se pueden especificar botones del puntero del ratón mediante "Pointer_Button1" y superiores, como "Shift+Pointer_Button3".
program options
program es el nombre del ejecutable o su ruta. Puede comenzar con una virgulilla o una variable de entorno, que se expandirá. Las options se pasan como argumentos al program.
runonce
Es una alternativa a key. Su sintaxis es:
runonce "hotkey" "wmclass" program options

Aquí wmclass es el nombre y/o clase del recurso. La clase debe ir precedida de un punto. El programa solo se ejecuta cuando no existe otra ventana de aplicación con el mismo wmclass . Icewm ignora los eventos de repetición de teclas para esta tecla rápida.

switchkey
Es una alternativa a key. En este caso, el program debe imprimir en la salida estándar la definición de un icewm-menu(1)dinámico. Este menú se presentará como un menú emergente.

EJEMPLOS

A continuación se muestra el ejemplo de archivo keys que se distribuye con icewm(1):

# Este es un ejemplo para el archivo de definición de teclas rápidas de IceWM.
#
# Una lista de todos los símbolos de teclado válidos se puede encontrar en
# /usr/include/X11/keysymdef.h, XF86keysym.h, ...
# Omita los prefijos XK_ y reemplace los prefijos XF86XK_ por XF86.
# Los modificadores válidos son Alt, AltGr, Ctrl, Shift, Meta, Super, Hyper.
#
key "Alt+Ctrl+t" xterm
key "Alt+Ctrl+b" xdg-open about:blank
key "Alt+Ctrl+s" xdg-open https://www.google.com
key "Super+KP_Subtract" amixer sset PCM 5%-
key "Super+KP_Add" amixer sset PCM 5%+
# Vinculaciones de "teclas multimedia" para XFree86. Obtenga los
# códigos de tecla de sus teclas de función avanzadas observando la
# salida del comando xev mientras presiona esas teclas
# y asigne esos símbolos usando xmodmap.
key "XF86AudioLowerVolume" amixer sset PCM 5%-
key "XF86AudioRaiseVolume" amixer sset PCM 5%+
key "XF86AudioMute" amixer sset PCM 0%
key "XF86HomePage" xdg-open about:blank
key "XF86Search" xdg-open https://www.google.com
key "XF86Eject" eject
# mostrar y seleccionar configuraciones de monitores
switchkey "Super+p" icewm-menu-xrandr
# mostrar y seleccionar entre todas las terminales
switchkey "Super+q"     icesh -Z switchmenu

Lo siguiente muestra cómo agregar vinculaciones de botones del ratón en la ventana raíz para cambiar el espacio de trabajo actual desplazando la rueda del ratón en el escritorio:

key "Pointer_Button4"   icesh goto prev
key "Pointer_Button5"   icesh goto next

Estas son vinculaciones de teclas para operaciones de mosaico de una sola ventana para reemplazar las vinculaciones de teclas KeyWinArrange del archivo preferences :

key "Ctrl+Alt+KP_Home"  icesh -f sizeto 49% 49% top left
key "Ctrl+Alt+KP_Up"    icesh -f sizeto 100% 49% top left
key "Ctrl+Alt+KP_Prior" icesh -f sizeto 49% 49% top right
key "Ctrl+Alt+KP_Right" icesh -f sizeto 49% 100% top right
key "Ctrl+Alt+KP_Next"  icesh -f sizeto 49% 49% bottom right
key "Ctrl+Alt+KP_Down"  icesh -f sizeto 100% 49% bottom left
key "Ctrl+Alt+KP_End"   icesh -f sizeto 49% 49% bottom left
key "Ctrl+Alt+KP_Left"  icesh -f sizeto 49% 100% top left
key "Ctrl+Alt+KP_Begin" icesh -f sizeto 49% 49% center

ARCHIVOS

Las ubicaciones para el keys archivo son las siguientes:

$ICEWM_PRIVCFG/keys
$XDG_CONFIG_HOME/icewm/keys
$HOME/.icewm/keys
/usr/etc/icewm/keys
/usr/share/icewm/keys

Las ubicaciones se buscan en el orden indicado; se lee el primer archivo encontrado y se ignoran los demás.
