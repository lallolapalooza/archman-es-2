NOMBRE

icegriddb - La utilidad de importación/exportación de bases de datos de IceGrid.

SINOPSIS

icegriddb [opciones]

DESCRIPCIÓN

La utilidad icegriddb es una herramienta de línea de comandos para importar y exportar bases de datos de IceGrid. La documentación completa para icegriddb está disponible en línea en:
https://doc.zeroc.com/ice/3.7/ice-services/icegrid/icegrid-database-utility

OPCIONES

-h, --help

Mostrar la ayuda del programa.
-v, --version

Mostrar la versión de Ice.
--import ARCHIVO

Importar la base de datos desde el archivo especificado.
--export ARCHIVO

Exportar la base de datos al archivo especificado.
--dbpath DIR

Entorno de base de datos de origen o destino.
--mapsize VALOR

Establecer el tamaño del mapa LMDB en MB (opcional, solo importación).
--server-version VER

Establecer la versión de Ice para los servidores IceGrid (opcional, solo importación).
-d, --debug

Imprimir mensajes de depuración.

VER TAMBIÉN

icegridadmin(1), icegridnode(1), icegridregistry(1)
