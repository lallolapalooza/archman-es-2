NOMBR

E

icedtea-web proporciona un plugin de navegador web de software libre que ejecuta applets escritos en el lenguaje de programación Java y una implementación de Java Web Start, originalmente basada en el proyecto

NetX.

NetX permite descargar applets y aplicaciones Java a través de la red, almacenarlos en caché y (de forma predeterminada) ejecutarlos en un entorno de sandbox seguro. Las ejecuciones posteriores del applet descargan automáticamente la versión más reciente. La configuración de actualizaciones y seguridad, entre otros ajustos, se puede realizar mediante el comando itw-settings.
icedtea-web también incluye un plugin para habilitar applets Java (http://www.java.com/en/download/testjava.jsp) dentro de los navegadores web.

Los nombres y direcciones de correo electrónico de los colaboradores de este proyecto se pueden encontrar en el archivo AUTHORS en el directorio raíz de
IcedTea-Web.
La licencia GPLv2 completa de este proyecto se puede encontrar en el archivo COPYING en el directorio raíz de
IcedTea-Web.
Las noticias sobre las versiones de este proyecto se pueden encontrar en el archivo NEWS en el directorio raíz de
IcedTea-Web.
