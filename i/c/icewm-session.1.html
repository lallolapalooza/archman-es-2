NOMBRE

icewm-session - Proveedor del gestor de sesiones de X.Org con IceWM

SINOPSIS

icewm-session [OPCIONES]

DESCRIPCIÓN

icewm-session es una implementación de un gestor de sesiones de X.Org y puede ejecutarse desde una configuración de sesión X11. Ejecuta icewm como el gestor de ventanas predeterminado y controla el ciclo de vida de las aplicaciones de soporte relacionadas.

OPCIONES

OPCIONES ESPECIFICAS

-c, --config=ARCHIVO
Permite que IceWM cargue las preferencias desde ARCHIVO.
-t, --theme=ARCHIVO
Permite que IceWM cargue el tema ARCHIVO.
-i, --icewm=ARCHIVO
Usa ARCHIVO como el gestor de ventanas de IceWM.
-o, --output=ARCHIVO
Redirige toda la salida a ARCHIVO. Se expande una tilde inicial o una variable de entorno.
-a, --alpha
Usa una visualización de 32 bits para la translucidez.
-b, --nobg
No iniciar icewmbg.
-n, --notray
No iniciar icewmtray. Esto solo es aplicable si IceWM fue configurado explícitamente para usar un proceso icewmtray externo.
-s, --sound
También iniciar icesound.
--replace
Reemplazar un gestor de ventanas existente.

OPCIONES GENERALES

-d, --display=PANTALLA
Usa PANTALLA para conectarte al servidor X. Si falta esta opción, entonces PANTALLA se lee de la variable de entorno "DISPLAY".
--sync
Usa una comunicación síncrona más lenta con el servidor X11.
-h, --help
Proporciona una lista de todas las opciones admitidas y sale.
-V, --version
Imprime la versión del programa y sale.
-C, --copying
Imprime los permisos de copia y sale.

OPCIONES DE DEPURACIÓN

-v, ---valgrind
Permite que "/usr/bin/valgrind" ejecute icewm. Examina a fondo la ejecución de icewm.
-g, ---catchsegv
Permite que "/usr/bin/catchsegv" ejecute icewm. Proporciona un rastreo de pila si icewm falla.

USO

Al iniciar, icewm-session ejecuta los siguientes pasos. Del archivo env en el directorio de configuración, carga variables de entorno adicionales, si dicho archivo existe. Luego iniciará icewmbg para gestionar los colores y las imágenes de fondo de la raíz. También puede iniciar icesound, si esto se habilitó en el momento de la configuración. Luego se inicia icewm.

Si existe un script ejecutable startup en el directorio de configuración, se ejecutará. Puede contener comandos para inicializar la configuración de X11 con xset, cargar la configuración del teclado, iniciar un gestor de composición como compton y cargar aplicaciones de bandeja del sistema.

Cuando icewm se cierra, icewm-session ejecutará un script shutdown, si existe en el directorio de configuración. Cuando esto finalice, icewm-session terminará icewm, icewmbg e icesound. Finalmente, icewm-session saldrá.

Si el proceso icewm falla, icewm-session intentará reiniciarlo. Si dos de estos fallos ocurren en un corto período, icewm-session intentará mostrar un diálogo usando yad, xmessage, kdialog o zenity. Este diálogo presenta una opción entre reiniciar icewm, iniciar un terminal o abortar la ejecución de icewm-session.

ENTORNO

ICEWM_OPTIONS
Una lista de opciones separadas por espacios que se añadirán a la línea de comandos de invocación de icewm. Esto puede configurarse en el archivo env.

VER TAMBIÉN

icewm(1), icewm-env(5), icewm-shutdown(5), icewm-startup(5), icewmbg(1).
