ICEAUTH(1) Manual de Comandos Generales ICEAUTH(1)

NOMBRE

iceauth - utilidad de archivo de autorización ICE

SINOPSIS

iceauth [ -f archivo_auth ] [ -vqibuV ] [ comando argumento ... ]

DESCRIPCIÓN

El programa iceauth se utiliza para editar y mostrar la información de autorización utilizada para conectarse con ICE. Este programa se usa generalmente para extraer registros de autorización de una máquina y fusionarlos en otra (como ocurre al usar inicios de sesión remotos o al conceder acceso a otros usuarios). Los comandos (descritos a continuación) pueden ingresarse interactivamente, en la línea de comandos de iceauth, o en scripts.

OPCIONES

-f archivo_auth Nombre del archivo de autorización a usar. Por defecto, será el archivo actualmente en uso por la sesión.

-v Activa mensajes adicionales (modo verboso)

-q Desactiva mensajes adicionales (modo silencioso)

-i Ignora los bloqueos en el archivo de autorización

-b Rompe los bloqueos en el archivo de autorización

-u Muestra instrucciones básicas de uso

-V Muestra la versión y sale

USO

Cuando se ejecuta iceauth, permite ingresar el siguiente conjunto de comandos de forma interactiva o en scripts.

?

Lista los comandos disponibles.

help

Muestra información de ayuda. Puedes proporcionar un nombre de comando a help para obtener información específica sobre él.

info

Muestra información sobre las entradas en el archivo de autorización.

list

Lista (muestra) las entradas en el archivo de autorización. Puedes especificar modificadores opcionales como se muestra a continuación para especificar qué entradas se listan.

list [ nombre_protocolo ] [ datos_protocolo ] [ netid ] [ nombre_auth ]

add

Agrega una entrada al archivo de autorización. Debe tener el siguiente formato:

add nombre_protocolo datos_protocolo netid nombre_auth datos_auth

remove

Elimina entradas del archivo de autorización.

remove [ nombre_protocolo ] [ datos_protocolo ] [ netid ] [ nombre_auth ]

extract

Extrae entradas del archivo de autorización a un archivo de destino. Debes proporcionar la ruta al destino a este comando, como en el siguiente formato. Los especificadores opcionales te permiten acotar qué entradas se extraen.

extract nombre_archivo [ nombre_protocolo ] [ datos_protocolo ] [ netid ] [ nombre_auth ]

merge

Fusiona entradas de otros archivos en el archivo de autorización seleccionado por el programa. Puedes proporcionar cualquier número de rutas de archivo a este comando, como sigue:

merge nombre_archivo1 [ nombre_archivo2 ] [ nombre_archivo3 ] ...

exit

Guarda los cambios y sale del programa.

quit

Aborta los cambios y sale del programa sin guardar.

source

Lee y ejecuta comandos desde un archivo.

source nombre_archivo
