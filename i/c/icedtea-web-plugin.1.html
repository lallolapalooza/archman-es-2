NOMBRE

icedtea-web-plugin - permite ejecutar applets de java en tu navegador favorito

SINOPSIS

icedtea-web-plugin funciona en tu navegador, una vez que tu navegador conozca estos archivos.

El archivo IcedTeaPlugin.so debe colocarse o enlazarse dentro de directorios específicos. Ver http://icedtea.classpath.org/wiki/IcedTea-Web#Plugin

Navegadores compatibles con Mozilla como Firefox, Midori, Epiphany, Chrome o Chromium usan:

$HOME/.mozilla/plugins
Ubicación de la biblioteca de plugins para propósitos del usuario en un navegador compatible con Mozilla.
/usr/lib64/mozilla/plugins
Ubicación de la biblioteca de plugins para propósitos globales en un navegador compatible con Mozilla, sistemas de 64 bits.
/usr/lib/mozilla/plugins
Ubicación de la biblioteca de plugins para propósitos globales en un navegador compatible con Mozilla, sistemas de 32 bits.

Navegadores de la familia Opera como Opera usan:

/usr/lib64/opera/plugins
Ubicación de la biblioteca de plugins para propósitos globales en un navegador compatible con Opera, sistemas de 64 bits.
/usr/lib/opera/plugins
Ubicación de la biblioteca de plugins para propósitos globales en un navegador compatible con Opera, sistemas de 32 bits.

Todas las marcas registradas de terceros son propiedad de sus respectivos dueños.

ARCHIVOS

$HOME/.mozilla/plugins/IcedTeaPlugin.so
Ubicación de la biblioteca de plugins para propósitos del usuario en un navegador compatible con Mozilla.
$XDG_CACHE_HOME/icedtea-web/cache/recently_used
Información adicional sobre los elementos en la caché
$XDG_CONFIG_HOME/icedtea-web/generated_jnlps
Ubicación donde se almacenan los archivos jnlp generados a partir de páginas html para aplicaciones javaws con iconos de lanzadores de escritorio/menú.
$XDG_RUNTIME_DIR/tmp/icedteaplugin-user-*
Contiene el pipe de entrada y salida para la comunicación nativa a java y el pipe de depuración (si está habilitado).
/usr/lib/mozilla/plugins/IcedTeaPlugin.so
Ubicación de la biblioteca de plugins para propósitos globales en un navegador compatible con Mozilla, sistemas de 32 bits.
/usr/lib/opera/plugins/IcedTeaPlugin.so
Ubicación de la biblioteca de plugins para propósitos globales en un navegador compatible con Opera, sistemas de 32 bits.
/usr/lib64/mozilla/plugins/IcedTeaPlugin.so
Ubicación de la biblioteca de plugins para propósitos globales en un navegador compatible con Mozilla, sistemas de 64 bits.
/usr/lib64/opera/plugins/IcedTeaPlugin.so
Ubicación de la biblioteca de plugins para propósitos globales en un navegador compatible con Opera, sistemas de 64 bits.

Donde $XDG_CONFIG_DIR, $XDG_CACHE_DIR y $XDG_RUNTIME_DIR se establecen como ~/.config, ~/.cache y /tmp o /var/tmp si no están definidos.

ERRORES

No se conocen errores. Si encuentras uno, por favor repórtalo en:
http://icedtea.classpath.org/wiki/IcedTea-Web#Filing_bugs
http://icedtea.classpath.org/bugzilla

Por favor, ejecuta en modo de depuración (con el modificador -verbose, o configurando itw-settings, o estableciendo la variable ICEDTEAPLUGIN_DEBUG a true) e incluye esa salida (preferiblemente de la consola de java) junto con la URL del archivo jnlp o html (o el archivo jnlp/html o la aplicación misma) al informar un error.
