NOMBRE

icewm-set-gnomewm - modificar la configuración de GNOME para usar IceWM

SINOPSIS

icewm-set-gnomewm [OPCIONES]

DESCRIPCIÓN

icewm-set-gnomewm es un script auxiliar que instrumenta GNOME para reemplazar su propio gestor de ventanas con icewm.

OPCIONES

OPCIONES GENERALES

-h, --help
Imprime una breve declaración de uso en stdout y sale.
-V, --version
Imprime la versión del programa en stdout y sale.

ERRORES

Por favor, reporte los errores en https://github.com/bbidulock/icewm/issues.
