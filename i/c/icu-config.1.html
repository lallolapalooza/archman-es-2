DESCRIPCIÓ

N

icu-config simplifica la tarea de compilar y enlazar con ICU en comparación con configurar manualmente los archivos make del usuario o lo equivalente. Debido a que icu-config es un script ejecutable, también resuelve el problema de localizar las

bibliotecas y cabeceras de ICU, al permiti
r que el PATH del sistema lo encuentre.

EJEMPLO

S

icu-config se puede usar sin un archivo make. La línea de comandos siguiente es suficiente para compilar un programa C++ de un solo archivo contra ICU. (Por ejemplo, icu/source/samples/prop

s/props.cpp)
`icu-config --cxx --cxxflags --cppflags --ldflags` -o props props.
cpp

Más comúnmente, icu-config se llamará desde dentro de un archivo make, y se usará para configurar variables. El siguiente ejemplo también compila el ejemplo props

.
CC=$(shell icu-config --cc)

CXX=$(shell icu-config

--cxx)

CPPFLAGS=$(shell icu-config

--cppflags)

CXXFLAGS=$(shell icu-config

--cxxflags)

LDFLAGS =$(shell icu-config

--ldflags)

all:

props

props.

o: pro
ps.cpp

make(1) usará auto

máticamente las var
iables anteriores.

OPCIONE

S
--bind
ir
Imprime la ruta del directorio de binarios (ejecutables). Normalmente equivalente a 'bin'. Aquí se encuentran las aplicaciones y scripts ejecutables por el usuario de
ICU.
--
cc
Imprime el compilador de C utilizado. Equivalente a la variable del archivo make
$(CC).
--cfla
gs
Imprime los indicadores del compilador de C. Equivalente a la variable del archivo make $(CFLAGS). NO incluye directivas del preprocesador como la ruta de inclusión o los símbolos definidos. Los ejemplos incluyen depuración (-g) e indicadores de
optimización.
--cppfla
gs
Imprime los indicadores del preprocesador de C. Equivalente a la variable del archivo make $(CPPFLAGS). Ejemplos son las rutas de inclusión -I y las directivas de definición
-D.
--cppflags-searchp
ath
Imprime los indicadores del preprocesador de C, como arriba pero solo las rutas de búsqueda
-I.
--c
xx
Imprime el compilador de C++. Equivalente a la variable del archivo make $(CXX)
.
--cxxfla
gs
Imprime los indicadores del compilador de C++. Equivalente a la variable del archivo make $(CXXFLAGS)
.
--detect-pre
fix
Si ICU se ha movido de su ubicación de instalación, anteponer este indicador a otras llamadas a icu-config intentará localizar ICU en relación con la ubicación donde se encontró el script icu-config. Se puede usar como un último recurso si la instalación de ICU está
dañada.
--exec-pref
ix
Imprime el prefijo utilizado para los directorios de programas ejecutables (como bin, sbin, etc). Normalmente es el mismo que el
prefijo.
--exis
ts
El script devolverá un estado exitoso (0) si parece que ICU está instalado y localizado correctamente, de lo contrario se mostrará un mensaje de error y un estado distinto de
cero.
--help, -?,--usa
ge
Imprime un mensaje de ayuda y de
uso.
--icuda
ta
Imprime el nombre corto del archivo de datos de ICU. Esto no incluye ningún sufijo como .dat, .dll, .so, .lib, .a, etc. ni incluye prefijos como 'lib'. Puede tener la forma icudt2
1b
--icudata-install-
dir
Imprime el directorio donde se debe instalar el empaquetado de datos de ICU. Se puede usar como la opción --install de pkgdata(1)
.
--icudata-mo
de
Imprime el modo pkgdata predeterminado de ICU, como dll o common. Se puede usar como la opción --mode de pkgdata(1)
.
--icudatad
ir
Imprime la ruta a los datos de archivo empaquetados. (debería ser donde apunta $ICU_DATA o la ruta predeterminada equivalente.) NO apuntará al
libdir.
--invo
ke
Si ICU no está instalado en una ubicación donde el sistema operativo localice sus bibliotecas compartidas, esta opción imprimirá comandos para configurar las variables de entorno apropiadas para cargar las bibliotecas compartidas de ICU. Por ejemplo, en muchos sistemas se debe configurar una variable llamada LD_LIBRARY_PATH o
equivalente.
--invoke=pr
og
Igual que la opción --invoke, excepto que incluye opciones para invocar un programa llamado prog. Si prog es el nombre de una herramienta de ICU, como genrb(1), entonces icu-config también incluirá la ruta completa a esa
herramienta.
--ldfla
gs
Imprime cualquier indicador que deba pasarse al enlazador. Estos pueden incluir -L para las rutas de búsqueda de bibliotecas, y -l para incluir las bibliotecas de ICU. Por defecto, esta opción intentará enlazar las bibliotecas "common" (libicuuc) y "i18n" (libicui18n), así como la biblioteca de datos. Si se requieren bibliotecas adicionales, cualquiera de los dos indicadores siguientes puede añadirse junto con este, por ejemplo "--ldflags --ldflags-icuio" si se requiere la biblioteca icuio además de las bibliotecas estándar de ICU. Equivalente a la variable del archivo make $(LDFLAGS)
.
--ldflags-lay
out
Imprime la opción de enlace para la biblioteca de diseño de
ICU.
--ldflags-ic
uio
Imprime la opción de enlace para añadir el paquete de E/S de
ICU.
--ldflags-libso
nly
Similar a --ldflags pero solo incluye las opciones
-l.
--ldflags-searchp
ath
Similar a --ldflags pero solo incluye las opciones de ruta de búsqueda
-L.
--ldflags-sys
tem
Similar a --ldflags pero solo incluye bibliotecas del sistema (como pthreads). --mandir Imprime la ubicación de las páginas de manual de ICU instaladas. Normalmente (man)
.
--pref
ix
Imprime el prefijo (directorio base) bajo el cual reside ICU
instalado.
--prefix=pref
ix
Establece el prefijo de ICU a prefix para el resto de esta línea de comandos. Comprueba si el nuevo prefijo es
válido.
--sbind
ir
Imprime la ubicación de los binarios del sistema de ICU, normalmente
(sbin).
--shared-data
dir
Imprime la ubicación de los datos compartidos de ICU, normalmente (share)
.
--sysconfd
ir
Imprime la ubicación de los datos de configuración del sistema de ICU, normalmente
(etc).
--unicode-vers
ion
Imprime la versión del Estándar Unicode que utiliza el ICU
actual.
--versi
on
Imprime la versión actual de
ICU.
--incfi
le
Imprime la ruta 'Makef
ile.inc', adecuada para
usarse con la opción -
O de pkgdata(1).
