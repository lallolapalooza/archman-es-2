ICONV_OPEN(3P) Manual de Programador POSIX ICONV_OPEN(3P)

PRÓLOGO

Esta página del manual forma parte del Manual de Programador POSIX. La implementación de Linux de esta interfaz puede diferir (consulte la página del manual de Linux correspondiente para conocer los detalles del comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

iconv_open — función de asignación de conversión de conjuntos de códigos

SINOPSIS

#include <iconv.h>
iconv_t iconv_open(const char *tocode, const char *fromcode);

DESCRIPCIÓN

La función iconv_open() devolverá un descriptor de conversión que describe una conversión del conjunto de códigos especificado por la cadena a la que apunta el argumento fromcode al conjunto de códigos especificado por la cadena a la que apunta el argumento tocode. Para codificaciones dependientes del estado, el descriptor de conversión estará en un estado de cambio inicial dependiente del conjunto de códigos, listo para su uso inmediato con iconv().

La configuración de fromcode y tocode y sus combinaciones permitidas son definiciones de la implementación.

Un descriptor de conversión seguirá siendo válido hasta que sea cerrado por iconv_close() o un cierre implícito.

Si se utiliza un descriptor de archivo para implementar los descriptores de conversión, se establecerá la bandera FD_CLOEXEC; consulte <fcntl.h>.

VALOR DE RETORNO

Si se completa con éxito, iconv_open() devolverá un descriptor de conversión para su uso en llamadas posteriores a iconv(). De lo contrario, iconv_open() devolverá (iconv_t)-1 y establecerá errno para indicar el error.

ERRORES

La función iconv_open() puede fallar si:

EMFILE
Todos los descriptores de archivo disponibles para el proceso están actualmente abiertos.
ENFILE
Hay demasiados archivos abiertos actualmente en el sistema.
ENOMEM
No hay suficiente espacio de almacenamiento disponible.
EINVAL
La conversión especificada por fromcode y tocode no es soportada por la implementación.

USO DE APLICACIÓN

Algunas implementaciones de iconv_open() utilizan malloc() para asignar espacio para áreas de búfer internas. La función iconv_open() puede fallar si no hay suficiente espacio de almacenamiento para acomodar estos búferes.

Las aplicaciones compatibles deben asumir que los descriptores de conversión no son válidos después de una llamada a una de las funciones exec.

Los desarrolladores de aplicaciones deben consultar la documentación del sistema para determinar los conjuntos de códigos soportados y sus esquemas de denominación.
