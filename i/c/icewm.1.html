DESCRIPCIÓ

N

icewm es un gestor de ventanas pequeño y rápido para el sistema de ventanas X11. Es mejor iniciarlo mediante icewm-session(1), que también inicia icewmbg

(1).

icewm se denomina de re-parenting, porque dibuja marcos alrededor de las ventanas de las aplicaciones. Arrastre este marco con el ratón para mover o redimensionar una

ventana.

Debido a que las ventanas pueden superponerse, icewm es también un gestor de ventanas de apilamiento. Pueden existir muchas ventanas, algunas ocultas detrás de

otras.

icewm admite un número configurable de escritorios virtuales. Estos se denominan espacios de trabajo. Las ventanas relacionadas se agrupan en un espacio de trabajo dedicado. Al cambiar entre espacios de trabajo, el usuario puede atender a diferentes tareas mientras mantiene el control general. Esto está soportado por una barra de tareas y un

paginador.

La instalación viene con varios temas. Elija un tema mediante un menú. Instale temas adicionales automáticamente con la opción --install

.

icewm cumple con las especificacione

s de gestor de vent
anas ICCCM y EWMH.

BARRA DE

TAREAS

Al inicio icewm lanza la barra de tareas en la parte inferior de la pantalla. La barra de tareas consta de izquierda a derecha de los siguientes

componentes:

El botón Menú en la esquina inferior izquierda da acceso al menú raíz de icewm. Este menú tiene submenús para iniciar aplicaciones, para controlar la configuración de icewm, y el menú icewm Cerrar se

sión.

El botón Mostrar escritorio desmapea todas las ventanas de aplicación para descubrir completamente el

escritorio.

El botón Menú de lista de ventanas da acceso a un menú con una lista de ventanas activas para el espacio de trabajo actual y una lista de espacios de trabajo con submenús para sus ventanas de aplicación

activas.

La Barra de herramientas es una lista de iconos para aplicaciones que están definidas en el archivo de configuración de la barra de

herramientas.

El Panel de espacios de trabajo muestra un botón para cada espacio de trabajo. El espacio de trabajo actual está indicado por un botón presionado. Hacer clic en otro espacio de trabajo cambia a ese espacio de trabajo. Presionar el botón izquierdo del ratón, luego la tecla Shift, luego soltar el botón izquierdo, lleva la ventana actual a ese espacio de trabajo. Presionar izquierdo, luego Alt, luego soltar izquierdo, mueve solo la ventana enfocada a otro espacio de trabajo, sin cambiar el espacio de trabajo

actual.

Los espacios de trabajo están definidos en el archivo de preferencias. Para cambiar un nombre solo para esta sesión, haga doble clic, edite el nombre y pulse Intro. Cuando "PagerShowPreview" está activado, se muestra un pequeño resumen gráfico de ventana para cada espacio de trabajo. Soportan arrastrar y soltar: arrastrar una pestaña de Firefox a un botón de espacio de trabajo cambia el espacio de trabajo actual. Luego soltarla mueve esa pestaña a una nueva ventana en ese espacio de

trabajo.

El Panel de tareas consta de una lista de botones anchos para cada aplicación que se está ejecutando en el espacio de trabajo actual, o todos los espacios de trabajo si "TaskBarShowAllWindows=1". Cada botón de tarea muestra el icono de la aplicación y el título de la aplicación. La aplicación activa está indicada por un botón presionado. Esta es la aplicación que tiene el foco de entrada. Hacer clic en otro botón activa esa aplicación: se trae al primer plano y recibe el foco de entrada. Hacer clic en el botón de una aplicación activa la minimiza. Para minimizar una aplicación inactiva, haga clic en su botón mientras "Ctrl" está

presionado.

Los botones de ventana se pueden arrastrar con el botón izquierdo del ratón para reorganizar su orden. Una ventana se puede cerrar con "Alt" + botón central, bajarla con "Ctrl" + botón central, o traerla al espacio de trabajo actual con "Shift" + botón central cuando "TaskBarShowAllWindows=1"

Incluso con un panel de tareas completo, este menú generalmente se puede acceder haciendo clic derecho en la esquina inferior derecha de la barra de

tareas.

FOCO DE

ENTRADA

De todas las ventanas visibles solo una puede ser la ventana activa. Esta es la ventana que tiene el foco de entrada. Es el receptor principal de eventos de teclado y ratón y por lo tanto uno puede interactuar con la aplicación que creó esa ventana. Una tarea principal de un gestor de ventanas es permitir al usuario cambiar el foco de entrada entre diferentes ventanas. El medio principal para hacer esto es el puntero del ratón. Al mover el puntero del ratón sobre la pantalla a otra ventana, y quizás también al hacer clic en una ventana, se puede dirigir el foco de

entrada.

La opción "FocusMode" controla la forma en que icewm da el foco de entrada a las aplicaciones. Es inicializada por el archivo de configuración focus_mode. El modo de foco se establece a través del menú Foco. icewm soporta seis modelos de

foco:
1.
Clic-para-enfocar
El modo de foco predeterminado. En este modo, cambiar el foco de entrada requiere hacer clic en una ventana con el botón izquierdo del ratón. La ventana se eleva si es necesario. Cuando una aplicación solicita foco, su botón en el panel de tareas parpadea. Esto da la opción de honrar esta solicitud o ignorarla. Cuando aparece una nueva ventana de aplicación, recibe automáticamente el foco. También cuando una aplicación oculta se eleva al frente, recibe el
foco.
2. Foco de ratón
descuidado
Establece el foco de entrada simplemente moviendo el puntero del ratón sobre una ventana. Se llama descuidado, porque si el ratón luego deja la ventana y se mueve al fondo del escritorio, el foco de entrada permanece con la última ventana activa. Cuando una ventana recibe el foco, se eleva. Cuando una aplicación solicita foco, su botón en el panel de tareas parpadea. Una nueva aplicación o una aplicación que se eleva al frente recibe automáticamente el
foco.
3. Foco
explícito
El foco es aún más controlado por el usuario que en Clic-para-enfocar. Cuando una ventana recibe el foco, no se eleva por defecto, a menos que se haga clic en el borde del marco. No ocurre ningún parpadeo cuando una aplicación solicita foco. Cuando aparece una nueva ventana de aplicación, no recibe el foco. Solo al hacer clic explícitamente en una ventana se dirige el
foco.
4. Foco estricto de
ratón
Como Descuidado pero el foco permanece con la última ventana. Las nuevas aplicaciones no reciben el foco y se mapean detrás de otras ventanas. Cuando una aplicación se eleva al frente, aún no obtiene el
foco.
5. Foco descuidado
tranquilo
Como Descuidado pero no ocurre ningún parpadeo perturbador en la barra de tareas cuando una aplicación solicita
foco.
6. Modo
personalizado
Un modo de foco que está definido por las siguientes diez opciones: "ClickToFocus", "FocusOnAppRaise", "RequestFocusOnAppRaise", "RaiseOnFocus", "RaiseOnClickClient", "FocusChangesWorkspace", "FocusOnMap", "FocusOnMapTransient", "FocusOnMapTransientActive", "MapInactiveOnTop".

Todos los modos de

foco que no son Per
sonalizado anulan e
stas diez opciones.

Aparte del ratón, icewm soporta cambiar el foco de entrada de dos maneras por teclado. Al presionar "Alt+Esc" o "Alt+Shift+Esc", el foco de entrada cambia inmediatamente a la siguiente o ventana anterior, q

ue será elevada para hacerla completamente visi
ble. El otro método involucra el cambio rápido.

CAMBIO

RÁPIDO

El QuickSwitch es un medio para cambiar rápida e interactivamente el foco de entrada a otra ventana. Se activa presionando la combinación de teclas "Alt+Tab" o "Alt+Shift+Tab". Una ventana aparece en el centro de la pantalla con una lista de ventanas para elegir. Una banda estrecha indica una selección: la ventana candidata que será activada para recibir el foco de entrada cuando se suelte la tecla

Alt.

La selección se puede cambiar presionando repetidamente la tecla Tab, mientras se mantiene presionada la tecla Alt. Si también se mantiene presionada la tecla Shift, la dirección del recorrido se invierte. O use la rueda de desplazamiento del ratón. O use una de las teclas de dígito para seleccionar la ventana correspondiente de la lista. Las teclas de flecha también son soportadas, así como las teclas Inicio y

Fin.

Para hacer de una ventana seleccionada la ventana activa, simplemente suelte la tecla Alt, o pulse la tecla Intro, o haga clic en ella. Para cancelar el QuickSwitch, pulse Escape o haga clic fuera de la ventana del

QuickSwitch.

Una ventana seleccionada se puede cerrar con Delete, "Alt+F4", o el botón central del ratón. Mientras la ventana del QuickSwitch está visible, aún se puede cambiar de espacio de trabajo con los atajos de teclado habituales de espacio de

trabajo.

El QuickSwitch tiene dos modos distintos: vertical y horizontal. La lista de ventanas puede

incluir todas las ventanas o limitarse al espacio de trabajo actual. Hay una opción para el
evar el candidato seleccionado. Vea las muchas preferencias disponibles para el QuickSwitch.

COLOCACIÓN DE

VENTANAS

Una segunda tarea importante de un gestor de ventanas es colocar nuevas ventanas en la pantalla. Por defecto icewm elige una colocación con solapamiento mínimo, pero esto está determinado por la &qu

COLOCACIÓN DE VENTANAS

Hay tres opciones para la colocación de ventanas. "SmartPlacement" está activada por defecto. Esto significa que las ventanas se colocan de manera que no se solapen entre sí. Las ventanas se agrupan en bloques de 4 y cada nueva ventana se colocará en el primer espacio libre. Si esta opción está desactivada, las ventanas se colocarán en secuencia de izquierda a derecha y de arriba a abajo. También se puede activar "ManualPlacement". Entonces las nuevas ventanas aparecerán inicialmente en la esquina superior izquierda y el cursor del ratón se convertirá en un puño. Moviendo el cursor del puño a una ubicación adecuada y haciendo clic, la nueva ventana aparecerá en la ubicación del clic del ratón.

CAPAS DE VENTANAS

Las ventanas pueden superponerse. Qué ventana aparece encima está determinado por tres características. Las ventanas más nuevas aparecen sobre las más antiguas. Al hacer clic en una ventana, ésta se eleva a la parte superior. Pero ambas son anuladas por la capa de la ventana. Las ventanas pueden colocarse en diferentes capas a través del menú Layers. Haga clic con el botón derecho del ratón en el marco de la ventana y seleccione Layer. Desde allí elija una de las siete capas de ventanas. Estas están ordenadas de mayor a menor. Las ventanas en capas superiores aparecen sobre las ventanas en capas inferiores.

Hay 16 capas en total, pero la mayoría rara vez se utilizan o nunca. Están numeradas desde cero para la capa más baja hasta quince para la más alta. Sus nombres con su número de capa son: Desktop (0), Below (2), Normal (4), OnTop (6), Dock (8), AboveDock (10), Menu (12), Fullscreen (14) y AboveAll (15). Por defecto, cada ventana aparece en la capa Normal. Entonces Below y OnTop se usan con frecuencia para posicionar ventanas debajo o encima de la mayoría de las otras. Los menús de Icewm aparecen en la capa Menu y la capa Fullscreen está reservada para las ventanas en modo pantalla completa. La capa predeterminada para cada aplicación se puede establecer con una winoption.

Las ventanas colocadas en la capa Dock pueden configurarse para que estén siempre visibles estableciendo la preferencia "LimitByDockLayer" a 1. Entonces otras ventanas preferentemente no se colocarán sobre dichas ventanas, a menos que tengan información explícita de posicionamiento para hacerlo. Las ventanas maximizadas tampoco se superponen con estas ventanas de DockLayer. La winoption DoNotCover es similar.

APLICACIONES ACOPLADAS

Icewm tiene soporte nativo para dockapps de Window Maker. Tiene un contenedor de Dock llamado DockApps, que aparece automáticamente cuando se inician las dockapps. La posición y la capa de este contenedor se controlan mediante la preferencia "DockApps". Es una lista de palabras clave separadas por espacios. Las palabras clave "right, left, center, down, high" controlan la posición, mientras que "above, dock, ontop, normal, below, desktop" establecen la capa. Cuando DockApps se establece como una cadena vacía, el soporte para dockapps se deshabilita. Las dockapps en el contenedor se pueden controlar usando el ratón cuando se mantiene presionada la tecla Ctrl. Arrastre con el botón izquierdo del ratón, cierre con el botón del medio, seleccione un menú con el botón derecho del ratón y gire con la rueda de desplazamiento.

Si al maximizar una ventana no debe superponerse al contenedor DockApps, colóquela en la capa dock y establezca la preferencia LimitByDockLayer=1.

VENTANAS CON PESTAÑAS

El marco de una ventana puede contener múltiples ventanas cliente. Solo un cliente puede ser visible, mientras que los otros están ocultos. Esto se llama tabbing. Esto puede ser útil para reducir el número de ventanas visibles. Para crear una pestaña, arrastre la barra de título con el botón del medio del ratón, mientras mantiene presionada la tecla shift, hacia la barra de título de otro marco. Las dos barras de título comenzarán a parpadear para indicar que pueden fusionarse. Suelte el botón del ratón para fusionar el cliente de la ventana superior en el marco inferior. Ahora el marco inferior tendrá múltiples clientes, llamados pestañas. La barra de título mostrará una barra vertical con tres puntos para indicarlo. Para cambiar la pestaña actual, haga una de las siguientes acciones:

  • Haga clic en los tres puntos junto a la barra vertical.
  • Use "KeyWinNext=Alt+F6" para seleccionar la siguiente pestaña.
  • Use "KeyWinPrev=Alt+Shift+F6" para la pestaña anterior.
  • Use el QuickSwitch.
  • Use la ventana de lista de ventanas.
  • Use un submenú en el menú de ventanas.

Para cambiar la vinculación del ratón para crear pestañas, modifique MouseWinTabbing="Shift+Pointer_Button2". Otra configuración útil es MouseWinTabbing="Pointer_Button1".

"Alt+F4" cierra todas las pestañas. Para cerrar solo la pestaña activa, añada a "keys":

key "Ctrl+Shift+F4"     icesh -f close

Para mover la pestaña activa a su propio marco de ventana por tecla, añada a "keys":

key "Alt+u"             icesh -f untab

Para abrir todas las ventanas de Chrome en el mismo marco, añada esto a "winoptions":

google-chrome.frame:    chrome

ESPACIOS DE TRABAJO

icewm soporta múltiples escritorios virtuales llamados espacios de trabajo. Un espacio de trabajo es como una pantalla donde se mapea un subconjunto de todas las ventanas de aplicaciones. Gracias a los múltiples espacios de trabajo podemos gestionar más fácilmente un gran número de aplicaciones. El número de espacios de trabajo y sus nombres son configurables en el archivo preferences a través de la opción "WorkspaceNames". Por defecto se crean cuatro espacios de trabajo con los nombres 1, 2, 3 y 4, de la siguiente manera:

WorkspaceNames=" 1 ", " 2 ", " 3 ", " 4 "

Esta sintaxis es típica para las opciones de icewm que reciben múltiples valores. Es una lista de valores separados por comas, cada uno de los cuales puede ir entre comillas.

Los espacios de trabajo son visibles en la barra de herramientas. Se puede cambiar a un espacio de trabajo diferente presionando el botón del espacio de trabajo en la barra de herramientas, pero después de familiarizarse con los 'atajos de teclado' a continuación, querrá usar una tecla de acceso rápido para elegir un espacio de trabajo. Si la opción "EdgeSwitch" está habilitada en el archivo preferences (con las sub-opciones "HorizontalEdgeSwitch" y "VerticalEdgeSwitch"), entonces se puede mover al siguiente o anterior espacio de trabajo moviendo el ratón al borde de la pantalla. La opción "ContinuousEdgeSwitch" habilita el movimiento continuo a los siguientes espacios de trabajo. La opción "EdgeSwitchDelay" indica cuánto tiempo esperar antes de que ocurra un cambio de espacio de trabajo.

Para mover una ventana de aplicación a un espacio de trabajo diferente, se puede usar un atajo de teclado. Otra opción es seleccionar el submenú Move To en el menú de ventanas del marco de la ventana.

ARRASTRAR Y SOLTAR

La barra de tareas soporta operaciones de arrastrar y soltar. Cuando se está realizando un arrastre, la ventana de destino se puede activar colocando el icono de arrastre sobre el botón de la barra de tareas de esa ventana. Alternativamente, el espacio de trabajo actual se puede cambiar colocando el icono de arrastre sobre el botón del espacio de trabajo deseado. Cuando la conmutación de borde está habilitada, el espacio de trabajo actual también se puede cambiar llevando el icono de arrastre al borde de la pantalla.

BARRA DE DIRECCIONES

La barra de tareas contiene una línea de comandos llamada barra de direcciones, si EnableAddressBar=1. Siempre se muestra cuando ShowAddressBar=1, de lo contrario se activa mediante KeySysAddressBar="Alt+Ctrl+space". En ella se puede escribir un comando de shell. Al presionar Enter, se ejecuta mediante AddressBarCommand="/bin/sh". Al presionar Control+Enter, este comando se ejecuta en una nueva terminal como se indica en TerminalCommand. Escape cancela la edición del comando de la barra de direcciones.

Los comandos se ejecutan en relación con el directorio de trabajo de icewm. Esto se muestra con "pwd". Cámbielo con "cd". Sin argumentos, "cd" por defecto es el directorio de inicio. Con un argumento se cambia. Este argumento se expande cuando comienza con un signo de dólar o tilde. Cuando es igual a "-", vuelve al directorio anterior.

La barra de direcciones tiene un historial que se puede navegar con Arriba y Abajo. Este historial se guarda en un archivo ahistory en su directorio de icewm y se restaura cuando se inicia icewm.

Se admite la autocompletación usando Tab o Ctrl+I. El comando inicial se completa a partir de los directorios en su PATH, mientras que los argumentos de archivo se expanden desde la ubicación en el sistema de archivos. Además, también se pueden expandir nombres de usuario y variables de entorno. Por ejemplo, "echo $TMP" y Tab pueden expandirse a "echo $TMPDIR" y "echo ~ro" y Tab pueden expandirse a "echo ~root".

MONITOREO DE BUZÓN DE

CORREO

La barra de tareas puede mostrar uno o más iconos para reflejar el estado de un buzón de correo. El buzón puede ser un archivo local o una cuenta POP o IMAP remota. Para esto se deben establecer algunas opciones. Primero, TaskBarShowMailboxStatus debe estar habilitado, que lo está por defecto. Luego se debe establecer la ubicación del buzón. Icewm primero busca MailBoxPath en las preferencias. Si no está definido, mira las variables de entorno "MAILPATH" y "MAIL". MailBoxPath puede contener una lista de buzones separada por espacios, mientras que "MAILPATH" puede contener una lista de buzones separada por dos puntos. Si un buzón comienza con una barra inclinada "/", entonces es un archivo local, de lo contrario una URL. Estos son seis ejemplos de buzones

posibles: 
file:///var/spool/mail/captnmark
file:///home/captnmark/Maildir/
pop3://markus:%2f%40%3a@maol.ch/
pop3s://markus:password@pop.gmail.com/
imap://mathias@localhost/INBOX.Maillisten.icewm-user
imaps://mathias:password@imap.gmail.
com/INBOX

Los esquemas POP3S e IMAPS usan "openssl" para el cifrado TLS/SSL. Tenga en cuenta que para que IceWM acceda a Gmail, primero debe configurar su cuenta de Gmail para habilitar el acceso POP3 o IMAP. Asegúrese de tener permisos de archivo seguros en su archivo de preferencias de IceWM y en el directorio que lo

contiene.

Los caracteres reservados en la contraseña, como barra inclinada, arroba y dos puntos, pueden especificarse usando secuencias de escape con una codificación hexadecimal como %2f para la barra inclinada o %40 para el signo de arroba. Para controlar los diseños de teclado en la barra de tareas, defina en las preferencias la opción KeyboardLayouts como una lista separada por comas de sus diseños de teclado preferidos. Por

disponibles.

esto.

Este archivo contiene el nombre del tema por defecto. Al arrancar, icewm lee este archivo para obtener el nombre del tema, a menos que icewm se haya iniciado con la opción --theme. Normalmente el archivo del tema es solo default.theme, pero un tema puede tener alternativas. Las alternativas son pequeñas modificaciones de un tema.
