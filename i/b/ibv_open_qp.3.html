IBV_OPEN_QP(3) Manual del programador de Libibverbs IBV_OPEN_QP(3)

NOMBRE

ibv_open_qp - abre un par de colas (QP) compartible

SINOPSIS

#include <infiniband/verbs.h>

struct ibv_qp *ibv_open_qp(struct ibv_context *context,
                           struct ibv_qp_open_attr *qp_open_attr);

DESCRIPCIÓN

ibv_open_qp() abre un par de colas (QP) existente asociado al dominio de protección extendido xrcd. El argumento qp_open_attr es una estructura ibv_qp_open_attr, tal como se define en <infiniband/verbs.h>.

struct ibv_qp_open_attr {
uint32_t          comp_mask;  /* Identifica los campos válidos */
uint32_t          qp_num;     /* Número de QP */
struct            *ibv_xrcd;  /* Dominio XRC */
void             *qp_context; /* Valor opaco definido por el usuario */
enum ibv_qp_type  qp_type;    /* Tipo de servicio de transporte QP */

ibv_destroy_qp() cierra el QP abierto y destruye el QP subyacente si no tiene otras referencias. qp.

VALOR DE RETORNO

ibv_open_qp() devuelve un puntero al QP abierto, o NULL si la solicitud falla. Compruebe el número de QP (qp_num) en el QP devuelto.

NOTAS

ibv_open_qp() fallará si se le pide que abra un QP que no existe dentro del xrcd con el qp_num y qp_type especificados.

VER TAMBIÉN

ibv_alloc_pd(3), ibv_create_qp(3), ibv_create_qp_ex(3), ibv_modify_qp(3), ibv_query_qp(3)
