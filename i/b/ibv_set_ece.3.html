IBV_SET_ECE(3) Manual del programador de Libibverbs IBV_SET_ECE(3)

NOMBRE

ibv_set_ece - establece opciones de ECE y las utiliza para la etapa de configuración de QP.

SINOPSIS

#include <infiniband/verbs.h>
int ibv_set_ece(struct ibv_qp *qp, struct ibv_ece *ece);

DESCRIPCIÓN

ibv_set_ece() establece opciones de ECE y las utiliza para la etapa de configuración de QP.

Las opciones de ECE deseadas se utilizarán durante varias etapas de modificación de QP basándose en las opciones admitidas en el estado de QP relevante.

ARGUMENTOS

qp
El par de colas (QP) asociado con las opciones ECE.
## Argumento ece
Los valores ECE solicitados. Este es un campo DE ENTRADA/SALIDA, las opciones aceptadas se devolverán en este campo.
struct ibv_ece {
    uint32_t vendor_id;
    uint32_t options;
    uint32_t comp_mask;
};
vendor_id
Identificador único del proveedor en la red. Los proveedores establecerán el OUI de IEEE aquí para distinguirse en redes no homogéneas.
options
Atributos específicos del proveedor que son compatibles o que los usuarios de ECE necesitan habilitar.
comp_mask
Máscara de bits que especifica qué campos de la estructura son válidos.

VALOR DE RETORNO

ibv_set_ece() devuelve 0 cuando la llamada fue exitosa, o el valor errno que indica el motivo del fallo.

EOPNOTSUPP
libibverbs o el controlador del proveedor no admite la llamada a ibv_set_ece().
EINVAL
En uno de los siguientes casos: o El QP no es válido. o Las opciones ECE no son válidas.
