IBV_GET_CQ_EVENT(3) Manual del programador de Libibverbs IBV_GET_CQ_EVENT(3)

NOMBRE

ibv_get_cq_event, ibv_ack_cq_events - obtener y acusar recibo de eventos de colas de finalización (CQ)

SINOPSIS

#include <infiniband/verbs.h>

int ibv_get_cq_event(struct ibv_comp_channel *channel,
                     struct ibv_cq **cq, void **cq_context);

void ibv_ack_cq_events(struct ibv_cq *cq, unsigned int nevents);

DESCRIPCIÓN

ibv_get_cq_event() espera el próximo evento de finalización en el canal de eventos de finalización channel. Rellena los argumentos cq con la CQ que recibió el evento y cq_context con el contexto de la CQ.

ibv_ack_cq_events() acusa recibo de nevents eventos en la CQ cq.

VALOR DE RETORNO

ibv_get_cq_event() devuelve 0 si tiene éxito y -1 si hay un error.

ibv_ack_cq_events() no devuelve ningún valor.

NOTAS

Todos los eventos de finalización que devuelve ibv_get_cq_event() deben ser acusados recibo usando ibv_ack_cq_events(). Para evitar condiciones de carrera, la destrucción de una CQ esperará a que se acusen recibo todos los eventos de finalización; esto garantiza una correspondencia uno a uno entre los acuses de recibo y las obtenciones exitosas.

Llamar a ibv_ack_cq_events() puede ser relativamente costoso en el plano de datos, ya que debe adquirir un mutex. Por lo tanto, puede ser mejor amortizar este coste manteniendo un recuento del número de eventos que necesitan acusar recibo y acusar recibo de varios eventos de finalización en una sola llamada a ibv_ack_cq_events().

EJEMPLOS

El siguiente ejemplo de código demuestra una forma posible de trabajar con eventos de finalización. Realiza los siguientes pasos:

Etapa I: Preparación
1. Crea una CQ
2. Solicita notificación ante un nuevo (primer) evento de finalización

Etapa II: Rutina de manejo de finalización
3. Espera el evento de finalización y acúsalo recibo
4. Solicita notificación ante el próximo evento de finalización
5. Vacía la CQ

Tenga en cuenta que puede activarse un evento adicional sin una entrada de finalización correspondiente en la CQ. Esto ocurre si se añade una entrada de finalización a la CQ entre el Paso 4 y el Paso 5, y luego la CQ se vacía (se consulta) en el Paso 5.

cq = ibv_create_cq(ctx, 1, ev_ctx, channel, 0);
if (!cq) {
        fprintf(stderr, "Fallo al crear CQ\n");
        return 1;
}
/* Solicita notificación antes de que se pueda crear ninguna finalización */
if (ibv_req_notify_cq(cq, 0)) {
        fprintf(stderr, "No se pudo solicitar notificación de CQ\n");
        return 1;
}
.
.
.
/* Espera el evento de finalización */
if (ibv_get_cq_event(channel, &ev_cq, &ev_ctx)) {
        fprintf(stderr, "Fallo al obtener cq_event\n");
        return 1;
}
/* Acusa recibo del evento */
ibv_ack_cq_events(ev_cq, 1);
/* Solicita notificación ante el próximo evento de finalización */
if (ibv_req_notify_cq(ev_cq, 0)) {
        fprintf(stderr, "No se pudo solicitar notificación de CQ\n");
        return 1;
}
/* Vacía la CQ: consulta todas las finalizaciones de la CQ (si las hay) */
do {
        ne = ibv_poll_cq(cq, 1, &wc);
        if (ne < 0) {
                fprintf(stderr, "Fallo al consultar finalizaciones de la CQ\n");
                return 1;
        }
        /* puede haber un evento extra sin finalización en la CQ */
        if (ne == 0)
                continue;
        if (wc.status != IBV_WC_SUCCESS) {
                fprintf(stderr, "Se encontró finalización con estado 0x%x\n", wc.status);
                return 1;
        }
} while (ne);

El siguiente ejemplo de código demuestra una forma posible de trabajar con eventos de finalización en modo no bloqueante. Realiza los siguientes pasos:

1. Establece el canal de eventos de finalización en modo no bloqueante
2. Consulta el canal hasta que tenga un evento de finalización
3. Obtiene el evento de finalización y acúsalo recibo

/* cambia el modo de bloqueo del canal de finalización */
flags = fcntl(channel->fd, F_GETFL);
rc = fcntl(channel->fd, F_SETFL, flags | O_NONBLOCK);
if (rc < 0) {
	fprintf(stderr, "Fallo al cambiar el descriptor de archivo del canal de eventos de finalización\n");
	return 1;
}
/*
 * consulta el canal hasta que tenga un evento y duerme ms_timeout
 * milisegundos entre cada iteración
 */
my_pollfd.fd      = channel->fd;
my_pollfd.events  = POLLIN;
my_pollfd.revents = 0;
do {
	rc = poll(&my_pollfd, 1, ms_timeout);
} while (rc == 0);
if (rc < 0) {
	fprintf(stderr, "poll falló\n");
	return 1;
}
ev_cq = cq;
/* Espera el evento de finalización */
if (ibv_get_cq_event(channel, &ev_cq, &ev_ctx)) {
        fprintf(stderr, "Fallo al obtener cq_event\n");
        return 1;
}
/* Acusa recibo del evento */
ibv_ack_cq_events(ev_cq, 1);
