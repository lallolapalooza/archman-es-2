IBV_OPEN_XRCD(3) Manual del programador de Libibverbs IBV_OPEN_XRCD(3)

NOMBRE

ibv_open_xrcd, ibv_close_xrcd - abre o cierra un dominio de protección XRC (XRCDs)

SINOPSIS

#include <infiniband/verbs.h>

struct ibv_xrcd *ibv_open_xrcd(struct ibv_context *context,
                               struct ibv_xrcd_init_attr *xrcd_init_attr);

int ibv_close_xrcd(struct ibv_xrcd *xrcd);

DESCRIPCIÓN

ibv_open_xrcd() abre un dominio XRC para el contexto del dispositivo RDMA context. xrcd_init_attr es una estructura ibv_xrcd_init_attr, como se define en <infiniband/verbs.h>.

struct ibv_xrcd_init_attr {
uint32_t         comp_mask;  /* Identifica los campos válidos */
int              fd;
int              oflag;

fd es el descriptor de archivo a asociar con el XRCD. oflag describe los atributos de creación deseados. Es una OR bit a bit de cero o más de las siguientes banderas:

O_CREAT
Indica que se debe crear un XRCD y asociarlo con el inodo referenciado por el fd dado. Si el XRCD existe, esta bandera no tiene efecto excepto como se indica en O_EXCL más abajo.
O_EXCL
Si O_EXCL y O_CREAT están establecidos, la apertura fallará si existe un XRCD asociado con el inodo.

Si fd es igual a -1, no se asocia ningún inodo con el XRCD. Para indicar que el XRCD debe crearse, utilice oflag = O_CREAT.

ibv_close_xrcd() cierra el XRCD xrcd. Si esta es la última referencia, el XRCD se destruirá.

VALOR DE RETORNO

ibv_open_xrcd() devuelve un puntero al XRCD abierto, o NULL si la solicitud falla.

ibv_close_xrcd() devuelve 0 si tiene éxito, o el valor de errno en caso de fallo (que indica la razón del fallo).

NOTAS

ibv_close_xrcd() puede fallar si algún otro recurso todavía está asociado con el XRCD que se está cerrando.
