IBV_UD_PINGPONG(1) COMANDOS DE USUARIO IBV_UD_PINGPONG(1)

NOMBRE

ibv_ud_pingpong - prueba simple de transporte UD de InfiniBand

SINOPSIS

ibv_ud_pingpong [-p puerto] [-d dispositivo] [-i puerto_ib] [-s tamaño] [-r profundidad_rx] [-n iteraciones] [-l sl] [-e] [-g indice_gid HOSTNAME

ibv_ud_pingpong [-p puerto] [-d dispositivo] [-i puerto_ib] [-s tamaño] [-r profundidad_rx] [-n iteraciones] [-l sl] [-e] [-g indice_gid]

DESCRIPCIÓN

Ejecuta una prueba simple de ping-pong a través de InfiniBand usando el transporte de datagramas no fiables (UD).

OPCIONES

-p, --port=PUERTO
usa el puerto TCP PUERTO para la sincronización inicial (predeterminado 18515)
-d, --ib-dev=DISPOSITIVO
usa el dispositivo IB DISPOSITIVO (predeterminado el primer dispositivo encontrado)
-i, --ib-port=PUERTO
usa el puerto IB PUERTO (puerto predeterminado 1)
-s, --size=TAMAÑO
mensajes de ping-pong de tamaño TAMAÑO (predeterminado 2048)
-r, --rx-depth=PROFUNDIDAD
publica PROFUNDIDAD recepciones a la vez (predeterminado 500)
-n, --iters=ITERACIONES
realiza ITERACIONES intercambios de mensajes (predeterminado 1000)
-l, --sl=SL
envía mensajes con nivel de servicio SL (predeterminado 0)
-e, --events
duerme mientras espera eventos de finalización de trabajo (el valor predeterminado es sonder las terminaciones)
-g, --gid-idx=INDICE_GID
puerto local INDICE_GID
-c, --chk
valida el buffer recibido

VER TAMBIÉN

ibv_rc_pingpong(1), ibv_uc_pingpong(1), ibv_srq_pingpong(1), ibv_xsrq_pingpong(1)

ERRORES

La sincronización de red entre las instancias cliente y servidor es débil y no impide el uso de opciones incompatibles en las dos instancias. El método utilizado para recuperar las finalizaciones de trabajo no es estrictamente correcto y las condiciones de carrera pueden causar fallos en algunos sistemas.
