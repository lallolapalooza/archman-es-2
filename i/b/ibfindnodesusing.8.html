ibfindnodesusing(8) Diagnósticos Open IB ibfindnodesusing(8)

Nombre

ibfindnodesusing - encuentra una lista de nodos finales que se enrutan a través del switch y puerto especificados

SINÓPSIS

ibfindnodesusing.pl [opciones] <guid_del_switch|nombre_del_switch> <puerto>

DESCRIPCIÓN

ibfindnodesusing.pl utiliza ibroute y detecta los nodos actuales que se enrutan a través de ambas direcciones del enlace especificado. El enlace se especifica por un extremo de puerto de switch; el script encuentra el extremo remoto automáticamente.

OPCIONES

-h
mostrar ayuda
-R
Recalcular la información de ibnetdiscover, es decir, no utilizar la información en caché. Esta opción es más lenta, pero debe usarse si las herramientas de diagnóstico no se han utilizado durante algún tiempo o si hay otras razones para creer que la red ha cambiado.

-C <nombre_de_ca> utiliza el nombre_de_ca especificado.

-P <puerto_de_ca> utiliza el puerto_de_ca especificado.

ARCHIVOS

ARCHIVO DE CONFIGURACIÓN

/etc/infiniband-diags/ibdiag.conf

Se proporciona un archivo de configuración global para establecer algunas de las opciones comunes para todas las herramientas. Consulte el archivo de configuración proporcionado para obtener detalles.

FORMATO DEL ARCHIVO DE MAPA DE NOMBRES DE NODOS

El mapa de nombres de nodos se utiliza para especificar nombres fáciles de usar para los nodos en la salida. Los GUID se utilizan para realizar la búsqueda.

Esta funcionalidad la proporciona el paquete opensm-libs. Consulte opensm(8) para conocer la ubicación del archivo para su instalación.

Genéricamente:

# comentario
<guid> "<nombre>"

Ejemplo:

# Tarjetas de línea
0x0008f104003f125c "IB1 (Rack 11 slot 1   ) ISR9288/ISR9096 Voltaire sLB-24D"
0x0008f104003f125d "IB1 (Rack 11 slot 1   ) ISR9288/ISR9096 Voltaire sLB-24D"
0x0008f104003f10d2 "IB1 (Rack 11 slot 2   ) ISR9288/ISR9096 Voltaire sLB-24D"
0x0008f104003f10d3 "IB1 (Rack 11 slot 2   ) ISR9288/ISR9096 Voltaire sLB-24D"
0x0008f104003f10bf "IB1 (Rack 11 slot 12  ) ISR9288/ISR9096 Voltaire sLB-24D"
# Spines
0x0008f10400400e2d "IB1 (Rack 11 spine 1   ) ISR9288 Voltaire sFB-12D"
0x0008f10400400e2e "IB1 (Rack 11 spine 1   ) ISR9288 Voltaire sFB-12D"
0x0008f10400400e2f "IB1 (Rack 11 spine 1   ) ISR9288 Voltaire sFB-12D"
0x0008f10400400e31 "IB1 (Rack 11 spine 2   ) ISR9288 Voltaire sFB-12D"
0x0008f10400400e32 "IB1 (Rack 11 spine 2   ) ISR9288 Voltaire sFB-12D"
# GUID   Nombre del nodo
0x0008f10400411a08 "SW1  (Rack  3) ISR9024 Voltaire 9024D"
