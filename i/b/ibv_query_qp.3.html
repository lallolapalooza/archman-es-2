IBV_QUERY_QP(3) Manual del programador de Libibverbs IBV_QUERY_QP(3)

NOMBRE

ibv_query_qp - obtener los atributos de un par de colas (QP)

SINOPSIS

#include <infiniband/verbs.h>

int ibv_query_qp(struct ibv_qp *qp, struct ibv_qp_attr *attr,
                 int attr_mask,
                 struct ibv_qp_init_attr *init_attr);

DESCRIPCIÓN

ibv_query_qp() obtiene los atributos especificados en attr_mask para el QP qp y los devuelve a través de los punteros attr y init_attr. El argumento attr es una estructura ibv_qp_attr, tal como se define en <infiniband/verbs.h>.

struct ibv_qp_attr {
enum ibv_qp_state       qp_state;            /* Estado actual del QP */
enum ibv_qp_state       cur_qp_state;        /* Estado actual del QP - irrelevante para ibv_query_qp */
enum ibv_mtu            path_mtu;            /* MTU de la ruta (solo válido para QPs RC/UC) */
enum ibv_mig_state      path_mig_state;      /* Estado de migración de ruta (válido si HCA soporta APM) */
uint32_t                qkey;                /* Q_Key del QP (solo válido para QPs UD) */
uint32_t                rq_psn;              /* PSN para la cola de recepción (solo válido para QPs RC/UC) */
uint32_t                sq_psn;              /* PSN para la cola de envío */
uint32_t                dest_qp_num;         /* Número del QP de destino (solo válido para QPs RC/UC) */
unsigned int            qp_access_flags;     /* Máscara de operaciones de acceso remoto habilitadas (solo válido para QPs RC/UC) */
struct ibv_qp_cap       cap;                 /* Capacidades del QP */
struct ibv_ah_attr      ah_attr;             /* Vector de direcciones de la ruta primaria (solo válido para QPs RC/UC) */
struct ibv_ah_attr      alt_ah_attr;         /* Vector de direcciones de la ruta alternativa (solo válido para QPs RC/UC) */
uint16_t                pkey_index;          /* Índice P_Key primario */
uint16_t                alt_pkey_index;      /* Índice P_Key alternativo */
uint8_t                 en_sqd_async_notify; /* Habilitar notificación asíncrona de SQD drenada - irrelevante para ibv_query_qp */
uint8_t                 sq_draining;         /* ¿Está el QP drenándose? (Solo válido si qp_state es SQD) */
uint8_t                 max_rd_atomic;       /* Número de lecturas RDMA y operaciones atómicas pendientes en el QP de destino (solo válido para QPs RC) */
uint8_t                 max_dest_rd_atomic;  /* Número de recursos de respondedor para manejar lecturas RDMA y operaciones atómicas entrantes (solo válido para QPs RC) */
uint8_t                 min_rnr_timer;       /* Temporizador mínimo NAK RNR (solo válido para QPs RC) */
uint8_t                 port_num;            /* Número de puerto primario */
uint8_t                 timeout;             /* Temporizador de acuse de recibo local para la ruta primaria (solo válido para QPs RC) */
uint8_t                 retry_cnt;           /* Contador de reintentos (solo válido para QPs RC) */
uint8_t                 rnr_retry;           /* Reintento RNR (solo válido para QPs RC) */
uint8_t                 alt_port_num;        /* Número de puerto alternativo */
uint8_t                 alt_timeout;         /* Temporizador de acuse de recibo local para la ruta alternativa (solo válido para QPs RC) */
};

Para obtener detalles sobre la estructura ibv_qp_cap, consulte la descripción de ibv_create_qp(). Para obtener detalles sobre la estructura ibv_ah_attr, consulte la descripción de ibv_create_ah().

VALOR DE RETORNO

ibv_query_qp() devuelve 0 si tiene éxito, o el valor de errno en caso de fallo (que indica la razón del fallo).

NOTAS

El argumento attr_mask es una pista que especifica la lista mínima de atributos a recuperar. Algunos dispositivos RDMA pueden devolver atributos adicionales no solicitados, por ejemplo, si el valor puede devolverse de forma económica. Esto tiene el mismo formato que en ibv_modify_qp().

Los valores de los atributos son válidos si se han establecido mediante ibv_modify_qp(). La lista exacta de atributos válidos depende del estado del QP.

Múltiples llamadas a ibv_query_qp() pueden producir algunas diferencias en los valores devueltos para los siguientes atributos: qp_state, path_mig_state, sq_draining, ah_attr (si APM está habilitado).

VER TAMBIÉN

ibv_create_qp(3), ibv_destroy_qp(3), ibv_modify_qp(3), ibv_create_ah(3)
