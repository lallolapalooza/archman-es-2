ibv_alloc_null_mr(3) Manual del programador de Libibverbs ibv_alloc_null_mr(3)

NOMBRE

ibv_alloc_null_mr - asignar una región de memoria nula (MR)

SINOPSIS

#include <infiniband/verbs.h>
struct ibv_mr *ibv_alloc_null_mr(struct ibv_pd *pd);

DESCRIPCIÓN

ibv_alloc_null_mr() asigna una región de memoria nula (MR) que está asociada con el dominio de protección pd.

Una MR nula descarta todos los datos escritos en ella y siempre devuelve 0 en lectura. Tiene la longitud máxima y solo el lkey es válido, la MR no se expone como un rkey.

Un dispositivo debe implementar la MR nula de manera que omita las transferencias PCI, descartando internamente datos o generando 0 datos. Esto proporciona una forma de evitar transferencias del bus PCI utilizando una lista de dispersión/agrupación en los comandos si las aplicaciones no tienen la intención de acceder a los datos o necesitan que los datos se rellenen con 0.

Específicamente, tras ibv_post_send(), el dispositivo omite los ciclos de lectura PCI y tras ibv_post_recv(), el dispositivo omite los ciclos de escritura PCI, lo que finalmente mejora el rendimiento.

ibv_dereg_mr() desregistra la MR. El uso de ibv_rereg_mr() o ibv_bind_mw() con esta MR no es válido.

VALOR DEVUELTO

ibv_alloc_null_mr() devuelve un puntero a la MR asignada, o NULL si la solicitud falla.

VER TAMBIÉN

ibv_reg_mr(3), ibv_dereg_mr(3),
