DESCRIPCIÓ

N

ibv_post_send() publica la lista enlazada de solicitudes de trabajo (WRs) que comienza con wr en la cola de envío del par de colas qp. Detiene el procesamiento de las WRs de esta lista en el primer fallo (que puede detectarse inmediatamente mientras se publican las solicitudes) y devuelve esta WR fallida a través de bad_wr

.

El argumento wr es una estructura ibv_send_wr, tal como se define en <infiniband/verbs.h>

. 
struct ibv_send_wr {
uint64_t                wr_id;                  /* ID de WR definido por el usuario */
struct ibv_send_wr     *next;                   /* Puntero a la siguiente WR en la lista, NULL si es la última WR */
struct ibv_sge         *sg_list;                /* Puntero al array s/g */
int                     num_sge;                /* Tamaño del array s/g */
enum ibv_wr_opcode      opcode;                 /* Tipo de operación */
unsigned int            send_flags;             /* Banderas de las propiedades de la WR */
union {
__be32                  imm_data;               /* Datos inmediatos (en orden de bytes de red) */
uint32_t                invalidate_rkey;        /* Rkey remoto a invalidar */
};
union {
struct {
uint64_t        remote_addr;    /* Dirección de inicio del búfer de memoria remoto */
uint32_t        rkey;           /* Clave de la Región de Memoria remota */
} rdma;
struct {
uint64_t        remote_addr;    /* Dirección de inicio del búfer de memoria remoto */
uint64_t        compare_add;    /* Operando de comparación */
uint64_t        swap;           /* Operando de intercambio */
uint32_t        rkey;           /* Clave de la Región de Memoria remota */
} atomic;
struct {
struct ibv_ah  *ah;             /* Manipulador de dirección (AH) para la dirección del nodo remoto */
uint32_t        remote_qpn;     /* Número de QP de la QP de destino */
uint32_t        remote_qkey;    /* Número de Q_Key de la QP de destino */
} ud;
} wr;
union {
struct {
uint32_t remote_srqn;            /* Número del SRQ remoto */
} xrc;
} qp_type;
union {
struct {
struct ibv_mw            *mw;             /* Ventana de memoria (MW) de tipo 2 a enlazar */
uint32_t                 rkey;            /* El nuevo rkey deseado de la MW */
struct ibv_mw_bind_info  bind_info;       /* Información adicional de enlace de la MW */
} bind_mw;
struct {
void			*hdr;	/* Dirección de puntero del encabezado en línea */
uint16_t		hdr_sz;	/* Tamaño del encabezado en línea */
uint16_t		mss;	/* Tamaño máximo de segmento para cada fragmento TSO */
} tso;
};
}
; 
struct ibv_mw_bind_info {
struct ibv_mr            *mr;             /* La Región de memoria (MR) a la que enlazar la MW */
uint64_t                 addr;           /* La dirección en la que la MW debería comenzar */
uint64_t                 length;          /* La longitud (en bytes) que la MW debería abarcar */
unsigned int             mw_access_flags; /* Banderas de acceso a la MW. Utilice ibv_access_flags */
}
; 
struct ibv_sge {
uint64_t                addr;                   /* Dirección de inicio del búfer de memoria local o número de bytes desde el
                                                   inicio de la MR para MRs que son IBV_ACCESS_ZERO_BASED */
uint32_t                length;                 /* Longitud del búfer */
uint32_t                lkey;                   /* Clave de la Región de memoria local */
}
;

El atributo send_flags describe las propiedades de la WR. Es 0 o el OR bit a bit de uno o más de los siguientes

indicadores:
IBV_SEND_FENCE Establece el indicador de valla. Válido solo para QPs con Tipo de Servicio de Transporte IBV_QPT_
RC
IBV_SEND_SIGNALED Establece el indicador de notificación de finalización. Relevante solo si la QP fue creada con
sq_sig_all=0
IBV_SEND_SOLICITED Establece el indicador de evento solicitado. Válido solo para Envío y Escritura RDMA con
inmediato
IBV_SEND_INLINE Envía los datos de la lista de recopilación dada como datos en
línea
en un WQE de envío. Válido solo para Envío y Escritura RDMA. La L_Key no será
comprobada.
IBV_SEND_IP_CSUM Descarga el cálculo de la suma de comprobación de IPv4 y
TCP/UDP.
Válido solo cuando device_cap_flags en device_attr indica que la
QP actual es compa
tible con la descarga d
e suma de comprobación.

VALOR DE

RETORNO

ibv_post_send() devuelve 0 en caso de éxito, o el valor de err

no en caso de fallo (lo cu
al indica el motivo del fallo).

NOTA

S

El usuario no debe alterar ni destruir los AHs asociados con las WRs hasta que la solicitud se haya ejecutado completamente y se haya recuperado una finalización de trabajo de la cola de finalización (CQ) correspondiente para evitar un comportamiento

inesperado.

Los búfers utilizados por una WR solo pueden reutilizarse de forma segura después de que la solicitud de la WR se haya ejecutado completamente y se haya recuperado una finalización de trabajo de la cola de finalización (CQ) correspondiente. Sin embargo, si se estableció la bandera IBV_SEND_INLINE, el búfer puede reutilizarse inmediatamente después de que la llamada

retorne.

IBV_WR_DRIVER1 es un código de operació

n que debe utilizarse para emitir una
operación específica del controlador.
