    ibase64buf(3bobcat)

    ibase64buf - decodifica un buffer de entrada en base64.

    SYNOPSIS

    int ibase64buf(const char *in, size_t inlen, char *out, size_t outlen);

    DESCRIPTION

    La función ibase64buf decodifica un buffer de entrada de longitud inlen, que contiene datos codificados en base64 en in, a un buffer de salida de longitud outlen en out.

    La función devuelve el número de bytes escritos en out o -1 en caso de error.

    Si el buffer de salida es demasiado pequeño, se truncará la salida y la función devolverá el número de bytes que se esperaría que hubieran sido escritos en un buffer suficientemente grande. En este caso, la variable global errno se establecerá en ENOSPC.

    Si los datos de entrada no son válidos para la codificación base64 (por ejemplo, caracteres no válidos o relleno incorrecto), la función devolverá -1 y establecerá errno en EINVAL.

    OPTIONS

    No hay opciones disponibles para esta función.

    EXAMPLE

    #include <bobcat/ibase64buf>
#include <stdio.h>
#include <string.h>
#include <errno.h>

int main()
{
    const char *encoded = "SGVsbG8sIFdvcmxkIQ=="; // "Hello, World!"
    char decoded[100];
    int ret;

    ret = ibase64buf(encoded, strlen(encoded), decoded, sizeof(decoded));
    if (ret < 0)
    {
        perror("ibase64buf");
        return 1;
    }

    printf("Decodificado: %.*s\n", ret, decoded);
    return 0;
}
