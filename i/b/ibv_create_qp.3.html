IBV_CREATE_QP(3) Manual del programador de Libibverbs IBV_CREATE_QP(3)

NOMBRE

ibv_create_qp, ibv_destroy_qp - crear o destruir un par de colas (QP)

SINOPSIS

#include <infiniband/verbs.h>

struct ibv_qp *ibv_create_qp(struct ibv_pd *pd,
                             struct ibv_qp_init_attr *qp_init_attr);

int ibv_destroy_qp(struct ibv_qp *qp);

DESCRIPCIÓN

ibv_create_qp() crea un par de colas (QP) asociado al dominio de protección pd. El argumento qp_init_attr es una struct ibv_qp_init_attr, como se define en <infiniband/verbs.h>.

struct ibv_qp_init_attr {
void                   *qp_context;     /* Contexto asociado del QP */
struct ibv_cq          *send_cq;        /* CQ a asociar con la Cola de Envío (SQ) */ 
struct ibv_cq          *recv_cq;        /* CQ a asociar con la Cola de Recepción (RQ) */
struct ibv_srq         *srq;            /* Handle SRQ si el QP se va a asociar con un SRQ, de lo contrario NULL */
struct ibv_qp_cap       cap;            /* Capacidades del QP */
enum ibv_qp_type        qp_type;        /* Tipo de Servicio de Transporte del QP: IBV_QPT_RC, IBV_QPT_UC, IBV_QPT_UD, IBV_QPT_RAW_PACKET o IBV_QPT_DRIVER */
int                     sq_sig_all;     /* Si está configurado, cada Solicitud de Trabajo (WR) enviada a la SQ genera una entrada de finalización */
};
struct ibv_qp_cap {
uint32_t                max_send_wr;    /* Número máximo solicitado de WR pendientes en la SQ */
uint32_t                max_recv_wr;    /* Número máximo solicitado de WR pendientes en la RQ */
uint32_t                max_send_sge;   /* Número máximo solicitado de elementos scatter/gather (s/g) en un WR en la SQ */
uint32_t                max_recv_sge;   /* Número máximo solicitado de elementos s/g en un WR en la RQ */
uint32_t                max_inline_data;/* Número máximo de datos (bytes) solicitados que se pueden publicar en línea en la SQ, de lo contrario 0 */
};

La función ibv_create_qp() actualizará la struct qp_init_attr->cap con los valores reales del QP que se creó; los valores serán mayores o iguales a los valores solicitados.

ibv_destroy_qp() destruye el QP qp.

VALOR DE RETORNO

ibv_create_qp() devuelve un puntero al QP creado, o NULL si la solicitud falla. Compruebe el número de QP (qp_num) en el QP devuelto.

ibv_destroy_qp() devuelve 0 si tiene éxito, o el valor de errno si falla (lo que indica el motivo del fallo).

NOTAS

ibv_create_qp() fallará si se le pide que cree un QP de un tipo distinto de IBV_QPT_RC o IBV_QPT_UD asociado con un SRQ.

Los atributos max_recv_wr y max_recv_sge son ignorados por ibv_create_qp() si el QP se va a asociar con un SRQ.

ibv_destroy_qp() falla si el QP está adjunto a un grupo de multicast.

IBV_QPT_DRIVER no representa un servicio específico y se utiliza para la lógica de QP específica del proveedor.

VER TAMBIÉN

ibv_alloc_pd(3), ibv_modify_qp(3), ibv_query_qp(3)
