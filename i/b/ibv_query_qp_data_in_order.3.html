NOMBRE

ibv_query_qp_data_in_order - comprueba si los datos del qp están garantizados en orden.

SINOPSIS

#include <infiniband/verbs.h>
int ibv_query_qp_data_in_order(struct ibv_qp *qp, enum ibv_wr_opcode op, uint32_t flags);

DESCRIPCIÓN

ibv_query_qp_data_in_order() Comprueba si los datos de WQE están garantizados para ser escritos en orden, y por lo tanto el lector puede consultar por datos en lugar de consultar por finalización. Esta función indica que los datos se escriben en orden dentro de cada WQE, pero no puede usarse para determinar el orden entre WQE separados. Esta función describe el orden en el lado de recepción del QP, no en el lado de envío.

ARGUMENTOS

qp
El par de colas (QP) local a consultar.
op
El tipo de operación sobre la que consultar. Diferentes tipos de operación pueden escribir datos en un orden diferente.
Para operaciones de lectura RDMA: describe el orden de las lecturas RDMA publicadas en este QP local. Para operaciones de escritura RDMA: describe el orden de las escrituras RDMA remotas que se realizan en este QP local. Para operaciones de envío RDMA: describe el orden de los envíos RDMA remotos que se realizan en este QP local. Esta función no debe utilizarse para determinar el orden de otros tipos de operación.
flags
Los flags se utilizan para seleccionar un tipo de consulta. Valores admitidos:

IBV_QUERY_QP_DATA_IN_ORDER_RETURN_CAPS - Consulta las capacidades admitidas y devuelve un vector de capacidades.

IBV_QUERY_QP_DATA_IN_ORDER_DEVICE_ONLY - Permite consultar solo el soporte del lado del dispositivo RDMA para semánticas de datos en orden sin imponer restricciones de arquitectura de CPU del host. Es responsabilidad de la aplicación garantizar el soporte de semánticas de datos en orden para la CPU del host o el dispositivo receptor.

Pasar 0 es equivalente a usar IBV_QUERY_QP_DATA_IN_ORDER_RETURN_CAPS y comprobar si se admite IBV_QUERY_QP_DATA_IN_ORDER_WHOLE_MSG.

VALOR DE RETORNO

El valor de retorno de ibv_query_qp_data_in_order() viene determinado por los flags. Por cada bit de capacidad, se devuelve 1 si los datos están garantizados para ser escritos en orden para la operación y tipo seleccionados, 0 en caso contrario. Si se utiliza el flag IBV_QUERY_QP_DATA_IN_ORDER_RETURN_CAPS, el valor de retorno puede constar de las siguientes capacidades:

IBV_QUERY_QP_DATA_IN_ORDER_WHOLE_MSG - Todos los datos se están escribiendo en orden.

IBV_QUERY_QP_DATA_IN_ORDER_ALIGNED_128_BYTES - Cada bloque alineado de 128 bytes se está escribiendo en orden.

Si flags es 0, la función devolverá 1 si IBV_QUERY_QP_DATA_IN_ORDER_WHOLE_MSG es compatible y 0 en caso contrario.

NOTAS

El valor de retorno solo es válido cuando los datos son leídos por la CPU y la memoria de orden relajado no es el destino de la transferencia.
