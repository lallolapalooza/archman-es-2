NOMBRE

ibus-table-createdb - crear base de datos ibus-table desde fuente de tabla

SINOPSIS

ibus-table-createdb [ -n nombre | --nombre nombre ] [ -s fuente | --fuente fuente ] [ -e extra | --extra extra ] [ -p pinyin | --pinyin pinyin ] [ -o ] [ --no-create-index ] [ -i ] [ --create-index-only ] [ -d ] [ --debug ]

DESCRIPCIÓN

ibus-table-createdb crea una base de datos para ibus-table a partir de una tabla fuente.

OPCIONES

Este programa sigue la sintaxis habitual de línea de comandos de GNU, con opciones largas que comienzan con dos guiones (`-'). A continuación se incluye un resumen de las opciones.

-n --nombre archivo-base-de-datos
archivo-base-de-datos especifica el nombre del archivo para la base de datos binaria para el IME. El valor por defecto es ''. Si no se especifica el nombre del archivo de la base de datos, se añadirá '.db' al nombre del archivo fuente antes del primer '.' y se utilizará como nombre de archivo de la base de datos.
-s --fuente archivo-fuente
archivo-fuente especifica el archivo que contiene la fuente del IME. El valor por defecto es ''.
-e --extra archivo-palabras-extra
archivo-palabras-extra especifica el nombre del archivo para las palabras extra para el IME. El valor por defecto es ''.
-p --pinyin archivo-pinyin
archivo-pinyin especifica el archivo fuente para el pinyin. El valor por defecto es '/usr/share/ibus-table/data/pinyin_table.txt.bz2'.
-o --no-create-index
No crear un índice para una base de datos (Solo para fines de distribución, ¡un usuario normal no debería usar esta bandera!).
-i --create-index-only
Solo crear un índice para una base de datos existente. Es necesario especificar el nombre del archivo de la base de datos binaria con la opción -n o --nombre cuando se utiliza esta opción.
-d --debug
Imprimir mensajes de depuración adicionales.

EJEMPLOS

ibus-table-createdb -n ipa-x-sampa.db -s ipa-x-sampa.txt
Crear la base de datos binaria ``ipa-x-sampa.db'' a partir del archivo fuente ``ipa-x-sampa.txt''.
ibus-table-createdb -i -n ipa-x-sampa.db
Crear un índice para la base de datos ``ipa-x-sampa.db''.
