IBV_MODIFY_CQ(3) Manual del programador de Libibverbs IBV_MODIFY_CQ(3)

NOMBRE

ibv_modify_cq - modificar una cola de finalización (CQ)

SINOPSIS

#include <infiniband/verbs.h>

int ibv_modify_cq(struct ibv_cq *cq, struct ibv_modify_cq_attr *cq_attr);

DESCRIPCIÓN

ibv_modify_cq() modifica una CQ cq. El argumento cq_attr es una estructura ibv_modify_cq_attr, como se define en <infiniband/verbs.h>.

struct ibv_moderate_cq {
uint16_t cq_count;  /* número de finalizaciones por evento */
uint16_t cq_period; /* en microsegundos */
};
struct ibv_modify_cq_attr {
	uint32_t attr_mask;
	struct ibv_moderate_cq moderate;
};

La función ibv_modify_cq() modificará la CQ, basándose en el cq_attr->attr_mask dado

VALOR DE RETORNO

devuelve 0 si tiene éxito, o el valor de errno en caso de error (que indica la razón del fallo).

VER TAMBIÉN

ibv_create_cq(3)
