NOMBRE

IBUS - archivo de base de datos dconf para IBus

SINOPSIS

/etc/dconf/db/ibus

DESCRIPCIÓN

IBus es un Bus de Entrada Inteligente. Es un nuevo framework de entrada para el sistema operativo Linux. Proporciona una interfaz de usuario de método de entrada completa y fácil de usar. También puede ayudar a los desarrolladores a desarrollar métodos de entrada fácilmente.

/etc/dconf/db/ibus es un archivo de base de datos de dconf y guarda la configuración predeterminada de IBus. Puede ser generado a partir de /etc/dconf/db/ibus.d/00-upstream-settings por el comando dconf update con privilegios de escritura en /etc/dconf/db. Las claves y valores guardados pueden ser leídos por el comando dconf.

env DCONF_PROFILE=ibus dconf list /desktop/ibus/

ERRORES

Si encuentra un error, por favor repórtelo en https://github.com/ibus/ibus/issues

VER TAMBIÉN
