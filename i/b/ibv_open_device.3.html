IBV_OPEN_DEVICE(3) Manual del programador de Libibverbs IBV_OPEN_DEVICE(3)

NOMBRE

ibv_open_device, ibv_close_device - abrir y cerrar un contexto de dispositivo RDMA

SINOPSIS

#include <infiniband/verbs.h>

struct ibv_context *ibv_open_device(struct ibv_device *device);

int ibv_close_device(struct ibv_context *context);

DESCRIPCIÓN

ibv_open_device() abre el dispositivo device y crea un contexto para su uso posterior.

ibv_close_device() cierra el contexto del dispositivo context.

VALOR DE RETORNO

ibv_open_device() devuelve un puntero al contexto del dispositivo asignado, o NULL si la solicitud falla.

ibv_close_device() devuelve 0 si tiene éxito, -1 si falla.

NOTAS

ibv_close_device() no libera todos los recursos asignados usando el contexto context. Para evitar fugas de recursos, el usuario debe liberar todos los recursos asociados antes de cerrar un contexto.

Establecer la variable de entorno **RDMAV_ALLOW_DISASSOC_DESTROY** indica a la biblioteca que relacione un EIO de los comandos de destrucción como un éxito, ya que los recursos del kernel ya fueron liberados. Esto es para evitar fugas de memoria en el área del espacio de usuario al desasociar el dispositivo. Las aplicaciones que utilizan esta bandera no pueden llamar a ibv_get_cq_event o ibv_get_async_event concurrentemente con ninguna llamada a una función de destrucción de objetos.
