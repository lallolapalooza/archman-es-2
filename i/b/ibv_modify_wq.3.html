IBV_MODIFY_WQ(3) Manual del programador de Libibverbs IBV_MODIFY_WQ(3)

NOMBRE

ibv_modify_wq - Modificar una Cola de Trabajo (WQ).

SINOPSIS

#include <infiniband/verbs.h>

struct int ibv_modify_wq(struct ibv_wq *wq,
                             struct ibv_wq_attr *wq_attr);

DESCRIPCIÓN

ibv_modify_wq() modifica una WQ wq. El argumento wq_attr es una estructura ibv_wq_attr, como se define en <infiniband/verbs.h>.

struct ibv_wq_attr {
uint32_t                attr_mask;     /* Usar enum ibv_wq_attr_mask */
enum ibv_wq_state       wq_state;      /* Mover a este estado */
enum ibv_wq_state       curr_wq_state; /* Asumir que este es el estado actual */
uint32_t                flags;         /* Valores de flags a modificar, usar enum ibv_wq_flags */
uint32_t                flags_mask;    /* Qué flags modificar, usar enum ibv_wq_flags */
};

La función ibv_modify_wq() modificará la WQ basándose en la wq_attr->attr_mask dada.

VALOR DE RETORNO

Devuelve 0 si tiene éxito, o el valor de errno en caso de fallo (que indica la razón del fallo).

VER TAMBIÉN

ibv_create_wq(3), ibv_destroy_wq(3),
