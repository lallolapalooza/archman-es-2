IBHOSTS(8) Diagnósticos de InfiniBand IBHOSTS(8)

Nombre

IBHOSTS - muestra los nodos de host InfiniBand en la topología

SINOPSIS

ibhosts [opciones] [<archivo-topología>]

DESCRIPCIÓN

ibhosts es un script que recorre la topología de la subred IB o utiliza un archivo de topología ya guardado y extrae los nodos de CA.

OPCIONES

-C, --Ca <nombre_ca> usa el nombre_ca especificado.

-P, --Port <puerto_ca> usa el puerto_ca especificado.

-t, --timeout <timeout_ms> anula el tiempo de espera predeterminado para los MAD solicitados.

-y, --m_key <clave>
usa la clave M especificada para las solicitudes. Si se especifica un valor no numérico (como 'x'), se le pedirá el valor.

-h, --help muestra el mensaje de uso

--config, -z <archivo_config> especifica un archivo de configuración alternativo.

Predeterminado: /etc/infiniband-diags/ibdiag.conf

Selección del puerto local

Soporte para múltiples puertos/múltiples CA: cuando no se especifica ningún dispositivo o puerto IB (consulte los "parámetros umad locales" a continuación), la biblioteca libibumad selecciona el puerto a utilizar según los siguientes criterios:

1.
el primer puerto que está ACTIVO.
2.
si no se encuentra, el primer puerto que está ARRIBA (enlace físico arriba).

Si se especifica un nombre de puerto y/o CA, la biblioteca libibumad intenta cumplir la solicitud del usuario y fallará si no es posible.

Por ejemplo:

ibaddr                 # usa el primer puerto (criterio #1 anterior)
ibaddr -C mthca1       # elige el mejor puerto solo de "mthca1".
ibaddr -P 2            # usa el segundo puerto (activo/arriba) del primer dispositivo IB disponible.
ibaddr -C mthca0 -P 2  # usa solo el puerto especificado.

ARCHIVOS

ARCHIVO DE CONFIGURACIÓN

/etc/infiniband-diags/ibdiag.conf

Se proporciona un archivo de configuración global para establecer algunas de las opciones comunes para todas las herramientas. Consulte el archivo de configuración proporcionado para obtener más detalles.

FORMATO DEL ARCHIVO DE MAPA DE NOMBRES DE NODOS

El mapa de nombres de nodos se utiliza para especificar nombres amigables para los nodos en la salida. Las GUID se utilizan para realizar la búsqueda.

Esta funcionalidad la proporciona el paquete opensm-libs. Consulte opensm(8) para conocer la ubicación del archivo en su instalación.

Genéricamente:

# comentario
<guid> "<nombre>"

Ejemplo:
