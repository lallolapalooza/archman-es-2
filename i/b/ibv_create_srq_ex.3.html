IBV_CREATE_SRQ_EX(3) Manual del programador de Libibverbs IBV_CREATE_SRQ_EX(3)

NOMBRE

ibv_create_srq_ex, ibv_destroy_srq - crear o destruir una cola de recepción compartida (SRQ)

SINOPSIS

#include <infiniband/verbs.h>

struct ibv_srq *ibv_create_srq_ex(struct ibv_context *context, struct 
                               ibv_srq_init_attr_ex *srq_init_attr_ex);

int ibv_destroy_srq(struct ibv_srq *srq);

DESCRIPCIÓN

ibv_create_srq_ex() crea una cola de recepción compartida (SRQ) que soporta modos básicos y xrc. El argumento srq_init_attr_ex es una estructura ibv_srq_init_attr_ex, tal como se define en <infiniband/verbs.h>.

struct ibv_srq_init_attr_ex {
void                   *srq_context;    /* Contexto asociado del SRQ */
struct ibv_srq_attr     attr;           /* Atributos del SRQ */
uint32_t                comp_mask;      /* Identifica los campos válidos */
enum ibv_srq_type       srq_type;       /* Básico / XRC / coincidencia de etiquetas */
struct ibv_pd          *pd;             /* PD asociado con el SRQ */
struct ibv_xrcd        *xrcd;           /* Dominio XRC a asociar con el SRQ */
struct ibv_cq          *cq;             /* CQ a asociar con el SRQ para el modo XRC */
struct ibv_tm_cap       tm_cap;         /* Atributos de coincidencia de etiquetas */
};
struct ibv_srq_attr {
uint32_t                max_wr;         /* Número máximo solicitado de solicitudes de trabajo (WRs) pendientes en el SRQ */
uint32_t                max_sge;        /* Número máximo solicitado de elementos de dispersión por WR */
uint32_t                srq_limit;      /* El valor límite del SRQ */
};
struct ibv_tm_cap {
uint32_t                max_num_tags;   /* Tamaño de la lista de coincidencia de etiquetas */
uint32_t                max_ops;        /* Número de operaciones pendientes de la lista de etiquetas */
};

La función ibv_create_srq_ex() actualizará la estructura srq_init_attr_ex con los valores originales del SRQ que fue creado; los valores de max_wr y max_sge serán mayores o iguales a los valores solicitados.

ibv_destroy_srq() destruye el SRQ srq.

VALOR DE RETORNO

ibv_create_srq_ex() devuelve un puntero al SRQ creado, o NULL si la solicitud falla.

ibv_destroy_srq() devuelve 0 si tiene éxito, o el valor de errno en caso de fallo (que indica la razón del fallo).

NOTAS

ibv_destroy_srq() falla si alguna pareja de colas todavía está asociada con este SRQ.

VER TAMBIÉN

ibv_alloc_pd(3), ibv_modify_srq(3), ibv_query_srq(3)
