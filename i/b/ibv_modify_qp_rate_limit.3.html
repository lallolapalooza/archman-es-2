IBV_MODIFY_QP_RATE_LIMIT(3) Manual del Programador de Libibverbs IBV_MODIFY_QP_RATE_LIMIT(3)

NOMBRE

ibv_modify_qp_rate_limit - modifica los atributos de limitación de tasa de envío de una cola de pares (QP)

SINOPSIS

#include <infiniband/verbs.h>

int ibv_modify_qp_rate_limit(struct ibv_qp *qp, struct ibv_qp_rate_limit_attr *attr);

DESCRIPCIÓN

ibv_modify_qp_rate_limit() modifica los atributos de control de paquetes de limitación de tasa de envío del QP qp con los atributos en attr. El argumento attr es una estructura ibv_qp_rate_limit_attr, como se define en <infiniband/verbs.h>.

El rate_limit define la tasa de envío MÁXIMA que este QP enviará siempre que el enlace no esté bloqueado y haya solicitudes de trabajo en la cola de envío.

Se logra un control más fino para dar forma a la tasa límite de un QP definiendo el max_burst_sz, tamaño máximo de bytes de ráfaga única y el typical_pkt_sz, tamaño de bytes de paquete típico. Estos permiten que el dispositivo ajuste el retraso de la brecha entre ráfagas requerido para dar forma correctamente a la programación de envíos al cable para alcanzar los requisitos de aplicación solicitados.

Establecer un valor de 0 para max_burst_sz o typical_pkt_sz utilizará los valores predeterminados del dispositivo. typical_pkt_sz tendrá por defecto el valor MTU del puerto.

struct ibv_qp_rate_limit_attr {
uint32_t        rate_limit;     /* kbps */
uint32_t        max_burst_sz;   /* bytes */
uint16_t        typical_pkt_sz; /* bytes */
};

VALOR DE RETORNO

ibv_modify_qp_rate_limit() devuelve 0 si tiene éxito, o el valor de errno en caso de fallo (que indica la razón del fallo).

ERRORES

EINVAL

Argumentos inválidos.

EOPNOTSUPP

La función no está implementada para este dispositivo. (ENOSYS puede ser devuelto a veces por versiones antiguas de libibverbs).

VER TAMBIÉN

ibv_create_qp(3), ibv_destroy_qp(3), ibv_modify_qp(3), ibv_query_qp(3)
