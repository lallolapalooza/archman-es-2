IBV_BIND_MW(3) Manual del Programador de Libibverbs IBV_BIND_MW(3)

NOMBRE

ibv_bind_mw - publica una solicitud para vincular una ventana de memoria tipo 1 a una región de memoria

SINOPSIS

#include <infiniband/verbs.h>

int ibv_bind_mw(struct ibv_qp *qp, struct ibv_mw *mw,
                struct ibv_mw_bind *mw_bind);

DESCRIPCIÓN

ibv_bind_mw() publica en la cola de pares qp una solicitud para vincular la ventana de memoria mw de acuerdo con los detalles en mw_bind.

El argumento mw_bind es una estructura ibv_mw_bind, tal como se define en <infiniband/verbs.h>.

struct ibv_mw_bind {
uint64_t                     wr_id;           /* ID de WR definido por el usuario */
unsigned int                 send_flags;      /* Usar ibv_send_flags */
struct ibv_mw_bind_info      bind_info;       /* Información de vinculación de MW */
}
struct ibv_mw_bind_info {
struct ibv_mr                *mr;             /* La MR a la que vincular la MW */
uint64_t                     addr;            /* La dirección donde debe comenzar la MW */
uint64_t                     length;          /* La longitud (en bytes) que debe abarcar la MW */
unsigned int                 mw_access_flags; /* Indicadores de acceso a la MW. Usar ibv_access_flags */
};

El Tipo de Servicio de Transporte del QP debe ser UC, RC o XRC_SEND para las operaciones de vinculación.

El indicador send_flags describe las propiedades del WR. Es 0 o el OR bit a bit de uno o más de los siguientes indicadores:

IBV_SEND_FENCE Establece el indicador de valla.
IBV_SEND_SIGNALED Establece el indicador de notificación de finalización. Solo relevante si el QP se creó con sq_sig_all=0

Los mw_access_flags definen el acceso permitido a la MW después de que la vinculación se complete con éxito. Es 0 o el OR bit a bit de uno o más de los siguientes indicadores:

IBV_ACCESS_REMOTE_WRITE Habilita el Acceso de Escritura Remota. Requiere acceso de escritura local a la MR.
IBV_ACCESS_REMOTE_READ Habilita el Acceso de Lectura Remota
IBV_ACCESS_REMOTE_ATOMIC Habilita el Acceso a Operaciones Atómicas Remotas (si se admite). Requiere acceso de escritura local a la MR.
IBV_ACCESS_ZERO_BASED Si está establecido, la dirección establecida en el campo 'remote_addr' en el WR será un desplazamiento desde la dirección de inicio de la MW.

VALOR DE RETORNO

ibv_bind_mw() devuelve 0 si tiene éxito, o el valor de errno en caso de fallo (que indica el motivo del fallo). En caso de éxito, la R_key de la ventana de memoria después de la vinculación se devuelve en el campo mw_bind->mw->rkey.

NOTAS

La vinculación no se completa cuando la función regresa; simplemente se publica en el QP. El usuario debe conservar una copia de la R_key antigua y corregir la estructura mw si el CQE posterior para la operación de vinculación indica un fallo. El usuario puede enviar de forma segura la R_key utilizando una solicitud de envío en el mismo QP (basándose en las reglas de ordenación de QP: un envío después de una solicitud de vinculación en el mismo QP siempre se ordena), pero no debe transferirla al remoto de ninguna otra manera antes de leer un CQE exitoso.

Tenga en cuenta que para las MW de tipo 2, se deben publicar directamente los WR de vinculación en el QP, utilizando ibv_post_send.
