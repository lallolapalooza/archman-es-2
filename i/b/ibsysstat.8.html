ibsysstat(8) Diagnóstico de InfiniBand de Fabric Manager ibsysstat(8)

Nombre

ibsysstat - estado del sistema en una dirección InfiniBand

SINOPSIS

ibsysstat [opciones] <lid | guid de destino> [<operación>]

DESCRIPCIÓN

ibsysstat utiliza mads del proveedor para validar la conectividad entre nodos IB y obtener otra información sobre el nodo IB. ibsysstat se ejecuta como cliente/servidor. El valor predeterminado es ejecutarse como cliente.

OPCIONES

Operaciones actualmente soportadas:

ping \- verificar la conectividad al servidor (predeterminado)
host \- obtener información del host del servidor
cpu  \- obtener información de la cpu del servidor
-o, --oui
usa el número OUI especificado para multiplexar mads del proveedor
-S, --Server
inicia en modo servidor (no regresa)

Banderas de direccionamiento

-G, --Guid La dirección especificada es un GUID de puerto

-L, --Lid La dirección especificada es una LID

-s, --sm_port <smlid> usa 'smlid' como la lid de destino para consultas SA.

Banderas de selección de puerto

-C, --Ca <nombre_ca> usa el nombre_ca especificado.

-P, --Port <puerto_ca> usa el puerto_ca especificado.

Selección de puerto local

Soporte para múltiples puertos/múltiples CA: cuando no se especifica ningún dispositivo o puerto IB (ver los "parámetros umad locales" a continuación), la biblioteca libibumad selecciona el puerto a usar según los siguientes criterios:

1.
el primer puerto que esté ACTIVO.
2.
si no se encuentra, el primer puerto que esté ARRIBA (enlace físico activo).

Si se especifica un nombre de puerto y/o CA, la biblioteca libibumad intenta cumplir la solicitud del usuario y fallará si no es posible.

Por ejemplo:

ibaddr                 # usa el primer puerto (criterio #1 arriba)
ibaddr -C mthca1       # elige el mejor puerto solo de "mthca1".
ibaddr -P 2            # usa el segundo puerto (activo/arriba) del primer dispositivo IB disponible.
ibaddr -C mthca0 -P 2  # usa solo el puerto especificado.

Banderas de depuración

-d
aumenta el nivel de depuración de IB. Se puede usar varias veces (-ddd o -d -d -d).
-e
muestra errores de envío y recepción (tiempos de espera y otros)

-h, --help muestra el mensaje de uso

-v, --verbose
aumenta el nivel de verbosidad de la aplicación. Se puede usar varias veces (-vv o -v -v -v)

-V, --version muestra la información de la versión.

Banderas de configuración

-t, --timeout <timeout_ms> anula el tiempo de espera predeterminado para los mads solicitados.

--config, -z <archivo_config> especifica un archivo de configuración alternativo.

Predeterminado: /etc/infiniband-diags/ibdiag.conf

ARCHIVOS

ARCHIVO DE CONFIGURACIÓN

/etc/infiniband-diags/ibdiag.conf

Se proporciona un archivo de configuración global para establecer algunas de las opciones comunes para todas las herramientas. Ver el archivo de configuración proporcionado para más detalles.
