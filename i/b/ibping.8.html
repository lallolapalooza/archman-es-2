IBPING(8) Diagnósticos Open IB IBPING(8)

Nombre

IBPING - hacer ping a una dirección InfiniBand

SINOPSIS

ibping [opciones] <lid | guid de destino>

DESCRIPCIÓN

ibping usa mads del proveedor para validar la conectividad entre nodos IB. Al salir, se muestra una salida similar a (IP) ping. ibping se ejecuta como cliente/servidor. Por defecto, se ejecuta como cliente. Tenga en cuenta también que hay un servidor de ping por defecto implementado dentro del kernel.

OPCIONES

-c, --count detener después de contar paquetes

-f, --flood inundar destino: enviar paquetes uno tras otro sin demora

-o, --oui usar el número OUI especificado para multiplexar mads del proveedor

-S, --Server iniciar en modo servidor (no regresar)

Flags de direccionamiento

-L, --Lid La dirección especificada es un LID

-G, --Guid La dirección especificada es un GUID de puerto

-s, --sm_port <smlid> usar 'smlid' como lid de destino para consultas SA.

Flags de selección de puerto

-C, --Ca <nombre_ca> usar el nombre_ca especificado.

-P, --Port <puerto_ca> usar el puerto_ca especificado.

Selección de puerto local

Soporte para múltiples puertos/múltiples CA: cuando no se especifica ningún dispositivo o puerto IB (ver "parámetros umad locales" a continuación), la biblioteca libibumad selecciona el puerto a utilizar según los siguientes criterios:

1.
el primer puerto que esté ACTIVO.
2.
si no se encuentra, el primer puerto que esté ARRIBA (enlace físico activo).

Si se especifica un nombre de puerto y/o CA, la biblioteca libibumad intenta satisfacer la solicitud del usuario, y fallará si no es posible.

Por ejemplo:

ibaddr                 # usar el primer puerto (criterio #1 arriba)
ibaddr -C mthca1       # seleccionar el mejor puerto solo de "mthca1".
ibaddr -P 2            # usar el segundo puerto (activo/arriba) del primer dispositivo IB disponible.
ibaddr -C mthca0 -P 2  # usar solo el puerto especificado.

Flags de configuración

--config, -z <archivo_config> Especificar archivo de config. alternativo.

Por defecto: /etc/infiniband-diags/ibdiag.conf

-t, --timeout <timeout_ms> anular el timeout por defecto para los mads solicitados.

Flags de depuración

-h, --help mostrar el mensaje de uso

-d
aumentar el nivel de depuración de IB. Se puede usar varias veces (-ddd o -d -d -d).
-e
mostrar errores de envío y recepción (tiempos de espera y otros)
-v, --verbose
aumentar el nivel de verbosidad de la aplicación. Se puede usar varias veces (-vv o -v -v -v)

-V, --version mostrar la información de la versión.

ARCHIVOS

ARCHIVO DE CONFIGURACIÓN

/etc/infiniband-diags/ibdiag.conf

Se proporciona un archivo de configuración global para establecer algunas de las opciones comunes para todas las herramientas. Consulte el archivo de configuración proporcionado para obtener más detalles.
