NOMBRE

ibv_import_dm - importar un DM desde un contexto ibv dado

ibv_unimport_dm - desimportar un DM

SINOPSIS

#include <infiniband/verbs.h>
struct ibv_dm *ibv_import_dm(struct ibv_context *context, uint32_t dm_handle);
void ibv_unimport_dm(struct ibv_dm *dm)

DESCRIPCIÓN

ibv_import_dm() devuelve una memoria de dispositivo (DM) que está asociada con el dm_handle dado en el contexto RDMA.

El valor de dm_handle de entrada debe ser un identificador de kernel válido para un objeto DM en el contexto RDMA asociado. Se puede obtener del DM original obteniendo el valor de su miembro ibv_dm->handle.

ibv_unimport_dm() desimporta el DM. Una vez finalizado el uso del DM, se debe llamar a ibv_free_dm() o ibv_unimport_dm(). La primera ira al kernel para destruir el objeto, mientras que la segunda limpiará lo que sea necesario/opuesto a la importación sin llamar al kernel.

Es responsabilidad de la aplicación coordinar entre todos los ibv_context(s) que utilizan este DM. Una vez que se completa la destrucción, ningún otro proceso puede manipular el objeto excepto para la desimportación. Todos los usuarios del contexto deben colaborar para garantizar esto.

VALOR DE RETORNO

ibv_import_dm() devuelve un puntero al DM asignado, o NULL si la solicitud falla y errno está configurado.
