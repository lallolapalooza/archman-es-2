IBV_CREATE_CQ(3) Manual del programador de Libibverbs IBV_CREATE_CQ(3)

NOMBRE

ibv_create_cq, ibv_destroy_cq - crear o destruir una cola de completado (CQ)

SINOPSIS

#include <infiniband/verbs.h>

struct ibv_cq *ibv_create_cq(struct ibv_context *context, int cqe,
                             void *cq_context,
                             struct ibv_comp_channel *channel,
                             int comp_vector);

int ibv_destroy_cq(struct ibv_cq *cq);

DESCRIPCIÓN

ibv_create_cq() crea una cola de completado (CQ) con al menos cqe entradas para el contexto del dispositivo RDMA context. El puntero cq_context se utilizará para establecer el puntero de contexto del usuario de la estructura CQ. El argumento channel es opcional; si no es NULL, se utilizará el canal de completado channel para devolver eventos de completado. La CQ utilizará el vector de completado comp_vector para señalizar eventos de completado; debe ser al menos cero y menor que context->num_comp_vectors.

ibv_destroy_cq() destruye la CQ cq.

VALOR DEVUELTO

ibv_create_cq() devuelve un puntero a la CQ, o NULL si la solicitud falla.

ibv_destroy_cq() devuelve 0 si tiene éxito, o el valor de errno en caso de fallo (que indica el motivo del fallo).

NOTAS

ibv_create_cq() puede crear una CQ con un tamaño mayor o igual al solicitado. Compruebe el atributo cqe en la CQ devuelta para conocer el tamaño real.

ibv_destroy_cq() falla si alguna pareja de colas todavía está asociada con esta CQ.

VER TAMBIÉN

ibv_resize_cq(3), ibv_req_notify_cq(3), ibv_ack_cq_events(3), ibv_create_qp(3)
