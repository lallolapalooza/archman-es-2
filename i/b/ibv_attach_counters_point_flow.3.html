NOMBRE

ibv_attach_counters_point_flow - adjuntar definición de contador individual a un objeto de flujo

SINOPSIS

#include <infiniband/verbs.h>
int ibv_attach_counters_point_flow(struct ibv_counters *counters,
                                   struct ibv_counter_attach_attr *counter_attach_attr,
                                   struct ibv_flow *flow);

DESCRIPCIÓN

Los puntos de adjunción de contadores son una familia de API para adjuntar una definición de contador individual a un objeto de verbo en una ubicación de índice específica.

El objeto de contadores comenzará a recopilar valores después de que se vincule al recurso del objeto de verbo.

Se puede crear una adjunción estática cuando se proporciona NULL en lugar de la referencia al objeto de verbos (por ejemplo, en el caso de un flujo que proporciona NULL en lugar de flow). En este caso, este objeto de contadores solo comenzará a recopilar valores después de que se vincule al recurso de verbos; para el flujo, esto ocurre cuando se hace referencia al manejador de contadores al crear un flujo con ibv_create_flow().

Una vez que un ibv_counters se vincula estáticamente a un recurso de verbos, no se permiten adjunciones adicionales hasta que el objeto de contador no esté vinculado a ningún objeto de verbo.

El argumento counter_desc especifica qué valor del contador debe recopilarse. Se define en verbs.h como una de las opciones de la enumeración ibv_counter_description.

Las capacidades admitidas de valores counter_desc específicos por objeto de verbos se pueden probar verificando el valor de retorno para el éxito o el errno ENOTSUP.

Adjuntar un manejador de contadores a múltiples objetos del mismo tipo acumulará los valores en un solo índice. Por ejemplo, crear varios ibv_flow con el mismo manejador ibv_counters recopilará los valores de todos los flujos relevantes en la ubicación del índice relevante al leer los valores de ibv_read_counters(). Establecer el índice más de una vez con counter_desc diferente o igual agregará los valores de todos los contadores relevantes en la ubicación del índice relevante.

Los valores en tiempo de ejecución de los contadores se pueden leer del hardware llamando a ibv_read_counters().

ARGUMENTOS

counters
Contadores existentes en los que adjuntar un nuevo punto de contador.
counter_attach_attr
Una estructura ibv_counter_attach_attr, como se define en verbs.h.
flow
Flujo existente en el que adjuntar un nuevo punto de contadores (en modo estático debe ser NULL).

Argumento counter_attach_attr

struct ibv_counter_attach_attr {
    enum ibv_counter_description counter_desc;
    uint32_t index;
    uint32_t comp_mask;
};

Argumento counter_desc

enum ibv_counter_description {
    IBV_COUNTER_PACKETS,
    IBV_COUNTER_BYTES,
};
index
Ubicación deseada del contador específico en el objeto de contadores.
comp_mask
Máscara de bits que especifica qué campos de la estructura son válidos.

VALOR DE RETORNO

ibv_attach_counters_point_flow() devuelve 0 si tiene éxito, o el valor de errno en caso de error (que indica el motivo del error).

ERRORES

EINVAL
se pasaron argumentos no válidos
ENOTSUP
counter_desc no es compatible con el objeto solicitado
EBUSY
el objeto contador ya está vinculado a un flujo, no se permiten llamadas de adjunción adicionales (válido solo para adjunción estática)
ENOMEM
no hay suficiente memoria

NOTAS

Los valores de los contadores en cada ubicación de índice se borran al crearse al llamar a ibv_create_counters(). La adjunción de puntos de contadores solo aumentará estos valores en consecuencia.

EJEMPLO

Un ejemplo de uso de ibv_attach_counters_point_flow() se muestra en ibv_read_counters

VER TAMBIÉN

ibv_create_counters, ibv_destroy_counters, ibv_read_counters, ibv_create_flow
