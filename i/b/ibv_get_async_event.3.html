NAME

ibv_get_async_event - Retrieve an asynchronous event

SYNOPSIS

#include <infiniband/verbs.h>

int ibv_get_async_event(
    struct ibv_context *context,
    struct ibv_async_event *event
);

DESCRIPTION

The ibv_get_async_event() function retrieves an asynchronous event from the specified context. The event will be stored in the event structure pointed to by the event argument. If no event is currently available, the function will block until an event is received.

The event structure contains the following fields:

  • event_type: The type of the asynchronous event.
  • device_event: Pointer to a ibv_device_event structure, containing information about the event if it is a device event.
  • port_event: Pointer to a ibv_port_event structure, containing information about the event if it is a port event.

The ibv_async_event structure is defined as follows:

struct ibv_async_event {
    enum ibv_event_type event_type;
    union {
        struct ibv_port_event port_event;
        struct ibv_device_event device_event;
        // ... other event types
    } data;
};

The following event types are supported:

  • IBV_EVENT_PORT_ACTIVE: A port has become active.
  • IBV_EVENT_PORT_IDLE: A port has become idle.
  • IBV_EVENT_DEVICE_OPEN: A device has been opened.
  • IBV_EVENT_DEVICE_CLOSE: A device has been closed.

RETURN VALUE

On success, ibv_get_async_event() returns 0. On failure, it returns a negative value and sets errno.

NOTES

The caller is responsible for freeing the event structure after it is no longer needed. This can be done using the ibv_ack_async_event() function.

EXAMPLES

#include <infiniband/verbs.h>
#include <stdio.h>
#include <stdlib.h>

int main() {
    struct ibv_context *context;
    struct ibv_async_event event;
    int ret;

    // Get a context for the first available InfiniBand device
    context = ibv_open_device(NULL);
    if (!context) {
        perror("ibv_open_device failed");
        return 1;
    }

    // Wait for an asynchronous event
    printf("Waiting for an asynchronous event...\n");
    ret = ibv_get_async_event(context, &event);
    if (ret) {
        perror("ibv_get_async_event failed");
        ibv_close_device(context);
        return 1;
    }

    // Process the event
    printf("Received event: %d\n", event.event_type);

    // Acknowledge the event
    ret = ibv_ack_async_event(&event);
    if (ret) {
        perror("ibv_ack_async_event failed");
    }

    // Close the device
    ibv_close_device(context);

    return 0;
}
