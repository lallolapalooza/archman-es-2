IBV_QUERY_DEVICE(3) Manual del programador de Libibverbs IBV_QUERY_DEVICE(3)

NOMBRE

ibv_query_device - consulta los atributos de un dispositivo RDMA

SINOPSIS

#include <infiniband/verbs.h>

int ibv_query_device(struct ibv_context *context,
                     struct ibv_device_attr *device_attr);

DESCRIPCIÓN

ibv_query_device() devuelve los atributos del dispositivo con contexto context. El argumento device_attr es un puntero a una estructura ibv_device_attr, según se define en <infiniband/verbs.h>.

struct ibv_device_attr {
char                    fw_ver[64];             /* Versión del firmware */
uint64_t                node_guid;              /* GUID del nodo (en orden de bytes de red) */
uint64_t                sys_image_guid;         /* GUID de la imagen del sistema (en orden de bytes de red) */
uint64_t                max_mr_size;            /* El bloque contiguo más grande que se puede registrar */
uint64_t                page_size_cap;          /* Tamaños de desplazamiento de memoria admitidos */
uint32_t                vendor_id;              /* ID del proveedor, según IEEE */
uint32_t                vendor_part_id;         /* ID de parte suministrado por el proveedor */
uint32_t                hw_ver;                 /* Versión del hardware */
int                     max_qp;                 /* Número máximo de QP admitidos */
int                     max_qp_wr;              /* Número máximo de WR pendientes en cualquier cola de trabajo */
unsigned int            device_cap_flags;       /* Máscara de capacidades de HCA */
int                     max_sge;                /* Número máximo de s/g por WR para SQ y RQ de QP para operaciones que no son de lectura RDMA */
int                     max_sge_rd;             /* Número máximo de s/g por WR para operaciones de lectura RDMA */
int                     max_cq;                 /* Número máximo de CQ admitidas */
int                     max_cqe;                /* Capacidad máxima de CQE por CQ */
int                     max_mr;                 /* Número máximo de MR admitidas */
int                     max_pd;                 /* Número máximo de PD admitidas */
int                     max_qp_rd_atom;         /* Número máximo de operaciones de lectura y atómicas RDMA que pueden estar pendientes por QP */
int                     max_ee_rd_atom;         /* Número máximo de operaciones de lectura y atómicas RDMA que pueden estar pendientes por EEC */
int                     max_res_rd_atom;        /* Número máximo de recursos utilizados para operaciones de lectura y atómicas RDMA por esta HCA como Destino */
int                     max_qp_init_rd_atom;    /* Profundidad máxima por QP para la iniciación de operaciones de lectura y atómicas RDMA */ 
int                     max_ee_init_rd_atom;    /* Profundidad máxima por EEC para la iniciación de operaciones de lectura y atómicas RDMA */
enum ibv_atomic_cap     atomic_cap;             /* Nivel de soporte de operaciones atómicas */
int                     max_ee;                 /* Número máximo de contextos EE admitidos */
int                     max_rdd;                /* Número máximo de dominios RD admitidos */
int                     max_mw;                 /* Número máximo de MW admitidas */
int                     max_raw_ipv6_qp;        /* Número máximo de QP de datagramas IPv6 sin procesar admitidos */
int                     max_raw_ethy_qp;        /* Número máximo de QP de datagramas de tipo Ethernet sin procesar admitidos */
int                     max_mcast_grp;          /* Número máximo de grupos de multidifusión admitidos */
int                     max_mcast_qp_attach;    /* Número máximo de QP por grupo de multidifusión que se pueden adjuntar */
int                     max_total_mcast_qp_attach;/* Número máximo de QP que se pueden adjuntar a grupos de multidifusión */
int                     max_ah;                 /* Número máximo de manejadores de dirección admitidos */
int                     max_fmr;                /* Número máximo de FMR admitidas */
int                     max_map_per_fmr;        /* Número máximo de (re)mapeos por FMR antes de que se requiera una operación de desmapeo */
int                     max_srq;                /* Número máximo de SRQ admitidos */
int                     max_srq_wr;             /* Número máximo de WR por SRQ */
int                     max_srq_sge;            /* Número máximo de s/g por SRQ */
uint16_t                max_pkeys;              /* Número máximo de particiones */
uint8_t                 local_ca_ack_delay;     /* Retraso de ACK de CA local */
uint8_t                 phys_port_cnt;          /* Número de puertos físicos */
};

VALOR DE RETORNO

ibv_query_device() devuelve 0 si tiene éxito, o el valor de errno en caso de error (que indica el motivo del fallo).

NOTAS

Los valores máximos devueltos por esta función son los límites superiores de los recursos admitidos por el dispositivo. Sin embargo, puede que no sea posible utilizar estos valores máximos, ya que el número real de cualquier recurso que se pueda crear puede estar limitado por la configuración de la máquina, la cantidad de memoria del host, los permisos del usuario y la cantidad de recursos que ya están en uso por otros usuarios/procesos.
