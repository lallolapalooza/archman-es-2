IBADDR(8) Diagnósticos de OpenIB IBADDR(8)

Nombre

ibaddr - consultar dirección(es) InfiniBand

SINAPSIS

ibaddr [opciones]

DESCRIPCIÓN

Muestra el lid (y el rango) así como la dirección GID del puerto especificado (por ruta directa, lid o GUID) o el puerto local por defecto.

Nota: esta utilidad puede usarse como un simple resolvedor de direcciones.

OPCIONES

--gid_show, -g mostrar solo la dirección gid

--lid_show, -l mostrar solo el rango de lid

--Lid_show, -L mostrar solo el rango de lid (en decimal)

Indicadores de direccionamiento

-D, --Direct La dirección especificada es una ruta directa

Ejemplos:
   [opciones] -D [opciones] "0"          # puerto propio
   [opciones] -D [opciones] "0,1,2,1,4"  # salir por el puerto 1, luego 2, ...
   (Nota que el segundo número en la ruta especificada debe coincidir con el puerto que
   se está utilizando. Esto se puede especificar usando el indicador de selección de puerto '-P' o el
   puerto encontrado a través del proceso de selección automática.)

-G, --Guid La dirección especificada es un GUID de puerto

-s, --sm_port <smlid> usar 'smlid' como lid de destino para consultas SA.

Indicadores de depuración

-d
aumentar el nivel de depuración de IB. Puede usarse varias veces (-ddd o -d -d -d).
-e
mostrar errores de envío y recepción (tiempos de espera y otros)

-h, --help mostrar el mensaje de uso

-v, --verbose
aumentar el nivel de verbosidad de la aplicación. Puede usarse varias veces (-vv o -v -v -v)

-V, --version mostrar la información de la versión.

Indicadores de selección de puerto

-C, --Ca <ca_name> usar el nombre de CA especificado.

-P, --Port <ca_port> usar el puerto de CA especificado.

Selección de puerto local

Soporte para múltiples puertos/múltiples CA: cuando no se especifica ningún dispositivo o puerto IB (ver los "parámetros umad locales" a continuación), la biblioteca libibumad selecciona el puerto a usar según los siguientes criterios:

1.
el primer puerto que esté ACTIVO.
2.
si no se encuentra, el primer puerto que esté ARRIBA (enlace físico activado).

Si se especifica un nombre de puerto y/o CA, la biblioteca libibumad intenta cumplir la solicitud del usuario y fallará si no es posible.

Por ejemplo:

ibaddr                  # usar el primer puerto (criterio #1 arriba)
ibaddr -C mthca1       # elegir el mejor puerto solo de "mthca1".
ibaddr -P 2            # usar el segundo puerto (activo/arriba) del primer dispositivo IB disponible.
ibaddr -C mthca0 -P 2  # usar solo el puerto especificado.

Indicadores de configuración

-y, --m_key <key>
usar la M_key especificada para las solicitudes. Si se especifica un valor no numérico (como 'x'), se le pedirá uno.

-t, --timeout <timeout_ms> anular el tiempo de espera predeterminado para los mads solicitados.

--config, -z <config_file> Especificar un archivo de configuración alternativo.

Predeterminado: /etc/infiniband-diags/ibdiag.conf

ARCHIVOS

ARCHIVO DE CONFIGURACIÓN

/etc/infiniband-diags/ibdiag.conf

Se proporciona un archivo de configuración global para establecer algunas de las opciones comunes para todas las herramientas. Consulte el archivo de configuración proporcionado para obtener detalles.

EJEMPLOS

ibaddr                  # dirección del puerto local
ibaddr 32               # mostrar rango de lid y gid del lid 32
ibaddr -G 0x8f1040023   # igual pero usando dirección guid
ibaddr -l 32            # mostrar solo rango de lid
ibaddr -L 32            # mostrar solo rango de lid decimal
ibaddr -g 32            # mostrar solo dirección gid

VER TAMBIÉN

ibroute (8), ibtracert (8)
