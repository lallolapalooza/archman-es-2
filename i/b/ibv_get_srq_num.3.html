IBV_GET_SRQ_NUM(3) Manual del programador de Libibverbs IBV_GET_SRQ_NUM(3)

NOMBRE

ibv_get_srq_num - devuelve el número srq asociado a la cola de recepción compartida (SRQ) dada

SINOPSIS

#include <infiniband/verbs.h>
int ibv_get_srq_num(struct ibv_srq *srq, uint32_t *srq_num);

DESCRIPCIÓN

ibv_get_srq_num() devuelve el número srq asociado a la cola de recepción compartida XRC dada. El argumento srq es una estructura ibv_srq, tal como se define en <infiniband/verbs.h>. srq_num es un parámetro de salida que contiene el número srq devuelto.

VALOR DE RETORNO

ibv_get_srq_num() devuelve 0 si tiene éxito, o el valor de errno en caso de error (que indica el motivo del fallo).

VER TAMBIÉN

ibv_alloc_pd(3), ibv_create_srq_ex(3), ibv_modify_srq(3)
