IBV_QUERY_SRQ(3) Manual del programador de Libibverbs IBV_QUERY_SRQ(3)

NOMBRE

ibv_query_srq - obtener los atributos de una cola de recepción compartida (SRQ)

SINOPSIS

#include <infiniband/verbs.h>

int ibv_query_srq(struct ibv_srq *srq, struct ibv_srq_attr *srq_attr);

DESCRIPCIÓN

ibv_query_srq() obtiene los atributos de la SRQ srq y los devuelve a través del puntero srq_attr. El argumento srq_attr es una estructura ibv_srq_attr, tal como se define en <infiniband/verbs.h>.

struct ibv_srq_attr {
uint32_t                max_wr;         /* número máximo de solicitudes de trabajo (WR) pendientes en la SRQ */
uint32_t                max_sge;        /* número máximo de elementos scatter por WR */
uint32_t                srq_limit;      /* el valor límite de la SRQ */
};

VALOR DE RETORNO

ibv_query_srq() devuelve 0 si tiene éxito, o el valor de errno si falla (lo que indica la razón del fallo).

NOTAS

Si el valor devuelto para srq_limit es 0, entonces el evento de límite alcanzado de la SRQ ("marca de agua baja") no está (o ya no está) activado, y no se generarán eventos asíncronos hasta que el evento se vuelva a activar.

VER TAMBIÉN

ibv_create_srq(3), ibv_destroy_srq(3), ibv_modify_srq(3)
