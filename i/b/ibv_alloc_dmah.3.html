ibv_alloc_dmah(3) Manual del Programador de Libibverbs ibv_alloc_dmah(3)

NOMBRE

ibv_alloc_dmah - asignar un manejador dma

int ibv_dealloc_dmah - desasignar un manejador dma

SINOPSIS

#include <infiniband/verbs.h>
struct ibv_dmah *ibv_alloc_dmah(struct ibv_context *context, struct ibv_dmah_init_attr *attr);
int ibv_dealloc_dmah(struct ibv_dmah *dmah);

DESCRIPCIÓN

ibv_alloc_dmah() asigna un objeto ibv_dmah que está asociado con el contexto dado y el parámetro de entrada attr.

El manejador asignado puede usarse posteriormente para optimizar las operaciones DMA y RDMA asociadas con una región de memoria registrada.

Una vez que se ha finalizado el uso de ibv_dmah, se debe llamar a ibv_dealloc_dmah().

Esta llamada liberará los recursos que fueron previamente asignados utilizando la API ibv_alloc_dmah().

ARGUMENTOS

attr

enum ibv_tph_mem_type {
    IBV_TPH_MEM_TYPE_VM, /* memoria volátil */
    IBV_TPH_MEM_TYPE_PM, /* memoria persistente */
};
enum ibv_dmah_init_attr_mask {
    IBV_DMAH_INIT_ATTR_MASK_CPU_ID = 1 << 0,
    IBV_DMAH_INIT_ATTR_MASK_PH = 1 << 1,
    IBV_DMAH_INIT_ATTR_MASK_TPH_MEM_TYPE = 1 << 2,
};
struct ibv_dmah_init_attr {
    uint32_t comp_mask; /* De ibv_dmah_init_attr_mask */
    uint32_t cpu_id;
    uint8_t ph;
    uint8_t tph_mem_type; /* De enum ibv_tph_mem_type */
};
comp_mask
Máscara de bits que especifica qué campos de la estructura son válidos.
cpu_id
El ID de CPU al que se refiere el manejador dma.
ph
Pistas de procesamiento, utilizadas para ayudar a optimizar el manejo de transacciones sobre PCIe.
tph_mem_type
El tipo de memoria de destino, uno entre enum ibv_tph_mem_type.

VALOR DE RETORNO

ibv_alloc_dmah() devuelve un puntero al objeto manejador dma asignado, o NULL si la solicitud falla.

ibv_dealloc_dmah() devuelve 0 si tiene éxito, de lo contrario el valor de errno.
