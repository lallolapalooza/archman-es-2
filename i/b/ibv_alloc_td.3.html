IBV_ALLOC_TD(3) Manual del programador de Libibverbs IBV_ALLOC_TD(3)

NOMBRE

ibv_alloc_td(), ibv_dealloc_td() - asignar y desasignar objeto de dominio de hilo

SINOPSIS

#include <infiniband/verbs.h>

struct ibv_td *ibv_alloc_td(struct ibv_context *context,
                            struct ibv_td_init_attr *init_attr);

int ibv_dealloc_td(struct ibv_td *td);

DESCRIPCIÓN

ibv_alloc_td() asigna un objeto de dominio de hilo para el contexto del dispositivo RDMA context.

El objeto de dominio de hilo define cómo las bibliotecas de verbs y el proveedor utilizarán bloqueos y capacidades de hardware adicionales para lograr el mejor rendimiento al manejar protección multihilo o de un solo hilo. Una aplicación asigna recursos de verbs a un dominio de hilo cuando crea un objeto de verbs.

Si se especifica el objeto ibv_td, cualquier objeto creado bajo este dominio de hilo deshabilitará los bloqueos internos diseñados para proteger contra el acceso concurrente a ese objeto desde múltiples hilos de usuario. Por defecto, todos los objetos de verbs son seguros para acceso multihilo, ya sea que se especifique o no un dominio de hilo.

Un struct ibv_td puede añadirse a un dominio padre a través de ibv_alloc_parent_domain() y luego el dominio padre puede usarse para crear objetos de verbs.

ibv_dealloc_td() desasignará el dominio de hilo td. Todos los recursos creados con el td deben destruirse antes de desasignar el td.

VALOR DEVUELTO

ibv_alloc_td() devuelve un puntero al objeto struct ibv_td asignado, o NULL si la solicitud falla (y establece errno para indicar el motivo de la falla).

ibv_dealloc_td() devuelve 0 si tiene éxito, o el valor de errno en caso de fallo (que indica el motivo del fallo).
