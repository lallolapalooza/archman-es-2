IBV_REREG_MR(3) Manual del programador de Libibverbs IBV_REREG_MR(3)

NOMBRE

ibv_rereg_mr - re-registrar una región de memoria (MR)

SINOPSIS

#include <infiniband/verbs.h>
int ibv_rereg_mr(struct ibv_mr *mr,
                 int flags,
                 struct ibv_pd *pd,
                 void *addr,
                 size_t length,
                 int access);

DESCRIPCIÓN

ibv_rereg_mr() Modifica los atributos de una región de memoria (MR) existente mr. Conceptualmente, esta llamada realiza las funciones de anular el registro de la región de memoria seguida de registrar la región de memoria. Siempre que sea posible, se reutilizan recursos en lugar de liberarlos y volver a asignarlos.

flags es una máscara de bits utilizada para indicar qué de las siguientes propiedades de la región de memoria se están modificando. Los flags deben ser una combinación (campo de bits) de:

IBV_REREG_MR_CHANGE_TRANSLATION
Cambiar la traducción (ubicación y longitud)
IBV_REREG_MR_CHANGE_PD
Cambiar el dominio de protección
IBV_REREG_MR_CHANGE_ACCESS
Cambiar los flags de acceso

Cuando se utiliza IBV_REREG_MR_CHANGE_PD, pd representa el nuevo PD al que se debe registrar esta MR.

Cuando se utiliza IBV_REREG_MR_CHANGE_TRANSLATION, addr. representa la dirección virtual (puntero del espacio de usuario) de la nueva MR, mientras que length representa su longitud.

El acceso y otros flags se representan en el campo access. Este campo describe los atributos de protección de memoria deseados; es 0 o la OR a nivel de bits de uno o más de los ibv_access_flags.

VALOR DE RETORNO

ibv_rereg_mr() devuelve 0 si tiene éxito, de lo contrario, ha ocurrido un error, enum ibv_rereg_mr_err_code representa el error según lo indicado a continuación.

IBV_REREG_MR_ERR_INPUT - La MR antigua es válida, libibverbs detectó un error de entrada.

IBV_REREG_MR_ERR_DONT_FORK_NEW - La MR antigua es válida, falló debido a no crear una bifurcación en el nuevo rango de direcciones.

IBV_REREG_MR_ERR_DO_FORK_OLD - La nueva MR es válida, falló debido a crear una bifurcación en el rango de direcciones antiguo.

IBV_REREG_MR_ERR_CMD - La MR no debería usarse, error de comando.

IBV_REREG_MR_ERR_CMD_AND_DO_FORK_NEW - La MR no debería usarse, error de comando, estado de bifurcación inválido en el nuevo rango de direcciones.

NOTAS

Incluso en caso de fallo, el usuario aún necesita llamar a ibv_dereg_mr en esta MR.

VER TAMBIÉN

ibv_dereg_mr(3), ibv_reg_mr(3)
