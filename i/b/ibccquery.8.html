IBCCQUERY(8) Diagnósticos de OpenIB IBCCQUERY(8)

Nombre

ibccquery - consulta la configuración/información del control de congestión

SINOPSIS

ibccquery [opciones_comunes] [-c cckey] <operación> <lid|guid> [puerto]

DESCRIPCIÓN

ibccquery admite la consulta de configuraciones y otra información relacionada con el control de congestión.

OPCIONES

Operaciones admitidas actualmente y sus parámetros:
CongestionInfo (CI) <dirección> CongestionKeyInfo (CK) <dirección> CongestionLog (CL) <dirección> SwitchCongestionSetting (SS) <dirección> SwitchPortCongestionSetting (SP) <dirección> [<número_puerto>] CACongestionSetting (CS) <dirección> CongestionControlTable (CT) <dirección> Timestamp (TI) <dirección>

--cckey, -c <cckey> Especifica una clave de control de congestión (CC). Si no se especifica ninguna, se utiliza la clave 0.

Banderas de depuración

-d
aumenta el nivel de depuración de IB. Puede usarse varias veces (-ddd o -d -d -d).
-e
muestra errores de envío y recepción (tiempos de espera y otros)

-h, --help muestra el mensaje de uso

-v, --verbose
aumenta el nivel de verbosidad de la aplicación. Puede usarse varias veces (-vv o -v -v -v)

-V, --version muestra la información de la versión.

Banderas de direccionamiento

-G, --Guid La dirección especificada es un GUID de puerto

-L, --Lid La dirección especificada es un LID

-s, --sm_port <smlid> usa 'smlid' como lid de destino para las consultas SA.

Banderas de selección de puerto

-C, --Ca <nombre_ca> usa el nombre_ca especificado.

-P, --Port <puerto_ca> usa el puerto_ca especificado.

Selección de puerto local

Soporte para múltiples puertos/múltiples CA: cuando no se especifica ningún dispositivo o puerto IB (ver los "parámetros de umad local" a continuación), la biblioteca libibumad selecciona el puerto a usar según los siguientes criterios:

1.
el primer puerto que está ACTIVO.
2.
si no se encuentra, el primer puerto que está ARRIBA (enlace físico activo).

Si se especifica un nombre de puerto y/o CA, la biblioteca libibumad intenta cumplir la solicitud del usuario y fallará si no es posible.

Por ejemplo:

ibaddr                 # usa el primer puerto (criterio #1 anterior)
ibaddr -C mthca1       # elige el mejor puerto solo de "mthca1".
ibaddr -P 2            # usa el segundo puerto (activo/arriba) del primer dispositivo IB disponible.
ibaddr -C mthca0 -P 2  # usa solo el puerto especificado.

Banderas de configuración

-y, --m_key <clave>
usa la M_key especificada para las solicitudes. Si se especifica un valor no numérico (como 'x'), se solicitará un valor.

--config, -z <archivo_config> Especifica un archivo de configuración alternativo.

Predeterminado: /etc/infiniband-diags/ibdiag.conf

ARCHIVOS

ARCHIVO DE CONFIGURACIÓN

/etc/infiniband-diags/ibdiag.conf

Se proporciona un archivo de configuración global para establecer algunas de las opciones comunes para todas las herramientas. Consulte el archivo de configuración proporcionado para obtener más detalles.

EJEMPLOS

ibccquery CongestionInfo 3              # Información de congestión por lid
ibccquery SwitchPortCongestionSetting 3 # Consulta todas las configuraciones de congestión de puertos de switch
ibccquery SwitchPortCongestionSetting 3 1 # Consulta la configuración de congestión de puertos de switch para el puerto 1
