NOMBRE

ibacm - Asistente de gestión de comunicaciones InfiniBand

SINOPSIS

#include <infiniband/acm.h>

DESCRIPCIÓN

Se utiliza para resolver la información de puntos finales remotos antes de establecer comunicaciones sobre InfiniBand.

NOTAS

El IB ACM proporciona servicios escalables de resolución de direcciones y rutas sobre InfiniBand. Resuelve nombres de red del sistema y direcciones IP a datos de registro de ruta InfiniBand utilizando mecanismos eficientes, incluyendo el almacenamiento en caché de datos.

El IB ACM proporciona la información necesaria para establecer una conexión, pero no implementa el protocolo de gestión de comunicaciones. Proporciona servicios similares a rdma_getaddrinfo, rdma_resolve_addr y rdma_resolve_route utilizando multidifusión IB. El IB ACM no requiere IPoIB ni utiliza servicios de nombres estándar, como DNS, y limita la comunicación de red, especialmente con el SA de IB. La utilidad ib_acme ayuda a verificar qué opciones del servicio ibacm pueden ser utilizables para la topología de red actual.

Las interacciones del cliente con el servicio ibacm se realizan a través de sockets mediante una conexión TCP estándar. librdmacm abstrae esta interacción.
