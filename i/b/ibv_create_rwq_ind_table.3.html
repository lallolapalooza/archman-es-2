NOMBRE

ibv_create_rwq_ind_table, ibv_destroy_rwq_ind_table - crear o destruir una Tabla de Indirección de Colas de Trabajo de Recepción (RWQ IND TBL).

SINOPSIS

#include <infiniband/verbs.h>

struct ibv_rwq_ind_table *ibv_create_rwq_ind_table(struct ibv_context *context,
                                                           struct ibv_rwq_ind_table_init_attr *init_attr);

int ibv_destroy_rwq_ind_table(struct ibv_rwq_ind_table *rwq_ind_table);

DESCRIPCIÓN

ibv_create_rwq_ind_table() crea una RWQ IND TBL asociada con el ibv_context context. El argumento init_attr es una estructura ibv_rwq_ind_table_init_attr, tal como se define en <infiniband/verbs.h>.

struct ibv_rwq_ind_table_init_attr {
uint32_t        log_ind_tbl_size;     /* Logaritmo, base 2, del tamaño de la tabla de')),
                                      /*   Indirección */
struct          ibv_wq **ind_tbl;     /* Cada entrada es un puntero a una Cola de Trabajo */
                                      /*   de Recepción */
uint32_t        comp_mask;            /* Identifica los campos válidos. Utilizar ibv_ind_table_init_attr_mask */
};

La función ibv_create_rwq_ind_table() creará una RWQ IND TBL que contiene una tabla de Colas de Trabajo de Recepción. Para uso adicional del objeto creado, véase abajo en NOTAS.

ibv_destroy_rwq_ind_table() destruye la RWQ IND TBL rwq_ind_table.

VALOR DE RETORNO

ibv_create_rwq_ind_table() devuelve un puntero a la RWQ IND TBL creada, o NULL si la solicitud falla.

ibv_destroy_rwq_ind_table() devuelve 0 si tiene éxito, o el valor de errno en caso de fallo (que indica el motivo del fallo).

NOTAS

El objeto creado debe utilizarse como parte de ibv_create_qp_ex() para permitir el envío de paquetes entrantes basado en alguna configuración de hash RX.
