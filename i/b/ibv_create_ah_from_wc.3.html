IBV_CREATE_AH_FROM_WC(3) Manual del programador de Libibverbs IBV_CREATE_AH_FROM_WC(3)

NOMBRE

ibv_init_ah_from_wc, ibv_create_ah_from_wc - inicializar o crear un manejador de direcciones (AH) a partir de una finalización de trabajo

SINOPSIS

#include <infiniband/verbs.h>

int ibv_init_ah_from_wc(struct ibv_context *context, uint8_t port_num,
                        struct ibv_wc *wc, struct ibv_grh *grh,
                        struct ibv_ah_attr *ah_attr);

struct ibv_ah *ibv_create_ah_from_wc(struct ibv_pd *pd,
                                     struct ibv_wc *wc,
                                     struct ibv_grh *grh,
                                     uint8_t port_num);

DESCRIPCIÓN

ibv_init_ah_from_wc() inicializa la estructura de atributos del manejador de direcciones (AH) ah_attr para el contexto del dispositivo RDMA context usando el número de puerto port_num, utilizando atributos de la finalización de trabajo wc y la estructura de Cabecera de Enrutamiento Global (GRH) grh.

ibv_create_ah_from_wc() crea un AH asociado con el dominio de protección pd usando el número de puerto port_num, utilizando atributos de la finalización de trabajo wc y la estructura de Cabecera de Enrutamiento Global (GRH) grh.

VALOR DE RETORNO

ibv_init_ah_from_wc() devuelve 0 si tiene éxito y -1 si ocurre un error.

ibv_create_ah_from_wc() devuelve un puntero al AH creado, o NULL si la solicitud falla.

NOTAS

La estructura rellenada ah_attr devuelta por ibv_init_ah_from_wc() puede usarse para crear un nuevo AH usando ibv_create_ah().

VER TAMBIÉN

ibv_open_device(3), ibv_alloc_pd(3), ibv_create_ah(3), ibv_destroy_ah(3), ibv_poll_cq(3)
