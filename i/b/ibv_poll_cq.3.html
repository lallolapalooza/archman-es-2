IBV_POLL_CQ(3) Manual del programador de Libibverbs IBV_POLL_CQ(3)

NOMBRE

ibv_poll_cq - sondear una cola de finalización (CQ)

SINOPSIS

#include <infiniband/verbs.h>

int ibv_poll_cq(struct ibv_cq *cq, int num_entries,
                struct ibv_wc *wc);

DESCRIPCIÓN

ibv_poll_cq() sondea la CQ cq en busca de finalizaciones de trabajo y devuelve las primeras num_entries (o todas las finalizaciones disponibles si la CQ contiene menos que este número) en la matriz wc. El argumento wc es un puntero a una matriz de estructuras ibv_wc, según se define en <infiniband/verbs.h>.

struct ibv_wc {
uint64_t                wr_id;          /* ID de la solicitud de trabajo (WR) completada */
enum ibv_wc_status      status;         /* Estado de la operación */
enum ibv_wc_opcode      opcode;         /* Tipo de operación especificada en la WR completada */
uint32_t                vendor_err;     /* Síndrome de error del proveedor */
uint32_t                byte_len;       /* Número de bytes transferidos */
union {
__be32                  imm_data;         /* Datos inmediatos (en orden de bytes de red) */
uint32_t                invalidated_rkey; /* RKey local que fue invalidado */
};
uint32_t                qp_num;         /* Número QP local de la WR completada */
uint32_t                src_qp;         /* Número QP de origen (número QP remoto) de la WR completada (válido solo para QPs UD) */
unsigned int            wc_flags;       /* Banderas de la WR completada */
uint16_t                pkey_index;     /* Índice P_Key (válido solo para QPs GSI) */
uint16_t                slid;           /* LID de origen */
uint8_t                 sl;             /* Nivel de servicio */
uint8_t                 dlid_path_bits; /* Bits de ruta DLID (no aplicable a mensajes multicast) */
};

El atributo wc_flags describe las propiedades de la finalización del trabajo. Es 0 o la OR a nivel de bits de una o más de las siguientes banderas:

IBV_WC_GRH GRH presente (válido solo para QPs UD)
IBV_WC_WITH_IMM el valor de los datos inmediatos es válido
IBV_WC_WITH_INV el valor de los datos RKey invalidados es válido (no se puede combinar con IBV_WC_WITH_IMM)
IBV_WC_IP_CSUM_OK la suma de verificación TCP/UDP sobre IPv4 y la suma de verificación de cabecera IPv4 son
verificadas. Válido solo cuando device_cap_flags en device_attr indica que la QP actual es compatible con la descarga de suma de verificación.

No todos los atributos de wc son siempre válidos. Si el estado de finalización es diferente de IBV_WC_SUCCESS, solo los siguientes atributos son válidos: wr_id, status, qp_num y vendor_err.

VALOR DE RETORNO

En caso de éxito, ibv_poll_cq() devuelve un valor no negativo igual al número de finalizaciones encontradas. En caso de fallo, se devuelve un valor negativo.

NOTAS

Cada finalización sondeada se elimina de la CQ y no se puede devolver a ella.

El usuario debe consumir las finalizaciones de trabajo a una velocidad que evite la sobresaturación de la CQ. En caso de sobresaturación de la CQ, se activará el evento asíncrono IBV_EVENT_CQ_ERR y la CQ no podrá ser utilizada.

IBV_WC_DRIVER1 se informará como respuesta a la operación IBV_WR_DRIVER1; IBV_WC_DRIVER2/IBV_WC_DRIVER3 se informarán en operaciones específicas del controlador.

VER TAMBIÉN

ibv_post_send(3), ibv_post_recv(3)
