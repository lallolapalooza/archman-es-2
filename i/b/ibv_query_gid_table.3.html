IBV_QUERY_GID_TABLE(3) Manual del programador de Libibverbs IBV_QUERY_GID_TABLE(3)

NOMBRE

ibv_query_gid_table - consulta la tabla GID de un dispositivo InfiniBand

SINOPSIS

#include <infiniband/verbs.h>
ssize_t ibv_query_gid_table(struct ibv_context *context,
                            struct ibv_gid_entry *entries,
                            size_t max_entries,
                            uint32_t flags);

DESCRIPCIÓN

ibv_query_gid_table() devuelve las entradas válidas de la tabla GID del contexto del dispositivo RDMA context en el puntero entries.

El llamador debe asignar el array entries para las entradas de la tabla GID que desea consultar. Esta API solo devuelve entradas válidas de la tabla GID.

El llamador debe pasar un número de entradas no cero en max_entries que corresponda al tamaño del array entries.

El array entries debe asignarse de tal manera que pueda contener todas las entradas válidas de la tabla GID del dispositivo. Si hay más entradas válidas de GID que el valor proporcionado de max_entries y el array entries, la llamada fallará. Por ejemplo, si un dispositivo RDMA context tiene un total de 10 entradas GID válidas, entries debería asignarse para al menos 10 entradas, y max_entries debería establecerse apropiadamente.

ARGUMENTOS

context
El contexto del dispositivo a consultar.
entries
Array de estructuras ibv_gid_entry donde se devuelven las entradas GID. Por favor, consulta la página del manual de ibv_query_gid_ex(3) para ibv_gid_entry.
max_entries
Número máximo de entradas que se pueden devolver.
flags
Campos adicionales a consultar después de entries->ndev_ifindex, por ahora debe ser 0.

VALOR DE RETORNO

ibv_query_gid_table() devuelve el número de entradas que se leyeron con éxito o un valor errno negativo en caso de error. El número de entradas devueltas es <= max_entries.

VER TAMBIÉN

ibv_open_device(3), ibv_query_device(3), ibv_query_port(3), ibv_query_gid_ex(3)
