IBV_CREATE_AH(3) Manual del programador de Libibverbs IBV_CREATE_AH(3)

NOMBRE

ibv_create_ah, ibv_destroy_ah - crear o destruir un manejador de direcciones (AH)

SINOPSIS

#include <infiniband/verbs.h>

struct ibv_ah *ibv_create_ah(struct ibv_pd *pd,
                             struct ibv_ah_attr *attr);

int ibv_destroy_ah(struct ibv_ah *ah);

DESCRIPCIÓN

ibv_create_ah() crea un manejador de direcciones (AH) asociado con el dominio de protección pd. El argumento attr es una estructura ibv_ah_attr, tal como se define en <infiniband/verbs.h>.

struct ibv_ah_attr {
struct ibv_global_route grh;            /* Atributos de la cabecera de enrutamiento global (GRH) */
uint16_t                dlid;           /* LID de destino */
uint8_t                 sl;             /* Nivel de servicio */
uint8_t                 src_path_bits;  /* Bits de ruta de origen */
uint8_t                 static_rate;    /* Tasa estática máxima */
uint8_t                 is_global;      /* Los atributos GRH son válidos */
uint8_t                 port_num;       /* Número de puerto físico */
};
struct ibv_global_route {
union ibv_gid           dgid;           /* GID de destino o MGID */
uint32_t                flow_label;     /* Etiqueta de flujo */
uint8_t                 sgid_index;     /* Índice GID de origen */
uint8_t                 hop_limit;      /* Límite de saltos */
uint8_t                 traffic_class;  /* Clase de tráfico */
};

ibv_destroy_ah() destruye el AH ah.

VALOR DE RETORNO

ibv_create_ah() devuelve un puntero al AH creado, o NULL si la solicitud falla.

NOTAS

Si la bandera de puerto IBV_QPF_GRH_REQUIRED está establecida, entonces ibv_create_ah() debe crearse con la definición de 'struct ibv_ah_attr { .is_global = 1; .grh = {...}; }'.

ibv_destroy_ah() devuelve 0 en caso de éxito, o el valor de errno en caso de fallo (que indica la razón del fallo).

VER TAMBIÉN

ibv_alloc_pd(3), ibv_init_ah_from_wc(3), ibv_create_ah_from_wc(3)
