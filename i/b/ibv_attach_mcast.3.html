IBV_ATTACH_MCAST(3) Manual del programador de Libibverbs IBV_ATTACH_MCAST(3)

NOMBRE

ibv_attach_mcast, ibv_detach_mcast - adjuntar y desadjuntar un par de colas (QPs) a/desde un grupo multicast

SINOPSIS

#include <infiniband/verbs.h>
int ibv_attach_mcast(struct ibv_qp *qp, const union ibv_gid *gid, uint16_t lid);
int ibv_detach_mcast(struct ibv_qp *qp, const union ibv_gid *gid, uint16_t lid);

DESCRIPCIÓN

ibv_attach_mcast() adjunta el QP qp al grupo multicast con MGID gid y MLID lid.

ibv_detach_mcast() desadjunta el QP qp del grupo multicast con MGID gid y MLID lid.

VALOR DE RETORNO

ibv_attach_mcast() y ibv_detach_mcast() devuelven 0 en caso de éxito, o el valor de errno en caso de fallo (que indica la razón del fallo).

NOTAS

Solo los QPs de Tipo de Servicio de Transporte IBV_QPT_UD pueden adjuntarse a grupos multicast.

Si un QP se adjunta al mismo grupo multicast varias veces, el QP seguirá recibiendo una única copia de un mensaje multicast.

Para recibir mensajes multicast, se debe enviar una solicitud de unión al grupo multicast al administrador de la subred (SA), de modo que el enrutamiento multicast de la red esté configurado para entregar mensajes al puerto local.
