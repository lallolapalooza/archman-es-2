ibv_import_device(3) Manual del programador de Libibverbs ibv_import_device(3)

NOMBRE

ibv_import_device - importar un dispositivo desde un descriptor de archivo de comando dado

SINOPSIS

#include <infiniband/verbs.h>
struct ibv_context *ibv_import_device(int cmd_fd);

DESCRIPCIÓN

ibv_import_device() devuelve un puntero ibv_context que está asociado con el cmd_fd dado.

El cmd_fd se obtiene del miembro cmd_fd del ibv_context, que debe duplicarse (por ejemplo, con dup(), SCM_RIGHTS, etc.) antes de pasarse a ibv_import_device().

Una vez que se haya finalizado el uso del ibv_context, se debe llamar a ibv_close_device(). Esta llamada puede limpiar lo que sea necesario/opuesto a la importación, incluido el cierre del descriptor de archivo de comando.

VALOR DE RETORNO

ibv_import_device() devuelve un puntero al contexto RDMA asignado, o NULL si la solicitud falla.

VER TAMBIÉN

ibv_open_device(3), ibv_close_device(3),
