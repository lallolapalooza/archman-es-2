IBV_QUERY_PORT(3) Manual del programador de Libibverbs IBV_QUERY_PORT(3)

NOMBRE

ibv_query_port - consultar los atributos de un puerto RDMA

SINOPSIS

#include <infiniband/verbs.h>

int ibv_query_port(struct ibv_context *context, uint8_t port_num,
                   struct ibv_port_attr *port_attr);

DESCRIPCIÓN

ibv_query_port() devuelve los atributos del puerto port_num para el contexto del dispositivo context a través del puntero port_attr. El argumento port_attr es una estructura ibv_port_attr, tal como se define en <infiniband/verbs.h>.

struct ibv_port_attr {
enum ibv_port_state     state;          /* Estado lógico del puerto */
enum ibv_mtu            max_mtu;        /* MTU máximo admitido por el puerto */
enum ibv_mtu            active_mtu;     /* MTU real */
int                     gid_tbl_len;    /* Longitud de la tabla GID de origen */
uint32_t                port_cap_flags; /* Capacidades del puerto */
uint32_t                max_msg_sz;     /* Tamaño máximo del mensaje */
uint32_t                bad_pkey_cntr;  /* Contador de P_Key erróneos */
uint32_t                qkey_viol_cntr; /* Contador de violaciones de Q_Key */
uint16_t                pkey_tbl_len;   /* Longitud de la tabla de partición */
uint16_t                lid;            /* LID base del puerto */
uint16_t                sm_lid;         /* LID del SM */
uint8_t                 lmc;            /* LMC del LID */
uint8_t                 max_vl_num;     /* Número máximo de VL */
uint8_t                 sm_sl;          /* Nivel de servicio del SM */
uint8_t                 subnet_timeout; /* Retraso de propagación de la subred */
uint8_t                 init_type_reply;/* Tipo de inicialización realizada por el SM */
uint8_t                 active_width;   /* Ancho de enlace activo actual */
uint8_t                 active_speed;   /* Velocidad de enlace activa actual si la velocidad es

VALOR DE RETORNO

ibv_query_port() devuelve 0 si tiene éxito, o el valor de errno en caso de fallo (que indica el motivo del fallo).

VER TAMBIÉN

ibv_create_qp(3), ibv_destroy_qp(3), ibv_query_qp(3), ibv_create_ah(3)
