ibidsverify(8) Diagnóstico de IB Abierto ibidsverify(8)

Nombre

ibidsverify - valida los identificadores de IB en la subred e informa errores

SINOPSIS

ibidsverify.pl [-h] [-R]

DESCRIPCIÓN

ibidsverify.pl es un script de perl que utiliza un archivo de topología completo creado por ibnetdiscover, escanea la red para validar los LID y GUID en la subred. La validación consiste en comprobar que no hay identificadores cero o duplicados.

Finalmente, ibidsverify.pl también reutiliza la salida en caché de ibnetdiscover de algunas de las otras herramientas de diagnóstico, lo que lo hace un poco más rápido que ejecutar ibnetdiscover desde cero.

OPCIONES

-R Recalcular la información de ibnetdiscover, es decir, no usar la información en caché. Esta opción es más lenta, pero debe usarse si las herramientas de diagnóstico no se han utilizado durante algún tiempo o si hay otras razones para creer que la estructura ha cambiado.

-C <nombre_ca> usar el nombre_ca especificado.

-P <puerto_ca> usar el puerto_ca especificado.

ESTADO DE SALIDA

El estado de salida es 1 si se encuentran errores, 0 en caso contrario.

ARCHIVOS

ARCHIVO DE CONFIGURACIÓN

/etc/infiniband-diags/ibdiag.conf

Se proporciona un archivo de configuración global para establecer algunas de las opciones comunes para todas las herramientas. Consulte el archivo de configuración proporcionado para obtener detalles.
