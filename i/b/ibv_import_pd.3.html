ibv_import_pd, ibv_unimport_pd(3) Manual del programador de Libibverbs ibv_import_pd, ibv_unimport_pd(3)

NOMBRE

ibv_import_pd - importar un PD de un ibv_context dado

ibv_unimport_pd - desimportar un PD

SINOPSIS

#include <infiniband/verbs.h>
struct ibv_pd *ibv_import_pd(struct ibv_context *context, uint32_t pd_handle);
void ibv_unimport_pd(struct ibv_pd *pd)

DESCRIPCIÓN

ibv_import_pd() devuelve un dominio de protección (PD) que está asociado con el pd_handle dado en el context dado.

El valor pd_handle de entrada debe ser un identificador válido del kernel para un objeto PD en el context dado. Se puede obtener del PD original obteniendo el valor de su miembro ibv_pd->handle.

El ibv_pd devuelto se puede utilizar en todos los verbs que reciben un dominio de protección.

ibv_unimport_pd() desimporta el PD. Una vez que se ha finalizado el uso del PD, se debe llamar a ibv_dealloc_pd() o ibv_unimport_pd(). La primera irá al kernel para destruir el objeto, mientras que la segunda limpiará lo que sea necesario/opuesto a la importación sin llamar al kernel.

Es responsabilidad de la aplicación coordinar entre todos los ibv_context(s) que utilizan este PD. Una vez que se ha realizado la destrucción, ningún otro proceso puede manipular el objeto excepto para desimportarlo. Todos los usuarios del contexto deben colaborar para garantizar esto.

VALOR DEVUELTO

ibv_import_pd() devuelve un puntero al PD asignado, o NULL si la solicitud falla.

VER TAMBIÉN
