IBPORTSTATE(8) Diagnósticos Open IB IBPORTSTATE(8)

Nombre

ibportstate - manejar el estado (físico) del puerto y la velocidad del enlace de un puerto InfiniBand

SINOPSIS

ibportstate [opciones] <destino dr_path|lid|guid> <número_de_puerto> [<op>]

DESCRIPCIÓN

ibportstate permite consultar el estado del puerto y el estado físico del puerto de un puerto IB (además de validar el ancho y la velocidad del enlace con respecto al puerto par cuando el puerto consultado es un puerto de conmutador), o deshabilitar, habilitar o restablecer un puerto de conmutador. El estado del puerto HCA de InfiniBand puede cambiarse localmente sin el conocimiento del Subnet Manager. También permite ajustar la velocidad/ancho del enlace habilitado en cualquier puerto IB.

OPCIONES

<op>
Operaciones admitidas: enable, disable, reset, speed, espeed, fdr10, width, query,
on, off, down, arm, active, vls, mtu, lid, smlid, lmc, mkey, mkeylease, mkeyprot (El valor predeterminado es query)

enable, disable y reset cambian o restablecen el estado de un puerto de conmutador o HCA (Debe especificar el nombre del CA y el número de puerto al cambiar localmente el estado del puerto del CA.)

off cambia el estado del puerto a deshabilitado.

on cambia el estado del puerto a habilitado (solo cuando el estado actual es deshabilitado).

speed y width están permitidos en cualquier puerto

speed los valores son los valores legales para PortInfo:LinkSpeedEnabled (Se indica un error si PortInfo:LinkSpeedSupported no admite esta configuración)

espeed está permitido en cualquier puerto que admita velocidades de enlace extendidas

fdr10 está permitido en cualquier puerto que admita fdr10 (Se indica un error si la máscara de capacidad del puerto indica que no se admiten velocidades de enlace extendidas o si PortInfo:LinkSpeedExtSupported no admite esta configuración)

width los valores son valores legales para PortInfo:LinkWidthEnabled (Se indica un error si PortInfo:LinkWidthSupported no admite esta configuración) (NOTA: Los cambios de velocidad y ancho no tienen efecto hasta que el puerto pasa por una renegociación del enlace)

query también valida las características del puerto (ancho del enlace, velocidad, espeed y fdr10) basándose en el puerto par. Esta comprobación se realiza cuando el puerto consultado es un puerto de conmutador, ya que depende del enrutamiento combinado (un enrutamiento LID inicial con enrutamiento dirigido hacia el par), lo cual solo puede hacerse en un conmutador. Esta función de validación del puerto par de la operación query requiere que el enrutamiento LID funcione en la subred.

mkey, mkeylease y mkeyprot solo están permitidos en CAs, enrutadores o puerto 0 del conmutador (Se genera un error si se intenta en puertos externos del conmutador). Las claves mkey en hexadecimal y octal pueden especificarse anteponiendo '0x' o '0' a la clave, respectivamente. Si se especifica un valor no numérico (como 'x') para la mkey, ibportstate solicitará un valor.

Banderas de direccionamiento

-L, --Lid La dirección especificada es un LID

-G, --Guid La dirección especificada es un GUID de puerto

-D, --Direct La dirección especificada es una ruta dirigida

Ejemplos:
   [opciones] -D [opciones] "0"          # puerto propio
   [opciones] -D [opciones] "0,1,2,1,4"  # salir por el puerto 1, luego 2, ...
   (Tenga en cuenta que el segundo número en la ruta especificada debe coincidir con el puerto utilizado. Esto puede especificarse usando la bandera de selección de puerto '-P' o el puerto encontrado mediante el proceso de selección automática.)

-s, --sm_port <smlid> usar 'smlid' como lid de destino para las consultas al SA.

Banderas de selección de puerto

-C, --Ca <ca_name> usar el ca_name especificado.

-P, --Port <ca_port> usar el ca_port especificado.

Selección de puerto local

Soporte de múltiples puertos/múltiples CAs: cuando no se especifica ningún dispositivo o puerto IB (vea los "parámetros umad locales" más abajo), la biblioteca libibumad selecciona el puerto a usar según los siguientes criterios:

1.
el primer puerto que esté ACTIVO.
2.
si no se encuentra, el primer puerto que esté UP (enlace físico activo).

Si se especifica un puerto y/o nombre de CA, la biblioteca libibumad intentará satisfacer la solicitud del usuario y fallará si no es posible.

Por ejemplo:

ibaddr                 # usar el primer puerto (criterio #1 anterior)
ibaddr -C mthca1       # elegir el mejor puerto solo de "mthca1".
ibaddr -P 2            # usar el segundo puerto (activo/up) del primer dispositivo IB disponible.
ibaddr -C mthca0 -P 2  # usar solo el puerto especificado.

Banderas de configuración

--config, -z <config_file> Especificar un archivo de configuración alternativo.

Predeterminado: /etc/infiniband-diags/ibdiag.conf

-t, --timeout <timeout_ms> anular el tiempo de espera predeterminado para los mads solicitados.

-y, --m_key <key>
usar la M_key especificada para las solicitudes. Si se especifica un valor no numérico (como 'x'), se solicitará un valor.

Banderas de depuración

-h, --help mostrar el mensaje de uso

-d
aumentar el nivel de depuración de IB. Puede usarse varias veces (-ddd o -d -d -d).
-e
mostrar errores de envío y recepción (tiempos de espera y otros)
-K, --show_keys
mostrar las claves de seguridad (mkey, smkey, etc.) asociadas con la solicitud.
-v, --verbose
aumentar el nivel de verbosidad de la aplicación. Puede usarse varias veces (-vv o -v -v -v)

-V, --version mostrar la información de la versión.

ARCHIVOS

ARCHIVO DE CONFIGURACIÓN

/etc/infiniband-diags/ibdiag.conf

Se proporciona un archivo de configuración global para establecer algunas de las opciones comunes para todas las herramientas. Consulte el archivo de configuración suministrado para más detalles.

EJEMPLOS

ibportstate -C qib0 -P 1 3 1 disable     # por nombre de CA, número de puerto del CA, lid, número de puerto físico
ibportstate -C qib0 -P 1 3 1 enable      # por nombre de CA, número de puerto del CA, lid, número de puerto físico
ibportstate -D 0 1                       # (query) por ruta dirigida
ibportstate 3 1 reset                    # por lid
ibportstate 3 1 speed 1                  # por lid
ibportstate 3 1 width 1                  # por lid
ibportstate -D 0 1 lid 0x1234 arm        # por ruta dirigida
