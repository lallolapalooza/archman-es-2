IBV_CREATE_CQ_EX(3) Manual del Programador de Libibverbs IBV_CREATE_CQ_EX(3)

NOMBRE

ibv_create_cq_ex - crear una cola de finalización (CQ)

SINOPSIS

#include <infiniband/verbs.h>

struct ibv_cq_ex *ibv_create_cq_ex(struct ibv_context *context,
                                   struct ibv_cq_init_attr_ex *cq_attr);

DESCRIPCIÓN

ibv_create_cq_ex() crea una cola de finalización (CQ) para el contexto del dispositivo RDMA context. El argumento cq_attr es un puntero a struct ibv_cq_init_attr_ex como se define en <infiniband/verbs.h>.

struct ibv_cq_init_attr_ex {
int                     cqe;               /* Número mínimo de entradas requeridas para la CQ */
void                    *cq_context;       /* Contexto proporcionado por el consumidor devuelto para eventos de finalización */
struct ibv_comp_channel *channel;          /* Canal de finalización donde se pondrán en cola los eventos de finalización. Puede ser NULL si no se utilizarán eventos de finalización. */
int                     comp_vector;       /* Vector de finalización utilizado para señalar eventos de finalización. Debe ser >= 0 y < context->num_comp_vectors. */
uint64_t                wc_flags;          /* Los wc_flags que deben devolverse en ibv_poll_cq_ex. OR de bits de enum ibv_wc_flags_ex. */
uint32_t                comp_mask;         /* Máscara de compatibilidad (verbo extendido). */
uint32_t                flags              /* Una o más banderas de enum ibv_create_cq_attr_flags */
struct ibv_pd           *parent_domain;    /* Dominio padre a utilizar por esta CQ */
};
enum ibv_wc_flags_ex {
        IBV_WC_EX_WITH_BYTE_LEN              = 1 << 0,  /* Requerir longitud de bytes en WC */
        IBV_WC_EX_WITH_IMM                   = 1 << 1,  /* Requerir inmediato en WC */
        IBV_WC_EX_WITH_QP_NUM                = 1 << 2,  /* Requerir número de QP en WC */
        IBV_WC_EX_WITH_SRC_QP                = 1 << 3,  /* Requerir QP de origen en WC */
        IBV_WC_EX_WITH_SLID                  = 1 << 4,  /* Requerir SLID en WC */
        IBV_WC_EX_WITH_SL                    = 1 << 5,  /* Requerir SL en WC */
        IBV_WC_EX_WITH_DLID_PATH_BITS        = 1 << 6,  /* Requerir bits de ruta DLID en WC */
        IBV_WC_EX_WITH_COMPLETION_TIMESTAMP  = 1 << 7,  /* Requerir marca de tiempo del dispositivo de finalización en WC /*
        IBV_WC_EX_WITH_CVLAN                 = 1 << 8,  /* Requerir información VLAN en WC */
        IBV_WC_EX_WITH_FLOW_TAG		     = 1 << 9,  /* Requerir etiqueta de flujo en WC */
        IBV_WC_EX_WITH_COMPLETION_TIMESTAMP_WALLCLOCK  = 1 << 11, /* Requerir marca de tiempo del reloj de pared de finalización en WC */
};
enum ibv_cq_init_attr_mask {
        IBV_CQ_INIT_ATTR_MASK_FLAGS             = 1 << 0,
        IBV_CQ_INIT_ATTR_MASK_PD                = 1 << 1,
};
enum ibv_create_cq_attr_flags {
        IBV_CREATE_CQ_ATTR_SINGLE_THREADED      = 1 << 0, /* Esta CQ se utiliza desde un solo hilo, por lo que no se requieren bloqueos */
        IBV_CREATE_CQ_ATTR_IGNORE_OVERRUN       = 1 << 1, /* Esta CQ no pasará al estado de error si hay desbordamiento, CQE siempre se escribirá en la siguiente entrada.
                                                           * Una aplicación debe diseñarse para evitar que la CQ se desborde, de lo contrario, se podrían perder los CQE.
                                                           */
};

Sondeo de una CQ extendida

Para sondear una CQ extendida de manera eficiente, un usuario puede utilizar las siguientes funciones.

Funciones iteradoras de finalización

int ibv_start_poll(struct ibv_cq_ex *cq, struct ibv_poll_cq_attr *attr)
Inicia el sondeo de un lote de finalizaciones de trabajo. Se proporciona attr para que esta función sea fácilmente extensible en el futuro. Esta función devuelve 0 si tiene éxito o un código de error en caso contrario. Cuando no hay finalizaciones disponibles en la CQ, se devuelve ENOENT, pero la CQ permanece en un estado válido. Si tiene éxito, se puede consultar el atributo de la finalización utilizando las funciones de consulta descritas a continuación. Si se devuelve un código de error, no se debe llamar a end_poll.

int ibv_next_poll(struct ibv_cq_ex *cq)
Esta función se llama para obtener la siguiente finalización de trabajo. Debe llamarse después de llamar a start_poll y antes de llamar a end_poll. Esta función devuelve 0 si tiene éxito o un código de error en caso contrario. Cuando no hay finalizaciones disponibles en la CQ, se devuelve ENOENT, pero la CQ permanece en un estado válido. Si tiene éxito, se puede consultar el atributo de la finalización utilizando las funciones de consulta descritas a continuación. Si se devuelve un código de error, aún se debe llamar a end_poll, lo que indica que este es el final del lote sondeado.

void ibv_end_poll(struct ibv_cq_ex *cq)
Esta función indica el final del lote de sondeo de finalizaciones de trabajo. Después de llamar a esta función, el usuario debe iniciar un nuevo lote llamando a start_poll.

Sondeo de campos en la finalización
Los siguientes miembros y funciones se utilizan para sondear la finalización actual. La finalización actual es la finalización a la que apunta el iterador (start_poll y next_poll avanzan este iterador). Solo se pueden consultar los campos que el usuario solicitó a través de wc_flags en ibv_create_cq_ex. Además, algunos campos solo son válidos para determinados opcodes y códigos de estado.

uint64_t wr_id - Se puede acceder directamente desde struct ibv_cq_ex.

enum ibv_wc_status - Se puede acceder directamente desde struct ibv_cq_ex.

enum ibv_wc_opcode ibv_wc_read_opcode(struct ibv_cq_ex *cq); Obtiene el opcode de la finalización actual.

uint32_t ibv_wc_read_vendor_err(struct ibv_cq_ex *cq); Obtiene el error del proveedor de la finalización actual.

uint32_t ibv_wc_read_byte_len(struct ibv_cq_ex *cq); Obtiene la longitud de la carga útil de la finalización actual.

__be32 ibv_wc_read_imm_data(struct ibv_cq_ex *cq); Obtiene el campo de datos inmediato de la finalización actual.

uint32_t ibv_wc_read_invalidated_rkey(struct ibv_cq_ex *cq); Obtiene la rkey invalidada por SEND_INVAL de la finalización actual.

uint32_t ibv_wc_read_qp_num(struct ibv_cq_ex *cq); Obtiene el campo de número de QP de la finalización actual.

uint32_t ibv_wc_read_src_qp(struct ibv_cq_ex *cq); Obtiene el campo de número de QP de origen de la finalización actual.

unsigned int ibv_wc_read_wc_flags(struct ibv_cq_ex *cq); Obtiene el campo de banderas de QP de la finalización actual.

uint16_t ibv_wc_read_pkey_index(struct ibv_cq_ex *cq); Obtiene el campo de índice pkey de la finalización actual.

uint32_t ibv_wc_read_slid(struct ibv_cq_ex *cq); Obtiene el campo SLID de la finalización actual.

uint8_t ibv_wc_read_sl(struct ibv_cq_ex *cq); Obtiene el campo SL de la finalización actual.

uint8_t ibv_wc_read_dlid_path_bits(struct ibv_cq_ex *cq); Obtiene el campo dlid_path_bits de la finalización actual.

uint64_t ibv_wc_read_completion_ts(struct ibv_cq_ex *cq); Obtiene la marca de tiempo de finalización de la finalización actual en unidades de reloj del HCA.

uint64_t ibv_wc_read_completion_wallclock_ns(struct ibv_cq_ex *cq); Obtiene la marca de tiempo de finalización de la finalización actual y la convierte de unidades de reloj del HCA a nanosegundos del reloj de pared.

uint16_t ibv_wc_read_cvlan(struct ibv_cq_ex *cq); Obtiene el campo CVLAN de la finalización actual.

uint32_t ibv_wc_read_flow_tag(struct ibv_cq_ex *cq); Obtiene la etiqueta de flujo de la finalización actual.

void ibv_wc_read_tm_info(struct ibv_cq_ex *cq, struct ibv_wc_tm_info *tm_info); Obtiene la información de coincidencia de etiquetas de la finalización actual.

struct ibv_wc_tm_info {
uint64_t tag;  /* etiqueta de TMH */
uint32_t priv; /* datos opacos del usuario de TMH */
};

VALOR DE RETORNO

ibv_create_cq_ex() devuelve un puntero a la CQ, o NULL si la solicitud falla.

NOTAS

ibv_create_cq_ex() puede crear una CQ con un tamaño mayor o igual al solicitado. Verifique el atributo cqe en la CQ devuelta para conocer el tamaño real.

La CQ debe ser destruida con ibv_destroy_cq.
