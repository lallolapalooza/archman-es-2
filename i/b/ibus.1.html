IBUS(1) Comandos de usuario IBUS(1)

NOMBRE

ibus - utilidad de línea de comandos para ibus

SINOPSIS

ibus COMANDO [OPCIÓN]...

DESCRIPCIÓN

IBus es un Bus de Entrada Inteligente. Es un nuevo framework de entrada para el sistema operativo Linux. Proporciona una interfaz de usuario de método de entrada completa y fácil de usar. También puede ayudar a los desarrolladores a desarrollar métodos de entrada fácilmente.

ibus es una utilidad de línea de comandos que puede reiniciar o salir de ibus-daemon, obtener o establecer el motor ibus actual o listar los motores ibus.

Página principal: https://github.com/ibus/ibus/wiki

COMANDO

help
Muestra la lista de comandos.
engine [NOMBRE_MOTOR]
Muestra el motor ibus actual cuando no se proporciona NOMBRE_MOTOR. Establece NOMBRE_MOTOR como el motor ibus actual.
exit
Sale de ibus-daemon.
list-engine
Muestra la lista de motores ibus.
restart [--type=TIPO|--verbose|--help]
Reinicia ibus-daemon. Este comando intenta reiniciar ibus-daemon a través de systemd primero y directamente después por defecto. Si se proporciona --type=systemd, intenta reiniciar solo a través de systemd. Si se proporciona --type=direct, intenta reiniciar solo con una API de IBus. El escritorio GNOME ejecuta ibus-daemon a través de systemd y otros escritorios ejecutan ibus-daemon directamente.
start [--type=TIPO|--verbose|--help]
Inicia ibus-daemon. Este comando intenta iniciar ibus-daemon a través de systemd primero y directamente después por defecto. Si se proporciona --type=systemd, intenta iniciarlo solo como un proceso en segundo plano a través de systemd. Si se proporciona --type=direct, intenta iniciarlo directamente solo como un proceso en primer plano y las demás opciones del comando ibus se envían a ibus-daemon. Por ejemplo: ibus start --type=direct --xim & El escritorio GNOME ejecuta ibus-daemon a través de systemd y otros escritorios ejecutan ibus-daemon directamente.
version
Muestra la versión de ibus.
read-cache [--system|--file=ARCHIVO|--help]
Muestra el contenido de la caché de registro de usuario si no se proporciona --system. Muestra el contenido de la caché de registro del sistema si se proporciona --system. Muestra el contenido de la caché de registro personalizada ARCHIVO si se proporciona --file=ARCHIVO.
write-cache [--system|--file=ARCHIVO|--help]
Guarda la caché de registro de usuario si no se proporciona --system. Guarda la caché de registro del sistema si se proporciona --system. Guarda la caché de registro personalizada ARCHIVO si se proporciona --file=ARCHIVO.

Por defecto, lee los archivos XML de componentes del directorio de componentes estándar (/usr/share/ibus/component), puede establecer la variable de entorno IBUS_COMPONENT_PATH para directorios de componentes personalizados, separados por ':'.

address
Muestra la dirección D-Bus de ibus-daemon.
read-config
Imprime los valores de configuración en un archivo de configuración de gsettings.
reset-config
Restablece los valores de configuración del usuario a los predeterminados en un archivo de configuración de gsettings.
watch
En construcción.
emoji [--font=FUENTE|--lang=IDIOMA|--help|--partial-match]
Inicia el selector de emojis de IBus ( ibus-emoji (1) ) y guarda el emoji seleccionado en su portapapeles. Puede elegir una fuente de emoji con la opción --font. Puede elegir un idioma de anotaciones de emoji con la opción --lang. Si LANG="en", IBus Emojier carga /usr/share/ibus/dicts/emoji-en.dict. La opción --partial-match permite coincidir anotaciones con una cadena parcial. Estas configuraciones están disponibles con la utilidad ibus-setup (1).
im-module [--type=TIPO|--help]
Muestra un valor interno de im-module en una aplicación GTK virtual. Si IBus está instalado y configurado correctamente, la salida es "ibus". Este subcomando es útil para algunos usuarios que compilan IBus desde el código fuente y verifican las configuraciones. Actualmente el subcomando soporta solo aplicaciones GTK y el valor predeterminado es GTK3. Si desea verificar una aplicación GTK4, puede especificar la opción --type=gtk4 y puede elegir una de "gtk2", "gtk3" y "gtk4".

ERRORES

Si encuentra un error, repórtelo en https://github.com/ibus/ibus/issues
