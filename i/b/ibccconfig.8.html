IBCCCONFIG(8) Diagnósticos OpenIB IBCCCONFIG(8)

Nombre

ibccconfig - configurar ajustes de control de congestión

SINOPSIS

ibccconfig [opciones_comunes] [-c cckey] <op> <lid|guid> [puerto]

DESCRIPCIÓN

ibccconfig soporta la configuración de ajustes de control de congestión en switches y HCAs.

ADVERTENCIA -- Debes entender lo que estás haciendo antes de usar esta herramienta. El uso incorrecto de esta herramienta podría resultar en una red rota.

OPCIONES

Operaciones compatibles actualmente y sus parámetros:
CongestionKeyInfo (CK) <lid|guid> <cckey> <cckeyprotectbit> <cckeyleaseperiod> <cckeyviolations> SwitchCongestionSetting (SS) <lid|guid> <controlmap> <victimmask> <creditmask> <threshold> <packetsize> <csthreshold> <csreturndelay> <markingrate> SwitchPortCongestionSetting (SP) <lid|guid> <portnum> <valid> <control_type> <threshold> <packet_size> <cong_parm_marking_rate> CACongestionSetting (CS) <lid|guid> <port_control> <control_map> <ccti_timer> <ccti_increase> <trigger_threshold> <ccti_min> CongestionControlTable (CT) <lid|guid> <cctilimit> <index> <cctentry> <cctentry> ...

--cckey, -c, <cckey> Especifica una clave de control de congestión (CC). Si no se especifica ninguna, se usa la clave 0.

Flags de depuración

-d
aumenta el nivel de depuración de IB. Puede usarse varias veces (-ddd o -d -d -d).
-e
muestra errores de envío y recepción (tiempos de espera y otros)

-h, --help muestra el mensaje de uso

-v, --verbose
aumenta el nivel de verbosidad de la aplicación. Puede usarse varias veces (-vv o -v -v -v)

-V, --version muestra la información de la versión.

Flags de direccionamiento

-G, --Guid La dirección especificada es un GUID de puerto

-L, --Lid La dirección especificada es una LID

-s, --sm_port <smlid> usa 'smlid' como la LID de destino para las consultas SA.

Flags de selección de puerto

-C, --Ca <ca_name> usa el ca_name especificado.

-P, --Port <ca_port> usa el ca_port especificado.

Selección de puerto local

Soporte para múltiples puertos/múltiples CA: cuando no se especifica dispositivo o puerto IB (ver los "parámetros umad locales" a continuación), la biblioteca libibumad selecciona el puerto a usar según los siguientes criterios:

1.
el primer puerto que esté ACTIVO.
2.
si no se encuentra, el primer puerto que esté ARRIBA (enlace físico activo).

Si se especifica un nombre de puerto y/o CA, la biblioteca libibumad intenta cumplir la solicitud del usuario, y fallará si no es posible.

Por ejemplo:

ibaddr                 # usa el primer puerto (criterio #1 arriba)
ibaddr -C mthca1       # elige el mejor puerto solo de "mthca1".
ibaddr -P 2            # usa el segundo puerto (activo/arriba) del primer dispositivo IB disponible.
ibaddr -C mthca0 -P 2  # usa solo el puerto especificado.

Flags de configuración

-y, --m_key <key>
usa la M_key especificada para las solicitudes. Si se especifica un valor no numérico (como 'x'), se solicitará.

--config, -z <config_file> Especifica un archivo de configuración alternativo.

Predeterminado: /etc/infiniband-diags/ibdiag.conf

EJEMPLOS

ibccconfig SwitchCongestionSetting 2 0x1F 0x1FFFFFFFFF 0x0 0xF 8 0 0:0 1  # Configurar ajustes de congestión del switch
ibccconfig CACongestionSetting 1 0 0x3 150 1 0 0                          # Configurar ajustes de congestión de CA a SL 0 y SL 1
ibccconfig CACongestionSetting 1 0 0x4 200 1 0 0                          # Configurar ajustes de congestión de CA a SL 2
ibccconfig CongestionControlTable 1 63 0 0:0 0:1 ...                      # Configurar el primer bloque de la tabla de control de congestión
ibccconfig CongestionControlTable 1 127 0 0:64 0:65 ...                   # Configurar el segundo bloque de la tabla de control de congestión

ARCHIVOS

ARCHIVO DE CONFIGURACIÓN

/etc/infiniband-diags/ibdiag.conf

Se proporciona un archivo de configuración global para establecer algunas de las opciones comunes para todas las herramientas. Consulte el archivo de configuración proporcionado para obtener más detalles.
