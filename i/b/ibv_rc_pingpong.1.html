IBV_RC_PINGPONG(1) COMANDOS DE USUARIO IBV_RC_PINGPONG(1)

NOMBRE

ibv_rc_pingpong - prueba simple de transporte InfiniBand RC

SINOPSIS

ibv_rc_pingpong [-p puerto] [-d dispositivo] [-i puerto ib] [-s tamaño] [-m tamaño] [-r profundidad rx] [-n iters] [-l sl] [-e] [-g índice gid] [-o] [-P] [-t] [-j] [-N] NOMBRE_HOST

ibv_rc_pingpong [-p puerto] [-d dispositivo] [-i puerto ib] [-s tamaño] [-m tamaño] [-r profundidad rx] [-n iters] [-l sl] [-e] [-g índice gid] [-o] [-P] [-t] [-j] [-N]

DESCRIPCIÓN

Ejecuta una prueba simple de ping-pong a través de InfiniBand utilizando el transporte de conexión confiable (RC).

OPCIONES

-p, --port=PUERTO
usa el puerto TCP PUERTO para la sincronización inicial (por defecto 18515)
-d, --ib-dev=DISPOSITIVO
usa el dispositivo IB DISPOSITIVO (por defecto, el primer dispositivo encontrado)
-i, --ib-port=PUERTO
usa el puerto IB PUERTO (por defecto, puerto 1)
-s, --size=TAMAÑO
mensajes de ping-pong de tamaño TAMAÑO (por defecto 4096)
-m, --mtu=TAMAÑO
MTU de ruta TAMAÑO (por defecto 1024)
-r, --rx-depth=PROFUNDIDAD
publica PROFUNDIDAD recepciones a la vez (por defecto 1000)
-n, --iters=ITERS
realiza ITERS intercambios de mensajes (por defecto 1000)
-l, --sl=SL
usa SL como valor de nivel de servicio del QP (por defecto 0)
-e, --events
duerme mientras espera eventos de finalización de trabajo (por defecto, sondea las finalizaciones)
-g, --gid-idx=GIDINDEX
puerto local GIDINDEX
-o, --odp
usa paginación bajo demanda
-P, --prefetch=
pre-busca un MR ODP
-t, --ts
obtiene CQE con marca de tiempo
-c, --chk
valida el buffer recibido
-j, --dm
usa memoria del dispositivo
-N, --new_send
usa la API de WR de envío nueva

VER TAMBIÉN

ibv_uc_pingpong(1), ibv_ud_pingpong(1), ibv_srq_pingpong(1), ibv_xsrq_pingpong(1)

ERRORES

La sincronización de red entre las instancias cliente y servidor es débil y no evita el uso de opciones incompatibles en ambas instancias. El método utilizado para recuperar las finalizaciones de trabajo no es estrictamente correcto y las condiciones de carrera pueden causar fallos en algunos sistemas.
