IBV_QUERY_GID_EX(3) Manual del programador de Libibverbs IBV_QUERY_GID_EX(3)

NOMBRE

ibv_query_gid_ex - Consultar una entrada de la tabla GID del puerto InfiniBand

SINOPSIS

#include <infiniband/verbs.h>
int ibv_query_gid_ex(struct ibv_context *context,
                     uint32_t port_num,
                     uint32_t gid_index,
                     struct ibv_gid_entry *entry,
                     uint32_t flags);

DESCRIPCIÓN

ibv_query_gid_ex() devuelve la entrada GID en entry para el gid_index del puerto port_num para el contexto del dispositivo context.

ARGUMENTOS

context
El contexto del dispositivo a consultar.
port_num
El número del puerto del que consultar la tabla GID.
gid_index
El índice de la entrada de la tabla GID a consultar.
## Argumento entry
Una estructura ibv_gid_entry, como se define en <infiniband/verbs.h>.
struct ibv_gid_entry {
    union ibv_gid gid;
    uint32_t gid_index;
    uint32_t port_num;
    uint32_t gid_type;
    uint32_t ndev_ifindex;
};

gid

    La entrada GID.

gid_index

    El índice de la tabla GID de esta entrada.

port_num

    El número de puerto al que pertenece este GID.

gid_type

    enum ibv_gid_type, puede ser uno de IBV_GID_TYPE_IB, IBV_GID_TYPE_ROCE_V1 o IBV_GID_TYPE_ROCE_V2.

ndev_ifindex

    El índice de interfaz del dispositivo de red asociado con este GID.
    Es 0 si no hay ningún dispositivo de red asociado a él.
flags
Campos adicionales a consultar después de ndev_ifindex, por ahora debe ser 0.

VALOR DE RETORNO

ibv_query_gid_ex() devuelve 0 si tiene éxito o el valor errno en caso de error.

ERRORES

ENODATA
gid_index está dentro del tamaño de la tabla GID del puerto port_num pero no hay datos en este índice.

VER TAMBIÉN

ibv_open_device(3), ibv_query_device(3), ibv_query_pkey(3), ibv_query_port(3), ibv_query_gid_table(3)
