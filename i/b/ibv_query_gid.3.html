IBV_QUERY_GID(3) Manual del programador de Libibverbs IBV_QUERY_GID(3)

NOMBRE

ibv_query_gid - consulta la tabla GID del puerto InfiniBand

SINOPSIS

#include <infiniband/verbs.h>
int ibv_query_gid(struct ibv_context *context,
                  uint8_t port_num,
                  int index,
                  union ibv_gid *gid);

DESCRIPCIÓN

ibv_query_gid() devuelve el valor GID en la entrada index del puerto port_num para el contexto del dispositivo context a través del puntero gid.

VALOR DE RETORNO

ibv_query_gid() devuelve 0 si tiene éxito y -1 si hay un error.

VER TAMBIÉN

ibv_open_device(3), ibv_query_device(3), ibv_query_pkey(3), ibv_query_port(3)
