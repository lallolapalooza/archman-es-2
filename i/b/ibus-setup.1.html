NOMBRE

ibus-setup - programa de configuración para ibus

SINOPSIS

ibus-setup

DESCRIPCIÓN

IBus es un Bus de Entrada Inteligente. Es un nuevo framework de entrada para el sistema operativo Linux. Proporciona una interfaz de usuario de método de entrada con todas las funciones y fácil de usar. También puede ayudar a los desarrolladores a desarrollar métodos de entrada fácilmente.

ibus-setup es el programa de configuración para IBus.

Página de inicio: https://github.com/ibus/ibus/wiki

AVANZADO

Usar diseño de teclado del sistema
Si esta opción está activada, utiliza tu mapa de teclas del sistema y IBus no lo modificará con ningún motor de método de entrada. El mapa de teclas del sistema se decide por tu sesión de escritorio. IBus llama al comando setxkbmap (1) internamente para establecer el mapa de teclas seleccionado y anula el mapa de teclas del sistema si esta opción está desactivada. Puedes comprobar el mapa de teclas actual con el comando setxkbmap -query.
Compartir el mismo método de entrada entre todas las aplicaciones
Si esta opción está desactivada, puedes elegir un motor de método de entrada por contexto de entrada.

ERRORES

Si encuentras un error, por favor repórtalo en https://github.com/ibus/ibus/issues
