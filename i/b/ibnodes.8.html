IBNODES(8) Diagnósticos de OpenIB IBNODES(8)

Nombre

IBNODES - mostrar nodos InfiniBand en la topología

SINOPSIS

ibnodes [opciones] [<archivo-topología>]

DESCRIPCIÓN

ibnodes es un script que recorre la topología de subred IB o utiliza un archivo de topología guardado previamente y extrae los nodos IB (CAs y conmutadores).

OPCIONES

-C, --Ca <nombre_ca> usar el nombre_ca especificado.

-P, --Port <puerto_ca> usar el puerto_ca especificado.

-t, --timeout <timeout_ms> anular el tiempo de espera predeterminado para los mad solicitados.

-h, --help mostrar el mensaje de uso

--config, -z <archivo_configuracion> Especificar archivo de configuración alternativo.

Predeterminado: /etc/infiniband-diags/ibdiag.conf

Selección de puerto local

Múltiples puertos/Múltiples CAs: cuando no se especifica ningún dispositivo o puerto IB (ver más abajo los "parámetros umad locales"), la biblioteca libibumad selecciona el puerto a utilizar según los siguientes criterios:

1.
el primer puerto que esté ACTIVO.
2.
si no se encuentra, el primer puerto que esté ARRIBA (enlace físico arriba).

Si se especifica un nombre de puerto y/o CA, la biblioteca libibumad intenta satisfacer la solicitud del usuario y fallará si no es posible.

Por ejemplo:

ibaddr                 # usar el primer puerto (criterio #1 arriba)
ibaddr -C mthca1       # elegir el mejor puerto solo de "mthca1".
ibaddr -P 2            # usar el segundo puerto (activo/arriba) del primer dispositivo IB disponible.
ibaddr -C mthca0 -P 2  # usar solo el puerto especificado.

ARCHIVOS

ARCHIVO DE CONFIGURACIÓN

/etc/infiniband-diags/ibdiag.conf

Se proporciona un archivo de configuración global para establecer algunas de las opciones comunes para todas las herramientas. Consulte el archivo de configuración proporcionado para obtener detalles.

FORMATO DEL ARCHIVO DE MAPA DE NOMBRES DE NODO

El mapa de nombres de nodos se utiliza para especificar nombres amigables para los nodos en la salida. Los GUID se utilizan para realizar la búsqueda.

Esta funcionalidad es proporcionada por el paquete opensm-libs. Consulte opensm(8) para conocer la ubicación del archivo para su instalación.

Genéricamente:

# comentario
<guid> "<nombre>"

Ejemplo:

# IB1
# Tarjetas de línea
0x0008f104003f125c "IB1 (Rack 11 slot 1   ) ISR9288/ISR9096 Voltaire sLB-24D"
0x0008f104003f125d "IB1 (Rack 11 slot 1   ) ISR9288/ISR9096 Voltaire sLB-24D"
0x0008f104003f10d2 "IB1 (Rack 11 slot 2   ) ISR9288/ISR9096 Voltaire sLB-24D"
0x0008f104003f10d3 "IB1 (Rack 11 slot 2   ) ISR9288/ISR9096 Voltaire sLB-24D"
0x0008f104003f10bf "IB1 (Rack 11 slot 12  ) ISR9288/ISR9096 Voltaire sLB-24D"
# Spines
0x0008f10400400e2d "IB1 (Rack 11 spine 1   ) ISR9288 Voltaire sFB-12D"
0x0008f10400400e2e "IB1 (Rack 11 spine 1   ) ISR9288 Voltaire sFB-12D"
0x0008f10400400e2f "IB1 (Rack 11 spine 1   ) ISR9288 Voltaire sFB-12D"
0x0008f10400400e31 "IB1 (Rack 11 spine 2   ) ISR9288 Voltaire sFB-12D"
0x0008f10400400e32 "IB1 (Rack 11 spine 2   ) ISR9288 Voltaire sFB-12D"
# GUID   Node Name
0x0008f10400411a08 "SW1  (Rack  3) ISR9024 Voltaire 9024D"
0x0008f10400411a28 "SW2  (Rack  3) ISR9024 Voltaire 9024D"
