IBND_DISCOVER_FABRIC(3) Manual del programador de OpenIB IBND_DISCOVER_FABRIC(3)

NOMBRE

ibnd_discover_fabric, ibnd_destroy_fabric, ibnd_debug ibnd_show_progress - inicializa la biblioteca ibnetdiscover.

SINOPSIS

#include <infiniband/ibnetdisc.h>

ibnd_fabric_t *ibnd_discover_fabric(struct ibmad_port *ibmad_port, int timeout_ms, ib_portid_t *from, int hops)
void ibnd_destroy_fabric(ibnd_fabric_t *fabric)
void ibnd_debug(int i)
void ibnd_show_progress(int i)
int ibnd_set_max_smps_on_wire(int i)

DESCRIPCIÓN

ibnd_discover_fabric() Descubre la red conectada al puerto especificado por ibmad_port, utilizando el tiempo de espera especificado. Los parámetros "from" y "hops" son opcionales y permiten escanear una parte de la red especificando un nodo "from" y un número de saltos desde ese nodo para escanear, "hops". Esto le da al usuario una "sub-red" que está "centrada" donde elija.

ibmad_port debe abrirse con al menos las clases IB_SMI_CLASS e IB_SMI_DIRECT_CLASS para que ibnd_discover_fabric funcione.

ibnd_destroy_fabric() libera toda la memoria y recursos asociados con la red.

ibnd_debug() Establece el nivel de depuración que se imprimirá a medida que se realizan las operaciones de la biblioteca.

ibnd_show_progress() Indica que la biblioteca debe imprimir salida de depuración que muestre su progreso a través de la red.

ibnd_set_max_smps_on_wire() Establece el número de SMPs que se emitirán simultáneamente en el cable.

VALOR DE RETORNO

ibnd_discover_fabric() devuelve NULL en caso de fallo, de lo contrario, un objeto ibnd_fabric_t válido.

ibnd_destory_fabric(), ibnd_debug() NINGUNO

ibnd_set_max_smps_on_wire() Se devuelve el valor anterior

EJEMPLOS

Descubrir toda la red conectada al dispositivo mthca0, puerto 1.

int mgmt_classes[2] = {IB_SMI_CLASS, IB_SMI_DIRECT_CLASS}; struct ibmad_port *ibmad_port = mad_rpc_open_port(ca, ca_port, mgmt_classes, 2); ibnd_fabric_t *fabric = ibnd_discover_fabric(ibmad_port, 100, NULL, 0); ... ibnd_destroy_fabric(fabric); mad_rpc_close_port(ibmad_port);

Descubrir solo un nodo y los nodos conectados a él.

... str2drpath(&(port_id.drpath), from, 0, 0); ... ibnd_discover_fabric(ibmad_port, 100, &port_id, 1); ...

VER TAMBIÉN

libibmad, mad_rpc_open_port
