ibtracert(8) Diagnósticos de Open IB ibtracert(8)

Nombre

ibtracert - rastrear ruta InfiniBand

SINOPSIS

ibtracert [opciones] [<lid|guid> [<startlid> [<endlid>]]]

DESCRIPCIÓN

ibtracert utiliza SMPs para rastrear la ruta desde un GID/LID de origen hasta un GID/LID de destino. Cada salto a lo largo de la ruta se muestra hasta que se alcanza el destino o un salto no responde. Al usar la opción -m, se puede realizar un rastreo de ruta de multidifusión entre nodos de origen y destino.

OPCIONES

-n, --no_info
formato simple; no mostrar información adicional
-m
mostrar el rastreo de multidifusión del mlid especificado
-f, --force
forzar ruta al puerto de destino

Indicadores de dirección

-G, --Guid La dirección especificada es un GUID de puerto

-L, --Lid La dirección especificada es un LID

-s, --sm_port <smlid> usar 'smlid' como lid de destino para consultas SA.

--ports-file <archivo_puertos> Especificar un archivo de puertos. Ver sección ARCHIVOS.

Este archivo contiene múltiples pares de lid o guid de origen y destino. Ver sección ARCHIVOS.

Indicadores de selección de puerto

-C, --Ca <nombre_ca> usar el nombre_ca especificado.

-P, --Port <puerto_ca> usar el puerto_ca especificado.

Selección de puerto local

Soporte múltiple de puertos/múltiples CA: cuando no se especifica ningún dispositivo o puerto IB (ver los "parámetros umad locales" a continuación), la biblioteca libibumad selecciona el puerto a usar según los siguientes criterios:

1.
el primer puerto que esté ACTIVO.
2.
si no se encuentra, el primer puerto que esté ARRIBA (enlace físico activo).

Si se especifica un nombre de puerto y/o CA, la biblioteca libibumad intenta cumplir la solicitud del usuario y fallará si no es posible.

Por ejemplo:

ibaddr                 # usar el primer puerto (criterio #1 arriba)
ibaddr -C mthca1       # seleccionar el mejor puerto solo de "mthca1".
ibaddr -P 2            # usar el segundo puerto (activo/arriba) del primer dispositivo IB disponible.
ibaddr -C mthca0 -P 2  # usar solo el puerto especificado.

Indicadores de depuración

-d
aumentar el nivel de depuración de IB. Se puede usar varias veces (-ddd o -d -d -d).
-e
mostrar errores de envío y recepción (tiempos de espera y otros)

-h, --help mostrar el mensaje de uso

-v, --verbose
aumentar el nivel de verbosidad de la aplicación. Se puede usar varias veces (-vv o -v -v -v)

-V, --version mostrar la información de la versión.

Indicadores de configuración

-t, --timeout <timeout_ms> anular el tiempo de espera por defecto para los mads solicitados.

--node-name-map <mapa_nombres_nodos> Especificar un mapa de nombres de nodos. Ver sección ARCHIVOS.

Este archivo mapea GUIDs a nombres más amigables para el usuario. Ver sección ARCHIVOS.
-y, --m_key <clave>
usar la M_key especificada para las solicitudes. Si se especifica un valor no numérico (como 'x'), se pedirá un valor.

--config, -z <archivo_config> Especificar un archivo de configuración alternativo.

Por defecto: /etc/infiniband-diags/ibdiag.conf

ARCHIVOS

ARCHIVO DE CONFIGURACIÓN

/etc/infiniband-diags/ibdiag.conf

Se proporciona un archivo de configuración global para establecer algunas de las opciones comunes para todas las herramientas. Consulte el archivo de configuración proporcionado para obtener más detalles.

FORMATO DEL ARCHIVO DE MAPA DE NOMBRES DE NODO

El mapa de nombres de nodos se utiliza para especificar nombres amigables para el usuario para los nodos en la salida. Los GUIDs se utilizan para realizar la búsqueda.

Esta funcionalidad es proporcionada por el paquete opensm-libs. Consulte opensm(8) para conocer la ubicación del archivo para su instalación.

Genéricamente:

# comentario
<guid> "<nombre>"

Ejemplo:

# IB1
# Tarjetas de línea
0x0008f104003f125c "IB1 (Rack 11 slot 1   ) ISR9288/ISR9096 Voltaire sLB-24D"
0x0008f104003f125d "IB1 (Rack 11 slot 1   ) ISR9288/ISR9096 Voltaire sLB-24D"
0x0008f104003f10d2 "IB1 (Rack 11 slot 2   ) ISR9288/ISR9096 Voltaire sLB-24D"
0x0008f104003f10d3 "IB1 (Rack 11 slot 2   ) ISR9288/ISR9096 Voltaire sLB-24D"
0x0008f104003f10bf "IB1 (Rack 11 slot 12  ) ISR9288/ISR9096 Voltaire sLB-24D"
# Spines
0x0008f10400400e2d "IB1 (Rack 11 spine 1   ) ISR9288 Voltaire sFB-12D"
0x0008f10400400e2e "IB1 (Rack 11 spine 1   ) ISR9288 Voltaire sFB-12D"
0x0008f10400400e2f "IB1 (Rack 11 spine 1   ) ISR9288 Voltaire sFB-12D"
0x0008f10400400e31 "IB1 (Rack 11 spine 2   ) ISR9288 Voltaire sFB-12D"
0x0008f10400400e32 "IB1 (Rack 11 spine 2   ) ISR9288 Voltaire sFB-12D"
# GUID   Node Name
0x0008f10400411a08 "SW1  (Rack  3) ISR9024 Voltaire 9024D"
0x0008f10400411a28 "SW2  (Rack  3) ISR9024 Voltaire 9024D"
0x0008f10400411a34 "SW3  (Rack  3) ISR9024 Voltaire 9024D"
0x0008f104004119d0 "SW4  (Rack  3) ISR9024 Voltaire 9024D"

FORMATO DEL ARCHIVO DE PUERTOS

El archivo de puertos se puede usar para especificar múltiples pares de origen y destino. Pueden ser lids o guids. Si son guids, use la opción -G para indicarlo.

Genéricamente:

# comentario
<origen> <destino>

Ejemplo:

73 207
203 657
531 101
> O <
0x0008f104003f125c 0x0008f104003f133d
0x0008f1040011ab07 0x0008f104004265c0
0x0008f104007c5510 0x0008f1040099bb08

EJEMPLOS

Ejemplos de unicast

ibtracert 4 16                                  # mostrar ruta entre lids 4 y 16
ibtracert -n 4 16                               # lo mismo, pero usando formato de salida simple
ibtracert -G 0x8f1040396522d 0x002c9000100d051  # usar direcciones guid

Ejemplo de multidifusión

ibtracert -m 0xc000 4 16    # mostrar ruta de multidifusión del mlid 0xc000 entre lids 4 y 16
