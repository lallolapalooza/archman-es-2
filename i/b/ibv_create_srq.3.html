IBV_CREATE_SRQ(3) Manual del programador de Libibverbs IBV_CREATE_SRQ(3)

NOMBRE

ibv_create_srq, ibv_destroy_srq - crear o destruir una cola de recepción compartida (SRQ)

SINOPSIS

#include <infiniband/verbs.h>

struct ibv_srq *ibv_create_srq(struct ibv_pd *pd, struct 
                               ibv_srq_init_attr *srq_init_attr);

int ibv_destroy_srq(struct ibv_srq *srq);

DESCRIPCIÓN

ibv_create_srq() crea una cola de recepción compartida (SRQ) asociada al dominio de protección pd. El argumento srq_init_attr es una estructura ibv_srq_init_attr, según se define en <infiniband/verbs.h>.

struct ibv_srq_init_attr {
void                   *srq_context;    /* Contexto asociado de la SRQ */
struct ibv_srq_attr     attr;           /* Atributos de la SRQ */
};
struct ibv_srq_attr {
uint32_t                max_wr;         /* Número máximo solicitado de solicitudes de trabajo (WRs) pendientes en la SRQ */
uint32_t                max_sge;        /* Número máximo solicitado de elementos de dispersión por WR */
uint32_t                srq_limit;      /* Valor límite de la SRQ (irrelevante para ibv_create_srq) */
};

La función ibv_create_srq() actualizará la estructura srq_init_attr con los valores originales de la SRQ que se creó; los valores de max_wr y max_sge serán mayores o iguales a los valores solicitados.

ibv_destroy_srq() destruye la SRQ srq.

VALOR DE RETORNO

ibv_create_srq() devuelve un puntero a la SRQ creada, o NULL si la solicitud falla.

ibv_destroy_srq() devuelve 0 si tiene éxito, o el valor de errno en caso de fallo (que indica la razón del fallo).

NOTAS

ibv_destroy_srq() falla si alguna pareja de colas todavía está asociada con esta SRQ.

VER TAMBIÉN

ibv_alloc_pd(3), ibv_modify_srq(3), ibv_query_srq(3)
