NOMBRE

ibv_import_mr - importar una MR de un ibv_pd dado

ibv_unimport_mr - desimportar una MR

SINOPSIS

#include <infiniband/verbs.h>
struct ibv_mr *ibv_import_mr(struct ibv_pd *pd, uint32_t mr_handle);
void ibv_unimport_mr(struct ibv_mr *mr)

DESCRIPCIÓN

ibv_import_mr() devuelve una región de memoria (MR) que está asociada con el mr_handle dado en el contexto RDMA que está asociado con el pd dado.

El valor de mr_handle de entrada debe ser un identificador válido del kernel para un objeto MR en el contexto RDMA asociado. Se puede obtener de la MR original obteniendo el valor de su miembro ibv_mr->handle.

ibv_unimport_mr() desimporta la MR. Una vez que se ha terminado el uso de la MR, se debe llamar a ibv_dereg_mr() o ibv_unimport_mr(). La primera irá al kernel para destruir el objeto una vez que la segunda limpie lo que sea necesario/opuesto a la importación sin llamar al kernel.

Es responsabilidad de la aplicación coordinar entre todos los ibv_context(s) que utilizan esta MR. Una vez que se completa la destrucción, ningún otro proceso puede tocar el objeto excepto para desimportar. Todos los usuarios del contexto deben colaborar para asegurar esto.

VALOR DE RETORNO

ibv_import_mr() devuelve un puntero a la MR asignada, o NULL si la solicitud falla.

NOTAS

El campo addr en la MR importada no es aplicable, se espera un valor NULL.
