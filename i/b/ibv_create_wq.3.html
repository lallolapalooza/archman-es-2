IBV_CREATE_WQ(3) Manual del programador de Libibverbs IBV_CREATE_WQ(3)

NOMBRE

ibv_create_wq, ibv_destroy_wq - crear o destruir una Cola de Trabajo (WQ).

SINOPSIS

#include <infiniband/verbs.h>

struct ibv_wq *ibv_create_wq(struct ibv_context *context,
                                     struct ibv_wq_init_attr *wq_init_attr);

int ibv_destroy_wq(struct ibv_wq *wq);

DESCRIPCIÓN

ibv_create_wq() crea una WQ asociada con el ibv_context context. El argumento wq_init_attr es una estructura ibv_wq_init_attr, tal como se define en <infiniband/verbs.h>.

struct ibv_wq_init_attr {
void                      *wq_context;    /* Contexto asociado de la WQ */
enum ibv_wq_type           wq_type;       /* Tipo de WQ */
uint32_t                   max_wr;        /* Número máximo solicitado de WRs pendientes en la WQ */
uint32_t                   max_sge;       /* Número máximo solicitado de elementos scatter/gather (s/g) por WR en la WQ */
struct  ibv_pd            *pd;            /* PD a asociar con la WQ */
struct  ibv_cq            *cq;            /* CQ a asociar con la WQ */
uint32_t                   comp_mask;     /* Identifica los campos válidos. Usar ibv_wq_init_attr_mask */
uint32_t                   create_flags    /* Banderas de creación para esta WQ, usar enum ibv_wq_flags */
};
enum ibv_wq_flags {
IBV_WQ_FLAGS_CVLAN_STRIPPING            = 1 << 0, /* El campo CVLAN se eliminará de los paquetes entrantes */
IBV_WQ_FLAGS_SCATTER_FCS                = 1 << 1, /* El campo FCS se dispersará en la memoria del host */
IBV_WQ_FLAGS_DELAY_DROP                 = 1 << 2, /* Los paquetes no se descartarán inmediatamente si no hay WQE de recepción */
IBV_WQ_FLAGS_PCI_WRITE_END_PADDING      = 1 << 3, /* Los paquetes entrantes se rellenarán hasta el tamaño de la línea de caché */
IBV_WQ_FLAGS_RESERVED                   = 1 << 4,
};

La función ibv_create_wq() actualizará los campos wq_init_attr->max_wr y wq_init_attr->max_sge con los valores reales de la WQ que se creó; los valores serán mayores o iguales a los valores solicitados.

ibv_destroy_wq() destruye la WQ wq.

VALOR DE RETORNO

ibv_create_wq() devuelve un puntero a la WQ creada, o NULL si la solicitud falla.

ibv_destroy_wq() devuelve 0 en caso de éxito, o el valor de errno en caso de fallo (que indica el motivo del fallo).
