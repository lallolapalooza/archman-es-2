ibv_create_counters(3) Manual del Programador de Libibverbs ibv_create_counters(3)

NOMBRE

ibv_create_counters, ibv_destroy_counters - Crear o destruir un manejador de contadores

SINOPSIS

#include <infiniband/verbs.h>
struct ibv_counters *
ibv_create_counters(struct ibv_context *context,
                    struct ibv_counters_init_attr *init_attr);
int ibv_destroy_counters(struct ibv_counters *counters);

DESCRIPCIÓN

ibv_create_counters() crea un nuevo manejador de contadores para el contexto del dispositivo de RDMA.

Un manejador ibv_counters se puede adjuntar a un recurso de verificaciones (ej. QP, WQ, Flow) estáticamente cuando estos se crean.

Por ejemplo, adjuntar un ibv_counters estáticamente a un Flujo (struct ibv_flow) durante la creación de un nuevo Flujo llamando a ibv_create_flow().

Los contadores se borran al crearlos y los valores serán monotónicamente crecientes.

ibv_destroy_counters() libera el manejador de contadores, el usuario debe desadjuntar el objeto de contadores antes de destruirlo.

ARGUMENTOS

context
Contexto del dispositivo RDMA en el que crear los contadores.
init_attr
Es una estructura ibv_counters_init_attr, tal como se define en verbs.h.

Argumento init_attr

struct ibv_counters_init_attr {
    int comp_mask;
};
comp_mask
Máscara de bits que especifica qué campos de la estructura son válidos.

VALOR DE RETORNO

ibv_create_counters() devuelve un puntero al objeto ibv_counters asignado, o NULL si la solicitud falla (y establece errno para indicar la razón del fallo).

ibv_destroy_counters() devuelve 0 si tiene éxito, o el valor de errno en caso de fallo (que indica la razón del fallo).

ERRORES

EOPNOTSUPP
ibv_create_counters() no es compatible actualmente en este dispositivo (ENOSYS puede ser devuelto a veces por versiones antiguas de libibverbs).
ENOMEM
ibv_create_counters() no pudo crear el objeto ibv_counters, no hay suficiente memoria.
EINVAL
se proporcionó un parámetro inválido a ibv_destroy_counters().

EJEMPLO

Se muestra un ejemplo de uso de ibv_counters en ibv_read_counters

VER TAMBIÉN

ibv_attach_counters_point_flow, ibv_read_counters, ibv_create_flow
