El archivo de configuración main.conf configura los ajustes del sistema para iwd. Este archivo se encuentra en el directorio de configuración especificado por la variable de entorno $CONFIGURATION_DIRECTORY, que normalmente es proporcionada por systemd. En ausencia de dicha variable de entorno, el valor predeterminado es /etc/iwd. Si no existe main.conf, se eligen valores predeterminados. La presencia de main.conf no

EnableNetworkConfiguraValores: true, false Activa la configuración de red. Establecer esta opción en true permite que iwd configure las interfaces de red con las direcciones IP. Hay dos tipos de direccionamiento IP admitidos por iwd: estático y dinámico. Las direcciones IP estáticas se configuran a través de los archivos de configuración de red. Si no se ha proporcionado una configuración IP estática para una red, iwd intentará obtener las direcciones dinámicas de la red a través del cliente DHCP integrado. Esto también activa la configuración de red y el servidor DHCP cuando se está en modo AP y el perfil AP activado no lo anula. La función de configuración de red está desactivada de forma predeterminada. Consulte los ajustes de [Network] para obtener ajustes adicionales relacionados con la configuración

AddressRandomizaValores: disabled, once, network Si AddressRandomization está establecido en disabled, se utiliza el comportamiento predeterminado del kernel. Esto significa que el kernel asignará una dirección MAC del rango de direcciones MAC permanentes proporcionado por el hardware o el controlador. Por lo tanto, es posible que las redes rastreen al usuario por la dirección MAC que es permanente. Si AddressRandomization está establecido en once, la dirección MAC se aleatoriza una sola vez cuando iwd se inicia o cuando el hardware es detectado por primera vez (debido a hotplug, etc.). Tenga en cuenta que el rango de aleatorización está limitado de 00:00:01 a 00:00:FE. La dirección MAC permanente de la tarjeta se usa para los 3 primeros octetos.
