NOMBRE

iwspy - Obtener estadísticas inalámbricas de nodos específicos

SINOPSIS

iwspy [interfaz]
iwspy interfaz [+] NOMBRE DNS | DIRECCIÓN IP | DIRECCIÓN FÍSICA [...]
iwspy interfaz off
iwspy interfaz setthr bajo alto
iwspy interfaz getthr

DESCRIPCIÓN

Iwspy se utiliza para establecer una lista de direcciones a monitorear en una interfaz de red inalámbrica y para leer información de calidad de enlace para cada una de ellas. Esta información es la misma que la disponible en /proc/net/wireless: calidad del enlace, intensidad de la señal y nivel de ruido.

Esta información se actualiza cada vez que se recibe un nuevo paquete, por lo que cada dirección de la lista agrega una sobrecarga al driver.

Tenga en cuenta que esta funcionalidad solo funciona para nodos que forman parte de la celda inalámbrica actual, no puede monitorear Puntos de Acceso a los que no está asociado (puede usar Escaneo para eso) ni nodos en otras celdas. En modo Gestionado, en la mayoría de los casos los paquetes son retransmitidos por el Punto de Acceso, en este caso obtendrá la intensidad de la señal del Punto de Acceso. Por estas razones, esta funcionalidad es principalmente útil en modo Ad-Hoc y Maestro.

PARÁMETROS

Puede establecer hasta 8 direcciones.

NOMBRE DNS | DIRECCIÓN IP
Establece una dirección IP, o en algunos casos un nombre DNS (usando el resolutor de nombres). Dado que el hardware funciona con direcciones físicas, iwspy traducirá esta dirección IP a través de ARP. En algunos casos, esta dirección podría no estar en la caché ARP y iwspy fallará. En esos casos, haga ping(8) a este nombre/dirección e inténtelo de nuevo.
DIRECCIÓN FÍSICA
Establece una dirección física (MAC) (esta dirección no se traduce ni se verifica como la IP). La dirección debe contener dos puntos (:) para ser reconocida como una dirección física.
+
Agrega el nuevo conjunto de direcciones al final de la lista actual en lugar de reemplazarla. La lista de direcciones es única para cada dispositivo, por lo que cada usuario debe usar esta opción para evitar conflictos.
off
Elimina la lista actual de direcciones y deshabilita la funcionalidad de espía.
setthr
Establece el umbral de intensidad de señal bajo y alto para el evento iwspy (para drivers que lo soporten).
Cada vez que la intensidad de la señal de alguna de las direcciones monitoreadas con iwspy caiga por debajo del umbral bajo o supere el umbral alto, se generará un Evento Inalámbrico.
Esto puede usarse para monitorear interrupciones del enlace sin tener que ejecutar iwspy periódicamente.
getthr
Recupera el umbral de intensidad de señal bajo y alto actual para el evento iwspy.
