DESCRIPCIÓ

N

Iwconfig es similar a ifconfig(8), pero está dedicado a las interfaces inalámbricas. Se utiliza para establecer los parámetros de la interfaz de red que son específicos de la operación inalámbrica (por ejemplo: la frecuencia). Iwconfig también puede usarse para mostrar esos parámetros y las estadísticas inalámbricas (extraídas de /proc/net/wir

eless).

Todos estos parámetros y estadísticas dependen del dispositivo. Cada controlador propo

rcionará solo algunos de ellos dependiendo del soporte del hardware, y el rango de va
lores puede cambiar. Consulte la página man de cada dispositivo para obtener detalles.

PARÁMETRO

S
ess
id
Establece el ESSID (o Nombre de Red - en algunos productos también puede llamarse ID de Dominio). El ESSID se utiliza para identificar celdas que forman parte de la misma red virtual.
A diferencia de la Dirección AP o NWID que definen una sola celda, el ESSID define un grupo de celdas conectadas a través de repetidores o infraestructura, donde el usuario puede desplazarse de forma transparente.
Con algunas tarjetas, puede desactivar la comprobación del ESSID (ESSID promiscuo) con off o any (y on para volver a activarlo).
Si el ESSID de su red es una de las palabras clave especiales (off, on o any), debe usar -- para escaparlo.
Ejemplos:
iwconfig eth0 essid any
iwconfig eth0 essid "My Network"
iwconfig eth0 essid --
"ANY"
nw
id
Establece el ID de Red. Como todas las redes inalámbricas adyacentes comparten el mismo medio, este parámetro se utiliza para diferenciarlas (crear redes lógicas colocadas) e identificar los nodos que pertenecen a la misma celda.
Este parámetro solo se usa para hardware anterior a 802.11, el protocolo 802.11 usa el ESSID y la Dirección AP para esta función.
Con algunas tarjetas, puede desactivar la comprobación del ID de Red (NWID promiscuo) con off (y on para volver a activarlo).
Ejemplos:
iwconfig eth0 nwid AB34
iwconfig eth0 nwid
off

Ejemplo:
iwconfig eth0 nickname "My Linux

mo
de
Establece el modo de funcionamiento del dispositivo, que depende de la topología de la red. El modo puede ser Ad-Hoc (red compuesta solo por una celda y sin Punto de Acceso), Managed (el nodo se conecta a una red compuesta por muchos Puntos de Acceso, con roaming), Master (el nodo es el maestro de sincronización o actúa como un Punto de Acceso), Repeater (el nodo reenvía paquetes entre otros nodos inalámbricos), Secondary (el nodo actúa como maestro/repetidor de respaldo), Monitor (el nodo no está asociado a ninguna celda y monitorea pasivamente todos los paquetes en la frecuencia) o Auto.
Ejemplo:
iwconfig eth0 mode Managed
iwconfig eth0 mode
Ad-Hoc
freq/chann
el
Establece la frecuencia de operación o el canal en el dispositivo. Un valor inferior a 1000 indica un número de canal, un valor superior a 1000 es una frecuencia en Hz. Puede añadir el sufijo k, M o G al valor (por ejemplo, "2.46G" para una frecuencia de 2.46 GHz), o añadir suficientes '0'.
Los canales suelen numerarse a partir del 1, y puede usar iwlist(8) para obtener el número total de canales, listar las frecuencias disponibles y mostrar la frecuencia actual como un canal. Dependiendo de la normativa, algunas frecuencias/canales pueden no estar disponibles.
Al usar el modo Managed, la mayoría de las veces el Punto de Acceso dicta el canal y el controlador puede rechazar el ajuste de la frecuencia. En el modo Ad-Hoc, el ajuste de la frecuencia solo puede usarse en la creación inicial de la celda y puede ignorarse al unirse a una celda existente.
También puede usar off o auto para permitir que la tarjeta elija el mejor canal (cuando se soporta).
Ejemplos:
iwconfig eth0 freq 2422000000
iwconfig eth0 freq 2.422G
iwconfig eth0 channel 3
iwconfig eth0 channel
auto
a
p
Fuerza a la tarjeta a registrarse en el Punto de Acceso indicado por la dirección, si es posible. Esta dirección es la identidad de celda del Punto de Acceso, tal como la informa el escaneo inalámbrico, que puede ser diferente de su dirección MAC de red. Si el enlace inalámbrico es punto a punto, establezca la dirección del otro extremo del enlace. Si el enlace es ad-hoc, establezca la identidad de celda de la red ad-hoc.
Cuando la calidad de la conexión baja demasiado, el controlador puede volver al modo automático (la tarjeta selecciona el mejor Punto de Acceso en alcance).
También puede usar off para volver a habilitar el modo automático sin cambiar el Punto de Acceso actual, o puede usar any o auto para forzar a la tarjeta a reasociarse con el mejor Punto de Acceso actual.
Ejemplo:
iwconfig eth0 ap 00:60:1D:01:23:45
iwconfig eth0 ap any
iwconfig eth0 ap
off
rate/bit[rat
e]
Para tarjetas que soportan múltiples velocidades de bits, establece la velocidad de bits en b/s. La velocidad de bits es la velocidad a la que se transmiten los bits sobre el medio, la velocidad de usuario del enlace es menor debido al uso compartido del medio y a la sobrecarga.
Puede añadir el sufijo k, M o G al valor (multiplicador decimal: 10^3, 10^6 y 10^9 b/s), o añadir suficientes '0'. Los valores inferiores a 1000 son específicos de la tarjeta, generalmente un índice en la lista de velocidades de bits. Use auto para seleccionar el modo de velocidad de bits automático (retroceso a una velocidad menor en canales ruidosos), que es el predeterminado para la mayoría de las tarjetas, y fixed para volver a la configuración fija. Si especifica un valor de velocidad de bits y añade auto, el controlador usará todas las velocidades de bits inferiores o iguales a este valor.
Ejemplos:
iwconfig eth0 rate 11M
iwconfig eth0 rate auto
iwconfig eth0 rate 5.5M
auto
txpow
er
Para tarjetas que soportan múltiples potencias de transmisión, establece la potencia de transmisión en dBm. Si W es la potencia en Vatios, la potencia en dBm es P = 30 + 10.log(W). Si el valor tiene el sufijo mW, se convertirá automáticamente a dBm.
Además, on y off habilitan y deshabilitan la radio, y auto y fixed habilitan y deshabilitan el control de potencia (si esas características están disponibles).
Ejemplos:
iwconfig eth0 txpower 15
iwconfig eth0 txpower 30mW
iwconfig eth0 txpower auto
iwconfig eth0 txpower
off
se
ns
Establece el umbral de sensibilidad. Esto define cuán sensible es la tarjeta a las pobres condiciones de funcionamiento (señal baja, interferencia). Se asume que los valores positivos son el valor bruto utilizado por el hardware o un porcentaje, nSe asume que los valores negativos están en dBm. Dependiendo de la implementación del hardware, este parámetro puede controlar varias funciones.
En las tarjetas modernas, este parámetro suele controlar el umbral de traspaso/roaming, el nivel de señal más bajo para el cual el hardware permanece asociado al Punto de Acceso actual. Cuando el nivel de señal cae por debajo de este umbral, la tarjeta comienza a buscar un Punto de Acceso nuevo/mejor. Algunas tarjetas pueden usar el número de balizas perdidas para activar esto. Para una alta densidad de Puntos de Acceso, un umbral más alto asegura que la tarjeta siempre esté asociada al mejor AP; para una baja densidad de AP, un umbral más bajo minimiza el número de traspasos fallidos.
En tarjetas más antiguas, este parámetro suele controlar el umbral de diferimiento, el nivel de señal más bajo para el cual el hardware considera el canal ocupado. Los niveles de señal por encima de este umbral hacen que el hardware inhiba su propia transmisión, mientras que las señales más débiles que esta se ignoran y el hardware es libre de transmitir. Esto suele estar fuertemente vinculado al umbral de recepción, el nivel de señal más bajo para el cual el hardware intenta la recepción de paquetes. La configuración adecuada de estos umbrales evita que la tarjeta pierda tiempo en el ruido de fondo mientras aún recibe transmisiones débiles. Los diseños modernos parecen controlar estos umbrales automáticamente.
Ejemplo :
iwconfig eth0 sens -80
iwconfig eth0 sens
2
ret
ry
La mayoría de las tarjetas tienen retransmisiones MAC, y algunas permiten configurar el comportamiento del mecanismo de reintento.
Para establecer el número máximo de reintentos, introduzca limit `valor'. Este es un valor absoluto (sin unidad), y es el predeterminado (cuando no se especifica nada). Para establecer la longitud máxima de tiempo que el MAC debe reintentar, introduzca lifetime `valor'. Por defecto, este valor está en segundos, añada el sufijo m o u para especificar valores en milisegundos o microsegundos.
También puede añadir los modificadores short, long, min y max. Si la tarjeta soporta el modo automático, definen los límites del límite o del tiempo de vida. Algunas otras tarjetas definen valores diferentes dependiendo del tamaño del paquete, por ejemplo en 802.11 min limit es el límite de reintento corto (paquetes no RTS/CTS).
Ejemplos :
iwconfig eth0 retry 16
iwconfig eth0 retry lifetime 300m
iwconfig eth0 retry short 12
iwconfig eth0 retry min limit
8
rts[_thresho
ld]
RTS/CTS añade un protocolo de enlace antes de cada transmisión de paquete para asegurar que el canal está libre. Esto añade sobrecarga, pero aumenta el rendimiento en caso de nodos ocultos o un gran número de nodos activos. Este parámetro establece el tamaño del paquete más pequeño para el cual el nodo envía RTS; un valor igual al tamaño máximo de paquete desactiva el mecanismo. También puede establecer este parámetro a auto, fixed o off.
Ejemplos :
iwconfig eth0 rts 250
iwconfig eth0 rts
off
frag[mentation_thresho
ld]
La fragmentación permite dividir un paquete IP en una ráfaga de fragmentos más pequeños transmitidos en el medio. En la mayoría de los casos esto añade sobrecarga, pero en un entorno muy ruidoso esto reduce la penalización de error y permite que los paquetes atraviesen ráfagas de interferencia. Este parámetro establece el tamaño máximo de fragmento, que siempre es menor que el tamaño máximo de paquete.
Este parámetro también puede controlar el Frame Bursting disponible en algunas tarjetas, la capacidad de enviar múltiples paquetes IP juntos. Este mecanismo se habilitaría si el tamaño del fragmento es mayor que el tamaño máximo de paquete.
También puede establecer este parámetro a auto, fixed o off.
Ejemplos :
iwconfig eth0 frag 512
iwconfig eth0 frag
off
key/enc[ryptio
n]
Se usa para manipular claves de cifrado o descifrado y el modo de seguridad.
Para establecer la clave de cifrado actual, simplemente introduzca la clave en dígitos hexadecimales como XXXX-XXXX-XXXX-XXXX o XXXXXXXX. Para establecer una clave diferente a la clave actual, anteponga o añada [índice] a la propia clave (esto no cambiará cuál es la clave activa). También puede introducir la clave como una cadena ASCII usando el prefijo s:. La frase de paso actualmente no está soportada.
Para cambiar cuál es la clave activa actualmente, simplemente introduzca [índice] (sin introducir ningún valor de clave).
off y on desactivan y reactivan el cifrado.
El modo de seguridad puede ser open o restricted, y su significado depende de la tarjeta utilizada. Con la mayoría de las tarjetas, en el modo open no se usa autenticación y la tarjeta también puede aceptar sesiones no cifradas, mientras que en el modo restricted solo se aceptan sesiones cifradas y la tarjeta usará autenticación si está disponible.
Si necesita establecer múltiples claves, o establecer una clave y cambiar la clave activa, necesita usar múltiples directivas key. Los argumentos pueden ponerse en cualquier orden, el último tendrá prioridad.
Ejemplos :
iwconfig eth0 key 0123-4567-89
iwconfig eth0 key [3] 0123-4567-89
iwconfig eth0 key s:password [2]
iwconfig eth0 key [2]
iwconfig eth0 key open
iwconfig eth0 key off
iwconfig eth0 key restricted [3] 0123456789
iwconfig eth0 key 01-23 key 45-67 [4] key
[4]
pow
er
Se usa para manipular los parámetros y el modo del esquema de gestión de energía.
Para establecer el período entre despertares, introduzca period `valor'. Para establecer el tiempo de espera antes de volver a dormir, introduzca timeout `valor'. Para establecer el nivel genérico de ahorro de energía, introduzca saving `valor'. También puede añadir los modificadores min y max. Por defecto, estos valores están en segundos, añada el sufijo m o u para especificar valores en milisegundos o microsegundos. A veces, estos valores no tienen unidades (número de períodos de baliza, tiempo de permanencia, porcentaje o similar).
off y on desactivan y reactivan la gestión de energía. Finalmente, puede establecer el modo de gestión de energía a all (recibir todos los paquetes), unicast (recibir solo paquetes unicast, descartar multicast y broadcast) y multicast (recibir solo multicast y broadcast, descartar paquetes unicast).
Ejemplos :
iwconfig eth0 power period 2
iwconfig eth0 power 500m unicast
iwconfig eth0 power timeout 300u all
iwconfig eth0 power saving 3
iwconfig eth0 power off
iwconfig eth0 power min period 2 power max period

Fuerza a la tarjeta a usar un conjunto específico de modulaciones. Las tarjetas modernas soportan varias modulaciones, algunas que son estándar, como 802.11b o 802.11g, y algunas propietarias. Este comando fuerza a la tarjeta a usar solo el conjunto específico de modulaciones listado en la línea de comandos. Esto se puede usar para solucionar problemas de interoperabilidad.
La lista de modulaciones disponibles depende de la tarjeta/controlador y puede mostrarse usando iwlist modulation. Tenga en cuenta que algunas tarjetas/controladores pueden no ser capaces de seleccionar cada modulación listada independientemente, algunas pueden venir como un grupo. También puede establecer este parámetro a auto para dejar que la tarjeta/controlador haga lo mejor posible.
Ejemplos :
iwconfig eth0 modu 11g
iwconfig eth0 modu CCK OFDMa
iwconfig eth0 modu

VISUALIZACI

ÓN

Para cada dispositivo que soporte extensiones inalámbricas, iwconfig mostrará el nombre del protocolo MAC utilizado (nombre del dispositivo para protocolos propietarios), el ESSID (Nombre de Red), el NWID, la frecuencia (o canal), la sensibilidad, el modo de operación, la dirección del Punto de Acceso, la velocidad de bits, el umbral RTS, el umbral de fragmentación, la clave de cifrado y la configuración de gestión de energía (dependiendo de la disponibilidad)

.

Los parámetros mostrados tienen el mismo significado y valores que los parámetros que puede establecer, por favor consulte la parte anterior para una explicación detallada de ellos.
Algunos parámetros solo se muestran en forma corta/abreviada (como cifrado). Puede usar iwlist(8) para obtener todos los detalles.
Algunos parámetros tienen dos modos (como la velocidad de bits). Si el valor está precedido por=, significa que el parámetro está fijado y forzado a ese valor; si está precedido por:, el parámetro está en modo automático y se muestra el valor actual (y puede cambiar)

.
