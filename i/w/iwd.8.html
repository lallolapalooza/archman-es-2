IWD(8) Conectividad Linux IWD(8)

NOMBRE

iwd - demonio de red inalámbrica

SINOPSIS

iwd [opciones ...]

DESCRIPCIÓN

Demonio para gestionar dispositivos inalámbricos en Linux.

El proyecto iNet Wireless Daemon (iwd) tiene como objetivo proporcionar una solución completa de conectividad Wi-Fi para dispositivos basados en Linux. El objetivo principal del proyecto es optimizar la utilización de recursos: almacenamiento, memoria en tiempo de ejecución y costos en tiempo de enlace. Esto se logra al no depender de ninguna biblioteca externa y utilizar las características proporcionadas por el Kernel de Linux al máximo posible. El resultado es un entorno autocontenido que solo depende del Kernel de Linux y de la biblioteca C en tiempo de ejecución.

OPCIONES

--version, -v
Muestra el número de versión y sale.
--help, -h
Muestra el mensaje de ayuda y sale.

ENTORNO

$STATE_DIRECTORY se utiliza para los archivos de configuración de red. Consulte iwd.network para más detalles.

$CONFIGURATION_DIRECTORY se utiliza para la configuración del demonio. Actualmente, solo se lee el archivo main.conf de este directorio. Consulte iwd.config para más detalles.

Consulte iwd.debug para conocer más variables de entorno para depuración.

VER TAMBIÉN

iwd.config(5), iwd.network(5), iwd.debug(7), iwctl(1), iwmon(1), hwsim(1), ead(8), systemd.exec(5)
