NOMBRE

iw - mostrar / manipular dispositivos inalámbricos y su configuración

SINOPSIS


iw [ OPCIONES ] { help [ comando ] | OBJETO COMANDO }

OBJETO := { dev | phy | reg }

OPCIONES := { --version | --debug }

OPCIONES

--version
imprime información de versión y sale.
--debug
habilita la depuración de mensajes netlink.

IW - SINTAXIS DE COMANDOS

OBJETO

dev <nombre_interfaz>
- interfaz de red.
phy <nombre_phy>
- dispositivo de hardware inalámbrico (por nombre).
phy#<indice_phy>
- dispositivo de hardware inalámbrico (por índice).
reg
- agente regulatorio.

COMANDO

Especifica la acción a realizar sobre el objeto. El conjunto de acciones posibles depende del tipo de objeto. iw help imprimirá todos los comandos soportados, mientras que iw help command imprimirá la ayuda para todos los comandos que coincidan.

VER TAMBIÉN

ip(8), crda(8), regdbdump(8), regulatory.bin(5).
