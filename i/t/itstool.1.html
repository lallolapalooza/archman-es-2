ITSTOOL(1) Manual de comandos generales ITSTOOL(1)

NOMBRE

itstool - convierte entre XML y PO usando ITS

SINOPSIS

itstool [OPCIONES] ARCHIVOS_XML...
itstool -m <ARCHIVO_MO> [OPCIONES] ARCHIVOS_XML...
itstool -j <ARCHIVO_XML> [OPCIONES] ARCHIVOS_MO...

DESCRIPCIÓN

itstool extrae mensajes de archivos XML y genera archivos de plantilla PO, luego fusiona traducciones de archivos MO para crear archivos XML traducidos. Determina qué traducir y cómo dividirlo en mensajes usando el Conjunto de Etiquetas de Internacionalización (ITS) de W3C.

Para extraer mensajes de los archivos XML ARCHIVOS_XML y generarlos en SALIDA.pot:

itstool -o SALIDA.pot ARCHIVOS_XML

Después de fusionar con traducciones existentes o traducir cadenas, genere un archivo MO con msgfmt(1), luego genere archivos traducidos en el directorio DIR:

itstool -m SALIDA.mo -o DIR ARCHIVOS_XML

También puede crear un único archivo de salida XML multilingüe usando un archivo XML de entrada y un conjunto de archivos MO:

itstool -j ARCHIVO.xml -o SALIDA.xml ARCHIVOS_MO

Las definiciones de ITS se cargan desde las reglas integradas, las reglas incrustadas en los archivos XML de origen, los archivos pasados con la opción -i y los atributos ITS en los archivos XML de origen. Las definiciones posteriores tienen prioridad. Puede deshabilitar las reglas integradas pasando la opción -n.

OPCIONES

Extracción

-o SALIDA.pot
--salida SALIDA.pot
genera la plantilla PO en el archivo SALIDA.pot

Fusión

-m ARCHIVO_MO ARCHIVOS_XML
--fusionar ARCHIVO_MO ARCHIVOS_XML
fusiona desde un archivo MO ARCHIVO_MO y genera archivos XML traducidos para los ARCHIVOS_XML de origen
-l IDIOMA
--idioma IDIOMA
establece explícitamente el código de idioma a generar en XML
-o SALIDA
--salida SALIDA
genera archivos XML en el directorio SALIDA

Unión

-j ARCHIVO_ML ARCHIVOS_MO
--unir ARCHIVO_XML ARCHIVOS_MO
une traducciones de ARCHIVOS_MO en un archivo multilingüe basado en el ARCHIVO_XML de origen
-o SALIDA.xml
--salida SALIDA.xml
genera al archivo XML SALIDA.xml

Comunes

-i ITS
--its ITS
carga las reglas ITS en el archivo ITS (se puede especificar múltiples veces)
-n
--no-integradas
no aplica las reglas ITS integradas que vienen con itstool
-s
--estricto
sale con error cuando los archivos PO contienen XML roto
-d
--cargar-dtd
carga DTD externas utilizadas por los archivos XML de entrada
-k
--mantener-entidades
mantiene las referencias de entidad sin expandir en los archivos PO
-p NOMBRE VALOR
--parametro NOMBRE VALOR
define el parámetro ITS NOMBRE con el valor VALOR (se puede especificar múltiples veces)
