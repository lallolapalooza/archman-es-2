itimerspec(3type) itimerspec(3type)

NOMBRE

itimerspec - intervalo para un temporizador con precisión de nanosegundos

BIBLIOTECA

Biblioteca C estándar (libc)

SINOPSIS

#include <time.h>
struct itimerspec {
    struct timespec  it_interval;  /* Intervalo para temporizador periódico */
    struct timespec  it_value;     /* Expiración inicial */
};

DESCRIPCIÓN

Describe la expiración inicial de un temporizador y su intervalo, en segundos y nanosegundos.

ESTÁNDARES

POSIX.1-2024.

HISTORIA

POSIX.1-2001.

VER TAMBIÉN

timerfd_create(2), timer_settime(2), timespec(3type)
