component(n) [incr Tcl] component(n)

NOMBRE

itcl::component - define componentes para extendedclass, widget o widgetadaptor

Partes de esta descripción se han "tomado prestadas" de la extensión de Tcl [snit], ya que la funcionalidad es en su mayoría idéntica.

¡ADVERTENCIA!

¡Esta es una funcionalidad nueva en [incr Tcl] donde la API aún puede cambiar!

SINOPSIS

public component comp ?-inherit?
protected component comp ?-inherit?
private component comp ?-inherit?

DESCRIPCIÓN

El comando component se usa dentro de una definición [incr Tcl] extendedclass/widget/widgetadaptor para definir componentes.

Declara explícitamente un componente llamado comp y define automáticamente la variable de instancia del componente.

Si se especifica la opción -inherit, todos los métodos y opciones desconocidos se delegarán a este componente. El nombre -inherit implica que las instancias de este nuevo tipo heredan, en cierto sentido, los métodos y opciones del componente. Es decir, -inherit yes es equivalente a:

component mycomp
delegate option * to mycomp
delegate method * to mycomp

PALABRAS CLAVE
