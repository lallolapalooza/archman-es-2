NOMBRE

itweb-settings - ver y modificar la configuración de javaws y el plugin del navegador

SINOPSIS

itweb-settings
itweb-settings argumento de comando

DESCRIPCIÓN

itweb-settings es un programa de línea de comandos y una GUI para modificar y editar la configuración utilizada por la implementación de IcedTea-Web de javaws y el plugin del navegador.

Si se ejecuta sin argumentos, inicia una GUI. De lo contrario, intenta realizar lo especificado en el argumento.

La línea de comandos permite buscar, copiar y modificar rápidamente configuraciones específicas sin tener que navegar por una interfaz de usuario.

DESCRIPCIÓN

-check nombre
Comprueba que todos los ajustes actuales tengan valores válidos. (No se esperan argumentos)
-get nombre
Muestra el valor de la configuración especificada. (Se esperan uno o más argumentos)
-headless
Deshabilita la ventana de descarga y otras interfaces de usuario. (No se esperan argumentos)
-help
Imprime información sobre el comando compatible y el uso básico. También puede tomar un parámetro y luego imprime ayuda detallada para ese comando. (No se esperan argumentos)
-info nombre
Muestra información adicional sobre la configuración con nombre. Incluye una descripción, el valor actual, los valores posibles y la fuente de la configuración. (Se esperan uno o más argumentos)
-list
Muestra una lista de todas las configuraciones de IcedTea-Web y sus valores actuales. (No se esperan argumentos)
-reset nombre
Restablece la configuración especificada a su valor original. (Se esperan uno o más argumentos)
-reset all
Restablece todas las configuraciones a sus valores originales. (No se esperan argumentos)
-set nombre valor
Establece la configuración al nuevo valor especificado, si es un valor apropiado. (Se espera un número par de argumentos con el formato param=valor)
-verbose
Habilita la salida detallada. (No se esperan argumentos)

EJEMPLOS

itweb-settings
Muestra el editor GUI.
itweb-settings -reset deployment.proxy.type

Restablece el valor de la configuración `deployment.proxy.type`.

DESCRIPTION

The itweb-settings utility is used to change the properties that control the behavior of IcedTea-Web, the free Java browser plugin and web start implementation.

OPTIONS

itweb-settings accepts the following command line options:

-a, --all
Display all properties and their values.
-h, --help
Display a help message and exit.
-l, --list
Display all properties and their values.
-p, --properties
Display properties defined in deployment.properties
-t, --trusted
Display trusted certificates.
-v, --version
Display version information and exit.

PROPERTIES

The following properties can be set. They are stored in the deployment.properties file located in the users config directory. The default location is $XDG_CONFIG_HOME/icedtea-web/deployment.properties.

User specific properties:

deployment.browser. நிரல்
Path to browser executable. Used to launch the browser when a link is clicked inside an applet.
deployment.browser. நிரல்.arguments
Arguments to pass to the browser executable.

Enable/disable the cache. Default true.

Enable/disable JavaScript calls from applets to the browser content window. Default true.
deployment.user.debug.enabled
Enable/disable debug output. Default false.
deployment.user.debug.loglevel
Set the debug log level. Possible values: FINE, FINER, FINEST. Default FINEST.
deployment.user.delete.cache.on.exit
Clear cache on exit. Default false.
deployment.user.enable-append-log
Enable/disable appending to log files. Default false.

BUGS

There aren't any known bugs. If you come across one, please file it at:
http://icedtea.classpath.org/wiki/IcedTea-Web#Filing_bugs
http://icedtea.classpath.org/bugzilla

Please run in debug (-verbose switch or itw-settings setting or ICEDTEAPLUGIN_DEBUG variable set to true) mode and include that output (best is from java console) with URL to jnlp or html file (or the jnlp/html file or application itself) when filing out the bug report.
