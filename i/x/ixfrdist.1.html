IXFRDIST(1) Servidor Autoritativo PowerDNS IXFRDIST(1)

NOMBRE

ixfrdist - Un servidor solo IXFR/AXFR que redistribuye zonas

SINOPSIS

ixfrdist [OPCIÓN]...

DESCRIPCIÓN

ixfrdist transfiere zonas de un servidor autoritativo y vuelve a servir estas zonas a través de AXFR y IXFR. Comprueba la serie SOA para todos los dominios configurados y descarga nuevas versiones a disco.

Cuando llega una consulta SOA y la dirección del cliente está permitida por la ACL, ixfrdist responde con la última SOA para la zona que tiene. Esta consulta puede ser seguida por una consulta IXFR o AXFR, que luego se servirán al cliente. Si se sirve una IXFR, ixfrdist condensará todas las diferencias que tiene para el dominio en una sola IXFR.

ixfrdist se configura con un archivo de configuración en formato YAML. Por favor, consulte ixfrdist.yml(5) para obtener información.

OPCIONES

--help
Mostrar todas las opciones soportadas
--verbose
Registrar mensajes INFO
--debug
Registrar mensajes INFO y DEBUG
--version
Mostrar la versión de ixfrdist
--config <RUTA>
Cargar configuración desde RUTA, un archivo YAML. Cuando no se establece, se intenta leer un ixfrdist.yml desde el SYSCONFDIR.

VER TAMBIÉN

ixplore(1), pdns_server(1), ixfrdist.yml(5)
