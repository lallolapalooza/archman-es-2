NOMBRE

isbmex - Controlador para equipos ISBMEX de SAI

SINOPSIS

isbmex -h

isbmex -a NOMBRE_SAI [OPCIONES]


Nota

Esta página del manual solo documenta las características específicas del hardware del controlador isbmex. Para obtener información sobre el controlador principal, consulta nutupsdrv(8).

HARDWARE SOPORTADO

Este controlador soporta equipos SAI con el protocolo ISBMEX de SOLA/BASIC Mexico.

ARGUMENTOS ADICIONALES

Este controlador no soporta ninguna configuración adicional en el archivo ups.conf(5).
