DESCRIPCIÓ

N

Estas funciones comprueban si c, que debe tener el valor de un unsigned char o EOF, pertenece a una cierta clase de caracteres de acuerdo con la configuración regional especificada. Las funciones sin el sufijo "_l" realizan la comprobación basándose en la configuración regional

actual.

Las funciones con el sufijo "_l" realizan la comprobación basándose en la configuración regional especificada por el objeto de configuración regional locale. El comportamiento de estas funciones es indefinido si locale es el objeto de configuración regional especial LC_GLOBAL_LOCALE (véase duplocale(3)) o no es un identificador de objeto de configuración regional

válido.

La lista siguiente explica el funcionamiento de las funciones sin el sufijo "_l"; las funciones con el sufijo "_l" difieren solo en usar el objeto de configuración regional locale en lugar de la configuración regional

actual.
