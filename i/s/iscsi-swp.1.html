ISCSI-SWP(1) iscsi-swp: obtener/establecer escritura por software ISCSI-SWP(1)

NOMBRE

iscsi-swp - Utilidad para obtener/establecer la protección contra escritura por software en un LUN iSCSI.

SINOPSIS

iscsi-swp [ OPCIONES ] <PORTAL_ISCSI>

iscsi-ls [-i --nombre-iniciador=<IQN>] [-s --swp {encendido|apagado}] [-d --debug=<ENTERO>] [-? --ayuda] [--uso]

DESCRIPCIÓN

iscsi-swp es una utilidad para obtener o establecer la protección contra escritura por software en un LUN iSCSI.

FORMATO URL PORTAL ISCSI

El formato del portal iSCSI es 'iscsi://[<nombre_usuario>[%<contraseña>]@]<host>[:<puerto>]'

El nombre de usuario y la contraseña solo son necesarios si el destino requiere autenticación CHAP. Opcionalmente, puede especificar el nombre de usuario y la contraseña a través de las variables de entorno LIBISCSI_CHAP_USERNAME y LIBISCSI_CHAP_PASSWORD.

El host puede especificarse como un nombre de host, una dirección IPv4 o una dirección IPv6. Ejemplos:

	iscsi://192.0.2.1
	iscsi://[2001:DB8::1]:3261
	iscsi://ronnie%password@iscsi.example.com

El puerto es el puerto TCP en el destino al que conectarse. El valor predeterminado es 3260.

OPCIONES

-i --nombre-iniciador=<IQN>

Esto especifica el nombre_iniciador que iscsi-ls usará al iniciar sesión en el destino.

El nombre predeterminado es 'iqn.2007-10.com.github:sahlberg:libiscsi:iscsi-ls', pero puede usar este argumento para anularlo. Esto es principalmente necesario para casos en los que el destino está configurado con control de acceso para permitir solo inicios de sesión de descubrimiento desde nombres_iniciador conocidos.

-s --swp {encendido|apagado}

Por defecto, iscsi-swp solo imprimirá la configuración actual del bit de protección contra escritura por software. Al usar este argumento, iscsi-swp también intentará establecer/borrar la bandera en el LUN de destino. 
iscsi-swp iscsi://127.0.0.1/iqn.ronnie.test/1
SWP:0
iscsi-swp iscsi://127.0.0.1/iqn.ronnie.test/1 --swp on
SWP:0
Activando SWP
iscsi-swp iscsi://127.0.0.1/iqn.ronnie.test/1 --swp off
SWP:0
Desactivando SWP

-d --debug=<ENTERO>

Nivel de depuración.

-? --ayuda

Mostrar texto de ayuda básico.

--uso

Mostrar texto de uso básico.
