ISO-INFO(1) Comandos de usuario ISO-INFO(1)

NOMBRE

iso-info - muestra Información sobre una imagen ISO 9660

SINOPSIS

iso-info [OPCIÓN...]

DESCRIPCIÓN

-d, --debug=UINT
Establece la depuración a NIVEL
-i, --input[=ARCHIVO]
Nombre del archivo del que leer la imagen ISO-9960
-f
Genera una salida similar a 'find . -print'
-l, --iso9660
salida similar a 'ls -lR' para un sistema de archivos ISO 9660
-U, --udf
salida similar a 'ls -lR' para un sistema de archivos UDF
--no-header
No mostrar cabecera ni copyright (para regresión
--no-joliet
No usar información de la extensión Joliet
--no-rock-ridge
No usar información de la extensión Rock-Ridge
--no-xa
No usar información de la extensión XA
-r --show-rock-ridge UINT Muestra si la imagen usa extensiones Rock-Ridge
Se considerará un máximo de UINT archivos. Usa 0 para todos los archivos.
-q, --quiet
No producir salida de advertencia
-V, --version
muestra la versión y la información de copyright y sale

Opciones de ayuda:

-?, --help
Muestra este mensaje de ayuda
--usage
Muestra un breve mensaje de uso
