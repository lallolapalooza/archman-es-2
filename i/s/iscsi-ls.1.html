ISCSI-LS(1) iscsi-ls: listar objetivos iSCSI ISCSI-LS(1)

NOMBRE

iscsi-ls - Utilidad para listar objetivos y LUNs iSCSI

SINOPSIS

iscsi-ls [ OPCIONES ] <PORTAL_ISCSI>

iscsi-ls [-i --nombre-iniciador=<IQN>] [-s --mostrar-luns] [-d --depurar] [-? --ayuda] [--uso]

DESCRIPCIÓN

iscsi-ls es una utilidad para listar todos los objetivos y LUNs de un portal iSCSI.

FORMATO URL PORTAL ISCSI

El formato del portal iSCSI es 'iscsi://[<nombredeusuario>[%<contraseña>]@]<host>[:<puerto>]'

El nombre de usuario y la contraseña solo son necesarios si el objetivo requiere autenticación CHAP. Opcionalmente, puede especificar el nombre de usuario y la contraseña a través de las variables de entorno LIBISCSI_CHAP_USERNAME y LIBISCSI_CHAP_PASSWORD.

El host puede especificarse como un nombre de host, una dirección IPv4 o una dirección IPv6. Ejemplos:

	iscsi://192.0.2.1
	iscsi://[2001:DB8::1]:3261
	iscsi://ronnie%contraseña@iscsi.example.com

El puerto es el puerto TCP en el objetivo al que conectarse. El valor predeterminado es 3260.

OPCIONES

-i --nombre-iniciador=<IQN>

Esto especifica el nombre de iniciador que iscsi-ls utilizará al iniciar sesión en el objetivo.

El nombre predeterminado es 'iqn.2007-10.com.github:sahlberg:libiscsi:iscsi-ls' pero puede usar este argumento para anularlo. Esto es principalmente necesario para casos en los que el objetivo está configurado con control de acceso para permitir solo inicios de sesión de descubrimiento desde nombres de iniciador conocidos.

-s --mostrar-luns

Además de listar todos los objetivos en el portal especificado, también lista todos los LUNs y sus tipos en cada objetivo descubierto.

Para mostrar el tipo de LUN, iscsi-ls necesita poder realizar un inicio de sesión normal en los objetivos. Si el objetivo utiliza control de acceso, deberá especificar un nombre de iniciador que permita inicios de sesión normales en el objetivo.

-d --depurar

Imprime información de depuración.

-? --ayuda

Muestra texto de ayuda básico.

--uso

Muestra texto de uso básico.
