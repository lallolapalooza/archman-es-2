NOMBRE

iscsiuio - Controlador de I/O UserSpace de iSCSI

SINOPSIS

iscsiuio [-d-f-v]

DESCRIPCIÓN

iscsiuio es el controlador de I/O UserSpace para la Tarjeta de Interfaz de Red (NIC) Gigabit Ethernet QLogic NetXtreme II BCM5706/5708/5709 series PCI/PCI-X y para la Tarjeta de Interfaz de Red (NIC) Gigabit Ethernet QLogic NetXtreme II BCM57710/57711/57712/57800/57810/57840 series PCI-E. El controlador ha sido probado en kernels 2.6.28 y superiores.

Consulte el archivo README.TXT del paquete del controlador sobre cómo compilar e instalar el controlador.

Consulte diversas documentaciones de Linux sobre cómo configurar el protocolo y la dirección de red.

DEPENDENCIA DEL CONTROLADOR

PARÁMETROS

Hay muy pocos parámetros al ejecutar esta aplicación.

-d|--debug<niveldedebug>
Esto es para habilitar el modo de depuración donde los mensajes de depuración se enviarán a stdout. Los siguientes modos de depuración son compatibles:
DEBUG 4 - Imprimir todos los mensajes

INFO 3 - Imprimir mensajes necesarios para seguir el código uIP (por defecto)

WARN 2 - Imprimir mensajes de advertencia

ERROR 1 - Imprimir solo errores críticos

-f|--foreground
Esto es para habilitar el modo en primer plano para que esta aplicación no se ejecute en segundo plano.
-v|--version
Esto es para imprimir la versión.
-p|--pid<archivodepid>
Usar archivo de pid (por defecto /run/iscsiuio.pid )
-h|--help
Mostrar esta ayuda y salir.
