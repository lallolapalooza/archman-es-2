El constructor por defecto define un objeto ISharedStream de tipo stub que no puede usarse inmediatamente para acceder a la memoria compartida. Para usarlo, primero se debe llamar a su miembro open

ISharedStream(size_t maxSize, SizeUnit sizeUnit, std::ios::openmode openMode = std::ios::in, size_t access = 0600):
Este constructor crea un std::istream que se conecta a un segmento de memoria compartida con una capacidad de al menos maxSize * sizeUnit bytes. Por defecto, el segmento de memoria compartida se abre para lectura. A diferencia de los modos de apertura utilizados para flujos de archivos, crear un flujo de memoria compartida con el modo de apertura ios::in es válido. En este caso se crea el segmento de memoria compartida y, una vez que otro proceso (u objeto) haya escrito información en la memoria compartida, esta información puede leerse. Los permisos de acceso de la memoria compartida se definen con el parámetro access, utilizando la conocida forma dechmod(1) para definir los permisos de acceso para el propietario, el grupo y otros, usando dígitos octales. Si la construcción tiene éxito, la memoria compartida está lista para su uso. Si la construcción falla, se lanza una excepción FBB::Excep
tion.
o
ISharedStream(int id, std::ios::openmode openMode = std::ios::in):
Este constructor crea un std::istream que se conecta a un segmento de memoria compartida con ID id. Si la construcción tiene éxito, la memoria compartida está lista para su uso. Si la construcción falla (p. ej., no existe ningún segmento de memoria compartida con ID id), se lanza una excepción FBB::Exc

void memInfo(std::ostream &out, char const *end = "\n"):
Se inserta información sobre el objeto ISharedMemory en el objeto ostream proporcionado. Se muestran los IDs de los segmentos compartidos, sus tamaños, el número máximo de segmentos de memoria compartida, el número de bytes que se pueden leer de la memoria compartida y su capacidad de almacenamiento actual, etc. Después de la información sobre la memoria compartida, end se inserta en out
.

void open(size_t maxSize, SizeUnit sizeUnit, std::ios::openmode openMode = std::ios::in, size_t access = 0600):
Este miembro crea un segmento de memoria compartida con una capacidad de al menos maxSize * sizeUnit bytes, y conecta el segmento de memoria compartida con el FBB::ISharedStream. No existe un miembro close correspondiente y no es necesario. Por defecto, el segmento de memoria compartida se abre para lectura. A diferencia de los modos de apertura utilizados para flujos de archivos, crear un flujo de memoria compartida con el modo de apertura ios::in es válido. En este caso se crea el segmento de memoria compartida y, una vez que otro proceso haya escrito información en la memoria compartida, esta puede leerse. Los permisos de acceso de la memoria compartida se definen con el parámetro access, utilizando la conocida forma dechmod(1) para definir los permisos de acceso para el propietario, el grupo y otros, usando dígitos octales. Si la apertura tiene éxito, la memoria compartida está lista para su uso. Si la apertura falla, se lanza una excepción FBB::Excep
tion.
o
void open(int id, std::ios::openmode openMode = std::ios::in):
Este miembro conecta el objeto FBB::ISharedStream a un segmento de memoria compartida con ID id. No existe un miembro close correspondiente y no es necesario. Si la apertura tiene éxito, la memoria compartida está lista para su uso. Si la apertura falla (p. ej., no existe ningún segmento de memoria compartida con ID id), se lanza una excepción FBB::Excep
tion.
o
void remove():
Primero se bloquea la memoria compartida. A continuación, toda la memoria compartida se devuelve al sistema operativo. El objeto FBB::ISharedStream queda inutilizable después de regresar de remove. Otros procesos que estaban usando la memoria compartida pueden continuar
haciéndolo.

Tenga en cuenta que, de forma predeterminada, las excepciones lanzadas desde dentro de un objeto std::stream son capturadas por el propio objeto stream, estableciendo su indicador ios::failbit. Para permitir que las excepciones salgan de un objeto stream, se puede llamar a su miembro exceptions, p. ej., usando: std::stream object are caught by the stream object, setting its ios::failbit flag. To allow exceptions to leave a stream object, its exceptions member can be called, e.g.,

adbit | ios::eofbit);
