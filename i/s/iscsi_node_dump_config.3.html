NOMBRE

iscsi_node_dump_config - Volcar todas las configuraciones del nodo iSCSI especificado.

SINOPSIS

const char * iscsi_node_dump_config (struct iscsi_node *node, bool show_secret);

ARGUMENTOS

node
Puntero de 'struct iscsi_node'. Si este puntero es NULL, su programa será terminado por assert.
show_secret
Si mostrar el secreto CHAP. Si se establece como falso, mostrará la contraseña como "********"

DESCRIPCIÓN

Volcar todas las configuraciones del nodo iSCSI especificado. Se omitirán las configuraciones vacías.

RETORNO

const char *. Es necesario liberar esta memoria con free.
