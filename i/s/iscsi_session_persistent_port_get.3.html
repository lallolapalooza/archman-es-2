NOMBRE

iscsi_session_persistent_port_get - Recupera el puerto persistente del objetivo iSCSI de la sesión especificada

SINOPSIS

int32_t iscsi_session_persistent_port_get (struct iscsi_session *se);

ARGUMENTOS

se
Puntero de 'struct iscsi_session'. Si este puntero es NULL, su programa será terminado por assert.

DESCRIPCIÓN

Recupera el puerto persistente del objetivo iSCSI de la sesión iSCSI especificada. El 'puerto persistente' es el puerto de red donde el iniciador iSCSI envía la solicitud inicial. Cuando se utiliza la redirección iSCSI, este puerto podría no ser el puerto de red utilizado para la transacción iSCSI real. Utilice `iscsi_session_port_get` para la dirección de red del objetivo de la transacción iSCSI.

RETORNO

int32_t. -1 si no es compatible.
