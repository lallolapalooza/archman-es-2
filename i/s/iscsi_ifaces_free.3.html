iscsi_ifaces_free(3) Manual de la API iscsi_ifaces_free(3)

NOMBRE

iscsi_ifaces_free - Libera la memoria del array de punteros 'struct iscsi_iface'

SINOPSIS

void iscsi_ifaces_free (struct iscsi_iface **ifaces, uint32_t iface_count);

ARGUMENTOS

ifaces
Puntero al array de punteros 'struct iscsi_iface'.
iface_count
uint32_t, el tamaño del array de punteros 'struct iscsi_iface'.

DESCRIPCIÓN

Libera la memoria del array de punteros 'iscsi_iface' generado por Si el puntero 'ifaces' proporcionado es NULL o 'iface_count' es 0, no hace nada.

RETORNO

void
