finite(3) Manual de Funciones de Biblioteca finite(3)

NOMBRE

finite, finitef, finitel, isinf, isinff, isinfl, isnan, isnanf, isnanl - funciones de clasificación de punto flotante de BSD

BIBLIOTECA

Biblioteca matemática (libm, -lm)

SINOPSIS

#include <math.h>
int finite(double x);
int finitef(float x);
int finitel(long double x);
int isinf(double x);
int isinff(float x);
int isinfl(long double x);
int isnan(double x);
int isnanf(float x);
int isnanl(long double x);

DESCRIPCIÓN

Las funciones finite(), finitef() y finitel() devuelven un valor distinto de cero si x no es ni infinito ni un valor "no es un número" (NaN), y 0 en caso contrario.

Las funciones isnan(), isnanf() y isnanl() devuelven un valor distinto de cero si x es un valor NaN, y 0 en caso contrario.

Las funciones isinf(), isinff() y isinfl() devuelven 1 si x es infinito positivo, -1 si x es infinito negativo, y 0 en caso contrario.

ATRIBUTOS

Para una explicación de los términos utilizados en esta sección, ver attributes(7).

Interfaz Atributo Valor
finite (), finitef (), finitel (), isinf (), isinff (), isinfl (), isnan (), isnanf (), isnanl () Seguridad en hilos MT-Safe

NOTAS

Tenga en cuenta que estas funciones están obsoletas. C99 define las macros isfinite(), isinf() y isnan() (para todos los tipos) que las reemplazan. Además, tenga en cuenta que la función isinf() de C99 tiene garantías más débiles sobre el valor de retorno. Ver fpclassify(3).
