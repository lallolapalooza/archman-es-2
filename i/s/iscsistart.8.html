ISCSISTART(8) Manual del Administrador de Linux ISCSISTART(8)

NOMBRE

iscsistart - herramienta de arranque iSCSI

SINOPSIS

iscsistart [OPCIÓN]

DESCRIPCIÓN

iscsistart iniciará una sesión utilizando la configuración pasada, o utilizando la información de arranque iBFT o Open Firmware [OF]. Este programa no debe ejecutarse para gestionar sesiones. Su uso principal es iniciar sesiones utilizadas para el arranque raíz iSCSI.

OPCIONES

[-c|--config=]archivo-configuración
Leer la configuración de archivo-configuración en lugar del archivo predeterminado /etc/iscsi/iscsid.conf.
[-i|--initiatorname=]nombre
Establecer InitiatorName a nombre (Requerido si no se usa iBFT u OF)
[-t|--targetname=]nombre
Establecer TargetName a nombre (Requerido si no se usa iBFT u OF)
[-g|--tgpt=]N
Establecer el tag del grupo de portales de destino a N (Requerido si no se usa iBFT u OF)
[-a|--address=]A.B.C.D
Establecer la dirección IP a A.B.C.D (Requerido si no se usa iBFT u OF)
[-p|--port=]N
Establecer el puerto a N (Opcional. Predeterminado 3260)
[-u|--username=]N
Establecer nombre de usuario a N (Opcional)
[-w|--password=]N
Establecer contraseña a N (Opcional)
[-U|-username_in=]N
Establecer nombre de usuario entrante a N (Opcional)
[-W|--password_in=]N
Establecer contraseña entrante a N (Opcional)
[-d|--debug=]nivel-depuración
Imprimir información de depuración
[-b|--fwparam_connect]
Crear una sesión con el destino usando la información iBFT u OF
[-N|--fwparam_network]
Activar la red según lo especificado por iBFT u OF
[-f|--fwparam_print]
Imprimir la información iBFT u OF en STDOUT
[-P|--param=]NOMBRE=VALOR
Establecer el parámetro con el nombre NOMBRE a VALOR. NOMBRE es una de las configuraciones en el registro del nodo o en iscsid.conf. Se pueden pasar múltiples parámetros.
[-h|--help]
Mostrar esta ayuda y salir
[-v|--version]
Mostrar versión y salir
