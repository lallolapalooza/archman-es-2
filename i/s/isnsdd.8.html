NOMBRE

isnsdd - demonio de descubrimiento iSNS

SINOPSIS

isnsdd [-f] [-c archivo] [-d instalación-depuración]

DESCRIPCIÓN

Isnsdd es un demonio del lado del cliente para iSNS. Registra nodos de almacenamiento y puertos con el servicio iSNS y actualiza estos registros de manera oportuna.

El demonio también se registra para recibir notificaciones SCN y las procesa. Puede configurarse para invocar una aplicación auxiliar externa para cada notificación de estado recibida. El nombre de la ruta de la aplicación auxiliar se puede especificar a través de la opción SCNCallout en el archivo de configuración.

OPCIONES

Por defecto, isnsd tomará la mayoría de su configuración del archivo de configuración /etc/isns/isnsdd.conf, con la adición de las siguientes opciones de línea de comandos:

--config archivo, -c archivo
Esta opción anula el archivo de configuración predeterminado.
--foreground,-f
Por defecto, isnsd se ejecutará en segundo plano. Al especificar esta opción, puede indicarle que se ejecute en primer plano. Cualquier mensaje de error o salida de depuración se imprimirá en la consola en lugar de enviarse a syslog.
--role rol
Esto le dice al demonio de descubrimiento en qué capacidad debe registrarse con el servidor iSNS. Rol puede ser initiator (iniciador) o control. El valor predeterminado es registrarse como un iniciador.
El registro de nodos de destino requiere el uso de un mecanismo diferente, ya que el servidor de destino iSCSI necesita informar al demonio de descubrimiento sobre cada destino exportado por separado. Esto aún no está implementado.
--debug instalación, -d instalación
habilita la depuración. Las instalaciones válidas son
socket envío/recepción de red
auth información relacionada con la autenticación y seguridad
message capa de protocolo iSNS
state estado de la base de datos
scn mensajes SCN (notificación de cambio de estado)
esi mensajes ESI (consulta de estado de entidad)
all todos los anteriores

VER TAMBIÉN

RFC 4171, isnsd(8), isnsadm(8), isns_config(5).
