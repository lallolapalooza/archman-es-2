ISADUMP(8) Manual del Administrador del Sistema ISADUMP(8)

NOMBRE

isadump - examinar registros ISA

SINOPSIS

isadump [-y] [-W|-L] [-k V1,V2...] reg_dir reg_dat [banco [reg_banco]] # para acceso tipo I2C
isadump -f [-y] [-W|-L] direccion [rango [banco [reg_banco]]] # para espacio de direcciones plano

DESCRIPCIÓN

isadump es un pequeño programa auxiliar para examinar registros visibles a través del bus ISA. Está diseñado para sondear cualquier chip que resida en el bus ISA trabajando con un registro de direcciones y un registro de datos (acceso tipo I2C) o un rango plano (de hasta 256 bytes).

OPCIONES

-f
Habilita el modo de espacio de direcciones plano.
-y
Deshabilita el modo interactivo. Por defecto, isadump esperará una confirmación del usuario antes de manipular el bus ISA. Cuando se utiliza esta bandera, realizará la operación directamente. Esto está pensado principalmente para usarse en scripts.
-k V1,V2...
Especifica una lista separada por comas de bytes a enviar como secuencia de teclas para entrar en el modo de configuración del chip. La mayoría de los chips Super-I/O lo necesitan. Las secuencias de teclas conocidas son: 0x87,0x01,0x55,0x55 para ITE, 0x55 para SMSC, 0x87,0x87 para Winbond y VIA, no se necesita ninguna para National Semiconductor.
-W
Realiza lecturas de 16 bits.
-L
Realiza lecturas de 32 bits.

OPCIONES (modo acceso tipo I2C)

Se deben proporcionar al menos dos opciones a isadump. reg_dir contiene la dirección ISA del registro de direcciones para el chip a sondear; reg_dat contiene la dirección del registro de datos. Ambas direcciones son enteros entre 0x0000 y 0x3FFF. Normalmente, si la dirección base del chip es 0x0nn0, el registro de direcciones está en 0x0nn5 y el registro de datos está en 0x0nn6. La dirección base más común para chips de monitorización de hardware es 0x0290.

Para chips Super-I/O, el registro de direcciones suele estar en 0x2E con el registro de datos en 0x2F.

Los parámetros banco y reg_banco son útiles en los chips Winbond así como en los chips Super-I/O. banco es un entero entre 0 y 31, y reg_banco es un entero entre 0x00 y 0xFF (valor por defecto: 0x4E para chips Winbond, 0x07 para chips Super-I/O). La hoja de datos del W83781D tiene más información sobre la selección de bancos.

OPCIONES (modo espacio de direcciones plano)

En modo plano, solo se requiere un parámetro. direccion contiene la dirección ISA del chip a sondear; es un entero entre 0x0000 y 0xFFFF. Si se proporciona, rango indica cuántos bytes se deben leer (debe ser múltiplo de 16). Si no se proporciona el rango, por defecto son 256 bytes y la dirección se alinea forzosamente a un límite de 256 bytes.

Los parámetros banco y reg_banco son útiles en los chips Super-I/O National Semiconductor PC87365 y PC87366. banco es un entero entre 0 y 31, y reg_banco es un entero entre 0x00 y 0xFF (valor por defecto: 0x09; debe caber en el rango especificado). Consulte la hoja de datos del PC87365 para obtener más información sobre la selección de bancos.

NOTAS

Si no se especifica ningún banco, no se realiza ninguna operación de cambio de banco.

Si se especifica un banco, se restaura el valor original antes de que isadump salga.

Volcar chips Super-I/O es típicamente un proceso de dos pasos. Primero, tendrá que acceder a la dirección principal del Super-I/O con un comando como: isadump 0x2e 0x2f 0x09. Esto seleccionará el dispositivo lógico 9 (el valor correcto depende del chip). En 0x60 encontrará la palabra de dirección del dispositivo lógico, por ejemplo "ec c0". Luego puede usar un comando como: isadump -f 0xecc0 16. Esto volcará los registros del dispositivo lógico. El rango correcto depende del chip.

ADVERTENCIA

Manipular el espacio de datos ISA es extremadamente peligroso. Ejecutar isadump con parámetros aleatorios puede causar bloqueos del sistema, pérdida de datos y ¡peores consecuencias! Tenga mucho cuidado al usar este programa.
