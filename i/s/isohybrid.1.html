NOMBRE

isohybrid — Procesa posteriormente una imagen ISO 9660 para arrancar como un disco duro.

SINOPSIS

isohybrid [OPCIONES] <boot.iso>

DESCRIPCIÓN

La utilidad isohybrid modifica una imagen ISO 9660 generada con mkisofs, genisoimage, o utilidades compatibles, para que sea arrancable como un CD-ROM o como un disco duro.

OPCIONES

-h <X>

Número de cabezales de geometría (por defecto 64)
-s <X>

Número de sectores de geometría (por defecto 32)
-e <X>, --entry <X>
Especifica el número de entrada de la partición (1-4)
-o <X>, --offset <X>

Especifica el desplazamiento de la partición (por defecto 0)
-t <X>, --type <X>

Especifica el tipo de partición (por defecto 0x17)
-i <X>, --id <X>

Especifica el ID del MBR (por defecto aleatorio)
-u, --uefi
Construye una imagen arrancable por EFI
-m, --mac
Añade soporte para tabla de particiones de Apple File Protocol
--forcehd0
Asume que se carga como disco ID 0
--ctrlhd0
Asume disco ID 0 si se presiona la tecla Ctrl
--partok
Permite arrancar desde dentro de una partición
-?, --help
Muestra la ayuda
-v, --verbose
Muestra salida detallada
-V, --version
Muestra información de la versión

VER TAMBIÉN

mkisofs(1)
