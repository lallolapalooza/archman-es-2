ISASET(8) Manual del Administrador del Sistema ISASET(8)

NOMBRE

isaset - establecer registros ISA

SINOPSIS

isaset [-y] [-W|-L] addrreg datareg address value [mask] #para acceso tipo I2C
isaset -f [-y] [-W|-L] address value [mask] #para espacio de direcciones plano

DESCRIPCIÓN

isaset es un pequeño programa auxiliar para establecer registros visibles a través del bus ISA.

OPCIONES

-f
Habilita el modo de espacio de direcciones plano.
-y
Deshabilita el modo interactivo. Por defecto, isaset esperará una confirmación del usuario antes de modificar el bus ISA. Cuando se utiliza esta opción, realizará la operación directamente. Esto está pensado principalmente para ser utilizado en scripts.
-W
Realiza una escritura de 16 bits.
-L
Realiza una escritura de 32 bits.

OPCIONES (modo de acceso tipo I2C)

Se deben proporcionar cuatro opciones a isaset. addrreg contiene la dirección ISA del registro de dirección para el chip a sondear; datareg contiene la dirección del registro de datos. Ambas direcciones son enteros entre 0x0000 y 0x3FFF. Normalmente, si la dirección base del chip es 0x0nn0, el registro de dirección está en 0x0nn5 y el registro de datos está en 0x0nn6. La dirección base más común para los chips de monitoreo de hardware es 0x0290. Para los chips Super-I/O, el registro de dirección suele estar en 0x2E con el registro de datos en 0x2F. Los parámetros address y value son dos enteros entre 0x00 y 0xFF. isaset escribirá el valor value en la dirección address. Se puede proporcionar una mask opcional como quinto parámetro, preservando los bits no enmascarados en la ubicación escrita.

OPCIONES (modo de espacio de direcciones plano)

En modo plano, se deben proporcionar dos parámetros. address contiene la dirección ISA del registro a escribir; es un entero entre 0x0000 y 0xFFFF. Básicamente, es la suma de la dirección base del chip y la dirección del registro del chip. isaset escribirá el valor value en esta dirección. Se puede proporcionar una mask opcional como tercer parámetro, preservando los bits no enmascarados en la ubicación escrita.

ADVERTENCIA

Manipular el espacio de datos ISA es extremadamente peligroso. Ejecutar isaset con parámetros aleatorios puede causar fallos del sistema, pérdida de datos y algo peor. Tenga mucho cuidado al usar este programa.

VER TAMBIÉN

i2cset(8), isadump(8)
