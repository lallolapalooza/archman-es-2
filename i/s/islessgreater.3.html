isgreater(3) Manual de Funciones de Librería isgreater(3)

NOMBRE

isgreater, isgreaterequal, isless, islessequal, islessgreater, isunordered - pruebas relacionales de punto flotante sin excepción para NaN

LIBRERÍA

Librería matemática (libm, -lm)

SINOPSIS

#include <math.h>
int isgreater(x, y);
int isgreaterequal(x, y);
int isless(x, y);
int islessequal(x, y);
int islessgreater(x, y);
int isunordered(x, y);
Requisitos de Macros de Prueba de Funcionalidad para glibc (ver feature_test_macros(7)):
    Todas las funciones descritas aquí:
        _ISOC99_SOURCE || _POSIX_C_SOURCE >= 200112L

DESCRIPCIÓN

Las operaciones relacionales normales (como <, "menor que") fallan si uno de los operandos es NaN. Esto provocará una excepción. Para evitar esto, C99 define las macros listadas a continuación.

Se garantiza que estas macros evalúan sus argumentos solo una vez. Los argumentos deben ser de tipo punto flotante real (nota: no pase valores enteros como argumentos a estas macros, ya que los argumentos *no* serán promovidos a tipos de punto flotante real).

isgreater()
determina (x) > (y) sin una excepción si x o y es NaN.
isgreaterequal()
determina (x) >= (y) sin una excepción si x o y es NaN.
isless()
determina (x) < (y) sin una excepción si x o y es NaN.
islessequal()
determina (x) <= (y) sin una excepción si x o y es NaN.
islessgreater()
determina (x) < (y) || (x) > (y) sin una excepción si x o y es NaN. Esta macro no es equivalente a x != y porque esa expresión es verdadera si x o y es NaN.
isunordered()
determina si sus argumentos no están ordenados, es decir, si al menos uno de los argumentos es un NaN.

VALOR DE RETORNO

Las macros, excepto isunordered(), devuelven el resultado de la comparación relacional; estas macros devuelven 0 si alguno de los argumentos es un NaN.

isunordered() devuelve 1 si x o y es NaN y 0 en caso contrario.

ERRORES

No se producen errores.

ATRIBUTOS

Para una explicación de los términos utilizados en esta sección, consulte attributes(7).

Interfaz Atributo Valor
isgreater (), isgreaterequal (), isless (), islessequal (), islessgreater (), isunordered () Seguridad en hilos MT-Safe

VERSIÓNES

No todo el hardware soporta estas funciones, y donde el soporte hardware no está proporcionado, serán emuladas por macros. Esto resultará en una penalización de rendimiento. No use estas funciones si NaN no es de su interés.

ESTÁNDARES

C11, POSIX.1-2008.

HISTORIA

POSIX.1-2001, C99.

VER TAMBIÉN

fpclassify(3), isnan(3)
