NOMBRE

iscsi_session_username_get - Recupera el nombre de usuario de autenticación de la sesión especificada.

SINOPSIS

const char * iscsi_session_username_get (struct iscsi_session *se);

ARGUMENTOS

se
Puntero de 'struct iscsi_session'. Si este puntero es NULL, su programa será terminado por una aserción.

DESCRIPCIÓN

Recupera el nombre de usuario de autenticación de la sesión iSCSI especificada. Actualmente, open-iscsi solo soporta el método de autenticación CHAP. Este ajuste se controla en iscsid.conf:

RETORNO

const char *. Cadena vacía si no se utiliza la autenticación CHAP o si no se pudieron leer los datos de autenticación. No es necesario liberar esta memoria; los recursos serán liberados por iscsi_session_free o iscsi_sessions_free.
