NOMBRE

iso_8859-11 - Conjunto de caracteres ISO/IEC 8859-11 codificado en octal, decimal y hexadecimal

DESCRIPCIÓN

El estándar ISO/IEC 8859 incluye varias extensiones de 8 bits al conjunto de caracteres ASCII (también conocido como ISO/IEC 646-IRV). ISO/IEC 8859-11 codifica los caracteres utilizados en el idioma tailandés.

ALFABETOS ISO/IEC 8859

El conjunto completo de alfabetos ISO/IEC 8859 incluye:

ISO/IEC 8859-1 Idiomas de Europa Occidental (Latin-1)
ISO/IEC 8859-2 Idiomas de Europa Central y Oriental (Latin-2)
ISO/IEC 8859-3 Idiomas del Sureste de Europa y misceláneos (Latin-3)
ISO/IEC 8859-4 Idiomas escandinavos/bálticos (Latin-4)
ISO/IEC 8859-5 Latín/Cirílico
ISO/IEC 8859-6 Latín/Árabe
ISO/IEC 8859-7 Latín/Griego
ISO/IEC 8859-8 Latín/Hebreo
ISO/IEC 8859-9 Modificación de Latin-1 para turco (Latin-5)
ISO/IEC 8859-10 Idiomas lapón/nórdico/esquimales (Latin-6)
ISO/IEC 8859-11 Latín/Tailandés
ISO/IEC 8859-13 Idiomas de la cuenca del Báltico (Latin-7)
ISO/IEC 8859-14 Celta (Latin-8)
ISO/IEC 8859-15 Idiomas de Europa Occidental (Latin-9)
ISO/IEC 8859-16 Rumano (Latin-10)

CARACTERES ISO/IEC 8859-11

NAME

iso_8859-11 - TIS-620 Thai character code chart

DESCRIPTION

The ISO/IEC 8859 standard specifies a character encoding scheme for the Latin alphabet. It is a 7-bit encoding, defining 128 characters. The lower 128 characters (0-127) are the same as the ASCII character set. The upper 128 characters (128-255) are assigned according to the specific standard.

ISO/IEC 8859-11 is an 8-bit encoding used for the Thai language. It is identical to TIS-620 (Thai Industrial Standard 620), which is the standard character encoding for Thai in Thailand.

NOTES

ISO/IEC 8859-11 is the same as TIS (Thai Industrial Standard) 620-2253, commonly known as TIS-620, except for the character in position A0: ISO/IEC 8859-11 defines this as NO-BREAK SPACE, while TIS-620 leaves it undefined.
