isfdtype(3) Manual de funciones de la biblioteca isfdtype(3)

NOMBRE

isfdtype - comprobar el tipo de archivo de un descriptor de archivo

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <sys/stat.h>
#include <sys/socket.h>
int isfdtype(int fd, int fdtype);
Requisitos de Macro de Prueba de Funciones para glibc (ver feature_test_macros(7)):

isfdtype():

    Desde glibc 2.20:
        _DEFAULT_SOURCE
    Antes de glibc 2.20:
        _BSD_SOURCE || _SVID_SOURCE

DESCRIPCIÓN

La función isfdtype() comprueba si el descriptor de archivo fd se refiere a un archivo del tipo fdtype. El argumento fdtype especifica una de las constantes S_IF* definidas en <sys/stat.h> y documentadas en stat(2) (por ejemplo, S_IFREG).

VALOR DE RETORNO

La función isfdtype() devuelve 1 si el descriptor de archivo fd es del tipo fdtype y 0 si no lo es. En caso de error, devuelve -1 y establece errno para indicar el error.

ERRORES

La función isfdtype() puede fallar con cualquiera de los mismos errores que fstat(2).

VERSIÓNES

Las aplicaciones portátiles deben usar fstat(2) en su lugar.

ESTÁNDARES

Ninguno.

HISTORIA

Apareció en el borrador del estándar POSIX.1g. Está presente en OpenBSD y Tru64 UNIX (donde el archivo de cabecera requerido en ambos casos es solo <sys/stat.h>, como se muestra en el borrador de POSIX.1g).

VER TAMBIÉN

fstat(2)
