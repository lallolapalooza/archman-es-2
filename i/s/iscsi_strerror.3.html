NOMBRE

iscsi_strerror - Convertir código de error a cadena.

SINOPSIS

const char * iscsi_strerror (int rc);

ARGUMENTOS

rc
int. Código de retorno de las funciones de libiscsiur. Cuando el código de error proporcionado no es un código de error válido, devuelve "Argumento inválido".

DESCRIPCIÓN

Convierte el código de error (int) a cadena (const char *):

* LIBISCSI_OK -- "OK"

* LIBISCSI_ERR_BUG -- "BUG de la biblioteca libopeniscsiusr"

* LIBISCSI_ERR_SESS_NOT_FOUND - "Sesión iSCSI especificada no encontrada"

* LIBISCSI_ERR_ACCESS - "Permiso denegado"

* LIBISCSI_ERR_NOMEM - "Fuera de memoria"

* LIBISCSI_ERR_SYSFS_LOOKUP - "No se pudo buscar el objeto en sysfs"

* Otro número de error inválido -- "Argumento inválido"

RETORNO

const char *. El significado del código de error proporcionado. No liberar el puntero devuelto.
