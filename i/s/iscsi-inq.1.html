ISCSI-INQ(1) iscsi-inq: Realiza una consulta INQUIRY en ISCSI-INQ(1)

NOMBRE

iscsi-inq - Utilidad para solicitar datos INQUIRY de un LUN iSCSI

SINOPSIS

iscsi-inq [ OPCIONES ] <URL_ISCSI>

iscsi-inq [-i --nombre-iniciador=<IQN>] [-e --evpd=<ENTERO>] [-c --codigopagina=<ENTERO>] [-d --depuracion=<ENTERO>] [-? --ayuda] [--uso] [<URL_ISCSI>]

DESCRIPCIÓN

iscsi-inq es una utilidad para solicitar datos INQUIRY de un LUN iSCSI.

FORMATO URL ISCSI

El formato de la URL iSCSI es 'iscsi://[<usuario>[%<contraseña>]@]<host>[:<puerto>]/<nombre-iqn-objetivo>/<lun>'

El nombre de usuario y la contraseña solo son necesarios si el objetivo requiere autenticación CHAP. Opcionalmente, puede especificar el nombre de usuario y la contraseña a través de las variables de entorno LIBISCSI_CHAP_USERNAME y LIBISCSI_CHAP_PASSWORD.

El host puede especificarse como un nombre de host, una dirección IPv4 o una dirección IPv6. Ejemplos:

	iscsi://192.0.2.1/iqn.ronnie.test/1
	iscsi://[2001:DB8::1]:3261/iqn.ronnie.test/1
	iscsi://ronnie%contraseña@iscsi.example.com/iqn.ronnie.test/1

El puerto es el puerto TCP en el objetivo al que conectarse. El predeterminado es 3260.

El nombre-iqn-objetivo es el nombre iqn del objetivo. Un portal iSCSI puede tener varios objetivos definidos. Utilice iscsi-ls para listar todos los objetivos disponibles en un portal específico.

LUN es el número de LUN para el que se informarán los datos de INQUIRY.

OPCIONES

-i --nombre-iniciador=<IQN>

Esto especifica el nombre-iniciador que usará iscsi-inq al iniciar sesión en el objetivo.

El nombre predeterminado es 'iqn.2007-10.com.github:sahlberg:libiscsi:iscsi-inq', pero puede usar este argumento para anularlo. Esto es necesario principalmente para casos en los que el objetivo está configurado con control de acceso para permitir solo inicios de sesión de descubrimiento desde nombres-iniciador conocidos.

-e --evpd=<ENTERO>

Por defecto, iscsi-inq mostrará los datos de consulta estándar. Especifique evpd como 1 para mostrar páginas VPD extendidas.

-c --codigopagina=<ENTERO>

Este argumento especifica qué página VPD se mostrará cuando se solicite evpd. El valor predeterminado es 0x00, que representa PÁGINAS VPD ADMITIDAS.

Este argumento solo se puede utilizar cuando evpd se establece en 1.

-d --depuracion=<ENTERO>

Nivel de depuración.

-? --ayuda

Muestra texto básico de ayuda.

--uso

Muestra texto básico de uso.

EJEMPLOS

Para imprimir la página INQUIRY estándar:

	iscsi-inq iscsi://192.0.2.1/iqn.ronnie.test/1

Para listar las páginas disponibles:

	iscsi-inq -e 1 iscsi://192.0.2.1/iqn.ronnie.test/1

Para mostrar una página específica:

	iscsi-inq -e 1 -c 0x80 iscsi://192.0.2.1/iqn.ronnie.test/1
