ISCSI-MD5SUM(1) iscsi-md5sum: calcular MD5 ISCSI-MD5SUM(1)

NOMBRE

iscsi-md5sum - Utilidad para calcular el valor MD5 de un LUN iSCSI en el rango [LBAm, LBAn)

SINOPSIS

iscsi-md5sum [ OPCIONES ] <ISCSI-PORTAL>

iscsi-md5sum [-i --initiator-name=<IQN>] [-o --offset] [-l --length] [-d --debug] [-? --help] [--usage]

DESCRIPCIÓN

iscsi-md5sum es una utilidad para calcular el valor MD5 de un LUN iSCSI en el rango [LBAm, LBAn).

FORMATO URL DEL PORTAL iSCSI

El formato del portal iSCSI es 'iscsi://[<usuario>[%<contraseña>]@]<host>[:<puerto>]'

El nombre de usuario y la contraseña solo son necesarios si el destino requiere autenticación CHAP. Opcionalmente, puede especificar el nombre de usuario y la contraseña a través de las variables de entorno LIBISCSI_CHAP_USERNAME y LIBISCSI_CHAP_PASSWORD.

El host puede especificarse como un nombre de host, una dirección IPv4 o una dirección IPv6. Ejemplos:

	iscsi://192.0.2.1
	iscsi://[2001:DB8::1]:3261
	iscsi://ronnie%password@iscsi.example.com

El puerto es el puerto TCP en el destino al que conectarse. El valor predeterminado es 3260.

OPCIONES

-i --initiator-name=<IQN>

Esto especifica el nombre del iniciador que iscsi-md5sum utilizará al iniciar sesión en el destino.

El nombre predeterminado es 'iqn.2007-10.com.github:sahlberg:libiscsi:iscsi-md5sum', pero puede usar este argumento para anularlo. Esto es principalmente necesario para casos en los que el destino está configurado con control de acceso para permitir solo sesiones de descubrimiento de nombres de iniciador conocidos.

-o --offset

Desplazamiento en bytes en el destino desde el cual comenzar a calcular. El valor proporcionado debe estar alineado con el tamaño del sector del destino. El valor predeterminado es cero.

-l --length

El número de bytes a calcular (contando desde el punto de inicio). El valor proporcionado debe estar alineado con el tamaño del sector del destino. Si el valor especificado se extiende más allá del final del dispositivo, iscsi-md5sum se detendrá en el límite del tamaño del dispositivo. El valor predeterminado se extiende hasta el final del dispositivo.

-d --debug

Imprimir información de depuración.

-? --help

Mostrar texto de ayuda básico.

--usage

Mostrar texto de uso básico.
