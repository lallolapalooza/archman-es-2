ISWDIGIT(3P) Manual de Programador POSIX ISWDIGIT(3P)

PROLOG

Esta página del manual forma parte del Manual de Programador POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual de Linux correspondiente para conocer los detalles del comportamiento en Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

iswdigit, iswdigit_l — comprobar si un código de carácter ancho es un dígito decimal

SINOPSIS

#include <wctype.h>
int iswdigit(wint_t wc);
int iswdigit_l(wint_t wc, locale_t locale);

DESCRIPCIÓN

Para iswdigit(): la funcionalidad descrita en esta página de referencia se alinea con el estándar ISO C. Cualquier conflicto entre los requisitos descritos aquí y el estándar ISO C es no intencional. Este volumen de POSIX.1‐2017 remite al ISO C estándar.

Las funciones iswdigit() y iswdigit_l() comprobarán si wc es un código de carácter ancho que representa un carácter de la clase digit (dígito) en la configuración regional actual, o en la configuración regional representada por locale, respectivamente; consulte el volumen de Definiciones Base de POSIX.1‐2017, Capítulo 7, Configuración Regional.

El argumento wc es un wint_t, cuyo valor la aplicación deberá asegurarse que es un código de carácter ancho que corresponde a un carácter válido en la configuración regional utilizada por la función, o igual al valor de la macro WEOF. Si el argumento tiene algún otro valor, el comportamiento es indefinido.

El comportamiento es indefinido si el argumento locale a iswdigit_l() es el objeto de configuración regional especial LC_GLOBAL_LOCALE o no es un manejador de objeto de configuración regional válido.

VALOR DE RETORNO

Las funciones iswdigit() y iswdigit_l() devolverán un valor distinto de cero si wc es un código de carácter ancho de dígito decimal; de lo contrario, devolverán 0.
