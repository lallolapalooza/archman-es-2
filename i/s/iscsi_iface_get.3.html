NOMBRE

iscsi_iface_get - Recupera la interfaz iSCSI especificada.

SINOPSIS

int iscsi_iface_get (struct iscsi_context *ctx, const char *iface_name, struct iscsi_iface **iface);

ARGUMENTOS

ctx
Puntero a 'struct iscsi_context'. Si este puntero es NULL, su programa será terminado por assert.
iface_name
Cadena. Nombre de la interfaz iSCSI. También el nombre del archivo de configuración "/etc/iscsi/iface/<iface_name>". Si este puntero es NULL o una cadena vacía, su programa será terminado por assert.
iface
Puntero de salida a 'struct iscsi_iface'. Su memoria debe liberarse con iscsi_iface_free. Si este puntero es NULL, su programa será terminado por assert.

DESCRIPCIÓN

Recupera la interfaz iSCSI especificada leyendo la configuración de "/etc/iscsi/iface/<iface_name>". Para generar la configuración de la interfaz iSCSI cuando se instala una nueva tarjeta, utilice iscsi_default_iface_setup. Un archivo de configuración ilegal será tratado como error LIBISCSI_ERR_IDBM. La ausencia del archivo de configuración se tratará como error LIBISCSI_ERR_INVAL.

RETORNO

int. Los códigos de error válidos son:

* LIBISCSI_OK

* LIBISCSI_ERR_BUG

* LIBISCSI_ERR_NOMEM

* LIBISCSI_ERR_ACCESS

* LIBISCSI_ERR_SYSFS_LOOKUP

* LIBISCSI_ERR_IDBM

El número de error se puede convertir en cadena mediante iscsi_strerror.
