NOMBRE

iscsid - Demonio de Open-iSCSI

SINOPSIS

iscsid [OPCIÓN]

DESCRIPCIÓN

El iscsid implementa la ruta de control del protocolo iSCSI, además de algunas facilidades de gestión. Por ejemplo, el demonio puede ser configurado para reiniciar automáticamente el descubrimiento al inicio, basado en el contenido de la base de datos iSCSI persistente.

OPCIONES

[-c|--config=]archivo-config
Lee la configuración del archivo-config en lugar del archivo predeterminado /etc/iscsi/iscsid.conf.
[-i|--initiatorname=]archivo-iname
Lee el nombre del iniciador del archivo-iname en lugar del archivo predeterminado /etc/iscsi/initiatorname.iscsi.
[-f|--foreground]
ejecuta iscsid en primer plano. Implica --no-pid-file.
[-d|--debug=]nivel-debug
muestra información de depuración. Los valores válidos para nivel-debug son de 0 a 8.
[-u|--uid=]uid
ejecuta bajo el ID de usuario uid (el predeterminado es el ID de usuario actual).
[-g|--gid=]gid
ejecuta bajo el ID de grupo de usuario gid (el predeterminado es el ID de grupo de usuario actual).
[-n|--no-pid-file]
no escribe un archivo de ID de proceso. Entra en conflicto con la opción --pid=.
[-p|--pid=]archivo-pid
escribe el ID de proceso en archivo-pid en lugar del predeterminado /run/iscsid.pid. Entra en conflicto con la opción --no-pid-file.
[-h|--help]
muestra esta ayuda y sale
[-v|--version]
muestra la versión y sale.

ARCHIVOS

/etc/iscsi/iscsid.conf
El archivo de configuración leído por iscsid y iscsiadm al inicio.
/etc/iscsi/initiatorname.iscsi
El archivo que contiene el nombre del iniciador iSCSI y el alias del iniciador leídos por iscsid y iscsiadm al inicio.
/var/lib/iscsi/nodes
Base de datos de configuración persistente de Open-iSCSI
