ISWSPACE(3P) Manual del programador POSIX ISWSPACE(3P)

PRÓLOGO

Esta página del manual forma parte del Manual del Programador POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual de Linux correspondiente para obtener detalles del comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

iswspace, iswspace_l — comprobar si un código de carácter ancho es un espacio en blanco

SINOPSIS

#include <wctype.h>
int iswspace(wint_t wc);
int iswspace_l(wint_t wc, locale_t locale);

DESCRIPCIÓN

Para iswspace(): La funcionalidad descrita en esta página de referencia está alineada con el estándar ISO C. Cualquier conflicto entre los requisitos descritos aquí y el estándar ISO C es no intencional. Este volumen de POSIX.1‐2017 remite al estándar ISO C.

Las funciones iswspace() y iswspace_l() comprobarán si wc es un código de carácter ancho que representa un carácter de la clase space en la configuración regional actual, o en la configuración regional representada por locale, respectivamente; consulte el volumen de Definiciones Base de POSIX.1‐2017, Capítulo 7, Configuración regional.

El argumento wc es un wint_t, cuyo valor la aplicación deberá asegurarse de que sea un código de carácter ancho correspondiente a un carácter válido en la configuración regional utilizada por la función, o igual al valor de la macro WEOF. Si el argumento tiene algún otro valor, el comportamiento es indefinido.

El comportamiento es indefinido si el argumento locale a iswspace_l() es el objeto especial de configuración regional LC_GLOBAL_LOCALE o no es un manejador de objeto de configuración regional válido.

VALOR DE RETORNO

Las funciones iswspace() y iswspace_l() devolverán un valor distinto de cero si wc es un código de carácter ancho de espacio en blanco; de lo contrario, devolverán 0.
