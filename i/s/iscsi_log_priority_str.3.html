iscsi_log_priority_str(3) Manual de la API iscsi_log_priority_str(3)

NOMBRE

iscsi_log_priority_str - Convierte la prioridad del registro a cadena.

SINOPSIS

const char * iscsi_log_priority_str (int prioridad);

ARGUMENTOS

prioridad
int. Prioridad del registro.

DESCRIPCIÓN

Convierte la prioridad del registro a cadena (const char *).

RETORNO

const char *. Por favor, no libere el puntero devuelto. Las cadenas válidas son:

* "ERROR" para LIBISCSI_LOG_PRIORITY_ERROR

* "WARN" para LIBISCSI_LOG_PRIORITY_WARNING

* "INFO" para LIBISCSI_LOG_PRIORITY_INFO

* "DEBUG" para LIBISCSI_LOG_PRIORITY_DEBUG

* "Invalid argument" para una prioridad de registro inválida.
