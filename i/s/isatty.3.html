isatty(3) Manual de funciones de biblioteca isatty(3)

NOMBRE

isatty - comprobar si un descriptor de archivo se refiere a una terminal

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <unistd.h>
int isatty(int fd);

DESCRIPCIÓN

La función isatty() comprueba si fd es un descriptor de archivo abierto que se refiere a una terminal.

VALOR DE RETORNO

isatty() devuelve 1 si fd es un descriptor de archivo abierto que se refiere a una terminal; de lo contrario, devuelve 0 y establece errno para indicar el error.

ERRORES

EBADF
fd no es un descriptor de archivo válido.
ENOTTY
fd se refiere a un archivo distinto de una terminal. En algunos kernels más antiguos, algunos tipos de archivos provocaban el error EINVAL en este caso (lo cual es una violación de POSIX, que especifica el error ENOTTY).
