isympy es un shell de Python para SymPy. Es simplemente un shell de python normal (un shell de ipython si tienes el paquete ipython instalado) que ejecuta los siguientes comandos para que no tengas que hacerlo tú:
>>> from __future__ import division >>> from sympy import * >>> x, y, z = symbols("x,y,z") >>> k, m, n = symbols("k,m,n", integer=True)Así que iniciar isympy es equivalente a iniciar python (o ipython) y ejecutar los comandos anteriores a mano. Está destinado a la experimentación fácil y rápida con SymPy. Para programas más complicados, se recomienda escribir un script e importar las cosas explícitamente (usando la idiomática "from sympy import sin, log, Symbol, ..."). OPCIONES-c SHELL

Configura los tipos base para los polinomios. Por defecto, se usan los tipos base de gmpy si gmpy2 o gmpy está instalado, de lo contrario se recurre a los tipos base de python, que son un poco más lentos. Puedes elegir manualmente los tipos base de python incluso si gmpy está instalado (por ejemplo, para propósitos de prueba). Ten en cuenta que los tipos base de sympy no están soportados, y deben usarse solo con fines experimentales. Ten en cuenta que el tipo base de gmpy1 está destinado principalmente a pruebas; fuerza el uso de gmpy incluso si gmpy2 está disponible. Esto es lo mismo que configurar la variable de entorno SYMPY_GROUND_TYPES al tipo base dado (por ejemplo, SYMPY_GROUND_TYPES='gmpy')Los tipos base pueden determinarse interactivamente desde la variable sympy.

--order=

ORDEN

Configura el orden de los términos para la impresión. El valor predeterminado es lex, que ordena los términos lexicográficamente (por ejemplo, x**2 + x + 1). Puedes elegir otros órdenes, como rev-lex, que usará un orden lexicográfico inverso

(por ejemplo,
1 + x + x**2).
Ten en cuenta que para expresiones muy grandes, ORDEN='none' puede acelerar considerablemente la impresión, a cambio de que el orden de los términos en la expresión impresa no tendrá un orden canónico. Ejemplo: isympy -o rev-lax ORDENdebe ser uno de 'lex', 'rev-lex', 'grlex', 'rev-grlex',
'grevlex', 'rev-grevlex', 'old' o 'none'.

Crea automáticamente los símbolos que faltan. Normalmente, escribir el nombre de un Symbol que no ha sido instanciado primero generaría un NameError, pero con esta opción habilitada, cualquier nombre no definido será creado automáticamente como un Symbol. Esto solo funciona en IPython 0.11. Ten en cuenta que esto está destinado solo para uso interactivo, estilo calculadora. En un script que usa SymPy, los Symbols deberían
instanciarse en la parte superior, para que quede claro qué son.
Esto no sobrescribirá ningún nombre que ya esté definido, lo que incluye las letras de un solo carácter representadas por el mnemónico QCOSINE (ver el documento "Gotchas and Pitfalls" en la documentación). Puedes eliminar nombres existentes ejecutando "del name" en el propio shell. Puedes ver si un nombre está definido escribiendo "'name' in globals()".

Los Symbols que se crean usando esto tienen suposiciones por defecto. Si quieres colocar suposiciones en los símbolos, deberías crearlos usando symbols() o

var().

Finalmente, esto solo funciona en el espacio de nombres de nivel superior. Así que, por ejemplo, si defines una función en isympy con un Symbol no definido, no

funcionará.
