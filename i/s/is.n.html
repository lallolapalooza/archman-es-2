is(n)

Paquete: tcl

Licencias: TCL

is(n) [incr Tcl] is(n)

NOMBRE

itcl::is - probar un argumento para ver si es una clase o un objeto

SINOPSIS

itcl::is opción ?arg arg ...?

DESCRIPCIÓN

El comando is se usa para verificar si el argumento dado es una clase o un objeto; dependiendo de la opción dada. Si el argumento es una clase u objeto, se devuelve 1. De lo contrario, se devuelve 0. El comando is también reconoce los comandos envueltos en el comando code de itcl.

El argumento opción determina qué acción se lleva a cabo por el comando. Las opciones legales (que pueden abreviarse) son:

is clase comando
Devuelve 1 si el comando es una clase y devuelve 0 en caso contrario.

Se debe proporcionar el nombre completo de la clase como argumento comando. Por lo tanto, si una clase reside en un espacio de nombres, se debe especificar también el espacio de nombres. Así, si una clase C reside en un espacio de nombres N, el comando debe llamarse así:

is N::C
    o
is ::N::C
is objeto ?-clase nombreClase? comando
Devuelve 1 si comando es un objeto y devuelve 0 en caso contrario.

Si se especifica el parámetro opcional "-clase", entonces el comando se verificará en el contexto de la clase dada. Tenga en cuenta que nombreClase debe existir. Si no es así, se producirá un error. Por lo tanto, si no se está seguro de que nombreClase sea una clase, el programador deberá verificar su existencia de antemano o envolverla en una sentencia `catch`.

Entonces, si c es un objeto de la clase C, en el espacio de nombres N, estas son las posibilidades (todas devuelven 1):

set obj [N::C c]
itcl::is objeto N::c
itcl::is objeto c
itcl::is objeto $obj
itcl::is objeto [itcl::code c]
