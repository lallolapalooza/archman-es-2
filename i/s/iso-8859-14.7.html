NAME

iso-8859-14 - ISO/IEC 8859-14:1998, Latin-8 character set

DESCRIPTION

ISO/IEC 8859-14 is an 8-bit character set that defines codes for the characters needed for the Celtic languages: Breton, Irish, Scottish Gaelic, Welsh, and Manx.

It includes the characters needed for Basque, Estonian, Finnish, German, Icelandic, Irish, Italian, Latvian, Maltese, Norwegian, Portuguese, Sami, Spanish, Swedish, and Welsh.

The character set is a superset of ISO-8859-1 (Latin-1). It defines characters in the range 0xA0-0xFF.
