NOMBRE

iscsi_context_new - Crear struct iscsi_context.

SINOPSIS

struct iscsi_context * iscsi_context_new (void);

ARGUMENTOS

void
sin argumentos

DESCRIPCION

El nivel de registro predeterminado (LIBISCSI_LOG_PRIORITY_DEFAULT) es LIBISCSI_LOG_PRIORITY_WARNING, lo que significa que solo los mensajes de advertencia y error se enviarán a la función controladora de registros. La función controladora de registros predeterminada imprimirá el mensaje de registro en STDERR. Para cambiarlo, utilice iscsi_context_log_func_set para establecer su propia función controladora de registros; consulte la página del manual libopeniscsiusr.h(3) para obtener más detalles.

DEVOLUCIÓN

Puntero a 'struct iscsi_context'. Debe liberarse mediante iscsi_context_free.
