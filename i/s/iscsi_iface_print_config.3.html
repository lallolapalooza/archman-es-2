NOMBRE

iscsi_iface_print_config - Imprime todas las configuraciones de la interfaz iSCSI especificada en STDOUT.

SINOPSIS

void iscsi_iface_print_config (struct iscsi_iface *iface);

ARGUMENTOS

iface
Puntero de 'struct iscsi_iface'. Si este puntero es NULL, tu programa será terminado por assert.

DESCRIPCION

Imprime todas las configuraciones de la interfaz iSCSI especificada. Para una configuración vacía, se mostrará como "nombre = <vacío>".

RETORNO

void
