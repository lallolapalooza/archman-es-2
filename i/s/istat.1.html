ISTAT(1) Manual de Comandos Generales ISTAT(1)

NOMBRE

istat - Muestra detalles de una estructura de metadatos (es decir, inodo)

SINOPSIS

istat [-B num ] [-f tiposistemaficheros ] [-i tipoimagen] [-o desplazamientoimagen] [-b tamañosectordispositivo] [-vV] [-z zona ] [-s segundos ] imagen [imágenes] inodo

DESCRIPCIÓN

istat muestra el uid, gid, modo, tamaño, número de enlaces, tiempos de modificación, acceso y cambio, y todas las unidades de disco que una estructura tiene asignadas.

Las opciones son las siguientes:

-B num
Muestra las direcciones de num unidades de disco. Útil cuando el inodo no está asignado con tamaño 0, pero todavía tiene punteros de bloque.
-f tiposistemaficheros
Especifica el tipo de sistema de ficheros. Usa '-f list' para listar los tipos de sistemas de ficheros soportados. Si no se proporciona, se usan métodos de autodetección.
-s segundos
El desfase horario del sistema original en segundos. Por ejemplo, si el sistema original tenía un retraso de 100 segundos, este valor sería -100.
-i tipoimagen
Identifica el tipo de archivo de imagen, como raw. Usa '-i list' para listar los tipos soportados. Si no se proporciona, se usan métodos de autodetección.
-o desplazamientoimagen
El desplazamiento de sector donde comienza el sistema de ficheros en la imagen.
-b tamañosectordispositivo
El tamaño, en bytes, de los sectores del dispositivo subyacente. Si no se proporciona, se usa el valor en el formato de imagen (si existe) o se asumen 512 bytes.
-v
Salida detallada de declaraciones de depuración a stderr
-V
Muestra la versión
-z zona
Una cadena ASCII de la zona horaria del sistema original. Por ejemplo, EST5EDT o GMT. Estas cadenas son definidas por el sistema operativo y pueden variar. NOTA: Esto ha cambiado desde TCTUTILs.
imagen [imágenes]
La imagen del disco o partición a leer, cuyo formato se indica con '-i'. Se pueden dar varios nombres de archivo de imagen si la imagen está dividida en varios segmentos. Si solo se da un archivo de imagen y su nombre es el primero de una secuencia (por ejemplo, si termina en '.001'), los segmentos de imagen subsiguientes se incluirán automáticamente.
inodo
Número de metadatos para mostrar estadísticas
