NOMBRE

iscsi_is_default_iface - Determina si la interfaz iSCSI especificada es la interfaz predeterminada.

SINOPSIS

bool iscsi_is_default_iface (struct iscsi_iface *iface);

ARGUMENTOS

iface
Puntero a 'struct iscsi_iface'.

DESCRIPCIÓN

Comprueba si la interfaz iSCSI especificada es una de las interfaces predeterminadas. Actualmente, las interfaces predeterminadas son:

* Interfaz 'default' que utiliza el módulo del kernel 'iscsi_tcp'.

* Interfaz 'iser' que utiliza el módulo del kernel 'ib_iser'.

RETORNO

bool.
