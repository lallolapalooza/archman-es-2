DESCRIPCIÓ

N

Estas funciones comprueban si c, que debe tener el valor de un unsigned char o EOF, cae dentro de cierta clase de carácter de acuerdo con la configuración regional (locale) especificada. Las funciones sin el sufijo "_l" realizan la comprobación basándose en la configuración regional

actual.

Las funciones con el sufijo "_l" realizan la comprobación basándose en la configuración regional especificada por el objeto de configuración regional locale. El comportamiento de estas funciones es indefinido si locale es el objeto de configuración regional especial LC_GLOBAL_LOCALE (véase duplocale(3)) o no es un identificador de objeto de configuración regional

válido.

La lista siguiente explica el funcionamiento de las funciones sin el sufijo "_l"; las funciones con el sufijo "_l" difieren solo en usar el objeto de configuración regional locale en lugar de la configuración regional

actual.

ADVERTENCI

AS

Los estándares requieren que el argumento c para estas funciones sea o bien EOF o un valor que sea representable en el tipo unsigned char; de lo contrario, el comportamiento es indefinido. Si el argumento c es de tipo char, debe convertirse a unsigned char, como en el siguiente

ejemplo: 


char c;
...
res = toupper((unsigned char) c)
;

Esto es necesario porque char puede ser equivalente a signed char, en cuyo caso un byte con el bit más significativo estable se extendería con signo al convertirlo a int, produciendo un valor que está fuera del rango de unsigned

char.

Los detalles de qué caracteres pertenecen a qué clase dependen de la configuración regional (locale). Por ejemplo, isupper() no reconocerá una A con diéresis (Ä) como una letra mayúscula en la configuración regional C predet

ermin
ada.
