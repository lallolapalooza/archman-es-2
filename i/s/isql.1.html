DSN El Nombre de Fuente de Datos (DSN) utilizado para conectarse a la base de datos SQL. unixODBC busca el DSN especificado en /etc/odbc.ini y $HOME/.odbc.ini, teniendo prioridad el último. Al buscar en los archivos de configuración, unixODBC busca un nombre simple. Si el DSN comienza con un punto y coma, se trata como una cadena de conexión. ARCHIVOS

/etc/odbc.ini

Archivo de configuración que contiene definiciones de nombres de origen de datos (DSN) a nivel de sistema. Consulte odbc.ini(5) para obtener más información.

$HOME/.odbc.ini

Archivo de configuración que contiene definiciones de nombres de origen de datos (DSN) específicas del usuario. Consulte odbc.ini(5) para obtener más información.
