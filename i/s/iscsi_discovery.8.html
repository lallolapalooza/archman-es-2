NOMBRE

iscsi_discovery - descubrir objetivos iSCSI

SINOPSIS

iscsi_discovery <IP> [-p <puerto>] [-d] [ -t <tcp|iser> [-f] ] [-m] [-l]

DESCRIPCIÓN

Realiza el descubrimiento de envío de objetivos a la IP especificada. Si se genera un registro de descubrimiento, intenta iniciar sesión en el portal utilizando el transporte preferido (la opción -t especifica el tipo de transporte solicitado, TCP es el predeterminado). Si el inicio de sesión con un determinado transporte tiene éxito, marca el portal para el inicio de sesión automático (a menos que se use la opción -m) y se desconecta (a menos que se use la opción -l).

Para que el descubrimiento iSCSI funcione, los servicios open-iscsi deben estar en ejecución. es decir, iscsid debe estar activo y los módulos iSCSI cargados. Esto se logra mejor mediante el script de inicio init.d.

[-p=]número-de-puerto
establece el número de puerto (el predeterminado es 3260).
[-d]
imprime información de depuración.
[-t=]tipo-de-transporte
establece el transporte (el predeterminado es tcp).
[-f]
fuerza un transporte específico: deshabilita la opción de respaldo a tcp (el predeterminado es respaldo habilitado). fuerza el transporte especificado por el argumento de la opción -t.
[-m]
inicio manual: establecerá el inicio manual (el predeterminado es inicio automático).
[-l]
inicio de sesión: inicia sesión en los nuevos nodos descubiertos (el predeterminado es falso).
