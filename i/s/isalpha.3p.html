ISALPHA(3P) Manual del programador POSIX ISALPHA(3P)

PROLOG

Esta página del manual es parte del Manual del programador POSIX. La implementación de Linux de esta interfaz puede diferir (consulte la página del manual de Linux correspondiente para conocer los detalles del comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

isalpha, isalpha_l — probar si es un carácter alfabético

SINOPSIS

#include <ctype.h>
int isalpha(int c);
int isalpha_l(int c, locale_t locale);

DESCRIPCIÓN

Para isalpha(): la funcionalidad descrita en esta página de referencia está alineada con el estándar ISO C. Cualquier conflicto entre los requisitos descritos aquí y el estándar ISO C no es intencional. Este volumen de POSIX.1-2017 remite al estándar ISO C.

Las funciones isalpha() y isalpha_l() probarán si c es un carácter de la clase alpha en la configuración regional actual, o en la configuración regional representada por locale, respectivamente; consulte el volumen de Definiciones base de POSIX.1-2017, Capítulo 7, Configuración regional.

El argumento c es un int, cuyo valor la aplicación deberá asegurarse de que sea representable como un unsigned char o igual al valor de la macro EOF. Si el argumento tiene cualquier otro valor, el comportamiento no está definido.

El comportamiento no está definido si el argumento locale para isalpha_l() es el objeto de configuración regional especial LC_GLOBAL_LOCALE o no es un manejador de objeto de configuración regional válido.

VALOR DE RETORNO

Las funciones isalpha() y isalpha_l() devolverán un valor distinto de cero si c es un carácter alfabético; de lo contrario, devolverán 0.
