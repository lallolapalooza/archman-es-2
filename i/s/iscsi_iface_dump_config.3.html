NOMBRE

iscsi_iface_dump_config - Volcar todas las configuraciones de la interfaz iSCSI especificada.

SINOPSIS

const char * iscsi_iface_dump_config (struct iscsi_iface *iface);

ARGUMENTOS

iface
Puntero de 'struct iscsi_iface'. Si este puntero es NULL, tu programa será terminado por assert.

DESCRIPCIÓN

Vuelca todas las configuraciones de la interfaz iSCSI especificada. Omitirá las configuraciones vacías para que la cadena de salida pueda ser guardada directamente en el archivo /etc/iscsi/ifaces/<nombre_interfaz>.

RETORNO

const char *. Se debe liberar esta memoria usando free.
