ISOSIZE(8) Administración del Sistema ISOSIZE(8)

NOMBRE

isosize - mostrar la longitud de un sistema de archivos iso9660

SINOPSIS

isosize [opciones] archivo_de_imagen_iso9660

DESCRIPCIÓN

Este comando muestra la longitud de un sistema de archivos iso9660 que está contenido en el archivo especificado. Este archivo puede ser un archivo normal o un dispositivo de bloques (por ejemplo, /dev/hdd o /dev/sr0). En ausencia de cualquier opción (y errores), mostrará el tamaño del sistema de archivos iso9660 en bytes. Este puede ser ahora un número grande (>> 4 GB).

OPCIONES

-x, --sectores

Mostrar el recuento de bloques y el tamaño de bloque en un formato legible por humanos. La salida utiliza el término "sectores" para "bloques".

-d, --divisor número

Solo tiene efecto cuando -x no se proporciona. El valor mostrado (si no hay errores) es el tamaño del archivo iso9660 en bytes dividido por número. Por lo tanto, si número es el tamaño del bloque, el valor mostrado será el recuento de bloques.

El tamaño del archivo (o dispositivo de bloques) que contiene un sistema de archivos iso9660 puede ser marginalmente mayor que el tamaño real del sistema de archivos iso9660. Una razón para esto es que los grabadores de CD tienen permitido agregar sectores de "agotamiento" al final de una imagen iso9660.

-h, --ayuda

Mostrar texto de ayuda y salir.

-V, --versión

Mostrar la versión y salir.

ESTADO DE SALIDA

0

éxito

1

fallo genérico, como uso inválido

32

todos fallaron

64

algunos fallaron
