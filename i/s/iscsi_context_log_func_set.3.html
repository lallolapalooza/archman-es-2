NOMBRE

iscsi_context_log_func_set - Establece la función de manejo de registros.

SINOPSIS

void iscsi_context_log_func_set (struct iscsi_context *ctx, void (*log_func) (struct iscsi_context *ctx, int priority, const char *file, int line, const char *func_name, const char *format, va_list args));

ARGUMENTOS

ctx
Puntero de 'struct iscsi_context'. Si este puntero es NULL, su programa será terminado por assert.
log_func
Puntero de la función de manejo de registros.

DESCRIPCIÓN

Establece un manejador de registros personalizado. El manejador de registros será invocado cuando el mensaje de registro sea igual o más importante (menor valor) que la configuración de prioridad de registro. Por favor, consulte la página del manual libopeniscsiusr.h(3) para más detalles sobre el uso.

RETORNO

void
