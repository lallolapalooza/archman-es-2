NOMBRE

iscsi_sessions_get - Recupera todas las sesiones iSCSI.

SINOPSIS

int iscsi_sessions_get (struct iscsi_context *ctx, struct iscsi_session ***ses, uint32_t *se_count);

ARGUMENTOS

ctx
Puntero de 'struct iscsi_context'. Si este puntero es NULL, su programa será terminado por assert.
ses
Puntero de salida del array de punteros 'struct iscsi_session'. Su memoria debe ser liberada por iscsi_sessions_free. Si este puntero es NULL, su programa será terminado por assert.
se_count
Puntero de salida de uint32_t. Almacenará el tamaño de

DESCRIPCIÓN

Recupera todas las sesiones iSCSI. Para las propiedades de 'struct iscsi_session', consulte las funciones definidas en el archivo 'libopeniscsiusr_session.h'.

RETORNO

int. Los códigos de error válidos son:

* LIBISCSI_OK

* LIBISCSI_ERR_BUG

* LIBISCSI_ERR_NOMEM

* LIBISCSI_ERR_ACCESS

* LIBISCSI_ERR_SYSFS_LOOKUP

El número de error puede ser convertido a cadena mediante iscsi_strerror.
