iio_stresstest(1) Utilidades de LibIIO iio_stresstest(1)

NOMBRE

iio_stresstest - Programa de prueba de estrés para Libiio

SINOPSIS

iio_stresstest [ opciones ] -u <uri>

DESCRIPCIÓN

iio_stresstest es un programa de prueba de estrés que puede ser utilizado para encontrar errores en Libiio o en el demonio de Libiio (IIOD).

OPCIONES

-h, --help
Indica a iio_stresstest que muestre una ayuda y luego salga.
-V, --version
Imprime la información de la versión de esta copia particular de iio_stresstest y la versión de la biblioteca libiio que está usando. Esto es útil para saber si la versión de la biblioteca y iio_stresstest en su sistema están actualizadas. También es útil al reportar errores.
-S, --scan [backends]
Escanea los contextos IIO disponibles, argumento opcional de backend(s) específico(s) 'ip', 'usb' o 'ip:usb'. Opciones específicas para USB incluyen ID del Vendedor, ID del Producto para limitar el escaneo a dispositivos específicos 'usb=0456,b673'. vid,pid son números hexadecimales (no se necesita prefijo), "*" (coincide con cualquiera solo para pid). Si no se proporciona ningún argumento, comprueba todos los disponibles.
-u, --uri
El Identificador Uniforme de Recurso (uri) para conectarse a los dispositivos, puede ser uno de:
ip:[dirección]
dirección de red, ya sea numérica (192.168.0.1) o nombre de host de red
ip:
en blanco, si se compila con soporte zeroconf, encontrará un dispositivo IIO en la red
usb:[dispositivo:puerto:instancia]
normalmente devuelto por iio_stresstest -S
serial:[puerto],[velocidad],[configuración]
que están controlados y deben coincidir con el iiod (o tinyiiod) en el otro extremo del puerto serie.
[puerto]
es algo como '/dev/ttyUSB0' en Linux y 'COM4' en Windows.
[velocidad]
es normalmente una de 110, 300, 600, 1200, 2400, 4800, 9600, 14400, 19200, 38400, 57600, 115200 [predeterminado], 128000 o 256000, pero puede variar según el sistema.
[configuración]
normalmente se configuraría como '8n1', esto es controlado por:
bits_de_datos:
(5, 6, 7, 8 [predeterminado], o 9)
bits_de_paridad:
('n' ninguno [predeterminado], 'o' impar, 'e' par, 'm' marca, o 's' espacio)
bits_de_parada:
(1 [predeterminado, o 2)
control_de_flujo:
('0' ninguno [predeterminado], 'x' Xon Xoff, 'r' RTSCTS, o 'd' DTRDSR)
local:
sin parte de dirección.
-a, --auto
Escanea los contextos disponibles y si solo hay uno, úsalo.
-T, --timeout <arg>
Tiempo de espera del contexto en milisegundos. 0 = sin tiempo de espera (esperar siempre)
-b, --buffer-size <arg>
Tamaño del búfer de captura. El predeterminado es 256.
-s, --samples <arg>
Número de muestras a capturar, 0 = infinito. El predeterminado es 0.
-d, --duration <arg>
Tiempo de espera (en segundos) antes de detener todos los hilos
-t, --threads <arg>
Número de hilos a utilizar
-v, --verbose
Aumenta la verbosidad (-vv y -vvv para más)

VALOR DE RETORNO

Si no se encuentra el dispositivo especificado, se devuelve un código de salida distinto de cero.
