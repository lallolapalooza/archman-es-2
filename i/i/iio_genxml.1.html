NOMBRE

iio_genxml - Genera una representación XML de un contexto Libiio

SINOPSIS

iio_genxml [ opciones ]

DESCRIPCIÓN

iio_genxml es una utilidad para generar una representación XML de un contexto Libiio.

OPCIONES

-h, --help
Indica a iio_genxml que muestre ayuda y luego salga.
-V, --version
Imprime la información de la versión de esta copia particular de iio_genxml y la versión de la biblioteca libiio que está utilizando. Esto es útil para saber si la versión de la biblioteca y iio_genxml en su sistema están actualizadas. También es útil al informar de errores.
-S, --scan [backends]
Busca contextos IIO disponibles, con un argumento opcional de backend(s) específico(s) 'ip', 'usb' o 'ip:usb'. Opciones específicas para USB incluyen ID de proveedor, ID de producto para limitar la búsqueda a dispositivos específicos 'usb=0456,b673'. vid,pid son números hexadecimales (no se necesita prefijo), "*" (coincide con cualquiera solo para pid). Si no se proporciona argumento, comprueba todos los disponibles.
-u, --uri
El Identificador Uniforme de Recurso (uri) para conectarse a dispositivos, puede ser uno de:
ip:[direccion]
dirección de red, ya sea numérica (192.168.0.1) o nombre de host de red
ip:
vacío, si se compila con soporte zeroconf, encontrará un dispositivo IIO en la red
usb:[dispositivo:puerto:instancia]
normalmente devuelto por iio_genxml -S
serial:[puerto],[baud],[ajustes]
que están controlados y deben coincidir con iiod (o tinyiiod) en el otro extremo del puerto serie.
[puerto]
es algo como '/dev/ttyUSB0' en Linux, y 'COM4' en Windows.
[baud]
es normalmente uno de 110, 300, 600, 1200, 2400, 4800, 9600, 14400, 19200, 38400, 57600, 115200 [predeterminado], 128000 o 256000, pero puede variar según el sistema.
[ajustes]
normalmente se configurarían como '8n1' esto está controlado por:
bits_de_datos:
(5, 6, 7, 8 [predeterminado], o 9)
bits_de_paridad:
('n' ninguno [predeterminado], 'o' impar, 'e' par, 'm' marca, o 's' espacio)
bits_de_parada:
(1 [predeterminado, o 2)
control_de_flujo:
('0' ninguno [predeterminado], 'x' Xon Xoff, 'r' RTSCTS, o 'd' DTRDSR)
local:
sin parte de dirección.

VALOR DE RETORNO

Si no se encuentra el dispositivo especificado, se devuelve un código de salida distinto de cero.
