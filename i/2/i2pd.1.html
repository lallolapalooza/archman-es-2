I2PD(1) Manual de comandos generales I2PD(1)

NOMBRE

i2pd - Implementación C++ completa de cliente I2P.

SINOPSIS

i2pd [OPCIÓN1] [OPCIÓN2]...

DESCRIPCIÓN

i2pd es una implementación en C++ del router para la red de anonimización I2P, que ofrece una capa simple que las aplicaciones sensibles a la identidad pueden usar para comunicarse de forma segura. Todos los datos se envuelven con varias capas de encriptación, y la red es tanto distribuida como dinámica, sin partes confiables.

Cualquiera de las opciones de configuración a continuación se puede usar en la variable DAEMON_ARGS en /etc/default/i2pd.

OPCIONES

--help
Muestra las opciones disponibles.
--conf=
Archivo de configuración (predeterminado: ~/.i2pd/i2pd.conf o /var/lib/i2pd/i2pd.conf). Este parámetro será ignorado silenciosamente si el archivo de configuración especificado no existe. Las opciones especificadas en la línea de comandos tienen prioridad sobre las del archivo de configuración.
--tunconf=
Archivo de configuración de túneles (predeterminado: ~/.i2pd/tunnels.conf o /var/lib/i2pd/tunnels.conf)
--pidfile=
Dónde escribir el archivo PID (no se escribe por defecto)
--log=
Destino de los registros: stdout, file, syslog (stdout si no se establece, file en caso contrario, por compatibilidad)
--logfile=
Ruta al archivo de registro (predeterminado: autodetectar)
--loglevel=
Registra mensajes por encima de este nivel (debug, info, warn, error, none)
--logclftime
Registra mensajes con fecha y hora completas con formato CLF (deshabilitado por defecto)
--datadir=
Ruta al almacenamiento de datos de i2pd (RI, claves, perfiles de peers, ...)
--tunnelsdir=
Ruta a los archivos de configuración de túneles (predeterminado: ~/.i2pd/tunnels.d o /var/lib/i2pd/tunnels.d)
--host=
La dirección IP externa.
--port=
El puerto en el que escuchar las conexiones entrantes.
--ifname=
La interfaz de red a la que vincularse.
--ifname4=
La interfaz de red a la que vincularse para conexiones IPv4.
--ifname6=
La interfaz de red a la que vincularse para conexiones IPv6.
--ipv4=
Habilita la comunicación a través de IPv4 (habilitado por defecto).
--ipv6
Habilita la comunicación a través de IPv6 (deshabilitado por defecto).
--ntcp=
Habilita el uso del transporte NTCP (habilitado por defecto).
--ntcpproxy=
Establece la URL del proxy para el transporte NTCP.
--ssu=
Habilita el uso del transporte SSU (habilitado por defecto).
--notransit
El router no aceptará túneles de tránsito al iniciar (deshabilitado por defecto).
--floodfill
El router será floodfill (deshabilitado por defecto).
--bandwidth=
Límite de ancho de banda: entero en KBps o alias de letras: L (32KBps), O (256), P (2048), X (>9000)
--share=
Límite de tráfico de tránsito del ancho de banda máximo en porcentajes. (predeterminado: 100)
--daemon
El router se ejecutará en segundo plano después de iniciarse (deshabilitado por defecto).
--service
El router utilizará carpetas del sistema como /var/lib/i2pd (deshabilitado por defecto).
--family=
Nombre de la familia a la que pertenece el router.

Los interruptores que están habilitados por defecto (como --ssu, --ntcp, etc.) se pueden deshabilitar en el archivo de configuración.
Consulte los parámetros específicos del servicio en el archivo de configuración de ejemplo /usr/share/doc/i2pd/i2pd.conf.gz

ARCHIVOS

/etc/i2pd/i2pd.conf, /etc/i2pd/tunnels.conf, /etc/default/i2pd

Archivos de configuración de i2pd (cuando se ejecuta como un servicio del sistema)

/var/lib/i2pd/

Directorio de perfil de i2pd (cuando se ejecuta como un servicio del sistema, consulte --service arriba)

$HOME/.i2pd/

Directorio de perfil de i2pd (cuando se ejecuta como un usuario normal)
