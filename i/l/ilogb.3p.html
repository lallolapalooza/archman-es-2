DESCRIPCIÓ

N

La funcionalidad descrita en esta página de referencia está alineada con el estándar ISO C. Cualquier conflicto entre los requisitos descritos aquí y el estándar ISO C no es intencional. Este volumen de POSIX.1‐2017 se subordina al estándar ISO

C.

Estas funciones devolverán la parte del exponente de su argumento x. Formalmente, el valor de retorno es la parte entera de logr|x| como un valor entero con signo, para x distinto de cero, donde r es la base de la aritmética de punto flotante de la máquina, que es el valor de FLT_RADIX definido en <float.h>

.

Una aplicación que desee comprobar situaciones de error debe establecer errno a cero y llamar a feclearexcept(FE_ALL_EXCEPT) antes de llamar a estas funciones. Al regresar, si errno no es cero o fetestexcept(FE_INVALID | FE_DIVBYZERO | FE_OVERFLOW

| FE_UNDERFLOW) no es c
ero, ha ocurrido un error.

VALOR DE

RETORNO

Tras una finalización exitosa, estas funciones devolverán la parte del exponente de x como un valor entero con signo. Son equivalentes a llamar a la función logb() correspondiente y convertir el valor devuelto al tipo int

.

Si x es 0, se devolverá el valor FP_ILOGB0. En sistemas conformes con XSI, ocurrirá un error de dominio;
de lo contrario, puede ocurrir un error de

dominio.

Si x es ±Inf, se devolverá el valor {INT_MAX}. En sistemas conformes con XSI, ocurrirá un error de dominio;
de lo contrario, puede ocurrir un error de

dominio.

Si x es un NaN, se devolverá el valor FP_ILOGBNAN. En sistemas conformes con XSI, ocurrirá un error de dominio;
de lo contrario, puede ocurrir un error de

dominio.

Si el valor correcto es mayor que {INT_MAX}, ocurrirá un error de dominio y se devolverá un valor no especificado. En sistemas conformes con XSI, ocurrirá un error de dominio y se devolverá {INT_MAX}

.

Si el valor correcto es menor que {INT_MIN}, ocurrirá un error de

dominio y se devolverá un valor no especificado. En sistemas conforme
s con XSI, ocurrirá un error de dominio y se devolverá {INT_MIN}.

APLICACIONES

En caso de error, las expresiones (math_errhandling & MATH_ERRNO) y (math_errhandling & MATH_ERREXCEPT) son independientes en

tre sí, pero al menos una de el
las debe ser distinta de cero.

JUSTIFICACIÓ

N

Los errores provienen de tomar el valor de punto flotante esperado y convertirlo a int, lo cual es una operación inválida en IEEE Std 754‐1985 (ya que el desbordamiento, el infinito y el NaN no son representables en un tipo int), por lo que debería ser un error de

dominio.

No se conocen implementaciones que se desborden. Para que ocurra un desbordamiento, {INT_MAX} debe ser menor que LDBL_MAX_EXP*log2(FLT_RADIX) o {INT_MIN} debe ser mayor que LDBL_MIN_EXP*log2(FLT_RADIX) si no se soportan subnormales, o {INT_MIN} debe ser mayor que (LDBL_MIN_EXP-LDBL_MANT_DIG)*log2(FLT_RADIX) si se

soportan s
ubnormales.
