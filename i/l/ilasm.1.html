ilasm(1) Manual de Comandos Generales ilasm(1)

NOMBRE

ilasm, ilasm2 - Ensamblador IL de Mono

SINOPSIS

ilasm [opción] [archivos-fuente]

ilasm2 [opción] [archivos-fuente]

DESCRIPCIÓN

ilasm es el ensamblador ILAsm de Mono. Puedes pasar una o más opciones para controlar el compilador y un conjunto de archivos fuente.

Usa ilasm para generar ensamblados 1.0 y usa ilasm2 para ensamblar programas que utilicen las características 2.0 (genéricos).

El ensamblador ILAsm de Mono acepta opciones que comienzan con / o - para la mayoría de las opciones.

El ensamblador ILAsm de Mono genera imágenes (archivos .exe y .dll) que contienen bytecode CIL que puede ser ejecutado por cualquier sistema que implemente una máquina virtual de Common Language Infrastructure.

OPCIONES

/output:<nombre_archivo>
Especifica el nombre del archivo de salida.
/exe
Genera un ejecutable
/dll
Genera una biblioteca
/scan_only
Solo escanea el código IL y muestra los tokens.
/show_tokens
Muestra los tokens a medida que se analizan.
/show_method_def
Muestra información del método cuando se define un método.
/show_method_ref
Muestra información del método cuando se hace referencia a un método.
/key:KEYFILE
Firma con nombre seguro (firma) el ensamblado de salida utilizando el par de claves presente en el archivo de claves de nombre seguro especificado (snk). Se requiere un par de claves completo (es decir, la firma retardada se hace utilizando una directiva .publickey en las fuentes).
/key:@CONTAINER
Firma con nombre seguro (firma) el ensamblado de salida utilizando el par de claves presente en el contenedor especificado.
--about
Muestra información sobre ilasm
--version
Muestra la versión de ilasm
