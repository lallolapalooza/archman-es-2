ILAENV2STAGE

Propósito:

!>
!> ILAENV2STAGE es llamada desde las rutinas de LAPACK para elegir parámetros
!> dependientes del problema para el entorno local. Ver ISPEC para una descripción
!> de los parámetros.
!> Establece parámetros dependientes de la máquina y del problema útiles para
!> *_2STAGE y subrutinas relacionadas.
!>
!> ILAENV2STAGE devuelve un ENTERO
!> si ILAENV2STAGE >= 0: ILAENV2STAGE devuelve el valor del parámetro
!>                       especificado por ISPEC
!> si ILAENV2STAGE < 0:  si ILAENV2STAGE = -k, el k-ésimo argumento tuvo un
!>                       valor ilegal.
!>
!> Esta versión proporciona un conjunto de parámetros que deberían dar un buen
!> rendimiento, pero no óptimo, en muchas de las computadoras actualmente
!> disponibles para los solucionadores de 2 etapas. Se anima a los usuarios a
!> modificar esta subrutina para establecer los parámetros de ajuste para su
!> máquina en particular utilizando la información de opciones y tamaño del
!> problema en los argumentos.
!>
!> Esta rutina no funcionará correctamente si se convierte a minúsculas.
!> Convertirla a mayúsculas está permitido.
!>

Parámetros

ISPEC 
!>          ISPEC es ENTERO
!>          Especifica el parámetro a devolver como valor de
!>          ILAENV2STAGE.
!>          = 1: el tamaño de bloque óptimo nb para la reducción a BAND
!>
!>          = 2: el tamaño de bloque óptimo ib para la rutina de actualización
!>               de vectores singulares de los vectores propios
!>
!>          = 3: La longitud del array que almacena la representación de
!>               Housholder para la segunda etapa
!>               Band a Tridiagonal o Bidiagonal
!>
!>          = 4: El espacio de trabajo necesario para la rutina de entrada.
!>
!>          = 5: Para futuras versiones.
!>

NOMBRE

!>          NOMBRE es CARACTER*(*)
!>          El nombre de la subrutina que llama, en mayúsculas o
!>          minúsculas.
!>

OPTS

!>          OPTS es CARACTER*(*)
!>          Las opciones de caracteres para la subrutina NOMBRE, concatenadas
!>          en una única cadena de caracteres. Por ejemplo, UPLO = 'U',
!>          TRANS = 'T', y DIAG = 'N' para una rutina triangular se
!>          especificarían como OPTS = 'UTN'.
!>

N1

!>          N1 es ENTERO
!>

N2

!>          N2 es ENTERO
!>

N3

!>          N3 es ENTERO
!>

N4

!>          N4 es ENTERO
!>          Dimensiones del problema para la subrutina NOMBRE; puede que no
!>          todas sean necesarias.
!>

Detalles Adicionales:

!>
!>  Las siguientes convenciones se han utilizado al llamar a ILAENV2STAGE
!> desde las rutinas de LAPACK:
!>  1)  OPTS es una concatenación de todas las opciones de caracteres para
!>      la subrutina NOMBRE, en el mismo orden en que aparecen en la
!>      lista de argumentos para NOMBRE, incluso si no se utilizan para determinar
!>      el valor del parámetro especificado por ISPEC.
!>  2)  Las dimensiones del problema N1, N2, N3, N4 se especifican en el orden
!>      en que aparecen en la lista de argumentos para NOMBRE. N1 se usa
!>      primero, N2 segundo, y así sucesivamente, y las dimensiones del problema
!>      no utilizadas se pasan con un valor de -1.
!>  3)  El valor del parámetro devuelto por ILAENV2STAGE se verifica para
!>      su validez en la subrutina que llama.
!>
!>
