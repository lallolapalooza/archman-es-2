integer function ilaenv (integer ispec, character*( * ) name, character*( * ) opts, integer n1, integer n2, integer n3, integer n4)

ILAENV

Propósito:

!>
!> ILAENV es llamada por las rutinas de LAPACK para elegir parámetros dependientes del problema
!> para el entorno local. Véase ISPEC para una descripción de los parámetros.
!>
!> ILAENV devuelve un ENTERO
!> si ILAENV >= 0: ILAENV devuelve el valor del parámetro especificado por ISPEC
!> si ILAENV < 0:  si ILAENV = -k, el k-ésimo argumento tenía un valor ilegal.
!>
!> Esta versión proporciona un conjunto de parámetros que deberían dar un rendimiento bueno,
!> pero no óptimo, en muchas de las computadoras actualmente disponibles.
!> Se anima a los usuarios a modificar esta subrutina para establecer los parámetros de ajuste
!> para su máquina en particular utilizando la información de opciones y tamaño del problema
!> en los argumentos.
!>
!> Esta rutina no funcionará correctamente si se convierte a minúsculas.
!> Convertirla a mayúsculas está permitido.
!>

Parámetros

ISPEC 
!>          ISPEC es ENTERO
!>          Especifica el parámetro que se devolverá como valor de
!>          ILAENV.
!>          = 1: el tamaño de bloque óptimo; si este valor es 1, un algoritmo
!>               no bloqueado dará el mejor rendimiento.
!>          = 2: el tamaño de bloque mínimo para el cual se debe usar la rutina bloqueada;
!>               si el tamaño de bloque utilizable es menor que este valor, se debe usar
!>               una rutina no bloqueada.
!>          = 3: el punto de cruce (en una rutina bloqueada, para N menor que este valor,
!>               se debe usar una rutina no bloqueada)
!>          = 4: el número de desplazamientos, utilizado en las rutinas de valores propios
!>               no simétricos (OBSOLETO)
!>          = 5: el tamaño de columna mínimo para el cual se utilizará el bloqueo;
!>               los bloques rectangulares deben tener una dimensión de al menos k por m,
!>               donde k es dado por ILAENV(2,...) y m por ILAENV(5,...)
!>          = 6: el punto de cruce para la SVD (al reducir una matriz m por n
!>               a forma bidiagonal, si max(m,n)/min(m,n) excede este valor,
!>               se usa primero una factorización QR para reducir la matriz a una forma triangular.)
!>          = 7: el número de procesadores
!>          = 8: el punto de cruce para el método QR multidesplazamiento
!>               para problemas de valores propios no simétricos (OBSOLETO)
!>          = 9: tamaño máximo de los subproblemas en la parte inferior del
!>               árbol de cómputo en el algoritmo de divide y vencerás
!>               (usado por xGELSD y xGESDD)
!>          =10: la aritmética de infinito e NaN de ieee se puede confiar en que no
!>               generará excepciones
!>          =11: la aritmética de infinito se puede confiar en que no generará
!>               excepciones
!>          12 <= ISPEC <= 17:
!>               xHSEQR o subrutinas relacionadas,
!>               ver IPARMQ para una explicación detallada
!>

NAME

!>          NAME es CHARACTER*(*)
!>          El nombre de la subrutina que llama, en mayúsculas o minúsculas.
!>

OPTS

!>          OPTS es CHARACTER*(*)
!>          Las opciones de caracteres para la subrutina NAME, concatenadas
!>          en una sola cadena de caracteres. Por ejemplo, UPLO = 'U',
!>          TRANS = 'T', y DIAG = 'N' para una rutina triangular se especificarían
!>          como OPTS = 'UTN'.
!>

N1

!>          N1 es ENTERO
!>

N2

!>          N2 es ENTERO
!>

N3

!>          N3 es ENTERO
!>

N4

!>          N4 es ENTERO
!>          Dimensiones del problema para la subrutina NAME; puede que no todas
!>          sean necesarias.
!>

Detalles Adicionales:

!>
!>  Las siguientes convenciones se han utilizado al llamar a ILAENV desde
!>  las rutinas de LAPACK:
!>  1)  OPTS es una concatenación de todas las opciones de caracteres de la
!>      subrutina NAME, en el mismo orden en que aparecen en la
!>      lista de argumentos para NAME, incluso si no se utilizan en la determinación
!>      del valor del parámetro especificado por ISPEC.
!>  2)  Las dimensiones del problema N1, N2, N3, N4 se especifican en el orden
!>      en que aparecen en la lista de argumentos para NAME. N1 se utiliza
!>      primero, N2 segundo, y así sucesivamente, y las dimensiones del problema no utilizadas
!>      se pasan con un valor de -1.
!>  3)  El valor del parámetro devuelto por ILAENV se comprueba para determinar su validez en
!>      la subrutina que llama. Por ejemplo, ILAENV se utiliza para obtener
!>      el tamaño de bloque óptimo para STRTRI de la siguiente manera:
!>
!>      NB = ILAENV( 1, 'STRTRI', UPLO // DIAG, N, -1, -1, -1 )
!>      IF( NB.LE.1 ) NB = MAX( 1, N )
!>
