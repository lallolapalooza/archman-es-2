ilmid(1) Manual de Comandos Generales ilmid(1)

NOMBRE

ilmid - Demonio de Interfaz de Gestión Local Integrada

SINOPSIS

ilmid [ -b ] [ -d ] [ -v ] [ -l archivo_log ] [ -x ] [ -q qos ] [ -i ip_local ] [ -u uni ] <interfaz>

PARÁMETROS

-b
Pone el proceso en segundo plano.
-d
Activa la salida de depuración.
-v
Verboso.
-l archivo_log
Establece la ubicación del archivo de registro.
-x
¿Sin enlaces var?
-q qos
Establece los parámetros qos a usar en el VC de ilmi.
-i ip_local
la dirección que debe ser utilizada por el conmutador para la gestión de red.
-u uni
versión uni. Puede ser 3.0, 3.1 o 4.0.

DESCRIPCIÓN

ilmid implementa SNMP en un PVC ATM. Se utiliza para negociar parámetros operativos con un conmutador.
