ilogb(3) Manual de funciones de biblioteca ilogb(3)

NOMBRE

ilogb, ilogbf, ilogbl - obtener el exponente entero de un valor de punto flotante

BIBLIOTECA

Biblioteca matemática (libm, -lm)

SINOPSIS

#include <math.h>
int ilogb(double x);
int ilogbf(float x);
int ilogbl(long double x);
Requisitos de Macro de Prueba de Funciones para glibc (ver feature_test_macros(7)):

ilogb():

    _ISOC99_SOURCE || _POSIX_C_SOURCE >= 200112L
        || _XOPEN_SOURCE >= 500
        || /* Desde glibc 2.19: */ _DEFAULT_SOURCE
        || /* glibc <= 2.19: */ _BSD_SOURCE || _SVID_SOURCE

ilogbf(), ilogbl():

    _ISOC99_SOURCE || _POSIX_C_C_SOURCE >= 200112L
        || /* Desde glibc 2.19: */ _DEFAULT_SOURCE
        || /* glibc <= 2.19: */ _BSD_SOURCE || _SVID_SOURCE

DESCRIPCIÓN

Estas funciones devuelven la parte del exponente de su argumento como un entero con signo. Cuando no ocurre ningún error, estas funciones son equivalentes a las funciones correspondientes de logb(3), convertidas a int.

VALOR DE RETORNO

En caso de éxito, estas funciones devuelven el exponente de x, como un entero con signo.

Si x es cero, se produce un error de dominio y las funciones devuelven FP_ILOGB0.

Si x es un NaN, se produce un error de dominio y las funciones devuelven FP_ILOGBNAN.

Si x es infinito negativo o infinito positivo, se produce un error de dominio y las funciones devuelven INT_MAX.

ERRORES

Consulte math_error(7) para obtener información sobre cómo determinar si se ha producido un error al llamar a estas funciones.

Los siguientes errores pueden ocurrir:

Error de dominio: x es 0 o un NaN
Se genera una excepción de punto flotante no válida (FE_INVALID) y errno se establece en EDOM (pero consulte ERRORES).
Error de dominio: x es un infinito
Se genera una excepción de punto flotante no válida (FE_INVALID) y errno se establece en EDOM (pero consulte ERRORES).

ATRIBUTOS

Para una explicación de los términos utilizados en esta sección, consulte attributes(7).

Interfaz Atributo Valor
ilogb (), ilogbf (), ilogbl () Seguridad de hilos MT-Safe

ESTÁNDARES

C11, POSIX.1-2008.

HISTORIA

C99, POSIX.1-2001.

ERRORES CONOCIDOS

Antes de glibc 2.16, existían los siguientes errores en la implementación de glibc de estas funciones:

•
El caso de error de dominio en el que x es 0 o un NaN no provocaba que errno se estableciera o (en algunas arquitecturas) que se generara una excepción de punto flotante.
•
El caso de error de dominio en el que x es un infinito no provocaba que errno se estableciera o que se generara una excepción de punto flotante.

VER TAMBIÉN

log(3), logb(3), significand(3)
