DESCRIPCIÓ

N

Estas funciones convierten números de red entre el formato de presentación (es decir, imprimible) y el formato de red (es decir, binario)

.

Para ambas funciones, af especifica la familia de direcciones para la conversión; el único valor soportado es AF_INET

.

inet_net_pton(

)

La función inet_net_pton() convierte pres, una cadena terminada en nulo que contiene un número de red de Internet en formato de presentación, a formato de red. El resultado de la conversión, que está en orden de bytes de red, se coloca en el búfer apuntado por netp. (El argumento netp típicamente apunta a una estructura in_addr.) El argumento nsize especifica el número de bytes disponibles en netp

.

En caso de éxito, inet_net_pton() devuelve el número de bits en el campo de número de red del resultado colocado en netp. Para una discusión sobre el formato de presentación de entrada y el valor de retorno, ver

NOTAS.

Nota: el búfer apuntado por netp debe ser puesto a cero antes de llamar a inet_net_pton(), ya que la llamada escribe solo tantos bytes como se requieren para el número de red (o como son explícitamente especificados por pres), lo cual puede ser menos que el número d

e bytes en una dir
ección de red completa.

inet_net_ntop(

)

La función inet_net_ntop() convierte el número de red en el búfer apuntado por netp a formato de presentación; *netp es interpretado como un valor en orden de bytes de red. El argumento bits especifica el número de bits en el número de red en *netp

.

La cadena de presentación terminada en nulo se coloca en el búfer apuntado por pres. El argumento psize especifica el número de bytes disponibles en pres. La cadena de presentación está en formato CIDR: un número decimal

con puntos que representa la direcció
n de red, seguido por una barra,
y el tamaño del número de red en bits.

NOTA

S

Formato de presentación de entrada para

inet_net_pton()

El número de red puede ser especificado ya sea como un valor hexadecimal o en notación decimal con

puntos.

Los valores hexadecimales son indicados por un "0x" inicial o "0X". Los dígitos hexadecimales rellenan los nibbles (medio octetos) del número de red de izquierda a derecha en orden de bytes de

red.

En notación decimal con puntos, se especifican hasta cuatro octetos, como números decimales separados por puntos. Así, cualquiera de las siguientes formas es

aceptada: 


a.b.c.d
a.b.c
a.b
a

Cada parte es un número en el rango de 0 a 255 que rellena un byte del número de red resultante, yendo de izquierda a derecha, en orden de bytes de red (big endian). Donde una parte es omitida, el byte resultante en el número de red es

cero.

Ya sea para el formato hexadecimal o decimal con puntos, el número

de red puede ser seguido opcionalmente por una barra y un número en el r
ango de 0 a 32, que especifica el tamaño del número de red en bits.

Valor de retorno de

inet_net_pton()

El valor de retorno de inet_net_pton() es el número de bits en el campo de número de red. Si la cadena de presentación de entrada termina con una barra y un valor de tamaño explícito, entonces ese tamaño se convierte en el valor de retorno de inet_net_pton(). De lo contrario, el valor de retorno, bits, se infiere como

sigue:
•
Si el byte más significativo del número de red es mayor o igual a 240, entonces bits es
32.
•
De lo contrario, si el byte más significativo del número de red es mayor o igual a 224, entonces bits es
4.
•
De lo contrario, si el byte más significativo del número de red es mayor o igual a 192, entonces bits es
24.
•
De lo contrario, si el byte más significativo del número de red es mayor o igual a 128, entonces bits es
16.
•
De lo contrario, bits
es
8.

Si el valor de bits resultante de los pasos anteriores es mayor o igual a 8, pero el número de octetos especificados en el número de red excede bits/8, entonces bits es establecido a 8 veces el

número de
octetos realment
e especificados.

EJEMPLO

S

El programa a continuación demuestra el uso de inet_net_pton() y inet_net_ntop(). Usa inet_net_pton() para convertir la dirección de red en formato de presentación proporcionada en su primer argumento de línea de comandos a forma binaria, muestra el valor de retorno de inet_net_pton(). Luego usa inet_net_ntop() para convertir la forma binaria de vuelta a formato de presentación, y muestra la cadena

resultante.

Para demostrar que inet_net_pton() puede no escribir en todos los bytes de su argumento netp, el programa permite un segundo argumento opcional de línea de comandos, un número usado para inicializar el búfer antes de llamar a inet_net_pton(). Como su última línea de salida, el programa muestra todos los bytes del búfer devuelto por inet_net_pton() permitiendo al usuario ver qué bytes no han sido tocados por inet_net_pt

on().

Un ejemplo de ejecución, mostrando que inet_net_pton() infiere el número de bits en el número de

red: 


$ ./a.out 193.168;
inet_net_pton() devolvió: 24
inet_net_ntop() produjo:  193.168.0/24
Dirección cruda:
c1a80000

Demuestra que inet_net_pton() no pone a cero los bytes no usados en su búfer de

resultado: 


$ ./a.out 193.168 0xffffffff;
inet_net_pton() devolvió: 24
inet_net_ntop() produjo:  193.168.0/24
Dirección cruda:
c1a800ff

Demuestra queinet_net_pton() ampliará el tamaño inferido del número de red, si el número de bytes proporcionado en la cadena de presentación excede el valor inferido: 


$ ./a.out 193.168.1.128;
inet_net_pton() returned: 32
inet_net_ntop() yielded:  193.168.1.128/32
Raw address:              c1a80180
Especificar explícitamente el tamaño del número de red anula cualquier inferencia sobre su tamaño (pero cualquier byte adicional que se especifique explícitamente todavía será utilizado por inet_net_pton() para poblar el búfer de resultado): 


$ ./a.out 193.168.1.128/24;
inet_net_pton() returned: 24
inet_net_ntop() yielded:  193.168.1/24
Raw address:              c1a80180

Fuente del programa

/* Enlazar con "-lresolv" */
#include <arpa/inet.h>
#include <err.h>
#include <stdio.h>
#include <stdlib.h>
int
main(int argc, char *argv[])
{
    char buf[100];
    struct in_addr addr;
    int bits;
    if (argc < 2) {
        fprintf(stderr,
                "Uso: %s forma-presentacion [valor-inicial-dir]\n",
                argv[0]);
        exit(EXIT_FAILURE);
    }
    /* Si se suministra argv[2] (un valor numérico), utilícelo para inicializar
       el búfer de salida proporcionado a inet_net_pton(), para que podamos ver
       que inet_net_pton() inicializa solo los bytes necesarios
       para el número de red. Si no se suministra argv[2], inicialice
       el búfer a cero (como es práctica recomendada).  */
    addr.s_addr = (argc > 2) ? strtod(argv[2], NULL) : 0;
    /* Convertir el número de red en forma de presentación en argv[1] a binario.  */
    bits = inet_net_pton(AF_INET, argv[1], &addr, sizeof(addr));
    if (bits == -1)
        err(EXIT_FAILURE, "inet_net_ntop");
    printf("inet_net_pton() devolvió: %d\n", bits);
    /* Convertir el formato binario de nuevo a presentación, utilizando 'bits'
       devueltos por inet_net_pton().  */
    if (inet_net_ntop(AF_INET, &addr, bits, buf, sizeof(buf)) == NULL)
        err(EXIT_FAILURE, "inet_net_ntop");
    printf("inet_net_ntop() produjo:  %s\n", buf);
    /* Mostrar 'addr' en forma bruta (en orden de bytes de red), para que podamos
       ver los bytes no mostrados por inet_net_ntop(); algunos de esos bytes
       pueden no haber sido tocados por inet_net_ntop(), y por lo tanto conservarán
       cualquier valor inicial que se haya especificado en argv[2].  */
    printf("Dirección bruta:              %x\n", htonl(addr.s_addr));
    exit(EXIT_SUCCESS);
}
