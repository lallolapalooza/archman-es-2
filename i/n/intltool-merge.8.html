INTLTOOL-MERGE(8) Manual del Administrador del Sistema INTLTOOL-MERGE(8)

NOMBRE

intltool-merge - fusiona cadenas traducidas en varios tipos de archivos

SINOPSIS

intltool-merge [opción]... DIRECTORIO_PO ARCHIVO ARCHIVO_SALIDA

DESCRIPCIÓN

Fusiona cadenas traducidas en archivos po del DIRECTORIO_PO con el archivo de aplicación original ARCHIVO, y genera el archivo ARCHIVO_SALIDA que contiene tanto las cadenas originales como las localizadas.

Si ARCHIVO es un archivo XML, ARCHIVO_SALIDA contendrá nodos XML repetidos, donde cada nodo contiene una de las cadenas localizadas con el atributo "xml:lang".

OPCIONES

Modo de operación

-b
--estilo-ba
Fusiona archivos en estilo bonobo-activation, que se usa para servidores bonobo.
-d
--estilo-desktop
Fusiona archivos en estilo desktop, que es similar al formato de archivo .ini de Windows.
-k
--estilo-claves
Fusiona archivos en estilo claves, que se usa para metadatos.
-o
--estilo-oaf
(OBSOLETO) Igual que -b/--estilo-ba.
-r
--estilo-rfc822deb
Fusiona archivos en estilo RFC 822, que generalmente se usa en archivos de configuración de Debian.
--estilo-citado
Fusiona archivos en estilo de cadena entrecomillada, que simplemente traduce cualquier cadena entre comillas ("").
-x
--estilo-xml
Fusiona archivos en estilo XML estándar, tanto en atributos como en pcdata crudo.

Otras opciones

-u
--utf8
Convierte todas las cadenas a UTF-8 antes de fusionar.
-p
--paso-a-paso
Usa las cadenas tal cual están en los archivos .po sin conversión (MUY poco recomendable con -x).
-c
--cache
(POR DETERMINAR)
-q
--silencioso
Ejecuta en modo silencioso.
-v
--version
Muestra información de la versión.
-h
--ayuda
Muestra el uso y la información básica de ayuda.

ARCHIVOS

po/.intltool-merge-cache
Archivo de caché generado por intltool-merge, que contiene todas las cadenas de todos los archivos po separadas por \01.
