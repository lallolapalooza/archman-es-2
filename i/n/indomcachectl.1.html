INDOMCACHECTL(1) Manual de Comandos Generales INDOMCACHECTL(1)

NOMBRE

indomcachectl - administra archivos de caché de dominio de instancia

SINOPSIS

$PCP_BINADM_DIR/indomcachectl [-w] -l indom

$PCP_BINADM_DIR/indomcachectl [-w] [-m modo] [-g grupo] [-u usuario] indom

DESCRIPCIÓN

indomcachectl ayuda en la administración de los archivos de caché de dominio de instancia que se almacenan en $PCP_VAR_DIR/config/pmda.

El parámetro obligatorio indom utiliza un formato de 2 puntos para especificar los campos de *dominio* y *serie* del número de dominio de instancia. Los valores requeridos se pueden reportar para una métrica particular usando la opción -d de pminfo(1).

La lista de opciones disponibles se puede obtener usando la opción -?/--help, que muestra un mensaje de uso y sale.

Si se especifica la opción -l/--list, el contenido del archivo de caché de dominio de instancia se vuelca en *stdout* y *indomcachectl* sale.

De lo contrario, se creará un archivo de caché de dominio de instancia vacío. La propiedad del usuario del archivo creado se asigna al uid del llamador, pero opcionalmente se puede asignar al uid del *usuario* del archivo passwd(5) si se especifica la opción -u/--user. La propiedad del grupo del archivo creado se asigna al gid del llamador, de lo contrario, el gid predeterminado del usuario *usuario* si se especifica la opción * -u*, de lo contrario, el gid de *group* del archivo group(5) si se especifica la opción -g/--group.

El archivo de caché de dominio de instancia se crea con el modo 0660 por defecto (algunos PMDA usan permisos de lectura/escritura de grupo para acceder y actualizar el contenido del archivo) - si esto no es adecuado, la opción -m/--mode se puede usar para establecer el modo al valor (octal) *modo*.

Debido a que los archivos de caché indom son valiosos para el PMDA asociado, *indomcachectl* no sobrescribirá un archivo de caché indom existente.

La operación suele ser silenciosa, excepto por errores (o advertencias si se usa la opción -w/--warning). El estado de salida es 0 para éxito, 1 para fallo.

OTRAS OPCIONES DE GESTIÓN

Los archivos en $PCP_VAR_DIR/config/pmda son todos archivos de texto (uno por dominio de instancia cacheados) por lo que se puede usar una cirugía juiciosa para hacer cambios o incluso eliminar los archivos en casos extremos, *siempre que* el PMDA no se esté ejecutando.

Aquí hay un ejemplo para el número de dominio de instancia 60.17 que está asociado con las métricas network.interface.*. 

$ cat /var/lib/pcp/config/pmda/60.17
2 0 2147483647
0 1712727825 ens33
1 1712727825 virbr0
2 1712727825 lo


La primera línea es una cabecera mágica, no la cambie. Después de eso, hay una línea por instancia con el identificador de instancia (un entero) en el primer campo, algo mágico en el segundo campo (no lo cambie) y el nombre de instancia externo en el tercer campo.

VER TAMBIÉN

PCPIntro(1), chmod(1), pminfo(1), PMAPI(3), PMDA(3), pmdaCache(3), group(5) y passwd(5).
