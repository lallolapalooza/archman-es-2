DESCRIPCIÓ

N

innreport es un script de Perl que resume los archivos de registro de INN, con salida HTML opcional y gráficos. Normalmente es invocado por scanlogs(8), que incluye la salida de innreport en los informes diarios de

Usenet.

Los programas soportados son batcher, cnfsstat, controlchan, innd, innfeed, innxbatch, innxmit, nnrpd, nntplink (un programa externo), overchan, perl-nocem y rnews

.

innreport también actualiza el recuento de grupos de noticias no distribuidos localmente por el servidor de noticias, y para los cuales se han recibido artículos, en el archivo de registro unwanted.log. Si esa actualización no debe realizarse, ya que debería ocurrir solo una vez al día al analizar los registros diarios, se debe proporcionar la opción -notdaily a innreport

.

Si desea que innreport genere gráficos en sus informes HTML, necesita la biblioteca gráfica de Perl GD.p

m.

Al menos un archivo de registro no vacío para analizar debe ser proporcionado al final de la línea de comando que invoca a innre

por
t.

OPCIONE

S

Solo una opción es

obligatoria:
-f archivo-de-configur
ación
Ruta completa al archivo de configuración. Usualmente es innreport.conf en pathetc, pero no hay un valor por defecto. Este archivo lista las opciones a usar para el informe. Las opciones dadas en la línea de comando al llamar a innreport tienen prioridad sobre las
del archivo
de configuración.

Las otras opciones son opcionales. Anteponer "no" delante de opciones booleanas permite desactivarlas. Por ejemplo, use -nograph para eliminar la característica que -graph habi

lita.
-archive o -
a
Establece si las páginas HTML y los gráficos deben archivarse si los informes HTML están habilitados. Cuando esta opción está activada, que es el valor por defecto, se añadirá una fecha en el nombre de archivo de cada informe y cada gráfico. De lo contrario, solo se conserva el informe HTML más
reciente.
-casesensiti
ve
Si se deben realizar búsquedas sensibles a mayúsculas/minúsculas en los archivos de registro de noticias para patrones predeterminados. Esta opción está habilitada por
defecto.
-conf
ig
Imprime en la salida estándar la información de configuración de innreport y
sale.
-cycle o -c num-cyc
le
Establece cuántos archivos de informe deben conservarse si los informes HTML están habilitados y archivados. El valor por defecto es 0, lo que significa que todos los archivos se
conservan.
-dir o -d http-d
ir
Establece el directorio para las páginas web si los informes HTML están habilitados. El valor por defecto es el valor de pathhttp como se establece en inn.co
nf.
-graph o -
g
Si la biblioteca gráfica de Perl GD.pm está instalada y los informes HTML están habilitados, también se generan gráficos en PNG si es soportado por "GD", que es el caso en versiones modernas (de lo contrario se generará GIF). El valor por defecto es habilitar la generación de
gráficos.
-help o -
h
Imprime en la salida estándar un mensaje de ayuda con todas las opciones reconocidas por innreport y
sale.
-ht
ml
Además del informe de texto plano impreso en la salida estándar, innreport genera informes HTML si esta opción está habilitada. Esta opción está deshabilitada por defecto (es decir, -nohtml es el valor por defecto)
.
-html-unkno
wn
Si se deben informar las entradas desconocidas de los archivos de registro de noticias en los informes HTML, cuando esté habilitado. Esta opción toma por defecto el mismo valor que la de los informes de texto plano (como se establece con la opción unknow
n).
-index o -
i
Establece el nombre de la página web de índice si los informes HTML están habilitados. El valor por defecto es "index.ht
ml".
-maxunrec num-lin
es
Cuántas entradas no reconocidas de los archivos de registro de noticias informar, cuando las opciones -unknown o -html-unknown están activadas. El valor por defecto es 50. Usar "-1" significa que no hay
límite.
-notdai
ly
Si se deben diferir las acciones diarias para esta ejecución de innreport. Algunas acciones deben realizarse solo una vez al día para un archivo de registro (notablemente unwanted.log). Esta opción está deshabilitada por defecto, lo que significa que todas las acciones se realizan siempre, ya que asumimos una configuración por defecto de ejecutar scanlogs diari
amente.
-path o -p pictures-d
ir
Establece el directorio para las imágenes si los informes HTML están habilitados y se desean gráficos. El valor por defecto es pathhttp/pics.

Si se usan tanto -dir como -webpath, y -path no se usa, el directorio para las imágenes por defecto es http-dir como se establece con -dir/pictures-path como se establece con -webpath

.
-separator o -s ch
ar
Establece el separador entre horas, minutos y segundos en los nombres de archivo si los informes HTML están habilitados y archivados. El valor por defecto es "." ya que ":" puede no ser leído correctamente por todos los navegadores web. Tenga cuidado de no usar "/" como separador, y de usar solo un carácter válido para nombres de
archivo.
-unkno
wn
Si se deben informar las entradas desconocidas de los archivos de registro de noticias en los informes de texto plano. Esta opción está habilitada por
defecto.
-
v
Imprime en la salida estándar el número de versión de innreport y
sale.
-webpath o -w pictures-pa
th
Establece la ruta web para las imágenes en las páginas HTML si los informes HTML están habilitados y se desean gráficos. El valor por defecto es "pics". Puede ser una ruta relativa o una ruta absoluta. Si se usa una ruta absoluta, debe establecer -path apropiadamente; de
lo contrario
no se calculará
correctamente.
