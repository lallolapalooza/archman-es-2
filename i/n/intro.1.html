DESCRIPCIÓ

N

La sección 1 del manual describe comandos y herramientas de usuario, por

ejemplo, herramientas de manipulación de archivos, shells, compiladores, nav
egadores web, visores y editores de archivos e imágenes, y así sucesivamente.

NOTA

S

Linux es una variante de UNIX, y los comandos de usuario bajo UNIX funcionan de manera similar bajo Linux (y bajo muchos otros sistemas similares a UNIX también, como FreeBSD)

.

Bajo Linux, existen GUIs (interfaces gráficas de usuario), donde puedes apuntar, hacer clic y arrastrar, y con suerte hacer trabajo sin primero leer mucha documentación. El entorno tradicional de UNIX es una CLI (interfaz de línea de comandos), donde escribes comandos para decirle a la computadora qué hacer. Esto es más rápido y más potente, pero requiere averiguar qué comandos hay y cómo usarlos. A continuación se muestra una guía mínima para que

comiences.

Inicio de

sesión

Para empezar a trabajar, probablemente primero tendrás que abrir una sesión. El programa login(1) esperará a que escribas tu nombre de usuario y contraseña, y después de eso, iniciará un shell (intérprete de comandos) para ti. En caso de un inicio de sesión gráfico, obtendrás una pantalla con menús o iconos y un clic del ratón iniciará un shell en una ventana. Ver también xter

m(1
).

El

shell

Se escriben comandos en el shell, el intérprete de comandos. No está integrado; es solo otro programa. Puedes cambiar tu shell, y cada uno tiene su favorito. El estándar se llama sh. Ver también ash(1), bash(1), chsh(1), csh(1), dash(1), ksh(1), zsh(1

).

El $ aquí era el símbolo del prompt—es la forma del shell de indicar que está listo para el siguiente comando. El prompt se puede personalizar de muchas maneras, y podría incluir cosas como el nombre de usuario, el nombre de la máquina, el directorio actual, la hora, y así sucesivamente. Una asignación PS1="What next, master? " cambiaría el prompt como se

indica.

Vemos que hay comandos date (que da la fecha y hora), y cal (que da un calendario)

.

El comando ls lista el contenido del directorio actual—te dice qué archivos tienes. Con una opción -l da un listado largo, que incluye el propietario, el tamaño y la fecha del archivo, y los permisos que las personas tienen para leer y/o modificar el archivo. Por ejemplo, el archivo "tel" aquí tiene 37 bytes de longitud, es propiedad de aeb y el propietario puede leerlo y escribirlo, otros solo pueden leerlo. El propietario y los permisos se pueden cambiar con los comandos chown y chmod

.

El comando cat mostrará el contenido de un archivo. (El nombre es de "concatenate and print" (concatenar e imprimir): todos los archivos dados como parámetros se concatenan y se envían a "salida estándar" (ver stdout(3)), aquí la pantalla de la terminal.

)

El comando cp (de "copy" (copiar)) copiará un

archivo.

El comando mv (de "move" (mover)), por otro lado, solo lo

renombra.

El comando diff lista las diferencias entre dos archivos. Aquí no hubo salida porque no había

diferencias.

El comando rm (de "remove" (eliminar)) borra el archivo, ¡y ten cuidado! se ha ido. No hay papelera de reciclaje ni nada. Borrado significa

perdido.

El comando grep (de "g/re/p") encuentra ocurrencias de una cadena en uno

o más archivos. Aquí encuentra e
l número de teléfono de Maja.

Rutas de archivo y el directorio

actual

Los archivos viven en un gran árbol, la jerarquía de archivos. Cada uno tiene una ruta que describe el camino desde la raíz del árbol (que se llama /) hasta el archivo. Por ejemplo, una ruta completa así podría ser /home/aeb/tel. Siempre usar rutas completas sería inconveniente, y el nombre de un archivo en el directorio actual se puede abreviar dando solo el último componente. Por eso /home/aeb/tel se puede abreviar a tel cuando el directorio actual es /home/aeb

.

El comando pwd imprime el directorio

actual.

El comando cd cambia el directorio

actual.

Prueba alternativamente cd y pwd y explora el uso de cd: "cd", "cd .", "

cd ..", "cd
/", y "cd ~".

Directorio

s

El comando mkdir crea un nuevo

directorio.

El comando rmdir elimina un directorio si está vacío, y se queja en caso

contrario.

El comando find (con una sintaxis bastante barroca) encontrará archivos con un nombre dado u otras propiedades. Por ejemplo, "find . -name tel" encontraría el archivo tel empezando en el directorio presente (que se llama .). Y "find / -name tel" haría lo mismo, pero empezando en la raíz del árbol. Las búsquedas grandes en un disco de varios GB consumirán tiempo, y puede ser mejor usar locat

e(1
).

Discos y sistemas de

archivos

El comando mount adjuntará el sistema de archivos encontrado en algún disco (o disquete, o CDROM o similar) a la gran jerarquía del sistema de archivos. Y umount lo desengancha de nuevo. El comando df te dirá cuánto d

e tu disco
sigue libre.

Proceso

s

En un sistema UNIX, muchos procesos de usuario y de sistema se ejecutan simultáneamente. El que estás usando se ejecuta en el primer plano, los demás en el segundo plano. El comando ps te mostrará qué procesos están activos y qué números tienen estos procesos. El comando kill te permite deshacerte de ellos. Sin opción, esto es una solicitud amable: por favor, vete. Y "kill -9" seguido del nú

mero del proceso es una eliminación inmediata. Los procesos en pr
imer plano a menudo se pueden eliminar escribiendo Control-C.

Obtener

información

Hay miles de comandos, cada uno con muchas opciones. Tradicionalmente, los comandos se documentan en páginas man, (como esta), para que el comando "man kill" documente el uso del comando "kill" (y "man man" documente el comando "man"). El programa man envía el texto a través de algún paginador, usualmente less. Pulsa la barra espaciadora para obtener la siguiente página, pulsa q para

salir.

En la documentación es habitual referirse a las páginas de manual dando el nombre y el número de sección, como en man(1). Las páginas de manual son concisas y te permiten encontrar rápidamente algún detalle olvidado. Para los recién llegados, un texto introductorio con más ejemplos y explicaciones es

útil.

Mucho del software de GNU/FSF se proporciona con archivos info. Escribe "info info" para una introducción sobre el uso del programa info

.

Los temas especiales a menudo se tratan en los HOWTO. Busca en /usr/share/doc/howto/en y usa un

navegador si en
cuentras archivo
s HTML allí.
