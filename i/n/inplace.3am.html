INPLACE(3am) Módulos de extensión de GNU Awk INPLACE(3am)

NOMBRE

inplace - emular la edición in situ de sed/perl/ruby

SINOPSIS

gawk -i inplace ...

DESCRIPCIÓN

La extensión inplace añade dos funciones llamadas inplace_begin() y inplace_end(). Estas funciones están destinadas a ser invocadas desde el script de envoltura inplace.awk que se instala cuando se instala gawk.

Por defecto, cada archivo nombrado en la línea de comandos se reemplaza con un nuevo archivo del mismo nombre cuyos contenidos son los resultados de ejecutar el programa AWK. Dado que se crea un nuevo archivo, si el archivo es un enlace (duro o simbólico), el enlace se romperá. Este comportamiento es coherente con GNU sed, que también rompe los enlaces cuando se utiliza la opción -i o --in-place. Si el usuario proporciona una variable AWK llamada inplace::suffix en una regla BEGIN o en la línea de comandos, la extensión inplace concatena ese sufijo al nombre del archivo original y utiliza el resultado como nombre de archivo para renombrar el original.

Por compatibilidad con versiones anteriores, la variable también comprueba INPLACE_SUFFIX (en el espacio de nombres awk) para el sufijo a usar si inplace::suffix no está establecido.

Se puede deshabilitar la edición in situ selectivamente colocando inplace::enable=0 en la línea de comandos antes de los archivos que deben procesarse normalmente. Se puede volver a habilitar la edición in situ colocando inplace::enable=1 antes de los archivos que deben ser objeto de edición in situ.

ERRORES

Si bien la extensión intenta preservar la propiedad y los permisos, no intenta copiar las ACL del archivo original.

Si el programa muere prematuramente, como podría suceder si se recibe una señal no manejada, podría quedar un archivo temporal.

EJEMPLO

gawk -i inplace 'script' archivos ...
gawk -i inplace -f archivodescript archivos ...

VER TAMBIÉN
