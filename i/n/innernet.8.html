INNERNET(8) Utilidades de administración del sistema INNERNET(8)

NOMBRE

innernet - página de manual para innernet 1.7.1

SINOPSIS

innernet [OPCIONES] [COMANDO]

DESCRIPCIÓN

Un cliente para administrar interfaces de red innernet.

Comandos:

instalar
Instala una nueva configuración de innernet
mostrar
Enumera todas las conexiones de innernet
subir
Activa tu interfaz local y actualízala con la última lista de pares
obtener
Obtiene y actualiza tu interfaz local con la última lista de pares
desinstalar
Desinstala una red innernet
bajar
Desactiva la interfaz (equivalente a 'wg-quick down <interfaz>')
agregar-par
Agrega un nuevo par
renombrar-par
Renombra un par
agregar-cidr
Agrega un nuevo CIDR
renombrar-cidr
Renombra un CIDR
eliminar-cidr
Elimina un CIDR
listar-cidrs
Lista los CIDR
deshabilitar-par
Deshabilita un par habilitado
habilitar-par
Habilita un par deshabilitado
agregar-asociacion
Agrega una asociación entre CIDRs
eliminar-asociacion
Elimina una asociación entre CIDRs
listar-asociaciones
Lista las asociaciones existentes entre CIDRs
establecer-puerto-escucha
Establece el puerto de escucha local
reemplazar-endpoint
Reemplaza tu endpoint externo que el servidor envía a otros pares
completions
Genera scripts de completado para la shell
ayuda
Imprime este mensaje o la ayuda de los subcomandos dados

OPCIONES

-v, --verbose...
Salida detallada, usa -vv para una verbosidad aún mayor
-c, --config-dir <DIRECTORIO_CONFIG>
[predeterminado: /etc/innernet]
-d, --data-dir <DIRECTORIO_DATOS>
[predeterminado: /var/lib/innernet]
--no-routing
Si el enrutamiento debe ser realizado por innernet o por una herramienta externa como babeld, por ejemplo
--backend <BACKEND>
Especifica un backend WireGuard a usar. Si no se establece, innernet lo seleccionará automáticamente según la disponibilidad [predeterminado: kernel] [posibles valores: kernel, userspace]
--mtu <MTU>
Especifica la MTU deseada para tu interfaz (predeterminado: 1280)
-h, --help
Imprime la ayuda
-V, --version
Imprime la versión
