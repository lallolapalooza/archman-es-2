INSTALL(1) Comandos de Usuario INSTALL(1)

NOMBRE

install - copia archivos y establece atributos

SINOPSIS

install [OPCIÓN]... [-T] ORIGEN DESTINO
install [OPCIÓN]... ORIGEN... DIRECTORIO
install [OPCIÓN]... -t DIRECTORIO ORIGEN...
install [OPCIÓN]... -d DIRECTORIO...

DESCRIPCIÓN

Este programa de instalación copia archivos (a menudo recién compilados) a las ubicaciones de destino que usted elija. Si desea descargar e instalar un paquete listo para usar en un sistema GNU/Linux, debería usar en su lugar un gestor de paquetes como yum(1) o apt-get(1).

En las tres primeras formas, copia ORIGEN a DESTINO o múltiples ORIGEN(es) al DIRECTORIO existente, estableciendo modos de permiso y propietario/grupo. En la 4ª forma, crea todos los componentes del(los) DIRECTORIO(s) dado(s).

Los argumentos obligatorios para las opciones largas son también obligatorios para las opciones cortas.

--backup[=CONTROL]
crea una copia de seguridad de cada archivo de destino existente
-b
similar a --backup pero no acepta argumento
-c
(ignorado)
-C, --compare
compara el contenido de los archivos de origen y destino y, si no hay cambios en el contenido, la propiedad y los permisos, no modifica el destino en absoluto
-d, --directory
trata todos los argumentos como nombres de directorio; crea todos los componentes de los directorios especificados
-D
crea todos los componentes principales de DESTINO excepto el último, o todos los componentes de --target-directory, y luego copia ORIGEN a DESTINO
--debug
explica cómo se copia un archivo. Implica -v
-g, --group=GRUPO
establece la propiedad del grupo, en lugar del grupo actual del proceso
-m, --mode=MODO
establece el modo de permisos (como en chmod), en lugar de rwxr-xr-x
-o, --owner=PROPIETARIO
establece la propiedad (solo para superusuario)
-p, --preserve-timestamps
aplica los tiempos de acceso/modificación de los archivos ORIGEN a los archivos de destino correspondientes
-s, --strip
elimina tablas de símbolos
--strip-program=PROGRAMA
programa utilizado para eliminar binarios
-S, --suffix=SUFIJO
anula el sufijo de copia de seguridad habitual
-t, --target-directory=DIRECTORIO
copia todos los argumentos ORIGEN en DIRECTORIO
-T, --no-target-directory
trata DESTINO como un archivo normal
-v, --verbose
imprime el nombre de cada archivo o directorio creado
--preserve-context
conserva el contexto de seguridad SELinux
-Z
establece el contexto de seguridad SELinux del archivo de destino y de cada directorio creado al tipo predeterminado
--context[=CTX]
similar a -Z, o si se especifica CTX, establece el contexto de seguridad SELinux o SMACK a CTX
--help
muestra esta ayuda y sale
--version
muestra la información de la versión y sale

El sufijo de copia de seguridad es '~', a menos que se establezca con --suffix o SIMPLE_BACKUP_SUFFIX. El método de control de versiones se puede seleccionar a través de la opción --backup o mediante la variable de entorno VERSION_CONTROL. Estos son los valores:

none, off
nunca crear copias de seguridad (incluso si se proporciona --backup)
numbered, t
crear copias de seguridad numeradas
existing, nil
numeradas si existen copias de seguridad numeradas, simples en caso contrario
simple, never
siempre crear copias de seguridad simples
