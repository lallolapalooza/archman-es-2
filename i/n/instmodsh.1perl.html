NOMBRE

instmodsh - Un intérprete para examinar módulos instalados

SINOPSIS

instmodsh

DESCRIPCIÓN

Una pequeña interfaz para ExtUtils::Installed para examinar módulos instalados, validar sus listas de paquetes e incluso crear un archivo tarball a partir de un módulo instalado.

VER TAMBIÉN

ExtUtils::Installed
