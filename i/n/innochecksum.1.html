INNOCHECKSUM(1) Sistema de bases de datos MariaDB INNOCHECKSUM(1)

NOMBRE

innochecksum - utilidad de suma de verificación sin conexión para archivos InnoDB

SINOPSIS

innochecksum [opciones] nombre_archivo

DESCRIPCIÓN

innochecksum imprime sumas de verificación para archivos InnoDB. Esta herramienta lee un archivo de espacio de tabla InnoDB, calcula la suma de verificación para cada página, compara la suma de verificación calculada con la suma de verificación almacenada e informa las discrepancias, que indican páginas dañadas. Originalmente se desarrolló para acelerar la verificación de la integridad de los archivos de espacio de tabla después de cortes de energía, pero también se puede usar después de copias de archivos. Dado que las discrepancias en las sumas de verificación harán que InnoDB apague deliberadamente un servidor en ejecución, puede ser preferible usar esta herramienta en lugar de esperar a que un servidor en uso de producción encuentre las páginas dañadas.

innochecksum no se puede usar en archivos de espacio de tabla que el servidor ya tiene abiertos. Para tales archivos, debe usar CHECK TABLE para verificar tablas dentro del espacio de tabla.

Si se encuentran discrepancias en las sumas de verificación, normalmente restauraría el espacio de tabla a partir de una copia de seguridad o iniciaría el servidor e intentaría usar mariadb-dump para hacer una copia de seguridad de las tablas dentro del espacio de tabla.

Invoque innochecksum de la siguiente manera:

shell> innochecksum [opciones] nombre_archivo

innochecksum admite las siguientes opciones. Para las opciones que se refieren a números de página, los números se basan en cero.

•-?, --help

Muestra la ayuda y sale.

•-a num, --allow-mismatches=#

Número máximo de discrepancias de suma de verificación permitidas antes de que innochecksum termine. El valor predeterminado es 0, que termina en la primera discrepancia.

•-c, --count

Imprime el número de páginas en el archivo.

•-e num, --end-page=#

Termina en este número de página.

•-i, --per-page-details

Imprime detalles por página.

•-I, --info

Sinónimo de --help.

•-f, --leaf

Examina las páginas de índice hoja.

•-l fn, --log=fn

Registra la salida en el nombre de archivo especificado, fn.

•-m num, --merge=#

Número de páginas hoja si se fusionan el número dado de páginas consecutivas.

•-n, --no-check

Ignora la verificación de la suma de verificación. Hasta MariaDB 10.6, debe usarse con la opción --write.

•-p num, --page-num=#

Verifica solo este número de página.

•-D nombre, --page-type-dump=nombre

Descarga la información del tipo de página para cada página en un espacio de tabla.

•-S, --page-type-summary

Muestra un recuento de cada tipo de página en un espacio de tabla.

•-s num, --start-page

Comienza en este número de página.

•-u, --skip-corrupt

Omitir páginas corruptas.

•-C nombre, --strict-check=nombre

Especifica el algoritmo de suma de verificación estricto. Uno de: crc32, innodb, none. Si no se especifica, valida contra innodb, crc32 y none. Eliminado en MariaDB 10.6.

•-w nombre, --write=nombre

Reescribe el algoritmo de suma de verificación. Uno de crc32, innodb, none. Se obtiene un bloqueo exclusivo durante el uso. Úselo junto con la opción -no-check para reescribir una suma de verificación no válida. Eliminado en MariaDB 10.6.

•-v, --verbose

Modo detallado; imprime un indicador de progreso cada cinco segundos.

•-V, --version

Muestra información de versión y sale.
