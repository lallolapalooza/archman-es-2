NOMBRE

/etc/incron.conf - archivo de configuración principal para inotify cron (incron)

DESCRIPCIÓN

El archivo /etc/incron.conf contiene la configuración predeterminada para el programa incrond. Cada línea contiene un par de valores en el formato opción = valor. Las líneas de comentarios deben tener un signo de almohadilla (#) en la primera línea.

Las opciones de configuración válidas son:

system_table_dir
Este directorio es examinado por incrond para los archivos de tabla del sistema. Predeterminado:/etc/incron.d
user_table_dir
Este directorio es examinado por incrond para los archivos de tabla de usuario. Predeterminado:/var/spool/incron
allowed_users
Este archivo contiene los usuarios a los que se les permite usar incron. Predeterminado:/etc/incron.allow
denied_users
Este archivo contiene los usuarios a los que se les niega el uso de incron. Predeterminado:/etc/incron.deny
lockfile_dir
Este directorio se utiliza para crear un bloqueo que evita la ejecución de múltiples instancias de incrond. Predeterminado:/var/run
lockfile_name
Este nombre (añadido con '.pid') se utiliza para crear un bloqueo que evita la ejecución de múltiples instancias de incrond. Predeterminado:incrond
editor
Este nombre o ruta se utiliza para ejecutar como editor para editar tablas de incron. El valor predeterminado de sin editor se proporciona, se utiliza el editor del sistema; esta opción anula esto.
