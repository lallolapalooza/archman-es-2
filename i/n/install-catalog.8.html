NOMBRE

install-catalog - Gestionar un catálogo centralizado SGML o XML

SINOPSIS

install-catalog [ opción ] acción ... [ [ -d] [ --delegate] ] [ [ -a centralizado ordinario] [ --add centralizado ordinario]


[ -r centralizado ordinario] [ --remove centralizado ordinario]


[ -h] [ --help]


[ -v] [ --version] ]

DESCRIPCIÓN

Este script de shell permite manejar un catálogo centralizado que referencia otros Catálogos Abiertos SGML o XML ("ordinarios").

Un Catálogo Abierto contiene un conjunto de directivas definidas por OASIS, usadas principalmente para definir equivalencias entre FPIs (Identificadores Públicos Formales) y nombres de archivo reales (ver TR9401:1997 en http://www.oasis-open.org <URL:http://www.oasis-open.org>). Los Catálogos Abiertos suelen residir en /usr/share/sgml.

Un catálogo centralizado es un Catálogo Abierto especial que solo contiene comentarios y directivas CATALOG que apuntan a otros catálogos (o directivas DELEGATE si son compatibles). El catálogo centralizado puede ser la clave para todos los demás recursos SGML. Normalmente reside en /etc/sgml.

El catálogo centralizado puede editarse manualmente o a través del script install-catalog para añadir o eliminar referencias a otros catálogos ordinarios. Este script está destinado principalmente a los scripts post-instalación de paquetes de software.

Un ejemplo de una llamada típica a install-catalog es:

      install-catalog --add \
        /usr/share/sgml/docbook/dsssl-stylesheets-1.54/catalog \
        /etc/sgml/sgml-docbook-4.0.cat

Esta llamada instalará en /etc/sgml/sgml-docbook-4.0.cat una referencia a /usr/share/sgml/docbook/dsssl-stylesheets-1.54/catalog.

OPCIONES

Aquí está la lista de opciones que pueden influir en cómo funciona install-catalog:


[ [ -d] [ --delegate] ]

Utiliza DELEGATE en lugar de directivas CATALOG para especificar un puntero.

ACCIONES

Aquí está la lista de acciones que se pueden solicitar a install-catalog:


[ [ -a centralizado ordinario] [ --add centralizado ordinario] ]

Declara un nuevo paquete SGML.


[ [ -r centralizado ordinario] [ --remove centralizado ordinario] ]

Elimina un paquete SGML previamente instalado.


[ [ -h] [ --help] ]

Imprime un breve mensaje de ayuda y sale.


[ [ -v] [ --version] ]

Imprime el identificador de versión y sale.
