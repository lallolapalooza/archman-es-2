DESCRIPCIÓ

N

infiniband-diags es un conjunto de utilidades diseñadas para ayudar a configurar, depurar y mantener redes InfiniBand. Se proporcionan muchas herramientas y utilidades. Algunas con funcionalidad

similar.

Las utilidades base utilizan MADs de ruta dirigida para realizar sus operaciones. Por

lo tanto, pueden funcionar incluso en subredes no configuradas. Otras utilidades de
nivel más alto requieren MADs enrutados por LID y hasta cierto punto acceso a SA/SM.

EL USO DE SMPs

(QP0)

Muchas de las herramientas de este paquete dependen del uso de SMPs a través de QP0 para adquirir datos directamente del SMA. Aunque este modo de operación no es técnicamente confor

me con la especificación InfiniBand, la experiencia práctica ha encontrado que este nivel de diagnóstico es valioso cuando se trabaja con una red que está rota o solo parcialmente
configurada. Por esta razón muchas de estas herramientas pueden requerir el uso de una MKey o la operación desde Máquinas Virtuales puede estar restringida por razones de seguridad.

FORMATO DEL ARCHIVO DE

TOPOLOGÍA

El formato del archivo de topología es legible por humanos y en gran medida intuitivo. La mayoría de los identificadores se dan con nombres textuales como vendor ID (vendid), device ID (device ID), GUIDs de varios tipos (sysimgguid, caguid, switchguid, etc.). Los PortGUIDs se muestran entre paréntesis (). Para los switches, esto se muestra en la línea del switchguid. Para los puertos CA y router, se muestra en las líneas de conectividad. El nodo IB se identifica seguido del número de puertos y un GUID de nodo entre comillas. A la derecha de esta línea hay un comentario (#) seguidoseguido por la NodeDescription entre comillas. Si el nodo es un switch, esta línea también contiene si el puerto 0 del switch es base o mejorado, y el LID y el LMC del puerto 0. Las líneas siguientes que pertenecen a este nodo muestran la conectividad. A la izquierda está el número de puerto del nodo actual. A la derecha está el nodo par (el nodo en el otro extremo del enlace). Se identifica entre comillas con nodetype seguido de - seguido de NodeGUID con el número de puerto entre corchetes. Más a la derecha hay un comentario (#). Lo que sigue al comentario depende del tipo de nodo. Si es un nodo switch, le sigue la NodeDescription entre comillas y el LID del nodo par. Si es un nodo CA o router, le sigue el LID y el LMC locales y luego la NodeDescription entre comillas y el LID del nodo par. El ancho y la velocidad del enlace activo se añaden al final de esta línea de

salida.
