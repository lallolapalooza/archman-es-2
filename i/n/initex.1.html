DESCRIPCIÓ

N

Ejecuta el compositor tipográfico TeX sobre archivo, generalmente creando archivo.dvi. Si el argumento de archivo no tiene extensión, se le añadirá ".tex". En lugar de un nombre de archivo, se puede dar un conjunto de comandos de TeX, el primero de los cuales debe comenzar con una barra invertida. Con un &argumento de formato, TeX utiliza un conjunto diferente de comandos precompilados, contenidos en formato.fmt; generalmente es mejor usar la -fmt opción de formato en su

lugar.

TeX formatea el texto y los comandos intercalados contenidos en los archivos nombrados y genera un archivo independiente del compositor (llamado DVI, que es la abreviatura de DeVice Independent). Las capacidades y el lenguaje de TeX se describen en The TeXbook. TeX se usa normalmente con un gran cuerpo de macros precompiladas, y existen varios sistemas de formateo específicos, como LaTeX, que requieren el soporte de varios archivos de

macros.

Esta versión de TeX examina su línea de comandos para ver con qué nombre fue invocada. Si existen, entonces tanto initex como virtex son enlaces simbólicos al ejecutable tex. Cuando se invoca como initex (o cuando se da la opción -ini), se puede usar para precompilar macros en un archivo .fmt. Cuando se invoca como virtex, utilizará el formato plain. Cuando se invoca con cualquier otro nombre, TeX usará ese nombre como el nombre del formato a utilizar. Por ejemplo, cuando se invoca como tex, se usa el formato tex, que es idéntico al formato plain. Los comandos definidos por el formato plain están documentados en The TeXbook. Otros formatos que a menudo están disponibles incluyen latex y amstex

.

Los argumentos de la línea de comandos que no son opciones se pasan al programa TeX como la primera línea de entrada. (Pero a menudo es más fácil escribir argumentos extendidos como la primera línea de entrada, ya que los shells de UNIX tienden a tragar o malinterpretar los símbolos favoritos de TeX, como las barras invertidas, a menos que los cites.) Como se describe en The TeXbook, esa primera línea debe comenzar con un nombre de archivo, una \secuencia_de_control, o un &nombre_de_formato

.

El uso normal es

decir 
tex paper
para comenzar a procesar paper.tex. El nombre paper será el "nombre del trabajo" (jobname), y se usa para formar los nombres de los archivos de salida. Si TeX no recibe un nombre de archivo en la primera línea, el nombre del trabajo es texput. Al buscar un archivo, TeX busca el nombre con y sin la extensión predeterminada (.tex) añadida, a menos que el nombre ya contenga esa extensión. Si paper es el "nombre del trabajo", un registro de mensajes de error, con bastante más detalle de lo que normalmente aparece en la pantalla, aparecerá en paper.log, y el archivo de salida estará en paper.dvi.

Esta versión de TeX puede examinar la primera línea del archivo paper.tex para ver si comienza con la secuencia mágica %&. Si la primera línea comienza con %&formato -translate-filenombre_de_tcx, entonces TeX usará el formato y la tabla de traducción nombrados nombre_de_tcx para procesar el archivo fuente. Se puede omitir el nombre del formato o la especificación -translate-file, pero no ambos. Esto anula la selección de formato basada en el nombre con el que se invoca el programa. La opción -parse-first-line o la variable de configuración parse_first_line controla si este comportamiento está

habilitado.

La respuesta e al indicador de error de TeX hace que el editor predeterminado del sistema se inicie en la línea actual del archivo actual. La variable de entorno TEXEDIT se puede usar para cambiar el editor utilizado. Puede contener una cadena con "%s" que indica dónde va el nombre del archivo y "%d" que indica dónde va el número de línea decimal (si lo hay). Por ejemplo, una cadena TEXEDIT para emacs se puede establecer con el comando s

h 
TEXEDIT="emacs +%d %s"; export TEXEDIT

Un archivo conveniente en la biblioteca es null.tex, que contiene nada. Cuando TeX no puede encontrar un archivo que cree que desea introducir, sigue pidiéndole otro nombre de

archivo; responder `null' lo saca del bucle si no desea introducir na
da. También puede escribir su carácter EOF (generalmente control-D).

Consulte la documentación de la biblioteca Kpathsearch (el nodo `Path specifications') para detalles precisos sobre cómo se utilizan las variables de entorno. La utilidad kpsewhich se puede usar para consultar los valores de las

variables.

Una advertencia: En la mayoría de los formatos de TeX, no puede usar ~ en un nombre de archivo que proporcione directamente a TeX, porque ~ es un carácter activo y, por lo tanto, se expande, no se toma como parte del nombre del archivo. Otros programas, como Metafont, no tienen este

problema.
TEXMFOUTP
UT
Normalmente, TeX coloca sus archivos de salida en el directorio actual. Si algún archivo de salida no se puede abrir allí, intenta abrirlo en el directorio especificado en la variable de entorno TEXMFOUTPUT. No hay un valor predeterminado para esa variable. Por ejemplo, si usted dice tex paper y el directorio actual no es escribible, si TEXMFOUTPUT tiene el valor /tmp, TeX intenta crear /tmp/paper.log (y /tmp/paper.dvi, si se produce alguna salida.) TEXMFOUTPUT también se comprueba para los archivos de entrada, ya que TeX a menudo genera archivos que necesitan ser leídos posteriormente; para la entrada, no se añaden sufijos (como ``.tex'') por defecto, el nombre de entrada simplemente se comprueba tal como se
proporciona.
TEXINPU
TS
Ruta de búsqueda para los archivos \input y \openin. Esta debería probablemente empezar con ``.'', para que los archivos de usuario se encuentren antes que los archivos del sistema. Un componente de ruta vacío será reemplazado con las rutas definidas en el archivo texmf.cnf. Por ejemplo, establezca TEXINPUTS en ".:/home/user/tex:" para anteponer el directorio actual y ``/home/user/tex'' a la ruta de búsqueda
estándar.

ERRORE

S

Esta versión de TeX implementa una serie de extensiones opcionales. De hecho, muchas de estas extensiones entran en conflicto en mayor o menor medida con la definición de TeX. Cuando estas extensiones están habilitadas, el mensaje que se imprime cuando TeX inicia cambia para imprimir TeXk en lugar de TeX

.

Esta versión de TeX no logra detectar el desbordamiento aritmético cuando se suman o restan dimensiones. Los casos en los que esto ocurre son raros, pero cuando ocurre, el archivo DVI genera

do será
inválido.
