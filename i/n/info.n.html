Esta forma es una lista de tamaño par que alterna tokens y parámetros. Los tokens actualmente son CALL, UP o INNER, pero otros valores pueden introducirse en el futuro. CALL indica una llamada a procedimiento, y su parámetro es el info level 0 correspondiente. UP indica un cambio en los marcos de variables generado por uplevel o similar, y se aplica al elemento CALL anterior. Su parámetro es el desplazamiento de nivel. INNER identifica el “contexto interno”, que es el comando atómico o la instrucción de código de bytes más interna que provocó el error, junto con sus argumentos cuando están disponibles. Mientras que CALL y UP permiten seguir rutas de llamada complejas, INNER se centra en la operación problemática en la llamada al procedimiento más interna, incluso llegando a la granularidad de

subexpresiones.

EJEMPLO

S

Este comando imprime un procedimiento adecuado para guardar en un script de

Tcl: 
proc printProc {procName} {
    set result [list proc $procName]
    set formals {}
    foreach var [info args $procName] {
        if {[info default $procName $var def]} {
            lappend formals [list $var $def]
        } else {
            # Still need the list-quoting because variable
            # names may properly contain spaces.
            lappend formals [list $var]
        }
    }
    puts [lappend result $formals [info body $procName]]
}
