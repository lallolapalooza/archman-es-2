INET_ADDR(3P) Manual de Programador POSIX INET_ADDR(3P)

PRÓLOGO

Esta página del manual forma parte del Manual del Programador POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual de Linux correspondiente para conocer los detalles del comportamiento en Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

inet_addr, inet_ntoa — manipulación de direcciones IPv4

SINOPSIS

#include <arpa/inet.h>
in_addr_t inet_addr(const char *cp);
char *inet_ntoa(struct in_addr in);

DESCRIPCIÓN

La función inet_addr() convertirá la cadena apuntada por cp, en la notación estándar decimal con puntos de IPv4, a un valor entero adecuado para ser utilizado como dirección de Internet.

La función inet_ntoa() convertirá la dirección de host de Internet especificada por in a una cadena en la notación decimal estándar de Internet.

La función inet_ntoa() no necesita ser segura para hilos (thread-safe).

Todas las direcciones de Internet se devolverán en orden de red (los bytes ordenados de izquierda a derecha).

Los valores especificados usando la notación decimal con puntos de IPv4 toman una de las siguientes formas:

a.b.c.d
Cuando se especifican cuatro partes, cada una se interpretará como un byte de datos y se asignará, de izquierda a derecha, a los cuatro bytes de una dirección de Internet.
a.b.c
Cuando se especifica una dirección de tres partes, la última parte se interpretará como una cantidad de 16 bits y se colocará en los dos bytes más a la derecha de la dirección de red. Esto hace que el formato de dirección de tres partes sea conveniente para especificar direcciones de red de Clase B como "128.net.host".
a.b
Cuando se proporciona una dirección de dos partes, la última parte se interpretará como una cantidad de 24 bits y se colocará en los tres bytes más a la derecha de la dirección de red. Esto hace que el formato de dirección de dos partes sea conveniente para especificar direcciones de red de Clase A como "net.host".
a
Cuando solo se proporciona una parte, el valor se almacenará directamente en la dirección de red sin ninguna reorganización de bytes.

Todos los números especificados como partes en la notación decimal con puntos de IPv4 pueden ser decimales, octales o hexadecimales, como se especifica en el estándar ISO C (es decir, un 0x o 0X inicial indica hexadecimal; de lo contrario, un **'0'** inicial indica octal; de lo contrario, el número se interpreta como decimal).

VALOR DE RETORNO

Al completarse con éxito, inet_addr() devolverá la dirección de Internet. De lo contrario, devolverá (in_addr_t)(-1).

La función inet_ntoa() devolverá un puntero a la dirección de red en notación decimal estándar de Internet.

ERRORES

No se definen errores.
