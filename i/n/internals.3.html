int LIBMTP_Get_Supported_Devices_List (LIBMTP_device_entry_t **const devices, int *const numdevs)

Obtiene una lista de los dispositivos USB compatibles.

Los desarrolladores dependen de los usuarios de esta biblioteca para añadir constantemente a la lista de dispositivos compatibles. Lo que necesitamos es el nombre del dispositivo, el ID de Vendedor USB (VID) y el ID de Producto USB (PID). Por favor, inclúyalo en un ticket de error en la página principal del proyecto. El VID/PID se utiliza para permitir, por ejemplo, que udev eleve el dispositivo al espacio de usuario de la consola cuando se conecta.

Parámetros

devices un puntero a un puntero que contendrá una lista de dispositivos después de la llamada a esta función, si tuvo éxito.
numdevs un puntero a un entero que contendrá el número de dispositivos en la lista de dispositivos si la llamada tuvo éxito.

Devuelve

0 si la lista se recuperó con éxito, cualquier otro valor significa fallo.

void LIBMTP_Init (void )

Inicializa la biblioteca. Solo debes llamar a esta función una vez, antes de usar la biblioteca por primera vez en un programa. ¡Nunca re-inicialices libmtp!

Lo único que hace en este momento es inicializar la tabla de mapeo de tipos de archivo, así como cargar los datos MTPZ si es necesario.
