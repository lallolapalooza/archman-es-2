La

función inet_addr() convierte la dirección de host de Internet cp desde la notación de números y puntos IPv4 a datos binarios en orden de bytes de red. Si la entrada no es válida, se devuelve INADDR_NONE (generalmente -1). El uso de esta función es problemático porque -1 es una dirección válida (255.255.255.255). Evite su uso en favor de inet_aton(), inet_pton(3) , o getaddrinfo(3) , que proporcionan una forma más limpia de indicar el retorno de

error.

La función inet_network() convierte cp, una cadena en notación de números y puntos IPv4, a un número en orden de bytes del host adecuado para su uso como dirección de red de Internet. En caso de éxito, se devuelve la dirección convertida. Si la entrada no es

válida,

se devuelve -1. La función inet_ntoa() convierte la dirección de host de Internet in, dada en orden de bytes de red, a una cadena en notación decimal con puntos IPv4. La cadena se devuelve en un búfer asignado estáticamente, que las llamadas

main(int argc, char *argv[])
{
    struct in_addr addr;
    if (argc != 2) {
        fprintf(stderr, "%s <dotted-address>\n", argv[0]);
        exit(EXIT_FAILURE);
    }
    if (inet_aton(argv[1], &addr) == 0) {
