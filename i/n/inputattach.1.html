NOMBRE

inputattach - adjunta una línea serie a un dispositivo de capa de entrada

SINOPSIS

inputattach [--daemon] [--always] [--noinit] [--baud velocidad>] <modo> <dispositivo>

DESCRIPCIÓN

inputattach adjunta una línea serie a un dispositivo de capa de entrada a través de una disciplina de línea.

Se debe especificar al menos uno de los modos disponibles en la línea de comandos; si los modos se pueden detectar, se pueden especificar hasta cuatro y se probarán en secuencia hasta que uno coincida con el dispositivo.

OPCIONES

--daemon
Se bifurca en segundo plano.
--always
Ignora los fallos de inicialización al adjuntar el dispositivo.
--noinit
Omite la inicialización del dispositivo.
--baud
Especifica la velocidad en baudios a utilizar. (Esto solo es necesario si la velocidad predeterminada es incorrecta.)

NAME

inputattach - Attaches input devices to the virtual console

SYNOPSIS

inputattach [-a] [-d] [-i device] [-k keymap] [-m] [-s speed] [-t type] [-v] [-w width]

DESCRIPTION

The inputattach command attaches input devices to the virtual console. It can be used to configure various input devices such as keyboards, mice, and touchscreens. The command reads input device configurations from files and applies them to the system.

OPTIONS

  • -a: Attach all available input devices.
  • -d: Detach all attached input devices.
  • -i device: Specify the input device to attach.
  • -k keymap: Specify the keymap to use for the input device.
  • -m: Attach a mouse device.
  • -s speed: Specify the speed for the input device.
  • -t type: Specify the type of the input device.
  • -v: Verbose output.
  • -w width: Specify the width for the input device.
