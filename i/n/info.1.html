INFO(1) Comandos de usuario INFO(1)

NOMBRE

info - leer documentos Info

SINOPSIS

info [OPCIÓN]... [ELEMENTO_DE_MENÚ...]

DESCRIPCIÓN

Lee documentación en formato Info.

Opciones de uso frecuente:

-a, --all
usar todos los manuales coincidentes
-k, --apropos=CADENA
buscar CADENA en todos los índices de todos los manuales
-d, --directory=DIR
añadir DIR a INFOPATH
-f, --file=MANUAL
especificar el manual de Info a visitar
-h, --help
mostrar esta ayuda y salir
--index-search=CADENA
ir al nodo apuntado por la entrada del índice CADENA
-n, --node=NOMBRE_NODO
especificar nodos en el primer archivo Info visitado
-o, --output=ARCHIVO
enviar los nodos seleccionados a ARCHIVO
--subnodes
enviar recursivamente los elementos del menú
-v, --variable VAR=VALOR
asignar VALOR a la variable Info VAR
--version
mostrar información de versión y salir
-w, --where, --location
imprimir la ubicación física del archivo Info

El primer argumento que no sea una opción, si está presente, es la entrada del menú desde la que empezar; se busca en todos los archivos 'dir' a lo largo de INFOPATH. Si no está presente, info combina todos los archivos 'dir' y muestra el resultado. Los argumentos restantes se tratan como nombres de elementos de menú relativos al nodo inicial visitado.

Para un resumen de las combinaciones de teclas, escriba H dentro de Info.

EJEMPLOS

info
mostrar el menú dir de nivel superior
info info-stnd
mostrar el manual de este programa Info
info emacs
empezar en el nodo emacs desde el dir de nivel superior
info emacs buffers
seleccionar la entrada del menú buffers en el manual de emacs
info emacs -n Files
empezar en el nodo Files dentro del manual de emacs
info '(emacs)Files'
forma alternativa de empezar en el nodo Files
info --subnodes -o out.txt emacs
volcar todo el manual de emacs a out.txt
info -f ./foo.info
mostrar el archivo ./foo.info, sin buscar en dir

VER TAMBIÉN

La documentación completa de info se mantiene como un manual Texinfo. Si el programa info está instalado correctamente en su sitio, el comando

info info

debería darle acceso al manual completo. (O, si tiene Emacs, M-x info le llevará al manual.)
