inotify_rm_watch(2) Manual de llamadas al sistema inotify_rm_watch(2)

NOMBRE

inotify_rm_watch - eliminar un reloj existente de una instancia de inotify

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <sys/inotify.h>
int inotify_rm_watch(int fd, int wd);

DESCRIPCIÓN

inotify_rm_watch() elimina el reloj asociado con el descriptor de reloj wd de la instancia de inotify asociada con el descriptor de archivo fd.

La eliminación de un reloj causa que se genere un evento IN_IGNORED para este descriptor de reloj. (Ver inotify(7)).

VALOR DE RETORNO

En caso de éxito, inotify_rm_watch() devuelve cero. En caso de error, devuelve -1 y se establece errno para indicar el error.

ERRORES

EBADF
fd no es un descriptor de archivo válido.
EINVAL
El descriptor de reloj wd no es válido; o fd no es un descriptor de archivo de inotify.

ESTANDARES

Linux.

HISTORIA

Linux 2.6.13.

VER TAMBIÉN

inotify_add_watch(2), inotify_init(2), inotify(7)
