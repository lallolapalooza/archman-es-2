NOMBRE

innconfval - Obtiene parámetros de configuración de archivos de configuración

SINOPSIS

innconfval [-pstv] [-f archivo] [-F tipodearchivo] [-i archivoconfiginn] [parámetro ...]

innconfval -C [-i archivoconfiginn]

DESCRIPCIÓN

innconfval normalmente imprime los valores de los parámetros especificados en la línea de comandos, desde inn.conf. Por defecto, solo imprime los valores de los parámetros, pero si se proporcionan -p, -s, o -t, imprime en su lugar el parámetro y el valor en forma de asignación de variable en Perl, Bourne shell o Tcl respectivamente. Si no se solicitan parámetros específicos, innconfval imprime todos los valores de los parámetros (esto no es particularmente útil a menos que se especifique uno de -p, -s o -t).

Todos los parámetros se toman de inn.conf excepto version, que es siempre la cadena de versión de INN.

Use las opciones -f y -F para especificar otro archivo de configuración del cual imprimir los valores de los parámetros.

Si se proporciona la opción -C, innconfval en su lugar verifica inn.conf, informando cualquier problema encontrado en la salida de error estándar.

OPCIONES

-C
Verifica inn.conf en lugar de imprimir los valores de los parámetros, y sale con estado 0 si no se encuentran problemas y con estado 1 en caso contrario.
-f archivo
Usa archivo como el archivo de configuración de origen para el tipo mencionado en la opción -F. Si no se establece, se usa el archivo de configuración predeterminado (es decir, el archivo en pathetc con el nombre del tipo proporcionado con -F). archivo debe ser un archivo de configuración válido de ese tipo y se analizará de la misma manera que ese tipo.
-F tipodearchivo
tipodearchivo debe ser "inn.conf" (el valor predeterminado) o "inn-secrets.conf". Define el tipo de archivo de configuración a analizar.

Por ejemplo, ejecute "innconfval -F inn-secrets.conf canlockuser" para obtener el valor canlockuser de inn-secrets.conf.

Se utilizará la ruta predeterminada al archivo de configuración del tipo solicitado, a menos que se proporcione -f (o se establezca un archivo de configuración de origen específico para inn.conf con -i y se defina otra ubicación pathetc).

-i archivoconfiginn
Usa archivoconfiginn como el archivo de configuración de origen para inn.conf en lugar de inn.conf en pathetc. archivoconfiginn debe ser un archivo inn.conf válido y se analizará de la misma manera que inn.conf.
-p
Imprime los parámetros como sentencias de asignación de Perl. El nombre de la variable será el mismo que el parámetro de configuración, y los valores de cadena se encerrarán entre comillas simples con el escape apropiado. Los valores booleanos se mapearán a las cadenas "true" o "false". Los valores de lista se mapearán a un array de cadenas. Los valores NULL se imprimen con el valor "undef".

Aquí hay un ejemplo:

$enableoverview = 'true';
@extraoverviewadvertised = ( 'Newsgroups', 'Injection-Info' );
@extraoverviewhidden = undef;
$organization = 'Let\'s try nasty "quotes"';
$maxforks = 10;

Si innconfval se llama a través del módulo Perl "INN::Config", todas estas variables se exportan correctamente.

-s
Imprime los parámetros como sentencias de asignación de Bourne shell. El nombre de la variable será el nombre del parámetro de configuración en mayúsculas y todas las variables se exportarán, si no son NULL. Los valores de cadena se encerrarán entre comillas simples con el escape apropiado, y los valores booleanos se mapearán a "true" o "false". Los valores de lista se mapearán a una cadena separada por espacios que representa un array de cadenas (como Bourne shell no reconoce arrays, a diferencia de varios otros shells, no se puede devolver un array por razones de interoperabilidad).

Aquí hay un ejemplo:

ENABLEOVERVIEW=true; export ENABLEOVERVIEW;
EXTRAOVERVIEWADVERTISED='"Newsgroups" "Injection-Info"';
    export EXTRAOVERVIEWADVERTISED;
ORGANIZATION='Let'\''s try nasty "quotes"'; export ORGANIZATION;
MAXFORKS=10; export MAXFORKS;
-t
Imprime los parámetros como sentencias de asignación de Tcl. El nombre de la variable será el mismo que el nombre del parámetro de configuración pero con "inn_" delante, y las variables de cadena se escaparán apropiadamente. Los valores booleanos se mapearán a las cadenas "true" o "false". Los valores de lista se mapearán a un array de cadenas. Los valores NULL no se imprimen.

Aquí hay un ejemplo:

set inn_enableoverview "true"
set inn_extraoverviewadvertised { "Newsgroups" "Injection-Info" }
set inn_organization "Let's try nasty \"quotes\""
set inn_maxforks 10
-v
Imprime la versión de INN y sale. Esto es equivalente a "innconfval version".
