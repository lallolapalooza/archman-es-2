inotify_add_watch(2) Manual de llamadas al sistema inotify_add_watch(2)

NOMBRE

inotify_add_watch - añade una vigilancia a una instancia inotify inicializada

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <sys/inotify.h>
int inotify_add_watch(int fd, const char *path, uint32_t mask);

DESCRIPCIÓN

inotify_add_watch() añade una nueva vigilancia, o modifica una vigilancia existente, para el archivo cuya ubicación se especifica en path; el llamante debe tener permiso de lectura para este archivo. El argumento fd es un descriptor de archivo que hace referencia a la instancia inotify cuya lista de vigilancias debe modificarse. Los eventos a monitorizar para path se especifican en el argumento de máscara de bits mask. Vea inotify(7) para una descripción de los bits que se pueden establecer en mask.

Una llamada exitosa a inotify_add_watch() devuelve un descriptor de vigilancia único para esta instancia inotify, para el objeto del sistema de archivos (inodo) que corresponde a path. Si el objeto del sistema de archivos no estaba siendo vigilado previamente por esta instancia inotify, entonces el descriptor de vigilancia se asigna de nuevo. Si el objeto del sistema de archivos ya estaba siendo vigilado (quizás a través de un enlace diferente al mismo objeto), entonces se devuelve el descriptor para la vigilancia existente.

El descriptor de vigilancia se devuelve en las lecturas posteriores (read(2)) desde el descriptor de archivo inotify. Estas lecturas obtienen estructuras inotify_event (ver inotify(7)) que indican eventos del sistema de archivos; el descriptor de vigilancia dentro de esta estructura identifica el objeto para el cual ocurrió el evento.

VALOR DE RETORNO

En caso de éxito, inotify_add_watch() devuelve un descriptor de vigilancia (un entero no negativo). En caso de error, se devuelve -1 y se establece errno para indicar el error.

ERRORES

EACCES
No se permite el acceso de lectura al archivo dado.
EBADF
El descriptor de archivo dado no es válido.
EEXIST
mask contiene IN_MASK_CREATE y path se refiere a un archivo que ya está siendo vigilado por el mismo fd.
EFAULT
path apunta fuera del espacio de direcciones accesible del proceso.
EINVAL
La máscara de eventos dada no contiene eventos válidos; o mask contiene tanto IN_MASK_ADD como IN_MASK_CREATE; o fd no es un descriptor de archivo inotify.
ENAMETOOLONG
path es demasiado largo.
ENOENT
Un componente del directorio en path no existe o es un enlace simbólico colgante.
ENOMEM
No había suficiente memoria del kernel disponible.
ENOSPC
Se alcanzó el límite de usuario en el número total de vigilancias inotify o el kernel no pudo asignar un recurso necesario.
ENOTDIR
mask contiene IN_ONLYDIR y path no es un directorio.

ESTÁNDARES

Linux.

HISTORIA

Linux 2.6.13.

EJEMPLOS

Vea inotify(7).
