intro(3) Manual de Funciones de Librería intro(3)

NOMBRE

intro - introducción a las funciones de librería

DESCRIPCIÓN

La sección 3 del manual describe todas las funciones de librería excluyendo las funciones de librería (envoltorios de llamadas al sistema) descritas en la Sección 2, que implementan llamadas al sistema.

Muchas de las funciones descritas en la sección forman parte de la Librería Estándar de C (libc). Algunas funciones son parte de otras librerías (p. ej., la librería matemática, libm, o la librería de tiempo real, librt) en cuyo caso la página del manual indicará la opción del enlazador necesaria para enlazar contra la librería requerida (p. ej., -lm y -lrt, respectivamente, para las librerías mencionadas).

En algunos casos, el programador debe definir una macro de prueba de características para obtener la declaración de una función del archivo de cabecera especificado en la sección SYNOPSIS de la página del manual. (Donde se requiera, estas macros de prueba de características deben definirse antes de incluir cualquier archivo de cabecera.) En tales casos, la macro requerida se describe en la página del manual. Para más información sobre macros de prueba de características, ver feature_test_macros(7).

Subsecciones

La sección 3 de este manual está organizada en subsecciones que reflejan la compleja estructura de la librería estándar de C y sus muchas implementaciones:

•
3const
•
3head
•
3type

Esta difícil historia frecuentemente la convierte en un mal ejemplo a seguir en diseño, implementación y presentación.

Idealmente, una librería para el lenguaje C está diseñada de tal forma que cada archivo de cabecera presenta la interfaz de un módulo de software coherente. Proporciona un pequeño número de declaraciones de funciones y expone solo tipos de datos y constantes que son necesarios para el uso de esas funciones. Conjuntamente, estos se denominan API o interfaz de programa de aplicación. Los tipos y constantes que se compartirán entre múltiples API deberían colocarse en archivos de cabecera que no declaren funciones. Esta organización permite que un módulo de librería C sea documentado de forma concisa con un archivo de cabecera por página de manual. Tal enfoque mejora la legibilidad y accesibilidad de la documentación de la librería, y por lo tanto la usabilidad del software.

ESTÁNDARES

Ciertos términos y abreviaturas se usan para indicar variantes de UNIX y estándares a los que se ajustan las llamadas en esta sección. Ver standards(7).

NOTAS

Autores y condiciones de copyright

Mire el encabezado del código fuente de la página del manual para el(los) autor(es) y las condiciones de copyright. ¡Tenga en cuenta que estas pueden ser diferentes de una página a otra!
