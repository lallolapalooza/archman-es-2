INPUTLEAPS(1) Comandos de usuario INPUTLEAPS(1)

NOMBRE

input-leap - Servidor de teclado/ratón InputLeap

SINOPSIS

input-leap [--address <dirección>] [--config <ruta_archivo>] [--display <pantalla>] [--daemon|--no-daemon] [--name <nombre_pantalla>] [--restart|--no-restart] [--debug <nivel>]

DESCRIPCIÓN

Inicia el componente servidor de InputLeap.

OPCIONES

-a, --address <dirección>
escucha a los clientes en la dirección dada.
-c, --config <ruta_archivo>
usa el archivo de configuración nombrado en su lugar.
-d, --debug <nivel>
filtra los mensajes de registro con prioridad inferior al nivel. El nivel puede ser: FATAL, ERROR, WARNING, NOTE, INFO, DEBUG, DEBUG1, DEBUG2.
-n, --name <nombre_pantalla> usa nombre_pantalla en lugar del nombre de host para identificar
esta pantalla en la configuración.
-1, --no-restart
no intentes reiniciar en caso de fallo.
--restart
reinicia el servidor automáticamente si falla. (*)
-l --log <archivo>
escribe los mensajes de registro en el archivo.
--no-tray
deshabilita el icono de la bandeja del sistema.
--enable-drag-drop
habilita la arrastrar y soltar archivos.
--enable-crypto
habilita el plugin criptográfico (ssl).
--display <pantalla>
conéctate al servidor X en <pantalla>
--screen-change-script <ruta>
ruta completa al script para ejecutar en caso de cambio de pantalla; el primer argumento es el nuevo nombre de pantalla.
-f, --no-daemon
ejecutar en primer plano.
--daemon
ejecutar como demonio. (*)
-h, --help
muestra esta ayuda y sale.
--version
muestra la información de la versión y sale.

Las opciones por defecto están marcadas con un *

El argumento para --address tiene el formato: [<nombre_host>][:<puerto>]. El nombre_host debe ser la dirección o nombre de host de una interfaz del sistema. Se requiere colocar corchetes alrededor de una dirección IPv6 cuando también se especifica un número de puerto y es opcional en otros casos. El valor predeterminado es escuchar en todas las interfaces usando el número de puerto 24800.

ARCHIVOS

Si no se proporciona una ruta de archivo de configuración, el primero de los siguientes que se cargue con éxito establecerá la configuración:

$HOME/.config/InputLeap/input-leap.conf
/etc/input-leap.conf
