NOMBRE

incrontab - manipulador de tablas para inotify cron (incron)

SINOPSIS

incrontab [-u usuario] [-f config] archivo

incrontab [-u usuario] [-f config] [-l | -r | -e | -t | -d]

DESCRIPCIÓN

incrontab es un manipulador de tablas para el sistema inotify cron (incron). Crea, elimina, modifica y lista tablas de usuario (incrontab(5)).

Cada usuario (incluyendo incluso usuarios del sistema sin directorios personales) tiene una tabla incron que no puede ser manipulada directamente (solo root puede cambiar efectivamente estas tablas y NO se recomienda hacerlo).

Todos los mensajes informativos de este programa se imprimen en la salida de error estándar (stderr).

Si existe /etc/incron.allow, solo los usuarios listados aquí pueden usar incron. De lo contrario, si existe /etc/incron.deny, solo los usuarios NO listados aquí pueden usar incron. Si ninguno de estos archivos existe, todos pueden usar incron. (Nota importante: Este comportamiento no es seguro y probablemente se cambiará para ser compatible con el estilo utilizado por ISC Cron.) La ubicación de estos archivos se puede cambiar en la configuración.

La primera forma de este comando importa un archivo, lo valida y lo almacena en la tabla. Se puede usar "-" para cargar desde la entrada estándar.

La opción -u (o --user) anula el usuario actual (real) por el dado. Esta opción está destinada a la manipulación de tablas de usuarios del sistema (como apache, postfix, daemon, etc.). Solo se puede usar si el usuario actual tiene derechos efectivos de root.

La opción -l (o --list) hace que la tabla actual se imprima en la salida estándar.

La opción -r (o --remove) hace que la tabla actual (si la hay) se elimine permanentemente sin ninguna advertencia o confirmación. ¡Úselo con precaución!

La opción -e (o --edit) hace que se ejecute un editor para editar la tabla del usuario (ver más abajo para obtener información sobre la selección del editor). Ahora puede editar su tabla incron. Si la tabla se cambia, almacena la versión modificada.

La opción -t (o --types) hace que la lista de tipos de evento compatibles (delimitados por comas) se imprima en la salida estándar. Esta función está destinada a aplicaciones frontales para averiguar qué tipos de eventos se compilaron.

La opción -d (o --reload) hace que la tabla actual sea recargada por incrond(8). Esto se hace "tocando" la tabla (escribiendo en ella sin modificarla). Esta función está destinada, por ejemplo, a crear monitores en archivos recién creados (con reglas ya existentes) o para reactivar monitores IN_ONESHOT.

La opción -f <ARCHIVO> (o --config=<ARCHIVO>) especifica otra ubicación para el archivo de configuración (se usa /etc/incron.conf por defecto). Esta función requiere privilegios de root.

Existe un algoritmo complejo para determinar qué editor se usará para la edición. Si alguna de las siguientes reglas tiene éxito, se utiliza el editor apropiado:

1. Variable de entorno EDITOR

2. Variable de entorno VISUAL

3. Valor de configuración

4. etc/alternatives/editor

5. Editor fijo (vim por defecto)

No se recomienda el uso de editores gráficos (como gVim, KEdit, etc.) debido a posibles problemas de conexión al servidor X.

VER TAMBIÉN

incrond(8), incrontab(5), incron.conf(5)
