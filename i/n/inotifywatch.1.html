EVENTOS

open
Se abrió un archivo o directorio vigilado.
moved_to
Se movió un archivo o directorio a un directorio vigilado. Este evento ocurre incluso si el archivo simplemente se mueve dentro y fuera del mismo directorio.
moved_from
Se movió un archivo o directorio desde un directorio vigilado. Este evento ocurre incluso si el archivo simplemente se mueve dentro y fuera del mismo directorio.
move
Se movió un archivo o directorio hacia o desde un directorio vigilado. Tenga en cuenta que esto se implementa simplemente escuchando tanto moved_to como moved_from, por lo tanto, todos los eventos de cierre recibidos se emitirán como uno o ambos de estos, no como MOVE.
move_self
Se movió un archivo o directorio vigilado. Después de este evento, el archivo o directorio ya no está siendo vigilado.
create
Se creó un archivo o directorio dentro de un directorio vigilado.
delete
Se eliminó un archivo o directorio dentro de un directorio vigilado.
delete_self
Se eliminó un archivo o directorio vigilado. Después de este evento, el archivo o directorio ya no está siendo vigilado. Tenga en cuenta que este evento puede ocurrir incluso si no se está escuchando explícitamente.
unmount
Se desmontó el sistema de archivos en el que reside un archivo o directorio vigilado. Después de este evento, el archivo o directorio ya no está siendo vigilado. Tenga en cuenta que este evento puede ocurrir incluso si no se está escuchando explícitamente.

ADVERTENCIAS

Al usar inotifywatch, el nombre de archivo que se emite no está garantizado que esté actualizado después de una move porque es el inode lo que se está monitoreando. Adicionalmente, ninguna de las operaciones observadas está garantizada que se haya realizado en el nombre de archivo que inotifywatch recibió instrucciones para monitorear en casos en que el archivo sea conocido por varios nombres en el sistema de archivos.

ERRORES

Existen condiciones de carrera en el código de vigilancia recursiva de directorios que pueden hacer que se pierdan eventos si ocurren en un directorio inmediatamente después de que ese directorio se crea. Esto probablemente no sea solucionable.

Se asume que la cola de eventos de inotify nunca se desbordará.
