insque(3) Manual de Funciones de Biblioteca insque(3)

NOMBRE

insque, remque - insertar/eliminar un elemento de una cola

BIBLIOTECA

Biblioteca C estándar (libc,-lc)

SINOPSIS

#include <search.h>
void insque(void *elem, void *prev);
void remque(void *elem);
Requisitos de la macro de prueba de características para glibc (ver feature_test_macros(7)):

insque(), remque():

    _XOPEN_SOURCE >= 500
        || /* glibc >= 2.19: */ _DEFAULT_SOURCE
        || /* glibc <= 2.19: */ _SVID_SOURCE

DESCRIPCIÓN

Las funciones insque() y remque() manipulan listas doblemente enlazadas. Cada elemento de la lista es una estructura de la que los dos primeros elementos son un puntero hacia adelante y un puntero hacia atrás. La lista enlazada puede ser lineal (es decir, puntero hacia adelante NULL al final de la lista y puntero hacia atrás NULL al inicio de la lista) o circular.

La función insque() inserta el elemento al que apunta elem inmediatamente después del elemento al que apunta prev.

Si la lista es lineal, entonces la llamada insque(elem, NULL) puede usarse para insertar el elemento inicial de la lista, y la llamada establece los punteros hacia adelante y hacia atrás de elem a NULL.

Si la lista es circular, el llamador debe asegurarse de que los punteros hacia adelante y hacia atrás del primer elemento estén inicializados para apuntar a ese elemento, y el prev argumento de la insque() llamada debe también apuntar al elemento.

La función remque() elimina el elemento al que apunta elem de la lista doblemente enlazada.

VERSIONES

En sistemas antiguos, los argumentos de estas funciones eran de tipo struct qelem *, definido como:


struct qelem {
    struct qelem *q_forw;
    struct qelem *q_back;
    char          q_data[1];
};

Esto es lo que seguirá obteniendo si _GNU_SOURCE está definido antes de incluir <search.h>.

La ubicación de los prototipos de estas funciones difiere entre varias versiones de UNIX. La anterior es la versión POSIX. Algunos sistemas las colocan en <string.h>.

ESTÁNDARES

POSIX.1-2008.

HISTORIA

POSIX.1-2001.

ERRORES

En glibc 2.4 y versiones anteriores, no era posible especificar prev como NULL. En consecuencia, para construir una lista lineal, el llamador tenía que construir una lista usando una llamada inicial que contenía los dos primeros elementos de la lista, con los punteros hacia adelante y hacia atrás en cada elemento adecuadamente inicializados.

EJEMPLOS

El programa siguiente demuestra el uso de insque(). Aquí está un ejemplo de ejecución del programa:


$ ./a.out -c a b c
Recorriendo lista completada:
    a
    b
    c
Esa era una lista circular

Fuente del programa

#include <search.h>
#include <stdio.h>
#include <stdlib.h>
#include <unistd.h>
struct element {
    struct element *forward;
    struct element *backward;
    char *name;
};
static struct element *
new_element(void)
{
    struct element *e;
    e = malloc(sizeof(*e));
    if (e == NULL) {
        fprintf(stderr, "malloc() failed\n");
        exit(EXIT_FAILURE);
    }
    return e;
}
int
main(int argc, char *argv[])
{
    struct element *first, *elem, *prev;
    int circular, opt, errfnd;
    /* The "-c" command-line option can be used to specify that the
       list is circular.  */
    errfnd = 0;
    circular = 0;
    while ((opt = getopt(argc, argv, "c")) != -1) {
        switch (opt) {
        case 'c':
            circular = 1;
            break;
        default:
            errfnd = 1;
            break;
        }
    }
    if (errfnd || optind >= argc) {
        fprintf(stderr,  "Usage: %s [-c] string...\n", argv[0]);
        exit(EXIT_FAILURE);
    }
    /* Create first element and place it in the linked list.  */
    elem = new_element();
    first = elem;
    elem->name = argv[optind];
    if (circular) {
        elem->forward = elem;
        elem->backward = elem;
        insque(elem, elem);
    } else {
        insque(elem, NULL);
    }
    /* Add remaining command-line arguments as list elements.  */
    while (++optind < argc) {
        prev = elem;
        elem = new_element();
        elem->name = argv[optind];
        insque(elem, prev);
    }
    /* Traverse the list from the start, printing element names.  */
    printf("Traversing completed list:\n");
    elem = first;
    do {
        printf("    %s\n", elem->name);
        elem = elem->forward;
    } while (elem != NULL && elem != first);
    if (elem == first)
        printf("That was a circular list\n");
    exit(EXIT_SUCCESS);
}
