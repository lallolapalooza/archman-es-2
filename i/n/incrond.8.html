NOMBRE

incrond - demonio de inotify cron (incron)

SINOPSIS

incrond [ -f archivo ] [ -n | -k ]

DESCRIPCIÓN

El demonio de inotify cron (incrond) es un demonio que monitorea eventos del sistema de archivos y ejecuta comandos definidos en tablas del sistema y del usuario. Su uso es generalmente similar al de cron(8).

incrond puede iniciarse desde /etc/rc, /etc/rc.local y similares. Se demoniza a sí mismo (retorna inmediatamente) y no necesita ser iniciado con & ni a través de nohup(1). También puede ejecutarse en primer plano.

incrond utiliza dos categorías de tablas incrontab(5). Las tablas del sistema se encuentran generalmente en /etc/incron.d y son mantenidas fuera de incron (por ejemplo, por diversas aplicaciones). Estas tablas funcionan a nivel de derechos de root, por lo que se puede vigilar cualquier archivo y los comandos se ejecutan con privilegios de root.

Las tablas de usuario se encuentran por defecto en /var/spool/incron y tienen nombres basados en las cuentas de usuario. Estas tablas utilizan los derechos de acceso de los usuarios, por lo que solo se vigilan los archivos a los que el usuario tiene acceso. Los comandos se ejecutan con los privilegios de los usuarios.

Si una tabla (incrontab) se modifica, incrond reacciona inmediatamente y recarga la tabla. Los procesos hijos en ejecución (comandos) no se ven afectados.

Hay dos archivos que determinan si un usuario tiene permiso para usar incron. Estos archivos tienen una sintaxis muy simple: un nombre de usuario por línea. Si existe /etc/incron.allow, el usuario debe estar anotado allí para tener permiso para usar incron. De lo contrario, si existe /etc/incron.deny, el usuario no debe estar anotado allí para usar incron. Si ninguno de estos archivos existe, no hay ninguna otra restricción para que alguien use incron. La ubicación de estos archivos se puede cambiar en la configuración.

El demonio en sí mismo no está protegido contra bucles en este momento. Si un comando ejecutado debido a un evento causa el mismo evento, esto lleva a un bucle infinito a menos que se especifique una máscara de banderas que contenga loopable=true. Por favor, tenga cuidado con esto y no permita el uso de incron a usuarios no confiables.

La opción -n (o --foreground) hace que se ejecute en primer plano. Esto es útil especialmente para pruebas, depuración y optimización.

La opción -k (o --kill) termina una instancia en ejecución de incrond.

La opción -f <ARCHIVO> (o --config=<ARCHIVO>) especifica una ubicación diferente para el archivo de configuración (por defecto se usa /etc/incron.conf).

Variables de entorno: Para las tablas del sistema, se utiliza el entorno por defecto (el mismo que para incrond). Lo mismo se aplica a la tabla de root. Para las tablas de usuario que no son de root, todo el entorno se limpia y luego solo se configuran estas variables: LOGNAME, USER, USERNAME, SHELL, HOME y PATH. Las variables (excepto PATH) toman valores de la base de datos de usuarios (por ejemplo, /etc/passwd). La variable PATH se establece en /usr/local/bin:/usr/bin:/bin:/usr/X11R6/bin.

VER TAMBIÉN

incrontab(1), incrontab(5), incron.conf(5)

ERRORES

incrond no es resistente a bucles en este momento.
