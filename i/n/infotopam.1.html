NOMBRE

infotopam - convertir iconos Amiga .info a PAM

SINOPSIS

infotopam [-forcecolor] [-numcolors numcolores] [-selected] [índice color ...] [archivo]

Se puede usar la abreviatura única mínima de la opción. Puede usar guiones dobles en lugar de un solo guion para indicar opciones. Puede usar espacios en blanco en lugar del signo igual para separar el nombre de una opción de su valor.

EJEMPLOS

Por defecto, infotopam convierte el primer icono en un archivo .info:

    infotopam amiga.info > amiga.primer.pam

Use la opción -selected para convertir el segundo icono en un archivo .info. Aquí infotopam lee desde la entrada estándar:

    infotopam -selected < amiga.info > amiga.segundo.pam

Use la opción -forcecolor para forzar la conversión a color para un archivo .info de 1 bit-plano:

    infotopam -forcecolor bw.info > bw.pam

Use -numcolors para anular los colores para los índices 0 y 3. Observe las dos formas de especificar el color:

    infotopam -numcolors 2 0 verde 3 #FF0000 icono.info > icono.pam

Dado que los monitores Amiga no utilizan píxeles cuadrados, algunos iconos pueden aparecer aplastados. Filtrar la salida a través de pamscale puede solucionar esto:

     infotopam squish.info | pamtopnm | pamscale -yscale 1.7 > normal.pnm

DESCRIPCION

Este programa es parte de Netpbm(1)

infotopam convierte un archivo .info (icono) de Amiga a una imagen PAM. infotopam lee un archivo .info desde archivo, o desde la entrada estándar si no se especifica un nombre de archivo, y escribe la imagen PAM convertida en la salida estándar.

infotopam actualmente maneja iconos de 1 y 2 bit-planos. Si el icono .info solo tiene 1 bit-plano, infotopam genera una imagen PAM de mapa de bits (blanco y negro); de lo contrario, genera una imagen PAM a color. Puede forzar a infotopam a convertir imágenes de 1 bit-plano a imágenes PAM a color usando la opción -forcecolor.

OPCIONES

-forcecolor

Fuerza a infotopam a convertir iconos de 1 bit-plano a imágenes PAM a
color en lugar de imágenes PAM de mapa de bits. infotopam usa el índice 2
de color para negro y el índice 1 de color para blanco (más sobre esto
a continuación).

-numcolors numcolores

Indica a infotopam cuántos colores anular. Los píxeles en los
archivos .info de Amiga se asignan un valor de índice en lugar de un color específico.
Los colores estándar para un icono de 2 bit-planos son:

    Índice 0:  Azul   (00, 55, AA)
    Índice 1:  Blanco  (FF, FF, FF)
    Índice 2:  Negro  (00, 00, 20)
    Índice 3:  Naranja (FF, 8A, 00)

Para anular los colores, primero especifique cuántos colores anular usando
-numcolors, luego especifique un par (índice color) para cada color
que desee anular, donde índice es un valor de 0 a 3 y
color el nuevo color para ese índice. Especifique color como
se describe para el argumento de ppm_parsecolor().

-selected

Indica a infotopam que convierta el icono seleccionado (segundo) en lugar del
icono normal (primero). Cada archivo de icono .info de Amiga contiene dos imágenes de
icono. La primera imagen es el icono normal, no seleccionado, y la segunda
imagen es el icono seleccionado. Por defecto infotopam convierte el primer
icono. Puede indicarle a infotopam que convierta el segundo icono usando la
opción -selected.

Todas las opciones pueden abreviarse a su prefijo único más corto.

El formato del archivo .info de Amiga es el siguiente:

    Cabecera DiskObject            78 bytes
    Cabecera opcional DrawerData   56 bytes
    Cabecera del primer icono      20 bytes
    Datos del primer icono        Varía
    Cabecera del segundo icono     20 bytes
    Datos del segundo icono       Varía

La cabecera DiskObject contiene, entre otras cosas, el número mágico (0xE310), el ancho y alto del objeto (dentro de la cabecera Gadget incrustada) y la versión.

Cada cabecera de icono contiene el ancho y alto del icono, que puede ser menor que el ancho y alto del objeto, y el número de bit-planos.

Los datos del icono tienen el siguiente formato:

BIT-PLANO planos, cada uno con ALTURA filas de (ANCHO
+15) / 16 * 2 bytes de longitud.

Así que si tienes un icono de 9x3x2, los datos del icono se verán así:

    aaaa aaaa a000 0000
    aaaa aaaa a000 0000
    aaaa aaaa a000 0000
    bbbb bbbb b000 0000
    bbbb bbbb b000 0000
    bbbb bbbb b000 0000

donde a es un bit para el primer bit-plano, b es un bit para el segundo bit-plano, y 0 es relleno. ¡Gracias de nuevo a Ben Hutchings por su útil publicación!

HISTORIAL

infotopam fue nuevo en Netpbm 10.22 (abril de 2004).

LIMITACIONES

infotopam actualmente solo maneja iconos de 1 y 2 bit-planos.

No existe un comando pamtoinfo, ya que los archivos .info contienen mucho más que solo datos de iconos, y mapear los colores sería difícil.
