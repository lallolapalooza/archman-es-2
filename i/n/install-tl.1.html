NOMBRE

install-tl - Instalador multiplataforma de TeX Live

SINOPSIS

install-tl [opción]...

install-tl-windows.bat [opción]...

DESCRIPCIÓN

Este instalador crea una instalación funcional de TeX Live a partir de diversos medios, incluyendo a través de la red, desde el disco duro local, un DVD, etc. El instalador funciona en todas las plataformas soportadas por TeX Live. Para obtener información sobre la descarga inicial de TeX Live, consulte https://tug.org/texlive/acquire.html.

La idea básica de la instalación de TeX Live es que elija uno de los esquemas de nivel superior, cada uno de los cuales se define como un conjunto diferente de colecciones y paquetes, donde una colección es un conjunto de paquetes y un paquete es lo que contiene los archivos reales. Cada paquete está en exactamente una colección, mientras que los esquemas pueden contener cualquier combinación de paquetes y colecciones.

Dentro del instalador, puede elegir un esquema y personalizar aún más el conjunto de colecciones a instalar, pero no el conjunto de paquetes. Para trabajar a nivel de paquete, use "tlmgr" (referencia justo debajo) después de que la instalación inicial se complete.

El valor predeterminado es "scheme-full", que instala todo, y esto es muy recomendable.

REFERENCIAS

La configuración post-instalación, las actualizaciones de paquetes y más, se manejan a través de tlmgr(1), el Gestor de TeX Live (https://tug.org/texlive/tlmgr.html).

La versión más actualizada de esta documentación del instalador está en Internet en https://tug.org/texlive/doc/install-tl.html.

Para obtener instrucciones paso a paso, consulte https://tug.org/texlive/quickinstall.html.

Para la documentación completa de TeX Live, consulte https://tug.org/texlive/doc.

EJEMPLOS

Sin opciones, "install-tl" le lleva a un menú interactivo donde se pueden cambiar esencialmente todas las configuraciones predeterminadas. Con opciones, puede inicializar la configuración de diversas maneras o realizar la instalación sin interacción. Algunos ejemplos:

"install-tl --paper=letter"
Inicializa la configuración del tamaño del papel. Los únicos valores permitidos son "letter" y (el predeterminado) "a4".
"install-tl --scheme" esquema
Inicializa el esquema de instalación; el valor predeterminado es "full". Para obtener una lista de esquemas, consulte el menú interactivo "S".
"install-tl --no-interaction"
Realiza la instalación inmediatamente después de analizar las opciones, sin entrar en el menú interactivo.
"install-tl --profile" texlive.profile
Instala, sin interacción, según el archivo de perfil de TL dado; vea "PERFILES" a continuación. Para inicializar desde el perfil y luego entrar en el menú interactivo, añada "--init-from-profile".

La documentación completa sigue a continuación.

OPCIONES

Como es habitual, todas las opciones se pueden especificar en cualquier orden y con un prefijo "-" o "--". Un valor de argumento puede separarse de su opción por un espacio o por "=".

Las opciones relacionadas con la personalización de la instalación también se pueden seleccionar en los menús interactivos de instalación (GUI o texto).

-gui [[=]módulo]
-no-gui
Si no se proporciona módulo, inicia el instalador gráfico Tcl/Tk (ver más abajo).

Si se proporciona módulo, carga el módulo instalador dado. Actualmente los siguientes módulos son soportados:

"text"
La interfaz de usuario en modo texto (predeterminado en sistemas Unix, incluidos los Mac). Igual que la opción "-no-gui".
"tcl" (o "perltk" o "wizard" o "expert" o nada)
La interfaz de usuario Tcl/Tk (predeterminada en Windows). Comienza con un pequeño número de opciones de configuración, aproximadamente equivalente a lo que ofrecía la antigua opción wizard, pero un botón "Avanzado" le lleva a una pantalla con aproximadamente las mismas opciones que la antigua interfaz "perltk".

La GUI predeterminada requiere Tcl/Tk. Esto era estándar en Mac, pero se ha eliminado en las últimas versiones de macOS. A menudo ya está instalado en GNU/Linux o se puede instalar fácilmente a través de un gestor de paquetes de distribución. Para Windows, TeX Live proporciona un entorno de ejecución Tcl/Tk.

-lang código_idioma
Por defecto, la GUI de Tcl utiliza la detección de idioma integrada en Tcl/Tk. Si falla, puede seleccionar un idioma diferente proporcionando esta opción con un código de idioma (basado en ISO 639-1). Actualmente soportados (pero no necesariamente completamente traducidos) son: Inglés (en, predeterminado), Checo (cs), Alemán (de), Francés (fr), Italiano (it), Japonés (ja), Holandés (nl), Polaco (pl), Portugués Brasileño (pt_BR), Ruso (ru), Eslovaco (sk), Esloveno (sl), Serbio (sr), Ucraniano (uk), Vietnamita (vi), Chino simplificado (zh_CN) y Chino tradicional (zh_TW).
-repository url|ruta
Especifica el repositorio de paquetes a utilizar como fuente de la instalación. En resumen, puede ser un nombre de directorio o una url usando http(s), ftp o scp. La documentación de "tlmgr" tiene los detalles (https://tug.org/texlive/doc/tlmgr.html#OPTIONS).

Para la instalación, el valor predeterminado es elegir un espejo automáticamente, utilizando https://mirror.ctan.org/systems/texlive/tlnet; el espejo elegido se utilizará para toda la descarga. Puede usar el argumento especial "ctan" como abreviatura para esto. (Ver https://ctan.org para más sobre CTAN y sus espejos.)

Después de completar la instalación, puede usar esa instalación como repositorio para otra instalación. Si eligió instalar menos que el esquema completo que contiene todos los paquetes, la lista de esquemas disponibles se ajustará en consecuencia.

-select-repository
Esta opción le permite elegir un espejo particular de la lista actual de espejos activos de CTAN. Esta opción es compatible con los modos de instalación "text" y "gui", y también ofrecerá instalar desde medios locales si están disponibles, o desde un repositorio especificado en la línea de comandos. Es útil cuando la redirección automática (predeterminada) no le elige un buen host.
-all-options
Normalmente, las opciones no relevantes para la plataforma actual no se muestran (por ejemplo, cuando se ejecuta en Unix, se omiten las opciones específicas de Windows). Proporcionar esta opción de línea de comandos permite configurar dichas configuraciones "foráneas".
-custom-bin ruta
Si ha compilado su propio conjunto de binarios de TeX Live (por ejemplo, porque no se proporcionaron binarios precompilados por TL para su plataforma), esta opción le permite especificar la ruta a un directorio donde están presentes los binarios para el sistema actual. La instalación continuará como de costumbre, pero al final todos los archivos de ruta se copiarán a "bin/custom/" bajo su directorio de instalación y este directorio "bin/custom/" será lo que se añada a la ruta para las acciones post-instalación. PERFILE

S

Un archivo de perfil normalmente contiene todos los valores necesarios para realizar una instalación. Después de que finalice una instalación normal, se escribe un perfil para esa instalación exacta en el archivo "tlpkg/texlive.profile". Además, desde el menú de texto se puede seleccionar "P" para guardar la configuración actual como un perfil en cualquier momento. Estos son pequeños archivos de texto; siéntase libre de examinarlos y editarlos según sus

necesidades.

Un archivo de perfil de este tipo puede darse como argumento a "-profile", por ejemplo, para repetir exactamente la misma instalación en un sistema diferente. Alternativamente, puede usar un perfil personalizado, creado más fácilmente a partir de uno generado y cambiando valores. Un archivo de perfil vacío hará que el instalador use los valores predeterminados

.

Como se mencionó anteriormente, el instalador solo admite la selección por esquema y colecciones, no paquetes individuales, por lo que los paquetes tampoco pueden especificarse en los archivos de perfil. Use "tlmgr" para trabajar a nivel de

paquete.

Dentro de un archivo de perfil, cada línea consiste

en

variable [valor

]

excepto para las líneas de comentario que comienzan con "#". Los posibles nombres de variables se enumeran a continuación. Los valores, cuando están presentes, son 0 o 1 para booleanos, o cadenas de texto (que deben especificarse sin ningún carácter de comilla). Se ignora el espacio en blanco

inicial.

Si la variable "selected_scheme" está definida y no hay variables de colección definidas en absoluto, entonces se instalan las colecciones requeridas por el esquema especificado (lo cual puede cambiar con el tiempo), sin listarlas explícitamente. Esto facilita el mantenimiento de los archivos de perfil. Sin embargo, si se especifican algunas colecciones en un perfil, el esquema se ignora y todas las colecciones deseadas deben darse

explícitamente.

Por ejemplo, una

línea 
selected_scheme
scheme-small

junto con las definiciones de los directorios de instalación (dadas a continuación en "opciones de ruta") es suficiente para instalar el esquema "small" con todas las opciones predeterminadas. Los esquemas se describen en el menú "S" del instalador de texto, o

equivalente.

ÁRBOLES DE

DIRECTORIOS

Existe una gran cantidad de formas de especificar la gran cantidad de árboles de directorios utilizados por TeX Live. Con diferencia, el enfoque más sencillo, y el recomendado, es no cambiar nada. Los valores predeterminados son suficientes para la gran mayoría de

instalaciones.

Pero, para mayor claridad, aquí hay una tabla de los árboles y las opciones de la línea de comandos que los modifican. El primer grupo de tres son directorios del sistema, y el segundo grupo de tres son directorios de usuario; los dos grupos son bastante

análogos. 
+----------------+--------------------------------------+--------------+------------------+
|    árbol       | predeterminado                       | cambio grupo | cambio individual|
+----------------+--------------------------------------+--------------+------------------+
| TEXMFLOCAL     | /usr/local/texlive/texmf-local       | --texdir     | --texmflocal     |
| TEXMFSYSVAR    | /usr/local/texlive/YYYY/texmf-var    | --texdir     | --texmfsysvar    |
| TEXMFSYSCONFIG | /usr/local/texlive/YYYY/texmf-config | --texdir     | --texmfsysconfig |
+----------------+--------------------------------------+--------------+------------------+
| TEXMFHOME      | ~/texmf                              | --texuserdir | --texmfhome      |
| TEXMFVAR       | ~/.texliveYYYY/texmf-var             | --texuserdir | --texmfvar       |
| TEXMFCONFIG    | ~/.texliveYYYY/texmf-config          | --texuserdir | --texmfconfig    |
+----------------+--------------------------------------+--------------+------------------
+

Además, como se mencionó en la sección anterior, cada árbol tiene una variable de entorno "TEXLIVE_INSTALL_"árbol que anula el valor predeterminado; la línea de comandos y la configuración del perfil anulan la configuración de las variables de

entorno.

Los valores predeterminados varían ligeramente en Macs, como se explicó arriba en

"OPTIONS".

Para los árboles de usuario, el valor predeterminado utiliza "~", y esto se deja como un literal "~" en "texmf.cnf". De esa manera, cada usuario puede tener su propio "TEXMFHOME", etc., como se pretendía. Por otro lado, para los árboles del sistema, si "~" se utiliza durante la instalación, se asume que simplemente es una abreviatura de escritura, y el directorio de inicio expandido se escribe en "texmf.cnf", ya que no tiene sentido tener directorios del sistema específicos para cada

usuario.

Para obtener más información sobre los árboles de directorios y su uso previsto, consulte la documentación principal de TeX Live en https://tug.or

g/texli

ERRORE

S

El script "install-tl" se copia a sí mismo en el árbol instalado. Normalmente, se puede ejecutar desde allí, utilizando el árbol instalado como fuente para otra instalación. Sin embargo, ocasionalmente puede haber incompatibilidades en el código del nuevo "install-tl" y la infraestructura, lo que resulta en errores de Perl (probablemente) inescrutables. La solución es ejecutar "install-tl" desde el paquete del instalador ("install-tl-unx.tar.gz" o "install-tl.zip") en lugar de desde la instalación. No dude en informar del problema también; normalmente el código puede sincronizarse fácilmente de

nuevo.

Por cierto, no intente usar "install-tl" para ajustar opciones o paquetes instalados en un árbol instalado existente. Utilice "tlmgr" en

su l
ugar.
