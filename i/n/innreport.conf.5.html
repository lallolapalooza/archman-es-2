DESCRIPCIÓ

N

El archivo pathetc/innreport.conf permite configurar el comportamiento de innreport. Consiste en una serie de líneas; se ignoran las líneas en blanco y lo que sigue a un signo de número ("#") en una línea. La estructura de este archivo

es: 
section default {
    libpath             "/ruta/a/las/bibliotecas";
    logpath             "/ruta/a/los/registros";
    module              "innreport_inn";
    display_conf_file   "innreport-display.conf";
    unwanted_log        "unwanted.log";
    text                true;
    html                true;  # Habilitar informes HTML.
    # Otras opciones a configurar.
}
;

Solo esta sección default necesita ser configurada. Comienza con "section default {" y termina con "};". Cada línea de la sección consta de un nombre de opción seguido de uno o más espacios o tabulaciones, su valor y un punto y coma ";"

.

La opción display_conf_file define el nombre del archivo de configuración de visualización a utilizar. Este archivo, ubicado en libpath, tiene la misma sintaxis que innreport.conf. Si desea usar una configuración de visualización personalizada, simplemente renombre el archivo predeterminado innreport-display.conf a otro nombre, y configúrelo en display_conf_file (de lo contrario, innreport-display.conf será sobrescrito cada vez que actualice INN)

.

Las secciones definidas en el archivo de configuración de visualización se usan para parametrizar la visualización, cómo y qué informar, pero normalmente no deberían cambiarse (a menos que sepa exactamente lo que está haciendo). Estas secciones están escritas en un lenguaje específico del dominio que no está destinado a ser modificado (puede romper los informes, especialmente si cambia los parámetros data, double, format, primary, sort, total o value ). Los parámetros más fáciles de cambiar, si es necesario,

serían:
  • title (los títulos de las secciones en innrepo
    • rt),
  • name (los nombres de las columnas)
    • ,
  • color (el color de las curvas en los gráficos)
    • ,
  • numbering (un valor booleano para configurar si cada fila de los informes HTML está precedida por un número de rango)
    • ,
  • text, html y skip (valores booleanos para configurar si una sección determinada debe estar presente en los informes de texto, HTML o ambos respectivamente)
    • ,
  • top (el número máximo de valores a mostrar); puede especificar valores diferentes para los informes de texto y HTML con top_text y top_
    • h
tm
