INNERNET-SERVER(8) Utilidades de administración del sistema INNERNET-SERVER(8)

NOMBRE

innernet-server - página del manual para innernet-server 1.7.1

SINOPSIS

innernet-server [OPCIONES] <COMANDO>

DESCRIPCIÓN

Un servidor para coordinar redes innernet.

Comandos:

new
Crear una nueva red
uninstall
Desinstalar permanentemente una red creada, haciéndola inutilizable. Usar con precaución
serve
Servir el servidor coordinador para una red existente
add-peer
Agregar un par a una red existente
disable-peer
Deshabilitar un par habilitado
enable-peer
Habilitar un par deshabilitado
rename-peer
Renombrar un par existente
add-cidr
Agregar un nuevo CIDR a una red existente
rename-cidr
Renombrar un CIDR existente
delete-cidr
Eliminar un CIDR
completions
Generar scripts de compleción de shell
help
Imprimir este mensaje o la ayuda del subcomando(s) dado(s)

OPCIONES

-c, --config-dir <DIRECTORIO_CONFIG>
[predeterminado: /etc/innernet-server]
-d, --data-dir <DIRECTORIO_DATOS>
[predeterminado: /var/lib/innernet-server]
--no-routing
Si el enrutamiento debe ser realizado por innernet o por una herramienta externa como, por ejemplo, babeld
--backend <BACKEND>
Especificar un backend de WireGuard a usar. Si no se establece, innernet seleccionará automáticamente según la disponibilidad [predeterminado: kernel] [valores posibles: kernel, userspace]
--mtu <MTU>
Especificar la MTU deseada para tu interfaz (predeterminado: 1280)
-h, --help
Imprimir ayuda
-V, --version
Imprimir versión
