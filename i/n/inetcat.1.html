inetcat(1) Manual de comandos generales inetcat(1)

NOMBRE

inetcat - Abre una interfaz de lectura/escritura a través de STDIN/STDOUT a un puerto TCP en un dispositivo usbmux

SINOPSIS

inetcat [OPCIONES] <PUERTO_TCP_DISPOSITIVO>

DESCRIPCIÓN

inetcat es una herramienta simple similar a netcat que permite abrir una interfaz de lectura/escritura a un puerto TCP en un dispositivo usbmux y exponerla a través de STDIN/STDOUT.

OPCIONES

-u, --udid UDID
Dirigirse a un dispositivo específico por UDID. Tenga en cuenta que si esta opción *no* se especifica, inetcat se conectará al primer dispositivo encontrado.
-n, --network
Conectarse a un dispositivo de red. El dispositivo necesita tener habilitada la sincronización WiFi y estar emparejado con este ordenador para que esto funcione. Tenga en cuenta que un dispositivo puede cerrar conexiones en cualquier momento para ahorrar energía. Esta opción hará que inetcat se conecte solo a dispositivos conectados a la red, a menos que también se pase -l (ver más abajo).
-l, --local
Conectarse a un dispositivo USB. Esta es la opción predeterminada si no se pasa ninguna opción. Si se usa junto con -n, inetcat primero intentará conectarse a un dispositivo conectado a través de USB y, si no está disponible, intentará alcanzar un dispositivo a través de la red.
-h, --help
Imprime información de uso.
-d, --debug
Aumentar el nivel de depuración.

EJEMPLO

Usar ssh ProxyCommand para conectarse a un dispositivo iOS con jailbreak a través de SSH:

$ ssh -oProxyCommand="inetcat 22" root@localhost

Usado en el archivo de configuración de SSH para conectarse a un dispositivo iOS:

$ cat ~/.ssh/config Host myiphone
User root
ProxyCommand "icat 22 UDID_de_mi_iphone" $ ssh myiphone
