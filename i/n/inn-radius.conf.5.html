NOMBRE

inn-radius.conf - Configuración del autenticador RADIUS de nnrpd

DESCRIPCIÓN

Describe el formato y los atributos del archivo de configuración para el autenticador RADIUS de nnrpd. Consulte radius(8) para obtener más información sobre el programa autenticador. La ubicación predeterminada para este archivo es inn-radius.conf en pathetc.

Las líneas en blanco y las líneas que comienzan con "#" se ignoran, al igual que cualquier cosa después de un "#" en una línea. Todas las demás líneas deben comenzar con un nombre de parámetro seguido de dos puntos y el valor de esa clave, excepto que cada sección de configuración para un servidor particular debe estar encerrada en:

server <nombre> {
    # parámetros...
}

donde <nombre> es solo una etiqueta conveniente para ese servidor.

PARÁMETROS DE GRUPO DE SERVIDORES

Los parámetros disponibles son:

radhost
El nombre de host del servidor RADIUS a utilizar para la autenticación. Este parámetro debe establecerse.
radport
El puerto a consultar en el servidor RADIUS. Por defecto es 1645 si no se establece.
lochost
El nombre de host o la dirección IP que realiza la solicitud. El servidor RADIUS espera una dirección IP; un nombre de host se traducirá a una dirección IP con gethostbyname(). Si no se proporciona, esta información no se incluye en la solicitud (no todas las configuraciones de RADIUS requieren esta información).
locport
El puerto al que se está conectando el lector que se está autenticando. Si no se proporciona, por defecto es 119. Esto no necesita configurarse a menos que los lectores se conecten a un puerto no estándar.
secret
El secreto compartido con el servidor RADIUS. Si su secreto incluye espacios, tabulaciones o "#", asegúrese de incluirlo entre comillas dobles. Este parámetro debe establecerse.
prefix
Anteponer el valor de este parámetro a todos los nombres de usuario antes de pasarlos al servidor RADIUS. Se puede utilizar para anteponer algo como "news-" a todos los nombres de usuario para colocar a los usuarios de noticias en un espacio de nombres diferente al de otras cuentas atendidas por el mismo servidor. Si no se establece, no se antepone nada.
suffix
Añadir el valor de este parámetro a todos los nombres de usuario antes de pasarlos al servidor RADIUS. A menudo, esto es algo como "@example.com", dependiendo de cómo esté configurado su servidor RADIUS. Si no se establece, no se añade nada.
ignore-source
Se puede establecer en "true", "yes", "on", "false", "no" u "off". Si se establece en false, el autenticador RADIUS verificará que la respuesta que recibe sea de la misma dirección IP a la que envió la solicitud (para mayor seguridad). Si se establece en true, omitirá esta verificación (si su servidor RADIUS tiene múltiples direcciones IP o si ocurren otras cosas extrañas, puede ser perfectamente normal que la respuesta provenga de una dirección IP diferente).

EJEMPLO

Aquí hay una configuración para un servidor de noticias llamado news.example.com, que autentica a los usuarios contra radius.example.com y añade "@example.com" a todos los nombres de usuario proporcionados por el cliente antes de pasarlos al servidor RADIUS:

server example {
    radhost: radius.example.com
    lochost: news.example.com
    secret: IamARADIUSsecRET
    suffix: @example.com
}

El secreto compartido con el servidor RADIUS es "IamARADIUSsecRET".
