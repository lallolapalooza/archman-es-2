NOMBRE

intro - atributos de C/C++

SINOPSIS

[[attr]]
[[proveedor::attr]]

DESCRIPCIÓN

Los atributos modifican las propiedades de una construcción de código fuente, como un tipo, una variable o una función.

La sintaxis estándar permite especificar un proveedor para atributos no estándar.

VERSIONES

Los dialectos de C y C++ han proporcionado varias formas de atributos antes de la estandarización.

__attribute__((attr))
Esta es la sintaxis de GNU para atributos. Es compatible tanto con GCC como con Clang.
__declspec(attr)
Esta es la sintaxis de MSVC para atributos. Es compatible con Clang.

ESTÁNDARES

C23, C++23.

HISTORIA

[[attr]]
[[proveedor::attr]]
C23, C++11.
[[attr]]
[[gnu::attr]]
gcc 10, g++ 9, clang 9, clang++ 9.
__attribute__((attr))
gcc, g++, clang, clang++.
__declspec(attr)
clang, clang++.
