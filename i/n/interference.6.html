NOMBRE

interference - ondas sinusoidales decrecientes

SINOPSIS

interference [--display host:display.screen] [--visual visual] [--window] [--root] [--window-id número] [--count número] [--gridsize número] [--delay número] [--speed número] [--radius número] [--ncolors número] [--color-shift número] [--hue número] [--no-db] [--fps]

DESCRIPCIÓN

Otro truco de campo de color, este funciona calculando ondas sinusoidales decrecientes y permitiendo que interfieran entre sí a medida que sus orígenes se mueven.

OPCIONES

--visual visual
Especificar qué visual usar. Los valores legales son el nombre de una clase visual o el número de id (decimal o hexadecimal) de un visual específico.
--window
Dibujar en una ventana recién creada. Este es el valor predeterminado.
--root
Dibujar en la ventana raíz.
--window-id número
Dibujar en la ventana especificada.
--count número
Número de Ondas. 0 - 20. Predeterminado: 3.
--gridsize número
Magnificación. 1 - 20. Predeterminado: 2.
--delay número
Retardo por fotograma, en microsegundos. Predeterminado: 30000 (0.03 segundos).
--speed número
Velocidad de la Onda. 1 - 100. Predeterminado: 30.
--radius número
Tamaño de la Onda. 50 - 1500. Predeterminado: 800.
--ncolors número
Número de Colores. Predeterminado: 192.
--color-shift número
Contraste de Color. 0 - 100. Predeterminado: 60.
--hue número
Tono del color base (0-360, como en el espacio HSV). Predeterminado 0, que significa aleatorio.
--db | --no-db
Si se debe usar doble búfer.
--fps
Mostrar la tasa de fotogramas actual y la carga de la CPU.

AMBIENTE

DISPLAY
para obtener el host y el número de pantalla predeterminados.
XENVIRONMENT
para obtener el nombre de un archivo de recursos que anula los recursos globales almacenados en la propiedad RESOURCE_MANAGER.
XSCREENSAVER_WINDOW
El ID de la ventana a usar con --root.

VER TAMBIÉN

X(1), xscreensaver(1)
