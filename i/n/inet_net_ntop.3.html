inet_net_pton(3) Manual de Funciones de Biblioteca inet_net_pton(3)

NOMBRE

inet_net_pton, inet_net_ntop - Conversión de números de red de Internet

BIBLIOTECA

Biblioteca de resolución (libresolv,-lresolv)

SINOPSIS

#include <arpa/inet.h>
int inet_net_pton(size_t nsize;
                  int af, const char *pres,
                  void netp[nsize], size_t nsize);
char *inet_net_ntop(int bits, size_t psize;
                  int af,
                  const void netp[(bits - CHAR_BIT + 1) / CHAR_BIT],
                  int bits,
                  char pres[psize], size_t psize);
Requisitos de la macro de prueba de características para glibc (ver feature_test_macros(7)):

inet_net_pton(), inet_net_ntop():

    Desde glibc 2.20:
        _DEFAULT_SOURCE
    Antes de glibc 2.20:
        _BSD_SOURCE || _SVID_SOURCE

DESCRIPCIÓN

Estas funciones convierten números de red entre el formato de presentación (es decir, imprimible) y el formato de red (es decir, binario).

Para ambas funciones, af especifica la familia de direcciones para la conversión; el único valor soportado es AF_INET.

inet_net_pton()

La inet_net_pton() función convierte pres, una cadena terminada en nulo que contiene un número de red de Internet en formato de presentación a formato de red. El resultado de la conversión, que está en orden de bytes de red, se coloca en el búfer apuntado por netp. (El netp argumento típicamente apunta a una in_addr estructura.) El nsize argumento especifica el número de bytes disponibles en netp.

En caso de éxito, inet_net_pton() devuelve el número de bits en el campo de número de red del resultado colocado en netp. Para una discusión del formato de presentación de entrada y el valor de retorno, ver NOTAS.

Nota: el búfer apuntado por netp debe ser puesto a cero antes de llamar a inet_net_pton(), ya que la llamada escribe solo tantos bytes como sean necesarios para el número de red (o como sean explícitamente especificados por pres), lo cual puede ser menos que el número de bytes en una dirección de red completa.

inet_net_ntop()

La inet_net_ntop() función convierte el número de red en el búfer apuntado por netp a formato de presentación; *netp es interpretado como un valor en orden de bytes de red. El bits argumento especifica el número de bits en el número de red en *netp.

La cadena de presentación terminada en nulo se coloca en el búfer apuntado por pres. El psize argumento especifica el número de bytes disponibles en pres. La cadena de presentación está en formato CIDR: un número decimal con puntos que representa la dirección de red, seguido por una barra, y el tamaño del número de red en bits.

VALOR DE RETORNO

En caso de éxito, inet_net_pton() devuelve el número de bits en el número de red. En caso de error, devuelve -1, y errno se establece para indicar el error.

En caso de éxito, inet_net_ntop() devuelve pres. En caso de error, devuelve NULL, y errno se establece para indicar el error.

ERRORES

EAFNOSUPPORT
af especificó un valor diferente de AF_INET.
EMSGSIZE
El tamaño del búfer de salida era insuficiente.
ENOENT
(inet_net_pton()) pres no estaba en el formato de presentación correcto.

ESTÁNDARES

Ninguno.

NOTAS

Formato de presentación de entrada para inet_net_pton()

El número de red puede ser especificado ya sea como un valor hexadecimal o en notación decimal con puntos.

Los valores hexadecimales se indican con un "0x" inicial o "0X". Los dígitos hexadecimales llenan los nibbles (medios octetos) del número de red de izquierda a derecha en orden de bytes de red.

En notación decimal con puntos, se especifican hasta cuatro octetos, como números decimales separados por puntos. Así, cualquiera de las siguientes formas son aceptadas:


a.b.c.d
a.b.c
a.b
a

Cada parte es un número en el rango 0 a 255 que llena un byte del número de red resultante, yendo de izquierda a derecha, en orden de bytes de red (big endian). Donde una parte es omitida, el byte resultante en el número de red es cero.

Ya sea para el formato hexadecimal o decimal con puntos, el número de red puede ser seguido opcionalmente por una barra y un número en el rango 0 a 32, que especifica el tamaño del número de red en bits.

Valor de retorno de inet_net_pton()

El valor de retorno de inet_net_pton() es el número de bits en el campo de número de red. Si la cadena de presentación de entrada termina con una barra y un valor de tamaño explícito, entonces ese tamaño se convierte en el valor de retorno de inet_net_pton(). De lo contrario, el valor de retorno, bits, se infiere de la siguiente manera:

•
Si el byte más significativo del número de red es mayor o igual a 240, entonces bits es 32.
•
De lo contrario, si el byte más significativo del número de red es mayor o igual a 224, entonces bits es 4.
•
De lo contrario, si el byte más significativo del número de red es mayor o igual a 192, entonces bits es 24.
•
De lo contrario, si el byte más significativo del número de red es mayor o igual a 128, entonces bits es 16.
•
De lo contrario, bits es 8.

Si el valor resultante de bits de los pasos anteriores es mayor o igual a 8, pero el número de octetos especificados en el número de red excede bits/8, entonces bits se establece a 8 veces el número de octetos realmente especificados.

EJEMPLOS

El programa a continuación demuestra el uso de inet_net_pton() y inet_net_ntop(). Usa inet_net_pton() para convertir la dirección de red en formato de presentación proporcionada en su primer argumento de línea de comandos a forma binaria, muestra el valor de retorno de inet_net_pton(). Luego usa inet_net_ntop() para convertir la forma binaria de vuelta a formato de presentación, y muestra la cadena resultante.

Para demostrar que inet_net_pton() puede no escribir en todos los bytes de su netp argumento, el programa permite un segundo argumento opcional de línea de comandos, un número usado para inicializar el búfer antes de inet_net_pton() es llamado. Como su última línea de salida, el programa muestra todos los bytes del búfer devuelto por inet_net_pton() permitiendo al usuario ver qué bytes no han sido tocados por inet_net_pton().

Un ejemplo de ejecución, mostrando que inet_net_pton() infiere el número de bits en el número de red:


$ ./a.out 193.168;
inet_net_pton() devolvió: 24
inet_net_ntop() produjo:  193.168.0/24
Dirección cruda:              c1a80000

Demuestra que inet_net_pton() no pone a cero los bytes no usados en su búfer de resultado:


$ ./a.out 193.168 0xffffffff;
inet_net_pton() devolvió: 24
inet_net_ntop() produjo:  193.168.0/24
Dirección cruda:              c1a800ff

Demuestra que inet_net_pton() ampliará el tamaño inferido del número de red, si el número de bytes proporcionados en la cadena de presentación excede el inferido valor:


$ ./a.out 193.168.1.128;
inet_net_pton() devolvió: 32
inet_net_ntop() produjo:  193.168.1.128/32
Dirección en bruto:              c1a80180

Especificar explícitamente el tamaño del número de red anula cualquier inferencia sobre su tamaño (pero cualquier byte extra que se especifique explícitamente seguirá siendo utilizado por inet_net_pton(): para poblar el búfer de resultado):


$ ./a.out 193.168.1.128/24;
inet_net_pton() devolvió: 24
inet_net_ntop() produjo:  193.168.1/24
Dirección en bruto:              c1a80180

Fuente del programa

/* Enlazar con "-lresolv" */
#include <arpa/inet.h>
#include <err.h>
#include <stdio.h>
#include <stdlib.h>
int
main(int argc, char *argv[])
{
    char buf[100];
    struct in_addr addr;
    int bits;
    if (argc < 2) {
        fprintf(stderr,
                "Uso: %s forma-de-presentación [valor-inicial-dir]\n",
                argv[0]);
        exit(EXIT_FAILURE);
    }
    /* Si se proporciona argv[2] (un valor numérico), se usa para inicializar
       el búfer de salida dado a inet_net_pton(), para que podamos ver
       que inet_net_pton() inicializa solo los bytes necesarios para
       el número de red.  Si no se proporciona argv[2], entonces se inicializa
       el búfer a cero (como se recomienda).  */
    addr.s_addr = (argc > 2) ? strtod(argv[2], NULL) : 0;
    /* Convertir el número de red en forma de presentación en argv[1] a binario.  */
    bits = inet_net_pton(AF_INET, argv[1], &addr, sizeof(addr));
    if (bits == -1)
        err(EXIT_FAILURE, "inet_net_ntop");
    printf("inet_net_pton() devolvió: %d\n", bits);
    /* Convertir el formato binario de vuelta a presentación, usando 'bits'
       devuelto por inet_net_pton().  */
    if (inet_net_ntop(AF_INET, &addr, bits, buf, sizeof(buf)) == NULL)
        err(EXIT_FAILURE, "inet_net_ntop");
    printf("inet_net_ntop() produjo:  %s\n", buf);
    /* Mostrar 'addr' en forma en bruto (en orden de bytes de red), para que podamos
       ver los bytes no mostrados por inet_net_ntop(); algunos de esos bytes
       pueden no haber sido tocados por inet_net_ntop(), y por lo tanto aún tendrán
       cualquier valor inicial que se haya especificado en argv[2].  */
    printf("Dirección en bruto:              %x\n", htonl(addr.s_addr));
    exit(EXIT_SUCCESS);
}
