inotify_init(2) Manual de llamadas al sistema inotify_init(2)

NOMBRE

inotify_init, inotify_init1 - inicializar una instancia de inotify

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <sys/inotify.h>
int inotify_init(void);
int inotify_init1(int flags);

DESCRIPCIÓN

Para obtener una visión general de la API de inotify, consulte inotify(7).

inotify_init() inicializa una nueva instancia de inotify y devuelve un descriptor de archivo asociado a una nueva cola de eventos de inotify.

Si flags es 0, entonces inotify_init1() es lo mismo que inotify_init(). Los siguientes valores pueden ser combinados mediante OR bit a bit en flags para obtener un comportamiento diferente:

IN_NONBLOCK
Establece la bandera de estado de archivo O_NONBLOCK en la descripción de archivo abierta (ver open(2)) a la que se refiere el nuevo descriptor de archivo. Usar esta bandera ahorra llamadas adicionales a fcntl(2) para lograr el mismo resultado.
IN_CLOEXEC
Establece la bandera de cierre al ejecutar (FD_CLOEXEC) en el nuevo descriptor de archivo. Consulte la descripción de la bandera O_CLOEXEC en open(2) para ver las razones por las que esto puede ser útil.

VALOR DE RETORNO

En caso de éxito, estas llamadas al sistema devuelven un nuevo descriptor de archivo. En caso de error, se devuelve -1 y se establece errno para indicar el error.

ERRORES

EINVAL
(inotify_init1()) Se especificó un valor no válido en flags.
EMFILE
Se alcanzó el límite del usuario en el número total de instancias de inotify.
EMFILE
Se alcanzó el límite por proceso en el número de descriptores de archivo abiertos.
ENFILE
Se alcanzó el límite a nivel de sistema en el número total de archivos abiertos.
ENOMEM
No hay suficiente memoria del kernel disponible.

ESTANDARES

Linux.

HISTORIAL

inotify_init()
Linux 2.6.13, glibc 2.4.
inotify_init1()
Linux 2.6.27, glibc 2.9.

VER TAMBIÉN
