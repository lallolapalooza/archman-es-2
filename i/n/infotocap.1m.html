infotocap(1M) Comandos de usuario infotocap(1M)

NOMBRE

infotocap - convierte una descripción terminfo a una descripción termcap

SINOPSIS

infotocap [opción-tic] archivo ...

infotocap -V

DESCRIPCIÓN

infotocap traduce descripciones de terminales. Busca en cada archivo de texto dado las entradas terminfo y, para cada una encontrada, escribe una descripción análoga de termcap al flujo de salida estándar. Las capacidades terminfo “use” se traducen a capacidades termcap tc. Dado que termcap es un formato menos expresivo que terminfo, algunas capacidades no pueden traducirse.

Esta utilidad se implementa como un enlace a tic(1M), con la opción -C de este último implícita. Puedes usar otras opciones de tic como -1, -f, -v, -w y -x. La opción -V informa de la versión de ncurses asociada con este programa y sale con estado de éxito.

ARCHIVOS

/usr/share/terminfo
base de datos compilada de descripciones de terminales

PORTABILIDAD

Ninguno de X/Open Curses, Issue 7 (2009), SVr4, o NetBSD documentan esta aplicación.
