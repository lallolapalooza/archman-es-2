inc::Module::Install(3) Documentación de Perl aportada por el usuario inc::Module::Install(3)

NOMBRE

inc::Module::Install - Sistema de configuración de Module::Install

SINOPSIS

use inc::Module::Install;

DESCRIPCIÓN

Este módulo primero verifica si existe el directorio inc/.author y elimina todo el directorio inc/ si lo hace, para que el autor del módulo siempre obtenga un inc nuevo cada vez que ejecute Makefile.PL. Luego, antepone "inc" a @INC, y finalmente carga Module::Install desde allí.

A continuación se explica el motivo de usar un módulo cargador:

La implementación original de CPAN::MakeMaker introduce problemas sutiles para las distribuciones que terminan en "CPAN" (por ejemplo, CPAN.pm, WAIT::Format::CPAN), porque su ubicación en ./CPAN/ duplica las bibliotecas reales que se instalarán; además, el nombre del directorio ./CPAN/ puede confundir a los usuarios.

Por otro lado, colocar bibliotecas incluidas, solo para tiempo de compilación, en ./inc/ es una práctica normal, y hay pocas probabilidades de que una distribución CPAN se llame "Something::inc", por lo que es mucho más seguro de usar.

Además, permite que otros módulos auxiliares como Module::AutoInstall también residan en inc/ y hagan uso de ellos.
