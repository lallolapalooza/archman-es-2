NOMBRE

in2csv - Documentación de in2csv

DESCRIPCIÓN

Convierte varios formatos de datos tabulares a CSV.

La conversión de ancho fijo requiere que proporciones un archivo de esquema con la opción "-s". El archivo de esquema debe tener el siguiente formato:

columna,inicio,longitud
nombre,0,30
cumpleaños,30,10
edad,40,3

La línea de encabezado es obligatoria, aunque las columnas pueden estar en cualquier orden:

uso: in2csv [-h] [-d DELIMITADOR] [-t] [-q CARACTER_COMILLA] [-u {0,1,2,3}] [-b]
              [-p CARACTER_ESCAPADO] [-z LIMITE_TAMANO_CAMPO] [-e CODIFICACION] [-L LOCAL]
              [-S] [--blanks] [--null-value VALORES_NULOS [VALORES_NULOS ...]]
              [--date-format FORMATO_FECHA] [--datetime-format FORMATO_FECHA_HORA]
              [-H] [-K NUMERO_LINEAS_A_SALTAR] [-v] [-l] [--zero] [-V]
              [-f {csv,dbf,fixed,geojson,json,ndjson,xls,xlsx}] [-s ESQUEMA]
              [-k CLAVE] [-n] [--sheet HOJA] [--write-sheets HOJAS_A_ESCRIBIR]
              [--use-sheet-names] [--reset-dimensions]
              [--encoding-xls CODIFICACION_XLS] [-y LIMITE_SNIFF] [-I]
              [ARCHIVO]
Convierte formatos de datos tabulares comunes, pero menos geniales, a CSV.
argumentos posicionales:
  ARCHIVO               El archivo CSV a procesar. Si se omite, aceptará la entrada
                        como datos transmitidos a través de STDIN.
argumentos opcionales:
  -h, --help            muestra este mensaje de ayuda y sale
  -f {csv,dbf,fixed,geojson,json,ndjson,xls,xlsx}, --format {csv,dbf,fixed,geojson,json,ndjson,xls,xlsx}
                        El formato del archivo de entrada. Si no se especifica,
                        se inferirá del tipo de archivo.
  -s SCHEMA, --schema SCHEMA
                        Especifica un archivo de esquema con formato CSV para convertir
                        archivos de ancho fijo. Ver documentación web.
  -k KEY, --key KEY     Especifica una clave de nivel superior dentro de la cual buscar una lista de
                        objetos a convertir al procesar JSON.
  -n, --names           Muestra los nombres de las hojas del archivo Excel de entrada.
  --sheet SHEET         El nombre de la hoja de Excel a procesar.
  --write-sheets WRITE_SHEETS
                        Los nombres de las hojas de Excel a escribir en archivos, o
                        "-" para escribir todas las hojas.
  --use-sheet-names     Utiliza los nombres de las hojas como nombres de archivo cuando
                        --write-sheets está configurado.
  --reset-dimensions    Ignora las dimensiones de hoja proporcionadas por el archivo XLSX.
  --encoding-xls ENCODING_XLS
                        Especifica la codificación del archivo XLS de entrada.
  -y SNIFF_LIMIT, --snifflimit SNIFF_LIMIT
                        Limita la detección del dialecto CSV al número especificado de
                        bytes. Especifica "0" para deshabilitar la detección por completo,
                        o "-1" para detectar todo el archivo.
  -I, --no-inference    Deshabilita la inferencia de tipos (y --locale, --date-format,
                        --datetime-format, --no-leading-zeroes) al analizar la entrada CSV.
 Algunas opciones de línea de comandos solo se aplican a formatos de entrada específicos.

Ver también: Argumentos comunes a todas las herramientas.

NOTA:

El formato "ndjson" se refiere a "JSON delimitado por nueva línea", como lo usan muchas APIs de streaming.

NOTA:

Si un XLS parece idéntico a un XLSX cuando se ve en Excel, pueden no ser idénticos como CSV. Por ejemplo, XLSX tiene un tipo entero, pero XLS no. Los números que parecen enteros de un XLS tendrán decimales en CSV, pero los de un XLSX no.

NOTA:

Para convertir desde HTML, considera messytables.

EJEMPLOS

Convierte el archivo de encabezados geográficos del censo de 2000 de ancho fijo a CSV y de codificación latin-1 a utf8:

in2csv -e iso-8859-1 -f fixed -s examples/realdata/census_2000/census2000_geo_schema.csv examples/realdata/census_2000/usgeo_excerpt.upl

NOTA:

Se mantiene una biblioteca de esquemas de ancho fijo en el proyecto ffs:

https://github.com/wireservice/ffs

Convierte un archivo Excel .xls:

in2csv examples/test.xls

Estandariza el formato de un archivo CSV (comillas, saltos de línea, etc.):

in2csv examples/realdata/FY09_EDU_Recipients_by_State.csv

Obtiene los problemas abiertos de csvkit de la API de GitHub, convierte la respuesta JSON a CSV y la escribe en un archivo:

curl https://api.github.com/repos/wireservice/csvkit/issues?state=open | in2csv -f json -v

Convierte un archivo DBase DBF a un CSV equivalente:

in2csv examples/testdbf.dbf

Esta herramienta nombra encabezados sin nombre. Para evitar ese comportamiento, ejecuta:

in2csv --no-header-row examples/test.xlsx | tail -n +2

SOLUCIÓN DE PROBLEMAS

Si ocurre un error como el siguiente al proporcionar un archivo de entrada en formato CSV o Excel:

ValueError: Row 0 has 11 values, but Table only has 1 columns.

Entonces, el archivo de entrada podría tener filas iniciales antes de las filas de encabezado y de datos. Puedes omitir dichas filas con --skip-lines (-K):

in2csv --skip-lines 3 examples/test_skip_lines.csv

Si un archivo XLSX produce muy pocas filas o muy pocas columnas, entonces la aplicación que creó el archivo podría haber establecido incorrectamente las dimensiones de la hoja de cálculo. Inténtalo de nuevo con la opción --reset-dimensions.
