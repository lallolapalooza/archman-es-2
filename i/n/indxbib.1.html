indxbib(1) Manual de Comandos Generales indxbib(1)

Nombre

indxbib - crea un índice invertido para bases de datos bibliográficas

Sinopsis

indxbib [-w] [-c archivo-palabras-comunes] [-d directorio] [-f archivo-lista] [-h tamaño-tabla-hash-min] [-i campos-excluidos] [-k claves-max-por-registro] [-l longitud-clave-min] [-n umbral] [-o archivo] [-t longitud-clave-max] [archivo ...]
indxbib --help
indxbib -v
indxbib --version

Descripción

indxbib crea un índice invertido para las bases de datos bibliográficas en cada archivo para su uso con refer(1), lookbib(1) y lkbib(1). Cada índice creado se nombra archivo.i; la escritura se realiza en un archivo temporal que luego se renombra a este. Si no se proporcionan operandos de archivo en la línea de comandos porque se ha utilizado la opción -f, y no se proporciona la opción -o, el índice se llamará Ind.i.

Las bases de datos bibliográficas se dividen en registros mediante líneas en blanco. Dentro de un registro, cada campo comienza con un carácter % al principio de una línea. Los campos tienen un nombre de una sola letra que sigue al carácter %.

Los valores establecidos por las opciones -c, -l, -n y -t se almacenan en el índice: cuando se busca el índice, las claves se descartarán y se truncarán de manera apropiada a estas opciones; las claves originales se utilizarán para verificar que cualquier registro encontrado utilizando el índice realmente contenga las claves. Esto significa que un usuario de un índice no necesita saber si estas opciones se utilizaron en la creación del índice, siempre que no todas las claves a buscar se hayan descartado durante la indexación y que el usuario proporcione al menos la parte de cada clave que hubiera permanecido después de ser truncada durante la indexación. El valor establecido por la opción -i también se almacena en el índice y se utilizará para verificar los registros encontrados utilizando el índice.

Opciones

--help muestra un mensaje de uso, mientras que -v y --version muestran información de la versión; todas salen después.

-c archivo-palabras-comunes
Lee la lista de palabras comunes de archivo-palabras-comunes en lugar de /usr/share/groff/1.23.0/eign.
-d directorio
Usa directorio como el nombre del directorio para almacenar en el índice, en lugar del devuelto por getcwd(2). Típicamente, directorio será un enlace simbólico cuyo destino es el directorio de trabajo actual.
-f archivo-lista
Lee los archivos a indexar de archivo-lista. Si archivo-lista es -, los archivos se leerán de la entrada estándar. La opción -f se puede dar como máximo una vez.
-h tamaño-tabla-hash-min
Utiliza el primer número primo mayor o igual al argumento para el tamaño de la tabla hash. Valores más grandes generalmente harán la búsqueda más rápida, pero harán el archivo de índice más grande y causarán que indxbib use más memoria. El tamaño de tabla hash predeterminado es 997.
-i campos-excluidos
No indexar el contenido de los campos cuyos nombres se encuentran en campos-excluidos. Los nombres de campo son de un carácter cada uno. Si esta opción no está presente, indxbib excluye los campos X, Y y Z.
-k claves-max-por-registro
No usar más de las claves especificadas en el argumento por registro de entrada. Si esta opción no está presente, el máximo es 100.
-l longitud-clave-min
Descarta cualquier clave cuya longitud en caracteres sea menor que el valor del argumento. Si esta opción no está presente, la longitud mínima de clave es 3.
-n umbral
Descarta las umbral palabras más comunes del archivo de palabras comunes. Si esta opción no está presente, se descartan las 100 palabras más comunes.
-o nombre-base
Nombra el índice nombre-base.i.
-t longitud-clave-max
Trunca las claves a longitud-clave-max en caracteres. Si esta opción no está presente, las claves se truncan a 6 caracteres.
-w
Indexar archivos completos. Cada archivo es un registro separado.
