NOMBRE

infinoted - servidor dedicado para el protocolo infinote (p.ej. Gobby)

SINOPSIS

infinoted-0.7 [opciones]

DESCRIPCIÓN

infinoted es un servidor dedicado que permite a los clientes editar documentos de texto plano y archivos fuente colaborativamente a través de una red. Los cambios en los documentos se sincronizan instantáneamente con los otros clientes.

Este servidor soporta el protocolo infinote tal como lo implementa libinfinity. Los clientes de ejemplo incluyen Gobby 0.5.x, Kobby y un plugin especial para gedit. No es compatible con el protocolo libobby anterior.

Viene con una lista de plugins como autosave, integración dbus y otros. Para una lista completa, consulta https://github.com/gobby/gobby/wiki/Dedicated%20Server. El plugin predeterminado es note-text. Debe agregarse junto con cualquier otro plugin que se desee habilitar.

OPCIONES

Opciones de Ayuda:

-h, --help
Muestra las opciones de ayuda

Opciones de Aplicación:

-c, --config-file=ARCHIVO-CONFIG
Carga el archivo de configuración dado en lugar de buscar en las ubicaciones estándar.
-k, --key-file=ARCHIVO-CLAVE
La clave privada del servidor
-c, --certificate-file=ARCHIVO-CERTIFICADO
El certificado del servidor
--certificate-chain
La cadena de certificados hasta el certificado raíz, si no está incluida en el archivo proporcionado en --certificate-file.
--create-key
Crea una nueva clave privada aleatoria
--create-certificate
Crea un nuevo certificado autofirmado utilizando la clave dada
-p, --port-number=PUERTO
El número de puerto en el que escuchar
--listen-address=DIRECCIÓN
La dirección IP en la que escuchar
--security-policy=no-tls|allow-tls|require-tls
Cómo decidir si usar TLS
-r, --root-directory=DIRECTORIO
Un directorio donde guardar el árbol de documentos en formato infinoted-xml. Esta es la ubicación donde se mantiene el árbol de forma persistente para que esté disponible nuevamente después de reiniciar el servidor. Normalmente, los documentos se guardan en este árbol 60 segundos después de que el último usuario abandona la sesión. Además de esto, cuando se habilita el plugin autosave, es posible guardar sesiones en el árbol periódicamente. El directorio predeterminado es ~/.infinote.
--plugins=PLUGIN
Plugin adicional a cargar. Repite la opción en la línea de comandos para especificar múltiples plugins y usa punto y coma en el archivo de configuración. Las opciones del plugin se pueden configurar en el archivo de configuración (una sección para cada plugin) o con la opción --plugin-parameter.
--plugin-parameter=PLUGIN:CLAVE:VALOR
Establece la opción CLAVE para el plugin PLUGIN al valor dado. Normalmente, las opciones del plugin se especifican en el archivo de configuración, pero esta opción de línea de comandos permite establecer o anular las opciones del plugin en la línea de comandos.
-P, --password=CONTRASEÑA
Requiere la contraseña dada en las conexiones
--pam-service=SERVICIO
Autentica a los clientes contra el servicio pam dado al conectarse
--pam-allow-user=USUARIOS
Usuarios permitidos para conectarse después de la autenticación pam. Separa las entradas con punto y coma.
--pam-allow-group=GRUPOS
Grupo permitido para conectarse después de la autenticación pam. Separa las entradas con punto y coma.
-d, --daemonize
Convierte el servidor en un demonio
-D, --kill-daemon
Mata un demonio en ejecución
-v, --version
Muestra la información de la versión y sale
