INTLTOOL-UPDATE(8) Manual del Administrador del Sistema INTLTOOL-UPDATE(8)

NOMBRE

intltool-update - actualiza el archivo de plantilla PO y fusiona las traducciones con él

SINOPSIS

intltool-update [opción]...
intltool-update CÓDIGOIDIOMA

DESCRIPCIÓN

intltool-update genera nuevas plantillas de archivos PO a partir del código fuente y fusiona las traducciones existentes con estas nuevas plantillas PO.

Debes cambiar el directorio de trabajo al subdirectorio que contiene las traducciones (normalmente "po/") antes de ejecutar intltool-update.

OPCIONES

Cuando se ejecuta intltool-update , solo se permite un modo de operación a la vez.

Modo de operación

-p
--pot
Genera solo la plantilla PO (.pot).
-s
--headers
Ejecuta intltool-extract(8) para extraer cadenas dentro de archivos estilo XML/INI listados en POTFILES.in, y escribe las cadenas extraídas en archivos de cabecera, para que las cadenas puedan ser reconocidas por xgettext(1).
-m
--maintain
Busca archivos omitidos que deberían haber sido listados en POTFILES.in o POTFILES.skip. Una lista de todos estos archivos se escribe en otro archivo llamado "missing".
-r
--report
Muestra un informe de estado para todas las traducciones en el software.
-d CÓDIGOIDIOMA
--dist CÓDIGOIDIOMA
Fusiona CÓDIGOIDIOMA.po con la plantilla PO existente.

Otras opciones

-g NOMBRE
--gettext-package=NOMBRE
Especifica manualmente el nombre del archivo de plantilla PO, en lugar de determinar el nombre automáticamente a partir del código fuente. Útil con la opción -p/--pot. Esta opción tiene un efecto adicional: el nombre del directorio de trabajo actual ya no se limita a "po" o "po-*".
-o NOMBREARCHIVO
--output-file=NOMBREARCHIVO
Especifica manualmente el NOMBREARCHIVO de salida después de fusionar la traducción antigua con la plantilla PO. Útil con la opción -d/--dist o sin ninguna opción.
-x
--verbose
Muestra mucha información de retroalimentación.
--version
Muestra la información de la versión.
--help
Muestra el uso y la información básica de ayuda.

EJEMPLOS

Crea una nueva plantilla PO a partir del código fuente y la llama foo.pot:

intltool-update --pot --gettext-package=foo

Actualiza el archivo de traducción xy.po usando la plantilla PO existente llamada "bar.pot" y escribe la salida en "xy1.po":

intltool-update --dist --gettext-package=bar --output-file=xy1.po xy

Crea una nueva plantilla PO y actualiza el archivo de traducción xy.po (xy.po se sobrescribe con el nuevo contenido):

intltool-update xy
(igual que intltool-update --pot && intltool-update --dist xy)

ARCHIVOS

po/POTFILES.in
Contiene la lista de archivos fuente que contienen cadenas traducibles, un archivo por línea.
po/POTFILES.skip
po/POTFILES.ignore (obsoleto)
Contiene la lista de archivos fuente que deben ser ignorados al buscar cadenas traducibles.

REPORTAR ERRORES

Reporta errores a http://bugs.launchpad.net/intltool
