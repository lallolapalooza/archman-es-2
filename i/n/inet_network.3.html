NAME

                    
inet_network, inet_lnaof, inet_netof — IPv4 address to network byte order conversion

                

                

                    
LIBRARY

                    
Standard C library (libc, -lc)

                

                

                    
SYNOPSIS

                    
#include <arpa/inet.h>
uint32_t inet_network(const char *cp);
in_addr_t inet_lnaof(in_addr_t ina);
in_addr_t inet_netof(in_addr_t ina);

                

                

                    
DESCRIPTION

                    
The inet_network function interprets the character string cp as an IPv4 network address. The string must be in the standard dotted-decimal format (e.g., "192.168.1.1"). The function returns the network number corresponding to the address. If the string is not a valid IPv4 address, inet_network returns (uint32_t)-1 (that is, 0xFFFFFFFF).

                    
The inet_lnaof and inet_netof functions extract the local network address part and the network number part, respectively, from an IPv4 address ina, which is assumed to be in network byte order. The return value is in network byte order.

                    
These functions are obsolete and are provided for compatibility with older code. For new applications, use inet_pton and inet_ntop.

STANDARDS

                    
These functions first appeared in BIND 4.0.

                

                

                    
STANDARDS

                    
The IPv4 address conversion functions are part of the BSD sockets API. They are specified in POSIX.1-2001 and POSIX.1-2008 but are marked as obsolete there as well.

                

                

                    
NOTES

                    
inet_network does not handle the optional network mask suffix (e.g., "192.168.1.1/24").

                    
The return value of inet_network is of type uint32_t, but the address is interpreted as an IPv4 address. For inet_lnaof and inet_netof, the argument ina and the return value are of type in_addr_t (which is usually a uint32_t).

                    
The behavior of inet_network is locale-dependent if the input string cp contains characters outside the ASCII range.

                    
The following program demonstrates the use of inet_network and related functions.

                

                

                    
EXAMPLES

                    
The inet_aton function converts a string in dotted-decimal format into a network address structure. The inet_ntoa function converts a network address structure to its string representation in dotted-decimal format. The following example program takes an IP address string as a command-line argument, converts it to network byte order using inet_aton, then converts it back to a string using inet_ntoa, and finally prints the result.

                    
#include <arpa/inet.h>
#include <stdio.h>
#include <stdlib.h>
int
main(int argc, char *argv[])
{
    struct in_addr addr;

    if (argc != 2) {
        fprintf(stderr, "%s <dotted-address>\n", argv[0]);
        exit(EXIT_FAILURE);
    }

    if (inet_aton(argv[1], &addr) == 0 ) {
        fprintf(stderr, "Invalid address\n");
        exit(EXIT_FAILURE);
    }

    printf("%s\n", inet_ntoa(addr));

    exit(EXIT_SUCCESS);
}


                    
Compile with:

                    
gcc -o example example.c

                    
And run with:

                    
./example 127.0.0.1
