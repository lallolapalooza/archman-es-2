inet_ntop(3) Manual de funciones de biblioteca inet_ntop(3)

NOMBRE

inet_ntop - convertir direcciones IPv4 e IPv6 de formato binario a texto

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <arpa/inet.h>
const char *inet_ntop(socklen_t size;
                      int af, const void *restrict src,
                      char dst[restrict size], socklen_t size);

DESCRIPCIÓN

Esta función convierte la estructura de dirección de red src en la familia de direcciones af a una cadena de caracteres. La cadena resultante se copia al búfer apuntado por dst, que debe ser un puntero no nulo. El llamador especifica el número de bytes disponibles en este búfer en el argumento size.

inet_ntop() extiende la función inet_ntoa(3) para soportar múltiples familias de direcciones; inet_ntoa(3) ahora se considera obsoleta en favor de inet_ntop(). Las siguientes familias de direcciones están soportadas actualmente:

AF_INET
src apunta a una struct in_addr (en orden de bytes de red) que se convierte a una dirección de red IPv4 en formato decimal punteado, "ddd.ddd.ddd.ddd". El búfer dst debe tener al menos INET_ADDRSTRLEN bytes de longitud.
AF_INET6
src apunta a una struct in6_addr (en orden de bytes de red) que se convierte a una representación de esta dirección en el formato de dirección de red IPv6 más apropiado para esta dirección. El búfer dst debe tener al menos INET6_ADDRSTRLEN bytes de longitud.

VALOR DE RETORNO

En caso de éxito, inet_ntop() devuelve un puntero no nulo a dst. Se devuelve NULL si hubo un error, con errno establecido para indicar el error.

ERRORES

EAFNOSUPPORT
af no era una familia de direcciones válida.
ENOSPC
La cadena de dirección convertida excedería el tamaño dado por size.

ATRIBUTOS

Para una explicación de los términos utilizados en esta sección, consulte attributes(7).

Interfaz Atributo Valor
inet_ntop () Seguridad de hilos MT-Safe locale

ESTÁNDARES

POSIX.1-2008.

HISTORIA

POSIX.1-2001.

Tenga en cuenta que RFC 2553 define un prototipo donde el último argumento size es de tipo size_t. Muchos sistemas siguen la RFC 2553. glibc 2.0 y 2.1 tienen size_t, pero 2.2 y posteriores tienen socklen_t.

ERRORES CONOCIDOS

AF_INET6 convierte direcciones IPv6 mapeadas por IPv4 a un formato IPv6.

EJEMPLOS

Consulte inet_pton(3).

VER TAMBIÉN

getnameinfo(3), inet(3), inet_pton(3)
