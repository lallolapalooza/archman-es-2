random(3) Manual de funciones de biblioteca random(3)

NOMBRE

random, srandom, initstate, setstate - generador de números aleatorios

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <stdlib.h>
long random(void);
void srandom(unsigned int seed);
char *initstate(size_t n;
                unsigned int seed, char state[n], size_t n);
char *setstate(char *state);
Requisitos de Macro de Prueba de Funciones para glibc (ver feature_test_macros(7)):

random(), srandom(), initstate(), setstate():

    _XOPEN_SOURCE >= 500
        || /* glibc >= 2.19: */ _DEFAULT_SOURCE
        || /* glibc <= 2.19: */ _SVID_SOURCE || _BSD_SOURCE

DESCRIPCIÓN

La función random() utiliza un generador de números aleatorios de retroalimentación aditiva no lineal que emplea una tabla por defecto de 31 enteros largos para devolver números pseudoaleatorios sucesivos en el rango de 0 a 2^31 - 1. El período de este generador de números aleatorios es muy grande, aproximadamente 16 * ((2^31) - 1).

La función srandom() establece su argumento como la semilla para una nueva secuencia de enteros pseudoaleatorios que serán devueltos por random(). Estas secuencias son repetibles llamando a srandom() con el mismo valor de semilla. Si no se proporciona ningún valor de semilla, la función random() se inicia automáticamente con un valor de 1.

La función initstate() permite inicializar una matriz de estado state para su uso por random(). El tamaño de la matriz de estado n es utilizado por initstate() para decidir qué tan sofisticado será el generador de números aleatorios que utilizará: cuanto mayor sea la matriz de estado, mejores serán los números aleatorios. Los valores "óptimos" actuales para el tamaño de la matriz de estado n son 8, 32, 64, 128 y 256 bytes; otras cantidades se redondearán a la baja a la cantidad conocida más cercana. Usar menos de 8 bytes resulta en un error. seed es la semilla para la inicialización, que especifica un punto de partida para la secuencia de números aleatorios y permite reiniciar en el mismo punto.

La función setstate() cambia la matriz de estado utilizada por la función random(). La matriz de estado state se utiliza para la generación de números aleatorios hasta la próxima llamada a initstate() o setstate(). state debe haber sido inicializada previamente usando initstate() o ser el resultado de una llamada anterior de setstate().

VALOR DE RETORNO

La función random() devuelve un valor entre 0 y (2^31) - 1. La función srandom() no devuelve ningún valor.

La función initstate() devuelve un puntero a la matriz de estado anterior. En caso de fallo, devuelve NULL y se establece errno para indicar el error.

En caso de éxito, setstate() devuelve un puntero a la matriz de estado anterior. En caso de fallo, devuelve NULL y se establece errno para indicar el error.

ERRORES

EINVAL
El argumento state proporcionado a setstate() era NULL.
EINVAL
Se especificó una matriz de estado de menos de 8 bytes a initstate().

NOTAS

La generación de números aleatorios es un tema complejo. Numerical Recipes in C: The Art of Scientific Computing (William H. Press, Brian P. Flannery, Saul A. Teukolsky, William T. Vetterling; Nueva York: Cambridge University Press, 2007, 3ª ed.) proporciona una excelente discusión sobre cuestiones prácticas de generación de números aleatorios en el Capítulo 7 (Números aleatorios).

Para una discusión más teórica que también cubre muchos temas prácticos en profundidad, consulte el Capítulo 3 (Números aleatorios) en The Art of Computer Programming de Donald E. Knuth, volumen 2 (Seminumerical Algorithms), 2ª ed.; Reading, Massachusetts: Addison-Wesley Publishing Company, 1981.

ADVERTENCIAS

La función random() no debe usarse en programas multihilo donde se requiera un comportamiento reproducible. Use random_r(3) para ese propósito.

ERRORES

Según POSIX, initstate() debería devolver NULL en caso de error. En la implementación de glibc, errno se establece (como se especifica) en caso de error, pero la función no devuelve NULL.

VER TAMBIÉN

Acerca de Arch Linux

Arch Linux es una distribución Linux independiente, compilada para arquitecturas x86-64 y optimizada para la simplicidad, modernidad, pragmatismo, centralidad del usuario y versatilidad.

Arch se adhiere a las principios de desarrollo de software libre y de código abierto, y tiene como objetivo que el usuario sea el que controle su sistema y tenga la libertad de hacerlo como quiera.

El sistema base de Arch Linux es un sistema mínimo y simple, que se expande según las necesidades del usuario. El sistema se construye alrededor de un gestor de paquetes llamado Pacman, que facilita la gestión de paquetes y sus dependencias.

La documentación es una parte fundamental de Arch Linux. El Wiki de Arch Linux es un recurso increíblemente completo y actualizado, mantenido por la comunidad, que cubre la instalación, configuración y uso del sistema.
