intptr_t(3type) intptr_t(3type)

NOMBRE

intptr_t, uintptr_t - tipos enteros lo suficientemente anchos para contener punteros

BIBLIOTECA

Biblioteca C estándar (libc)

SINOPSIS

#include <stdint.h>
typedef /* ... */ intptr_t;
typedef /* ... */ uintptr_t;
#define INTPTR_WIDTH  /* ... */
#define UINTPTR_WIDTH INTPTR_WIDTH
#define INTPTR_MAX    /*  2**(INTPTR_WIDTH - 1) - 1  */
#define INTPTR_MIN    /*  - 2**(INTPTR_WIDTH - 1)    */
#define UINTPTR_MAX   /*  2**UINTPTR_WIDTH - 1       */

DESCRIPCIÓN

intptr_t es un tipo entero con signo tal que cualquier valor válido de (void *) puede ser convertido a este tipo y luego reconvertido de nuevo. Es capaz de almacenar valores en el rango [INTPTR_MIN, INTPTR_MAX].

uintptr_t es un tipo entero sin signo tal que cualquier valor válido de (void *) puede ser convertido a este tipo y luego reconvertido de nuevo. Es capaz de almacenar valores en el rango [0, UINTPTR_MAX].

Las macros [U]INTPTR_WIDTH se expanden al ancho en bits de estos tipos.

Las macros [U]INTPTR_MAX se expanden al valor máximo que estos tipos pueden contener.

La macro INTPTR_MIN se expande al valor mínimo que intptr_t puede contener.

Los modificadores de longitud para los tipos [u]intptr_t para la familia de funciones printf(3) son expandidos por las macros PRIdPTR, PRIiPTR, y PRIuPTR (definidas en <inttypes.h>); resultando comúnmente en %"PRIdPTR" o %"PRIiPTR" para imprimir valores de intptr_t. Los modificadores de longitud para los tipos [u]intptr_t para la familia de funciones scanf(3) son expandidos por las macros SCNdPTR, SCNiPTR, y SCNuPTR (definidas en <inttypes.h>); resultando comúnmente en %"SCNuPTR" para leer valores de uintptr_t.

ESTÁNDARES

C11, POSIX.1-2024.

HISTORIA

C99, POSIX.1-2001.

NOTAS

La siguiente cabecera también proporciona estos tipos: <inttypes.h>.
