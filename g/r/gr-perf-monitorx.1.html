GR-CTRLPORT-MONITOR(1) Comandos de usuario GR-CTRLPORT-MONITOR(1)

NOMBRE

gr-ctrlport-monitor - GUI de puerto de control de gnuradio

SINOPSIS

gr-ctrlport-monitor [opciones]

OPCIONES

-h, --help
mostrar este mensaje de ayuda y salir
-H HOST, --host=HOST
Nombre de host del servidor ControlPort.
-p PORT, --port=PORT
Número de puerto del punto final ControlPort del host.
-i INTERFACES, --interfaces=INTERFACES
Interfaces a usar. [por defecto=['lo']]
-P PROTOCOL, --protocol=PROTOCOL
Tipo de protocolo a usar (generalmente tcp). [por defecto=tcp]
-a APP, --app=APP
Nombre de la aplicación [por defecto=gnuradio]

gr-ctrlport-monitor: error: no existe la opción: --version
