grep busca patrones en cada ARCHIVO. En la primera forma de la sinopsis, que se usa si no están presentes las opciones -e o -f, el primer operando PATRONES es uno o más patrones separados por caracteres de salto de línea, y grep imprime cada línea que coincide con un patrón. Típicamente PATRONES debe estar entre comillas cuando grep se usa en un comando de

shell.

EXPRESIONES REGULARES

Una expresión regular es un patrón que describe un conjunto de cadenas. Las expresiones regulares se construyen de manera análoga a las expresiones aritméticas, utilizando varios operadores para combinar expresiones más pequeñas.

grep entiende tres versiones diferentes de la sintaxis de expresiones regulares: "básica" (BRE), "extendida" (ERE) y "perl" (PCRE). En GNU grep, las expresiones regulares básicas y extendidas son simplemente notaciones diferentes para la misma funcionalidad de búsqueda de patrones. En otras implementaciones, las expresiones regulares básicas son ordinariamente menos potentes que las extendidas, aunque ocasionalmente es al revés. La siguiente descripción se aplica a las expresiones regulares extendidas; las diferencias para las expresiones regulares básicas se resumen después. Las expresiones regulares compatibles con Perl tienen una funcionalidad diferente y se documentan en pcre2syntax(3) y pcre2pattern(3), pero solo funcionan si el soporte PCRE está habilitado.

Los bloques de construcción fundamentales son las expresiones regulares que coinciden con un solo carácter. La mayoría de los caracteres, incluidas todas las letras y dígitos, son expresiones regulares que coinciden consigo mismos. Cualquier metacaracter con un significado especial puede ser escapado anteponiéndole una barra invertida.

El punto . coincide con cualquier carácter individual. No está especificado si coincide con un error de codificación.

Clases de Caracteres y Expresiones entre Corchetes

Una expresión entre corchetes es una lista de caracteres encerrada entre [ y ]. Coincide con cualquier carácter individual de esa lista. Si el primer carácter de la lista es el acento circunflejo ^, entonces coincide con cualquier carácter que *no* esté en la lista; no está especificado si coincide con un error de codificación. Por ejemplo, la expresión regular [0123456789] coincide con cualquier dígito individual.

Dentro de una expresión entre corchetes, una expresión de rango consta de dos caracteres separados por un guion. En la configuración predeterminada del locale C, coincide con cualquier carácter individual que aparezca entre los dos caracteres en orden ASCII, inclusivo. Por ejemplo, [a-d] es equivalente a [abcd]. En otros locales, el comportamiento no está especificado: [a-d] podría ser equivalente a [abcd] o [aBbCcDd] o alguna otra expresión entre corchetes, o podría no coincidir con ningún carácter, o el conjunto de caracteres con los que coincide podría ser errático, o podría ser inválido. Para obtener la interpretación tradicional de las expresiones entre corchetes, puede usar el locale C configurando la variable de entorno LC_ALL al valor C.

Finalmente, ciertas clases nombradas de caracteres están predefinidas dentro de las expresiones entre corchetes, como las siguientes. Sus nombres se explican por sí mismos, y son [:alnum:], [:alpha:], [:blank:], [:cntrl:], [:digit:], [:graph:], [:lower:], [:print:], [:punct:], [:space:], [:upper:] y [:xdigit:]. Por ejemplo, [[:alnum:]] significa la clase de caracteres de números y letras en el locale actual. En el locale C y la codificación de conjunto de caracteres ASCII, esto es lo mismo que [0-9A-Za-z]. (Tenga en cuenta que los corchetes en estos nombres de clase son parte de los nombres simbólicos y deben incluirse además de los corchetes que delimitan la expresión entre corchetes.) La mayoría de los metacaracteres pierden su significado especial dentro de las expresiones entre corchetes. Para incluir un literal ], colóquelo primero en la lista. De manera similar, para incluir un literal ^, colóquelo en cualquier lugar excepto al principio. Finalmente, para incluir un literal -, colóquelo al final.

Anclaje

El acento circunflejo ^ y el signo del dólar $ son metacaracteres que respectivamente coinciden con la cadena vacía al principio y al final de una línea.

El Carácter Barra Invertida y Expresiones Especiales

Los símbolos \< y \> coinciden respectivamente con la cadena vacía al principio y al final de una palabra. El símbolo \b coincide con la cadena vacía en el borde de una palabra, y \B coincide con la cadena vacía siempre que *no* esté en el borde de una palabra. El símbolo \w es un sinónimo de [_[:alnum:]] y \W es un sinónimo de [^_[:alnum:]].

Repetición

Una expresión regular puede ir seguida de uno de varios operadores de repetición:

?
El elemento anterior es opcional y coincide como máximo una vez.
*
El elemento anterior se coincidirá cero o más veces.
+
El elemento anterior se coincidirá una o más veces.
{n}
El elemento anterior se coincidirá exactamente n veces.
{n,}
El elemento anterior se coincidirá n o más veces.
{,m}
El elemento anterior se coincidirá como máximo m veces. Esta es una extensión de GNU.
{n,m}
El elemento anterior se coincidirá al menos n veces, pero no más de m veces.

Concatenación

Dos expresiones regulares pueden concatenarse; la expresión regular resultante coincide con cualquier cadena formada por la concatenación de dos subcadenas que coincidan respectivamente con las expresiones concatenadas.

Alternancia

Dos expresiones regulares pueden unirse mediante el operador infijo |; la expresión regular resultante coincide con cualquier cadena que coincida con una u otra expresión alternativa.

Precedencia

La repetición tiene precedencia sobre la concatenación, que a su vez tiene precedencia sobre la alternancia. Una expresión completa puede encerrarse entre paréntesis para anular estas reglas de precedencia y formar una subexpresión.

Retro-referencias y Subexpresiones

La retro-referencia \n, donde n es un solo dígito, coincide con la subcadena previamente coincidente por la n-ésima subexpresión entre paréntesis de la expresión regular.

Expresiones Regulares Básicas vs Extendidas

En las expresiones regulares básicas, los metacaracteres ?, +, {, |, ( y ) pierden su significado especial; en su lugar, use las versiones con barra invertida \?, \+, \{, \|, \( y \).

ESTADO DE SALIDA

Normalmente, el estado de salida es 0 si se selecciona una línea, 1 si no se seleccionó ninguna línea y 2 si ocurrió un error. Sin embargo, si se usa -q o --quiet o --silent y se selecciona una línea, el estado de salida es 0 incluso si ocurrió un error.

ENTORNO

El comportamiento de grep se ve afectado por las siguientes variables de entorno.

El locale para la categoría LC_foo se especifica examinando las tres variables de entorno LC_ALL, LC_foo, LANG, en ese orden. La primera de estas variables que esté configurada especifica el locale. Por ejemplo, si LC_ALL no está configurada, pero LC_MESSAGES está configurada a pt_BR, entonces se usa el locale portugués brasileño para la categoría LC_MESSAGES. Se usa el locale C si ninguna de estas variables de entorno está configurada, si el catálogo de locale no está instalado, o si grep no fue compilado con soporte para idiomas nacionales (NLS). El comando de shell locale -a enumera los locales disponibles actualmente.
