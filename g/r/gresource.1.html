gresource() gresource()

Nombre

gresource - Herramienta GResource

SINÓPSIS

gresource [--section SECCIÓN] list ARCHIVO [RUTA]
gresource [--section SECCIÓN] details ARCHIVO [RUTA]
gresource [--section SECCIÓN] extract ARCHIVO RUTA
gresource sections ARCHIVO
gresource help [COMANDO]

DESCRIPCIÓN

gresource ofrece una interfaz de línea de comandos sencilla para GResource. Te permite listar y extraer recursos que han sido compilados en un archivo de recursos o incluidos en un archivo ELF (un binario o una biblioteca compartida).

El archivo sobre el que operar se especifica mediante el argumento ARCHIVO.

Si un archivo ELF incluye múltiples secciones con recursos, es posible seleccionar cuál operar con la opción --section. Usa el comando sections para encontrar las secciones disponibles.

COMANDOS

list

Lista recursos. Si se da SECCIÓN, solo lista recursos en esta sección. Si se da RUTA, solo lista recursos coincidentes.

details

Lista recursos con detalles. Si se da SECCIÓN, solo lista recursos en esta sección. Si se da RUTA, solo lista recursos coincidentes. Los detalles incluyen la sección, tamaño y compresión de cada recurso.

extract

Extrae el recurso nombrado por RUTA a stdout. Ten en cuenta que los recursos pueden contener datos binarios.

sections

Lista las secciones que contienen recursos. Esto solo es interesante si ARCHIVO es un archivo ELF.

help

Imprime ayuda y sale.
