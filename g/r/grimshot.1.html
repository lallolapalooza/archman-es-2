NOMBRE

grimshot - una utilidad auxiliar para capturas de pantalla en sway

SINOPSIS

grimshot [--notify] [--cursor] [--wait N] (copy|save) [TARGET] [FILE]
grimshot check
grimshot usage

OPCIONES

--notify

Muestra notificaciones al usuario de que se ha tomado una captura de pantalla.

--cursor

Incluye el cursor en la captura de pantalla.

--wait N

Espera N segundos antes de tomar una captura de pantalla. Espera después de que se realice cualquier selección manual. Se recomienda combinar con --notify para saber cuándo se ha tomado la captura de pantalla.

save

Guarda la captura de pantalla en un archivo normal. Grimshot escribirá archivos de imagen en XDG_SCREENSHOTS_DIR si este está configurado (o definido en user-dirs.dir), o de lo contrario recurrirá a XDG_PICTURES_DIR. Establece FILE a '-' para enviar la salida a STDOUT. Establece la variable de entorno GRIMSHOT_FILENAME_FORMAT para anular el nombre de archivo predeterminado.

copy

Copia los datos de la captura de pantalla (como image/png) al portapapeles.

savecopy

Guarda la captura de pantalla en un archivo normal (ver la documentación de save) y copia los datos de la captura de pantalla al portapapeles (ver la documentación de copy).

DESCRIPCIÓN

Grimshot es una utilidad de captura de pantalla fácil de usar para sway. Proporciona una interfaz conveniente sobre grim, slurp y jq, y soporta almacenar la captura de pantalla directamente en el portapapeles usando wl-copy o en un archivo.

EJEMPLOS

Un patrón de uso de ejemplo es añadir estos enlaces a tu configuración de sway:

# Capturas de pantalla:
# Super+P: Ventana actual
# Super+Shift+p: Seleccionar área
# Super+Alt+p Salida actual
# Super+Ctrl+p Seleccionar una ventana
bindsym Mod4+p       exec grimshot save active
bindsym Mod4+Shift+p exec grimshot save area
bindsym Mod4+Mod1+p  exec grimshot save output
bindsym Mod4+Ctrl+p  exec grimshot save window

Y/o añadir estas variables de entorno a tu configuración de shell:

export GRIMSHOT_FILENAME_FORMAT="$(date --iso-8601=ns | tr ':' -)"

OBJETIVOS

grimshot puede capturar los siguientes objetivos nombrados:

active

Captura la ventana activa actualmente.

screen

Captura toda la pantalla. Esto incluye todas las salidas visibles.

area

Permite seleccionar manualmente una región rectangular y la captura.

window

Permite seleccionar manualmente una sola ventana (haciendo clic en ella) y la captura.

output

Captura la salida activa actualmente.

anything

Permite seleccionar manualmente una sola ventana (haciendo clic en ella), una salida (haciendo clic fuera de todas las ventanas, por ejemplo, en la barra de estado), o un área (arrastrando el ratón).

SALIDA

Grimshot imprimirá el nombre del archivo de la captura de pantalla capturada en stdout si se llama con los subcomandos save o savecopy.
