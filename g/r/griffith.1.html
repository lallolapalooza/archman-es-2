NOMBRE

griffith - gestor de colecciones de películas

SINOPSIS


griffith

DESCRIPCIÓN

Griffith es un gestor de colecciones de películas. Añadir elementos a la colección de películas es tan rápido y fácil como escribir el título de la película y seleccionar una fuente compatible. Griffith intentará entonces obtener toda la información relacionada de la Web.

OPCIONES

-h --help
Mostrar información de uso.
-D --debug
Ejecutar en modo de depuración.
-C --clean
Encontrar y eliminar archivos huérfanos en el directorio de pósters.
--check-dep
Comprobar dependencias: si todos los módulos de Python necesarios están instalados, no imprime nada.
--sqlecho
Imprime todas las consultas SQL en la salida estándar.
--home DIR
Establecer el directorio principal de Griffith. Utilice esta opción si desea cambiar el valor predeterminado ~/.griffith

Imprimir lista de películas:

-c <expr> --cast=<expr>
el campo de reparto debe contener <expr>
-d <expr> --director=<expr>
el campo de director debe contener <expr>
-o <expr> --original_title=<expr>
el campo de título original debe contener <expr>
-t <expr> --title=<expr>
el campo de título debe contener <expr>
-y <numero> --year=<numero>
la película debe haberse estrenado en el año <número>
-s <columnas> --sort=<columnas>
establecer las columnas de ordenación en <columnas>. Ejemplo: --sort=o_title,number,director
