NOMBRE

grl-inspect - Muestra información sobre fuentes y claves de Grilo

SINOPSIS

grl-inspect [opciones] [fuente|clave]

DESCRIPCIÓN

Esta página del manual documenta brevemente el comando grl-inspect.

grl-inspect es una herramienta que muestra información sobre las fuentes de Grilo y las claves de metadatos disponibles. Cuando se ejecuta sin un argumento SOURCE, grl-inspect mostrará la lista de todos los plugins y fuentes. Cuando se ejecuta con una FUENTE, grl-inspect mostrará información sobre esa fuente.

Alternativamente, usando -k se muestra información sobre las claves de metadatos disponibles.

OPCIONES

-h, --help
Muestra un resumen de las opciones de grl-inspect.
--help-grl
Muestra un resumen de las opciones de Grilo.
--help-all
Muestra un resumen de todas las opciones.
-k
Muestra información sobre las claves de metadatos.
-d, --delay segundos
Espera algunos segundos antes de mostrar los resultados. Útil cuando los plugins pueden necesitar tiempo para el proceso de descubrimiento de la fuente (ejemplo: UPnP). Si no se especifica, por defecto espera 1 segundo.
-c, --config archivo-de-configuración
Archivo de configuración a usar con los plugins.
