GROUPS(1) Comandos de usuario GROUPS(1)

NOMBRE

groups - imprime los grupos a los que pertenece un usuario

SINOPSIS

groups [OPCIÓN]... [NOMBRE_USUARIO]...

DESCRIPCIÓN

Imprime las membresías de grupo para cada NOMBRE_USUARIO o, si no se especifica ningún NOMBRE_USUARIO, para el proceso actual (que puede diferir si la base de datos de grupos ha cambiado).

--help
muestra esta ayuda y sale
--version
muestra información de la versión y sale
