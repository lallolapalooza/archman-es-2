Paquete: fastjar

Licencias: GPL

GREPJAR(1) GNU GREPJAR(1)

NOMBRE

grepjar - buscar patrones en archivos dentro de un archivo jar

SINOPSIS

grepjar [-bcinsw] -e PATRÓN | PATRÓN archivos...

DESCRIPCIÓN

El programa "grepjar" se puede usar para buscar patrones en archivos dentro de un archivo jar.

OPCIONES

-b
Imprime el desplazamiento en bytes de la coincidencia.
-c
Imprime el número de coincidencias.
-i
Compara sin distinguir entre mayúsculas y minúsculas.
-n
Imprime el número de línea de cada coincidencia.
-s
Suprime los mensajes de error.
-w
Fuerza que PATRÓN solo coincida con palabras completas.
-e PATRÓN
Usa PATRÓN como expresión regular.
--help
Imprime la ayuda y sale.
-V
--version
Imprime el número de versión y sale.

VER TAMBIÉN

fastjar(1), gcj(1), gij(1), gfdl(7) y la entrada Info para gcj.
