greetd(1) Manual de Comandos Generales greetd(1)

NOMBRE

greetd - Un demonio gestor de inicio de sesión

SINOPSIS

greetd [opciones]

OPCIONES

-h, --help

Muestra el mensaje de ayuda y sale.

-c, --config <config>

Especifica el archivo de configuración a utilizar.

--vt <vt>

La VT (terminal virtual) a usar, sobrescribiendo el valor del archivo de configuración. Esto puede ser útil al iniciar una instancia por VT si greetd no puede deducir la VT prevista a partir de una terminal de control asociada.

DESCRIPCIÓN

greetd fue creado para satisfacer la necesidad de un gestor de inicio de sesión simple que no haga suposiciones sobre las aplicaciones que inicia, siendo así igualmente adecuado para iniciar sesiones de consola, sesiones Wayland o cualquier otra cosa.

greetd en sí mismo no interactúa con el usuario, sino que depende de un proceso de greeter externo como agreety(1) para manejar ese aspecto.

OPERACIÓN

greetd opera sobre **sesiones**. Un greeter crea una sesión, intenta autenticar a un usuario en ella y, finalmente, la utiliza para iniciar una aplicación arbitraria.

Hay dos tipos de sesiones preconfiguradas: La sesión predeterminada, también conocida como **greeter**, y la sesión inicial opcional, que sirve para el propósito de "inicio de sesión automático". La sesión inicial, si está configurada, se inicia una vez al lanzar greetd. La sesión predeterminada se inicia al lanzar si no hay una sesión inicial configurada, y se inicia de nuevo cada vez que no hay ninguna sesión en ejecución, como cuando el usuario cierra la sesión.

Se expone un socket IPC a este greeter, tal como se informa en GREETD_SOCK. El greeter puede usarlo para crear, autenticar y finalmente iniciar una sesión. Para más información sobre la capa IPC, véase greetd-ipc(7).

Una vez que el greeter ha solicitado el inicio de una sesión y se ha terminado a sí mismo, greetd iniciará la nueva sesión. Una vez que esta sesión termine, el proceso se reinicia.

greetd no hace suposiciones sobre ninguna sesión, incluido el greeter. Pueden ser basadas en texto, ejecutándose en la consola activa, o entornos gráficos completos.

CONFIGURACIÓN

greetd busca un archivo de configuración en /etc/greetd/config.toml por defecto. Esto se puede sobrescribir con un argumento de línea de comandos.

Para obtener información sobre el formato del archivo de configuración, véase greetd(5).
