grantpt(3) Manual de funciones de biblioteca grantpt(3)

NOMBRE

grantpt - concede acceso al pseudoterminal esclavo

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#define _XOPEN_SOURCE
#include <stdlib.h>
int grantpt(int fd);
Requisitos de la macro de prueba de características para glibc (ver feature_test_macros(7)):

grantpt():

    Desde glibc 2.24:
        _XOPEN_SOURCE >= 500
    glibc 2.23 y anteriores:
        _XOPEN_SOURCE

DESCRIPCIÓN

La función grantpt() cambia el modo y el propietario del dispositivo pseudoterminal esclavo correspondiente al pseudoterminal maestro al que se refiere el descriptor de archivo fd. El ID de usuario del esclavo se establece en el UID real del proceso que llama. El ID de grupo se establece en un valor no especificado (por ejemplo, tty). El modo del esclavo se establece en 0620 (crw--w----).

El comportamiento de grantpt() no está especificado si se instala un manejador de señales para capturar señales SIGCHLD.

VALOR DE RETORNO

Cuando tiene éxito, grantpt() devuelve 0. De lo contrario, devuelve -1 y establece errno para indicar el error.

ERRORES

EACCES
No se pudo acceder al pseudoterminal esclavo correspondiente.
EBADF
El argumento fd no es un descriptor de archivo válido y abierto.
EINVAL
El argumento fd es válido pero no está asociado con un pseudoterminal maestro.

ATRIBUTOS

Para una explicación de los términos utilizados en esta sección, consulte attributes(7).

Interfaz Atributo Valor
grantpt () Seguridad en hilos MT-Safe locale

ESTÁNDARES

POSIX.1-2008.

HISTORIA

glibc 2.1. POSIX.1-2001.

Esto forma parte del soporte de pseudoterminales UNIX 98, véase pts(4).

Los sistemas históricos implementaban esta función a través de un binario auxiliar con set-user-ID llamado "pt_chown". glibc en Linux antes de glibc 2.33 también podía hacerlo, para admitir configuraciones con solo pseudoterminales BSD; este soporte se ha eliminado. En sistemas modernos, esto es una operación nula (no-op) —con permisos configurados en la asignación de pty, como es el caso en Linux— o un ioctl(2).
