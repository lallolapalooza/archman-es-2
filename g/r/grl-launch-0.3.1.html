grl-launch(1) Manual de comandos generales grl-launch(1)

NOMBRE

grl-launch - ejecuta operaciones de Grilo desde la línea de comandos

SINOPSIS

grl-launch [OPCIONES] OPERACIÓN PARÁMETROS

DESCRIPCIÓN

Esta página del manual documenta brevemente el comando grl-launch.

grl-launch es una herramienta que permite al usuario ejecutar operaciones de Grilo desde la línea de comandos.

OPERACIONES

navegar <fuente>|<caja de medios>
puede_resolver <clave> <fuente>|<caja de medios> [<fuente>]
consultar <expresión> <fuente>
resolver <fuente>|<medio> [<fuente>]
buscar <término> <fuente>
monitorizar <fuente>
probar_medio_desde_uri <uri> [<fuente>]
medio_desde_uri <uri> <fuente>

OPCIONES

-h, --help
Muestra un resumen de las opciones de grl-launch.
--help-grl
Muestra un resumen de las opciones de Grilo.
--help-all
Muestra un resumen de todas las opciones.
-C, --config
Archivo de configuración a enviar a las fuentes
-c, --count
Número de elementos a devolver
-d, --delay
Espera algunos segundos antes de realizar la operación (por defecto 1 segundo)
-f, --flags=full|fast_only|idle_relay
Lista de banderas separadas por comas a usar
-F, --full
Serialización completa
-k, --keys
Lista de claves separadas por comas a recuperar
-S, --serialize
Serializar
-s, --skip
Número de elementos a omitir
-T, --titles
Imprime los títulos de las columnas (útil para hojas de cálculo CSV)
-V, --version
Imprime la versión

EJEMPLOS

Imprime el ID de todos los elementos buscados en la fuente Tracker:

grl-launch-0.3 search "" -S grl-tracker-source
Imprime el ID y el título de los elementos de la fuente Apple Trailers:
grl-launch-0.3 -k id,title browse grl-appletrailers-lua
Imprime el título de los vídeos indexados por Tracker:
grl-launch-0.3 -S browse -k title grlcontainer://grl-tracker-source/videos
