GRUB-FSTEST(1) Comandos de usuario GRUB-FSTEST(1)

NOMBRE

grub-fstest - herramienta de depuración para los controladores de sistemas de archivos de GRUB

SINOPSIS

grub-fstest [OPCIÓN...] RUTA_IMAGEN COMANDOS

DESCRIPCIÓN

Herramienta de depuración para el controlador de sistemas de archivos.

Comandos:
blocklist ARCHIVO
Muestra la lista de bloques de ARCHIVO.
cat ARCHIVO
Copia ARCHIVO a la salida estándar.
cmp ARCHIVO LOCAL
Compara ARCHIVO con el archivo local LOCAL.
cp ARCHIVO LOCAL
Copia ARCHIVO al archivo local LOCAL.
crc ARCHIVO
Obtiene la suma de verificación crc32 de ARCHIVO.
hex ARCHIVO
Muestra el contenido de ARCHIVO en formato hexadecimal.
ls RUTA
Lista los archivos en RUTA.
xnu_uuid DISPOSITIVO
Calcula el UUID XNU del dispositivo.
zfs-bootfs CONJUNTO_DATOS_ZFS
Calcula la ruta de arranque del conjunto de datos ZFS.
-c, --contar-discos=NUM
Especifica el número de archivos de entrada.
-C, --cifrado
Monta dispositivos cifrados.
-d, --depurar=CADENA
Establece la variable de entorno de depuración.
-K, --clave-zfs=ARCHIVO|prompt
Carga la clave criptográfica de zfs.
-n, --longitud=NUM
Maneja N bytes en el archivo de salida.
-r, --raiz=NOMBRE_DISPOSITIVO
Establece el dispositivo raíz.
-s, --saltar=NUM
Salta N bytes del archivo de salida.
-u, --descomprimir
Descomprime datos.
-v, --verboso
imprime mensajes detallados.
-?, --ayuda
muestra esta lista de ayuda
--uso
muestra un breve mensaje de uso
-V, --version
imprime la versión del programa

Los argumentos obligatorios u opcionales para las opciones largas también son obligatorios u opcionales para cualquier opción corta correspondiente.

VER TAMBIÉN

grub-probe(8)
