Nombre

groff_mmse - Plantilla sueca de "memorandum" para GNU roff

Sintaxis

groff -mmse [opciones...] [archivos...]
groff -m mmse [opciones...] [archivos...]

Descripción

mmse es una variante sueca de mm. Todos los textos están traducidos. Una página A4 tiene un ancho de texto de 13 cm, una sangría de 3,5 cm y una altura de 28,5 cm. Hay soporte para la disposición de cartas según el estándar sueco para texto justificado a la izquierda y a la derecha.

COVER puede usar se_ms como argumento. Esto proporciona una página de título sueca. Consulte groff_mm(7) para más detalles.

Cartas

Tipos de carta disponibles:

.LT SVV
Texto corrido justificado a la izquierda con el destinatario en la posición T0 (justificado a la izquierda).
.LT SVH
Texto corrido justificado a la derecha con el destinatario en la posición T4 (adecuado para sobres con ventana).

Se utilizan las siguientes variables LO adicionales.

.LO DNAMN nombre
Especifica el nombre del documento.
.LO MDAT fecha
Fecha del destinatario, se muestra debajo de Su fecha: (LetMDAT).
.LO BIL cadena
Especifica el anexo, número o cadena con el prefijo Bilaga (LetBIL).
.LO KOMP texto
Especifica información de complemento.
.LO DBET designación
Especifica la designación del documento o el número de documento.
.LO BET designación
Especifica la designación (designación de asunto en forma de número de diario o similar).
.LO SIDOR cantidad
Especifica el número total de páginas y se imprime después del número de página entre paréntesis.

Si la macro .TP está definida, se llama después de imprimir el encabezado de la carta. Es ahí donde se pueden colocar adecuadamente la dirección postal y otros elementos del pie de carta.
