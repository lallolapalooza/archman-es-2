GR_PLOT_IQ(1) Comandos de usuario GR_PLOT_IQ(1)

NOMBRE

gr_plot_iq - grafica datos complejos I&Q binarios frente al tiempo usando GNU Radio

SINOPSIS

gr_plot_iq.py: [opciones] nombre_archivo_entrada

DESCRIPCIÓN

Toma un archivo binario complejo de GNU Radio y muestra los datos I&Q frente al tiempo. Puede configurar el tamaño del bloque para especificar cuántos puntos leer a la vez y la posición de inicio en el archivo. Por defecto, el sistema asume una tasa de muestreo de 1, por lo que en el tiempo, cada muestra se grafica frente al número de muestra. Para establecer un eje de tiempo real, configure la tasa de muestreo (-R o --sample-rate) a la tasa de muestreo utilizada al capturar las muestras.

OPCIONES

-h, --help
mostrar este mensaje de ayuda y salir
-B BLOQUE, --block=BLOQUE
Especificar el tamaño del bloque [por defecto=1000]
-s INICIO, --start=INICIO
Especificar dónde empezar en el archivo [por defecto=0]
-R TASA_MUESTREO, --sample-rate=TASA_MUESTREO
Establecer la tasa de muestreo de los datos [por defecto=1.0]
