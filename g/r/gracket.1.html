NOMBRE

gracket - la implementación GUI de Racket

SINOPSIS

gracket [ opción ... ] [ argumento ... ]

DESCRIPCIÓN

GRacket es la variante de aplicación GUI de racket.

Ejecuta


gracket --help

para obtener una lista de opciones de línea de comandos y otra información de inicio.

Proporcionar ningún argumento a gracket es lo mismo que proporcionar la opción -i para evaluación interactiva.

Proporcionar argumentos que no sean modificadores ni de configuración a gracket es lo mismo que poner -u antes de los argumentos para ejecutar el primero como un script basado en módulos.

MÁS INFORMACIÓN

Para obtener más información, ejecuta


raco docs

para abrir la documentación instalada en tu navegador web.

Alternativamente, consulta la documentación en línea y otra información disponible en


http://racket-lang.org/


AUTOR
