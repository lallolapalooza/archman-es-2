NOMBRE

user_from_uid, uid_from_user, group_from_gid, gid_from_group — entradas en caché de contraseña y grupo

BIBLIOTECA

biblioteca “libbsd”

SINOPSIS

#include <pwd.h> (Ver libbsd(7) para el uso de includes.)
int
uid_from_user(const char *name, uid_t *uid);

const char *
user_from_uid(uid_t uid, int nouser);

#include <grp.h>

int
gid_from_group(const char *name, gid_t *gid);

const char *
group_from_gid(gid_t gid, int nogroup);

DESCRIPCIÓN

La función user_from_uid() devuelve el nombre de usuario asociado con el argumento uid. El nombre de usuario se almacena en caché para que múltiples llamadas con el mismo uid no requieran llamadas adicionales a getpwuid(3). Si no hay ningún usuario asociado con el uid, se devuelve un puntero a una representación en cadena del uid, a menos que el argumento nouser sea distinto de cero, en cuyo caso se devuelve un puntero nulo.

La función uid_from_user() devuelve el ID de usuario asociado con el argumento name. El ID de usuario se almacena en caché para que múltiples llamadas con el mismo name no requieran llamadas adicionales a getpwnam(3). Si no hay ningún ID de usuario asociado con el name, la función uid_from_user() devuelve -1; de lo contrario, almacena el ID de usuario en la ubicación apuntada por uid y devuelve 0.

La función group_from_gid() devuelve el nombre del grupo asociado con el argumento gid. El nombre del grupo se almacena en caché para que múltiples llamadas con el mismo gid no requieran llamadas adicionales a getgrgid(3). Si no hay ningún grupo asociado con el gid, se devuelve un puntero a una representación en cadena del gid, a menos que el argumento nogroup sea distinto de cero, en cuyo caso se devuelve un puntero nulo.

La función gid_from_group() devuelve el ID del grupo asociado con el argumento name. El ID del grupo se almacena en caché para que múltiples llamadas con el mismo name no requieran llamadas adicionales a getgrnam(3). Si no hay ningún ID de grupo asociado con el name, la función gid_from_group() devuelve -1; de lo contrario, almacena el ID del grupo en la ubicación apuntada por gid y devuelve 0.

VER TAMBIÉN

getgrgid(3), getpwuid(3)

HISTORIA

Las funciones user_from_uid() y group_from_gid() aparecieron por primera vez en 4.4BSD.

Las funciones uid_from_user() y gid_from_group() aparecieron por primera vez en NetBSD 1.4 y OpenBSD 6.4.
