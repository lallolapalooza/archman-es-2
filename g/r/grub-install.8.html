GRUB-INSTALL(8) Utilidades de Administración del Sistema GRUB-INSTALL(8)

NOMBRE

grub-install - instalar GRUB en un dispositivo

SINOPSIS

grub-install [OPCIÓN...] [OPCIÓN] [DISPOSITIVO_INSTALACION]

DESCRIPCIÓN

Instala GRUB en tu disco.

--appended-signature-size=TAMAÑO
Añade un segmento de nota reservando TAMAÑO bytes para una firma anexa
--compress=no|xz|gz|lzo
comprimir archivos GRUB [opcional]
--disable-cli
deshabilitar el acceso a la interfaz de línea de comandos
--disable-shim-lock
deshabilitar el verificador shim_lock
--dtb=ARCHIVO
incrustar un DTB específico
-d, --directory=DIR
usar imágenes y módulos bajo DIR [por defecto=/usr/lib/grub/<plataforma>]
--fonts=FUENTES
instalar FUENTES [por defecto=unicode]
--install-modules=MODULOS
instalar solo MÓDULOS y sus dependencias [por defecto=todos]
-k, --pubkey=ARCHIVO
incrustar ARCHIVO como clave pública para la verificación de firmas
--locale-directory=DIR usar traducciones bajo DIR
[por defecto=/usr/share/locale]
--locales=LOCALES
instalar solo LOCALES [por defecto=todos]
--modules=MODULOS
pre-cargar los módulos especificados MÓDULOS
--sbat=ARCHIVO
metadatos SBAT
--themes=TEMAS
instalar TEMAS [por defecto=starfield]
-v, --verbose
imprimir mensajes detallados.
-x, --x509key=ARCHIVO
incrustar ARCHIVO como certificado x509 para la verificación de firma anexa
--allow-floppy
hacer que el disco sea también arrancable como disquete (por defecto para dispositivos fdX). Puede fallar en algunas BIOS.
--boot-directory=DIR
instalar imágenes GRUB bajo el directorio DIR/grub en lugar del directorio /boot/grub
--bootloader-id=ID
el ID del cargador de arranque. Esta opción solo está disponible en EFI y Macs.
--core-compress=xz|none|auto
elegir la compresión a usar para la imagen principal
--disk-module=MODULO
módulo de disco a usar (biosdisk o native). Esta opción solo está disponible en el objetivo de BIOS.
--efi-directory=DIR
usar DIR como la raíz de la Partición del Sistema EFI.
--force
instalar incluso si se detectan problemas
--force-file-id
usar el archivo identificador incluso si la UUID está disponible
--label-bgcolor=COLOR
usar COLOR para el fondo de la etiqueta
--label-color=COLOR
usar COLOR para la etiqueta
--label-font=ARCHIVO
usar ARCHIVO como fuente para la etiqueta

--macppc-directory=DIR usar DIR para la instalación MAC de PPC.

--no-bootsector
no instalar el sector de arranque
--no-nvram
no actualizar las variables NVRAM de `boot-device' / `Boot*'. Esta opción solo está disponible en objetivos EFI e IEEE1275.
--no-rs-codes
No aplicar ningún código reed-solomon al incrustar core.img. Esta opción solo está disponible en objetivos BIOS x86.
--product-version=CADENA
usar CADENA como versión del producto
--recheck
eliminar el mapa de dispositivo si ya existe
--removable
el dispositivo de instalación es extraíble. Esta opción solo está disponible en EFI.
-s, --skip-fs-probe
no buscar sistemas de archivos en DISPOSITIVO
--target=OBJETIVO
instalar GRUB para la plataforma OBJETIVO [por defecto=x86_64-efi]; objetivos disponibles: arm-coreboot, arm-efi, arm-uboot, arm64-efi, i386-coreboot, i386-efi, i386-ieee1275, i386-multiboot, i386-pc, i386-qemu, i386-xen, i386-xen_pvh, ia64-efi, loongarch64-efi, mips-arc, mips-qemu_mips, mipsel-arc, mipsel-loongson, mipsel-qemu_mips, powerpc-ieee1275, riscv32-efi, riscv64-efi, sparc64-ieee1275, x86_64-efi, x86_64-xen
-?, --help
mostrar esta lista de ayuda
--usage
mostrar un breve mensaje de uso
-V, --version
imprimir la versión del programa

Los argumentos obligatorios u opcionales para las opciones largas son también obligatorios u opcionales para cualquier opción corta correspondiente.

DISPOSITIVO_INSTALACION debe ser el nombre de archivo del dispositivo del sistema. grub-install copia las imágenes de GRUB en /boot/grub. En algunas plataformas, también puede instalar GRUB en el sector de arranque.

REPORTE DE ERRORES

Reportar errores a <bug-grub@gnu.org>.

VER TAMBIÉN

grub-mkconfig(8), grub-mkimage(1), grub-mkrescue(1)

La documentación completa para grub-install se mantiene como un manual Texinfo. Si los programas info y grub-install están instalados correctamente en su sitio, el comando

info grub-install

debería darle acceso al manual completo.
