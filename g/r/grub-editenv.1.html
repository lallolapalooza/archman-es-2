GRUB-EDITENV(1) Comandos de usuario GRUB-EDITENV(1)

NOMBRE

grub-editenv - editar bloque de entorno GRUB

SINOPSIS

grub-editenv [OPCIÓN...] ARCHIVO COMANDO

DESCRIPCIÓN

Herramienta para editar el bloque de entorno.

Comandos:
crear
Crear un archivo de bloque de entorno vacío.
listar
Listar las variables actuales.
establecer [NOMBRE=VALOR ...]
Establecer variables.
eliminar [NOMBRE ...]
Eliminar variables.
Opciones:
-?, --help
mostrar esta lista de ayuda
--usage
mostrar un breve mensaje de uso
-v, --verbose
mostrar mensajes detallados.
-V, --version
mostrar la versión del programa

Si ARCHIVO es `-', se usa el valor predeterminado //boot/grub/grubenv.

No hay comando `delete'; si desea eliminar todo el bloque de entorno, use `rm //boot/grub/grubenv'.

REPORTE DE ERRORES

Reportar errores a <bug-grub@gnu.org>.

VER TAMBIÉN

grub-reboot(8), grub-set-default(8)

La documentación completa de grub-editenv se mantiene como un manual Texinfo. Si los programas info y grub-editenv están correctamente instalados en su sitio, el comando

info grub-editenv

debería darle acceso al manual completo.
