GRUB-MKSTANDALONE(1) Comandos de usuario GRUB-MKSTANDALONE(1)

NOMBRE

grub-mkstandalone - crea una imagen GRUB basada en memdisk

SINOPSIS

grub-mkstandalone [OPCIÓN...] [OPCIÓN] FUENTE...

DESCRIPCIÓN

Genera una imagen autónoma (que contiene todos los módulos) en el formato seleccionado.

--appended-signature-size=TAMAÑO
Añade un segmento de nota reservando TAMAÑO bytes para una firma adjunta.
--compress=no|xz|gz|lzo
comprime archivos GRUB [opcional]
--disable-cli
deshabilita el acceso a la interfaz de línea de comandos.
--disable-shim-lock
deshabilita el verificador shim_lock.
--dtb=ARCHIVO
incrusta un DTB específico.
-d, --directory=DIR
usa imágenes y módulos bajo DIR [por defecto=/usr/lib/grub/<plataforma>]
--fonts=FUENTES
instala FUENTES [por defecto=unicode]
--install-modules=MÓDULOS
instala solo MÓDULOS y sus dependencias [por defecto=all]
-k, --pubkey=ARCHIVO
incrusta ARCHIVO como clave pública para la verificación de firmas.
--locale-directory=DIR usa traducciones bajo DIR
[por defecto=/usr/share/locale]
--locales=LOCALES
instala solo LOCALES [por defecto=all]
--modules=MÓDULOS
pre-carga los módulos especificados MÓDULOS.
--sbat=ARCHIVO
metadatos SBAT.
--themes=TEMAS
instala TEMAS [por defecto=starfield].
-v, --verbose
imprime mensajes detallados.
-x, --x509key=ARCHIVO
incrusta ARCHIVO como un certificado x509 para la verificación de firmas adjuntas.
--core-compress=xz|none|auto
elige la compresión a usar para la imagen central.
-o, --output=ARCHIVO
guarda la salida en ARCHIVO [requerido].
-O, --format=ARCHIVO
genera una imagen en el FORMATO. formatos disponibles: i386-coreboot, i386-multiboot, i386-pc, i386-xen_pvh, i386-pc-pxe, i386-pc-eltorito, i386-efi, i386-ieee1275, i386-qemu, x86_64-efi, i386-xen, x86_64-xen, mipsel-yeeloong-flash, mipsel-fuloong2f-flash, mipsel-loongson-elf, powerpc-ieee1275, sparc64-ieee1275-raw, sparc64-ieee1275-cdcore, sparc64-ieee1275-aout, ia64-efi, mips-arc, mipsel-arc, mipsel-qemu_mips-elf, mips-qemu_mips-flash, mipsel-qemu_mips-flash, mips-qemu_mips-elf, arm-uboot, arm-coreboot-vexpress, arm-coreboot-veyron, arm-efi, arm64-efi, loongarch64-efi, riscv32-efi, riscv64-efi.
-?, --help
muestra esta lista de ayuda.
--usage
muestra un mensaje de uso corto.
-V, --version
imprime la versión del programa.

Los argumentos obligatorios u opcionales para las opciones largas también son obligatorios u opcionales para cualesquiera opciones cortas correspondientes.

Se acepta la sintaxis de punto de injerto (Ej. /boot/grub/grub.cfg=./grub.cfg).

REPORTAR ERRORES

Reportar errores a <bug-grub@gnu.org>.
