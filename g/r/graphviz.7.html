GRAPHVIZ(7) Manual de información miscelánea GRAPHVIZ(7)

NOMBRE

graphviz - conjunto de herramientas para el dibujo de grafos

SINOPSIS

Esta página del manual ha sido escrita para cubrir la necesidad de una documentación centralizada que presente todas las herramientas disponibles en el paquete graphviz.

HERRAMIENTAS DISPONIBLES

Programas de diseño de grafos

dot
filtro para diseños jerárquicos de grafos
neato
filtro para diseños simétricos de grafos
twopi
filtro para diseños radiales de grafos
circo
filtro para diseño circular de grafos
fdp
filtro para diseños simétricos de grafos

Todos los filtros funcionan con grafos dirigidos o no dirigidos, aunque dot se usa típicamente para grafos dirigidos y neato para grafos no dirigidos.

Mejora del diseño de grafos

gvcolor
fluye colores a través de un grafo dirigido clasificado
unflatten
ajusta grafos dirigidos para mejorar la relación de aspecto del diseño
gvpack
fusiona y empaqueta grafos disjuntos

Información y transformación de grafos

gc
cuenta componentes de grafos
acyclic
hace que el grafo dirigido sea acíclico
nop
imprime bonito un archivo de grafo
ccomps
filtro de componentes conexas para grafos
sccmap
extrae componentes fuertemente conexas de grafos dirigidos
tred
filtro de reducción transitiva para grafos dirigidos
dijkstra
filtro de distancia de fuente única
bcomps
filtro de componentes biconexas para grafos
gvpr
lenguaje de escaneo y procesamiento de patrones de grafos
prune
poda grafos dirigidos

Otros

gxl2dot, dot2gxl
convertidores GXL-DOT
