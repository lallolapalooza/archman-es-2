GRUB-GLUE-EFI(1) Comandos de Usuario GRUB-GLUE-EFI(1)

NOMBRE

grub-glue-efi - generar un binario gordo para EFI

SINOPSIS

grub-glue-efi [OPCIÓN...] [OPCIONES]

DESCRIPCIÓN

grub-glue-efi procesa imágenes EFI ia32 y amd64 y las une según el formato de Apple.

Une binarios de 32 y 64 bits en uno universal de Apple.

-3, --input32=ARCHIVO
establecer el nombre de archivo de entrada para la parte de 32 bits.
-6, --input64=ARCHIVO
establecer el nombre de archivo de entrada para la parte de 64 bits.
-o, --output=ARCHIVO
establecer el nombre de archivo de salida. Por defecto es STDOUT
-v, --verbose
imprimir mensajes detallados.
-?, --help
dar esta lista de ayuda
--usage
dar un mensaje de uso corto
-V, --version
imprimir la versión del programa

Los argumentos obligatorios u opcionales a las opciones largas son también obligatorios u opcionales para cualquier opción corta correspondiente.

REPORTAR ERRORES

Reportar errores a <bug-grub@gnu.org>.

VER TAMBIÉN

La documentación completa de grub-glue-efi se mantiene como un manual de Texinfo. Si los programas info y grub-glue-efi están instalados correctamente en su sitio, el comando

info grub-glue-efi

debería darle acceso al manual completo.
