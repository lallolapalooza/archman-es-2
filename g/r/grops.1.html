La entrada para grops debe estar en el formato emitido por troff(1), descrito en groff_out(5). Además, los archivos de descripción del dispositivo y de las fuentes para el dispositivo utilizado deben cumplir ciertos requisitos. La resolución del dispositivo debe ser un múltiplo entero de 72 veces el sizescale. El archivo de descripción del dispositivo debe contener un formato de papel válido; véase groff_font(5). Cada archivo de descripción de fuentes debe contener una

directiva 
internalnamepsname

que indica q
ue el nombre PostSc
ript de la fuente es psname.

Un archivo de descripción de fuentes también puede contener una

directiva 
encodingenc-file

que indica que la fuente
PostScript debe ser recodificada u
sando la codificación descrita en enc-file; este archivo debe consistir en una secuencia de líneas de la forma 
pschar
code
donde pschar es el nombre PostScript del carácter, y code es su posición en la codificación expresada como un entero decimal; los valores válidos están en el rango de 0 a 255. Las líneas que comienzan con # y las líneas en blanco se ignoran. El código para cada carácter dado en el archivo de descripción de fuentes debe corresponder al código para el carácter en el archivo de codificación, o al código en la codificación predeterminada para la fuente si la fuente PostScript no debe ser recodificada. Este código se puede usar con la secuencia de escape \N en troff para seleccionar el carácter, incluso si no tiene un nombre de glifo de groff. Cada carácter en el archivo de descripción de fuentes debe existir en la fuente PostScript, y los anchos dados en el archivo de descripción de fuentes deben coincidir con los anchos usados en la fuente PostScript. grops asume que un carácter con un nombre de groff de space es en blanco (no hace marcas en la página); puede hacer uso de tal carácter para generar una salida PostScript más eficiente y compacta.

grops es capaz de mostrar todos los glifos en una fuente PostScript; no está limitado a 256 de ellos. enc-file (o la codificación predeterminada si no se especifica un archivo de codificación) solo define el orden de los glifos para los primeros 256 caracteres; todos los demás glifos se acceden con vectores de codificación adicionales que grops produce al

vuelo.

grops puede incrustar en un documento las fuentes que sean necesarias para renderizarlo; esto es cllamado “downloading”. Estas fuentes deben estar en formato PFA. Utilice pfbtops(1) para convertir una fuente Type 1 en formato PFB. Las fuentes descargables deben estar listadas en un archivo download que contenga líneas con el siguiente

formato 
psname
file
donde psname es el nombre PostScript de la fuente, y file es el nombre del archivo que la contiene; las líneas que comienzan con # y las líneas en blanco se ignoran; los campos pueden estar separados por tabulaciones o espacios. file se busca utilizando el mismo mecanismo que para los archivos de descripción de fuentes de groff. El propio archivo download también se busca utilizando este mecanismo; actualmente, solo se utiliza el primer archivo coincidente encontrado en la ruta de búsqueda de descripciones de dispositivos y fuentes.

Si el archivo que contiene una fuente descargable o un documento importado se ajusta a las Convenciones de Estructura de Documentos de Adobe, entonces grops interpreta los comentarios en los archivos lo suficiente para asegurar que su propia salida sea conforme. También proporciona los recursos de fuente necesarios que están listados en el archivo download, así como los recursos de archivo necesarios. También es capaz de manejar dependencias entre recursos. Por ejemplo, suponga que tiene una fuente descargable llamada Garamond, y también una fuente descargable llamada Garamond-Outline que depende de Garamond (típicamente se definiría para copiar el diccionario de fuente de Garamond y cambiar el PaintType), entonces es necesario que Garamond aparezca antes de Garamond-Outline en el documento PostScript. grops maneja esto automáticamente, siempre que el archivo de fuente descargable para Garamond-Outline indique su dependencia en Garamond por medio de las Convenciones de Estructura de Documentos, por ejemplo, comenzando con las siguientes

líneas. 
%!PS-Adobe-3.0 Resource-Font
%%DocumentNeededResources: font Garamond
%%EndComments
%%IncludeResource: font Garamond
En este caso, tanto Garamond como Garamond-Outline necesitarían estar listados en el archivo download. Una fuente descargable no debe incluir su propio nombre en un comentario %%DocumentSuppliedResources.

grops no interpreta comentarios %%DocumentFonts. Deben utilizarse los comentarios %%DocumentNeededResources, %%DocumentSuppliedResources, %%IncludeResource, %%BeginResource y %%EndResource (o posiblemente los antiguos %%DocumentNeededFonts, %%DocumentSuppliedFonts, %%IncludeFont, %%BeginFont y %%EndFo

nt).

El color de trazo y relleno predeterminado es negro. Para colores definidos en el espacio de color “rgb”, se utiliza setrgbcolor; para “cmy” y “cmyk”, setcmykcolor; y para “gray”, setgray. setcmykcolor es un comando de PostScript LanguageLevel 2 y por lo tanto no está disponible en algunas impresoras más

antiguas.

groff 1.19.2 y anteriores contenían descripciones de un conjunto ligeramente diferente de las 35 fuentes base de PostScript nivel 2 definidas por Adobe. El conjunto antiguo tiene 229 glifos y un conjunto más grande de pares de espaciado; el nuevo tiene 314 glifos e incluye el glifo Euro. Por compatibilidad con versiones anteriores, estas descripciones de fuentes antiguas también se instalan en el directorio /usr/share/groff/1.23.0/oldfont/devps.
