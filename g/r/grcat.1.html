GRCAT(1) Manual de comandos generales GRCAT(1)

NOMBRE

grcat - leer desde la entrada estándar, colorearla y escribirla en la salida estándar

SINOPSIS

grcat configuración

DESCRIPCIÓN

configuración es el nombre de un archivo de configuración. Los directorios ~/.grc/, /usr/local/share/grc/, /usr/share/grc/ se buscan para encontrar el archivo (en este orden).

Si el archivo no se encuentra, se asume que es una ruta absoluta de un archivo de configuración ubicado en otro lugar.

El archivo de configuración consiste en entradas, una por expresión regular. Las entradas están separadas por líneas con el primer carácter no alfanumérico (excepto #). Las líneas que comienzan con # o las líneas vacías se ignoran.

Cada entrada consta de varias líneas. Cada línea tiene el formato: palabra_clave=valor donde la palabra clave es una de: regexp, colours, command, concat, skip, count. Solo regexp es obligatoria, pero no tiene mucho sentido por sí sola a menos que especifique al menos una palabra clave colour o command también.

regexp es la expresión regular a coincidir

colours es la lista de colores, separados por comas (puedes especificar solo un color), cada color por grupo de expresión regular especificado en la expresión.

command es el comando que se ejecutará cuando coincida la expresión regular. Su salida se mezclará con la salida estándar normal, use redireccionadores ( >/dev/null) si desea suprimirla.

replace significa que la coincidencia de la expresión regular será reemplazada por el valor, todas las expresiones regulares precedentes se evaluarán contra el texto original, todas las expresiones regulares siguientes se evaluarán contra el texto reemplazado.

skip puede ser yes o no, si es yes, la línea coincidente se omitirá y no se mostrará en la salida. Por defecto es no.

count es una de las palabras: once, more, o stop.

once significa que si la expresión regular coincide, su primera ocurrencia se colorea y el programa continuará con otras expresiones regulares.

more significa que si hay múltiples coincidencias de la expresión regular en una línea, todas ellas se colorearán.

stop significa que la expresión regular se coloreará y el programa pasará a la siguiente línea (es decir, ignorando otras expresiones regulares)

Las expresiones regulares se evalúan de arriba a abajo, esto permite expresiones anidadas y superpuestas. (por ejemplo, coloreas todo dentro de paréntesis con un color, y si una expresión siguiente coincide con el texto dentro de los paréntesis, también se coloreará)
