NOMBRE

grub-btrfsd - Un demonio de OpenRC para actualizar automáticamente el menú de grub con grub-btrfs(8)

cuando se crea una nueva instantánea de btrfs.

SINOPSIS

grub-btrfsd [-h, --help] [-c, --no-color] [-l, --log-file ARCHIVO_LOG] [-r, --recursive] [-s, --syslog] [-t, --timeshift-auto] [-o, --timeshift-old] [-v, --verbose] DIRECTORIOS_INSTANTANEAS

DESCRIPCIÓN

Grub-btrfsd es un script de shell que está diseñado para ejecutarse como un demonio. Grub-btrfsd supervisa un directorio donde se crean o eliminan instantáneas de btrfs a través de inotifywait y ejecuta grub-mkconfig (si grub-mkconfig nunca se ejecutó antes desde que se instaló grub-btrfs) o /etc/grub.d/41_snapshots-btrfs (cuando grub-mkconfig se ejecutó antes con grub-btrfs instalado) cuando algo en ese directorio cambia.

OPCIONES

DIRECTORIOS_INSTANTANEAS

Este argumento especifica las rutas (separadas por espacios) donde grub-btrfsd busca instantáneas recién creadas y eliminaciones de instantáneas. Generalmente lo define el programa utilizado para crear las instantáneas. Por ejemplo, para Snapper, sería /.snapshots. Es posible definir más de un directorio aquí, todos los directorios heredarán la misma configuración (recursivo, etc.). Este argumento no es necesario proporcionarlo si se establece --timeshift-auto.

-c / --no-color

Desactivar los colores en la salida.

-l / --log-file

Este argumento especifica un archivo donde grub-btrfsd debería escribir mensajes de registro.

-r / --recursive

Vigilar el directorio de instantáneas de forma recursiva.

-s / --syslog

Escribir en syslog.

-t / --timeshift-auto

Esta es una bandera para activar la detección automática de la ruta donde Timeshift almacena las instantáneas. Las versiones más nuevas (>=22.06) de Timeshift montan sus instantáneas en /run/timeshift/$PID/backup/timeshift-btrfs. Donde $PID es el ID del proceso de la sesión de Timeshift en ejecución. El PID cambia cada vez que se abre Timeshift. Grub-btrfsd puede encargarse automáticamente de la detección del PID y directorio correctos si se establece esta bandera. En este caso, el argumento DIRECTORIOS_INSTANTANEAS no tiene efecto.

-o / --timeshift-old

Buscar instantáneas en /run/timeshift/backup/timeshift-btrfs en lugar de /run/timeshift/$PID/backup/timeshift-btrfs. Esto se debe usar para versiones de Timeshift <22.06.

-v / --verbose

Hacer que el registro del demonio sea más detallado.

-h / --help

Muestra un breve mensaje de ayuda.

CONFIGURACIÓN

El demonio generalmente se configura a través del archivo /etc/conf.d/grub-btrfsd en sistemas con init de OpenRC y sudo systemctl edit --full grub-btrfsd en sistemas con systemd. En este archivo se pueden configurar los argumentos (ver OPCIONES), que OpenRC pasa al demonio cuando se inicia.

NOTAS

Una configuración común para Snapper sería establecer SNAPSHOTS_DIR a /.snapshots y no establecer --timeshift-auto. Para Timeshift, se establece --timeshift-auto a true y SNAPSHOTS_DIR se puede dejar como está.
