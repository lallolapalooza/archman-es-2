group_member(3) Manual de funciones de biblioteca group_member(3)

NOMBRE

group_member - comprobar si un proceso pertenece a un grupo

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <unistd.h>
int group_member(gid_t gid);
Requisitos de Macro de Prueba de Características para glibc (ver feature_test_macros(7)):

group_member():

    _GNU_SOURCE

DESCRIPCIÓN

La función group_member() comprueba si alguna de las IDs de grupo suplementarias del llamante (tal como se devuelve por getgroups(2)) coincide con gid.

VALOR DE RETORNO

La función group_member() devuelve un valor distinto de cero si alguna de las IDs de grupo suplementarias del llamante coincide con gid, y cero en caso contrario.

ESTÁNDARES

GNU.

VER TAMBIÉN

getgid(2), getgroups(2), getgrouplist(3), group(5)
