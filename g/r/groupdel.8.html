GROUPDEL(8) Comandos de administración del sistema GROUPDEL(8)

NOMBRE

groupdel - eliminar un grupo

SINOPSIS

groupdel [opciones] GRUPO

DESCRIPCIÓN

El comando groupdel modifica los archivos de cuenta del sistema, eliminando todas las entradas que se refieren a GRUPO. El grupo nombrado debe existir.

OPCIONES

Las opciones que se aplican al comando groupdel son:

-f, --force

Esta opción fuerza la eliminación del grupo, incluso si hay algún usuario que tenga el grupo como principal.

-h, --help

Muestra el mensaje de ayuda y sale.

-R, --root CHROOT_DIR

Aplica los cambios en el directorio CHROOT_DIR y utiliza los archivos de configuración del directorio CHROOT_DIR. Solo se admiten rutas absolutas.

-P, --prefix PREFIX_DIR

Aplica los cambios en el directorio PREFIX_DIR y utiliza los archivos de configuración del directorio PREFIX_DIR. Esta opción no realiza chroot y está pensada para preparar un destino de compilación cruzada. Algunas limitaciones: los usuarios/grupos NIS y LDAP no son verificados. La autenticación PAM utiliza los archivos del host. Sin soporte SELINUX.

ADVERTENCIAS

No se puede eliminar el grupo principal de ningún usuario existente. Debe eliminar al usuario antes de eliminar el grupo.

Debe comprobar manualmente todos los sistemas de archivos para asegurarse de que no queden archivos propiedad de este grupo.

CONFIGURACIÓN

Las siguientes variables de configuración en /etc/login.defs cambian el comportamiento de esta herramienta:

MAX_MEMBERS_PER_GROUP (número)

Máximo de miembros por entrada de grupo. Cuando se alcanza el máximo, se inicia una nueva entrada de grupo (línea) en /etc/group (con el mismo nombre, la misma contraseña y el mismo GID).

El valor predeterminado es 0, lo que significa que no hay límites en el número de miembros de un grupo.

Esta característica (grupo dividido) permite limitar la longitud de las líneas en el archivo de grupos. Esto es útil para asegurar que las líneas de los grupos NIS no tengan más de 1024 caracteres.

Si necesita aplicar dicho límite, puede usar 25.

Nota: los grupos divididos pueden no ser compatibles con todas las herramientas (incluso dentro de la suite de herramientas Shadow). No debe usar esta variable a menos que realmente la necesite.

ARCHIVOS

/etc/group

Información de la cuenta del grupo.

/etc/gshadow

Información segura de la cuenta del grupo.

VALORES DE SALIDA

El comando groupdel sale con los siguientes valores:

0

éxito

2

sintaxis de comando inválida

6

el grupo especificado no existe

8

no se puede eliminar el grupo principal del usuario

10

no se puede actualizar el archivo de grupo
