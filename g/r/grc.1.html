NOMBRE

grc - interfaz para el coloreador genérico grcat(1)

SINOPSIS

grc [opciones] comando [argumentos]

DESCRIPCIÓN

grc ejecutará el comando comando con parámetros opcionales [argumentos] canalizando su salida estándar o de error a grcat, con el archivo de configuración apropiado.

El archivo de configuración para grc se determina por el archivo /etc/grc.conf.

Formato de /etc/grc.conf: cada entrada consiste en 2 líneas, entre las entradas puede haber cualquier número de líneas vacías o líneas que comiencen con # (comentarios)

La primera línea es una expresión regular, la segunda línea es el nombre del archivo de configuración para grcat.

El archivo de configuración después de la primera expresión regular que coincida con comando [argumentos] se pasará a grcat como su archivo de configuración.

OPCIONES

--ayuda
Mostrar resumen de opciones.
--version
Mostrar versión.
-e --stderr
Redirigir la salida de error. A menos que también se seleccione -s, esto cancela la redirección de la salida estándar a través de grcat
-s --stdout
Redirigir la salida estándar. Se utiliza para redirigir la salida estándar junto con la opción --stderr.
--color=x
x es uno de activado desactivado auto

--color=activado coloreará (por defecto)

--color=desactivado simplemente ejecutará comando sin colorear.

--color=auto probará si la salida estándar es una tty y coloreará solo cuando lo sea.

VER TAMBIÉN
