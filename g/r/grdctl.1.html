GRDCTL(1) Comandos de usuario GRDCTL(1)

NOMBRE

grdctl - Herramienta de línea de comandos para configurar el Escritorio Remoto de GNOME

SINOPSIS

grdctl [OPCIÓN...] [COMANDO] [SUBCOMANDO...]

DESCRIPCIÓN

grdctl proporciona métodos para configurar el servicio de Escritorio Remoto de GNOME, por ejemplo, estableciendo credenciales.

OPCIONES

--help

Mostrar texto de ayuda.

COMANDOS GENERALES

status

Mostrar el estado actual.

COMANDOS RDP

rdp enable

Habilitar el backend RDP.

rdp disable

Deshabilitar el backend RDP.

rdp set-tls-cert CERT-TLS

Establecer la ruta al certificado TLS.

rdp set-tls-key CLAVE-TLS

Establecer la ruta a la clave TLS.

rdp set-credentials USUARIO CONTRASEÑA

Establecer el nombre de usuario y la contraseña.

rdp clear-credentials

Borrar el nombre de usuario y la contraseña.

rdp enable-view-only

Deshabilitar el control remoto de los dispositivos de entrada.

rdp disable-view-only

Habilitar el control remoto de los dispositivos de entrada.

COMANDOS VNC

vnc enable

Habilitar el backend VNC.

vnc disable

Deshabilitar el backend VNC.

vnc set-password CONTRASEÑA

Establecer la contraseña VNC.

vnc clear-password

Borrar la contraseña VNC.

vnc set-auth-method METODO-AUTENTICACION

Establecer el método de autenticación utilizado para nuevas conexiones VNC. Puede ser password o prompt.

vnc enable-view-only: Deshabilitar el control remoto de los dispositivos de entrada.

vnc disable-view-only

Habilitar el control remoto de los dispositivos de entrada.

ERRORES CONOCIDOS

El rastreador de errores se puede consultar visitando el sitio web https://gitlab.gnome.org/GNOME/gnome-remote-desktop/issues. Antes de enviar un informe de error, verifique que tiene la última versión de gnome-remote-desktop. Muchos errores (mayores y menores) se corrigen en cada lanzamiento, y si el suyo está desactualizado, el problema puede que ya se haya resuelto.
