PWCONV(8) Comandos de gestión del sistema PWCONV(8)

NOMBRE

pwconv, pwunconv, grpconv, grpunconv - convertir entre los archivos de cuentas sombreados y planos del sistema

SINOPSIS

pwconv [opciones]

pwunconv [opciones]

grpconv [opciones]

grpunconv [opciones]

DESCRIPCIÓN

El comando pwconv crea shadow a partir de passwd y un shadow opcionalmente existente.

El comando pwunconv crea un passwd plano a partir de passwd sombreado y shadow, y luego elimina shadow.

El comando grpconv crea gshadow a partir de group y un gshadow opcionalmente existente.

El comando grpunconv crea group plano a partir de group sombreado y gshadow, y luego elimina gshadow.

Estos cuatro programas operan sobre los archivos normales y sombreados de contraseñas y grupos: /etc/passwd, /etc/group, /etc/shadow y /etc/gshadow.

Cada programa adquiere los bloqueos necesarios antes de la conversión. pwconv y grpconv son similares. Primero, se eliminan las entradas del archivo sombreado que no existen en el archivo plano. Luego, se actualizan las entradas del archivo sombreado que no tienen 'x' como contraseña en el archivo plano. Se agregan las entradas sombreadas faltantes. Finalmente, las contraseñas en el archivo plano se reemplazan con 'x'. Estos programas se pueden usar para la conversión inicial y también para actualizar el archivo sombreado si el archivo plano ha sido editado manualmente.

pwconv usará los valores de PASS_MIN_DAYS, PASS_MAX_DAYS y PASS_WARN_AGE de /etc/login.defs al agregar nuevas entradas a /etc/shadow.

De manera similar, pwunconv y grpunconv son similares. Las contraseñas en el archivo plano se actualizan desde el archivo sombreado. Las entradas que existen en el archivo plano pero no en el archivo sombreado se dejan solas. Finalmente, se elimina el archivo sombreado. Parte de la información de envejecimiento de contraseñas se pierde con pwunconv. Convertirá lo que pueda.

OPCIONES

Las opciones que se aplican a los comandos pwconv, pwunconv, grpconv y grpunconv son:

-h, --help

Muestra el mensaje de ayuda y sale.

-R, --root CHROOT_DIR

Aplica los cambios en el directorio CHROOT_DIR y usa los archivos de configuración del directorio CHROOT_DIR. Solo se admiten rutas absolutas.

ERRORES

Los errores en los archivos de contraseñas o grupos (como entradas inválidas o duplicadas) pueden hacer que estos programas se ejecuten en bucle indefinidamente o fallen de otras maneras extrañas. Por favor, ejecute pwck y grpck para corregir cualquier error de este tipo antes de convertir a o desde archivos sombreados.

CONFIGURACIÓN

La siguiente variable de configuración en /etc/login.defs cambia el comportamiento de grpconv y grpunconv:

MAX_MEMBERS_PER_GROUP (número)

Miembros máximos por entrada de grupo. Cuando se alcanza el máximo, se inicia una nueva entrada de grupo (línea) en /etc/group (con el mismo nombre, la misma contraseña y el mismo GID).

El valor predeterminado es 0, lo que significa que no hay límites en el número de miembros de un grupo.

Esta característica (grupo dividido) permite limitar la longitud de las líneas en el archivo de grupos. Esto es útil para asegurarse de que las líneas de los grupos NIS no superen los 1024 caracteres.

Si necesita aplicar dicho límite, puede usar 25.

Nota: Los grupos divididos pueden no ser compatibles con todas las herramientas (incluso en el conjunto de herramientas Shadow). No debe usar esta variable a menos que realmente la necesite.

Las siguientes variables de configuración en /etc/login.defs cambian el comportamiento de pwconv:

PASS_MAX_DAYS (número)

El número máximo de días que se puede usar una contraseña. Si la contraseña tiene más antigüedad que esto, se forzará un cambio de contraseña. Si no se especifica, se asumirá -1 (lo que deshabilita la restricción).

PASS_MIN_DAYS (número)

El número mínimo de días permitidos entre cambios de contraseña. Se rechazarán los intentos de cambio de contraseña realizados antes de este tiempo. Si no se especifica, se asumirá 0 (lo que deshabilita la restricción).

PASS_WARN_AGE (número)

El número de días de advertencia dados antes de que expire una contraseña. Un valor cero significa que la advertencia se da solo el día de la expiración, un valor de -1 significa que no se da ninguna advertencia. Si no se especifica, no se proporcionará ninguna advertencia.

ARCHIVOS

/etc/login.defs

Configuración del conjunto de contraseñas sombreadas.
