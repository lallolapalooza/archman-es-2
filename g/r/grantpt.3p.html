GRANTPT(3P) Manual del programador POSIX GRANTPT(3P)

PROLOG

Esta página del manual forma parte del Manual del programador POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual correspondiente de Linux para detalles sobre el comportamiento en Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

grantpt — otorga acceso al dispositivo esclavo de pseudo-terminal

SINOPSIS

#include <stdlib.h>
int grantpt(int fildes);

DESCRIPCIÓN

La función grantpt() cambiará el modo y la propiedad del dispositivo esclavo de pseudo-terminal asociado con su contraparte maestra de pseudo-terminal. El argumento fildes es un descriptor de archivo que se refiere a un dispositivo maestro de pseudo-terminal. El ID de usuario del esclavo se establecerá en el UID real del proceso que llama y el ID de grupo se establecerá en un ID de grupo no especificado. El modo de permiso del pseudo-terminal esclavo se establecerá como legible y escribible por el propietario, y escribible por el grupo.

El comportamiento de la función grantpt() no está especificado si la aplicación ha instalado un manejador de señales para capturar señales SIGCHLD.

VALOR DE RETORNO

Al completarse con éxito, grantpt() devolverá 0; de lo contrario, devolverá -1 y establecerá errno para indicar el error.

ERRORES

La función grantpt() puede fallar si:

EACCES
No se pudo acceder al dispositivo esclavo de pseudo-terminal correspondiente.
EBADF
El argumento fildes no es un descriptor de archivo abierto válido.
EINVAL
El argumento fildes no está asociado con un dispositivo maestro de pseudo-terminal.
