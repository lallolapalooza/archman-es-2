GRUB-MKNETDIR(1) Comandos de usuario GRUB-MKNETDIR(1)

NOMBRE

grub-mknetdir - prepara un directorio de red para GRUB.

SINOPSIS

grub-mknetdir [OPCIÓN...]

DESCRIPCIÓN

Prepara las imágenes de arranque de red de GRUB en net_directory/subdir asumiendo que net_directory es la raíz de TFTP.

--appended-signature-size=TAMAÑO
Agrega un segmento de nota reservando SIZE bytes para una firma adjunta.
--compress=no|xz|gz|lzo
comprime los archivos de GRUB [opcional]
--disable-cli
interfaz de línea de comandos desactivada.
--disable-shim-lock
desactiva el verificador shim_lock.
--dtb=ARCHIVO
incrusta un DTB específico.
-d, --directory=DIR
usa imágenes y módulos bajo DIR [predeterminado=/usr/lib/grub/<plataforma>].
--fonts=FUENTES
instala FUENTES [predeterminado=unicode].
--install-modules=MÓDULOS
instala solo MÓDULOS y sus dependencias [predeterminado=todos].
-k, --pubkey=ARCHIVO
incrusta ARCHIVO como clave pública para la verificación de firmas.
--locale-directory=DIR usa traducciones bajo DIR
[predeterminado=/usr/share/locale].
--locales=LOCALIZACIONES
instala solo LOCALIZACIONES [predeterminado=todas].
--modules=MÓDULOS
carga previamente los módulos especificados MÓDULOS.
--sbat=ARCHIVO
metadatos SBAT.
--themes=TEMAS
instala TEMAS [predeterminado=starfield].
-v, --verbose
imprime mensajes detallados.
-x, --x509key=ARCHIVO
incrusta ARCHIVO como un certificado x509 para la verificación de firmas adjuntas.
--core-compress=xz|none|auto
elige la compresión a usar para la imagen principal.
--net-directory=DIR
directorio raíz del servidor TFTP.
--subdir=DIR
subdirectorio relativo en el servidor de red.
-?, --help
muestra esta lista de ayuda.
--usage
muestra un breve mensaje de uso.
-V, --version
imprime la versión del programa.

Los argumentos obligatorios u opcionales para las opciones largas son también obligatorios u opcionales para las opciones cortas correspondientes.

Prepara las imágenes de arranque de red de GRUB en net_directory/subdir asumiendo que net_directory es la raíz de TFTP.

Reporta errores a <bug-grub@gnu.org>.
