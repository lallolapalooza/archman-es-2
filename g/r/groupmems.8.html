GROUPMEMS(8) Comandos de Administración del Sistema GROUPMEMS(8)

NOMBRE

groupmems - administrar miembros del grupo principal de un usuario

SINOPSIS

groupmems -a nombre_usuario | -d nombre_usuario | [-g nombre_grupo] | -l | -p

DESCRIPCIÓN

groupmems permite a un usuario administrar su propia lista de membresía de grupo sin necesidad de privilegios de superusuario. La utilidad groupmems es para sistemas que configuran a sus usuarios para estar en su propio grupo principal con el mismo nombre (por ejemplo, invitado / invitado).

Solo el superusuario, como administrador, puede usar groupmems para modificar las membresías de otros grupos.

OPCIONES

Las opciones que se aplican al comando groupmems son:

-a, --add nombre_usuario

Añadir un usuario a la lista de membresía del grupo.

Si el archivo /etc/gshadow existe y el grupo no tiene una entrada en el archivo /etc/gshadow, se creará una nueva entrada.

-d, --delete nombre_usuario

Eliminar un usuario de la lista de membresía del grupo.

Si el archivo /etc/gshadow existe, el usuario será eliminado de la lista de miembros y administradores del grupo.

Si el archivo /etc/gshadow existe y el grupo no tiene una entrada en el archivo /etc/gshadow, se creará una nueva entrada.

-g, --group nombre_grupo

El superusuario puede especificar qué lista de membresía de grupo modificar.

-h, --help

Mostrar mensaje de ayuda y salir.

-l, --list

Listar la lista de membresía del grupo.

-p, --purge

Purgar todos los usuarios de la lista de membresía del grupo.

Si el archivo /etc/gshadow existe y el grupo no tiene una entrada en el archivo /etc/gshadow, se creará una nueva entrada.

-R, --root CHROOT_DIR

Aplicar cambios en el directorio CHROOT_DIR y usar los archivos de configuración del directorio CHROOT_DIR. Solo se admiten rutas absolutas.

CONFIGURACIÓN INICIAL

El ejecutable groupmems debe estar en modo 2710 como usuario root y en el grupo groups. El administrador del sistema puede añadir usuarios al grupo groups para permitirles o no usar la utilidad groupmems para gestionar su propia lista de membresía de grupo.

	$ groupadd -r groups
	$ chmod 2710 groupmems
	$ chown root:groups groupmems
	$ groupmems -g groups -a gk4

CONFIGURACIÓN

Las siguientes variables de configuración en /etc/login.defs cambian el comportamiento de esta herramienta:

MAX_MEMBERS_PER_GROUP (número)

Máximo de miembros por entrada de grupo. Cuando se alcanza el máximo, se inicia un nuevo grupo (línea) en /etc/group (con el mismo nombre, misma contraseña y mismo GID).

El valor predeterminado es 0, lo que significa que no hay límites en el número de miembros de un grupo.

Esta característica (grupo dividido) permite limitar la longitud de las líneas en el archivo de grupos. Esto es útil para asegurar que las líneas de los grupos NIS no sean mayores de 1024 caracteres.

Si necesita forzar dicho límite, puede usar 25.

Nota: los grupos divididos pueden no ser compatibles con todas las herramientas (incluso en la suite de herramientas Shadow). No debe usar esta variable a menos que realmente la necesite.
