GRUB-FILE(1) Comandos de usuario GRUB-FILE(1)

NOMBRE

grub-file - comprobar tipo de archivo

SINOPSIS

file OPCIONES ARCHIVO

DESCRIPCIÓN

Comprueba si ARCHIVO es del tipo especificado.

--is-i386-xen-pae-domu
Comprueba si ARCHIVO puede ser arrancado como un kernel invitado no privilegiado de Xen i386 PAE
--is-x86_64-xen-domu
Comprueba si ARCHIVO puede ser arrancado como un kernel invitado no privilegiado de Xen x86_64
--is-x86-xen-dom0
Comprueba si ARCHIVO puede ser usado como un kernel invitado privilegiado de Xen x86
--is-x86-multiboot
Comprueba si ARCHIVO puede ser usado como un kernel multiboot x86

--is-x86-multiboot2 Comprueba si ARCHIVO puede ser usado como un kernel multiboot2 x86

--is-arm-linux
Comprueba si ARCHIVO es Linux ARM
--is-arm64-linux
Comprueba si ARCHIVO es Linux ARM64
--is-ia64-linux
Comprueba si ARCHIVO es Linux IA64
--is-mips-linux
Comprueba si ARCHIVO es Linux MIPS
--is-mipsel-linux
Comprueba si ARCHIVO es Linux MIPSEL
--is-sparc64-linux
Comprueba si ARCHIVO es Linux SPARC64
--is-powerpc-linux
Comprueba si ARCHIVO es Linux POWERPC
--is-x86-linux
Comprueba si ARCHIVO es Linux x86
--is-x86-linux32
Comprueba si ARCHIVO es Linux x86 que soporta el protocolo de 32 bits
--is-x86-kfreebsd
Comprueba si ARCHIVO es kFreeBSD x86
--is-i386-kfreebsd
Comprueba si ARCHIVO es kFreeBSD i386
--is-x86_64-kfreebsd
Comprueba si ARCHIVO es kFreeBSD x86_64
--is-x86-knetbsd
Comprueba si ARCHIVO es kNetBSD x86
--is-i386-knetbsd
Comprueba si ARCHIVO es kNetBSD i386

--is-x86_64-knetbsd Comprueba si ARCHIVO es kNetBSD x86_64

--is-i386-efi
Comprueba si ARCHIVO es un archivo EFI i386
--is-x86_64-efi
Comprueba si ARCHIVO es un archivo EFI x86_64
--is-ia64-efi
Comprueba si ARCHIVO es un archivo EFI IA64
--is-arm64-efi
Comprueba si ARCHIVO es un archivo EFI ARM64
--is-arm-efi
Comprueba si ARCHIVO es un archivo EFI ARM
--is-riscv32-efi
Comprueba si ARCHIVO es un archivo EFI RISC-V de 32 bits
--is-riscv64-efi
Comprueba si ARCHIVO es un archivo EFI RISC-V de 64 bits
--is-hibernated-hiberfil
Comprueba si ARCHIVO es hiberfil.sys en estado hibernado
--is-x86_64-xnu
Comprueba si ARCHIVO es XNU x86_64 (kernel de Mac OS X)
--is-i386-xnu
Comprueba si ARCHIVO es XNU i386 (kernel de Mac OS X)
--is-xnu-hibr
Comprueba si ARCHIVO es una imagen hibernada de XNU (kernel de Mac OS X)
--is-x86-bios-bootsector
Comprueba si ARCHIVO es un sector de arranque BIOS

-h, --help Muestra esta ayuda y sale. -u, --usage Muestra el uso de este comando y sale.

VER TAMBIÉN

La documentación completa de grub-file se mantiene como un manual de Texinfo. Si los programas info y grub-file están correctamente instalados en su sitio, el comando

info grub-file

debería darle acceso al manual completo.
