Contrairement à l'implémentation d'AT&T, groff ne possède pas de format binaire ; tous les fichiers sont des fichiers texte. (Le troff de Plan 9 a également abandonné le format binaire.) Les fichiers de description des périphériques et des polices pour un périphérique nommé sont stockés dans un répertoire devname. Le fichier de description du périphérique est appelé DESC, et, pour chaque police prise en charge par le périphérique, un fichier de description depolice est appelé f, où f est généralement une abréviation du nom et/ou du style d'une police.
