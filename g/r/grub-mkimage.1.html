GRUB-MKIMAGE(1) Comandos de usuario GRUB-MKIMAGE(1)

NOMBRE

grub-mkimage - crear una imagen arrancable de GRUB

SINOPSIS

grub-mkimage [OPCIÓN...] [OPCIÓN]... [MÓDULOS]

DESCRIPCIÓN

Crear una imagen arrancable de GRUB.

-c, --config=ARCHIVO
incrustar ARCHIVO como una configuración temprana
-C, --compression=(xz|none|auto)
elegir la compresión a usar para la imagen principal
--disable-cli
deshabilitar el acceso a la interfaz de línea de comandos
--disable-shim-lock
deshabilitar el verificador shim_lock
-d, --directory=DIR
usar imágenes y módulos bajo DIR [predeterminado=/usr/lib/grub/<plataforma>]
-D, --dtb=ARCHIVO
incrustar ARCHIVO como un árbol de dispositivos (DTB)
-k, --pubkey=ARCHIVO
incrustar ARCHIVO como clave pública para la verificación de firmas PGP
-m, --memdisk=ARCHIVO
incrustar ARCHIVO como una imagen memdisk

Implica `-p (memdisk)/boot/grub' y anula

cualquier prefijo suministrado previamente, pero el prefijo
en sí mismo puede ser anulado por opciones posteriores
-n, --note
añadir un segmento NOTE para CHRP IEEE1275
-o, --output=ARCHIVO
generar una imagen en ARCHIVO [predeterminado=salida estándar]
-O, --format=FORMATO
generar una imagen en FORMATO formatos disponibles: i386-coreboot, i386-multiboot, i386-pc, i386-xen_pvh, i386-pc-pxe, i386-pc-eltorito, i386-efi, i386-ieee1275, i386-qemu, x86_64-efi, i386-xen, x86_64-xen, mipsel-yeeloong-flash, mipsel-fuloong2f-flash, mipsel-loongson-elf, powerpc-ieee1275, sparc64-ieee1275-raw, sparc64-ieee1275-cdcore, sparc64-ieee1275-aout, ia64-efi, mips-arc, mipsel-arc, mipsel-qemu_mips-elf, mips-qemu_mips-flash, mipsel-qemu_mips-flash, mips-qemu_mips-elf, arm-uboot, arm-coreboot-vexpress, arm-coreboot-veyron, arm-efi, arm64-efi, loongarch64-efi, riscv32-efi, riscv64-efi
-p, --prefix=DIR
establecer el directorio de prefijo
-s, --sbat=ARCHIVO
metadatos SBAT
-S, --appended-signature-size=TAMAÑO
Añadir un segmento de nota reservando TAMAÑO bytes para una firma añadida
-v, --verbose
mostrar mensajes detallados.
-x, --x509key=ARCHIVO
incrustar ARCHIVO como un certificado x509 para la verificación de firmas añadidas
-?, --help
mostrar esta lista de ayuda
--usage
mostrar un mensaje de uso corto
-V, --version
mostrar la versión del programa

Los argumentos obligatorios u opcionales para las opciones largas son también obligatorios u opcionales para cualquier opción corta correspondiente.

REPORTE DE ERRORES

Reportar errores a <bug-grub@gnu.org>.

VER TAMBIÉN

grub-install(8), grub-mkrescue(1), grub-mknetdir(8)
