NOMBRE

grilo-test-ui - Interfaz gráfica de prueba de Grilo

SINOPSIS

grilo-test-ui [opciones]

DESCRIPCIÓN

Esta página del manual documenta brevemente el comando grilo-test-ui.

grilo-test-ui es una interfaz gráfica para Grilo que permite al usuario realizar consultas y ver sus resultados.

OPCIONES

-h, --help
Muestra un resumen de las opciones de grilo-test-ui.
--help-grl
Muestra un resumen de las opciones de Grilo.
--help-all
Muestra un resumen de todas las opciones.
