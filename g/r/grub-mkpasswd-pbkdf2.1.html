GRUB-MKPASSWD-PBKDF2(1) Comandos de usuario GRUB-MKPASSWD-PBKDF2(1)

NOMBRE

grub-mkpasswd-pbkdf2 - genera contraseña cifrada para GRUB

SINOPSIS

grub-mkpasswd-pbkdf2 [OPCIÓN...] [OPCIONES]

DESCRIPCIÓN

Genera un hash de contraseña PBKDF2.

-c, --iteration-count=NÚM
Número de iteraciones PBKDF2
-l, --buflen=NÚM
Longitud del hash generado
-s, --salt=NÚM
Longitud de la sal
-?, --help
mostrar esta lista de ayuda
--usage
mostrar un mensaje de uso corto
-V, --version
imprimir la versión del programa

Los argumentos obligatorios u opcionales para las opciones largas son también obligatorios u opcionales para las opciones cortas correspondientes.

REPORTAR ERRORES

Reportar errores a <bug-grub@gnu.org>.

VER TAMBIÉN

grub-mkconfig(8)

La documentación completa de grub-mkpasswd-pbkdf2 se mantiene como un manual de Texinfo. Si los programas info y grub-mkpasswd-pbkdf2 están instalados correctamente en su sitio, el comando

info grub-mkpasswd-pbkdf2

debería darle acceso al manual completo.
