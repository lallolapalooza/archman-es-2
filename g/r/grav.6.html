NOMBRE

grav - dibuja una simulación orbital simple

SINOPSIS

grav [--display host:display.screen] [--foreground color] [--background color] [--window] [--root] [--window-id número][--mono] [--install] [--visual visual] [--ncolors entero] [--delay microsegundos] [--count entero] [--decay] [--no-decay] [--trail] [--no-trail]

[--fps]

DESCRIPCIÓN

El programa grav dibuja una simulación orbital simple.

OPCIONES

grav acepta las siguientes opciones:

--window
Dibuja en una ventana recién creada. Este es el valor predeterminado.
--root
Dibuja en la ventana raíz.
--window-id número
Dibuja en la ventana especificada.
--mono
Si se está en una pantalla en color, simula estar en una pantalla monocromática.
--install
Instala un mapa de colores privado para la ventana.
--visual visual
Especifica qué visual usar. Los valores legales son el nombre de una clase visual, o el número de ID (decimal o hexadecimal) de un visual específico.
--ncolors entero
Cuántos colores se deben usar (si es posible). Por defecto 64. Los colores se eligen aleatoriamente.
--count entero
Por defecto 12.
--decay
--no-decay
Si las órbitas deben decaer.
--trail
--no-trail
Si los objetos deben dejar rastros detrás de ellos (lo que hace que parezca vagamente una cámara de niebla).
--fps
Muestra la tasa de fotogramas actual y la carga de la CPU.

ENTORNO

DISPLAY
para obtener el host y el número de pantalla predeterminados.
XENVIRONMENT
para obtener el nombre de un archivo de recursos que anula los recursos globales almacenados en la propiedad RESOURCE_MANAGER.
XSCREENSAVER_WINDOW
El ID de la ventana a usar con --root.
