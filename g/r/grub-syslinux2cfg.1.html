GRUB-SYSLINUX2CFG(1) Comandos de usuario GRUB-SYSLINUX2CFG(1)

NOMBRE

grub-syslinux2cfg - transformar configuración de syslinux en grub.cfg

SINOPSIS

grub-syslinux2cfg [OPCIÓN...] ARCHIVO

DESCRIPCIÓN

Transforma la configuración de syslinux en una de GRUB.

-c, --cwd=DIR
directorio actual de syslinux [por defecto es el directorio padre del archivo de entrada].
-i, --isolinux
asume que la entrada es un archivo de configuración de isolinux.
-o, --output=ARCHIVO
escribe la salida en ARCHIVO [por defecto=stdout].
-p, --pxelinux
asume que la entrada es un archivo de configuración de pxelinux.
-r, --root=DIR
directorio raíz del disco de syslinux [por defecto=/].
-s, --syslinux
asume que la entrada es un archivo de configuración de syslinux.
-t, --target-root=DIR
directorio raíz tal como se verá en tiempo de ejecución [por defecto=/].
-T, --target-cwd=DIR
directorio actual de syslinux tal como se verá en tiempo de ejecución [por defecto es el directorio padre del archivo de entrada].
-v, --verbose
muestra mensajes detallados.
-?, --help
muestra esta lista de ayuda
--usage
muestra un breve mensaje de uso
-V, --version
muestra la versión del programa

Los argumentos obligatorios u opcionales para las opciones largas son también obligatorios u opcionales para las opciones cortas correspondientes.

REPORTE DE ERRORES

Reporta errores a <bug-grub@gnu.org>.

VER TAMBIÉN
