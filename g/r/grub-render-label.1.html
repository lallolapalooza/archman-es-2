GRUB-RENDER-LABEL(1) Comandos de usuario GRUB-RENDER-LABEL(1)

NOMBRE

grub-render-label - generar un .disk_label para Macs de Apple.

SINOPSIS

grub-render-label [OPCIÓN...] [OPCIONES]

DESCRIPCIÓN

Renderiza .disk_label de Apple.

-b, --bgcolor=COLOR
usa COLOR para el fondo
-c, --color=COLOR
usa COLOR para el texto
-f, --font=ARCHIVO
usa ARCHIVO como fuente (PF2).
-i, --input=ARCHIVO
lee el texto desde ARCHIVO.
-o, --output=ARCHIVO
establece el nombre del archivo de salida. Por defecto es STDOUT
-t, --text=CADENA
establece la etiqueta a renderizar
-v, --verbose
imprime mensajes detallados.
-?, --help
muestra esta lista de ayuda
--usage
muestra un breve mensaje de uso
-V, --version
imprime la versión del programa

Los argumentos obligatorios u opcionales para las opciones largas también son obligatorios u opcionales para cualquier opción corta correspondiente.

REPORTE DE ERRORES

Reporta errores a <bug-grub@gnu.org>.

VER TAMBIÉN

La documentación completa de grub-render-label se mantiene como un manual de Texinfo. Si los programas info y grub-render-label están correctamente instalados en tu sitio, el comando

info grub-render-label

debería darte acceso al manual completo.
