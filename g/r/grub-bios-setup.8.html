GRUB-BIOS-SETUP(8) Utilidades de Administración del Sistema GRUB-BIOS-SETUP(8)

NOMBRE

grub-bios-setup - configurar un dispositivo para arrancar usando GRUB

SINOPSIS

grub-bios-setup [OPCIÓN...] DISPOSITIVO

DESCRIPCIÓN

Configura imágenes para arrancar desde DISPOSITIVO.

Normalmente no deberías ejecutar este programa directamente. Usa grub-install en su lugar.

-a, --allow-floppy
hace que la unidad también sea arrancable como disquete (predeterminado para dispositivos fdX). Puede fallar en algunas BIOS.
-b, --boot-image=ARCHIVO
usa ARCHIVO como imagen de arranque [predeterminado=boot.img]
-c, --core-image=ARCHIVO
usa ARCHIVO como imagen principal [predeterminado=core.img]
-d, --directory=DIR
usa los archivos GRUB en el directorio DIR [predeterminado=//boot/grub]
-f, --force
instala incluso si se detectan problemas
-m, --device-map=ARCHIVO
usa ARCHIVO como el mapa de dispositivos [predeterminado=//boot/grub/device.map]
--no-rs-codes
No aplica ningún código reed-solomon al incrustar core.img. Esta opción solo está disponible en destinos BIOS x86.
-s, --skip-fs-probe
no sondear sistemas de archivos en DISPOSITIVO
-v, --verbose
imprime mensajes detallados.
-?, --help
muestra esta lista de ayuda
--usage
muestra un breve mensaje de uso
-V, --version
imprime la versión del programa

Los argumentos obligatorios u opcionales para las opciones largas también son obligatorios u opcionales para cualquier opción corta correspondiente.

DISPOSITIVO debe ser un dispositivo del sistema operativo (por ejemplo, /dev/sda).

REPORTAR ERRORES

Informa de errores a <bug-grub@gnu.org>.

VER TAMBIÉN

grub-install(8), grub-mkimage(1), grub-mkrescue(1)

La documentación completa de grub-bios-setup se mantiene como un manual Texinfo. Si los programas info y grub-bios-setup están correctamente instalados en su sitio, el comando

info grub-bios-setup

debería darle acceso al manual completo.
