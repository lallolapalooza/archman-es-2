NOMBRE

greetd-ipc - Protocolo IPC para greetd

DESCRIPCIÓN

Detalla el protocolo de comunicación entre procesos (IPC) para greetd(1). Este protocolo IPC se puede utilizar para crear y gestionar sesiones bajo greetd.

El protocolo IPC utiliza un socket UNIX como método de comunicación. La ruta al socket se almacena en la variable de entorno GREETD_SOCK.

FORMATO DE MENSAJE Y RESPUESTA

El formato para mensajes y respuestas es:

<longitud-del-payload> <payload>
Donde 
<longitud-del-payload> es un entero de 32 bits en orden de bytes nativo
<payload> es una cadena JSON codificada en UTF-8.

Por ejemplo, enviar el comando "create_session" se vería como el siguiente volcado hexadecimal:

00000000  2c 00 00 00 7b 22 74 79  70 65 22 3a 20 22 63 72  |,...{"type": "cr|
00000010  65 61 74 65 5f 73 65 73  73 69 6f 6e 22 2c 20 22  |eate_session", "|
00000020  75 73 65 72 6e 61 6d 65  22 3a 20 22 6d 65 22 7d  |username": "me"}|

MENSAJES

Solicitudes

TIPO DE MENSAJE CAMPOS PROPÓSITO
create_session username (cadena) Crea una sesión e inicia un intento de inicio de sesión para el usuario dado. La sesión está lista para iniciarse si se devuelve un éxito.
post_auth_message_response response (cadena, opcional) Responde a un mensaje de autenticación. Si el mensaje fue informativo (info, error), entonces no es necesario establecer una respuesta en este mensaje. La sesión está lista para iniciarse si se devuelve un éxito.
start_session cmd (array de cadenas), env (array de cadenas) Solicita que la sesión se inicie utilizando la línea de comandos proporcionada, añadiendo el entorno suministrado al creado por PAM. La sesión se iniciará después de que termine el proceso del greeter.
cancel_session Cancela la sesión que se está configurando actualmente.

Respuestas

TIPO DE MENSAJE CAMPOS PROPÓSITO
success Indica que la solicitud fue exitosa.
error error_type (enum como cadena), description (cadena) Indica que la solicitud falló.
auth_message auth_message_type (enum como cadena), auth_message (cadena) Indica que se debe responder a un mensaje de autenticación para continuar el flujo de autenticación. No hay límites en el número y tipo de mensajes que pueden requerirse para que la autenticación sea exitosa, y un greeter no debe hacer suposiciones sobre los mensajes. Debe ser respondido con post_auth_message_response o cancel_session.

Enums de tipo de mensaje de autenticación

TIPO DE MENSAJE DE AUTENTICACIÓN PROPÓSITO
visible Indica que la entrada del usuario debe ser visible cuando responda a esta pregunta.
secret Indica que la entrada del usuario debe considerarse secreta cuando responda a esta pregunta.
info Indica que este mensaje es informativo, no una pregunta.
error Indica que este mensaje es un error, no una pregunta.

Enums de error

TIPO DE ERROR PROPÓSITO
auth_error Indica que la autenticación falló. Este no es un error fatal, y es probablemente causado por credenciales incorrectas. Tratar según corresponda.
error Un error general. Consulte la descripción del error para obtener más información.
