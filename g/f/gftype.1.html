GFTYPE(1) Manual de comandos generales GFTYPE(1)

NOMBRE

gftype - traduce un archivo de fuente genérico para que lo lean los humanos

SINOPSIS

gftype [-i] [-m] nombre_archivo_gf [nombre_archivo_salida]

DESCRIPCIÓN

Esta página del manual no pretende ser exhaustiva. La documentación completa para esta versión de TeX se puede encontrar en el archivo info o en el manual Web2C: A TeX implementation.

El programa gftype traduce un archivo gf (fuente genérica) generado por, por ejemplo, mf(1), a un archivo que los humanos puedan leer. También sirve como programa de validación de archivos gf (es decir, si gftype puede leerlo, es correcto) y como ejemplo de programa de lectura de gf para otro software que quiera leer archivos gf.

El nombre_archivo_gf en la línea de comandos debe estar completo. Dado que la resolución forma parte de la extensión, no tendría sentido añadir una extensión predeterminada como se hace con el software de lectura de TeX o DVI. Si no se especifica ningún nombre_archivo_salida, la salida va a stdout.

OPCIONES

El archivo de salida incluye imágenes de mapa de bits de los caracteres, si se especifica -i en la línea de comandos, y una lista simbólica de los comandos gf, si se especifica -m.

AMBIENTE

gftype busca nombre_archivo_gf utilizando la variable de entorno GFFONTS. Si esta no está establecida, utiliza la variable TEXFONTS. Si esta tampoco está establecida, utiliza la predeterminada del sistema.

VER TAMBIÉN

dvitype(1), pktype(1).
Donald E. Knuth et al., Metafontware.

AUTORES

David Fuchs y Don Knuth escribieron el programa. Se publicó como parte del informe técnico Metafontware, disponible en el TeX Users Group. Paul Richards lo adaptó originalmente a Unix.
