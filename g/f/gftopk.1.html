GFTOPK(1) Manual de comandos generales GFTOPK(1)

NOMBRE

gftopk - convierte archivos de fuente genéricos a archivos de fuente empaquetados

SINOPSIS

gftopk [-v] nombre_archivo_gf [nombre_archivo_pk]

DESCRIPCIÓN

Esta página del manual no pretende ser exhaustiva. La documentación completa para esta versión de TeX se puede encontrar en el archivo info o en el manual Web2C: Una implementación de TeX.

El programa gftopk convierte un archivo de fuente genérico (salida de, por ejemplo, mf(1)) a un archivo de fuente empaquetado (pk) para su uso por programas que leen DVI. Los archivos de fuente empaquetados (archivos pk) son mucho más pequeños que los archivos gf correspondientes, por lo que generalmente son el formato de fuente preferido.

El nombre_archivo_gf en la línea de comandos debe estar completo. Dado que la resolución forma parte de la extensión, no tendría sentido añadir una extensión predeterminada como se hace con TeX o el software de lectura de DVI. El nombre_archivo_pk por defecto es el mismo nombre (sin extensión) que el nombre_archivo_gf, y se coloca en el directorio de trabajo actual con el sufijo pk reemplazando a gf. Por ejemplo, el archivo de entrada cmr10.300gf se convertiría en cmr10.300pk.

OPCIONES

A menos que se indique la opción -v, gftopk opera silenciosamente. Con -v, el número de versión del programa y las estadísticas sobre el empaquetado se envían a stdout.

ENTORNO

gftopk busca nombre_archivo_gf primero en el directorio actual. Si no está allí, utiliza la variable de entorno GFFONTS. Si esta no está establecida, utiliza la variable TEXFONTS. Si esta no está establecida, utiliza la configuración predeterminada del sistema.

Consulte tex(1) para obtener detalles sobre la búsqueda.

VER TAMBIÉN

gftype(1), pktogf(1), pktype(1).
Donald E. Knuth et al., Metafontware.

AUTORES

Tomas Rokicki escribió el programa. Fue publicado como parte del informe técnico Metafontware, disponible en el TeX Users Group. Paul Richards lo adaptó originalmente a Unix.
