GFTODVI(1) Manual de comandos generales GFTODVI(1)

NOMBRE

gftodvi - crear hojas de prueba a partir de archivos de fuente genéricos

SINOPSIS

gftodvi [-offset-etiqueta-desbordamiento=real] [-verbose] nombre_archivo_gf

DESCRIPCIÓN

Esta página del manual no pretende ser exhaustiva. La documentación completa de esta versión de TeX se puede encontrar en el archivo info o en el manual Web2C: Una implementación de TeX.

El programa gftodvi convierte un archivo de fuente genérico (gf) generado, por ejemplo, por mf(1), a un archivo independiente del dispositivo (DVI) (que luego puede ser compuesto utilizando el mismo software que ya se ha escrito para TeX). Los caracteres del archivo gf aparecerán uno por página, con etiquetas, títulos y anotaciones según lo especificado en el Apéndice H (Pruebas de impresión) de The Metafontbook.

gftodvi utiliza otras fuentes además del archivo gf principal. Se utiliza una fuente `gris' para componer los píxeles que componen el carácter. (No querríamos que todos los píxeles fueran simplemente negros, ya que de lo contrario se perderían las etiquetas, los puntos clave y otra información). Se utiliza una fuente `título' para la información en la parte superior de la página. Se utiliza una fuente `etiqueta' para las etiquetas en los puntos clave de la figura. Se utiliza una fuente `inclinada' para componer líneas diagonales, que de lo contrario tendrían que simularse utilizando reglas horizontales y verticales. Las fuentes por defecto gris, título y etiqueta son gray, cmr8 y cmtt10, respectivamente; no hay fuente inclinada por defecto.

Para cambiar las fuentes predeterminadas, puede usar comandos special en su archivo fuente de Metafont, o puede cambiar las fuentes en línea. Se inicia un diálogo en línea si finaliza el nombre_archivo_gf con `/'. Por ejemplo,
gftodvi cmr10.300gf/
Sustitución de fuente especial: fuente gris negro
OK; ¿alguna más? fuente gris área /home/art/don/
OK; ¿alguna más? fuente inclinada /home/fonts/slantimagen6
OK; ¿alguna más? <RET>
utilizará /home/art/don/black como fuente `gris' y /home/fonts/slantimagen6 como fuente `inclinada' (este nombre indica una fuente para líneas con pendiente 1/6 a la resolución de una impresora Imagen).

El nombre_archivo_gf en la línea de comandos debe estar completo. Dado que la resolución forma parte de la extensión, no tendría sentido añadir una extensión predeterminada como se hace con TeX o software de lectura de DVI. El nombre del archivo de salida utiliza la misma raíz que el archivo gf, con la extensión .dvi añadida. Por ejemplo, el archivo de entrada cmr10.2602gf se convertiría en cmr10.dvi.

OPCIONES

El argumento para -offset-etiqueta-desbordamiento especifica la distancia desde el borde derecho del cuadro delimitador del carácter en la que se componen las ecuaciones de desbordamiento (si las hay). El valor se da en puntos TeX. El valor predeterminado es poco más de dos pulgadas.

Sin la opción -verbose, gftodvi opera en silencio. Con ella, se imprime un encabezado y un informe de progreso en stdout.

ENTORNO

gftodvi busca nombre_archivo_gf utilizando la variable de entorno GFFONTS. Si no está configurada, utiliza la variable TEXFONTS. Si no está configurada, utiliza la configuración predeterminada del sistema.

Consulte tex(1) para obtener detalles sobre la búsqueda.

ARCHIVOS

{gray.tfm,...}
Las fuentes predeterminadas.
{gray.mf,...}
Las fuentes de Metafont.
