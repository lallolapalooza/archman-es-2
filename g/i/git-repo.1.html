NOMBRE

git-repo - Recuperar información sobre el repositorio

SINOPSIS

git repo info [--format=(keyvalue|nul)] [-z] [<clave>...]
git repo structure [--format=(table|keyvalue|nul)]

DESCRIPCIÓN

Recuperar información sobre el repositorio.

ESTE COMANDO ES EXPERIMENTAL. EL COMPORTAMIENTO PUEDE CAMBIAR.

COMANDOS

info [--format=(keyvalue|nul)] [-z] [<clave>...]

Recuperar información relacionada con metadatos del repositorio actual. Solo se devolverán los datos solicitados en función de sus claves (ver la sección "CLAVES DE INFO" más abajo).

Los valores se devuelven en el mismo orden en que se solicitaron sus respectivas claves.

El formato de salida se puede elegir mediante la bandera --format. Se admiten dos formatos:

keyvalue

muestra pares clave-valor, uno por línea, utilizando el carácter = como delimitador entre la clave y el valor. Los valores que contienen caracteres "inusuales" se citan como se explica para la variable de configuración core.quotePath (véase git-config(1)). Este es el valor predeterminado.

nul

similar a keyvalue, pero utiliza un carácter de nueva línea como delimitador entre la clave y el valor, y un carácter NUL después de cada valor. Este formato es más adecuado para ser analizado por otras aplicaciones que keyvalue. A diferencia del formato keyvalue, los valores nunca se citan.

-z es un alias para --format=nul.

structure [--format=(table|keyvalue|nul)]

Recuperar estadísticas sobre la estructura del repositorio actual. Se informa los siguientes tipos de información:
•Recuentos de referencias categorizados por tipo
•Recuentos de objetos alcanzables categorizados por tipo

El formato de salida se puede elegir mediante la bandera --format. Se admiten tres formatos:

table

Muestra las estadísticas del repositorio en una tabla fácil de leer. Este formato puede cambiar y no está destinado al análisis por máquina. Este es el formato predeterminado.

keyvalue

Cada línea de salida contiene un par clave-valor para una estadística del repositorio. El carácter = se utiliza para delimitar entre la clave y el valor. Los valores que contienen caracteres "inusuales" se citan como se explica para la variable de configuración core.quotePath (véase git-config(1)).

nul

Similar a keyvalue, pero utiliza un carácter NUL para delimitar entre pares clave-valor en lugar de una nueva línea. También utiliza un carácter de nueva línea como delimitador entre la clave y el valor en lugar de =. A diferencia del formato keyvalue, los valores que contienen caracteres "inusuales" nunca se citan.

CLAVES DE INFO

Para obtener un conjunto de valores de git repo info, debes proporcionar las claves que los identifican. Aquí tienes una lista de las claves disponibles y los valores que devuelven:

layout.bare

true si se trata de un repositorio bare, de lo contrario false.

layout.shallow

true si se trata de un repositorio superficial, de lo contrario false.

object.format

El formato de objeto (algoritmo hash) utilizado en el repositorio.

references.format

El formato de almacenamiento de referencias. Los valores válidos son:
•files para archivos sueltos con refs empaquetadas. Este es el valor predeterminado.
•reftable para el formato reftable. Este formato es experimental y sus detalles internos están sujetos a cambios.

EJEMPLOS

•Recupera el formato de referencia del repositorio actual: 
git repo info references.format
•Recupera si el repositorio actual es bare y si es superficial utilizando el formato nul: 
git repo info --format=nul layout.bare layout.shallow
