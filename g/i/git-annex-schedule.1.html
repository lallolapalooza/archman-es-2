NOMBRE

git-annex-schedule - obtener o establecer trabajos programados

SINOPSIS

git annex schedule repositorio [expresión]

DESCRIPCIÓN

El demonio git-annex-assistant(1) puede configurarse para ejecutar trabajos programados. Esto es similar a cron y anacron (y puedes usarlos si lo prefieres), pero tiene la ventaja de estar integrado en git-annex, y por lo tanto poder, por ejemplo, hacer fsck de un repositorio en una unidad extraíble cuando la unidad se conecta.

Cuando se ejecuta con una expresión, configura trabajos programados para ejecutarse en un momento particular. Esto puede usarse para hacer que el asistente ejecute periódicamente fscks incrementales.

Cuando se ejecuta sin una expresión, muestra los trabajos programados actuales para el repositorio.

EXPRESIONES

Estas acciones están disponibles: "fsck self", "fsck UUID" (donde UUID es el UUID de un remoto para hacer fsck). Después de la acción viene la duración permitida para la acción, y finalmente la programación de cuándo ejecutarla.

Para programar múltiples trabajos, sepáralos con "; ".

Algunos ejemplos:


fsck self 30m cada día a cualquier hora
fsck self 1h cada mes a las 3 AM
fsck self 1h el día 1 de cada mes a cualquier hora
fsck self 1h cada semana divisible por 2 a cualquier hora

OPCIONES

Las git-annex-common-options(1) pueden ser usadas.

VER TAMBIÉN

git-annex-assistant(1)
