NOMBRE

git-annex-oldkeys - lista las claves usadas para versiones antiguas de los archivos

SINOPSIS

git annex oldkeys [ruta ...]

DESCRIPCIÓN

Lista las claves usadas para versiones antiguas de los archivos o directorios especificados.

La salida de este comando puede ser enviada a través de una tubería a un comando como git-annex drop --batch-keys

Las claves se listan en orden, de la más nueva a la más antigua.

Al listar claves antiguas para un directorio, se incluirán las claves usadas por archivos eliminados que estaban en ese directorio en commits anteriores.

OPCIONES

--unchecked
Por defecto, este comando no lista una clave que también sea usada por cualquier archivo en la rama actualmente verificada. Esta opción hace que también se listen dichas claves.
El comportamiento por defecto evita sorpresas al soltar las claves listadas. Esta opción puede ser útil, por ejemplo, al copiar todas las versiones antiguas de un archivo a un remoto.
--revision-range=valor
Solo lista claves antiguas usadas en el rango de revisiones especificado. Esto funciona igual que la opción de rango de revisiones de git log. Consulte gitrevisions(7) para obtener documentación sobre el formato de esta opción.
Por ejemplo, para listar solo las claves usadas desde la etiqueta v1.0, use --revision-range=v1.0..HEAD
También se pueden usar las opciones comunes de git-annex (git-annex-common-options(1)).
