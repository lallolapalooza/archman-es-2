NOMBRE

git-annex-fromkey - añade un archivo usando una clave específica

SINOPSIS

git annex fromkey [clave archivo ...]

DESCRIPCIÓN

Este comando de nivel de plomería puede ser utilizado para configurar manualmente un archivo en el repositorio de git para enlazar a una clave especificada.

Se pueden dar múltiples pares de archivo y clave en una sola línea de comando.

Si no se especifica ningún par clave-archivo en la línea de comandos, se usa entrada por lotes, igual que si se hubiera especificado la opción --batch.

Normalmente la clave es una clave formateada por git-annex. Sin embargo, para facilitar el uso de esto para añadir URLs, si la clave no puede ser analizada como una clave, y es una URL válida, se construye una clave de URL a partir de la URL. Tenga en cuenta que esto no registra la URL como una ubicación de la clave; use git-annex-registerurl(1) para hacer eso.

OPCIONES

--force
Permite que un archivo se enlace a una clave cuyo contenido no está en el repositorio local. Es posible que la clave no sea conocida por git-annex en absoluto.
--batch
En el modo de entrada por lotes, las líneas se leen desde la entrada estándar, y cada línea debe contener una clave y un nombre de archivo, separados por un solo espacio.
-z
Cuando está en modo por lotes, la entrada está delimitada por nulos en lugar de los saltos de línea habituales.
(Nota: para que esto se use, debe habilitar explícitamente el modo por lotes con --batch)
--json
Habilita la salida JSON. Esto está destinado a ser analizado por programas que utilizan git-annex. Cada línea de salida es un objeto JSON.
También se pueden utilizar las opciones comunes de git-annex(1).
