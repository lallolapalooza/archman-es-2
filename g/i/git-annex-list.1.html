NOMBRE

git-annex-list - mostrar qué remotos contienen archivos

SINOPSIS

git annex list [ruta ...]

DESCRIPCIÓN

Muestra una tabla de los remotos que contienen los contenidos de los archivos especificados. Esto es similar a git annex whereis pero con una visualización más compacta.

OPCIONES

--allrepos
Por defecto, solo se muestran los remotos configurados; esta opción añade todos los repositorios conocidos a la lista.
opciones de coincidencia de archivos
Se pueden utilizar las opciones de coincidencia de archivos de git-annex-matching-options(1) para especificar los archivos a listar.
También se pueden usar las opciones comunes de git-annex-common-options(1).
