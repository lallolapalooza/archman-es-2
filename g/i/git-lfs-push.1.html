NOMBRE

git-lfs-push - Empujar archivos grandes en cola al punto final de Git LFS

SINOPSIS

git lfs push [opciones] <remoto> [<ref>...]
git lfs push <remoto> [<ref>...]
git lfs push [opciones] <remoto> --stdin git lfs push --object-id <remoto> [<oid>...] git lfs push --object-id <remoto> --stdin

DESCRIPCIÓN

Sube archivos de Git LFS al punto final configurado para el remoto de Git actual. Por defecto, filtra los objetos que ya están referenciados por la clonación local del remoto.

OPCIONES

--dry-run

Imprime los archivos que se empujarían, sin empujarlos realmente.

--all

Esto empuja todos los objetos al remoto que están referenciados por cualquier commit alcanzable desde las refs proporcionadas como argumentos. Si no se proporcionan refs, se empujan todas las refs locales. Ten en cuenta que este comportamiento difiere del de git-lfs-fetch(1) cuando se utiliza su opción --all; en ese caso, se obtienen todas las refs, incluyendo refs distintas de las que se encuentran en refs/heads y refs/tags. Si estás migrando un repositorio con estos comandos, asegúrate de ejecutar git lfs push para cualquier ref remota adicional que contenga objetos de Git LFS no alcanzables desde tus refs locales.

--object-id

Esto empuja solo los OID de objetos listados al final del comando, separados por espacios.

--stdin

Lee una lista de refs delimitadas por saltos de línea (o IDs de objetos cuando se usa --object-id) desde la entrada estándar en lugar de la línea de comandos.

VER TAMBIÉN

git-lfs-fetch(1), git-lfs-pre-push(1).

Parte de la suite git-lfs(1).
