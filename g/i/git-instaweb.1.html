GIT-INSTAWEB(1) Manual de Git GIT-INSTAWEB(1)

NOMBRE

git-instaweb - Navega instantáneamente en tu repositorio de trabajo en gitweb

SINOPSIS

git instaweb [--local] [--httpd=<httpd>] [--port=<puerto>]
               [--browser=<navegador>]
git instaweb [--start] [--stop] [--restart]

DESCRIPCIÓN

Un script sencillo para configurar gitweb y un servidor web para navegar por el repositorio local.

OPCIONES

-l, --local

Vincula el servidor web únicamente a la IP local (127.0.0.1).

-d, --httpd

La línea de comandos del demonio HTTP que se ejecutará. Se pueden especificar opciones de línea de comandos aquí, y el archivo de configuración se añadirá al final de la línea de comandos. Actualmente se soportan apache2, lighttpd, mongoose, plackup, python y webrick. (Por defecto: lighttpd)

-m, --module-path

La ruta del módulo (solo es necesario si httpd es Apache). (Por defecto: /usr/lib/apache2/modules)

-p, --port

El número de puerto al que se vinculará el httpd. (Por defecto: 1234)

-b, --browser

El navegador web que se utilizará para ver la página de gitweb. Esto se pasará al script auxiliar git web--browse junto con la URL de la instancia de gitweb. Consulte git-web--browse(1) para obtener más información sobre esto. Si el script falla, la URL se imprimirá en la salida estándar.

start, --start

Inicia la instancia httpd y sale. Regenera los archivos de configuración según sea necesario para iniciar una nueva instancia.

stop, --stop

Detiene la instancia httpd y sale. Esto no genera ninguno de los archivos de configuración para iniciar una nueva instancia, ni cierra el navegador.

restart, --restart

Reinicia la instancia httpd y sale. Regenera los archivos de configuración según sea necesario para iniciar una nueva instancia.

CONFIGURACIÓN

Puedes especificar la configuración en tu archivo .git/config

[instaweb]
        local = true
        httpd = apache2 -f
        port = 4321
        browser = konqueror
        modulePath = /usr/lib/apache2/modules

Si la variable de configuración instaweb.browser no está establecida, se utilizará web.browser en su lugar si está definida. Consulte git-web--browse(1) para obtener más información sobre esto.
