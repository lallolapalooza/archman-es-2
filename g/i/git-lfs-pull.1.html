NOMBRE

git-lfs-pull - Descargar todos los archivos Git LFS para la referencia actual y el checkout

SINOPSIS

git lfs pull [opciones] [<remoto>]

DESCRIPCIÓN

Descarga objetos Git LFS para la referencia actualmente seleccionada y actualiza la copia de trabajo con el contenido descargado si es necesario.

Esto es generalmente equivalente a ejecutar los siguientes dos comandos:

$ git lfs fetch [opciones] [<remoto>]
$ git lfs checkout

Si la versión instalada de Git es al menos 2.42.0, en un repositorio no vacío, este comando descargará y seleccionará objetos Git LFS para archivos solo si están presentes en el índice de Git y si coinciden con un atributo de filtro de Git LFS de un archivo .gitattributes que esté presente en el índice o en el árbol de trabajo actual (o, como siempre ocurre, si coinciden con un atributo de filtro de Git LFS en un archivo .gitattributes local como $GIT_DIR/info/attributes). Estas restricciones no se aplican con versiones anteriores de Git.

En un repositorio con clonación parcial o checkout disperso, por lo tanto, es aconsejable seleccionar todos los archivos .gitattributes de HEAD antes de usar este comando, si se instala Git v2.42.0 o posterior. Alternativamente, la variable de entorno GIT_ATTR_SOURCE puede establecerse en HEAD, lo que hará que Git solo lea atributos de los archivos .gitattributes en HEAD e ignore los del índice o árbol de trabajo.

En un repositorio vacío, si la versión instalada de Git es al menos 2.42.0, este comando descargará por defecto objetos Git LFS para archivos solo si están presentes en el índice de Git y si coinciden con un atributo de filtro de Git LFS de un archivo .gitattributes local como $GIT_DIR/info/attributes. Cualquier archivo .gitattributes en HEAD será ignorado, a menos que la variable de entorno GIT_ATTR_SOURCE se establezca en HEAD, y cualquier archivo .gitattributes en el índice o árbol de trabajo actual siempre será ignorado. Estas restricciones no se aplican con versiones anteriores de Git.

OPCIONES

-I <rutas>, --include=<rutas>

Especifica lfs.fetchinclude solo para esta invocación; ver INCLUIR Y EXCLUIR

-X <rutas>, --exclude=<rutas>

Especifica lfs.fetchexclude solo para esta invocación; ver INCLUIR Y EXCLUIR

INCLUIR Y EXCLUIR

Puedes configurar Git LFS para descargar objetos solo para satisfacer referencias en ciertas rutas del repositorio, y/o para excluir ciertas rutas del repositorio, para reducir el tiempo que pasas descargando cosas que no usas.

En tu configuración de Git o en un archivo .lfsconfig, puedes establecer uno o ambos de lfs.fetchinclude y lfs.fetchexclude a listas de rutas separadas por comas. Si lfs.fetchinclude está definido, los objetos Git LFS solo se descargarán si su ruta coincide con una de la lista, y si lfs.fetchexclude está definido, los objetos Git LFS solo se descargarán si su ruta no coincide con una de la lista. Las rutas se comparan usando coincidencia de comodines según gitignore(5).

Ten en cuenta que el uso de las opciones de línea de comandos -I y -X anulan la configuración respectiva. Establecer cualquiera de las opciones a una cadena vacía borra el valor.

REMOTO POR OMISIÓN

Sin argumentos, pull descarga desde el remoto por omisión. El remoto por omisión es el mismo que para git pull, es decir, basado en la rama remota que estás rastreando primero, o origin en caso contrario.

VER TAMBIÉN

git-lfs-fetch(1), git-lfs-checkout(1), gitattributes(5), gitignore(5).

Parte de la suite git-lfs(1).
