NOMBRE

git-web--browse - Script auxiliar de Git para lanzar un navegador web

SINOPSIS

git web--browse [<opciones>] (<URL>|<archivo>)...

DESCRIPCIÓN

Este script intenta, tanto como sea posible, mostrar las URLs y ARCHIVOS pasados como argumentos, como páginas HTML en nuevas pestañas de un navegador web ya abierto.

Los siguientes navegadores (o comandos) son soportados actualmente:

•firefox (este es el predeterminado en X Window cuando no se usa KDE)
•iceweasel
•seamonkey
•iceape
•chromium (también soportado como chromium-browser)
•google-chrome (también soportado como chrome)
•konqueror (este es el predeterminado en KDE, ver Nota sobre konqueror abajo)
•opera
•w3m (este es el predeterminado fuera de entornos gráficos)
•elinks
•links
•lynx
•dillo
•open (este es el predeterminado en la GUI de Mac OS X)
•start (este es el predeterminado en MinGW)
•cygstart (este es el predeterminado en Cygwin)
•xdg-open

También se pueden especificar comandos personalizados.

OPCIONES

-b <navegador>, --browser=<navegador>

Usa el navegador especificado. Debe estar en la lista de navegadores soportados.

-t <navegador>, --tool=<navegador>

Igual que el anterior.

-c <var.conf>, --config=<var.conf>

Se busca VAR.CONF en los archivos de configuración de Git. Si está establecida, su valor especifica el navegador que debe ser usado.

VARIABLES DE CONFIGURACIÓN

VAR.CONF (desde opción -c) y web.browser

El navegador web puede ser especificado usando una variable de configuración pasada con la opción de línea de comandos -c (o --config), o la variable de configuración web.browser si la primera no se usa.

browser.<herramienta>.path

Puedes proporcionar explícitamente una ruta completa a tu navegador preferido estableciendo la variable de configuración browser.<herramienta>.path. Por ejemplo, puedes configurar la ruta absoluta a firefox estableciendo browser.firefox.path. De lo contrario, git web--browse asume que la herramienta está disponible en PATH.

browser.<herramienta>.cmd

Cuando el navegador, especificado por opciones o variables de configuración, no está entre los soportados, entonces se buscará la variable de configuración correspondiente browser.<herramienta>.cmd. Si esta variable existe, entonces git web--browse tratará la herramienta especificada como un comando personalizado y usará un eval de shell para ejecutar el comando con las URLs pasadas como argumentos.

NOTA SOBRE KONQUEROR

Cuando se especifica konqueror por una opción de línea de comandos o una variable de configuración, lanzamos kfmclient para intentar abrir la página del manual HTML en un konqueror ya abierto en una nueva pestaña si es posible.

Por consistencia, también intentamos ese truco si browser.konqueror.path está configurado como algo como UNA_RUTA/konqueror. Eso significa que intentaremos lanzar UNA_RUTA/kfmclient en su lugar.

Si realmente quieres usar konqueror, puedes usar algo como lo siguiente:

        [web]
                browser = konq
        [browser "konq"]
                cmd = UNA_RUTA/konqueror

Nota sobre git-config --global

Nota que estas variables de configuración probablemente deberían ser establecidas usando la bandera --global, por ejemplo, así:

$ git config --global web.browser firefox

ya que son probablemente más específicas del usuario que del repositorio. Ver git-config(1) para más información sobre esto.
