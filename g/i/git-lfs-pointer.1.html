NOMBRE

git-lfs-pointer - Construir, comparar y verificar punteros

SINOPSIS

git lfs pointer --file=ruta/al/archivo
git lfs pointer --file=ruta/al/archivo --pointer=ruta/al/puntero
git lfs pointer --file=ruta/al/archivo --stdin
git lfs pointer --check --file=ruta/al/archivo

DESCRIPCIÓN

Construye y opcionalmente compara archivos puntero generados para asegurar la consistencia entre diferentes implementaciones de Git LFS.

OPCIONES

--file

Un archivo local desde el cual construir el puntero.

--pointer

Un archivo local que incluye el contenido de un puntero generado desde otra implementación. Esto se compara con el puntero generado desde --file.

--stdin

Lee el puntero desde STDIN para compararlo con el puntero generado desde --file.

--check

Lee el puntero desde STDIN (si se proporciona --stdin) o desde la ruta del archivo (si se proporciona --file). Si no se proporcionan ni --stdin ni --file, o si se proporcionan ambos, la invocación es inválida. Sale con 0 si los datos leídos son un puntero Git LFS válido. Sale con 1 en caso contrario.

--strict, --no-strict

En conjunción con --check, --strict verifica que el puntero sea canónico; es decir, que sería el que crearía Git LFS. Si no lo es, sale con 2. El valor predeterminado, por compatibilidad retroactiva, es --no-strict, pero esto puede cambiar en una versión futura.

VER TAMBIÉN

Parte del conjunto de herramientas de git-lfs(1).
