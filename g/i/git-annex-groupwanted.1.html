NOMBRE

git-annex-groupwanted - obtener o establecer la expresión groupwanted

SINOPSIS

git annex groupwanted nombregrupo [expresión]

DESCRIPCIÓN

Establece o muestra la expresión groupwanted. Esta será utilizada por los repositorios que estén en el grupo y que tengan su expresión de contenido preferido configurada como "groupwanted".

Por ejemplo, para configurar un grupo llamado redundantarchive y hacer que los repositorios del grupo deseen contener 3 copias de cada archivo:


git annex groupwanted redundantarchive "not (copies=redundantarchive:3)"
para repo en foo bar baz; hacer
git annex group $repo redundantarchive
git annex wanted $repo groupwanted
hecho

Tenga en cuenta que debe haber exactamente una expresión groupwanted configurada entre todos los grupos en los que se encuentra un repositorio; si hay más de una, ninguna de ellas se usará.

OPCIONES

Las opciones comunes de git-annex(1) pueden ser utilizadas.
