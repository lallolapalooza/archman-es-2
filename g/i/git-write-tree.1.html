NOMBRE

git-write-tree - Crea un objeto de árbol a partir del índice actual

SINOPSIS

git write-tree [--missing-ok] [--prefix=<prefijo>/]

DESCRIPCIÓN

Crea un objeto de árbol utilizando el índice actual. El nombre del nuevo objeto de árbol se imprime en la salida estándar.

El índice debe estar en un estado completamente fusionado.

Conceptualmente, git write-tree sincroniza los contenidos del índice actual en un conjunto de archivos de árbol. Para que coincida con lo que está realmente en tu directorio en este momento, necesitas haber realizado una fase de git update-index antes de hacer el git write-tree.

OPCIONES

--missing-ok

Normalmente git write-tree se asegura de que los objetos referenciados por el directorio existan en la base de datos de objetos. Esta opción deshabilita esta comprobación.

--prefix=<prefijo>/

Escribe un objeto de árbol que representa un subdirectorio <prefijo>. Esto se puede utilizar para escribir el objeto de árbol de un subproyecto que se encuentra en el subdirectorio especificado.
