NOMBRE

git-annex-resolvemerge - resolver conflictos de fusión

SINOPSIS

git annex resolvemerge

DESCRIPCIÓN

Resuelve automáticamente un conflicto de fusión. Esto se hace automáticamente al usar git annex sync o git annex merge.

Cuando dos árboles que se fusionan contienen versiones conflictivas de un archivo anexo, el conflicto de fusión se resolverá agregando ambas versiones al árbol, utilizando variantes del nombre del archivo.

Cuando un árbol modificó el archivo y el otro árbol eliminó el archivo, el conflicto de fusión se resolverá agregando el archivo modificado usando una variante del nombre del archivo, dejando el nombre del archivo original eliminado.

Cuando el conflicto de fusión involucra un archivo que está anexo en un árbol, pero no está anexo en el otro árbol, se resuelve manteniendo el archivo no anexo tal cual, y agregando la versión anexa usando una variante del nombre del archivo.

Tenga en cuenta que solo se resuelven los conflictos de fusión que involucran uno o más archivos anexos. Los conflictos de fusión entre dos archivos que no están anexos no se resolverán automáticamente.

EJEMPLOS

Supongamos que Alice confirma un cambio en el archivo anexo foo, y Bob confirma un cambio diferente en el mismo archivo foo.

La fusión entre ellos fallará y git presentará el conflicto de fusión como un archivo foo apuntando a una versión del enlace simbólico de git-annex, con git status indicando que foo tiene un conflicto no resuelto.

Ejecutar git annex resolvemerge en esta situación resolverá el conflicto de fusión, reemplazando el archivo foo con archivos con nombres como foo.variant-c696 y foo.variant-f16a. Uno de los archivos contendrá el contenido que Alice confirmó, y el otro contendrá el contenido que Bob confirmó.

El usuario podrá entonces examinar las dos variantes del archivo, y ya sea fusionar los dos cambios en un solo archivo, o renombrar uno de ellos de nuevo a foo y eliminar el otro.

Ahora supongamos que Alice confirma un cambio en el archivo anexo bar, mientras que Bob confirma una eliminación del mismo archivo bar. La fusión fallará. Ejecutar git annex resolvemerge en esta situación resolverá el conflicto de fusión creando un archivo con un nombre como bar.variant-421f que contiene la versión de Alice. El archivo bar permanecerá eliminado. El usuario podrá más tarde examinar la variante del archivo y decidir renombrarla de nuevo a bar, o decidir eliminarla también.

OPCIONES

Las git-annex-common-options(1) se pueden usar.
