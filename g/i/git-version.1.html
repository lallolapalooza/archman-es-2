NOMBRE

git-version - Muestra información de la versión de Git

SINOPSIS

git version [--build-options]

DESCRIPCIÓN

Sin opciones, se imprime la versión de git en la salida estándar.

Tenga en cuenta que git --version es idéntico a git version ya que el primero se convierte internamente en el segundo.

OPCIONES

--build-options

Incluir información adicional sobre cómo se construyó git con fines de diagnóstico.

Las bibliotecas utilizadas para implementar los algoritmos SHA-1 y SHA-256 se muestran en el formato SHA-1: <opción> y SHA-256: <opción>. Tenga en cuenta que las opciones SHA-1 SHA1_APPLE, SHA1_OPENSSL y SHA1_BLK no utilizan un algoritmo de detección de colisiones y, por lo tanto, pueden ser vulnerables a ataques de colisión SHA-1 conocidos. Cuando se utiliza una implementación SHA-1 más rápida sin detección de colisiones solo para fines no criptográficos, el algoritmo se muestra en el formato non-collision-detecting-SHA-1: <opción>.
