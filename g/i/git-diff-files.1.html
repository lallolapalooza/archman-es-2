•--max-depth=1 -- foo: foo/bar
•--max-depth=1 -- foo/bar: foo/bar/baz

FORMATO DE SALIDA RAW

El formato de salida raw de git-diff-index, git-diff-tree, git-diff-files y git diff --raw son muy similares.

Estos comandos comparan dos conjuntos de elementos; lo que se compara difiere:

git-diff-index <tree-ish>

compara el <tree-ish> y los archivos en el sistema de archivos.

git-diff-index --cached <tree-ish>

compara el <tree-ish> y el índice.

git-diff-tree [-r] <tree-ish-1> <tree-ish-2> [<patrón>...]

compara los árboles nombrados por los dos argumentos.

git-diff-files [<patrón>...]

compara el índice y los archivos en el sistema de archivos.

El comando git-diff-tree comienza su salida imprimiendo el hash de lo que se está comparando. Después de eso, todos los comandos imprimen una línea de salida por archivo modificado.

Una línea de salida se formatea de esta manera:

in-place edit  :100644 100644 bcd1234 0123456 M file0
copy-edit      :100644 100644 abcd123 1234567 C68 file1 file2
rename-edit    :100644 100644 abcd123 1234567 R86 file1 file3
create         :000000 100644 0000000 1234567 A file4
delete         :100644 000000 1234567 0000000 D file5
unmerged       :000000 000000 0000000 0000000 U file6

Es decir, de izquierda a derecha:

1.dos puntos.
2.modo para "src"; 000000 si es creación o no fusionado.
3.un espacio.
4.modo para "dst"; 000000 si es eliminación o no fusionado.
5.un espacio.
6.sha1 para "src"; 0{40} si es creación o no fusionado.
7.un espacio.
8.sha1 para "dst"; 0{40} si es eliminación, no fusionado o "el árbol de trabajo está desincronizado con el índice".
9.un espacio.
10.estado, seguido de un número opcional de "puntuación".
11.una tabulación o un NUL cuando se usa la opción -z.
12.ruta para "src"
13.una tabulación o un NUL cuando se usa la opción -z; solo existe para C o R.
14.ruta para "dst"; solo existe para C o R.
15.un LF o un NUL cuando se usa la opción -z, para terminar el registro.

Las letras de estado posibles son:

•A: adición de un archivo
•C: copia de un archivo a uno nuevo
•D: eliminación de un archivo
•M: modificación del contenido o modo de un archivo
•R: renombre de un archivo
•T: cambio en el tipo de archivo (archivo regular, enlace simbólico o submódulo)
•U: el archivo no está fusionado (debes completar la fusión antes de poder confirmarlo)
•X: tipo de cambio "desconocido" (muy probablemente un error, por favor repórtalo)

Las letras de estado C y R siempre van seguidas de una puntuación (que denota el porcentaje de similitud entre el origen y el destino del movimiento o la copia). La letra de estado M puede ir seguida de una puntuación (que denota el porcentaje de disimilitud) para las reescrituras de archivos.

El sha1 para "dst" se muestra como todos ceros si un archivo en el sistema de archivos está desincronizado con el índice.

Ejemplo:

:100644 100644 5be4a4a 0000000 M file.c

Sin la opción -z, las rutas con caracteres "inusuales" se citan como se explica para la variable de configuración core.quotePath (consulte git-config(1)). Usando -z, el nombre del archivo se muestra literalmente y la línea se termina con un byte NUL.
