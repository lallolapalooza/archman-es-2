CONFIGURACIÓN

git-lfs lee su configuración de cualquier archivo admitido por git config -l, incluyendo todos los archivos de configuración de Git por repositorio, por usuario y por sistema. git config -l, incluyendo todos los archivos de configuración de Git por repositorio, por usuario y por

sistema.

Adicionalmente, un pequeño número de ajustes puede especificarse en un archivo llamado .lfsconfig en la raíz del repositorio; consulta la sección "LFSCONFIG" para más detalles. Este archivo de configuración es útil para establecer opciones como la URL de LFS o el tipo de acceso para todos los usuarios de un repositorio, especialmente cuando estas difieren de las predeterminadas. El archivo .lfsconfig usa el mismo formato que .gitcon

fig.

Si el archivo .lfsconfig falta, se comprueba el índice en busca de una versión del archivo, y esa se usa en su lugar. Si ambos faltan, se comprueba HEAD en busca del archivo. Si el repositorio es desnudo (bare), solo se comprueba HEAD. Este orden puede cambiar en el futuro para las comprobaciones (checkouts) para coincidir mejor con el comportamiento de

Git.

La configuración de los archivos de configuración de Git anula el archivo .lfsconfig. Esto te permite anular ajustes como lfs.url en tu entorno local sin tener que modificar el archivo .lfsc

onfig.

La mayoría de las opciones relacionadas con git-lfs están contenidas en la sección [lfs], lo que significa que todas se nombran lfs.foo o similar, aunque ocasionalmente una opción lfs pu
