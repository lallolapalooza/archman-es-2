Le hook pre-push de Git LFS varie son comportement en fonction de la valeur de cette clé de configuration. null - En l'absence d'une valeur, Git LFS tentera l'appel, et avertira s'il renvoie une erreur. Si le serveur renvoie une réponse 501 Not Implemented , Git LFS définira la valeur à false. true - Git LFS tentera de v érifier les verrous, interrompant le push Git s'il y a des problèmes côté serveur, ou si l'utilisateur tente de mettre à jour un fichier verrouillé par un autre utilisateur. ** false - Git LFS ignorera faux complètement la vérification des verrous dans le hook pre-push. Vous devriez définir cette valeur si vous n'utilisez pas le File Locking, ou si votre serveur Git vérifie automatiquement les fichiers verrouillés lors des pushes.
