NOMBRE

git-annex-smudge - controlador de filtro git para git-annex

SINOPSIS

git annex smudge [--clean] archivo

git annex smudge --update

DESCRIPCIÓN

Este comando permite usar git-annex como un controlador de filtro de git que permite que los archivos anexados en el repositorio git se desbloqueen, en lugar de ser enlaces simbólicos, y permite que git add almacene archivos en el anexo.

Al añadir un archivo con git add, se consulta la configuración annex.largefiles para decidir si un archivo dado debe añadirse a git tal cual, o si su contenido es lo suficientemente grande como para necesitar usar git-annex. La configuración annex.gitaddtoannex tiene prioridad; establecerla en falso evita que git add añada archivos al anexo.

Sin embargo, si git-annex puede determinar que un archivo fue anexado antes, aún se añadirá al anexo incluso cuando esas configuraciones normalmente lo evitarían. Dos ejemplos de esto son añadir una versión modificada de un archivo anexado, y mover un archivo anexado a un nuevo nombre de archivo y añadirlo.

La configuración de git para usar este comando como controlador de filtro es la siguiente. Normalmente, git-annex init la configura por usted, por lo que no debería necesitar configurarla manualmente.


[filter "annex"]
smudge = git-annex smudge %f
clean = git-annex smudge --clean %f

Para que git use ese controlador de filtro, debe configurarse en el archivo .gitattributes o en .git/info/attributes. Este último normalmente se configura cuando se inicializa un repositorio, con el siguiente contenido:


* filter=annex

El filtro smudge no proporciona a git el contenido de los archivos anexados, porque eso sería lento y provocaría fugas de memoria en git. En su lugar, registra qué archivos del espacio de trabajo necesitan ser actualizados, y git annex smudge --update actualiza posteriormente el espacio de trabajo para contener el contenido. Esto es ejecutado por varios hooks de git, incluyendo post-checkout y post-merge. Sin embargo, algunos comandos de git, notablemente git stash y git cherry-pick, no ejecutan ningún hook, por lo que después de usar esos comandos puede ejecutar manualmente git annex smudge --update para actualizar el árbol de trabajo.

OPCIONES

Se pueden usar las opciones-comunes-de-git-annex(1).
