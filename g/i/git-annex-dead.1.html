NOMBRE

git-annex-dead - ocultar un repositorio o clave perdida

SINOPSIS

git annex dead [repositorio ...] [--clave algunaclave ...]

DESCRIPCIÓN

Este comando existe para lidiar con situaciones en las que se ha perdido información y sabes que así ha sido, y quieres dejar de que te recuerden ese hecho.

Cuando se especifica un repositorio, indica que el repositorio se ha perdido de forma irreparable, por lo que no aparecerá en, por ejemplo, git annex whereis. Los repositorios se pueden especificar usando su nombre remoto, su descripción o su UUID. (Para deshacer, usa git annex semitrust.)

Cuando se especifica una clave, indica que el contenido de esa clave se ha perdido de forma irreparable. Esto hace que la clave se omita al operar sobre todas las claves con, por ejemplo, --all. (Para deshacer, añade el contenido de la clave de vuelta al repositorio, usando, por ejemplo, git annex reinject.)

OPCIONES

--clave=algunaclave
Se usa para especificar una clave que está muerta.
--json
Habilita la salida JSON. Está pensada para ser analizada por programas que usan git-annex. Cada línea de salida es un objeto JSON.
--json-error-messages
Los mensajes que normalmente se enviarían a la salida de error estándar se incluyen en el JSON en su lugar.
También se pueden usar las git-annex-common-options(1).
