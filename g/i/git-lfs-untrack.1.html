NOMBRE

git-lfs-untrack - Eliminar rutas de Git LFS de Atributos de Git

SINOPSIS

git lfs untrack <ruta>...

DESCRIPCIÓN

Deja de rastrear la(s) ruta(s) dada(s) a través de Git LFS. El argumento puede ser un patrón glob o una ruta de archivo.

EJEMPLOS

•Configurar Git LFS para dejar de rastrear archivos GIF:

git lfs untrack "*.gif"

VER TAMBIÉN

git-lfs-track(1), git-lfs-install(1), gitattributes(5).

Parte de la suite git-lfs(1).
