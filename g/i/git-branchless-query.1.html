NOMBRE

query - Consulta el grafo de commits utilizando el lenguaje "revset" e imprime los commits coincidentes

SINOPSIS

query [--hidden] [-b|--branches] [-r|--raw] [-h|--help] <REVSET>

DESCRIPCIÓN

Consulta el grafo de commits utilizando el lenguaje "revset" e imprime los commits coincidentes.

Consulta https://github.com/arxanas/git-branchless/wiki/Reference:-Revsets para obtener más información sobre revsets.

Se garantiza que los commits impresos estarán ordenados topológicamente, con los commits ancestros apareciendo primero.

OPCIONES

--hidden
Incluye commits ocultos en los resultados de la evaluación de expresiones revset
-b, --branches
Imprime las ramas adjuntas a los commits resultantes, en lugar de los commits en sí
-r, --raw
Imprime el OID de cada commit coincidente, uno por línea. Esta salida es estable para su uso en scripts.
-h, --help
Imprime la ayuda (ver un resumen con '-h')
<REVSET>
La consulta a ejecutar
query
