NOMBRE

git-lfs-lock - Establece un archivo como "bloqueado" en el servidor Git LFS

SINOPSIS

git lfs lock [opciones] <ruta>

DESCRIPCIÓN

Establece la ruta de archivo dada como "bloqueada" contra el servidor Git LFS, con la intención de impedir intentos por parte de otros usuarios de actualizar la ruta dada. Bloquear un archivo requiere que el archivo exista en la copia de trabajo.

Una vez bloqueado, LFS verificará que las subidas de Git no modifiquen archivos bloqueados por otros usuarios. Consulte la descripción de la clave de configuración lfs.<url>.locksverify en git-lfs-config(5) para más detalles.

OPCIONES

-r <nombre>, --remote=<nombre>

Especifica el servidor Git LFS a usar. Se ignora si la clave de configuración lfs.url está establecida.

-j, --json

Escribe la información del bloqueo como JSON en STDOUT si el comando finaliza con éxito. Previsto para interoperación con herramientas externas. Si el comando devuelve un código de salida distinto de cero, se enviarán mensajes de texto plano a STDERR.

VEASE TAMBIÉN

git-lfs-unlock(1), git-lfs-locks(1).

Parte de la suite git-lfs(1).
