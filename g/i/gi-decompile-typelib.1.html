Nombre

gi-decompile-typelib - Descompilador de Typelib

SINOPSIS

gi-decompile-typelib [OPCIÓN…] TYPELIB [TYPELIB…]

DESCRIPCIÓN

gi-decompile-typelib es un descompilador de GIR, que utiliza la API del repositorio. Genera archivos XML de GIR a partir del formato binario compilado de typelib. La salida se escribirá en la salida estándar a menos que se especifique --output.

El formato binario de typelib almacena un subconjunto de la información disponible en el XML de GIR, por lo que no todos los typelibs se pueden descompilar de esta manera, y el XML de GIR resultante podría estar incompleto.

Normalmente, el XML de GIR debe generarse a partir del código fuente, encabezados y bibliotecas compartidas utilizando g-ir-scanner(1) <man:g-ir-scanner(1)> en lugar de usar esta herramienta.

OPCIONES

--help
Mostrar opciones de ayuda.
--output NOMBRE_ARCHIVO, -o NOMBRE_ARCHIVO
Guardar la salida resultante en NOMBRE_ARCHIVO.
--includedir DIRECTORIO
Añadir DIRECTORIO a la ruta de búsqueda de typelibs. Esta opción se puede usar varias veces. El primer DIRECTORIO en la línea de comandos se buscará primero (mayor precedencia).
--all
Mostrar toda la información disponible.
--version
Mostrar el número de versión del programa y salir.

EJEMPLO

::
$ libdir=/usr/lib/x86_64-linux-gnu # o /usr/lib64 o similar $ gi-decompile-typelib -o Gio-2.0.gir
Mensaje del Sistema: ERROR/3 (../glib/docs/reference/girepository/gi-decompile-typelib.rst:, línea 84)
Indentación inesperada.
$libdir/girepository-1.0/Gio-2.0.typelib

$ diff -u /usr/share/gir-1.0/Gio-2.0.gir Gio-2.0.gir

Verás que el XML GIR original contiene mucha más información que el typelib descompilado.
