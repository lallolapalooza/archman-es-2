NOMBRE

git-annex-unlock - desbloquear archivos para su modificación

SINOPSIS

git annex unlock [ruta ...]

DESCRIPCIÓN

Normalmente, el contenido de los archivos anexados está protegido contra cambios. Desbloquear un archivo anexado permite modificarlo. Cuando no se especifican archivos, se desbloquean todos los archivos anexados en el directorio actual.

Desbloquear un archivo cambia cómo se almacena en el repositorio de git (de un enlace simbólico a un archivo puntero), por lo que este comando realizará un cambio que puede confirmar.

El contenido de un archivo desbloqueado todavía se almacena en git-annex, no en git, y cuando confirme modificaciones en el archivo, las modificaciones también se almacenarán en git-annex, con solo el archivo puntero almacenado en git.

Si usa git add para agregar un archivo al anexo, se agregará desbloqueado desde el principio. Esto permite flujos de trabajo donde un archivo comienza desbloqueado, se modifica según sea necesario y se bloquea una vez que alcanza su versión final.

Normalmente, desbloquear un archivo requiere hacer una copia de su contenido, para que se preserve su contenido original, mientras que la copia puede modificarse. Para usar menos espacio, annex.thin se puede establecer en true; esto hará un enlace duro al contenido en lugar de una copia. (Solo cuando es compatible con el sistema de archivos). Si bien esto puede ahorrar un considerable espacio en disco, cualquier modificación realizada en un archivo hará que la versión anterior del archivo se pierda del repositorio local. Por lo tanto, habilite annex.thin con cuidado.

EJEMPLOS


# git annex unlock imagen-disco
# git commit -m "desbloqueado para permitir que la VM realice cambios mientras se ejecuta"


# git annex unlock foto.jpg
# gimp foto.jpg
# git commit foto.jpg -m "eliminación de ojos rojos"
# gimp foto.jpg
# git commit foto.jpg -m "fijar sobresaturación" # git annex lock foto.jpg

OPCIONES

opciones de coincidencia de archivos
Las opciones de coincidencia de git-annex(1) se pueden usar para especificar archivos a desbloquear.
--json
Habilita la salida JSON. Está destinado a ser analizado por programas que usan git-annex. Cada línea de salida es un objeto JSON.
--json-error-messages
Los mensajes que normalmente se mostrarían en la salida estándar de error se incluyen en el JSON en su lugar.
Ademas se pueden usar las opciones comunes de git-annex(1).
