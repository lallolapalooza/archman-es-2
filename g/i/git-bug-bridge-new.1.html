NOMBRE

git-bug-bridge-new - Configura un nuevo puente

SINOPSIS

git-bug bridge new [opciones]

DESCRIPCIÓN

Configura un nuevo puente pasando opciones o usando indicaciones interactivas en la terminal. Puedes evitar todas las indicaciones de la terminal pasando todas las opciones necesarias para configurar tu puente.

OPCIONES

-n, --name="" Un nombre distintivo para identificar el puente

-t, --target="" El objetivo del puente. Los valores válidos son [github,gitlab,jira,launchpad-preview]

-u, --url="" La URL del repositorio remoto

-b, --base-url="" La URL base de tu rastreador de incidencias remoto

-l, --login="" El inicio de sesión en tu rastreador de incidencias remoto

-c, --credential="" El identificador o prefijo de una credencial ya conocida para tu rastreador de incidencias remoto (ver "git-bug bridge auth")

--token="" Un token de autenticación crudo para el rastreador de incidencias remoto

--token-stdin[=false] Leerá el token desde stdin e ignorará --token

-o, --owner="" El propietario del repositorio remoto

-p, --project="" El nombre del repositorio remoto

--non-interactive[=false] No pedir entrada al usuario

-h, --help[=false] Ayuda para new

# Para GitHub
git bug bridge new \
    --name=default \
    --target=github \
    --owner=ejemplo-propietario
    --project=ejemplo-repositorio \
    --token=$TOKEN
# Para Launchpad
git bug bridge new \
    --name=default \
    --target=launchpad-preview \
    --url=https://bugs.launchpad.net/ubuntu/
# Para Gitlab
git bug bridge new \
    --name=default \
    --target=gitlab \
    --url=https://github.com/ejemplo-org/ejemplo-repositorio \
    --token=$TOKEN
