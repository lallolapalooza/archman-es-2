NOMBRE

git-lfs-status - Mostrar el estado de los archivos de Git LFS en el árbol de trabajo

SINOPSIS

git lfs status [<opciones>]

DESCRIPCIÓN

Muestra las rutas de los objetos de Git LFS que

•no han sido subidos al servidor de Git LFS. Estos son archivos grandes que serían subidos por git push.
•tienen diferencias entre el archivo de índice y el commit HEAD actual. Estos son archivos grandes que serían confirmados por git commit.
•tienen diferencias entre el árbol de trabajo y el archivo de índice. Estos son archivos que podrían ser preparados usando git add.

Este comando debe ejecutarse en un repositorio no vacío (non-bare).

OPCIONES

-p, --porcelain

Da la salida en un formato fácil de analizar para scripts.

-j, --json

Da la salida en un formato JSON estable para scripts.

VER TAMBIÉN

git-lfs-ls-files(1).

Parte de la suite git-lfs(1).
