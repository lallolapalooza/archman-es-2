NOMBRE

git-unpack-objects - Desempaqueta objetos de un archivo empaquetado

SINOPSIS

git unpack-objects [-n] [-q] [-r] [--strict]

DESCRIPCIÓN

Lee un archivo empaquetado (.pack) de la entrada estándar, expandiendo los objetos contenidos en él y escribiéndolos en el repositorio en formato "suelto" (un objeto por archivo).

Los objetos que ya existen en el repositorio no serán desempaquetados del packfile. Por lo tanto, nada será desempaquetado si usas este comando en un packfile que existe dentro del repositorio destino.

Consulta git-repack(1) para ver opciones para generar nuevos packs y reemplazar los existentes.

OPCIONES

-n

Simulación. Comprueba el archivo pack sin desempaquetar realmente los objetos.

-q

El comando normalmente muestra el progreso en porcentaje. Esta bandera lo suprime.

-r

Al desempaquetar un packfile corrupto, el comando muere ante la primera corrupción. Esta bandera le indica que continúe y haga todo lo posible para recuperar tantos objetos como sea posible.

--strict

No escribas objetos con contenido o enlaces rotos.

--max-input-size=<tamaño>

Muere si el pack es mayor que <tamaño>.
