NOMBRE

git-branchless - Flujo de trabajo sin ramas para Git

SINOPSIS

git-branchless [-C ] [--color] [-h|--help] [-V|--version] <subcomandos>

DESCRIPCIÓN

Flujo de trabajo sin ramas para Git.

Ver la documentación en https://github.com/arxanas/git-branchless/wiki.

OPCIONES

-C=DIRECTORIO_TRABAJO
Cambiar al directorio dado antes de ejecutar el resto del programa. (La opción se llama `-C` por simetría con Git.)
--color=COLOR
Bandera para forzar la activación o desactivación de los colores de la terminal

Posibles valores:

  • auto: Determina automáticamente si se deben mostrar colores desde la terminal y las variables de entorno. Este es el comportamiento por defecto
  • always: Muestra siempre los colores de la terminal
  • never: Nunca muestra los colores de la terminal
-h, --help
Imprime la ayuda (ver un resumen con '-h')
-V, --version
Imprime la versión

SUBCOMANDOS

git-branchless-amend(1)
Modifica el commit HEAD actual
git-branchless-bug-report(1)
Recopila información sobre operaciones recientes para subirla como parte de un informe de error
git-branchless-difftool(1)
Usa la interfaz de selección de commits parciales como difftool compatible con Git; ver git-difftool(1) para más información sobre los difftools de Git
git-branchless-gc(1)
Ejecuta la recolección de basura interna
git-branchless-hide(1)
Oculta los commits proporcionados del smartlog
git-branchless-init(1)
Inicializa el flujo de trabajo sin ramas para este repositorio
git-branchless-install-man-pages(1)
Instala las páginas del manual de git-branchless en la ruta dada
git-branchless-move(1)
Mueve un subárbol de commits de una ubicación a otra
git-branchless-next(1)
Mueve a un commit posterior en la pila actual
git-branchless-prev(1)
Mueve a un commit anterior en la pila actual
git-branchless-query(1)
Consulta el grafo de commits usando el lenguaje "revset" e imprime los commits coincidentes
git-branchless-repair(1)
Restaura los invariantes internos reconciliando el registro de operaciones internas con el estado del repositorio Git
git-branchless-restack(1)
Corrige commits abandonados por una operación de reescritura anterior
git-branchless-record(1)
Crea un commit seleccionando interactivamente qué cambios incluir
git-branchless-reword(1)
Reescribe commits
git-branchless-smartlog(1)
Comando `smartlog`
git-branchless-submit(1)
Envía commits a un remoto
git-branchless-switch(1)
Cambia a la rama o commit proporcionado

Muestra commits previamente ocultos del smartlog
