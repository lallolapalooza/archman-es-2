NOMBRE

git-annex-filter-branch - filtra información de la rama git-annex

SINOPSIS

git annex filter-branch [...]

DESCRIPCIÓN

Esto copia información seleccionada de la rama git-annex a un objeto de commit de git, y muestra su hash. El commit de git puede transportarse a otro repositorio git, y dársele un nombre de rama como "foo/git-annex", y git-annex allí fusionará automáticamente eso en su rama git-annex. Esto permite publicar alguna información de tu rama git-annex, sin publicar todo.

Otras formas de evitar publicar información de una rama git-annex, o eliminar información de ella, incluyen git-annex-forget(1), la annex.private configuración de git, y la --private opción de git-annex-initremote(1). Esas son mucho más fáciles de usar, pero esto proporciona control total para quienes lo necesiten.

Sin opciones, no se incluirá ninguna información de la rama git-annex. Usa opciones para especificar qué incluir. Todas las opciones pueden especificarse varias veces.

Cuando el repositorio contiene información sobre un repositorio privado (debido a annex.private estar establecido, o a que se haya usado git-annex initremote --private), esa información privada se incluirá cuando lo permitan las opciones, aunque no esté registrada en la rama git-annex.

Cuando un repositorio fue creado con git annex initremote --sameas=foo, su información se incluirá cuando se incluya la información de foo, y se excluirá cuando foo se excluya.

Cuando un remoto especial está configurado con importtree=yes o exporttree=yes, normalmente el árbol git correspondiente al repositorio se incluye en la rama git-annex, para asegurarse de que no sea recolectado como basura por git gc. Esos árboles *no* se incluyen al filtrar la rama git-annex. Normalmente esto no causará problemas, pero si un árbol así es recolectado como basura, impedirá el acceso a los archivos en el remoto especial, hasta la próxima vez que se importe o exportee un árbol a él.

OPCIONES

ruta
Incluye información sobre todas las claves de los archivos anexados en la ruta.
opciones de coincidencia de archivos
Se pueden usar las git-annex-matching-options(1) para especificar qué archivos en una ruta incluir.
--branch=ref
Incluye información sobre las claves referenciadas de los archivos anexados en la rama o árbol.
--key=clave
Incluye información sobre una clave específica.
--all
Incluye información sobre todas las claves.
--include-key-information-for=repo
Al incluir información sobre una clave, incluye información específica de este repositorio. El repositorio puede especificarse con un uuid o el nombre de un remoto. Esta opción puede usarse repetidamente para incluir varios repositorios.
--include-all-key-information
Incluye información de claves para todos los repositorios, excepto los excluidos con la --exclude-key-information-for opción.
--exclude-key-information-for=repo
Al incluir información sobre una clave, excluye información específica de este repositorio. El repositorio puede especificarse con un uuid o el nombre de un remoto. Esta opción puede usarse repetidamente para excluir varios repositorios.
--include-repo-config-for=repo
Incluye la configuración específica de este repositorio. El repositorio puede especificarse con un uuid o el nombre de un remoto.
Esto incluye la configuración de los remotos especiales, que puede incluir credenciales incrustadas o parámetros de cifrado. También incluye ajustes de confianza, contenido preferido, etc. No incluye información sobre ninguna clave de git-annex. Esta opción puede usarse repetidamente para incluir varios repositorios.
--include-all-repo-config
Incluye la configuración de todos los repositorios, excepto los excluidos con la --exclude-repo-config-for opción.
--exclude-repo-config-for=repo
Excluye la configuración específica de este repositorio. El repositorio puede especificarse con un uuid o el nombre de un remoto. Esta opción puede usarse repetidamente para excluir varios repositorios.
--include-global-config
Incluye la configuración global, que no es específica de ningún repositorio.
Esto incluye configuraciones almacenadas por git-annex-numcopies(1), git-annex-config(1), etc.

EJEMPLOS

Tienes un repositorio git-annex grande y estás separando el directorio "foo" para hacer un repositorio más pequeño. Quieres que la rama git-annex del repositorio más pequeño contenga toda la información sobre remotos y otra configuración, pero solo información sobre las claves en ese directorio.


git-annex filter-branch foo --include-all-key-information \
--include-all-repo-config --include-global-config

Eso solo incluye información sobre las claves que están actualmente en el directorio "foo", no claves usadas por versiones antiguas de los archivos. Para incluir también información sobre la versión del subdirectorio en la etiqueta "1.0", añade la opción --branch=1.0:foo

Tu repositorio tiene un remoto especial "bar", y quieres compartir información sobre qué archivos anexados están almacenados en él, pero sin compartir nada sobre la configuración del remoto.


git-annex filter-branch --all --include-all-key-information \
--include-all-repo-config --exclude-repo-config-for=bar \
--include-global-config
