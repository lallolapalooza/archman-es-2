NOMBRE

git-annex-extendcluster - añadir una puerta de enlace adicional a un cluster

SINOPSIS

git-annex extendcluster gateway clustername

DESCRIPCIÓN

Este comando se utiliza para configurar un repositorio como una puerta de enlace adicional a un cluster. Se ejecuta en ese repositorio.

El repositorio en el que se ejecuta este comando debe tener un remoto que sea una puerta de enlace al cluster. El parámetro gateway es el nombre de ese remoto. El parámetro clustername es el nombre del cluster.

El siguiente paso después de ejecutar este comando es configurar los nodos de cluster adicionales que esta puerta de enlace sirve al cluster, luego ejecutar git-annex-updatecluster. Consulte la documentación de ese comando para obtener detalles sobre la configuración de nodos.

Después de ejecutar este comando en el nuevo repositorio de puerta de enlace, normalmente también es necesario ejecutarlo en los demás repositorios de puerta de enlace, después de añadir el nuevo repositorio de puerta de enlace como remoto.

OPCIONES

Las git-annex-common-options(1) pueden ser utilizadas.
