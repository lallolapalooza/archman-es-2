NOMBRE

git-annex-vcycle - cambia la vista al siguiente diseño

SINOPSIS

git annex vcycle

DESCRIPCIÓN

Cuando una vista involucra subdirectorios anidados, esto cicla el orden.

Por ejemplo, cuando la vista es por año/autor/etiqueta, vcycle la cambiará a autor/etiqueta/año.

OPCIONES

Se pueden usar las opciones-comunes-de-git-annex(1).
