NOMBRE

git-warp-time - utilidad CLI que restablece las marcas de tiempo de los archivos en el directorio de trabajo de un repositorio Git a la marca de tiempo exacta de la última confirmación que modificó cada archivo

SINOPSIS

git-warp-time [-d|--dirty] [-i|--ignored] [-o|--ignore-older] [-q|--quiet] [-h|--help] [RUTAS]

DESCRIPCIÓN

Utilidad CLI que restablece las marcas de tiempo de los archivos en el directorio de trabajo de un repositorio Git a la marca de tiempo exacta de la última confirmación que modificó cada archivo

OPCIONES

-d, --dirty
Incluir archivos rastreados por Git pero con modificaciones en la copia de trabajo
-i, --ignored
Incluir archivos rastreados por Git pero también ignorados
-o, --ignore-older
Solo tocar archivos que son más nuevos que su historial, ignorar los que son más antiguos
-q, --quiet
No imprimir ninguna salida sobre los archivos tocados o omitidos
-h, --help
Imprimir ayuda
[RUTAS]
Lista opcional de rutas para operar en lugar del valor predeterminado, que son todos los archivos rastreados por Git
