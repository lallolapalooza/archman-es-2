NOMBRE

git-annex-webapp - iniciar aplicación web

SINOPSIS

git annex webapp

DESCRIPCIÓN

Abre una aplicación web que permite la fácil configuración de un repositorio git-annex y el control del asistente de git-annex. Si el asistente no se está ejecutando, se iniciará. Esto provocará que se añadan nuevos archivos y que se realicen operaciones de sincronización.

Por defecto, la aplicación web solo es accesible desde localhost y su ejecución abre una ventana del navegador.

OPCIONES

--listen=direccion
Útil para usar la aplicación web en un ordenador remoto. Esto hace que la aplicación web escuche en la dirección IP especificada. (O en la dirección a la que resuelve un nombre de host especificado).
Esto deshabilita la ejecución de un navegador web local y muestra la URL que puedes usar para abrir la aplicación web.
Establece annex.listen en la configuración de git para que la aplicación web siempre escuche en una dirección IP.
--port=numero
Usa esta opción para especificar un puerto para la aplicación web. Por defecto, la aplicación web elige un puerto no utilizado.
También se pueden usar las opciones-comunes-de-git-annex(1).

USANDO HTTPS

Al usar la aplicación web en un ordenador remoto, casi seguro querrás habilitar HTTPS. La aplicación web usará HTTPS si encuentra .git/annex/privkey.pem y .git/annex/certificate.pem. Aquí tienes una forma de generar esos archivos, usando un certificado autofirmado:


openssl genrsa -out .git/annex/privkey.pem 4096
openssl req -new -x509 -key .git/annex/privkey.pem > .git/annex/certificate.pem
