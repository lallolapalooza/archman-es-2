NOMBRE

git-annex-status - mostrar el estado del árbol de trabajo (obsoleto)

SINOPSIS

git annex status [ruta ...]

DESCRIPCIÓN

Similar a git status --short, este comando muestra el estado de los archivos en el árbol de trabajo.

Muestra los archivos que no están registrados en git (?), eliminados (D), modificados (M), añadidos pero no confirmados (A), y con el tipo cambiado/desbloqueados (T).

OPCIONES

--ignore-submodules=cuando
Esta opción se pasa a git status, consulta su página del manual para más detalles.
--json
Habilita la salida JSON. Está destinada a ser analizada por programas que usan git-annex. Cada línea de salida es un objeto JSON.
--json-error-messages
Los mensajes que normalmente se enviarían a la salida de error estándar se incluyen en el JSON en su lugar.
También se pueden usar las git-annex-common-options(1).
