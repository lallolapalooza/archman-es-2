NOMBRE

git-annex-map - generar mapa de repositorios

SINOPSIS

git annex map

DESCRIPCIÓN

Te ayuda a mantener un registro de tus repositorios y de las conexiones entre ellos, saliendo y examinando todos los que puede alcanzar, y generando un archivo Graphviz que lo muestra todo. Si el comando xdot o dot está disponible, se utiliza para mostrar el archivo en tu pantalla.

Este comando solo se conecta a hosts a los que el host en el que se ejecuta puede conectarse directamente. No intenta tunelizar a través de hosts intermedios. Por lo tanto, podría no mostrar todas las conexiones entre los repositorios de la red.

Además, si conectarse a un host requiere una contraseña, es posible que tengas que introducirla varias veces mientras se construye el mapa.

Ten en cuenta que esta subcomando puede usarse para graficar cualquier repositorio git; no se limita a los repositorios git-annex.

LEYENDA

Los óvalos son repositorios. Blanco es normal, verde es de confianza, rojo es no confiable y gris es muerto.

Las flechas entre repositorios son conexiones a través de remotos git.

Las cajas de color azul claro son hosts que fueron mapeados y contienen los repositorios de ese host.

OPCIONES

--fast
No muestres el archivo Graphviz generado, sino guárdalo para uso posterior.
--json
Genera la salida del mapa como un objeto JSON.
También se pueden usar las opciones generales de git-annex (git-annex-common-options(1)).
