NOMBRE

git-evtag - Firma un commit de git con checksums extendidos

SINOPSIS

git evtag sign [OPCIONES...] {NOMBRE ETIQUETA}

git evtag verify [OPCIONES...] {NOMBRE ETIQUETA}

DESCRIPCIÓN

Si bien git puede usar GPG para firmar etiquetas y commits, solo cubre un objeto de commit, que está sujeto a debilidades de SHA1. Esta herramienta utiliza SHA512 en todo el contenido de una etiqueta, creando un nivel de garantía más fuerte.

OPCIONES

Consulte la ayuda del subcomando, por ejemplo, git-evtag sign --help.
