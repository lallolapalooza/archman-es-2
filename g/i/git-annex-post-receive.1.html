NOMBRE

git-annex-post-receive - ejecutado por el hook git post-receive

SINOPSIS

git annex post-receive

DESCRIPCIÓN

Esto está destinado a ser llamado desde el hook post-receive de git. git annex init crea automáticamente un hook post-receive usando esto.

Cuando un repositorio se configura con receive.denyCurrentBranch=updateInstead, los pushes al repositorio actualizan su árbol de trabajo. Sin embargo, eso no funciona para repositorios que tienen una rama ajustada en checkout. El hook actualiza el árbol de trabajo cuando se ejecuta en dicho repositorio, de la misma manera que lo haría ejecutar git-annex merge.

Cuando un repositorio se configura para hacer proxy a un remoto especial con exporttree=yes, y se recibe la rama annex-tracking-branch configurada en remote.name, el hook se encarga de actualizar el árbol exportado al remoto especial.

OPCIONES

Se pueden usar las opciones-comunes-de-git-annex(1).
