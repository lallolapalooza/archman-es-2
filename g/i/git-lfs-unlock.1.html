NOMBRE

git-lfs-unlock - Elimina la configuración de "bloqueado" para un archivo en el servidor Git LFS

SINOPSIS

git lfs unlock [<opciones>] <ruta>

DESCRIPCIÓN

Elimina la ruta de archivo dada como "bloqueada" en el servidor Git LFS. Los archivos deben existir y tener un estado git limpio antes de poder ser desbloqueados. La opción --force omitirá estas comprobaciones.

OPCIONES

-r <nombre>, --remote=<nombre>

Especifica el servidor Git LFS a utilizar. Se ignora si la clave de configuración lfs.url está establecida.

-f, --force

Indica al servidor que elimine el bloqueo, incluso si pertenece a otro usuario.

-i <id>, --id=<id>

Especifica un bloqueo por su ID en lugar de por su ruta.

-j, --json

Escribe la información del bloqueo como JSON en STDOUT si el comando se ejecuta correctamente. Diseñado para la interoperación con herramientas externas. Si el comando devuelve un código de salida distinto de cero, se enviarán mensajes de texto plano a STDERR.

VER TAMBIÉN

git-lfs-lock(1), git-lfs-locks(1).

Parte del conjunto git-lfs(1).
