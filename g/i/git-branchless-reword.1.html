NOMBRE

reword - Reescribir commits

SINOPSIS

reword [--hidden] [-f|--force-rewrite] [-m|--message] [-d|--discard] [--fixup] [-h|--help] [REVSETS]

DESCRIPCIÓN

Reescribe commits

OPCIONES

--hidden
Incluye commits ocultos en los resultados de la evaluación de expresiones revset
-f, --force-rewrite
Fuerza la reescritura de commits públicos, aunque otras personas puedan tener acceso a esos commits
-m, --message=MENSAJES
Mensaje a aplicar a los commits. Múltiples mensajes se combinarán como párrafos separados, similar a `git commit`
-d, --discard
Descarta los mensajes de commit originales.

Si `commit.template` está configurado, el editor se pre-rellena con él; de lo contrario, el editor comienza vacío.

--fixup=COMMIT_A_CORREGIR
Un commit a "corregir". Los commits reescritos se convertirán en commits `fixup!` (adecuados para usar con `git rebase --autosquash`) dirigidos al commit proporcionado
-h, --help
Imprime la ayuda (ver un resumen con '-h')
[REVSETS] [predeterminado: stack() | @]
Cero o más commits para reescribir
