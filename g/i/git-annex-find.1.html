NOMBRE

git-annex-find - lista los archivos disponibles

SINOPSIS

git annex find [ruta ...]

DESCRIPCIÓN

Emite una lista de archivos anexados en la ruta especificada. Sin ruta, busca archivos en el directorio actual y sus subdirectorios.

OPCIONES

opciones coincidentes
Las opciones de coincidencia de git-annex(1) se pueden usar para especificar los archivos a listar.
Por defecto, el comando find solo lista los archivos anexados cuyo contenido está presente actualmente. Especificar cualquiera de las opciones de coincidencia anulará este comportamiento predeterminado.
Para listar todos los archivos anexados, presentes o no, especifique --anything.
Para listar archivos anexados cuyo contenido no está presente, especifique --not --in=here
--branch=ref
Lista archivos en la rama o treeish especificado.
--print0
Nombres de archivo de salida terminados en nulos, para usar con xargs -0
--format=valor
Utiliza formato de salida personalizado.
El valor es una cadena de formato, en la que '${var}' se expande al valor de una variable. Para justificar a la derecha una variable con espacios, use '${var;ancho}'; para justificar a la izquierda una variable, use '${var;-ancho}'; para escapar caracteres inusuales (incluidos caracteres de control) en una variable, use '${var_escapada}'
Estas variables están disponibles para su uso en formatos: file, key, backend, bytesize, humansize, keyname, hashdirlower, hashdirmixed, mtime (para el campo mtime de una clave WORM).
Además, '\n' es una nueva línea, '\000' es un NULL, etc.
El formato de salida predeterminado es el mismo que --format='${file}\n', excepto cuando se emite a una terminal, los caracteres de control se escaparán.
--json
Emite la lista de archivos en formato JSON.
Esto está destinado a ser analizado por programas que usan git-annex. Cada línea de salida es un objeto JSON.
--json-error-messages
Los mensajes que normalmente se emitirían a la salida estándar de error se incluyen en el JSON en su lugar.
--batch
Habilita el modo por lotes, en el que se lee un archivo línea por línea de stdin, se muestra su información y se repite.
Tenga en cuenta que si el archivo no es un archivo anexado, o no está presente, o de lo contrario no cumple con las opciones de coincidencia, se emitirá una línea vacía en su lugar.
-z
Hace que la entrada de --batch se delimite con nulos en lugar de las nuevas líneas habituales.
También se pueden usar las opciones comunes de git-annex(1).
