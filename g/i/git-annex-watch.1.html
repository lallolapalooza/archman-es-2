NOMBRE

git-annex-watch - demonio para observar cambios

SINOPSIS

git annex watch

DESCRIPCIÓN

Observa los cambios en los archivos del directorio actual y sus subdirectorios, y se encarga de añadir automáticamente nuevos archivos, así como de gestionar archivos eliminados, copiados y movidos. Con esto ejecutándose como un demonio en segundo plano, ya no necesitará ejecutar comandos git manualmente al manipular sus archivos.

Por defecto, todos los archivos nuevos en el directorio se añadirán al repositorio. (Incluyendo los archivos ocultos). Para bloquear la adición de algunos archivos, utilice los archivos .gitignore.

Por defecto, todos los archivos que se añaden se agregan al annex, igual que cuando ejecuta git annex add. Si configura annex.largefiles, los archivos que no coincidan se añadirán en su lugar con git add.

OPCIONES

--foreground
Evita la bifurcación a segundo plano.
--stop
Detiene un demonio en ejecución en el repositorio actual.
También se pueden usar las opciones generales de git-annex (git-annex-common-options(1)).
