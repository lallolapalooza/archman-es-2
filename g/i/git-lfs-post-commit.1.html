NOMBRE

git-lfs-post-commit - Implementación del hook post-commit de Git

SINOPSIS

git lfs post-commit

DESCRIPCIÓN

Responde a eventos post-commit de Git. Se asegura de que los archivos marcados como bloqueables por git lfs track no sean modificables en la copia de trabajo, a menos que estén actualmente bloqueados por el usuario local.

Mientras que el comando git lfs post-merge, que tiene un propósito similar, debe examinar todos los archivos en la copia de trabajo, git lfs post-commit puede limitarse a verificar solo aquellos archivos que han cambiado en HEAD. Maneja principalmente los archivos bloqueables recién añadidos que aún no se han hecho no modificables.

VER TAMBIÉN

git-lfs-post-merge(1), git-lfs-track(1)

Parte de la suite git-lfs(1).
