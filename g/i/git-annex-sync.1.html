NOMBRE

git-annex-sync - sincronizar el repositorio local con los remotos

SINOPSIS

git annex sync [remoto ...]

DESCRIPCIÓN

Este comando sincroniza el repositorio local con sus remotos.

Este comando primero confirma los cambios locales en archivos que previamente se han añadido al repositorio. Luego, realiza el equivalente de git-annex-pull(1) seguido de git-annex-push(1).

Sin embargo, a diferencia de esos comandos, este comando no transfiere contenido anexionado por defecto. Eso cambiará en una futura versión de git-annex, al sincronizar con repositorios que tengan contenido preferido configurado.

OPCIONES

--content, --no-content, -g
La opción --content hace que el contenido de los archivos anexionados también se descargue y se suba.
Las opciones --no-content y -g hacen que el contenido de los archivos anexionados no se descargue ni se suba.
El archivo de configuración annex.synccontent se puede establecer en true para que --content esté habilitado por defecto.
--content-of=ruta -C ruta
Esta opción hace que el contenido de los archivos anexionados en la ruta dada también se descargue y se suba.
Esta opción se puede repetir varias veces con diferentes rutas.
Tenga en cuenta que esta opción no evita exportar otros archivos a un remoto con "exporttree=yes".
--commit, --no-commit
Por defecto se realiza una confirmación (a menos que annex.autocommit esté configurado como false).
Use --no-commit para evitar confirmar cambios locales.
--message=msg -m msg
Use esta opción para especificar un mensaje de confirmación.
Si se dan varias opciones -m, sus valores se concatenan como párrafos separados.
--pull, --no-pull
Use esta opción para deshabilitar la descarga.
Cuando remote.<nombre>.annex-sync está configurado como false, la descarga se deshabilita para ese remoto, y usar --pull no la habilitará.
--push, --no-push
Use esta opción para deshabilitar la subida.
Cuando remote.<nombre>.annex-sync está configurado como false, la subida se deshabilita para ese remoto, y usar --push no la habilitará.
También todas las opciones soportadas por git-annex-pull(1) y
git-annex-push(1) pueden ser utilizadas.
También las opciones-comunes-de-git-annex(1) pueden ser utilizadas.
