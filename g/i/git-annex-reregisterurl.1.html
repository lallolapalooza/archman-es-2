NOMBRE

git-annex-reregisterurl - actualiza la información de registro de url

SINOPSIS

git annex reregisterurl [clave]

DESCRIPCIÓN

Este comando de bajo nivel actualiza la información sobre las url que están registradas para una clave.

OPCIONES

--move-from=nombre|uuid
Para cada clave, actualiza cualquier url que actualmente esté reclamada por el repositorio remoto especificado para ser utilizada en su lugar por el repositorio especial web.
Esto podría usarse, por ejemplo, cuando se necesitaba un repositorio especial para proporcionar autorización para obtener una url, pero la url se ha vuelto públicamente disponible y, por lo tanto, se puede usar el repositorio especial web.
Tenga en cuenta que, al igual que git-annex unregisterurl, usar esta opción anula el registro de una url de un repositorio especial, pero no marca el contenido como no presente en ese repositorio especial. Sin embargo, al igual que git-annex registerurl, esta opción marca el contenido como presente en el repositorio especial web.
--batch
En modo de entrada por lotes, las líneas se leen desde stdin, y cada línea debe contener una clave.
-z
Cuando está en modo por lotes, la entrada se delimita por nulos en lugar de las nuevas líneas habituales.
--json
Habilita la salida JSON. Esto está destinado a ser analizado por programas que utilizan git-annex. Cada línea de salida es un objeto JSON.
--json-error-messages
Los mensajes que normalmente se enviarían a la salida estándar de error se incluyen en el JSON en su lugar.
También se pueden usar las opciones comunes de git-annex(1).
