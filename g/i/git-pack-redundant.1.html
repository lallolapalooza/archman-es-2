GIT-PACK-REDUNDANT(1) Manual de Git GIT-PACK-REDUNDANT(1)

NOMBRE

git-pack-redundant - Encuentra archivos de paquete redundantes

SINOPSIS

git pack-redundant [--verbose] [--alt-odb] (--all | <nombre-archivo-paquete>...)

ADVERTENCIA

git pack-redundant ha sido deprecado y está programado para su eliminación en una futura versión de Git. Dado que solo puede eliminar paquetes duplicados completos y no objetos individuales duplicados, generalmente no es una herramienta útil para reducir el tamaño del repositorio. Es mejor utilizar git gc para hacerlo, lo que colocará los objetos en un nuevo paquete, eliminando duplicados.

Ejecutar pack-redundant sin la opción --i-still-use-this fallará en esta versión. Si cree que tiene un caso de uso para el cual pack-redundant es más adecuado y se opone a esta eliminación, póngase en contacto con la lista de correo de Git en git@vger.kernel.org[1]. Más información sobre la lista está disponible en https://git-scm.com/community.

DESCRIPCIÓN

Este programa calcula qué paquetes en su repositorio son redundantes. La salida es adecuada para enviarla a xargs rm si se encuentra en la raíz del repositorio.

git pack-redundant acepta una lista de objetos en la entrada estándar. Cualquier objeto proporcionado será ignorado al verificar qué paquetes son necesarios. Esto hace que el siguiente comando sea útil cuando se quieren eliminar paquetes que contienen objetos inalcanzables.

git fsck --full --unreachable | cut -d ' ' -f3 | \ git pack-redundant --all | xargs rm

OPCIONES

--all

Procesa todos los paquetes. Se ignoran los nombres de archivo en la línea de comandos.

--alt-odb

No requiere que los objetos presentes en paquetes de directorios de bases de datos de objetos (odb) alternativos estén presentes en los paquetes locales.

--verbose

Muestra algunas estadísticas en stderr. Tiene una pequeña penalización de rendimiento.
