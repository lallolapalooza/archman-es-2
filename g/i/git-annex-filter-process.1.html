NOMBRE

git-annex-filter-process - proceso de filtro de git de larga duración para git-annex

SINOPSIS

git annex filter-process

DESCRIPCIÓN

Cuando esto no está habilitado, cada archivo que git intenta filtrar implica el inicio de un nuevo proceso git-annex smudge. Iniciar muchos de estos procesos para muchos archivos puede ser lento y puede hacer que comandos como git checkout y git add sean lentos cuando operan sobre muchos archivos. (Muchos archivos anexados bloqueados no hacen que git checkout sea lento, pero los archivos desbloqueados y los archivos no anexados sí que lo ralentizan).

Por otro lado, cuando esto está habilitado, git add de un archivo grande realiza una lectura innecesaria adicional del archivo y canaliza su contenido a git-annex. Por lo tanto, cuando esto está habilitado, será más rápido usar git-annex add para añadir archivos grandes al anexo, en lugar de git add. Otros comandos que añaden archivos, como git commit -a, también se ven afectados por esto.

Esto se utiliza por defecto en los repositorios git-annex v9 y superiores, mientras que los repositorios v8 utilizan git-annex smudge para la compatibilidad con versiones anteriores de git-annex.

Para habilitar esto en un repositorio v8, ejecute:


git config filter.annex.process 'git-annex filter-process'

Para deshabilitarlo, simplemente puede anular la configuración:


git config --unset filter.annex.process

No habrá ninguna diferencia visible en el comportamiento entre habilitar esto y no hacerlo, aparte de los cambios en la velocidad y el uso de memoria al usar git.

OPCIONES

Las opciones generales de git-annex(1) pueden ser utilizadas.

VER TAMBIÉN
