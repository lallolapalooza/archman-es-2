Especifica el factor de compresión para los canales RGB entre 0 y 100. El predeterminado es 75. En caso de compresión sin pérdida (predeterminada), un factor pequeño permite una velocidad de compresión más rápida, pero produce un archivo más grande. La máxima compresión se logra usando un

m
int Especifica el método de compresión a usar. Este parámetro controla la compensación entre la velocidad de codificación y el tamaño y calidad del archivo comprimido. Los valores posibles van de 0 a 6. El valor predeterminado es 4. Cuando se usan valores más altos, el codificador gastará más tiempo inspeccionando posibles codificaciones adicionales y decidirá
sobre la ganancia de calidad. Un valor más bajo puede resultar en un tiempo de procesamiento más rápido a costa de un tamaño de archivo más grande y una calidad de compresión más baja.
-min_size
Codifica la imagen para lograr el tamaño más pequeño. Esto desactiva la inserción de fotogramas clave y elige el método de disposición que resulta en la salida más pequeña para cada fotograma. Usa compresión sin pérdida por defecto, pero puede combinarse con las opciones -q, -m, -lossy o -mixed.
-kmi

int -km

Especifica la distancia mínima y máxima entre fotogramas clave consecutivos (fotogramas independientemente descodificables) en la animación de salida. La herramienta insertará algunos fotogramas clave en la
animación de salida según sea necesario para que se cumpla este criterio.
Un valor de 'kmax' de 0 desactivará la inserción de fotogramas clave. Un valor de 'kmax' de 1 resultará en que todos los fotogramas sean fotogramas clave. El valor de 'kmin' no se tiene en cuenta en ambos casos especiales. Los valores típicos están en el rango de 3 a 30. Los valores predeterminados son kmin = 9, kmax = 17 para compresión sin pérdida y kmin = 3, kmax = 5 para compresión con
pérdida.
Estas dos opciones son relevantes solo para imágenes animadas con un gran número de fotogramas (>50). Cuando se usan valores más bajos, más fotogramas se convertirán en fotogramas clave. Esto puede llevar a un número menor de fotogramas requeridos para descodificar un fotograma en promedio, mejorando así el rendimiento de descodificación. Pero esto puede llevar a tamaños de archivo ligeramente más grandes.
Valores más altos pueden llevar a un peor rendimiento de descodificación, pero tamaños de archivo más pequeños.
Algunas restricciones: (i) kmin <
kmax,
(ii) kmin >= kmax / 2 + 1 y
(iii) kmax - kmin <= 30.
Si alguna de estas restricciones no se cumple, se aplicarán automáticamente.
