GIT-LAST-MODIFIED(1) Manual de Git GIT-LAST-MODIFIED(1)

NOMBRE

git-last-modified - EXPERIMENTAL: Muestra cuándo se modificaron por última vez los archivos

SINOPSIS

git last-modified [--recursive] [--show-trees] [<rango-de-revisiones>] [[--] <ruta>...]

DESCRIPCIÓN

Muestra qué commit modificó por última vez cada uno de los archivos y subdirectorios relevantes. También se tiene en cuenta un commit que renombra una ruta o cambia su modo.

ESTE COMANDO ES EXPERIMENTAL. EL COMPORTAMIENTO PUEDE CAMBIAR.

OPCIONES

-r, --recursive

En lugar de mostrar las entradas del árbol, entra en los subárboles y muestra todas las entradas dentro de ellos recursivamente.

-t, --show-trees

Muestra las entradas del árbol incluso cuando se recursa en ellas. No tiene ningún efecto sin --recursive.

<rango-de-revisiones>

Solo recorre los commits en el rango de revisiones especificado. Cuando no se especifica ningún <rango-de-revisiones>, por defecto es HEAD (es decir, todo el historial que conduce al commit actual). Para una lista completa de formas de escribir <rango-de-revisiones>, consulta la sección Especificación de rangos de gitrevisions(7).

[--] <ruta>...

Para cada <ruta> dada, se devuelve el commit que la modificó por última vez. Sin un parámetro de ruta opcional, se incluyen en la salida todos los archivos y subdirectorios en el recorrido de la ruta.

VER TAMBIÉN

git-blame(1), git-log(1).
