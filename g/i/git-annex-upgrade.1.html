NOMBRE

git-annex-upgrade - actualizar repositorio

SINOPSIS

git annex upgrade

DESCRIPCIÓN

Actualiza el repositorio a la última versión.

Cada repositorio de git-annex tiene un `annex.version` en su configuración de git, que indica la versión del repositorio. Cuando una versión antigua del repositorio queda obsoleta, git-annex la actualizará automáticamente (a menos que `annex.autoupgraderepository` esté configurado como falso). Para actualizar manualmente, puedes usar este comando.

A veces hay una versión de repositorio más nueva que aún no es la predeterminada, y entonces puedes usar este comando para actualizarla.

Actualmente, git-annex admite actualizaciones desde versiones anteriores hasta la versión 0, que solo fue utilizada por su autor. Se espera que git-annex siempre admita actualizaciones desde todas las versiones pasadas del repositorio; esto es necesario para permitir que los archivos se desconecten durante años y se utilicen más tarde.

OPCIONES

--autoonly
Solo realiza las actualizaciones automáticas que se puedan hacer, no necesariamente actualiza a la última versión. Esto se utiliza internamente por git-annex.
--json
Habilita la salida JSON. Está destinado a ser analizado por programas que utilizan git-annex.
--json-error-messages
Los mensajes que normalmente se mostrarían en la salida estándar de error se incluyen en el JSON.
También se pueden usar las opciones comunes de git-annex(1).
