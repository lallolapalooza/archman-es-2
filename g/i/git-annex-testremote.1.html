NOMBRE

git-annex-testremote - prueba las transferencias hacia/desde un remoto

SINOPSIS

git annex testremote remoto

DESCRIPCIÓN

Esto prueba un remoto enviándole objetos, descargando objetos desde él, etc.

Es seguro ejecutarlo en un repositorio existente (el contenido del repositorio no se altera), aunque puede realizar transferencias de datos costosas.

Es mejor crear un nuevo remoto para fines de prueba. Aunque la prueba intenta limpiarse después de sí misma, si el remoto que se está probando tuviera un error, la limpieza podría fallar, dejando datos de prueba en el remoto. Además, algunos remotos especiales no admiten la eliminación de datos que se han almacenado en ellos, por lo que los datos de prueba no podrán limpiarse al probarlos.

Las pruebas utilizarán la configuración del remoto, variando automáticamente los tamaños de los fragmentos, y con el cifrado compartido simple deshabilitado y habilitado, y exporttree deshabilitado y habilitado. Si el remoto es de solo lectura, las pruebas se limitan a verificar varias propiedades de la descarga desde él.

OPCIONES

--fast
Realiza un conjunto de pruebas más pequeño.
--test-readonly=archivo
Normalmente, se generan objetos aleatorios para la prueba y se envían al remoto. Cuando se prueba un remoto de solo lectura, eso no se puede hacer, y por lo tanto necesita especificar algunos archivos anexados para usar en las pruebas, usando esta opción. Su contenido debe estar presente en el remoto de solo lectura que se está probando, y en el repositorio local.
Esta opción se puede repetir.
--size=NUnidades
Ajusta el tamaño base de los objetos generados. El valor predeterminado es 1MiB.
También se pueden usar las opciones de git-annex-common-options(1).
