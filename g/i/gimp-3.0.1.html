NOMBRE

gimp - un programa de manipulación de imágenes y pintura.

SINOPSIS

gimp [-h] [--help] [--help-all] [--help-gtk] [-v] [--version] [--license] [--verbose] [-n] [--new-instance] [-a] [--as-new] [-i] [--no-interface] [-d] [--no-data] [-f] [--no-fonts] [-s] [--no-splash] [--no-shm] [--no-cpu-accel] [--display pantalla] [--session <nombre>] [-g] [--gimprc <gimprc>] [--system-gimprc <gimprc>] [--dump-gimprc] [--console-messages] [--debug-handlers] [--stack-trace-mode <modo>] [--pdb-compat-mode <modo>] [--batch-interpreter <procedimiento>] [-b] [--batch <comando>] [nombre_archivo] ...

DESCRIPCIÓN

GIMP es el GNU Image Manipulation Program. Se utiliza para editar y manipular imágenes. Puede cargar y guardar una variedad de formatos de imagen y puede usarse para convertir entre formatos.

GIMP también se puede usar como un programa de pintura. Cuenta con un conjunto de herramientas de dibujo y pintura como aerógrafo, clonar, lápiz y pincel. Las herramientas de pintura y dibujo se pueden aplicar a una imagen con una variedad de modos de pintura. También ofrece una amplia gama de herramientas de selección como rectángulo, elipse, selección difusa, selección de Bézier, tijeras inteligentes y selección por color.

GIMP ofrece una variedad de complementos que realizan una variedad de manipulaciones de imágenes. Los ejemplos incluyen bumpmap, detección de bordes, desenfoque gaussiano y muchos otros. Además, GIMP tiene varias extensiones de scripting que permiten el procesamiento y la creación de imágenes avanzadas no interactivas.

GIMP se distribuye con un segundo binario llamado gimp-console. Este binario es una versión solo para consola y se comporta como si gimp se hubiera llamado con la opción de línea de comandos --no-interface.

En plataformas con el sistema de bus de mensajes D-Bus, GIMP verificará por defecto si una instancia ya se está ejecutando en esta sesión de usuario. Si detecta que es así, pasará todos los nombres de archivo proporcionados en la línea de comandos a la instancia de GIMP ya en ejecución y saldrá.

OPCIONES

GIMP acepta las siguientes opciones:

-h, --help
Muestra las opciones de línea de comandos de GIMP.
--help-all
Muestra todas las opciones de línea de comandos.
--help-gtk
Muestra las opciones de línea de comandos de GTK.
--help-gegl
Muestra las opciones de línea de comandos de GEGL.
-v, --version
Muestra información de la versión y sale. Cuando se combina con la opción --verbose, también se muestra información de la versión de las bibliotecas utilizadas por GIMP.
--license
Muestra información de la licencia y sale.
--verbose
Sé verboso y genera información en la salida estándar.
-n, --new-instance
No intentes reutilizar una instancia de GIMP ya en ejecución. Siempre inicia una nueva.
-a, --as-new
Abre los nombres de archivo pasados en la línea de comandos como nuevas imágenes, no les asignes el nombre de archivo.
-i, --no-interface
Ejecuta sin interfaz de usuario.
-d, --no-data
No cargues patrones, degradados, paletas ni pinceles. Útil en situaciones no interactivas donde se busca minimizar el tiempo de inicio.
-f, --no-fonts
No cargues ninguna fuente. No habrá funcionalidad de texto disponible si se utiliza esta opción.
--display pantalla
Usa la pantalla X designada.
-s, --no-splash
No muestres la pantalla de presentación.
--no-shm
No uses memoria compartida entre GIMP y sus complementos. En lugar de usar memoria compartida, GIMP enviará los datos a través de una tubería. Esto resultará en un rendimiento más lento que usando memoria compartida.
--no-cpu-accel
No uses aceleraciones de CPU como MMX o SSE, incluso si GIMP detecta que tu CPU proporciona esta funcionalidad.
--session <nombre>
Usa un archivo sessionrc diferente para esta sesión de GIMP. El nombre de sesión dado se añade al nombre de archivo sessionrc predeterminado.
-g, --gimprc <gimprc>
Usa un archivo gimprc alternativo en lugar del predeterminado. Útil en casos donde las rutas de los complementos o las especificaciones de la máquina pueden ser diferentes.
--system-gimprc <gimprc>
Usa un archivo gimprc del sistema alternativo.
--dump-gimprc
Genera un archivo gimprc con la configuración predeterminada.
--debug-handlers
Habilita manejadores de señales de depuración.
-c, --console-messages
No muestres cuadros de diálogo en caso de errores o advertencias. En su lugar, imprime los mensajes en la consola.
--stack-trace-mode {never|query|always}
Si se debe generar un rastreo de pila en caso de señales fatales.
--pdb-compat-mode {off|on|warn}
Si el PDB debe proporcionar alias para funciones obsoletas.
--batch-interpreter <procedimiento>
Especifica el procedimiento a utilizar para procesar eventos por lotes. El valor predeterminado es dejar que Script-Fu evalúe los comandos.
-b, --batch <comando>
Ejecuta <comando> de forma no interactiva. Esta opción puede aparecer varias veces. El <comando> se pasa al intérprete por lotes. Cuando <comando> es -, los comandos se leen de la entrada estándar.

MEDIO AMBIENTE

GIMP respeta una serie de variables de entorno.

DISPLAY
para obtener el host y número de pantalla predeterminados.
GIMP3_DIRECTORY
para obtener el nombre del directorio personal de GIMP. Si no está establecido, se usa $XDG_CONFIG_HOME/GIMP/3.0. Si es una ruta absoluta, se usa tal cual. Si es una ruta relativa, se considera un subdirectorio de $XDG_CONFIG_HOME.
GIMP3_DATADIR
para obtener la ubicación base de los archivos de datos, como pinceles y patrones. Si no está establecido, se usa /usr/share/gimp/3.0.
GIMP3_LOCALEDIR
para obtener la ubicación base de las traducciones. Si no está establecido, se usa /usr/share/locale.
GIMP3_PLUGINDIR
para obtener la ubicación base de los complementos y módulos. Si no está establecido, se usa /usr/lib/gimp/3.0.
GIMP3_SYSCONFDIR
para obtener la ubicación de los archivos de configuración. Si no está establecido, se usa /etc/gimp/3.0.
GIMP3_CACHEDIR
para obtener la ubicación de los archivos de caché. Si no está establecido, se usa la ubicación predeterminada del sistema para archivos de caché por usuario.
GIMP3_TEMPDIR
para obtener la ubicación de los archivos temporales. Si no está establecido, se usa la ubicación predeterminada del sistema para archivos temporales.

En Linux, GIMP puede compilarse con soporte para reubicación binaria. Esto hará que los archivos de datos, complementos y configuración se busquen en relación con la ubicación del archivo ejecutable de gimp, a menos que se anule mediante las variables de entorno mencionadas anteriormente.

ARCHIVOS

Los archivos de datos de GIMP se almacenan en /usr/share/gimp/3.0, donde ${datarootdir} se establece en la instalación, pero normalmente es /usr/share. Los archivos de configuración de GIMP a nivel de sistema se almacenan en /etc/gimp/3.0, donde ${prefix} normalmente es /usr.

La mayor parte de la configuración de GIMP se lee desde el archivo de inicialización del usuario, $XDG_CONFIG_HOME/GIMP/3.0/gimprc. El equivalente a nivel de sistema está en /etc/gimp/3.0/gimprc. El archivo a nivel de sistema se analiza primero y el gimprc del usuario puede anular la configuración del sistema. /etc/gimp/3.0/gimprc_user es el gimprc por defecto que se coloca en los directorios de inicio de los usuarios la primera vez que se ejecuta GIMP.

$XDG_CONFIG_HOME/GIMP/3.0/devicerc - contiene la configuración de los dispositivos de entrada junto con la herramienta, colores, pincel, patrón y degradado asociados a ese dispositivo.

$XDG_CONFIG_HOME/GIMP/3.0/gtkrc - conjunto de configuraciones GTK específicas de GIMP del usuario. Aquí se pueden establecer opciones como el color de los widgets y los tamaños de las fuentes.

/etc/gimp/3.0/gtkrc - conjunto por defecto de configuraciones GTK específicas de GIMP a nivel de sistema.

$XDG_CONFIG_HOME/GIMP/3.0/shortcutsrc - conjunto de atajos de teclado del usuario.

$XDG_CONFIG_HOME/GIMP/3.0/parasiterc - Almacena todos los parásitos persistentes de GIMP. Este archivo se reescribirá cada vez que salgas de GIMP.

$XDG_CONFIG_HOME/GIMP/3.0/sessionrc - Este archivo toma información específica de la sesión (es decir, información que deseas conservar entre dos sesiones de GIMP). No se supone que lo edites manualmente, pero por supuesto que puedes hacerlo. Este archivo se reescribirá por completo cada vez que salgas de GIMP. Si este archivo no se encuentra, se usan los valores por defecto.

$XDG_CONFIG_HOME/GIMP/3.0/templaterc - Las plantillas de imagen se mantienen en este archivo. Se pueden crear nuevas imágenes convenientemente a partir de estas plantillas. Si este archivo no se encuentra, se usan los valores por defecto.

/etc/gimp/3.0/unitrc - base de datos de unidades por defecto del usuario. Contiene las definiciones de unidades para centímetros, metros, pies, yardas, puntos tipográficos y picas tipográficas, y se coloca en los directorios de inicio de los usuarios la primera vez que se ejecuta GIMP. Si este archivo no se encuentra, se usan los valores por defecto.

$XDG_CONFIG_HOME/GIMP/3.0/unitrc - Este archivo contiene tu base de datos de unidades de usuario. Puedes modificar esta lista con el editor de unidades. No se supone que lo edites manualmente, pero por supuesto que puedes hacerlo. Este archivo se reescribirá por completo cada vez que salgas de GIMP.

$XDG_CONFIG_HOME/GIMP/3.0/plug-ins - ubicación de los complementos instalados por el usuario.

$XDG_CONFIG_HOME/GIMP/3.0/pluginrc - los valores de inicialización de los complementos se almacenan aquí. Este archivo se analiza al inicio y se regenera si es necesario.

$XDG_CONFIG_HOME/GIMP/3.0/modules - ubicación de los módulos instalados por el usuario.

$XDG_CONFIG_HOME/GIMP/3.0/tmp - ubicación por defecto que GIMP usa como espacio temporal.

/usr/share/gimp/3.0/brushes - archivos de pinceles a nivel de sistema.

$XDG_CONFIG_HOME/GIMP/3.0/brushes - archivos de pinceles creados e instalados por el usuario. Estos archivos están en los formatos de archivo .gbr, .gih o .vbr.

$XDG_CONFIG_HOME/GIMP/3.0/curves - Perfiles y ajustes preestablecidos de curvas guardados desde la herramienta Curvas.

$XDG_CONFIG_HOME/GIMP/3.0/gimpressionist - Aquí se almacenan los ajustes preestablecidos y los pinceles y papeles creados por el usuario.

$XDG_CONFIG_HOME/GIMP/3.0/levels - Perfiles y ajustes preestablecidos de niveles guardados desde la herramienta Niveles.

/usr/share/gimp/3.0/palettes - los archivos de paletas a nivel de sistema.

$XDG_CONFIG_HOME/GIMP/3.0/palettes - archivos de paletas creados y modificados por el usuario. Estos archivos están en el formato .gpl.

/usr/share/gimp/3.0/patterns - conjunto básico de patrones para usar en GIMP.

$XDG_CONFIG_HOME/GIMP/3.0/patterns - archivos de patrones de GIMP creados e instalados por el usuario. Estos archivos están en el formato .pat.

/usr/share/gimp/3.0/gradients - conjunto estándar de archivos de degradados a nivel de sistema.

$XDG_CONFIG_HOME/GIMP/3.0/gradients - archivos de degradados creados e instalados por el usuario.

/usr/share/gimp/3.0/scripts - directorio de scripts a nivel de sistema utilizados en Script-Fu y otras extensiones de scripting.

$XDG_CONFIG_HOME/GIMP/3.0/scripts - scripts creados e instalados por el usuario.

/usr/share/gimp/3.0/gflares - directorio a nivel de sistema utilizado por el complemento gflare.

$XDG_CONFIG_HOME/GIMP/3.0/gflares - archivos gflare creados e instalados por el usuario.

/usr/share/gimp/3.0/gfig - directorio a nivel de sistema utilizado por el complemento gfig.

$XDG_CONFIG_HOME/GIMP/3.0/gfig - archivos gfig creados e instalados por el usuario.

/usr/share/gimp/3.0/images/gimp-splash.png - la imagen por defecto usada para la pantalla de bienvenida de GIMP.

/usr/share/gimp/3.0/images/gimp-logo.png - imagen usada en el diálogo Acerca de de GIMP.

/usr/share/gimp/3.0/tips/gimp-tips.xml - consejos como se muestran en el cuadro de diálogo "Consejo del día".

IMÁGENES DE BIENVENIDA

GIMP viene con una imagen por defecto para la pantalla de bienvenida, pero permite a los administradores del sistema y a los usuarios personalizar la pantalla de bienvenida proporcionando otras imágenes. La imagen que se usará con la pantalla de bienvenida se elige de la siguiente manera:

1.
GIMP intenta cargar una pantalla de bienvenida aleatoria desde el directorio $XDG_CONFIG_HOME/GIMP/3.0/splashes.
2.
Luego, recurre a usar $XDG_CONFIG_HOME/GIMP/3.0/gimp-splash.png.
3.
Si el usuario no instaló ninguna imagen de bienvenida personalizada, se elige una imagen aleatoria de /usr/share/gimp/3.0/splashes.
4.
Como último recurso, GIMP usa la imagen de bienvenida por defecto ubicada en /usr/share/gimp/3.0/images/gimp-splash.png.

SUGERENCIAS Y INFORMES DE ERRORES

Cualquier error que se encuentre debe reportarse al sistema de seguimiento de errores en línea disponible en la web en https://gitlab.gnome.org/GNOME/gimp/issues. Antes de reportar errores, por favor verifica si el error ya ha sido reportado.

Al reportar errores de GIMP, es importante incluir una forma fiable de reproducir el error, el número de versión de GIMP (y probablemente de GTK), el nombre del sistema operativo y su versión, y cualquier especificación de hardware relevante. Si un error causa un fallo, es muy útil si se puede proporcionar un seguimiento de pila. Y por supuesto, los parches para corregir el error son aún mejores.

OTRA INFORMACIÓN

El lugar canónico para encontrar información sobre GIMP es en https://www.gimp.org/. Aquí puedes encontrar enlaces a muchos otros sitios de GIMP, tutoriales, conjuntos de datos, archivos de listas de correo y más.

También hay disponible un Manual de Usuario de GIMP en https://docs.gimp.org/ que entra en mucho más detalle sobre el uso interactivo de GIMP.

Las últimas versiones de GIMP y las bibliotecas GTK siempre están disponibles en https://download.gimp.org/.
