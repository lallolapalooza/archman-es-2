NOMBRE

git-lfs-logs - Muestra errores del comando git-lfs

SINOPSIS

git lfs logs
git lfs logs <archivo>
git lfs logs clear
git lfs logs boomtown

DESCRIPCIÓN

Muestra errores del comando git-lfs. Cada vez que se bloquea, los detalles se guardan en ".git/lfs/logs".

COMANDOS

clear

Borra todos los errores registrados existentes.

boomtown

Desencadena una excepción simulada.

OPCIONES

Sin opciones, git lfs logs simplemente muestra la lista de registros de errores.

•<archivo>: Muestra el registro de error especificado. Usa "last" para mostrar el error más reciente.

VER TAMBIÉN

Parte de la suite git-lfs(1).
