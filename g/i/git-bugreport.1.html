NOMBRE

git-bugreport - Recopila información para que el usuario pueda presentar un informe de error

SINOPSIS

git bugreport [(-o | --output-directory) <ruta>]
                [(-s | --suffix) <formato> | --no-suffix]
                [--diagnose[=<modo>]]

DESCRIPCIÓN

Recopila información sobre la máquina del usuario, el cliente Git y el estado del repositorio, además de un formulario que solicita información sobre el comportamiento observado por el usuario, y lo almacena en un único archivo de texto que el usuario puede compartir, por ejemplo, en la lista de correo de Git, para informar de un error observado.

La siguiente información se solicita al usuario:

•Pasos para reproducir
•Comportamiento esperado
•Comportamiento real

La siguiente información se captura automáticamente:

•git version --build-options
•cadenas de sysname, release, version y machine de uname
•Cadena de información específica del compilador
•Una lista de ganchos habilitados
•$SHELL

Se puede recopilar información adicional en un archivo zip separado utilizando la opción --diagnose, y se puede adjuntar junto con el documento del informe de error para proporcionar contexto adicional a los lectores.

Esta herramienta se invoca a través del proceso de configuración típico de Git, lo que significa que en algunos casos, podría no poder iniciarse, por ejemplo, si un archivo de configuración relevante no es legible. En este tipo de escenario, puede ser útil recopilar manualmente el tipo de información que se enumera anteriormente al solicitar ayuda manualmente.

OPCIONES

-o <ruta>, --output-directory <ruta>

Coloca el archivo del informe de error resultante en <ruta> en lugar del directorio actual.

-s <formato>, --suffix <formato>, --no-suffix

Especifica un sufijo alternativo para el nombre del informe de error, para crear un archivo llamado git-bugreport-<sufijo-formateado>. Esto debería tener la forma de una cadena de formato strftime(3); se utilizará la hora local actual. --no-suffix deshabilita el sufijo y el archivo se llama simplemente git-bugreport sin ninguna medida de desambiguación.

--no-diagnose, --diagnose[=<modo>]

Crea un archivo zip de información suplementaria sobre la máquina del usuario, el cliente Git y el estado del repositorio. El archivo se escribe en el mismo directorio de salida que el informe de error y se llama git-diagnostics-<sufijo-formateado>.

Sin especificar un modo, el archivo de diagnóstico contendrá el conjunto predeterminado de estadísticas informadas por git diagnose. Se puede especificar un valor de modo opcional para cambiar qué información se incluye en el archivo. Consulte git-diagnose(1) para ver la lista de valores válidos para modo y detalles sobre su uso.
