NOMBRE

git-annex-pre-commit - ejecutado por el hook pre-commit de git

SINOPSIS

git annex pre-commit [ruta ...]

DESCRIPCIÓN

Esto está destinado a ser llamado desde el hook pre-commit de git. git annex init crea automáticamente un hook pre-commit utilizando esto.

Corrige los enlaces simbólicos que se están preparando como parte de un commit, para asegurar que apuntan al contenido anexionado.

Cuando está en una vista, actualiza los metadatos para reflejar los cambios realizados en los archivos de la vista.

OPCIONES

Se pueden usar las git-annex-common-options(1).
