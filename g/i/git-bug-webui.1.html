NOMBRE

git-bug-webui - Inicia la interfaz web

SINOPSIS

git-bug webui [flags]

DESCRIPCIÓN

Inicia la interfaz web.

Configuración de git disponible:
git-bug.webui.open [bool]: controla la apertura automática de la interfaz web en el navegador predeterminado

OPCIONES

--host="127.0.0.1" Dirección de red o nombre de host al que escuchar (por defecto 127.0.0.1)

--open[=false] Abre automáticamente la interfaz web en el navegador predeterminado

--no-open[=false] Evita la apertura automática de la interfaz web en el navegador predeterminado

-p, --port=0 Puerto al que escuchar (por defecto puerto aleatorio disponible)

--read-only[=false] Si ejecutar la interfaz web en modo de solo lectura

--log-errors[=false] Si registrar errores

-q, --query="" La consulta para abrir en la lista de errores de la interfaz web

-h, --help[=false] Ayuda para webui
