NOMBRE

git-annex-restage - Vuelve a preparar archivos desbloqueados en el índice de git

SINOPSIS

git annex restage

DESCRIPCIÓN

Dado que obtener o soltar un archivo desbloqueado modifica el archivo en el árbol de trabajo, git necesita saber que la modificación no cambia el contenido que ha registrado (el puntero del anexo). Volver a preparar el archivo logra eso.

Normalmente no necesitas ejecutar este comando, porque generalmente git-annex puede volver a preparar archivos desbloqueados por sí mismo. Hay algunas situaciones en las que git-annex necesita volver a preparar un archivo, pero el índice de git está bloqueado y, por lo tanto, no puede hacerlo. En ese caso, mostrará una advertencia sugiriéndote que ejecutes este comando.

Es seguro ejecutar este comando incluso después de haber realizado una modificación en un archivo desbloqueado.

VER TAMBIÉN
