NOMBRE

git-annex-merge - fusionar cambios de remotos

SINOPSIS

git annex merge [rama]

DESCRIPCIÓN

Cuando se ejecuta sin parámetros, realiza la misma fusión (y resolución de conflictos de fusión) que realizan los comandos git-annex pull y git-annex sync, pero sin subir ni descargar ningún dato.

Cuando se especifica una rama a fusionar, esta la fusiona en la rama actual, utilizando la misma resolución de conflictos de fusión que el comando git-annex pull. Esto es especialmente útil en una rama ajustada, ya que aplica el mismo ajuste a la rama antes de fusionarla.

Cuando annex.resolvemerge está configurado como falso, la resolución de conflictos de fusión no se realizará.

OPCIONES

--allow-unrelated-histories, --no-allow-unrelated-histories
Se pasa a git merge, para controlar si se fusionan o no historiales que no comparten un ancestro común.
--json
Habilita la salida JSON. Está pensado para ser analizado por programas que utilizan git-annex. Cada línea de salida es un objeto JSON.
--json-error-messages
Los mensajes que normalmente se enviarían a la salida de error estándar se incluyen en el JSON en su lugar.
También, se pueden usar las git-annex-common-options(1).
