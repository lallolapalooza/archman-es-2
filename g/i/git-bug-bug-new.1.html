NOMBRE

git-bug-bug-new - Crear un nuevo error

SINOPSIS

git-bug bug new [indicadores]

DESCRIPCION

Crear un nuevo error

OPCIONES

-t, --title="" Proporcionar un título para describir el problema

-m, --message="" Proporcionar un mensaje para describir el problema

-F, --file="" Tomar el mensaje del archivo dado. Usar - para leer el mensaje de la entrada estándar

--non-interactive[=false] No solicitar entrada al usuario

-h, --help[=false] ayuda para new
