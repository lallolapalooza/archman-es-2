NOMBRE

git-hook - Ejecutar hooks de git

SINOPSIS

git hook run [--ignore-missing] [--to-stdin=<ruta>] <nombre-del-hook> [-- <argumentos-del-hook>]

DESCRIPCIÓN

Una interfaz de comandos para ejecutar hooks de git (ver githooks(5)), para uso por otros comandos scriptados de git.

SUBCOMANDOS

run

Ejecuta el hook <nombre-del-hook>. Ver githooks(5) para los nombres de hooks soportados.

Cualquier argumento posicional para el hook debe ser pasado después de un obligatorio -- (o --end-of-options, ver gitcli(7)). Ver githooks(5) para los argumentos que los hooks podrían esperar (si los hubiera).

OPCIONES

--to-stdin

Para "run"; especifica un archivo que será transmitido a la entrada estándar del hook. El hook recibirá el archivo completo desde el principio hasta el final (EOF).

--ignore-missing

Ignora cualquier hook faltante devolviendo silenciosamente cero. Usado para herramientas que quieren hacer una ejecución ciega de un hook que puede o no estar presente.

VER TAMBIÉN

githooks(5)
