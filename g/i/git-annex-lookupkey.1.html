NOMBRE

git-annex-lookupkey - busca la clave utilizada para un archivo

SINOPSIS

git annex lookupkey [archivo ...]

DESCRIPCIÓN

Este comando de bajo nivel busca la clave utilizada para un archivo en el índice. La clave se envía a la salida estándar. Si no hay ninguna clave (porque el archivo no está presente en el índice o no es un archivo gestionado por git-annex), no se envía nada y el comando sale con un código distinto de cero.

OPCIONES

--ref
En lugar de buscar los archivos especificados en el índice, interprétalos como referencias de git. Por ejemplo, para encontrar la clave utilizada para algun_archivo en la etiqueta v1.0:
git annex lookupkey v1.0:algun_archivo
--batch
Habilita el modo por lotes, en el que se lee una línea que contiene el nombre del archivo desde la entrada estándar, se envía la clave a la salida estándar (con una nueva línea al final) y se repite.
Ten en cuenta que si no hay ninguna clave que corresponda al archivo, se enviará una línea vacía a la salida estándar en su lugar.
-z
Hace que la entrada de --batch esté delimitada por nulos en lugar de las nuevas líneas habituales.
También se pueden utilizar las git-annex-common-options(1).
