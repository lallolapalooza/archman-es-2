NOMBRE

git-annex-p2p - configurar enlaces peer-2-peer entre repositorios

SINOPSIS

git annex p2p [opciones]

DESCRIPCIÓN

Este comando se puede usar para enlazar repositorios git-annex a través de redes peer-2-peer.

git-annex incluye soporte integrado para usar servicios ocultos de Tor como una red P2P. (Esto requiere que Tor esté instalado.)

git-annex también puede soportar otras redes P2P, utilizando un programa auxiliar que puedes instalar. Estos programas tienen nombres de la forma git-annex-p2p-<nombredered>. Consulta https://git-annex.branchable.com/special_remotes/p2p/ para obtener más detalles.

OPCIONES

--enable <nombredered>
Habilita el uso de la red P2P con el nombre especificado.
Para redes distintas de tor, esto requiere que el programa auxiliar git-annex-p2p-<nombredered> esté instalado.
Después de ejecutar este comando, se puede ejecutar git annex remotedaemon para servir conexiones entrantes de pares, y se puede ejecutar git annex p2p --pair o git annex p2p --gen-addresses para dar a otros usuarios acceso a tu repositorio a través de la red P2P.
--pair
Ejecuta esto en dos repositorios para emparejarlos a través de la red P2P.
Esto imprimirá una frase de código, como "3-mango-elefante", y pedirá que ingreses la frase de código del otro repositorio.
Una vez intercambiadas las frases de código, los dos repositorios quedarán emparejados. Se creará un remoto de git para el otro repositorio, con un nombre como "peer1".
Esto utiliza [Magic Wormhole](https://github.com/warner/magic-wormhole) para verificar las frases de código y comunicar de forma segura las direcciones P2P de los repositorios, por lo que necesitarás tenerlo instalado en ambos ordenadores que se emparejan.
Esta característica estuvo presente en una forma rota en versiones de git-annex anteriores a la 6.20180705. Asegúrate de que una versión de git-annex lo suficientemente nueva esté instalada en ambos ordenadores que se emparejan.
--gen-addresses
Genera direcciones que se pueden usar para acceder a este repositorio git-annex a través de las redes P2P disponibles. La dirección o direcciones se muestran en la salida estándar.
Ten en cuenta que cualquiera que conozca estas direcciones puede acceder a tu repositorio a través de las redes P2P.
Esto se puede ejecutar repetidamente, para dar diferentes direcciones a diferentes personas.
--link
Configura un remoto de git al que se accede a través de una red P2P.
Esto pedirá que se ingrese una dirección; deberías pegar la dirección que fue generada por --gen-addresses en el repositorio remoto.
Por defecto, el nombre del remoto de git será "peer1", "peer2", etc. Esto se puede anular con la opción --name.
--name
Especifica un nombre a usar al configurar un remoto de git con --link o --pair.
También se pueden usar las opciones comunes de git-annex(1).
