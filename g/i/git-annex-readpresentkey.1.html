NOMBRE

git-annex-readpresentkey - leer registros de dónde está presente una clave

SINOPSIS

git annex readpresentkey clave uuid

DESCRIPCIÓN

Este comando de bajo nivel lee los registros de git-annex sobre si el contenido de la clave especificada está presente en el remoto con el uuid especificado.

Sale con 0 si se registra que la clave está presente y con 1 si no.

Tenga en cuenta que esto no realiza una comprobación activa para verificar si la clave está presente. Para realizar dicha comprobación, utilice git-annex-checkpresentkey(1)

OPCIONES

Se pueden usar las git-annex-common-options(1).
