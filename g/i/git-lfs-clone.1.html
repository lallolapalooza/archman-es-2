NOMBRE

git-lfs-clone - Clonar un repositorio LFS de forma eficiente

SINOPSIS

git lfs clone [opciones de git clone] <repositorio> [<directorio>]

DESCRIPCIÓN

Clona un repositorio Git habilitado para LFS de forma más eficiente al deshabilitar LFS durante la clonación de git, y luego realizar un 'git lfs pull' directamente después.

'git lfs clone' también instala todos los hooks a nivel de repositorio (.git/hooks) que LFS requiere para operar. Si se proporciona --separate-git-dir, los hooks se instalarán allí.

Esto es más rápido que un 'git clone' normal porque este último descargará contenido LFS utilizando el filtro smudge, que se ejecuta individualmente por archivo en la copia de trabajo. Esto es relativamente ineficiente en comparación con el modo de lotes y las descargas paralelas realizadas por 'git lfs pull'.

OPCIONES

Todas las opciones compatibles con 'git clone'

-I <rutas>, --include=<rutas>

Ver INCLUIR Y EXCLUIR.

-X <rutas>, --exclude=<rutas>

Ver INCLUIR Y EXCLUIR.

--skip-repo

Omitir la instalación de hooks a nivel de repositorio (.git/hooks) que LFS requiere. Deshabilitado por defecto.

INCLUIR Y EXCLUIR

Puede configurar Git LFS para que solo obtenga objetos que satisfagan referencias en ciertas rutas del repositorio, y/o para excluir ciertas rutas del repositorio, a fin de reducir el tiempo que dedica a descargar cosas que no utiliza.

En su configuración de Git o en un archivo .lfsconfig, puede establecer `lfs.fetchinclude` y/o `lfs.fetchexclude` a listas separadas por comas de rutas. Si se define `lfs.fetchinclude`, los objetos de Git LFS solo se obtendrán si su ruta coincide con una en esa lista, y si se define `lfs.fetchexclude`, los objetos de Git LFS solo se obtendrán si su ruta no coincide con una en esa lista. Las rutas se comparan utilizando coincidencia de comodines según gitignore(5).

Tenga en cuenta que el uso de las opciones de línea de comandos -I y -X anulan la configuración correspondiente. Establecer cualquiera de las opciones a una cadena vacía elimina el valor.

VER TAMBIÉN

git-clone(1), git-lfs-pull(1), gitignore(5).

Parte de la suite git-lfs(1).
