NOMBRE

difftool - Usa la interfaz del selector de commits parciales como una difftool compatible con Git; consulta git-difftool(1) para más información sobre las difftools de Git

SINOPSIS

difftool [-d|--dir-diff] [--read-only] [-N|--dry-run] [-b|--base] [-o|--output] [-h|--help] <IZQUIERDA> <DERECHA>

DESCRIPCIÓN

Usa la interfaz del selector de commits parciales como una difftool compatible con Git; consulta git-difftool(1) para más información sobre las difftools de Git

OPCIONES

-d, --dir-diff
En lugar de comparar dos archivos, compara dos directorios recursivamente
--read-only
Deshabilita todos los controles de edición y no escribe los contenidos del commit seleccionado en disco
-N, --dry-run
Muestra lo que se habría escrito en disco como parte de la selección del commit, pero sin escribirlo realmente
-b, --base=BASE
Renderiza la interfaz como una mergetool en lugar de una difftool y usa este archivo como la base de una diff de tres vías como parte de la resolución de conflictos de fusión
-o, --output=SALIDA
Escribe los conflictos de fusión resueltos en este archivo
-h, --help
Imprime la ayuda
<IZQUIERDA>
El archivo de la izquierda a comparar (o directorio si se pasa `--dir-diff`)
<DERECHA>
El archivo de la derecha a comparar (o directorio si se pasa `--dir-diff`)
