NOMBRE

git-lfs-ext - Ver detalles de las extensiones

SINOPSIS

git lfs ext list [<nombre>...]

DESCRIPCIÓN

Las extensiones de Git LFS permiten la manipulación de flujos de archivos durante el proceso de "smudge" y "clean".

EJEMPLOS

•Listar detalles de todas las extensiones 
$ git lfs ext
$ git lfs ext list
•Listar detalles de las extensiones especificadas 
$ git lfs ext list 'foo' 'bar'

VER TAMBIÉN

Parte de la suite git-lfs(1).
