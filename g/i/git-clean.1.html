GIT-CLEAN(1) Manual de Git GIT-CLEAN(1)

NOMBRE

git-clean - Elimina archivos no rastreados del árbol de trabajo

SINAPSIS

git clean [-d] [-f] [-i] [-n] [-q] [-e <patrón>] [-x | -X] [--] [<patrón_ruta>...]

DESCRIPCIÓN

Limpia el árbol de trabajo eliminando recursivamente los archivos que no están bajo control de versión, comenzando desde el directorio actual.

Normalmente, solo se eliminan los archivos desconocidos para Git, pero si se especifica la opción -x, también se eliminan los archivos ignorados. Esto puede ser útil, por ejemplo, para eliminar todos los productos de compilación.

Si se proporcionan argumentos opcionales de <patrón_ruta>..., solo se verán afectadas las rutas que coincidan con el patrón de ruta.

OPCIONES

-d

Normalmente, cuando no se especifica ningún <patrón_ruta>, git clean no recursará en directorios no rastreados para evitar eliminar demasiado. Especifique -d para que también recursa en dichos directorios. Si se especifica un <patrón_ruta>, -d es irrelevante; se eliminarán todos los archivos no rastreados que coincidan con las rutas especificadas (con excepciones para directorios git anidados mencionados en --force).

-f, --force

Si la variable de configuración de Git clean.requireForce no está configurada a false, git clean se negará a eliminar archivos o directorios a menos que se le proporcione -f. Git se negará a modificar repositorios git anidados no rastreados (directorios con un subdirectorio .git) a menos que se proporcione un segundo -f.

-i, --interactive

Muestra lo que se haría y limpia los archivos interactivamente. Consulte "Modo interactivo" para obtener más detalles. La variable de configuración clean.requireForce se ignora, ya que este modo proporciona su propia protección de seguridad al ser interactivo.

-n, --dry-run

No elimine nada realmente, solo muestre lo que se haría. La variable de configuración clean.requireForce se ignora, ya que de todos modos no se eliminará nada.

-q, --quiet

Sea silencioso, solo informe de errores, pero no de los archivos que se eliminan correctamente.

-e <patrón>, --exclude=<patrón>

Utilice el patrón de exclusión dado además de las reglas de ignorancia estándar (consulte gitignore(5)).

-x

No utilice las reglas de ignorancia estándar (consulte gitignore(5)), pero siga utilizando las reglas de ignorancia dadas con opciones -e de la línea de comandos. Esto permite eliminar todos los archivos no rastreados, incluidos los productos de compilación. Esto se puede utilizar (posiblemente en conjunción con git restore o git reset) para crear un árbol de trabajo prístino para probar una compilación limpia.

-X

Elimine solo los archivos ignorados por Git. Esto puede ser útil para reconstruir todo desde cero, pero manteniendo los archivos creados manualmente.

MODO INTERACTIVO

Cuando el comando entra en modo interactivo, muestra los archivos y directorios que se limpiarán, y entra en su bucle de comandos interactivo.

El bucle de comandos muestra la lista de subcomandos disponibles y muestra un indicador "What now> ". En general, cuando el indicador termina con un solo >, puede elegir solo una de las opciones dadas y presionar intro, así:

    *** Commands ***
        1: clean                2: filter by pattern    3: select by numbers
        4: ask each             5: quit                 6: help
    What now> 1

También podría decir c o clean arriba siempre que la opción sea única.

El bucle de comandos principal tiene 6 subcomandos.

clean

Comienza a limpiar archivos y directorios, y luego finaliza.

filter by pattern

Esto muestra los archivos y directorios que se eliminarán y muestra un indicador "Input ignore patterns>>". Puede ingresar patrones separados por espacios para excluir archivos y directorios de la eliminación. Por ejemplo, "*.c *.h" excluirá los archivos que terminan en ".c" y ".h" de la eliminación. Cuando esté satisfecho con el resultado filtrado, presione ENTER (vacío) para volver al menú principal.

select by numbers

Esto muestra los archivos y directorios que se eliminarán y muestra un indicador "Select items to delete>>". Cuando el indicador termina con doble >> como este, puede hacer más de una selección, concatenada con espacios en blanco o comas. También puede decir rangos. Por ejemplo, "2-5 7,9" para elegir 2,3,4,5,7,9 de la lista. Si se omite el segundo número en un rango, se seleccionan todos los elementos restantes. Por ejemplo, "7-" para elegir 7,8,9 de la lista. Puede decir * para elegir todo. También, cuando esté satisfecho con el resultado filtrado, presione ENTER (vacío) para volver al menú principal.

ask each

Esto comenzará a limpiar, y deberá confirmar uno por uno para eliminar elementos. Tenga en cuenta que esta acción no es tan eficiente como las dos acciones anteriores.

quit

Esto le permite salir sin realizar ninguna limpieza.

help

Muestra un breve uso de git-clean interactivo.

CONFIGURACIÓN

Todo lo que está debajo de esta línea en esta sección se incluye selectivamente de la documentación de git-config(1). El contenido es el mismo que se encuentra allí:

clean.requireForce

Un booleano para hacer que git-clean se niegue a eliminar archivos a menos que se proporcione -f. Por defecto es true.
