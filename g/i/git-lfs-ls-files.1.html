NOMBRE

git-lfs-ls-files - Muestra información sobre archivos Git LFS en el índice y el árbol de trabajo

SINOPSIS

git lfs ls-files [<ref>]
git lfs ls-files <ref> <ref>

DESCRIPCIÓN

Muestra las rutas de los archivos Git LFS que se encuentran en el árbol de la referencia dada. Si no se proporciona ninguna referencia, escanea la rama actualmente seleccionada. Si se dan dos referencias, se muestran los archivos LFS que se modifican entre las dos referencias; las eliminaciones no se listan.

Un asterisco (*) después del OID indica un objeto completo, un guion (-) indica un puntero LFS.

OPCIONES

-l, --long

Muestra el OID completo de 64 caracteres, en lugar de solo los primeros 10.

-s, --size

Muestra el tamaño del objeto LFS entre paréntesis al final de una línea.

-d, --debug

Muestra la mayor cantidad de información posible sobre un archivo LFS. Esto está destinado a la inspección manual; el formato exacto puede cambiar en cualquier momento.

-a, --all

Inspecciona el historial completo del repositorio, no el HEAD actual (u otra referencia proporcionada). Esto incluirá versiones anteriores de objetos LFS que ya no se encuentran en el árbol actual.

--deleted

Muestra el historial completo de la referencia dada, incluyendo los objetos que han sido eliminados.

-I <rutas>, --include=<rutas>

Incluye rutas que coinciden solo con estos patrones; véase [_fetch_settings].

-X <rutas>, --exclude=<rutas>

Excluye rutas que coinciden con alguno de estos patrones; véase [_fetch_settings].

-n, --name-only

Muestra solo los nombres de los archivos rastreados por lfs.

-j, --json

Proporciona la salida en un formato json estable para scripts.

VER TAMBIÉN

git-lfs-status(1), git-lfs-config(5).

Parte del conjunto git-lfs(1).
