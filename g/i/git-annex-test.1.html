NOMBRE

git-annex-test - ejecutar suite de pruebas incorporada

SINOPSIS

git annex test

DESCRIPCIÓN

Esto ejecuta la suite de pruebas incorporada de git-annex.

La suite de pruebas se ejecuta en el subdirectorio .t del directorio actual.

Puede ser útil ejecutar la suite de pruebas en diferentes sistemas de archivos, o para verificar su instalación local de git-annex.

OPCIONES

Hay varias opciones, proporcionadas por el framework de pruebas tasty de Haskell. Pase --help para más detalles sobre ellas.

--jobs=N -JN
Cuántas pruebas ejecutar en paralelo. El valor predeterminado es "cpus", que ejecutará un trabajo por núcleo de CPU.
--keep-failures
Cuando hay fallos en las pruebas, deja el directorio .t poblado con repositorios que demuestran los fallos, para su análisis posterior.
--test-git-config name=value
La suite de pruebas impide que git lea cualquier archivo de configuración de git. Normalmente, es una buena idea ejecutar la suite de pruebas con una configuración de git estándar. Sin embargo, esta opción puede ser útil para ver qué efecto tiene una configuración de git en la suite de pruebas.
Algunas configuraciones romperán la suite de pruebas, de maneras que se deben a un error en git-annex. Pero es posible que cambiar una configuración encuentre un error legítimo en git-annex.
Un uso válido de esto es cambiar una configuración de git a un valor que está previsto que sea el nuevo valor predeterminado en una versión futura de git.
Además, algunas cosas solo se pueden probar con una configuración de git. Por ejemplo, annex.shared-sop-command debe estar configurado para que la suite de pruebas lo pruebe usando ese comando.
--test-debug
Normalmente, la salida de los comandos ejecutados por la suite de pruebas se oculta, por lo que incluso cuando annex.debug o --debug están habilitados, no se mostrarán. Esta opción hace que la salida completa de los comandos ejecutados por la suite de pruebas se muestre. También hace que la suite de pruebas ejecute git-annex con --debug.
Es una buena idea usar -J1 en combinación con esto, de lo contrario, la salida de las pruebas concurrentes se mezclará.
