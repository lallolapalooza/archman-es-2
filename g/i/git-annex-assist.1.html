NOMBRE

git-annex-assist - añadir archivos y sincronizar cambios con remotos

SINOPSIS

git annex assist [remoto ...]

DESCRIPCIÓN

Este comando te ayuda a registrar archivos en el repositorio y a sincronizar con remotos. Es la forma más sencilla posible de usar git-annex en la línea de comandos, ya que solo es necesario ejecutar este comando de forma regular.

Este comando primero añade cualquier archivo nuevo al repositorio y confirma esos como también cualquier archivo modificado. Luego hace el equivalente de ejecutar [[git-annex-pull](1) seguido de git-annex-push(1).

Este comando opera sobre todos los archivos en todo el árbol de trabajo, incluso cuando se ejecuta en un subdirectorio. Para limitarlo a operar en archivos de un subdirectorio, usa la opción --content-of.

Para bloquear la adición de algunos archivos al repositorio, usa los archivos .gitignore.

Por defecto, todos los archivos que se añaden se añaden al annex, lo mismo que cuando ejecutas git annex add. Si configuras annex.largefiles, los archivos que no coincidan se añadirán en su lugar con git add.

OPCIONES

--message=msg -m msg
Usa esta opción para especificar un mensaje de commit.
Si se dan múltiples opciones -m, sus valores se concatenan como párrafos separados.
--content-of=ruta -C ruta
Solo añade, descarga y sube archivos en la ruta dada.
Esta opción puede repetirse varias veces con diferentes rutas.
Además, se pueden usar todas las opciones soportadas por
git-annex-pull(1) y git-annex-push(1).
Además, se pueden usar las opciones generales de
git-annex-common-options(1).
