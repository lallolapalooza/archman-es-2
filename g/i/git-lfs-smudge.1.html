NOMBRE

git-lfs-smudge - Filtro smudge de Git que convierte punteros en blobs al contenido real

SINOPSIS

git lfs smudge [<ruta>]
git lfs smudge --skip [<ruta>]

DESCRIPCIÓN

Lee un archivo puntero de Git LFS de la entrada estándar y escribe el contenido del archivo grande correspondiente en la salida estándar. Si es necesario, descarga el contenido del archivo del punto final de Git LFS. El argumento, si se proporciona, solo se utiliza para una barra de progreso.

Smudge es típicamente ejecutado por el filtro smudge de Git, configurado por los atributos de Git del repositorio.

En tu configuración de Git o en un archivo .lfsconfig, puedes establecer lfs.fetchinclude y/o lfs.fetchexclude a listas de rutas separadas por comas. Si lfs.fetchinclude está definido, los archivos puntero de Git LFS solo se reemplazarán con el contenido del archivo de objeto de Git LFS correspondiente si su ruta coincide con una en esa lista, y si lfs.fetchexclude está definido, los archivos puntero de Git LFS solo se reemplazarán con el contenido del archivo de objeto de Git LFS correspondiente si su ruta no coincide con una en esa lista. Las rutas se comparan utilizando coincidencias de comodines según gitignore(5). Los archivos puntero de Git LFS que no se reemplazan con el contenido de sus archivos de objeto correspondientes simplemente se copian a la salida estándar sin cambios.

OPCIONES

Sin opciones, git lfs smudge genera el contenido bruto de Git LFS en la salida estándar.

--skip

Omite la descarga automática de objetos en clone o pull.

GIT_LFS_SKIP_SMUDGE

Deshabilita el proceso de smudge. Para más información: git-lfs-config(5).

ERRORES CONOCIDOS

En Windows, Git antes de la versión 2.34.0 no maneja archivos en el árbol de trabajo de más de 4 gigabytes. Las versiones más recientes de Git, así como las versiones Unix, no se ven afectadas.

VER TAMBIÉN

git-lfs-install(1), gitattributes(5), gitignore(5).

Parte del conjunto de git-lfs(1).
