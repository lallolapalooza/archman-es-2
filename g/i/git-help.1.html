DESCRIPCIÓ

N

Sin opciones y sin <command> ni <doc> proporcionados, la sinopsis del comando git y una lista de los comandos de Git más comúnmente utilizados se imprimen en la salida

estándar.

Si se proporciona la opción --all o -a, todos los comandos disponibles se imprimen en la salida

estándar.

Si se proporciona la opción --guides o -g, también se imprime en la salida estándar una lista de las guías de conceptos de

Git.

Si se proporciona un comando u otra documentación, se mostrará la página de manual correspondiente. El programa man se usa por defecto para este propósito, pero esto puede ser anulado por otras opciones o variables de

configuración.

Si se proporciona un alias, git muestra la definición del alias en la salida estándar. Para obtener la página de manual del comando con alias, use git <command> --help

.

Tenga en cuenta que git --help ... es idéntico a git help ... porque el primero se convierte internamente en el

último.

Para mostrar la página man git(1), use git help git

.

Esta página se puede mostrar con git help help o git help --he

l
p.

OPCIONE

S

-a,

--all
Imprime todos los comandos disponibles en la salida
estándar.

--no-external-command

s
Cuando se usa con --all, excluye la lista de comandos externos "git-*" encontrados en el $PATH
.

--no-aliase

s
Cuando se usa con --all, excluye la lista de aliases
configurados.

--verbos

e
Cuando se usa con --all, imprime la descripción de todos los comandos reconocidos. Este es el valor por
defecto.

-c,

--config
Lista todas las variables de configuración disponibles. Este es un resumen corto de la lista en git-confi
g(1).

-g,

--guides
Imprime una lista de las guías de conceptos de Git en la salida
estándar.

--user-interface

s
Imprime una lista de la documentación de interfaces de repositorio, comandos y archivos en la salida estándar.

Las interfaces de archivos dentro del repositorio como .git/info/exclude están documentadas aquí (véase gitrepository-layout(5)), así como la configuración dentro del árbol como .mailmap (véase gitmailmap(5))

.

Esta sección de la documentación también cubre convenciones de interfaz de usuario generales o extendidas (por ejemplo gitcli(7)), y pseudo-configuración como la interfaz basada en archivos .git/hooks/* descrita en githoo

ks(
5).

--developer-interface

s
Imprime una lista de la documentación de formatos de archivo, protocolos y otras interfaces para desarrolladores en la salida
estándar.

-i,

--info
Muestra la página de manual del comando en el formato info . Para ese propósito se usará el programa
info.

-m,

--man
Muestra la página de manual del comando en el formato man . Esta opción puede usarse para anular un valor establecido en la variable de configuración help.format.

Por defecto se usará el programa man para mostrar la página de manual, pero la variable de configuración man.viewer puede usarse para elegir otros

programas de visualiza
ción (véase más abajo).

-w,

--web
Muestra la página de manual del comando en el formato web (HTML). Para ese propósito se usará un navegador web.

El navegador web puede especificarse usando la variable de configuración help.browser, o web.browser si la anterior no está definida. Si ninguna de estas variables de configuración está definida, el script auxiliar git web--browse (llamado por git help) elegirá un valor por defecto adecuado. Véase git-web--browse(1) p

ara más inf
ormación s

help.

format

Si no se pasa ninguna opción de línea de comandos, se comprobará la variable de configuración help.format . Se admiten los siguientes valores para esta variable; hacen que git help se comporte como su correspondiente opción de línea de

comandos:
•"man" corresponde a -m|--man
,
•"info" corresponde a -i|--info
,
•"web" o "html" corresponden a -w|-

help.browser, web.browser y browser.<tool>.

path

También se comprobarán help.browser, web.browser y browser.<tool>.path si se elige el formato web (ya sea por opción de línea de comandos o por variable de configuración). Véase -w|--web en la sección OPCIONES de arriba y git-web--b

man.

viewer

Se comprobará la variable de configuración man.viewer si se elige el formato man. Actualmente se admiten los siguientes

valores:
•"man": usar el programa man como es
habitual,
•"woman": usar emacsclient para iniciar el modo "woman" en emacs (esto solo funciona a partir de las versiones 22 de emacsclient)
,
•"konqueror": usar kfmclient para abrir la página man en una nueva pestaña de konqueror (véase Nota sobre konqueror más abajo)
.

Se pueden usar valores para otras herramientas si existe una entrada de configuración man.<tool>.cmd correspondiente (véase más abajo)

.

Se pueden proporcionar múltiples valores a la variable de configuración man.viewer . Sus programas correspondientes se probarán en el orden en que se listan en el archivo de

configuración.

Por ejemplo, esta

configuración: 
        [man]
                vi
ewer = konqueror
viewer = woman

intentará usar konqueror primero. Pero esto puede fallar (por ejemplo, si DISPLAY no está definido) y en ese caso se probará el modo woman de

emacs.

Si todo falla, o si no hay ningún visor configurado, se probará el visor especificado en la variable de entorno GIT_MAN_VIEWER. Si eso también falla, se probará de todos modos el progra

ma m
an.

man.<tool>.

path

Puede proporcionar explícitamente una ruta completa a su visor de man preferido estableciendo la variable de configuración man.<tool>.path. Por ejemplo, puede configurar la ruta absoluta a konqueror estableciendo man.konqueror.path. De lo contrario, git help asume que la herrami

enta está dispo
nible en PATH.

man.<tool>.

cmd

Cuando el visor de man, especificado por las variables de configuración man.viewer , no está entre los admitidos, se buscará la variable de configuración correspondiente man.<tool>.cmd . Si esta variable existe, la herramienta especificada se tratará como un comando personaliz

ado y se usará un eval de shell para ejecutar el coma
ndo con la página de man pasada como argumentos.

Nota sobre

konqueror

Cuando konqueror se especifica en la variable de configuración man.viewer , lanzamos kfmclient para intentar abrir la página man en un konqueror ya abierto en una nueva pestaña si es

posible.

Por consistencia, también intentamos este truco si man.konqueror.path está definido a algo como A_PATH_TO/konqueror. Eso significa que intentaremos lanzar A_PATH_TO/kfmclient en su

lugar.

Si realmente desea usar konqueror, entonces puede usar algo como lo

siguiente: 
        [man]
                viewer = konq
        [man "konq"]
                cmd = A_PATH_TO/konque
