NOMBRE

git-quiltimport - Aplica un conjunto de parches de quilt a la rama actual

SINOPSIS

git quiltimport [--dry-run | -n] [--author <autor>] [--patches <dir>]
                [--series <archivo>] [--keep-non-patch]

DESCRIPCIÓN

Aplica un conjunto de parches de quilt a la rama Git actual, preservando los límites de los parches, el orden de los parches y las descripciones de los parches presentes en el conjunto de parches de quilt.

Para cada parche, el código intenta extraer el autor de la descripción del parche. Si falla, recurre al autor especificado con --author. Si no se proporcionó la bandera --author, se muestra la descripción del parche y se le pide al usuario que introduzca interactivamente el autor del parche.

Si no se encuentra un asunto en la descripción del parche, se conserva el nombre del parche como el asunto de 1 línea en la descripción de Git.

OPCIONES

-n, --dry-run

Recorre los parches de la serie y advierte si no podemos encontrar toda la información necesaria para confirmar un parche. En el momento de escribir esto, solo se advierte sobre la información de autor faltante.

--author Nombre del Autor <Email del Autor>

El nombre y la dirección de correo electrónico del autor a utilizar cuando no se pueda encontrar información del autor en la descripción del parche.

--patches <dir>

El directorio donde encontrar los parches de quilt.

El valor predeterminado para el directorio de parches es patches o el valor de la variable de entorno $QUILT_PATCHES.

--series <archivo>

El archivo de series de quilt.

El valor predeterminado para el archivo de series es <patches>/series o el valor de la variable de entorno $QUILT_SERIES.

--keep-non-patch

Pasa la bandera -b a git mailinfo (ver git-mailinfo(1)).
