NOMBRE

git-sh-i18n - Código de configuración i18n de Git para scripts de shell

SINOPSIS

. "$(git --exec-path)/git-sh-i18n"

DESCRIPCIÓN

Este no es un comando que el usuario final quiera ejecutar. Jamás. Esta documentación está pensada para quienes estudian los scripts de tipo Porcelain y/o están escribiendo otros nuevos.

El scriptlet 'git sh-i18n está diseñado para ser incluido (usando .) por los programas de porcelana de Git implementados en scripts de shell. Proporciona envolturas para las funciones GNU gettext y eval_gettext accesibles a través del script gettext.sh, y proporciona opciones de reserva (fallbacks) que pasan directamente en sistemas sin GNU gettext.

FUNCIONES

gettext

Actualmente es una función dummy de paso directo implementada como una envoltura alrededor de printf(1). Será reemplazada por una implementación real de gettext en una versión posterior.

eval_gettext

Actualmente es una función dummy de paso directo implementada como una envoltura alrededor de printf(1) con variables expandidas por la utilidad git-sh-i18n--envsubst(1). Será reemplazada por una implementación real de gettext en una versión posterior.
