NOMBRE

git-annex-wanted - obtener o establecer la expresión de contenido preferido

SINOPSIS

git annex wanted repositorio [expresión]

DESCRIPCIÓN

Cuando se ejecuta con una expresión, configura el contenido que se prefiere mantener en el repositorio. Ver git-annex-preferred-content(1)

Por ejemplo:


git annex wanted aquí "incluir=*.mp3 o incluir=*.ogg"

Sin una expresión, muestra la configuración de contenido preferido actual del repositorio.

Para devolver un repositorio al comportamiento predeterminado original, utilice un valor vacío para la expresión, por ejemplo:

git annex wanted aquí ""

OPCIONES

Se pueden usar las git-annex-common-options(1).
