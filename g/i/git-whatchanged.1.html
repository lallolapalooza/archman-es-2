GIT-WHATCHANGED(1) Manual de Git GIT-WHATCHANGED(1)

NOMBRE

git-whatchanged - Muestra registros con las diferencias que introduce cada commit

SINOPSIS

git whatchanged <opción>...

ADVERTENCIA

git whatchanged ha sido obsoleto y está programado para su eliminación en una futura versión de Git, ya que es simplemente git log con valores predeterminados diferentes.

DESCRIPCIÓN

Muestra registros de commits y la salida de diferencias que introduce cada commit.

Se anima a los nuevos usuarios a usar git-log(1) en su lugar. El comando whatchanged es esencialmente el mismo que git-log(1), pero por defecto muestra la salida de diferencias en formato crudo y omite las fusiones:

git log --raw --no-merges

El comando se mantiene principalmente por razones históricas; los dedos de muchas personas que aprendieron Git mucho antes de que se inventara git log al leer la lista de correo del kernel de Linux están entrenados para escribirlo.

EJEMPLOS

git whatchanged -p v2.6.12.. include/scsi drivers/scsi

Muestra como parches los commits desde la versión v2.6.12 que cambiaron algún archivo en los subdirectorios include/scsi o drivers/scsi

git whatchanged --since="2 semanas atrás" -- gitk

Muestra los cambios durante las últimas dos semanas en el archivo gitk. El "--" es necesario para evitar confusiones con la rama llamada gitk
