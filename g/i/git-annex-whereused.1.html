NOMBRE

git-annex-whereused - encuentra qué archivos usan o usaron una clave

SINOPSIS

git annex whereused --key=nombreclave|--unused

DESCRIPCIÓN

Encuentra qué archivos usan o usaron una clave.

Para cada archivo en el árbol de trabajo que usa una clave, esto genera una línea, comenzando con la clave, luego un espacio y luego el nombre del archivo. Cuando varios archivos usan la misma clave, todos serán listados. Cuando no se encuentra nada que use la clave, no habrá salida.

Por defecto, se buscan solo archivos en el árbol de trabajo actual que usan una clave. La opción --historical hace que también se busquen versiones anteriores de los archivos.

OPCIONES

--key=nombreclave
Opera sobre esta clave.
--unused
Opera sobre las claves encontradas por la última ejecución de git-annex unused.
Normalmente, estas claves no serán utilizadas por ningún archivo en el árbol de trabajo actual, ni por ninguna etiqueta o rama. Combinar esta opción con --historical buscará usos anteriores de las claves.
--historical
Cuando ningún archivo en el árbol de trabajo actual usa una clave, esto causa que se realice un trabajo adicional, revisando versiones anteriores de la rama actual, otras ramas, etiquetas y el reflog, para encontrar dónde se usó la clave. Se detiene después de encontrar un uso de la clave y produce una revisión de git que se refiere a dónde se usó, por ejemplo, "HEAD@{40}:algúnarchivo"
