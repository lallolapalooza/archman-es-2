NOMBRE

git-lfs - Trabaja con archivos grandes en repositorios Git

SINOPSIS

git lfs <comando> [<argumentos>]

DESCRIPCIÓN

Git LFS es un sistema para gestionar y versionar archivos grandes en asociación con un repositorio Git. En lugar de almacenar los archivos grandes dentro del repositorio Git como blobs, Git LFS almacena archivos especiales de "puntero" en el repositorio, mientras almacena el contenido real del archivo en un servidor Git LFS. El contenido del archivo grande se descarga automáticamente cuando es necesario, por ejemplo, cuando se selecciona una rama Git que contiene el archivo grande.

Git LFS funciona utilizando un filtro "smudge" para buscar el contenido del archivo grande basándose en el archivo de puntero, y un filtro "clean" para crear una nueva versión del archivo de puntero cuando el contenido del archivo grande cambia. También utiliza un hook pre-push para subir el contenido del archivo grande al servidor Git LFS cada vez que un commit que contiene una nueva versión de archivo grande está a punto de ser enviado al servidor Git correspondiente.

COMANDOS

Al igual que Git, los comandos de Git LFS se separan en comandos de alto nivel ("porcelana") y comandos de bajo nivel ("plomería").

Comandos de porcelana de alto nivel

git-lfs-checkout(1)

Puebla la copia de trabajo con contenido real de los archivos Git LFS.

git-lfs-completion(1)

Genera scripts de shell para la compleción automática de comandos en la línea de comandos de Git LFS.

git-lfs-dedup(1)

Elimina duplicados de archivos Git LFS.

git-lfs-env(1)

Muestra el entorno de Git LFS.

git-lfs-ext(1)

Muestra detalles de la extensión de Git LFS.

git-lfs-fetch(1)

Descarga archivos Git LFS desde un remoto.

git-lfs-fsck(1)

Verifica la consistencia de los archivos Git LFS.

git-lfs-install(1)

Instala la configuración de Git LFS.

git-lfs-lock(1)

Establece un archivo como "bloqueado" en el servidor Git LFS.

git-lfs-locks(1)

Lista los archivos actualmente "bloqueados" del servidor Git LFS.

git-lfs-logs(1)

Muestra errores del comando Git LFS.

git-lfs-ls-files(1)

Muestra información sobre archivos Git LFS en el índice y el árbol de trabajo.

git-lfs-migrate(1)

Migra el historial hacia o desde Git LFS

git-lfs-prune(1)

Elimina archivos Git LFS antiguos del almacenamiento local

git-lfs-pull(1)

Descarga cambios de Git LFS desde el remoto y extrae los archivos necesarios del árbol de trabajo.

git-lfs-push(1)

Envía los archivos grandes en cola al punto final de Git LFS.

git-lfs-status(1)

Muestra el estado de los archivos Git LFS en el árbol de trabajo.

git-lfs-track(1)

Verifica o agrega rutas de Git LFS a los atributos de Git.

git-lfs-uninstall(1)

Desinstala Git LFS eliminando los hooks y la configuración del filtro smudge/clean.

git-lfs-unlock(1)

Elimina la configuración de "bloqueado" para un archivo en el servidor Git LFS.

git-lfs-untrack(1)

Elimina rutas de Git LFS de los atributos de Git.

git-lfs-update(1)

Actualiza los hooks de Git para el repositorio Git actual.

git-lfs-version(1)

Reporta el número de versión.

Adaptador de transferencia de Git LFS independiente para URLs de archivo (rutas locales).

EJEMPLOS

Para comenzar con Git LFS, se pueden usar los siguientes comandos.

1.Configura Git LFS en tu sistema. Solo tienes que hacer esto una vez por cuenta de usuario: 
git lfs install
2.Elige el tipo de archivos que deseas rastrear, por ejemplo, todas las imágenes ISO, con git-lfs-track(1): 
git lfs track "*.iso"
3.Lo anterior almacena esta información en archivos gitattributes(5), por lo que ese archivo debe agregarse al repositorio: 
git add .gitattributes
4.Confirma, envía y trabaja con los archivos normalmente: 
git add file.iso
git commit -m "Agregar imagen de disco"
git push
