GIT-UPLOAD-ARCHIVE(1) Manual de Git GIT-UPLOAD-ARCHIVE(1)

NOMBRE

git-upload-archive - Envía un archivo comprimido a git-archive

SINOPSIS

git upload-archive <repositorio>

DESCRIPCIÓN

Invocado por git archive --remote y envía un archivo generado al otro extremo a través del protocolo Git.

Este comando generalmente no es invocado directamente por el usuario final. La interfaz de usuario para el protocolo está en el lado de git archive, y el par de programas está destinado a ser utilizado para obtener un archivo de un repositorio remoto.

SEGURIDAD

Para proteger la privacidad de los objetos que han sido eliminados del historial pero que aún no han sido podados, git-upload-archive evita servir archivos para commits y árboles que no son alcanzables desde las referencias del repositorio. Sin embargo, dado que el cálculo de la alcanzabilidad de los objetos es computacionalmente costoso, git-upload-archive implementa un conjunto de reglas más estricto pero más fácil de verificar:

1. Los clientes pueden solicitar un commit o árbol al que apunta directamente una referencia. Por ejemplo, git archive --remote=origin v1.0.
2. Los clientes pueden solicitar un subárbol dentro de un commit o árbol usando la sintaxis ref:path. Por ejemplo, git archive --remote=origin v1.0:Documentation.
3. Los clientes no pueden usar otras expresiones sha1, incluso si el resultado final es alcanzable. Por ejemplo, ni un commit relativo como master^ ni un sha1 literal como abcd1234 están permitidos, incluso si el resultado es alcanzable desde las referencias.

Tenga en cuenta que la regla 3 prohíbe muchos casos que no tienen implicaciones de privacidad. Estas reglas están sujetas a cambios en futuras versiones de git, y el servidor al que accede git archive --remote puede o no seguir estas reglas exactas.

Si la opción de configuración uploadArchive.allowUnreachable es verdadera, estas reglas se ignoran y los clientes pueden usar expresiones sha1 arbitrarias. Esto es útil si no le importa la privacidad de los objetos no alcanzables, o si su base de datos de objetos ya está disponible públicamente para acceder a través de http no inteligente.

OPCIONES

<repositorio>

El repositorio del que obtener un archivo tar.
