git-branchless-amend(1) Manual de Comandos Generales git-branchless-amend(1)

NOMBRE

amend - Modifica el commit actual de HEAD

SINOPSIS

amend [-f|--force-rewrite] [--in-memory] [--on-disk] [--no-deduplicate-commits] [-m|--merge] [--debug-dump-rebase-constraints] [--debug-dump-rebase-plan] [--reparent] [-h|--help]

DESCRIPCIÓN

Modifica el commit actual de HEAD

OPCIONES

-f, --force-rewrite
Forzar el movimiento de commits públicos, aunque otras personas puedan tener acceso a esos commits
--in-memory
Intentar solo una operación de rebase en memoria. Si falla, no intentar un rebase en disco
--on-disk
Omitir el intento de usar un rebase en memoria e intentar directamente un rebase en disco
--no-deduplicate-commits
No intentar duplicar commits. Normalmente, un commit con el mismo contenido que otro commit que ya ha sido aplicado a la rama de destino se omite. Si se establece, esta bandera omite esa comprobación
-m, --merge
Intentar resolver conflictos de fusión, si los hay. Si ocurre un conflicto de fusión y esta opción no está establecida, la operación se aborta
--debug-dump-rebase-constraints
Opción de depuración. Imprime las restricciones utilizadas para crear el plan de rebase antes de ejecutarlo
--debug-dump-rebase-plan
Opción de depuración. Imprime el plan de rebase que se ejecutará antes de ejecutarlo
--reparent
Modificar el contenido del commit actual de HEAD, pero mantener intacto todo el contenido de los commits descendientes (es decir, "reparentarlos"). Esto puede ser útil al aplicar cambios de formato o refactorización
-h, --help
Imprimir ayuda
amend
