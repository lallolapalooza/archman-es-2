NOMBRE

git-annex-unannex - deshacer el comando add accidental

SINOPSIS

git annex unannex [ruta ...]

DESCRIPCIÓN

Utiliza esto para deshacer un comando git annex add accidental. Devuelve el archivo a su estado anterior al comando add.

Ten en cuenta que, por seguridad, el contenido del archivo permanece en el annex, hasta que utilices git annex unused y git annex dropunused.

Este no es el comando que debes usar si añadiste intencionalmente un archivo hace tiempo y ya no quieres sus contenidos. En ese caso, deberías usar git annex drop en su lugar, y también puedes eliminar el archivo con git rm.

OPCIONES

--fast
Normalmente esto realiza una copia lenta del archivo. En modo --fast, en su lugar crea un enlace físico desde el archivo al contenido del annex. Pero usa el modo --fast con precaución, ya que editar el archivo cambiará el contenido del annex.
--json
Habilita la salida JSON. Esto está destinado a ser analizado por programas que utilizan git-annex. Cada línea de salida es un objeto JSON.
--json-error-messages
Los mensajes que normalmente se emitirían al error estándar se incluyen en el JSON.
opciones de coincidencia de archivos
Las opciones de coincidencia de archivos git-annex(1) se pueden utilizar para especificar los archivos a eliminar del annex.
También se pueden usar las opciones comunes de git-annex(1).
