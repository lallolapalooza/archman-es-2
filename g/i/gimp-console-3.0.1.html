NOMBRE

gimp - un programa de manipulación y pintura de imágenes.

SINOPSIS

gimp [-h] [--help] [--help-all] [--help-gtk] [-v] [--version] [--license] [--verbose] [-n] [--new-instance] [-a] [--as-new] [-i] [--no-interface] [-d] [--no-data] [-f] [--no-fonts] [-s] [--no-splash] [--no-shm] [--no-cpu-accel] [--display display] [--session <name>] [-g] [--gimprc <gimprc>] [--system-gimprc <gimprc>] [--dump-gimprc] [--console-messages] [--debug-handlers] [--stack-trace-mode <mode>] [--pdb-compat-mode <mode>] [--batch-interpreter <procedure>] [-b] [--batch <command>] [filename] ...

DESCRIPCIÓN

GIMP es el Programa GNU de Manipulación de Imágenes. Se utiliza para editar y manipular imágenes. Puede cargar y guardar una variedad de formatos de imagen y puede usarse para convertir entre formatos.

GIMP también puede usarse como un programa de pintura. Cuenta con un conjunto de herramientas de dibujo y pintura como aerógrafo, clonar, lápiz y pincel de pintura. Las herramientas de pintura y dibujo pueden aplicarse a una imagen con una variedad de modos de pintura. También ofrece una amplia gama de herramientas de selección como rectángulo, elipse, selección difusa, selección bezier, tijeras inteligentes y selección por color.

GIMP ofrece una variedad de complementos que realizan diversas manipulaciones de imágenes. Algunos ejemplos incluyen mapa de relieve, detección de bordes, desenfoque gaussiano y muchos otros. Además, GIMP tiene varias extensiones de scripting que permiten el procesamiento y la creación avanzados de imágenes de forma no interactiva.

GIMP se distribuye con un segundo binario llamado gimp-console. Este binario es una versión solo de consola y se comporta como si gimp fuera llamado con la opción de línea de comandos --no-interface.

En plataformas con el sistema de bus de mensajes D-Bus, GIMP comprobará por defecto si ya hay una instancia en ejecución en esta sesión de usuario. Si la detecta, pasará todos los nombres de archivo dados en la línea de comandos a la instancia de GIMP ya en ejecución y se cerrará.

OPCIONES

GIMP acepta las siguientes opciones:

-h, --help
Muestra las opciones de línea de comandos de GIMP.
--help-all
Muestra todas las opciones de línea de comandos.
--help-gtk
Muestra las opciones de línea de comandos de GTK.
--help-gegl
Muestra las opciones de línea de comandos de GEGL.
-v, --version
Muestra la información de la versión y sale. Cuando se combina con la opción --verbose, también se muestra la información de la versión de las bibliotecas utilizadas por GIMP.
--license
Muestra la información de la licencia y sale.
--verbose
Ser detallado y crear información en la salida estándar.
-n, --new-instance
No intentar reutilizar una instancia de GIMP ya en ejecución. Iniciar siempre una nueva.
-a, --as-new
Abrir los nombres de archivo pasados en la línea de comandos como imágenes nuevas, no establecer el nombre de archivo en ellas.
-i, --no-interface
Ejecutar sin una interfaz de usuario.
-d, --no-data
No cargar patrones, degradados, paletas o pinceles. A menudo útil en situaciones no interactivas donde se quiere minimizar el tiempo de inicio.
-f, --no-fonts
No cargar ninguna fuente. No habrá disponible ninguna funcionalidad de texto si se usa esta opción.
--display display
Usar el display X designado.
-s, --no-splash
No mostrar la pantalla de bienvenida.
--no-shm
No usar memoria compartida entre GIMP y sus complementos. En lugar de usar memoria compartida, GIMP enviará los datos a través de un pipe. Esto resultará en un rendimiento más lento que usar memoria compartida.
--no-cpu-accel
No usar aceleraciones de CPU como MMX o SSE incluso si GIMP detecta que su CPU proporciona esta funcionalidad.
--session <name>
Usar un sessionrc diferente para esta sesión de GIMP. El nombre de sesión dado se añade al nombre de archivo sessionrc predeterminado.
-g, --gimprc <gimprc>
Usar un gimprc alternativo en lugar del predeterminado. Útil en casos donde las rutas de los complementos o las especificaciones de la máquina puedan ser diferentes.
--system-gimprc <gimprc>
Usar un archivo de configuración de sistema gimprc alternativo.
--dump-gimprc
Mostrar un archivo gimprc con la configuración predeterminada.
--debug-handlers
Habilitar los manejadores de señales de depuración.
-c, --console-messages
No mostrar cuadros de diálogo emergentes en errores o advertencias. Imprimir los mensajes en la consola en su lugar.
--stack-trace-mode {never|query|always}
Si se debe generar un rastreo de pila en caso de señales fatales.
--pdb-compat-mode {off|on|warn}
Si el PDB debe proporcionar alias para funciones obsoletas.
--batch-interpreter <procedure>
Especifica el procedimiento a usar para procesar eventos por lotes. El predeterminado es dejar que Script-Fu evalúe los comandos.
-b, --batch <command>
Ejecutar <command> de forma no interactiva. Esta opción puede aparecer varias veces. El <command> se pasa al intérprete de lotes. Cuando <command> es - los comandos se leen de la entrada estándar.

ENTORNO

GIMP respeta una serie de variables de entorno.

DISPLAY
para obtener el host y el número de display predeterminados.
GIMP3_DIRECTORY
para obtener el nombre del directorio personal de GIMP. Si no está definida, se usa $XDG_CONFIG_HOME/GIMP/3.0. Si es una ruta absoluta, se usa tal cual. Si es una ruta relativa, se considera un subdirectorio de $XDG_CONFIG_HOME.
GIMP3_DATADIR
para obtener la ubicación base para archivos de datos como pinceles y patrones. Si no está definida, se usa /usr/share/gimp/3.0.
GIMP3_LOCALEDIR
para obtener la ubicación base para las traducciones. Si no está definida, se usa /usr/share/locale.
GIMP3_PLUGINDIR
para obtener la ubicación base para complementos y módulos. Si no está definida, se usa /usr/lib/gimp/3.0.
GIMP3_SYSCONFDIR
para obtener la ubicación de los archivos de configuración. Si no está definida, se usa /etc/gimp/3.0.
GIMP3_CACHEDIR
para obtener la ubicación para archivos de caché. Si no está definida, se usa la configuración predeterminada del sistema para archivos de caché por usuario.
GIMP3_TEMPDIR
para obtener la ubicación de los archivos temporales. Si no está definida, se usa la configuración predeterminada del sistema para archivos temporales.

En Linux, GIMP puede compilarse con soporte para reubicabilidad binaria. Esto hará que los datos, complementos y archivos de configuración se busquen de forma relativa a la ubicación del archivo ejecutable de gimp, a menos que se anule con las variables de entorno mencionadas anteriormente.

Los archivos de datos de GIMP se almacenan en /usr/share/gimp/3.0, donde ${datarootdir} se establece al instalar, pero normalmente es /usr/share. Los archivos de configuración de GIMP para todo el sistema se almacenan en /etc/gimp/3.0, donde ${prefix} normalmente es /usr.

La mayor parte de la configuración de GIMP se lee desde el archivo de inicialización del usuario, $XDG_CONFIG_HOME/GIMP/3.0/gimprc. El equivalente para todo el sistema está en /etc/gimp/3.0/gimprc. El archivo para todo el sistema se analiza primero y el gimprc del usuario puede anular la configuración del sistema. /etc/gimp/3.0/gimprc_user es el gimprc predeterminado que se coloca en los directorios de inicio de los usuarios la primera vez que se ejecuta GIMP.

$XDG_CONFIG_HOME/GIMP/3.0/devicerc - contiene la configuración de los dispositivos de entrada junto con la herramienta, los colores, el pincel, el patrón y el degradado asociados a ese dispositivo.

$XDG_CONFIG_HOME/GIMP/3.0/gtkrc - conjunto de configuraciones GTK específicas de GIMP del usuario. Aquí se pueden establecer opciones como el color de los widgets y los tamaños de las fuentes.

/etc/gimp/3.0/gtkrc - conjunto predeterminado de configuraciones GTK específicas de GIMP para todo el sistema.

$XDG_CONFIG_HOME/GIMP/3.0/shortcutsrc - conjunto de combinaciones de teclas del usuario.

$XDG_CONFIG_HOME/GIMP/3.0/parasiterc - Almacena todos los parásitos persistentes de GIMP. Este archivo se reescribirá cada vez que salgas de GIMP.

$XDG_CONFIG_HOME/GIMP/3.0/sessionrc - Este archivo toma información específica de la sesión (es decir, información que deseas conservar entre dos sesiones de GIMP). No se supone que lo edites manualmente, pero por supuesto puedes hacerlo. Este archivo se reescribirá por completo cada vez que salgas de GIMP. Si este archivo no se encuentra, se usarán los valores predeterminados.

$XDG_CONFIG_HOME/GIMP/3.0/templaterc - Las plantillas de imágenes se guardan en este archivo. Se pueden crear nuevas imágenes convenientemente a partir de estas plantillas. Si este archivo no se encuentra, se usarán los valores predeterminados.

/etc/gimp/3.0/unitrc - base de datos de unidades de usuario predeterminada. Contiene las definiciones de unidades para centímetros, metros, pies, yardas, puntos tipográficos y picas tipográficas y se coloca en los directorios de inicio de los usuarios la primera vez que se ejecuta GIMP. Si este archivo no se encuentra, se usarán los valores predeterminados.

$XDG_CONFIG_HOME/GIMP/3.0/unitrc - Este archivo contiene tu base de datos de unidades de usuario. Puedes modificar esta lista con el editor de unidades. No se supone que lo edites manualmente, pero por supuesto puedes hacerlo. Este archivo se reescribirá por completo cada vez que salgas de GIMP.

$XDG_CONFIG_HOME/GIMP/3.0/plug-ins - ubicación de los complementos instalados por el usuario.

$XDG_CONFIG_HOME/GIMP/3.0/pluginrc - los valores de inicialización de los complementos se almacenan aquí. Este archivo se analiza al inicio y se regenera si es necesario.

$XDG_CONFIG_HOME/GIMP/3.0/modules - ubicación de los módulos instalados por el usuario.

$XDG_CONFIG_HOME/GIMP/3.0/tmp - ubicación predeterminada que GIMP usa como espacio temporal.

/usr/share/gimp/3.0/brushes - archivos de pinceles para todo el sistema.

$XDG_CONFIG_HOME/GIMP/3.0/brushes - archivos de pinceles creados e instalados por el usuario. Estos archivos están en los formatos de archivo .gbr, .gih o .vbr.

$XDG_CONFIG_HOME/GIMP/3.0/curves - Perfiles y ajustes preestablecidos de curvas guardados desde la herramienta Curvas.

$XDG_CONFIG_HOME/GIMP/3.0/gimpressionist - Aquí se almacenan los ajustes preestablecidos y los pinceles y papeles creados por el usuario.

$XDG_CONFIG_HOME/GIMP/3.0/levels - Perfiles y ajustes preestablecidos de niveles guardados desde la herramienta Niveles.

/usr/share/gimp/3.0/palettes - los archivos de paletas para todo el sistema.

$XDG_CONFIG_HOME/GIMP/3.0/palettes - archivos de paletas creados y modificados por el usuario. Estos archivos están en el formato .gpl.

/usr/share/gimp/3.0/patterns - conjunto básico de patrones para usar en GIMP.

$XDG_CONFIG_HOME/GIMP/3.0/patterns - archivos de patrones de GIMP creados e instalados por el usuario. Estos archivos están en el formato .pat.

/usr/share/gimp/3.0/gradients - conjunto estándar de archivos de degradados para todo el sistema.

$XDG_CONFIG_HOME/GIMP/3.0/gradients - archivos de degradados creados e instalados por el usuario.

/usr/share/gimp/3.0/scripts - directorio de scripts para todo el sistema utilizados en Script-Fu y otras extensiones de scripting.

$XDG_CONFIG_HOME/GIMP/3.0/scripts - scripts creados e instalados por el usuario.

/usr/share/gimp/3.0/gflares - directorio para todo el sistema utilizado por el complemento gflare.

$XDG_CONFIG_HOME/GIMP/3.0/gflares - archivos gflare creados e instalados por el usuario.

/usr/share/gimp/3.0/gfig - directorio para todo el sistema utilizado por el complemento gfig.

$XDG_CONFIG_HOME/GIMP/3.0/gfig - archivos gfig creados e instalados por el usuario.

/usr/share/gimp/3.0/images/gimp-splash.png - la imagen predeterminada usada para la pantalla de bienvenida de GIMP.

/usr/share/gimp/3.0/images/gimp-logo.png - imagen usada en el diálogo Acerca de de GIMP.

/usr/share/gimp/3.0/tips/gimp-tips.xml - consejos tal como se muestran en el cuadro de diálogo "Consejo del día".

IMÁGENES DE BIENVENIDA

GIMP viene con una imagen predeterminada para la pantalla de bienvenida, pero permite a los administradores del sistema y a los usuarios personalizar la pantalla de bienvenida proporcionando otras imágenes. La imagen que se usará con la pantalla de bienvenida se elige de la siguiente manera:

1.
GIMP intenta cargar una pantalla de bienvenida aleatoria desde el directorio $XDG_CONFIG_HOME/GIMP/3.0/splashes.
2.
Luego, recurre a usar $XDG_CONFIG_HOME/GIMP/3.0/gimp-splash.png.
3.
Si el usuario no instaló ninguna imagen de bienvenida personalizada, se elige una imagen aleatoria de /usr/share/gimp/3.0/splashes.
4.
Como último recurso, GIMP usa la imagen de bienvenida predeterminada ubicada en /usr/share/gimp/3.0/images/gimp-splash.png.

SUGERENCIAS Y INFORMES DE ERRORES

Cualquier error que se encuentre debe informarse al sistema de seguimiento de errores en línea disponible en la web en https://gitlab.gnome.org/GNOME/gimp/issues. Antes de informar errores, por favor, comprueba si el error ya ha sido informado.

Al informar errores de GIMP, es importante incluir una forma fiable de reproducir el error, el número de versión de GIMP (y probablemente de GTK), el nombre y la versión del sistema operativo y cualquier especificación de hardware relevante. Si un error está causando un fallo, es muy útil si se puede proporcionar un seguimiento de la pila. Y por supuesto, los parches para corregir el error son aún mejores.

OTRA INFORMACIÓN

El lugar canónico para encontrar información sobre GIMP es en https://www.gimp.org/. Aquí puedes encontrar enlaces a muchos otros sitios de GIMP, tutoriales, conjuntos de datos, archivos de listas de correo y más.

También hay un Manual de Usuario de GIMP disponible en https://docs.gimp.org/ que entra en mucho más detalle sobre el uso interactivo de GIMP.

Las últimas versiones de GIMP y las bibliotecas GTK siempre están disponibles en https://download.gimp.org/.
