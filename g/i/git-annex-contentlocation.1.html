NOMBRE

git-annex-contentlocation - busca el contenido de una clave

SINOPSIS

git annex contentlocation [clave ...]

DESCRIPCIÓN

Este comando de bajo nivel busca el nombre de archivo utilizado para almacenar el contenido de una clave. El nombre de archivo se imprime en salida estándar. Si el contenido de la clave no está presente en el repositorio local, no se imprime nada y el comando sale con un valor distinto de cero.

OPCIONES

--batch
Habilita el modo por lotes, en el que se lee una línea que contiene la clave desde la entrada estándar, se imprime el nombre del archivo de su contenido en la salida estándar (con un salto de línea al final) y se repite.
Ten en cuenta que si el contenido de una clave no está presente, se imprime una línea vacía en la salida estándar en su lugar.
También se pueden usar las opciones comunes de git-annex(1).
