NOMBRE

git-get-tar-commit-id - Extraer el ID de commit de un archivo creado con git-archive

SINOPSIS

git get-tar-commit-id

DESCRIPCIÓN

Lee un archivo tar creado por git archive desde la entrada estándar y extrae el ID de commit almacenado en él. Lee solo los primeros 1024 bytes de entrada, por lo tanto, su tiempo de ejecución no se ve muy influenciado por el tamaño del archivo tar.

Si no se encuentra ningún ID de commit, git get-tar-commit-id sale silenciosamente con un código de retorno de 1. Esto puede ocurrir si el archivo no se creó usando git archive o si el primer parámetro de git archive había sido un ID de árbol en lugar de un ID de commit o una etiqueta.
