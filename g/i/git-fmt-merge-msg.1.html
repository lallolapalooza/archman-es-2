NOMBRE

git-fmt-merge-msg - Produce un mensaje de commit de fusión

SINOPSIS

git fmt-merge-msg [-m <mensaje>] [--into-name <rama>] [--log[=<n>] | --no-log]
git fmt-merge-msg [-m <mensaje>] [--log[=<n>] | --no-log] -F <archivo>

DESCRIPCIÓN

Toma la lista de objetos fusionados en la entrada estándar y produce un mensaje de commit adecuado para la fusión, normalmente para ser pasado como argumento de <mensaje-de-fusión> de git merge.

Este comando está destinado principalmente a un uso interno por scripts que invocan automáticamente git merge.

OPCIONES

--log[=<n>]

Además de los nombres de las ramas, rellena el mensaje de registro con descripciones de una línea de los commits reales que se están fusionando. Se utilizarán como máximo <n> commits de cada padre de fusión (20 si se omite <n>). Esto anula la variable de configuración merge.log.

--no-log

No lista descripciones de una línea de los commits reales que se están fusionando.

--summary, --no-summary

Sinónimos de --log y --no-log; estos están obsoletos y se eliminarán en el futuro.

-m <mensaje>, --message <mensaje>

Usa <mensaje> en lugar de los nombres de las ramas para la primera línea del mensaje de registro. Para usar con --log.

--into-name <rama>

Prepara el mensaje de fusión como si se estuviera fusionando a la rama <rama>, en lugar del nombre de la rama real a la que se realiza la fusión.

-F <archivo>, --file <archivo>

Toma la lista de objetos fusionados de <archivo> en lugar de la entrada estándar.

CONFIGURACIÓN

merge.branchdesc

Además de los nombres de las ramas, rellena el mensaje de registro con el texto de descripción de la rama asociado a ellas. Por defecto es falso.

merge.log

Además de los nombres de las ramas, rellena el mensaje de registro con un máximo del número especificado de descripciones de una línea de los commits reales que se están fusionando. Por defecto es falso, y true es un sinónimo de 20.

merge.suppressDest

Al añadir un patrón global que coincida con los nombres de las ramas de integración a esta variable de configuración multivalor, el mensaje de fusión predeterminado calculado para las fusiones en estas ramas de integración omitirá "into <nombre-rama>" de su título.

Se puede usar un elemento con un valor vacío para borrar la lista de patrones globales acumulados de entradas de configuración anteriores. Cuando no hay ninguna variable merge.suppressDest definida, se utiliza el valor predeterminado de master para compatibilidad con versiones anteriores.

merge.summary

Sinónimo de merge.log; esto está obsoleto y se eliminará en el futuro.

EJEMPLOS

$ git fetch origin master
$ git fmt-merge-msg --log <$GIT_DIR/FETCH_HEAD

Imprime un mensaje de registro que describe una fusión de la rama "master" del remoto "origin".
