git-cliff(1) Manual de Comandos Generales git-cliff(1)

NOMBRE

git-cliff - Un generador de changelog altamente personalizable ⛰️

SINOPSIS

git-cliff [-h|--help] [-V|--version] [-v|--verbose]... [-i|--init] [-c|--config] [--config-url] [-w|--workdir] [-r|--repository] [--include-path] [--exclude-path] [--tag-pattern] [--with-commit] [--with-tag-message] [--ignore-tags] [--count-tags] [--skip-commit] [-p|--prepend] [-o|--output] [-t|--tag] [--bump] [--bumped-version] [-b|--body] [-l|--latest] [--current] [-u|--unreleased] [--topo-order] [--use-branch-tags] [--no-exec] [-x|--context] [--from-context] [-s|--strip] [--sort] [--github-token] [--github-repo] [--gitlab-token] [--gitlab-repo] [--gitea-token] [--gitea-repo] [--bitbucket-token] [--bitbucket-repo] [--use-native-tls] [RANGO]

DESCRIPCIÓN

Un generador de changelog altamente personalizable ⛰️

FLAGS

-h, --help
Imprime información de ayuda
-V, --version
Imprime información de la versión
-v, --verbose
Incrementa la verbosidad del registro
--bumped-version
Imprime la versión incrementada para los cambios no publicados
-l, --latest
Procesa los commits a partir de la última etiqueta
--current
Procesa los commits que pertenecen a la etiqueta actual
-u, --unreleased
Procesa los commits que no pertenecen a una etiqueta
--topo-order
Ordena las etiquetas topológicamente
--use-branch-tags
Incluye solo las etiquetas que pertenecen a la rama actual
--no-exec
Deshabilita la ejecución de comandos externos
-x, --context
Imprime el contexto del changelog como JSON
--use-native-tls
Carga certificados TLS desde el almacén de certificados nativo

OPCIONES

-i, --init [<CONFIG>]
Escribe el archivo de configuración predeterminado en cliff.toml
-c, --config <RUTA> [predeterminado: cliff.toml]
Establece el archivo de configuración
También puede especificarse con la variable de entorno GIT_CLIFF_CONFIG.
--config-url <URL>
Establece la URL para el archivo de configuración
También puede especificarse con la variable de entorno GIT_CLIFF_CONFIG_URL.
-w, --workdir <RUTA>
Establece el directorio de trabajo
También puede especificarse con la variable de entorno GIT_CLIFF_WORKDIR.
-r, --repository <RUTA>...
Establece el repositorio git
También puede especificarse con la variable de entorno GIT_CLIFF_REPOSITORY.
--include-path <PATRÓN>...
Establece la ruta para los commits relacionados a incluir
También puede especificarse con la variable de entorno GIT_CLIFF_INCLUDE_PATH.
--exclude-path <PATRÓN>...
Establece la ruta para los commits relacionados a excluir
También puede especificarse con la variable de entorno GIT_CLIFF_EXCLUDE_PATH.
--tag-pattern <PATRÓN>
Establece la expresión regular para coincidir con las etiquetas git
También puede especificarse con la variable de entorno GIT_CLIFF_TAG_PATTERN.
--with-commit <MENSAJE>...
Establece mensajes de commit personalizados para incluir en el changelog
También puede especificarse con la variable de entorno GIT_CLIFF_WITH_COMMIT.
--with-tag-message [<MENSAJE>]
Establece un mensaje personalizado para la última versión
También puede especificarse con la variable de entorno GIT_CLIFF_WITH_TAG_MESSAGE.
--ignore-tags <PATRÓN>
Establece las etiquetas a ignorar en el changelog
También puede especificarse con la variable de entorno GIT_CLIFF_IGNORE_TAGS.
--count-tags <PATRÓN>
Establece las etiquetas a contar en el changelog
También puede especificarse con la variable de entorno GIT_CLIFF_COUNT_TAGS.
--skip-commit <SHA1>...
Establece los commits que se omitirán en el changelog
También puede especificarse con la variable de entorno GIT_CLIFF_SKIP_COMMIT.
-p, --prepend <RUTA>
Añade entradas al principio del archivo de changelog dado
También puede especificarse con la variable de entorno GIT_CLIFF_PREPEND.
-o, --output [<RUTA>]
Escribe la salida en el archivo dado
También puede especificarse con la variable de entorno GIT_CLIFF_OUTPUT.
-t, --tag <ETIQUETA>
Establece la etiqueta para la última versión
También puede especificarse con la variable de entorno GIT_CLIFF_TAG.
--bump [<INCREMENTO>]
Incrementa la versión para los cambios no publicados. Opcionalmente con la versión especificada
-b, --body <PLANTILLA>
Establece la plantilla para el cuerpo del changelog
También puede especificarse con la variable de entorno GIT_CLIFF_TEMPLATE.
--from-context <RUTA>
Genera el changelog desde un contexto JSON
También puede especificarse con la variable de entorno GIT_CLIFF_CONTEXT.
-s, --strip <PARTE>
Elimina las partes dadas del changelog

[posibles valores: header, footer, all]

--sort <ORDEN> [predeterminado: oldest]
Establece el orden de los commits dentro de las secciones

[posibles valores: oldest, newest]

--github-token <TOKEN>
Establece el token de la API de GitHub
También puede especificarse con la variable de entorno GITHUB_TOKEN.
--github-repo <PROPIETARIO/REPO>
Establece el repositorio de GitHub
También puede especificarse con la variable de entorno GITHUB_REPOSITORY.
--gitlab-token <TOKEN>
Establece el token de la API de GitLab
También puede especificarse con la variable de entorno GITLAB_TOKEN.
--gitlab-repo <PROPIETARIO/REPO>
Establece el repositorio de GitLab
También puede especificarse con la variable de entorno GITLAB_REPOSITORY.
--gitea-token <TOKEN>
Establece el token de la API de Gitea
También puede especificarse con la variable de entorno GITEA_TOKEN.
--gitea-repo <PROPIETARIO/REPO>
Establece el repositorio de Gitea
También puede especificarse con la variable de entorno GITEA_REPOSITORY.
--bitbucket-token <TOKEN>
Establece el token de la API de Bitbucket
También puede especificarse con la variable de entorno BITBUCKET_TOKEN.
--bitbucket-repo <PROPIETARIO/REPO>
Establece el repositorio de Bitbucket
También puede especificarse con la variable de entorno BITBUCKET_REPOSITORY.

RANGO

El rango de commits se puede especificar en el siguiente formato:

<TAG_DESDE>..<TAG_HASTA>

Por defecto, el rango será:

<ÚLTIMA_ETIQUETA>..HEAD

Esto se puede modificar con las siguientes opciones:

--latest-tag-only
Procesa solo commits desde la última etiqueta.
--current-tag-only
Procesa solo commits desde la etiqueta actual.
--unreleased-only
Procesa solo commits no etiquetados.
--range <TAG_DESDE>..<TAG_HASTA>
Especifica explícitamente un rango de etiquetas.

EJEMPLOS

Generar changelog para la última versión:

git-cliff --latest

Generar changelog para todos los commits no publicados:

git-cliff --unreleased

Generar changelog para el rango de etiquetas v1.0.0..v1.1.0:

git-cliff --range v1.0.0..v1.1.0

Generar changelog para la rama actual, excluyendo la rama main:

git-cliff --use-branch-tags --ignore-tags main

Escribir el archivo de configuración predeterminado:

git-cliff --init

Escribir changelog en un archivo de salida específico:

git-cliff -o CHANGELOG.md

Generar changelog solo con commits de la ruta `src/`:

git-cliff --include-path src/
