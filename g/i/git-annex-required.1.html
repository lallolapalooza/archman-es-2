NOMBRE

git-annex-required - obtener o establecer la expresión de contenido requerido

SINOPSIS

git annex required repositorio [expresión]

DESCRIPCIÓN

Cuando se ejecuta con una expresión, configura el contenido que se requiere que se mantenga en el repositorio.

Sin una expresión, muestra la configuración actual del contenido requerido del repositorio.

Mientras que git-annex-wanted(1) es solo una preferencia, esto designa el contenido que realmente no debería eliminarse. Por ejemplo, un archivo que es querido puede eliminarse con git annex drop, pero si ese archivo es requerido, debería eliminarse con git annex drop --force.

Además, git-annex fsck advertirá sobre contenidos requeridos que no están presentes.

Por ejemplo:


git annex required here "include=*.mp3 or include=*.ogg"

Para devolver un repositorio al comportamiento predeterminado original, use un valor vacío para la expresión, por ejemplo:

git annex required here ""

OPCIONES

Las git-annex-common-options(1) pueden ser utilizadas.

NOTAS

El comando required se añadió en git-annex 5.20150420.
