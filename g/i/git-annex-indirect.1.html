NOMBRE

git-annex-indirect - cambiar el repositorio a modo indirecto (obsoleto)

SINOPSIS

git annex indirect

DESCRIPCIÓN

Este comando se utilizaba para cambiar un repositorio del modo directo al modo indirecto.

Ahora, git-annex convierte automáticamente los repositorios en modo directo a v7 con ramas desbloqueadas ajustadas, por lo que este comando no hace nada.
