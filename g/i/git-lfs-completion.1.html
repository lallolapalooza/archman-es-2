DESCRIPCIÓN
Genera un script que, al ejecutarse en una sesión del shell indicado, implementará el autocompletado de tabulación de los comandos de Git LFS en la línea

de
comandos.

Cada shell requiere un conjunto diferente de comandos para cargar el script de autocompletado, ya sea para una sesión individual o automáticamente cada vez que se inicia una nueva sesión. Consulte la sección EJEMPLOS para

obtener más detalles.

El script para cada shell proporciona el autocompletado de tabulación de los nombres de comandos y banderas de Git LFS, pero no ofrece autocompletado de términos de Git como los nombres de remotos, ramas o etiquetas de Git. (Esto puede cambiar en una versión futura de Git LFS.

)

De forma predeterminada, el script de cada shell admite el autocompletado de comandos de Git LFS cuando se presiona la tecla de tabulación después del nombre del

programa

git-lfs. Por

ejemplo,

git-lfs [Tab] listará los comandos de Git LFS disponibles como fetch, migrate y pull, y git-lfs pull --[Tab] listará las banderas posibles para el comando git-lfs-pull(1). Sin embargo, la mayoría de los usuarios estarán acostumbrados a usar Git LFS como un programa invocado por Git, por ejemplo, git lfs checkout

o

git lfs pull. Para habilitar el autocompletado de tabulación de los comandos de Git LFS en este caso, el autocompletado de tabulación de los comandos normales de Git también debe estar activo. Asumiendo que esto es cierto, los scripts generados por el comando git lfs completion deberían admitir el autocompletado de los comandos de Git LFS cuando se presiona la tecla de tabulación después de git lfs, como git lfs [Tab] para listar todos los comandos de Git LFS disponibles o git lfs pull --[Tab] para listar las banderas posibles de ese comando. Consulte la sección SHELLS para obtener detalles sobre el autocompletado de tabulación de Git en los shells admitidos. Como es común en el autocompletado de tabulación de shell, se debe introducir un espacio después de los nombres de comando git-lfs

o

git lfs antes de que la tecla de tabulación haga que se ejecute el script de autocompletado de Git LFS. Sin el carácter de espacio, cualquier autocompletado de tabulación de shell activo buscará en su lugar programas cuyos nombres tengan un prefijo coincidente. Los scripts de autocompletado utilizan comandos "ocultos" de Git LFS para solicitar resultados de autocompletado del cliente Git LFS, específicamente los comandos git lfs __complete

y

git lfs __completeNoDesc. Estos comandos pueden eliminarse en el futuro, o su acción puede alterarse sin aviso, por lo que los usuarios no deben llamarlos directamente ni considerarlos parte de la interfaz de línea de comandos de Git LFS documentada oficialmente. SHELLS E

l

comando git lfs completion admite tres shells de Unix: GNU Bash (Bourne Again SHell), fish y Zsh (Z shell). El autocompletado de tabulación se configura de manera diferente en cada uno, tanto en general como específicamente para Git

y, por lo tanto, también para Git LFS.

En Windows, los usuarios que tienen Git LFS instalado como parte del proyecto Git for Windows tienen acceso a una emulación del shell Bash que se incluye con Git for Windows. •Bash

https://git-scm.com/book/en/v2/Appendix-A%3A-Git-in-Other-Environments-Git-in-Bash

(Sin embargo, no es requerido por el script de autocompletado de Git para Bash.

Asumiendo que el paquete bash-completion está instalado, para cargar el script de autocompletado de Git en todas las sesiones futuras iniciadas por el usuario actual (pero no por todos los usuarios), coloque

•fish:

El shell fish proporciona su propia implementación del autocompletado de tabulación de comandos de Git, definida en un archivo git.fish que probablemente esté presente de forma predeterminada en la lista de ubicaciones que el shell busca para los scripts de

autocompletado.

El script devuelto por el comando git lfs completion fish debería ser compatible con esta implementación y permitir el autocompletado de tabulación de los comandos de Git LFS introducidos usando cualquiera de los formatos de comando git lfs o git-

lf
s.
•Zsh:

Para habilitar el autocompletado de tabulación en Zsh para cualquier comando, la función compinit debe cargarse primero con un comando similar al

siguiente: 
% autoload -
Uz compinit
&& compinit

Esto puede hacerse individualmente para cada sesión, o agregarse a un archivo de inicio como ~/.zshrc o /etc/zshrc para que se aplique a todas las sesiones futuras, ya sea para el usuario actual o para todos los

usuarios.

Zsh lee las funciones de autocompletado de las ubicaciones especificadas en la variable de entorno FPATH, con los rutas listadas primero teniendo prioridad. Esta lista también está disponible como una matriz en la variable fpath; el shell sincroniza automáticamente FPATH y fpath

.

El shell Z proporciona su propia implementación del autocompletado de tabulación de comandos de Git, definida en un archivo _git que probablemente esté presente en una de las ubicaciones especificadas en fpath

.

El script devuelto por el comando git lfs completion zsh debería ser compatible con esta implementación y permitir el autocompletado de tabulación de los comandos de Git LFS introducidos usando cualquiera de los formatos de comando git lfs o git-lfs

.

El proyecto Git también ofrece scripts de autocompletado para Zsh, en la forma del mismo script git-completion.bash utilizado para el shell Bash, más un script git-completion.zsh que está destinado a ser renombrado a _git y colocado en una ubicación listada en fpath. Estos scripts no son compatibles con el devuelto por el lass="Li">git lfs completion comando de zsh, y si se usan en conjunto con ese script, el autocompletado con tabulación de los comandos de Git LFS no funcionará correctamente cuando se inicie utilizando el formato de comando git

lfs.

En macOS, si Git se instaló usando Homebrew, los scripts de autocompletado de Zsh del proyecto Git pueden instalarse en una ubicación donde tengan prioridad sobre la implementación proporcionada por Zsh. En este caso, para hacer uso completo del script devuelto por git lfs completion zsh, el archivo de script _git completion instalado por Homebrew para Git debe moverse o eliminarse para que no preceda al script de autocompletado de Git de la propia Z shell en el orden de rutas especificado por fp

at

Como se mencionó en la sección SHELLS, el paquete bash-completion es requerido por los scripts de autocompletado de Git LFS para Bash, y también proporciona utilidades convenientes que buscan scripts de autocompletado en un conjunto de ubicaciones definidas y los ejecutan durante el inicio de la
