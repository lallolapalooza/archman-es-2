GIT-MERGETOOL--LIB(1) Manual de Git GIT-MERGETOOL--LIB(1)

NOMBRE

git-mergetool--lib - Scripts comunes para la herramienta de fusión de Git

SINOPSIS

TOOL_MODE=(diff|merge) . "$(git --exec-path)/git-mergetool--lib"

DESCRIPCIÓN

Este no es un comando que el usuario final querría ejecutar. Jamás. Esta documentación está destinada a personas que estén estudiando los scripts "Porcelain-ish" y/o estén escribiendo otros nuevos.

El scriptlet git-mergetool--lib está diseñado para ser incluido (usando .) por otros scripts de shell para configurar funciones para trabajar con herramientas de fusión de Git.

Antes de incluir git-mergetool--lib, tu script debe establecer TOOL_MODE para definir el modo de operación para las funciones listadas a continuación. diff y merge son valores válidos.

FUNCIONES

get_merge_tool

Devuelve una herramienta de fusión. El código de retorno es 1 si devolvió una herramienta de fusión adivinada, de lo contrario es 0. $GIT_MERGETOOL_GUI puede ser establecido a true para buscar la herramienta gráfica apropiada.

get_merge_tool_cmd

Devuelve el comando personalizado para una herramienta de fusión.

get_merge_tool_path

Devuelve la ruta personalizada para una herramienta de fusión.

initialize_merge_tool

Trae funciones específicas de la herramienta de fusión al ámbito para que puedan ser utilizadas o anuladas.

run_merge_tool

Inicia una herramienta de fusión dada la herramienta y una bandera verdadero/falso para indicar si está presente una base de fusión. $MERGED, $LOCAL, $REMOTE y $BASE deben estar definidos para su uso por la herramienta de fusión.
