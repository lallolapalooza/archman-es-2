NOMBRE

git-annex-examinekey - imprime información de una clave

SINOPSIS

git annex examinekey [clave ...]

DESCRIPCIÓN

Este comando de bajo nivel recibe una clave y imprime información que se puede determinar puramente observando la clave.

OPCIONES

--format=valor
Utiliza un formato de salida personalizado.
El valor es una cadena de formato, en la que '${var}' se expande al valor de una variable. Para justificar a la derecha una variable con espacios, usa '${var;ancho}'; para justificar a la izquierda una variable, usa '${var;-ancho}'; para escapar caracteres inusuales (incluidos caracteres de control) en una variable, usa '${var_escapada}'
Para generar una ruta desde la parte superior del repositorio hasta el objeto git-annex para una clave, usa ${rutadelobjeto}. Para generar el valor de un archivo de puntero git-annex para una clave, usa ${punterodelobjeto}.
Estas variables también están disponibles para su uso en formatos: ${clave}, ${backend}, ${bytesize}, ${humansize}, ${nombredelclave}, ${hashdirlower}, ${hashdirmixed}, ${mtime} (para el campo mtime de una clave WORM), ${archivo} (cuando se proporciona un nombre de archivo a examinekey).
Además, '\n' es una nueva línea, '\000' es un NULL, etc.
El formato de salida predeterminado es el mismo que --format='${clave_escapada}\n', excepto cuando se muestra en una terminal, los caracteres de control se escaparán.
--json
Habilita la salida JSON. Está diseñado para ser analizado por programas que utilizan git-annex. Cada línea de salida es un objeto JSON.
--json-error-messages
Los mensajes que normalmente se enviarían a la salida estándar de error se incluyen en el JSON en su lugar.
--migrate-to-backend=backend
Intenta migrar la clave de entrada al nuevo backend especificado. Si tiene éxito, imprime información sobre la clave migrada. De lo contrario, imprime información sobre la clave de entrada.
Esto solo realiza migraciones rápidas; no volverá a hashear el contenido de una clave ni realizará operaciones costosas similares.
Una forma de usarlo es agregar una extensión a una clave.

git annex examinekey SHA256--xxx --migrate-to-backend=SHA256E --filename=foo.tar.gz
O para eliminar la extensión de una clave:

git annex examinekey SHA256E--xxx.tar.gz --migrate-to-backend=SHA256
--filename=nombre
El nombre de un archivo asociado con la clave, por ejemplo, un archivo del árbol de trabajo. No es necesario que exista. Esto es necesario al usar --migrate-to-backend para agregar una extensión a la clave.
--batch
Habilita el modo batch, en el que se lee una línea que contiene una clave de stdin, se imprime la información sobre ella en stdout, y se repite.
Para proporcionar también el nombre de un archivo asociado con la clave, la línea puede tener el formato "$clave $archivo"
También se pueden utilizar las opciones comunes de git-annex (git-annex-common-options(1).
