GIT-PRUNE(1) Manual de Git GIT-PRUNE(1)

NOMBRE

git-prune - Elimina todos los objetos inalcanzables de la base de datos de objetos

SINOPSIS

git prune [-n] [-v] [--progress] [--expire <tiempo>] [--] [<cabeza>...]

DESCRIPCIÓN


Nota

En la mayoría de los casos, los usuarios deben ejecutar git gc, que llama a git prune. Consulte la sección "NOTAS", más abajo.

Esto ejecuta git fsck --unreachable utilizando todas las referencias disponibles en refs/, opcionalmente con un conjunto adicional de objetos especificados en la línea de comandos, y elimina de la base de datos de objetos todos los objetos desempaquetados que son inalcanzables desde cualquiera de estos objetos de cabeza. Además, elimina los objetos desempaquetados que también se encuentran en los paquetes ejecutando git prune-packed. También elimina entradas de .git/shallow que no son alcanzables por ninguna referencia.

Tenga en cuenta que los objetos empaquetados inalcanzables permanecerán. Si esto no es deseado, consulte git-repack(1).

OPCIONES

-n, --dry-run

No elimine nada; solo informe lo que eliminaría.

-v, --verbose

Informe todos los objetos eliminados.

--progress

Muestre el progreso.

--expire <tiempo>

Solo expire objetos sueltos más antiguos que <tiempo>.

--

No interprete más argumentos como opciones.

<cabeza>...

Además de los objetos alcanzables desde cualquiera de nuestras referencias, mantenga los objetos alcanzables desde las <cabezas> listadas.

EJEMPLOS

Para eliminar objetos no utilizados por su repositorio o por otro que toma prestado de su repositorio a través de su .git/objects/info/alternates:

$ git prune $(cd ../otro && git rev-parse --all)

NOTAS

En la mayoría de los casos, los usuarios no necesitarán llamar a git prune directamente, sino que deberían llamar a git gc, que se encarga de la poda junto con muchas otras tareas de mantenimiento.

Para una descripción de qué objetos se consideran para la poda, consulte la opción --unreachable de git fsck.

VER TAMBIÉN

git-fsck(1), git-gc(1), git-reflog(1)
