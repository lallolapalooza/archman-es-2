NOMBRE

git-annex-log - muestra información del registro de ubicaciones

SINOPSIS

git annex log [ruta ...]

DESCRIPCIÓN

Este comando muestra información del historial de la rama git-annex.

Varias cosas pueden impedir que esa información esté disponible para su visualización. Cuando se usa git-annex-forget, se borran datos históricos antiguos de la rama. Cuando annex.private o remote.name.annex-private están configurados, git-annex no escribe información en la rama en absoluto. Y cuando annex.alwayscommit está configurado en false, es posible que la información aún no se haya confirmado en la rama.

OPCIONES

[ruta ...]
Muestra el registro de ubicaciones para el archivo o archivos especificados, mostrando cada repositorio al que se agregaron ("+") y del que se eliminaron ("-"). Tenga en cuenta que muestra información sobre el contenido del archivo actualmente en estas rutas, no sobre ningún contenido diferente que existía en commits anteriores.
opciones de coincidencia
Las opciones de coincidencia de git-annex (git-annex-matching-options(1)) se pueden usar para controlar sobre qué actuar al mostrar el registro de ubicaciones para los archivos especificados.
--all -A
Muestra los cambios del registro de ubicaciones para todo el contenido, con los cambios más recientes primero. En este modo, los nombres de los archivos no están disponibles y se muestran las claves en su lugar.
--key=nombreclave
Muestra el registro de ubicaciones para la clave especificada.
--branch=ref
Muestra el registro de ubicaciones para los archivos en la rama o tree-ish especificada.
--unused
Muestra el registro de ubicaciones para los archivos encontrados por la última ejecución de git-annex unused.
--sizesof=repositorio
Muestra un historial del tamaño total de los archivos anexados en un repositorio a lo largo del tiempo, desde la creación del repositorio hasta el presente.
El repositorio puede ser "here" para el repositorio actual, o el nombre de un remoto, o una descripción de repositorio o uuid.
Tenga en cuenta que las claves que no tienen un tamaño conocido no se incluyen en el total.
--sizes
Esto es como --sizesof, pero en lugar de mostrar el tamaño de un solo repositorio, muestra los tamaños de todos los repositorios conocidos.
La salida es una tabla con formato CSV.
--totalsizes
Esto es como --sizesof, pero muestra el tamaño total de todos los repositorios conocidos.
--interval=tiempo
Al usar --sizesof, --sizes y --totalsizes, esto controla el intervalo mínimo entre la visualización del tamaño. El valor predeterminado es mostrar cada nuevo tamaño registrado.
El tiempo tiene el formato "30d" o "1y".
--received
Combine esta opción con --sizesof o --sizes para mostrar la cantidad de datos recibidos en los repositorios desde que se generó la última línea.
--gnuplot
Combine esta opción con --sizesof o --sizes o --totalsizes para usar gnuplot(1) para graficar los datos. El archivo gnuplot se dejará en el disco para que lo reutilice.
Por ejemplo, para graficar los tamaños de todos los repositorios:
git annex log --sizes --interval=1d --gnuplot
Para graficar la cantidad de datos nuevos recibidos en cada repositorio cada 30 días:
git annex log --sizes --interval=30d --gnuplot --recieved
--bytes
Muestra los tamaños en bytes, deshabilitando las unidades más agradables por defecto.
--raw-date
En lugar de la visualización normal de una fecha en la zona horaria local, muestra segundos desde la época de Unix.
--since=fecha, --after=fecha, --until=fecha, --before=fecha, --max-count=N
Estas opciones se pasan a git log y se pueden usar para limitar cuánto buscar cambios en el registro de ubicaciones.
Por ejemplo: --since "1 mes atrás"
Estas opciones no tienen efecto cuando se usa --sizesof, --sizes, y --totalsizes.
--gource
Genera una salida adecuada para el programa de visualización gource.
Esta opción no tiene efecto cuando se usa --sizesof, --sizes, y --totalsizes.
--json
Habilita la salida JSON. Esto está destinado a ser analizado por programas que utilizan git-annex. Cada línea de salida es un objeto JSON.
Esta opción no tiene efecto cuando se usa --sizesof, --sizes, y --totalsizes.
--json-error-messages
Los mensajes que normalmente se mostrarían en la salida de error estándar se incluyen en el JSON.
Esta opción no tiene efecto cuando se usa --sizesof, --sizes, y --totalsizes.
También se pueden usar las opciones generales de git-annex (git-annex-common-options(1).
