Nombre

gi-compile-repository - Compilador de Typelib

Sinopsis

gi-compile-repository [OPCIÓN…] GIRFILE

Descripción

gi-compile-repository convierte uno o más archivos GIR en una o más typelibs. La salida se escribirá en la salida estándar a menos que se especifique la opción --output.

Opciones

--help
Mostrar opciones de ayuda.
--output NOMBRE_ARCHIVO, -o NOMBRE_ARCHIVO
Guardar la salida resultante en NOMBRE_ARCHIVO.
--verbose
Mostrar mensajes detallados.
--debug
Mostrar mensajes de depuración.
--includedir DIRECTORIO
Añadir DIRECTORIO a la ruta de búsqueda de XML GIR. Esta opción se puede utilizar varias veces. El primer DIRECTORIO en la línea de comandos se buscará primero (mayor precedencia).
--shared-library NOMBRE_ARCHIVO, -l NOMBRE_ARCHIVO
Especifica la biblioteca compartida donde se pueden encontrar los símbolos en la typelib. El nombre de la biblioteca no debe contener la extensión del sufijo de la biblioteca compartida. Esta opción se puede utilizar varias veces, para typelibs que describen más de una biblioteca compartida.
--version
Mostrar el número de versión del programa y salir.

Ejemplo

::
$ gi-compile-repository -o Gio-2.0.typelib /usr/share/gir-1.0/Gio-2.0.gir
