NOMBRE

git-annex-calckey - calcula la clave para un archivo

SINOPSIS

git annex calckey [archivo ...]

DESCRIPCIÓN

Este comando de bajo nivel calcula la clave que se usaría para referirse a un archivo. Este comando no añade el archivo al annex. La clave se muestra en la salida estándar.

Se utiliza el backend especificado en la configuración annex.backend, que puede ser anulado con la opción --backend. Por ejemplo, para forzar el uso del backend SHA1:


git annex calckey --backend=SHA1 archivo

OPCIONES

--backend=nombre
Especifica qué backend de clave-valor usar.
--batch
Habilita el modo batch, en el cual se lee una línea con el nombre del archivo desde la entrada estándar, la clave se muestra en la salida estándar (con una nueva línea al final), y se repite.
-z
Hace que la entrada de --batch esté delimitada por nulos en lugar de las nuevas líneas habituales.
También se pueden usar las opciones generales de git-annex(1).
