NOMBRE

git-lfs-fsck - Comprueba la consistencia de los archivos GIT LFS

SINOPSIS

git lfs fsck [opciones] [revisiones]

DESCRIPCIÓN

Comprueba la consistencia de todos los archivos Git LFS en el HEAD actual.

Los archivos corruptos se mueven a ".git/lfs/bad".

Las revisiones pueden especificarse como un único committish, en cuyo caso solo se inspecciona ese commit; especificarse como un rango de la forma A..B (y solo esta forma), en cuyo caso se inspecciona ese rango; u omitirse por completo, en cuyo caso se examina HEAD (y, para --objects, el índice).

Por defecto, se realizan todas las comprobaciones.

En su configuración de Git o en un archivo .lfsconfig, puede establecer lfs.fetchexclude a una lista de rutas separada por comas. Si lfs.fetchexclude está definido, entonces cualquier archivo Git LFS cuyas rutas coincidan con una de esa lista no se comprobará para ver su consistencia. Las rutas se comparan utilizando coincidencia de patrones comodín según gitignore(5).

OPCIONES

--objects

Comprueba que cada objeto en HEAD coincide con su hash esperado y que cada objeto existe en disco.

--pointers

Comprueba que cada puntero es canónico y que cada archivo que debería almacenarse como un archivo Git LFS lo está.

VER TAMBIÉN

git-lfs-ls-files(1), git-lfs-status(1), gitignore(5).

Parte de la suite git-lfs(1).
