NOMBRE

git-annex-matchexpression - comprueba si una expresión coincide

SINOPSIS

git annex matchexpression expresión [datos]

DESCRIPCIÓN

Este comando de nivel bajo recibe una expresión de contenido preferido, y algunos datos, y comprueba si la expresión coincide con los datos. Sale con 0 si coincide y con 1 si no. Si no se proporcionaron suficientes datos, muestra un error y sale con el código especial 42.

Por ejemplo, esto saldrá con 0:


git annex matchexpression "include=*.png and largerthan=1mb" --file=foo.png --size=10mb

OPCIONES

--file=
Proporciona el nombre del archivo con el que coincidir. Ten en cuenta que el archivo no tiene que existir realmente en el disco.
--size=
Indica cuál es el tamaño del archivo. El tamaño se puede especificar con cualquier unidad de uso común, por ejemplo, "0.5 gb" o "100 KiloBytes".
--key=
Indica qué clave se está comparando. Esto es necesario para comparar expresiones como "copies=N" y "metadata=tag=foo" y "present", que necesitan buscar la información del archivo para una clave.
Muchas claves tienen un tamaño conocido, por lo que no se necesita --size al especificar una clave de este tipo.
--largefiles
Analiza la expresión como una expresión de annex.largefiles, en lugar de una expresión de contenido preferido.
--mimetype=
Indica cuál es el tipo MIME del archivo. Solo se necesita cuando se usa --largefiles con una expresión mimetype=.
--mimeencoding=
Indica cuál es la codificación MIME del archivo. Solo se necesita cuando se usa --largefiles con una expresión mimeencoding=.
--explain
Muestra una explicación de qué partes de la expresión de contenido preferido coinciden y cuáles no.
También se pueden utilizar las opciones comunes de git-annex(1).
