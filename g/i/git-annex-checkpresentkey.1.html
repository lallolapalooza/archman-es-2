NOMBRE

git-annex-checkpresentkey - comprueba si una clave está presente en un remoto

SINOPSIS

git annex checkpresentkey clave [remoto]

DESCRIPCIÓN

Este comando de bajo nivel verifica si el contenido de la clave especificada está presente en el remoto especificado.

Cuando no se especifica ningún remoto, verifica si el contenido de la clave está presente en cualquier remoto accesible.

Sale con 0 si el contenido se verifica como presente en el remoto, o con 1 si se verifica que no está presente en el remoto. Si hay un problema, se utiliza el código de salida especial 100 y se muestra un mensaje de error en stderr.

OPCIONES

--batch
Habilita el modo por lotes. En este modo, la clave no se especifica en la línea de comandos, pero el remoto sí puede serlo. Las líneas que contienen claves se leen de la entrada estándar y se genera una línea de salida con "1" si la clave se verifica como presente y "0" en caso contrario.
También se pueden usar las opciones comunes de git-annex(1).
