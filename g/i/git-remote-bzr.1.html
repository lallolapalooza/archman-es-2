NOMBRE

git-remote-bzr - Soporte de remotos de Git para repositorios de Bazaar

SINOPSIS

git clone bzr::<<repo-fuente>> [<destino>]
git fetch bzr::<<repo-fuente>> [<destino>]

DESCRIPCIÓN

Este comando proporciona soporte para usar repositorios bzr como remotos de Git, a través del plugin breezy-git. Por el momento, soporta clonar desde, obtener desde y enviar a repositorios Bazaar. El soporte de obtención aún es experimental y puede ser lento.

ERRORES

Por favor, reporte errores en https://launchpad.net/brz/+filebug
