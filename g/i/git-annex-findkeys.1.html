NOMBRE

git-annex-findkeys - lista las claves disponibles

SINOPSIS

git annex findkeys

DESCRIPCIÓN

Muestra una lista de las claves conocidas por git-annex.

OPCIONES

opciones de coincidencia
Se pueden utilizar las opciones de coincidencia de git-annex(1) para especificar qué claves listar.
Por defecto, el comando findkeys solo lista las claves cuyo contenido está actualmente presente. Especificar cualquiera de las opciones de coincidencia anulará este comportamiento predeterminado y coincidirá con todas las claves que git-annex conozca.
Para listar todas las claves, presentes o no, especifique --anything.
Para listar claves cuyo contenido no está presente, especifique --not --in=here
--print0
Imprime las claves terminadas en nulos, para su uso con xargs -0
--format=value
Utiliza formato de salida personalizado.
El valor es una cadena de formato, en la que '${var}' se expande al valor de una variable. Para justificar a la derecha una variable con espacios, use '${var;width}'; para justificar a la izquierda una variable, use '${var;-width}'; para escapar caracteres inusuales (incluidos caracteres de control) en una variable, use '${escaped_var}'
Estas variables están disponibles para su uso en formatos: key, backend, bytesize, humansize, keyname, hashdirlower, hashdirmixed, mtime (para el campo mtime de una clave WORM).
Además, '\n' es una nueva línea, '\000' es un NULL, etc.
El formato de salida predeterminado es el mismo que --format='${escapedkey}\n' excepto cuando se muestra en una terminal, los caracteres de control se escaparán.
--json
Muestra la lista de claves en formato JSON.
Esto está destinado a ser analizado por programas que utilizan git-annex. Cada línea de salida es un objeto JSON.
--json-error-messages
Los mensajes que normalmente se mostrarían en la salida estándar de error se incluyen en el JSON en su lugar.
También se pueden utilizar las opciones comunes de git-annex(1).
