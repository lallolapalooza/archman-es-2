NOMBRE

git-mv - Mover o renombrar un archivo, directorio o enlace simbólico

SINOPSIS

git mv [-v] [-f] [-n] [-k] <origen> <destino>
git mv [-v] [-f] [-n] [-k] <origen>... <directorio-destino>

DESCRIPCIÓN

Mueve o renombra un archivo, directorio o enlace simbólico.

En la primera forma, renombra <origen>, que debe existir y ser un archivo, enlace simbólico o directorio, a <destino>. En la segunda forma, <directorio-destino> debe ser un directorio existente; los orígenes dados se moverán a este directorio.

El índice se actualiza después de una ejecución exitosa, pero el cambio aún debe ser confirmado.

OPCIONES

-f, --force

Fuerza el renombrado o movimiento de un archivo aunque el <destino> exista.

-k

Omite las acciones de mover o renombrar que resultarían en un error. Un error ocurre cuando un origen no existe ni está controlado por Git, o cuando sobrescribiría un archivo existente a menos que se proporcione -f.

-n, --dry-run

No hacer nada; solo mostrar lo que sucedería.

-v, --verbose

Reportar los nombres de los archivos a medida que se mueven.

SUBMÓDULOS

Mover un submódulo usando un gitfile (lo que significa que se clonó con una versión de Git 1.7.8 o posterior) actualizará el gitfile y la configuración core.worktree para que el submódulo funcione en la nueva ubicación. También intentará actualizar la configuración submodule.<nombre>.path en el archivo gitmodules(5) y pondrá ese archivo en el staging (a menos que se use -n).

ERRORES

Cada vez que una actualización de superproyecto mueve un submódulo poblado (por ejemplo, al cambiar entre commits antes y después de la transferencia) quedará una copia de checkout de submódulo obsoleta en la ubicación antigua y aparecerá un directorio vacío en la nueva ubicación. Para volver a poblar el submódulo en la nueva ubicación, el usuario deberá ejecutar "git submodule update" después. Eliminar el directorio antiguo solo es seguro si usa un gitfile, ya que de lo contrario también se eliminará el historial del submódulo. Ambos pasos serán obsoletos cuando se implemente la actualización recursiva de submódulos.
