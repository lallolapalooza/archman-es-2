NOMBRE

git-bug - Un rastreador de errores incrustado en Git

SINOPSIS

git-bug [flags]

DESCRIPCIÓN

git-bug es un rastreador de errores incrustado en Git.

git-bug utiliza objetos Git para almacenar el seguimiento de errores separado del historial de archivos. Como los errores son objetos Git regulares, se pueden enviar (push) y extraer (pull) desde/hacia el mismo remoto de Git que ya estás utilizando para colaborar con otras personas.

OPCIONES

-h, --help[=false] Ayuda para git-bug
