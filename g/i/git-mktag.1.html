GIT-MKTAG(1) Manual de Git GIT-MKTAG(1)

NOMBRE

git-mktag - Crea un objeto de etiqueta con validación adicional

SINOPSIS

git mktag

DESCRIPCIÓN

Lee el contenido de una etiqueta de la entrada estándar y crea un objeto de etiqueta. La salida es el identificador del <objeto> de la nueva etiqueta.

Este comando es en su mayor parte equivalente a git-hash-object(1) invocado con -t tag -w --stdin. Es decir, cualquiera de estos creará y escribirá una etiqueta encontrada en mi-etiqueta:

git mktag <mi-etiqueta
git hash-object -t tag -w --stdin <mi-etiqueta

La diferencia es que mktag fallará antes de escribir la etiqueta si esta no pasa una comprobación de git-fsck(1).

La comprobación "fsck" realizada por mktag es más estricta que la que git-fsck(1) ejecutaría por defecto, en el sentido de que todos los mensajes fsck.<id-mensaje> se promocionan de advertencias a errores (por lo tanto, por ejemplo, una línea de "tagger" faltante es un error).

Los encabezados adicionales en el objeto también son un error para mktag, pero ignorados por git-fsck(1). Esta comprobación adicional puede desactivarse estableciendo la variable fsck.<id-mensaje> apropiada:

git -c fsck.extraHeaderEntry=ignore mktag <mi-etiqueta-con-encabezados

OPCIONES

--strict

Por defecto, mktag activa el equivalente al modo --strict de git-fsck(1). Use --no-strict para desactivarlo.

FORMATO DE ETIQUETA

Un archivo de firma de etiqueta, que se alimentará a la entrada estándar de este comando, tiene un formato fijo muy simple: cuatro líneas de

object <hash>
type <tipo>
tag <nombre-etiqueta>
tagger <tagger>

seguido de un mensaje *opcional* de formato libre (algunas etiquetas creadas por Git más antiguas pueden no tener una línea tagger). El mensaje, cuando existe, está separado por una línea en blanco del encabezado. La parte del mensaje puede contener una firma que Git en sí no tiene en cuenta, pero que puede ser verificada con gpg.
