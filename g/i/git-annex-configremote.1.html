NOMBRE

git-annex-configremote - cambia la configuración de un remoto especial

SINOPSIS

git annex configremote nombre|uuid|desc [parametro=valor ...]

DESCRIPCIÓN

Cambia la configuración de un remoto especial que se configuró anteriormente con git-annex initremote. El remoto especial no necesita estar habilitado para su uso en el repositorio actual, y este comando no lo habilitará.

Actualmente, este comando solo puede usarse para cambiar el valor del parámetro autoenable, por ejemplo, "autoenable=false".

Para cambiar otros parámetros, usa git-annex enableremote

OPCIONES

La mayoría de las opciones no van precedidas por un guion y establecen parámetros del remoto, como se muestra arriba.

Además, se pueden usar las opciones comunes de git-annex (git-annex-common-options(1)).
