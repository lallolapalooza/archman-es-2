NOMBRE

switch - Cambiar a la rama o commit proporcionado

SINOPSIS

switch [-i|--interactive] [-c|--create] [-f|--force] [-m|--merge] [-d|--detach] [-h|--help] [TARGET]

DESCRIPCIÓN

Cambiar a la rama o commit proporcionado

OPCIONES

-i, --interactive
Seleccionar interactivamente un commit para extraer.
-c, --create=NOMBRE_DE_RAMA
Al extraer el commit de destino, también crea una rama con el nombre proporcionado apuntando a ese commit.
-f, --force
Forzar el cambio de commits, descartando cualquier cambio en la copia de trabajo si es necesario.
-m, --merge
Si los cambios de la copia de trabajo actual no se aplican limpiamente al commit de destino, iniciar la resolución de conflictos de fusión en lugar de abortar.
-d, --detach
Si el destino es una rama, cambiar a esa rama y separarse inmediatamente de ella.
-h, --help
Imprimir ayuda (ver un resumen con '-h').
[TARGET]
El commit o la rama a extraer.

Si no se proporciona, se inicia la selección interactiva de commits como si se hubiera pasado `--interactive`.

Si se proporciona y se pasa el indicador `--interactive`, este texto se utiliza para pre-rellenar el selector interactivo de commits.
