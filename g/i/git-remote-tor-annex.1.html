NOMBRE

git-remote-tor-annex - programa auxiliar de remoto para comunicarse con git-annex a través de tor

SINOPSIS

git fetch tor-annex::direccion.onion:puerto

git remote add tor tor-annex::direccion.onion:puerto

DESCRIPCIÓN

Este es un programa auxiliar de remoto de git que permite a git obtener y enviar a través de tor(1), comunicándose con un servicio oculto de tor.

El servicio oculto de tor probablemente requiere un authtoken para usarlo. El authtoken se puede proporcionar en la variable de entorno GIT_ANNEX_P2P_AUTHTOKEN. O, si hay un archivo en .git/annex/creds/ que coincida con la dirección onion del servicio oculto, se utiliza su primera línea como authtoken.
