NOMBRE

git-diagnose - Generar un archivo zip de información de diagnóstico

SINOPSIS

git diagnose [(-o | --output-directory) <ruta>] [(-s | --suffix) <formato>]
               [--mode=<modo>]

DESCRIPCIÓN

Recopila información detallada sobre la máquina del usuario, el cliente Git y el estado del repositorio y empaqueta esa información en un archivo zip. El archivo generado puede, por ejemplo, compartirse con la lista de correo de Git para ayudar a depurar un problema o servir como referencia para la depuración independiente.

Por defecto, la siguiente información se captura en el archivo:

•git version --build-options
•La ruta a la raíz del repositorio
•El espacio en disco disponible en el sistema de archivos
•El nombre y tamaño de cada archivo pack, incluidos los de almacenes de objetos alternativos
•El recuento total de objetos sueltos, así como los recuentos desglosados por subdirectorio de .git/objects

Se puede recopilar información adicional seleccionando un modo de diagnóstico diferente usando la opción --mode.

Esta herramienta difiere de git-bugreport(1) en que recopila información mucho más detallada con un mayor enfoque en informar sobre el tamaño y la forma de los datos del contenido del repositorio.

OPCIONES

-o <ruta>, --output-directory <ruta>

Coloca el archivo de diagnóstico resultante en <ruta> en lugar del directorio actual.

-s <formato>, --suffix <formato>

Especifica un sufijo alternativo para el nombre del archivo de diagnóstico, para crear un archivo llamado git-diagnostics-<sufijo-formateado>. Esto debería tener la forma de una cadena de formato strftime(3); se utilizará la hora local actual.

--mode=(stats|all)

Especifica el tipo de diagnósticos que deben recopilarse. El comportamiento predeterminado de git diagnose es equivalente a --mode=stats.

La opción --mode=all recopila todo lo incluido en --mode=stats, así como copias de los directorios .git, .git/hooks, .git/info, .git/logs y .git/objects/info. Esta información adicional puede ser sensible, ya que puede utilizarse para reconstruir el contenido completo del repositorio diagnosticado. Los usuarios deben tener precaución al compartir un archivo generado con --mode=all.
