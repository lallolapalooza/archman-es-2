NOMBRE

git-annex-updatecluster - actualiza los registros de los nodos del clúster

SINOPSIS

git-annex updatecluster

DESCRIPCIÓN

Este comando se utiliza para registrar los nodos de un clúster en la rama git-annex y configurar el proxy para los nodos. Debe ejecutarse en el repositorio que servirá como puerta de enlace al clúster.

Examina la configuración de git remote.name.annex-cluster-node de cada remoto. Cuando esta opción está configurada con el nombre de un clúster que ha sido inicializado con git-annex initcluster, el nodo se registrará en la rama git-annex.

Para eliminar un nodo de un clúster, anula la configuración de remote.name.annex-cluster-node y ejecuta este comando.

Para añadir puertas de enlace adicionales a un clúster, después de ejecutar este comando, utiliza git-annex-extendcluster.

OPCIONES

Se pueden usar las git-annex-common-options(1).
