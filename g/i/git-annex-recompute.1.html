NOMBRE

git-annex-recompute - recalcula archivos computados

SINOPSIS

git-annex recompute [ruta ...]

DESCRIPCIÓN

Esto actualiza los archivos computados que fueron añadidos con git-annex-addcomputed(1).

Por defecto, esto solo recalcula los archivos cuyos archivos de entrada han cambiado. Los nuevos contenidos de los archivos de entrada se utilizan para reejecutar el cálculo.

Cuando la salida del cálculo es diferente, el archivo computado se actualiza con el nuevo contenido. El archivo actualizado se prepara en git.

OPCIONES

--original
Vuelve a ejecutar el cálculo con el contenido original de los archivos de entrada.
--remote=nombre
Solo recalcula los archivos que fueron calculados por este remoto de cálculo.
Cuando esta opción no se utiliza, todos los archivos computados se recalculan utilizando el remoto de cálculo que se utilizó originalmente para añadirlos. (En casos donde un archivo puede ser calculado por múltiples remotos, se utiliza el que tiene el coste configurado más bajo.)
--unreproducible, -u
Indica que no se espera que el cálculo sea completamente reproducible. Puede variar, de maneras que producen archivos equivalentes suficientes para ser intercambiables, pero no necesariamente idénticos.
Este es el valor por defecto a menos que el remoto de cálculo indique que produce salida reproducible.
--reproducible, -r
Indica que se espera que el cálculo sea completamente reproducible.
Este es el valor por defecto cuando el remoto de cálculo indica que produce salida reproducible.
--json
Habilita la salida JSON. Esto está destinado a ser analizado por programas que utilizan git-annex. Cada línea de salida es un objeto JSON.
opciones de coincidencia
Las opciones de coincidencia de git-annex(1) se pueden usar para controlar qué archivos se recalculan.
También las opciones comunes de git-annex(1) pueden ser utilizadas.
