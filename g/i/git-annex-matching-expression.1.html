NOMBRE

git-annex-matching-expression - especificar un conjunto de archivos

DESCRIPCIÓN

Las configuraciones annex.largefiles y annex.addunlocked utilizan expresiones que coinciden con algunos archivos en el árbol de trabajo.

SINTAXIS

El formato de estas expresiones es similar a las expresiones de git-annex-preferred-content(1).

Por ejemplo:


largerthan=100kb and not (include=*.c or include=*.h)

Esto coincide con archivos grandes, pero excluye archivos fuente de C.

Se pueden usar los siguientes términos:

include=glob / exclude=glob
Especifica archivos para incluir o excluir.
El glob puede contener * y ? para coincidir con caracteres arbitrarios.
Tenga en cuenta que esto coincide con el nombre de archivo completo, relativo a la parte superior del directorio de git. Por lo tanto, include=foo incluirá un archivo foo en la parte superior, pero no subdir/foo. Para incluir ambos, use include=foo or include=*/foo
smallerthan=size / largerthan=size
Coincide solo con archivos más pequeños o más grandes que el tamaño especificado.
El tamaño se puede especificar con cualquier unidad comúnmente utilizada, por ejemplo, "0.5 gb" o "100 KiloBytes"
mimetype=glob
Busca el tipo MIME de un archivo y comprueba si el glob coincide con él.
Por ejemplo, "mimetype=text/*" coincidirá con muchas variedades de archivos de texto, incluyendo "text/plain", pero también "text/x-shellscript", "text/x-makefile", etc.
Los tipos MIME son los mismos que se muestran al ejecutar file --mime-type
Esto solo coincide cuando el contenido del archivo está presente en el repositorio local. Normalmente es así, pero por ejemplo, al importar desde un repositorio especial con --no-content, el contenido normalmente no está presente.
Esto solo está disponible para usar cuando git-annex se compiló con el indicador de compilación MagicMime.
mimeencoding=glob
Busca la codificación MIME de un archivo y comprueba si el glob coincide con ella.
Por ejemplo, "mimeencoding=binary" coincidirá con muchos tipos de archivos binarios.
Las codificaciones MIME son las mismas que se muestran al ejecutar file --mime-encoding
Esto solo coincide cuando el contenido del archivo está presente en el repositorio local. Normalmente es así, pero por ejemplo, al importar desde un repositorio especial con --no-content, el contenido normalmente no está presente.
Esto solo está disponible para usar cuando git-annex se compiló con el indicador de compilación MagicMime.
anything
Coincide con cualquier archivo.
nothing
No coincide con ningún archivo. (Lo mismo que "not anything")
not expression
Invierte lo que coincide la expresión.
and / or / ( expression )
Estos se pueden usar para construir expresiones más complicadas.
