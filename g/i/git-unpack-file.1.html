NOMBRE

git-unpack-file - Crea un archivo temporal con el contenido de un blob

SINOPSIS

git unpack-file <blob>

DESCRIPCIÓN

Crea un archivo que contiene el contenido del blob especificado por su sha1. Devuelve el nombre del archivo temporal en el siguiente formato: .merge_file_XXXXX

OPCIONES

<blob>

Debe ser un ID de blob
