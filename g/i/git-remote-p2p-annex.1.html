NOMBRE

git-remote-p2p-annex - programa auxiliar remoto para comunicarse con git-annex a través de una red P2P

SINOPSIS

git fetch p2p-annex::netname+address

git remote add foo p2p-annex::netname+address

DESCRIPCIÓN

Este es un programa auxiliar de remoto de git que permite a git hacer pull y push a través de una red P2P.

Utiliza un comando git-annex-p2p-<netname> para comunicarse con la red P2P.
