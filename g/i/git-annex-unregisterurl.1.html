NOMBRE

git-annex-unregisterurl - anula el registro de una url para una clave

SINOPSIS

git annex unregisterurl [clave url]

DESCRIPCIÓN

Este comando de nivel de fontanería se puede utilizar para anular el registro de urls cuando las claves ya no se pueden descargar de ellas.

Normalmente, la clave tiene el formato de clave de git-annex. Sin embargo, si la clave no se puede analizar como una clave y es una url válida, se construye una clave de URL a partir de la url.

Anular el registro de la última url web de una clave hará que git-annex ya no considere que el contenido está presente en el repositorio especial web. Si algún otro repositorio especial reclama la url, anular el registro de la url no actualizará la información de presencia para él, ya que el contenido puede seguir presente en el repositorio.

OPCIONES

--remote=nombre|uuid
Indica que se espera que la url sea reclamada por el repositorio especificado. Si algún otro repositorio reclama la url en su lugar, anular su registro fallará.
Tenga en cuenta que --remote=web impedirá que cualquier otro repositorio reclame la url.
--batch
En el modo de entrada por lotes, las líneas se leen desde stdin, y cada línea debe contener una clave y una url, separadas por un solo espacio.
-z
Cuando esté en modo por lotes, la entrada estará delimitada por nulos en lugar de las nuevas líneas habituales.
--json
Habilita la salida JSON. Está destinada a ser analizada por programas que utilizan git-annex. Cada línea de salida es un objeto JSON.
--json-error-messages
Los mensajes que normalmente se emitirían a la salida de error estándar se incluyen en el JSON en su lugar.
También se pueden usar las git-annex-common-options(1).
