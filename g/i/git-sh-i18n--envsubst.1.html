NOMBRE

git-sh-i18n--envsubst - envsubst(1) propio de Git para fallbacks de i18n

SINOPSIS

eval_gettext () {
        printf "%s" "$1" | (
                export PATH $(git sh-i18n--envsubst --variables "$1");
                git sh-i18n--envsubst "$1"
        )
}

DESCRIPCIÓN

Este no es un comando que el usuario final quiera ejecutar. Nunca. Esta documentación está destinada a personas que estudian los scripts internos y/o están escribiendo otros nuevos.

git sh-i18n--envsubst es una copia reducida del programa GNU envsubst(1) que viene con el paquete GNU gettext. Es utilizado internamente por git-sh-i18n(1) para interpolar las variables pasadas a la función eval_gettext.

No se hacen promesas sobre la interfaz, o sobre que este programa no desaparezca sin previo aviso en la próxima versión de Git. No lo uses.
