NOMBRE

git-lfs-install - Instalar la configuración de Git LFS.

SINOPSIS

git lfs install [opciones]

DESCRIPCIÓN

Realiza las siguientes acciones para asegurar que Git LFS esté configurado correctamente:

•Configura los filtros clean y smudge bajo el nombre "lfs" en la configuración global de Git.
•Instala un hook pre-push para ejecutar git-lfs-pre-push(1) para el repositorio actual, si se ejecuta desde dentro de uno. Si "core.hooksPath" está configurado en alguna configuración de Git (y es compatible, es decir, la versión de Git instalada es al menos 2.9.0), entonces el hook pre-push se instalará en ese directorio en su lugar.

OPCIONES

Sin opciones, git lfs install solo configurará los filtros smudge y clean de "lfs" si aún no están establecidos.

--force

Establece los filtros smudge y clean de "lfs", sobrescribiendo los valores existentes.

--local

Establece los filtros smudge y clean de "lfs" en la configuración de Git del repositorio local, en lugar de la configuración global de Git (~/.gitconfig).

--worktree

Establece los filtros smudge y clean de "lfs" en la configuración de Git del árbol de trabajo actual, en lugar de la configuración global de Git (~/.gitconfig) o la configuración del repositorio local ($GIT_DIR/config). Si se utilizan varios árboles de trabajo, la extensión de configuración de Git worktreeConfig debe estar habilitada para usar esta opción. Si solo se utiliza un árbol de trabajo, --worktree tiene el mismo efecto que --local. Esta opción solo está disponible si la versión de Git instalada es al menos 2.20.0 y, por lo tanto, admite la extensión "worktreeConfig".

--manual

Imprime instrucciones para actualizar manualmente tus hooks e incluir la funcionalidad de git-lfs. Usa esta opción si git lfs install falla debido a hooks existentes y deseas conservar su funcionalidad.

--system

Establece los filtros smudge y clean de "lfs" en la configuración del sistema de Git, por ejemplo, /etc/gitconfig en lugar de la configuración global de Git (~/.gitconfig).

--skip-smudge

Omite la descarga automática de objetos en clone o pull. Esto requiere un "git lfs pull" manual cada vez que se extrae un nuevo commit en tu repositorio.

--skip-repo

Omite la instalación de hooks en el repositorio local; úsalo si deseas instalar los filtros LFS pero no realizar cambios en los hooks. Es válido usar --local, --global o --system en conjunción con esta opción.

VER TAMBIÉN

git-lfs-uninstall(1), git-worktree(1).

Parte de la suite git-lfs(1).
