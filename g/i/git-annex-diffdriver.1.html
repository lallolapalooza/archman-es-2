NOMBRE

git-annex-diffdriver - controlador de diff de git

SINOPSIS

git annex diffdriver [--get,--text] [-- --diffopts --]

git annex diffdriver -- cmd --cmdopts --

DESCRIPCIÓN

Normalmente, git diff cuando se ejecuta en archivos anexados muestra los cambios que están preparados en git, por ejemplo, enlaces simbólicos y punteros de annex. Este comando permite a git diff mostrar en su lugar el contenido de los archivos anexados.

Este comando se puede utilizar tanto como un simple comparador de texto, como un intermediario que ejecuta un controlador de diff externo de git.

Si algunos de sus archivos anexados son de naturaleza textual, y se pueden comparar útilmente con diff(1), puede configurar git para que utilice este comando para compararlos, configurando .gitattributes para que contenga, por ejemplo, *.txt diff=annextextdiff y estableciendo git config diff.annextextdiff.command "git annex diffdriver --text".

Si sus archivos anexados no son de naturaleza textual, necesitará un programa controlador de diff externo que sea capaz de comparar los formatos de archivo que utiliza. Consulte la documentación de git sobre GIT_EXTERNAL_DIFF y la documentación de gitattributes(5) sobre controladores de diff externos.

Normalmente, al usar git diff con un controlador de diff externo, este no verá el contenido de los archivos anexados, ya que git le pasará los enlaces simbólicos o archivos puntero de git-annex. Este comando soluciona el problema, ejecutando el controlador de diff externo real, y pasándole las rutas al contenido anexo. Configure git para que utilice "git-annex diffdriver -- cmd params --" como controlador de diff externo, donde cmd es el controlador de diff externo que desea que ejecute, y params son los parámetros adicionales para pasarle. Tenga en cuenta el "--" final, que es obligatorio.

Por ejemplo, para usar el programa j-c-diff como controlador de diff externo, establezca GIT_EXTERNAL_DIFF="git-annex diffdriver -- j-c-diff --"

OPCIONES

Para obtener el contenido de los archivos anexados de los remotos cuando aún no están presentes, utilice la opción --get. El contenido del archivo permanecerá en el repositorio para su uso posterior hasta que se elimine de la forma habitual.

Para comparar archivos de texto con diff(1), utilice la opción --text. Para pasar opciones adicionales a diff(1), utilice, por ejemplo, "--text -- --color --"

Para utilizar un comando controlador de diff externo, las opciones deben comenzar con "--" seguido del comando controlador de diff, sus opciones y otro "--"

También se pueden utilizar las git-annex-common-options(1).
