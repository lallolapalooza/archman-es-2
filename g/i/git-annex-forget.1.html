NOMBRE

git-annex-forget - podar el historial de la rama git-annex

SINOPSIS

git annex forget

DESCRIPCIÓN

Provoca que la rama git-annex se reescriba, descartando datos históricos sobre ubicaciones pasadas de archivos. La rama resultante utilizará menos espacio, pero git annex log no podrá mostrar dónde se encontraban ubicados los archivos anteriormente.

Cuando esta rama reescrita se fusiona en otros clones del repositorio, git-annex realizará automáticamente la misma reescritura en sus ramas locales de git-annex. Por lo tanto, el olvido se propagará automáticamente desde su punto de partida hasta que todos los repositorios que ejecuten git-annex hayan olvidado su historial antiguo. (Es posible que deba forzar a git a enviar la rama a cualquier repositorio git que no ejecute git-annex).

OPCIONES

--drop-dead
También poda las referencias a repositorios que han sido marcados como muertos.
También se pueden utilizar las opciones comunes de git-annex.
