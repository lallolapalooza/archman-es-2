NOMBRE

git-annex-inprogress - acceder a archivos mientras se están descargando

SINOPSIS

git annex inprogress [ruta ...]

DESCRIPCIÓN

Este comando permite acceder al contenido de un archivo anexado mientras todavía se está descargando. Muestra en la salida estándar el nombre del archivo temporal que se está utilizando para descargar el archivo anexado especificado.

No se mostrará nada cuando la descarga sea desde un repositorio especial cifrado o fragmentado.

Esto a veces se puede usar para transmitir un archivo antes de que se haya descargado completamente, por ejemplo:


git annex get video.mpeg &
vlc $(git annex inprogress video.mpeg)

Por supuesto, si el archivo se descarga demasiado lento, el reproductor multimedia llegará al final demasiado pronto y no mostrará todo. Y, por supuesto, solo algunos formatos de archivo se pueden transmitir de manera útil de esta manera.

OPCIONES

[ruta ..]
Los archivos o directorios cuyo contenido parcialmente descargado desea acceder.
Tenga en cuenta que, cuando no se especifica ninguna ruta, por defecto se utilizan todos los archivos en el directorio de trabajo actual y subdirectorios, lo que puede tardar en recorrerse. Es más eficiente especificar el archivo que le interesa, o usar --all
--all -A
En lugar de especificar un nombre de archivo o ruta, esta opción se puede utilizar para acceder a todos los archivos que se están descargando actualmente.
--key=nombreclave
Acceder al archivo que se está descargando para la clave especificada.
opciones de coincidencia de archivo
Se pueden usar las opciones de coincidencia de git-annex(1) para especificar archivos a los que acceder.
También se pueden usar las opciones comunes de git-annex(1).

ESTADO DE SALIDA

Si alguno de los elementos solicitados no se está descargando actualmente, el estado de salida será 1.
