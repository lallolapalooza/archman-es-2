NOMBRE

git-latexdiff - Llama a latexdiff en dos revisiones de Git de un archivo

OPCIONES

Uso: git latexdiff [opciones] ANTIGUO [NUEVO]
       git latexdiff [opciones] ANTIGUO --
       git latexdiff [opciones] -- ANTIGUO
Ejecuta latexdiff sobre dos revisiones de Git de un archivo.
ANTIGUO y NUEVO son identificadores de revisión de Git. NUEVO por defecto es HEAD.
Si se usa "--" para NUEVO, entonces se compara con el directorio de trabajo.
Opciones:
    --help                este mensaje de ayuda
    --help-examples       muestra ejemplos de uso
    --main <archivo>      nombre del archivo principal de LaTeX, R Sweave,
                            o Emacs Org mode.
                            Se intentará buscar el único archivo que contenga 'documentclass'
                            si no se especifica.
                            Para archivos que no son LaTeX, se usará un comando `prepare`
                            razonable a menos que se proporcione explícitamente
    --no-view             no mostrar el archivo PDF resultante
    --latex               ejecutar latex en lugar de pdflatex
    --xelatex             ejecutar xelatex en lugar de pdflatex
    --lualatex            ejecutar lualatex en lugar de pdflatex
    --tectonic            ejecutar tectonic en lugar de pdflatex
    --bibtex, --bbl       mostrar cambios en la bibliografía
                             (ejecuta bibtex para generar archivos *.bbl e
                             incluirlos en el archivo fuente usando
                             latexpand --expand-bbl antes de calcular
                             el diff)
    --biber               como --bibtex, pero ejecuta biber en su lugar.
    --run-bibtex, -b      ejecutar bibtex además de latex para generar el archivo PDF
                             (pdflatex,bibtex,pdflatex,pdflatex)
                          NOTA: --bibtex normalmente funciona mejor
    --run-biber           ejecutar BibLaTex-Biber además de latex para generar el archivo PDF
                             (pdflatex,biber,pdflatex,pdflatex)
                          NOTA: --biber normalmente funciona mejor
    --view                ver el archivo PDF resultante
                            (predeterminado si no se usa -o)
    --pdf-viewer <cmd>    usar <cmd> para ver el archivo PDF (predeterminado: $PDFVIEWER)
    --no-cleanup          no limpiar el directorio temporal después de ejecutar
    --no-flatten          no llamar a latexpand para aplanar el documento
    --cleanup MODO        Limpiar archivos temporales según MODO:
                           - keeppdf (predeterminado): conservar solo el
                                  archivo PDF generado
                           - none: conservar todos los archivos temporales
                                  (puede consumir tu espacio en disco)
                           - all: borrar todos los archivos generados.
                                  Problemático con --view cuando el
                                  visor es, por ejemplo, evince, y no
                                  le gusta que se elimine el archivo
                                  que se está viendo.
    --latexmk             usar latexmk
    --build-dir           usar PDFs de un directorio de compilación específico
    --latexopt            pasar opciones adicionales a latex (p. ej. -shell-escape)
    -o <archivo>, --output <archivo>
                          copiar el PDF resultante en <archivo> (normalmente terminado en .pdf)
                          Implica "--cleanup all"
    --tmpdirprefix        dónde se creará el directorio temporal (predeterminado: /tmp).
                            Una ruta relativa usará la raíz del repositorio como base
    --verbose, -v         proporcionar salida más detallada
    --quiet               redirigir la salida de los subprocesos a archivos de registro
    --prepare <cmd>       ejecutar <cmd> antes de latexdiff (p. ej. ejecutar make para generar
                             archivos incluidos)
    --filter <cmd>        ejecutar <cmd> después de latexdiff y antes de la compilación
                             (p. ej. para corregir la salida de latexdiff)
    --ln-untracked        crear enlaces simbólicos a archivos no confirmados del directorio de trabajo
    --ln-untracked-dir <dir>
                          crear enlaces simbólicos al subdirectorio de archivos no confirmados (relativo al archivo .tex principal)
    --version             mostrar la versión de git-latexdiff.
    --subtree             hacer checkout del árbol en y debajo del archivo principal
                             (habilitado por defecto, deshabilitar con --whole-tree)
    --whole-tree          hacer checkout de todo el árbol (contraste con --subtree)
    --ignore-latex-errors continuar aunque latex dé errores, siempre que
                          se produzca un archivo PDF
    --ignore-makefile     ignorar el Makefile, compilar como si no existiera
    -*                    otras opciones se pasan directamente a latexdiff
    --latexpand OPT       pasar la opción OPT a latexpand. Usar varias veces como
                          --latexpand OPT1 --latexpand OPT2 para pasar múltiples opciones.
    --latexdiff-flatten   usar --flatten de latexdiff en lugar de latexpand
    --early-exit-if-equal si dos archivos son idénticos no se llamará a latexdiff y git-latexdiff saldrá correctamente.
                          Esta opción solo funciona si se usa latexpand
Las opciones no reconocidas se pasan sin modificar a latexdiff.

EJEMPLOS

Comparar la revisión anterior con el último commit:

git latexdiff HEAD^

Comparar el último commit con el árbol de trabajo:

git latexdiff HEAD --

Comparar el último commit con la rama master:

git latexdiff master HEAD

Pasar --type=CHANGEBAR a latexdiff para obtener barras de cambio en los márgenes en lugar de la diferencia rojo+tachado/azul+subrayado:

git latexdiff --type=CHANGEBAR HEAD^

Usar un archivo de configuración específico de latexdiff:

git latexdiff --config /path/to/file HEAD^

Añadir una sentencia \makeatletter para intentar corregir algunos errores de compilación de LaTeX que involucran comandos que contienen el carácter @:

git latexdiff --latexpand --makeatletter HEAD^
