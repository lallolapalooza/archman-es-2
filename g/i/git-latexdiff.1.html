NOMBRE

git-latexdiff - Llama a latexdiff en dos revisiones de Git de un archivo

OPCIONES

Uso: git latexdiff [opciones] VIEJO [NUEVO]
       git latexdiff [opciones] VIEJO --
       git latexdiff [opciones] -- VIEJO
Llama a latexdiff en dos revisiones de Git de un archivo.
`VIEJO` y `NUEVO` son identificadores de revisión de Git. `NUEVO` por defecto es `HEAD`.
Si se usa "--" para `NUEVO`, entonces se compara con el directorio de trabajo.
Opciones:
    --help                este mensaje de ayuda
    --help-examples       mostrar ejemplos de uso
    --main <archivo>      nombre del archivo principal de LaTeX, R Sweave,
                            o Emacs Org mode.
                            Si no se especifica, se intentará buscar el único archivo que contenga 'documentclass'.
                            Para archivos que no son LaTeX, se utilizará un comando `prepare` razonable
                            a menos que se proporcione explícitamente.
    --no-view             no mostrar el archivo PDF resultante
    --latex               ejecutar latex en lugar de pdflatex
    --xelatex             ejecutar xelatex en lugar de pdflatex
    --lualatex            ejecutar lualatex en lugar de pdflatex
    --tectonic            ejecutar tectonic en lugar de pdflatex
    --bibtex, --bbl       mostrar cambios en la bibliografía
                             (ejecuta bibtex para generar archivos *.bbl y
                             los incluye en el archivo fuente usando
                             latexpand --expand-bbl antes de calcular
                             la diferencia)
    --biber               igual que --bibtex, pero ejecuta biber en su lugar.
    --run-bibtex, -b      ejecutar bibtex así como latex para generar el archivo PDF
                             (pdflatex,bibtex,pdflatex,pdflatex)
                          NOTA: --bibtex generalmente funciona mejor
    --run-biber           ejecutar BibLaTex-Biber así como latex para generar el archivo PDF
                             (pdflatex,biber,pdflatex,pdflatex)
                          NOTA: --biber generalmente funciona mejor
    --view                ver el archivo PDF resultante
                            (por defecto si no se usa -o)
    --pdf-viewer <cmd>    usar <cmd> para ver el archivo PDF (por defecto: $PDFVIEWER)
    --no-cleanup          no limpiar el directorio temporal después de ejecutar
    --no-flatten          no llamar a latexpand para aplanar el documento
    --cleanup MODO        Limpiar archivos temporales según MODO:
                           - keeppdf (por defecto): conservar solo el
                                  archivo PDF generado
                           - none: conservar todos los archivos temporales
                                  (puede consumir tu espacio en disco)
                           - all: borrar todos los archivos generados.
                                  Problemático con --view cuando el
                                  visor es, por ejemplo, evince, y no
                                  le gusta cuando el archivo que se está viendo
                                  es eliminado.
    --latexmk             usar latexmk
    --build-dir           usar pdfs de un directorio de compilación específico
    --latexopt            pasar opciones adicionales a latex (por ejemplo, -shell-escape)
    -o <archivo>, --output <archivo>
                          copiar el PDF resultante a <archivo> (generalmente terminando en .pdf)
                          Implica "--cleanup all"
    --tmpdirprefix        dónde se creará el directorio temporal (por defecto: /tmp).
                            Una ruta relativa usará la raíz del repositorio como base.
    --verbose, -v         dar salida más detallada
    --quiet               redirigir la salida de los subprocesos a archivos de registro
    --prepare <cmd>       ejecutar <cmd> antes de latexdiff (por ejemplo, ejecutar make para generar
                             archivos incluidos)
    --filter <cmd>        ejecutar <cmd> después de latexdiff y antes de la compilación
                             (por ejemplo, para corregir la salida de latexdiff)
    --ln-untracked        enlazar archivos no confirmados del directorio de trabajo
    --version             mostrar la versión de git-latexdiff.
    --subtree             extraer el árbol en y debajo del archivo principal
                             (habilitado por defecto, deshabilitar con --whole-tree)
    --whole-tree          extraer todo el árbol (en contraste con --subtree)
    --ignore-latex-errors continuar aunque latex arroje errores, siempre que
                          se produzca un archivo PDF
    --ignore-makefile     ignorar el Makefile, compilar como si no existiera
    -*                    otras opciones se pasan directamente a latexdiff
    --latexpand OPT       pasar la opción OPT a latexpand. Usar varias veces como
                          --latexpand OPT1 --latexpand OPT2 para pasar múltiples opciones.
    --latexdiff-flatten   usar --flatten de latexdiff en lugar de latexpand
Opciones no reconocidas se pasan sin modificar a latexdiff.
Ejemplos:
Comparar la revisión anterior con el último commit:
    git latexdiff HEAD^
Comparar el último commit con el árbol de trabajo:
    git latexdiff HEAD --
Comparar el último commit con la rama master:
    git latexdiff master HEAD
Pasar --type=CHANGEBAR a latexdiff para obtener barras de cambio en los márgenes
en lugar de diff rojo+tachado/azul+subrayado:
    git latexdiff --type=CHANGEBAR HEAD^
Usar un archivo de configuración de latexdiff específico:
    git latexdiff --config /ruta/a/archivo HEAD^
