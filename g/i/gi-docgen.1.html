GI-DOCGEN(1) Comandos de Usuario GI-DOCGEN(1)

NOMBRE

gi-docgen - un generador de documentación que usa gobject-introspection

SINOPSIS

gi-docgen COMANDO [OPCIÓN...] ARCHIVO_GIR

DESCRIPCIÓN

GI-DocGen es un generador de documentos para bibliotecas basadas en GObject. GObject es el sistema de tipos base del proyecto GNOME. GI-DocGen usa los datos de introspección legibles por máquina proporcionados por las bibliotecas basadas en GObject para generar la referencia de API de estas bibliotecas, así como otra documentación auxiliar.

El ejecutable principal gi-docgen proporciona varios subcomandos para acceder a toda su funcionalidad.

Opciones comunes

Todos los comandos tienen las siguientes opciones:

--quiet
no imprimir detalles de la operación actual
--fatal-warnings
convertir advertencias en errores fatales
--help
imprimir la ayuda de la línea de comandos

El comando generate

El comando generate proporciona la funcionalidad principal de gi-docgen.

gi-docgen generate [ OPCIONES ] [ ARCHIVO_GIR ]

El comando generate analizará el archivo GIR dado, así como sus dependencias, y construirá una referencia de API para el espacio de nombres que encuentre en los datos de introspección. Los proyectos pueden usar un archivo de configuración para controlar aspectos de la salida, así como proporcionar contenido adicional que deba incluirse en la documentación.

opciones:

--config=ARCHIVO
usar el archivo de configuración del proyecto dado
--content-dir=RUTA
especificar el directorio donde se pueden encontrar los archivos de contenido listados en el archivo de configuración del proyecto
--templates-dir=RUTA
especificar el directorio donde se encuentran las plantillas utilizadas para generar la documentación
--theme-name=NOMBRE
especificar el nombre de la plantilla que se utilizará al generar la documentación, anulando la configuración del proyecto
--output-dir=RUTA
crear la documentación bajo el directorio dado
--no-namespace-dir
generar todos los archivos de documentación directamente bajo el directorio de salida, en lugar de crear un directorio con el nombre del espacio de nombres y la versión
--add-include-path=RUTA
añadir un directorio a la ruta que el escáner utiliza para encontrar archivos GIR. Se puede usar varias veces para especificar múltiples directorios
--section=NOMBRE
generar la documentación solo para la sección dada. Se puede usar varias veces para especificar múltiples secciones. Las secciones admitidas son alias, campos_de_bits, clases, dominios, enumeraciones, interfaces, estructuras y uniones. Los valores especiales son all, que significa todas las secciones (el valor predeterminado); y none, que significa ninguna sección
--dry-run
analizar el ARCHIVO_GIR sin generar la documentación

El comando gen-index

El comando gen-index genera un índice de símbolos y términos que se puede usar para buscar dentro de la documentación generada por gi-docgen.

gi-docgen gen-index [ OPCIONES ] [ ARCHIVO_GIR ]

El índice generado es un archivo con formato JSON llamado index.json.

opciones:

--config=ARCHIVO
usar el archivo de configuración del proyecto dado
--content-dir=RUTA
especificar el directorio donde se pueden encontrar los archivos de contenido listados en el archivo de configuración del proyecto
--output-dir=RUTA
crear el índice bajo el directorio dado
--add-include-path=RUTA
añadir un directorio a la ruta que el escáner utiliza para encontrar archivos GIR. Se puede usar varias veces para especificar múltiples directorios
--dry-run
analizar el ARCHIVO_GIR sin generar la documentación

El comando check

El comando check ejecuta una serie de comprobaciones en el archivo de introspección, para verificar que la API pública esté documentada correctamente. Se puede usar como parte de un conjunto de pruebas.

gi-docgen check [ OPCIONES ] [ ARCHIVO_GIR ]

opciones:

--config=ARCHIVO
usar el archivo de configuración del proyecto dado
--add-include-path=RUTA
añadir un directorio a la ruta que el escáner utiliza para encontrar archivos GIR. Se puede usar varias veces para especificar múltiples directorios

El comando serve

El comando serve genera una referencia de API y la sirve usando un servidor HTTP local.

gi-docgen serve [ OPCIONES ] [ ARCHIVO_GIR ]

El comando serve analizará el archivo GIR dado, así como sus dependencias, y construirá una referencia de API para el espacio de nombres que encuentre en los datos de introspección. Una vez que la referencia se haya construido con éxito, gi-docgen iniciará un servidor HTTP local que apunte al directorio de salida.

opciones:

--bind=DIRECCION
usar la dirección dada para el servidor HTTP; el valor predeterminado es 127.0.0.1
--port=PUERTO
usar el puerto dado para el servidor HTTP; el valor predeterminado es 8080

El comando help

El comando help imprime la ayuda de la línea de comandos. Si no especifica ningún comando u opción al invocar gi-docgen, se implicará el comando help.

gi-docgen help [ OPCIONES ] [ COMANDO ]

Si no se especifica ningún comando, help imprimirá la lista de comandos.

Si se especifica un comando, help imprimirá la ayuda de la línea de comandos para ese programa.

opciones:

--version
imprimir la versión de gi-docgen

ESTADO DE SALIDA

0
El comando se ejecutó correctamente.
1
Se generó un error o una advertencia.
