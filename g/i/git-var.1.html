NOMBRE

git-var - Mostrar una variable lógica de Git

SINOPSIS

git var (-l | <variable>)

DESCRIPCIÓN

Imprime una variable lógica de Git. Sale con código 1 si la variable no tiene valor.

OPCIONES

-l

Muestra las variables lógicas. Además, se listan todas las variables del archivo de configuración de Git .git/config. (Sin embargo, la funcionalidad de listado de variables de configuración está obsoleta en favor de git config -l.)

EJEMPLOS

$ git var GIT_AUTHOR_IDENT
Eric W. Biederman <ebiederm@lnxi.com> 1121223278 -0600

VARIABLES

GIT_AUTHOR_IDENT

El autor de un fragmento de código.

GIT_COMMITTER_IDENT

La persona que introdujo un fragmento de código en Git.

GIT_EDITOR

Editor de texto para usar en comandos de Git. El valor está destinado a ser interpretado por el shell cuando se usa. Ejemplos: ~/bin/vi, $ALGUNA_VARIABLE_DE_ENTORNO, "C:\Program Files\Vim\gvim.exe" --nofork. El orden de preferencia es $GIT_EDITOR, luego el valor de configuración core.editor, luego $VISUAL, luego $EDITOR, y luego el predeterminado elegido en tiempo de compilación, que suele ser vi.

GIT_SEQUENCE_EDITOR

Editor de texto utilizado para editar el archivo todo mientras se ejecuta git rebase -i. Al igual que GIT_EDITOR, el valor está destinado a ser interpretado por el shell cuando se usa. El orden de preferencia es $GIT_SEQUENCE_EDITOR, luego el valor de configuración sequence.editor, y luego el valor de git var GIT_EDITOR.

GIT_PAGER

Visor de texto para usar en comandos de Git (por ejemplo, less). El valor está destinado a ser interpretado por el shell. El orden de preferencia es $GIT_PAGER, luego el valor de la configuración core.pager, luego $PAGER, y luego el predeterminado elegido en tiempo de compilación (normalmente less).

GIT_DEFAULT_BRANCH

El nombre de la primera rama creada en repositorios recién inicializados.

GIT_SHELL_PATH

La ruta al binario que proporciona el shell POSIX para los comandos que utilizan el shell.

GIT_ATTR_SYSTEM

La ruta al archivo gitattributes(5) del sistema, si hay uno habilitado.

GIT_ATTR_GLOBAL

La ruta al archivo gitattributes(5) global (por usuario).

GIT_CONFIG_SYSTEM

La ruta al archivo de configuración del sistema, si hay uno habilitado.

GIT_CONFIG_GLOBAL

La ruta a los archivos de configuración globales (por usuario), si los hay.

La mayoría de los valores de ruta contienen un solo valor. Sin embargo, algunos pueden contener varios valores, que están separados por saltos de línea y se enumeran en orden de mayor a menor prioridad. Los llamadores deben estar preparados para que cualquier valor de ruta de este tipo contenga varios elementos.

Tenga en cuenta que las rutas se imprimen incluso si no existen, pero no si están deshabilitadas por otras variables de entorno.
