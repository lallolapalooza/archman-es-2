NOMBRE

ginsh - Shell Interactivo de GiNaC

SINOPSIS

ginsh [archivo...]

DESCRIPCIÓN

ginsh es un frontend interactivo para el framework de cálculo simbólico GiNaC. Está destinado a ser una herramienta para probar y experimentar con las características de GiNaC, no como un reemplazo para los sistemas tradicionales de álgebra computacional interactivos. Aunque puede hacer muchas de las cosas que estos sistemas tradicionales pueden hacer, ginsh no proporciona construcciones de programación como bucles o expresiones condicionales. Si necesita esta funcionalidad, se le aconseja escribir su programa en C++, usando el framework de clases "nativo" de GiNaC.

USO

FORMATO DE ENTRADA

Después del inicio, ginsh muestra un prompt ("> ") que indica que está listo para aceptar su entrada. La entrada aceptable son expresiones numéricas o simbólicas que consisten en números (por ejemplo, 42, 2/3 o 0.17), símbolos (por ejemplo, x o resultado), operadores matemáticos como + y *, y funciones (por ejemplo, sin o normal). Cada expresión de entrada debe terminar con un punto y coma (;) o dos puntos (:). Si termina con un punto y coma, ginsh evaluará la expresión e imprimirá el resultado en stdout. Si termina con dos puntos, ginsh solo evaluará la expresión pero no imprimirá el resultado. Es posible introducir múltiples expresiones en una sola línea. El espacio en blanco (espacios, tabulaciones, saltos de línea) puede aplicarse libremente entre tokens. Para salir de ginsh, introduzca quit o exit, o escriba un EOF (Ctrl-D) en el prompt.

COMENTARIOS

Cualquier cosa que siga a una barra doble (//) hasta el final de la línea, y todas las líneas que comiencen con un signo de número (#) se tratan como un comentario y se ignoran.

NÚMEROS

ginsh acepta números en las notaciones decimales habituales. Esto incluye enteros y racionales de precisión arbitraria, así como números de punto flotante en notación estándar o científica (por ejemplo, 1.2E6). La regla general es que si un número contiene un punto decimal (.), es un número de punto flotante (inexacto); de lo contrario, es un entero o racional (exacto). Los enteros se pueden especificar en binario, octal, hexadecimal o base arbitraria (2-36) prefijándolos con #b, #o, #x, o #nR , respectivamente.

SÍMBOLOS

Los símbolos están formados por una cadena de caracteres alfanuméricos y el guion bajo (_), con el primer carácter siendo no numérico. Por ejemplo, a y mu_1 son nombres de símbolos aceptables, mientras que 2pi no lo es. Es posible usar símbolos con los mismos nombres que funciones (por ejemplo, sin); ginsh es capaz de distinguir entre los dos.

Los símbolos pueden asignarse valores introduciendo

símbolo = expresión;

Para desasignar el valor de un símbolo asignado, escriba

unassign('símbolo');

Los símbolos asignados se evalúan automáticamente (= se reemplazan por su valor asignado) cuando se usan. Para referirse al símbolo sin evaluar, ponga comillas simples (') alrededor del nombre, como se demostró para el comando "unassign" anterior.

Los símbolos se consideran en el dominio complejo de forma predeterminada, es decir, se tratan como si representaran números complejos. Este comportamiento se puede cambiar usando las palabras clave real_symbols y complex_symbols y afecta a todos los símbolos creados recientemente.

Los siguientes símbolos son constantes predefinidas que no pueden ser asignadas por el usuario:

Pi
Constante de Arquímedes
Catalan
Constante de Catalan
Euler
Constante de Euler-Mascheroni
I
sqrt(-1)
FAIL
un objeto de la clase "fail" de GiNaC

También existe el símbolo especial

Digits
que controla la precisión numérica de los cálculos con números inexactos. Asignar un valor entero a digits cambiará la precisión al número dado de decimales.

COMODINES

Las funciones has(), find(), match() y subs() aceptan comodines como marcadores de posición para expresiones. Estos tienen la sintaxis

$número
por ejemplo $0, $1 etc.

ÚLTIMAS EXPRESIONES IMPRESAS

ginsh proporciona los tres símbolos especiales

%, %% y %%%
que se refieren a la última, la penúltima y la antepenúltima expresión impresa, respectivamente. Son útiles si desea usar los resultados de cálculos anteriores en una nueva expresión.

Todos los operadores binarios son asociativos a la izquierda, con la excepción de ^ y = que son asociativos a la derecha. El resultado del operador de asignación (=) es su lado derecho, por lo que es posible asignar múltiples símbolos en una sola expresión (por ejemplo, a = b = c = 2;).

LISTAS

Las listas son usadas por las funciones subs y lsolve . Una lista consiste en una llave de apertura ({), una secuencia de expresiones separadas por comas (posiblemente vacía), y una llave de cierre (}).

MATRICES

Una matriz consiste en un corchete de apertura ([), una secuencia no vacía de filas de matriz separadas por comas, y un corchete de cierre (]). Cada fila de matriz consiste en un corchete de apertura ([), una secuencia no vacía de expresiones separadas por comas, y un corchete de cierre (]). Si las filas de una matriz no tienen la misma longitud, el ancho de la matriz se convierte en el de la fila más larga y las filas más cortas se rellenan al final con elementos de valor cero.

FUNCIONES

Una llamada a función en ginsh tiene la forma

nombre(argumentos)
donde argumentos es una secuencia de expresiones separadas por comas. ginsh proporciona algunas funciones incorporadas y también "importa" todas las funciones simbólicas definidas por GiNaC y bibliotecas adicionales. No hay manera de definir sus propias funciones aparte de vincular ginsh contra una biblioteca que defina funciones simbólicas de GiNaC.

ginsh proporciona autocompletado con Tab en los nombres de funciones: si escribe la primera parte de un nombre de función, pulsar Tab completará el nombre si es posible. Si la parte que escribió no es única, pulsar Tab de nuevo mostrará una lista de funciones coincidentes. Pulsar Tab dos veces en el prompt mostrará la lista de todas las funciones disponibles.

SPECIAL COMMANDS

To exit ginsh, enter

quit
or
exit

ginsh can display a (short) help for a given topic (mostly about functions and operators) by entering

?topic
Typing
??
will display a list of available help topics.

The command

print(expression);
will print a dump of GiNaC's internal representation for the given expression. This is useful for debugging and for learning about GiNaC internals.

The command

print_latex(expression);
prints a LaTeX representation of the given expression.

The command

print_csrc(expression);
prints the given expression in a way that can be used in a C or C++ program.

The command

iprint(expression);
prints the given expression (which must evaluate to an integer) in decimal, octal, and hexadecimal representations.

Finally, the shell escape

! [command [arguments]]
passes the given command and optionally arguments to the shell for execution. With this method, you can execute shell commands from within ginsh without having to quit.
