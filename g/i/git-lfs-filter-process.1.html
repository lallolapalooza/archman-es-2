NOMBRE

git-lfs-filter-process - Proceso de filtro de Git que convierte entre puntero y contenido real

SINOPSIS

git lfs filter-process
git lfs filter-process --skip

DESCRIPCIÓN

Implementa la API de proceso de filtro de Git, intercambiando mensajes de saludo y luego aceptando y respondiendo a las solicitudes para limpiar o ensuciar un archivo.

filter-process siempre es ejecutado por el proceso de filtro de Git, y está configurado por los atributos de Git del repositorio.

En tu configuración de Git o en un archivo .lfsconfig, puedes establecer lfs.fetchinclude y/o lfs.fetchexclude a listas separadas por comas de rutas. Si lfs.fetchinclude está definido, los archivos de puntero de Git LFS solo se reemplazarán con el contenido del archivo de objeto de Git LFS correspondiente si su ruta coincide con una en esa lista, y si lfs.fetchexclude está definido, los archivos de puntero de Git LFS solo se reemplazarán con el contenido del archivo de objeto de Git LFS correspondiente si su ruta no coincide con una en esa lista. Las rutas se comparan utilizando coincidencia de comodines según gitignore(5). Los archivos de puntero de Git LFS que no se reemplazan con el contenido de sus archivos de objeto correspondientes se copian simplemente a la salida estándar sin cambios.

El proceso de filtro utiliza el protocolo de línea de paquetes de Git para comunicarse, y está documentado en detalle en gitattributes(5).

OPCIONES

Sin opciones, filter-process acepta y responde a las solicitudes normalmente.

--skip

Omite la descarga automática de objetos al clonar o hacer pull.

GIT_LFS_SKIP_SMUDGE

Deshabilita el proceso de ensuciado. Para más información: git-lfs-config(5).

VER TAMBIÉN

git-lfs-clean(1), git-lfs-install(1), git-lfs-smudge(1), gitattributes(5), gitignore(5).

Parte de la suite git-lfs(1).
