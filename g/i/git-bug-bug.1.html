NOMBRE

git-bug-bug - Listar errores

SINOPSIS

git-bug bug [CONSULTA] [flags]

DESCRIPCIÓN

Muestra un resumen de cada error.

Puedes pasar una consulta adicional para filtrar y ordenar la lista. Esta consulta puede expresarse ya sea con un lenguaje de consulta simple, flags, una búsqueda de texto completo en lenguaje natural, o una combinación de lo anterior.

OPCIONES

-s, --status=[] Filtrar por estado. Los valores válidos son [abierto, cerrado]

-a, --author=[] Filtrar por autor

-m, --metadata=[] Filtrar por metadatos. Ejemplo: github-url=URL

-p, --participant=[] Filtrar por participante

-A, --actor=[] Filtrar por actor

-l, --label=[] Filtrar por etiqueta

-t, --title=[] Filtrar por título

-n, --no=[] Filtrar por ausencia de algo. Los valores válidos son [etiqueta]

-b, --by="creation" Ordenar los resultados por una característica. Los valores válidos son [id,creación,edición]

-d, --direction="asc" Seleccionar la dirección de ordenación. Los valores válidos son [asc,desc]

-f, --format="default" Seleccionar el estilo de formato de salida. Los valores válidos son [default,plain,id,json,org-mode]

-h, --help[=false] Ayuda para bug

EJEMPLO

Listar errores abiertos ordenados por última edición con una consulta:
git bug status:open sort:edit-desc
Listar errores cerrados ordenados por creación con flags:
git bug --status closed --by creation
Realizar una búsqueda de texto completo de todos los errores:
git bug "foo bar" baz
Usar consultas, flags y búsqueda de texto completo:
git bug status:open --by creation "foo bar" baz
