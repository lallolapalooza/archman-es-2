NOMBRE

git-annex-renameremote - cambia el nombre de un remoto especial

SINOPSIS

git annex renameremote nombre|uuid|desc nuevonombre

DESCRIPCIÓN

Cambia el nombre que se utiliza para habilitar un remoto especial.

Normalmente se utiliza el nombre actual para identificar el remoto especial a renombrar, pero también se puede utilizar su uuid o descripción.

Esto es especialmente útil cuando un antiguo remoto especial utilizaba un nombre, y ahora quieres usar ese nombre para un nuevo remoto especial. git annex initremote no te permitirá crear un remoto con un nombre conflictivo, así que renombra el antiguo remoto primero.


git annex renameremote telefono telefono-perdido
git annex initremote telefono ...

Esto solo actualiza el nombre que git-annex ha almacenado para ser utilizado por git annex enableremote. No actualiza la sección de configuración de git para el remoto especial para usar el nuevo nombre, pero por supuesto puedes editar la configuración de git si quieres renombrarlo allí.

OPCIONES

Las opciones-comunes-de-git-annex(1) pueden ser utilizadas.
