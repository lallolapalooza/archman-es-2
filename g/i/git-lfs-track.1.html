NOMBRE

git-lfs-track - Ver o añadir rutas de Git LFS a los atributos de Git

SINOPSIS

git lfs track [opciones] [<patrón>...]

DESCRIPCIÓN

Comienza a rastrear el(los) patrón(es) dados a través de Git LFS. El argumento se escribe en .gitattributes. Si no se proporcionan rutas, simplemente lista las rutas rastreadas actualmente.

La documentación de gitattributes https://git-scm.com/docs/gitattributes establece que los patrones utilizan las reglas de patrón de gitignore https://git-scm.com/docs/gitignore para coincidir con las rutas. Esto significa que los patrones que contienen asteriscos (*), signos de interrogación (?) y los caracteres de corchete ([ y ]) se tratan de forma especial; para deshabilitar este comportamiento y tratarlos literalmente en su lugar, usa --filename o escapa el carácter con una barra invertida.

OPCIONES

--verbose, -v

Si está habilitado, hace que git lfs track registre los archivos que tocará. Deshabilitado por defecto.

--dry-run, -d

Si está habilitado, hace que git lfs track registre todas las acciones que normalmente realizaría (añadir entradas a .gitattributes, tocar archivos en el disco, etc.) sin realizar ninguna operación mutativa en el disco.

git lfs track --dry-run [archivos] también simula implícitamente el comportamiento de pasar --verbose, y registrará con mayor detalle lo que está haciendo.

Deshabilitado por defecto.

--filename

Trata los argumentos como nombres de archivo literales, no como patrones. Cualquier carácter especial de comodín en el nombre del archivo se escapará al escribir el archivo .gitattributes.

--lockable, -l

Hace que las rutas sean 'bloqueables', lo que significa que deben bloquearse para editarlas y se volverán de solo lectura en la copia de trabajo cuando no estén bloqueadas.

--not-lockable

Elimina la bandera de bloqueable de las rutas para que ya no sean de solo lectura a menos que estén bloqueadas.

--no-excluded


No lista patrones que están excluidos en la salida; solo lista patrones que están rastreados. --no-modify-attrs: Hace que las entradas coincidentes estén marcadas como "stat-dirty" para que Git pueda reindexar los archivos que deseas convertir a LFS. No modifica ningún archivo .gitattributes.

EJEMPLOS

•Lista los patrones que Git LFS está rastreando actualmente:

git lfs track

•Configura Git LFS para rastrear archivos GIF:

git lfs track "*.gif"

•Configura Git LFS para rastrear archivos PSD y hacerlos de solo lectura a menos que estén bloqueados:

git lfs track --lockable "*.psd"

•Configura Git LFS para rastrear el archivo llamado project [1].psd:

git lfs track --filename "project [1].psd"

git-lfs-untrack(1), git-lfs-install(1), gitattributes(5), gitignore(5).
