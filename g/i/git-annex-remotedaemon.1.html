NOMBRE

git-annex-remotedaemon - comunicación persistente con remotos

SINOPSIS

git annex remotedaemon

DESCRIPCIÓN

El remotedaemon proporciona comunicación persistente con los remotos.

Se admiten varios tipos de remotos:

Para remotos ssh, el remotedaemon intenta mantener una conexión con el repositorio git remoto y utiliza git-annex-shell notifychanges para detectar cuándo ha cambiado el repositorio git remoto, y obtiene cambios de él. Para que esto funcione, el remoto git debe tener instalado git-annex-shell(1), con soporte para notifychanges. La primera versión de git-annex-shell que lo soporta es la 5.20140405.

Para remotos tor-annex, el remotedaemon ejecuta un servicio oculto de tor, aceptando conexiones de otros nodos y sirviendo el contenido del repositorio. Esto solo se hace si primero ejecutas git annex enable-tor. Usa git annex p2p para configurar el acceso a remotos tor-annex.

Para remotos p2p-annex, el remotedaemon ejecuta un comando git-annex-p2p-<netname> para obtener un archivo socket, escucha en el archivo socket las conexiones de otros pares y sirve el contenido del repositorio. Esto solo se hace si primero ejecutas git annex p2p --enable <netname>.

Ten en cuenta que cuando remote.<name>.annex-pull está configurado como falso, el remotedaemon evitará obtener cambios de ese remoto.

OPCIONES

--foreground
No te desdobles en segundo plano y comunícate en stdin/stdout utilizando un protocolo textual simple. El asistente ejecuta el remotedaemon de esta manera.
Los comandos del protocolo incluyen LOSTNET, que indica al remotedaemon que se ha perdido la conexión de red y hace que detenga cualquier conexión TCP. Esto puede ir seguido de RESUME cuando la conexión de red se restablece.
También se pueden utilizar las opciones comunes de git-annex(1).
