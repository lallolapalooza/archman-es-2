DESCRIPCIÓN

gio es una utilidad que pone a disposición muchas de las características de GIO desde la línea de comandos. Al hacerlo, proporciona comandos similares a las utilidades tradicionales, pero te permite usar ubicaciones de GIO en lugar de archivos locales: por ejemplo, puedes usar algo como smb://servidor/recurso/archivo.txt como ubicación.

Los nombres de archivo simples que contengan dos puntos se interpretarán como URIs con un protocolo desconocido. Para evitar esto, prefíjalos con una ruta como ./, o con el protocolo file:.

Los volúmenes, unidades y montajes se limitan a los que se consideran interesantes para el usuario, como unidades extraíbles. Los montajes del sistema no se mostrarán, lo que significa que la salida de gio mount no es equivalente a la salida de herramientas como fdisk, y gio monitor --mounts solo listará eventos relevantes para los montajes seleccionados.

COMANDOS

help COMANDO

Muestra una sinopsis corta de los comandos disponibles o proporciona ayuda detallada sobre un comando específico.

version

Imprime la versión de GLib a la que pertenece gio.

cat UBICACIÓN…

Concatena los archivos dados y los imprime en la salida estándar.

El comando cat funciona igual que la utilidad tradicional cat.

Nota: simplemente canaliza a través de cat si necesitas sus opciones de formato como -n, -T u otras.

copy [OPCIÓN…] FUENTE… DESTINO

Copia uno o más archivos de FUENTE a DESTINO. Si se especifica más de una fuente, el destino debe ser un directorio.

El comando copy es similar a la utilidad tradicional cp.

Opciones

-T, --no-target-directory

No copies en DESTINO aunque sea un directorio.

-p, --progress

Muestra el progreso.

-i, --interactive

Pregunta por confirmación antes de sobrescribir archivos.

--preserve

Preserva todos los atributos de los archivos copiados.

-b, --backup

Crea copias de seguridad de los archivos de destino existentes.

-P, --no-dereference

Nunca sigas enlaces simbólicos.

--default-permissions

Usa los permisos predeterminados del proceso actual para el archivo de destino, en lugar de copiar los permisos del archivo de origen.

info [OPCIÓN…] UBICACIÓN…

Muestra información sobre las ubicaciones dadas.

El comando info es similar a la utilidad tradicional ls.

Opciones

-w, --query-writable

Lista los atributos escribibles.

-f, --filesystem

Muestra información sobre el sistema de archivos en el que residen las ubicaciones dadas.

-a, --attributes=<ATRIBUTOS>

Los atributos a obtener.

Los atributos se pueden especificar con su nombre GIO, por ejemplo, standard::icon, o solo por el espacio de nombres, por ejemplo, unix, o por *, que coincide con todos los atributos. Se pueden especificar varios atributos o grupos de atributos, separados por comas.

Por defecto, se listan todos los atributos.

-n, --nofollow-symlinks

No sigas enlaces simbólicos.

launch ARCHIVO-ESCRITORIO [ARG-ARCHIVO…]

Inicia un archivo de escritorio desde cualquier ubicación dada.

El comando launch extiende el comportamiento del comando open al permitir iniciar cualquier archivo de escritorio, no solo aquellos registrados como manejadores de archivos.

list [OPCIÓN…] [UBICACIÓN…]

Lista el contenido de las ubicaciones dadas. Si no se da ninguna ubicación, se muestra el contenido del directorio actual.

El comando list es similar a la utilidad tradicional ls.

Opciones

-a, --attributes=<ATRIBUTOS>

Los atributos a obtener.

Los atributos se pueden especificar con su nombre GIO, por ejemplo, standard::icon, o solo por el espacio de nombres, por ejemplo, unix, o por *, que coincide con todos los atributos. Se pueden especificar varios atributos o grupos de atributos, separados por comas.

Por defecto, se listan todos los atributos.

-h, --hidden

Muestra archivos ocultos.

-l, --long

Usa un formato de lista larga.

-n, --nofollow-symlinks

No sigas enlaces simbólicos.

-d, --print-display-names

Imprime nombres de visualización.

-u, --print-uris

Imprime URIs completos.

mime TIPO-MIME [MANEJADOR]

Si no se proporciona un manejador, el comando mime lista las aplicaciones registradas y recomendadas para el tipo MIME. Si se proporciona un manejador, se establece como el manejador predeterminado para el tipo MIME.

Los manejadores deben especificarse por el nombre de su archivo de escritorio, incluida la extensión. Ejemplo: org.gnome.gedit.desktop.

mkdir [OPCIÓN…] UBICACIÓN…

Crea directorios.

El comando mkdir es similar a la utilidad tradicional mkdir.

Opciones

-p, --parent

Crea directorios padre cuando sea necesario.

Monitorea archivos o directorios para detectar cambios, como creación, eliminación, cambios de contenido y atributos, y operaciones de montaje y desmontaje que afecten a las ubicaciones monitoreadas.

El comando monitor utiliza las API de monitoreo de archivos de GIO para realizar su trabajo. GIO tiene diferentes implementaciones para diferentes plataformas. La implementación más común en Linux utiliza inotify.

mount [OPTION…] [LOCATIO

N…]
Proporciona acceso desde la línea de comandos a varios aspectos de la funcionalidad de montaje de GIO.

El montaje se refiere al concepto tradicional de organizar múltiples sistemas de archivos y dispositivos en un único árbol, con raíz en /. El montaje clásico ocurre en el kernel y es controlado por la utilidad mount. GIO expande este concepto introduciendo demonios de montaje que pueden hacer que los sistemas de archivos estén disponibles para las aplicaciones de GIO sin la intervención del

kernel.

Los montajes de GIO pueden requerir autenticación, y el comando mount puede pedir identificadores de usuario, contraseñas, etc., cuando sea

necesario.

trash [OPTION…] [LOCATIO

N…]
Envía archivos o directorios a la ‘Papelera’ o los restaura de la ‘Papelera’. Esta puede ser una carpeta diferente dependiendo de dónde se encuentre el archivo, y no todos los sistemas de archivos soportan este concepto. En el caso común de que el archivo se encuentre dentro del directorio de inicio de un usuario, la carpeta de la papelera es $XDG_DATA_HOME/Trash.

Tenga en cuenta que mover archivos a la papelera no libera espacio en el sistema de archivos hasta que la ‘Papelera’ se vacíe. Si está interesado en eliminar un archivo de forma irreversible, consulte el comando re

move.
