GIT-REMOTE-FD(1) Manual de Git GIT-REMOTE-FD(1)

NOMBRE

git-remote-fd - Reflejar el flujo de transporte inteligente de vuelta al llamador

SINOPSIS

"fd:<infd>[,<outfd>][/<cualquiercosa>]" (como URL)

DESCRIPCIÓN

Este ayudante utiliza descriptores de archivo especificados para conectarse a un servidor Git remoto. No está diseñado para usuarios finales, sino para programas y scripts que llaman a git fetch, push o archive.

Si solo se proporciona <infd>, se asume que es un socket bidireccional conectado a un servidor Git remoto (git-upload-pack, git-receive-pack o git-upload-archive). Si se proporcionan tanto <infd> como <outfd>, se asume que son tuberías conectadas a un servidor Git remoto (<infd> siendo la tubería de entrada y <outfd> siendo la tubería de salida).

Se asume que cualquier procedimiento de negociación ya se ha completado (como enviar la solicitud de servicio para git://) antes de que se inicie este ayudante.

<cualquiercosa> puede ser cualquier cadena. Se ignora. Está destinado a proporcionar información al usuario en la URL en caso de que esa URL se muestre en algún contexto.

VARIABLES DE ENTORNO

GIT_TRANSLOOP_DEBUG

Si está configurado, imprime información de depuración sobre varias lecturas/escrituras.

EJEMPLOS

git fetch fd::17 master

Obtener master, usando el descriptor de archivo #17 para comunicarse con git-upload-pack.

git fetch fd::17/foo master

Igual que el anterior.

git push fd::7,8 master (como URL)

Enviar master, usando el descriptor de archivo #7 para leer datos de git-receive-pack y el descriptor de archivo #8 para escribir datos al mismo servicio.

git push fd::7,8/bar master

Igual que el anterior.
