NOMBRE

git-lfs-uninstall - Eliminar la configuración de Git LFS

SINOPSIS

git lfs uninstall

DESCRIPCIÓN

Realiza las siguientes acciones para eliminar la configuración de Git LFS:

•Elimina los filtros de limpieza (clean) y empañado (smudge) de "lfs" de la configuración global de Git.
•Desinstala el hook pre-push de Git LFS si se ejecuta desde dentro de un repositorio Git.

OPCIONES

--local

Elimina los filtros de empañado (smudge) y limpieza (clean) de "lfs" de la configuración de Git del repositorio local, en lugar de la configuración global de Git (~/.gitconfig).

--worktree

Elimina los filtros de empañado (smudge) y limpieza (clean) de "lfs" de la configuración de Git del árbol de trabajo actual, en lugar de la configuración global de Git (~/.gitconfig) o la configuración del repositorio local ($GIT_DIR/config). Si se utilizan varios árboles de trabajo, la extensión de configuración de Git worktreeConfig debe estar habilitada para usar esta opción. Si solo se utiliza un árbol de trabajo, --worktree tiene el mismo efecto que --local. Esta opción solo está disponible si la versión instalada de Git es al menos 2.20.0 y, por lo tanto, admite la extensión "worktreeConfig".

--system

Elimina los filtros de empañado (smudge) y limpieza (clean) de "lfs" de la configuración del sistema de Git, en lugar de la configuración global de Git (~/.gitconfig).

--skip-repo

Omite la limpieza del repositorio local; úselo si desea desinstalar los filtros globales de lfs pero no realizar cambios en el repo actual.

VER TAMBIÉN

git-lfs-install(1), git-worktree(1).

Parte de la suite git-lfs(1).
