DESCRIPCIÓ

N

git difftool es un comando de Git que permite comparar y editar archivos entre revisiones usando herramientas de diff comunes. git difftool es una interfaz para git diff y acepta las mismas opciones y argumentos. Ver git-di

ff(
1).

OPCIONE

S

-d,

--dir-diff
Copia los archivos modificados a una ubicación temporal y realiza un diff de directorio sobre ellos. Este modo nunca solicita confirmación antes de lanzar la herramienta de
diff.

-y,

--no-prompt
No solicitar confirmación antes de lanzar una herramienta de
diff.

--promp

t
Solicitar confirmación antes de cada invocación de la herramienta de diff. Este es el comportamiento predeterminado; la opción se proporciona para anular cualquier
configuración.

--rotate-to=<archivo

>
Comenzar a mostrar el diff para la ruta dada, las rutas anteriores se moverán al final de la
salida.

--skip-to=<archivo

>
Comenzar a mostrar el diff para la ruta dada, omitiendo todas las rutas
anteriores.

-t <herramienta>, --tool=<herramient

a>
Usar la herramienta de diff especificada por <herramienta>. Los valores válidos incluyen emerge, kompare, meld y vimdiff. Ejecutar git difftool --tool-help para obtener la lista de ajustes válidos de <herramienta>.

Si no se especifica una herramienta de diff, git difftool usará la variable de configuración diff.tool. Si la variable de configuración diff.tool no está establecida, git difftool elegirá un valor predeterminado

adecuado.

Puedes proporcionar explícitamente una ruta completa a la herramienta estableciendo la variable de configuración difftool.<herramienta>.path. Por ejemplo, puedes configurar la ruta absoluta a kdiff3 estableciendo difftool.kdiff3.path. De lo contrario, git difftool asume que la herramienta está disponible en

PATH.

En lugar de ejecutar una de las herramientas de diff conocidas, git difftool puede personalizarse para ejecutar un programa alternativo especificando la línea de comandos a invocar en una variable de configuración difftool.<herramienta>.cm

d.

Cuando git difftool se invoca con esta herramienta (ya sea a través de la opción -t o --tool o la variable de configuración diff.tool) la línea de comandos configurada será invocada con las siguientes variables disponibles: $LOCAL se establece al nombre del archivo temporal que contiene el contenido de la pre-imagen del diff y $REMOTE se establece al nombre del archivo temporal que contiene el contenido de la post-imagen del diff. $MERGED es el nombre del archivo que se está comparando. $BASE se proporciona por compatibilidad con comandos personalizados de herramientas de fusión y tiene el mismo valor que $MER

GE
D.

--tool-hel

p
Imprimir una lista de herramientas de diff que pueden usarse con --tool
.

--symlinks,

--no-symlinks
El comportamiento predeterminado de git difftool es crear enlaces simbólicos al árbol de trabajo cuando se ejecuta en el modo --dir-diff y el lado derecho de la comparación produce el mismo contenido que el archivo en el árbol de trabajo.

Especificar --no-symlinks indica a git difftool que cree copias en su lugar. --no-symlinks es el valor

predeterminad
o en Windows.

-x <comando>, --extcmd=<comando

>
Especificar un comando personalizado para ver los diffs. git-difftool ignora los valores predeterminados configurados y ejecuta <comando> $LOCAL $REMOTE cuando se especifica esta opción. Además, $BASE se establece en el
entorno.

-g, --gui,

--no-gui
Cuando git-difftool se invoca con la opción -g o --gui la herramienta de diff predeterminada se leerá de la variable diff.guitool configurada en lugar de diff.tool. Esto puede seleccionarse automáticamente usando la variable de configuración difftool.guiDefault. La opción --no-gui puede usarse para anular estos ajustes. Si diff.guitool no está establecida, recurriremos en el orden de merge.guitool, diff.tool, merge.tool hasta que se encuentre una
herramienta.

--trust-exit-code, --no-trust-exit-cod

e
Los errores reportados por la herramienta de diff se ignoran por defecto. Usar --trust-exit-code para hacer que git-difftool salga cuando una herramienta de diff invocada devuelve un código de salida distinto de cero.

git-difftool reenviará el código de salida de la herramienta invocada cuando se use --trust-e

xit-c
ode.

Ver git-diff(1) para la lista com

pleta de opcion
es soportadas.

difftool.<herramienta>.

cmd
Especificar el comando para invocar la herramienta de diff especificada. El comando especificado se evalúa en el shell con las siguientes variables disponibles: LOCAL se establece al nombre del archivo temporal que contiene el contenido de la pre-imagen del diff y REMOTE se establece al nomarchivo temporal que contiene el contenido de la diferencia posterior a la imagen.

Consulte la opción --tool=<tool> en git-difftool(1) para más detalles.

difftool.<tool>.path

Anula la ruta para la herramienta dada. Esto es útil en caso de que su herramienta no esté en la RUTA.

difftool.trustExitCode

Sale de difftool si la herramienta de diferencia invocada devuelve un estado de salida distinto de cero.

Consulte la opción --trust-exit-code en git-difftool(1) para más detalles.

difftool.prompt

Pregunta antes de cada invocación de la herramienta de diferencia.

difftool.guiDefault

Establezca en true para usar diff.guitool por defecto (equivalente a especificar el argumento --gui), o en auto para seleccionar diff.guitool o diff.tool dependiendo de la presencia de un valor en la variable de entorno DISPLAY. El valor por defecto es false, donde el argumento --gui debe proporcionarse explícitamente para que se utilice diff.guitool.
