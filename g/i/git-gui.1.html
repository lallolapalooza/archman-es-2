GIT-GUI(1) Manual de Git GIT-GUI(1)

NOMBRE

git-gui - Una interfaz gráfica portable para Git

SINOPSIS

git gui [<comando>] [<argumentos>]

DESCRIPCIÓN

Una interfaz gráfica de usuario para Git basada en Tcl/Tk. git gui se enfoca en permitir a los usuarios realizar cambios en su repositorio creando nuevos commits, modificando los existentes, creando ramas, realizando merges locales y haciendo fetch/push a repositorios remotos.

A diferencia de gitk, git gui se enfoca en la generación de commits y la anotación de archivos individuales y no muestra el historial del proyecto. Sin embargo, proporciona acciones de menú para iniciar una sesión de gitk desde dentro de git gui.

Se sabe que git gui funciona en todos los sistemas UNIX populares, Mac OS X y Windows (tanto en Cygwin como en MSYS). En la medida de lo posible, se siguen las guías de interfaz de usuario específicas del sistema operativo, lo que hace que git gui sea una interfaz bastante nativa para los usuarios.

COMANDOS

blame

Inicia un visor de blame en el archivo especificado en la versión dada (o en el directorio de trabajo si no se especifica).

browser

Inicia un navegador de árbol que muestra todos los archivos en el commit especificado. Los archivos seleccionados a través del navegador se abren en el visor de blame.

citool

Inicia git gui y se organiza para realizar exactamente un commit antes de salir y regresar a la shell. La interfaz se limita solo a acciones de commit, reduciendo ligeramente el tiempo de inicio de la aplicación y simplificando la barra de menú.

version

Muestra la versión actualmente en ejecución de git gui.

EJEMPLOS

git gui blame Makefile

Muestra el contenido del archivo Makefile en el directorio de trabajo actual, y proporciona anotaciones tanto para el autor original de cada línea como para quién movió la línea a su ubicación actual. Se anota el archivo no confirmado, y los cambios no confirmados (si los hay) se atribuyen explícitamente a Aún No Confirmado.

git gui blame v0.99.8 Makefile

Muestra el contenido de Makefile en la revisión v0.99.8 y proporciona anotaciones para cada línea. A diferencia del ejemplo anterior, el archivo se lee de la base de datos de objetos y no del directorio de trabajo.

git gui blame --line=100 Makefile

Carga las anotaciones como se describe anteriormente y desplaza automáticamente la vista para centrarla en la línea 100.

git gui citool

Realiza un commit y regresa a la shell cuando se completa. Este comando devuelve un código de salida distinto de cero si la ventana se cerró de alguna manera que no fuera realizando un commit.

git gui citool --amend

Entra automáticamente en el modo Modificar último commit de la interfaz.

git gui citool --nocommit

Se comporta como un citool normal, pero en lugar de realizar un commit, simplemente termina con un código de salida cero. Aún verifica que el índice no contenga entradas sin fusionar, por lo que puedes usarlo como una versión GUI de git-mergetool(1)

git citool

Igual que git gui citool (arriba).

git gui browser maint

Muestra un navegador para el árbol de la rama maint. Los archivos seleccionados en el navegador se pueden ver con el visor de blame interno.

VER TAMBIÉN

gitk(1)

El navegador de repositorios de Git. Muestra ramas, historial de commits y diferencias de archivos. gitk es la utilidad iniciada por las acciones de Visualizar Repositorio de git gui.

OTRO

git gui se mantiene en realidad como un proyecto independiente, pero las versiones estables se distribuyen como parte de la suite Git para la conveniencia de los usuarios finales.

El repositorio oficial del proyecto git gui se puede encontrar en:

https://github.com/j6t/git-gui
