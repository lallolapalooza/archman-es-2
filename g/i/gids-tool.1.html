NOMBRE

gids-tool - utilidad de tarjeta inteligente para tarjetas GIDS

SINOPSIS

gids-tool [OPCIONES]

La utilidad gids-tool se puede usar desde la línea de comandos para realizar operaciones diversas con tarjetas inteligentes en una tarjeta inteligente GIDS.

OPCIONES

-X, --initialize

Inicializa el token.

--admin-key argumento

Define la clave del administrador

--pin pin

Esta opción se puede usar para especificar el valor del PIN en la línea de comandos. Si el valor se establece en env:VARIABLE, se usa el valor de la variable de entorno especificada. Por defecto, se solicita el código en la línea de comandos si es necesario.

Tenga en cuenta que en la mayoría de los sistemas operativos, cualquier usuario puede mostrar la línea de comandos de cualquier proceso en el sistema utilizando utilidades como ps(1). Por lo tanto, debe preferir pasar los códigos a través de una variable de entorno en un sistema no seguro.

--serial-number argumento

Define el número de serie.

-U, --unblock

Desbloquea el PIN de usuario después de una autenticación de administrador.

-C, --change-admin-key

Cambia la clave del administrador.

--new-admin-key argumento

Define la nueva clave del administrador.

--reader argumento, -r argumento

Número del lector a utilizar. Por defecto, se utiliza el primer lector con una tarjeta presente. Si argumento es un ATR, se elegirá el lector con una tarjeta coincidente.

-w, --wait

Espera a que se inserte una tarjeta.

-v, --verbose

Operación detallada. Úselo varias veces para habilitar la salida de depuración.
