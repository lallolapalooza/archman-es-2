NOMBRE

git-annex-dropunused - eliminar contenido de archivos no utilizado

SINOPSIS

git annex dropunused [número|rango ...]

DESCRIPCIÓN

Elimina los datos correspondientes a los números, tal como se enumeran en el último comando git annex unused.

También puedes especificar rangos de números, como "1-1000". O, especificar "all" para eliminar todos los datos no utilizados.

OPCIONES

--from=remoto
En lugar de eliminar los archivos no utilizados del repositorio local, elimínelos del repositorio remoto.
--force
¡Utiliza esta opción con cuidado! Evita las comprobaciones de seguridad y fuerza a git-annex a eliminar el contenido de los archivos especificados, incluso del último repositorio que está almacenando su contenido. El uso de esta opción puede provocar la pérdida de datos.
--jobs=N -JN
Ejecuta varios trabajos de eliminación en paralelo. Esto es particularmente útil cuando git-annex tiene que contactar con repositorios remotos para verificar si puede eliminar contenido. Por ejemplo: -J4
Establecer esto en "cpus" ejecutará un trabajo por núcleo de CPU.
--json
Habilita la salida JSON. Está pensada para ser analizada por programas que usan git-annex. Cada línea de salida es un objeto JSON.
--json-error-messages
Los mensajes que normalmente se mostrarían en la salida de error estándar se incluyen en el JSON en su lugar.
También se pueden usar las git-annex-common-options(1).
