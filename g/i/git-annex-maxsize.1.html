git-annex-maxsize(1) Manual de comandos generales git-annex-maxsize(1)

NOMBRE

git-annex-maxsize - configurar el tamaño máximo de un repositorio

SINOPSIS

git annex maxsize repositorio tamaño

git annex maxsize repositorio

git annex maxsize

DESCRIPCIÓN

Esto configura el tamaño combinado máximo de archivos anexados que pueden almacenarse en un repositorio. Cuando se ejecuta con un repositorio pero sin un tamaño, muestra el maxsize configurado actualmente. Cuando se ejecuta sin parámetros, muestra un resumen del tamaño y el maxsize de todos los repositorios.

El repositorio puede especificarse por nombre de remoto de git o por uuid. Para el repositorio actual, usa "here".

El tamaño puede especificarse usando cualquier unidad. Por ejemplo, "100 gigabytes" o "0.8TB".

Esto es solo orientativo, no impide que git-annex intente almacenar más datos en un repositorio. Cuando un repositorio tiene una expresión de contenido preferido configurada usando "balanced" o "sizebalanced", tendrá en cuenta el maxsize al verificar el contenido preferido. Todavía es posible que el maxsize sea excedido, por ejemplo, cuando hay varios escritores en el mismo repositorio.

Un límite de tamaño fijo para el repositorio debe aplicarse de alguna otra manera, por ejemplo, colocando el repositorio en una partición del tamaño deseado. Este comando puede usarse entonces para informar a git-annex sobre ese límite de tamaño.

Por ejemplo, si un repositorio git está en un disco de 1 terabyte, y es lo único almacenado en ese disco, y annex.diskreserve está configurado a 1 gigabyte, entonces tendría sentido ejecutar git-annex maxsize here "999 gigabytes"

Para dejar de verificar el tamaño máximo de un repositorio, establezca el maxsize a 0.

OPCIONES

--bytes
Muestra el tamaño máximo en bytes, deshabilitando las unidades más agradables por defecto.
--json
Habilita la salida JSON.
También se pueden usar las opciones comunes de git-annex (`git-annex-common-options(1)`).
