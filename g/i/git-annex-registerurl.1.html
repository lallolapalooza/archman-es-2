NOMBRE

git-annex-registerurl - registra una URL para una clave

SINOPSIS

git annex registerurl [clave url]

DESCRIPCIÓN

Este comando de nivel de fontanería se puede usar para registrar URL desde donde se puede descargar una clave.

No se realiza ninguna verificación del contenido de la URL.

Normalmente, la clave tiene un formato de clave git-annex. Sin embargo, para facilitar el uso de esto para añadir URL, si la clave no se puede analizar como una clave y es una URL válida, se construye una clave URL a partir de la URL.

Registrar una URL también hace que git-annex trate la clave como presente en el remoto especial que la reclama. (Normalmente el remoto especial web.)

OPCIONES

--remote=nombre|uuid
Indica que se espera que la URL sea reclamada por el remoto especificado. Si algún otro remoto reclama la URL en su lugar, registrarla fallará.
Nota: --remote=web evitará que cualquier otro remoto reclame la URL.
--batch
En el modo de entrada por lotes, las líneas se leen desde stdin y cada línea debe contener una clave y una URL, separadas por un solo espacio.
Por compatibilidad con versiones anteriores de git-annex antes de que se añadiera esta opción, cuando no se especifica un par clave y URL en la línea de comandos, se utiliza la entrada por lotes, igual que si se hubiera especificado la opción --batch. Sin embargo, se recomienda usar --batch.
-z
Cuando está en modo por lotes, la entrada se delimita con nulos en lugar de las nuevas líneas habituales.
(Nota: Para que esto se use, debes habilitar explícitamente el modo por lotes con --batch)
--json
Habilita la salida JSON. Está destinado a ser analizado por programas que utilizan git-annex. Cada línea de salida es un objeto JSON.
--json-error-messages
Los mensajes que normalmente se enviarían a la salida estándar de error se incluyen en el JSON en su lugar.
También se pueden usar las git-annex-common-options(1).
