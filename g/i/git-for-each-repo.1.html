NOMBRE

git-for-each-repo - Ejecuta un comando Git en una lista de repositorios

SINOPSIS

git for-each-repo --config=<config> [--] <argumentos>

DESCRIPCIÓN

Ejecuta un comando Git en una lista de repositorios. Los argumentos después de las opciones conocidas o el indicador -- se utilizan como argumentos para el subproceso de Git.

ESTE COMANDO ES EXPERIMENTAL. EL COMPORTAMIENTO PUEDE CAMBIAR.

Por ejemplo, podríamos ejecutar el mantenimiento en cada uno de una lista de repositorios almacenados en una variable de configuración maintenance.repo usando

git for-each-repo --config=maintenance.repo maintenance run

Esto ejecutará git -C <repo> maintenance run por cada valor <repo> en la variable de configuración multivaluada maintenance.repo.

OPCIONES

--config=<config>

Utiliza la variable de configuración dada como una lista multivaluada que almacena nombres de ruta absolutos. Itera sobre esa lista de rutas para ejecutar los argumentos dados.

Estos valores de configuración se cargan de la configuración de Git del sistema, global y local, según estén disponibles. Si git for-each-repo se ejecuta en un directorio que no es un repositorio Git, entonces solo se utiliza la configuración del sistema y global.

--keep-going

Continúa con los repositorios restantes si el comando falló en un repositorio. El código de salida aún indicará que la operación general no fue exitosa.

Tenga en cuenta que el código de salida exacto del comando fallido no se transmite como el código de salida del comando for-each-repo: si el comando falló en alguno de los repositorios especificados, el código de salida general será 1.

COMPORTAMIENTO DEL SUBPROCESO

Si algún subproceso git -C <repo> <argumentos> devuelve un código de salida distinto de cero, entonces el proceso git for-each-repo devuelve ese código de salida sin ejecutar más subprocesos.

Cada subproceso git -C <repo> <argumentos> hereda los descriptores de archivo estándar stdin, stdout y stderr.
