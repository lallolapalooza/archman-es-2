NOMBRE

git-annex-setpresentkey - cambia registros de dónde está presente la clave

SINOPSIS

git annex setpresentkey clave uuid [1|0]

DESCRIPCIÓN

Este comando de bajo nivel cambia los registros de git-annex sobre si el contenido de la clave especificada está presente en un remoto con el uuid especificado.

Use 1 para indicar que la clave está presente, o 0 para indicar que la clave no está presente.

OPCIONES

--batch
Habilita el modo batch, en el cual las líneas se leen desde stdin. El formato de la línea es "clave uuid [1|0]"
--json
Habilita la salida JSON. Esto está destinado a ser analizado por programas que utilizan git-annex. Cada línea de salida es un objeto JSON.
--json-error-messages
Los mensajes que normalmente se emitirían a la salida estándar de error se incluyen en el JSON en su lugar.
También se pueden usar las opciones comunes de git-annex(1).
