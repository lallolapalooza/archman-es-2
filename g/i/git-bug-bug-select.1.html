NOMBRE

git-bug-bug-select - Selecciona un error para su uso implícito en comandos futuros

SINOPSIS

git-bug bug select ID_DEL_ERROR [flags]

DESCRIPCIÓN

Selecciona un error para su uso implícito en comandos futuros.

Este comando te permite omitir cualquier argumento de ID de error, por ejemplo:
git bug show en lugar de
git bug show 2f153ca

El comando complementario es "git bug deselect", que realiza la operación opuesta.

OPCIONES

-h, --help[=false] Ayuda para select

EJEMPLO

git bug select 2f15
git bug comment
git bug status
