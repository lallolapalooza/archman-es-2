GIT-SHOW-INDEX(1) Manual de Git GIT-SHOW-INDEX(1)

NOMBRE

git-show-index - Muestra el índice del archivo empaquetado

SINOPSIS

git show-index [--object-format=<algoritmo-hash>] < <archivo-pack-idx>

DESCRIPCIÓN

Lee el archivo .idx para un archivo de paquete de Git (creado con git-pack-objects(1) o git-index-pack(1)) de la entrada estándar y muestra su contenido. La salida consta de un objeto por línea, y cada línea contiene dos o tres columnas separadas por espacios:

•la primera columna es el desplazamiento en bytes del objeto dentro del archivo de paquete correspondiente
•la segunda columna es el identificador del objeto
•si la versión del índice es 2 o superior, la tercera columna contiene el CRC32 de los datos del objeto

Los objetos se muestran en el orden en que se encuentran en el archivo de índice, que debería estar (en un archivo correctamente construido) ordenado por identificador de objeto.

Tenga en cuenta que puede obtener más información sobre un archivo de paquete llamando a git-verify-pack(1). Sin embargo, como este comando solo considera el archivo de índice en sí, es tanto más rápido como más flexible.

OPCIONES

--object-format=<algoritmo-hash>

Especifica el formato de objeto (algoritmo de hash) dado para el archivo de índice. Los valores válidos son sha1 y (si está habilitado) sha256. El valor predeterminado es el algoritmo para el repositorio actual (establecido por extensions.objectFormat), o sha1 si no se establece ningún valor o fuera de un repositorio.

Nota: Actualmente, no existe interoperabilidad entre los repositorios SHA-256 y los repositorios SHA-1.

Históricamente, advertimos que los repositorios SHA-256 podrían necesitar cambios incompatibles hacia atrás más adelante cuando introduzcamos dichas funciones de interoperabilidad. Hoy en día, solo esperamos cambios compatibles. Además, si resulta que dichos cambios son necesarios, se puede esperar que los repositorios SHA-256 creados con Git actual sean utilizables por versiones futuras de Git sin pérdida de datos.
