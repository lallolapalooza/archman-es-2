NOMBRE

git-annex-reinit - inicializar repositorio, reutilizando UUID antiguo

SINOPSIS

git annex reinit uuid|descripción

DESCRIPCIÓN

Normalmente, al inicializar un repositorio se genera un identificador único (UUID) nuevo para ese repositorio. Ocasionalmente puede ser útil reutilizar un UUID, por ejemplo, si un repositorio se eliminó y lo estás configurando de nuevo.

Utiliza esto con precaución; puede ser confuso tener dos repositorios existentes con el mismo UUID.

Asegúrate de ejecutar git annex fsck después de cambiar el UUID de un repositorio para asegurarte de que la información de seguimiento de ubicaciones se registre correctamente.

Al igual que git annex init, esto intenta habilitar cualquier remoto especial que esté configurado con autoenable=true.

OPCIONES

--json
Habilita la salida JSON. Está diseñado para ser analizado por programas que usan git-annex.
--json-error-messages
Los mensajes que normalmente se mostrarían en la salida estándar de error se incluyen en el JSON.
También se pueden usar las opciones comunes de git-annex(1).
