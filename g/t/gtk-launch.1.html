GTK-LAUNCH(1) Comandos de usuario GTK-LAUNCH(1)

NOMBRE

gtk-launch - Inicia una aplicación

SINOPSIS

gtk-launch [OPCIÓN...] APLICACIÓN [URI...]

DESCRIPCIÓN

gtk-launch inicia una aplicación usando el nombre dado. La aplicación se inicia con una notificación de inicio adecuada en una pantalla predeterminada, a menos que se especifique lo contrario.

gtk-launch toma al menos un argumento, el nombre de la aplicación a iniciar. El nombre debe coincidir con el nombre del archivo desktop de la aplicación, tal como se encuentra en /usr/share/application, con o sin el sufijo '.desktop'.

Si se llama con más de un argumento, el resto de ellos además del nombre de la aplicación se consideran ubicaciones URI y se pasan como argumentos a la aplicación iniciada.

OPCIONES

Se entienden las siguientes opciones:

-?, --help

Imprime un breve texto de ayuda y sale.

--version

Imprime la versión del programa y sale.
