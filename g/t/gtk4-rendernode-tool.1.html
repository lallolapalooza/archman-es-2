Nombre

gtk4-rendernode-tool - Utilidad de GskRenderNode

SINOPSIS

gtk4-rendernode-tool <COMANDO> [OPCIONES...] <ARCHIVO>
gtk4-rendernode-tool benchmark [OPCIONES...] <ARCHIVO>
gtk4-rendernode-tool compare [OPCIONES...] <ARCHIVO1> <ARCHIVO2>
gtk4-rendernode-tool convert [OPCIONES...] <ARCHIVO1>
gtk4-rendernode-tool extract [OPCIONES...] <ARCHIVO>
gtk4-rendernode-tool info [OPCIONES...] <ARCHIVO>
gtk4-rendernode-tool render [OPCIONES...] <ARCHIVO> [<ARCHIVO>]
gtk4-rendernode-tool show [OPCIONES...] <ARCHIVO>

DESCRIPCIÓN

gtk4-rendernode-tool puede realizar diversas operaciones en nodos de renderizado serializados.

COMANDOS

Información

El comando info muestra información general sobre el nodo de renderizado, como el número de nodos y la profundidad del árbol.

Mostrar

El comando show muestra el nodo de renderizado.

--offload

Coloca el nodo en un GraphicsOffload. Destinado a probar las capacidades de descarga de nodos de renderizado simples.

--undecorated

Elimina las decoraciones de la ventana. Esto está destinado a renderizar exactamente el nodo de renderizado sin ninguna barra de título.

Renderizado

El comando render guarda un renderizado del nodo de renderizado como una imagen png, tiff o svg o como un documento pdf. El nombre del archivo a escribir se puede especificar como un segundo argumento ARCHIVO.

--renderer=RENDERIZADOR

Utiliza el renderizador dado. Utiliza --renderer=help para obtener información sobre los valores posibles para RENDERIZADOR.

--dont-move

No cambies la posición del nodo, en relación con la cuadrícula de píxeles.

Benchmark

El comando benchmark realiza un benchmark del renderizado de un nodo con los renderizadores existentes e imprime los tiempos de ejecución.

--renderer=RENDERIZADOR

Añade el renderizador dado. Este argumento se puede pasar varias veces para probar múltiples renderizadores. Por defecto, se ejecutan todos los renderizadores principales de GTK.

--runs=EJECUCIONES

Número de veces que se renderiza el nodo en cada renderizador. Por defecto, son 3 veces. Ten en cuenta que la primera ejecución a menudo se utiliza para poblar cachés y puede ser significativamente más lenta.

--no-download

No intentes descargar el resultado. Esto puede hacer que la medición no incluya la ejecución de los comandos en la GPU. Puede ser útil usar esta bandera para probar el rendimiento de la presentación de comandos.

Comparar

El comando compare compara el renderizado de un nodo con una imagen de referencia, o los renderizados de dos nodos, o dos imágenes. Si se encuentran diferencias, el código de salida es 1. Si las imágenes son idénticas, es 0.

--renderer=RENDERIZADOR

Utiliza el renderizador dado.

--output=ARCHIVO

Guarda las diferencias como una imagen png en ARCHIVO.

--quiet

No escribas resultados en la salida estándar.

Convertir

El comando convert convierte un icono SVG simbólico en un nodo y escribe el resultado en la salida estándar.

--recolor

Si se utiliza esta opción, el nodo resultante tendrá sus colores simbólicos reemplazados por los valores dados a las opciones --fg, --success, --warning y --error. De lo contrario, el nodo tendrá los colores sin reemplazar, lo que puede ser útil para diagnosticar problemas de renderizado.

--fg=COLOR --success=COLOR --warning=COLOR --error=COLOR

Establece los colores simbólicos para recolorear el icono. Si no se especifican, se utilizan colores predeterminados.

--size=TAMAÑO

Establece el tamaño al que se renderizará el icono. El tamaño puede ser un número o una cadena de la forma ANCHOxALTO.

Extraer

El comando extract guarda todas las URLs de datos encontradas en un archivo de nodo en un directorio dado. Los nombres de archivo para los archivos extraídos se derivan del tipo MIME de la URL.

--dir=DIRECTORIO

Guarda los archivos extraídos en DIRECTORIO (por defecto, el directorio actual).
