gtkgreet(1) Manual de comandos generales gtkgreet(1)

NOMBRE

gtkgreet - Un greeter gráfico basado en Gtk para greetd

SINOPSIS

gtkgreet [opciones]

OPCIONES

-h, --help

Muestra el mensaje de ayuda y sale.

-c, --command <comando>

Especifica el comando a ejecutar en caso de inicio de sesión exitoso. gtkgreet preguntará si no se especifica ninguno.

-l, --layer-shell

Utiliza wlr-layer-shell para mostrar una ventana en cada salida. Debe estar habilitado en tiempo de compilación.

-b, --background

Especifica una imagen de fondo que será utilizada por gtkgreet. Se sabe que JPG y PNG funcionan. La imagen se anclará a la esquina superior izquierda y se renderizará 1:1 cuando la escala DPI sea 1.

Nota: Esto no maneja correctamente los valores de escala distintos de 1. Utilice una hoja de estilos para una representación de fondo más flexible y correcta.

-s, --style <archivo.css>

Especifica una hoja de estilos CSS personalizada con estilos adicionales para la ventana de gtkgreet. Consulte https://developer.gnome.org/gtk3/stable/theming.html para ver la descripción del subconjunto de CSS compatible con GTK.

Nota: Esto no puede cargar hojas de estilos de temas de Gtk, y es solo para modificaciones a nivel de aplicación. Para seleccionar un tema, use los mecanismos habituales de selección de temas de Gtk.

DESCRIPCIÓN

gtkgreet es un greeter gráfico basado en Gtk para greetd(1).

gtkgreet permite la selección de la aplicación a iniciar al iniciar sesión. Consulte la sección DE ENTORNO para obtener más información sobre cómo configurar las opciones proporcionadas. El usuario también puede especificar la aplicación directamente al iniciar sesión escribiendo la línea de comandos deseada.

gtkgreet requiere un compositor Wayland para ejecutarse, como cage(1) o sway(1).

CONFIGURACIÓN

Para usar gtkgreet, configure un compositor Wayland de su elección para que sea su greeter. Haga que el compositor inicie gtkgreet y, lo que es importante, que se cierre a sí mismo una vez que gtkgreet termine.

Usando cage, la línea de comandos simplemente se convierte en "cage gtkgreet".

Usando sway(1), se puede usar una configuración de sway que contenga "exec 'gtkgreet; swaymsg exit'", y una línea de comandos similar a "sway --config /etc/greetd/sway-config". El componente "; swaymg exit" es importante, ya que hace que sway termine una vez que gtkgreet haya finalizado un inicio de sesión.

Consulte greetd(5) para obtener información sobre cómo configurar greetd. Lea la documentación de su compositor elegido para obtener información sobre cómo usarlo correctamente.

ESTILIZADO

La hoja de estilos se puede utilizar para modificar el estilo de los elementos de gtkgreet, como el fondo de la ventana, las fuentes, el contenedor del cuadro de diálogo de inicio de sesión y otros.

Se puede ver un ejemplo de hoja de estilos aquí:

window {
        background-image: url("file:///etc/greetd/gtkgreet-background.jpg");
        background-size: cover;
        background-position: center;
}
box#body {
        background-color: rgba(50, 50, 50, 0.5);
        border-radius: 10px;
        padding: 50px;
}

ENTORNOS

gtkgreet popula las opciones de usuario para las aplicaciones a iniciar al iniciar sesión utilizando tanto un archivo de configuración como el argumento de línea de comandos '-c'.

El archivo de configuración se lee desde /etc/greetd/environments, y es una lista de opciones separadas por saltos de línea, cada una siendo una línea de comandos a ejecutar al iniciar sesión si se selecciona.
