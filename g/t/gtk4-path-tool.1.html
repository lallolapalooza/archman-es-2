DESCRIPCIÓN
gtk4-path-tool
puede realizar varias tareas en rutas. Las rutas
    se especifican en sintaxis SVG, como cadenas como "M 100 100 C 100 200 200
    200 200 100 Z".
Para leer una ruta desde un archivo, use un nombre de archivo que comience con un '.'
    o un '/'. Para leer una ruta desde stdin, use '-'.
