Nombre

gtk4-demo - Demostrar widgets de GTK

SINOPSIS

gtk4-demo [OPCIONES...]

DESCRIPCIÓN

gtk4-demo es una colección de ejemplos.

Su propósito es demostrar muchos widgets de GTK de una forma útil para los desarrolladores de aplicaciones.

La aplicación muestra el código fuente de cada ejemplo, así como otros recursos utilizados, como archivos de descripción de interfaz de usuario y recursos de imagen.

OPCIONES

-h, --help

Muestra las opciones de ayuda.

--version

Muestra la versión del programa.

--list

Lista los ejemplos disponibles.

--run EJEMPLO

Ejecuta el ejemplo nombrado. Usa --list para ver los ejemplos disponibles.

--autoquit

Sale después de un breve tiempo de espera. Esto está pensado para su uso con --run, por ejemplo, al perfilar.
