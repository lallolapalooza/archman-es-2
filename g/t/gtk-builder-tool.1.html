NOMBRE

gtk-builder-tool - Utilidad de archivos GtkBuilder

SINOPSIS

gtk-builder-tool [COMANDO] [OPCIÓN...] ARCHIVO

DESCRIPCIÓN

gtk-builder-tool puede realizar varias operaciones en archivos .ui de GtkBuilder.

Siempre debes probar los archivos .ui modificados producidos por gtk-builder-tool antes de usarlos en producción.

COMANDOS

Se entienden los siguientes comandos:

validate

Valida el archivo .ui e informa de errores a stderr.

simplify

Simplifica el archivo .ui eliminando propiedades que están establecidas en sus valores predeterminados y escribe el XML resultante en stdout, o de vuelta al archivo de entrada.

enumerate

Lista todos los objetos con nombre que se crean en el archivo .ui.

preview

Previsualiza el archivo .ui. Este comando acepta opciones para especificar el ID de un objeto y un archivo .css a usar.

OPCIONES SIMPLIFY

El comando simplify acepta las siguientes opciones:

--replace

Escribe el contenido de vuelta al archivo .ui en lugar de stdout.

OPCIONES PREVIEW

El comando preview acepta las siguientes opciones:

--id=ID

El ID del objeto a previsualizar. Si no se especifica, gtk-builder-tool elegirá un objeto adecuado por sí mismo.

--css=ARCHIVO

Carga la información de estilo del archivo .css dado.
