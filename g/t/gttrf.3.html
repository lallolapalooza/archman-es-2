CGTTRF

Propósito:

!>
!> CGTTRF calcula una factorización LU de una matriz tridiagonal compleja A
!> usando eliminación con pivoteo parcial e intercambios de filas.
!>
!> La factorización tiene la forma
!>    A = L * U
!> donde L es un producto de matrices de permutación y bidiagonales inferiores unitarias
!> y U es triangular superior con elementos distintos de cero solo en la diagonal principal
!> y las dos primeras superdiagonales.
!>

Parámetros

N 
!>          N es INTEGER
!>          El orden de la matriz A.
!>

DL

!>          DL es un arreglo COMPLEX, dimensión (N-1)
!>          Al entrar, DL debe contener los (n-1) elementos de subdiagonal de
!>          A.
!>
!>          Al salir, DL es sobrescrito por los (n-1) multiplicadores que
!>          definen la matriz L de la factorización LU de A.
!>

D

!>          D es un arreglo COMPLEX, dimensión (N)
!>          Al entrar, D debe contener los elementos de la diagonal de A.
!>
!>          Al salir, D es sobrescrito por los n elementos de la diagonal de la
!>          matriz triangular superior U de la factorización LU de A.
!>

DU

!>          DU es un arreglo COMPLEX, dimensión (N-1)
!>          Al entrar, DU debe contener los (n-1) elementos de superdiagonal
!>          de A.
!>
!>          Al salir, DU es sobrescrito por los (n-1) elementos de la primera
!>          superdiagonal de U.
!>

DU2

!>          DU2 es un arreglo COMPLEX, dimensión (N-2)
!>          Al salir, DU2 es sobrescrito por los (n-2) elementos de la
!>          segunda superdiagonal de U.
!>

IPIV

!>          IPIV es un arreglo INTEGER, dimensión (N)
!>          Los índices de pivote; para 1 <= i <= n, la fila i de la matriz fue
!>          intercambiada con la fila IPIV(i).  IPIV(i) siempre será o bien
!>          i o i+1; IPIV(i) = i indica que no se requirió un intercambio de filas.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -k, el k-ésimo argumento tenía un valor ilegal
!>          > 0:  si INFO = k, U(k,k) es exactamente cero. La factorización
!>                se ha completado, pero el factor U es exactamente
!>                singular, y ocurrirá una división por cero si se usa
!>                para resolver un sistema de ecuaciones.
!>

NAME


gttrf - computes an LU factorization of a real/complex tridiagonal matrix

    INTEGER INFO







Detailed Description


SGTTRF computes an LU factorization of a real tridiagonal matrix A
    using elimination with partial pivoting and row interchanges.


The factorization has the form


    A = P * L * U



where P is a permutation matrix, L is a unit lower bidiagonal
    matrix with at most one nonzero subdiagonal, and U is an upper
    triangular matrix with nonzeros in only the main diagonal and the first
    two superdiagonals.


ZGTTRF computes an LU factorization of a complex tridiagonal matrix A
    using elimination with partial pivoting and row interchanges.


The factorization has the form


    A = L * U



where L is a product of permutation and unit lower bidiagonal
    matrices and U is upper triangular with nonzeros in only the main
    diagonal and first two superdiagonals.

subroutine   sgttrf (integer n, real, dimension( * ) dl, real,   dimension( * ) d, real, dimension( * ) du, real, dimension( * ) du2, integer,   dimension( * ) ipiv, integer info)


SGTTRF


Purpose:




!>
!> SGTTRF computes an LU factorization of a real tridiagonal matrix A
!> using elimination with partial pivoting and row interchanges.
!>
!> The factorization has the form
!>    A = P * L * U
!> where P is a permutation matrix, L is a unit lower bidiagonal
!> matrix with at most one nonzero subdiagonal, and U is an upper
!> triangular matrix with nonzeros in only the main diagonal and the
!> first two superdiagonals.
!> 




Parameters


N

!>          N is INTEGER
!>          The order of the matrix A.
!> 


DL


!>          DL is REAL array, dimension (N-1)
!>          On entry, DL must contain the (n-1) sub-diagonal elements of
!>          A.
!>
!>          On exit, DL is overwritten by the (n-1) multipliers that
!>          define the matrix L from the LU factorization of A.
!> 


D


!>          D is REAL array, dimension (N)
!>          On entry, D must contain the diagonal elements of A.
!>
!>          On exit, D is overwritten by the n diagonal elements of the
!>          upper triangular matrix U from the LU factorization of A.
!> 


DU


!>          DU is REAL array, dimension (N-1)
!>          On entry, DU must contain the (n-1) super-diagonal elements
!>          of A.
!>
!>          On exit, DU is overwritten by the (n-1) elements of the first
!>          super-diagonal of U.
!> 


DU2


!>          DU2 is REAL array, dimension (N-2)
!>          On exit, DU2 is overwritten by the (n-2) elements of the
!>          second super-diagonal of U.
!> 


IPIV


!>          IPIV is INTEGER array, dimension (N)
!>          The pivot indices; for 1 <= i <= n, row i of the matrix was
!>          interchanged with row IPIV(i).  IPIV(i) will always be either
!>          i or i+1; IPIV(i) = i indicates a row interchange was not
!>          required.
!> 


INFO


!>          INFO is INTEGER
!>          = 0:  successful exit
!>          < 0:  if INFO = -k, the k-th argument had an illegal value
!>          > 0:  if INFO = k, U(k,k) is exactly zero. The factorization
!>                has been completed, but the factor U is exactly
!>                singular, and division by zero will occur if it is used
!>                to solve a system of equations.
!>
