gtklock(1) Manual de Comandos Generales gtklock(1)

NOMBRE

gtklock - Pantalla de bloqueo basada en GTK para Wayland

SINOPSIS

gtklock [opciones...]

OPCIONES

-h, --help

Muestra las opciones de ayuda

--help-config

Muestra las opciones disponibles en la configuración. Véase CONFIGURACIÓN.

-d, --daemonize

Desconecta del terminal de control.

-c, --config <ruta>

Especifica el archivo de configuración a usar. Por defecto, las siguientes rutas se verifican en el siguiente orden: $XDG_CONFIG_HOME/gtklock/config.ini y gtklock/config.ini bajo cada directorio en $XDG_CONFIG_DIRS.

CONFIGURACIÓN

La configuración se almacena en formato de archivo de claves glib. Las opciones se especifican como nombre=valor y se pueden usar desde la línea de comandos como --nombre=valor. Todas las opciones deben estar bajo el grupo principal.

Todas las opciones disponibles son:

-g, --gtk-theme <cadena>

Establece el tema GTK.

-s, --style <ruta>

Carga el archivo de estilo CSS.

-x, --layout <ruta>

Carga el archivo de diseño XML.

-m, --modules <nombre>

Carga módulos de gtklock. El nombre del módulo puede ser una ruta absoluta, una ruta relativa (que comience con ./ o ../) o un nombre en el directorio del sistema (como example-module.so para /usr/lib/gtklock/example-module.so). Se puede omitir el sufijo .so.

-b, --background <ruta>

Carga el fondo. El fondo especificado puede ser sobrescrito por CSS.

-t, --time-format <cadena>

Establece el formato de la hora. Véase date(1).

-d, --date-format <cadena>

Establece el formato de la fecha. Véase date(1).

-f, --follow-focus

Sigue el foco entre monitores. Puede no funcionar para todos los compositores, recomendado para hyprland.

-H, --idle-hide

Oculta el formulario de entrada cuando está inactivo.

-T, --idle-timeout <entero>

Tiempo de espera de inactividad en segundos.

-S, --start-hidden

Inicia con el formulario de entrada oculto.

-L, --lock-command

Comando a ejecutar después de bloquear. El comando se ejecuta de forma asíncrona.

-U, --unlock-command

Comando a ejecutar después de desbloquear. El comando se ejecuta de forma asíncrona.

-M, --monitor-priority <nombre>

Establece la prioridad de foco del monitor. La opción se puede especificar varias veces.

EJEMPLO

Configuración de ejemplo:

[main]
gtk-theme=Adwaita-dark

Estilo de ejemplo:

window {
   background-image: url("background.png");
   background-size: cover;
   background-repeat: no-repeat;
   background-position: center;
   background-color: black;
}
