GTAGS(1) Manual de Comandos Generales GTAGS(1)

NOMBRE

gtags - crea archivos de etiquetas para global

SINOPSIS

gtags [-ciIOqvw][-C dir][-d tag-file][-f file][dbpath]

DESCRIPCIÓN

Gtags se utiliza para crear archivos de etiquetas para global(1).

Gtags recopila recursivamente archivos fuente bajo el directorio actual, extrae símbolos y escribe los datos de referencia cruzada en los archivos de etiquetas (´GTAGS´, ´GRTAGS´ y ´GPATH´).

Por defecto, gtags extrae archivos fuente de C, Yacc, lenguaje ensamblador, Java, C++ y PHP. Los archivos cuyos nombres terminan en ´.c´, ´.h´ se asumen como archivos fuente de C. Los archivos cuyos nombres terminan en ´.y´ se asumen como archivos fuente de Yacc. Los archivos cuyos nombres terminan en ´.s´, ´.S´ se asumen como archivos fuente de lenguaje ensamblador. Los archivos cuyos nombres terminan en ´.java´ se asumen como archivos fuente de Java. Los archivos cuyos nombres terminan en ´.c++´, ´.cc´, ´.hh´, ´.cpp´, ´.cxx´, ´.hxx´, ´.hpp´, ´.C´, ´.H´ se asumen como archivos fuente de C++. Los archivos cuyos nombres terminan en ´.php´, ´.php3´, ´.phtml´ se asumen como archivos fuente de PHP. Otros archivos se asumen como archivos de texto. Gtags no trata archivos binarios.

Si ´gtags.files´ existe en el directorio actual o se especifica un archivo con la opción -f, los archivos de destino se limitan por él. Las líneas que comienzan con ´. ´ son comentarios.

OPCIONES

Las siguientes opciones están disponibles:

--accept-dotfiles
Acepta archivos y directorios cuyos nombres comienzan con un punto. Por defecto, gtags los ignora.
-c, --compact
Genera ´GTAGS´ en formato compacto. Esta opción no influye en ´GRTAGS´, ya que siempre se genera en formato compacto.
-C, --directory dir
Cambia el directorio antes de realizar todo el trabajo, incluido el análisis de parámetros. Esta opción se ignora en GTAGS_OPTIONS. Por favor, especifíquela directamente en la línea de comandos.
--config[=name]
Imprime el valor de la variable de configuración name. Si no se especifica name, imprime todos los nombres y valores. Adicionalmente, puede referirse al nombre del directorio donde está instalado el sistema como variables de solo lectura: bindir, libdir, datadir, localstatedir y sysconfdir.
-d, --dump tag-file
Exporta un archivo de etiquetas como texto a la salida estándar. El formato de salida es 'clave<tab>datos'. Esto es para depuración.
--explain
Explica el manejo de archivos.
-f, --file file
Proporciona una lista de candidatos de archivos de destino. Los archivos que no están en la lista se ignoran. El argumento file puede establecerse a ´-´ para aceptar una lista de archivos desde la entrada estándar. Los nombres de archivo deben separarse por saltos de línea. Para crear la lista puede usar find(1), que tiene opciones ricas para seleccionar archivos.
--gtagsconf file
Establece la variable de entorno GTAGSCONF a file.
--gtagslabel label
Establece la variable de entorno GTAGSLABEL a label.
--help
Imprime un mensaje de uso.
-I, --idutils
Además de los archivos de etiquetas, crea una base de datos ID para idutils(1).
-i, --incremental
Actualiza los archivos de etiquetas de forma incremental. Es mejor usar global(1) con el comando -u.
-O, --objdir
Utiliza el directorio de objetos estilo BSD como ubicación de los archivos de etiquetas. Si GTAGSOBJDIRPREFIX está establecido y el directorio ´$GTAGSOBJDIRPREFIX´ existe, gtags crea el directorio ´$GTAGSOBJDIRPREFIX/<directorio actual>´ y genera los archivos de etiquetas en él. Aunque puede usar MAKEOBJDIRPREFIX en lugar de GTAGSOBJDIRPREFIX, está obsoleto. Si se especifica dbpath, esta opción se ignora.
--single-update file
Actualiza los archivos de etiquetas para un solo archivo. Se considera que file fue añadido, actualizado o eliminado, y no hay cambios en otros archivos. Esta opción implica la opción -i.
--skip-unreadable
Omite los archivos no legibles.
--skip-symlink [=type]
Omite los enlaces simbólicos. Si type es 'f' entonces omite solo los enlaces simbólicos para archivos, si es 'd' entonces omite solo los enlaces simbólicos para directorios. El valor por defecto de type es 'a' (todos los enlaces simbólicos).
--sqlite3
Utiliza la API de Sqlite 3 para crear archivos de etiquetas. Por defecto, se utiliza la API de BSD/DB 1.85. Para usar esta opción, necesita invocar el script de configuración con --with-sqlite3 durante la fase de compilación.
--statistics
Imprime información estadística.
-q, --quiet
Modo silencioso.
-v, --verbose
Modo detallado.
--version
Muestra el número de versión.
-w, --warning
Imprime mensajes de advertencia.
dbpath
El directorio en el que se generan los archivos de etiquetas. El valor por defecto es el directorio actual.

EJEMPLOS

$ ls -F
Makefile      src/    lib/
$ gtags -v
$ global -x main
main              10 src/main.c  main (argc, argv) {

ARCHIVOS

´GTAGS´
Archivo de etiquetas para definiciones.
´GRTAGS´
Archivo de etiquetas para referencias.
´GPATH´
Archivo de etiquetas para archivos fuente.
´gtags.conf´, ´$HOME/.globalrc´
Datos de configuración para GNU Global. Ver gtags.conf(5).
´gtags.files´
La lista de candidatos de archivos de destino.
´.notfunction´
La lista de símbolos que no son una definición. Si este archivo existe en el directorio raíz del proyecto, gtags no considera los símbolos listados en este archivo como definiciones. Las líneas que comienzan con ';' son líneas de comentario.

ENTORNO

Las siguientes variables de entorno afectan la ejecución de gtags:

GTAGSCACHE
El tamaño de la caché del árbol B. El valor por defecto es 50000000 (bytes).
GTAGSCONF
Archivo de configuración.
GTAGSFORCECPP
Si esta variable está establecida, cada archivo cuyo sufijo es ´.h´ se analiza de forma forzada por el analizador C++ incorporado. No establezca esta variable si está utilizando analizadores complementarios. Esta variable y el analizador C++ incorporado están obsoletos.
GTAGSFORCEENDBLOCK
Si esta variable está establecida, cada } en la primera columna provoca el fin de un bloque de nivel 0.
GTAGSLABEL
Etiqueta de configuración. El valor por defecto es

#x00B4;default´.
GTAGSLOGGING
Si esta variable está configurada, ´$GTAGSLOGGING´ se utiliza como el nombre de la ruta de un archivo de registro. No hay valor por defecto.
GTAGS_COMMANDLINE
Esta variable solo se puede referenciar desde el hook (ver gtags_hook). Gtags establece su propia línea de comandos efectiva en esta variable antes de llamar al hook. Cada argumento está separado por espacios en blanco, y el espacio en blanco real se representa como '%20'. Esto es de solo lectura.
GTAGS_OPTIONS
El valor de esta variable se inserta en la cabecera de los argumentos.
GTAGSOBJDIR
Si esta variable está configurada, se utiliza como el nombre del objdir estilo BSD. El valor por defecto es ´obj´. Aunque puedes usar MAKEOBJDIR en lugar de GTAGSOBJDIR, está obsoleto.
GTAGSOBJDIRPREFIX
Si esta variable está configurada, se utiliza como el prefijo del objdir estilo BSD. El valor por defecto es ´/usr/obj´. Aunque puedes usar MAKEOBJDIRPREFIX en lugar de GTAGSOBJDIRPREFIX, está obsoleto.
TMPDIR
La ubicación utilizada para almacenar archivos temporales. El valor por defecto es ´/tmp´.

CONFIGURACIÓN

Las siguientes variables de configuración afectan la ejecución de gtags. Puedes ver el valor por defecto para cada variable con la opción --config.

gtags_parser (lista separada por comas)
Especifica el mapeo de nombres de lenguajes y parsers de plugins. Cada parte delimitada por la coma consta de un nombre de lenguaje, dos puntos, la ruta del objeto compartido, dos puntos opcionales seguidos de un nombre de función. Si no se especifica el nombre de la función, se asume 'parser'. Como excepción especial, gtags recopila valores de múltiples variables gtags_parser. Para estos mapeos, se adopta la primera coincidencia.
gtags_hook (línea de comandos)
Especifica una línea de comandos que debe ejecutarse al principio de gtags después de cargar el archivo de configuración. Puedes usar este hook para actualizar ´gtags.files´ dinámicamente. "./" en él siempre significa el directorio raíz del proyecto, ya que gtags siempre se invoca allí.

Este hook se ignora cuando se especifican las siguientes opciones: --version, --help, --config, --dump.

icase_path (booleano)
Ignora las distinciones de mayúsculas y minúsculas en la ruta. La verificación de sufijos se ve afectada por esta capacidad.
langmap (lista separada por comas)
Mapeo de lenguajes. Cada mapa separado por comas consta de un nombre de lenguaje, dos puntos y una lista de extensiones de archivo. Puedes especificar un patrón glob rodeado de paréntesis en lugar de una extensión para los archivos sin extensiones (por ejemplo, Make:([Mm]akefile).mak.mk). Como excepción especial, gtags recopila valores de múltiples variables langmap. Para estos mapeos, se adopta la primera coincidencia. El mapeo por defecto es:
´c:.c.h,yacc:.y,asm:.s.S,java:.java,cpp:.c++.cc.hh.cpp.cxx.hxx.hpp.C.H,php:.php.php3.phtml´.
skip (lista separada por comas)
Gtags omite archivos y directorios que se encuentran en esta lista. Como excepción especial, gtags recopila valores de múltiples variables skip. Si el valor termina con ´/´, se asume como un directorio y gtags omite todos los archivos bajo él. El valor puede incluir patrones glob (*, ?, [...], [!...], [^...]).

Si el valor comienza con ´/´, se asume como un nombre de ruta relativo desde el directorio raíz del proyecto. No puedes usar patrones glob para un nombre de ruta. Sin embargo, esta dirección está desactualizada y no se recomienda. En su lugar, puedes usar la opción -f que se puede combinar con find(1). Dado que find(1) tiene opciones ricas para seleccionar archivos, puedes hacer todo. Adicionalmente, esta técnica también se puede aplicar a cualquier otro sistema de etiquetado como ctags(1), cscope(1), etc.

La lista de omisión también es efectiva cuando usas la opción -f o ´gtags.files´.

EJEMPLOS

#
# Hay varias formas de usar el parser de plugin Universal Ctags.
#
$ gtags --gtagsconf=/usr/local/share/gtags/gtags.conf --gtagslabel=universal-ctags
$ gtags --explain
o
$ export GTAGSCONF=/usr/local/share/gtags/gtags.conf
$ export GTAGSLABEL=universal-ctags
$ gtags --explain
o
# En tu proyecto
$ cp /usr/local/share/gtags/gtags.conf .
$ vi gtags.conf		# default:tc=native => default:tc=universal-ctags
$ gtags --explain

DIAGNÓSTICOS

Gtags sale con un valor distinto de 0 si ocurrió un error, 0 en caso contrario.

Ten en cuenta que los archivos creados por gtags con un código de salida distinto de cero deben considerarse corruptos.

VER TAMBIÉN

global(1), htags(1), gtags.conf(5).

Sistema de etiquetas de código fuente GNU Global
(http://www.gnu.org/software/global/).

ERRORES

´GTAGS´ y ´GRTAGS´ son muy grandes. Antes de usar este comando, verifica el espacio en tu disco.

El soporte para lenguaje ensamblador está lejos de ser completo. Extrae solo ENTRY() y ALTENTRY() del archivo fuente. Probablemente solo sea válido para el código fuente de FreeBSD y Linux.

El soporte para C++ está obsoleto.

No hay control de concurrencia sobre los archivos de etiquetas.
