GTAGS.CONF(5) Manual de formatos de archivo GTAGS.CONF(5)

NOMBRE

gtags.conf - datos de configuración para GNU Global

SINOPSIS

´gtags.conf´
´~/.globalrc´

DESCRIPCIÓN

´gtags.conf´ contiene datos de configuración para global(1), gozilla(1), gtags(1) y htags(1). Buscan los siguientes archivos en este orden y leen del primero que exista y sea legible.

(1) --gtagsconf archivo
(2) $GTAGSCONF
(3) [raíz del proyecto]/gtags.conf
(4) [raíz del proyecto]/[directorio obj]/gtags.conf
(5) $HOME/.globalrc
(6) /etc/gtags.conf
(7) [sysconfdir]/gtags.conf

[sysconfdir] es ´/usr/local/etc´ por defecto; puedes cambiarlo con la opción --sysconfdir del script configure. [directorio obj] es ´obj´ por defecto; puedes cambiarlo con GTAGSOBJDIR o MAKEOBJDIR.

Su sintaxis es similar a la de termcap(5) excepto por algunas extensiones descritas más adelante. Un archivo incluye uno o más registros. Debes seleccionar un registro usando una etiqueta. La etiqueta por defecto es ´default´. Si se establece GTAGSLABEL, se usa su valor. Ten en cuenta que el significado de ´default´ es diferente al de termcap(5).

Las líneas que empiezan con ´#´ se ignoran. Un registro consta de uno o más campos separados por ´:´ y termina con un salto de línea. El primer campo debe tener un nombre de etiqueta. Cada uno de los restantes campos tiene una definición de variable. Hay tres tipos de variables.

Booleano: Este tipo no tiene valor; la existencia de la variable significa verdadero, de lo contrario falso.
Número: Este tipo tiene un valor numérico después de ´#´.
Cadena: Este tipo tiene un valor de cadena después de ´=´.
La mayoría de las variables son de tipo cadena.

Si los datos incluyen ´:´ o un salto de línea, necesitas escaparlos con ´\´. Se permite un campo vacío, pero no tiene sentido.

Cuando hay más de una definición, se adopta la anterior. Excepcionalmente, todos los valores de skip, langmap y gtags_parser se adoptan y conectan respectivamente.

Sustitución de variables

La sustitución de variables similar a la de sh(1) está disponible. Puedes referirte a cualquier variable de cadena usando el prefijo ´$´. Por ejemplo, la siguiente b tiene el valor ´XYZ´.

:a=Y:b=X${a}Z:

Inclusión de otro registro

Tc es una variable especial; lee definiciones de otro registro. Es similar a la tc de termcap(5). Su sintaxis es la siguiente:
tc=etiqueta[@archivo]
Si solo se da una etiqueta, tc se lee de un registro especificado por la etiqueta en el mismo archivo. Si también se da @archivo, tc se lee de un registro especificado por la etiqueta en el archivo especificado. Archivo debe ser una ruta absoluta y no debe incluir variables. A diferencia de termcap(5), puedes usar tc en cualquier momento y en cualquier lugar.

CONFIGURACIÓN

Para las variables de cada comando, consulta el manual correspondiente.

Puedes usar las siguientes variables de entorno como variables de cadena. Si estas variables se establecen, las variables de entorno del mismo nombre se establecen antes de la ejecución del comando.
GREP_COLOR
GREP_COLORS
GTAGSBLANKENCODE
GTAGSCACHE
GTAGSFORCECPP
GTAGSGLOBAL
GTAGSGTAGS
GTAGSLIBPATH
GTAGSLOGGING
GTAGSTHROUGH
GTAGS_OPTIONS
HTAGS_OPTIONS
MAKEOBJDIR
MAKEOBJDIRPREFIX
TMPDIR

Las siguientes variables también están disponibles como variables de cadena. Por defecto, cada una de ellas tiene una ruta de directorio dada por el script configure.
bindir
datadir
libdir
localstatedir
sysconfdir

ENTORNO

Las siguientes variables de entorno afectan la ejecución de los comandos.

GTAGSCONF
Si esta variable está establecida, su valor se utiliza como archivo de configuración.
GTAGSLABEL
Si esta variable está establecida, su valor se utiliza como etiqueta del archivo de configuración. El valor por defecto es default.

global(1), gozilla(1), gtags(1), htags(1).
