GTKWAVERC(5) Archivo de configuración de GTKWave GTKWAVERC(5)

NOMBRE

gtkwaverc - Archivo de configuración de GTKWave

SINTAXIS

opción <valor>

El archivo de configuración es una serie de pares de opción y valor. Se permiten líneas de comentario marcadas con el carácter inicial '#'. Las líneas en blanco se ignoran.

DESCRIPCIÓN

Archivo de configuración para gtkwave(1). La ruta de búsqueda para el archivo de configuración (si no se especifica) es el directorio de trabajo actual seguido del directorio de inicio del usuario.

OPCIONES

accel <"pathvalue" accelerator>
Esto permite la sustitución de las teclas aceleradoras del menú. Consulte el archivo .gtkwaverc en la distribución de código fuente para ver ejemplos de la sintaxis de pathvalue y accelerator. El valor especial de accelerator (null) significa que no hay ninguna aceleradora vinculada al elemento del menú.
alt_hier_delimeter <value>
Esto permite usar otro carácter además de hier_delimeter para delimitar niveles en la jerarquía para VCD. Solo el primer carácter del valor es significativo. Tenga en cuenta que normalmente está desactivado. El uso previsto es resolver las jerarquías de modelos basados en netlist que a menudo contienen barras para delimitar la jerarquía dentro de las declaraciones $var.
alt_wheel_mode <value>
El valor predeterminado está activado. La rueda del ratón sola desplaza un cuarto de página a la vez en lugar de una página completa, para que no se pierda. Ctrl+rueda acerca/aleja alrededor de la posición del cursor del ratón, no la posición del marcador. Alt+rueda desplaza a la izquierda/derecha basándose en la señal seleccionada actualmente. Esto hace que sea más fácil medir los deltas.
analog_redraw_skip_count <value>
Especifica cuántos segmentos analógicos superpuestos se pueden dibujar para una posición X determinada en la pantalla. (Predeterminado: 20) Si hay huecos en las trazas analógicas, este valor es demasiado bajo.
append_vcd_hier <value>
Permite la especificación de una jerarquía de prefijo para los archivos VCD. Esto se puede hacer en "partes", de modo que se antepongan múltiples capas de jerarquía a los nombres de símbolos, siendo la adición más significativa la que ocurre primero (consulte .gtkwaverc en el directorio examples/vcd). El uso previsto de esto es tener la capacidad de añadir prefijos de "proyecto" que permitan una selección más fácil de todo desde la jerarquía del árbol.
atomic_vectors <value>
Acelera la carga de vcd y ocupa menos memoria. Esta opción está obsoleta; actualmente es la predeterminada.
autocoalesce <value>
Un valor distinto de cero habilita la coalescencia automática de los vectores VCD cuando corresponda. Esto se puede alternar dinámicamente durante el uso del visor de ondas.
autocoalesce_reversal <value>
hace que los vectores divididos se reconstruyan en orden inverso (solo si autocoalesce también está activo).
autoname_bundles <value>
Un valor distinto de cero indica que GTKWave creará sus propios nombres de paquete en lugar de pedírselos al usuario.
clipboard_mouseover <value>
Un valor distinto de cero indica que, cuando el mouseover está habilitado, todos los valores generados para las descripciones emergentes se copiarán automáticamente al portapapeles para que puedan pegarse en otros programas como editores de texto, etc.
color_0 <value>
color de la traza cuando es 0.
color_1 <value>
color de la traza cuando es 1.
color_1fill <value>
color de la traza (dentro de la caja) cuando es 1.
color_back <value>
color de fondo.
color_baseline <value>
color del marcador del botón central del ratón.
color_black <value>
valor de color para "negro" en la ventana de señales.
color_brkred <value>
color rojo ladrillo para los comentarios.
color_dash <value>
color de la traza cuando es indeterminado ("-").
color_dashfill <value>
color de la traza (dentro de la caja) cuando es indeterminado ("-").
color_dkblue <value>
valor de color para "azul oscuro" en la ventana de señales.
color_dkgray <value>
valor de color para "gris oscuro" en la ventana de señales.
color_gmstrd <value>
valor de color para los agrupamientos de trazas.
color_grid <value>
color de la cuadrícula (use Alt-G/Shift-Alt-G para mostrar/ocultar la cuadrícula). Este es también el color utilizado para highlight_wavewindow cuando está habilitado.
color_grid2 <value>
color de la cuadrícula para la búsqueda de patrones secundaria.
color_high <value>
color de la traza cuando es alta ("H").
color_highfill <value>
color de la traza (dentro de la caja) cuando es alta ("H").
color_low <value>
color de la traza cuando es baja ("L").
color_ltblue <value>
color para trazas con sombra.
color_ltgray <value>
valor de color para "gris claro" en la ventana de señales.
color_mark <value>
color de los marcadores con nombre.
color_mdgray <value>
valor de color para "gris medio" en la ventana de señales.
color_mid <value>
color de la traza cuando está flotando ("Z").
color_normal <value>
valor de color para el estado GTK "normal" en la ventana de señales.
color_time <value>
color del texto para la barra de tiempo.
color_timeb <value>
color del texto para el fondo de la barra de tiempo.
color_trans <value>
color de la traza cuando está en transición.
color_u <value>
color de la traza cuando es indefinida ("U").
color_ufill <value>
color de la traza (dentro de la caja) cuando es indefinida ("U").
color_umark <value>
color del marcador (principal) sin nombre.
color_value <value>
<dd>color de texto para valores de vector.
color_vbox <value>
color de vector (horizontal).
color_vtrans <value>
color de vector (verticales/transiciones).
color_w <value>
color de traza cuando es débil ("W").
color_wfill <value>
color de traza (dentro de la caja) cuando es débil ("W").
color_white <value>
valor de color para "blanco" en la ventana de señales.
color_x <value>
color de traza cuando es indefinido ("X") (colisión para VHDL).
color_xfill <value>
color de traza (dentro de la caja) cuando es indefinido ("X") (colisión para VHDL).
constant_marker_update <value>
Un valor distinto de cero indica que los valores de las trazas listadas en la ventana de señales deben actualizarse constantemente mientras se mantiene presionado el botón izquierdo del ratón, en lugar de solo cuando se presiona por primera vez y luego al soltar (que es el comportamiento predeterminado).
context_tabposition <value>
Use cero para una visualización con pestañas con nombres en la parte superior. Un valor distinto de cero coloca pestañas con índice numérico a la izquierda.
convert_to_reals <value>
Convierte todas las declaraciones VCD de enteros y parámetros en valores reales cuando se establece en un valor distinto de cero/sí. El aspecto positivo de esto es que los enteros y parámetros ocuparán menos espacio en la memoria y se mostrarán automáticamente en formato decimal. El aspecto negativo es que los enteros y parámetros solo se podrán mostrar como decimales y no se pueden invertir bits, invertir, etc.
cursor_snap <value>
Un valor distinto de cero indica el número de píxeles al que el marcador debe ajustarse para la transición de señal más cercana.
disable_ae2_alias <value>
Un valor distinto de cero indica que el cargador AE2 debe ignorar la palabra clave aliasdb y no debe construir alias de instalación.
disable_auto_comphier <value>
Un valor distinto de cero indica que los cargadores que admiten jerarquías comprimidas no deben activar automáticamente la compresión si se ha alcanzado el umbral de conteo de señales (500000).
disable_empty_gui <value>
Un valor distinto de cero indica que si se invoca gtkwave sin un nombre de archivo de volcado, entonces una sesión de gtkwave vacía debe suprimirse. El valor predeterminado es cero: para abrir una sesión vacía que necesita que se cargue o arrastre un archivo en ella.
disable_mouseover <value>
Un valor distinto de cero indica que las burbujas emergentes de información sobre señales/valores al presionar botones del ratón deben desactivarse en la ventana de valores. Un valor cero indica que las informaciones sobre valores deben estar activas (el valor predeterminado es desactivado).
disable_tooltips <value>
Un valor distinto de cero indica que las burbujas emergentes de información deben desactivarse. Un valor cero indica que la información debe estar activa (predeterminado).
do_initial_zoom_fit <value>
Un valor distinto de cero indica que la traza debe comprimirse inicialmente para ajustarse a la pantalla. Un valor cero indica que el zoom inicial debe ser cero (predeterminado).
dragzoom_threshold <value>
Un valor distinto de cero indica el número de píxeles en la dirección x que el marcador debe moverse para que se active un arrastre de zoom. Esto es principalmente para manejar dispositivos de entrada ruidosos.
dynamic_resizing <value>
Un valor distinto de cero indica que el redimensionamiento dinámico debe estar activado inicialmente (predeterminado). Un valor cero indica que el redimensionamiento dinámico debe estar desactivado inicialmente.
editor <"value">
Esto se usa para especificar una cadena (las comillas son obligatorias) para cuando gtkwave invoca un editor de texto (p. ej., Open Source Definition). Ejemplos son: editor "vimx -g +%d %s", editor "gedit +%d %s", editor "emacs +%d %s", y para OSX, editor "mate -l %d %s". El %d puede combinarse con otros caracteres en una cadena como +, etc. El argumento %s debe estar por sí solo. Tenga en cuenta que si esta variable rc no está configurada, a continuación se consultará la variable de entorno GTKWAVE_EDITOR, y finalmente se utilizará gedit (si se encuentra).
enable_fast_exit <value>
Permite salir sin mostrar un solicitante de confirmación. El valor predeterminado es distinto de cero/sí.
enable_ghost_marker <value>
permite al usuario activar/desactivar el marcador fantasma durante el arrastre del marcador principal. El valor predeterminado es activado.
enable_horiz_grid <value>
Un valor distinto de cero indica que cuando el dibujado de la cuadrícula está habilitado, deben dibujarse líneas horizontales. Este es el valor predeterminado.
enable_vcd_autosave <value>
hace que el cargador vcd genere automáticamente un archivo .sav (vcd_autosave.sav) en el directorio de trabajo actual si no se especifica un archivo de guardado en la línea de comandos. Tenga en cuenta que esto refleja las definiciones $var de VCD y no se intenta coalescer vectores de bits divididos de nuevo.
enable_vert_grid <value>
Un valor distinto de cero indica que cuando el dibujado de la cuadrícula está habilitado, deben dibujarse líneas verticales. Este es el valor predeterminado. Tenga en cuenta que todas las combinaciones posibles de valores de enable_horiz_grid y enable_vert_grid son aceptables.
fill_waveform <value>
Un valor cero indica que la forma de onda no debe rellenarse para los valores 1/H. Este es el valor predeterminado.
fontname_logfile <value>
Cuando va seguido de un argumento, esto indica el nombre de la fuente X11 que desea usar para el navegador de archivos de registro. Puede generar nombres de fuente apropiados usando el programa xfontsel.
fontname_signals <value>
Cuando va seguido de un argumento, esto indica el nombre de la fuente X11 que desea usar para las señales. Puede generar nombres de fuente apropiados usando el programa xfontsel.
fontname_waves <value>
Cuando va seguido de un argumento, esto indica el nombre de la fuente X11 que desea usar para las ondas. Puede generar nombres de fuente apropiados usando el programa xfontsel. Tenga en cuenta que la fuente de señales debe ser más alta que la fuente de ondas o el visor se quejará y terminará.
force_toolbars <value>
Cuando está habilitado, esto fuerza todo lo que está encima de las ventanas de señales y ondas a renderizarse como barras de herramientas. Esto permite que se puedan separar, lo que permite más espacio útil para el visor de ondas. Por defecto, esto está desactivado.
hide_sst <value>
Oculta el widget de Árbol de Búsqueda de Señales para GTK2.4 y superior de modo que no esté incrustado en la ventana principal del visor. Aún se puede acceder a él como un widget externo a través de los menús.
hier_delimeter <value>
Esto permite usar caracteres distintos de '/' para delimitar niveles en la jerarquía. Solo el primer carácter del valor es significativo.
hier_grouping <value>
Para los widgets de árbol, esto permite agrupar las jerarquías en un solo lugar en lugar de dispersarlas entre los nombres de red.
hier_ignore_escapes <value>
Un valor distinto de cero indica que el panel de señales ignora las secuencias de escape en los identificadores al determinar la profundidad máxima de la jerarquía. El valor predeterminado es desactivado para que se examinen las secuencias de escape.
hier_max_level <value>
Establece la profundidad máxima de la jerarquía (desde el lado derecho) para mostrar en los nombres de las trazas. Tenga en cuenta que un valor de cero muestra el nombre de la jerarquía completo.
highlight_wavewindow <value>
Cuando está habilitado, esto hace que las trazas resaltadas en la ventana de señales también se resalten en la ventana de ondas.
hpane_pack <value>
Un valor distinto de cero indica que el panel horizontal debe construirse usando las funciones gtk_paned_pack (predeterminado y recomendado). Un valor cero indica que se usará gtk_paned_add en su lugar.
ignore_savefile_pane_pos <value>
Si es distinto de cero, especifica que los atributos de posición del panel (es decir, el tamaño de ancho de la ventana de señales, si la SST está expandida, etc.) deben ignorarse durante la carga del archivo de guardado y deben omitirse durante el guardado. El valor predeterminado es que el atributo se utilice.
ignore_savefile_pos <value>
Si es distinto de cero, especifica que el atributo de posición de la ventana debe ignorarse durante la carga del archivo de guardado y debe omitirse durante el guardado. Por defecto, se utiliza el atributo de posición.
ignore_savefile_size <value>
Si es distinto de cero, especifica que el atributo de tamaño de la ventana debe ignorarse durante la carga del archivo de guardado y omitirse durante el guardado. Por defecto, se utiliza el atributo de tamaño.
initial_signal_window_width <value>
Establece el ancho de creación para el panel de señales en la inicialización de la GUI. También establece otro valor mínimo potencial para el redimensionamiento dinámico.
initial_window_x <value>
Establece el ancho inicial de la ventana del visor de ondas. Los valores menores o iguales a cero establecerán el ancho inicial igual a -1, lo que permitirá que GTK determine el tamaño mínimo.
initial_window_xpos <value>
Establece la coordenada x inicial de la ventana del visor de ondas. -1 permitirá que el gestor de ventanas determine la posición.
initial_window_y <value>
Establece la altura inicial de la ventana del visor de ondas. Los valores menores o iguales a cero establecerán el ancho inicial igual a -1, lo que permitirá que GTK determine el tamaño mínimo.
initial_window_ypos <value>
Establece la coordenada y inicial de la ventana del visor de ondas. -1 permitirá que el gestor de ventanas determine la posición.
keep_xz_colors <value>
Cuando es distinto de cero, indica que se debe usar el esquema de color original para los valores de señal que no son 0/1 cuando están activas las anulaciones de Formato de Color. Por defecto, está desactivado.
left_justify_sigs <value>
Cuando es distinto de cero, indica que la justificación del nombre de la señal en la ventana de señales debe ser a la izquierda por defecto; de lo contrario, la justificación es a la derecha (por defecto).
lxt_clock_compress_to_z <value>
Para LXT (no LXT2), permite que los relojes se compriman en un valor 'z' para que se puedan notar cambios de valor regulares/periódicos.
lz_removal <value>
Cuando es distinto de cero, suprime la visualización de ceros a la izquierda en trazas no filtradas. Esto no tiene efecto en las trazas filtradas.
max_fsdb_trees <value>
establece el número máximo de jerarquías y árboles de señales a procesar para un archivo FSDB. Predeterminado = 0 = ilimitado. La intención de esto es sortear entornos de simulación que accidentalmente llaman a fsdbDumpVars varias veces.
page_divisor <value>
Establece la cantidad de desplazamiento para las operaciones de página izquierda y derecha. (Los botones, no la barra de desplazamiento horizontal.) Los valores superiores a 1.0 se toman como 1/x y los valores iguales o inferiores a 1.0 se toman literalmente. (Es decir, 2 da un desplazamiento de media página y .67 da 2/3). El valor predeterminado es 1.0.
ps_maxveclen <value>
establece el número máximo de caracteres que se pueden imprimir para un valor en la parte de la ventana de señales de un archivo postscript (sin incluir el nombre de la red en sí). Los valores legales van del 4 al 66 (predeterminado).
ruler_origin <value>
establece el origen cero para las marcas de tiempo alternativas.
ruler_step <value>
establece el valor de paso izquierda/derecha para las marcas de tiempo alternativas desde el origen. Cuando este valor es cero, las marcas de tiempo alternativas están deshabilitadas.
scale_to_time_dimension <value>
El valor puede ser cualquiera de los caracteres m, u, n, f, p o s, lo que indica a qué dimensión de tiempo convertir los valores de tiempo. El valor predeterminado para esto es *, lo que significa que la conversión de la dimensión de tiempo está deshabilitada.
show_base_symbols <value>
Un valor distinto de cero (predeterminado) indica que los símbolos de base numérica para hexadecimal ('$'), binario ('%') y octal ('#') deben renderizarse. De lo contrario, se omitirán.
show_grid <value>
Un valor distinto de cero (predeterminado) indica que se debe dibujar una cuadrícula detrás de las trazas. Un cero indica que no se debe dibujar ninguna cuadrícula.
splash_disable <value>
Desactivar esto habilita la pantalla de presentación con la mascota de GTKWave al cargar una traza. Por defecto, está activado.
sst_dbl_action_type <value>
Permite que el doble clic esté activo en el panel de señales de la SST con las siguientes acciones posibles: insertar (predeterminado), reemplazar, añadir al final, añadir al principio, ninguno. El valor especificado para la acción no distingue entre mayúsculas y minúsculas y solo se requiere la primera letra. Los tipos de acción no válidos se establecen por defecto en ninguno.
sst_dynamic_filter <value>
Cuando es verdadero (predeterminado), permite que el filtro de señales del diálogo SST filtre las señales mientras se presionan las teclas; de lo contrario, se debe presionar Intro para que el filtro se active.
sst_expanded <value>
Cuando es verdadero, permite que el diálogo SST (cuando no está oculto) aparezca ya expandido.
strace_repeat_count <value>
Determina cuántas veces la búsqueda de bordes y la búsqueda de patrones iterarán en una búsqueda. Esto permite, por ejemplo, saltar 10 bordes de reloj en lugar de 1.
use_big_fonts <value>
Un valor distinto de cero indica que cualquier texto renderizado en la ventana de ondas usará fuentes cuatro puntos más grandes que el tamaño normal. Esto puede mejorar la legibilidad. Un valor cero indica que se deben usar tamaños de fuente normales.
use_fat_lines <value>
Un valor distinto de cero indica que cualquier línea renderizada en la ventana de ondas tendrá dos píxeles de ancho en lugar de un solo píxel. Esto puede mejorar la legibilidad. Un valor cero indica que se deben usar anchos de línea normales.
use_frequency_delta <value>
le permite alternar entre la visualización del tiempo delta y la de frecuencia en la esquina superior derecha de la ventana principal al medir distancias entre marcadores. El comportamiento predeterminado es que se muestre el tiempo delta (desactivado).
use_gestures <value>
si lo admite la versión de GTK, habilitará gestos como el deslizamiento en la ventana de ondas. El valor predeterminado es que esta función esté habilitada si hay una pantalla táctil disponible (el valor es "maybe"). También se permiten los valores "on" o "off".
use_full_precision <value>
no redondea los valores de tiempo cuando el número de ticks por píxel en pantalla es mayor que 10 cuando está activo. El valor predeterminado es que esta función esté deshabilitada.
use_maxtime_display <value>
Un valor distinto de cero indica que el tiempo máximo se mostrará en la esquina superior derecha de la pantalla. De lo contrario, se mostrará el tiempo del marcador principal actual (sin nombre). Esto se puede alternar en cualquier momento con la opción de menú "Toggle Max-Marker".
use_nonprop_fonts <value>
Permite redibujos acelerados de la ventana de señales que se pueden hacer porque el ancho de la fuente es constante. Por defecto, está desactivado.
use_pango_fonts <value>
Usa fuentes pango antialiasadas (GTK2) en lugar de las de mapa de bits de X11. Por defecto, está activado.
use_roundcaps <value>
Un valor distinto de cero indica que las trazas de vector deben dibujarse con extremos redondeados en lugar de perpendiculares. El valor predeterminado para esto es cero.
use_scrollbar_only <value>
Un valor distinto de cero indica que los botones de página, desplazamiento, obtención y descarte no deben dibujarse (es decir, las manipulaciones de tiempo deben hacerse a través de la barra de desplazamiento en lugar de los botones del panel frontal). El valor predeterminado para esto es cero.
use_scrollwheel_as_y <value>
Un valor distinto de cero indica que la rueda de desplazamiento del mouse debe usarse para desplazar las señales hacia arriba y hacia abajo en lugar de desplazar el valor del tiempo de izquierda a derecha.
use_standard_clicking <value>
Esta opción ya no tiene ningún efecto en gtkwave: se utilizan las semánticas de clic normales de GTK en la ventana de señales.
use_standard_trace_select <value>
Un valor distinto de cero mantiene las trazas actualmente seleccionadas sin deseleccionar al presionar el botón del ratón. Esto permite que el arrastrar y soltar funcione de manera más fluida. Dado que este comportamiento no es el funcionamiento normal de GTK, está deshabilitado de forma predeterminada.
use_toolbutton_interface <value>
Un valor distinto de cero indica que una barra de herramientas con botones debe estar en la parte superior de la pantalla en lugar de los grupos de botones de estilo tradicional de gtkwave. Por defecto, está activado.
vcd_explicit_zero_subscripts <valor>
indica que los nombres de señal deben almacenarse internamente como nombre.númerodebit cuando está habilitado. Cuando está deshabilitado, se utiliza un ordenamiento más "normal" de nombre[númerodebit]. Tenga en cuenta que cuando está deshabilitado, las opciones Bundle Up y Bundle Down están deshabilitadas en las opciones de Búsqueda de Señal por Expresión Regular, Búsqueda de Señal por Jerarquía y Búsqueda de Señal por Árbol. Esto es necesario porque las estructuras de datos internas para las señales se representan con un "menos" nivel de jerarquía que cuando está habilitado y esas funciones no funcionarían correctamente. Esto no debería ser un problema si atomic_vectors están habilitados. El valor predeterminado para vcd_explicit_zero_subscripts es deshabilitado.
vcd_preserve_glitches <valor>
indica que cualquier valor repetido igual para una red que abarque diferentes valores de tiempo en el archivo VCD/FST no debe comprimirse en un solo cambio de valor, sino que debe permanecer para permitir que existan glitches en este caso. El valor predeterminado para vcd_preserve_glitches es deshabilitado.
vcd_preserve_glitches_real <valor>
indica que cualquier valor repetido igual para una red real que abarque diferentes valores de tiempo en el archivo VCD/FST no debe comprimirse en un solo cambio de valor, sino que debe permanecer en este caso. El valor predeterminado para vcd_preserve_glitches es deshabilitado. El uso previsto es para cuando se ven datos analógicos interpolados, de modo que eliminar valores duplicados deformaría incorrectamente la interpolación.
vcd_warning_filesize <valor>
produce un mensaje de advertencia si el tamaño del archivo VCD es mayor que el tamaño del argumento en MB. Establezca en cero para deshabilitar esto.
vector_padding <valor>
indica el número de píxeles de espacio en blanco adicional que debe agregarse a cualquier cadena con el propósito de calcular el texto en vectores. Los valores permitidos son de 0 a 16, siendo el predeterminado 4.
vlist_compression <valor>
indica el valor a pasar a zlib durante el procesamiento de vlist (que se usa en el regrabador VCD). -1 deshabilita la compresión, 0-9 corresponden al valor que espera zlib. 4 es el predeterminado.
vlist_prepack <valor>
indica que el regrabador VCD debe precomprimir los datos que entran en los vlists de cambio de valor para reducir el uso de memoria. Esto se hace antes del posible empaquetado de zlib. El valor predeterminado es desactivado.
vlist_spill <valor>
indica que el regrabador VCD debe volcar todos los vlists generados a un archivo temporal en el disco para reducir el uso de memoria. El valor predeterminado es desactivado.
wave_scrolling <valor>
un valor distinto de cero habilita el desplazamiento al arrastrar el marcador fuera de los lados izquierdo o derecho de la ventana de ondas. Un valor cero lo deshabilita.
zoom_base <valor>
permite establecer la base de zoom con un valor entre 1.5 y 10.0. El valor predeterminado es 2.0.
zoom_center <valor>
un valor distinto de cero habilita el zoom centrado, un valor cero lo deshabilita.
zoom_dynamic <valor>
un valor distinto de cero habilita el zoom dinámico completo al usar el cargador parcial de VCD (incremental), un valor cero lo deshabilita.
zoom_dynamic_end <valor>
un valor distinto de cero habilita el zoom dinámico hasta el final al usar el cargador parcial de VCD (incremental), un valor cero lo deshabilita.
zoom_pow10_snap <valor>
corresponde a la opción de menú Zoom Pow10 Snap. El valor predeterminado para esto es deshabilitado (cero).
