Nombre

gtk4-builder-tool - Utilidad de archivos GtkBuilder

SINOPSIS

gtk4-builder-tool <COMANDO> [OPCIONES...] <ARCHIVO>
gtk4-builder-tool validate [OPCIONES...] <ARCHIVO>
gtk4-builder-tool enumerate [OPCIONES...] <ARCHIVO>
gtk4-builder-tool simplify [OPCIONES...] <ARCHIVO>
gtk4-builder-tool preview [OPCIONES...] <ARCHIVO>
gtk4-builder-tool render [OPCIONES...] <ARCHIVO>
gtk4-builder-tool screenshot [OPCIONES...] <ARCHIVO>

DESCRIPCIÓN

gtk4-builder-tool puede realizar varias operaciones en archivos de definición de UI GtkBuilder.

COMANDOS

Validación

El comando validate valida el archivo de definición de UI proporcionado e informa de los errores a stderr.

Tenga en cuenta que existen limitaciones en la validación que se puede realizar para las plantillas, ya que están estrechamente ligadas a la función class_init en la que se utilizan. Si su archivo de UI utiliza tipos de bibliotecas de terceros, puede ser útil añadir esas bibliotecas a la variable de entorno LD_PRELOAD.

--deprecations

Advierte sobre el uso de tipos obsoletos en el archivo de definición de UI.

Enumeración

El comando enumerate imprime todos los objetos con nombre que están presentes en el archivo de definición de UI.

--callbacks

Imprime también los nombres de las callbacks.

Vista previa

El comando preview muestra el archivo de definición de UI.

Este comando acepta opciones para especificar el ID del objeto de nivel superior y un archivo CSS a utilizar.

--id=ID

El ID del objeto a previsualizar. Si no se especifica, gtk4-builder-tool elegirá un objeto adecuado por sí mismo.

--css=ARCHIVO

Carga información de estilo del archivo CSS dado.

Renderizado

El comando render guarda un renderizado del archivo de definición de UI como una imagen png o un archivo de nodo. El nombre del archivo a escribir puede especificarse como un segundo argumento ARCHIVO.

Este comando acepta opciones para especificar el ID del objeto de nivel superior y un archivo CSS a utilizar.

--id=ID

El ID del objeto a previsualizar. Si no se especifica, gtk4-builder-tool elegirá un objeto adecuado por sí mismo.

--css=ARCHIVO

Carga información de estilo del archivo CSS dado.

--node

Escribe un archivo de nodo serializado en lugar de una imagen png.

--force

Sobrescribe un archivo existente.

Captura de pantalla

El comando screenshot es un alias para render.

Simplificación

El comando simplify simplifica el archivo de definición de UI eliminando propiedades que se establecen en sus valores predeterminados y escribe el XML resultante en la salida estándar, o de vuelta al archivo de entrada.

Cuando se especifica la opción --3to4, el comando simplify interpreta la entrada como un archivo de definición de UI de GTK 3 e intenta convertirlo a los equivalentes de GTK 4. Realiza varias conversiones, como renombrar propiedades, traducir propiedades hijas a propiedades de diseño, reescribir la configuración de GtkNotebook, GtkStack, GtkAssistant o cambiar barras de herramientas por cajas.

Siempre debes probar los archivos de definición de UI modificados producidos por gtk4-builder-tool antes de usarlos en producción.

Tenga en cuenta en particular que la conversión realizada con --3to4 está pensada como punto de partida para una migración de GTK 3 a GTK 4. Se espera que tenga que realizar correcciones manuales después de la conversión inicial.

--replace

Escribe el contenido de vuelta en el archivo de definición de UI en lugar de usar la salida estándar.

--3to4

Transforma un archivo de definición de UI de GTK 3 a las definiciones equivalentes de GTK 4.
