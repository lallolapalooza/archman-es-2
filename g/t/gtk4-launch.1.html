Nombre

gtk4-launch - Inicia una aplicación

SINÓPSIS

gtk4-launch [OPCIONES...] <APLICACIÓN> [URI...]

DESCRIPCIÓN

gtk4-launch inicia una aplicación usando el nombre dado. La aplicación se inicia con notificación de inicio adecuada en una pantalla predeterminada, a menos que se especifique lo contrario.

gtk4-launch toma al menos un argumento, el nombre de la aplicación a iniciar. El nombre debe coincidir con el nombre del archivo desktop de la aplicación, tal como se encuentra en los subdirectorios de aplicaciones de los directorios de datos XDG, con o sin el sufijo .desktop.

Si se llama con más de un argumento, los restantes además del nombre de la aplicación se consideran ubicaciones URI y se pasan como argumentos a la aplicación iniciada.

OPCIONES

-?, -h, --help

Imprime la ayuda del comando y sale.

--version

Imprime la versión del comando y sale.

ENTORNO

Algunas variables de entorno afectan el comportamiento de gtk4-launch:

XDG_DATA_HOME, XDG_DATA_DIRS

Las variables de entorno que especifican los directorios de datos XDG.
