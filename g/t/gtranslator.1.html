NOMBRE

gtranslator -- un editor de archivos po gettext cómodo con muchas características.

SINOPSIS

gtranslator [ ARCHIVO.po ]

DESCRIPCIÓN

gtranslator es un editor de archivos po gettext cómodo con muchas características como edición de caracteres especiales, vista de formas plurales, soporte de diferentes juegos de caracteres, preferencias cómodas, vista de lista de mensajes, función de búsqueda basada en expresiones regulares, posibilidades de compilación/actualización y mucho, mucho más.

Por supuesto, todas las características estándar de una buena aplicación como arrastrar y soltar, soporte de sesión, archivos complementarios para tipos mime y elementos de menú están presentes.
Vista de comentarios instantánea, una cómoda tabla de mensajes de navegación rápida con colores personalizables, temas de color, soporte UTF-8, un alto nivel de personalización y un búfer de aprendizaje personal/memoria de traducción con capacidades de autotraducción son las características principales de gtranslator además de la cómoda edición de las entradas de traducción.

OPCIONES

--help
Te muestra una pequeña ayuda autogenerada por GNOME.

BÚFER DE APRENDIZAJE

El búfer de aprendizaje es la implementación de una memoria de traducción (TM) personal en gtranslator. gtranslator utiliza el formato UMTF (un archivo XML comprimido que normalmente es bastante legible para humanos si se descomprime) para almacenar sus cadenas aprendidas.
Tus cadenas aprendidas estarán disponibles para la función de autotraducción de gtranslator, donde gtranslator rellenará automáticamente las traducciones correspondientes y valiosas para cualquier mensaje que ya se haya aprendido previamente. Esto resulta en un porcentaje bastante alto de mensajes pre-rellenados/pre-traducidos.
El estilo común y bueno de trabajar con el búfer de aprendizaje y con la autotraducción debería ser aprender los archivos po principales (para GNOME, por ejemplo, gnumeric, nautilus, evolution o cualquier otro archivo po de un paquete más grande ya traducido) para tu idioma.
Deberías aprender los archivos po principales (para GNOME, por ejemplo, gnumeric, nautilus, evolution o cualquier otro archivo po de un paquete más grande y ya traducido) para tu idioma; puedes usar un nuevo script del paquete gtranslator para automatizar un poco esta tarea: es “build-gtranslator-learn-buffer.sh”, que se instala en el directorio de scripts de gtranslator que puedes ver llamando a gtranslator -b y simplemente ejecutas el script con su ruta completa y sigues la información en la línea de comandos.
Después, simplemente puedes usar la entrada de menú "Autotraducción" de la GUI o usar la tecla de acceso rápido "F10" para que gtranslator autotraduzca todas las traducciones faltantes de tu búfer de aprendizaje personal. Esto facilitará tu trabajo de traducción y hará que una gran parte de los archivos po estén pre-traducidos.
Con un búfer de aprendizaje personal bastante grande, de aproximadamente 2 MB, puedes lograr muchos mensajes pre-traducidos para un nuevo proyecto/traducción.
Si deseas usar el contenido del búfer de aprendizaje almacenado para producir un archivo po con todas las traducciones "aprendidas", también puedes usar la capacidad de "exportar búfer de aprendizaje" de gtranslator para obtener una versión en archivo po plano del búfer de aprendizaje.
