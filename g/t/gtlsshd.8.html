    NAME

    gtlsshd — Secure remote login daemon

    SYNOPSIS

    gtlsshd [-d] [-p port] [-l logfile] [-v]

    DESCRIPTION

    gtlsshd is a daemon that listens for incoming TLS connections and allows users to log in remotely. It uses SSH keys for authentication by default.

    OPTIONS

    -d
    Run in debug mode.
    -p port
    Listen on the specified port instead of the default (2222).
    -l logfile
    Log messages to the specified file instead of stderr.
    -v
    Enable verbose output.

    TWO-FACTOR AUTHENTICATION

    gtlsshd supports two-factor authentication using TOTP. To enable it, the user must have a TOTP secret configured in their account. When logging in, the user will be prompted for their password followed by their TOTP code.
