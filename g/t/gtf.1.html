NOMBRE

gtf - calcular líneas de modo VESA GTF

SINOPSIS

gtf h-resolucion v-resolucion refresco [-v|--verbose] [-f|--fbmode] [-x|--xorgmode]

DESCRIPCIÓN

Gtf es una utilidad para calcular modos VESA GTF. Dados la resolución horizontal y vertical deseadas y la tasa de refresco (en Hz), se imprimen los parámetros para una línea de modo GTF que coincida. Se admiten dos formatos de salida: líneas de modo adecuadas para el archivo xorg.conf(5) de Xorg, y parámetros de modo adecuados para la utilidad fbset(8) de Linux.

OPCIONES

-v|--verbose
Habilita impresiones detalladas. Esto muestra un seguimiento de cada paso del cálculo.
-x|--xorgmode
Imprime los parámetros del modo como líneas de modo estilo Xorg. Este es el formato por defecto.
-f|--fbset
Imprime los parámetros del modo en un formato adecuado para fbset(8).

VER TAMBIÉN

xorg.conf(5), cvt(1)
