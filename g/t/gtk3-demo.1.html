NOMBRE

gtk3-demo - Demuestra los widgets de GTK+

SINOPSIS

gtk3-demo [--ayuda] [--listar] [--ejecutar EJEMPLO] [--auto-salir]

DESCRIPCIÓN

gtk3-demo es una colección de ejemplos. Su propósito es demostrar muchos widgets de GTK+ de una forma útil para los desarrolladores de aplicaciones.

La aplicación muestra el código fuente de cada ejemplo, así como otros recursos utilizados, como archivos ui e iconos.

OPCIONES

Se entienden las siguientes opciones:

-h, --ayuda

Mostrar opciones de ayuda

--listar

Listar los ejemplos disponibles.

-ejecutar EJEMPLO

Ejecutar el ejemplo con el nombre especificado. Use --listar para ver los ejemplos disponibles.

--auto-salir

Salir después de un breve tiempo de espera. Esto está previsto para usarse con --ejecutar, por ejemplo, durante la creación de perfiles.
