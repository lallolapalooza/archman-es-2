GTAGS-CSCOPE(1) Manual de Comandos Generales GTAGS-CSCOPE(1)

NOMBRE

gtags-cscope - examina interactivamente un programa C

SINOPSIS

gtags-cscope [-abCdehilLvV][-F archivo ][-012345678 patrón][-p n]

DESCRIPCIÓN

gtags-cscope es una herramienta interactiva orientada a pantalla que permite al usuario navegar por los archivos fuente para elementos de código específicos.

gtags-cscope construye la referencia cruzada de símbolos la primera vez que se usa en los archivos fuente del programa que se está explorando. En una invocación posterior, gtags-cscope reconstruye la referencia cruzada solo si un archivo fuente ha cambiado o si la lista de archivos fuente es diferente. Cuando se reconstruye la referencia cruzada, se actualiza de forma incremental, lo que hace que la reconstrucción sea más rápida que la construcción inicial.

gtags-cscope es una herramienta que simplemente toma prestada la interfaz de usuario de cscope; es Global en sí mismo en lo esencial.

OPCIONES

Algunos argumentos de línea de comandos solo pueden aparecer como el único argumento en la ejecución de gtags-cscope. Hacen que el programa simplemente imprima algo de salida y salga inmediatamente:

-h
Ver la ayuda de uso detallada.
-V
Imprimir el número de versión de gtags-cscope.
--help
Igual que -h
--version
Igual que -V

Las siguientes opciones pueden aparecer en cualquier combinación:

-a
Imprimir nombres de ruta absolutos.
-b
Solo construir la referencia cruzada.
-C
Ignorar mayúsculas y minúsculas al buscar.
-d
No actualizar la referencia cruzada.
-e
Suprimir el prompt de comando ´^e´ entre archivos.
-F archivo
Leer líneas de referencia de símbolos desde archivo. (Un archivo de referencia de símbolos se crea con > y >>, y también se puede leer usando el comando <, descrito bajo «Emitiendo peticiones posteriores», más abajo.)
-i
Ignorar la señal SIGINT en modo orientado a líneas.
-L
Hacer una sola búsqueda con salida orientada a líneas cuando se usa con la opción -num patrón.
-l
Interfaz orientada a líneas. Esta opción implica la -d opción.
-[0-9] patrón
Ir al campo de entrada num (contando desde 0) y buscar patrón.
-p n
Mostrar los últimos n componentes de la ruta del archivo en lugar del valor predeterminado (1). Usar ´0´ para no mostrar el nombre del archivo en absoluto.
-v
Ser más detallado en modo orientado a líneas.

Solicitando la búsqueda inicial

Cuando la referencia cruzada está lista, gtags-cscope mostrará este menú:

Buscar este símbolo:
Buscar esta definición global:
Buscar funciones llamadas por esta función (N/A):
Buscar referencias de esta función:
Buscar esta cadena de texto:
Cambiar esta cadena de texto:
Buscar este patrón egrep:
Buscar este archivo:
Buscar archivos que incluyen #este archivo:
Buscar asignaciones a este símbolo:

Pulse repetidamente las teclas <Arriba> o <Abajo> para moverse al campo de entrada deseado, escriba el texto a buscar y luego pulse la tecla <Intro>.

Emitiendo peticiones posteriores

Si la búsqueda es exitosa, cualquiera de estos comandos de un solo carácter se puede usar:

0-9a-zA-Z
Editar el archivo referenciado por el número de línea dado.
<Espacio>
Mostrar el siguiente conjunto de líneas coincidentes.
<Tabulador>
Alternar entre el menú y la lista de líneas coincidentes
<Arriba>
Moverse al elemento anterior del menú (si el cursor está en el menú) o moverse a la línea coincidente anterior (si el cursor está en la lista de líneas coincidentes).
<Abajo>
Moverse al siguiente elemento del menú (si el cursor está en el menú) o moverse a la siguiente línea coincidente (si el cursor está en la lista de líneas coincidentes).
+
Mostrar el siguiente conjunto de líneas coincidentes.
-
Mostrar el conjunto anterior de líneas coincidentes.
^e
Editar los archivos mostrados en orden.
>
Escribir la lista de líneas mostrada en un archivo.
>>
Añadir la lista de líneas mostrada a un archivo.
<
Leer líneas de un archivo que está en formato de referencia de símbolos (creado por ´>´ o ´>>´), igual que la -F opción.
^
Filtrar todas las líneas a través de un comando de shell y mostrar las líneas resultantes, reemplazando las líneas que ya estaban allí.
|
Enviar todas las líneas a un comando de shell y mostrarlas sin cambiar las.
^g
Leer líneas del resultado de la ejecución de global(1).

En cualquier momento estos comandos de un solo carácter también se pueden usar:

<Intro>
Moverse al siguiente campo de entrada.
^n
Moverse al siguiente campo de entrada.
^p
Moverse al campo de entrada anterior.
^y
Buscar con el último texto escrito.
^b
Moverse al campo de entrada y patrón de búsqueda anterior.
^f
Moverse al campo de entrada y patrón de búsqueda siguiente.
^c
Alternar ignorar/usar mayúsculas y minúsculas al buscar. (Cuando se ignoran las mayúsculas y minúsculas, una búsqueda de ´FILE´ coincidirá con ´File´ y ´file´.)
^r
Reconstruir la referencia cruzada.
!
Iniciar un shell interactivo (escriba ´^d´ para volver a gtags-cscope).
^l
Redibujar la pantalla.
?
Dar información de ayuda sobre gtags-cscope comandos.
^d
Salir de gtags-cscope.

NOTA: Si el primer carácter del texto a buscar coincide con uno de los comandos anteriores, escápelo escribiendo primero un ´\' (barra invertida).

Sustituyendo texto nuevo por texto antiguo

Después de escribir el texto a cambiar, gtags-cscope pedirá el nuevo texto, y luego mostrará las líneas que contienen el texto antiguo. Seleccione las líneas a cambiar con estos comandos de un solo carácter:

0-9a-zA-Z
Marcar o desmarcar la línea a cambiar.
*
Marcar o desmarcar todas las líneas mostradas para cambiar.
<Espacio>
Mostrar el siguiente conjunto de líneas.
+
Mostrar el siguiente conjunto de líneas.
-
Mostrar el conjunto anterior de líneas.
^a
Marcar o desmarcar todas las líneas para cambiar.
^d
Cambiar las líneas marcadas y salir.
<Esc>
Salir sin cambiar las líneas marcadas.
!
Iniciar un shell interactivo (escriba ´^d´ para volver a gtags-cscope).
^l
Redibujar la pantalla.
?
Dar información de ayuda sobre gtags-cscope comandos.
Teclas especiales
Si su terminal tiene teclas de flecha que funcionan en vi, puede usarlas para moverse por los campos de entrada. La tecla de flecha hacia arriba es útil para moverse al campo de entrada anterior en lugar de usar repetidamente la tecla <Tabulador>. Si tiene teclas <CLEAR>, <NEXT> o <PREV>, actuarán como los comandos ´^l´, ´+´ y ´-´ respectivamente.

Interfaz orientada a líneas

La -l opción le permite usar gtags-cscope donde una interfaz orientada a pantalla no sería útil, por ejemplo, desde otro programa orientado a pantalla.

gtags-cscope mostrará ´>>´ cuando esté listo para una línea de entrada, que comienza con el número de campo (contando desde 0), seguido inmediatamente por el patrón de búsqueda. Por ejemplo, ´1main´ encuentra la definición de la función ´main´.

Si solo desea una búsqueda única, en lugar de la opción -l use las opciones -L y -num patrón , y no obtendrá el prompt ´>>´.

Para -l, gtags-cscope emite el número de líneas de referencia:
cscope: 2 lines

Por cada referencia encontrada, gtags-cscope emite una línea que consiste en el nombre del archivo, el nombre de la función, el número de línea y el texto de la línea, separados por espacios. Por ejemplo:
main.c main 161 main(argc, argv)

Tenga en cuenta que el editor no se invoca para mostrar una única referencia, a diferencia de la interfaz orientada a pantalla.

Puede usar el comando ´c´ para alternar ignorar/usar mayúsculas y minúsculas al buscar. (Cuando se ignoran mayúsculas y minúsculas, una búsqueda de ´FILE´ coincidirá con ´File´ y ´file´.)

Puede usar el comando ´r´ para reconstruir la base de datos.

gtags-cscope se cerrará cuando detecte el fin del archivo, o cuando el primer carácter de una línea de entrada sea ´^d´ o ´q´.

ENTORNO

Las siguientes variables de entorno son de origen de cscope.

CSCOPE_EDITOR
Anula las variables EDITOR y VIEWER . Úselo si desea usar un editor diferente con cscope al especificado por sus variables EDITOR/VIEWER .
CSCOPE_LINEFLAG
Formato del indicador de número de línea para su editor. Por defecto, cscope invoca su editor mediante el equivalente a ´editor +N file´, donde N es el número de línea al que el editor debe saltar. Este formato es utilizado tanto por emacs como por vi. Si su editor necesita algo diferente, especifíquelo en esta variable, con ´%s´ como marcador de posición para el número de línea. Ej.: si su editor necesita ser invocado como ´editor -#103 file´ para ir a la línea 103, establezca esta variable en ´-#%s´.
CSCOPE_LINEFLAG_AFTER_FILE
Establezca esta variable en ´yes´ si su editor necesita ser invocado con la opción de número de línea después del nombre del archivo a editar. Para continuar el ejemplo de CSCOPE_LINEFLAG, anterior: si su editor necesita ver ´editor file -#number´, establezca esta variable de entorno. Los usuarios de la mayoría de los editores estándar (vi, emacs) no necesitan establecer esta variable.
EDITOR
Editor preferido, que por defecto es vi.
HOME
Directorio de inicio, que se establece automáticamente al iniciar sesión.
SHELL
Shell preferido, que por defecto es sh.
TERM
Tipo de terminal, que debe ser una terminal de pantalla.
TERMINFO
Ruta completa del directorio de información de la terminal. Si su terminal no está en el directorio estándar de terminfo, consulte curses y terminfo para saber cómo crear su propia descripción de terminal.
TMPDIR
Directorio de archivos temporales, que por defecto es ´/tmp´.
VIEWER
Programa de visualización de archivos preferido (como less), que anula EDITOR (ver arriba).

Las siguientes variables de entorno son de origen Global.

GTAGSCONF
Archivo de configuración.
GTAGSGLOBAL
Si esta variable está establecida, ´$GTAGSGLOBAL´ se usa como el nombre de global(1). El valor por defecto es global.
GTAGSGTAGS
Si esta variable está establecida, ´$GTAGSGTAGS´ se usa como el nombre de gtags(1). El valor por defecto es gtags.
GTAGSDBPATH
El directorio en el que existen los archivos de etiquetas. Este valor se ignora cuando GTAGSROOT no está definido.
GTAGSLABEL
Etiqueta de configuración. El valor por defecto es ´default´.
GTAGSLIBPATH
Si esta variable está establecida, se usa como la ruta para buscar funciones de biblioteca. Si las etiquetas especificadas no se encuentran en el proyecto, global también busca en estas rutas. Dado que en la recuperación solo se dirige a ´GTAGS´, esta variable se ignora cuando se especifica -r o -s .
GTAGSROOT
El directorio raíz del proyecto.
MAKEOBJDIR
Si esta variable está establecida, ´$MAKEOBJDIR´ se usa como el nombre del directorio obj de estilo BSD. El valor por defecto es ´obj´.
MAKEOBJDIRPREFIX
Si esta variable está establecida, ´$MAKEOBJDIRPREFIX´ se usa como el prefijo del directorio obj de estilo BSD. El valor por defecto es ´/usr/obj´.

ARCHIVOS

´GTAGS´
Archivo de etiquetas para definiciones.
´GRTAGS´
Archivo de etiquetas para referencias.
´GPATH´
Archivo de etiquetas para archivos fuente.
´GTAGSROOT´
Si la variable de entorno GTAGSROOT no está establecida y el archivo ´GTAGSROOT´ existe en el mismo directorio que ´GTAGS´, entonces global establece GTAGSROOT al contenido del archivo.
´gtags.conf´, ´$HOME/.globalrc´
Datos de configuración para GNU Global. Véase gtags.conf(5).

VÉASE TAMBIÉN

gtags(1), global(1), htags(1).

Sistema de etiquetado de código fuente de GNU Global

ERRORES

El campo de función de la pantalla es casi siempre <unknown> ya que Global no lo reconoce.

´Encontrar funciones llamadas por esta función´ no está implementado.

AUTOR

Joe Steffen (autor original) y otros.

HISTORIA

Cscope fue desarrollado originalmente en Bell Labs a principios de la década de 1980, y se publicó como software libre bajo la licencia BSD en abril de 2000. Gtags-cscope es un derivado de cscope que usa Global como backend. Su interfaz orientada a líneas fue escrita originalmente en 2006, y fue re-implementada en 2011 usando cscope mismo.
