NAME

dgbrfsx - provides error bounds and improved accuracy for the solution of a system of linear equations with a general band matrix.

SYNOPSIS

This subroutine is called within the LAPACK routines.

The interface to this subroutine is subject to change. Use of the Fortran interface is recommended.

There are no user-callable routines that directly call this routine.

Fortran-77 Interface

SUBROUTINE DGBRFSX( TRANS, EQUED, N, KL, KU, NRHS, AB, LDAB, AFB, LDAFB, IPIV,
                    R, C, B, LDB, X, LDX, RCOND, BERR, N_ERR_BNDS,
                    ERR_BNDS_NORM, ERR_BNDS_COMP, NPARAMS, PARAMS, WORK,
                    RWORK, INFO )
CHARACTER*1 TRANS, EQUED
INTEGER N, KL, KU, NRHS, LDAB, LDAFB, LDB, LDX, N_ERR_BNDS, NPARAMS, INFO
INTEGER IPIV( * )
DOUBLE PRECISION AB( LDAB, * ), AFB( LDAFB, * ), R( * ), C( * ),
               B( LDB, * ), X( LDX, * ), RCOND, BERR( * ),
               ERR_BNDS_NORM( NRHS, * ), ERR_BNDS_COMP( NRHS, * ),
               PARAMS( * ), WORK( * ), RWORK( * )

Description

dgbrfsx computes error bounds and improves the accuracy of a computed solution to a system of linear equations AX = B using the LU factorization of the band matrix A computed by DGBTRF.

This routine uses iterative refinement to reduce the error in the solution X in effect if the scaling factors R and C are not trivial. It also uses the scaling factors to compute componentwise error bounds.

For each right hand side, the routine also computes an estimate of the componentwise backward error.

If the routine detects that the input matrix A is singular, or near singular, then the error bounds may not be valid. To avoid use of nearly singular routines, the user may also ask for a reciprocal condition number to be computed as part of the error analysis.

See Lapack Working Note 165 for further details and extra cautions.

>          TRANS = 'N':  Solve A * X = B [the input system]
>          TRANS = 'T':  Solve A**T * X = B
>          TRANS = 'C':  Solve A**H * X = B (Use 'C' for complex routines only)

>          Specifies the form of equilibration computed by DGBTRF:
>          EQUED = 'N': No equilibration was computed.
>          EQUED = 'R': Row equilibration was computed.

>          The order of the matrix A. N >= 0.

KU (INTEGER)

>          The number of superdiagonals within the band of A. 0 <= KU < N.

>          The number of right hand sides, i.e., the number of columns of

>          On entry, the N-by-N band matrix A, stored in an
>          (KL+KU+1)-by-N array. The j-th column contains the elements of

>          zeroes elsewhere.

LDAB (INTEGER)

>          The leading dimension of the array AB. LDAB >= KL + KU + 1.

AFB (DOUBLE PRECISION array, dimension (LDAFB, *))

>          On entry, the factors L and U of the band matrix A, as
>          computed by DGBTRF.

LDAFB (INTEGER)

>          The leading dimension of the array AFB. LDAFB >= KL + KU + 1.

IPIV (INTEGER array, dimension (*))

>          The pivot indices array, as computed by DGBTRF.

R (DOUBLE PRECISION array, dimension (*))

>          The scaling vector for row equilibration, if EQUED = 'R' or
>          'B'. The ith element of R contains the scale factor R(i)
>          that was applied to the ith row of A. If EQUED = 'N' or 'C',
>          the array R is not accessed.

C (DOUBLE PRECISION array, dimension (*))

>          The scaling vector for column equilibration, if EQUED = 'C' or
>          'B'. The jth element of C contains the scale factor C(j)
>          that was applied to the jth column of A. If EQUED = 'N' or 'R',
>          the array C is not accessed.

B (DOUBLE PRECISION array, dimension (LDB, *))

>          On entry, the right-hand side matrix B.

LDB (INTEGER)

>          The leading dimension of the array B. LDB >= max(1,N).

X (DOUBLE PRECISION array, dimension (LDX, *))

>          On entry, the solution matrix X, as computed by DGBTRS.
>          On exit, the improved solution matrix X.

LDX (INTEGER)

>          The leading dimension of the array X. LDX >= max(1,N).

>          Reciprocal scaled condition number. This is an estimate of the
>          reciprocal Skeel condition number of the matrix A after
>          equilibration (if done). If this is less than the machine
>          precision (in particular, if it is zero), the matrix is singular
>          to working precision. Note that the error may still be small even
>          if this number is very small and the matrix appears ill-
>          conditioned.

BERR (DOUBLE PRECISION array, dimension (NRHS))

>          Componentwise relative backward error. This is the
>          componentwise relative backward error of each solution vector X(j)
>          (i.e., the smallest relative change in any element of A or B that
>          makes X(j) an exact solution).

N_ERR_BNDS (INTEGER)

>          Number of error bounds to return for each right hand side
>          and each type (normwise or componentwise). See ERR_BNDS_NORM and
>          ERR_BNDS_COMP below.

ERR_BNDS_NORM (DOUBLE PRECISION array, dimension (NRHS, N_ERR_BNDS))

>          For each right-hand side, this array contains information about
>          various error bounds and condition numbers corresponding to the
>          normwise relative error, which is defined as follows:
>
>          Normwise relative error in the ith solution vector:
>                  max_j (abs(XTRUE(j,i) - X(j,i)))
>                 ------------------------------
>                       max_j abs(X(j,i))
>
>          The array is indexed by the type of error information as described
>          below. There currently are up to three pieces of information
>          returned.
>
>          The first index in ERR_BNDS_NORM(i,:) corresponds to the ith
>          right-hand side.
>
>          The second index in ERR_BNDS_NORM(:,err) contains the following
>          three fields:
>          err = 1  boolean. Trust the answer if the
>                   reciprocal condition number is less than the threshold
>                   sqrt(n) * slamch('Epsilon').
>
>          err = 2  error bound: The estimated forward error,
>                   almost certainly within a factor of 10 of the true error
>                   so long as the next entry is greater than the threshold
>                   sqrt(n) * slamch('Epsilon'). This error bound should only
>                   be trusted if the previous boolean is true.
>
>          err = 3  Reciprocal condition number: Estimated normwise
>                   reciprocal condition number.  Compared with the threshold
>                   sqrt(n) * slamch('Epsilon') to determine if the error
>                   estimate is . These reciprocal condition
>                   numbers are 1 / (norm(Z^{-1},inf) * norm(Z,inf)) for some
>                   appropriately scaled matrix Z.
>                   Let Z = S*A, where S scales each row by a power of the
>                   radix so all absolute row sums of Z are approximately 1.
>
>          See Lapack Working Note 165 for further details and extra
>          cautions.

ERR_BNDS_COMP (DOUBLE PRECISION array, dimension (NRHS, N_ERR_BNDS))

>          For each right-hand side, this array contains information about
>          various error bounds and condition numbers corresponding to the
>          componentwise relative error, which is defined as follows:
>
>          Componentwise relative error in the ith solution vector:
>                         abs(XTRUE(j,i) - X(j,i))
>                  max_j ----------------------
>                              abs(X(j,i))
>
>          The array is indexed by the right-hand side i (on which the
>          componentwise relative error depends), and the type of error
>          information as described below. There currently are up to three
>          pieces of information returned for each right-hand side. If
>          componentwise accuracy is not requested (PARAMS(3) = 0.0), then
>          ERR_BNDS_COMP is not accessed. If N_ERR_BNDS < 3, then at most
>          the first (:,N_ERR_BNDS) entries are returned.
>
>          The first index in ERR_BNDS_COMP(i,:) corresponds to the ith
>          right-hand side.
>
>          The second index in ERR_BNDS_COMP(:,err) contains the following
>          three fields:
>          err = 1  boolean. Trust the answer if the
>                   reciprocal condition number is less than the threshold
>                   sqrt(n) * slamch('Epsilon').
>
>          err = 2  error bound: The estimated forward error,
>                   almost certainly within a factor of 10 of the true error
>                   so long as the next entry is greater than the threshold
>                   sqrt(n) * slamch('Epsilon'). This error bound should only
>                   be trusted if the previous boolean is true.
>
>          err = 3  Reciprocal condition number: Estimated componentwise
>                   reciprocal condition number. Compared with the threshold
>                   sqrt(n) * slamch('Epsilon') to determine if the error
>                   estimate is . These reciprocal condition
>                   numbers are 1 / (norm(Z^{-1},inf) * norm(Z,inf)) for some
>                   appropriately scaled matrix Z.
>                   Let Z = S*(A*diag(x)), where x is the solution for the
>                   current right-hand side and S scales each row of
>                   A*diag(x) by a power of the radix so all absolute row
>                   sums of Z are approximately 1.
>
>          See Lapack Working Note 165 for further details and extra
>          cautions.

NPARAMS (INTEGER)

>          Specifies the number of parameters set in PARAMS. If <= 0, the
>          PARAMS array is never referenced and default values are used.

PARAMS (DOUBLE PRECISION array, dimension NPARAMS)

>          Specifies algorithm parameters. If an entry is < 0.0, then
>          that entry will be filled with default value used for that
>          parameter. Only positions up to NPARAMS are accessed; defaults
>          are used for higher-numbered parameters.
>
>            PARAMS(LA_LINRX_ITREF_I = 1) : Whether to perform iterative
>                 refinement or not.
>            Default: 1.0
>               = 0.0:  No refinement is performed, and no error bounds are
>                       computed.
>               = 1.0:  Use the double-precision refinement algorithm,
>                       possibly with doubled-single computations if the
>                       compilation environment does not support DOUBLE
>                       PRECISION.
>                 (other values are reserved for future use)
>
>            PARAMS(LA_LINRX_ITHRESH_I = 2) : Maximum number of residual

>            Aggressive: Set to 100 to permit convergence using approximate

>                        the factorization uses a technique other than
>                        Gaussian elimination, the guarantees in
>                        err_bnds_norm and err_bnds_comp may no longer be
>                        trustworthy.
>
>            PARAMS(LA_LINRX_CWISE_I = 3) : Flag determining if the code
>                 will attempt to find a solution with small componentwise
>                 relative error in the double-precision algorithm. Positive
>                 is true, 0.0 is false.
>            Default: 1.0 (attempt componentwise convergence)

WORK (DOUBLE PRECISION array, dimension (2*N))

RWORK (DOUBLE PRECISION array, dimension (2*N))

INFO (INTEGER)

>       = 0:  Successful exit. The solution to every right-hand side is
>        guaranteed.
>       < 0:  If INFO = -i, the i-th argument had an illegal value
>       > 0 and <= N:  U(INFO,INFO) is exactly zero.  The factorization

>       = N+J: The solution corresponding to the Jth right-hand side is

>         ERR_BNDS_NORM(:,1) and ERR_BNDS_COMP(:,1). To get information
>         about all of the right-hand sides check ERR_BNDS_NORM or
>         ERR_BNDS_COMP.

Propósito:

!>    DGBRFSX mejora la solución calculada de un sistema de ecuaciones
!>    lineales y proporciona cotas de error y estimaciones de error
!>    hacia atrás para la solución. Además de la cota de error en norma,
!>    el código proporciona, si es posible, la cota de error máxima
!>    componente a componente. Consulte los comentarios de
!>    ERR_BNDS_NORM y ERR_BNDS_COMP para obtener detalles sobre las
!>    cotas de error.
!>
!>    El sistema original de ecuaciones lineales puede haber sido
!>    ecualizado antes de llamar a esta rutina, como se describe en los
!>    argumentos EQUED, R y C a continuación. En este caso, la solución
!>    y las cotas de error devueltas son para el sistema original no
!>    ecualizado.
!> 


!>     Algunos parámetros opcionales están agrupados en la matriz PARAMS.
!>     Estas configuraciones determinan cómo se realiza el refinamiento,
!>     pero a menudo los valores por defecto son aceptables. Si los
!>     valores por defecto son aceptables, los usuarios pueden pasar

!>     PARAMS.

DESCRIPTION


ZGbrfsx improves the computed solution to a system of linear
  equations A*X = B for a general band matrix A by iterative
  refinement. It also computes a forward error bound and estimates the
  residual backward error for each solution vector X(j).


ZGbrfsx is called after Zgbtrf and Zgbtrs.


A band matrix A with kl sub-diagonals and ku
  super-diagonals is stored, and passed as the array AB. The
  routine assumes that A has been factorized by Zgbtrf. The precondition
  for the iterative refinement routines is that the matrix A is
  non-singular.


If the matrix A is not banded, then the routine Zgerfsx should
  be used instead.


This routine also equilibrates the matrix, if requested, to
  reduce the number of outliers.


The condition number is estimated using the scaled matrix:


  (A) = S*A



where S is a diagonal matrix determined by the scaling of the matrix A.
  The value RCOND is an estimate of the reciprocal condition number of (A).


If the iterative refinement procedure chooses to use double
  precision computations, then the routine uses the LAPACK
  double precision routines, which are otherwise unused. If the
  compilation environment does not support double precision, then the
  double precision computations are performed in single precision.


The routine also computes error bounds for each right-hand
  side vector of the system of equations.


The scaling of the matrix is done based on the values in the
  array PARAMS. The value of PARAMS(3) determines whether the code
  attempts to find a solution with small componentwise relative error.


The routine uses the LAPACK routines Zgbcon, Zgbtrs, and Zlacn2
  to compute the error bounds.


The routine computes the error bounds for each solution
  vector X(j) using the following algorithms:



  
Normwise relative error:

  
The normwise relative error is defined as the maximum of the
    relative errors in each component of the solution vector X(j).

  
Componentwise relative error:

  
The componentwise relative error is defined as the maximum of the
    relative errors in each component of the solution vector X(j).

Forward error bound:

  
The estimated forward error is computed as:

  
    fwd_err = || X_true - X || / || X ||

    smallest relative change in any element of A or B that makes X(j) an
    exact solution.

For each right-hand side, this array contains information about
  various error bounds and condition numbers corresponding to the
  componentwise relative error, which is defined as follows:


  Componentwise relative error in the ith solution vector:
                 abs(XTRUE(j,i) - X(j,i))
          max_j ----------------------
                      abs(X(j,i))



The array is indexed by the right-hand side i (on which the
  componentwise relative error depends), and the type of error
  information as described below. There currently are up to three
  pieces of information returned for each right-hand side. If
  componentwise accuracy is not requested (PARAMS(3) = 0.0), then
  ERR_BNDS_COMP is not accessed. If N_ERR_BNDS < 3, then at most
  the first (:,N_ERR_BNDS) entries are returned.


The first index in ERR_BNDS_COMP(i,:) corresponds to the ith
  right-hand side.


The second index in ERR_BNDS_COMP(:,err) contains the following
  three fields:



  
err = 1

  
boolean. Trust the answer if the reciprocal condition number is less than the threshold sqrt(n) * slamch('Epsilon').

  
err = 2

  
error bound: The estimated forward error, almost certainly within a factor of 10 of the true error so long as the next entry is greater than the threshold sqrt(n) * slamch('Epsilon'). This error bound should only be trusted if the previous boolean is true.

  
err = 3

  
Reciprocal condition number: Estimated componentwise reciprocal condition number. Compared with the threshold sqrt(n) * slamch('Epsilon') to determine if the error estimate is . These reciprocal condition numbers are 1 / (norm(Z^{-1},inf) * norm(Z,inf)) for some appropriately scaled matrix Z. Let Z = S*(A*diag(x)), where x is the solution for the current right-hand side and S scales each row of A*diag(x) by a power of the radix so all absolute row sums of Z are approximately 1.

Detailed Description


GBRFSX computes error bounds and estimates condition numbers for the
    solution to a system of linear equations AX=B, or the solution to
    a related system of linear equations, given the LU factorization of
    A. 


For the following scope, the input matrix A is factored and B
    is factored:


SCOPE = 'N' or 'n': the routine factors the matrix A and
    computes the error bounds for the solution of AX=B.


SCOPE = 'B' or 'b': the routine computes the error bounds
    for the solution of AX=B and the factored matrix B.


For the following TRANS, the routine computes the error
    bounds for the solution to a system of equations of the form:


TRANS = 'N' or 'n': AX = B


TRANS = 'T' or 't': A^T X = B


TRANS = 'C' or 'c': A^H X = B


where A^T is the transpose of A and A^H is the conjugate
    transpose of A.


The routine computes the forward error, the backward error
    and estimates of the reciprocal condition number.


The componentwise relative error is defined as:


         max_j |XTRUE(j,i) - X(j,i)| / |X(j,i)|



The normwise relative error is defined as:


         max_i |XTRUE(j,i) - X(j,i)| / |X(j,i)|



The routine is based on the following papers:


R. Burston, D.J. Higham, and L. Maximoff, "A new model for
    residual-based condition estimation for linear systems", SIAM J. Matrix
    Anal. Appl., Vol. 23, No. 3, pp. 618-640, 2001.


R. Burston, D.J. Higham, and L. Maximoff, "A new model for
    residual-based condition estimation for linear systems", SIAM J. Matrix
    Anal. Appl., Vol. 23, No. 3, pp. 618-640, 2001.


and


R. Burston, D.J. Higham, and L. Maximoff, "A new model for
    residual-based condition estimation for linear systems", SIAM J. Matrix
    Anal. Appl., Vol. 23, No. 3, pp. 618-640, 2001.


The routine also computes the componentwise backward error
    (BERR) and the componentwise forward error bound (FERR).


BERR is defined as:


         max_j |XTRUE(j,i) - X(j,i)| / |X(j,i)|



FERR is defined as:


         max_j |XTRUE(j,i) - X(j,i)| / |X(j,i)|



The componentwise condition number is defined as:


         max_j |X(j,i)| * |Z^{-1}|_inf / |A*diag(X)|_inf



where Z = S * (A * diag(X)) and S is a diagonal matrix
    that scales each row of A * diag(X) by a power of the radix so that all
    absolute row sums of Z are approximately 1.
