NOMBRE

gbs3 - Intérprete de Gambas

SINOPSIS

gbs3 [opciones] [--] [<archivo de script> | -]
gbs3 --convert-project <directorio de proyecto de origen> <directorio de script de destino>

DESCRIPCIÓN

DESCRIPCIÓN

Gambas es un entorno de desarrollo libre basado en un intérprete Basic con extensiones de objetos, una mezcla de Java(tm) y Visual Basic(tm). Con Gambas, puede diseñar rápidamente la GUI de su programa con Qt o GTK+, acceder a sistemas de bases de datos como MySQL, PostgreSQL, SQlite u ODBC, controlar aplicaciones con DBus, traducir su programa a muchos idiomas, crear aplicaciones GStreamer, OpenGL o SDL, y mucho más...

gbs3 es el intérprete que le permite compilar y ejecutar un script de Gambas.
gbs3 también se puede usar para convertir un proyecto de Gambas a un script.

OPCIONES

-b, --buildonly
procesar y compilar el script sin ejecutarlo
-c, --nocache
forzar la compilación del script (no comprobar la caché)
-e
ejecutar el código fuente proporcionado en la línea de comandos (separador ':' )
-f, --fast
usar el compilador just-in-time TP -g, --debug añadir información de depuración a la aplicación
-h, --help
mostrar la ayuda y salir
-l, --list
mostrar una lista de Componentes o Librerías disponibles, '-l componente' o '-l librería'
-L, --license
mostrar la licencia
-S --strict
fallar si se definen 'Public' o 'Sub' sin una función 'main', de lo contrario crear main()
-t, --trace
activar la opción de rastreo durante la ejecución
-T, --terse
imprimir solo un informe de error muy conciso en caso de errores de compilación
-u, --use
cargar componente o librerías ('comp1,comp2,lib1...')
-v, --verbose
ser detallado
-V, --version
mostrar la versión
-w, --warnings
mostrar advertencias durante la compilación
--convert-project
convertir un proyecto simple a un script

CONVERSIÓN DE PROYECTOS

gbs3 puede convertir un proyecto de Gambas a un archivo de script ejecutable usando la opción --convert-project.
El directorio del proyecto de entrada se utiliza para crear el script, que se escribe en el directorio de scripts de destino.
El script se crea y se nombra igual que el proyecto de origen.

gbs3 MiDirectorioDeProyecto MiDirectorioDeScripts

EJEMPLO

#!/usr/bin/env gbs3
for i as integer = 0 to 10
print i;;
next
