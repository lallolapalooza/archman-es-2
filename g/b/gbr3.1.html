NOMBRE

gbr3 - Intérprete de GAMBAS

SINOPSIS

gbr3 [opciones] <archivo ejecutable> [<argumentos>]

DESCRIPCIÓN

Gambas es un entorno de desarrollo libre basado en un intérprete Basic con extensiones de objetos, una mezcla de Java(tm) y Visual Basic(tm). Con Gambas, puedes diseñar rápidamente la GUI de tu programa con Qt o GTK+, acceder a sistemas de bases de datos como MySQL, PostgreSQL, SQlite o bases de datos ODBC, pilotar aplicaciones con DBus, traducir tu programa a muchos idiomas, crear aplicaciones GStreamer, OpenGL o SDL, y mucho más...

gbr3 es el intérprete que te permite ejecutar un ejecutable de Gambas.

OPCIONES

-a <ruta>
ignorar la ruta de la aplicación
-g
entrar en modo depuración
-h, --help
mostrar ayuda y salir
-H, --httpd
ejecutar a través de un servidor http incrustado
-j
desactivar el compilador just-in-time
-k
no descargar librerías compartidas
-L, --license
mostrar licencia
-p <ruta>
activar el modo de perfilado y depuración
-r <ruta>
redirigir la salida de error estándar
-s <clase>
ignorar la clase de inicio
-t, --trace
volcar la posición de cada línea de código ejecutada
-T
listar todos los módulos de prueba
-T <pruebas>
ejecutar los módulos de prueba especificados
-V, --version
mostrar versión

DISPONIBILIDAD

La última versión de Gambas siempre se puede obtener en gambas.sourceforge.net, la documentación sobre el lenguaje está en www.gambasdoc.org.
