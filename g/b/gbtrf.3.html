Propósito

!>
!> CGBTRF calcula una factorización LU de una matriz de banda compleja m-por-n A
!> usando pivoteo parcial con intercambios de filas.
!>
!> Esta es la versión bloqueada del algoritmo, que llama a BLAS de Nivel 3.
!
>

Parámetro

s
M 
!>          M es INTEGER
!>          El número de filas de la matriz A.  M >= 0.
!
>

N 
!>          N es INTEGER
!>          El número de columnas de la matriz A.  N >= 0.
!
>

K

L 
!>          KL es INTEGER
!>          El número de subdiagonales dentro de la banda de A.  KL >= 0.
!
>

K

U 
!>          KU es INTEGER
!>          El número de superdiagonales dentro de la banda de A.  KU >= 0.
!
>

A

B 
!>          AB es un arreglo COMPLEX, dimensión (LDAB,N)
!>          En la entrada, la matriz A en almacenamiento de banda, en las filas KL+1 a
!>          2*KL+KU+1; las filas 1 a KL del arreglo no necesitan ser establecidas.
!>          La j-ésima columna de A se almacena en la j-ésima columna del
!>          arreglo AB de la siguiente manera:
!>          AB(kl+ku+1+i-j,j) = A(i,j) para max(1,j-ku)<=i<=min(m,j+kl)
!>
!>          En la salida, detalles de la factorización: U se almacena como una
!>          matriz de banda triangular superior con KL+KU superdiagonales en
!>          las filas 1 a KL+KU+1, y los multiplicadores usados durante la
!>          factorización se almacenan en las filas KL+KU+2 a 2*KL+KU+1.
!>          Vea más abajo para más detalles.
!
>

LDA

B 
!>          LDAB es INTEGER
!>          La dimensión principal del arreglo AB.  LDAB >= 2*KL+KU+1.
!
>

IPI

V 
!>          IPIV es un arreglo INTEGER, dimensión (min(M,N))
!>          Los índices de pivote; para 1 <= i <= min(M,N), la fila i de la
!>          matriz fue intercambiada con la fila IPIV(i).
!
>

INF

O 
!>          INFO es INTEGER
!>          = 0: salida exitosa
!>          < 0: si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>          > 0: si INFO = +i, U(i,i) es exactamente cero. La factorización
!>               ha sido completada, pero el factor U es exactamente
!>               singular, y ocurrirá una división por cero si se usa
!>               para resolver un sistema de ecuaciones.
!

NAME

gbtrf - computes the LU factorization of a real or complex band matrix

SYNOPSIS

subroutine sgbtrf(m, n, kl, ku, ab, ldab, ipiv, info)
    integer m, n, kl, ku, ldab, info
    real ab(ldab, *)
    integer ipiv(*)

subroutine zgbtrf(m, n, kl, ku, ab, ldab, ipiv, info)
    integer m, n, kl, ku, ldab, info
    complex*16 ab(ldab, *)
    integer ipiv(*)

Detailed Description

This subroutine computes the LU factorization of a real or complex m-by-n band matrix A using partial pivoting with row interchanges. The factorization is computed in blocked form, utilizing Level 3 BLAS routines.

The band storage scheme is defined as follows:

The matrix A is stored in an array AB of dimension (LDAB, N). The j-th column of A is stored in the j-th column of AB. Specifically, the element A(i,j) is stored at AB(kl+ku+1+i-j, j) for max(1, j-ku) <= i <= min(m, j+kl).

On exit, the array AB contains the details of the factorization. The upper triangular factor U is stored in the upper part of AB, and the multipliers used during the factorization are stored in the lower part of AB.

The array IPIV stores the pivot indices. For each i, row i was interchanged with row IPIV(i).

The subroutine returns an integer INFO, which indicates the status of the factorization:

  • INFO = 0: successful exit.
  • INFO < 0: if INFO = -i, then the i-th argument had an illegal value.
  • INFO > 0: if INFO = +i, then the diagonal element U(i,i) is exactly zero. The factorization is complete, but the factor U is singular, and division by zero will occur if it is used to solve a system of equations.

subroutine sgbtrf (integer m, integer n, integer kl, integer ku, real, dimension( ldab, * ) ab, integer ldab, integer, dimension( * ) ipiv, integer info)

SGBTRF

Purpose:

!>
!> SGBTRF computes an LU factorization of a real m-by-n band matrix A
!> using partial pivoting with row interchanges.
!>
!> This is the blocked version of the algorithm, calling Level 3 BLAS.
!>

Parameters

M 
!>          M is INTEGER
!>          The number of rows of the matrix A.  M >= 0.
!>

N

!>          N is INTEGER
!>          The number of columns of the matrix A.  N >= 0.
!>

KL

!>          KL is INTEGER
!>          The number of subdiagonals within the band of A.  KL >= 0.
!>

KU

!>          KU is INTEGER
!>          The number of superdiagonals within the band of A.  KU >= 0.
!>

AB

!>          AB is REAL array, dimension (LDAB,N)
!>          On entry, the matrix A in band storage, in rows KL+1 to
!>          2*KL+KU+1; rows 1 to KL of the array need not be set.
!>          The j-th column of A is stored in the j-th column of the
!>          array AB as follows:
!>          AB(kl+ku+1+i-j,j) = A(i,j) for max(1,j-ku)<=i<=min(m,j+kl)
!>
!>          On exit, details of the factorization: U is stored as an
!>          upper triangular band matrix with KL+KU superdiagonals in
!>          rows 1 to KL+KU+1, and the multipliers used during the
!>          factorization are stored in rows KL+KU+2 to 2*KL+KU+1.
!>          See below for further details.
!>

LDAB

!>          LDAB is INTEGER
!>          The leading dimension of the array AB.  LDAB >= 2*KL+KU+1.
!>

IPIV

!>          IPIV is INTEGER array, dimension (min(M,N))
!>          The pivot indices; for 1 <= i <= min(M,N), row i of the
!>          matrix was interchanged with row IPIV(i).
!>

INFO

!>          INFO is INTEGER
!>          = 0: successful exit
!>          < 0: if INFO = -i, the i-th argument had an illegal value
!>          > 0: if INFO = +i, U(i,i) is exactly zero. The factorization
!>               has been completed, but the factor U is exactly
!>               singular, and division by zero will occur if it is used
!>               to solve a system of equations.
!>

!>
!>  On entry:                       On exit:
!>
!>      *    *    *    +    +    +       *    *    *   u14  u25  u36

!>      *   a12  a23  a34  a45  a56      *   u12  u23  u34  u45  u56
