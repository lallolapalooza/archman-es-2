NOMBRE

gbx3 - Intérprete de GAMBAS

SINOPSIS

gbx3 [opciones] [<directorio de proyecto>] [-- <argumentos>]
gbx3 -e <expresión>

DESCRIPCIÓN

Gambas es un entorno de desarrollo libre basado en un intérprete Basic con extensiones de objetos, una mezcla de Java(tm) y Visual Basic(tm). Con Gambas, puedes diseñar rápidamente la GUI de tu programa con Qt o GTK+, acceder a sistemas de bases de datos como MySQL, PostgreSQL, SQlite u ODBC, pilotar aplicaciones con DBus, traducir tu programa a muchos idiomas, crear aplicaciones GStreamer, OpenGL o SDL, y mucho más...

gbx3 es el intérprete que te permite ejecutar un proyecto Gambas o evaluar una expresión Gambas (opción -e).

OPCIONES

-a <ruta>
Sobrescribe la ruta de la aplicación
-e
Evalúa una expresión
-g
Entra en modo depuración
-h, --help
Muestra la ayuda y sale
-H, --httpd
Ejecuta a través de un servidor http incrustado
-j
Deshabilita el compilador just-in-time
-k
No descarga las bibliotecas compartidas
-L, --license
Muestra la licencia
-p <ruta>
Activa el modo de perfilado y depuración
-r <ruta>
Redirige la salida de error estándar
-s <clase>
Sobrescribe la clase de inicio
-t, --trace
Muestra la posición de cada línea de código ejecutada
-T
Lista todos los módulos de prueba
-T <pruebas>
Ejecuta los módulos de prueba especificados
-V, --version
Muestra la versión

VARIABLES DE ENTORNO

GB_DB_DEBUG
Establecida a "1" para habilitar la depuración del componente de base de datos.
GB_GUI
Define el componente GUI que será cargado por la familia de componentes 'gb.gui*'.
GB_GUI_DARK_THEME
Establecida a "1" para forzar el comportamiento del tema oscuro.
GB_GUI_PLATFORM
Define la plataforma gráfica utilizada por los componentes GUI. Puede ser "x11" o "wayland".
GB_HTTPD_DEBUG
Establecida a "1" para habilitar el modo de depuración del servidor web incrustado.
GB_HTTPD_HOST
Define el nombre de host utilizado por el servidor web incrustado.
GB_HTTPD_PORT
Define el puerto utilizado por el servidor web incrustado.
GB_HTTPD_TIMEOUT
Define el tiempo de espera de la solicitud del servidor web incrustado.
GB_JIT_CACHE
Establecida a "0" para usar el antiguo proceso de compilación que no utiliza ninguna caché.
GB_JIT_CC
Define el compilador utilizado por el componente just-in-time. "gcc" o "clang" son compatibles en este momento.
GB_JIT_CFLAGS
Define las banderas de compilación utilizadas para generar código just-in-time.
GB_JIT_DEBUG
Establecida a "1" para habilitar la depuración del compilador just-in-time.
GB_JIT_ENABLED
Establecida a "0" para deshabilitar el compilador just-in-time.
GB_JIT_FORCE
Establecida a "1" para ignorar la caché y forzar una nueva compilación de código just-in-time.
GB_JIT_TRACE
Establecida a "1" para mostrar cada línea ejecutada por el código compilado just-in-time.
GB_MEDIA_DEBUG
Establecida a "1" para habilitar la depuración del componente 'gb.media'.
GB_NO_JIT
Establecida a "1" para deshabilitar el compilador just-in-time.
GB_REVERSE
Establecida a "1" para invertir la dirección del idioma.
GB_STOCK_DEBUG
Establecida a "1" para habilitar la depuración del tema de iconos.
GB_WEB_GUI_DEBUG
Establecida a "1" para habilitar la depuración del componente 'gb.web.gui'.
