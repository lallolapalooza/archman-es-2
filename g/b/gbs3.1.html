DESCRIPCIÓ

N

Gambas es un entorno de desarrollo gratuito basado en un intérprete de Basic con extensiones orientadas a objetos, una mezcla de Java(tm) y Visual Basic(tm). Con Gambas, puedes diseñar rápidamente la interfaz gráfica de tu programa con Qt o GTK+, acceder a sistemas de bases de datos como MySQL, PostgreSQL, SQlite o bases de datos ODBC, pilotar aplicaciones con DBus, traducir tu programa a muchos idiomas, crear aplicaciones GStreamer, OpenGL o SDL, y así sucesivamente..

.

gbs3 es el intérprete que permite compilar y ejecutar un script de Gambas.
gbs3 también puede usarse para convertir un proyecto de Ga

mbas a un script o un sc
ript de vuelta a un proyecto.

CONVERSIÓN DE

PROYECTOS

gbs3 puede convertir un proyecto de Gambas en un archivo de script ejecutable usando la opción --convert-project. El directorio de proyecto de entrada se usa para crear el script, que se escribe en el directorio de script de salida. El script se crea y se nombra igual que el proyecto de origen.
gbs3 MyProjectDirectory DestinationScriptDirecto

CONVERSIÓN DE

SCRIPTS

gbs3 puede convertir un archivo de script en un proyecto completo de Gambas usando la opción --convert-script.
El script de entrada se traduce en un proyecto con el mismo nombre base que el script y se crea en el directorio especificado. En el caso de que no se especifique un directorio de salida, la variable de entorno PWD se usa como ubicación para crear el proyecto de Gambas.
gbs3 MyScript.gbs ~/Projects
Esto creó el directorio del pro

yecto 'MyScript' en el directo
rio 'Projects' del usuario.

PLUGIN

S

gbs3 puede crear plugins que pueden ser usados por otros scripts o aplicaciones de Gambas después de ser compilados usando la opción --plugin o -p. Los plugins se crean en un directorio seleccionado por el usuario y también se ejecutan y se almacenan en caché en este directorio, a diferencia de un script normal, en el que los ejecutables se crean en el directorio temporal y se ejecutan desde allí. Esto permite que los plugins persistan después de que el scripter salga.
Si no se especifica un destino de salida, entonces el plugin se crea en el directorio ~/.local/lib/gambas. y puede ser cargado desde allí usando la función component.load().
gbs3 MyPluginScript [Direct

orio de Desti
no del Plugin]
