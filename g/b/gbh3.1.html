NOMBRE

gbh3 - Extractor de ayuda de GAMBAS

SINOPSIS

gbh3 [opciones] [<fuentes>]

DESCRIPCIÓN

Gambas es un entorno de desarrollo libre basado en un intérprete Basic con extensiones de objetos, una mezcla de Java(tm) y Visual Basic(tm). Con Gambas, puedes diseñar rápidamente la GUI de tu programa con Qt o GTK+, acceder a sistemas de bases de datos como MySQL, PostgreSQL, SQlite u ODBC, pilotar aplicaciones con DBus, traducir tu programa a muchos idiomas, crear aplicaciones GStreamer, OpenGL o SDL, y más...

gbh3 se utiliza para extraer la documentación de Gambas de archivos fuente C/C++ y crear archivos .help para un componente a partir de ellos.

OPCIONES

-r, --root <raíz>
indica el directorio de instalación de Gambas
-c, --component <componente>
genera la ayuda directamente en un archivo '*.help' de componente
-v, --verbose
ejecutar en modo verboso
-V, --version
muestra la versión
-L, --license
muestra la licencia
-h, --help
muestra la ayuda y sale

DISPONIBILIDAD

La última versión de Gambas siempre se puede obtener en gambas.sourceforge.net, la documentación sobre el lenguaje está en http://gambaswiki.org/wiki.
