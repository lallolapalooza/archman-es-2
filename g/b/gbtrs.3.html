CGBTRS

Propósito:

!>
!> CGBTRS resuelve un sistema de ecuaciones lineales
!>    A * X = B,  A**T * X = B,  o  A**H * X = B
!> con una matriz de banda general A usando la factorización LU computada
!> por CGBTRF.
!>

Parámetros

TRANS 
!>          TRANS es CHARACTER*1
!>          Especifica la forma del sistema de ecuaciones.
!>          = 'N':  A * X = B     (Sin transponer)
!>          = 'T':  A**T * X = B  (Transpuesta)
!>          = 'C':  A**H * X = B  (Transpuesta conjugada)
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

KL

!>          KL es INTEGER
!>          El número de subdiagonales dentro de la banda de A.  KL >= 0.
!>

KU

!>          KU es INTEGER
!>          El número de superdiagonales dentro de la banda de A.  KU >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de lados derechos, es decir, el número de columnas
!>          de la matriz B.  NRHS >= 0.
!>

AB

!>          AB es un array COMPLEX, de dimensión (LDAB,N)
!>          Detalles de la factorización LU de la matriz de banda A, tal como
!>          la computa CGBTRF. U se almacena como una matriz triangular superior de banda
!>          con KL+KU superdiagonales en las filas 1 a KL+KU+1, y
!>          los multiplicadores usados durante la factorización se almacenan en
!>          las filas KL+KU+2 a 2*KL+KU+1.
!>

LDAB

!>          LDAB es INTEGER
!>          La dimensión principal del array AB.  LDAB >= 2*KL+KU+1.
!>

IPIV

!>          IPIV es un array INTEGER, de dimensión (N)
!>          Los índices de pivote; para 1 <= i <= N, la fila i de la matriz fue
!>          intercambiada con la fila IPIV(i).
!>

B

!>          B es un array COMPLEX, de dimensión (LDB,NRHS)
!>          En la entrada, la matriz del lado derecho B.
!>          En la salida, la matriz solución X.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B.  LDB >= max(1,N).
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tuvo un valor ilegal
!>
