NOMBRE

gbz80 — referencia de opcodes de la CPU

DESCRIPCIÓN

Esta es la lista de opcodes soportados por rgbasm(1), incluyendo una breve descripción, el número de bytes necesarios para codificarlos y el número de ciclos de CPU a 1MHz (o 2MHz en modo de doble velocidad de GBC) necesarios para completarlos.

Nota: Todas las instrucciones aritméticas y lógicas que usan el registro A como destino pueden omitir el destino, ya que se asume que es el registro A por defecto. Por lo tanto, las siguientes dos líneas tienen el mismo efecto:

OR A,B
OR B

Además, la instrucción CPL puede tomar un destino opcional A, ya que solo puede ser el registro A. Por lo tanto, las siguientes dos líneas tienen el mismo efecto:

CPL
CPL A

LEYENDA

Lista de abreviaturas utilizadas en este documento.

r8
Cualquiera de los registros de 8 bits (A, B, C, D, E, H, L).
r16
Cualquiera de los registros generales de 16 bits (BC, DE, HL).
n8
Constante entera de 8 bits (con signo o sin signo, de -128 a 255).
n16
Constante entera de 16 bits (con signo o sin signo, de -32768 a 65535).
e8
Desplazamiento con signo de 8 bits (de -128 a 127).
u3
Índice de bit sin signo de 3 bits (de 0 a 7, con 0 como el bit menos significativo).
cc
Un código de condición:
Z
Ejecutar si Z está establecido.
NZ
Ejecutar si Z no está establecido.
C
Ejecutar si C está establecido.
NC
Ejecutar si C no está establecido.
vec
Un vector RST (0x00, 0x08, 0x10, 0x18, 0x20, 0x28, 0x30 y 0x38).

POP AF

Saca el registro AF de la pila. Esto es aproximadamente equivalente a las siguientes instrucciones imaginarias:

LD F, [SP]  ; Ver abajo para los flags individuales
INC SP
LD A, [SP]
INC SP

Ciclos: 3

Bytes: 1

Flags:

Z
Establecido a partir del bit 7 del byte bajo extraído.
N
Establecido a partir del bit 6 del byte bajo extraído.
H
Establecido a partir del bit 5 del byte bajo extraído.
C
Establecido a partir del bit 4 del byte bajo extraído.

POP r16

Saca el registro r16 de la pila. Esto es aproximadamente equivalente a las siguientes instrucciones imaginarias:

LD LOW(r16), [SP]   ; C, E o L
INC SP
LD HIGH(r16), [SP]  ; B, D o H
INC SP

Ciclos: 3

Bytes: 1

Flags: Ninguno afectado.

DEC SP

DEC SP

Bytes: 1

Flags: Ninguno afectado.

Retorna de la subrutina. Esto es básicamente un POP PC (si tal instrucción existiera). Ver POP r16 para una explicación de cómo POP funciona.

Retorna de la subrutina y habilita las interrupciones. Esto es básicamente equivalente a ejecutar EI y luego RET, lo que significa que IME se establece justo después de esta instrucción.
