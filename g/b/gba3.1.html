NOMBRE

gba3 - Archiver de GAMBAS

SINOPSIS

gba3 [opciones] [<directorio del proyecto>]
gba3 -x <ruta del archivo> <archivo>

DESCRIPCIÓN

Gambas es un entorno de desarrollo gratuito basado en un intérprete Basic con extensiones de objetos, una mezcla de Java(tm) y Visual Basic(tm). Con Gambas, puedes diseñar rápidamente la GUI de tu programa con Qt o GTK+, acceder a sistemas de bases de datos como MySQL, PostgreSQL, SQlite u ODBC, pilotar aplicaciones con DBus, traducir tu programa a muchos idiomas, crear aplicaciones GStreamer, OpenGL o SDL, y mucho más...

gba3 es el archiver que te permite crear un ejecutable autocontenido de un solo archivo a partir de un proyecto Gambas o extraer un archivo específico de un ejecutable Gambas (opción -x).

OPCIONES

-h, --help
muestra la ayuda y sale
-i, --ignore=RUTA
excluir un archivo o directorio específico
-l, --list=ARCHIVO
listar archivos del archivo
-L, --license
mostrar la licencia
-o, --output=ARCHIVO
ruta del archivo [<directorio del proyecto>/<nombre del proyecto>.gambas]
-p, --ignore-public
excluir el directorio '.public'
-s, --swap
intercambiar el orden de los bytes (endianness)
-x, --extract=ARCHIVO
ruta del archivo
-v, --verbose
salida detallada
-V, --version
mostrar la versión

DISPONIBILIDAD

La última versión de Gambas siempre se puede obtener en gambas.sourceforge.net, la documentación sobre el lenguaje está en http://gambaswiki.org/wiki.
