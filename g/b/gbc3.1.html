NOMBRE

gbc3 - Compilador de GAMBAS

SINOPSIS

gbc3 [opciones] [<directorio del proyecto>]

DESCRIPCIÓN

Gambas es un entorno de desarrollo libre basado en un intérprete Basic con extensiones de objetos, una mezcla de Java(tm) y Visual Basic(tm). Con Gambas, puedes diseñar rápidamente la GUI de tu programa con Qt o GTK+, acceder a sistemas de bases de datos como MySQL, PostgreSQL, SQLite u ODBC, pilotar aplicaciones con DBus, traducir tu programa a muchos idiomas, crear aplicaciones GStreamer, OpenGL o SDL, y mucho más...

gbc3 es el compilador que te permite compilar proyectos de Gambas en bytecode independiente de la arquitectura.

OPCIONES

-a, --all
compilar todo
-b, --bytecode-version
forzar una versión específica de bytecode
-d, --output-desc
generar archivos de descripción de clases para el IDE
-e, --translate-errors
mostrar mensajes de error traducibles
-F, --form <archivo de formulario>
convertir un archivo de formulario a código e imprimirlo
-g, --debug
añadir información de depuración
-h, --help
mostrar ayuda y salir
-j, --jobs <contador>
número de trabajos en segundo plano (por defecto: <número de núcleos de CPU>)
-L, --license
mostrar licencia
-n, --default-namespace <espacio de nombres>
espacio de nombres predeterminado para clases exportadas
-q --quiet
no imprimir nada si la compilación tiene éxito
-r, --root <directorio>
indica el directorio de instalación de gambas
-s, --swap
intercambiar el orden de bytes (endianness)
-t, --translate
generar archivos de traducción
-v, --verbose
salida detallada
-V, --version
mostrar versión
-w, --warnings
mostrar advertencias
-x, --exec
definir la constante del preprocesador 'Exec'

FLAGS DEL COMPILADOR

-f check-prefix
comprobar el prefijo de las variables si las advertencias están activadas
-f public-module
los símbolos de módulo son públicos por defecto
-f public-control
los controles del formulario son públicos

DISPONIBILIDAD

La última versión de Gambas siempre se puede obtener en gambas.sourceforge.net, la documentación sobre el lenguaje está en http://gambaswiki.org/wiki.
