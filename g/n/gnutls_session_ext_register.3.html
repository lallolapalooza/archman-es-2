gnutls_session_ext_register(3) gnutls gnutls_session_ext_register(3)

NOMBRE

gnutls_session_ext_register - función de la API

SINOPSIS

#include <gnutls/gnutls.h>

int gnutls_session_ext_register(gnutls_session_t session, const char * name, int id, gnutls_ext_parse_type_t parse_point, gnutls_ext_recv_func recv_func, gnutls_ext_send_func send_func, gnutls_ext_deinit_data_func deinit_func, gnutls_ext_pack_func pack_func, gnutls_ext_unpack_func unpack_func, unsigned flags);

ARGUMENTOS

gnutls_session_t session
la sesión para la cual se establecerá esta extensión
const char * name
el nombre de la extensión a registrar
int id
el id numérico de la extensión
gnutls_ext_parse_type_t parse_point
el tipo de análisis de la extensión (ver gnutls_ext_parse_type_t)
gnutls_ext_recv_func recv_func
una función para recibir los datos
gnutls_ext_send_func send_func
una función para enviar los datos
gnutls_ext_deinit_data_func deinit_func
una función para desinicializar cualquier dato privado
gnutls_ext_pack_func pack_func
una función que serializa los datos privados de la extensión (se usa al empaquetar la sesión para reanudación)
gnutls_ext_unpack_func unpack_func
una función que deserializará los datos privados de la extensión
unsigned flags
debe ser cero o flags de gnutls_ext_flags_t

DESCRIPCIÓN

Esta función registrará un nuevo tipo de extensión. La extensión solo será utilizable dentro de la sesión registrada. Si el tipo de extensión ya está registrado, se devolverá GNUTLS_E_ALREADY_REGISTERED, a menos que se especifique el flag GNUTLS_EXT_FLAG_OVERRIDE_INTERNAL. Este último flag, cuando se especifica, puede usarse para anular ciertas extensiones introducidas después de 3.6.0. Se espera que sea utilizado por aplicaciones que manejan extensiones personalizadas que no están actualmente soportadas en GnuTLS, pero que pueden ser añadidas en el futuro.

Cada extensión registrada puede almacenar datos temporales en la estructura gnutls_session_t usando gnutls_ext_set_data(), y estos pueden ser recuperados usando gnutls_ext_get_data().

La validez de la extensión registrada puede ser dada por los flags apropiados de gnutls_ext_flags_t. Si no se proporciona validez, la extensión registrada será válida para el cliente y para el servidor TLS1.2 hello (o extensiones cifradas para TLS1.3).

RETORNA

GNUTLS_E_SUCCESS en caso de éxito, de lo contrario un código de error negativo.
