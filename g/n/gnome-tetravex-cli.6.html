NOMBRE

Tetravex - Un juego de puzzle simple para jugar en CLI

SINOPSIS

gnome-tetravex-cli [OPCIÓN...] [COMANDO]

DESCRIPCIÓN

GNOME Tetravex es un puzzle simple donde las piezas deben posicionarse de tal manera que los mismos números estén tocándose entre sí.
Este es un programa CLI; ver también `gnome-tetravex` para la aplicación Gtk.

OPCIONES

-c, --colores=NÚMERO
Establece el número de colores (2-10)
-s, --tamaño=TAMAÑO
Establece el tamaño del tablero (2-6)
-v, --versión
Imprime la versión de lanzamiento y sale

COMANDO

A1b2
Invierte dos fichas, la del tablero inicial A1 y la del tablero b2.
Una mayúscula se dirige a una ficha del tablero inicial.
Una minúscula se dirige a una ficha del tablero izquierdo/final.
Los dígitos especifican las filas de las dos fichas a invertir.

(nada)
estado
mostrar

Muestra el puzzle actual.
nuevo
Crea un nuevo puzzle; para cambiar el tamaño, usa --tamaño.
resolver
Rendirse con el puzzle actual y ver la solución.

terminar
fin

Termina el puzzle actual, automáticamente. Funciona para puzzles resueltos correctamente o si queda una ficha.

arriba,    i-arriba
abajo,  i-abajo
izquierda, i-izquierda
derecha, i-derecha

Mueve todas las fichas del tablero izquierdo hacia arriba/abajo/izquierda/derecha en uno.

d-arriba
d-abajo
d-izquierda
d-derecha

Mueve todas las fichas del tablero derecho hacia arriba/abajo/izquierda/derecha en uno.
