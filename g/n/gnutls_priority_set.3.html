NOMBRE

gnutls_priority_set - función de la API

SINOPSIS

#include <gnutls/gnutls.h>

int gnutls_priority_set(gnutls_session_t session, gnutls_priority_t priority);

ARGUMENTOS

gnutls_session_t session
es un tipo gnutls_session_t.
gnutls_priority_t priority
es un tipo gnutls_priority_t.

DESCRIPCIÓN

Establece las prioridades a utilizar en los cifrados, métodos de intercambio de claves y MACs. Tenga en cuenta que se espera que esta función se llame una vez por sesión; cuando se llama varias veces (por ejemplo, antes de un re-handshake, el llamador debe asegurarse de que cualquier configuración nueva no sea incompatible con la sesión original).

RETORNOS

GNUTLS_E_SUCCESS en caso de éxito, o un código de error en caso de error.
