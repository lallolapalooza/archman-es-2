NOMBRE

gnutls_handshake - Función de la API

SINOPSIS

#include <gnutls/gnutls.h>

int gnutls_handshake(gnutls_session_t session);

ARGUMENTOS

gnutls_session_t session
es un tipo gnutls_session_t.

DESCRIPCIÓN

Esta función realiza el handshake del protocolo TLS/SSL, e inicializa los parámetros de la sesión TLS.

Los errores no fatales esperados por esta función son: GNUTLS_E_INTERRUPTED, GNUTLS_E_AGAIN, GNUTLS_E_WARNING_ALERT_RECEIVED. Cuando esta función se llama para un re-handshake bajo TLS 1.2 o anterior, el código de error no fatal GNUTLS_E_GOT_APPLICATION_DATA también puede ser devuelto.

Los dos primeros interrumpen el procedimiento de handshake debido a la interrupción de la capa de transporte, y el último debido a una alerta de "advertencia" enviada por el par (siempre es una buena idea verificar cualquier alerta recibida). En estos errores no fatales, llame a esta función nuevamente, hasta que devuelva 0; véase gnutls_record_get_direction() y gnutls_error_is_fatal(). En sesiones DTLS, el error no fatal GNUTLS_E_LARGE_PACKET también es posible, e indica que la MTU debería ajustarse.

Cuando esta función es llamada por un servidor después de una solicitud de re-handshake bajo TLS 1.2 o anterior, el código de error GNUTLS_E_GOT_APPLICATION_DATA indica que algunos datos estaban pendientes antes de que el par iniciara el handshake. Bajo TLS 1.3, esta función, cuando se llama después de un handshake exitoso, no hace nada y siempre tiene éxito en el lado del servidor; en el lado del cliente, esta función es equivalente a gnutls_session_key_update() con la bandera GNUTLS_KU_PEER.

Esta función maneja tanto handshakes TLS completos como abreviados (reanudación). Para handshakes abreviados, en el lado del cliente, se debe llamar a gnutls_session_set_data() antes de esta función para establecer los parámetros de una sesión anterior. En el lado del servidor, la reanudación se maneja estableciendo un backend de base de datos o configurando claves para tickets de sesión.

DEVUELVE

GNUTLS_E_SUCCESS en un handshake exitoso, de lo contrario, un código de error negativo.
