DESCRIPCIÓ

N

Establece las prioridades para los cifrados, métodos de intercambio de claves y MACs. El priority_cache debe ser desinicializado usando gnutls_priority_d

einit().

La opción priorities le permite especificar una lista de prioridades de cifrado separada por dos puntos para habilitar. Se definen algunas palabras clave para proporcionar un acceso rápido a las preferencias

comunes.

Cuando flags se establece en GNUTLS_PRIORITY_INIT_DEF_APPEND entonces las prioridades especificadas se añadirán a las opciones predeterminadas

.

A menos que haya una necesidad especial, use la palabra clave "NORMAL" para aplicar un nivel de seguridad razonable, o "NORMAL:%COMPAT" para

compatibilidad.

"PERFORMANCE" significa que todos los conjuntos de cifrado "seguros" están habilitados, limitados a cifrados de 128 bits y ordenados por términos de rendimiento de

velocidad.

"LEGACY" las configuraciones NORMALES para GnuTLS 3.2.x o versiones anteriores. No se establece un perfil de verificación, y las primas DH permitidas se consideran débiles hoy en

día.

"NORMAL" significa todos los conjuntos de cifrado "seguros". Los cifrados de 256 bits se incluyen solo como un respaldo. Los cifrados se ordenan por margen de

seguridad.

"PFS" significa todos los conjuntos de cifrado "seguros" que admiten secreto perfecto hacia adelante. Los cifrados de 256 bits se incluyen solo como un respaldo. Los cifrados se ordenan por margen de

seguridad.

"SECURE128" significa todos los conjuntos de cifrado "seguros" de nivel de seguridad de 128 bits o

más.

"SECURE192" significa todos los conjuntos de cifrado "seguros" de nivel de seguridad de 192 bits o

más.

"SUITEB128" significa todos los conjuntos de cifrado NSA SuiteB con nivel de seguridad de

128.

"SUITEB192" significa todos los conjuntos de cifrado NSA SuiteB con nivel de seguridad de

192.

"NONE" significa que nada está habilitado. Esto deshabilita todo, incluyendo

protocolos.

"@KEYWORD1,KEYWORD2,..." Las configuraciones impuestas por el administrador del sistema. La(s) palabra(s) clave proporcionada(s) se expandirán desde un archivo proporcionado en el momento de la configuración; el predeterminado es: /etc/gnutls/config. Cualquier atributo que le siga se añadirá a la cadena expandida. Si se proporcionan múltiples palabras clave, separadas por comas, se usará la primera palabra clave que exista en el archivo de configuración. Al menos una de las palabras clave debe existir, o esta función devolverá un error. El uso típico sería especificar primero una palabra clave especificada por la aplicación, seguida de "SYSTEM" como un respaldo predeterminado. Por ejemplo, " LIBVIRT ,SYSTEM:!-VERS-SSL3.0" primero intentará encontrar una entrada de archivo de configuración que coincida con "LIBVIRT", pero si esa no existe, usará la entrada para "SYSTEM". Si "SYSTEM" tampoco existe, se devolverá un error. En todos los casos, el protocolo SSL3.0 se deshabilitará. Las entradas del archivo de prioridades del sistema deben tener el formato "KEYWORD=VALUE", por ejemplo, "SYSTEM=NORMAL:

+ARCFOUR-128".

Las palabras clave especiales son "!", "-" y "+". "!" o "-" añadido a un algoritmo eliminará este algoritmo. "+" añadido a un algoritmo añadirá este

algoritmo.

Consulte la sección "Cadenas de

prioridad" del manual de GnuTLS
para información detallada.
