NOMBRE

gnutls_sec_param_to_symmetric_bits - función de la API

SINOPSIS

#include <gnutls/gnutls.h>

unsigned int gnutls_sec_param_to_symmetric_bits(gnutls_sec_param_t param);

ARGUMENTOS

gnutls_sec_param_t param
es un parámetro de seguridad

DESCRIPCIÓN

Esta función devolverá el número de bits que corresponden a la fuerza del cifrado simétrico para el parámetro de seguridad dado.

DEVUELVE

El número de bits, o (0).
