NOMBRE

gnutls_ocsp_resp_verify - función de la API

SINOPSIS

#include <gnutls/ocsp.h>

int gnutls_ocsp_resp_verify(gnutls_ocsp_resp_const_t resp, gnutls_x509_trust_list_t trustlist, unsigned int * verify, unsigned int flags);

ARGUMENTOS

gnutls_ocsp_resp_const_t resp
debería contener un tipo gnutls_ocsp_resp_t
gnutls_x509_trust_list_t trustlist
âncoras de confianza como un tipo gnutls_x509_trust_list_t
unsigned int * verify
variable de salida con el estado de verificación, un gnutls_ocsp_verify_reason_t
unsigned int flags
banderas de verificación de gnutls_certificate_verify_flags

DESCRIPCIÓN

Verifica la firma de la Respuesta OCSP Básica contra la clave pública en el certificado de un firmante de confianza. El trustlist debería estar poblado con âncoras de confianza. La función extraerá el certificado del firmante de la Respuesta OCSP Básica y lo verificará contra el trustlist. Un firmante de confianza es un certificado que está en el trustlist, o está firmado directamente por un certificado en el
trustlist y tiene el bit de uso de clave extendida id-ad-ocspSigning establecido.

La variable de salida verify contendrá códigos de estado de verificación (por ejemplo, GNUTLS_OCSP_VERIFY_SIGNER_NOT_FOUND, GNUTLS_OCSP_VERIFY_INSECURE_ALGORITHM) que solo son válidos si la función devolvió GNUTLS_E_SUCCESS.

Tenga en cuenta que la función devuelve GNUTLS_E_SUCCESS incluso cuando la verificación falla. El llamador siempre debe inspeccionar la variable verify para conocer el estado de verificación.

La variable flags debe ser 0 por ahora.

RETORNOS

En caso de éxito, se devuelve GNUTLS_E_SUCCESS (0), de lo contrario, un valor de error negativo.
