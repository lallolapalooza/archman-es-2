NOMBRE

gnome-calls - Realizar y recibir llamadas

SINOPSIS

gnome-calls [OPCIONES...] [URI SIP/TEL]

DESCRIPCIÓN

gnome-calls es un marcador GTK para PSTN y SIP.

Utiliza ModemManager para comunicarse con el módem celular para PSTN. Además de las llamadas telefónicas, también maneja USSD. En el caso de SIP, utiliza sofia-sip para la señalización SIP y pipelines de GStreamer para manejar la carga útil RTP de datos de audio.

Funciona en escritorios, pero también se adapta a tamaños de pantalla pequeños como teléfonos inteligentes y otros dispositivos móviles.

OPCIONES

-h, --help

Muestra las opciones de ayuda.

--help-all

Muestra todas las opciones de ayuda.

--help-gapplication

Muestra las opciones de GApplication.

--help-gtk

Muestra las opciones de GTK+.

--version

Muestra la versión del programa.

-p, --provider=PLUGIN

Los plugins a utilizar como proveedor de llamadas. Se puede pasar varias veces. Por defecto es ModemManger y SIP (-p mm -p sip).

-l, --dial=NUMBER

Marca un número de teléfono (no es necesario prefijar el esquema de URI tel:).

-d, --daemon

Si se muestra la ventana principal al iniciar.

-v, --verbose

Habilita mensajes de depuración detallados. Se puede pasar varias veces.
