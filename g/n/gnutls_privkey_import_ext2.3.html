NOMBRE

gnutls_privkey_import_ext2 - Función de la API

SINOPSIS

#include <gnutls/abstract.h>

int gnutls_privkey_import_ext2(gnutls_privkey_t pkey, gnutls_pk_algorithm_t pk, void * userdata, gnutls_privkey_sign_func sign_fn, gnutls_privkey_decrypt_func decrypt_fn, gnutls_privkey_deinit_func deinit_fn, unsigned int flags);

ARGUMENTOS

gnutls_privkey_t pkey
La clave privada
gnutls_pk_algorithm_t pk
El algoritmo de clave pública
void * userdata
Datos privados que se proporcionarán a las devoluciones de llamada
gnutls_privkey_sign_func sign_fn
Devolución de llamada para operaciones de firma
gnutls_privkey_decrypt_func decrypt_fn
Devolución de llamada para operaciones de descifrado
gnutls_privkey_deinit_func deinit_fn
Una función de desinicialización
unsigned int flags
Banderas para la importación

DESCRIPCIÓN

Esta función asociará las devoluciones de llamada dadas con el tipo gnutls_privkey_t. Al menos una de las dos devoluciones de llamada debe ser distinta de nulo. Si se proporciona una función de desinicialización, se asume que las banderas contienen GNUTLS_PRIVKEY_IMPORT_AUTO_RELEASE.

Tenga en cuenta que se supone que la función de firma firma datos "en crudo", es decir, sin ningún hash ni preprocesamiento. En el caso de RSA, se proporcionará el DigestInfo, y se espera que la función de firma realice el relleno PKCS 1 1.5 y la exponenciación.

Véase también gnutls_privkey_import_ext3().

RETORNA

En caso de éxito, se devuelve GNUTLS_E_SUCCESS (0), de lo contrario, un valor de error negativo.
