gnutls_x509_crq_get_dn_by_oid(3)

gnutls_x509_crq_get_dn_by_oid(3) gnutls gnutls_x509_crq_get_dn_by_oid(3)

NOMBRE

gnutls_x509_crq_get_dn_by_oid - función de la API

SINOPSIS

#include <gnutls/x509.h>

int gnutls_x509_crq_get_dn_by_oid(gnutls_x509_crq_t crq, const char * oid, unsigned indx, unsigned int raw_flag, void * buf, size_t * buf_size);

ARGUMENTOS

gnutls_x509_crq_t crq
debería contener un tipo gnutls_x509_crq_t
const char * oid
contiene un Identificador de Objeto en una cadena terminada en nulo
unsigned indx
En caso de que existan múltiples OID iguales en el RDN, esto especifica cuál obtener. Use (0) para obtener el primero.
unsigned int raw_flag
Si es distinto de cero, devuelve los datos DER brutos de la parte DN.
void * buf
un puntero a una estructura para contener el nombre (puede ser NULL)
size_t * buf_size
inicialmente contiene el tamaño de buf

DESCRIPCIÓN

Esta función extraerá la parte del nombre del sujeto de la solicitud de Certificado, especificada por el OID dado. La salida se codificará según se describe en RFC2253. La cadena de salida será codificada en ASCII o UTF-8, dependiendo de los datos del certificado.

Algunas macros de ayuda con OID populares se pueden encontrar en gnutls/x509.h. Si la bandera raw es (0), esta función solo devolverá OID conocidos como texto. Otros OID se codificarán en DER, como se describe en RFC2253, en formato hexadecimal utilizando gnutls_x509_dn_oid_known().

VALOR DEVUELTO

GNUTLS_E_SHORT_MEMORY_BUFFER si el búfer proporcionado no es lo suficientemente largo, y en ese caso * buf_size se actualizará con el tamaño requerido. En caso de éxito, se devuelve 0.
