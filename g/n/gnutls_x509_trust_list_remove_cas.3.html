gnutls_x509_trust_list_remove_cas(3) gnutls gnutls_x509_trust_list_remove_cas(3)

NOMBRE

gnutls_x509_trust_list_remove_cas - función de API

SINOPSIS

#include <gnutls/x509.h>

int gnutls_x509_trust_list_remove_cas(gnutls_x509_trust_list_t list, const gnutls_x509_crt_t * clist, unsigned clist_size);

ARGUMENTOS

gnutls_x509_trust_list_t list
La lista
const gnutls_x509_crt_t * clist
Una lista de CAs
unsigned clist_size
La longitud de la lista de CAs

DESCRIPCIÓN

Esta función eliminará las autoridades certificadoras dadas de la lista de confianza.

Tenga en cuenta que esta función puede aceptar certificados y autoridades que aún no se conocen. En ese caso, se mantendrán en un bloque de lista separado que se utilizará durante la verificación del certificado. A diferencia de gnutls_x509_trust_list_add_cas(), no hay una restricción de desinicialización para la lista de certificados proporcionada en esta función.

DEVUELVE

Se devuelve el número de elementos eliminados.
