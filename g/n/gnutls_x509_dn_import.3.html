NOMBRE

gnutls_x509_dn_import - Función de API

SINOPSIS

#include <gnutls/x509.h>

int gnutls_x509_dn_import(gnutls_x509_dn_t dn, const gnutls_datum_t * data);

ARGUMENTOS

gnutls_x509_dn_t dn
la estructura que contendrá el DN importado
const gnutls_datum_t * data
debe contener una secuencia RDN codificada en DER

DESCRIPCIÓN

Esta función analiza una secuencia RDN y almacena el resultado en un tipo gnutls_x509_dn_t. Los datos deben haber sido inicializados con gnutls_x509_dn_init(). Puede usar gnutls_x509_dn_get_rdn_ava() para decodificar el DN.

DEVOLUCIONES

En caso de éxito, se devuelve GNUTLS_E_SUCCESS (0), de lo contrario, un valor de error negativo.
