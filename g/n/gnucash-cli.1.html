NOMBRE

gnucash-cli - herramienta de línea de comandos para acompañar a GnuCash

SINOPSIS

gnucash-cli [opciones] [ cuentas.gnucash ]

DESCRIPCIÓN

gnucash-cli permite ciertas interacciones con un archivo de datos de gnucash directamente desde la línea de comandos.

Tiene dos modos: modo quotes (cotizaciones) y modo report (informe).

Modo Cotizaciones (activado con --quotes <cmd>)

Este modo tiene opciones para obtener cotizaciones en línea de divisas y acciones extranjeras en el archivo de datos dado. Soporta el siguiente comando:

info
Muestra la versión de Finance::Quote y las fuentes de cotización expuestas.
get
Recupera cotizaciones en línea. Tenga en cuenta que esto requiere que Finance::Quote esté configurado correctamente para su sistema.

El comando get toma las siguientes opciones:

--namespace=REGEXP
Expresión regular que determina qué productos de nombres se recuperarán.
dump
Obtiene las cotizaciones actuales de divisas o acciones especificadas de un espacio de nombres especificado e imprime los resultados en la consola. Esto debe ir seguido de una fuente y uno o más símbolos, a menos que la fuente sea "currency" en cuyo caso debe ir seguida de dos o más símbolos, el primero de los cuales es la divisa en la que se cotizarán las demás.

El comando dump toma la opción

-v
--verbose
Enumera todos los parámetros que Finance::Quote devuelve para el símbolo en lugar de solo los que Gnucash requiere.

Modo Informe (activado con --report <cmd>)

Este modo tiene opciones para trabajar con informes en el archivo de datos dado. Soporta el siguiente comando:

run
Ejecuta un informe en el archivo de datos dado.

El comando run toma las siguientes opciones:

--name=NOMBRE_DEL_INFORME
Nombre del informe a ejecutar
--export-type=TIPO
Especificar el tipo de exportación

Opciones Generales

--version
Muestra la versión de GnuCash
--help
Muestra este mensaje de ayuda
--debug
Habilita el modo de depuración: aumenta el registro para proporcionar detalles profundos.
--extra
Habilita características adicionales/de desarrollo/depuración.
--log
Anulaciones del nivel de registro, del tipo "log.ger.path={debug,info,warn,crit,error}" Esta opción se puede especificar varias veces.
--logto
Archivo en el que registrar; por defecto es "$TMPDIR/gnucash.trace"; use "stderr" o "stdout" para escribir en la terminal.

ARCHIVOS

~/.gnucash/config.auto

Archivo de configuración generado automáticamente por usuario. ¡NO EDITAR MANUALMENTE!

ENTORNO

GNC_DEBUG
Habilita la salida de depuración. Esto le permite activar la depuración antes en el proceso de inicio de lo que puede hacer con --debug.
GUILE_LOAD_PATH
Una anulación de la ruta de carga de scheme de GnuCash. No debería necesitar alterarla. Para más información, consulte el archivo README.
GNC_MODULE_PATH
Una anulación de la ruta de carga de scheme de GnuCash para los módulos de Gnucash. No debería necesitar alterarla. Para más información, consulte el archivo README.

ERRORES

Por favor, informe de cualquier error utilizando el formulario de informe de errores en el sitio web de GnuCash.

VER TAMBIÉN

GnuCash tiene una amplia ayuda en línea disponible en el menú "ayuda".

Información adicional y la última versión están disponibles en el sitio web: https://www.gnucash.org
