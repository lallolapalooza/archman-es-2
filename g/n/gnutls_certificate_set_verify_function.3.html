gnutls_certificate_set_verify_function(3)

gnutls_certificate_set_verify_function(3) gnutls gnutls_certificate_set_verify_function(3)

NOMBRE

gnutls_certificate_set_verify_function - Función de API

SINOPSIS

#include <gnutls/gnutls.h>

void gnutls_certificate_set_verify_function(gnutls_certificate_credentials_t cred, gnutls_certificate_verify_function * func);

ARGUMENTOS

gnutls_certificate_credentials_t cred
es un tipo gnutls_certificate_credentials_t.
gnutls_certificate_verify_function * func
es la función de devolución de llamada

DESCRIPCIÓN

Esta función establece una devolución de llamada para que se llame cuando se reciba el certificado del par, para verificarlo en el momento de la recepción en lugar de hacerlo después de que se complete el handshake.

El prototipo de la función de devolución de llamada es: int (*callback)(gnutls_session_t);

Si se proporciona la función de devolución de llamada, gnutls la llamará durante el handshake, justo después de recibir el mensaje del certificado. Para verificar u obtener el certificado, se pueden usar las funciones gnutls_certificate_verify_peers2(), gnutls_certificate_type_get(), gnutls_certificate_get_peers().

La función de devolución de llamada debe devolver 0 para que el handshake continúe o un valor distinto de cero para terminarlo.
