NOMBRE

gnutls_session_get_id - Función de API

SINOPSIS

#include <gnutls/gnutls.h>

int gnutls_session_get_id(gnutls_session_t session, void * session_id, size_t * session_id_size);

ARGUMENTOS

gnutls_session_t session
es un tipo gnutls_session_t.
void * session_id
es un puntero a un espacio para almacenar el ID de sesión.
size_t * session_id_size
inicialmente debe contener el tamaño máximo de session_id y se actualizará.

DESCRIPCIÓN

Devuelve el identificador de sesión TLS. El ID de sesión es seleccionado por el servidor, y en versiones antiguas de TLS era un identificador único compartido entre cliente y servidor que era persistente a través de la reanudación. En la última versión de TLS (1.3) o TLS con tickets de sesión, la noción de identificadores de sesión no está definida y no se puede confiar en ella para identificar de forma única sesiones entre cliente y servidor.

En el lado del cliente, esta función devuelve el identificador devuelto por el servidor y no se puede asumir que tenga ninguna relación con la reanudación de sesiones. En el lado del servidor, se garantiza que esta función devuelve un identificador persistente de la sesión desde GnuTLS 3.6.4, que puede que no se corresponda necesariamente con el valor del ID de sesión TLS. Antes de esa versión, el valor solo podía considerarse un identificador persistente, en TLS1.2 o anterior y cuando no se utilizaban tickets de sesión.

El valor del identificador de sesión devuelto es siempre menor que GNUTLS_MAX_SESSION_ID_SIZE.

RETORNOS

En caso de éxito, se devuelve GNUTLS_E_SUCCESS (0), de lo contrario se devuelve un código de error.
