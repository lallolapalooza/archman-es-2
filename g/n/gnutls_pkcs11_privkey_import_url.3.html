NOMBRE

gnutls_pkcs11_privkey_import_url - Función de API

SINOPSIS

#include <gnutls/pkcs11.h>

int gnutls_pkcs11_privkey_import_url(gnutls_pkcs11_privkey_t pkey, const char * url, unsigned int flags);

ARGUMENTOS

gnutls_pkcs11_privkey_t pkey
La clave privada
const char * url
una URL PKCS 11 que identifica la clave
unsigned int flags
O una secuencia de banderas GNUTLS_PKCS11_OBJ_*

DESCRIPCIÓN

Esta función "importará" una URL PKCS 11 que identifica una clave privada al tipo gnutls_pkcs11_privkey_t. En realidad, dado que en la mayoría de los casos las claves no pueden ser exportadas, la estructura de la clave privada se asocia con las operaciones disponibles en el token.

RETORNA

En caso de éxito, se devuelve GNUTLS_E_SUCCESS (0), de lo contrario, un valor de error negativo.
