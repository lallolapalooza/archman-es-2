NOMBRE

gnutls_pubkey_export_rsa_raw2 - función de la API

SINOPSIS

#include <gnutls/abstract.h>

int gnutls_pubkey_export_rsa_raw2(gnutls_pubkey_t key, gnutls_datum_t * m, gnutls_datum_t * e, unsigned flags);

ARGUMENTOS

gnutls_pubkey_t key
Contiene el certificado
gnutls_datum_t * m
contendrá el módulo (puede ser NULL)
gnutls_datum_t * e
contendrá el exponente público (puede ser NULL)
unsigned flags
flags de gnutls_abstract_export_flags_t

DESCRIPCIÓN

Esta función exportará los parámetros de la clave pública RSA encontrados en la estructura dada. Los nuevos parámetros se asignarán usando gnutls_malloc() y se almacenarán en el datum apropiado.

Esta función permite parámetros NULL desde la versión 3.4.1.

VALOR DE RETORNO

GNUTLS_E_SUCCESS en caso de éxito, de lo contrario un código de error negativo.
