NOMBRE

gnutls_bye - Función de la API

SINOPSIS

#include <gnutls/gnutls.h>

int gnutls_bye(gnutls_session_t session, gnutls_close_request_t how);

ARGUMENTOS

gnutls_session_t session
es un tipo gnutls_session_t.
gnutls_close_request_t how
es un entero

DESCRIPCIÓN

Termina la conexión TLS/SSL actual. La conexión debe haber sido iniciada usando gnutls_handshake(). how debe ser uno de GNUTLS_SHUT_RDWR, GNUTLS_SHUT_WR.

En el caso de GNUTLS_SHUT_RDWR, la sesión TLS se termina y las recepciones y envíos posteriores se prohibirán. Si el valor de retorno es cero, puede continuar usando la capa de transporte subyacente. GNUTLS_SHUT_RDWR envía una alerta que contiene una solicitud de cierre y espera que el par responda con el mismo mensaje.

En el caso de GNUTLS_SHUT_WR, la sesión TLS se termina y los envíos posteriores se prohibirán. Para reutilizar la conexión, debe esperar un EOF del par. GNUTLS_SHUT_WR envía una alerta que contiene una solicitud de cierre.

Tenga en cuenta que no todas las implementaciones terminarán correctamente una conexión TLS. Algunas de ellas, generalmente por razones de rendimiento, solo terminarán la capa de transporte subyacente, y por lo tanto no distinguirán entre una parte maliciosa que termina la conexión prematuramente y una terminación normal.

Esta función también puede devolver GNUTLS_E_AGAIN o GNUTLS_E_INTERRUPTED; véase gnutls_record_get_direction().

RETORNA

GNUTLS_E_SUCCESS si la operación es exitosa, o un código de error; consulte la documentación de la función para ver la semántica completa.
