gnutls_x509_ext_export_subject_alt_names(3) gnutls gnutls_x509_ext_export_subject_alt_names(3)

NOMBRE

gnutls_x509_ext_export_subject_alt_names - Función API

SINOPSIS

#include <gnutls/x509-ext.h>

int gnutls_x509_ext_export_subject_alt_names(gnutls_subject_alt_names_t sans, gnutls_datum_t * ext);

ARGUMENTOS

gnutls_subject_alt_names_t sans
Los nombres alternativos
gnutls_datum_t * ext
Los datos de la extensión codificados en DER; deben liberarse usando gnutls_free().

DESCRIPCIÓN

Esta función convertirá la estructura de nombres alternativos proporcionada a una extensión PKIX SubjectAltName codificada en DER. Los datos de salida en ext se asignarán usando gnutls_malloc().

VALOR DE RETORNO

En caso de éxito, se devuelve GNUTLS_E_SUCCESS (0), de lo contrario, un valor de error negativo.
