NOMBRE

gnutls_prf - Función API

SINOPSIS

#include <gnutls/gnutls.h>

int gnutls_prf(gnutls_session_t session, size_t label_size, const char * label, int server_random_first, size_t extra_size, const char * extra, size_t outsize, char * out);

ARGUMENTOS

gnutls_session_t session
es un tipo gnutls_session_t.
size_t label_size
longitud de la variable label.
const char * label
etiqueta utilizada en el cálculo de PRF, típicamente una cadena corta.
int server_random_first
distinto de cero si el campo aleatorio del servidor debe ser el primero en la semilla
size_t extra_size
longitud de la variable extra.
const char * extra
datos adicionales opcionales para sembrar el PRF.
size_t outsize
tamaño del búfer de salida preasignado para contener la salida.
char * out
búfer preasignado para contener los datos generados.

DESCRIPCIÓN

Aplica la Pseudo-Función Aleatoria (PRF) de TLS sobre el secreto maestro y los datos proporcionados, sembrada con los campos aleatorios del cliente y del servidor. Para la expansión de claves especificada en RFC5705, véase gnutls_prf_rfc5705().

La variable label generalmente contiene una cadena que denota el propósito de los datos generados. server_random_first indica si el campo aleatorio del cliente o el campo aleatorio del servidor deben ser los primeros en la semilla. Distinto de cero indica que el campo aleatorio del servidor es el primero, 0 que el campo aleatorio del cliente es el primero.

La variable extra se puede usar para agregar más datos a la semilla, después de las variables aleatorias. Se puede utilizar para asegurarse de que la salida generada esté fuertemente conectada a datos adicionales (por ejemplo, una cadena utilizada en la autenticación del usuario).

La salida se coloca en out, que debe estar preasignado.

NOTA

Esta función produce una salida idéntica con gnutls_prf_rfc5705() cuando server_random_first se establece en 0 y extra es NULL. Bajo TLS1.3 esta función solo operará cuando estas condiciones sean verdaderas, o de lo contrario devolverá GNUTLS_E_INVALID_REQUEST.

RETORNOS

GNUTLS_E_SUCCESS en caso de éxito, o un código de error.
