NOMBRE

gnutls_anti_replay_set_add_function - función de API

SINOPSIS

#include <gnutls/gnutls.h>

void gnutls_anti_replay_set_add_function(gnutls_anti_replay_t anti_replay, gnutls_db_add_func add_func);

ARGUMENTOS

gnutls_anti_replay_t anti_replay
es un tipo gnutls_anti_replay_t.
gnutls_db_add_func add_func
es la función.

DESCRIPCIÓN

Establece la función que se utilizará para almacenar una entrada si no está presente en la base de datos de sesiones reanudadas. Esta función devuelve 0 si la entrada se almacena correctamente y un código de error negativo en caso contrario. En particular, si la entrada se encuentra en la base de datos, devuelve GNUTLS_E_DB_ENTRY_EXISTS.

Los argumentos para add_func son: - ptr: el puntero establecido con gnutls_anti_replay_set_ptr() - exp_time: la hora de expiración de la entrada - key: un puntero a la clave - data: un puntero a los datos a almacenar

Los datos establecidos por esta función se pueden examinar usando gnutls_db_check_entry_expire_time() y gnutls_db_check_entry_time().
