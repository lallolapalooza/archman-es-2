NOMBRE

gnome-pie - lanzador de aplicaciones visual para GNOME

SINOPSIS

gnome-pie [OPCIONES]

DESCRIPCIÓN

gnome-pie es un lanzador de aplicaciones visual radial para GNOME. Permite al usuario asociar grupos de aplicaciones usadas frecuentemente a un anillo que aparece al activar una combinación de teclas/ratón.

OPCIONES

Opciones de ayuda:

-h, --help
Muestra las opciones de ayuda
--help-all
Muestra todas las opciones de ayuda
--help-gtk
Muestra las opciones de GTK+

Opciones de aplicación:

-o, --open=ID
Abre el Pie con el ID dado
-r, --reset
Restablece todas las opciones a los valores predeterminados
--display=MOSTRAR
Pantalla X a utilizar
