GNOME-SESSION-INHI(1) Comandos de usuario GNOME-SESSION-INHI(1)

NOMBRE

gnome-session-inhibit - Inhibir la funcionalidad de gnome-session

SINOPSIS

gnome-session-inhibit [OPCIÓN...] [COMANDO]

DESCRIPCIÓN

gnome-session-inhibit puede inhibir ciertas funcionalidades de gnome-session mientras ejecuta el COMANDO dado. Para lograr esto, llama al método Inhibit() de la API D-Bus de gnome-session y crea un inhibidor. El inhibidor se elimina automáticamente cuando gnome-session-inhibit finaliza.

Un caso de uso típico es evitar que la sesión se quede inactiva (y, por lo tanto, bloquee la pantalla) mientras se reproduce un reproductor de vídeo.

OPCIONES

-h, --help

Imprime la ayuda y sale

--version

Imprime información de la versión y sale

--app-id ID

El ID de la aplicación a usar al llamar al método Inhibit() de gnome-session. Si esta opción no se especifica, se usa "unknown".

--reason RAZÓN

Una razón legible por humanos para pasar al llamar al método Inhibit() de gnome-session. Si esta opción no se especifica, se usa "not specified".

--inhibit ACCIÓN

ACCIÓN especifica las acciones a inhibir. Esta opción se puede repetir para inhibir múltiples acciones. Los valores posibles para una ACCIÓN son: logout, switch-user, suspend, idle, automount. Si esta opción no se especifica, se asume "idle".

--inhibit-only

No lanzar COMANDO y esperar para siempre en su lugar

-l, --list

Lista las inhibiciones existentes y sale
