gnutls_pkcs11_token_set_pin(3) gnutls gnutls_pkcs11_token_set_pin(3)

NOMBRE

gnutls_pkcs11_token_set_pin - función de la API

SINOPSIS

#include <gnutls/pkcs11.h>

int gnutls_pkcs11_token_set_pin(const char * token_url, const char * oldpin, const char * newpin, unsigned int flags);

ARGUMENTOS

const char * token_url
Una URL PKCS 11 que especifica un token
const char * oldpin
PIN del usuario anterior
const char * newpin
PIN del nuevo usuario
unsigned int flags
uno de gnutls_pin_flag_t.

DESCRIPCIÓN

Esta función modificará o establecerá el PIN de un usuario o administrador para el token dado. Si se llama para establecer un PIN por primera vez, oldpin debe ser NULL. Al establecer el PIN del administrador con la bandera GNUTLS_PIN_SO, se debe proporcionar el valor de oldpin (este requisito se relaja a partir de GnuTLS 3.6.5, ya que el PIN se solicitará si falta).

RETORNA

En caso de éxito, se devuelve GNUTLS_E_SUCCESS (0), de lo contrario, un valor de error negativo.
