gnutls_x509_crq_set_spki(3) gnutls gnutls_x509_crq_set_spki(3)

NOMBRE

gnutls_x509_crq_set_spki - Función de API

SINOPSIS

#include <gnutls/x509.h>

int gnutls_x509_crq_set_spki(gnutls_x509_crq_t crq, const gnutls_x509_spki_t spki, unsigned int flags);

ARGUMENTOS

gnutls_x509_crq_t crq
una solicitud de certificado de tipo gnutls_x509_crq_t
const gnutls_x509_spki_t spki
una estructura SubjectPublicKeyInfo de tipo gnutls_x509_spki_t
unsigned int flags
debe ser cero

DESCRIPCIÓN

Esta función establecerá explícitamente la información de la clave pública del sujeto de la solicitud de certificado. Esto está destinado a ser utilizado en casos donde una única clave pública (por ejemplo, RSA) puede ser utilizada para múltiples algoritmos de firma (RSA PKCS1-1.5 y RSA-PSS).

Para exportar la clave pública (es decir, la parte SubjectPublicKeyInfo), consulte gnutls_pubkey_import_x509().

VALORES DEVUELTOS

En caso de éxito, se devuelve GNUTLS_E_SUCCESS (0), de lo contrario, un valor de error negativo.
