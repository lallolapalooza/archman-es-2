NOMBRE

gnutls_pubkey_import_rsa_raw - función de API

SINOPSIS

#include <gnutls/abstract.h>

int gnutls_pubkey_import_rsa_raw(gnutls_pubkey_t key, const gnutls_datum_t * m, const gnutls_datum_t * e);

ARGUMENTOS

gnutls_pubkey_t key
la clave
const gnutls_datum_t * m
contiene el módulo
const gnutls_datum_t * e
contiene el exponente público

DESCRIPCIÓN

Esta función reemplazará los parámetros en la estructura dada. Los nuevos parámetros deben almacenarse en el gnutls_datum apropiado.

DEVOLUCIONES

GNUTLS_E_SUCCESS en caso de éxito, o un código de error negativo.
