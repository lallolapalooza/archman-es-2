NOMBRE

gnutls_register_custom_url - Función de la API

SINOPSIS

#include <gnutls/urls.h>

int gnutls_register_custom_url(const gnutls_custom_url_st * st);

ARGUMENTOS

const gnutls_custom_url_st * st
Una estructura gnutls_custom_url_st

DESCRIPCIÓN

Registra una URL personalizada. Esto afectará a las siguientes funciones: gnutls_url_is_supported(), gnutls_privkey_import_url(), gnutls_pubkey_import_url, gnutls_x509_crt_import_url() y todas las funciones que dependen de ellas, por ejemplo, gnutls_certificate_set_x509_key_file2().

La estructura y las funciones de devolución de llamada proporcionadas deben ser válidas durante toda la vida del proceso. El registro de un tipo de URL existente fallará con GNUTLS_E_INVALID_REQUEST. Desde GnuTLS 3.5.0, esta función se puede usar para reemplazar las URLs integradas.

Esta función no es segura para hilos.

DEVUELVE

Devuelve cero si la estructura dada fue importada o un valor negativo en caso contrario.
