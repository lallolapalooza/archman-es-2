NOMBRE

gnutls_hash - Función de la API

SINOSIS

#include <gnutls/crypto.h>

int gnutls_hash(gnutls_hash_hd_t handle, const void * ptext, size_t ptext_len);

ARGUMENTOS

gnutls_hash_hd_t handle
es un tipo gnutls_hash_hd_t
const void * ptext
los datos a hashear
size_t ptext_len
la longitud de los datos a hashear

DESCRIPCIÓN

Esta función hashea los datos proporcionados utilizando el algoritmo especificado por el contexto.

DEVOLUCIONES

Cero o un código de error negativo en caso de error.

DESDE

2.10.0
