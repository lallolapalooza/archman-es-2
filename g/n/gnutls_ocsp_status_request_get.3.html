NOMBRE

gnutls_ocsp_status_request_get - función de API

SINOPISIS

#include <gnutls/gnutls.h>

int gnutls_ocsp_status_request_get(gnutls_session_t session, gnutls_datum_t * response);

ARGUMENTOS

gnutls_session_t session
es un tipo gnutls_session_t.
gnutls_datum_t * response
un gnutls_datum_t con la respuesta OCSP codificada en DER

DESCRIPCIÓN

Esta función devuelve la respuesta de estado OCSP recibida del servidor TLS. El argumento response debe tratarse como constante. Si no hay ninguna respuesta OCSP disponible, se devuelve GNUTLS_E_REQUESTED_DATA_NOT_AVAILABLE.

RETORNA

En caso de éxito, se devuelve GNUTLS_E_SUCCESS (0), de lo contrario, se devuelve un código de error negativo.
