NOMBRE

gnutls_record_set_timeout - Función de API

SINOPSIS

#include <gnutls/gnutls.h>

void gnutls_record_set_timeout(gnutls_session_t session, unsigned int ms);

ARGUMENTOS

gnutls_session_t session
es un tipo gnutls_session_t.
unsigned int ms
es un valor de tiempo de espera en milisegundos

DESCRIPCIÓN

Esta función establece el tiempo de espera de recepción para la capa de registro al valor proporcionado. Use un valor ms de cero para deshabilitar el tiempo de espera (el predeterminado), o GNUTLS_INDEFINITE_TIMEOUT, para establecer un tiempo de espera indefinido.

Esta función requiere establecer una función de devolución de llamada de tiempo de espera de extracción. Consulte gnutls_transport_set_pull_timeout_function().
