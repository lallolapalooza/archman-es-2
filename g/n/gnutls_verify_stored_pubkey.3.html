NOMBRE

gnutls_verify_stored_pubkey - Función de API

SINOPSIS

#include <gnutls/gnutls.h>

int gnutls_verify_stored_pubkey(const char * db_name, gnutls_tdb_t tdb, const char * host, const char * service, gnutls_certificate_type_t cert_type, const gnutls_datum_t * cert, unsigned int flags);

ARGUMENTOS

const char * db_name
Un archivo que especifica las claves almacenadas (use NULL para el valor predeterminado)
gnutls_tdb_t tdb
Una estructura de almacenamiento o NULL para usar el valor predeterminado
const char * host
El nombre del par
const char * service
no NULL si esta clave es específica de un servicio (por ejemplo, http)
gnutls_certificate_type_t cert_type
El tipo del certificado
const gnutls_datum_t * cert
Los datos brutos (der) del certificado
unsigned int flags
debería ser 0.

DESCRIPCIÓN

Esta función intentará verificar una clave pública bruta o una clave pública proporcionada a través de un certificado bruto (codificado en DER) utilizando una lista de claves públicas almacenadas. El campo service, si no es NULL, debe ser un número de puerto.

La variable db_name, si no es NULL, especifica un backend personalizado para la recuperación de entradas. Si es NULL, se utilizará el backend de archivo predeterminado. En sistemas tipo POSIX, el backend de archivo utiliza el archivo $HOME/.gnutls/known_hosts.

Tenga en cuenta que si se proporciona el backend de almacenamiento personalizado, la función de recuperación debe devolver GNUTLS_E_CERTIFICATE_KEY_MISMATCH si se encuentra el par host/servicio pero la clave no coincide, GNUTLS_E_NO_CERTIFICATE_FOUND si no se encuentra ningún host/servicio con la clave dada, y 0 si se encontró. La función de almacenamiento debe devolver 0 en caso de éxito.

A partir de GnuTLS 3.6.6, esta función también verifica claves públicas brutas.

RETORNA

Si no se encuentra ninguna clave pública asociada, se devolverá GNUTLS_E_NO_CERTIFICATE_FOUND. Si se encuentra una clave pero no coincide, se devolverá GNUTLS_E_CERTIFICATE_KEY_MISMATCH. En caso de éxito, se devolverá GNUTLS_E_SUCCESS (0), o un valor de error negativo en caso de otros errores.
