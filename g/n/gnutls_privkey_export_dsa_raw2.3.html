NOMBRE

gnutls_privkey_export_dsa_raw2 - Función de API

SINOPSIS

#include <gnutls/abstract.h>

int gnutls_privkey_export_dsa_raw2(gnutls_privkey_t key, gnutls_datum_t * p, gnutls_datum_t * q, gnutls_datum_t * g, gnutls_datum_t * y, gnutls_datum_t * x, unsigned int flags);

ARGUMENTOS

gnutls_privkey_t key
Contiene la clave privada
gnutls_datum_t * p
contendrá p
gnutls_datum_t * q
contendrá q
gnutls_datum_t * g
contendrá g
gnutls_datum_t * y
contendrá y
gnutls_datum_t * x
contendrá x
unsigned int flags
flags de gnutls_abstract_export_flags_t

DESCRIPCIÓN

Esta función exportará los parámetros de la clave privada DSA encontrados en la estructura dada. Los nuevos parámetros se asignarán utilizando gnutls_malloc() y se almacenarán en el datum apropiado.

VALOR DEVUELTO

GNUTLS_E_SUCCESS si tiene éxito, de lo contrario un código de error negativo.
