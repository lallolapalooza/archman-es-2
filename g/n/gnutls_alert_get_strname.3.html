NOMBRE

gnutls_alert_get_strname - función de la API

SINOPSIS

#include <gnutls/gnutls.h>

const char * gnutls_alert_get_strname(gnutls_alert_description_t alerta);

ARGUMENTOS

gnutls_alert_description_t alerta
es un número de alerta.

DESCRIPCIÓN

Esta función devolverá una cadena con el nombre de la alerta.

DEVUELVE

cadena correspondiente al valor gnutls_alert_description_t.
