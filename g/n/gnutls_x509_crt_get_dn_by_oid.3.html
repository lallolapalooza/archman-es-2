NOMBRE

gnutls_x509_crt_get_dn_by_oid - función de la API

SINOPSIS

#include <gnutls/x509.h>

int gnutls_x509_crt_get_dn_by_oid(gnutls_x509_crt_t cert, const char * oid, unsigned indx, unsigned int raw_flag, void * buf, size_t * buf_size);

ARGUMENTOS

gnutls_x509_crt_t cert
debería contener un tipo gnutls_x509_crt_t
const char * oid
contiene un Identificador de Objeto en formato de cadena terminada en nulo
unsigned indx
En caso de que existan múltiples OIDs iguales en el RDN, esto especifica cuál enviar. Use (0) para obtener el primero.
unsigned int raw_flag
Si es distinto de cero, devuelve los datos DER sin procesar de la parte DN.
void * buf
un puntero donde se copiará la parte DN (puede ser nulo).
size_t * buf_size
inicialmente contiene el tamaño de buf

DESCRIPCIÓN

Esta función extraerá la parte del nombre del sujeto del Certificado especificado por el OID dado. La salida, si no se utiliza la bandera raw, se codificará según lo descrito en RFC4514. Por lo tanto, una cadena codificada en ASCII o UTF-8, dependiendo de los datos del certificado.

Algunas macros de ayuda con OIDs populares se pueden encontrar en gnutls/x509.h. Si la bandera raw es (0), esta función solo devolverá OIDs conocidos como texto. Otros OIDs se codificarán en DER, como se describe en RFC4514, en formato hexadecimal con un prefijo '#'. Puedes verificar los OIDs conocidos usando gnutls_x509_dn_oid_known().

Si buf es nulo, solo se llenará el tamaño. Si la bandera
raw_flag no se especifica, la salida siempre terminará en nulo, aunque
el buf_size no incluirá el carácter nulo.

DEVUELVE

GNUTLS_E_SHORT_MEMORY_BUFFER si el búfer proporcionado no es lo suficientemente largo, y en ese caso buf_size se actualizará con el tamaño requerido. GNUTLS_E_REQUESTED_DATA_NOT_AVAILABLE si no hay datos en el índice actual. En caso de éxito, se devuelve 0.
