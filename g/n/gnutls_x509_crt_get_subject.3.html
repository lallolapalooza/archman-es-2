NOMBRE

gnutls_x509_crt_get_subject - función de API

SINOPSIS

#include <gnutls/x509.h>

int gnutls_x509_crt_get_subject(gnutls_x509_crt_t cert, gnutls_x509_dn_t * dn);

ARGUMENTOS

gnutls_x509_crt_t cert
debería contener un tipo gnutls_x509_crt_t
gnutls_x509_dn_t * dn
variable de salida con un puntero a DN de uint8_t.

DESCRIPCIÓN

Devuelve el DN del Sujeto del Certificado como un tipo de datos gnutls_x509_dn_t, que puede ser decodificado usando gnutls_x509_dn_get_rdn_ava().

Tenga en cuenta que dn debe tratarse como constante. Dado que apunta dentro del objeto cert, no debe usar dn después de que cert haya sido desasignado.

DEVUELVE

Devuelve 0 si tiene éxito, o un código de error.
