gnutls_privkey_import_ext4(3) gnutls gnutls_privkey_import_ext4(3)

NOMBRE

gnutls_privkey_import_ext4 - función de la API

SINOPSIS

#include <gnutls/abstract.h>

int gnutls_privkey_import_ext4(gnutls_privkey_t pkey, void * userdata, gnutls_privkey_sign_data_func sign_data_fn, gnutls_privkey_sign_hash_func sign_hash_fn, gnutls_privkey_decrypt_func decrypt_fn, gnutls_privkey_deinit_func deinit_fn, gnutls_privkey_info_func info_fn, unsigned int flags);

ARGUMENTOS

gnutls_privkey_t pkey
La clave privada
void * userdata
datos privados para ser proporcionados a las callbacks
gnutls_privkey_sign_data_func sign_data_fn
callback para operaciones de firma (puede ser NULL)
gnutls_privkey_sign_hash_func sign_hash_fn
callback para operaciones de firma (puede ser NULL)
gnutls_privkey_decrypt_func decrypt_fn
callback para operaciones de descifrado (puede ser NULL)
gnutls_privkey_deinit_func deinit_fn
una función de desinicialización
gnutls_privkey_info_func info_fn
devuelve información sobre el algoritmo de clave pública (no debe ser NULL)
unsigned int flags
Flags para la importación

DESCRIPCIÓN

Esta función asociará las callbacks dadas con el tipo gnutls_privkey_t. Al menos una de las callbacks debe ser no nula. Si se proporciona una función de desinicialización, se asume que flags contiene GNUTLS_PRIVKEY_IMPORT_AUTO_RELEASE.

Tenga en cuenta que, a diferencia de la función de firma de gnutls_privkey_import_ext3(), las funciones de firma proporcionadas a esta función toman explícitamente el algoritmo de firma como parámetro y se proporcionan funciones diferentes para firmar los datos y los hashes.

La sign_hash_fn se utilizará para firmar datos pre-hasheados. La entrada para la callback es la salida del hash (como SHA256) que corresponde al algoritmo de firma. Para firmas RSA PKCS1, el algoritmo de firma puede establecerse en GNUTLS_SIGN_RSA_RAW, y en ese caso los datos deben tratarse como si fueran una estructura DigestInfo de RSA PKCS1.

La sign_data_fn se utilizará para firmar datos. Los datos de entrada serán los datos a firmar (y hashear), con el algoritmo de firma proporcionado. Esta función se utilizará para algoritmos de firma como Ed25519, que no pueden tomar datos pre-hasheados como entrada.

Cuando se proporcionan ambas funciones sign_data_fn y sign_hash_fn, deben ser capaces de operar en todos los algoritmos de firma soportados, a menos que esté prohibido por el tipo de algoritmo (por ejemplo, como con Ed25519).

La info_fn debe proporcionar información sobre los algoritmos de firma soportados por esta clave privada, y debe soportar los flags GNUTLS_PRIVKEY_INFO_PK_ALGO, GNUTLS_PRIVKEY_INFO_HAVE_SIGN_ALGO y GNUTLS_PRIVKEY_INFO_PK_ALGO_BITS. Debe devolver -1 en flags desconocidos.

VALOR DE RETORNO

En caso de éxito, se devuelve GNUTLS_E_SUCCESS (0), de lo contrario, un valor de error negativo.
