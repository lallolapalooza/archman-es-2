NOMBRE

gnutls_rnd - Función de API

SINOPSIS

#include <gnutls/crypto.h>

int gnutls_rnd(gnutls_rnd_level_t level, void * data, size_t len);

ARGUMENTOS

gnutls_rnd_level_t level
un nivel de seguridad
void * data
lugar para almacenar bytes aleatorios
size_t len
El tamaño solicitado

DESCRIPCIÓN

Esta función generará datos aleatorios y los almacenará en el búfer de salida. El valor de level debe ser uno de GNUTLS_RND_NONCE, GNUTLS_RND_RANDOM y GNUTLS_RND_KEY. Consulte el manual y gnutls_rnd_level_t para obtener información detallada.

Esta función es segura para hilos y también segura para forks.

DEVOLUCIONES

Cero en caso de éxito, o un código de error negativo en caso de error.
