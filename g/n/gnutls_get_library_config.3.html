NOMBRE

gnutls_get_library_config - Función de la API

SINOPSIS

#include <gnutls/gnutls.h>

const gnutls_library_config_st * gnutls_get_library_config( void);

ARGUMENTOS

void

DESCRIPCIÓN

Devuelve la configuración de la biblioteca como pares clave-valor. Las claves definidas actualmente son:

- fips-module-name: el nombre del módulo FIPS140

- fips-module-version: la versión del módulo FIPS140

- libgnutls-soname: el SONAME de la propia biblioteca

- libnettle-soname: el SONAME de la biblioteca libnettle enlazada

- libhogweed-soname: el SONAME de la biblioteca libhogweed enlazada

- libgmp-soname: el SONAME de la biblioteca libgmp enlazada

- hardware-features: características de soporte de hardware habilitadas

- tls-features: características del protocolo TLS habilitadas

RETORNA

un array gnutls_library_config_st terminado en NUL
