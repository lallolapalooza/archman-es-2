gnu::format(3attr) gnu::format(3attr)

NOMBRE

gnu::format - especificar el estilo de la cadena de formato

SINOPSIS

[[gnu::format(estilo, fmt-idx, first-idx)]]

DESCRIPCIÓN

Este atributo se puede aplicar a una función. Especifica que un parámetro de función es una cadena de formato y especifica el estilo de la cadena de formato. Esto permite verificar la sintaxis de la cadena de formato, así como los tipos de los argumentos variádicos. El estilo puede ser uno de los siguientes.

printf
scanf
strftime
strfmon

fmt-idx es un índice basado en 1 que especifica la posición de la cadena de formato dentro de la lista de parámetros.

first-idx es un índice basado en 1 que especifica la posición del primer argumento que corresponde a la cadena de formato. Si el primer argumento es parte de un argumento va_list, debe especificarse como 0.

VERSIÓNES

Sintaxis GNU

__attribute__((format(estilo, fmt-idx, first-idx)))

Estilos

En algunos destinos, se admiten estilos adicionales.

MinGW
Microsoft Windows
ms_printf
ms_scanf
ms_strftime

Estos corresponden a los formatos admitidos por la biblioteca msvcrt.dll.

Solo GCC.

Solaris
cmn_err
Darwin
CFString
OpenBSD
kprintf
syslog
syslog
Solo Clang.
FreeBSD
freebsd_kprintf
Solo Clang.

En algunos lenguajes, se admiten estilos adicionales.

Objective-C
NSString

Funciones no variádicas

Clang acepta el atributo en funciones no variádicas como una extensión.

ESTÁNDARES

GNU.

HISTORIA

gcc, g++, clang 2.8, clang++ 2.8.

EJEMPLOS


[[gnu::format(printf, 3, 0)]]
int
vstprintf(int size;
    char buf[restrict size], int size,
    const char *restrict fmt, va_list args)
{
	int len;
	if (size == 0) {
		errno = EOVERFLOW;
		return -1;
	}
	len = vsnprintf(buf, size, fmt, args);
	if (len >= size) {
		errno = E2BIG;
		return -1;
	}
	return len;
}
[[gnu::format(printf, 3, 4)]]
int
stprintf(int size;
    char buf[restrict size], int size,
    const char *restrict fmt, ...)
{
	int len;
	va_list args;
	va_start(args, fmt);
	len = vstprintf(buf, size, fmt, args);
	va_end(args);
	return len;
}
