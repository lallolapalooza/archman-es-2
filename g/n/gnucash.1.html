NOMBRE

gnucash - gestor de finanzas personales

SINOPSIS

gnucash [opciones] [ cuentas.gnucash ]

DESCRIPCIÓN

GnuCash es un paquete de contabilidad personal que te permite registrar y seguir ingresos, gastos, activos e inversiones. Soporta la conciliación, tiene capacidades sustanciales de informes y es extensible mediante guile. Puede importar datos QIF de Quicken(TM) y muchos otros paquetes de contabilidad comerciales. Utiliza GTK+ y GNOME para proporcionar una interfaz de usuario atractiva y tiene una extensa ayuda en línea.

OPCIONES

--version
Mostrar la versión de GnuCash
--help
Mostrar este mensaje de ayuda
--debug
Habilitar el modo de depuración: aumentando el registro para proporcionar detalles profundos.
--extra
Habilitar funciones adicionales/de desarrollo/depuración.
--log
Sobrescrituras del nivel de registro, del tipo "log.ger.path={debug,info,warn,crit,error}" Esta opción puede especificarse varias veces.
--logto
Archivo en el que registrar; el valor predeterminado es "$TMPDIR/gnucash.trace"; usar "stderr" o "stdout" para escribir en la terminal.
--paths
Mostrar las rutas de instalación y configuración.
--nofile
No cargar el último archivo abierto

ARCHIVOS

~/.gnucash/config.auto

Archivo de configuración generado automáticamente por usuario. ¡NO LO EDITES MANUALMENTE!

ENTORNO

GNC_DEBUG
Habilitar la salida de depuración. Esto te permite activar la depuración antes en el proceso de inicio de lo que puedes hacer con --debug.
GUILE_LOAD_PATH
Una sobrescritura de la ruta de carga de scheme de GnuCash. No deberías necesitar alterarla. Para más información, consulta el archivo README.
GNC_MODULE_PATH
Una sobrescritura de la ruta de carga de scheme de GnuCash para módulos de Gnucash. No deberías necesitar alterarla. Para más información, consulta el archivo README.

ERRORES

Por favor, informa de cualquier error utilizando el formulario de reporte de errores en el sitio web de GnuCash.

VER TAMBIÉN

GnuCash tiene una extensa ayuda en línea disponible en el menú "ayuda".

Información adicional y la última versión están disponibles en el sitio web: https://www.gnucash.org
