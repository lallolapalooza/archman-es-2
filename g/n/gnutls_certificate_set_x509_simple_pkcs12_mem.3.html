gnutls_certificate_set_x509_simple_pkcs12_mem(3) gnutls gnutls_certificate_set_x509_simple_pkcs12_mem(3)

NOMBRE

gnutls_certificate_set_x509_simple_pkcs12_mem - función de API

SINOPSIS

#include <gnutls/gnutls.h>

int gnutls_certificate_set_x509_simple_pkcs12_mem(gnutls_certificate_credentials_t res, const gnutls_datum_t * p12blob, gnutls_x509_crt_fmt_t type, const char * password);

ARGUMENTOS

gnutls_certificate_credentials_t res
es un tipo gnutls_certificate_credentials_t.
const gnutls_datum_t * p12blob
el blob PKCS12.
gnutls_x509_crt_fmt_t type
es PEM o DER del pkcs12file.
const char * password
contraseña opcional utilizada para descifrar el archivo PKCS12, bolsas y claves.

DESCRIPCIÓN

Esta función establece un par certificado/clave privada y/o una CRL en el tipo gnutls_certificate_credentials_t. Esta función puede ser llamada más de una vez (en caso de que existan múltiples claves/certificados para el servidor).

Se admiten bolsas PKCS12 cifradas y claves privadas PKCS8. Sin embargo, solo se admite la seguridad basada en contraseñas y la misma contraseña para todas las operaciones.

El archivo PKCS12 puede contener muchas claves y/o certificados, y esta función intentará detectar automáticamente, basándose en el ID de la clave, el par certificado y clave a utilizar. Si el archivo PKCS12 contiene el emisor del certificado seleccionado, se añadirá al certificado para formar una cadena.

Si hay más de una clave privada almacenada en el archivo PKCS12, solo se leerá una clave (y no está definido cuál).

Se cree que las limitaciones de esta función son aceptables para la mayoría de los usos, y que cualquier flexibilidad adicional introduciría una complejidad que haría más difícil usar esta funcionalidad en absoluto.

Tenga en cuenta que, por defecto, esta función devuelve cero en caso de éxito y un valor negativo en caso de error. Desde la versión 3.5.6, cuando la bandera GNUTLS_CERTIFICATE_API_V2 se establece usando gnutls_certificate_set_flags(), devuelve un índice (mayor o igual a cero). Ese índice puede ser utilizado por otras funciones para referirse al par clave añadido.

DEVOLUCIONES

En caso de éxito, estas funciones devuelven cero, y en caso contrario, un valor negativo en caso de error (consulte arriba para modificar ese comportamiento).
