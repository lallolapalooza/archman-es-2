NOMBRE

Gnac - Convertidor de audio para GNOME

SINOPSIS

gnac [opción...] [URIs...]

DESCRIPCIÓN

Gnac es un programa de conversión de audio fácil de usar para el escritorio GNOME. ¡Está diseñado para ser potente pero simple! Proporciona conversión fácil de archivos de audio entre todos los formatos de audio compatibles con GStreamer.

OPCIONES

-a, --audio-profile=nombre
Usar el perfil de audio 'nombre'
-l, --list-profiles
Listar perfiles disponibles y salir
--verbose
Habilitar salida detallada
--debug
Mostrar información de depuración
--version
Mostrar la versión del programa y salir
--display=DISPLAY
Pantalla X a usar
-? , -h , --help
Mostrar opciones de ayuda
--help-all
Mostrar todas las opciones de ayuda
--help-gst
Mostrar Opciones de GStreamer
--help-gtk
Mostrar Opciones de GTK+

ATAJOS DE TECLADO

Atajos de teclado globales para Gnac:

Ctrl+i Añadir nuevos archivos o carpetas
Ctrl+Shift+c Limpiar la lista de archivos
Ctrl+Shift+x Iniciar y detener una conversión
Intro Mostrar las propiedades del archivo seleccionado
Supr Eliminar el archivo seleccionado de la lista

ARCHIVOS

~/.local/share/gnac/profiles/

El directorio de perfiles.

/usr/share/gnac/profiles/default/

El directorio de perfiles predeterminados.
