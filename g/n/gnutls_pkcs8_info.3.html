NOMBRE

gnutls_pkcs8_info - función de la API

SINOPSIS

#include <gnutls/x509.h>

int gnutls_pkcs8_info(const gnutls_datum_t * data, gnutls_x509_crt_fmt_t format, unsigned int * schema, unsigned int * cipher, void * salt, unsigned int * salt_size, unsigned int * iter_count, char ** oid);

ARGUMENTOS

const gnutls_datum_t * data
Contiene los datos PKCS 8
gnutls_x509_crt_fmt_t format
el formato de los datos PKCS 8
unsigned int * schema
indica el esquema como uno de gnutls_pkcs_encrypt_flags_t
unsigned int * cipher
el cifrado utilizado como gnutls_cipher_algorithm_t
void * salt
sal de PBKDF2 (si no es NULL, entonces salt_size inicialmente contiene su tamaño)
unsigned int * salt_size
tamaño de la sal de PBKDF2
unsigned int * iter_count
contador de iteraciones de PBKDF2
char ** oid
si no es NULL, contendrá una variable asignada con terminación nula con el OID

DESCRIPCIÓN

Esta función proporcionará información sobre los algoritmos utilizados en una estructura PKCS 8 particular. Si los algoritmos de la estructura son desconocidos, se devolverá el código GNUTLS_E_UNKNOWN_CIPHER_TYPE y solo se establecerá oid. Es decir, oid se establecerá en estructuras PKCS 8 cifradas, independientemente de si son compatibles o no. Debe ser desinicializado usando gnutls_free(). Las otras variables solo se establecen en estructuras compatibles.

VALORES DEVUELTOS

GNUTLS_E_INVALID_REQUEST si la estructura proporcionada no es una clave cifrada, GNUTLS_E_UNKNOWN_CIPHER_TYPE si el cifrado de la estructura no es compatible, o algún otro código de error negativo en caso de fallo. Cero si tiene éxito.
