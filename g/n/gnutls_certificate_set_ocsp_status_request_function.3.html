gnutls_certificate_set_ocsp_status_request_function(3)

Licencias: GPL-3.0-or-later AND LGPL-2.1-or-later

gnutls_certificate_set_ocsp_status_request_function(3) gnutls gnutls_certificate_set_ocsp_status_request_function(3)

NOMBRE

gnutls_certificate_set_ocsp_status_request_function - función de la API

SINOPSIS

#include <gnutls/gnutls.h>

void gnutls_certificate_set_ocsp_status_request_function(gnutls_certificate_credentials_t sc, gnutls_status_request_ocsp_func ocsp_func, void * ptr);

ARGUMENTOS

gnutls_certificate_credentials_t sc
es un tipo gnutls_certificate_credentials_t.
gnutls_status_request_ocsp_func ocsp_func
puntero a la función de devolución de llamada para la solicitud de estado OCSP.
void * ptr
puntero opaco pasado a la función de devolución de llamada

DESCRIPCIÓN

Esta función debe ser utilizada por el servidor para registrar una devolución de llamada que maneje las solicitudes de estado OCSP del cliente. La devolución de llamada se invocará si el cliente proporcionó una extensión OCSP de solicitud de estado. El prototipo de la función de devolución de llamada es:

typedef int (*gnutls_status_request_ocsp_func) (gnutls_session_t session, void *ptr, gnutls_datum_t *ocsp_response);

La devolución de llamada se invocará si el cliente solicita un estado de certificado OCSP. La devolución de llamada puede devolver GNUTLS_E_NO_CERTIFICATE_STATUS, si no hay una respuesta OCSP reciente. Si la devolución de llamada devuelve GNUTLS_E_SUCCESS, se espera que el campo ocsp_response esté establecido con una respuesta OCSP válida (codificada en DER). La respuesta debe ser un valor asignado usando gnutls_malloc(), y será desinicializado por el llamante.

Es posible establecer una devolución de llamada específica para cada certificado proporcionado usando gnutls_certificate_set_ocsp_status_request_function2().
