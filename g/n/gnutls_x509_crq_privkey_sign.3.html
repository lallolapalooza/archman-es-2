gnutls_x509_crq_privkey_sign(3)

Paquete: gnutls

Licencias: GPL-3.0-or-later AND LGPL-2.1-or-later

gnutls_x509_crq_privkey_sign(3) gnutls gnutls_x509_crq_privkey_sign(3)

NOMBRE

gnutls_x509_crq_privkey_sign - función de API

SINOPSIS

#include <gnutls/abstract.h>

int gnutls_x509_crq_privkey_sign(gnutls_x509_crq_t crq, gnutls_privkey_t key, gnutls_digest_algorithm_t dig, unsigned int flags);

ARGUMENTOS

gnutls_x509_crq_t crq
debe contener un tipo gnutls_x509_crq_t
gnutls_privkey_t key
contiene una clave privada
gnutls_digest_algorithm_t dig
El digest del mensaje a usar, es decir, GNUTLS_DIG_SHA1
unsigned int flags
debe ser 0

DESCRIPCIÓN

Esta función firmará la solicitud de certificado con una clave privada. Esta debe ser la misma clave que la utilizada en gnutls_x509_crt_set_key() ya que una solicitud de certificado se auto-firma.

Este debe ser el último paso en la generación de una solicitud de certificado ya que todos los parámetros establecidos previamente están ahora firmados.

Una limitación conocida de esta función es que una solicitud recién firmada no será completamente funcional (por ejemplo, para la verificación de firmas) hasta que se exporte y se vuelva a importar.

Después de GnuTLS 3.6.1, el valor de dig puede ser GNUTLS_DIG_UNKNOWN, y en ese caso, se seleccionará un digest adecuado para el algoritmo de clave.

DEVUELVE

GNUTLS_E_SUCCESS en caso de éxito, de lo contrario, un código de error negativo. Se devuelve GNUTLS_E_ASN1_VALUE_NOT_FOUND si no ha establecido toda la información en la solicitud de certificado (por ejemplo, la versión usando gnutls_x509_crq_set_version()).
