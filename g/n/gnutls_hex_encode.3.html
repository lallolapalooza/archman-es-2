NOMBRE

gnutls_hex_encode - Función de API

SINÓPSIS

#include <gnutls/gnutls.h>

int gnutls_hex_encode(const gnutls_datum_t * data, char * result, size_t * result_size);

ARGUMENTOS

const gnutls_datum_t * data
contiene los datos crudos
char * result
el lugar donde se copiarán los datos hexadecimales
size_t * result_size
contiene el tamaño del resultado

DESCRIPCIÓN

Esta función convertirá los datos dados a datos imprimibles, usando la codificación hexadecimal, tal como se usa en los archivos de contraseña PSK.

Tenga en cuenta que el tamaño del resultado incluye el terminador nulo.

RETORNA

GNUTLS_E_SHORT_MEMORY_BUFFER si el búfer proporcionado no es lo suficientemente grande, o 0 en caso de éxito.
