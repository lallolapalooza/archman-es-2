NOMBRE

gnutls_pkcs12_mac_info - función API

SINOPSIS

#include <gnutls/pkcs12.h>

int gnutls_pkcs12_mac_info(gnutls_pkcs12_t pkcs12, unsigned int * mac, void * salt, unsigned int * salt_size, unsigned int * iter_count, char ** oid);

ARGUMENTOS

gnutls_pkcs12_t pkcs12
Un tipo pkcs12
unsigned int * mac
el algoritmo MAC utilizado como gnutls_mac_algorithm_t
void * salt
la sal utilizada para string a clave (si no es NULL, entonces salt_size inicialmente contiene su tamaño)
unsigned int * salt_size
tamaño de la sal de string a clave
unsigned int * iter_count
contador de iteraciones de string a clave
char ** oid
si no es NULL, contendrá una variable asignada y terminada en nulo con el OID

DESCRIPCIÓN

Esta función proporcionará información sobre el algoritmo MAC utilizado en una estructura PKCS 12. Si los algoritmos de la estructura son desconocidos, se devolverá el código GNUTLS_E_UNKNOWN_HASH_ALGORITHM, y solo se establecerá oid. Es decir, oid se establecerá en estructuras con un MAC, ya sea compatible o no. Debe ser desinicializado usando gnutls_free(). Las otras variables solo se establecen en estructuras compatibles.

RETORNA

GNUTLS_E_INVALID_REQUEST si la estructura proporcionada no contiene un MAC, GNUTLS_E_UNKNOWN_HASH_ALGORITHM si el MAC de la estructura no es compatible, o algún otro código de error negativo en caso de fallo. Cero en caso de éxito.
