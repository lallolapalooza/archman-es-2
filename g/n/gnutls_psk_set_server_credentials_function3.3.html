gnutls_psk_set_server_credentials_function3(3)

Paquete: gnutls

Licencias: GPL-3.0-or-later AND LGPL-2.1-or-later

gnutls_psk_set_server_credentials_function3(3) gnutls gnutls_psk_set_server_credentials_function3(3)

NOMBRE

gnutls_psk_set_server_credentials_function3 - Función de la API

SINOPSIS

#include <gnutls/gnutls.h>

void gnutls_psk_set_server_credentials_function3(gnutls_psk_server_credentials_t cred, gnutls_psk_server_credentials_function3 func);

ARGUMENTOS

gnutls_psk_server_credentials_t cred
es un tipo gnutls_psk_server_credentials_t.
gnutls_psk_server_credentials_function3 func
es la función de callback

DESCRIPCIÓN

Esta función se puede utilizar para establecer una función de callback para recuperar las credenciales PSK del usuario. La forma de la función de callback es: int (*callback)(gnutls_session_t, const gnutls_datum_t* username, gnutls_datum_t* key, gnutls_psk_key_flags *flags);

Esta función de callback tiene la misma semántica que la de gnutls_psk_set_server_credentials_function2(), pero devuelve flags asociados a la clave. La función de callback puede importar PSK externos utilizando el método descrito en RFC 9258 mediante gnutls_psk_format_imported_identity().


username contiene el nombre de usuario real. La key debe ser rellenada utilizando gnutls_malloc().

En caso de que la función de callback devuelva un número negativo, gnutls asumirá que el nombre de usuario no existe.

La función de callback solo se llamará una vez por handshake. La función de callback debe devolver 0 en caso de éxito, mientras que -1 indica un error.
