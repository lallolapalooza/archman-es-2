Establece múltiples conexiones TLS con un servidor y consulta sus capacidades. Fue creado para ayudar en la depuración de GnuTLS, pero podría ser útil para extraer las capacidades de un servidor TLS. Se conecta a un servidor TLS, realiza pruebas e imprime las capacidades del servidor. Si se llama con el parámetro `-V' se realizarán más comprobaciones. Puede usarse para comprobar servidores con necesidades o errores especiales.OPCIONE
