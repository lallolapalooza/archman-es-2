DESCRIPCIÓ

N

Gnumeric es un potente programa de hoja de cálculo creado por el proyecto GNOME. Gnumeric pretende competir con las hojas de cálculo comerciales siendo totalmente compatible con Microsoft Excel(TM) y mediante el soporte de la mayoría de los formatos de archivo de hoja de cálculo populares como Excel(TM), Lotus 1-2-3(TM), Applix(TM), Sylk(TM), XBase(TM), Oleo(TM) y los formatos de OpenOffice.

org.

Gnumeric soporta cálculos avanzados usando funciones estadísticas, financieras y de acceso a bases de datos. El trazado de datos está soportado a través de un sistema de gráficos incompleto pero potente. Un sistema de plugins extiende gnumeric , por ejemplo, permitiendo la exportación de datos al formato \longtable de LaTeX. Los plugins pueden usarse para definir funcionalidad personalizada. Existe una API de scripting rudimentaria para el lenguaje Python que se ampliará en un futuro cercano. Dado que gnumeric es software libre, gnumeric también puede extenderse directamente a nivel de código fuente por cualquier programador

competente.

El programa puede iniciarse desde la línea de comandos como gnumeric o desde uno de los menús proporcionados por la plataforma subyacente. Cuando se inicia en la línea de comandos, gnumeric puede ir seguido de las opciones listadas abajo y posiblemente de los nombres de archivos en varios formatos de hoja de cálculo que serán abiertos inmediatamente. Por ejemplo, el

comando:


gnumeric myfile.

gnumeric

iniciará gnumeric y abrirá el archivo llamado "myfile.gnumeric". El formato de archivo por defecto de gnumeric está en lenguaje de marcado extensible (XML) el cual posteriormente ha sido comprimido con gz

ip
