NOMBRE

gnutls_buffer_append_data - función de la API

SINOPSIS

#include <gnutls/gnutls.h>

int gnutls_buffer_append_data(gnutls_buffer_t dest, const void * data, size_t data_size);

ARGUMENTOS

gnutls_buffer_t dest
el búfer al que se añadirá
const void * data
los datos
size_t data_size
el tamaño de data

DESCRIPCIÓN

Añade los datos proporcionados al búfer de destino.

DEVUELVE

GNUTLS_E_SUCCESS si tiene éxito, de lo contrario, un código de error negativo.
