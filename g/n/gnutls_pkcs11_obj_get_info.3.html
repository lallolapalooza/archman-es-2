gnutls_pkcs11_obj_get_info(3)

gnutls_pkcs11_obj_get_info(3) gnutls gnutls_pkcs11_obj_get_info(3)

NOMBRE

gnutls_pkcs11_obj_get_info - Función de API

SINOPSIS

#include <gnutls/pkcs11.h>

int gnutls_pkcs11_obj_get_info(gnutls_pkcs11_obj_t obj, gnutls_pkcs11_obj_info_t itype, void * output, size_t * output_size);

ARGUMENTOS

gnutls_pkcs11_obj_t obj
debería contener un tipo gnutls_pkcs11_obj_t
gnutls_pkcs11_obj_info_t itype
Indica el tipo de información solicitada
void * output
donde se almacenará la salida
size_t * output_size
contiene el tamaño máximo del búfer de salida y será sobrescrito con el tamaño real.

DESCRIPCIÓN

Esta función devolverá información sobre el certificado PKCS11, como la etiqueta, el ID, así como información del token donde se almacena la clave.

Cuando la salida es texto, se escribe una cadena terminada en null en output y su longitud de cadena se escribe en output_size (sin el terminador null). Si el búfer es demasiado pequeño, output_size contendrá el tamaño esperado del búfer (con terminador null para texto) y devolverá GNUTLS_E_SHORT_MEMORY_BUFFER.

En versiones anteriores a la 3.6.0, esta función incluía el terminador null en output_size. Después de la 3.6.0, el tamaño de salida no incluye el carácter terminador.

RETORNA

GNUTLS_E_SUCCESS (0) en caso de éxito o un código de error negativo en caso de error.
