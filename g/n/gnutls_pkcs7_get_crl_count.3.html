NOMBRE

gnutls_pkcs7_get_crl_count - función de la API

SINOPSIS

#include <gnutls/pkcs7.h>

int gnutls_pkcs7_get_crl_count(gnutls_pkcs7_t pkcs7);

ARGUMENTOS

gnutls_pkcs7_t pkcs7
El tipo pkcs7

DESCRIPCIÓN

Esta función devolverá el número de certificados en el conjunto crl de PKCS7 o RFC2630.

VALORES DE RETORNO

En caso de éxito, se devuelve GNUTLS_E_SUCCESS (0), de lo contrario, un valor de error negativo.
