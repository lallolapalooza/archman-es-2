NOMBRE

gnutls_cipher_suite_info - Función de API

SINOPSIS

#include <gnutls/gnutls.h>

const char * gnutls_cipher_suite_info(size_t idx, unsigned char * cs_id, gnutls_kx_algorithm_t * kx, gnutls_cipher_algorithm_t * cipher, gnutls_mac_algorithm_t * mac, gnutls_protocol_t * min_version);

ARGUMENTOS

size_t idx
índice del conjunto de cifrado del que se desea obtener información, comienza en 0.
unsigned char * cs_id
buffer de salida con espacio para 2 bytes, que indica el valor del conjunto de cifrado
gnutls_kx_algorithm_t * kx
variable de salida que indica el algoritmo de intercambio de claves, o NULL.
gnutls_cipher_algorithm_t * cipher
variable de salida que indica el cifrado, o NULL.
gnutls_mac_algorithm_t * mac
variable de salida que indica el algoritmo MAC, o NULL.
gnutls_protocol_t * min_version
variable de salida que indica la versión del protocolo TLS, o NULL.

DESCRIPCIÓN

Obtiene información sobre los conjuntos de cifrado admitidos. Utilice la función iterativamente para obtener información sobre todos los conjuntos de cifrado admitidos. Llame con idx=0 para obtener información sobre el primer conjunto de cifrado, luego idx=1 y así sucesivamente hasta que la función devuelva NULL.

VALORES DEVUELTOS

el nombre del conjunto de cifrado idx, y establece la información sobre el conjunto de cifrado en las variables de salida. Si idx está fuera de los límites, se devuelve NULL.
