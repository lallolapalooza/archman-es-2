NOMBRE

gnutls_x509_crt_verify_data2 - Función de la API

SINOPSIS

#include <gnutls/x509.h>

int gnutls_x509_crt_verify_data2(gnutls_x509_crt_t crt, gnutls_sign_algorithm_t algo, unsigned int flags, const gnutls_datum_t * data, const gnutls_datum_t * signature);

ARGUMENTOS

gnutls_x509_crt_t crt
Contiene el certificado con el que verificar
gnutls_sign_algorithm_t algo
El algoritmo de firma utilizado
unsigned int flags
Cero o una lista OR de gnutls_certificate_verify_flags
const gnutls_datum_t * data
contiene los datos firmados
const gnutls_datum_t * signature
contiene la firma

DESCRIPCIÓN

Esta función verificará los datos firmados dados, utilizando los parámetros del certificado.

RETORNA

En caso de fallo de verificación se devuelve GNUTLS_E_PK_SIG_VERIFY_FAILED, GNUTLS_E_EXPIRED o GNUTLS_E_NOT_YET_ACTIVATED si el certificado está caducado o aún no activado, y un código cero o positivo en caso de éxito.

Tenga en cuenta que desde GnuTLS 3.5.6 esta función introduce comprobaciones en el certificado final ( crt ), incluyendo comprobaciones de tiempo y de uso de claves.
