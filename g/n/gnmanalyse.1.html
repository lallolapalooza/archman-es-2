NOMBRE

gnmanalyse - Analiza redes

SINOPSIS

Uso: gnmanalyse [--help][--help-general][-q][-quiet][--long-usage]
                  [dijkstra <gfid_inicio> <gfid_fin [-alo <NOMBRE>=<VALOR>]...]
                  [kpaths <gfid_inicio> <gfid_fin> <k> [-alo NOMBRE=VALOR]...]
                  [resource [-alo <NOMBRE>=<VALOR>]...]
                  [-ds <nombre_ds>][-f <formato_ds>][-l <nombre_capa>]
                  [-dsco <NOMBRE>=<VALOR>]... [-lco <NOMBRE>=<VALOR>]...
                  <nombre_gnm>

DESCRIPCIÓN

El programa gnmanalyse proporciona capacidades de análisis de redes geográficas en GDAL. Los resultados de los cálculos se devuelven en un formato OGRLayer o como una salida de texto en consola si dicha capa no está definida. Todos los cálculos se realizan teniendo en cuenta el estado de bloqueo de las características.

--help
Mostrar este mensaje de ayuda y salir
--help-general
Muestra un breve mensaje de uso para las opciones genéricas de línea de comandos de GDAL y sale.
dijkstra <gfid_inicio> <gfid_fin>
Calcula la mejor ruta entre dos puntos usando el algoritmo de Dijkstra desde el punto gfid_inicio hasta el punto gfid_fin.
kpaths <gfid_inicio> <gfid_fin>
Calcula las K rutas más cortas entre dos puntos usando el algoritmo de Yen (que internamente utiliza el algoritmo de Dijkstra para calcular rutas individuales) desde el punto gfid_inicio hasta el punto gfid_fin.
resource
Calcula la "distribución de recursos". La búsqueda de componentes conectados se realiza utilizando una búsqueda en anchura y comenzando por las características que están marcadas por las reglas como 'EMITTERS' (emisores).
-d <nombre_ds>
El nombre y la ruta del conjunto de datos para guardar la capa con las rutas resultantes. No es necesario que el conjunto de datos exista.
-f <formato_ds>
Defina esto para establecer el formato del conjunto de datos recién creado.
-l <nombre_capa>
El nombre de la capa resultante. Si la capa ya existe, será sobrescrita.
<nombre_gnm>
La red con la que trabajar (ruta y nombre).
-dsco <NOMBRE>=<VALOR>
Opción de creación de conjunto de datos (específico del formato)
-lco <NOMBRE>=<VALOR>
Opción de creación de capa (específico del formato)
-alo <NOMBRE>=<VALOR>
Opción de algoritmo (específico del formato)
