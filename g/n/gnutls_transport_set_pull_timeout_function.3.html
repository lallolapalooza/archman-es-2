NOMBRE

gnutls_transport_set_pull_timeout_function - Función de la API

SINOPSIS

#include <gnutls/gnutls.h>

void gnutls_transport_set_pull_timeout_function(gnutls_session_t session, gnutls_pull_timeout_func func);

ARGUMENTOS

gnutls_session_t session
es un tipo gnutls_session_t.
gnutls_pull_timeout_func func
una función de callback

DESCRIPCIÓN

Esta es la función donde se establece una función para que gnutls sepa si hay datos listos para ser recibidos. Debería esperar datos durante un marco de tiempo dado en milisegundos. La función de callback debería devolver 0 en caso de tiempo de espera agotado, un número positivo si los datos pueden ser recibidos y -1 en caso de error. Deberá anular esta función si select() no es adecuada para las llamadas de transporte proporcionadas.

Al igual que con select(), si el valor del tiempo de espera es cero, la función de callback debería devolver cero si no hay datos disponibles inmediatamente. El valor especial GNUTLS_INDEFINITE_TIMEOUT indica que la función de callback debería esperar indefinidamente por datos.


gnutls_pull_timeout_func tiene la forma: int (*gnutls_pull_timeout_func)(gnutls_transport_ptr_t, unsigned int ms);

Esta función de callback es necesaria cuando se establecen gnutls_handshake_set_timeout() o gnutls_record_set_timeout(), bajo TLS1.3 y para forzar los tiempos de espera del modo DTLS cuando está en modo de bloqueo.

Para compatibilidad con futuras versiones de GnuTLS, esta función de callback debe ser establecida cuando se registra una función de extracción personalizada. La función de callback no se utilizará cuando la sesión esté en modo TLS con sockets no bloqueantes. Es decir, cuando GNUTLS_NONBLOCK se especifica para una sesión TLS en gnutls_init().

La función auxiliar gnutls_system_recv_timeout() se proporciona para simplificar la escritura de funciones de callback.
