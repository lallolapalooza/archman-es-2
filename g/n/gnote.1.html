NOMBRE

gnote - Una aplicación simple para tomar notas para Gnome

SINOPSIS

gnote [OPCIÓN] ...

DESCRIPCIÓN

Esta página del manual documenta brevemente el comando gnote.

Gnote es una aplicación de escritorio para tomar notas para Linux y Unix. Simple y fácil de usar, pero con el potencial de ayudarte a organizar las ideas y la información con la que tratas cada día.

La utilidad de Gnote reside en la capacidad de relacionar notas e ideas, utilizando un sistema de enlaces similar a WikiWiki.

Cuando se ejecuta sin opciones, aparece una ventana de Búsqueda de Todas las Notas o el menú de notas de Gnote en el área de la bandeja de notificaciones, según la configuración. Seleccionar una nota de una lista en Búsqueda de Todas las Notas o del menú desde el área de notificaciones muestra la ventana espacial de la nota.

Los cambios en las notas se guardan automáticamente. Los enlaces a URL, archivos y otras notas se detectan a medida que escribes. Se admite edición enriquecida como resaltado, negrita, cursiva, deshacer/rehacer y tamaños de fuente variables.

Existen atajos de teclado globales para permitir un acceso rápido a las notas y diálogos de Gnote. Estos atajos de teclado se configuran en GSettings (ver más abajo) y pueden activarse desde cualquier aplicación.

OPCIONES

El programa sigue la sintaxis habitual de línea de comandos de GNU, con opciones que comienzan con dos guiones (`--'). A continuación se incluye un resumen de las opciones.

--background
Ejecuta Gnote en segundo plano.
--help
Muestra un resumen de las opciones.
--highlight-search TEXTO
Busca y resalta TEXTO en la nota abierta.
--note-path RUTA
Especifica la ruta del directorio que contiene las notas.
--new-note
Crea y muestra una nueva nota.
--new-note TÍTULO
Crea y muestra una nueva nota con el título dado.
--new-window
Abre una nueva ventana.
--open-note TÍTULO/URL
Muestra la nota existente que coincide con TÍTULO o URL.
--search
Abre la ventana de búsqueda de todas las notas con el texto de búsqueda.
--shell-search
Ejecuta Gnote como proveedor de búsqueda de GNOME Shell.
--start-here
Muestra la nota "Empezar aquí".
--version
Muestra la versión del programa.

CONFIGURACIÓN DE GSETTINGS

Gnote tiene varias configuraciones de preferencias almacenadas en GSettings. Los cambios en la Configuración se aplican instantáneamente a cualquier instancia de Gnote en ejecución. Puedes usar DConf-Editor para ver todas las configuraciones y leer sus descripciones.
