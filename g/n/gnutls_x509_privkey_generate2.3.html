NOMBRE

gnutls_x509_privkey_generate2 - Función de la API

SINOPSIS

#include <gnutls/x509.h>

int gnutls_x509_privkey_generate2(gnutls_x509_privkey_t key, gnutls_pk_algorithm_t algo, unsigned int bits, unsigned int flags, const gnutls_keygen_data_st * data, unsigned data_size);

ARGUMENTOS

gnutls_x509_privkey_t key
una clave
gnutls_pk_algorithm_t algo
es uno de los algoritmos de gnutls_pk_algorithm_t.
unsigned int bits
el tamaño del módulo
unsigned int flags
Debe ser cero o flags de gnutls_privkey_flags_t.
const gnutls_keygen_data_st * data
Permite especificar tipos de gnutls_keygen_data_st como la semilla a utilizar.
unsigned data_size
El número de data disponibles.

DESCRIPCIÓN

Esta función generará una clave privada aleatoria. Tenga en cuenta que esta función debe llamarse sobre una clave privada inicializada.

El flag GNUTLS_PRIVKEY_FLAG_PROVABLE instruye al proceso de generación de claves a utilizar algoritmos como Shawe-Taylor (de FIPS PUB186-4) que generan parámetros demostrables a partir de una semilla para claves RSA y DSA. En claves DSA, los parámetros PQG se generan utilizando la semilla, mientras que en RSA, los dos primos.

Para especificar una semilla explícita (por defecto se utiliza una semilla aleatoria), use data con un tipo GNUTLS_KEYGEN_SEED.

Tenga en cuenta que al generar una clave de curva elíptica, la curva puede ser sustituida en el lugar del parámetro de bits utilizando la macro GNUTLS_CURVE_TO_BITS().

Para exportar las claves generadas en memoria o en archivos, se recomienda utilizar el formato PKCS8 ya que puede manejar todos los tipos de claves y almacenar parámetros adicionales como la semilla, en caso de claves RSA o DSA demostrables. Las claves generadas pueden exportarse en memoria utilizando gnutls_privkey_export_x509() y luego con gnutls_x509_privkey_export2_pkcs8().

Si la generación de claves es parte de su aplicación, evite establecer el número de bits directamente y, en su lugar, utilice gnutls_sec_param_to_pk_bits(). De esta manera, las claves generadas se adaptarán a los niveles de seguridad de la biblioteca GnuTLS subyacente.

Ver también gnutls_privkey_generate2().

RETORNOS

En caso de éxito, se devuelve GNUTLS_E_SUCCESS (0), de lo contrario, un valor de error negativo.
