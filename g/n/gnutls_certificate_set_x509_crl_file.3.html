gnutls_certificate_set_x509_crl_file(3)

gnutls_certificate_set_x509_crl_file(3) gnutls gnutls_certificate_set_x509_crl_file(3)

NOMBRE

gnutls_certificate_set_x509_crl_file - Función de API

SINOPSIS

#include <gnutls/gnutls.h>

int gnutls_certificate_set_x509_crl_file(gnutls_certificate_credentials_t res, const char * crlfile, gnutls_x509_crt_fmt_t type);

ARGUMENTOS

gnutls_certificate_credentials_t res
es un tipo gnutls_certificate_credentials_t.
const char * crlfile
es un archivo que contiene la lista de CRLs verificadas (lista DER o PEM)
gnutls_x509_crt_fmt_t type
es PEM o DER

DESCRIPCIÓN

Esta función añade las CRLs de confianza para verificar certificados de cliente o servidor. En caso de un cliente, no es necesario llamar a esta función si los certificados no se verifican usando gnutls_certificate_verify_peers2(). Esta función puede ser llamada múltiples veces.

RETORNA

número de CRLs procesadas o un código de error negativo en caso de error.
