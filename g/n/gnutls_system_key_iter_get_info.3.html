gnutls_system_key_iter_get_info(3)

gnutls_system_key_iter_get_info(3) gnutls gnutls_system_key_iter_get_info(3)

NOMBRE

gnutls_system_key_iter_get_info - función de la API

SINOPSIS

#include <gnutls/system-keys.h>

int gnutls_system_key_iter_get_info(gnutls_system_key_iter_t * iter, unsigned cert_type, char ** cert_url, char ** key_url, char ** label, gnutls_datum_t * der, unsigned int flags);

ARGUMENTOS

gnutls_system_key_iter_t * iter
un iterador de las claves del sistema (debe inicializarse a NULL)
unsigned cert_type
Un valor de gnutls_certificate_type_t que indica el tipo de certificado a buscar
char ** cert_url
La URL del certificado del par (puede ser NULL)
char ** key_url
La URL de la clave del par (puede ser NULL)
char ** label
El nombre amigable (si lo hay) del par (puede ser NULL)
gnutls_datum_t * der
si no es NULL, los datos DER del certificado
unsigned int flags
debe ser cero

DESCRIPCIÓN

Esta función devolverá en cada llamada URLs de certificado y clave, así como una etiqueta asociada a ellas, y el certificado codificado en DER. Cuando la iteración haya finalizado, devolverá GNUTLS_E_REQUESTED_DATA_NOT_AVAILABLE.

Típicamente cert_type debería ser GNUTLS_CRT_X509.

Todos los valores establecidos se asignan y deben liberarse usando gnutls_free().

RETORNA

En caso de éxito, se devuelve GNUTLS_E_SUCCESS (0), de lo contrario, un valor de error negativo.
