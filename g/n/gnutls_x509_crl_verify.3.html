gnutls_x509_crl_verify(3)

Paquete: gnutls

Licencias: GPL-3.0-or-later AND LGPL-2.1-or-later

gnutls_x509_crl_verify(3) gnutls gnutls_x509_crl_verify(3)

NOMBRE

gnutls_x509_crl_verify - función de la API

SINOPSIS

#include <gnutls/x509.h>

int gnutls_x509_crl_verify(gnutls_x509_crl_t crl, const gnutls_x509_crt_t * trusted_cas, unsigned tcas_size, unsigned int flags, unsigned int * verify);

ARGUMENTOS

gnutls_x509_crl_t crl
es la CRL (Lista de Revocación de Certificados) a verificar
const gnutls_x509_crt_t * trusted_cas
es una lista de certificados que se consideran confiables
unsigned tcas_size
contiene el número de certificados de CA en CA_list
unsigned int flags
Flags que pueden usarse para cambiar el algoritmo de verificación. Usa el OR de las enumeraciones gnutls_certificate_verify_flags.
unsigned int * verify
contendrá la salida de la verificación de la CRL.

DESCRIPCIÓN

Esta función intentará verificar la CRL dada y devolverá su estado de verificación. Consulta gnutls_x509_crt_list_verify() para una descripción detallada de los valores de retorno. Ten en cuenta que desde GnuTLS 3.1.4, esta función incluye las comprobaciones de tiempo.

Ten en cuenta que el valor en verify solo se establece cuando el valor de retorno de esta función es éxito (es decir, no confiar en una CRL de un certificado no implica un valor de retorno negativo).

Antes de GnuTLS 3.5.7, esta función devolvería cero o un número positivo en caso de éxito.

RETORNOS

En caso de éxito, GNUTLS_E_SUCCESS (0), de lo contrario un valor de error negativo.
