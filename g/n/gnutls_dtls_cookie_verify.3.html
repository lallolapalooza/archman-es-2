NOMBRE

gnutls_dtls_cookie_verify - Función de la API

SINOPSIS

#include <gnutls/dtls.h>

int gnutls_dtls_cookie_verify(gnutls_datum_t * key, void * client_data, size_t client_data_size, void * _msg, size_t msg_size, gnutls_dtls_prestate_st * prestate);

ARGUMENTOS

gnutls_datum_t * key
es una clave aleatoria para usar en la generación de la cookie
void * client_data
contiene datos que identifican al cliente (es decir, su dirección)
size_t client_data_size
El tamaño de los datos del cliente
void * _msg
Un mensaje entrante que inicia una conexión.
size_t msg_size
El tamaño del mensaje.
gnutls_dtls_prestate_st * prestate
La cookie de este cliente.

DESCRIPCIÓN

Esta función verificará si el mensaje recibido contiene una cookie válida. Si se devuelve una cookie válida, debe asociarse con la sesión utilizando gnutls_dtls_prestate_set().

Esta función debe ser llamada después de gnutls_dtls_cookie_send().

VALORES DEVUELTOS

GNUTLS_E_SUCCESS (0) en caso de éxito, o un código de error negativo.
