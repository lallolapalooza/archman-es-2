GNOME-SESSION-QUIT(1) Comandos de usuario GNOME-SESSION-QUIT(1)

NOMBRE

gnome-session-quit - Finalizar la sesión GNOME actual

SINOPSIS

gnome-session-quit [OPCIÓN...]

DESCRIPCIÓN

gnome-session-quit se puede usar para finalizar una sesión GNOME.

OPCIONES

-h, --help

Muestra la ayuda y sale

--logout

Solicita al usuario que confirme el cierre de sesión. Este es el comportamiento predeterminado. No se puede combinar con --power-off o --reboot.

--power-off

Solicita al usuario que confirme el apagado del sistema. No se puede combinar con --logout o --reboot.

--reboot

Solicita al usuario que confirme el reinicio del sistema. No se puede combinar con --logout o --power-off.

--force

Ignora cualquier inhibidor.

--no-prompt

Finaliza la sesión sin interacción del usuario. Esto solo funciona con --logout.
