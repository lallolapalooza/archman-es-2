NOMBRE

gnutls_pkcs11_token_init - función de la API

SINOPSIS

#include <gnutls/pkcs11.h>

int gnutls_pkcs11_token_init(const char * token_url, const char * so_pin, const char * label);

ARGUMENTOS

const char * token_url
Una URL PKCS 11 que especifica un token
const char * so_pin
PIN del Oficial de Seguridad
const char * label
Un nombre que se utilizará para el token, de como máximo 32 caracteres

DESCRIPCIÓN

Esta función inicializará (formateará) un token. Si el token se encuentra en el estado de fábrica por defecto, el PIN del oficial de seguridad proporcionado se establecerá como el valor predeterminado. De lo contrario, debe coincidir con el PIN del oficial.

DEVOLUCIONES

En caso de éxito, se devuelve GNUTLS_E_SUCCESS (0), de lo contrario, un valor de error negativo.
