NOMBRE

gnutls_digest_set_secure - función de API

SINOPSIS

#include <gnutls/gnutls.h>

int gnutls_digest_set_secure(gnutls_digest_algorithm_t dig, unsigned int secure);

ARGUMENTOS

gnutls_digest_algorithm_t dig
es un algoritmo de resumen
unsigned int secure
si se debe marcar el algoritmo de resumen como seguro

DESCRIPCIÓN

Modifica la configuración previa del sistema que marcaba dig como seguro o inseguro. Esto solo tiene efecto cuando el algoritmo está habilitado a través del modo de lista blanca en el archivo de configuración, o cuando la configuración se modifica con una llamada previa a esta función.
