gnutls_pkcs11_copy_x509_privkey2(3)

Licencias: GPL-3.0-or-later AND LGPL-2.1-or-later

gnutls_pkcs11_copy_x509_privkey2(3) gnutls gnutls_pkcs11_copy_x509_privkey2(3)

NOMBRE

gnutls_pkcs11_copy_x509_privkey2 - Función de la API

SINOPSIS

#include <gnutls/pkcs11.h>

int gnutls_pkcs11_copy_x509_privkey2(const char * token_url, gnutls_x509_privkey_t key, const char * label, const gnutls_datum_t * cid, unsigned int key_usage, unsigned int flags);

ARGUMENTOS

const char * token_url
Una URL PKCS 11 que especifica un token
gnutls_x509_privkey_t key
Una clave privada
const char * label
Un nombre que se utilizará para los datos almacenados
const gnutls_datum_t * cid
El CKA_ID a establecer para el objeto - si es NULL, el ID se derivará de la clave pública
unsigned int key_usage
Uno de GNUTLS_KEY_*
unsigned int flags
Uno de los flags GNUTLS_PKCS11_OBJ_*

DESCRIPCIÓN

Esta función copiará una clave privada en un token PKCS 11 especificado por una URL.

Desde la versión 3.6.3, los objetos se marcan como sensibles por defecto, a menos que se especifique GNUTLS_PKCS11_OBJ_FLAG_MARK_NOT_SENSITIVE.

RETORNA

En caso de éxito, se devuelve GNUTLS_E_SUCCESS (0), de lo contrario, un valor de error negativo.
