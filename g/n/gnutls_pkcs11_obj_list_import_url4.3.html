gnutls_pkcs11_obj_list_import_url4(3) gnutls gnutls_pkcs11_obj_list_import_url4(3)

NOMBRE

gnutls_pkcs11_obj_list_import_url4 - función de la API

SINOPSIS

#include <gnutls/pkcs11.h>

int gnutls_pkcs11_obj_list_import_url4(gnutls_pkcs11_obj_t ** p_list, unsigned int * n_list, const char * url, unsigned int flags);

ARGUMENTOS

gnutls_pkcs11_obj_t ** p_list
Una lista de objetos no inicializada (puede ser NULL)
unsigned int * n_list
Contendrá el tamaño de la lista.
const char * url
Una URL PKCS 11 que identifica un conjunto de objetos
unsigned int flags
Una secuencia de flags GNUTLS_PKCS11_OBJ_*

DESCRIPCIÓN

Esta función enumerará todos los objetos especificados por la URL PKCS11 proporcionada. Inicializará y establecerá valores en la lista de punteros de objetos ( p_list ) proporcionada. Para obtener una lista de todos los objetos disponibles, use una url de 'pkcs11:'.

Todos los objetos devueltos deben ser desinicializados usando gnutls_pkcs11_obj_deinit(), y p_list debe ser desinicializado usando gnutls_free().

Los flags soportados en esta función son GNUTLS_PKCS11_OBJ_FLAG_LOGIN, GNUTLS_PKCS11_OBJ_FLAG_LOGIN_SO, GNUTLS_PKCS11_OBJ_FLAG_PRESENT_IN_TRUSTED_MODULE, GNUTLS_PKCS11_OBJ_FLAG_CRT, GNUTLS_PKCS11_OBJ_FLAG_PUBKEY, GNUTLS_PKCS11_OBJ_FLAG_PRIVKEY, GNUTLS_PKCS11_OBJ_FLAG_WITH_PRIVKEY, GNUTLS_PKCS11_OBJ_FLAG_MARK_CA, GNUTLS_PKCS11_OBJ_FLAG_MARK_TRUSTED, y desde la versión 3.5.1 GNUTLS_PKCS11_OBJ_FLAG_OVERWRITE_TRUSTMOD_EXT.

En versiones de GnuTLS anteriores a la 3.4.0, la función equivalente era gnutls_pkcs11_obj_list_import_url2(). Esta también está disponible en esta versión como una macro que se mapea a esta función.

RETORNA

En caso de éxito, se devuelve GNUTLS_E_SUCCESS (0), de lo contrario, un valor de error negativo.
