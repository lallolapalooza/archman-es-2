NOMBRE

gnutls_ocsp_req_add_cert_id - función de la API

SINOPSIS

#include <gnutls/ocsp.h>

int gnutls_ocsp_req_add_cert_id(gnutls_ocsp_req_t req, gnutls_digest_algorithm_t digest, const gnutls_datum_t * issuer_name_hash, const gnutls_datum_t * issuer_key_hash, const gnutls_datum_t * serial_number);

ARGUMENTOS

gnutls_ocsp_req_t req
debería contener un tipo gnutls_ocsp_req_t
gnutls_digest_algorithm_t digest
algoritmo de hash, un valor gnutls_digest_algorithm_t
const gnutls_datum_t * issuer_name_hash
hash del DN del emisor
const gnutls_datum_t * issuer_key_hash
hash de la clave pública del emisor
const gnutls_datum_t * serial_number
número de serie del certificado a comprobar

DESCRIPCIÓN

Esta función añadirá otra solicitud a la solicitud OCSP para un certificado particular que tenga el hash del nombre del emisor de
issuer_name_hash y el hash de la clave del emisor de issuer_key_hash (ambos hasheados usando digest ) y el número de serie serial_number .

La información necesaria corresponde a la estructura CertID:

<informalexample><programlisting> CertID ::= SEQUENCE { hashAlgorithm AlgorithmIdentifier, issuerNameHash OCTET STRING, -- Hash del DN del Emisor issuerKeyHash OCTET STRING, -- Hash de la clave pública del Emisor serialNumber CertificateSerialNumber } </programlisting></informalexample>

DEVUELVE

En caso de éxito, se devuelve GNUTLS_E_SUCCESS (0), de lo contrario se devuelve un código de error negativo.
