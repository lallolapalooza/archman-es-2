NOMBRE

gnutls_cipher_decrypt2 - Función de API

SINOPSIS

#include <gnutls/crypto.h>

int gnutls_cipher_decrypt2(gnutls_cipher_hd_t handle, const void * ctext, size_t ctext_len, void * ptext, size_t ptext_len);

ARGUMENTOS

gnutls_cipher_hd_t handle
es un tipo gnutls_cipher_hd_t
const void * ctext
los datos a descifrar
size_t ctext_len
la longitud de los datos a descifrar
void * ptext
los datos descifrados
size_t ptext_len
la longitud disponible para los datos descifrados

DESCRIPCIÓN

Esta función descifrará los datos proporcionados utilizando el algoritmo especificado por el contexto. Para cifrados de bloque, ctext_len debe ser un múltiplo del tamaño del bloque. Para los cifrados soportados, la longitud de los datos del texto plano será igual al tamaño del texto cifrado.

Tenga en cuenta que en los cifrados AEAD, esto no verificará la etiqueta. Deberá comparar la etiqueta enviada con el valor devuelto por gnutls_cipher_tag().

DEVUELVE

Cero o un código de error negativo en caso de error.
