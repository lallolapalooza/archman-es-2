NOMBRE

gnutls_ext_raw_parse - función de la API

SINOPSIS

#include <gnutls/gnutls.h>

int gnutls_ext_raw_parse(void * ctx, gnutls_ext_raw_process_func cb, const gnutls_datum_t * data, unsigned int flags);

ARGUMENTOS

void * ctx
un puntero para pasar a la función de devolución de llamada
gnutls_ext_raw_process_func cb
función de devolución de llamada para procesar cada extensión encontrada
const gnutls_datum_t * data
datos de la extensión TLS
unsigned int flags
debe ser cero o GNUTLS_EXT_RAW_FLAG_TLS_CLIENT_HELLO o GNUTLS_EXT_RAW_FLAG_DTLS_CLIENT_HELLO

DESCRIPCIÓN

Esta función itera a través de las extensiones TLS tal como se pasan en
data , pasando los datos individuales de la extensión a la función de devolución de llamada.
data debe cumplir con el formato Extension extensions<0..2^16-1>.

Si las flags son GNUTLS_EXT_RAW_TLS_FLAG_CLIENT_HELLO, esta función analizará los datos de la extensión desde la posición, como si el paquete en
data fuera un client hello (sin encabezados de registro o handshake), tal como lo proporciona gnutls_handshake_set_hook_function().

El valor de retorno de la función de devolución de llamada se propagará.

DEVUELVE

GNUTLS_E_SUCCESS si tiene éxito, o un código de error. En flags desconocidas, devuelve GNUTLS_E_INVALID_REQUEST.
