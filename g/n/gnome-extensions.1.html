Nombre

gnome-extensions - Herramienta de línea de comandos para gestionar extensiones de GNOME

SINOPSIS

gnome-extensions help [COMMAND]
gnome-extensions version
gnome-extensions enable UUID
gnome-extensions disable UUID
gnome-extensions reset UUID
gnome-extensions info UUID
gnome-extensions show UUID
gnome-extensions list [OPTION...]
gnome-extensions prefs UUID
gnome-extensions create [OPTION...]
gnome-extensions pack [OPTION...]
gnome-extensions install [OPTION...] PACK
gnome-extensions uninstall UUID
gnome-extensions upload [OPTION...] PACK...

DESCRIPCIÓN

gnome-extensions es una utilidad que pone a disposición en la línea de comandos algunas operaciones comunes con extensiones de GNOME.

OPCIONES COMUNES

Todos los comandos excepto help y version manejan las siguientes opciones:

--quiet, -q

No imprimir mensajes de error

COMANDOS

help [COMMAND]

Muestra un breve resumen de los comandos disponibles o proporciona ayuda detallada sobre un comando específico.

version

Imprime la versión del programa.

enable UUID

Habilita la extensión identificada por UUID.

El comando no detectará ningún error de la propia extensión, use el comando info para confirmar que el estado de la extensión es ACTIVE.

Si la extensión ya está habilitada, el comando no hará nada.

disable UUID

Deshabilita la extensión identificada por UUID.

Si la extensión no está habilitada, el comando no hará nada.

reset UUID

Restablece la extensión identificada por UUID.

La extensión será deshabilitada en GNOME, pero puede ser habilitada por otras sesiones como GNOME Classic.

info UUID

Muestra detalles de la extensión identificada por UUID, incluyendo nombre, descripción y estado.

show UUID

Sinónimo de info.

list [OPTION...]

Muestra una lista de las extensiones instaladas.

Crea un paquete de extensión adecuado para publicación. El paquete siempre incluirá los archivos requeridos extension.js y metadata.json, así como cualquiera de los opcionales stylesheet.css, stylesheet-dark.css, stylesheet-light.css o prefs.js si se encuentran. Cada fuente adicional que deba incluirse debe especificarse con--extra-source

. Si la extensión incluye uno o más esquemas GSettings, estos pueden colocarse en una carpeta schemas/ para ser detectados automáticamente, o especificarse con--schema

. De manera similar, las traducciones se incluyen automáticamente cuando se encuentran en una carpeta po/, de lo contrario se puede usar la opción --podir para apuntar al directorio correcto. Si no se proporciona un dominio gettext en la línea de comandos, se usa el valor del campo de metadatos gettext-domain

si existe, y el UUID de la extensión si no. Todos los archivos se buscan en SOURCE-DIRECTORY

si se especifica, o en el directorio actual de lo contrario.
