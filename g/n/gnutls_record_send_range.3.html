NOMBRE

gnutls_record_send_range - Función de API

SINÓPSIS

#include <gnutls/gnutls.h>

ssize_t gnutls_record_send_range(gnutls_session_t session, const void * data, size_t data_size, const gnutls_range_st * range);

ARGUMOS

gnutls_session_t session
es un tipo gnutls_session_t.
const void * data
contiene los datos a enviar.
size_t data_size
es la longitud de los datos.
const gnutls_range_st * range
es el rango de longitudes en el que se debe ocultar la longitud real de los datos.

DESCRIPCIÓN

Esta función opera de manera similar a gnutls_record_send() pero, mientras que gnutls_record_send() agrega un relleno mínimo a cada registro TLS, esta función utiliza la característica de relleno extra de TLS para ocultar el tamaño real de los datos dentro del rango de longitudes proporcionado. Algunas sesiones TLS no admiten relleno extra (por ejemplo, cifrados de flujo en TLS estándar o sesiones SSL3). Para saber si la sesión actual admite relleno extra y, por lo tanto, el ocultamiento de longitud, use la función gnutls_record_can_use_length_hiding().

NOTA

Esta función está actualmente limitada a sockets de bloqueo.

RETORNOS

El número de bytes enviados (es decir, data_size en una invocación exitosa), o un código de error negativo.
