NOMBRE

gnutls_certificate_set_retrieve_function3 - función de la API

SINOPSIS

#include <gnutls/abstract.h>

void gnutls_certificate_set_retrieve_function3(gnutls_certificate_credentials_t cred, gnutls_certificate_retrieve_function3 * func);

ARGUMENTOS

gnutls_certificate_credentials_t cred
es un tipo gnutls_certificate_credentials_t.
gnutls_certificate_retrieve_function3 * func
es la función de callback

DESCRIPCIÓN

Esta función establece una función de callback que se llamará para recuperar el certificado y las respuestas OCSP a utilizar en el handshake. func solo se llamará si el par solicita un certificado durante el handshake o durante la autenticación post-handshake.

El prototipo de la función de callback se define en `abstract.h':

int gnutls_certificate_retrieve_function3( gnutls_session_t, const struct gnutls_cert_retr_st *info, gnutls_pcert_st **certs, unsigned int *certs_length, gnutls_ocsp_data_st **ocsp, unsigned int *ocsp_length, gnutls_privkey_t *privkey, unsigned int *flags);

El campo info del callback contiene:
req_ca_dn que es una lista con los nombres de las CA que el servidor considera confiables. Esto es una pista y típicamente el cliente debería enviar un certificado firmado por una de estas CA. Estos nombres, cuando están disponibles, están codificados en DER. Para obtener un valor más significativo, use la función gnutls_x509_rdn_get().
pk_algos contiene una lista con los algoritmos de clave pública aceptables del servidor. El certificado devuelto debería soportar los algoritmos dados por el servidor.

El callback debería rellenar los siguientes valores:


certs debería contener una lista asignada de certificados y claves públicas.
certs_length es el tamaño de la lista anterior.
ocsp debería contener una lista asignada de respuestas OCSP.
ocsp_length es el tamaño de la lista anterior.
privkey es la clave privada.

Si los flags en el callback se establecen a GNUTLS_CERT_RETR_DEINIT_ALL, entonces todos los valores proporcionados deben ser asignados usando gnutls_malloc() y serán liberados por gnutls; de lo contrario, gnutls no los modificará.

La función de callback debería establecer la lista de certificados y respuestas OCSP a enviar, y devolver 0 en caso de éxito. Si no hay certificados disponibles, certs_length y ocsp_length deberían establecerse a cero. El valor de retorno (-1) indica un error y el handshake se terminará. Si tanto los certificados se establecen en las credenciales como una función de callback está disponible, la función de callback tiene precedencia.

Claves públicas en bruto: En caso de que se negocien claves públicas en bruto como tipo de certificado, los certificados que normalmente contendrían el material de la clave pública no estarán disponibles. En ese caso,
certs contiene una lista asignada solo con la clave pública. Dado que no hay certificado, tampoco hay estado del certificado. Por lo tanto, no se debería establecer información OCSP.
