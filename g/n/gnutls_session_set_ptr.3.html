NOMBRE

gnutls_session_set_ptr - Función de la API

SINOPSIS

#include <gnutls/gnutls.h>

void gnutls_session_set_ptr(gnutls_session_t session, void * ptr);

ARGUMENTOS

gnutls_session_t session
es un tipo gnutls_session_t.
void * ptr
es el puntero de usuario

DESCRIPCIÓN

Esta función establecerá (asociará) el puntero proporcionado por el usuario ptr a la estructura de sesión. Este puntero puede ser accedido con gnutls_session_get_ptr().
