NOMBRE

gnutls_pem_base64_encode - Función de la API

SINOPSIS

#include <gnutls/gnutls.h>

int gnutls_pem_base64_encode(const char * msg, const gnutls_datum_t * data, char * result, size_t * result_size);

ARGUMENTOS

const char * msg
es un mensaje para poner en la cabecera (puede ser NULL)
const gnutls_datum_t * data
contiene los datos brutos
char * result
el lugar donde se copiarán los datos base64
size_t * result_size
contiene el tamaño del resultado

DESCRIPCIÓN

Esta función convertirá los datos proporcionados a datos imprimibles, utilizando la codificación base64. Esta es la codificación utilizada en los mensajes PEM.

La cadena de salida estará terminada en nulo, aunque el tamaño de la salida no incluirá el nulo terminador.

VALORES DEVUELTOS

En caso de éxito se devuelve GNUTLS_E_SUCCESS (0), GNUTLS_E_SHORT_MEMORY_BUFFER se devuelve si el búfer proporcionado no es lo suficientemente largo, o 0 en caso de éxito.
