NOMBRE

gnutls_pkcs11_obj_init - Función de la API

SINOPSIS

#include <gnutls/pkcs11.h>

int gnutls_pkcs11_obj_init(gnutls_pkcs11_obj_t * obj);

ARGUMENTOS

gnutls_pkcs11_obj_t * obj
Un puntero al tipo a inicializar

DESCRIPCIÓN

Esta función inicializará una estructura de certificado pkcs11.

RETORNA

En caso de éxito, se devuelve GNUTLS_E_SUCCESS (0), de lo contrario, un valor de error negativo.
