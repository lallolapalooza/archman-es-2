gnutls_ocsp_resp_get_single(3) gnutls gnutls_ocsp_resp_get_single(3)

NOMBRE

gnutls_ocsp_resp_get_single - función de la API

SINOPSIS

#include <gnutls/ocsp.h>

int gnutls_ocsp_resp_get_single(gnutls_ocsp_resp_const_t resp, unsigned indx, gnutls_digest_algorithm_t * digest, gnutls_datum_t * issuer_name_hash, gnutls_datum_t * issuer_key_hash, gnutls_datum_t * serial_number, unsigned int * cert_status, time_t * this_update, time_t * next_update, time_t * revocation_time, unsigned int * revocation_reason);

ARGUMENTOS

gnutls_ocsp_resp_const_t resp
debe contener un tipo gnutls_ocsp_resp_t
unsigned indx
Especifica el número de respuesta a obtener. Use (0) para obtener la primera.
gnutls_digest_algorithm_t * digest
variable de salida con el algoritmo de hash gnutls_digest_algorithm_t
gnutls_datum_t * issuer_name_hash
buffer de salida con el hash del DN del emisor
gnutls_datum_t * issuer_key_hash
buffer de salida con el hash de la clave pública del emisor
gnutls_datum_t * serial_number
buffer de salida con el número de serie del certificado a verificar
unsigned int * cert_status
un estado del certificado, una enumeración gnutls_ocsp_cert_status_t.
time_t * this_update
hora en la que se sabe que el estado es correcto.
time_t * next_update
cuándo habrá información más reciente disponible, o (time_t)-1 si no se especifica
time_t * revocation_time
cuando cert_status es GNUTLS_OCSP_CERT_REVOKED, contiene la hora de revocación.
unsigned int * revocation_reason
razón de revocación, una enumeración gnutls_x509_crl_reason_t.

DESCRIPCIÓN

Esta función devolverá la información del certificado de la
respuesta con índice indx en la Respuesta OCSP Básica resp. La información devuelta corresponde a la estructura OCSP SingleResponse, excepto las singleExtensions finales.

Cada uno de los punteros a variables de salida puede ser NULL para indicar que el llamador no está interesado en ese valor.

RETORNA

En caso de éxito, se devuelve GNUTLS_E_SUCCESS (0), de lo contrario, se devuelve un código de error negativo. Si se ha alcanzado el último CertID disponible, se devolverá GNUTLS_E_REQUESTED_DATA_NOT_AVAILABLE.
