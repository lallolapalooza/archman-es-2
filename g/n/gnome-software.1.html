GNOME-SOFTWARE(1) Comandos de usuario GNOME-SOFTWARE(1)

NOMBRE

gnome-software - Instalar y actualizar aplicaciones

SINOPSIS

gnome-software [OPCIÓN...])

DESCRIPCIÓN

gnome-software le permite agregar y eliminar aplicaciones y actualizar su sistema.

OPCIONES

--mode=MODO

Inicia gnome-software en el modo dado. MODO puede ser updates, updated, installed u overview. El modo predeterminado es overview.

--search=BÚSQUEDA

Busca aplicaciones.

--details=ID

Muestra los detalles de la aplicación (usando el ID de la aplicación).

--details-pkg=NOMBREPAQUETE

Muestra los detalles de la aplicación (usando el nombre del paquete).

--install=ID

Instala la aplicación (usando el ID de la aplicación).

--uninstall=ID

Desinstala la aplicación (usando el ID de la aplicación).

--local-filename=NOMBREARCHIVO

Abre un archivo de paquete local.

--interaction=INTERACCIÓN

El tipo de interacción esperado para esta acción: none, notify o full.

--show-metainfo=NOMBREARCHIVO

Muestra un archivo metainfo o appdata local.

--verbose

Habilita la salida de depuración detallada (de la instancia en ejecución, si ya está en ejecución).

--autoupdate

Instala las actualizaciones pendientes en segundo plano.

--prefs

Muestra las preferencias.

--quit

Cierra la instancia en ejecución.

--prefer-local

Prefiere las fuentes de archivos locales a AppStream.

--version

Imprime la versión y sale.

-?, --help

Muestra la ayuda y sale.

Otras opciones estándar de GNOME no listadas aquí también son soportadas.

ERRORES

El rastreador de errores se puede encontrar visitando el sitio web https://gitlab.gnome.org/GNOME/gnome-software/issues.
