NOMBRE

gnutls_certificate_set_x509_key - Función de la API

SINOPSIS

#include <gnutls/gnutls.h>

int gnutls_certificate_set_x509_key(gnutls_certificate_credentials_t res, gnutls_x509_crt_t * cert_list, int cert_list_size, gnutls_x509_privkey_t key);

ARGUMENTOS

gnutls_certificate_credentials_t res
es un tipo gnutls_certificate_credentials_t.
gnutls_x509_crt_t * cert_list
contiene una lista de certificados (ruta) para la clave privada especificada
int cert_list_size
contiene el tamaño de la lista de certificados
gnutls_x509_privkey_t key
es una clave gnutls_x509_privkey_t

DESCRIPCIÓN

Esta función establece un par certificado/clave privada en el tipo gnutls_certificate_credentials_t. Esta función puede ser llamada más de una vez, en caso de que existan múltiples claves/certificados para el servidor. Para clientes que deseen enviar más que su propio certificado de entidad final (por ejemplo, también un certificado de CA intermedio), entonces coloque la cadena de certificados en cert_list.

Tenga en cuenta que los certificados y claves proporcionados pueden ser desinicializados de forma segura después de que esta función sea llamada.

Si esta función falla al cargar, el tipo res se encuentra en un estado indefinido, no debe ser reutilizado para cargar otras claves o certificados.

Tenga en cuenta que, por defecto, esta función devuelve cero en caso de éxito y un valor negativo en caso de error. Desde la versión 3.5.6, cuando la bandera GNUTLS_CERTIFICATE_API_V2 se establece usando gnutls_certificate_set_flags(), devuelve un índice (mayor o igual a cero). Ese índice puede ser utilizado por otras funciones para referirse al par clave añadido.

RETORNA

En caso de éxito, esta función devuelve cero y, de lo contrario, un valor negativo en caso de error (ver arriba para modificar ese comportamiento).
