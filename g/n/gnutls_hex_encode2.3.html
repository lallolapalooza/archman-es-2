NOMBRE

gnutls_hex_encode2 - Función de API

SINOPSIS

#include <gnutls/gnutls.h>

int gnutls_hex_encode2(const gnutls_datum_t * data, gnutls_datum_t * result);

ARGUMENTOS

const gnutls_datum_t * data
contiene los datos brutos
gnutls_datum_t * result
el resultado en una cadena asignada

DESCRIPCIÓN

Esta función convertirá los datos dados a datos imprimibles, usando la codificación hexadecimal, tal como se usa en los archivos de contraseña PSK.

Tenga en cuenta que el tamaño del resultado NO incluye el terminador nulo.

VALOR DEVUELTO

GNUTLS_E_SUCCESS si tiene éxito, de lo contrario, un código de error negativo.
