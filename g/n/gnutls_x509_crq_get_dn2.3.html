NOMBRE

gnutls_x509_crq_get_dn2 - función de API

SINOPSIS

#include <gnutls/x509.h>

int gnutls_x509_crq_get_dn2(gnutls_x509_crq_t crq, gnutls_datum_t * dn);

ARGUMENTOS

gnutls_x509_crq_t crq
debería contener un tipo gnutls_x509_crq_t
gnutls_datum_t * dn
un puntero a una estructura para contener el nombre; debe liberarse usando gnutls_free()

DESCRIPCIÓN

Esta función asignará un búfer y copiará el nombre de la solicitud de certificado. El nombre tendrá el formato "C=xxxx,O=yyyy,CN=zzzz" como se describe en RFC4514. La cadena de salida estará codificada en ASCII o UTF-8, dependiendo de los datos del certificado.

Esta función no genera una cadena completamente compatible con RFC4514. Si se requiere eso, consulte gnutls_x509_crq_get_dn3().

RETORNA

En caso de éxito, se devuelve GNUTLS_E_SUCCESS (0), de lo contrario, un valor de error negativo y un código de error negativo en caso de error.
