GNOME-CONTACTS(1) Comandos de usuario GNOME-CONTACTS(1)

NOMBRE

gnome-contacts - Acceder y almacenar información sobre contactos

SINOPSIS

gnome-contacts [OPCIÓN...]

DESCRIPCIÓN

gnome-contacts es una interfaz gráfica de usuario para acceder y almacenar información sobre sus contactos.

gnome-contacts utiliza la biblioteca folks para recopilar información de contacto de diversas fuentes, incluyendo evolution-data-server, sus cuentas en línea de GNOME configuradas, etc.

OPCIONES

-?, --help

Imprime un breve texto de ayuda y sale.

-e, --email

Muestra el contacto con esta dirección de correo electrónico.

-i, --individual

Muestra el contacto con este id individual.

-v, --version

Muestra la versión actual de Contacts.
