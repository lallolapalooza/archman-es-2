NOMBRE

gnutls_session_get_verify_cert_status - función de API

SINOPSIS

#include <gnutls/gnutls.h>

unsigned int gnutls_session_get_verify_cert_status(gnutls_session_t session);

ARGUMENTOS

gnutls_session_t session
es una sesión de gnutls

DESCRIPCIÓN

Esta función devuelve el estado de la verificación cuando se inició mediante la verificación automática, es decir, mediante gnutls_session_set_verify_cert2() o gnutls_session_set_verify_cert(). Si no se produjo ninguna verificación de certificado, el valor de retorno se establecería en ((unsigned int)-1).

El estado de verificación del certificado es el mismo que en gnutls_certificate_verify_peers().

DEVUELVE

el estado de verificación del certificado.
