GNOME-DISKS(1) utilidad de discos de gnome GNOME-DISKS(1)

NOMBRE

gnome-disks - la aplicación GNOME Disks

SINOPSIS

gnome-disks [OPCIONES]

DESCRIPCIÓN

gnome-disks es el comando para iniciar la aplicación GNOME Disks. Disks proporciona una forma de inspeccionar, formatear, particionar y configurar discos y dispositivos de bloque.

La aplicación Disks es de instancia única. Lo que esto significa es que si la aplicación aún no se está ejecutando cuando se invoca el comando gnome-disks, se iniciará y la invocación del comando se bloqueará hasta que la aplicación se cierre. De lo contrario, se utilizará la instancia de aplicación existente y el comando gnome-disks finalizará inmediatamente.

OPCIONES

Se entienden las siguientes opciones:

--block-device DISPOSITIVO

Cambia a la aplicación Disks y selecciona el dispositivo de bloque dado por DISPOSITIVO (por ejemplo, /dev/sda).

--block-device DISPOSITIVO --format-device [--xid ID-VENTANA]

Muestra el diálogo "Formatear Volumen" para el dispositivo de bloque dado por DISPOSITIVO (por ejemplo, /dev/sdb1). Si se proporciona ID-VENTANA, hace que el diálogo sea transitorio a la XID dada.

--restore-disk-image ARCHIVO

Muestra el diálogo "Restaurar Imagen de Disco" para el archivo dado por ARCHIVO (por ejemplo, /home/usuario/Descargas/SuperOS.iso) y le pide al usuario que elija un disco en el que restaurar la imagen.

-h, --help

Imprime un breve texto de ayuda y sale.
