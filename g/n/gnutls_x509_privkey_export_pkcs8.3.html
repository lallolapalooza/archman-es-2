NOMBRE

gnutls_x509_privkey_export_pkcs8 - Función API

SINOPSIS

#include <gnutls/x509.h>

int gnutls_x509_privkey_export_pkcs8(gnutls_x509_privkey_t key, gnutls_x509_crt_fmt_t format, const char * password, unsigned int flags, void * output_data, size_t * output_data_size);

ARGUMENTOS

gnutls_x509_privkey_t key
Contiene la clave
gnutls_x509_crt_fmt_t format
el formato de los parámetros de salida. Uno de PEM o DER.
const char * password
la contraseña que se utilizará para cifrar la clave.
unsigned int flags
una secuencia OR de gnutls_pkcs_encrypt_flags_t
void * output_data
contendrá una clave privada codificada en PEM o DER
size_t * output_data_size
contiene el tamaño de output_data (y será reemplazado por el tamaño real de los parámetros)

DESCRIPCIÓN

Esta función exportará la clave privada a una estructura PKCS8. Se pueden exportar claves RSA y DSA. Para claves DSA utilizamos las definiciones de PKCS 11. Si las banderas no especifican el cifrado de encriptación, entonces se utilizará el 3DES por defecto (PBES2).

La contraseña puede ser ASCII o UTF-8 en los esquemas de encriptación PBES2 por defecto, o ASCII para los esquemas PKCS12.

Si el búfer proporcionado no es lo suficientemente largo para contener la salida, entonces *output_data_size se actualizará y se devolverá GNUTLS_E_SHORT_MEMORY_BUFFER.

Si la estructura está codificada en PEM, tendrá una cabecera de "BEGIN ENCRYPTED PRIVATE KEY" o "BEGIN PRIVATE KEY" si no se utiliza encriptación.

DEVUELVE

En caso de fallo se devolverá un código de error negativo y 0 en caso de éxito.
