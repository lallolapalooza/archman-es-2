gnutls_psk_set_client_credentials(3)

Paquete: gnutls

Licencias: GPL-3.0-or-later AND LGPL-2.1-or-later

gnutls_psk_set_client_credentials(3) gnutls gnutls_psk_set_client_credentials(3)

NOMBRE

gnutls_psk_set_client_credentials - función API

SINOPSIS

#include <gnutls/gnutls.h>

int gnutls_psk_set_client_credentials(gnutls_psk_client_credentials_t res, const char * username, const gnutls_datum_t * key, gnutls_psk_key_flags flags);

ARGUMENTOS

gnutls_psk_client_credentials_t res
es un tipo gnutls_psk_client_credentials_t.
const char * username
es el nombre de usuario terminado en cero.
const gnutls_datum_t * key
es la clave del usuario.
gnutls_psk_key_flags flags
indica el formato de la clave, ya sea GNUTLS_PSK_KEY_RAW o GNUTLS_PSK_KEY_HEX.

DESCRIPCION

Esta función establece el nombre de usuario y la contraseña, en un tipo gnutls_psk_client_credentials_t. Estos se utilizarán en la autenticación PSK. username debe ser una cadena ASCII o UTF-8. En caso de una cadena UTF-8, se recomienda que siga el framework PRECIS para nombres de usuario (rfc8265). La clave puede estar en formato de bytes crudos o en formato Hex (sin el prefijo 0x).

RETORNOS

En caso de éxito, se devuelve GNUTLS_E_SUCCESS (0), de lo contrario, se devuelve un código de error.
