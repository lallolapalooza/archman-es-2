gnutls_x509_crq_get_extension_by_oid(3)

gnutls_x509_crq_get_extension_by_oid(3) gnutls gnutls_x509_crq_get_extension_by_oid(3)

NOMBRE

gnutls_x509_crq_get_extension_by_oid - Función API

SINOPSIS

#include <gnutls/x509.h>

int gnutls_x509_crq_get_extension_by_oid(gnutls_x509_crq_t crq, const char * oid, unsigned indx, void * buf, size_t * buf_size, unsigned int * critical);

ARGUMENTOS

gnutls_x509_crq_t crq
debe contener un tipo gnutls_x509_crq_t
const char * oid
contiene un Identificador de Objeto en una cadena terminada en nulo
unsigned indx
En caso de que existan múltiples OIDs iguales en las extensiones, esto especifica cuál obtener. Use (0) para obtener la primera.
void * buf
un puntero a una estructura para contener el nombre (puede ser nulo)
size_t * buf_size
inicialmente contiene el tamaño de buf
unsigned int * critical
será distinto de cero si la extensión está marcada como crítica

DESCRIPCIÓN

Esta función devolverá la extensión especificada por el OID en el certificado. Las extensiones se devolverán como datos binarios codificados en DER, en el buffer proporcionado.

RETORNOS

En caso de éxito, se devuelve GNUTLS_E_SUCCESS (0), de lo contrario, un código de error negativo en caso de error. Si el certificado no contiene la extensión especificada, se devolverá GNUTLS_E_REQUESTED_DATA_NOT_AVAILABLE.
