GNOME-COMMANDER(1) Manual de comandos generales GNOME-COMMANDER(1)

NOMBRE

gnome-commander - un gestor de archivos de GNOME

SINOPSIS

gnome-commander [-d CADENA] [opciones] [opciones gtk,gnome,bonobo]

DESCRIPCIÓN

GNOME Commander es un gestor de archivos gráfico rápido y potente para el entorno de escritorio GNOME, tiene una interfaz de "dos paneles" en la tradición de Norton y Midnight Commander.

OPCIONES

--help
Muestra un resumen de las opciones.
--version
Muestra la versión del programa.
-i, --start-left-dir=CADENA
Especifica el directorio de inicio para el panel izquierdo
-d, --start-right-dir=CADENA
Especifica el directorio de inicio para el panel derecho
  --config-dir=CADENA
Especifica el directorio para los archivos de configuración
-d, --debug=CADENA
Especifica las banderas de depuración a usar. La salida de depuración se escribirá en STDOUT.
Banderas posibles:
a: activa todas las banderas de depuración
c: conteo de archivos y directorios
d: conteo de referencias de directorios
f: conteo de referencias de archivos
g: depuración de run_command
i: cargador de imágenes
k: grupo de directorios
l: listados de directorios
m: depuración de conexión
n: monitoreo de directorios
p: monitoreo de scripts
s: navegador de red SMB
t: etiquetas de metadatos
u: depuración de acciones de usuario
v: visor interno
w: búsqueda de widgets
x: transferencia
y: carga de imágenes MIME rápida
z: carga de imágenes MIME detallada
[opciones gtk,gnome,bonobo]
Se admiten las opciones estándar de gtk, gnome y bonobo. Usa --help para ver las opciones posibles.

EJEMPLOS

gnome-commander -d nvl
Inicia GNOME Commander con depuración de listados de directorios, visor interno y facilidades de monitoreo de directorios.

CARPETAS

~/.config/gnome-commander/scripts
Scripts específicos del usuario, utilizados en el menú contextual de archivos.
/usr/lib/gnome-commander/plugins
Plugins a nivel de sistema.

ERRORES

Si encuentras algún error, por favor repórtalo (o mejor aún, corrígelo y envía un parche). Consulta la página principal de GNOME Commander para más información:
https://gcmd.github.io/

AUTOR

GNOME Commander fue desarrollado originalmente por Marcus Bjurman de 2001 a 2004. Assaf Gordon añadió el código del visor interno y otras funcionalidades. Piotr Eljasiak fue el gestor del proyecto de 2006 hasta 2012. Desde 2013 hasta ahora, Uwe Scholz <u.scholz83@gmx.de> es el gestor actual del proyecto.
Las traducciones y otras contribuciones fueron realizadas por numerosas personas. Ver
https://gitlab.gnome.org/GNOME/gnome-commander/-/graphs/master

La página del manual original fue escrita por Michael Vogt <mvo@debian.org>, para el sistema Debian GNU/Linux. La página del manual actual se mantiene como parte del proyecto GNOME Commander.
