gnutls_x509_crq_get_challenge_password(3)

Licencias: GPL-3.0-or-later AND LGPL-2.1-or-later

gnutls_x509_crq_get_challenge_password(3) gnutls gnutls_x509_crq_get_challenge_password(3)

NOMBRE

gnutls_x509_crq_get_challenge_password - función de la API

SINOPSIS

#include <gnutls/x509.h>

int gnutls_x509_crq_get_challenge_password(gnutls_x509_crq_t crq, char * pass, size_t * pass_size);

ARGUMENTOS

gnutls_x509_crq_t crq
debería contener un tipo gnutls_x509_crq_t
char * pass
contendrá una cadena de contraseña (terminada en 0)
size_t * pass_size
Inicialmente contiene el tamaño de pass.

DESCRIPCIÓN

Esta función devolverá la contraseña de desafío en la solicitud. La contraseña de desafío está destinada a ser utilizada para solicitar la revocación del certificado.

RETORNA

En caso de éxito, se devuelve GNUTLS_E_SUCCESS (0), de lo contrario, un valor de error negativo.
