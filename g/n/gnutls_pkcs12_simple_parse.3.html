NOMBRE

gnutls_pkcs12_simple_parse - Función de la API

SINOPSIS

#include <gnutls/pkcs12.h>

int gnutls_pkcs12_simple_parse(gnutls_pkcs12_t p12, const char * password, gnutls_x509_privkey_t * key, gnutls_x509_crt_t ** chain, unsigned int * chain_len, gnutls_x509_crt_t ** extra_certs, unsigned int * extra_certs_len, gnutls_x509_crl_t * crl, unsigned int flags);

ARGUMENTOS

gnutls_pkcs12_t p12
Un tipo pkcs12
const char * password
contraseña opcional utilizada para descifrar la estructura, bolsas y claves.
gnutls_x509_privkey_t * key
una estructura para almacenar la clave privada analizada.
gnutls_x509_crt_t ** chain
la cadena de certificados correspondiente a la clave (puede ser NULL)
unsigned int * chain_len
se actualizará con el número de adicionales (puede ser NULL)
gnutls_x509_crt_t ** extra_certs
puntero opcional para recibir una matriz de certificados adicionales encontrados en la estructura PKCS12 (puede ser NULL).
unsigned int * extra_certs_len
se actualizará con el número de certificados adicionales (puede ser NULL).
gnutls_x509_crl_t * crl
una estructura opcional para almacenar el CRL analizado (puede ser NULL).
unsigned int flags
debe ser cero o uno de GNUTLS_PKCS12_SP_*

DESCRIPCIÓN

Esta función analiza una estructura PKCS12 en pkcs12 y extrae la clave privada, la cadena de certificados correspondiente, cualquier certificado adicional y un CRL. Las estructuras en key , chain crl y extra_certs no deben estar inicializadas.

Los parámetros extra_certs y extra_certs_len son opcionales y ambos pueden establecerse en NULL. Si alguno no es NULL, entonces ambos deben establecerse. El valor para extra_certs se asigna usando gnutls_malloc().

Se admiten bolsas PKCS12 cifradas y claves privadas PKCS8, pero solo con seguridad basada en contraseña y la misma contraseña para todas las operaciones.

Tenga en cuenta que una estructura PKCS12 puede contener muchas claves y/o certificados, y no hay forma de identificar el par clave/certificado que desea. Por esta razón, esta función es útil para archivos PKCS12 que solo contienen un par clave/certificado y/o un CRL.

Si la estructura proporcionada tiene campos cifrados pero no se proporciona contraseña, esta función devuelve GNUTLS_E_DECRYPTION_FAILED.

Tenga en cuenta que normalmente la cadena construida no incluye certificados autofirmados, para cumplir con los requisitos de TLS. Si, sin embargo, se especifica la bandera GNUTLS_PKCS12_SP_INCLUDE_SELF_SIGNED, entonces los certificados autofirmados se incluirán en la cadena.

Antes de usar esta función, la integridad de la estructura PKCS 12 debe verificarse utilizando gnutls_pkcs12_verify_mac().

DEVUELVE

En caso de éxito, se devuelve GNUTLS_E_SUCCESS (0), de lo contrario, un valor de error negativo.
