gnutls_x509_crt_get_subject_alt_othername_oid(3) gnutls gnutls_x509_crt_get_subject_alt_othername_oid(3)

NOMBRE

gnutls_x509_crt_get_subject_alt_othername_oid - función de API

SINOPSIS

#include <gnutls/x509.h>

int gnutls_x509_crt_get_subject_alt_othername_oid(gnutls_x509_crt_t cert, unsigned int seq, void * oid, size_t * oid_size);

ARGUMENTOS

gnutls_x509_crt_t cert
debe contener un tipo gnutls_x509_crt_t
unsigned int seq
especifica el número de secuencia del nombre alternativo (0 para el primero, 1 para el segundo, etc.)
void * oid
es el lugar donde se copiará el OID de otherName
size_t * oid_size
contiene el tamaño de retorno.

DESCRIPCIÓN

Esta función extraerá el OID de tipo de un Nombre Alternativo de Sujeto otherName, contenido en el certificado dado, y devolverá el tipo como un elemento enumerado.

Esta función solo es útil si gnutls_x509_crt_get_subject_alt_name() devolvió GNUTLS_SAN_OTHERNAME.

Si oid es nulo, solo se rellenará el tamaño. El oid devuelto será terminado en nulo, aunque oid_size no tendrá en cuenta el nulo final.

DEVOLUCIONES

el tipo de nombre de asunto alternativo en caso de éxito, uno de los gnutls_x509_subject_alt_name_t enumerados. Para OIDs compatibles, devolverá uno de los tipos virtuales (GNUTLS_SAN_OTHERNAME_*), por ejemplo, GNUTLS_SAN_OTHERNAME_XMPP, y GNUTLS_SAN_OTHERNAME para OIDs desconocidos. Devolverá GNUTLS_E_SHORT_MEMORY_BUFFER si
ian_size no es lo suficientemente grande como para contener el valor. En ese caso
ian_size se actualizará con el tamaño requerido. Si el certificado no tiene un nombre alternativo con el número de secuencia especificado y con el tipo otherName, entonces se devolverá GNUTLS_E_REQUESTED_DATA_NOT_AVAILABLE.
