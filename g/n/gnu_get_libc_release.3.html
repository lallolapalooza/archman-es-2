gnu_get_libc_version(3) Manual de funciones de biblioteca gnu_get_libc_version(3)

NOMBRE

gnu_get_libc_version, gnu_get_libc_release - obtener versión y lanzamiento de glibc

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <gnu/libc-version.h>
const char *gnu_get_libc_version(void);
const char *gnu_get_libc_release(void);

DESCRIPCIÓN

La función gnu_get_libc_version() devuelve una cadena que identifica la versión de glibc disponible en el sistema.

La función gnu_get_libc_release() devuelve una cadena que indica el estado de lanzamiento de la versión de glibc disponible en el sistema. Esta será una cadena como stable.

ATRIBUTOS

Para obtener una explicación de los términos utilizados en esta sección, consulte attributes(7).

Interfaz Atributo Valor
gnu_get_libc_version (), gnu_get_libc_release () Seguridad de hilos MT-Safe

ESTÁNDARES

GNU.

HISTORIA

glibc 2.1.

EJEMPLOS

Al ejecutarse, el siguiente programa producirá una salida como la siguiente:


$ ./a.out
Versión de GNU libc: 2.8
Lanzamiento de GNU libc: stable

Código fuente del programa

#include <stdio.h>
#include <stdlib.h>
#include <gnu/libc-version.h>
int
main(void)
{
    printf("Versión de GNU libc: %s\n", gnu_get_libc_version());
    printf("Lanzamiento de GNU libc: %s\n", gnu_get_libc_release());
    exit(EXIT_SUCCESS);
}
