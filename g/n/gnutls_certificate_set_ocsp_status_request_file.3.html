gnutls_certificate_set_ocsp_status_request_file(3)

Licencias: GPL-3.0-or-later AND LGPL-2.1-or-later

gnutls_certificate_set_ocsp_status_request_file(3) gnutls gnutls_certificate_set_ocsp_status_request_file(3)

NOMBRE

gnutls_certificate_set_ocsp_status_request_file - función de la API

SINOPSIS

#include <gnutls/gnutls.h>

int gnutls_certificate_set_ocsp_status_request_file(gnutls_certificate_credentials_t sc, const char * response_file, unsigned idx);

ARGUMENTOS

gnutls_certificate_credentials_t sc
es una estructura de credenciales.
const char * response_file
un nombre de archivo de la respuesta OCSP
unsigned int idx
es un índice de certificado devuelto por gnutls_certificate_set_key() y similares.

DESCRIPCIÓN

Esta función carga la respuesta OCSP proporcionada. Se enviará al cliente si este solicita un estado de certificado OCSP para la cadena de certificados especificada por idx.

NOTA

La capacidad de establecer múltiples respuestas OCSP por estructura de credenciales a través del índice idx se añadió en la versión 3.5.6. Para mantener la compatibilidad con versiones anteriores, requiere el uso de gnutls_certificate_set_flags() con la bandera GNUTLS_CERTIFICATE_API_V2 para que las funciones de certificado establecido devuelvan un índice utilizable por esta función.

Esta función se puede llamar varias veces desde GnuTLS 3.6.3 cuando hay disponibles múltiples respuestas que se aplican a la cadena. Si la respuesta proporcionada no coincide con ningún certificado presente en la cadena, se devuelve el código GNUTLS_E_OCSP_MISMATCH_WITH_CERTS. Para volver al comportamiento anterior, establezca la bandera GNUTLS_CERTIFICATE_SKIP_OCSP_RESPONSE_CHECK en la estructura de credenciales del certificado. En ese caso, solo se puede establecer la respuesta OCSP del certificado final. Si la respuesta ya ha expirado en el momento de la carga, se devuelve el código GNUTLS_E_EXPIRED.

Para volver al comportamiento anterior de esta función, que no devuelve ningún error, establezca la bandera GNUTLS_CERTIFICATE_SKIP_OCSP_RESPONSE_CHECK.

RETORNA

En caso de éxito, se devuelve GNUTLS_E_SUCCESS (0), de lo contrario, se devuelve un código de error negativo.
