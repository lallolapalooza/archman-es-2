gnutls_x509_crq_get_subject_alt_name(3) gnutls gnutls_x509_crq_get_subject_alt_name(3)

NOMBRE

gnutls_x509_crq_get_subject_alt_name - Función de la API

SINOPSIS

#include <gnutls/x509.h>

int gnutls_x509_crq_get_subject_alt_name(gnutls_x509_crq_t crq, unsigned int seq, void * ret, size_t * ret_size, unsigned int * ret_type, unsigned int * critical);

ARGUMENTOS

gnutls_x509_crq_t crq
debería contener un tipo gnutls_x509_crq_t
unsigned int seq
especifica el número de secuencia del nombre alternativo, 0 para el primero, 1 para el segundo, etc.
void * ret
es el lugar donde se copiará el nombre alternativo
size_t * ret_size
contiene el tamaño de ret.
unsigned int * ret_type
contiene el tipo de nombre gnutls_x509_subject_alt_name_t
unsigned int * critical
será distinto de cero si la extensión está marcada como crítica (puede ser nulo)

DESCRIPCIÓN

Esta función devolverá los nombres alternativos, contenidos en el certificado dado. Es igual a gnutls_x509_crq_get_subject_alt_name() excepto por el hecho de que devolverá el tipo del nombre alternativo en ret_type incluso si la función falla por alguna razón (es decir, el búfer proporcionado no es suficiente).

VALORES DEVUELTOS

el tipo de nombre alternativo del sujeto en caso de éxito, uno de los enumerados gnutls_x509_subject_alt_name_t. Devolverá GNUTLS_E_SHORT_MEMORY_BUFFER si ret_size no es lo suficientemente grande para contener el valor. En ese caso ret_size se actualizará con el tamaño requerido. Si la solicitud de certificado no tiene un nombre alternativo con el número de secuencia especificado, se devolverá GNUTLS_E_REQUESTED_DATA_NOT_AVAILABLE.
