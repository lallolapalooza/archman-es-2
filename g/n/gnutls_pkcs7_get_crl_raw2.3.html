NOMBRE

gnutls_pkcs7_get_crl_raw2 - función de la API

SINOPSIS

#include <gnutls/pkcs7.h>

int gnutls_pkcs7_get_crl_raw2(gnutls_pkcs7_t pkcs7, unsigned indx, gnutls_datum_t * crl);

ARGUMENTOS

gnutls_pkcs7_t pkcs7
El tipo pkcs7
unsigned indx
contiene el índice del crl a extraer
gnutls_datum_t * crl
contendrá el contenido del CRL en un buffer asignado

DESCRIPCIÓN

Esta función devolverá un CRL codificado en DER del conjunto de crl PKCS7 o RFC2630.

DEVUELVE

En caso de éxito, se devuelve GNUTLS_E_SUCCESS (0), de lo contrario, un valor de error negativo. Después de leer el último crl, se devolverá GNUTLS_E_REQUESTED_DATA_NOT_AVAILABLE.
