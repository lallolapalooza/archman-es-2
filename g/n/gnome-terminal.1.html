GNOME-TERMINAL(1) Comandos de usuario GNOME-TERMINAL(1)

NOMBRE

gnome-terminal - Un emulador de terminal para GNOME

SINOPSIS

gnome-terminal [OPCIÓN...] [-- PROGRAMA [ARG...]]

DESCRIPCIÓN

gnome-terminal es una aplicación de emulador de terminal para acceder a un entorno de shell de UNIX que puede ser utilizado para ejecutar programas disponibles en su sistema. Soporta varios perfiles, múltiples pestañas e implementa varios atajos de teclado.

OPCIONES

--help, -h

Muestra un breve resumen de todas las opciones.

--help-all

Muestra todas las opciones en detalle.

--help-gtk

Muestra todas las opciones de GTK.

--help-terminal

Muestra todas las opciones para seleccionar entre nuevas pestañas o ventanas de terminal.

--help-terminal-options

Muestra todas las opciones para cambiar los atributos de las terminales independientemente de si están en pestañas o ventanas separadas.

--help-window-options

Muestra todas las opciones para cambiar los atributos de las ventanas que contienen terminales.

--load-config=ARCHIVO

Restaura la aplicación a un estado guardado previamente cargándola desde un archivo de configuración.

--preferences

Muestra la ventana de preferencias.

--print-environment, -p

Imprime las variables de entorno para interactuar con las terminales recién creadas.

--quiet, -q

Suprime diagnósticos.

--verbose, -v

Aumenta la verbosidad de los diagnósticos.

--tab

Abre una nueva pestaña con una terminal en la ventana abierta más recientemente con el perfil por defecto.

--window

Abre una nueva ventana con una pestaña que contiene una terminal con el perfil por defecto.

--command, -e COMANDO

Divide el argumento de esta opción en un programa y argumentos de la misma manera que lo haría un shell, y ejecuta la línea de comandos resultante dentro de la terminal.

Esta opción está obsoleta. En su lugar, use -- para terminar las opciones, y coloque el programa y los argumentos a ejecutar después de él: por ejemplo, en lugar de gnome-terminal -e "python3 -q", prefiera usar gnome-terminal -- python3 -q.

Tenga en cuenta que el COMANDO no se ejecuta a través de un shell: se divide en palabras y se ejecuta como un programa. Si se requiere sintaxis de shell, use la forma gnome-terminal -- sh -c '...'.

--execute PROGRAMA [ARG...] , -x PROGRAMA [ARG...]

Deja de analizar opciones en este punto, e interpreta todas las opciones subsiguientes como un programa y argumentos para ejecutar dentro de la terminal.

Esta opción está obsoleta: use -- en su lugar. Por ejemplo, en lugar de gnome-terminal -x python3 -q, prefiera usar gnome-terminal -- python3 -q.

--fd=FD

Pasa el descriptor de archivo.

--profile=NOMBRE-PERFIL

Utiliza el perfil dado en lugar del perfil por defecto.

--title, -t TÍTULO

Establece el título inicial de la terminal.

--wait

Espera hasta que el proceso hijo de la terminal termine.

--working-directory=DIRNAME

Establece el directorio de trabajo de la terminal.

--zoom=ZOOM

Establece el factor de zoom de la terminal. 1.0 es el tamaño normal.

--active

Establece la última pestaña especificada como activa en su ventana.

--full-screen

Pone la ventana en pantalla completa.

--geometry=GEOMETRÍA

Establece el tamaño de la ventana como COLSxROWS+X+Y. Por ejemplo, 80x24 o 80x24+200+200.

--hide-menubar

Desactiva la barra de menú de la ventana.

--show-menubar

Activa la barra de menú de la ventana.

--maximize

Maximiza la ventana.

--role=ROLE

Establece el rol de la ventana X.

--class=CLASS

Clase del programa tal como la utiliza el gestor de ventanas.

--display=DISPLAY

Pantalla X a utilizar.

--g-fatal-warnings

Hace que todas las advertencias sean fatales.

--gdk-debug=FLAGS

Banderas de depuración de GDK a establecer.

--gdk-no-debug=FLAGS

Banderas de depuración de GDK a desestablecer.

--gtk-debug=FLAGS

Banderas de depuración de GTK a establecer.

--gtk-no-debug=FLAGS

Banderas de depuración de GTK a desestablecer.

--gtk-module=MODULES

Carga módulos GTK adicionales.

--name=NAME

Nombre del programa tal como lo utiliza el gestor de ventanas.

ERRORES

Por favor, lea https://wiki.gnome.org/Apps/Terminal/ReportingBugs sobre cómo reportar errores.

EJEMPLOS

Para ejecutar una terminal que contenga un prompt interactivo de Python:

        gnome-terminal --title=Python -- python3 -q

Para interpretar sintaxis de shell en una terminal, ya sea escríbala en un script de shell separado, o use sh -c:

        gnome-terminal -- sh -c 'if [ "$(id -u)" = 0 ]; then ...'

VER TAMBIÉN

Para más información, visite el sitio web https://wiki.gnome.org/Apps/Terminal. Hay una lista de preguntas frecuentes en https://wiki.gnome.org/Apps/Terminal/FAQ.
