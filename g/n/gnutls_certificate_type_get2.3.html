NOMBRE

gnutls_certificate_type_get2 - Función de la API

SINOPSIS

#include <gnutls/gnutls.h>

gnutls_certificate_type_t gnutls_certificate_type_get2(gnutls_session_t sesión, gnutls_ctype_target_t objetivo);

ARGUMENTOS

gnutls_session_t sesión
es un tipo gnutls_session_t.
gnutls_ctype_target_t objetivo
es un tipo gnutls_ctype_target_t.

DESCRIPCIÓN

Esta función devuelve el tipo de certificado que un lado negoció para utilizar. El tipo de certificado es X.509 por defecto, a menos que un tipo de certificado alternativo sea habilitado por gnutls_init() y negociado durante la sesión.

El parámetro objetivo especifica si se solicita el tipo de certificado negociado para el cliente (GNUTLS_CTYPE_CLIENT), o para el servidor (GNUTLS_CTYPE_SERVER). Adicionalmente, en la conexión de modo P2P donde no sabes de antemano quién será el cliente y quién el servidor, puedes usar las banderas (GNUTLS_CTYPE_OURS) y (GNUTLS_CTYPE_PEERS) para obtener los tipos de certificado correspondientes.

Las sesiones reanudadas devolverán el tipo de certificado que fue negociado y utilizado en la sesión original. Es decir, esta función puede ser utilizada para determinar de manera confiable el tipo de certificado devuelto por gnutls_certificate_get_peers().

RETORNA

el tipo de certificado gnutls_certificate_type_t actualmente en uso para el cliente o el servidor.
