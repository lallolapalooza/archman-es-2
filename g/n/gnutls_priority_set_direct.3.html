NOMBRE

gnutls_priority_set_direct - función de API

SINOPSIS

#include <gnutls/gnutls.h>

int gnutls_priority_set_direct(gnutls_session_t session, const char * priorities, const char ** err_pos);

ARGUMENTOS

gnutls_session_t session
es un tipo gnutls_session_t.
const char * priorities
es una cadena que describe las prioridades
const char ** err_pos
En caso de error, contendrá la posición en la cadena donde ocurrió el error.

DESCRIPCIÓN

Establece las prioridades a usar en los cifrados, métodos de intercambio de claves y MACs. Esta función evita mantener una caché de prioridades y se utiliza para establecer directamente prioridades de cadena a una sesión TLS. Para obtener documentación, consulte gnutls_priority_init().

Para usar una opción predeterminada razonable, considere usar gnutls_set_default_priority() o gnutls_set_default_priority_append() en lugar de esta función.

VALORES DEVUELTOS

En caso de error de sintaxis, se devuelve GNUTLS_E_INVALID_REQUEST, GNUTLS_E_SUCCESS en caso de éxito, o un código de error.
