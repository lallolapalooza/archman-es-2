NOMBRE

gnutls_x509_crl_list_import - función API

SINOPSIS

#include <gnutls/x509.h>

int gnutls_x509_crl_list_import(gnutls_x509_crl_t * crls, unsigned int * crl_max, const gnutls_datum_t * data, gnutls_x509_crt_fmt_t format, unsigned int flags);

ARGUMENTOS

gnutls_x509_crl_t * crls
Indica dónde se copiarán las CRLs analizadas. No debe estar inicializado.
unsigned int * crl_max
Inicialmente debe contener el número máximo de CRLs. Se actualizará con el número de CRLs disponibles.
const gnutls_datum_t * data
Los datos de la CRL.
gnutls_x509_crt_fmt_t format
DER o PEM.
unsigned int flags
debe ser (0) o una secuencia combinada mediante OR de gnutls_certificate_import_flags.

DESCRIPCIÓN

Esta función convertirá la lista de CRLs dada al formato nativo gnutls_x509_crl_t. La salida se almacenará en crls. Se inicializarán automáticamente.

Si el Certificado está codificado en PEM, debe tener una cabecera de "X509 CRL".

RETORNA

el número de certificados leídos o un valor de error negativo.
