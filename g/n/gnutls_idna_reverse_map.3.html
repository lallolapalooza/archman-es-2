NOMBRE

gnutls_idna_reverse_map - Función de API

SINOPSIS

#include <gnutls/gnutls.h>

int gnutls_idna_reverse_map(const char * input, unsigned ilen, gnutls_datum_t * out, unsigned flags);

ARGUMENTOS

const char * input
contiene el nombre de dominio formateado ACE (IDNA)
unsigned ilen
la longitud de la cadena proporcionada
gnutls_datum_t * out
el resultado en una cadena UTF-8 asignada y terminada en nulo
unsigned flags
debería ser cero

DESCRIPCIÓN

Esta función convertirá un nombre de dominio ACE (codificado en ASCII) a un nombre de dominio UTF-8.

Si GnuTLS se compila sin soporte IDNA, esta función devolverá GNUTLS_E_UNIMPLEMENTED_FEATURE.

Tenga en cuenta también que esta función devolverá una cadena vacía si se proporciona una cadena vacía como entrada.

DEVUELVE

Un código de error negativo en caso de error, o 0 en caso de éxito.
