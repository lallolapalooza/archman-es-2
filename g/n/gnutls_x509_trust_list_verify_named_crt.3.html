gnutls_x509_trust_list_verify_named_crt(3) gnutls gnutls_x509_trust_list_verify_named_crt(3)

NOMBRE

gnutls_x509_trust_list_verify_named_crt - Función de API

SINOPSIS

#include <gnutls/x509.h>

int gnutls_x509_trust_list_verify_named_crt(gnutls_x509_trust_list_t lista, gnutls_x509_crt_t certificado, const void * nombre, size_t tamano_nombre, unsigned int flags, unsigned int * salida_verificacion, gnutls_verify_output_function funcion);

ARGUMENTOS

gnutls_x509_trust_list_t lista
La lista
gnutls_x509_crt_t certificado
es el certificado a verificar
const void * nombre
es el nombre del certificado
size_t tamano_nombre
es el tamaño del nombre del certificado
unsigned int flags
Marcas que pueden usarse para cambiar el algoritmo de verificación. Usar OR de las enumeraciones de gnutls_certificate_verify_flags.
unsigned int * salida_verificacion
contendrá la salida de la verificación del certificado.
gnutls_verify_output_function funcion
Si no es nulo, se llamará en cada elemento de la cadena de verificación con la salida.

DESCRIPCIÓN

Esta función intentará encontrar un certificado asociado con el nombre proporcionado -- ver gnutls_x509_trust_list_add_named_crt(). Si se encuentra una coincidencia, el certificado se considera válido. Además de eso, esta función también verificará las CRLs. El parámetro salida_verificacion contendrá una secuencia OR de las marcas gnutls_certificate_status_t.

Adicionalmente, se puede especificar un perfil de verificación de certificados de entre los de gnutls_certificate_verification_profiles_t mediante un OR del resultado de GNUTLS_PROFILE_TO_VFLAGS() a las marcas de verificación.

RETORNA

En caso de éxito, se devuelve GNUTLS_E_SUCCESS (0), de lo contrario, un valor de error negativo.
