gnutls_x509_privkey_verify_seed(3)

Licencias: GPL-3.0-or-later AND LGPL-2.1-or-later

gnutls_x509_privkey_verify_seed(3) gnutls gnutls_x509_privkey_verify_seed(3)

NOMBRE

gnutls_x509_privkey_verify_seed - función de la API

SINOPSIS

#include <gnutls/x509.h>

int gnutls_x509_privkey_verify_seed(gnutls_x509_privkey_t key, gnutls_digest_algorithm_t digest, const void * seed, size_t seed_size);

ARGUMENTOS

gnutls_x509_privkey_t key
debería contener un tipo gnutls_x509_privkey_t
gnutls_digest_algorithm_t digest
contiene el algoritmo de hash utilizado para la generación de claves (si corresponde)
const void * seed
la semilla de la clave a verificar
size_t seed_size
contiene el tamaño de seed

DESCRIPCIÓN

Esta función verificará que la clave privada proporcionada fue generada a partir de la semilla proporcionada. Si seed es NULL, entonces la semilla almacenada en la estructura de la key se utilizará para la verificación.

VALORES DEVUELTOS

En caso de fallo en la verificación, se devuelve GNUTLS_E_PRIVKEY_VERIFICATION_ERROR, y un código cero o positivo en caso de éxito.
