NOMBRE

gnutls_privkey_import_gost_raw - Función de API

SINOPSIS

#include <gnutls/abstract.h>

int gnutls_privkey_import_gost_raw(gnutls_privkey_t key, gnutls_ecc_curve_t curve, gnutls_digest_algorithm_t digest, gnutls_gost_paramset_t paramset, const gnutls_datum_t * x, const gnutls_datum_t * y, const gnutls_datum_t * k);

ARGUMENTOS

gnutls_privkey_t key
la clave
gnutls_ecc_curve_t curve
contiene la curva
gnutls_digest_algorithm_t digest
contiene el digest
gnutls_gost_paramset_t paramset
contiene el ID del conjunto de parámetros GOST
const gnutls_datum_t * x
contiene la coordenada x
const gnutls_datum_t * y
contiene la coordenada y
const gnutls_datum_t * k
contiene k (clave privada)

DESCRIPCIÓN

Esta función convertirá los parámetros de la clave privada GOST dada al formato nativo gnutls_privkey_t. La salida se almacenará en key. digest debe ser uno de GNUTLS_DIG_GOSR_94, GNUTLS_DIG_STREEBOG_256 o GNUTLS_DIG_STREEBOG_512. Si paramset se establece en GNUTLS_GOST_PARAMSET_UNKNOWN, se seleccionará uno por defecto dependiendo de
digest .

NOTA

Los parámetros deben almacenarse con el byte menos significativo primero. En la versión 3.6.3, el formato big-endian se usó incorrectamente.

DEVOLUCIONES

En caso de éxito, se devuelve GNUTLS_E_SUCCESS (0), de lo contrario, un valor de error negativo.
