NOMBRE

gnutls_idna_map - Función de la API

SINOPSIS

#include <gnutls/gnutls.h>

int gnutls_idna_map(const char * input, unsigned ilen, gnutls_datum_t * out, unsigned flags);

ARGUMENTOS

const char * input
contiene el nombre de dominio formateado en UTF-8
unsigned ilen
la longitud de la cadena proporcionada
gnutls_datum_t * out
el resultado en una cadena asignada y terminada en nulo
unsigned flags
debería ser cero

DESCRIPCIÓN

Esta función convertirá el nombre de dominio UTF-8 proporcionado a su mapeo IDNA en una variable asignada. Tenga en cuenta que, dependiendo de las banderas con las que se compiló la biblioteca gnutls utilizada, la salida de esta función puede variar (es decir, puede ser IDNA2008 o IDNA2003).

Para forzar IDNA2008, especifique la bandera GNUTLS_IDNA_FORCE_2008. En caso de que GnuTLS no esté compilado con las dependencias necesarias, se devolverá GNUTLS_E_UNIMPLEMENTED_FEATURE para indicar que gnutls no puede realizar la conversión solicitada.

Tenga en cuenta también que esta función devolverá una cadena vacía si se proporciona una cadena vacía como entrada.

VALOR DEVUELTO

GNUTLS_E_INVALID_UTF8_STRING en caso de datos UTF-8 inválidos, o 0 si tiene éxito.
