NOMBRE

gnutls_x509_rdn_get - función API

SINOPSIS

#include <gnutls/x509.h>

int gnutls_x509_rdn_get(const gnutls_datum_t * idn, char * buf, size_t * buf_size);

ARGUMENTOS

const gnutls_datum_t * idn
debe contener una secuencia RDN codificada en DER
char * buf
un puntero a una estructura para contener el nombre del par
size_t * buf_size
contiene el tamaño de buf

DESCRIPCIÓN

Esta función devolverá el nombre de la secuencia RDN dada. El nombre tendrá el formato "C=xxxx,O=yyyy,CN=zzzz" como se describe en RFC4514.

Esta función no genera una cadena completamente compatible con RFC4514; si eso es lo que necesitas, consulta gnutls_x509_rdn_get2().

RETORNA

En caso de éxito, se devuelve GNUTLS_E_SUCCESS (0), o se devuelve GNUTLS_E_SHORT_MEMORY_BUFFER y se actualiza * buf_size si el búfer proporcionado no es lo suficientemente largo, de lo contrario, un valor de error negativo.
