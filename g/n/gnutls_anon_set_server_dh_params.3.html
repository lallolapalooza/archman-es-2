NOMBRE

gnutls_anon_set_server_dh_params - Función de la API

SINOPSIS

#include <gnutls/gnutls.h>

void gnutls_anon_set_server_dh_params(gnutls_anon_server_credentials_t res, gnutls_dh_params_t dh_params);

ARGUMENTOS

gnutls_anon_server_credentials_t res
es un tipo gnutls_anon_server_credentials_t
gnutls_dh_params_t dh_params
Los parámetros Diffie-Hellman.

DESCRIPCIÓN

Esta función establecerá los parámetros Diffie-Hellman que utilizará un servidor anónimo. Estos parámetros se usarán en las suites de cifrado Diffie-Hellman anónimo.

OBSOLETO

Esta función es innecesaria y desaconsejada en GnuTLS 3.6.0 o posterior. Desde la versión 3.6.0, los parámetros DH se negocian siguiendo la RFC7919.
