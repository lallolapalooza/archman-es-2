gnutls_certificate_set_x509_key_mem(3)

gnutls_certificate_set_x509_key_mem(3) gnutls gnutls_certificate_set_x509_key_mem(3)

NOMBRE

gnutls_certificate_set_x509_key_mem - Función de la API

SINOPSIS

#include <gnutls/gnutls.h>

int gnutls_certificate_set_x509_key_mem(gnutls_certificate_credentials_t res, const gnutls_datum_t * cert, const gnutls_datum_t * key, gnutls_x509_crt_fmt_t type);

ARGUMENTOS

gnutls_certificate_credentials_t res
es un tipo gnutls_certificate_credentials_t.
const gnutls_datum_t * cert
contiene una lista de certificados (ruta) para la clave privada especificada
const gnutls_datum_t * key
es la clave privada, o NULL
gnutls_x509_crt_fmt_t type
es PEM o DER

DESCRIPCIÓN

Esta función establece un par certificado/clave privada en el tipo gnutls_certificate_credentials_t. Esta función puede ser llamada más de una vez, en caso de que existan múltiples claves/certificados para el servidor.

Tenga en cuenta que se admite la extensión de clave de uso (2.5.29.15) PKIX en los certificados X.509. Esto significa que los certificados destinados a la firma no se pueden utilizar para cifrados que requieran cifrado.

Si el certificado y la clave privada se proporcionan en codificación PEM, entonces las cadenas que contienen sus valores deben terminar en nulo.

La key puede ser NULL si está utilizando una función de retorno de llamada de firma, consulte gnutls_sign_callback_set().

Tenga en cuenta que, por defecto, esta función devuelve cero en caso de éxito y un valor negativo en caso de error. Desde la versión 3.5.6, cuando la bandera GNUTLS_CERTIFICATE_API_V2 se establece usando gnutls_certificate_set_flags(), devuelve un índice (mayor o igual a cero). Ese índice se puede usar en otras funciones para referirse al par clave-par agregado.

DEVUELVE

En caso de éxito, esta función devuelve cero, y en caso contrario, un valor negativo en caso de error (consulte lo anterior para modificar ese comportamiento).
