NOMBRE

gnutls_pkcs12_import - Función de la API

SINOPSIS

#include <gnutls/pkcs12.h>

int gnutls_pkcs12_import(gnutls_pkcs12_t pkcs12, const gnutls_datum_t * data, gnutls_x509_crt_fmt_t format, unsigned int flags);

ARGUMENTOS

gnutls_pkcs12_t pkcs12
Los datos para almacenar el PKCS12 analizado.
const gnutls_datum_t * data
El PKCS12 codificado en DER o PEM.
gnutls_x509_crt_fmt_t format
Uno de DER o PEM
unsigned int flags
Una secuencia OR de flags de gnutls_privkey_pkcs8.

DESCRIPCIÓN

Esta función convertirá el PKCS12 codificado en DER o PEM proporcionado al formato nativo gnutls_pkcs12_t. La salida se almacenará en 'pkcs12'.

Si el PKCS12 está codificado en PEM, debe tener una cabecera de "PKCS12".

DEVOLUCIONES

En caso de éxito, se devuelve GNUTLS_E_SUCCESS (0), de lo contrario, un valor de error negativo.
