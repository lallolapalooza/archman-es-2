gnutls_record_send(3) gnutls gnutls_record_send(3)

NOMBRE

gnutls_record_send - Función de la API

SINOPSIS

#include <gnutls/gnutls.h>

ssize_t gnutls_record_send(gnutls_session_t session, const void * data, size_t data_size);

ARGUMENTOS

gnutls_session_t session
es un tipo gnutls_session_t.
const void * data
contiene los datos a enviar
size_t data_size
es la longitud de los datos

DESCRIPCIÓN

Esta función tiene semánticas similares a send(). La única diferencia es que acepta una sesión GnuTLS y usa códigos de error diferentes. Tenga en cuenta que si el búfer de envío está lleno, send() bloqueará esta función. Consulte la documentación de send() para obtener más información.

Puede reemplazar la función push predeterminada, que es send(), utilizando gnutls_transport_set_push_function().

Si la función push interna devuelve EINTR, se devolverá GNUTLS_E_INTERRUPTED. Si se devuelve GNUTLS_E_INTERRUPTED o GNUTLS_E_AGAIN, debe volver a llamar a esta función con los mismos parámetros exactos, o proporcionar un puntero NULL para data y 0 para data_size, para escribir los mismos datos que antes. Si desea descartar los datos anteriores en lugar de reintentar, debe llamar a gnutls_record_discard_queued() antes de llamar a esta función con parámetros diferentes. Tenga en cuenta que esto último solo funciona en transportes especiales (por ejemplo, UDP). Consulte gnutls_record_get_direction().

Tenga en cuenta que en DTLS, esta función devolverá el código de error GNUTLS_E_LARGE_PACKET si los datos enviados exceden el valor MTU de datos, tal como lo devuelve gnutls_dtls_get_data_mtu(). El valor errno EMSGSIZE también se mapea a GNUTLS_E_LARGE_PACKET. Tenga en cuenta que desde la versión 3.2.13, esta función se puede llamar bajo "cork" en modo DTLS y se negará a enviar datos que superen el tamaño MTU, devolviendo GNUTLS_E_LARGE_PACKET.

DEVOLUCIONES

El número de bytes enviados, o un código de error negativo. El número de bytes enviados puede ser menor que data_size. El número máximo de bytes que esta función puede enviar en una sola llamada depende del tamaño máximo de registro negociado.
