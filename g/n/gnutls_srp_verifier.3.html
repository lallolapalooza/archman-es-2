NOMBRE

gnutls_srp_verifier - Función de la API

SINOPSIS

#include <gnutls/gnutls.h>

int gnutls_srp_verifier(const char * username, const char * password, const gnutls_datum_t * salt, const gnutls_datum_t * generator, const gnutls_datum_t * prime, gnutls_datum_t * res);

ARGUMENTOS

const char * username
es el nombre del usuario
const char * password
es la contraseña del usuario
const gnutls_datum_t * salt
deberían ser algunos bytes generados aleatoriamente
const gnutls_datum_t * generator
es el generador del grupo
const gnutls_datum_t * prime
es el primo del grupo
gnutls_datum_t * res
donde se almacenará el verificador.

DESCRIPCIÓN

Esta función creará un verificador SRP, según lo especificado en RFC2945. El prime y el generator deberían ser uno de los parámetros estáticos definidos en gnutls/gnutls.h o pueden ser generados.

El verificador se asignará con @gnutls_malloc() y se almacenará en
res utilizando formato binario.

RETORNA

En caso de éxito, se devuelve GNUTLS_E_SUCCESS (0), o un código de error.
