gnustep-config(1) Manual del Sistema GNUstep gnustep-config(1)

NOMBRE

gnustep-config - imprime información sobre la instalación actual de gnustep.

SINOPSIS

gnustep-config [ --variable=variable |--objc-flags|--objc-libs|--base-libs|--gui-libs ]

DESCRIPCIÓN

gnustep-config puede imprimir información sobre el sistema GNUstep instalado actualmente. La salida se genera dinámicamente basándose en variables de entorno como GNUSTEP_CONFIG_FILE y GNUSTEP_MAKEFILES, aunque los valores predeterminados para estas se generan cuando la herramienta se configura/instala. La salida son principalmente las ubicaciones donde se instalan varios recursos de GNUstep, pero también proporciona las banderas utilizadas para construir diferentes tipos de proyectos GNUstep.

OPCIONES

--variable=variable
imprime el valor de la variable especificada. Las variables posibles son:

GNUSTEP_MAKEFILES

GNUSTEP_USER_DIR

GNUSTEP_USER_DEFAULTS_DIR

GNUSTEP_HOST

GNUSTEP_HOST_CPU

GNUSTEP_HOST_VENDOR

GNUSTEP_HOST_OS

GNUSTEP_IS_FLATTENED

GNUSTEP_xxx_APPS

GNUSTEP_xxx_TOOLS

GNUSTEP_xxx_LIBRARY

GNUSTEP_xxx_HEADERS

GNUSTEP_xxx_LIBRARIES

GNUSTEP_xxx_DOC

GNUSTEP_xxx_DOC_MAN

GNUSTEP_xxx_DOC_INFO

donde 'xxx' podría ser cualquiera de 'SYSTEM', 'NETWORK', 'LOCAL' y 'USER'.
--objc-flags
imprime todas las banderas necesarias para compilar un archivo ObjC
--objc-libs

imprime todas las banderas necesarias para enlazar un programa ObjC puro (sin Foundation/GUI)
--base-libs
imprime todas las banderas necesarias para enlazar un programa ObjC de línea de comandos (sin GUI)
--gui-libs
imprime todas las banderas necesarias para enlazar un programa ObjC GUI

ERRORES

Ninguno conocido
