gnutls_session_supplemental_register(3)

gnutls_session_supplemental_register(3) gnutls gnutls_session_supplemental_register(3)

NOMBRE

gnutls_session_supplemental_register - función de la API

SINOPSIS

#include <gnutls/gnutls.h>

int gnutls_session_supplemental_register(gnutls_session_t session, const char * name, gnutls_supplemental_data_format_type_t type, gnutls_supp_recv_func recv_func, gnutls_supp_send_func send_func, unsigned flags);

ARGUMENTOS

gnutls_session_t session
la sesión para la que se registrará esto
const char * name
el nombre de los datos suplementarios a registrar
gnutls_supplemental_data_format_type_t type
el tipo de formato de datos suplementarios
gnutls_supp_recv_func recv_func
la función para recibir los datos
gnutls_supp_send_func send_func
la función para enviar los datos
unsigned flags
debe ser cero

DESCRIPCIÓN

Esta función registrará un nuevo tipo de datos suplementarios (rfc4680). Las funciones suplementarias registradas se utilizarán para esa sesión específica. El type proporcionado debe ser un tipo no asignado en gnutls_supplemental_data_format_type_t.

Si el tipo ya está registrado o es manejado internamente por GnuTLS, se devolverá GNUTLS_E_ALREADY_REGISTERED.

Dado que los datos suplementarios no están definidos en TLS 1.3, esta función deshabilitará el soporte de TLS 1.3 para la sesión dada.

RETORNOS

GNUTLS_E_SUCCESS si tiene éxito, de lo contrario, un código de error negativo.
