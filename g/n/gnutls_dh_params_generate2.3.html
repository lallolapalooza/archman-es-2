NOMBRE

gnutls_dh_params_generate2 - Función de la API

SINOPSIS

#include <gnutls/gnutls.h>

int gnutls_dh_params_generate2(gnutls_dh_params_t dparams, unsigned int bits);

ARGUMENTOS

gnutls_dh_params_t dparams
Los parámetros
unsigned int bits
es el número de bits del primo

DESCRIPCIÓN

Esta función generará un nuevo par de primo y generador para ser utilizado en el intercambio de claves Diffie-Hellman. Esto puede llevar mucho tiempo.

Se recomienda no establecer el número de bits directamente, sino utilizar gnutls_sec_param_to_pk_bits() en su lugar. Tenga en cuenta también que los parámetros DH solo son útiles para los servidores. Dado que los clientes utilizan los parámetros enviados por el servidor, no tiene sentido llamar a esto en el lado del cliente.

Los parámetros generados son de forma DSA. También es posible generar parámetros comprobables (siguiendo el algoritmo de Shawe-Taylor), utilizando gnutls_x509_privkey_generate2() con la opción DSA y el flag GNUTLS_PRIVKEY_FLAG_PROVABLE establecido. Estos pueden ser importados con gnutls_dh_params_import_dsa().

Ya no se recomienda que las aplicaciones generen parámetros. Ver la sección "Generación de parámetros" en el manual.

RETORNOS

En caso de éxito, se devuelve GNUTLS_E_SUCCESS (0), de lo contrario se devuelve un código de error negativo.
