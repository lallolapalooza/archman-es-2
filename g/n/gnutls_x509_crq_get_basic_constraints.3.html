gnutls_x509_crq_get_basic_constraints(3)

Paquete: gnutls

Licencias: GPL-3.0-or-later AND LGPL-2.1-or-later

gnutls_x509_crq_get_basic_constraints(3) gnutls gnutls_x509_crq_get_basic_constraints(3)

NOMBRE

gnutls_x509_crq_get_basic_constraints - función de la API

SINOPSIS

#include <gnutls/x509.h>

int gnutls_x509_crq_get_basic_constraints(gnutls_x509_crq_t crq, unsigned int * critical, unsigned int * ca, int * pathlen);

ARGUMENTOS

gnutls_x509_crq_t crq
debe contener un tipo gnutls_x509_crq_t
unsigned int * critical
será distinto de cero si la extensión está marcada como crítica
unsigned int * ca
puntero a un entero de salida que indica el estado de CA, puede ser NULL, el valor es 1 si se establece la bandera CA del certificado, 0 en caso contrario.
int * pathlen
puntero a un entero de salida que indica la longitud de la ruta (puede ser NULL), los códigos de error no negativos indican un campo pathLenConstraint presente y el valor real, -1 indica que el campo está ausente.

DESCRIPCIÓN

Esta función leerá las restricciones básicas del certificado y devolverá el estado de CA del certificado. Lee la extensión X.509 basicConstraints (2.5.29.19).

DEVUELVE

Si el certificado es una CA, se devolverá un valor positivo, o (0) si el certificado no tiene la bandera CA establecida. Se puede devolver un código de error negativo en caso de errores. Si el certificado no contiene la extensión basicConstraints, se devolverá GNUTLS_E_REQUESTED_DATA_NOT_AVAILABLE.
