NOMBRE

gnutls_init - Función API

SINOPSIS

#include <gnutls/gnutls.h>

int gnutls_init(gnutls_session_t * session, unsigned int flags);

ARGUMENTOS

gnutls_session_t * session
es un puntero a un tipo gnutls_session_t.
unsigned int flags
indica si esta sesión se utilizará para el servidor o el cliente.

DESCRIPCIÓN

Esta función inicializa la sesión proporcionada. Cada sesión debe ser inicializada antes de su uso, y después de una inicialización y uso exitosos debe ser desinicializada llamando a gnutls_deinit().


flags puede ser cualquier combinación de indicadores de gnutls_init_flags_t.

Tenga en cuenta que desde la versión 3.1.2 esta función habilita algunas extensiones TLS comunes como tickets de sesión y solicitud de estado del certificado OCSP en el lado del cliente por defecto. Para evitarlo, use el indicador GNUTLS_NO_DEFAULT_EXTENSIONS.

Tenga en cuenta que nunca es obligatorio usar gnutls_deinit() después de que esta función falle. Desde gnutls 3.8.0, es seguro usar incondicionalmente gnutls_deinit() incluso después de un fallo, independientemente de si la memoria fue inicializada antes de gnutls_init(); sin embargo, los clientes que deseen ser portables a versiones anteriores de la biblioteca deben omitir la desinicialización en caso de fallo, o pre-inicializar la memoria pasada a gnutls_init() a todos ceros mediante memset() o similar.

DEVUELVE

GNUTLS_E_SUCCESS en caso de éxito, o un código de error.
