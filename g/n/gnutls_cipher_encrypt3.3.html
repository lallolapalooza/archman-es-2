NOMBRE

gnutls_cipher_encrypt3 - Función API

SINOPSIS

#include <gnutls/crypto.h>

int gnutls_cipher_encrypt3(gnutls_cipher_hd_t handle, const void * ptext, size_t ptext_len, void * ctext, size_t * ctext_len, unsigned flags);

ARGUMENTOS

gnutls_cipher_hd_t handle
es un tipo gnutls_cipher_hd_t
const void * ptext
los datos a cifrar
size_t ptext_len
la longitud de los datos a cifrar
void * ctext
los datos cifrados
size_t * ctext_len
la longitud de los datos cifrados (inicialmente debe contener el tamaño máximo disponible)
unsigned flags
banderas para el relleno

DESCRIPCIÓN

Esta función cifrará los datos proporcionados utilizando el algoritmo especificado por el contexto. Para cifradores de bloque, ptext_len típicamente es un múltiplo del tamaño del bloque. Si no lo es, el llamante puede indicar a la función que rellene el último bloque según flags. Actualmente, el único esquema de relleno disponible es GNUTLS_CIPHER_PADDING_PKCS7.

Si ctext no es NULL, debe tener suficiente espacio para almacenar el texto cifrado resultante. Para verificar el tamaño requerido, esta función puede ser llamada con ctext establecido a NULL. En ese caso, ctext_len se actualizará sin realizar el cifrado real.

DEVUELVE

Cero o un código de error negativo en caso de error.
