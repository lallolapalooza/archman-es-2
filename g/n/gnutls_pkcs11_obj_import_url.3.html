NOMBRE

gnutls_pkcs11_obj_import_url - Función de la API

SINOPSIS

#include <gnutls/pkcs11.h>

int gnutls_pkcs11_obj_import_url(gnutls_pkcs11_obj_t obj, const char * url, unsigned int flags);

ARGUMENTOS

gnutls_pkcs11_obj_t obj
La estructura para almacenar el objeto
const char * url
una URL PKCS 11 que identifica la clave
unsigned int flags
O secuencia de flags GNUTLS_PKCS11_OBJ_*

DESCRIPCIÓN

Esta función "importará" una URL PKCS 11 que identifica un objeto (por ejemplo, un certificado) al tipo gnutls_pkcs11_obj_t. Esto no implica ningún análisis (como X.509 u OpenPGP), ya que gnutls_pkcs11_obj_t es agnóstico al formato. Solo se transfieren datos.

Si se especifica el flag GNUTLS_PKCS11_OBJ_FLAG_OVERWRITE_TRUSTMOD_EXT, cualquier certificado leído tendrá sus extensiones sobrescritas por cualquier extensión adjunta en el módulo de confianza.

RETORNA

En caso de éxito, se devuelve GNUTLS_E_SUCCESS (0), de lo contrario, un valor de error negativo.
