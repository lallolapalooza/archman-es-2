gnutls_certificate_set_key(3) gnutls gnutls_certificate_set_key(3)

NOMBRE

gnutls_certificate_set_key - Función de la API

SINOPSIS

#include <gnutls/abstract.h>

int gnutls_certificate_set_key(gnutls_certificate_credentials_t res, const char ** names, int names_size, gnutls_pcert_st * pcert_list, int pcert_list_size, gnutls_privkey_t key);

ARGUMENTOS

gnutls_certificate_credentials_t res
es un tipo gnutls_certificate_credentials_t.
const char ** names
es un array de nombres DNS que pertenecen a la clave pública (NULL si no hay ninguno)
int names_size
contiene el tamaño de la lista de nombres
gnutls_pcert_st * pcert_list
contiene una lista de certificados (cadena) o clave pública en bruto
int pcert_list_size
contiene el tamaño de la lista de certificados
gnutls_privkey_t key
es una clave gnutls_privkey_t que corresponde a la primera clave pública en pcert_list

DESCRIPCIÓN

Esta función establece un par de claves pública/privada en el tipo gnutls_certificate_credentials_t. La clave pública dada puede estar encapsulada en un certificado o puede proporcionarse como una clave en bruto. Esta función puede llamarse más de una vez, en caso de que existan varios pares de claves para el servidor. Para clientes que deseen enviar más que su propio certificado de entidad final (por ejemplo, también un certificado de CA intermedio), la cadena completa de certificados debe proporcionarse en pcert_list.

Tenga en cuenta que la key pasará a formar parte de la estructura de credenciales y no debe liberarse. Se liberará automáticamente cuando la estructura res se desinitialice.

Si esta función falla, la estructura res se encuentra en un estado indefinido y no debe reutilizarse para cargar otras claves o certificados.

Tenga en cuenta que, por defecto, esta función devuelve cero en caso de éxito y un valor negativo en caso de error. Desde la versión 3.5.6, cuando el indicador GNUTLS_CERTIFICATE_API_V2 se establece usando gnutls_certificate_set_flags(), devuelve un índice (mayor o igual a cero). Ese índice puede ser utilizado por otras funciones para referirse al par clave-valor añadido.

Desde GnuTLS 3.6.6, esta función también maneja claves públicas en bruto.

RETORNA

En caso de éxito, esta función devuelve cero y, de lo contrario, un valor negativo en caso de error (consulte arriba para modificar ese comportamiento).
