NOMBRE

gnutls_ocsp_status_request_is_checked - Función de la API

SINOPSIS

#include <gnutls/gnutls.h>

unsigned gnutls_ocsp_status_request_is_checked(gnutls_session_t session, unsigned int flags);

ARGUMENTOS

gnutls_session_t session
es una sesión de gnutls
unsigned int flags
debe ser cero o GNUTLS_OCSP_SR_IS_AVAIL

DESCRIPCIÓN

Cuando los flags son cero, esta función devuelve un valor distinto de cero si se incluyó una respuesta de estado OCSP válida en el handshake TLS. Es decir, una respuesta de estado OCSP que no es demasiado antigua, está suplantada o marca el certificado como revocado. Devuelve cero en caso contrario.

Cuando se especifica el flag GNUTLS_OCSP_SR_IS_AVAIL, la función devuelve un valor distinto de cero si se incluyó una respuesta de estado OCSP en el handshake, incluso si era inválida. En caso contrario, si no se incluyó ninguna respuesta de estado OCSP, devuelve cero. El flag GNUTLS_OCSP_SR_IS_AVAIL se introdujo en GnuTLS 3.4.0.

Esta es una función auxiliar cuando se necesita decidir si se realiza una comprobación explícita de validez OCSP del certificado del oponente. Debe llamarse después de que se hayan llamado las funciones gnutls_certificate_verify_peers*().

Esta función siempre es utilizable en el lado del cliente, pero en el lado del servidor solo bajo TLS 1.3, que es la primera versión de TLS que permite a los clientes enviar respuestas OCSP.

RETORNA

Distinto de cero si la respuesta fue válida, o cero si no se envió, o se envió y fue inválida.
