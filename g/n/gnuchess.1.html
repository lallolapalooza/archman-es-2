CHESS(1) Comandos de Usuario CHESS(1)

NOMBRE

Chess - GNU Chess

SINOPSIS

gnuchess [OPCIÓN]...

DESCRIPCIÓN

GNU Chess

Juega al ajedrez.

OPCIONES

-h, --help
muestra esta ayuda y sale
-v, --version
muestra información de la versión y sale
-q, --quiet
silencia el programa al iniciarse
--silent
igual que -q
-x, --xboard
inicia en modo motor
-p, --post
inicia mostrando el pensamiento
-e, --easy
deshabilita el pensamiento durante el tiempo del oponente
-m, --manual
habilita el modo manual
-u, --uci
habilita el protocolo UCI (es decir: se comporta como un motor UCI); incompatible con otras opciones
-M TAMAÑO, --memory=TAMAÑO
especifica el uso de memoria en MB para la tabla hash
-a NOMBRE_ARCHIVO, --addbook=NOMBRE_ARCHIVO
compila book.bin desde el libro PGN NOMBRE_ARCHIVO
-g, --graphic
habilita el modo gráfico

Se aceptan las opciones xboard y post sin guiones iniciales por compatibilidad hacia atrás.

Los movimientos se aceptan en notación algebraica estándar (SAN) o en notación algebraica de coordenadas.

El archivo 'gnuchess.ini' permite establecer opciones de configuración, pero se ignora si se usa la opción --uci. Consulte 'info gnuchess' para obtener detalles sobre las opciones. El programa buscará 'gnuchess.ini' en $XDG_CONFIG_HOME/gnuchess/ y $HOME/.config/gnuchess/ en ese orden, y utilizará el primero que encuentre, si lo hay.
