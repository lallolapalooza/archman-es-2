NOMBRE

gnutls_cipher_get_name - Función de la API

SINOPSIS

#include <gnutls/gnutls.h>

const char * gnutls_cipher_get_name(gnutls_cipher_algorithm_t algorithm);

ARGUMENTOS

gnutls_cipher_algorithm_t algorithm
es un algoritmo de cifrado

DESCRIPCIÓN

Convierte un tipo gnutls_cipher_algorithm_t a una cadena.

DEVOLUCIONES

un puntero a una cadena que contiene el nombre del cifrado especificado, o NULL.
