gnutls_x509_crt_set_issuer_alt_othername(3)

gnutls_x509_crt_set_issuer_alt_othername(3) gnutls gnutls_x509_crt_set_issuer_alt_othername(3)

NOMBRE

gnutls_x509_crt_set_issuer_alt_othername - función de la API

SINOPSIS

#include <gnutls/x509.h>

int gnutls_x509_crt_set_issuer_alt_othername(gnutls_x509_crt_t crt, const char * oid, const void * data, unsigned int data_size, unsigned int flags);

ARGUMENTOS

gnutls_x509_crt_t crt
un certificado de tipo gnutls_x509_crt_t
const char * oid
El OID del otro nombre
const void * data
Los datos a establecer
unsigned int data_size
El tamaño de los datos a establecer
unsigned int flags
GNUTLS_FSAN_SET para borrar datos previos o GNUTLS_FSAN_APPEND para añadir.

DESCRIPCIÓN

Esta función establecerá un "othername" en la extensión del certificado del nombre alternativo del emisor.

Los valores establecidos se guardan como valores binarios y se espera que tengan la codificación DER correcta. Para mayor comodidad, se pueden usar las banderas GNUTLS_FSAN_ENCODE_OCTET_STRING y GNUTLS_FSAN_ENCODE_UTF8_STRING para codificar los datos proporcionados.

RETORNA

En caso de éxito, se devuelve GNUTLS_E_SUCCESS (0), de lo contrario, un valor de error negativo.
