NOMBRE

gnutls_srp_set_client_credentials - función de API

SINOSIS

#include <gnutls/gnutls.h>

int gnutls_srp_set_client_credentials(gnutls_srp_client_credentials_t res, const char * username, const char * password);

ARGUMENTOS

gnutls_srp_client_credentials_t res
es un tipo gnutls_srp_client_credentials_t.
const char * username
es el nombre de usuario
const char * password
es la contraseña del usuario

DESCRIPCIÓN

Esta función establece el nombre de usuario y la contraseña, en un tipo gnutls_srp_client_credentials_t. Estos se utilizarán en la autenticación SRP. username debe ser una cadena ASCII o UTF-8. En caso de una cadena UTF-8, se recomienda que siga el marco PRECIS para nombres de usuario (rfc8265). La contraseña puede estar en formato ASCII o normalizada usando gnutls_utf8_password_normalize().

VALORES DEVUELTOS

En caso de éxito, se devuelve GNUTLS_E_SUCCESS (0), o un código de error.
