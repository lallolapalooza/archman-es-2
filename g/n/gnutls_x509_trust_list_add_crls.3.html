NOMBRE

gnutls_x509_trust_list_add_crls - función de API

SINOPSIS

#include <gnutls/x509.h>

int gnutls_x509_trust_list_add_crls(gnutls_x509_trust_list_t list, const gnutls_x509_crl_t * crl_list, unsigned crl_size, unsigned int flags, unsigned int verification_flags);

ARGUMENTOS

gnutls_x509_trust_list_t list
La lista
const gnutls_x509_crl_t * crl_list
Una lista de CRLs
unsigned crl_size
La longitud de la lista de CRLs
unsigned int flags
banderas de gnutls_trust_list_flags_t
unsigned int verification_flags
gnutls_certificate_verify_flags si flags especifica GNUTLS_TL_VERIFY_CRL

DESCRIPCIÓN

Esta función agregará las listas de revocación de certificados proporcionadas a la lista de confianza. Las CRLs en crl_list no deben ser desinicializadas durante la vida útil de list.

Esta función debe llamarse después de gnutls_x509_trust_list_add_cas() para permitir la verificación de la validez de las CRLs. Si se proporciona la bandera GNUTLS_TL_NO_DUPLICATES, entonces la lista final de CRLs no contendrá entradas duplicadas.

Si se proporciona la bandera GNUTLS_TL_NO_DUPLICATES, se debe llamar a gnutls_x509_trust_list_deinit() con el parámetro all establecido en 1.

Si se proporciona la bandera GNUTLS_TL_VERIFY_CRL, las CRLs serán verificadas antes de ser añadidas, y si la verificación falla, serán omitidas.

RETORNA

Se devuelve el número de elementos añadidos; esto incluye entradas duplicadas.
