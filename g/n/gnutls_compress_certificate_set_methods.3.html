NOMBRE

gnutls_compress_certificate_set_methods - Función de la API

SINOPSIS

#include <gnutls/gnutls.h>

int gnutls_compress_certificate_set_methods(gnutls_session_t session, const gnutls_compression_method_t * methods, size_t methods_len);

ARGUMENTOS

gnutls_session_t session
es un tipo gnutls_session_t.
const gnutls_compression_method_t * methods
es una lista de métodos de compresión soportados.
size_t methods_len
número de métodos de compresión en methods

DESCRIPCIÓN

Esta función establece los métodos de compresión soportados para la compresión de certificados para la sesión dada. La lista de métodos de compresión soportados se utilizará para a) solicitar la compresión del certificado del par y b) seleccionar el método para comprimir el certificado local antes de enviarlo al par. El orden de los métodos de compresión dentro de la lista importa, ya que el método que aparece antes en la lista tendrá preferencia sobre los posteriores. Tenga en cuenta que incluso si establece la lista de métodos de compresión soportados, la compresión podría no utilizarse si el par no soporta ninguno de los métodos de compresión elegidos.

La lista de métodos de compresión soportados debe cumplir los siguientes criterios: El argumento methods debe ser un array de métodos de compresión válidos del tipo gnutls_compression_method_t. El argumento methods_len debe contener el número de métodos de compresión almacenados en el array methods y debe estar dentro del rango <1, 127>. Las restricciones de longitud se definen por las macros MIN_COMPRESS_CERTIFICATE_METHODS y MAX_COMPRESS_CERTIFICATE_METHODS ubicadas en el archivo de cabecera compress_certificate.h.

Si methods o methods_len es igual a 0, la lista actual de métodos de compresión soportados se deshará.

RETORNA

GNUTLS_E_SUCCESS si tiene éxito, de lo contrario un código de error negativo.
