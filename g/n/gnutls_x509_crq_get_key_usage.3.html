gnutls_x509_crq_get_key_usage(3)

gnutls_x509_crq_get_key_usage(3) gnutls gnutls_x509_crq_get_key_usage(3)

NOMBRE

gnutls_x509_crq_get_key_usage - función de la API

SINOPSIS

#include <gnutls/x509.h>

int gnutls_x509_crq_get_key_usage(gnutls_x509_crq_t crq, unsigned int * key_usage, unsigned int * critical);

ARGUMENTOS

gnutls_x509_crq_t crq
debería contener un tipo gnutls_x509_crq_t
unsigned int * key_usage
donde se almacenarán los bits de uso de clave
unsigned int * critical
será distinto de cero si la extensión está marcada como crítica

DESCRIPCIÓN

Esta función devolverá el uso de clave del certificado, leyendo la extensión X.509 keyUsage (2.5.29.15). El valor de uso de clave OReará los valores de: GNUTLS_KEY_DIGITAL_SIGNATURE, GNUTLS_KEY_NON_REPUDIATION, GNUTLS_KEY_KEY_ENCIPHERMENT, GNUTLS_KEY_DATA_ENCIPHERMENT, GNUTLS_KEY_KEY_AGREEMENT, GNUTLS_KEY_KEY_CERT_SIGN, GNUTLS_KEY_CRL_SIGN, GNUTLS_KEY_ENCIPHER_ONLY, GNUTLS_KEY_DECIPHER_ONLY.

RETORNA

el uso de clave del certificado, o un código de error negativo en caso de error de análisis. Si el certificado no contiene la extensión keyUsage, se devolverá GNUTLS_E_REQUESTED_DATA_NOT_AVAILABLE.
