NOMBRE

gnutls_ocsp_resp_get_nonce - función de API

SINOPSIS

#include <gnutls/ocsp.h>

int gnutls_ocsp_resp_get_nonce(gnutls_ocsp_resp_const_t resp, unsigned int * critical, gnutls_datum_t * nonce);

ARGUMENTOS

gnutls_ocsp_resp_const_t resp
debería contener un tipo gnutls_ocsp_resp_t
unsigned int * critical
si la extensión nonce está marcada como crítica
gnutls_datum_t * nonce
contendrá un nuevo búfer asignado con datos nonce

DESCRIPCIÓN

Esta función devolverá los datos de la extensión nonce de la Respuesta OCSP Básica.

El llamador necesita liberar la memoria llamando a gnutls_free() en
nonce ->data.

RETORNA

En caso de éxito, se devuelve GNUTLS_E_SUCCESS (0), de lo contrario se devuelve un código de error negativo.
