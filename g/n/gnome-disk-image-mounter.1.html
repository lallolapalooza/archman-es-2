NOMBRE

gnome-disk-image-mounter - Adjuntar y montar imágenes de disco

SINOPSIS

gnome-disk-image-mounter [--writable] [URI...]

DESCRIPCIÓN

gnome-disk-image-mounter puede ser utilizado para configurar imágenes de disco. Se pueden usar tanto archivos regulares como URIs de GVfs (como smb://filer/media/file.iso) en el parámetro URI. Si no se proporcionan URIs y está en ejecución un servidor gráfico, se presentará un selector de archivos gráfico.

Tenga en cuenta que gnome-disk-image-mounter no montará sistemas de archivos ni desbloqueará volúmenes cifrados en la imagen de disco; esta responsabilidad se deja al automontador en GNOME Shell para asegurar que ocurran las mismas interacciones que si la imagen de disco fuera un dispositivo físico o disco regular.

Por defecto, las imágenes de disco se adjuntan en modo de solo lectura; use la opción --writable para cambiar esto.

VALOR DE RETORNO

gnome-disk-image-mounter devuelve 0 si tiene éxito y un valor distinto de cero si falla.

AUTOR

ERRORES
