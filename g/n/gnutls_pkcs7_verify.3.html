gnutls_pkcs7_verify(3) gnutls gnutls_pkcs7_verify(3)

NOMBRE

gnutls_pkcs7_verify - función de la API

SINOPSIS

#include <gnutls/pkcs7.h>

int gnutls_pkcs7_verify(gnutls_pkcs7_t pkcs7, gnutls_x509_trust_list_t tl, gnutls_typed_vdata_st * vdata, unsigned int vdata_size, unsigned idx, const gnutls_datum_t * data, unsigned flags);

ARGUMENTOS

gnutls_pkcs7_t pkcs7
debería contener un tipo gnutls_pkcs7_t
gnutls_x509_trust_list_t tl
Una lista de certificados de confianza
gnutls_typed_vdata_st * vdata
un array de datos tipados
unsigned int vdata_size
el número de elementos de datos
unsigned idx
el índice de la información de la firma a verificar
const gnutls_datum_t * data
Los datos a verificar o NULL
unsigned flags
Cero o una lista OR de gnutls_certificate_verify_flags

DESCRIPCIÓN

Esta función verificará los datos proporcionados contra la firma presente en los Datos Firmados (SignedData) de la estructura PKCS 7. Si los datos proporcionados son NULL, se utilizarán los datos del campo encapsulatedContent en su lugar.

DEVUELVE

En caso de éxito, se devuelve GNUTLS_E_SUCCESS (0), de lo contrario un valor de error negativo. Un error de verificación resulta en GNUTLS_E_PK_SIG_VERIFY_FAILED y la falta de datos encapsulados para verificar resulta en GNUTLS_E_REQUESTED_DATA_NOT_AVAILABLE.
