-------------------
Cliente de servicio GNOME
-------------------

SINOPSIS

gnome-service-client [opción ...] -- COMANDO

DESCRIPCIÓN

gnome-service-client proporciona una forma de iniciar un cliente Wayland y, opcionalmente, establecer una etiqueta de ventana predeterminada para todas sus ventanas.

Requiere un compositor que soporte la API de D-Bus org.gnome.Mutter.ServiceChannel, como GNOME Shell o GNOME Kiosk.

OPCIONES

--help, -h

Muestra un mensaje de ayuda y sale.

--tag, -t

Opcionalmente especifica la etiqueta que se establecerá para todas las ventanas del cliente.

EJEMPLOS

Inicia el cliente "gnome-calculator" sin ninguna etiqueta

gnome-service-client -- gnome-calculator

Inicia el cliente "gnome-tour" con la etiqueta "demo"

gnome-service-client -t demo -- gnome-tour

ERRORES

El rastreador de errores se puede encontrar visitando el sitio web https://gitlab.gnome.org/GNOME/mutter/-/issues. Antes de enviar un informe de error, verifique que tiene la última versión de gnome-shell. Muchos errores (mayores y menores) se corrigen en cada versión, y si la suya está desactualizada, el problema puede que ya se haya resuelto.
