NOMBRE

gnutls_x509_crl_get_extension_oid - función de la API

SINOPSIS

#include <gnutls/x509.h>

int gnutls_x509_crl_get_extension_oid(gnutls_x509_crl_t crl, unsigned indx, void * oid, size_t * sizeof_oid);

ARGUMENTOS

gnutls_x509_crl_t crl
debería contener un tipo gnutls_x509_crl_t
unsigned indx
Especifica qué OID de extensión se va a enviar, use (0) para obtener la primera.
void * oid
un puntero para almacenar el OID (puede ser nulo)
size_t * sizeof_oid
inicialmente contiene el tamaño de oid

DESCRIPCIÓN

Esta función devolverá el OID de extensión solicitado en la CRL. El OID de extensión se almacenará como una cadena en el buffer proporcionado.

VALORES DEVUELTOS

En caso de éxito, se devuelve GNUTLS_E_SUCCESS (0), de lo contrario, un código de error negativo en caso de error. Si ha llegado a la última extensión disponible, se devolverá GNUTLS_E_REQUESTED_DATA_NOT_AVAILABLE.
