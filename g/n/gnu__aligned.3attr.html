gnu::aligned(3attr) gnu::aligned(3attr)

NOMBRE

gnu::aligned - establece la alineación de un objeto

SINOPSIS

[[gnu::aligned(alineación)]]
[[gnu::aligned]]

DESCRIPCIÓN

Este atributo se puede aplicar a un tipo o una variable, y establece su alineación en bytes.

Si no se especifica la alineación, se utiliza la alineación máxima. Esto es equivalente a


[[gnu::aligned(alignof(max_align_t))]]

VERSIÓNES

__attribute__((aligned(alineación)))
__declspec(align(alineación))

C11 proporciona el especificador de tipo _Alignas(), que tiene semántica similar.

ESTÁNDARES

GNU.

HISTORIA

gcc, g++, clang 11, clang++ 2.8.0.

ADVERTENCIAS

Este atributo puede aumentar la alineación natural de un tipo, pero no puede disminuirla.

El enlazador puede limitar la alineación máxima que se puede aplicar.
