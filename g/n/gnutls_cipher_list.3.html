NOMBRE

gnutls_cipher_list - Función de la API

SINOPSIS

#include <gnutls/gnutls.h>

const gnutls_cipher_algorithm_t * gnutls_cipher_list( void);

ARGUMENTOS

void

DESCRIPCIÓN

Obtiene una lista de algoritmos de cifrado soportados. Tenga en cuenta que no necesariamente todos los cifrados son soportados como conjuntos de cifrado TLS. Por ejemplo, DES no es soportado como un conjunto de cifrado, pero es soportado para otros propósitos (por ejemplo, PKCS8 o similares).

Esta función no es segura para hilos.

RETORNA

Una lista de enteros gnutls_cipher_algorithm_t terminada en (0) que indica los cifrados disponibles.
