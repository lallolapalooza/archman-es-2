gnutls_session_set_verify_cert(3) gnutls gnutls_session_set_verify_cert(3)

NOMBRE

gnutls_session_set_verify_cert - función de API

SINOPSIS

#include <gnutls/gnutls.h>

void gnutls_session_set_verify_cert(gnutls_session_t session, const char * hostname, unsigned flags);

ARGUMENTOS

gnutls_session_t session
es una sesión de gnutls
const char * hostname
es el nombre esperado del par; puede ser NULL
unsigned flags
banderas para la verificación del certificado -- gnutls_certificate_verify_flags

DESCRIPCIÓN

Esta función instruye a GnuTLS para verificar el certificado del par utilizando el nombre de host proporcionado. Si la verificación falla, el handshake también fallará con GNUTLS_E_CERTIFICATE_VERIFICATION_ERROR. En ese caso, el resultado de la verificación se puede obtener usando gnutls_session_get_verify_cert_status().

El puntero hostname proporcionado debe permanecer válido durante la vida útil de la sesión. Más precisamente, debe estar disponible durante cualquier handshake posterior. Si no se proporciona ningún nombre de host, no se realizará ninguna verificación de nombre de host. Para una función de verificación más avanzada, consulte gnutls_session_set_verify_cert2().

Si se proporciona flags que contienen un perfil, esta función debe llamarse después de cualquier función de configuración de prioridad de sesión.

La función gnutls_session_set_verify_cert() está destinada a ser utilizada por clientes TLS para verificar el certificado del servidor.
