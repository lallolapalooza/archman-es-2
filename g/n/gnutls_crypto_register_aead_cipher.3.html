NOMBRE

gnutls_crypto_register_aead_cipher - Función de API

SINOPSIS

#include <gnutls/crypto.h>

int gnutls_crypto_register_aead_cipher(gnutls_cipher_algorithm_t algoritmo, int prioridad, gnutls_cipher_init_func init, gnutls_cipher_setkey_func setkey, gnutls_cipher_aead_encrypt_func aead_encrypt, gnutls_cipher_aead_decrypt_func aead_decrypt, gnutls_cipher_deinit_func deinit);

ARGUMENTOS

gnutls_cipher_algorithm_t algoritmo
es el identificador del cifrado AEAD de gnutls
int prioridad
es la prioridad del algoritmo
gnutls_cipher_init_func init
Una función que inicializa el cifrado
gnutls_cipher_setkey_func setkey
Una función que establece la clave del cifrado
gnutls_cipher_aead_encrypt_func aead_encrypt
Realiza la encriptación AEAD
gnutls_cipher_aead_decrypt_func aead_decrypt
Realiza la desencriptación AEAD
gnutls_cipher_deinit_func deinit
Una función que desinicializa el cifrado

DESCRIPCIÓN

Esta función registrará un algoritmo de cifrado para ser utilizado por gnutls. Cualquier algoritmo registrado anulará los algoritmos incluidos y, por convención, los algoritmos implementados en el kernel tienen una prioridad de 90 y los asistidos por CPU de 80. El algoritmo con la menor prioridad será utilizado por gnutls.

En caso de que las funciones de inicialización o establecimiento de clave registradas devuelvan GNUTLS_E_NEED_FALLBACK, GnuTLS intentará utilizar el siguiente cifrado registrado en orden de prioridad.

Las funciones registradas se utilizarán con la nueva API AEAD introducida en GnuTLS 3.4.0. Internamente, GnuTLS utiliza la nueva API AEAD.

DEPRECADO

desde 3.7.0 ya no es posible anular la implementación del cifrado

DEVUELVE

GNUTLS_E_SUCCESS si la operación es exitosa, de lo contrario, un código de error negativo.
