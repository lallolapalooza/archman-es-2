gnutls_x509_crl_get_authority_key_id(3) gnutls gnutls_x509_crl_get_authority_key_id(3)

NOMBRE

gnutls_x509_crl_get_authority_key_id - función de la API

SINOPSIS

#include <gnutls/x509.h>

int gnutls_x509_crl_get_authority_key_id(gnutls_x509_crl_t crl, void * id, size_t * id_size, unsigned int * critical);

ARGUMENTOS

gnutls_x509_crl_t crl
debería contener un tipo gnutls_x509_crl_t
void * id
El lugar donde se copiará el identificador
size_t * id_size
Contiene el tamaño del campo de resultado.
unsigned int * critical
será distinto de cero si la extensión está marcada como crítica (puede ser nulo)

DESCRIPCIÓN

Esta función devolverá el identificador de clave de la autoridad CRL. Esto se obtiene del campo de extensión de Identificador de Clave de Autoridad X.509 (2.5.29.35). Tenga en cuenta que esta función solo devuelve el campo keyIdentifier de la extensión y GNUTLS_E_X509_UNSUPPORTED_EXTENSION, si la extensión contiene el nombre y el número de serie del certificado. En ese caso, se puede utilizar gnutls_x509_crl_get_authority_key_gn_serial().

RETORNA

En caso de éxito, se devuelve GNUTLS_E_SUCCESS (0), de lo contrario, un código de error negativo en caso de error.
