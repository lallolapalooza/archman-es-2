NOMBRE

gnutls_certificate_set_retrieve_function - función de la API

SINOPSIS

#include <gnutls/gnutls.h>

void gnutls_certificate_set_retrieve_function(gnutls_certificate_credentials_t cred, gnutls_certificate_retrieve_function * func);

ARGUMENTOS

gnutls_certificate_credentials_t cred
es un tipo gnutls_certificate_credentials_t.
gnutls_certificate_retrieve_function * func
es la función de callback

DESCRIPCIÓN

Esta función establece una función de callback que se llamará para recuperar el certificado que se utilizará en el handshake. La función de callback tomará el control solo si el par solicita un certificado. Se recomienda usar gnutls_certificate_set_retrieve_function2() porque es mucho más eficiente en el procesamiento que requiere de gnutls.

El prototipo de la función de callback es: int (*callback)(gnutls_session_t, const gnutls_datum_t* req_ca_dn, int nreqs, const gnutls_pk_algorithm_t* pk_algos, int pk_algos_length, gnutls_retr2_st* st);


req_ca_dn solo se usa en certificados X.509. Contiene una lista con los nombres de las CA que el servidor considera confiables. Esto es una pista y típicamente el cliente debe enviar un certificado que sea firmado por una de estas CAs. Estos nombres, cuando están disponibles, están codificados en DER. Para obtener un valor más significativo, use la función gnutls_x509_rdn_get().


pk_algos contiene una lista de algoritmos de clave pública aceptables por el servidor. El certificado devuelto debe soportar los algoritmos dados por el servidor.


st debe contener los certificados y las claves privadas.

Si se proporciona la función de callback, gnutls la llamará, en el handshake, después de recibir el mensaje de solicitud de certificado.

En el lado del servidor, pk_algos y req_ca_dn son NULL.

La función de callback debe establecer la lista de certificados a enviar y devolver 0 si tiene éxito. Si no se seleccionó ningún certificado, el número de certificados debe establecerse en cero. El valor (-1) indica un error y el handshake se terminará. Si tanto los certificados se establecen en las credenciales como hay una función de callback disponible, la función de callback tiene precedencia.
