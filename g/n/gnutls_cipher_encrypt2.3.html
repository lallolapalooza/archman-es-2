NOMBRE

gnutls_cipher_encrypt2 - Función de la API

SINOPSIS

#include <gnutls/crypto.h>

int gnutls_cipher_encrypt2(gnutls_cipher_hd_t handle, const void * ptext, size_t ptext_len, void * ctext, size_t ctext_len);

ARGUMENTOS

gnutls_cipher_hd_t handle
es un tipo gnutls_cipher_hd_t
const void * ptext
los datos a cifrar
size_t ptext_len
la longitud de los datos a cifrar
void * ctext
los datos cifrados
size_t ctext_len
la longitud disponible para los datos cifrados

DESCRIPCIÓN

Esta función cifrará los datos proporcionados utilizando el algoritmo especificado por el contexto. Para cifradores de bloque, ptext_len debe ser un múltiplo del tamaño del bloque. Para los cifradores soportados, la longitud de los datos cifrados será igual al tamaño del texto plano.

RETORNA

Cero o un código de error negativo en caso de error.
