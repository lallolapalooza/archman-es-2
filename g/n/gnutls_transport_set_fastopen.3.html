NOMBRE

gnutls_transport_set_fastopen - función de API

SINOPSIS

#include <gnutls/socket.h>

void gnutls_transport_set_fastopen(gnutls_session_t session, int fd, struct sockaddr * connect_addr, socklen_t connect_addrlen, unsigned int flags);

ARGUMENTOS

gnutls_session_t session
es un tipo gnutls_session_t.
int fd
es el descriptor del socket de la sesión
struct sockaddr * connect_addr
es la dirección a la que queremos conectarnos
socklen_t connect_addrlen
es la longitud de connect_addr
unsigned int flags
debe ser cero

DESCRIPCIÓN

Habilita TCP Fast Open (TFO) para la sesión cliente TLS especificada. Esto significa que el establecimiento de la conexión TCP y la transmisión del primer paquete TLS client hello se combinan. La dirección del par debe ser especificada en connect_addr y connect_addrlen, y el socket especificado por fd no debe estar conectado.

TFO solo funciona para sockets TCP de tipo AF_INET y AF_INET6. Si el sistema operativo no soporta TCP fast open, esta función resultará en que gnutls use connect() transparentemente durante la primera escritura.

NOTA

Esta función anula todas las funciones de devolución de llamada de transporte. Si esto no es deseable, TCP Fast Open debe implementarse en las funciones de devolución de llamada del usuario sin llamar a esta función. Al usar esta función, no se deben establecer devoluciones de llamada de transporte, y no se deben llamar gnutls_transport_set_ptr() o gnutls_transport_set_int().

En GNU/Linux, TFO debe habilitarse a nivel del sistema, es decir, en /proc/sys/net/ipv4/tcp_fastopen, el bit 0 debe estar establecido.

Esta función no tiene ningún efecto en las sesiones del servidor.
