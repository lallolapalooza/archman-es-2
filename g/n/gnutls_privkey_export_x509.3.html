NOMBRE

gnutls_privkey_export_x509 - función API

SINOPSIS

#include <gnutls/abstract.h>

int gnutls_privkey_export_x509(gnutls_privkey_t pkey, gnutls_x509_privkey_t * key);

ARGUMENTOS

gnutls_privkey_t pkey
La clave privada
gnutls_x509_privkey_t * key
Ubicación para exportar la clave.

DESCRIPCIÓN

Convierte la clave privada abstracta dada a un tipo gnutls_x509_privkey_t. La clave abstracta debe ser de tipo GNUTLS_PRIVKEY_X509. La entrada
key no debe estar inicializada. La clave devuelta en key debe ser desinicializada usando gnutls_x509_privkey_deinit().

VALORES DEVUELTOS

En caso de éxito, se devuelve GNUTLS_E_SUCCESS (0), de lo contrario, un valor de error negativo.
