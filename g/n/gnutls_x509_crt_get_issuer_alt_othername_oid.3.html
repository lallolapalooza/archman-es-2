gnutls_x509_crt_get_issuer_alt_othername_oid(3) gnutls gnutls_x509_crt_get_issuer_alt_othername_oid(3)

NOMBRE

gnutls_x509_crt_get_issuer_alt_othername_oid - Función de API

SINOPSIS

#include <gnutls/x509.h>

int gnutls_x509_crt_get_issuer_alt_othername_oid(gnutls_x509_crt_t cert, unsigned int seq, void * ret, size_t * ret_size);

ARGUMENTOS

gnutls_x509_crt_t cert
debería contener un tipo gnutls_x509_crt_t
unsigned int seq
especifica el número de secuencia del nombre alternativo (0 para el primero, 1 para el segundo, etc.)
void * ret
es el lugar donde se copiará el OID de otherName
size_t * ret_size
contiene el tamaño de ret.

DESCRIPCIÓN

Esta función extraerá el OID del tipo de un nombre alternativo de sujeto otherName, contenido en el certificado dado, y devolverá el tipo como un elemento enumerado.

Si oid es nulo, entonces solo se rellenará el tamaño. El oid devuelto estará terminado en nulo, aunque oid_size no tendrá en cuenta el nulo final.

Esta función solo es útil si gnutls_x509_crt_get_issuer_alt_name() devolvió GNUTLS_SAN_OTHERNAME.

RETORNA

el tipo de nombre alternativo del emisor en caso de éxito, uno de los enumerados gnutls_x509_subject_alt_name_t. Para OIDs soportados, devolverá uno de los tipos virtuales (GNUTLS_SAN_OTHERNAME_*), p. ej. GNUTLS_SAN_OTHERNAME_XMPP, y GNUTLS_SAN_OTHERNAME para OIDs desconocidos. Devolverá GNUTLS_E_SHORT_MEMORY_BUFFER si
ret_size no es lo suficientemente grande como para contener el valor. En ese caso
ret_size se actualizará con el tamaño requerido. Si el certificado no tiene un nombre alternativo con el número de secuencia especificado y con el tipo otherName, entonces se devuelve GNUTLS_E_REQUESTED_DATA_NOT_AVAILABLE.
