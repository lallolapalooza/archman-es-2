NOMBRE

gnutls_x509_tlsfeatures_deinit - función de API

SINOPSIS

#include <gnutls/x509.h>

void gnutls_x509_tlsfeatures_deinit(gnutls_x509_tlsfeatures_t f);

ARGUMENTOS

gnutls_x509_tlsfeatures_t f
Las características TLS

DESCRIPCIÓN

Esta función desinicializará una estructura de extensión de características TLS X.509.
