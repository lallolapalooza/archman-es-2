NOMBRE

gnutls_handshake_set_hook_function - Función de la API

SINOPSIS

#include <gnutls/gnutls.h>

void gnutls_handshake_set_hook_function(gnutls_session_t session, unsigned int htype, int when, gnutls_handshake_hook_func func);

ARGUMENTOS

gnutls_session_t session
es un tipo gnutls_session_t
unsigned int htype
la gnutls_handshake_description_t del mensaje al que engancharse
int when
GNUTLS_HOOK_* dependiendo de cuándo deba llamarse la función de enganche
gnutls_handshake_hook_func func
es la función que se llamará

DESCRIPCIÓN

Esta función establecerá una llamada de retorno para que se llame después o antes de que se reciba o genere el mensaje de handshake especificado. Esta es una generalización de gnutls_handshake_set_post_client_hello_function().

Para llamar a la función de enganche antes de que el mensaje sea generado o procesado, use GNUTLS_HOOK_PRE como parámetro when, GNUTLS_HOOK_POST para llamar después, y GNUTLS_HOOK_BOTH para ambos casos.

Esta llamada de retorno debe devolver 0 en caso de éxito o un código de error de gnutls para terminar el handshake.

Para engancharse a todos los mensajes de handshake, use un htype de GNUTLS_HANDSHAKE_ANY.

ADVERTENCIA

No debe usar esta función para terminar el handshake basándose en la entrada del cliente a menos que sepa lo que está haciendo. Antes de que el handshake finalice, no hay forma de saber si se está realizando un ataque de man-in-the-middle.
