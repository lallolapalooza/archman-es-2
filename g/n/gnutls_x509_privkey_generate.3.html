gnutls_x509_privkey_generate(3) gnutls gnutls_x509_privkey_generate(3)

NOMBRE

gnutls_x509_privkey_generate - función de la API

SINOPSIS

#include <gnutls/x509.h>

int gnutls_x509_privkey_generate(gnutls_x509_privkey_t key, gnutls_pk_algorithm_t algo, unsigned int bits, unsigned int flags);

ARGUMENTOS

gnutls_x509_privkey_t key
una clave inicializada
gnutls_pk_algorithm_t algo
es uno de los algoritmos en gnutls_pk_algorithm_t.
unsigned int bits
el tamaño de los parámetros a generar
unsigned int flags
Debe ser cero o banderas de gnutls_privkey_flags_t.

DESCRIPCIÓN

Esta función generará una clave privada aleatoria. Tenga en cuenta que esta función debe ser llamada en una clave privada inicializada.

La bandera GNUTLS_PRIVKEY_FLAG_PROVABLE instruye al proceso de generación de claves para usar algoritmos como Shawe-Taylor (de FIPS PUB186-4) que generan parámetros demostrables a partir de una semilla para claves RSA y DSA. Consulte gnutls_x509_privkey_generate2() para más información.

Tenga en cuenta que al generar una clave de curva elíptica, la curva puede ser sustituida en lugar del parámetro de bits usando la macro GNUTLS_CURVE_TO_BITS(). La entrada a la macro es cualquier curva de gnutls_ecc_curve_t.

Para claves DSA, si se necesita especificar el tamaño del subgrupo, consulte la macro GNUTLS_SUBGROUP_TO_BITS().

Se recomienda no establecer el número de bits directamente, utilice gnutls_sec_param_to_pk_bits() en su lugar.

Véase también gnutls_privkey_generate(), gnutls_x509_privkey_generate2().

RETORNA

En caso de éxito, se devuelve GNUTLS_E_SUCCESS (0), de lo contrario, un valor de error negativo.
