gnutls_pkcs11_privkey_get_info(3)

Paquete: gnutls

Licencias: GPL-3.0-or-later AND LGPL-2.1-or-later

gnutls_pkcs11_privkey_get_info(3) gnutls gnutls_pkcs11_privkey_get_info(3)

NOMBRE

gnutls_pkcs11_privkey_get_info - función de API

SINOPSIS

#include <gnutls/pkcs11.h>

int gnutls_pkcs11_privkey_get_info(gnutls_pkcs11_privkey_t pkey, gnutls_pkcs11_obj_info_t itype, void * output, size_t * output_size);

ARGUMENTOS

gnutls_pkcs11_privkey_t pkey
debería contener un tipo gnutls_pkcs11_privkey_t
gnutls_pkcs11_obj_info_t itype
Indica el tipo de información solicitada
void * output
donde se almacenará la salida
size_t * output_size
contiene el tamaño máximo de la salida y se sobrescribirá con el tamaño real

DESCRIPCIÓN

Esta función devolverá información sobre la clave privada PKCS 11, como la etiqueta, el ID, así como información del token donde se almacena la clave. Cuando la salida es de texto, devuelve una cadena terminada en nulo, aunque output_size contiene solo el tamaño de los datos reales.

RETORNA

GNUTLS_E_SUCCESS (0) en caso de éxito o un código de error negativo en caso de error.
