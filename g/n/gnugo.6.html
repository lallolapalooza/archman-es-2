Sistema de puntuación La partida se detiene cuando ambos jugadores pasan. GNU Go intentará calcular y reportar la puntuación. Puede cometer errores ocasionalmente debido a una evaluación incorrecta del estado de un grupo. Puedes verificar la puntuación como sigue. En modo ASCII, al final de la partida, las piedras que se creen muertas se marcan con letras minúsculas, y tienes la opción de alternar su estado antes de contar. Usando CGoban, puedes usar la función de conteo de CGoban para contar la partida usando reglas japonesas o chinas.

El Protocolo Go

Modem

es una interfaz estándar entre programas de Go y la visualización gráfica. El Protocolo Go

Modem

fue desarrollado por Bruce Wilcox con aportes de David Fotland, Anders Kierulf y otros. Cualquier programa de Go *debería* usar este protocolo ya que es estándar. Dado que CGoban soporta este protocolo, la interfaz de usuario para cualquier programa de Go puede hacerse completamente a través de CGoban. Usando el Protocolo Go Modem, puedes jugar con otro ordenador ejecutando un programa diferente (incluso en un sistema operativo diferente) usando un módem, un cable serie o por internet si el otro programa también soporta el protocolo. También puedes comunicarte con los servidores de Go usando CGoban. Formato Smart Game Las partidas (con
