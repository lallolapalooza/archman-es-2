NOMBRE

gnutls_privkey_import_x509 - Función de la API

SINOPSIS

#include <gnutls/abstract.h>

int gnutls_privkey_import_x509(gnutls_privkey_t pkey, gnutls_x509_privkey_t key, unsigned int flags);

ARGUMENTOS

gnutls_privkey_t pkey
La clave privada
gnutls_x509_privkey_t key
La clave privada a importar
unsigned int flags
Banderas para la importación

DESCRIPCIÓN

Esta función importará la clave privada dada al tipo abstracto gnutls_privkey_t.

El objeto gnutls_x509_privkey_t no debe ser liberado durante la vida útil de esta estructura.


flags puede ser cero o una de GNUTLS_PRIVKEY_IMPORT_AUTO_RELEASE y GNUTLS_PRIVKEY_IMPORT_COPY.

DEVUELVE

En caso de éxito, se devuelve GNUTLS_E_SUCCESS (0), de lo contrario un valor de error negativo.
