NOMBRE

gnutls_global_set_mem_functions - Función de la API

SINOPSIS

#include <gnutls/compat.h>

void gnutls_global_set_mem_functions(gnutls_alloc_function alloc_func, gnutls_alloc_function secure_alloc_func, gnutls_is_secure_function is_secure_func, gnutls_realloc_function realloc_func, gnutls_free_function free_func);

ARGUMENTOS

gnutls_alloc_function alloc_func
es la función de asignación de memoria predeterminada. Como malloc().
gnutls_alloc_function secure_alloc_func
Esta es la función de asignación de memoria que se usará para datos sensibles.
gnutls_is_secure_function is_secure_func
una función que devuelve 0 si la memoria proporcionada no es segura. Puede ser NULL.
gnutls_realloc_function realloc_func
Una función realloc
gnutls_free_function free_func
La función que libera los datos asignados. Debe aceptar un puntero NULL.

OBSOLETO

desde la versión 3.3.0 ya no es posible reemplazar las funciones de asignación de memoria utilizadas internamente

Esta es la función donde se establecen las funciones de asignación de memoria que usará gnutls. Por defecto, las funciones de asignación de la libc (malloc(), free()), son utilizadas por gnutls, para asignar tanto datos sensibles como no sensibles. Esta función se proporciona para establecer las funciones de asignación de memoria a algo diferente de los valores predeterminados.

Esta función debe llamarse antes de que se llame a gnutls_global_init(). Esta función no es segura para hilos.
