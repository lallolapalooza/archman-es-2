NOMBRE

gnutls_handshake_set_random - Función de la API

SINOPSIS

#include <gnutls/gnutls.h>

int gnutls_handshake_set_random(gnutls_session_t session, const gnutls_datum_t * random);

ARGUMENTOS

gnutls_session_t session
es un tipo gnutls_session_t.
const gnutls_datum_t * random
un valor aleatorio de 32 bytes

DESCRIPCIÓN

Esta función establecerá explícitamente el valor aleatorio del hello del servidor o cliente en el posterior handshake TLS. El valor aleatorio debe ser un valor de 32 bytes.

Tenga en cuenta que esta función normalmente no debería usarse, ya que gnutls seleccionará automáticamente un valor aleatorio para el handshake.

Esta función no debe usarse al reanudar una sesión.

RETORNOS

GNUTLS_E_SUCCESS en caso de éxito, o un código de error.
