gnutls_certificate_set_ocsp_status_request_function2(3) gnutls gnutls_certificate_set_ocsp_status_request_function2(3)

NOMBRE

gnutls_certificate_set_ocsp_status_request_function2 - función de API

SINOPSIS

#include <gnutls/gnutls.h>

int gnutls_certificate_set_ocsp_status_request_function2(gnutls_certificate_credentials_t sc, unsigned idx, gnutls_status_request_ocsp_func ocsp_func, void * ptr);

ARGUMENTOS

gnutls_certificate_credentials_t sc
es un tipo gnutls_certificate_credentials_t.
unsigned idx
es un índice de certificado tal como lo devuelven gnutls_certificate_set_key() y similares.
gnutls_status_request_ocsp_func ocsp_func
puntero de función a la devolución de llamada para la solicitud de estado OCSP.
void * ptr
puntero opaco pasado a la función de devolución de llamada.

DESCRIPCIÓN

Esta función debe ser utilizada por el servidor para registrar una devolución de llamada que proporcione solicitudes de estado OCSP que correspondan a la cadena de certificados indexada del cliente. La devolución de llamada se invocará si el cliente suministró una extensión OCSP de solicitud de estado.

El prototipo de la función de devolución de llamada es:

typedef int (*gnutls_status_request_ocsp_func) (gnutls_session_t session, void *ptr, gnutls_datum_t *ocsp_response);

La devolución de llamada se invocará si el cliente solicita un estado de certificado OCSP. La devolución de llamada puede devolver GNUTLS_E_NO_CERTIFICATE_STATUS, si no hay una respuesta OCSP reciente. Si la devolución de llamada devuelve GNUTLS_E_SUCCESS, se espera que el campo ocsp_response esté establecido con una respuesta OCSP válida (codificada en DER). La respuesta debe ser un valor asignado usando gnutls_malloc(), y será desinicializado por el llamador.

NOTA

la capacidad de establecer múltiples respuestas OCSP por estructura de credenciales a través del índice idx se añadió en la versión 3.5.6. Para mantener la compatibilidad con versiones anteriores, requiere el uso de gnutls_certificate_set_flags() con la bandera GNUTLS_CERTIFICATE_API_V2 para que las funciones de certificado establecidas devuelvan un índice utilizable por esta función.

RETORNA

En caso de éxito, se devuelve GNUTLS_E_SUCCESS (0), de lo contrario, se devuelve un código de error negativo.
