NOMBRE

gnustep-tests - script para ejecutar una suite de pruebas de GNUstep

SINOPSIS

gnustep-tests [ directorio | test.m ]

DESCRIPCIÓN

gnustep-tests ejecuta las pruebas especificadas, o cualquier prueba encontrada en el directorio. Si no se proporcionan argumentos, el directorio actual y sus subdirectorios se escanean y procesan correspondientemente.

OPCIONES

--documentation
imprime detalles completos sobre el framework de pruebas
--clean
elimina registros antiguos y cualquier archivo residual
--failfast
se detiene después de la primera falla de prueba encontrada
--debug
ejecuta cualquier prueba fallida en gdb(1)
--developer
trata cualquier esperanza como pruebas reales
--verbose
salida de registro detallada
--sequential
deshabilita la compilación paralela

VER TAMBIÉN
