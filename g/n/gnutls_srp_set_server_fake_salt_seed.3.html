gnutls_srp_set_server_fake_salt_seed(3)

Paquete: gnutls

Licencias: GPL-3.0-or-later AND LGPL-2.1-or-later

gnutls_srp_set_server_fake_salt_seed(3) gnutls gnutls_srp_set_server_fake_salt_seed(3)

NOMBRE

gnutls_srp_set_server_fake_salt_seed - función de API

SINOPSIS

#include <gnutls/gnutls.h>

void gnutls_srp_set_server_fake_salt_seed(gnutls_srp_server_credentials_t cred, const gnutls_datum_t * seed, unsigned int salt_length);

ARGUMENTOS

gnutls_srp_server_credentials_t cred
es un tipo gnutls_srp_server_credentials_t
const gnutls_datum_t * seed
son los datos de la semilla, solo necesitan ser válidos hasta que la función retorne; el tamaño de la semilla debe ser mayor que cero
unsigned int salt_length
es la longitud de las sales falsas generadas

DESCRIPCIÓN

Esta función establece la semilla que se utiliza para generar sales para nombres de usuario inválidos (inexistentes).

Para evitar que los atacantes adivinen nombres de usuario válidos, cuando un usuario no existe, gnutls genera una sal y un verificador y continúa con el protocolo como de costumbre. La autenticación finalmente fallará, pero el cliente no puede saber si el nombre de usuario es válido (existe) o inválido.

Si un atacante aprende la semilla, dado una sal (que es parte del handshake) que se generó cuando la semilla estaba en uso, puede decir si la autenticación falló o no debido a un nombre de usuario desconocido. Esta semilla no se puede utilizar para revelar datos de aplicación o contraseñas.


salt_length debe representar la longitud de la sal que utiliza su aplicación. No se admite la generación de sales falsas de más de 20 bytes.

Por defecto, la semilla es un valor aleatorio, diferente cada vez que se asigna un gnutls_srp_server_credentials_t y las sales falsas tienen 16 bytes de longitud.
