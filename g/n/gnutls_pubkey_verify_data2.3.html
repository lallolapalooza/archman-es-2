NOMBRE

gnutls_pubkey_verify_data2 - Función de API

SINOPSIS

#include <gnutls/abstract.h>

int gnutls_pubkey_verify_data2(gnutls_pubkey_t pubkey, gnutls_sign_algorithm_t algo, unsigned int flags, const gnutls_datum_t * data, const gnutls_datum_t * signature);

ARGUMENTOS

gnutls_pubkey_t pubkey
Contiene la clave pública
gnutls_sign_algorithm_t algo
El algoritmo de firma utilizado
unsigned int flags
Cero o una lista OR de gnutls_certificate_verify_flags
const gnutls_datum_t * data
Contiene los datos firmados
const gnutls_datum_t * signature
Contiene la firma

DESCRIPCIÓN

Esta función verificará los datos firmados dados, utilizando los parámetros del certificado.

VALORES DEVUELTOS

En caso de fallo de verificación, se devolverá GNUTLS_E_PK_SIG_VERIFY_FAILED, y un código cero o positivo en caso de éxito. Para firmas conocidas por ser inseguras, esta función devolverá GNUTLS_E_INSUFFICIENT_SECURITY a menos que se especifique la bandera GNUTLS_VERIFY_ALLOW_BROKEN.
