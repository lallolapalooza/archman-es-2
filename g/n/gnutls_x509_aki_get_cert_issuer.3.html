NOMBRE

gnutls_x509_aki_get_cert_issuer - función de la API

SINOPSIS

#include <gnutls/x509-ext.h>

int gnutls_x509_aki_get_cert_issuer(gnutls_x509_aki_t aki, unsigned int seq, unsigned int * san_type, gnutls_datum_t * san, gnutls_datum_t * othername_oid, gnutls_datum_t * serial);

ARGUMENTOS

gnutls_x509_aki_t aki
La clave de identificación de la autoridad
unsigned int seq
El índice del nombre a obtener
unsigned int * san_type
Contendrá el tipo del nombre (de gnutls_subject_alt_names_t)
gnutls_datum_t * san
Los datos del nombre alternativo
gnutls_datum_t * othername_oid
El identificador de objeto si san_type es GNUTLS_SAN_OTHERNAME
gnutls_datum_t * serial
El número de serie de la autoridadCertSerialNumber

DESCRIPCIÓN

Esta función devolverá un nombre específico de authorityCertIssuer tal como está almacenado en el tipo aki, así como el authorityCertSerialNumber. Todos los valores devueltos deben ser tratados como constantes y pueden ser establecidos a NULL cuando no se requieran.

RETORNA

En caso de éxito, se devuelve GNUTLS_E_SUCCESS (0), GNUTLS_E_REQUESTED_DATA_NOT_AVAILABLE si el índice está fuera de límites, de lo contrario un valor de error negativo.
