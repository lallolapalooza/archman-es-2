NOMBRE

gnutls_pubkey_import_ecc_raw - función de API

SINOPSIS

#include <gnutls/abstract.h>

int gnutls_pubkey_import_ecc_raw(gnutls_pubkey_t key, gnutls_ecc_curve_t curve, const gnutls_datum_t * x, const gnutls_datum_t * y);

ARGUMENTOS

gnutls_pubkey_t key
La estructura para almacenar la clave analizada
gnutls_ecc_curve_t curve
contiene la curva
const gnutls_datum_t * x
contiene la coordenada x
const gnutls_datum_t * y
contiene la coordenada y

DESCRIPCIÓN

Esta función convertirá los parámetros de la curva elíptica dados a una gnutls_pubkey_t. El resultado se almacenará en key .

En las curvas EdDSA, el parámetro y debe ser NULL y el parámetro x debe ser el valor en el formato nativo para la curva.

RETORNA

En caso de éxito, se devuelve GNUTLS_E_SUCCESS (0), de lo contrario, un valor de error negativo.
