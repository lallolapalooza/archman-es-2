NOMBRE

gnutls_hash_squeeze - Función de API

SINOPSIS

#include <gnutls/crypto.h>

int gnutls_hash_squeeze(gnutls_hash_hd_t handle, void * output, size_t length);

ARGUMENTOS

gnutls_hash_hd_t handle
un gnutls_hash_hd_t
void * output
destino para almacenar la salida; debe ser igual o mayor que length
size_t length
longitud de output

DESCRIPCIÓN

Esta función extraerá la salida del hash de length bytes. El handle debe ser inicializado con gnutls_hash_init() como una función de salida extendida (XOF), como GNUTLS_DIG_SHAKE_128 o GNUTLS_DIG_SHAKE_256.

Esta función se puede llamar varias veces. Para restablecer el estado del handle, llame a gnutls_hash_deinit() con NULL como argumento del digest.

VALOR DEVUELTO

GNUTLS_E_SUCCESS (0) en caso de éxito; código de error negativo en caso contrario.
