DESCRIPCIÓ

N

Gnuplot es un programa interactivo de gráficos dirigido por

comandos.

Si se dan nombres de archivos en la línea de comandos, gnuplot carga y ejecuta cada archivo en el orden especificado, y sale después de que se haya procesado el último archivo. Si no se dan archivos, gnuplot muestra un prompt para comandos

interactivos.

Aquí hay algunas de sus características

:

Grafica cualquier número de funciones, construidas con operadores de C, funciones de la biblioteca matemática de C, y algunas cosas que C no tiene como **, sgn(),

etc.

Constantes y funciones definidas por el

usuario.

Todos los cálculos se realizan en el dominio complejo. Solo la parte real se grafica por defecto, pero funciones como imag() y abs() y arg() están disponibles para anular

esto.

Muchos estilos de presentación para graficar datos de usuario desde archivos, incluyendo ajuste de superficies, barras de error, diagramas de caja, histogramas, mapas de calor y manipulación simple de datos de imagen. Hay una colección de demostraciones en línea en
http://gnuplot.

info/demo

Ajuste de mínimos cuadrados no

lineal.

Gráficos 2D y 3D con zoom, rotación e hipertexto controlados por el

ratón.

Escapes de shell y sustitución de línea de

comandos.

Capacidad de carga y

guardado.

Soporte para una gran varied

ad de dispositivos de salid
a y formatos de archivo.

-p, --persist permite que las ventanas de gráficos sobrevivan después de que el programa principal gnuplot

salga.

-c nombre_de_script ARG1 ARG2 ..., carga el script usando el mecanismo "call" de gnuplot y le pasa el resto de la línea de comandos como

argumentos

-d, --default-settings no leer de gnuplotrc, ~/.gnuplot, y $XDG_CONFIG_HOME/gnuplot/gnuplotrc al

entrar.

-e "lista de comandos" ejecuta los comandos solicitados antes de cargar el siguiente archivo de

entrada.

-s, --slow esperar la inicialización lenta de fuentes en lugar de continuar con un

error.

OPCIONES

X11

Para el tipo de terminal x11, gnuplot acepta las opciones y recursos estándar del X Toolkit como geometry, font y background. Vea la página man X(1) para una descripción de opciones comunes. Para opciones X adicionales específicas de gnuplot, escriba help x11 en la línea de comandos de gnuplot. Estas

opciones no tienen efecto
en otros tipos de terminal.

Usado por el controlador postscript para localizar archivos de prólogo externos. Dependie

postscript con archivos de prólogo personalizados. Vea "help postscript prologue".

ARCHIVO

S
gnuplot
rc
Cuando se ejecuta gnuplot, primero busca un archivo de inicialización de todo el sistema llamado gnuplotrc. La ubicación estándar de este archivo esperada por el programa es reportada por el comando "show
loadpath".
.
gnuplot
Después de cargar el archivo de inicialización de todo el sistema, si existe, Gnuplot busca un archivo de inicialización privado en el directorio HOME. Puede contener cualquier comando legal de gnuplot, pero típicamente se limitan a establecer el terminal y los tipos de línea preferidos y definir funciones o variables de uso
frecuente.
$XDG_CONFIG_HOME/gnuplot/gnuplo
trc
Después de cargar los otros archivos de inicialización, Gnuplot comprobará si hay un archivo llamado gnuplotrc en el subdirectorio gnuplot en $XDG_CONFIG_HOME (por defecto ~/.config). Se aplican las mismas restricciones que para .
gnuplot.
