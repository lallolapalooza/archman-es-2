NOMBRE

gnutls_privkey_export_ecc_raw - función de la API

SINOPSIS

#include <gnutls/abstract.h>

int gnutls_privkey_export_ecc_raw(gnutls_privkey_t key, gnutls_ecc_curve_t * curve, gnutls_datum_t * x, gnutls_datum_t * y, gnutls_datum_t * k);

ARGUMENTOS

gnutls_privkey_t key
Contiene la clave pública
gnutls_ecc_curve_t * curve
Contendrá la curva
gnutls_datum_t * x
Contendrá la coordenada x
gnutls_datum_t * y
Contendrá la coordenada y
gnutls_datum_t * k
Contendrá la clave privada

DESCRIPCIÓN

Esta función exportará los parámetros de la clave privada ECC encontrados en la estructura dada. Los nuevos parámetros se asignarán usando gnutls_malloc() y se almacenarán en el datum apropiado.

En las curvas EdDSA, el parámetro y será NULL y los otros parámetros estarán en el formato nativo para la curva.

VALOR DE RETORNO

GNUTLS_E_SUCCESS en caso de éxito, de lo contrario un código de error negativo.
