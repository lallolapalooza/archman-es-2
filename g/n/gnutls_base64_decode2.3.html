NOMBRE

gnutls_base64_decode2 - función de API

SINOPSIS

#include <gnutls/gnutls.h>

int gnutls_base64_decode2(const gnutls_datum_t * base64, gnutls_datum_t * result);

ARGUMENTOS

const gnutls_datum_t * base64
contiene los datos codificados
gnutls_datum_t * result
la ubicación de los datos decodificados

DESCRIPCIÓN

Esta función decodificará los datos codificados en base64 proporcionados. Los datos decodificados se asignarán y se almacenarán en result.

Deberías usar gnutls_free() para liberar los datos devueltos.

RETORNA

En caso de éxito, se devuelve GNUTLS_E_SUCCESS (0), de lo contrario se devuelve un código de error.
