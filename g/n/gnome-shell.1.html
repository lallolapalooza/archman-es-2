gnome-shell(1) Comandos de usuario gnome-shell(1)

Nombre

gnome-shell - Shell gráfica para el escritorio GNOME

SINOPSIS

gnome-shell [OPCIÓN...]

DESCRIPCIÓN

GNOME shell proporciona funciones centrales de la interfaz de usuario para el escritorio GNOME 3, como cambiar entre ventanas y lanzar aplicaciones. GNOME shell aprovecha las capacidades del hardware gráfico moderno e introduce conceptos innovadores de interfaz de usuario para ofrecer una experiencia visualmente atractiva y fácil de usar.

gnome-shell es un componente requerido del escritorio GNOME, es decir, está listado en el campo RequiredComponents de /usr/share/gnome-session/sessions/gnome.session. Se inicia en la fase del gestor de ventanas de la sesión.

OPCIONES

--wayland

Ejecutar como un compositor wayland

--display-server

Ejecutar como un servidor de pantalla completo, en lugar de anidado

--nested

Ejecutar como un compositor anidado

--no-x11

Ejecutar el compositor wayland sin iniciar Xwayland

--x11

Ejecutar con el backend X11

--wayland-display=DISPLAY

Nombre de la pantalla Wayland a usar

-d, --display=DISPLAY

Pantalla X a usar

-r, --replace

Reemplazar el gestor de ventanas en ejecución

--sm-disable

Desactivar la conexión con el gestor de sesiones

--sm-client-id=ID

Especificar el ID de gestión de sesiones

--sm-save-file=FILE

Inicializar sesión desde FILE

--sync

Hacer que las llamadas X sean síncronas

--mode=MODE

Usar un modo específico, por ejemplo, "gdm" para la pantalla de inicio de sesión

--list-modes

Listar los modos posibles y salir

--version

Imprimir la versión y salir

--help

Mostrar la ayuda y salir

ARCHIVOS

/usr/share/gnome-session/sessions/gnome.session, /usr/share/applications/org.gnome.Shell.desktop.

ERRORES

Se puede acceder al rastreador de errores visitando el sitio web https://gitlab.gnome.org/GNOME/gnome-shell/issues. Antes de enviar un informe de error, por favor verifique que tiene la última versión de gnome-shell. Muchos errores (mayores y menores) se corrigen en cada lanzamiento, y si el suyo está desactualizado, el problema puede haber sido resuelto.

INFORMACIÓN ADICIONAL

Para más información, visite el sitio web https://gitlab.gnome.org/GNOME/gnome-shell/-/blob/main/README.md.
