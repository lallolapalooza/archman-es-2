gnutls_record_send_file(3) gnutls gnutls_record_send_file(3)

NOMBRE

gnutls_record_send_file - Función de API

SINOPSIS

#include <gnutls/gnutls.h>

ssize_t gnutls_record_send_file(gnutls_session_t session, int fd, off_t * offset, size_t count);

ARGUMENTOS

gnutls_session_t session
es un tipo gnutls_session_t.
int fd
descriptor de archivo del cual leer datos.
off_t * offset
Es relativo al desplazamiento del archivo, denota la ubicación de inicio para la lectura. Después de que la función retorna, apunta a la posición siguiente al último byte leído.
size_t count
es la longitud de los datos en bytes a leer del archivo y enviar.

DESCRIPCIÓN

Esta función envía datos desde fd. Si KTLS (kernel TLS) está habilitado, utilizará la llamada al sistema sendfile() para evitar la sobrecarga de copiar datos entre el espacio de usuario y el kernel. De lo contrario, esta funcionalidad se emula simplemente llamando a read() y gnutls_record_send(). Si esta implementación es subóptima, comprueba si KTLS está habilitado usando gnutls_transport_is_ktls_enabled().

Si offset es NULL, entonces el desplazamiento del archivo se incrementa por el número de bytes enviados; de lo contrario, el desplazamiento del archivo permanece sin cambios.

RETORNA

El número de bytes enviados, o un código de error negativo.
