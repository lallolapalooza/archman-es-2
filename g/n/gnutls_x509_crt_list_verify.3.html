gnutls_x509_crt_list_verify(3)

Paquete: gnutls

Licencias: GPL-3.0-or-later AND LGPL-2.1-or-later

gnutls_x509_crt_list_verify(3) gnutls gnutls_x509_crt_list_verify(3)

NOMBRE

gnutls_x509_crt_list_verify - función de API

SINOPSIS

#include <gnutls/x509.h>

int gnutls_x509_crt_list_verify(const gnutls_x509_crt_t * cert_list, unsigned cert_list_length, const gnutls_x509_crt_t * CA_list, unsigned CA_list_length, const gnutls_x509_crl_t * CRL_list, unsigned CRL_list_length, unsigned int flags, unsigned int * verify);

ARGUMENTOS

const gnutls_x509_crt_t * cert_list
es la lista de certificados a verificar
unsigned cert_list_length
contiene el número de certificados en cert_list
const gnutls_x509_crt_t * CA_list
es la lista de AC que se utilizará en la verificación
unsigned CA_list_length
contiene el número de certificados de AC en CA_list
const gnutls_x509_crl_t * CRL_list
contiene una lista de CRL.
unsigned CRL_list_length
la longitud de la lista de CRL.
unsigned int flags
Banderas que se pueden usar para cambiar el algoritmo de verificación. Use OR de las enumeraciones gnutls_certificate_verify_flags.
unsigned int * verify
contendrá la salida de la verificación del certificado.

DESCRIPCIÓN

Esta función intentará verificar la lista de certificados dada y devolverá su estado. Los detalles de la verificación son los mismos que en gnutls_x509_trust_list_verify_crt2().

Debe comprobar el nombre del par para asegurarse de que el certificado verificado pertenece al par real.

La salida de la verificación del certificado se colocará en verify y será uno o más de los elementos enumerados de gnutls_certificate_status_t combinados con OR a nivel de bits. Para un estado de verificación más detallado, utilice gnutls_x509_crt_verify() por cada elemento de la lista.

DEVUELVE

En caso de éxito, se devuelve GNUTLS_E_SUCCESS (0), de lo contrario, un valor de error negativo.
