NOMBRE

gnutls_priority_init - Función API

SINOPSIS

#include <gnutls/gnutls.h>

int gnutls_priority_init(gnutls_priority_t * priority_cache, const char * priorities, const char ** err_pos);

ARGUMENTOS

gnutls_priority_t * priority_cache
es un tipo gnutls_priority_t.
const char * priorities
es una cadena que describe las prioridades (puede ser NULL)
const char ** err_pos
En caso de error, contendrá la posición en la cadena donde ocurrió el error

DESCRIPCIÓN

Para aplicaciones que no modifican sus configuraciones criptográficas por liberación, considera usar gnutls_priority_init2() con la bandera GNUTLS_PRIORITY_INIT_DEF_APPEND en su lugar. Sugerimos usar configuraciones criptográficas centralizadas manejadas por la biblioteca GnuTLS, y que las aplicaciones modifiquen las configuraciones predeterminadas según sus necesidades.

Esta función es idéntica a gnutls_priority_init2() con cero banderas.

Una cadena priorities NULL indica las prioridades predeterminadas a ser usadas (esto está disponible desde GnuTLS 3.3.0).

RETORNA

En caso de error de sintaxis se retorna GNUTLS_E_INVALID_REQUEST, GNUTLS_E_SUCCESS en caso de éxito, o un código de error.
