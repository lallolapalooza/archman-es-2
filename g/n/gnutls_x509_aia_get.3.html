NOMBRE

gnutls_x509_aia_get - función de API

SINOPSIS

#include <gnutls/x509-ext.h>

int gnutls_x509_aia_get(gnutls_x509_aia_t aia, unsigned int seq, gnutls_datum_t * oid, unsigned * san_type, gnutls_datum_t * san);

ARGUMENTOS

gnutls_x509_aia_t aia
La información de acceso de la autoridad
unsigned int seq
especifica el número de secuencia del descriptor de acceso (0 para el primero, 1 para el segundo, etc.)
gnutls_datum_t * oid
el tipo de datos disponibles; para ser tratado como constante.
unsigned * san_type
Contendrá el tipo del nombre de gnutls_subject_alt_names_t (puede ser nulo).
gnutls_datum_t * san
el nombre de ubicación de acceso; para ser tratado como constante (puede ser nulo).

DESCRIPCIÓN

Esta función lee del tipo Authority Information Access.

El parámetro de entrada seq se utiliza para indicar qué miembro de la secuencia interesa al llamador. El primer miembro es 0, el segundo miembro es 1 y así sucesivamente. Cuando el valor de seq está fuera de los límites, se devuelve GNUTLS_E_REQUESTED_DATA_NOT_AVAILABLE.

Típicamente oid es GNUTLS_OID_AD_CAISSUERS o GNUTLS_OID_AD_OCSP.

RETORNA

En caso de éxito, se devuelve GNUTLS_E_SUCCESS (0), de lo contrario, un valor de error negativo.
