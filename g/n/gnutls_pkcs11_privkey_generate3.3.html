NOMBRE

gnutls_pkcs11_privkey_generate3 - función de la API

SINOPSIS

#include <gnutls/pkcs11.h>

int gnutls_pkcs11_privkey_generate3(const char * url, gnutls_pk_algorithm_t pk, unsigned int bits, const char * label, const gnutls_datum_t * cid, gnutls_x509_crt_fmt_t fmt, gnutls_datum_t * pubkey, unsigned int key_usage, unsigned int flags);

ARGUMENTOS

const char * url
una URL de token
gnutls_pk_algorithm_t pk
el algoritmo de clave pública
unsigned int bits
los bits de seguridad
const char * label
una etiqueta
const gnutls_datum_t * cid
El CKA_ID a utilizar para el nuevo objeto
gnutls_x509_crt_fmt_t fmt
el formato de los parámetros de salida. PEM o DER
gnutls_datum_t * pubkey
contendrá la clave pública (puede ser NULL)
unsigned int key_usage
Uno de GNUTLS_KEY_*
unsigned int flags
cero o una secuencia OR de GNUTLS_PKCS11_OBJ_FLAGs

DESCRIPCIÓN

Esta función generará una clave privada en el token especificado por la url. La clave privada se generará dentro del token y no será exportable. Esta función almacenará la clave pública codificada en DER en el formato SubjectPublicKeyInfo en pubkey. El pubkey debe ser desinicializado usando gnutls_free().

Tenga en cuenta que al generar una clave de curva elíptica, la curva puede ser sustituida en lugar del parámetro bits usando la macro GNUTLS_CURVE_TO_BITS().

Desde 3.6.3 los objetos se marcan como sensibles por defecto a menos que se especifique GNUTLS_PKCS11_OBJ_FLAG_MARK_NOT_SENSITIVE.

VALOR DE RETORNO

En caso de éxito, se devuelve GNUTLS_E_SUCCESS (0), de lo contrario, un valor de error negativo.
