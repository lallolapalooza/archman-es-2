gnu_get_libc_version(3) Manual de funciones de biblioteca gnu_get_libc_version(3)

NOMBRE

gnu_get_libc_version, gnu_get_libc_release - obtener la versión y la versión de glibc

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <gnu/libc-version.h>
const char *gnu_get_libc_version(void);
const char *gnu_get_libc_release(void);

DESCRIPCIÓN

La función gnu_get_libc_version() devuelve una cadena que identifica la versión de glibc disponible en el sistema.

La función gnu_get_libc_release() devuelve una cadena que indica el estado de la versión de glibc disponible en el sistema. Será una cadena como stable.

ATRIBUTOS

Para una explicación de los términos utilizados en esta sección, véase attributes(7).

Interfaz Atributo Valor
gnu_get_libc_version (), gnu_get_libc_release () Seguridad de hilos MT-Safe

ESTÁNDARES

GNU.

HISTORIA

glibc 2.1.

EJEMPLOS

Al ejecutarse, el programa a continuación producirá una salida similar a la siguiente:


$ ./a.out
GNU libc version: 2.8
GNU libc release: stable

Código fuente del programa

#include <stdio.h>
#include <stdlib.h>
#include <gnu/libc-version.h>
int
main(void)
{
    printf("GNU libc version: %s\n", gnu_get_libc_version());
    printf("GNU libc release: %s\n", gnu_get_libc_release());
    exit(EXIT_SUCCESS);
}
