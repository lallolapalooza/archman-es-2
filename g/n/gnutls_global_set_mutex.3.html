NOMBRE

gnutls_global_set_mutex - Función de la API

SINOPSIS

#include <gnutls/gnutls.h>

void gnutls_global_set_mutex(mutex_init_func init, mutex_deinit_func deinit, mutex_lock_func lock, mutex_unlock_func unlock);

ARGUMENTOS

mutex_init_func init
función de inicialización de mutex
mutex_deinit_func deinit
función de desinicialización de mutex
mutex_lock_func lock
función de bloqueo de mutex
mutex_unlock_func unlock
función de desbloqueo de mutex

DESCRIPCION

Con esta función puedes anular los bloqueos de mutex predeterminados utilizados en algunas partes de gnutls y bibliotecas dependientes. Esta función debe usarse si tienes control total sobre tu programa y bibliotecas. No llames a esta función desde una biblioteca, o preferiblemente desde ninguna aplicación a menos que sea realmente necesario. GnuTLS usará los bloqueos apropiados para el sistema en ejecución.

Esta función debe llamarse antes que cualquier otra función de GnuTLS; de lo contrario, el comportamiento es indefinido.

OBSOLETO

Esta función está desaconsejada en GnuTLS 3.7.3 o posterior.
