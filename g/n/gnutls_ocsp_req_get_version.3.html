NOMBRE

gnutls_ocsp_req_get_version - función de API

SINOPSIS

#include <gnutls/ocsp.h>

int gnutls_ocsp_req_get_version(gnutls_ocsp_req_const_t req);

ARGUMENTOS

gnutls_ocsp_req_const_t req
debería contener un tipo gnutls_ocsp_req_t

DESCRIPCIÓN

Esta función devolverá la versión de la solicitud OCSP. Normalmente, esta siempre es 1, lo que indica la versión 1.

DEVUELVE

versión de la solicitud OCSP, o un código de error negativo en caso de error.
