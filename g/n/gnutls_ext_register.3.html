gnutls_ext_register(3)

gnutls_ext_register(3) gnutls gnutls_ext_register(3)

NOMBRE

gnutls_ext_register - función API

SINOPSIS

#include <gnutls/gnutls.h>

int gnutls_ext_register(const char * nombre, int id, gnutls_ext_parse_type_t punto_parseo, gnutls_ext_recv_func funcion_recv, gnutls_ext_send_func funcion_send, gnutls_ext_deinit_data_func funcion_deinit, gnutls_ext_pack_func funcion_pack, gnutls_ext_unpack_func funcion_unpack);

ARGUMENTOS

const char * nombre
el nombre de la extensión a registrar
int id
el ID numérico de TLS de la extensión
gnutls_ext_parse_type_t punto_parseo
el tipo de parseo de la extensión (ver gnutls_ext_parse_type_t)
gnutls_ext_recv_func funcion_recv
una función para recibir los datos
gnutls_ext_send_func funcion_send
una función para enviar los datos
gnutls_ext_deinit_data_func funcion_deinit
una función para inicializar cualquier dato privado
gnutls_ext_pack_func funcion_pack
una función que serializa los datos privados de la extensión (utilizada en el empaquetado de sesión para reanudación)
gnutls_ext_unpack_func funcion_unpack
una función que deserializará los datos privados de la extensión

DESCRIPCIÓN

Esta función registrará un nuevo tipo de extensión. La extensión permanecerá registrada hasta que se llame a gnutls_global_deinit(). Si el tipo de extensión ya está registrado, se devolverá GNUTLS_E_ALREADY_REGISTERED.

Cada extensión registrada puede almacenar datos temporales en la estructura gnutls_session_t usando gnutls_ext_set_data(), y pueden ser recuperados usando gnutls_ext_get_data().

Cualquier extensión registrada con esta función es válida para el cliente y el servidor TLS1.2 hello (o extensiones cifradas para TLS1.3).

Esta función no es segura para hilos.

RETORNA

GNUTLS_E_SUCCESS si tiene éxito, de lo contrario un código de error negativo.
