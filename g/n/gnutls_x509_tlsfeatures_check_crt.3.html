NOMBRE

gnutls_x509_tlsfeatures_check_crt - función de API

SINOPSIS

#include <gnutls/x509.h>

unsigned gnutls_x509_tlsfeatures_check_crt(gnutls_x509_tlsfeatures_t feat, gnutls_x509_crt_t cert);

ARGUMENTOS

gnutls_x509_tlsfeatures_t feat
un conjunto de TLSFeatures
gnutls_x509_crt_t cert
el certificado a comprobar

DESCRIPCIÓN

Esta función comprobará el certificado proporcionado contra el conjunto TLSFeatures en feat utilizando las reglas del RFC7633 p.4.2.2. Comprobará si el certificado contiene las características en feat o un superconjunto.

DEVUELVE

un valor distinto de cero si el certificado proporcionado cumple, y cero en caso contrario.
