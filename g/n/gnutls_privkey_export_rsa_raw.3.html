NOMBRE

gnutls_privkey_export_rsa_raw - Función de API

SINOPSIS

#include <gnutls/abstract.h>

int gnutls_privkey_export_rsa_raw(gnutls_privkey_t key, gnutls_datum_t * m, gnutls_datum_t * e, gnutls_datum_t * d, gnutls_datum_t * p, gnutls_datum_t * q, gnutls_datum_t * u, gnutls_datum_t * e1, gnutls_datum_t * e2);

ARGUMENTOS

gnutls_privkey_t key
Contiene el certificado
gnutls_datum_t * m
contendrá el módulo
gnutls_datum_t * e
contendrá el exponente público
gnutls_datum_t * d
contendrá el exponente privado
gnutls_datum_t * p
contendrá el primer primo (p)
gnutls_datum_t * q
contendrá el segundo primo (q)
gnutls_datum_t * u
contendrá el coeficiente
gnutls_datum_t * e1
contendrá e1 = d mod (p-1)
gnutls_datum_t * e2
contendrá e2 = d mod (q-1)

DESCRIPCIÓN

Esta función exportará los parámetros de la clave privada RSA que se encuentran en la estructura dada. Los nuevos parámetros se asignarán utilizando gnutls_malloc() y se almacenarán en el datum apropiado. Para las claves EdDSA, el valor de y debe ser NULL.

DEVUELVE

GNUTLS_E_SUCCESS en caso de éxito, de lo contrario, un código de error negativo.
