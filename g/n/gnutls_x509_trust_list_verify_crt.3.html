gnutls_x509_trust_list_verify_crt(3) gnutls gnutls_x509_trust_list_verify_crt(3)

NOMBRE

gnutls_x509_trust_list_verify_crt - Función de la API

SINOPSIS

#include <gnutls/x509.h>

int gnutls_x509_trust_list_verify_crt(gnutls_x509_trust_list_t lista, gnutls_x509_crt_t * lista_cert, unsigned int tamano_lista_cert, unsigned int flags, unsigned int * salida_verif, gnutls_verify_output_function func);

ARGUMENTOS

gnutls_x509_trust_list_t lista
La lista
gnutls_x509_crt_t * lista_cert
es la lista de certificados a verificar
unsigned int tamano_lista_cert
es el tamaño de la lista de certificados
unsigned int flags
Banderas que se pueden usar para cambiar el algoritmo de verificación. Usar OR de las enumeraciones de gnutls_certificate_verify_flags.
unsigned int * salida_verif
contendrá la salida de la verificación del certificado.
gnutls_verify_output_function func
Si no es nulo, se llamará en cada verificación de elemento de la cadena con la salida.

DESCRIPCIÓN

Esta función intentará verificar el certificado dado y devolverá su estado. El parámetro salida_verif contendrá una secuencia OR'ed de las banderas de gnutls_certificate_status_t.

Los detalles de la verificación son los mismos que en gnutls_x509_trust_list_verify_crt2().

DEVUELVE

En caso de éxito, se devuelve GNUTLS_E_SUCCESS (0), de lo contrario, un valor de error negativo.
