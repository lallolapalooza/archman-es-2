gnutls_privkey_import_ext3(3) gnutls gnutls_privkey_import_ext3(3)

NOMBRE

gnutls_privkey_import_ext3 - Función de la API

SINOPSIS

#include <gnutls/abstract.h>

int gnutls_privkey_import_ext3(gnutls_privkey_t pkey, void * userdata, gnutls_privkey_sign_func sign_fn, gnutls_privkey_decrypt_func decrypt_fn, gnutls_privkey_deinit_func deinit_fn, gnutls_privkey_info_func info_fn, unsigned int flags);

ARGUMENTOS

gnutls_privkey_t pkey
La clave privada
void * userdata
Datos privados que se proporcionarán a las funciones de devolución de llamada
gnutls_privkey_sign_func sign_fn
Función de devolución de llamada para operaciones de firma
gnutls_privkey_decrypt_func decrypt_fn
Función de devolución de llamada para operaciones de descifrado
gnutls_privkey_deinit_func deinit_fn
Una función de desinicialización
gnutls_privkey_info_func info_fn
Devuelve información sobre el algoritmo de clave pública (no debe ser NULL)
unsigned int flags
Indicadores para la importación

DESCRIPCIÓN

Esta función asociará las funciones de devolución de llamada dadas con el tipo gnutls_privkey_t. Al menos una de las dos funciones de devolución de llamada debe ser diferente de nulo. Si se proporciona una función de desinicialización, se asume que los indicadores contienen GNUTLS_PRIVKEY_IMPORT_AUTO_RELEASE.

Tenga en cuenta que la función de firma debe firmar los datos de forma "cruda", es decir, sin ningún tipo de hash ni preprocesamiento. En el caso de RSA, se proporcionará el DigestInfo, y se espera que la función de firma realice el relleno PKCS 1 1.5 y la exponenciación.

La función info_fn debe proporcionar información sobre los algoritmos admitidos por esta clave privada y debe admitir los indicadores GNUTLS_PRIVKEY_INFO_PK_ALGO y GNUTLS_PRIVKEY_INFO_SIGN_ALGO. Debe devolver -1 para indicadores desconocidos.

DEVUELVE

En caso de éxito, se devuelve GNUTLS_E_SUCCESS (0), de lo contrario, un valor de error negativo.
