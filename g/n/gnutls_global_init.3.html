NOMBRE

gnutls_global_init - función de API

SINOPSIS

#include <gnutls/gnutls.h>

int gnutls_global_init( void);

ARGUMENTOS

void

DESCRIPCIÓN

Desde GnuTLS 3.3.0, esta función ya no es necesario llamarla explícitamente. Para deshabilitar la llamada implícita (en un constructor de biblioteca) de esta función, establezca la variable de entorno GNUTLS_NO_IMPLICIT_INIT a 1.

Esta función realiza los precalculos necesarios, detecta las capacidades de la CPU soportadas e inicializa el backend criptográfico subyacente. Para liberar cualquier recurso tomado por esta llamada, debe llamar a gnutls_global_deinit() cuando ya no se necesite el uso de gnutls.

Esta función incrementa un contador global, de modo que gnutls_global_deinit() solo libera recursos cuando se ha llamado tantas veces como gnutls_global_init(). Esto es útil cuando GnuTLS es utilizado por más de una biblioteca en una aplicación. Esta función puede ser llamada muchas veces, pero solo hará algo la primera vez. Es segura para hilos desde GnuTLS 3.3.0.

Una llamada posterior a esta función si la inicialización falló devolverá el mismo código de error.

RETORNA

En caso de éxito, se devuelve GNUTLS_E_SUCCESS (0), de lo contrario, se devuelve un código de error negativo.
