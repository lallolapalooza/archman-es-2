NOMBRE

gnutls_aead_cipher_decryptv2 - Función de la API

SINOPSIS

#include <gnutls/crypto.h>

int gnutls_aead_cipher_decryptv2(gnutls_aead_cipher_hd_t handle, const void * nonce, size_t nonce_len, const giovec_t * auth_iov, int auth_iovcnt, const giovec_t * iov, int iovcnt, void * tag, size_t tag_size);

ARGUMENTOS

gnutls_aead_cipher_hd_t handle
es un tipo gnutls_aead_cipher_hd_t.
const void * nonce
el nonce a establecer
size_t nonce_len
La longitud del nonce
const giovec_t * auth_iov
datos adicionales a autenticar
int auth_iovcnt
El número de buffers en auth_iov
const giovec_t * iov
los datos a descifrar
int iovcnt
El número de buffers en iov
void * tag
La etiqueta de autenticación
size_t tag_size
El tamaño de la etiqueta a usar (use cero para el predeterminado)

DESCRIPCIÓN

Esto es similar a gnutls_aead_cipher_decrypt(), pero realiza el descifrado en el lugar sobre los buffers de datos proporcionados.

RETORNA

Cero o un código de error negativo en caso de error.
