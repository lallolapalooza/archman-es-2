NOMBRE

gnutls_x509_crt_check_key_purpose - Función de la API

SINOPSIS

#include <gnutls/x509.h>

unsigned gnutls_x509_crt_check_key_purpose(gnutls_x509_crt_t cert, const char * purpose, unsigned flags);

ARGUMENTOS

gnutls_x509_crt_t cert
debería contener un tipo gnutls_x509_crt_t
const char * purpose
un OID de propósito de clave (p. ej., GNUTLS_KP_CODE_SIGNING)
unsigned flags
cero o GNUTLS_KP_FLAG_DISALLOW_ANY

DESCRIPCIÓN

Esta función verificará si el certificado proporcionado coincide con el propósito de clave especificado. Si flags contiene GNUTLS_KP_FLAG_ALLOW_ANY, entonces un certificado marcado para cualquier propósito no coincidirá.

VALORES DEVUELTOS

cero si el propósito de clave no coincide, y distinto de cero en caso contrario.
