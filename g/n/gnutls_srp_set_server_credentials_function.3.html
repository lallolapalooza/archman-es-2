gnutls_srp_set_server_credentials_function(3) gnutls gnutls_srp_set_server_credentials_function(3)

NOMBRE

gnutls_srp_set_server_credentials_function - función de la API

SINOPSIS

#include <gnutls/gnutls.h>

void gnutls_srp_set_server_credentials_function(gnutls_srp_server_credentials_t cred, gnutls_srp_server_credentials_function * func);

ARGUMENTOS

gnutls_srp_server_credentials_t cred
es un tipo gnutls_srp_server_credentials_t.
gnutls_srp_server_credentials_function * func
es la función de devolución de llamada

DESCRIPCIÓN

Esta función se puede usar para establecer una devolución de llamada para recuperar las credenciales SRP del usuario. La forma de la función de devolución de llamada es:

int (*callback)(gnutls_session_t, const char* username, gnutls_datum_t *salt, gnutls_datum_t *verifier, gnutls_datum_t *generator, gnutls_datum_t *prime);


username contiene el nombre de usuario real. El salt , verifier , generator y prime deben ser completados usando gnutls_malloc(). Para mayor comodidad, prime y generator también pueden ser uno de los parámetros estáticos definidos en gnutls.h.

Inicialmente, el campo de datos es NULL en cada estructura gnutls_datum_t que la función de devolución de llamada debe completar. Cuando la función de devolución de llamada termina, GnuTLS desasigna todos esos búferes que no son NULL, independientemente del valor de retorno.

Para evitar que los atacantes adivinen nombres de usuario válidos, si un usuario no existe, los valores g y n deben completarse con los parámetros de un usuario aleatorio. En ese caso, la función de devolución de llamada debe devolver el valor especial (1). Consulte también gnutls_srp_set_server_fake_salt_seed. Si esto no es necesario para su aplicación, devuelva un número negativo desde la función de devolución de llamada para abortar el apretón de manos.

La función de devolución de llamada solo se llamará una vez por cada apretón de manos. La función de devolución de llamada debe devolver 0 en caso de éxito, mientras que -1 indica un error.
