NOMBRE

gnutls_store_pubkey - Función de la API

SINOPSIS

#include <gnutls/gnutls.h>

int gnutls_store_pubkey(const char * db_name, gnutls_tdb_t tdb, const char * host, const char * service, gnutls_certificate_type_t cert_type, const gnutls_datum_t * cert, time_t expiration, unsigned int flags);

ARGUMENTOS

const char * db_name
Un archivo que especifica las claves almacenadas (use NULL para el valor predeterminado)
gnutls_tdb_t tdb
Una estructura de almacenamiento o NULL para usar la predeterminada
const char * host
El nombre del par
const char * service
no es NULL si esta clave es específica de un servicio (por ejemplo, http)
gnutls_certificate_type_t cert_type
El tipo del certificado
const gnutls_datum_t * cert
Los datos del certificado
time_t expiration
La hora de expiración (use 0 para deshabilitar la expiración)
unsigned int flags
debe ser 0.

DESCRIPCIÓN

Esta función almacenará una clave pública en bruto o una clave pública proporcionada a través de un certificado en bruto (codificado en DER) en la lista de claves públicas almacenadas. La clave se considerará válida hasta la hora de expiración proporcionada.

La variable tdb, si no es NULL, especifica un backend personalizado para el almacenamiento de entradas. Si es NULL, se utilizará el backend de archivo predeterminado.

A menos que se proporcione un tdb alternativo, el formato de almacenamiento es un formato textual que consiste en una línea por cada host con campos separados por '|'. El contenido de los campos es un identificador de formato que se establece en 'g0', el nombre de host al que se aplican los demás datos, el puerto numérico o el nombre del host, la hora de expiración en segundos desde la época (0 para sin expiración) y una codificación base64 de la información de la clave pública en bruto (DER) (SPKI) del par.

A partir de GnuTLS 3.6.6, esta función también acepta claves públicas en bruto.

RETORNA

En caso de éxito, se devuelve GNUTLS_E_SUCCESS (0), de lo contrario, un valor de error negativo.
