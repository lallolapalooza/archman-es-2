gnutls_x509_privkey_import_rsa_raw2(3) gnutls gnutls_x509_privkey_import_rsa_raw2(3)

NOMBRE

gnutls_x509_privkey_import_rsa_raw2 - Función de API

SINOPSIS

#include <gnutls/x509.h>

int gnutls_x509_privkey_import_rsa_raw2(gnutls_x509_privkey_t key, const gnutls_datum_t * m, const gnutls_datum_t * e, const gnutls_datum_t * d, const gnutls_datum_t * p, const gnutls_datum_t * q, const gnutls_datum_t * u, const gnutls_datum_t * e1, const gnutls_datum_t * e2);

ARGUMENTOS

gnutls_x509_privkey_t key
los datos para almacenar la clave analizada
const gnutls_datum_t * m
contiene el módulo
const gnutls_datum_t * e
contiene el exponente público
const gnutls_datum_t * d
contiene el exponente privado
const gnutls_datum_t * p
contiene el primer primo (p)
const gnutls_datum_t * q
contiene el segundo primo (q)
const gnutls_datum_t * u
contiene el coeficiente (opcional)
const gnutls_datum_t * e1
contiene e1 = d mod (p-1) (opcional)
const gnutls_datum_t * e2
contiene e2 = d mod (q-1) (opcional)

DESCRIPCIÓN

Esta función convertirá los parámetros brutos de RSA dados al formato nativo gnutls_x509_privkey_t. La salida se almacenará en
key .

RETORNA

En caso de éxito, se devuelve GNUTLS_E_SUCCESS (0), de lo contrario, un valor de error negativo.
