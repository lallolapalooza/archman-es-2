NOMBRE

gnutls_privkey_import_rsa_raw - función de la API

SINOPSIS

#include <gnutls/abstract.h>

int gnutls_privkey_import_rsa_raw(gnutls_privkey_t key, const gnutls_datum_t * m, const gnutls_datum_t * e, const gnutls_datum_t * d, const gnutls_datum_t * p, const gnutls_datum_t * q, const gnutls_datum_t * u, const gnutls_datum_t * e1, const gnutls_datum_t * e2);

ARGUMENTOS

gnutls_privkey_t key
La estructura para almacenar la clave analizada
const gnutls_datum_t * m
contiene el módulo
const gnutls_datum_t * e
contiene el exponente público
const gnutls_datum_t * d
contiene el exponente privado (opcional)
const gnutls_datum_t * p
contiene el primer primo (p)
const gnutls_datum_t * q
contiene el segundo primo (q)
const gnutls_datum_t * u
contiene el coeficiente (opcional)
const gnutls_datum_t * e1
contiene e1 = d mod (p-1) (opcional)
const gnutls_datum_t * e2
contiene e2 = d mod (q-1) (opcional)

DESCRIPCIÓN

Esta función convertirá los parámetros RSA brutos dados al formato nativo gnutls_privkey_t. La salida se almacenará en
key .

VALORES DEVUELTOS

En caso de éxito, se devuelve GNUTLS_E_SUCCESS (0), de lo contrario, un valor de error negativo.
