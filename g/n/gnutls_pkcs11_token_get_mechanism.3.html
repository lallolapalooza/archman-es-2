NOMBRE

gnutls_pkcs11_token_get_mechanism - Función de la API

SINAPSIS

#include <gnutls/pkcs11.h>

int gnutls_pkcs11_token_get_mechanism(const char * url, unsigned int idx, unsigned long * mechanism);

ARGUMENTOS

const char * url
debería contener una URL PKCS 11
unsigned int idx
El índice del mecanismo
unsigned long * mechanism
El ID del mecanismo PKCS 11

DESCRIPCIÓN

Esta función devolverá los nombres de los mecanismos soportados por el token. Debería llamarse con un índice creciente hasta que devuelva GNUTLS_E_REQUESTED_DATA_NOT_AVAILABLE.

DEVOLUCIONES

GNUTLS_E_SUCCESS (0) en caso de éxito o un código de error negativo en caso de error.
