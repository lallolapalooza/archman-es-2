NOMBRE

gnutls_store_commitment - función de la API

SINOPSIS

#include <gnutls/gnutls.h>

int gnutls_store_commitment(const char * db_name, gnutls_tdb_t tdb, const char * host, const char * service, gnutls_digest_algorithm_t hash_algo, const gnutls_datum_t * hash, time_t expiration, unsigned int flags);

ARGUMENTOS

const char * db_name
Un archivo que especifica las claves almacenadas (use NULL para el valor predeterminado)
gnutls_tdb_t tdb
Una estructura de almacenamiento o NULL para usar el valor predeterminado
const char * host
El nombre del par
const char * service
no NULL si esta clave es específica de un servicio (por ejemplo, http)
gnutls_digest_algorithm_t hash_algo
El tipo de algoritmo de hash
const gnutls_datum_t * hash
El hash en bruto
time_t expiration
La hora de expiración (use 0 para deshabilitar la expiración)
unsigned int flags
debería ser 0 o GNUTLS_SCOMMIT_FLAG_ALLOW_BROKEN.

DESCRIPCIÓN

Esta función almacenará el hash de compromiso proporcionado en la lista de claves públicas almacenadas. La clave con el hash dado se considerará válida hasta la hora de expiración proporcionada.

La variable tdb, si no es nula, especifica un backend personalizado para el almacenamiento de entradas. Si es NULL, se utilizará el backend de archivo predeterminado.

Tenga en cuenta que esta función no es segura para hilos con el backend predeterminado.

RETORNA

En caso de éxito, se devuelve GNUTLS_E_SUCCESS (0), de lo contrario, un valor de error negativo.
