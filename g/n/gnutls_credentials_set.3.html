gnutls_credentials_set(3)

Paquete: gnutls

Licencias: GPL-3.0-or-later AND LGPL-2.1-or-later

gnutls_credentials_set(3) gnutls gnutls_credentials_set(3)

NOMBRE

gnutls_credentials_set - función de la API

SINOPSIS

#include <gnutls/gnutls.h>

int gnutls_credentials_set(gnutls_session_t session, gnutls_credentials_type_t type, void * cred);

ARGUMENTOS

gnutls_session_t session
es un tipo gnutls_session_t.
gnutls_credentials_type_t type
es el tipo de las credenciales
void * cred
las credenciales a establecer

DESCRIPCIÓN

Establece las credenciales necesarias para el tipo especificado. Por ejemplo, nombre de usuario, contraseña - o claves públicas y privadas, etc. El parámetro cred es una estructura que depende del type especificado y de la sesión actual (cliente o servidor). Solo se puede establecer una cred por cada type diferente; las llamadas subsiguientes con el mismo type reemplazarán las credenciales establecidas previamente.

Para minimizar el uso de memoria y compartir credenciales entre varios hilos, gnutls mantiene un puntero a cred, y no la estructura completa de credenciales. Por lo tanto, deberá mantener la estructura asignada hasta que llame a gnutls_deinit(), o hasta que una llamada futura a gnutls_credentials_set() con el mismo type reemplace la estructura cred.

Para GNUTLS_CRD_ANON, cred debe ser gnutls_anon_client_credentials_t en caso de un cliente. En caso de un servidor, debe ser gnutls_anon_server_credentials_t.

Para GNUTLS_CRD_SRP, cred debe ser gnutls_srp_client_credentials_t en caso de un cliente, y gnutls_srp_server_credentials_t, en caso de un servidor.

Para GNUTLS_CRD_CERTIFICATE, cred debe ser gnutls_certificate_credentials_t.

RETORNA

En caso de éxito, se devuelve GNUTLS_E_SUCCESS (0), de lo contrario, se devuelve un código de error negativo.
