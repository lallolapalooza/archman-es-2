NOMBRE

gvmap.sh - pipeline para ejecutar gvmap

SINOPSIS

gvmap.sh [-vV?] [ opciones ] [ -o archivo_salida ] [ archivos ]

DESCRIPCIÓN

gvmap.sh toma como entrada un grafo en formato DOT, realiza un layout, procesa la salida a través de gvmap y renderiza la salida. En algún momento, se espera integrar todas estas tareas en gvmap.

OPCIONES

Las siguientes opciones son compatibles:

-a k
El entero k especifica el número promedio de puntos artificiales añadidos a lo largo del cuadro delimitador de las etiquetas. Dichos puntos artificiales se añaden para evitar que un límite de país corte el cuadro delimitador de las etiquetas. El tiempo de cálculo es proporcional a k; por lo tanto, para grafos grandes, se sugiere un valor pequeño de k. Si k = -1, se selecciona automáticamente un valor adecuado de k basándose en el tamaño del grafo. Por defecto, k = -1.
-K layout
especifica qué programa se debe usar para el layout inicial. Por defecto, se ejecuta sfdp. También por defecto, el layout recibe el flag -Goverlap=prism. Esto puede ser anulado usando un flag -g.
-T formato
especifica el formato de salida final. Esto funciona de la misma manera que el flag -T para cualquier programa de layout de Graphviz.
-N attr=val
especifica la configuración de un atributo de nodo predeterminado durante la fase de renderizado. Esto funciona de la misma manera que el flag -N para cualquier programa de layout de Graphviz.
-G attr=val
especifica la configuración de un atributo de grafo durante la fase de renderizado. Esto funciona de la misma manera que el flag -G para cualquier programa de layout de Graphviz.
-E attr=val
especifica la configuración de un atributo de arista predeterminado durante la fase de renderizado. Esto funciona de la misma manera que el flag -E para cualquier programa de layout de Graphviz.
-n attr=val
especifica la configuración de un atributo de nodo predeterminado durante la fase de layout. Esto funciona de la misma manera que el flag -N para cualquier programa de layout de Graphviz.
-g attr=val
especifica la configuración de un atributo de grafo durante la fase de layout. Esto funciona de la misma manera que el flag -G para cualquier programa de layout de Graphviz.
-e attr=val
especifica la configuración de un atributo de arista predeterminado durante la fase de layout. Esto funciona de la misma manera que el flag -E para cualquier programa de layout de Graphviz.
-A flag
especifica un flag que se pasará a gvmap. Por ejemplo, gvmap.sh -Ae -As3 hace que se ejecute gvmap -e -s3.
-v
Establece el modo detallado.
-V
Imprime la información de la versión y sale.
-?
Imprime la información de uso y sale.

EJEMPLOS

La siguiente invocación crea un mapa con aristas en gris claro semitransparente y nodos dispuestos usando sfdp:

gvmap.sh -Ae -Ecolor=#55555522 -Tpng foo.gv > foo.png

Es equivalente a ejecutar el pipeline

sfdp -Goverlap=prism foo.gv | gvmap -e | neato -n2 -Ecolor=#55555522 -Tpng > foo.png
