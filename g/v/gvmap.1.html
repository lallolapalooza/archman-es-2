NOMBRE

gvmap - encontrar clústeres y crear un mapa geográfico resaltando clústeres.

SINOPSIS

gvmap [ opciones ] [ -o archivo_salida ] [ archivos ]

DESCRIPCIÓN

gvmap toma como entrada un grafo en formato DOT, encuentra clústeres de nodos y produce una representación del grafo como un mapa de estilo geográfico, con clústeres resaltados como países, en formato xdot.

En el grafo de entrada, cada nodo debe tener definida información de posición, ancho y alto (atributos pos, width y height, respectivamente), y los nodos no deben solaparse.

Por defecto, gvmap generará los clústeres a partir de los datos. Si se desea, el grafo de entrada puede especificar información de clústeres asignando a cada nodo un atributo cluster cuyo valor es un entero positivo pequeño. (Funciona mejor si los valores de cluster son todos enteros en el intervalo [1,K] para algún K. Los nodos que comparten el mismo valor de atributo cluster se agruparán en el mismo clúster. **Nota:** Para que el atributo cluster sea utilizado, todos los nodos deben tener un valor válido.)

Si se utiliza la opción -D, gvmap utilizará los subgrafos de clústeres de nivel superior para determinar la agrupación. Cualquier nodo que no esté en dicho clúster se incluirá en un único clúster general.

Si la entrada especifica la agrupación deseada como se describió anteriormente, también puede especificar un color deseado teniendo un nodo en cada clúster que proporcione un atributo clustercolor. **Nota:** A menos que se especifique -c0, solo el clustercolor del último nodo en un clúster tiene efecto. Además, a menos que se use -O, gvmap puede permutar los colores dados.

OPCIONES

Se admiten las siguientes opciones:

-a k
El entero k especifica el número promedio de puntos artificiales añadidos a lo largo del cuadro delimitador de las etiquetas. Dichos puntos artificiales se añaden para evitar que un límite de país corte el cuadro delimitador de las etiquetas. El tiempo de cálculo es proporcional a k; por lo tanto, para grafos grandes, se sugiere un valor pequeño de k. Si k = -1, se selecciona automáticamente un valor adecuado de k basado en el tamaño del grafo. Por defecto, k = -1.
-b v
El número real v especifica el ancho de línea utilizado para dibujar los límites de los polígonos, con v < 0 para no dibujar línea. Por defecto, v = 0.
-c k
El entero k especifica el esquema de color utilizado para colorear los países. Por defecto, k = 1.

Valores aceptables son:

0 : sin polígonos
1 : pastel
2 : azul a amarillo
3 : blanco a rojo
4 : gris claro a rojo
5 : colores primarios
6 : rojo de tono único secuencial
7 : rojo de tono único más claro secuencial
8 : gris claro
-c_opacidad=xy
Especifica una cadena hexadecimal de dos caracteres que indica la opacidad de los polígonos.
-C d
El entero d especifica el número máximo de clústeres (países) permitidos. Por defecto, d = 0, lo que significa que no hay límite.
-d d
El entero d especifica la semilla aleatoria utilizada durante la optimización de asignación de colores que maximiza la diferencia de color entre países vecinos.
-D
Si se especifica, se utilizan los subgrafos de clúster del grafo para especificar la agrupación.
-e
Si se especifica, se incluirán las aristas en la salida final.
-g c
Especifica el color del cuadro delimitador. Si no se especifica, no se dibuja ningún cuadro delimitador.
-h k
El número de puntos artificiales añadidos para mantener un puente entre los extremos. Por defecto, esto es cero.
-resaltar=k
Solo dibuja el clúster k. Por defecto, se dibujan todos los clústeres.
-k
Si se especifica, aumenta la aleatoriedad del límite exterior.
-l s
Usa la cadena s como etiqueta para el dibujo.
-m v
Genera un margen de v puntos alrededor del dibujo. Por defecto, esto lo determina gvmap.
-O
NO realizar optimización de asignación de colores que maximice las diferencias de color entre países vecinos.
-o<archivo>
Colocar la salida en <archivo>. La salida predeterminada es stdout
-p k
Indica qué nivel de puntos se debe mostrar. Por defecto, no se muestran puntos.

Valores aceptables son:

0 : sin puntos
1 : todos los puntos
2 : puntos de etiqueta
3 : puntos aleatorios/artificiales
-Q
Usar calidad de modularidad para la agrupación en lugar de la agrupación de modularidad predeterminada.
-r k
El número de puntos aleatorios k (entero) utilizados para definir los límites del mar y los lagos. Si es 0, se asigna automáticamente. Por defecto, v = 0.
-s v
El número real v especifica la profundidad del mar y las costas de los lagos en puntos. Si es 0, se asigna automáticamente. Por defecto, v = 0.
-t n
Intentar n veces para mejorar la contigüidad del clúster.
-v
Modo detallado.
-z c
Especifica el color de la línea del polígono. El valor predeterminado es negro.
-?
Imprimir uso y salir.

EJEMPLOS

Dado un grafo foo.gv, una forma de generar un diseño y resaltar los clústeres es primero seleccionar un motor de diseño con un método adecuado de eliminación de solapamientos, luego alimentar la salida a gvmap, y finalmente renderizar el mapa utilizando un formato gráfico específico. Por ejemplo, la siguiente tubería crea un mapa con aristas en gris claro semitransparente y nodos organizados usando sfdp:

sfdp -Goverlap=prism foo.gv | gvmap -e | neato -n2 -Ecolor=#55555522 -Tpng > foo.png

El script de shell gvmap.sh proporciona una forma abreviada para tales tuberías. Por ejemplo, la tubería anterior se puede lograr usando

gvmap.sh -Ae -Ecolor=#55555522 -Tpng foo.gv > foo.png
