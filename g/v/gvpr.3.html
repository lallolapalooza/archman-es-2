Paquete: graphviz

LIBGVPR(3) Manual de funciones de biblioteca LIBGVPR(3)

NOMBRE

libgvpr - biblioteca para el filtrado de grafos

SINOPSIS

#include <graphviz/gvpr.h>
  /* Si se establece, gvpr llama a exit() en errores */
#define GV_USE_EXIT 1
  /* Si se establece, gvpr almacena los grafos de salida en gvpropts */
#define GV_USE_OUTGRAPH 2
typedef ssize_t (*gvprwr) (void*, const char *buf, size_t nbyte, void*);
typedef struct {
    Agraph_t** ingraphs;      /* Array terminado en NULL de grafos de entrada */
    int n_outgraphs;          /* si GV_USE_OUTGRAPH está establecido, grafos de salida */
    Agraph_t** outgraphs;
    gvprwr out;               /* función de escritura para stdout */
    gvprwr err;               /* función de escritura para stderr */
    int flags;
} gvpropts;
extern int gvpr (int argc, char *argv[], gvpropts* opts);

DESCRIPCIÓN

La biblioteca gvpr permite a una aplicación realizar manipulación y filtrado general de grafos basado en un lenguaje similar a awk. (Para una descripción más completa de este lenguaje, consulte gvpr(1).)

La biblioteca tiene un único punto de entrada: la función gvpr(). Esta proporciona una interfaz estándar argc/argv, junto con una estructura para admitir grafos en memoria, funciones de impresión de aplicaciones y opciones adicionales.

Cuando se llama, gvpr() procesa las banderas proporcionadas en la matriz argv y compila el programa gvpr a ejecutar (proporcionado a través de la bandera -f o como un elemento en argv). Luego ejecuta el programa en cada grafo de entrada. Si opts->ingraphs no es NULL, se toma como un array terminado en NULL de grafos en memoria para ser utilizados como entrada. De lo contrario, los elementos no procesados de argv se toman como los nombres de archivos que contienen grafos a procesar. (Si no quedan, gvpr leerá de stdin.)

Normalmente, gvpr escribe cualquier grafo de salida en stdout. Sin embargo, si la bandera GV_USE_OUTGRAPH está establecida en opts->flags, los grafos de salida se almacenarán en un array apuntado por opts->outgraphs y el recuento se almacenará en opts->n_outgraphs. En este caso, la aplicación debe llamar a agclose() en cada grafo de salida cuando haya terminado con él.

La aplicación puede anular las funciones de escritura predeterminadas para stdout y stderr utilizando los campos out y err en opts. Cuando es llamada por gvpr, el segundo argumento apuntará a un búfer de caracteres a escribir, mientras que el tercer argumento proporciona el número de caracteres. La función debe devolver el número de bytes realmente escritos.

VALORES DE RETORNO

Normalmente, gvpr devuelve 0 en caso de éxito y un valor distinto de cero si ocurre un error. Cualquier mensaje de error relevante se habrá escrito en stderr o se habrá llamado a la función opts->err de la aplicación. Si, sin embargo, GV_USE_EXIT está establecido en opts->flags, gvpr llamará a exit(3) en caso de error.

VER TAMBIÉN

gvpr(1), awk(1), cgraph(3)
