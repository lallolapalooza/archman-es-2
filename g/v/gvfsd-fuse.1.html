NOMBRE

gvfsd-fuse - Demonio de Fuse para gvfs

SINOPSIS

gvfsd-fuse RUTA

DESCRIPCIÓN

gvfsd-fuse mantiene un montaje de fuse para hacer que los backends de gvfs estén disponibles para aplicaciones POSIX. El punto de montaje del sistema de archivos fuse se proporciona mediante el argumento [RUTA].

Normalmente, gvfsd-fuse es iniciado por gvfsd(1). En este caso, el punto de montaje es $XDG_RUNTIME_DIR/gvfs o $HOME/.gvfs.

OPCIONES

-d

Habilita la salida de depuración de fuse. Esto implica -f.

-f

Ejecuta en primer plano.

-s

Ejecuta en un solo hilo.

-o OPCIÓN

Establece una opción específica de fuse. Consulta la documentación de fuse para ver una lista de estas opciones.

ESTADO DE SALIDA

En caso de éxito, se devuelve 0; de lo contrario, se devuelve un código de error distinto de cero.
