GVGEN(1) Manual de Comandos Generales GVGEN(1)

NOMBRE

gvgen - generar grafos

SINOPSIS

gvgen [ -dv? ] [ -in ] [ -cn ] [ -Cx,y ] [ -g[f]x,y ] [ -G[f]x,y ] [ -hn ] [ -kn ] [ -bx,y ] [ -Bx,y ] [ -mn ] [ -Mx,y ] [ -pn ] [ -rx,y ] [ -Rx ] [ -sn ] [ -Sn ] [ -Sn,d ] [ -tn ] [ -td,n ] [ -Tx,y ] [ -Tx,y,u,v ] [ -useed ] [ -wn ] [ -nprefix ] [ -Nname ] [ -ooutfile ]

DESCRIPCIÓN

gvgen genera una variedad de grafos abstractos simples y de estructura regular.

OPCIONES

Se admiten las siguientes opciones:

-c n
Genera un ciclo con n vértices y aristas.
-C x,y
Genera un cilindro de x por y . Este tendrá x*y vértices y 2*x*y - y aristas.
-g [f]x,y
Genera una cuadrícula de x por y . Si se proporciona f , la cuadrícula está plegada, con una arista que une cada par de vértices en esquinas opuestas. Esto tendrá x*y vértices y 2*x*y - y - x aristas si está desplegada y 2*x*y - y - x + 2 aristas si está plegada.
-G [f]x,y
Genera una cuadrícula parcial de x por y . Si se proporciona f , la cuadrícula está plegada, con una arista que une cada par de vértices en esquinas opuestas. Esto tendrá x*y vértices.
-h n
Genera un hipercubo de grado n. Este tendrá 2^n vértices y n*2^(n-1) aristas.
-k n
Genera un grafo completo sobre n vértices con n*(n-1)/2 aristas.
-b x,y
Genera un grafo bipartito completo de x por y . Este tendrá x+y vértices y x*y aristas.
-B x,y
Genera una bola de x por y , es decir, un cilindro de x por y con dos nodos "tapas" que cierran los extremos. Esto tendrá x*y + 2 vértices y 2*x*y + y aristas.
-m n
Genera una malla triangular con n vértices por lado. Esto tendrá (n+1)*n/2 vértices y 3*(n-1)*n/2 aristas.
-M x,y
Genera una banda de Möbius de x por y. Esto tendrá x*y vértices y 2*x*y - y aristas.
-p n
Genera un camino sobre n vértices. Esto tendrá n-1 aristas.
-r x,y
Genera un grafo aleatorio. El número de vértices será el mayor valor de la forma 2^n-1 menor o igual que x. Valores mayores de y aumentan la densidad del grafo.
-R x
Genera un árbol aleatorio con raíz sobre x vértices.
-s n
Genera una estrella sobre n vértices. Esto tendrá n-1 aristas.
-S n
Genera un grafo de Sierpinski de orden n. Este tendrá 3*(3^(n-1) + 1)/2 vértices y 3^n aristas.
-S n,d
Genera un grafo de Sierpinski de dimensión dy de orden n. Actualmente, d debe ser 2 o 3. Para d igual a 3, habrá 4*(4^(n-1) + 1)/2 vértices y 6 * 4^(n-1) aristas.
-t n
Genera un árbol binario de altura n. Este tendrá 2^n-1 vértices y 2^n-2 aristas.
-t h,n
Genera un árbol n-ario de altura h.
-T x,y
-T x,y,u,v
Genera un toro de x por y . Este tendrá x*y vértices y 2*x*y aristas. Si se proporcionan u y v , especifican giros de esa cantidad en las direcciones horizontal y vertical, respectivamente.
-u seed
Especifica el estado inicial para el generador de números aleatorios. Si no se proporciona esta opción, se usa la hora actual para derivar una semilla.
-w n
Genera un camino sobre n vértices. Esto tendrá n-1 aristas.
-i n
Genera n grafos del tipo solicitado. Actualmente, solo está disponible si se usa el indicador -R .
-n prefix
Normalmente, se usan enteros como nombres de nodos. Si se especifica prefix , este se antepondrá al entero para crear el nombre.
-N name
Usa name como el nombre del grafo. De forma predeterminada, el grafo es anónimo.
-o outfile
Si se especifica, el grafo generado se escribe en el archivo outfile. De lo contrario, el grafo se escribe en la salida estándar.
-d
Hace que el grafo generado sea dirigido.
-v
Salida detallada.
-?
Imprime información de uso.

ESTADO DE SALIDA

gvgen sale con 0 en una finalización exitosa, y sale con 1 si se le da un indicador mal formado o incorrecto, o si el archivo de salida especificado no se pudo abrir.
