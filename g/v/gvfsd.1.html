NOMBRE

gvfsd - Demonio principal de gvfs

SINOPSIS

gvfsd [OPCIÓN...]

DESCRIPCIÓN

gvfsd es el demonio principal del sistema de archivos virtual gvfs. Proporciona el nombre org.gtk.vfs.Daemon en el bus de sesión. gvfsd se inicia automáticamente por los clientes GIO si no se está ejecutando.

La tarea principal de gvfsd es actuar como rastreador/gestor de montajes. Genera nuevos backends cuando se solicitan y realiza un seguimiento de su ciclo de vida, manteniendo una lista de montajes activos y creando conexiones directas a ellos.

Dado que los backends de gvfs se ejecutan como hijos del proceso gvfsd, es posible iniciar gvfsd en una terminal y establecer variables de entorno para obtener salida de depuración de backends individuales.

gvfsd también inicia gvfsd-fuse(1) y le proporciona el punto de montaje donde se debe montar el sistema de archivos fuse.

OPCIONES

-h, --help

Imprime un breve texto de ayuda y sale.

--version

Muestra el número de versión y sale.

-r, --replace

Reemplaza la instancia de gvfsd en ejecución actualmente.

--no-fuse

No inicia el sistema de archivos fuse.

-d, --debug

Habilita la salida de depuración.

ENTORNO

GVFS_DISABLE_FUSE

Si esta variable de entorno está establecida, gvfsd no iniciará el sistema de archivos fuse.

ESTADO DE SALIDA

En caso de éxito se devuelve 0, de lo contrario, un código de fallo distinto de cero.

VER TAMBIÉN

gvfs(7), gvfsd-fuse(1)
