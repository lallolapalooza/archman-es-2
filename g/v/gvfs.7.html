NOMBRE

gvfs - sistema de archivos virtual GIO

DESCRIPCIÓN

GIO proporciona una API de VFS para aplicaciones GLib. Incluye una implementación 'local' que utiliza POSIX. gvfs proporciona implementaciones que van más allá y permiten acceder a archivos y almacenamiento utilizando muchos protocolos, como ftp, http, sftp, dav, nfs, etc. También proporciona soporte para carpetas de papelera, para grabación de CDs y para monitorear dispositivos y volúmenes interesantes en el ordenador.

Las aplicaciones usan gvfs indirectamente, a través de GIO que carga el módulo gvfs que implementa los puntos de extensión GIO. El soporte de gvfs para el monitoreo de volúmenes se incluye en un módulo cargable separado.

La implementación real de gvfs se distribuye en varios procesos. Ninguno de ellos se espera que se inicie desde la línea de comandos, excepto con fines de depuración.

Procesos principales:

•gvfsd - el demonio principal de gvfs
•gvfsd-fuse - monta gvfs como un sistema de archivos fuse
•gvfsd-metadata - escribe metadatos de gvfs

Monitores de volumen:

•gvfs-afc-volume-monitor - un monitor de volumen para dispositivos Apple iPhone/iPod Touch
•gvfs-goa-volume-monitor - un monitor de volumen para Cuentas en Línea de GNOME
•gvfs-gphoto2-volume-monitor - un monitor de volumen para dispositivos PTP
•gvfs-mtp-volume-monitor - un monitor de volumen para dispositivos MTP
•gvfs-udisks2-volume-monitor - un monitor de volumen basado en udisks2

Backends de montaje:

•gvfsd-admin - monta sistemas de archivos locales con privilegios de administrador
•gvfsd-afc - monta volúmenes de iPhone/iPod touch
•gvfsd-afp - monta volúmenes de Apple Filing Protocol
•gvfsd-afp-browse - busca volúmenes de Apple Filing Protocol
•gvfsd-archive - monta archivos de archivo en varios formatos
•gvfsd-burn - proporciona una ubicación para grabar CDs
•gvfsd-cdda - monta CDs de audio
•gvfsd-computer - proporciona computer://
•gvfsd-dav - monta sistemas de archivos DAV
•gvfsd-dnssd - busca dnssd
•gvfsd-ftp - monta sobre FTP
•gvfsd-google - monta recursos compartidos de Google Drive
•gvfsd-gphoto2 - monta sobre PTP
•gvfsd-http - monta sobre HTTP
•gvfsd-localtest - un backend de prueba
•gvfsd-mtp - monta sobre MTP
•gvfsd-network - proporciona network://
•gvfsd-nfs - monta sobre NFS
•gvfsd-recent - proporciona recent://
•gvfsd-sftp - monta sobre sftp
•gvfsd-smb - monta volúmenes de sistemas de archivos compartidos de Windows
•gvfsd-smb-browse - busca volúmenes de sistemas de archivos compartidos de Windows
•gvfsd-trash - proporciona trash://

AMBIENTE

GIO_USE_VFS

Si se establece, especifica la implementación vfs de GIO a utilizar. Los valores posibles incluyen 'local' y 'gvfs'.

GIO_USE_VOLUME_MONITOR

Si se establece, especifica la implementación del monitor de volumen de GIO a utilizar. Los valores posibles incluyen 'unix', 'GProxyVolumeMonitorUDisks2', así como otros monitores de volumen nativos que se describen en los archivos clave en $XDG_DATA_DIRS/gvfs/remote-volume-monitors.

ARCHIVOS

$XDG_DATA_DIRS/gvfs/mounts

Este directorio contiene archivos clave que describen los demonios de montaje.

$XDG_DATA_DIRS/gvfs/remote-volume-monitors

Este directorio contiene archivos clave que describen los monitores de volumen remotos.
