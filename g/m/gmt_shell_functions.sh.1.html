NAME

gmt_shell_functions.sh — Shell functions for the Generic Mapping Tools

SYNOPSIS

gmt_shell_functions.sh

DESCRIPTION

These are several shell functions that can be used to set up the environment for using GMT. The functions are:

gmt_get_ps_file_name
gmt_get_ps_file_extension
gmt_get_figure_name
gmt_get_projection
gmt_set_ps_file_name
gmt_set_ps_file_extension
gmt_set_figure_name
gmt_set_projection
gmt_check_installed
gmt_make_dirs
gmt_get_home_dir
gmt_is_file
gmt_is_dir
gmt_get_path
gmt_shell_aliases
gmt_shell_unset
gmt_shell_usage
gmt_shell_version

To make these functions available, type:

source /path/to/gmt_shell_functions.sh

in your shell.

NOTES

These functions are primarily intended for use with GMT scripts.

gmt(1), gmt-config(1), gmt_helpers(3), gmtinfo(1), grdinfo(1)
