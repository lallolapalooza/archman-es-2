NOMBRE

gmt-config - Obtener información sobre la instalación de gmt

SINOPSIS

gmt-config [ opciones ]

DESCRIPCIÓN

gmt-config es utilizado por desarrolladores que necesitan conocer información técnica sobre la instalación actual de GMT, como qué archivos de inclusión proporcionar, la ruta de la biblioteca y más.

ARGUMENTOS REQUERIDOS

Ninguno.

ARGUMENTOS OPCIONALES

--help
Mostrar este mensaje de ayuda y salir.
--all
Mostrar todas las opciones.
--bits
Si la biblioteca está compilada en 32 o 64 bits.
--cc
El compilador C utilizado.
--cflags
Las banderas del preprocesador y compilador utilizadas.
--datadir
Los directorios de datos de GMT.
--dataserver
La URL del servidor de datos remoto de GMT.
--dcw
La ubicación de la base de datos DCW.
--dep-libs
Las bibliotecas dependientes.
--gshhg
La ubicación de la base de datos GSHHG.
--has-fftw
Si se utiliza FFTW en la compilación.
--has-pcre
Si se utiliza PCRE en la compilación.
--has-lapack
Si se utiliza LAPACK en la compilación.
--has-openmp
Si GMT fue compilado con soporte OpenMP.
--includedir
El directorio de inclusión.
--libdir
El directorio de la biblioteca.
--libs
La información de enlace de la biblioteca.
--plugindir
El directorio de plugins de GMT.
--prefix
El prefijo de instalación.
--version
La versión de la biblioteca

EJEMPLOS

Para determinar las banderas del compilador que se requieren para que una aplicación externa encuentre los prototipos de funciones de GMT, intente:

gmt-config --cflags
