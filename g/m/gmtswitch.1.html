NOMBRE

gmtswitch - Cambiar entre diferentes versiones de GMT

SINOPSIS

gmtswitch [ D | version ]

INTRODUCCIÓN

gmtswitch le ayuda a modificar su entorno para permitir el cambio entre varias versiones instaladas de GMT. Funciona manteniendo una lista de directorios de instalaciones de GMT en un archivo en su directorio personal, y luego manipula un enlace simbólico para que apunte al directorio de GMT cuyos ejecutables desea usar [La versión de Windows funciona de manera un poco diferente; véase WINDOWS más abajo].

ARGUMENTOS REQUERIDOS

Ninguno. Si no se dan argumentos, se le presenta un menú de versiones de GMT instaladas de 1 a n y usted especifica a cuál desea cambiar.

ARGUMENTOS OPCIONALES

D
Selecciona la versión de GMT predeterminada. Esta es la primera entrada en el archivo ~/.gmtversions
version
Busca una coincidencia única en el archivo ~/.gmtversions. Si se encuentra una coincidencia, cambiamos a esa entrada; de lo contrario, se genera un error. donde módulo es el nombre de un programa de GMT y las opciones son las que corresponden a ese programa en particular.

CONFIGURACIÓN

Si tiene versiones oficiales instaladas, ejecutar gmtswitch por primera vez examinará su disco duro empezando en / y buscará directorios con GMT4, GMT5, etc., en los nombres. Esto fallará al encontrar los directorios de subversiones y posiblemente otros que haya colocado en otro lugar. La forma más rápida de empezar a funcionar es esta:

1.
Editar/Crear ~/.gmtversions y añadir las rutas a todas las instalaciones de GMT
que tenga o desee considerar. Cada ruta va en líneas separadas y apunta al directorio principal de cada distribución, p. ej., /Users/pwessel/UH/RESEARCH/PROJECTS/GMTdev/gmt-4.5.18
2.
En su .bashrc o .[t]csrh o donde esté manteniendo su PATH
o variable path, elimine cualquier directorio que haya añadido que contenga GMT, y añada la nueva ruta $HOME/this_gmt/bin (podría ser $home para usuarios de csh). Asegúrese de que esta ruta aparezca antes de cualquier otra que pueda contener una instalación de GMT, como las usadas por gestores de paquetes (p. ej., /sw/bin para fink, /opt/local/bin para Macports, etc.).
3.
Haga que la nueva ruta surta efecto (salir/reiniciar terminal, cerrar sesión/abrir sesión, etc.).
4.
cd al directorio de GMT más reciente donde existe una versión de gmtswitch,
y ejecute gmtswitch sin argumentos. Seleccione una de las versiones del menú.
5.
Si está en csh, puede tener que decir rehash después.
6.
Escriba "plot -" y la sinopsis debería decirle que tiene la
versión correcta. Ahora puede ejecutar gmtswitch desde cualquier lugar; pruébelo y asegúrese de que puede cambiar entre las versiones.

EJEMPLOS

Para cambiar a la versión de GMT 4.5.18 (suponiendo que se instaló así y no a través de un gestor de paquetes), intente

gmtswitch gmt-4.5.18

Para cambiar a la predeterminada (su primera opción), haga

gmtswitch D

Finalmente, para seleccionar del menú, simplemente ejecute

gmtswitch

y elija la que quiera.

ADVERTENCIA

GMT recuerda dónde se instaló la primera vez y usa ese directorio para encontrar el directorio compartido de GMT predeterminado. Si mueve toda la instalación de GMT después de la compilación, puede que tenga que establecer GMT_SHAREDIR para que apunte al directorio principal para que las cosas funcionen. Es mejor no mover cosas después de la instalación.

WINDOWS

En Windows, use gmtswitch.bat que es un script de lotes que cambia la variable PATH de Windows para que el directorio BIN de la versión preferida siempre venga primero. Para ello, el script de lotes trabaja en dos modos alternativos:

1 - Modo permanente

2 - Modo temporal

El modo permanente utiliza el programa ejecutable gratuito "EditPath" para cambiar la ruta del usuario en el registro. Se llama permanente porque los cambios permanecen hasta ... el próximo cambio. Véase

https://www.softpedia.com/get/Tweak/Registry-Tweak/EditPath.shtml

Por supuesto, el binario editpath.exe también debe estar en la ruta de su sistema. ADVERTENCIA: El cambio de ruta no será visible en el shell cmd donde se ejecutó. Para que el cambio esté activo, necesitará abrir una nueva ventana de cmd.

El segundo modo es temporal porque la ruta al directorio binario de GMT seleccionado se antepone a la ruta anterior a través de una línea de comando del shell. Esta modificación desaparece cuando la ventana de shell cmd donde se ejecuta se cierra.

Es responsabilidad del usuario establecer el contenido de G32_32 a G5_64 más abajo a rutas válidas donde estén instalados los binarios de las diferentes versiones de GMT. Nótese que no es obligatorio tener las cuatro en su computadora. Para las que no tenga, simplemente déjelas apuntando a nada, p. ej.,

set G4_64=

El modo permanente es el predeterminado (pero esto puede cambiarse. Véase la sección de edición) Para ejecutar en modo temporal simplemente dé un segundo argumento (no importa cuál)

Ejemplo de uso para establecer GMT5 64 bits permanente

gmtswitch g5_64

Para establecer temporalmente un GMT4 32 bits haga

gmtswitch g4_32 1

Ejecute sin argumentos para obtener un "Uso" (para el modo permanente)
