NOMBRE

asctime, ctime, gmtime, localtime, mktime, asctime_r, ctime_r, gmtime_r, localtime_r - transformar fecha y hora en tiempo desglosado o ASCII

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <time.h>
char *asctime(const struct tm *tm);
char *asctime_r(const struct tm *restrict tm,
                    char buf[restrict 26]);
char *ctime(const time_t *timep);
char *ctime_r(const time_t *restrict timep,
                    char buf[restrict 26]);

struct tm *gmtime_r(const time_t *restrict timep,

struct tm *localtime(const time_t *timep);
struct tm *localtime_r(const time_t *restrict timep,
                    struct tm *restrict result);

DESCRIPCIÓN

Las funciones ctime(), gmtime() y localtime() toman un argumento de tipo de datos time_t, que representa el tiempo calendario. Cuando se interpreta como un valor de tiempo absoluto, representa el número de segundos transcurridos desde la Época, 1970-01-01 00:00:00 +0000 (UTC).

Las funciones asctime() y mktime() toman un argumento que representa el tiempo desglosado, que es una representación separada en año, mes, día, etc.

El tiempo desglosado se almacena en la estructura tm, descrita en tm(3tipo).

La llamada ctime(t) es equivalente a asctime(localtime(t)). Convierte el tiempo calendario t en una cadena terminada en nulo del formato


"Mié Jun 30 21:49:08 1993\n"

Las abreviaturas de los días de la semana son "Dom", "Lun", "Mar", "Mié", "Jue", "Vie" y "Sáb". Las abreviaturas de los meses son "Ene", "Feb", "Mar", "Abr", "May", "Jun", "Jul", "Ago", "Sep", "Oct", "Nov" y "Dic". El valor de retorno apunta a una cadena estáticamente asignada que puede ser sobrescrita por llamadas posteriores a cualquiera de las funciones de fecha y hora. La función también establece las variables externas tzname, timezone y daylight como si hubiera llamado a tzset(3). La versión reentrante ctime_r() hace lo mismo, pero almacena la cadena en un búfer suministrado por el usuario que debe tener espacio para al menos 26 bytes. No necesita establecer tzname, timezone y daylight.

La función gmtime() convierte el tiempo calendario timep a una representación de tiempo desglosado, expresada en Tiempo Universal Coordinado (UTC). Puede devolver NULL cuando el año no cabe en un entero. El valor de retorno apunta a una estructura estáticamente asignada que puede ser sobrescrita por llamadas posteriores a cualquiera de las funciones de fecha y hora. La función gmtime_r() hace lo mismo, pero almacena los datos en una estructura suministrada por el usuario.

La función localtime() convierte el tiempo calendario timep a una representación de tiempo desglosado, expresada en relación con la zona horaria especificada por el usuario. La función también establece las variables externas tzname, timezone y daylight como si hubiera llamado a tzset(3). El valor de retorno apunta a una estructura estáticamente asignada que puede ser sobrescrita por llamadas posteriores a cualquiera de las funciones de fecha y hora. La función localtime_r() hace lo mismo, pero almacena los datos en una estructura suministrada por el usuario. No necesita establecer tzname, timezone y daylight.

La función asctime() convierte el valor de tiempo desglosado tm en una cadena terminada en nulo con el mismo formato que ctime(). El valor de retorno apunta a una cadena estáticamente asignada que puede ser sobrescrita por llamadas posteriores a cualquiera de las funciones de fecha y hora. La función asctime_r() hace lo mismo, pero almacena la cadena en un búfer suministrado por el usuario que debe tener espacio para al menos 26 bytes.

La función mktime() convierte una estructura de tiempo desglosado, expresada como hora local, a una representación de tiempo calendario. La función ignora los valores suministrados por el llamador en los campos tm_wday y tm_yday. El valor especificado en el campo tm_isdst informa a mktime() si el horario de verano (DST) está o no en vigor para la hora suministrada en la estructura tm: un valor positivo significa que el DST está en vigor; cero significa que el DST no está en vigor; y un valor negativo significa que mktime() debe (utilizar la información de la zona horaria y las bases de datos del sistema para) intentar determinar si el DST está en vigor en el momento especificado. Consulte timegm(3) para una versión equivalente de esta función en UTC.

La función mktime() modifica los campos de la estructura tm de la siguiente manera: tm_wday y tm_yday se establecen con valores determinados a partir del contenido de los otros campos; si los miembros de la estructura están fuera de su intervalo válido, se normalizarán (de modo que, por ejemplo, 40 de octubre se cambie a 9 de noviembre); tm_isdst se establece (independientemente de su valor inicial) en un valor positivo o en 0, respectivamente, para indicar si el DST está o no en vigor en el momento especificado. La función también establece las variables externas tzname, timezone y daylight como si hubiera llamado a tzset(3).

Si el tiempo desglosado especificado no puede representarse como tiempo calendario (segundos desde la Época), mktime() devuelve (time_t) -1 y no altera los miembros de la estructura de tiempo desglosado.

VALOR DE RETORNO

En caso de éxito, gmtime() y localtime() devuelven un puntero a una struct tm.

En caso de éxito, gmtime_r() y localtime_r() devuelven la dirección de la estructura apuntada por result.

En caso de éxito, asctime() y ctime() devuelven un puntero a una cadena.

En caso de éxito, asctime_r() y ctime_r() devuelven un puntero a la cadena apuntada por buf.

En caso de éxito, mktime() devuelve el tiempo calendario (segundos desde la Época), expresado como un valor de tipo time_t.

En caso de error, mktime() devuelve el valor (time_t) -1 y no modifica el miembro tm->tm_wday. Las demás funciones devuelven NULL en caso de error. En caso de error, errno se establece para indicar el error.

ERRORES

EOVERFLOW
El resultado no puede ser representado.

ADVERTENCIAS

Seguridad de hilos

Las cuatro funciones asctime(), ctime(), gmtime(), y localtime() devuelven un puntero a datos estáticos y por lo tanto no son seguras para hilos. Las versiones seguras para hilos, asctime_r(), ctime_r(), gmtime_r(), y localtime_r(), son especificadas por SUSv2.

POSIX.1 dice: "Las funciones asctime(), ctime(), gmtime(), y localtime() devolverán valores en uno de dos objetos estáticos: una estructura de tiempo descompuesta y un array de tipo char. La ejecución de cualquiera de las funciones que devuelven un puntero a uno de estos tipos de objetos puede sobrescribir la información en cualquier objeto del mismo tipo al que apunte el valor devuelto por cualquier llamada previa a cualquiera de ellas." Esto puede ocurrir en la implementación de glibc.

mktime()

(time_t) -1 puede representar un tiempo válido (un segundo antes de la Época). Para determinar si mktime() falló, se debe usar el campo tm->tm_wday . Vea el programa de ejemplo en EJEMPLOS.

El manejo de un tm_isdst no negativo en mktime() está pobremente especificado, y pasar un valor que sea incorrecto para el tiempo especificado produce resultados no especificados. Dado que mktime() es una de las pocas funciones que sabe cuándo está activo el DST, proporcionar un valor correcto puede ser difícil. Una solución para esto es llamar a mktime() dos veces, una vez con tm_isdst establecido a cero, y una vez con tm_isdst establecido a un valor positivo, y descartar los resultados de la llamada que lo cambia. Si ninguna llamada cambia tm_isdst entonces el tiempo especificado probablemente ocurre durante un período de retroceso donde el DST comienza o termina, y ambos resultados son válidos pero representan dos tiempos diferentes. Si ambas llamadas lo cambian, eso podría indicar una transición de avance, u alguna otra razón por la que el tiempo especificado no existe.

La especificación de las zonas horarias y el horario de verano están a cargo de los gobiernos regionales, cambian con frecuencia, y pueden incluir discontinuidades más allá de la capacidad de mktimede documentar un resultado. Por ejemplo, un cambio en la definición de la zona horaria puede causar que una hora del reloj se repita o se omita sin un cambio correspondiente de DST.

Fuente del programa: mktime.c

#include <err.h>
#include <errno.h>
#include <stdint.h>
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <time.h>
#define is_signed(T)  ((T) -1 < 1)
static time_t my_mktime(struct tm *tp);
int
main(int argc, char *argv[])
{
    char       **p;
    time_t     t;
    struct tm  tm;
    if (argc != 8) {
        fprintf(stderr, "Uso: %s aaaa mm dd HH MM SS isdst\n", argv[0]);
        exit(EXIT_FAILURE);
    }
    p = &argv[1];
    tm.tm_year  = atoi(*p++) - 1900;
    tm.tm_mon   = atoi(*p++) - 1;
    tm.tm_mday  = atoi(*p++);
    tm.tm_hour  = atoi(*p++);
    tm.tm_min   = atoi(*p++);
    tm.tm_sec   = atoi(*p++);
    tm.tm_isdst = atoi(*p++);
    errno = 0;
    tm.tm_wday = -1;
    t = my_mktime(&tm);
    if (tm.tm_wday == -1)
        err(EXIT_FAILURE, "mktime");
    if (errno == EINVAL || errno == ENOTUNIQ)
        warn("my_mktime");
    if (is_signed(time_t))
        printf("%jd\n", (intmax_t) t);
    else
        printf("%ju\n", (uintmax_t) t);
    exit(EXIT_SUCCESS);
}
static time_t
my_mktime(struct tm *tp)
{
    int            e, isdst;
    time_t         t;
    struct tm      tm;
    unsigned char  wday[sizeof(tp->tm_wday)];
    e = errno;
    tm = *tp;
    isdst = tp->tm_isdst;
    memcpy(wday, &tp->tm_wday, sizeof(wday));
    tp->tm_wday = -1;
    t = mktime(tp);
    if (tp->tm_wday == -1) {
        memcpy(&tp->tm_wday, wday, sizeof(wday));
        return -1;
    }
    if (isdst == -1)
        tm.tm_isdst = tp->tm_isdst;
    if (   tm.tm_sec   != tp->tm_sec
        || tm.tm_min   != tp->tm_min
        || tm.tm_hour  != tp->tm_hour
        || tm.tm_mday  != tp->tm_mday
        || tm.tm_mon   != tp->tm_mon
        || tm.tm_year  != tp->tm_year
        || tm.tm_isdst != tp->tm_isdst)
    {
        errno = EINVAL;
        return t;
    }
    if (isdst != -1)
        goto out;
    tm = *tp;
    tm.tm_isdst = !tm.tm_isdst;
    tm.tm_wday = -1;
    mktime(&tm);
    if (tm.tm_wday == -1)
        goto out;
    if (tm.tm_isdst != tp->tm_isdst) {
        errno = ENOTUNIQ;
        return t;
    }
out:
    errno = e;
    return t;
}
