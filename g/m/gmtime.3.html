NOMBRE

asctime, ctime, gmtime, localtime, mktime, asctime_r, ctime_r, gmtime_r, localtime_r - transformar fecha y hora a tiempo descompuesto o ASCII

BIBLIOTECA

Biblioteca C estándar (libc,-lc)

SINOPSIS

#include <time.h>
char *asctime(const struct tm *tm);
char *asctime_r(const struct tm *restrict tm,
                    char buf[restrict 26]);
char *ctime(const time_t *timep);
char *ctime_r(const time_t *restrict timep,
                    char buf[restrict 26]);
struct tm *gmtime(const time_t *timep);
struct tm *gmtime_r(const time_t *restrict timep,
                    struct tm *restrict result);
struct tm *localtime(const time_t *timep);
struct tm *localtime_r(const time_t *restrict timep,
                    struct tm *restrict result);
time_t mktime(struct tm *tm);

DESCRIPCIÓN

Las funciones ctime(), gmtime(), y localtime() toman todas un argumento de tipo de datos time_t, que representa tiempo de calendario. Cuando se interpreta como un valor de tiempo absoluto, representa el número de segundos transcurridos desde la Época, 1970-01-01 00:00:00 +0000 (UTC).

Las funciones asctime() y mktime() toman ambas un argumento que representa tiempo descompuesto, que es una representación separada en año, mes, día, etc.

El tiempo descompuesto se almacena en la estructura tm, descrita en tm(3type).

La llamada ctime(t) es equivalente a asctime(localtime(t)). Convierte el tiempo de calendario t en una cadena terminada en nulo de la forma


"Wed Jun 30 21:49:08 1993\n"

Las abreviaturas para los días de la semana son "Sun", "Mon", "Tue", "Wed", "Thu", "Fri", y "Sat". Las abreviaturas para los meses son "Jan", "Feb", "Mar", "Apr", "May", "Jun", "Jul", "Aug", "Sep", "Oct", "Nov", y "Dec". El valor de retorno apunta a una cadena asignada estáticamente que podría ser sobrescrita por llamadas subsecuentes a cualquiera de las funciones de fecha y hora. La función también establece las variables externas tzname, timezone, y daylight como si llamara a tzset(3). La versión reentrante ctime_r() hace lo mismo, pero almacena la cadena en un búfer proporcionado por el usuario que debe tener espacio para al menos 26 bytes. No necesita establecer tzname, timezone, y daylight.

La función gmtime() convierte el tiempo de calendario timep a representación de tiempo descompuesto, expresado en Tiempo Universal Coordinado (UTC). Puede devolver NULL cuando el año no cabe en un entero. El valor de retorno apunta a una estructura asignada estáticamente que podría ser sobrescrita por llamadas subsecuentes a cualquiera de las funciones de fecha y hora. La función gmtime_r() hace lo mismo, pero almacena los datos en una estructura proporcionada por el usuario.

La función localtime() convierte el tiempo de calendario timep a representación de tiempo descompuesto, expresado relativo a la zona horaria especificada por el usuario. La función también establece las variables externas tzname, timezone, y daylight como si llamara a tzset(3). El valor de retorno apunta a una estructura asignada estáticamente que podría ser sobrescrita por llamadas subsecuentes a cualquiera de las funciones de fecha y hora. La función localtime_r() hace lo mismo, pero almacena los datos en una estructura proporcionada por el usuario. No necesita establecer tzname, timezone, y daylight.

La función asctime() convierte el valor de tiempo descompuesto tm en una cadena terminada en nulo con el mismo formato que ctime(). El valor de retorno apunta a una cadena asignada estáticamente que podría ser sobrescrita por llamadas subsecuentes a cualquiera de las funciones de fecha y hora. La función asctime_r() hace lo mismo, pero almacena la cadena en un búfer proporcionado por el usuario que debe tener espacio para al menos 26 bytes.

La función mktime() convierte una estructura de tiempo descompuesto, expresada como hora local, a representación de tiempo de calendario. La función ignora los valores proporcionados por el llamador en los campos tm_wday y tm_yday . El valor especificado en el campo tm_isdst informa a mktime() si el horario de verano (DST) está o no en efecto para el tiempo proporcionado en la estructura tm : un valor positivo significa que el DST está en efecto; cero significa que el DST no está en efecto; y un valor negativo significa que mktime() debe (usar información de zona horaria y bases de datos del sistema para) intentar determinar si el DST está en efecto en el tiempo especificado. Ver timegm(3) para un equivalente UTC de esta función.

La función mktime() modifica los campos de la estructura tm de la siguiente manera: tm_wday y tm_yday se establecen a valores determinados a partir del contenido de los otros campos; si los miembros de la estructura están fuera de su intervalo válido, serán normalizados (de manera que, por ejemplo, 40 de octubre se cambia a 9 de noviembre); tm_isdst se establece (independientemente de su valor inicial) a un valor positivo o a 0, respectivamente, para indicar si el DST está o no en efecto en el tiempo especificado. La función también establece las variables externas tzname, timezone, y daylight como si llamara a tzset(3).

Si el tiempo descompuesto especificado no puede ser representado como tiempo de calendario (segundos desde la Época), mktime() devuelve (time_t) -1 y no altera los miembros de la estructura de tiempo descompuesto.

VALOR DE RETORNO

En caso de éxito, gmtime() y localtime() devuelven un puntero a un struct tm.

En caso de éxito, gmtime_r() y localtime_r() devuelven la dirección de la estructura apuntada por result.

En caso de éxito, asctime() y ctime() devuelven un puntero a una cadena.

En caso de éxito, asctime_r() y ctime_r() devuelven un puntero a la cadena apuntada por buf.

En caso de éxito, mktime() devuelve el tiempo de calendario (segundos desde la Época), expresado como un valor de tipo time_t.

En caso de error, mktime() devuelve el valor (time_t) -1, y deja el miembro tm->tm_wday sin modificar. Las funciones restantes devuelven NULL en caso de error. En caso de error, errno se establece para indicar el error.

ERRORES

EOVERFLOW
El resultado no puede ser representado.

ADVERTENCI

AS

Seguridad de

hilos

Las cuatro funciones asctime(), ctime(), gmtime() y localtime() devuelven un puntero a datos estáticos y por lo tanto no son seguras en hilos. Las versiones seguras en hilos, asctime_r(), ctime_r(), gmtime_r() y localtime_r(), están especificadas por

SUSv2.

POSIX.1 dice: "Las asctime(), ctime(), gmtime() y localtime() devolverán valores en uno de dos objetos estáticos: una estructura de tiempo descompuesta y un array de tipo char. La ejecución de cualquiera de las funciones que devuelven un puntero a uno de estos tipos de objetos puede sobrescribir la información en cualquier obje

to del mismo tipo al que apunte el valor devuelto por cualquier llamada anter
ior a cualquiera de ellas." Esto puede ocurrir en la implementación de glibc.

)

(time_t) -1 puede representar una hora válida (un segundo antes de la Época). Para determinar si mktime() falló, se debe usar el campo tm->tm_wday. Vea el programa de ejemplo en

EJEMPLOS.

El manejo de un tm_isdst no negativo en mktime() está mal especificado, y pasar un valor que es incorrecto para la hora especificada produce resultados no especificados. Dado que mktime() es una de las pocas funciones que sabe cuándo está activo el horario de verano (DST), proporcionar un valor correcto puede ser difícil. Una solución para esto es llamar a mktime() dos veces, una con tm_isdst establecido a cero, y una con tm_isdst establecido a un valor positivo, y descartar los resultados de la llamada que lo cambia. Si ninguna llamada cambia tm_isdst, entonces la hora especificada probablemente ocurre durante un período de retroceso donde el DST comienza o termina, y ambos resultados son válidos pero representan dos horas diferentes. Si ambas llamadas lo cambian, eso podría indicar un avance, o alguna otra razón por la que la hora especificada no

existe.

La especificación de las zonas horarias y el horario de verano depende de los gobiernos regionales, cambia con frecuencia y puede incluir discontinuidades más allá de la capacidad de mktime de documentar un resultado. Por ejemplo, un cambio en la de

finición de la zona horaria puede causar qu
e una hora del reloj se repita o se omita s
in un cambio correspondiente en el DST.

c 
#include <err.h>
#include <errno.h>
#include <stdint.h>
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <time.h>
#define is_signed(T)  ((T) -1 < 1)
static time_t my_mktime(struct tm *tp);
int
main(int argc, char *argv[])
{
    char       **p;
    time_t     t;
    struct tm  tm;
    if (argc != 8) {
        fprintf(stderr, "Usage: %s yyyy mm dd HH MM SS isdst\n", argv[0]);
        exit(EXIT_FAILURE);
    }
    p = &argv[1];
    tm.tm_year  = atoi(*p++) - 1900;
    tm.tm_mon   = atoi(*p++) - 1;
    tm.tm_mday  = atoi(*p++);
    tm.tm_hour  = atoi(*p++);
    tm.tm_min   = atoi(*p++);
    tm.tm_sec   = atoi(*p++);
    tm.tm_isdst = atoi(*p++);
    errno = 0;
    tm.tm_wday = -1;
    t = my_mktime(&tm);
    if (tm.tm_wday == -1)
        err(EXIT_FAILURE, "mktime");
    if (errno == EINVAL || errno == ENOTUNIQ)
        warn("my_mktime");
    if (is_signed(time_t))
        printf("%jd\n", (intmax_t) t);
    else
        printf("%ju\n", (uintmax_t) t);
    exit(EXIT_SUCCESS);
}
static time_t
my_mktime(struct tm *tp)
{
    int            e, isdst;
    time_t         t;
    struct tm      tm;
    unsigned char  wday[sizeof(tp->tm_wday)];
    e = errno;
    tm = *tp;
    isdst = tp->tm_isdst;
    memcpy(wday, &tp->tm_wday, sizeof(wday));
    tp->tm_wday = -1;
    t = mktime(tp);
    if (tp->tm_wday == -1) {
        memcpy(&tp->tm_wday, wday, sizeof(wday));
        return -1;
    }
    if (isdst == -1)
        tm.tm_isdst = tp->tm_isdst;
    if (   tm.tm_sec   != tp->tm_sec
        || tm.tm_min   != tp->tm_min
        || tm.tm_hour  != tp->tm_hour
        || tm.tm_mday  != tp->tm_mday
        || tm.tm_mon   != tp->tm_mon
        || tm.tm_year  != tp->tm_year
        || tm.tm_isdst != tp->tm_isdst)
    {
        errno = EINVAL;
        return t;
    }
    if (isdst != -1)
        goto out;
    tm = *tp;
    tm.tm_isdst = !tm.tm_isdst;
    tm.tm_wday = -1;
    mktime(&tm);
    if (tm.tm_wday == -1)
        goto out;
    if (tm.tm_isdst != tp->tm_isdst) {
        errno = ENOTUNIQ;
        return t;
    }
out:
    errno = e;
    return
t;
}
