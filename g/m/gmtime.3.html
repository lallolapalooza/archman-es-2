ADVERTENCI

AS

Seguridad de

hilos

Las cuatro funciones asctime(), ctime(), gmtime() y localtime() devuelven un puntero a datos estáticos y por lo tanto no son seguras en hilos. Las versiones seguras en hilos, asctime_r(), ctime_r(), gmtime_r() y localtime_r(), están especificadas por

SUSv2.

POSIX.1 dice: "Las asctime(), ctime(), gmtime() y localtime() devolverán valores en uno de dos objetos estáticos: una estructura de tiempo descompuesta y un array de tipo char. La ejecución de cualquiera de las funciones que devuelven un puntero a uno de estos tipos de objetos puede sobrescribir la información en cualquier obje

to del mismo tipo al que apunte el valor devuelto por cualquier llamada anter
ior a cualquiera de ellas." Esto puede ocurrir en la implementación de glibc.

mktime(

)

(time_t) -1 puede representar una hora válida (un segundo antes de la Época). Para determinar si mktime() falló, se debe usar el campo tm->tm_wday. Vea el programa de ejemplo en

EJEMPLOS.

El manejo de un tm_isdst no negativo en mktime() está mal especificado, y pasar un valor que es incorrecto para la hora especificada produce resultados no especificados. Dado que mktime() es una de las pocas funciones que sabe cuándo está activo el horario de verano (DST), proporcionar un valor correcto puede ser difícil. Una solución para esto es llamar a mktime() dos veces, una con tm_isdst establecido a cero, y una con tm_isdst establecido a un valor positivo, y descartar los resultados de la llamada que lo cambia. Si ninguna llamada cambia tm_isdst, entonces la hora especificada probablemente ocurre durante un período de retroceso donde el DST comienza o termina, y ambos resultados son válidos pero representan dos horas diferentes. Si ambas llamadas lo cambian, eso podría indicar un avance, o alguna otra razón por la que la hora especificada no

existe.

La especificación de las zonas horarias y el horario de verano depende de los gobiernos regionales, cambia con frecuencia y puede incluir discontinuidades más allá de la capacidad de mktime de documentar un resultado. Por ejemplo, un cambio en la de

finición de la zona horaria puede causar qu
e una hora del reloj se repita o se omita s
in un cambio correspondiente en el DST.

#define is_signed(T)  ((T) -1 < 1)
static time_t my_mktime(struct tm *tp);
int
main(int argc, char *argv[])
{
    char       **p;
    time_t     t;
    struct tm  tm;
    if (argc != 8) {
        fprintf(stderr, "Usage: %s yyyy mm dd HH MM SS isdst\n", argv[0]);
        exit(EXIT_FAILURE);
    }
    p = &argv[1];
    tm.tm_year  = atoi(*p++) - 1900;
    tm.tm_mon   = atoi(*p++) - 1;
    tm.tm_mday  = atoi(*p++);
    tm.tm_hour  = atoi(*p++);
    tm.tm_min   = atoi(*p++);
    tm.tm_sec   = atoi(*p++);
    tm.tm_isdst = atoi(*p++);
    errno = 0;
    tm.tm_wday = -1;
    t = my_mktime(&tm);
    if (tm.tm_wday == -1)
        err(EXIT_FAILURE, "mktime");
    if (errno == EINVAL || errno == ENOTUNIQ)
        warn("my_mktime");
    if (is_signed(time_t))
        printf("%jd\n", (intmax_t) t);
    else
        printf("%ju\n", (uintmax_t) t);
    exit(EXIT_SUCCESS);
}
static time_t
my_mktime(struct tm *tp)
{
    int            e, isdst;
    time_t         t;
    struct tm      tm;
    unsigned char  wday[sizeof(tp->tm_wday)];
    e = errno;
    tm = *tp;
    isdst = tp->tm_isdst;
    memcpy(wday, &tp->tm_wday, sizeof(wday));
    tp->tm_wday = -1;
    t = mktime(tp);
    if (tp->tm_wday == -1) {
        memcpy(&tp->tm_wday, wday, sizeof(wday));
        return -1;
    }
    if (isdst == -1)
        tm.tm_isdst = tp->tm_isdst;
    if (   tm.tm_sec   != tp->tm_sec
        || tm.tm_min   != tp->tm_min
        || tm.tm_hour  != tp->tm_hour
        || tm.tm_mday  != tp->tm_mday
        || tm.tm_mon   != tp->tm_mon
        || tm.tm_year  != tp->tm_year
        || tm.tm_isdst != tp->tm_isdst)
    {
        errno = EINVAL;
        return t;
    }
    if (isdst != -1)
        goto out;
    tm = *tp;
    tm.tm_isdst = !tm.tm_isdst;
    tm.tm_wday = -1;
    mktime(&tm);
    if (tm.tm_wday == -1)
        goto out;
    if (tm.tm_isdst != tp->tm_isdst) {
        errno = ENOTUNIQ;
        return t;
    }

    errno = e;
    return
t;

    gmtime(3)

    NOMBRE
    gmtime, gmtime_r, gmtime_s - convertir tiempo en estructura tm (UTC)

    SINÓPSIS

    #include <time.h>

struct tm *gmtime(const time_t *timep);
struct tm *gmtime_r(const time_t *timep, struct tm *result);
struct tm *gmtime_s(const time_t *timep, struct tm *result);

    DESCRIPCIÓN
    La función gmtime() convierte el valor de tiempo representado por timep a un valor de tiempo expresado como el número de segundos transcurridos desde la Época (00:00:00 UTC, 1 de enero de 1970) y lo devuelve como una estructura tm. El resultado se almacena en un búfer estático que es compartido por todas las llamadas a gmtime() y localtime(). Si se llama a ambas funciones, la segunda llamada sobrescribirá la primera. La estructura tm contiene los siguientes campos: 

       int tm_sec;   // segundos, 0-60
   int tm_min;   // minutos, 0-59
   int tm_hour;  // horas, 0-23
   int tm_mday;  // día del mes, 1-31
   int tm_mon;   // mes, 0-11
   int tm_year;  // años desde 1900
   int tm_wday;  // días de la semana, 0-6 (domingo = 0)
   int tm_yday;  // día del año, 0-365
   int tm_isdst; // no usado

    gmtime_r() y gmtime_s() son versiones reentrantes de gmtime(). Convierten el tiempo dado en timep a una estructura tm y almacenan el resultado en la estructura proporcionada por el llamador en result.

    gmtime_s() es una versión segura que garantiza que no habrá desbordamiento del búfer, incluso si el llamador proporciona un puntero NULL. Sin embargo, esta función no está estandarizada y no se proporciona en todas las implementaciones de C.

    VALOR DE RETORNO
    La función gmtime() devuelve un puntero a la estructura tm que representa el tiempo en UTC. Si ocurre un error, se devuelve NULL.

    Las funciones gmtime_r() y gmtime_s() devuelven un puntero a la estructura tm en result si tienen éxito, o NULL si ocurre un error (por ejemplo, si result es NULL).

    ERRORES
    No se definen errores específicos para gmtime(), gmtime_r() y gmtime_s(). Sin embargo, si el valor de timep no es representable como un tiempo en UTC, se puede devolver NULL.

    ESTÁNDARES
    La función gmtime() está definida por la norma C. Las funciones gmtime_r() y gmtime_s() no son estándares POSIX ni C, aunque gmtime_r() es común en sistemas tipo Unix.

    HISTORIA
    La función gmtime() apareció en Version 7 Unix.

    ADVERTENCIAS
    El valor de retorno de gmtime() apunta a una ubicación estática que puede ser sobrescrita por llamadas posteriores a gmtime() o localtime(). Si necesita conservar el resultado, debe copiarlo en su propia estructura. Las versiones gmtime_r() y gmtime_s() evitan este problema al permitir que el llamador proporcione su propio búfer de resultados.

    EJEMPLOS
    ```c #include <stdio.h> #include <time.h> int main() { time_t t = time(NULL); struct tm *data; data = gmtime(&t); if (data == NULL) { perror("gmtime"); return 1; } printf("Tiempo actual en UTC: %d/%d/%d %d:%d:%d\n", data->tm_mday, data->tm_mon + 1, data->tm_year + 1900, data->tm_hour, data->tm_min, data->tm_sec); return 0; } ```
