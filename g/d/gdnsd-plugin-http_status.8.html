gdnsd-plugin-http_status(8)

Paquete: gdnsd

Licencias: GPL3

GDNSD-PLUGIN-HTTP_STATUS(8) gdnsd GDNSD-PLUGIN-HTTP_STATUS(8)

NOMBRE

gdnsd-plugin-http_status - plugin de monitoreo HTTP de gdnsd

SINOPSIS

Ejemplo de configuración de service_types http_status:

service_types => {
  webcheck => {
    plugin => http_status,
    port => 8080,             # por defecto 80
    url_path => /checkme      # por defecto '/'
    vhost => www.example.com  # por defecto none
    ok_codes => [ 200, 301 ], # por defecto [ 200 ]
    up_thresh => 20,
    ok_thresh => 10,
    down_thresh => 10,
    interval => 10,
    timeout => 3,
  }
}

DESCRIPCIÓN

gdnsd-plugin-http_status es un plugin de monitoreo que verifica un servicio HTTP básico.

PARÁMETROS

port
El número de puerto numérico al que conectarse, por defecto 80.
url_path
La cadena de URL a obtener del servicio remoto, por defecto "/"
vhost
El nombre de host de la cadena a proporcionar como encabezado "Host:" con la solicitud. Sin valor por defecto. Si no se especifica, no se envía ningún encabezado "Host:".
ok_codes
Una matriz de códigos de estado HTTP enteros que son aceptables como respuestas positivas. El valor predeterminado es "[ 200 ]".
