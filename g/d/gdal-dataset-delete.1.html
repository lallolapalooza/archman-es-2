NOMBRE

gdal-dataset-delete - Eliminar conjunto(s) de datos

Añadido en la versión 3.12.

gdal dataset delete elimina conjunto(s) de datos, incluidos los posibles archivos auxiliares/asociados.

SINOPSIS

Uso: gdal dataset delete [OPCIONES] <NOMBRE_ARCHIVO>
Eliminar conjunto(s) de datos.
Argumentos posicionales:
  --filename <NOMBRE_ARCHIVO>   Nombre de archivo o directorio [puede repetirse] [requerido]
Opciones comunes:
  -h, --help              Mostrar mensaje de ayuda y salir
  --json-usage            Mostrar uso como documento JSON y salir
  --config <CLAVE>=<VALOR>  Opción de configuración [puede repetirse]
Opciones avanzadas:
  -f, --format <FORMATO>   Formato del conjunto de datos

OPCIONES

--filename <NOMBRE_ARCHIVO>
Cualquier nombre de archivo o directorio. Requerido. Puede repetirse.
-f, --format <FORMATO>
Formato del conjunto de datos. Útil si la detección automática no funciona.

EJEMPLOS

Ejemplo 1: Eliminar un conjunto de datos

$ gdal dataset delete NE1_50M_SR_W.tif
