NOMBRE

gdal-raster-create - Crea un nuevo conjunto de datos ráster

Añadido en la versión 3.11.

SINOPSIS

Uso: gdal raster create [OPCIONES] <SALIDA>
Crea un nuevo conjunto de datos ráster.
Argumentos posicionales:
  -o, --output <SALIDA>                                    Conjunto de datos ráster de salida (creado por el algoritmo) [requerido]
Opciones comunes:
  -h, --help                                               Muestra el mensaje de ayuda y sale
  --json-usage                                             Muestra el uso como un documento JSON y sale
  --config <CLAVE>=<VALOR>                                   Opción de configuración [puede repetirse]
  -q, --quiet                                              Modo silencioso (sin barra de progreso)
Opciones:
  -f, --of, --format, --output-format <FORMATO-SALIDA>      Formato de salida
  -i, --like, --input <ENTRADA>                              Conjunto de datos ráster de entrada
  --co, --creation-option <CLAVE>=<VALOR>                    Opción de creación [puede repetirse]
  --overwrite                                              Si se permite sobrescribir la salida existente
                                                           Mutuamente excluyente con --append
  --append                                                 Añadir como subconjunto de datos a la salida existente
                                                           Mutuamente excluyente con --overwrite
  --size <ancho>,<alto>                                  Tamaño de salida en píxeles
  --band-count <NUMERO-BANDAS>                                Número de bandas (por defecto: 1)
  --ot, --datatype, --output-data-type <TIPO-DATO-SALIDA>  Tipo de dato de salida. TIPO-DATO-SALIDA=Byte|Int8|UInt16|Int16|UInt32|Int32|UInt64|Int64|CInt16|CInt32|Float16|Float32|Float64|CFloat32|CFloat64 (por defecto: Byte)
  --nodata <NODATA>                                        Asigna un valor nodata especificado a las bandas de salida ('none', valor numérico, 'nan', 'inf', '-inf')
  --burn <QUEMAR>                                            Valor a quemar [puede repetirse]
  --crs <CRS>                                              Establecer CRS
  --bbox <BBOX>                                            Caja delimitadora como xmin,ymin,xmax,ymax
  --metadata <CLAVE>=<VALOR>                                 Añadir elemento de metadatos [puede repetirse]
  --copy-metadata                                          Copiar metadatos del conjunto de datos de entrada
  --copy-overviews                                         Crear los mismos niveles de vistas previas que el conjunto de datos de entrada
Opciones avanzadas:
  --oo, --open-option <CLAVE>=<VALOR>                        Opciones de apertura [puede repetirse]
  --if, --input-format <FORMATO-ENTRADA>                      Formatos de entrada [puede repetirse]

DESCRIPCIÓN

gdal raster create se puede usar para inicializar un nuevo archivo ráster, a partir de sus dimensiones, número de bandas, CRS, transformación afín, valor nodata y metadatos.

El nuevo archivo también se puede inicializar a partir de un archivo de entrada modelo con la opción opcional --like, copiando sus propiedades pero no sus valores de píxeles. Por defecto, los metadatos y la estructura de las vistas previas no se copian del archivo de entrada modelo, a menos que se especifiquen --copy-metadata y --copy-overviews. Las opciones --size, --band-count, --datatype, --nodata, --crs, --bbox, --metadata se pueden usar para anular los valores heredados del archivo de entrada modelo.

Para la salida GeoTIFF, establecer la opción de creación SPARSE_OK a YES puede ser útil para crear un archivo de tamaño mínimo.

gdal raster create también se puede usar en casos especiales, como la creación de un archivo PDF a partir de un archivo de composición XML.

Opciones

--like, --like <DATASET>
Nombre del conjunto de datos de entrada GDAL que sirve como plantilla para los valores por defecto de las opciones --size, --band-count, --datatype, --crs, --bbox y --nodata. Tenga en cuenta que los valores de los píxeles no se copiarán.
--co <NOMBRE>=<VALOR>
Muchos formatos tienen una o más opciones de creación opcionales que se pueden usar para controlar detalles específicos del archivo creado. Por ejemplo, el controlador GeoTIFF admite opciones de creación para controlar la compresión y si el archivo debe estar en mosaicos.

Puede repetirse.

Las opciones de creación disponibles varían según el controlador de formato, y algunos formatos simples no tienen opciones de creación en absoluto. Una lista de opciones compatibles con un formato se puede listar con la opción de línea de comandos --formats, pero la documentación del formato es la fuente definitiva de información sobre las opciones de creación del controlador. Consulte la documentación específica del formato de Controladores ráster para ver las opciones de creación legales para cada formato.

--overwrite
Permite al programa sobrescribir el archivo o conjunto de datos de destino existente. De lo contrario, por defecto, gdal genera un error si el archivo o conjunto de datos de destino ya existe.
--append
Añade el nuevo ráster como un nuevo subconjunto de datos al archivo de salida existente. Solo funciona con controladores que admiten la adición de subconjuntos de datos, como GTiff -- Formato de archivo GeoTIFF y GPKG -- Ríster GeoPackage.
--size <tamaño-x>,<tamaño-y>
Establece el tamaño del archivo de salida en píxeles. El primer valor es el ancho. El segundo es la altura.
--band-count <número>
Número de bandas. Por defecto es 1.
--ot, --datatype, --output-data-type <TIPO-DATO-SALIDA>
Tipo de dato de salida entre Byte, Int8, UInt16, Int16, UInt32, Int32, UInt64, Int64, CInt16, CInt32, Float32, Float64, CFloat32, CFloat64.
--nodata <valor>
Establece el valor nodata.

Se pueden especificar null o none para desestablecer el valor nodata existente del conjunto de datos --like si está establecido. También se aceptan nan, inf o -inf para rásteres de punto flotante para significar respectivamente los valores especiales no es un número, infinito positivo e infinito negativo.

--burn <valor>
Un valor fijo para grabar en una banda. Se puede suministrar una lista de opciones --burn, una por banda (el primer valor se aplicará a la primera banda, el segundo a la segunda banda, etc.). Si se especifica un único valor, se aplicará a todas las bandas.
--crs <CRS>
Establece el CRS.

Los sistemas de referencia de coordenadas que se pueden pasar son cualquiera soportado por la llamada OGRSpatialReference::SetFromUserInput(), que incluye CRS Proyectados, Geográficos o Compuestos EPSG (por ejemplo, EPSG:4296), una definición de CRS en texto conocido (WKT), declaraciones PROJ.4, o el nombre de un archivo .prj que contiene una definición de CRS en WKT.

Se pueden especificar null o none para desestablecer el CRS existente del conjunto de datos --like si está establecido.

Tenga en cuenta que la extensión espacial tampoco se modifica.

--bbox <xmin>,<ymin>,<xmax>,ymax>
Establece la caja delimitadora espacial, en unidades CRS. 'x' son valores de longitud para CRS geográficos y este para CRS proyectados. 'y' son valores de latitud para CRS geográficos y norte para CRS proyectados.
--metadata <CLAVE>=<VALOR>
Añade un elemento de metadatos, a nivel de conjunto de datos.
--copy-metadata
Copia los metadatos del conjunto de datos y las bandas ráster de entrada. Requiere que se especifique --like.
--copy-overviews
Crea los mismos niveles de vistas previas que el conjunto de datos de entrada. Requiere que se especifique --like.

EJEMPLOS

Crear un archivo GeoTIFF de 100x50 píxeles:
$ gdal raster create -of GTiff --size 100,50 out.tif

Crear un archivo GeoTIFF de 100x50 píxeles, de tipo Byte, con CRS EPSG:4326 y que contenga el valor nodata 255:
$ gdal raster create -of GTiff --size 100,50 --ot Byte --nodata 255 --crs EPSG:4326 out.tif

Crear un archivo GeoTIFF basado en la estructura de otro archivo existente, pero con diferente tamaño y sin valor nodata:
$ gdal raster create --like existing.tif --size 200,150 --nodata none out.tif

Crear un archivo GeoTIFF con dos bandas, donde la primera banda se quema con el valor 10 y la segunda con el valor 20:
$ gdal raster create -of GTiff --size 100,50 --band-count 2 --burn 10 --burn 20 out.tif
