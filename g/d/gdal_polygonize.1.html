NOMBRE

gdal_polygonize - Produce una capa de características de polígonos a partir de un ráster.

SINOPSIS

gdal_polygonize [--help] [--help-general]
                   [-8] [-o <nombre>=<valor>]... [-nomask]
                   [-mask <archivo>] <archivo_ráster> [-b <banda>]
                   [-q] [-f <formato_ogr>] [-lco <nombre>=<valor>]...
                   [-overwrite] <archivo_salida> [<capa>] [<nombre_campo>]

DESCRIPCIÓN

Esta utilidad crea polígonos vectoriales para todas las regiones conectadas de píxeles en el ráster que comparten un valor de píxel común. Cada polígono se crea con un atributo que indica el valor de píxel de ese polígono. También se puede proporcionar una máscara ráster para determinar qué píxeles son elegibles para el procesamiento.

La utilidad creará el origen de datos vectorial de salida si no existe, de lo contrario, intentará añadir a uno existente.

La utilidad se basa en la función :GDALPolygonize() que tiene detalles adicionales sobre el algoritmo.

NOTA:

gdal_polygonize es una utilidad de Python y solo está disponible si los enlaces de Python de GDAL están disponibles.
--help
Mostrar este mensaje de ayuda y salir
--help-general
Muestra un breve mensaje de uso para las opciones genéricas de línea de comandos de GDAL y sale.
-8
Usar conectividad de 8. Por defecto es conectividad de 4.
-nomask
No usar la máscara de validez predeterminada para la banda de entrada (como máscaras nodata o alfa).
-mask <archivo>
Usar la primera banda del archivo especificado como máscara de validez (cero es inválido, distinto de cero es válido). Si no se especifica, se usará la máscara de validez predeterminada para la banda de entrada (como máscaras nodata o alfa) (a menos que se especifique -nomask)
<archivo_ráster>
El archivo ráster de origen del cual se derivan los polígonos.
-b <banda>
La banda en <archivo_ráster> para construir los polígonos. El valor también se puede establecer en "mask", para indicar que se debe usar la banda de máscara de la primera banda (o "mask,número_banda" para la máscara de una banda especificada)
-f <formato_ogr>
Seleccionar el formato de salida. Si no se especifica, el formato se adivina a partir de la extensión. Usar el nombre corto del formato
-o <NOMBRE>=<VALOR>
Añadido en la versión 3.7.

Opción de poligonización. Consulte la documentación de :GDALPolygonize().

-lco <NOMBRE>=<VALOR>
Añadido en la versión 3.7.

Opción de creación de capa (específica del formato)

-overwrite
Añadido en la versión 3.8.

Sobrescribir la capa de salida si ya existe.

<archivo_salida>
El archivo vectorial de destino donde se escribirán los polígonos.
<capa>
El nombre de la capa creada para contener las características del polígono.
<nombre_campo>
El nombre del campo a crear (por defecto es "DN").
-q
El script se ejecuta en modo silencioso. El monitor de progreso se suprime y los mensajes de rutina no se muestran.
