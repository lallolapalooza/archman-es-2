gdump(1) Manual de usuario de Scotch gdump(1)

NOMBRE

gdump - vuelca el contenido de un grafo fuente como código fuente

SINOPSIS

gdump [opciones] [archivo_entrada] [archivo_salida]

DESCRIPCIÓN

El programa gdump permite crear un equivalente en código fuente para la carga de un grafo fuente centralizado. El contenido del grafo fuente se representa como arrays de datos que se ensamblan llamando a la rutina SCOTCH_graphBuild de la biblioteca libScotch.

OPCIONES

-b?base
Establece el valor de base del grafo descrito por el código fuente.
-h
Muestra ayuda.
-p?prefijo
Establece el prefijo que se añadirá a todos los nombres de arrays y al nombre de la función de construcción del grafo.
-s?sufijo
Establece el sufijo que se añadirá a todos los nombres de arrays y al nombre de la función de construcción del grafo.
-V
Muestra la versión del programa y los derechos de autor.

EJEMPLO

Crea un archivo fuente C 'brol.c' que corresponde al grafo 'brol.grf', con el identificador y el nombre de la función de creación con el sufijo '_brol'.

    $ gdump -s_brol brol.grf brol.c
