DESCRIPCIÓ

N

gdal vector edit se puede utilizar para editar los metadatos de un conjunto de datos vectorial: su SRC, el tipo de geometría de la capa, los metadatos del conjunto de datos y de la

capa.

edit también se puede usar como un paso de gdal vector p

Nombre del formato/controlador que se intentará para abrir el(los) archivo(s) de entrada. Generalmente no es necesario especificarlo, pero se puede usar para omitir la detección automática de controladores, cuando falla al seleccionar el controlador apropiado.
