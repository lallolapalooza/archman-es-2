NOMBRE

gdal_rasterize - Graba geometrías vectoriales en un ráster.

SINOPSIS

Uso: gdal_rasterize [--help] [--long-usage] [--help-general]
                      [-b <banda>]... [-i] [-at]
                      [[-burn <valor>]...|[-a <nombre_atributo>]|[-3d]]
                      [-add]
                      [[-l <nombre_capa>]...|[-sql <sentencia_sql>]]
                      [-where <expresion>] [-dialect <dialecto_sql>]
                      [-a_nodata <valor>] [-init <valor>]... [-a_srs <definicion_srs>]
                      [-to <NOMBRE>=<VALOR>]... [-te <xmin> <ymin> <xmax> <ymax>]
                      [[-tr <res_x> <res_y>]|[-ts <ancho> <alto>]]
                      [-tap] [-optim AUTO|VECTOR|RASTER] [-co <NOMBRE>=<VALOR>]...
                      [-ot Byte|Int8|[U]Int{16|32|64}|CInt{16|32}|[C]Float{32|64}]
                      [-of <formato_salida>] [--quiet] [-oo <NOMBRE>=<VALOR>]...
                      <fuente_datos_origen> <archivo_destino>

DESCRIPCIÓN

Este programa graba geometrías vectoriales (puntos, líneas y polígonos) en la(s) banda(s) ráster de una imagen ráster. Los vectores se leen de formatos vectoriales compatibles con OGR. Si el ráster de salida ya existe, los píxeles afectados se actualizan in situ.

Se soporta la reproyección sobre la marcha de datos vectoriales al sistema de coordenadas de los datos ráster.

--help
Muestra este mensaje de ayuda y sale.
--help-general
Proporciona un breve mensaje de uso para las opciones genéricas de línea de comandos de GDAL y sale.
-b <banda>
La(s) banda(s) en la(s) que grabar los valores. Se pueden usar múltiples argumentos -b para grabar en una lista de bandas. El valor por defecto es grabar en la banda 1. No se usa al crear un nuevo ráster.
-i
Invertir rasterización. Graba el valor fijo de grabación, o el valor de grabación asociado a la primera característica en todas las partes de la imagen *no* dentro del polígono proporcionado.

NOTA:

Cuando las características vectoriales contienen un polígono anidado dentro de otro polígono (como una isla en un lago), GDAL debe ser compilado contra GEOS para obtener resultados correctos.
-at
Habilita la opción de rasterización ALL_TOUCHED, de modo que se actualizarán todos los píxeles tocados por líneas o polígonos, no solo aquellos en la ruta de renderizado de la línea, o cuyo centro esté dentro del polígono (el comportamiento no está especificado cuando el polígono solo toca el centro del píxel). Por defecto está deshabilitado para las reglas de renderizado normales.

NOTA:

Cuando esta opción está habilitada, el orden de las características de entrada (líneas o polígonos) puede afectar los resultados. Cuando dos características se tocan, la última (es decir, la más superior) determinará el valor del píxel grabado en el borde. Es posible que desees usar la opción -sql para reordenar las características (ORDER BY) para lograr un resultado más predecible.
-burn <valor>
Un valor fijo para grabar en una banda para todos los objetos. Se puede suministrar una lista de opciones -burn, una por banda que se esté escribiendo.
-a <nombre_atributo>
Identifica un campo de atributo en las características para ser usado como valor de grabación. El valor se grabará en todas las bandas de salida.
-3d
Indica que se debe extraer un valor de grabación de los valores "Z" de la característica. Funciona con puntos y líneas (interpolación lineal a lo largo de cada segmento). Para polígonos, solo funciona correctamente si son planos (mismo valor Z para todos los vértices).
-add
En lugar de grabar un nuevo valor, este añade el nuevo valor al ráster existente. Adecuado para mapas de calor, por ejemplo.
-l <nombre_capa>
Indica la(s) capa(s) de la fuente de datos que se usarán para las características de entrada. Se puede especificar varias veces, pero se debe especificar al menos un nombre de capa o una opción -sql (no ambos).
-where <expresion>
Una expresión de consulta opcional estilo WHERE SQL para ser aplicada y seleccionar características para grabar desde la(s) capa(s) de entrada.
-sql <sentencia_select>
Una sentencia SQL para ser evaluada contra la fuente de datos para producir una capa virtual de características para grabar. A partir de GDAL 3.7, se puede usar la sintaxis @nombre_archivo para indicar que el contenido está en el archivo indicado.

NOTA:

Esta opción se ignorará si también se ha establecido la opción -l.
-dialect <dialecto>
Dialecto SQL. En algunos casos se puede usar OGR SQL (no optimizado) en lugar del SQL nativo de un RDBMS pasando OGRSQL. El dialecto "SQLITE" también se puede usar con cualquier fuente de datos.
-of <formato>
Selecciona el formato de salida. Si no se especifica, el formato se adivina por la extensión. Usa el nombre corto del formato.
-a_nodata <valor>
Asigna un valor nodata especificado a las bandas de salida.
-init <valor>
Pre-inicializa las bandas de la imagen de salida con estos valores. Sin embargo, no se marca como el valor nodata en el archivo de salida. Si solo se da un valor, se usa el mismo valor en todas las bandas.
-a_srs <definicion_srs>
Sobrescribe la proyección para el archivo de salida. Si no se especifica, se usará la proyección del archivo vectorial de entrada si está disponible. Al usar esta opción, no se realiza reproyección de las características desde el SRS del vector de entrada al SRS especificado de la salida, por lo que solo se debe usar esta opción para corregir un SRS de origen inválido. La <definicion_srs> puede ser cualquiera de las formas habituales de GDAL/OGR, WKT completo, PROJ.4, EPSG:n o un archivo que contenga el WKT.
-to <NOMBRE>=<VALOR>
Establece una opción de transformador adecuada para pasar a GDALCreateGenImgProjTransformer2(). Se utiliza al convertir las coordenadas de las geometrías al espacio de píxeles del ráster de destino. Por ejemplo, se puede usar para especificar opciones de transformador relacionadas con RPC.
-co <NOMBRE>=<VALOR>
Muchos formatos tienen una o más opciones de creación opcionales que se pueden usar para controlar detalles sobre el archivo creado. Por ejemplo, el controlador GeoTIFF soporta opciones de creación para controlar la compresión y si el archivo debe ser embaldosado.

Las opciones de creación disponibles varían según el controlador de formato, y algunos formatos simples no tienen opciones de creación. Se puede listar un conjunto de opciones soportadas para un formato con la opción de línea de comandos --format, pero la documentación del formato es la fuente definitiva de información sobre las opciones de creación del controlador. Consulta la documentación específica del formato de Controladores Ráster para ver las opciones de creación legales para cada formato.

-te <xmin> <ymin>
Establece la extensión de la región de interés para la salida. El valor por defecto es la extensión combinada de todas las características de entrada. La extensión se especifica en las unidades del sistema de coordenadas de salida.
-tr <res_x> <res_y>
Establece la resolución del píxel (tamaño del píxel) en las unidades del sistema de coordenadas de salida. Si no se especifica, se calcula a partir de las características de entrada.
-ts <ancho> <alto>
Establece el tamaño de salida en píxeles. Si no se especifica, se calcula a partir de las características de entrada.
-tap
Establece la alineación de la extensión de salida (y por lo tanto la alineación de píxeles) al sistema de coordenadas de la entrada (si se especifica como objetivo). Esto asegura que la extensión de salida sea un múltiplo entero de la resolución de salida y que el píxel superior izquierdo de la extensión de salida sea un múltiplo entero de la resolución de salida. Esto se hace estableciendo las coordenadas de la extensión de salida más cercanas, que son un múltiplo entero de la resolución de salida. Es útil para evitar el desplazamiento de píxeles o problemas de resolución.
-optim AUTO|VECTOR|RASTER
Establece el modo de optimización para la rasterización.
AUTO
GDAL elige el modo de optimización.
VECTOR
Optimización basada en vectores. Recomendado para conjuntos de datos de entrada de tamaño pequeño a mediano. Puede ser más rápido si el conjunto de datos ráster de destino es muy grande.
RASTER
Optimización basada en ráster. Recomendado para conjuntos de datos de entrada muy grandes y/o conjuntos de datos ráster de destino de tamaño pequeño a mediano. Puede ser más rápido si el conjunto de datos de entrada es muy grande.
-ot <Tipo>
Tipo de banda de salida. El valor por defecto es el del ráster de origen o Byte si el ráster de origen no tiene banda.
--quiet
Suprime la visualización de mensajes de progreso y de advertencia.
-oo <NOMBRE>=<VALOR>
Opción de apertura de fuente de datos. Se aplica a la fuente de datos de entrada.

<fuente_datos_origen> es la fuente de datos vectorial que contiene las geometrías a grabar.

<archivo_destino> es el nombre del archivo de imagen ráster de salida. Si el archivo existe, se modificará in situ. Si no existe, se creará. En el caso de que se cree un nuevo archivo ráster, este será un archivo GeoTIFF por defecto, a menos que se especifique lo contrario mediante la opción -of.
