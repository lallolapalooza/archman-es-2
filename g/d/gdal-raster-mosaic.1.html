DESCRIPCIÓ

N

Este programa construye un mosaico de una lista de conjuntos de datos GDAL de entrada, que pueden ser tanto un mosaico virtual en el VRT (Virtual Dataset) formato, o en un formato ráster más convencional como

GeoTIFF.

Los comodines '*', '?' o '['] de VSIGlob() pueden usarse para nombres de conjuntos de datos de entrada, incluso en archivos ubicados en sistemas de archivos de red como /vsis3/, /vsigs/, /vsiaz/, etc. Alternativamente, si el nombre de un conjunto de datos de entrada tiene el prefijo del carácter @, se asumirá que contiene la lista de los nombres reales de los conjuntos de datos (uno por línea) para usar como conjuntos de datos de

entrada.

gdal raster mosaic realiza algunas comprobaciones para asegurarse de que todos los archivos que se colocarán en el archivo resultante tengan características similares: número de bandas, proyección, interpretación de color, etc. Si no es así, los archivos que no coincidan con las características comunes serán

omitidos.

A partir de GDAL 3.12, se puede especificar una función (por ejemplo, min, mean, median) (--pixel-function) para calcular los valores de píxel a partir de las entradas superpuestas. Si no se especifica ninguna función, o en versiones anteriores, se usa el orden de la lista de entrada para determinar la prioridad. Los archivos que se enumeran al final son los de los que se obtendrá el contenido. Tenga en cuenta que el nodata se tendrá en cuenta para obtener potencialmente datos de conjuntos de datos de menor prioridad, pero actualmente, el canal alfa no se tiene en cuenta para hacer composición alfa (así que un origen con alfa=0 que aparezca sobre otro origen sobrescribirá su contenido). Esto podría cambiar en versiones

posteriores.

A partir de GDAL 3.12, este comando también puede usarse como el primer paso de gdal raster pi

peline.
