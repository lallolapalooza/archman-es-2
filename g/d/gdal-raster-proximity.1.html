DESCRIPCIÓ

N

gdal raster proximity genera un mapa de proximidad ráster que indica la distancia cartesiana desde el centro de cada píxel hasta el centro del píxel más cercano identificado como píxel objetivo. Los píxeles objetivo son aquellos del ráster de origen cuyo valor de píxel está en el conjunto de valores de píxeles

objetivo.

Este subcomando también está disponible como un paso potencial de gdal raster

pipeline

Este programa admite la serialización de la línea de comandos como un archivo JSON usando el formato de salida GDALG. El archivo resultante puede luego abrirse como un conjunto de datos ráster usando el controlador GDALG: GDAL Streamed Algorithm, y aplicar la canalización especificada de una manera en tiempo real / en

flujo.

NOTA

:
Sin embargo, este algoritmo no es nativamente compatible con el streaming. En consecuencia, se generará un conjunto de datos temporal, lo que puede causar un tiempo de procesamiento significativo al
abrir. v>
