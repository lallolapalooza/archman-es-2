NOMBRE

gdal-raster-pansharpen - Realiza una operación de pansharpening

Añadido en la versión 3.12.

SINOPSIS

Uso: gdal raster pansharpen [OPCIONES] <ENTRADA> <ESPECTRAL>... <SALIDA>
Realiza una operación de pansharpening.
Argumentos posicionales:
  -i, --panchromatic, --input <ENTRADA>                      Conjunto de datos ráster panrométrico de entrada [requerido]
  --spectral <ESPECTRAL>                                    Conjunto de datos de bandas espectrales de entrada [1.. valores] [requerido]
  -o, --output <SALIDA>                                     Conjunto de datos ráster de salida [requerido]
Opciones comunes:
  -h, --help                                                Muestra el mensaje de ayuda y sale
  --json-usage                                              Muestra el uso como documento JSON y sale
  --config <CLAVE>=<VALOR>                                  Opción de configuración [puede repetirse]
  -q, --quiet                                               Modo silencioso (sin barra de progreso)
Opciones:
  -f, --of, --format, --output-format <FORMATO-SALIDA>      Formato de salida ("GDALG" permitido)
  --co, --creation-option <CLAVE>=<VALOR>                   Opción de creación [puede repetirse]
  --overwrite                                               Si se permite sobrescribir la salida existente
                                                            Excluyente mutuamente con --append
  --append                                                  Añadir como subconjunto de datos a la salida existente
                                                            Excluyente mutuamente con --overwrite
  -r, --resampling <REMUESTREO>                             Algoritmo de remuestreo. REMUESTREO=nearest|bilinear|cubic|cubicspline|lanczos|average (predeterminado: cubic)
  --weights <PESOS>                                         Peso para cada banda espectral de entrada [puede repetirse]
  --nodata <NODATA>                                         Sobrescribir el valor nodata de las bandas de entrada
  --bit-depth <PROFUNDIDAD-BITS>                            Sobrescribir la profundidad de bits de las bandas de entrada
  --spatial-extent-adjustment <AJUSTE-EXTENTO-ESPACIAL>     Seleccionar el comportamiento cuando las bandas no tienen el mismo extento. AJUSTE-EXTENTO-ESPACIAL=union|intersection|none|none-without-warning (predeterminado: union)
  -j, --num-threads <NUM-HILOS>                             Número de trabajos (o ALL_CPUS) (predeterminado: ALL_CPUS)
Opciones avanzadas:
  --if, --input-format <FORMATO-ENTRADA>                    Formatos de entrada [puede repetirse]
  --oo, --open-option <CLAVE>=<VALOR>                       Opciones de apertura [puede repetirse]

DESCRIPCIÓN

gdal raster pansharpen realiza una operación de pan-sharpening. Puede crear un conjunto de datos de salida "clásico" (como GeoTIFF), o un conjunto de datos VRT que describe la operación de pan-sharpening.

Toma como entrada un conjunto de datos panrométrico de una banda y varias bandas espectrales, generalmente a una resolución inferior que la banda panrométrica. La salida es un conjunto de datos multibanda (con tantas bandas como bandas panrométricas de entrada), mejorado a la resolución de la banda panrométrica.

Todas las bandas deben estar en el mismo sistema de referencia de coordenadas.

Se pueden encontrar más detalles en la sección VRT de pansharpening.

OPCIONES

Las siguientes opciones están disponibles:

-i, --panchromatic, --input <ENTRADA>
Conjunto de datos con banda panrométrica. [requerido]
--spectral <conjunto_datos_espectral>[,band=<num>]
Conjunto de datos con una o varias bandas espectrales. [requerido]

Si la opción de banda no se especifica, todas las bandas del conjunto de datos se tienen en cuenta. De lo contrario, solo la banda (num) especificada. El mismo conjunto de datos puede repetirse varias veces.

-f, --of, --format, --output-format <FORMATO-SALIDA>
Qué formato ráster de salida usar. Los valores permitidos pueden darse por gdal --formats | grep raster | grep rw | sort
--co <NOMBRE>=<VALOR>
Muchos formatos tienen una o más opciones de creación opcionales que pueden usarse para controlar detalles sobre el archivo creado. Por ejemplo, el controlador GeoTIFF admite opciones de creación para controlar la compresión y si el archivo debe estar en mosaico (tiling).

Puede repetirse.

Las opciones de creación disponibles varían según el controlador de formato, y algunos formatos simples no tienen opciones de creación en absoluto. Una lista de opciones admitidas para un formato puede listarse con la --formats opción de línea de comando pero la documentación del formato es la fuente definitiva de información sobre las opciones de creación del controlador. Ver documentación específica de formato de los controladores ráster para las opciones de creación válidas de cada formato.

--overwrite
Permite al programa sobrescribir el archivo o conjunto de datos de destino existente. De lo contrario, por defecto, gdal da error si el archivo o conjunto de datos de destino ya existe.
--weights <PESOS>
Especifica un peso para el cálculo del valor panrométrico pseudo. Debe haber tantos valores como bandas espectrales de entrada.
-r, --resampling nearest|bilinear|cubic|cubicspline|lanczos|average
Selecciona un algoritmo de remuestreo. cubic es el predeterminado.
--bit-depth <val>
Especifica la profundidad de bits de las bandas panrométrica y espectrales (p. ej. 12). Si no se especifica, se usará el elemento de metadatos NBITS de la banda panrométrica si existe.
--nodata <val>
Especifica el valor nodata para las bandas. Se usa para el remuestreo y el propio cálculo de pan-sharpening. Si no se establece, se deduce de las bandas de entrada, siempre que tengan una configuración consistente.
--spatial-extent--adjustment union|intersection|none|none-without-warning
Selecciona el comportamiento cuando las bandas no tienen el mismo extento. Ver documentación SpatialExtentAdjustment en VRT de pansharpening union es el predeterminado.
-j, --num-threads <valor>
Especifica el número de hilos a usar para hacer el remuestreo y el propio pan-sharpening. Puede ser un número entero o ALL_CPUS (el predeterminado)

GDALG SALIDA (CONJUNTO DE DATOS EN TIEMPO REAL / TRANSMITIDO)

Este programa admite serializar la línea de comandos como un archivo JSON usando el formato de salida GDALG. El archivo resultante puede luego abrirse como un conjunto de datos ráster usando el controlador GDALG: GDAL Streamed Algorithm, y aplicar la tubería especificada de una manera en tiempo real / transmitida.

EJEMPLOS

Ejemplo 1: Con bandas espectrales en un solo conjunto de datos

gdal raster pansharpen panchro.tif rgb.tif pansharpened_out.tif

Ejemplo 2: Con algunas bandas espectrales de un solo conjunto de datos, reordenadas

gdal raster pansharpen panchro.tif bgr.tif,band=3 bgr.tif,band=2 bgr.tif,band=1 pansharpened_out.tif

Ejemplo 3: Con bandas espectrales envarios conjuntos de datos

gdal raster pansharpen panchro.tif red.tif green.tif blue.tif pansharpened_out.tif

Ejemplo 4: Especificar pesos

gdal raster pansharpen -w 0.7,0.2,0.1 panchro.tif multispectral.tif pansharpened_out.tif

Ejemplo 5: Seleccionar bandas RGB de un conjunto de datos multiespectral RGBNir mientras se calcula la intensidad pancromática pseudo en las 4 bandas RGBNir

gdal raster pipeline read panchro.tif ! pansharpen rgbnir.tif ! select 1,2,3 ! write pansharpened_out.tif
