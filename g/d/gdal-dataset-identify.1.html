NOMBRE

gdal-dataset-identify - Identifica el controlador que abre el/los conjunto(s) de datos

Añadido en la versión 3.12.

gdal manage-dataset identify informa el nombre de los controladores que pueden abrir uno o varios conjuntos de datos.

SINOPSIS

Uso: gdal dataset identify [OPCIONES] <NOMBRE_ARCHIVO>
Identifica el controlador que abre el/los conjunto(s) de datos.
Argumentos posicionales:
  --filename <NOMBRE_ARCHIVO>                                Nombre de archivo o directorio [puede repetirse] [requerido]
Opciones comunes:
  -h, --help                                           Muestra el mensaje de ayuda y sale
  --json-usage                                         Muestra el uso como documento JSON y sale
  --config <CLAVE>=<VALOR>                               Opción de configuración [puede repetirse]
  -q, --quiet                                          Modo silencioso (sin barra de progreso)
Opciones:
  -f, --of, --format, --output-format <FORMATO-SALIDA>  Formato de salida. FORMATO-SALIDA=json|text
  -r, --recursive                                      Escanea recursivamente archivos/carpetas en busca de conjuntos de datos
  --force-recursive                                    Escanea recursivamente carpetas en busca de conjuntos de datos, forzando la recursión en carpetas reconocidas como formatos válidos
  --report-failures                                    Informa de fallos si el tipo de archivo no se identifica

OPCIONES

--filename <NOMBRE_ARCHIVO>
Cualquier nombre de archivo o directorio. Requerido. Puede repetirse
-f, --of, --format, --output-format json|text
Qué formato de salida utilizar. Por defecto es JSON, o texto cuando se invoca desde la línea de comandos.
-r, --recursive
Escanea recursivamente archivos/carpetas en busca de conjuntos de datos.
--force-recursive
Escanea recursivamente carpetas en busca de conjuntos de datos, forzando la recursión en carpetas reconocidas como formatos válidos.
--report-failures
Informa de fallos si el tipo de archivo no se identifica.

EJEMPLOS

Ejemplo 1: Identificando un único archivo

$ gdal dataset identify --of=text NE1_50M_SR_W.tif
NE1_50M_SR_W.tif: GTiff

Ejemplo 2: Identificando un único archivo con salida JSON

$ gdal dataset identify NE1_50M_SR_W.tif
[
   {
     "name": "NE1_50M_SR_W.tif",
     "driver": "GTiff"
   }
]

Ejemplo 3: El modo recursivo escanea subcarpetas e informa del formato de datos

$ gdal dataset identify --of=text -r 50m_raster/
NE1_50M_SR_W/ne1_50m.jpg: JPEG
NE1_50M_SR_W/ne1_50m.png: PNG
NE1_50M_SR_W/ne1_50m_20pct.tif: GTiff
NE1_50M_SR_W/ne1_50m_band1.tif: GTiff
NE1_50M_SR_W/ne1_50m_print.png: PNG
NE1_50M_SR_W/NE1_50M_SR_W.aux: HFA
NE1_50M_SR_W/NE1_50M_SR_W.tif: GTiff
NE1_50M_SR_W/ne1_50m_sub.tif: GTiff
NE1_50M_SR_W/ne1_50m_sub2.tif: GTiff
