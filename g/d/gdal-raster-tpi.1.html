NOMBRE

gdal-raster-tpi - Generar un mapa de Índice de Posición Topográfica (TPI)

Añadido en la versión 3.11.

SINOPSIS

Uso: gdal raster tpi [OPCIONES] <ENTRADA> <SALIDA>
Generar un mapa de Índice de Posición Topográfica (TPI)
Argumentos posicionales:
  -i, --input <ENTRADA>                                  Conjuntos de datos ráster de entrada [requerido]
  -o, --output <SALIDA>                                Conjunto de datos ráster de salida [requerido]
Opciones comunes:
  -h, --help                                           Mostrar mensaje de ayuda y salir
  --json-usage                                         Mostrar el uso como documento JSON y salir
  --config <CLAVE>=<VALOR>                               Opción de configuración [puede repetirse]
  -q, --quiet                                          Modo silencioso (sin barra de progreso)
Opciones:
  -f, --of, --format, --output-format <FORMATO-SALIDA>  Formato de salida ("GDALG" permitido)
  --co, --creation-option <CLAVE>=<VALOR>                Opción de creación [puede repetirse]
  --overwrite                                          Si se permite sobrescribir la salida existente
                                                       Mutuamente excluyente con --append
  --append                                             Añadir como subconjunto de datos a la salida existente
                                                       Mutuamente excluyente con --overwrite
  -b, --band <BANDA>                                    Banda de entrada (índice basado en 1) (por defecto: 1)
  --no-edges                                           No intentar interpolar valores en los bordes del conjunto de datos o cerca de los valores nulos
Opciones avanzadas:
  --if, --input-format <FORMATO-ENTRADA>                  Formatos de entrada [puede repetirse]
  --oo, --open-option <CLAVE>=<VALOR>                    Opciones de apertura [puede repetirse]

DESCRIPCIÓN

gdal raster tpi genera un ráster de banda única con valores calculados a partir de la elevación. TPI significa Índice de Posición Topográfica, que se define como la diferencia entre un píxel central y la media de sus celdas circundantes (ver Wilson et al 2007, Marine Geodesy 30:3-35).

Este subcomando también está disponible como un posible paso de gdal raster pipeline

El valor -9999 se utiliza como valor nulo.

También se emitirá un valor nulo en el conjunto de datos de destino si se encuentra al menos un píxel establecido en el valor nulo dentro de la ventana de 3x3 centrada en cada píxel fuente. Por defecto, el algoritmo calculará valores en los bordes de la imagen o si se encuentra un valor nulo en la ventana de 3x3, interpolando los valores faltantes, a menos que se especifique --no-edges, en cuyo caso un borde de 1 píxel alrededor de la imagen se establecerá con el valor nulo.

Opciones estándar

-f, --of, --format, --output-format <FORMATO-SALIDA>
Qué formato de ráster de salida utilizar. Los valores permitidos pueden ser proporcionados por gdal --formats | grep raster | grep rw | sort
--co <NOMBRE>=<VALOR>
Muchos formatos tienen una o más opciones de creación opcionales que pueden utilizarse para controlar detalles sobre el archivo creado. Por ejemplo, el controlador GeoTIFF admite opciones de creación para controlar la compresión y si el archivo debe dividirse en mosaicos.

Puede repetirse.

Las opciones de creación disponibles varían según el controlador de formato, y algunos formatos simples no tienen ninguna opción de creación. Una lista de opciones admitidas para un formato se puede listar con la opción de línea de comandos --formats, pero la documentación del formato es la fuente definitiva de información sobre las opciones de creación del controlador. Consulte la documentación específica del formato de Controladores ráster para conocer las opciones de creación legales para cada formato.

--overwrite
Permite al programa sobrescribir el archivo o conjunto de datos de destino existente. De lo contrario, por defecto, gdal genera un error si el archivo o conjunto de datos de destino ya existe.
-b, --band <BANDA>
Índice (empezando por 1) de la banda para la que se debe calcular el TPI.
--no-edges
No intentar interpolar valores en los bordes del conjunto de datos o cerca de los valores nulos

SALIDA GDALG (AL VUELO / CONJUNTO DE DATOS EN SECUENCIA)

Este programa admite la serialización de la línea de comandos como un archivo JSON utilizando el formato de salida GDALG. El archivo resultante puede luego abrirse como un conjunto de datos ráster utilizando el controlador GDALG: GDAL Streamed Algorithm, y aplicar el pipeline especificado de forma "al vuelo" / en secuencia.

EJEMPLOS

Ejemplo 1: Genera un mapa de Índice de Posición Topográfica (TPI) a partir de un archivo DTED0.

$ gdal raster tpi n43.dt0 out.tif --overwrite
