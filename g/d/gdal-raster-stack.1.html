Uso: gdal raster stack [OPCIONES] <ENTRADA>... <SALIDA>
Combina bandas de entrada en una salida multibanda, ya sea virtual (VRT) o materializada.
Argumentos posicionales:
  -i, --input <ENTRADA>                                             Conjuntos de datos ráster de entrada (o especifique un @<nombrearchivo> para apuntar a un archivo que contiene nombres de archivo) [1.. valores] [requerido]

--overwrite Si se permite sobrescribir la salida existente Mutuamente exclusivo con --append --append Añadir como subconjunto de datos a la salida existente Mutuamente exclusivo con --overwrite -b, --band <BANDA> Banda(s) de entrada (índice basado en 1) [puede repetirse] --absolute-path

DESCRIPCIÓ

N

Este programa combina bandas de entrada de conjuntos de datos GDAL en un conjunto de datos, que puede ser una pila virtual en el formato VRT (Virtual Dataset), o en un formato ráster más convencional como

GeoTIFF.

Todas las bandas de cada archivo de entrada se añaden como bandas de salida separadas, a menos que -b se especifique para seleccionar un subconjunto de

ellas.

La lista de conjuntos de datos GDAL de entrada puede especificarse al final de la línea de comandos o ponerse en un archivo de texto (un nombre de archivo por línea) para listas muy largas. Los comodines '*', '?' o '['] de VSIGlob() pueden usarse, incluso en archivos ubicados en sistemas de archivos de red como /vsis3/, /vsigs/, /vsiaz/,

etc.

A partir de GDAL 3.12, este comando también puede usarse como el primer paso de gdal raster pi

peline.
