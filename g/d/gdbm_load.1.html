NOMBRE

gdbm_load - recrear una base de datos GDBM a partir de un archivo de volcado.

SINOPSIS

gdbm_load [-MUnr] [-b NUM] [-c NUM] [-m MODO] [-u NOMBRE|UID[:NOMBRE|GID]] [--block-size=NUM] [--cache-size=NUM] [--mmap=NUM] [--mode=MODO] [--no-meta] [--replace] [--update] [--user=NOMBRE|UID[:NOMBRE|GID]] ARCHIVO [DB_FILE]

gdbm_load [-Vh] [--help] [--usage] [--version]

DESCRIPCIÓN

Crea un archivo de base de datos gdbm DB_FILE a partir del archivo de volcado ARCHIVO. Si no se proporciona el argumento ARCHIVO, la salida de la base de datos creada será a la salida de error estándar.

Si el archivo de entrada está en formato de volcado ASCII, el modo y la propiedad de la base de datos creada se restauran a partir de la información del volcado. Esto se puede anular utilizando las opciones de la línea de comandos (ver abajo).

OPCIONES

-b, --block-size=NUM
Establece el tamaño del bloque.
-c, --cache-size=NUM
Establece el tamaño de la caché.
-M, --mmap
Usa mapeo de memoria.
-m, --mode=MODO
Establece el modo del archivo de la base de datos (número octal).
-n, --no-meta
No intentes restaurar los metadatos de la base de datos (modo y propiedad).
-r, --replace
Reemplaza las claves existentes. Esto debe usarse junto con la opción -U (--update).
-U, --update
Actualiza una base de datos existente. Los pares clave/valor del archivo de volcado se añadirán a esa base de datos, sin eliminar las claves existentes. Para sobrescribir claves duplicadas en el archivo de volcado, usa la opción --replace.
Si la base de datos no existe, se creará.
-u, --user=NOMBRE|UID[:NOMBRE|GID]
Establece la propiedad del archivo.
-h, --help
Imprime un breve resumen de uso.
--usage
Imprime una lista de opciones disponibles.
-V, --version
Imprime la versión del programa

VER TAMBIÉN

gdbm_dump(1), gdbmtool(1), gdbm(3).

Para una descripción detallada de gdbm_load y otras utilidades de gdbm, consulta el Manual GDBM disponible en formato Texinfo. Para acceder a él, ejecuta:

info gdbm

La documentación también está disponible en línea en
