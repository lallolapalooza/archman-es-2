NOMBRE

gdtclft - renderiza imágenes en varios formatos de mapa de bits (GD, GD2, GIF, JPEG, PNG, WBMP, XBM)

Resumen
   Este paquete proporciona una interfaz Tcl simple para el paquete gd (dibujo de
   mapas de bits). Incluye una interfaz a todas las funciones y estructuras de
   datos de gd desde comandos Tcl.
Referencia
   Se añade un comando Tcl, 'gd'. Todas las acciones del paquete gd son
   subcomandos (u "opciones" en terminología Tcl) de este comando.
   Cada imagen gd activa se referencia con un "manejador". El manejador es un
   nombre de la forma gd# (por ejemplo, gd0) devuelto por las opciones de gd create.
   Casi todos los comandos gd toman un manejador como primer argumento (después de
   la opción). Todos los comandos de dibujo toman un color_idx como siguiente
   argumento.
   gd create <width> <height> ?true?
          Devuelve un manejador a un nuevo gdImage que es width X height.
	  Si se especifica "true", la nueva imagen es "TrueColor".
   gd createTrueColor <width> <height>
          Devuelve un manejador a un nuevo gdImage trueColor que es width X height.
   gd createFromGD <file>
   gd createFromGD2 <file>
   gd createFromGIF <file>
   gd createFromJPEG <file>
   gd createFromPNG <file>
   gd createFromWBMP <file>
   gd createFromXBM <file>
          Devuelve un manejador a un nuevo gdImage creado leyendo una
          imagen en el formato indicado desde el nombre de archivo o el manejador de
          archivo TCL abierto
	  (excepto para XPM, que solo acepta nombres de archivo).
   gd destroy <gdhandle>
          Destruye el gdImage referenciado por gdhandle.
   gd writeGD <gdhandle> <file>
   gd writeGD2 <gdhandle> <file>
   gd writeGIF <gdhandle> <file>
   gd writeJPEG <gdhandle> <file>
   gd writePNG <gdhandle> <file>
   gd writeWBMP <gdhandle> <file>
   gd writeXBM <gdhandle> <file>
          Escribe la imagen en gdhandle al nombre de archivo o manejador de archivo
	  TCL abierto en el formato indicado.
   gd writePNGvar <gdhandle> <varname>
          Escribe la imagen en gdhandle a la variable Tcl "varname" como un objeto
          PNG codificado en binario.
   gd interlace <gdhandle> <on-off>
          Hace que la imagen de salida esté entrelazada (si on-off es verdadero) o
          no (si on-off es falso).
   gd color new <gdhandle> <red> <green> <blue>
          Asigna un nuevo color con los valores RGB dados. Devuelve el
          color_idx, o -1 en caso de fallo (256 colores ya asignados).
   gd color exact <gdhandle> <red> <green> <blue>
          Encuentra un color_idx en la imagen que coincida exactamente con el color
          RGB dado. Devuelve el color_idx, o -1 si no hay coincidencia exacta.
   gd color closest <gdhandle> <red> <green> <blue>
          Encuentra un color en la imagen que esté más cerca del color RGB dado.
          Garantiza devolver un color idx.
   gd color resolve <gdhandle> <red> <green> <blue>
          Devuelve el índice del mejor esfuerzo posible para obtener un color.
          Garantiza devolver un color idx. Equivalente a:
               if {[set idx [gd color exact $gd $r $g $b]] == -1} {
                   if {[set idx [gd color neW $Gd $r $g $b]] == -1} {
                       set idx [gd color closest $gd $r $g $b]
                   }
               }
   gd color free <gdhandle> <color_idx>
          Libera el color en el color_idx dado para su reutilización.
   gd color transparent <gdhandle> [<color_idx>]
          Marca el color en <color_idx> como el color de fondo transparente. O,
          devuelve el color_idx transparente si no se especifica color_idx.
   gd color get <gdhandle> [<color_idx>]
          Devuelve el valor RGB en <color_idx>, o {} si no está asignado.
          Si no se especifica <color_idx>, devuelve una lista de valores
          {color_idx R G B} para todos los colores asignados.
   gd brush <gdhandle> <brushhandle>
          Establece la imagen de pincel a usar para líneas con pincel. Los píxeles
          transparentes en el pincel no cambiarán la imagen cuando se aplique el
          pincel.
   gd style <gdhandle> <color_idx> ...
          Establece el estilo de línea a la lista de índices de color. Esto se
          interpreta de una de dos maneras. Para una línea con estilo simple, cada
          color se aplica a los puntos a lo largo de la línea por turnos. El valor
          color_idx transparente puede usarse para dejar huecos en la línea.
          Para una línea con estilo y pincel, un 0 (o el color_idx transparente)
          significa no rellenar el píxel, y un valor distinto de cero significa
          aplicar el pincel.
   gd tile <gdhandle> <tilehandle>
          Establece la imagen de mosaico a usar para rellenos en mosaico. Los
          píxeles transparentes en el mosaico no cambiarán la imagen subyacente
          durante el mosaico.
          En todas las funciones de dibujo, el color_idx es un número, o puede ser
          una de las cadenas styled, brushed, tiled, "styled brushed" o
          "brushed styled". Se usará el estilo, pincel o mosaico actualmente en
          efecto. El pincelado y el estilo se aplican a líneas, el mosaico a áreas
          rellenas.
   gd set <gdhandle> <color_idx> <x> <y>
          Establece el píxel en (x,y) al color <color_idx>.
   gd line <gdhandle> <color_idx> <x1> <y1> <x2> <y2>
   gd rectangle <gdhandle> <color_idx> <x1> <y1> <x2> <y2>
   gd fillrectangle <gdhandle> <color_idx> <x1> <y1> <x2> <y2>
          Dibuja el contorno de (respectivamente, rellena) un rectángulo en el color
          <color_idx> con esquinas en (x1,y1) y (x2,y2).
   gd arc       <gdhandle> <color_idx> <cx> <cy> <width> <height> <start> <end>
   gd fillarc   <gdhandle> <color_idx> <cx> <cy> <width> <height> <start> <end>
   gd openarc   <gdhandle> <color_idx> <cx> <cy> <width> <height> <start> <end>
   gd chord     <gdhandle> <color_idx> <cx> <cy> <width> <height> <start> <end>
   gd fillchord <gdhandle> <color_idx> <cx> <cy> <width> <height> <start> <end>
   gd openchord <gdhandle> <color_idx> <cx> <cy> <width> <height> <start> <end>
   gd pie       <gdhandle> <color_idx> <cx> <cy> <width> <height> <start> <end>
   gd fillpie   <gdhandle> <color_idx> <cx> <cy> <width> <height> <start> <end>
   gd openpie   <gdhandle> <color_idx> <cx> <cy> <width> <height> <start> <end>
          Todos describen una forma basada en arco en el color <color_idx>,
	  centrada en (cx,cy) en un rectángulo width x height, comenzando en
	  start grados y terminando en end grados.
	  arc       - Solo la línea curva.
	  fillarc   - (Pretendía ser un relleno entre la curva y la cuerda,
		      pero gd no hace eso) - Igual que pie.
	  openarc   - Forma de contorno con curva y cuerda.
	  chord     - Cuerda de línea recta entre los extremos de la curva,
		      pero sin mostrar la curva.
	  fillchord - Triángulo relleno entre la cuerda y el centro.
	  openchord - Triángulo de contorno entre la cuerda y el centro.
	  pie       - Segmento de tarta relleno entre la curva y el centro.
	  fillpie   - Igual que pie.
	  openpie   - Segmento de tarta de contorno entre la curva y el centro.
   gd polygon <gdhandle> <color_idx> <x1> <y1> ...
   gd fillpolygon <gdhandle> <color_idx> <x1> <y1> ...
          Dibuja el contorno de, o rellena, un polígono especificado por la lista de
          coordenadas x, y. Debe haber al menos 3 puntos especificados.
   gd fill <gdhandle> <color_idx> <x> <y>
   gd fill <gdhandle> <color_idx> <x> <y> <borderindex>
          Rellena con el color <color_idx>, comenzando desde (x,y) dentro de una
          región de píxeles todos del color del píxel en (x,y) (respectivamente,
          dentro de un borde coloreado borderindex).
   gd size <gdhandle>
          Devuelve una lista {width height} de la imagen.
   gd text <gdhandle> <color_idx> <fontlist> <size> <angle> <x> <y> <string>
          Dibuja texto usando <fontlist> en el color <color_idx>,
          con tamaño de punto <size>, rotación en radianes <angle>, con la esquina
          inferior izquierda en (x,y). La cadena puede contener secuencias UTF8
          como: "&"
          Devuelve 4 coordenadas de esquina del rectángulo delimitador.
          Usa gdhandle = {} para obtener el límite sin renderizar.
          Usa el negativo de color_idx para desactivar el antialiasing.
	  <fontlist> puede contenern bien una ruta de nombre completo de una fuente, incluyendo
	  la extensión ".ttf", o puede contener una lista de nombres
	  alternativos para una fuente, separados por espacios, sin el ".ttf".  p. ej.
		"Times-Roman times"
          El archivo <name>.ttf correspondiente a uno de los nombres alternativos
	  debe encontrarse en la ruta de fuentes predeterminada incorporada (DEFAULT_FONTPATH), o en la
	  ruta de fuentes especificada en la variable de entorno GDFONTPATH.
   gd copy <desthandle> <srchandle> <destx> <desty> <srcx> <srcy> <w> <h>
	  Copia una subimagen de srchandle(srcx, srcy)
	  a desthandle(destx, desty), de tamaño w x h.
   gd copy <desthandle> <srchandle> <destx> <desty> <srcx> <srcy> \
       <destw> <desth> <srcw> <srch>
	  Copia una subimagen de srchandle(srcx, srcy) 
          a desthandle(destx, desty), y redimensiona la subimagen 
	  de srcw por srch a destw por desth.
Ejemplos
   El programa de ejemplo de la documentación de gd puede escribirse así:
#!/bin/sh
# la siguiente línea es un comentario en tcl exec tclsh "$0" ${1+"$@"}
package require Gdtclft
################################################################
# Programa de ejemplo gdtcl  - de la página de manual de gdtclft
#
# Crear una imagen de 64 x 64
set im [gd create 64 64]
# Obtener blanco y negro como colores. El negro es el color de fondo porque
# se asigna primero desde una nueva imagen.
set black [gd color new $im 0 0 0]
set white [gd color new $im 255 255 255]
# Dibujar una línea desde la esquina superior izquierda hasta la inferior derecha
gd line $im $white 0 0 63 63
# Abrir un archivo para escritura (Tcl en Unix, al menos, no soporta el modo 'wb')
set out [open test.png w]
# Escribir la imagen en el archivo de disco
gd writePNG $im $out
# Cerrar el archivo
close $out
# Destruir la imagen en memoria
gd destroy $im
  GDDEMO
   Aquí está el programa gddemo.c traducido a tcl.
#!/bin/sh
# la siguiente línea es un comentario en tcl exec tclsh "$0" ${1+"$@"}
package require Gdtclft
################################################################
#
# gddemo en tcl
#
# abrir demoin.png o terminar
if {[catch {open demoin.png r} in]} {
  puts stderr "No se puede cargar la imagen de origen; esta demo es mucho";
  puts stderr "más impresionante si demoin.png está disponible";
  exit
}
# Crear imagen de salida 128 x 128
set im_out [gd create 128 128]
# El primer color es el fondo
set white [gd color new $im_out 255 255 255]
# Establecer transparente
gd color transparent $im_out $white
# Cargar demoin.png y pegar parte de ella en la imagen de salida.
set im_in [gd createFromPNG $in]
close $in
# Copiar y reducir
gd copy $im_out $im_in 16 16 0 0 96 96 128 128
# Obtener algunos colores
set red [gd color new $im_out 255 0 0]
set green [gd color new $im_out 0 255 0]
set blue [gd color new $im_out 0 0 255]
# Dibujar un rectángulo
gd line $im_out $green 8 8 120 8
gd line $im_out $green 120 8 120 120
gd line $im_out $green 120 120 8 120
gd line $im_out $green 8 120 8 8
# Texto
gd text $im_out $red arial 20 0 16 16 hi
gd text $im_out $red arial 20 90 23 23 hi
# Círculo
gd arc $im_out $blue 64 64 30 10 0 360
# Arco
gd arc $im_out $blue 64 64 20 20 45 135
# Relleno de inundación
gd fill $im_out $blue 4 4
# Polígono
gd fillpolygon $im_out $green 32 0 0 64 64 64
# Pincel. ¡Un ejemplo bastante salvaje que también involucra un estilo de línea!
if {$im_in != ""} {
  set brush [gd create 8 8];
  eval [concat gd copy $brush $im_in 0 0 0 0 [gd size $brush] [gd size $im_in]]
  gd brush $im_out $brush
  # Estilo para que no se impriman unos sobre otros.
  gd style $im_out "0 0 0 0 0 0 0 1"
  gd line $im_out "styled brushed" 0 0 128 128
}
# Entrelazar el resultado para "aparecer gradualmente" en los visores que lo soportan
gd interlace $im_out true
# Escribir PNG
set out [open demoout.png w]
gd writePNG $im_out $out
close $out
gd destroy $im_out
  GDSHOW
   Un procedimiento rápido de Tcl para mostrar una imagen GD usando el programa xv.
################################################################
# gdshow -- usar xv para mostrar una imagen.
#
# Espera hasta que xv salga para retornar.
#
proc gdshow {gd} {
  set f [open "|xv -" w]
  catch {gd writePNG $gd $f}
  catch {close $f} xx
  if {$xx != {}} {
    error "XV error: $xx"
  }
}
