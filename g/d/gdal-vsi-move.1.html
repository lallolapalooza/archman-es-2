NOMBRE

gdal-vsi-move - Mover/renombrar un archivo/directorio ubicado en la Interfaz de Sistema Virtual (VSI) de GDAL

Añadido en la versión 3.11.

SINOPSIS

Uso: gdal vsi move [OPCIONES] <FUENTE> <DESTINO>
Mover/renombrar un archivo/directorio ubicado en la Interfaz de Sistema Virtual
(VSI) de GDAL.
Argumentos posicionales:
  --source <FUENTE>            Nombre del archivo o directorio fuente [requerido]
  --destination <DESTINO>  Nombre del archivo o directorio destino [requerido]
Opciones comunes:
  -h, --help                   Muestra el mensaje de ayuda y sale
  --json-usage                 Muestra el uso como documento JSON y sale
  --config <CLAVE>=<VALOR>     Opción de configuración [puede repetirse]
  -q, --quiet                  Modo silencioso (sin barra de progreso)

DESCRIPCIÓN

gdal vsi move mueve archivos y directorios ubicados en los *Sistemas de Archivos Virtuales (comprimidos, alojados en red, etc.): /vsimem, /vsizip, /vsitar, /vsicurl, ...* de GDAL.

Si la ruta de destino es un directorio existente, el archivo se moverá a él.

Puede mover archivos y directorios entre diferentes sistemas de archivos virtuales, pero esto implicará copias y eliminaciones.

Tenga en cuenta que para el almacenamiento de objetos en la nube, mover/renombrar un directorio puede implicar renombrar todos los archivos que contiene de forma recursiva, y por lo tanto no es una operación atómica (¡y podría ser lenta y costosa en directorios con muchos archivos!).

Esto está implementado por VSIMove().

Este es un análogo del comando mv de UNIX, y gdal vsi mv es un alias para gdal vsi move.

EJEMPLOS

Ejemplo 1: Renombrar un archivo dentro del mismo sistema de archivos virtual

$ gdal vsi move /vsis3/bucket/my.tif /vsis3/bucket/new_name.tif

Ejemplo 2: Mover un archivo a otro directorio dentro del mismo sistema de archivos virtual

$ gdal vsi move /vsis3/bucket/my.tif /vsis3/bucket/existing_subdir

Ejemplo 3: Mover un directorio entre dos sistemas de archivos virtuales diferentes

$ gdal vsi move /vsis3/bucket/my_directory /vsigs/bucket/
