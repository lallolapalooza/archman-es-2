NOMBRE

gdal-vsi-delete - Eliminar archivos ubicados en la Interfaz de Sistema Virtual de GDAL (VSI)

Añadido en la versión 3.11.

SINOPSIS

Uso: gdal vsi delete [OPCIONES] <NOMBRE_ARCHIVO>
Eliminar archivos ubicados en la Interfaz de Sistema Virtual de GDAL (VSI).
Argumentos posicionales:
  --filename <NOMBRE_ARCHIVO>   Nombre del archivo o directorio a eliminar [requerido]
Opciones comunes:
  -h, --help              Mostrar mensaje de ayuda y salir
  --json-usage            Mostrar el uso como documento JSON y salir
  --config <CLAVE>=<VALOR>  Opción de configuración [puede repetirse]
Opciones:
  -r, -R, --recursive     Eliminar directorios recursivamente

DESCRIPCIÓN

gdal vsi delete elimina archivos y directorios ubicados en los Sistemas de Archivos Virtuales de GDAL (comprimidos, alojados en red, etc...): /vsimem, /vsizip, /vsitar, /vsicurl, ....

Este es el equivalente al comando rm de UNIX, y gdal vsi rm es un alias para gdal vsi delete.

ADVERTENCIA:

Ten cuidado. Este comando no se puede deshacer. También puede actuar sobre el sistema de archivos "real".

Opciones

-r, -R, --recursive
Eliminar directorios recursivamente.

EJEMPLOS

Ejemplo 1: Eliminar recursivamente archivos de /vsis3/bucket/my_dir

$ gdal vsi delete -r /vsis3/bucket/my_dir
