NOMBRE

gdnsd-plugin-tcp_connect - plugin de monitorización TCP de gdnsd

SINOPSIS

Ejemplo de configuración de tipos de servicio tcp_connect:

service_types => {
  tcp9000 => {
    plugin => tcp_connect,
    port => 9000, # requerido
    up_thresh => 20,
    ok_thresh => 10,
    down_thresh => 10,
    interval => 10,
    timeout => 3,
  }
}

DESCRIPCIÓN

gdnsd-plugin-tcp_connect es un plugin de monitorización que verifica la conectividad TCP básica a un puerto dado. Establece una conexión TCP básica y luego la cierra inmediatamente sin enviar ni recibir ningún dato en cada comprobación de monitorización.

PARÁMETROS

puerto
El número de puerto numérico al que conectarse, es requerido.
