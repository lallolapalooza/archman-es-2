NOMBRE

gdal_create - Crea un archivo ráster (sin conjunto de datos de origen)

SINOPSIS

Uso: gdal_create [--help] [--long-usage] [--help-general]
                   [-ot Byte|Int8|[U]Int{16|32|64}|CInt{16|32}|[C]Float{32|64}]
                   [-of <output_format>] [-outsize <xsize> <ysize>]
                   [-bands <count>] [-burn <value>]... [-a_srs <srs_def>]
                   [-a_ullr <ulx> <uly> <lrx> <lry>] [-a_nodata <value>]
                   [-mo <NAME>=<VALUE>]... [-co <NAME>=<VALUE>]... [--quiet]
                   [-if <input_dataset>]
                   <out_dataset>

DESCRIPCIÓN

La utilidad gdal_create se puede utilizar para inicializar un nuevo archivo ráster, a partir de sus dimensiones, el número de bandas y establecer varios parámetros, como el sistema de referencia de coordenadas (CRS), la transformación geográfica, el valor de datos nulos y los metadatos. También se puede utilizar en casos especiales, como la creación de un archivo PDF a partir de un archivo de composición XML.

--help
Muestra este mensaje de ayuda y sale
--help-general
Proporciona un breve mensaje de uso para las opciones de línea de comandos genéricas de GDAL y sale.
-ot <type>
Fuerza a las bandas de la imagen de salida a tener un tipo de datos específico soportado por el controlador, que puede ser uno de los siguientes: Byte, Int8, UInt16, Int16, UInt32, Int32, UInt64, Int64, Float32, Float64, CInt16, CInt32, CFloat32 o CFloat64.
-of <format>
Selecciona el formato de salida. Si no se especifica, el formato se deduce de la extensión. Utilice el nombre corto del formato.
-outsize <xsize> <ysize>
Establece el tamaño del archivo de salida en píxeles. El primer valor es el ancho. El segundo es el alto.
-bands <count>
Número de bandas. Por defecto es 1 si se especifica -outsize, o 0 en caso contrario.
-burn <value>
Un valor fijo para quemar en una banda. Se puede proporcionar una lista de opciones -burn , una por banda (el primer valor se aplicará a la primera banda, el segundo a la segunda banda, etc.). Si se especifica un solo valor, se aplicará a todas las bandas.
-a_srs <srs_def>
Anula la proyección para el archivo de salida. El<srs_def> puede ser cualquiera de las formas habituales de GDAL/OGR, WKT completo, PROJ.4, EPSG:n o un archivo que contenga el WKT. No se realiza ninguna reproyección.
-a_ullr <ulx> <uly> <lrx> <lry>
Asigna los límites georreferenciados del archivo de salida.
-a_nodata <value>
Asigna un valor de datos nulos especificado a las bandas de salida.
-mo <META-TAG>=<VALUE>
Pasa una clave y un valor de metadatos para establecerlos en el conjunto de datos de salida, si es posible.
-co <NAME>=<VALUE>
Muchos formatos tienen una o más opciones de creación opcionales que se pueden utilizar para controlar detalles sobre el archivo creado. Por ejemplo, el controlador GeoTIFF soporta opciones de creación para controlar la compresión y si el archivo debe estar en mosaico.

Las opciones de creación disponibles varían según el controlador del formato, y algunos formatos simples no tienen opciones de creación en absoluto. Se puede listar una lista de opciones soportadas para un formato con la opción de línea de comandos --format , pero la documentación del formato es la fuente definitiva de información sobre las opciones de creación del controlador. Véase Controladores ráster documentación específica del formato para las opciones de creación válidas de cada formato.

-q
Suprime el monitor de progreso y otras salidas que no sean de error.
-if <input_dataset>
Añadido en la versión 3.3.

Nombre del conjunto de datos de entrada de GDAL que sirve como plantilla para los valores por defecto de las opciones -outsize, -bands, -ot, -a_srs, -a_ullr y -a_nodata. Tenga en cuenta que los valores de los píxeles no se copiarán .

<out_dataset>
El nombre del archivo de destino.

EJEMPLOS

Ejemplo 1: Inicializar un nuevo archivo GeoTIFF con un valor uniforme de 10

gdal_create -outsize 20 20 -a_srs EPSG:4326 -a_ullr 2 50 3 49 -burn 10 out.tif

Ejemplo 2: Crear un archivo PDF a partir de un archivo de composición XML

gdal_create -co COMPOSITION_FILE=composition.xml out.pdf

Ejemplo 3: Inicializar un archivo GeoTIFF en blanco a partir de uno de entrada

gdal_create -if prototype.tif output.tif
