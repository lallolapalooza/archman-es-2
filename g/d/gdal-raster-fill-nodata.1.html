NOMBRE

gdal-raster-fill-nodata - Rellena valores sin datos en un conjunto de datos ráster

Añadido en la versión 3.11.

SINOPSIS

Uso: gdal raster fill-nodata [OPCIONES] <ENTRADA> <SALIDA>
Rellena regiones ráster sin datos mediante interpolación desde los bordes.
Argumentos posicionales:
  -i, --input <ENTRADA>                                  Conjuntos de datos ráster de entrada [requerido]
  -o, --output <SALIDA>                                 Conjunto de datos ráster de salida [requerido]
Opciones comunes:
  -h, --help                                           Muestra el mensaje de ayuda y sale
  --json-usage                                         Muestra el uso como documento JSON y sale
  --config <CLAVE>=<VALOR>                             Opción de configuración [puede repetirse]
  -q, --quiet                                          Modo silencioso (sin barra de progreso)
Opciones:
  -f, --of, --format, --output-format <FORMATO-DE-SALIDA>  Formato de salida ("GDALG" permitido)
  --co, --creation-option <CLAVE>=<VALOR>                Opción de creación [puede repetirse]
  --overwrite                                          Si se permite sobrescribir la salida existente
                                                       Excluyente mutuamente con --append
  --append                                             Añadir como subconjunto de datos a la salida existente
                                                       Excluyente mutuamente con --overwrite
  -b, --band <BANDA>                                    Banda de entrada (índice basado en 1) (predeterminado: 1)
  -d, --max-distance <DISTANCIA_MÁXIMA>                    La distancia máxima (en píxeles) que el algoritmo buscará para encontrar valores a interpolar. (predeterminado: 100)
  -s, --smoothing-iterations <ITERACIONES_SUAVIZADO>    El número de iteraciones de suavizado con filtro promedio 3x3 a ejecutar después de la interpolación para atenuar artefactos. El valor predeterminado es cero iteraciones de suavizado. (predeterminado: 0)
  --mask <MÁSCARA>                                        Usar la primera banda del archivo especificado como máscara de validez (cero es inválido, distinto de cero es válido).
  --strategy <ESTRATEGIA>                                Por defecto, los píxeles se interpolan utilizando una ponderación por distancia inversa (invdist). También es posible elegir una estrategia de vecino más cercano (nearest).. STRATEGY=invdist|nearest (predeterminado: invdist)
Opciones avanzadas:
  --if, --input-format <FORMATO-DE-ENTRADA>                  Formatos de entrada [puede repetirse]
  --oo, --open-option <CLAVE>=<VALOR>                    Opciones de apertura [puede repetirse]

DESCRIPCIÓN

gdal raster fill-nodata rellena áreas sin datos interpolando desde píxeles válidos alrededor de los bordes del área.

Este subcomando también está disponible como un paso potencial de gdal raster pipeline (desde GDAL 3.12)

OPCIONES

Las siguientes opciones están disponibles:

-f, --of, --format, --output-format <FORMATO-DE-SALIDA>
Qué formato ráster de salida usar. Los valores permitidos pueden darse por gdal --formats | grep raster | grep rw | sort
--co <NOMBRE>=<VALOR>
Muchos formatos tienen una o más opciones de creación opcionales que pueden usarse para controlar detalles sobre el archivo creado. Por ejemplo, el controlador GeoTIFF admite opciones de creación para controlar la compresión y si el archivo debe estar en mosaico.

Puede repetirse.

Las opciones de creación disponibles varían según el controlador de formato, y algunos formatos simples no tienen opciones de creación en absoluto. Una lista de opciones admitidas para un formato puede listarse con la --formats opción de línea de comando, pero la documentación del formato es la fuente definitiva de información sobre las opciones de creación del controlador. Véase Controladores ráster documentación específica del formato para las opciones de creación válidas de cada formato.

--overwrite
Permite al programa sobrescribir el archivo o conjunto de datos de destino existente. De lo contrario, por defecto, gdal genera un error si el archivo o conjunto de datos de destino ya existe.
--output-layer <CAPA-DE-SALIDA>
Nombre de la capa de salida.
--overwrite
Permite al programa sobrescribir el archivo o conjunto de datos de destino existente. De lo contrario, por defecto, gdal genera un error si el archivo o conjunto de datos de destino ya existe.
-b <BANDA>
Selecciona una <BANDA> de entrada a procesar. Las bandas se numeran desde 1. El valor predeterminado es la primera banda del conjunto de datos de entrada.
-max-distance <DISTANCIA_MÁXIMA>
Especifica la distancia máxima (en píxeles) que el algoritmo buscará para encontrar valores a interpolar. El valor predeterminado es 100 píxeles.
--smoothing-iterations <ITERACIONES_SUAVIZADO>
Especifica el número de iteraciones de suavizado a aplicar al ráster rellenado. Esto puede ayudar a reducir artefactos en las áreas rellenadas. El valor predeterminado es 0 iteraciones.
--strategy <ESTRATEGIA>
Selecciona la <ESTRATEGIA> de interpolación a usar. Por defecto, los píxeles se interpolan utilizando una ponderación por distancia inversa (invdist). También es posible elegir una estrategia de vecino más cercano (nearest) .
--mask <MÁSCARA>
Usar la primera banda del archivo especificado como máscara de validez (cero es inválido, distinto de cero es válido).

Añadido en la versión 3.12.

GDALG SALIDA (CONJUNTO DE DATOS EN TIEMPO REAL / EN FLUJO)

Este programa admite la serialización de la línea de comandos como un archivo JSON usando el GDALG formato de salida. El archivo resultante puede luego abrirse como un conjunto de datos ráster usando el GDALG: GDAL Streamed Algorithm controlador, y aplicar la tubería especificada de una manera en tiempo real / en flujo.

NOTA:

Sin embargo, este algoritmo no es nativamente compatible con el flujo. En consecuencia, se generará un conjunto de datos temporal, lo que puede causar un tiempo de procesamiento significativo al abrir.

EJEMPLOS

Ejemplo 1: Rellenar áreas sin datos en un ráster

El comando especifica usar la segunda banda del ráster de entrada, 50 px de distancia máxima, 3 iteraciones de suavizado y la estrategia nearest para la interpolación. La salida se guardará en output.tif.

gdal raster fill-nodata -b 2 --max-distance 50 --smoothing-iterations 3 \
    --strategy nearest --mask mask.tif \
    input.tif output.tif
