NOMBRE

gdal-raster-aspect - Genera un mapa de aspecto

Añadido en la versión 3.11.

SINOPSIS

Uso: gdal raster aspect [OPCIONES] <ENTRADA> <SALIDA>
Genera un mapa de aspecto
Argumentos posicionales:
  -i, --input <ENTRADA>                                Datos ráster de entrada [requerido]
  -o, --output <SALIDA>                                Conjunto de datos ráster de salida [requerido]
Opciones comunes:
  -h, --help                                           Muestra el mensaje de ayuda y sale
  --json-usage                                         Muestra el uso como documento JSON y sale
  --config <CLAVE>=<VALOR>                             Opción de configuración [puede repetirse]
  -q, --quiet                                          Modo silencioso (sin barra de progreso)
Opciones:
  -f, --of, --format, --output-format <FORMATO-SALIDA>  Formato de salida ("GDALG" permitido)
  --co, --creation-option <CLAVE>=<VALOR>             Opción de creación [puede repetirse]
  --overwrite                                          Si se permite sobrescribir la salida existente
                                                       Mutuamente excluyente con --append
  --append                                             Añadir como subconjunto de datos a la salida existente
                                                       Mutuamente excluyente con --overwrite
  -b, --band <BANDA>                                    Banda de entrada (índice basado en 1) (predeterminado: 1)
  --convention <CONVENIO>                              Convenio para los ángulos de salida. CONVENIO=azimuth|trigonometric-angle (predeterminado: azimuth)
  --gradient-alg <GRADIENT-ALG>                        Algoritmo utilizado para calcular el gradiente del terreno. GRADIENT-ALG=Horn|ZevenbergenThorne (predeterminado: Horn)
  --zero-for-flat                                      Si se debe generar cero para áreas planas
  --no-edges                                           No intentar interpolar valores en los bordes del conjunto de datos o cerca de valores nulos
Opciones avanzadas:
  --if, --input-format <FORMATO-ENTRADA>               Formatos de entrada [puede repetirse]
  --oo, --open-option <CLAVE>=<VALOR>                 Opciones de apertura [puede repetirse]

DESCRIPCIÓN

gdal raster aspect genera un mapa de aspecto, a partir de cualquier ráster de elevación compatible con GDAL.

Este subcomando también está disponible como un paso potencial de gdal raster pipeline

Genera un ráster de punto flotante de 32 bits con valores entre 0° y 360° que representan el azimut hacia el que miran las pendientes. La definición del azimut es tal que: - 0° significa que la pendiente mira al Norte, - 90° mira al Este, - 180° mira al Sur - y 270° mira al Oeste (siempre que la parte superior de tu ráster de entrada esté orientada al norte).

El valor de aspecto -9999 se utiliza como valor nulo para indicar un aspecto indefinido en áreas planas con pendiente=0.

También se emitirá un valor nulo en el conjunto de datos de destino si se encuentra al menos un píxel establecido en el valor nulo dentro de la ventana de 3x3 centrada alrededor de cada píxel de origen. Por defecto, el algoritmo calculará valores en los bordes de la imagen o si se encuentra un valor nulo en la ventana de 3x3, interpolando los valores faltantes, a menos que se especifique --no-edges, en cuyo caso se aplicará un borde de 1 píxel alrededor de la imagen con el valor nulo.

Opciones estándar

-f, --of, --format, --output-format <FORMATO-SALIDA>
Qué formato de ráster de salida usar. Los valores permitidos pueden ser obtenidos con gdal --formats | grep raster | grep rw | sort
--co <NOMBRE>=<VALOR>
Muchos formatos tienen una o más opciones de creación opcionales que se pueden usar para controlar detalles sobre el archivo creado. Por ejemplo, el controlador GeoTIFF soporta opciones de creación para controlar la compresión y si el archivo debe ser dividido en teselas.

Puede repetirse.

Las opciones de creación disponibles varían según el controlador de formato y algunos formatos simples no tienen opciones de creación en absoluto. Una lista de opciones compatibles con un formato se puede listar con la opción de línea de comandos --formats, pero la documentación del formato es la fuente definitiva de información sobre las opciones de creación del controlador. Consulte la documentación específica del formato de Controladores ráster para conocer las opciones de creación legales para cada formato.

--overwrite
Permite al programa sobrescribir el archivo o conjunto de datos de destino existente. De lo contrario, por defecto, gdal genera un error si el archivo o conjunto de datos de destino ya existe.
-b, --band <BANDA>
Índice (comenzando en 1) de la banda a la que se debe calcular el aspecto.
--convention azimuth|trigonometric-angle
Convenio para los ángulos de salida.

Por defecto es azimuth, es decir: - 0° significa que la pendiente mira al Norte, - 90° mira al Este, - 180° mira al Sur - y 270° mira al Oeste (siempre que la parte superior de tu ráster de entrada esté orientada al norte).

Si se establece en trigonometric-angle, - 0° significa que la pendiente mira al Este, - 90° mira al Norte, - 180° mira al Oeste - y 270° mira al Sur.

--gradient-alg Horn|ZevenbergenThorne
Algoritmo utilizado para calcular el gradiente del terreno. El valor predeterminado es Horn. La literatura sugiere que Zevenbergen & Thorne es más adecuado para paisajes suaves, mientras que la fórmula de Horn funciona mejor en terrenos más accidentados.
--zero-for-flat
Si se debe generar cero para áreas planas. Por defecto, las áreas planas donde la pendiente es nula se asignarán un valor nulo (-9999). Al configurar esta opción, se establecen en 0.
--no-edges
No intentar interpolar valores en los bordes del conjunto de datos o cerca de valores nulos.

SALIDA GDALG (EN TIEMPO REAL / CONJUNTO DE DATOS EN STREAMING)

Este programa admite la serialización de la línea de comandos como un archivo JSON utilizando el formato de salida GDALG. El archivo resultante puede luego abrirse como un conjunto de datos ráster utilizando el controlador GDALG: GDAL Streamed Algorithm, y aplicar el pipeline especificado de manera en tiempo real / streaming.

EJEMPLOS

Ejemplo 1: Genera un mapa de aspecto a partir de un archivo DTED0.

$ gdal raster aspect n43.dt0 out.tif --overwrite
