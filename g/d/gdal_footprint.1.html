gdal_footprint(1)

NAME

gdal_footprint — Compute the footprint of a raster file as a vector layer.

SYNOPSIS

gdal_footprint [-of output_format] [-t_srs target_srs] [-split_polys] [-densify distance] [-min_ring_area area] [-convex_hull] [-simplify tolerance] [-max_points max_points] [-dsco NAME=VALUE] [-lyr_name value] [-overwrite] src_filename dst_filename

DESCRIPTION

The gdal_footprint utility computes the geographical footprint of a raster dataset and writes it as a vector layer to a file. The footprint is the bounding box of the raster's valid data.

The following command-line options are available:

-of output_format
Select the output vector format driver. Defaults to GeoJSON.
-t_srs target_srs
Coordinate system of the output vector layer. Defaults to the source raster's coordinate system.
-split_polys
Split the polygon into multiple polygons if it's a multipolygon.
-densify distance
Densify the output geometry by adding intermediate points. The distance is the maximum distance between two consecutive points.
-min_ring_area area
Filter out rings with an area smaller than the specified value.
-convex_hull
Compute the convex hull of the footprint.
-simplify tolerance
Simplify the output geometry using the specified tolerance.
-max_points max_points
Limit the number of points in the output geometry.
-dsco NAME=VALUE
Dataset creation option (format specific)
-lyr_name value
Name of the target layer. footprint if not specified.
-overwrite
Overwrite the target layer if it exists.
src_filename
The source raster file name.
dst_filename
The destination vector file name. If the file and the output layer exist, the new footprint is appended to them, unless -overwrite is used.

Post-vectorization geometric operations are applied in the following order:

  • optional splitting (-split_polys)
  • optional densification (-densify)
  • optional reprojection (-t_srs)
  • optional filtering by minimum ring area (-min_ring_area)
  • optional application of convex hull (-convex_hull)
  • optional simplification (-simplify)
  • limitation of number of points (-max_points)

C API

This utility is also callable from C with GDALFootprint().

EXAMPLES

Example 1: Compute the footprint of a GeoTIFF file as a GeoJSON file

gdal_footprint -t_srs EPSG:4326 input.tif output.geojson

The footprint will be written using WGS84 longitude, latitude coordinates, regardless of the spatial reference system used by the input raster.
