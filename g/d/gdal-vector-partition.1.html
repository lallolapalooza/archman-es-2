DESCRIPCIÓ

N

gdal vector partition distribuye features en diferentes archivos, dependiendo de los valores que la feature tome en un subconjunto de campos especificado por el

usuario.

Hay disponibles dos esquemas de

partición:
  • hive, correspondiente a Apache Hive partitioning, es el predeterminado.

    Cada campo de partición corresponde a un directorio anidado. Consideremos una capa con los campos "continent" y "country", elegidos como campos de partición. Todas las features donde "continent" evalúe a "Europe" y "country" evalúe a "France", se escribirán en el subdirectorio "continent=Europe/country=France/" del directorio de

    salida.

    Los valores NULL para los campos de partición se codifican como __HIVE_DEFAULT_PARTITION__ en el nombre del directorio. Los caracteres no ASCII, espacio, signo igual, o caracteres no compatibles con las restricciones de los nombres de directorio se codifican porcentaje (por ejemplo, %20 para

    espacio)
    • .
  • flat donde los archivos se escriben directamente bajo el directorio de salida usando un patrón de nombre de archivo predeterminado de {LAYER_NAME}_
    • {FIELD
_VALUE}
_%10d.

Por defecto, se usará el formato del conjunto de datos de entrada para el salida, si se puede determinar y el controlador de entrada soporta la escritura. De lo contrario, --format debe

usarse.

gdal vector partition puede usarse como el último paso de una

canalización.
