NOMBRE

gdal-raster-select - Selecciona un subconjunto de bandas de un conjunto de datos ráster Añadido en la versión 3.11.

Añadido en la versión 3.11.

SINOPSIS

Uso: gdal raster select [OPCIONES] <ENTRADA> <SALIDA> <BANDA>
Selecciona un subconjunto de bandas de un conjunto de datos ráster.
Argumentos posicionales:
  -i, --input <ENTRADA>                                  Conjuntos de datos ráster de entrada [requerido]
  -o, --output <SALIDA>                                  Conjunto de datos ráster de salida [requerido]
  -b, --band <BANDA>                                    Banda(s) (índice basado en 1, 'mask' o 'mask:<banda>') [1.. valores] [requerido]
Opciones comunes:
  -h, --help                                           Muestra el mensaje de ayuda y sale
  --json-usage                                         Muestra el uso como documento JSON y sale
  --config <CLAVE>=<VALOR>                             Opción de configuración [puede repetirse]
  -q, --quiet                                          Modo silencioso (sin barra de progreso)
Opciones:
  -f, --of, --format, --output-format <FORMATO-SALIDA>  Formato de salida ("GDALG" permitido)
  --co, --creation-option <CLAVE>=<VALOR>                Opción de creación [puede repetirse]
  --overwrite                                          Si se permite sobrescribir la salida existente
                                                       Excluyente mutuamente con --append
  --append                                             Añadir como subconjunto de datos a la salida existente
                                                       Excluyente mutuamente con --overwrite
  --mask <MASCARA>                                        Banda de máscara (índice basado en 1, 'mask', 'mask:<banda>' o 'none')
Opciones avanzadas:
  --if, --input-format <FORMATO-ENTRADA>                  Formatos de entrada [puede repetirse]
  --oo, --open-option <CLAVE>=<VALOR>                    Opciones de apertura [puede repetirse]

DESCRIPCIÓN

gdal raster select puede usarse para seleccionar y reordenar un subconjunto de bandas ráster de un conjunto de datos ráster.

Este subcomando también está disponible como un paso potencial de gdal raster pipeline

Opciones estándar

-f, --of, --format, --output-format <FORMATO-SALIDA>
Qué formato de salida ráster usar. Los valores permitidos pueden darse con gdal --formats | grep raster | grep rw | sort
--co <NOMBRE>=<VALOR>
Muchos formatos tienen una o más opciones de creación opcionales que pueden usarse para controlar detalles sobre el archivo creado. Por ejemplo, el controlador GeoTIFF admite opciones de creación para controlar la compresión y si el archivo debe estar en mosaico.

Puede repetirse.

Las opciones de creación disponibles varían según el controlador de formato, y algunos formatos simples no tienen opciones de creación en absoluto. Una lista de opciones admitidas para un formato puede listarse con la --formats opción de la línea de comandos, pero la documentación del formato es la fuente definitiva de información sobre las opciones de creación del controlador. Véase Controladores ráster documentación específica del formato para las opciones de creación válidas de cada formato.

--overwrite
Permite al programa sobrescribir el archivo o conjunto de datos de destino existente. De lo contrario, por defecto, gdal da error si el archivo o conjunto de datos de destino ya existe.
--band <BANDA>
Selecciona una o varias bandas de entrada. Las bandas se numeran desde 1. Se pueden seleccionar varios valores para seleccionar un conjunto de bandas de entrada que escribir en el archivo de salida, o para reordenar bandas. El valor especial mask significa la banda de máscara de la primera banda del conjunto de datos de entrada. La banda de máscara de cualquier banda puede especificarse con mask:<banda>. Una banda de máscara seleccionada con --band se convertirá en una banda ordinaria en el conjunto de datos de salida.
--mask <BANDA>
Selecciona una banda de entrada para crear la banda de máscara del conjunto de datos de salida. Las bandas se numeran desde 1. El valor especial mask significa la banda de máscara de la primera banda del conjunto de datos de entrada. La banda de máscara de cualquier banda puede especificarse con mask:<banda>. <BANDA> puede establecerse a none para evitar copiar la máscara global del conjunto de datos de entrada si existe. De lo contrario, se copia por defecto, a menos que la máscara sea un canal alfa, o si se selecciona explícitamente como una banda regular del conjunto de datos de salida (--band mask)

SALIDA GDALG (CONJUNTO DE DATOS EN TIEMPO REAL / EN FLUJO)

Este programa admite la serialización de la línea de comandos como un archivo JSON usando el GDALG formato de salida. El archivo resultante puede luego abrirse como un conjunto de datos ráster usando el GDALG: GDAL Streamed Algorithm controlador, y aplicar la canalización especificada de una manera en tiempo real / en flujo.

EJEMPLOS

Ejemplo 1: Reordenar un conjunto de datos de 3 bandas con las bandas ordenadas Azul, Verde, Rojo a Rojo, Verde, Azul

$ gdal raster select --band 3,2,1 bgr.tif rgb.tif --overwrite

Ejemplo 2: Convertir un conjunto de datos RGBA a un GeoTIFF comprimido YCbCR JPEG

$ gdal raster select --band 1,2,3 --mask 4 --co COMPRESS=JPEG,PHOTOMETRIC=YCBCR rgba.tif rgb_mask.tif
