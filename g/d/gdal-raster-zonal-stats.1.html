DESCRIPCIÓ

N

gdal raster zonal-stats calcula estadísticas zonales de ráster -- un resumen de los valores de píxel dentro de zonas especificadas ya sea por características poligonales o un ráster

categórico.
[imagen] Elevación media calculada para cada polígono a partir de un ráster de elevación..
UNINDENT

Se puede proporcionar un ráster de ponderación además del ráster de origen, lo que permite calcular estadísticas como condiciones meteorológicas con media ponderada por

población.

Todas las entradas deben proporcionarse en el mismo sistema de referencia espacial. Si lo

s rásteres de entrada usan diferentes resoluciones, se remuestrearán a una resolución con
sistente usando remuestreo por promedio. Sin embargo, no se realiza ninguna reproyección.

Inclusión de píxeles y

ponderación

Cuando las zonas se definen usando polígonos, hay tres métodos disponibles para determinar qué píxeles incluir en el cálculo. Por defecto, las geometrías se rasterizan usando parámetros predeterminados, y los píxeles incluidos en la rasterización se usan en el cálculo con ponderación igual. Usando --pixels all-touched, se usan todos los píxeles tocados por el polígono en el cálculo, también con ponderación igual. Si se usa --pixels fractional, se calcula la fracción de cada píxel que está cubierta por el polígono, y los píxeles se ponderan de acue

rdo con esta fracción. Esta opción requiere que GDAL esté comp
ilado contra la versión 3.14 o posterior de la biblioteca GEOS.

Especifica la estrategia de procesamiento (raster o feature), cuando se utilizan zonas vectoriales. En la estrategia predeterminada (--strategy feature), GDAL iterará sobre las entidades del conjunto de datos de zonas, leerá los píxeles correspondientes del ráster y escribirá las estadísticas de esa entidad. Esto evita la necesidad de leer todo el conjunto de datos de entidades en memoria a la vez, pero puede causar que los mismos píxeles se lean varias veces si las entidades de polígono son grandes o no están ordenadas espacialmente. Si --strategy raster se usa, GDAL iterará sobre fragmentos del conjunto de datos de ráster, encontrará las zonas de polígono correspondientes y actualizará las estadísticas de esas entidades.
