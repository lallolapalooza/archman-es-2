NOMBRE

gdal-vsi - Punto de entrada para comandos de la Interfaz de Archivo Virtual de GDAL (VSI)

Añadido en la versión 3.11.

Los subcomandos de gdal vsi permiten la manipulación de archivos ubicados en los Sistemas de Archivos Virtuales de GDAL (comprimidos, alojados en red, etc.): /vsimem, /vsizip, /vsitar, /vsicurl, ....

SINOPSIS

Uso: gdal vsi <SUBCOMANDO> [OPCIONES]
donde <SUBCOMANDO> es uno de:
  copy:   Copia archivos ubicados en la Interfaz de Archivo Virtual de GDAL (VSI). (alias: cp)
  delete: Elimina archivos ubicados en la Interfaz de Archivo Virtual de GDAL (VSI). (alias: rm, rmdir, del)
  list:   Lista archivos de una de las Interfaces de Archivo Virtual de GDAL (VSI). (alias: ls)
  move:   Mueve/renombra un archivo/directorio ubicado en la Interfaz de Archivo Virtual de GDAL (VSI). (alias: mv, ren, rename)
  sozip:  Comandos ZIP optimizados para búsqueda (SOZIP).
  sync:   Sincroniza archivos/directorios de origen y destino ubicados en la Interfaz de Archivo Virtual de GDAL (VSI).
Opciones Comunes:
  -h, --help              Muestra el mensaje de ayuda y sale
  --json-usage            Muestra el uso como documento JSON y sale
  --config <CLAVE>=<VALOR>  Opción de configuración [puede repetirse]

SUB-COMANDOS DISPONIBLES

  • gdal vsi copy
  • gdal vsi delete
  • gdal vsi list
  • gdal vsi move
  • gdal vsi sync
  • gdal vsi sozip

EJEMPLOS

Ejemplo 1: Listar recursivamente archivos en /vsis3/bucket con detalles

$ gdal vsi list -lR --of=text /vsis3/bucket
