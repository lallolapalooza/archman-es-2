NOMBRE

gdal-raster-unscale - Convierte los valores escalados de un conjunto de datos ráster en valores no escalados

Añadido en la versión 3.11.

SINOPSIS

Uso: gdal raster unscale [OPCIONES] <ENTRADA> <SALIDA>
Convierte los valores escalados de un conjunto de datos ráster en valores no
escalados.
Argumentos posicionales:
  -i, --input <ENTRADA>                                    Conjuntos de datos ráster de entrada [requerido]
  -o, --output <SALIDA>                                    Conjunto de datos ráster de salida [requerido]
Opciones Comunes:
  -h, --help                                               Muestra el mensaje de ayuda y sale
  --json-usage                                             Muestra el uso como un documento JSON y sale
  --config <CLAVE>=<VALOR>                                 Opción de configuración [puede repetirse]
  -q, --quiet                                              Modo silencioso (sin barra de progreso)
Opciones:
  -f, --of, --format, --output-format <FORMATO-SALIDA>      Formato de salida ("GDALG" permitido)
  --co, --creation-option <CLAVE>=<VALOR>                Opción de creación [puede repetirse]
  --overwrite                                              Permitir sobrescribir la salida existente
                                                           Mutuamente excluyente con --append
  --append                                                 Añadir como subconjunto de datos a la salida existente
                                                           Mutuamente excluyente con --overwrite
  --ot, --datatype, --output-data-type <TIPO-DATOS-SALIDA>  Tipo de datos de salida. TIPO-DATOS-SALIDA=Byte|Int8|UInt16|Int16|UInt32|Int32|UInt64|Int64|CInt16|CInt32|Float16|Float32|Float64|CFloat32|CFloat64
Opciones Avanzadas:
  --if, --input-format <FORMATO-ENTRADA>                   Formatos de entrada [puede repetirse]
  --oo, --open-option <CLAVE>=<VALOR>                    Opciones de apertura [puede repetirse]

DESCRIPCIÓN

gdal raster unscale aplica la metadatos de escala/desplazamiento para las bandas para convertir los valores escalados en valores no escalados.

Si el tipo de datos de la banda de entrada es Byte, Int8, UInt16, Int16, UInt32, Int32, Int64, UInt64, Float16 o Float32, el tipo de datos de salida predeterminado será Float32. Si el tipo de datos de la banda de entrada es Float64, se mantendrá como el tipo de datos de salida predeterminado. Si el tipo de datos de la banda de entrada es CInt16, CFloat16 o CFloat32, el tipo de datos de salida predeterminado será Float32. Si el tipo de datos de la banda de entrada es CFloat64, se mantendrá como el tipo de datos de salida predeterminado.

El valor no escalado se calcula a partir del valor crudo escalado con la siguiente fórmula:


{valor\_no\_escalado} = {valor\_escalado} * {escala} + {desplazamiento}



Si una de las bandas de entrada no tiene metadatos de escala/desplazamiento, sus valores se mantienen sin modificar.

Este comando es la operación inversa de gdal raster scale.

Este subcomando también está disponible como un posible paso de gdal raster pipeline

Opciones estándar

-f, --of, --format, --output-format <FORMATO-SALIDA>
Qué formato de ráster de salida usar. Los valores permitidos pueden ser proporcionados por gdal --formats | grep raster | grep rw | sort
--co <NOMBRE>=<VALOR>
Muchos formatos tienen una o más opciones de creación opcionales que se pueden usar para controlar detalles sobre el archivo creado. Por ejemplo, el controlador GeoTIFF admite opciones de creación para controlar la compresión y si el archivo debe ser embaldosado.

Puede repetirse.

Las opciones de creación disponibles varían según el controlador de formato, y algunos formatos simples no tienen opciones de creación en absoluto. Una lista de opciones admitidas para un formato se puede obtener con la opción de línea de comandos --formats, pero la documentación del formato es la fuente definitiva de información sobre las opciones de creación del controlador. Consulte la documentación específica del formato de Controladores ráster para conocer las opciones de creación legales para cada formato.

--overwrite
Permite al programa sobrescribir el archivo o conjunto de datos de destino existente. De lo contrario, por defecto, gdal genera un error si el archivo o conjunto de datos de destino ya existe.
--ot, --datatype, --output-data-type <TIPO-DATOS-SALIDA>
Tipo de datos de salida entre Byte, Int8, UInt16, Int16, UInt32, Int32, UInt64, Int64, CInt16, CInt32, Float32, Float64, CFloat32, CFloat64.

SALIDA GDALG (CONJUNTO DE DATOS EN TIEMPO REAL / EN FLUJO)

Este programa admite la serialización de la línea de comandos como un archivo JSON utilizando el formato de salida GDALG. El archivo resultante puede abrirse como un conjunto de datos ráster utilizando el controlador GDALG: GDAL Streamed Algorithm, y aplicar el pipeline especificado de forma en tiempo real / en flujo.

EJEMPLOS

Ejemplo 1: Escalar un ráster escalado a uno Float32

$ gdal raster unscale scaled_byte.tif unscaled_float32.tif --overwrite
