NOMBRE

gdal-mdim-convert - Convertir un conjunto de datos multidimensional

Añadido en la versión 3.11.

SINOPSIS

Uso: gdal mdim convert [OPCIONES] <ENTRADA> <SALIDA>
Convierte un conjunto de datos multidimensional.
Argumentos posicionales:
  -i, --input <ENTRADA>                                Conjunto de datos ráster de entrada o ráster multidimensional [requerido]
  -o, --output <SALIDA>                                Conjunto de datos ráster multidimensional de salida (creado por el algoritmo) [requerido]
Opciones comunes:
  -h, --help                                           Mostrar mensaje de ayuda y salir
  --json-usage                                         Mostrar uso como documento JSON y salir
  --config <CLAVE>=<VALOR>                             Opción de configuración [puede repetirse]
  -q, --quiet                                          Modo silencioso (sin barra de progreso)
Opciones:
  -f, --of, --format, --output-format <FORMATO-SALIDA>  Formato de salida
  --co, --creation-option <CLAVE>=<VALOR>            Opción de creación [puede repetirse]
  --overwrite                                          Permitir sobrescribir la salida existente
  --array <ESPECIFICACION-ARRAY>                       Seleccionar un único array en lugar de convertir todo el conjunto de datos. [puede repetirse]
  --array-option <CLAVE>=<VALOR>                     Opción pasada a GDALGroup::GetMDArrayNames() para filtrar arrays. [puede repetirse]
  --group <ESPECIFICACION-GRUPO>                       Seleccionar un único grupo en lugar de convertir todo el conjunto de datos. [puede repetirse]
  --subset <ESPECIFICACION-SUBSET>                     Seleccionar un subconjunto de los datos. [puede repetirse]
  --scale-axes <ESPECIFICACION-ESCALADO-EJES>        Aplica un factor de escala integral a una o varias dimensiones [puede repetirse]
  --strict                                             Convertir advertencias en fallos.
Opciones avanzadas:
  --oo, --open-option <CLAVE>=<VALOR>                  Opciones de apertura [puede repetirse]
  --if, --input-format <FORMATO-ENTRADA>               Formatos de entrada [puede repetirse]

DESCRIPCIÓN

gdal mdim convert se puede usar para convertir datos multidimensionales entre diferentes formatos.

Las siguientes opciones están disponibles:

Opciones estándar

-f, --of, --format, --output-format <FORMATO-SALIDA>
Selecciona el formato de salida. Este puede ser un formato que admita salida multidimensional (como NetCDF: Network Common Data Form, Multidimensional VRT), o formatos 2D "clásicos", si solo resulta un único array 2D de las otras operaciones de conversión especificadas. Cuando esta opción no se especifica, el formato se deduce cuando es posible a partir de la extensión del nombre de archivo de destino.
--co, --creation-option <CLAVE>=<VALOR>
Muchos formatos tienen una o más opciones de creación opcionales que se pueden usar para controlar detalles del archivo creado.

Las opciones de creación disponibles varían según el controlador de formato, y algunos formatos simples no tienen ninguna opción de creación. Se puede listar una lista de opciones admitidas para un formato con la opción de línea de comandos --format, pero la documentación del formato es la fuente definitiva de información sobre las opciones de creación del controlador. Consulte la documentación específica del formato de Controladores ráster para conocer las opciones de creación legales para cada formato.

Las opciones de creación a nivel de array se pueden pasar prefijándolas con ARRAY:. Consulte GDALGroup::CopyFrom() para obtener más detalles sobre dichas opciones.

--overwrite
Permite que el programa sobrescriba el archivo o conjunto de datos de destino existente. De lo contrario, por defecto, gdal genera un error si el archivo o conjunto de datos de destino ya existe.
--array <especificación_array>
En lugar de convertir todo el conjunto de datos, selecciona un array y, posiblemente, realiza operaciones sobre él. Esta opción se puede especificar varias veces para operar en diferentes arrays.

<especificación_array> puede ser solo un nombre de array, potencialmente usando una sintaxis completamente calificada (/grupo/subgrupo/nombre_array). O puede ser una combinación de opciones con la sintaxis: name={nombre_array_origen}[,dstname={nombre_array_destino}][,resample=yes][,transpose=[{eje1},{eje2},...][,view={expresion_vista}]

Las siguientes opciones se procesan en este orden:

  • resample=yes solicita que el array pase por GDALMDArray::GetResampled().
[{eje1},{eje2},...] es el argumento de GDALMDArray::Transpose().
Por ejemplo, transpose=[1,0] cambia el orden de los ejes de un array 2D. Ver Ejemplo 5.
•
{expresion_vista} es el valor del argumento viewExpr de GDALMDArray::GetView(). Ver Ejemplo 4.

Al especificar una expresion_vista que realiza un corte o subconjunto en una dimensión, la operación equivalente se aplicará a la variable de indexación correspondiente.

--array-option <NOMBRE>=<VALOR>
Opción pasada a GDALGroup::GetMDArrayNames() para filtrar los arrays reportados. Dicha opción es específica del formato. Consulte la documentación del controlador. Esta opción se puede usar varias veces.
--group <especificación_grupo>
En lugar de convertir todo el conjunto de datos, selecciona un grupo y, posiblemente, realiza operaciones sobre él. Esta opción se puede especificar varias veces para operar en diferentes grupos. Si solo se especifica un grupo, su contenido se copiará directamente al grupo raíz de destino. Si se especifican varios, se copiarán bajo el grupo raíz de destino.

<especificación_grupo> puede ser solo un nombre de grupo, potencialmente usando una sintaxis completamente calificada (/grupo/subgrupo/nombre_subsubgrupo). O puede ser una combinación de opciones con la sintaxis: name={nombre_grupo_origen}[,dstname={nombre_grupo_destino}][,recursive=no]

--subset <especificación_subconjunto>
Realiza una operación de subconjunto (recorte o corte) a lo largo de una dimensión, siempre que esté indexada por una variable 1D de tipo de datos numérico o de cadena, y cuyos valores estén ordenados monótonamente. <especificación_subconjunto> sigue exactamente la codificación KVP de OGC WCS 2.0 para subconjuntos.

Es decir, dim_name(valor_min,valor_max) o dim_name(valor_cortado). La primera sintaxis recortará la dimensión dim_name a valores en el rango [valor_min,valor_max]. La segunda sintaxis cortará la dimensión dim_name al valor valor_cortado (y esta dimensión se eliminará de los arrays que la referencian).

Usar --subset es incompatible con especificar una opción view en --array.

Ver Ejemplo 2.

-scaleaxes <especificación_escalado_ejes>
Aplica un factor de escala integral a una o varias dimensiones, es decir, extrae 1 valor cada N valores (sin remuestreo).

Es decir, <nombre_dim1>(<factor_escala>)[,<nombre_dim2>(<factor_escala>)]...

Usar --scaleaxes es incompatible con especificar una opción view en --array.

Ver Ejemplo 3.

--strict
Por defecto, se toleran algunos fallos durante la traducción, como no poder escribir atributos de grupo. Al establecer esta opción, dichos fallos harán que el proceso falle.

Opciones avanzadas

--oo <NOMBRE>=<VALOR>
Opción de apertura del conjunto de datos (específica del formato).

Puede repetirse.

--if <formato>
Nombre del formato/controlador que se intentará utilizar para abrir los archivos de entrada. Generalmente no es necesario especificarlo, pero puede usarse para omitir la detección automática del controlador, cuando esta falla en seleccionar el controlador apropiado. Esta opción puede repetirse varias veces para especificar varios controladores candidatos. Nótese que no obliga a esos controladores a abrir el conjunto de datos. En particular, algunos controladores tienen requisitos sobre las extensiones de archivo.

Puede repetirse.

EJEMPLOS

Ejemplo 1: Convertir un archivo netCDF a un archivo VRT multidimensional

gdal mdim convert in.nc out.vrt

Ejemplo 2: Extraer una sección 2D de un arreglo tiempo,Y,X

gdal mdim convert in.nc out.tif --subset "time(\"2010-01-01\")" --array temperature

Ejemplo 3: Submuestrear a lo largo de los ejes X e Y

gdal mdim convert in.nc out.nc --scaleaxes "X(2),Y(2)"

Ejemplo 4: Reordenar los valores de un arreglo

Reordenar los valores del arreglo tiempo,Y,X a lo largo del eje Y de arriba a abajo a abajo a arriba (o viceversa)

gdal mdim convert in.nc out.nc --array "name=temperature,view=[:,::-1,:]"

Ejemplo 5: Transponer un arreglo que tiene el orden de dimensiones X,Y,tiempo a tiempo,Y,X

gdal mdim convert in.nc out.nc --array "name=temperature,transpose=[2,1,0]"
