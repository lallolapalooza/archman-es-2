NOMBRE

gdal-vsi-list - Listar archivos de la Interfaz del Sistema Virtual de GDAL (VSI)

Añadido en la versión 3.11.

SINOPSIS

Uso: gdal vsi list [OPCIONES] <NOMBRE_ARCHIVO>
Listar archivos de la Interfaz del Sistema Virtual de GDAL (VSI).
Argumentos posicionales:
  --filename <NOMBRE_ARCHIVO>                                Nombre de archivo o directorio [requerido]
Opciones comunes:
  -h, --help                                           Mostrar mensaje de ayuda y salir
  --json-usage                                         Mostrar uso como documento JSON y salir
  --config <CLAVE>=<VALOR>                               Opción de configuración [se puede repetir]
Opciones:
  -f, --of, --format, --output-format <FORMATO-SALIDA>  Formato de salida. FORMATO-SALIDA=json|text
  -l, --long, --long-listing                           Usar un formato de listado largo
  -R, --recursive                                      Listar subdirectorios recursivamente
  --depth <PROFUNDIDAD>                                Máxima profundidad en modo recursivo
  --abs, --absolute-path                               Mostrar ruta absoluta
  --tree                                               Usar una presentación jerárquica para la salida JSON

DESCRIPCIÓN

gdal vsi list lista archivos de los Sistemas de Archivos Virtuales de GDAL (comprimidos, alojados en red, etc.): /vsimem, /vsizip, /vsitar, /vsicurl, ....

Esto es el equivalente al comando ls de UNIX, y gdal vsi ls es un alias para gdal vsi list.

Por defecto, produce nombres de archivo, en el nivel inmediato, sin detalles y en formato JSON.

Opciones

--filename <NOMBRE_ARCHIVO>
Cualquier nombre de archivo o directorio de uno de los sistemas de archivos virtuales de GDAL. Requerido.
-f, --of, --format, --output-format json|text
Qué formato de salida usar. El valor predeterminado es JSON, y a partir de GDAL 3.12, texto cuando se invoca desde la línea de comandos.
-l, --long, --long-listing
Usar un formato de listado largo, añadiendo permisos, tamaño de archivo y fecha de última modificación.
-R, --recursive
Listar subdirectorios recursivamente. Por defecto, la profundidad es ilimitada, pero puede reducirse con --depth.
--depth <PROFUNDIDAD>
Profundidad máxima en modo recursivo. 1 corresponde a ninguna recursión, 2 a los subdirectorios inmediatos, etc.
--abs, --absolute-path
Si se deben reportar los nombres de archivo como rutas absolutas. Por defecto, son relativas al nombre de archivo de entrada.
--tree
Usar una presentación jerárquica para la salida JSON, en lugar de una lista plana. Solo válido cuando --output-format está establecido a json (o se deja en su valor predeterminado).

EJEMPLOS

Ejemplo 1: Listar recursivamente archivos en /vsis3/bucket con detalles

$ gdal vsi list -lR --of=text /vsis3/bucket
