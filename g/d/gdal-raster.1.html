NOMBRE

gdal-raster - Punto de entrada para comandos ráster

Añadido en la versión 3.11.

SINOPSIS

Uso: gdal raster <SUBCOMANDO> [OPCIONES]
donde <SUBCOMANDO> es uno de:
  - as-features:     Crear entidades a partir de píxeles de un conjunto de datos ráster
  - aspect:          Generar un mapa de aspecto
  - blend:           Combinar/componer dos conjuntos de datos ráster
  - calc:            Realizar álgebra ráster
  - clean-collar:    Limpiar el borde de un conjunto de datos ráster, eliminando ruido.
  - clip:            Recortar un conjunto de datos ráster.
  - color-map:       Generar un conjunto de datos RGB o RGBA a partir de una sola banda, utilizando un mapa de colores
  - compare:         Comparar dos conjuntos de datos ráster.
  - contour:         Crea un contorno vectorial a partir de un modelo de elevación ráster (DEM).
  - convert:         Convertir un conjunto de datos ráster.
  - create:          Crear un nuevo conjunto de datos ráster.
  - edit:            Editar un conjunto de datos ráster.
  - fill-nodata:     Rellenar regiones ráster sin datos mediante interpolación desde los bordes.
  - footprint:       Calcular la huella de un conjunto de datos ráster.
  - hillshade:       Generar un mapa de relieve sombreado
  - index:           Crear un índice vectorial de conjuntos de datos ráster.
  - info:            Devolver información sobre un conjunto de datos ráster.
  - mosaic:          Construir un mosaico, ya sea virtual (VRT) o materializado.
  - neighbors:       Calcular el valor de cada píxel a partir de sus vecinos (estadísticas focales) (alias: neighbours)
  - nodata-to-alpha: Reemplazar los valores sin datos con una banda alfa.
  - overview:        Gestionar las vistas generales de un conjunto de datos ráster.
  - pansharpen:      Realizar una operación de pansharpening.
  - pipeline:        Procesar un conjunto de datos ráster aplicando varios pasos.
  - pixel-info:      Devolver información sobre un píxel de un conjunto de datos ráster.
  - polygonize:      Crear un conjunto de datos de entidades poligonales a partir de una banda ráster.
  - proximity:       Produce un mapa de proximidad ráster.
  - reclassify:      Reclasificar valores en un conjunto de datos ráster
  - reproject:       Reproyectar un conjunto de datos ráster.
  - resize:          Redimensionar un conjunto de datos ráster sin cambiar las extensiones georreferenciadas.
  - rgb-to-palette:  Convertir una imagen RGB en una imagen pseudo-color / paletizada.
  - roughness:       Generar un mapa de rugosidad
  - scale:           Escalar los valores de las bandas de un conjunto de datos ráster.
  - select:          Seleccionar un subconjunto de bandas de un conjunto de datos ráster.
  - set-type:        Modificar el tipo de datos de las bandas de un conjunto de datos ráster.
  - sieve:           Eliminar polígonos pequeños de un conjunto de datos ráster.
  - slope:           Generar un mapa de pendiente
  - stack:           Combinar bandas de entrada en una salida multibanda, ya sea virtual (VRT) o materializada.
  - tile:            Generar teselas en archivos separados a partir de un conjunto de datos ráster.
  - tpi:             Generar un mapa de Índice de Posición Topográfica (TPI)
  - tri:             Generar un mapa de Índice de Rugosidad del Terreno (TRI)
  - unscale:         Convertir los valores escalados de un conjunto de datos ráster en valores sin escalar.
  - update:          Actualizar el destino ráster con el contenido del de entrada.
  - viewshed:        Calcular la línea de vista de un conjunto de datos ráster.
  - zonal-stats:     Calcular estadísticas zonales ráster
Opciones comunes:
  -h, --help              Mostrar mensaje de ayuda y salir
  --json-usage            Mostrar el uso como documento JSON y salir
  --config <CLAVE>=<VALOR>  Opción de configuración [puede repetirse]
Opciones:
  --drivers               Mostrar la lista de drivers ráster como documento JSON

EJEMPLOS

Ejemplo 1: Obtener información del archivo utm.tif (con salida JSON)

$ gdal raster info utm.tif

Ejemplo 2: Convertir el archivo utm.tif a un ráster GeoPackage

$ gdal raster convert utm.tif utm.gpkg

Ejemplo 3: Obtener la lista de drivers ráster (con salida JSON)

$ gdal raster --drivers
