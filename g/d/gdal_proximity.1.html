NOMBRE

gdal_proximity - Produce un mapa de proximidad ráster.

SINOPSIS

gdal_proximity [--help] [--help-general]
                  <archivo_fuente> <archivo_destino> [-srcband <n>] [-dstband <n>]
                  [-of <formato>] [-co <nombre>=<valor>]...
                  [-ot Byte/UInt16/UInt32/Float32/etc]
                  [-values <n>,<n>,<n>] [-distunits {PIXEL|GEO}]
                  [-maxdist <n>] [-nodata <n>] [-use_input_nodata {YES|NO}]
                  [-fixed-buf-val <n>]

DESCRIPCIÓN

gdal_proximity genera un mapa de proximidad ráster que indica la distancia desde el centro de cada píxel hasta el centro del píxel más cercano identificado como píxel objetivo. Los píxeles objetivo son aquellos en el ráster fuente para los cuales el valor del píxel ráster se encuentra en el conjunto de valores de píxeles objetivo.

NOTA:

gdal_proximity es una utilidad de Python y solo está disponible si los enlaces de Python de GDAL están disponibles.
--help
Mostrar este mensaje de ayuda y salir
--help-general
Proporciona un breve mensaje de uso para las opciones genéricas de línea de comandos de GDAL y sale.
<archivo_fuente>
El archivo ráster fuente utilizado para identificar los píxeles objetivo.
<archivo_destino>
El archivo ráster de destino al que se escribirá el mapa de proximidad. Puede ser un archivo preexistente del mismo tamaño que archivo_fuente. Si no existe, se creará.
-srcband <n>
Identifica la banda en el archivo fuente a utilizar (por defecto es 1).
-dstband <n>
Identifica la banda en el archivo de destino a utilizar (por defecto es 1).
-of <formato>
Selecciona el formato de salida. Si no se especifica, el formato se deduce de la extensión. Utiliza el nombre corto del formato.
-co <NOMBRE>=<VALOR>
Muchos formatos tienen una o más opciones de creación opcionales que se pueden usar para controlar detalles sobre el archivo creado. Por ejemplo, el controlador GeoTIFF soporta opciones de creación para controlar la compresión y si el archivo debe ser en mosaicos.

Las opciones de creación disponibles varían según el controlador de formato, y algunos formatos simples no tienen opciones de creación. Se puede listar un conjunto de opciones disponibles para un formato con la opción de línea de comandos --format, pero la documentación del formato es la fuente definitiva de información sobre las opciones de creación del controlador. Consulte la documentación específica del formato Controladores ráster para conocer las opciones de creación legales para cada formato.

-ot <tipo>
Especifica un tipo de datos compatible con el controlador, que puede ser uno de los siguientes: Byte, UInt16, Int16, UInt32, Int32, Float32 (por defecto), o Float64.
-values <n>,<n>,<n>
Una lista de valores de píxel objetivo en la imagen fuente que se considerarán píxeles objetivo. Si no se especifica, se considerarán píxeles objetivo todos los píxeles distintos de cero.
-distunits {PIXEL|GEO}
Indica si las distancias generadas deben estar en coordenadas de píxel o georreferenciadas (por defecto PIXEL).
-maxdist <n>
La distancia máxima a generar. El valor nodata se usará para píxeles más allá de esta distancia. Si no se proporciona un valor nodata, se consultará la banda de salida para obtener su valor nodata. Si la banda de salida no tiene un valor nodata, se utilizará el valor 65535. La distancia se interpreta en píxeles a menos que se especifique -distunits GEO.
-nodata <n>
Especifica un valor nodata a utilizar para el ráster de proximidad de destino.
-use_input_nodata {YES|NO}
Indica si los píxeles nodata en el ráster de entrada deben ser nodata en el ráster de salida (por defecto NO).
-fixed-buf-val <n>
Especifica un valor a aplicar a todos los píxeles que se encuentren dentro de -maxdist de los píxeles objetivo (incluidos los píxeles objetivo) en lugar de un valor de distancia.
