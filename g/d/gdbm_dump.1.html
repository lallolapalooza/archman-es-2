NOMBRE

gdbm_dump - volcar una base de datos GDBM a un archivo

SINOPSIS

gdbm_dump [-H FMT] [--format=FMT] ARCHIVO_DB [ARCHIVO]

gdbm_dump [-Vh] [--help] [--usage] [--version]

DESCRIPCIÓN

La utilidad gdbm_dump crea un volcado del archivo de base de datos gdbm(3) especificado. El nombre para el archivo de volcado de salida se suministra mediante el segundo argumento (ARCHIVO). Si no se especifica, la salida va al error estándar.

El volcado creado puede ser proporcionado como argumento a la utilidad gdbm_load(1) para recrear una copia exacta del ARCHIVO_DB.

OPCIONES

-H, --format=FMT
Selecciona el formato del volcado. El valor binary (o 0) instruye a gdbm_dump a producir un volcado binario, compatible con versiones anteriores de gdbm (hasta la versión 1.9). El valor ascii (o 1) le instruye a crear un volcado ASCII (este es el valor por defecto). Este último es preferible porque, aparte de los datos reales, también contiene metadatos que permitirán a gdbm_load(1) recrear una copia exacta del archivo.
-h, --help
Imprime un resumen de uso corto.
--usage
Imprime una lista de opciones disponibles.
-V, --version
Imprime la versión del programa

VER TAMBIÉN

gdbm_load(1), gdbmtool(1), gdbm(3).
