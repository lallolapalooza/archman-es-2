DESCRIPCIÓ

N

gdal raster reclassify reclasifica valores en un conjunto de datos de entrada. Un archivo (o cadena de texto) especifica el mapeo de los valores de píxeles de entrada o rangos a archivos de

salida.

Se muestra un ejemplo de archivo a

continuación. 
# remap land cover types
0       = 10
# land [2,4] = 20 # freshwat
er 1 = 40 # ocean NO_DATA = N
O_DATA # leave NoData pixels unmodified

(El # carácter indica un comentario que es ignorado por el analizador pero puede hacer que el archivo sea más fácil de leer.) En este

caso:
  • los valores de entrada de 0 se emitirán como
    • 10
  • los valores de entrada entre 2 y 4 (inclusive) se emitirán como
    • 20
  • los valores de entrada de 1 se emitirán como
    • 40
  • los valores
    • NoData se
conservarán
como NoData

La presencia de cualquier otro valor en la entrada causará un error. Si esto no es deseado, se puede usar el rango de entrada DEFAULT para especificar un valor de salida para los píxeles no cubiertos por ningún otro rango de entrada. Estos píxeles pueden convertirse en NoData (DEFAULT = NO_DATA), alguna otra constante (por ejemplo, DEFAULT = 50), o dejarse sin modificar (DEFAULT = PASS_T

HROUGH).
