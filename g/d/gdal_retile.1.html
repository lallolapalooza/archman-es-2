Normalmente las teselas de la imagen base se almacenan como se
describe en
-targetDir . Para imágenes grandes, algunos sistemas de archivos tienen problemas de rendimiento si el número de archivos en un directorio es demasiado grande, causando que gdal_retile no termine en un tiempo razonable. Usar este parámetro crea una estructura de salida diferente. Las teselas de la imagen
base se almacenan en un subdirectorio llamado 0, las pirámides en subdirectorios numerados 1,2,.... Dentro de cada uno de estos directorios se crea
otro nivel de subdirectorios, numerados desde 0...n, dependiendo de cuántas filas de teselas se necesiten para cada nivel. Finalmente, un director
io contiene solo las teselas de una fila para un nivel específico. Para imágenes grandes se podría lograr una mejora de rendimiento de un factor N.
