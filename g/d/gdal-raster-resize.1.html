NOMBRE

gdal-raster-resize - Redimensionar un conjunto de datos ráster

Añadido en la versión 3.11.

SINOPSIS

Uso: gdal raster resize [OPCIONES] <ENTRADA> <SALIDA>
Redimensiona un conjunto de datos ráster sin cambiar las extenciones geo-referenciadas.
Argumentos posicionales:
  -i, --input <ENTRADA>                                  Conjuntos de datos ráster de entrada [requerido]
  -o, --output <SALIDA>                                Conjunto de datos ráster de salida [requerido]
Opciones comunes:
  -h, --help                                           Muestra el mensaje de ayuda y sale
  --json-usage                                         Muestra el uso como documento JSON y sale
  --config <CLAVE>=<VALOR>                               Opción de configuración [puede repetirse]
  -q, --quiet                                          Modo silencioso (sin barra de progreso)
Opciones:
  -f, --of, --format, --output-format <FORMATO-SALIDA>  Formato de salida ("GDALG" permitido)
  --co, --creation-option <CLAVE>=<VALOR>                Opción de creación [puede repetirse]
  --overwrite                                          Si se permite sobrescribir la salida existente
                                                       Mutuamente excluyente con --append
  --append                                             Añadir como subconjunto de datos a la salida existente
                                                       Mutuamente excluyente con --overwrite
  --resolution <xres>,<yres>                           Resolución objetivo (en unidades de la CRS de destino)
                                                       Mutuamente excluyente con --size
  --size <ancho[%]>,<alto[%]>                        Tamaño objetivo en píxeles (o porcentaje si se usa sufijo '%') [requerido]
                                                       Mutuamente excluyente con --resolution
  -r, --resampling <RESAMPLING>                        Método de remuestreo. RESAMPLING=nearest|bilinear|cubic|cubicspline|lanczos|average|mode (por defecto: nearest)

DESCRIPCIÓN

gdal raster resize se puede usar para redimensionar un conjunto de datos ráster sin cambiar las extenciones geo-referenciadas.

Este subcomando también está disponible como un paso potencial de gdal raster pipeline

Opciones estándar

-f, --of, --format, --output-format <FORMATO-SALIDA>
Qué formato de ráster de salida usar. Los valores permitidos pueden obtenerse con gdal --formats | grep raster | grep rw | sort
--co <NOMBRE>=<VALOR>
Muchos formatos tienen una o más opciones de creación opcionales que se pueden usar para controlar detalles sobre el archivo creado. Por ejemplo, el controlador GeoTIFF soporta opciones de creación para controlar la compresión y si el archivo debe ser segmentado.

Puede repetirse.

Las opciones de creación disponibles varían según el controlador de formato, y algunos formatos simples no tienen opciones de creación en absoluto. Una lista de opciones soportadas para un formato puede mostrarse con la opción de línea de comandos --formats, pero la documentación del formato es la fuente definitiva de información sobre las opciones de creación del controlador. Consulte la documentación específica del formato de Controladores ráster para conocer las opciones de creación legales para cada formato.

--overwrite
Permite que el programa sobrescriba el archivo o conjunto de datos de destino existente. De lo contrario, por defecto, gdal genera un error si el archivo o conjunto de datos de destino ya existe.
--resolution <xres>,<yres>
Añadido en la versión 3.12.

Establece la resolución del archivo de salida (en unidades geo-referenciadas de destino).

Mutuamente excluyente con --size.

--size <ancho[%]>,<alto[%]>
Establece el ancho y alto del ráster de salida, expresados en píxeles, o porcentaje si se usa el sufijo %. Si el ancho o el alto se establecen a 0, la otra dimensión se adivinará a partir de la resolución calculada.

Mutuamente excluyente con --resolution.

-r, --resampling <RESAMPLING>
Método de remuestreo a utilizar. Los métodos disponibles son:

nearest: remuestreo de vecino más cercano (por defecto, algoritmo más rápido, peor calidad de interpolación).

bilinear: remuestreo bilinear.

cubic: remuestreo cúbico.

cubicspline: remuestreo de spline cúbico.

lanczos: remuestreo de sinc con ventana de Lanczos.

average: remuestreo promedio, calcula el promedio ponderado de todos los píxeles contribuyentes que no son NODATA.

SALIDA GDALG (CONJUNTO DE DATOS ON-THE-FLY / STREAMED)

Este programa soporta la serialización de la línea de comandos como un archivo JSON usando el formato de salida GDALG. El archivo resultante puede luego abrirse como un conjunto de datos ráster usando el controlador GDALG: GDAL Streamed Algorithm, y aplicar la canalización especificada de forma on-the-fly / streamed.

EJEMPLOS

Ejemplo 1: Redimensionar un conjunto de datos a 1000 columnas y 500 líneas usando remuestreo cúbico

$ gdal raster resize --size=1000,500 -r cubic in.tif out.tif --overwrite

Ejemplo 2: Redimensionar un conjunto de datos a la mitad de tamaño usando remuestreo cúbico

$ gdal raster resize --size=50%,50% -r cubic in.tif out.tif --overwrite
