gdalmdiminfo(1)

Paquete: gdal

Licencias: custom

GDALMDIMINFO(1) GDAL GDALMDIMINFO(1)

NOMBRE

gdalmdiminfo - Informa de la estructura y el contenido de un conjunto de datos multidimensional

SINOPSIS

Los siguientes parámetros de línea de comandos pueden aparecer en cualquier orden

--help
Muestra este mensaje de ayuda y sale
--help-general
Proporciona un breve mensaje de uso para las opciones genéricas de línea de comandos de GDAL y sale.
-detailed
Salida más detallada. Informa sobre los tipos de datos de atributos y los valores de los arrays.
-nopretty
Salida en una sola línea sin ninguna indentación.
-array <nombre_array>
Nombre del array utilizado para restringir la salida al array especificado.
-limit <número>
Número de valores en cada dimensión que se utiliza para limitar la visualización de los valores de los arrays. Por defecto, ilimitado. Solo se tiene en cuenta si se usa con -detailed.
-oo <NOMBRE>=<VALOR>
Opción de apertura del conjunto de datos (específica del formato). Esta opción puede usarse varias veces.
-arrayoption <NOMBRE>=<VALOR>
Opción pasada a GDALGroup::GetMDArrayNames() para filtrar los arrays informados. Dicha opción es específica del formato. Consulte la documentación del controlador. Esta opción puede usarse varias veces.
-stats
Lee y muestra estadísticas del array. Fuerza el cálculo si no hay estadísticas almacenadas en un array.

Añadido en la versión 3.2.

-if <formato>
Nombre del formato/controlador a intentar para abrir el(los) archivo(s) de entrada. Generalmente no es necesario especificarlo, pero puede usarse para omitir la detección automática del controlador cuando esta falla al seleccionar el controlador apropiado. Esta opción puede repetirse varias veces para especificar varios controladores candidatos. Tenga en cuenta que no fuerza la apertura del conjunto de datos con esos controladores. En particular, algunos controladores tienen requisitos sobre las extensiones de archivo.

Añadido en la versión 3.2.

API C

Esta utilidad también se puede llamar desde C con GDALMultiDimInfo().
