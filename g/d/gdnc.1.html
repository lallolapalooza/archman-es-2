GDNC(1) Manual del sistema GNUstep GDNC(1)

NOMBRE

gdnc - Centro de Notificaciones Distribuidas de GNUstep

SINOPSIS

gdnc

DESCRIPCIÓN

El demonio gdnc es utilizado por los programas de GNUstep para enviar notificaciones y mensajes entre sí. Por defecto, utiliza comunicaciones interproceso privadas accesibles solo para el usuario actual en la máquina en la que se está ejecutando (donde el sistema operativo las soporta).

Cada usuario necesita tener su propia instancia de gdnc en ejecución. Si bien gdnc se iniciará automáticamente tan pronto como sea necesario, se recomienda iniciar gdnc en un script de inicio de sesión personal, como ~/.bashrc o ~/.cshrc. Alternativamente (si no tienes herramientas de línea de comandos que utilicen notificaciones distribuidas), puedes lanzar gdnc cuando se inicie tu sistema de ventanas o el gestor de ventanas. Por ejemplo, en sistemas con X11 puedes lanzar gdnc desde tu script .xinitrc o, alternativamente, si estás ejecutando Window Maker, inclúyelo en el script de inicio automático de Window Maker. Consulta la Guía de Compilación de GNUstep para ver un script de inicio de ejemplo.

OPCIONES

Para adjuntar gdnc a una sesión remota, utiliza el argumento

-NSHost nombre_host

Para ejecutar una copia del servidor para manejar notificaciones públicas (disponibles para todos los usuarios en la máquina local)

-GSPublic YES

Para ejecutar una copia del servidor para manejar notificaciones públicas de red (disponibles para todos los usuarios que puedan conectarse a la máquina local en la red)

-GSNetwork YES

DIAGNÓSTICOS

gdomap -L GDNCServer buscará instancias de gdnc que se lanzaron con los argumentos de línea de comandos NSHost, GSPublic o GSNetwork.

Alternativamente, gdomap -N listará todos los nombres registrados en el host local.

VER TAMBIÉN

gdomap(8), GNUstep(7), gpbs(1)
