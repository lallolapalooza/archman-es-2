NOMBRE

gdal-vsi-sozip - Comandos relacionados con SOZIP (ZIP optimizado para búsqueda).

Añadido en la versión 3.11.

DESCRIPCIÓN

La utilidad gdal vsi sozip se puede usar para:

  • crear un archivo SOZip (ZIP optimizado para búsqueda)
  • añadir archivos a un archivo ZIP/SOZip existente
  • listar el contenido de un archivo ZIP/SOZip
  • validar un archivo SOZip
  • convertir un archivo Zip existente en uno optimizado para SOZip

SINOPSIS

Uso: gdal vsi sozip <SUBCOMANDO> [OPCIONES]
donde <SUBCOMANDO> es uno de:
  - create:   Crear un archivo ZIP optimizado para búsqueda (SOZIP).
  - list:     Listar el contenido de un archivo ZIP, con información relacionada con SOZIP.
  - optimize: Crear un archivo ZIP optimizado para búsqueda (SOZIP) a partir de un archivo ZIP regular.
  - validate: Validar un archivo ZIP, posiblemente utilizando la optimización SOZIP.
Opciones comunes:
  -h, --help              Mostrar mensaje de ayuda y salir
  --json-usage            Mostrar uso como documento JSON y salir
  --config <CLAVE>=<VALOR>  Opción de configuración [puede repetirse]

GDAL VSI SOZIP CREATE

Descripción

Añade uno o varios archivos a un archivo zip nuevo o existente.

Sinopsis

Uso: gdal vsi sozip create [OPCIONES] <ENTRADA> <SALIDA>
Crear un archivo ZIP optimizado para búsqueda (SOZIP).
Argumentos posicionales:
  -i, --input <ENTRADA>                                          Nombres de archivo de entrada [puede repetirse] [requerido]
  -o, --output <SALIDA>                                        Nombre de archivo ZIP de salida [requerido]
Opciones comunes:
  -h, --help                                                   Mostrar mensaje de ayuda y salir
  --json-usage                                                 Mostrar uso como documento JSON y salir
  --config <CLAVE>=<VALOR>                                       Opción de configuración [puede repetirse]
  -q, --quiet                                                  Modo silencioso (sin barra de progreso)
Opciones:
  --overwrite                                                  Si se permite sobrescribir la salida existente
  -r, --recursive                                              Recorre la estructura del directorio de los directorios especificados recursivamente
  -j, --junk-paths, --no-paths                                 Almacena solo el nombre de un archivo guardado y no almacena nombres de directorio
  --enable-sozip <ENABLE-SOZIP>                                Si se aplica la optimización SOZIP automática/sistemática/nunca. ENABLE-SOZIP=auto|yes|no (por defecto: auto)
  --sozip-chunk-size <valor en bytes o con sufijo K/M>       Tamaño de bloque para un archivo optimizado para búsqueda (por defecto: 32768)
  --sozip-min-file-size <valor en bytes o con sufijo K/M/G>  Tamaño mínimo de archivo para decidir si un archivo debe ser optimizado para búsqueda (por defecto: 1 MB)
  --content-type <CONTENT-TYPE>                                Almacenar el Content-Type del archivo que se está añadiendo.

Opciones

-i, --input <ENTRADA>
Nombres de archivo de entrada. Requerido. Se aceptan varios nombres de archivo o de directorio.
-o, --output <SALIDA>
Nombre de archivo ZIP de salida. Requerido. Debe tener la extensión .zip
--overwrite
Si se permite sobrescribir la salida existente.
-r, --recursive
Recorre la estructura del directorio de los directorios especificados recursivamente.
-j, --junk-paths, --no-paths
Almacena solo el nombre de un archivo guardado (descarta la ruta) y no almacena nombres de directorio. Por defecto, sozip almacenará la ruta completa (relativa al directorio actual).
--enable-sozip auto|yes|no
En modo auto, un archivo se optimiza para búsqueda solo si su tamaño está por encima del valor de --sozip-min-file-size. En modo yes, todos los archivos de entrada se optimizarán para búsqueda. En modo no, ningún archivo de entrada se optimizará para búsqueda.
--sozip-chunk-size <valor>
Tamaño de bloque para un archivo optimizado para búsqueda. Por defecto es 32768 bytes. El valor se especifica en bytes, o se pueden usar los sufijos K y M (opcionalmente precedidos por un espacio) para especificar un valor en kilo-bytes o mega-bytes.
--sozip-min-file-size <valor>
Tamaño mínimo de archivo para decidir si un archivo debe ser optimizado para búsqueda, en modo --enable-sozip=auto. Por defecto es 1 MB. El valor se especifica en bytes, o se pueden usar los sufijos K, M o G (opcionalmente precedidos por un espacio) para especificar un valor en kilo-bytes, mega-bytes o giga-bytes.
--content-type <valor>
Almacena el Content-Type del archivo que se está añadiendo como un par clave-valor en la extensión del campo extra 'KV' (0x564b) dedicada a almacenar metadatos de pares clave-valor.
-q, --quiet
No muestres ningún mensaje informativo (solo errores).

Multiproceso

La opción de configuración GDAL_NUM_THREADS se puede establecer en ALL_CPUS o un valor entero para especificar el número de hilos a utilizar para archivos comprimidos con SOZip. Por defecto es ALL_CPUS.

Ejemplos

Ejemplo 1: Crear un archivo ZIP, potencialmente optimizado para búsqueda, con el contenido de my.gpkg

gdal vsi sozip create my.gpkg my.gpkg.zip

Ejemplo 2: Crear un archivo ZIP, potencialmente optimizado para búsqueda, a partir del contenido de un directorio fuente:

gdal vsi sozip create -r source_dir/ my.gpkg.zip

GDAL VSI SOZIP LIST

Descripción

Lista los archivos contenidos en el archivo zip en una salida similar a Info-ZIP unzip utilidad, pero con la adición de una columna que indica si cada archivo está optimizado para búsqueda.

Sinopsis

Uso: gdal vsi sozip list [OPTIONS] <INPUT>
Lista el contenido de un archivo ZIP, con información relacionada con SOZIP.
Argumentos posicionales:
  -i, --input <INPUT>     Nombre de archivo ZIP de entrada [obligatorio]
Opciones comunes:
  -h, --help              Muestra el mensaje de ayuda y sale
  --json-usage            Muestra el uso como documento JSON y sale
  --config <KEY>=<VALUE>  Opción de configuración [puede repetirse]

Opciones

-i, --input <INPUT>
Nombre de archivo ZIP de entrada. Obligatorio.

Ejemplos

Ejemplo 4: Listar el contenido de my.zip.

gdal vsi sozip list my.zip

GDAL VSI SOZIP VALIDATE

Descripción

Valida un archivo SOZip. La validación básica de ZIP se realiza de una manera ligera, limitada a poder navegar por los registros ZIP con el lector ZIP basado en InfoZIP utilizado por GDAL. Pero la validación de los aspectos específicos de SOZip se realiza de una manera más exhaustiva.

Sinopsis

Uso: gdal vsi sozip list [OPTIONS] <INPUT>
Lista el contenido de un archivo ZIP, con información relacionada con SOZIP.
Argumentos posicionales:
  -i, --input <INPUT>     Nombre de archivo ZIP de entrada [obligatorio]
Opciones comunes:
  -h, --help              Muestra el mensaje de ayuda y sale
  --json-usage            Muestra el uso como documento JSON y sale
  --config <KEY>=<VALUE>  Opción de configuración [puede repetirse]

Opciones

-i, --input <INPUT>
Nombre de archivo ZIP de entrada. Obligatorio.
-q, --quiet
No emitir ningún mensaje informativo (solo errores).
-v, --verbose
Activa el modo detallado.

Ejemplos

Ejemplo 5: Validar my.zip.

gdal vsi sozip validate my.zip
