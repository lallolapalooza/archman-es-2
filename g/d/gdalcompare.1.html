NOMBRE

gdalcompare - Compara dos imágenes.

SINOPSIS

gdalcompare [--help] [--help-general]
               [-dumpdiffs] [-skip_binary] [-skip_overviews]
               [-skip_geolocation] [-skip_geotransform]
               [-skip_metadata] [-skip_rpc] [-skip_srs]
               [-sds] <archivo_dorado> <archivo_nuevo>

DESCRIPCIÓN

gdalcompare compara dos conjuntos de datos compatibles con GDAL y reporta las diferencias. Además de reportar las diferencias a la salida estándar, el script también devolverá el recuento de diferencias en su valor de salida.

Se comprueban píxeles de imagen y varios metadatos. También se realiza una comparación byte a byte que contará como una diferencia. Por lo tanto, si solo es importante que los datos visibles de GDAL sean idénticos, un recuento de diferencias de 1 (la diferencia binaria) debería considerarse aceptable.

NOTA:

gdalcompare es una utilidad de Python y solo está disponible si hay disponibles bindings de Python para GDAL.
--help
Muestra este mensaje de ayuda y sale.
--help-general
Proporciona un breve mensaje de uso para las opciones de línea de comandos generales de GDAL y sale.
-dumpdiffs
Añadido en la versión 3.8.

Si se debe generar una salida de la diferencia en el contenido de los píxeles en un archivo TIFF en el directorio actual.

-skip_binary
Añadido en la versión 3.8.

Si se debe omitir la comparación exacta del contenido binario.

-skip_overviews
Añadido en la versión 3.8.

Si se debe omitir la comparación de las vistas generales (overviews).

-skip_geolocation
Añadido en la versión 3.8.

Si se debe omitir la comparación del dominio de metadatos GEOLOCATION.

-skip_geotransform
Añadido en la versión 3.8.

Si se debe omitir la comparación de la matriz de transformación geográfica (geotransform).

-skip_metadata
Añadido en la versión 3.8.

Si se deben omitir la comparación de metadatos.

-skip_rpc
Añadido en la versión 3.8.

Si se debe omitir la comparación del dominio de metadatos de Coeficientes Polinomiales Racionales (RPC).

-skip_srs
Añadido en la versión 3.8.

Si se debe omitir la comparación de los sistemas de referencia espacial (SRS).

-sds
Si se pasa esta bandera, el script comparará todos los subconjuntos de datos que forman parte del conjunto de datos; de lo contrario, los subconjuntos de datos se ignorarán.
<archivo_dorado>
El archivo que se considera correcto, denominado archivo dorado.
<archivo_nuevo>
El archivo que se compara con el archivo dorado, denominado archivo nuevo.

Tenga en cuenta que el script gdalcompare (como todos los demás scripts) también puede llamarse como una biblioteca desde código python: from osgeo_utils import gdalcompare. El punto de entrada principal es gdalcompare.compare_db() que toma un gdal.Dataset dorado y un gdal.Dataset nuevo como argumentos y devuelve un recuento de diferencias (excluyendo la comparación binaria). El punto de entrada gdalcompare.compare_sds() se puede utilizar para comparar subconjuntos de datos.

EJEMPLOS

gdalcompare -dumpdiffs N.tiff S.tiff; echo $?
Files differ at the binary level.
Band 1 checksum difference:
  Golden: 36694
  New:    40645
  Pixels Differing: 1509
  Maximum Pixel Difference: 255.0
  Wrote Diffs to: 1.tif
Differences Found: 2
2
gdalcompare N.tiff N.tiff; echo $?
Differences Found: 0
0
