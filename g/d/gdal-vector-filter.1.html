NOMBRE

gdal-vector-filter - Filtrar un conjunto de datos vectoriales

Añadido en la versión 3.11.

SINOPSIS

Uso: gdal vector filter [OPCIONES] <ENTRADA> <SALIDA>
Filtrar un conjunto de datos vectoriales.
Argumentos posicionales:
  -i, --input <ENTRADA>                                Conjuntos de datos vectoriales de entrada [requerido]
  -o, --output <SALIDA>                                Conjunto de datos vectoriales de salida [requerido]
Opciones comunes:
  -h, --help                                           Mostrar mensaje de ayuda y salir
  --json-usage                                         Mostrar uso como documento JSON y salir
  --config <CLAVE>=<VALOR>                             Opción de configuración [puede repetirse]
  -q, --quiet                                          Modo silencioso (sin barra de progreso)
Opciones:
  -l, --layer, --input-layer <CAPA-ENTRADA>            Nombre(s) de la capa de entrada [puede repetirse]
  -f, --of, --format, --output-format <FORMATO-SALIDA> Formato de salida ("GDALG" permitido)
  --co, --creation-option <CLAVE>=<VALOR>            Opción de creación [puede repetirse]
  --lco, --layer-creation-option <CLAVE>=<VALOR>       Opción de creación de capa [puede repetirse]
  --overwrite                                          Permitir sobrescribir la salida existente
  --update                                             Abrir conjunto de datos existente en modo de actualización
  --overwrite-layer                                    Permitir sobrescribir la capa de salida existente
  --append                                             Añadir a la capa existente
                                                       Mutuamente excluyente con --upsert
  --output-layer <CAPA-SALIDA>                         Nombre de la capa de salida
  --skip-errors                                        Omitir errores al escribir características
  --active-layer <CAPA-ACTIVA>                         Establecer capa activa (si no se especifica, todas)
  --bbox <BBOX>                                        Caja delimitadora como xmin,ymin,xmax,ymax
  --where <WHERE>|@<nombre-archivo>                   Consulta de atributos en una forma restringida de las consultas utilizadas en la cláusula WHERE de SQL
Opciones avanzadas:
  --if, --input-format <FORMATO-ENTRADA>               Formatos de entrada [puede repetirse]
  --oo, --open-option <CLAVE>=<VALOR>                  Opciones de apertura [puede repetirse]
  --output-oo, --output-open-option <CLAVE>=<VALOR>    Opciones de apertura de salida [puede repetirse]
  --upsert                                             Insertar o actualizar características (implica 'append')
                                                       Mutuamente excluyente con --append

DESCRIPCIÓN

gdal vector filter se puede usar para filtrar un conjunto de datos vectoriales desde su extensión espacial o una cláusula WHERE de SQL.

filter también se puede usar como un paso de la pipeline de gdal vector.

Opciones estándar

-f, --of, --format, --output-format <FORMATO-SALIDA>
Qué formato vectorial de salida usar. Los valores permitidos pueden darse con gdal --formats | grep vector | grep rw | sort
--co <NOMBRE>=<VALOR>
Muchos formatos tienen una o más opciones opcionales de creación de conjuntos de datos que se pueden utilizar para controlar detalles sobre el archivo creado. Por ejemplo, el controlador GeoPackage admite opciones de creación para controlar la versión.

Puede repetirse.

Las opciones de creación de conjuntos de datos disponibles varían según el controlador de formato, y algunos formatos simples no tienen opciones de creación en absoluto. Una lista de opciones admitidas para un formato se puede obtener con la opción de línea de comandos --formats, pero la documentación del formato es la fuente definitiva de información sobre las opciones de creación del controlador. Consulte la documentación específica del formato de los Controladores vectoriales para conocer las opciones de creación legales para cada formato.

Tenga en cuenta que las opciones de creación de conjuntos de datos son diferentes de las opciones de creación de capas.

-lco <NOMBRE>=<VALOR>
Opción de creación de capa (específica del formato)
--overwrite
Permitir que el programa sobrescriba el archivo o conjunto de datos de destino existente. De lo contrario, por defecto, gdal genera un error si el archivo o conjunto de datos de destino ya existe.
--active-layer <CAPA-ACTIVA>
Establecer la capa activa. Cuando se especifica, solo la capa especificada por su nombre será objeto del procesamiento. Las otras capas no se modificarán. Si esta opción no se especifica, todas las capas serán objeto del procesamiento.
--bbox <xmin>,<ymin>,<xmax>,<ymax>
Límites a los que filtrar el conjunto de datos. Se asumen en el CRS del conjunto de datos de entrada. Los ejes X e Y son los "amigables con GIS", es decir, X es longitud o este, e Y es latitud o norte. Tenga en cuenta que el filtrado no recorta las geometrías al cuadro delimitador.
--where <WHERE>|@<nombre-archivo>
Consulta de atributos (como SQL WHERE).

Opciones avanzadas

--oo <NOMBRE>=<VALOR>
Opción de apertura de conjunto de datos (específica del formato).

Puede repetirse.

--if <formato>
Nombre del formato/controlador que se intentará para abrir los archivos de entrada. Generalmente no es necesario especificarlo, pero se puede utilizar para omitir la detección automática del controlador, cuando falla al seleccionar el controlador apropiado. Esta opción se puede repetir varias veces para especificar varios controladores candidatos. Tenga en cuenta que no obliga a esos controladores a abrir el conjunto de datos. En particular, algunos controladores tienen requisitos sobre las extensiones de archivo.

Puede repetirse.

SALIDA GDALG (SOBRE LA MARCHA / CONJUNTO DE DATOS EN FLUJO)

Este programa admite la serialización de la línea de comandos como un archivo JSON utilizando el formato de salida GDALG. El archivo resultante se puede abrir como un conjunto de datos vectoriales utilizando el controlador GDALG: GDAL Streamed Algorithm, y aplicar la pipeline especificada de forma sobre la marcha / en flujo.

EJEMPLOS

Ejemplo 1: Seleccionar características de un archivo GeoPackage que intersecan el cuadro delimitador desde la longitud 2, latitud 49, hasta la longitud 3, latitud 50 en WGS 84

$ gdal vector filter --bbox=2,49,3,50 in.gpkg out.gpkg --overwrite
