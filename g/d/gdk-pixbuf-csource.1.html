Nombre

gdk-pixbuf-csource - Utilidad de generación de código C para imágenes GdkPixbuf

SINÓPSIS

gdk-pixbuf-csource [OPCIONES...] <IMAGEN>

DESCRIPCIÓN

gdk-pixbuf-csource es una pequeña utilidad que genera código C que contiene imágenes, útil para compilar imágenes directamente en programas.

gdk-pixbuf-csource toma como entrada el nombre de un archivo de imagen para generar código, o, usando la opción --build-list, una lista de pares (nombre, imagen) para generar código para una lista de imágenes en variables con nombre.

Esta herramienta está pensada principalmente para ser utilizada por compatibilidad hacia atrás. Las aplicaciones y bibliotecas recién escritas deberían usar GResource para incrustar activos de imagen en sus binarios.

OPCIONES

--stream

Genera un flujo de datos de pixbuf: una única cadena que contiene una estructura GdkPixdata serializada en orden de bytes de red.

--struct

Genera la estructura GdkPixdata; tu código necesita la definición de la estructura GdkPixdata de gdk-pixdata.h.

--macros

Genera definiciones de macros *_ROWSTRIDE, *_WIDTH, *_HEIGHT, *_BYTES_PER_PIXEL y *_RLE_PIXEL_DATA o *_PIXEL_DATA para la imagen.

--rle

Habilita la codificación de longitud de ejecución para los datos de píxeles generados (por defecto).

--raw

Deshabilita la codificación de longitud de ejecución para los datos de píxeles generados.

--extern

Genera símbolos externos.

--static

Genera símbolos estáticos (por defecto).

--decoder

Proporciona una definición de macro *_RUN_LENGTH_DECODE(image_buf, rle_data, size, bpp) para decodificar datos de imagen codificados con longitud de ejecución.

--name=identificador

Especifica el nombre del identificador (prefijo) para las variables o macros generadas (solo útil si no se especificó --build-list).

--build-list

Habilita el modo de análisis de pares (nombre, imagen).

-h, --help

Imprime una breve ayuda y sale.

-v, --version

Imprime la versión de la herramienta y sale.

--g-fatal-warnings

Convierte las advertencias en fatales y hace que el programa aborte.

VER TAMBIÉN

La documentación de GdkPixbuf, distribuida por gdk-pixbuf, y también disponible en línea en docs.gtk.org https://docs.gtk.org/gdk-pixbuf/.

ERRORES

El codificador de longitud de ejecución se desincroniza con los límites de los píxeles, ya que incluye el relleno de la anchura de fila en el flujo codificado. Además, genera pixbufs con anchuras de fila subóptimas en algunos casos.
