NOMBRE

gdal - Punto de entrada principal de gdal

Añadido en la versión 3.11.

SINOPSIS

Uso: gdal <COMANDO> [OPCIONES]
donde <COMANDO> es uno de:
  - convert:  Convierte un dataset (atajo para 'gdal raster convert' o 'gdal vector convert').
  - dataset:  Comandos para gestionar datasets.
  - driver:   Comando para operaciones específicas del driver.
  - info:     Devuelve información sobre un dataset (atajo para 'gdal raster info' o 'gdal vector info').
  - mdim:     Comandos multidimensionales.
  - pipeline: Procesa un dataset aplicando varios pasos.
  - raster:   Comandos ráster.
  - vector:   Comandos vectoriales.
  - vsi:      Comandos de la Interfaz de Sistema Virtual (VSI) de GDAL.
Opciones Comunes:
  -h, --help              Muestra el mensaje de ayuda y sale
  --json-usage            Muestra el uso como documento JSON y sale
  --config <CLAVE>=<VALOR>  Opción de configuración [puede repetirse]
Opciones:
  --version               Muestra la versión de GDAL y sale
  --drivers               Muestra la lista de drivers como documento JSON
'gdal <NOMBRE_ARCHIVO>' también puede usarse como atajo para 'gdal info <NOMBRE_ARCHIVO>'.
Y 'gdal read <NOMBRE_ARCHIVO> ! ...' como atajo para 'gdal pipeline <NOMBRE_ARCHIVO> ! ...'.

EJEMPLOS

Ejemplo 1: Obtener información del archivo utm.tif (con salida JSON)

$ gdal info utm.tif

Ejemplo 2: Convertir el archivo utm.tif a raster GeoPackage

$ gdal convert utm.tif utm.gpkg

Ejemplo 3: Obtener información sobre todos los comandos y subcomandos disponibles como un documento JSON.

$ gdal --json-usage

Ejemplo 4: Obtener la lista de todos los formatos soportados por la compilación actual de GDAL, en texto

$ gdal --formats

Ejemplo 5: Obtener la lista de todos los formatos soportados por la compilación actual de GDAL, en JSON.

$ gdal --formats --json
