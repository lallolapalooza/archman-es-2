DESCRIPCIÓ

N

gdal raster viewshed crea un ráster de visibilidad binario a partir de una banda del modelo de elevación ráster de entrada (DEM). El ráster de salida será de tipo Byte. Usando los valores DEM o ground de --mode también puede crear un ráster de altura mínima visible de tipo

Float64.

Utiliza el método definido en [Wang2000] para un punto definido por el

usuario.

Este subcomando también está disponible como un paso potencial de gdal raster pipeline (desde GDAL 3.

12)

--curvature-coefficient
<value>
Coeficiente para considerar el efecto de la curvatura y la refracción. Al calcular la visibilidad entre dos puntos (es decir, Línea de Visión o Visibilidad), la magnitud de este efecto varía con las condiciones atmosféricas y depende de la longitud de onda.

Diferentes aplicaciones para calcular la visibilidad usan diferentes notaciones intercambiables para describir este fenómeno: Coeficiente de Refracción, Coeficiente de Curvatura y Factor de Diámetro de la Esfera. gdal_viewshed usa la notación de Coeficiente de

Curvatura.


{CurvCoeff}=1-{RefractionCoeff}

Los cambios en la densidad del aire curvan la luz hacia abajo, haciendo que un observador pueda ver más lejos y que la Tierra parezca menos curva, como si el diámetro de la esfera (Tierra) fuera mayor de lo que realmente es. La razón entre ese diámetro de esfera imaginario y el diámetro de la esfera real está dada por la

fórmula:


{SphereDiameterFactor}=1/{CurvCoeff}=1/(1-{RefractionCoeff}

)



Para la luz visible, el coeficiente de refracción atmosférica estándar que generalmente se usa es 1/7. Por lo tanto, el valor predeterminado (desde GDAL 3.4) para CurvCoeff que usa gdal_viewshed es 0.85714 (=~ 1-1/7) para el CRS de la Tierra. A partir de GDAL 3.6, para CRS no terrestres (aquellos cuyo semieje mayor difiere en más de 5% con el de WGS 84), el valor predeterminado de CurvCoeff es 1.0, para tener en cuenta el caso de uso de no

refracción.

La altura del MDE se corrige de acuerdo con la siguiente

fórmula:


Height_{Corrected}=Height_{DEM}-{CurvCoeff}\frac{{TargetDistance}^2}{SphereDiameter}

SALIDA GDALG (DATASET EN TIEMPO DE EJECUCIÓN / EN

FLUJO)

Este programa soporta serializar la línea de comandos como un archivo JSON usando el formato de salida GDALG. El archivo resultante puede luego ser abierto como un dataset de ráster usando el GDALG: GDAL Streamed Algorithm driver, y aplicar la canalización especificada de una manera en tiempo de ejecución / en

flujo.

:
Sin embargo, este algoritmo no es nativamente comp

erará un dataset temporal, lo que puede causar un
tiempo de procesamiento significativo al abrirlo.
