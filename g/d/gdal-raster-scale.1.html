NOMBRE

gdal-raster-scale - Escala los valores de las bandas de un conjunto de datos ráster

Añadido en la versión 3.11.

SINOPSIS

Uso: gdal raster scale [OPCIONES] <ENTRADA> <SALIDA>
Escala los valores de las bandas de un conjunto de datos ráster.
Argumentos posicionales:
  -i, --input <ENTRADA>                                      Conjuntos de datos ráster de entrada [requerido]
  -o, --output <SALIDA>                                    Conjunto de datos ráster de salida [requerido]
Opciones comunes:
  -h, --help                                               Mostrar mensaje de ayuda y salir
  --json-usage                                             Mostrar uso como documento JSON y salir
  --config <CLAVE>=<VALOR>                                   Opción de configuración [puede repetirse]
  -q, --quiet                                              Modo silencioso (sin barra de progreso)
Opciones:
  -f, --of, --format, --output-format <FORMATO-SALIDA>      Formato de salida ("GDALG" permitido)
  --co, --creation-option <CLAVE>=<VALOR>                    Opción de creación [puede repetirse]
  --overwrite                                              Permitir sobrescribir archivo de salida existente
                                                           Mutuamente excluyente con --append
  --append                                                 Añadir como subconjunto de datos a la salida existente
                                                           Mutuamente excluyente con --overwrite
  --ot, --datatype, --output-data-type <TIPO-DATOS-SALIDA>  Tipo de datos de salida. TIPO-DATOS-SALIDA=Byte|Int8|UInt16|Int16|UInt32|Int32|UInt64|Int64|CInt16|CInt32|Float16|Float32|Float64|CFloat32|CFloat64
  -b, --band <BANDA>                                        Seleccionar banda para restringir el escalado (índice basado en 1)
  --src-min <SRCMIN>                                      Valor mínimo del rango de origen
  --src-max <SRCMAX>                                      Valor máximo del rango de origen
  --dst-min <DSTMIN>                                      Valor mínimo del rango de destino
  --dst-max <DSTMAX>                                      Valor máximo del rango de destino
  --exponent <EXPONENTE>                                    Exponente para aplicar escalado no lineal con una función de potencia
  --no-clip                                                No recortar los valores de entrada a [srcmin, srcmax]
Opciones avanzadas:
  --if, --input-format <FORMATO-ENTRADA>                      Formatos de entrada [puede repetirse]
  --oo, --open-option <CLAVE>=<VALOR>                        Opciones de apertura [puede repetirse]

DESCRIPCIÓN

gdal raster scale se puede usar para reescalar los valores de píxeles de entrada del rango --src-min a --src-max al rango --dst-min a --dst-max. También es a menudo necesario restablecer el tipo de datos de salida con el modificador --ot. Si se omite, el rango de salida va desde el valor mínimo hasta el valor máximo permitido para tipos de datos enteros (por ejemplo, de 0 a 255 para salida Byte) o de 0 a 1 para tipos de datos de punto flotante. Si se omite, el rango de entrada se calcula automáticamente a partir del conjunto de datos de origen. Esto puede ser una operación lenta en un conjunto de datos de origen grande y, si se usa varias veces para varias invocaciones de gdal_translate, podría ser beneficioso llamar a gdal raster edit --stats {conjunto_datos_fuente} previamente para precalcular estadísticas, para formatos que admitan la serialización de cálculos de estadísticas (GeoTIFF, VRT...). Los valores de origen se recortan al rango definido por srcmin y srcmax, a menos que se establezca --no-clip.

Por defecto, el escalado se aplica a todas las bandas. Es posible restringirlo a una sola banda con --band y dejar los valores de otras bandas sin modificar.

Este comando es la operación inversa de gdal raster unscale.

Este subcomando también está disponible como un paso potencial de gdal raster pipeline.

Opciones estándar

-f, --of, --format, --output-format <FORMATO-SALIDA>
Qué formato ráster de salida usar. Los valores permitidos se pueden obtener con gdal --formats | grep raster | grep rw | sort
--co <NOMBRE>=<VALOR>
Muchos formatos tienen una o más opciones de creación opcionales que se pueden usar para controlar particularidades del archivo creado. Por ejemplo, el controlador GeoTIFF admite opciones de creación para controlar la compresión y si el archivo debe ser en mosaico.

Puede repetirse.

Las opciones de creación disponibles varían según el controlador de formato, y algunos formatos simples no tienen ninguna opción de creación. Una lista de opciones compatibles con un formato se puede mostrar con la opción de línea de comandos --formats, pero la documentación del formato es la fuente definitiva de información sobre las opciones de creación del controlador. Consulte la documentación específica del formato de Controladores ráster para conocer las opciones de creación legales para cada formato.

--overwrite
Permite que el programa sobrescriba el archivo o conjunto de datos de destino existente. De lo contrario, por defecto, gdal genera un error si el archivo o conjunto de datos de destino ya existe.
--ot, --datatype, --output-data-type <TIPO-DATOS-SALIDA>
Tipo de datos de salida entre Byte, Int8, UInt16, Int16, UInt32, Int32, UInt64, Int64, CInt16, CInt32, Float32, Float64, CFloat32, CFloat64.
-b, --band <BANDA>
Índice (empezando en 1) de la banda a la que se debe aplicar el escalado.
--src-min <SRCMIN>
Valor mínimo del rango de origen. Si no se especifica, se calculará a partir del conjunto de datos de entrada. Esta opción debe usarse junto con --src-max.
--src-max <SRCMAX>
Valor máximo del rango de origen. Si no se especifica, se calculará a partir del conjunto de datos de origen. Esta opción debe usarse junto con --src-min.
--dst-min <DSTMIN>
Valor mínimo del rango de salida. Esta opción debe usarse junto con --dst-max.
--dst-max <DSTMAX>
Valor máximo del rango de salida. Esta opción debe usarse junto con --dst-min.
--exponent <EXPONENTE>
Aplica un escalado no lineal con una función de potencia. exp_val es el exponente de la función de potencia (debe ser positivo). Esta opción debe usarse con las opciones --src-min / --src-max / --dst-min / --dst-max.

El valor escalado Dst se calcula a partir del valor de origen Src con la siguiente fórmula:


{Dst} = \left( {Dst}_{max} - {Dst}_{min} \right) \times \operatorname{max} \left( 0, \operatorname{min} \left( 1, \left( \frac{{Src} - {Src}_{min}}{{Src}_{max}-{Src}_{min}} \right)^{exp\_val} \right) \right) + {Dst}_{min}



NOTA:

gdal raster unscale asume escalado lineal, y este comando no puede deshacer el escalado de valores a los originales.
--no-clip
Deshabilita el recorte de los valores de entrada al rango de origen. Tenga en cuenta que el uso de esta opción con escalado no lineal con un exponente no entero provocará que los valores de entrada inferiores al valor mínimo del rango de origen se mapeen a "no es un número".

NAME

gdal-raster-scale - Rescales pixel values of a raster layer

SYNOPSIS

gdal raster scale [options] <input dataset> <output dataset>

DESCRIPTION

The gdal-raster-scale utility converts pixel values of an input raster layer to new values, based on a linear scaling function.

The output values are calculated as follows:

out_value = (in_value - src_min) * (dst_max - dst_min) / (src_max - src_min) + dst_min

Where:

in_value is the pixel value in the input raster.

src_min and src_max are the minimum and maximum values in the input raster (or as specified with --src-min and --src-max).

dst_min and dst_max are the minimum and maximum values in the output raster (or as specified with --dst-min and --dst-max).

The available options are:

--datatype <type>
Output pixel data type. Supported types are Byte (8-bit unsigned integer), Int16 (16-bit signed integer), UInt16 (16-bit unsigned integer), Int32 (32-bit signed integer), UInt32 (32-bit unsigned integer), Float32 (32-bit floating point), Float64 (64-bit floating point).
--src-min <value>
Minimum value of the input raster. If not specified, the minimum value of the input raster is automatically computed.
--src-max <value>
Maximum value of the input raster. If not specified, the maximum value of the input raster is automatically computed.
--dst-min <value>
Minimum value of the output raster.
--dst-max <value>
Maximum value of the output raster.
--overwrite
Overwrite the output dataset if it exists.
--quiet
Suppress progress messages.
--format <format>
GDAL format of the output dataset. Defaults to GeoTIFF.
--band <band_number>
Input and output band number. Defaults to 1.
--nomd

GDALG OUTPUT (ON-THE-FLY / STREAMED DATASET)

The output of the command can be serialized as a JSON file using the GDALG output format. The resulting file can then be opened as a raster dataset using the GDALG: GDAL Streamed Algorithm driver, and apply the specified pipeline in a on-the-fly / streamed way.

EXAMPLES

Example 1: Rescale linearly values of a UInt16 dataset from [0,4095] to a Byte dataset [0,255]

$ gdal raster scale --datatype Byte --src-min 0 --src-max 4095 uint16.tif byte.tif --overwrite
