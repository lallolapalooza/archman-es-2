NOMBRE

gdal-vector-info - Obtener información sobre un conjunto de datos vectoriales

Añadido en la versión 3.11.

SINOPSIS

Uso: gdal vector info [OPCIONES] <ENTRADA>...
Devuelve información sobre un conjunto de datos vectoriales.
Argumentos posicionales:
  -i, --dataset, --input <ENTRADA>                       Conjuntos de datos vectoriales de entrada [puede repetirse] [requerido]
Opciones comunes:
  -h, --help                                           Mostrar mensaje de ayuda y salir
  --json-usage                                         Mostrar uso como documento JSON y salir
  --config <CLAVE>=<VALOR>                               Opción de configuración [puede repetirse]
Opciones:
  -f, --of, --format, --output-format <FORMATO-SALIDA>  Formato de salida. FORMATO-SALIDA=json|text
  -l, --layer, --input-layer <CAPA-ENTRADA>             Nombre de la capa de entrada [puede repetirse]
                                                       Mutuamente excluyente con --sql
  --features                                           Listar todas las características (cuidado con el consumo de RAM en capas grandes)
                                                       Mutuamente excluyente con --summary
  --summary                                            Listar los nombres de las capas y el tipo de geometría
                                                       Mutuamente excluyente con --features
  --limit <NUMERO-DE-CARACTERISTICAS>                  Limitar el número de características por capa (implica --features)
  --sql <sentencia>|@<nombre-archivo>                   Ejecutar la sentencia SQL indicada y devolver el resultado
                                                       Mutuamente excluyente con --input-layer
  --where <DONDE>|@<nombre-archivo>                   Consulta de atributos en una forma restringida de las consultas utilizadas en la cláusula WHERE de SQL
  --dialect <DIALECTO>                                  Dialecto SQL
  --update                                             Abrir el conjunto de datos en modo de actualización
Opciones avanzadas:
  --oo, --open-option <CLAVE>=<VALOR>                    Opciones de apertura [puede repetirse]
  --if, --input-format <FORMATO-ENTRADA>                 Formatos de entrada [puede repetirse]

DESCRIPCIÓN

gdal vector info lista diversa información sobre un conjunto de datos vectoriales compatible con GDAL.

A partir de GDAL 3.12, gdal vector info puede utilizarse como último paso de una canalización.

Las siguientes opciones están disponibles:

Opciones estándar

-f, --of, --format, --output-format json|text
Qué formato de salida usar. El valor predeterminado es JSON, y a partir de GDAL 3.12, texto cuando se invoca desde la línea de comandos.
-l, --layer, --input-layer <CAPA-ENTRADA>
Nombre de una o más capas a inspeccionar. Si no se pasan nombres de capa y no se especifica --sql, se seleccionarán todas las capas.
--summary
Imprimir un resumen con la lista de capas y el tipo de geometría de cada capa. Esta opción es mutuamente excluyente con la opción --features.
--features
Listar todas las características de forma predeterminada, a menos que se limite con --limit. Tenga cuidado con el consumo de RAM en capas grandes al usar la salida JSON. Esta opción es mutuamente excluyente con la opción --summary.
--limit <NUMERO-DE-CARACTERISTICAS>
Añadido en la versión 3.12.

Limitar el número de características reportadas por capa. Cuando se establece, esto implica --features.

--sql <sentencia>|@<nombre-archivo>
Ejecutar la sentencia SQL indicada y devolver el resultado. La sintaxis @<nombre-archivo> puede usarse para indicar que el contenido está en el archivo señalado (ej. @my_select.txt donde my_select.txt es un archivo en el directorio actual). Los datos también pueden ser editados con SQL INSERT, UPDATE, DELETE, DROP TABLE, ALTER TABLE etc si el conjunto de datos se abre en modo de actualización. Las capacidades de edición dependen del dialecto seleccionado con --dialect.

Esta opción es mutuamente excluyente con la opción --where.

--where <DONDE>|@<nombre-archivo>
Una consulta de atributos en una forma restringida de las consultas utilizadas en la sentencia SQL WHERE. Solo se reportarán las características que coincidan con la consulta de atributos. La sintaxis @<nombre-archivo> puede usarse para indicar que el contenido está en el archivo señalado.

Ejemplo de --where y comillas:

--where "\"Nombre del Punto Esquina\" COMO '%__00_00'"

Esta opción es mutuamente excluyente con la opción --sql.

--dialect <dialecto>
Dialecto SQL. En algunos casos, puede usarse para emplear el dialecto OGR SQL (no optimizado) en lugar del SQL nativo de un RDBMS pasando el valor de dialecto OGRSQL. El dialecto SQL SQLite puede ser seleccionado con los valores de dialecto SQLITE e INDIRECT_SQLITE, y esto puede usarse con cualquier fuente de datos.

Opciones avanzadas

--oo <NOMBRE>=<VALOR>
Opción de apertura del conjunto de datos (específica del formato).

Puede repetirse.

--if <formato>
Nombre del formato/controlador a intentar para abrir el archivo de entrada. Generalmente no es necesario especificarlo, pero puede usarse para omitir la detección automática del controlador, cuando esta falla en seleccionar el controlador apropiado. Esta opción puede repetirse varias veces para especificar varios controladores candidatos. Tenga en cuenta que no fuerza a esos controladores a abrir el conjunto de datos. En particular, algunos controladores tienen requisitos sobre las extensiones de archivo.

Puede repetirse.
