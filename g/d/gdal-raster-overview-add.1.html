NAME

gdal-raster-overview-add - Añadir vistas previas a un conjunto de datos ráster

Añadido en la versión 3.11.

SYNOPSIS

Uso: gdal raster overview add [OPCIONES] <ENTRADA>
Añadiendo vistas previas.
Argumentos posicionales:
  -i, --dataset, --input <ENTRADA>         Conjunto de datos (a actualizar in situ, a menos que se especifique --external) [obligatorio]
Opciones comunes:
  -h, --help                             Mostrar mensaje de ayuda y salir
  --json-usage                           Mostrar uso como documento JSON y salir
  --config <CLAVE>=<VALOR>                 Opción de configuración [puede repetirse]
  -q, --quiet                            Modo silencioso (sin barra de progreso)
Opciones:
  --overview-src <OVERVIEW-SRC>          Conjunto de datos de vista previa de origen [puede repetirse]
                                         Mutuamente excluyente con --levels
  --external                             Añadir vistas previas externas
  -r, --resampling <RESAMPLING>          Método de remuestreo. RESAMPLING=nearest|average|cubic|cubicspline|lanczos|bilinear|gauss|average_magphase|rms|mode
  --levels <LEVELS>                      Niveles / factores de decimation [puede repetirse]
                                         Mutuamente excluyente con --overview-src
  --min-size <MIN-SIZE>                  Ancho o alto máximo del nivel de vista previa más pequeño.
  --co, --creation-option <CLAVE>=<VALOR>  Opción de creación de vistas previas [puede repetirse]
Opciones avanzadas:
  --oo, --open-option <CLAVE>=<VALOR>      Opciones de apertura [puede repetirse]

DESCRIPCIÓN

gdal raster overview add se puede utilizar para construir o reconstruir imágenes de vistas previas para la mayoría de los formatos de archivo soportados con uno de varios algoritmos de submuestreo.

A partir de GDAL 3.12, gdal raster overview add se puede utilizar como un paso de una tubería. En ese caso, se generarán vistas previas virtuales en la salida del paso, y podrán materializarse potencialmente en el paso de escritura final, al escribir un archivo GeoTIFF con la opción de creación COPY_SRC_OVERVIEWS, o al escribir en un archivo COG (Cloud Optimized GeoTIFF).

Opciones

--dataset <DATASET>
Nombre del conjunto de datos, a actualizar in situ por defecto (a menos que se especifique --external). Obligatorio para ejecución independiente, implícito cuando se ejecuta como paso de tubería.
--external
Crear vistas previas externas .ovr como archivos GeoTIFF. No disponible cuando se ejecuta como paso de tubería.
--overview-src <ENTRADA>
Añadido en la versión 3.12.

Añadir los conjuntos de datos ráster de entrada especificados como vistas previas del conjunto de datos de destino. Las vistas previas de origen pueden provenir de cualquier formato soportado por GDAL, siempre que tengan el mismo número de bandas y la misma extensión geoespacial que el conjunto de datos de destino.

Este modo actualmente solo está implementado cuando el conjunto de datos de destino tiene formato GeoTIFF, o cuando se utiliza --external.

Mutuamente excluyente con --levels

--resampling {nearest|average|cubic|cubicspline|lanczos|bilinear|gauss|average_magphase|rms|mode}
Seleccionar un algoritmo de remuestreo. El valor por defecto es nearest, que generalmente no es apropiado si se desea precisión subpíxel.

Al actualizar vistas previas de TIFF existentes, se utilizará el método previamente usado, tal como se indica en el elemento de metadatos RESAMPLING de la vista previa, si no se especifica -r.

Los métodos disponibles son:

nearest aplica un remuestreador de vecino más cercano (muestreo simple).

average calcula el promedio de todos los píxeles contribuyentes que no son NODATA. Este es un promedio ponderado que tiene en cuenta adecuadamente el peso de los píxeles de origen que no contribuyen completamente al píxel de destino.

bilinear aplica un kernel de convolución bilineal.

cubic aplica un kernel de convolución cúbica.

cubicspline aplica un kernel de convolución B-Spline.

lanczos aplica un kernel sinc en ventana de Lanczos.

gauss aplica un kernel Gaussiano antes de calcular la vista previa, lo que puede llevar a mejores resultados que el promedio simple en casos de bordes nítidos con alto contraste o patrones ruidosos. Los valores de nivel recomendados deben ser 2, 4, 8, ... para que se seleccione un kernel Gaussiano de remuestreo de 3x3.

average_magphase promedia datos complejos en espacio de magnitud/fase.

rms calcula la raíz cuadrática media / media cuadrática de todos los píxeles contribuyentes no NODATA.

mode selecciona el valor que aparece con mayor frecuencia de todos los puntos muestreados.

--levels <nivel1,nivel2,...>
Una lista de niveles de vistas previas a construir. Cada nivel de vista previa debe ser un valor entero mayor o igual a 2.

Cuando no se especifican niveles explícitos,

  • Si ya existen vistas previas, se utilizarán los niveles correspondientes para actualizarlas si no se especifican niveles explícitos.
  • De lo contrario, se seleccionarán factores de potencia de dos apropiados para las vistas previas hasta que la vista previa más pequeña sea menor que el valor del modificador --min-size.

Mutuamente excluyente con --overview-src

--min-size <val>
Ancho o alto máximo del nivel de vista previa más pequeño. Solo se tiene en cuenta si no se especifican niveles explícitos. Por defecto es 256.
--co <NOMBRE>=<VALOR>
Añadido en la versión 3.12.

Opciones de creación de vistas previas. Pueden repetirse.

Muchos formatos tienen una o más opciones de creación opcionales que se pueden usar para controlar detalles sobre las vistas previas creadas. Las opciones disponibles se pueden obtener consultando la OverviewCreationOptionList devuelta por gdal --format <NOMBRE-FORMATO>.

La mayoría de los formatos admitirán vistas previas externas en un archivo GeoTIFF en un archivo lateral con la extensión .ovr. Puede consultar las opciones de creación de vistas previas para GeoTIFF.

EJEMPLOS

Ejemplo 1: Crear vistas previas, incrustadas en el archivo TIFF proporcionado, con cálculo automático de niveles

gdal raster overview add -r average abc.tif

Ejemplo 2: Crear vistas previas, incrustadas en el archivo TIFF proporcionado

gdal raster overview add -r average --levels=2,4,8,16 abc.tif

Ejemplo 3: Crear un archivo de vista previa GeoTIFF comprimido externo a partir del archivo ERDAS .IMG

gdal raster overview add --external --levels=2,4,8,16 --co COMPRESS=YES erdas.img

Ejemplo 4: Crear un archivo de vista previa GeoTIFF comprimido en JPEG externo a partir de un conjunto de datos RGB de 3 bandas

Si el conjunto de datos es un GeoTIFF escribible, también necesita agregar la opción --external para fo

rce la generación de resúmenes externos.

gdal raster overview add --co OVERVIEW=JPEG --co PHOTOMETRIC=YCBCR \
                         --co INTERLEAVE=PIXEL rgb_dataset.ext 2 4 8 16

Ejemplo 5: Crear resúmenes para un subconjunto de datos específico

Por ejemplo, una de las posibles muchas capas ráster en un GeoPackage (el parámetro "filename" debe ser el prefijo del controlador, el nombre del archivo y el nombre del subconjunto de datos, como por ejemplo lo muestra gdalinfo):

gdal raster overview add GPKG:file.gpkg:layer

Ejemplo 6: Agregar 3 conjuntos de datos existentes a escala 1:25K, 1:50K y 1:100K como resúmenes de my.tif.

gdal raster overview add --overview-src ovr_25k.tif --overview-src ovr_50k.tif --overview-src ovr_100k.tif --dataset my.tif

Ejemplo 7: Crear un archivo COG con niveles de resumen que no son potencias de dos.

gdal pipeline read input.tif ! reproject --dst-crs=EPSG:4326 ! add overview --levels 16,64,128 ! write output.tif --format=COG
