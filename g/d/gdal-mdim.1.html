NOMBRE

gdal-mdim - Punto de entrada para comandos multidimensionales

Añadido en la versión 3.11.

SINOPSIS

Uso: gdal mdim <SUBCOMANDO> [OPCIONES]
donde <SUBCOMANDO> es uno de:
  convert: Convierte un conjunto de datos multidimensional.
  info:    Devuelve información sobre un conjunto de datos multidimensional.
  mosaic:  Construye un mosaico, ya sea virtual (VRT) o materializado, a partir de conjuntos de datos multidimensionales.
Opciones comunes:
  -h, --help              Muestra el mensaje de ayuda y sale
  --json-usage            Muestra el uso como un documento JSON y sale
  --config <CLAVE>=<VALOR>  Opción de configuración [puede repetirse]
Opciones:
  --drivers               Muestra la lista de controladores multidimensionales como un documento JSON

SUB-COMANDOS DISPONIBLES

  • gdal mdim info
  • gdal mdim convert
  • gdal mdim mosaic

EJEMPLOS

Ejemplo 1: Obtener información del archivo temperaturas.nc (con salida JSON)

$ gdal mdim info temperaturas.nc

Ejemplo 2: Convertir el archivo temperaturas.nc a Zarr

$ gdal mdim convert temperatures.nc temperatures.zarr

Ejemplo 3: Obtener la lista de controladores multidimensionales (con salida JSON)

$ gdal mdim --drivers
