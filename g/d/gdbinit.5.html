GDBINIT(5) Herramientas de desarrollo GNU GDBINIT(5)

NOMBRE

gdbinit - Scripts de inicialización de GDB

SINOPSIS

~/.config/gdb/gdbinit

~/.gdbinit

./.gdbinit

DESCRIPCIÓN

Estos archivos contienen comandos de GDB para ejecutar automáticamente durante el inicio de GDB. Las líneas de contenido son secuencias de comandos almacenadas, descritas en el manual de GDB en el nodo "Sequences" -- comando shell "info -f gdb -n Sequences".

Por favor, lea más en el manual de GDB en el nodo "Startup" -- comando shell "info -f gdb -n Startup".

(no habilitado con "--with-system-gdbinit" durante la compilación)
Archivo de inicialización a nivel de sistema. Se ejecuta a menos que el usuario especifique la opción de GDB "-nx" o "-n". Ver más en el manual de GDB en el nodo "System-wide configuration" -- comando shell "info -f gdb -n 'System-wide configuration'".
(no habilitado con "--with-system-gdbinit-dir" durante la compilación)
Directorio de inicialización a nivel de sistema. Todos los archivos en este directorio se ejecutan al inicio a menos que el usuario especifique la opción de GDB "-nx" o "-n", siempre que tengan una extensión de archivo reconocida. Ver más en el manual de GDB en el nodo "System-wide configuration" -- comando shell "info -f gdb -n 'System-wide configuration'".
~/.config/gdb/gdbinit o ~/.gdbinit
Archivo de inicialización del usuario. Se ejecuta a menos que el usuario especifique las opciones de GDB "-nx", "-n" o "-nh".
.gdbinit
Archivo de inicialización para el directorio actual. Puede ser necesario habilitarlo con el comando de seguridad de GDB "set auto-load local-gdbinit". Ver más en el manual de GDB en el nodo "Init File in the Current Directory" -- comando shell "info -f gdb -n 'Init File in the Current Directory'".
