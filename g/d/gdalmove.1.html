NOMBRE

gdalmove - Transforma la georreferenciación de un archivo ráster en el lugar.

SINOPSIS

gdalmove [--help] [--help-general]
            [-s_srs <srs_defn>] -t_srs <srs_defn>
            [-et <max_pixel_err>] <target_file>

DESCRIPCIÓN

El script gdalmove transforma los límites de un archivo ráster de un sistema de coordenadas a otro, y luego actualiza el sistema de coordenadas y la geotransformación del archivo. Esto se hace sin alterar los valores de los píxeles en absoluto. Es similar en cierto modo a usar gdalwarp para transformar una imagen, pero evitando el paso de remuestreo para evitar daños en la imagen. Generalmente, solo es adecuado para transformaciones que son efectivamente lineales en el área del archivo.

Si no se proporciona ningún valor de umbral de error (-et), el archivo no se actualiza realmente, pero se informan los errores que se producirían. Si se proporciona -et, el archivo solo se modifica si el error aparente que se introduce es menor que el umbral indicado (en píxeles).

Actualmente, la geotransformación transformada se calcula basándose en la transformación de las esquinas superior izquierda, superior derecha e inferior izquierda. Se podría producir un error general reducido utilizando un ajuste por mínimos cuadrados de al menos los cuatro puntos de las esquinas.

NOTA:

gdalmove es una utilidad de Python y solo está disponible si las bindings de Python de GDAL están disponibles.
--help
Muestra este mensaje de ayuda y sale.
--help-general
Muestra un breve mensaje de uso para las opciones genéricas de la línea de comandos de GDAL y sale.
-s_srs <srs_defn>
Anula el sistema de coordenadas del archivo con la definición del sistema de coordenadas indicada. Opcional. Si no se proporciona, el sistema de coordenadas de origen se lee del archivo de origen.
-t_srs <srs_defn>
Define el sistema de coordenadas de destino. Este sistema de coordenadas se escribirá en el archivo después de una actualización.
-et <max_pixel_err>
El umbral de error (en píxeles) más allá del cual el archivo no se actualizará. Si no se proporciona, no se aplicará ninguna actualización al archivo, pero se informarán los errores.

<target_file>

El archivo sobre el que se va a operar. Para actualizar, este debe ser un formato de archivo que admita actualizaciones en el lugar de la geotransformación y el SRS.
