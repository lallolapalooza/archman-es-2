DESCRIPCIÓ

N

gdomap El demonio gdomap es utilizado por los programas de GNUstep para buscar objetos distribuidos de procesos que se ejecutan a través de la red (y entre diferentes cuentas de usuario en una sola máquina). El demonio NO se utiliza para la búsqueda cuando dos procesos que pertenecen al mismo usuario utilizan una conexión local al host. Esta página de manual explica el uso de gdomap. Para información de diseño e implementación (y notas especiales para empaquetadores), consulte la documentación HTML instalada en $GNUSTEP_SYSTEM_DOC, en Herramientas de Línea de

Comandos.

Normalmente, el demonio gdomap se inicia en el arranque del sistema y se enlaza al puerto 538. Véase la Guía de Compilación de GNUstep para un ejemplo de script de

inicio.

Por defecto, gdomap sondea cada máquina en la red local para ver si hay una copia de gdomap ejecutándose en ella. Esto se hace para redes de clase C y subredes de redes de clase C. Si su host está en una red de clase B o clase A, el comportamiento por defecto es tratarla como una de clase C y sondear solo los hosts que se esperarían en una red de clase C del mismo

número.

Si está ejecutando en una red de clase A o clase B, o si su red tiene un gran número de hosts que no tendrán gdomap en ellos, es posible que desee proporcionar un archivo de configuración que liste los hosts a sondear explícitamente, en lugar de hacer que gdomap sondee todos los hosts en la red

local.

También puede querer proporcionar el archivo de configuración para que hosts que no están realmente en su red local puedan ser encontrados cuando su código intente conectarse a un host usando @"*" como el nombre del host. NB. esta funcionalidad no existe en

OpenStep.

Un archivo de configuración consiste en una lista de direcciones IP a sondear. Las direcciones IP deben estar en la notación estándar de puntos, una por línea. Se permiten líneas vacías en el archivo de configuración. Cualquier cosa en una línea después de un símbolo de almohadilla ('#') se ignora. Le indica a gdomap sobre el archivo de configuración con la opción de línea de comandos

'-c'.

gdomap usa el ioctl SIOCGIFCONF para construir una lista de direcciones IP y máscaras de red para las tarjetas de interfaz de red de su máquina. En algunos sistemas operativos, esta funcionalidad no está disponible (o está rota), por lo que debe decirle a gdomap las direcciones y máscaras de la

s interfaces usando la opción '-a' de línea de comandos. El archivo nombrado con '-a' debe contener una serie de líneas con pares de direcciones y máscaras separados por espacios en la notación de puntos. NO debe incluir interfaces de loopback en esta lista. Si desea soportar el broadcast d
e información de sondeo en una red, puede proporcionar la dirección de broadcast como un tercer elemento en la línea. Si su sistema operativo tiene algún otro método para darle una lista de interfaces de red y máscaras, por favor envíeme código de ejemplo para que pueda implementarlo en gdomap.
