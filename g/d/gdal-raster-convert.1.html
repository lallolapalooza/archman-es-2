NOMBRE

gdal-raster-convert - Convertir un conjunto de datos ráster

Añadido en la versión 3.11.

SINOPSIS

Uso: gdal raster convert [OPCIONES] <ENTRADA> <SALIDA>
Convertir un conjunto de datos ráster.
Argumentos posicionales:
  -i, --input <ENTRADA>                                  Conjuntos de datos ráster de entrada [requerido]
  -o, --output <SALIDA>                                Conjunto de datos ráster de salida [requerido]
Opciones comunes:
  -h, --help                                           Mostrar mensaje de ayuda y salir
  --json-usage                                         Mostrar uso como documento JSON y salir
  --config <CLAVE>=<VALOR>                               Opción de configuración [puede repetirse]
  -q, --quiet                                          Modo silencioso (sin barra de progreso)
Opciones:
  -f, --of, --format, --output-format <FORMATO-SALIDA>  Formato de salida ("GDALG" permitido)
  --co, --creation-option <CLAVE>=<VALOR>                Opción de creación [puede repetirse]
  --overwrite                                          Indica si se permite sobrescribir el archivo de salida existente
                                                       Mutuamente excluyente con --append
  --append                                             Añadir como subconjunto de datos a la salida existente
                                                       Mutuamente excluyente con --overwrite
Opciones avanzadas:
  --if, --input-format <FORMATO-ENTRADA>                  Formatos de entrada [puede repetirse]
  --oo, --open-option <CLAVE>=<VALOR>                    Opciones de apertura [puede repetirse]

DESCRIPCIÓN

gdal raster convert puede usarse para convertir datos ráster entre diferentes formatos.

Las siguientes opciones están disponibles:

Opciones estándar

-f, --of, --format, --output-format <FORMATO-SALIDA>
Qué formato de ráster de salida usar. Los valores permitidos pueden ser dados por gdal --formats | grep raster | grep rw | sort
--co <NOMBRE>=<VALOR>
Muchos formatos tienen una o más opciones de creación opcionales que pueden usarse para controlar detalles sobre el archivo creado. Por ejemplo, el controlador GeoTIFF soporta opciones de creación para controlar la compresión y si el archivo debe ser organizado en teselas (tiles).

Puede repetirse.

Las opciones de creación disponibles varían según el controlador de formato, y algunos formatos simples no tienen opciones de creación. Una lista de opciones disponibles para un formato se puede listar con la opción de línea de comandos --formats, pero la documentación del formato es la fuente definitiva de información sobre las opciones de creación del controlador. Consulte la documentación específica del formato Controladores Ráster para conocer las opciones de creación válidas para cada formato.

--overwrite
Permite al programa sobrescribir el archivo o conjunto de datos de destino existente. De lo contrario, por defecto, gdal genera un error si el archivo o conjunto de datos de destino ya existe.
--append
Añade el ráster de entrada como un nuevo subconjunto de datos al archivo de salida existente. Solo funciona con controladores que soportan la adición de subconjuntos de datos, como GTiff -- Formato de Archivo GeoTIFF y GPKG -- GeoPackage ráster

Opciones avanzadas

--oo <NOMBRE>=<VALOR>
Opción de apertura del conjunto de datos (específica del formato).

Puede repetirse.

--if <formato>
Nombre del formato/controlador que se intentará usar para abrir el archivo de entrada. Generalmente no es necesario especificarlo, pero puede usarse para omitir la detección automática del controlador, cuando esta falla en seleccionar el controlador apropiado. Esta opción puede repetirse varias veces para especificar varios controladores candidatos. Tenga en cuenta que no fuerza la apertura del conjunto de datos por esos controladores. En particular, algunos controladores tienen requisitos sobre las extensiones de archivo.

Puede repetirse.

EJEMPLOS

Ejemplo 1: Convertir el archivo utm.tif a un GeoTIFF optimizado para la nube con compresión JPEG

$ gdal raster convert --format=COG --co COMPRESS=JPEG utm.tif utm_cog.tif

Ejemplo 2: Convertir el archivo utm.tif a GeoPackage ráster

$ gdal raster convert utm.tif utm.gpkg
