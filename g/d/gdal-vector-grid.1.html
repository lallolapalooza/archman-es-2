SINOPSI

Uso: gdal vector grid <SUBCOMANDO> [OPCIONES]
donde <SUBCOMANDO> es uno de los siguientes:
  - average:                 Crea una cuadrícula regular a partir de puntos dispersos usando interpolación de media móvil.
  - average-distance:        Crea una cuadrícula regular a partir de puntos dispersos usando la distancia media entre el nodo de la cuadrícula (centro de la elipse de búsqueda) y
todos los puntos de datos en la elipse de búsqueda. - average-distance-points: Crea una cuadrícula regular a partir de puntos dispersos usando la distancia media entre los puntos de datos en la elipse de búsqueda. - count: Crea una cuadrícula regular a partir de puntos dispersos usando el número de puntos en la elipse de búsqueda. - invdist: Crea un
a cuadrícula regular a partir de puntos dispersos usando interpolación de distancia inversa ponderada. - invdistnn: Crea una cuadrícula regular a partir de puntos dispersos usando interpolación de distancia inversa ponderada del vecino más cercano. - linear: Crea una cuadrícula regular a partir de puntos dispersos usando interpolación lineal/barycéntrica.
- maximum: Crea una cuadrícula regular a partir de puntos dispersos usando el valor máximo en la elipse de búsqueda. - minimum: Crea una cuadrícula regular a partir de puntos dispersos usando el valor mínimo en la elipse de búsqueda. - nearest: Crea una cuadrícula regular a partir de puntos dispersos usando interpolación del vecino más
cercano. - range: Crea una cuadrícula regular a partir de puntos dispersos usando la diferencia entre los valores mínimo y máximo en la elipse de búsqueda. Opciones comunes: -h, --help Muestra el mensaje de ayuda y sale --json-usage Muestra el uso como documento JSON y sale --config <CLAVE>=<VALOR> Opción de configuración [puede repetirse]

DESCRIPCIÓ

N

Este programa crea una cuadrícula regular (raster) a partir de los datos dispersos leídos de un conjunto de datos vectorial. Los datos de entrada se interpolarán para rellenar los nodos de la cuadrícula con valores, puedes elegir entre varios métodos de

interpolación.

Es posible establecer la opción de configuración GDAL_NUM_THREADS para paralelizar el procesamiento. El valor a especificar es el número de hilos de trabajo, o ALL_CPUS para usar todos los núcleos/CPUs de la

computadora.

Desde GDAL 3.12, este algoritmo puede formar parte de una tubería de

gdal.

LECTURA DE VALORES SEPARADOS POR

COMAS

A menudo tienes un archivo de texto con una lista de valores XYZ separados por comas con los que trabajar (el llamado archivo CSV). Puedes usar fácilmente ese tipo de fuente de datos en gdal vector grid. Todo lo que necesitas es crear un encabezado de conjunto de datos virtual (VRT) para tu archivo CSV y usarlo como fuente de datos de entrada para gdal vector grid. Puedes encontrar detalles sobre el formato VRT en la página de descripción VRT -- OGR Virtual

Format.

Aquí hay un pequeño ejemplo. Digamos que tenemos un archivo CSV llamado dem.csv que

contiene 
Easting,Northing,Elevation
86943.4,891957,139.13
87124.3,892075,135.01
86962.4,892321,182.04
87077.6,891995,135.01
.
.
.

Para los datos anteriores crearemos un encabezado dem.vrt con el siguiente

contenido: 
<OGRVRTDataSource>
    <OGRVRTLayer name="dem">
        <SrcDataSource>dem.csv</SrcDataSource>
        <GeometryType>wkbPoint</GeometryType>
        <GeometryField encoding="PointFromColumns" x="Easting" y="Northing" z="Elevation"/>
    </OGRVRTLayer>
</OGRVRTDataSour
c
e
>

Esta descripción especifica la llamada geometría 2.5D con tres coordenadas X, Y y Z. El valor Z se usará para la interpolación. Ahora puedes usar dem.vrt con todos los programas OGR (empieza con ogrinfo para probar que todo funciona bien). La fuente de datos contendrá una única capa llamada "dem" llena con entidades puntuales construidas a partir de valores en el archivo CSV. Usando esta técnica puedes manejar archivos CSV con más de tres columnas, cambiar columnas, etc. OK, ahora el paso

final: 
gdal vecto

t demv.tif

O, si no deseamos usar un archivo

VRT:

-oo X_POSSIBLE_NAMES=Easting \ -

zfield=Elevation dem.csv dem.tif
