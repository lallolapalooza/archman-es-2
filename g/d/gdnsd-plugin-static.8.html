GDNSD-PLUGIN-STATIC(8) gdnsd GDNSD-PLUGIN-STATIC(8)

NOMBRE

gdnsd-plugin-static - plugin estático de gdnsd

SINOPSIS

Configuración de ejemplo de recursos estáticos para resolución:

plugins => {
  static => {
    foo => 192.0.2.1
    bar => 2001:db8::1
    baz => something.example.org.
  }
}

Configuración de ejemplo de tipos de servicio estáticos para monitorización:

service_types => {
  my_static_mon => {
    plugin => static,
    ttl => 123,
    state => UP,
    # ... otros parámetros genéricos de service_type (ignorados)
  }
}

RR de archivo de zona que utiliza resolución del plugin estático, en la zona example.com:

foo 300 DYNA static!foo
bar 300 DYNC static!bar
baz 300 DYNC static!baz

DESCRIPCIÓN

gdnsd-plugin-static es un plugin combinado de monitorización y resolución que devuelve datos estáticos. Generalmente es inútil en escenarios reales y sirve principalmente como ejemplo/plugin de prueba.

Para la resolución, la configuración es un simple hash clave/valor donde las claves son nombres de recursos y los valores pueden ser una única dirección IP (v4 o v6) o un nombre de dominio. La forma de nombre de dominio solo puede usarse con "DYNC", mientras que la forma de dirección puede usarse con "DYNA" o "DYNC".

Para la configuración de monitorización como tipo de servicio, los únicos dos parámetros útiles son "ttl" y "state", que establecen un TTL y un estado fijos para este resultado de monitor estático. Los otros parámetros de monitorización estándar (p. ej., intervalo, tiempo de espera) se ignoran, ya que static establece sus estados una vez al inicio y nunca se vuelve a ejecutar.
