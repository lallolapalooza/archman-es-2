NOMBRE

gdal-raster-overview-delete - Elimina las vistas generales de un conjunto de datos ráster

Añadido en la versión 3.11.

SINOPSIS

Uso: gdal raster overview delete [OPCIONES] <DATASET>
Eliminando vistas generales.
Argumentos posicionales:
  --dataset <DATASET>                Conjunto de datos (se actualizará in situ, a menos que se use --read-only) [requerido]
Opciones comunes:
  -h, --help                         Muestra el mensaje de ayuda y sale
  --json-usage                       Muestra el uso como un documento JSON y sale
  --config <CLAVE>=<VALOR>             Opción de configuración [puede repetirse]
  -q, --quiet                        Modo silencioso (sin barra de progreso)
Opciones:
  --external                         Elimina vistas generales externas
Opciones avanzadas:
  --oo, --open-option <CLAVE>=<VALOR>  Opciones de apertura [puede repetirse]

DESCRIPCIÓN

gdal raster overview delete se puede usar para eliminar todas las vistas generales existentes de un conjunto de datos.

NOTA:

Para la mayoría de los formatos de archivo (incluyendo GeoTIFF o GeoPackage), el espacio ocupado previamente por las vistas generales eliminadas puede que no se libere. Podría ser necesario usar gdal raster convert para crear un nuevo conjunto de datos compacto.
--dataset <DATASET>
Nombre del conjunto de datos, que se actualizará in situ por defecto (a menos que se especifique --external). Requerido.
--external
Elimina las vistas generales externas .ovr.

EJEMPLOS

Ejemplo 1: Eliminar las vistas generales de un archivo GeoTIFF.

gdal raster overview delete mi.tif
