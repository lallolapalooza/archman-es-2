NOMBRE

gdal-dataset - Punto de entrada para comandos de gestión de conjuntos de datos

Añadido en la versión 3.12.

gdal dataset puede realizar diversas operaciones en archivos de datos, dependiendo de la operación elegida. Esto incluye la identificación de tipos de datos y la eliminación, renombrado o copia de los archivos.

SINOPSIS

Uso: gdal dataset <SUBCOMANDO> [OPCIONES]
donde <SUBCOMANDO> es uno de:
  - copy:     Copia archivos de un conjunto de datos. (alias: cp)
  - delete:   Elimina conjunto(s) de datos. (alias: rm, remove)
  - identify: Identifica el controlador que abre conjunto(s) de datos.
  - rename:   Renombra archivos de un conjunto de datos. (alias: ren, mv)
Opciones Comunes:
  -h, --help              Muestra el mensaje de ayuda y sale
  --json-usage            Muestra el uso como documento JSON y sale
  --config <CLAVE>=<VALOR>  Opción de configuración [puede repetirse]

SUB-COMANDOS DISPONIBLES

  • gdal dataset identify: Identifica el controlador que abre conjunto(s) de datos
  • gdal dataset copy: Copia archivos de un conjunto de datos.
  • gdal dataset rename: Renombra archivos de un conjunto de datos.
  • gdal dataset delete: Elimina conjunto(s) de datos
