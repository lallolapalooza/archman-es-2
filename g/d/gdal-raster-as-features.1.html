NOMBRE

gdal-raster-as-features - Crear características que representan los píxeles de un ráster

Añadido en la versión 3.12.

SINOPSIS

Uso: gdal raster as-features [OPCIONES] <ENTRADA> <SALIDA>
Crear características a partir de los píxeles de un conjunto de datos ráster
Argumentos posicionales:
  -i, --input <ENTRADA>                                  Conjuntos de datos ráster de entrada [requerido]
  -o, --output <SALIDA>                                Conjunto de datos vectoriales de salida [requerido]
Opciones comunes:
  -h, --help                                           Mostrar mensaje de ayuda y salir
  --json-usage                                         Mostrar uso como documento JSON y salir
  --config <CLAVE>=<VALOR>                               Opción de configuración [puede repetirse]
Opciones:
  -f, --of, --format, --output-format <FORMATO-SALIDA>  Formato de salida ("GDALG" permitido)
  --co, --creation-option <CLAVE>=<VALOR>                Opción de creación [puede repetirse]
  --lco, --layer-creation-option <CLAVE>=<VALOR>         Opción de creación de capa [puede repetirse]
  --overwrite                                          Indica si se permite sobrescribir la salida existente
  --update                                             Indica si se abre el conjunto de datos existente en modo de actualización
  --overwrite-layer                                    Indica si se permite sobrescribir la capa existente
  --append                                             Indica si se permite añadir a la capa existente
  --output-layer <CAPA-SALIDA>                         Nombre de la capa de salida
  -b, --band <BANDA>                                   Banda(s) de entrada (índice basado en 1) [puede repetirse]
  --geometry-type <TIPO-GEOMETRIA>                     Tipo de geometría. TIPO-GEOMETRIA=none|point|polygon (predeterminado: none)
  --skip-nodata                                        Omitir píxeles NoData del resultado
  --include-xy                                         Incluir campos para las coordenadas del centro de la celda
  --include-row-col                                    Incluir columnas para fila y columna
Opciones avanzadas:
  --if, --input-format <FORMATO-ENTRADA>                 Formatos de entrada [puede repetirse]
  --oo, --open-option <CLAVE>=<VALOR>                    Opciones de apertura [puede repetirse]
  --output-oo, --output-open-option <CLAVE>=<VALOR>      Opciones de apertura de salida [puede repetirse]

DESCRIPCIÓN

gdal raster as-features crea características que representan los píxeles de un conjunto de datos ráster. Las características pueden crearse como polígonos, puntos o sin geometría alguna. A diferencia de gdal raster polygonize, los píxeles adyacentes que tienen los mismos valores no se combinan.

Este algoritmo puede formar parte de un pipeline de gdal o de un pipeline de ráster de gdal.

Las siguientes opciones están disponibles:

--geometry-type
Especifica el tipo de geometría de las características creadas. Las opciones disponibles son "none" (predeterminada), "point", o "polygon".
--skip-nodata
Si se establece, no se emitirán características para los píxeles iguales al valor NoData.
--include-xy
Si se establece, se añadirán los campos CENTER_X y CENTER_Y con las coordenadas centrales de cada píxel.
--include-row-col
Si se establece, se añadirán los campos ROW y COL con las posiciones de la celda.
-b <banda>
Especifica las bandas para las cuales los valores de píxel se añadirán como campos de las características creadas. Por defecto, se añadirán valores para todas las bandas.
-f, --of, --format, --output-format <FORMATO-SALIDA>
Qué formato vectorial de salida usar. Los valores permitidos pueden obtenerse con gdal --formats | grep vector | grep rw | sort
--co <NOMBRE>=<VALOR>
Muchos formatos tienen una o más opciones de creación opcionales que pueden utilizarse para controlar detalles específicos del archivo creado. Por ejemplo, el controlador GeoTIFF admite opciones de creación para controlar la compresión y si el archivo debe estar en mosaico.

Puede repetirse.

Las opciones de creación disponibles varían según el controlador de formato y algunos formatos simples no tienen opciones de creación. Una lista de opciones admitidas para un formato puede mostrarse con la opción de línea de comandos --formats, pero la documentación del formato es la fuente definitiva de información sobre las opciones de creación del controlador. Consulte la documentación específica del formato de los Controladores de ráster para conocer las opciones de creación legales para cada formato.

--overwrite
Permite al programa sobrescribir el archivo o conjunto de datos de destino existente. De lo contrario, por defecto, gdal genera un error si el archivo o conjunto de datos de destino ya existe.

EJEMPLOS

Ejemplo 1: Crear puntos en el centro de píxeles con un valor menor que 150

gdal pipeline read input.tif !
         reclassify -m "[-inf, 150)=1; DEFAULT=NO_DATA" !
         as-features --geometry-type point --skip-nodata !
         write out.shp
