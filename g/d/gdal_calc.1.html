NOMBRE

gdal_calc - Calculadora ráster de línea de comandos con sintaxis numpy.

SINOPSIS

gdal_calc [--help] [--help-general]
             --calc=expresion --outfile=<nombre_archivo_salida> [-A <nombre_archivo>]
             [--A_band=<n>] [-B...-Z <nombre_archivo>] [<otras_opciones>]

DESCRIPCIÓN

Calculadora ráster de línea de comandos con sintaxis numpy. Usa aritmética básica soportada por arrays numpy como +, -, *, y / junto con operadores lógicos como >. Nota que todos los archivos deben tener las mismas dimensiones (a menos que se use la opción --extent), pero no se realiza comprobación de proyección (a menos que se use la opción --projectionCheck).

NOTA:

gdal_calc es una utilidad de Python y solo está disponible si los enlaces de Python de GDAL están disponibles.
--help
Mostrar este mensaje de ayuda y salir.
--help-general
Proporciona un breve mensaje de uso para las opciones genéricas de línea de comandos de GDAL y sale.
--calc=<expresion>
Cálculo en sintaxis numpy usando +, -, /, *, o cualquier función de array numpy (es decir, log10()). Se pueden listar múltiples --calc para producir un archivo multibanda (GDAL >= 3.2). Ver Ejemplo 10.
-A <nombre_archivo>
Archivo ráster de entrada GDAL, puedes usar cualquier letra (a-z, A-Z). (minúsculas soportadas desde GDAL 3.3)

Se puede repetir una letra o se pueden proporcionar varios valores (separados por espacio) (GDAL >= 3.3). El efecto será crear un array numpy 3D. Desde GDAL 3.5, se admiten excepciones de comodín (usando ?, *) para todos los shells/plataformas. En tal caso, la fórmula de cálculo debe usar esta entrada como un array 3D y debe devolver un array 2D (ver Ejemplo 3). Si el cálculo no devuelve un array 2D, se generará un error.

--A_band=<n>
Número de banda ráster para el archivo A (predeterminado 1).
--outfile=<nombre_archivo_salida>
Archivo de salida a generar o rellenar.
--NoDataValue=<valor>
Valor NoData de salida (valor específico del tipo de datos predeterminado). Para indicar que no se establece un NoDataValue, usa --NoDataValue=none (GDAL >= 3.3)

NOTA:

Usando la API de Python: el valor None indicará el valor específico del tipo de datos predeterminado. El valor 'none' indicará que no se establecerá un NoDataValue.
--hideNoData
Añadido en la versión 3.3.

Ignora el valor NoDataValue de las bandas de entrada. Por defecto, el valor NoDataValue de las bandas de entrada no participa en el cálculo. Al establecer esta opción, no se realizará ningún tratamiento especial sobre el valor NoDataValue de entrada, y participarán en el cálculo como cualquier otro valor. La salida no tendrá un NoDataValue establecido, a menos que se especifique explícitamente un valor específico estableciendo --NoDataValue=<valor>.

--type=<tipo_dato>
Tipo de dato de salida, debe ser uno de [Byte, Int8, UInt16, Int16, UInt32, Int32, UInt64, Int64, Float64, Float32, CInt16, CInt32, CFloat64, CFloat32].

NOTA:

A pesar del tipo de dato establecido con --type, al realizar operaciones aritméticas intermedias utilizando operandos del mismo tipo, el resultado de la operación respetará el tipo de dato original. Esto puede llevar a resultados inesperados en el resultado final.

NOTA:

UInt64, Int64, CInt16, CInt32, CFloat32, CFloat64 se añadieron en GDAL 3.5.3. Int8 se añadió en GDAL 3.7.
--format=<formato_gdal>
Formato GDAL para el archivo de salida.
--color-table=<nombre_archivo>
Permite especificar un nombre de archivo de una tabla de colores (o un objeto ColorTable) (con interpretación de Índice de Paleta) que se utilizará para el ráster de salida. Formatos soportados: txt (es decir, como gdaldem, pero los nombres de colores no se soportan), qlr, qml (es decir, exportado desde QGIS)
--extent=<opcion>
Añadido en la versión 3.3.

Esta opción determina cómo manejar rásteres con extents diferentes. Esta opción es mutuamente excluyente con la opción projwin, que se utiliza para proporcionar un extent personalizado.

Para todas las opciones siguientes, el tamaño de píxel (resolución) y el SRS (Sistema de Referencia Espacial) de todos los rásteres de entrada deben ser los mismos.

ignore (predeterminado) - solo se comparan las dimensiones de los rásteres. Si las dimensiones no coinciden, la operación fallará.

fail - las dimensiones y el extent (límites) de los rásteres deben coincidir, de lo contrario la operación fallará.

union - el extent (límites) de la salida será el rectángulo mínimo que contenga todos los extents de entrada.

intersect - el extent (límites) de la salida será el rectángulo máximo que esté contenido en todos los extents de entrada.

--projwin <ulx> <uly> <lrx> <lry>
Añadido en la versión 3.3.

Esta opción proporciona un extent personalizado para la salida, es mutuamente excluyente con la opción extent.

--projectionCheck
Añadido en la versión 3.3.

Por defecto, no se realizará ninguna comprobación de proyección. Al establecer esta opción, si la proyección no es la misma para todas las bandas, la operación fallará.

--creation-option=<opcion>
Pasa una opción de creación al controlador del formato de salida. Se pueden listar varias opciones. Consulte la documentación específica del formato para conocer las opciones de creación legales para cada formato.
--co=<opcion>
Lo mismo que creation-option.
--allBands=[a-z, A-Z]
Aplica la expresión a todas las bandas de un ráster dado. Cuando se usa --allBands, --calc solo puede especificarse una vez. Ver Ejemplo 11 y Ejemplo 12.
--overwrite
Sobrescribe el archivo de salida si ya existe. Sobrescribir debe entenderse aquí como eliminar y recrear el archivo desde cero. Nota que si esta opción no se especifica y el archivo de salida ya existe, se actualizará en el lugar.
--debug
Imprime información de depuración.
--quiet
Suprime los mensajes de progreso.
