NOMBRE

gdal-raster-clip - Recortar un conjunto de datos ráster

Añadido en la versión 3.11.

SINOPSIS

Uso: gdal raster clip [OPCIONES] <ENTRADA> <SALIDA>
Recortar un conjunto de datos ráster.
Argumentos posicionales:
  -i, --input <ENTRADA>                                  Conjuntos de datos ráster de entrada [requerido]
  -o, --output <SALIDA>                                  Conjunto de datos ráster de salida [requerido]
Opciones comunes:
  -h, --help                                           Mostrar mensaje de ayuda y salir
  --json-usage                                         Mostrar el uso como documento JSON y salir
  --config <CLAVE>=<VALOR>                               Opción de configuración [puede repetirse]
  -q, --quiet                                          Modo silencioso (sin barra de progreso)
Opciones:
  -f, --of, --format, --output-format <FORMATO-SALIDA>  Formato de salida ("GDALG" permitido)
  --co, --creation-option <CLAVE>=<VALOR>                Opción de creación [puede repetirse]
  --overwrite                                          Si se permite sobrescribir la salida existente
                                                       Mutuamente exclusivo con --append
  --append                                             Añadir como subconjunto de datos a la salida existente
                                                       Mutuamente exclusivo con --overwrite
  --bbox <BBOX>                                        Caja delimitadora de recorte como xmin,ymin,xmax,ymax
                                                       Mutuamente exclusivo con --window, --geometry, --like
  --bbox-crs <BBOX-CRS>                                SRC de la caja delimitadora de recorte
  --window <WINDOW>                                    Ventana ráster como col,linea,ancho,alto en píxeles
                                                       Mutuamente exclusivo con --bbox, --geometry, --like
  --geometry <GEOMETRY>                                Geometría de recorte (WKT o GeoJSON)
                                                       Mutuamente exclusivo con --bbox, --window, --like
  --geometry-crs <GEOMETRY-CRS>                        SRC de la geometría de recorte
  --like <DATASET>                                     Conjunto de datos a usar como plantilla para los límites
                                                       Mutuamente exclusivo con --bbox, --window, --geometry
  --like-sql <SENTENCIA-SELECT>                        Sentencia SELECT a ejecutar en el conjunto de datos 'like'
                                                       Mutuamente exclusivo con --like-where
  --like-layer <NOMBRE-CAPA>                           Nombre de la capa del conjunto de datos 'like'
  --like-where <EXPRESIÓN-WHERE>                       Cláusula WHERE SQL a ejecutar en el conjunto de datos 'like'
                                                       Mutuamente exclusivo con --like-sql
  --only-bbox                                          Para 'geometry' y 'like', considerar solo su caja delimitadora
  --allow-bbox-outside-source                          Permitir que la caja de recorte incluya píxeles fuera del conjunto de datos de entrada
  --add-alpha                                          Añade una banda de máscara alfa al destino cuando el ráster de origen no tiene ninguna.
Opciones avanzadas:
  --if, --input-format <FORMATO-ENTRADA>                  Formatos de entrada [puede repetirse]
  --oo, --open-option <CLAVE>=<VALOR>                    Opciones de apertura [puede repetirse]

DESCRIPCIÓN

gdal raster clip se puede usar para recortar un conjunto de datos ráster usando coordenadas georreferenciadas.

Se debe especificar --bbox o --like .

El conjunto de datos de salida está en el mismo SRC que el de entrada, y se conserva la resolución original. Los límites se redondean para coincidir con ubicaciones de píxeles completos (es decir, no se realiza ningún remuestreo)

clip también se puede usar como un paso de gdal raster pipeline.

Opciones estándar

-f, --of, --format, --output-format <FORMATO-SALIDA>
Qué formato ráster de salida usar. Los valores permitidos se pueden obtener con gdal --formats | grep raster | grep rw | sort
--co <NOMBRE>=<VALOR>
Muchos formatos tienen una o más opciones de creación opcionales que se pueden usar para controlar detalles sobre el archivo creado. Por ejemplo, el controlador GeoTIFF admite opciones de creación para controlar la compresión y si el archivo debe estar en mosaico.

Puede repetirse.

Las opciones de creación disponibles varían según el controlador de formato, y algunos formatos simples no tienen opciones de creación en absoluto. Se puede obtener una lista de las opciones admitidas para un formato con la opción de línea de comandos --formats pero la documentación del formato es la fuente definitiva de información sobre las opciones de creación del controlador. Véase Controladores ráster documentación específica del formato para las opciones de creación válidas de cada formato.

--overwrite
Permite al programa sobrescribir el archivo o conjunto de datos de destino existente. De lo contrario, por defecto, gdal genera un error si el archivo o conjunto de datos de destino ya existe.
--bbox <xmin>,<ymin>,<xmax>,<ymax>
Límites a los que recortar el conjunto de datos. Se asume que están en el SRC de el conjunto de datos de entrada, a menos que se especifique --bbox-crs . Los ejes X e Y son los "amigables para SIG", es decir, X es longitud o este, y Y es latitud o norte. Los límites se expanden si es necesario para coincidir con los límites de los píxeles de entrada. Por defecto, gdal raster clip generará un error si los límites indicados por --bbox son mayores que las extensiones del conjunto de datos de entrada. Esta comprobación se puede omitir usando --allow-bbox-outside-source.
--bbox-crs <SRC>
SRC en el que se expresan los valores <xmin>,<ymin>,<xmax>,<ymax> de --bbox . Si no se especifica, se asume que es el SRC del conjunto de datos de entrada. Tenga en cuenta que especificar --bbox-crs no hace que el ráster se reproyecte. En su lugar, los límites se reproyectan del bbox-crs al SRC del conjunto de datos de entrada.
--window <columna>,<linea>,<ancho>,<alto>
Añadido en la versión 3.12.

Selecciona una subventana de la imagen de origen para copiar basándose en la ubicación de píxel/línea. Los desplazamientos de píxel/línea (columna y linea) se miden desde la izquierda y la parte superior de la imagen. Si la subventana se extiende más allá de los límites del conjunto de datos de origen, los píxeles de salida se escribirán con un valor de cero, a menos que se defina un valor NoData en el conjunto de datos de origen.

--geometry <WKT_o_GeoJSON>
Geometría como una cadena WKT o GeoJSON de un polígono (o multipolígono) al que recortar el conjunto de datos. Las áreas ráster dentro de la caja delimitadora de la geometría pero no dentro de la geometría en sí se establecerán en el valor nodata del ráster, o 0 si no hay ninguno. Todos los píxeles que se superpongan a la geometría serán seleccionados. Si la geometría de entrada es GeoJSON, se asume que su SRC es WGS84, a menos que haya un SRC definido en la geometría GeoJSON o se especifique --geometry-crs . Si la geometría de entrada es WKT, se asume que su SRC es el del conjunto de datos de entrada, a menos que se especifique --geometry-crs . Los ejes X e Y son los "amigables para SIG", es decir, X es longitud o este, y Y es latitud o norte. Mutuamente exclusivo con --bbox y --like.
--geometry-crs <SRC>
SRC en el que se expresan los valores de coordenadas de --geometry . Si no se especifica, se asume que es el SRC del conjunto de datos de entrada. Los límites se reproyectan del geometry-crs al SRC del conjunto de datos de entrada.
--like <DATASET>
Conjunto de datos vectorial o ráster a usar como plantilla para los límites. Si el conjunto de datos especificado es un ráster, se usan sus límites rectangulares como la geometría de recorte. Si el conjunto de datos especificado es un conjunto de datos vectorial, sus geometrías poligonales se unen juntos para formar la geometría de recorte. Si hay varias capas presentes, --like-sql o --like-layer debe ser especificado. Las áreas ráster dentro del cuadro delimitador de la geometría pero no dentro de la geometría en sí se establecerán en el valor nodata del ráster, o 0 si no lo hay. Mutuamente excluyente con --bbox y --geometry.
--like-sql <SELECT-STATEMENT>
Seleccione las geometrías deseadas del conjunto de datos vectorial de recorte utilizando una consulta SQL. por ejemplo SELECT geom FROM my_layer WHERE country = 'France'. El dialecto SQL utilizado será el predeterminado del like conjunto de datos (OGR SQL para Shapefile, SQLite para GeoPackage, PostgreSQL para PostGIS, etc.). Mutuamente excluyente con --like-layer y --like-where
--like-layer <LAYER-NAME>
Seleccione la capa con nombre del conjunto de datos vectorial de recorte. Mutuamente excluyente con --like-sql
--like-where <WHERE-EXPRESSION>
Restrinja las geometrías deseadas de la capa del conjunto de datos vectorial de recorte basándose en una consulta de atributos. por ejemplo country = 'France'.
--only-bbox
Para --geometry y --like, considere únicamente el cuadro delimitador de la geometría.
--allow-bbox-outside-source
Si se establece, permite que los límites indicados por --bbox cubran una extensión mayor que el conjunto de datos de entrada. Los píxeles de salida de áreas más allá de la extensión de entrada se establecerán en cero o en el valor NoData del conjunto de datos de entrada.
--addalpha
Añade una banda de máscara alfa al destino cuando el ráster de origen no tiene ninguna.

Opciones avanzadas

--oo <NAME>=<VALUE>
Opción de apertura del conjunto de datos (específica del formato).

Puede repetirse.

--if <format>
Nombre del formato/controlador que se intentará para abrir el(los) archivo(s) de entrada. Generalmente no es necesario especificarlo, pero puede usarse para omitir la detección automática del controlador, cuando falla la selección del controlador apropiado. Esta opción puede repetirse varias veces para especificar varios controladores candidatos. Tenga en cuenta que no fuerza a esos controladores a abrir el conjunto de datos. En particular, algunos controladores tienen requisitos sobre las extensiones de archivo.

Puede repetirse.

EJEMPLOS

Ejemplo 1: Recortar un archivo GeoTIFF al cuadro delimitador desde longitud 2, latitud 49, hasta longitud 3, latitud 50 en WGS 84

$ gdal raster clip --bbox=2,49,3,50 --bbox-crs=EPSG:4326 in.tif out.tif --overwrite

Ejemplo 2: Recortar un archivo GeoTIFF utilizando los límites de reference.tif

$ gdal raster clip --like=reference.tif in.tif out.tif --overwrite

Ejemplo 3: Recortar un archivo GeoTIFF desde la columna ráster 1000 y la línea 2000, para un ancho de 500 píxeles y una altura de 600 píxeles

$ gdal raster clip --window=1000,2000,500,600 in.tif out.tif --overwrite
