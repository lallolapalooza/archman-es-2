NOMBRE

gdal-vector-set-geom-type - Modificar el tipo de geometría de un conjunto de datos vectorial

Añadido en la versión 3.12.

SINOPSIS

Uso: gdal vector set-geom-type [OPCIONES] <ENTRADA> <SALIDA>
Modifica el tipo de geometría de un conjunto de datos vectorial.
Argumentos posicionales:
  -i, --input <ENTRADA>                                  Conjuntos de datos vectoriales de entrada [requerido]
  -o, --output <SALIDA>                                  Conjunto de datos vectorial de salida [requerido]
Opciones comunes:
  -h, --help                                           Mostrar mensaje de ayuda y salir
  --json-usage                                         Mostrar el uso como documento JSON y salir
  --config <CLAVE>=<VALOR>                              Opción de configuración [puede repetirse]
  -q, --quiet                                          Modo silencioso (sin barra de progreso)
Opciones:
  -l, --layer, --input-layer <CAPA-ENTRADA>             Nombre(s) de capa(s) de entrada [puede repetirse]
  -f, --of, --format, --output-format <FORMATO-SALIDA>  Formato de salida ("GDALG" permitido)
  --co, --creation-option <CLAVE>=<VALOR>                Opción de creación [puede repetirse]
  --lco, --layer-creation-option <CLAVE>=<VALOR>         Opción de creación de capa [puede repetirse]
  --overwrite                                          Si se permite sobrescribir la salida existente
  --update                                             Si abrir el conjunto de datos existente en modo de actualización
  --overwrite-layer                                    Si se permite sobrescribir la salida existente
  --append                                             Si se permite añadir a una capa existente
                                                       Excluyente mutuamente con --upsert
  --output-layer <CAPA-SALIDA>                         Nombre de la capa de salida
  --skip-errors                                        Omitir errores al escribir elementos
  --active-layer <CAPA-ACTIVA>                         Establecer la capa activa (si no se especifica, todas)
  --active-geometry <GEOMETRÍA-ACTIVA>                 Nombre del campo de geometría al que restringir el procesamiento (si no se especifica, todos)
  --layer-only                                         Solo modificar el tipo de geometría de la capa
                                                       Excluyente mutuamente con --feature-only
  --feature-only                                       Solo modificar el tipo de geometría de los elementos
                                                       Excluyente mutuamente con --layer-only
  --geometry-type <TIPO-GEOMETRÍA>                     Tipo de geometría
  --multi                                              Forzar geometrías a tipos de geometría MULTI
                                                       Excluyente mutuamente con --single
  --single                                             Forzar geometrías a tipos de geometría no MULTI
                                                       Excluyente mutuamente con --multi
  --linear                                             Convertir geometrías de curva a tipos lineales
                                                       Excluyente mutuamente con --curve
  --curve                                              Convertir geometrías lineales a tipos de curva
                                                       Excluyente mutuamente con --linear
  --dim <DIM>                                          Forzar geometrías a la dimensión especificada. DIM=XY|XYZ|XYM|XYZM
  --skip                                               Omitir elemento cuando falle el cambio del tipo de geometría del elemento
Opciones avanzadas:
  --if, --input-format <FORMATO-ENTRADA>                Formatos de entrada [puede repetirse]
  --oo, --open-option <CLAVE>=<VALOR>                   Opciones de apertura [puede repetirse]
  --output-oo, --output-open-option <CLAVE>=<VALOR>     Opciones de apertura de salida [puede repetirse]
  --upsert                                             Actualizar o insertar elementos (implica 'append')
                                                       Excluyente mutuamente con --append

DESCRIPCIÓN

gdal vector set-geom-type puede usarse para modificar el tipo de geometría de los campos de geometría a nivel de capa y/o de elemento.

También puede usarse como paso de gdal vector pipeline.

Los siguientes grupos de opciones pueden combinarse entre sí: - --multi / --single - --linear / --curve - --dim

Opciones estándar

-f, --of, --format, --output-format <FORMATO-SALIDA>
Qué formato vectorial de salida usar. Los valores permitidos pueden obtenerse con gdal --formats | grep vector | grep rw | sort
--co <NOMBRE>=<VALOR>
Muchos formatos tienen una o más opciones opcionales de creación de conjuntos de datos que pueden usarse para controlar detalles sobre el archivo creado. Por ejemplo, el controlador de GeoPackage admite opciones de creación para controlar la versión.

Puede repetirse.

Las opciones de creación de conjuntos de datos disponibles varían según el controlador de formato, y algunos formatos simples no tienen opciones de creación en absoluto. Una lista de opciones admitidas para un formato puede listarse con la opción de línea de comandos --formats pero la documentación del formato es la fuente definitiva de información sobre las opciones de creación del controlador. Véase Controladores vectoriales documentación específica del formato para las opciones de creación válidas de cada formato.

Tenga en cuenta que las opciones de creación de conjuntos de datos son diferentes de las opciones de creación de capas.

-lco <NOMBRE>=<VALOR>
Opción de creación de capa (específica del formato)
--overwrite
Permite al programa sobrescribir el archivo o conjunto de datos de destino existente. De lo contrario, por defecto, gdal da error si el archivo o conjunto de datos de destino ya existe.
--active-layer <CAPA-ACTIVA>
Establece la capa activa. Cuando se especifica, solo la capa indicada por su nombre será sometida al procesamiento. Las demás capas no serán modificadas. Si no se especifica esta opción, todas las capas serán sometidas al procesamiento.
--active-geometry <GEOMETRÍA-ACTIVA>
Establece el campo de geometría activo por su nombre. Cuando se especifica, solo el campo de geometría indicado será sometido al procesamiento. Los demás campos de geometría no serán modificados. Si no se especifica esta opción, todos los campos de geometría serán sometidos al procesamiento. Esta opción puede combinarse con --active-layer.
--layer-only
Solo modificar el tipo de geometría de la capa. Un caso de uso típico es si el tipo de geometría de la capa está establecido como desconocido y el usuario sabe que la capa solo contiene geometrías de un tipo dado.
--feature-only
Solo modificar el tipo de geometría de los elementos.
--geometry-type <TIPO-GEOMETRÍA>
Cambiar el tipo de geometría a uno de GEOMETRY, POINT, LINESTRING, POLYGON, MULTIPOINT, MULTILINESTRING, MULTIPOLYGON, GEOMETRYCOLLECTION, CURVE, CIRCULARSTRING, COMPOUNDCURVE, SURFACE, CURVEPOLYGON, MULTICURVE, MULTISURFACE, POLYHEDRALSURFACE o TIN. Z, M o ZM pueden añadirse como sufijos a los valores anteriores para indicar la dimensionalidad.

Esta opción es excluyente mutuamente con --multi, --single, --linear, --curvey --dim.

--multi
Forzar geometrías a tipos de geometría MULTI. p. ej. POINT ==> MULTIPOINT. Esta opción es excluyente mutuamente con --single.
--single
Forzar geometrías a tipos de geometría no MULTI. p. ej. MULTIPOINT ==> POINT. Esta opción es excluyente mutuamente con --m

NOMBRE

gdal vector set-geom-type — Transforma el tipo de geometría de las características de un conjunto de datos vectorial.

SINOPSIS

gdal vector set-geom-type [-options...] --config CONFIG_OPTION VALUE... --allow-datasource-creation-option OPTION[=VALUE]... --dimension DIM... --geometry-type TYPE --linear --curve --multi --single --dim DIM --skip INPUT_VECTOR_DATASET OUTPUT_VECTOR_DATASET

DESCRIPCION

El programa gdal vector set-geom-type se utiliza para modificar el tipo de geometría de las características de un conjunto de datos vectorial de entrada y escribir el resultado en un conjunto de datos vectorial de salida.

Es útil para estandarizar tipos de geometría o para convertir geometrías a formatos que no admiten ciertos tipos.

El conjunto de datos de salida se crea a partir de las opciones de creación de conjuntos de datos disponibles para el controlador del formato de salida.

--config CONFIG_OPTION VALUE
Establece una opción de configuración de GDAL. Por ejemplo, --config OGR_ARC_STEPSIZE 10.
--allow-datasource-creation-option OPTION[=VALUE]
Opciones de creación de conjunto de datos (específicas del formato). Por ejemplo, --allow-datasource-creation-option COMPRESS=LZW.
Puede repetirse.
--dimension DIM
Dimensiones para las que se procesarán las geometrías (XY, XYZ, XYM, XYZM). Si la geometría de entrada carece de componentes Z o M, se establecerán a 0.
Esta opción es mutuamente excluyente con --geometry-type.
Puede repetirse.
--geometry-type TYPE
Especifica el tipo de geometría de salida. Los valores válidos son los nombres de tipo de geometría OGC, como POINT, LINESTRING, POLYGON, MULTIPOINT, MULTILINESTRING, MULTIPOLYGON, GEOMETRYCOLLECTION, CIRCULARSTRING, COMPOUNDCURVE, CURVEPOLYGON, MULTICURVE, MULTISURFACE, CURVE.
Si la geometría de entrada es incompatible con el tipo de geometría de salida especificado (por ejemplo, intentar forzar un tipo POINT para una geometría LINESTRING), el comportamiento depende de la opción --skip.
Esta opción es mutuamente excluyente con --dimension.
--multi
Convierte geometrías simples a sus contrapartes múltiples. Por ejemplo, POINT -> MULTIPOINT, LINESTRING -> MULTILINESTRING, POLYGON -> MULTIPOLYGON.
MultiPoint o MultiLinestring con más de un componente se mantendrán sin modificar. MultiPolygon con más de un componente se fusionarán en un solo polígono (probablemente inválido según la regla de características simples de OGC), fusionando todos sus anillos.
--linear
Fuerza las geometrías a tipos de geometría lineales/no curvas, aproximando arcos con segmentos lineales. La aproximación lineal se puede controlar con las opciones de configuración OGR_ARC_STEPSIZE y OGR_ARC_MAX_GAP (especificadas usando --config). por ejemplo, COMPOUNDCURVE ==> LINESTRING. Esta opción es mutuamente excluyente con --curve.
--curve
Fuerza las geometrías a tipos de geometría de curva. por ejemplo, LINESTRING ==> COMPOUNDCURVE o POLYGON ==> CURVEPOLYGON. Los puntos se mantienen sin modificar. Esta opción es mutuamente excluyente con --linear.
--dim
Fuerza las geometrías a la dimensión especificada (XY, XYZ, XYM o XYZM). Si la geometría de entrada carece de componentes Z o M, se establecerán a 0. Esta opción es mutuamente excluyente con --geometry-type.
--skip
Omitir característica cuando el cambio del tipo de geometría de la característica falló (por ejemplo, al intentar forzar un tipo de geometría Point para una geometría LineString). De lo contrario, la geometría de origen se mantendrá sin modificar (lo que puede hacerla incompatible con la capa de salida si no admite la mezcla de tipos de geometría). Esta opción se aplica tanto cuando el tipo de geometría de destino se define con --geometry-type, como con cualquiera de --multi, --single, --linear y --curve.

Opciones avanzadas

--oo <NOMBRE>=<VALOR>
Opción de apertura del conjunto de datos (específica del formato).
Puede repetirse.
--if <formato>
Nombre del formato/controlador que se intentará para abrir el archivo de entrada. Por lo general, no es necesario especificarlo, pero se puede usar para omitir la detección automática del controlador, cuando no logra seleccionar el controlador apropiado. Esta opción se puede repetir varias veces para especificar varios controladores candidatos. Tenga en cuenta que no obliga a esos controladores a abrir el conjunto de datos. En particular, algunos controladores tienen requisitos sobre las extensiones de archivo.
Puede repetirse.

SALIDA GDALG (ON-THE-FLY / CONJUNTO DE DATOS EN STREAMING)

Este programa admite la serialización de la línea de comandos como un archivo JSON utilizando el formato de salida GDALG. El archivo resultante se puede abrir como un conjunto de datos vectorial utilizando el controlador GDALG: GDAL Streamed Algorithm, y aplicar el pipeline especificado de forma sobre la marcha / en streaming.

EJEMPLOS

Ejemplo 1: Convertir un shapefile que mezcla polígonos y multipolígonos a un GeoPackage con multipolígonos.

$ gdal vector set-geom-type --geometry-type=MULTIPOLYGON in.shp out.gpkg --overwrite

Ejemplo 2: Convertir un GeoPackage con geometrías de curva a un Shapefile (que no las admite).

$ gdal vector set-geom-type --linear in.gpkg out.shp --overwrite
