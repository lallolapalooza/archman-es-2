NOMBRE

gdal-convert - Convierte un conjunto de datos

Añadido en la versión 3.11.

Actúa como un atajo para gdal raster convert o gdal vector convert dependiendo de la naturaleza del conjunto de datos especificado.

SINOPSIS

Uso: gdal convert [OPCIONES] <ENTRADA> <SALIDA>
Convierte un conjunto de datos (atajo para 'gdal raster convert' o 'gdal vector convert').
Argumentos posicionales:
  -i, --input <ENTRADA>                                Conjunto de datos de entrada ráster, vectorial o multidimensional [requerido]
  -o, --output <SALIDA>                                Conjunto de datos de salida ráster, vectorial o multidimensional (creado por el algoritmo) [requerido]
Opciones comunes:
  -h, --help                                           Muestra el mensaje de ayuda y sale
  --json-usage                                         Muestra el uso como documento JSON y sale
  --config <CLAVE>=<VALOR>                             Opción de configuración [puede repetirse]
  -q, --quiet                                          Modo silencioso (sin barra de progreso)
Opciones:
  -f, --of, --format, --output-format <FORMATO-SALIDA>  Formato de salida
Para todas las opciones, ejecuta 'gdal raster convert --help' o 'gdal vector convert --help'

EJEMPLOS

Ejemplo 1: Convirtiendo el archivo utm.tif a ráster GeoPackage

$ gdal convert utm.tif utm.gpkg
