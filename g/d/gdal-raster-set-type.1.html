NOMBRE

gdal-raster-set-type - Modifica el tipo de datos de las bandas de un conjunto de datos ráster

Añadido en la versión 3.11.

SINOPSIS

Uso: gdal raster set-type [OPCIONES] <ENTRADA> <SALIDA>
Modifica el tipo de datos de las bandas de un conjunto de datos ráster.
Argumentos posicionales:
  -i, --input <ENTRADA>                                    Conjuntos de datos ráster de entrada [obligatorio]
  -o, --output <SALIDA>                                    Conjunto de datos ráster de salida [obligatorio]
Opciones comunes:
  -h, --help                                               Muestra el mensaje de ayuda y sale
  --json-usage                                             Muestra el uso como documento JSON y sale
  --config <CLAVE>=<VALOR>                                   Opción de configuración [puede repetirse]
  -q, --quiet                                              Modo silencioso (sin barra de progreso)
Opciones:
  -f, --of, --format, --output-format <FORMATO-SALIDA>     Formato de salida ("GDALG" permitido)
  --co, --creation-option <CLAVE>=<VALOR>                  Opción de creación [puede repetirse]
  --overwrite                                              Si se permite sobrescribir la salida existente
                                                           Mutuamente excluyente con --append
  --append                                                 Añadir como subconjunto de datos a la salida existente
                                                           Mutuamente excluyente con --overwrite
  --ot, --datatype, --output-data-type <TIPO-DATOS-SALIDA>  Tipo de datos de salida. TIPO-DATOS-SALIDA=Byte|Int8|UInt16|Int16|UInt32|Int32|UInt64|Int64|CInt16|CInt32|Float16|Float32|Float64|CFloat32|CFloat64 [obligatorio]
Opciones avanzadas:
  --if, --input-format <FORMATO-ENTRADA>                   Formatos de entrada [puede repetirse]
  --oo, --open-option <CLAVE>=<VALOR>                      Opciones de apertura [puede repetirse]

DESCRIPCIÓN

gdal raster set-type se puede utilizar para forzar que las bandas de la imagen de salida tengan un tipo de datos específico. Los valores pueden truncarse o redondearse si el tipo de datos de salida es "menor" que el de entrada.

Este subcomando también está disponible como un posible paso de gdal raster pipeline

Opciones estándar

-f, --of, --format, --output-format <FORMATO-SALIDA>
Qué formato ráster de salida usar. Los valores permitidos pueden ser proporcionados por gdal --formats | grep raster | grep rw | sort
--co <NOMBRE>=<VALOR>
Muchos formatos tienen una o más opciones de creación opcionales que se pueden usar para controlar detalles sobre el archivo creado. Por ejemplo, el controlador GeoTIFF admite opciones de creación para controlar la compresión y si el archivo debe ser empaquetado en mosaicos.

Puede repetirse.

Las opciones de creación disponibles varían según el controlador de formato y algunos formatos simples no tienen ninguna opción de creación. Se puede listar un conjunto de opciones admitidas para un formato con la opción de línea de comandos --formats, pero la documentación del formato es la fuente definitiva de información sobre las opciones de creación del controlador. Consulte la documentación específica del formato de Controladores ráster para conocer las opciones de creación legales para cada formato.

--overwrite
Permite que el programa sobrescriba el archivo o conjunto de datos de destino existente. De lo contrario, por defecto, gdal genera un error si el archivo o conjunto de datos de destino ya existe.
--ot, --datatype, --output-data-type <TIPO-DATOS-SALIDA>
Tipo de datos de salida entre Byte, Int8, UInt16, Int16, UInt32, Int32, UInt64, Int64, CInt16, CInt32, Float32, Float64, CFloat32, CFloat64.

SALIDA GDALG (ON-THE-FLY / CONJUNTO DE DATOS EN STREAMING)

Este programa admite la serialización de la línea de comandos como un archivo JSON utilizando el formato de salida GDALG. El archivo resultante se puede abrir como un conjunto de datos ráster utilizando el controlador GDALG: GDAL Streamed Algorithm y aplicar el pipeline especificado de forma sobre la marcha / en streaming.

EJEMPLOS

Ejemplo 1: Convertir a tipo de datos Float32

$ gdal raster set-type --datatype Float32 byte.tif float32.tif --overwrite
