NOMBRE

gdal-vector - Punto de entrada para comandos vectoriales

Añadido en la versión 3.11.

SINOPSIS

Uso: gdal vector <SUBCOMANDO> [OPCIONES]
donde <SUBCOMANDO> es uno de:
  - buffer:              Calcula un buffer alrededor de las geometrías de un conjunto de datos vectorial.
  - check-coverage:      Comprueba la validez de una cobertura poligonal.
  - check-geometry:      Comprueba la validez de las geometrías de un conjunto de datos.
  - clean-coverage:      Modifica los límites de los polígonos para hacer idénticas las aristas compartidas, eliminando huecos y solapamientos.
  - clip:                Recorta un conjunto de datos vectorial.
  - concat:              Concatena conjuntos de datos vectoriales.
  - convert:             Convierte un conjunto de datos vectorial.
  - edit:                Edita los metadatos de un conjunto de datos vectorial.
  - explode-collections: Explota las geometrías de tipo colección de un conjunto de datos vectorial.
  - filter:              Filtra un conjunto de datos vectorial.
  - grid:                Crea una rejilla regular a partir de puntos dispersos.
  - index:               Crea un índice vectorial de conjuntos de datos vectoriales.
  - info:                Devuelve información sobre un conjunto de datos vectorial.
  - layer-algebra:       Realiza una operación algebraica entre 2 capas.
  - make-point:          Crea geometrías de punto a partir de campos de atributos.
  - make-valid:          Corrige la validez de las geometrías de un conjunto de datos vectorial.
  - partition:           Particiona un conjunto de datos vectorial en múltiples archivos.
  - pipeline:            Procesa un conjunto de datos vectorial aplicando varios pasos.
  - rasterize:           Quema geometrías vectoriales en un ráster.
  - reproject:           Reproyecta un conjunto de datos vectorial.
  - segmentize:          Segmenta las geometrías de un conjunto de datos vectorial.
  - select:              Selecciona un subconjunto de campos de un conjunto de datos vectorial.
  - set-field-type:      Modifica el tipo de un campo de un conjunto de datos vectorial.
  - set-geom-type:       Modifica el tipo de geometría de un conjunto de datos vectorial.
  - simplify:            Simplifica las geometrías de un conjunto de datos vectorial.
  - simplify-coverage:   Simplifica los límites compartidos de un conjunto de datos vectorial poligonal.
  - sql:                 Aplica sentencias SQL a un conjunto de datos.
  - swap-xy:             Intercambia las coordenadas X e Y de las geometrías de un conjunto de datos vectorial.
Opciones Comunes:
  -h, --help              Muestra el mensaje de ayuda y sale.
  --json-usage            Muestra el uso como un documento JSON y sale.
  --config <CLAVE>=<VALOR>  Opción de configuración [puede repetirse]
Opciones:
  --drivers               Muestra la lista de drivers vectoriales como un documento JSON y sale.

EJEMPLOS

Ejemplo 1: Obtener información del archivo poly.gpkg (con salida JSON)

$ gdal vector info poly.gpkg

Ejemplo 2: Convertir el archivo poly.gpkg a Esri File Geodatabase

$ gdal vector convert --format=OpenFileGDB poly.gpkg poly.gdb
