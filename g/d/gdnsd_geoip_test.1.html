NOMBRE

gdnsd_geoip_test - Programa de prueba en línea de comandos para mapas de gdnsd-plugin-geoip

SINOPSIS

gdnsd_geoip_test [-c /etc/gdnsd] [nombre_mapa direccion]
  -c            Directorio de configuración de gdnsd, consulte la página del manual principal de gdnsd(8) para obtener detalles
  nombre_mapa      Nombre del mapa de la configuración del plugin geoip
  direccion          Dirección IP del cliente a mapear.

DESCRIPCIÓN

Este es un programa de prueba simple en línea de comandos para las configuraciones de mapas de "gdnsd-plugin-geoip". Analiza su archivo de configuración estándar de gdnsd, extrae las partes relevantes de la sección del plugin geoip y procesa la sección de "mapas" utilizando el mismo código central que el propio plugin. Luego resuelve la dirección IP proporcionada contra el nombre de mapa proporcionado, proporcionando una lista ordenada de centros de datos (y máscara de ámbito edns) como resultado.

Las direcciones IP de entrada en la línea de comandos no aceptan información de subred CIDR. Esto es intencional. Debido al método por el cual "gdnsd-plugin-geoip" construye, optimiza y realiza búsquedas en los datos internos, la máscara de subred del cliente es irrelevante, y la máscara de ámbito de respuesta es siempre tan específica o general como sea necesario. Para simular diferentes máscaras de entrada edns en los mismos datos de dirección, simplemente ponga a cero más bits del lado derecho de la dirección.

Si no se proporciona "[nombre_mapa direccion]" en la línea de comandos, el programa entra en modo REPL (Bucle Leer-Evaluar-Imprimir) con un prompt, lo que le permite introducir interactivamente varios pares de "[nombre_mapa direccion]" sin recargar la(s) base(s) de datos configurada(s).
