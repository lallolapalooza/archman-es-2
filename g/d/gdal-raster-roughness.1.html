NOMBRE

gdal-raster-roughness - Generar un mapa de rugosidad

Añadido en la versión 3.11.

SINOPSIS

Uso: gdal raster roughness [OPCIONES] <ENTRADA> <SALIDA>
Generar un mapa de rugosidad
Argumentos posicionales:
  -i, --input <ENTRADA>                                Archivos ráster de entrada [requerido]
  -o, --output <SALIDA>                                Archivo ráster de salida [requerido]
Opciones comunes:
  -h, --help                                           Mostrar mensaje de ayuda y salir
  --json-usage                                         Mostrar uso como documento JSON y salir
  --config <CLAVE>=<VALOR>                             Opción de configuración [puede repetirse]
  -q, --quiet                                          Modo silencioso (sin barra de progreso)
Opciones:
  -f, --of, --format, --output-format <FORMATO-SALIDA>  Formato de salida ("GDALG" permitido)
  --co, --creation-option <CLAVE>=<VALOR>             Opción de creación [puede repetirse]
  --overwrite                                          Si se permite sobrescribir la salida existente
                                                       Mutuamente excluyente con --append
  --append                                             Anexar como subconjunto de datos a la salida existente
                                                       Mutuamente excluyente con --overwrite
  -b, --band <BANDA>                                   Banda de entrada (índice basado en 1) (predeterminado: 1)
  --no-edges                                           No intentar interpolar valores en los bordes del conjunto de datos o cerca de valores nulos
Opciones avanzadas:
  --if, --input-format <FORMATO-ENTRADA>               Formatos de entrada [puede repetirse]
  --oo, --open-option <CLAVE>=<VALOR>                Opciones de apertura [puede repetirse]

DESCRIPCIÓN

gdal raster roughness genera un ráster de banda única con valores calculados a partir de la elevación. La rugosidad es la mayor diferencia intercelular de un píxel central y su celda circundante, como se define en Wilson et al. (2007, Marine Geodesy 30:3-35).

Este subcomando también está disponible como un paso potencial de gdal raster pipeline

Se utiliza el valor nulo de rugosidad -9999 como valor nulo.

También se emitirá un valor nulo en el conjunto de datos de destino si se encuentra al menos un píxel establecido en el valor nulo dentro de la ventana de 3x3 centrada alrededor de cada píxel de origen. Por defecto, el algoritmo calculará valores en los bordes de la imagen o si se encuentra un valor nulo en la ventana de 3x3, interpolando los valores faltantes, a menos que se especifique --no-edges, en cuyo caso se establecerá un borde de 1 píxel alrededor de la imagen con el valor nulo.

Opciones estándar

-f, --of, --format, --output-format <FORMATO-SALIDA>
Qué formato ráster de salida utilizar. Los valores permitidos pueden ser dados por gdal --formats | grep raster | grep rw | sort
--co <NOMBRE>=<VALOR>
Muchos formatos tienen una o más opciones de creación opcionales que pueden utilizarse para controlar detalles sobre el archivo creado. Por ejemplo, el controlador GeoTIFF admite opciones de creación para controlar la compresión y si el archivo debe estar dividido en mosaicos.

Puede repetirse.

Las opciones de creación disponibles varían según el controlador de formato, y algunos formatos simples no tienen opciones de creación en absoluto. Una lista de opciones admitidas para un formato se puede obtener con la opción de línea de comandos --formats, pero la documentación del formato es la fuente definitiva de información sobre las opciones de creación del controlador. Consulte la documentación específica del formato de Controladores ráster para conocer las opciones de creación válidas para cada formato.

--overwrite
Permitir que el programa sobrescriba el archivo o conjunto de datos de destino existente. De lo contrario, por defecto, gdal arroja un error si el archivo o conjunto de datos de destino ya existe.
-b, --band <BANDA>
Índice (comenzando en 1) de la banda para la cual se debe calcular la rugosidad.
--no-edges
No intentar interpolar valores en los bordes del conjunto de datos o cerca de valores nulos.

SALIDA GDALG (EN EL MOVIMIENTO / CONJUNTO DE DATOS DE STREAMING)

Este programa admite la serialización de la línea de comandos como un archivo JSON utilizando el formato de salida GDALG. El archivo resultante puede abrirse como un conjunto de datos ráster utilizando el controlador GDALG: Algoritmo en Streaming de GDAL, y aplicar la tubería especificada de forma on-the-fly / en streaming.

EJEMPLOS

Ejemplo 1: Genera un mapa de rugosidad a partir de un archivo DTED0.

$ gdal raster roughness n43.dt0 out.tif --overwrite
