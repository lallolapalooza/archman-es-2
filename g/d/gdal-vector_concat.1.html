DESCRIPCIÓ

N

gdal vector concat concatena varios conjuntos de datos de

origen.

Tiene 3 modos

principales:
  • --mode = merge-per-layer-name (el predeterminado). El conjunto de datos de salida generado por el comando contendrá tantas capas como nombres de capa diferentes haya en los conjuntos de datos de origen. Por ejemplo, si hay 2 conjuntos de datos, uno con capas a y b, y el otro con capas b y c, se crearán 3 capas de salida: a, b (fusionando las 2 capas de origen) y c
    • .
  • --mode = stack. El conjunto de datos de salida generado por el comando contendrá tantas capas como capas haya en los conjuntos de datos de origen. Por ejemplo, si hay 2 conjuntos de datos ds1 (con capas a y b) y ds2 (con capas b y c), se crearán 4 capas de salida: ds1_a, ds1_b, ds2_b y ds2_
    • c.
  • --mode = single. El conjunto de datos de salida generado por el comando
    • contendrá una sola capa, fus
ionando todas las capas en los c
onjuntos de datos de origen.

Cuando una capa de salida fusiona varias capas de origen, por defecto el esquema resultante contendrá la unión de todos los campos de origen. Es posible seleccionar solo la intersección con la --field-strategy establecida en intersection. En cuanto al CRS resultante, por defecto se usará el CRS de la capa de origen como CRS de destino, y los elementos de otras capas de origen que no coincidan con este CRS serán reproyectados a él. --dst-crs se puede usar para seleccionar un CRS de destino

dado.

Este comando también se puede usar como el primer paso de gdal vector p

ipeline.
