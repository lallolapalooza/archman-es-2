NOMBRE

gdal-raster-pixel-info - Devuelve información sobre un píxel de un conjunto de datos ráster

Añadido en la versión 3.11.

SINOPSIS

Uso: gdal raster pixel-info [OPCIONES] <ENTRADA> [<columna,línea> o <X,Y>]
Devuelve información sobre un píxel de un conjunto de datos ráster.
Argumentos posicionales:
  -i, --dataset, --input <ENTRADA>                       Conjunto de datos ráster de entrada [requerido]
  -p, --pos, --position <columna,línea> o <X,Y>         Posición del píxel [puede repetirse]
Opciones comunes:
  -h, --help                                           Muestra el mensaje de ayuda y sale
  --json-usage                                         Muestra el uso como documento JSON y sale
  --config <CLAVE>=<VALOR>                             Opción de configuración [puede repetirse]
Opciones:
  -f, --of, --format, --output-format <FORMATO-SALIDA>  Formato de salida. FORMATO-SALIDA=geojson|csv (predeterminado: geojson)
  -b, --band <BANDA>                                    Banda(s) de entrada (índice basado en 1) [puede repetirse]
  --overview <VISTA-PREVIA>                            Qué nivel de vista previa del archivo de origen debe usarse
  --position-crs <CRS-POSICIÓN>                        CRS de la posición (predeterminado: píxel)
  -r, --resampling <REMUESTREO>                        Algoritmo de remuestreo para interpolación. REMUESTREO=nearest|bilinear|cubic|cubicspline (predeterminado: nearest)
Opciones avanzadas:
  --oo, --open-option <CLAVE>=<VALOR>                    Opciones de apertura [puede repetirse]
  --if, --input-format <FORMATO-ENTRADA>                  Formatos de entrada [puede repetirse]

DESCRIPCIÓN

gdal raster pixel-info proporciona un mecanismo para consultar información sobre un píxel dado su ubicación en uno de una variedad de sistemas de coordenadas.

Admite la salida tanto en GeoJSON como en CSV.

Se informará de los siguientes elementos (cuando se conozcan):

  • Coordenadas de entrada
  • Coordenadas de entrada convertidas a columna, línea
  • Valor del píxel por banda(s) seleccionada(s), con el valor sin escalar
  • Para archivos VRT, qué archivo(s) contribuyen al valor del píxel.

Las siguientes opciones están disponibles:

Opciones estándar

-f, --of, --format, --output-format geojson|csv
Qué formato de salida usar. El predeterminado es GeoJSON.
--oo <NOMBRE>=<VALOR>
Opción de apertura del conjunto de datos (específica del formato).

Puede repetirse.

--if <formato>
Nombre del formato/controlador que se intentará para abrir los archivos de entrada. Generalmente no es necesario especificarlo, pero puede usarse para omitir la detección automática del controlador, cuando falla en seleccionar el controlador apropiado. Esta opción puede repetirse varias veces para especificar varios controladores candidatos. Tenga en cuenta que no fuerza a esos controladores a abrir el conjunto de datos. En particular, algunos controladores tienen requisitos sobre las extensiones de archivo.

Puede repetirse.

-b <banda>
Selecciona una banda para consultar. Se pueden listar múltiples bandas. Por defecto, se consultan todas las bandas.
-p, --pos, --position <columna,línea> o <X,Y>
Requerido. Esto puede especificarse ya sea como una opción, un valor posicional después del nombre del conjunto de datos, o cuando se llama desde gdal, como valores (separados por espacios) proporcionados en la entrada estándar.

Por defecto, cuando --position-crs no se especifica, o se establece en pixel, esto es una tupla de columna, línea (posiblemente con parte fraccionaria). Si --position-crs se establece en dataset, esto es una coordenada georreferenciada expresada en el CRS del conjunto de datos. Si --position-crs se especifica como una definición de CRS, esto es una coordenada georreferenciada expresada en este CRS.

X significa siempre longitud o este, Y significa siempre latitud o norte.

Se pueden especificar varias tuplas x,y.

--position-crs pixel|dataset|<def-crs>
CRS de la posición, o uno de los dos valores especiales siguientes:
  • pixel significa que la posición se establece como columna, línea (predeterminado)
  • dataset significa que la posición es una coordenada georreferenciada expresada en el CRS del conjunto de datos.
-r, --resampling nearest|bilinear|cubic|cubicspline
Selecciona un algoritmo de muestreo. El predeterminado es nearest.

Los métodos disponibles son:

  • nearest aplica un vecino más cercano.
  • bilinear aplica un kernel de convolución bilineal.
  • cubic aplica un kernel de convolución cúbico.
  • cubicspline aplica un kernel de convolución B-Spline.
--ovr, --overview <índice>
Consulta la vista previa (nivel_de_vista_previa) (nivel_de_vista_previa=0 es la 1ª vista previa), en lugar de la banda base. Tenga en cuenta que la ubicación x,y (si el sistema de coordenadas es píxel/línea) aún debe darse con respecto a la banda base.

EJEMPLOS

Ejemplo 1: Informe sobre el píxel columna=5, línea=10 en el archivo byte.tif

$ gdal raster pixel-info byte.tif 5 10
{
  "type":"FeatureCollection",
  "crs":{
    "type":"name",
    "properties":{
      "name":"urn:ogc:def:crs:EPSG::26711"
    }
  },
  "features":[
    {
      "type":"Feature",
      "properties":{
        "input_coordinate":[
          5.0,
          10.0
        ],
        "column":5.0,
        "line":10.0,
        "bands":[
          {
            "band_number":1,
            "raw_value":132,
            "unscaled_value":132.0
          }
        ]
      },
      "geometry":{
        "type":"Point",
        "coordinates":[
          441020.0,
          3750720.0
        ]
      }
    }
  ]
}

Ejemplo 2: Informe sobre el punto en coordenadas UTM 11N este=441320 y norte=3750720 en el archivo byte.tif

$ gdal raster pixel-info --position-crs=dataset byte.tif 441320 3750720
{
  "type":"FeatureCollection",
  "crs":{
    "type":"name",
    "properties":{
      "name":"urn:ogc:def:crs:EPSG::26711"
    }
  },
  "features":[
    {
      "type":"Feature",
      "properties":{
        "input_coordinate":[
          441320.0,
          3750720.0
        ],
        "column":10.0,
        "line":10.0,
        "bands":[
          {
            "band_number":1,
            "raw_value":115,
            "unscaled_value":115.0
          }
        ]
      },
      "geometry":{
        "type":"Point",
        "coordinates":[
          441320.0,
          3750720.0
        ]
      }
    }
  ]
}

Ejemplo 4: Informe sobre un punto en coordenadas WGS84 proporcionadas en la entrada estándar con el orden longitud, latitud.

$ echo -117.6355 33.8970 | gdal raster pixel-info --of=csv --position-crs=WGS84 byte.tif
-117.6355 33.8970 | gdal raster pixel-info --of=csv --position-crs=WGS84 byte.tif
