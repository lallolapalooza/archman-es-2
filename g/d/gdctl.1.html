gdctl(1) Comandos de usuario gdctl(1)

Nombre

gdctl - Controlador de Pantallas GNOME

SINOPSIS

gdctl [-h] COMANDO ...

DESCRIPCIÓN

gdctl proporciona medios para mostrar la configuración de monitor activa y establecer una nueva configuración de monitor usando argumentos de línea de comandos.

Requiere un compositor que soporte la API D-Bus org.gnome.Mutter.DisplayConfig, como GNOME Shell.

COMANDOS

show

Muestra la configuración de pantalla actual

set

Establece una nueva configuración de pantalla

pref

Establece preferencias relacionadas con el monitor.

OPCIONES SHOW

--help, -h

Muestra un mensaje de ayuda y sale.

--modes, -m

Lista los modos de monitor disponibles.

--properties, -p

Lista las propiedades.

--verbose, -v

Muestra toda la información disponible (equivalente a --modes --properties).

OPCIONES SET

--help, -h

Muestra un mensaje de ayuda y sale.

--persistent, -P

Almacena la configuración aplicada en almacenamiento persistente y la restaura cuando sea aplicable.

--verbose, -v

Imprime la configuración en la salida estándar antes de aplicarla.

--verify, -V

Solo verifica, sin aplicar, la configuración.

--layout-mode MODO-DISPOSICIÓN, -l MODO-DISPOSICIÓN

Especifica el modo de disposición que debe usar la configuración. Puede ser logical (lógica) o physical (física).

--logical-monitor MONITOR-LÓGICO, -L MONITOR-LÓGICO

Añade y configura un monitor lógico. Ver OPCIONES DE MONITOR LÓGICO.

--for-lease-monitor CONECTOR, -e CONECTOR

Establece un monitor, que no forma parte de ningún monitor lógico, disponible para alquiler.

OPCIONES DE MONITOR LÓGICO

--monitor CONECTOR, -M CONECTOR

Añade un monitor al monitor lógico configurado actualmente. Todos los monitores dentro del mismo monitor lógico deben tener la misma resolución de monitor.

--primary, -p

Marca el monitor lógico configurado actualmente como primario.

--scale ESCALA, -s ESCALA

Escala los monitores dentro del monitor lógico configurado actualmente con ESCALA. Debe ser una escala soportada por todos los monitores y sus modos configurados.

--transform TRANSFORMACIÓN, -t TRANSFORMACIÓN

Transforma los monitores dentro del monitor lógico configurado actualmente usando TRANSFORMACIÓN. Las transformaciones posibles son normal, 90, 180, 270, flipped, flipped-90, flipped-270 y flipped-180.

--x X, -x X

Establece la posición X del monitor lógico configurado actualmente.

--y Y, -y Y Posición Y

Establece la posición Y del monitor lógico configurado actualmente.

--right-of CONECTOR

Coloca el monitor lógico a la derecha del monitor lógico al que pertenece CONECTOR.

--left-of CONECTOR Colocar a la izquierda de otro monitor

Coloca el monitor lógico a la izquierda del monitor lógico al que pertenece CONECTOR.

--above CONECTOR

Coloca el monitor lógico encima del monitor lógico al que pertenece CONECTOR.

--below CONECTOR

Coloca el monitor lógico debajo del monitor lógico al que pertenece CONECTOR.

OPCIONES DE MONITOR

--mode MODO, -m MODO

Establece el modo del monitor.

--color-mode MODO-COLOR, -c MODO-COLOR

Establece el modo de color del monitor. Los modos de color disponibles son default (predeterminado) y bt2100.

--rgb-range RANGO-RGB, -r RANGO-RGB

Establece el rango de cuantificación RGB del monitor. Los rangos disponibles son auto, full (completo) y limited (limitado, 16:235).

OPCIONES PREFS

--monitor CONECTOR, -M CONECTOR

Cambia las preferencias del monitor. Ver OPCIONES DE PREFERENCIAS DE MONITOR.

OPCIONES DE PREFERENCIAS DE MONITOR

--luminance LUMINANCIA, -l LUMINANCIA

Establece la luminancia del monitor para el modo de color actual.

--reset-luminance

Restablece la luminancia del monitor para el modo de color actual a su valor predeterminado.

EJEMPLOS

Duplica DP-1 y eDP-1, y coloca DP-2, transformado 270 grados, a la derecha de los dos monitores duplicados.

gdctl set --logical-monitor
          --primary
          --monitor DP-1
          --monitor eDP-1
          --logical-monitor
          --monitor DP-2
          --right-of DP-1
          --transform 270

Establece eDP-1 y DP-2 como disponibles para alquiler.

gdctl set --logical-monitor
          --primary
          --monitor DP-1
          --for-lease-monitor eDP-1
          --for-lease-monitor DP-2

ERRORES

El rastreador de errores se puede encontrar visitando el sitio web https://gitlab.gnome.org/GNOME/mutter/-/issues. Antes de enviar un informe de error, verifique que tiene la última versión de gnome-shell. Muchos errores (mayores y menores) se corrigen en cada versión, y si el suyo está desactualizado, el problema puede haber sido resuelto.
