NOMBRE

gdalmanage - Identificar, eliminar, renombrar y copiar archivos de datos ráster.

SINOPSIS

Uso: gdalmanage [--help] [--help-general]
                  <modo> [-r] [-fr] [-u] [-f <formato>]
                  <nombredelconjuntodedatos> [<nuevonombreconjuntodedatos>]

DESCRIPCIÓN

El programa gdalmanage puede realizar diversas operaciones en archivos de conjuntos de datos, dependiendo del modo elegido. Esto incluye identificar tipos de conjuntos de datos y eliminar, renombrar o copiar los archivos.

<modo>
Modo de operación
identify <nombredelconjuntodedatos>:
Listar el formato de datos del/los archivo/s.
copy <nombredelconjuntodedatos> <nuevonombreconjuntodedatos>:
Crear una copia del archivo del conjunto de datos con un nuevo nombre.
rename <nombredelconjuntodedatos> <nuevonombreconjuntodedatos>:
Cambiar el nombre del archivo del conjunto de datos.
delete <nombredelconjuntodedatos>:
Eliminar archivo(s) del conjunto de datos.
-r
Escanear recursivamente archivos/carpetas en busca de archivos de conjuntos de datos.
-fr
Escanear recursivamente carpetas en busca de archivos de conjuntos de datos, forzando la recursión en carpetas reconocidas como formatos válidos.
-u
Informar fallos si el tipo de archivo no está identificado.
-f <formato>
Especificar el formato del archivo del conjunto de datos si es desconocido por la aplicación. Usa un nombre corto del formato de datos (p.ej., GTiff).
<nombredelconjuntodedatos>
Archivo ráster sobre el que operar. Con identify puede repetirse para múltiples archivos.
<nuevonombreconjuntodedatos>
Para los modos de copia y renombrado, proporcionas un nombre de archivo fuente y un nombre de archivo destino, al igual que los comandos de copia y movimiento en un sistema operativo.

EJEMPLOS

Usando el modo identify

Informar el formato de datos del archivo del conjunto de datos utilizando el modo identify y especificando un nombre de archivo de datos:

$ gdalmanage identify NE1_50M_SR_W.tif
NE1_50M_SR_W.tif: GTiff

El modo recursivo escaneará las subcarpetas e informará el formato de datos:

$ gdalmanage identify -r 50m_raster/
NE1_50M_SR_W/ne1_50m.jpg: JPEG
NE1_50M_SR_W/ne1_50m.png: PNG
NE1_50M_SR_W/ne1_50m_20pct.tif: GTiff
NE1_50M_SR_W/ne1_50m_band1.tif: GTiff
NE1_50M_SR_W/ne1_50m_print.png: PNG
NE1_50M_SR_W/NE1_50M_SR_W.aux: HFA
NE1_50M_SR_W/NE1_50M_SR_W.tif: GTiff
NE1_50M_SR_W/ne1_50m_sub.tif: GTiff
NE1_50M_SR_W/ne1_50m_sub2.tif: GTiff

Usando el modo copy

Copiar el conjunto de datos:

$ gdalmanage copy NE1_50M_SR_W.tif ne1_copy.tif

Usando el modo rename

Renombrar el conjunto de datos:

$ gdalmanage rename NE1_50M_SR_W.tif ne1_rename.tif

Usando el modo delete

Eliminar el conjunto de datos:

gdalmanage delete NE1_50M_SR_W.tif
