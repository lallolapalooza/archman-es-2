gdnsd-plugin-null(8)

Paquete: gdnsd

Licencias: GPL3

GDNSD-PLUGIN-NULL(8) gdnsd GDNSD-PLUGIN-NULL(8)

NOMBRE

gdnsd-plugin-null - plugin null de gdnsd

SINOPSIS

Ejemplo de configuración de service_types para null:

service_types => {
  my_null_mon => {
    plugin => null,
    # ... otros parámetros genéricos de service_type
  }
}

RRs de archivo de zona que usan resolución null

foo 300 DYNA null
bar 300 DYNC null!whatever

DESCRIPCIÓN

gdnsd-plugin-null existe principalmente como un ejemplo del mínimo plugin posible de ambos tipos. Es simultáneamente un plugin de monitorización y un plugin de resolución.

Cuando se usa como plugin de resolución en RRs "DNYA" o "DYNC", ignora cualquier nombre de recurso proporcionado. Siempre devuelve la dirección IPv4 0.0.0.0 y la dirección IPv6 "::".

Cuando se usa como plugin de monitorización definiendo un service_type como se muestra en el ejemplo anterior, emula el comportamiento de un plugin de monitorización real (actualizando en intervalos correctos, etc.) pero envía un resultado "DOWN" en cada intervalo de comprobación de monitorización sin comprobar nada realmente.
