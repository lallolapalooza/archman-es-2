NOMBRE

gdb-add-index - Añadir archivos de índice para acelerar GDB

SINOPSIS

gdb-add-index [-dwarf-5] nombre_archivo

DESCRIPCIÓN

Cuando GDB encuentra un archivo de símbolos, escanea los símbolos en el archivo para construir una tabla de símbolos interna. Esto permite que la mayoría de las operaciones de GDB funcionen rápidamente, a costa de un retraso inicial. Para programas grandes, este retraso puede ser bastante largo, por lo que GDB proporciona una forma de construir un índice, que acelera el arranque.

Para determinar si un archivo contiene dicho índice, utilice el comando "readelf -S nombre_archivo": el índice se almacena en una sección llamada ".gdb_index" (pre-DWARF 5) o ".debug_names" y ".debug_str" (DWARF 5). Los índices solo se pueden generar en sistemas que utilizan binarios ELF e información de depuración DWARF (es decir, secciones llamadas ".debug_*").

Por defecto, gdb-add-index añadirá una sección ".gdb_index" pre-DWARF 5 a nombre_archivo. Con -dwarf-5 se añaden secciones DWARF 5 en su lugar.

nombre_archivo debe ser escribible.

gdb-add-index utiliza GDB, objcopy y readelf que se encuentran en la variable de entorno PATH. Si desea utilizar diferentes versiones de estos programas, puede especificarlas a través de las variables de entorno apropiadas (ver abajo).

gdb-add-index sale con el estado 0 si tiene éxito en la creación del índice para nombre_archivo o mayor que 0 si ocurre un error.

Ver más información en el manual de GDB en el nodo "Index Files" -- comando de shell "info -f gdb -n \"Index Files\"".

OPCIONES

-dwarf-5
Añade secciones DWARF 5 en lugar de la sección ".debug_index" anterior.

AMBIENTE

GDB
Nombre de archivo completo del programa "gdb" a utilizar para la generación del índice. Si no está configurado, se buscará un programa "gdb" en el PATH.
OBJCOPY
Nombre de archivo completo del programa "objcopy" a utilizar para copiar la información de la sección en el archivo dado. Si no está configurado, se buscará un programa "objcopy" en el PATH.
READELF
Nombre de archivo completo del programa "readelf" a utilizar para inspeccionar las propiedades del archivo dado. Si no está configurado, se buscará un programa "readelf" en el PATH.

VER TAMBIÉN

La documentación completa de GDB se mantiene como un manual de Texinfo. Si los programas "info" y "gdb" y la documentación de Texinfo de GDB están correctamente instalados en su sitio, el comando

info gdb

debería darle acceso al manual completo.
