NOMBRE

gdal-raster-rgb-to-palette - Convierte una imagen RGB en una imagen de paleta / pseudo-color.

Añadido en la versión 3.12.

SINOPSIS

Uso: gdal raster rgb-to-palette [OPCIONES] <ENTRADA> <SALIDA>
Convierte una imagen RGB en una imagen de paleta / pseudo-color.
Argumentos posicionales:
  -i, --input <ENTRADA>                                Dataset(s) de raster de entrada [requerido]
  -o, --output <SALIDA>                                Dataset de raster de salida [requerido]
Opciones comunes:
  -h, --help                                           Muestra el mensaje de ayuda y sale
  --json-usage                                         Muestra el uso como un documento JSON y sale
  --config <CLAVE>=<VALOR>                             Opción de configuración [puede repetirse]
  -q, --quiet                                          Modo silencioso (sin barra de progreso)
Opciones:
  -f, --of, --format, --output-format <FORMATO-SALIDA>  Formato de salida ("GDALG" permitido)
  --co, --creation-option <CLAVE>=<VALOR>            Opción de creación [puede repetirse]
  --overwrite                                          Si se permite sobrescribir la salida existente
                                                       Mutuamente excluyente con --append
  --append                                             Añadir como subdataset a la salida existente
                                                       Mutuamente excluyente con --overwrite
  --color-count <NUMERO-DE-COLORES>                    Selecciona el número de colores en la tabla de color generada (por defecto: 256)
  --color-map <MAPA-DE-COLORES>                        Archivo del mapa de colores
Opciones avanzadas:
  --if, --input-format <FORMATO-ENTRADA>               Formatos de entrada [puede repetirse]
  --oo, --open-option <CLAVE>=<VALOR>                  Opciones de apertura [puede repetirse]

DESCRIPCIÓN

gdal raster rgb-to-palette calcula una tabla de pseudo-color óptima para una imagen RGB dada utilizando un algoritmo de corte mediano en un histograma RGB degradado, a menos que se proporcione una tabla de colores con la opción --color-map. Luego, convierte la imagen en una imagen pseudo-coloreada utilizando la tabla de colores. Esta conversión utiliza el difuminado Floyd-Steinberg (difusión de errores) para maximizar la calidad visual de la imagen de salida.

Este subcomando también está disponible como un paso potencial de gdal raster pipeline

Opciones estándar

-f, --of, --format, --output-format <FORMATO-SALIDA>
Qué formato de raster de salida usar. Los valores permitidos pueden ser proporcionados por gdal --formats | grep raster | grep rw | sort
--co <NOMBRE>=<VALOR>
Muchos formatos tienen una o más opciones de creación opcionales que pueden usarse para controlar detalles sobre el archivo creado. Por ejemplo, el controlador GeoTIFF soporta opciones de creación para controlar la compresión y si el archivo debe ser en mosaicos.

Puede repetirse.

Las opciones de creación disponibles varían según el controlador de formato, y algunos formatos simples no tienen opciones de creación en absoluto. Una lista de opciones soportadas para un formato puede ser listada con la opción de línea de comandos --formats, pero la documentación del formato es la fuente definitiva de información sobre las opciones de creación del controlador. Consulte la documentación específica del formato de Controladores de raster para ver las opciones de creación legales para cada formato.

--overwrite
Permite al programa sobrescribir el archivo o dataset de destino existente. En caso contrario, por defecto, gdal genera un error si el archivo o dataset de destino ya existe.
--color-count <NUMERO-DE-COLORES>
Selecciona el número de colores en la tabla de colores generada. Por defecto es 256. Debe estar entre 2 y 256.
--color-map <NOMBRE-DE-ARCHIVO>
Extrae la tabla de colores de <NOMBRE-DE-ARCHIVO> en lugar de calcularla. Se puede usar para tener una tabla de colores consistente para múltiples archivos. El <NOMBRE-DE-ARCHIVO> debe ser un archivo raster en un formato soportado por GDAL con una paleta o un archivo de colores en un formato soportado (.txt, .qml de QGIS, .qlr de QGIS).

SALIDA GDALG (EN TIEMPO REAL / DATASET EN FLUJO)

Este programa soporta la serialización de la línea de comandos como un archivo JSON usando el formato de salida GDALG. El archivo resultante puede ser abierto como un dataset raster usando el controlador GDALG: GDAL Streamed Algorithm, y aplicar el pipeline especificado de forma en tiempo real / en flujo.

NOTA:

Sin embargo, este algoritmo no es nativamente compatible con el flujo. En consecuencia, se generará un dataset temporal, lo que puede causar un tiempo de procesamiento significativo al abrirlo.

EJEMPLOS

Ejemplo 1

Convertir un archivo TIFF en una imagen PNG paletizada

$ gdal raster rgb-to-palette entrada.tif salida.png
