NOMBRE

gdal-raster-nodata-to-alpha - Reemplazar valores nodata con una banda alfa

Añadido en la versión 3.12.

SINOPSIS

Uso: gdal raster nodata-to-alpha [OPCIONES] <ENTRADA> <SALIDA>
Reemplazar valores nodata con una banda alfa.
Argumentos posicionales:
  -i, --input <ENTRADA>                                  Conjuntos de datos ráster de entrada [requerido]
  -o, --output <SALIDA>                                Conjunto de datos ráster de salida [requerido]
Opciones comunes:
  -h, --help                                           Mostrar mensaje de ayuda y salir
  --json-usage                                         Mostrar uso como documento JSON y salir
  --config <CLAVE>=<VALOR>                               Opción de configuración [puede repetirse]
  -q, --quiet                                          Modo silencioso (sin barra de progreso)
Opciones:
  -f, --of, --format, --output-format <FORMATO-SALIDA>  Formato de salida ("GDALG" permitido)
  --co, --creation-option <CLAVE>=<VALOR>                Opción de creación [puede repetirse]
  --overwrite                                          Permitir sobrescribir la salida existente
                                                       Mutuamente excluyente con --append
  --append                                             Añadir como subconjunto de datos a la salida existente
                                                       Mutuamente excluyente con --overwrite
  --nodata <NODATA>                                    Anular el valor nodata de las bandas de entrada (valor numérico, 'nan', 'inf', '-inf') [puede repetirse]
Opciones avanzadas:
  --if, --input-format <FORMATO-ENTRADA>                  Formatos de entrada [puede repetirse]
  --oo, --open-option <CLAVE>=<VALOR>                    Opciones de apertura [puede repetirse]

DESCRIPCIÓN

gdal raster nodata-to-alpha añade una banda alfa basada en los metadatos del valor nodata establecidos en las bandas del conjunto de datos de entrada.

Si no hay un valor nodata explícito en el conjunto de datos de entrada, es posible añadirlo con la opción --nodata.

Este programa no realiza ninguna operación y puede ser utilizado de forma segura si el conjunto de datos de entrada no tiene valor nodata y no se especifica --nodata.

Opciones

--nodata <NODATA>
Anular el valor nodata de las bandas de entrada (valor numérico, 'nan', 'inf', '-inf'). Se puede especificar un valor o tantos valores como bandas de entrada haya. Cuando se especifican múltiples valores, un píxel solo se considera inválido si coincide con los valores nodata en todas las bandas.
--co <NOMBRE>=<VALOR>
Muchos formatos tienen una o más opciones de creación opcionales que se pueden usar para controlar detalles sobre el archivo creado. Por ejemplo, el controlador GeoTIFF admite opciones de creación para controlar la compresión y si el archivo debe ser en mosaico.

Puede repetirse.

Las opciones de creación disponibles varían según el controlador de formato, y algunos formatos simples no tienen opciones de creación en absoluto. Se puede listar una lista de opciones compatibles para un formato con la opción de línea de comandos --formats, pero la documentación del formato es la fuente definitiva de información sobre las opciones de creación del controlador. Consulte la documentación específica del formato de Controladores ráster para conocer las opciones de creación legales para cada formato.

-f, --of, --format, --output-format <FORMATO-SALIDA>
Qué formato ráster de salida usar. Los valores permitidos pueden ser proporcionados por gdal --formats | grep raster | grep rw | sort
--ot, --datatype, --output-data-type <TIPO-DATO-SALIDA>
Tipo de dato de salida entre Byte, Int8, UInt16, Int16, UInt32, Int32, UInt64, Int64, CInt16, CInt32, Float32, Float64, CFloat32, CFloat64.

SALIDA GDALG (FORMATO SOBRE LA MARCHA / STREAMING)

Este programa admite la serialización de la línea de comandos como un archivo JSON utilizando el formato de salida GDALG. El archivo resultante puede luego abrirse como un conjunto de datos ráster usando el controlador GDALG: GDAL Streamed Algorithm, y aplicar el pipeline especificado de forma sobre la marcha / en streaming.

EJEMPLOS

Ejemplo 1

$ gdal raster nodata-to-alpha input_with_nodata.tif output_with_alpha_band.tif
