NOMBRE

gdal_fillnodata - Rellena regiones de ráster por interpolación desde los bordes.

SINOPSIS

gdal_fillnodata [--help] [--help-general] [-q] [-md <distancia_maxima>]
           [-si <iteraciones_suavizado>] [-o <nombre>=<valor> [<nombre>=<valor> ...]]
           [-mask <archivo>] [-interp {inv_dist,nearest}] [-b <banda>]
           [-of <formato_gdal>] [-co <nombre>=<valor>]
           <archivo_fuente> <archivo_destino>

DESCRIPCIÓN

gdal_fillnodata rellena regiones seleccionadas (generalmente áreas sin datos) interpolando a partir de píxeles válidos alrededor de los bordes del área.

Más detalles sobre el algoritmo están disponibles en la documentación de GDALFillNodata().

NOTA:

gdal_fillnodata es una utilidad de Python y solo está disponible si las vinculaciones de Python de GDAL están disponibles.
--help
Muestra este mensaje de ayuda y sale.
--help-general
Proporciona un breve mensaje de uso para las opciones genéricas de línea de comandos de GDAL y sale.
-q
El script se ejecuta en modo silencioso. El monitor de progreso se suprime y los mensajes rutinarios no se muestran.
-md <distancia_maxima>
La distancia máxima (en píxeles) que el algoritmo buscará para obtener valores para interpolar. El valor predeterminado es 100 píxeles.
-si <iteraciones_suavizado>
El número de iteraciones de suavizado con filtro de promedio 3x3 para ejecutar después de la interpolación para atenuar artefactos. El valor predeterminado es cero iteraciones de suavizado.
-o <nombre>=<valor>
Especifica un argumento especial para el algoritmo. Actualmente no se soportan.
-b <banda>
La banda en la que operar. Por defecto, se opera en la primera banda.
-mask <archivo>
Usa la primera banda del archivo especificado como máscara de validez (cero es inválido, distinto de cero es válido).
-of <formato>
Selecciona el formato de salida. El predeterminado es GTiff -- Formato de archivo GeoTIFF. Usa el nombre corto del formato.
-interp {inv_dist,nearest}
Añadido en la versión 3.9.

Por defecto, los píxeles se interpolan utilizando un ponderado por distancia inversa (inv_dist). También es posible elegir una estrategia de vecino más cercano (nearest).

<archivo_fuente>
El archivo ráster fuente utilizado para identificar los píxeles objetivo. Solo se usa una banda.
<archivo_destino>
El nuevo archivo a crear con el resultado interpolado.
