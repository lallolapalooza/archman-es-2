NOMBRE

gdal-vector-simplify - Simplifica geometrías de un conjunto de datos vectoriales

Añadido en la versión 3.12.

SINOPSIS

Uso: gdal vector simplify [OPCIONES] <ENTRADA> <SALIDA> <TOLERANCIA>
Simplifica geometrías de un conjunto de datos vectoriales.
Argumentos posicionales:
  -i, --input <ENTRADA>                                  Conjuntos de datos vectoriales de entrada [requerido]
  -o, --output <SALIDA>                                  Conjunto de datos vectoriales de salida [requerido]
  --tolerance <TOLERANCIA>                              Tolerancia de distancia para la simplificación. [requerido]
Opciones comunes:
  -h, --help                                           Muestra el mensaje de ayuda y sale
  --json-usage                                         Muestra el uso como un documento JSON y sale
  --config <CLAVE>=<VALOR>                               Opción de configuración [puede repetirse]
  -q, --quiet                                          Modo silencioso (sin barra de progreso)
Opciones:
  -l, --layer, --input-layer <CAPA-ENTRADA>             Nombre(s) de la capa de entrada [puede repetirse]
  -f, --of, --format, --output-format <FORMATO-SALIDA>  Formato de salida ("GDALG" permitido)
  --co, --creation-option <CLAVE>=<VALOR>                Opción de creación [puede repetirse]
  --lco, --layer-creation-option <CLAVE>=<VALOR>         Opción de creación de capa [puede repetirse]
  --overwrite                                          Si se permite sobrescribir la salida existente
  --update                                             Si se abre el conjunto de datos existente en modo de actualización
  --overwrite-layer                                    Si se permite sobrescribir la capa de salida existente
  --append                                             Si se permite añadir a la capa existente
                                                       Mutuamente excluyente con --upsert
  --output-layer <CAPA-SALIDA>                         Nombre de la capa de salida
  --skip-errors                                        Omitir errores al escribir características
  --active-layer <CAPA-ACTIVA>                         Establecer la capa activa (si no se especifica, todas)
  --active-geometry <GEOMETRIA-ACTIVA>                 Nombre del campo de geometría al que se restringirá el procesamiento (si no se especifica, todas)
Opciones avanzadas:
  --if, --input-format <FORMATO-ENTRADA>                 Formatos de entrada [puede repetirse]
  --oo, --open-option <CLAVE>=<VALOR>                    Opciones de apertura [puede repetirse]
  --output-oo, --output-open-option <CLAVE>=<VALOR>      Opciones de apertura de salida [puede repetirse]
  --upsert                                             Insertar/actualizar características (implica 'append')
                                                       Mutuamente excluyente con --append

DESCRIPCIÓN

gdal vector simplify simplifica geometrías, asegurando que el resultado sea una geometría válida que tenga la misma dimensión y número de componentes que la entrada.

La simplificación utiliza un algoritmo de diferencia de distancia máxima similar al utilizado en el algoritmo de Douglas-Peucker.

Esto se hace mediante el método OGRGeometry::SimplifyPreserveTopology() que preserva la topología por característica, pero no para una capa completa. Por lo tanto, pueden ocurrir huecos o superposiciones entre geometrías que inicialmente eran contiguas. Para realizar una simplificación que preserve los límites compartidos entre geometrías, consulte gdal vector simplify-coverage.

Este comando también puede utilizarse como un paso de gdal vector pipeline.

NOTA:

Este comando requiere una compilación de GDAL contra la biblioteca GEOS.

Opciones estándar

-f, --of, --format, --output-format <FORMATO-SALIDA>
Qué formato vectorial de salida utilizar. Los valores permitidos pueden ser proporcionados por gdal --formats | grep vector | grep rw | sort
--co <NOMBRE>=<VALOR>
Muchos formatos tienen una o más opciones de creación de conjuntos de datos opcionales que pueden usarse para controlar detalles específicos del archivo creado. Por ejemplo, el controlador GeoPackage admite opciones de creación para controlar la versión.

Puede repetirse.

Las opciones de creación de conjuntos de datos disponibles varían según el controlador de formato, y algunos formatos simples no tienen opciones de creación en absoluto. Una lista de opciones compatibles para un formato puede mostrarse con la opción de línea de comandos --formats, pero la documentación del formato es la fuente definitiva de información sobre las opciones de creación del controlador. Consulte la documentación específica del formato de Controladores vectoriales para conocer las opciones de creación legales para cada formato.

Tenga en cuenta que las opciones de creación de conjuntos de datos son diferentes de las opciones de creación de capas.

-lco <NOMBRE>=<VALOR>
Opción de creación de capa (específica del formato)
--overwrite
Permite al programa sobrescribir el archivo o conjunto de datos de destino existente. De lo contrario, por defecto, gdal genera un error si el archivo o conjunto de datos de destino ya existe.
--active-layer <CAPA-ACTIVA>
Establece la capa activa. Cuando se especifica, solo la capa especificada por su nombre estará sujeta al procesamiento. Otras capas no se modificarán. Si no se especifica esta opción, todas las capas estarán sujetas al procesamiento.
--active-geometry <GEOMETRIA-ACTIVA>
Establece el campo de geometría activa por su nombre. Cuando se especifica, solo el campo de geometría especificado estará sujeto al procesamiento. Otros campos de geometría no se modificarán. Si no se especifica esta opción, todos los campos de geometría estarán sujetos al procesamiento. Esta opción se puede combinar con --active-layer.
--tolerance <TOLERANCIA>
El valor especificado de esta opción es la tolerancia utilizada para fusionar puntos consecutivos de la geometría de salida utilizando el método OGRGeometry::SimplifyPreserveTopology(). La unidad de la distancia está en unidades geoespaciales de la capa de origen.

Opciones avanzadas

--oo <NOMBRE>=<VALOR>
Opción de apertura del conjunto de datos (específica del formato).

Puede repetirse.

--if <formato>
Nombre del formato/controlador que se intentará para abrir el/los archivo(s) de entrada. Generalmente no es necesario especificarlo, pero puede usarse para omitir la detección automática del controlador cuando falla en seleccionar el controlador apropiado. Esta opción puede repetirse varias veces para especificar varios controladores candidatos. Tenga en cuenta que no obliga a esos controladores a abrir el conjunto de datos. En particular, algunos controladores tienen requisitos sobre las extensiones de archivo.

Puede repetirse.

SALIDA GDALG (CONJUNTO DE DATOS SOBRE LA MARCHA / STREAMING)

Este programa admite la serialización de la línea de comandos como un archivo JSON utilizando el formato de salida GDALG. El archivo resultante puede luego abrirse como un conjunto de datos vectoriales utilizando el controlador GDALG: GDAL Streamed Algorithm, y aplicar el pipeline especificado de forma sobre la marcha / streaming.

EJEMPLOS

Ejemplo 1: Simplificar geometrías usando una tolerancia de un km (asumiendo que el SRC está en metros)

$ gdal vector simplify --tolerance=1000 in.gpkg out.gpkg --overwrite
