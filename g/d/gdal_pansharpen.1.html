NOMBRE

gdal_pansharpen - Realiza una operación de pan-sharpening.

SINOPSIS

gdal_pansharpen [--help] [--help-general]
                <dataset_pan>
                <dataset_espectral>[,banda=<num>] [<dataset_espectral>[,banda=<num>]]...
                <dataset_salida>
                [-of <formato>] [-b <banda>]... [-w <valor_peso>]...
                [-r {nearest|bilinear|cubic|cubicspline|lanczos|average}]
                [-threads {ALL_CPUS|<numero>}] [-bitdepth <val>] [-nodata <val>]
                [-spat_adjust {union|intersection|none|nonewithoutwarning}]
                [-co <NOMBRE>=<VALOR>]... [-q]

DESCRIPCIÓN

gdal_pansharpen realiza una operación de pan-sharpening. Puede crear un dataset de salida "clásico" (como GeoTIFF) o un dataset VRT que describe la operación de pan-sharpening.

Se pueden encontrar más detalles en la sección VRT Pan-sharpened.

NOTA:

gdal_pansharpen es una utilidad de Python y solo está disponible si las bindings de Python de GDAL están disponibles.
--help
Muestra este mensaje de ayuda y sale
--help-general
Proporciona un breve mensaje de uso para las opciones de línea de comandos generales de GDAL y sale.
-of <formato>
Selecciona el formato de salida. Si no se especifica, el formato se adivina a partir de la extensión. Utiliza el nombre corto del formato. También se puede usar VRT.
-b <banda>
Selecciona la banda banda de las bandas espectrales de entrada para la salida. Las bandas se numeran a partir de 1 en el orden en que se especifican las bandas espectrales. Se pueden usar múltiples interruptores -b. Cuando no se utiliza ningún interruptor -b, se configuran todas las bandas espectrales de entrada para la salida.
-w <valor_peso>
Especifica un peso para el cálculo del valor pancromático pseudo. Debe haber tantos interruptores -w como bandas espectrales de entrada.
-r {nearest|bilinear|cubic|cubicspline|lanczos|average}
Selecciona un algoritmo de remuestreo. cubic es el valor por defecto.
-threads {ALL_CPUS|<numero>}
Especifica el número de hilos a utilizar para realizar el remuestreo y el pan-sharpening en sí. Puede ser un número entero o ALL_CPUS.
-bitdepth <val>
Especifica la profundidad de bits de las bandas pancromática y espectrales (por ejemplo, 12). Si no se especifica, se utilizará el elemento de metadatos NBITS de la banda pancromática si existe.
-nodata <val>
Especifica el valor de no datos para las bandas. Se utiliza para el cálculo del remuestreo y pan-sharpening en sí. Si no está establecido, se deduce de las bandas de entrada, siempre que tengan una configuración consistente.
-spat_adjust {union|intersection|none|nonewithoutwarning}
Selecciona el comportamiento cuando las bandas no tienen la misma extensión. Consulte la documentación de SpatialExtentAdjustment en VRT Pan-sharpened. union es el valor por defecto.
-co <NOMBRE>=<VALOR>
Muchos formatos tienen una o más opciones de creación opcionales que se pueden usar para controlar detalles del archivo creado. Por ejemplo, el controlador GeoTIFF admite opciones de creación para controlar la compresión y si el archivo debe dividirse en mosaicos.

Las opciones de creación disponibles varían según el controlador de formato y algunos formatos simples no tienen opciones de creación en absoluto. Se puede listar una lista de opciones admitidas para un formato con la opción de línea de comandos --format, pero la documentación del formato es la fuente definitiva de información sobre las opciones de creación del controlador. Consulte la documentación específica del formato de Controladores ráster para conocer las opciones de creación legales para cada formato.

-q
Suprime el monitor de progreso y otra salida que no sea de error.
<dataset_pan>
Dataset con banda pancromática (se utilizará la primera banda).
<dataset_espectral>[,banda=<num>]
Dataset con una o varias bandas espectrales. Si no se especifica la opción de banda, se tienen en cuenta todas las bandas de los datasets. De lo contrario, solo la banda especificada (num). El mismo dataset se puede repetir varias veces.
<dataset_salida>
Dataset de salida

Las bandas deben estar en la misma proyección.

EJEMPLO

Ejemplo 1: Con bandas espectrales en un único dataset

gdal_pansharpen panchro.tif multispectral.tif pansharpened_out.tif

Ejemplo 2: Con algunas bandas espectrales de un único dataset, reordenadas

gdal_pansharpen panchro.tif multispectral.tif,banda=3 multispectral.tif,banda=2 multispectral.tif,banda=1 pansharpened_out.tif

Ejemplo 3: Con bandas espectrales en varios datasets

gdal_pansharpen panchro.tif band1.tif band2.tif band3.tif pansharpened_out.tif

Ejemplo 4: Especificando pesos

gdal_pansharpen -w 0.7 -w 0.2 -w 0.1 panchro.tif multispectral.tif pansharpened_out.tif

Ejemplo 5: Especificar bandas RGB de un dataset multiespectral RGBNir mientras se calcula la intensidad pancromática pseudo en las 4 bandas RGBNir

gdal_pansharpen -b 1 -b 2 -b 3 panchro.tif rgbnir.tif pansharpened_out.tif
