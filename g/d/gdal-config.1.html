NOMBRE

gdal-config - Determina diversa información sobre una instalación de GDAL.

Determina diversa información sobre una instalación de GDAL.

SINOPSIS

gdal-config [OPCIONES]
Opciones:
        [--prefix[=DIR]]
        [--libs]
        [--cflags]
        [--version]
        [--ogr-enabled]
        [--formats]

DESCRIPCIÓN

Este script de utilidad (disponible en sistemas Unix) se puede usar para determinar diversa información sobre una instalación de GDAL. Normalmente solo lo usan los scripts de configuración para aplicaciones que utilizan GDAL, pero un usuario final puede consultarlo.

--prefix
el directorio de nivel superior para la instalación de GDAL.
--libs
Las bibliotecas y directivas de enlace necesarias para usar GDAL.
--cflags
Las inclusiones y definiciones de macros necesarias para compilar módulos que usan GDAL.
--version
Informa la versión de GDAL.
--ogr-enabled
Informa "yes" o "no" a la salida estándar dependiendo de si OGR está integrado en GDAL.
--formats
Informa qué formatos están configurados en GDAL a la salida estándar.
