NOMBRE

gdal-vector-select - Selecciona un subconjunto de campos de un conjunto de datos vectorial

Añadido en la versión 3.11.

SINOPSIS

Uso: gdal vector select [OPCIONES] <ENTRADA> <SALIDA> <CAMPOS>
Selecciona un subconjunto de campos de un conjunto de datos vectorial.
Argumentos posicionales:
  -i, --input <ENTRADA>                                Conjuntos de datos vectoriales de entrada [requerido]
  -o, --output <SALIDA>                                Conjunto de datos vectoriales de salida [requerido]
  --fields <CAMPOS>                                    Campos a seleccionar (o excluir si --exclude) [se puede repetir] [requerido]
Opciones comunes:
  -h, --help                                           Muestra el mensaje de ayuda y sale
  --json-usage                                         Muestra el uso como documento JSON y sale
  --config <CLAVE>=<VALOR>                             Opción de configuración [se puede repetir]
  -q, --quiet                                          Modo silencioso (sin barra de progreso)
Opciones:
  -l, --layer, --input-layer <CAPA-ENTRADA>            Nombre(s) de la capa de entrada [se puede repetir]
  -f, --of, --format, --output-format <FORMATO-SALIDA> Formato de salida ("GDALG" permitido)
  --co, --creation-option <CLAVE>=<VALOR>                Opción de creación [se puede repetir]
  --lco, --layer-creation-option <CLAVE>=<VALOR>         Opción de creación de capa [se puede repetir]
  --overwrite                                          Si se permite sobrescribir la salida existente
  --update                                             Si se abre el conjunto de datos existente en modo de actualización
  --overwrite-layer                                    Si se permite sobrescribir la capa existente
  --append                                             Si se permite añadir a la capa existente
                                                       Mutuamente excluyente con --upsert
  --output-layer <CAPA-SALIDA>                         Nombre de la capa de salida
  --skip-errors                                        Omitir errores al escribir características
  --active-layer <CAPA-ACTIVA>                         Establece la capa activa (si no se especifica, todas)
  --exclude                                            Excluir los campos especificados
                                                       Mutuamente excluyente con --ignore-missing-fields
  --ignore-missing-fields                              Ignorar campos que faltan
                                                       Mutuamente excluyente con --exclude
Opciones avanzadas:
  --if, --input-format <FORMATO-ENTRADA>               Formatos de entrada [se puede repetir]
  --oo, --open-option <CLAVE>=<VALOR>                    Opciones de apertura [se puede repetir]
  --output-oo, --output-open-option <CLAVE>=<VALOR>      Opciones de apertura de salida [se puede repetir]
  --upsert                                             Actualizar elementos (implica 'append')
                                                       Mutuamente excluyente con --append

DESCRIPCIÓN

gdal vector select se puede usar para seleccionar un subconjunto de campos.

select también se puede usar como un paso del gdal vector pipeline.

Opciones estándar

-f, --of, --format, --output-format <FORMATO-SALIDA>
Qué formato vectorial de salida usar. Los valores permitidos pueden ser dados por gdal --formats | grep vector | grep rw | sort
--co <NOMBRE>=<VALOR>
Muchos formatos tienen una o más opciones de creación de conjunto de datos opcionales que se pueden usar para controlar particularidades del archivo creado. Por ejemplo, el controlador GeoPackage soporta opciones de creación para controlar la versión.

Se puede repetir.

Las opciones de creación de conjunto de datos disponibles varían según el controlador del formato, y algunos formatos simples no tienen opciones de creación. Una lista de opciones soportadas para un formato se puede obtener con la opción de línea de comandos --formats, pero la documentación del formato es la fuente definitiva de información sobre las opciones de creación del controlador. Consulte la documentación específica del formato de Controladores vectoriales para ver las opciones de creación legales para cada formato.

Tenga en cuenta que las opciones de creación de conjunto de datos son diferentes de las opciones de creación de capa.

-lco <NOMBRE>=<VALOR>
Opción de creación de capa (específica del formato)
--overwrite
Permite al programa sobrescribir el archivo o conjunto de datos de destino existente. De lo contrario, por defecto, gdal genera un error si el archivo o conjunto de datos de destino ya existe.
--active-layer <CAPA-ACTIVA>
Establece la capa activa. Cuando se especifica, solo la capa especificada por su nombre será objeto del procesamiento. Otras capas no se modificarán. Si esta opción no se especifica, todas las capas serán objeto del procesamiento.
--fields <CAMPOS>
Lista separada por comas de campos de la capa de entrada para copiar a la nueva capa (o para excluir si se especifica --exclude)

Los nombres de campo con espacios, comas o comillas dobles deben estar rodeados por un carácter de comilla doble de inicio y fin, y las comillas dobles en un nombre de campo deben escaparse con una barra invertida.

Dependiendo del shell utilizado, esto podría requerir comillas adicionales. Por ejemplo, para seleccionar regular_field, a_field_with space, and comma y a field with " double quote con un shell de Unix:

--fields "regular_field,\"a_field_with space, and comma\",\"a field with \\\" double quote\""

Un campo solo se selecciona una vez, incluso si se menciona varias veces en la lista.

Los campos de geometría también se pueden especificar en la lista. Si la capa de origen no tiene un nombre explícito para el campo de geometría, se debe usar _ogr_geometry_ para seleccionar el campo de geometría único.

Especificar un nombre de campo de origen no existente resulta en un error.

--ignore-missing-fields
Por defecto, si un campo especificado por --fields no existe en las capas de entrada, se emite un error y se detiene el procesamiento. Al especificar --ignore-missing-fields, solo se emite una advertencia y los campos no existentes simplemente se ignoran.
--exclude
Modifica el comportamiento del algoritmo de tal manera que se seleccionan todos los campos, excepto los mencionados por --fields.

Opciones avanzadas

--oo <NOMBRE>=<VALOR>
Opción de apertura de conjunto de datos (específica del formato).

Se puede repetir.

--if <formato>
Nombre del formato/controlador que se intentará para abrir el(los) archivo(s) de entrada. Generalmente no es necesario especificarlo, pero puede usarse para omitir la detección automática del controlador, cuando falla al seleccionar el controlador apropiado. Esta opción se puede repetir varias veces para especificar varios controladores candidatos. Tenga en cuenta que no obliga a esos controladores a abrir el conjunto de datos. En particular, algunos controladores tienen requisitos sobre las extensiones de archivo.

Se puede repetir.

SALIDA GDALG (CONJUNTO DE DATOS EN TIEMPO REAL / STREAMING)

Este programa admite la serialización de la línea de comandos como un archivo JSON utilizando el formato de salida GDALG. El archivo resultante se puede abrir como un conjunto de datos vectorial utilizando el controlador GDALG: GDAL Streamed Algorithm, y aplicar el pipeline especificado de forma en tiempo real / streaming.

Ejemplo 1: Seleccionar los campos EAS_ID y geometría de un Shapefile

$ gdal vector select in.shp out.gpkg "EAS_ID,_ogr_geometry_" --overwrite

Ejemplo 2: Eliminar campos sensibles de una capa

$ gdal vector select in.shp out.gpkg --exclude "name,surname,address" --overwrite
