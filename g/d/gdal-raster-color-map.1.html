DESCRIPCIÓ

N

gdal raster color-map genera un conjunto de datos RGB o RGBA a partir de una sola banda, usando un mapa de colores, ya sea adjunto directamente a una banda ráster o desde un archivo de texto externo. Se utiliza típicamente para crear mapas hipsométricos a partir de un

DEM.

Este subcomando también está disponible como un paso potencial de gdal raster

pipeline

--color-map
<MAPA-COLORES>
Nombre de archivo del mapa de colores que contiene la asociación entre varios valores ráster y el color correspondiente deseado.

Esta opción debe especificarse si la banda ráster de entrada no tiene una tabla de colores

adjunta.

El archivo de configuración de colores basado en texto generalmente contiene 4 columnas por línea: el valor ráster y el componente Rojo, Verde, Azul correspondiente (entre 0 y 255). El valor ráster puede ser cualquier valor de punto flotante, o la palabra clave nv para el valor sin datos. El valor ráster también puede expresarse como un porcentaje: 0% siendo el valor mínimo encontrado en el ráster, 100% el valor

máximo.

Opcionalmente se puede añadir una columna extra para el componente alfa. Si no se especifica, se asume opacidad completa

(255).

Se aceptan varios separadores de campos: coma, tabulación, espacios,

':'.
