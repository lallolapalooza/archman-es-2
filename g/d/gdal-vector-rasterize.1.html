SALIDA GDALG (CONJUNTO DE DATOS EN TIEMPO REAL / EN

FLUJO)

Este programa admite la serialización de la línea de comandos como un archivo JSON usando el formato de salida GDALG. El archivo resultante puede luego abrirse como un conjunto de datos ráster usando el controlador GDALG: GDAL Streamed Algorithm, y aplicar la tubería especificada de manera en tiempo real / en

flujo.

NOTA

:
Sin embargo, este algoritmo no es compatible con el s
treaming de forma nativa. En consecuencia, se gener
ará un conjunto de datos temporal, lo que puede caus
ar un tiempo de procesamiento significativo al abrir.
