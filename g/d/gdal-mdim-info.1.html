NOMBRE

gdal-mdim-info - Obtener información sobre un conjunto de datos multidimensional

Añadido en la versión 3.11.

SINOPSIS

Uso: gdal mdim info [OPCIONES] <ENTRADA>
Devolver información sobre un conjunto de datos multidimensional.
Argumentos posicionales:
  -i, --dataset, --input <ENTRADA>       Conjunto de datos ráster multidimensional de entrada [requerido]
Opciones comunes:
  -h, --help                           Mostrar mensaje de ayuda y salir
  --json-usage                         Mostrar uso como documento JSON y salir
  --config <CLAVE>=<VALOR>               Opción de configuración [puede repetirse]
Opciones:
  --detailed                           Salida más verbosa. Informar tipos de datos de atributos y valores de matrices.
  --array <MATRIZ>                     Nombre de la matriz, se usa para restringir la salida a la matriz especificada.
  --limit <LIMITE>                     Número de valores en cada dimensión que se usa para limitar la visualización de valores de matriz.
  --array-option <CLAVE>=<VALOR>       Opción pasada a GDALGroup::GetMDArrayNames() para filtrar las matrices reportadas. [puede repetirse]
  --stats                              Leer y mostrar estadísticas de imagen.
Opciones avanzadas:
  --oo, --open-option <CLAVE>=<VALOR>    Opciones de apertura [puede repetirse]
  --if, --input-format <FORMATO-ENTRADA>  Formatos de entrada [puede repetirse]

DESCRIPCIÓN

gdal mdim info lista información variada sobre un conjunto de datos multidimensional compatible con GDAL.

Los siguientes elementos se informarán (cuando se conozcan) como JSON:

  • El controlador de formato utilizado para acceder al archivo.
  • Jerarquía de grupos
  • Atributos de grupo
Arrays:
  • Nombre
  • Nombre de la dimensión, tamaños, variable de indexación
  • Tipo de datos
  • Atributos
  • SRS
  • Valor Nodata
  • Unidades
  • Estadísticas (si se solicitan)

Las siguientes opciones están disponibles:

Opciones estándar

--detailed
Salida más verbosa. Informar tipos de datos de atributos y valores de matrices.
--array <nombre_matriz>
Nombre de la matriz utilizado para restringir la salida a la matriz especificada.

NOTA:

La compleción de Bash para --array es posible si el nombre del conjunto de datos se especifica antes.
--limit <número>
Número de valores en cada dimensión que se usa para limitar la visualización de valores de matriz. Por defecto, sin límite. Solo se tiene en cuenta si se usa con -detailed.
--array-option <NOMBRE>=<VALOR>
Opción pasada a GDALGroup::GetMDArrayNames() para filtrar las matrices reportadas. Dicha opción es específica del formato. Consulte la documentación del controlador. Esta opción puede usarse varias veces.

NOTA:

La compleción de Bash para --array-option es posible si el nombre del conjunto de datos se especifica antes.
--stats
Leer y mostrar estadísticas de la matriz. Fuerza el cálculo si no hay estadísticas almacenadas en una matriz.

Opciones avanzadas

--oo <NOMBRE>=<VALOR>
Opción de apertura del conjunto de datos (específica del formato).

Puede repetirse.

--if <formato>
Nombre del formato/controlador que se intentará para abrir los archivos de entrada. Generalmente no es necesario especificarlo, pero se puede usar para omitir la detección automática del controlador, cuando falla al seleccionar el controlador apropiado. Esta opción puede repetirse varias veces para especificar varios controladores candidatos. Tenga en cuenta que no fuerza a esos controladores a abrir el conjunto de datos. En particular, algunos controladores tienen requisitos sobre las extensiones de archivo.

Puede repetirse.
