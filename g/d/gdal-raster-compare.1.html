NOMBRE

gdal-raster-compare - Compara dos conjuntos de datos ráster

Añadido en la versión 3.12.

SINOPSIS

Uso: gdal raster compare [OPCIONES] <REFERENCIA> <ENTRADA>
Compara dos conjuntos de datos ráster.
Argumentos posicionales:
  --reference <REFERENCIA>              Conjunto de datos de referencia [requerido]
  -i, --input <ENTRADA>                 Conjunto de datos ráster de entrada [requerido]
Opciones comunes:
  -h, --help                           Muestra el mensaje de ayuda y sale
  --json-usage                         Muestra el uso como documento JSON y sale
  --config <CLAVE>=<VALOR>             Opción de configuración [puede repetirse]
  -q, --quiet                          Modo silencioso (sin barra de progreso)
Opciones:
  --skip-all-optional                  Omite todas las comparaciones opcionales
  --skip-binary                        Omite la comparación de archivos binarios
  --skip-crs                           Omite la comparación de CRS
  --skip-geotransform                  Omite la comparación de la transformación geográfica
  --skip-overview                      Omite la comparación de vistas generales
  --skip-metadata                      Omite la comparación de metadatos
  --skip-rpc                           Omite la comparación de metadatos RPC
  --skip-geolocation                   Omite la comparación de metadatos de geolocalización
  --skip-subdataset                    Omite la comparación de subconjuntos de datos
Opciones avanzadas:
  --if, --input-format <FORMATO-ENTRADA>  Formatos de entrada [puede repetirse]
  --oo, --open-option <CLAVE>=<VALOR>    Opciones de apertura [puede repetirse]

DESCRIPCIÓN

gdal raster compare compara dos conjuntos de datos compatibles con GDAL e informa de las diferencias. Además de informar de las diferencias en la salida estándar, el programa también devolverá el recuento de diferencias en su valor de salida.

Por convención, el primer conjunto de datos especificado como argumento posicional, o a través de --reference, se asume que es el conjunto de datos de referencia/exacto/golden. El segundo conjunto de datos especificado como argumento posicional, o a través de --input, es el conjunto de datos comparado con el conjunto de datos de referencia.

Se comprueban los píxeles de la imagen y varios metadatos. También se realiza una comparación byte a byte que se contará como una diferencia. Por lo tanto, si solo es importante que los datos visibles por GDAL sean idénticos, un recuento de diferencias de 1 (la diferencia binaria) debería considerarse aceptable, o puede especificar --skip-binary para omitir la comparación byte a byte.

Este programa también puede usarse como el último paso de un pipeline ráster.

Las siguientes opciones están disponibles:

Opciones

--reference <conjunto-de-datos-de-referencia>
El conjunto de datos que se considera correcto, denominado conjunto de datos de referencia.
--input <conjunto-de-datos-de-entrada>
El conjunto de datos que se compara con el conjunto de datos de referencia, denominado conjunto de datos de entrada.
--skip-all-optional
Si se deben omitir todas las pruebas opcionales. Este es un alias para definir todas las demás --skip-XXXX opciones.

Las pruebas no opcionales restantes son:

  • comprobar el ancho, la altura y el número de bandas del conjunto de datos
  • comprobar la descripción de la banda, el tipo de datos, la interpretación del color y el valor de datos nulos
  • comprobar el contenido de los píxeles
--skip-binary
Si se debe omitir la comparación exacta del contenido binario.
--skip-overview
Si se debe omitir la comparación de las vistas generales.
--skip-geolocation
Si se debe omitir la comparación del dominio de metadatos GEOLOCATION.
--skip-geotransform
Si se debe omitir la comparación de la matriz de transformación geográfica.
--skip-metadata
Si se debe omitir la comparación de metadatos
--skip-rpc
Si se debe omitir la comparación del dominio de metadatos de Coeficientes de Polinomio Racional (RPC).
--skip-crs
Si se debe omitir la comparación de los sistemas de referencia de coordenadas (CRS).
--skip-sds
Si se deben ignorar la comparación de todos los subconjuntos de datos que forman parte del conjunto de datos.

EJEMPLOS

Ejemplo 1: Comparación de dos conjuntos de datos que difieren en sus tipos de datos

$ gdal raster compare autotest/gcore/data/byte.tif autotest/gcore/data/uint16.tif
El archivo de referencia tiene un tamaño de 736 bytes, mientras que el archivo de entrada tiene un tamaño de 1136 bytes.
La banda 1 de referencia tiene el tipo de datos Byte, pero la banda de entrada tiene el tipo de datos UInt16
$ echo $?
2

Ejemplo 2: Comparación de dos conjuntos de datos mientras los valores tienen unidades diferentes

$ gdal raster pipeline read test_in_foot.tif ! calc --calc "X * 0.3048" ! compare --reference=reference_in_meter.tif
