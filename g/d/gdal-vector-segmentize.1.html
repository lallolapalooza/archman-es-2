NOMBRE

gdal-vector-segmentize - Segmentar geometrías de un conjunto de datos vectoriales

Añadido en la versión 3.12.

SINOPSIS

Uso: gdal vector segmentize [OPCIONES] <ENTRADA> <SALIDA> <LONGITUD-MAXIMA>
Segmentar geometrías de un conjunto de datos vectoriales.
Argumentos posicionales:
  -i, --input <ENTRADA>                                Conjuntos de datos vectoriales de entrada [requerido]
  -o, --output <SALIDA>                                Conjunto de datos vectoriales de salida [requerido]
  --max-length <LONGITUD-MAXIMA>                       Longitud máxima de un segmento [requerido]
Opciones comunes:
  -h, --help                                           Mostrar mensaje de ayuda y salir
  --json-usage                                         Mostrar uso como documento JSON y salir
  --config <CLAVE>=<VALOR>                             Opción de configuración [puede repetirse]
  -q, --quiet                                          Modo silencioso (sin barra de progreso)
Opciones:
  -l, --layer, --input-layer <CAPA-ENTRADA>             Nombre(s) de la capa de entrada [puede repetirse]
  -f, --of, --format, --output-format <FORMATO-SALIDA> Formato de salida ("GDALG" permitido)
  --co, --creation-option <CLAVE>=<VALOR>             Opción de creación [puede repetirse]
  --lco, --layer-creation-option <CLAVE>=<VALOR>      Opción de creación de capa [puede repetirse]
  --overwrite                                          Si se permite sobrescribir la salida existente
  --update                                             Si se permite abrir el conjunto de datos existente en modo de actualización
  --overwrite-layer                                    Si se permite sobrescribir la capa de salida existente
  --append                                             Si se permite añadir a la capa existente
                                                       Mutuamente excluyente con --upsert
  --output-layer <CAPA-SALIDA>                         Nombre de la capa de salida
  --skip-errors                                        Omitir errores al escribir características
  --active-layer <CAPA-ACTIVA>                         Establecer capa activa (si no se especifica, todas)
  --active-geometry <GEOMETRIA-ACTIVA>                 Nombre del campo de geometría al que restringir el procesamiento (si no se especifica, todos)
Opciones avanzadas:
  --if, --input-format <FORMATO-ENTRADA>               Formatos de entrada [puede repetirse]
  --oo, --open-option <CLAVE>=<VALOR>                 Opciones de apertura [puede repetirse]
  --output-oo, --output-open-option <CLAVE>=<VALOR>   Opciones de apertura de salida [puede repetirse]
  --upsert                                             Actualizar/insertar características (implica 'append')
                                                       Mutuamente excluyente con --append

DESCRIPCIÓN

gdal vector segmentize asegura que los segmentos de LineStrings o los anillos de Polygons no sean más largos que la longitud máxima especificada, insertando puntos intermedios.

Ejecuta la operación OGRGeometry::segmentize().

También puede usarse como un paso de gdal vector pipeline.

Opciones estándar

-f, --of, --format, --output-format <FORMATO-SALIDA>
Qué formato vectorial de salida usar. Los valores permitidos pueden ser obtenidos con gdal --formats | grep vector | grep rw | sort
--co <NOMBRE>=<VALOR>
Muchos formatos tienen una o más opciones de creación de conjunto de datos opcionales que pueden usarse para controlar detalles específicos del archivo creado. Por ejemplo, el controlador GeoPackage soporta opciones de creación para controlar la versión.

Puede repetirse.

Las opciones de creación de conjunto de datos disponibles varían según el controlador del formato, y algunos formatos simples no tienen opciones de creación. Una lista de opciones soportadas para un formato puede ser listada con la opción de línea de comandos --formats, pero la documentación del formato es la fuente definitiva de información sobre las opciones de creación del controlador. Consulte la documentación específica del formato de Controladores vectoriales para ver las opciones de creación permitidas para cada formato.

Tenga en cuenta que las opciones de creación de conjunto de datos son diferentes de las opciones de creación de capa.

-lco <NOMBRE>=<VALOR>
Opción de creación de capa (específica del formato)
--overwrite
Permite al programa sobrescribir el archivo o conjunto de datos de destino existente. De lo contrario, por defecto, gdal genera un error si el archivo o conjunto de datos de destino ya existe.
--active-layer <CAPA-ACTIVA>
Establece la capa activa. Cuando se especifica, solo la capa especificada por su nombre será objeto del procesamiento. Otras capas no se modificarán. Si esta opción no se especifica, todas las capas serán objeto del procesamiento.
--active-geometry <GEOMETRIA-ACTIVA>
Establece el campo de geometría activo por su nombre. Cuando se especifica, solo el campo de geometría especificado será objeto del procesamiento. Otros campos de geometría no se modificarán. Si esta opción no se especifica, todos los campos de geometría serán objeto del procesamiento. Esta opción se puede combinar con --active-layer.
--max-length <LONGITUD-MAXIMA>
El valor especificado de esta opción es la distancia máxima entre dos puntos consecutivos de la geometría de salida antes de que se añadan puntos intermedios. La unidad de la distancia son las unidades georreferenciadas de la capa de origen.

Opciones avanzadas

--oo <NOMBRE>=<VALOR>
Opción de apertura de conjunto de datos (específica del formato).

Puede repetirse.

--if <formato>
Nombre del formato/controlador que se intentará para abrir el(los) archivo(s) de entrada. Generalmente no es necesario especificarlo, pero puede usarse para omitir la detección automática del controlador, cuando esta falla al seleccionar el controlador apropiado. Esta opción puede repetirse varias veces para especificar varios controladores candidatos. Tenga en cuenta que no fuerza a esos controladores a abrir el conjunto de datos. En particular, algunos controladores tienen requisitos sobre extensiones de archivo.

Puede repetirse.

SALIDA GDALG (SOBRE LA MARCHA / EN STREAMING)

Este programa soporta la serialización de la línea de comandos como un archivo JSON usando el formato de salida GDALG. El archivo resultante puede entonces ser abierto como un conjunto de datos vectoriales usando el controlador GDALG: GDAL Streamed Algorithm, y aplicar el pipeline especificado de forma sobre la marcha / en streaming.

EJEMPLOS

Ejemplo 1: Asegurarse de que los segmentos de las geometrías no sean más largos de un km (asumiendo que la CRS está en metros)

$ gdal vector segmentize --max-length=1000 in.gpkg out.gpkg --overwrite

NAME

gdal-vector-segmentize - Segmentize linestrings in vector files

SYNOPSIS

gdal-vector-segmentize [-skipFACTOR] [-STRUCTION_KEY] [-STRUCTION_VALUE] [-STRUCTION_SUBKEY] [-INSTRUCTION_SUBVALUE] [-STRUCTION_MAXSPEED] [-INSTRUCTION_MAXSPEED] [-INSTRUCTION_AVGSPEED] [-INSTRUCTION_AVERAGE_SPEED] [-Z] [-M] [-progress] [-of <format>] [-tiled] [-co <NAME=VALUE>]... [-q] <input_dataset> <output_dataset>

DESCRIPTION

The gdal-vector-segmentize utility takes a vector dataset with linestrings, and outputs a new dataset where linestrings have been segmented into smaller segments of a specified length or at specified intervals.

This utility is part of the GDAL utilities.

GDALG OUTPUT (ON-THE-FLY / STREAMED DATASET)

The output dataset can be of a format that supports on-the-fly processing or streamed data. This is particularly useful when dealing with large datasets or when you don't need to store the entire output dataset on disk.

EXAMPLES

Segmentize a GeoJSON file into segments of 100 meters:

gdal-vector-segmentize input.geojson output.geojson -STRUCTION_KEY "SEGMENT_LENGTH" -STRUCTION_VALUE "100"

Segmentize a Shapefile into segments of 1 kilometer, preserving Z and M values:

gdal-vector-segmentize input.shp output.shp -STRUCTION_KEY "SEGMENT_LENGTH" -STRUCTION_VALUE "1000" -Z -M
