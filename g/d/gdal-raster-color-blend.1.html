NOMBRE

gdal-raster-color-blend - Usa un raster en escala de grises para reemplazar la intensidad de un conjunto de datos RGB/RGBA

Añadido en la versión 3.12.

SINOPSIS

Uso: gdal raster blend [OPCIONES] <COLOR-ENTRADA> <SOBREPOSICION> <SALIDA>
Mezcla/compone dos conjuntos de datos ráster
Argumentos posicionales:
  -i, --color-input, --input <COLOR-ENTRADA>             Conjunto de datos ráster de entrada [requerido]
  --overlay <SOBREPOSICION>                                Conjunto de datos de superposición [requerido]
  -o, --output <SALIDA>                                Conjunto de datos ráster de salida [requerido]
Opciones comunes:
  -h, --help                                           Muestra el mensaje de ayuda y sale
  --json-usage                                         Muestra el uso como un documento JSON y sale
  --config <CLAVE>=<VALOR>                               Opción de configuración [puede repetirse]
  -q, --quiet                                          Modo silencioso (sin barra de progreso)
Opciones:
  -f, --of, --format, --output-format <FORMATO-SALIDA>  Formato de salida ("GDALG" permitido)
  --co, --creation-option <CLAVE>=<VALOR>                Opción de creación [puede repetirse]
  --overwrite                                          Permite sobrescribir la salida existente
                                                       Mutuamente excluyente con --append
  --append                                             Añadir como subconjunto de datos a la salida existente
                                                       Mutuamente excluyente con --overwrite
  --operator <OPERADOR>                                Operador de composición. OPERATOR=src-over|hsv-value (predeterminado: src-over)
  --opacity <OPACIDAD>                                 Porcentaje de opacidad a aplicar al conjunto de datos de superposición (0=completamente transparente, 100=uso completo de la opacidad de la superposición) (predeterminado: 100)
Opciones avanzadas:
  --if, --input-format <FORMATO-ENTRADA>                  Formatos de entrada [puede repetirse]
  --oo, --open-option <CLAVE>=<VALOR>                    Opciones de apertura [puede repetirse]

DESCRIPCIÓN

gdal raster blend permite al usuario componer dos conjuntos de datos ráster (del mismo tamaño) utilizando una operación de mezcla seleccionada y un ajuste de opacidad.

Esto puede usarse, por ejemplo, para colorear un ráster de sombras de colina generado por gdal raster hillshade con una representación hipsométrica de un DEM generada por gdal raster color-map al usar el operador de mezcla hsv-value.

El operador de mezcla más estándar src-over, que realiza el "alpha blending" (mezcla alfa), también está disponible.

Este subcomando también está disponible como un paso potencial de gdal raster pipeline

Opciones estándar

-f, --of, --format, --output-format <FORMATO-SALIDA>
Qué formato de ráster de salida usar. Los valores permitidos pueden ser dados por gdal --formats | grep raster | grep rw | sort
--co <NOMBRE>=<VALOR>
Muchos formatos tienen una o más opciones de creación opcionales que se pueden usar para controlar detalles específicos del archivo creado. Por ejemplo, el controlador GeoTIFF admite opciones de creación para controlar la compresión y si el archivo debe dividirse en mosaicos.

Puede repetirse.

Las opciones de creación disponibles varían según el controlador de formato y algunos formatos simples no tienen opciones de creación en absoluto. Una lista de opciones admitidas para un formato se puede enumerar con la opción de línea de comandos --formats, pero la documentación del formato es la fuente definitiva de información sobre las opciones de creación del controlador. Consulte la documentación específica del formato de controladores ráster para conocer las opciones de creación legales para cada formato.

--overwrite
Permite que el programa sobrescriba el archivo o conjunto de datos de destino existente. De lo contrario, por defecto, gdal genera un error si el archivo o conjunto de datos de destino ya existe.
--input <ENTRADA>
Nombre del conjunto de datos en el que mezclar el conjunto de datos de superposición. Requerido.

Al usar el operador de mezcla hsv-value, este debe ser un ráster Byte de tres o cuatro bandas.

--overlay <ESCALA_GRISES>
Nombre del conjunto de datos de superposición. Requerido
--operator src-over|hsv-value
Selecciona el operador de mezcla, que define cómo se mezcla el conjunto de datos de superposición en el conjunto de datos de entrada. Predeterminado: src-over.
  • src-over realiza una mezcla alfa estándar, componiendo el conjunto de datos de superposición sobre el conjunto de datos de entrada.

    Dado overlay_{C} el valor de uno de los componentes rojo, verde o azul del conjunto de datos de superposición, overlay_{A} el valor del componente alfa del conjunto de datos de superposición, input_{C} el valor del componente correspondiente de los datos de entrada, input_{A} el valor del componente alfa de los datos de entrada y opacity, la opacidad, el componente resultante output_{C} es (todos los valores normalizados al rango [0,1]):


    output_{C} * output_{A} = (overlay_{C} * overlay_{A} * opacity) + (input_{C} * input_{A} * (1 - overlay_{A} * opacity))

    con


    output_{A} = (overlay_{A} * opacity) + (input_{A} * (1 - overlay_{A} * opacity))

  • hsv-value crea un color con el valor de la superposición y el tono y la saturación de la entrada. Realiza los siguientes pasos:
  • lee los componentes RGB (Rojo, Verde, Azul) del conjunto de datos de entrada
  • transforma los componentes RGB al espacio de color HSV (Tono, Saturación, Valor)
  • calcula el valor de salida output_{V}, a partir de input_{V} el valor de entrada calculado en el paso anterior, overlay_{V} el valor de la superposición, overlay_{A} el valor del componente alfa del conjunto de datos de superposición y opacity, la opacidad (todos los valores normalizados al rango [0,1]):


    output_{V} = (overlay_{V} * overlay_{A} * opacity) + (input_{V} * (1 - overlay_{A} * opacity))

    Si el conjunto de datos de superposición es un conjunto de datos RGB/RGBA, overlay_{V} es max(overlay_{R},overlay_{G},overlay_{B}).

  • transforma de nuevo (Tono, Saturación, :math:output_{V}) a RGB.

Si el canal alfa del conjunto de datos de entrada está presente, se conserva sin cambios.

--opacity <OPACIDAD>
Opacidad a utilizar al mezclar el conjunto de datos de superposición, como un porcentaje entre 0 y 100. 0 significa que el conjunto de datos de superposición se considera completamente transparente. 100 significa que el conjunto de datos de superposición se mezcla con el máximo de su canal alfa. Predeterminado: 100.

SALIDA GDALG (CONJUNTO DE DATOS SOBRE LA MARCHA / EN SECEUNCIA)

Este programa soporta la serialización de la línea de comandos como un archivo JSON utilizando el formato de salida GDALG. El archivo resultante puede ser abierto como un conjunto de datos ráster usando el controlador GDALG: GDAL Streamed Algorithm y aplicar el pipeline especificado de forma sobre la marcha / en secuencia.

EJEMPLOS

Ejemplo 1: Mezcla alfa de dos conjuntos de datos usando un 75% de opacidad para el conjunto de datos de superposición.

$ gdal raster blend --opacity 75 source.tif overlay.tif out.tif

Ejemplo 2: Combinar un mapa de sombras y una representación hipsométrica de un DEM en un mapa de sombras con color.

$ gdal raster blend -i hillshade.tif --overlay hypsometric_color.tif --operator hsv-value colorized_hillshade.tif
