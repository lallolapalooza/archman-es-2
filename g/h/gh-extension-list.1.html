GH-EXTENSION-LIST(1) Manual de la CLI de GitHub GH-EXTENSION-LIST(1)

NOMBRE

gh-extension-list - Listar comandos de extensión instalados

SINOPSIS

gh extension list [flags]

ALIAS

gh ext ls, gh extension ls, gh extensions ls

CÓDIGOS DE SALIDA

0: Ejecución exitosa

1: Error

2: Comando cancelado

4: Autenticación requerida

NOTA: Comandos específicos pueden tener códigos de salida adicionales. Consulte la ayuda del comando para más información.
