NOMBRE

gh-label-create - Crear una nueva etiqueta

SINOPSIS

gh label create <nombre> [flags]

DESCRIPCIÓN

Crea una nueva etiqueta en GitHub, o actualiza una existente con --force.

Se debe especificar el nombre de la etiqueta. La descripción y el color son opcionales. Si no se proporciona un color, se elegirá uno aleatorio.

El color de la etiqueta debe ser un valor hexadecimal de 6 caracteres.

OPCIONES

-c, --color <cadena>
Color de la etiqueta
-d, --description <cadena>
Descripción de la etiqueta
-f, --force
Actualiza el color y la descripción de la etiqueta si ya existe

OPCIONES HEREDADAS DE COMANDOS PADRE

-R, --repo <[HOST/]PROPIETARIO/REPO>
Selecciona otro repositorio usando el formato [HOST/]PROPIETARIO/REPO

CÓDIGOS DE SALIDA

0: Ejecución exitosa

1: Error

2: Comando cancelado

4: Autenticación requerida

NOTA: Los comandos específicos pueden tener códigos de salida adicionales. Consulta la ayuda del comando para obtener más información.

EJEMPLO

# Crea una nueva etiqueta de error
$ gh label create bug --description "Algo no funciona" --color E99695
