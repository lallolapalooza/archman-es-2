NOMBRE

gh-auth-refresh - Actualizar credenciales de autenticación almacenadas

SINOPSIS

gh auth refresh [flags]

DESCRIPCIÓN

Expandir o corregir los ámbitos de permisos para las credenciales almacenadas para la cuenta activa.

La bandera --scopes acepta una lista de ámbitos separada por comas que desea que tengan sus credenciales de gh. Si no se proporcionan ámbitos, el comando mantiene los ámbitos añadidos previamente.

La bandera --remove-scopes acepta una lista de ámbitos separada por comas que desea eliminar de sus credenciales de gh. La eliminación de ámbitos es idempotente. El conjunto mínimo de ámbitos (repo, read:org y gist) no se puede eliminar.

La bandera --reset-scopes restablece los ámbitos de sus credenciales de gh al conjunto predeterminado de ámbitos para su flujo de autenticación.

Si tiene varias cuentas en gh auth status y desea actualizar las credenciales de una cuenta inactiva, deberá usar gh auth switch a esa cuenta primero antes de usar este comando, y luego volver a cambiar cuando haya terminado.

Para más información sobre los ámbitos de OAuth, consulte

⟨https://docs.github.com/en/developers/apps/building-oauth-apps/scopes-for-oauth-apps/⟩.

OPCIONES

-c, --clipboard
Copiar código de dispositivo OAuth de un solo uso al portapapeles
-h, --hostname <string>
El host de GitHub a utilizar para la autenticación
--insecure-storage
Guardar las credenciales de autenticación en texto plano en lugar del gestor de credenciales
-r, --remove-scopes <strings>
Ámbitos de autenticación a eliminar de gh
--reset-scopes
Restablecer los ámbitos de autenticación al conjunto mínimo predeterminado de ámbitos
-s, --scopes <strings>
Ámbitos de autenticación adicionales para que gh los tenga

CÓDIGOS DE SALIDA

0: Ejecución exitosa

1: Error

2: Comando cancelado

4: Autenticación requerida

NOTA: Los comandos específicos pueden tener códigos de salida adicionales. Consulte la ayuda del comando para obtener más información.

EJEMPLO

# Abrir un navegador para añadir los ámbitos write:org y read:public_key
$ gh auth refresh --scopes write:org,read:public_key
# Abrir un navegador para asegurar que sus credenciales de autenticación tengan los ámbitos mínimos correctos
$ gh auth refresh
# Abrir un navegador para eliminar de forma idempotente el ámbito delete_repo
$ gh auth refresh --remove-scopes delete_repo
# Abrir un navegador para reautenticarse con los ámbitos mínimos predeterminados
$ gh auth refresh --reset-scopes
# Abrir un navegador para reautenticarse y copiar el código OAuth de un solo uso al portapapeles
$ gh auth refresh --clipboard
