GH-BROWSE(1) Manual de la CLI de GitHub GH-BROWSE(1)

NOMBRE

gh-browse - Abrir repositorios, incidencias, solicitudes de extracción y más en el navegador

SINOPSIS

gh browse [<número> | <ruta> | <commit-sha>] [flags]

DESCRIPCIÓN

Transición de la terminal al navegador web para ver e interactuar con:

  • Incidencias
  • Solicitudes de extracción
  • Contenido del repositorio
  • Página principal del repositorio
  • Configuración del repositorio

OPCIONES

-b, --branch <cadena>
Seleccionar otra rama pasando el nombre de la rama
-c, --commit <cadena>
Seleccionar otro commit pasando el SHA del commit, por defecto es el último commit
-n, --no-browser
Imprimir la URL de destino en lugar de abrir el navegador
-p, --projects
Abrir proyectos del repositorio
-r, --releases
Abrir lanzamientos del repositorio
-R, --repo <[HOST/]OWNER/REPO>
Seleccionar otro repositorio usando el formato [HOST/]OWNER/REPO
-s, --settings
Abrir configuración del repositorio
-w, --wiki
Abrir wiki del repositorio

CÓDIGOS DE SALIDA

0: Ejecución exitosa

1: Error

2: Comando cancelado

4: Autenticación requerida

NOTA: Los comandos específicos pueden tener códigos de salida adicionales. Consulte la ayuda del comando para obtener más información.

EJEMPLO

# Abrir la página principal del repositorio actual
$ gh browse
# Abrir el directorio de scripts del repositorio actual
$ gh browse script/
# Abrir la incidencia o solicitud de extracción 217
$ gh browse 217
# Abrir la página del commit
$ gh browse 77507cd94ccafcf568f8560cfecde965fcfa63
# Abrir la configuración del repositorio
$ gh browse --settings
# Abrir main.go en la línea 312
$ gh browse main.go:312
# Abrir main.go con el repositorio en la cabeza de la rama bug-fix
$ gh browse main.go --branch bug-fix
# Abrir main.go con el repositorio en el commit 775007cd
$ gh browse main.go --commit=77507cd94ccafcf568f8560cfecde965fcfa63
