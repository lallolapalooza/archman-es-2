NOMBRE

gh-codespace-view - Ver detalles sobre un codespace

SINOPSIS

gh codespace view [flags]

OPCIONES

-c, --codespace <cadena>
Nombre del codespace
-q, --jq <expresion>
Filtrar la salida JSON usando una expresión jq
--json <campos>
Generar salida JSON con los campos especificados
-R, --repo <cadena>
Filtrar la selección de codespace por nombre de repositorio (usuario/repo)
--repo-owner <cadena>
Filtrar la selección de codespace por propietario del repositorio (nombre de usuario u organización)
-t, --template <cadena>
Formatear la salida JSON usando una plantilla Go; ver "gh help formatting"

CAMPOS JSON

billableOwner, createdAt, devcontainerPath, displayName, environmentId, gitStatus, idleTimeoutMinutes, lastUsedAt, location, machineDisplayName, machineName, name, owner, prebuild, recentFolders, repository, retentionExpiresAt, retentionPeriodDays, state, vscsTarget

CÓDIGOS DE SALIDA

0: Ejecución exitosa

1: Error

2: Comando cancelado

4: Autenticación requerida

NOTA: Los comandos específicos pueden tener códigos de salida adicionales. Consulte la ayuda del comando para obtener más información.

EJEMPLO

# Seleccionar un codespace de una lista de todos los codespaces que posees
$ gh cs view
# Ver los detalles de un codespace específico
$ gh cs view -c nombre-del-codespace-12345
# Ver la lista de todos los campos disponibles para un codespace
$ gh cs view --json
# Ver campos específicos para un codespace
$ gh cs view --json displayName,machineDisplayName,state
