NOMBRE

gh-search-repos - Buscar repositorios

SINOPSIS

gh search repos [<consulta>] [flags]

DESCRIPCIÓN

Buscar repositorios en GitHub.

El comando permite construir consultas utilizando la sintaxis de búsqueda de GitHub, usando los flags de parámetro y calificador, o una combinación de ambos.

La sintaxis de búsqueda de GitHub está documentada en:

⟨https://docs.github.com/search-github/searching-on-github/searching-for-repositories⟩

Para más información sobre cómo manejar consultas de búsqueda que contienen un guion, ejecute gh search --help.

OPCIONES

--archived
Filtrar según el estado de archivado del repositorio {true|false}
--created <fecha>
Filtrar según la fecha de creación
--followers <número>
Filtrar según el número de seguidores
--forks <número>
Filtrar según el número de forks
--good-first-issues <número>
Filtrar según el número de issues con la etiqueta 'good first issue'
--help-wanted-issues <número>
Filtrar según el número de issues con la etiqueta 'help wanted'
--include-forks <cadena>
Incluir forks en los repositorios obtenidos: {false|true|only}
-q, --jq <expresión>
Filtrar la salida JSON usando una expresión jq
--json <campos>
Salida JSON con los campos especificados
--language <cadena>
Filtrar según el lenguaje de programación
--license <cadenas>
Filtrar según el tipo de licencia
-L, --limit <int> (por defecto 30)
Número máximo de repositorios a obtener
--match <cadenas>
Restringir la búsqueda a un campo específico del repositorio: {name|description|readme}
--number-topics <número>
Filtrar según el número de temas
--order <cadena> (por defecto "desc")
Orden de los repositorios devueltos, ignorado a menos que se especifique el flag '--sort': {asc|desc}
--owner <cadenas>
Filtrar según el propietario
--size <cadena>
Filtrar según un rango de tamaño, en kilobytes
--sort <cadena> (por defecto "best-match")
Ordenar los repositorios obtenidos: {forks|help-wanted-issues|stars|updated}
--stars <número>
Filtrar según el número de estrellas
-t, --template <cadena>
Formatear la salida JSON usando una plantilla de Go; ver "gh help formatting"
--topic <cadenas>
Filtrar según el tema
--updated <fecha>
Filtrar según la fecha de última actualización
--visibility <cadenas>
Filtrar según la visibilidad: {public|private|internal}
-w, --web
Abrir la consulta de búsqueda en el navegador web

CAMPOS JSON

createdAt, defaultBranch, description, forksCount, fullName, hasDownloads, hasIssues, hasPages, hasProjects, hasWiki, homepage, id, isArchived, isDisabled, isFork, isPrivate, language, license, name, openIssuesCount, owner, pushedAt, size, stargazersCount, updatedAt, url, visibility, watchersCount

CÓDIGOS DE SALIDA

0: Ejecución exitosa

1: Error

2: Comando cancelado

4: Autenticación requerida

NOTA: Los comandos específicos pueden tener códigos de salida adicionales. Consulte la ayuda del comando para más información.

EJEMPLO

# Buscar repositorios que coincidan con el conjunto de palabras clave "cli" y "shell"
$ gh search repos cli shell
# Buscar repositorios que coincidan con la frase "vim plugin"
$ gh search repos "vim plugin"
# Buscar repositorios públicos en la organización microsoft
$ gh search repos --owner=microsoft --visibility=public
# Buscar repositorios con un conjunto de temas
$ gh search repos --topic=unix,terminal
# Buscar repositorios por lenguaje de programación y número de good first issues
$ gh search repos --language=go --good-first-issues=">=10"
# Buscar repositorios sin el tema "linux"
$ gh search repos -- -topic:linux
# Buscar repositorios excluyendo los repositorios archivados
$ gh search repos --archived=false
