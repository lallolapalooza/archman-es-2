NOMBRE

gh-release-list - Listar releases en un repositorio

SINOPSIS

gh release list [flags]

OPCIONES

--exclude-drafts
Excluir releases borradores
--exclude-pre-releases
Excluir pre-releases
-q, --jq <expresión>
Filtrar la salida JSON usando una expresión jq
--json <campos>
Salida JSON con los campos especificados
-L, --limit <int> (por defecto 30)
Número máximo de elementos a obtener
-O, --order <cadena> (por defecto "desc")
Orden de las releases devueltas: {asc|desc}
-t, --template <cadena>
Formatear la salida JSON usando una plantilla Go; ver "gh help formatting"

OPCIONES HEREDADAS DE COMANDOS PADRE

-R, --repo <[HOST/]PROPIETARIO/REPO>
Seleccionar otro repositorio usando el formato [HOST/]PROPIETARIO/REPO

ALIAS

gh release ls

CAMPOS JSON

createdAt, isDraft, isImmutable, isLatest, isPrerelease, name, publishedAt, tagName

CÓDIGOS DE SALIDA

0: Ejecución exitosa

1: Error

2: Comando cancelado

4: Autenticación requerida

NOTA: Comandos específicos pueden tener códigos de salida adicionales. Consultar la ayuda del comando para más información.
