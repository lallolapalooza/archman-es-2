NOMBRE

gh-agent-task-view - Ver una sesión de tarea del agente (vista previa)

SINOPSIS

gh agent-task view [<session-id> | <pr-number> | <pr-url> | <pr-branch>] [flags]

DESCRIPCIÓN

Ver una sesión de tarea del agente.

OPCIONES

--follow
Seguir los registros de la sesión del agente
--log
Mostrar los registros de la sesión del agente
-R, --repo <[HOST/]OWNER/REPO>
Seleccionar otro repositorio usando el formato [HOST/]OWNER/REPO
-w, --web
Abrir la tarea del agente en el navegador

CÓDIGOS DE SALIDA

0: Ejecución exitosa

1: Error

2: Comando cancelado

4: Autenticación requerida

NOTA: Los comandos específicos pueden tener códigos de salida adicionales. Consulte la ayuda del comando para obtener más información.

EJEMPLO

# Ver una tarea del agente por ID de sesión
$ gh agent-task view e2fa49d2-f164-4a56-ab99-498090b8fcdf
# Ver una tarea del agente por número de pull request en el repositorio actual
$ gh agent-task view 12345
# Ver una tarea del agente por número de pull request
$ gh agent-task view --repo OWNER/REPO 12345
# Ver una tarea del agente por referencia de pull request
$ gh agent-task view OWNER/REPO#12345
# Ver las tareas de agentes de una pull request en el navegador
$ gh agent-task view 12345 --web
