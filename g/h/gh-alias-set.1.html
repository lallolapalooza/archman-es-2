GH-ALIAS-SET(1) Manual de GitHub CLI GH-ALIAS-SET(1)

NOMBRE

gh-alias-set - Crea un atajo para un comando gh

SINOPSIS

gh alias set <alias> <expansión> [flags]

DESCRIPCIÓN

Define una palabra que se expandirá a un comando gh completo cuando se invoque.

La expansión puede especificar argumentos y flags adicionales. Si la expansión incluye marcadores de posición posicionales como $1, los argumentos adicionales que sigan al alias se insertarán apropiadamente. De lo contrario, los argumentos adicionales se añadirán al comando expandido.

Usa - como argumento de expansión para leer la cadena de expansión de la entrada estándar. Esto es útil para evitar problemas de comillas al definir expansiones.

Si la expansión comienza con ! o si se proporcionó --shell, la expansión es una expresión de shell que se evaluará a través del intérprete sh cuando se invoque el alias. Esto permite encadenar múltiples comandos mediante tuberías y redirecciones.

OPCIONES

--clobber
Sobrescribe alias existentes del mismo nombre
-s, --shell
Declara un alias que se pasará a través de un intérprete de shell

CÓDIGOS DE SALIDA

0: Ejecución exitosa

1: Error

2: Comando cancelado

4: Autenticación requerida

NOTA: Los comandos específicos pueden tener códigos de salida adicionales. Consulte la ayuda del comando para obtener más información.

EJEMPLO

# Nota: El Símbolo del sistema en Windows requiere usar comillas dobles para los argumentos
$ gh alias set pv 'pr view'
$ gh pv -w 123  #=> gh pr view -w 123
$ gh alias set bugs 'issue list --label=bugs'
$ gh bugs
$ gh alias set homework 'issue list --assignee @me'
$ gh homework
$ gh alias set 'issue mine' 'issue list --mention @me'
$ gh issue mine
$ gh alias set epicsBy 'issue list --author="$1" --label="epic"'
$ gh epicsBy vilmibm  #=> gh issue list --author="vilmibm" --label="epic"
$ gh alias set --shell igrep 'gh issue list --label="$1" | grep "$2"'
$ gh igrep epic foo  #=> gh issue list --label="epic" | grep "foo"
