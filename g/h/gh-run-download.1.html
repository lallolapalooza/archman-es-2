NOMBRE

gh-run-download - Descargar artefactos generados por una ejecución de flujo de trabajo

SINOPSIS

gh run download [<id-ejecucion>] [flags]

DESCRIPCIÓN

Descarga los artefactos generados por una ejecución de flujo de trabajo de GitHub Actions.

El contenido de cada artefacto se extraerá en directorios separados basados en el nombre del artefacto. Si solo se especifica un artefacto, se extraerá en el directorio actual.

Por defecto, este comando descarga el último artefacto creado y cargado a través de GitHub Actions. Dado que los flujos de trabajo pueden eliminar o sobrescribir artefactos, se debe usar <id-ejecucion> para seleccionar un artefacto de una ejecución de flujo de trabajo específica.

OPCIONES

-D, --dir <cadena> (predeterminado ".")
El directorio donde descargar los artefactos
-n, --name <array-cadena>
Descargar artefactos que coincidan con cualquiera de los nombres dados
-p, --pattern <array-cadena>
Descargar artefactos que coincidan con un patrón glob

OPCIONES HEREDADAS DE COMANDOS PADRE

-R, --repo <[HOST/]PROPIETARIO/REPO>
Seleccionar otro repositorio usando el formato [HOST/]PROPIETARIO/REPO

CÓDIGOS DE SALIDA

0: Ejecución exitosa

1: Error

2: Comando cancelado

4: Autenticación requerida

NOTA: Los comandos específicos pueden tener códigos de salida adicionales. Consulte la ayuda del comando para obtener más información.

EJEMPLO

# Descargar todos los artefactos generados por una ejecución de flujo de trabajo
$ gh run download <id-ejecucion>
# Descargar un artefacto específico dentro de una ejecución
$ gh run download <id-ejecucion> -n <nombre>
# Descargar artefactos específicos en todas las ejecuciones de un repositorio
$ gh run download -n <nombre1> -n <nombre2>
# Seleccionar artefactos para descargar de forma interactiva
$ gh run download
