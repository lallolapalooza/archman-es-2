NOMBRE

gh-project-field-create - Crear un campo en un proyecto

SINOPSIS

gh project field-create [<número>] [flags]

OPCIONES

--data-type <cadena>
Tipo de datos del nuevo campo.: {TEXT|SINGLE_SELECT|DATE|NUMBER}
--format <cadena>
Formato de salida: {json}
-q, --jq <expresión>
Filtrar la salida JSON usando una expresión jq
--name <cadena>
Nombre del nuevo campo
--owner <cadena>
Inicio de sesión del propietario. Usar "@me" para el usuario actual.
--single-select-options <cadenas>
Opciones para el tipo de datos SINGLE_SELECT
-t, --template <cadena>
Formatear la salida JSON usando una plantilla Go; ver "gh help formatting"

CÓDIGOS DE SALIDA

0: Ejecución exitosa

1: Error

2: Comando cancelado

4: Autenticación requerida

NOTA: Los comandos específicos pueden tener códigos de salida adicionales. Consulte la ayuda del comando para más información.

EJEMPLO

# Crear un campo en el proyecto "1" del usuario actual
$ gh project field-create 1 --owner "@me" --name "nuevo campo" --data-type "text"
# Crear un campo con tres opciones para elegir para el propietario monalisa
$ gh project field-create 1 --owner monalisa --name "nuevo campo" --data-type "SINGLE_SELECT" --single-select-options "uno,dos,tres"
