NOMBRE

gh-ruleset-check - Ver las reglas que se aplicarían a una rama dada

SINOPSIS

gh ruleset check [<rama>] [flags]

DESCRIPCIÓN

Ver información sobre las reglas de GitHub que se aplican a una rama dada.

El nombre de rama proporcionado no necesita existir; se mostrarán las reglas que se aplicarían a una rama con ese nombre. Se devuelven todas las reglas independientemente de dónde estén configuradas.

Si no se proporciona ningún nombre de rama, se utilizará la rama actual.

La bandera --default se puede utilizar para ver las reglas que se aplican a la rama por defecto del repositorio.

OPCIONES

--default
Comprobar reglas en la rama por defecto
-w, --web
Abrir la página de reglas de la rama en un navegador web

OPCIONES HEREDADAS DE COMANDOS PADRE

-R, --repo <[HOST/]PROPIETARIO/REPO>
Seleccionar otro repositorio utilizando el formato [HOST/]PROPIETARIO/REPO

CÓDIGOS DE SALIDA

0: Ejecución exitosa

1: Error

2: Comando cancelado

4: Autenticación requerida

NOTA: Los comandos específicos pueden tener códigos de salida adicionales. Consulte la ayuda del comando para obtener más información.

EJEMPLO

# Ver todas las reglas que se aplican a la rama actual
$ gh ruleset check
# Ver todas las reglas que se aplican a una rama llamada "mi-rama" en un repositorio diferente
$ gh ruleset check mi-rama --repo propietario/repo
# Ver todas las reglas que se aplican a la rama por defecto en un repositorio diferente
$ gh ruleset check --default --repo propietario/repo
# Ver un conjunto de reglas configurado en un repositorio diferente o en cualquiera de sus
# padres
$ gh ruleset view 23 --repo propietario/repo
# Ver un conjunto de reglas a nivel de organización
$ gh ruleset view 23 --org mi-org
