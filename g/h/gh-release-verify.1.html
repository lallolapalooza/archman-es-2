NOMBRE

gh-release-verify - Verifica la atestación de una versión

SINOPSIS

gh release verify [<etiqueta>] [flags]

DESCRIPCIÓN

Verifica que una versión de GitHub vaya acompañada de una atestación válida criptográficamente firmada.

Una atestación es una declaración hecha por GitHub con respecto a una versión y sus activos.

Este comando comprueba que la versión especificada (o la última versión, si no se proporciona etiqueta) tenga una atestación válida. Recupera la atestación para la versión e imprime metadatos sobre todos los activos referenciados en la atestación, incluidos sus digests.

OPCIONES

--format <cadena>
Formato de salida: {json}
-q, --jq <expresión>
Filtra la salida JSON usando una expresión jq
-t, --template <cadena>
Formatea la salida JSON usando una plantilla Go; consulta "gh help formatting"

OPCIONES HEREDADAS DE COMANDOS PADRE

-R, --repo <[HOST/]OWNER/REPO>
Selecciona otro repositorio usando el formato [HOST/]OWNER/REPO

CÓDIGOS DE SALIDA

0: Ejecución exitosa

1: Error

2: Comando cancelado

4: Autenticación requerida

NOTA: Los comandos específicos pueden tener códigos de salida adicionales. Consulta la ayuda del comando para obtener más información.

EJEMPLO

# Verifica la última versión
gh release verify
# Verifica una versión específica por etiqueta
gh release verify v1.2.3
# Verifica una versión específica por etiqueta y muestra la atestación en formato JSON
gh release verify v1.2.3 --format json
