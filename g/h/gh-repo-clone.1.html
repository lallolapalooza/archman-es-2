GH-REPO-CLONE(1) Manual de la CLI de GitHub GH-REPO-CLONE(1)

NOMBRE

gh-repo-clone - Clonar un repositorio localmente

SINOPSIS

gh repo clone <repositorio> [<directorio>] [-- <flags-git>...]

DESCRIPCIÓN

Clona un repositorio de GitHub localmente. Pasa flags adicionales de git clone listándolos después de --.

Si se omite la parte PROPIETARIO/ del argumento de repositorio PROPIETARIO/REPO, se usará por defecto el nombre del usuario autenticado.

Cuando no se proporciona un esquema de protocolo en el argumento del repositorio, se elegirá el git_protocol de tu configuración, lo cual se puede verificar con gh config get git_protocol. Si se proporciona el esquema de protocolo, el repositorio se clonará usando el protocolo especificado.

Si el repositorio es una bifurcación (fork), su repositorio padre se añadirá como un remoto git adicional llamado upstream. El nombre del remoto se puede configurar usando --upstream-remote-name. La opción --upstream-remote-name admite un valor @owner que nombrará el remoto con el nombre del propietario del repositorio padre.

Si el repositorio es una bifurcación, su repositorio padre se configurará como el repositorio remoto por defecto.

OPCIONES

-u, --upstream-remote-name <cadena> (por defecto "upstream")
Nombre del remoto ascendente al clonar una bifurcación

CÓDIGOS DE SALIDA

0: Ejecución exitosa

1: Error

2: Comando cancelado

4: Autenticación requerida

NOTA: Comandos específicos pueden tener códigos de salida adicionales. Consulta la ayuda del comando para más información.

EJEMPLO

# Clonar un repositorio de una organización específica
$ gh repo clone cli/cli
# Clonar un repositorio de tu propia cuenta
$ gh repo clone mi-repo
# Clonar un repo, sobrescribiendo la configuración del protocolo git
$ gh repo clone https://github.com/cli/cli
$ gh repo clone git@github.com:cli/cli.git
# Clonar un repositorio a un directorio personalizado
$ gh repo clone cli/cli workspace/cli
# Clonar un repositorio con flags adicionales de git clone
$ gh repo clone cli/cli -- --depth=1
