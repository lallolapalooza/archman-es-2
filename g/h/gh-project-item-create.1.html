NOMBRE

gh-project-item-create - Crear un elemento de borrador de incidencia en un proyecto

SINOPSIS

gh project item-create [<número>] [flags]

OPCIONES

--body <cadena>
Cuerpo para el borrador de la incidencia
--format <cadena>
Formato de salida: {json}
-q, --jq <expresión>
Filtrar la salida JSON usando una expresión jq
--owner <cadena>
Inicio de sesión del propietario. Usar "@me" para el usuario actual.
-t, --template <cadena>
Formatear la salida JSON usando una plantilla Go; ver "gh help formatting"
--title <cadena>
Título para el borrador de la incidencia

CÓDIGOS DE SALIDA

0: Ejecución exitosa

1: Error

2: Comando cancelado

4: Autenticación requerida

NOTA: Comandos específicos pueden tener códigos de salida adicionales. Consulte la ayuda del comando para más información.

EJEMPLO

# Crear un borrador de incidencia en el proyecto "1" del usuario actual
$ gh project item-create 1 --owner "@me" --title "nuevo elemento" --body "cuerpo del nuevo elemento"
