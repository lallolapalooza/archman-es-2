NOMBRE

gh-project-item-archive - Archivar un elemento en un proyecto

SINOPSIS

gh project item-archive [<número>] [flags]

OPCIONES

--format <cadena>
Formato de salida: {json}
--id <cadena>
ID del elemento a archivar
-q, --jq <expresión>
Filtrar la salida JSON usando una expresión jq
--owner <cadena>
Inicio de sesión del propietario. Use "@me" para el usuario actual.
-t, --template <cadena>
Formatear la salida JSON usando una plantilla Go; consulte "gh help formatting"
--undo
Desarchivar un elemento

CÓDIGOS DE SALIDA

0: Ejecución exitosa

1: Error

2: Comando cancelado

4: Autenticación requerida

NOTA: Los comandos específicos pueden tener códigos de salida adicionales. Consulte la ayuda del comando para obtener más información.

EJEMPLO

# Archivar un elemento en el proyecto "1" del usuario actual
$ gh project item-archive 1 --owner "@me" --id <ID-del-elemento>
