GH-PR(1) Manual de la CLI de GitHub GH-PR(1)

NOMBRE

gh-pr - Gestionar solicitudes de extracción (pull requests)

SINOPSIS

gh pr <comando> [flags]

DESCRIPCIÓN

Trabajar con solicitudes de extracción de GitHub.

COMANDOS GENERALES

gh-pr-create(1)
Crear una solicitud de extracción
gh-pr-list(1)
Listar solicitudes de extracción en un repositorio
gh-pr-status(1)
Mostrar el estado de las solicitudes de extracción relevantes

COMANDOS ESPECÍFICOS

gh-pr-checkout(1)
Descargar una solicitud de extracción en git
gh-pr-checks(1)
Mostrar el estado CI para una sola solicitud de extracción
gh-pr-close(1)
Cerrar una solicitud de extracción
gh-pr-comment(1)
Añadir un comentario a una solicitud de extracción
gh-pr-diff(1)
Ver cambios en una solicitud de extracción
gh-pr-edit(1)
Editar una solicitud de extracción
gh-pr-lock(1)
Bloquear conversación de solicitud de extracción
gh-pr-merge(1)
Fusionar una solicitud de extracción
gh-pr-ready(1)
Marcar una solicitud de extracción como lista para revisión
gh-pr-reopen(1)
Reabrir una solicitud de extracción
gh-pr-revert(1)
Revertir una solicitud de extracción
gh-pr-review(1)
Añadir una revisión a una solicitud de extracción
gh-pr-unlock(1)
Desbloquear conversación de solicitud de extracción
gh-pr-update-branch(1)
Actualizar la rama de una solicitud de extracción
gh-pr-view(1)
Ver una solicitud de extracción

OPCIONES

-R, --repo <[HOST/]PROPIETARIO/REPO>
Seleccionar otro repositorio usando el formato [HOST/]PROPIETARIO/REPO

CÓDIGOS DE SALIDA

0: Ejecución exitosa

1: Error

2: Comando cancelado

4: Autenticación requerida

NOTA: Los comandos específicos pueden tener códigos de salida adicionales. Consulte la ayuda del comando para más información.

EJEMPLO

$ gh pr checkout 353
$ gh pr create --fill
$ gh pr view --web
