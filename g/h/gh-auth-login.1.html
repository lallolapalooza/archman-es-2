GH-AUTH-LOGIN(1) Manual de GitHub CLI GH-AUTH-LOGIN(1)

NOMBRE

gh-auth-login - Iniciar sesión en una cuenta de GitHub

SINOPSIS

gh auth login [flags]

DESCRIPCIÓN

Autenticarse con un host de GitHub.

El nombre de host predeterminado es github.com. Esto se puede anular usando la opción --hostname.

El modo de autenticación predeterminado es un flujo de navegador basado en web. Después de completarlo, se almacenará un token de autenticación de forma segura en el almacén de credenciales del sistema. Si no se encuentra un almacén de credenciales o hay algún problema al usarlo, gh recurrirá a escribir el token en un archivo de texto plano. Consulte gh auth status para conocer su ubicación almacenada.

Alternativamente, use --with-token para pasar un token de acceso personal (clásico) en la entrada estándar. Los alcances mínimos requeridos para el token son: repo, read:org y gist. Tenga cuidado al pasar un token de acceso personal con granularidad fina a --with-token, ya que el alcance inherente a ciertos recursos puede causar un comportamiento confuso al interactuar con otros recursos. Prefiera establecer GH_TOKEN para el uso de tokens de acceso personal con granularidad fina.

Alternativamente, gh utilizará el token de autenticación que se encuentre en las variables de entorno. Este método es el más adecuado para el uso de gh "sin cabeza", como en la automatización. Consulte gh help environment para obtener más información.

Para usar gh en GitHub Actions, agregue GH_TOKEN: ${{ github.token }} a env.

El protocolo git a usar para las operaciones git en este host se puede establecer con --git-protocol, o durante el aviso interactivo. Aunque el inicio de sesión es para una sola cuenta en un host, el protocolo git establecido tendrá efecto para todos los usuarios en el host.

Especificar ssh para el protocolo git detectará las claves SSH existentes para subir, pidiendo crear y subir una nueva clave si no se encuentra ninguna. Esto se puede omitir con la opción --skip-ssh-key.

Para más información sobre los alcances OAuth, consulte

⟨https://docs.github.com/en/developers/apps/building-oauth-apps/scopes-for-oauth-apps/⟩.

OPCIONES

-c, --clipboard
Copiar el código OAuth de un solo uso al portapapeles
-p, --git-protocol <cadena>
El protocolo a usar para las operaciones git en este host: {ssh|https}
-h, --hostname <cadena>
El nombre de host de la instancia de GitHub con la que autenticarse
--insecure-storage
Guardar las credenciales de autenticación en texto plano en lugar de en el almacén de credenciales
-s, --scopes <cadenas>
Alcances de autenticación adicionales a solicitar
--skip-ssh-key
Omitir la solicitud de generar/subir clave SSH
-w, --web
Abrir un navegador para autenticarse
--with-token
Leer el token de la entrada estándar

CÓDIGOS DE SALIDA

0: Ejecución exitosa

1: Error

2: Comando cancelado

4: Autenticación requerida

NOTA: Los comandos específicos pueden tener códigos de salida adicionales. Consulte la ayuda del comando para obtener más información.

EJEMPLO

# Iniciar configuración interactiva
$ gh auth login
# Abrir un navegador para autenticarse y copiar el código OAuth de un solo uso al portapapeles
$ gh auth login --web --clipboard
# Autenticarse contra github.com leyendo el token desde un archivo
$ gh auth login --with-token < mytoken.txt
# Autenticarse con un host específico
$ gh auth login --hostname enterprise.internal
