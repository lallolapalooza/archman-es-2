NOMBRE

gh-run-view - Ver un resumen de la ejecución de un flujo de trabajo

SINOPSIS

gh run view [<id-ejecución>] [flags]

DESCRIPCIÓN

Ver un resumen de la ejecución de un flujo de trabajo.

Debido a limitaciones de la plataforma, gh puede que no siempre sea capaz de asociar trabajos con sus registros correspondientes al usar el método principal de obtención de registros en formato zip.

En tales casos, gh intentará obtener los registros de cada trabajo individualmente a través de la API. Esta solución alternativa es más lenta y consume más recursos. Si faltan más de 25 registros de trabajos, la operación fallará con un error.

Adicionalmente, debido a restricciones similares de la plataforma, algunas líneas de registro pueden no estar asociadas con un paso específico dentro de un trabajo. En estos casos, el nombre del paso aparecerá como PASO DESCONOCIDO en la salida del registro.

OPCIONES

-a, --attempt <uint> (por defecto 0)
El número de intento de la ejecución del flujo de trabajo
--exit-status
Salir con un estado distinto de cero si la ejecución falló
-j, --job <string>
Ver un ID de trabajo específico de una ejecución
-q, --jq <expresión>
Filtrar la salida JSON usando una expresión jq
--json <campos>
Generar salida JSON con los campos especificados
--log
Ver el registro completo de una ejecución o un trabajo específico
--log-failed
Ver el registro de cualquier paso fallido en una ejecución o un trabajo específico
-t, --template <string>
Formatear la salida JSON usando una plantilla Go; consulte "gh help formatting"
-v, --verbose
Mostrar pasos del trabajo
-w, --web
Abrir la ejecución en el navegador

OPCIONES HEREDADAS DE COMANDOS PADRE

-R, --repo <[HOST/]PROPIETARIO/REPO>
Seleccionar otro repositorio usando el formato [HOST/]PROPIETARIO/REPO

CAMPOS JSON

attempt, conclusion, createdAt, databaseId, displayTitle, event, headBranch, headSha, jobs, name, number, startedAt, status, updatedAt, url, workflowDatabaseId, workflowName

CÓDIGOS DE SALIDA

0: Ejecución exitosa

1: Error

2: Comando cancelado

4: Autenticación requerida

NOTA: Los comandos específicos pueden tener códigos de salida adicionales. Consulte la ayuda del comando para obtener más información.

EJEMPLO

# Seleccionar interactivamente una ejecución para ver, opcionalmente seleccionando un solo trabajo
$ gh run view
# Ver una ejecución específica
$ gh run view 12345
# Ver una ejecución específica con un número de intento específico
$ gh run view 12345 --attempt 3
# Ver un trabajo específico dentro de una ejecución
$ gh run run view --job 456789
# Ver el registro completo de un trabajo específico
$ gh run view --log --job 456789
# Salir con un valor distinto de cero si una ejecución falló
$ gh run view 0451 --exit-status && echo "ejecución pendiente o aprobada"
