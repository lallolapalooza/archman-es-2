GH-PROJECT-CLOSE(1) Manual de la CLI de GitHub GH-PROJECT-CLOSE(1)

NOMBRE

gh-project-close - Cerrar un proyecto

SINOPSIS

gh project close [<número>] [flags]

OPCIONES

--formato <cadena>
Formato de salida: {json}
-q, --jq <expresión>
Filtrar la salida JSON usando una expresión jq
--propietario <cadena>
Inicio de sesión del propietario. Usar "@yo" para el usuario actual.
-t, --plantilla <cadena>
Formatear la salida JSON usando una plantilla Go; ver "gh help formatting"
--deshacer
Reabrir un proyecto cerrado

CÓDIGOS DE SALIDA

0: Ejecución exitosa

1: Error

2: Comando cancelado

4: Autenticación requerida

NOTA: Los comandos específicos pueden tener códigos de salida adicionales. Consulte la ayuda del comando para obtener más información.

EJEMPLO

# Cerrar el proyecto "1" propiedad de monalisa
$ gh project close 1 --owner monalisa
# Reabrir el proyecto cerrado "1" propiedad de github
$ gh project close 1 --owner github --undo
