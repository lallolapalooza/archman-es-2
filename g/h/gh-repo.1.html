GH-REPO(1) Manual de la CLI de GitHub GH-REPO(1)

NOMBRE

gh-repo - Gestionar repositorios

SINOPSIS

gh repo <comando> [flags]

DESCRIPCIÓN

Trabajar con repositorios de GitHub.

COMANDOS GENERALES

gh-repo-create(1)
Crear un nuevo repositorio
gh-repo-list(1)
Listar repositorios propiedad del usuario u organización

COMANDOS ESPECÍFICOS

gh-repo-archive(1)
Archivar un repositorio
gh-repo-autolink(1)
Gestionar referencias de autolink
gh-repo-clone(1)
Clonar un repositorio localmente
gh-repo-delete(1)
Eliminar un repositorio
gh-repo-deploy-key(1)
Gestionar claves de despliegue en un repositorio
gh-repo-edit(1)
Editar la configuración del repositorio
gh-repo-fork(1)
Crear un fork de un repositorio
gh-repo-gitignore(1)
Listar y ver plantillas de gitignore de repositorio disponibles
gh-repo-license(1)
Explorar licencias de repositorios
gh-repo-rename(1)
Renombrar un repositorio
gh-repo-set-default(1)
Configurar el repositorio predeterminado para este directorio
gh-repo-sync(1)
Sincronizar un repositorio
gh-repo-unarchive(1)
Desarchivar un repositorio
gh-repo-view(1)
Ver un repositorio

CÓDIGOS DE SALIDA

0: Ejecución exitosa

1: Error

2: Comando cancelado

4: Autenticación requerida

NOTA: Los comandos específicos pueden tener códigos de salida adicionales. Consulte la ayuda del comando para más información.

EJEMPLO

$ gh repo create
$ gh repo clone cli/cli
$ gh repo view --web
