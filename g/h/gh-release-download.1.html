NOMBRE

gh-release-download - Descargar activos de lanzamientos

SINOPSIS

gh release download [<etiqueta>] [flags]

DESCRIPCIÓN

Descarga activos de un lanzamiento de GitHub.

Sin un argumento explícito de nombre de etiqueta, se descargan los activos del último lanzamiento en el proyecto. En este caso, se requiere --pattern o --archive.

OPCIONES

-A, --archive <formato>
Descarga el archivo de código fuente en el formato especificado (zip o tar.gz)
--clobber
Sobrescribe archivos existentes con el mismo nombre
-D, --dir <directorio> (por defecto ".")
El directorio donde descargar los archivos
-O, --output <archivo>
El archivo donde escribir un solo activo (usa "-" para escribir a salida estándar)
-p, --pattern <stringArray>
Descarga solo activos que coincidan con un patrón glob
--skip-existing
Omite la descarga cuando existen archivos con el mismo nombre

OPCIONES HEREDADAS DE COMANDOS PADRE

-R, --repo <[HOST/]PROPIETARIO/REPO>
Selecciona otro repositorio usando el formato [HOST/]PROPIETARIO/REPO

CÓDIGOS DE SALIDA

0: Ejecución exitosa

1: Error

2: Comando cancelado

4: Autenticación requerida

NOTA: Comandos específicos pueden tener códigos de salida adicionales. Consulta la ayuda del comando para más información.

EJEMPLO

# Descarga todos los activos de un lanzamiento específico
$ gh release download v1.2.3
# Descarga solo paquetes .deb para el último lanzamiento
$ gh release download --pattern '*.deb'
# Especifica múltiples patrones de archivo
$ gh release download -p '*.deb' -p '*.rpm'
# Descarga el archivo de código fuente de un lanzamiento
$ gh release download v1.2.3 --archive=zip
