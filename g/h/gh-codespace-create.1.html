NOMBRE

gh-codespace-create - Crear un codespace

SINOPSIS

gh codespace create [flags]

OPCIONES

-b, --branch <cadena>
Rama del repositorio
--default-permissions
No preguntar para aceptar permisos adicionales solicitados por el codespace
--devcontainer-path <cadena>
Ruta al archivo devcontainer.json que se utilizará al crear el codespace
-d, --display-name <cadena>
Nombre visible para el codespace (48 caracteres o menos)
--idle-timeout <duración>
Inactividad permitida antes de que el codespace se detenga, por ejemplo, "10m", "1h"
-l, --location <cadena>
Ubicación: {EastUs|SouthEastAsia|WestEurope|WestUs2} (se determina automáticamente si no se proporciona)
-m, --machine <cadena>
Especificaciones de hardware para la VM
-R, --repo <cadena>
Nombre del repositorio con propietario: usuario/repo
--retention-period <duración>
Tiempo permitido después de apagar antes de que el codespace se elimine automáticamente (máximo 30 días), por ejemplo, "1h", "72h"
-s, --status
Mostrar el estado del comando post-creación y los dotfiles
-w, --web
Crear codespace desde el navegador, no se puede usar con --display-name, --idle-timeout o --retention-period

CÓDIGOS DE SALIDA

0: Ejecución exitosa

1: Error

2: Comando cancelado

4: Autenticación requerida

NOTA: Los comandos específicos pueden tener códigos de salida adicionales. Consulte la ayuda del comando para obtener más información.
