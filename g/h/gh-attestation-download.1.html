NOMBRE

gh-attestation-download - Descarga las atestaciones de un artefacto para uso sin conexión

SINOPSIS

gh attestation download [<ruta-archivo> | oci://<uri-imagen>] [--owner | --repo] [flags]

DESCRIPCIÓN

NOTA: Esta característica se encuentra actualmente en vista previa pública, y está sujeta a cambios.

Descarga las atestaciones asociadas con un artefacto para uso sin conexión.

El comando requiere: * una ruta de archivo a un artefacto, o * una URI de imagen de contenedor (por ejemplo, oci://<uri-imagen>)
* (tenga en cuenta que si proporciona una URL OCI, ya debe estar autenticado con su registro de contenedor)

Además, el comando requiere: * la bandera --repo (por ejemplo, --repo github/example), o * la bandera --owner (por ejemplo, --owner github), o

El valor de la bandera --repo debe coincidir con el nombre del repositorio de GitHub con el que está vinculado el artefacto.

El valor de la bandera --owner debe coincidir con el nombre de la organización de GitHub a la que pertenece el repositorio vinculado del artefacto.

Cualquier paquete asociado se escribirá en un archivo en el directorio actual con el nombre del digest del artefacto. Por ejemplo, si el digest es "sha256:1234", el archivo se llamará "sha256:1234.jsonl".

Los dos puntos son caracteres especiales en Windows y no se pueden utilizar en los nombres de archivo. Para adaptarlo, se utilizará un guion para separar el algoritmo del digest en el nombre del archivo de atestaciones. Por ejemplo, si el digest es "sha256:1234", el archivo se llamará "sha256-1234.jsonl".

OPCIONES

-d, --digest-alg <cadena> (predeterminado "sha256")
El algoritmo utilizado para calcular un digest del artefacto: {sha256|sha512}
--hostname <cadena>
Configurar el host a utilizar
-L, --limit <int> (predeterminado 30)
Número máximo de atestaciones a obtener
-o, --owner <cadena>
Organización de GitHub para delimitar la búsqueda de atestaciones por
--predicate-type <cadena>
Filtrar atestaciones por tipo de predicado proporcionado
-R, --repo <cadena>
Nombre del repositorio en el formato /

CÓDIGOS DE SALIDA

0: Ejecución exitosa

1: Error

2: Comando cancelado

4: Autenticación requerida

NOTA: Los comandos específicos pueden tener códigos de salida adicionales. Consulte la ayuda del comando para obtener más información.

EJEMPLO

# Descargar atestaciones para un artefacto local vinculado con una organización
$ gh attestation download example.bin -o github
# Descargar atestaciones para un artefacto local vinculado con un repositorio
$ gh attestation download example.bin -R github/example
# Descargar atestaciones para una imagen OCI vinculada con una organización
$ gh attestation download oci://example.com/foo/bar:latest -o github
