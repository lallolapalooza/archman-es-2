GH-REPO-AUTOLINK-VIEW(1) Manual de la CLI de GitHub GH-REPO-AUTOLINK-VIEW(1)

NOMBRE

gh-repo-autolink view - Ver una referencia de autovínculo

SINOPSIS

gh repo autolink view <id> [flags]

DESCRIPCIÓN

Ver una referencia de autovínculo para un repositorio.

OPCIONES

-q, --jq <expresión>
Filtrar la salida JSON usando una expresión jq
--json <campos>
Generar salida JSON con los campos especificados
-t, --template <cadena>
Formatear la salida JSON usando una plantilla Go; ver "gh help formatting"

OPCIONES HEREDADAS DE COMANDOS PADRE

-R, --repo <[HOST/]OWNER/REPO>
Seleccionar otro repositorio usando el formato [HOST/]OWNER/REPO

CAMPOS JSON

id, isAlphanumeric, keyPrefix, urlTemplate

CÓDIGOS DE SALIDA

0: Ejecución exitosa

1: Error

2: Comando cancelado

4: Autenticación requerida

NOTA: Los comandos específicos pueden tener códigos de salida adicionales. Consultar la ayuda del comando para más información.
