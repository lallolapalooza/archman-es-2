NOMBRE

gh-issue-unpin - Desfijar un issue

SINOPSIS

gh issue unpin {<número> | <url>} [flags]

DESCRIPCIÓN

Desfija un issue de un repositorio.

El issue se puede especificar por su número o URL.

OPCIONES HEREDADAS DE LOS COMANDOS PADRE

-R, --repo <[HOST/]PROPIETARIO/REPO>
Seleccionar otro repositorio usando el formato [HOST/]PROPIETARIO/REPO

CÓDIGOS DE SALIDA

0: Ejecución exitosa

1: Error

2: Comando cancelado

4: Autenticación requerida

NOTA: Comandos específicos pueden tener códigos de salida adicionales. Consulte la ayuda del comando para más información.

EJEMPLO

# Desfijar issue del repositorio actual
$ gh issue unpin 23
# Desfijar issue por URL
$ gh issue unpin https://github.com/owner/repo/issues/23
# Desfijar un issue de un repositorio específico
$ gh issue unpin 23 --repo owner/repo
