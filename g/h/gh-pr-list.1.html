NOMBRE

gh-pr-list - Lista las solicitudes de extracción en un repositorio

SINOPSIS

gh pr list [flags]

DESCRIPCIÓN

Lista las solicitudes de extracción en un repositorio de GitHub. Por defecto, solo lista las PR abiertas.

La sintaxis de la consulta de búsqueda se documenta aquí:

⟨https://docs.github.com/en/search-github/searching-on-github/searching-issues-and-pull-requests⟩

En hosts de GitHub compatibles, se puede usar la sintaxis de búsqueda avanzada de problemas en la consulta --search. Para más información sobre la búsqueda avanzada de problemas, ver:

⟨https://docs.github.com/en/issues/tracking-your-work-with-issues/using-issues/filtering-and-searching-issues-and-pull-requests#building-advanced-filters-for-issues⟩

OPCIONES

--app <cadena>
Filtrar por autor de la aplicación de GitHub
-a, --assignee <cadena>
Filtrar por asignado
-A, --author <cadena>
Filtrar por autor
-B, --base <cadena>
Filtrar por rama base
-d, --draft
Filtrar por estado de borrador
-H, --head <cadena>
Filtrar por rama principal (":" la sintaxis no es compatible)
-q, --jq <expresión>
Filtrar salida JSON usando una expresión jq
--json <campos>
Salida JSON con los campos especificados
-l, --label <cadenas>
Filtrar por etiqueta
-L, --limit <int> (predeterminado 30)
Número máximo de elementos a obtener
-S, --search <consulta>
Buscar solicitudes de extracción con consulta
-s, --state <cadena> (predeterminado "open")
Filtrar por estado: {open|closed|merged|all}
-t, --template <cadena>
Formatear la salida JSON usando una plantilla Go; ver "gh help formatting"
-w, --web
Listar solicitudes de extracción en el navegador web

OPCIONES HEREDADAS DE COMANDOS PADRE

-R, --repo <[HOST/]OWNER/REPO>
Seleccionar otro repositorio usando el formato [HOST/]OWNER/REPO

ALIAS

gh pr ls

CAMPOS JSON

additions, assignees, author, autoMergeRequest, baseRefName, baseRefOid, body, changedFiles, closed, closedAt, closingIssuesReferences, comments, commits, createdAt, deletions, files, fullDatabaseId, headRefName, headRefOid, headRepository, headRepositoryOwner, id, isCrossRepository, isDraft, labels, latestReviews, maintainerCanModify, mergeCommit, mergeStateStatus, mergeable, mergedAt, mergedBy, milestone, number, potentialMergeCommit, projectCards, projectItems, reactionGroups, reviewDecision, reviewRequests, reviews, state, statusCheckRollup, title, updatedAt, url

CÓDIGOS DE SALIDA

0: Ejecución exitosa

1: Error

2: Comando cancelado

4: Autenticación requerida

NOTA: Los comandos específicos pueden tener códigos de salida adicionales. Consulte la ayuda del comando para obtener más información.

EJEMPLO

# Listar PRs escritas por ti
$ gh pr list --author "@me"
# Listar PRs con un nombre de rama principal específico
$ gh pr list --head "typo"
# Listar solo PRs con todas las etiquetas dadas
$ gh pr list --label bug --label "priority 1"
# Filtrar PRs usando sintaxis de búsqueda
$ gh pr list --search "status:success review:required"
# Encontrar una PR que introdujo un commit dado
$ gh pr list --search "<SHA>" --state merged
