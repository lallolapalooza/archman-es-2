NOMBRE

gh-search-commits - Buscar commits

SINOPSIS

gh search commits [<consulta>] [flags]

DESCRIPCIÓN

Busca commits en GitHub.

El comando soporta la construcción de consultas utilizando la sintaxis de búsqueda de GitHub, empleando los parámetros y flags de cualificador, o una combinación de ambos.

La sintaxis de búsqueda de GitHub está documentada en:

⟨https://docs.github.com/search-github/searching-on-github/searching-commits⟩

Para más información sobre cómo manejar consultas de búsqueda que contienen un guion, ejecuta gh search --help.

OPCIONES

--author <cadena>
Filtrar por autor
--author-date <fecha>
Filtrar basado en la fecha de autoría
--author-email <cadena>
Filtrar por correo electrónico del autor
--author-name <cadena>
Filtrar por nombre del autor
--committer <cadena>
Filtrar por committer
--committer-date <fecha>
Filtrar basado en la fecha de commit
--committer-email <cadena>
Filtrar por correo electrónico del committer
--committer-name <cadena>
Filtrar por nombre del committer
--hash <cadena>
Filtrar por hash del commit
-q, --jq <expresión>
Filtrar la salida JSON usando una expresión jq
--json <campos>
Generar salida JSON con los campos especificados
-L, --limit <entero> (predeterminado 30)
Número máximo de commits a obtener
--merge
Filtrar por commits de fusión
--order <cadena> (predeterminado "desc")
Orden de los commits devueltos, ignorado a menos que se especifique el flag '--sort': {asc|desc}
--owner <cadenas>
Filtrar por propietario del repositorio
--parent <cadena>
Filtrar por hash del padre
-R, --repo <cadenas>
Filtrar por repositorio
--sort <cadena> (predeterminado "best-match")
Ordenar los commits obtenidos: {author-date|committer-date}
-t, --template <cadena>
Formatear la salida JSON usando una plantilla Go; ver "gh help formatting"
--tree <cadena>
Filtrar por hash del árbol
--visibility <cadenas>
Filtrar basado en la visibilidad del repositorio: {public|private|internal}
-w, --web
Abrir la consulta de búsqueda en el navegador web

CAMPOS JSON

author, commit, committer, id, parents, repository, sha, url

CÓDIGOS DE SALIDA

0: Ejecución exitosa

1: Error

2: Comando cancelado

4: Autenticación requerida

NOTA: Comandos específicos pueden tener códigos de salida adicionales. Consulte la ayuda del comando para más información.

EJEMPLO

# Buscar commits que coincidan con el conjunto de palabras clave "readme" y "typo"
$ gh search commits readme typo
# Buscar commits que coincidan con la frase "bug fix"
$ gh search commits "bug fix"
# Buscar commits realizados por el usuario "monalisa"
$ gh search commits --committer=monalisa
# Buscar commits cuyo autor tenga el nombre "Jane Doe"
$ gh search commits --author-name="Jane Doe"
# Buscar commits que coincidan con el hash "8dd03144ffdc6c0d486d6b705f9c7fba871ee7c3"
$ gh search commits --hash=8dd03144ffdc6c0d486d6b705f9c7fba871ee7c3
# Buscar commits creados antes del 1 de febrero de 2022
$ gh search commits --author-date="<2022-02-01"
