NOMBRE

gh-run-watch - Observar una ejecución hasta que se complete, mostrando su progreso

SINOPSIS

gh run watch <id-ejecucion> [banderas]

DESCRIPCIÓN

Observa una ejecución hasta que se complete, mostrando su progreso.

Por defecto, se muestran todos los pasos. La opción --compact puede usarse para mostrar solo los pasos relevantes/fallidos.

Este comando no admite la autenticación a través de PATs de grano fino, ya que actualmente no es posible crear un PAT con el permiso checks:read.

OPCIONES

--compact
Mostrar solo pasos relevantes/fallidos
--exit-status
Salir con un estado distinto de cero si la ejecución falla
-i, --interval <entero> (por defecto 3)
Intervalo de actualización en segundos

OPCIONES HEREDADAS DE COMANDOS PADRE

-R, --repo <[HOST/]PROPIETARIO/REPO>
Seleccionar otro repositorio usando el formato [HOST/]PROPIETARIO/REPO

CÓDIGOS DE SALIDA

0: Ejecución exitosa

1: Error

2: Comando cancelado

4: Autenticación requerida

NOTA: Los comandos específicos pueden tener códigos de salida adicionales. Consulte la ayuda del comando para obtener más información.

EJEMPLO

# Observar una ejecución hasta que termine
$ gh run watch
# Observar una ejecución en modo compacto
$ gh run watch --compact
# Ejecutar algún otro comando cuando la ejecución termine
$ gh run watch && notify-send 'la ejecución ha terminado!'
