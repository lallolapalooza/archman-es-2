NOMBRE

gh-repo-set-default - Configura el repositorio predeterminado para este directorio

SINOPSIS

gh repo set-default [<repositorio>] [flags]

DESCRIPCIÓN

Este comando establece el repositorio remoto predeterminado a usar al consultar la API de GitHub para el repositorio clonado localmente.

gh utiliza el repositorio predeterminado para cosas como:

  • ver y crear solicitudes de extracción (pull requests)
  • ver y crear incidencias (issues)
  • ver y crear lanzamientos (releases)
  • trabajar con GitHub Actions

NOTA: gh no utiliza el repositorio predeterminado para gestionar secretos del repositorio y del entorno.

OPCIONES

-u, --unset
Anula la configuración del repositorio predeterminado actual
-v, --view
Muestra el repositorio predeterminado actual

CÓDIGOS DE SALIDA

0: Ejecución exitosa

1: Error

2: Comando cancelado

4: Autenticación requerida

NOTA: Los comandos específicos pueden tener códigos de salida adicionales. Consulte la ayuda del comando para obtener más información.

EJEMPLO

# Selecciona interactivamente un repositorio predeterminado
$ gh repo set-default
# Establece un repositorio explícitamente
$ gh repo set-default propietario/repo
# Muestra el repositorio predeterminado actual
$ gh repo set-default --view
# Muestra más opciones de repositorio en el selector interactivo
$ git remote add newrepo https://github.com/propietario/repo
$ gh repo set-default
