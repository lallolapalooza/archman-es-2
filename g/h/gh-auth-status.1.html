GH-AUTH-STATUS(1) Manual de la CLI de GitHub GH-AUTH-STATUS(1)

NOMBRE

gh-auth-status - Muestra la cuenta activa y el estado de autenticación en cada host de GitHub conocido

SINOPSIS

gh auth status [flags]

DESCRIPCIÓN

Muestra la cuenta activa y el estado de autenticación en cada host de GitHub conocido.

Para cada host, se prueba el estado de autenticación de cada cuenta conocida y se incluyen los problemas en la salida. Cada sección de host indicará la cuenta activa, que se utilizará al dirigirse a ese host.

Si una cuenta en cualquier host (o solo la proporcionada a través de --hostname) tiene problemas de autenticación, el comando saldrá con 1 y mostrará la salida en stderr. Tenga en cuenta que al usar la opción --json, el comando siempre saldrá con cero independientemente de cualquier problema de autenticación, a menos que haya un error fatal.

Para cambiar la cuenta activa para un host, consulte gh auth switch.

OPCIONES

-a, --active
Mostrar solo la cuenta activa
-h, --hostname <string>
Verificar solo el estado de autenticación de un nombre de host específico
--jq <expression>
Filtrar la salida JSON usando una expresión jq
--json <fields>
Generar salida JSON con los campos especificados
-t, --show-token
Mostrar el token de autenticación
--template <string>
Formatear la salida JSON usando una plantilla de Go; consulte "gh help formatting"

CAMPOS JSON

hosts

CÓDIGOS DE SALIDA

0: Ejecución exitosa

1: Error

2: Comando cancelado

4: Autenticación requerida

NOTA: Comandos específicos pueden tener códigos de salida adicionales. Consulte la ayuda del comando para más información.

EJEMPLO

# Mostrar estado de autenticación para todas las cuentas en todos los hosts
$ gh auth status
# Mostrar estado de autenticación para la cuenta activa en un host específico
$ gh auth status --active --hostname github.example.com
# Mostrar tokens en texto plano
$ gh auth status --show-token
# Formatear el estado de autenticación como JSON
$ gh auth status --json hosts
# Incluir token en texto plano en la salida JSON
$ gh auth status --json hosts --show-token
# Formatear hosts como un array JSON plano
$ gh auth status --json hosts --jq '.hosts | add'
