NOMBRE

gh-attestation-trusted-root - Muestra el contenido de trusted_root.jsonl, probablemente para verificación sin conexión

SINOPSIS

gh attestation trusted-root [--tuf-url <url> --tuf-root <ruta-archivo>] [--verify-only] [flags]

DESCRIPCIÓN

Muestra el contenido de un archivo trusted_root.jsonl, probablemente para verificación sin conexión.

Al usar gh attestation verify, si tu máquina está conectada a Internet, esto ocurrirá automáticamente. Pero para hacer una verificación sin conexión, necesitas proporcionar un archivo de raíz confiable con --custom-trusted-root; este comando te ayudará a obtener un archivo trusted_root.jsonl para ese propósito.

Puedes llamar a este comando sin ningún flag para obtener un archivo de raíz confiable que cubra la Instancia Sigstore Public Good, así como la instancia Sigstore de GitHub.

De lo contrario, puedes usar --tuf-url para especificar la URL de un espejo de repositorio TUF personalizado, y --tuf-root debe ser la ruta al archivo root.json que obtuviste de forma segura fuera de banda.

Si solo deseas verificar la integridad de tu repositorio TUF local y no quieres el contenido de un archivo trusted_root.jsonl, usa --verify-only.

OPCIONES

--hostname <cadena>
Configura el host a utilizar
--tuf-root <cadena>
Ruta al archivo root.json de TUF en el disco
--tuf-url <cadena>
URL del espejo del repositorio de TUF
--verify-only
No mostrar el contenido de trusted_root.jsonl

CÓDIGOS DE SALIDA

0: Ejecución exitosa

1: Error

2: Comando cancelado

4: Autenticación requerida

NOTA: Comandos específicos pueden tener códigos de salida adicionales. Consulta la ayuda del comando para obtener más información.

EJEMPLO

# Obtener un trusted_root.jsonl para Sigstore Public Good y la instancia de GitHub
$ gh attestation trusted-root
