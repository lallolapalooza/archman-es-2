NOMBRE

gh-run-list - Listar ejecuciones recientes de flujos de trabajo

SINOPSIS

gh run list [flags]

DESCRIPCIÓN

Listar ejecuciones recientes de flujos de trabajo.

Ten en cuenta que proporcionar el nombre_del_flujo a la opción -w no obtendrá flujos de trabajo deshabilitados. Pasa también la opción -a para obtener ejecuciones de flujos de trabajo deshabilitados usando el nombre_del_flujo y la opción -w.

Las ejecuciones creadas por flujos de trabajo de reglas de organización y de empresa no mostrarán un nombre de flujo de trabajo debido a limitaciones de la API de GitHub.

Para ver ejecuciones asociadas con una solicitud de extracción, los usuarios deben ejecutar gh pr checks.

OPCIONES

-a, --all
Incluir flujos de trabajo deshabilitados
-b, --branch <cadena>
Filtrar ejecuciones por rama
-c, --commit <SHA>
Filtrar ejecuciones por el SHA del commit
--created <fecha>
Filtrar ejecuciones por la fecha en que fueron creadas
-e, --event <evento>
Filtrar ejecuciones por el evento que disparó la ejecución
-q, --jq <expresión>
Filtrar la salida JSON usando una expresión jq
--json <campos>
Salida JSON con los campos especificados
-L, --limit <int> (por defecto 20)
Número máximo de ejecuciones a obtener
-s, --status <cadena>
Filtrar ejecuciones por estado: {queued|completed|in_progress|requested|waiting|pending|action_required|cancelled|failure|neutral|skipped|stale|startup_failure|success|timed_out}
-t, --template <cadena>
Formatear la salida JSON usando una plantilla Go; ver "gh help formatting"
-u, --user <cadena>
Filtrar ejecuciones por el usuario que disparó la ejecución
-w, --workflow <cadena>
Filtrar ejecuciones por flujo de trabajo

OPCIONES HEREDADAS DE COMANDOS PADRE

-R, --repo <[HOST/]OWNER/REPO>
Seleccionar otro repositorio usando el formato [HOST/]OWNER/REPO

ALIAS

gh run ls

CAMPOS JSON

attempt, conclusion, createdAt, databaseId, displayTitle, event, headBranch, headSha, name, number, startedAt, status, updatedAt, url, workflowDatabaseId, workflowName

CÓDIGOS DE SALIDA

0: Ejecución exitosa

1: Error

2: Comando cancelado

4: Autenticación requerida

NOTA: Los comandos específicos pueden tener códigos de salida adicionales. Consulta la ayuda del comando para más información.
