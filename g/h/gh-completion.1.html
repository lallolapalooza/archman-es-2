NOMBRE

gh-completion - Genera scripts de autocompletado para la shell

SINOPSIS

gh completion -s <shell>

DESCRIPCIÓN

Genera scripts de autocompletado para los comandos de GitHub CLI.

Al instalar GitHub CLI a través de un gestor de paquetes, es posible que no sea necesaria ninguna configuración adicional de la shell para obtener soporte de autocompletado. Para Homebrew, consulta ⟨https://docs.brew.sh/Shell-Completion⟩

Si necesitas configurar autocompletados manualmente, sigue las instrucciones a continuación. Las ubicaciones exactas de los archivos de configuración pueden variar según tu sistema. Asegúrate de reiniciar tu shell antes de probar si los autocompletados funcionan.

bash

Primero, asegúrate de instalar bash-completion usando tu gestor de paquetes.

Después, añade esto a tu archivo ~/.bash_profile:

eval "$(gh completion -s bash)"

zsh

Genera un script de autocompletado _gh y colócalo en algún lugar de tu $fpath:

gh completion -s zsh > /usr/local/share/zsh/site-functions/_gh

Asegúrate de que lo siguiente esté presente en tu archivo ~/.zshrc:

autoload -U compinit
compinit -i

Se recomienda usar Zsh versión 5.7 o posterior.

fish

Genera un script de autocompletado gh.fish:

gh completion -s fish > ~/.config/fish/completions/gh.fish

PowerShell

Abre tu script de perfil con:

mkdir -Path (Split-Path -Parent $profile) -ErrorAction SilentlyContinue
notepad $profile

Añade la línea y guarda el archivo:

Invoke-Expression -Command $(gh completion -s powershell | Out-String)

OPCIONES

-s, --shell <string>
Tipo de shell: {bash|zsh|fish|powershell}

CÓDIGOS DE SALIDA

0: Ejecución exitosa

1: Error

2: Comando cancelado

4: Autenticación requerida

NOTA: Comandos específicos pueden tener códigos de salida adicionales. Consulta la ayuda del comando para más información.
