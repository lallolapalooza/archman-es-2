NOMBRE

gh-pr-reopen - Reabrir una solicitud de extracción

SINOPSIS

gh pr reopen {<número> | <url> | <rama>} [flags]

OPCIONES

-c, --comentario <cadena>
Añadir un comentario de reapertura

OPCIONES HEREDADAS DE COMANDOS PADRE

-R, --repo <[HOST/]PROPIETARIO/REPO>
Seleccionar otro repositorio usando el formato [HOST/]PROPIETARIO/REPO

CÓDIGOS DE SALIDA

0: Ejecución exitosa

1: Error

2: Comando cancelado

4: Autenticación requerida

NOTA: Los comandos específicos pueden tener códigos de salida adicionales. Consulte la ayuda del comando para obtener más información.
