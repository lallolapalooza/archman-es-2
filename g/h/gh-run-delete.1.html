NOMBRE

gh-run-delete - Eliminar una ejecución de flujo de trabajo

SINOPSIS

gh run delete [<id-de-ejecucion>] [flags]

OPCIONES HEREDADAS DE COMANDOS PADRE

-R, --repo <[HOST/]PROPIETARIO/REPO>
Selecciona otro repositorio usando el formato [HOST/]PROPIETARIO/REPO

CÓDIGOS DE SALIDA

0: Ejecución exitosa

1: Error

2: Comando cancelado

4: Autenticación requerida

NOTA: Los comandos específicos pueden tener códigos de salida adicionales. Consulta la ayuda del comando para obtener más información.

EJEMPLO

# Seleccionar interactivamente una ejecución para eliminar
$ gh run delete
# Eliminar una ejecución específica
$ gh run delete 12345
