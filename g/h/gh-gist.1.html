GH-GIST(1) Manual de la CLI de GitHub GH-GIST(1)

NOMBRE

gh-gist - Gestionar gists

SINOPSIS

gh gist <comando> [flags]

DESCRIPCIÓN

Trabajar con gists de GitHub.

COMANDOS DISPONIBLES

gh-gist-clone(1)
Clonar un gist localmente
gh-gist-create(1)
Crear un nuevo gist
gh-gist-delete(1)
Eliminar un gist
gh-gist-edit(1)
Editar uno de tus gists
gh-gist-list(1)
Listar tus gists
gh-gist-rename(1)
Renombrar un archivo en un gist
gh-gist-view(1)
Ver un gist

CÓDIGOS DE SALIDA

0: Ejecución exitosa

1: Error

2: Comando cancelado

4: Autenticación requerida

NOTA: Los comandos específicos pueden tener códigos de salida adicionales. Consulta la ayuda del comando para más información.
