NOMBRE

gh-ruleset-view - Ver información sobre un conjunto de reglas

SINOPSIS

gh ruleset view [<id-del-conjunto-de-reglas>] [flags]

DESCRIPCIÓN

Ver información sobre un conjunto de reglas de GitHub.

Si no se proporciona un ID, se utilizará un aviso interactivo para elegir el conjunto de reglas a ver.

Utilice la bandera --parents para controlar si se deben devolver los conjuntos de reglas configurados en niveles superiores que también se aplican al repositorio u organización proporcionados. El valor predeterminado es true.

OPCIONES

-o, --org <cadena>
Nombre de la organización si el ID proporcionado es un conjunto de reglas a nivel de organización.
-p, --parents (predeterminado true)
Si se deben incluir los conjuntos de reglas configurados en niveles superiores que también se aplican.
-w, --web
Abrir el conjunto de reglas en el navegador.

OPCIONES HEREDADAS DE COMANDOS PADRE

-R, --repo <[HOST/]PROPIETARIO/REPO>
Seleccionar otro repositorio usando el formato [HOST/]PROPIETARIO/REPO.

CÓDIGOS DE SALIDA

0: Ejecución exitosa

1: Error

2: Comando cancelado

4: Autenticación requerida

NOTA: Los comandos específicos pueden tener códigos de salida adicionales. Consulte la ayuda del comando para obtener más información.

EJEMPLO

# Elegir interactivamente un conjunto de reglas para ver de todos los conjuntos de reglas que se aplican al repositorio actual
$ gh ruleset view
# Elegir interactivamente un conjunto de reglas para ver solo de los conjuntos de reglas configurados en el repositorio actual
$ gh ruleset view --no-parents
# Ver un conjunto de reglas configurado en el repositorio actual o en cualquiera de sus padres
$ gh ruleset view 43
# Ver un conjunto de reglas configurado en un repositorio diferente o en cualquiera de sus padres
$ gh ruleset view 23 --repo owner/repo
# Ver un conjunto de reglas a nivel de organización
$ gh ruleset view 23 --org mi-org
