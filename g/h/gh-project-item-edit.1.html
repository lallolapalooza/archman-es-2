NOMBRE

gh-project-item-edit - Edita un elemento de un proyecto

SINOPSIS

gh project item-edit [flags]

DESCRIPCIÓN

Edita una versión preliminar de un issue o un elemento de un proyecto. Ambos usos requieren el ID del elemento a editar.

Para los issues que no son versiones preliminares, también se requiere el ID del proyecto, y solo se puede actualizar un valor de campo por invocación.

Elimina el valor de un campo de elemento de proyecto usando la bandera --clear.

OPCIONES

--body <string>
Cuerpo del elemento de la versión preliminar del issue
--clear
Elimina el valor del campo
--date <string>
Valor de fecha para el campo (YYYY-MM-DD)
--field-id <string>
ID del campo a actualizar
--format <string>
Formato de salida: {json}
--id <string>
ID del elemento a editar
--iteration-id <string>
ID del valor de iteración a establecer en el campo
-q, --jq <expresión>
Filtra la salida JSON usando una expresión jq
--number <float> (por defecto 0)
Valor numérico para el campo
--project-id <string>
ID del proyecto al que pertenece el campo
--single-select-option-id <string>
ID del valor de opción de selección única a establecer en el campo
-t, --template <string>
Formatea la salida JSON usando una plantilla Go; consulta "gh help formatting"
--text <string>
Valor de texto para el campo
--title <string>
Título del elemento de la versión preliminar del issue

CÓDIGOS DE SALIDA

0: Ejecución exitosa

1: Error

2: Comando cancelado

4: Autenticación requerida

NOTA: Comandos específicos pueden tener códigos de salida adicionales. Consulta la ayuda del comando para más información.

EJEMPLO

# Edita el valor de un campo de texto de un elemento
$ gh project item-edit --id <item-id> --field-id <field-id> --project-id <project-id> --text "nuevo texto"
# Borra el valor de un campo de un elemento
$ gh project item-edit --id <item-id> --field-id <field-id> --project-id <project-id> --clear
