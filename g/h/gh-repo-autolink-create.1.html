NOMBRE

gh-repo-autolink-create - Crea una nueva referencia de autolink

SINOPSIS

gh repo autolink create <prefijoClave> <plantillaURL> [banderas]

DESCRIPCIÓN

Crea una nueva referencia de autolink para un repositorio.

El argumento prefijoClave especifica el prefijo que generará un enlace cuando se le añadan ciertos caracteres.

El argumento plantillaURL especifica la URL de destino que se generará cuando se encuentre el prefijoClave, la cual debe contener la variable <num> para el número de referencia.

Por defecto, los autolinks son alfanuméricos; se utiliza la bandera --numeric para crear un autolink numérico.

El comportamiento de la variable <num> difiere según si el autolink es alfanumérico o numérico:

  • alfanumérico: coincide con A-Z (sin distinción de mayúsculas y minúsculas), 0-9 y -
  • numérico: coincide con 0-9

Si la plantilla contiene múltiples instancias de <num>, solo se reemplazará la primera.

OPCIONES

-n, --numeric
Marca el autolink como numérico

OPCIONES HEREDADAS DE COMANDOS PADRE

-R, --repo <[HOST/]PROPIETARIO/REPO>
Selecciona otro repositorio usando el formato [HOST/]PROPIETARIO/REPO

ALIAS

gh repo autolink new

CÓDIGOS DE SALIDA

0: Ejecución exitosa

1: Error

2: Comando cancelado

4: Autenticación requerida

NOTA: Comandos específicos pueden tener códigos de salida adicionales. Consulta la ayuda del comando para obtener más información.

EJEMPLO

# Crea un autolink alfanumérico a example.com para el prefijo de clave "TICKET-".
# Genera https://example.com/TICKET?query=123abc a partir de "TICKET-123abc".
$ gh repo autolink create TICKET- "https://example.com/TICKET?query=<num>"
# Crea un autolink numérico a example.com para el prefijo de clave "STORY-".
# Genera https://example.com/STORY?id=123 a partir de "STORY-123".
$ gh repo autolink create STORY- "https://example.com/STORY?id=<num>" --numeric
