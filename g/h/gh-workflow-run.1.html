NOMBRE

gh-workflow-run - Ejecuta un flujo de trabajo creando un evento workflow_dispatch

SINOPSIS

gh workflow run [<id-del-flujo> | <nombre-del-flujo>] [flags]

DESCRIPCIÓN

Crea un evento workflow_dispatch para un flujo de trabajo dado.

Este comando activará GitHub Actions para ejecutar un archivo de flujo de trabajo dado. El archivo de flujo de trabajo debe soportar un disparador on.workflow_dispatch para poder ejecutarse de esta manera.

Si el archivo de flujo de trabajo soporta entradas, estas se pueden especificar de varias maneras:

  • Interactivamente
  • Mediante las flags -f/--raw-field o -F/--field
  • Como JSON, a través de la entrada estándar

OPCIONES

-F, --field <clave=valor>
Añade un parámetro de cadena en formato clave=valor, respetando la sintaxis @ (ver "gh help api").
--json
Lee las entradas del flujo de trabajo como JSON a través de STDIN
-f, --raw-field <clave=valor>
Añade un parámetro de cadena en formato clave=valor
-r, --ref <cadena>
Rama o etiqueta que contiene la versión del archivo de flujo de trabajo que desea ejecutar.

OPCIONES HEREDADAS DE COMANDOS PADRE

-R, --repo <[HOST/]PROPIETARIO/REPOSITORIO>
Selecciona otro repositorio usando el formato [HOST/]PROPIETARIO/REPOSITORIO.

CÓDIGOS DE SALIDA

0: Ejecución exitosa

1: Error

2: Comando cancelado

4: Autenticación requerida

NOTA: Los comandos específicos pueden tener códigos de salida adicionales. Consulte la ayuda del comando para obtener más información.

EJEMPLO

# Que gh te pregunte qué flujo de trabajo deseas ejecutar y recopile interactivamente las entradas
$ gh workflow run
# Ejecuta el archivo de flujo de trabajo 'triage.yml' en la rama por defecto del remoto
$ gh workflow run triage.yml
# Ejecuta el archivo de flujo de trabajo 'triage.yml' en una referencia especificada
$ gh workflow run triage.yml --ref mi-rama
# Ejecuta el archivo de flujo de trabajo 'triage.yml' con entradas de línea de comandos
$ gh workflow run triage.yml -f name=scully -f greeting=hello
# Ejecuta el archivo de flujo de trabajo 'triage.yml' con JSON a través de la entrada estándar
$ echo '{"name":"scully", "greeting":"hello"}' | gh workflow run triage.yml --json
