NOMBRE

gh-run-rerun - Volver a ejecutar una ejecución

SINOPSIS

gh run rerun [<id-ejecucion>] [flags]

DESCRIPCIÓN

Vuelve a ejecutar una ejecución completa, solo los trabajos fallidos o un trabajo específico de una ejecución.

Tenga en cuenta que, debido a razones históricas, la bandera --job puede no tomar lo que espera. Específicamente, al navegar a un trabajo en el navegador, la URL se ve así: https://github.com/<propietario>/<repositorio>/actions/runs/<id-ejecucion>/jobs/<numero>.

Sin embargo, este <numero> no debe usarse con la bandera --job y resultará en que la API devuelva 404 NOT FOUND. En su lugar, puede obtener los ID de trabajo correctos utilizando el siguiente comando:

gh run view <id-ejecucion> --json jobs --jq '.jobs[] | {name, databaseId}'

Deberá usar el campo databaseId para activar las re-ejecuciones de trabajos.

OPCIONES

-d, --debug
Vuelve a ejecutar con registro de depuración.
--failed
Vuelve a ejecutar solo los trabajos fallidos, incluidas las dependencias.
-j, --job <cadena>
Vuelve a ejecutar un ID de trabajo específico de una ejecución, incluidas las dependencias.

OPCIONES HEREDADAS DE COMANDOS PADRE

-R, --repo <[HOST/]PROPIETARIO/REPOSITORIO>
Selecciona otro repositorio usando el formato [HOST/]PROPIETARIO/REPOSITORIO.

CÓDIGOS DE SALIDA

0: Ejecución exitosa

1: Error

2: Comando cancelado

4: Autenticación requerida

NOTA: Los comandos específicos pueden tener códigos de salida adicionales. Consulte la ayuda del comando para obtener más información.
