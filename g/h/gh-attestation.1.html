NOMBRE

gh-attestation - Trabajar con atestaciones de artefactos

SINOPSIS

gh attestation [subcomando] [flags]

DESCRIPCIÓN

Descarga y verifica atestaciones de artefactos.

COMANDOS DISPONIBLES

gh-attestation-download(1)
Descarga atestaciones de un artefacto para uso sin conexión
gh-attestation-trusted-root(1)
Muestra el contenido de trusted_root.jsonl, probablemente para verificación sin conexión
gh-attestation-verify(1)
Verifica la integridad de un artefacto utilizando atestaciones

ALIAS

gh at

CÓDIGOS DE SALIDA

0: Ejecución exitosa

1: Error

2: Comando cancelado

4: Autenticación requerida

NOTA: Los comandos específicos pueden tener códigos de salida adicionales. Consulte la ayuda del comando para obtener más información.
