NOMBRE

gh-label-list - Listar etiquetas en un repositorio

SINOPSIS

gh label list [flags]

DESCRIPCIÓN

Muestra las etiquetas en un repositorio de GitHub.

Al usar la opción --search, los resultados se ordenan por la mejor coincidencia de la consulta. Este comportamiento no se puede configurar con las opciones --order o --sort.

OPCIONES

-q, --jq <expresión>
Filtrar la salida JSON usando una expresión jq
--json <campos>
Generar salida JSON con los campos especificados
-L, --limit <int> (predeterminado 30)
Número máximo de etiquetas a obtener
--order <cadena> (predeterminado "asc")
Orden de las etiquetas devueltas: {asc|desc}
-S, --search <cadena>
Buscar nombres y descripciones de etiquetas
--sort <cadena> (predeterminado "created")
Ordenar las etiquetas obtenidas: {created|name}
-t, --template <cadena>
Formatear la salida JSON usando una plantilla Go; véase "gh help formatting"
-w, --web
Abrir el navegador web para ver las etiquetas

OPCIONES HEREDADAS DE COMANDOS PADRE

-R, --repo <[HOST/]OWNER/REPO>
Seleccionar otro repositorio usando el formato [HOST/]OWNER/REPO

ALIAS

gh label ls

CAMPOS JSON

color, createdAt, description, id, isDefault, name, updatedAt, url

CÓDIGOS DE SALIDA

0: Ejecución exitosa

1: Error

2: Comando cancelado

4: Autenticación requerida

NOTA: Los comandos específicos pueden tener códigos de salida adicionales. Consulte la ayuda del comando para obtener más información.

EJEMPLO

# Ordenar etiquetas por nombre
$ gh label list --sort name
# Buscar etiquetas con "bug" en el nombre o descripción
$ gh label list --search bug
