NOMBRE

gh-pr-comment - Añadir un comentario a una solicitud de extracción (pull request)

SINOPSIS

gh pr comment [<número> | <url> | <rama>] [flags]

DESCRIPCIÓN

Añade un comentario a una solicitud de extracción de GitHub.

Sin el texto del cuerpo proporcionado a través de flags, el comando solicitará interactivamente el texto del comentario.

OPCIONES

-b, --body <texto>
El texto del cuerpo del comentario
-F, --body-file <archivo>
Leer el texto del cuerpo desde un archivo (usa "-" para leer desde la entrada estándar)
--create-if-none
Crea un nuevo comentario si no se encuentra ninguno. Solo se puede usar con --edit-last
--delete-last
Elimina el último comentario del usuario actual
--edit-last
Edita el último comentario del usuario actual
-e, --editor
Omite las preguntas y abre el editor de texto para escribir el cuerpo
-w, --web
Abre el navegador web para escribir el comentario
--yes
Omite la pregunta de confirmación de eliminación cuando se proporciona --delete-last

OPCIONES HEREDADAS DE COMANDOS PADRE

-R, --repo <[HOST/]PROPIETARIO/REPO>
Selecciona otro repositorio usando el formato [HOST/]PROPIETARIO/REPO

CÓDIGOS DE SALIDA

0: Ejecución exitosa

1: Error

2: Comando cancelado

4: Autenticación requerida

NOTA: Comandos específicos pueden tener códigos de salida adicionales. Consulta la ayuda del comando para más información.

EJEMPLO

$ gh pr comment 13 --body "Hola desde la CLI de GitHub"
