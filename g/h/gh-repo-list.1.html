NOMBRE

gh-repo-list - Lista los repositorios propiedad del usuario u organización

SINOPSIS

gh repo list [<propietario>] [flags]

DESCRIPCIÓN

Lista los repositorios propiedad de un usuario u organización.

Tenga en cuenta que la lista solo incluirá los repositorios propiedad del argumento proporcionado, y las banderas --fork o --source no recorrerán los límites de propiedad. Por ejemplo, al listar las bifurcaciones en una organización, la salida no incluiría las propiedad de usuarios individuales.

OPCIONES

--archived
Mostrar solo repositorios archivados
--fork
Mostrar solo bifurcaciones
-q, --jq <expresión>
Filtrar la salida JSON usando una expresión jq
--json <campos>
Salida JSON con los campos especificados
-l, --language <cadena>
Filtrar por idioma de codificación principal
-L, --limit <int> (predeterminado 30)
Número máximo de repositorios a listar
--no-archived
Omitir repositorios archivados
--source
Mostrar solo no bifurcaciones
-t, --template <cadena>
Formatear la salida JSON usando una plantilla Go; ver "gh help formatting"
--topic <cadenas>
Filtrar por tema
--visibility <cadena>
Filtrar por visibilidad del repositorio: {public|private|internal}

ALIAS

gh repo ls

CAMPOS JSON

archivedAt, assignableUsers, codeOfConduct, contactLinks, createdAt, defaultBranchRef, deleteBranchOnMerge, description, diskUsage, forkCount, fundingLinks, hasDiscussionsEnabled, hasIssuesEnabled, hasProjectsEnabled, hasWikiEnabled, homepageUrl, id, isArchived, isBlankIssuesEnabled, isEmpty, isFork, isInOrganization, isMirror, isPrivate, isSecurityPolicyEnabled, isTemplate, isUserConfigurationRepository, issueTemplates, issues, labels, languages, latestRelease, licenseInfo, mentionableUsers, mergeCommitAllowed, milestones, mirrorUrl, name, nameWithOwner, openGraphImageUrl, owner, parent, primaryLanguage, projects, projectsV2, pullRequestTemplates, pullRequests, pushedAt, rebaseMergeAllowed, repositoryTopics, securityPolicyUrl, squashMergeAllowed, sshUrl, stargazerCount, templateRepository, updatedAt, url, usesCustomOpenGraphImage, viewerCanAdminister, viewerDefaultCommitEmail, viewerDefaultMergeMethod, viewerHasStarred, viewerPermission, viewerPossibleCommitEmails, viewerSubscription, visibility, watchers

CÓDIGOS DE SALIDA

0: Ejecución exitosa

1: Error

2: Comando cancelado

4: Autenticación requerida

NOTA: Los comandos específicos pueden tener códigos de salida adicionales. Consulte la ayuda del comando para obtener más información.
