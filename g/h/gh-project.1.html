GH-PROJECT(1) Manual de la CLI de GitHub GH-PROJECT(1)

NOMBRE

gh-project - Trabajar con Proyectos de GitHub.

SINOPSIS

gh project <comando> [flags]

DESCRIPCIÓN

Trabajar con Proyectos de GitHub.

El ámbito mínimo requerido para el token es: project. Puedes verificar el ámbito de tu token ejecutando gh auth status y añadir el ámbito project ejecutando gh auth refresh -s project.

COMANDOS DISPONIBLES

gh-project-close(1)
Cerrar un proyecto
gh-project-copy(1)
Copiar un proyecto
gh-project-create(1)
Crear un proyecto
gh-project-delete(1)
Eliminar un proyecto
gh-project-edit(1)
Editar un proyecto
gh-project-field-create(1)
Crear un campo en un proyecto
gh-project-field-delete(1)
Eliminar un campo en un proyecto
gh-project-field-list(1)
Listar los campos en un proyecto
gh-project-item-add(1)
Añadir una solicitud de extracción o un problema a un proyecto
gh-project-item-archive(1)
Archivar un elemento en un proyecto
gh-project-item-create(1)
Crear un elemento de borrador de problema en un proyecto
gh-project-item-delete(1)
Eliminar un elemento de un proyecto por ID
gh-project-item-edit(1)
Editar un elemento en un proyecto
gh-project-item-list(1)
Listar los elementos en un proyecto
gh-project-link(1)
Vincular un proyecto a un repositorio o un equipo
gh-project-list(1)
Listar los proyectos de un propietario
gh-project-mark-template(1)
Marcar un proyecto como plantilla
gh-project-unlink(1)
Desvincular un proyecto de un repositorio o un equipo
gh-project-view(1)
Ver un proyecto

CÓDIGOS DE_SALIDA

0: Ejecución exitosa

1: Error

2: Comando cancelado

4: Autenticación requerida

NOTA: Los comandos específicos pueden tener códigos de salida adicionales. Consulta la ayuda del comando para obtener más información.

EJEMPLO

$ gh project create --owner monalisa --title "Roadmap"
$ gh project view 1 --owner cli --web
$ gh project field-list 1 --owner cli
$ gh project item-list 1 --owner cli
