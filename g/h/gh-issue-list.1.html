NOMBRE

gh-issue-list - Listar incidencias en un repositorio

SINOPSIS

gh issue list [flags]

DESCRIPCIÓN

Lista las incidencias en un repositorio de GitHub. Por defecto, esto solo lista las incidencias abiertas.

La sintaxis de la consulta de búsqueda se documenta aquí:

⟨https://docs.github.com/en/search-github/searching-on-github/searching-issues-and-pull-requests⟩

En hosts de GitHub compatibles, se puede utilizar la sintaxis avanzada de búsqueda de incidencias en la consulta de --search. Para más información sobre la búsqueda avanzada de incidencias, véase:

⟨https://docs.github.com/en/issues/tracking-your-work-with-issues/using-issues/filtering-and-searching-issues-and-pull-requests#building-advanced-filters-for-issues⟩

OPCIONES

--app <string>
Filtrar por autor de la GitHub App
-a, --assignee <string>
Filtrar por asignado
-A, --author <string>
Filtrar por autor
-q, --jq <expresión>
Filtrar la salida JSON usando una expresión jq
--json <campos>
Salida JSON con los campos especificados
-l, --label <cadenas>
Filtrar por etiqueta
-L, --limit <int> (por defecto 30)
Número máximo de incidencias a obtener
--mention <string>
Filtrar por mención
-m, --milestone <string>
Filtrar por número o título de hito
-S, --search <consulta>
Buscar incidencias con consulta
-s, --state <string> (por defecto "open")
Filtrar por estado: {open|closed|all}
-t, --template <string>
Formatear la salida JSON usando una plantilla Go; véase "gh help formatting"
-w, --web
Listar incidencias en el navegador web

OPCIONES HEREDADAS DE COMANDOS PADRE

-R, --repo <[HOST/]OWNER/REPO>
Seleccionar otro repositorio usando el formato [HOST/]OWNER/REPO

ALIAS

gh issue ls

CAMPOS JSON

assignees, author, body, closed, closedAt, closedByPullRequestsReferences, comments, createdAt, id, isPinned, labels, milestone, number, projectCards, projectItems, reactionGroups, state, stateReason, title, updatedAt, url

CÓDIGOS DE SALIDA

0: Ejecución exitosa

1: Error

2: Comando cancelado

4: Autenticación requerida

NOTA: Los comandos específicos pueden tener códigos de salida adicionales. Consulta la ayuda del comando para más información.

EJEMPLO

$ gh issue list --label "bug" --label "help wanted"
$ gh issue list --author monalisa
$ gh issue list --assignee "@me"
$ gh issue list --milestone "The big 1.0"
$ gh issue list --search "error no:assignee sort:created-asc"
$ gh issue list --state all
