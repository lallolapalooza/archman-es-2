NOMBRE

gh-pr-checks - Mostrar estado de CI para una solicitud de extracción única

SINOPSIS

gh pr checks [<número> | <url> | <rama>] [flags]

DESCRIPCIÓN

Mostrar estado de CI para una solicitud de extracción única.

Sin argumento, se selecciona la solicitud de extracción que pertenece a la rama actual.

Cuando se utiliza la bandera --json, incluye un campo bucket, que clasifica el campo state en pass, fail, pending, skipping o cancel.

Códigos de salida adicionales: 8: Chequeos pendientes

OPCIONES

--fail-fast
Salir del modo de observación ante el primer fallo de chequeo
-i, --interval <int> (predeterminado 10)
Intervalo de actualización en segundos en modo de observación
-q, --jq <expresión>
Filtrar la salida JSON usando una expresión jq
--json <campos>
Generar salida JSON con los campos especificados
--required
Mostrar solo los chequeos que son requeridos
-t, --template <cadena>
Formatear la salida JSON usando una plantilla Go; consulte "gh help formatting"
--watch
Observar los chequeos hasta que finalicen
-w, --web
Abrir el navegador web para mostrar detalles sobre los chequeos

OPCIONES HEREDADAS DE COMANDOS PADRE

-R, --repo <[HOST/]PROPIETARIO/REPO>
Seleccionar otro repositorio usando el formato [HOST/]PROPIETARIO/REPO

CAMPOS JSON

bucket, completedAt, description, event, link, name, startedAt, state, workflow

CÓDIGOS DE SALIDA

0: Ejecución exitosa

1: Error

2: Comando cancelado

4: Autenticación requerida

NOTA: Los comandos específicos pueden tener códigos de salida adicionales. Consulte la ayuda del comando para obtener más información.
