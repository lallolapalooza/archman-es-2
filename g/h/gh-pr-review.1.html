NOMBRE

gh-pr-review - Añadir una reseña a una solicitud de extracción (pull request)

SINOPSIS

gh pr review [<número> | <url> | <rama>] [flags]

DESCRIPCIÓN

Añade una reseña a una solicitud de extracción.

Sin argumento, se reseña la solicitud de extracción que pertenece a la rama actual.

OPCIONES

-a, --approve
Aprobar la solicitud de extracción.
-b, --body <cadena>
Especificar el cuerpo de una reseña.
-F, --body-file <archivo>
Leer el texto del cuerpo desde un archivo (usar "-" para leer desde la entrada estándar).
-c, --comment
Comentar en una solicitud de extracción.
-r, --request-changes
Solicitar cambios en una solicitud de extracción.

OPCIONES HEREDADAS DE COMANDOS PADRE

-R, --repo <[HOST/]PROPIETARIO/REPO>
Seleccionar otro repositorio usando el formato [HOST/]PROPIETARIO/REPO.

CÓDIGOS DE SALIDA

0: Ejecución exitosa.

1: Error.

2: Comando cancelado.

4: Se requiere autenticación.

NOTA: Los comandos específicos pueden tener códigos de salida adicionales. Consulte la ayuda del comando para obtener más información.

EJEMPLO

# Aprobar la solicitud de extracción de la rama actual
$ gh pr review --approve
# Dejar un comentario de reseña para la rama actual
$ gh pr review --comment -b "interesante"
# Añadir una reseña para una solicitud de extracción específica
$ gh pr review 123
# Solicitar cambios en una solicitud de extracción específica
$ gh pr review 123 -r -b "necesita más arte ASCII"
