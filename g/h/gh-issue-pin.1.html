NOMBRE

gh-issue-pin - Fijar un issue

SINOPSIS

gh issue pin {<número> | <url>} [flags]

DESCRIPCIÓN

Fija un issue a un repositorio.

El issue puede especificarse por su número o URL.

OPCIONES HEREDADAS DE COMANDOS PADRE

-R, --repo <[HOST/]OWNER/REPO>
Selecciona otro repositorio usando el formato [HOST/]OWNER/REPO

CÓDIGOS DE SALIDA

0: Ejecución exitosa

1: Error

2: Comando cancelado

4: Autenticación requerida

NOTA: Comandos específicos pueden tener códigos de salida adicionales. Consulta la ayuda del comando para más información.

EJEMPLO

# Fijar un issue al repositorio actual
$ gh issue pin 23
# Fijar un issue por URL
$ gh issue pin https://github.com/owner/repo/issues/23
# Fijar un issue a un repositorio específico
$ gh issue pin 23 --repo owner/repo
