NOMBRE

gh-pr-update-branch - Actualizar una rama de solicitud de extracción

SINOPSIS

gh pr update-branch [<número> | <url> | <rama>] [flags]

DESCRIPCIÓN

Actualiza una rama de solicitud de extracción con los últimos cambios de la rama base.

Sin un argumento, se selecciona la solicitud de extracción que pertenece a la rama actual.

El comportamiento predeterminado es actualizar con un commit de fusión (es decir, fusionar la rama base en la rama de la PR). Para conciliar los cambios con la reorganización sobre la rama base, se debe proporcionar la opción --rebase.

OPCIONES

--rebase
Actualizar la rama de la PR reorganizando sobre la última rama base

OPCIONES HEREDADAS DE COMANDOS PADRE

-R, --repo <[HOST/]PROPIETARIO/REPO>
Selecciona otro repositorio usando el formato [HOST/]PROPIETARIO/REPO

CÓDIGOS DE SALIDA

0: Ejecución exitosa

1: Error

2: Comando cancelado

4: Autenticación requerida

NOTA: Los comandos específicos pueden tener códigos de salida adicionales. Consulte la ayuda del comando para obtener más información.

EJEMPLO

$ gh pr update-branch 23
$ gh pr update-branch 23 --rebase
$ gh pr update-branch 23 --repo propietario/repo
