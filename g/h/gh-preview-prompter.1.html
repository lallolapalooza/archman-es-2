NOMBRE

gh-preview-prompter - Ejecuta un programa de prueba para previsualizar el prompt

SINOPSIS

gh preview prompter [tipo de prompt] [opciones]

DESCRIPCIÓN

Ejecuta un programa de prueba para previsualizar el prompt. Sin argumento, se ejecutarán todos los prompts.

Tipos de prompt disponibles: - select - multi-select - input - password - confirm - auth-token - confirm-deletion - input-hostname - markdown-editor

CÓDIGOS DE SALIDA

0: Ejecución exitosa

1: Error

2: Comando cancelado

4: Autenticación requerida

NOTA: Los comandos específicos pueden tener códigos de salida adicionales. Consulte la ayuda del comando para obtener más información.
