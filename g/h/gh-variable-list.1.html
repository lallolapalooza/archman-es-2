NOMBRE

gh-variable-list - Listar variables

SINOPSIS

gh variable list [flags]

DESCRIPCIÓN

Lista variables en uno de los siguientes niveles: - repositorio (por defecto): disponibles para ejecuciones de GitHub Actions o Dependabot en un repositorio - entorno: disponibles para ejecuciones de GitHub Actions para un entorno de despliegue en un repositorio - organización: disponibles para ejecuciones de GitHub Actions o Dependabot dentro de una organización

OPCIONES

-e, --env <string>
Listar variables para un entorno
-q, --jq <expresión>
Filtrar la salida JSON usando una expresión jq
--json <campos>
Emitir JSON con los campos especificados
-o, --org <string>
Listar variables para una organización
-t, --template <string>
Formatear la salida JSON usando una plantilla Go; ver "gh help formatting"

OPCIONES HEREDADAS DE COMANDOS PADRE

-R, --repo <[HOST/]OWNER/REPO>
Seleccionar otro repositorio usando el formato [HOST/]OWNER/REPO

ALIAS

gh variable ls

CAMPOS JSON

createdAt, name, numSelectedRepos, selectedReposURL, updatedAt, value, visibility

CÓDIGOS DE SALIDA

0: Ejecución exitosa

1: Error

2: Comando cancelado

4: Autenticación requerida

NOTA: Los comandos específicos pueden tener códigos de salida adicionales. Consulte la ayuda del comando para más información.
