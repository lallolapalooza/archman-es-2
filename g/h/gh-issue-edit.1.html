NOMBRE

gh-issue-edit - Editar incidencias

SINOPSIS

gh issue edit {<números> | <urls>} [flags]

DESCRIPCIÓN

Edita una o más incidencias dentro del mismo repositorio.

La edición de proyectos de incidencias requiere autorización con el ámbito project. Para autorizar, ejecuta gh auth refresh -s project.

Las banderas --add-assignee y --remove-assignee admiten ambas los siguientes valores especiales: - @me: asignarte o desasignarte a ti mismo - @copilot: asignar o desasignar Copilot (no soportado en GitHub Enterprise Server)

OPCIONES

--add-assignee <login>
Añade usuarios asignados por su nombre de usuario. Usa "@me" para asignarte a ti mismo, o "@copilot" para asignar Copilot.
--add-label <nombre>
Añade etiquetas por nombre
--add-project <título>
Añade la incidencia a proyectos por título
-c, --cuerpo <cadena>
Establece el nuevo cuerpo.
-F, --archivo-cuerpo <archivo>
Lee el texto del cuerpo desde un archivo (usa "-" para leer desde la entrada estándar)
-m, --hito <nombre>
Edita el hito al que pertenece la incidencia por nombre
--remove-assignee <login>
Elimina usuarios asignados por su nombre de usuario. Usa "@me" para desasignarte a ti mismo, o "@copilot" para desasignar Copilot.
--remove-label <nombre>
Elimina etiquetas por nombre
--remove-milestone
Elimina la asociación del hito de la incidencia
--remove-project <título>
Elimina la incidencia de proyectos por título
-t, --título <cadena>
Establece el nuevo título.

OPCIONES HEREDADAS DE COMANDOS PADRE

-R, --repo <[HOST/]PROPIETARIO/REPO>
Selecciona otro repositorio usando el formato [HOST/]PROPIETARIO/REPO

CÓDIGOS DE SALIDA

0: Ejecución exitosa

1: Error

2: Comando cancelado

4: Autenticación requerida

NOTA: Comandos específicos pueden tener códigos de salida adicionales. Consulta la ayuda del comando para más información.

EJEMPLO

$ gh issue edit 23 --title "Encontré un error" --body "Nada funciona"
$ gh issue edit 23 --add-label "bug,help wanted" --remove-label "core"
$ gh issue edit 23 --add-assignee "@me" --remove-assignee monalisa,hubot
$ gh issue edit 23 --add-assignee "@copilot"
$ gh issue edit 23 --add-project "Roadmap" --remove-project v1,v2
$ gh issue edit 23 --milestone "Version 1"
$ gh issue edit 23 --remove-milestone
$ gh issue edit 23 --archivo-cuerpo body.txt
$ gh issue edit 23 34 --add-label "help wanted"
