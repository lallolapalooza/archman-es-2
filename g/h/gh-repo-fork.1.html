NOMBRE

gh-repo-fork - Crear un fork de un repositorio

SINOPSIS

gh repo fork [<repositorio>] [-- <gitflags>...] [flags]

DESCRIPCIÓN

Crea un fork de un repositorio.

Sin argumentos, crea un fork del repositorio actual. De lo contrario, hace un fork del repositorio especificado.

Por defecto, el nuevo fork se establece como tu remoto origin y cualquier remoto origin existente se renombra a upstream. Para modificar este comportamiento, puedes establecer un nombre para el remoto del nuevo fork con --remote-name.

El remoto upstream se establecerá como el repositorio remoto predeterminado.

Se pueden pasar flags adicionales de git clone después de --.

OPCIONES

--clone
Clona el fork
--default-branch-only
Incluye solo la rama predeterminada en el fork
--fork-name <string>
Renombra el repositorio bifurcado
--org <string>
Crea el fork en una organización
--remote
Agrega un remoto git para el fork
--remote-name <string> (por defecto "origin")
Especifica el nombre para el nuevo remoto

CÓDIGOS DE SALIDA

0: Ejecución exitosa

1: Error

2: Comando cancelado

4: Autenticación requerida

NOTA: Comandos específicos pueden tener códigos de salida adicionales. Consulta la ayuda del comando para más información.
