NOMBRE

gh-cache-list - Listar cachés de GitHub Actions

SINOPSIS

gh cache list [flags]

OPCIONES

-q, --jq <expresión>
Filtrar la salida JSON usando una expresión jq
--json <campos>
Mostrar JSON con los campos especificados
-k, --key <cadena>
Filtrar por prefijo de clave de caché
-L, --limit <entero> (por defecto 30)
Número máximo de cachés a obtener
-O, --order <cadena> (por defecto "desc")
Orden de los cachés devueltos: {asc|desc}
-r, --ref <cadena>
Filtrar por ref, formateado como refs/heads/ o refs/pull//merge
-S, --sort <cadena> (por defecto "last_accessed_at")
Ordenar los cachés obtenidos: {created_at|last_accessed_at|size_in_bytes}
-t, --template <cadena>
Formatear la salida JSON usando una plantilla Go; ver "gh help formatting"

OPCIONES HEREDADAS DE COMANDOS PADRE

-R, --repo <[HOST/]OWNER/REPO>
Seleccionar otro repositorio usando el formato [HOST/]OWNER/REPO

ALIAS

gh cache ls

CAMPOS JSON

createdAt, id, key, lastAccessedAt, ref, sizeInBytes, version

CÓDIGOS DE SALIDA

0: Ejecución exitosa

1: Error

2: Comando cancelado

4: Autenticación requerida

NOTA: Comandos específicos pueden tener códigos de salida adicionales. Consultar la ayuda del comando para más información.

EJEMPLO

# Listar cachés para el repositorio actual
$ gh cache list
# Listar cachés para un repositorio específico
$ gh cache list --repo cli/cli
# Listar cachés ordenados por los menos accedidos recientemente
$ gh cache list --sort last_accessed_at --order asc
# Listar cachés cuyas claves coinciden con un prefijo (o coinciden exactamente)
$ gh cache list --key key-prefix
# Listar cachés para una rama específica, reemplaza <nombre-rama> con el nombre real de la rama
$ gh cache list --ref refs/heads/<nombre-rama>
# Listar cachés para una solicitud de extracción específica, reemplaza <número-pr> con el número real de la solicitud de extracción
$ gh cache list --ref refs/pull/<número-pr>/merge
