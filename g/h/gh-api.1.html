NAME

                    
gh-api - interact with GitHub API v3

                

                

                    
SYNOPSIS

                    
gh api <request> [<request>...]

                    
gh api [flags] <request> [<request>...]


                

                

                    
DESCRIPTION

                    
Interact with the GitHub API v3. See https://docs.github.com/en/rest for API documentation.

                    
The API endpoint is determined by the API request string, which is a string like:

                    
"GET /users/{username}/repos"
"POST /repos/{owner}/{repo}/issues"
"PATCH /gists/{gist_id}"
"DELETE /notifications"


                    
The request string can be followed by arguments for placeholders in the path and/or request body.

                    
Arguments are interpreted as path parameters if they are simple values (e.g. username, repo) and as request body parameters if they are JSON objects or arrays.

                    
If the request contains a request body, arguments can be provided in the following formats:

                    
    
                        
  • key=value: Sets the value of a key in the request body.
    • 
                        
  • key=@file: Reads the value of a key from a file.
    • 
                        
  • @file: Reads the entire request body from a file.
    • 
                    

                    
If the request method is GET or HEAD, arguments are appended as query parameters.

                    
If the request method is POST, PUT, or PATCH, arguments are sent as JSON in the request body.

                    
If multiple requests are made, they are executed in sequence.

                    
gh api repos/octocat/Spoon-Knife "GET /repos/{owner}/{repo}/issues" "GET /users/{username}/followers"


                    
The output of each request is printed to stdout as JSON.

                    
Use the --jq flag to process the output with jq.

                    
Use the --include-headers flag to include response headers in the output.

                    
Use the --paginate flag to fetch all pages of results.

                    
Use the --raw flag to print raw response body.

                    
Use the --method flag to specify the HTTP method if it is not obvious from the request string.

                    
Use the --preview flag to enable API previews.

                

                

                    
OPTIONS

                    
-F, --field <[KEY=]VALUE>
    Add field to the request body for POST/PATCH/PUT requests.
-q, --jq <EXPRESSION>
    Filter JSON output using jq syntax.
-H, --header <FIELD:VALUE>
    Add HTTP header to the request.
-i, --include-headers
    Include HTTP response headers in output.
-R, --input <FILE>
    Read request body from file.
-X, --method <METHOD>
    Specify HTTP method (GET, POST, PUT, PATCH, DELETE).
-p, --paginate
    Paginate through results and combine them into a single list.
-r, --raw
    Print raw response body.
-X, --preview <url>
    Enable preview version of the API. The URL is like: "0000-00-00".
-v, --verbose
    Enable verbose output.
--help
    Help for gh api


                

                

                    
EXIT CODES

                    
0 Success, 1 Failure

                

                

                    
EXAMPLE

                    
# List repositories for the authenticated user
$ gh api user/repos

# List repositories for a specific user
$ gh api "GET /users/{username}/repos" username=octocat

# Create a repository
$ gh api repos --method POST -f name=my-new-repo -f description="a repo for testing"

# Get details of a specific issue
$ gh api "GET /repos/{owner}/{repo}/issues/{issue_number}" owner=octocat repo=Spoon-Knife issue_number=1

# Get the number of forks of a repository
$ gh api "GET /repos/{owner}/{repo}" owner=cli repo=cli | jq .forks_count

# Get the number of forks of repositories in an organization
$ gh api "GET /orgs/{org}/repos" org=github | jq 'map(.forks_count) | add'

# Get the percentage of forks in a user's repositories
$ gh api "GET /users/{username}/repos" username=cli --jq 'map(.isFork) | [mul] | add / length'

# Get the percentage of forks in a user's repositories (using select)
$ gh api "GET /users/{username}/repos" username=cli --jq 'map(select(.isFork)) | length as $forks | length as $total | $forks / $total'

# Get the percentage of forks in a user's repositories (using pipes)
$ gh api "GET /users/{username}/repos" username=cli | jq 'map(.isFork) | add / length'

# Get the percentage of forks in a user's repositories (using select and pipes)
$ gh api "GET /users/{username}/repos" username=cli | jq 'map(select(.isFork)) | length as $forks | length as $total | $forks / $total'

# Get the percentage of forks in a user's repositories (using map and select)
$ gh api "GET /users/{username}/repos" username=cli --jq 'map(select(.isFork)) | length as $forks | . | length as $total | $forks / $total'

# Get the percentage of forks in a user's repositories (alternative jq syntax)
$ gh api "GET /users/{username}/repos" username=cli --jq 'map(.isFork) | add / length'

# Get the percentage of forks in a user's repositories (alternative jq syntax with select)
$ gh api "GET /users/{username}/repos" username=cli --jq 'map(select(.isFork)) | length as $forks | length as $total | $forks / $total'

# Get the percentage of forks in a user's repositories (alternative jq syntax with pipes)
$ gh api "GET /users/{username}/repos" username=cli | jq 'map(.isFork) | add / length'

# Get the percentage of forks in a user's repositories (alternative jq syntax with pipes and select)
$ gh api "GET /users/{username}/repos" username=cli | jq 'map(select(.isFork)) | length as $forks | length as $total | $forks / $total'

# Get the percentage of forks in a user's repositories (using count and select)
$ gh api "GET /users/{username}/repos" username=cli --jq 'map(.isFork) | count(select(.==true)) / length'

# Get the percentage of forks in a user's repositories (using count and select with pipes)
$ gh api "GET /users/{username}/repos" username=cli | jq 'map(.isFork) | count(select(.==true)) / length'

# Get the percentage of forks in a user's repositories (using count and select with arrays)
$ gh api "GET /users/{username}/repos" username=cli --jq 'map(.isFork) as $r | count(select($r[].==true)) / count($r[])'
