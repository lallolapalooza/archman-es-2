NOMBRE

gh-secret - Gestionar secretos de GitHub

SINOPSIS

gh secret <comando> [flags]

DESCRIPCIÓN

Los secretos se pueden establecer a nivel de repositorio u organización para su uso en GitHub Actions o Dependabot. Los secretos de usuario, organización y repositorio se pueden establecer para su uso en GitHub Codespaces. Los secretos de entorno se pueden establecer para su uso en GitHub Actions. Ejecuta gh help secret set para aprender cómo empezar.

COMANDOS DISPONIBLES

gh-secret-delete(1)
Eliminar secretos
gh-secret-list(1)
Listar secretos
gh-secret-set(1)
Crear o actualizar secretos

OPCIONES

-R, --repo <[HOST/]PROPIETARIO/REPOSITORIO>
Seleccionar otro repositorio usando el formato [HOST/]PROPIETARIO/REPOSITORIO

CÓDIGOS DE SALIDA

0: Ejecución exitosa

1: Error

2: Comando cancelado

4: Autenticación requerida

NOTA: Los comandos específicos pueden tener códigos de salida adicionales. Consulta la ayuda del comando para obtener más información.
