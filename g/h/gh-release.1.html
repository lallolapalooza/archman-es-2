GH-RELEASE(1) Manual de la CLI de GitHub GH-RELEASE(1)

NOMBRE

gh-release - Gestionar lanzamientos

SINOPSIS

gh release <comando> [flags]

COMANDOS GENERALES

gh-release-create(1)
Crear un nuevo lanzamiento
gh-release-list(1)
Listar lanzamientos en un repositorio

COMANDOS DIRIGIDOS

gh-release-delete(1)
Eliminar un lanzamiento
gh-release-delete-asset(1)
Eliminar un activo de un lanzamiento
gh-release-download(1)
Descargar activos de lanzamientos
gh-release-edit(1)
Editar un lanzamiento
gh-release-upload(1)
Subir activos a un lanzamiento
gh-release-verify(1)
Verificar la atestación para un lanzamiento
gh-release-verify-asset(1)
Verificar que un activo dado se originó en un lanzamiento
gh-release-view(1)
Ver información sobre un lanzamiento

OPCIONES

-R, --repo <[HOST/]OWNER/REPO>
Seleccionar otro repositorio usando el formato [HOST/]OWNER/REPO

CÓDIGOS DE SALIDA

0: Ejecución exitosa

1: Error

2: Comando cancelado

4: Autenticación requerida

NOTA: Comandos específicos pueden tener códigos de salida adicionales. Consulte la ayuda del comando para más información.
