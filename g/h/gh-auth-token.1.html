NOMBRE

gh-auth-token - Imprime el token de autenticación que gh usa para un nombre de host y cuenta

SINOPSIS

gh auth token [banderas]

DESCRIPCIÓN

Este comando muestra el token de autenticación para una cuenta en un host de GitHub dado.

Sin la bandera --hostname, se elige el host predeterminado.

Sin la bandera --user, se elige la cuenta activa para el host.

OPCIONES

-h, --hostname <cadena>
El nombre del host de la instancia de GitHub autenticada con
-u, --user <cadena>
La cuenta para la que se imprimirá el token

CÓDIGOS DE SALIDA

0: Ejecución exitosa

1: Error

2: Comando cancelado

4: Autenticación requerida

NOTA: Los comandos específicos pueden tener códigos de salida adicionales. Consulte la ayuda del comando para obtener más información.
