GH-REPO-CREATE(1) Manual de la CLI de GitHub GH-REPO-CREATE(1)

NOMBRE

gh-repo-create - Crear un nuevo repositorio

SINOPSIS

gh repo create [<nombre>] [flags]

DESCRIPCIÓN

Crea un nuevo repositorio de GitHub.

Para crear un repositorio interactivamente, usa gh repo create sin argumentos.

Para crear un repositorio remoto de forma no interactiva, proporciona el nombre del repositorio y uno de --public, --private o --internal. Pasa --clone para clonar el nuevo repositorio localmente.

Si se omite la porción OWNER/ del argumento de nombre OWNER/REPO, se usará por defecto el nombre del usuario autenticado.

Para crear un repositorio remoto a partir de un repositorio local existente, especifica el directorio de origen con --source. Por defecto, el nombre del repositorio remoto será el nombre del directorio de origen.

Pasa --push para enviar cualquier commit local al nuevo repositorio. Si el repositorio está vacío (bare), esto reflejará todas las referencias.

Para plantillas de .gitignore de lenguaje o plataforma a usar con --gitignore, véase ⟨https://github.com/github/gitignore⟩.

Para palabras clave de licencias a usar con --license, ejecuta gh repo license list o visita ⟨https://choosealicense.com⟩.

El repositorio se crea con la rama por defecto del repositorio configurada, véase ⟨https://docs.github.com/en/account-and-profile/setting-up-and-managing-your-personal-account-on-github/managing-user-account-settings/managing-the-default-branch-name-for-your-repositories⟩.

OPCIONES

--add-readme
Añadir un archivo README al nuevo repositorio
-c, --clone
Clonar el nuevo repositorio en el directorio actual
-d, --description <cadena>
Descripción del repositorio
--disable-issues
Desactivar issues en el nuevo repositorio
--disable-wiki
Desactivar wiki en el nuevo repositorio
-g, --gitignore <cadena>
Especificar una plantilla de gitignore para el repositorio
-h, --homepage <URL>
URL de la página de inicio del repositorio
--include-all-branches
Incluir todas las ramas del repositorio plantilla
--internal
Hacer el nuevo repositorio interno
-l, --license <cadena>
Especificar una Licencia de Código Abierto para el repositorio
--private
Hacer el nuevo repositorio privado
--public
Hacer el nuevo repositorio público
--push
Enviar commits locales al nuevo repositorio
-r, --remote <cadena>
Especificar el nombre del remoto para el nuevo repositorio
-s, --source <cadena>
Especificar la ruta al repositorio local a usar como origen
-t, --team <nombre>
El nombre del equipo de la organización al que se le otorgará acceso
-p, --template <repositorio>
Hacer el nuevo repositorio basado en un repositorio plantilla

ALIAS

gh repo new

CÓDIGOS DE SALIDA

0: Ejecución exitosa

1: Error

2: Comando cancelado

4: Autenticación requerida

NOTA: Comandos específicos pueden tener códigos de salida adicionales. Consulta la ayuda del comando para más información.

EJEMPLO

# Crear un repositorio interactivamente
$ gh repo create
# Crear un nuevo repositorio remoto y clonarlo localmente
$ gh repo create mi-proyecto --public --clone
# Crear un nuevo repositorio remoto en otra organización
$ gh repo create mi-org/mi-proyecto --public
# Crear un repositorio remoto desde el directorio actual
$ gh repo create mi-proyecto --private --source=. --remote=upstream
