NOMBRE

gh-repo-edit - Editar la configuración del repositorio

SINOPSIS

gh repo edit [<repositorio>] [opciones]

DESCRIPCIÓN

Edita la configuración del repositorio.

Para desactivar una opción, utiliza la sintaxis --<opción>=false.

Cambiar la visibilidad del repositorio puede tener consecuencias inesperadas, incluyendo pero no limitándose a:

  • Pérdida de estrellas y observadores, afectando la clasificación del repositorio
  • Desvinculación de bifurcaciones públicas de la red
  • Desactivación de las reglas de inserción (push rulesets)
  • Permitir el acceso al historial y a los registros de GitHub Actions

Cuando se utiliza la opción --visibility, la opción --accept-visibility-change-consequences es obligatoria.

Para obtener información sobre todas las consecuencias posibles, consulta ⟨https://gh.io/setting-repository-visibility⟩.

OPCIONES

--accept-visibility-change-consequences
Acepta las consecuencias de cambiar la visibilidad del repositorio
--add-topic <cadenas>
Añadir tema al repositorio
--allow-forking
Permitir la bifurcación de un repositorio de organización
--allow-update-branch
Permitir que una rama de origen de solicitud de extracción (pull request) que está detrás de su rama base sea actualizada
--default-branch <nombre>
Establecer el nombre de la rama predeterminada para el repositorio
--delete-branch-on-merge
Eliminar la rama de origen cuando se fusionen las solicitudes de extracción
-d, --description <cadena>
Descripción del repositorio
--enable-advanced-security
Habilitar seguridad avanzada en el repositorio
--enable-auto-merge
Habilitar la funcionalidad de fusión automática
--enable-discussions
Habilitar discusiones en el repositorio
--enable-issues
Habilitar incidencias (issues) en el repositorio
--enable-merge-commit
Habilitar la fusión de solicitudes de extracción mediante un commit de fusión
--enable-projects
Habilitar proyectos en el repositorio
--enable-rebase-merge
Habilitar la fusión de solicitudes de extracción mediante rebase
--enable-secret-scanning
Habilitar el escaneo de secretos en el repositorio
--enable-secret-scanning-push-protection
Habilitar la protección de inserción para el escaneo de secretos en el repositorio. El escaneo de secretos debe estar habilitado primero
--enable-squash-merge
Habilitar la fusión de solicitudes de extracción mediante un commit squash
--enable-wiki
Habilitar wiki en el repositorio
-h, --homepage <URL>
URL de la página de inicio del repositorio
--remove-topic <cadenas>
Eliminar tema del repositorio
--template
Hacer que el repositorio esté disponible como repositorio de plantilla
--visibility <cadena>
Cambiar la visibilidad del repositorio a {público,privado,interno}

CÓDIGOS DE SALIDA

0: Ejecución exitosa

1: Error

2: Comando cancelado

4: Autenticación requerida

NOTA: Comandos específicos pueden tener códigos de salida adicionales. Consulte la ayuda del comando para obtener más información.

EJEMPLO

# Habilitar incidencias y wiki
$ gh repo edit --enable-issues --enable-wiki
# Deshabilitar proyectos
$ gh repo edit --enable-projects=false
