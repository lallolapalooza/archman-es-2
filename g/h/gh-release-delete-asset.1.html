GH-RELEASE-DELETE-ASSET(1) Manual de la CLI de GitHub GH-RELEASE-DELETE-ASSET(1)

NOMBRE

gh-release-delete-asset - Elimina un activo de una versión

SINOPSIS

gh release delete-asset <etiqueta> <nombre-del-activo> [banderas]

OPCIONES

-y, --yes
Omite la solicitud de confirmación

OPCIONES HEREDADAS DE COMANDOS PADRE

-R, --repo <[HOST/]PROPIETARIO/REPO>
Selecciona otro repositorio usando el formato [HOST/]PROPIETARIO/REPO

CODIGOS DE SALIDA

0: Ejecución exitosa

1: Error

2: Comando cancelado

4: Autenticación requerida

NOTA: Comandos específicos pueden tener códigos de salida adicionales. Consulta la ayuda del comando para más información.
