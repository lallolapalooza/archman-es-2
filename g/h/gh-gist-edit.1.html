GH-GIST-EDIT(1) Manual de la CLI de GitHub GH-GIST-EDIT(1)

NOMBRE

gh-gist-edit - Edita uno de tus gists

SINOPSIS

gh gist edit {<id> | <url>} [<nombre-archivo>] [flags]

OPCIONES

-a, --add <cadena>
Añade un nuevo archivo al gist
-d, --desc <cadena>
Nueva descripción para el gist
-f, --filename <cadena>
Selecciona un archivo para editar
-r, --remove <cadena>
Elimina un archivo del gist

CODIGOS DE SALIDA

0: Ejecución exitosa

1: Error

2: Comando cancelado

4: Autenticación requerida

NOTA: Los comandos específicos pueden tener códigos de salida adicionales. Consulte la ayuda del comando para más información.
