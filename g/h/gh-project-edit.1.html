NOMBRE

gh-project-edit - Editar un proyecto

SINOPSIS

gh project edit [<número>] [flags]

OPCIONES

-d, --description <cadena>
Nueva descripción del proyecto
--format <cadena>
Formato de salida: {json}
-q, --jq <expresión>
Filtrar la salida JSON usando una expresión jq
--owner <cadena>
Inicio de sesión del propietario. Usa "@me" para el usuario actual.
--readme <cadena>
Nuevo readme para el proyecto
-t, --template <cadena>
Formatear la salida JSON usando una plantilla Go; consulta "gh help formatting"
--title <cadena>
Nuevo título para el proyecto
--visibility <cadena>
Cambiar la visibilidad del proyecto: {PUBLIC|PRIVATE}

CÓDIGOS DE SALIDA

0: Ejecución exitosa

1: Error

2: Comando cancelado

4: Autenticación requerida

NOTA: Comandos específicos pueden tener códigos de salida adicionales. Consulta la ayuda del comando para más información.

EJEMPLO

# Editar el título del proyecto "1" de monalisa
$ gh project edit 1 --owner monalisa --title "Nuevo título"
