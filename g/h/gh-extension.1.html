NOMBRE

gh-extension - Gestionar extensiones de gh

SINOPSIS

gh extension [flags]

DESCRIPCIÓN

Las extensiones de la CLI de GitHub son repositorios que proporcionan comandos adicionales de gh.

El nombre del repositorio de la extensión debe comenzar con gh- y debe contener un ejecutable del mismo nombre. Todos los argumentos pasados a la invocación de gh <nombre_ext> se reenviarán al ejecutable gh-<nombre_ext> de la extensión.

Una extensión no puede sobrescribir ningún comando principal de gh. Si el nombre de una extensión entra en conflicto con un comando principal de gh, puedes usar gh extension exec <nombre_ext>.

Cuando se ejecuta una extensión, gh verificará nuevas versiones una vez cada 24 horas y mostrará un aviso de actualización. Consulta gh help environment para obtener información sobre cómo deshabilitar los avisos de extensión.

Para ver la lista de extensiones disponibles, consulta ⟨https://github.com/topics/gh-extension⟩.

ALIAS

CÓDIGOS DE SALIDA

0: Ejecución exitosa

1: Error

2: Comando cancelado

4: Autenticación requerida
