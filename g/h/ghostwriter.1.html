GHOSTWRITER(1) Manual de usuario de ghostwriter GHOSTWRITER(1)

NOMBRE

ghostwriter - editor de texto sin distracciones para Markdown

SINOPSIS

ghostwriter [ARCHIVO]

DESCRIPCIÓN

ghostwriter es una aplicación de edición de texto en Qt para Markdown que proporciona un entorno de escritura estético y sin distracciones.

Crea tus propios temas personalizados, escribe en modo de pantalla completa o utiliza el modo de enfoque para concentrarte en una o varias líneas.

Una vista previa HTML en vivo te permite ver el formato final mientras escribes. Las opciones de vista previa y exportación HTML son proporcionadas por el procesador Markdown incorporado, cmark-gfm; pero puedes añadir más instalando procesadores Pandoc, MultiMarkdown o cmark. La aplicación los detectará automáticamente si sus ubicaciones están en la variable de entorno PATH del sistema.

OPCIONES

--disable-gpu

Deshabilita la aceleración por GPU.
