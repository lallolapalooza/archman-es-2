GH-EXTENSION-SEARCH(1) Manual de la CLI de GitHub GH-EXTENSION-SEARCH(1)

NOMBRE

gh-extension-search - Buscar extensiones para la CLI de GitHub

SINOPSIS

gh extension search [<consulta>] [flags]

DESCRIPCIÓN

Busca extensiones de gh.

Sin argumentos, este comando imprime las primeras 30 extensiones disponibles para instalar, ordenadas por número de estrellas. Se pueden recuperar más extensiones especificando un límite mayor con la bandera --limit.

Cuando se conecta a una terminal, este comando imprime tres columnas. La primera tiene un ✓ si la extensión ya está instalada localmente. La segunda es el nombre completo del repositorio de la extensión en formato PROPIETARIO/REPOSITORIO. La tercera es la descripción de la extensión.

Cuando no se está conectado a una terminal, el carácter ✓ se renderiza como la palabra "instalada", pero el orden y el contenido de las columnas son los mismos.

Este comando se comporta de manera similar a gh search repos pero no admite tantos calificadores de búsqueda. Para una búsqueda más detallada de extensiones, intente usar:

gh search repos --topic "gh-extension"

y agregue calificadores según sea necesario. Consulte gh help search repos para obtener más información sobre la búsqueda de repositorios.

Para listar solo las extensiones que ya están instaladas localmente, consulte:

gh ext list

OPCIONES

-q, --jq <expresión>
Filtra la salida JSON usando una expresión jq
--json <campos>
Imprime JSON con los campos especificados
--license <cadenas>
Filtra según el tipo de licencia
-L, --limit <entero> (por defecto 30)
Número máximo de extensiones a obtener
--order <cadena> (por defecto "desc")
Orden de los repositorios devueltos, ignorado a menos que se especifique la bandera '--sort': {asc|desc}
--owner <cadenas>
Filtra por propietario
--sort <cadena> (por defecto "best-match")
Ordena los repositorios obtenidos: {forks|help-wanted-issues|stars|updated}
-t, --template <cadena>
Formatea la salida JSON usando una plantilla Go; consulte "gh help formatting"
-w, --web
Abre la consulta de búsqueda en el navegador web

CAMPOS JSON

createdAt, defaultBranch, description, forksCount, fullName, hasDownloads, hasIssues, hasPages, hasProjects, hasWiki, homepage, id, isArchived, isDisabled, isFork, isPrivate, language, license, name, openIssuesCount, owner, pushedAt, size, stargazersCount, updatedAt, url, visibility, watchersCount

CÓDIGOS DE SALIDA

0: Ejecución exitosa

1: Error

2: Comando cancelado

4: Autenticación requerida

NOTA: Los comandos específicos pueden tener códigos de salida adicionales. Consulte la ayuda del comando para obtener más información.

EJEMPLO

# Lista las primeras 30 extensiones ordenadas por recuento de estrellas, descendente
$ gh ext search
# Lista más extensiones
$ gh ext search --limit 300
# Lista extensiones que coinciden con el término "branch"
$ gh ext search branch
# Lista extensiones propiedad de la organización "github"
$ gh ext search --owner github
# Lista extensiones, ordenando por actualización reciente, ascendente
$ gh ext search --sort updated --order asc
# Lista extensiones, filtrando por licencia
$ gh ext search --license MIT
# Abre los resultados de búsqueda en el navegador
$ gh ext search -w
