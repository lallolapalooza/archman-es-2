NOMBRE

gh-repo-rename - Renombrar un repositorio

SINOPSIS

gh repo rename [<nuevo-nombre>] [flags]

DESCRIPCIÓN

Renombra un repositorio de GitHub.

<nuevo-nombre> es el nombre de repositorio deseado sin el propietario.

Por defecto, se renombra el repositorio actual. De lo contrario, se renombra el repositorio especificado con --repo.

Para transferir la propiedad del repositorio a otra cuenta de usuario o organización, debes seguir pasos adicionales en github.com.

Para más información sobre la transferencia de propiedad de repositorios, ver:

⟨https://docs.github.com/en/repositories/creating-and-managing-repositories/transferring-a-repository⟩

OPCIONES

-R, --repo <[HOST/]PROPIETARIO/REPO>
Selecciona otro repositorio usando el formato [HOST/]PROPIETARIO/REPO
-y, --yes
Omite la solicitud de confirmación

CÓDIGOS DE SALIDA

0: Ejecución exitosa

1: Error

2: Comando cancelado

4: Autenticación requerida

NOTA: Comandos específicos pueden tener códigos de salida adicionales. Consulta la ayuda del comando para más información.

EJEMPLO

# Renombrar el repositorio actual (foo/bar -> foo/baz)
$ gh repo rename baz
# Renombrar el repositorio especificado (qux/quux -> qux/baz)
$ gh repo rename -R qux/quux baz
