NOMBRE

gh-variable - Gestionar variables de GitHub Actions

SINOPSIS

gh variable <comando> [flags]

DESCRIPCIÓN

Las variables se pueden establecer a nivel de repositorio, entorno u organización para su uso en GitHub Actions o Dependabot. Ejecute gh help variable set para aprender cómo empezar.

COMANDOS DISPONIBLES

gh-variable-delete(1)
Eliminar variables
gh-variable-get(1)
Obtener variables
gh-variable-list(1)
Listar variables
gh-variable-set(1)
Crear o actualizar variables

OPCIONES

-R, --repo <[HOST/]PROPIETARIO/REPO>
Seleccionar otro repositorio usando el formato [HOST/]PROPIETARIO/REPO

CÓDIGOS DE SALIDA

0: Ejecución exitosa

1: Error

2: Comando cancelado

4: Autenticación requerida

NOTA: Los comandos específicos pueden tener códigos de salida adicionales. Consulte la ayuda del comando para obtener más información.
