NOMBRE

gh-repo-sync - Sincronizar un repositorio

SINOPSIS

gh repo sync [<repositorio-destino>] [flags]

DESCRIPCIÓN

Sincroniza el repositorio de destino desde el repositorio de origen. La sincronización utiliza la rama predeterminada del repositorio de origen para actualizar la rama correspondiente en el repositorio de destino para que sean iguales. Se utilizará una actualización de avance rápido, excepto cuando se especifique la bandera --force, en cuyo caso las dos ramas se sincronizarán mediante un restablecimiento forzado.

Sin un argumento, se selecciona el repositorio local como repositorio de destino.

El repositorio de origen es el padre del repositorio de destino por defecto. Esto se puede anular con la bandera --source.

OPCIONES

-b, --branch <cadena>
Rama a sincronizar (predeterminada [rama predeterminada])
--force
Restablece forzadamente la rama del repositorio de destino para que coincida con el repositorio de origen.
-s, --source <cadena>
Repositorio de origen

CÓDIGOS DE SALIDA

0: Ejecución exitosa

1: Error

2: Comando cancelado

4: Autenticación requerida

NOTA: Los comandos específicos pueden tener códigos de salida adicionales. Consulte la ayuda del comando para obtener más información.

EJEMPLO

# Sincronizar repositorio local desde el padre remoto
$ gh repo sync
# Sincronizar repositorio local desde el padre remoto en una rama específica
$ gh repo sync --branch v1
# Sincronizar fork remoto desde su padre
$ gh repo sync owner/cli-fork
# Sincronizar repositorio remoto desde otro repositorio remoto
$ gh repo sync owner/repo --source owner2/repo2
