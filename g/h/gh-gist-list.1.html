NOMBRE

gh-gist-list - Lista tus gists

SINOPSIS

gh gist list [flags]

DESCRIPCIÓN

Lista los gists de tu cuenta de usuario.

Puedes usar una expresión regular para filtrar la descripción, los nombres de archivo o incluso el contenido de los archivos en el gist usando --filter.

Para la sintaxis de expresiones regulares soportadas, consulta ⟨https://pkg.go.dev/regexp/syntax⟩.

Usa --include-content para incluir el contenido de los archivos, teniendo en cuenta que esto será más lento y aumentará el límite de tasa de uso. En lugar de imprimir una tabla, se imprimirá código con resaltados similares a gh search code:

{{ID del gist}} {{nombre del archivo}}
    {{descripción}}
        {{líneas coincidentes del contenido}}

No se imprime ningún resaltado ni otro color cuando la salida se redirige.

OPCIONES

--filter <expresión>
Filtra los gists usando una expresión regular
--include-content
Incluye el contenido de los archivos de los gists al filtrar
-L, --limit <int> (predeterminado 10)
Número máximo de gists a obtener
--public
Muestra solo gists públicos
--secret
Muestra solo gists secretos

ALIAS

gh gist ls

CÓDIGOS DE SALIDA

0: Ejecución exitosa

1: Error

2: Comando cancelado

4: Autenticación requerida

NOTA: Los comandos específicos pueden tener códigos de salida adicionales. Consulta la ayuda del comando para obtener más información.

EJEMPLO

# Lista todos los gists secretos de tu cuenta de usuario
$ gh gist list --secret
# Encuentra todos los gists de tu cuenta de usuario que mencionan "octo" en cualquier lugar
$ gh gist list --filter octo --include-content
