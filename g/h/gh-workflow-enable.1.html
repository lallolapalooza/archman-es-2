NOMBRE

gh-workflow-enable - Habilitar un flujo de trabajo

SINOPSIS

gh workflow enable [<id-del-flujo-de-trabajo> | <nombre-del-flujo-de-trabajo>] [flags]

DESCRIPCIÓN

Habilita un flujo de trabajo, permitiendo que se ejecute y que aparezca al listar los flujos de trabajo.

OPCIONES HEREDADAS DE COMANDOS PADRE

-R, --repo <[HOST/]PROPIETARIO/REPO>
Selecciona otro repositorio usando el formato [HOST/]PROPIETARIO/REPO

CÓDIGOS DE SALIDA

0: Ejecución exitosa

1: Error

2: Comando cancelado

4: Autenticación requerida

NOTA: Comandos específicos pueden tener códigos de salida adicionales. Consulta la ayuda del comando para más información.
