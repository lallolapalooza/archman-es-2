NOMBRE

gh-release-verify-asset - Verificar que un activo dado se originó en una versión

SINOPSIS

gh release verify-asset [<etiqueta>] <ruta-archivo> [flags]

DESCRIPCIÓN

Verifica que un archivo de activo dado se originó en una Versión de GitHub específica utilizando las atestaciones firmadas criptográficamente.

Una atestación es una afirmación hecha por GitHub con respecto a una versión y sus activos.

Este comando comprueba que el activo que proporcionas coincide con una atestación válida para la versión especificada (o la última versión, si no se proporciona etiqueta).

Asegura la integridad del activo validando que el resumen del activo coincide con el sujeto en la atestación y que la atestación está asociada con la versión.

OPCIONES

--format <cadena>
Formato de salida: {json}
-q, --jq <expresión>
Filtrar la salida JSON usando una expresión jq
-t, --template <cadena>
Formatear la salida JSON usando una plantilla Go; ver "gh help formatting"

OPCIONES HEREDADAS DE COMANDOS PADRE

-R, --repo <[HOST/]PROPIETARIO/REPO>
Selecciona otro repositorio usando el formato [HOST/]PROPIETARIO/REPO

CÓDIGOS DE SALIDA

0: Ejecución exitosa

1: Error

2: Comando cancelado

4: Autenticación requerida

NOTA: Comandos específicos pueden tener códigos de salida adicionales. Consulta la ayuda del comando para más información.

EJEMPLO

# Verificar un activo de la última versión
$ gh release verify-asset ./dist/mi-activo.zip
# Verificar un activo de una etiqueta de versión específica
$ gh release verify-asset v1.2.3 ./dist/mi-activo.zip
# Verificar un activo de una etiqueta de versión específica y mostrar la atestación en formato JSON
$ gh release verify-asset v1.2.3 ./dist/mi-activo.zip --format json
