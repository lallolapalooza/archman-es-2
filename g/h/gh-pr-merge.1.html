NOMBRE

gh-pr-merge - Fusionar una solicitud de extracción

SINOPSIS

gh pr merge [<número> | <url> | <rama>] [flags]

DESCRIPCIÓN

Fusiona una solicitud de extracción en GitHub.

Sin un argumento, se selecciona la solicitud de extracción que pertenece a la rama actual.

Cuando se apunta a una rama que requiere una cola de fusión, no se necesita una estrategia de fusión. Si las verificaciones requeridas aún no han pasado, se habilitará la fusión automática. Si las verificaciones requeridas han pasado, la solicitud de extracción se agregará a la cola de fusión. Para omitir una cola de fusión y fusionar directamente, pase el flag --admin.

OPCIONES

--admin
Utilizar privilegios de administrador para fusionar una solicitud de extracción que no cumple los requisitos.
-A, --author-email <texto>
Texto del correo electrónico para el autor del commit de fusión.
--auto
Fusionar automáticamente solo después de que se cumplan los requisitos necesarios.
-b, --body <texto>
Texto del cuerpo para el commit de fusión.
-F, --body-file <archivo>
Leer el texto del cuerpo desde un archivo (usar "-" para leer desde la entrada estándar).
-d, --delete-branch
Eliminar la rama local y remota después de la fusión.
--disable-auto
Deshabilitar la fusión automática para esta solicitud de extracción.
--match-head-commit <SHA>
SHA del commit que la cabeza de la solicitud de extracción debe coincidir para permitir la fusión.
-m, --merge
Fusionar los commits con la rama base.
-r, --rebase
Reorganizar los commits sobre la rama base.
-s, --squash
Comprimir los commits en un solo commit y fusionarlo en la rama base.
-t, --subject <texto>
Texto del asunto para el commit de fusión.

OPCIONES HEREDADAS DE COMANDOS PADRE

-R, --repo <[HOST/]OWNER/REPO>
Seleccionar otro repositorio usando el formato [HOST/]OWNER/REPO.

CÓDIGOS DE SALIDA

0: Ejecución exitosa

1: Error

2: Comando cancelado

4: Autenticación requerida

NOTA: Los comandos específicos pueden tener códigos de salida adicionales. Consulte la ayuda del comando para obtener más información.
