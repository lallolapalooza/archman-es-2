NOMBRE

gh-pr-view - Ver una solicitud de extracción (pull request)

SINOPSIS

gh pr view [<número> | <url> | <rama>] [flags]

DESCRIPCIÓN

Muestra el título, el cuerpo y otra información sobre una solicitud de extracción.

Sin un argumento, se muestra la solicitud de extracción que pertenece a la rama actual.

Con la bandera --web, abre la solicitud de extracción en un navegador web en su lugar.

OPCIONES

-c, --comments
Ver comentarios de la solicitud de extracción
-q, --jq <expresión>
Filtrar la salida JSON usando una expresión jq
--json <campos>
Generar salida JSON con los campos especificados
-t, --template <cadena>
Formatear la salida JSON usando una plantilla Go; ver "gh help formatting"
-w, --web
Abrir una solicitud de extracción en el navegador

OPCIONES HEREDADAS DE COMANDOS PADRE

-R, --repo <[HOST/]PROPIETARIO/REPO>
Seleccionar otro repositorio usando el formato [HOST/]PROPIETARIO/REPO

CAMPOS JSON

additions, assignees, author, autoMergeRequest, baseRefName, baseRefOid, body, changedFiles, closed, closedAt, closingIssuesReferences, comments, commits, createdAt, deletions, files, fullDatabaseId, headRefName, headRefOid, headRepository, headRepositoryOwner, id, isCrossRepository, isDraft, labels, latestReviews, maintainerCanModify, mergeCommit, mergeStateStatus, mergeable, mergedAt, mergedBy, milestone, number, potentialMergeCommit, projectCards, projectItems, reactionGroups, reviewDecision, reviewRequests, reviews, state, statusCheckRollup, title, updatedAt, url

CÓDIGOS DE SALIDA

0: Ejecución exitosa

1: Error

2: Comando cancelado

4: Autenticación requerida

NOTA: Los comandos específicos pueden tener códigos de salida adicionales. Consulte la ayuda del comando para obtener más información.
