NOMBRE

gh-extension-browse - Entra en una interfaz para explorar, añadir y eliminar extensiones

SINOPSIS

gh extension browse [flags]

DESCRIPCIÓN

Este comando se apoderará de tu terminal y ejecutará una interfaz completamente interactiva para explorar, añadir y eliminar extensiones de gh. Se recomienda un ancho de terminal superior a 100 columnas.

Para aprender a controlar esta interfaz, presiona ? después de ejecutar el comando para ver el texto de ayuda.

Presiona q para salir.

Ejecutar este comando con --single-column debería hacer que este comando sea más inteligible para usuarios que dependen de tecnologías de asistencia como lectores de pantalla o zoom alto.

Para una forma más tradicional de descubrir extensiones, consulta:

gh ext search

junto con gh ext install, gh ext remove y gh repo view.

OPCIONES

--debug
Registrar en /tmp/extBrowse-*
-s, --single-column
Renderizar TUI con una sola columna de texto

CÓDIGOS DE SALIDA

0: Ejecución exitosa

1: Error

2: Comando cancelado

4: Autenticación requerida

NOTA: Comandos específicos pueden tener códigos de salida adicionales. Consulta la ayuda del comando para más información.
