NOMBRE

gh-pr-edit - Editar una solicitud de extracción (pull request)

SINOPSIS

gh pr edit [<número> | <url> | <rama>] [flags]

DESCRIPCIÓN

Edita una solicitud de extracción.

Sin argumento, se selecciona la solicitud de extracción que pertenece a la rama actual.

La edición de los proyectos de una solicitud de extracción requiere autorización con el ámbito project. Para autorizar, ejecuta gh auth refresh -s project.

Las banderas --add-assignee y --remove-assignee admiten ambos los siguientes valores especiales: - @me: asignar o desasignar a ti mismo - @copilot: asignar o desasignar a Copilot (no compatible con GitHub Enterprise Server)

Las banderas --add-reviewer y --remove-reviewer no admiten estos valores especiales.

OPCIONES

--add-assignee <login>
Añade usuarios asignados por su nombre de usuario (login). Usa "@me" para asignarte a ti mismo, o "@copilot" para asignar a Copilot.
--add-label <nombre>
Añade etiquetas por nombre.
--add-project <título>
Añade la solicitud de extracción a proyectos por título.
--add-reviewer <login>
Añade revisores por su nombre de usuario (login).
-B, --base <rama>
Cambia la rama base para esta solicitud de extracción.
-b, --body <cadena>
Establece el nuevo cuerpo (descripción).
-F, --body-file <archivo>
Lee el texto del cuerpo desde un archivo (usa "-" para leer desde la entrada estándar).
-m, --milestone <nombre>
Edita el hito (milestone) al que pertenece la solicitud de extracción por nombre.
--remove-assignee <login>
Elimina usuarios asignados por su nombre de usuario (login). Usa "@me" para desasignarte a ti mismo, o "@copilot" para desasignar a Copilot.
--remove-label <nombre>
Elimina etiquetas por nombre.
--remove-milestone
Elimina la asociación del hito de la solicitud de extracción.
--remove-project <título>
Elimina la solicitud de extracción de proyectos por título.
--remove-reviewer <login>
Elimina revisores por su nombre de usuario (login).
-t, --title <cadena>
Establece el nuevo título.

OPCIONES HEREDADAS DE COMANDOS PADRE

-R, --repo <[HOST/]OWNER/REPO>
Selecciona otro repositorio usando el formato [HOST/]OWNER/REPO.

CÓDIGOS DE SALIDA

0: Ejecución exitosa

1: Error

2: Comando cancelado

4: Autenticación requerida

NOTA: Los comandos específicos pueden tener códigos de salida adicionales. Consulta la ayuda del comando para más información.

EJEMPLO

$ gh pr edit 23 --title "Encontré un error" --body "Nada funciona"
$ gh pr edit 23 --add-label "bug,help wanted" --remove-label "core"
$ gh pr edit 23 --add-reviewer monalisa,hubot  --remove-reviewer monalisa/team-name
$ gh pr edit 23 --add-assignee "@me" --remove-assignee monalisa,hubot
$ gh pr edit 23 --add-assignee "@copilot"
$ gh pr edit 23 --add-project "Roadmap" --remove-project v1,v2
$ gh pr edit 23 --milestone "Version 1"
$ gh pr edit 23 --remove-milestone
