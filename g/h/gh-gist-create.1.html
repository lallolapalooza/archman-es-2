NOMBRE

gh-gist-create - Crear un nuevo gist

SINOPSIS

gh gist create [<nombre de archivo>... | <patrón>... | -] [flags]

DESCRIPCIÓN

Crea un nuevo gist de GitHub con el contenido proporcionado.

Los gists se pueden crear a partir de uno o varios archivos. Alternativamente, pasa - como nombre de archivo para leer desde la entrada estándar.

Por defecto, los gists son secretos; usa --public para hacerlos públicamente visibles.

OPCIONES

-d, --desc <cadena>
Una descripción para este gist
-f, --filename <cadena>
Proporciona un nombre de archivo que se utilizará al leer desde la entrada estándar
-p, --public
Lista el gist públicamente (por defecto es "secreto")
-w, --web
Abre el navegador web con el gist creado

ALIAS

gh gist new

CÓDIGOS DE SALIDA

0: Ejecución exitosa

1: Error

2: Comando cancelado

4: Autenticación requerida

NOTA: Los comandos específicos pueden tener códigos de salida adicionales. Consulta la ayuda del comando para más información.

EJEMPLO

# Publicar el archivo 'hello.py' como un gist público
$ gh gist create --public hello.py
# Crear un gist con una descripción
$ gh gist create hello.py -d "mi programa Hola-Mundo en Python"
# Crear un gist que contenga varios archivos
$ gh gist create hello.py world.py cool.txt
# Crear un gist que contenga varios archivos usando patrones
$ gh gist create *.md *.txt artifact.*
# Leer desde la entrada estándar para crear un gist
$ gh gist create -
# Crear un gist a partir de la salida canalizada de otro comando
$ cat cool.txt | gh gist create
