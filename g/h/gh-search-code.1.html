NOMBRE

gh-search-code - Buscar dentro del código

SINOPSIS

gh search code <consulta> [flags]

DESCRIPCIÓN

Busca dentro del código en repositorios de GitHub.

La sintaxis de búsqueda se documenta en:

⟨https://docs.github.com/search-github/searching-on-github/searching-code⟩

Tenga en cuenta que estos resultados de búsqueda son impulsados por lo que ahora es un motor de búsqueda de código de GitHub heredado. Los resultados podrían no coincidir con lo que se ve en github.com, y las nuevas características como la búsqueda con expresiones regulares aún no están disponibles a través de la API de GitHub.

Para obtener más información sobre cómo manejar consultas de búsqueda que contienen un guion, ejecute gh search --help.

OPCIONES

--extension <cadena>
Filtra por extensión de archivo
--filename <cadena>
Filtra por nombre de archivo
-q, --jq <expresión>
Filtra la salida JSON usando una expresión jq
--json <campos>
Muestra salida JSON con los campos especificados
--language <cadena>
Filtra los resultados por idioma
-L, --limit <entero> (por defecto 30)
Número máximo de resultados de código a obtener
--match <cadenas>
Restringe la búsqueda al contenido del archivo o la ruta del archivo: {file|path}
--owner <cadenas>
Filtra por propietario
-R, --repo <cadenas>
Filtra por repositorio
--size <cadena>
Filtra por rango de tamaño, en kilobytes
-t, --template <cadena>
Formatea la salida JSON usando una plantilla Go; consulta "gh help formatting"
-w, --web
Abre la consulta de búsqueda en el navegador web

CAMPOS JSON

path, repository, sha, textMatches, url

CÓDIGOS DE SALIDA

0: Ejecución exitosa

1: Error

2: Comando cancelado

4: Autenticación requerida

NOTA: Los comandos específicos pueden tener códigos de salida adicionales. Consulta la ayuda del comando para obtener más información.

EJEMPLO

# Buscar código que coincida con "react" y "lifecycle"
$ gh search code react lifecycle
# Buscar código que coincida con "error handling"
$ gh search code "error handling"
# Buscar código que coincida con "deque" en archivos Python
$ gh search code deque --language=python
# Buscar código que coincida con "cli" en repositorios de la organización microsoft
$ gh search code cli --owner=microsoft
# Buscar código que coincida con "panic" en el repositorio de GitHub CLI
$ gh search code panic --repo cli/cli
# Buscar código que coincida con la palabra clave "lint" en archivos package.json
$ gh search code lint --filename package.json
