NOMBRE

gh-agent-task-create - Crear una tarea de agente (vista previa)

SINOPSIS

gh agent-task create [<descripción de la tarea>] [flags]

OPCIONES

-b, --base <cadena>
Rama base para la solicitud de extracción (usa la rama predeterminada si no se proporciona)
-a, --custom-agent <cadena>
Usar un agente personalizado para la tarea. por ejemplo, usa 'mi-agente' para el agente 'mi-agente.md'
--follow
Seguir los registros de la sesión del agente
-F, --from-file <archivo>
Leer la descripción de la tarea desde un archivo (usa "-" para leer desde la entrada estándar)
-R, --repo <[HOST/]PROPIETARIO/REPO>
Seleccionar otro repositorio usando el formato [HOST/]PROPIETARIO/REPO

CÓDIGOS DE SALIDA

0: Ejecución exitosa

1: Error

2: Comando cancelado

4: Autenticación requerida

NOTA: Los comandos específicos pueden tener códigos de salida adicionales. Consulte la ayuda del comando para obtener más información.

EJEMPLO

# Crear una tarea desde una descripción en línea
$ gh agent-task create "constrúyeme una nueva aplicación"
# Crear una tarea desde una descripción en línea y seguir los registros
$ gh agent-task create "constrúyeme una nueva aplicación" --follow
# Crear una tarea desde un archivo
$ gh agent-task create -F task-desc.md
# Crear una tarea con el enunciado del problema desde stdin
$ echo "constrúyeme una nueva aplicación" | gh agent-task create -F -
# Crear una tarea con un editor
$ gh agent-task create
# Crear una tarea con un editor y un archivo como plantilla
$ gh agent-task create -F task-desc.md
# Seleccionar una rama base diferente para la PR
$ gh agent-task create "corregir errores" --base branch
# Crear una tarea usando el agente personalizado definido en '.github/agents/my-agent.md'
$ gh agent-task create "constrúyeme una nueva aplicación" --custom-agent my-agent
