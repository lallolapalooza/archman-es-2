NOMBRE

gh-repo-autolink - Gestionar referencias de autolink

SINOPSIS

gh repo autolink <comando> [flags]

DESCRIPCIÓN

Los autolinks vinculan incidencias, solicitudes de extracción, mensajes de confirmación y descripciones de lanzamientos a servicios externos de terceros.

Los autolinks requieren el rol de admin para ser vistos o gestionados.

Para más información, véase ⟨https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/managing-repository-settings/configuring-autolinks-to-reference-external-resources⟩

COMANDOS DISPONIBLES

gh-repo-autolink-create(1)
Crear una nueva referencia de autolink
gh-repo-autolink-delete(1)
Eliminar una referencia de autolink
gh-repo-autolink-list(1)
Listar referencias de autolink para un repositorio de GitHub
gh-repo-autolink-view(1)
Ver una referencia de autolink

OPCIONES

-R, --repo <[HOST/]PROPIETARIO/REPO>
Seleccionar otro repositorio usando el formato [HOST/]PROPIETARIO/REPO

CÓDIGOS DE_SALIDA

0: Ejecución exitosa

1: Error

2: Comando cancelado

4: Autenticación requerida

NOTA: Los comandos específicos pueden tener códigos de salida adicionales. Consulte la ayuda del comando para más información.
