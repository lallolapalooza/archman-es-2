NOMBRE

gh-issue-develop - Gestionar ramas enlazadas para un issue

SINOPSIS

gh issue develop {<número> | <url>} [flags]

DESCRIPCIÓN

Gestiona ramas enlazadas para un issue.

Al usar la bandera --base, la nueva rama de desarrollo se creará a partir de la rama remota especificada. La nueva rama se configurará como la rama base para las solicitudes de extracción creadas usando gh pr create.

OPCIONES

-b, --base <cadena>
Nombre de la rama remota de la cual deseas crear tu nueva rama
--branch-repo <cadena>
Nombre o URL del repositorio donde deseas crear tu nueva rama
-c, --checkout
Seleccionar la rama después de crearla
-l, --list
Listar ramas enlazadas para el issue
-n, --name <cadena>
Nombre de la rama a crear

OPCIONES HEREDADAS DE COMANDOS PADRE

-R, --repo <[HOST/]PROPIETARIO/REPOSITORIO>
Seleccionar otro repositorio usando el formato [HOST/]PROPIETARIO/REPOSITORIO

CÓDIGOS DE SALIDA

0: Ejecución exitosa

1: Error

2: Comando cancelado

4: Autenticación requerida

NOTA: Comandos específicos pueden tener códigos de salida adicionales. Consulta la ayuda del comando para más información.

EJEMPLO

# Listar ramas para el issue 123
$ gh issue develop --list 123
# Listar ramas para el issue 123 en el repositorio cli/cli
$ gh issue develop --list --repo cli/cli 123
# Crear una rama para el issue 123 basada en la rama my-feature
$ gh issue develop 123 --base my-feature
# Crear una rama para el issue 123 y seleccionarla
$ gh issue develop 123 --checkout
# Crear una rama en el repositorio monalisa/cli para el issue 123 en el repositorio cli/cli
$ gh issue develop 123 --repo cli/cli --branch-repo monalisa/cli
