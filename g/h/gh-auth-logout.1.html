NOMBRE

gh-auth-logout - Cerrar sesión de una cuenta de GitHub

SINOPSIS

gh auth logout [flags]

DESCRIPCIÓN

Eliminar la autenticación de una cuenta de GitHub.

Este comando elimina la configuración de autenticación almacenada para una cuenta. La configuración de autenticación solo se elimina localmente.

Este comando no revoca los tokens de autenticación.

Para revocar todos los tokens de autenticación generados por la CLI de GitHub:

1.
Visita ⟨https://github.com/settings/applications⟩
2.
Selecciona la aplicación "GitHub CLI"
3.
Selecciona "Revocar Acceso"
4.
Selecciona "Entiendo, revocar acceso"

Nota: este procedimiento revocará todos los tokens de autenticación generados alguna vez por la CLI de GitHub en todos tus dispositivos.

Para más información sobre la revocación de tokens de aplicaciones OAuth, consulta:

⟨https://docs.github.com/en/apps/oauth-apps/using-oauth-apps/reviewing-your-authorized-oauth-apps⟩

OPCIONES

-h, --hostname <string>
El nombre de host de la instancia de GitHub de la que cerrar sesión
-u, --user <string>
La cuenta de la que cerrar sesión

CÓDIGOS DE SALIDA

0: Ejecución exitosa

1: Error

2: Comando cancelado

4: Autenticación requerida

NOTA: Comandos específicos pueden tener códigos de salida adicionales. Consulta la ayuda del comando para más información.

EJEMPLO

# Selecciona qué host y cuenta cerrar sesión a través de un mensaje
$ gh auth logout
# Cierra sesión de un host y cuenta específicos
$ gh auth logout --hostname enterprise.internal --user monalisa
