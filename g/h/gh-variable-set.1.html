NOMBRE

gh-variable-set - Crear o actualizar variables

SINOPSIS

gh variable set <nombre-variable> [flags]

DESCRIPCIÓN

Establece un valor para una variable en uno de los siguientes niveles: - repositorio (predeterminado): disponible para ejecuciones de GitHub Actions o Dependabot en un repositorio - entorno: disponible para ejecuciones de GitHub Actions para un entorno de despliegue en un repositorio - organización: disponible para ejecuciones de GitHub Actions o Dependabot dentro de una organización

La variable de organización puede restringirse opcionalmente para que solo esté disponible para repositorios específicos.

OPCIONES

-b, --body <cadena>
El valor para la variable (se lee de la entrada estándar si no se especifica)
-e, --env <entorno>
Establecer variable de entorno de despliegue
-f, --env-file <archivo>
Cargar nombres y valores de variables desde un archivo con formato dotenv
-o, --org <organización>
Establecer variable de organización
-r, --repos <repositorios>
Lista de repositorios que pueden acceder a una variable de organización
-v, --visibility <cadena> (predeterminado "privado")
Establecer visibilidad para una variable de organización: {todos|privado|seleccionado}

OPCIONES HEREDADAS DE COMANDOS PADRE

-R, --repo <[HOST/]PROPIETARIO/REPO>
Seleccionar otro repositorio usando el formato [HOST/]PROPIETARIO/REPO

CÓDIGOS DE SALIDA

0: Ejecución exitosa

1: Error

2: Comando cancelado

4: Autenticación requerida

NOTA: Comandos específicos pueden tener códigos de salida adicionales. Consulte la ayuda del comando para más información.

EJEMPLO

# Añadir valor de variable para el repositorio actual en un prompt interactivo
$ gh variable set MI_VARIABLE
# Leer valor de variable desde una variable de entorno
$ gh variable set MI_VARIABLE --body "$VALOR_ENTORNO"
# Leer valor de variable desde un archivo
$ gh variable set MI_VARIABLE < miarchivo.txt
# Establecer variable para un entorno de despliegue en el repositorio actual
$ gh variable set MI_VARIABLE --env mi_entorno
# Establecer variable a nivel de organización visible para repositorios públicos y privados
$ gh variable set MI_VARIABLE --org miOrg --visibility all
# Establecer variable a nivel de organización visible para repositorios específicos
$ gh variable set MI_VARIABLE --org miOrg --repos repo1,repo2,repo3
# Establecer múltiples variables importadas desde el archivo ".env"
$ gh variable set -f .env
