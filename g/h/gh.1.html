GH(1) Manual de la CLI de GitHub GH(1)

NOMBRE

gh - CLI de GitHub

SINOPSIS

gh <comando> <subcomando> [flags]

DESCRIPCIÓN

Trabaja sin problemas con GitHub desde la línea de comandos.

COMANDOS PRINCIPALES

gh-auth(1)
Autentica gh y git con GitHub
gh-browse(1)
Abre repositorios, issues, pull requests y más en el navegador
gh-codespace(1)
Conéctate y gestiona codespaces
gh-gist(1)
Gestiona gists
gh-issue(1)
Gestiona issues
gh-org(1)
Gestiona organizaciones
gh-pr(1)
Gestiona pull requests
gh-project(1)
Trabaja con Proyectos de GitHub.
gh-release(1)
Gestiona releases
gh-repo(1)
Gestiona repositorios

COMANDOS DE GITHUB ACTIONS

gh-cache(1)
Gestiona las cachés de GitHub Actions
gh-run(1)
Consulta detalles sobre ejecuciones de flujos de trabajo
gh-workflow(1)
Consulta detalles sobre flujos de trabajo de GitHub Actions

COMANDOS ADICIONALES

gh-agent-task(1)
Trabaja con tareas de agente (vista previa)
gh-alias(1)
Crea atajos de comandos
gh-api(1)
Realiza una solicitud autenticada a la API de GitHub
gh-attestation(1)
Trabaja con las atestaciones de artefactos
gh-completion(1)
Genera scripts de finalización de shell
gh-config(1)
Gestiona la configuración de gh
gh-extension(1)
Gestiona extensiones de gh
gh-gpg-key(1)
Gestiona claves GPG
gh-label(1)
Gestiona etiquetas
gh-preview(1)
Ejecuta vistas previas de funcionalidades de gh
gh-ruleset(1)
Consulta información sobre rulesets de repositorios
gh-search(1)
Busca repositorios, issues y pull requests
gh-secret(1)
Gestiona secretos de GitHub
gh-ssh-key(1)
Gestiona claves SSH
gh-status(1)
Muestra información sobre issues, pull requests y notificaciones relevantes en todos los repositorios
gh-variable(1)
Gestiona variables de GitHub Actions

OPCIONES

--version
Muestra la versión de gh

CÓDIGOS DE SALIDA

0: Ejecución exitosa

1: Error

2: Comando cancelado

4: Autenticación requerida

NOTA: Los comandos específicos pueden tener códigos de salida adicionales. Consulta la ayuda del comando para obtener más información.

EJEMPLO

$ gh issue create
$ gh repo clone cli/cli
$ gh pr checkout 321
