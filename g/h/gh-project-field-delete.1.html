GH-PROJECT-FIELD-DELETE(1) Manual de la CLI de GitHub GH-PROJECT-FIELD-DELETE(1)

NOMBRE

gh-project-field-delete - Elimina un campo en un proyecto

SINOPSIS

gh project field-delete [banderas]

OPCIONES

--format <cadena>
Formato de salida: {json}
--id <cadena>
ID del campo a eliminar
-q, --jq <expresión>
Filtra la salida JSON usando una expresión jq
-t, --template <cadena>
Formatea la salida JSON usando una plantilla Go; consulta "gh help formatting"

CÓDIGOS DE SALIDA

0: Ejecución exitosa

1: Error

2: Comando cancelado

4: Autenticación requerida

NOTA: Los comandos específicos pueden tener códigos de salida adicionales. Consulta la ayuda del comando para más información.
