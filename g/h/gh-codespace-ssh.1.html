NOMBRE

gh-codespace-ssh - Conéctate por SSH a un codespace

SINOPSIS

gh codespace ssh [<opciones>...] [-- <opciones-ssh>...] [<comando>]

DESCRIPCIÓN

El comando ssh se utiliza para conectarse por SSH a un codespace. En su forma más simple, puedes ejecutar gh cs ssh, seleccionar un codespace interactivamente y conectarte.

El comando ssh creará automáticamente un par de claves ssh públicas/privadas en el directorio ~/.ssh si no tienes un par de claves válido existente. Al seleccionar el par de claves a utilizar, el orden preferido es:

1.
Clave especificada por -i en <opciones-ssh>
2.
Clave automática, si ya existe
3.
Primer par de claves válido en la configuración ssh (según ssh -G)
4.
Clave automática, recién creada

El comando ssh también soporta una integración más profunda con OpenSSH utilizando la opción --config que genera una configuración ssh por codespace en formato OpenSSH. Incluir esta configuración en tu ~/.ssh/config mejora la experiencia del usuario de herramientas que se integran con OpenSSH, como la compleción de Bash/Zsh de nombres de host ssh, la compleción de rutas remotas para scp/rsync/sshfs, remotos ssh de git, etc.

Una vez configurado esto (ver el segundo ejemplo a continuación), puedes conectarte por ssh a los codespaces como si fueran hosts remotos ordinarios (usando ssh, no gh cs ssh).

Ten en cuenta que el codespace al que te estás conectando debe tener un servidor SSH preinstalado. Si la imagen docker que se utiliza para el codespace no tiene un servidor SSH, instálalo en tu Dockerfile o, para codespaces que utilizan imágenes basadas en Debian, puedes añadir lo siguiente a tu devcontainer.json:

"features": {
	"ghcr.io/devcontainers/features/sshd:1": {
		"version": "latest"
	}
}

OPCIONES

-c, --codespace <cadena>
Nombre del codespace
--config
Escribe la configuración de OpenSSH en la salida estándar
-d, --debug
Registra datos de depuración en un archivo
--debug-file <cadena>
Ruta del archivo de registro
--profile <cadena>
Nombre del perfil SSH a utilizar
-R, --repo <cadena>
Filtra la selección de codespace por nombre de repositorio (usuario/repo)
--repo-owner <cadena>
Filtra la selección de codespace por propietario del repositorio (nombre de usuario u organización)
--server-port <entero> (predeterminado 0)
Número de puerto del servidor SSH (0 => elegir uno no utilizado)

CÓDIGOS DE SALIDA

0: Ejecución exitosa

1: Error

2: Comando cancelado

4: Autenticación requerida

NOTA: Los comandos específicos pueden tener códigos de salida adicionales. Consulta la ayuda del comando para más información.

EJEMPLO

$ gh codespace ssh
$ gh codespace ssh --config > ~/.ssh/codespaces
$ printf 'Match all\nInclude ~/.ssh/codespaces\n' >> ~/.ssh/config
