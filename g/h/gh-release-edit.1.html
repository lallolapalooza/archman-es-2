GH-RELEASE-EDIT(1) Manual de la CLI de GitHub GH-RELEASE-EDIT(1)

NOMBRE

gh-release-edit - Editar una versión

SINOPSIS

gh release edit <etiqueta>

OPCIONES

--discussion-category <cadena>
Iniciar una discusión en la categoría especificada al publicar un borrador
--draft
Guardar la versión como borrador en lugar de publicarla
--latest
Marcar explícitamente la versión como "La más reciente"
-n, --notes <cadena>
Notas de la versión
-F, --notes-file <archivo>
Leer notas de la versión desde un archivo (usar "-" para leer desde la entrada estándar
--prerelease
Marcar la versión como una versión preliminar
--tag <cadena>
El nombre de la etiqueta
--target <rama>
Rama de destino o SHA del commit completo (rama principal por defecto)
-t, --title <cadena>
Título de la versión
--verify-tag
Abortar en caso de que la etiqueta git no exista ya en el repositorio remoto

OPCIONES HEREDADAS DE COMANDOS PADRE

-R, --repo <[HOST/]PROPIETARIO/REPOSITORIO>
Seleccionar otro repositorio usando el formato [HOST/]PROPIETARIO/REPOSITORIO

CÓDIGOS DE SALIDA

0: Ejecución exitosa

1: Error

2: Comando cancelado

4: Autenticación requerida

NOTA: Comandos específicos pueden tener códigos de salida adicionales. Consulte la ayuda del comando para más información.

EJEMPLO

# Publicar una versión que anteriormente era un borrador
$ gh release edit v1.0 --draft=false
# Actualizar las notas de la versión con el contenido de un archivo
$ gh release edit v1.0 --notes-file /ruta/a/release_notes.md
