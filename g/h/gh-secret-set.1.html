NOMBRE

gh-secret-set - Crear o actualizar secretos

SINOPSIS

gh secret set <nombre-secreto> [banderas]

DESCRIPCIÓN

Establece un valor para un secreto en uno de los siguientes niveles: - repositorio (predeterminado): disponible para ejecuciones de GitHub Actions o Dependabot en un repositorio - entorno: disponible para ejecuciones de GitHub Actions para un entorno de despliegue en un repositorio - organización: disponible para ejecuciones de GitHub Actions, Dependabot o Codespaces dentro de una organización - usuario: disponible para Codespaces para tu usuario

Los secretos de organización y usuario pueden restringirse opcionalmente para que solo estén disponibles para repositorios específicos.

Los valores de los secretos se cifran localmente antes de enviarse a GitHub.

OPCIONES

-a, --app <cadena>
Establece la aplicación para un secreto: {actions|codespaces|dependabot}
-c, --body <cadena>
El valor para el secreto (lee desde la entrada estándar si no se especifica)
-e, --env <entorno>
Establece el secreto del entorno de despliegue
-f, --env-file <archivo>
Carga nombres y valores de secretos desde un archivo con formato dotenv
--no-repos-selected
Ningún repositorio puede acceder al secreto de la organización
--no-store
Imprime el valor cifrado y codificado en base64 en lugar de almacenarlo en GitHub
-o, --org <organización>
Establece el secreto de la organización
-r, --repos <repositorios>
Lista de repositorios que pueden acceder a un secreto de organización o usuario
-u, --user
Establece un secreto para tu usuario
-v, --visibility <cadena> (predeterminado "private")
Establece la visibilidad para un secreto de organización: {all|private|selected}

OPCIONES HEREDADAS DE COMANDOS PADRE

-R, --repo <[HOST/]OWNER/REPO>
Selecciona otro repositorio usando el formato [HOST/]OWNER/REPO

CÓDIGOS DE SALIDA

0: Ejecución exitosa

1: Error

2: Comando cancelado

4: Autenticación requerida

NOTA: Comandos específicos pueden tener códigos de salida adicionales. Consulta la ayuda del comando para más información.

EJEMPLO

# Pega el valor del secreto para el repositorio actual en una solicitud interactiva
$ gh secret set MI_SECRETO
# Lee el valor del secreto desde una variable de entorno
$ gh secret set MI_SECRETO --body "$VALOR_ENV"
# Establece el secreto para un repositorio remoto específico
$ gh secret set MI_SECRETO --repo origin/repo --body "$VALOR_ENV"
# Lee el valor del secreto desde un archivo
$ gh secret set MI_SECRETO < miarchivo.txt
# Establece el secreto para un entorno de despliegue en el repositorio actual
$ gh secret set MI_SECRETO --env mi_entorno
# Establece el secreto a nivel de organización visible para repositorios públicos y privados
$ gh secret set MI_SECRETO --org miOrg --visibility all
# Establece el secreto a nivel de organización visible para repositorios específicos
$ gh secret set MI_SECRETO --org miOrg --repos repo1,repo2,repo3
# Establece el secreto a nivel de organización visible para ningún repositorio
$ gh secret set MI_SECRETO --org miOrg --no-repos-selected
# Establece el secreto a nivel de usuario para Codespaces
$ gh secret set MI_SECRETO --user
# Establece el secreto a nivel de repositorio para Dependabot
$ gh secret set MI_SECRETO --app dependabot
# Establece múltiples secretos importados desde el archivo ".env"
$ gh secret set -f .env
# Establece múltiples secretos desde stdin
$ gh secret set -f - < miarchivo.txt
