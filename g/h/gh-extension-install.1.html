NOMBRE

gh-extension-install - Instala una extensión de gh desde un repositorio

SINOPSIS

gh extension install <repositorio> [flags]

DESCRIPCIÓN

Instala una extensión de GitHub CLI desde un repositorio de GitHub o local.

Para repositorios de GitHub, el argumento del repositorio puede especificarse en formato PROPIETARIO/REPO o como una URL de repositorio completa. El formato URL es útil cuando el repositorio no está alojado en github.com.

Para repositorios remotos, GitHub CLI primero busca los artefactos de la versión asumiendo que es una extensión binaria, es decir, binarios precompilados proporcionados como parte de la versión. En ausencia de una versión, el repositorio en sí se clona asumiendo que es una extensión de script, es decir, un ejecutable precompilado o un script existe en su raíz.

La bandera --pin puede usarse para especificar una etiqueta o commit para extensiones binarias y de script, respectivamente; de lo contrario, se usa la última versión.

Para repositorios locales, a menudo se usan mientras se desarrollan extensiones, utilice . como valor del argumento del repositorio. Tenga en cuenta lo siguiente:

  • Después de instalar una extensión desde un repositorio clonado localmente, GitHub CLI administrará esta extensión como un enlace simbólico (o un mecanismo equivalente en Windows) que apunta a un archivo ejecutable con el mismo nombre que el repositorio en la raíz del repositorio. Por ejemplo, si el repositorio se llama gh-foobar, el enlace simbólico apuntará a gh-foobar en la raíz del repositorio de la extensión.
  • Al ejecutar la extensión, GitHub CLI ejecutará el archivo ejecutable que se encuentra siguiendo el enlace simbólico. Si no se encuentra ningún archivo ejecutable, la extensión fallará al ejecutarse.
  • Si la extensión está precompilada, el archivo ejecutable debe compilarse manualmente y colocarse en la raíz del repositorio.

Para la lista de extensiones disponibles, consulte ⟨https://github.com/topics/gh-extension⟩.

OPCIONES

--force
Forzar la actualización de la extensión, o ignorar si la última ya está instalada
--pin <cadena>
Fijar la extensión a una etiqueta de versión o ref de commit

CÓDIGOS DE SALIDA

0: Ejecución exitosa

1: Error

2: Comando cancelado

4: Autenticación requerida

NOTA: Comandos específicos pueden tener códigos de salida adicionales. Consulte la ayuda del comando para obtener más información.

EJEMPLO

# Instalar una extensión desde un repositorio remoto alojado en GitHub
$ gh extension install owner/gh-extension
# Instalar una extensión desde un repositorio remoto a través de una URL completa
$ gh extension install https://my.ghes.com/owner/gh-extension
# Instalar una extensión desde un repositorio local en el directorio de trabajo actual
$ gh extension install .
