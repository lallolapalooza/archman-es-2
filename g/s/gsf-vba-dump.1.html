NOMBRE

gsf-vba-dump - extraer macros de Visual Basic for Applications

SINOPSIS

gsf-vba-dump [ARCHIVO]...

DESCRIPCIÓN

Esta página del manual documenta brevemente el comando gsf-vba-dump.

Varios formatos de datos binarios de Microsoft, incluyendo Excel (.xls), Word (.doc) y PowerPoint (.ppt) pueden incrustar flujos de código de macros. Estos flujos de macros están en P-code (lenguaje intermedio) compilado desde Visual Basic for Applications (VBA).

La utilidad gsf-vba-dump extrae estos flujos de macros.

ERRORES

La extracción de macros de archivos de Powerpoint (.ppt) aún no se ha implementado.
