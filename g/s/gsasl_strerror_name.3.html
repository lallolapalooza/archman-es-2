NOMBRE

gsasl_strerror_name - Función de la API

SINOPSIS

#include <gsasl.h>

const char * gsasl_strerror_name(int err);

ARGUMENTOS

int err
código de error de libgsasl

DESCRIPCIÓN

Convierte el código de retorno a una cadena legible por humanos que representa el símbolo del código de error en sí. Por ejemplo, gsasl_strerror_name(GSASL_OK) devuelve la cadena "GSASL_OK".

Esta cadena puede ser utilizada para mostrar un mensaje de diagnóstico al usuario.

Esta función es una de las pocas en la biblioteca que puede ser utilizada sin una llamada exitosa a gsasl_init().

Valor de retorno: Devuelve un puntero a una cadena asignada estáticamente que contiene una versión en cadena del código de error err , o NULL si el código de error no es conocido.
