subrutina cgsvj0 (character*1 jobv, integer m, integer n, complex, dimension( lda, * ) a, integer lda, complex, dimension( n ) d, real, dimension( n ) sva, integer mv, complex, dimension( ldv, * ) v, integer ldv, real eps, real sfmin, real tol, integer nsweep, complex, dimension( lwork ) work, integer lwork, integer info)

CGSVJ0 preprocesador para la subrutina cgesvj.

Propósito:

!>
!> CGSVJ0 es llamada desde CGESVJ como preprocesador y ese es su propósito principal.
!> Aplica rotaciones de Jacobi de la misma manera que CGESVJ, pero no verifica la convergencia
!> (criterio de parada). Pocos parámetros de ajuste (marcados con [TP]) están disponibles para el implementador.
!>

Parámetros

JOBV 
!>          JOBV es CHARACTER*1
!>          Especifica si la salida de este procedimiento se utiliza
!>          para calcular la matriz V:
!>          = 'V': el producto de las rotaciones de Jacobi se acumula
!>                 premultiplicando la matriz V de N por N.
!>                (Ver la descripción de V.)
!>          = 'A': el producto de las rotaciones de Jacobi se acumula
!>                 premultiplicando la matriz V de MV por N.
!>                (Ver las descripciones de MV y V.)
!>          = 'N': las rotaciones de Jacobi no se acumulan.
!>

M

!>          M es INTEGER
!>          El número de filas de la matriz de entrada A. M >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz de entrada A.
!>          M >= N >= 0.
!>

A

!>          A es una matriz COMPLEX, de dimensión (LDA,N)
!>          En la entrada, la matriz A de M por N, tal que A*diag(D) representa
!>          la matriz de entrada.
!>          En la salida,
!>          A_salida * diag(D_salida) representa la matriz de entrada A*diag(D)
!>          premultiplicada por una secuencia de rotaciones de Jacobi, donde el
!>          umbral de rotación y el número total de barridos se dan en
!>          TOL y NSWEEP, respectivamente.
!>          (Ver las descripciones de D, TOL y NSWEEP.)
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal de la matriz A. LDA >= max(1,M).
!>

D

!>          D es una matriz COMPLEX, de dimensión (N)
!>          La matriz D acumula los factores de escala de las rotaciones de Jacobi
!>          escaladas complejas.
!>          En la entrada, A*diag(D) representa la matriz de entrada.
!>          En la salida, A_salida*diag(D_salida) representa la matriz de entrada
!>          premultiplicada por una secuencia de rotaciones de Jacobi, donde el
!>          umbral de rotación y el número total de barridos se dan en
!>          TOL y NSWEEP, respectivamente.
!>          (Ver las descripciones de A, TOL y NSWEEP.)
!>

SVA

!>          SVA es una matriz REAL, de dimensión (N)
!>          En la entrada, SVA contiene las normas euclidianas de las columnas de
!>          la matriz A*diag(D).
!>          En la salida, SVA contiene las normas euclidianas de las columnas de
!>          la matriz A_salida*diag(D_salida).
!>

MV

!>          MV es INTEGER
!>          Si JOBV = 'A', entonces MV filas de V se premultiplican por una
!>                           secuencia de rotaciones de Jacobi.
!>          Si JOBV = 'N',   entonces MV no se referencia.
!>

V

!>          V es una matriz COMPLEX, de dimensión (LDV,N)
!>          Si JOBV = 'V' entonces N filas de V se premultiplican por una
!>                           secuencia de rotaciones de Jacobi.
!>          Si JOBV = 'A' entonces MV filas de V se premultiplican por una
!>                           secuencia de rotaciones de Jacobi.
!>          Si JOBV = 'N',   entonces V no se referencia.
!>

LDV

!>          LDV es INTEGER
!>          La dimensión principal de la matriz V, LDV >= 1.
!>          Si JOBV = 'V', LDV >= N.
!>          Si JOBV = 'A', LDV >= MV.
!>

EPS

!>          EPS es REAL
!>          EPS = SLAMCH('Epsilon')
!>

SFMIN

!>          SFMIN es REAL
!>          SFMIN = SLAMCH('Safe Minimum')
!>

TOL

!>          TOL es REAL
!>          TOL es el umbral para las rotaciones de Jacobi. Para un par
!>          A(:,p), A(:,q) de columnas pivote, la rotación de Jacobi se
!>          aplica solo si ABS(COS(angulo(A(:,p),A(:,q)))) > TOL.
!>

NSWEEP

!>          NSWEEP es INTEGER
!>          NSWEEP es el número de barridos de rotaciones de Jacobi a realizar.
!>

WORK

!>          WORK es una matriz COMPLEX, de dimensión (LWORK)
!>

LWORK

!>          LWORK es INTEGER
!>          LWORK es la dimensión de WORK. LWORK >= M.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa.
!>          < 0:  si INFO = -i, entonces el i-ésimo argumento tuvo un valor ilegal.
!>

subroutine gsvj0 (character*1 jobv, integer m, integer n, real, dimension( lda, * ) a, integer lda, real, dimension( n ) d, real, dimension( n ) sva, integer mv, real, dimension( ldv, * ) v, integer ldv, real eps, real sfmin, real tol, integer nsweep, real, dimension( lwork ) work, integer lwork, integer info)


 GSVJ0 pre-processor for the routine ggesvj. 


Purpose:




!>
!> GSVJ0 is called from.’”*&’:GE“*&” as a pre-processor and that is its main
!> purpose. It applies Jacobi rotations in the same way as,’”*&’:GE“*&” does, but
!> it does not check convergence (stopping criterion). Few tuning
!> parameters (marked by [TP]) are available for the implementer.
!> 




Parameters


JOBV

!>          JOBV is CHARACTER*1
!>          Specifies whether the output from this procedure is used
!>          to compute the matrix V:
!>          = 'V': the product of the Jacobi rotations is accumulated
!>                 by postmultiplying the N-by-N array V.
!>                (See the description of V.)
!>          = 'A': the product of the Jacobi rotations is accumulated
!>                 by postmultiplying the MV-by-N array V.
!>                (See the descriptions of MV and V.)
!>          = 'N': the Jacobi rotations are not accumulated.
!> 


M


!>          M is INTEGER
!>          The number of rows of the input matrix A.  M >= 0.
!> 


N


!>          N is INTEGER
!>          The number of columns of the input matrix A.
!>          M >= N >= 0.
!> 


A


!>          A is REAL array, dimension (LDA,N)
!>          On entry, M-by-N matrix A, such that A*diag(D) represents
!>          the input matrix.
!>          On exit,
!>          A_onexit * diag(D_onexit) represents the input matrix A*diag(D)
!>          post-multiplied by a sequence of Jacobi rotations, where the
!>          rotation threshold and the total number of sweeps are given in
!>          TOL and NSWEEP, respectively.
!>          (See the descriptions of D, TOL and NSWEEP.)
!> 


LDA


!>          LDA is INTEGER
!>          The leading dimension of the array A.  LDA >= max(1,M).
!> 


D


!>          D is REAL array, dimension (N)
!>          The array D accumulates the scaling factors from the scaled
!>          Jacobi rotations.
!>          On entry, A*diag(D) represents the input matrix.
!>          On exit, A_onexit*diag(D_onexit) represents the input matrix
!>          post-multiplied by a sequence of Jacobi rotations, where the
!>          rotation threshold and the total number of sweeps are given in
!>          TOL and NSWEEP, respectively.
!>          (See the descriptions of A, TOL and NSWEEP.)
!> 


SVA


!>          SVA is REAL array, dimension (N)
!>          On entry, SVA contains the Euclidean norms of the columns of
!>          the matrix A*diag(D).
!>          On exit, SVA contains the Euclidean norms of the columns of
!>          the matrix A_onexit*diag(D_onexit).
!> 


MV


!>          MV is INTEGER
!>          If JOBV = 'A', then MV rows of V are post-multiplied by a
!>                           sequence of Jacobi rotations.
!>          If JOBV = 'N',   then MV is not referenced.
!> 


V


!>          V is REAL array, dimension (LDV,N)
!>          If JOBV = 'V' then N rows of V are post-multiplied by a
!>                           sequence of Jacobi rotations.
!>          If JOBV = 'A' then MV rows of V are post-multiplied by a
!>                           sequence of Jacobi rotations.
!>          If JOBV = 'N',   then V is not referenced.
!> 


LDV


!>          LDV is INTEGER
!>          The leading dimension of the array V,  LDV >= 1.
!>          If JOBV = 'V', LDV >= N.
!>          If JOBV = 'A', LDV >= MV.
!> 


EPS


!>          EPS is REAL
!>          EPS = DLAMCH('Epsilon')
!> 


SFMIN


!>          SFMIN is REAL
!>          SFMIN = DLAMCH('Safe Minimum')
!> 


TOL


!>          TOL is REAL
!>          TOL is the threshold for Jacobi rotations. For a pair
!>          A(:,p), A(:,q) of pivot columns, the Jacobi rotation is
!>          applied only if ABS(COS(angle(A(:,p),A(:,q)))) > TOL.
!> 


NSWEEP


!>          NSWEEP is INTEGER
!>          NSWEEP is the number of sweeps of Jacobi rotations to be
!>          performed.
!> 


WORK


!>          WORK is REAL array, dimension (LWORK)
!> 


LWORK


!>          LWORK is INTEGER
!>          LWORK is the dimension of WORK. LWORK >= M.
!> 


INFO


!>          INFO is INTEGER
!>          = 0:  successful exit.
!>          < 0:  if INFO = -i, then the i-th argument had an illegal value
!>

 GSVJ0 pre-processor for the routine cgesvj. 


Purpose:




!>
!> GSVJ0 is called from.’”*&’:GE“*&” as a pre-processor and that is its main
!> purpose. It applies Jacobi rotations in the same way as,’”*&’:GE“*&” does, but
!> it does not check convergence (stopping criterion). Few tuning
!> parameters (marked by [TP]) are available for the implementer.
!> 




Parameters


JOBV

!>          JOBV is CHARACTER*1
!>          Specifies whether the output from this procedure is used
!>          to compute the matrix V:
!>          = 'V': the product of the Jacobi rotations is accumulated
!>                 by postmultiplying the N-by-N array V.
!>                (See the description of V.)
!>          = 'A': the product of the Jacobi rotations is accumulated
!>                 by postmultiplying the MV-by-N array V.
!>                (See the descriptions of MV and V.)
!>          = 'N': the Jacobi rotations are not accumulated.
!> 


M


!>          M is INTEGER
!>          The number of rows of the input matrix A.  M >= 0.
!> 


N


!>          N is INTEGER
!>          The number of columns of the input matrix A.
!>          M >= N >= 0.
!> 


A


!>          A is COMPLEX array, dimension (LDA,N)
!>          On entry, M-by-N matrix A, such that A*diag(D) represents
!>          the input matrix.
!>          On exit,
!>          A_onexit * diag(D_onexit) represents the input matrix A*diag(D)
!>          post-multiplied by a sequence of Jacobi rotations, where the
!>          rotation threshold and the total number of sweeps are given in
!>          TOL and NSWEEP, respectively.
!>          (See the descriptions of D, TOL and NSWEEP.)
!> 


LDA


!>          LDA is INTEGER
!>          The leading dimension of the array A.  LDA >= max(1,M).
!> 


D


!>          D is REAL array, dimension (N)
!>          The array D accumulates the scaling factors from the complex scaled
!>          Jacobi rotations.
!>          On entry, A*diag(D) represents the input matrix.
!>          On exit, A_onexit*diag(D_onexit) represents the input matrix
!>          post-multiplied by a sequence of Jacobi rotations, where the
!>          rotation threshold and the total number of sweeps are given in
!>          TOL and NSWEEP, respectively.
!>          (See the descriptions of A, TOL and NSWEEP.)
!> 


SVA


!>          SVA is REAL array, dimension (N)
!>          On entry, SVA contains the Euclidean norms of the columns of
!>          the matrix A*diag(D).
!>          On exit, SVA contains the Euclidean norms of the columns of
!>          the matrix A_onexit*diag(D_onexit).
!> 


MV


!>          MV is INTEGER
!>          If JOBV = 'A', then MV rows of V are post-multiplied by a
!>                           sequence of Jacobi rotations.
!>          If JOBV = 'N',   then MV is not referenced.
!> 


V


!>          V is COMPLEX array, dimension (LDV,N)
!>          If JOBV = 'V' then N rows of V are post-multiplied by a
!>                           sequence of Jacobi rotations.
!>          If JOBV = 'A' then MV rows of V are post-multiplied by a
!>                           sequence of Jacobi rotations.
!>          If JOBV = 'N',   then V is not referenced.
!> 


LDV


!>          LDV is INTEGER
!>          The leading dimension of the array V,  LDV >= 1.
!>          If JOBV = 'V', LDV >= N.
!>          If JOBV = 'A', LDV >= MV.
!> 


EPS


!>          EPS is REAL
!>          EPS = DLAMCH('Epsilon')
!> 


SFMIN


!>          SFMIN is REAL
!>          SFMIN = DLAMCH('Safe Minimum')
!> 


TOL


!>          TOL is REAL
!>          TOL is the threshold for Jacobi rotations. For a pair
!>          A(:,p), A(:,q) of pivot columns, the Jacobi rotation is
!>          applied only if ABS(COS(angle(A(:,p),A(:,q)))) > TOL.
!> 


NSWEEP


!>          NSWEEP is INTEGER
!>          NSWEEP is the number of sweeps of Jacobi rotations to be
!>          performed.
!> 


WORK


!>          WORK is COMPLEX array, dimension (LWORK)
!> 


LWORK


!>          LWORK is INTEGER
!>          LWORK is the dimension of WORK. LWORK >= M.
!> 


INFO


!>          INFO is INTEGER
!>          = 0:  successful exit.
!>          < 0:  if INFO = -i, then the i-th argument had an illegal value
!>

Further Details:


GSVJ0 is used just to enable GESVJ to call a simplified
  version of itself to work on a submatrix of the original matrix.
