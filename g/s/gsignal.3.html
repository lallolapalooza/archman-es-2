gsignal(3) Manual de funciones de biblioteca gsignal(3)

NOMBRE

gsignal, ssignal - sistema de señales de software

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <signal.h>
typedef typeof(void (int))  *sighandler_t;
[[deprecated]] int gsignal(int signum);
[[deprecated]] sighandler_t ssignal(int signum, sighandler_t action);
Requisitos de macro de prueba de características para glibc (ver feature_test_macros(7)):

gsignal(), ssignal():

    Desde glibc 2.19:
        _DEFAULT_SOURCE
    glibc 2.19 y anteriores:
        _SVID_SOURCE

DESCRIPCIÓN

No utilice estas funciones en Linux. Debido a un error histórico, en Linux estas funciones son alias de raise(3) y signal(2), respectivamente.

En otros sistemas, similares a System V, estas funciones implementan señalización de software, completamente independiente de las funciones clásicas de signal(2) y kill(2). La función ssignal() define la acción a tomar cuando se dispara la señal de software con el número signum usando la función gsignal(), y devuelve la acción anterior o SIG_DFL. La función gsignal() hace lo siguiente: si no se especificó ninguna acción (o la acción SIG_DFL) para signum, entonces no hace nada y devuelve 0. Si se especificó la acción SIG_IGN para signum, entonces no hace nada y devuelve 1. De lo contrario, restablece la acción a SIG_DFL y llama a la función de acción con el argumento signum, y devuelve el valor devuelto por esa función. El rango de valores posibles de signum varía (a menudo 1-15 o 1-17).

ATRIBUTOS

Para una explicación de los términos utilizados en esta sección, ver attributes(7).

Interfaz Atributo Valor
gsignal () Seguridad en hilos MT-Safe
ssignal () Seguridad en hilos MT-Safe sigintr

ESTANDARES

Ninguno.

HISTORIA

AIX, DG/UX, HP-UX, SCO, Solaris, Tru64. Se consideran obsoletas en la mayoría de estos sistemas y están rotas en glibc. Algunos sistemas también tienen gsignal_r() y ssignal_r().

VER TAMBIÉN

kill(2), signal(2), raise(3)
