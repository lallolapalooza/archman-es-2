DESCRIPCIÓ

N

gsftopk es un programa que invoca el programa ghostscript gs(1) para renderizar una fuente dada a una resolución dada. Empaqueta los caracteres resultantes en el formato de archivo pk y los escribe en un archivo cuyo nombre se forma a partir del nombre de la fuente y la resolución (redondeada al entero más cercano). La fuente puede estar en cualquier formato aceptable por Ghostscript, incluyendo los archivospfa, .pfb, .gsf, y .ttf

.

Este programa normalmente debería ser llamado por un script, como mktexpk, para crear fuentes bajo

demanda.

gsftopk obtiene los anchos de los caracteres del archivotfm , que debe existir en la ruta de búsqueda estándar. También debe poder encontrar la fuente en un archivo de mapa (como psfonts.map), con el formato de dvips(1)), a menos que se use la opción --mapline. El conjunto de archivos de mapa se da mediante la opción --mapfile, o en los archivos config.ps, $HOME/.dvipsrc, y config.gsftopk (como los usaría dvips -Pgsf

topk).

Los siguientes "especiales" pk se añaden al final del archivo de salida, para proporcionar una comprobación interna del contenido del archivo: "jobname=fuente", "mag=1", "mode=modeless", y "pixels_per_inch=ppp". Esto es de acuerdo con el

Estándar de Direct
orio de TeX (TDS).

CONFIGURACIÓ

N

Para determinar el conjunto de archivos de mapa a usar y la ruta para encontrar archivos PostScript, gsftopk lee, en orden, los archivos config.ps, .dvipsrc, y config.gsftopk. Los archivos config.ps y config.gsftopk se buscan usando la variable de entorno TEXCONFIG, el archivo de configuración de Kpathsea, o las rutas predeterminadas compiladas. El archivo .dvipsrc se busca en el directorio de inicio del

usuario.

Estos archivos están en el mismo formato que para dvips (así como en las mismas ubicaciones). Las entradas usadas por gsftopk son las

siguientes.
H ru
ta
Indica que el archivo de controlador de Ghostscript render.ps y los archivos de encabezado y fuente PostScript deben buscarse usando rut
a.

vo.

Todas las demás entradas se

Esto es similar al manejo de estas opciones al ejecutar dvips -Pgsftopk. Para más detalles, ver el manual de

ERRORE

S

gsftopk a veces tiene problemas con fuentes con caracteres muy complicados (como el Sello de la Universidad de California). Esto se debe a que gsftopk usa el operador charpath para determinar la caja delimitadora de cada carácter. Si el carácter es demasiado complicado, las versiones antiguas de Ghostscript fallan, causando que gsftopk termine con un mensaje de

error
Call to gs
stopped by
signal 10

(El número puede variar de un sistema a otro; corresponde a un error de bus o una violación de segmentación.) La mejor manera de corregir este error es instalar una versión actual de ghostscript. Como alternativa, gsftopk puede ser instruido para usar la caja delimitadora proporcionada con la fuente (si existe) en lugar de encontrar una caja delimitadora para cada carácter. Para hacer esto, incluya la

cadena
/usefon
tbbox t
rue def

en el archivo de mapa de fuentes; p. ej

.,
ucseal "/u
sefontbbox
true def"

Esto no afectará el uso de la fuente por dvi

p
s.
