NOMBRE

gsasl_init - Función de la API

SINOPSIS

#include <gsasl.h>

int gsasl_init(Gsasl ** ctx);

ARGUMENTOS

Gsasl ** ctx
puntero al manejador de libgsasl.

DESCRIPCIÓN

Esta función inicializa libgsasl. El manejador al que apunta ctx es válido para ser usado con otras funciones de libgsasl si esta función se ejecuta con éxito. También registra todos los mecanismos SASL incorporados, usando gsasl_register().

Valor de retorno: GSASL_OK si tiene éxito, de lo contrario GSASL_MALLOC_ERROR.
