NOMBRE

gspath - Utilidad para mostrar información de directorios/rutas estándar

SINOPSIS

gspath

DESCRIPCIÓN

Esta utilidad se puede usar para imprimir un único directorio o ruta para que aplicaciones externas sepan qué rutas está utilizando el sistema GNUstep. Fue escrita para proporcionar información para el paquete GNUstep make.

La utilidad gspath se llama con exactamente un argumento, que determina qué imprime.

Argumentos

Para mostrar la ruta al directorio de configuración para el usuario actual, use el argumento defaults.

Para mostrar la ruta de búsqueda de directorios necesaria para localizar bibliotecas dinámicas, use el argumento libpath.

Para mostrar la ruta de búsqueda de directorios necesaria para localizar programas de línea de comandos, use el argumento path.

Para mostrar el directorio de inicio de GNUstep del usuario actual, use el argumento user.
