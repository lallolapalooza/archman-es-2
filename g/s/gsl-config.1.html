NOMBRE

gsl-config - script para obtener el número de versión y las banderas del compilador de la biblioteca GSL instalada

SINOPSIS

gsl-config [--prefix] [--version] [--libs] [--libs-without-cblas] [--cflags]

DESCRIPCIÓN

gsl-config es una herramienta que se utiliza para configurar y determinar las banderas del compilador y del enlazador que deben usarse para compilar y enlazar programas que utilizan GSL. También se utiliza internamente para las macros .m4 para GNU autoconf que se incluyen con GSL.

OPCIONES

gsl-config acepta las siguientes opciones:

--version
Imprime la versión actualmente instalada de GSL en la salida estándar.
--libs
Imprime las banderas del enlazador necesarias para enlazar un programa de GSL, con cblas
--libs-without-cblas
Imprime las banderas del enlazador necesarias para enlazar un programa de GSL, sin cblas
--cflags
Imprime las banderas del compilador necesarias para compilar un programa de GSL.
--prefix
Muestra el prefijo de instalación de GSL.

VER TAMBIÉN

gtk-config(1), gnome-config(1)
