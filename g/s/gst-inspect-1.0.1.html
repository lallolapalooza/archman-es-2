GStreamer(1) Manual de comandos generales GStreamer(1)

NOMBRE

gst-inspect-1.0 - imprime información sobre un plugin o elemento de GStreamer

SINOPSIS

gst-inspect-1.0 [OPCIÓN...] [PLUGIN|ELEMENTO]

DESCRIPCIÓN

gst-inspect-1.0 es una herramienta que imprime información sobre los GStreamer plugins disponibles, información sobre un plugin particular o información sobre un elemento particular. Cuando se ejecuta sin argumento PLUGIN o ELEMENTO, gst-inspect-1.0 imprimirá una lista de todos los plugins y elementos junto con un resumen. Cuando se ejecuta con un argumento PLUGIN o ELEMENTO, gst-inspect-1.0 imprimirá información sobre ese plugin o elemento.

OPCIONES

gst-inspect-1.0 acepta los siguientes argumentos y opciones:

PLUGIN
Nombre de un plugin
ELEMENTO
Nombre de un elemento
--help
Imprime el resumen de ayuda y las BANDERAS disponibles
--gst-info-mask=FLAGS
Marcas de información de GStreamer para establecer (lista con --help)
-a, --print-all
Imprime todos los plugins y elementos
-b, --print-blacklist
Imprime la lista de archivos en lista negra
--plugin
Lista el contenido del plugin
--types=Elemento/Tipos
Permite inspeccionar solo elementos que coinciden con todos los tipos de elementos filtrados en esta lista separada por barras (´/´). Esos tipos corresponden a lo que también se llama ´klass´, que es una cadena que describe el tipo de elemento, como ´Decoder´, ´Audio´, ´Encoder´, etc. Esta opción implica que solo se imprimirán elementos (no funciones de búsqueda de tipo ni rastreadores).
--exists
Comprueba si el elemento o plugin especificado existe
--atleast-version
Al comprobar si un elemento o plugin existe, también comprueba que su versión sea al menos la versión especificada
-u, --uri-handlers
Imprime los esquemas de URI compatibles, con los elementos que los implementan
--no-colors
Desactiva los colores en la salida. También puedes conseguir lo mismo estableciendo la variable de entorno ´GST_INSPECT_NO_COLORS´ a cualquier valor.
-C, --color
Colorea la salida, incluso cuando no está conectada a una tty.
--print-plugin-auto-install-info
Imprime una lista de características que proporciona el plugin especificado, analizable por máquina. Útil en conexión con mecanismos externos de instalación automática de plugins.
--gst-debug-mask=FLAGS
Marcas de depuración de GStreamer para establecer (lista con --help)
--gst-mask=FLAGS
Marcas de información y depuración de GStreamer para establecer (lista con --help)
--gst-plugin-path=PATH
Añade directorios separados por ':' a la ruta de búsqueda de plugins

VARIABLES DE ENTORNO

gst-inspect-1.0 lee las siguientes variables de entorno, además de las variables genéricas de entorno de GStreamer también descritas en gst-launch-1.0(1):

GST_LESS
Sobrescribe las opciones pasadas a less (por defecto "RXF").
Consulta less(1) para más información.

VER TAMBIÉN

gst-launch-1.0(1), gst-typefind-1.0(1)
