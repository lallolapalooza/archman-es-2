NOMBRE

gsasl_saslprep - función de la API

SINOPSIS

#include <gsasl.h>

int gsasl_saslprep(const char * in, Gsasl_saslprep_flags flags, char ** out, int * stringpreprc);

ARGUMENTOS

const char * in
una cadena codificada en UTF-8.
Gsasl_saslprep_flags flags
cualquier indicador de SASLprep, p.ej., GSASL_ALLOW_UNASSIGNED.
char ** out
a la salida, contendrá la cadena de salida recién asignada.
int * stringpreprc
si no es NULL, contendrá el código de retorno preciso de stringprep.

DESCRIPCIÓN

Prepara una cadena usando SASLprep. En caso de éxito, la variable out debe ser liberada por el llamador.

Valor de retorno: Devuelve GSASL_OK en caso de éxito, o GSASL_SASLPREP_ERROR en caso de error.
