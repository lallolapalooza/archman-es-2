GS-MOUNT(1) Manual de Comandos Generales GS-MOUNT(1)

NOMBRE

gs-mount — Cliente de sistema de archivos seguro a través de Global Socket.

SINOPSIS

gs-mount [-lTR] [-s secreto] [-k archivo_clave] [punto_montaje]

DESCRIPCIÓN

La utilidad gs-mount es un script envoltorio para gs-netcat. Permite a un usuario montar y acceder a un sistema de archivos de otro usuario a través de la Red Global de Relevo de Sockets (GSRN). Esto es útil en un escenario donde ambos usuarios están detrás de NAT/Firewall y no pueden conectarse entre sí directamente.

OPCIONES

-s secreto
Una contraseña elegida por el usuario. Ambos usuarios deben usar la misma contraseña para conectarse.
-k ARCHIVO
Un archivo que contiene la contraseña.
-l
Modo servidor. El modo predeterminado es cliente.
-R
Coloca el servidor (-l) en modo de solo lectura. Los intentos de abrir archivos para escritura, así como otras operaciones que cambian el estado del sistema de archivos, serán denegados.
-T
Usar TOR. La herramienta gs-mount se conectará a través de TOR a la GSRN. Esto requiere que TOR esté instalado y en ejecución. La IP y el PUERTO del servidor TOR se pueden establecer utilizando variables de entorno.

Ver gs-netcat(1) para más opciones.

EJEMPLOS

Ejemplo 1 - Alice compartiendo su directorio actual:

$ gs-mount -s MiSecreto -l

Bob montando el directorio de Alice en ~/gs-alice:

$ gs-mount -s MiSecreto ~/gs-alice

AMBIENTE

Ver gs-netcat(1) para una lista de variables de entorno admitidas.

VER TAMBIÉN

gsocket(1), gs-netcat(1), gs-sftp(1), blitz(1), sshfs(1)

ERRORES

Se han hecho esfuerzos para que gs-mount "haga lo correcto" en todos sus diversos modos. Si cree que está haciendo lo incorrecto bajo cualquier circunstancia, por favor notifíqueme (skyper@thc.org) y dígame cómo cree que debería comportarse.
