GS-SFTP(1) Manual de Comandos Generales GS-SFTP(1)

NOMBRE

gs-sftp — Protocolo Seguro de Transferencia de Archivos a través de Socket Global.

SINOPSIS

gs-sftp [-lTR] [-s secreto] [-k archivo_clave]

DESCRIPCIÓN

La utilidad gs-sftp es un script envoltorio para gs-netcat. Permite a dos usuarios establecer una conexión SFTP segura a través de la Red Global de Relevo de Sockets (GSRN). Esto es útil en un escenario donde ambos usuarios están detrás de NAT/Firewall y no pueden conectarse entre sí directamente.

OPCIONES

-s secreto
Una contraseña elegida por el usuario. Ambos usuarios deben usar la misma contraseña para conectarse.
-k ARCHIVO
Un archivo que contiene la contraseña.
-l
Modo servidor. El modo predeterminado es cliente.
-R
Pone al servidor (-l) en modo de solo lectura. Los intentos de abrir archivos para escribir, así como otras operaciones que cambian el estado del sistema de archivos, serán denegados.
-T
Usar TOR. La herramienta gs-sftp se conectará a través de TOR a la GSRN. Esto requiere que TOR esté instalado y en ejecución. La IP y el PUERTO del servidor TOR se pueden configurar mediante variables de entorno.

Consulte gs-netcat(1) para ver más opciones.

EJEMPLOS

Ejemplo 1 - Servidor SFTP escuchando a clientes con la contraseña 'MiSecreto':

$ gs-sftp -s MiSecreto -l

Conectar cliente sftp usando la misma contraseña:

$ gs-sftp -s MiSecreto

AMBIENTE

Consulte gs-netcat(1) para ver una lista de variables de entorno admitidas.

VER TAMBIÉN
