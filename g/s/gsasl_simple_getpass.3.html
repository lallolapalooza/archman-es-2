NOMBRE

gsasl_simple_getpass - Función de la API

SINOPSIS

#include <gsasl.h>

int gsasl_simple_getpass(const char * filename, const char * username, char ** key);

ARGUMENTOS

const char * filename
nombre de archivo que contiene contraseñas.
const char * username
cadena de nombre de usuario.
char ** key
arreglo de caracteres de salida recién asignado.

DESCRIPCIÓN

Recupera la contraseña del usuario del archivo especificado. El buffer key contendrá la contraseña si esta función tiene éxito. El llamador es responsable de liberarlo.

El archivo debe estar en el formato UoW "MD5 Based Authentication", lo que significa que está en formato de texto con comentarios indicados por # al principio de la línea, con entradas de usuario que se ven como "nombredeusuarioTABcontraseña". Esta función elimina CR y LF al final de las líneas antes de procesar. TAB, CR y LF denotan los valores ASCII 9, 13 y 10, respectivamente.

Valor de retorno: Devuelve GSASL_OK si el buffer de salida contiene la contraseña, GSASL_AUTHENTICATION_ERROR si el usuario no pudo ser encontrado, u otro código de error.
