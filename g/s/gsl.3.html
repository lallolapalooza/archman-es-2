NOMBRE

gsl - Biblioteca Científica GNU

SINOPSIS

#include <gsl/...>

DESCRIPCIÓN

La Biblioteca Científica GNU (GSL) es una colección de rutinas para cálculo numérico. Las rutinas están escritas desde cero por el equipo de GSL en C, y presentan una moderna Interfaz de Programación de Aplicaciones (API) para programadores de C, permitiendo la creación de *wrappers* para lenguajes de muy alto nivel.

La biblioteca cubre las siguientes áreas,

Números Complejos
Raíces de Polinomios
Funciones Especiales
Vectores y Matrices
Permutaciones
Combinaciones
Ordenación
Soporte BLAS
Álgebra Lineal
Auto-valores y Auto-vectores
Transformadas Rápidas de Fourier
Cuadratura
Números Aleatorios
Secuencias Pseudoaleatorias
Distribuciones Aleatorias
Estadísticas
Histogramas
N-tuplas
Integración Monte Carlo
Recocido Simulado
Ecuaciones Diferenciales
Interpolación
Diferenciación Numérica
Aproximaciones de Chebyshev
Aceleración de Series
Transformadas de Hankel Discretas
Búsqueda de Raíces
Minimización
Ajuste por Mínimos Cuadrados
Constantes Físicas
Punto Flotante IEEE

Para más información, consulte el Manual de Referencia de GSL, que está disponible como un archivo de información. Puede leerlo en línea usando el comando de shell info gsl-ref (si la biblioteca está instalada).

Por favor, reporte cualquier error a bug-gsl@gnu.org.
