NOMBRE

gst-device-monitor-1.0 - Herramienta de prueba simple en línea de comandos para monitores de dispositivos GStreamer

SINOPSIS

gst-device-monitor-1.0 [CLASES_DE_DISPOSITIVOS[:CAPS_FILTRO]] [CLASES_DE_DISPOSITIVOS[:CAPS_FILTRO]]

DESCRIPCIÓN

gst-device-monitor-1.0 es una herramienta en línea de comandos que se puede usar para probar la funcionalidad de monitoreo de dispositivos de GStreamer. Por defecto, simplemente imprimirá una lista de todos los dispositivos encontrados y saldrá, pero también puedes hacer que espere por más dispositivos pasando la opción --follow. También puedes pasarle uno o más argumentos de filtro para filtrar el tipo de dispositivos que te interesan.

OPCIONES

gst-device-monitor-1.0 acepta las siguientes opciones:

--help
Imprime el resumen de ayuda y las opciones de línea de comandos disponibles
--version
Imprime la versión y sale
-f, --follow
No salir después de mostrar la lista inicial de dispositivos, sino esperar a que se agreguen o eliminen dispositivos
-i, --include-hidden
Incluir dispositivos de proveedores de dispositivos ocultos.

EJEMPLOS

gst-device-monitor-1.0

gst-device-monitor-1.0 --follow
gst-device-monitor-1.0 Audio/Source
gst-device-monitor-1.0 Video/Source:video/x-raw
gst-device-monitor-1.0 -i Audio/Sink
