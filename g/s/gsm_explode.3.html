GSM_EXPLODE(3) Manual de funciones de biblioteca GSM_EXPLODE(3)

NOMBRE

gsm_explode, gsm_implode — funciones suplementarias de GSM 06.10 para pruebas

SINOPSIS

#include "gsm.h"

void gsm_explode(g, frame, xframe)
gsm g;
gsm_frame frame;
gsm_signal xframe[ 76 ];

void gsm_implode(g, xframe, frame)
gsm g;
gsm_signal xframe[ 76 ];
gsm_frame frame;

DESCRIPCIÓN

Gsm es una implementación del borrador final del estándar GSM 06.10 para la transcodificación de voz de tasa completa. Los datos de prueba para implementaciones de este documento en particular se pueden comprar y utilizar para verificar una implementación.

Los datos de prueba codificados utilizan un formato diferente al que se usaría para transmitir tramas con el menor número de bits. Gsm_explode() y gsm_implode() convierten entre el formato interno, pequeño, de 33 bytes y el formato de 76 palabras utilizado por los datos de prueba.

VALOR DE RETORNO

gsm_explode() devuelve -1 si la trama pasada es inválida, de lo contrario, 0.
