gsasl_property_get(3) gsasl gsasl_property_get(3)

NOMBRE

gsasl_property_get - función de la API

SINOPSIS

#include <gsasl.h>

const char * gsasl_property_get(Gsasl_session * sctx, Gsasl_property prop);

ARGUMENTOS

Gsasl_session * sctx
manejador de sesión.
Gsasl_property prop
valor enumerado del tipo Gsasl_property, que indica el tipo de datos en data .

DESCRIPCIÓN

Recupera los datos almacenados en el manejador de sesión para la propiedad dada
prop , invocando posiblemente la función de devolución de llamada de la aplicación para obtener el valor.

El puntero apunta a datos válidos y no debe ser liberado ni modificado de ninguna manera.

Esta función invocará la función de devolución de llamada de la aplicación, utilizando gsasl_callback(), cuando no se conozca el valor de una propiedad.

Valor de retorno: Devuelve los datos de la propiedad, o NULL si no se conoce ningún valor.
