gsettings() gsettings()

Nombre

gsettings - Herramienta de configuración de GSettings

SINOPSIS

gsettings get SCHEMA*[:*PATH] CLAVE
gsettings monitor SCHEMA*[:*PATH] CLAVE
gsettings writable SCHEMA*[:*PATH] CLAVE
gsettings range SCHEMA*[:*PATH] CLAVE
gsettings describe SCHEMA*[:*PATH] CLAVE
gsettings set SCHEMA*[:*PATH] CLAVE VALOR
gsettings reset SCHEMA*[:*PATH] CLAVE
gsettings reset-recursively SCHEMA*[:*PATH]
gsettings list-schemas [--print-paths]
gsettings list-relocatable-schemas
gsettings list-keys SCHEMA*[:*PATH]
gsettings list-children SCHEMA*[:*PATH]
gsettings list-recursively [SCHEMA*[:*PATH]]
gsettings help [COMANDO]

DESCRIPCIÓN

gsettings ofrece una interfaz simple de línea de comandos para GSettings. Permite obtener, establecer o monitorear una clave individual para cambios.

Los argumentos SCHEMA y CLAVE son requeridos para la mayoría de los comandos para especificar el ID del esquema y el nombre de la clave sobre la que operar. El ID del esquema puede tener opcionalmente un sufijo :PATH. Especificar la ruta solo es necesario si el esquema no tiene una ruta fija.

Al establecer una clave, también es necesario especificar un VALOR. El formato del valor es el de un GVariant serializado, por lo que, por ejemplo, una cadena debe incluir comillas explícitas: 'foo'. Este formato también se utiliza al imprimir valores.

Tenga en cuenta que gsettings necesita una conexión al bus de sesión de D-Bus para escribir cambios en la base de datos de dconf.

COMANDOS

get

Obtiene el valor de CLAVE. El valor se imprime como un GVariant serializado.

monitor

Monitorea CLAVE para detectar cambios e imprime los valores cambiados. Si no se especifica ninguna CLAVE, se monitorean todas las claves del esquema. El monitoreo continuará hasta que el proceso sea terminado.

writable

Averigua si CLAVE es escribible.

range

Consulta el rango de valores válidos para CLAVE.

describe

Consulta la descripción de los valores válidos para CLAVE.

set

Establece el valor de CLAVE a VALOR. El valor se especifica como un GVariant serializado.

reset

Restaura CLAVE a su valor predeterminado.

reset-recursively

Restaura todas las claves bajo el SCHEMA dado.

list-schemas

Lista los esquemas instalados y no reubicables. Consulte list-relocatable-schemas si está interesado en esquemas reubicables. Si se proporciona --print-paths, también se imprimirá la ruta donde se mapea cada esquema.

list-relocatable-schemas

Lista los esquemas instalados y reubicables. Consulte list-schemas si está interesado en esquemas no reubicables.

list-keys

Lista las claves en SCHEMA.

list-children

Lista los hijos de SCHEMA.

list-recursively

Lista claves y valores, recursivamente. Si no se proporciona un SCHEMA, lista claves en todos los esquemas.

help

Imprime ayuda y sale.
