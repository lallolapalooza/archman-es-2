gsasl_scram_secrets_from_password(3) gsasl gsasl_scram_secrets_from_password(3)

NOMBRE

gsasl_scram_secrets_from_password - función de API

SINOPSIS

#include <gsasl.h>

int gsasl_scram_secrets_from_password(Gsasl_hash hash, const char * password, unsigned int iteration_count, const char * salt, size_t saltlen, char * salted_password, char * client_key, char * server_key, char * stored_key);

ARGUMENTOS

Gsasl_hash hash
un elemento Gsasl_hash, por ejemplo, GSASL_HASH_SHA256.
const char * password
parámetro de entrada con la contraseña.
unsigned int iteration_count
número de rondas PBKDF2 a aplicar.
const char * salt
array de caracteres de entrada de longitud saltlen con la sal para PBKDF2.
size_t saltlen
longitud de salt.
char * salted_password
array de salida preasignado con la contraseña con sal derivada.
char * client_key
array de salida preasignado con la clave de cliente derivada.
char * server_key
array de salida preasignado con la clave de servidor derivada.
char * stored_key
array de salida preasignado con la clave almacenada derivada.

DESCRIPCIÓN

Función auxiliar para generar secretos SCRAM a partir de una contraseña. Los
buffers salted_password , client_key , server_key y stored_key deben tener espacio suficiente para almacenar el digest para el hash dado; use GSASL_HASH_MAX_SIZE que es suficiente para todos los hashes.

Valor de retorno: Devuelve GSASL_OK si tiene éxito, o un código de error.
