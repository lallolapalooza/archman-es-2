NOMBRE

gsasl_property_set - función de API

SINOPSIS

#include <gsasl.h>

int gsasl_property_set(Gsasl_session * sctx, Gsasl_property prop, const char * data);

ARGUMENTOS

Gsasl_session * sctx
manejador de sesión.
Gsasl_property prop
valor enumerado del tipo Gsasl_property, que indica el tipo de datos en data .
const char * data
cadena de caracteres terminada en cero para almacenar.

DESCRIPCIÓN

Realiza una copia de data y la almacena en el manejador de sesión para la propiedad indicada prop .

Puede liberar data inmediatamente después de llamar a esta función, sin afectar los datos almacenados en el manejador de sesión.

Valor de retorno: GSASL_OK si tiene éxito, de lo contrario GSASL_MALLOC_ERROR.
