NOMBRE

gsasl_step64 - función de la API

SINOPSIS

#include <gsasl.h>

int gsasl_step64(Gsasl_session * sctx, const char * b64input, char ** b64output);

ARGUMENTOS

Gsasl_session * sctx
manejador de cliente libgsasl.
const char * b64input
array de bytes codificado en base64 de entrada.
char ** b64output
array de bytes codificado en base64 de salida recién asignado.

DESCRIPCIÓN

Este es un envoltorio simple alrededor de gsasl_step() que decodifica la entrada en base64 y codifica la salida en base64.

El contenido del búfer b64output no está especificado si esta función devuelve algo que no sea GSASL_OK o GSASL_NEEDS_MORE. Si esta función devuelve GSASL_OK o GSASL_NEEDS_MORE, sin embargo, el búfer b64output es asignado por esta función, y es responsabilidad del llamador liberarlo llamando a gsasl_free( b64output ).

Valor de retorno: Devuelve GSASL_OK si la autenticación finalizó con éxito, GSASL_NEEDS_MORE si se necesitan más datos, o un código de error.
