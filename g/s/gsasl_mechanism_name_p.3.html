NOMBRE

gsasl_mechanism_name_p - función de la API

SINOPSIS

#include <gsasl.h>

int gsasl_mechanism_name_p(const char * mech);

ARGUMENTOS

const char * mech
variable de entrada con el nombre del mecanismo en formato de cadena.

DESCRIPCIÓN

Comprueba si la cadena del nombre del mecanismo mech sigue las reglas sintácticas. No comprueba si el nombre está registrado en IANA. No comprueba si el nombre del mecanismo está realmente implementado y soportado.

Los mecanismos SASL se nombran mediante cadenas, de 1 a 20 caracteres de longitud, que consisten en letras mayúsculas, dígitos, guiones y/o guiones bajos.

DEVUELVE

Un valor distinto de cero cuando la cadena del nombre del mecanismo mech se ajusta a las reglas, cero cuando no cumple los requisitos.
