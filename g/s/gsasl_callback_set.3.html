NOMBRE

gsasl_callback_set - función de la API

SINOPSIS

#include <gsasl.h>

void gsasl_callback_set(Gsasl * ctx, Gsasl_callback_function cb);

ARGUMENTOS

Gsasl * ctx
manejador recibido de gsasl_init().
Gsasl_callback_function cb
puntero a la función implementada por la aplicación.

DESCRIPCIÓN

Almacena el puntero a la devolución de llamada proporcionada por la aplicación en el manejador de la biblioteca. La devolución de llamada será utilizada, a través de gsasl_callback(), por los mecanismos para descubrir varios parámetros (como nombres de usuario y contraseñas). La función de devolución de llamada será llamada con un valor de propiedad Gsasl que indica el comportamiento solicitado. Por ejemplo, para GSASL_ANONYMOUS_TOKEN, se espera que la función invoque gsasl_property_set( CTX , GSASL_ANONYMOUS_TOKEN, "token") donde "token" es el token anónimo que la aplicación desea que use el mecanismo SASL. Consulte el manual para conocer el significado de todos los parámetros.
