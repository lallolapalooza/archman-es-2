NOMBRE

gsasl_step - Función de la API

SINOPSIS

#include <gsasl.h>

int gsasl_step(Gsasl_session * sctx, const char * input, size_t input_len, char ** output, size_t * output_len);

ARGUMENTOS

Gsasl_session * sctx
Identificador de sesión de libgsasl.
const char * input
Array de bytes de entrada.
size_t input_len
Tamaño del array de bytes de entrada.
char ** output
Array de bytes de salida recién asignado.
size_t * output_len
Puntero a la variable de salida con el tamaño del array de bytes de salida.

DESCRIPCIÓN

Realiza un paso de autenticación SASL. Esto lee datos del otro extremo (de input y input_len ), los procesa (invocando potencialmente callbacks a la aplicación) y escribe datos al servidor (en la variable recién asignada output y output_len que indican la longitud de output ).

El contenido del buffer output no está especificado si esta función devuelve algo diferente a GSASL_OK o GSASL_NEEDS_MORE. Si esta función devuelve GSASL_OK o GSASL_NEEDS_MORE, sin embargo, el
buffer output es asignado por esta función, y es responsabilidad del llamador liberarlo llamando a gsasl_free( output ).

Valor de retorno: Devuelve GSASL_OK si la autenticación terminó con éxito, GSASL_NEEDS_MORE si se necesitan más datos, o un código de error.
