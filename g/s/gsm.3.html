GSM(3) Manual de funciones de biblioteca GSM(3)

NOMBRE

gsm_create, gsm_destroy, gsm_encode, gsm_decode — Compresión de sonido con pérdida GSM 06.10

SINOPSIS

#include "gsm.h"

gsm gsm_create();

void gsm_encode(handle, src, dst)
gsm handle;
gsm_signal src[160];
gsm_frame dst;

int gsm_decode(handle, src, dst)
gsm handle;
gsm_frame src;
gsm_signal dst[160];

void gsm_destroy(handle)
gsm handle;

DESCRIPCIÓN

Gsm es una implementación del borrador final del estándar GSM 06.10 para transcodificación de voz de tasa completa.

gsm_create() inicializa un paso gsm y devuelve un objeto 'gsm' que se puede utilizar como manejador en llamadas posteriores a gsm_decode(), gsm_encode() o gsm_destroy().

gsm_encode() codifica una matriz de 160 muestras de 13 bits (dadas como gsm_signal, valores enteros con signo de al menos 16 bits) en un gsm_frame de 33 bytes. (gsm_frame es un tipo definido como una matriz de 33 gsm_bytes en gsm.h.)

gsm_decode() decodifica un gsm_frame en una matriz de 160 muestras de 13 bits (dadas como gsm_signals), que suenan muy parecido a lo que se envió a gsm_encode() en el otro extremo de la comunicación.

gsm_destroy() finaliza un paso gsm y libera todo el almacenamiento asociado a él.

Formato de muestra

Se asume el siguiente escalado para la entrada del algoritmo: 

   0  1                             11 12
   S..v..v..v..v..v..v..v..v..v..v..v..v..*..*..*
Solo los 13 bits superiores se utilizan como valor de entrada con signo.
La salida de gsm_decode() tiene los tres bits inferiores establecidos a cero.

VALOR DE RETORNO

gsm_create() devuelve un objeto manejador opaco de tipo gsm, o 0 en caso de error. gsm_decode() devuelve -1 si el frame proporcionado no es válido, de lo contrario 0.

EJEMPLO

#include "gsm.h"
gsm handle;
gsm_frame buf;
gsm_signal sample[160];
int cc, soundfd;
play() {	/* leer datos comprimidos de la entrada estándar, escribir en soundfd */
	if (!(handle = gsm_create())) error...
	while (cc = read(0, (char *)buf, sizeof buf)) {
		if (cc != sizeof buf) error...
		if (gsm_decode(handle, buf, sample) < 0) error... 
		if (write(soundfd, sample, sizeof sample) != sizeof sample)
			error...
	}
	gsm_destroy(handle);
}
record() {	/* leer de soundfd, escribir comprimido en la salida estándar */
	if (!(handle = gsm_create())) error...
	while (cc = read(soundfd, sample, sizeof sample)) {
		if (cc != sizeof sample) error...
		gsm_encode(handle, sample, buf);
		if (write(1, (char *)buf, sizeof buf) != sizeof sample) 
			error...
	}
	gsm_destroy(handle);
}
