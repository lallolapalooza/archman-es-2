NOMBRE

gstack - Imprime un rastreo de pila de un programa en ejecución

SINOPSIS

gstack [-h | --help] [-v | --version] pid

DESCRIPCIÓN

Imprime un rastreo de pila de un programa en ejecución con el ID de proceso pid. Si el proceso es multihilo, gstack genera rastreos de pila para cada hilo existente en el proceso.

El script invoca GDB, se adjunta al ID de proceso dado, imprime el rastreo de pila y se desvincula del proceso.

gstack sale con un estado distinto de cero si "gdb" no pudo adjuntarse al ID de proceso dado por cualquier motivo, como un ID de proceso inexistente o privilegios insuficientes para adjuntarse al proceso.

OPCIONES

--help
-h
Lista todas las opciones, con explicaciones breves.
--version
-v
Imprime información de la versión y luego sale.

ENTORNO

AWK
Nombre de archivo completo de un intérprete Awk a usar. Si no está configurado, se buscará un programa "awk" en el PATH.
GDB
Nombre de archivo completo de un ejecutable GDB a usar para generar rastreos de pila. Si no está configurado, se buscará un programa "gdb" en el PATH.
GDBARGS
Opciones opcionales que se pasarán al programa "gdb".

VER TAMBIÉN

La documentación completa de GDB se mantiene como un manual Texinfo. Si los programas "info" y "gdb" y la documentación Texinfo de GDB están instalados correctamente en su sitio, el comando

info gdb

debería darle acceso al manual completo.

Using GDB: A Guide to the GNU Source-Level Debugger, Richard M. Stallman y Roland H. Pesch, julio de 1991.
