NOMBRE

gsf - utilidad de archivado que utiliza la biblioteca G Structured File

SINOPSIS

gsf [OPCIÓN...] SUBCOMANDO ARCHIVO...

DESCRIPCIÓN

Esta página del manual documenta brevemente el comando gsf.

gsf es una utilidad de archivo simple, algo similar a tar(1). Opera sobre archivos que siguen uno de los formatos de archivo estructurados entendidos por la biblioteca G Structured File, por ejemplo, archivos de Microsoft Excel(TM).

OPCIONES

Opciones

-?, --help
Mostrar opciones de ayuda
-v, --version
Mostrar la versión de gsf

Subcomandos

cat
Extraer uno o más archivos del archivo
dump
Volcar uno o más archivos del archivo como hexadecimal formateado
help
Listar subcomandos
list
Listar archivos en el archivo
props
Archivar lista de nombres de propiedades

EJEMPLOS

Para listar la estructura del contenido de un archivo Microsoft Excel(TM) arrays.xls:

gsf list arrays.xls

Para volcar Workbook, un flujo de datos individual en arrays.xls:

gsf dump arrays.xls Workbook
