NOMBRE

gsasl_callback_hook_set - función de la API

SINOPSIS

#include <gsasl.h>

void gsasl_callback_hook_set(Gsasl * ctx, void * hook);

ARGUMENTOS

Gsasl * ctx
manejador de libgsasl.
void * hook
puntero opaco a datos específicos de la aplicación.

DESCRIPCIÓN

Almacena datos específicos de la aplicación en el manejador de libgsasl.

Los datos de la aplicación pueden ser recuperados más tarde (por ejemplo, dentro de una devolución de llamada) llamando a gsasl_callback_hook_get(). Esto se usa normalmente por la aplicación para mantener un estado global entre el programa principal y las devoluciones de llamada.
