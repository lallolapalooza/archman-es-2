NOMBRE

gsasl_hash_length - función de API

SINOPSIS

#include <gsasl.h>

size_t gsasl_hash_length(Gsasl_hash hash);

ARGUMENTOS

Gsasl_hash hash
un elemento Gsasl_hash, por ejemplo, GSASL_HASH_SHA256.

DESCRIPCION

Devuelve el tamaño de salida del digest para la función hash hash. Por ejemplo, gsasl_hash_length(GSASL_HASH_SHA256) devuelve GSASL_HASH_SHA256_SIZE, que es 32.

RETORNA

tamaño del elemento Gsasl_hash proporcionado.
