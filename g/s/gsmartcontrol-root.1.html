GSmartControl(1) Comandos de usuario GSmartControl(1)

NOMBRE

GSmartControl - Herramienta de inspección de salud de discos duros y SSD

SINOPSIS

gsmartcontrol [OPCIONES]

gsmartcontrol-root [--desktop=<escritorio>] [OPCIONES]

DESCRIPCIÓN

GSmartControl es una interfaz gráfica de usuario para smartctl (de smartmontools), que es una herramienta para consultar y controlar datos SMART (Self-Monitoring, Analysis, and Reporting Technology) en discos duros y unidades de estado sólido modernas. Permite inspeccionar los datos SMART de la unidad para determinar su estado, así como ejecutar varias pruebas en ella.

Esta página del manual documenta brevemente los comandos gsmartcontrol y gsmartcontrol-root.

El comando gsmartcontrol-root inicia gsmartcontrol con privilegios administrativos. El argumento escritorio especifica qué escritorio se está ejecutando actualmente, para la selección automática del mecanismo de su nativo. Los valores válidos para escritorio son auto, kde, gnome, other.

OPCIONES

Opciones de ayuda:

-?, --help
Mostrar opciones de ayuda
--help-all
Mostrar todas las opciones de ayuda
--help-gtk
Mostrar opciones de GTK+
--help-debug
Mostrar opciones de registro

Opciones de la aplicación:

-l, --no-locale
No usar la configuración regional del sistema
-V, --version
Mostrar información de la versión
--no-scan
No escanear dispositivos al inicio
--add-virtual
Cargar datos de smartctl desde un archivo, creando una unidad virtual. Se puede especificar esta opción varias veces.
--add-device
Añadir este dispositivo a la lista de dispositivos. El formato del dispositivo es <dispositivo>::<tipo>::<argumentos_adicionales>, donde el tipo y los argumentos adicionales son opcionales. Esta opción es útil con --no-scan para listar solo ciertas unidades. Se puede especificar esta opción varias veces. Ejemplo: 
--add-device /dev/sda --add-device /dev/twa0::3ware,2 --add-device '/dev/sdb::::-T permissive'
--display=PANTALLA
Pantalla X a utilizar
-v, --verbose
Habilitar registro detallado; igual que --verbosity-level 5
-q, --quiet
Deshabilitar registro; igual que --verbosity-level 0
-b, --verbosity-level
Establecer el nivel de detalle [0-5]
