NOMBRE

gscriptor - Script de Perl para enviar comandos a una tarjeta inteligente mediante una GUI Gtk

SINOPSIS

gscriptor

DESCRIPCIÓN

Esta página del manual documenta brevemente el comando gscriptor.

gscriptor es un programa que envía comandos a una tarjeta inteligente utilizando un archivo por lotes. La sintaxis de los comandos es la misma que para scriptor(1).

scriptor(1) está en modo texto. gscriptor(1) utiliza una interfaz gráfica de usuario Perl-Gtk y puede ser más fácil de usar.

Ver scriptor(1) para más detalles sobre el formato de los comandos.
