NOMBRE

gscan2pdf - Una GUI para producir PDFs o DjVus a partir de documentos escaneados

USO

1. Escanear una o varias páginas con Archivo/Escanear
2. Crear PDF de las páginas seleccionadas con Archivo/Guardar

ARGUMENTOS REQUERIDOS

Ninguno

OPCIONES

gscan2pdf tiene las siguientes opciones de línea de comandos:

--dispositivo=dispositivo
Especifica el dispositivo a usar, en lugar de obtener la lista de dispositivos a través de la API de SANE. Esto puede ser útil si el escáner está en un ordenador remoto que no está anunciando su existencia.
--ayuda
Muestra esta página de ayuda y sale.
--log=archivo-log
Especifica un archivo para almacenar los mensajes de registro.
--debug, --info, --warn, --error, --fatal
Define el nivel de registro. Si se especifica un archivo de registro, el valor predeterminado es --debug; de lo contrario, es --error.
--importar=PDF|DjVu|imágenes
Importa el(los) archivo(s) especificado(s). Si el documento tiene más de una página, se muestra una ventana para seleccionar las páginas requeridas.
--importar-todo=PDF|DjVu|imágenes Importa todas las páginas del(los) archivo(s) especificado(s).
--version
Muestra la versión del programa y sale.

El escaneo se maneja con SANE a través de scanimage. La conversión a PDF la realiza PDF::Builder. La exportación a TIFF la maneja libtiff (más rápida y menor uso de memoria para archivos de varias páginas).

DIAGNÓSTICO

Para diagnosticar un posible error, inicia gscan2pdf desde la línea de comandos con el registro habilitado:

"gscan2pdf --log=archivo.log"

y revisa archivo.log.

ESTADO DE SALIDA

Ninguno

CONFIGURACIÓN

gscan2pdf crea un archivo de recursos de texto en ~/.config/gscan2pdfrc. El directorio se puede cambiar estableciendo la variable $XDG_CONFIG_HOME. Generalmente, sin embargo, las preferencias deben cambiarse a través del menú Editar/Preferencias, o se capturan automáticamente durante el uso normal del programa.

INCOMPATIBILIDADES

Ninguna conocida.

ERRORES Y LIMITACIONES

Si bien es posible importar PDFs, esto está destinado a poder realizar un ciclo de ida y vuelta de archivos creados por gscan2pdf.

Descarga

gscan2pdf está disponible en Sourceforge (https://sourceforge.net/projects/gscan2pdf/files/gscan2pdf/).

Basado en Debian

Si estás usando Debian, deberías encontrar que sid https://www.debian.org/releases/sid/ ya tiene la última versión empaquetada.

Si estás usando un sistema basado en Ubuntu, puedes mantenerte automáticamente al día con la última versión a través del ppa:

"sudo apt-add-repository ppa:jeffreyratcliffe/ppa"

Si estás usando Synaptic, entonces usa el menú Editar/Recargar información de paquetes, busca gscan2pdf en la lista de paquetes, y he aquí, puedes instalar la nueva y brillante versión.

Desde la línea de comandos:

"sudo apt update"

"sudo apt install gscan2pdf"

Desde fuente

El código fuente está alojado en la sección de archivos del proyecto gscan2pdf en Sourceforge (https://sourceforge.net/projects/gscan2pdf/files/).

Desde el repositorio

gscan2pdf utiliza Git para su Sistema de Control de Revisiones. Puedes explorar el árbol en https://sourceforge.net/p/gscan2pdf/code/.

Los usuarios de Git pueden clonar el árbol completo con "git clone git://git.code.sf.net/p/gscan2pdf/code"

Compilar gscan2pdf desde fuente

Después de descargar el código fuente, ya sea de una versión de archivo de Sourceforge o del repositorio Git, descomprímelo si es necesario con "tar xvfz gscan2pdf-x.x.x.tar.gz cd gscan2pdf-x.x.x"

"perl Makefile.PL", creará el Makefile.

"make test" debería ejecutar varios cientos de pruebas para confirmar que las cosas funcionarán correctamente en tu sistema.

Puedes instalar directamente desde la fuente con "make install", pero compilar el paquete apropiado para tu distribución debería ser tan sencillo como "make debdist" o "make rpmdist". Sin embargo, adicionalmente necesitarás los paquetes rpm, devscripts, fakeroot, debhelper y gettext.

Traducciones

gscan2pdf ya ha sido parcialmente traducido a varios idiomas. Si desea contribuir a una traducción existente o nueva, por favor, consulte Rosetta: https://translations.launchpad.net/gscan2pdf

Tenga en cuenta que las traducciones de las opciones del escáner se toman directamente de sane-backends. Si desea contribuir a estas, puede hacerlo contactando con la lista de correo sane-devel (sane-devel@lists.alioth.debian.org) y mirando el directorio po/ en el código fuente http://www.sane-project.org/cvs.html.

Alternativamente, Ubuntu tiene su propio proyecto de traducción. Para la versión 9.04, las traducciones están disponibles en https://translations.launchpad.net/ubuntu/jaunty/+source/sane-backends/+pots/sane-backends

Si ha actualizado un ".po" archivo en el "po" directorio del árbol de código fuente de gscan2pdf y desea probarlo, elija un directorio de prueba para las configuraciones locales compiladas, por ejemplo "./locale", y cree los ".mo" archivos con:

"perl Makefile.PL LOCALEDIR=./locale"

Si la configuración local actualizada es la estándar, lo siguiente encontrará el archivo actualizado:

"perl -I lib bin/gscan2pdf --log=log --locale=locale"

Si no es su configuración local estándar, necesitará algo como (para ruso):

"LC_ALL=ru_RU.utf8 LC_MESSAGES=ru_RU.utf8 LC_CTYPE=ru_RU.utf8 LANG=ru_RU.utf8 LANGUAGE=ru_RU.utf8 perl -I lib bin/gscan2pdf --log=log --locale=locale"

o alemán:

"LC_ALL=de_DE LC_MESSAGES=de_DE LC_CTYPE=de_DE LANG=de_DE LANGUAGE=de_DE perl -I lib bin/gscan2pdf --log=log --locale=locale"

Si lo anterior no funciona, asegúrese de que está en la lista producida por "locale -a", incluyendo cualquier ".utf8" sufijo. Si es necesario, genere nuevas configuraciones locales con "sudo dpkg-reconfigure locales"

DESCRIPCIÓN

Archivo

Nuevo

Borra la lista de páginas.

Abrir

Abre cualquier formato que soporte imagemagick. Los PDF tendrán sus imágenes incrustadas extraídas e importadas una por página.

Tenga en cuenta que los archivos también se pueden importar arrastrándolos a la lista de miniaturas desde un programa como nautilus o konqueror.

Escanear

Establece opciones antes de escanear vía SANE.

Dispositivo

Elige entre los escáneres disponibles.

Nº de páginas

Selecciona el número de páginas, o todas las páginas a escanear.

Documento de origen

Selecciona entre páginas a una cara o a doble cara.

Esto afecta a la numeración de páginas. Los escaneos a una cara se numeran consecutivamente. Los escaneos a doble cara se incrementan (o decrementan, véase más abajo) en 2, es decir, 1, 3, 5, etc.

Cara a escanear

Si se seleccionó doble cara arriba, asumiendo un escáner no dúplex, es decir, un escáner que no puede escanear automáticamente ambas caras de una página, esto determina si el número de página se incrementa o decrementa en 2.

Para escanear ambas caras de tres páginas, es decir, 6 caras:

1. Seleccione:
Nº de páginas = 3 (o "todas" si su escáner puede detectar cuando se le acaba el papel)

Doble cara

Cara frontal

2. Escanea las caras 1, 3 y 5.
3. Coloque la pila de nuevo con el escáner listo para escanear el reverso de la última página.
4. Seleccione:
Nº de páginas = 3 (o "todas" si su escáner puede detectar cuando se le acaba el papel)

Doble cara

Cara trasera

5. Escanea las caras 6, 4 y 2.
6. gscan2pdf ordena automáticamente las páginas para que aparezcan en el orden correcto.

Opciones dependientes del dispositivo

Estas, naturalmente, dependen de su escáner. Pueden incluir

Tamaño de página.
Modo (color/blanco y negro/escala de grises)
Resolución (en PPI)
Escaneo por lotes
Garantiza que se devolverá una condición de "sin documentos" después de la última página escaneada, para prevenir escaneos de platina infinitos después de un escaneo por lotes.
Esperar al botón/Espera del botón
Después de enviar el comando de escaneo, espera hasta que se presione el botón en el escáner antes de empezar realmente el proceso de escaneo.
Fuente
Selecciona la fuente del documento. Las opciones posibles pueden incluir Platina o ADF (alimentador automático de documentos). En algunos escáneres, esta es la única forma de generar una señal de fin de documentos.

Guardar

Guarda las páginas seleccionadas o todas como PDF, DjVu, TIFF, PNG, JPEG, PNM o GIF.

Metadatos

Los metadatos son información que no es visible al ver el PDF/DjVu, pero está incrustada en el archivo y por lo tanto es buscable y puede ser examinada, típicamente con la opción "Propiedades" del visor de documentos.

Los metadatos son completamente opcionales, pero también se pueden usar para generar el nombre de archivo, consulte las preferencias para más detalles.

La fecha se puede seleccionar con el uso del widget de calendario. La fecha mostrada se puede incrementar o decrementar con el uso de las teclas '+' y '-'.

DjVu

Tanto las imágenes en blanco y negro como en color producen una mejor compresión que el PDF. Véase http://www.djvuzone.org/ para más detalles.

Enviar por correo electrónico como PDF

Adjunta las páginas seleccionadas o todas como PDF a un correo electrónico en blanco. Esto requiere xdg-email, que está en el paquete xdg-utils. Si esto no está presente, la opción aparece atenuada.

Imprimir

Imprime las páginas seleccionadas o todas.

Comprimir archivos temporales

Si su directorio temporal ($TMPDIR) se está llenando, esta función puede ser útil: comprime todas las imágenes en TIFFs comprimidos con LZW. Estos requieren mucho menos espacio que los archivos PNM que son típicamente producidos por SANE o al importar un PDF.

Editar

Eliminar

Elimina la página seleccionada.

Renumerar

Renumera las páginas de 1..n.

Tenga en cuenta que el orden de las páginas también se puede cambiar arrastrando y soltando en la vista de miniaturas.

Seleccionar

Los menús de selección se pueden usar para seleccionar todas, pares, impares, en blanco, oscuras o modificadas. Seleccionar páginas en blanco u oscuras ejecuta imagemagick para tomar la decisión. Seleccionar páginas modificadas selecciona aquellas que han sido modificadas por umbral, enfoque, etc., desde que se hizo la última ejecución de OCR.

Propiedades

Cuando se escanea una imagen, gscan2pdf intenta extraer la resolución de las opciones de escaneo. Esto casi siempre funciona sin problemas.

Importar una imagen puede ser más complicado, sin embargo. Algunos formatos de imagen como PNM no codifican metadatos para la resolución. En otros casos, los datos son incorrectos. Editar/Propiedades Permite al usuario corregir manualmente los metadatos de una página en particular, corrigiendo así el tamaño del PDF o DjVu final. La imagen en sí no se modifica en otros aspectos - no se reduce ni se amplía.

Preferencias

El elemento de menú de preferencias permite controlar el comportamiento predeterminado de varias funciones. La mayoría de estas son

autoexplicativas.

Frontend

s

gscan2pdf inicialmente soportaba dos frontends, scanimage y scanadf. El soporte para scanadf se añadió cuando se descubrió que scanadf funciona mejor que scanimage con algunos escáneres. En los sistemas basados en Debian, scanadf está en el paquete sane, no, como scanimage, en sane-utils. Si scanadf no está presente, la

opción está obviamente deshabilitada.

En 0.9.27, se introdujeron los bindings de Perl para SANE. Estos se llaman

libsane-perl.

Antes de la versión 1.2.0, las opciones disponibles a través de frontends CLI como scanimage se hacían visibles a medida que los usuarios las solicitaban. En 1.2.0, todas las opciones pueden mostrarse u ocultarse a través de Editar/Preferencias, junto con la capacidad de especificar qué opciones activan una

recarga.

En 1.8.3, se introdujeron nuevos bindings de Perl para SANE. Estos se llaman libimage-sane-perl y son el frontend

preferido.

En 1.8.5, se eliminó el soporte para

libsane-perl.

OCR (Reconocimiento Óptico de

Caracteres)

Las utilidades gocr, tesseract o cuneiform se utilizan para producir texto a partir de

una imagen.

Hay un búfer de salida de OCR para cada página y se incrusta como texto plano detrás de la imagen escaneada en el PDF producido. De esta manera, Beagle puede indexar (es decir, buscar) el texto

plano.

En los archivos DjVu, el búfer de salida de OCR se incrusta en la capa de texto oculta. Por lo tanto, estos también pueden ser indexados

por Beagle.

Hay una reseña interesante del software OCR

en

https://web.archive.org/web/20080529012847/http:

//groundstate.ca/ocr

. Una conclusión importante fue que se necesitan 400 ppp para obtener resultados

decentes.

Hasta la versión v2.04, la única forma de saber qué idiomas estaban disponibles para tesseract era buscar los archivos de idioma. Por lo tanto, gscan2pdf verifica la ruta devuelta por: "tesseract '' '' -l

''"

Si no hay archivos de idioma en la ubicación anterior, entonces gscan2pdf asume que está instalada la versión tesseract v1.0, que no tenía archivos de

idioma.
