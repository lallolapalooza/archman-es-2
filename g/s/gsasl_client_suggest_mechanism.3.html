NOMBRE

gsasl_client_suggest_mechanism - función de la API

SINOPSIS

#include <gsasl.h>

const char * gsasl_client_suggest_mechanism(Gsasl * ctx, const char * mechlist);

ARGUMENTOS

Gsasl * ctx
identificador de libgsasl.
const char * mechlist
array de caracteres de entrada con nombres de mecanismos SASL, separados por caracteres inválidos (p. ej., ESPACIO).

DESCRIPCIÓN

Dada una lista de mecanismos, sugiere cuál usar.

Valor de retorno: Devuelve el nombre del "mejor" mecanismo SASL soportado por el cliente libgsasl que está presente en la cadena de entrada, o NULL si no se encuentra ningún mecanismo soportado.
