NOMBRE

gsasl_check_version - Función de API

SINOPSIS

#include <gsasl.h>

const char * gsasl_check_version(const char * req_version);

ARGUMENTOS

const char * req_version
cadena de versión para comparar, o NULL.

DESCRIPCIÓN

Comprueba la versión de la Biblioteca GNU SASL.

Ver GSASL_VERSION para una cadena req_version adecuada.

Esta es una de las pocas funciones de la biblioteca que se pueden utilizar sin una llamada exitosa a gsasl_init().

Valor de retorno: Comprueba que la versión de la biblioteca sea como mínimo la proporcionada como cadena en req_version y devuelve la cadena de versión real de la biblioteca; devuelve NULL si no se cumple la condición. Si se pasa NULL a esta función, no se realiza ninguna comprobación y solo se devuelve la cadena de versión.
