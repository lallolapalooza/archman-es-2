NOMBRE

gst-typefind-1.0 - imprime el tipo de medio de un archivo

SINOPSIS

gst-typefind-1.0 <archivo>

DESCRIPCIÓN

gst-typefind-1.0 utiliza el sistema de búsqueda de tipos de GStreamer para determinar el plugin GStreamer relevante para analizar o decodificar archivo, y el tipo de medio correspondiente.

OPCIONES

gst-typefind-1.0 acepta las siguientes opciones:

--help
Imprime el resumen de ayuda y las BANDERAS disponibles
--gst-info-mask=FLAGS
Marcas de información de GStreamer a establecer (lista con --help)
--gst-debug-mask=FLAGS
Marcas de depuración de GStreamer a establecer (lista con --help)
--gst-mask=FLAGS
Marcas de información y depuración de GStreamer a establecer (lista con --help)
--gst-plugin-path=PATH
Agrega directorios separados por ':' a la ruta de búsqueda de plugins

VER TAMBIÉN

gst-inspect-1.0(1), gst-launch-1.0(1)

AUTOR

El equipo de GStreamer en http://gstreamer.freedesktop.org/
