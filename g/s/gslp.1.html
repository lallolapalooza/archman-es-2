DESCRIPCIÓN

Esta utilidad proporciona una funcionalidad aproximadamente equivalente al programa Unix enscript(1). Imprime archivos de texto plano utilizando una única fuente. Actualmente maneja tabulaciones y saltos de formulario, pero no retrocesos. Realizará saltos de línea al usar fuentes de paso fijo. También realizará ajustes de kerning y ancho.

El dispositivo por defecto (-sDEVICE=) y la resolución (-r) son los siguientes:

      gslp      epson      180
      gsbj      bj10e      180
      gsdj      deskjet    300
      gsdj500   djet500    300
      gslj      laserjet   300
Por defecto, la fecha actual se formatea como el encabezado central.

OPCIONES

Interruptores estándar implementados:
-12BclqRr -b<encabezado> -f<fuente> -F<fuente_encabezado> -L<lineas> -p<archivo_salida>
Interruptores Sun implementados:
-T<n> establecer ancho de tabulación
Interruptores ignorados:
-GghKkmow -# -C -d -J -n -P -S -s -t -v
Interruptores añadidos:
--add-to-space <unidades>
añadir el número dado de unidades de 1/72" al ancho de cada espacio (puede ser negativo)
--add-to-width <unidades>
añadir el número dado de unidades de 1/72" al ancho de cada carácter (puede ser negativo)
--columns <n>
imprimir en <n> columnas
--detect
tratar el archivo como PostScript si comienza con %!
--first-page <n>
comenzar a imprimir en la página <n>
--kern <archivo.afm>
aplicar kerning usando información del archivo .AFM dado
--last-page <n>
dejar de imprimir después de la página <n>
--(heading|footing)-(left|center|right) <cadena>
establecer los campos de encabezado/pie; usar -B primero para borrar
--margin-(top|bottom|left|right) <pulgadas>
establecer un margen
--no-eject-(file|formfeed)
fin de archivo/salto de formulario solo inicia una nueva columna, no una nueva hoja
--spacing <n>
usar espaciado doble (n=2), triple (n=3), etc.

Además, la cadena %# en un encabezado o pie se reemplaza con el número de página.
