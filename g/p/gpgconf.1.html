DESCRIPCIÓ

N

El gpgconf es una utilidad para consultar y modificar de forma automática y razonablemente segura los archivos de configuración en el directorio home ‘.gnupg’. Está diseñado para no ser invocado manualmente por el usuario, sino automáticamente por interfaces gráficas de usuario (GUI). ([Por favor, tenga en cuenta que actualmente no se realiza ningún bloqueo, por lo que se debe evitar el acceso concurrente. Hay algunas precauciones para evitar la corrupción con el uso concurrente, pero los resultados pueden ser inconsistentes y algunos cambios pueden perderse. El diseño sin estado hace difícil proporcionar más garantías.]

)

gpgconf proporciona acceso a la configuración de uno o más componentes del sistema GnuPG. Estos componentes corresponden más o menos a los programas que existen en el marco de trabajo de GnuPG, como GPG, GPGSM, DirMngr, etc. Pero esta no es una relación estricta uno a uno. No todas las opciones de configuración están disponibles a través de gpgconf. gpgconf proporciona un método genérico y abstracto para acceder a las opciones de configuración más importantes que pueden ser controladas de manera factible a través de tal

mecanismo.

gpgconf puede usarse para recopilar y cambiar las opciones disponibles en cada componente, y también puede proporcionar sus valores predeterminados. gpgconf proporcionará información de tipo detallada que puede usarse para restringir la entrada del usuario sin intentar realizar los

cambios.

gpgconf proporciona el backend de un editor de configuración. El editor de configuración normalmente sería un programa de interfaz gráfica de usuario que muestra las opciones actuales, sus valores predeterminados y permite al usuario realizar cambios en las opciones. Estos cambios pueden luego hacerse activos con gpgconf de nuevo. Tal programa que usa gpgconf de esta manera se llamar

á GUI a lo largo
de esta sección.

El comando --list-components listará todos los componentes que se pueden configurar con gpgconf. Usualmente, un componente corresponderá a un programa relacionado con GnuPG y contendrá las opciones del archivo de configuración de ese programa que se pueden modificar usando gpgconf. Sin embargo, este no es necesariamente el caso. Un componente también podría ser un grupo de opciones seleccionadas de varios programas, o contener opciones completamente virtuales que tienen un efecto especial en lugar de cambiar exactamente una opción en un archivo de

configuración.

Un componente es un conjunto de opciones de configuración que semánticamente pertenecen juntas. Además, varios cambios en un componente se pueden hacer de manera atómica con una sola operación. La GUI podría, por ejemplo, proporcionar un menú con una entrada por cada componente, o una ventana con una hoja de tabulación por

componente.

es:
