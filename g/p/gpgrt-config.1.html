NOMBRE

gpgrt-config - Script auxiliar para obtener información sobre la versión instalada de las bibliotecas gpg

SINOPSIS

gpgrt-config [opciones] [ módulo ]

DESCRIPCIÓN

gpgrt-config es una herramienta de script que es utilizada por las macros autoconf incluidas con el software gnupg (por ejemplo, AM_PATH_GPG_ERROR y AM_PATH_GPGME) para determinar las opciones del compilador y del enlazador que deben utilizarse para compilar y enlazar programas que usan la biblioteca específica (por ejemplo, libgpg-error o libgpgme). gpgrt-config utiliza los archivos .pc de pkg-config como fuente de datos.

Además de las opciones, gpgrt-config acepta un único argumento módulo que especifica el nombre base (sin el sufijo ".pc") del archivo pkg-config que se utilizará como entrada. El valor por defecto de módulo será gpg-error si no se especifica.

OPCIONES

gpgrt-config acepta las siguientes opciones:

--libdir=DIRLIB
Ruta del directorio padre de la ruta de búsqueda de archivos pkgconfig. Por ejemplo, ‘gpgrt-config --libdir=/usr/lib --exists gpgme’ analizará ‘/usr/lib/pkgconfig/gpgme.pc’.
--exists
Comprueba si el archivo pkg-config ‘módulo.pc’ existe y sale con éxito o error en consecuencia.
--modversion
Imprime la versión actualmente instalada de módulo en la salida estándar.
--libs
Imprime las opciones del enlazador que son necesarias para enlazar un programa que utiliza el módulo.
--cflags
Imprime las opciones del compilador que son necesarias para compilar un programa que utiliza el módulo.
--static
Modifica la salida si se enlaza estáticamente en lugar de dinámicamente.
--variable=NOMVAR
Imprime la variable NOMVAR del archivo pkg-config del módulo.

ERRORES

gpgrt-config intenta ser compatible con pkg-config y admitir la compilación cruzada bien, pero no pretende ser un reemplazo.
