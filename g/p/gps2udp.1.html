GPS2UDP(1) Documentación de GPSD GPS2UDP(1)

NOMBRE

gps2udp - enviar la salida de gpsd a uno o varios sitios de agregación

SINOPSIS

gps2udp [OPCIONES] [servidor[:puerto[:dispositivo]]]

gps2udp -h

gps2udp -V

DESCRIPCIÓN

gps2udp es una herramienta para conectarse a gpsd y enviar las sentencias recibidas a uno o varios destinos de host:puerto UDP. Esto hace que el programa sea útil para alimentar información AIS de gpsd a aishub, marinetraffic, shipfinder, ...

gps2udp no requiere privilegios de root, pero puede ejecutarse como root. Puede ejecutarse simultáneamente con otras herramientas que se conecten al gpsd local sin causar problemas.

La salida consistirá en sentencias NMEA (opción -n) y/o JSON (opción -j) de gpsd. La salida se envía a uno o varios destinos host a través de un socket de red UDP (opciones -u HOST:PORT).

Opcionalmente se puede especificar un servidor, un número de puerto TCP/IP y un dispositivo remoto. Si se omiten, gps2udp se conecta a localhost en el puerto predeterminado (2947) y monitoriza todos los dispositivos abiertos por gpsd.

gps2udp puede ejecutarse como un demonio (opción -b).

gps2udp está diseñado para ejecutarse sin problemas en segundo plano; se reconecta automáticamente a gpsd siempre que este se reinicia. Para fines de depuración, existe una opción para salir limpiamente después de un número determinado de paquetes (opción -c).

OPCIONES

-?, -h, --help

Imprime un mensaje de uso y sale.

-a, --ais

Enviar solo mensajes AIS.

-b, --daemon

Hace que gps2udp se ejecute como un demonio.

-c COUNT, --count COUNT

Salir después de enviar COUNT sentencias.

-d LVL, --debug LVL

Establece el nivel de depuración a LVL. LVL = 0 no imprime nada. LVL = 1 imprime el paquete enviado en stdout. LVL = 2 imprime los paquetes ignorados.

-j, --json

Genera sentencias JSON como salida.

-n, --nmea

Genera sentencias NMEA como salida.

-t, --tpv

Solo genera sentencias TPV. Implica --json.

-u HOST:PORT, --udp HOST:PORT

Destino UDP para las sentencias de salida (hasta cinco destinos).

-v, -V, --version

Imprime la versión del programa y sale. -v está obsoleto desde diciembre de 2020.

ARGUMENTOS

Por defecto, los clientes recopilan datos del demonio gpsd local que se ejecuta en localhost, utilizando el puerto predeterminado de GPSD 2947. El argumento opcional para cualquier cliente puede anular este comportamiento: [servidor[:puerto[:dispositivo]]]

Para obtener más explicaciones y ejemplos, consulte la sección ARGUMENTOS de la página del manual de gps(1)

EJEMPLOS

Con un gpsd en ejecución accesible en la red, esto recopilará datos de localhost:gpsd, los mostrará en stdout y enviará una copia para probar aishub en formato NMEA.

gps2udp -d 1 -n -u data.aishub.net:2222

Esto recopilará datos de un gpsd remoto ubicado en el host fridu.net, filtrará los mensajes AIS y los enviará a 3 destinos (aishub, marinetraffic, shipfinder) en formato NMEA, mientras se ejecuta en modo segundo plano.

gps2udp -a -n -b -u data.aishub.net:2222 -u 5.9.207.224:5321 \
   -u 109.200.19.151:4001 fridu.net:2947

VALORES DE RETORNO

0

en caso de éxito.

1

en caso de fallo
