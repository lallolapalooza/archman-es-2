gpgwrap(1) Manual de Comandos Generales gpgwrap(1)

NOMBRE

gpgwrap - un pequeño envoltorio para gpg

SINOPSIS

gpgwrap -V

gpgwrap -P [-v] [-i] [-a] [-p <archivo>]

gpgwrap -F [-v] [-i] [-a] [-c] [-p <archivo>] [-o <nombre>] [--] <archivo> [<archivo> ... ]

gpgwrap [-v] [-i] [-a] [-p <archivo>] [-o <nombre>] [--] gpg [opciones de gpg]

DESCRIPCIÓN

El Guardián de Privacidad de GNU (gpg) proporciona la opción --passphrase-fd. Esto le indica a gpg que lea la frase de contraseña desde el descriptor de archivo dado. Normalmente este descriptor de archivo se abre antes de gpg se ejecute mediante execvp(3). Exactamente eso es lo que gpgwrap está haciendo. La frase de contraseña puede pasarse a gpgwrap de 4 maneras:

  • como ruta de archivo, donde la frase de contraseña se almacena como texto plano en el archivo
  • se redirige desde otro programa a la entrada estándar de gpgwrap
  • a través de la variable de entorno GPGWRAP_PASSPHRASE
  • gpgwrap solicita la frase de contraseña

Sin precauciones, el primer punto socava la infraestructura segura que gpg proporciona. Pero en entornos puramente orientados a lotes esto puede ser lo que desee. De lo contrario, si está dispuesto a introducir frases de contraseña una vez y no quiere que se almacenen como texto plano en un archivo gpg-agent es lo que está buscando. Otra objeción de seguridad podría ser el uso de la variable de entorno GPGWRAP_PASSPHRASE que contiene la frase de contraseña y puede ser leída por otros procesos del mismo usuario.

OPCIONES

-V, --version
Imprime la versión y sale.
-P, --print
Obtiene la frase de contraseña y la imprime escapada en la salida estándar.
-F, --file
Lee comandos de gpg de los archivos dados. Si <archivo> es - se lee desde la entrada estándar. Se espera exactamente un comando por línea. La línea dada se maneja de la siguiente manera:
  • En primer lugar, la frase de contraseña se escapa. Esto significa que los caracteres no habituales son reemplazados por sus números octales escapados con barra invertida.
  • En segundo lugar, la frase de contraseña escapada se almacena en la variable de entorno GPGWRAP_PASSPHRASE.
  • "exec gpgwrap -- " se antepone a cada línea, antes de que el resultado se pase como argumento a "sh -c".
-h, --help
Imprime la información de uso.
-v, --verbose
Aumenta el nivel de verbosidad.
-i, --interactive
Siempre solicita la frase de contraseña (ignora -p y la variable de entorno).
-a, --ask-twice
Pregunta dos veces si solicita una frase de contraseña.
-c, --check-exit-code
Mientras se leen comandos de gpg de un archivo, gpgwrap ignora por defecto el código de salida de sus procesos secundarios. Esta opción habilita la comprobación del código de salida. Si un proceso secundario termina de forma anormal o con un código de salida distinto de 0 gpgwrap se detiene inmediatamente y devuelve con este código de salida. Véase también la sección ERRORES.
-p <archivo>, --passphrase-file <archivo>
Lee la frase de contraseña desde <archivo>. Si <archivo> es - se lee desde la entrada estándar. Se espera que la frase de contraseña esté en texto plano. Si esta opción no se proporciona, la frase de contraseña se tomará o bien de la variable de entorno GPGWRAP_PASSPHRASE o se solicitará en el tty de control si la variable de entorno no está definida.
-o <nombre>, --option-name <nombre>
Especifica el nombre de la opción "--passphrase-fd" que entiende el programa a ejecutar. Esto es útil si desea usar gpgwrap en combinación con otros programas que no sean gpg.

LIMITACIONES

La frase de contraseña dada está sujeta a varias limitaciones dependiendo de la manera en que se pasó a gpgwrap:

  • Hay una limitación de tamaño: la frase de contraseña no debería ser mayor que unos pocos kilobytes (examine el código fuente para el límite exacto).
  • gpgwrap le permite usar todos los caracteres en una frase de contraseña, incluso \000, pero esto no significa que gpg la aceptará. gpg puede rechazar su frase de contraseña o puede leer solo una parte de ella, si contiene caracteres como \012 (en C también conocido como \n).
  • Si define la variable de entorno GPGWRAP_PASSPHRASE debería tener especial cuidado con el carácter de barra invertida, porque gpgwrap usa la barra invertida para escapar números octales, (véase la opción -F). Por lo tanto, escriba la barra invertida misma como número octal: \134.

EJEMPLOS

1.
gpgwrap -p /ruta/a/un/archivo/secreto  \
gpg -c -z 0 --batch --no-tty  \
    --cipher-algo blowfish < archivo_entrada > archivo_salida
Lee la frase de contraseña desde /ruta/a/un/archivo/secreto y ejecuta gpg para hacer un cifrado simétrico de archivo_entrada y escribirlo en archivo_salida.
2.
gpgwrap -i -a  \
gpg -c -z 0 --batch --no-tty  \
    --cipher-algo blowfish < archivo_entrada > archivo_salida
Igual que lo anterior excepto que gpgwrap solicita la frase de contraseña dos veces.
3.
gpgwrap -F -i - <<EOL
gpg --decrypt --batch --no-tty < "$HOME/archivo_entrada1" > "$HOME/archivo_salida1"
gpg --decrypt --batch --no-tty < "$HOME/archivo_entrada2" > "$HOME/archivo_salida2"
gpg --decrypt --batch --no-tty < "$HOME/archivo_entrada3" > "$HOME/archivo_salida3"
gpg --decrypt --batch --no-tty < "$HOME/archivo_entrada4" > "$HOME/archivo_salida4"
EOL
gpgwrap solicita la frase de contraseña y ejecuta cuatro instancias de gpg para descifrar los archivos dados.
4.
GPGWRAP_PASSPHRASE="misfrasedecontraseñas"
export GPGWRAP_PASSPHRASE
gpgwrap -F -c -v /tmp/archivo_comandos1 - /tmp/archivo_comandos2 <<EOL
gpg --decrypt --batch --no-tty < "$HOME/archivo_entrada1" > "$HOME/archivo_salida1"
gpg --decrypt --batch --no-tty < "$HOME/archivo_entrada2" > "$HOME/archivo_salida2"
gpg --decrypt --batch --no-tty < "$HOME/archivo_entrada3" > "$HOME/archivo_salida3"
gpg --decrypt --batch --no-tty < "$HOME/archivo_entrada4" > "$HOME/archivo_salida4"
EOL
Igual que lo anterior excepto que gpgwrap obtiene la frase de contraseña a través de la variable de entorno, lee comandos adicionalmente de otros archivos y comprueba el código de salida de cada instancia de gpg . Esto significa que si un comando de gpg tiene un código de salida distinto de cero, no se ejecutan más comandos. Además gpgwrap produce una salida detallada.
5.
GPGWRAP_PASSPHRASE="$(gpgwrap -P -i -a)"
export GPGWRAP_PASSPHRASE
find . -maxdepth 1 -type f |
while read FILE; do
    FILE2="$FILE.bz2.gpg"
    bzip2 -c "$FILE" |
    gpgwrap gpg -c -z 0 --batch --no-tty  \
        --cipher-algo blowfish > "$FILE2" &&
    touch -r "$FILE" "$FILE2" &&
    rm -f "$FILE"
done
Lee la frase de contraseña, comprime todos los archivos en el directorio actual, los cifra y conserva la fecha del archivo original.
6.
find . -maxdepth 1 -type f -name '*.bz2.gpg' |
awk '{
    printf("gpg --decrypt --batch --no-tty --quiet ");
    printf("--no-secmem-warning < %s\n", $0);
    }' |
gpgwrap -F -i -c - |
bzip2 -d -c - |
grep -i 'data'
Descifra todos los archivos *.bz2.gpg en el directorio actual, los descomprime y imprime todas las apariciones de datos. Si redirige el resultado a less se encontrará con problemas porque gpgwrap y less intentan leer del TTY al mismo tiempo. En tal caso es mejor usar la variable de entorno para dar la frase de contraseña (el ejemplo anterior muestra cómo hacerlo).
7.
GPGWRAP_PASSPHRASE="$(gpgwrap -P -i -a)"
export GPGWRAP_PASSPHRASE
gpgwrap -P |
ssh -C -x -P -l user host "
    GPGWRAP_PASSPHRASE=\"\$(cat)\"
    ...
    "
Solicita una frase de paso dos veces y la escribe en la GPGWRAP_PASSPHRASE variable de entorno.
8.
echo -n "Frase de paso: "
stty -echo
read GPGWRAP_PASSPHRASE
echo
stty echo
export GPGWRAP_PASSPHRASE
Otra forma de solicitar manualmente la frase de paso. Era necesaria en combinación con versiones anteriores de gpgwrap, porque no soportaban -P. Ten en cuenta que con este método no se realiza ninguna conversión automática a números octales escapados con barra invertida.
9.
echo "mysecretpassphrase" |
gpg --batch --no-tty --passphrase-fd 0  \
    --output outfile --decrypt infile
Método sencillo para dar la frase de paso a gpg sin gpgwrap. Ten en cuenta que no puedes usar stdin para pasar un archivo a gpg, porque stdin ya está siendo utilizado para la frase de paso.
10.
gpg --batch --no-tty  \
    --passphrase-fd 3 3< /path/to/a/secret/file  \
    < infile > outfile
Este es un método más avanzado para dar la frase de paso, es equivalente a la opción -p de gpgwrap. Este ejemplo debería funcionar al menos con bash.
11.
gpg --batch --no-tty --passphrase-fd 3  \
    3< <(echo "mysecretpassphrase")  \
    < infile > outfile
Como arriba, pero la frase de paso se da directamente. Este ejemplo debería funcionar al menos con bash.

ERRORES

En la versión 0.02 de gpgwrap el código de salida de gpg solo se devolvía si gpgwrap leía la frase de paso desde un archivo. Desde la versión 0.03, solo -F omite la comprobación del código de salida por defecto, pero se puede habilitar con -c.
