NOMBRE

gpg-tui - gestiona tus claves GnuPG con facilidad

SINOPSIS

gpg-tui [OPCIONES]

DESCRIPCIÓN

gpg-tui es una Interfaz de Usuario de Terminal para GnuPG.

Su objetivo es facilitar las operaciones de gestión de claves, como listarlas, exportarlas o firmarlas, proporcionando una interfaz junto con un modo de línea de comandos para operaciones más complejas. No pretende ser una interfaz completa para todas las funcionalidades que ofrece gpg, pero intenta aportar un enfoque más interactivo a la gestión de claves.

OPCIONES

-a, --armor
Habilita la salida en formato ASCII armazón.
--splash
Muestra la pantalla de bienvenida al iniciar.
--config <ruta>
Establece el archivo de configuración [env: GPG_TUI_CONFIG=]
--homedir <directorio>
Establece el directorio de inicio de GnuPG [env: GNUPGHOME=]
-o, --outdir <directorio>
Establece el directorio de salida [env: OUTDIR=]
--outfile <ruta>
Establece la plantilla para el nombre del archivo de salida [env: OUTFILE=]
-d, --default-key <clave>
Establece la clave predeterminada para firmar [env: DEFAULT_KEY=]
-t, --tick-rate <ms>
Establece la velocidad de actualización (tick rate) de la terminal [env: TICK_RATE=] [predeterminado: 250]
-c, --color <color>
Establece el color de acento de la terminal [env: COLOR=] [predeterminado: gray]
-s, --style <estilo>
Establece el estilo de la terminal [env: STYLE=] [predeterminado: colored] [posibles valores: plain, colored]
-f, --file-explorer <app>
Establece la utilidad para la selección de archivos [env: FILE_EXPLORER=] [predeterminado: xplr]
--detail-level <nivel>
Establece el nivel de detalle para las claves [env: DETAIL_LEVEL=] [predeterminado: minimum] [posibles valores: minimum, standard, full]
--log-file <ruta>
Establece el archivo donde guardar los registros [env: LOG_FILE=]
--select <opción>
Habilita el modo de selección [env: SELECT=] [posibles valores: key_id, key_fpr, user_id, row1, row2]
-h, --help
Imprime información de ayuda.
-V, --version
Imprime información de la versión.

ATAJOS DE TECLADO

INTERFAZ DE USUARIO

Atajo de Teclado Acción
? mostrar ayuda
o,espacio,enter mostrar opciones
hjkl,flechas,pgkeys navegar
n cambiar a modo normal
v cambiar a modo visual
c cambiar a modo de copia
p,C-v pegar desde el portapapeles
a alternar salida en armazón
1,2,3 establecer nivel de detalle
t,tab alternar detalle (todos/seleccionados)
` alternar margen de tabla
m alternar tamaño de tabla
C-s alternar estilo
/ buscar
: ejecutar comando
r,f5 refrescar aplicación
q,C-c/d,escape salir de la aplicación

GESTIÓN DE CLAVES

Atajo de Teclado Acción
x exportar clave
s firmar clave
e editar clave
i importar clave(s)
f recibir clave
u enviar clave
g generar clave
d,retroceso eliminar clave
C-r refrescar claves
