NOMBRE

gpodder-migrate2tres - Migrador de perfiles de gPodder 2.x a 3.x

SINOPSIS

gpodder-migrate2tres

DESCRIPCIÓN

Utilidad de línea de comandos para migrar los datos de configuración de gPodder 2.x del usuario para su uso con gPodder 3.x. Ejecute el comando sin opciones para migrar los datos de configuración del usuario actual. Se proporcionará información.

La utilidad gpodder-backup (incluida con gPodder 2.x) se puede utilizar para hacer una copia de seguridad de la configuración antes de la migración. Actualmente no hay migración de gPodder 3.x a gPodder 2.x.

Mayo de 2012 gpodder 3.2.0
