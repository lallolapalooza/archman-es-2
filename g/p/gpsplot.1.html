gpsplot(1)

Paquete: gpsd

Licencias: BSD

GPSPLOT(1) Documentación de GPSD GPSPLOT(1)

NOMBRE

gpsplot - herramienta para volcar dinámicamente datos de trazado desde gpsd

SINOPSIS

gpsplot [OPCIONES] [servidor[:puerto[:dispositivo]]]

gpsplot -h

gpsplot -V

DESCRIPCIÓN

gpsplot es una herramienta para conectarse a gpsd y trazar dinámicamente datos en la pantalla del usuario. Los tipos de trazado incluyen diagramas de dispersión y gráficos de tiras.

El trazado requiere el módulo Python Matplotlib, y sus numerosas dependencias, instaladas en el host de visualización. Si el host de visualización no es el host de gpsd, entonces Matplotlib no necesita estar en el host de gpsd.

gpslot no requiere privilegios de root, pero se puede ejecutar como root. Ejecutar bajo sudo causará alguna pérdida de funcionalidad. Puede ejecutarse concurrentemente con otras herramientas que se conecten al gpsd local sin causar problemas.

OPCIONES

-?, -h, --help

Muestra un mensaje de uso y sale.

-b BACKEND, --backend BACKEND

Establece el backend interactivo de Matplotlib a BACKEND.

-B, --backends

Muestra los backends interactivos disponibles de Matplotlib y sale. Los backends de Matplotlib varían drásticamente en cuanto a su velocidad de ejecución y su apariencia. Pruébalos todos para verlo por ti mismo.

-d LVL, --debug LVL

Establece el nivel de depuración a LVL.

--device DISPOSITIVO

El DISPOSITIVO en gpsd al que conectarse. Por defecto, todos.

--exit

Sale después de que se complete --count, --file o --file.

--fields CAMPOS

El código para los campos a trazar. CAMPOS es uno de: llh (latitud/longitud/altitudHAE) o llm (latitud/longitud/altitudMSL).

--file ARCHIVO

Lee JSON desde ARCHIVO en lugar de desde gpsd.

--host HOST

Conéctate al gpsd en HOST (servidor). Por defecto, localhost.

--image IMAGEN.EXT

Guarda el trazado como IMAGEN.EXT. EXT determina el tipo de imagen (.jpg, .png, etc.). Qué EXT es compatible depende de la instalación.

-n COUNT, --count COUNT

Detente después de COUNT mensajes de trazado. 0 para deshabilitar. Por defecto 0',

--plottype TIPOTRAZADO

El tipo de trazado a realizar. TIPOTRAZADO es uno de 'scatterplot' o 'stripchart'.

-p PORT, --port PORT

Usa PORT para conectarte a gpsd. Por defecto, 2947.

-V, --version

Muestra la versión del programa y sale.

-x SECONDS, --seconds SECONDS

Detente después de SECONDS. 0 para deshabilitar. Por defecto 0',

ARGUMENTOS

Por defecto, los clientes recopilan datos del demonio gpsd local que se ejecuta en localhost, utilizando el puerto GPSD predeterminado 2947. El argumento opcional para cualquier cliente puede anular este comportamiento: [servidor[:puerto[:dispositivo]]]

Para obtener más explicaciones y ejemplos, consulte la sección ARGUMENTOS en la página del manual de gps(1)

ENTORNO

Puedes establecer la variable de entorno MPLBACKEND a tu backend preferido de Matplotlib. Esto te ahorra tener que usar -b BACKEND cada vez que ejecutas gpsplot.

EJEMPLOS

Genera un diagrama de dispersión de Latitud, Longitud y la Altitud sobre el Nivel Medio del Mar (altMSL). Detente después de 60 segundos:

gpsplot --seconds 60 --fields llm

Genera un diagrama de dispersión de Latitud, Longitud y la Altitud sobre el Elipsoide (altHAE). Detente después de 60 mediciones:

gpsplot --count 60 --plottype stripchart

Usa el backend WXAgg para repetir el último experimento y ver si es más rápido o se ve mejor para ti.

export MPLBACKEND=WX
gpsplot --count 60 --plottype stripchart

Genera un diagrama de dispersión local de Latitud, Longitud y altMSL desde una instancia remota de gpsd en el host "example.com" y el dispositivo remoto "/dev/ttyS0". Recopila 60 mediciones, Detente, guarda el trazado como "save.jpg" y sal:

gpsplot --count 60 --exit --fields llm --image save.jpg example.com::/dev/ttyS0

VALORES DE RETORNO

0

en caso de éxito.

1

en caso de fallo
