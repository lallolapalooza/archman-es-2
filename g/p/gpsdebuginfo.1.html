GPSDEBUGINFO(1) Documentación de gpsd GPSDEBUGINFO(1)

NOMBRE

gpsdebuginfo - Genera un volcado de depuración de gpsd de tu host.

SINOPSIS

gpsdebuginfo

DESCRIPCIÓN

gpsdebuginfo es un script de shell que ejecuta una serie de pruebas cortas para ver el estado de gpsd en tu máquina. Ejecútalo y envía la salida completa, sin cambios, cuando solicites ayuda de soporte.

El script no debería recopilar Información de Identificación Personal (PII). Es posible que desees estudiar la salida antes de enviarla para verificarlo.

gpsdebuginfo debe ejecutarse como root. Puede ejecutarse como un usuario normal, pero con pérdida de funcionalidad. Ejecutar bajo sudo puede causar resultados engañosos.

OPCIONES

Ninguna.

ENTORNO

Este script depende de las siguientes variables de entorno:

PATH

Para encontrar gpsd, gpspipe y otras partes instaladas de gpsd.

PYTHONPATH

Para encontrar el módulo Python gps.

VALORES DE RETORNO

0

en caso de éxito.

VER TAMBIÉN

gpsd(8), cgps(1), gps(1), gpspipe(1)
