gpscsv(1)

Paquete: gpsd

Licencias: BSD

GPSCSV(1) Documentación de GPSD GPSCSV(1)

NOMBRE

gpscsv - volcar la salida JSON como CSV

SINOPSIS

gpscsv [OPCIONES] [host[:puerto[:dispositivo]]]

gpscsv -h

gpscsv -V

DESCRIPCIÓN

gpscsv es un programa simple de Python para leer flujos de datos JSON de gpsd y emitirlos en formato de valores separados por comas (CSV). Toma la entrada de un gpsd especificado e informa a la salida estándar. El programa se ejecuta hasta que gpsd muere, se procesan mensajes "-n COUNT", transcurren "-x SEGUNDOS", o se interrumpe por ^C o de otra manera.

gpscsv solo puede recopilar datos que su gpsd ya está enviando. Use gpspipe para ver qué clases de mensajes JSON está enviando.

Un buen uso de gpscsv es crear archivos CSV para usar con el programa gnuplot.

gpscsv no necesita ser root, pero funcionará bien como root.

OPCIONES

El programa acepta las siguientes opciones:

-?, -h, --help

Mostrar información de ayuda y salir.

-c MCLASS, --class MCLASS

Selecciona las clases de mensajes JSON de tipo MCLASS. Anula la clase predeterminada de TPV. Ver la sección CLASES más abajo para más información.

--cvt-isotime

Convierte los campos llamados "time" de tiempo ISO a tiempo UNIX.

-D LVL, --debug LVL

Establece el nivel de depuración a LVL. Predeterminado 0. Argumentos más altos que 0 producen más salida de depuración.

--device DISPOSITIVO

El DISPOSITIVO en gpsd al que conectarse. Predeterminado: todos.

-f CAMPOS, -fields CAMPOS

Los CAMPOS del mensaje JSON a volcar a la salida. Establezca CAMPO a vacío ('') para todos los campos vistos inicialmente. El predeterminado varía según la CLASE.

--file ARCHIVO

Leer JSON desde ARCHIVO en lugar de desde gpsd.

--header CABECERA

Establece el estilo de la cabecera a CABECERA. 0 para sin cabecera, 1 para volcar campos como cabecera, 2 para enviar campos como un comentario ('#'). Predeterminado: 1.

--host HOST

Conéctese a gpsd en HOST. Predeterminado: localhost.

-n COUNT, --count COUNT

Salir después de emitir COUNT registros. Establezca COUNT a 0 para deshabilitar. Predeterminado: 0.

--port PUERTO

Use PUERTO para conectarse a gpsd. Predeterminado: 2947.

--separator SEPARADOR

Use SEPARADOR como el separador de campos. El separador predeterminado es una coma (',').

-V, --version

Mostrar la versión de gpscsv y salir.

-x SECONDS, --seconds SECONDS

Salir después de que hayan transcurrido SECONDS segundos. Establezca SECONDS a 0 para deshabilitar. Predeterminado: 0.

Todas las opciones individuales anteriores pueden especificarse múltiples veces, pero solo la última de cada una se usará.

CLASES

Algunas de las clases de mensajes JSON de gpsd incluyen subclases. gpscsv permite el acceso directo a ellas usando una meta-clase (MCLASS).

MCLASS Clase Descripción
ALMANAC SUBFRAME ALMANAC desde JSON SUBFRAME
HEALTH SUBFRAME HEALTH desde JSON SUBFRAME
HEALTH2 SUBFRAME HEALTH2 desde JSON SUBFRAME
IONO SUBFRAME IONO desde JSON SUBFRAME
NMCT SUBFRAME NMCT desde JSON SUBFRAME
SUBFRAME1 SUBFRAME SUBFRAME1 (Efemérides 1) desde JSON SUBFRAME
SUBFRAME2 SUBFRAME SUBFRAME2 (Efemérides 2) desde JSON SUBFRAME
SUBFRAME3 SUBFRAME SUBFRAME3 (Efemérides 3) desde JSON SUBFRAME
SAT SKY Satélites individuales desde SKY
SKY SKY Las partes básicas del JSON SKY
TPV TPV Las partes básicas del JSON TPV

ARGUMENTOS

Por defecto, los clientes recopilan datos del demonio gpsd local que se ejecuta en localhost, utilizando el puerto predeterminado de GPSD 2947. El argumento opcional para cualquier cliente puede anular este comportamiento: [servidor[:puerto[:dispositivo]]]

Para obtener más explicaciones y ejemplos, consulte la sección ARGUMENTOS de la página del manual gps(1)

gpscsv(1) — gpsd 3.27

NAME

gpscsv

parse GPSD JSON or NMEA to CSV

SYNOPSIS

gpscsv [-p poll_interval] [-r report_interval] [-d debug_level] [-V]

DESCRIPTION

This program reads GPSD JSON or NMEA sentences from standard input, converts them to CSV format, and writes them to standard output.

The structure of the output is dependent on the input. For NMEA sentences, the output is simply the fields from the sentences, with the '$' and the checksum removed.

For JSON sentences, the program has to know which fields to output. The default fields are those found in the SKY, TV, and EPV subobjects. Additional fields can be requested using the command line options.

The command line options are as follows:

OPTIONS

-p
Sets the poll interval. The default is 5 seconds.
-r
Sets the report interval. The default is 1 second.
-d
Sets the debug level. The default is 0.
-V
Prints version information and exits.

CLASSES

gpscsv can be configured to output specific fields from the JSON stream. These are defined as classes. The default classes are: tpv, epv, sky.

tpv
Time, Position, Velocity data.
epv
Estimated Position and Velocity data.
sky
Sky view data.
sat
Satellite data.
device
Device data.

ARGUMENTS

The following arguments can be provided to select the fields to be output. Each argument selects a class of data. If no arguments are given, then the classes tpv, epv, and sky are selected.

tpv
Selects Time, Position, Velocity data.
epv
Selects Estimated Position and Velocity data.
sky
Selects Sky view data.
sat
Selects Satellite data.
device
Selects Device data.

The fields output for each class are hardcoded in the program.

EXAMPLES

Output all data from NMEA sentences:

  $ gpspipe -r 1 -f partial | gpscsv

Output all data from JSON sentences:

  $ gpspipe -r 1 -f json | gpscsv

Output Time, Position, Velocity data, plus Estimated Position and Velocity data:

  $ gpspipe -r 1 -f json | gpscsv tpv epv

Output Satellite data and Sky view data:

  $ gpspipe -r 1 -f json | gpscsv sat sky

Output Device data:

  $ gpspipe -r 1 -f json | gpscsv device

Use gnuplot to plot time vs latitude, using tpv.dat, which contains time, latitude, longitude, altitude, and speed.

First, set up gnuplot to read CSV data.

  # this are csv files
  gnuplot> set datafile separator ','
  # use the first line as title
  gnuplot> set key autotitle columnhead
  # X axis is UNIT time in seconds.
  gnuplot> set xdata time
  gnuplot> set timefmt "%s"

Now to plot time vs latitude, using tpv.dat from above:

  gnuplot> plot 'tpv.dat' using 1:2

Then to plot longitude and altHAE, in separate plots:

  gnuplot> plot 'tpv.dat' using 1:3
  gnuplot> plot 'tpv.dat' using 1:4

Put both latitude and longitude on one plot:

  gnuplot> set y2tics
  gnuplot> plot 'tpv.dat' using 1:2, '' using 1:3 axes x1y2

Plot epx, epy, epv, eph, and sep in one plot, using ep.dat from above:

  gnuplot> plot 'ep.dat' using 1:2, '' using 1:3, \
           '' using 1:4, '' using 1:5, '' using 1:6

Plot all the DOPs on one plot, from sky.dat above:

  gnuplot> plot 'sky.dat' using 1:2, '' using 1:3, '' using 1:4, \
           '' using 1:5, '' using 1:6, '' using 1:7, '' using 1:8

Plot nSat and uSat together:

  gnuplot> plot 'sat.dat' using 1:2, '' using 1:3

Lat/lon scatter plot:

  # x is no longer time
  gnuplot> set xdata
  gnuplot> plot 'tpv.dat' using 3:2 title 'fix'

RETURN VALUES

0

on success.

1

on failure
