gpspipe(1)

Paquete: gpsd

Licencias: BSD

GPSPIPE(1) Documentación de GPSD GPSPIPE(1)

NOMBRE

gpspipe - herramienta para conectarse a gpsd y obtener frases

SINOPSIS

gpspipe [OPCIONES] [servidor[:puerto[:dispositivo]]]

gpspipe -h

gpspipe -V

DESCRIPCIÓN

gpspipe es una herramienta para conectarse a gpsd y sacar por stdout las frases recibidas. Esto hace que el programa sea útil como tubería desde gpsd hacia otro programa o archivo.

gpspipe no requiere privilegios de root y puede ejecutarse concurrentemente con otras herramientas que se conecten al gpsd local sin causar problemas.

La salida consistirá en una o ambas de las frases NMEA en bruto o nativas de gpsd . Cada línea puede llevar opcionalmente una marca de tiempo. También existe una opción para salir de forma ordenada después de una cantidad dada de paquetes.

gpspipe puede ejecutarse como demonio, pero requiere el indicador -o, --output para escribir la salida en un archivo.

OPCIONES

-?, -h, --help

Imprime un mensaje de uso y sale.

-2, --split24

-2 activa el indicador split24 en los informes AIS.

-B, --nobuffer

No hace buffer de la salida.

-d, --daemonize

Se ejecuta como demonio.

-D LVL, --debug LVL

Establece el nivel de depuración a LVL.

-l, --sleep

Duerme diez segundos antes de intentar conectarse a gpsd. Esto es muy útil al ejecutarse como demonio, dando gpsd tiempo para arrancar antes de intentar la conexión.

-n COUNT, --count COUNT

Sale después de que se hayan emitido COUNT mensajes.

-o FILE, --output FILE

Hace que los datos recopilados se escriban en el archivo especificado. El uso de esta opción es obligatorio si gpspipe se ejecuta como demonio.

-p, --profile

Vuelca la información de perfilado en JSON.

-P, --pps

Habilita el volcado de la deriva PPS en JSON en los modos NMEA y raw.

-r, --nmea

Hace que se emitan frases NMEA. Puede ser NMEA, pseudo NMEA construido a partir de datos binarios, o alguna combinación de ambos.

-R, --raw

Hace que se emitan datos super-raw (binario de gps). Esto reenviará exactamente lo que envió el dispositivo.

-s DEV, --serial DEV

Hace que los datos recopilados se escriban en el dispositivo serie (DEV) especificado con la configuración 4800 8N1. Así gpspipe puede usarse con las opciones -s, --serial y -r, --nmea para emular un puerto serie conectado por hardware a un GPS que gpsd está gestionando.

-S, --scaled

Establece el indicador scaled. Esto es solo para datos AIS y SUBFRAME. Los datos escalados se emitirán en el JSON, en lugar de los datos en bruto en el JSON.

-t, --timestamp

Añade una marca de tiempo UTC a cada frase emitida.

-T FMT, --timefmt FMT

Establece el formato de la marca de tiempo. Véase strftime(3) para los marcadores disponibles. Establecer esta opción implica -t (--timestamp). La configuración por defecto es "%F %T"

-u, --usec

Usa una marca de tiempo con resolución de usec, implica -t (--timestamp). Úsese dos veces (-uu) para emitir sec.usec.

-v, --spinner

Muestra un indicador de actividad giratorio en stderr. Esto es útil si stdout se redirige a un archivo o una tubería. Por defecto, el indicador avanza con cada mensaje escrito; especificar -v, o --spinner, más de una vez duplicará el número de mensajes necesarios para rotar el indicador.

-V, --version

Imprime la versión del programa y sale.

-w, --json

Hace que se emitan frases JSON nativas de gpsd .

-x SEC, --seconds SEC

Sale después de un retardo de SEC segundos.

-Z, --zulu

Establece el formato de la marca de tiempo iso8601: implica -t.

Debe especificarse al menos uno de -R, -r o -w .

Debe usar -o si usa -d.

ARGUMENTOS

Por defecto, los clientes recopilan datos del demonio local gpsd que se ejecuta en localhost, usando el puerto GPSD por defecto 2947. El argumento opcional de cualquier cliente puede anular este comportamiento: [servidor[:puerto[:dispositivo]]]

Para una explicación más detallada y ejemplos, véase la sección ARGUMENTOS en la página man gps(1)

EJEMPLOS

Cuando gpsd esté en ejecución, este ejemplo enviará cien frases NMEA en bruto a la salida estándar y luego saldrá:

$ gpspipe -r -n 100

Cuando gpsd esté en ejecución, este ejemplo esperará como máximo 5 segundos un mensaje TPV, lo imprimirá en stdout y luego saldrá:

$ gpspipe -x 5 -w|sed -n '/TPV/{p;q}'

Use gpspipe y socat para servir NMEA desde el gpsd local en el puerto tcp 2948:

$ socat EXEC:'gpspipe -r' TCP-LISTEN:2948,reuseaddr,fork

Los paranoicos pueden querer que socat se ejecute como el usuario 'nobody' y solo acepte conexiones de la red local. Usar la opción -B de gpspipe reducirá la latencia y el jitter. El "su=nobody" significa que esto debe ejecutarse como root:

# socat EXEC:'gpspipe -rB' \
   TCP-LISTEN:2948,reuseaddr,fork,su=nobody,range=192.168.0.0/24

VALORES DE RETORNO

0

en caso de éxito.

1

en caso de fallo
