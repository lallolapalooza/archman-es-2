NOMBRE

gpick - selector de color avanzado

SINOPSIS

gpick [ARCHIVO]

DESCRIPCIÓN

gpick inicia una aplicación y abre ARCHIVO si se especifica

OPCIONES

-v, --version
Imprime información de la versión.
-g, --geometry
Geometría de la ventana.
-p, --pick
Seleccionar un color. Puedes insertar el color en el puntero en el portapapeles pulsando CTRL-C. Para ocultar la instancia flotante, pulsa ESC.

Cuando se utiliza esta opción, gpick se queda ejecutándose en segundo plano, de modo que todas las demás instancias flotantes no inician un nuevo proceso. Si se necesita cerrar el proceso, utiliza la bandera -s.

-s, --single
Seleccionar un color y salir.
-o, --output
Salida del color seleccionado.
-c, --converter-name
Nombre del convertidor utilizado para el modo selector flotante. Los convertidores disponibles son "color_web_hex", "color_css_rgb" y "color_css_hsl".
--no-newline
Salida del color seleccionado sin nueva línea.
--no-start
No iniciar si ya no se está ejecutando.

EJEMPLOS

Aquí tienes algunos ejemplos de uso de gpick

gpick -o -s

Abre una instancia flotante (es decir, no se queda ejecutándose en segundo plano) y envía el color seleccionado a STDOUT.

gpick -o -s -c color_css_hsl | xclip -sel c

Inserta el color seleccionado en el PORTAPAPELES utilizando la notación CSS HSL.
