Si una opción larga muestra un argumento como obligatorio, entonces también es obligatorio para la opción corta

Ubicación del archivo de

Los resultados se escriben en la sa

Interpretación del archivo de

entrada:
-e, --delimiters=LISTA-DE-DELIMITAD
ORES
Permite al usuario proporcionar una cadena que contenga los delimitadores utilizados para separar las palabras clave de sus atributos. El valor predeterminado es
",".
-t, --struct-ty
pe
Permite al usuario incluir una declaración de tipo estructurado para el código generado. Cualquier texto antes de %% se considera parte de la declaración de tipo. Las palabras clave y los campos adicionales pueden seguir a esto, un grupo de campos por
línea.
--ignore-ca
se
Considera los caracteres ASCII en mayúsculas y min
úsculas como equivalentes. Tenga en cuenta que
las asignaciones de mayúsculas/minúsculas dep
endientes de la configuración regional se ignoran.

Lenguaje para el código de

salida:
-L, --language=NOMBRE-DE-LENGU
AJE
Genera código en el lenguaje especif
icado. Los lenguajes manejados actual
mente son C++, ANSI-C, C y KR-C
. El valor predeterminado es ANSI-C.

Detalles en el código de

salida:
-K, --slot-name=NOM
BRE
Selecciona el nombre del componente de la palabra clave en la estructura de la palabra
clave.
-F, --initializer-suffix=INICIALIZADO
RES
Inicializadores para componentes adicionales en la estructura de la palabra
clave.
-H, --hash-function-name=NOM
BRE
Especifica el nombre de la función hash generada. El valor predeterminado es
'hash'.
-N, --lookup-function-name=NOM

Especifica el nombre de la función de búsqueda generada. El nombre predeterminado es
'in_word_set'.
-Z, --class-name=NOM

Especifica el nombre de la clase C++ generada. El nombre predeterminado es

-7, --seven-b

Asume caracteres de 7

-l, --compare-leng

Compara las longitudes de las claves antes de intentar una comparación de cadenas. Esto es necesario si las palabras clave contienen bytes NUL. También ayuda a reducir el número de comparaciones de cadenas realizadas durante la
búsqueda.
-c, --compare-strn
cmp
Genera código de comparación usando strncmp en lugar de
strcmp.
-C, --readonly-tab

Hace que el contenido de las tablas de búsqueda generadas sea constante, es decir, de solo

-E, --en

Define valores constantes usando un enum local a la función de búsqueda en lugar de con

-I, --includ

Incluye el archivo de inclusión del sistema necesario <string.h> al principio del
código.
-G, --global-tab
le
Genera la tabla estática de palabras clave como una variable global estática, en lugar de ocultarla dentro de la función de búsqueda (que es el comportamiento predeterminado)
.
-P, --p
ic
Optimiza la tabla generada para su inclusión en bibliotecas compartidas. Esto reduce el tiempo de inicio de los programas que usan una biblioteca compartida que contiene el código
generado.
-Q, --string-pool-name=NOM
BRE
Especifica el nombre del pool de cadenas generado por la opción --pic. El nombre predeterminado es
'stringpool'.
--null-strin
gs
Usa cadenas NULL en lugar de cadenas vacías para las entradas de la tabla de palabras clave
vacías.
--constants-prefix=PREFI
JO
Especifica el prefijo para las constantes como
TOTAL_KEYWORDS.
-W, --word-array-name=NOM
BRE
Especifica el nombre del array de la lista de palabras. El nombre predeterminado es
'wordlist'.
--length-table-name=NOM
BRE
Especifica el nombre del array de la tabla de longitudes. El nombre predeterminado es
'lengthtable'.
-S, --switch=CUEN
TA
Hace que el código C generado use un esquema de declaración switch, en lugar de una tabla de búsqueda de array. Esto puede llevar a una reducción tanto en el tiempo como en el espacio requerido para algunos archivos de claves. El argumento CUENTA determina cuántas declaraciones switch se generan. Un valor de 1 genera 1 switch que contiene todos los elementos, un valor de 2 genera 2 tablas con 1/2 de los elementos en cada tabla, etc. Si CUENTA es muy grande, digamos 1000000, el código C generado hace una búsqueda
binaria.
-T, --omit-struct-t
ype
Evita la transferencia de la decla
ración de tipo al archivo de salid
a. Use esta opción si el ti

Algoritmo empleado por

gperf:
-k, --key-positions=CLA
VES
Selecciona las posiciones de las claves utilizadas en la función hash. Las opciones permitidas van entre 1-255, inclusive. Las posiciones se separan por comas, se pueden usar rangos, y las posiciones de las claves pueden aparecer en cualquier orden. Además, el metacaracter '*' hace que la función hash generada considere TODAS las posiciones de las claves, y $ indica el "carácter final" de una clave, por ejemplo, $,1,2,4,
6-10.
-D, --duplicat
es
Maneja palabras clave que tienen valores hash duplicados. Esto es útil para ciertos conjuntos de palabras clave altamente
redundantes.
-m, --multiple-iterations=ITERACIO
NES
Realiza múltiples elecciones de los -i y -j valores, y elige los mejores resultados. Esto aumenta el tiempo de ejecución en un factor de ITERACIONES pero hace un buen trabajo minimizando el tamaño de la tabla
generada.
-i, --initial-asso=
N
Proporciona un valor inicial para el array de valores asociados. El valor predeterminado es 0. Establecer este valor más alto ayuda a inflar el tamaño de la tabla
final.
-j, --jump=VALOR-SA
LTO
Afecta el "valor de salto", es decir, cuánto avanzar el valor del carácter asociado en caso de colisiones. Debe ser un número impar, el valor predeterminado es
5.
-n, --no-strl
en
No incluye la longitud de la palabra clave al calcular la función
hash.
-r, --rand
om
Utiliza aleatoriedad para inicializar la tabla de valores
asociados.
-s, --size-multiple=
N
Afecta el tamaño de la tabla hash generada. El argumento numérico N indica "cuántas veces más grande o más pequeña" debe ser el rango de valores asociados, en rela
ción con el número de claves, por ejemplo, un valor de 3 significa "permitir que el valor asociado máximo sea aproximadamente 3 veces más grande que el número de c
laves de entrada". A la inversa, un valor de 1/3 significa "hacer que el valor asociado máximo sea aproximadamente 3 veces más pequeño que el número de claves de e
ntrada". Una tabla más grande debería disminuir el tiempo requerido para una búsqueda fallida, a costa de espacio de tabla adicional. El valor predeterminado es 1. ss="Ss">
