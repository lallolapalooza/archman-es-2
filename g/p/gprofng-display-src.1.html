GPROFNG-DISPLAY-SRC(1) Comandos de usuario GPROFNG-DISPLAY-SRC(1)

NOMBRE

gprofng-display-src - Muestra el código fuente y opcionalmente el desensamblado del objeto destino

SINOPSIS

gprofng display src [opción(es)] archivo-destino

DESCRIPCIÓN

Muestra la lista del código fuente, o el código fuente entrelazado con código de desensamblado, tal como se extrae del archivo destino (un ejecutable, objeto compartido, archivo objeto o un archivo .class de Java).

Por ejemplo, este comando muestra la lista del código fuente y desensamblado para una función llamada mxv_core que forma parte del archivo objeto mxv.o:

$ gprofng display src -disasm mxv_core mxv.o

Para listar el código fuente y el desensamblado de todas las funciones en este archivo, use el siguiente comando:

$ gprofng display src -disasm all -1 mxv.o

El archivo-destino es el nombre de un ejecutable, objeto compartido, archivo objeto (.o) o archivo .class de Java.

Si no se proporcionan opciones, se muestra la lista del código fuente del archivo-destino. Esto es equivalente a -source all -1. Si esta información no está disponible, se imprime un mensaje al respecto.

OPCIONES

--version
Imprime el número de versión y sale.
--help
Imprime información de uso y sale.
-functions
Lista todas las funciones del objeto dado.
-source item etiqueta
Muestra el código fuente de item en archivo-destino. La etiqueta se usa para diferenciar en caso de que haya múltiples ocurrencias con el mismo nombre. Consulte la sección NOTAS para la definición de item y etiqueta.
-disasm item etiqueta
Incluye el desensamblado en la lista del código fuente. La lista por defecto no incluye el desensamblado. Si el código fuente no está disponible, muestra solo una lista del desensamblado. Consulte la sección NOTAS para la definición de item y etiqueta.
-outfile nombre-archivo
Escribe los resultados en el archivo nombre-archivo. Un guion (-) escribe en stdout. Esta también es la opción por defecto. Tenga en cuenta que esta opción solo afecta a las opciones incluidas a la derecha de la opción.

NOTAS

Use item para especificar el nombre de una función, o de un archivo fuente u objeto que se utilizó para construir el ejecutable o el objeto compartido.

La etiqueta es un índice utilizado para determinar a qué elemento se hace referencia cuando múltiples funciones tienen el mismo nombre. Es obligatoria, pero se ignorará si no es necesaria para resolver la función.

El item también puede especificarse en el formato función`archivo`, en cuyo caso se utilizará el código fuente o el desensamblado de la función nombrada en el contexto fuente del archivo nombrado.

La combinación especial de item y etiqueta all -1, se utiliza para indicar la generación del código fuente o del desensamblado para todas las funciones en el archivo-destino.
