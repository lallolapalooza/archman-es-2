GPO(1) Comandos de usuario GPO(1)

NOMBRE

gpo - Interfaz en modo texto de gPodder

SINOPSIS

gpo [--verbose|-v|--quiet|-q] [COMANDO] [params...]

DESCRIPCIÓN

gpo es la interfaz en modo texto de gPodder. Ejecútala sin argumentos para iniciar el shell interactivo (ver abajo). Usa "gpo help" para obtener una lista de comandos soportados.

gpo se puede usar para gestionar podcasts desde la línea de comandos sin tener que iniciar gPodder. También se puede usar para automatizar tareas como descargar o actualizar feeds.

La base de datos y los archivos son los mismos que los utilizados por la GUI, gpodder(1).

MODO SHELL INTERACTIVO

Si ejecutas "gpo" sin COMANDO entrará en su modo shell interactivo. Desde allí, puedes escribir comandos directamente. Cuando readline está disponible, este shell soporta autocompletado usando <Tab>. Las URLs de los feeds de podcasts también se autocompletan para los comandos que toman la URL de un podcast como argumento.

Algunos comandos (por ejemplo, search y toplist) proporcionarán una consulta en modo shell interactivo (para suscribirse a podcasts). Estas consultas no se mostrarán cuando se inician directamente desde la línea de comandos.

PREFIJOS DE COMANDO

Para todos los comandos, puedes usar solo los primeros caracteres en lugar del comando completo, siempre que el comando sea único. Si no, gpo te mostrará todos los comandos coincidentes y el prefijo más corto de cada uno.

Ten en cuenta que futuras adiciones al conjunto de comandos podrían cambiar el prefijo más corto de cualquier comando dado, por lo que se recomienda el uso del comando completo en scripts (por ejemplo, usa "gpo update" y no "gpo up" en scripts y cronjobs). Los prefijos cortos de comando son principalmente útiles para el uso interactivo.

EJEMPLOS

gpo

Entrar en modo shell interactivo

gpo update && gpo download

Comprobar nuevos episodios, luego descargar todos los episodios nuevos

gpo search linux outlaws

Buscar en el directorio podcasts llamados "linux outlaws"

gpo youtube http://youtube.com/watch?v=oHg5SJYRHA0

Imprimir la URL de descarga de un video de YouTube a stdout
