Paquete: gpsd

Licencias: BSD

GPXLOGGER(1) Documentación de GPSD GPXLOGGER(1)

NOMBRE

gpxlogger - Herramienta para conectarse a gpsd y generar un archivo GPX

SINOPSIS

gpxlogger [OPCIONES] [servidor[:puerto[:dispositivo]]]

gpxlogger -h

gpxlogger -V

DESCRIPCIÓN

El programa gpslogger recopila correcciones de gpsd y las registra en la salida estándar en formato GPX, un perfil XML para el registro de trayectos. No necesita ejecutarse como root, pero puede hacerlo.

La salida puede estar compuesta por múltiples trayectos. Se crea un nuevo trayecto si no hay ninguna corrección registrada durante un intervalo especificado por la opción -i o --interval, que por defecto es de 5 segundos.

gpxlogger puede usar cualquiera de los métodos de exportación que gpsd soporta. Para obtener una lista de estos métodos, use la opción -l o --exports. Para forzar un método, proporcione la opción -e, --export seguida de uno de los nombres de método terminados en dos puntos de la tabla de -l, --exports.

OPCIONES

-?, -h, --help

Imprime un resumen de las opciones y luego sale.

-d, --daemonize

Ejecuta como demonio en segundo plano. Requiere la opción -f, --output, que dirige la salida a un archivo de registro especificado.

-D LVL, --debug LVL

Establece el nivel de depuración, principalmente para solución de problemas. Habilita varios mensajes de progreso a la salida de error estándar.

-e MÉTODO, --export MÉTODO

Si el soporte D-Bus está disponible en el host, GPSD está configurado para usarlo y se especifica -e dbus o --export dbus, este programa escucha las transmisiones de DBUS de gpsd a través de org.gpsd.fix.

Con -e sockets, o si sockets es el método predeterminado, puede proporcionar una especificación [servidor[:puerto[:dispositivo]]] como argumentos. Consulte la sección ARGUMENTOS a continuación para más detalles.

Con -e shm, --export shm este programa escuchará el gpsd local utilizando memoria compartida.

-f ARCHIVO_SALIDA, --output ARCHIVO_SALIDA

Exporta el registro GPX al archivo ARCHIVO_SALIDA, en lugar de a la salida estándar. Puede usar opciones de strftime(3) en ARCHIVO_SALIDA.

-F ARCHIVO_ENTRADA, --filein ARCHIVO_ENTRADA

Lee JSON de gpsd desde el archivo ARCHIVO_ENTRADA, en lugar de desde un demonio gpsd.

-g, --garmin

Habilita las extensiones Garmin al formato GPX. Esto permite que la profundidad también se registre en la salida gpx. No compatible con Google Maps.

-i SEGUNDOS, --interval SEGUNDOS

Se crea un nuevo trayecto si no hay ninguna corrección registrada durante un intervalo de SEGUNDOS. Por defecto son 5 segundos.

-l, --exports

Lista todas las opciones posibles para -e, --export.

-m MINMOVE, --minmove MINMOVE

Establece una distancia mínima de movimiento en metros (puede incluir una parte decimal fraccionaria). Los movimientos más cortos que esto no se registrarán.

-r, --reconnect

Reintenta cuando GPSd pierde la corrección. Sin -r, gpxlogger saldría en este caso.

-V, --version

Muestra la versión del paquete y sale.

ARGUMENTOS

Por defecto, los clientes recopilan datos del demonio local gpsd que se ejecuta en localhost, utilizando el puerto predeterminado de GPSD 2947. El argumento opcional a cualquier cliente puede anular este comportamiento: [servidor[:puerto[:dispositivo]]]

Para obtener más explicaciones y ejemplos, consulte la sección ARGUMENTOS de la página del manual de gps(1)

VALORES DE RETORNO

0

si tiene éxito.

1

si falla

Nota

spxlogger envía mensajes de error al registro del sistema, no a
stderr.

EJEMPLOS

Para ejecutar como demonio y exportar el registro gpx a un nombre de archivo con marca de fecha:

$ gpxlogger -d -f "out-%c.gpx"
