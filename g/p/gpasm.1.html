DESCRIPCIÓ

N

gpasm es un ensamblador para los microcontroladores PIC (TM) de Microchip (TM). Está destinado a ser compatible con el ensamblador MPASM del fabricante. gpasm es parte de gputils. Consulte la página man gputils(1) para obtener detal

les sobre otras util
idades GNU para PIC.

NAME

gpasm - PASM assembler for PIC microcontrollers.

SYNOPSIS

gpasm [-a] [-c] [-d] [-e] [-f] [-h] [-i] [-l] [-m] [-n] [-o] [-p] [-r] [-s] [-t] [-v] [-w] [-z] [-@] [-afilename] [-bfilename] [-dfilename] [-gfilename] [-ifilename] [-lfilename] [-mfilename] [-ofilename] [-pfilename] [-sfilename] [-wfilename] [-zfilename] [-iarch] [-lprocessor] [-ooutput_format] [-pdirective] [-ssyntax] [-wwarning_level] [-zdecimal_base] [-@filename] [input_file]

WARNING

This man page has been automatically generated from the gpasm.info file. It may not be complete or accurate.

DESCRIPTION

The Global PIC Assembler (gpasm) is a multi-architecture assembler that can be used to assemble code for a variety of PIC microcontroller architectures. It is part of the GPDK (Global PIC Development Kit).

OPTIONS

The following options are available:

-a
Assembler options (see below).
-c
Generate C header file.
-d
Generate disassembly listing.
-e
Enable extended PIC instruction set.
-f
Force overwriting of output files.
-h
Display help message.
-i
Specify include path.
-l
Generate listing file.
-m
Generate map file.
-n
No cross-reference.
-o
Specify output file name.
-p
Specify processor.
-r
Generate raw binary output.
-s
Generate symbol table.
-t
Generate TLM (MPLAB) compatible output.
-v
Verbose output.
-w
Set warning level.
-z
Specify decimal base.
-@
Specify command file.

Consult the gpasm documentation for more details.
