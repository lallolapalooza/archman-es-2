DESCRIPCIÓ

N

El programa gpm-root está diseñado para manejar eventos de Control-Ratón para dibujar menús en el fondo del tty actual. Los menús reales son descritos por un archivo de configuración en el directorio de inicio del

usuario.

Por favor, tenga en cuenta que gpm-root necesita ejecutarse con Linux 1.1.73 o más reciente, porque los núcleos anteriores carecen de algunas capacidades de manejo de pantalla requeridas por el

programa.

El programa usa los archivos /dev/vcs* para dibujar en la pantalla de la consola. Estos están disponibles solo desde el núcleo 1.1.81 en adelante. Si le faltan esos nodos de dispositivo, debería crearlos usando create_vcs en el directorio de la distribución. La herramienta no se ejecutará con núcleos más antiguos que 1.1.81, porque carecían de una capacidad completa de volcado/restauración de

pantalla.

Las opciones de línea de comando disponibles son las

siguientes:
-m núme
ro
Elige el modificador a usar (por defecto: control). El modificador puede proporcionarse ya sea como un número o como una cadena simbólica. Las cadenas permitidas son shift, anyAlt, leftAlt, rightAlt,
control.
-
u
Denegar el uso de archivos de configuración específicos del usuario. Con esta opción activada, solo /etc/gpm-root.conf será usado como fuente de información de configuración. Esta opción está destinada para aquellos administradores del sistema que temen que la seguridad podría ser comprometida por este demonio. Las cosas deberían ser lo suficientemente seguras, pero si encuentra un agujero, por favor,
cuéntemelo.
-
D
No entrar automáticamente en operación en segundo plano cuando se inicie, y registrar mensajes en el flujo de error estándar, no en el mecanismo de syslog. Esto es útil para depurar; en versiones anteriores se hacía con una opción en tiempo de
compilación.
-V incremento de
verbosidad
Aumenta el nivel máximo de mensajes que serán registrados. Así, un argumento positivo tiene el efecto de hacer el programa más detallado. Uno también puede dar un argumento negativo para silenciar el programa; sin embargo, tenga en cuenta que debido a las reglas de getopt(3), un argumento negativo debe seguir a la opción sin espacio entre ellos (es decir,
-V-1 pero no -V -1). Program Arguments,,,libc. El
argumento es opcional y su valor por defecto es 1.

Cada vez que se dibuja un menú, el archivo de configuración se vuelve a analizar si ha cambiado. Esto permite la modificación de la configuración personal sin volver a invocar al

demonio.

El archivo de configuración real se introduce mejor mirando su /etc/gpm-root.conf.

La sintaxis del archivo no se describirá aquí, siendo bastante aparente del ejemplo de arriba. Los espacios en blanco y los saltos de línea no se usan al analizar el archivo, y la disposición del archivo es libre. Se permiten comentarios en el archivo: cualquier signo de número (#) encontrado al principio de la línea o después de un espacio en blanco hace que el analizador descarte todo hasta la siguiente línea. Para insertar comillas (") en cadenas, precedalas con una barra

invertida.

Tenga en cuenta que se permiten menús recursivos, a cualquier nivel de

recursión.

Las palabras clave pertenecen a tres grupos: la palabra clave button, las palabras clave cfg y las palabras clave de acción. Todas se describen en la tabla de

abajo:
button número me
nu
La palabra clave button se usa para introducir un menú. Le sigue el número del botón relevante (1=izquierdo, 2=medio, 3=derecho), una llave abierta,
un menú y una llave cerrada. Un menú se compone de sentencias cfg, seguidas por sentencias de acción. Las sentencias cfg pueden venir en cualquier ord
en, mientras que el orden de las sentencias de acción indica el orden real en el que las acciones aparecerán en la pantalla, de arriba hacia abajo.

Las siguientes sentencias pertenecen al conjunto

cfg.
name cade
na
Si la palabra clave name está presente, la cadena especificada será usada como el nombre para el menú
actual.
background col
or
Esta sentencia se usa para especificar el color de fondo a usar en el menú actual. El color puede especificarse con una de las ocho cadenas canónicas black, red, cyan etc. El fondo por defecto es
negro.
foreground col
or
Esta sentencia se usa para especificar el color de primer plano para los elementos del menú. Su valor por defecto es blanco. Una palabra clave bright opcional puede aparecer antes del color
real.
border col
or
border se usa para especificar el color del borde para el menú. Su valor por defecto es blanco. Una palabra clave bright opcional puede aparecer antes del color
real.
head col
or
head se usa para especificar el color de primer plano para el tí
tulo del menú. Su valor por defecto es blanco. Una palabra
clave bright opcional puede aparecer antes del color real.

Las siguientes sentencias pertenecen al conjunto de

acciones.
cadena f.fgcmd cadena de
comando
Cuando se suelta el botón del ratón sobre el elemento de menú correspondiente, la cadena de comando se pega en la cola de teclado de la consola actual. Esto aún no está
implementado.
cadena f.bgcmd cadena de
comando
Cuando se suelta el botón del ratón sobre el elemento de menú correspondiente, se hace un fork de un shell (/bin/sh) para ejecutar el comando especificado, con stdin conectado a /dev/null, y stdout, stderr conectados a la consola
activa.
cadena f.jptty número de
tty
Cuando se suelta el botón del ratón sobre el elemento de menú correspondiente, la consola se cambia a la especificada. El número de tty debe especificarse como una cadena. Cualquier tty puede alcanzarse de esta manera, incluso aquellos que no son accesibles vía el
teclado.
cadena f.mktty número de
tty
Cuando se suelta el botón del ratón sobre el elemento de menú correspondiente, se selecciona una consola no usada, y se ejecuta /sbin/mingetty en ella. La consola actual se cambia a la consola recién abierta. Uso este comando para ahorrar memoria del kernel abriendo una sola consola a través de /etc/inittab y solicitando las otras solo cuando necesito iniciar
sesión.
cadena Menú
completo
Un menú puede seguir directamente a la etiqueta cadena. Cuando el puntero del ratón deja el marco del menú a nivel de cadena, un segundo menú se publica en la
pantalla.
cadena f.
lock
Cuando se suelta el botón del ratón sobre el elemento de menú correspondiente, el teclado y la pantalla se bloquean, y solo el usuario que bloqueó o el superusuario pueden desbloquearlos. Esto aún no está
implementado.
cadena f.
load
El promedio de carga actual cuando el menú se publica se concatena a cadena para construir el mensaje real mostrado en pantalla. Nada sucede al soltar el
botón.
cadena f.
free
La memoria libre y el swap cuando el menú se publica se concatenan a cadena para construir el mensaje real mostrado en pantalla. Nada sucede al soltar el
botón.
cadena f.
time
La hora actual se formatea con strftime(3), de acuerdo con cadena. La cadena resultante es el mensaje real mostrado en pantalla. Nada sucede al soltar el
botón.
cadena f.pipe línea de
comando
Cuando el puntero del ratón deja el marco del menú a nivel de cadena, un cuadro de mensaje se publica en pantalla mostrando las últimas diez líneas de la salida de línea de comando. La línea de comando es ejecutada por /bin/sh. Esto aún no está
implementado.
cadena f.
nop
Esto no hace nada, solo muestra cadena en
el m
enú.

Las variables de entorno HOME, LOGNAME y USER se establecen a

los valores del usuario que invoca antes de generar un proceso
externo (f.bgcmd, f.pipe). El directorio actual siempre es /.

ERRORE

S

Se han corregido los errores conocidos. En particular, si

invocas gpm-root justo después de gpm, se retrasará u
nos segundos antes de intentar conectarse al demonio.
