NOMBRE

gpg-preset-passphrase - Poner una frase de contraseña en la caché de gpg-agent

SINOPSIS

gpg-preset-passphrase [opciones] [comando] id-de-caché

DESCRIPCIÓN

gpg-preset-passphrase es una utilidad para sembrar la caché interna de un gpg-agent en ejecución con frases de contraseña. Es principalmente útil para máquinas desatendidas, donde la herramienta habitual pinentry puede no ser utilizada y las frases de contraseña para las claves a usar se proporcionan al inicio de la máquina.

Este programa funciona con GnuPG 2 y versiones posteriores. GnuPG 1.x no es compatible.

Las frases de contraseña establecidas con esta utilidad no expiran a menos que se utilice la opción --forget para borrarlas explícitamente de la caché — o gpg-agent se reinicie o se recargue (enviándole una señal SIGHUP). Tenga en cuenta que el tiempo máximo de caché establecido con --max-cache-ttl todavía se respeta. Es necesario permitir esta preconfiguración de frase de contraseña iniciando gpg-agent con la opción --allow-preset-passphrase.

gpg-preset-passphrase se invoca de la siguiente manera:

gpg-preset-passphrase [opciones] [comando] id-de-caché

id-de-caché es un identificador de 40 caracteres hexadecimales del keygrip de la clave para la cual se debe establecer o borrar la frase de contraseña. El keygrip se lista junto con la clave al ejecutar el comando: gpgsm --with-keygrip --list-secret-keys. Alternativamente, se puede usar una cadena arbitraria para identificar una frase de contraseña; se sugiere que dicha cadena se prefije con el nombre de la aplicación (por ejemplo, foo:12346). Los scripts siempre deben usar la opción --with-colons, que proporciona el keygrip en una línea "grp" (cf. 'doc/DETAILS')

Se debe proporcionar una de las siguientes opciones de comando:

--preset
Preconfigura una frase de contraseña. Esto es lo que normalmente usará. gpg-preset-passphrase leerá entonces la frase de contraseña desde stdin.
--forget
Descarta la frase de contraseña para el id de caché dado de la caché.

Las siguientes opciones adicionales pueden ser utilizadas:

-v
--verbose
Muestra información adicional mientras se ejecuta.
-P cadena
--passphrase cadena
En lugar de leer la frase de contraseña de stdin, usa la cadena proporcionada como frase de contraseña. Tenga en cuenta que esto hace que la frase de contraseña sea visible para otros usuarios.
