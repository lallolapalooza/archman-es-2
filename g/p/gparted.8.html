GPARTED(8) Manual de GParted GPARTED(8)

NOMBRE

gparted - Editor de particiones GNOME para manipular particiones de disco.

SINOPSIS

gparted [dispositivo]...

DESCRIPCIÓN

La aplicación gparted es el editor de particiones GNOME para crear, reorganizar y eliminar particiones de disco.

Un dispositivo de disco puede subdividirse en una o más particiones. La aplicación gparted le permite cambiar la organización de las particiones en un dispositivo de disco mientras preserva el contenido de la partición.

Con gparted puede realizar las siguientes tareas:
- Crear una tabla de particiones en un dispositivo de disco.
- Habilitar y deshabilitar indicadores de partición como arranque y oculto.
- Realizar acciones con particiones como crear, eliminar, redimensionar, mover, comprobar, etiquetar, copiar y pegar.

Puede encontrar más documentación en el manual de ayuda de la aplicación y en línea en:
https://gparted.org

EJEMPLOS

Puede ejecutar gparted desde una línea de comandos y especificar uno o más dispositivos de disco.

Por ejemplo, para iniciar gparted con los dispositivos /dev/sda y /dev/sdc, usaría el siguiente comando:

gparted /dev/sda /dev/sdc

NOTAS

La edición de particiones tiene el potencial de causar PÉRDIDA de DATOS.

La aplicación gparted está diseñada para permitirle editar particiones reduciendo el riesgo de pérdida de datos. La aplicación está cuidadosamente probada y es utilizada por el equipo del proyecto GParted. Sin embargo, la pérdida de datos puede ocurrir debido a errores de software, problemas de hardware o fallos de alimentación.

Puede ayudar a reducir el riesgo de pérdida de datos no montando o desmontando particiones fuera de la aplicación gparted mientras gparted se está ejecutando.

Se recomienda que HAGA UNA COPIA DE SEGURIDAD de sus DATOS antes de utilizar la aplicación gparted.
