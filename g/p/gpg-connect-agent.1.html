NOMBRE

gpg-connect-agent - Comunicarse con un agente en ejecución

SINOPSIS

gpg-connect-agent [opciones][comandos]

DESCRIPCIÓN

El gpg-connect-agent es una utilidad para comunicarse con un agente en ejecución gpg-agent. Es útil para examinar los comandos que gpg-agent proporciona mediante la interfaz Assuan. También puede ser útil para crear scripts de aplicaciones sencillas. Se espera la entrada en stdin y la salida se imprime en stdout.

Es muy similar a ejecutar gpg-agent en modo servidor; pero aquí nos conectamos a una instancia en ejecución.

Se pueden usar las siguientes opciones:

--dirmngr
Conectarse a un gestor de directorios (cliente de servidor de claves) en ejecución en lugar de al gpg-agent. Si un dirmngr no está en ejecución, se inicia.
--keyboxd
Conectarse a un demonio de caja de claves en ejecución en lugar de al gpg-agent. Si un keyboxd no está en ejecución, se inicia.
-S
--raw-socket nombre
Conectarse al socket nombre asumiendo que es un servidor de estilo Assuan. No ejecutar ninguna inicialización especial ni comprobaciones de entorno. Esto puede usarse para conectarse directamente a cualquier servidor de socket de estilo Assuan.
-E
--exec
Tomar el resto de la línea de comandos como un programa y sus argumentos y ejecutarlo como un servidor Assuan. Así es como ejecutaría gpgsm:
 gpg-connect-agent --exec gpgsm --server
Tenga en cuenta que en este caso no puede usar opciones en la línea de comandos.
-v
--verbose
Mostrar información adicional durante la ejecución.
-q
--quiet
Intentar ser lo más silencioso posible.
--homedir dir
Establecer el nombre del directorio de inicio en dir. Si esta opción no se usa, el directorio de inicio por defecto es ‘~/.gnupg’. Solo se reconoce cuando se indica en la línea de comandos. También anula cualquier directorio de inicio indicado a través de la variable de entorno ‘GNUPGHOME’ o (en sistemas Windows) mediante la entrada del Registro HKCU\Software\GNU\GnuPG:HomeDir.

En sistemas Windows es posible instalar GnuPG como una aplicación portátil. En este caso solo se considera esta opción de línea de comandos; se ignoran todas las demás formas de establecer un directorio de inicio.

--chuid uid
Cambiar el usuario actual a uid , que puede ser un número o un nombre. Esto puede usarse desde la cuenta root para ejecutar gpg-connect-agent para otro usuario. Si uid no es el UID actual, se establece una ruta PATH estándar y se desestablece la variable de entorno GNUPGHOME. Para anular esto último se puede usar la opción --homedir . Esta opción solo tiene efecto cuando se usa en la línea de comandos. Actualmente esta opción no tiene ningún efecto en Windows.
--no-ext-connect
Al usar -S o --exec, gpg-connect-agent se conecta al servidor Assuan en modo extendido para permitir el paso de descriptores. Esta opción hace que use el modo antiguo.
--no-autostart
No iniciar el gpg-agent o el dirmngr si aún no se han iniciado.
--no-history
En modo interactivo, el historial de la línea de comandos normalmente se guarda y se restaura desde un archivo bajo el directorio de inicio de GnuPG. Esta opción inhibe el uso de ese archivo.
--agent-program archivo
Especificar el programa de agente a iniciar si ninguno está en ejecución. El valor por defecto se determina ejecutando gpgconf con la opción --list-dirs. Tenga en cuenta que el símbolo de tubería (|) se usa para un truco de la suite de pruebas de regresión y por lo tanto no puede usarse en el nombre del archivo.
--dirmngr-program archivo
Especificar el programa de gestor de directorios (cliente de servidor de claves) a iniciar si ninguno está en ejecución. Esto solo tiene efecto si se usa junto con la opción --dirmngr.
--keyboxd-program archivo
Especificar el programa de demonio de caja de claves a iniciar si ninguno está en ejecución. Esto solo tiene efecto si se usa junto con la opción --keyboxd.
-r archivo
--run archivo
Ejecutar los comandos de archivo al inicio y luego continuar con el método de entrada normal. Tenga en cuenta que los comandos indicados en la línea de comandos se ejecutan después de este archivo.
-s
--subst
Ejecutar el comando /subst al inicio.
--hex
Imprimir las líneas de datos en formato hexadecimal y la representación ASCII de los caracteres de control.
--decode
Decodificar las líneas de datos. Es decir, eliminar los escapes de porcentaje pero asegurándose de que una nueva línea siempre comience con una D y un espacio.
-u
--unbuffered
Establecer stdin y stdout en modo de E/S sin búfer. Esto es a veces útil para scripts.

COMANDOS DE CONTROL

Mientras lee los comandos Assuan, gpg-agent también permite algunos comandos especiales para controlar su operación. Todos estos comandos de control comienzan con una barra inclinada (/).

/echo args
Simplemente imprimir args.
/let nombre valor
Establecer la variable nombre a valor. Las variables solo se sustituyen en la entrada si se ha usado /subst . Las variables se referencian anteponiendo el nombre con un signo de dólar e incluyendo opcionalmente el nombre entre llaves. Las reglas para un nombre válido son idénticas a las del shell bourne estándar. Esto aún no se aplica pero puede hacerse en el futuro. Cuando se usa con llaves no se permite espacio en blanco inicial ni final.

Si no se encuentra una variable, se busca en el entorno y si se encuentra se copia a la tabla de variables.

Hay disponibles funciones de variables: El nombre de la función debe ir seguido de al menos un espacio y al menos un argumento. Las siguientes funciones están disponibles:

get
Devolver un valor descrito por el argumento. Los argumentos disponibles son:
cwd
El directorio de trabajo actual.
homedir
El directorio de inicio de gnupg.
sysconfdir
El directorio de configuración del sistema de GnuPG.
bindir
El directorio de binarios de GnuPG.
libdir
El directorio de bibliotecas de GnuPG.
libexecdir
El directorio de bibliotecas de GnuPG para archivos ejecutables.
datadir
El directorio de datos de GnuPG.
serverpid
El PID del servidor actual. El comando /serverpid debe haberse dado para devolver un valor útil.
unescape args
Eliminar los escapes de estilo C de args. Tenga en cuenta que \0 y \x00 terminan la cadena devuelta implícitamente.citly. La cadena a convertir son todos los argumentos que siguen al espacio delimitador del nombre de la función.
unpercent args
unpercent+ args
Elimina el escapado de estilo porcentaje de args. Ten en cuenta que %00 termina la cadena implícitamente. La cadena a convertir son todos los argumentos que siguen al espacio delimitador del nombre de la función. unpercent+ también convierte los signos más en espacios.
percent args
percent+ args
Escapa args usando escapado de estilo porcentaje. Se escapan tabuladores, saltos de página, saltos de línea, retornos de carro y dos puntos. percent+ también convierte los espacios en signos más.
errcode arg
errsource arg
errstring arg
Asume que arg es un entero y lo evalúa usando strtol. Devuelve el código de error de gpg-error, la fuente del error o una cadena formateada con el código de error y la fuente del error.
+
-
*
/
%
Evalúa todos los argumentos como enteros largos usando strtol y aplica este operador. Una división por cero produce una cadena vacía.
!
|
&
Evalúa todos los argumentos como enteros largos usando strtol y aplica los operadores lógicos NOT, OR o AND. El operador NOT solo funciona en el último argumento.
/definq name var
Usa el contenido de la variable var para consultas con name. name puede ser un asterisco (*) para que coincida con cualquier consulta.
/definqfile name file
Usa el contenido de file para consultas con name. name puede ser un asterisco (*) para que coincida con cualquier consulta.
/definqprog name prog
Ejecuta prog para consultas que coincidan con name y le pasa la línea completa como argumentos de línea de comandos.
/datafile name
Escribe todas las líneas de datos del servidor en el archivo name. El archivo se abre para escritura y se crea si no existe. Un archivo existente se trunca primero a 0. Los datos escritos en el archivo están completamente decodificados. Usar un guion simple para name escribe en stdout. El archivo permanece abierto hasta que se establece un nuevo archivo usando este comando o se usa este comando sin argumento.
/showdef
Imprime todas las definiciones
/cleardef
Elimina todas las definiciones
/sendfd file mode
Abre file en mode (que debe ser una cadena de modo válida de fopen ) y envía el descriptor de archivo al servidor. Esto normalmente va seguido de un comando como INPUT FD para establecer la fuente de entrada para otros comandos.
/recvfd
Aún no implementado.
/open var file [mode]
Abre file y asigna el descriptor de archivo a var. Advertencia: Este comando es experimental y podría cambiar en versiones futuras.
/close fd
Cierra el descriptor de archivo fd. Advertencia: Este comando es experimental y podría cambiar en versiones futuras.
/showopen
Muestra una lista de archivos abiertos.
/serverpid
Envía el comando Assuan GETINFO pid al servidor y almacena el PID devuelto para propósitos internos.
/sleep
Duerme durante un segundo.
/hex
/nohex
Igual que la opción de línea de comandos --hex.
/decode
/nodecode
Igual que la opción de línea de comandos --decode.
/subst
/nosubst
Habilita y deshabilita la sustitución de variables. Está deshabilitada por defecto a menos que se haya usado la opción de línea de comandos --subst . Si /subst se ha habilitado una vez, se elimina el espacio en blanco inicial de las líneas de entrada, lo que hace que los scripts sean más fáciles de leer.
/while condition
/end
Estos comandos proporcionan una forma de ejecutar bucles. Todas las líneas entre while y el end correspondiente se ejecutan mientras la evaluación de condition produzca un valor distinto de cero o sea la cadena true o yes. La evaluación se hace pasando condition a la función strtol . Ejemplo: 
  /subst
  /let i 3
  /while $i
    /echo el contador del bucle es $i
    /let i ${- $i 1}
  /end
/if condition
/end
Estos comandos proporcionan una forma de ejecución condicional. Todas las líneas entre el if y el end correspondiente se ejecutan solo si la evaluación de condition produce un valor distinto de cero o es la cadena true o yes. La evaluación se hace pasando condition a la función strtol .
/run file
Ejecuta comandos desde file.
/history --clear
Borra el historial de comandos.
/bye
Termina la conexión y el programa.
/help
Imprime una lista de los comandos de control disponibles.
