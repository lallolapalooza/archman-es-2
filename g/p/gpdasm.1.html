NOMBRE

gpdasm - Desensamblador GNU PIC

SINOPSIS

gpdasm [opciones] archivo

ADVERTENCIA

La información de esta página del manual es un extracto de la documentación completa de gputils y se limita al significado de las opciones. Para una documentación completa y actualizada, consulte "gputils.ps" ubicado en el directorio de documentación de gputils.

DESCRIPCIÓN

gpdasm es un desensamblador para microcontroladores Microchip (TM) PIC (TM). gpdasm forma parte de gputils. Consulte la página del manual de gputils(1) para obtener detalles sobre otras utilidades GNU PIC.

OPCIONES

-c, --mnemonics
Decodifica los mnemotécnicos especiales.
-h, --help
Muestra este mensaje de uso y sale.
-i, --hex-info
Reporta información adicional sobre el archivo hex de entrada. Esta información incluye el tamaño del archivo y el formato hex.
-j, --mov-fsrn
En las instrucciones MOVIW o MOVWI, muestra FSRn como base en lugar de INDFn. [INDFn]
-k ARCHIVO, --label-list ARCHIVO
Un archivo que lista los nombres y direcciones de las etiquetas en el código del programa desensamblado. (Con las opciones -n, -o y -s).
-l, --list-chips
Lista los procesadores soportados.
-m, --dump
Muestra el contenido de la memoria de instrucciones.
-n, --show-names
Para algunos casos de SFR, muestra el nombre en lugar de la dirección. Además, también muestra las etiquetas.
-o, --show-config
Muestra las directivas CONFIG e IDLOCS - o __idlocs -.
-p PROC, --processor PROC
Selecciona el procesador.
-s, --short
Genera la salida en formato corto. Este formato puede ser reensamblado por gpasm. (Ver también las opciones -k, -n y -o).
-t, --use-tab
Utiliza el carácter de tabulación en el texto escrito.
-v, --version
Muestra la información de la versión y sale.
-y, --extended
Habilita el modo extendido 18xx.
--strict
Desensambla solo los opcodes generados por gpasm en caso de instrucciones con varios opcodes.
--strict-options
Si esto está establecido, entonces una opción no puede ser un parámetro de otra opción. Por ejemplo: -p --dump
