GPGV(1) GNU Privacy Guard 2.4 GPGV(1)

NOMBRE

gpgv - Verificar firmas OpenPGP

SINOPSIS

gpgv [opciones] archivos_firmados

DESCRIPCIÓN

gpgv es una herramienta de verificación de firmas OpenPGP.

Este programa es en realidad una versión recortada de gpg que solo es capaz de comprobar firmas. Es algo más pequeño que el completo gpg y utiliza una forma diferente (y más simple) de comprobar que las claves públicas utilizadas para realizar la firma son válidas. No hay archivos de configuración y solo se implementan algunas opciones.

gpgv asume que todas las claves del llavero son fiables. Eso también significa que no comprueba claves caducadas o revocadas.

Si no se proporciona la opción --keyring , gpgv busca un llavero ``por defecto'' llamado ‘trustedkeys.kbx’ (preferido) o ‘trustedkeys.gpg’ en el directorio personal de GnuPG, ya sea el directorio personal predeterminado o el establecido por la opción --homedir o la variable de entorno GNUPGHOME . Si se usa alguna opción --keyring , gpgv no buscará el llavero por defecto. La opción --keyring puede usarse varias veces y todos los llaveros especificados se usarán juntos.

VALOR DE RETORNO

El programa devuelve 0 si todo está bien, 1 si al menos una firma era incorrecta y otros códigos de error para errores fatales.

OPCIONES

gpgv reconoce estas opciones:

--verbose
-v
Proporciona más información durante el procesamiento. Si se usa dos veces, los datos de entrada se listan en detalle.
--quiet
-q
Intenta ser lo más silencioso posible.
--keyring archivo
Añade archivo a la lista de llaveros. Si archivo comienza con una virgulilla y una barra, estas se reemplazan por el directorio HOME. Si el nombre del archivo no contiene una barra, se asume que está en el directorio personal ("~/.gnupg" si no se usa --homedir).
--output archivo
-o archivo
Escribe la salida en archivo; para escribir en stdout use -. Esta opción puede usarse para obtener el texto firmado de una firma de texto claro o binaria; también funciona para firmas separadas, pero en ese caso esta opción generalmente no es útil. Tenga en cuenta que un archivo existente será sobrescrito.
--status-fd n
Escribe cadenas de estado especiales al descriptor de archivo n. Vea el archivo DETAILS en la documentación para un listado de ellas.
--logger-fd n
Escribe la salida del registro al descriptor de archivo n y no a stderr.
--log-file archivo
Igual que --logger-fd, excepto que los datos del registro se escriben en el archivo archivo. Use ‘socket://’ para registrar en un socket.
--ignore-time-conflict
GnuPG normalmente comprueba que las marcas de tiempo asociadas con las claves y firmas tienen valores plausibles. Sin embargo, a veces una firma parece ser más antigua que la clave debido a problemas de reloj. Esta opción convierte estas comprobaciones en advertencias.
--homedir dir
Establece el nombre del directorio personal a dir. Si esta opción no se usa, el directorio personal por defecto es ‘~/.gnupg’. Solo se reconoce cuando se da en la línea de comandos. También anula cualquier directorio personal declarado a través de la variable de entorno ‘GNUPGHOME’ o (en sistemas Windows) por medio de la entrada del Registro HKCU\Software\GNU\GnuPG:HomeDir.

En sistemas Windows es posible instalar GnuPG como una aplicación portátil. En este caso solo se considera esta opción de línea de comandos, todas las demás formas de establecer un directorio personal se ignoran.

--weak-digest nombre
Trata el algoritmo de resumen especificado como débil. Las firmas hechas sobre algoritmos de resumen débiles son normalmente rechazadas. Esta opción puede proporcionarse varias veces si varios algoritmos deben considerarse débiles. MD5 siempre se considera débil y no necesita listarse explícitamente.
--enable-special-filenames
Esta opción habilita un modo en el que los nombres de archivo de la forma ‘-&n’, donde n es un número decimal no negativo, se refieren al descriptor de archivo n y no a un archivo con ese nombre.
--assert-pubkey-algo lista_de_algoritmos
Esta opción funciona de la misma manera que se describe para gpg.

EJEMPLOS

gpgv archivo_pgp
gpgv archivo_firma [archivo_datos]
Verifica la firma del archivo. La segunda forma se usa para firmas separadas, donde archivo_firma es la firma separada (ya sea ASCII-armored o binaria) y archivo_datos contiene los datos firmados; si archivo_datos es "-" se espera que los datos firmados estén en stdin; si archivo_datos no se da, el nombre del archivo que contiene los datos firmados se construye cortando la extensión (".asc", ".sig" o ".sign") de archivo_firma.

ARCHIVOS

~/.gnupg/trustedkeys.gpg
El llavero por defecto con las claves permitidas.

ENTORNO

HOME
Se usa para localizar el directorio personal por defecto.
GNUPGHOME
Si está establecido, el directorio usado en lugar de "~/.gnupg".
