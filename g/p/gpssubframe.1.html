Paquete: gpsd

GPSSUBFRAME(1) Documentación de gpsd GPSSUBFRAME(1)

NOMBRE

gpssubframe - herramienta para volcar sentencias de sub-frame de gpsd

SINOPSIS

gpssubframe [OPCIONES] [servidor[:puerto[:dispositivo]]]

gpssubframe -h

gpssubframe -V

DESCRIPCIÓN

gpssubframe es una herramienta para conectarse a gpsd y volcar datos de sub-frame decodificados a la salida estándar. Esto solo es útil si su receptor GNSS puede emitir mensajes de sub-frame GPS y está configurado para hacerlo. También se requiere un conocimiento práctico de IS-GPS-200. Mantenga su copia a mano.

gpssubframe no requiere privilegios de root, pero funcionará bien como root. Puede ejecutarse simultáneamente con otras herramientas que se conecten al gpsd local sin causar problemas.

El programa acumulará mensajes de sub-frame y los volcará por número de satélite GPS al salir. Por defecto, el programa nunca sale a menos que el usuario seleccione el número de segundos para ejecutar o el número de mensajes a capturar.

Por defecto, gpssubframe se conecta a un gpsd que se ejecuta en el host local. Opcionalmente, se puede proporcionar un host, número de puerto TCP/IP y dispositivo remoto.

OPCIONES

-?, -h, --help

Imprime un mensaje de uso y sale.

-c COUNT, --count COUNT

Sale después de COUNT mensajes de sub-frame.

-D DEBUG, --debug DEBUG

Establece el nivel de depuración. Debe ser un entero. Por defecto 0.

--desc

Imprime descripciones largas.

--device DEVICE

Conéctate al dispositivo DEVICE en el host de gpsd.

-D LVL, --debug LVL

Establece el nivel de depuración a LVL.

--file FILE

Lee el JSON de gpsd desde FILE en lugar de desde gpsd.

--host HOST

Conéctate a gpsd en el host HOST.

--load LOADFILE

Carga datos guardados de Sub-frame, TPV y RAW JSON de LOADFILE.

-n COUNT, --count COUNT

Número de mensajes a analizar. 0 para deshabilitar.

--port PORT

Conéctate a gpsd en el puerto PORT.

--progress

Imprime informes de progreso a medida que se reciben los mensajes.

--satpos

Calcula las posiciones de los satélites GPS antes de salir. Si se proporciona --time, las posiciones se calcularán en ese momento. De lo contrario, si se recibió un mensaje RAW, se usará la hora de la medición en ese mensaje. El último recurso es usar la hora del último mensaje TPV.

--save SAVEFILE

Guarda los datos de Sub-frame decodificados en SAVEFILE como JSON. Si está presente, también se guardarán los últimos registros JSON TPV y RAW.

--test

Ejecuta el código de autocomprobación --satpos.

--time SEC

Calcula la posición del satélite en el tiempo SEC en segundos POSIX.

-V, --version

Imprime la versión del programa y sale.

-x SEC, --seconds SEC

Segundos de mensajes a analizar. 0 para deshabilitar.

ARGUMENTOS

Por defecto, los clientes recopilan datos del demonio gpsd local que se ejecuta en localhost, utilizando el puerto por defecto de GPSD, 2947. El argumento opcional a cualquier cliente puede anular este comportamiento: [servidor[:puerto[:dispositivo]]]

Para más explicaciones y ejemplos, consulta la sección ARGUMENTOS de la página del manual gps(1).

EJEMPLOS

Primero, configura un u-blox serie 9 para emitir mensajes de sub-frame. Luego, haz que gpssubframe recopile un conjunto completo de sub-frames, y luego imprime los datos organizados por número de satélite GPS. Asegúrate de reemplazar -P 22 con la versión de protocolo correcta para tu receptor. Luego calcula e imprime las posiciones conocidas de los satélites, así como el acimut, la elevación y el rango desde la posición actual:

ubxtool -P 22 -e SFRBX
gpssubframe -x 750 --satpos

Si mirar fijamente una pantalla en blanco durante 12,5 minutos es demasiado estresante, entonces habilita los mensajes de progreso:

gpssubframe -x 750 --satpos --progress

VALORES DE RETORNO

0

en caso de éxito.

1

en caso de fallo.

VER TAMBIÉN

gpsd(8), gps(1), gpsprof(1), gpsfake(1).
