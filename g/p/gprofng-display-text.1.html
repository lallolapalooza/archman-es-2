NAME

gprofng-display-text, gprofng-display-html, gprofng-display-src - display gprofng profiling data

SYNOPSIS

gprofng-display-text [OPTION]... <profile-data>
gprofng-display-html [OPTION]... <profile-data>
gprofng-display-src [OPTION]... <profile-data>

DESCRIPTION

The gprofng-display-* commands display profile data collected by gprofng(1). The default output format is text. Use gprofng-display-html for an HTML output, and gprofng-display-src to display the source code annotated with profiling information.

The profile-data argument is the name of the file containing the collected profile data. By default, this file is named gprofng.data in the current directory.

OPTIONS

-h, --help
Display help message and exit.
-v, --version
Display version information and exit.
-q, --quiet
Suppress informational messages.
-o, --output <file>
Write output to <file> instead of stdout.
-c, --command <command>
Execute a given command within the display tool. This can be used to switch between different views or to perform other actions.
-f, --file <file>
Specify the input profile data file. This option is equivalent to providing the filename as a positional argument.
-p, --processes
Show profiling information aggregated across all processes. This is useful when profiling multi-process applications.
-t, --threads
Show profiling information aggregated across all threads. This is useful when profiling multi-threaded applications.

NOTES

The following commands can be used with the -c option:

"flat"
Show a flat profile, listing functions sorted by the total time spent in each function. This is the default view.
"graph"
Show a call graph profile, illustrating the relationships between functions and the time spent in each call.
"tree"
Show a call tree profile, representing the call hierarchy and time spent in each function and its descendants.
"source"
Show the source code annotated with profiling information. This view is similar to what gprofng-display-src provides.
"symbols"
Show a list of all symbols (functions, variables) found in the profile data.
"threads"
Show profiling information per thread. This view is useful for analyzing the behavior of multi-threaded applications.
"machine"
Show the actual native call stacks for all threads. This is the view mode for C, C++, and Fortran.
