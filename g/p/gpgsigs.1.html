NOMBRE

gpgsigs - Anota la lista de claves GnuPG con las firmas ya realizadas

SINOPSIS

gpgsigs [opciones] id_clave[,id_clave[,...]] texto_clave [archivo_salida]

DESCRIPCIÓN

gpgsigs fue escrito para ayudar al usuario a firmar claves durante una fiesta de firma de claves. Toma como entrada un archivo que contiene claves en formato de "gpg --list-keys" y antepone a cada línea una etiqueta que indica si el usuario ya ha firmado esa uid. Cuando el archivo contiene líneas de "ALGORITMO Checksum:" y marcadores de posición ("__ __"), se inserta la suma de verificación. ALGORITMO puede configurarse en los siguientes algoritmos: MD5 SHA1 SHA256 o RIPEMD160.

OPCIONES

-r
Llama a gpg --recv-keys antes de crear la salida.
-f conjunto_caracteres
Convierte texto_clave desde conjunto_caracteres. El valor predeterminado es ISO-8859-1.
-t conjunto_caracteres
Convierte UIDs a conjunto_caracteres. El valor predeterminado se deriva de LC_ALL, LC_CTYPE y LANG, y si todos estos no están definidos, el valor predeterminado es ISO-8859-1.
--refresh
Actualiza las listas de UID por clave desde gpg. Útil cuando se agregaron o revocaron UIDs desde que se generó el texto de entrada.
--latex
Genera salida LaTeX, incluyendo IDs de fotos. Implica --refresh. Nota: Esto escribe archivos jpg en el directorio actual.
id_clave
Usa este id_clave (8 o 16 bytes, o huella digital completa) para la anotación. Se pueden separar varios id_clave por una coma (,).
texto_clave
Lee la entrada desde texto_clave.
archivo_salida
Escribe la salida en archivo_salida. El valor predeterminado es stdout.

AMBIENTE

HOME
El directorio de inicio predeterminado.
GNUPGBIN
El binario de gpg. Predeterminado: "gpg".
GNUPGHOME
El directorio de trabajo predeterminado para gpg. Predeterminado: "$HOME/.gnupg".

EJEMPLOS

Las siguientes fiestas de firma de claves están utilizando gpgsigs:

http://www.palfrader.org/ksp-lt2k4.html

http://www.palfrader.org/ksp-lt2k5.html

ERRORES

Se sabe que GnuPG cambia su formato de salida con bastante frecuencia. Esta versión ha sido probada con gpg 1.4.18 y gpg 2.0.26. Los resultados pueden variar.
