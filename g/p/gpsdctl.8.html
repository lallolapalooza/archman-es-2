GPSDCTL(8) Documentación de GPSD GPSDCTL(8)

NOMBRE

gpsdctl - herramienta para enviar comandos a gpsd a través de su socket de control

SINOPSIS

gpsdctl acción dispositivo

OPCIONES

acción

puede ser add o remove. Si no hay ninguna instancia del demonio en ejecución cuando se solicita un add, este programa lanzará una.

dispositivo

el argumento debe ser la ruta de un dispositivo. El dispositivo será abierto por gpsd para leer datos del sensor.

DESCRIPCIÓN

Esta es una herramienta para enviar comandos de una instancia de gpsd a través de su socket de control para añadir o eliminar dispositivos de la lista de dispositivos del demonio. No está pensada para ser llamada por los usuarios, sino por el sistema de hotplug de Linux y otras instalaciones similares.

ENTORNO

Se interpretan dos variables de entorno.

GPSD_SOCKET

establece la ubicación del socket de control. Si el ID de usuario efectivo de este programa es root, normalmente será /run/gpsd.sock, aunque algunos sistemas pueden usar el obsoleto /var/run/gpsd.sock. Los usuarios no root usarán /tmp/gpsd.sock.

GPSD_OPTIONS

puede ser una lista de opciones que se pasarán a gpsd cuando esta herramienta lo inicie. Por defecto es una cadena vacía.

VALORES DE RETORNO

0

en caso de éxito.

1

si la acción fue desconocida o si falló la escritura en el socket de control.
