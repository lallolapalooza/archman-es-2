GPSINIT(8) Documentación de GPSD GPSINIT(8)

NOMBRE

gpsinit - inicializa módulos del kernel CAN para GPSD

SINOPSIS

gpsinit [-n control] [-s velocidad] nombre_módulo [nombre_interfaz]

gpsinit -h

gpsinit -V

DESCRIPCIÓN

gpsinit inicializa los módulos a nivel de kernel necesarios para permitir que hardware especial no serial se comunique con una instancia de gpsd. Nota: requerirá permisos de root para cargar módulos y realizar otras operaciones especiales, como cambiar las tasas de baudios de la interfaz del kernel.

Actualmente, todos los modos de esta herramienta se centran en configurar interfaces a nivel de kernel para hardware que habla NMEA2000 sobre CAN (Control Area Network).

El programa acepta las siguientes opciones:

-h

Muestra un breve texto de ayuda.

-n

Establece el número de red CAN. El valor predeterminado es 0.

-s

Establece la velocidad en baudios que se utilizará para comunicarse a través de la línea serial con el hardware CAN. El valor predeterminado es 38400 baudios.

-V

Muestra la versión de gpsinit.

El parámetro nombre_módulo es obligatorio. Se cargará el módulo controlador de socket CAN nombre_módulo.ko. gpsinit reconoce los siguientes nombres de módulo:

plx_pci, esd_usb2, vcan, slcan

El parámetro nombre_interfaz y velocidad de -s se pueden usar aquí.

beaglebone

El módulo dcan necesario para beaglebone forma parte del kernel de Linux, por lo que en este caso no se carga ningún módulo.

El parámetro nombre_interfaz solo es necesario para hardware slcan. Indica el nombre del dispositivo serial al que está conectado el hardware SL CAN. El valor predeterminado es /dev/ttyUSB0.

EJEMPLOS

Todos los siguientes ejemplos probablemente necesiten ejecutarse como root.

gpsinit plx_pci

Intenta cargar el módulo plx_pci e inicializar la red 0 para la conexión a una red NMEA2000. Establecerá la velocidad en baudios a 250kBits.

gpsinit -n 1 plx_pci

Igual que el anterior, pero utiliza la red 1.

gpsinit -s 38400 slcan /dev/ttyUSB0

Intenta cargar el módulo slcan y comunicarse con el hardware a 38400 baudios conectado al puerto /dev/ttyUSB0.

gpsinit -h

Muestra un breve mensaje de ayuda.

gpsinit -v

Muestra la versión de gpsinit.

VALORES DE RETORNO

0

en caso de éxito.

1

en caso de fallo
