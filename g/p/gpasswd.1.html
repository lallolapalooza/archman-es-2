DESCRIPCIÓ

N

El comando gpasswd se utiliza para administrar /etc/group y /etc/gshadow. Cada grupo puede tener administradores, miembros y una

contraseña.

Los administradores del sistema pueden usar la opción -A para definir al administrador o administradores del grupo y la opción -M para definir a los miembros. Tienen todos los derechos de los administradores y miembros del

grupo.

gpasswd invocado por un administrador de grupo solo con un nombre de grupo solicita la nueva contraseña del grupo

.

Si se establece una contraseña, los miembros aún pueden usar newgrp(1) sin contraseña, y los no miembros deben proporcionar la

contraseña.

Notas sobre las contraseñas de

grupo

Las contraseñas de grupo son un problema de seguridad inhere

nte, ya que se permite que más de una persona conozca la
contraseña. Sin embargo, los grupos son una herramienta
útil para permitir la cooperación entre diferentes usuarios.

CONFIGURACIÓ

N

Las siguientes variables de configuración en /etc/login.defs cambian el comportamiento de esta

herramienta:

ENCRYPT_METHOD

(cadena)
Define el algoritmo de cifrado predeterminado del sistema para cifrar contraseñas (si no se especifica ningún algoritmo en la línea de comandos).

Puede tomar uno de estos valores: DES (predeterminado), MD5, SHA256, SHA512, YESCRYPT. No se deben usar MD5 y DES para nuevos hashes, consulte crypt(5) para obtener recomendaciones

.

Nota: este parámetro anula la variable MD5_CRY

PT_ENAB.

Nota: Esto solo afecta a la generación de contraseñas de grupo. La generación de c

ontraseñas de usuario la realiza PAM y está sujeta a la configuración de PAM. Se re
comienda establecer esta variable de manera coherente con la configuración de PAM.

MAX_MEMBERS_PER_GROU

P (número)
Número máximo de miembros por entrada de grupo. Cuando se alcanza el máximo, se inicia una nueva entrada de grupo (línea) en /etc/group (con el mismo nombre, la misma contraseña y el mismo GID).

El valor predeterminado es 0, lo que significa que no hay límite en el número de miembros de un

grupo.

Esta característica (grupo dividido) permite limitar la longitud de las líneas en el archivo de grupo. Esto es útil para asegurarse de que las líneas de los grupos NIS no superen los 1024

caracteres.

Si necesita hacer cumplir dicho límite, puede usar

25.

Nota: es posible que no todas las herramientas admitan los grupos

divididos (incluso en el conjunto de herramientas Shadow). No
debería usar esta variable a menos que realmente la necesite.

MD5_CRYPT_ENAB (b

ooleano)
Indica si las contraseñas deben cifrarse usando el algoritmo basado en MD5. Si se establece en yes, las nuevas contraseñas se cifrarán usando el algoritmo basado en MD5 compatible con el utilizado por versiones recientes de FreeBSD. Admite contraseñas de longitud ilimitada y cadenas de sal más largas. Establezca en no si necesita copiar contraseñas cifradas a otros sistemas que no entiendan el nuevo algoritmo. El valor predeterminado es no.

Esta variable ha sido reemplazada por la variable ENCRYPT_METHOD o por cualquier opción de la línea de comandos utilizada para configurar el algoritmo de

cifrado.

Esta variable está obsoleta. Debería usar ENCRYPT_METHOD

.

Nota: Esto solo afecta a la generación de contraseñas de grupo. La generación de c

ontraseñas de usuario la realiza PAM y está sujeta a la configuración de PAM. Se re
comienda establecer esta variable de manera coherente con la configuración de PAM.

SHA_CRYPT_MIN_ROUNDS (número), SHA_CRYPT_MAX_ROUNDS

(número)
Cuando ENCRYPT_METHOD está establecido en SHA256 o SHA512, esto define el número de rondas SHA que usa el algoritmo de cifrado de forma predeterminada (cuando no se especifica el número de rondas en la línea de comandos).

Con muchas rondas, es más difícil hacer un ataque de fuerza bruta a la contraseña. Pero tenga en cuenta también que se necesitarán más recursos de CPU para autenticar a los

usuarios.

Si no se especifica, la libc elegirá el número de rondas predeterminado (5000), que es demasiado bajo en varios órdenes de magnitud para el hardware

moderno.

Los valores deben estar dentro del rango 1000-999,999,

999.

Si solo se establece uno de los valores SHA_CRYPT_MIN_ROUNDS o SHA_CRYPT_MAX_ROUNDS, se usará ese

valor.

Si SHA_CRYPT_MIN_ROUNDS > SHA_CRYPT_MAX_ROUNDS, se usará el valor más

alto.

Nota: Esto solo afecta a la generación de contraseñas de grupo. L

a generación de contraseñas de usuario la realiza PAM y está
sujeta a la configuración de PAM. Se recomienda establecer e
