gpssnmp(1)

Paquete: gpsd

Licencias: BSD

GPSSNMP(1) Documentación de GPSD GPSSNMP(1)

NOMBRE

gpssnmp - Cliente auxiliar SNMP para gpsd

SINOPSIS

gpssnmp [OPCIONES] [servidor[:puerto[:dispositivo]]]

gpssnmp -h

gpssnmp -g OID

gpssnmp -n OID

gpssnmp -p

gpssnmp -V

DESCRIPCIÓN

gpssnmp es un cliente de gpsd que funciona como un ayudante SNMP para MRTG.

gpssnmp no requiere privilegios de root. También funcionará bien como root.

gpssnmp puede actuar como un agente para snmpd en modo pass o en modo pass_persist. Por lo tanto, puede usarse para extender snmpd con el GPSD-MIB. Dada la naturaleza del protocolo SNMP, no espere una buena latencia. Los datos de diferentes épocas pueden mezclarse.


Nota

este programa es nuevo en la versión 3.24.1 y estará sujeto a
cambios durante algunas revisiones. Considérese un Trabajo en Progreso (WIP).

OPCIONES

-?, -h, --help

Imprime un resumen de las opciones y luego sale. Úselo con "-D 1" para ver los valores OID válidos. Úselo con "-D 2" para ver los valores OID válidos con valores de escala y descripciones.

-g OID

Obtiene el OID especificado.

-n OID

Obtiene el siguiente OID a partir de OID.

-p, --persist

Entra en modo pass_persist. Esto permite un mejor rendimiento cuando se usa como agente para el demonio snmpd. Consulte la página del manual snmpd.conf para obtener más detalles.

-V, --version

Imprime la versión del paquete y sale.

EJEMPLOS:

Para obtener el número de satélites vistos con el OID

   $ gpssnmp -g .1.3.6.1.4.1.59054.11.2.1.3.1
   .1.3.6.1.4.1.59054.11.2.1.3.1
   INTEGER
   15

Para obtener el número de satélites vistos con el nombre MIB

   $ gpssnmp -g skynSat.1
   .1.3.6.1.4.1.59054.11.2.1.3.1
   INTEGER
   15

Conectando a snmpd

gpssnmp puede funcionar como un "script de paso" con snmpd. Para habilitar esta funcionalidad en una instalación de snmpd ya existente, agregue esto a su archivo snmpd.conf y luego reinicie snmpd:

# asegúrese de que la comunidad SNMPv2 "public" pueda acceder a todas las MIBs:
rocommunity public  localhost
# configurar el paso de GPSD-MIB a gpssnmp
pass .1.3.6.1.4.1.59054  /usr/local/bin/gpssnmp

Luego podrá consultar el número de satélites en uso de esta manera:

$ snmpget -c public -v 2c localhost skynSat.1
GPSD-MIB::skynSat.1 = INTEGER: 16

Volcar todo el OID "sky" de esta manera:

$ snmpwalk -c public -v 2c localhost GPSD-MIB::sky
GPSD-MIB::skynSat.1 = INTEGER: 17
GPSD-MIB::skyuSat.1 = INTEGER: 8
GPSD-MIB::skySNRavg.1 = INTEGER: 2000

Volcar todo el GPSD-MIB de esta manera:

$ snmpwalk -c public -v 2c localhost gpsd
GPSD-MIB::tpvLeapSeconds = INTEGER: 18
GPSD-MIB::tpvNumber = INTEGER: 1
GPSD-MIB::tpvIndex.1 = INTEGER: 1
[...]

gpssnmp soporta el modo pass_persist de snmpd. Para que snmpd use gpssnmp en este modo, ponga esto en su archivo snmpd.conf:

pass_persist .1.3.6.1.4.1.59054  /usr/local/bin/gpssnmp --persist

VALORES DE RETORNO

0

en caso de éxito.

1

en caso de fallo
