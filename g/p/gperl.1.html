gperl(1) Manual de Comandos Generales gperl(1)

Nombre

gperl - ejecuta comandos Perl en documentos de groff

Sinopsis

gperl [archivo ...]
gperl -h
gperl --help
gperl -v
gperl --version

Descripción

Este es un preprocesador para groff(1). Permite el uso de código de perl(7) en archivos de groff(7). El resultado de una parte Perl puede almacenarse en strings o registros numéricos de groff basándose en los argumentos de una línea final de una parte Perl.

Si no se proporcionan operandos, o si archivo es “-”, gperl lee el flujo de entrada estándar. Un argumento de doble guion (“--”) hace que todos los argumentos subsiguientes se interpreten como operandos de archivo, incluso si sus nombres comienzan con un guion. -h y --help muestran un mensaje de uso, mientras que -v y --version muestran información de la versión; todos salen después.

Regiones Perl

Las partes Perl en los archivos groff se encierran entre dos solicitudes .Perl con argumentos diferentes, un comando de inicio y uno de fin.

Inicio modo Perl

La solicitud Perl de inicio puede ser sin argumentos, o mediante una solicitud que tenga el término start como único argumento.

  • .Perl
  • .Perl start

Fin modo Perl sin almacenamiento

Una línea de comando .Perl con un argumento diferente de start finaliza una parte Perl en ejecución. Por supuesto, sería razonable añadir el argumento stop; eso es posible, pero no necesario.

  • .Perl stop
  • .Perl otro_que_no_sea_start
El argumento otro_que_no_sea_start puede usarse además como un nombre de variable de cadena groff para almacenamiento — véase la siguiente sección.

Fin modo Perl con almacenamiento

Una característica útil de gperl es almacenar uno o más resultados del modo Perl.

La salida de una parte Perl se puede obtener con comillas invertidas `...`.

Este programa recopila toda la impresión a STDOUT (salida estándar normal) por parte del programa print de Perl. Esta salida pseudo-impresa puede tener varias líneas, debido a los saltos de línea impresos con \n. Por lo tanto, la salida de una ejecución de Perl debería almacenarse en un array de Perl, con una única línea por cada miembro del array.

Esta salida de array de Perl puede ser almacenada por gperl en uno de los siguientes:

cadenas de groff
creando un comando groff .ds
registro de groff
creando un comando groff .nr

Los modos de almacenamiento se pueden determinar mediante los argumentos de un comando .Perl de parada final. Cada argumento .ds cambia el modo a cadena de groff y .nr cambia el modo a registro de groff para todas las partes de salida siguientes.

Por defecto, toda la salida se guarda como cadenas, por lo que .ds no es realmente necesario antes del primer comando .nr. Eso se adapta a groff(7), porque toda la salida se puede guardar como cadena de groff, pero los registros pueden ser muy restrictivos.

En modo cadena, gperl genera una línea de almacenamiento de cadena groff

.ds nombre_var contenido
En modo registro se genera el siguiente comando groff 
.nr nombre_var contenido

Presentamos colecciones de argumentos en lo siguiente. Puede añadir como primer argumento para todos stop. Omitimos este elemento adicional.

.Perl .ds nombre_var
Esto almacenará 1 línea de salida en la cadena de groff llamada nombre_var mediante el comando creado automáticamente
.ds nombre_var salida
.Perl nombre_var
Si nombre_var es diferente de start, esto es equivalente al comando anterior, ya que el modo de cadena es cadena con el comando .ds. por defecto.
.Perl nombre_var1 nombre_var2
Esto almacenará 2 líneas de salida en los nombres de cadena de groff nombre_var1 y nombre_var2, ya que el modo por defecto .ds está activo, de modo que no se necesita argumento .ds. Por supuesto, esto es equivalente a
.Perl .ds nombre_var1 nombre_var2
y 
.Perl .ds nombre_var1 .ds nombre_var2
.Perl .nr nombre_var1 nombre_var2
almacena ambas variables como variables de registro. gperl genera
.nr nombre_var1 linea_salida1
.nr nombre_var2 linea_salida2
.Perl .nr nombre_var1 .ds nombre_var2
almacena el primer argumento como registro y el segundo como cadena mediante
.nr nombre_var1 linea_salida1
.ds nombre_var2 linea_salida2

Ejemplo

Una posible parte Perl en un archivo roff podría verse así:

antes
.Perl start
my $result = 'some data';
print $result;
.Perl stop .ds string_var
después

Esto almacena el resultado ”some data” en la cadena roff llamada string_var, de modo que la siguiente línea se imprime:

.ds string_var some data
por gperl como entrada para la próxima ejecución de groff.

Una parte Perl con varias salidas es:

.Perl start
print ”primera\n”;
print ”segunda linea\n”;
print ”3\n”;
.Perl var1 var2 .nr var3
Esto almacena 3 líneas impresas en 3 cadenas groff. var1, var2, var3. Así, las siguientes líneas de comandos groff son creadas: 
.ds var1 primera
.ds var2 segunda linea
.nr var3 3
