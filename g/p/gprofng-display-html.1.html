NOMBRE

gprofng-display-html - Genera una estructura de directorios basada en HTML para explorar los perfiles

SINOPSIS

gprofng display html [opción(es)] experimento(s)

DESCRIPCIÓN

Procesa uno o más experimentos para generar un directorio que contiene el archivo index.html que se puede utilizar para explorar los datos del experimento.

OPCIONES

--version
Imprime el número de versión y sale.
--help
Imprime información de uso y sale.
--verbose
Habilita el modo detallado para mostrar mensajes de diagnóstico sobre el procesamiento de los datos. Por defecto, el modo detallado está deshabilitado.
-d [tamaño-volumen-db], --debug[=tamaño-volumen-db]
Controla la impresión de información de depuración en tiempo de ejecución para ayudar a la resolución de problemas o al desarrollo futuro de esta herramienta.

El parámetro tamaño-volumen-db controla el volumen de salida y es uno de la lista s, S, m, M, l, L, xl o XL. Si no se establece tamaño-volumen-db, se imprime una cantidad modesta de información. Esto es equivalente a seleccionar s o S. El volumen de datos aumenta a medida que aumenta el tamaño. Tenga en cuenta que actualmente l/L es equivalente a xl/XL, pero se espera que esto cambie en futuras actualizaciones. Por defecto, el modo de depuración está deshabilitado.

--highlight-percentage=valor
Establece un valor porcentual en el intervalo [0,100] para seleccionar y codificar por colores las líneas de código fuente, así como las instrucciones, que se encuentran dentro de este porcentaje de los valores métricos máximos. El valor por defecto es 90 (%). Un valor de cero deshabilita esta función.
-o nombre-dir, --output=nombre-dir
Utiliza nombre-dir como el nombre del directorio para almacenar los resultados. En ausencia de esta opción, el nombre por defecto es display.<n>.html. Este directorio se crea en el directorio actual. El número <n> es el primer número entero positivo no utilizado en este esquema de nomenclatura. No se sobrescribe un directorio existente con el mismo nombre. En caso de que el directorio ya exista, se imprime un mensaje de error y la herramienta termina.
-O nombre-dir, --overwrite=nombre-dir
Utiliza nombre-dir como el nombre del directorio para almacenar los resultados. En ausencia de esta opción, el nombre por defecto es display.<n>.html. Este directorio se crea en el directorio actual. El número <n> es el primer número entero positivo no utilizado en este esquema de nomenclatura. Se sobrescribe silenciosamente un directorio existente con el mismo nombre.
-q, --quiet
Deshabilita la visualización de todos los mensajes de advertencia, depuración, detallados y cualquier otro mensaje. Si está habilitado, la configuración de detallado y depuración se acepta, pero se ignora. Con esta opción, no hay salida en pantalla, excepto errores. Por defecto, el modo silencioso está deshabilitado.
--nowarnings
Deshabilita la impresión de mensajes de advertencia en stdout. Por defecto, se imprimen los mensajes de advertencia.

NOTAS

  • Las opciones y los valores distinguen entre mayúsculas y minúsculas.
  • En esta versión, la sintaxis de las opciones ha cambiado para ser más compatible con otras herramientas y comandos.

    Las opciones que solían tener solo un valor de on o off, ahora actúan como un interruptor. La opción niega la configuración predeterminada. Por ejemplo, por defecto, el modo detallado está deshabilitado. Se habilita utilizando la opción --verbose.

    Las opciones largas, aquellas que comienzan con "--", que requieren un valor, esperan el signo "=" entre la opción y el valor.

    Aunque la sintaxis y las opciones anteriores todavía se aceptan, recomendamos encarecidamente cambiar el uso de las opciones de acuerdo con la nueva sintaxis y los nuevos valores. En algún momento, es posible que estas configuraciones heredadas ya no se acepten.

    Para ayudar con la transición, se muestra un mensaje de advertencia si se utilizan la sintaxis o los valores heredados, o ambos.

  • La opción -hp todavía se acepta, pero se eliminará en una futura versión. Utilice la opción --highlight-percentage en su lugar.
  • Al establecer un nombre de directorio para que se almacenen los archivos HTML, asegúrese de que umask esté configurado con los permisos de acceso correctos.
  • Independientemente de la configuración de los mensajes de advertencia, si hay advertencias, son accesibles a través de la página principal index.html.
  • La herramienta intenta acumular tantas advertencias y errores como sea posible antes de tomar medidas. De esta manera, es más fácil abordar varios problemas a la vez. Como resultado de este enfoque, es posible que los mensajes no se muestren de inmediato. En particular, las advertencias se muestran hacia el final de la ejecución, pero uno o más errores terminarán la ejecución antes de que comience el procesamiento.
