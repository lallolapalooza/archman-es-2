DESCRIPCIÓ

N

Este es el controlador de la suite de herramientas gprofng para recopilar y analizar datos de

rendimiento.

El controlador ejecuta la acción especificada. Un ejemplo de acción es collect para recopilar datos de rendimiento. Dependiendo de la acción, puede ser necesario un calificador para definir más el comando. El último elemento es el destino al que se aplica el

comando.

Hay tres lugares donde se admiten opciones. El controlador admite opciones. Estas se encuentran a continuación. La acción, posiblemente en combinación con el calificador, también admite opciones. Una descripción de estas se puede encontrar en la página man del comando. Cualquier opción necesaria para ejecutar el comando de destino debe seguir al nombre del

destino.

Por ejemplo, para recopilar datos de rendimiento de una aplicación llamada a.out y almacenar los resultados en el directorio de experimento mydata.er, se puede usar el siguiente

comando: 
$ gprofng collect app -o mydata.er a.out -t
2

En este ejemplo, la acción es collect, el calificador es app, el único argumento del comando es "-o mydata.er" y el destino es a.out. El comando de destino se invoca con la opción -t

2.

Si se ejecuta gprofng sin ninguna opció

n, acción o destino adicional, se i
mprime una descripción general del uso.

La interfaz gráfica de usuario (GUI) de gprofng es una herramienta opcional que proporciona una interfaz gráfica para "gprofng". Es fácil de usar y admite muchas vistas de los datos de rendimiento.
