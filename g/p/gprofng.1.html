    gprofng.1

    SINAPSIS

    gprofng [opciones] [archivo-de-ejecución]...

    DESCRIPCIÓN

    gprofng es una herramienta de perfilado de código para programas. Analiza el código compilado para proporcionar información detallada sobre el rendimiento de la ejecución, incluyendo el tiempo empleado en cada función, el número de llamadas a funciones y la jerarquía de llamadas.

    OPCIONES

    -b, --brief : Muestra una salida breve.

    -c, --compute-call-graph : Calcula el grafo de llamadas.

    -d, --depgraph : Muestra el grafo de dependencias.

    -e funciones, --exclude funciones : Excluye las funciones especificadas de la salida.

    -f funciones, --flat-profile funciones : Muestra un perfil plano de las funciones especificadas.

    -h, --help : Muestra un mensaje de ayuda y sale.

    -I ruta, --directory ruta : Añade ruta a la lista de directorios de búsqueda de archivos fuente.

    -l, --line-numbers : Muestra información a nivel de línea de código.

    -O archivo, --outfile archivo : Escribe la salida en archivo en lugar de la salida estándar.

    -p, --profile : Muestra un perfil de llamadas.

    -r, --reset : Borra las estadísticas de perfilado anteriores.

    -s, --combine : Combina varios archivos de datos de perfilado en uno solo.

    -T, --traditional : Utiliza el formato de salida tradicional de gprof.

    -v, --version : Muestra la información de la versión y sale.

    -W, --no-warn : Desactiva las advertencias.

    ENTORNO

    GPROF_OPTIONS : Permite especificar opciones de configuración para gprofng.

    NOTAS

    Para que gprofng funcione correctamente, el programa que se va a perfilar debe compilarse con las opciones de depuración y perfilado activadas (normalmente -g -pg con GCC o Clang).
