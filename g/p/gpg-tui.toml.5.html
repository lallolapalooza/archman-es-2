GPG-TUI.TOML(5) Manual de formatos de archivo GPG-TUI.TOML(5)

NOMBRE

gpg-tui.toml - archivo de configuración para gpg-tui

SINOPSIS

El archivo gpg-tui.toml es un archivo de configuración para gpg-tui. El archivo debe ubicarse en una de las siguientes ubicaciones:

$HOME/.config/gpg-tui.toml, $HOME/.config/gpg-tui/gpg-tui.toml, $HOME/.config/gpg-tui/config

También se puede especificar con la opción --config o la variable de entorno $GPG_TUI_CONFIG. Si el archivo no existe en la ubicación apropiada o no se proporciona, gpg-tui utiliza su configuración por defecto.

DESCRIPCIÓN

El archivo TOML utilizado para configurar gpg-tui tiene una sección de configuraciones generales seguida de la sección gpg que permite configurar las opciones de GnuPG.

FORMATO

[general]
Sección para configuraciones generales.
  • splash: mostrar la pantalla de bienvenida al iniciar (por defecto: false)
  • tick_rate: establecer la tasa de tics de la terminal (por defecto: 250)
  • color: establecer el color de acento de la terminal (por defecto: gray)
  • style: establecer el estilo de la terminal (por defecto: colored) (valores posibles: plain, colored)
  • file_explorer: establecer la utilidad para la selección de archivos (por defecto: xplr)
  • detail_level: establecer el nivel de detalle para las claves (por defecto: minimum) (valores posibles: minimum, standard, full)
  • log_file: establecer el archivo para guardar los registros
  • key_bindings: lista de atajos de teclado personalizados
[gpg]
Sección para configuraciones de GnuPG.
  • armor: habilitar salida ASCII armada (por defecto: false)
  • homedir: establecer el directorio de inicio de GnuPG
  • outdir: establecer el directorio de salida
  • outfile: establecer la plantilla para el nombre del archivo de salida
  • default_key: establecer la clave predeterminada para firmar

EJEMPLO

El siguiente es un ejemplo completo de configuración por defecto de gpg-tui.toml:

[general]
  splash = false
  tick_rate = 250
  color = "gray"
  style = "colored"
  file_explorer = "xplr"
  detail_level = "minimum"
  key_bindings = [
    { keys = [ "?", "h", "f1" ], command = ":help" },
    { keys = [ "C-d", "C-c", "q" ], command = ":quit" },
  ]
[gpg]
  armor = false
  homedir = "~/.gnupg"
  outdir = "~/.gnupg/out"
  outfile = "{type}_{query}.{ext}"
  default_key = ""
