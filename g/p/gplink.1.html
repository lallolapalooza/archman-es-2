NOMBRE

gplink - enlazador GNU PIC

SINOPSIS

gplink [opciones] [objetos] [librerías]

ADVERTENCIA

La información en esta página del manual es un extracto de la documentación completa de gputils y se limita al significado de las opciones. Para una documentación completa y actualizada, consulte "gputils.ps" ubicado en el directorio de documentación de gputils.

DESCRIPCIÓN

gplink combina una serie de archivos objeto y de archivo, relocaliza sus datos y enlaza sus referencias de símbolos. Genera un ejecutable para microcontroladores Microchip (TM) PIC (TM). gplink es parte de gputils. Consulte la página del manual gputils(1) para obtener detalles sobre otras utilidades GNU PIC.

OPCIONES

-a FMT, --hex-format FMT
gplink admite los formatos de archivo hexadecimal inhx8m, inhx8s, inhx16 e inhx32. Esta opción controla qué formato de archivo hexadecimal se utiliza. El valor predeterminado es inhx32.
-b OPT, --optimize-banksel OPT
Elimina directivas Banksel innecesarias. [0]
-B, --experimental-banksel
Utiliza eliminación experimental de Banksel.
-c, --object
Genera un objeto ejecutable.
-C, --no-cinit-warnings
Deshabilita las advertencias de la sección _cinit con la opción -O2: "La relocalización del símbolo _cinit no tiene sección."
-d, --debug
Muestra mensajes de depuración.
-f VALUE, --fill VALUE
Rellena la memoria de programa desprotegida no utilizada con el valor proporcionado. El valor anula el valor de relleno del script del enlazador. El valor no debe ser superior a 0xffff. El valor está en hexadecimal. El valor puede ir precedido por "0x".
-h, --help
Muestra el mensaje de uso y sale.
-I DIR, --include DIR
Especifica el directorio de inclusión.
-j, --no-save-local
Deshabilita el guardado de registros locales en el archivo COD.
-l, --no-list
Deshabilita la generación del archivo de lista.
-m, --map
Genera un archivo de mapa.
--mplink-compatible
Esta opción establece el modo de compatibilidad de MPLINK.
-o FILE, --output FILE
Nombre alternativo del archivo de salida.
-O OPT, --optimize OPT
Nivel de optimización. El valor predeterminado es 1.
-p OPT, --optimize-pagesel OPT
Elimina directivas Pagesel innecesarias. [0]
-P, --experimental-pagesel
Utiliza eliminación experimental de Pagesel.
-q, --quiet
Suprime todo lo enviado a la salida estándar.
-r, --use-shared
Intenta relocalizar secciones de datos no compartidas a memoria compartida si la relocalización falla.
-s FILE, --script FILE
Script del enlazador.
-t SIZE, --stack SIZE
Crea una sección de pila (stack).
-S [0|1|2], --strict [0|1|2]
Establece el nivel de estrictez del símbolo faltante. 0: Este es el predeterminado. Sin mensaje. 1: Muestra un mensaje de advertencia si hay un símbolo faltante. 2: Muestra un mensaje de error si hay un símbolo faltante.
--strict-options
Si se establece esto, una opción no puede ser un parámetro de otra opción. Por ejemplo: -s --quiet
-u, --macro symbol=[value]
Agrega un valor macro para el script.
-v, --version
Muestra la información de la versión y sale.
-w, --processor-mismatch
Deshabilita la advertencia de "incompatibilidad de procesador".
-W, --experimental-pcallw
Elimina stubs PCALLW innecesarios creados por SDCC.
