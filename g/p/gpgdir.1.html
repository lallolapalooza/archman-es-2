DESCRIPCIÓ

N

gpgdir es un script perl que usa el módulo perl de CPAN GnuPG::Interface para cifrar y descifrar recursivamente directorios usando gpg. gpgdir desciende recursivamente por un directorio para asegurarse de que cifra o descifra cada archivo en un directorio y todos sus subdirectorios. Por defecto, los valores mtime y atime de todos los archivos se conservarán al cifrar y descifrar (esto se puede deshabilitar con la --no-preserve-times option). Tenga en cuenta que en el --encrypt mode, gpgdir eliminará los archivos originales que cifre con éxito (a menos que se proporcione la --no-delete option). Sin embargo, al iniciar, gpgdir primero solicita la contraseña de descifrado para asegurarse de que un archivo de prueba pueda cifrarse y descifrarse con éxito. La prueba inicial se puede deshabilitar con la --skip-test option para que un directorio pueda cifrarse fácilmente sin tener que especificar también una contraseña (esto es consistente con el gpg behavior). Además, tenga en cuenta que gpgdir tiene cuidado de no cifrar archivos ocultos y directorios. Después de todo, probablemente no desee que su directorio ~/.gnupg o su archivo ~/.bashrc se cifren. La clave gpgdir usa para cifrar/descifrar un directorio se especifica en ~/.

gpgdirrc.

Finalmente, gpgdir puede usar el wipe program con la --Wipe command line option para eliminar de forma segura los archivos originales sin cifrar después de que se hayan cifrado con éxito. Esto eleva la postura de seguridad de gpgdir ya que es má

s difícil recuperar los datos sin cifrar asociados con los archivos del sistema de archivos des
pués de que se cifren (unlink() no borra los bloques de datos aunque un archivo se elimine).

OPCIONE

S
-e, --encrypt
<directorio>
Cifra recursivamente todos los archivos en el directorio especificado en la línea de comandos. Todos los archivos originales serán eliminados (se realiza primero una comprobación de contraseña para asegurarse de que el usuario conoce la contraseña correcta para desbloquear la clave privada de
GnuPG).
-d, --decrypt
<directorio>
Descifra recursivamente todos los archivos en el directorio especificado en la línea de comandos. La versión .gpg cifrada de cada archivo será
eliminada.
--sign
<directorio>
Firma recursivamente todos los archivos en el directorio especificado en la línea de comandos. Para cada archivo, se creará una firma .asc
separada.
--verify
<directorio>
Verifica recursivamente todas las firmas .asc de los archivos en el directorio especificado en la línea de
comandos.
-g, --gnupg-dir
<directorio>
Especifica qué directorio .gnupg se usará para encontrar las claves de GnuPG. El valor predeterminado es ~/.gnupg si no se usa esta opción. Esta opción permite que gpgdir se ejecute como un usuario pero use las claves de otro usuario (suponiendo que los permisos estén configurados correctamente,
etc.).
-p, --pw-file
<pw-file>
Lee la contraseña de descifrado desde pw-file en lugar de escribirla en la línea de
comandos.
-t, --test-mo
de
Ejecuta una prueba de cifrado y descifrado contra un archivo de prueba y sale. Esta prueba siempre se ejecuta de forma predeterminada tanto en el --encrypt and --decrypt
mode.
-S, --Symmetr
ic
Indica a gpgdir que cifre y descifre archivos usando un cifrado simétrico soportado por GnuPG (CAST5 se usa comúnmente). Esto resulta en una aceleración significativa del proceso de cifrado/descifra
do.
-T, --Trial-r
un
Muestra qué acciones de cifrado/descifrado se realizarían sin hacerlas realmente. El sistema de archivos no se modifica de ninguna manera en este
modo.
-I, --Interacti
ve
Solicita al usuario antes de cifrar o descifrar realmente cada archivo. Esto es útil para tener un control detallado sobre las gpgdir operations mientras recorre recursivamente una estructura de
directorios.
-F, --For
ce
Indica a gpgdir que ignore condiciones de error no fatales, como la incapacidad de cifrar o descifrar archivos individuales debido a errores de
permisos.
--Exclude
<patrón>
Indica a gpgdir que omita todos los archivos que coincidan con patrón como una coincidencia de expresión regular contra cada nombre de archivo. Esto es similar a la --exclude opción en el comando estándar GNU
tar.
--Exclude-from
<archivo>
Indica a gpgdir que excluya todos los archivos coincidentes con los patrones listados en archivo. Esto es similar a la --exclude-from del comando GNU tar
.
--Include
<patrón>
Indica a gpgdir que solo incluya archivos que coincidan con patrón como una coincidencia de expresión regular contra cada nombre de
archivo.
--Include-from
<archivo>
Indica a gpgdir que solo incluya archivos coincidentes con los patrones listados en archi
vo.
-W, --Wi
pe
Usa el wipe program para eliminar de forma segura los archivos después de que se hayan cifrado con
éxito.
-O, --Obfuscate-filen
ame
Indica a gpgdir que ofusque los nombres de los archivos que cifra (en el modo -e). Los nombres de cada archivo se almacenan dentro del archivo .gpgdir_map_file para cada subdirectorio, y este archivo está cifrado. En el modo de descifrado (-d), el argumento -O invierte el proceso para que se restauren los archivos
originales.
--overwrite-encryp
ted
Sobrescribe archivos cifrados incluso si ya existe un archivo <archivo>.gpg
anterior.
--overwrite-decryp
ted
Sobrescribe archivos descifrados incluso si ya existe el archivo sin cifrar
anterior.
-K, --Key-id
<id>
Especifica manualmente un ID de clave de GnuPG desde la línea de comandos. Debido a que GnuPG soporta la coincidencia de claves con una cadena, id no tiene que ser estrictamente un ID de clave; puede ser una cadena que coincida de forma única con una clave en el anillo de claves de
GnuPG.
-D, --Default-k
ey
Usa la clave que GnuPG define como predeterminada, es decir, la clave que es especificada por la default-key variable en ~/.gnupg/options. Si la variable default-key no está definida dentro de ~/.gnupg/options, entonces GnuPG intenta usar la primera clave adecuada en su anillo de claves (la prueba inicial de cifrado/descifrado se asegura de que el usuario conozca la contraseña correspondiente para la clave)
.
-a, --age
nt
Indica a gpgdir que obtenga la contraseña de la clave gpg de una instancia gpg-agent en
ejecución.
-A, --Agent-info <info de
conexión>
Especifica el valor de la variable de entorno GPG_AGENT_INFO tal como lo devuelve el gpg-agent --daemon command. Si se usa el argumento de línea de comandos gpgdir --agent en lugar de --Agent-info, entonces gpgdir asume que la variable de entorno GPG_AGENT_INFO ya ha sido establecida en el shell
actual.
-s, --skip-te
st
Omite la prueba de cifrado y descifrado. Esto permitirá gpgdir usarse para cifrar un directorio sin especificar una contraseña (que normalmente se usa en el modo de cifrado para probar que el descifrado contra un archivo de prueba funciona correctamente)
.
-q, --qui
et
Imprime lo menos posible en la pantalla al cifrar o descifrar un
directorio.
--no-recur
se
Indica a gpgdir que no recorra recursivamente ningún subdirectorio del directorio que se está cifrando o
descifrando.
--no-passwo
rd
Indica a gpgdir que no solicite una contraseña al usuario. Esto solo es útil cuando una clave gpg literalmente no tiene una contraseña asociada (esto no es común)
.
--no-dele
te
Indica a gpgdir que no elimine los archivos originales al momento de
cifrar.
--no-preserveti
mes
Indica a gpgdir que no preserve los valores mtime y atime originales de los archivos al cifrar o
descifrar.
-l, --locale
<locale>
Proporciona una configuración de configuración regional (locale) diferente a la configuración regional "C"
predeterminada.
--no-loca
le
No establece la configuración regional en absoluto, de modo que se aplicará la configuración regional predeterminada del
sistema.
-v, --verbo
se
Ejecuta en modo
detallado.
-V, --Versi
on
Imprime el número de versión y
sale.
-h, --he
lp
Imprime l
a informa
ción de us
o y sale.

EJEMPLO

S

Los siguientes ejemplos ilustran los argumentos de línea de comandos que podrían proporcionarse a gpgdir en algunas

situaciones:

Para cifrar un

directorio:

$ gpgdir -e

/some/dir

Para cifrar un directorio y usar el comando wipe para eliminar de forma segura los archivos originales sin

cifrar:

$ gpgdir -W -e

/some/dir

Para cifrar un directorio con la clave GnuPG predeterminada definida en ~/.

gnupg/options:

$ gpgdir -e /some/dir

--Default-key

Para descifrar un directorio con una clave especificada en ~/.

gpgdirrc:

$ gpgdir -d

/some/dir

Para cifrar un directorio pero omitir todos los nombres de archivo que contengan la cadena

"host":

$ gpgdir -e /some/dir --Exclude

host

Para cifrar un directorio pero solo cifrar aquellos archivos que contengan la cadena

"passwd":

$ gpgdir -e /some/dir --Include

passwd

Para obtener la contraseña de la clave GnuPG de un demonio gpg-agent en ejecución para descifrar un directorio (esto requiere que gpg-agent tenga la contraseña)

:

$ gpgdir -A /tmp/gpg-H4DBhc/S.gpg-agent:7046:1 -d

/some/dir

Para cifrar un directorio pero omitir la prueba de cifrado/descifrado (de modo que no se le solicitará una contraseña de descifrado)

:

$ gpgdir -e /some/dir

-s

Para cifrar un directorio y no

subdirectorios:

$ gpgdir -e /some/dir

--no-recurse

Para cifrar el directorio de inicio de root, pero usar las claves GnuPG asociadas con el usuario

"bob":

# gpgdir -e

/root -g /hom
e/bob/.gnupg

DEPENDENCIA

S

gpgdir requiere que gpg, el Guardia de Privacidad de Gnu (http://www.gnupg.org) esté instalado. gpgdir también requiere el módulo perl GnuPG::Interface de CPAN, pero está incluido con gpgdir y se instala en /usr/lib/gpgdir en el momento de la instalaci

ón, por lo que no contamina el ár
bol de bibliotecas perl del sistema.
