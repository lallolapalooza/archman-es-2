GXL2GV,GV2GXL(1) Manual de comandos generales GXL2GV,GV2GXL(1)

NOMBRE

gxl2gv,gv2gxl - Convertidores GXL-GV

SINOPSIS

gxl2gv [ -gd? ] [ -oarchivo_salida ] [ archivos ]
gv2gxl [ -gd? ] [ -oarchivo_salida ] [ archivos ]

DESCRIPCIÓN

gxl2gv convierte entre grafos representados en GXL y en el lenguaje GV. A menos que se especifique un tipo de conversión usando una opción, gxl2gv deducirá el tipo de conversión del sufijo del archivo de entrada, un sufijo ".gv" que causará una conversión de GV a GXL, y un sufijo ".gxl" que causará una conversión de GXL a GV. Si no hay sufijo disponible, por ejemplo, cuando la entrada proviene de una tubería, y no se usan opciones, entonces gxl2gv asume el tipo del archivo de entrada a partir de su nombre ejecutable, de modo que gxl2gv convierte de GXL a GV, y gv2gxl convierte de GV a GXL.

GXL soporta un modelo de grafo mucho más rico que GV. gxl2gv intentará mapear construcciones GXL en la construcción GV análoga cuando sea posible. Si no, la información GXL se almacena como un atributo. La intención es que aplicar gxl2gv|gv2gxl sea semánticamente equivalente al operador identidad.

OPCIONES

Se soportan las siguientes opciones:

-g
Se ignora el nombre del comando y las extensiones de los archivos de entrada, la entrada se toma como un archivo GV y se genera un archivo GXL.
-d
Se ignora el nombre del comando y las extensiones de los archivos de entrada, la entrada se toma como un archivo GXL y se genera un archivo GV.
-?
Imprime información de uso y sale.
-o archivo_salida
Si se especifica, la salida se escribirá en el archivo archivo_salida. De lo contrario, la salida se escribe en la salida estándar.

OPERANDOS

Se soporta el siguiente operando:

archivos
Nombres de archivos que contienen 1 o más grafos en GXL o GV. Si no se especifica ningún operando archivos, se utilizará la entrada estándar.

CÓDIGOS DE RETORNO

Tanto gxl2gv como gv2gxl devuelven 0 si no hubo problemas durante la conversión; y un valor distinto de cero si ocurrió algún error.

ERRORES

gxl2gv solo convertirá en una dirección incluso si se le dan varios archivos con extensiones variables.

La conversión solo puede manejar un grafo por archivo GXL.

Hay algunas construcciones GXL que gxl2gv no puede manejar.
