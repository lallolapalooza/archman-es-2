DESCRIPCIÓ

N

gxmessage abre una ventana para mostrar un mensaje obtenido desde la línea de comandos, desde un archivo, o desde stdin. La ventana incluye una fila de botones, cada uno de los cuales hace que el programa termine con un código de retorno

diferente.

La entrada de Info de GNU par

a gxmessage contiene informac
ión detallada y ejemplos.

OPCIONE

S

gxmessage acepta cualquier opción que xmessage aceptaría, aunque algunas (como -bw y -xrm) se ignoran silenciosamente

.
-bg COL
OR

Establece el color de fondo del mensaje a COLOR. Ejemplos: red, "#c90",
"#446a7e".
-buttons LISTA_DE_BOTO
NES

Define los botones a crear. LISTA_DE_BOTONES es una lista separada por comas de pares ETIQUETA:VALOR, uno para cada botón. La ETIQUETA es el texto que aparece en el botón. El VALOR (0..255) es el código con el que el programa terminará si se presiona ese botón. Las comas y los dos puntos se pueden escapar usando barras invertidas (\). Además del texto normal, la ETIQUETA puede especificar un botón "stock" de GTK, como "GTK_STOCK_CANCEL", o puede incluir un guion bajo (_) para especificar un acelerador de teclado. Si los VALOR se omiten, por defecto son 101, 102, 103, etc., en orden. Si no se proporciona la opción -buttons, LISTA_DE_BOTONES por defecto es "okay:0". 
gxmessage -buttons "Foo:42,Bar:63" "Ejemplo"
echo $?
gxmessage -buttons "_Foo,_Bar" "Ejemplo"
echo $?
gxmessage "Ejemplo"
echo $?
gxmessage -buttons "GTK_STOCK_OK:0" "Ejemplo"
echo $?
gxmessage -buttons "Hola\, mundo"
"Ejemplo"
-cent
er

Abre la ventana de gxmessage en el medio de la
pantalla.
-default ETIQU
ETA

Abre la ventana de gxmessage con el foco de entrada en el botón especificado. ETIQUETA es una de las ETIQUETAS en LISTA_DE_BOTONES (véase -buttons, arriba)
.
-display PANTAL
LA

Especifica la pantalla X a
usar.
-fg COL
OR

Establece el color del texto del mensaje a COLO
R.
-file NOMBRE_DE_AR
CHIVO

Hace que el archivo nombrado se use como fuente del mensaje. Si se usa un guion (-) en lugar de NOMBRE_DE_ARCHIVO, el mensaje se leerá desde stdi
n.
-fn | -font FUE
NTE

Especifica la fuente del mensaje, usando el sistema de especificación de fuentes de GTK. Por ejemplo, -font "serif italic 14". (El sistema de fuentes de GTK no es compatible con xmessage. Véase la sección de Compatibilidad, más abajo, para una solución alternativa.
)
-geometry GEOMETR
ÍA

Establece el tamaño y/o la posición de la ventana. Ejemplos: 
-geometry 400x200
-geometry 400x200+600+100
-geometry
+600+100

termina.
-icon
ic

Abre la ventana de gxmessage en su estado iconificado (minimizado)
.
-name NOM
BRE

Establece el nombre de la ventana de gxmessage a NOMBR
E.
-nearmou
se

Abre la ventana de gxmessage cerca del puntero del
ratón.
-pri

Escribe la ETIQUETA del botón seleccionado en stdou
t.

OS

Cierra automáticamente la ventana de gxmessage con un código de salida de 0 si no se presiona ningún botón dentro de SEGUNDOS segundos. (Las opciones -entry y -entrytext hacen que -timeout se ignore.
)
-title TÍTU

Establece el título de la ventana de gxmessage a TÍT

OPCIONES ESPECÍFICAS DE

GXMESSAGE

Las siguientes opciones son específicas de gxmessage y no son compatibles con xmessage

.
-borderle
ss

Abre la ventana de gxmessage sin el marco de ventana
habitual.
-encoding JUEGO_DE_CARA
CTERES

Especifica la codificación del texto del mensaje. Por defecto, se asume que el texto del mensaje coincide con la codificación de la configuración regional
actual.
-ent
ry

Añade una caja de entrada de texto a la ventana de gxmessage. Cuando la ventana se cierra, cualquier texto en la caja de entrada se copiará a stdout. Esta opción no se puede usar al mismo tiempo que la opción -p
rint.
-entrytext TEX
TO

Igual que -entry, pero establece el contenido por defecto de la caja de entrada a TEXT
O.
-noesca
pe

Evita que la ventana se cierre si se presiona la tecla ESC. Esta opción solo funciona si existe un archivo llamado /usr/share/gxmessage/allow_noesca
pe.
-nofoc
us

Evita que la ventana de gxmessage reciba el foco cuando se
abre.
-ont
op

Intenta mantener la ventana de gxmessage por delante de otras
ventanas.
-stic
ky

Hace que la ventana de gxmessage aparezca en todos los espacios de
trabajo.
-versi
on

Muestra el número de versión del programa y los detalles del Copyright, y luego
termina.
-wr
ap

VALORES POR DEFECTO DE

GTK

La apariencia por defecto del programa se puede ajustar usando archivos de recursos de GTK. El widget principal de visualización de texto se llama gxmessage-textview. El widget de entrada de texto se llama gxmessage-entry

. 
# Ejemplo: ~/.gtkrc-2.0
style "gxmsg" {
    text[NORMAL]   = "#cc9900"
    base[NORMAL]   = "#66
0000" text[SELECTED] = "#660000" base[SELECTED] = "#cc9900" font_name = "monosp
ace" } widget "*.gxmessage-textview" style "gxmsg" widget "*.gxmessage-entry" style "gxmsg"

ESTADO DE

SALIDA

Si se presiona un botón, el programa devuelve el valor asignado a ese botón. El botón "okay" por defecto devuelve

0.

Si ocurre un evento de tiempo de espera, el programa devuelve

0.

Si ocurre un error, o si la ventana se cierra sin un evento de pulsació

n de botón o de tiempo de espera, el programa termina con el código 1. Presi
onar la tecla ESC también hace que el programa termine con el código 1.

COMPATIBILIDAD CON

XMESSAGE

Vuelva a xmessage si gxmessage no está

disponible: 
#! /bin/sh
XMESSAGE=$(which gxmessage) || XMESSAGE=xmessage
$XMESSAGE "hola,
mundo"

Si ustedEspecifique las fuentes, verifique qué programa está

utilizando: 
font="monospace 14"
[ "$XMESSAGE" = xmessage ] && font="fixed"
$XMESSAGE ${font:+-fn "$font"} "hello,
world"

No use opciones de línea de comandos con guiones

dobles: 
$XMESSAGE "hello, world" -buttons good
$XMESSAGE "hello, world" --buttons
bad

No use las opciones específicas de

gxmessage: 
-entry, -entrytext, -borderless, -wrap,
-encoding, -nofocus, -noescape, -ontop,
-sticky, -version, -h, -
?

ERRORE

S

Por alguna razón, abrir la ventana de gxmessage sin ningún botón establecido como predeterminado hace que GTK emita un sonido de

"beep".

Si descubre otros errores en la versión más reciente de gxmessage, por favor

póngase en
contacto.
