NOMBRE

gxkb - Indicador y cambiador de teclado de X11.

SINOPSIS

gxkb

DESCRIPCIÓN

gxkb es un pequeño applet indicador que permite cambiar rápidamente entre diferentes diseños de teclado en X. Se muestra una bandera correspondiente al país del diseño activo en el área del indicador.

El applet está escrito en C y utiliza la biblioteca GTK+ y, por lo tanto, no depende de ningún componente de GNOME.

OPCIONES

-v
Imprime el número de versión de gxkb en la salida estándar y lista las características con las que fue compilado.
-h
Imprime un mensaje de uso resumiendo brevemente estas opciones de línea de comandos y luego sale.

ARCHIVOS

Las rutas completas a continuación pueden variar entre instalaciones. También se ven afectadas por las variables de entorno XDG_CONFIG_HOME y XDG_DATA_HOME.

PREFIX/share/gxkb/flags/

Directorio con recursos de todo el sistema.

$XDG_CONFIG_HOME/gxkb/gxkb.cfg

Configuración para gxkb. Si $XDG_CONFIG_HOME no está establecido o está vacío, se debe usar un valor predeterminado igual a $HOME/.config/gxkb/gxkb.cfg. El archivo de configuración debe crearse en la primera ejecución y se puede modificar cuando gxkb no se está ejecutando. La configuración de gxkb se puede cambiar sobre la marcha con el comando setxkbmap(1), en cuyo caso gxkb actualizará su archivo de configuración al salir.

$XDG_DATA_HOME/gxkb/flags

Recursos propios del usuario para reemplazar las imágenes de banderas del directorio PREFIX/share/gxkb/flags. Si $XDG_DATA_HOME no está establecido o está vacío, se debe usar un valor predeterminado igual a $HOME/.local/share/gxkb/flags.
