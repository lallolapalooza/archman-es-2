NOMBRE

geoiplookup - buscar país usando dirección IP o nombre de host

SINOPSIS

geoiplookup [-d directorio] [-f nombre_archivo] [-v] <direccion_ip|nombre_host>

DESCRIPCIÓN

geoiplookup utiliza la biblioteca GeoIP y la base de datos para encontrar el País de origen de una dirección IP o nombre de host.

Por ejemplo

geoiplookup 80.60.233.195

encontrará el País de origen de 80.60.233.195, en el siguiente formato:

NL, Países Bajos

OPCIONES

-f
Especificar una ruta personalizada a un único archivo de datos GeoIP.
-d
Especificar un directorio personalizado que contenga archivos de datos GeoIP. Por defecto, geoiplookup busca en /usr/share/GeoIP
-v
Muestra la fecha y el número de compilación de los archivos de datos GeoIP.
