subrutina cgeesx (character jobvs, character sort, external select, character sense, integer n, complex, dimension( lda, * ) a, integer lda, integer sdim, complex, dimension( * ) w, complex, dimension( ldvs, * ) vs, integer ldvs, real rconde, real rcondv, complex, dimension( * ) work, integer lwork, real, dimension( * ) rwork, logical, dimension( * ) bwork, integer info)

CGEESX calcula los valores propios, la forma de Schur y, opcionalmente, la matriz de vectores de Schur para matrices GE

Propósito:

!>
!> CGEESX calcula para una matriz compleja A no simétrica de N por N, los
!> valores propios, la forma de Schur T y, opcionalmente, la matriz de
!> vectores de Schur Z. Esto da la factorización de Schur A = Z*T*(Z**H).
!>
!> Opcionalmente, también ordena los valores propios en la diagonal de
!> la forma de Schur para que los valores propios seleccionados estén en la
!> parte superior izquierda;
!> calcula un número recíproco de condición para el promedio de los
!> valores propios seleccionados (RCONDE); y calcula un número recíproco de
!> condición para el subespacio invariante derecho correspondiente a los
!> valores propios seleccionados (RCONDV). Las columnas principales de Z forman una
!> base ortonormal para este subespacio invariante.
!>
!> Para una mayor explicación de los números recíprocos de condición RCONDE
!> y RCONDV, consulte la Sección 4.10 de la Guía del Usuario de LAPACK
!> (donde estas cantidades se llaman s y sep respectivamente).
!>
!> Una matriz compleja está en forma de Schur si es triangular superior.
!>

Parámetros

JOBVS 
!>          JOBVS es CHARACTER*1
!>          = 'N': no se calculan vectores de Schur;
!>          = 'V': se calculan vectores de Schur.
!>

SORT

!>          SORT es CHARACTER*1
!>          Especifica si se ordenan o no los valores propios en la
!>          diagonal de la forma de Schur.
!>          = 'N': los valores propios no se ordenan;
!>          = 'S': los valores propios se ordenan (ver SELECT).
!>

SELECT

!>          SELECT es una FUNCIÓN LOGICA de un argumento COMPLEJO
!>          SELECT debe declararse EXTERNAL en la subrutina que llama.
!>          Si SORT = 'S', SELECT se usa para seleccionar valores propios para ordenar
!>          en la parte superior izquierda de la forma de Schur.
!>          Si SORT = 'N', SELECT no se referencia.
!>          Un valor propio W(j) se selecciona si SELECT(W(j)) es verdadero.
!>

SENSE

!>          SENSE es CHARACTER*1
!>          Determina qué números recíprocos de condición se calculan.
!>          = 'N': no se calcula ninguno;
!>          = 'E': se calcula solo para el promedio de los valores propios seleccionados;
!>          = 'V': se calcula solo para el subespacio invariante derecho seleccionado;
!>          = 'B': se calcula para ambos.
!>          Si SENSE = 'E', 'V' o 'B', SORT debe ser igual a 'S'.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A. N >= 0.
!>

A

!>          A es un array COMPLEJO, de dimensión (LDA, N)
!>          En la entrada, la matriz A de N por N.
!>          En la salida, A se sobrescribe con su forma de Schur T.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A. LDA >= max(1, N).
!>

SDIM

!>          SDIM es INTEGER
!>          Si SORT = 'N', SDIM = 0.
!>          Si SORT = 'S', SDIM = número de valores propios para los que
!>                         SELECT es verdadero.
!>

W

!>          W es un array COMPLEJO, de dimensión (N)
!>          W contiene los valores propios calculados, en el mismo orden
!>          en que aparecen en la diagonal de la forma de Schur de salida T.
!>

VS

!>          VS es un array COMPLEJO, de dimensión (LDVS, N)
!>          Si JOBVS = 'V', VS contiene la matriz unitaria Z de vectores
!>          de Schur.
!>          Si JOBVS = 'N', VS no se referencia.
!>

LDVS

!>          LDVS es INTEGER
!>          La dimensión principal del array VS. LDVS >= 1, y si
!>          JOBVS = 'V', LDVS >= N.
!>

RCONDE

!>          RCONDE es REAL
!>          Si SENSE = 'E' o 'B', RCONDE contiene el número recíproco
!>          de condición para el promedio de los valores propios seleccionados.
!>          No se referencia si SENSE = 'N' o 'V'.
!>

RCONDV

!>          RCONDV es REAL
!>          Si SENSE = 'V' o 'B', RCONDV contiene el número recíproco
!>          de condición para el subespacio invariante derecho seleccionado.
!>          No se referencia si SENSE = 'N' o 'E'.
!>

WORK

!>          WORK es un array COMPLEJO, de dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK. LWORK >= max(1, 2*N).
!>          Además, si SENSE = 'E' o 'V' o 'B', LWORK >= 2*SDIM*(N-SDIM),
!>          donde SDIM es el número de valores propios seleccionados calculados por
!>          esta rutina. Tenga en cuenta que 2*SDIM*(N-SDIM) <= N*N/2. Tenga en cuenta
!>          también que solo se devuelve un error si LWORK < max(1, 2*N), pero si
!>          SENSE = 'E' o 'V' o 'B' esto puede no ser suficiente.
!>          Para un buen rendimiento, LWORK generalmente debe ser mayor.
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula un límite superior para el tamaño óptimo del
!>          array WORK, devuelve este valor como la primera entrada del array WORK,
!>          y XERBLA no emite ningún mensaje de error relacionado con LWORK.
!>

RWORK

!>          RWORK es un array REAL, de dimensión (N)
!>

BWORK

!>          BWORK es un array LOGICAL, de dimensión (N)
!>          No se referencia si SORT = 'N'.
!>

INFO

!>          INFO es INTEGER
!>          = 0: salida exitosa
!>          < 0: si INFO = -i, el argumento i tuvo un valor ilegal.
!>          > 0: si INFO = i, y i es
!>             <= N: el algoritmo QR falló en calcular todos los
!>                   valores propios; los elementos 1:ILO-1 y i+1:N de W
!>                   contienen aquellos valores propios que han convergido; si
!>                   JOBVS = 'V', VS contiene la transformación que
!>                   reduce A a su forma de Schur parcialmente convergida.
!>             = N+1: los valores propios no pudieron ser reordenados porque algunos
!>                   valores propios estaban demasiado cerca para separarse (el problema
!>                   es muy mal condicionado);
!>             = N+2: después de reordenar, la precisión cambió los valores de algunos
!>

 ZGEESX calcula los eigenvalores, la forma de Schur y,
    opcionalmente, la matriz de vectores de Schur para matrices GE


Propósito:




!>
!> ZGEESX calcula para una matriz compleja no simétrica A de dimensión N por N, los
!> eigenvalores, la forma de Schur T y, opcionalmente, la matriz de vectores de Schur
!> Z. Esto da la factorización de Schur A = Z*T*(Z**H).
!>
!> Opcionalmente, también ordena los eigenvalores en la diagonal de la
!> forma de Schur de modo que los eigenvalores seleccionados estén en la
!> parte superior izquierda; calcula un número de condición recíproco para el promedio de los
!> eigenvalores seleccionados (RCONDE); y calcula un número de condición
!> recíproco para el subespacio invariante derecho correspondiente a los
!> eigenvalores seleccionados (RCONDV). Las columnas principales de Z forman una
!> base ortonormal para este subespacio invariante.
!>
!> Para una explicación adicional de los números de condición recíprocos RCONDE
!> y RCONDV, véase la Sección 4.10 de la Guía de Usuarios de LAPACK (donde
!> estas cantidades se denominan s y sep respectivamente).

!>
