GENPMDA(1) Manual de Comandos Generales GENPMDA(1)

NOMBRE

genpmda - Generador de Agentes de Dominio de Rendimiento (PMDA)

SINOPSIS

genpmda [-dv] [-D dominio] [-n pmns] [-o dir] [-s stdpmid] [-t topdir] -c config -i IAM

DESCRIPCIÓN

genpmda es una herramienta de desarrollo rápido de aplicaciones para crear nuevos Agentes de Dominio de Rendimiento (PMDA), véase PMDA(3). Proporciona una forma muy fácil y eficiente de extender el Co-Pilot de Rendimiento (PCP) con nuevas métricas de rendimiento sin necesidad de comprender los detalles de bajo nivel de cómo se construyen los PMDA.

genpmda lee un archivo de configuración que contiene un Espacio de Nombres de Métricas de Rendimiento (PMNS) aumentado, véase PMNS(5), y genera automáticamente casi todo el código fuente para implementar un PMDA completamente funcional, incluyendo el Makefile, el espacio de nombres, scripts de soporte para configurar el nuevo PMDA y el texto de ayuda de las métricas. Los PMDA bastante simples pueden generarse automáticamente a partir del archivo de configuración sin escribir código adicional. Los PMDA más complicados, por ejemplo, que contienen múltiples dominios de instancia, solo requieren que los métodos de actualización para los dominios de instancia se escriban manualmente.

A continuación se muestra un ejemplo del formato del archivo de configuración aceptado por genpmda.

OPCIONES

Opciones requeridas:
-c config
archivo de entrada config, véase el ejemplo a continuación
-i IAM
nombre del PMDA IAM, debe aparecer en stdpmid o se debe usar la opción -D para especificar un dominio.
Otras opciones:
-d
generar un script de instalación para un PMDA demonio (por defecto es DSO)
-D dominio
usar el número de dominio en el pmns generado y en domain.h (si no se usa -s)
-n pmns
usar pmns como raíz del espacio de nombres (el valor por defecto coincide con la opción -i)
-o dir
usar dir para el código fuente generado, por defecto ./generated
-s stdpmid
ruta a stdpmid (por defecto ../../pmns/stdpmid)
-t topdir
usar topdir en el GNUmakefile generado, por defecto ../../..
-v
imprimir mensajes detallados sobre lo que está haciendo genpmda.

Ejemplo:
Generar un PMDA de "ejemplo" usando el dominio 99:


genpmda -D 99 -v -i EXAMPLE -c example.conf

Aquí está el archivo de configuración example.conf (para la opción requerida -c): 

example {
    metric
}
example.metric {
    ##  metric            string
    ##  pmid              EXAMPLE:CLUSTER:0
    ##  indom             PM_INDOM_NULL
    ##  type              PM_TYPE_STRING
    ##  units             PMDA_PMUNITS(0,0,0,0,0,0)
    ##  semantics         PM_SEM_DISCRETE
    ##  briefhelptext     texto de ayuda de una línea para example.metric.string
    ##  helptext          texto de ayuda largo para example.metric.string
    ##  helptext          Esta es la segunda línea del texto de ayuda largo
    ##  helptext          y esta es la tercera línea.
    ##  fetch             función example_string_fetch_callback
    ##  code              atom->cp = "hola mundo";
    ##  code              return 1;
    ##  endmetric
}

ENTORNO PCP

Las variables de entorno con el prefijo PCP_ se utilizan para parametrizar los nombres de archivos y directorios utilizados por PCP. En cada instalación, el archivo /etc/pcp.conf contiene los valores locales para estas variables. La variable $PCP_CONF puede usarse para especificar un archivo de configuración alternativo, como se describe en pcp.conf(5).
