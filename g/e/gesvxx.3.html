CGESVXX calcula la solución al sistema de ecuaciones lineales A * X = B para matrices

GE

Propósito

: 
!>
!>    CGESVXX usa la factorización LU para calcular la solución a un
!>    sistema complejo de ecuaciones lineales A * X = B, donde A es una
!>    matriz N por N y X y B son matrices N por NRHS.
!>
!>    Si se solicita, se devuelven tanto límites de error en norma como
!>    límites de error máximo por componente. CGESVXX devolverá una
!>    solución con un error garantizado diminuto (O(eps) donde eps es la
!>    precisión de máquina de trabajo), a menos que la matriz esté muy mal
!>    condicionada, en cuyo caso se devuelve una advertencia. También se
!>    calculan y devuelven los números de condición relevantes.
!>
!>    CGESVXX acepta factorizaciones y factores de equilibrado
!>    proporcionados por el usuario; consulte las definiciones de las
!>    opciones FACT y EQUED. Resolver con refinamiento y usando una
!>    factorización de una llamada anterior a CGESVXX también producirá
!>    una solución con errores O(eps) o advertencias, pero no podemos
!>    afirmar eso para factorizaciones y factores de equilibrado
!>    proporcionados por el usuario en general si difieren de lo que
!>    CGESVXX produciría por sí mismo.
!
>

Descripción

: 
!>
!>    Se realizan los siguientes pasos:
!>
!>    1. Si FACT = 'E', se calculan factores de escala reales para
!>    equilibrar el sistema:
!>
!>      TRANS = 'N':  diag(R)*A*diag(C)     *inv(diag(C))*X = diag(R)*B
!>      TRANS = 'T': (diag(R)*A*diag(C))**T *inv(diag(R))*X = diag(C)*B
!>      TRANS = 'C': (diag(R)*A*diag(C))**H *inv(diag(R))*X = diag(C)*B
!>
!>    Si el sistema se equilibra o no depende de la escala de la matriz
!>    A, pero si se usa el equilibrado, A se sobrescribe por
!>    diag(R)*A*diag(C) y B por diag(R)*B (si TRANS='N') o diag(C)*B
!>    (si TRANS = 'T' o 'C').
!>
!>    2. Si FACT = 'N' o 'E', se usa la descomposición LU para factorizar
!>    la matriz A (después del equilibrado si FACT = 'E') como
!>
!>      A = P * L * U,
!>
!>    donde P es una matriz de permutación, L es una matriz triangular
!>    inferior unitaria y U es triangular superior.
!>
!>    3. Si algún U(i,i)=0, de modo que U sea exactamente singular, la
!>    rutina retorna con INFO = i. De lo contrario, la forma factorizada
!>    de A se usa para estimar el número de condición de la matriz A (véase
!>    el argumento RCOND). Si el recíproco del número de condición es menor
!>    que la precisión de máquina, la rutina continúa igualmente para
!>    resolver X y calcular los límites de error como se describe a
!>    continuación.
!>
!>    4. El sistema de ecuaciones se resuelve para X usando la forma
!>    factorizada de A.
!>
!>    5. Por defecto (a menos que PARAMS(LA_LINRX_ITREF_I) esté establecido
!>    en cero), la rutina usará refinamiento iterativo para intentar
!>    obtener un error y límites de error pequeños. El refinamiento
!>    calcula el residuo con al menos el doble de la precisión de
!>    trabajo.
!>
!>    6. Si se usó el equilibrado, la matriz X se premultiplica por
!>    diag(C) (si TRANS = 'N') o diag(R) (si TRANS = 'T' o 'C') de modo
!>    que resuelva el sistema original antes del equilibrado.
!
> 
!>     Algunos parámetros opcionales se agrupan en el array PARAMS. Estas
!>     configuraciones determinan cómo se realiza el refinamiento, pero
!>     a menudo los valores por defecto son aceptables. Si los valores
!>     por defecto son aceptables, los usuarios pueden pasar NPARAMS = 0
!>     lo que impide que el código fuente acceda al argumento PARAMS.
!
>

subroutine cgesvxx (character fact, character trans, integer n, integer nrhs, complex, dimension( lda, * ) a, integer lda, complex, dimension( ldaf, * ) af, integer ldaf, integer, dimension( * ) ipiv, character equed, complex, dimension( * ) r, complex, dimension( * ) c, complex, dimension( ldb, * ) b, integer ldb, complex, dimension( ldx , * ) x, integer ldx, double precision rcond, double precision rpvgrw, double precision, dimension( * ) berr, integer n_err_bnds, double precision, dimension( nrhs, * ) err_bnds_norm, double precision, dimension( nrhs, * ) err_bnds_comp, integer nparams, double precision, dimension( * ) params, complex, dimension( * ) work, integer, dimension( * ) iwork, integer info)

CGESVXX computes the solution to system of linear equations A * X = B for GE matrices

Purpose:

!>
!>    CGESVXX uses the LU factorization to compute the solution to a
!>    complex system of linear equations  A * X = B,  where A is an
!>    N-by-N matrix and X and B are N-by-NRHS matrices.
!>
!>    If requested, both normwise and maximum componentwise error bounds
!>    are returned. CGESVXX will return a solution with a tiny
!>    guaranteed error (O(eps) where eps is the working machine
!>    precision) unless the matrix is very ill-conditioned, in which
!>    case a warning is returned. Relevant condition numbers also are
!>    calculated and returned.
!>
!>    CGESVXX accepts user-provided factorizations and equilibration
!>    factors; see the definitions of the FACT and EQUED options.
!>    Solving with refinement and using a factorization from a previous
!>    CGESVXX call will also produce a solution with either O(eps)
!>    errors or warnings, but we cannot make that claim for general
!>    user-provided factorizations and equilibration factors if they
!>    differ from what CGESVXX would itself produce.
!>

Description:

!>
!>    The following steps are performed:
!>
!>    1. If FACT = 'E', complex scaling factors are computed to equilibrate
!>    the system:
!>
!>      TRANS = 'N':  diag(R)*A*diag(C)     *inv(diag(C))*X = diag(R)*B
!>      TRANS = 'C': (diag(R)*A*diag(C))**H *inv(diag(R))*X = diag(C)*B
!>
!>    Note that TRANS = 'T' is not allowed for complex matrices.
!>    Whether or not the system will be equilibrated depends on the
!>    scaling of the matrix A, but if equilibration is used, A is
!>    overwritten by diag(R)*A*diag(C) and B by diag(R)*B (if TRANS='N')
!>    or diag(C)*B (if TRANS = 'C').
!>
!>    2. If FACT = 'N' or 'E', the LU decomposition is used to factor
!>    the matrix A (after equilibration if FACT = 'E') as
!>
!>      A = P * L * U,
!>
!>    where P is a permutation matrix, L is a unit lower triangular
!>    matrix, and U is upper triangular.
!>
!>    3. If some U(i,i)=0, so that U is exactly singular, then the

Purpose:

!>
!>    DGESVXX uses the LU factorization to compute the solution to a
!>    double precision system of linear equations  A * X = B,  where A is an
!>    N-by-N matrix and X and B are N-by-NRHS matrices.
!>
!>    If requested, both normwise and maximum componentwise error bounds

!>
!>    SGESVXX usa la factorización LU para calcular la solución de un
!>    sistema real de ecuaciones lineales  A * X = B,  donde A es una
!>    matriz N-por-N y X y B son matrices N-por-NRHS.
!>
!>    Si se solicita, se devuelven tanto límites de error en norma como
!>    límites de error máximo componente a componente. SGESVXX devolverá una
!>    solución con un error garantizado diminuto (O(eps) donde eps es la
!>    precisión de máquina de trabajo) a menos que la matriz esté muy mal
!>    condicionada, en cuyo caso se devuelve una advertencia. También se
!>    calculan y devuelven números de condición relevantes.
!>
!>    SGESVXX acepta factorizaciones y factores de equilibrado proporcionados
!>    por el usuario; véanse las definiciones de las opciones FACT y EQUED.
!>    Resolver con refinamiento y usando una factorización de una llamada
!>    anterior a SGESVXX también producirá una solución con errores O(eps)
!>    o advertencias, pero no podemos hacer esa afirmación para
!>    factorizaciones y factores de equilibrado generales proporcionados por
!>    el usuario si difieren de lo que SGESVXX produciría por sí mismo.
!

Descripción

!>
!>    Se realizan los siguientes pasos:
!>
!>    1. Si FACT = 'E', se calculan factores de escala reales para equilibrar
!>    el sistema:
!>
!>      TRANS = 'N':  diag(R)*A*diag(C)     *inv(diag(C))*X = diag(R)*B
!>      TRANS = 'T': (diag(R)*A*diag(C))**T *inv(diag(R))*X = diag(C)*B
!>      TRANS = 'C': (diag(R)*A*diag(C))**H *inv(diag(R))*X = diag(C)*B
!>
!>    Si el sistema se equilibra o no depende de la escala de la matriz A,
!>    pero si se usa equilibrado, A se sobrescribe por diag(R)*A*diag(C) y B
!>    por diag(R)*B (si TRANS='N') o diag(C)*B (si TRANS = 'T' o 'C').
!>
!>    2. Si FACT = 'N' o 'E', se usa la descomposición LU para factorizar
!>    la matriz A (después del equilibrado si FACT = 'E') como
!>
!>      A = P * L * U,
!>
!>    donde P es una matriz de permutación, L es una matriz triangular
!>    inferior unitaria, y U es triangular superior.
!>
!>    3. Si algún U(i,i)=0, de modo que U es exactamente singular, entonces la
!>    rutina retorna con INFO = i. De lo contrario, la forma factorizada de A
!>    se usa para estimar el número de condición de la matriz A (véase el
!>    argumento RCOND). Si el recíproco del número de condición es menor
!>    que la precisión de máquina, la rutina continúa para resolver X
!>    y calcular límites de error como se describe a continuación.
!>
!>    4. El sistema de ecuaciones se resuelve para X usando la forma
!>    factorizada de A.
!>
!>    5. Por defecto (a menos que PARAMS(LA_LINRX_ITREF_I) se establezca en
!>    cero), la rutina usará refinamiento iterativo para intentar obtener un
!>    pequeño error y límites de error.  El refinamiento calcula el residuo
!>    con al menos el doble de la precisión de trabajo.
!>
!>    6. Si se usó equilibrado, la matriz X se premultiplica por
!>    diag(C) (si TRANS = 'N') o diag(R) (si TRANS = 'T' o 'C') de modo
!>    que resuelva el sistema original antes del equilibrado.
!

!>     Algunos parámetros opcionales se agrupan en el arreglo PARAMS.  Estas
!>     configuraciones determinan cómo se realiza el refinamiento, pero a
!>     menudo los valores predeterminados son aceptables.  Si los valores

!>     lo que evita que el código fuente acceda al argumento PARAMS.

GE

Propósito

: 
!>
!>    ZGESVXX usa la factorización LU para calcular la solución a un
!>    sistema de ecuaciones lineales complejo*16 A * X = B, donde A es
!>    una matriz N-por-N y X y B son matrices N-por-NRHS.
!>
!>    Si se solicita, se devuelven tanto cotas de error normativas como
!>    de máximo componente a componente. ZGESVXX devolverá una
!>    solución con un error garantizado minúsculo (O(eps) donde eps es
!>    la precisión de máquina de trabajo) a menos que la matriz esté
!>    muy mal condicionada, en cuyo caso se devuelve una advertencia.
!>    También se calculan y devuelven números de condición relevantes.
!>
!>    ZGESVXX acepta factorizaciones y factores de equilibrado
!>    proporcionados por el usuario; vea las definiciones de las
!>    opciones FACT y EQUED. Resolver con refinamiento y usando una
!>    factorización de una llamada previa a ZGESVXX también producirá
!>    una solución con errores O(eps) o advertencias, pero no podemos
!>    hacer esa afirmación para factorizaciones y factores de
!>    equilibrado proporcionados por el usuario en general si difieren
!>    de lo que ZGESVXX produciría por sí mismo.
!
>

Descripción

: 
!>
!>    Se realizan los siguientes pasos:
!>
!>    1. Si FACT = 'E', se calculan factores de escala en precisión
!>    doble para equilibrar el sistema:
!>
!>      TRANS = 'N':  diag(R)*A*diag(C)     *inv(diag(C))*X = diag(R)*B
!>      TRANS = 'T': (diag(R)*A*diag(C))**T *inv(diag(R))*X = diag(C)*B
!>      TRANS = 'C': (diag(R)*A*diag(C))**H *inv(diag(R))*X = diag(C)*B
!>
!>    Si el sistema se equilibra o no depende de la escala de la
!>    matriz A, pero si se usa equilibrado, A se sobrescribe con
!>    diag(R)*A*diag(C) y B con diag(R)*B (si TRANS='N') o diag(C)*B
!>    (si TRANS = 'T' o 'C').
!>
!>    2. Si FACT = 'N' o 'E', se usa la descomposición LU para
!>    factorizar la matriz A (después del equilibrado si FACT = 'E')
!>    como
!>
!>      A = P * L * U,
!>
!>    donde P es una matriz de permutación, L es una matriz triangular
!>    inferior unitaria, y U es triangular superior.
!>
!>    3. Si algún U(i,i)=0, de modo que U es exactamente singular,
!>    entonces la rutina retorna con INFO = i. De lo contrario, la
!>    forma factorizada de A se usa para estimar el número de
!>    condición de la matriz A (vea el argumento RCOND). Si el
!>    recíproco del número de condición es menor que la precisión de
!>    máquina, la rutina continúa para resolver X y calcular cotas de
!>    error como se describe a continuación.
!>
!>    4. El sistema de ecuaciones se resuelve para X usando la forma
!>    factorizada de A.
!>
!>    5. Por defecto (a menos que PARAMS(LA_LINRX_ITREF_I) se establezca
!>    en cero), la rutina usará refinamiento iterativo para intentar
!>    obtener un pequeño error y cotas de error. El refinamiento
!>    calcula el residuo a al menos dos veces la precisión de trabajo.
!>
!>    6. Si se usó equilibrado, la matriz X se premultiplica por
!>    diag(C) (si TRANS = 'N') o diag(R) (si TRANS = 'T' o 'C') de
!>    modo que resuelva el sistema original antes del equilibrado.
!
> 
!>     Algunos parámetros opcionales están agrupados en el arreglo
!>     PARAMS. Estas configuraciones determinan cómo se realiza el
!>     refinamiento, pero a menudo los valores predeterminados son
!>     aceptables. Si los valores predeterminados son aceptables, los
!>     usuarios pueden pasar NPARAMS = 0 lo que impide que el código
!>     fuente acceda al argumento PARAMS.
!
>
