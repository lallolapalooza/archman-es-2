CGEQRF

Propósito:

!>
!> CGEQRF calcula una factorización QR de una matriz compleja A de M por N:
!>
!>    A = Q * ( R ),
!>            ( 0 )
!>
!> donde:
!>
!>    Q es una matriz ortogonal de M por M;
!>    R es una matriz triangular superior de N por N;
!>    0 es una matriz cero de (M-N) por N, si M > N.
!>
!>

Parámetros

M 
!>          M es INTEGER
!>          El número de filas de la matriz A.  M >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz A.  N >= 0.
!>

A

!>          A es un arreglo COMPLEX, dimensión (LDA,N)
!>          En la entrada, la matriz A de M por N.
!>          En la salida, los elementos en y por encima de la diagonal del arreglo
!>          contienen la matriz trapezoidal superior R de min(M,N) por N (R es
!>          triangular superior si m >= n); los elementos por debajo de la diagonal,
!>          junto con el arreglo TAU, representan la matriz unitaria Q como un
!>          producto de min(m,n) reflectores elementales (ver Detalles
!>          Adicionales).
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del arreglo A.  LDA >= max(1,M).
!>

TAU

!>          TAU es un arreglo COMPLEX, dimensión (min(M,N))
!>          Los factores escalares de los reflectores elementales (ver Detalles
!>          Adicionales).
!>

WORK

!>          WORK es un arreglo COMPLEX, dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del arreglo WORK.
!>          LWORK >= 1, si MIN(M,N) = 0, y LWORK >= N, en caso contrario.
!>          Para un rendimiento óptimo LWORK >= N*NB, donde NB es
!>          el tamaño de bloque óptimo.
!>
!>          Si LWORK = -1, se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo del arreglo WORK, devuelve
!>          este valor como la primera entrada del arreglo WORK, y XERBLA no emite
!>          ningún mensaje de error relacionado con LWORK.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>

Autor

Univ. of Tennessee

Univ. of California Berkeley

Univ. of Colorado Denver

NAG Ltd.

Detalles Adicionales:

!>
!>  La matriz Q se representa como un producto de reflectores elementales
!>
!>     Q = H(1) H(2) . . . H(k), donde k = min(m,n).
!>
!>  Cada H(i) tiene la forma
!>
!>     H(i) = I - tau * v * v**H
!>
!>  donde tau es un escalar complejo, y v es un vector complejo con
!>  v(1:i-1) = 0 y v(i) = 1; v(i+1:m) se almacena en la salida en A(i+1:m,i),
!>  y tau en TAU(i).
!>

SGEQRF


Purpose:




!>
!> SGEQRF computes a QR factorization of a real M-by-N matrix A:
!>
!>    A = Q * ( R ),
!>            ( 0 )
!>
!> where:
!>
!>    Q is a M-by-M orthogonal matrix;
!>    R is an upper-triangular N-by-N matrix;
!>    0 is a (M-N)-by-N zero matrix, if M > N.
!>
!> 




Parameters


M

!>          M is INTEGER
!>          The number of rows of the matrix A.  M >= 0.
!> 


N


!>          N is INTEGER
!>          The number of columns of the matrix A.  N >= 0.
!> 


A


!>          A is REAL array, dimension (LDA,N)
!>          On entry, the M-by-N matrix A.
!>          On exit, the elements on and above the diagonal of the array
!>          contain the min(M,N)-by-N upper trapezoidal matrix R (R is
!>          upper triangular if m >= n); the elements below the diagonal,
!>          with the array TAU, represent the orthogonal matrix Q as a
!>          product of min(m,n) elementary reflectors (see Further
!>          Details).
!> 


LDA


!>          LDA is INTEGER
!>          The leading dimension of the array A.  LDA >= max(1,M).
!> 


TAU


!>          TAU is REAL array, dimension (min(M,N))
!>          The scalar factors of the elementary reflectors (see Further
!>          Details).
!> 


WORK


!>          WORK is REAL array, dimension (MAX(1,LWORK))
!>          On exit, if INFO = 0, WORK(1) returns the optimal LWORK.
!> 


LWORK


!>          LWORK is INTEGER
!>          The dimension of the array WORK.
!>          LWORK >= 1, if MIN(M,N) = 0, and LWORK >= N, otherwise.
!>          For optimum performance LWORK >= N*NB, where NB is
!>          the optimal blocksize.
!>
!>          If LWORK = -1, then a workspace query is assumed; the routine
!>          only calculates the optimal size of the WORK array, returns
!>          this value as the first entry of the WORK array, and no error
!>          message related to LWORK is issued by XERBLA.
!> 


INFO


!>          INFO is INTEGER
!>          = 0:  successful exit
!>          < 0:  if INFO = -i, the i-th argument had an illegal value
!> 




Author


Univ. of Tennessee

Univ. of California Berkeley


Univ. of Colorado Denver


NAG Ltd.




Further Details:




!>
!>  The matrix Q is represented as a product of elementary reflectors
!>
!>     Q = H(1) H(2) . . . H(k), where k = min(m,n).
!>
!>  Each H(i) has the form
!>
!>     H(i) = I - tau * v * v**T
!>
!>  where tau is a real scalar, and v is a real vector with
!>  v(1:i-1) = 0 and v(i) = 1; v(i+1:m) is stored on exit in A(i+1:m,i),
!>  and tau in TAU(i).
!>
