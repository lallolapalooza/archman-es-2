GETS(3P) Manual de Programador de POSIX GETS(3P)

PRÓLOGO

Esta página del manual forma parte del Manual de Programador de POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual de Linux correspondiente para conocer los detalles del comportamiento en Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

gets — obtener una cadena de un flujo stdin

SINOPSIS

#include <stdio.h>
char *gets(char *s);

DESCRIPCIÓN

La funcionalidad descrita en esta página de referencia está alineada con el estándar ISO C. Cualquier conflicto entre los requisitos descritos aquí y el estándar ISO C es involuntario. Este volumen de POSIX.1‐2017 remite al estándar ISO C.

La función gets() leerá bytes del flujo de entrada estándar, stdin, en el array apuntado por s, hasta que se lea un <salto de línea> o se encuentre una condición de fin de archivo. Cualquier <salto de línea> se descartará y se colocará un byte nulo inmediatamente después del último byte leído en el array.

La función gets() puede marcar la marca de tiempo del último acceso a datos del archivo asociado con stream para su actualización. La marca de tiempo del último acceso a datos se marcará para su actualización por la primera ejecución exitosa de fgetc(), fgets(), fread(), fscanf(), getc(), getchar(), getdelim(), getline(), gets() o scanf() utilizando stream que devuelva datos no proporcionados por una llamada previa a ungetc().

VALOR DE RETORNO

Al completarse con éxito, gets() devolverá s. Si el indicador de fin de archivo para el flujo está establecido, o si el flujo está en fin de archivo, el indicador de fin de archivo para el flujo se establecerá y gets() devolverá un puntero nulo. Si ocurre un error de lectura, el indicador de error para el flujo se establecerá, gets() devolverá un puntero nulo y establecerá errno para indicar el error.

ERRORES

Consulte fgetc().

Las siguientes secciones son informativas.

EJEMPLOS

Ninguno.

USO POR LA APLICACIÓN

Leer una línea que desborda el array apuntado por s resulta en comportamiento indefinido. Se recomienda el uso de fgets().

Dado que el usuario no puede especificar la longitud del búfer pasado a gets(), se desaconseja el uso de esta función. La longitud de la cadena leída es ilimitada. Es posible desbordar este búfer de tal manera que cause fallos en las aplicaciones o posibles violaciones de seguridad del sistema.

Las aplicaciones deben usar la función fgets() en lugar de la función obsoleta gets().

JUSTIFICACIÓN

Los desarrolladores del estándar decidieron marcar la función gets() como obsoleta a pesar de estar en el estándar ISO C debido a la posibilidad de desbordamiento del búfer.

DIRECCIONES FUTURAS

La función gets() puede ser eliminada en una versión futura.
