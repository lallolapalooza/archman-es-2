gethostname(2) Manual de llamadas al sistema gethostname(2)

NOMBRE

gethostname, sethostname - obtener/establecer el nombre de host

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <unistd.h>
int gethostname(char *name, size_t size);
int sethostname(const char *name, size_t size);
Requisitos de macros de prueba de características para glibc (ver feature_test_macros(7)):

gethostname():

    _XOPEN_SOURCE >= 500 || _POSIX_C_SOURCE >= 200112L
        || /* glibc 2.19 y anteriores */ _BSD_SOURCE

sethostname():

    Desde glibc 2.21:
        _DEFAULT_SOURCE
    En glibc 2.19 y 2.20:
        _DEFAULT_SOURCE || (_XOPEN_SOURCE && _XOPEN_SOURCE < 500)
    Hasta e incluyendo glibc 2.19:
        _BSD_SOURCE || (_XOPEN_SOURCE && _XOPEN_SOURCE < 500)

DESCRIPCIÓN

Estas llamadas al sistema se utilizan para acceder o cambiar el nombre de host del sistema. Más precisamente, operan sobre el nombre de host asociado al espacio de nombres UTS del proceso que llama.

sethostname() establece el nombre de host al valor proporcionado en el array de caracteres name. El argumento size especifica el número de bytes en name. (Por lo tanto, name no requiere un byte nulo de terminación.)

gethostname() devuelve el nombre de host terminado en nulo en el array de caracteres name, que tiene un tamaño de size bytes. Si el nombre de host terminado en nulo es demasiado grande para caber, el nombre se trunca y no se devuelve ningún error (pero véase VERSIONES abajo). POSIX.1 dice que si ocurre tal truncamiento, es impredecible si el buffer devuelto incluye un byte nulo de terminación.

VALOR DE RETORNO

En caso de éxito, se devuelve cero. En caso de error, se devuelve -1 y errno se establece para indicar el error.

ERRORES

EFAULT
name es una dirección inválida.
EINVAL
size es negativo o, para sethostname(), size es mayor que el tamaño máximo permitido.
ENAMETOOLONG
(gethostname() de glibc) size es menor que el tamaño real. (Antes de glibc 2.1, glibc usa EINVAL para este caso).
EPERM
Para sethostname(), el llamador no tenía la capacidad CAP_SYS_ADMIN en el espacio de nombres de usuario asociado a su espacio de nombres UTS (ver namespaces(7)).

VERSIONES

SUSv2 garantiza que "Los nombres de host se limitan a 255 bytes". POSIX.1 garantiza que "Los nombres de host (sin incluir el byte nulo de terminación) se limitan a HOST_NAME_MAX bytes". En Linux, HOST_NAME_MAX se define con el valor 64, que ha sido el límite desde Linux 1.0 (kernels anteriores imponían un límite de 8 bytes).

Diferencias entre biblioteca C y kernel

La biblioteca C de GNU no utiliza la llamada al sistema gethostname(); en su lugar, implementa gethostname() como una función de biblioteca que llama a uname(2) y copia hasta size bytes del campo nodename devuelto en name. Después de realizar la copia, la función comprueba si la longitud de nodename era mayor o igual a size y, si es así, la función devuelve -1 con errno establecido en ENAMETOOLONG; en este caso, no se incluye un byte nulo de terminación en el name devuelto.

ESTÁNDARES

gethostname()
POSIX.1-2024.
sethostname()
Ninguno.

HISTORIA

SVr4, 4.4BSD (estas interfaces aparecieron por primera vez en 4.2BSD). POSIX.1 especifica gethostname() pero no sethostname().

Las versiones de glibc anteriores a glibc 2.2 manejan el caso en que la longitud de nodename era mayor o igual a size de manera diferente: no se copia nada en name y la función devuelve -1 con errno establecido en ENAMETOOLONG.

VER TAMBIÉN
