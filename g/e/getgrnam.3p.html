DESCRIPCIÓ

N

La función getgrnam() buscará en la base de datos de grupos una entrada con un name coinci

dente.

La función getgrnam() no necesita ser segura en entornos con

hilos.

Las aplicaciones que deseen comprobar situaciones de error deben establecer errno a 0 antes de llamar a getgrnam(). Si getgrnam() devuelve un puntero nulo y errno está establecido a un valor distinto de cero, ocurrió un

error.

La función getgrnam_r() actualizará la estructura group a la que apunta grp y almacenará un puntero a esa estructura en la ubicación a la que apunta result. La estructura contendrá una entrada de la base de datos de grupos con un name coincidente. El almacenamiento al que hace referencia la estructura group se asigna de la memoria proporcionada con el parámetro buffer, que tiene un tamaño de bufsize bytes. Una llamada a sysconf(_SC_GETGR_R_SIZE_MAX) devuelve -1 sin cambiar errno o un valor inicial sugerido para el tamaño de este búfer. Se devuelve un puntero nulo en la ubicación a la que apunta result en caso de error o si la en

trada solicitada
no se encuentra.

VALOR DE

RETORNO

La función getgrnam() devolverá un puntero a un struct group con la estructura definida en <grp.h> con una entrada coincidente si se encuentra alguna. La función getgrnam() devolverá un puntero nulo si la entrada solicitada no se encontró o si ocurrió un error. Si la entrada solicitada no se encontró, errno no se modificará. En caso de error, errno se establecerá para indicar el

error.

La aplicación no debe modificar la estructura a la que apunta el valor de retorno, ni ninguna de las áreas de almacenamiento a las que apuntan punteros dentro de la estructura. El puntero devuelto y los punteros dentro de la estructura podrían invalidarse, o la estructura o las áreas de almacenamiento podrían sobrescribirse por una llamada posterior a getgrent(), getgrgid() o getgrnam(). El puntero devuelto y los punteros dentro de la estructura también podrían invalidarse si el hilo que llama es

terminado.

La función getgrnam_r() devolverá cero en caso de éxito o si la entrada solicitada no se encontró y no ocur

rió ningún error. Si ocurrió algún error, se d
evolverá un número de error para indicar el error.
