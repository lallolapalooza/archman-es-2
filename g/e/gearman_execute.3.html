Enlazar con -lgearman

DESCRIPCIÓN

gearman_execute() se utiliza para crear una nueva gearman_task_st que se ejecuta contra la función que se encuentra mediante el argumento function_name.

gearman_work_t se puede utilizar para describir el trabajo que se ejecutará; se construye con gearman_argument_make(). El argumento unique_str es opcional, pero si se proporciona, es utilizado para la coalescencia por gearmand.

gearman_argument_t es el trabajo que el client enviará al servidor.

Si gearman_execute() recibe un gearman_work_t que se ha construido con un reductor, toma el gearman_argument_t y lo ejecuta contra una función como lo haría normalmente, pero le dice a la función que procese los resultados a través de una función *reductora* con la que se creó el gearman_work_t.

Lo que está sucediendo es que la función está mapeando/dividiendo el trabajo en unidades, y luego enviando cada una de ellas a la función reductora. Una vez que todo el trabajo se completa, la función *mappeadora* agregará el trabajo a través de una función *agregadora*, gearman_aggregator_fn, y devolverá un resultado.

Si alguna de las unidades de trabajo falla, el trabajo se abortará. El valor resultante se almacenará en el gearman_task_st.

El resultado se puede obtener de la tarea llamando a gearman_task_result() para obtener el gearman_result_st.

VALOR DE RETORNO

gearman_execute() devuelve una c:type:gearman_task_st.

EJEMPLO

/*
  Ejemplo de código para mostrar cómo enviar una cadena a una función llamada "reverse" e imprimir los resultados.
*/
/*
# Servidor y biblioteca Gearman
# Copyright (C) 2012 Data Differential, http://datadifferential.com/
# Todos los derechos reservados.
#
# Uso y distribución autorizados bajo la licencia BSD.  Ver
# el archivo COPYING en este directorio para el texto completo.
*/
#include <string.h>
#include <stdlib.h>
#include <stdio.h>
#include <libgearman/gearman.h>
int main(void)
{
  gearman_client_st *client= gearman_client_create(NULL);
  gearman_return_t ret= gearman_client_add_server(client, "localhost", 0);
  if (gearman_failed(ret))
  {
    return EXIT_FAILURE;
  }
  gearman_argument_t value= gearman_argument_make(0, 0, "Reverse Me", strlen("Reverse Me"));
  gearman_task_st *task= gearman_execute(client, 
                                         "reverse", strlen("reverse"),  // función
                                         NULL, 0,  // no se proporcionó valor único
                                         NULL, 
                                         &value, 0);
  if (task == NULL) // Si gearman_execute() puede devolver NULL en caso de error
  {
    fprintf(stderr, "Error: %s\n", gearman_client_error(client));
    gearman_client_free(client);
    return EXIT_FAILURE;
  }
  // Asegurarse de que la tarea se ejecutó correctamente
  if (gearman_success(gearman_task_return(task)))
  {
    // Hacer uso del valor
    gearman_result_st *result= gearman_task_result(task);
    printf("%.*s\n", (int)gearman_result_size(result), gearman_result_value(result));
  }
  gearman_client_free(client);
  return EXIT_SUCCESS;
}
