CGEMQRT

Propósito:

!>
!> CGEMQRT sobrescribe la matriz compleja general M-por-N C con
!>
!>                 SIDE = 'L'     SIDE = 'R'
!> TRANS = 'N':      Q C            C Q
!> TRANS = 'C':    Q**H C            C Q**H
!>
!> donde Q es una matriz compleja ortogonal definida como el producto de K
!> reflectores elementales:
!>
!>       Q = H(1) H(2) . . . H(K) = I - V T V**H
!>
!> generada usando la representación compacta WY tal como la devuelve CGEQRT.
!>
!> Q es de orden M si SIDE = 'L' y de orden N si SIDE = 'R'.
!>

Parámetros

SIDE 
!>          SIDE es CHARACTER*1
!>          = 'L': aplicar Q o Q**H desde la izquierda;
!>          = 'R': aplicar Q o Q**H desde la derecha.
!>

TRANS

!>          TRANS es CHARACTER*1
!>          = 'N':  Sin transposición, aplicar Q;
!>          = 'C':  Transpuesta conjugada, aplicar Q**H.
!>

M

!>          M es INTEGER
!>          El número de filas de la matriz C. M >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz C. N >= 0.
!>

K

!>          K es INTEGER
!>          El número de reflectores elementales cuyo producto define
!>          la matriz Q.
!>          Si SIDE = 'L', M >= K >= 0;
!>          si SIDE = 'R', N >= K >= 0.
!>

NB

!>          NB es INTEGER
!>          El tamaño de bloque usado para el almacenamiento de T.  K >= NB >= 1.
!>          Este debe ser el mismo valor de NB usado para generar T
!>          en CGEQRT.
!>

V

!>          V es un arreglo COMPLEX, dimensión (LDV,K)
!>          La i-ésima columna debe contener el vector que define el
!>          reflector elemental H(i), para i = 1,2,...,k, tal como lo devuelve
!>          CGEQRT en las primeras K columnas de su argumento de arreglo A.
!>

LDV

!>          LDV es INTEGER
!>          La dimensión principal del arreglo V.
!>          Si SIDE = 'L', LDA >= max(1,M);
!>          si SIDE = 'R', LDA >= max(1,N).
!>

T

!>          T es un arreglo COMPLEX, dimensión (LDT,K)
!>          Los factores triangulares superiores de los reflectores de bloque
!>          tal como los devuelve CGEQRT, almacenados como una matriz NB-por-N.
!>

LDT

!>          LDT es INTEGER
!>          La dimensión principal del arreglo T.  LDT >= NB.
!>

C

!>          C es un arreglo COMPLEX, dimensión (LDC,N)
!>          A la entrada, la matriz M-por-N C.
!>          A la salida, C es sobrescrita por Q C, Q**H C, C Q**H o C Q.
!>

LDC

!>          LDC es INTEGER
!>          La dimensión principal del arreglo C. LDC >= max(1,M).
!>

WORK

!>          WORK es un arreglo COMPLEX. La dimensión de WORK es
!>           N*NB si SIDE = 'L', o  M*NB si SIDE = 'R'.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>
