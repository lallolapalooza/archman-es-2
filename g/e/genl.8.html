NOMBRE

genl - frontend de utilidad de netlink genérico

SINOPSIS


genl [ -s[tats] ] [ -d[etalles] ] [ -r[aw] ] OBJETO

genl { -V[ersion] | -h[elp] }

OBJETO := { ctrl OPCIONES_CTRL }

OPCIONES_CTRL := { help | list | monitor | get PARMS }

PARMS := { name NOMBRE | id ID }

DESCRIPCIÓN

La utilidad genl proporciona un frontend simple para la biblioteca genérica netlink. Aunque está diseñada para soportar múltiples OBJETOS, por ahora solo está disponible el objeto ctrl, que se utiliza para consultar el controlador genérico netlink.

ctrl

El controlador genérico netlink se puede consultar de varias maneras:

help
Este comando simplemente imprime un texto de ayuda para el objeto ctrl.
list
Muestra los usuarios de netlink registrados.
monitor
Escucha las notificaciones genéricas de netlink.
get
Consulta el controlador para un usuario dado, identificado por name o id.

OPCIONES

genl admite las siguientes opciones.

-h, -help
Muestra un resumen de las opciones.
-V, -Version
Muestra la versión del programa.
-s, -stats, -statistics
Muestra estadísticas del objeto.
-d, -details
Muestra detalles del objeto.
-r, -raw
Solo muestra la salida bruta.
