getunwind(2) Manual de llamadas al sistema getunwind(2)

NOMBRE

getunwind - copia los datos de "unwind" al búfer del llamador

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <linux/unwind.h>
#include <sys/syscall.h>      /* Definición de constantes SYS_* */
#include <unistd.h>
[[deprecated]] long syscall(size_t buf_size;
                            SYS_getunwind, void buf[buf_size],
                            size_t buf_size);

DESCRIPCIÓN

Nota: esta llamada al sistema está obsoleta.

La llamada al sistema getunwind() específica para IA-64 copia los datos de "unwind" del marco de llamada del kernel al búfer apuntado por buf y devuelve el tamaño de los datos de "unwind"; estos datos describen la página de puerta (código del kernel que se mapea al espacio de usuario).

El tamaño del búfer buf se especifica en buf_size. Los datos se copian solo si buf_size es mayor o igual que el tamaño de los datos de "unwind" y buf no es NULL; de lo contrario, no se copian datos y la llamada tiene éxito, devolviendo el tamaño que se necesitaría para almacenar los datos de "unwind".

La primera parte de los datos de "unwind" contiene una tabla de "unwind". El resto contiene la información de "unwind" asociada, en ningún orden particular. La tabla de "unwind" contiene entradas de la siguiente forma:


u64 start;      (dirección de 64 bits del inicio de la función)
u64 end;        (dirección de 64 bits del fin de la función)
u64 info;       (desplazamiento relativo a BUF hacia la información de unwind)

Una entrada cuyo valor start sea cero indica el final de la tabla. Para más información sobre el formato, consulte el manual *IA-64 Software Conventions and Runtime Architecture*.

VALOR DE RETORNO

En caso de éxito, getunwind() devuelve el tamaño de los datos de "unwind". En caso de error, se devuelve -1 y errno se establece para indicar el error.

ERRORES

getunwind() falla con el error EFAULT si la información de "unwind" no se puede almacenar en el espacio especificado por buf.

ESTÁNDARES

Linux en IA-64.

HISTORIA

Linux 2.4.

Esta llamada al sistema ha sido obsoleta. La forma moderna de obtener los datos de "unwind" del kernel es a través de vdso(7).
