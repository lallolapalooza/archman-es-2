getdents(2) Manual de llamadas al sistema getdents(2)

NOMBRE

getdents, getdents64 - obtener entradas de directorio

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <sys/syscall.h>      /* Definición de constantes SYS_* */
#include <unistd.h>
long syscall(SYS_getdents, unsigned int fd, struct linux_dirent *dirp,
             unsigned int count);
#define _GNU_SOURCE           /* Ver feature_test_macros(7) */
#include <dirent.h>
ssize_t getdents64(size_t count;
                   int fd, void dirp[count], size_t count);

Nota: glibc no proporciona un envoltorio para getdents(), lo que requiere el uso de syscall(2).

Nota: No hay una definición de struct linux_dirent en glibc; ver NOTAS.

DESCRIPCIÓN

Estas no son las interfaces que te interesan. Busca readdir(3) para la interfaz de la biblioteca C conforme a POSIX. Esta página documenta las interfaces de llamada al sistema sin procesar del kernel.

getdents()

La llamada al sistema getdents() lee varias estructuras linux_dirent del directorio al que se refiere el descriptor de archivo abierto fd en el búfer apuntado por dirp. El argumento count especifica el tamaño de ese búfer.

La estructura linux_dirent se declara de la siguiente manera:


struct linux_dirent {
    unsigned long  d_ino;     /* Número de inodo */
    unsigned long  d_off;     /* No es un desplazamiento; ver abajo */
    unsigned short d_reclen;  /* Longitud de este linux_dirent */
    char           d_name[];  /* Nombre del archivo (terminado en nulo) */
                      /* la longitud es en realidad (d_reclen - 2 -
                         offsetof(struct linux_dirent, d_name)) */
    /*
    char           pad;       // Byte de relleno cero
    char           d_type;    // Tipo de archivo (solo desde Linux
                              // 2.6.4); el desplazamiento es (d_reclen - 1)
    */
}

d_ino es un número de inodo. d_off es un valor específico del sistema de archivos sin un significado específico para el espacio de usuario, aunque en sistemas de archivos más antiguos solía ser la distancia desde el inicio del directorio hasta el inicio de la siguiente linux_dirent; ver readdir(3). d_reclen es el tamaño de esta linux_dirent completa. d_name es un nombre de archivo terminado en nulo.

d_type es un byte al final de la estructura que indica el tipo de archivo. Contiene uno de los siguientes valores (definidos en <dirent.h>):

DT_BLK
Este es un dispositivo de bloques.
DT_CHR
Este es un dispositivo de caracteres.
DT_DIR
Este es un directorio.
DT_FIFO
Esta es una tubería con nombre (FIFO).
DT_LNK
Este es un enlace simbólico.
DT_REG
Este es un archivo regular.
DT_SOCK
Este es un socket de dominio UNIX.
DT_UNKNOWN
El tipo de archivo es desconocido.

El campo d_type se implementa desde Linux 2.6.4. Ocupa un espacio que anteriormente era un byte de relleno cero en la estructura linux_dirent. Por lo tanto, en kernels hasta e incluyendo Linux 2.6.3, intentar acceder a este campo siempre proporciona el valor 0 (DT_UNKNOWN).

Actualmente, solo algunos sistemas de archivos (entre ellos: Btrfs, ext2, ext3 y ext4) tienen soporte completo para devolver el tipo de archivo en d_type. Todas las aplicaciones deben manejar correctamente un retorno de DT_UNKNOWN.

getdents64()

La llamada al sistema original de Linux getdents() no manejaba sistemas de archivos grandes ni desplazamientos de archivos grandes. En consecuencia, Linux 2.4 agregó getdents64(), con tipos más amplios para los campos d_ino y d_off. Además, getdents64() soporta un campo explícito d_type.

La llamada al sistema getdents64() es como getdents(), excepto que su segundo argumento es un puntero a un búfer que contiene estructuras del siguiente tipo:


struct linux_dirent64 {
    ino64_t        d_ino;    /* Número de inodo de 64 bits */
    off64_t        d_off;    /* No es un desplazamiento; ver getdents() */
    unsigned short d_reclen; /* Tamaño de este dirent */
    unsigned char  d_type;   /* Tipo de archivo */
    char           d_name[]; /* Nombre del archivo (terminado en nulo) */
};

VALOR DE RETORNO

En caso de éxito, se devuelve el número de bytes leídos. Al final del directorio, se devuelve 0. En caso de error, se devuelve -1 y se establece errno para indicar el error.

ERRORES

EBADF
Descriptor de archivo fd inválido.
EFAULT
El argumento apunta fuera del espacio de direcciones del proceso que llama.
EINVAL
El búfer de resultado es demasiado pequeño.
ENOENT
No existe tal directorio.
ENOTDIR
El descriptor de archivo no se refiere a un directorio.

ESTÁNDARES

Ninguno.

HISTORIA

SVr4.

getdents64()
glibc 2.30.

NOTAS

glibc no proporciona un envoltorio para getdents(); llama a getdents() usando syscall(2). En ese caso, necesitarás definir tú mismo la estructura linux_dirent o linux_dirent64.

Probablemente, quieras usar readdir(3) en lugar de estas llamadas al sistema.

Estas llamadas sustituyen a readdir(2).

EJEMPLOS

El siguiente programa demuestra el uso de getdents(). La siguiente salida muestra un ejemplo de lo que vemos al ejecutar este programa en un directorio ext2:


$ ./a.out /testfs/
--------------- nread=120 ---------------
nodo    tipo de archivo    d_reclen  d_off   d_name
       2  directorio    16         12  .
       2  directorio    16         24  ..
      11  directorio    24         44  lost+found
      12  regular      16         56  a
  228929  directorio    16         68  sub
   16353  directorio    16         80  sub2
  130817  directorio    16       4096  sub3

Fuente del programa

#define _GNU_SOURCE
#include <dirent.h>     /* Define las constantes DT_* */
#include <err.h>
#include <fcntl.h>
#include <stdint.h>
#include <stdio.h>
#include <stdlib.h>
#include <sys/syscall.h>
#include <sys/types.h>
#include <unistd.h>
struct linux_dirent {
    unsigned long  d_ino;
    off_t          d_off;
    unsigned short d_reclen;
    char           d_name[];
};
#define BUF_SIZE 1024
int
main(int argc, char *argv[])
{
    int                  fd;
    char                 d_type;
    char                 buf[BUF_SIZE];
    long                 nread;
    struct linux_dirent  *d;
    fd = open(argc >
1 ? argv[1] : ".", O_RDONLY | O_DIRECTORY); if (fd == -1) err(EXIT_FAILURE, "open"); for (;;) { nread = syscall(SYS_getdents, fd, buf, BUF_SIZE); if (nread == -1) err(EXIT_FAILURE, "getdents"); if (nread == 0) break; printf("--------------- nread=%ld ---------------\n", nread); printf("inode# file type d_reclen d_off d_name\n"); for (size_t bpos = 0; bpos < nread;) { d = (struct linux_dirent *) (buf + bpos); printf("%8lu ", d->d_ino); d_type = *(buf + bpos + d->d_reclen - 1); printf("%-10s ", (d_type == DT_REG) ? "regular" : (d_type == DT_DIR) ? "directory" : (d_type == DT_FIFO) ? "FIFO" : (d_type == DT_SOCK) ? "socket" : (d_type == DT_LNK) ? "symlink" : (d_type == DT_BLK) ? "block dev" : (d_type == DT_CHR) ? "char dev" : "???"); printf("%4d %10jd %s\n", d->d_reclen, (intmax_t) d->d_off, d->d_name); bpos += d->d_reclen; } } exit(EXIT_SUCCESS); }
