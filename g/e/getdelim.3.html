getline(3) Manual de funciones de la biblioteca getline(3)

NOMBRE

getline, getdelim - entrada de cadena delimitada

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <stdio.h>
ssize_t getline(char **restrict lineptr, size_t *restrict n,
                FILE *restrict stream);
ssize_t getdelim(char **restrict lineptr, size_t *restrict n,
                int delim, FILE *restrict stream);
Requisitos de las macros de prueba de características para glibc (ver feature_test_macros(7)):

getline(), getdelim():

    Desde glibc 2.10:
        _POSIX_C_SOURCE >= 200809L
    Antes de glibc 2.10:
        _GNU_SOURCE

DESCRIPCIÓN

getline() lee una línea completa de stream, almacenando la dirección del búfer que contiene el texto en *lineptr. El búfer se termina con nulo e incluye el carácter de nueva línea, si se encontró uno.

Si *lineptr se establece en NULL antes de la llamada, getline() asignará un búfer para almacenar la línea. Este búfer debe ser liberado por el programa de usuario incluso si getline() falló.

Alternativamente, antes de llamar a getline(), *lineptr puede contener un puntero a un búfer asignado con malloc(3) de *n bytes de tamaño. Si el búfer no es lo suficientemente grande para contener la línea, getline() lo redimensiona con realloc(3), actualizando *lineptr y *n según sea necesario.

En cualquier caso, en una llamada exitosa, *lineptr y *n se actualizarán para reflejar la dirección del búfer y el tamaño asignado respectivamente.

getdelim() funciona como getline(), excepto que se puede especificar un delimitador de línea diferente a la nueva línea como argumento delim. Al igual que con getline(), no se agregará un carácter delimitador si no estaba presente en la entrada antes de llegar al final del archivo.

VALOR DE RETORNO

En caso de éxito, getline() y getdelim() devuelven el número de caracteres leídos, incluido el carácter delimitador, pero sin incluir el byte nulo de terminación ('\0'). Este valor se puede usar para manejar bytes nulos incrustados en la línea leída.

Al final del archivo, ambas funciones devuelven -1 con el indicador de fin de archivo del flujo del archivo establecido. En caso de error, ambas funciones devuelven -1 con el indicador de error del flujo del archivo establecido, y errno se establece para indicar el error.

Si *lineptr se estableció en NULL antes de la llamada, el búfer debe ser liberado por el programa de usuario incluso en caso de fallo.

ERRORES

EINVAL
Argumentos incorrectos (n o lineptr es NULL, o stream no es válido).
ENOMEM
Falló la asignación o reasignación del búfer de línea.

EJEMPLOS

#define _GNU_SOURCE
#include <stdio.h>
#include <stdlib.h>
int
main(int argc, char *argv[])
{
    FILE *stream;
    char *line = NULL;
    size_t size = 0;
    ssize_t nread;
    if (argc != 2) {
        fprintf(stderr, "Uso: %s <archivo>\n", argv[0]);
        exit(EXIT_FAILURE);
    }
    stream = fopen(argv[1], "r");
    if (stream == NULL) {
        perror("fopen");
        exit(EXIT_FAILURE);
    }
    while ((nread = getline(&line, &size, stream)) != -1) {
        printf("Línea recuperada de longitud %zd:\n", nread);
        fwrite(line, nread, 1, stdout);
    }
    free(line);
    fclose(stream);
    exit(EXIT_SUCCESS);
}
