NOMBRE

gettext, dgettext, dcgettext - traducir mensaje

SINOPSIS

#include <libintl.h>

char * gettext (const char * msgid);
char * dgettext (const char * domainname, const char * msgid);
char * dcgettext (const char * domainname, const char * msgid,
                  int category);

DESCRIPCIÓN

Las funciones gettext, dgettext y dcgettext intentan traducir una cadena de texto al idioma nativo del usuario, buscando la traducción en un catálogo de mensajes.

El argumento msgid identifica el mensaje a traducir. Por convención, es la versión en inglés del mensaje, con los caracteres no ASCII reemplazados por aproximaciones ASCII. Esta elección permite a los traductores trabajar con catálogos de mensajes, llamados archivos PO, que contienen tanto la versión en inglés como la traducida de cada mensaje, y pueden ser instalados usando la utilidad msgfmt.

Un dominio de mensajes es un conjunto de msgids traducibles. Generalmente, cada paquete de software tiene su propio dominio de mensajes. El nombre del dominio se utiliza para determinar el catálogo de mensajes donde se busca la traducción; debe ser una cadena no vacía. Para la función gettext, se especifica mediante una llamada previa a textdomain. Para las funciones dgettext y dcgettext, se pasa como el argumento domainname; si este argumento es NULL, en su lugar se utiliza el nombre de dominio especificado mediante una llamada previa a textdomain.

La búsqueda de mensajes opera en el contexto de la configuración regional (locale) actual. Para las funciones gettext y dgettext, se utiliza la faceta LC_MESSAGES de la configuración regional. Se determina mediante una llamada previa a la función setlocale. setlocale (LC_ALL, "") inicializa la configuración regional de LC_MESSAGES basándose en el primer valor no vacío de las tres variables de entorno LC_ALL, LC_MESSAGES, LANG; véase setlocale(3). Para la función dcgettext, la faceta de configuración regional se determina por el argumento category, que debe ser una de las constantes LC_xxx definidas en la cabecera <locale.h>, excluyendo LC_ALL. En ambos casos, las funciones también utilizan la faceta de configuración regional LC_CTYPE para convertir el mensaje traducido del conjunto de códigos del traductor al conjunto de códigos de la configuración regional actual, a menos que se anule por una llamada previa a la función bind_textdomain_codeset.

El catálogo de mensajes utilizado por las funciones se encuentra en la ruta dirname/locale/category/domainname.mo. Aquí dirname es el directorio especificado mediante bindtextdomain. Su valor predeterminado depende del sistema y la configuración; típicamente es prefix/share/locale, donde prefix es el prefijo de instalación del paquete. locale es el nombre de la faceta de configuración regional actual; la implementación GNU también intenta generalizaciones, como el nombre del idioma sin el nombre del territorio. category es LC_MESSAGES para las funciones gettext y dgettext, o el argumento pasado a la función dcgettext.

Si la variable de entorno LANGUAGE se establece a un valor no vacío, y la configuración regional no es la configuración regional "C", se asume que el valor de LANGUAGE contiene una lista de nombres de configuraciones regionales separadas por dos puntos. Las funciones intentarán buscar una traducción de msgid en cada una de las configuraciones regionales en orden. Esta es una extensión de GNU.

En la configuración regional "C", o si ninguno de los catálogos utilizados contiene una traducción para msgid, las funciones gettext, dgettext y dcgettext devuelven msgid.

VALOR DE RETORNO

Si se encontró una traducción en uno de los catálogos especificados, se convierte al conjunto de códigos de la configuración regional y se devuelve. La cadena resultante se asigna estáticamente y no debe ser modificada ni liberada. De lo contrario, se devuelve msgid.

ERRORES

errno no se modifica.

ERRORES CONOCIDOS

El tipo de retorno debería ser const char *, pero es char * para evitar advertencias en código C anterior a ANSI C.

Cuando se utiliza una cadena vacía para msgid, las funciones pueden devolver una cadena no vacía.
