subrutina cgeqrt (integer m, integer n, integer nb, complex, dimension( lda, * ) a, integer lda, complex, dimension( ldt, * ) t, integer ldt, complex, dimension( * ) work, integer info)

CGEQRT

Propósito:

!>
!> CGEQRT calcula una factorización QR bloqueada de una matriz compleja M por N A
!> utilizando la representación compacta WY de Q.
!>

Parámetros

M 
!>          M es ENTERO
!>          El número de filas de la matriz A.  M >= 0.
!>

N

!>          N es ENTERO
!>          El número de columnas de la matriz A.  N >= 0.
!>

NB

!>          NB es ENTERO
!>          El tamaño del bloque a utilizar en la QR bloqueada.  MIN(M,N) >= NB >= 1.
!>

A

!>          A es un array COMPLEJO, de dimensión (LDA,N)
!>          En la entrada, la matriz M por N A.
!>          En la salida, los elementos en y sobre la diagonal del array
!>          contienen la matriz trapezoidal superior min(M,N)-por-N R (R es
!>          triangular superior si M >= N); los elementos debajo de la diagonal
!>          son las columnas de V.
!>

LDA

!>          LDA es ENTERO
!>          La dimensión principal del array A.  LDA >= max(1,M).
!>

T

!>          T es un array COMPLEJO, de dimensión (LDT,MIN(M,N))
!>          Los reflectores de bloque triangulares superiores almacenados en forma compacta
!>          como una secuencia de bloques triangulares superiores.  Ver abajo
!>          para más detalles.
!>

LDT

!>          LDT es ENTERO
!>          La dimensión principal del array T.  LDT >= NB.
!>

WORK

!>          WORK es un array COMPLEJO, de dimensión (NB*N)
!>

INFO

!>          INFO es ENTERO
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tuvo un valor ilegal
!>

Más Detalles:

!>
!>  La matriz V almacena los reflectores elementales H(i) en la i-ésima columna
!>  debajo de la diagonal. Por ejemplo, si M=5 y N=3, la matriz V es
!>
!>               V = (  1       )
!>                   ( v1  1    )
!>                   ( v1 v2  1 )
!>                   ( v1 v2 v3 )
!>                   ( v1 v2 v3 )
!>
!>  donde los vi's representan los vectores que definen H(i), los cuales son devueltos
!>  en la matriz A. Los 1's a lo largo de la diagonal de V no se almacenan en A.
!>
!>  Sea K=MIN(M,N). El número de bloques es B = techo(K/NB), donde cada
!>  bloque es de orden NB excepto el último bloque, que es de orden
!>  IB = K - (B-1)*NB. Para cada uno de los B bloques, se calcula un factor
!>  reflector de bloque triangular superior: T1, T2, ..., TB. Los T de NBxNB
!>  (y IBxIB para el último bloque) se almacenan en la matriz T de NBxK como
!>
!>               T = (T1 T2 ... TB).
!>
