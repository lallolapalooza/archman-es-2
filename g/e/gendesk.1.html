NOMBRE

gendesk - genera archivos .desktop basados en argumentos de línea de comandos (o un archivo PKGBUILD)

SINOPSIS

gendesk [banderas o archivo PKGBUILD]

DESCRIPCIÓN

Variables de PKGBUILD admitidas que se incluirán en el archivo generado:

_name

_genericname

_comment

_mimetype

_exec

_categories

Gendesk intentará encontrar el icono correcto de la Biblioteca de Iconos Abierta o, de lo contrario, recurrirá al icono predeterminado.

La categoría de aplicación correcta se adivinará si no se proporciona. Variables de entorno admitidas:

pkgname

pkgdesc

EJEMPLOS

gendesk
Sale con código de error 1 si no se encuentra ../PKGBUILD y no se proporciona pkgname y $pkgname no está definido. Intentará usar tanto $pkgname como $pkgdesc.

gendesk PKGBUILD
Busca un PKGBUILD en el directorio actual y genera un archivo .desktop.

gendesk --pkgname test --pkgdesc test
Genera un archivo .desktop para el nombre "test" con la descripción "test".

gendesk /home/user/archpackages/mypackage/PKGBUILD
Genera un archivo .desktop desde el PKGBUILD dado.

Se debe proporcionar un nombre de paquete, ya sea especificando un archivo PKGBUILD, usando --pkgname o definiendo una variable de entorno $pkgname.

Tenga en cuenta que se ignorará un sufijo "-bin", "-git", "-hg" o "-svn" en un nombre de paquete, si está presente.

OPCIONES

--version
muestra la información de la versión actual
-h o --help
muestra información de uso breve
-n
no intentes descargar un icono, si falta
--nocolor
no uses texto a color
-q
silencioso; no emitas texto
-f
forzar; sobrescribe archivos si es necesario
-wm
genera un archivo .desktop pequeño para lanzar un gestor de ventanas en su lugar
--pkgname
usa este nombre de paquete para la aplicación (ej. emacs)
--pkgdesc
usa esta descripción del paquete para describir la aplicación e intenta encontrar una categoría adecuada
--name
usa este nombre para el acceso directo del escritorio (ej. Emacs)
--genericname
usa este nombre genérico para el acceso directo del escritorio (ej. Editor de Texto)
--comment
usa este comentario para el acceso directo del escritorio (ej. Usa esto para editar archivos)
--exec
especifica un ejecutable alternativo (ej. /usr/bin/emacs)
--path
especifica una ruta de inicio para el programa (ej. /usr/share/kotlin)
--icon
especifica un nombre de archivo de icono (el predeterminado es el nombre del paquete)
--categories
especifica categorías (ej. Utility;TextEditor;)
--terminal
especifica si la aplicación debe ejecutarse en una terminal (el valor predeterminado es falso)
--mimetypes
especifica tipos mime
--startupnotify
especifica si debe ocurrir una notificación de escritorio cuando la aplicación se inicie (el valor predeterminado es falso)
--custom
especifica una línea adicional (o varias líneas) para agregar al final

POR QUÉ

Tiene como objetivo facilitar a los mantenedores de paquetes la adición de entradas de menú para las aplicaciones que empaquetan, sin incluir nada que no haya sido proporcionado por el upstream en el propio paquete.

ERRORES

Solo errores desconocidos hasta ahora. Los errores se pueden informar en https://github.com/xyproto/gendesk/issues.
