DESCRIPCIÓ

N

getrusage() devuelve medidas de uso de recursos para who, que puede ser uno de los

siguientes:
RUSAGE_SE
LF
Devuelve estadísticas de uso de recursos para el proceso que llama, que es la suma de los recursos utilizados por todos los hilos en el
proceso.
RUSAGE_CHILD
REN
Devuelve estadísticas de uso de recursos para todos los hijos del proceso que llama que han terminado y por los que se ha esperado. Estas estadísticas incluirán los recursos utilizados por los nietos, y descendientes más alejados, si todos los descendientes intermedios esperaron por sus hijos
terminados.
RUSAGE_THREAD (desde Linux 2.6.
26)
Devuelve estadísticas de uso de recursos para el hilo que llama. La macro de prueba de características _GNU_SOURCE debe estar definida (antes de incluir cualquier archivo de cabecera) para obtener la definición de esta constante desde <sys/res
ource
.h>.

Los usos de recursos se devuelven en la estructura apuntada por usage, que tiene la siguiente

forma: 


struct rusage {
    struct timeval ru_utime; /* tiempo de CPU de usuario usado */
    struct timeval ru_stime; /* tiempo de CPU de sistema usado */
    long   ru_maxrss;        /* tamaño máximo del conjunto residente */
    long   ru_ixrss;         /* tamaño integral de memoria compartida */
    long   ru_idrss;         /* tamaño integral de datos no compartidos */
    long   ru_isrss;         /* tamaño integral de pila no compartida */
    long   ru_minflt;        /* recuperaciones de página (fallos de página suaves) */
    long   ru_majflt;        /* fallos de página (fallos de página duros) */
    long   ru_nswap;         /* intercambios */
    long   ru_inblock;       /* operaciones de entrada de bloque */
    long   ru_oublock;       /* operaciones de salida de bloque */
    long   ru_msgsnd;        /* mensajes IPC enviados */
    long   ru_msgrcv;        /* mensajes IPC recibidos */
    long   ru_nsignals;      /* señales recibidas */
    long   ru_nvcsw;         /* cambios de contexto voluntarios */
    long   ru_nivcsw;        /* cambios de contexto involuntarios */
}
;

No todos los campos se completan; los campos no mantenidos se establecen a cero por el kernel. (Los campos no mantenidos se proporcionan por compatibilidad con otros sistemas, y porque algún día podrían ser soportados en Linux.) Los campos se interpretan de la siguiente

manera:

me

.
ru_sti
me
Este es el tiempo total dedicado a la ejecución en modo kernel, expresado en una estructura timeval (segundos más microsegundos)

32)

procesos.

HISTORI

A

POSIX.1-2001, SVr4, 4.

3BSD.

Antes de Linux 2.6.9, si la disposición de SIGCHLD estaba establecida a SIG_IGN, entonces los usos de recursos de los procesos hijos se incluían automáticamente en el valor devuelto por RUSAGE_CHILDREN, aunque POSIX.1-2001 prohíbe explícitamente esto. Esta no conformidad se corrigió en Linux 2.6.9 y

posteriores.

La definición de estructura mostrada al principio de esta página se tomó de 4.3BSD

Reno.

Los sistemas antiguos proporcionaban una función vtimes() con un propósito similar a getrusage(). Por compatibilidad hacia atrás, glibc (hasta Linux 2.32) también proporciona vtimes(). Todas las nuevas aplicaciones deberían escribirse usando getrusage(). (Desde Linux 2.33, glibc ya no proporciona una implementación de vtimes()

.
)
