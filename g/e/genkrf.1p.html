NOMBRE

genkrf - Genera un archivo keyrec a partir de archivos de Clave de Firma de Zona (KSK) y/o Clave de Firma de Zona (ZSK)

SINOPSIS

genkrf [opciones] <archivo-zona> [<archivo-zona-firmado>]

DESCRIPCIÓN

genkrf genera un archivo keyrec a partir de archivos KSK y/o ZSK. Genera nuevas claves KSK y ZSK si es necesario.

El nombre del archivo keyrec a generar lo proporciona la opción -krfile . Si no se especifica esta opción, zone-name.krf se usa como nombre del archivo keyrec. Si el archivo keyrec ya existe, se sobrescribirá con nuevas definiciones keyrec.

El argumento archivo-zona es obligatorio. Especifica el nombre del archivo de zona a partir del cual se creó el archivo de zona firmado. El argumento opcional archivo-zona-firmado especifica el nombre del archivo de zona firmado. Si no se proporciona, por defecto será archivo-zona.signed. El campo de archivo de zona firmado es, en la práctica, un campo ficticio ya que la zona no está realmente firmada.

OPCIONES

genkrf tiene varias opciones que ayudan en la creación del archivo keyrec . Estas opciones se establecerán con el primer valor encontrado en esta ruta de búsqueda:

opciones de la línea de comandos
archivo de configuración de DNSSEC-Tools
valores predeterminados de DNSSEC-Tools

Consulte tooloptions.pm(3) para más detalles. Las excepciones a esto se indican en las descripciones de las opciones.

Las opciones de genkrf se describen a continuación.

Opciones genkrf generales

-zone nombre-zona
Esta opción especifica el nombre de la zona. Si no se proporciona, se usará archivo-zona como nombre de la zona.
-krfile archivo-keyrec
Esta opción especifica el nombre del archivo keyrec a generar. Si no se proporciona, se usará nombre-zona.krf .
-algorithm algoritmo
Esta opción especifica el algoritmo utilizado para generar las claves de cifrado.
-endtime hora-fin
Esta opción especifica el momento en que expira la firma de la zona, medido en segundos.
-random dispositivo-aleatorio
Fuente de aleatoriedad utilizada para generar las claves de la zona. Consulte la página del manual de dnssec-signzone para conocer el formato válido de este campo.
-verbose
Muestra mensajes adicionales durante el procesamiento. Si se proporciona esta opción al menos una vez, se mostrará un mensaje indicando la generación exitosa del archivo keyrec. Si se proporciona dos veces, también se mostrarán los valores de todas las opciones.
-Version
Muestra la información de versión de genkrf y del paquete DNSSEC-Tools.
-help
Muestra un mensaje de uso.

Opciones relacionadas con KSK

-kskcur nombre-KSK
Esta opción especifica el archivo de clave de la KSK actual que se utiliza para firmar la zona. Si no se proporciona esta opción, se creará una nueva KSK.
-kskcount cantidad-KSK
Esta opción especifica el número de claves KSK que se generarán. Si no se proporciona esta opción, se usará el valor predeterminado dado en el archivo de configuración de DNSSEC-Tools.
-kskdir directorio-KSK
Esta opción especifica la ruta absoluta o relativa del directorio donde reside la KSK. Si no se proporciona esta opción, por defecto será el directorio actual ".".
-ksklength longitud-KSK
Esta opción especifica la longitud de la clave de cifrado KSK.
-ksklife duración-KSK
Esta opción especifica la duración de la clave de cifrado KSK. Esta duración no es inherente a la clave misma. Se usa únicamente para determinar cuándo se debe renovar la KSK.

Opciones relacionadas con ZSK

-zskcur nombre-ZSK
Esta opción especifica la ZSK actual que se utiliza para firmar la zona. Si no se proporciona esta opción, se creará una nueva ZSK.
-zskpub nombre-ZSK
Esta opción especifica la ZSK publicada para la zona. Si no se proporciona esta opción, se creará una nueva ZSK.
-zskcount cantidad-ZSK
Esta opción especifica el número de claves ZSK actuales y publicadas que se generarán. Si no se proporciona esta opción, se usará el valor predeterminado dado en el archivo de configuración de DNSSEC-Tools.
-zskdir directorio-ZSK
Esta opción especifica la ruta absoluta o relativa del directorio donde residen las ZSK. Si no se proporciona esta opción, por defecto será el directorio actual ".".
-zsklength longitud-ZSK
Esta opción especifica la longitud de la clave de cifrado ZSK.
-zsklife duración-ZSK
Esta opción especifica la duración de la clave de cifrado ZSK. Esta duración no es inherente a la clave misma. Se usa únicamente para determinar cuándo se debe renovar la ZSK.
