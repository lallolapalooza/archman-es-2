gearman_client_free(3)

Paquete: gearmand

Licencias: BSD-3-Clause

GEARMAN_CLIENT_FREE(3) Gearmand GEARMAN_CLIENT_FREE(3)

NOMBRE

gearman_client_free - Documentación de Gearmand, https://gearman.org/gearmand/

SINOPSIS

#include <libgearman/gearman.h>

gearman_client_st *gearman_client_create(gearman_client_st *client)
gearman_client_st *gearman_client_clone(gearman_client_st *client, const gearman_client_st *from)
void gearman_client_free(gearman_client_st *client)

Enlazar con -lgearman

DESCRIPCIÓN

gearman_client_create() se utiliza para crear una estructura c:type:gearman_client_st que se utilizará luego en otras funciones cliente de libgearman para comunicarse con el servidor. Debe pasar una gearman_client_st declarada estáticamente a gearman_client_create() o un NULL. Si se pasa NULL, la estructura se asignará para usted.

gearman_client_clone() es similar a gearman_client_create() pero copia los valores predeterminados y la lista de servidores de la gearman_client_st de origen. Si pasa un NULL como argumento de origen para clonar, es lo mismo que una llamada a gearman_client_create. Si el argumento de destino es NULL, se asignará una gearman_client_st para usted.

Para limpiar la memoria asociada con una estructura gearman_client_st, debe pasarla a gearman_client_free cuando haya terminado de usarla. gearman_client_free() es la única forma de asegurarse de que se desasigna toda la memoria cuando termine de usar la estructura.

ADVERTENCIA:

Es posible que desee evitar el uso de gearman_client_create() o gearman_client_clone() con una asignación basada en pila, es decir, el primer parámetro. Los problemas más comunes relacionados con la seguridad de la ABI implican estructuras asignadas en la pila.

VALOR DE RETORNO

gearman_client_create devuelve un puntero a la gearman_client_st que se creó (o inicializó). En caso de error de asignación, devuelve NULL.

gearman_client_clone devuelve un puntero a la gearman_client_st que se creó (o inicializó). En caso de error de asignación, devuelve NULL.

INICIO
