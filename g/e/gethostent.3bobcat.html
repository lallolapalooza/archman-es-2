DESCRIPCIÓ

N

Los objetos FBB::GetHostent producen structs hostent que pueden ser utilizados por otros tipos de objetos. La clase FBB::GetHostent se utiliza por lo tanto principalmente como clase base para otras clases y rara vez se usa de forma independiente. Los structs hostent son structs estáticos, pero se puede obtener una copia no estática utilizando un objeto FBB::Host

ent.

Un struct hostent se define de la siguiente

manera: 
    struct hostent
    {
        char    *h_name;        // nombre oficial del host
        char    **h_aliases;    // lista de alias
        int     h_addrtype;     // tipo de dirección del host (siempre AF_INET)
        int     h_length;       // longitud de la dirección
        char    **h_addr_list;  // lista de direcciones
    }
Los campos de dirección son valores binarios de las direcciones, cada dirección requiere h_length bytes, siendo la última dirección igual a 0. Estos valores binarios pueden convertirse a representaciones de caracteres mediante el miembro addressToString(), que utiliza inet_ntop()
internamente.

Todos los miembros de la clase FBB::GetHostent son estáticos. En consecuencia, no es necesario construir un objeto FBB::Get

Host

MIEMBROS

ESTÁTICOS
o
hostent const *gethostent(char const *errorprefix, std::string const &nameOrAddress):
El miembro gethostent() devuelve un puntero a un struct estático hostent. Contiene la información sobre el host cuyo nombre o dirección decimal con puntos se proporcionó como su segundo argumento. Su primer argumento es una cadena de prefijo de error, que precede al mensaje de error en un objeto FBB::Exception. Dicho objeto se lanza como excepción cuando no se pudo recuperar la información del
host.
o
std::string addressToString(char const *errorprefix, void const *ads):
Este miembro devuelve la dirección decimal con puntos del host cuya dirección binaria se proporciona en ads. Su primer argumento es una cadena de prefijo de error, que precede al mensaje de error en un objeto FBB::Exception. Dicho objeto se lanza como excepción cuando no se pudo determinar la dirección decimal con
puntos.
Los miembros de la clase solo pueden usarse cuando el host cuyo nombre o dirección se busca puede ser resuelto por un proceso de resolución de nombres, por ejemplo, bin
d(
1
).

EJEMPL

O 
    #include <iostream>
    #include <algorithm>
    #include <iterator>
    #include <bobcat/hostent>
    #include <bobcat/gethostent>
    using namespace std;
    using namespace FBB;
    int main(int argc, char **argv)
    try
    {
        if (argc == 1)
        {
            cerr << "Proporcione un nombre de host o una dirección de host para resolver\n";
            return 1;
        }
        Hostent he(GetHostent::gethostent(argv[1], argv[1]));
        cout << "Nombre de host: " << he.hostname() << endl;
        cout << "Alias:\n";
        copy(he.beginAlias(), he.endAlias(),
                ostream_iterator<char const *>(cout, "\n"));
        cout << "Direcciones:\n";
        for (size_t idx = 0; idx < he.nAddresses(); idx++)
            cout << he.dottedDecimalAddress(idx) << endl;
    }
    catch (Exception const &err)
    {
        cout << err.what() << endl;
        return 1;
}
