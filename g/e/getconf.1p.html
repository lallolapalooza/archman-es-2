GETCONF(1P) Manual del Programador POSIX GETCONF(1P)

PRÓLOGO

Esta página del manual forma parte del Manual del Programador POSIX. La implementación de Linux de esta interfaz puede diferir (consulte la página del manual de Linux correspondiente para detalles del comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

getconf — obtener valores de configuración

SINOPSIS

getconf [-v especificación] variable_del_sistema
getconf [-v especificación] variable_de_ruta ruta_de_acceso

DESCRIPCIÓN

En la primera forma de sinopsis, la utilidad getconf escribirá en la salida estándar el valor de la variable especificada por el operando variable_del_sistema .

En la segunda forma de sinopsis, la utilidad getconf escribirá en la salida estándar el valor de la variable especificada por el operando variable_de_ruta para la ruta especificada por el operando ruta_de_acceso .

El valor de cada variable de configuración se determinará como si se hubiera obtenido llamando a la función de la que se define que está disponible por este volumen de POSIX.1‐2017 o por el volumen de Interfaces del Sistema de POSIX.1‐2017 (vea la sección OPERANDOS). El valor reflejará las condiciones en el entorno operativo actual.

OPCIONES

La utilidad getconf deberá cumplir con el volumen de Definiciones Base de POSIX.1‐2017, Sección 12.2, Directrices de Sintaxis de Utilidades.

Se deberá soportar la siguiente opción:

-vespecificación

Indicar una especificación y versión específicas para las cuales se determinarán las variables de configuración. Si no se especifica esta opción, los valores devueltos corresponden a un entorno de compilación conforme predeterminado de la implementación.

Si el comando:

getconf _POSIX_V7_ILP32_OFF32

no escribe "-1\n" o "undefined\n" en la salida estándar, entonces los comandos de la forma:

getconf -v POSIX_V7_ILP32_OFF32 ...

determinan valores para las variables de configuración correspondientes al entorno de compilación POSIX_V7_ILP32_OFF32 especificado en c99, la DESCRIPCIÓN EXTENDIDA.

Si el comando:

getconf _POSIX_V7_ILP32_OFFBIG

no escribe "-1\n" o "undefined\n" en la salida estándar, entonces los comandos de la forma:

getconf -v POSIX_V7_ILP32_OFFBIG ...

determinan valores para las variables de configuración correspondientes al entorno de compilación POSIX_V7_ILP32_OFFBIG especificado en c99, la DESCRIPCIÓN EXTENDIDA.

Si el comando:

getconf _POSIX_V7_LP64_OFF64

no escribe "-1\n" o "undefined\n" en la salida estándar, entonces los comandos de la forma:

getconf -v POSIX_V7_LP64_OFF64 ...

determinan valores para las variables de configuración correspondientes al entorno de compilación POSIX_V7_LP64_OFF64 especificado en c99, la DESCRIPCIÓN EXTENDIDA.

Si el comando:

getconf _POSIX_V7_LPBIG_OFFBIG

no escribe "-1\n" o "undefined\n" en la salida estándar, entonces los comandos de la forma:

getconf -v POSIX_V7_LPBIG_OFFBIG ...

determinan valores para las variables de configuración correspondientes al entorno de compilación POSIX_V7_LPBIG_OFFBIG especificado en c99, la DESCRIPCIÓN EXTENDIDA.

OPERANDOS

Se deberán soportar los siguientes operandos:

variable_de_ruta
Un nombre de una variable de configuración. Se deberán soportar todas las variables en la columna Variable de la tabla en la DESCRIPCIÓN de la función fpathconf() definida en el volumen de Interfaces del Sistema de POSIX.1‐2017, sin las llaves que las rodean. La implementación puede añadir otras variables locales.
ruta_de_acceso
Una ruta de acceso para la cual se determinará la variable especificada por variable_de_ruta .
variable_del_sistema
Un nombre de una variable de configuración. Se deberán soportar todas las siguientes variables:
*
Los nombres en la columna Variable de la tabla en la DESCRIPCIÓN de la función sysconf() en el volumen de Interfaces del Sistema de POSIX.1‐2017, excepto para las entradas correspondientes a _SC_CLK_TCK, _SC_GETGR_R_SIZE_MAX y _SC_GETPW_R_SIZE_MAX, sin las llaves que las rodean.

Por compatibilidad con versiones anteriores, también se deberán soportar los siguientes nombres de variables: POSIX2_C_BIND POSIX2_C_DEV POSIX2_CHAR_TERM POSIX2_FORT_DEV POSIX2_FORT_RUN POSIX2_LOCALEDEF POSIX2_SW_DEV POSIX2_UPE POSIX2_VERSION

y serán equivalentes al mismo nombre con un <guion_bajo> como prefijo. Este requisito puede eliminarse en una versión futura.

*
Los nombres de las constantes simbólicas usadas como argumento nombre de la función confstr() en el volumen de Interfaces del Sistema de POSIX.1‐2017, sin el prefijo _CS_.
*
Los nombres de las constantes simbólicas listadas bajo los encabezados «Valores Máximos» y «Valores Mínimos» en la descripción del encabezado <limits.h> en el volumen de Definiciones Base de POSIX.1‐2017, sin las llaves que las rodean.

Por compatibilidad con versiones anteriores, también se deberán soportar los siguientes nombres de variables: POSIX2_BC_BASE_MAX POSIX2_BC_DIM_MAX POSIX2_BC_SCALE_MAX POSIX2_BC_STRING_MAX POSIX2_COLL_WEIGHTS_MAX POSIX2_EXPR_NEST_MAX POSIX2_LINE_MAX POSIX2_RE_DUP_MAX

y serán equivalentes al mismo nombre con un <guion_bajo> como prefijo. Este requisito puede eliminarse en una versión futura.

La implementación puede añadir otros valores locales.

STDIN

No se usa.

ARCHIVOS DE ENTRADA

VARIABLES DE ENTORNO

Las siguientes variables de entorno afectarán la ejecución de getconf:

LANG
Proporcionar un valor predeterminado para las variables de internacionalización que no están establecidas o son nulas. (Vea el volumen de Definiciones Base de POSIX.1‐2017, Sección 8.2, Variables de Internacionalización para la precedencia de las variables de internacionalización usadas para determinar los valores de las categorías de configuración regional.)
LC_ALL
Si se establece en un valor de cadena no vacío, anula los valores de todas las demás variables de internacionalización.
LC_CTYPE
Determinar la configuración regional para la interpretación de secuencias de bytes de datos de texto como caracteres (por ejemplo, caracteres de un solo byte en oposición a multibyte en los argumentos).
LC_MESSAGES

Determinar la configuración regional que debe usarse para afectar el formato y el contenido de los mensajes de diagnóstico escritos en la salida de error estándar.
NLSPATH
Determinar la ubicación de los catálogos de mensajes para el procesamiento de LC_MESSAGES.
