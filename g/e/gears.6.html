NOMBRE

gears - dibuja engranajes entrelazados, para xscreensaver.

SINOPSIS

gears [--display host:display.screen] [--window] [--root] [--window-id número][--install] [--visual visual] [--delay usecs] [--speed float] [--no-spin] [--no-wander] [-count entero] [-wireframe] [-fps]

DESCRIPCIÓN

Esto dibuja un conjunto de engranajes giratorios.

OPCIONES

gears acepta las siguientes opciones:

--window
Dibuja en una ventana recién creada. Esta es la opción predeterminada.
--root
Dibuja en la ventana raíz.
--window-id número
Dibuja en la ventana especificada.
--install
Instala un mapa de colores privado para la ventana.
--visual visual
Especifica qué visual usar. Los valores válidos son el nombre de una clase visual, o el ID (decimal o hexadecimal) de un visual específico.
--delay usecs
El retraso entre fotogramas de la animación, en microsegundos. Predeterminado: 30000 (0.03 segundos).
--speed float
Números más grandes significan una ejecución más rápida. Predeterminado: 1.0.
--no-spin
No girar el objeto.
--no-wander
No hacer que el objeto se mueva por la pantalla.
--count entero
Cuántos engranajes dibujar. Predeterminado: 0 para aleatorio.
--wireframe
Renderizar en modo de alambre en lugar de sólido.
--fps
Muestra la tasa de fotogramas actual, la carga de la CPU y el número de polígonos.

AMBIENTE

DISPLAY
para obtener el host y el número de pantalla predeterminados.
XENVIRONMENT
para obtener el nombre de un archivo de recursos que anula los recursos globales almacenados en la propiedad RESOURCE_MANAGER.
XSCREENSAVER_WINDOW
El ID de ventana a usar con --root.
