CGEQRFP

Propósito:

!>
!> CGEQR2P calcula una factorización QR de una matriz compleja A de M-por-N:
!>
!>    A = Q * ( R ),
!>            ( 0 )
!>
!> donde:
!>
!>    Q es una matriz ortogonal M-por-M;
!>    R es una matriz triangular superior N-por-N con entradas diagonales
!>    no negativas;
!>    0 es una matriz cero (M-N)-por-N, si M > N.
!>
!>

Parámetros

M 
!>          M es INTEGER
!>          El número de filas de la matriz A.  M >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz A.  N >= 0.
!>

A

!>          A es un array COMPLEX, dimensión (LDA,N)
!>          En la entrada, la matriz A de M-por-N.
!>          En la salida, los elementos en y por encima de la diagonal del array
!>          contienen la matriz trapezoidal superior R de min(M,N)-por-N (R es
!>          triangular superior si m >= n). Las entradas diagonales de R
!>          son reales y no negativas; los elementos por debajo de la diagonal,
!>          junto con el array TAU, representan la matriz unitaria Q como un
!>          producto de min(m,n) reflectores elementales (ver Detalles
!>          Adicionales).
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,M).
!>

TAU

!>          TAU es un array COMPLEX, dimensión (min(M,N))
!>          Los factores escalares de los reflectores elementales (ver Detalles
!>          Adicionales).
!>

WORK

!>          WORK es un array COMPLEX, dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK.
!>          LWORK >= 1, si MIN(M,N) = 0, y LWORK >= N, en caso contrario.
!>          Para un rendimiento óptimo LWORK >= N*NB, donde NB es
!>          el tamaño de bloque óptimo.
!>
!>          Si LWORK = -1, se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo del array WORK, devuelve
!>          este valor como la primera entrada del array WORK, y XERBLA no emite
!>          ningún mensaje de error relacionado con LWORK.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>

Autor

Univ. of Tennessee

Univ. of California Berkeley

Detalles Adicionales:

!>
!>  La matriz Q se representa como un producto de reflectores elementales
!>
!>     Q = H(1) H(2) . . . H(k), donde k = min(m,n).
!>
!>  Cada H(i) tiene la forma
!>
!>     H(i) = I - tau * v * v**H
!>
!>  donde tau es un escalar complejo, y v es un vector complejo con
!>  v(1:i-1) = 0 y v(i) = 1; v(i+1:m) se almacena en la salida en A(i+1:m,i),
!>  y tau en TAU(i).
!>
!>  Ver Lapack Working Note 203 para más detalles
!>
