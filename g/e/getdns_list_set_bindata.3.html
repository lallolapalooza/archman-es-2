getdns_list_set_bindata(3)

Paquete: getdns

Licencias: BSD

getdns_list_set(3) getdns getdns_list_set(3)

NOMBRE

getdns_list_set, getdns_list_set_bindata, getdns_list_set_dict, getdns_list_set_int, getdns_list_set_list, -- establece un valor por índice desde una lista getdns

BIBLIOTECA

Biblioteca del resolvedor DNS (libgetdns, -lgetdns)

SINOPSIS

#include <getdns.h>

getdns_return_t
getdns_list_set_bindata (getdns_list *this_list,

size_t index,
getdns_bindata *child_bindata)

getdns_return_t
getdns_list_set_dict (getdns_list *this_list,

size_t index,
getdns_dict *child_dict)

getdns_return_t
getdns_list_set_int (getdns_list *this_list,

size_t index,
uint32_t child_uint32_t)

getdns_return_t
getdns_list_set_list (getdns_list *this_list,

size_t index,
getdns_list *child_list)

DESCRIPCIÓN

El tipo getdns_list se utiliza para gestionar una lista indexada heterogénea de valores que incluyen:


getdns_bindata
getdns_dict
getdns_list
uint32_t

this_list la lista en la que se va a añadir/actualizar el elemento indexado

index el índice cuyo valor asociado se va a establecer. Si el índice existe en la lista, se reemplaza el valor asociado con ese índice; si el índice no existe en la lista, se añade un nuevo elemento a la lista en el índice especificado.

child_bindata child_dict child_list child_uint32 valor a asignar al elemento indexado

VALORES DE RETORNO

Al completarse con éxito, las funciones devuelven GETDNS_RETURN_GOOD; de lo contrario, se devuelven los siguientes valores de error:

GETDNS_RETURN_NO_SUCH_LIST_ITEM si el índice está fuera de rango

GETDNS_RETURN_GENERIC_ERROR si this_list no es una lista válida
