getgid(2) Manual de llamadas al sistema getgid(2)

NOMBRE

getgid, getegid - obtener identidad de grupo

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <unistd.h>
gid_t getgid(void);
gid_t getegid(void);

DESCRIPCIÓN

getgid() devuelve el ID de grupo real del proceso que llama.

getegid() devuelve el ID de grupo efectivo del proceso que llama.

ERRORES

Estas funciones siempre tienen éxito y nunca modifican errno.

VERSIÓNES

En Alpha, en lugar de un par de llamadas al sistema getgid() y getegid(), se proporciona una única llamada al sistema getxgid(), que devuelve un par de GID reales y efectivos. Las funciones envoltorio getgid() y getegid() de glibc manejan transparente esta situación. Consulte syscall(2) para obtener detalles sobre el mapeo de registros.

ESTáNDARES

POSIX.1-2024.

HISTóRIA

POSIX.1-2001, 4.3BSD.

Las llamadas al sistema originales getgid() y getegid() de Linux admitían solo ID de grupo de 16 bits. Posteriormente, Linux 2.4 añadió getgid32() y getegid32(), que admitían ID de 32 bits. Las funciones envoltorio getgid() y getegid() de glibc manejan transparentemente las variaciones entre versiones del núcleo.

VéASE TAMBIÉN

getresgid(2), setgid(2), setregid(2), credentials(7)
