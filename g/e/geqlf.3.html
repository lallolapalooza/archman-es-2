subrutina cgeqlf (integer m, integer n, complex, dimension( lda, * ) a, integer lda, complex, dimension( * ) tau, complex, dimension( * ) work, integer lwork, integer

info)

CGEQL

F

Propósito

: 
!>
!> CGEQLF calcula una factorización QL de una matriz compleja A de M por N:
!> A = Q * L.
!
>

Parámetro

s
M 
!>          M es INTEGER
!>          El número de filas de la matriz A.  M >= 0.
!
>

N 
!>          N es INTEGER
!>          El número de columnas de la matriz A.  N >= 0.
!
>

A 
!>          A es un array COMPLEX, dimensión (LDA,N)
!>          En la entrada, la matriz A de M por N.
!>          En la salida,
!>          si m >= n, el triángulo inferior del subarray
!>          A(m-n+1:m,1:n) contiene la matriz triangular inferior L de N por N;
!>          si m <= n, los elementos en y por debajo de la (n-m)-ésima
!>          superdiagonal contienen la matriz trapezoidal inferior L de M por N;
!>          los elementos restantes, junto con el array TAU, representan la
!>          matriz unitaria Q como un producto de reflectores elementales
!>          (véase Detalles adicionales).
!
>

LD

A 
!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,M).
!
>

TA

U 
!>          TAU es un array COMPLEX, dimensión (min(M,N))
!>          Los factores escalares de los reflectores elementales (véase
!>          Detalles adicionales).
!
>

WOR

K 
!>          WORK es un array COMPLEX, dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!
>

LWOR

K 
!>          LWORK es INTEGER
!>          La dimensión del array WORK.
!>          LWORK >= 1, si MIN(M,N) = 0, y LWORK >= N, en caso contrario.
!>          Para un rendimiento óptimo LWORK >= N*NB, donde NB es
!>          el tamaño de bloque óptimo.
!>
!>          Si LWORK = -1, se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo del array WORK, devuelve
!>          este valor como la primera entrada del array WORK, y XERBLA no emite
!>          ningún mensaje de error relacionado con LWORK.
!
>

INF

O 
!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!
>

Detalles

adicionales: 
!>
!>  La matriz Q se representa como un producto de reflectores elementales
!>
!>     Q = H(k) . . . H(2) H(1), donde k = min(m,n).
!>
!>  Cada H(i) tiene la forma
!>
!>     H(i) = I - tau * v * v**H
!>
!>  donde tau es un escalar complejo, y v es un vector complejo con
!>  v(m-k+i+1:m) = 0 y v(m-k+i) = 1; v(1:m-k+i-1) se almacena en la salida en
!>  A(1:m-k+i-1,n-k+i), y tau en TAU(i).
!
>
