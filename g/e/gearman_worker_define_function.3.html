SINOPSIS

#include <libgearman/gearman.h>

tipo gearman_function_t
gearman_return_t gearman_worker_define_function(gearman_worker_st *worker, const char *function_name, const size_t function_name_length, const gearman_function_t function, const uint32_t timeout, void *context)
tipo gearman_function_fn
tipo gearman_aggregator_fn

Enlazar con -lgearman

DESCRIPCIÓN

gearman_worker_define_function() define funciones para un trabajador.

La interfaz es de tipo callback por diseño. Cuando el servidor tiene un trabajo para el trabajador, se invoca gearman_function_fn con un gearman_job_st que representa el trabajo y el contexto que se definió originalmente cuando se definió la función.

Los resultados se envían de vuelta al cliente invocando gearman_job_send_data().

Si el cliente especificó una función reductora, la salida de gearman_function_fn se enviará a esa función. Puedes dividir el trabajo a la función reductora enviando datos varias veces con gearman_job_send_data().

Si se detectan errores, todo el trabajo se cancela. La gearman_aggregator_fn se llamará cuando todos los trabajos mapeados hayan completado. El resultado de esta función será lo que se devuelva al cliente.

La función de callback debe devolver uno de los siguientes errores:

GEARMAN_SUCCESS

La función fue exitosa.

GEARMAN_FAIL

Ha ocurrido un error, el trabajo no se procesó y el trabajador no puede continuar.

GEARMAN_ERROR

Ha ocurrido un error transitorio, como una falla de red, y el trabajo puede reiniciarse.

Si se devuelve un valor distinto de los anteriores, se convierte en GEARMAN_FAIL y gearman_worker_work() devuelve GEARMAN_INVALID_ARGUMENT.

No se pueden usar gearman_job_send_complete() y gearman_job_send_fail() con ninguna función creada con gearman_worker_define_function().
