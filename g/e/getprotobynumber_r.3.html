getprotoent_r(3) Manual de Funciones de Biblioteca getprotoent_r(3)

NOMBRE

getprotoent_r, getprotobyname_r, getprotobynumber_r - obtener una entrada de protocolo (reentrante)

BIBLIOTECA

Biblioteca C estándar (libc,-lc)

SINOPSIS

#include <netdb.h>
int getprotoent_r(size_t size;
                  struct protoent *restrict result_buf,
                  char buf[restrict size], size_t size,
                  struct protoent **restrict result);
int getprotobyname_r(size_t size;
                  const char *restrict name,
                  struct protoent *restrict result_buf,
                  char buf[restrict size], size_t size,
                  struct protoent **restrict result);
int getprotobynumber_r(size_t size;
                  int proto,
                  struct protoent *restrict result_buf,
                  char buf[restrict size], size_t size,
                  struct protoent **restrict result);
Requisitos de la macro de prueba de características para glibc (ver feature_test_macros(7)):

getprotoent_r(), getprotobyname_r(), getprotobynumber_r():

    Desde glibc 2.19:
        _DEFAULT_SOURCE
    glibc 2.19 y anteriores:
        _BSD_SOURCE || _SVID_SOURCE

DESCRIPCIÓN

Las funciones getprotoent_r(), getprotobyname_r() y getprotobynumber_r() son los equivalentes reentrantes de getprotoent(3), getprotobyname(3)y getprotobynumber(3), respectivamente. Difieren en la forma en que se devuelve la estructura protoent , y en la firma de llamada y el valor de retorno de la función. Esta página del manual describe solo las diferencias con las funciones no reentrantes.

En lugar de devolver un puntero a una estructura protoent asignada estáticamente como resultado de la función, estas funciones copian la estructura en la ubicación apuntada por result_buf.

El arreglo buf se utiliza para almacenar los campos de cadena apuntados por la estructura protoent devuelta. (Las funciones no reentrantes asignan estas cadenas en almacenamiento estático.) El tamaño de este arreglo se especifica en size. Si buf es demasiado pequeño, la llamada falla con el error ERANGE, y el llamador debe intentarlo de nuevo con un búfer más grande. (Un búfer de 1024 bytes debería ser suficiente para la mayoría de las aplicaciones.)

Si la llamada a la función obtiene con éxito un registro de protocolo, entonces *result se establece apuntando a result_buf; de lo contrario, *result se establece en NULL.

VALOR DE RETORNO

En caso de éxito, estas funciones devuelven 0. En caso de error, devuelven uno de los números de error positivos listados en ERRORES.

En caso de error, registro no encontrado (getprotobyname_r(), getprotobynumber_r()), o fin de la entrada (getprotoent_r()) result se establece en NULL.

ERRORES

ENOENT
(getprotoent_r()) No hay más registros en la base de datos.
ERANGE
buf es demasiado pequeño. Inténtelo de nuevo con un búfer más grande (y con sizeincrementado).

ESTÁNDARES

GNU.

EJEMPLOS

El programa siguiente utiliza getprotobyname_r() para recuperar el registro del protocolo para el protocolo nombrado en su primer argumento de línea de comandos. Si se proporciona un segundo argumento de línea de comandos (entero), se utiliza como el valor inicial para size; si getprotobyname_r() falla con el error ERANGE, el programa reintenta con tamaños de búfer más grandes. La siguiente sesión de shell muestra un par de ejecuciones de ejemplo:


$ ./a.out tcp 1
ERANGE! Retrying with larger buffer
getprotobyname_r() returned: 0 (success)  (size=78)
p_name=tcp; p_proto=6; aliases=TCP
$ ./a.out xxx 1
ERANGE! Retrying with larger buffer
getprotobyname_r() returned: 0 (success)  (size=100)
Call failed/record not found

Código fuente del programa

#define _GNU_SOURCE
#include <ctype.h>
#include <errno.h>
#include <netdb.h>
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#define MAX_BUF 10000
int
main(int argc, char *argv[])
{
    int size, erange_cnt, s;
    struct protoent result_buf;
    struct protoent *result;
    char buf[MAX_BUF];
    if (argc < 2) {
        printf("Usage: %s proto-name [size]\n", argv[0]);
        exit(EXIT_FAILURE);
    }
    size = 1024;
    if (argc > 2)
        size = atoi(argv[2]);
    if (size > MAX_BUF) {
        printf("Exceeded buffer limit (%d)\n", MAX_BUF);
        exit(EXIT_FAILURE);
    }
    erange_cnt = 0;
    do {
        s = getprotobyname_r(argv[1], &result_buf,
                             buf, size, &result);
        if (s == ERANGE) {
            if (erange_cnt == 0)
                printf("ERANGE! Retrying with larger buffer\n");
            erange_cnt++;
            /* Increment a byte at a time so we can see exactly
               what size buffer was required.  */
            size++;
            if (size > MAX_BUF) {
                printf("Exceeded buffer limit (%d)\n", MAX_BUF);
                exit(EXIT_FAILURE);
            }
        }
    } while (s == ERANGE);
    printf("getprotobyname_r() returned: %s  (size=%d)\n",
           (s == 0) ? "0 (success)" : (s == ENOENT) ? "ENOENT" :
           strerror(s), size);
    if (s != 0 || result == NULL) {
        printf("Call failed/record not found\n");
        exit(EXIT_FAILURE);
    }
    printf("p_name=%s; p_proto=%d; aliases=",
           result_buf.p_name, result_buf.p_proto);
    for (char **p = result_buf.p_aliases; *p != NULL; p++)
        printf("%s ", *p);
    printf("\n");
    exit(EXIT_SUCCESS);
}
