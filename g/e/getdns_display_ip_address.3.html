Licencias: BSD

getdns_display_ip_address(3) getdns getdns_display_ip_address(3)

NOMBRE

getdns_display_ip_address -- convierte una dirección IP de getdns a cadena

BIBLIOTECA

Biblioteca del Resolvedor DNS (libgetdns, -lgetdns)

SINOPSIS

#include <getdns.h>

char *
getdns_display_ip_address (const getdns_bindata *ipv4_or_ipv6_addr)

DESCRIPCIÓN

Esta función auxiliar devuelve una representación de cadena con formato agradable de la dirección IPv4 o IPv6. La longitud de los bindata se utiliza para determinar si la dirección es IPv4 o IPv6.

ipv4_or_ipv6_addr bindata de la dirección a imprimir

VALORES DE RETORNO

Devuelve una representación de cadena de la dirección IP (asignada usando el asignador del sistema - malloc), el llamador es responsable de liberar el almacenamiento usando free().
