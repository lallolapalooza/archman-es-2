getenv(3) Manual de funciones de biblioteca getenv(3)

NOMBRE

getenv, secure_getenv - obtener una variable de entorno

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <stdlib.h>
char *getenv(const char *name);
char *secure_getenv(const char *name);
Requisitos de macro de prueba de características para glibc (ver feature_test_macros(7)):

secure_getenv():

    _GNU_SOURCE

DESCRIPCIÓN

La función getenv() busca en la lista de entorno la variable de entorno name y devuelve un puntero a la cadena de value correspondiente.

La función secure_getenv() es igual que getenv() excepto que devuelve NULL en casos donde se requiere "ejecución segura". La ejecución segura se requiere si una de las siguientes condiciones fue cierta cuando el programa ejecutado por el proceso en curso fue cargado:

•
el ID de usuario efectivo del proceso no coincidía con su ID de usuario real o el ID de grupo efectivo del proceso no coincidía con su ID de grupo real (típicamente esto es el resultado de ejecutar un programa set-user-ID o set-group-ID);
•
el bit de capacidad efectiva estaba establecido en el archivo ejecutable; o
•
el proceso tiene un conjunto de capacidades permitidas no vacío.

La ejecución segura también puede ser requerida si es activada por algunos módulos de seguridad de Linux.

La función secure_getenv() está destinada para su uso en bibliotecas de propósito general para evitar vulnerabilidades que podrían ocurrir si los programas set-user-ID o set-group-ID confiaran accidentalmente en el entorno.

VALOR DE RETORNO

La función getenv() devuelve un puntero al valor en el entorno, o NULL si no hay coincidencia.

NOTAS

Las cadenas en la lista de entorno son del tipo name=value.

Como se implementa típicamente, getenv() devuelve un puntero a una cadena dentro de la lista de entorno. El llamador debe tener cuidado de no modificar esta cadena, ya que eso cambiaría el entorno del proceso.

La implementación de getenv() no se requiere que sea reentrante. La cadena apuntada por el valor de retorno de getenv() puede ser asignada estáticamente y puede ser modificada por una llamada subsiguiente a getenv(), putenv(3), setenv(3), o unsetenv(3).

El modo de "ejecución segura" de secure_getenv() se controla mediante el flag AT_SECURE contenido en el vector auxiliar pasado desde el kernel al espacio de usuario.
