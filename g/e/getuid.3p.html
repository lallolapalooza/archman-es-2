GETUID(3P) Manual del programador POSIX GETUID(3P)

PROLOG

Esta página del manual forma parte del Manual del programador POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual de Linux correspondiente para obtener detalles del comportamiento en Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

getuid — obtener un ID de usuario real

SINOPSIS

#include <unistd.h>
uid_t getuid(void);

DESCRIPCIÓN

La función getuid() devolverá el ID de usuario real del proceso que realiza la llamada. La función getuid() no modificará errno.

VALOR DE RETORNO

La función getuid() siempre tendrá éxito y no se reserva ningún valor de retorno para indicar el error.

ERRORES

No se definen errores.

Las siguientes secciones son informativas.

EJEMPLOS

Establecer el ID de usuario efectivo al ID de usuario real

El siguiente ejemplo establece el ID de usuario efectivo del proceso llamante al ID de usuario real.

#include <unistd.h>
...
seteuid(getuid());

USO DE LA APLICACIÓN

Ninguno.

JUSTIFICACIÓN

En un entorno conforme, getuid() siempre tendrá éxito. Es posible que las implementaciones proporcionen una extensión en la que un proceso en un entorno no conforme no esté asociado con un ID de usuario o grupo. Se recomienda que dichas implementaciones devuelvan (uid_t)-1 y establezcan errno para indicar dicho entorno; hacerlo no viola este estándar, ya que dicho entorno ya es una extensión.

DIRECCIONES FUTURAS

Ninguna.
