DESCRIPCIÓN

Una gearman_task_st representa una tarea. El trabajo que un cliente envía a un servidor de gearman se ve como una tarea (un trabajador recibe una tarea en forma de trabajo.

Las tareas, es decir, gearman_task_st se crean llamando a gearman_execute(), gearman_client_add_task(), o gearman_client_add_task_background().

gearman_client_add_task_status() también puede crear gearman_task_st, estas tareas se usarán para monitorizar una gearman_task_st creada previamente.

gearman_task_free() se usa para liberar una tarea. Esto solo necesita hacerse si una tarea se creó con una estructura preasignada o si desea limpiar la memoria de una tarea específica.

gearman_task_set_context() establece el contexto dado de la gearman_task_st. El contexto puede usarse para pasar información a una gearman_task_st.

gearman_task_context() devuelve el contexto que se usó en la creación de la gearman_task_st (o que se estableció con gearman_task_set_context().

gearman_task_data() devuelve los datos actuales que se han devuelto a la tarea. gearman_task_data_size() le dará el tamaño del valor. gearman_task_take_data() es lo mismo que gearman_task_data() pero el valor que se devuelve debe ser liberado por el cliente (free(3)). gearman_task_recv_data() se puede usar con búferes preasignados.

gearman_task_is_known(), gearman_task_is_running(), gearman_task_numerator(), y gearman_task_denominator(), devuelven valores relacionados con la última actualización de estado que se realizó a la gearman_task_st. No hacen que la gearman_task_st se actualice a sí misma.

gearman_task_error() devuelve el último mensaje de error que encontró la gearman_task_st. gearman_task_return() devuelve el último gearman_return_t almacenado. Un valor de GEARMAN_UNKNOWN_STATE significa que la tarea aún no se ha enviado al servidor, o que no había ninguna función disponible si el trabajo se ha enviado.

VALOR DE RETORNO

Varios. Los valores que son devueltos por gearman_task_take_data() deben tener free(3) llamado sobre ellos.
