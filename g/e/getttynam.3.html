getttyent(3) Manual de funciones de biblioteca getttyent(3)

NOMBRE

getttyent(3) - obtener entrada del archivo ttys

getttynam(3) - obtener entrada del archivo ttys

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <ttyent.h>
struct ttyent *getttyent(void);
struct ttyent *getttynam(const char *name);
int setttyent(void);
int endttyent(void);

DESCRIPCIÓN

Estas funciones proporcionan una interfaz al archivo _PATH_TTYS (por ejemplo, /etc/ttys).

La función setttyent() abre el archivo o lo rebobina si ya está abierto.

La función endttyent() cierra el archivo.

La función getttynam() busca un nombre de terminal dado en el archivo. Devuelve un puntero a una estructura ttyent (descripción a continuación).

La función getttyent() abre el archivo _PATH_TTYS (si es necesario) y devuelve la primera entrada. Si el archivo ya está abierto, la siguiente entrada. La estructura ttyent tiene la forma:


struct ttyent {
    char *ty_name;     /* nombre del dispositivo de terminal */
    char *ty_getty;    /* comando a ejecutar, normalmente getty */
    char *ty_type;     /* tipo de terminal para termcap */
    int   ty_status;   /* flags de estado */
    char *ty_window;   /* comando para iniciar el gestor de ventanas */
    char *ty_comment;  /* campo de comentario */
};

ty_status puede ser:


#define TTY_ON     0x01  /* habilitar inicios de sesión (iniciar programa ty_getty) */
#define TTY_SECURE 0x02  /* permitir inicio de sesión del UID 0 */

ATRIBUTOS

Para obtener una explicación de los términos utilizados en esta sección, consulte attributes(7).

Interfaz Atributo Valor
getttyent (), setttyent (), endttyent (), getttynam () Seguridad de hilos MT-Unsafe race:ttyent

ESTÁNDARES

BSD.

NOTAS

En Linux, el archivo /etc/ttys, y las funciones descritas anteriormente, no se utilizan.
