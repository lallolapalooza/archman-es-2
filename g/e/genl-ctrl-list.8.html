NOMBRE

genl-ctrl-list - Listar familias Generic Netlink disponibles en el lado del kernel

SINOPSIS

genl-ctrl-list [-d]

DESCRIPCIÓN

Consulta el controlador Generic Netlink en el kernel e imprime una lista de todas las familias Generic Netlink registradas, incluyendo la versión de la interfaz que se ha registrado.

OPCIONES

-h o --help
Imprime el texto de ayuda en la consola y sale.
-v o --version
Imprime la información de la versión en la consola y sale.
-d o --details
Incluye información detallada adicional para cada familia Generic Netlink que se imprime.

La información incluye:

hdrsize N
El tamaño de la cabecera específica del usuario.
maxattr N
El identificador de atributo Netlink máximo esperado por la interfaz.
op NOMBRE (ID) <FLAGS>
Una lista de operaciones disponibles incluyendo su nombre, identificador numérico y las banderas que indican las capacidades de la operación.

Banderas disponibles:

admin-perm
Requiere privilegios de administrador
has-doit
El comando puede manejar la solicitud
has-dump
El comando puede manejar una solicitud de volcado
has-policy
El comando aplica la política de validación de atributos
grp NOMBRE (ID)
Una lista de grupos multicast registrados incluyendo el nombre (si está disponible) y el identificador.
Ejemplo:
0x0010 nlctrl version 2

hdrsize 0 maxattr 7

op GETFAMILY (0x03) <has-doit,has-dump,has-policy>

grp notify (0x10)

EJEMPLO

$ genl-ctrl-list
0x0010 nlctrl version 2
0x0011 NLBL_MGMT version 3
0x0012 NLBL_CIPSOv4 version 3
0x0013 NLBL_UNLBL version 3
0x0014 acpi_event version 1
0x0015 thermal_event version 1
0x0016 VFS_DQUOT version 1
0x0017 TASKSTATS version 1
0x0018 NET_DM version 2
