NOMBRE

getcap - examinar las capacidades de archivos

SINOPSIS

getcap [-v] [-n] [-r] [-h] nombre_archivo [ ... ]

DESCRIPCIÓN

getcap muestra el nombre y las capacidades de cada archivo especificado.

OPCIONES

-h
muestra un resumen rápido de uso.
-n
muestra cualquier valor de ID de usuario del espacio de nombres de usuario distinto de cero que se encuentre asociado con las capacidades de un archivo.
-r
habilita la búsqueda recursiva.
-v
muestra todas las entradas buscadas, incluso si no tienen capacidades de archivo.

NOTA: Un valor *vacío* de '=' *no* es equivalente a una capacidad omitida (o eliminada) en un archivo. Esto es más significativo con respecto al vector de capacidades Ambient, ya que un proceso con capacidades Ambient las perderá al ejecutar un archivo que tenga capacidades de archivo de '=', pero conservará la herencia Ambiental de privilegios al ejecutar un archivo con una capacidad de archivo omitida. Esta configuración especial *vacía* se puede usar para evitar que un binario se ejecute con privilegios. Durante un tiempo, el kernel respetó esta supresión para la ejecución de archivos por parte de root, pero los desarrolladores del kernel decidieron después de varios años que este comportamiento era inesperado para el superusuario y lo revirtieron solo para esa identidad de usuario. La supresión de privilegios de root, para un árbol de procesos, es posible utilizando la opción --mode de capsh(1).

nombre_archivo
Un archivo por línea.

REPORTAR ERRORES

Por favor, reporte errores a través de:

https://bugzilla.kernel.org/buglist.cgi?component=libcap&list_id=1090757
