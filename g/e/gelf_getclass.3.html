NOMBRE

gelf_getclass - devuelve la clase ELF (32 bits o 64 bits) de un objeto

SINOPSIS

#include <gelf.h>
int gelf_getclass(Elf *elf);

DESCRIPCIÓN

gelf_getclass() devuelve la clase del objeto ELF al que hace referencia elf. La clase de un archivo ELF válido será una de las siguientes:

ELFCLASS32
El objeto es de clase ELF de 32 bits.
ELFCLASS64
El objeto es de clase ELF de 64 bits.

Si elf no denota un objeto ELF válido, o si la clase no se puede determinar, se devuelve ELFCLASSNONE.

VALOR DE RETORNO

Devuelve ELFCLASS32 o ELFCLASS64 en caso de éxito. Si elf es NULL o no se refiere a un binario ELF válido con tipo ELF_K_ELF, entonces se devuelve ELFCLASSNONE.

VER TAMBIÉN

elf_kind(3), libelf(3), elf(5)

ATRIBUTOS
