GETC(3P) Manual del programador de POSIX GETC(3P)

PROLOG

Esta página del manual es parte del Manual del programador de POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual de Linux correspondiente para obtener detalles sobre el comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

getc — obtener un byte de un flujo

SINOPSIS

#include <stdio.h>
int getc(FILE *stream);

DESCRIPCIÓN

La funcionalidad descrita en esta página de referencia está alineada con el estándar ISO C. Cualquier conflicto entre los requisitos descritos aquí y el estándar ISO C es no intencional. Este volumen de POSIX.1‐2017 remite al estándar ISO C.

La función getc() será equivalente a fgetc(), excepto que si se implementa como una macro puede evaluar stream más de una vez, por lo que el argumento nunca debe ser una expresión con efectos secundarios.

VALOR DE RETORNO

Consulte fgetc().

ERRORES

Consulte fgetc().

Ninguno.

USO DE APLICACIÓN

Si el valor entero devuelto por getc() se almacena en una variable de tipo char y luego se compara con la constante entera EOF, la comparación puede no tener éxito nunca, ya que la extensión de signo de una variable de tipo char al ampliarse a entero es definida por la implementación.

Dado que puede implementarse como una macro, getc() puede tratar incorrectamente un argumento stream con efectos secundarios. En particular, getc(*f++) no necesariamente funciona como se espera. Por lo tanto, el uso de esta función debe ir precedido por **"#undef**getc" en tales situaciones; también se podría usar fgetc().
