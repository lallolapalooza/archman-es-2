Diferencias entre biblioteca C/núcleo En Linux, el núcleo proporciona una llamada al sistema getcwd(), que las funciones descritas en esta página usarán si es posible. La llamada al sistema toma los mismos argumentos que la función de biblioteca del mismo nombre, pero está limitada a devolver como máximo PATH_MAX bytes. (Antes de Linux 3.12, el límite en el tamaño de la ruta devuelta era el tamaño de página del sistema. En muchas arquitecturas, PATH_MAX y el tamaño de página del sistema son ambos 4096 bytes, pero algunas arquitecturas tienen un tamaño de página mayor.) Si la longitud de la ruta del directorio de trabajo actual excede este límite, entonces la llamada al sistema falla con el

error

ENAMETOOLONG. En este caso, las funciones de biblioteca recurren a una implementación alternativa (más lenta) que devuelve la ruta completa. Tras un cambio en Linux 2.6.36, la ruta devuelta por la llamada al sistema getcwd() tendrá como prefijo la cadena "(unreachable)" si el directorio actual no está debajo del directorio raíz del proceso actual (por ejemplo, porque el proceso estableció una nueva raíz del sistema de archivos usando chroot(2) sin cambiar su directorio actual a la nueva raíz). Este comportamiento también puede ser causado por un usuario sin privilegios

cambiando el directorio actual a otro espacio de nombres de montaje. A
l tratar con rutas de fuentes no confiables, los llamadores de las fu
nciones descritas en esta página (antes de glibc 2.27) o la llamada cruda

al sistema getcwd() deberían considerar comprobar si la ruta devuelta comienza con '/' o '(' para evitar malinterpretar una ruta inaccesible como

una ruta relativa.
