NOMBRE

genpyt - genera el léxico PINYIN

SINOPSIS

genpyt archivo-lexicon archivo-resultado archivo-log archivo-slm

DESCRIPCIÓN

genpyt se utiliza para generar el léxico PINYIN. Solo funciona en la configuración regional zh_CN.UTF-8.

ARGUMENTOS

archivo-lexicon
Especifica un archivo de diccionario. Debe ser un archivo de texto basado en líneas con codificación utf-8. Cada línea tiene el siguiente formato: 
CCC  id  [pinyin'pinyin'pinyin]*

Se puede encontrar un archivo de diccionario predeterminado en /usr/share/sunpinyin/dict.utf8.

archivo-resultado
El archivo binario de léxico PINYIN de salida. Este léxico contiene un trie que presenta el árbol de claves de PINYIN. Y todas las palabras candidatas se ordenan utilizando el unigrama en archivo-slm. Este archivo puede usarse con los motores del método de entrada sunpinyin.
archivo-log
Especifica el archivo al que irá el registro. El archivo-log puede verse como la presentación legible por humanos del archivo de salida binario.
archivo-slm
El modelo de lenguaje del cual se recupera la información del unigrama. Típicamente, el archivo-slm es generado por slmthread.
