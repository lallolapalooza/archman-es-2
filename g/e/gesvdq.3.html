CGESVDQ calcula la descomposición en valores singulares (SVD) con un método de SVD QR con precondicionamiento QR para matrices

GE

Propósito

: 
!>
!> CGESVDQ calcula la descomposición en valores singulares (SVD) de una matriz compleja
!> A de M por N, donde M >= N. La SVD de A se escribe como
!>                                    [++]   [xx]   [x0]   [xx]
!>              A = U * SIGMA * V^*,  [++] = [xx] * [ox] * [xx]
!>                                    [++]   [xx]
!> donde SIGMA es una matriz diagonal de N por N, U es una matriz
!> ortogonal de M por N, y V es una matriz unitaria de N por N. Los elementos
!> diagonales de SIGMA son los valores singulares de A. Las columnas de U y V son los
!> vectores singulares izquierdo y derecho de A, respectivamente.
!
>

Parámetro

s
JOBA 
!>  JOBA es CHARACTER*1
!>  Especifica el nivel de precisión en la SVD calculada
!>  = 'A' La precisión solicitada corresponde a tener el error
!>        inverso acotado por || delta A ||_F <= f(m,n) * EPS * || A ||_F,
!>        donde EPS = SLAMCH('Epsilon'). Esto autoriza a CGESVDQ a
!>        truncar el factor triangular calculado en una factorización QR
!>        reveladora de rango siempre que la parte truncada esté por debajo del
!>        umbral del orden de EPS * ||A||_F. Este es el nivel de
!>        truncamiento agresivo.
!>  = 'M' De manera similar a 'A', pero el truncamiento es más suave: se
!>        permite solo cuando hay una caída en la diagonal del
!>        factor triangular en la factorización QR. Este es el nivel de
!>        truncamiento medio.
!>  = 'H' Se solicita alta precisión. No se intenta determinar el rango numérico basado
!>        en la factorización QR reveladora de rango.
!>  = 'E' Igual que 'H', y además se estima el número de condición de la
!>        matriz A escalada por columnas y se devuelve en RWORK(1).
!>        N^(-1/4)*RWORK(1) <= ||pinv(A_scaled)||_2 <= N^(1/4)*RWORK(1)
!
>

JOB

P 
!>  JOBP es CHARACTER*1
!>  = 'P' Las filas de A se ordenan en orden decreciente con respecto a
!>        ||A(i,:)||_\infty. Esto mejora la precisión numérica a costa
!>        de un movimiento de datos adicional. Recomendado para robustez numérica.
!>  = 'N' Sin pivoteo de filas.
!
>

JOB

R 
!>          JOBR es CHARACTER*1
!>          = 'T' Después de la factorización QR inicial con pivoteo, se aplica CGESVD al
!>          adjunto R**H del factor triangular R calculado. Esto implica
!>          algo de movimiento de datos adicional (transposiciones de matrices). Útil para
!>          experimentos, investigación y desarrollo.
!>          = 'N' El factor triangular R se da como entrada a CGESVD. Esto puede
!>          preferirse ya que implica menos movimiento de datos.
!
>

JOB

U 
!>          JOBU es CHARACTER*1
!>          = 'A' Se calculan los M vectores singulares izquierdos y se devuelven en la
!>          matriz U. Ver la descripción de U.
!>          = 'S' o 'U' Se calculan N = min(M,N) vectores singulares izquierdos y se devuelven
!>          en la matriz U. Ver la descripción de U.
!>          = 'R' Se determina el rango numérico NUMRANK y solo se calculan NUMRANK vectores singulares
!>          izquierdos y se devuelven en la matriz U.
!>          = 'F' Los N vectores singulares izquierdos se devuelven en forma factorizada como el
!>          producto del factor Q de la factorización QR inicial y los
!>          N vectores singulares izquierdos de (R**H , 0)**H. Si se usa pivoteo de filas,
!>          entonces la información necesaria sobre el pivoteo de filas se almacena en
!>          IWORK(N+1:N+M-1).
!>          = 'N' No se calculan los vectores singulares izquierdos.
!
>

JOB

V 
!>          JOBV es CHARACTER*1
!>          = 'A', 'V' Se calculan los N vectores singulares derechos y se devuelven en
!>          la matriz V.
!>          = 'R' Se determina el rango numérico NUMRANK y solo se calculan NUMRANK vectores singulares
!>          derechos y se devuelven en la matriz V. Esta opción
!>          se permite solo si JOBU = 'R' o JOBU = 'N'; de lo contrario es ilegal.
!>          = 'N' No se calculan los vectores singulares derechos.
!
>

M 
!>          M es INTEGER
!>          El número de filas de la matriz de entrada A.  M >= 0.
!
>

N 
!>          N es INTEGER
!>          El número de columnas de la matriz de entrada A.  M >= N >= 0.
!
>

A 
!>          A es un arreglo COMPLEX de dimensiones LDA x N
!>          En la entrada, la matriz de entrada A.
!>          En la salida, si JOBU .NE. 'N' o JOBV .NE. 'N', el triángulo inferior de A contiene
!>          los vectores de Householder tal como los almacena CGEQP3. Si JOBU = 'F', estos vectores de Householder
!>          junto con CWORK(1:N) se pueden usar para restaurar los factores Q de la
!>          factorización QR inicial con pivoteo de A. Ver la descripción de U.
!
>

LD

A 
!>          LDA es INTEGER.
!>          La dimensión principal del arreglo A.  LDA >= max(1,M).
!
>

S 
!>          S es un arreglo REAL de dimensión N.
!>          Los valores singulares de A, ordenados de modo que S(i) >= S(i+1).
!
>

U 
!>          U es un arreglo COMPLEX, dimensión
!>          LDU x M si JOBU = 'A'; ver la descripción de LDU. En este caso,
!>          en la salida, U contiene los M vectores singulares izquierdos.
!>          LDU x N si JOBU = 'S', 'U', 'R' ; ver la descripción de LDU. En este
!>          caso, U contiene los N primeros o los NUMRANK primeros vectores singulares izquierdos.
!>          LDU x N si JOBU = 'F' ; ver la descripción de LDU. En este caso U
!>          contiene una matriz unitaria N x N que se puede usar para formar los vectores
!>          singulares izquierdos.
!>          Si JOBU = 'N', U no se referencia.
!
>

LD

U 
!>          LDU es INTEGER.
!>          La dimensión principal del arreglo U.
!>          Si JOBU = 'A', 'S', 'U', 'R',  LDU >= max(1,M).
!>          Si JOBU = 'F',                 LDU >= max(1,N).
!>          De lo contrario,                     LDU >= 1.
!
>

V 
!>          V es un arreglo COMPLEXray, dimensión
!>          LDV x N si JOBV = 'A', 'V', 'R' o si JOBA = 'E' .
!>          Si JOBV = 'A' o 'V', V contiene la matriz unitaria N-por-N V**H;
!>          Si JOBV = 'R', V contiene las primeras NUMRANK filas de V**H (los
!>          vectores singulares derechos, almacenados por filas, de los NUMRANK
!>          valores singulares más grandes).
!>          Si JOBV = 'N' y JOBA = 'E', V se usa como espacio de trabajo.
!>          Si JOBV = 'N' y JOBA.NE.'E', V no se referencia.
!
>

LD

V 
!>          LDV es INTEGER
!>          La dimensión principal del array V.
!>          Si JOBV = 'A', 'V', 'R' o JOBA = 'E', LDV >= max(1,N).
!>          En otro caso, LDV >= 1.
!
>

NUMRAN

K 
!>          NUMRANK es INTEGER
!>          NUMRANK es el rango numérico determinado primero después de la
!>          factorización QR reveladora de rango, siguiendo la estrategia
!>          especificada por el valor de JOBA. Si JOBV = 'R' y JOBU = 'R', solo
!>          se solicitan los NUMRANK valores singulares y vectores principales
!>          en la llamada a CGESVD. El valor final de NUMRANK podría reducirse
!>          aún más si algunos valores singulares se calculan como ceros.
!
>

IWOR

K 
!>          IWORK es un array INTEGER, dimensión (max(1, LIWORK)).
!>          En la salida, IWORK(1:N) contiene la permutación de pivoteo por
!>          columnas de la factorización QR reveladora de rango.
!>          Si JOBP = 'P', IWORK(N+1:N+M-1) contiene los índices de la secuencia
!>          de intercambios de filas usados en el pivoteo de filas. Estos pueden
!>          usarse para restaurar los vectores singulares izquierdos en el caso
!>          JOBU = 'F'.
!>
!>          Si LIWORK, LCWORK o LRWORK = -1, entonces en la salida, si INFO = 0,
!>          IWORK(1) devuelve el LIWORK mínimo.
!
>

LIWOR

K 
!>          LIWORK es INTEGER
!>          La dimensión del array IWORK.
!>          LIWORK >= N + M - 1, si JOBP = 'P';
!>          LIWORK >= N si JOBP = 'N'.
!>
!>          Si LIWORK = -1, se asume una consulta de espacio de trabajo; la
!>          rutina solo calcula y devuelve los tamaños óptimos y mínimos para
!>          los arrays CWORK, IWORK y RWORK, y XERBLA no emite ningún mensaje de
!>          error relacionado con LCWORK.
!
>

CWOR

K 
!>          CWORK es un array COMPLEX, dimensión (max(2, LCWORK)), usado como
!>          espacio de trabajo.
!>          En la salida, si en la entrada LCWORK.NE.-1, CWORK(1:N) contiene los
!>          parámetros necesarios para recuperar el factor Q de la factorización
!>          QR calculada por CGEQP3.
!>
!>          Si LIWORK, LCWORK o LRWORK = -1, entonces en la salida, si INFO = 0,
!>          CWORK(1) devuelve el LCWORK óptimo y CWORK(2) devuelve el LCWORK
!>          mínimo.
!
>

LCWOR

K 
!>          LCWORK es INTEGER
!>          La dimensión del array CWORK. Se determina de la siguiente manera:
!>          Sea LWQP3 = N+1, LWCON = 2*N, y sea
!>          LWUNQ = { MAX( N, 1 ),  si JOBU = 'R', 'S' o 'U'
!>                  { MAX( M, 1 ),  si JOBU = 'A'
!>          LWSVD = MAX( 3*N, 1 )
!>          LWLQF = MAX( N/2, 1 ), LWSVD2 = MAX( 3*(N/2), 1 ), LWUNLQ = MAX( N, 1 ),
!>          LWQRF = MAX( N/2, 1 ), LWUNQ2 = MAX( N, 1 )
!>          Entonces el valor mínimo de LCWORK es:
!>          = MAX( N + LWQP3, LWSVD )        si solo se necesitan los valores singulares;
!>          = MAX( N + LWQP3, LWCON, LWSVD ) si solo se necesitan los valores singulares,
!>                                   y se solicita una estimación de condición escalada;
!>
!>          = N + MAX( LWQP3, LWSVD, LWUNQ ) si se solicitan los valores singulares y los
!>                                   vectores singulares izquierdos;
!>          = N + MAX( LWQP3, LWCON, LWSVD, LWUNQ ) si se solicitan los valores singulares y los
!>                                   vectores singulares izquierdos, y también
!>                                   se solicita una estimación de condición escalada;
!>
!>          = N + MAX( LWQP3, LWSVD )        si se solicitan los valores singulares y los
!>                                   vectores singulares derechos;
!>          = N + MAX( LWQP3, LWCON, LWSVD ) si se solicitan los valores singulares y los
!>                                   vectores singulares derechos, y también
!>                                   se solicita una estimación de condición escalada;
!>
!>          = N + MAX( LWQP3, LWSVD, LWUNQ ) si se solicita la SVD completa con JOBV = 'R';
!>                                   independientemente de JOBR;
!>          = N + MAX( LWQP3, LWCON, LWSVD, LWUNQ ) si se solicita la SVD completa,
!>                                   JOBV = 'R' y también se solicita una estimación de
!>                                   condición escalada; independientemente de JOBR;
!>          = MAX( N + MAX( LWQP3, LWSVD, LWUNQ ),
!>         N + MAX( LWQP3, N/2+LWLQF, N/2+LWSVD2, N/2+LWUNLQ, LWUNQ) ) si se
!>                         solicita la SVD completa con JOBV = 'A' o 'V', y
!>                         JOBR ='N'
!>          = MAX( N + MAX( LWQP3, LWCON, LWSVD, LWUNQ ),
!>         N + MAX( LWQP3, LWCON, N/2+LWLQF, N/2+LWSVD2, N/2+LWUNLQ, LWUNQ ) )
!>                         si se solicita la SVD completa con JOBV = 'A' o 'V', y
!>                         JOBR ='N', y también se solicita una estimación de
!>                         número de condición escalado.
!>          = MAX( N + MAX( LWQP3, LWSVD, LWUNQ ),
!>         N + MAX( LWQP3, N/2+LWQRF, N/2+LWSVD2, N/2+LWUNQ2, LWUNQ ) ) si se
!>                         solicita la SVD completa con JOBV = 'A', 'V', y JOBR ='T'
!>          = MAX( N + MAX( LWQP3, LWCON, LWSVD, LWUNQ ),
!>         N + MAX( LWQP3, LWCON, N/2+LWQRF, N/2+LWSVD2, N/2+LWUNQ2, LWUNQ ) )
!>                         si se solicita la SVD completa con JOBV = 'A', 'V' y
!>                         JOBR ='T', y también se solicita una estimación de
!>                         número de condición escalado.
!>          Finalmente, LCWORK debe ser al menos dos: LCWORK = MAX( 2, LCWORK ).
!>
!>          Si LCWORK = -1, se asume una consulta de espacio de trabajo; la
!>          rutina solo calcula y devuelve los tamaños óptimos y mínimos para
!>          los arrays CWORK, IWORK y RWORK, y XERBLA no emite ningún mensaje de
!>          error relacionado con LCWORK.
!
>

RWOR

K 
!>          RWORK es un array REAL, dimensión (max(1, LRWORK)).
!>          En la salida,
!>          1. Si JOBA = 'E', RWORK(1) contiene una estimación del número de
!>          condición de A escalado por columnas. Si A = C * D donde D es
!>          diagonal y C tiene columnas unitarias en la norma euclidiana, entonces,
!>          asumiendo rango de columna completo,
!>          N^(-1/4) * RWORK(1) <= ||pinv(C)||_2 <= N^(1/4) * RWORK(1).
!>          En otro caso, RWORK(1) = -1.
!>          2. RWORK(2) contiene el número de valores singulares calculados como
!>          ceros exactos en CGESVD aplicado a la R triangular superior o
!>          trapezoidal (de la factorización QR inicial). En caso de salida
!>          anticipada (sin llamada a CGESVD, como en el caso de una matriz de
!>          ceros) RWORK(2) = -1.
!>
!>          Si LIWORK, LCWORK o LRWORK = -1, entonces en la salida, si INFO = 0,
!>          RWORK(1) devuelve el LRWORK mínimo.
!
>

LRWOR

K 
!>          LRWORK es INTEGER.
!>          La dimensión del array RWORK.
!>          Si JOBP ='P', entonces LRWORK >= MAX(2, M, 5*N);
!>          En otro caso, LRWORK >= MAX(2, 5*N).
!>
!>          Si LRWORK = -1, se asume una consulta de espacio de trabajo; la
!>          rutina solo calcula y devuelve los tamaños óptimos y mínimos para
!>          los arrays CWORK, IWORK y RWORK, y XERBLA no emite ningún mensaje de
!>          error relacionado con LCWORK.
!
>

INF

O 
!>          INFO es INTEGER
!>          = 0:  salida exitosa.
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>          > 0:  si CBDSQR no convergió, INFO especifica cuántas superdiagonales
!>          de una forma bidiagonal intermedia B (calculada en CGESVD) no
!>          convergieron a cero.
!
>

Detalles

adicionales: 
!>
!>   1. El movimiento de datos (transposición de matriz) está codificado usando
!>   bucles DO anidados simples porque BLAS y LAPACK no proporcionan subrutinas
!>   correspondientes. Esas bucles DO se identifican fácilmente en este código
!>   fuente - por las sentencias CONTINUE etiquetadas con 11**. En una versión
!>   optimizada de este código, las bucles DO anidadas deberían reemplazarse con
!>   llamadas a una subrutina optimizada.
!>   2. Este código escala A por 1/SQRT(M) si el ABS(A(i,j)) más grande podría
!>   causar desbordamiento de la norma de columna. Esta es la precaución mínima
!>   y se deja a la rutina SVD (CGESVD) hacer su propio escalado preventivo si
!>   se detectan posibles desbordamientos o desbordamientos inferiores. Para
!>   evitar el escaneo repetido del array A, una implementación óptima haría
!>   todo el escalado necesario antes de llamar a CGESVD y el escalado en
!>   CGESVD puede desactivarse.
!>   3. Otros comentarios relacionados con la optimización del código se dan en
!>   comentarios en el código, encerrados en [[corchetes dobles]].
!

!>          entonces la información necesaria sobre el pivoteo de filas se almacena en
!>          IWORK(N+1:N+M-1).

!>

!>          JOBV es CHARACTER*1
!>          = 'A', 'V' Se calculan y devuelven los N vectores singulares derechos en la
!>          matriz V.
!>          = 'R' Se determina el rango numérico NUMRANK y solo se calculan y devuelven
!>          NUMRANK vectores singulares derechos en la matriz V. Esta opción es
!>          permitida solo si JOBU = 'R' o JOBU = 'N'; de lo contrario es ilegal.
!>          = 'N' No se calculan los vectores singulares derechos.
!>

M

!>          M es INTEGER
!>          El número de filas de la matriz de entrada A.  M >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz de entrada A.  M >= N >= 0.
!>

A

!>          A es un array DOUBLE PRECISION de dimensiones LDA x N
!>          En la entrada, la matriz de entrada A.
!>          En la salida, si JOBU .NE. 'N' o JOBV .NE. 'N', el triángulo inferior de A contiene
!>          los vectores de Householder tal como los almacena DGEQP3. Si JOBU = 'F', estos vectores de
!>          Householder junto con WORK(1:N) pueden usarse para restaurar los factores Q de

!>

!>          LDA es INTEGER.
!>          La dimensión principal del array A.  LDA >= max(1,M).
!>

S

!>          S es un array DOUBLE PRECISION de dimensión N.
!>          Los valores singulares de A, ordenados de modo que S(i) >= S(i+1).
!>

U

!>          U es un array DOUBLE PRECISION, dimensión
!>          LDU x M si JOBU = 'A'; vea la descripción de LDU. En este caso,
!>          en la salida, U contiene los M vectores singulares izquierdos.
!>          LDU x N si JOBU = 'S', 'U', 'R' ; vea la descripción de LDU. En este
!>          caso, U contiene los N primeros o los NUMRANK primeros vectores singulares izquierdos.
!>          LDU x N si JOBU = 'F' ; vea la descripción de LDU. En este caso U
!>          contiene una matriz ortogonal N x N que puede usarse para formar los vectores
!>          singulares izquierdos.
!>          Si JOBU = 'N', U no se referencia.
!>

LDU

!>          LDU es INTEGER.
!>          La dimensión principal del array U.
!>          Si JOBU = 'A', 'S', 'U', 'R',  LDU >= max(1,M).
!>          Si JOBU = 'F',                 LDU >= max(1,N).
!>          De lo contrario,             LDU >= 1.
!>

V

!>          V es un array DOUBLE PRECISION, dimensión
!>          LDV x N si JOBV = 'A', 'V', 'R' o si JOBA = 'E' .
!>          Si JOBV = 'A', o 'V',  V contiene la matriz ortogonal N por N  V**T;
!>          Si JOBV = 'R', V contiene las primeras NUMRANK filas de V**T (los vectores
!>          singulares derechos, almacenados por filas, de los NUMRANK mayores valores singulares).
!>          Si JOBV = 'N' y JOBA = 'E', V se usa como espacio de trabajo.
!>          Si JOBV = 'N', y JOBA.NE.'E', V no se referencia.
!>

LDV

!>          LDV es INTEGER
!>          La dimensión principal del array V.
!>          Si JOBV = 'A', 'V', 'R',  o JOBA = 'E', LDV >= max(1,N).
!>          De lo contrario,                               LDV >= 1.
!>

!>          NUMRANK es INTEGER
!>          NUMRANK es el rango numérico determinado primero después de la
!>          factorización QR reveladora de rango, siguiendo la estrategia especificada por el
!>          valor de JOBA. Si JOBV = 'R' y JOBU = 'R', solo se solicitan NUMRANK
!>          valores singulares y vectores principales en la llamada
!>          de DGESVD. El valor final de NUMRANK podría reducirse aún más si
!>          algunos valores singulares se calculan como ceros.
!>

IWORK

!>          IWORK es un array INTEGER, dimensión (max(1, LIWORK)).
!>          En la salida, IWORK(1:N) contiene la permutación de pivoteo de columnas de la
!>          factorización QR reveladora de rango.
!>          Si JOBP = 'P', IWORK(N+1:N+M-1) contiene los índices de la secuencia

!>          vectores singulares izquierdos en el caso JOBU = 'F'.

!>          Si LIWORK, LWORK, o LRWORK = -1, entonces en la salida, si INFO = 0,

!>          LIWORK es INTEGER
!>          La dimensión del array IWORK.
!>          LIWORK >= N + M - 1,     si JOBP = 'P' y JOBA .NE. 'E';

!>          Si LIWORK = -1, entonces se asume una consulta de espacio de trabajo; la rutina

!>          para los arrays WORK, IWORK, y RWORK, y no se emite ningún mensaje de error
!>          relacionado con LWORK por parte de XERBLA.

WORK

!>          WORK es un array DOUBLE PRECISION, dimensión (max(2, LWORK)), usado como espacio de trabajo.
!>          En la salida, si, en la entrada, LWORK.NE.-1, WORK(1:N) contiene parámetros
!>          necesarios para recuperar el factor Q de la factorización QR calculada por
!>          DGEQP3.
!>
!>          Si LIWORK, LWORK, o LRWORK = -1, entonces en la salida, si INFO = 0,
!>          WORK(1) devuelve el LWORK óptimo, y
!>          WORK(2) devuelve el LWORK mínimo.

!>          La dimensión del array WORK. Se determina de la siguiente manera:

!>          LWORQ = { MAX( N, 1 ),  si JOBU = 'R', 'S', o 'U'
!>                  { MAX( M, 1 ),  si JOBU = 'A'
!>          LWSVD = MAX( 5*N, 1 )
!>          LWLQF = MAX( N/2, 1 ), LWSVD2 = MAX( 5*(N/2), 1 ), LWORLQ = MAX( N, 1 ),
!>          LWQRF = MAX( N/2, 1 ), LWORQ2 = MAX( N, 1 )

!>                                   singulares derechos, y también
!>                                   se solicita una estimación de condición escalada;
!>

!>          = N + MAX( LWQP3, LWCON, LWSVD, LWORQ ) si se solicita la SVD completa,

!>                         solicita la SVD completa con JOBV = 'A' o 'V', y
!>                         JOBR ='N'
!>          = MAX( N + MAX( LWQP3, LWCON, LWSVD, LWORQ ),
!>         N + MAX( LWQP3, LWCON, N/2+LWLQF, N/2+LWSVD2, N/2+LWORLQ, LWORQ ) )

!>                         JOBR ='N', y también se solicita una estimación del
!>                         número de condición escalado.
!>          = MAX( N + MAX( LWQP3, LWSVD, LWORQ ),
!>         N + MAX( LWQP3, N/2+LWQRF, N/2+LWSVD2, N/2+LWORQ2, LWORQ ) ) si se
!>                         solicita la SVD completa con JOBV = 'A', 'V', y JOBR ='T'
!>          = MAX( N + MAX( LWQP3, LWCON, LWSVD, LWORQ ),
!>         N + MAX( LWQP3, LWCON, N/2+LWQRF, N/2+LWSVD2, N/2+LWORQ2, LWORQ ) )
!>                         si se solicita la SVD completa con JOBV = 'A' o 'V', y
!>                         JOBR ='T', y también se solicita una estimación del
!>                         número de condición escalado.
!>          Finalmente, LWORK debe ser al menos dos: LWORK = MAX( 2, LWORK ).
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula y devuelve los tamaños óptimos y mínimos
!>          para los arreglos WORK, IWORK y RWORK, y XERBLA no emite ningún

SGESVDQ calcula la descomposición en valores singulares (SVD) con un Método de SVD QR Precondicionado con QR para matrices

GE

Propósito

: 
!>
!> SGESVDQ calcula la descomposición en valores singulares (SVD) de una matriz real
!> A de M por N, donde M >= N. La SVD de A se escribe como
!>                                    [++]   [xx]   [x0]   [xx]
!>              A = U * SIGMA * V^*,  [++] = [xx] * [ox] * [xx]
!>                                    [++]   [xx]
!> donde SIGMA es una matriz diagonal de N por N, U es una matriz ortonormal
!> de M por N, y V es una matriz ortogonal de N por N. Los elementos diagonales
!> de SIGMA son los valores singulares de A. Las columnas de U y V son los
!> vectores singulares izquierdo y derecho de A, respectivamente.
!
>

Parámetro

s
JOBA 
!>  JOBA es CHARACTER*1
!>  Especifica el nivel de precisión en la SVD calculada
!>  = 'A' La precisión solicitada corresponde a tener el error hacia atrás
!>        acotado por || delta A ||_F <= f(m,n) * EPS * || A ||_F,
!>        donde EPS = SLAMCH('Epsilon'). Esto autoriza a CGESVDQ a
!>        truncar el factor triangular calculado en una factorización QR reveladora de rango
!>        siempre que la parte truncada esté por debajo del
!>        umbral del orden de EPS * ||A||_F. Este es el nivel de truncamiento
!>        agresivo.
!>  = 'M' De manera similar a 'A', pero el truncamiento es más suave: se
!>        permite solo cuando hay una caída en la diagonal del
!>        factor triangular en la factorización QR. Este es el nivel de truncamiento
!>        medio.
!>  = 'H' Se solicita alta precisión. No se intenta determinación de rango numérico basada
!>        en la factorización QR reveladora de rango.
!>  = 'E' Igual que 'H', y además se estima el número de condición de A
!>        escalado por columnas y se devuelve en RWORK(1).
!>        N^(-1/4)*RWORK(1) <= ||pinv(A_scaled)||_2 <= N^(1/4)*RWORK(1)
!
>

P

!>  = 'P' Las filas de A se ordenan en orden decreciente con respecto a
!>        ||A(i,:)||_\infty. Esto mejora la precisión numérica a costa
!>        de un movimiento de datos adicional. Recomendado para robustez numérica.
!>  = 'N' Sin pivoteo de filas.
!
>

subrutina zgesvdq (caracter joba, caracter jobp, caracter jobr, caracter jobu, caracter jobv, entero m, entero n, complejo*16, dimension( lda, * ) a, entero lda, doble precision, dimension( * ) s, complejo*16, dimension( ldu, * ) u, entero ldu, complejo*16, dimension( ldv, * ) v, entero ldv, entero numrank, entero, dimension( * ) iwork, entero liwork, complejo*16, dimension( * ) cwork, entero lcwork, doble precision, dimension( * ) rwork, entero lrwork, entero info)

ZGESVDQ calcula la descomposición en valores singulares (SVD) con un Método SVD QR Precondicionado por QR para matrices GE

Propósito:

!>
!> ZCGESVDQ calcula la descomposición en valores singulares (SVD) de una matriz compleja
!> M por N, A, donde M >= N. La SVD de A se escribe como
!>                                    [++]   [xx]   [x0]   [xx]
!>              A = U * SIGMA * V^*,  [++] = [xx] * [ox] * [xx]
!>                                    [++]   [xx]
!> donde SIGMA es una matriz diagonal N por N, U es una matriz ortonormal M por N,
!> y V es una matriz unitaria N por N. Los elementos diagonales
!> de SIGMA son los valores singulares de A. Las columnas de U y V son los
!> vectores singulares izquierdos y derechos de A, respectivamente.
!>

Parámetros

JOBA 
!>  JOBA es CARACTER*1
!>  Especifica el nivel de precisión en la SVD calculada
!>  = 'A' La precisión solicitada corresponde a tener el error hacia atrás
!>        acotado por || delta A ||_F <= f(m,n) * EPS * || A ||_F,
!>        donde EPS = DLAMCH('Epsilon'). Esto autoriza a ZGESVDQ a
!>        truncar el factor triangular calculado en una factorización QR
!>        que revela el rango siempre que la parte truncada esté por debajo del
!>        umbral del orden de EPS * ||A||_F. Este es un nivel de truncamiento agresivo.
!>  = 'M' Similar a 'A', pero el truncamiento es más suave: solo se permite
!>        cuando hay una caída en la diagonal del factor triangular en la
!>        factorización QR. Este es un nivel de truncamiento medio.
!>  = 'H' Alta precisión solicitada. No se intenta ninguna determinación numérica del rango basada
!>        en la factorización QR que revela el rango.
!>  = 'E' Igual que 'H', y además se estima el número de condición de A escalada por columna
!>        y se devuelve en RWORK(1).
!>        N^(-1/4)*RWORK(1) <= ||pinv(A_escalada)||_2 <= N^(1/4)*RWORK(1)
!>

JOBP

!>  JOBP es CARACTER*1
!>  = 'P' Las filas de A se ordenan en orden decreciente con respecto a
!>        ||A(i,:)||_\infty. Esto mejora la precisión numérica a costa de
!>        movimiento de datos adicional. Recomendado para robustez numérica.
!>  = 'N' Sin pivoteo de fila.
!>

JOBR

!>          JOBR es CARACTER*1
!>          = 'T' Después de la factorización QR pivotada inicial, ZGESVD se aplica a
!>          la adjunta R**H del factor triangular R calculado. Esto implica
!>          movimiento de datos adicional (transposiciones de matrices). Útil para
!>          experimentos, investigación y desarrollo.
!>          = 'N' El factor triangular R se proporciona como entrada a CGESVD. Esto puede ser
!>          preferible ya que implica menos movimiento de datos.
!>

JOBU

!>          JOBU es CARACTER*1
!>          = 'A' Todos los M vectores singulares izquierdos se calculan y se devuelven en
!>          la matriz U. Ver la descripción de U.
!>          = 'S' o 'U' N = min(M,N) vectores singulares izquierdos se calculan y se devuelven
!>          en la matriz U. Ver la descripción de U.
!>          = 'R' Se determina el rango numérico NUMRANK y solo se calculan NUMRANK vectores singulares izquierdos
!>          y se devuelven en la matriz U.
!>          = 'F' Los N vectores singulares izquierdos se devuelven en forma factorizada como el
!>          producto del factor Q de la factorización QR inicial y los
!>          N vectores singulares izquierdos de (R**H , 0)**H. Si se utiliza pivoteo de fila,
!>          la información necesaria sobre el pivoteo de fila se almacena en
!>          IWORK(N+1:N+M-1).
!>          = 'N' Los vectores singulares izquierdos no se calculan.
!>

JOBV

!>          JOBV es CARACTER*1
!>          = 'A', 'V' Todos los N vectores singulares derechos se calculan y se devuelven en
!>          la matriz V.
!>          = 'R' Se determina el rango numérico NUMRANK y solo se calculan NUMRANK vectores singulares derechos
!>          y se devuelven en la matriz V. Esta opción solo se permite si JOBU = 'R' o JOBU = 'N'; de lo contrario, es ilegal.
!>          = 'N' Los vectores singulares derechos no se calculan.
!>

M

!>          M es ENTERO
!>          El número de filas de la matriz de entrada A. M >= 0.
!>

N

!>          N es ENTERO
!>          El número de columnas de la matriz de entrada A. M >= N >= 0.
!>

A

!>          A es un array COMPLEJO*16 de dimensiones LDA x N
!>          En la entrada, la matriz de entrada A.
!>          En la salida, si JOBU .NE. 'N' o JOBV .NE. 'N', el triángulo inferior de A contiene
!>          los vectores de Householder almacenados por ZGEQP3. Si JOBU = 'F', estos vectores de Householder
!>          junto con CWORK(1:N) pueden usarse para restaurar los factores Q de
!>          la factorización QR pivotada inicial de A. Ver la descripción de U.
!>

LDA

!>          LDA es ENTERO.
!>          La dimensión principal del array A. LDA >= max(1,M).
!>

S

!>          S es un array DOBLE PRECISION de dimensión N.
!>          Los valores singulares de A, ordenados de manera que S(i) >= S(i+1).
!>

U

!>          U es un array COMPLEJO*16, dimensión
!>          LDU x M si JOBU = 'A'; ver la descripción de LDU. En este caso,
!>          en la salida, U contiene los M vectores singulares izquierdos.
!>          LDU x N si JOBU = 'S', 'U', 'R' ; ver la descripción de LDU. En este
!>          caso, U contiene los N o los NUMRANK vectores singulares izquierdos principales.
!>          LDU x N si JOBU = 'F' ; ver la descripción de LDU. En este caso U
!>          contiene la matriz unitaria N x N que se puede usar para formar los vectores singulares izquierdos.
!>          Si JOBU = 'N', U no se referencia.
!>

LDU

!>          LDU es ENTERO.
!>          La dimensión principal del array U.
!>          Si JOBU = 'A', 'S', 'U', 'R', LDU >= max(1,M).
!>          Si JOBU = 'F', LDU >= max(1,N).
!>          De lo contrario, LDU >= 1.
!>

V

!>          V es un array COMPLEJO*16, dimensión
!>          LDV x N si JOBV = 'A', 'V', 'R' o si JOBA = 'E'.
!>          Si JOBV = 'A', o 'V', V contiene la matriz unitaria N x N V**H;
!>          Si JOBV = 'R', V contiene las primeras NUMRANK filas de V**H (los vectores singulares derechos,
!>          almacenados por filas, de los NUMRANK valores singulares más grandes).
!>          Si JOBV = 'N' y JOBA = 'E', V se usa como área de trabajo.
!>          Si JOBV = 'N', y JOBA.NE.'E', V no se referencia.
!>

LDV

!>          LDV es ENTERO
!>          La dimensión principal del array V.
!>          Si JOBV = 'A', 'V', 'R', o JOBA = 'E', LDV >= max(1,N).
!>          De lo contrario, LDV >= 1.
!>

NUMRANK

!>          NUMRANK es ENTERO
!>          NUMRANK es el rango numérico determinado por primera vez después de la factorización QR
!>          que revela el rango, siguiendo la estrategia especificada por el
!>          valor de JOBA. Si JOBV = 'R' y JOBU = 'R', solo se solicitan NUMRANK
!>          valores singulares y vectores principales en la llamada
!>          a CGESVD. El valor final de NUMRANK puede reducirse aún más si
!>          algunos valores singulares se calculan como cero.
!>

IWORK

!>          IWORK es un array ENTERO, dimensión (max(1, LIWORK)).
!>          En la salida, IWORK(1:N) contiene la permutación de columna de la
!>          factorización QR que revela el rango.
!>          Si JOBP = 'P', IWORK(N+1:N+M-1) contiene los índices de la secuencia
!>          de intercambios de filas utilizados en el pivoteo de fila. Estos se pueden usar para restaurar
!>          los vectores singulares izquierdos en el caso JOBU = 'F'.
!>
!>          Si LIWORK, LCWORK, o LRWORK = -1, entonces en la salida, si INFO = 0,
!>          IWORK(1) devuelve el LIWORK mínimo.
!>

LIWORK

!>          LIWORK es ENTERO
!>          La dimensión del array IWORK.
!>          LIWORK >= N + M - 1, si JOBP = 'P';
!>          LIWORK >= N si JOBP = 'N'.
!>
!>          Si LIWORK = -1, entonces se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula y devuelve los tamaños óptimo y mínimo
!>          para los arrays CWORK, IWORK y RWORK, y no se emite ningún mensaje de error
!>          relacionado con LCWORK por XERBLA.
!>

CWORK

!>          CWORK es un array COMPLEJO*12, dimensión (max(2, LCWORK)), usado como área de trabajo.
!>          En la salida, si, en la entrada, LCWORK.NE.-1, CWORK(1:N) contiene los parámetros
!>          necesarios para recuperar el factor Q de la factorización QR calculada por
!>          ZGEQP3.
!>
!>          Si LIWORK, LCWORK, o LRWORK = -1, entonces en la salida, si INFO = 0,
!>          CWORK(1) devuelve el LCWORK óptimo, y
!>          CWORK(2) devuelve el LCWORK mínimo.
!>

LCWORK

!>          LCWORK es ENTERO
!>          La dimensión del array CWORK. Se determina de la siguiente manera:
!>          Sea LWQP3 = N+1, LWCON = 2*N, y
!>          LWUNQ = { MAX( N, 1 ), si JOBU = 'R', 'S', o 'U'
!>          { MAX( M, 1 ), si JOBU = 'A'
!>          LWSVD = MAX( 3*N, 1 )
!>          LWLQF = MAX( N/2, 1 ), LWSVD2 = MAX( 3*(N/2), 1 ), LWUNLQ = MAX( N, 1 ),
!!>          LWQRF = MAX( N/2, 1 ), LWUNQ2 = MAX( N, 1 )
!>          Entonces el valor mínimo de LCWORK es:
!>
= MAX( N + LWQP3, LWSVD ) si solo se necesitan los valores singulares; !> = MAX( N + LWQP3, LWCON, LWSVD ) si solo se necesitan los valores singulares, !> y se solicita una estimación de condición escalada; !> !> = N + MAX( LWQP3, LWSVD, LWUNQ ) si se solicitan los valores singulares y los !> vectores singulares izquierdos; !> = N + MAX( LWQP3, LWCON, LWSVD, LWUNQ ) si se solicitan los valores singulares y los !> vectores singulares izquierdos, y también !> se solicita una estimación de condición escalada; !> !> = N + MAX( LWQP3, LWSVD ) si se solicitan los valores singulares y los !> vectores singulares derechos; !> = N + MAX( LWQP3, LWCON, LWSVD ) si se solicitan los valores singulares y los !> vectores singulares derechos, y también !> se solicita una estimación de condición escalada; !> !> = N + MAX( LWQP3, LWSVD, LWUNQ ) si se solicita la SVD completa con JOBV = 'R'; !> independientemente de JOBR; !> = N + MAX( LWQP3, LWCON, LWSVD, LWUNQ ) si se solicita la SVD completa, !> JOBV = 'R' y también se solicita una estimación !> de condición escalada; independientemente de JOBR; !> = MAX( N + MAX( LWQP3, LWSVD, LWUNQ ), !> N + MAX( LWQP3, N/2+LWLQF, N/2+LWSVD2, N/2+LWUNLQ, LWUNQ) ) si se !> solicita la SVD completa con JOBV = 'A' o 'V', y !> JOBR ='N' !> = MAX( N + MAX( LWQP3, LWCON, LWSVD, LWUNQ ), !> N + MAX( LWQP3, LWCON, N/2+LWLQF, N/2+LWSVD2, N/2+LWUNLQ, LWUNQ ) ) !> si se solicita la SVD completa con JOBV = 'A' o 'V', y !> JOBR ='N', y también se solicita una estimación del número !> de condición escalado. !> = MAX( N + MAX( LWQP3, LWSVD, LWUNQ ), !> N + MAX( LWQP3, N/2+LWQRF, N/2+LWSVD2, N/2+LWUNQ2, LWUNQ ) ) si se !> solicita la SVD completa con JOBV = 'A', 'V', y JOBR ='T' !> = MAX( N + MAX( LWQP3, LWCON, LWSVD, LWUNQ ), !> N + MAX( LWQP3, LWCON, N/2+LWQRF, N/2+LWSVD2, N/2+LWUNQ2, LWUNQ ) ) !> si se solicita la SVD completa con JOBV = 'A', 'V' y !> JOBR ='T', y también se solicita una estimación del número !> de condición escalado. !> Finalmente, LCWORK debe ser al menos dos: LCWORK = MAX( 2, LCWORK ). !> !> Si LCWORK = -1, se asume una consulta de espacio de trabajo;
