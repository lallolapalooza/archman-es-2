CGERFSX

Propósito:

!>
!>    CGERFSX mejora la solución computada para un sistema de ecuaciones
!>    lineales y proporciona cotas de error y estimaciones de error hacia
!>    atrás para la solución. Además de la cota de error a nivel de norma,
!>    el código proporciona la cota de error máxima a nivel de componente,
!>    si es posible. Consulte los comentarios para ERR_BNDS_NORM y ERR_BNDS_COMP
!>    para obtener detalles sobre las cotas de error.
!>
!>    El sistema original de ecuaciones lineales puede haber sido
!>    equilibrado antes de llamar a esta subrutina, como se describe en los
!>    argumentos EQUED, R y C a continuación. En este caso, la solución y las
!>    cotas de error devueltas son para el sistema original no
!>    equilibrado.
!> 
!>     Algunos parámetros opcionales están agrupados en el array PARAMS.
!>     Estos ajustes determinan cómo se realiza el refinamiento, pero a
!>     menudo los valores predeterminados son aceptables. Si los valores
!>     predeterminados son aceptables, los usuarios pueden pasar NPARAMS = 0,
!>     lo que evita que el código fuente acceda al argumento PARAMS.
!>

Parámetros

TRANS 
!>          TRANS es CHARACTER*1
!>     Especifica la forma del sistema de ecuaciones:
!>       = 'N':  A * X = B     (Sin transposición)
!>       = 'T':  A**T * X = B  (Transpuesta)
!>       = 'C':  A**H * X = B  (Transpuesta conjugada)
!>

EQUED

!>          EQUED es CHARACTER*1
!>     Especifica la forma de equilibrado que se realizó en A
!>     antes de llamar a esta subrutina. Esto es necesario para calcular
!>     correctamente la solución y las cotas de error.
!>       = 'N':  Sin equilibrado
!>       = 'R':  Equilibrado de filas, es decir, A se ha multiplicado
!>               por diag(R).
!>       = 'C':  Equilibrado de columnas, es decir, A se ha postmultiplicado
!>               por diag(C).
!>       = 'B':  Equilibrado tanto de filas como de columnas, es decir,
!>               A ha sido reemplazado por diag(R) * A * diag(C).
!>               El lado derecho B se ha modificado en consecuencia.
!>

N

!>          N es INTEGER
!>     El orden de la matriz A.  N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>     El número de lados derechos, es decir, el número de columnas
!>     de las matrices B y X.  NRHS >= 0.
!>

A

!>          A es un array COMPLEX, de dimensión (LDA,N)
!>     La matriz original A de N por N.
!>

LDA

!>          LDA es INTEGER
!>     La dimensión principal del array A.  LDA >= max(1,N).
!>

AF

!>          AF es un array COMPLEX, de dimensión (LDAF,N)
!>     Los factores L y U de la factorización A = P*L*U
!>     tal como los calcula CGETRF.
!>

LDAF

!>          LDAF es INTEGER
!>     La dimensión principal del array AF.  LDAF >= max(1,N).
!>

IPIV

!>          IPIV es un array INTEGER, de dimensión (N)
!>     Los índices de pivote de CGETRF; para 1<=i<=N, la fila i de la
!>     matriz se intercambió con la fila IPIV(i).
!>

R

!>          R es un array REAL, de dimensión (N)
!>     Los factores de escala de fila para A.  Si EQUED = 'R' o 'B', A se
!>     multiplica a la izquierda por diag(R); si EQUED = 'N' o 'C', R
!>     no se accede.
!>     Si se accede a R, cada elemento de R debe ser una potencia de la base
!>     para garantizar una solución y estimaciones de error fiables. El
!>     escalado por potencias de la base no causa errores de redondeo a
!>     menos que el resultado sea un subdesbordamiento o desbordamiento.
!>     Los errores de redondeo durante el escalado provocan un refinamiento
!>     con una matriz que no es equivalente a la matriz de entrada,
!>     produciendo estimaciones de error que pueden no ser fiables.
!>

C

!>          C es un array REAL, de dimensión (N)
!>     Los factores de escala de columna para A.  Si EQUED = 'C' o 'B', A se
!>     multiplica a la derecha por diag(C); si EQUED = 'N' o 'R', C
!>     no se accede.
!>     Si se accede a C, cada elemento de C debe ser una potencia de la base
!>     para garantizar una solución y estimaciones de error fiables. El
!>     escalado por potencias de la base no causa errores de redondeo a
!>     menos que el resultado sea un subdesbordamiento o desbordamiento.
!>     Los errores de redondeo durante el escalado provocan un refinamiento
!>     con una matriz que no es equivalente a la matriz de entrada,
!>     produciendo estimaciones de error que pueden no ser fiables.
!>

B

!>          B es un array COMPLEX, de dimensión (LDB,NRHS)
!>     La matriz del lado derecho B.
!>

LDB

!>          LDB es INTEGER
!>     La dimensión principal del array B.  LDB >= max(1,N).
!>

X

!>          X es un array COMPLEX, de dimensión (LDX,NRHS)
!>     En la entrada, la matriz solución X, tal como la calculó CGETRS.
!>     En la salida, la matriz solución mejorada X.
!>

LDX

!>          LDX es INTEGER
!>     La dimensión principal del array X.  LDX >= max(1,N).
!>

RCOND

!>          RCOND es REAL
!>     Condición recíproca escalada. Esta es una estimación del
!>     número de condición de Skeel recíproco de la matriz A después del
!>     equilibrado (si se realizó). Si este valor es menor que la precisión
!>     de la máquina (en particular, si es cero), la matriz es singular
!>     a la precisión de trabajo. Tenga en cuenta que el error aún puede ser
!>     pequeño incluso si este número es muy pequeño y la matriz parece
!>     mal condicionada.
!>

BERR

!>          BERR es un array REAL, de dimensión (NRHS)
!>     Error relativo hacia atrás a nivel de componente. Este es el
!>     error relativo hacia atrás a nivel de componente de cada vector
!>     solución X(j) (es decir, el cambio relativo más pequeño en cualquier
!>     elemento de A o B que haga que X(j) sea una solución exacta).
!>

ERR_BNDS_NOR

!>          ERR_BNDS_NORM es un array REAL, dimensión (NRHS, N_ERR_BNDS)
!>     Para cada segundo miembro, este array contiene información sobre
!>     varios límites de error y números de condición correspondientes al
!>     error relativo en norma, que se define como sigue:
!>
!>     Error relativo en norma en el i-ésimo vector solución:
!>             max_j (abs(XTRUE(j,i) - X(j,i)))
!>            ------------------------------
!>                  max_j abs(X(j,i))
!>
!>     El array se indexa por el tipo de información de error descrito
!>     más abajo. Actualmente se devuelven hasta tres piezas de
!>     información.
!>
!>     El primer índice en ERR_BNDS_NORM(i,:) corresponde al i-ésimo
!>     segundo miembro.
!>
!>     El segundo índice en ERR_BNDS_NORM(:,err) contiene los siguientes
!>     tres campos:
!>     err = 1  booleano. Confiar en la respuesta si el
!>              número de condición recíproco es menor que el umbral
!>              sqrt(n) * slamch('Epsilon').
!>
!>     err = 2  límite de error: El error hacia adelante estimado,
!>              casi con certeza dentro de un factor de 10 del error
!>              verdadero siempre que la siguiente entrada sea mayor que
!>              el umbral sqrt(n) * slamch('Epsilon'). Este límite de
!>              error solo debe confiarse si el booleano anterior es
!>              verdadero.
!>
!>     err = 3  Número de condición recíproco: Número de condición
!>              recíproco en norma estimado. Se compara con el umbral
!>              sqrt(n) * slamch('Epsilon') para determinar si la
!>              estimación del error es . Estos números de condición
!>              recíprocos son 1 / (norm(Z^{-1},inf) * norm(Z,inf)) para
!>              alguna matriz Z escalada adecuadamente.
!>              Sea Z = S*A, donde S escala cada fila por una potencia de
!>              la base de modo que todas las sumas absolutas de fila de Z
!>              sean aproximadamente 1.
!>
!>     Véase Lapack Working Note 165 para más detalles y precauciones
!>     adicionales.
!

!>          ERR_BNDS_COMP es un array REAL, dimensión (NRHS, N_ERR_BNDS)
!>     Para cada segundo miembro, este array contiene información sobre
!>     varios límites de error y números de condición correspondientes al

!>              recíproco componente a componente estimado. Se compara con
!>              el umbral sqrt(n) * slamch('Epsilon') para determinar si
!>              la estimación del error es . Estos números de condición
!>              recíprocos son 1 / (norm(Z^{-1},inf) * norm(Z,inf)) para
!>              alguna matriz Z escalada adecuadamente.
!>              Sea Z = S*(A*diag(x)), donde x es la solución para el
!>              segundo miembro actual y S escala cada fila de
!>              A*diag(x) por una potencia de la base de modo que todas
