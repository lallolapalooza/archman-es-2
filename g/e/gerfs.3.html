info)

CGERF

S

Propósito

: 
!>
!> CGERFS mejora la solución calculada de un sistema de ecuaciones lineales
!> y proporciona límites de error y estimaciones de error hacia atrás para
!> la solución.
!
>

Parámetro

s
TRANS 
!>          TRANS es CHARACTER*1
!>          Especifica la forma del sistema de ecuaciones:
!>          = 'N':  A * X = B     (Sin transponer)
!>          = 'T':  A**T * X = B  (Transponer)
!>          = 'C':  A**H * X = B  (Transponer conjugado)
!
>

N 
!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!
>

NRH

S 
!>          NRHS es INTEGER
!>          El número de miembros independientes, es decir, el número de columnas
!>          de las matrices B y X.  NRHS >= 0.
!
>

A 
!>          A es un array COMPLEX, dimensión (LDA,N)
!>          La matriz A original de N por N.
!
>

LD

A 
!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!
>

A

F 
!>          AF es un array COMPLEX, dimensión (LDAF,N)
!>          Los factores L y U de la factorización A = P*L*U
!>          tal como se calculan con CGETRF.
!
>

LDA

F 
!>          LDAF es INTEGER
!>          La dimensión principal del array AF.  LDAF >= max(1,N).
!
>

IPI

V 
!>          IPIV es un array INTEGER, dimensión (N)
!>          Los índices de pivote de CGETRF; para 1<=i<=N, la fila i de la
!>          matriz se intercambió con la fila IPIV(i).
!
>

B 
!>          B es un array COMPLEX, dimensión (LDB,NRHS)
!>          La matriz de miembros independientes B.
!
>

LD

B 
!>          LDB es INTEGER
!>          La dimensión principal del array B.  LDB >= max(1,N).
!
>

X 
!>          X es un array COMPLEX, dimensión (LDX,NRHS)
!>          Al entrar, la matriz de solución X, tal como se calcula con CGETRS.
!>          Al salir, la matriz de solución X mejorada.
!
>

LD

X 
!>          LDX es INTEGER
!>          La dimensión principal del array X.  LDX >= max(1,N).
!
>

FER

R 
!>          FERR es un array REAL, dimensión (NRHS)
!>          El límite estimado del error hacia adelante para cada vector de solución
!>          X(j) (la j-ésima columna de la matriz de solución X).
!>          Si XTRUE es la solución verdadera correspondiente a X(j), FERR(j)
!>          es un límite superior estimado para la magnitud del elemento más grande
!>          en (X(j) - XTRUE) dividido por la magnitud del
!>          elemento más grande en X(j).  La estimación es tan fiable como
!>          la estimación para RCOND, y casi siempre es una ligera
!>          sobreestimación del error verdadero.
!
>

BER

R 
!>          BERR es un array REAL, dimensión (NRHS)
!>          El error hacia atrás relativo componente a componente de cada vector de
!>          solución X(j) (es decir, el cambio relativo más pequeño en
!>          cualquier elemento de A o B que hace de X(j) una solución exacta).
!
>

WOR

K 
!>          WORK es un array COMPLEX, dimensión (2*N)
!
>

RWOR

K 
!>          RWORK es un array REAL, dimensión (N)
!
>

INF

O 
!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!
>

Parámetros

Internos: 
!>  ITMAX es el número máximo de pasos de refinamiento iterativo.
!
>
