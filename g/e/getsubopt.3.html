getsubopt(3) Manual de funciones de biblioteca getsubopt(3)

NOMBRE

getsubopt - analizar argumentos de subopciones de una cadena

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <stdlib.h>
int getsubopt(char **restrict optionp, char *const *restrict tokens,
              char **restrict valuep);
Requisitos de macro de prueba de características para glibc (ver feature_test_macros(7)):

getsubopt():

    _XOPEN_SOURCE >= 500
        || /* Desde glibc 2.12: */ _POSIX_C_SOURCE >= 200809L

DESCRIPCIÓN

getsubopt() analiza la lista de subopciones separadas por comas proporcionada en optionp. (Dicha lista de subopciones se produce típicamente cuando getopt(3) se utiliza para analizar una línea de comandos; ver, por ejemplo, la opción -o de mount(8).) Cada subopción puede incluir un valor asociado, que se separa del nombre de la subopción por un signo igual. El siguiente es un ejemplo del tipo de cadena que podría pasarse en optionp:


ro,name=xyz

El argumento tokens es un puntero a una matriz terminada en NULL de punteros a los tokens que getsubopt() buscará en optionp. Los tokens deben ser cadenas distintas y terminadas en nulo que contengan al menos un carácter, sin signos de igual o comas incrustados.

Cada llamada a getsubopt() devuelve información sobre la siguiente subopción no procesada en optionp. El primer signo igual en una subopción (si lo hay) se interpreta como un separador entre el nombre y el valor de esa subopción. El valor se extiende hasta la siguiente coma o (para la última subopción) hasta el final de la cadena. Si el nombre de la subopción coincide con un nombre conocido de tokens y se encontró una cadena de valor, getsubopt() establece *valuep a la dirección de esa cadena. La primera coma en optionp se sobrescribe con un byte nulo, por lo que *valuep es precisamente la "cadena de valor" para esa subopción.

Si la subopción es reconocida, pero no se encontró una cadena de valor, *valuep se establece en NULL.

Cuando getsubopt() retorna, optionp apunta a la siguiente subopción, o al byte nulo ('\0') al final de la cadena si la última subopción acaba de ser procesada.

VALOR DE RETORNO

Si la primera subopción en optionp es reconocida, getsubopt() devuelve el índice del elemento de subopción coincidente en tokens. De lo contrario, se devuelve -1 y *valuep es toda la cadena nombre[=valor].

Dado que *optionp se modifica, la primera subopción antes de la llamada a getsubopt() no es (necesariamente) la misma que la primera subopción después de getsubopt().

NOTAS

Dado que getsubopt() sobrescribe las comas que encuentra en la cadena *optionp, esa cadena debe ser escribible; no puede ser una cadena constante.

EJEMPLOS

El siguiente programa espera subopciones después de la opción "-o".

#define _XOPEN_SOURCE 500
#include <stdio.h>
#include <stdlib.h>
#include <assert.h>
int
main(int argc, char *argv[])
{
    enum {
        RO_OPT = 0,
        RW_OPT,
        NAME_OPT
    };
    char *const token[] = {
        [RO_OPT]   = "ro",
        [RW_OPT]   = "rw",
        [NAME_OPT] = "name",
        NULL
    };
    char *subopts;
    char *value;
    int opt;
    int readonly = 0;
    int readwrite = 0;
    char *name = NULL;
    int errfnd = 0;
    while ((opt = getopt(argc, argv, "o:")) != -1) {
        switch (opt) {
        case 'o':
            subopts = optarg;
            while (*subopts != '\0' && !errfnd) {
                switch (getsubopt(&subopts, token, &value)) {
                case RO_OPT:
                    readonly = 1;
                    break;
                case RW_OPT:
                    readwrite = 1;
                    break;
                case NAME_OPT:
                    if (value == NULL) {
                        fprintf(stderr,
                                "Falta el valor para la subopción '%s'\n",
                                token[NAME_OPT]);
                        errfnd = 1;
                        continue;
                    }
                    name = value;
                    break;
                default:
                    fprintf(stderr,
                            "No se encontró coincidencia para el token: /%s/\n", value);
                    errfnd = 1;
                    break;
                }
            }
            if (readwrite && readonly) {
                fprintf(stderr,
                        "Solo se puede especificar una de '%s' y '%s'\n",
                        token[RO_OPT], token[RW_OPT]);
                errfnd = 1;
            }
            break;
        default:
            errfnd = 1;
        }
    }
    if (errfnd || argc == 1) {
        fprintf(stderr, "\nUso: %s -o <cadena_subopcion>\n", argv[0]);
        fprintf(stderr,
                "las subopciones son 'ro', 'rw' y 'name=<valor>'\n");
        exit(EXIT_FAILURE);
    }
    /* Resto del programa...  */
    exit(EXIT_SUCCESS);
}
