getnetent_r(3) Manual de funciones de la biblioteca getnetent_r(3)

NOMBRE

getnetent_r, getnetbyname_r, getnetbyaddr_r - obtener entrada de red (reentrante)

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <netdb.h>
int getnetent_r(size_t size;
                struct netent *restrict result_buf,
                char buf[restrict size], size_t size,
                struct netent **restrict result,
                int *restrict h_errnop);
int getnetbyname_r(size_t size;
                const char *restrict name,
                struct netent *restrict result_buf,
                char buf[restrict size], size_t size,
                struct netent **restrict result,
                int *restrict h_errnop);
int getnetbyaddr_r(size_t size;
                uint32_t net, int type,
                struct netent *restrict result_buf,
                char buf[restrict size], size_t size,
                struct netent **restrict result,
                int *restrict h_errnop);
Requisitos de Macro de Prueba de Funcionalidad para glibc (ver feature_test_macros(7)):

getnetent_r(), getnetbyname_r(), getnetbyaddr_r():

    Desde glibc 2.19:
        _DEFAULT_SOURCE
    glibc 2.19 y anteriores:
        _BSD_SOURCE || _SVID_SOURCE

DESCRIPCIÓN

Las funciones getnetent_r(), getnetbyname_r() y getnetbyaddr_r() son los equivalentes reentrantes de, respectivamente, getnetent(3), getnetbyname(3) y getnetbynumber(3). Difieren en la forma en que se devuelve la estructura netent, y en la firma de llamada a la función y el valor de retorno. Esta página del manual describe solo las diferencias con las funciones no reentrantes.

En lugar de devolver un puntero a una estructura netent estáticamente asignada como resultado de la función, estas funciones copian la estructura a la ubicación apuntada por result_buf.

El array buf se utiliza para almacenar los campos de cadena apuntados por la estructura netent devuelta. (Las funciones no reentrantes asignan estas cadenas en almacenamiento estático). El tamaño de este array se especifica en size. Si buf es demasiado pequeño, la llamada falla con el error ERANGE, y el llamante debe intentarlo de nuevo con un buffer más grande. (Un buffer de 1024 bytes debería ser suficiente para la mayoría de las aplicaciones).

Si la llamada a la función obtiene con éxito un registro de red, entonces *result se establece apuntando a result_buf; de lo contrario, *result se establece en NULL.

El buffer apuntado por h_errnop se utiliza para devolver el valor que se almacenaría en la variable global h_errno por las versiones no reentrantes de estas funciones.

VALOR DE RETORNO

En caso de éxito, estas funciones devuelven 0. En caso de error, devuelven uno de los números de error positivos enumerados en ERRORES.

En caso de error, registro no encontrado (getnetbyname_r(), getnetbyaddr_r()), o fin de entrada (getnetent_r()) result se establece en NULL.

ERRORES

ENOENT
(getnetent_r()) No hay más registros en la base de datos.
ERANGE
buf es demasiado pequeño. Inténtelo de nuevo con un buffer más grande (y un size incrementado).
