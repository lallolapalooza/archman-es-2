GETSUBOPT(3P) Manual del programador POSIX GETSUBOPT(3P)

PROLOG

Esta página del manual es parte del Manual del programador POSIX. La implementación de Linux de esta interfaz puede diferir (consulte la página del manual de Linux correspondiente para conocer los detalles del comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

getsubopt — analiza argumentos de subopción de una cadena

SINOPSIS

#include <stdlib.h>
int getsubopt(char **optionp, char * const *keylistp, char **valuep);

DESCRIPCIÓN

La función getsubopt() analiza argumentos de subopción en un argumento de bandera. Dichas opciones a menudo resultan del uso de getopt().

El argumento optionp de getsubopt() es un puntero a un puntero a la cadena del argumento de la opción. Los argumentos de subopción están separados por caracteres de <coma> y cada uno puede consistir en un solo token o en un par token-valor separado por un <signo-igual>.

El argumento keylistp es un puntero a un vector de cadenas. El final del vector se identifica mediante un puntero nulo. Cada entrada del vector es uno de los posibles tokens que pueden encontrarse en *optionp. Dado que los caracteres de <coma> delimitan los argumentos de subopción en optionp, no deben aparecer en ninguna de las cadenas a las que apunta keylistp. Del mismo modo, debido a que un <signo-igual> separa un token de su valor, la aplicación no debe incluir un <signo-igual> en ninguna de las cadenas a las que apunta keylistp. La función getsubopt() no modificará el vector keylistp.

El argumento valuep es la dirección de un puntero a la cadena de valor.

Si aparece una <coma> en optionp, se interpretará como un separador de subopción. Después de procesar los caracteres de <coma>, si hay uno o más caracteres de <signo-igual> en una cadena de subopción, el primer <signo-igual> en cualquier cadena de subopción se interpretará como un separador entre un token y un valor. Los caracteres de <signo-igual> posteriores en una cadena de subopción se interpretarán como parte del valor.

Si la cadena en *optionp contiene solo un argumento de subopción (equivalente, sin caracteres de <coma>), getsubopt() actualizará *optionp para que apunte al carácter nulo al final de la cadena. De lo contrario, reemplazará el separador de <coma> por un carácter nulo y actualizará *optionp para que apunte al inicio del siguiente argumento de subopción. Si el argumento de subopción tiene un valor asociado (equivalente, contiene un <signo-igual>), getsubopt() actualizará *valuep para que apunte al primer carácter del valor. De lo contrario, establecerá *valuep en un puntero nulo. La aplicación que llama puede utilizar esta información para determinar si la presencia o ausencia de un valor para la subopción es un error.

Además, cuando getsubopt() no logra hacer coincidir el argumento de subopción con un token en la matriz keylistp, la aplicación que llama debe decidir si esto es un error, o si la opción no reconocida debe procesarse de otra manera.

VALOR DE RETORNO

La función getsubopt() devolverá el índice de la cadena de token coincidente, o -1 si no se encontraron coincidencias de cadenas de token.

ERRORES

No se definen errores.

EJEMPLOS

Análisis de subopciones

El siguiente ejemplo utiliza la función getsubopt() para analizar un argumento value en la variable externa optarg devuelta por una llamada a getopt().

#include <stdio.h>
#include <stdlib.h>
#include <unistd.h>
int do_all;
const char *type;
int read_size;
int write_size;
int read_only;
enum
{
    RO_OPTION = 0,
    RW_OPTION,
    READ_SIZE_OPTION,
    WRITE_SIZE_OPTION
};
const char *mount_opts[] =
{
    [RO_OPTION] = "ro",
    [RW_OPTION] = "rw",
    [READ_SIZE_OPTION] = "rsize",
    [WRITE_SIZE_OPTION] = "wsize",
    NULL
};
int
main(int argc, char *argv[])
{
    char *subopts, *value;
    int opt;
    while ((opt = getopt(argc, argv, "at:o:")) != -1)
        switch(opt)
            {
            case 'a':
                do_all = 1;
                break;
            case 't':
                type = optarg;
                break;
            case 'o':
                subopts = optarg;
                while (*subopts != ' ')
                {
                    char *saved = subopts;
                    switch(getsubopt(&subopts, (char **)mount_opts,
                        &value))
                    {
                    case RO_OPTION:
                        read_only = 1;
                        break;
                    case RW_OPTION:
                        read_only = 0;
                        break;
                    case READ_SIZE_OPTION:
                        if (value == NULL)
                            abort();
                        read_size = atoi(value);
                        break;
                    case WRITE_SIZE_OPTION:
                        if (value == NULL)
                            abort();
                        write_size = atoi(value);
                        break;
                    default:
                        /* Subopción desconocida. */
                        printf("Subopción desconocida `%s'\n", saved);
                        abort();
                    }
                }
                break;
            default:
                abort();
            }
    /* Hacer el trabajo real. */
    return 0;
}

Si el ejemplo anterior se invoca con:

programa -o ro,rsize=512

entonces, después del análisis de opciones, la variable do_all será 0, type será un puntero nulo, read_size será 512, write_size será 0 y read_only será 1. Si se invoca con:

programa -o oops

imprimirá:

"Subopción desconocida `oops'"

antes de abortar.

USO DE LA APLICACIÓN

El valor de *valuep cuando getsubopt() devuelve -1 no está especificado. Las implementaciones históricas proporcionan varias extensiones incompatibles para permitir que una aplicación acceda al texto de la subopción que no se encontró en la matriz keylistp.

FUNDAMENTO

El argumento keylistp de getsubopt() tiene el tipo char * const * para que coincida con la práctica histórica. Sin embargo, el estándar es claro en que las implementaciones no modificarán ni la matriz ni las cadenas contenidas en la matriz, como si el argumento hubiera tenido el tipo const char * const *.
