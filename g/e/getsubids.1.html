NOMBRE

getsubids - obtener los rangos de IDs subordinados para un usuario

SINOPSIS

getsubids [opciones] USUARIO

DESCRIPCIÓN

El comando getsubids lista los rangos de IDs de usuario subordinados para un usuario dado. Los IDs de grupo subordinados se pueden listar usando la opción -g.

OPCIONES

Las opciones que se aplican al comando getsubids son:

-g

Lista los rangos de IDs de grupo subordinados.

-h

Muestra el mensaje de ayuda y sale.

EJEMPLO

Por ejemplo, para obtener los UIDs subordinados de testuser:

$ getsubids testuser
0: testuser 100000 65536

La salida de este comando proporciona (en orden de izquierda a derecha) el índice de la lista, el nombre de usuario, el inicio del rango de UID y el número de UIDs en el rango.
