DESCRIPCIÓ

N

gensio_control realiza una operación específica de gensio en el gensio (si depth es 0) o en uno de sus hijos ( depth > 0). Si depth es GENSIO_CONTROL_DEPTH_ALL, entonces se llamará a todos los hijos con los datos. Los errores GE_NOTSUP devueltos por gensios individuales se ignoran en ese caso, pero se detendrá en el primer error distinto a ese. Si depth es GENSIO_CONTROL_DEPTH_FIRST, se devolverá en el primer gensio que no devuelva GE_NOTSUP. Devuelve GE_NOTFOUND si nada lo

manejó.

Si especifica una profundidad (depth) >= 0, y la profundidad es mayor que el número de gensios en la pila, esto devolverá GE_NOTFOUND. De esta manera puede saber si llegó al fondo de la

pila.

La mayoría de los controles usan cadenas normales para la configuración, un control será de esta manera a menos que se especifique lo contrario. Algunos controles permiten que se pase información

binaria.

Si get es GENSIO_CONTROL_GET (true), intenta obtener la opción. No puede usar GENSIO_CONTROL_DEPTH_ALL con una obtención. Para obtener una opción, debe pasar datos lo suficientemente largos para contener la salida y establecer datalen en el número de bytes disponibles en data para la salida. Devolverá la longitud de la cadena (como strlen, sin incluir el nil final) o datos binarios en datalen

.

Una operación con get establecido en GENSIO_CONTROL_SET (false) es una operación de establecimiento (set), establecerá valores o controles en el gensio. Para valores de cadena, datalen no se usa en una operación de inserción (put) ni para determinar la longitud de la cadena de entrada en data, debe ser una cadena terminada en nil. Para valores binarios, datalen debe ser

proporcionado.

Todos los controles normales obtienen datos inmediatamente y no se

bloquean.

gensio_acontrol realiza un control que es asíncrono, lo que significa que no está terminado cuando la función devuelve. Si devuelve cero, la función de retorno done será llamada con el resultado cuando la operación complete. Todas las opciones de control asíncronas comienzan con GENSIO_ACONTROL_xxx. Los controles asíncronos no permiten GENSIO_CONTROL_DEPTH_ALL, solo pueden llamarse en un solo gensio en la

pila.

gensio_acontrol_s realiza un control asíncrono, pero espera hasta que la operación complete usando un esperador de funciones del sistema operativo (os function waiter)

.

Los valores de tiempo de espera (timeout) en las funciones acontrol son una pista para el código, puede o no tener algún efecto. Tampoco se actualiza necesariamente al tiempo restante. Para telnet, esto actualiza el tiempo por defecto para esperar un resultado. Para serialdev no tiene efecto, ya que esas operaciones son inmediatas. Se ignora para

ipmisol.

Una operación de obtención (get) siempre es idempotente (no cambiará nada, por lo que múltiples llamadas no tendrán ningún efecto en el estado del sistema). Una operación de obtención puede o no usar información pasada en data, y devuelve información en el campo d

ata.

Si la salida no cabe en una operación de obtención, datalen se actualiza a donde habría estado si hubiera tenido suficientes bytes (uno menos que el número total de bytes requeridos para controles de cadena), pero la salida en data se trunca (y se termina en nil si es posible para controles de cadena). Esto se puede usar para sondear para ver qué longitud de búfer se requiere pasando un *datalen cero, y luego asignando *datalen (+ 1 para gensios de cadena) y llamando a la función de nuevo con esos

datos.

Las operaciones de control de gensio en option dependen del gensio particular. A continuación se documentan algunos, pero puede haber otros controles disponibles. Vea la documentación de gensio en gensio(5) para

detalles.

Devuelve el objeto del certificado del extremo remoto. Esto es principalmente para SSL y certauth para que la aplicación pueda validar el nombre común del certificado, pero puede obtener cualquier objeto del

Hay dos formas de usar esta interfaz: obtener por índice u obtener por tipo de

Para obtener por índice, simplemente pase un número en los datos, como "0" y obtendrá el valor en ese

CONTROLES DE PUERTO

SERIE

Lo siguiente establece varios valores del puerto

serie.

En el cliente, esto establece el valor o solicita el valor del otro extremo. Al obtener los datos, el valor no se usa. Al establecer los datos, el valor es una cadena con un número o una configuración. La respuesta en el callback done informa de una cadena con el valor establecido (que puede ser diferente del valor solicitado) en el mismo formato que la

solicitud.

En el servidor, estos se utilizan para responder a un evento del cliente. El callback done se

ignora.

GENSIO_ACONTROL_SER_BAUD
es la velocidad en baudios como un número. Por ejemplo, establecer en "1200" establece 1200 baudios. No todos los gensios soportan todas las velocidades en

baudios.

GENSIO_ACONTROL_SER_DATASIZE
es el tamaño de datos, un número de "5" a "8". No todos los gensios soportan todos los tamaños de

datos.

GENSIO_ACONTROL_SER_PARITY
establece la paridad, una de "none", "odd", "even", "mark" o "space". Puedes usar gensio_parity_to_str y gensio_str_to_parity para convertir entre la cadena y los valores numéricos. gensio_parity_to_str devuelve NULL si el número no es válido, gensio_str_to_parity devuelve -1 si la cadena no es

válida.

GENSIO_ACONTROL_SER_STOPBITS
establece el número de bits de parada, "1" o

"2".

GENSIO_ACONTROL_SER_FLOWCONTROL
establece el tipo de control de flujo, uno de "none", "xonxoff" o "rtscts". Puedes usar gensio_flowcontrol_to_str y gensio_str_to_flowcontrol para convertir entre la cadena y los valores numéricos. gensio_flowcontrol_to_str devuelve NULL si el número no es válido, gensio_str_to_flowcontrol devuelve -1 si la cadena no es

válida.

GENSIO_ACONTROL_SER_IFLOWCONTROL
establece el estado del flujo de entrada, uno de "none", "dcd", "dtr" o "dsr". Usas las mismas funciones de conversión que GENSIO_ACONTROL_SER_FLOWCONTROL para convertir entre cadenas y

enteros.

GENSIO_ACONTROL_SER_SBREAK
Habilita o deshabilita la condición de break en un puerto serie. Uno de "on" o "off". Puedes usar gensio_onoff_to_str y gensio_str_to_onoff para convertir entre la cadena y los valores numéricos. gensio_onoff_to_str devuelve NULL si el número no es válido, gensio_str_to_onoff devuelve -1 si la cadena no es

válida.

GENSIO_ACONTROL_SER_DTR
Habilita o deshabilita la línea DTR en un puerto serie. Uno de "on" o "off". Ver GENSIO_ACONTROL_SER_SBREAK para las conversiones de

cadena/entero.

GENSIO_ACONTROL_SER_RTS
Habilita o deshabilita la línea RTS en un puerto serie. Uno de "on" o "off". Ver GENSIO_ACONTROL_SER_SBREAK para las conversiones de

cadena/entero.

GENSIO_ACONTROL_SER_CTS
Habilita o deshabilita la línea CTS en un puerto serie. Uno de "on" o "off". Solo ipmisol. Ver GENSIO_ACONTROL_SER_SBREAK para las conversiones de

cadena/entero.

GENSIO_ACONTROL_SER_DCD_DSR
Habilita o deshabilita las líneas DCD y DTR en un puerto serie. Uno de "on" o "off". Solo ipmisol. Ver GENSIO_ACONTROL_SER_SBREAK para las conversiones de

cadena/entero.

GENSIO_ACONTROL_SER_RI
Habilita o deshabilita la línea RI en un puerto serie. Uno de "on" o "off". Solo ipmisol. Ver GENSIO_ACONTROL_SER_SBREAK para las conversiones de

cadena/entero.

GENSIO_ACONTROL_SER_SIGNATURE
Obtiene o informa la firma rfc2217 de un puerto serie. Esta es una cadena arbitraria. Solo

telnet.

GENSIO_ACONTROL_SER_FLUSH
Envía un flush al otro extremo y obtiene la

respuesta.
