GENCCODE(8) Manual de ICU 78.1 GENCCODE(8)

NOMBRE

genccode - generar código C o ensamblado específico de plataforma a partir de un archivo de datos de ICU.

SINOPSIS

genccode [ -h, -?, --help ] [ -a, --assembly nombre ] [ -d, --destdir destino ] [ -n, --name nombre ] [ -e, --entrypoint nombre ] [ -f, --filename nombre ] [ nombre_archivo ... ]

DESCRIPCIÓN

genccode lee cada uno de los nombre_archivo suministrados y escribe un archivo C que contiene una definición compilable de los datos en el archivo de datos. El nombre del archivo C se crea tomando el nombre base del nombre_archivo de datos, reemplazando los puntos por guiones bajos y añadiendo la extensión de archivo .c.

Si se utiliza la opción -a, se genera código ensamblador específico de plataforma en lugar de código C. La mayoría de los compiladores C aceptarán archivos C y ensamblador. En lugar de escribir un nombre de archivo con la extensión de archivo .c, se escribirá un nombre de archivo con .s.

Si se llama a genccode sin ningún nombre_archivo, termina con gracia.

OPCIONES

-h, -?, --help
Imprime ayuda sobre el uso y sale.
-a, --assembly nombre
Genera código ensamblador en lugar de código C. Usa -h para ver la lista de tipos de ensamblado disponibles para generar y especificar para esta opción.
-d, --destdir destino
Establece el directorio de destino a destino. El directorio de destino predeterminado es el directorio actual.
-n, --name nombre
Establece el nombre de los datos a nombre en lugar del predeterminado. Este nombre también se usa como el nombre base de la salida. El nombre predeterminado se compone del prefijo icudt, seguido de un número de versión de dos dígitos correspondiente a la versión actual de la versión de ICU, y una sola letra que indica el orden de bytes de los datos (la letra b indica datos big endian, y la letra l indica ones little endian).
-f, --filename nombre
Normalmente, un archivo de datos de ICU como mydata.icu se convertirá en mydata_icu.c y mydata_icu.o. Sin embargo, si este parámetro se establece en "somedata", los archivos de salida serán somedata.o y somedata.c, respectivamente.
-e, --entrypoint nombre
Establece el punto de entrada de los datos (utilizado para enlazar con los datos en forma de biblioteca compartida) a nombre. El nombre del punto de entrada predeterminado se compone de los datos (establecidos por la opción -n, --name) seguidos de un guion bajo y el tipo de los datos (establecidos por la opción -t, --type).
