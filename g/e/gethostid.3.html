gethostid(3) Manual de funciones de biblioteca gethostid(3)

NOMBRE

gethostid, sethostid — obtener o establecer el identificador único del host actual

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <unistd.h>
long gethostid(void);
int sethostid(long hostid);
Requisitos de Macro de Prueba de Funciones para glibc (ver feature_test_macros(7)):

gethostid():

    Desde glibc 2.20:
        _DEFAULT_SOURCE || _XOPEN_SOURCE >= 500
    Hasta e incluyendo glibc 2.19:
        _BSD_SOURCE || _XOPEN_SOURCE >= 500

sethostid():

    Desde glibc 2.21:
        _DEFAULT_SOURCE
    En glibc 2.19 y 2.20:
        _DEFAULT_SOURCE || (_XOPEN_SOURCE && _XOPEN_SOURCE < 500)
    Hasta e incluyendo glibc 2.19:
        _BSD_SOURCE || (_XOPEN_SOURCE && _XOPEN_SOURCE < 500)

DESCRIPCIÓN

gethostid() y sethostid() respectivamente obtienen o establecen un identificador único de 32 bits para la máquina actual. El identificador de 32 bits estaba destinado a ser único entre todos los sistemas UNIX existentes. Esto normalmente se parece a la dirección de Internet para la máquina local, tal como la devuelve gethostbyname(3), y por lo tanto normalmente nunca necesita ser establecido.

La llamada sethostid() está restringida al superusuario.

VALOR DE RETORNO

gethostid() devuelve el identificador de 32 bits para el host actual establecido por sethostid().

En caso de éxito, sethostid() devuelve 0; en caso de error, se devuelve -1 y se establece errno para indicar el error.

ERRORES

sethostid() puede fallar con los siguientes errores:

EACCES
El llamador no tenía permiso para escribir en el archivo utilizado para almacenar el ID del host.
EPERM
El ID de usuario o grupo efectivo del proceso llamador no es el mismo que su ID real correspondiente.

ATRIBUTOS

Para una explicación de los términos utilizados en esta sección, ver attributes(7).

Interfaz Atributo Valor
gethostid () Seguridad de hilos MT-Safe hostid env locale
sethostid () Seguridad de hilos MT-Unsafe const:hostid

VERSIONES

En la implementación de glibc, el hostid se almacena en el archivo /etc/hostid. (Antes de glibc 2.2, se usaba el archivo /var/adm/hostid.)

En la implementación de glibc, si gethostid() no puede abrir el archivo que contiene el ID del host, obtiene el nombre del host usando gethostname(2), pasa ese nombre de host a gethostbyname_r(3) para obtener la dirección IPv4 del host y devuelve un valor obtenido mediante manipulación de bits de la dirección IPv4. (Este valor puede no ser único).

ESTÁNDARES

gethostid()
POSIX.1-2008.
sethostid()
Ninguno.

HISTORIA

4.2BSD; eliminado en 4.4BSD. SVr4 y POSIX.1-2001 incluyen gethostid() pero no sethostid().

BUGS

Es imposible garantizar que el identificador sea globalmente único.

VER TAMBIÉN

hostid(1), gethostbyname(3)
