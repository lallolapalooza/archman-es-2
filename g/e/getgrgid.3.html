DESCRIPCIÓ

N

La función getgrnam() devuelve un puntero a una estructura que contiene los campos desglosados del registro en la base de datos de grupos (por ejemplo, el archivo de grupos local /etc/group, NIS y LDAP) que coincide con el nombre de grupo name

.

La función getgrgid() devuelve un puntero a una estructura que contiene los campos desglosados del registro en la base de datos de grupos que coincide con el ID de grupo gid

.

La estructura group está definida en <grp.h> de la siguiente

manera: 


struct group {
    char   *gr_name;        /* group name */
    char   *gr_passwd;      /* group password */
    gid_t   gr_gid;         /* group ID */
    char  **gr_mem;         /* NULL-terminated array of pointers
                               to names of group members */
}
;

Para más información sobre los campos de esta estructura, véase group(

5).

Las funciones getgrnam_r() y getgrgid_r() obtienen la misma información que getgrnam() y getgrgid(), pero almacenan la estructura group recuperada en el espacio apuntado por grp. Los campos de cadena apuntados por los miembros de la estructura group se almacenan en el búfer buf de tamaño size. Un puntero al result (en caso de éxito) o NULL (en caso de que no se haya encontrado ninguna entrada o se haya producido un error) se

almacena en *result.

Las funciones getgrnam() y getgrgid() devuelven un puntero a una estructura group, o NULL si la entrada que coincide no se encuentra o se produce un error. Si se produce un error, errno se establece para indicar el error. Si se desea comprobar errno después de la llamada, debe establecerse a cero antes de la

llamada.

El valor de retorno puede apuntar a un área estática y puede ser sobrescrito por llamadas posteriores a getgrent(3), getgrgid() o getgrnam(). (No pase el puntero devuelto a free(3).

    getgrgid(3)

    getgrgid, getgrnam - obtener información del grupo por ID o nombre

    NOMBRE

    getgrgid, getgrnam - obtener información del grupo por ID o nombre

    SINOPSIS

    #include <sys/types.h>
#include <grp.h>

struct group *getgrgid(gid_t gid);
struct group *getgrnam(const char *name);
int getgrgid_r(gid_t gid, struct group *grp, char *buf, size_t buflen, struct group **result);
int getgrnam_r(const char *name, struct group *grp, char *buf, size_t buflen, struct group **result);

    DESCRIPCIÓN

    Las funciones getgrgid() y getgrnam() buscan en la base de datos de grupos (generalmente el archivo /etc/group o un origen de nombres de red como NIS) para encontrar una entrada para el grupo especificado por el ID de grupo numérico gid o por el nombre de grupo name.

    La estructura group se define en <grp.h> y contiene la siguiente información sobre un grupo:

    struct group {
        char   *gr_name;        /* nombre del grupo */
        char   *gr_passwd;      /* contraseña del grupo cifrada */
        gid_t   gr_gid;         /* ID de grupo numérico */
        char  **gr_mem;         /* lista terminada en NULL de miembros del grupo */
    };

    Si se encuentra una entrada, las funciones devuelven un puntero a una estructura group que contiene la información del grupo. El puntero se refiere a una estructura estática que puede ser sobrescrita por llamadas posteriores a la misma función, o por llamadas a otras funciones de la biblioteca de consulta de bases de datos (como getpwnam(), getpwuid(), gethostbyname(), etc.).

    Las funciones getgrgid_r() y getgrnam_r() son versiones reentrantes de getgrgid() y getgrnam(). Toman un puntero a una estructura group (grp), un búfer (buf) y la longitud del búfer (buflen) como argumentos adicionales. La estructura group devuelta se almacena en la ubicación apuntada por grp. Toda la memoria utilizada por la estructura devuelta se asigna del búfer proporcionado por buf. El puntero result se establece en un puntero a la estructura group devuelta si la llamada tiene éxito, o en NULL si no se encuentra ningún grupo o si ocurre un error. Si un grupo se encuentra correctamente, getgrgid_r() y getgrnam_r() devuelven 0. Si no se encuentra ningún grupo, devuelven un valor de error distinto de cero y establecen result en NULL. Si el búfer proporcionado no es lo suficientemente grande, devuelven ERANGE.

    La interfaz de búsqueda reentrante se describe en gethostbyname_r(3).

    VALOR DE RETORNO

    En caso de éxito, getgrgid() y getgrnam() devuelven un puntero a una estructura group. Si no se encuentra ningún grupo, devuelven NULL y establecen h_errno en NETDB_INTERNAL (si se produce un error en la búsqueda) o 0 (si no se encuentra ninguna entrada).

    Las funciones getgrgid_r() y getgrnam_r() devuelven 0 si se encuentra un grupo, y un número de error distinto de cero en caso contrario. Si no se encuentra ningún grupo, establecen result en NULL. Si el búfer no es lo suficientemente grande, devuelven ERANGE.

    ERRORES

    No hay errores definidos en la especificación POSIX. Las implementaciones pueden establecer errno en caso de error de EIO, ENFILE, ENOMEM o ENOTDIR.

    ARCHIVOS

    /etc/group
    Archivo de base de datos de grupos local.

    ESTÁNDARES

    getgrgid(), getgrnam() son conformes a POSIX.1-2001, POSIX.1-2008, SVr4, XPG4.

    getgrgid_r(), getgrnam_r() son conformes a POSIX.1-2001, POSIX.1-2008.

    La función getgrnam() apareció en AT&T UNIX System V.

    La función getgrnam_r() apareció en FreeBSD 2.0.
