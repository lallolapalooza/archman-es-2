NOMBRE

gensio_acc_set_sync, gensio_acc_accept_s, gensio_acc_accept_s_intr - Operaciones de E/S síncronas en un aceptador gensio

SINOPSIS

#include <gensio/gensio.h>

int gensio_acc_set_sync(struct gensio_accepter *acc);
int gensio_acc_accept_s(struct gensio_accepter *acc,

struct gensio_time *timeout,
struct gensio **new_io);
int gensio_acc_accept_s_intr(struct gensio_accepter *acc,

struct gensio_time *timeout,
struct gensio **new_io);

DESCRIPCIÓN

La operación normal del aceptador gensio se basa en devoluciones de llamada asíncronas. Esto sirve a la mayoría de los programas bastante bien, especialmente si necesitan manejar múltiples aceptaciones en el mismo o diferentes aceptadores.

Pero ocasionalmente, necesitas hacer algo síncrono con la ejecución del programa, especialmente si tienes un programa simple que solo acepta una conexión y luego hace algo.

gensio_acc_set_sync configura el aceptador gensio para aceptaciones síncronas. Si haces esto, la devolución de llamada de eventos que está actualmente registrada ya no recibirá eventos de nuevas conexiones. *Sí* recibirá otras devoluciones de llamada. Debes llamar a esto antes de iniciar el aceptador gensio, y una vez que lo llames, el aceptador gensio estará en modo síncrono hasta que lo cierres.

gensio_accept_s espera una conexión entrante en el aceptador gensio. Esta función espera durante la cantidad de tiempo en timeout. timeout se actualiza a la cantidad de tiempo restante para esperar. Si timeout es NULL, espera para siempre. Si no se devuelve ningún error, la nueva conexión entrante se devuelve en new_io.

gensio_accept_s_intr es como gensio_accept_s, pero devuelve inmediatamente si ocurre una interrupción de señal. En sistemas sin señales, esto es lo mismo que gensio_accept_s.

VALORES DE RETORNO

Se devuelve cero en caso de éxito, o un error de gensio en caso de fallo.
