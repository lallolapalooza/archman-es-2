DESCRIPCIÓ

N

getlogin() devuelve un puntero a una cadena que contiene el nombre del usuario que ha iniciado sesión en el terminal de control del proceso, o un puntero nulo si esta información no se puede determinar. La cadena es asignada estáticamente y podría ser sobrescrita en llamadas posteriores a esta función o a cuserid

().

getlogin_r() devuelve este mismo nombre de usuario en el array buf de tamaño bufsize

.

cuserid() devuelve un puntero a una cadena que contiene un nombre de usuario asociado con el ID de usuario efectivo del proceso. Si string no es un puntero nulo, debería ser un array que pueda contener al menos L_cuserid caracteres; la cadena se devuelve en este array. De lo contrario, se devuelve un puntero a una cadena en un área estática. Esta cadena es asignada estáticamente y podría ser sobrescrita en llamadas posteriores a esta función o a getlogi

n().

La macro L_cuserid es una constante entera que indica qué tan largo podría necesitar ser un array para almacenar un nombre de usuario. L_cuserid está declarada en <stdio.h>

.

Estas funciones permiten a tu programa identificar positivamente al usuario que está ejecutando (cuserid()) o al usuario que inició sesión en esta sesión (getlogin()). (Estos pueden diferir cuando se involucran programas con ID de usuario establecido.

)

Para la mayoría de los propósitos, es más útil usar la variable de entorno LOGNAME para averiguar quién es el usuario. Esto es más flexible precisamente porque el usuario puede establecer LOGNAME arbi

traria
mente.

ERRORE

S

Desafortunadamente, a menudo es bastante fácil engañar a getlogin(). A veces no funciona en absoluto, porque algún programa arruinó el archivo utmp. A menudo, solo da los primeros 8 caracteres del nombre de inicio de sesión. El usuario que actualmente ha iniciado sesión en el terminal de control de nuestro programa no necesita ser el usuario que lo inició. Evita getlogin() para propósitos relacionados con la

seguridad.

Ten en cuenta que glibc no sigue la especificación POSIX y usa stdin en lugar de /dev/tty. Un error. (Otros sistemas recientes, como SunOS 5.8 y HP-UX 11.11 y FreeBSD 4.8, todos devuelven el nombre de inicio de sesión también cuando stdin está redirigido.

)

Nadie sabe con precisión qué hace cuserid(); evítalo en programas portables. O evítalo por completo: usa getpwuid(geteuid()) en su lugar, si eso es lo que pretendías. No uses cuser

id(
).
