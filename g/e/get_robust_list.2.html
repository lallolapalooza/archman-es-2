get_robust_list(2) Manual de llamadas al sistema get_robust_list(2)

NOMBRE

get_robust_list, set_robust_list - obtener/establecer lista de futex robustos

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <linux/futex.h>   /* Definición de struct robust_list_head */
#include <sys/syscall.h>   /* Definición de constantes SYS_* */
#include <unistd.h>
long syscall(SYS_get_robust_list, int pid,
             struct robust_list_head **head_ptr, size_t *sizep);
long syscall(SYS_set_robust_list,
             struct robust_list_head *head, size_t size);

Nota: glibc no proporciona envolturas para estas llamadas al sistema, lo que hace necesario el uso de syscall(2).

DESCRIPCIÓN

Estas llamadas al sistema manejan listas de futex robustos por hilo. Estas listas se gestionan en el espacio de usuario: el kernel solo conoce la ubicación de la cabeza de la lista. Un hilo puede informar al kernel de la ubicación de su lista de futex robustos usando set_robust_list(). La dirección de la lista de futex robustos de un hilo se puede obtener usando get_robust_list().

El propósito de la lista de futex robustos es asegurar que si un hilo falla accidentalmente al desbloquear un futex antes de terminar o llamar a execve(2), otro hilo que está esperando en ese futex sea notificado de que el propietario anterior del futex ha muerto. Esta notificación consta de dos partes: el bit FUTEX_OWNER_DIED se establece en la palabra futex, y el kernel realiza una operación futex(2) FUTEX_WAKE en uno de los hilos que esperan en el futex.

La llamada al sistema get_robust_list() devuelve la cabeza de la lista de futex robustos del hilo cuyo ID de hilo se especifica en pid. Si pid es 0, se devuelve la cabeza de la lista para el hilo que llama. La cabeza de la lista se almacena en la ubicación apuntada por head_ptr. El tamaño del objeto apuntado por **head_ptr se almacena en sizep.

El permiso para emplear get_robust_list() se rige por una verificación de modo de acceso ptrace PTRACE_MODE_READ_REALCREDS; ver ptrace(2).

La llamada al sistema set_robust_list() solicita al kernel que registre la cabeza de la lista de futex robustos propiedad del hilo que llama. El argumento head es la cabeza de lista a registrar. El argumento size debe ser sizeof(*head).

VALOR DE RETORNO

Las llamadas al sistema set_robust_list() y get_robust_list() devuelven cero cuando la operación es exitosa, un código de error en caso contrario.

ERRORES

La llamada al sistema set_robust_list() puede fallar con el siguiente error:

EINVAL
size no es igual a sizeof(struct robust_list_head).

La llamada al sistema get_robust_list() puede fallar con los siguientes errores:

EFAULT
La cabeza de la lista de futex robustos no se puede almacenar en la ubicación head.
EPERM
El proceso que llama no tiene permiso para ver la lista de futex robustos del hilo con el ID de hilo pid, y no tiene la capacidad CAP_SYS_PTRACE.
ESRCH
No se encontró ningún hilo con el ID de hilo pid.

VERSIÓNES

Estas llamadas al sistema se añadieron en Linux 2.6.17.

NOTAS

Estas llamadas al sistema no son necesarias para aplicaciones normales.

Un hilo solo puede tener una lista de futex robustos; por lo tanto, las aplicaciones que deseen utilizar esta funcionalidad deberían usar los mutex robustos proporcionados por glibc.

En la implementación inicial, un hilo que esperaba en un futex solo era notificado de que el propietario había muerto si el propietario terminaba. A partir de Linux 2.6.28, la notificación se extendió para incluir el caso en que el propietario realiza un execve(2).

Los ID de hilo mencionados en el texto principal son ID de hilo del *kernel* del tipo devuelto por clone(2) y gettid(2).
