getgrouplist(3) Manual de funciones de biblioteca getgrouplist(3)

NOMBRE

getgrouplist - obtener la lista de grupos a los que pertenece un usuario

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <grp.h>
int getgrouplist(const char *user, gid_t group,
                 gid_t *groups, int *ngroups);
Requisitos de la Macro de Prueba de Funcionalidades para glibc (ver feature_test_macros(7)):

getgrouplist():

    Desde glibc 2.19:
        _DEFAULT_SOURCE
    glibc 2.19 y anteriores:
        _BSD_SOURCE

DESCRIPCIÓN

La función getgrouplist() escanea la base de datos de grupos (ver group(5)) para obtener la lista de grupos a los que pertenece user. Se devuelven hasta *ngroups de estos grupos en la matriz groups.

Si group no estaba entre los grupos definidos para user en la base de datos de grupos, entonces group se incluye en la lista de grupos devuelta por getgrouplist(); típicamente este argumento se especifica como el ID de grupo del registro de contraseña para user.

El argumento ngroups es un argumento de valor-resultado: al regresar, siempre contiene el número de grupos encontrados para user, incluido group; este valor puede ser mayor que el número de grupos almacenados en groups.

VALOR DEVUELTO

Si el número de grupos de los que user es miembro es menor o igual a *ngroups, entonces se devuelve el valor *ngroups.

Si el usuario es miembro de más de *ngroups grupos, entonces getgrouplist() devuelve -1. En este caso, el valor devuelto en *ngroups puede usarse para redimensionar el búfer pasado a una llamada posterior a getgrouplist().

ESTÁNDARES

Ninguno.

HISTORIA

glibc 2.2.4.

ERRORES

Antes de glibc 2.3.3, la implementación de esta función contenía un error de desbordamiento de búfer: devuelve la lista completa de grupos para user en la matriz groups, incluso cuando el número de grupos excede *ngroups.

EJEMPLOS

El programa a continuación muestra la lista de grupos para el usuario nombrado en su primer argumento de línea de comandos. El segundo argumento de línea de comandos especifica el valor ngroups a proporcionar a getgrouplist(). La siguiente sesión de shell muestra ejemplos de uso de este programa:


$ ./a.out cecilia 0
getgrouplist() devolvió -1
ngroups = 3
$ ./a.out cecilia 3
ngroups = 3
16 (dialout)
33 (video)
100 (users)

Código fuente del programa

#include <errno.h>
#include <grp.h>
#include <pwd.h>
#include <stdio.h>
#include <stdlib.h>
int
main(int argc, char *argv[])
{
    int            ngroups;
    gid_t          *groups;
    struct group   *gr;
    struct passwd  *pw;
    if (argc != 3) {
        fprintf(stderr, "Uso: %s <usuario> <ngroups>\n", argv[0]);
        exit(EXIT_FAILURE);
    }
    ngroups = atoi(argv[2]);
    groups = malloc(sizeof(*groups) * ngroups);
    if (groups == NULL) {
        perror("malloc");
        exit(EXIT_FAILURE);
    }
    /* Obtener la estructura passwd (contiene el primer ID de grupo para el usuario).  */
    errno = 0;
    pw = getpwnam(argv[1]);
    if (pw == NULL) {
        if (errno)
            perror("getpwnam");
        else
            fprintf(stderr, "usuario no existe\n");
        exit(EXIT_FAILURE);
    }
    /* Recuperar la lista de grupos.  */
    if (getgrouplist(argv[1], pw->pw_gid, groups, &ngroups) == -1) {
        fprintf(stderr, "getgrouplist() devolvió -1\n");
        fprintf(stderr, "ngroups = %d\n", ngroups);
        exit(EXIT_FAILURE);
    }
    /* Mostrar la lista de grupos recuperados, junto con los nombres de los grupos.  */
    fprintf(stderr, "ngroups = %d\n", ngroups);
    for (int j = 0; j < ngroups; j++) {
        printf("%d", groups[j]);
        gr = getgrgid(groups[j]);
        if (gr != NULL)
            printf(" (%s)", gr->gr_name);
        printf("\n");
    }
    exit(EXIT_SUCCESS);
}
