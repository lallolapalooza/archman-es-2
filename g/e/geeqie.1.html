Todos los demás parámetros de línea de comandos se utilizan como archivos simples si existen, o una URL o una carpeta. Se puede utilizar el nombre de una colección, con o sin ruta o extensión (.
gqv).
Si hay más de una carpeta en la línea de comandos, solo se utilizará la
última.
Si hay más de un archivo en la línea de
comandos:
Si están en la misma carpeta, se abrirá esa carpeta y esos archivos seránseleccionados. Si no están en la misma carpeta, se abrirá una nueva Colección que contenga esos
archivos.
Para ejecutar Geeqie como una nueva instancia, use: GQ_NEW_INSTANCE=y[es] geeqie Normalmente se usa un único conjunto de archivos de configuración para todas las instancias. Sin embargo, las variables de entorno XDG_CONFIG_HOME, XDG_CACHE_HOME, XDG_DATA_HOME pueden usarse para modificar este comportamiento de forma individual p. ej. XDG_CONFIG_HOME=/tmp/a XDG_CACHE_HOME=/tmp/b GQ_NEW_INSTANCE=y
geeqie
