getlogin(3) Manual de Funciones de Biblioteca getlogin(3)

NOMBRE

getlogin, getlogin_r, cuserid - obtener el nombre de usuario

BIBLIOTECA

Biblioteca C estándar (libc,-lc)

SINOPSIS

#include <unistd.h>
char *getlogin(void);
int getlogin_r(size_t bufsize;
               char buf[bufsize], size_t bufsize);
#include <stdio.h>
char *cuserid(char *string);
Requisitos de la macro de prueba de características para glibc (ver feature_test_macros(7)):

getlogin_r():

    _POSIX_C_SOURCE >= 199506L

cuserid():

    Desde glibc 2.24:
        (_XOPEN_SOURCE && ! (_POSIX_C_SOURCE >= 200112L)
            || _GNU_SOURCE
    Hasta e incluyendo glibc 2.23:
        _XOPEN_SOURCE

DESCRIPCIÓN

getlogin() devuelve un puntero a una cadena que contiene el nombre del usuario que ha iniciado sesión en la terminal de control del proceso, o un puntero nulo si esta información no se puede determinar. La cadena está asignada estáticamente y puede ser sobrescrita en llamadas posteriores a esta función o a cuserid().

getlogin_r() devuelve este mismo nombre de usuario en el array buf de tamaño bufsize.

cuserid() devuelve un puntero a una cadena que contiene un nombre de usuario asociado con el ID de usuario efectivo del proceso. Si string no es un puntero nulo, debería ser un array que pueda contener al menos L_cuserid caracteres; la cadena se devuelve en este array. De lo contrario, se devuelve un puntero a una cadena en un área estática. Esta cadena está asignada estáticamente y puede ser sobrescrita en llamadas posteriores a esta función o a getlogin().

La macro L_cuserid es una constante entera que indica qué tan largo podría necesitar ser un array para almacenar un nombre de usuario. L_cuserid está declarada en <stdio.h>.

Estas funciones permiten que su programa identifique positivamente al usuario que se está ejecutando (cuserid()) o al usuario que inició esta sesión (getlogin()). (Estos pueden diferir cuando están involucrados programas con ID de usuario establecido.)

Para la mayoría de los propósitos, es más útil usar la variable de entorno LOGNAME para averiguar quién es el usuario. Esto es más flexible precisamente porque el usuario puede establecer LOGNAME arbitrariamente.

VALOR DE RETORNO

getlogin() devuelve un puntero al nombre de usuario cuando tiene éxito, y NULL en caso de fallo, con errno establecido para indicar el error. getlogin_r() devuelve 0 cuando tiene éxito, y distinto de cero en caso de fallo.

ERRORES

POSIX especifica:

EMFILE
Se ha alcanzado el límite por proceso del número de descriptores de archivo abiertos.
ENFILE
Se ha alcanzado el límite del sistema para el número total de archivos abiertos.
ENXIO
El proceso que llama no tiene terminal de control.
ERANGE
(getlogin_r) La longitud del nombre de usuario, incluyendo el byte nulo finalizador ('\0'), es mayor que bufsize.

Linux/glibc también tiene:

ENOENT
No había una entrada correspondiente en el archivo utmp.
ENOMEM
Memoria insuficiente para asignar la estructura passwd.
ENOTTY
La entrada estándar no se refería a una terminal. (Ver ERRORES.)

ARCHIVOS

/etc/passwd
archivo de base de datos de contraseñas
/var/run/utmp
(tradicionalmente /etc/utmp; algunas versiones de libc usaban /var/adm/utmp)

ATRIBUTOS

Para una explicación de los términos usados en esta sección, ver attributes(7).

Interfaz Atributo Valor
getlogin () Seguridad de hilos MT-Unsafe race:getlogin race:utent sig:ALRM timer locale
getlogin_r () Seguridad de hilos MT-Unsafe race:utent sig:ALRM timer locale
cuserid () Seguridad de hilos MT-Unsafe race:cuserid/!string locale

En la tabla anterior, utent en race:utent significa que si alguna de las funciones setutent(3), getutent(3), o endutent(3) se usan en paralelo en diferentes hilos de un programa, podrían ocurrir condiciones de carrera de datos. getlogin() y getlogin_r() llaman a esas funciones, por lo que usamos race:utent para recordar a los usuarios.

VERSIONES

OpenBSD tiene getlogin() y setlogin(), y un nombre de usuario asociado con una sesión, incluso si no tiene terminal de control.

ESTÁNDARES

getlogin()
getlogin_r()
POSIX.1-2008.
cuserid()
Ninguno.

ESTÁNDARES

getlogin()
getlogin_r():
POSIX.1-2001. OpenBSD.
cuserid()
System V, POSIX.1-1988. Eliminado en POSIX.1-1990. SUSv2. Eliminado en POSIX.1-2001.
System V tiene una función cuserid() que usa el ID de usuario real en lugar del ID de usuario efectivo.

ERRORES

Desafortunadamente, a menudo es bastante fácil engañar a getlogin(). A veces no funciona en absoluto, porque algún programa desordenó el archivo utmp. A menudo, solo da los primeros 8 caracteres del nombre de inicio de sesión. El usuario que actualmente ha iniciado sesión en la terminal de control de nuestro programa no necesita ser el usuario que lo inició. Evite getlogin() para propósitos relacionados con la seguridad.

Tenga en cuenta que glibc no sigue la especificación POSIX y usa stdin en lugar de /dev/tty. Un error. (Otros sistemas recientes, como SunOS 5.8 y HP-UX 11.11 y FreeBSD 4.8, también devuelven el nombre de inicio de sesión cuando stdin está redirigido.)

Nadie sabe con precisión qué hace cuserid(); evítela en programas portátiles. O evítela por completo: use getpwuid(geteuid()) en su lugar, si eso es lo que pretendía. No use cuserid().

VER TAMBIÉN
