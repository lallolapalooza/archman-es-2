GEOIPLOOKUP6(1) Manual de Comandos Generales GEOIPLOOKUP6(1)

NOMBRE

geoiplookup6 - buscar país usando dirección IP o nombre de host

SINOPSIS

geoiplookup6 [-d directorio] [-f archivo] [-v] <direccionip|nombrehost>

DESCRIPCIÓN

geoiplookup6 utiliza la biblioteca GeoIP y la base de datos para encontrar el País de origen de una dirección IP o nombre de host. Debes instalar una base de datos adecuada para geoiplookup6. Ej: GeoIPv6.dat

Por ejemplo:

geoiplookup6 2001:4860:0:1001::68

geoiplookup6 ipv6.google.com

encontrará el País de origen de 2001:4860:0:1001::68, en el siguiente formato:

US, Estados Unidos

OPCIONES

-f
Especificar una ruta personalizada a un solo archivo de datos GeoIP.
-d
Especificar un directorio personalizado que contenga archivo(s) de datos GeoIP. Por defecto, geoiplookup6 busca en /usr/share/GeoIP.
-v
Lista la fecha y el número de compilación para el(los) archivo(s) de datos GeoIP.
