getsid(2) Manual de Llamadas al Sistema getsid(2)

NOMBRE

getsid - obtener ID de sesión

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <unistd.h>
pid_t getsid(pid_t pid);
Requisitos de Macro de Prueba de Funcionalidad para glibc (ver feature_test_macros(7)):

getsid():

    _XOPEN_SOURCE >= 500
        || /* Desde glibc 2.12: */ _POSIX_C_SOURCE >= 200809L

DESCRIPCIÓN

getsid() devuelve el ID de sesión del proceso con ID de proceso pid. Si pid es 0, getsid() devuelve el ID de sesión del proceso que llama.

VALOR DE RETORNO

En caso de éxito, se devuelve un ID de sesión. En caso de error, se devuelve (pid_t) -1 y se establece errno para indicar el error.

ERRORES

EPERM
Existe un proceso con el ID de proceso pid, pero no está en la misma sesión que el proceso que llama, y la implementación considera esto un error.
ESRCH
No se encontró ningún proceso con el ID de proceso pid.

VERSIONES

Linux no devuelve EPERM.

ESTÁNDARES

POSIX.1-2024.

HISTORIA

POSIX.1-2001, SVr4. Linux 2.0.

NOTAS

Ver credentials(7) para una descripción de las sesiones y los IDs de sesión.

VER TAMBIÉN

getpgid(2), setsid(2), credentials(7)
