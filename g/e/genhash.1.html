NOMBRE

genhash - herramienta de generación de hash md5 para páginas web remotas

SINOPSIS

keepalived --genhash [opciones] [-s dirección-servidor] [-p puerto] [-u url]

DESCRIPCIÓN

genhash es una herramienta utilizada para generar sumas md5 de páginas web remotas. genhash puede utilizar HTTP o HTTPS para conectarse a la página web. La salida de esta utilidad incluye la cabecera HTTP, los datos de la página y la suma md5 de los datos. Esta suma md5 puede ser utilizada posteriormente en el programa keepalived(8), para la monitorización de servicios HTTP y HTTPS.

OPCIONES

--use-ssl, -S
Utiliza SSL para conectarse al servidor.
--server <host>, -s
Especifica la dirección IP a la que conectarse.
--port <puerto>, -p
Especifica el puerto al que conectarse.
--url <url>, -u
Especifica la ruta al archivo del que quieres generar el hash.
--use-virtualhost <host>, -V
Especifica el host virtual a enviar junto con las cabeceras HTTP.
--protocol <version-protocol>, -P
Especifica la versión del protocolo HTTP a utilizar. version-protocol puede ser 1.0, 1.1 o 1.0c. 1.0c significa versión del protocolo 1.0 pero con una línea "Connection: close"; esta se incluye por defecto en la versión 1.1.
--timeout <timeout>, -t
Especifica el tiempo de espera de la conexión en segundos.
--fwmark <marca>, -m
Establece la marca de firewall especificada en el socket
--verbose, -v
Sea verboso con la salida.
--help, -h
Muestra la pantalla de ayuda del programa y sale.
