GEARMAN(1) Gearmand GEARMAN(1)

NOMBRE

gearman - Documentación de Gearmand, https://gearman.org/gearmand/

Cliente de línea de comandos para Gearmand

SINOPSIS

Opciones comunes

-f <función>
Nombre de la función a usar para trabajos (se pueden dar varias)
-h <host>
Host del servidor de trabajos
-H
Muestra este menú de ayuda
-p <puerto>
Puerto del servidor Gearman
-t <tiempo_espera>
Tiempo de espera en milisegundos
-i <archivo_pid>
Crea un archivo de PID para el proceso
-n
En modo cliente, ejecuta un trabajo por línea; en modo trabajador, envía un paquete de datos por cada línea
-N
Igual que -n, pero elimina el salto de línea

Opciones del cliente

-b
Ejecuta trabajos en segundo plano
-I
Ejecuta trabajos con alta prioridad
-L
Ejecuta trabajos con baja prioridad
-P
Prefija todas las líneas de salida con los nombres de las funciones
-s
Envía el trabajo sin leer de la entrada estándar
-u <único>
Clave única a usar para el trabajo

Opciones del trabajador*

-c <contador>
Número de trabajos que el trabajador ejecutará antes de salir
-w
Ejecuta en modo trabajador

DESCRIPCIÓN

Con gearman puedes ejecutar funciones de cliente y trabajador desde la línea de comandos.

La variable de entorno GEARMAN_SERVER se puede usar para especificar múltiples servidores gearmand. Por favor, consulta la c:func:'gearman_client_add_servers' para una explicación de la sintaxis requerida.

INICIO

Para obtener más información, consulta: https://gearman.org/gearmand/
