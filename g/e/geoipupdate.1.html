NOMBRE

geoipupdate - Programa de actualización de GeoIP2 y GeoLite2

SINOPSIS

geoipupdate [-Vvh] [-f ARCHIVO_CONFIG] [-d DIRECTORIO_OBJETIVO]

DESCRIPCIÓN

geoipupdate actualiza automáticamente las bases de datos GeoIP2 y GeoLite2. El programa se conecta al servidor GeoIP Update de MaxMind para comprobar si hay bases de datos nuevas. Si hay una base de datos nueva disponible, el programa la descargará e instalará.

Si está utilizando un cortafuegos, debe tener abiertos los puertos DNS y HTTPS.

OPCIONES

-d, --directorio-base-datos
Instala las bases de datos en un directorio personalizado. Esto es opcional. Si se proporciona, anula el valor de DatabaseDirectory del archivo de configuración y la variable de entorno GEOIPUPDATE_DB_DIR.
-f, --archivo-configuracion
El archivo de configuración a utilizar. Consulte GeoIP.conf y su documentación para obtener más información. Es opcional. Por defecto, utiliza la variable de entorno GEOIPUPDATE_CONF_FILE si está establecida, o /etc/GeoIP.conf en caso contrario.
--paralelismo
Establece el número de descargas de bases de datos en paralelo.
-h, --ayuda
Muestra la ayuda y sale.
--traza-pila
Muestra una traza de pila en caso de cualquier mensaje de error. Esto es principalmente útil para la depuración.
-V, --version
Muestra la información de la versión y sale.
-v, --verbose
Habilita el modo detallado. Imprime los pasos que sigue geoipupdate. Si se proporciona, anula cualquier variable de entorno GEOIPUPDATE_VERBOSE.
-o, --salida
Muestra los resultados de la descarga/actualización en formato JSON.

ESTADO DE SALIDA

geoipupdate devuelve 0 en caso de éxito y 1 en caso de error.

NOTAS

Normalmente, deberías ejecutar geoipupdate al menos dos veces por semana. Consulta nuestro calendario de lanzamientos de bases de datos para obtener más información.

En la mayoría de los sistemas tipo Unix, esto se puede lograr utilizando cron. Puedes encontrar un ejemplo de archivo crontab en nuestro Portal de Desarrolladores.

Para usar con un servidor proxy, actualiza tu archivo GeoIP.conf como se especifica en la página del manual de GeoIP.conf. Alternativamente, establece la variable de entorno GEOIPUPDATE_PROXY o http_proxy.
