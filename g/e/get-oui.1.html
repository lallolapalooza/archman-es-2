NOMBRE

get-oui - Obtiene el archivo OUI de arp-scan del sitio web de IEEE

SINOPSIS

get-oui [opciones]

DESCRIPCIÓN

get-oui obtiene los datos del registro MAC/Vendedor del sitio web de IEEE y los convierte al formato utilizado por arp-scan. Se descargan y procesan los contenidos de los siguientes registros:

MA-L 24 bits El registro OUI original
MA-M 28 bits Registro de bloque de direcciones medianas
MA-S 36 bits Registro de bloque de direcciones pequeñas (OUI-36)
IAB 36 bits El registro IAB (cerrado para nuevas aplicaciones)

Este script crea ieee-oui.txt a partir de los últimos datos del sitio web de IEEE. Puedes ejecutar get-oui ocasionalmente para mantener el archivo OUI actualizado.

Los datos OUI se obtienen de las URL especificadas en el script get-oui y el archivo de salida se guarda en el archivo ieee-oui.txt en el directorio actual. El nombre del archivo de salida se puede cambiar con la opción -f.

El archivo ieee-oui.txt producido por este script es utilizado por arp-scan para determinar el vendedor de la tarjeta Ethernet a partir de su dirección de hardware.

arp-scan primero buscará ieee-oui.txt en el directorio actual. Si falla, usará el archivo global del sistema /usr/share/arp-scan/ieee-oui.txt.

OPCIONES

-h
Muestra un breve mensaje de uso y sale.
-f <fn>
Escribe la salida en el archivo especificado en lugar del predeterminado ieee-oui.txt.
-v
Muestra mensajes de progreso detallados.

ARCHIVOS

ieee-oui.txt
El archivo de salida predeterminado.

NOTAS

get-oui está implementado en Perl, por lo que necesitas tener el intérprete de Perl instalado en tu sistema para usarlo.

get-oui utiliza los módulos de Perl LWP::UserAgent y Text::CSV para obtener y procesar los datos del registro IEEE. Debes tener estos módulos instalados en tu sistema para que funcione. Estos módulos están disponibles en la mayoría de las distribuciones, a menudo se llaman libwww-perl y libtext-csv-perl. También están disponibles en formato fuente desde CPAN.

Puedes usar un servidor proxy definiendo la variable de entorno http_proxy.
