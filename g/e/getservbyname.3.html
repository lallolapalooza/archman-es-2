getservent(3) Library Functions Manual getservent(3)

NOMBRE

getservent, getservbyname, getservbyport, setservent, endservent - obtener entrada de servicio

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <netdb.h>
struct servent *getservent(void);
struct servent *getservbyname(const char *name, const char *proto);
struct servent *getservbyport(int port, const char *proto);
void setservent(int stayopen);
void endservent(void);

DESCRIPCIÓN

La función getservent() lee la siguiente entrada de la base de datos de servicios (ver services(5)) y devuelve una estructura servent que contiene los campos desglosados de la entrada. Se abre una conexión a la base de datos si es necesario.

La función getservbyname() devuelve una estructura servent para la entrada de la base de datos que coincide con el nombre de servicio name usando el protocolo proto. Si proto es NULL, se emparejará cualquier protocolo. Se abre una conexión a la base de datos si es necesario.

La función getservbyport() devuelve una estructura servent para la entrada de la base de datos que coincide con el puerto port (dado en orden de bytes de red) usando el protocolo proto. Si proto es NULL, se emparejará cualquier protocolo. Se abre una conexión a la base de datos si es necesario.

La función setservent() abre una conexión a la base de datos y establece la siguiente entrada a la primera entrada. Si stayopen es distinto de cero, la conexión a la base de datos no se cerrará entre llamadas a una de las funciones getserv*().

La función endservent() cierra la conexión a la base de datos.

La estructura servent se define en <netdb.h> de la siguiente manera:


struct servent {
    char  *s_name;       /* nombre oficial del servicio */
    char **s_aliases;    /* lista de alias */
    int    s_port;       /* número de puerto */
    char  *s_proto;      /* protocolo a usar */
}

Los miembros de la estructura servent son:

s_name
El nombre oficial del servicio.
s_aliases
Una lista terminada en NULL de nombres alternativos para el servicio.
s_port
El número de puerto para el servicio dado en orden de bytes de red.
s_proto
El nombre del protocolo a usar con este servicio.

VALOR DE RETORNO

Las funciones getservent(), getservbyname() y getservbyport() devuelven un puntero a una estructura servent estáticamente asignada, o NULL si ocurre un error o se llega al final del archivo.

ARCHIVOS

/etc/services
archivo de base de datos de servicios

ATRIBUTOS

Para obtener una explicación de los términos utilizados en esta sección, consulte attributes(7).

Interfaz Atributo Valor
getservent () Seguridad de hilos MT-Unsafe race:servent race:serventbuf locale
getservbyname () Seguridad de hilos MT-Unsafe race:servbyname locale
getservbyport () Seguridad de hilos MT-Unsafe race:servbyport locale
setservent (), endservent () Seguridad de hilos MT-Unsafe race:servent locale

En la tabla anterior, servent en race:servent significa que si alguna de las funciones setservent(), getservent() o endservent() se utilizan en paralelo en diferentes hilos de un programa, podrían ocurrir carreras de datos.
