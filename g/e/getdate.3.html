getdate(3) Manual de funciones de biblioteca getdate(3)

NOMBRE

getdate, getdate_r - convertir una cadena de fecha-más-hora a tiempo desglosado

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <time.h>
struct tm *getdate(const char *string);
extern int getdate_err;
int getdate_r(const char *restrict string, struct tm *restrict res);
Requisitos de Macro de Prueba de Funciones para glibc (ver feature_test_macros(7)):

getdate():

    _XOPEN_SOURCE >= 500

getdate_r():

    _GNU_SOURCE

DESCRIPCIÓN

La función getdate() convierte una representación en cadena de una fecha y hora, contenida en el búfer al que apunta string, en un tiempo desglosado. El tiempo desglosado se almacena en una estructura tm, y un puntero a esta estructura se devuelve como resultado de la función. Esta estructura tm se asigna en almacenamiento estático y, en consecuencia, será sobrescrita por llamadas posteriores a getdate().

A diferencia de strptime(3) (que tiene un argumento format), getdate() utiliza los formatos que se encuentran en el archivo cuyo nombre de ruta completo se da en la variable de entorno DATEMSK. La primera línea del archivo que coincide con la cadena de entrada dada se utiliza para la conversión.

La coincidencia se realiza sin distinción de mayúsculas y minúsculas. El espacio en blanco superfluo, ya sea en el patrón o en la cadena a convertir, se ignora.

Las especificaciones de conversión que puede contener un patrón son las dadas para strptime(3). Se especifica una conversión más en la especificación POSIX.1-2001:

%Z
Nombre de la zona horaria. Esto no está implementado en glibc.

Cuando se da %Z, la estructura que contiene el tiempo desglosado se inicializa con valores correspondientes a la hora actual en la zona horaria dada. De lo contrario, la estructura se inicializa al tiempo desglosado correspondiente a la hora local actual (como con una llamada a localtime(3)).

Cuando solo se da el día de la semana, el día se toma como el primer día de este tipo en o después de hoy.

Cuando solo se da el mes (y no el año), el mes se toma como el primer mes de este tipo igual o posterior al mes actual. Si no se da día, es el primer día del mes.

Cuando no se dan hora, minuto y segundo, se toma la hora, minuto y segundo actuales.

Si no se da fecha, pero conocemos la hora, entonces esa hora se toma como la primera hora de este tipo igual o posterior a la hora actual.

getdate_r() es una extensión de GNU que proporciona una versión reentrante de getdate(). En lugar de usar una variable global para informar de errores y un búfer estático para devolver el tiempo desglosado, devuelve errores a través del valor de retorno de la función y devuelve el tiempo desglosado resultante en el búfer asignado por el llamador apuntado por el argumento res.

VALOR DE RETORNO

Cuando tiene éxito, getdate() devuelve un puntero a una struct tm. De lo contrario, devuelve NULL y establece la variable global getdate_err en uno de los números de error que se muestran a continuación. Los cambios en errno no están especificados.

En caso de éxito, getdate_r() devuelve 0; en caso de error, devuelve uno de los números de error que se muestran a continuación.

ERRORES

Los siguientes errores se devuelven a través de getdate_err (para getdate()) o como resultado de la función (para getdate_r()):

1
La variable de entorno DATEMSK no está definida, o su valor es una cadena vacía.
2
El archivo de plantilla especificado por DATEMSK no se puede abrir para lectura.
3
Error al obtener información de estado del archivo.
4
El archivo de plantilla no es un archivo regular.
5
Se produjo un error al leer el archivo de plantilla.
6
Fallo en la asignación de memoria (no hay suficiente memoria disponible).
7
No hay ninguna línea en el archivo que coincida con la entrada.
8
Especificación de entrada no válida.

VERSIONES

La especificación POSIX.1 para strptime(3) contiene especificaciones de conversión que utilizan el modificador %E o %O, mientras que tales especificaciones no se dan para getdate(). En glibc, getdate() se implementa utilizando strptime(3), por lo que ambas admiten exactamente las mismas conversiones.

EJEMPLOS

El programa a continuación llama a getdate() para cada uno de sus argumentos de línea de comandos, y para cada llamada muestra los valores en los campos de la estructura tm devuelta. La siguiente sesión de shell demuestra el funcionamiento del programa:


$ TFILE=$PWD/tfile
$ echo '%A' > $TFILE       # Nombre completo del día de la semana
$ echo '%T' >> $TFILE      # Hora (HH:MM:SS)
$ echo '%F' >> $TFILE      # Fecha ISO (YYYY-MM-DD)
$ date
dom sep  7 06:03:36 CEST 2008
$ export DATEMSK=$TFILE
$ ./a.out Tuesday '2009-12-28' '12:22:33'

Código fuente del programa

#define _GNU_SOURCE
#include <stdio.h>
#include <stdlib.h>
#include <time.h>
int
main(int argc, char *argv[])
{
    struct tm *tmp;
    for (size_t j = 1; j < argc; j++) {
        tmp = getdate(argv[j]);
        if (tmp == NULL) {
            printf("Call %zu failed; getdate_err = %d\n",
                   j, getdate_err);
            continue;
        }
        printf("Call %zu (\"%s\") succeeded:\n", j, argv[j]);
        printf("    tm_sec   = %d\n", tmp->tm_sec);
        printf("    tm_min   = %d\n", tmp->tm_min);
        printf("    tm_hour  = %d\n", tmp->tm_hour);
        printf("    tm_mday  = %d\n", tmp->tm_mday);
        printf("    tm_mon   = %d\n", tmp->tm_mon);
        printf("    tm_year  = %d\n", tmp->tm_year);
        printf("    tm_wday  = %d\n", tmp->tm_wday);
        printf("    tm_yday  = %d\n", tmp->tm_yday);
        printf("    tm_isdst = %d\n", tmp->tm_isdst);
    }
    exit(EXIT_SUCCESS);
}
