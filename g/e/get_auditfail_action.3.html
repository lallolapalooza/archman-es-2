GET_AUDITFAIL_ACTION(3) Manual del programador de Linux GET_AUDITFAIL_ACTION(3)

NOMBRE

get_auditfail_action - Obtener el valor sintonizable de failure_action

SINOPSIS

#include <libaudit.h>
int get_auditfail_action(auditfail_t *failmode);

DESCRIPCIÓN

Esta función obtiene el valor sintonizable de failure_action almacenado en /etc/libaudit.conf. get_auditfail_action debe llamarse después de que una llamada a audit_open devuelva un error para ver qué acción prefiere el administrador.

El valor de failure_action encontrado en /etc/libaudit.conf se copia en el argumento failmode al devolver la función. Este valor debe ser utilizado entonces por la aplicación que llama para determinar qué acción se debe tomar cuando el subsistema de auditoría no está disponible.

VALOR DE RETORNO

En caso de éxito, get_auditfail_action devuelve cero y el argumento failmode contendrá el valor de failure_action. Los valores posibles para failure_action son: FAIL_IGNORE (0), FAIL_LOG (1) y FAIL_TERMINATE (2). En caso de fallo, get_auditfail_action devuelve un código de retorno de uno.

ERRORES

Se devuelve un error si hay un error al leer /etc/libaudit.conf o si el sintonizable failure_action no se encuentra en el archivo.

EJEMPLOS


/* Código de ejemplo */
auditfail_t failmode;


if ((fd = audit_open() ) < 0 ) {
fprintf (stderr, "No se puede abrir el socket de auditoría netlink");


/* Obtener el failure_action */
if ((rc = get_auditfail_action(&failmode)) == 0) {
if (failmode == FAIL_LOG)
fprintf (stderr, "Subsistema de auditoría no disponible");
else if (failmode == FAIL_TERMINATE)
exit (1);
/* Si failmode == FAIL_IGNORE, no hacer nada */
}
}

VER TAMBIÉN

audit_open(3), auditd(8).
