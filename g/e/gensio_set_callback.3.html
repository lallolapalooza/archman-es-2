Paquete: gensio

Licencias: GPL

gensio_set_callback(3) Manual de funciones de biblioteca gensio_set_callback(3)

NOMBRE

gensio_set_callback, gensio_get_user_data, gensio_set_user_data - Establecer la devolución de llamada de eventos y los datos de usuario para un gensio

SINOPSIS

#include <gensio/gensio.h>

void gensio_set_callback(struct gensio *io,

gensio_event cb, void *user_data)
void gensio_set_user_data(struct gensio *io, void *user_data);
void *gensio_get_user_data(struct gensio *io)

DESCRIPCIÓN

gensio_set_callback establece el manejador de eventos y los datos para el gensio. Esto debe hacerse en el evento GENSIO_ACC_EVENT_NEW_CONNECTION de un gensio_accepter antes de realizar cualquier otra operación en el gensio. La única excepción es que gensio_close puede ser llamado con devoluciones de llamada no establecidas. Esta función puede ser llamada de nuevo si el gensio no puede generar ninguna devolución de llamada, generalmente después de que se haya cerrado. De lo contrario, pueden producirse condiciones de carrera.

gensio_set_user_data Simplemente establece el campo user_data en el gensio. Si se llama cuando el gensio está en ejecución, pueden producirse condiciones de carrera.

gensio_get_user_data Devuelve los datos de usuario pasados cuando se creó el gensio o establecidos por una de las dos funciones anteriores.

VER TAMBIÉN
