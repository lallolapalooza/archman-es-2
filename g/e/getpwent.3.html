DESCRIPCIÓ

N

La función getpwent() devuelve un puntero a una estructura que contiene los campos desglosados de un registro de la base de datos de contraseñas (por ejemplo, el archivo de contraseñas local /etc/passwd, NIS y LDAP). La primera vez que se llama a getpwent(), devuelve la primera entrada; a partir de ahí, devuelve las entradas

sucesivas.

La función setpwent() retrocede al principio de la base de datos de

contraseñas.

La función endpwent() se utiliza para cerrar la base de datos de contraseñas después de que se haya realizado todo el

procesamiento.

La estructura passwd está definida en <pwd.h> de la siguiente

manera: 


struct passwd {
    char   *pw_name;       /* username */
    char   *pw_passwd;     /* user password */
    uid_t   pw_uid;        /* user ID */
    gid_t   pw_gid;        /* group ID */
    char   *pw_gecos;      /* user information */
    char   *pw_dir;        /* home directory */
    char   *pw_shell;      /* shell program */
}
;

Para obtener más información sobre los campos de esta estructura, ver passw

d(5
).

VALOR DE

RETORNO

La función getpwent() devuelve un puntero a una estructura passwd, o NULL si no hay más entradas o si ocurrió un error. Si ocurre un error, errno se establece para indicar el error. Si se desea comprobar errno después de la llamada, se debe establecer a cero antes de la

llamada.

El valor de retorno puede apuntar a un área estática, y puede ser sobrescrito por llamadas subsecuentes a getpwent(), getpwnam(3), o getpwuid(3). (No pase el puntero devuelto a free

(3)
.)
