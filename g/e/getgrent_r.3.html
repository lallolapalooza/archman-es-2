DESCRIPCIÓ

N

Las funciones getgrent_r() y fgetgrent_r() son las versiones reentrantes de getgrent(3) y fgetgrent(3). La primera lee la siguiente entrada de grupo desde el flujo inicializado por setgrent(3). La segunda lee la siguiente entrada de grupo desde stream

.

La estructura group está definida en <grp.h> como

sigue: 


struct group {
    char   *gr_name;        /* group name */
    char   *gr_passwd;      /* group password */
    gid_t   gr_gid;         /* group ID */
    char  **gr_mem;         /* NULL-terminated array of pointers
                               to names of group members */
}
;

Para más información sobre los campos de esta estructura, ver group(

5).

Las funciones no reentrantes devuelven un puntero a almacenamiento estático, donde este almacenamiento estático contiene punteros adicionales al nombre de grupo, contraseña y miembros. Las funciones reentrantes descritas aquí devuelven todo eso en buffers proporcionados por el llamante. En primer lugar está el buffer gbuf que puede contener una struct group. Y a continuación el buffer buf de tamaño size que puede contener cadenas adicionales. El resultado de estas funciones, la struct group leída del flujo, se almacena en el buffer proporcionado *gbuf, y se devuelve un puntero a esta struct group en *gbu

f
p.

EJEMPLO

S 
#define _GNU_SOURCE
#include <grp.h>
#include <stdint.h>
#include <stdio.h>
#include <stdlib.h>
#define BUFLEN 4096
int
main(void)
{
    struct group grp;
    struct group *grpp;
    char buf[BUFLEN];
    int i;
    setgrent();
    while (1) {
        i = getgrent_r(&grp, buf, sizeof(buf), &grpp);
        if (i)
            break;
        printf("%s (%jd):", grpp->gr_name, (intmax_t) grpp->gr_gid);
        for (size_t j = 0; ; j++) {
            if (grpp->gr_mem[j] == NULL)
                break;
            printf(" %s", grpp->gr_mem[j]);
        }
        printf("\n");
    }
    endgrent();
    exit(EXIT_SUCCESS);
}
