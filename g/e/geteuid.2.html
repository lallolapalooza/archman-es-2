getuid(2) Manual de llamadas al sistema getuid(2)

NOMBRE

getuid, geteuid — obtener identidad de usuario

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <unistd.h>
uid_t getuid(void);
uid_t geteuid(void);

DESCRIPCIÓN

getuid() devuelve el ID de usuario real del proceso que realiza la llamada.

geteuid() devuelve el ID de usuario efectivo del proceso que realiza la llamada.

ERRORES

Estas funciones siempre tienen éxito y nunca modifican errno.

ESTÁNDARES

POSIX.1-2024.

HISTORIA

POSIX.1-2001, 4.3BSD.

En UNIX V6, la llamada getuid() devolvía (euid << 8) + uid. UNIX V7 introdujo las llamadas separadas getuid() y geteuid().

Las llamadas al sistema originales getuid() y geteuid() de Linux solo admitían IDs de usuario de 16 bits. Posteriormente, Linux 2.4 añadió getuid32() y geteuid32(), que admiten IDs de 32 bits. Las funciones envoltorio getuid() y geteuid() de glibc manejan de forma transparente las variaciones entre versiones del kernel.

En Alpha, en lugar de un par de llamadas al sistema getuid() y geteuid(), se proporciona una única llamada al sistema getxuid(), que devuelve un par de UID reales y efectivos. Las funciones envoltorio getuid() y geteuid() de glibc manejan esto de forma transparente. Consulte syscall(2) para obtener detalles sobre el mapeo de registros.

VER TAMBIÉN

getresuid(2), setreuid(2), setuid(2), credentials(7)
