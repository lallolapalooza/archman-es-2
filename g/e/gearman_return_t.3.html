DESCRIPCIÓ

N

gearman_return_t se utiliza como tipo de retorno/error para todas las llamadas que usan gearman_client_st y gearman_worker_st. Se devuelve GEARMAN_SUCCESS en caso de éxito; de lo contrario, se devuelve un error. gearman_failed() se puede utilizar para ver si el valor de retorno es un valor de fallo. Puede imprimir una versión de texto del mensaje de error con gearman_strer

ror().

gearman_success() devuelve true si GEARMAN_SUCCESS o si GEARMAN_NO_PENDING_TASKS evalúa como

verdadero.

gearman_failed() devuelve true si se proporcionó cualquier valor distinto de GEARMAN_SUCCESS

.

gearman_continue() devuelve true si ocurrió algún error relacionado con la E/S no bloqueante. Esto debería usarse para probar

bucles.
