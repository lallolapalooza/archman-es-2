setnetgrent(3) Manual de funciones de la biblioteca setnetgrent(3)

NOMBRE

setnetgrent, endnetgrent, getnetgrent, getnetgrent_r, innetgr - manejar entradas de grupos de red

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <netdb.h>
int setnetgrent(const char *netgroup);
void endnetgrent(void);
int getnetgrent(char **restrict host,
            char **restrict user, char **restrict domain);
int getnetgrent_r(size_t size;
            char **restrict host,
            char **restrict user, char **restrict domain,
            char buf[restrict size], size_t size);
int innetgr(const char *netgroup, const char *host,
            const char *user, const char *domain);
Requisitos de Macro de Prueba de Funciones para glibc (ver feature_test_macros(7)):

setnetgrent(), endnetgrent(), getnetgrent(), getnetgrent_r(), innetgr():

    Desde glibc 2.19:
        _DEFAULT_SOURCE
    glibc 2.19 y anteriores:
        _BSD_SOURCE || _SVID_SOURCE

DESCRIPCIÓN

El netgroup es una invención de SunOS. Una base de datos de netgroup es una lista de tripletes de cadenas (nombre_host, nombre_usuario, nombre_dominio) u otros nombres de netgroup. Cualquiera de los elementos en un triplete puede estar vacío, lo que significa que coincide con cualquier cosa. Las funciones descritas aquí permiten el acceso a las bases de datos de netgroup. El archivo /etc/nsswitch.conf define qué base de datos se busca.

La llamada setnetgrent() define el netgroup que será buscado por las llamadas posteriores a getnetgrent(). La función getnetgrent() recupera la siguiente entrada de netgroup y devuelve punteros en host, user, domain. Un puntero nulo significa que la entrada correspondiente coincide con cualquier cadena. Los punteros solo son válidos mientras no haya una llamada a otras funciones relacionadas con netgroup. Para evitar este problema, puede usar la función GNU getnetgrent_r() que almacena las cadenas en el búfer proporcionado. Para liberar todos los búferes asignados, use endnetgrent().

En la mayoría de los casos, solo querrá comprobar si el triplete (nombre_host, nombre_usuario, nombre_dominio) es miembro de un netgroup. La función innetgr() se puede usar para esto sin llamar a las tres funciones anteriores. De nuevo, un puntero nulo es un comodín y coincide con cualquier cadena. La función es segura para hilos.

VALOR DE RETORNO

Estas funciones devuelven 1 en caso de éxito y 0 en caso de fallo.

FICHEROS

/etc/netgroup
/etc/nsswitch.conf

ATRIBUTOS

Para obtener una explicación de los términos utilizados en esta sección, consulte attributes(7).

Interfaz Atributo Valor
setnetgrent (), getnetgrent_r (), innetgr () Seguridad de hilos MT-Unsafe race:netgrent locale
endnetgrent () Seguridad de hilos MT-Unsafe race:netgrent
getnetgrent () Seguridad de hilos MT-Unsafe race:netgrent race:netgrentbuf locale

En la tabla anterior, netgrent en race:netgrent significa que si alguna de las funciones setnetgrent(), getnetgrent_r(), innetgr(), getnetgrent(), o endnetgrent() se utilizan en paralelo en diferentes hilos de un programa, podrían ocurrir carreras de datos.

VERSIÓNES

En la implementación de BSD, setnetgrent() devuelve void.

ESTÁNDARES

Ninguno.

HISTORIA

setnetgrent(), endnetgrent(), getnetgrent(), y innetgr() están disponibles en la mayoría de los sistemas UNIX. getnetgrent_r() no está ampliamente disponible en otros sistemas.
