getc_putc(8) Manual del Administrador del Sistema getc_putc(8)

NOMBRE

getc_putc - programa para probar el rendimiento del disco duro.

SINOPSIS

getc_putc [-d dir] [-s tamaño(KiB)] [-m nombre-máquina] [-u uid-a-usar:gid-a-usar] [-g gid-a-usar]

DESCRIPCIÓN

Esta página del manual documenta brevemente el programa getc_putc.

Este es un complemento simple del benchmark bonnie++. Se utiliza para probar diversas formas de realizar E/S byte a byte, generalmente no se necesita hacer suficiente de esto para que sea un problema de rendimiento que importe mucho la forma en que se haga. Pero a veces es necesario (por ejemplo, al analizar E/S desde una terminal y luego lanzar otro proceso que se encargará de toda la E/S, como un shell simple).

Los beneficios reales de esto son ayudar a resolver algunas discusiones sobre el rendimiento de tales cosas y educar a los novatos sobre lo malo que son las E/S por byte.

OPCIONES

Para getc_putc, cada opción es de la forma de un guion seguido de una letra y luego el siguiente parámetro contiene el valor.

-d
el directorio a usar para las pruebas.
-s
el tamaño del archivo para el rendimiento de E/S de bytes medido en kilobytes. NB Puede especificar el tamaño en mega-bytes si añade 'm' al final del número.

El valor predeterminado para esta prueba es probar con un archivo de 512MiB. De los cuales solo se usará 1/64 del archivo para las llamadas al sistema write() y read() (cualquier otra cosa lleva demasiado tiempo).

-m
nombre de la máquina, solo para fines de visualización.
-u
ID de usuario a usar. Cuando se ejecuta como root, especifique el UID a usar para las pruebas. No se recomienda usar root, así que si realmente quiere ejecutar como root, use -u root. También, si quiere especificar el grupo a usar, use el formato usuario:grupo. Si especifica un usuario por nombre pero no grupo, se elegirá el grupo principal de ese usuario. Si especifica un usuario por número y no grupo, el grupo será nogroup.
-g
ID de grupo a usar. Igual que usar :grupo para el parámetro -u, solo que es una forma diferente de especificarlo para compatibilidad con otros programas.
-q
modo silencioso. Si se especifica, se suprimirán algunos de los mensajes informativos adicionales. También, los datos csv serán la única salida en la salida estándar y los datos de texto plano estarán en el error estándar. Esto significa que puede ejecutar getc_putc -q >> archivo.csv para registrar sus datos csv.

SALIDA

La salida principal es texto plano en 80 columnas diseñado para encajar bien al pegarlo en correos electrónicos y que funcionará bien con pantallas Braille.

El segundo tipo de salida son CSV (Valores Separados por Comas). Estos se pueden importar fácilmente a cualquier programa de hoja de cálculo o base de datos.

Para cada prueba, el resultado es una velocidad en KiB/s. No muestro el tiempo de CPU porque presumiblemente es el 99% del poder de una CPU única (o algo muy cercano a eso).

SEÑALES

Maneja SIGINT y realiza una limpieza (que puede llevar algún tiempo), un segundo SIGINT o un SIGQUIT harán que muera inmediatamente.

SIGXCPU y SIGXFSZ actúan como SIGINT.

Ignora SIGHUP.
