getent(1) Manual de Comandos Generales getent(1)

NOMBRE

getent - obtener entradas de las bibliotecas Name Service Switch

SINOPSIS

getent [opción...] base-de-datos clave...

DESCRIPCIÓN

El comando getent muestra entradas de las bases de datos soportadas por las bibliotecas Name Service Switch, las cuales están configuradas en /etc/nsswitch.conf. Si se proporciona uno o más argumentos de clave , entonces solo se mostrarán las entradas que coincidan con las claves proporcionadas. De lo contrario, si no se proporciona ninguna clave , se mostrarán todas las entradas (a menos que la base de datos no soporte enumeración).

La base-de-datos puede ser cualquiera de las soportadas por la Biblioteca C GNU, listadas a continuación:

ahosts
Cuando no se proporciona ninguna clave , usa sethostent(3), gethostent(3), y endhostent(3) para enumerar la base de datos de hosts. Esto es idéntico a usar hosts(5). Cuando se proporciona uno o más argumentos de clave , pasa cada clave sucesivamente a getaddrinfo(3) con la familia de direcciones AF_UNSPEC, enumerando cada estructura de dirección de socket devuelta.
ahostsv4
Igual que ahosts, pero usa la familia de direcciones AF_INET.
ahostsv6
Igual que ahosts, pero usa la familia de direcciones AF_INET6. La llamada a getaddrinfo(3) en este caso incluye el indicador AI_V4MAPPED .
aliases
Cuando no se proporciona ninguna clave , usa setaliasent(3), getaliasent(3), y endaliasent(3) para enumerar la base de datos de aliases. Cuando se proporciona uno o más argumentos de clave , pasa cada clave sucesivamente a getaliasbyname(3) y muestra el resultado.
ethers
Cuando se proporciona uno o más argumentos de clave , pasa cada clave sucesivamente a ether_aton(3) y ether_hostton(3) hasta obtener un resultado, y muestra el resultado. La enumeración no está soportada en ethers, por lo que se debe proporcionar una clave .
group
Cuando no se proporciona ninguna clave , usa setgrent(3), getgrent(3), y endgrent(3) para enumerar la base de datos de grupos. Cuando se proporciona uno o más argumentos de clave , pasa cada clave numérica a getgrgid(3) y cada clave no numérica a getgrnam(3) y muestra el resultado.
gshadow
Cuando no se proporciona ninguna clave , usa setsgent(3), getsgent(3), y endsgent(3) para enumerar la base de datos gshadow. Cuando se proporciona uno o más argumentos de clave , pasa cada clave sucesivamente a getsgnam(3) y muestra el resultado.
hosts
Cuando no se proporciona ninguna clave , usa sethostent(3), gethostent(3), y endhostent(3) para enumerar la base de datos de hosts. Cuando se proporciona uno o más argumentos de clave , pasa cada clave a gethostbyaddr(3) o gethostbyname2(3), dependiendo de si una llamada a inet_pton(3) indica que la clave es una dirección IPv6 o IPv4 o no, y muestra el resultado.
initgroups
Cuando se proporciona uno o más argumentos de clave , pasa cada clave sucesivamente a getgrouplist(3) y muestra el resultado. La enumeración no está soportada en initgroups, por lo que se debe proporcionar una clave .
netgroup
Cuando se proporciona una clave , pasa la clave a setnetgrent(3) y, usando getnetgrent(3) muestra la cadena triple resultante (nombre-de-host, nombre-de-usuario, nombre-de-dominio). Alternativamente, se pueden proporcionar tres claves , que se interpretan como el nombre-de-host, nombre-de-usuario, y nombre-de-dominio para hacer coincidir con un nombre de netgroup vía innetgr(3). La enumeración no está soportada en netgroup, por lo que se debe proporcionar una o tres claves .
networks
Cuando no se proporciona ninguna clave , usa setnetent(3), getnetent(3), y endnetent(3) para enumerar la base de datos de redes. Cuando se proporciona uno o más argumentos de clave , pasa cada clave numérica a getnetbyaddr(3) y cada clave no numérica a getnetbyname(3) y muestra el resultado.
passwd
Cuando no se proporciona ninguna clave , usa setpwent(3), getpwent(3), y endpwent(3) para enumerar la base de datos passwd. Cuando se proporciona uno o más argumentos de clave , pasa cada clave numérica a getpwuid(3) y cada clave no numérica a getpwnam(3) y muestra el resultado.
protocols
Cuando no se proporciona ninguna clave , usa setprotoent(3), getprotoent(3), y endprotoent(3) para enumerar la base de datos de protocolos. Cuando se proporciona uno o más argumentos de clave , pasa cada clave numérica a getprotobynumber(3) y cada clave no numérica a getprotobyname(3) y muestra el resultado.
rpc
Cuando no se proporciona ninguna clave , usa setrpcent(3), getrpcent(3), y endrpcent(3) para enumerar la base de datos rpc. Cuando se proporciona uno o más argumentos de clave , pasa cada clave numérica a getrpcbynumber(3) y cada clave no numérica a getrpcbyname(3) y muestra el resultado.
services
Cuando no se proporciona ninguna clave , usa setservent(3), getservent(3), y endservent(3) para enumerar la base de datos de servicios. Cuando se proporciona uno o más argumentos de clave , pasa cada clave numérica a getservbynumber(3) y cada clave no numérica a getservbyname(3) y muestra el resultado.
shadow
Cuando no se proporciona ninguna clave , usa setspent(3), getspent(3), y endspent(3) para enumerar la base de datos shadow. Cuando se proporciona uno o más argumentos de clave , pasa cada clave sucesivamente a getspnam(3) y muestra el resultado.

OPCIONES

OPTIONS

--service service
-s service
Sobrescribe todas las bases de datos con el servicio especificado. (Desde glibc 2.2.5.)
--service database:service
-s database:service
Sobrescribe solo las bases de datos especificadas con el servicio especificado. La opción puede usarse varias veces, pero solo se utilizará el último servicio para cada base de datos. (Desde glibc 2.4.)
--no-idn
-i
Deshabilita la codificación IDN en las búsquedas para ahosts/getaddrinfo(3) (Desde glibc-2.13.)
--help
-?
Imprime un resumen de uso y sale.
--usage
Imprime un resumen de uso corto y sale.
--version
-V
Imprime el número de versión, la licencia y el descargo de responsabilidad de la garantía de getent.

ESTADO DE SALIDA

Uno de los siguientes valores de salida puede ser devuelto por getent:

0
Comando completado con éxito.
1
Argumentos faltantes o database desconocida.
2
Una o más key proporcionadas no pudieron encontrarse en la database.
3
La enumeración no está soportada en esta database.

VEA TAMBIÉN
