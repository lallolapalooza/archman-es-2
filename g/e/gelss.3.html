Documentación de la función

subrutina cgelss (integer m, integer n, integer nrhs, complex, dimension( lda, * ) a, integer lda, complex, dimension( ldb, * ) b, integer ldb, real, dimension( * ) s, real rcond, integer rank, complex, dimension( * ) work, integer lwork, real, dimension( * ) rwork, integer info)

CGELSS resuelve sistemas sobredeterminados o subdeterminados para matrices GE

Propósito:

!>
!> CGELSS calcula la solución de norma mínima a un problema de
!> mínimos cuadrados lineales complejo:
!>
!> Minimizar 2-norm(| b - A*x |).
!>
!> usando la descomposición en valores singulares (SVD) de A. A es una
!> matriz M-por-N que puede ser deficiente en rango.
!>
!> Varios vectores de segundo miembro b y vectores de solución x pueden
!> manejarse en una sola llamada; se almacenan como las columnas de la
!> matriz de segundo miembro B de tamaño M-por-NRHS y la matriz de
!> solución X de tamaño N-por-NRHS.
!>
!> El rango efectivo de A se determina tratando como cero aquellos
!> valores singulares que son menores que RCOND veces el mayor valor
!> singular.
!>

Parámetros

M 
!>          M es INTEGER
!>          El número de filas de la matriz A. M >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz A. N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de segundos miembros, es decir, el número de columnas
!>          de las matrices B y X. NRHS >= 0.
!>

A

!>          A es un arreglo COMPLEX, dimensión (LDA,N)
!>          A la entrada, la matriz A de tamaño M-por-N.
!>          A la salida, las primeras min(m,n) filas de A se sobrescriben con
!>          sus vectores singulares derechos, almacenados por filas.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del arreglo A. LDA >= max(1,M).
!>

B

!>          B es un arreglo COMPLEX, dimensión (LDB,NRHS)
!>          A la entrada, la matriz de segundo miembro B de tamaño M-por-NRHS.
!>          A la salida, B se sobrescribe con la matriz de solución X de
!>          tamaño N-por-NRHS.
!>          Si m >= n y RANK = n, la suma de residuos de cuadrados para
!>          la solución en la i-ésima columna está dada por la suma de
!>          cuadrados del módulo de los elementos n+1:m en esa columna.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del arreglo B.  LDB >= max(1,M,N).
!>

S

!>          S es un arreglo REAL, dimensión (min(M,N))
!>          Los valores singulares de A en orden decreciente.
!>          El número de condición de A en la 2-norma = S(1)/S(min(m,n)).
!>

RCOND

!>          RCOND es REAL
!>          RCOND se usa para determinar el rango efectivo de A.
!>          Los valores singulares S(i) <= RCOND*S(1) se tratan como cero.
!>          Si RCOND < 0, se usa la precisión de la máquina en su lugar.
!>

RANK

!>          RANK es INTEGER
!>          El rango efectivo de A, es decir, el número de valores singulares
!>          que son mayores que RCOND*S(1).
!>

WORK

!>          WORK es un arreglo COMPLEX, dimensión (MAX(1,LWORK))
!>          A la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del arreglo WORK. LWORK >= 1, y también:
!>          LWORK >=  2*min(M,N) + max(M,N,NRHS)
!>          Para un buen rendimiento, LWORK debería ser generalmente mayor.
!>
!>          Si LWORK = -1, se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo del arreglo WORK, devuelve
!>          este valor como la primera entrada del arreglo WORK, y no se emite
!>          ningún mensaje de error relacionado con LWORK por parte de XERBLA.
!>

RWORK

!>          RWORK es un arreglo REAL, dimensión (5*min(M,N))
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>          > 0:  el algoritmo para calcular el SVD falló en converger;
!>                si INFO = i, i elementos fuera de la diagonal de una forma
!>                bidiagonal intermedia no convergieron a cero.
!>
