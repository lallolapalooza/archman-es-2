NOMBRE

genact - Generador de actividad sin sentido

SINOPSIS

genact [-l|--list-modules] [-m|--modules] [-s|--speed-factor] [-i|--instant-print-lines] [--exit-after-time] [--exit-after-modules] [--print-completions] [--print-manpage] [-h|--help] [-V|--version]

DESCRIPCIÓN

Un generador de actividad sin sentido

OPCIONES

-l, --list-modules
Listar módulos disponibles
-m, --modules=MÓDULOS
Ejecutar solo estos módulos

[posibles valores: ansible, bootlog, botnet, bruteforce, cargo, cc, composer, cryptomining, docker_build, docker_image_rm, download, julia, kernel_compile, memdump, mkinitcpio, rkhunter, simcity, terraform, weblog]

-s, --speed-factor=FACTOR_VELOCIDAD [predeterminado: 1]
Factor de velocidad global
-i, --instant-print-lines=LÍNEAS_IMPRESIÓN_INSTANTÁNEA [predeterminado: 0]
Imprimir instantáneamente este número de líneas
--exit-after-time=TIEMPO_SALIDA
Salir después de ejecutar durante este tiempo (ejemplo de formato: 2h10min)
--exit-after-modules=MÓDULOS_SALIDA
Salir después de ejecutar este número de módulos
--print-completions=shell
Generar archivo de completado para un shell

[posibles valores: bash, elvish, fish, powershell, zsh]

--print-manpage
Generar página del manual
-h, --help
Imprimir ayuda
-V, --version
Imprimir versión
