NOMBRE

geotifcp - Copia TIFF con metadatos GeoTIFF actualizados

SINOPSIS

geotifcp [opciones] [-e archivo_mundial_esri] [-g metadatos] entrada salida

DESCRIPCIÓN

geotifcp es idéntico en función al programa LIBTIFF tiffcp, con la característica adicional de que si se utiliza la opción "-g", la información GeoTIFF del archivo se instalará en el archivo de salida. La opción "-e archivo_mundial" reemplazará la información de puntos de anclaje y escala del archivo de metadatos basándose en el contenido del archivo mundial ESRI.

Si no se utiliza la opción "-g", la información geotiff del archivo de origen se preserva en el nuevo archivo de salida.

"geotifcp" hereda todas las demás capacidades de transformación de archivos del programa tiffcp; para obtener ayuda sobre los parámetros adicionales, ejecute el comando:

% geotifcp -h

El formato de los metadatos es el mismo que se describe en el programa listgeo(1). Normalmente, los archivos de metadatos para usar con geotifcp se generan a partir de un archivo similar con listgeo, y luego se modifican manualmente según sea necesario.

OPCIONES

-g archivo
instala metadatos GeoTIFF desde el archivo archivo
-4 cadena_proj4
instala metadatos GeoTIFF desde la cadena proj4
-e archivo
instala información de posicionamiento desde el archivo mundial ESRI archivo
-a
añade a la salida en lugar de sobrescribir
-8
escribe BigTIFF en lugar del ClassicTIFF predeterminado
-o desplazamiento
establece el desplazamiento del directorio inicial
-p contig
empaqueta muestras de forma contigua (ej. RGBRGB...)
-p separate
almacena muestras por separado (ej. RRR...GGG...BBB...)
-s
escribe la salida en tiras
-t
escribe la salida en teselas
-i
ignora errores de lectura
-d
trunca bits por muestra de 8 a 4 bits por muestra
-r #
hace que cada tira tenga no más de # filas
-w #
establece el ancho de tesela de salida (píxeles)
-l #
establece la longitud de tesela de salida (píxeles)
-f lsb2msb
fuerza el orden de relleno lsb-a-msb para la salida
-f msb2lsb
fuerza el orden de relleno msb-a-lsb para la salida
-c lzw[:opts]
comprime la salida con codificación Lempel-Ziv & Welch
-c zip[:opts]
comprime la salida con codificación deflate
-c jpeg[:opts]
comprime la salida con codificación JPEG
-c packbits
comprime la salida con codificación packbits
-c g3[:opts]
comprime la salida con codificación CCITT Group 3
-c g4
comprime la salida con codificación CCITT Group 4
-c none
no utiliza ningún algoritmo de compresión en la salida

Opciones de Group 3:

1d
usa la codificación 1D predeterminada de CCITT Group 3
2d
usa la codificación 2D opcional de CCITT Group 3
fill
alinea en bytes los códigos EOL

Por ejemplo, -c g3:2d:fill para obtener datos codificados con G3-2D y EOLs alineados en bytes

Opciones JPEG:

#
establece el nivel de calidad de compresión (0-100, por defecto 75)
r
salida de imagen en color como RGB en lugar de YCbCr

Por ejemplo, -c jpeg:r:50 para obtener datos RGB codificados con JPEG y una calidad de compresión del 50%

Opciones LZW y deflate:

#
establece el valor del predictor

Por ejemplo, -c lzw:2 para obtener datos codificados con LZW y diferencia horizontal
