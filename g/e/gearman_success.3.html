NOMBRE

gearman_success - Documentación de Gearmand, https://gearman.org/gearmand/

SINOPSIS

#include <libgearman/gearman.h>

type gearman_return_t
const char *gearman_strerror(gearman_return_t rc)
bool gearman_success(gearman_return_t rc)
bool gearman_failed(gearman_return_t rc)
bool gearman_continue(gearman_return_t rc)

Compilar y enlazar con -lgearman

DESCRIPCIÓN

gearman_return_t se utiliza como tipo de retorno/error para todas las llamadas que usan gearman_client_st y gearman_worker_st. GEARMAN_SUCCESS se devuelve en caso de éxito, de lo contrario se devuelve un error. gearman_failed() se puede utilizar para ver si el valor de retorno es un valor fallido. Puede imprimir una versión de texto del mensaje de error con gearman_strerror().

gearman_success() devuelve true si GEARMAN_SUCCESS o si GEARMAN_NO_PENDING_TASKS evalúa a true.

gearman_failed() devuelve true si se proporcionó cualquier valor distinto de GEARMAN_SUCCESS .

gearman_continue() devuelve true si ocurrió algún error relacionado con E/S no bloqueante. Esto debe usarse para bucles de prueba.

Valores posibles de gearman_return_t:

type GEARMAN_NO_PENDING_TASKS
Se llamó a gearman_client_run_tasks() y ha completado todas las tareas asignadas al cliente.
type GEARMAN_IO_WAIT
Se encontró E/S bloqueante. Se puede usar gearman_continue() para probar esto.
type GEARMAN_ERRNO
Ocurrió un error del sistema. Use ya sea gearman_client_errno() o gearman_worker_errno()
type GEARMAN_NO_ACTIVE_FDS
No había conexiones activas disponibles. Se puede usar gearman_continue() para probar esto.
type GEARMAN_GETADDRINFO
Falló la resolución de nombres para un host.
type GEARMAN_NO_SERVERS
No se han proporcionado servidores para el cliente/trabajador.
type GEARMAN_LOST_CONNECTION
Se perdió la conexión con el servidor indicado.
type GEARMAN_MEMORY_ALLOCATION_FAILURE
Falló la asignación de memoria.
type GEARMAN_SERVER_ERROR
Ocurrió un error en el servidor.
type GEARMAN_NOT_CONNECTED
El cliente/trabajador no está conectado actualmente al servidor.
type GEARMAN_COULD_NOT_CONNECT
El nombre del servidor era válido, pero no se pudo establecer una conexión.
type GEARMAN_ECHO_DATA_CORRUPTION
Ya sea gearman_client_echo() o gearman_worker_echo() echo no tuvo éxito porque los datos devueltos por gearmand estaban corruptos.
type GEARMAN_UNKNOWN_STATE
El gearman_return_t nunca se estableció.
type GEARMAN_FLUSH_DATA
Estado interno, nunca debería ser visto por el cliente ni por el trabajador.
type GEARMAN_SEND_BUFFER_TOO_SMALL
El búfer de envío era demasiado pequeño.
type GEARMAN_TIMEOUT
Ocurrió un tiempo de espera al hacer una petición al servidor.
type GEARMAN_ARGUMENT_TOO_LARGE
El argumento era demasiado grande para el búfer actual.
type GEARMAN_INVALID_ARGUMENT
Uno de los argumentos de la llamada a la API indicada no era válido. Se establecerá EINVAL si gearman_client_error() o gearman_worker_error() no se pudieron establecer. Esto también puede devolverse si GEARMAN_CLIENT_UNBUFFERED_RESULT estaba establecido, pero el cliente no está manejando los datos correctamente.

SOLO CLIENTE

type GEARMAN_NEED_WORKLOAD_FN
Se le pidió trabajo a un cliente, pero no se especificó ningún callback gearman_workload_fn . Vea gearman_client_set_workload_fn()
type GEARMAN_WORK_FAIL
Una tarea ha fallado, y el trabajador ha salido con un error o llamó a gearman_job_send_fail()
type GEARMAN_IN_PROGRESS
Se ha llamado a gearman_client_job_status() para un gearman_job_handle_t y el trabajo está siendo ejecutado actualmente por un trabajador.
type GEARMAN_JOB_EXISTS
Se ha llamado a gearman_client_job_status() para un gearman_job_handle_t y el trabajo es conocido actualmente por un servidor, pero no está siendo ejecutado por un trabajador.

SOLO TRABAJADOR

type GEARMAN_INVALID_FUNCTION_NAME
Se envió a un trabajador una petición de un trabajo para el que no tenía una función válida.
type GEARMAN_INVALID_WORKLOAD_FUNCTION
El trabajador no proporcionó ningún callback para una función dada.
type GEARMAN_NO_REGISTERED_FUNCTION
La petición de eliminar una función dada de un trabajador no era válida ya que esa función no existía.
type GEARMAN_NO_REGISTERED_FUNCTIONS
El trabajador no ha registrado ninguna función.
type GEARMAN_NO_JOBS
No se encontraron trabajos para el trabajador. Este código de error solo se devuelve si el
