NOMBRE

gensio_to_sergensio, sergensio_to_gensio, sergensio_get_user_data, sergensio_is_client - Información general y rutinas de conversión para un sergensio

SINOPSIS

#include <gensio/sergensio.h>

struct sergensio *gensio_to_sergensio(struct gensio *io);
struct gensio *sergensio_to_gensio(struct sergensio *serio);
void *sergensio_get_user_data(struct sergensio *serio);
bool sergensio_is_client(struct sergensio *serio);

DESCRIPCIÓN

gensio_to_sergensio devuelve el objeto sergensio para un gensio. Devuelve NULL si no hay sergensio para el gensio. Tenga en cuenta que este puede ser un objeto sergensio para un hijo del gensio pasado. Si el gensio pasado no es un sergensio, buscará entre los hijos un gensio que también sea un sergensio. De esta manera, por ejemplo, si tiene un gensio conacc que se ejecuta sobre un serialdev y recibe un evento serial, puede simplemente llamar a gensio_to_sergensio para el objeto pasado y le dará el sergensio con el que debería estar trabajando. La primera vez que se llama a esto en un gensio, asocia el sergensio con el gensio pasado.

sergensio_to_gensio devuelve el gensio para un sergensio dado. No puede fallar. Tenga en cuenta que esto devuelve el gensio pasado a gensio_to_sergensio, no el gensio asociado directamente con el sergensio pasado.

sergensio_get_user_data devuelve los datos del usuario del gensio para el gensio asociado.

sergensio_is_client devuelve verdadero si el sergensio es un cliente o falso si es un servidor.
