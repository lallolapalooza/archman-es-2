subrutina cgeqr2 (integer m, integer n, complex, dimension( lda, * ) a, integer lda, complex, dimension( * ) tau, complex, dimension( * ) work, integer

info)

CGEQR2 calcula la factorización QR de una matriz rectangular general usando un algoritmo sin

bloqueos.

Propósito

: 
!>
!> CGEQR2 calcula una factorización QR de una matriz compleja A de m por n:
!>
!>    A = Q * ( R ),
!>            ( 0 )
!>
!> donde:
!>
!>    Q es una matriz ortogonal de m por m;
!>    R es una matriz triangular superior de n por n;
!>    0 es una matriz cero de (m-n) por n, si m > n.
!>
!
>

Parámetro

s
M 
!>          M es INTEGER
!>          El número de filas de la matriz A.  M >= 0.
!
>

N 
!>          N es INTEGER
!>          El número de columnas de la matriz A.  N >= 0.
!
>

A 
!>          A es un arreglo COMPLEX, dimensión (LDA,N)
!>          Al entrar, la matriz A de m por n.
!>          Al salir, los elementos en y por encima de la diagonal del arreglo
!>          contienen la matriz trapezoidal superior R de min(m,n) por n (R es
!>          triangular superior si m >= n); los elementos por debajo de la diagonal,
!>          junto con el arreglo TAU, representan la matriz unitaria Q como un
!>          producto de reflectores elementales (ver Detalles adicionales).
!
>

LD

A 
!>          LDA es INTEGER
!>          La dimensión principal del arreglo A.  LDA >= max(1,M).
!
>

TA

U 
!>          TAU es un arreglo COMPLEX, dimensión (min(M,N))
!>          Los factores escalares de los reflectores elementales (ver Detalles
!>          adicionales).
!
>

WOR

K 
!>          WORK es un arreglo COMPLEX, dimensión (N)
!
>

INF

O 
!>          INFO es INTEGER
!>          = 0: salida exitosa
!>          < 0: si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!
>

Auto

Detalles

adicionales: 
!>
!>  La matriz Q se representa como un producto de reflectores elementales
!>
!>     Q = H(1) H(2) . . . H(k), donde k = min(m,n).
!>
!>  Cada H(i) tiene la forma
!>
!>     H(i) = I - tau * v * v**H
!>
!>  donde tau es un escalar complejo, y v es un vector complejo con
!>  v(1:i-1) = 0 y v(i) = 1; v(i+1:m) se almacena al salir en A(i+1:m,i),
!>  y tau en TAU(i).
!
>

            Detailed Description
          

          
This routine calls the		 LAPACK
            routines sgeqr2, dgeqr2, cgeqr2, zgeqr2.

          
The routine computes the QR factorization of an
            m-by-n matrix with the minimum number of scalar operations.

          

            

              subroutine sgeqr2 (integer m, integer n, real, dimension( lda, *
              ) a, integer lda, real, dimension( * ) tau, real, dimension( * )
              work, integer info)
            

            
Purpose:

            

              
!> sgeqr2 computes a QR factorization of a real m-by-n matrix A:
!>
!>    A = Q * ( R ),
!>            ( 0 )
!>
!> where:
!>
!>    Q is an m-by-m orthogonal matrix;
!>    R is an n-by-n upper triangular matrix;
!>    0 is a (m-n)-by-n zero matrix, if m > n.
!>
!> 

            

            
Parameters

            

              M
              
!>          M is INTEGER
!>          The number of rows of the matrix A.  M >= 0.
!> 

              
N

              
!>          N is INTEGER
!>          The number of columns of the matrix A.  N >= 0.
!> 

              
A

              
!>          A is REAL array, dimension (LDA,N)
!>          On entry, the m by n matrix A.
!>          On exit, the elements on and above the diagonal of the array
!>          contain the min(m,n) by n upper trapezoidal matrix R (R is
!>          upper triangular if m >= n); the elements below the diagonal,
!>          with the array TAU, represent the orthogonal matrix Q as a
!>          product of elementary reflectors (see Further Details).
!> 

              
LDA

              
!>          LDA is INTEGER
!>          The leading dimension of the array A.  LDA >= max(1,M).
!> 

              
TAU

              
!>          TAU is REAL array, dimension (min(M,N))
!>          The scalar factors of the elementary reflectors (see Further
!>          Details).
!> 

              
WORK

              
!>          WORK is REAL array, dimension (N)
!> 

              
INFO

              
!>          INFO is INTEGER
!>          = 0: successful exit
!>          < 0: if INFO = -i, the i-th argument had an illegal value
!> 

            

            
Author

            

              Univ. of Tennessee
              
Univ. of California Berkeley

              
Univ. of Colorado Denver

              
NAG Ltd.

            

            
Further Details:

            

              
!>
!>  The matrix Q is represented as a product of elementary reflectors
!>
!>     Q = H(1) H(2) . . . H(k), where k = min(m,n).
!>
!>  Each H(i) has the form
!>
!>     H(i) = I - tau * v * v**T
!>
!>  where tau is a real scalar, and v is a real vector with
!>  v(1:i-1) = 0 and v(i) = 1; v(i+1:m) is stored on exit in A(i+1:m,i),
!>  and tau in TAU(i).
!>
