NOMBRE

gearman_continue - Documentación de Gearmand, https://gearman.org/gearmand/

SINOPSIS

#include <libgearman/gearman.h>

tipo gearman_return_t
const char *gearman_strerror(gearman_return_t rc)
bool gearman_success(gearman_return_t rc)
bool gearman_failed(gearman_return_t rc)
bool gearman_continue(gearman_return_t rc)

Compilar y enlazar con -lgearman

DESCRIPCIÓN

gearman_return_t se utiliza como tipo de retorno/error para todas las llamadas que usan gearman_client_st y gearman_worker_st. GEARMAN_SUCCESS se devuelve al tener éxito, de lo contrario se devuelve un error. gearman_failed() se puede usar para ver si el valor de retorno es un valor de error. Puede imprimir una versión de texto del mensaje de error con gearman_strerror().

gearman_success() devuelve verdadero si GEARMAN_SUCCESS o si GEARMAN_NO_PENDING_TASKS da como verdadero.

gearman_failed() devuelve verdadero si se proporcionó algún valor distinto de GEARMAN_SUCCESS.

gearman_continue() devuelve verdadero si ocurrió algún error relacionado con E/S no bloqueante. Esto debe usarse para probar bucles.

Posibles valores de gearman_return_t:

tipo GEARMAN_NO_PENDING_TASKS
Se llamó a gearman_client_run_tasks() y ha completado todas las tareas asignadas al cliente.
tipo GEARMAN_IO_WAIT
Se encontró E/S bloqueante. gearman_continue() se puede usar para probar esto.
tipo GEARMAN_ERRNO
Ocurrió un error del sistema. Use gearman_client_errno() o gearman_worker_errno()
tipo GEARMAN_NO_ACTIVE_FDS
No había conexiones activas disponibles. gearman_continue() se puede usar para probar esto.
tipo GEARMAN_GETADDRINFO
La resolución de nombres falló para un host.
tipo GEARMAN_NO_SERVERS
No se proporcionaron servidores para el cliente/trabajador.
tipo GEARMAN_LOST_CONNECTION
Se perdió la conexión con el servidor dado.
tipo GEARMAN_MEMORY_ALLOCATION_FAILURE
La asignación de memoria falló.
tipo GEARMAN_SERVER_ERROR
Ocurrió un error en el servidor.
tipo GEARMAN_NOT_CONNECTED
El cliente/trabajador no está conectado actualmente al servidor.
tipo GEARMAN_COULD_NOT_CONNECT
El nombre del servidor era válido, pero no se pudo establecer una conexión.
tipo GEARMAN_ECHO_DATA_CORRUPTION
gearman_client_echo() o gearman_worker_echo() fallaron porque los datos devueltos por gearmand estaban corruptos.
tipo GEARMAN_UNKNOWN_STATE
El gearman_return_t nunca se estableció.
tipo GEARMAN_FLUSH_DATA
Estado interno, nunca debería ser visto por el cliente ni por el trabajador.
tipo GEARMAN_SEND_BUFFER_TOO_SMALL
El búfer de envío era demasiado pequeño.
tipo GEARMAN_TIMEOUT
Ocurrió un tiempo de espera al realizar una solicitud al servidor.
tipo GEARMAN_ARGUMENT_TOO_LARGE
El argumento era demasiado grande para el búfer actual.
tipo GEARMAN_INVALID_ARGUMENT
Uno de los argumentos de la llamada a la API dada era inválido. EINVAL se establecerá si gearman_client_error() o gearman_worker_error() no se pudieron establecer. Esto también se puede devolver si se estableció GEARMAN_CLIENT_UNBUFFERED_RESULT, pero el cliente no está manejando los datos correctamente.

SOLO CLIENTE

tipo GEARMAN_NEED_WORKLOAD_FN
Se le pidió trabajo a un cliente, pero no se especificó ninguna función de callback gearman_workload_fn. Ver gearman_client_set_workload_fn()
tipo GEARMAN_WORK_FAIL
Una tarea ha fallado, y el trabajador ha salido con un error o ha llamado a gearman_job_send_fail()
tipo GEARMAN_IN_PROGRESS
Se llamó a gearman_client_job_status() para un gearman_job_handle_t y la Tarea está siendo ejecutada actualmente por un trabajador.
tipo GEARMAN_JOB_EXISTS
Se llamó a gearman_client_job_status() para un gearman_job_handle_t y la Tarea es conocida actualmente por un servidor, pero no está siendo ejecutada por un trabajador.

SOLO TRABAJADOR

tipo GEARMAN_INVALID_FUNCTION_NAME
A un trabajador se le envió una solicitud de una tarea para la que no tenía una función válida.
tipo GEARMAN_INVALID_WORKER_FUNCTION
El trabajador no proporcionó ninguna devolución de llamada para una función dada.
tipo GEARMAN_NO_REGISTERED_FUNCTION
Una solicitud para eliminar una función dada de un trabajador era inválida ya que esa función no existía.
tipo GEARMAN_NO_REGISTERED_FUNCTIONS
El trabajador no ha registrado ninguna función.
tipo GEARMAN_NO_JOBS
No se encontraron trabajos para el trabajador. Este código de error solo se devuelve
