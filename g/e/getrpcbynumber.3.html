getrpcent(3) Manual de funciones de biblioteca getrpcent(3)

NOMBRE

getrpcent, getrpcbyname, getrpcbynumber, setrpcent, endrpcent - obtener entrada RPC

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <netdb.h>
struct rpcent *getrpcent(void);
struct rpcent *getrpcbyname(const char *name);
struct rpcent *getrpcbynumber(int number);
void setrpcent(int stayopen);
void endrpcent(void);

DESCRIPCIÓN

Las funciones getrpcent(), getrpcbyname() y getrpcbynumber() devuelven un puntero a un objeto con la siguiente estructura que contiene los campos desglosados de una entrada en la base de datos de números de programa RPC.


struct rpcent {
    char  *r_name;     /* nombre del servidor para este programa RPC */
    char **r_aliases;  /* lista de alias */
    long   r_number;   /* número de programa RPC */
};

Los miembros de esta estructura son:

r_name
El nombre del servidor para este programa RPC.
r_aliases
Una lista terminada en NULL de nombres alternativos para el programa RPC.
r_number
El número de programa RPC para este servicio.

La función getrpcent() lee la siguiente entrada de la base de datos. Se abre una conexión a la base de datos si es necesario.

La función setrpcent() abre una conexión a la base de datos y establece la siguiente entrada en la primera entrada. Si stayopen no es cero, la conexión a la base de datos no se cerrará entre llamadas a una de las funciones getrpc*().

La función endrpcent() cierra la conexión a la base de datos.

Las funciones getrpcbyname() y getrpcbynumber() buscan secuencialmente desde el principio del archivo hasta que se encuentra un nombre de programa RPC o un número de programa coincidente, o hasta que se encuentra el fin de archivo.

VALOR DE RETORNO

En caso de éxito, getrpcent(), getrpcbyname() y getrpcbynumber() devuelven un puntero a una estructura rpcent estáticamente asignada. Se devuelve NULL en fin de archivo o error.

ARCHIVOS

/etc/rpc
Base de datos de números de programas RPC.
