El

Si tal carácter es seguido por dos puntos, la opción requiere un argumento, por lo que getopt() coloca un puntero al texto siguiente en el mismo elemento de argv, o el texto del siguiente elemento de argv, en optarg. Dos dos puntos significan que una opción toma un argumento opcional; si hay texto en el elemento de argv actual (es decir, en la misma palabra que el nombre de la opción misma, por ejemplo, "-oarg"), entonces se devuelve en optarg, de lo contrario optarg se establece a cero. Esta es una extensión de GNU. Si optstring contiene W seguido de un punto y coma, entonces -W foo se trata como la opción larga --foo. permuta

el contenido de argv mientras lo escanea, de modo que eventualmente todas las no opciones están al final. También se implementan otros dos modos de escaneo. Si el primer carácter de optstring es '+' o la variable de entorno POSIXLY_CORRECT está establecida, entonces el procesamiento de opciones se detiene tan pronto como se encuentra un argumento que no es una opción. Si '+' no es el primer carácter de optstring, se trata como una opción normal. Si se requiere el comportamiento POSIXLY_CORRECT en este caso optstring contendrá dos símbolos '+'. Si el primer carácter de optstring es '-', entonces cada elemento de argv que no es una opción se maneja como si fuera el argumento de una opción con código de carácter 1. (Esto es usado por programas que fueron escritos para esperar opciones y otros elementos de argv en cualquier orden y que se preocupan por el orden de los dos.) NOTA

S

Un programa que escanea múltiples vectores de argumentos, o que vuelve a escanear el mismo vector más de una vez, y quiere hacer uso de extensiones de GNU como '+' y '-' al inicio de optstring, o cambia el valor de POSIXLY_CORRECT entre escaneos, debe reinicializar getopt() restableciendo optind a 0, en lugar del valor tradicional de 1. (Restablecer a 0 fuerza la invocación de una rutina de inicialización interna que vuelve a verificar POSIXLY_CORRECT y busca extensiones de GNU en optstri

ng.)

Los argumentos de la línea de comandos se analizan en orden estricto, lo que significa que una opción que requiere un argumento consumirá el siguiente argumento, independientemente de si ese argumento es el argumento de opción correctamente especificado o simplemente la siguiente opción (en el escenario en que el usuario especifica incorrectamente la línea de comandos). Por ejemplo, si optstring se especifica como "1n:" y el usuario especifica los argumentos de la línea de comandos incorrectamente como prog -n -1, a la opción -n se le dará el valor optarg "-1", y la opción -1 será conside

rada como no
especificada.

getopt(

)

El siguiente programa de ejemplo trivial utiliza getopt() para manejar dos opciones de programa: -n, sin valor asociado; y -t val, que espera un valor

asociado. 
#include <stdio.h>
#include <stdlib.h>
#include <unistd.h>
int
main(int argc, char *argv[])
{
    int flags, opt;
    int nsecs, tfnd;
    nsecs = 0;
    tfnd = 0;
    flags = 0;
    while ((opt = getopt(argc, argv, "nt:")) != -1) {
        switch (opt) {
        case 'n':
            flags = 1;
            break;
        case 't':
            nsecs = atoi(optarg);
            tfnd = 1;
            break;
        default: /* '?' */
            fprintf(stderr, "Usage: %s [-t nsecs] [-n] name\n",
                    argv[0]);
            exit(EXIT_FAILURE);
        }
    }
    printf("flags=%d; tfnd=%d; nsecs=%d; optind=%d\n",
           flags, tfnd, nsecs, optind);
    if (optind >= argc) {
        fprintf(stderr, "Expected argument after options\n");
        exit(EXIT_FAILURE);
    }
    printf("name argument = %s\n", argv[optind]);
    /* Other code omitted */
    exit(EXIT_SUCCESS);
}

getopt_long(

)

El siguiente programa de ejemplo ilustra el uso de getopt_long() con la mayoría de sus características

. 
#include <getopt.h>
#include <stdio.h>     /* for printf */
#include <stdlib.h>    /* for exit */
int
main(int argc, char *argv[])
{
    int c;
    int digit_optind = 0;
    while (1) {
        int this_option_optind = optind ? optind : 1;
        int option_index = 0;
        static struct option long_options[] = {
            {"add",     required_argument, 0,  0 },
            {"append",  no_argument,       0,  0 },
            {"delete",  required_argument, 0,  0 },
            {"verbose", no_argument,       0,  0 },
            {"create",  required_argument, 0, 'c'},
            {"file",    required_argument, 0,  0 },
            {0,         0,                 0,  0 }
        };
        c = getopt_long(argc, argv, "abc:d:012",
                        long_options, &option_index);
        if (c == -1)
            break;
        switch (c) {
        case 0:
            printf("option %s", long_options[option_index].name);
            if (optarg)
                printf(" with arg %s", optarg);
            printf("\n");
            break;
        case '0':
        case '1':
        case '2':
            if (digit_optind != 0 && digit_optind != this_option_optind)
              printf("digits occur in two different argv-elements.\n");
            digit_optind = this_option_optind;
            printf("option %c\n", c);
            break;
        case 'a':
            printf("option a\n");
            break;
        case 'b':
            printf("option b\n");
            break;
        case 'c':
            printf("option c with value '%s'\n", optarg);
            break;
        case 'd':
            printf("option d with value '%s'\n", optarg);
            break;
        case '?':
            break;
        default:
            printf("?? getopt returned character code 0%o ??\n", c);
        }
    }
    if (optind < argc) {
        printf("non-option ARGV-elements: ");
        while (optind < argc)
            printf("%s ", argv[optind++]);
        printf("\n");
    }
    exit(EXIT_SUCCESS)
;
}
