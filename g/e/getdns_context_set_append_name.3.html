DESCRIPCIÓN

Estas funciones se utilizan para manipular un contexto previamente asignado e inicializado. Consulte getdns_context (3) para obtener más detalles sobre las funciones utilizadas para asignar, inicializar y destruir contextos, y para una discusión más detallada sobre getdns_context en general.

getdns_context_set_append_name Especifica si se debe agregar un sufijo proporcionado a través de getdns_context_set_suffix (3) a la cadena de consulta antes de que la API comience a resolver un nombre.

getdns_context_set_context_update_callback establece una función que se llamará si hay cambios en los archivos del sistema (por ejemplo, /etc/resolv.conf y /etc/hosts).

getdns_context_set_dns_transport especifica el transporte utilizado para las búsquedas DNS. El valor predeterminado es usar UDP y recurrir a TCP si es necesario.

getdns_context_set_dnssec_trust_anchors permite al llamador especificar anclas de confianza como alternativas a las anclas de confianza predeterminadas.

getdns_context_set_dnssec_allowed_skew establece el número de segundos de desfase permitido en cualquier dirección al verificar los campos de expiración e inicio de un RRSIG. El valor predeterminado es 0.

getdns_context_set_limit_outstanding_queries especifica el número máximo de consultas DNS pendientes. La API pondrá en cola las consultas que superen este límite hasta que las consultas actuales sean respuestas y luego emitirá automáticamente las consultas de la cola.

getdns_context_set_dns_root_servers proporciona un conjunto alternativo de direcciones para buscar los dominios de nivel superior. El valor predeterminado (si esta función no se llama) es la lista de servidores raíz de IANA (piense en esto como las sugerencias raíz).

getdns_context_set_follow_redirects especifica si las consultas DNS siguen o no las redirecciones (CNAME y DNAME). El comportamiento predeterminado es seguir las redirecciones y devolver el destino final.

getdns_context_set_namespaces establece los espacios de nombres que serán utilizados por el resolvedor. El valor predeterminado es DNS y luego archivos locales. Las implementaciones futuras admitirán netbios, mdns y nis.

getdns_context_set_resolution_type especifica si las consultas DNS se realizan con búsquedas no recursivas o como un resolvedor stub.

getdns_context_set_suffix Agrega sufijos a los nombres de dominio antes de ejecutar la búsqueda basándose en getdns_context_set_append_name.

getdns_context_set_timeout especifica el número de milisegundos que la API esperará una respuesta.

context un getdns_context previamente asignado e inicializado

callback una función de devolución de llamada que se llamará cuando se realicen cambios en los archivos del sistema (/etc/resolv.conf y /etc/hosts) para los contextos creados con set_from_os = 1. Cuando se llama a esta función, el parámetro changed_item indica qué elemento del contexto ha cambiado.

root_addresses Esta es una lista de tipos getdns_dict que identifican cada servidor raíz a utilizar para buscar dominios de nivel superior. Cada diccionario incluye dos nombres, address_type , un bindata que contiene la cadena "IPv4" o "IPv6" y address_data un bindata que contiene la dirección IP.

transport puede ser uno de GETDNS_CONTEXT_UDP_FIRST_AND_FALL_BACK_TO_TCP, GETDNS_CONTEXT_UDP_ONLY, GETDNS_CONTEXT_TCP_ONLY, GETDNS_CONTEXT_TCP_ONLY_KEEP_CONNECTIONS_OPEN. Si necesita más información sobre lo que significa cada uno, vuelva a leer la mnemotecnia y adivine ;)

followredir Si se establece en GETDNS_REDIRECTS_FOLLOW (el valor predeterminado), se devuelve el destino final de la redirección. Si se establece en GETDNS_REDIRECTS_DO_NOT_FOLLOW, se devuelve el CNAME o DNAME y NO el destino final.

limit El número máximo de consultas DNS pendientes (sin respuesta) simultáneas. Si se excede, la API pondrá en cola las consultas y las emitirá a medida que el número de consultas pendientes disminuya. Un valor de 0 indica que no hay límite.

namespaces La matriz de espacios de nombres contiene una lista ordenada de espacios de nombres que se consultarán. Importante: esta configuración del contexto se ignora para las funciones getdns_general y getdns_general_sync; se utiliza para las otras funciones. Los valores son GETDNS_CONTEXT_NAMESPACE_DNS, GETDNS_CONTEXT_NAMESPACE_LOCALNAMES, GETDNS_CONTEXT_NAMESPACE_NETBIOS, GETDNS_CONTEXT_NAMESPACE_MDNS y GETDNS_CONTEXT_NAMESPACE_NIS. Cuando se realiza una búsqueda normal, la API realiza las búsquedas en el orden dado y se detiene cuando obtiene el primer resultado; un método diferente con el mismo resultado sería ejecutar las consultas en paralelo y devolver cuando se obtenga el primer resultado. Dado que las búsquedas pueden realizarse a través de diferentes mecanismos debido a los diferentes espacios de nombres, puede haber fugas de información similares a las que se ven con getaddrinfo(). El valor predeterminado lo determina el sistema operativo.

restype Puede establecerse en GETDNS_CONTEXT_RECURSIVE (el valor predeterminado) o GETDNS_CONTEXT_STUB (requiere que el llamador especifique los forwards).

seconds_skew El número de segundos de desfase permitido en cualquier dirección al verificar los campos de expiración e inicio de un RRSIG.

suffixes Una lista de bindatas que son cadenas que se agregarán según getdns_context_set_append_name. Los valores aquí siguen las reglas de la sección 2.1 de RFC 4343 para permitir octetos no ASCII y caracteres especiales en las etiquetas.

timeout El número de milisegundos que la API esperará una respuesta, después de lo cual se invocará la devolución de llamada (o la función síncrona devolverá) con un error de tiempo de espera.

trust_anchors lista de bindatas que son las anclas de confianza DNSSEC expresadas como RDATA de los registros de recursos DNSKEY, los predeterminados son proporcionados por la raíz de IANA.

when_to_append El valor es

  • GETDNS_APPEND_NAME_ALWAYS,
  • GETDNS_APPEND_NAME_ONLY_TO_SINGLE_LABEL_AFTER_FAILURE,
  • GETDNS_APPEND_NAME_ONLY_TO_MULTIPLE_LABEL_NAME_AFTER_FAILURE, o
  • GETDNS_APPEND_NAME_NEVER.

DESCRIPTION

These functions are used to set general options on a getdns_context object.

The default behavior for most of these functions is described in getdns_context(3).

getdns_context_set_append_name
This function sets the append_name behavior. When set to true, getdns will append the suffix from the search list to names which are not fully qualified.
getdns_context_set_suffix
This function sets the suffix list. This list is used when getdns_context_set_append_name is set to true.
getdns_context_set_dns_port
This function sets the port to be used for DNS queries.
getdns_context_set_listen
This function sets the list of IP addresses and ports to listen on for incoming DNS queries. This is used for stub resolvers.
getdns_context_set_timeout
This function sets the timeout in milliseconds for DNS queries.
getdns_context_set_resolution_type
This function sets the resolution type. The possible values are GETDNS_RESOLUTION_STUB and GETDNS_RESOLUTION_NODE.
getdns_context_set_edns_present
This function sets whether EDNS options are present.
getdns_context_set_edns_udp_size
This function sets the EDNS UDP payload size.
getdns_context_set_dns_transport
This function sets the DNS transport mechanism. The possible values are GETDNS_TRANSPORT_UDP, GETDNS_TRANSPORT_TCP, and GETDNS_TRANSPORT_TLS.
getdns_context_set_tls_authentication
This function sets the TLS authentication mode. The possible values are GETDNS_AUTHENTICATION_NONE, GETDNS_AUTHENTICATION_HOSTNAME, GETDNS_AUTHENTICATION_PUBKEY, and GETDNS_AUTHENTICATION_BOTH.
getdns_context_set_tls_query_interval
This function sets the interval in seconds for querying TLS certificates.
getdns_context_set_tls_ca_file
This function sets the path to the CA certificate file for TLS authentication.
getdns_context_set_tls_ca_dir
This function sets the path to the CA certificate directory for TLS authentication.
getdns_context_set_tls_hostname
This function sets the hostname for TLS authentication.
getdns_context_set_tls_pubkey_file
This function sets the path to the public key file for TLS authentication.
getdns_context_set_tls_pubkey_dir
This function sets the path to the public key directory for TLS authentication.
getdns_context_set_tls_fingerprint
This function sets the TLS fingerprint for authentication.
getdns_context_set_round_robin_balance
This function sets the round-robin balancing behavior for multiple DNS servers.
getdns_context_set_dns_server_ip_PORT
This function sets a single DNS server IP address and port. The dictionary should have keys "address_type", "address_data" and "port".
getdns_context_set_dns_server_ip_PORT_array
This function sets an array of DNS server IP addresses and ports. Each element in the list should be a dictionary as described for getdns_context_set_dns_server_ip_PORT.
getdns_context_set_node
This function sets the node configuration for resolution.
getdns_context_set_search
This function sets the search list for domain name resolution.
getdns_context_set_limits
This function sets various limits on the resolution process. The dictionary can contain the following keys: "idle", "timeout", "rootns_timeout", "retransmissions".
getdns_context_set_num_threads
This function sets the number of threads to be used by the getdns library. This should be called before creating the context.

RETURN VALUES

Upon successful completion the functions return GETDNS_RETURN_GOOD, otherwise the following error values are returned:

GETDNS_RETURN_BAD_CONTEXT if the context pointer is invalid

GETDNS_RETURN_CONTEXT_UPDATE_FAIL if there was a problem updating the context
