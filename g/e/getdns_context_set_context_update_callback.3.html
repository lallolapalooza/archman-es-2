getdns_context_set_context_update_callback(3)

Paquete: getdns

Licencias: BSD

getdns_context_set_context_update_callback(3) getdns getdns_context_set_context_update_callback(3)

NOMBRE

getdns_context_set_context_update_callback -- ser informado sobre las actualizaciones del contexto de getdns

BIBLIOTECA

Biblioteca del Resolvedor DNS (libgetdns, -lgetdns)

SINOPSIS

#include <getdns.h>

getdns_return_t
getdns_context_set_context_update_callback (getdns_context ** context,


void (*cbfun)(getdns_context *context, getdns_context_code_t changed_item)

DESCRIPCIÓN

Los cambios en el contexto, como los que responden a archivos del sistema que afectan al contexto (/etc/resolv.conf etc.), activan una llamada a la función de devolución de llamada especificada como cbfun

context un contexto previamente inicializado

cbfun función de devolución de llamada a invocar cuando cambia el contexto especificado. Si este argumento es NULL, las actualizaciones del contexto no invocarán una devolución de llamada.

VALORES DE RETORNO

Al completarse con éxito, cada una de estas funciones devuelve GETDNS_RETURN_GOOD , de lo contrario, se devuelven los siguientes valores de error:

GETDNS_RETURN_GENERIC_ERROR error en la asignación de memoria o sucedió algo inesperado

GETDNS_RETURN_BAD_CONTEXT si el puntero de contexto es inválido
