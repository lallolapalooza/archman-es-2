getdns_cancel_callback(3)

Paquete: getdns

Licencias: BSD

getdns_cancel_callback(3) getdns getdns_cancel_callback(3)

NOMBRE

getdns_cancel_callback -- cancelar una solicitud asíncrona pendiente de getdns

BIBLIOTECA

Biblioteca de resolución DNS (libgetdns, -lgetdns)

SINOPSIS

#include <getdns.h>

getdns_return_t
getdns_cancel_callback (getdns_context_t context,


getdns_transaction_t *transaction_id)

DESCRIPCIÓN

Para cancelar una devolución de llamada pendiente, utilice getdns_cancel_callback. Esto hace que la API llame a la devolución de llamada con un tipo de devolución de llamada de GETDNS_CALLBACK_CANCEL si la devolución de llamada para este transaction_id aún no se ha realizado. El código de devolución de llamada para la cancelación debe limpiar cualquier memoria relacionada con la llamada identificada, como la desasignación de memoria para el userarg. getdns_cancel_callback() puede devolver inmediatamente, incluso antes de que la devolución de llamada termine su trabajo y retorne.

context véase getdns_context (3)

transaction_id poblado por la API y utilizado para identificar la devolución de llamada (por ejemplo, para getdns_cancel_callback), puede ser NULL, establecido en 0 si la función falla

VALORES DE RETORNO

Tras una ejecución correcta, las funciones devuelven GETDNS_RETURN_GOOD, de lo contrario, se devuelven los siguientes valores de error:

GETDNS_RETURN_INVALID_PARAMETER si context == NULL

GETDNS_RETURN_UNKNOWN_TRANSACTION si el transaction_id es desconocido o pertenece a una devolución de llamada que ya se ha realizado
