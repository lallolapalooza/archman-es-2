NOMBRE

getcifsacl - Utilidad del espacio de usuario para mostrar una ACL en un descriptor de seguridad para Common Internet File System (CIFS)

SINOPSIS

getcifsacl [-v|-r] {objeto del sistema de archivos}

DESCRIPCIÓN

Esta herramienta forma parte del conjunto de utilidades cifs-utils.

getcifsacl es un programa de ayuda del espacio de usuario para el sistema de archivos cliente CIFS de Linux. Está diseñado para mostrar un descriptor de seguridad, incluyendo DACL y SACL, para un objeto del sistema de archivos.

Este programa utiliza un plugin para manejar el mapeo de SIDs a nombres de usuario y grupo. /etc/cifs-utils/idmap-plugin debería ser un enlace simbólico que apunte al plugin correcto a usar.

Los campos de un ACE, como SID, tipo, banderas y máscara, se muestran separados por /. Los valores numéricos de tipo, banderas y máscara se muestran en formato hexadecimal.

OPCIONES

-v
Imprimir el número de versión y salir.
-r
Mostrar un descriptor de seguridad en modo crudo. Valores como tipo y banderas se muestran en formato hexadecimal, un SID no se mapea a un nombre.
-R
Listar las ACL de todos los archivos y directorios recursivamente.

NOTAS

El soporte del kernel para las utilidades getcifsacl/setcifsacl se introdujo inicialmente en el kernel 2.6.37.

VER TAMBIÉN

mount.cifs(8), setcifsacl(1)
