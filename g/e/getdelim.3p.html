DESCRIPCIÓ

N

La función getdelim() leerá desde stream hasta que encuentre un carácter que coincida con el carácter delimiter. El argumento delimiter es un int, cuyo valor la aplicación deberá asegurar que sea un carácter representable como un unsigned char de igual valor que termine el proceso de lectura. Si el argumento delimiter tiene cualquier otro valor, el comportamiento es

indefinido.

La aplicación deberá asegurar que *lineptr es un argumento válido que podría pasarse a la función free(). Si *n es distinto de cero, la aplicación deberá asegurar que *lineptr apunte a un objeto de tamaño de al menos *n bytes, o que sea un puntero

nulo.

Si *lineptr es un puntero nulo o si el objeto al que apunta *lineptr es de tamaño insuficiente, se asignará un objeto como si fuera por malloc() o se reasignará el objeto como si fuera por realloc(), respectivamente, de modo que el objeto sea lo suficientemente grande para contener los caracteres que se escribirán en él, incluyendo el NUL terminador, y *n se establecerá al nuevo tamaño. Si el objeto fue asignado, o si la operación de realocación movió el objeto, *lineptr se actualizará para que apunte al nuevo objeto o a la nueva ubicación. Los caracteres leídos, incluyendo cualquier delimitador, se almacenarán en el objeto, y se añadirá un NUL terminador cuando se encuentre el delimitador o el fin de

archivo.

La función getline() será equivalente a la función getdelim() con el carácter delimitador igual al carácter <newline>

.

Las funciones getdelim() y getline() pueden marcar la marca de tiempo de acceso a datos más reciente del archivo asociado con stream para su actualización. La marca de tiempo de acceso a datos más reciente se marcará para actualización por la primera ejecución exitosa de fgetc(), fgets(), fread(), fscanf(), getc(), getchar(), getdelim(), getline(), gets() o scanf() usando stream que devuelva datos no proporcionados por una llamada previa a unge

tc(
).

VALOR

DEVUELTO

Tras la finalización exitosa, las funciones getline() y getdelim() devolverán el número de bytes escritos en el búfer, incluyendo el carácter delimitador si se encontró alguno antes del EOF, pero excluyendo el carácter NUL terminador. Si el indicador de fin de archivo del flujo está activado, o si no se leyeron caracteres y el flujo está en fin de archivo, el indicador de fin de archivo del flujo se activará y la función devolverá -1. Si ocurre un error, el indicador de error del flujo se activará, y la función devolverá -1 y establecerá errno para ind

icar el
error.

USO EN

APLICACIONES

Establecer *lineptr a un puntero nulo y *n a cero está permitido y es una forma recomendada de comenzar a analizar un

archivo.

Las funciones ferror() o feof() deberían usarse para distinguir entre una condición de error y una condición de fin de

archivo.

Aunque siempre se proporciona un terminador NUL después de la línea, tenga en cuenta que strlen(*lineptr) será menor que el valor devuelto si

la línea contiene car
acteres NUL incrustados.

JUSTIFICACIÓ

N

Estas funciones se usan ampliamente para resolver el problema que la función fgets() tiene con las líneas largas. Las funciones amplían automáticamente los búfers de destino

si es necesario. Son especialmente útiles ya que
reducen el código necesario para las aplicaciones.
