GETUNIMAP(8) Manual del Administrador del Sistema GETUNIMAP(8)

NOMBRE

getunimap - vuelca el mapa unicode de la consola actual a la salida estándar

SINOPSIS

getunimap [opciones]

DESCRIPCIÓN

El programa getunimap es antiguo y obsoleto. Ahora forma parte de setfont (1).

El programa getunimap genera el mapa unicode (también llamado "Mapa de Fuente de Pantalla") para la consola actual a la salida estándar.

La opción -C puede usarse con Linux 2.6.1 y posteriores para obtener el mapa de una consola diferente a la actual. Su argumento es una ruta de archivo.

La salida de getunimap tiene el formato

0xAA U+1234 # comentario

donde 0xAA es el código del carácter de fuente y U+1234 es un carácter unicode, que si se muestra, se mostrará usando el glifo 0xAA en la fuente. Muchos caracteres unicode pueden mapearse al mismo glifo.
el símbolo de almohadilla # se usa como delimitador de comentarios; los caracteres después de un signo de almohadilla (hasta el final de la línea) son comentarios.

La opción -s ordenará y fusionará elementos, ordenando por carácter de fuente. Por lo tanto, producirá una salida del tipo:

0x22 U+1234 U+5678 U+3456
0x23 U+0023

etc., listando los múltiples caracteres unicode que se mapean a un glifo de fuente.

La salida de getunimap tiene el formato aceptado por setfont y psfaddtable

OPCIONES

-s, --sort
ordenar y fusionar elementos.
-C, --console=DEV
el dispositivo de consola a utilizar.
-V, --version
mostrar número de versión.
-h, --help
mostrar este mensaje de uso.

VER TAMBIÉN

psfaddtable(1), setfont(1).
