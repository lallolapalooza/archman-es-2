getentropy(3) Manual de funciones de biblioteca getentropy(3)

NOMBRE

getentropy - llenar un búfer con bytes aleatorios

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <unistd.h>
int getentropy(size_t longitud;
               void buffer[longitud], size_t longitud);
Requisitos de macro de prueba de características para glibc (ver feature_test_macros(7)):

getentropy():

    _DEFAULT_SOURCE

DESCRIPCIÓN

La función getentropy() escribe longitud bytes de datos aleatorios de alta calidad en el búfer que comienza en la ubicación a la que apunta buffer. El valor máximo permitido para el argumento longitud es 256.

Una llamada exitosa a getentropy() siempre proporciona el número de bytes de entropía solicitado.

VALOR DE RETORNO

En caso de éxito, esta función devuelve cero. En caso de error, se devuelve -1 y errno se establece para indicar el error.

ERRORES

EFAULT
Parte o la totalidad del búfer especificado por buffer y longitud no se encuentra en memoria válida direccionable.
EIO
longitud es mayor que 256.
EIO
Ocurrió un error no especificado al intentar sobrescribir buffer con datos aleatorios.
ENOSYS
Esta versión del kernel no implementa la llamada al sistema getrandom(2) requerida para implementar esta función.

ESTÁNDARES

Ninguno.

HISTORIA

glibc 2.25. OpenBSD.

NOTAS

La función getentropy() se implementa utilizando getrandom(2).

Mientras que el envoltorio de glibc hace de getrandom(2) un punto de cancelación, getentropy() no es un punto de cancelación.

getentropy() también se declara en <sys/random.h>. (No es necesario definir ninguna macro de prueba de características para obtener la declaración de ese archivo de cabecera.)

Una llamada a getentropy() puede bloquearse si el sistema acaba de arrancar y el kernel aún no ha recopilado suficiente aleatoriedad para inicializar el grupo de entropía. En este caso, getentropy() seguirá bloqueándose incluso si se maneja una señal, y solo devolverá una vez que el grupo de entropía se haya inicializado.

VER TAMBIÉN

getrandom(2), urandom(4), random(7)
