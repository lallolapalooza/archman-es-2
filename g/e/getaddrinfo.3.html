Si hints.ai_flags incluye el AI_ADDRCONFIG indicador, entonces se devuelven direcciones IPv4 en la lista apuntada por res solo si el sistema local tiene al menos una dirección IPv4 configurada, y las direcciones IPv6 se devuelven solo si el sistema local tiene al menos una dirección IPv6 configurada. La dirección de bucle (loopback) no se considera en este caso como válida como una dirección configurada. Este indicador es útil en, por ejemplo, sistemas solo IPv4, para asegurar que getaddrinfo() no devuelva direcciones de socket IPv6 que siempre fallarían en connect(2) o bind(2).

Si hints.ai_flags especifica el AI_V4MAPPED indicador, y hints.ai_family se especificó como AF_INET6, y no se pudieron encontrar direcciones IPv6 coincidentes, entonces se devuelven direcciones IPv6 mapeadas desde IPv4 en la lista apuntada por res. Si tanto AI_V4MAPPED como AI_ALL se especifican en hints.ai_flags, entonces se devuelven tanto direcciones IPv6 como direcciones IPv6 mapeadas desde IPv4 en la lista apuntada por res. AI_ALL se ignora si AI_V4MAPPED no se especifica también.

Extensiones a getaddrinfo() para Nombres de Dominio Internacionalizados

A partir de glibc 2.3.4, getaddrinfo() ha sido extendida para permitir selectivamente que los nombres de host entrantes y salientes sean convertidos transparentemente a y desde el formato de Nombre de Dominio Internacionalizado (IDN) (ver RFC 3490, Internationalizing Domain Names in Applications (IDNA)). Se definen cuatro nuevos indicadores:

AI_IDN
Si se especifica este indicador, entonces el nombre de nodo dado en node se convierte al formato IDN si es necesario. La codificación de origen es la del locale actual.
Si el nombre de entrada contiene caracteres no ASCII, entonces se usa la codificación IDN. Aquellas partes del nombre de nodo (delimitadas por puntos) que contienen caracteres no ASCII son codificadas usando ASCII Compatible Encoding (ACE) antes de ser pasadas a las funciones de resolución de nombres.
AI_CANONIDN
Después de una búsqueda de nombre exitosa, y si el AI_CANONNAME indicador fue especificado, getaddrinfo() devolverá el nombre canónico del nodo correspondiente al valor de la estructura addrinfo devuelto. El valor de retorno es una copia exacta del valor devuelto por la función de resolución de nombres.
Si el nombre está codificado usando ACE, entonces contendrá el xn-- prefijo para uno o más componentes del nombre. Para convertir estos componentes a una forma legible, el indicador AI_CANONIDN puede pasarse además a AI_CANONNAME. La cadena resultante está codificada usando la codificación del locale actual.
AI_IDN_ALLOW_UNASSIGNED
AI_IDN_USE_STD3_ASCII_RULES
Establecer estos indicadores habilitará los indicadores IDNA_ALLOW_UNASSIGNED (permitir puntos de código Unicode no asignados) y IDNA_USE_STD3_ASCII_RULES (verificar la salida para asegurarse de que es un nombre de host conforme a STD3) respectivamente para ser usados en el manejo de IDNA.

VALOR DE RETORNO

getaddrinfo() devuelve 0 si tiene éxito, o uno de los siguientes códigos de error no nulos:

EAI_ADDRFAMILY
El host de red especificado no tiene ninguna dirección de red en la familia de direcciones solicitada.
EAI_AGAIN
El servidor de nombres devolvió una indicación de fallo temporal. Intente de nuevo más tarde.
EAI_BADFLAGS
hints.ai_flags contiene indicadores inválidos; o, hints.ai_flags incluía AI_CANONNAME y node era NULL.
EAI_FAIL
El servidor de nombres devolvió una indicación de fallo permanente.
EAI_FAMILY
La familia de direcciones solicitada no es soportada.
EAI_MEMORY
Memoria agotada.
EAI_NODATA
El host de red especificado existe, pero no tiene ninguna dirección de red definida.
EAI_NONAME
El node o service no es conocido; o ambos node y service son NULL; o AI_NUMERICSERV fue especificado en hints.ai_flags y service no era una cadena de número de puerto numérico.
EAI_SERVICE
El servicio solicitado no está disponible para el tipo de socket solicitado. Puede estar disponible a través de otro tipo de socket. Por ejemplo, este error podría ocurrir si service era "shell" (un servicio disponible solo en sockets de flujo), y ya sea hints.ai_protocol era IPPROTO_UDP, o hints.ai_socktype era SOCK_DGRAM; o el error podría ocurrir si service no era NULL, y hints.ai_socktype era SOCK_RAW (un tipo de socket que no soporta el concepto de servicios).
EAI_SOCKTYPE
El tipo de socket solicitado no es soportado. Esto podría ocurrir, por ejemplo, si hints.ai_socktype y hints.ai_protocol son inconsistentes (p. ej., SOCK_DGRAM y IPPROTO_TCP, respectivamente).
EAI_SYSTEM
Otro error del sistema; errno se establece para indicar el error.

La gai_strerror() función traduce estos códigos de error a una cadena legible para humanos, adecuada para la notificación de errores.

EJEMPLOS

Los siguientes programas demuestran el uso de getaddrinfo(), gai_strerror(), freeaddrinfo(), y getnameinfo(3). Los programas son un servidor eco y un cliente para datagramas UDP.

Programa del servidor

#include <netdb.h>
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <sys/socket.h>
#include <sys/types.h>
#include <unistd.h>
#define BUF_SIZE 500
int
main(int argc, char *argv[])
{
    int                      sfd, s;
    char                     buf[BUF_SIZE];
    ssize_t                  nread;
    socklen_t                peer_addrlen;
    struct addrinfo          hints;
    struct addrinfo          *result, *rp;
    struct sockaddr_storage  peer_addr;
    if (argc != 2) {
        fprintf(stderr, "Usage: %s port\n", argv[0]);
        exit(EXIT_FAILURE);
    }
    memset(&hints, 0, sizeof(hints));
    hints.ai_family = AF_UNSPEC;    /* Allow IPv4 or IPv6 */
    hints.ai_socktype = SOCK_DGRAM; /* Datagram socket */
    hints.ai_flags = AI_PASSIVE;    /* For wildcard IP address */
    hints.ai_protocol = 0;          /* Any protocol */
    hints.ai_canonname = NULL;
    hints.ai_addr = NULL;
    hints.ai_next = NULL;
    s = getaddrinfo(NULL, argv[1], &hints, &result);
    if (s != 0) {
        fprintf(stderr, "getaddrinfo: %s\n", gai_strerror(s));
        exit(EXIT_FAILURE);
    }
    /* getaddrinfo() returns a list of address structures.
       Try each address until we successfully bind(2).
       If socket(2) (or bind(2)) fails, we (close the socket
       and) try the next address.  */
    for (rp = result; rp != NULL; rp = rp->ai_next) {
        sfd = socket(rp->ai_family, rp->ai_socktype,
                     rp->ai_protocol);
        if (sfd == -1)
            continue;
        if (bind(sfd, rp->ai_addr, rp->ai_addrlen) == 0)
            break;                  /* Success */
        close(sfd);
    }
    freeaddrinfo(result);           /* No longer needed */ */
    if (rp == NULL) {               /* No address succeeded */
        fprintf(stderr, "Could not bind\n");
        exit(EXIT_FAILURE);
    }
    /* Read datagrams and echo them back to sender.  */
    for (;;) {
        char host[NI_MAXHOST], service[NI_MAXSERV];
        peer_addrlen = sizeof(peer_addr);
        nread = recvfrom(sfd, buf, BUF_SIZE, 0,
                         (struct sockaddr *) &peer_addr, &peer_addrlen);
        if (nread == -1)
            continue;               /* Ignore failed request */
        s = getnameinfo((struct sockaddr *) &peer_addr,
                        peer_addrlen, host, NI_MAXHOST,
                        service, NI_MAXSERV, NI_NUMERICSERV);
        if (s == 0)
            printf("Received %zd bytes from %s:%s\n",
                   nread, host, service);
        else
            fprintf(stderr, "getnameinfo: %s\n", gai_strerror(s));
        if (sendto(sfd, buf, nread, 0, (struct sockaddr *) &peer_addr,
                   peer_addrlen) != nread)
        {
            fprintf(stderr, "Error sending response\n");
        }
    }
}

Programa cliente

#include <netdb.h>
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <sys/socket.h>
#include <sys/types.h>
#include <unistd.h>
#define BUF_SIZE 500
int
main(int argc, char *argv[])
{
    int              sfd, s;
    char             buf[BUF_SIZE];
    size_t           size;
    ssize_t          nread;
    struct addrinfo  hints;
    struct addrinfo  *result, *rp;
    if (argc < 3) {
        fprintf(stderr, "Usage: %s host port msg...\n", argv[0]);
        exit(EXIT_FAILURE);
    }
    /* Obtain address(es) matching host/port.  */
    memset(&hints, 0, sizeof(hints));
    hints.ai_family = AF_UNSPEC;    /* Allow IPv4 or IPv6 */
    hints.ai_socktype = SOCK_DGRAM; /* Datagram socket */
    hints.ai_flags = 0;
    hints.ai_protocol = 0;          /* Any protocol */
    s = getaddrinfo(argv[1], argv[2], &hints, &result);
    if (s != 0) {
        fprintf(stderr, "getaddrinfo: %s\n", gai_strerror(s));
        exit(EXIT_FAILURE);
    }
    /* getaddrinfo() returns a list of address structures.
       Try each address until we successfully connect(2).
       If socket(2) (or connect(2)) fails, we (close the socket
       and) try the next address.  */
    for (rp = result; rp != NULL; rp = rp->ai_next) {
        sfd = socket(rp->ai_family, rp->ai_socktype,
                     rp->ai_protocol);
        if (sfd == -1)
            continue;
        if (connect(sfd, rp->ai_addr, rp->ai_addrlen) != -1)
            break;                  /* Success */
        close(sfd);
    }
    freeaddrinfo(result);           /* No longer needed */
    if (rp == NULL) {               /* No address succeeded */
        fprintf(stderr, "Could not connect\n");
        exit(EXIT_FAILURE);
    }
    /* Send remaining command-line arguments as separate
       datagrams, and read responses from server.  */
    for (size_t j = 3; j < argc; j++) {
        size = strlen(argv[j]) + 1;
                /* +1 for terminating null byte */
        if (size > BUF_SIZE) {
            fprintf(stderr,
                    "Ignoring long message in argument %zu\n", j);
            continue;
        }
        if (write(sfd, argv[j], size) != size) {
            fprintf(stderr, "partial/failed write\n");
            exit(EXIT_FAILURE);
        }
        nread = read(sfd, buf, BUF_SIZE);
        if (nread == -1) {
            perror("read");
            exit(EXIT_FAILURE);
        }
        printf("Received %zd bytes: %s\n", nread, buf);
    }
    exit(EXIT_SUCCESS);
}
