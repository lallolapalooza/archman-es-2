NOMBRE

gencmn - generar un archivo de datos mapeable en memoria de ICU

SINOPSIS

gencmn [ -h, -?, --help ] [ -v, --verbose ] [ -c, --copyright | -C, --comment comentario ] [ -d, --destdir destino ] [ -n, --name nombre ] [ -t, --type extensión ] [ -S, --source ] [ -e, --entrypoint nombre ] tamañomax [ nombreficherolista ]

DESCRIPCIÓN

gencmn toma un conjunto de archivos y los empaqueta como un archivo de datos de ICU mapeable en memoria. El archivo de datos resultante puede ser utilizado directamente por ICU.

gencmn lee una lista de archivos a empaquetar desde el archivo nombreficherolista suministrado, o desde su salida estándar. Empaqueta todos los archivos de la lista que no sean mayores que tamañomax bytes, excepto si tamañomax es 0, lo que indica que no hay límite de tamaño para los archivos.

OPCIONES

-h, -?, --help
Imprime ayuda sobre el uso y sale.
-v, --verbose
Muestra mensajes informativos adicionales durante la ejecución.
-c,--copyright
Incluye el aviso de copyright de ICU en los datos resultantes.
-C, --comment comentario
Incluye el comentario especificado en los datos resultantes en lugar del aviso de copyright de ICU.
-d, --destdir destino
Establece el directorio de destino a destino. El directorio de destino por defecto es especificado por la variable de entorno ICU_DATA.
-n, --name nombre
Establece el nombre de los datos a nombre en lugar del valor por defecto. Este nombre también se usa como el nombre base de la salida. El nombre por defecto está compuesto por el prefijo icudt, seguido de un número de versión de dos dígitos correspondiente a la versión actual de la versión de ICU, y una sola letra que indica la endianidad de los datos (la letra b indica datos big endian, y la letra l indica little endian).
-t, --type tipo
Usa tipo como el tipo de los datos. Este tipo también se usa como la extensión del archivo de datos generado. El tipo por defecto es dat.
-S, --source
Escribe un archivo fuente C con la tabla de contenidos de los datos.
-e, --entrypoint nombre
Establece el punto de entrada de los datos (usado para enlazar contra los datos en forma de biblioteca compartida) a nombre. El nombre del punto de entrada por defecto está compuesto por los datos (establecidos por la opción -n, --name) seguido de un guion bajo y el tipo de los datos (establecido por la opción -t, --type).

AMBIENTE

ICU_DATA
Especifica el directorio que contiene los datos de ICU. Por defecto es ${prefix}/share/icu/78.1/. Algunas herramientas en ICU dependen de la presencia de la barra final. Es importante asegurarse de que esté presente si ICU_DATA está configurado.
