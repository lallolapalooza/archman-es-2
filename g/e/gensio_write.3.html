gensio_write(3) Manual de funciones de la biblioteca gensio_write(3)

NOMBRE

gensio_write - Escribe datos en un gensio

SINOPSIS

#include <gensio/gensio.h>

int gensio_write(struct gensio *io, gensiods *count,

const void *buf, gensiods buflen,
const char *const *auxdata);

struct gensio_sg {

const void *buf;
gensiods buflen;
};
int gensio_write_sg(struct gensio *io, gensiods *count,

const struct gensio_sg *sg, gensiods sglen,
const char *const *auxdata);

DESCRIPCIÓN

Escribe datos en el gensio dado. Los datos están en buf y la longitud de los datos está en buflen. Tenga en cuenta que gensio_write puede no escribir todos los datos proporcionados, dependiendo del tipo de gensio y del espacio de búfer interno. Devolverá el número de bytes realmente escritos en count, que puede ser NULL si no le importa. (Pista: casi siempre debería importarle).

Si gensio_write no puede escribir la cantidad total de datos, generalmente debería almacenar en búfer los datos no escritos y llamar a gensio_set_write_callback_enable(3) para saber cuándo puede escribir el resto de los datos. Muchas aplicaciones siempre almacenan los datos en búfer y habilitan la devolución de llamada de escritura para realizar la escritura y luego deshabilitan la devolución de llamada de escritura cuando se han escrito todos los datos, para mayor coherencia.

gensio_write nunca se bloqueará; si no puede escribir todos los datos, escribirá lo que pueda y regresará.

auxdata se utiliza para pasar datos auxiliares específicos de gensio, como el número de flujo para SCTP o si los datos están fuera de banda para SCTP o TCP.

gensio_write_sg es como gensio_write, pero toma una estructura de dispersión-agregación para permitirle combinar varios fragmentos de datos sin copiar. Tenga en cuenta que si obtiene una escritura parcial, debe determinar dónde terminó la escritura en su lista de dispersión-agregación y comenzar la siguiente escritura desde allí.

VALORES DE RETORNO

Se devuelve cero en caso de éxito, o un error de gensio en caso de fallo.

VER TAMBIÉN

gensio_err(3), gensio(5)
