DESCRIPCIÓ

N

La función getpwuid() buscará en la base de datos de usuarios una entrada con un uid coincid

ente.

La función getpwuid() no necesita ser segura en entornos con

hilos.

Las aplicaciones que deseen comprobar situaciones de error deben establecer errno a 0 antes de llamar a getpwuid(). Si getpwuid() devuelve un puntero nulo y errno está establecido a un valor distinto de cero, se produjo un

error.

La función getpwuid_r() actualizará la estructura passwd a la que apunta pwd y almacenará un puntero a esa estructura en la ubicación a la que apunta result. La estructura contendrá una entrada de la base de datos de usuarios con un uid coincidente. El almacenamiento referenciado por la estructura se asigna de la memoria proporcionada con el parámetro buffer, que tiene un tamaño de bufsize bytes. Una llamada a sysconf(_SC_GETPW_R_SIZE_MAX) devuelve -1 sin cambiar errno o un valor inicial sugerido para el tamaño de este búfer. Se devolverá un puntero nulo en la ubicación a la que apunta result en caso de error o si la

entrada solicitad
a no se encuentra.

VALOR DE

RETORNO

La función getpwuid() devolverá un puntero a un struct passwd con la estructura tal como está definida en <pwd.h> con una entrada coincidente si se encuentra. Se devolverá un puntero nulo si la entrada solicitada no se encuentra, o si se produce un error. Si la entrada solicitada no se encontró, errno no se modificará. En caso de error, errno se establecerá para indicar el

error.

La aplicación no debe modificar la estructura a la que apunta el valor de retorno, ni ninguna de las áreas de almacenamiento a las que apuntan los punteros dentro de la estructura. El puntero devuelto, y los punteros dentro de la estructura, podrían quedar invalidados o la estructura o las áreas de almacenamiento podrían ser sobrescritas por una llamada posterior a getpwent(), getpwnam(), o getpwuid(). El puntero devuelto, y los punteros dentro de la estructura, también podrían quedar invalidados si el hilo que realiza la llamada es

terminado.

Si tiene éxito, la función getpwuid_r() devolverá cero; de lo contrario

, se devolverá un número de
error para indicar el error.

USO EN

APLICACIONES

Se pueden determinar tres nombres asociados con el proceso actual: getpwuid(geteuid()) devuelve el nombre asociado con el ID de usuario efectivo del proceso; getlogin() devuelve el nombre asociado con la actividad de inicio de sesión actual; y getpwuid(getuid()) devuelve el nombre asociado con el ID de usuario real del

proceso.

La función getpwuid_r() es segura en entornos con hilos y devuelve valores en un búfer proporcionado por el usuario en lugar de usar posiblemente un área de datos estática que puede ser sobrescrita en cada

llamada.

Las aplicaciones portables deben tener en cuenta que es habitual que una implementación devuelva -1 desde sysconf() indicando que no hay un máximo para _SC_GETPW_R_SIZE_MA
