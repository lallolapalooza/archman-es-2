DESCRIPCIÓ

N

getsockopt() y setsockopt() manipulan opciones para el socket referenciado por el descriptor de archivo sockfd. Las opciones pueden existir en múltiples niveles de protocolo; siempre están presentes en el nivel de socket más

alto.

Al manipular opciones de socket, se debe especificar el nivel en el que reside la opción y el nombre de la opción. Para manipular opciones en el nivel de la API de sockets, level se especifica como SOL_SOCKET. Para manipular opciones en cualquier otro nivel, se proporciona el número de protocolo del protocolo apropiado que controla la opción. Por ejemplo, para indicar que una opción debe ser interpretada por el protocolo TCP, level debe establecerse en el número de protocolo de TCP; ver getprotoen

t(3).

Los argumentos optval y optlen se utilizan para acceder a los valores de las opciones para setsockopt(). Para getsockopt() identifican un búfer en el que se deben devolver el valor de las opciones solicitadas. Para getsockopt(), optlen es un argumento de valor-resultado, que inicialmente contiene el tamaño del búfer apuntado por optval, y se modifica al regresar para indicar el tamaño real del valor devuelto. Si no se debe proporcionar ni devolver ningún valor de opción, optval puede ser

NULL.

Optname y las opciones especificadas se pasan sin interpretar al módulo de protocolo apropiado para su interpretación. El archivo de inclusión <sys/socket.h> contiene definiciones para las opciones de nivel de socket, descritas a continuación. Las opciones en otros niveles de protocolo varían en formato y nombre; consulte las entradas apropiadas en la sección 4 del

manual.

La mayoría de las opciones de nivel de socket utilizan un argumento int para optval. Para setsockopt(), el argumento debe ser distinto de cero para habilitar una opción booleana, o cero si la opción debe ser

deshabilitada.

Para una descripción de las opciones de socket disponibles, ver socket(7) y las páginas man

de los protocol
os apropiados.
