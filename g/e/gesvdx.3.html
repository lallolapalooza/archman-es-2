CGESVDX calcula la descomposición en valores singulares (SVD) para matrices GE

Propósito:

!>
!>  CGESVDX calcula la descomposición en valores singulares (SVD) de una matriz
!>  compleja M-por-N A, calculando opcionalmente los vectores singulares
!>  izquierdos y/o derechos. La SVD se escribe
!>
!>      A = U * SIGMA * transpuesta(V)
!>
!>  donde SIGMA es una matriz M-por-N que es cero excepto por sus
!>  min(m,n) elementos diagonales, U es una matriz unitaria M-por-M, y
!>  V es una matriz unitaria N-por-N. Los elementos diagonales de SIGMA
!>  son los valores singulares de A; son reales y no negativos, y
!>  se devuelven en orden descendente. Las primeras min(m,n) columnas de
!>  U y V son los vectores singulares izquierdos y derechos de A.
!>
!>  CGESVDX utiliza un problema de valores propios para obtener la SVD, lo que
!>  permite el cálculo de un subconjunto de valores singulares y
!>  vectores. Consulte SBDSVDX para más detalles.
!>
!>  Tenga en cuenta que la rutina devuelve V**T, no V.
!>

Parámetros

JOBU 
!>          JOBU es CHARACTER*1
!>          Especifica opciones para calcular toda o parte de la matriz U:
!>          = 'V':  se devuelven en el array U las primeras min(m,n) columnas de U (los vectores
!>                  singulares izquierdos) o según lo especificado por RANGE;
!>          = 'N':  no se calculan columnas de U (no se calculan vectores
!>                  singulares izquierdos).
!>

JOBVT

!>          JOBVT es CHARACTER*1
!>           Especifica opciones para calcular toda o parte de la matriz
!>           V**T:
!>           = 'V':  se devuelven en el array VT las primeras min(m,n) filas de V**T (los vectores
!>                   singulares derechos) o según lo especificado por RANGE;
!>           = 'N':  no se calculan filas de V**T (no se calculan vectores
!>                   singulares derechos).
!>

RANGE

!>          RANGE es CHARACTER*1
!>          = 'A': se encontrarán todos los valores singulares.
!>          = 'V': se encontrarán todos los valores singulares en el intervalo semiabierto (VL,VU]
!>          = 'I': se encontrarán los valores singulares desde el IL-ésimo hasta el IU-ésimo.
!>

M

!>          M es INTEGER
!>          El número de filas de la matriz de entrada A.  M >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz de entrada A.  N >= 0.
!>

A

!>          A es un array COMPLEX, dimensión (LDA,N)
!>          En la entrada, la matriz A de M-por-N.
!>          En la salida, el contenido de A se destruye.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,M).
!>

VL

!>          VL es REAL
!>          Si RANGE='V', el límite inferior del intervalo en el
!>          que se buscarán valores singulares. VU > VL.
!>          No se referencia si RANGE = 'A' o 'I'.
!>

VU

!>          VU es REAL
!>          Si RANGE='V', el límite superior del intervalo en el
!>          que se buscarán valores singulares. VU > VL.
!>          No se referencia si RANGE = 'A' o 'I'.
!>

IL

!>          IL es INTEGER
!>          Si RANGE='I', el índice del
!>          valor singular más pequeño que se devolverá.
!>          1 <= IL <= IU <= min(M,N), si min(M,N) > 0.
!>          No se referencia si RANGE = 'A' o 'V'.
!>

IU

!>          IU es INTEGER
!>          Si RANGE='I', el índice del
!>          valor singular más grande que se devolverá.
!>          1 <= IL <= IU <= min(M,N), si min(M,N) > 0.
!>          No se referencia si RANGE = 'A' o 'V'.
!>

NS

!>          NS es INTEGER
!>          El número total de valores singulares encontrados,
!>          0 <= NS <= min(M,N).
!>          Si RANGE = 'A', NS = min(M,N); si RANGE = 'I', NS = IU-IL+1.
!>

S

!>          S es un array REAL, dimensión (min(M,N))
!>          Los valores singulares de A, ordenados de modo que S(i) >= S(i+1).
!>

U

!>          U es un array COMPLEX, dimensión (LDU,UCOL)
!>          Si JOBU = 'V', U contiene las columnas de U (los vectores
!>          singulares izquierdos, almacenados por columnas) según lo especificado por RANGE; si
!>          JOBU = 'N', U no se referencia.
!>          Nota: El usuario debe asegurarse de que UCOL >= NS; si RANGE = 'V',
!>          el valor exacto de NS no se conoce de antemano y se debe usar una
!>          cota superior.
!>

LDU

!>          LDU es INTEGER
!>          La dimensión principal del array U.  LDU >= 1; si
!>          JOBU = 'V', LDU >= M.
!>

VT

!>          VT es un array COMPLEX, dimensión (LDVT,N)
!>          Si JOBVT = 'V', VT contiene las filas de V**T (los vectores
!>          singulares derechos, almacenados por filas) según lo especificado por RANGE; si JOBVT = 'N',
!>          VT no se referencia.
!>          Nota: El usuario debe asegurarse de que LDVT >= NS; si RANGE = 'V',
!>          el valor exacto de NS no se conoce de antemano y se debe usar una
!>          cota superior.
!>

LDVT

!>          LDVT es INTEGER
!>          La dimensión principal del array VT.  LDVT >= 1; si
!>          JOBVT = 'V', LDVT >= NS (ver arriba).
!>

WORK

!>          WORK es un array COMPLEX, dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK.
!>          LWORK >= MAX(1,MIN(M,N)*(MIN(M,N)+4)) para las rutas (ver
!>          comentarios dentro del código):
!>             - RUTA 1  (M mucho mayor que N)
!>             - RUTA 1t (N mucho mayor que M)
!>          LWORK >= MAX(1,MIN(M,N)*2+MAX(M,N)) para las otras rutas.
!>          Para un buen rendimiento, LWORK debería ser generalmente mayor.
!>
!>          Si LWORK = -1, se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo del array WORK, devuelve
!>          este valor como la primera entrada del array WORK, y XERBLA no emite
!>          ningún mensaje de error relacionado con LWORK.
!> >

RWORK


!>          RWORK es un array REAL, de dimensión (MAX(1,LRWORK))
!>          LRWORK >= MIN(M,N)*(MIN(M,N)*2+15*MIN(M,N)).
!> 


IWORK


!>          IWORK es un array INTEGER, de dimensión (12*MIN(M,N))
!>          Si INFO = 0, los primeros NS elementos de IWORK son cero. Si INFO > 0,
!>          entonces IWORK contiene los índices de los autovectores que fallaron
!>          en converger en SBDSVDX/SSTEVX.
!> 


INFO


!>     INFO es INTEGER
!>           = 0:  salida exitosa
!>           < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>           > 0:  si INFO = i, entonces i autovectores fallaron en converger
!>                 en SBDSVDX/SSTEVX.
!>                 si INFO = N*2 + 1, ocurrió un error interno en
!>                 SBDSVDX
!>

SGESVDX calcula la descomposición en valores singulares (SVD) para matrices GE

Propósito:

!




subroutine   sgesvdx (character jobu, character jobvt, character range, integer m, integer   n, real, dimension( lda, * ) a, integer lda, real vl, real vu, integer il,   integer iu, integer ns, real, dimension( * ) s, real, dimension( ldu, * ) u,   integer ldu, real, dimension( ldvt, * ) vt, integer ldvt, real, dimension( * )   work, integer lwork, integer, dimension( * ) iwork, integer info)


 SGESVDX computes the singular value decomposition (SVD) for GE
    matrices


Purpose:




!>
!>  SGESVDX computes the singular value decomposition (SVD) of a real
!>  M-by-N matrix A, optionally computing the left and/or right singular
!>  vectors. The SVD is written
!>
!>      A = U * SIGMA * transpose(V)
!>
!>  where SIGMA is an M-by-N matrix which is zero except for its
!>  min(m,n) diagonal elements, U is an M-by-M orthogonal matrix, and
!>  V is an N-by-N orthogonal matrix.  The diagonal elements of SIGMA
!>  are the singular values of A; they are real and non-negative, and
!>  are returned in descending order.  The first min(m,n) columns of
!>  U and V are the left and right singular vectors of A.
!>
!>  SGESVDX uses an eigenvalue problem for obtaining the SVD, which
!>  allows for the computation of a subset of singular values and
!>  vectors. See SBDSVDX for details.
!>
!>  Note that the routine returns V**T, not V.
!> 




Parameters


JOBU

!>          JOBU is CHARACTER*1
!>          Specifies options for computing all or part of the matrix U:
!>          = 'V':  the first min(m,n) columns of U (the left singular
!>                  vectors) or as specified by RANGE are returned in
!>                  the array U;
!>          = 'N':  no columns of U (no left singular vectors) are
!>                  computed.
!> 


JOBVT


!>          JOBVT is CHARACTER*1
!>           Specifies options for computing all or part of the matrix
!>           V**T:
!>           = 'V':  the first min(m,n) rows of V**T (the right singular
!>                   vectors) or as specified by RANGE are returned in
!>                   the array VT;
!>           = 'N':  no rows of V**T (no right singular vectors) are
!>                   computed.
!> 


RANGE


!>          RANGE is CHARACTER*1
!>          = 'A': all singular values will be found.
!>          = 'V': all singular values in the half-open interval (VL,VU]
!>                 will be found.
!>          = 'I': the IL-th through IU-th singular values will be found.
!> 


M


!>          M is INTEGER
!>          The number of rows of the input matrix A.  M >= 0.
!> 


N


!>          N is INTEGER
!>          The number of columns of the input matrix A.  N >= 0.
!> 


A


!>          A is REAL array, dimension (LDA,N)
!>          On entry, the M-by-N matrix A.
!>          On exit, the contents of A are destroyed.
!> 


LDA


!>          LDA is INTEGER
!>          The leading dimension of the array A.  LDA >= max(1,M).
!> 


VL


!>          VL is REAL
!>          If RANGE='V', the lower bound of the interval to
!>          be searched for singular values. VU > VL.
!>          Not referenced if RANGE = 'A' or 'I'.
!> 


VU


!>          VU is REAL
!>          If RANGE='V', the upper bound of the interval to
!>          be searched for singular values. VU > VL.
!>          Not referenced if RANGE = 'A' or 'I'.
!> 


IL


!>          IL is INTEGER
!>          If RANGE='I', the index of the
!>          smallest singular value to be returned.
!>          1 <= IL <= IU <= min(M,N), if min(M,N) > 0.
!>          Not referenced if RANGE = 'A' or 'V'.
!> 


IU


!>          IU is INTEGER
!>          If RANGE='I', the index of the
!>          largest singular value to be returned.
!>          1 <= IL <= IU <= min(M,N), if min(M,N) > 0.
!>          Not referenced if RANGE = 'A' or 'V'.
!> 


NS


!>          NS is INTEGER
!>          The total number of singular values found,
!>          0 <= NS <= min(M,N).
!>          If RANGE = 'A', NS = min(M,N); if RANGE = 'I', NS = IU-IL+1.
!> 


S


!>          S is REAL array, dimension (min(M,N))
!>          The singular values of A, sorted so that S(i) >= S(i+1).
!> 


U


!>          U is REAL array, dimension (LDU,UCOL)
!>          If JOBU = 'V', U contains columns of U (the left singular
!>          vectors, stored columnwise) as specified by RANGE; if
!>          JOBU = 'N', U is not referenced.
!>          Note: The user must ensure that UCOL >= NS; if RANGE = 'V',
!>          the exact value of NS is not known in advance and an upper
!>          bound must be used.
!> 


LDU


!>          LDU is INTEGER
!>          The leading dimension of the array U.  LDU >= 1; if
!>          JOBU = 'V', LDU >= M.
!> 


VT


!>          VT is REAL array, dimension (LDVT,N)
!>          If JOBVT = 'V', VT contains the rows of V**T (the right singular
!>          vectors, stored rowwise) as specified by RANGE; if JOBVT = 'N',
!>          VT is not referenced.
!>          Note: The user must ensure that LDVT >= NS; if RANGE = 'V',
!>          the exact value of NS is not known in advance and an upper
!!>          bound must be used.
!> 


LDVT


!>          LDVT is INTEGER
!>          The leading dimension of the array VT.  LDVT >= 1; if
!>          JOBVT = 'V', LDVT >= NS (see above).
!> 


WORK


!>          WORK is REAL array, dimension (MAX(1,LWORK))
!>          On exit, if INFO = 0, WORK(1) returns the optimal LWORK;
!> 


LWORK


!>          LWORK is INTEGER
!>          The dimension of the array WORK.
!>          LWORK >= MAX(1,MIN(M,N)*(MIN(M,N)+4)) for the paths (see
!>          comments inside the code):
!>             - PATH 1  (M much larger than N)
!>             - PATH 1t (N much larger than M)
!>          LWORK >= MAX(1,MIN(M,N)*2+MAX(M,N)) for the other paths.
!>          For good performance, LWORK should generally be larger.
!>
!>          If LWORK = -1, then a workspace query is assumed; the routine
!>          only calculates the optimal size of the WORK array, returns
!>          this value as the first entry of the WORK array, and no error
!>          message related to LWORK is issued by XERBLA.
!> 


IWORK

    matrices


Purpose:




!>
!>  ZGESVDX computes the singular value decomposition (SVD) of a complex
!>  M-by-N matrix A, optionally computing the left and/or right singular
!>  vectors. The SVD is written
!>
!>      A = U * SIGMA * transpose(V)
!>
!>  where SIGMA is an M-by-N matrix which is zero except for its
!>  min(m,n) diagonal elements, U is an M-by-M unitary matrix, and
!>  V is an N-by-N unitary matrix.  The diagonal elements of SIGMA
!>  are the singular values of A; they are real and non-negative, and
!>  are returned in descending order.  The first min(m,n) columns of
!>  U and V are the left and right singular vectors of A.
!>
!>  ZGESVDX uses an eigenvalue problem for obtaining the SVD, which
!>  allows for the computation of a subset of singular values and
!>  vectors. See DBDSVDX for details.
!>
!>  Note that the routine returns V**T, not V.
!>

!>          JOBU is CHARACTER*1
!>          Specifies options for computing all or part of the matrix U:

!>          = 'N':  no columns of U (no left singular vectors) are
!>                  computed.

Detailed Description


Esta rutina calcula un subconjunto de los valores singulares
    de una matriz general compleja A y, opcionalmente, los vectores singulares
    izquierdos (U) y/o derechos (V**T).


Los valores singulares se ordenan de mayor a menor.
