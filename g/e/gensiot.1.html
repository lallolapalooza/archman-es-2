NOMBRE

gensiotool - Herramienta para realizar conexiones gensio

SINOPSIS

gensiotool [opciones] io2

DESCRIPCIÓN

El programa gensiotool permite establecer conexiones utilizando gensios. Crea dos gensios llamados io1 e io2. Por defecto, io1 es la terminal local y io2 debe especificarse.

Por defecto, gensiotool crea dos gensios normales y establece conexiones a cada uno de ellos. Cualquier dato que llegue por un gensio se transmite por el otro.

Para obtener una descripción de cómo especificar un gensio, consulte la documentación de gensio.

OPCIONES

-i|--input io1
Por defecto, io1 es la terminal local ( /dev/tty ) para una tty stdin, o la entrada/salida estándar del programa para una stdin no tty. Esto permite especificar otro gensio como dispositivo al que enganchar io2.
-a|--accepter
Por defecto, io2 realiza una conexión saliente. Esto modifica io2 para que sea un aceptador de gensio y espere una conexión entrante. Una vez que llega la conexión, se cierra el aceptador y las operaciones continúan como normal.
--signature
Firma del servidor de serie reportada al extremo remoto. Si se especifica un aceptador (actualmente solo un servidor telnet RFC2217), se utiliza la firma dada en lugar de "gensiotool".
-d|--debug
Genera salida de depuración. Especificarlo más de una vez aumenta la salida.
-e|--escchar char
Especifica un carácter para usar como carácter de escape. Establecerlo a -1 deshabilita el carácter de escape. Puede ser un número decimal o hexadecimal, o ^x para establecer un carácter de control. Por defecto es ^\\ si io1 es el predeterminado y stdin es una tty, o deshabilitado de lo contrario. Consulte ESCAPES a continuación para obtener más detalles sobre el carácter de escape. Solo se maneja en io1.
-p|--printacc
Si se especifica -a, imprime todas las direcciones de aceptación elegidas por el programa.
-n|--extra-threads <n>
Genera <n> hilos adicionales para manejar las operaciones de gensio. Útil para escalabilidad con --server.
--server
Cuando ocurre una aceptación, no se deshabilita la aceptación, sino que se continúa aceptando conexiones y no se cerrará si todas las conexiones desaparecen. Si no se especifica, el aceptador se cerrará cuando llegue una conexión y terminará cuando esa conexión se cierre.
--version
Imprime el número de versión y sale.
-h|--help
Salida de ayuda

ESCAPES

Si se recibe el carácter de escape en io1, el carácter no se transfiere y el programa espera otro carácter. Si el otro carácter también es el carácter de escape, se envía un solo carácter de escape. Si el otro carácter no se reconoce como un escape válido, se ignora y no se transfiere. Las mayúsculas y minúsculas son equivalentes.

Los caracteres de escape son:

q
Salir del programa.
b
Enviar una interrupción a io2. Se ignora si io2 no admite interrupción.
d
Volcar datos seriales para io2. Se ignora si io2 no es un gensio serial.
s
Establecer la velocidad en baudios del puerto serie para io2. Se ignora si io2 no es un gensio serial. Después de esto, se debe escribir la velocidad del puerto serie, terminada por una nueva línea. Las velocidades no válidas se ignoran, usa escchar-d para saber si la configuraste correctamente.
n, o, e
Establecer la paridad en io2 a ninguna, impar o par. Se ignora si io2 no es un gensio serial.
5, 6, 7, 8
Establecer el tamaño de datos en io2 al número de bits. Se ignora si io2 no es un gensio serial.
1, 2
Establecer el número de bits de parada a 1 o 2 en io2. Se ignora si io2 no es un gensio serial.
x, r, f
Establece el control de flujo a xonxoff, rtscts o ninguno.
