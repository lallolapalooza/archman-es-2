Propósito:

!> valores propios, la forma de Schur T y, opcionalmente, la matriz de vectores

!> forma de Schur de modo que los valores propios seleccionados estén en la
!> parte superior izquierda. Las columnas principales de Z forman entonces una
!> base ortonormal para el subespacio invariante correspondiente a los valores
!> propios seleccionados.
!>
!> Una matriz compleja está en forma de Schur si es triangular superior.
!>

Parámetros

!>          JOBVS es CHARACTER*1
!>          = 'N': no se calculan los vectores de Schur;
!>          = 'V': se calculan los vectores de Schur.
!>

SORT

!>          SORT es CHARACTER*1

!>          diagonal de la forma de Schur.
!>          = 'N': no se ordenan los valores propios:
!>          = 'S': se ordenan los valores propios (véase SELECT).
!>

SELECT

!>          SELECT es una FUNCIÓN LÓGICA de un argumento COMPLEJO
!>          SELECT debe declararse EXTERNAL en la subrutina de llamada.
!>          Si SORT = 'S', SELECT se utiliza para seleccionar los valores
!>          propios que se ordenarán en la parte superior izquierda de la
!>          forma de Schur.
!>          Si SORT = 'N', no se hace referencia a SELECT.
!>          El valor propio W(j) se selecciona si SELECT(W(j)) es verdadero.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A. N >= 0.
!>

A

!>          A es un arreglo COMPLEJO, dimensión (LDA,N)
!>          En la entrada, la matriz A de N por N.
!>          En la salida, A ha sido sobrescrita por su forma de Schur T.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del arreglo A.  LDA >= max(1,N).
!>

SDIM

!>          SDIM es INTEGER
!>          Si SORT = 'N', SDIM = 0.
!>          Si SORT = 'S', SDIM = número de valores propios para los cuales
!>                         SELECT es verdadero.
!>

W

!>          W es un arreglo COMPLEJO, dimensión (N)
!>          W contiene los valores propios calculados, en el mismo orden en
!>          el que aparecen en la diagonal de la forma de Schur de salida T.
!>

VS

!>          VS es un arreglo COMPLEJO, dimensión (LDVS,N)
!>          Si JOBVS = 'V', VS contiene la matriz unitaria Z de vectores
!>          de Schur.
!>          Si JOBVS = 'N', no se hace referencia a VS.
!>

LDVS

!>          LDVS es INTEGER
!>          La dimensión principal del arreglo VS.  LDVS >= 1; si
!>          JOBVS = 'V', LDVS >= N.
!>

WORK

!>          WORK es un arreglo COMPLEJO, dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del arreglo WORK.  LWORK >= max(1,2*N).
!>          Para un buen rendimiento, LWORK debe ser generalmente mayor.
!>
!>          Si LWORK = -1, se asume una consulta de espacio de trabajo; la
!>          rutina solo calcula el tamaño óptimo del arreglo WORK, devuelve
!>          este valor como la primera entrada del arreglo WORK, y XERBLA no
!>          emite ningún mensaje de error relacionado con LWORK.
!>

RWORK

!>          RWORK es un arreglo REAL, dimensión (N)
!>

BWORK

!>          BWORK es un arreglo LÓGICO, dimensión (N)
!>          No se hace referencia si SORT = 'N'.
!>

INFO

!>          INFO es INTEGER
!>          = 0: salida exitosa
!>          < 0: si INFO = -i, el i-ésimo argumento tenía un valor ilegal.

!>                      valores propios principales en la forma de Schur ya no

Description

    
This subroutine computes the eigenvalues, the Schur form T, and, optionally, the matrix of Schur vectors Z for GE matrices.

    
The Schur factorization is given by A = Z*T*(Z**H).

    
It can also order the eigenvalues on the diagonal of the Schur form such that selected eigenvalues appear at the top left. The leading columns of Z then form an orthonormal basis for the invariant subspace corresponding to the selected eigenvalues.

    
A complex matrix is in Schur form if it is upper triangular.





    
Function Documentation

    

        
subroutine gees (character jobvs, character sort, external select, integer n, real, dimension( lda, * ) a, integer lda, integer sdim, real, dimension( * ) wr, real, dimension( * ) wi, real, dimension( ldvs, * ) vs, integer ldvs, real, dimension( * ) work, integer lwork, logical, dimension( * ) bwork, integer info)

        
 GEES computes the eigenvalues, the Schur form, and, optionally, the matrix of Schur vectors for GE matrices

        
Purpose:

        

            
!>
!> GEES computes for an N-by-N real nonsymmetric matrix A, the
!> eigenvalues, the Schur form T, and, optionally, the matrix of Schur
!> vectors Z.  This gives the Schur factorization A = Z*T*(Z**H).
!>
!> Optionally, it also orders the eigenvalues on the diagonal of the
!> Schur form so that selected eigenvalues are at the top left.
!> The leading columns of Z then form an orthonormal basis for the
!> invariant subspace corresponding to the selected eigenvalues.
!>
!> A real matrix is in Schur form if it is upper triangular.
!>
!> Note that the order of eigenvalues on the diagonal of T is arbitrary
!> for an unsorted Schur decomposition; in particular, it does not
!> necessarily follow the order of the imaginary parts for complex
!> conjugate pairs.
!> 

        

        
Parameters

        
JOBVS
            
!>          JOBVS is CHARACTER*1
!>          = 'N': Schur vectors are not computed;
!>          = 'V': Schur vectors are computed.
!> 

            
SORT

            
!>          SORT is CHARACTER*1
!>          Specifies whether or not to order the eigenvalues on the
!>          diagonal of the Schur form.
!>          = 'N': Eigenvalues are not ordered.
!>          = 'S': Eigenvalues are ordered (see SELECT).
!> 

            
SELECT

            
!>          SELECT is a LOGICAL FUNCTION of one REAL argument
!>          SELECT must be declared EXTERNAL in the calling subroutine.
!>          If SORT = 'S', SELECT is used to select eigenvalues to order
!>          to the top left of the Schur form.
!>          IF SORT = 'N', SELECT is not referenced.
!>          The eigenvalue WR(j) + i*WI(j) is selected if SELECT(WR(j)) is
!>          true.
!> 

            
N

            
!>          N is INTEGER
!>          The order of the matrix A. N >= 0.
!> 

            
A

            
!>          A is REAL array, dimension (LDA,N)
!>          On entry, the N-by-N matrix A.
!>          On exit, A has been overwritten by its Schur form T.
!> 

            
LDA

            
!>          LDA is INTEGER
!>          The leading dimension of the array A. LDA >= max(1,N).
!> 

            
SDIM

            
!>          SDIM is INTEGER
!>          If SORT = 'N', SDIM = 0.
!>          If SORT = 'S', SDIM = number of eigenvalues for which
!>                         SELECT is true.
!> 

            
WR

            
!>          WR is REAL array, dimension (N)
!>          WI is REAL array, dimension (N)
!>          On exit, the real and imaginary parts of the eigenvalues of A,
!>          respectively. The eigenvalues are not necessarily ordered.
!>          The imaginary part Wi(j) is zero for real eigenvalues.
!> 

            
VS

            
!>          VS is REAL array, dimension (LDVS,N)
!>          If JOBVS = 'V', VS contains the orthogonal matrix Z of Schur
!>          vectors.
!>          If JOBVS = 'N', VS is not referenced.
!> 

            
LDVS

            
!>          LDVS is INTEGER
!>          The leading dimension of the array VS. LDVS >= 1; if
!>          JOBVS = 'V', LDVS >= N.
!> 

            
WORK

            
!>          WORK is REAL array, dimension (MAX(1,LWORK))
!>          On exit, if INFO = 0, WORK(1) returns the optimal LWORK.
!> 

            
LWORK

            
!>          LWORK is INTEGER
!>          The dimension of the array WORK. LWORK >= max(1,2*N).
!>          For good performance, LWORK must generally be larger.
!>
!>          If LWORK = -1, then a workspace query is assumed; the routine
!>          only calculates the optimal size of the WORK array, returns
!>          this value as the first entry of the WORK array, and no error
!>          message related to LWORK is issued by XERBLA.
!> 

            
BWORK

            
!>          BWORK is LOGICAL array, dimension (N)
!>          Not referenced if SORT = 'N'.
!>

subroutine zgees (character jobvs, character sort, external select, integer n, complex*16, dimension( lda, * ) a, integer lda, integer sdim, complex*16, dimension( * ) w, complex*16, dimension( ldvs, * ) vs, integer ldvs, complex*16, dimension( * ) work, integer lwork, double precision, dimension( * ) rwork, logical, dimension( * ) bwork, integer info)

        
 ZGEES computes the eigenvalues, the Schur form, and, optionally, the matrix of Schur vectors for GE matrices

        
Purpose:

        

            
!>
!> ZGEES computes for an N-by-N complex nonsymmetric matrix A, the
!> eigenvalues, the Schur form T, and, optionally, the matrix of Schur
!> vectors Z.  This gives the Schur factorization A = Z*T*(Z**H).
!>
!> Optionally, it also orders the eigenvalues on the diagonal of the
!> Schur form so that selected eigenvalues are at the top left.
!> The leading columns of Z then form an orthonormal basis for the
!> invariant subspace corresponding to the selected eigenvalues.
!>
!> A complex matrix is in Schur form if it is upper triangular.
!> 

        

        
Parameters

        
JOBVS
            
!>          JOBVS is CHARACTER*1
!>          = 'N': Schur vectors are not computed;
!>          = 'V': Schur vectors are computed.
!>

!>          SORT is CHARACTER*1
!>          Specifies whether or not to order the eigenvalues on the
!>          diagonal of the Schur form.
!>          = 'N': Eigenvalues are not ordered:
!>          = 'S': Eigenvalues are ordered (see SELECT).
!>

!>          SELECT is a LOGICAL FUNCTION of one COMPLEX*16 argument
!>          SELECT must be declared EXTERNAL in the calling subroutine.
