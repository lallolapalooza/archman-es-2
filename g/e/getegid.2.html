getgid(2) Manual de Llamadas al Sistema getgid(2)

NOMBRE

getgid, getegid - obtener identidad de grupo

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <unistd.h>
gid_t getgid(void);
gid_t getegid(void);

DESCRIPCIÓN

getgid() devuelve el ID de grupo real del proceso que llama.

getegid() devuelve el ID de grupo efectivo del proceso que llama.

ERRORES

Estas funciones siempre tienen éxito y nunca modifican errno.

VERSIÓNES

En Alpha, en lugar de un par de llamadas al sistema getgid() y getegid(), se proporciona una única llamada al sistema getxgid(), que devuelve un par de GIDs reales y efectivos. Las funciones de envoltura getgid() y getegid() de glibc manejan esto de forma transparente. Consulte syscall(2) para obtener detalles sobre el mapeo de registros.

ESTANDARES

POSIX.1-2024.

HISTORIA

POSIX.1-2001, 4.3BSD.

Las llamadas al sistema originales de Linux getgid() y getegid() solo admitían IDs de grupo de 16 bits. Posteriormente, Linux 2.4 agregó getgid32() y getegid32(), que admitían IDs de 32 bits. Las funciones de envoltura getgid() y getegid() de glibc manejan las variaciones entre las versiones del kernel de forma transparente.

VER TAMBIÉN

getresgid(2), setgid(2), setregid(2), credentials(7)
