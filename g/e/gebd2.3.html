CGEBD2 reduce una matriz general a forma bidiagonal usando un algoritmo sin

bloqueos.

Propósito

: 
!>
!> CGEBD2 reduce una matriz general compleja m por n A a la forma bidiagonal
!> real superior o inferior B mediante una transformación unitaria: Q**H * A * P = B.
!>
!> Si m >= n, B es bidiagonal superior; si m < n, B es bidiagonal inferior.
!
>

Parámetro

s
M 
!>          M es INTEGER
!>          El número de filas en la matriz A.  M >= 0.
!
>

N 
!>          N es INTEGER
!>          El número de columnas en la matriz A.  N >= 0.
!
>

A 
!>          A es un arreglo COMPLEX, dimensión (LDA,N)
!>          En la entrada, la matriz general m por n a reducir.
!>          En la salida,
!>          si m >= n, la diagonal y la primera superdiagonal son
!>            sobrescritas con la matriz bidiagonal superior B; los
!>            elementos por debajo de la diagonal, con el arreglo TAUQ, representan
!>            la matriz unitaria Q como un producto de reflectores
!>            elementales, y los elementos por encima de la primera superdiagonal,
!>            con el arreglo TAUP, representan la matriz unitaria P como
!>            un producto de reflectores elementales;
!>          si m < n, la diagonal y la primera subdiagonal son
!>            sobrescritas con la matriz bidiagonal inferior B; los
!>            elementos por debajo de la primera subdiagonal, con el arreglo TAUQ,
!>            representan la matriz unitaria Q como un producto de
!>            reflectores elementales, y los elementos por encima de la diagonal,
!>            con el arreglo TAUP, representan la matriz unitaria P como
!>            un producto de reflectores elementales.
!>          Ver Detalles Adicionales.
!
>

LD

A 
!>          LDA es INTEGER
!>          La dimensión principal del arreglo A.  LDA >= max(1,M).
!
>

D 
!>          D es un arreglo REAL, dimensión (min(M,N))
!>          Los elementos diagonales de la matriz bidiagonal B:
!>          D(i) = A(i,i).
!
>

E 
!>          E es un arreglo REAL, dimensión (min(M,N)-1)
!>          Los elementos fuera de la diagonal de la matriz bidiagonal B:
!>          si m >= n, E(i) = A(i,i+1) para i = 1,2,...,n-1;
!>          si m < n, E(i) = A(i+1,i) para i = 1,2,...,m-1.
!
>

TAU

Q 
!>          TAUQ es un arreglo COMPLEX, dimensión (min(M,N))
!>          Los factores escalares de los reflectores elementales que
!>          representan la matriz unitaria Q. Ver Detalles Adicionales.
!
>

TAU

P 
!>          TAUP es un arreglo COMPLEX, dimensión (min(M,N))
!>          Los factores escalares de los reflectores elementales que
!>          representan la matriz unitaria P. Ver Detalles Adicionales.

>

WOR

K

Adicionales: 
!>
!>  Las matrices Q y P se representan como productos de reflectores
!>  elementales:
!>
!>  Si m >= n,
!>
!>     Q = H(1) H(2) . . . H(n)  y  P = G(1) G(2) . . . G(n-1)
!>
!>  Cada H(i) y G(i) tiene la forma:
!>
!>     H(i) = I - tauq * v * v**H  y G(i) = I - taup * u * u**H
!>
!>  donde tauq y taup son escalares complejos, y v y u son vectores
!>  complejos; v(1:i-1) = 0, v(i) = 1, y v(i+1:m) se almacena en la salida en
!>  A(i+1:m,i); u(1:i) = 0, u(i+1) = 1, y u(i+2:n) se almacena en la salida en
!>  A(i,i+2:n); tauq se almacena en TAUQ(i) y taup en TAUP(i).
!>
!>  Si m < n,
!>
!>     Q = H(1) H(2) . . . H(m-1)  y  P = G(1) G(2) . . . G(m)
!>
!>  Cada H(i) y G(i) tiene la forma:
!>
!>     H(i) = I - tauq * v * v**H  y G(i) = I - taup * u * u**H
!>
!>  donde tauq y taup son escalares complejos, v y u son vectores complejos;
!>  v(1:i) = 0, v(i+1) = 1, y v(i+2:m) se almacena en la salida en A(i+2:m,i);
!>  u(1:i-1) = 0, u(i) = 1, y u(i+1:n) se almacena en la salida en A(i,i+1:n);
!>  tauq se almacena en TAUQ(i) y taup en TAUP(i).
!>
!>  El contenido de A en la salida se ilustra con los siguientes ejemplos:
!>
!>  m = 6 y n = 5 (m > n):          m = 5 y n = 6 (m < n):
!>
!>    (  d   e   u1  u1  u1 )           (  d   u1  u1  u1  u1  u1 )
!>    (  v1  d   e   u2  u2 )           (  e   d   u2  u2  u2  u2 )
!>    (  v1  v2  d   e   u3 )           (  v1  e   d   u3  u3  u3 )
!>    (  v1  v2  v3  d   e  )           (  v1  v2  e   d   u4  u4 )
!>    (  v1  v2  v3  v4  d  )           (  v1  v2  v3  e   d   u5 )
!>    (  v1  v2  v3  v4  v5 )
!>
!>  donde d y e denotan elementos diagonales y fuera de la diagonal de B, vi
!>  denota un elemento del vector que define H(i), y ui un elemento de
!>  el vector que define G(i).
!
>

dgebd2 reduce a general matrix to bidiagonal form using an unblocked algorithm.


Purpose:




!> SGEBD2 reduce a real general M by N matrix A to upper or lower
!> bidiagonal form B by an orthogonal transformation: Q' * A * P = B.
!>
!> If m >= n, B is upper bidiagonal; if m < n, B is lower bidiagonal.
!>





Parameters


M

!>          M is INTEGER
!>          The number of rows in the matrix A. M >= 0.
!> 


N


!>          N is INTEGER
!>          The number of columns in the matrix A. N >= 0.
!> 


A


!>          A is DOUBLE PRECISION array, dimension (LDA,N)
!>          On entry, the M by N general matrix to be reduced.
!>          On exit,
!>          if m >= n, the diagonal and the first superdiagonal are
!>            overwritten with the upper bidiagonal matrix B; the
!>            elements below the diagonal, with the array TAUQ, represent
!>            the orthogonal matrix Q as a product of elementary
!>            reflectors, and the elements above the first superdiagonal,
!>            with the array TAUP, represent the orthogonal matrix P as
!>            a product of elementary reflectors;
!>          if m < n, the diagonal and the first subdiagonal are
!>            overwritten with the lower bidiagonal matrix B; the
!>            elements below the first subdiagonal, with the array TAUQ,
!>            represent the orthogonal matrix Q as a product of
!>            elementary reflectors, and the elements above the diagonal,
!>            with the array TAUP, represent the orthogonal matrix P as
!>            a product of elementary reflectors.
!>          See Further Details.
!> 


LDA


!>          LDA is INTEGER
!>          The leading dimension of the array A. LDA >= max(1,M).
!> 


D


!>          D is DOUBLE PRECISION array, dimension (min(M,N))
!>          The diagonal elements of the bidiagonal matrix B:
!>          D(i) = A(i,i).
!> 


E


!>          E is DOUBLE PRECISION array, dimension (min(M,N)-1)
!>          The off-diagonal elements of the bidiagonal matrix B:
!>          if m >= n, E(i) = A(i,i+1) for i = 1,2,...,n-1;
!>          if m < n, E(i) = A(i+1,i) for i = 1,2,...,m-1.
!> 


TAUQ


!>          TAUQ is DOUBLE PRECISION array, dimension (min(M,N))
!>          The scalar factors of the elementary reflectors which
!>          represent the orthogonal matrix Q. See Further Details.
!> 


TAUP


!>          TAUP is DOUBLE PRECISION array, dimension (min(M,N))
!>          The scalar factors of the elementary reflectors which
!>          represent the orthogonal matrix P. See Further Details.
!> 


WORK


!>          WORK is DOUBLE PRECISION array, dimension (max(M,N))
!> 


INFO


!>          INFO is INTEGER
!>          = 0: successful exit.
!>          < 0: if INFO = -i, the i-th argument had an illegal value.
!>
