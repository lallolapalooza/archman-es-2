getrpcent_r(3) Manual de funciones de biblioteca getrpcent_r(3)

NOMBRE

getrpcent_r, getrpcbyname_r, getrpcbynumber_r - obtener entrada RPC (reentrante)

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <netdb.h>
int getrpcent_r(size_t size;
                struct rpcent *result_buf, char buf[size],
                size_t size, struct rpcent **result);
int getrpcbyname_r(size_t size;
                const char *name,
                struct rpcent *result_buf, char buf[size],
                size_t size, struct rpcent **result);
int getrpcbynumber_r(size_t size;
                int number,
                struct rpcent *result_buf, char buf[size],
                size_t size, struct rpcent **result);
Requisitos de macro de prueba de características para glibc (consulte feature_test_macros(7)):

getrpcent_r(), getrpcbyname_r(), getrpcbynumber_r():

    Desde glibc 2.19:
        _DEFAULT_SOURCE
    glibc 2.19 y anteriores:
        _BSD_SOURCE || _SVID_SOURCE

DESCRIPCIÓN

Las funciones getrpcent_r(), getrpcbyname_r() y getrpcbynumber_r() son los equivalentes reentrantes de, respectivamente, getrpcent(3), getrpcbyname(3) y getrpcbynumber(3). Difieren en la forma en que se devuelve la estructura rpcent y en la firma de llamada de la función y el valor de retorno. Esta página del manual describe solo las diferencias con las funciones no reentrantes.

En lugar de devolver un puntero a una estructura rpcent asignada estáticamente como resultado de la función, estas funciones copian la estructura en la ubicación apuntada por result_buf.

El array buf se utiliza para almacenar los campos de cadena apuntados por la estructura rpcent devuelta. (Las funciones no reentrantes asignan estas cadenas en almacenamiento estático). El tamaño de este array se especifica en size. Si buf es demasiado pequeño, la llamada falla con el error ERANGE, y el llamante debe intentarlo de nuevo con un buffer más grande. (Un buffer de 1024 bytes debería ser suficiente para la mayoría de las aplicaciones).

Si la llamada a la función obtiene con éxito un registro RPC, entonces *result se establece apuntando a result_buf; de lo contrario, *result se establece a NULL.

VALOR DE RETORNO

En caso de éxito, estas funciones devuelven 0. En caso de error, devuelven uno de los números de error positivos enumerados en ERRORES.

En caso de error, registro no encontrado (getrpcbyname_r(), getrpcbynumber_r()), o fin de entrada (getrpcent_r()), *result se establece a NULL.

ERRORES

ENOENT
(getrpcent_r()) No hay más registros en la base de datos.
ERANGE
buf es demasiado pequeño. Inténtelo de nuevo con un buffer más grande (y size aumentado).
