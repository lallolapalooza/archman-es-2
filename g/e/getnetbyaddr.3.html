getnetent(3) Manual de funciones de biblioteca getnetent(3)

NOMBRE

getnetent, getnetbyname, getnetbyaddr, setnetent, endnetent - obtener entrada de red

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <netdb.h>
struct netent *getnetent(void);
struct netent *getnetbyname(const char *name);
struct netent *getnetbyaddr(uint32_t net, int type);
void setnetent(int stayopen);
void endnetent(void);

DESCRIPCIÓN

La función getnetent() lee la siguiente entrada de la base de datos de redes y devuelve una estructura netent que contiene los campos desglosados de la entrada. Se abre una conexión a la base de datos si es necesario.

La función getnetbyname() devuelve una estructura netent para la entrada de la base de datos que coincide con el nombre name de la red.

La función getnetbyaddr() devuelve una estructura netent para la entrada de la base de datos que coincide con el número de red net del tipo type. El argumento net debe estar en orden de bytes del host.

La función setnetent() abre una conexión a la base de datos y establece la siguiente entrada en la primera entrada. Si stayopen no es cero, la conexión a la base de datos no se cerrará entre llamadas a una de las funciones getnet*().

La función endnetent() cierra la conexión a la base de datos.

La estructura netent se define en <netdb.h> de la siguiente manera:


struct netent {
    char      *n_name;     /* nombre oficial de la red */
    char     **n_aliases;  /* lista de alias */
    int        n_addrtype; /* tipo de dirección de red */
    uint32_t   n_net;      /* número de red */
}

Los miembros de la estructura netent son:

n_name
El nombre oficial de la red.
n_aliases
Una lista terminada en NULL de nombres alternativos para la red.
n_addrtype
El tipo del número de red; siempre AF_INET.
n_net
El número de red en orden de bytes del host.

VALOR DE RETORNO

Las funciones getnetent(), getnetbyname() y getnetbyaddr() devuelven un puntero a una estructura netent estáticamente asignada, o un puntero nulo si ocurre un error o se llega al final del archivo.

ARCHIVOS

/etc/networks
archivo de la base de datos de redes

ATRIBUTOS

Para obtener una explicación de los términos utilizados en esta sección, consulte attributes(7).

Interfaz Atributo Valor
getnetent () Seguridad de hilos MT-Unsafe race:netent race:netentbuf env locale
getnetbyname () Seguridad de hilos MT-Unsafe race:netbyname env locale
getnetbyaddr () Seguridad de hilos MT-Unsafe race:netbyaddr locale
setnetent (), endnetent () Seguridad de hilos MT-Unsafe race:netent env locale

En la tabla anterior, netent en race:netent indica que si alguna de las funciones setnetent(), getnetent() o endnetent() se utiliza en paralelo en diferentes hilos de un programa, podrían ocurrir carreras de datos.

ESTÁNDARES

POSIX.1-2008.

HISTORIA

POSIX.1-2001, 4.3BSD.

Antes de glibc 2.2, el argumento net de getnetbyaddr() era de tipo long.
