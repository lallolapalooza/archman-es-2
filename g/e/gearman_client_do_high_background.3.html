DESCRIPCIÓN

gearman_client_do_background() ejecuta una única solicitud al servidor gearmand y devuelve el estado a través de gearman_return_t.

gearman_client_add_task_high_background() y gearman_client_add_task_low_background() son idénticas a gearman_client_do_background(), solo que establecen gearman_priority_t en alta o baja.

Si job_handle no es NULL, se poblará con el nombre del job_handle para la tarea creada. El job handle debe tener el tamaño de GEARMAN_JOB_HANDLE_SIZE. Por favor, consulte gearman_job_handle_t para más información.

#include <stdlib.h>
#include <stdio.h>
#include <libgearman-1.0/gearman.h>
int main(void)
{
  gearman_client_st *client= gearman_client_create(NULL);
  gearman_return_t ret= gearman_client_add_server(client, "localhost", 0);
  if (gearman_failed(ret))
  {
    return EXIT_FAILURE;
  }
  gearman_job_handle_t job_handle;
  gearman_return_t rc= gearman_client_do_background(client,
                                                    "reverse_function",
                                                    "unique_value",
                                                    "my string to reverse", strlen("my string to reverse"),
                                                    job_handle);
  if (gearman_success(rc))
  {
    // Usar el valor
    printf("%s\n", job_handle);
  }
  gearman_client_free(client);
  return 0;
}
