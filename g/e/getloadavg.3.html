getloadavg(3) Manual de funciones de biblioteca getloadavg(3)

NOMBRE

getloadavg - obtener promedios de carga del sistema

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINÓPSIS

#include <stdlib.h>
int getloadavg(double loadavg[], int n);
Requisitos de Feature Test Macro para glibc (ver feature_test_macros(7)):

getloadavg():

    Desde glibc 2.19:
        _DEFAULT_SOURCE
    En glibc hasta e incluyendo 2.19:
        _BSD_SOURCE

DESCRIPCIÓN

La función getloadavg() devuelve el número de procesos en la cola de ejecución del sistema promediado durante varios períodos de tiempo. Se recuperan hasta n muestras y se asignan a elementos sucesivos de loadavg[]. El sistema impone un máximo de 3 muestras, que representan los promedios de los últimos 1, 5 y 15 minutos, respectivamente.

VALOR DE RETORNO

Si el promedio de carga no se pudo obtener, se devuelve -1; de lo contrario, se devuelve el número de muestras realmente recuperadas.

ATRIBUTOS

Para una explicación de los términos utilizados en esta sección, ver attributes(7).

Interfaz Atributo Valor
getloadavg () Seguridad de hilos MT-Safe

ESTÁNDARES

BSD.

HISTORIA

4.3BSD-Reno, Solaris. glibc 2.2.

VER TAMBIÉN

uptime(1), proc(5)
