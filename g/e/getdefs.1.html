NOMBRE

getdefs - Herramienta de extracción de definiciones de AutoGen

SINOPSIS

getdefs [nombre-opcion valor]

Todos los argumentos son opciones con nombre.

Si no se proporciona ningún argumento de entrada o se establece simplemente en "-", y si stdin no es una tty, entonces la lista de archivos de entrada se leerá desde stdin.

DESCRIPCIÓN

Este programa extrae definiciones de AutoGen de una lista de archivos fuente. Las definiciones están delimitadas por /*=<tipo-entrada> <nombre-entrada>0fP y =*/0fP.

OPCIONES

Especificar qué definiciones son de interés y qué decir sobre ellas

defs-to-get=reg-ex

Expresión regular para buscar después de "/*=".

Si solo desea definiciones de una categoría particular, o incluso con nombres que coincidan con patrones particulares, especifique esta expresión regular para el texto que debe seguir a /*=.

subblock=sub-def

Nombres de subdefinición. Esta opción puede aparecer un número ilimitado de veces.

Esta opción se utiliza para crear entradas abreviadas para definiciones anidadas. Por ejemplo, con:

usando subblock así --subblock=arg=argname,type,null

y definiendo un arg así arg: this, char *

luego se expandirá a: arg = { argname = this; type = "char *"; @;}
La cadena "this, char *" se separa en las comas, eliminando el espacio en blanco. Puede usar caracteres distintos de las comas comenzando la cadena de valor con un carácter de puntuación distinto de una comilla simple o doble. También puede omitir valores intermedios colocando las comas una al lado de la otra sin espacio en blanco intermedio. Por ejemplo, "+mumble++yes+" se expandirá a:
arg = { argname = mumble; null = "yes"; @;}.

listattr=def

atributo con lista de valores. Esta opción puede aparecer un número ilimitado de veces.

Esta opción se utiliza para crear entradas abreviadas para definiciones que generalmente aparecen varias veces. Es decir, tienden a ser una lista de valores. Por ejemplo, con:
listattr=foo definido, el texto:
foo: this, is, a, multi-list luego se expandirá a:
foo = 'this', 'is', 'a', 'multi-list';
Los textos se separan por las comas, eliminando el espacio en blanco. Puede usar caracteres distintos de las comas comenzando la cadena de valor con un carácter de puntuación distinto de una comilla simple o doble.

especificar cómo numerar las definiciones

ordering [=nombre-archivo], --no-ordering

Alphabetizar o usar archivo con nombre. La forma no-ordering desactivará la opción. Esta opción está habilitada por defecto.

Por defecto, el orden es alfabético por el nombre de la entrada. Use no-ordering si el orden no es importante. Use ordering sin argumento para ordenar sin distinción de mayúsculas y minúsculas. Use ordering=<nombre-archivo> si el orden cronológico es importante. getdefs mantendrá el contenido de texto de nombre-archivo. nombre-archivo no necesita existir.

first-index=first-index

El primer índice que se aplicará a los grupos. Esta opción toma un número entero como argumento. El first-index predeterminado para esta opción es:
0

Por defecto, la primera aparición de una definición con nombre tendrá un índice de cero. A veces, ese necesita ser un valor reservado. Proporcione esta opción para especificar un punto de partida diferente.

Opciones de inserción de definiciones

filelist [=archivo]

Insertar nombres de archivos fuente en defs.

Inserta el nombre de cada archivo de entrada en las definiciones de salida. Si no se proporciona ningún argumento, el formato será:

    infile = '%s';
Si se proporciona un argumento, esa cadena se usará para el nombre de la entrada en lugar de infile.
assign=ag-def

Asignaciones globales. Esta opción puede aparecer un número ilimitado de veces.

El argumento de cada copia de esta opción se insertará en las definiciones de salida, con solo un punto y coma adjunto.

common-assign=ag-def

Asignaciones comunes a todos los bloques. Esta opción puede aparecer un número ilimitado de veces.

El argumento de cada copia de esta opción se insertará en cada definición de salida, con solo un punto y coma adjunto.

copy=archivo

Archivos a copiar en definiciones. Esta opción puede aparecer un número ilimitado de veces.

El contenido de cada archivo nombrado por estas opciones se insertará en las definiciones de salida.

srcfile [=archivo]

Insertar nombre de archivo fuente en cada def.

Inserta el nombre del archivo de entrada donde se encontró una definición en la definición de salida. Si no se proporciona ningún argumento, el formato será:

    srcfile = '%s';
Si se proporciona un argumento, esa cadena se usará para el nombre de la entrada en lugar de srcfile.
linenum [=nombre-def]

Insertar número de línea fuente en cada def.

Inserta el número de línea en el archivo de entrada donde se encontró una definición en la definición de salida. Si no se proporciona ningún argumento, el formato será:

    linenum = '%s';
Si se proporciona un argumento, esa cadena se usará para el nombre de la entrada en lugar de linenum.

especificar qué archivos buscar marcadores

input=archivo-fuente

Archivo de entrada para buscar defs. Esta opción puede aparecer un número ilimitado de veces. Esta opción es la opción predeterminada.

Todos los archivos que se van a buscar para definiciones deben nombrarse en la línea de comandos o leerse desde stdin. Si solo hay una opción input y es la cadena "-", entonces la lista de archivos de entrada se lee desde stdin. Si un argumento de línea de comandos no es un nombre de opción y no contiene un operador de asignación (=), entonces se considera de forma predeterminada como un nombre de archivo de entrada. Se debe especificar al menos un archivo de entrada.

Opciones de disposición de salida de definición:

output=archivo

Archivo de salida para abrir. Esta opción es un miembro de la clase de opciones de autogen.

Si no está enviando la salida a un proceso de AutoGen, puede nombrar un archivo de salida en su lugar.

autogen [=ag-cmd], --no-autogen

Invocar AutoGen con defs. La forma no-autogen desactivará la opción. Esta opción está habilitada por defecto. Esta opción es un miembro de la clase de opciones de autogen.

Este es el modo de salida predeterminado. Especificar no-autogen es equivalente a output=-. Si proporciona un argumento a esta opción

getdefs(1) - Arch manual pages

NAME

getdefs

extract definitions from AutoGen input files

SYNOPSIS

getdefs [OPTIONS] [FILE…]

DESCRIPTION

The getdefs program will process any input FILEs specified and extract definitions from them. The definitions will be written to standard output, unless the --output option is used.

The purpose of getdefs is to extract the definitions from AutoGen templates so that they might be processed by another program. For example, it might be used to produce C header files from AutoGen definitions.

The definitions are formatted in the standard AutoGen style, which is a set of name/value pairs. When input is specified as stdin, the output is sent to stdout. Otherwise, the output is sent to a file named name.def, where name is the base name of the input file.

OPTIONS

--arg=arg

Extra argument. This option may appear an unlimited number of times.

This is a pass-through argument. It allows you to specify any arbitrary argument to be passed to AutoGen.

--help

Display usage information and exit.
--more-help

Pass the extended usage information through a pager.
--output=file

Output file. This option must not appear in combination with any of the following options: agarg, base-name, output.

This option specifies that the definitions should be written to the named file instead of standard output. If the file exists, it will be overwritten.

--template=file

Template Name.

Specifies the template name to be used for generating the final output.

--agarg=ag-opt

AutoGen Argument. This option may appear an unlimited number of times. This option must not appear in combination with any of the following options: output.

This is a pass-through argument. It allows you to specify any arbitrary argument to be passed to AutoGen.

--base-name=name

Base name for output file(s). This option must not appear in combination with any of the following options: output.

When output is going to AutoGen, a base name must either be supplied or derived. If this option is not supplied, then it is taken from the template option. If that is not provided either, then it is set to the base name of the current directory.

--help

Display usage information and exit.
--more-help

Pass the extended usage information through a pager.
--save-opts=[cfgfile]

Save the option state to cfgfile. The default is the last configuration file listed in the OPTION PRESETS section, below. The command will exit after updating the config file.
--load-opts=cfgfile, no-load-opts

Load options from cfgfile. The no-load-opts form will disable the loading of earlier config/rc/ini files. --no-load-opts is handled early, out of order.
--version [{v|c|n}]

Output version of program and exit. The default mode is `v', a simple version. The `c' mode will print copyright information and `n' will print the full copyright notice.

OPTION PRESETS

Any option that is not marked as not presettable may be preset by loading values from configuration ("RC" or ".INI") file(s). The homerc file is "/dev/null", unless that is a directory. In that case, the file ".getdefsrc" is searched for within that directory.

FILES

See OPTION PRESETS for configuration files.

EXIT STATUS

One of the following exit values will be returned:

0 (EXIT_SUCCESS)

Successful program execution.
1 (EXIT_FAILURE)

The operation failed or the command syntax was not valid.
2 (EXIT_INVALID_INPUT)

An input file was specified that is not a file
3 (EXIT_NO_MEM)

Insufficient memory for operation
66 (EX_NOINPUT)

A specified configuration file could not be loaded.
70 (EX_SOFTWARE)

libopts had an internal operational error. Please report it to autogen-users@lists.sourceforge.net. Thank you.
