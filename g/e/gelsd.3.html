CGELSD calcula la solución de norma mínima para un problema de mínimos cuadrados lineal para matrices

GE

Propósito

: 
!>
!> CGELSD calcula la solución de norma mínima para un problema real de mínimos
!> cuadrados lineales:
!>     minimizar 2-norma(| b - A*x |)
!> usando la descomposición en valores singulares (SVD) de A. A es una matriz
!> M por N que puede ser deficiente en rango.
!>
!> Varios vectores de segundo miembro b y vectores de solución x pueden ser
!> manejados en una sola llamada; se almacenan como las columnas de la
!> matriz de segundo miembro B de M por NRHS y la matriz de solución
!> X de N por NRHS.
!>
!> El problema se resuelve en tres pasos:
!> (1) Reducir la matriz de coeficientes A a forma bidiagonal con
!>     transformaciones de Householder, reduciendo el problema original
!>     a un (BLS)
!> (2) Resolver el BLS usando un enfoque de divide y vencerás.
!> (3) Aplicar de vuelta todas las transformaciones de Householder para resolver
!>     el problema original de mínimos cuadrados.
!>
!> El rango efectivo de A se determina tratando como cero aquellos
!> valores singulares que son menores que RCOND veces el mayor valor
!> singular.
!>
!
>

Parámetro

s
M 
!>          M es INTEGER
!>          El número de filas de la matriz A. M >= 0.
!
>

N 
!>          N es INTEGER
!>          El número de columnas de la matriz A. N >= 0.
!
>

NRH

S 
!>          NRHS es INTEGER
!>          El número de segundos miembros, es decir, el número de columnas
!>          de las matrices B y X. NRHS >= 0.
!
>

A 
!>          A es un arreglo COMPLEX, dimensión (LDA,N)
!>          En la entrada, la matriz A de M por N.
!>          En la salida, A ha sido destruida.
!
>

LD

A 
!>          LDA es INTEGER
!>          La dimensión principal del arreglo A. LDA >= max(1,M).
!
>

B 
!>          B es un arreglo COMPLEX, dimensión (LDB,NRHS)
!>          En la entrada, la matriz de segundo miembro B de M por NRHS.
!>          En la salida, B es sobrescrita por la matriz de solución X de N por NRHS.
!>          Si m >= n y RANK = n, la suma de cuadrados del residuo para
!>          la solución en la i-ésima columna está dada por la suma de
!>          cuadrados del módulo de los elementos n+1:m en esa columna.
!
>

LD

B 
!>          LDB es INTEGER
!>          La dimensión principal del arreglo B.  LDB >= max(1,M,N).
!
>

S 
!>          S es un arreglo REAL, dimensión (min(M,N))
!>          Los valores singulares de A en orden decreciente.
!>          El número de condición de A en la 2-norma = S(1)/S(min(m,n)).
!
>

RCON

D 
!>          RCOND es REAL
!>          RCOND se usa para determinar el rango efectivo de A.
!>          Los valores singulares S(i) <= RCOND*S(1) se tratan como cero.
!>          Si RCOND < 0, se usa la precisión de la máquina en su lugar.
!
>

RAN

K 
!>          RANK es INTEGER
!>          El rango efectivo de A, es decir, el número de valores singulares
!>          que son mayores que RCOND*S(1).
!
>

WOR

K 
!>          WORK es un arreglo COMPLEX, dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!
>

LWOR

K 
!>          LWORK es INTEGER
!>          La dimensión del arreglo WORK. LWORK debe ser al menos 1.
!>          La cantidad exacta mínima de espacio de trabajo necesaria depende de M,
!>          N y NRHS. Siempre que LWORK sea al menos
!>              2 * N + N * NRHS
!>          si M es mayor o igual que N o
!>              2 * M + M * NRHS
!>          si M es menor que N, el código se ejecutará correctamente.
!>          Para un buen rendimiento, LWORK debería ser generalmente mayor.
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo del arreglo WORK y los
!>          tamaños mínimos de los arreglos RWORK e IWORK, y devuelve
!>          estos valores como las primeras entradas de los arreglos WORK, RWORK e
!>          IWORK, y XERBLA no emite ningún mensaje de error relacionado con LWORK.
!
>

RWOR

K 
!>          RWORK es un arreglo REAL, dimensión (MAX(1,LRWORK))
!>          LRWORK >=
!>             10*N + 2*N*SMLSIZ + 8*N*NLVL + 3*SMLSIZ*NRHS +
!>             MAX( (SMLSIZ+1)**2, N*(1+NRHS) + 2*NRHS )
!>          si M es mayor o igual que N o
!>             10*M + 2*M*SMLSIZ + 8*M*NLVL + 3*SMLSIZ*NRHS +
!>             MAX( (SMLSIZ+1)**2, N*(1+NRHS) + 2*NRHS )
!>          si M es menor que N, el código se ejecutará correctamente.
!>          SMLSIZ es devuelto por ILAENV y es igual al máximo
!>          tamaño de los subproblemas en la parte inferior del árbol
!>          de cálculo (usualmente alrededor de 25), y
!>             NLVL = MAX( 0, INT( LOG_2( MIN( M,N )/(SMLSIZ+1) ) ) + 1 )
!>          En la salida, si INFO = 0, RWORK(1) devuelve el LRWORK mínimo.
!
>

IWOR

K 
!>          IWORK es un arreglo INTEGER, dimensión (MAX(1,LIWORK))
!>          LIWORK >= max(1, 3*MINMN*NLVL + 11*MINMN),
!>          donde MINMN = MIN( M,N ).
!>          En la salida, si INFO = 0, IWORK(1) devuelve el LIWORK mínimo.
!
>

INF

O 
!>          INFO es INTEGER
!>          = 0: salida exitosa
!>          < 0: si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>          > 0:  el algoritmo para calcular el SVD falló en converger;
!>                si INFO = i, i elementos fuera de la diagonal de una forma
!>                bidiagonal intermedia no convergieron a cero.
!
>

!>          RCOND se usa para determinar el rango efectivo de A.
!>          Los valores singulares S(i) <= RCOND*S(1) se tratan como cero.

!>          El rango efectivo de A, es decir, el número de valores singulares

K 
!>          WORK es un arreglo COMPLEX*16, dimensión (MAX(1,LWORK))
!>          Al salir, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!
>

LWOR

K 
!>          LWORK es INTEGER
!>          La dimensión del arreglo WORK. LWORK debe ser al menos 1.
!>          La cantidad exacta mínima de espacio de trabajo necesaria depende
!>          de M, N y NRHS. Siempre que LWORK sea al menos
!>              2*N + N*NRHS
!>          si M es mayor o igual que N o
!>              2*M + M*NRHS
!>          si M es menor que N, el código se ejecutará correctamente.
!>          Para un buen rendimiento, LWORK generalmente debería ser mayor.
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de
!>          trabajo; la rutina solo calcula el tamaño óptimo del arreglo
!>          WORK y los tamaños mínimos de los arreglos RWORK e IWORK, y
!>          devuelve estos valores como las primeras entradas de los arreglos
!>          WORK, RWORK e IWORK, y no se emite ningún mensaje de error
!>          relacionado con LWORK por parte de XERBLA.
!
>

RWOR

K 
!>          RWORK es un arreglo DOUBLE PRECISION, dimensión (MAX(1,LRWORK))
!>          LRWORK >=
!>             10*N + 2*N*SMLSIZ + 8*N*NLVL + 3*SMLSIZ*NRHS +
!>             MAX( (SMLSIZ+1)**2, N*(1+NRHS) + 2*NRHS )
!>          si M es mayor o igual que N o
!>             10*M + 2*M*SMLSIZ + 8*M*NLVL + 3*SMLSIZ*NRHS +
!>             MAX( (SMLSIZ+1)**2, N*(1+NRHS) + 2*NRHS )
!>          si M es menor que N, el código se ejecutará correctamente.
!>          SMLSIZ es devuelto por ILAENV y es igual al tamaño máximo
!>          de los subproblemas en la parte inferior del árbol de
!>          computación (usualmente alrededor de 25), y
!>             NLVL = MAX( 0, INT( LOG_2( MIN( M,N )/(SMLSIZ+1) ) ) + 1 )
!>          Al salir, si INFO = 0, RWORK(1) devuelve el LRWORK mínimo.
!
>

IWOR

K 
!>          IWORK es un arreglo INTEGER, dimensión (MAX(1,LIWORK))
!>          LIWORK >= max(1, 3*MINMN*NLVL + 11*MINMN),
!>          donde MINMN = MIN( M,N ).
!>          Al salir, si INFO = 0, IWORK(1) devuelve el LIWORK mínimo.
!
