getdate(3) Manual de Funciones de Biblioteca getdate(3)

NOMBRE

getdate, getdate_r - convierte una cadena de fecha y hora a tiempo desglosado

BIBLIOTECA

Biblioteca C estándar (libc,-lc)

SINOPSIS

#include <time.h>
struct tm *getdate(const char *string);
extern int getdate_err;
int getdate_r(const char *restrict string, struct tm *restrict res);
Requisitos de la macro de prueba de características para glibc (ver feature_test_macros(7)):

getdate():

    _XOPEN_SOURCE >= 500

getdate_r():

    _GNU_SOURCE

DESCRIPCIÓN

La función getdate() convierte una representación de cadena de una fecha y hora, contenida en el búfer apuntado por string, a un tiempo desglosado. El tiempo desglosado se almacena en una estructura tm , y un puntero a esta estructura se devuelve como el resultado de la función. Esta estructura tm se asigna en almacenamiento estático y, en consecuencia, será sobrescrita por llamadas posteriores a getdate().

A diferencia de strptime(3), (que tiene un argumento format ), getdate() usa los formatos encontrados en el archivo cuya ruta de nombre completa se da en la variable de entorno DATEMSK. La primera línea en el archivo que coincide con la cadena de entrada dada se usa para la conversión.

La coincidencia se realiza sin distinguir mayúsculas de minúsculas. Los espacios en blanco superfluos, ya sea en el patrón o en la cadena a convertir, se ignoran.

Las especificaciones de conversión que un patrón puede contener son las dadas para strptime(3). Se especifica una especificación de conversión más en POSIX.1-2001:

%Z
Nombre de la zona horaria. Esto no está implementado en glibc.

Cuando se da %Z , la estructura que contiene el tiempo desglosado se inicializa con valores correspondientes a la hora actual en la zona horaria dada. De lo contrario, la estructura se inicializa al tiempo desglosado correspondiente a la hora local actual (como por una llamada a localtime(3)).

Cuando solo se da el día de la semana, se toma el día como el primer día de ese tipo en o después de hoy.

Cuando solo se da el mes (y no el año), se toma el mes como el primer mes igual o posterior al mes actual. Si no se da ningún día, es el primer día del mes.

Cuando no se dan la hora, el minuto y el segundo, se toman la hora, el minuto y el segundo actuales.

Si no se da ninguna fecha, pero conocemos la hora, entonces esa hora se toma como la primera hora igual o posterior a la hora actual.

getdate_r() es una extensión de GNU que proporciona una versión reentrante de getdate(). En lugar de usar una variable global para reportar errores y un búfer estático para devolver el tiempo desglosado, devuelve los errores a través del valor de resultado de la función, y devuelve el tiempo desglosado resultante en el búfer asignado por el llamador apuntado por el argumento res.

VALOR DE RETORNO

Cuando tiene éxito, getdate() devuelve un puntero a un struct tm. De lo contrario, devuelve NULL y establece la variable global getdate_err en uno de los números de error mostrados a continuación. Los cambios a errno no están especificados.

En caso de éxito, getdate_r() devuelve 0; en caso de error, devuelve uno de los números de error mostrados a continuación.

ERRORES

Los siguientes errores se devuelven a través de getdate_err (para getdate()) o como el resultado de la función (para getdate_r()):

1
La variable de entorno DATEMSK no está definida, o su valor es una cadena vacía.
2
El archivo de plantilla especificado por DATEMSK no se puede abrir para lectura.
3
Fallo al obtener la información de estado del archivo.
4
El archivo de plantilla no es un archivo regular.
5
Se encontró un error al leer el archivo de plantilla.
6
Fallo en la asignación de memoria (no hay suficiente memoria disponible).
7
No hay ninguna línea en el archivo que coincida con la entrada.
8
Especificación de entrada no válida.

ENTORNO

DATEMSK
Archivo que contiene patrones de formato.
TZ
LC_TIME
Variables usadas por strptime(3).

VERSIONES

La especificación POSIX.1 para strptime(3) contiene especificaciones de conversión usando el modificador %E o %O , mientras que tales especificaciones no se dan para getdate(). En glibc, getdate() está implementado usando strptime(3), de modo que se admiten exactamente las mismas conversiones en ambos.

ESTÁNDARES

$ TFILE=$PWD/tfile
$ echo '%A' > $TFILE       # Nombre completo del día de la semana
$ echo '%T' >> $TFILE      # Hora (HH:MM:SS)
$ echo '%F' >> $TFILE      # Fecha ISO (AAAA-MM-DD)
$ date
$ export DATEMSK=$TFILE

#define _GNU_SOURCE
#include <stdio.h>
#include <stdlib.h>
#include <time.h>
int
main(int argc, char *argv[])
{
    struct tm *tmp;
    for (size_t j = 1; j < argc; j++) {
        tmp = getdate(argv[j]);
        if (tmp == NULL) {
            printf("Llamada %zu falló; getdate_err = %d\n",
                   j, getdate_err);
            continue;
        }
        printf("Llamada %zu (\"%s\") exitosa:\n", j, argv[j]);
