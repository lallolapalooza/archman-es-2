DESCRIPCIÓN

gearman_client_st se utiliza para la comunicación del cliente con el servidor.

gearman_client_context() y gearman_client_set_context() se pueden utilizar para almacenar un objeto arbitrario para el usuario.

gearman_client_set_task_context_free_fn() establece un disparador que se llamará cuando se libere un gearman_task_st.

gearman_client_timeout() y gearman_client_set_timeout() obtienen y establecen el valor actual de tiempo de espera de conexión, en milisegundos, para el cliente.

Normalmente se utilizan malloc(3) y free(3) para la asignación y liberación de cargas de trabajo. gearman_client_set_workload_malloc_fn() y gearman_client_set_workload_free_fn() se pueden utilizar para reemplazar estas con funciones personalizadas. (Estas han sido obsoletas, consulte gearman_allocator_t para la interfaz actualizada.

gearman_client_task_free_all() se utiliza para liberar todas las gearman_task_st actuales que se han creado con gearman_client_st.

ADVERTENCIA:

Al llamar a gearman_client_task_free_all() puede terminar con un SEGFAULT si intenta utilizar cualquier gearman_task_st del que haya conservado punteros.

VALOR DE RETORNO

gearman_client_timeout() devuelve un entero que representa la cantidad de tiempo en milisegundos para esperar una conexión antes de lanzar un error. Un valor de -1 significa un tiempo de espera infinito.
