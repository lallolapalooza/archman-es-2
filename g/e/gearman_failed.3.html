DESCRIPCIÓN

gearman_return_t se utiliza como tipo de retorno/error para todas las llamadas que usan gearman_client_st y gearman_worker_st. GEARMAN_SUCCESS se devuelve en caso de éxito, de lo contrario se devuelve un error. gearman_failed() se puede utilizar para ver si el valor de retorno es un valor de fallo. Puede imprimir una versión de texto del mensaje de error con gearman_strerror().

gearman_success() devuelve true si GEARMAN_SUCCESS o si GEARMAN_NO_PENDING_TASKS evalúa a true.

gearman_failed() devuelve true si se proporcionó cualquier valor distinto de GEARMAN_SUCCESS .

gearman_continue() devuelve true si ocurrió algún error relacionado con E/S no bloqueante. Esto debe usarse para bucles de prueba.

Valores posibles de gearman_return_t:

tipo GEARMAN_NO_PENDING_TASKS
Se llamó a gearman_client_run_tasks() y ha completado todas las tareas asignadas al cliente.
tipo GEARMAN_IO_WAIT
Se encontró E/S bloqueante. gearman_continue() puede usarse para probar esto.
tipo GEARMAN_ERRNO
Ocurrió un error del sistema. Use gearman_client_errno() o gearman_worker_errno()
tipo GEARMAN_NO_ACTIVE_FDS
No había conexiones activas disponibles. gearman_continue() puede usarse para probar esto.
tipo GEARMAN_GETADDRINFO
Falló la resolución de nombres para un host.
tipo GEARMAN_NO_SERVERS
No se han proporcionado servidores para el cliente/trabajador.
tipo GEARMAN_LOST_CONNECTION
Se perdió la conexión con el servidor dado.
tipo GEARMAN_MEMORY_ALLOCATION_FAILURE
Falló la asignación de memoria.
tipo GEARMAN_SERVER_ERROR
Ocurrió un error en el servidor.
tipo GEARMAN_NOT_CONNECTED
El cliente/trabajador no está conectado actualmente al servidor.
tipo GEARMAN_COULD_NOT_CONNECT
El nombre del servidor era válido, pero no se pudo establecer una conexión.
tipo GEARMAN_ECHO_DATA_CORRUPTION
Tanto gearman_client_echo() como gearman_worker_echo() echo fallaron porque los datos devueltos por gearmand estaban corruptos.
tipo GEARMAN_UNKNOWN_STATE
El gearman_return_t nunca se estableció.
tipo GEARMAN_FLUSH_DATA
Estado interno, nunca debería ser visto por el cliente ni por el trabajador.
tipo GEARMAN_SEND_BUFFER_TOO_SMALL
El búfer de envío era demasiado pequeño.
tipo GEARMAN_TIMEOUT
Ocurrió un tiempo de espera al hacer una petición al servidor.
tipo GEARMAN_ARGUMENT_TOO_LARGE
El argumento era demasiado grande para el búfer actual.
tipo GEARMAN_INVALID_ARGUMENT
Uno de los argumentos de la llamada a la API dada era inválido. Se establecerá EINVAL si gearman_client_error() o gearman_worker_error() no se pudieron establecer. Esto también puede devolverse si GEARMAN_CLIENT_UNBUFFERED_RESULT estaba establecido, pero el cliente no está manejando los datos correctamente.

SOLO CLIENTE

tipo GEARMAN_NEED_WORKLOAD_FN
Se le pidió trabajo a un cliente, pero no se especificó gearman_workload_fn callback. Vea gearman_client_set_workload_fn()
tipo GEARMAN_WORK_FAIL
Una tarea ha fallado, y el trabajador ha salido con un error o ha llamado a gearman_job_send_fail()
tipo GEARMAN_IN_PROGRESS
Se ha llamado a gearman_client_job_status() para un gearman_job_handle_t y el trabajo está siendo ejecutado actualmente por un trabajador.
tipo GEARMAN_JOB_EXISTS
Se ha llamado a gearman_client_job_status() para un gearman_job_handle_t y el trabajo es conocido actualmente por un servidor, pero no está siendo ejecutado por un trabajador.

SOLO TRABAJADOR

tipo GEARMAN_INVALID_FUNCTION_NAME
Se envió a un trabajador una petición de un trabajo para el que no tenía una función válida.
tipo GEARMAN_INVALID_WORKLOAD_FUNCTION
El trabajador no proporcionó ningún callback para una función dada.
tipo GEARMAN_NO_REGISTERED_FUNCTION
La petición de eliminar una función dada de un trabajador era inválida ya que esa función no existía.
tipo GEARMAN_NO_REGISTERED_FUNCTIONS
El trabajador no ha registrado ninguna función.
tipo GEARMAN_NO_JOBS
No se encontraron trabajos para el trabajador. Este código de error solo se devuelve si

DESCRIPTION

The gearman_return_t is an enumerated type that is used to return status codes from the various Gearman library functions.

The following is a list of possible return codes and their meaning:

CLIENT TO GEARMAND

These return values are used when communicating with the Gearman job server.

type GEARMAN_GETADDRINFO_ERROR
An error occurred during address resolution.
type GEARMAN_NO_SERVERS
No Gearman job servers were found.
type GEARMAN_LOST_CONNECTION
The connection to the Gearman job server was lost.
type GEARMAN_READ_TIMEOUT
A read operation timed out.
type GEARMAN_WRITE_TIMEOUT
A write operation timed out.
type GEARMAN_COULD_NOT_CONNECT
The client could not connect to the Gearman job server.
type GEARMAN_CONNECTION_REFUSED
The connection to the Gearman job server was refused.
type GEARMAN_HOST_RESOLUTION_ERROR
An error occurred while resolving the host name.
type GEARMAN_NETWORK_MEM_IO_ERROR
A network memory I/O error occurred.
type GEARMAN_TOO_MANY_CLIENTS
Too many clients are connected to the Gearman job server.
type GEARMAN_SERVER_ERROR
The Gearman job server returned an error.
type GEARMAN_TIMEOUT
A timeout occurred during a Gearman operation.
type GEARMAN_SCHEDULING_FAILURE
The job could not be scheduled.
type GEARMAN_REFUSED
The job was refused by the Gearman job server.
type GEARMAN_UNKNOWN_STATE
The Gearman job server is in an unknown state.
type GEARMAN_BAD_FILENAME
An invalid filename was provided.
type GEARMAN_WORK_QUEUE_EXISTS
A work queue with the specified name already exists.
type GEARMAN_WORK_QUEUE_DOES_NOT_EXIST
A work queue with the specified name does not exist.
type GEARMAN_CANNOT_DO
The Gearman job server cannot perform the requested operation.
type GEARMAN_TEXT_TRUNCATED
The text data was truncated.
type GEARMAN_NOT_SUPPORTED
The requested operation is not supported.
type GEARMAN_JOB_TO_LARGE
The job workload is too large.
type GEARMAN_INVALID_ARGUMENT
An invalid argument was provided.

WORKER TO CLIENT

Client which have registed a custom gearman_actions_t may use these value as return values to the calling client.

type GEARMAN_WORK_DATA
Worker has sent a chunked piece of data to the client via gearman_job_send_data()
type GEARMAN_WORK_WARNING
Worker has issued a warning to the client via gearman_job_send_warning()
type GEARMAN_WORK_STATUS
Status has been updated by the worker via gearman_job_send_status()
type GEARMAN_WORK_EXCEPTION
Worker has sent an exception the client via gearman_job_send_exception()
type GEARMAN_WORK_FAIL
The worker failed to complete the job.
type GEARMAN_WORK_ERROR
A task has had an error and will be retried.
type GEARMAN_PAUSE
Used only in custom application for client return based on GEARMAN_WORK_DATA, GEARMAN_WORK_WARNING, GEARMAN_WORK_EXCEPTION, GEARMAN_WORK_FAIL, or GEARMAN_WORK_STATUS. gearman_continue() can be used to check for this value.

WORKER TO CLIENT

Any function defined by gearman_worker_define_function() may, and can only, return the following gearman_return_t values.

type GEARMAN_FATAL
A fatal error occurred.
type GEARMAN_FAIL
The function failed to complete the job. GEARMAN_FATAL is the deprecated name for GEARMAN_FAIL
type GEARMAN_ERROR
A task has had an error and will be retried.
type GEARMAN_SHUTDOWN
GEARMAN_SHUTDOWN is a special case. If it is returned the client will be sent GEARMAN_SUCCESS, but gearman_worker_work() will exit with GEARMAN_SHUTDOWN.

TASK ONLY

type GEARMAN_NOT_FLUSHING
gearman_task_send_workload() failed, it was not in the correct state.
type GEARMAN_DATA_TOO_LARGE
gearman_task_send_workload() failed, the data was too large to be sent.
type GEARMAN_UNKNOWN_OPTION
Default state of task return value.

PROTOCOL

If any of these errors occurred the connection will be dropped/reset.

type GEARMAN_INVALID_MAGIC
Invalid magic number received.
type GEARMAN_INVALID_COMMAND
Invalid command received.
type GEARMAN_INVALID_PACKET
Invalid packet received.
type GEARMAN_UNEXPECTED_PACKET
An unexpected packet was received.
type GEARMAN_TOO_MANY_ARGS
Too many arguments were provided.

DEPRECATED

type GEARMAN_IGNORE_PACKET
This return code is no longer used.
type GEARMAN_MAX_RETURN
This is the maximum value for the gearman_return_t enumeration.
