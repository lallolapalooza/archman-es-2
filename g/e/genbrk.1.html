NOMBRE

genbrk - Compila archivos fuente de reglas de iteración de ruptura de ICU en archivos de datos binarios

SINOPSIS

genbrk [ -h, -?, --help ] [ -V, --version ] [ -c, --copyright ] [ -v, --verbose ] [ -d, --destdir destino ] [ -i, --icudatadir directorio ] -r, --rules archivo-reglas -o, --out archivo-salida

DESCRIPCIÓN

genbrk lee el código fuente de las reglas de ruptura (límite) del archivo archivo-reglas y crea un archivo de datos de iteración de ruptura. Normalmente, este archivo de datos tiene la extensión .brk.

Los detalles de la sintaxis de las reglas se pueden encontrar en la Guía del Usuario de ICU.

OPCIONES

-h, -?, --help
Imprime ayuda sobre el uso y sale.
-V, --version
Imprime la versión de genbrk y sale.
-c, --copyright
Incrusta el aviso de copyright estándar de ICU en el archivo-salida.
-v, --verbose
Muestra mensajes informativos adicionales durante la ejecución.
-d, --destdir destino
Establece el directorio de destino del archivo-salida a destino.
-i, --icudatadir directorio
Busca cualquier archivo de datos de ICU necesario en el directorio. Por ejemplo, el archivo pnames.icu debe estar ubicado cuando los datos de ICU no se compilan como una biblioteca compartida. El directorio de datos de ICU predeterminado se especifica mediante la variable de entorno ICU_DATA. La mayoría de las configuraciones de ICU no requieren este argumento.
-r, --rules archivo-reglas
El archivo fuente a leer.
-o, --out archivo-salida
El archivo de datos de salida a escribir.

ADVERTENCIAS

Cuando el archivo-reglas contiene una marca de orden de bytes (BOM) al principio del archivo, que es el carácter Unicode U+FEFF, entonces el archivo-reglas se interpreta como Unicode. Sin la BOM, el archivo se interpreta en la página de códigos predeterminada del sistema operativo actual. Para eliminar cualquier ambigüedad de codificación sobre cómo se escribió el archivo-reglas, se recomienda escribir este archivo en UTF-8 con la BOM.

ENTORNO

ICU_DATA
Especifica el directorio que contiene los datos de ICU. Predeterminado a ${prefix}/share/icu/78.1/. Algunas herramientas en ICU dependen de la presencia de la barra diagonal final. Por lo tanto, es importante asegurarse de que esté presente si se establece ICU_DATA.
