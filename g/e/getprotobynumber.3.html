getprotoent(3) Manual de funciones de biblioteca getprotoent(3)

NOMBRE

getprotoent, getprotobyname, getprotobynumber, setprotoent, endprotoent - obtener entrada de protocolo

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <netdb.h>
struct protoent *getprotoent(void);
struct protoent *getprotobyname(const char *name);
struct protoent *getprotobynumber(int proto);
void setprotoent(int stayopen);
void endprotoent(void);

DESCRIPCIÓN

La función getprotoent() lee la siguiente entrada de la base de datos de protocolos (véase protocols(5)) y devuelve una estructura protoent que contiene los campos desglosados de la entrada. Se abre una conexión a la base de datos si es necesario.

La función getprotobyname() devuelve una estructura protoent para la entrada de la base de datos que coincide con el nombre de protocolo name. Se abre una conexión a la base de datos si es necesario.

La función getprotobynumber() devuelve una estructura protoent para la entrada de la base de datos que coincide con el número de protocolo number. Se abre una conexión a la base de datos si es necesario.

La función setprotoent() abre una conexión a la base de datos y establece la siguiente entrada en la primera entrada. Si stayopen no es cero, la conexión a la base de datos no se cerrará entre llamadas a una de las funciones getproto*().

La función endprotoent() cierra la conexión a la base de datos.

La estructura protoent se define en <netdb.h> de la siguiente manera:


struct protoent {
    char  *p_name;       /* nombre oficial del protocolo */
    char **p_aliases;    /* lista de alias */
    int    p_proto;      /* número de protocolo */
}

Los miembros de la estructura protoent son:

p_name
El nombre oficial del protocolo.
p_aliases
Una lista terminada en NULL de nombres alternativos para el protocolo.
p_proto
El número de protocolo.

VALOR DE RETORNO

Las funciones getprotoent(), getprotobyname() y getprotobynumber() devuelven un puntero a una estructura protoent estáticamente asignada, o un puntero nulo si ocurre un error o se llega al final del archivo.

ARCHIVOS

/etc/protocols
archivo de base de datos de protocolos

ATRIBUTOS

Para obtener una explicación de los términos utilizados en esta sección, consulte attributes(7).

Interfaz Atributo Valor
getprotoent () Seguridad de hilos MT-Unsafe race:protoent race:protoentbuf locale
getprotobyname () Seguridad de hilos MT-Unsafe race:protobyname locale
getprotobynumber () Seguridad de hilos MT-Unsafe race:protobynumber locale
setprotoent (), endprotoent () Seguridad de hilos MT-Unsafe race:protoent locale

En la tabla anterior, protoent en race:protoent significa que si alguna de las funciones setprotoent(), getprotoent() o endprotoent() se utilizan en paralelo en diferentes hilos de un programa, podrían producirse carreras de datos.

ESTÁNDARES

POSIX.1-2008.

HISTORIA

POSIX.1-2001, 4.3BSD.

VER TAMBIÉN

getnetent(3), getprotoent_r(3), getservent(3), protocols(5)
