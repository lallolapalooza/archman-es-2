NOMBRE

genfstab - genera salida adecuada para añadir a un archivo fstab

SINOPSIS

genfstab [opciones] root

DESCRIPCIÓN

genfstab ayuda a completar un archivo fstab detectando automáticamente todos los montajes actuales por debajo de un punto de montaje dado e imprimiéndolos en formato compatible con fstab a la salida estándar. Se puede utilizar para persistir una jerarquía de sistemas de archivos montada manualmente y se utiliza a menudo durante la instalación y configuración inicial de un sistema operativo.

OPCIONES

-f <filtro>

Restringe la salida a los puntos de montaje que coincidan con el prefijo filtro.

-L

Usa etiquetas para los identificadores de origen (atajo para -t LABEL).

-p

Excluye montajes pseudofs (comportamiento predeterminado).

-P

Incluye montajes pseudofs.

-t <etiqueta>

Usa etiqueta para los identificadores de origen (debe ser uno de: LABEL, UUID, PARTLABEL, PARTUUID).

-U

Usa UUIDs para los identificadores de origen (atajo para -t UUID).

-h

Sintaxis de salida y opciones de línea de comandos.
