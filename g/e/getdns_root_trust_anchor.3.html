NOMBRE

getdns_root_trust_anchor -- devuelve la lista de getdns de anclas de confianza raíz predeterminadas

BIBLIOTECA

DNS Resolver library (libgetdns, -lgetdns)

SINOPSIS

#include <getdns.h>

getdns_list *
getdns_root_trust_anchor (time_t *utc_date_of_anchor)

DESCRIPCIÓN

Si una aplicación desea que la API realice la validación DNSSEC sin utilizar las extensiones, puede usar la función auxiliar getdns_validate_dnssec(). La API utilizará los registros de recursos en bundle_of_support_records para construir la cadena de validación y los registros DNSKEY o DS en trust_anchor_records como anclas de confianza. La lista predeterminada de registros de anclas de confianza que utiliza la biblioteca para validar DNSSEC se puede obtener utilizando la función auxiliar getdns_root_trust_anchor().

utc_date_of_anchor tiempo en que se obtuvieron las anclas de confianza en segundos de época (en caso de éxito)

VALORES DE RETORNO

Devuelve la lista predeterminada de registros de anclas de confianza utilizada por la biblioteca para validar DNSSEC o NULL si no hay anclas de confianza predeterminadas disponibles.
