subrutina cgetri (integer n, complex, dimension( lda, * ) a, integer lda, integer, dimension( * ) ipiv, complex, dimension( * ) work, integer lwork, integer info)

CGETRI

Propósito:

!>
!> CGETRI calcula la inversa de una matriz utilizando la factorización LU
!> calculada por CGETRF.
!>
!> Este método invierte U y luego calcula inv(A) resolviendo el sistema
!> inv(A)*L = inv(U) para inv(A).
!>

Parámetros

N 
!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

A

!>          A es un array COMPLEX, dimensión (LDA,N)
!>          En la entrada, los factores L y U de la factorización
!>          A = P*L*U tal como fue calculada por CGETRF.
!>          En la salida, si INFO = 0, la inversa de la matriz original A.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

IPIV

!>          IPIV es un array INTEGER, dimensión (N)
!>          Los índices de pivote de CGETRF; para 1<=i<=N, la fila i de la
!>          matriz fue intercambiada con la fila IPIV(i).
!>

WORK

!>          WORK es un array COMPLEX, dimensión (MAX(1,LWORK))
!>          En la salida, si INFO=0, entonces WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK.  LWORK >= max(1,N).
!>          Para un rendimiento óptimo LWORK >= N*NB, donde NB es
!>          el tamaño de bloque óptimo devuelto por ILAENV.
!>
!>          Si LWORK = -1, se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo del array WORK, devuelve
!>          este valor como la primera entrada del array WORK, y XERBLA no emite
!>          ningún mensaje de error relacionado con LWORK.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>          > 0:  si INFO = i, U(i,i) es exactamente cero; la matriz es
!>                singular y su inversa no pudo ser calculada.
!>
