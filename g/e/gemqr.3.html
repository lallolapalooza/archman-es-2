Función

subrutina cgemqr (character side, character trans, integer m, integer n, integer k, complex, dimension( lda, * ) a, integer lda, complex, dimension( * ) t, integer tsize, complex, dimension( ldc, * ) c, integer ldc, complex, dimension( * ) work, integer lwork, integer

info)

CGEMQ

R

Propósito

: 
!>
!> CGEMQR sobrescribe la matriz real general M-por-N C con
!>
!>                      SIDE = 'L'     SIDE = 'R'
!>      TRANS = 'N':      Q * C          C * Q
!>      TRANS = 'T':      Q**H * C       C * Q**H
!>
!> donde Q es una matriz unitaria compleja definida como el producto
!> de reflectores elementales bloqueados calculados por la factorización
!> QR alta y delgada (CGEQR)
!>
!
>

Parámetro

s
SIDE 
!>          SIDE es CHARACTER*1
!>          = 'L': aplicar Q o Q**H desde la Izquierda;
!>          = 'R': aplicar Q o Q**H desde la Derecha.
!
>

TRAN

S 
!>          TRANS es CHARACTER*1
!>          = 'N':  Sin transposición, aplicar Q;
!>          = 'C':  Transposición conjugada, aplicar Q**H.
!
>

M 
!>          M es INTEGER
!>          El número de filas de la matriz A.  M >=0.
!
>

N 
!>          N es INTEGER
!>          El número de columnas de la matriz C. N >= 0.
!
>

K 
!>          K es INTEGER
!>          El número de reflectores elementales cuyo producto define
!>          la matriz Q.
!>          Si SIDE = 'L', M >= K >= 0;
!>          si SIDE = 'R', N >= K >= 0.
!
>

A 
!>          A es un arreglo COMPLEX, dimensión (LDA,K)
!>          Parte de la estructura de datos para representar Q como lo devuelve CGEQR.
!
>

LD

A 
!>          LDA es INTEGER
!>          La dimensión principal del arreglo A.
!>          Si SIDE = 'L', LDA >= max(1,M);
!>          si SIDE = 'R', LDA >= max(1,N).
!
>

T 
!>          T es un arreglo COMPLEX, dimensión (MAX(5,TSIZE)).
!>          Parte de la estructura de datos para representar Q como lo devuelve CGEQR.
!
>

TSIZ

E 
!>          TSIZE es INTEGER
!>          La dimensión del arreglo T. TSIZE >= 5.
!
>

C 
!>          C es un arreglo COMPLEX, dimensión (LDC,N)
!>          En la entrada, la matriz M-por-N C.
!>          En la salida, C es sobrescrita por Q*C o Q**H*C o C*Q**H o C*Q.
!
>

LD

C 
!>          LDC es INTEGER
!>          La dimensión principal del arreglo C. LDC >= max(1,M).
!
>

WOR

K 
!>          (espacio de trabajo) Arreglo COMPLEX, dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK mínimo.
!
>

LWOR

K 
!>          LWORK es INTEGER
!>          La dimensión del arreglo WORK. LWORK >= 1.
!>          Si LWORK = -1, se asume una consulta de espacio de trabajo. La rutina
!>          solo calcula el tamaño del arreglo WORK, devuelve este
!>          valor como WORK(1), y XERBLA no emite ningún mensaje de error relacionado con WORK.
!
>

INF

O 
!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!
>
