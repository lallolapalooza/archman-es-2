getdns_pretty_print_dict(3) getdns getdns_pretty_print_dict(3)

NOMBRE

getdns_pretty_print_dict -- devuelve una representación en cadena de un diccionario getdns

BIBLIOTECA

Biblioteca de resolución DNS (libgetdns, -lgetdns)

SINOPSIS

#include <getdns.h>

char *
getdns_pretty_print_dict (const getdns_dict *this_dict)

DESCRIPCIÓN

Función auxiliar que devuelve una cadena de datos bien formateada, incluyendo todos los elementos del diccionario.

this_dict el diccionario a representar como una cadena

VALORES DE RETORNO

Devuelve una cadena que la función que llama debe liberar (se asigna usando el asignador del sistema, no el asignador definido por el usuario). Devuelve NULL si hay un error.
