DESCRIPCIÓ

N

Las funciones getprotoent_r(), getprotobyname_r() y getprotobynumber_r() son los equivalentes reentrantes de, respectivamente, getprotoent(3), getprotobyname(3) y getprotobynumber(3). Difieren en la forma en que se devuelve la estructura protoent y en la firma de llamada de la función y el valor de retorno. Esta página de manual describe solo las diferencias con las funciones no

reentrantes.

En lugar de devolver un puntero a una estructura protoent asignada estáticamente como resultado de la función, estas funciones copian la estructura en la ubicación apuntada por result_buf

.

El array buf se usa para almacenar los campos de cadena apuntados por la estructura protoent devuelta. (Las funciones no reentrantes asignan estas cadenas en almacenamiento estático.) El tamaño de este array se especifica en size. Si buf es demasiado pequeño, la llamada falla con el error ERANGE, y el llamador debe intentarlo de nuevo con un búfer más grande. (Un búfer de 1024 bytes debería ser suficiente para la mayoría de las aplicaciones.

)

Si la llamada a la función obtiene con éxito un registro de protocolo, entonces *result se establece apuntando a result_buf; de lo contrario, *result se est

ablece
a NULL.

EJEMPLO

S

El programa siguiente usa getprotobyname_r() para recuperar el registro de protocolo para el protocolo nombrado en su primer argumento de línea de comandos. Si se proporciona un segundo argumento de línea de comandos (entero), se usa como el valor inicial para size; si getprotobyname_r() falla con el error ERANGE, el programa reintenta con tamaños de búfer más grandes. La siguiente sesión de shell muestra un par de ejecuciones de

ejemplo: 


$ ./a.out tcp 1
ERANGE! Reintentando con búfer más grande
getprotobyname_r() devolvió: 0 (éxito)  (size=78)
p_name=tcp; p_proto=6; aliases=TCP
$ ./a.out xxx 1
ERANGE! Reintentando con búfer más grande
getprotobyname_r() devolvió: 0 (éxito)  (size=100)
Llamada fallida/registro no
encontrado

Fuente del

programa 
#define _GNU_SOURCE
#include <ctype.h>
#include <errno.h>
#include <netdb.h>
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#define MAX_BUF 10000
int
main(int argc, char *argv[])
{
    int size, erange_cnt, s;
    struct protoent result_buf;
    struct protoent *result;
    char buf[MAX_BUF];
    if (argc < 2) {
        printf("Usage: %s proto-name [size]\n", argv[0]);
        exit(EXIT_FAILURE);
    }
    size = 1024;
    if (argc > 2)
        size = atoi(argv[2]);
    if (size > MAX_BUF) {
        printf("Exceeded buffer limit (%d)\n", MAX_BUF);
        exit(EXIT_FAILURE);
    }
    erange_cnt = 0;
    do {
        s = getprotobyname_r(argv[1], &result_buf,
                             buf, size, &result);
        if (s == ERANGE) {
            if (erange_cnt == 0)
                printf("ERANGE! Retrying with larger buffer\n");
            erange_cnt++;
            /* Increment a byte at a time so we can see exactly
               what size buffer was required.  */
            size++;
            if (size > MAX_BUF) {
                printf("Exceeded buffer limit (%d)\n", MAX_BUF);
                exit(EXIT_FAILURE);
            }
        }
    } while (s == ERANGE);
    printf("getprotobyname_r() returned: %s  (size=%d)\n",
           (s == 0) ? "0 (success)" : (s == ENOENT) ? "ENOENT" :
           strerror(s), size);
    if (s != 0 || result == NULL) {
        printf("Call failed/record not found\n");
        exit(EXIT_FAILURE);
    }
    printf("p_name=%s; p_proto=%d; aliases=",
           result_buf.p_name, result_buf.p_proto);
    for (char **p = result_buf.p_aliases; *p != NULL; p++)
        printf("%s ", *p);
    printf("\n");
    exit(EXIT_SUCCESS)
;
}
