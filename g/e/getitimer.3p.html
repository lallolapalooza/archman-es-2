GETITIMER(3P) Manual del Programador POSIX GETITIMER(3P)

PRÓLOGO

Esta página manual forma parte del Manual del Programador POSIX. La implementación de Linux de esta interfaz puede diferir (consulte la página manual de Linux correspondiente para detalles del comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

getitimer, setitimer — obtener y establecer el valor del temporizador de intervalo

SINOPSIS

#include <sys/time.h>
int getitimer(int which, struct itimerval *value);
int setitimer(int which, const struct itimerval *restrict value,
    struct itimerval *restrict ovalue);

DESCRIPCIÓN

La función getitimer() almacenará el valor actual del temporizador especificado por which en la estructura apuntada por value. La función setitimer() establecerá el temporizador especificado por which al valor especificado en la estructura apuntada por value, y si ovalue no es un puntero nulo, almacenará el valor anterior del temporizador en la estructura apuntada por ovalue.

Un valor de temporizador está definido por la estructura itimerval , especificada en <sys/time.h>. Si it_value es distinto de cero, indicará el tiempo hasta la próxima expiración del temporizador. Si it_interval es distinto de cero, especificará un valor a usar al recargar it_value cuando el temporizador expire. Establecer it_value a 0 deshabilitará un temporizador, independientemente del valor de it_interval. Establecer it_interval a 0 deshabilitará un temporizador después de su próxima expiración (asumiendo que it_value es distinto de cero).

Las implementaciones pueden imponer limitaciones en la granularidad de los valores de los temporizadores. Para cada temporizador de intervalo, si el valor de temporizador solicitado requiere una granularidad más fina que la soportada por la implementación, el valor real del temporizador se redondeará hacia arriba al siguiente valor soportado.

Una implementación conforme a XSI proporciona a cada proceso al menos tres temporizadores de intervalo, los cuales son indicados por el argumento which :

ITIMER_PROF
Decrementa tanto en tiempo virtual del proceso como cuando el sistema está ejecutando en nombre del proceso. Está diseñado para ser usado por intérpretes en el perfilado estadístico de la ejecución de programas interpretados. Cada vez que el temporizador ITIMER_PROF expira, se entrega la señal SIGPROF.
ITIMER_REAL
Decrementa en tiempo real. Se entrega una señal SIGALRM cuando este temporizador expira.
ITIMER_VIRTUAL
Decrementa en tiempo virtual del proceso. Se ejecuta solo cuando el proceso está en ejecución. Se entrega una señal SIGVTALRM cuando expira.

La interacción entre setitimer() y alarm() o sleep() no está especificada.

VALOR DE RETORNO

Tras una finalización exitosa, getitimer() o setitimer() devolverán 0; de lo contrario, se devolverá -1 y se establecerá errno para indicar el error.

ERRORES

La función setitimer() fallará si:

EINVAL
El argumento value no está en forma canónica. (En forma canónica, el número de microsegundos es un entero no negativo menor que 1000000 y el número de segundos es un entero no negativo.)

Las funciones getitimer() y setitimer() pueden fallar si:

EINVAL
El argumento which no es reconocido.

EJEMPLOS

Ninguno.

USO EN APLICACIONES

Las aplicaciones deberían usar las funciones timer_gettime() y timer_settime() en lugar de las funciones obsoletas getitimer() y setitimer(), respectivamente.

JUSTIFICACIÓN

Ninguna.

DIRECCIONES FUTURAS

Las funciones getitimer() y setitimer() podrían ser eliminadas en una versión futura.
