NOMBRE

gensio_get_type, gensio_get_child, gensio_is_client, gensio_is_reliable, gensio_is_packet, gensio_is_authenticated, gensio_is_encrypted, gensio_is_message, gensio_is_mux - Devolver información general sobre un gensio

SINOPSIS

#include <gensio/gensio.h>

const char *gensio_get_type(struct gensio *io,

unsigned int depth);
struct gensio *gensio_get_child(struct gensio *io,

unsigned int depth);
bool gensio_is_client(struct gensio *io);
bool gensio_is_reliable(struct gensio *io);
bool gensio_is_packet(struct gensio *io);
bool gensio_is_authenticated(struct gensio *io);
bool gensio_is_encrypted(struct gensio *io);
bool gensio_is_message(struct gensio *io);
bool gensio_is_mux(struct gensio *io);

DESCRIPCIÓN

gensio_get_type devuelve la cadena de tipo para el gensio (si depth es 0) o uno de sus hijos (depth > 0). Devuelve NULL si la profundidad es mayor que el número de hijos.

gensio_get_child devuelve el hijo dado del gensio, devuelve NULL si la profundidad es mayor que el número de hijos.

gensio_is_client devuelve verdadero si el gensio es un cliente o falso si es un servidor.

gensio_is_reliable devuelve verdadero si el gensio es confiable (no perderá datos). Los dispositivos serie no se consideran confiables, ni UDP. Prácticamente todo lo demás lo es, porque no dejarán caer datos y tienen control de flujo.

gensio_is_packet devuelve si el gensio está orientado a paquetes. En un gensio orientado a paquetes, si un lado escribe un bloque de datos, cuando el otro lado realiza una lectura obtendrá el mismo bloque de datos como una sola unidad, asumiendo que los tamaños de su búfer están configurados correctamente.

gensio_is_authenticated devuelve verdadero si el extremo remoto se autenticó, falso si no. En el caso SSL, esto significa que se recibió y verificó el certificado remoto (cliente y servidor, consulte la sección SSL de gensio(5) para obtener detalles). Para el servidor certauth, esto significa que la autenticación autenticó exitosamente al cliente certauth, ya sea por certificado o por contraseña.

gensio_is_encrypted devuelve verdadero si la conexión está cifrada, falso si no.

gensio_is_message devuelve si el gensio está orientado a mensajes. En un gensio orientado a mensajes, una escritura puede marcar explícitamente los límites del mensaje, que se entregan al lector con esos límites establecidos. Consulte gensio(5) para obtener detalles sobre cómo funciona esto.

gensio_is_mux devuelve verdadero si el gensio es capaz de multiplexar, lo que significa que acepta una llamada a gensio_alloc_channel().

Tenga en cuenta que para las solicitudes del tipo "gensio_is_xxx", la propiedad generalmente se hereda del hijo. Por lo tanto, si ejecuta un gensio telnet sobre un gensio SSL, el gensio telnet devolverá verdadero para gensio_is_encrypted porque SSL está cifrado.
