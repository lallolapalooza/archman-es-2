DESCRIPCIÓN

Los valores predeterminados proporcionan una forma de establecer valores predeterminados generales o específicos de la clase para las opciones de gensio (o puede usarlos usted mismo para crear sus propios valores predeterminados). Las diversas opciones para gensios se describen en gensio(5).

Para los valores predeterminados, cada clase utilizará gensio_get_default con su clase (serialdev, telnet, ssl, etc.) con el nombre como el nombre de la opción dada. Si se ha establecido un valor para su clase, utilizará ese valor. Si se ha establecido un valor con la clase establecida en NULL (un valor predeterminado "global"), entonces el valor se utilizará desde allí. De lo contrario, el código usará su propio valor predeterminado interno.

Cualquier opción proporcionada en la cadena de gensio anulará cualquier valor predeterminado, por supuesto.

El parámetro classonly significa no buscar en los valores predeterminados globales. Si utiliza esto para sus propios valores predeterminados, se recomienda que utilice su propia clase y establezca classonly en true.

Los valores predeterminados vienen en uno de los cuatro formatos definidos por type: GENSIO_DEFAULT_INT, GENSIO_DEFAULT_BOOL, GENSIO_DEFAULT_ENUM, GENSIO_DEFAULT_STR, GENSIO_DEFAULT_DATA. int y bool son bastante autoexplicativos. Excepto que si pasa un strval no NULL al configurar uno, el código intentará obtener el valor de strval y devolverá NULL si el valor no es válido. Intentará traducir "true" y "false" para valores booleanos. Si el valor es <minval o >maxval, GE_OUTOFRANGE se devolverá de cualquier operación de configuración.

Al configurar una cadena, el valor se copia; no tiene que conservar la copia usted mismo.

Al obtener un valor de cadena, el valor se duplica con gensio_strdup, debe liberarlo con o->free().

Data es como las cadenas, excepto que la longitud se pasa en intval y se devuelve de la misma manera. Esto contendrá datos crudos arbitrarios. Al igual que las cadenas, cuando obtenga un valor de datos, debería liberarlo con o->free().

Si es un enum, al configurar el valor pasará una cadena y una tabla de valores posibles en enum (terminada con un nombre NULL). El código buscará la cadena que pase en la tabla de enums y establecerá el valor al valor entero. Si la cadena no está en la tabla de enums, devolverá GE_INVAL. Al obtener el valor, devolverá el valor en intval.

Al obtener el valor, el tipo debe coincidir con lo que se estableció en la llamada de configuración. Si el nombre no se encuentra, se devuelve GE_NOTFOUND. Si el tipo no coincide, entonces se devuelve GE_INVAL. Tenga en cuenta que si guarda un valor como enum, puede recuperarlo como un int.

Volver a configurar el mismo valor predeterminado reemplazará el valor antiguo.

gensio_del_default elimina el valor predeterminado dado. Solo puede eliminar valores predeterminados agregados por el usuario, no los creados por la biblioteca gensio. Si hay algún valor predeterminado específico de la clase registrado contra el valor predeterminado, esta llamada fallará con GE_INUSE a menos que delclasses sea true, lo que provocará que también se eliminen todos los valores predeterminados de la clase.

gensio_reset_defaults restablecerá todos los valores predeterminados al valor establecido cuando se llamó a gensio_add_default para crear el valor predeterminado, o al valor predeterminado incorporado.

gesnio_get_defaultaddr obtiene una dirección de la cadena de valor predeterminado dada. Consulte gensi_scan_network_port en gensio/gensio.h para obtener detalles sobre cómo se formatea la cadena, qué significan los parámetros y cómo manejar la estructura addrinfo.

VALORES DE RETORNO

Se devuelve cero en caso de éxito, o un error de gensio en caso de fallo.
