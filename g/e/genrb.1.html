NOMBRE

genrb - compilar un paquete de recursos

SINOPSIS

genrb [ -h, -?, --help ] [ -V, --version ] [ -v, --verbose ] [ -e, --encoding codificación ] [ -j, --write-java [ codificación ] ] [ -s, --sourcedir origen ] [ -d, --destdir destino ] [ -i, --icudatadir directorio ] paquete ...

DESCRIPCIÓN

genrb convierte los archivos fuente del paquete de recursos pasados en la línea de comandos a su forma binaria o a un archivo fuente de Java para su uso con ICU4J. Los archivos binarios resultantes tienen la extensión .res, mientras que los archivos fuente de paquetes de recursos suelen tener la extensión .txt. Los archivos fuente de Java tienen la extensión java y siguen las convenciones de nomenclatura de ICU4J.

Es habitual nombrar los paquetes de recursos por el nombre de su localidad, es decir, usar un identificador de localización para el nombre de archivo del paquete, por ejemplo, ja_JP.txt para datos de japonés (Japón), o root.txt para el paquete raíz. En cualquier caso, genrb producirá un archivo cuyo nombre base sea el nombre de la localidad encontrada en el archivo de recursos, no el nombre base del propio archivo de recursos.

Los archivos binarios pueden ser leídos directamente por ICU, o ser utilizados por pkgdata(1) para su incorporación en un archivo o biblioteca más grande.

OPCIONES

-h, -?, --help
Imprime la ayuda sobre el uso y sale.
-V, --version
Imprime la versión de genrb y sale.
-v, --verbose
Muestra mensajes informativos adicionales durante la ejecución.
-e, --encoding codificación
Establece la codificación utilizada para leer los archivos de entrada a codificación. La codificación predeterminada es la página de códigos invariante (subconjunto de ASCII o EBCDIC) del sistema (ver sección CARACTERES INVARIANTES). Las codificaciones UTF-8, UTF-16BE y UTF-16LE se detectan automáticamente si está presente una marca de orden de byte (BOM).
-j, --write-java [ codificación ]
Genera código fuente de Java para su uso con ICU4J. Se puede proporcionar una codificación opcional para el archivo Java.
-s, --sourcedir origen
Establece el directorio de origen a origen. El directorio de origen predeterminado es el especificado por la variable de entorno ICU_DATA, o la ubicación establecida cuando se compiló ICU si ICU_DATA no está configurado.
-d, --destdir destino
Establece el directorio de destino a destino. El directorio de destino predeterminado es el especificado por la variable de entorno ICU_DATA o es la ubicación establecida cuando se compiló ICU si ICU_DATA no está configurado.
-i, --icudatadir directorio
Busca cualquier archivo de datos ICU necesario en directorio. Por ejemplo, al procesar anulaciones de ordenación, el archivo ucadata.dat debe ser localizado. El directorio de datos ICU predeterminado es el especificado por la variable de entorno ICU_DATA.

CARACTERES INVARIANTES

El conjunto de caracteres invariantes consta del siguiente conjunto de caracteres, expresado como una expresión regular POSIX estándar: [a-z]|[A-Z]|[0-9]|_| |+|-|*|/. Este es el conjunto que está garantizado que estará disponible independientemente de la página de códigos.

ENTORNO

ICU_DATA
Especifica el directorio que contiene los datos de ICU. Por defecto es ${prefix}/share/icu/78.1/. Algunas herramientas en ICU dependen de la presencia de la barra inclinada final. Por lo tanto, es importante asegurarse de que esté presente si se establece ICU_DATA.
