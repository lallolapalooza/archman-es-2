gensio_err(3) Manual de funciones de la biblioteca gensio_err(3)

NOMBRE

gensio_err - Valores de reporte de errores para funciones de gensio

SINOPSIS

#include <gensio/gensio_err.h>
const char *gensio_err_to_str(int err)

DESCRIPCIÓN

Los valores de retorno de las funciones de gensio que devuelven errores y los valores reportados en las devoluciones de llamada de la biblioteca gensio son todos errores de gensio. Los valores posibles son:

GE_NOERR Sin error
GE_NOMEM Sin memoria
GE_NOTSUP Operación no soportada
GE_INVAL Dato inválido en el parámetro
GE_NOTFOUND Valor o archivo no encontrado
GE_EXISTS Valor ya existente
GE_OUTOFRANGE Valor fuera de rango
GE_INCONSISTENT Parámetros inconsistentes en la llamada
GE_NODATA No había datos disponibles para la función
GE_OSERR Error del SO, consulte los registros
GE_INUSE Objeto ya en uso
GE_INPROGRESS Operación en curso
GE_NOTREADY Objeto no listo para la operación
GE_TOOBIG Valor demasiado grande para los datos
GE_TIMEDOUT La operación expiró
GE_RETRY Reintentar la operación más tarde
GE_KEYNOTFOUND No se pudo encontrar la clave dada
GE_CERTREVOKED La clave fue revocada
GE_CERTEXPIRED La clave expiró
GE_KEYINVALID La clave no es válida
GE_NOCERT No se proporcionó certificado
GE_CERTINVALID El certificado no es válido
GE_PROTOERR Error de protocolo
GE_COMMERR Error de comunicación
GE_IOERR Error interno de E/S
GE_REMCLOSE El extremo remoto cerró la conexión
GE_HOSTDOWN No se pudo contactar el host
GE_CONNREFUSE Conexión rechazada
GE_DATAMISSING Faltaban datos
GE_CERTNOTFOUND No se pudo encontrar el certificado dado
GE_AUTHREJECT Tokens de autenticación rechazados
GE_ADDRINUSE Dirección ya en uso
GE_INTERRUPTED La operación fue interrumpida por una señal
GE_SHUTDOWN Operación en un descriptor de archivo de apagado
GE_LOCALCLOSED El lado local cerró la conexión
GE_PERM Permiso denegado
GE_APPERR Error de aplicación
GE_UNKNOWN_NAME_ERROR Error desconocido de consulta del servidor de nombres
GE_NAME_ERROR No se pudo encontrar un nombre válido en el servidor de nombres
GE_NAME_SERVER_FAILURE Fallo grave del servidor de nombres
GE_NAME_INVALID Información de servidor de nombres inválida
GE_NAME_NET_NOT_UP La dirección de red para el nombre dado no está disponible

gensio_err_to_str convierte un valor de error entero a la cadena dada.

VER TAMBIÉN

gensio(5), gensio_err(3), gensio_log(3)
