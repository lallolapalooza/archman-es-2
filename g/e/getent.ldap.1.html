NOMBRE

getent.ldap - consultar información de LDAP

SINOPSIS


getent.ldap
[opciones] [BASE_DE_DATOS] [CLAVE...]

DESCRIPCIÓN

El comando getent.ldap se puede usar para buscar o enumerar información de LDAP. A diferencia del comando getent(1), este comando ignora completamente las búsquedas configuradas en /etc/nsswitch.conf y consulta directamente al demonio nslcd(8).

getent.ldap intenta igualar el comportamiento y la salida de getent y el formato de los archivos planos correspondientes tanto como sea posible, sin embargo, existen varias diferencias. Si se encuentran múltiples entradas en LDAP que coinciden con una consulta específica, se imprimen múltiples valores (por ejemplo, direcciones de ethernet que tienen varios nombres, servicios que soportan múltiples protocolos, etc.). Además, algunas bases de datos tienen opciones adicionales como se describe a continuación.

OPCIONES

Las opciones que se pueden especificar al comando getent.ldap son:

-h, --help
Muestra una breve ayuda y sale.
-V, --version
Muestra información de la versión y sale.

BASES DE DATOS

El argumento BASE_DE_DATOS puede ser cualquiera de las bases de datos compatibles a continuación:

aliases
Lista o consulta alias de correo electrónico. Si se proporciona CLAVE, busca el alias por nombre, de lo contrario, devuelve todos los alias de LDAP.
ethers
Lista o consulta direcciones de ethernet. Si CLAVE coincide con el formato de una dirección de ethernet, se realiza una búsqueda por dirección, de lo contrario, se realiza una búsqueda por nombre o se devuelven todas las entradas si se omite CLAVE. A diferencia de getent, getent.ldapd soporta la enumeración de todas las direcciones de ethernet.
group
Lista o consulta grupos. Si CLAVE es numérica, busca el grupo por su ID.
group.bymember
La CLAVE es un nombre de usuario y se devuelven los grupos de los que este usuario es miembro. El formato es similar a la salida de group, pero los miembros del grupo se omiten por razones de rendimiento.
hosts
Lista o busca nombres y direcciones de host por nombre de host, dirección IPv4 o IPv6. Devuelve direcciones IPv4 e IPv6 (si están disponibles).
hostsv4
Similar a hosts, pero las direcciones IPv6 proporcionadas se tratan como nombres de host y solo se devuelven las direcciones IPv4.
hostsv6
Similar a hosts, pero CLAVE se trata como una dirección IPv6 o un nombre de host y solo se devuelven las direcciones IPv6.
netgroup
Lista o consulta grupos de red (netgroups) y triples de grupos de red (host, usuario, dominio) que son miembros del netgroup. A diferencia de getent, getent.ldapd soporta la enumeración de todas las direcciones de ethernet.
netgroup.norec
Similar a netgroup excepto que no se realizan búsquedas posteriores para expandir netgroups que son miembros del netgroup proporcionado, y la salida puede contener tanto otros nombres de netgroup como triples de netgroup.
networks
Lista o consulta nombres y direcciones de red. CLAVE puede ser un nombre o una dirección de red. Este mapa puede devolver direcciones de red IPv4 e IPv6.
networksv4
Devuelve solo direcciones de red IPv4.
networksv6
Devuelve solo direcciones de red IPv6.
passwd
Enumera o busca la base de datos de cuentas de usuario. CLAVE puede ser un nombre de usuario o un ID numérico de usuario, u omitirse para listar todos los usuarios.
protocols
Enumera la base de datos de protocolos de Internet.
rpc
Lista o busca nombres legibles por el usuario que se mapean a números de programa RPC. La búsqueda por CLAVE se puede realizar por nombre o número de programa RPC.
services
Lista o busca el mapeo entre nombres de servicios de Internet y sus correspondientes números de puerto y tipos de protocolo. La CLAVE puede ser un nombre de servicio o un número, seguido opcionalmente por una barra y un nombre de protocolo para restringir la búsqueda solo a las entradas para el protocolo especificado.
shadow
Enumera o busca información extendida de cuentas de usuario. Tenga en cuenta que la información de sombra probablemente solo se expone al usuario root y, por defecto, nslcd no expone hashes de contraseña, incluso al root.

VER TAMBIÉN

getent(1), nslcd(8)

ERRORES

Actualmente, getent.ldapd no establece correctamente un código de salida. Debería devolver el mismo tipo de códigos de salida que getent (por ejemplo, para entradas que faltan).
