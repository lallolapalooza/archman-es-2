DESCRIPCIÓ

N

ESTÁNDARES.

utmpname() establece la ruta de acceso del archivo en formato utmp para que las otras funciones utmp accedan a él. Si utmpname() no se usa para establecer la ruta de acceso antes de que se usen las otras funciones, estas asumen _PATH_UTMP, tal como está definido en <paths.h>

.

setutent() rebobina el puntero de archivo al principio del archivo utmp. Generalmente es una buena idea llamarla antes que a cualquiera de las otras

funciones.

endutent() cierra el archivo utmp. Debería llamarse cuando el código del usuario ha terminado de acceder al archivo con las otras

funciones.

getutent() lee una línea desde la posición actual del archivo en el archivo utmp. Devuelve un puntero a una estructura que contiene los campos de la línea. La definición de esta estructura se muestra en utmp(

5).

getutid() busca hacia adelante desde la posición actual del archivo en el archivo utmp basándose en ut. Si ut->ut_type es uno de RUN_LVL, BOOT_TIME, NEW_TIME, o OLD_TIME, getutid() encontrará la primera entrada cuyo campo ut_type coincida con ut->ut_type. Si ut->ut_type es uno de INIT_PROCESS, LOGIN_PROCESS, USER_PROCESS, o DEAD_PROCESS, getutid() encontrará la primera entrada cuyo campo ut_id coincida con ut->ut_

id.

getutline() busca hacia adelante desde la posición actual del archivo en el archivo utmp. Escanea entradas cuyo ut_type sea USER_PROCESS o LOGIN_PROCESS y devuelve la primera cuyo campo ut_line coincida con ut->ut_l

ine.

pututline() escribe la estructura utmp ut en el archivo utmp. Usa getutid() para buscar el lugar adecuado en el archivo donde insertar la nueva entrada. Si no puede encontrar un espacio apropiado para ut, pututline() añadirá la nueva en

trada al final
del archivo.

VALOR

DEVUELTO

getutent(), getutid(), y getutline() devuelven un puntero a un struct utmp en caso de éxito, y NULL en caso de fallo (lo cual incluye el caso de "registro no encontrado"). Este struct utmp está asignado en almacenamiento estático, y puede ser sobrescrito por llamadas

posteriores.

En caso de éxito pututline() devuelve ut; en caso de fallo, devuelve

NULL.

utmpname() devuelve 0 si el nuevo nombre fue almacenado con éxito, o -1 en caso de

fallo.

En caso de fallo, estas funciones establecen errno para indic

ar el
error.

HISTORI

A

XPG2,

SVr4.

En XPG2 y SVID 2 la función pututline() está documentada para devolver void, y eso es lo que hace en muchos sistemas (AIX, HP-UX). HP-UX introduce una nueva función _pututline() con el prototipo dado arriba para pututlin

e().

Todas estas funciones están obsoletas ahora en sistemas que no son Linux. POSIX.1-2001 y POSIX.1-2008, siguiendo a SUSv1, no tienen ninguna de estas funciones, sino que

usan

En algunos otros sistemas, la estructura utmpx es un superconjunto de la estructura utmp, con campos adicionales, y versiones más grandes de los campos existentes, y se mantienen archivos paralelos, a menudo /var/*/utmpx y /var/*/wtmpx

Linux glibc por otro lado no usa un archivo utmpx paralelo ya que su estructura utmp es ya lo suficientemente grande. Las funciones "x" listadas arriba son solo alias de sus contrapartes sin la "x" (por ejemplo, getutxent() es un alias para getute

Estas funciones son extensiones de GNU, análogas de las funciones con el mismo nombre sin el sufijo _r. El argumento ubuf da a estas funciones un lugar donde almacenar su resultado. En caso de éxito, devuelven 0, y se escribe un puntero al resultado en*ubufp. En caso de error, estas funciones devuelven -1. No existen equivalentes utmpx para las funciones anteriores. EJEMPLOS

El siguiente ejemplo agrega y elimina un registro utmp, asumiendo que se ejecuta desde dentro de una terminal pseudo. Para su uso en una aplicación real, debería comprobar los valores de retorno de getpwuid(3) y ttyname(3).

#include <err.h>
#include <pwd.h>
#include <stdlib.h>
#include <string.h>
#include <time.h>
#include <unistd.h>
#include <utmp.h>
int
main(void)
{
    struct utmp entry;
    if (system("echo antes de agregar entrada:;who") == -1)
        err(EXIT_FAILURE, "system");
    entry.ut_type = USER_PROCESS;
    entry.ut_pid = getpid();
    strcpy(entry.ut_line, ttyname(STDIN_FILENO) + strlen("/dev/"));
    /* solo correcto para ptys nombrados /dev/tty[pqr][0-9a-z] */
    strcpy(entry.ut_id, ttyname(STDIN_FILENO) + strlen("/dev/tty"));
    entry.ut_time = time(NULL);
    strcpy(entry.ut_user, getpwuid(getuid())->pw_name);
    memset(entry.ut_host, 0, UT_HOSTSIZE);
    entry.ut_addr = 0;
    setutent();
    if (pututline(&entry) == NULL)
        err(EXIT_FAILURE, "pututline");
    if (system("echo despues de agregar entrada:;who") == -1)
        err(EXIT_FAILURE, "system");
    entry.ut_type = DEAD_PROCESS;
    memset(entry.ut_line, 0, UT_LINESIZE);
    entry.ut_time = 0;
    memset(entry.ut_user, 0, UT_NAMESIZE);
    setutent();
    if (pututline(&entry) == NULL)
        err(EXIT_FAILURE, "pututline");
    if (system("echo despues de eliminar entrada:;who") == -1)
        err(EXIT_FAILURE, "system");
    endutent();
    exit(EXIT_SUCCESS);
}
