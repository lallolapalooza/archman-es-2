gensio_set_read_callback_enable(3)

Paquete: gensio

Licencias: GPL

gensio_set_read_callback_enable(3) Manual de funciones de biblioteca gensio_set_read_callback_enable(3)

NOMBRE

gensio_set_read_callback_enable, gensio_set_write_callback_enable - Habilitar o deshabilitar la lectura de datos y la preparación para escritura

SINOPSIS

#include <gensio/gensio.h>

void gensio_set_read_callback_enable(struct gensio *io,

bool enabled);
void gensio_set_write_callback_enable(struct gensio *io,

bool enabled);

DESCRIPCIÓN

Estas funciones habilitan la devolución de llamada de escritura o la devolución de llamada de lectura para los gensios (y todos los gensios hijos). Generalmente, deshabilitar la devolución de llamada de lectura deshabilitará todas las devoluciones de llamada excepto la de escritura, ya que no recibirá datos para realizar ningún procesamiento.

Después de abrir un gensio o recibir un gensio de un aceptador, el gensio tiene todas las habilitaciones establecidas en falso. Generalmente, querrá habilitar la devolución de llamada de lectura y mantenerla habilitada tanto como sea posible para que el procesamiento de bajo nivel se realice en el gensio. En particular, deshabilitar la lectura en un gensio UDP deshabilitará todo el procesamiento de lectura y aceptación.

Habilitar la devolución de llamada de escritura habilitará la devolución de llamada para indicarle si el gensio puede escribir datos en este momento. Normalmente, querrá dejarla deshabilitada y habilitarla si escribe datos y obtiene una escritura parcial. O mejor aún, cuando tenga datos para escribir, habilite la devolución de llamada de escritura y escriba los datos desde la devolución de llamada, deshabilitándola cuando esté todo escrito.

Deshabilitar la devolución de llamada de escritura no necesariamente impide que los datos sean transmitidos por el gensio. El gensio SSL, por ejemplo, puede transmitir información de clave en una renegociación, u otros gensios pueden transmitir información de control de flujo. Esto solo afecta a la devolución de llamada de escritura.

Deshabilitar las devoluciones de llamada puede que no sea inmediato. "Inmediato" es difícil de definir en un sistema SMP, de todos modos. Puede haber devoluciones de llamada en ejecución o a punto de ser llamadas cuando deshabilite la devolución de llamada, aún pueden ejecutarse. Debe estar preparado para manejar estas condiciones de carrera.

VALORES DE RETORNO

Se devuelve cero si la operación es exitosa, o un error de gensio si falla.
