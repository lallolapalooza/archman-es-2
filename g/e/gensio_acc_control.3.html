NOMBRE

gensio_acc_control - Realizar acciones específicas del aceptador de gensio

SINOPSIS

#include <gensio/gensio.h>

int gensio_acc_control(struct gensio_accepter *acc, int depth,

bool get, unsigned int option,
char *data, gensiods *datalen);

DESCRIPCIÓN

gensio_acc_control realiza una operación específica del aceptador de gensio en el aceptador de gensio. Funciona exactamente igual que gensio_control(3), consulta esa página para obtener detalles sobre get, depth y cómo funcionan data y datalen.

Las operaciones de control de gensio en option dependen del gensio particular. A continuación se documentan algunas, pero pueden haber otros controles disponibles. Consulte la documentación de gensio en gensio(5) para obtener detalles.

GENSIO_ACC_CONTROL_LADDR

Devuelve la dirección local dada para el gensio dado. Dado que un solo gensio puede tener más de una dirección local, este control proporciona un medio para saber cuál. El string data pasado debe ser la representación en string del número (como se creó con snprintf()) para el índice particular que desea obtener. Si especifica un número mayor que el número de sockets de escucha abiertos, se devuelve GE_NOTFOUND. Los datos devueltos son un string que contiene la dirección.

Tenga en cuenta que un solo string recuperado puede contener más de una dirección. Estas estarán separadas por punto y coma. En algunos casos, las direcciones pueden cambiar dinámicamente (como con SCTP), por lo que se obtiene un único conjunto de direcciones.

GENSIO_ACC_CONTROL_LPORT

Devuelve el puerto para la dirección local dada para el gensio dado. Dado que un solo gensio puede tener más de una dirección local, este control proporciona un medio para saber cuál. El string data pasado debe ser la representación en string del número (como se creó con snprintf()) para el índice particular que desea obtener. Si especifica un número mayor que el número de sockets de escucha abiertos, se devuelve GE_NOTFOUND. Los datos devueltos son un string que contiene el número de puerto.

GENSIO_ACC_CONTROL_TCPDNAME

Obtener o establecer el nombre TCPD para el gensio, solo para gensios TCP.

VALORES DEVUELTOS

Se devuelve cero si la operación fue exitosa, o un error de gensio en caso de fallo.

VER TAMBIÉN

gensio_err(3), gensio(5), gensio_control(3)
