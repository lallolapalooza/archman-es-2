NOMBRE

gensprep - compila datos de StringPrep desde archivos filtrados por filterRFC3454.pl

SINOPSIS

gensprep [ -h, -?, --help ] [ -v, --verbose ] [ -c, --copyright ] [ -s, --sourcedir origen ] [ -d, --destdir destino ]

DESCRIPCIÓN

gensprep lee archivos RFC 3454 filtrados y compila su información en un formato binario. El archivo resultante, <nombre>.icu, puede luego ser leído directamente por ICU, o utilizado por pkgdata(8) para su incorporación a un archivo o biblioteca más grande.

Los archivos leídos por gensprep se describen en la sección ARCHIVOS.

OPCIONES

-h, -?, --help
Imprime ayuda sobre el uso y sale.
-v, --verbose
Muestra mensajes informativos adicionales durante la ejecución.
-c, --copyright
Incluye un aviso de copyright en los datos binarios.
-s, --sourcedir origen
Establece el directorio de origen a origen. El directorio de origen predeterminado es especificado por la variable de entorno ICU_DATA.
-d, --destdir destino
Establece el directorio de destino a destino. El directorio de destino predeterminado es especificado por la variable de entorno ICU_DATA.

ENTORNO

ICU_DATA
Especifica el directorio que contiene los datos de ICU. El valor predeterminado es ${prefix}/share/icu/78.1/. Algunas herramientas en ICU dependen de la presencia de la barra inclinada final. Por lo tanto, es importante asegurarse de que esté presente si se establece ICU_DATA.

ARCHIVOS

Los siguientes archivos son leídos por gensprep y se buscan en el directorio origen /misc para los archivos rfc3454_*.txt y en origen /unidata para NormalizationCorrections.txt.

rfc3453_A_1.txt
Contiene la lista de puntos de código no asignados en la versión Unicode 3.2.0....
rfc3454_B_1.txt
Contiene la lista de puntos de código que comúnmente se mapean a nada....
rfc3454_B_2.txt
Contiene la lista de mapeos para la corrección de mayúsculas/minúsculas de puntos de código cuando se especifica la forma de normalización NFKC....
rfc3454_C_X.txt
Contiene la lista de puntos de código que están prohibidos para IDNA.
NormalizationCorrections.txt
Contiene la lista de puntos de código cuya normalización ha cambiado desde la versión Unicode 3.2.0.
