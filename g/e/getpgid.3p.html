PROLOG

Esta página del manual forma parte del Manual del Programador de POSIX. La implementación de Linux de esta interfaz puede diferir (consulte la página del manual de Linux correspondiente para conocer los detalles del comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

getpgid — obtener el ID del grupo de procesos de un proceso

SINOPSIS

#include <unistd.h>
pid_t getpgid(pid_t pid);

DESCRIPCIÓN

La función getpgid() devolverá el ID del grupo de procesos del proceso cuyo ID de proceso sea igual a pid. Si pid es igual a 0, getpgid() devolverá el ID del grupo de procesos del proceso llamante.

VALOR DE RETORNO

Al completarse con éxito, getpgid() devolverá un ID de grupo de procesos. De lo contrario, devolverá (pid_t)-1 y establecerá errno para indicar el error.

ERRORES

La función getpgid() fallará si:

EPERM
El proceso cuyo ID de proceso es igual a pid no está en la misma sesión que el proceso llamante, y la implementación no permite el acceso al ID del grupo de procesos de ese proceso desde el proceso llamante.
ESRCH
No existe ningún proceso con un ID de proceso igual a pid.

La función getpgid() puede fallar si:

EINVAL
El valor del argumento pid no es válido.
