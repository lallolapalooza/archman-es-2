gearman_client_remove_servers(3)

Paquete: gearmand

Licencias: BSD-3-Clause

GEARMAN_CLIENT_REMOVE_SERVERS(3) Gearmand GEARMAN_CLIENT_REMOVE_SERVERS(3)

NOMBRE

gearman_client_remove_servers - Documentación de Gearmand, https://gearman.org/gearmand/

SINOPSIS

#include <libgearman/gearman.h>

gearman_return_t gearman_client_add_server(gearman_client_st *client, const char *host, in_port_t port)
gearman_return_t gearman_client_add_servers(gearman_client_st *client, const char *servers)
void gearman_client_remove_servers(gearman_client_st *client)

DESCRIPCIÓN

gearman_client_add_server() agregará un servidor gearmand adicional a la lista de servidores de los cuales el cliente tomará trabajo.

gearman_client_remove_servers() eliminará todos los servidores del gearman_client_st.

gearman_client_add_servers() toma una lista de servidores gearmand que se analizará para proporcionar servidores al cliente. El formato para esto es SERVIDOR[:PUERTO][,SERVIDOR[:PUERTO]]...

Ejemplos de esto son::
10.0.0.1,10.0.0.2,10.0.0.3 localhost234,jobserver2.domain.com:7003,10.0.0.3

VALOR DE RETORNO

gearman_client_add_server() y gearman_client_remove_servers() devuelven gearman_return_t.

INICIO

Para obtener más información, consulte: https://gearman.org/gearmand/
