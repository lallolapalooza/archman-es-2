getservent_r(3) Manual de Funciones de Biblioteca getservent_r(3)

NOMBRE

getservent_r, getservbyname_r, getservbyport_r - obtener entrada de servicio (reentrante)

BIBLIOTECA

Biblioteca C estándar (libc,-lc)

SINOPSIS

#include <netdb.h>
int getservent_r(size_t size;
                 struct servent *restrict result_buf,
                 char buf[restrict size], size_t size,
                 struct servent **restrict result);
int getservbyname_r(size_t size;
                 const char *restrict name,
                 const char *restrict proto,
                 struct servent *restrict result_buf,
                 char buf[restrict size], size_t size,
                 struct servent **restrict result);
int getservbyport_r(size_t size;
                 int port,
                 const char *restrict proto,
                 struct servent *restrict result_buf,
                 char buf[restrict size], size_t size,
                 struct servent **restrict result);
Requisitos de la macro de prueba de características para glibc (ver feature_test_macros(7)):

getservent_r(), getservbyname_r(), getservbyport_r():

    Desde glibc 2.19:
        _DEFAULT_SOURCE
    glibc 2.19 y anteriores:
        _BSD_SOURCE || _SVID_SOURCE

DESCRIPCIÓN

Las funciones getservent_r(), getservbyname_r(), y getservbyport_r() son los equivalentes reentrantes de, respectivamente, getservent(3), getservbyname(3), y getservbyport(3). Difieren en la forma en que se devuelve la estructura servent , y en la firma de llamada de la función y el valor de retorno. Esta página de manual describe solo las diferencias con las funciones no reentrantes.

En lugar de devolver un puntero a una estructura servent asignada estáticamente como resultado de la función, estas funciones copian la estructura en la ubicación apuntada por result_buf.

El buf El array se usa para almacenar los campos de cadena apuntados por la estructura servent devuelta. (Las funciones no reentrantes asignan estas cadenas en almacenamiento estático.) El tamaño de este array se especifica en size. Si buf es demasiado pequeño, la llamada falla con el error ERANGE, y el llamador debe intentarlo de nuevo con un búfer más grande. (Un búfer de tamaño 1024 bytes debería ser suficiente para la mayoría de aplicaciones.)

Si la llamada a la función obtiene con éxito un registro de servicio, entonces *result se establece apuntando a result_buf; de lo contrario, *result se establece en NULL.

VALOR DE RETORNO

En caso de éxito, estas funciones devuelven 0. En caso de error, devuelven uno de los números de error positivos listados en errores.

En caso de error, registro no encontrado (getservbyname_r(), getservbyport_r()), o fin de la entrada (getservent_r()) result se establece en NULL.

ERRORES

ENOENT
(getservent_r()) No hay más registros en la base de datos.
ERANGE
buf es demasiado pequeño. Inténtelo de nuevo con un búfer más grande (y sizeaumentado).

ATRIBUTOS

Para una explicación de los términos utilizados en esta sección, ver attributes(7).

VERSIONES

Existen funciones con nombres similares en algunos otros sistemas, aunque típicamente con firmas de llamada diferentes.

ESTÁNDARES

GNU.

EJEMPLOS

El programa de abajo usa getservbyport_r() para recuperar el registro de servicio para el puerto y protocolo nombrados en su primer argumento de línea de comandos. Si se proporciona un tercer argumento de línea de comandos (entero), se usa como el valor inicial para size; si getservbyport_r() falla con el error ERANGE, el programa reintenta con tamaños de búfer más grandes. La siguiente sesión de shell muestra un par de ejecuciones de ejemplo:


$ ./a.out 7 tcp 1
¡ERANGE! Reintentando con búfer más grande
getservbyport_r() devolvió: 0 (éxito)  (size=87)
s_name=echo; s_proto=tcp; s_port=7; aliases=
$ ./a.out 77777 tcp
getservbyport_r() devolvió: 0 (éxito)  (size=1024)
Llamada fallida/registro no encontrado

Programa fuente

#define _GNU_SOURCE
#include <ctype.h>
#include <errno.h>
#include <netdb.h>
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#define MAX_BUF 10000
int
main(int argc, char *argv[])
{
    int size, erange_cnt, port, s;
    struct servent result_buf;
    struct servent *result;
    char buf[MAX_BUF];
    char *protop;
    if (argc < 3) {
        printf("Uso: %s num-puerto nombre-proto [size]\n", argv[0]);
        exit(EXIT_FAILURE);
    }
    port = htons(atoi(argv[1]));
    protop = (strcmp(argv[2], "null") == 0 ||
              strcmp(argv[2], "NULL") == 0) ?  NULL : argv[2];
    size = 1024;
    if (argc > 3)
        size = atoi(argv[3]);
    if (size > MAX_BUF) {
        printf("Límite de búfer excedido (%d)\n", MAX_BUF);
        exit(EXIT_FAILURE);
    }
    erange_cnt = 0;
    do {
        s = getservbyport_r(port, protop, &result_buf,
                            buf, size, &result);
        if (s == ERANGE) {
            if (erange_cnt == 0)
                printf("¡ERANGE! Reintentando con búfer más grande\n");
            erange_cnt++;
            /* Incrementar un byte a la vez para poder ver exactamente
               qué tamaño de búfer se requirió.  */
            size++;
            if (size > MAX_BUF) {
                printf("Límite de búfer excedido (%d)\n", MAX_BUF);
                exit(EXIT_FAILURE);
            }
        }
    } while (s == ERANGE);
    printf("getservbyport_r() devolvió: %s  (size=%d)\n",
           (s == 0) ? "0 (éxito)" : (s == ENOENT) ? "ENOENT" :
           strerror(s), size);
    if (s != 0 || result == NULL) {
        printf("Llamada fallida/registro no encontrado\n");
        exit(EXIT_FAILURE);
    }
    printf("s_name=%s; s_proto=%s; s_port=%d; aliases=",
           result_buf.s_name, result_buf.s_proto,
           ntohs(result_buf.s_port));
    for (char **p = result_buf.s_aliases; *p != NULL; p++)
        printf("%s ", *p);
    printf("\n");
    exit(EXIT_SUCCESS);
}
