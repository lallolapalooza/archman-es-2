DESCRIPCIÓN

Callbacks para estados de tareas de ejecución del cliente.

gearman_client_set_data_fn() establece la función de callback que se llamará si el servidor necesita solicitar datos adicionales al cliente.

gearman_client_do_job_handle() obtiene el manejador de trabajo para la tarea en ejecución. Esto debe usarse entre llamadas repetidas a gearman_client_do() (y relacionadas) para obtener información.

gearman_client_clear_fn() se puede llamar para eliminar todas las gearman_actions_t existentes que se hayan establecido.

gearman_client_set_created_fn(), gearman_client_set_data_fn(), gearman_client_set_warning_fn(), gearman_client_set_status_fn(), gearman_client_set_complete_fn(), gearman_client_set_exception_fn() y gearman_client_set_fail_fn(), establecen funciones de callback para los diferentes estados de ejecución de una solicitud del cliente. Cada solicitud, es decir, la creación de gearman_task_st, conserva una copia de los callbacks cuando se crea.

gearman_client_set_exception_fn() solo se llamará si las excepciones están habilitadas en el servidor. Puede hacer esto llamando a gearman_client_set_server_option().

Un ejemplo de esto:

const char *EXCEPCIONES="excepciones";
gearman_client_set_server_option(cliente, EXCEPCIONES, strlen(EXCEPCIONES));
