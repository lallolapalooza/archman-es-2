GETPWNAM(3P) Manual del Programador POSIX GETPWNAM(3P)

PRÓLOGO

Esta página del manual forma parte del Manual del Programador POSIX. La implementación de Linux de esta interfaz puede diferir (consulte la página del manual de Linux correspondiente para detalles del comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

getpwnam, getpwnam_r — buscar en la base de datos de usuarios un nombre

SINOPSIS

#include <pwd.h>
struct passwd *getpwnam(const char *name);
int getpwnam_r(const char *name, struct passwd *pwd, char *buffer,
    size_t bufsize, struct passwd **result);

DESCRIPCIÓN

La getpwnam() función buscará en la base de datos de usuarios una entrada con un namecoincidente.

La getpwnam() función no necesita ser segura para hilos.

Las aplicaciones que deseen comprobar situaciones de error deben establecer errno a 0 antes de llamar a getpwnam(). Si getpwnam() devuelve un puntero nulo y errno es distinto de cero, ocurrió un error.

La getpwnam_r() función actualizará la estructura passwd apuntada por pwd y almacenará un puntero a esa estructura en la ubicación apuntada por result. La estructura contendrá una entrada de la base de datos de usuarios con un namecoincidente. El almacenamiento referenciado por la estructura se asigna de la memoria proporcionada con el parámetro buffer , que tiene un tamaño de bufsize bytes. Una llamada a sysconf(_SC_GETPW_R_SIZE_MAX) devuelve -1 sin cambiar errno o un valor inicial sugerido para el tamaño de este búfer. Se devolverá un puntero nulo en la ubicación apuntada por result en caso de error o si la entrada solicitada no se encuentra.

VALOR DE RETORNO

La getpwnam() función devolverá un puntero a un struct passwd con la estructura tal como está definida en <pwd.h> con una entrada coincidente si se encuentra. Se devolverá un puntero nulo si la entrada solicitada no se encuentra, o si ocurre un error. Si la entrada solicitada no fue encontrada, errno no será modificado. En caso de error, errno será establecido para indicar el error.

La aplicación no debe modificar la estructura a la que apunta el valor de retorno, ni ninguna de las áreas de almacenamiento apuntadas por punteros dentro de la estructura. El puntero devuelto, y los punteros dentro de la estructura, podrían ser invalidados o la estructura o las áreas de almacenamiento podrían ser sobrescritas por una llamada posterior a getpwent(), getpwnam(), o getpwuid(). El puntero devuelto, y los punteros dentro de la estructura, también podrían ser invalidados si el hilo que llama es terminado.

La getpwnam_r() función devolverá cero en caso de éxito o si la entrada solicitada no fue encontrada y no ha ocurrido ningún error. Si ha ocurrido un error, se devolverá un número de error para indicar el error.

ERRORES

Estas funciones pueden fallar si:

EIO
Ha ocurrido un error de E/S.
EINTR
Una señal fue capturada durante getpwnam().
EMFILE
Todos los descriptores de archivo disponibles para el proceso están actualmente abiertos.
ENFILE
El número máximo de archivos permitidos está actualmente abierto en el sistema.

La getpwnam_r() función puede fallar si:

ERANGE
Se proporcionó almacenamiento insuficiente a través de buffer y bufsize para contener los datos a ser referenciados por la estructura passwd resultante.

Las siguientes secciones son informativas.

EJEMPLOS

Tenga en cuenta que sysconf(_SC_GETPW_R_SIZE_MAX) puede devolver -1 si no hay un límite duro en el tamaño del búfer necesario para almacenar todos los grupos devueltos. Este ejemplo muestra cómo una aplicación puede asignar un búfer de tamaño suficiente para trabajar con getpwnam_r().

long int initlen = sysconf(_SC_GETPW_R_SIZE_MAX);
size_t len;
if (initlen == -1)
    /* Longitud inicial por defecto. */
    len = 1024;
else
    len = (size_t) initlen;
struct passwd result;
struct passwd *resultp;
char *buffer = malloc(len);
if (buffer == NULL)
    ...manejar error...
int e;
while ((e = getpwnam_r("someuser", &result, buffer, len, &resultp))
        == ERANGE)
    {
    size_t newlen = 2 * len;
    if (newlen < len)
        ...manejar error...
    len = newlen;
    char *newbuffer = realloc(buffer, len);
    if (newbuffer == NULL)
        ...manejar error...
    buffer = newbuffer;
    }
if (e != 0)
    ...manejar error...
free (buffer);

Obteniendo una Entrada para el Nombre de Inicio de Sesión

El siguiente ejemplo usa la getlogin() función para devolver el nombre del usuario que inició sesión; esta información se pasa a la getpwnam() función para obtener la entrada de la base de datos de usuarios para ese usuario.

#include <sys/types.h>
#include <pwd.h>
#include <unistd.h>
#include <stdio.h>
#include <stdlib.h>
...
char *lgn;
struct passwd *pw;
...
if ((lgn = getlogin()) == NULL || (pw = getpwnam(lgn)) == NULL) {
    fprintf(stderr, "Get of user information failed.\n"); exit(1);
}
...

USO EN APLICACIONES

Se pueden determinar tres nombres asociados con el proceso actual: getpwuid(geteuid()) devuelve el nombre asociado con el ID de usuario efectivo del proceso; getlogin() devuelve el nombre asociado con la actividad de inicio de sesión actual; y getpwuid(getuid()) devuelve el nombre asociado con el ID de usuario real del proceso.

La getpwnam_r() función es segura para hilos y devuelve valores en un búfer proporcionado por el usuario en lugar de posiblemente usar un área de datos estática que puede ser sobrescrita por cada llamada.

Las aplicaciones portables deben tener en cuenta que es usual para una implementación devolver -1 desde sysconf() indicando que no hay un máximo para _SC_GETPW_R_SIZE_MAX.
