gettid(2) Manual de llamadas al sistema gettid(2)

NOMBRE

gettid - obtener identificación de hilo

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#define _GNU_SOURCE
#include <unistd.h>
pid_t gettid(void);

DESCRIPCIÓN

gettid() devuelve el ID del hilo (TID) del llamador. En un proceso de un solo hilo, el ID del hilo es igual al ID del proceso (PID, tal como lo devuelve getpid(2)). En un proceso multihilo, todos los hilos tienen el mismo PID, pero cada uno tiene un TID único. Para más detalles, ver la discusión de CLONE_THREAD en clone(2).

VALOR DE RETORNO

En caso de éxito, devuelve el ID del hilo del hilo llamador.

ERRORES

Esta llamada siempre tiene éxito.

ESTÁNDARES

Linux.

HISTORIAL

Linux 2.4.11, glibc 2.30.

NOTAS

El ID del hilo devuelto por esta llamada no es lo mismo que un ID de hilo POSIX (es decir, el valor opaco devuelto por pthread_self(3)).

En un nuevo grupo de hilos creado por una llamada a clone(2) que no especifica la bandera CLONE_THREAD (o, equivalentemente, un nuevo proceso creado por fork(2)), el nuevo proceso es un líder de grupo de hilos, y su ID de grupo de hilos (el valor devuelto por getpid(2)) es el mismo que su ID de hilo (el valor devuelto por gettid()).
