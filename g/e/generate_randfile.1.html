generate_randfile(1) Manual de Comandos Generales generate_randfile(1)

NOMBRE

generate_randfile - un programa para generar un archivo de datos aleatorios

SINOPSIS

generate_randfile [ -s semilla] [ -f archivo] cantidad

DESCRIPCIÓN

Produce un archivo compuesto por enteros aleatorios en orden de bytes de red de la llamada a la biblioteca rand(3).

OPCIONES

-s
la semilla a utilizar para crear los números aleatorios.
-f
el archivo a crear para escribir la salida (por defecto se utiliza la salida estándar).
cantidad
el número de enteros a escribir.

VER TAMBIÉN

rand(3)

AUTOR
