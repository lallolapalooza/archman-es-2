GETHOSTIP(1) Manual de Comandos Generales GETHOSTIP(1)

NOMBRE

gethostip — convierte una dirección IP a varios formatos

SINOPSIS

gethostip [-dxnf] [NOMBREHOST|IP]

DESCRIPCIÓN

Esta página del manual documenta brevemente el comando gethostip.

La utilidad gethostip convierte el nombre de host o la dirección IP dados en varios formatos. Es proporcionada por el paquete syslinux para facilitar el cálculo de los nombres apropiados para los archivos de configuración de pxelinux. Estos nombres de archivo pueden ser la representación hexadecimal completa de una dirección IP dada, o una representación hexadecimal parcial para que coincida con un rango de direcciones IP.

OPCIONES

A continuación se incluye un resumen de las opciones.

-d
Muestra la dirección IP en formato decimal.
-x
Muestra la dirección IP en formato hexadecimal.
-n
Muestra el nombre canónico del host.
-f
Salida completa. Muestra la dirección IP en todos los formatos soportados. Lo mismo que -xdn.

VER TAMBIÉN

syslinux(1)

Se pueden encontrar más detalles en la documentación de pxelinux, que se puede encontrar en /usr/share/doc/syslinux/pxelinux.doc.gz en los sistemas Debian GNU/Linux.
