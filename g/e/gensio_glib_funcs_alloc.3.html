NOMBRE

gensio_glib_funcs_alloc - Abstracción para algunas funciones del sistema operativo realizadas con glib

SINOPSIS

#include <gensio/gensio_glib.h>

int gensio_glib_funcs_alloc(struct gensio_os_funcs **o)

DESCRIPCIÓN

Esta estructura proporciona una abstracción para la biblioteca gensio que le permite funcionar sobre glib. Consulte la página del manual gensio_os_funcs.3 para obtener detalles sobre lo que esto hace. Esto se puede usar si tiene un proyecto basado en glib en el que desea integrar gensio.

Desafortunadamente, tiene algunas limitaciones debido a las debilidades en la interfaz de glib.

Si usa esto, realmente querrá usar las funciones de espera de gensio, no g_cont_wait..() usted mismo. No es estrictamente necesario, especialmente si su aplicación es de un solo hilo, pero especialmente en aplicaciones multihilo no puede mezclar llamadas a las funciones de espera de funciones del sistema operativo y las funciones de espera de glib. Lo que significa que no puede usar las funciones de bloqueo, que utilizan todos los receptores de espera de funciones del sistema operativo.

El rendimiento debería ser aceptable para un solo hilo. Sin embargo, para múltiples hilos, solo una cosa a la vez puede esperar en el hilo principal de glib. Esta es una debilidad en glib. Para múltiples hilos, una función se sienta en el contexto principal y las otras se sientan en variables de condición. Cuando el hilo que espera en el contexto principal se despierta, despierta a otro hilo en espera para que tome el relevo.

Si el rendimiento es importante, podría ser mejor poner glib sobre las funciones del sistema operativo de gensio con g_main_context_set_poll_func(). Dejo eso como un ejercicio para el lector.

VALORES DE RETORNO

Un gensio_err devuelve un error estándar de gensio.
