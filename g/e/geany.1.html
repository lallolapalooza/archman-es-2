NOMBRE

Geany — un IDE pequeño y ligero

SINOPSIS

geany [opción] [+número] [archivos ...]

DESCRIPCIÓN

Geany es un editor pequeño y rápido con características básicas de un entorno de desarrollo integrado.

Algunas de sus características: resaltado de sintaxis, autocompletado de código, plegado de código, listas de símbolos/etiquetas y muchos tipos de archivo soportados como C(++), Java, PHP, HTML, DocBook, Perl y más.

Página de inicio: https://www.geany.org/

OPCIONES

archivos ...
Una lista de nombres de archivo separados por espacios. Se pueden usar nombres de archivo absolutos y relativos. Geany también reconoce información de línea y columna cuando se añaden al nombre de archivo con dos puntos, por ejemplo, "geany foo.bar:10:5" abrirá el archivo foo.bar y colocará el cursor en la línea 10 en la columna 5.
También se pueden abrir proyectos, pero un archivo de proyecto (*.geany) debe ser el primer argumento que no sea una opción. Se ignorarán todos los archivos adicionales proporcionados.
+número
Establece el número de línea inicial para el primer archivo abierto (igual que --line, no pongas un espacio entre el signo + y el número). Por ejemplo, "geany +7 foo.bar" abrirá el archivo foo.bar y colocará el cursor en la línea 7.
--column
Establece el número de columna inicial para el primer archivo abierto (útil en conjunción con --line).
-c, --config
Usa un directorio de configuración alternativo. El directorio de configuración predeterminado es ~/.config/geany/ y allí se encuentra geany.conf y algunos archivos de plantilla.
--ft-names
Imprime una lista de los nombres de tipo de archivo internos de Geany (útil para la configuración de fragmentos).
-g, --generate-tags
Genera un archivo de etiquetas global (ver documentación).
-P, --no-preprocessing
No preprocesar archivos C/C++ al generar etiquetas.
-i, --new-instance
No abrir archivos en una instancia en ejecución, forzar la apertura de una nueva instancia. Solo disponible si Geany fue compilado con soporte para sockets.
-l, --line
Establece el número de línea inicial para el primer archivo abierto.
--list-documents
Devuelve una lista de documentos abiertos en una instancia de Geany en ejecución. Esto se puede usar para leer los documentos actualmente abiertos en Geany desde un script o herramienta externa. La lista devuelta está separada por saltos de línea (LF) y consta de los nombres de archivo completos, codificados en UTF-8, de los documentos. Solo disponible si Geany fue compilado con soporte para sockets.
-m, --no-msgwin
No mostrar la ventana de mensajes. Usa esta opción si no necesitas mensajes del compilador o soporte VTE.
-n, --no-ctags
No cargar datos de autocompletado de símbolos y de sugerencias de llamadas. Usa esta opción si no quieres usarlos. Para más información, consulta la documentación.
-p, --no-plugins
No cargar soporte de plugins.
--print-prefix
Imprime el prefijo de instalación, el directorio de datos, el directorio de bibliotecas y el directorio de localización (en ese orden) a la salida estándar, cada uno por línea. Esto está destinado principalmente a los autores de plugins para detectar las rutas de instalación.
-r, --read-only
Abrir todos los archivos proporcionados en la línea de comandos en modo de solo lectura. Esto solo se aplica a los archivos abiertos explícitamente desde la línea de comandos, por lo que los archivos de sesiones anteriores o archivos de proyecto no se ven afectados.
-s, --no-session
No cargar los archivos de la sesión anterior.
-t, --no-terminal
No cargar soporte de terminal. Usa esta opción si no quieres cargar el widget del emulador de terminal virtual al iniciar. Si no tienes libvte.so.4 instalado, el soporte de terminal se deshabilita automáticamente. Solo disponible si Geany fue compilado con soporte para VTE.
--socket-file
Usa este nombre de archivo de socket para la comunicación con una instancia de Geany en ejecución.
--vte-lib
Especifica explícitamente la ruta, incluido el nombre de archivo, o solo el nombre de archivo, de la biblioteca VTE, por ejemplo, /usr/lib/libvte.so o libvte.so. Esta opción solo es necesaria cuando la autodetección no funciona. Solo disponible si Geany fue compilado con soporte para VTE.
-v, --verbose
Ser verboso (imprimir mensajes de estado útiles).
-V, --version
Mostrar información de la versión y salir.
-?, --help
Mostrar información de ayuda y salir.

Geany soporta todas las opciones genéricas de GTK, una lista está disponible en la pantalla de ayuda.
