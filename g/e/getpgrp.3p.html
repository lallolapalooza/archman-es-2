PROLOG

Esta página del manual forma parte del Manual del programador POSIX. La implementación de Linux de esta interfaz puede diferir (consulte la página del manual de Linux correspondiente para conocer los detalles del comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

getpgrp — obtener el ID del grupo de procesos del proceso que llama

SINOPSIS

#include <unistd.h>
pid_t getpgrp(void);

DESCRIPCIÓN

La función getpgrp() devolverá el ID del grupo de procesos del proceso que llama.

VALOR DEVUELTO

La función getpgrp() siempre tendrá éxito y ningún valor de retorno se reserva para indicar un error.

ERRORES

No se definen errores.

Las siguientes secciones son informativas.

EJEMPLOS

Ninguno.

USO DE LA APLICACIÓN

Ninguno.

JUSTIFICACIÓN

4.3 BSD proporciona una función getpgrp() que devuelve el ID del grupo de procesos para un proceso especificado. Aunque esta función soporta el control de trabajos, todos los shells de control de trabajos conocidos especifican siempre el proceso que llama con esta función. Por lo tanto, basta con el getpgrp() más simple de System V, y la complejidad añadida del getpgrp() de 4.3 BSD se proporciona mediante la extensión XSI getpgid().
