gearman_worker_remove_servers(3)

Paquete: gearmand

Licencias: BSD-3-Clause

GEARMAN_WORKER_REMOVE_SERVERS(3) Gearmand GEARMAN_WORKER_REMOVE_SERVERS(3)

NOMBRE

Documentación de Gearmand, https://gearman.org/gearmand/

SINOPSIS

#include <libgearman/gearman.h>

gearman_return_t gearman_worker_add_server(gearman_worker_st *worker, const char *host, in_port_t port)
gearman_return_t gearman_worker_add_servers(gearman_worker_st *worker, const char *servers)
void gearman_worker_remove_servers(gearman_worker_st *worker)

Enlazar con -lgearman

DESCRIPCIÓN

gearman_worker_add_server() añadirá un servidor adicional de gearmand a la lista de servidores de los que el trabajador obtendrá trabajo.

gearman_worker_remove_servers() eliminará todos los servidores del gearman_worker_st.

gearman_worker_add_servers() toma una lista de servidores de gearmand que se analizará para proporcionar servidores al trabajador. El formato para esto es SERVIDOR[:PUERTO][,SERVIDOR[:PUERTO]]...

Ejemplos de esto son:

10.0.0.1,10.0.0.2,10.0.0.3
localhost234,jobserver2.domain.com:7003,10.0.0.3

VALOR DE RETORNO

gearman_worker_add_server() y gearman_worker_remove_servers() devuelven gearman_return_t.

INICIO

Para obtener más información, consulte: https://gearman.org/gearmand/
