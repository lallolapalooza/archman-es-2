getpw(3) Manual de funciones de biblioteca getpw(3)

NOMBRE

getpw - reconstruir entrada de línea de contraseña

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#define _GNU_SOURCE             /* Ver feature_test_macros(7) */
#include <sys/types.h>
#include <pwd.h>
[[deprecated]] int getpw(uid_t uid, char *buf);

DESCRIPCIÓN

La función getpw() reconstruye la entrada de línea de contraseña para el ID de usuario dado uid en el búfer buf. El búfer devuelto contiene una línea del formato


nombre:contraseña:uid:gid:gecos:dir:shell

La estructura passwd se define en <pwd.h> como sigue:


struct passwd {
    char   *pw_name;       /* nombre de usuario */
    char   *pw_passwd;     /* contraseña de usuario */
    uid_t   pw_uid;        /* ID de usuario */
    gid_t   pw_gid;        /* ID de grupo */
    char   *pw_gecos;      /* información del usuario */
    char   *pw_dir;        /* directorio personal */
    char   *pw_shell;      /* programa de shell */
};

Para más información sobre los campos de esta estructura, ver passwd(5).

VALOR DE RETORNO

La función getpw() devuelve 0 en caso de éxito; en caso de error, devuelve -1 y establece errno para indicar el error.

Si uid no se encuentra en la base de datos de contraseñas, getpw() devuelve -1, establece errno a 0 y deja buf sin cambios.

ERRORES

0 o ENOENT
No existe ningún usuario que corresponda a uid.
EINVAL
buf es NULL.
ENOMEM
Memoria insuficiente para asignar la estructura passwd.

ARCHIVOS

/etc/passwd
archivo de base de datos de contraseñas

ATRIBUTOS

Para una explicación de los términos usados en esta sección, ver attributes(7).

Interfaz Atributo Valor
getpw () Seguridad en hilos MT-Safe locale

ESTÁNDARES

Ninguno.

HISTORIA

SVr2.

ERRORES CONOCIDOS

La función getpw() es peligrosa ya que puede desbordar el búfer buf proporcionado. Está obsoleta por getpwuid(3).

VER TAMBIÉN
