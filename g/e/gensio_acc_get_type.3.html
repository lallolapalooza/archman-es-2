NOMBRE

gensio_acc_get_type, gensio_acc_is_reliable, gensio_acc_is_packet, gensio_acc_is_message, gensio_acc_is_mux - Devolver información general sobre un aceptador gensio

SINOPSIS

#include <gensio/gensio.h>

const char *gensio_acc_get_type(struct gensio *io,

unsigned int depth);
bool gensio_acc_is_reliable(struct gensio *io);
bool gensio_acc_is_packet(struct gensio *io);
bool gensio_acc_is_mux(struct gensio *io);

DESCRIPCIÓN

gensio_acc_get_type devuelve la cadena de tipo para el aceptador gensio (si depth es 0) o uno de sus hijos (depth > 0). Devuelve NULL si la profundidad es mayor que el número de hijos.

gensio_acc_is_reliable devuelve true si los genios producidos por este aceptador son fiables. Consulte gensio_is_reliable(3) para obtener más detalles.

gensio_acc_is_packet devuelve si los genios producidos por este aceptador están orientados a paquetes. Consulte gensio_is_packet(3) para obtener más detalles.

gensio_acc_is_message devuelve si los genios producidos por este aceptador están orientados a mensajes. Consulte gensio_is_message(3) para obtener más detalles.

gensio_acc_is_mux devuelve si los genios producidos por este aceptador son capaces de multiplexación. Consulte gensio_is_mux(3) para obtener más detalles.
