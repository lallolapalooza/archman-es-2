NOMBRE

gegps - Cliente de Google Earth para gpsd

SINOPSIS

gegps [OPCIONES] [servidor[:puerto[:dispositivo]]]

gegps -h

gegps -V

DESCRIPCIÓN

El programa gegps recopila correcciones de gpsd y las alimenta a una instancia en ejecución de Google Earth para el seguimiento de ubicación en vivo.

OPCIONES

-?, -h, --help

Imprime un resumen de las opciones y luego sale.

-d DIR, --kmldir DIR

Especifica la ubicación del directorio de instalación de Google Earth. Si no se especifica, por defecto es el directorio actual.

-D LVL, --debug LVL

Establece el nivel de depuración; es principalmente para uso de los desarrolladores de GPSD. Habilita varios mensajes de progreso en la salida estándar de error.

--device DEVICE

Conecta al dispositivo DEVICE en el host de gpsd.

--host HOST

Conecta a gpsd en el host HOST.

-i, --initialize

Si tienes la versión gratuita (sin suscripción), comienza ejecutando con la opción -i para dejar una pista en el directorio de instalación de Google Earth, como 'Open_in_Google_Earth_RT_GPS.kml', luego abre ese archivo en Lugares (Archivo > Abrir...). Ejecuta gegps de la manera normal después de eso.

--port PORT

Conecta a gpsd en el puerto PORT.

-V, --version

Imprime la versión del paquete y sale.

gegps no requiere privilegios de root, debe ejecutarse como el mismo usuario bajo el que se ejecuta tu cliente de Google Earth.

ARGUMENTOS

Por defecto, los clientes recopilan datos del demonio gpsd local que se ejecuta en localhost, utilizando el puerto GPSD por defecto 2947. El argumento opcional para cualquier cliente puede anular este comportamiento: [servidor[:puerto[:dispositivo]]]

Para obtener más explicaciones y ejemplos, consulta la sección ARGUMENTOS en la página del manual gps(1).

VALORES DE RETORNO

0

en caso de éxito.

1

en caso de fallo.
