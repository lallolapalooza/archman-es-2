GENRESSCRIPT(1) Manual de Comandos Generales GENRESSCRIPT(1)

NOMBRE

genresscript - genera un script de recursos a partir de binarios PE y NE

SINOPSIS

genresscript [ARCHIVO]...

DESCRIPCIÓN

Esta página del manual documenta brevemente el comando genresscript. Esta página del manual fue escrita para la distribución GNU Debian porque el programa original no tiene una página del manual.

Genresscript toma cualquier número de binarios PE o NE, y genera un script de recursos con todos los recursos de los binarios listados. (Todo excepto el nombre de archivo de destino se completará en el script.) Esto es útil cuando ya has extraído imágenes y quieres crear un script de recursos de ellas.

OPCIONES

-t
--type=ID
lista recursos de este tipo en lugar de group_icon
-b
--base=RUTA
el nombre de extracción por defecto de todos los recursos
-s
--sort
ordena alfabéticamente en lugar de usar el orden en el binario
--help
muestra esta ayuda y sale
--version
muestra información de la versión y sale

VER TAMBIÉN

extresso(1), icotool(1), wrestool(1).
