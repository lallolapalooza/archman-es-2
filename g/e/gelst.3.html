CGELST resuelve sistemas lineales reales sobredeterminados o subdeterminados para matrices GE usando factorización QR o LQ con representación compacta WY de

Q.

Propósito

: 
!>
!> CGELST resuelve sistemas lineales reales sobredeterminados o subdeterminados
!> que involucran una matriz A de M por N, o su conjugado-transpuesta, usando una
!> factorización QR o LQ de A con representación compacta WY de Q.
!>
!> Se asume que A tiene rango completo, y solo se proporciona una protección
!> rudimentaria contra matrices con rango deficiente. Esta subrutina solo detecta
!> rango-deficiencia exacta, donde un elemento diagonal del factor triangular
!> de A es exactamente cero.
!>
!> Es concebible que uno (o más) de los elementos diagonales del factor triangular
!> de A sean números subnormalmente pequeños sin que esta subrutina señale
!> un error. Las soluciones calculadas para tales matrices casi-rango-deficientes pueden
!> ser menos precisas debido a una pérdida de precisión numérica.
!>
!> Se proporcionan las siguientes opciones:
!>
!> 1. Si TRANS = 'N' y m >= n:  encontrar la solución de mínimos cuadrados de
!>    un sistema sobredeterminado, es decir, resolver el problema de mínimos cuadrados
!>                 minimizar || B - A*X ||.
!>
!> 2. Si TRANS = 'N' y m < n:  encontrar la solución de norma mínima de
!>    un sistema subdeterminado A * X = B.
!>
!> 3. Si TRANS = 'C' y m >= n:  encontrar la solución de norma mínima de
!>    un sistema subdeterminado A**T * X = B.
!>
!> 4. Si TRANS = 'C' y m < n:  encontrar la solución de mínimos cuadrados de
!>    un sistema sobredeterminado, es decir, resolver el problema de mínimos cuadrados
!>                 minimizar || B - A**T * X ||.
!>
!> Varios vectores de segundo miembro b y vectores de solución x pueden ser
!> manejados en una sola llamada; se almacenan como las columnas de la
!> matriz de segundo miembro B de M por NRHS y la matriz de solución
!> X de N por NRHS.
!
>

!>                       LQ tal como la devuelve CGELQT.

!

!>          En la entrada, la matriz B de vectores de segundo miembro, almacenada

!>          si TRANS = 'N' y m < n, las filas 1 a N de B contienen los
!>          vectores de solución de norma mínima;
!>          si TRANS = 'C' y m >= n, las filas 1 a M de B contienen los
!>          vectores de solución de norma mínima;
!>          si TRANS = 'C' y m < n, las filas 1 a M de B contienen los
!>          vectores de solución de mínimos cuadrados; la suma de residuos de cuadrados
!>          para la solución en cada columna está dada por la suma de
!>          cuadrados del módulo de los elementos M+1 a N en esa columna.
!

!

subrutina dgelst (character trans, integer m, integer n, integer nrhs, double precision, dimension( lda, * ) a, integer lda, double precision, dimension( ldb, * ) b, integer ldb, double precision, dimension( * ) work, integer lwork, integer

info)

DGELST resuelve sistemas sobredeterminados o subdeterminados para GE matrices using QR or LQ factorization with compact WY representation of

Q.

Purpose

: 
!>
!> DGELST solves overdetermined or underdetermined real linear systems
!> involving an M-by-N matrix A, or its transpose, using a QR or LQ
!> factorization of A with compact WY representation of Q.
!>
!> It is assumed that A has full rank, and only a rudimentary protection
!> against rank-deficient matrices is provided. This subroutine only detects
!> exact rank-deficiency, where a diagonal element of the triangular factor
!> of A is exactly zero.
!>
!> It is conceivable for one (or more) of the diagonal elements of the triangular
!> factor of A to be subnormally tiny numbers without this subroutine signalling
!> an error. The solutions computed for such almost-rank-deficient matrices may
!> be less accurate due to a loss of numerical precision.
!>
!> The following options are provided:
!>
!> 1. If TRANS = 'N' and m >= n:  find the least squares solution of
!>    an overdetermined system, i.e., solve the least squares problem
!>                 minimize || B - A*X ||.
!>
!> 2. If TRANS = 'N' and m < n:  find the minimum norm solution of
!>    an underdetermined system A * X = B.
!>
!> 3. If TRANS = 'T' and m >= n:  find the minimum norm solution of
!>    an underdetermined system A**T * X = B.
!>
!> 4. If TRANS = 'T' and m < n:  find the least squares solution of
!>    an overdetermined system, i.e., solve the least squares problem
!>                 minimize || B - A**T * X ||.
!>
!> Several right hand side vectors b and solution vectors x can be
!> handled in a single call; they are stored as the columns of the
!> M-by-NRHS right hand side matrix B and the N-by-NRHS solution
!> matrix X.
!
>

Parameter

s
TRANS 
!>          TRANS is CHARACTER*1
!>          = 'N': the linear system involves A;
!>          = 'T': the linear system involves A**T.
!
>

M 
!>          M is INTEGER
!>          The number of rows of the matrix A.  M >= 0.
!
>

N 
!>          N is INTEGER
!>          The number of columns of the matrix A.  N >= 0.
!
>

NRH

S 
!>          NRHS is INTEGER
!>          The number of right hand sides, i.e., the number of
!>          columns of the matrices B and X. NRHS >=0.
!
>

A 
!>          A is DOUBLE PRECISION array, dimension (LDA,N)
!>          On entry, the M-by-N matrix A.
!>          On exit,
!>            if M >= N, A is overwritten by details of its QR
!>                       factorization as returned by DGEQRT;
!>            if M <  N, A is overwritten by details of its LQ
!>                       factorization as returned by DGELQT.
!
>

LD

A 
!>          LDA is INTEGER
!>          The leading dimension of the array A.  LDA >= max(1,M).
!
>

B 
!>          B is DOUBLE PRECISION array, dimension (LDB,NRHS)
!>          On entry, the matrix B of right hand side vectors, stored
!>          columnwise; B is M-by-NRHS if TRANS = 'N', or N-by-NRHS
!>          if TRANS = 'T'.
!>          On exit, if INFO = 0, B is overwritten by the solution
!>          vectors, stored columnwise:
!>          if TRANS = 'N' and m >= n, rows 1 to n of B contain the least
!>          squares solution vectors; the residual sum of squares for the
!>          solution in each column is given by the sum of squares of
!>          elements N+1 to M in that column;
!>          if TRANS = 'N' and m < n, rows 1 to N of B contain the
!>          minimum norm solution vectors;
!>          if TRANS = 'T' and m >= n, rows 1 to M of B contain the
!>          minimum norm solution vectors;
!>          if TRANS = 'T' and m < n, rows 1 to M of B contain the
!>          least squares solution vectors; the residual sum of squares
!>          for the solution in each column is given by the sum of
!>          squares of elements M+1 to N in that column.
!
>

LD

B 
!>          LDB is INTEGER
!>          The leading dimension of the array B. LDB >= MAX(1,M,N).
!
>

WOR

K 
!>          WORK is DOUBLE PRECISION array, dimension (MAX(1,LWORK))
!>          On exit, if INFO = 0, WORK(1) returns the optimal LWORK.
!
>

LWOR

K 
!>          LWORK is INTEGER
!>          The dimension of the array WORK.
!>          LWORK >= max( 1, MN + max( MN, NRHS ) ).
!>          For optimal performance,
!>          LWORK >= max( 1, (MN + max( MN, NRHS ))*NB ).
!>          where MN = min(M,N) and NB is the optimum block size.
!>
!>          If LWORK = -1, then a workspace query is assumed; the routine
!>          only calculates the optimal size of the WORK array, returns
!>          this value as the first entry of the WORK array, and no error
!>          message related to LWORK is issued by XERBLA.
!
>

INF

O 
!>          INFO is INTEGER
!>          = 0:  successful exit
!>          < 0:  if INFO = -i, the i-th argument had an illegal value
!>          > 0:  if INFO =  i, the i-th diagonal element of the
!>                triangular factor of A is exactly zero, so that A does not have
!>                full rank; the least squares solution could not be
!>                computed.
!
>

!>          si TRANS = 'C'.
!>          En la salida, si INFO = 0, B se sobrescribe con los vectores solución,
!>          almacenados por columnas:
!>          si TRANS = 'N' y m >= n, las filas 1 a n de B contienen los vectores
!>          solución de mínimos cuadrados; la suma de cuadrados residual del residuo
!>          para la solución en cada columna se da por la suma de cuadrados
!>          de los módulos de los elementos N+1 a M en esa columna;
!>          si TRANS = 'N' y m < n, las filas 1 a N de B contienen los
!>          vectores solución de norma mínima;
!>          si TRANS = 'C' y m >= n, las filas 1 a M de B contienen los
!>          vectores solución de norma mínima;
!>          si TRANS = 'C' y m < n, las filas 1 a M de B contienen los
!>          vectores solución de mínimos cuadrados; la suma de cuadrados residual del residuo
!>          para la solución en cada columna se da por la suma de
!>          cuadrados de los módulos de los elementos M+1 a N en esa columna.
!> 


LDB


!>          LDB es INTEGER
!>          La dimensión principal del array B. LDB >= MAX(1,M,N).
!> 


WORK


!>          WORK es COMPLEX*16 array, dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!> 


LWORK


!>          LWORK es INTEGER
!>          La dimensión del array WORK.
!>          LWORK >= max( 1, MN + max( MN, NRHS ) ).
!>          Para un rendimiento óptimo,
!>          LWORK >= max( 1, (MN + max( MN, NRHS ))*NB ).
!>          donde MN = min(M,N) y NB es el tamaño de bloque óptimo.
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo del array WORK, devuelve
!>          este valor como la primera entrada del array WORK, y no se emite ningún mensaje
!>          de error relacionado con LWORK por XERBLA.
!> 


INFO


!>          INFO es INTEGER
!>          = 0: salida exitosa
!>          < 0: si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>          > 0: si INFO = i, el i-ésimo elemento diagonal del
!>                factor triangular de A es exactamente cero, por lo que A no tiene
!>                rango completo; la solución de mínimos cuadrados no pudo ser
!>                calculada.
