getpwnam(3) Manual de Funciones de Biblioteca getpwnam(3)

NOMBRE

getpwnam, getpwnam_r, getpwuid, getpwuid_r - obtener entrada del archivo de contraseñas

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <sys/types.h>
#include <pwd.h>
struct passwd *getpwnam(const char *name);
struct passwd *getpwuid(uid_t uid);
int getpwnam_r(size_t size;
               const char *restrict name,
               struct passwd *restrict pwd,
               char buf[restrict size], size_t size,
               struct passwd **restrict result);
int getpwuid_r(size_t size;
               uid_t uid,
               struct passwd *restrict pwd,
               char buf[restrict size], size_t size,
               struct passwd **restrict result);
Requisitos de Macro de Prueba de Características para glibc (ver feature_test_macros(7)):

getpwnam_r(), getpwuid_r():

    _POSIX_C_SOURCE
        || /* glibc <= 2.19: */ _BSD_SOURCE || _SVID_SOURCE

DESCRIPCIÓN

La función getpwnam() devuelve un puntero a una estructura que contiene los campos desglosados del registro en la base de datos de contraseñas (por ejemplo, el archivo de contraseñas local /etc/passwd, NIS y LDAP) que coincide con el nombre de usuario name.

La función getpwuid() devuelve un puntero a una estructura que contiene los campos desglosados del registro en la base de datos de contraseñas que coincide con el ID de usuario uid.

La estructura passwd se define en <pwd.h> de la siguiente manera:


struct passwd {
    char   *pw_name;       /* nombre de usuario */
    char   *pw_passwd;     /* contraseña del usuario */
    uid_t   pw_uid;        /* ID de usuario */
    gid_t   pw_gid;        /* ID de grupo */
    char   *pw_gecos;      /* información del usuario */
    char   *pw_dir;        /* directorio personal */
    char   *pw_shell;      /* programa de shell */
};

Ver passwd(5) para más información sobre estos campos.

Las funciones getpwnam_r() y getpwuid_r() obtienen la misma información que getpwnam() y getpwuid(), pero almacenan la estructura passwd recuperada en el espacio apuntado por pwd. Los campos de cadena apuntados por los miembros de la estructura passwd se almacenan en el búfer buf de tamaño size. Se almacena un puntero al resultado (en caso de éxito) o NULL (en caso de que no se encuentre ninguna entrada o ocurra un error) en *result.

La llamada


sysconf(_SC_GETPW_R_SIZE_MAX)

devuelve -1, sin cambiar errno, o un tamaño sugerido inicial para buf. (Si este tamaño es demasiado pequeño, la llamada falla con ERANGE, en el que caso el llamador puede reintentar con un búfer más grande).

VALOR DE RETORNO

Las funciones getpwnam() y getpwuid() devuelven un puntero a una estructura passwd, o NULL si no se encuentra la entrada coincidente o ocurre un error. Si ocurre un error, errno se establece para indicar el error. Si se desea comprobar errno después de la llamada, debe establecerse a cero antes de la llamada.

El valor de retorno puede apuntar a un área estática y puede ser sobrescrito por llamadas posteriores a getpwent(3), getpwnam(), o getpwuid(). (No pase el puntero devuelto a free(3).)

En caso de éxito, getpwnam_r() y getpwuid_r() devuelven cero y establecen *result a pwd. Si no se encontró ningún registro de contraseña coincidente, estas funciones devuelven 0 y almacenan NULL en *result. En caso de error, se devuelve un número de error y se almacena NULL en *result.

ERRORES

0 o ENOENT o ESRCH o EBADF o EPERM o ...
El name o uid proporcionado no se encontró.
EINTR
Se capturó una señal; ver signal(7).
EIO
Error de E/S.
EMFILE
Se alcanzó el límite por proceso en el número de descriptores de archivo abiertos.
ENFILE
Se alcanzó el límite a nivel de sistema en el número total de archivos abiertos.
ENOMEM
Memoria insuficiente para asignar la estructura passwd.
ERANGE
Espacio de búfer insuficiente proporcionado.

ARCHIVOS

/etc/passwd
archivo local de base de datos de contraseñas

VERSIONES

El campo pw_gecos no está especificado en POSIX, pero está presente en la mayoría de las implementaciones.

ESTANDARES

POSIX.1-2008.

HISTORIA

POSIX.1-2001, SVr4, 4.3BSD.

NOTAS

La formulación dada anteriormente bajo "VALOR DE RETORNO" es de POSIX.1-2001. No llama a "no encontrado" un error, y por lo tanto no especifica qué valor podría tener errno en esta situación. Pero eso hace imposible reconocer los errores. Se podría argumentar que según POSIX errno debería dejarse sin cambios si no se encuentra una entrada. Los experimentos en varios sistemas tipo UNIX muestran que muchos valores diferentes ocurren en esta situación: 0, ENOENT, EBADF, ESRCH, EWOULDBLOCK, EPERM, y probablemente otros.

El campo pw_dir contiene el nombre del directorio de trabajo inicial del usuario. Los programas de inicio de sesión utilizan el valor de este campo para inicializar la variable de entorno HOME para el shell de inicio de sesión. Una aplicación que desee determinar el directorio personal de su usuario debe inspeccionar el valor de HOME (en lugar del valor getpwuid(getuid())->pw_dir) ya que esto permite al usuario modificar su noción de "el directorio personal" durante una sesión de inicio de sesión. Para determinar el directorio personal (inicial) de otro usuario, es necesario usar getpwnam("nombredeusuario")->pw_dir o similar.

EJEMPLOS

El programa a continuación demuestra el uso de getpwnam_r() para encontrar el nombre de usuario completo y el ID de usuario para el nombre de usuario proporcionado como argumento de línea de comandos.

#include <errno.h>
#include <pwd.h>
#include <stdint.h>
#include <stdio.h>
#include <stdlib.h>
#include <unistd.h>
int
main(int argc, char *argv[])
{
    struct passwd pwd;
    struct passwd *result;
    char *buf;
    long bufsize;
    int s;
    if (argc != 2) {
        fprintf(stderr, "Usage: %s username\n", argv[0]);
        exit(EXIT_FAILURE);
    }
    bufsize = sysconf(_SC_GETPW_R_SIZE_MAX);
    if (bufsize == -1)          /* Value was indeterminate */
        bufsize = 16384;        /* Should be more than enough */
    buf = malloc(bufsize);
    if (buf == NULL) {
        perror("malloc");
        exit(EXIT_FAILURE);
    }
    s = getpwnam_r(argv[1], &pwd, buf, bufsize, &result);
