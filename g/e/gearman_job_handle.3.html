DESCRIPCIÓN

gearman_job_st se pasan a las funciones de trabajador para representar los trabajos que se están ejecutando mediante gearman_worker_work().

gearman_job_free() se utiliza para liberar un trabajo. Esto solo necesita hacerse si una tarea fue creada con una estructura preasignada.

gearman_job_handle() devuelve el identificador del trabajo (ver gearman_job_handle_t para más información).

gearman_job_function_name() devuelve el nombre de la función que el trabajo estaba configurado para ejecutar.

gearman_job_unique() devuelve el valor único que se utilizó para gearman_job_st.

gearman_job_take_workload devuelve la carga de trabajo de gearman_job_st. El tamaño de la misma se puede determinar con gearman_job_workload_size(). gearman_job_take_workload() es lo mismo que gearman_job_workload() con la excepción de que el resultado debe ser liberado(3) por el llamador.

gearman_job_use_client devuelve un gearman_client_st configurado desde gearman_job_st. El gearman_client_st se puede utilizar para comunicar comandos de la API del cliente al servidor. No es necesario, y no debe, llamar a gearman_client_free() en el gearman_client_st. Se limpia cuando se limpia el trabajo.

VALOR DE RETORNO

Se devuelve un valor de gearman_return_t. En caso de éxito, ese valor será :c:type::GEARMAN_SUCCESS. Utilice gearman_strerror() para traducir este valor a una cadena imprimible.
