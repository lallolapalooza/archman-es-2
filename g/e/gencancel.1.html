DESCRIPCIÓ

N

gencancel proporciona al administrador de noticias una herramienta útil para generar mensajes de control de cancelación, escribiéndolos en la salida estándar. El artículo de cancelación generado puede ser luego inyectado por inews (véanse los ejemplos más abajo)

.

gencancel espera el Message-ID del artículo a cancelar; este argumento message-id debe estar correctamente citado para el shell y rodeado por signos de ángulo. gencancel intentará entonces leer el artículo original en el almacén de noticias para determinar los grupos de noticias originales a los que fue publicado, y reutilizará esa información para el mensaje de control de cancelación. Si desea modificar eso, o si la información no fue encontrada, tendrá que establecerla con el indicador

-n.

Si INN fue compilado con soporte para Cancel-Lock, gencancel generará el campo de cabecera Cancel-Key de administrador correcto para usar a fin de autenticar las cancelaciones. Si por cualquier motivo necesita cancelar un artículo publicado desde su servidor de noticias con un campo de cabecera Cancel-Lock, se necesitan los hashes de Cancel-Key de administrador correspondientes para autenticar la solicitud de retirada. Esa información se calcula con el parámetro canlockadmin establecido en inn-secrets

.conf.

En caso de que solo necesite los hashes de Cancel-Key de administrador, puede usar el indicador -k. Solo se escribirá entonces el cuerpo del campo de cabecera Cancel-Key a la salid

a estándar. Puede reutilizarlo, por ejemplo, en
una solicitud de reemplazo o desde otro script.

OPCIONE

S
-
a
gencancel emite por defecto un campo de cabecera Approved, usando el mismo valor que el cuerpo del campo de cabecera From. Si se usa -a, no se emite ningún campo de cabecera Approved.

Este campo de cabecera es útil para cancelar artículos publicados originalmente en grupos de noticias moderados. Si un artículo de control de cancelación lista un grupo de noticias moderado en su campo de cabecera Newsgroups, y no está presente un campo de cabecera Approved, la cancelación será enviada primero al moderador para su aprobación. No se requiere que los mensajes de control de cancelación contengan un campo de cabecera Approved fuera de los grupos de noticias moderados, pero pueden hacerlo, por lo que generalmente no debería usar -a a menos que realmente desee que sus cancelaciones sean aprobadas por un moderador, o que e

sté seguro de que el campo de cabecera Newsgrou
ps no lista ningún grupo de noticias moderado.
-b cue
rpo
gencancel escribe por defecto "Admin cancel." en el cuerpo de los mensajes de control de cancelación. Usar este argumento permite escribir un valor diferente, que puede estar vacío o ser
multilínea.
-c juego de
caracteres
Por defecto, se especifica "ISO-8859-1" como el juego de caracteres usado en el campo de cabecera Content-Type. En caso de que cambie el cuerpo por defecto con -b, puede que desee cambiar también el juego de caracteres en
consecuencia.
-
d
gencancel genera un campo de cabecera Date en la hora local de su servidor de noticias. Usar -d hará que se use una fecha
UTC.
-f d
e
gencancel usa por defecto el valor de complaints en inn.conf para el campo de cabecera From. Usar este argumento permite establecer el valor que desee. El mismo valor se usará para el campo de cabecera Approved (si se genera, cuando no se da -a)
.
-
k
En lugar de emitir un mensaje de control de cancelación completo, gencancel solo emitirá el cuerpo del campo de cabecera Cancel-Key con los hashes de administrador.

Este indicador solo está disp

onible si INN fue compilado
con soporte para Cancel-Lock.
-
L
gencancel emite por defecto un campo de cabecera Cancel-Key para autenticar el mensaje de control de cancelación. Si se usa -L, no se emite ningún campo de cabecera Cancel-Key.

Este indicador solo está disp

onible si INN fue compilado
con soporte para Cancel-Lock.
-
m
gencancel genera por defecto un Message-ID aleatorio y lo usa como identificador único del mensaje de control de cancelación. Si se usa -m, no se emite ningún campo de cabecera
Message-ID.
-n grupos de
noticias
gencancel genera por defecto el mismo campo de cabecera Newsgroups que el presente en el artículo original a cancelar. Esto se hace para asegurar en la mejor medida posible que el mensaje de control de cancelación será retransmitido a los mismos servidores de noticias que el mensaje original.

En caso de que su servidor de noticias no lleve localmente (o ya no lleve) el artículo origina

l, deberá dar un grupo de noticias explícito o una lista de grupos de noticias separados por
comas con este indicador, que se usará como el campo de cabecera Newsgroups de la cancelación.
-s asun
to
gencancel usa por defecto "cmsg cancel <message-id>" como el asunto de los mensajes de control de cancelación. Usar
este argumento permite establecer un valor dife
rente para el campo de cabecera Subject. Asegúre
se de que esté correctamente codificado en MIME.

EJEMPLO

S

Para obtener solo los hashes de Cancel-Key de administrador asociados al Message-ID

dado: 
gencancel -k '<mid@news>
'

Si usa caracteres no ASCII en las cabeceras, asegúrese de codificarlos correctamente en MIME. Por ejemplo, use el módulo Perl "Encode"

: 
FROM=$(perl -e 'use Encode;
                print encode("MIME-Q",
                             decode("UTF-8", "Julien ELIE"));')
gencancel -f "$FROM <admin@news.server.com>" '<mid@news>
'

Verá entonces en la salida un campo de cabecera correctamente codificado en

MIME: 
From: =?UTF-8?Q?Julien_=C3=89LIE?= <admin@news.server.
com>

Un ejemplo de invocación con un cuerpo multilínea

personalizado: 
gencancel -b "$(echo -e "Multi\nLine\nBody.")" '<mid@news>
'

(Use -c para cambiar el juego de caracteres MIME Content-Type por defecto para el cuerpo.

)

Puede entonces canalizar el resultado a "inews -h -P -D" (lo que significa que inews espera un artículo con cabeceras, no añade un campo de cabecera Sender, y escribe el resultado a la salida estándar en lugar de inyectarlo realmente)

: 
gencancel '<mid@news>' | inews -h -P
-D

Si todo parece correcto, inyéctelo entonces en el sistema de noticias (sin dar "-D" a inews

): 
gencancel '<mid@news>' | inews -h
-P

Nótese que inews envía el mensaje al servidor especificado en el parámetro server en inn.

con
f.
