DESCRIPCIÓ

N

El archivo de configuración principal de GeoClue 'geoclue.conf' especifica parámetros que controlan el funcionamiento de geoclue. Los parámetros pueden sobrescribirse colocando archivos de configuración en el directorio conf.d y se aplican en orden alfabético. Así, un archivo de configuración '90-config.conf' sobrescribirá los parámetros especificados en otro archivo de configuración '50-config.conf' en el directorio conf.

d.

Todas las configuraciones siguientes son obligatorias y los valores predeterminados son los que ves antes de editarlos en geoclue.conf. Si deseas conservar los valores predeterminados, copia y comenta la(s) línea(s) correspondiente(s) antes de

cambiarlas.

La ausencia de la clave 'enable' para una fuente particular en el archivo de configuración pr

incipal hace que esa fuente esté habilitada de forma predeterminada. Añadir la clave 'enable
' en cualquier archivo de configuración posterior puede sobrescribir este valor predeterminado.

Opciones de configuración de la fuente
IP
enable=true
Habilita la fuente GeoIP
method=ichnaea
Método (backend) a usar para la ubicación por IP. Actualmente implementados están:
"ichnaea": Usa la API de Ichnaea con la URL de la fuente wifi.
"gmaps": Usa la ubicación determinada por Google Maps. "reallyfreegeoip": reallyfreegeoip.org. Esta API no devuelve precisión, por lo que usamos un valor constante. Ver la opción de precisión a continuación.
Las siguientes opciones no necesitan establecerse, pero pueden proporcionarse si deseas sobrescribir los valores predeterminados del método:
url=https://example.com/v1/geolocate
URL alternativa al servicio GeoIP implementado por el método seleccionado.
accuracy=30000.0
Sobrescribe la precisión recibida del servidor GeoIP (o codificada en el método) con este valor.

Opciones de configuración de la fuente
WiFi
enable=true
Habilita la fuente
WiFi
url=https://example.com/v1/geolocate?key=YOUR_KEY
URL al servicio de geolocalización inalámbrica compatible con la API de Ichnaea (https://ichnaea.readthedocs.io/en/latest/api/geolocate.html). Si no se establece, usa como valor predeterminado una URL establecida en la configuración de compilación. Si no se establece una URL aquí o en la configuración de compilación, las fuentes wifi y 3g estarán deshabilitadas. Se puede establecer una clave API con el parámetro de URL
"key".
submit-data=false
Enviar datos a un servicio de geolocalización inalámbrica.
Si se establece en true, geoclue enviará automáticamente datos de red a un servicio de geolocalización inalámbrica cada vez que obtenga un bloqueo GPS. Actualmente, solo las fuentes Modem-GPS o Network NMEA están soportadas como proveedores de una ubicación a enviar (una a la vez). Si la fuente Modem-GPS está habilitada arriba, será el proveedor exclusivo (independientemente de si el sistema está realmente equipado con dicho módem), de lo contrario se considerará la fuente Network
NMEA.
submission-url=https://example.com/v2/geosubmit?key=YOUR_KEY
URL para enviar datos a un servicio de geolocalización inalámbrica con una API compatible con Ichnaea (https://ichnaea.readthedocs.io/en/latest/api/geosubmit2.html)
.
submission-nick=geoclue
Un apodo con el que enviar datos de red. Establece una cabecera HTTP "X-Nickname" en la solicitud de envío. Si se establece en una cadena vacía, se omite del envío. De lo contrario, debe tener de 2 a 32 caracteres de longitud. El valor predeterminado es "geoclue".

Opciones de configuración de la fuente estática.
Esta fuente lee la ubicación del archivo "geolocation" en /etc. Ver "ARCHIVO DE UBICACIÓN ESTÁTICA" a continuación para el formato de este archivo. Aunque este archivo se monitorea constantemente para cambios durante la operación de geoclue, y la ubicación estática reportada se actualiza en consecuencia, esta fuente no está destinada para introducir una ubicación dinámicamente cambiante en geoclue (por favor usa la fuente Network NMEA para
eso).
enable=true

OPCIONES DE CONFIGURACIÓN DE LA

APLICACIÓN

Tener una entrada aquí para una aplicación con allowed=true significa que geoclue no pedirá al agente que autorice la aplicación. Esto es para asegurar que las aplicaciones con mecanismo de autorización integrado (por ejemplo, navegadores web) no tengan que estar vinculadas a

agentes.

Si tu aplicación es denegada acceso a la información de ubicación y tu sistema operativo no proporciona ningún mecanismo para cambiar eso, es probablemente un error en tu sistema operativo (o en geoclue). La solución es reportar el problema con todos los detalles, en lugar de añadir tu aplicación a esta

lista.

ESTÁTICA

Formato

básico:

El archivo de ubicación estática en /etc (usado por la fuente estática) es un archivo de texto que consta de lo

siguiente:
1
Latitud (número de punto flotante; los valores positivos significan norte, los negativos
sur)
2
Longitud (número de punto flotante; los valores positivos significan este, los negativos
oeste)
3
Altitud (número de punto flotante; en
metros)
4
Radio de precisión
(número de punto f
lotante; en metros)

Estos valores deben est

ar separados por caract
eres de salto de línea.

Información adicional de

formato:
•
El carácter '#' inicia un comentario, que continúa hasta el final de la línea
actual.
•
El espacio en blanco al principio y al final de cada línea se
ignora.
•
Las líneas vacías (o q
ue contengan solo espac
io en blanco o un comen
tario) se ignoran.

Ejemplo

:

a Estatua de la Libertad 40.6893129 # latitud -74.0445531 # longitud 96
# altitud 1.83 # radio de precisión (el diámetro de la antorcha es de 12 pies)
