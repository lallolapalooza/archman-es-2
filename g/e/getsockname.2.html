getsockname(2) Manual de llamadas al sistema getsockname(2)

NOMBRE

getsockname - obtener el nombre del socket

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <sys/socket.h>
int getsockname(int sockfd, struct sockaddr *restrict addr,
                socklen_t *restrict addrlen);

DESCRIPCIÓN

getsockname() devuelve la dirección actual a la que está vinculado el socket sockfd, en el búfer apuntado por addr. El argumento addrlen debe inicializarse para indicar la cantidad de espacio (en bytes) apuntado por addr. Al regresar, contendrá el tamaño real de la dirección del socket.

La dirección devuelta se trunca si el búfer proporcionado es demasiado pequeño; en este caso, addrlen devolverá un valor mayor que el suministrado en la llamada.

VALOR DE RETORNO

En caso de éxito, se devuelve cero. En caso de error, se devuelve -1 y errno se establece para indicar el error.

ERRORES

EBADF
El argumento sockfd no es un descriptor de archivo válido.
EFAULT
El argumento addr apunta a memoria que no forma parte del espacio de direcciones del proceso.
EINVAL
addrlen es inválido (por ejemplo, es negativo).
ENOBUFS
No había suficientes recursos disponibles en el sistema para realizar la operación.
ENOTSOCK
El descriptor de archivo sockfd no se refiere a un socket.

ESTANDARES

POSIX.1-2024.

HISTORIA

POSIX.1-2001, SVr4, 4.2BSD.

VER TAMBIÉN

bind(2), socket(2), getifaddrs(3), ip(7), socket(7), unix(7)
