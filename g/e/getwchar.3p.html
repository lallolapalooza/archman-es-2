GETWCHAR(3P) Manual del programador POSIX GETWCHAR(3P)

PRÓLOGO

Esta página del manual es parte del Manual del Programador POSIX. La implementación de Linux de esta interfaz puede diferir (consulte la página del manual correspondiente de Linux para conocer los detalles del comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

getwchar — obtener un carácter ancho de un flujo stdin

SINOPSIS

#include <wchar.h>
wint_t getwchar(void);

DESCRIPCIÓN

La funcionalidad descrita en esta página de referencia está alineada con el estándar ISO C. Cualquier conflicto entre los requisitos descritos aquí y el estándar ISO C es no intencional. Este volumen de POSIX.1‐2017 remite al estándar ISO C.

La función getwchar() será equivalente a getwc(stdin).

VALOR DE RETORNO

Consulte fgetwc().

ERRORES

Consulte fgetwc().

EJEMPLOS

Ninguno.

USO DE APLICACIONES

Si el valor wint_t devuelto por getwchar() se almacena en una variable de tipo wchar_t y luego se compara con la macro wint_t WEOF, el resultado puede ser incorrecto. Solo el tipo wint_t garantiza poder representar cualquier carácter ancho y WEOF.
