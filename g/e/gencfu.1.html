NOMBRE

gencfu - Genera archivos de datos de Confusables de Unicode

SINOPSIS

gencfu [ -h, -?, --help ] [ -V, --version ] [ -c, --copyright ] [ -v, --verbose ] [ -d, --destdir destino ] [ -i, --icudatadir directorio ] -r, --rules archivo-reglas -w, --wsrules archivo-reglas-script-completo -o, --out archivo-salida

DESCRIPCIÓN

gencfu lee las definiciones de caracteres confusos en el archivo de entrada, que son archivos de texto plano que contienen definiciones de caracteres confusos en el formato de entrada definido por Unicode UAX39 para los archivos confusables.txt y confusablesWholeScript.txt. Este formato fuente (.txt) también es aceptado por los detectores de suplantación de identidad de ICU. Los archivos deben estar codificados en formato utf-8, con o sin BOM. Normalmente, el archivo de datos de salida tiene la extensión .cfu.

OPCIONES

-h, -?, --help
Imprime ayuda sobre el uso y sale.
-V, --version
Imprime la versión de gencfu y sale.
-c, --copyright
Incrusta los derechos de autor estándar de ICU en el archivo-salida.
-v, --verbose
Muestra mensajes informativos adicionales durante la ejecución.
-d, --destdir destino
Establece el directorio de destino del archivo-salida a destino.
-i, --icudatadir directorio
Busca cualquier archivo de datos de ICU necesario en el directorio. Por ejemplo, el archivo pnames.icu debe ubicarse cuando los datos de ICU no se compilan como una biblioteca compartida. El directorio de datos predeterminado de ICU es especificado por la variable de entorno ICU_DATA. La mayoría de las configuraciones de ICU no requieren este argumento.
-r, --rules archivo-reglas
El archivo fuente a leer.
-w, --wsrules archivo-reglas-script-completo
El archivo fuente de script completo a leer.
-o, --out archivo-salida
El archivo de datos de salida a escribir.
