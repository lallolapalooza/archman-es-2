getresuid(2) Manual de llamadas al sistema getresuid(2)

NOMBRE

getresuid, getresgid - obtener IDs de usuario/grupo reales, efectivos y guardados

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#define _GNU_SOURCE         /* Ver feature_test_macros(7) */
#include <unistd.h>
int getresuid(uid_t *ruid, uid_t *euid, uid_t *suid);
int getresgid(gid_t *rgid, gid_t *egid, gid_t *sgid);

DESCRIPCIÓN

getresuid() devuelve el UID real, el UID efectivo y el conjunto de ID de usuario guardado del proceso que llama, en los argumentos ruid, euid y suid, respectivamente. getresgid() realiza la tarea análoga para los IDs de grupo del proceso.

VALOR DE RETORNO

En caso de éxito, se devuelve cero. En caso de error, se devuelve -1 y se establece errno para indicar el error.

ERRORES

EFAULT
Uno de los argumentos especificó una dirección fuera del espacio de direcciones del programa que llama.

ESTANDARES

Ninguno. Estas llamadas también aparecen en HP-UX y algunos de los BSDs.

HISTORIA

Linux 2.1.44, glibc 2.3.2.

Las llamadas al sistema originales getresuid() y getresgid() de Linux solo admitían IDs de usuario y grupo de 16 bits. Posteriormente, Linux 2.4 añadió getresuid32() y getresgid32(), que admitían IDs de 32 bits. Las funciones de envoltorio getresuid() y getresgid() de glibc manejan de forma transparente las variaciones entre las versiones del kernel.

VER TAMBIÉN

getuid(2), setresuid(2), setreuid(2), setuid(2), credentials(7)
