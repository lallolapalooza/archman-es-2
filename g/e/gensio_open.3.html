Paquete: gensio

gensio_open(3) Manual de funciones de biblioteca gensio_open(3)

NOMBRE

gensio_open, gensio_open_s, gensio_open_nochild, gensio_open_nochild_s - Iniciar un gensio de conexión

SINOPSIS

#include <gensio/gensio.h>

typedef void (*gensio_done_err)(struct gensio *io, int err,

void *open_data);
int gensio_open(struct gensio *io, gensio_done_err open_done,

void *open_data);
int gensio_open_s(struct gensio *io);
int gensio_open_nochild(struct gensio *io, gensio_done_err open_done,

void *open_data);
int gensio_open_nochild_s(struct gensio *io);

DESCRIPCIÓN

gensio_open inicia el gensio. Los gensios recibidos de un aceptor se abren al recibirlos, pero los gensios de conexión se inician cerrados y deben abrirse antes de usarlos. Si no se devuelve ningún error, se llamará a la devolución de llamada open_done; si no hay error en el valor err de la devolución de llamada, el gensio estará abierto. Esto abrirá también todos los hijos.

Tenga en cuenta que la devolución de llamada open_done siempre se llamará, incluso si cierra el gensio antes de que ocurra la devolución de llamada open_done o si ocurre un error. Esto está garantizado.

gensio_open_s es como gensio_open, pero espera a que la apertura se complete. El procesamiento normal de gensio ocurrirá mientras se espera. Tenga en cuenta que debe tener cuidado de no llamar a esto desde una devolución de llamada; solo debe llamar a esto desde un hilo que no sea de devolución de llamada o un ejecutor (consulte gensio_os_funcs(3) para obtener detalles sobre los ejecutores).

gensio_open_nochild es como gensio_open, pero asume que los gensios hijos ya están abiertos y solo abre este gensio. Esto puede ser útil si tiene un gensio que ya está abierto (como si lo recibió de un aceptor) y desea apilar otro gensio encima de él. Solo los gensios de filtro admitirán esto.

gensio_open_nochild_s es como gensio_open_nochild, pero espera a que la apertura se complete. Consulte las notas sobre gensio_open_s anteriores para ver las advertencias.

VALORES DE RETORNO

Se devuelve cero en caso de éxito, o un error de gensio en caso de fallo.

VER TAMBIÉN

gensio_err(3), gensio(5), gensio_os_funcs(3)
