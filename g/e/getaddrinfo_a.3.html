DESCRIPCIÓ

N

La función getaddrinfo_a() realiza la misma tarea que getaddrinfo(3), pero permite realizar múltiples búsquedas de nombres de forma asíncrona, con notificación opcional al completarse las operaciones de

búsqueda.

El argumento mode tiene uno de los siguientes

valores:
GAI_WA
IT
Realiza las búsquedas de forma sincrónica. La llamada se bloquea hasta que las búsquedas se hayan
completado.
GAI_NOWA
IT
Realiza las búsquedas de forma asíncrona. La llamada retorna inmediatamente, y las solicitudes se resuelven en segundo plano. Ver la discusión del argumento sevp más
ab
ajo.

El arreglo list especifica las solicitudes de búsqueda a procesar. El argumento n especifica el número de elementos en list. Las operaciones de búsqueda solicitadas se inician en paralelo. Los elementos NULL en list se ignoran. Cada solicitud se describe con una estructura gaicb, definida como

sigue: 


struct gaicb {
    const char            *ar_name;
    const char            *ar_service;
    const struct addrinfo *ar_request;
    struct addrinfo       *ar_result;
}
;

Los elementos de esta estructura corresponden a los argumentos de getaddrinfo(3). Así, ar_name corresponde al argumento node y ar_service al argumento service, identificando un host de Internet y un servicio. El elemento ar_request corresponde al argumento hints, especificando los criterios para seleccionar las estructuras de dirección de socket devueltas. Finalmente, ar_result corresponde al argumento res; no necesita inicializar este elemento, se establecerá automáticamente cuando la solicitud sea resuelta. La estructura addrinfo referenciada por los dos últimos elementos se describe en getaddrinf

o(3).

Cuando mode se especifica como GAI_NOWAIT, se pueden obtener notificaciones sobre las solicitudes resueltas empleando la estructura sigevent apuntada por el argumento sevp. Para la definición y detalles generales de esta estructura, ver sigevent(3type). El campo sevp->sigev_notify puede tener los siguientes

valores:

•
Una o más de las operaciones en list se

NAME

getaddrinfo_a, gai_suspend, gai_error, gai_cancel - Address to name information lookup (asynchronous interface)

LIBRARY

Name Service Switch library (libnss, -lnss)

SYNOPSIS

#define _GNU_SOURCE

#include <sys/types.h>
#include <sys/socket.h>
#include <netdb.h>

int getaddrinfo_a(int mode, struct gaicb *const list[], size_t nent,
                   struct sigevent *restrict sev);
int gai_suspend(const struct gaicb *const list[], size_t nent,
                const struct timespec *restrict timeout);
int gai_error(const struct gaicb *req);
void gai_cancel(struct gaicb *req);

DESCRIPTION

These functions provide an asynchronous interface for the getaddrinfo(3) function. This allows an application to initiate multiple name resolution requests concurrently without blocking the calling thread.

The structure struct gaicb is defined in <netdb.h> as follows:

typedef void (*gai_callout_func)(struct gaicb *req);

struct gaicb {
    int             				 gai_last_error; /* Internal use only */
    int             				 gai_req_type;   /* Internal use only */
    int             				 gai_ret;        /* Return value of getaddrinfo */
    char            				*ar_name;        /* Hostname to look up */
    char            				*ar_service;     /* Service name or port number */
    const struct addrinfo   *ar_hints;         /* Structure with criteria for socket */
    struct addrinfo 				*ar_result;      /* Result list */
    gai_callout_func    				 gai_callout;    /* Optional callback function */
    void            				*gaicb_private;  /* Private data for callout */
    struct sigevent 				 gai_event;      /* Event notification */
};

The getaddrinfo_a() function initiates name resolution requests for each of the nent requests in the list array. Each element of list is a pointer to a struct gaicb. For each request, the ar_name and ar_service fields should be filled with the host and service names, respectively. The ar_hints field can be used to specify criteria for the returned socket address structures, similar to the hints argument of getaddrinfo(3). If ar_hints is NULL, default criteria are used.

The mode argument controls the behavior of getaddrinfo_a():

GAI_WAIT: The call blocks until all requests in the list have completed.

GAI_NOWAIT: The call returns immediately. The requests are processed asynchronously in the background. The caller must later use gai_suspend() or poll the individual struct gaicb objects to determine when the requests have finished.

If sev is not NULL, it specifies the notification mechanism to use when all requests have completed. See sigevent(7) for details on struct sigevent.

If mode is GAI_NOWAIT, the gai_event field of each struct gaicb can be configured to notify the application upon completion of that specific request.

The gai_suspend() function blocks until at least one of the requests in the list array completes, or until the specified timeout expires. If timeout is NULL, gai_suspend() blocks indefinitely. gai_suspend() can be called multiple times to wait for different sets of requests.

The gai_error() function returns the error status of a specific request pointed to by req. If the request has not yet completed, it returns EAI_INPROGRESS. If the request completed successfully, it returns 0. Otherwise, it returns an error code from getaddrinfo(3).

The gai_cancel() function attempts to cancel a pending request pointed to by req. If the cancellation is successful, it returns 0; otherwise, it returns an error code.

After a request has completed, the ar_result field of the corresponding struct gaicb will point to a linked list of struct addrinfo structures, representing the resolved addresses. It is the caller's responsibility to free this list using freeaddrinfo(3).

If a gai_callout function is specified in struct gaicb, it will be invoked when the request completes. The gaicb_private field can be used to pass data to the callout function.

The asynchronous interface uses threads internally to perform the network lookups. The maximum number of simultaneous requests may be limited by system resources.

RETURN VALUE

The getaddrinfo_a() function returns 0 on success, or an error number if an error occurred. The gai_suspend() function returns 0 on success, or an error number if an error occurred. The gai_error() function returns the status of the request. The gai_cancel() function returns 0 on success or an error number.

Possible error codes (defined in <netdb.h>) are:

EAI_AGAIN
Temporary failure during name resolution, try again.
EAI_BADFLAGS
Invalid value for flags.
EAI_BUSY
The system is busy processing requests.
EAI_CANCELED
Request was canceled.
EAI_FAMILY
The AF family requested is not supported.
EAI_FAIL
A non-recoverable error occurred.
EAI_INPROGRESS
Request is in progress.
EAI_INTR
Interrupted by a signal.
EAI_MEMORY
Memory allocation failure.
EAI_NONAME
Neither nodename nor servname provided, or not known.
EAI_OVERFLOW
The result is too large to fit in the supplied buffer.
EAI_PROTOCOL
A protocol error occurred.
EAI_SOCKTYPE
The socket type is not supported.
EAI_SYSTEM
System error occurred.

In addition, getaddrinfo_a() and gai_suspend() may return POSIX error codes.

EXAMPLES

Two examples are provided: a simple example that resolves several requests in parallel synchronously, and a complex example showing some of the asynchronous capabilities.

Synchronous example

The program below simply resolves several hostnames in parallel, giving a speed-up compared to resolving the hostnames sequentially using getaddrinfo(3). The program might be used like this:


$ ./a.out mirrors.kernel.org enoent.linuxfoundation.org gnu.org;
mirrors.kernel.org: 139.178.88.99
enoent.linuxfoundation.org: Name or service not known
gnu.org: 209.51.188.116

Here is the program source code

#define _GNU_SOURCE
#include <err.h>
#include <netdb.h>
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#define MALLOC(n, type)  ((type *) reallocarray(NULL, n, sizeof(type)))
int
main(int argc, char *argv[])
{
    int ret;
    struct gaicb *reqs[argc - 1];
    char host[NI_MAXHOST];
    struct addrinfo *res;
    if (argc < 2) {
        fprintf(stderr, "Usage: %s HOST...\n", argv[0]);
        exit(EXIT_FAILURE);
    }
    for (size_t i = 0; i < argc - 1; i++) {
        reqs[i] = MALLOC(1, struct gaicb);
        if (reqs[i] == NULL)
            err(EXIT_FAILURE, "malloc");
        memset(reqs[i], 0, sizeof(*reqs[0]));
        reqs[i]->ar_name = argv[i + 1];
    }
    ret = getaddrinfo_a(GAI_WAIT, reqs, argc - 1, NULL);
    if (ret != 0) {
        fprintf(stderr, "getaddrinfo_a() failed: %s\n",
                gai_strerror(ret));
        exit(EXIT_FAILURE);
    }
    for (size_t i = 0; i < argc - 1; i++) {
        printf("%s: ", reqs[i]->ar_name);
        ret = gai_error(reqs[i]);
        if (ret == 0) {
            res = reqs[i]->ar_result;
            ret = getnameinfo(res->ai_addr, res->ai_addrlen,
                              host, sizeof(host),
                              NULL, 0, NI_NUMERICHOST);
            if (ret != 0) {
                fprintf(stderr, "getnameinfo() failed: %s\n",
                        gai_strerror(ret));
                exit(EXIT_FAILURE);
            }
            puts(host);
        } else {
            puts(gai_strerror(ret));
        }
    }
    exit(EXIT_SUCCESS);
}

Asynchronous example

This example shows a simple interactive getaddrinfo_a() front-end. The notification facility is not demonstrated.

An example session might look like this:


$ ./a.out;
> a mirrors.kernel.org enoent.linuxfoundation.org gnu.org
> c 2
[2] gnu.org: Request not canceled
> w 0 1
[00] mirrors.kernel.org: Finished
> l
[00] mirrors.kernel.org: 139.178.88.99
[01] enoent.linuxfoundation.org: Processing request in progress
[02] gnu.org: 209.51.188.116
> l
[00] mirrors.kernel.org: 139.178.88.99
[01] enoent.linuxfoundation.org: Name or service not known
[02] gnu.org: 209.51.188.116

The program source is as follows:

#define _GNU_SOURCE
#include <assert.h>
#include <err.h>
#include <netdb.h>
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#define CALLOC(n, type)  ((type *) calloc(n, sizeof(type)))
#define REALLOCF(ptr, n, type)                                          \
({                                                                      \
    static_assert(__builtin_types_compatible_p(typeof(ptr), type *));   \
                                                                        \
    (type *) reallocarrayf(ptr, n, sizeof(type));                       \
})
static struct gaicb **reqs = NULL;
static size_t nreqs = 0;
static inline void *
reallocarrayf(void *p, size_t n, size_t size)
{
    void  *q;
    q = reallocarray(p, n, size);
    if (q == NULL && n != 0 && size != 0)
        free(p);
    return q;
}
static char *
getcmd(void)
{
    static char buf[256];
    fputs("> ", stdout);
    fflush(stdout);
    if (fgets(buf, sizeof(buf), stdin) == NULL)
        return NULL;
    if (buf[strlen(buf) - 1] == '\n')
        buf[strlen(buf) - 1] = 0;
    return buf;
}
/* Add requests for specified hostnames.  */
static void
add_requests(void)
{
    size_t nreqs_base = nreqs;
    char *host;
    int ret;
    while ((host = strtok(NULL, " "))) {
        nreqs++;
        reqs = REALLOCF(reqs, nreqs, struct gaicb *);
        if (reqs == NULL)
            err(EXIT_FAILURE, "reallocf");
        reqs[nreqs - 1] = CALLOC(1, struct gaicb);
        if (reqs[nreqs - 1] == NULL)
            err(EXIT_FAILURE, "calloc");
        reqs[nreqs - 1]->ar_name = strdup(host);
    }
    /* Queue nreqs_base..nreqs requests.  */
    ret = getaddrinfo_a(GAI_NOWAIT, &reqs[nreqs_base],
                        nreqs - nreqs_base, NULL);
    if (ret) {
        fprintf(stderr, "getaddrinfo_a() failed: %s\n",
                gai_strerror(ret));
        exit(EXIT_FAILURE);
    }
}
/* Wait until at least one of specified requests completes.  */
static void
wait_requests(void)
{
    char *id;
    int ret;
    size_t n;
    struct gaicb const **wait_reqs;
    wait_reqs = CALLOC(nreqs, const struct gaicb *);
    if (wait_reqs == NULL)
        err(EXIT_FAILURE, "calloc");
                /* NULL elements are ignored by gai_suspend().  */
    while ((id = strtok(NULL, " ")) != NULL) {
        n = atoi(id);
        if (n >= nreqs) {
            printf("Bad request number: %s\n", id);
            return;
        }
        wait_reqs[n] = reqs[n];
    }
    ret = gai_suspend(wait_reqs, nreqs, NULL);
    if (ret) {
        printf("gai_suspend(): %s\n", gai_strerror(ret));
        return;
    }
    for (size_t i = 0; i < nreqs; i++) {
        if (wait_reqs[i] == NULL)
            continue;
        ret = gai_error(reqs[i]);
        if (ret == EAI_INPROGRESS)
            continue;
        printf("[%02zu] %s: %s\n", i, reqs[i]->ar_name,
               ret == 0 ? "Finished" : gai_strerror(ret));
    }
}
/* Cancel specified requests.  */
static void
cancel_requests(void)
{
    char *id;
    int ret;
    size_t n;
    while ((id = strtok(NULL, " ")) != NULL) {
        n = atoi(id);
        if (n >= nreqs) {
            printf("Bad request number: %s\n", id);
            return;
        }
        ret = gai_cancel(reqs[n]);
        printf("[%s] %s: %s\n", id, reqs[atoi(id)]->ar_name,
               gai_strerror(ret));
    }
}
/* List all requests.  */
static void
list_requests(void)
{
    int ret;
    char host[NI_MAXHOST];
    struct addrinfo *res;
    for (size_t i = 0; i < nreqs; i++) {
        printf("[%02zu] %s: ", i, reqs[i]->ar_name);
        ret = gai_error(reqs[i]);
        if (!ret) {
            res = reqs[i]->ar_result;
            ret = getnameinfo(res->ai_addr, res->ai_addrlen,
                              host, sizeof(host),
                              NULL, 0, NI_NUMERICHOST);
            if (ret) {
                fprintf(stderr, "getnameinfo() failed: %s\n",
                        gai_strerror(ret));
                exit(EXIT_FAILURE);
            }
            puts(host);
        } else {
            puts(gai_strerror(ret));
        }
    }
}
int
main(void)
{
    char *cmdline;
    char *cmd;
    while ((cmdline = getcmd()) != NULL) {
        cmd = strtok(cmdline, " ");
        if (cmd == NULL) {
            list_requests();
        } else {
            switch (cmd[0]) {
            case 'a':
                add_requests();
                break;
            case 'w':
                wait_requests();
                break;
            case 'c':
                cancel_requests();
                break;
            case 'l':
                list_requests();
                break;
            default:
                fprintf(stderr, "Bad command: %c\n", cmd[0]);
                break;
            }
        }
    }
    exit(EXIT_SUCCESS);
}
