getxattr(2) Manual de llamadas al sistema getxattr(2)

NOMBRE

getxattr, lgetxattr, fgetxattr - recuperar el valor de un atributo extendido

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <sys/xattr.h>
ssize_t getxattr(size_t size;
                 const char *path, const char *name,
                 void value[size], size_t size);
ssize_t lgetxattr(size_t size;
                 const char *path, const char *name,
                 void value[size], size_t size);
ssize_t fgetxattr(size_t size;
                 int fd, const char *name,
                 void value[size], size_t size);

DESCRIPCIÓN

Los atributos extendidos son pares de nombre:valor asociados con inodos (archivos, directorios, enlaces simbólicos, etc.). Son extensiones de los atributos normales que están asociados con todos los inodos del sistema (es decir, los datos de stat(2)). Se puede encontrar una descripción completa de los conceptos de atributos extendidos en xattr(7).

getxattr() recupera el valor del atributo extendido identificado por name y asociado con la ruta path dada en el sistema de archivos. El valor del atributo se coloca en el búfer apuntado por value; size especifica el tamaño de dicho búfer. El valor de retorno de la llamada es el número de bytes colocados en value.

lgetxattr() es idéntico a getxattr(), excepto en el caso de un enlace simbólico, donde se interroga el enlace en sí, no el archivo al que apunta.

fgetxattr() es idéntico a getxattr(), solo se interroga el archivo abierto al que se refiere fd (como lo devuelve open(2)) en lugar de path.

Un nombre de atributo extendido es una cadena terminada en nulo. El nombre incluye un prefijo de espacio de nombres; puede haber varios espacios de nombres, disjuntos, asociados con un inodo individual. El valor de un atributo extendido es un fragmento de datos textuales o binarios arbitrarios que se asignó utilizando setxattr(2).

Si size se especifica como cero, estas llamadas devuelven el tamaño actual del atributo extendido con nombre (y dejan value sin cambios). Esto se puede utilizar para determinar el tamaño del búfer que debe proporcionarse en una llamada posterior. (Pero, tenga en cuenta que existe la posibilidad de que el valor del atributo cambie entre las dos llamadas, por lo que todavía es necesario verificar el estado de retorno de la segunda llamada.)

VALOR DE RETORNO

En caso de éxito, estas llamadas devuelven un valor no negativo que es el tamaño (en bytes) del valor del atributo extendido. En caso de error, se devuelve -1 y se establece errno para indicar el error.

ERRORES

E2BIG
El tamaño del valor del atributo es mayor que el tamaño máximo permitido; el atributo no se puede recuperar. Esto puede suceder en sistemas de archivos que admiten valores de atributos muy grandes, como NFSv4, por ejemplo.
ENODATA
El atributo nombrado no existe, o el proceso no tiene acceso a este atributo.
ENOTSUP
Los atributos extendidos no son compatibles con el sistema de archivos o están deshabilitados.
ERANGE
El tamaño del búfer value es demasiado pequeño para contener el resultado.

Además, también pueden ocurrir los errores documentados en stat(2).

ESTANDARES

Linux.

HISTORIA

Linux 2.4, glibc 2.3.
