GENCNVAL(1) Manual de ICU 78.1 GENCNVAL(1)

NOMBRE

gencnval - compilar el archivo de alias de conversores

SINOPSIS

gencnval [ -h, -?, --help ] [ -v, --verbose ] [ -c, --copyright ] [ -s, --sourcedir fuente ] [ -d, --destdir destino ] [ archivo_conversores ]

DESCRIPCIÓN

gencnval convierte el archivo de alias de ICU archivo_conversores en el archivo binario cnvalias.icu. Este archivo binario puede ser leído directamente por ICU, o utilizado por pkgdata(1) para su incorporación en un archivo o biblioteca más grande.

Si no se proporciona archivo_conversores, se utiliza el archivo predeterminado de ICU convrtrs.txt.

OPCIONES

-h, -?, --help
Imprime ayuda sobre el uso y sale.
-v, --verbose
Muestra salida detallada. Esta información puede incluir detalles sobre alias en conflicto y los conversores a los que resuelven los alias.
-c, --copyright
Incluye un aviso de copyright en los datos binarios.
-s, --sourcedir fuente
Establece el directorio fuente a fuente. El directorio fuente predeterminado se especifica por la variable de entorno ICU_DATA.
-d, --destdir destino
Establece el directorio de destino a destino. El directorio de destino predeterminado se especifica por la variable de entorno ICU_DATA.

ENTORNO

ICU_DATA
Especifica el directorio que contiene los datos de ICU. Por defecto es ${prefix}/share/icu/78.1/. Algunas herramientas en ICU dependen de la presencia de la barra inclinada final. Por lo tanto, es importante asegurarse de que esté presente si se establece ICU_DATA.

ARCHIVOS

icu/source/data/mappings/convrtrs.txt
Descripción de los conversores de ICU y sus alias. Este archivo de datos normalmente no se instala y está disponible como parte del código fuente de ICU.
