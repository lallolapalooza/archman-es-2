NOMBRE

getds - Crea un registro DS a partir de información de claves DNS

SINOPSIS

getds <dominio>

DESCRIPCIÓN

getds creará un registro DS a partir de las claves DNS para el dominio DNS especificado. Lo hace convirtiendo las claves DNS en registros DS utilizando el algoritmo de hash especificado. Los resultados pueden ser pasados a padres que soporten DNSSEC o a registros DLV.

getds también obtendrá los registros DS publicados del padre y los comparará con las claves existentes. Luego listará cualquier registro DS que no esté publicado en el padre, así como cualquier registro DS que esté publicado en el padre pero que no coincida con una clave existente.

OPCIONES

getds acepta las siguientes opciones:

-a ALGORITMOS
--algoritmo-hash algoritmo ALGORITMOS
Esta opción especifica el algoritmo de hash a utilizar al convertir las claves DNS en registros DS. Puede ser una lista separada por comas si se desean múltiples algoritmos. Los algoritmos a elegir pueden ser SHA256 o SHA1.

El valor predeterminado es SHA256,SHA1

-f ARCHIVO_CLAVE
--leer-archivo-clave ARCHIVO_CLAVE
Esta opción especifica un archivo con una clave DNS almacenada en él (como la creada por el programa dnssec-keygen de bind). Esto es útil para comparar un archivo de clave conocido como bueno con algo que esté realmente publicado.
-z
--imprimir-zsk
Esta opción hace que getds imprima los registros DS ZSK, así como los registros KSK.
-p
--no-comprobar-padre
Instruye a getds para que no compruebe los registros en el padre por sus registros DS publicados.
-q
--silencioso
Produce una salida silenciosa sin encabezados explicativos. En otras palabras, solo imprime los registros DS generados a partir de las claves DNS.

Nota: Ejecutar con -q implica -p.

CONSIDERACIONES DE SEGURIDAD

Por defecto, getds obtiene datos del DNS en vivo. Si su resolver DNS no está configurado para que esto se obtenga de forma segura, entonces los resultados no se pueden confiar.
