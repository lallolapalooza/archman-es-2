getdns_dict_get_data_type(3)

Paquete: getdns

Licencias: BSD

getdns_dict_get(3) getdns getdns_dict_get(3)

NOMBRE

getdns_dict_get, getdns_dict_get_bindata, getdns_dict_get_data_type, getdns_dict_get_dict, getdns_dict_get_int, getdns_dict_get_list, getdns_dict_get_names -- obtener valor por nombre de un diccionario getdns

BIBLIOTECA

Biblioteca de resolución DNS (libgetdns, -lgetdns)

SINOPSIS

#include <getdns.h>

getdns_return_t
getdns_dict_get_bindata (getdns_dict *this_dict,

char *name,
getdns_bindata **answer)

getdns_return_t
getdns_dict_get_data_type (getdns_dict *this_dict,

char *name,
getdns_data_type *answer)

getdns_return_t
getdns_dict_get_dict (getdns_dict *this_dict,

char *name,
getdns_dict **answer)

getdns_return_t
getdns_dict_get_int (getdns_dict *this_dict,

char *name,
uint32_t *answer)

getdns_return_t
getdns_dict_get_list (getdns_dict *this_dict,

char *name,
getdns_list **answer)

getdns_return_t
getdns_dict_get_names (getdns_dict *this_dict,

getdns_list **answer)

DESCRIPCIÓN

El tipo getdns_dict se utiliza para gestionar pares nombre/valor en los que los nombres son cadenas y los tipos de datos de los valores son heterogéneos e incluyen


getdns_bindata
getdns_dict
getdns_list
uint32_t

this_dict el diccionario del que se recuperará la lista de nombres

name el nombre cuyo valor asociado se devolverá en answer

answer la lista de todos los nombres del diccionario, tenga en cuenta que el llamador debe liberar el almacenamiento asignado a la lista mediante una llamada a getdns_list_destroy(3)

VALORES DE RETORNO

Al completarse con éxito, las funciones devuelven GETDNS_RETURN_GOOD, de lo contrario, se devuelven los siguientes valores de error:

GETDNS_RETURN_GENERIC_ERROR si this_dict no es un diccionario válido

GETDNS_RETURN_NO_SUCH_DICT_NAME si el argumento name no existe en el diccionario

GETDNS_RETURN_WRONG_TYPE_REQUESTED si el tipo de dato solicitado no coincide con el contenido del argumento indexado o el nombre
