NOMBRE

getrpcport — obtener el número de puerto RPC

SINOPSIS

int
getrpcport(char *host, int prognum, int versnum, int proto);

DESCRIPCIÓN

La función getrpcport() devuelve el número de puerto para la versión versnum del programa RPC prognum que se ejecuta en host y utiliza el protocolo proto. Devuelve 0 si no puede contactar al portmapper, o si prognum no está registrado. Si prognum está registrado pero no con la versión versnum, aún devolverá un número de puerto (para alguna versión del programa) indicando que el programa está efectivamente registrado. La discrepancia de versión se detectará en la primera llamada al servicio.

DISPONIBILIDAD

La función getrpcport() forma parte de libtirpc.
