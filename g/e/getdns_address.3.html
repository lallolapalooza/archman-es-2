getdns_address(3)

Paquete: getdns

Licencias: BSD

getdns_address(3) getdns getdns_address(3)

NOMBRE

getdns_address, getdns_address_sync -- obtener la(s) dirección(es) IP de un nombre

BIBLIOTECA

Biblioteca del resolvedor DNS (libgetdns, -lgetdns)

SINOPSIS

#include <getdns.h>

getdns_return_t
getdns_address (getdns_context *context,

const char *name,
getdns_dict *extensions,
void *userarg,
getdns_transaction_t *transaction_id,
getdns_callback_t callbackfn)

getdns_return_t
getdns_address_sync (getdns_context *context,

const char *name,
getdns_dict *extensions,
getdns_dict **response)

DESCRIPCIÓN

Las funciones getdns_address(3) y getdns_address_sync proporcionan puntos de entrada públicos a la biblioteca API de getdns para recuperar la dirección dada un nombre de host. Siempre devuelven direcciones IPv4 e IPv6. Esta función utilizará todos los espacios de nombres del contexto (para emular mejor getaddrinfo (3)).

context Un puntero al contexto DNS creado previamente que se va a utilizar con esta solicitud DNS. Ver getdns_context (3)

name el nombre de host a resolver a una dirección (tenga en cuenta que una dirección IP se considera inválida)

extensions extensiones para esta solicitud, NULL si no hay extensiones, ver libgetdns (3) para una descripción detallada de las extensiones

userarg devuelto a la función de callback sin modificar, puede ser NULL

transaction_id poblado por la API y utilizado para identificar el callback (por ejemplo, para getdns_cancel_callback), puede ser NULL, establecido en 0 si la función falla

callbackfn puntero no NULL a una función de callback definida por la aplicación, utilizada típicamente para procesar la respuesta. Solo la firma asíncrona acepta una función de callback, la firma síncrona no incluye un callback. Ver libgetdns (3) para una discusión más detallada de las funciones de callback.

response Se devuelve un tipo getdns_dict en respuesta y siempre contiene al menos tres nombres: replies_full (una lista que contiene la respuesta DNS como datos binarios), replies_tree (una lista que contiene los datos analizados de la respuesta DNS) y status (un entero). El almacenamiento asociado a esto debe liberarse mediante una llamada a getdns_free_sync_request_memory (3).

VALORES DE RETORNO

Al completarse con éxito, las funciones devuelven GETDNS_RETURN_GOOD, de lo contrario, se devuelven los siguientes valores de error:

GETDNS_RETURN_BAD_CONTEXT si el puntero de contexto es inválido o si el contexto tiene deficiencias internas

GETDNS_RETURN_BAD_DOMAIN_NAME si el nombre de dominio pasado a la función es inválido

GETDNS_RETURN_EXTENSION_MISFORMAT si el tipo de datos especificado en una o más extensiones no coincide con las especificaciones

GETDNS_RETURN_GENERIC_ERROR si se encontró algún problema en la función que no está abordado por uno de los códigos de retorno más específicos

GETDNS_RETURN_INVALID PARAMETER si uno o más parámetros tienen un valor inválido

GETDNS_RETURN_MEMORY_ERROR si no se puede asignar la memoria requerida

GETDNS_RETURN_NO_SUCH_EXTENSION si una o más de las cadenas especificadas en las extensiones no son válidas

Los valores de estado incluidos en el parámetro de respuesta son:

GETDNS_RESPSTATUS_GOOD si se devolvió al menos una respuesta

GETDNS_RESPSTATUS_NO_NAME si las consultas para el nombre produjeron todas respuestas negativas

GETDNS_RESPSTATUS_ALL_TIMEOUT si todas las consultas para el nombre expiraron

GETDNS_RESPSTATUS_NO_SECURE_ANSWERS si solo se aceptaron respuestas seguras (según el contexto) y se recibió al menos una respuesta, pero ninguna respuesta DNS fue segura a través de DNSSEC

Para una explicación más detallada del objeto de respuesta, ver libgetdns (3)
