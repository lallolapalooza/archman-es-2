Enlace a -lgearman

DESCRIPCIÓN

Instala callbacks para la asignación personalizada.

Normalmente malloc(3) y free(3) se utilizan para la asignación y liberación de cargas de trabajo. Puedes usar gearman_client_set_memory_allocators() y gearman_worker_set_memory_allocators() para establecer tus propios asignadores personalizados.
