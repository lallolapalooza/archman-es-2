DESCRIPCIÓ

N

gearman_worker_st se utiliza para la comunicación del trabajador con el

servidor.

gearman_worker_context() y gearman_worker_set_context() se pueden utilizar para almacenar un objeto arbitrario para el

usuario.

gearman_worker_set_task_context_free_fn() establece un disparador que se llamará cuando un gearman_task_st sea

liberado.

gearman_worker_timeout() y gearman_worker_set_timeout() obtienen y establecen el valor de tiempo de espera actual, en milisegundos, para el

trabajador.

gearman_worker_function_exist() se utiliza para determinar si un trabajador dado tiene una función

específica.

gearman_worker_work() hace que el trabajador ejecute trabajos hasta que ocurra un

error.

gearman_worker_grab_job() Toma un trabajo de uno de los servidores de trabajos. Es responsabilidad del llamador liberar el trabajo una vez que haya terminado. Esta interfaz se utiliza en pruebas, y rara vez es la interfaz correcta para

programar.

Normalmente malloc(3) y free(3) se utilizan para la asignación y liberación de cargas de trabajo. gearman_worker_set_workload_malloc_fn() y gearman_worker_set_workload_free_fn() se pueden utilizar para reemplazar estas con funciones

personalizadas.

Si necesita eliminar una función del servidor, puede llamar a gearman_worker_unregister_all() para eliminar todas las funciones que el trabajador ha informado al servidor gearmand, o puede usar gearman_worker_unregister() pa

ra eliminar so
lo una función.
