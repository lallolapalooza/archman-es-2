gensio_accepter_event(3) Manual de funciones de biblioteca gensio_accepter_event(3)

NOMBRE

gensio_accepter_event - Manejador de eventos para eventos de un gensio

SINOPSIS

#include <gensio/gensio.h>

typedef int (*gensio_accepter_event)(struct gensio_accepter *acc,

void *user_data,
int event, void *data);

DESCRIPCIÓN

Cuando ocurre un evento en un aceptador de gensio que se informa al usuario, la biblioteca gensio llama al manejador de tipo gensio_accepter_event que se registró con el aceptador de gensio.

El uso de los diversos parámetros depende del evento particular. Los parámetros que no varían son:

acc
- El gensio_accepter para el que se está informando el evento.
user_data
- Los datos de usuario proporcionados al registrar el manejador de eventos.
event
- El evento particular que se está informando.
data
- Datos específicos del evento (puede que no se utilicen).

Eventos a continuación.

GENSIO_ACC_EVENT_NEW_CONNECTION

Se recibió una nueva conexión en el aceptador. data apunta al nuevo gensio.

GENSIO_ACC_EVENT_LOG

struct gensio_loginfo {
enum gensio_log_levels level;
char *str;
va_list args;
};

El aceptador de gensio tuvo un problema que de otra manera no se informaría como un error de retorno. data apunta a una struct gensio_loginfo.

GENSIO_ACC_EVENT_PRECERT_VERIFY

Se llama justo antes de la verificación del certificado en una nueva conexión entrante. Ver GENSIO_EVENT_PRECERT_VERIFY en gensio_event(3) para más detalles. data apunta al nuevo objeto gensio. Tenga en cuenta que este gensio aún no ha sido informado en una nueva conexión.

GENSIO_ACC_EVENT_AUTH_BEGIN

Se llama al inicio de un proceso de autorización para una nueva conexión. Ver GENSIO_EVENT_AUTH_BEGIN en gensio_event(3) para más detalles. data apunta al nuevo objeto gensio. Tenga en cuenta que este gensio aún no ha sido informado en una nueva conexión.

GENSIO_ACC_EVENT_PASSWORD_VERIFY

struct gensio_acc_password_verify_data {
struct gensio *io;
char *password;
gensiods password_len;
};

Un gensio de servidor ha recibido una contraseña que requiere verificación. Los manejadores de gensio no verifican realmente las contraseñas, las transfieren y las proporcionan para que el usuario las verifique. data apunta a una struct gensio_acc_password_verify_data que contiene el nuevo gensio y la información de la contraseña. Ver GENSIO_EVENT_PASSWORD_VERIFY en gensio_event(3) para más detalles.

GENSIO_ACC_EVENT_REQUEST_PASSWORD

Un gensio de servidor remoto ha solicitado que se envíe una contraseña para verificación. data apunta a una struct gensio_acc_password_verify_data que contiene el nuevo gensio y la información de la contraseña. Ver GENSIO_EVENT_REQUEST_PASSWORD en gensio_event(3) para más detalles.

GENSIO_ACC_EVENT_POSTCERT_VERIFY

struct gensio_acc_postcert_verify_data {
struct gensio *io;
int err;
const char *errstr;
};

Un gensio de servidor ha finalizado la verificación del certificado (y no ha realizado ninguna verificación de contraseña). data apunta a una struct gensio_acc_postcert_verify_data que contiene el nuevo gensio y la información de error. Ver GENSIO_EVENT_POSTCERT_VERIFY en gensio_event(3) para más detalles.

OTROS EVENTOS

Otros aceptadores de gensio que no forman parte de la biblioteca gensio propiamente dicha pueden tener sus propios eventos también.

VALORES DE RETORNO

Consulte los eventos individuales para los valores que debe devolver. Si un evento no es manejado por el manejador de eventos, el manejador debe devolver GE_NOTSUP, excepto en el caso de GENSIO_ACC_EVENT_NEW_CONNECTION que debe ser manejado.
