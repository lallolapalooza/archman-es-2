get_phys_pages(3) Manual de funciones de biblioteca get_phys_pages(3)

NOMBRE

get_phys_pages, get_avphys_pages - obtener recuentos de páginas físicas totales y disponibles

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <sys/sysinfo.h>
long get_phys_pages(void);
long get_avphys_pages(void);

DESCRIPCIÓN

La función get_phys_pages() devuelve el número total de páginas físicas de memoria disponibles en el sistema.

La función get_avphys_pages() devuelve el número de páginas físicas de memoria actualmente disponibles en el sistema.

VALOR DE RETORNO

En caso de éxito, estas funciones devuelven un valor no negativo tal como se indica en DESCRIPCIÓN. En caso de error, devuelven -1 y establecen errno para indicar el error.

ERRORES

ENOSYS
El sistema no pudo proporcionar la información requerida (posiblemente porque el sistema de archivos /proc no estaba montado).

ESTÁNDARES

GNU.

HISTORIA

Antes de glibc 2.23, estas funciones obtenían la información requerida escaneando los campos MemTotal y MemFree de /proc/meminfo. Desde glibc 2.23, estas funciones obtienen la información requerida llamando a sysinfo(2).

NOTAS

Las siguientes llamadas a sysconf(3) proporcionan un medio portátil para obtener la misma información que las funciones descritas en esta página.


total_pages = sysconf(_SC_PHYS_PAGES);    /* páginas totales */
avl_pages = sysconf(_SC_AVPHYS_PAGES);    /* páginas disponibles */

EJEMPLOS

El siguiente ejemplo muestra cómo se pueden utilizar get_phys_pages() y get_avphys_pages().

#include <stdio.h>
#include <stdlib.h>
#include <sys/sysinfo.h>
int
main(void)
{
    printf("Este sistema tiene %ld páginas de memoria física y "
            "%ld páginas de memoria física disponibles.\n",
            get_phys_pages(), get_avphys_pages());
    exit(EXIT_SUCCESS);
}
