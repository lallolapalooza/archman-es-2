DESCRIPCIÓ

N

La función getgrnam() devuelve un puntero a una estructura que contiene los campos desglosados del registro en la base de datos de grupos (por ejemplo, el archivo de grupos local /etc/group, NIS y LDAP) que coincide con el nombre de grupo name

.

La función getgrgid() devuelve un puntero a una estructura que contiene los campos desglosados del registro en la base de datos de grupos que coincide con el ID de grupo gid

.

La estructura group está definida en <grp.h> como

sigue: 


struct group {
    char   *gr_name;        /* group name */
    char   *gr_passwd;      /* group password */
    gid_t   gr_gid;         /* group ID */
    char  **gr_mem;         /* NULL-terminated array of pointers
                               to names of group members */
}
;

Para más información sobre los campos de esta estructura, véase group(

5).

Las funciones getgrnam_r() y getgrgid_r() obtienen la misma información que getgrnam() y getgrgid(), pero almacenan la estructura group recuperada en el espacio apuntado por grp. Los campos de cadena apuntados por los miembros de la estructura group se almacenan en el búfer buf de tamaño size. Un puntero al resultado (en caso de éxito) o NULL (en caso de que no se encontrara ninguna entrada o se produjera un error) se almacena en *result

.

La

llamada 


sysconf(_SC_GETGR_R_SIZE_MAX
)

devuelve -1 sin cambiar errno, o un tamaño inicial sugerido para buf. (Si este tamaño es demasiado pequeño, la llamada falla con ERANGE, en cuyo caso el llamante puede

reintentarlo con un
búfer más grande.)

VALOR DE

RETORNO

Las funciones getgrnam() y getgrgid() devuelven un puntero a una estructura group, o NULL si no se encuentra la entrada coincidente o se produce un error. Si se produce un error, errno se establece para indicar el error. Si se desea comprobar errno después de la llamada, debería establecerse a cero antes de la

misma.

El valor de retorno puede apuntar a un área estática y puede ser sobrescrito por llamadas posteriores a getgrent(3), getgrgid() o getgrnam(). (No pase el puntero devuelto a free(3).

)

En caso de éxito, getgrnam_r() y getgrgid_r() devuelven cero y establecen *result en grp. Si no se encontró ningún registro de grupo coincidente, estas funciones devuelven 0 y almacenan NULL en *result. En caso de error, se devuelve un número de error y se almacena NULL en *res

t.

VERSIONE

S

La formulación dada arriba en "VALOR DE RETORNO" proviene de POSIX.1. No considera "no encontrado" como un error, por lo que no especifica qué valor podría tener errno en esta situación. Pero eso hace imposible reconocer los errores. Podría argumentarse que, según POSIX, errno debería dejarse sin cambios si no se encuentra una entrada. Experimentos en varios sistemas tipo UNIX muestran que

ocurren muchos valores diferentes en esta situación: 0, ENO
ENT, EBADF, ESRCH, EWOULDBLOCK, EPERM y probablemente otros.
