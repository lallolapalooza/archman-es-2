DESCRIPCIÓ

N

Estas funciones se utilizan para manipular un contexto previamente asignado e inicializado; consulte getdns_context (3) para obtener más detalles sobre las funciones utilizadas para asignar, inicializar y destruir contextos, y para una discusión más detallada de getdns_context
en general.

getdns_context_set_append_name
Especifica si se debe añadir un sufijo proporcionado mediante getdns_context_set_suffix (3) a la cadena de consulta antes de que la API comience a resolver un

nombre.
getdns_context_set_context_update_callba
ck

establece una función que se llamará si se producen cambios en los archivos del sistema (por ejemplo, /etc/resolv.conf y /etc/hosts).
getdns_context_set_dns_transpor

t
especifica el transporte utilizado para las búsquedas DNS; el valor predeterminado es usar UDP y volver a TCP según sea
necesario.

getdns_context_set_dnssec_trust_anchors
permite al llamador especificar anclas de confianza como alternativas a las anclas de confianza

predeterminadas.

getdns_context_set_dnssec_allowed_ske
w

establece el número de segundos de desviación permitidos en cualquier dirección al comprobar los campos de expiración e inicio de un RRSIG; el valor predeterminado es 0.
getdns_context_set_limit_outstanding_querie

s

especifica el número máximo de consultas DNS pendientes; la API encolará las consultas que superen este límite hasta que las consultas actuales sean respondidas y luego emitirá automáticamente las consultas
de la cola.

getdns_context_set_dns_root_servers
proporciona un conjunto alternativo de direcciones para buscar los dominios de nivel superior. El valor predeterminado (si no se llama a esta función) es la lista de servidores raíz de IANA (piense en esto como las pistas

raíz).

getdns_context_set_follow_redirects
especifica si las consultas DNS siguen o no las redirecciones (CNAME y DNAME); el comportamiento predeterminado es seguir las redirecciones y devolver el destino
final.

getdns_context_set_namespaces
establece los espacios de nombres que utilizará el resolutor; el valor predeterminado es DNS y luego los archivos locales. Las implementaciones futuras admitirán netbios, mdns y

nis.
getdns_context_set_resolution_ty
pe

especifica si las consultas DNS se realizan con búsquedas no recursivas o como un resolutor stub.

x
Añade sufijos a los nombres de dominio antes de ejecutar la búsqueda basándose en getdns_context_set_append_
name.

especifica el número de milisegundos que la API esperará una

el número máximo de consultas DNS concurrentes pendientes (sin respuesta); si se supera, la API encolará las consultas y las emitirá a medida que disminuya el número de consultas pendientes. Un valor de 0 indica que no hay

namespace

s

El array de espacios de nombres contiene una lista ordenada de espacios de nombres que se consultarán. Importante: esta configuración de contexto se ignora para las funciones getdns_general y getdns_general_sync; se usa para las demás funciones. Los valores son GETDNS_CONTEXT_NAMESPACE_DNS, GETDNS_CONTEXT_NAMESPACE_LOCALNAMES, GETDNS_CONTEXT_NAMESPACE_NETBIOS, GETDNS_CONTEXT_NAMESPACE_MDNS y GETDNS_CONTEXT_NAMESPACE_NIS. Cuando se realiza una búsqueda normal, la API realiza las búsquedas en el orden dado y se detiene cuando obtiene el primer resultado; un método diferente con el mismo resultado sería ejecutar las consultas en paralelo y devolver cuando se obtiene el primer resultado. Como las búsquedas pueden realizarse a través de diferentes mecanismos debido a los diferentes espacios de nombres, puede haber una fuga de información similar a la observada con getaddrinfo(). El valor predeterminado lo determina el SO. restype puede establecerse en GETDNS_CONTEXT_RECURSIVE (el valor predeterminado) o GETDNS_CONTEXT_STUB (requiere que el llamador especifique los reenviadores)

VALORES DE RETORNO

Al completarse correctamente, las funciones devuelven GETDNS_RETURN_GOOD , de lo contrario se devuelven los siguientes valores de error:

GETDNS_RETURN_BAD_CONTEXT si el puntero de contexto es inválido

GETDNS_RETURN_CONTEXT_UPDATE_FAIL si hubo un problema al actualizar el contexto
