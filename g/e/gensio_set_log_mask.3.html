gensio_set_log_mask(3)

Paquete: gensio

Licencias: GPL

gensio_set_log_mask(3) Manual de funciones de la biblioteca gensio_set_log_mask(3)

NOMBRE

gensio_set_log_mask, gensio_get_log_mask, gensio_log_level_to_str, - Registro y establecimiento de qué registros de gensio se pasan o se ignoran

SINOPSIS

#include <gensio/gensio.h>

void gensio_set_log_mask(unsigned int mask);
unsigned int gensio_get_log_mask(void);
const char *gensio_log_level_to_str(enum gensio_log_levels level);
void gensio_vlog(struct gensio_os_funcs *o,

enum gensio_log_levels level,
const char *str, va_list args);
void gensio_log(struct gensio_os_funcs *o,

enum gensio_log_levels level,
const char *str, ...);

DESCRIPCIÓN

La máscara de registro es una variable global en la biblioteca gensio que establece qué nivel de registros se entregan a través del puntero de función vlog en gensio_os_funcs. Los niveles de registro son:

GENSIO_LOG_FATAL GENSIO_LOG_ERR GENSIO_LOG_WARNING GENSIO_LOG_INFO GENSIO_LOG_DEBUG

con significados obvios. También existe:

GENSIO_LOG_MASK_ALL

que es una máscara de bits de todos los niveles de registro.

La máscara de registro predeterminada es (1 << GENSIO_LOG_FATAL | 1 << GENSIO_LOG_ERR). Establecer otros valores de registro puede ser útil para depurar problemas con gensios.

gensio_log_level_to_str convierte un nivel de registro en una representación de cadena de ese nivel.

gensio_vlog y gensio_log son las funciones utilizadas para generar registros. Estas son principalmente para uso dentro de la biblioteca gensio, aunque usted también puede usarlas si lo desea.
