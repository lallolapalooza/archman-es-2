NOMBRE

gethostlatency.bt - Muestra la latencia para las llamadas getaddrinfo/gethostbyname[2]. Utiliza bpftrace/eBPF.

SINOPSIS

gethostlatency.bt

DESCRIPCIÓN

Esto rastrea e imprime cuándo se llaman getaddrinfo(), gethostbyname() y gethostbyname2(), en todo el sistema, y muestra el PID responsable y el nombre del comando, la latencia de la llamada (duración) en milisegundos y la cadena del host.

Esta herramienta puede ser útil para identificar la latencia de DNS, al identificar qué búsquedas de nombres de host remotos fueron lentas y en qué medida.

Esta herramienta utiliza actualmente el rastreo dinámico de funciones y registros a nivel de usuario, y puede requerir modificaciones para que coincida con su software y arquitectura de procesador.

Dado que esto utiliza BPF, solo el usuario root puede usar esta herramienta.

REQUISITOS

CONFIG_BPF y bcc.

EJEMPLOS

Rastrea las búsquedas de host (getaddrinfo/gethostbyname[2]) en todo el sistema:
# gethostlatency.bt

CAMPOS

TIEMPO
Hora del comando (HH:MM:SS).
PID
ID del proceso del cliente que realiza la llamada.
COMM
Nombre del proceso (comando) del cliente que realiza la llamada.
LATms
Latencia de la llamada, en milisegundos.
HOST
Cadena del nombre de host: el objetivo de la búsqueda.

SOBRECARGA

La tasa de búsquedas debería ser relativamente baja, por lo que no se espera que la sobrecarga sea un problema.

FUENTE
