DESCRIPCIÓ

N

La función getnameinfo() traducirá una dirección de socket a un nombre de nodo y una ubicación de servicio, todo lo cual está definido como en freeaddrinf

o().

El argumento sa apunta a una estructura de dirección de socket que debe ser traducida. El argumento salen contiene la longitud de la dirección a la que apunta sa

.

Si la estructura de dirección de socket contiene una dirección IPv6 mapeada IPv4 o una dirección IPv6 compatible IPv4, la implementación extraerá la dirección IPv4 incrustada y buscará el nombre de nodo para esa dirección

IPv4.

Si la dirección es la dirección IPv6 no especificada ("::"), no se realizará ninguna búsqueda y el comportamiento será el mismo que cuando el nombre del nodo no se puede

localizar.

Si el argumento node no es NULL y el argumento nodelen no es cero, entonces el argumento node apunta a un búfer capaz de contener hasta nodelen bytes que recibe el nombre del nodo como una cadena terminada en nulo. Si el argumento node es NULL o el argumento nodelen es cero, el nombre del nodo no se devolverá. Si el nombre del nodo no se puede localizar, se devolverá la forma numérica de la dirección contenida en la estructura de dirección de socket a la que apunta el argumento sa en lugar de su

nombre.

Si el argumento service no es NULL y el argumento servicelen no es cero, entonces el argumento service apunta a un búfer capaz de contener hasta servicelen bytes que recibe el nombre del servicio como una cadena terminada en nulo. Si el argumento service es NULL o el argumento servicelen es cero, el nombre del servicio no se devolverá. Si el nombre del servicio no se puede localizar, se devolverá la forma numérica de la dirección del servicio (por ejemplo, su número de puerto) en lugar de su

nombre.

El argumento flags es un indicador que cambia las acciones predeterminadas de la función. De manera predeterminada, se devolverá el nombre de dominio completamente calificado (FQDN) del host,

pero:
*
Si el bit indicador NI_NOFQDN está establecido, solo se devolverá la porción del nombre de nodo del FQDN para hosts
locales.
*
Si el bit indicador NI_NUMERICHOST está establecido, se devolverá la forma numérica de la dirección contenida en la estructura de dirección de socket a la que apunta el argumento sa en lugar de su
nombre.
*
Si el bit indicador NI_NAMEREQD está establecido, se devolverá un error si el nombre del host no se puede
localizar.
*
Si el bit indicador NI_NUMERICSERV está establecido, se devolverá la forma numérica de la dirección del servicio (por ejemplo, su número de puerto) en lugar de su
nombre.
*
Si el bit indicador NI_NUMERICSCOPE está establecido, se devolverá la forma numérica del identificador de ámbito (por ejemplo, el índice de interfaz) en lugar de su nombre. Este indicador se ignorará si el argumento sa no es una dirección
IPv6.
*
Si el bit indicador NI_DGRAM está establecido, esto indica que el servi
cio es un servicio de datagramas (SOCK_DGRAM). El comportamiento predet
erminado asumirá que el servicio es un servicio de flujo (SOCK_STREAM).

RETORNO

Un valor de retorno cero para getnameinfo() indica una finalización exitosa; un valor de retorno distinto de cero indica un fallo. Los valores posibles para los fallos se enumeran en la sección

ERRORES.

Tras una finalización exitosa, getnameinfo() devolverá los nombres del nodo y del servicio, si se solicitaron, en los búferes proporcionados.

4".
