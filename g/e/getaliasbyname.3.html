setaliasent(3) Manual de funciones de biblioteca setaliasent(3)

NOMBRE

setaliasent, endaliasent, getaliasent, getaliasent_r, getaliasbyname, getaliasbyname_r - leer una entrada de alias

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <aliases.h>
void setaliasent(void);
void endaliasent(void);
struct aliasent *getaliasent(void);
int getaliasent_r(size_t size;
                     struct aliasent *restrict result,
                     char buffer[restrict size], size_t size,
                     struct aliasent **restrict res);
struct aliasent *getaliasbyname(const char *name);
int getaliasbyname_r(size_t size;
                     const char *restrict name,
                     struct aliasent *restrict result,
                     char buffer[restrict size], size_t size,
                     struct aliasent **restrict res);

DESCRIPCIÓN

Una de las bases de datos disponibles con el Name Service Switch (NSS) es la base de datos de alias, que contiene alias de correo. (Para saber qué bases de datos son compatibles, prueba getent --help.) Se proporcionan seis funciones para acceder a la base de datos de alias.

La función getaliasent() devuelve un puntero a una estructura que contiene la información del grupo de la base de datos de alias. La primera vez que se llama, devuelve la primera entrada; a partir de entonces, devuelve entradas sucesivas.

La función setaliasent() reinicia el puntero del archivo al principio de la base de datos de alias.

La función endaliasent() cierra la base de datos de alias.

getaliasent_r() es la versión reentrante de la función anterior. La estructura solicitada se almacena a través del primer argumento, pero el programador debe rellenar también los otros argumentos. No proporcionar suficiente espacio provoca el fallo de la función.

La función getaliasbyname() toma el argumento name y busca en la base de datos de alias. La entrada se devuelve como un puntero a una struct aliasent.

getaliasbyname_r() es la versión reentrante de la función anterior. La estructura solicitada se almacena a través del segundo argumento, pero el programador debe rellenar también los otros argumentos. No proporcionar suficiente espacio provoca el fallo de la función.

La struct aliasent se define en <aliases.h>:


struct aliasent {
    char    *alias_name;             /* nombre del alias */
    size_t   alias_members_len;
    char   **alias_members;          /* lista de nombres de alias */
    int      alias_local;
};

VALOR DE RETORNO

Las funciones getaliasent_r() y getaliasbyname_r() devuelven un valor distinto de cero en caso de error.

FICHEROS

La base de datos de alias por defecto es el archivo /etc/aliases. Esto se puede cambiar en el archivo /etc/nsswitch.conf.

ATRIBUTOS

EJEMPLOS

El siguiente ejemplo compila con gcc example.c -o example. Volcará todos los nombres en la base de datos de alias.

#include <aliases.h>
#include <errno.h>
#include <stdio.h>
#include <stdlib.h>
int
main(void)
{
    struct aliasent *al;
    setaliasent();
    for (;;) {
        al = getaliasent();
        if (al == NULL)
            break;
        printf("Nombre: %s\n", al->alias_name);
    }
    if (errno) {
        perror("lectura del alias");
        exit(EXIT_FAILURE);
    }
    endaliasent();
    exit(EXIT_SUCCESS);
}
