gensio_close(3)

Paquete: gensio

Licencias: GPL

gensio_close(3) Manual de funciones de biblioteca gensio_close(3)

NOMBRE

gensio_close, gensio_close_s, gensio_disable, gensio_free - Detener/liberar un gensio que está abierto

SINOPSIS

#include <gensio/gensio.h>

typedef void (*gensio_done)(struct gensio *io, void *close_data);
int gensio_close(struct gensio *io, gensio_done close_done,

void *close_data);
int gensio_close_s(struct gensio *io);
void gensio_disable(struct gensio *io);
void gensio_free(struct gensio *io);

gensio_close cierra un gensio abierto. Tenga en cuenta que la operación de cierre no está completa hasta que se llame a close_done(). Esto desactiva los descriptores de archivo internos y similares, pero no libera el gensio. Si el gensio es de conexión, generalmente puede volver a abrirlo. Si usa gensio_close antes de que se informe que la apertura se completó, los resultados (principalmente si se llama a la finalización de la apertura) no están definidos. Si se llama a la finalización de la apertura, se llamará antes que a la finalización del cierre.

gensio_close_s es como gensio_close, pero se bloquea hasta que la operación se complete. TENGA MUCHO CUIDADO CON ESTA FUNCIÓN. No la llame desde una devolución de llamada porque espera hasta que todas las operaciones en el gensio hayan finalizado, y estas no finalizarán hasta que la devolución de llamada regrese. Se producirá un interbloqueo si lo hace.

gensio_disable deshabilita la operación del gensio para que el cierre no genere ninguna transmisión de datos. ESTO ES PARA UN USO EXTREMADAMENTE LIMITADO. Esto no cerrará los descriptores de archivo ni deshabilitará la E/S, necesariamente, pero pondrá la pila de gensio en un estado donde la liberación no generará ninguna transmisión de datos al otro extremo. DEBE estar en un estado donde ninguna devolución de llamada se esté ejecutando o pueda ejecutarse. Esto es principalmente para permitir el cierre de una conexión SSL después de un fork. Si no tuviera esto, el cierre normal en un fork cerraría la conexión SSL también para el otro fork. Ver gensio(5) para detalles sobre el fork.

gensio_free libera los datos asociados con el gensio. Si está abierto, el gensio se cierra. Si llama a gensio_free después de gensio_close antes de que se llame a la devolución de llamada close_done, si se llama a close_done no está definido.

VALORES DE RETORNO

Se devuelve cero en caso de éxito, o un error de gensio en caso de fallo.

VER TAMBIÉN
