CGEMLQT

Propósito:

!>
!> CGEMLQT sobrescribe la matriz compleja general M-por-N C con
!>
!>                 SIDE = 'L'     SIDE = 'R'
!> TRANS = 'N':      Q C            C Q
!> TRANS = 'C':   Q**H C            C Q**H
!>
!> donde Q es una matriz unitaria compleja definida como el producto de K
!> reflectores elementales:
!>
!>       Q = H(1) H(2) . . . H(K) = I - V T V**H
!>
!> generada utilizando la representación compacta WY devuelta por CGELQT.
!>
!> Q es de orden M si SIDE = 'L' y de orden N si SIDE = 'R'.
!>

Parámetros

SIDE 
!>          SIDE es CHARACTER*1
!>          = 'L': aplicar Q o Q**H desde la Izquierda;
!>          = 'R': aplicar Q o Q**H desde la Derecha.
!>

TRANS

!>          TRANS es CHARACTER*1
!>          = 'N':  Sin transponer, aplicar Q;
!>          = 'C':  Transpuesta conjugada, aplicar Q**H.
!>

M

!>          M es INTEGER
!>          El número de filas de la matriz C. M >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz C. N >= 0.
!>

K

!>          K es INTEGER
!>          El número de reflectores elementales cuyo producto define
!>          la matriz Q.
!>          Si SIDE = 'L', M >= K >= 0;
!>          si SIDE = 'R', N >= K >= 0.
!>

MB

!>          MB es INTEGER
!>          El tamaño del bloque utilizado para el almacenamiento de T.  K >= MB >= 1.
!>          Este debe ser el mismo valor de MB utilizado para generar T
!>          en CGELQT.
!>

V

!>          V es un array COMPLEX, de dimensión
!>                               (LDV,M) si SIDE = 'L',
!>                               (LDV,N) si SIDE = 'R'
!>          La i-ésima fila debe contener el vector que define el
!>          reflector elemental H(i), para i = 1,2,...,k, tal como lo devuelve
!>          CGELQT en las primeras K filas de su argumento A.
!>

LDV

!>          LDV es INTEGER
!>          La dimensión principal del array V. LDV >= max(1,K).
!>

T

!>          T es un array COMPLEX, de dimensión (LDT,K)
!>          Los factores triangulares superiores de los reflectores de bloque
!>          devueltos por CGELQT, almacenados como una matriz MB-por-K.
!>

LDT

!>          LDT es INTEGER
!>          La dimensión principal del array T.  LDT >= MB.
!>

C

!>          C es un array COMPLEX, de dimensión (LDC,N)
!>          A la entrada, la matriz C de M-por-N.
!>          A la salida, C se sobrescribe con Q C, Q**H C, C Q**H o C Q.
!>

LDC

!>          LDC es INTEGER
!>          La dimensión principal del array C. LDC >= max(1,M).
!>

WORK

!>          WORK es un array COMPLEX. La dimensión de
!>          WORK es N*MB si SIDE = 'L', o M*MB si SIDE = 'R'.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>
