NOMBRE

genxs - Generador de serializadores Xml de Mono

SINOPSIS

genxs archivoConfiguracion [carpetaDestino]

DESCRIPCIÓN

genxs es una herramienta para generar lectores y escritores de serialización XML personalizados para clases.

archivoConfiguracion es un archivo de configuración que especifica varias informaciones, como la clase para la que generar el lector y escritor, el nombre y el espacio de nombres de las clases a generar, y una colección de hooks (ganchos) a aplicar. Usando hooks, es posible personalizar el comportamiento del serializador sin necesidad de modificar el archivo generado, por lo que puedes regenerarlo de forma segura si la clase fuente se modifica.

carpetaDestino especifica la carpeta donde se generarán los archivos.

NOTA: Esta herramienta solo se ejecuta en el tiempo de ejecución de Mono, ya que utiliza algunas clases internas no disponibles en otros tiempos de ejecución.

FORMATO DEL ARCHIVO DE CONFIGURACIÓN

El archivo de configuración es un documento xml basado en la siguiente gramática ("?" significa opcional, "*" 0 o más):

<configuration>
	<serializer class="nombre" assembly="nombre"> *
		<reader>nombre</reader> ?
		<writer>nombre</writer> ?
		<namespace>nombre</namespace> ?
		<outFileName>nombre</outFileName> ?
		<readerHooks> ?
			<hook ...> *
		</readerHooks>
		<writerHooks> ?
			<hook ...> *
		</writerHooks>
	</serializer>
</configuration>

Un archivo de configuración puede tener múltiples elementos "serializer", cada uno de los cuales especifica la clase para la que generar un serializador junto con varias opciones de generación. La clase fuente se especifica en los siguientes atributos:

*
class: nombre de la clase (incluyendo el espacio de nombres).
*
assembly: nombre del ensamblado. Puede incluir la ruta completa.

Las opciones de generación se especifican en elementos hijos:

*
reader: nombre de la clase lectora.
*
noReader: si es "true", no genera la clase lectora.
*
writer: nombre de la clase escritora.
*
baseSerializer: nombre de la clase base del serializador xml. Este elemento solo es para la versión 2.0.
*
implementation: nombre de la clase de implementación del serializador. Este elemento solo es para la versión 2.0.
*
noWriter: si es "true", no genera la clase escritora.
*
namespace: espacio de nombres de las clases lectoras y escritoras.
*
generateAsInternal: si es "true", genera las clases como internas.
*
outFileName: nombre del archivo generado.
*
readerHooks: una lista de hooks a aplicar al lector.
*
writerHooks: una lista de hooks a aplicar al escritor.

ESPECIFICACIÓN DE HOOKS

Usando hooks, puedes personalizar el comportamiento de lectores y escritores. Una especificación de hook sigue esta gramática:

<hook type="nombre">
	<select> ?
		<typeName>nombre</typeName> ?
		<typeAttribute>nombre</typeAttribute> *
		<typeMember>nombre</typeMember> ?
	</select>
	<replace>código fuente</replace> ?
	<insertBefore>código fuente</insertBefore> ?
	<insertAfter>código fuente</insertAfter> ?
</hook>

El atributo "type" especifica el contexto en el que se aplica el hook. Puede ser uno de los siguientes:

*
attributes: el hook se aplica donde se serializan/deserializan atributos.
*
elements: el hook se aplica donde se serializan/deserializan elementos.
*
unknownAttribute: el hook se aplica donde se procesan atributos desconocidos.
*
unknownElement: el hook se aplica donde se procesan elementos desconocidos.
*
member: el hook se aplica donde se serializa/deserializa un miembro.
*
type: el hook se aplica para todo el tipo.

El elemento "select" especifica las clases y miembros a los que se debe añadir el hook. Puede contener los siguientes elementos:

*
typeName: se seleccionará la clase con ese nombre (debe incluir el espacio de nombres)
*
typeAttribute: se seleccionarán todas las clases que tengan ese atributo aplicado (especificar el nombre completo de la clase del atributo, incluyendo el espacio de nombres). Se pueden especificar varios nombres de atributos.
*
typeMember: nombre del miembro de la clase para el cual se debe añadir el hook.

El código fuente del hook se puede especificar usando cualquiera de los siguientes elementos:

*
replace: el código fuente proporcionado reemplazará todas las operaciones de serialización/deserialización en el contexto del hook.
*
insertBefore: el código fuente se añadirá antes del contexto del hook.
*
insertAfter: el código fuente se añadirá después del contexto del hook.

Al escribir el código para un hook, puedes usar algunas variables especiales que se definen durante el proceso de generación de código. Las variables son las siguientes:

*
$TYPE: nombre de la clase que se está generando, sin espacio de nombres.
*
$FULLTYPE: nombre completo de la clase que se está generando, incluyendo el espacio de nombres.
*
$OBJECT: el objeto que se está serializando o deserializando. Al usar un hook lector de reemplazo de tipo "type", el código del hook debe asignar el objeto deserializado a esta variable.
*
$ELEMENT: nombre del elemento del objeto que se está serializando/deserializando.
*
$NAMESPACE: espacio de nombres del elemento del objeto que se está serializando/deserializando.
*
$MEMBER: nombre del miembro que se está serializando/deserializando. Solo es válido en el contexto "member".

EJEMPLOS DE HOOKS

El siguiente ejemplo añade una llamada a un método Validate después de la deserialización de cualquier objeto:

<hook type="type">
	<insertAfter>
		System.Xml.Schema.XmlSchema.Validate$TYPE ($OBJECT);
	</insertAfter>
</hook>

Este ejemplo especifica el código que se utilizará para deserializar la clase XmlSchema:

<hook type="type">
	<select>
		<typeName>System.Xml.Schema.XmlSchema</typeName>
	</select>
	<replace>
		$OBJECT = System.Xml.Schema.XmlSchema.Read (Reader, null);
	</replace>
</hook>

Ese especifica el código que se utilizará para leer instancias de XmlSchema:

<hook type="type">
	<select>
		<typeName>System.Xml.Schema.XmlSchema</typeName>
	</select>
	<replace>$OBJECT.Write (Writer);</replace>
</hook>

Con estos dos hooks, el serializador imprimirá información al serializar la clase "MyClass":

<hook type="type">
	<select>
		<typeName>MyNamespace.MyClass</typeName>
	</select>
	<insertBefore>Console.WriteLine ("Serializando MyClass");</replace>
	<insertAfter>Console.WriteLine ("MyClass serializada");</insertAfter>
</hook>
<hook type="member">
	<select>
		<typeName>MyNamespace.MyClass</typeName>
	</select>
	<insertAfter>
		Console.WriteLine ("Miembro serializado $MEMBER");
	</insertAfter>
</hook>

Este hook escribe un elemento adicional para todos los tipos que tienen el atributo personalizado "MyAttribute":

<hook type="elements">
	<select>
		<typeAttribute>MyNamespace.MyAttribute</typeAttribute>
	</select>
	<insertAfter>
		Writer.WriteStartElement ("privateData");
		Writer.WriteString ($OBJECT.PrivateData);
		Writer.WriteEndElement ();
	</insertAfter>
</hook>
