DESCRIPCIÓ

N

La función getgrent() devuelve un puntero a una estructura que contiene los campos desglosados de un registro en la base de datos de grupos (por ejemplo, el archivo de grupos local /etc/group, NIS y LDAP). La primera vez que se llama a getgrent(), devuelve la primera entrada; a partir de ahí, devuelve las entradas

sucesivas.

La función setgrent() rebobina al principio de la base de datos de grupos, para permitir escaneos

repetidos.

La función endgrent() se utiliza para cerrar la base de datos de grupos después de que se haya realizado todo el

procesamiento.

La estructura group está definida en <grp.h> como

sigue: 


struct group {
    char   *gr_name;        /* nombre del grupo */
    char   *gr_passwd;      /* contraseña del grupo */
    gid_t   gr_gid;         /* ID del grupo */
    char  **gr_mem;         /* matriz terminada en NULL de punteros
                               a nombres de los miembros del grupo */
}
;

Para obtener más información sobre los campos de esta estructura, ver grou

p(5
).

VALOR DE

RETORNO

La función getgrent() devuelve un puntero a una estructura group, o NULL si no hay más entradas o si ocurre un

error.

En caso de error, errno puede establecerse. Si se desea comprobar errno después de la llamada, debería establecerse a cero antes de la

llamada.

El valor de retorno puede apuntar a un área estática, y puede ser sobrescrito por llamadas posteriores a getgrent(), getgrgid(3) o getgrnam(3). (No pase el puntero devuelto a free

(3)
.)
