getrpcent(3t)

Paquete: libtirpc

Licencias: SISSL, BSD-3-Clause

GETRPCENT(3) Manual de Funciones de Biblioteca GETRPCENT(3)

NOMBRE

getrpcent, getrpcbyname, getrpcbynumber, endrpcent, setrpcent — obtener entrada RPC

SINOPSIS

#include <rpc/rpc.h>

struct rpcent *
getrpcent(void);

struct rpcent *
getrpcbyname(char *name);

struct rpcent *
getrpcbynumber(int number);

void
setrpcent(int stayopen);

void
endrpcent(void);

DESCRIPCIÓN

Las funciones getrpcent(), getrpcbyname(), y getrpcbynumber() devuelven un puntero a un objeto con la siguiente estructura que contiene los campos desglosados de una línea en la base de datos de números de programa RPC, /etc/rpc:

struct rpcent {
	char	*r_name;	/* nombre del servidor para este programa rpc */
	char	**r_aliases;	/* lista de alias */
	long	r_number;	/* número de programa rpc */
};

Los miembros de esta estructura son:

r_name
El nombre del servidor para este programa RPC.
r_aliases
Una lista terminada en cero de nombres alternativos para el programa RPC.
r_number
El número de programa RPC para este servicio.

La función getrpcent() lee la siguiente línea del archivo, abriendo el archivo si es necesario.

La función setrpcent() abre y rebobina el archivo. Si el indicador stayopen no es cero, la base de datos de red no se cerrará después de cada llamada a getrpcent() (ya sea directamente, o indirectamente a través de una de las otras llamadas “getrpc”).

La función endrpcent() cierra el archivo.

Las funciones getrpcbyname() y getrpcbynumber() buscan secuencialmente desde el principio del archivo hasta que se encuentra un nombre de programa RPC o un número de programa coincidente, o hasta que se encuentra el final del archivo.

ARCHIVOS

/etc/rpc
 

DISPONIBILIDAD

Estas funciones forman parte de libtirpc.

VER TAMBIÉN

rpc(5), rpcinfo(8)

DIAGNÓSTICOS

Se devuelve un puntero NULL en EOF o error.
