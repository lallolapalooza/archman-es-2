PROLOG

Esta página del manual forma parte del Manual del programador POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual correspondiente de Linux para obtener detalles sobre el comportamiento en Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

getgroups — obtener IDs de grupo suplementarios

SINOPSIS

#include <unistd.h>
int getgroups(int gidsetsize, gid_t grouplist[]);

DESCRIPCIÓN

La función getgroups() llenará la matriz grouplist con los IDs de grupo suplementarios actuales del proceso que llama. Es definición de la implementación si getgroups() también devuelve el ID de grupo efectivo en la matriz grouplist.

El argumento gidsetsize especifica el número de elementos en la matriz grouplist. Se devolverá el número real de IDs de grupo almacenados en la matriz. Los valores de las entradas de la matriz con índices mayores o iguales que el valor devuelto no están definidos.

Si gidsetsize es 0, getgroups() devolverá el número de IDs de grupo que de lo contrario devolvería sin modificar la matriz apuntada por grouplist.

Si el ID de grupo efectivo del proceso se devuelve junto con los IDs de grupo suplementarios, el valor devuelto siempre será mayor o igual que uno y menor o igual que el valor de {NGROUPS_MAX}+1.

VALOR DE RETORNO

Al completarse con éxito, se devolverá el número de IDs de grupo suplementarios. Un valor de retorno de -1 indica un error y errno se establecerá para indicar el error.

ERRORES

La función getgroups() fallará si:

EINVAL
El argumento gidsetsize no es cero y es menor que el número de IDs de grupo que se habrían devuelto.

Las siguientes secciones son informativas.

EJEMPLOS

Obtener los IDs de Grupo Suplementarios del Proceso que Llama

El siguiente ejemplo coloca los IDs de grupo suplementarios actuales del proceso que llama en la matriz group.

#include <sys/types.h>
#include <unistd.h>
...
gid_t *group;
int nogroups;
long ngroups_max;
ngroups_max = sysconf(_SC_NGROUPS_MAX) + 1;
group = (gid_t *)malloc(ngroups_max *sizeof(gid_t));
ngroups = getgroups(ngroups_max, group);

USO DE LA APLICACIÓN

Ninguno.

FUNDAMENTO

La función relacionada setgroups() es una operación privilegiada y, por lo tanto, no está cubierta por este volumen de POSIX.1‐2017.

Como implica la definición de grupos suplementarios, el ID de grupo efectivo puede aparecer en la matriz devuelta por getgroups() o puede ser devuelto solo por getegid(). Puede haber duplicación, pero la aplicación necesita llamar a getegid() para asegurarse de obtener toda la información. Varias variaciones de implementación y secuencias administrativas hacen que el conjunto de grupos que aparecen en el resultado de getgroups() varíe en orden y en si se incluye el ID de grupo efectivo, incluso cuando el conjunto de grupos es el mismo (en el sentido matemático de "conjunto"). (El historial de un proceso y sus padres podría afectar los detalles del resultado).

Los desarrolladores de aplicaciones deben tener en cuenta que {NGROUPS_MAX} no es necesariamente una constante en todas las implementaciones.
