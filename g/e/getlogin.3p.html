getlogin(3p)

Paquete: man-pages

GETLOGIN(3P) Manual del programador POSIX GETLOGIN(3P)

PROLOGO

Esta página del manual forma parte del Manual del programador POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual de Linux correspondiente para conocer los detalles del comportamiento de Linux) o la interfaz puede no estar implementada en Linux.

NOMBRE

getlogin, getlogin_r — obtener el nombre de inicio de sesión

SINOPSIS

#include <unistd.h>
char *getlogin(void);
int getlogin_r(char *nombre, size_t tamañonombre);

DESCRIPCION

La función getlogin() devolverá un puntero a una cadena que contiene el nombre de usuario asociado por la actividad de inicio de sesión al terminal de control del proceso actual. Si getlogin() devuelve un puntero no nulo, entonces ese puntero apunta al nombre bajo el cual el usuario inició sesión, incluso si hay varios nombres de inicio de sesión con el mismo ID de usuario.

La función getlogin() no necesita ser segura para hilos.

La función getlogin_r() colocará el nombre asociado por la actividad de inicio de sesión al terminal de control del proceso actual en el array de caracteres al que apunta nombre. El array tiene tamañonombre caracteres de longitud y debe tener espacio para el nombre y el carácter nulo terminador. El tamaño máximo del nombre de inicio de sesión es {LOGIN_NAME_MAX}.

Si getlogin_r() tiene éxito, nombre apunta al nombre que el usuario utilizó al iniciar sesión, incluso si hay varios nombres de inicio de sesión con el mismo ID de usuario.

Las funciones getlogin() y getlogin_r() pueden utilizar los descriptores de archivo 0, 1 y 2 para encontrar el terminal de control del proceso actual, examinando cada uno en su turno hasta que se encuentre el terminal. Si en este caso ninguno de estos tres descriptores de archivo está abierto al terminal de control, estas funciones pueden fallar. El método utilizado para encontrar el terminal asociado a un descriptor de archivo puede depender de que el descriptor de archivo esté abierto al dispositivo de terminal real, no a /dev/tty.

VALOR DE RETORNO

Al completarse con éxito, getlogin() devolverá un puntero al nombre de inicio de sesión o un puntero nulo si no se puede encontrar el nombre de inicio de sesión del usuario. De lo contrario, devolverá un puntero nulo y establecerá errno para indicar el error.

La aplicación no debe modificar la cadena devuelta. El puntero devuelto puede invalidarse o el contenido de la cadena puede sobrescribirse por una llamada posterior a getlogin(). El puntero devuelto y el contenido de la cadena también pueden invalidarse si el hilo que llama es terminado.

Si tiene éxito, la función getlogin_r() devolverá cero; de lo contrario, se devolverá un número de error para indicar el error.

ERRORES

Estas funciones pueden fallar si:

EMFILE
Todos los descriptores de archivo disponibles para el proceso están actualmente abiertos.
ENFILE
El número máximo permitido de archivos está actualmente abierto en el sistema.
ENOTTY
Ninguno de los descriptores de archivo 0, 1 o 2 está abierto al terminal de control del proceso actual.
ENXIO
El proceso que llama no tiene un terminal de control.

La función getlogin_r() puede fallar si:

ERANGE
El valor de tamañonombre es menor que la longitud de la cadena a devolver, incluido el carácter nulo terminador.

EJEMPLOS

Obtener el nombre de inicio de sesión del usuario S

El siguiente ejemplo llama a la función getlogin() para obtener el nombre del usuario asociado con el proceso que llama, y pasa esta información a la función getpwnam() para obtener la información de la base de datos de usuarios asociada.

#include <unistd.h>
#include <sys/types.h>
#include <pwd.h>
#include <stdio.h>
...
char *lgn;
struct passwd *pw;
...
if ((lgn = getlogin()) == NULL || (pw = getpwnam(lgn)) == NULL) {
    fprintf(stderr, "La obtención de la información del usuario falló.\n"); exit(1);
    }

USO DE APLICACION

Se pueden determinar tres nombres asociados con el proceso actual: getpwuid(geteuid()) devolverá el nombre asociado con el ID de usuario efectivo del proceso; getlogin() devolverá el nombre asociado con la actividad de inicio de sesión actual; y getpwuid(getuid()) devolverá el nombre asociado con el ID de usuario real del proceso.

La función getlogin_r() es segura para hilos y devuelve valores en un búfer proporcionado por el usuario en lugar de posiblemente usar un área de datos estática que puede ser sobrescrita por cada llamada.

FUNDAMENTO RACIONAL

La función getlogin() devuelve un puntero al nombre de inicio de sesión del usuario. El mismo ID de usuario puede ser compartido por varios nombres de inicio de sesión. Si se desea obtener la entrada de la base de datos de usuarios que se utiliza durante el inicio de sesión, el resultado de getlogin() debe usarse para proporcionar el argumento a la función getpwnam(). (Esto podría usarse para determinar el shell de inicio de sesión del usuario, particularmente donde un solo usuario tiene múltiples shells de inicio de sesión con nombres de inicio de sesión distintos, pero el mismo ID de usuario).

La información proporcionada por la función cuserid(), que originalmente se definió en el estándar POSIX.1‐1988 y se eliminó posteriormente, se puede obtener de la siguiente manera:

getpwuid(geteuid())

mientras que la información proporcionada por las implementaciones históricas de cuserid() se puede obtener mediante:

getpwuid(getuid())

La versión segura para hilos de esta función coloca el nombre de usuario en un búfer proporcionado por el usuario y devuelve un valor distinto de cero si falla. La versión no segura para hilos puede devolver el nombre en un área de datos estática que puede ser sobrescrita por cada llamada.
