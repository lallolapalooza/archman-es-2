RETORNO

Las funciones getpwnam() y getpwuid() devuelven un puntero a una estructura passwd, o NULL si no se encuentra la entrada coincidente o si ocurre un error. Si ocurre un error, errno se establece para indicar el error. Si se desea comprobar errno después de la llamada, debería establecerse a cero antes de la

llamada.

El valor de retorno puede apuntar a un área estática y puede ser sobrescrito por llamadas posteriores a getpwent(3), getpwnam() o getpwuid(). (No pase el puntero devuelto a free(3).

)

En caso de éxito, getpwnam_r() y getpwuid_r() devuelven cero y establecen *result a pwd. Si no se encontró ningún registro de contraseña coincidente, estas funciones devuelven 0 y almacenan NULL en *result. En caso de error, se devuelve un número de error y se almacena NULL en *res

NOTA

S

La formulación dada arriba bajo "VALOR DE RETORNO" proviene de POSIX.1-2001. No considera "no encontrado" como un error y por lo tanto no especifica qué valor podría tener errno en esta situación. Pero eso hace imposible reconocer errores. Podría argumentarse que según POSIX errno debería dejarse sin cambios si no se encuentra una entrada. Experimentos en varios sistemas tipo UNIX muestran que ocurren muchos valores diferentes en esta situación: 0, ENOENT, EBADF, ESRCH, EWOULDBLOCK, EPERM y probablemente

otros.

El campo pw_dir contiene el nombre del directorio de trabajo inicial del usuario. Los programas de inicio de sesión utilizan el valor de este campo para inicializar la variable de entorno HOME para el shell de inicio de sesión. Una aplicación que quiera determinar el directorio de inicio de su usuario debería inspeccionar el valor de HOME (en lugar del valor getpwuid(getuid())->pw_dir) ya que esto permite al usuario modificar su noción de "el directorio de inicio" durante una sesión de inicio de sesión. Para determinar el directorio de inicio (inicial) de otro usuario, es necesario usar getpwnam("username")->

pw_dir o al
go similar.
