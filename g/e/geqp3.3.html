subrutina cgeqp3 (integer m, integer n, complex, dimension( lda, * ) a, integer lda, integer, dimension( * ) jpvt, complex, dimension( * ) tau, complex, dimension( * ) work, integer lwork, real, dimension( * ) rwork, integer info)

CGEQP3

Propósito:

!>
!> CGEQP3 calcula una factorización QR con pivoteo de columnas de una
!> matriz A:  A*P = Q*R  usando BLAS de Nivel 3.
!>

Parámetros

M 
!>          M es INTEGER
!>          El número de filas de la matriz A. M >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz A.  N >= 0.
!>

A

!>          A es un array COMPLEX de dimensión (LDA,N)
!>          En la entrada, la matriz M por N A.
!>          En la salida, la parte triangular superior del array contiene la
!>          matriz trapezoidal superior R de min(M,N) por N; los elementos debajo
!>          de la diagonal, junto con el array TAU, representan la
!>          matriz unitaria Q como un producto de min(M,N)
!>          reflectores elementales.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A. LDA >= max(1,M).
!>

JPVT

!>          JPVT es un array INTEGER de dimensión (N)
!>          En la entrada, si JPVT(J).ne.0, la columna J de A se permuta
!>          al frente de A*P (una columna líder); si JPVT(J)=0,
!>          la columna J de A es una columna libre.
!>          En la salida, si JPVT(J)=K, entonces la columna J de A*P era la
!>          la columna K de A.
!>

TAU

!>          TAU es un array COMPLEX de dimensión (min(M,N))
!>          Los factores escalares de los reflectores elementales.
!>

WORK

!>          WORK es un array COMPLEX de dimensión (MAX(1,LWORK))
!>          En la salida, si INFO=0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK. LWORK >= N+1.
!>          Para un rendimiento óptimo LWORK >= ( N+1 )*NB, donde NB
!>          es el tamaño de bloque óptimo.
!>
!>          Si LWORK = -1, se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo del array WORK, devuelve
!>          este valor como la primera entrada del array WORK, y no se emite
!>          ningún mensaje de error relacionado con LWORK por XERBLA.
!>

RWORK

!>          RWORK es un array REAL de dimensión (2*N)
!>

INFO

!>          INFO es INTEGER
!>          = 0: salida exitosa.
!>          < 0: si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>

Detalles Adicionales:

!>
!>  La matriz Q se representa como un producto de reflectores elementales
!>
!>     Q = H(1) H(2) . . . H(k), donde k = min(m,n).
!>
!>  Cada H(i) tiene la forma
!>
!>     H(i) = I - tau * v * v**H
!>
!>  donde tau es un escalar complejo y v es un vector real/complejo
!>  con v(1:i-1) = 0 y v(i) = 1; v(i+1:m) se almacena en la salida en
!>  A(i+1:m,i), y tau en TAU(i).
!>

geqp3(3) - LAPACK

NAME

geqp3 - Computes a QR factorization of a matrix with column pivoting

SYNOPSIS

  SUBROUTINE DG',{subroutine_dgeqp3_(integer_m,_integer_n,_real,_dimension(_lda,_*_)_a,_integer_lda,_integer,_dimension(_*_)_jpvt,_real,_dimension(_*_)_tau,_real,_dimension(_*_)_work,_integer_lwork,_integer_info)}
      
  SUBROUTINE SG',{subroutine_sgeqp3_(integer_m,_integer_n,_real,_dimension(_lda,_*_)_a,_integer_lda,_integer,_dimension(_*_)_jpvt,_real,_dimension(_*_)_tau,_real,_dimension(_*_)_work,_integer_lwork,_integer_info)}
      
  SUBROUTINE ZGEQP3( M, N, A, LDA, JPVT, TAU, WORK, LWORK, INFO )
    
  SUBROUTINE CG',{subroutine_cgeqp3_(integer_m,_integer_n,_complex,_dimension(_lda,_*_)_a,_integer_lda,_integer,_dimension(_*_)_jpvt,_complex,_dimension(_*_)_tau,_complex,_dimension(_*_)_work,_integer_lwork,_real,_dimension(_*_)_rwork,_integer_info)}
      
  SUBROUTINE ZGEQP3( M, N, A, LDA, JPVT, TAU, WORK, LWORK, RWORK, INFO )

Detailed Description

The subprograms solve the least squares problem

        minimize ||b - A*x||

by computing the QR factorization of A

        A*P = Q*R

where P is an orthogonal matrix, Q is an orthogonal matrix, and R is upper trapezoidal.

The equation is solved for x, and the norm of the solution is computed.

Arguments
==========

M

          M is INTEGER
          The number of rows of the matrix A. M >= 0.

N

          N is INTEGER
          The number of columns of the matrix A.  N >= 0.

A

          A is DOUBLE PRECISION array, dimension (LDA,N)
          On entry, the M-by-N matrix A.
          On exit, the upper trapezoid of A is updated with the factors R;
          the elements below the k-th diagonal element contain the non-zero
          elements of the rank-revealing U(k). The columns of A are permuted
          by JPVT. That is, A*P = Q*R.

LDA

          LDA is INTEGER
          The leading dimension of the array A. LDA >= max(1,M).

JPVT

          JPVT is INTEGER array, dimension (N)
          On entry, JPVT specifies the permutations. If JPVT(J) > 0, then the
          J-th column of A is a fixed column. If JPVT(J) = 0, then the J-th
          column of A is a free column.
          On exit, JPVT(K) = L means that the L-th column of A was the K-th
          column of A*P.

TAU

          TAU is DOUBLE PRECISION array, dimension (min(M,N))
          On exit, TAU(K) contains the scalar tau for the rank-revealing
          orthogonal transformation H(k), which is used in the factorization
          of A.

WORK

          WORK is DOUBLE PRECISION array, dimension (MAX(1,LWORK))
          On exit, if INFO = 0, WORK(1) contains the optimal LWORK.

LWORK

          LWORK is INTEGER
          The dimension of the array WORK. LWORK >= 3*N+1.
          For optimum performance, LWORK >= 2*N + (N+1)*NB, where NB is the
          optimal blocksize.
          If LWORK = -1, then only the workspace requirement is computed without
          performing any computation. In this case, WORK(1) will contain the
          required workspace.

RWORK

          RWORK is DOUBLE PRECISION array, dimension (N)
          On exit, RWORK(1) contains the 1-norm of the triangular factor R.

INFO

          INFO is INTEGER
          = 0: successful exit
          < 0: if INFO = -i, then the i-th argument had an illegal value.

Author

Univ. of Tennessee

Univ. of California Berkeley

Univ. of Colorado Denver

NAG Ltd.

Further Details: The factorization is returned in the upper trapezoid of the array A. The remaining elements of A contain information about the vectors that define Q. Q is represented as a product of elementary reflectors Q = H(1) H(2) ... H(k), where k = min(M,N). Each H(i) has the form H(i) = I - tau*v*v^T.
