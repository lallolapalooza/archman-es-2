GETNETPATH(3) Manual de funciones de biblioteca GETNETPATH(3)

NOMBRE

getnetpath, setnetpath, endnetpath — obtener la entrada de /etc/netconfig correspondiente al componente NETPATH

SINOPSIS

#include <netconfig.h>

struct netconfig *
getnetpath(void *handlep);

void *
setnetpath(void);

int
endnetpath(void *handlep);

DESCRIPCIÓN

Las rutinas descritas en esta página proporcionan al programa acceso a la base de datos de configuración de red del sistema, /etc/netconfig, tal como es “filtrada” por la variable de entorno NETPATH (ver environ(7)). Ver getnetconfig(3) para otras rutinas que también acceden directamente a la base de datos de configuración de red. La variable NETPATH es una lista de identificadores de red separados por dos puntos.

La función getnetpath() devuelve un puntero a la entrada de la base de datos netconfig correspondiente al primer componente NETPATH válido. La entrada netconfig está formateada como un struct netconfig. En cada llamada subsiguiente, getnetpath() devuelve un puntero a la entrada netconfig que corresponde al siguiente componente NETPATH válido. La función getnetpath() puede ser utilizada así para buscar en la base de datos netconfig todas las redes incluidas en la variable NETPATH. Cuando NETPATH se ha agotado, getnetpath() devuelve NULL.

Una llamada a setnetpath() “enlaza” o “rebobina” NETPATH. La función setnetpath() debe ser llamada antes de la primera llamada a getnetpath() y puede ser llamada en cualquier otro momento. Devuelve un manejador que es utilizado por getnetpath().

La función getnetpath() ignora silenciosamente los componentes NETPATH inválidos. Un componente NETPATH es inválido si no hay una entrada correspondiente en la base de datos netconfig.

Si la variable NETPATH no está establecida, getnetpath() se comporta como si NETPATH estuviera establecida a la secuencia de redes “predeterminadas” o “visibles” en la base de datos netconfig, en el orden en que aparecen.

La función endnetpath() puede ser llamada para “desenlazar” de NETPATH cuando se completa el procesamiento, liberando recursos para su reutilización. Sin embargo, los programadores deben ser conscientes de que endnetpath() libera toda la memoria asignada por getnetpath() para la estructura de datos struct netconfig.

VALORES DE RETORNO

La función setnetpath() devuelve un manejador que es utilizado por getnetpath(). En caso de error, setnetpath() devuelve NULL.

La función endnetpath() devuelve 0 en caso de éxito y -1 en caso de fallo (por ejemplo, si setnetpath() no se llamó previamente). La función nc_perror() o nc_sperror() puede ser utilizada para imprimir la razón del fallo. Ver getnetconfig(3).

Cuando se llama por primera vez, getnetpath() devuelve un puntero a la entrada de la base de datos netconfig correspondiente al primer componente NETPATH válido. Cuando NETPATH se ha agotado, getnetpath() devuelve NULL.

DISPONIBILIDAD

Estas funciones forman parte de libtirpc.

VER TAMBIÉN

getnetconfig(3), netconfig(5), environ(7)
