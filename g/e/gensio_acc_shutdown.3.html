gensio_acc_shutdown(3)

Paquete: gensio

Licencias: GPL

gensio_acc_shutdown(3) Manual de funciones de biblioteca gensio_acc_shutdown(3)

NOMBRE

gensio_acc_shutdown, gensio_acc_shutdown_s, gensio_acc_disable, gensio_acc_free - Detener/liberar un aceptador de gensio que se ha iniciado

SINOPSIS

#include <gensio/gensio.h>

typedef void (*gensio_acc_done)(struct gensio_accepter *acc,

void *cb_data);
int gensio_acc_shutdown(struct gensio_accepter *accepter,

gensio_acc_done shutdown_done,
void *shutdown_data);
int gensio_acc_shutdown_s(struct gensio_accepter *accepter);
void gensio_acc_disable(struct gensio_accepter *accepter);
void gensio_acc_free(struct gensio_accepter *accepter);

DESCRIPCIÓN

gensio_acc_shutdown Cierra todos los sockets y deshabilita todo en el aceptador de gensio. shutdown_done() será llamado si tiene éxito después de que el cierre se complete, si no es NULL. Devuelve GE_INUSE si el aceptador ya está cerrado, cero en caso contrario.

gensio_acc_shutdown_s cierra el gensio y espera a que el cierre finalice. Consulte las notas en gensio_close_s(3) para advertencias sobre el uso de esta función.

gensio_acc_disable es similar a gensio_disable(3), pero para aceptadores. Consulte gensio_disable(3) para obtener detalles.

gensio_acc_free libera el aceptador de red. Si el aceptador de red está iniciado, lo cierra primero y shutdown_done() NO será llamado.

VALORES DEVUELTOS

Se devuelve cero en caso de éxito, o un error de gensio en caso de fallo.

VER TAMBIÉN
