CGETSLS

Propósito:

!>
!> CGETSLS resuelve sistemas lineales complejos sobredeterminados o
!> subdeterminados que involucran una matriz A de M por N, usando una
!> factorización QR o LQ esbelta alta (tall skinny) o corta ancha (short wide) de A.
!>
!> Se asume que A tiene rango completo, y solo se proporciona una protección
!> rudimentaria contra matrices de rango deficiente. Esta subrutina solo detecta
!> la deficiencia de rango exacta, donde un elemento diagonal del factor triangular
!> de A es exactamente cero.
!>
!> Es concebible que uno (o más) de los elementos diagonales del factor triangular
!> de A sean números subnormalmente pequeños sin que esta subrutina señale
!> un error. Las soluciones calculadas para matrices casi deficientes en rango
!> pueden ser menos precisas debido a una pérdida de precisión numérica.
!>
!>
!> Se proporcionan las siguientes opciones:
!>
!> 1. Si TRANS = 'N' y m >= n:  encontrar la solución de mínimos cuadrados de
!>    un sistema sobredeterminado, es decir, resolver el problema de mínimos cuadrados
!>                 minimizar || B - A*X ||.
!>
!> 2. Si TRANS = 'N' y m < n:  encontrar la solución de norma mínima de
!>    un sistema subdeterminado A * X = B.
!>
!> 3. Si TRANS = 'C' y m >= n:  encontrar la solución de norma mínima de
!>    un sistema subdeterminado A**T * X = B.
!>
!> 4. Si TRANS = 'C' y m < n:  encontrar la solución de mínimos cuadrados de
!>    un sistema sobredeterminado, es decir, resolver el problema de mínimos cuadrados
!>                 minimizar || B - A**T * X ||.
!>
!> Se pueden manejar varios vectores de mano derecha b y vectores de solución x
!> en una sola llamada; se almacenan como las columnas de la
!> matriz de mano derecha B de M por NRHS y la matriz de solución X de N por NRHS.
!>

Parámetros

TRANS 
!>          TRANS es CHARACTER*1
!>          = 'N': el sistema lineal involucra A;
!>          = 'C': el sistema lineal involucra A**H.
!>

M

!>          M es INTEGER
!>          El número de filas de la matriz A.  M >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz A.  N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de manos derechas, es decir, el número de
!>          columnas de las matrices B y X. NRHS >=0.
!>

A

!>          A es un array COMPLEX, dimensión (LDA,N)
!>          En la entrada, la matriz A de M por N.
!>          En la salida,
!>          A se sobrescribe con detalles de su factorización QR o LQ
!>          devuelta por CGEQR o CGELQ.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,M).
!>

B

!>          B es un array COMPLEX, dimensión (LDB,NRHS)
!>          En la entrada, la matriz B de vectores de mano derecha, almacenada
!>          por columnas; B es M por NRHS si TRANS = 'N', o N por NRHS
!>          si TRANS = 'C'.
!>          En la salida, si INFO = 0, B se sobrescribe con los vectores
!>          de solución, almacenados por columnas:
!>          si TRANS = 'N' y m >= n, las filas 1 a n de B contienen los vectores
!>          de solución de mínimos cuadrados.
!>          si TRANS = 'N' y m < n, las filas 1 a N de B contienen los vectores
!>          de solución de norma mínima;
!>          si TRANS = 'C' y m >= n, las filas 1 a M de B contienen los vectores
!>          de solución de norma mínima;
!>          si TRANS = 'C' y m < n, las filas 1 a M de B contienen los vectores
!>          de solución de mínimos cuadrados.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B. LDB >= MAX(1,M,N).
!>

WORK

!>          (espacio de trabajo) array COMPLEX, dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) contiene LWORK óptimo (o mínimo
!>          o óptimo, si se asumió una consulta).
!>          Ver LWORK para más detalles.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK. LWORK >= 1.
!>          Si LWORK = -1 o -2, entonces se asume una consulta de espacio de trabajo.
!>          Si LWORK = -1, la rutina calcula el tamaño óptimo de WORK para un
!>          rendimiento óptimo y devuelve este valor en WORK(1).
!>          Si LWORK = -2, la rutina calcula el tamaño mínimo de WORK y
!>          devuelve este valor en WORK(1).
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>          > 0:  si INFO =  i, el i-ésimo elemento diagonal del
!>                factor triangular de A es exactamente cero, por lo que A no tiene
!>                rango completo; no se pudo calcular la solución de mínimos cuadrados.
!>
