getpwent_r(3) Manual de funciones de la biblioteca getpwent_r(3)

NOMBRE

getpwent_r, fgetpwent_r - obtener una entrada del archivo passwd de forma reentrante

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <pwd.h>
int getpwent_r(size_t size;
               struct passwd *restrict pwbuf,
               char buf[restrict size], size_t size,
               struct passwd **restrict pwbufp);
int fgetpwent_r(size_t size;
               FILE *restrict stream, struct passwd *restrict pwbuf,
               char buf[restrict size], size_t size,
               struct passwd **restrict pwbufp);
Requisitos de macro de prueba de características para glibc (ver feature_test_macros(7)):

getpwent_r(),

    Desde glibc 2.19:
        _DEFAULT_SOURCE
    glibc 2.19 y anteriores:
        _BSD_SOURCE || _SVID_SOURCE

fgetpwent_r():

    Desde glibc 2.19:
        _DEFAULT_SOURCE
    glibc 2.19 y anteriores:
        _SVID_SOURCE

DESCRIPCIÓN

Las funciones getpwent_r() y fgetpwent_r() son las versiones reentrantes de getpwent(3) y fgetpwent(3). La primera lee la siguiente entrada passwd del flujo inicializado por setpwent(3). La segunda lee la siguiente entrada passwd de stream.

La estructura passwd se define en <pwd.h> de la siguiente manera:


struct passwd {
    char    *pw_name;      /* nombre de usuario */
    char    *pw_passwd;    /* contraseña de usuario */
    uid_t    pw_uid;       /* ID de usuario */
    gid_t    pw_gid;       /* ID de grupo */
    char    *pw_gecos;     /* información del usuario */
    char    *pw_dir;       /* directorio personal */
    char    *pw_shell;     /* programa shell */
};

Para más información sobre los campos de esta estructura, ver passwd(5).

Las funciones no reentrantes devuelven un puntero a un almacenamiento estático, donde este almacenamiento estático contiene punteros adicionales al nombre de usuario, contraseña, campo gecos, directorio personal y shell. Las funciones reentrantes descritas aquí devuelven todo eso en búferes proporcionados por el llamador. Primero, está el búfer pwbuf que puede contener una struct passwd. Y luego, el búfer buf de tamaño size que puede contener cadenas adicionales. El resultado de estas funciones, la struct passwd leída del flujo, se almacena en el búfer proporcionado *pwbuf, y un puntero a esta struct passwd se devuelve en *pwbufp.

VALOR DE RETORNO

En caso de éxito, estas funciones devuelven 0 y *pwbufp es un puntero a la struct passwd. En caso de error, estas funciones devuelven un valor de error y *pwbufp es NULL.

ERRORES

ENOENT
No hay más entradas.
ERANGE
Espacio de búfer insuficiente proporcionado. Inténtelo de nuevo con un búfer más grande.

ATRIBUTOS

Para obtener una explicación de los términos utilizados en esta sección, ver attributes(7).

Interfaz Atributo Valor
getpwent_r () Seguridad de hilos MT-Unsafe race:pwent locale
fgetpwent_r () Seguridad de hilos MT-Safe

En la tabla anterior, pwent en race:pwent significa que si alguna de las funciones setpwent(), getpwent(), endpwent() o getpwent_r() se utilizan en paralelo en diferentes hilos de un programa, podrían producirse carreras de datos.

VERSIONES

Otros sistemas utilizan el prototipo


struct passwd *
getpwent_r(struct passwd *pwd, char buf[.size], int size);

o, mejor,


int
getpwent_r(struct passwd *pwd, char buf[.size], int size,
           FILE **pw_fp);

ESTÁNDARES

Ninguno.

HISTORIA

Estas funciones se hacen en un estilo que se asemeja a la versión POSIX de funciones como getpwnam_r(3).

NOTAS

La función getpwent_r() no es realmente reentrante ya que comparte la posición de lectura en el flujo con todos los demás hilos.

EJEMPLOS

#define _GNU_SOURCE
#include <pwd.h>
#include <stdint.h>
#include <stdio.h>
#include <stdlib.h>
#define BUFLEN 4096
int
main(void)
{
    struct passwd pw;
    struct passwd *pwp;
    char buf[BUFLEN];
    int i;
    setpwent();
    while (1) {
        i = getpwent_r(&pw, buf, sizeof(buf), &pwp);
        if (i)
            break;
        printf("%s (%jd)\tHOME %s\tSHELL %s\n", pwp->pw_name,
               (intmax_t) pwp->pw_uid, pwp->pw_dir, pwp->pw_shell);
    }
    endpwent();
    exit(EXIT_SUCCESS);
}
