getdns_validate_dnssec(3)

Paquete: getdns

Licencias: BSD

getdns_validate_dnssec(3) getdns getdns_validate_dnssec(3)

NOMBRE

getdns_validate_dnssec -- valida DNSSEC un registro getdns dado

BIBLIOTECA

Biblioteca del Resolutor DNS (libgetdns, -lgetdns)

SINOPSIS

#include <getdns.h>

getdns_return_t
getdns_validate_dnssec (getdns_list *record_to_validate,

getdns_list *bundle_of_support_records,
getdns_list *trust_anchor_records)

DESCRIPCIÓN

Si una aplicación desea que la API realice la validación DNSSEC sin utilizar las extensiones, puede usar la función auxiliar getdns_validate_dnssec(). La API utilizará los registros de recursos en bundle_of_support_records para construir la cadena de validación y los registros DNSKEY o DS en trust_anchor_records como anclas de confianza. La lista por defecto de registros de ancla de confianza que utiliza la biblioteca para validar DNSSEC se puede obtener utilizando la función auxiliar getdns_root_trust_anchor.

record_to_validate el registro de recursos que se está validando

bundle_of_support_records registros utilizados para construir la cadena de validación

trust_anchor_records registros de ancla de confianza a utilizar para la validación

VALORES DE RETORNO

GETDNS_DNSSEC_BOGUS la firma DNSSEC es falsa

GETDNS_DNSSEC_INDETERMINATE no se pudo completar la validación

GETDNS_DNSSEC_INSECURE una o más partes de la cadena de validación son demostrablemente incorrectas

GETDNS_DNSSEC_SECURE la validación se completó con éxito

GETDNS_RETURN_MEMORY_ERROR un intento de asignar memoria falló
