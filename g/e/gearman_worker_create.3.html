gearman_worker_create(3)

Paquete: gearmand

Licencias: BSD-3-Clause

GEARMAN_WORKER_CREATE(3) Gearmand GEARMAN_WORKER_CREATE(3)

NOMBRE

Documentación de Gearmand, https://gearman.org/gearmand/

SINOPSIS

#include <libgearman/gearman.h>

gearman_worker_st *gearman_worker_create(gearman_worker_st *cliente)
gearman_worker_st *gearman_worker_clone(gearman_worker_st *cliente, const gearman_worker_st *desde)
void gearman_worker_free(gearman_worker_st *cliente)

Enlazar con -lgearman

DESCRIPCIÓN

gearman_worker_create() se utiliza para crear una estructura gearman_worker_st que luego será utilizada por otras funciones cliente de libgearman(3) para comunicarse con el servidor. Debes pasar una gearman_worker_st declarada estáticamente a gearman_worker_create() o un NULL. Si se pasa un NULL, se asignará una estructura para ti.

gearman_worker_clone() es similar a gearman_worker_create() pero copia los valores predeterminados y la lista de servidores de la gearman_worker_st de origen. Si pasas un nulo como argumento de origen para clonar, es lo mismo que una llamada a gearman_worker_create(). Si el argumento de destino es NULL, se asignará una gearman_worker_st para ti.

Para limpiar la memoria asociada con una estructura gearman_worker_st, debes pasarla a gearman_worker_free() cuando termines de usarla. gearman_worker_free es la única forma de asegurarse de que toda la memoria se desasigne cuando termines de usar la estructura.

Es posible que desees evitar usar gearman_worker_create() o gearman_worker_clone() con una asignación basada en pila, es decir, el primer parámetro. Los problemas más comunes relacionados con la seguridad de la ABI involucran estructuras asignadas en el heap.

VALOR DE RETORNO

gearman_worker_create() devuelve un puntero a la gearman_worker_st que se creó (o inicializó). En caso de fallo de asignación, devuelve NULL.

gearman_worker_clone() devuelve un puntero a la gearman_worker_st que se creó (o inicializó). En caso de fallo de asignación, devuelve NULL.
