glutKeyboardUpFunc(3)

Paquete: freeglut

Licencias: X11

glutKeyboardUpFunc(3) freeglut glutKeyboardUpFunc(3)

NOMBRE

glutKeyboardUpFunc - establece la función de devolución de llamada para el evento de liberación de tecla (key release) del teclado de la ventana actual.

SINTAXIS

void glutKeyboardUpFunc(void (*func)(unsigned char key,
                      int x, int y));

ARGUMENTOS

func
La nueva función de devolución de llamada para el evento de liberación de tecla.

DESCRIPCIÓN

glutKeyboardFunc establece la función de devolución de llamada para el evento de liberación de tecla (key release) del teclado de la ventana actual. Cuando un usuario escribe en la ventana, cada liberación de tecla que corresponda a un carácter ASCII generará una devolución de llamada de liberación de tecla. El parámetro de la devolución de llamada para la tecla es el carácter ASCII generado. El estado de las teclas modificadoras como Shift no se puede determinar directamente; su único efecto será sobre los datos ASCII devueltos. Los parámetros x e y de la devolución de llamada indican la ubicación del ratón en coordenadas relativas a la ventana cuando se presionó la tecla. Cuando se crea una nueva ventana, inicialmente no hay ninguna función de devolución de llamada de teclado registrada, y las pulsaciones de teclas ASCII en la ventana se ignoran. Pasar NULL a glutKeyboardFunc deshabilita la generación de devoluciones de llamada de teclado.

Durante una devolución de llamada de liberación de tecla, se puede llamar a glutGetModifiers para determinar el estado de las teclas modificadoras cuando ocurrió la pulsación de tecla que generó la devolución de llamada.

Para evitar la notificación de pares de liberación/presión de teclas debido a la repetición automática, use glutIgnoreKeyRepeat para ignorar las pulsaciones de teclas repetidas automáticamente.

No hay garantía de que la devolución de llamada de presión de tecla coincida con el carácter ASCII exacto de la devolución de llamada de liberación de tecla. Por ejemplo, la pulsación de tecla puede ser para una 'b' minúscula, pero la liberación de tecla puede informar una 'B' mayúscula si el estado de Shift ha cambiado. Lo mismo se aplica a los símbolos y caracteres de control. El comportamiento exacto depende del sistema de ventanas.

Use glutSpecialUpFunc para un medio para detectar liberaciones de teclas no ASCII.

VER TAMBIÉN

glutKeyboardFunc, glutSpecialUpFunc, glutSpecialFunc, glutCreateWindow, glutMouseFunc, glutSpaceballButtonFunc, glutButtonBoxFunc, glutTabletButtonFunc, glutGetModifiers, glutIgnoreKeyRepeat
