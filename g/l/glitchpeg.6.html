NOMBRE

glitchpeg - salvapantallas de imagen con fallos.

SINOPSIS

glitchpeg [--display host:display.screen] [--visual visual] [--window] [--root] [--window-id número] [--delay número] [--duration número] [--count número]

DESCRIPCIÓN

Carga una imagen, la corrompe y luego muestra la versión corrupta, varias veces por segundo. Después de un tiempo, encuentra una nueva imagen para corromper.

Corrompe la imagen alterando bytes aleatorios en el archivo de imagen comprimido antes de descomprimirlo. Esto crea efectos visuales interesantes en archivos JPEG, pero no funciona bien en archivos PNG, ya que PNG contiene sumas de verificación que detectan la corrupción simple.

OPCIONES

--visual visual
Especifica qué visual usar. Los valores legales son el nombre de una clase visual o el número de ID (decimal o hexadecimal) de un visual específico.
--window
Dibuja en una ventana recién creada. Este es el valor predeterminado.
--root
Dibuja en la ventana raíz.
--window-id número
Dibuja en la ventana especificada.
--delay número
Retraso por fotograma, en microsegundos. Predeterminado: 30000 (0.03 segundos).
--duration número
Cuántos segundos antes de cargar una nueva imagen. Predeterminado: 120.
--count número
Número de fallos a introducir por iteración. Predeterminado: 400.

AMBIENTE

DISPLAY
para obtener el host y el número de pantalla predeterminados.
XENVIRONMENT
para obtener el nombre de un archivo de recursos que anula los recursos globales almacenados en la propiedad RESOURCE_MANAGER.
XSCREENSAVER_WINDOW
El ID de ventana a usar con --root.

SEGURIDAD

Debido a que este programa está alimentando datos intencionalmente inválidos en las bibliotecas de decodificación de imágenes de su sistema operativo, es posible que se bloquee como resultado de esos datos corruptos.

Eso no debería ser posible, pero podría serlo.

Tenga en cuenta que si esto sucede, ¡indica un grave error de seguridad en las bibliotecas de imágenes de su sistema! Probablemente significa que sus bibliotecas son susceptibles a ataques de desbordamiento de búfer o similares, lo que puede conducir a la ejecución remota de código. Debería informar ese error a los mantenedores de esas bibliotecas de imágenes.

En el contexto de xscreensaver, cuando se configura para cargar solo archivos de imagen locales, esto no debería ser una preocupación de seguridad directa: que este salvapantallas se bloquee no afectará al demonio xscreensaver y no desbloqueará su pantalla.
