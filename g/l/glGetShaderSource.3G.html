NOMBRE

glGetShaderSource - Devuelve la cadena de código fuente de un objeto de sombreador

ESPECIFICACIÓN C

void glGetShaderSource(GLuint shader, GLsizei bufSize, GLsizei *length, GLchar *source);

PARÁMETROS

shader

Especifica el objeto de sombreador a consultar.

bufSize

Especifica el tamaño del búfer de caracteres para almacenar la cadena de código fuente devuelta.

length

Devuelve la longitud de la cadena devuelta en source (excluyendo el terminador nulo).

source

Especifica una matriz de caracteres que se utiliza para devolver la cadena de código fuente.

DESCRIPCIÓN

glGetShaderSource devuelve la concatenación de las cadenas de código fuente del objeto de sombreador especificado por shader. Las cadenas de código fuente para un objeto de sombreador son el resultado de una llamada anterior a glShaderSource(). La cadena devuelta por la función será terminada en nulo.

glGetShaderSource devuelve en source tanta parte de la cadena de código fuente como sea posible, hasta un máximo de bufSize caracteres. El número de caracteres realmente devueltos, excluyendo el carácter de terminación nula, se especifica en length. Si no se requiere la longitud de la cadena devuelta, se puede pasar un valor de NULL en el argumento length. El tamaño del búfer necesario para almacenar la cadena de código fuente devuelta se puede obtener llamando a glGetShader() con el valor GL_SHADER_SOURCE_LENGTH.

ERRORES

Se genera GL_INVALID_VALUE si shader no es un valor generado por OpenGL.

Se genera GL_INVALID_OPERATION si shader no es un objeto de sombreador.

Se genera GL_INVALID_VALUE si bufSize es menor que 0.

GET ASOCIADOS

glGetShader() con el argumento GL_SHADER_SOURCE_LENGTH

glIsShader()
