GLDRAWARRAYSINDIRECT(3G) [FIXME: manual] GLDRAWARRAYSINDIRECT(3G)

NOMBRE

glDrawArraysIndirect - Dibuja primitivas a partir de datos de array, tomando parámetros de la memoria

ESPECIFICACIÓN C

void glDrawArraysIndirect(GLenum mode, const void *indirect);

PARÁMETROS

mode

Especifica qué tipo de primitivas se van a dibujar. Se aceptan los símbolos constantes GL_POINTS, GL_LINE_STRIP, GL_LINE_LOOP, GL_LINES, GL_LINE_STRIP_ADJACENCY, GL_LINES_ADJACENCY, GL_TRIANGLE_STRIP, GL_TRIANGLE_FAN, GL_TRIANGLES, GL_TRIANGLE_STRIP_ADJACENCY, GL_TRIANGLES_ADJACENCY y GL_PATCHES.

indirect

Especifica la dirección de una estructura que contiene los parámetros de dibujo.

DESCRIPCIÓN

glDrawArraysIndirect especifica múltiples primitivas geométricas con muy pocas llamadas a subrutinas. glDrawArraysIndirect se comporta de forma similar a glDrawArraysInstancedBaseInstance(), excepto que los parámetros de glDrawArraysInstancedBaseInstance() se almacenan en memoria en la dirección dada por indirect.

Los parámetros a los que apunta indirect se empaquetan en una estructura que toma la forma (en C):

    typedef  struct {
        uint  count;
        uint  instanceCount;
        uint  first;
        uint  baseInstance;
    } DrawArraysIndirectCommand;
    const DrawArraysIndirectCommand *cmd = (const DrawArraysIndirectCommand *)indirect;
    glDrawArraysInstancedBaseInstance(mode, cmd->first, cmd->count, cmd->instanceCount, cmd->baseInstance);

Si un buffer está enlazado a la conexión GL_DRAW_INDIRECT_BUFFER en el momento de una llamada a glDrawArraysIndirect, indirect se interpreta como un desplazamiento, en unidades básicas de máquina, dentro de ese buffer y los datos de los parámetros se leen del buffer en lugar de la memoria del cliente.

A diferencia de glDrawArraysInstancedBaseInstance(), el primer miembro de la estructura de parámetros es sin signo, y los índices fuera de rango no generan un error.

Los atributos de vértice que son modificados por glDrawArraysIndirect tienen un valor indefinido después de que glDrawArraysIndirect retorne. Los atributos que no se modifican permanecen bien definidos.

NOTAS

El miembro baseInstance de la estructura DrawArraysIndirectCommand solo está definido si la versión de GL es 4.2 o superior. Para versiones de GL anteriores a 4.2, este parámetro está presente pero reservado y debe establecerse en cero. En versiones anteriores de GL, el comportamiento es indefinido si es distinto de cero.

ERRORES

Se genera GL_INVALID_ENUM si mode no es un valor aceptado.

Se genera GL_INVALID_OPERATION si un objeto de buffer no cero está enlazado a un array habilitado o a la conexión GL_DRAW_INDIRECT_BUFFER y el almacén de datos del objeto de buffer está actualmente mapeado.

Se genera GL_INVALID_OPERATION si un shader de geometría está activo y mode es incompatible con el tipo de primitiva de entrada del shader de geometría en el objeto de programa actualmente instalado.

Se genera GL_INVALID_OPERATION si mode es GL_PATCHES y no hay un shader de control de teselación activo.
