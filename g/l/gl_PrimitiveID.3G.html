NOMBRE

gl_PrimitiveID - contiene el índice de la primitiva actual

DECLARACIÓN

// En shaders de control de teselación, evaluación de teselación y fragmentos

in int gl_PrimitiveID ;

// En shaders de geometría

out int gl_PrimitiveID ;

DESCRIPCIÓN

gl_PrimitiveID es una variable de entrada de los lenguajes de control de teselación, evaluación de teselación y fragmentos. Para los lenguajes de control de teselación y evaluación de teselación, contiene el número de primitivas procesadas por el shader desde que se inició el conjunto actual de primitivas de renderizado. La primera primitiva procesada por el comando de dibujo se numera cero y el contador de ID de primitiva se incrementa después de procesar cada primitiva individual de punto, línea o triángulo. Para triángulos dibujados en modo de punto o línea, el contador de ID de primitiva se incrementa solo una vez, incluso si se dibujan múltiples puntos o líneas. Reiniciar una topología de primitiva usando el índice de reinicio de primitiva no tiene ningún efecto en el contador de ID de primitiva.

En el lenguaje de geometría, gl_PrimitiveID es una variable de salida que se pasa a la variable de entrada gl_PrimitiveID correspondiente en el shader de fragmentos. Si no hay un shader de geometría presente, entonces gl_PrimitiveID en el lenguaje de fragmentos se comporta de manera idéntica a como lo haría en los lenguajes de control y evaluación de teselación. Si hay un shader de geometría presente pero no escribe en gl_PrimitiveID, el valor de gl_PrimitiveID en el shader de fragmentos es indefinido.
