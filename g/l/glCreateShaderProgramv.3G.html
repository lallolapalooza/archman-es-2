NOMBRE

glCreateShaderProgramv - crea un programa independiente a partir de una matriz de cadenas de código fuente terminadas en nulo

ESPECIFICACIÓN C

GLuint glCreateShaderProgramv(GLenum type, GLsizei count, const char **strings);

PARÁMETROS

type

Especifica el tipo de shader a crear.

count

Especifica el número de cadenas de código fuente en la matriz strings.

strings

Especifica la dirección de una matriz de punteros a cadenas de código fuente a partir de las cuales se creará el objeto de programa.

DESCRIPCIÓN

glCreateShaderProgram crea un objeto de programa que contiene shaders compilados y enlazados para una sola etapa especificada por type. strings se refiere a una matriz de count cadenas a partir de las cuales se crearán los ejecutables del shader.

glCreateShaderProgram es equivalente (suponiendo que no se generen errores) a:

    const GLuint shader = glCreateShader(type);
    if (shader) {
        glShaderSource(shader, count, strings, NULL);
        glCompileShader(shader);
        const GLuint program = glCreateProgram();
        if (program) {
            GLint compiled = GL_FALSE;
            glGetShaderiv(shader, GL_COMPILE_STATUS, &compiled);
            glProgramParameteri(program, GL_PROGRAM_SEPARABLE, GL_TRUE);
            if (compiled) {
                glAttachShader(program, shader);
                glLinkProgram(program);
                glDetachShader(program, shader);
            }
            /* append-shader-info-log-to-program-info-log */
        }
        glDeleteShader(shader);
        return program;
    } else {
        return 0;
    }

El objeto de programa creado por glCreateShaderProgram tiene su estado GL_PROGRAM_SEPARABLE establecido en GL_TRUE.

ERRORES

Se genera GL_INVALID_ENUM si type no es un tipo de shader aceptado.

Se genera GL_INVALID_VALUE si count es negativo.

Se generan otros errores si el código del shader suministrado falla al compilar y enlazar, como se describe para los comandos en la secuencia pseudocódigo anterior, pero todos esos errores se generan sin ningún efecto secundario de la ejecución de esos comandos.
