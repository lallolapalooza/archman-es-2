La ubicación de la variable uniforme a modificar se especifica mediante location, que debe ser un valor devuelto por glGetUniformLocation(). glProgramUniform opera sobre el objeto

de

programa especificado por program. Los comandos glProgramUniform{1|2|3|4}{f|i|ui} se utilizan para cambiar el valor de la variable uniforme especificada por location usando los valores pasados como argumentos. El número especificado en el comando debe coincidir con el número de componentes en el tipo de datos de la variable uniforme especificada (por ejemplo, 1 para float, int, unsigned int, bool; 2 para vec2, ivec2, uvec2, bvec2, etc.). El sufijo f indica que se están pasando valores de punto flotante; el sufijo i indica que se están pasando valores enteros; el sufijo ui indica que se están pasando valores enteros sin signo, y este tipo también debe coincidir con el tipo de datos de la variable uniforme especificada. Las variantes i de esta función deben usarse para proporcionar valores para variables uniformes definidas como int, ivec2, ivec3, ivec4, o arrays de estos. Las variantes ui de esta función deben usarse para proporcionar valores para variables uniformes definidas como unsigned int, uvec2, uvec3, uvec4, o arrays de estos. Las variantes f deben usarse para proporcionar valores para variables u niformes de tipo float, vec2, vec3, vec4, o arrays de estos. Se pueden usar las variantes i, ui o f para proporcionar valores para variables uniformes de tipo bool, bvec2, bvec3, bvec4, o arrays de estos. La variable uniforme se establecerá

en

false si el valor de entrada es 0 o 0.0f, y se establecerá en true en caso contrario. Todas las variables uniformes activas definidas en un objeto de programa se inicializan a 0 cuando el objeto de programa se enlaza correctamente. Conservan los valores asignados por una llamada a glProgramUniform hasta que

ocurre

la siguiente operación de enlace exitosa en el objeto de programa, cuando se inicializan nuevamente a 0. Los comandos glProgramUniform{1|2|3|4}{f|i|ui}v pueden usarse para modificar una única variable uniforme o un array de variables uniformes. Estos comandos pasan un count y un puntero a los valores que se cargarán en una variable uniforme o en un array de variables uniformes. Se debe usar un count de 1 si se modifica el valor de una sola variable uniforme, y se puede usar un count de 1 o mayor para modificar un array completo o parte de un array. Al cargar n elementos comenzando en una posición a rbitraria m en un array de variables uniformes, los elementos m + n - 1 en el array serán reemplazados con los nuevos valores. Si m + n - 1 es mayor que el tamaño del array de variables uniformes, los valores para todos los elementos del array más allá del final del array serán ignorados. El número especificado en el nombre del comando indica el número de componentes para cada elemento en value, y debe coincidir con el número de componentes en el tipo de datos de la variable uniforme especificada (por ejemplo, 1 para float, int, bool; 2 para vec2, ivec2, bvec2, etc.). El tipo de datos

NAME

glProgramUniform3iv - set uniform variables of type ivec3

C SPECIFICATION

void glProgramUniform3iv( GLuint program,
                          GLint location,
                          GLsizei count,
                          const GLint *value );

PARAMETERS

program
Specifies the program object containing the uniform variable to be modified.
location
Specifies the uniform variable location.
count
Specifies the number of elements that are to be downloaded and updated in the uniform buffer.
value
Specifies a pointer to the new values that will be stored in the specified uniform variable.

DESCRIPTION

glProgramUniform3iv specifies the value of a uniform variable, in none of the current program object, of type ivec3. Integer vectors are specified by value.

glProgramUniform3iv is the same as calling glUniform3iv, except that it operates directly on the program objectid specified by program, and it does not affect the currently active program object. When program objects are linked or validated, all uniform state is saved. glProgramUniform3iv updates the saved state. It is not necessary to enter or exit from a linked program object, or to validate it, after calling this function to update the state.

If program is not zero, then it is a value returned by a previous call to glCreateProgram, or it may be the name of the program object for which the currently active program was taken. If program is zero, then the uniform variable location must be from the currently active program object.

If location is not valid, then the specified parameter values are ignored.

If program was not successfully linked after the last call to glLinkProgram, or if program has not been successfully made part of the current GL state, it is undefined what happens.

If program is the name of an empty list, glProgramUniform3iv will do nothing.

Calling glProgramUniform3iv multiple times for the same program and location is allowed. The effects are the same as calling it once with the last specified value.

When a program object is deleted by glDeleteProgram, all uniform locations and values associated with that program object are invalidated.

NOTES

This function is available only in GLSL version 1.20 or greater.

Integer uniforms are deprecated in modern OpenGL. Use floating-point uniforms instead.

ERRORS

GL_INVALID_OPERATION is generated if program is not zero or a valid program object.

GL_INVALID_OPERATION is generated if program is the name of a program object that has not been successfully linked.

GL_INVALID_OPERATION is generated if program is not zero and has been installed as part of current rendering state by useProgram, and if program is not the name of the program for which the currently active program state has been taken.

glGetProgram(3G), glGetUniformLocation(3G)
