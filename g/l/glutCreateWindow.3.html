glutCreateWindow(3)

Licencias: X11

glutCreateWindow(3) freeglut glutCreateWindow(3)

NOMBRE

glutCreateWindow - crea una ventana de nivel superior.

SINTAXIS

int glutCreateWindow(char *name);

ARGUMENTOS

name
Cadena de caracteres ASCII para usar como nombre de la ventana.

DESCRIPCIÓN

glutCreateWindow crea una ventana de nivel superior. El nombre se proporcionará al sistema de ventanas como el nombre de la ventana. La intención es que el sistema de ventanas etiquete la ventana con el nombre.

Implícitamente, la ventana actual se establece en la ventana recién creada.

Cada ventana creada tiene un contexto OpenGL asociado único. Los cambios de estado en el contexto OpenGL de una ventana se pueden realizar inmediatamente después de crear la ventana.

El estado de visualización de una ventana es inicialmente para que la ventana se muestre. Pero el estado de visualización de la ventana no se actúa realmente hasta que se entra en glutMainLoop. Esto significa que hasta que no se llame a glutMainLoop, la representación en una ventana creada es ineficaz porque la ventana aún no se puede mostrar.

El valor devuelto es un identificador entero pequeño y único para la ventana. El rango de identificadores asignados comienza en uno. Este identificador de ventana se puede utilizar al llamar a glutSetWindow.

NOTAS DE IMPLEMENTACIÓN X

Se establecen las propiedades adecuadas del X Inter-Client Communication Conventions Manual (ICCCM) de nivel superior. La propiedad WM_COMMAND que enumera el comando utilizado para invocar el programa GLUT solo se establece para la primera ventana creada.

VER TAMBIÉN

glutCreateSubWindow, glutCreateMenu, glutDestroyWindow
