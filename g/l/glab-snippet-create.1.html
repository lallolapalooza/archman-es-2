NOMBRE

glab-snippet-create - Crea un nuevo fragmento.

SINOPSIS

glab snippet create [flags] -t [...] glab snippet create [flags] -t -f # lee desde stdin

DESCRIPCIÓN

Crea un nuevo fragmento.

OPCIONES

-d, --description="" Descripción del fragmento.

-f, --filename="" Nombre del archivo del fragmento en GitLab.

-p, --personal[=false] Crea un fragmento personal.

-t, --title="" (requerido) Título del fragmento.

-v, --visibility="private" Limita por visibilidad: 'public', 'internal', o 'private'

OPCIONES HEREDADAS DE COMANDOS PADRE

-h, --help[=false] Muestra ayuda para este comando.

-R, --repo="" Selecciona otro repositorio. Puede usar el formato OWNER/REPO o GROUP/NAMESPACE/REPO. También acepta URL completo o URL de Git.

EJEMPLO

$ glab snippet create script.py --title "Título del fragmento"
$ echo "package main" | glab snippet new --title "Título del fragmento" --filename "main.go"
$ glab snippet create -t Título -f "different.go" -d Descripción script.py
$ glab snippet create -t Título -f "different.go" -d Descripción --filename different.go script.py
$ glab snippet create --personal --title "Fragmento personal" script.py
