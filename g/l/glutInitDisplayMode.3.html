glutInitDisplayMode(3)

Paquete: freeglut

Licencias: X11

glutInitDisplayMode(3) freeglut glutInitDisplayMode(3)

NOMBRE

glutInitDisplayMode - establece el modo de visualización inicial.

SINTAXIS

void glutInitDisplayMode(unsigned int mode);

ARGUMENTOS

modo
Modo de visualización, normalmente la combinación bit a bit de las máscaras de bits del modo de visualización de GLUT. Consulte los valores a continuación:
GLUT_RGBA
Máscara de bits para seleccionar una ventana en modo RGBA. Este es el valor predeterminado si no se especifican ni GLUT_RGBA ni GLUT_INDEX.
GLUT_RGB
Un alias para GLUT_RGBA.
GLUT_INDEX
Máscara de bits para seleccionar una ventana en modo índice de color. Esto anula GLUT_RGBA si también se especifica.
GLUT_SINGLE
Máscara de bits para seleccionar una ventana de búfer único. Este es el valor predeterminado si no se especifican ni GLUT_DOUBLE ni GLUT_SINGLE.
GLUT_DOUBLE
Máscara de bits para seleccionar una ventana de búfer doble. Esto anula GLUT_SINGLE si también se especifica.
GLUT_ACCUM
Máscara de bits para solicitar una ventana con un búfer de acumulación.
GLUT_ALPHA
Máscara de bits para solicitar una ventana con un componente alfa en los búferes de color.
GLUT_DEPTH
Máscara de bits para solicitar una ventana con un búfer de profundidad.
GLUT_STENCIL
Máscara de bits para solicitar una ventana con un búfer de plantillas (stencil).
GLUT_MULTISAMPLE
Máscara de bits para solicitar una ventana con soporte de muestreo múltiple. Si el muestreo múltiple no está disponible, se elegirá automáticamente una ventana sin él. Nota: tanto la implementación del lado del cliente como la del lado del servidor de OpenGL deben admitir la extensión GLX_SAMPLE_SGIS para que el muestreo múltiple esté disponible.
GLUT_STEREO
Máscara de bits para seleccionar una ventana estéreo.
GLUT_LUMINANCE
Máscara de bits para seleccionar una ventana con un modelo de color de "luminancia". Este modelo proporciona la funcionalidad del modelo de color RGBA de OpenGL, pero los componentes verde y azul no se mantienen en el búfer de fotogramas. En su lugar, el componente rojo de cada píxel se convierte en un índice entre cero y glutGet(GLUT_WINDOW_COLORMAP_SIZE)-1 y se busca en un mapa de colores por ventana para determinar el color de los píxeles dentro de la ventana. El mapa de colores inicial de las ventanas GLUT_LUMINANCE se inicializa como una rampa de grises lineal, pero se puede modificar con las rutinas de mapa de colores de GLUT.

DESCRIPCIÓN

El modo de visualización inicial se utiliza al crear ventanas de nivel superior, subventanas y superposiciones para determinar el modo de visualización de OpenGL para la ventana o superposición que se creará.

Tenga en cuenta que GLUT_RGBA selecciona el modelo de color RGBA, pero no solicita que se asignen bits de alfa (a veces llamado búfer alfa o alfa de destino). Para solicitar alfa, especifique GLUT_ALPHA. Lo mismo se aplica a GLUT_LUMINANCE.

Tenga en cuenta que algunos bits "solicitan" una capacidad y otros bits "seleccionan" una capacidad. Una capacidad solicitable puede asignarse a la ventana creada incluso si el bit de la capacidad no estaba establecido. Por ejemplo, GLUT puede crear una ventana con un búfer de profundidad aunque no se especifique GLUT_DEPTH.

La rutina glutInitDisplayString proporciona una forma más potente de seleccionar las capacidades del búfer de fotogramas para las ventanas de GLUT.

GLUT_LUMINANCE NOTAS DE IMPLEMENTACIÓN

GLUT_LUMINANCE no se admite en la mayoría de las plataformas OpenGL.

VER TAMBIÉN

glutInit, glutCreateWindow, glutInitDisplayString
