NOMBRE

glBindTransformFeedback - enlaza un objeto de transformación de retroalimentación

ESPECIFICACIÓN EN C

void glBindTransformFeedback(GLenum target, GLuint id);

PARÁMETROS

target

Especifica el destino al que se enlazará el objeto de transformación de retroalimentación id. target debe ser GL_TRANSFORM_FEEDBACK.

id

Especifica el nombre de un objeto de transformación de retroalimentación reservado por glGenTransformFeedbacks().

DESCRIPCIÓN

glBindTransformFeedback enlaza el objeto de transformación de retroalimentación con el nombre id al estado actual de GL. id debe ser un nombre devuelto previamente por una llamada a glGenTransformFeedbacks(). Si id no se ha enlazado previamente, se creará un nuevo objeto de transformación de retroalimentación con el nombre id e inicializado con el vector de estado de transformación por defecto.

En el estado inicial, se enlaza un objeto de transformación de retroalimentación por defecto y se trata como un objeto de transformación de retroalimentación con un nombre de cero. Si posteriormente se enlaza el nombre cero, se volverá a enlazar el objeto de transformación de retroalimentación por defecto al estado de GL.

Mientras un objeto de búfer de transformación de retroalimentación esté enlazado, las operaciones de GL sobre el destino al que está enlazado afectan al objeto de transformación de retroalimentación enlazado, y las consultas del destino al que está enlazado un objeto de transformación de retroalimentación devuelven el estado del objeto enlazado. Cuando se enlazan objetos de búfer para transformación de retroalimentación, se adjuntan al objeto de transformación de retroalimentación actualmente enlazado. Los objetos de búfer se utilizan para la transformación de retroalimentación solo si están adjuntos al objeto de transformación de retroalimentación actualmente enlazado.

ERRORES

Se genera GL_INVALID_ENUM si target no es GL_TRANSFORM_FEEDBACK.

Se genera GL_INVALID_OPERATION si la operación de transformación de retroalimentación está activa en el objeto de transformación de retroalimentación actualmente enlazado, y esa operación no está pausada.

Se genera GL_INVALID_OPERATION si id no es cero o el nombre de un objeto de transformación de retroalimentación devuelto por una llamada previa a glGenTransformFeedbacks(), o si dicho nombre ha sido eliminado por glDeleteTransformFeedbacks().

GETS ASOCIADOS

glGet() con el argumento GL_TRANSFORM_FEEDBACK_BINDING
