DESCRIPCIÓ

N

glUnmapBuffer y glUnmapNamedBuffer desmapean (liberan) cualquier mapeo de un objeto buffer especificado en el espacio de direcciones del cliente (ver glMapBufferRange() y glMapBuffer())

.

Si un mapeo no se desmapea antes de que el almacén de datos del objeto buffer correspondiente sea utilizado por GL, se generará un error por cualquier comando GL que intente desreferenciar el almacén de datos del objeto buffer, a menos que el buffer haya sido mapeado exitosamente con GL_MAP_PERSISTENT_BIT (ver glMapBufferRange()). Cuando un almacén de datos es desmapeado, el puntero mapeado se vuelve

inválido.

glUnmapBuffer devuelve GL_TRUE a menos que el contenido del almacén de datos se haya corrompido durante el tiempo que el almacén de datos estuvo mapeado. Esto puede ocurrir por razones específicas del sistema que afectan la disponibilidad de memoria gráfica, como cambios en el modo de pantalla. En tales situaciones, GL_FALSE es devuelto y el contenido del almacén de datos es indefinido. Una aplicación debe detectar esta rara condición y reinicializar el almacén de

datos.

El almacén de datos mapeado de un objeto buffer es desmapeado automáticamente cuando el objeto buffer es eliminado o su almacén de datos es recreado con glBuffer

Data
()).
