NOMBRE

glsnake - Ciclo desperdiciador mejorado con OpenGL de Rubik's Snake.

SINOPSIS

glsnake [--display host:display.screen] [--window] [--root] [--window-id número] [--visual visual] [--delay microsegundos] [--fps] [--wireframe] [--altcolour] [--angvel angular] [--explode distancia] [--statictime milisegundos] [--yangvel ángulo] [--zangvel ángulo]

DESCRIPCIÓN

glsnake es una imitación de Rubiks´ Snake, utilizando OpenGL.

OPCIONES

glsnake acepta las siguientes opciones:

--window
Dibujar en una ventana recién creada. Esta es la opción predeterminada.
--root
Dibujar en la ventana raíz.
--window-id número
Dibujar en la ventana especificada.
--install
Instalar un mapa de colores privado para la ventana.
--visual visual
Especificar qué visual usar. Los valores legales son el nombre de una clase visual, o el número de ID (decimal o hexadecimal) de un visual específico.
--fps
Mostrar la velocidad de fotogramas actual, la carga de la CPU y el recuento de polígonos.
--wireframe
Mostrar la serpiente en modo de alambre, en lugar del modo sólido predeterminado.
--altcolour
Usar el esquema de colores alternativo para la serpiente. La identificación de formas mediante el color se desactivará.
-angvel angular
Cambiar la velocidad a la que la serpiente se transforma a una nueva forma.
-explode distancia
Cambiar la distancia entre los nodos de una serpiente.
--statictime milisegundos
Cambiar el tiempo entre transformaciones.
--yangvel ángulo
Cambiar el ángulo de rotación alrededor del eje Y por fotograma.
--zangvel ángulo
Cambiar el ángulo de rotación alrededor del eje Z por fotograma.

AMBIENTE

DISPLAY
para obtener el host y el número de pantalla predeterminados.
XENVIRONMENT
para obtener el nombre de un archivo de recursos que anula los recursos globales almacenados en la propiedad RESOURCE_MANAGER.
XSCREENSAVER_WINDOW
El ID de ventana a usar con --root.

VER TAMBIÉN

X(1), xscreensaver(1),
https://spacepants.org/src/glsnake/

ERRORES

La serpiente se intersectará felizmente consigo misma mientras se transforma (esto no es un error).

La rotación/posición de la cámara es pésima.
