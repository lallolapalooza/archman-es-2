NOMBRE

glGetActiveAtomicCounterBufferiv - recupera información sobre el conjunto de búferes de contador atómico activos para un programa

ESPECIFICACIÓN C

void glGetActiveAtomicCounterBufferiv(GLuint program, GLuint bufferIndex, GLenum pname, GLint *params);

PARÁMETROS

program

El nombre de un objeto de programa del cual recuperar información.

bufferIndex

Especifica el índice de un búfer de contador atómico activo.

pname

Especifica qué parámetro del búfer de contador atómico recuperar.

params

Especifica la dirección de una variable en la que escribir la información recuperada.

DESCRIPCIÓN

glGetActiveAtomicCounterBufferiv recupera información sobre el conjunto de búferes de contador atómico activos para un objeto de programa. program es el nombre de un objeto de programa para el cual se ha emitido el comando glLinkProgram() en el pasado. No es necesario que program se haya enlazado correctamente. El enlace puede haber fallado debido a que el número de contadores atómicos activos excedió los límites.

bufferIndex especifica el índice de un búfer de contador atómico activo y debe estar en el rango de cero hasta el valor de GL_ACTIVE_ATOMIC_COUNTER_BUFFERS menos uno. El valor de GL_ACTIVE_ATOMIC_COUNTER_BUFFERS para program indica el número de búferes de contador atómico activos y se puede consultar con glGetProgram().

Si no ocurre ningún error, los parámetros especificados por pname se devuelven en params. Si se genera un error, el contenido de params no se modifica.

Si pname es GL_ATOMIC_COUNTER_BUFFER_BINDING, se devuelve el índice del punto de enlace del búfer de contador asociado con el búfer de contador atómico activo bufferIndex para program.

Si pname es GL_ATOMIC_COUNTER_BUFFER_DATA_SIZE, se devuelve el tamaño mínimo del objeto de búfer dependiente de la implementación, en unidades de máquina básicas, requerido para contener todos los contadores atómicos activos en el punto de enlace del contador atómico identificado por bufferIndex.

Si pname es GL_ATOMIC_COUNTER_BUFFER_ACTIVE_ATOMIC_COUNTERS, se devuelve el número de contadores atómicos activos para el búfer de contador atómico identificado por bufferIndex.

Si pname es GL_ATOMIC_COUNTER_BUFFER_ACTIVE_ATOMIC_COUNTER_INDICES, se devuelve una lista de los índices de contadores atómicos activos para el búfer de contador atómico identificado por bufferIndex. El número de elementos que se escribirán en params es el valor de GL_ATOMIC_COUNTER_BUFFER_ACTIVE_ATOMIC_COUNTERS para bufferIndex.

Si pname es GL_ATOMIC_COUNTER_BUFFER_REFERENCED_BY_VERTEX_SHADER, GL_ATOMIC_COUNTER_BUFFER_REFERENCED_BY_TESS_CONTROL_SHADER, GL_ATOMIC_COUNTER_BUFFER_REFERENCED_BY_TESS_EVALUATION_SHADER, GL_ATOMIC_COUNTER_BUFFER_REFERENCED_BY_GEOMETRY_SHADER, GL_ATOMIC_COUNTER_BUFFER_REFERENCED_BY_FRAGMENT_SHADER, GL_ATOMIC_COUNTER_BUFFER_REFERENCED_BY_COMPUTE_SHADER entonces se devuelve un valor booleano que indica si el búfer de contador atómico identificado por bufferIndex es referenciado por las etapas de vértice, control de teselado, evaluación de teselado, geometría, fragmento o cálculo de program, respectivamente.

NOTAS

glGetActiveAtomicCounterBufferiv solo está disponible si la versión de GL es 4.2 o superior.

GL_ATOMIC_COUNTER_BUFFER_REFERENCED_BY_COMPUTE_SHADER solo está disponible si la versión de GL es 4.3 o superior.

ERRORES

Se genera GL_INVALID_VALUE si program no es el nombre de un objeto de programa para el cual se ha llamado a glLinkProgram() en el pasado.

Se genera GL_INVALID_VALUE si bufferIndex es mayor o igual que el valor de GL_ACTIVE_ATOMIC_COUNTER_BUFFERS para program.

Se genera GL_INVALID_ENUM si pname no es uno de los tokens aceptados.
