NAME

glTexStorage2D, glTextureStorage2D - specify immutable storage for a 2D texture

C SPECIFICATION

void glTexStorage2D(GLenum target, GLint levels, GLenum internalformat, GLsizei width, GLsizei height);

void glTextureStorage2D(GLuint texture, GLint levels, GLenum internalformat, GLsizei width, GLsizei height);

PARAMETERS

target
Specifies the target texture. See the description of target in glTexImage2D. For glTextureStorage2D, texture is the texture object to be modified.
levels
Specifies the number of texture levels. This must be 1 if the texture is immutable.
internalformat
Specifies the internal format of the texture. The format must be a sized internal format. See the section "Formats for immutable images" in glTexStorage2D.
width
Specifies the width of the texture image.
height
Specifies the height of the texture image.
texture
Specifies the texture object name for glTextureStorage2D.

DESCRIPTION

glTexStorage2D and glTextureStorage2D specify the complete storage for a 2D texture, or an array of 2D textures, or a cubemap texture, or an array of cubemap textures. Once the storage is specified, it is immutable. The texture will remain immutable until it is deleted.

The texture targets supported by glTexStorage2D are GL_TEXTURE_2D, GL_TEXTURE_1D_ARRAY, GL_TEXTURE_2D_ARRAY, GL_TEXTURE_CUBE_MAP, GL_PROXY_TEXTURE_2D, GL_PROXY_TEXTURE_1D_ARRAY, GL_PROXY_TEXTURE_2D_ARRAY, and GL_PROXY_TEXTURE_CUBE_MAP.

The texture targets supported by glTextureStorage2D are GL_TEXTURE_2D, GL_TEXTURE_1D_ARRAY, GL_TEXTURE_2D_ARRAY, and GL_TEXTURE_CUBE_MAP.

The internalformat specifies the number of components and the internal precision of the texture. The table below lists the accepted sized internal formats for glTexStorage2D and glTextureStorage2D.

NOTES

GL_STENCIL_INDEX8
is accepted for internalformat only if the GL version is 4.4 or higher.

ERRORS

GL_INVALID_OPERATION is generated by glTexStorage2D if zero is bound to target.

GL_INVALID_OPERATION is generated by glTextureStorage2D if texture is not the name of an existing texture object.

GL_INVALID_ENUM is generated if internalformat is not a valid sized internal format.

GL_INVALID_ENUM is generated if target or the effective target of texture is not one of the accepted targets described above.

GL_INVALID_VALUE is generated if width, height or levels are less than 1.

GL_INVALID_OPERATION is generated if target is GL_TEXTURE_1D_ARRAY or GL_PROXY_TEXTURE_1D_ARRAY and levels is greater than log 2 width + 1.

GL_INVALID_OPERATION is generated if target is not GL_TEXTURE_1D_ARRAY or GL_PROXY_TEXTURE_1D_ARRAY and levels is greater than log 2 max width ,   height + 1.
