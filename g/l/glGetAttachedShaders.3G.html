NOMBRE

glGetAttachedShaders - Devuelve los identificadores de los objetos de sombreado adjuntos a un objeto de programa

ESPECIFICACIÓN C

void glGetAttachedShaders(GLuint program, GLsizei maxCount, GLsizei *count, GLuint *shaders);

PARÁMETROS

program

Especifica el objeto de programa a consultar.

maxCount

Especifica el tamaño del array para almacenar los nombres de objeto devueltos.

count

Devuelve el número de nombres realmente devueltos en shaders.

shaders

Especifica un array que se utiliza para devolver los nombres de los objetos de sombreado adjuntos.

DESCRIPCIÓN

glGetAttachedShaders devuelve los nombres de los objetos de sombreado adjuntos a program. Los nombres de los objetos de sombreado que están adjuntos a program se devolverán en shaders. El número real de nombres de sombreado escritos en shaders se devuelve en count. Si no hay objetos de sombreado adjuntos a program, count se establece en 0. El número máximo de nombres de sombreado que se pueden devolver en shaders se especifica mediante maxCount.

Si no se requiere el número real de nombres devueltos (por ejemplo, si se acaba de obtener llamando a glGetProgram()), se puede pasar un valor de NULL para count. Si no hay objetos de sombreado adjuntos a program, se devolverá un valor de 0 en count. El número real de sombreados adjuntos se puede obtener llamando a glGetProgram() con el valor GL_ATTACHED_SHADERS.

ERRORES

GL_INVALID_VALUE se genera si program no es un valor generado por OpenGL.

GL_INVALID_OPERATION se genera si program no es un objeto de programa.

GL_INVALID_VALUE se genera si maxCount es menor que 0.

GETS ASOCIADOS

glGetProgram() con el argumento GL_ATTACHED_SHADERS

glIsProgram()
