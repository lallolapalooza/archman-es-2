NOMBRE

glab-cluster-agent-get-token - Crea y devuelve un token de acceso personal con ámbito k8s_proxy para autenticarse con Agentes de GitLab para Kubernetes.

SINOPSIS

glab cluster agent get-token [flags]

DESCRIPCIÓN

Crea y devuelve un token de acceso personal con ámbito k8s_proxy para autenticarse con Agentes de GitLab para Kubernetes.

Este comando crea un token de acceso personal que es válido hasta el final del día actual. Es posible que reciba un correo electrónico de su instancia de GitLab indicando que se ha creado un nuevo token de acceso personal.

OPCIONES

-a, --agent=0 El ID numérico del Agente al que conectarse.

-c, --cache-mode="force-keyring" Modo a utilizar para almacenar en caché el token. Valores permitidos: keyring-filesystem-fallback, force-keyring, force-filesystem, no

--check-revoked[=false] Comprueba si un token en caché ha sido revocado. Esto requiere una llamada a la API de GitLab, lo que añade latencia cada vez que se accede a un token en caché.

--token-expiry-duration=24h0m0s Duración de la validez de los tokens generados. El mínimo es 1 día y la expiración efectiva siempre es al final del día, se ignora la hora.

OPCIONES HEREDADAS DE COMANDOS PADRE

-h, --help[=false] Mostrar ayuda para este comando.

-R, --repo="" Seleccionar otro repositorio. Puede usar el formato PROPIETARIO/REPO o GRUPO/NAMESPACE/REPO. También acepta URL completa o URL de Git.
