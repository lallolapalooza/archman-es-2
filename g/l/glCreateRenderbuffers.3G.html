NOMBRE

glCreateRenderbuffers - crear objetos de búfer de renderizado

ESPECIFICACIÓN C

void glCreateRenderbuffers(GLsizei n, GLuint *renderbuffers);

PARÁMETROS

n

Número de objetos de búfer de renderizado a crear.

renderbuffers

Especifica un array en el que se almacenan los nombres de los nuevos objetos de búfer de renderizado.

DESCRIPCIÓN

glCreateRenderbuffers devuelve n nombres de objetos de búfer de renderizado previamente no utilizados en renderbuffers, cada uno representando un nuevo objeto de búfer de renderizado inicializado a su estado predeterminado.

ERRORES

GL_INVALID_VALUE se genera si n es negativo.
