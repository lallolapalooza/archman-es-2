NOMBRE

glDrawTransformFeedbackStream - dibuja primitivas usando un recuento derivado de un stream específico de un objeto de retroalimentación de transformación

ESPECIFICACIÓN EN C

void glDrawTransformFeedbackStream(GLenum mode, GLuint id, GLuint stream);

PARÁMETROS

mode

Especifica qué tipo de primitivas dibujar. Se aceptan las constantes simbólicas GL_POINTS, GL_LINE_STRIP, GL_LINE_LOOP, GL_LINES, GL_LINE_STRIP_ADJACENCY, GL_LINES_ADJACENCY, GL_TRIANGLE_STRIP, GL_TRIANGLE_FAN, GL_TRIANGLES, GL_TRIANGLE_STRIP_ADJACENCY, GL_TRIANGLES_ADJACENCY y GL_PATCHES.

id

Especifica el nombre de un objeto de retroalimentación de transformación del cual obtener un recuento de primitivas.

stream

Especifica el índice del stream de retroalimentación de transformación del cual obtener un recuento de primitivas.

DESCRIPCIÓN

glDrawTransformFeedbackStream dibuja primitivas del tipo especificado por mode usando un recuento recuperado del stream de retroalimentación de transformación especificado por stream del objeto de retroalimentación de transformación especificado por id. Llamar a glDrawTransformFeedbackStream es equivalente a llamar a glDrawArrays() con mode como se especifica, first establecido a cero, y count establecido al número de vértices capturados en el stream de vértices stream la última vez que la retroalimentación de transformación estuvo activa en el objeto de retroalimentación de transformación nombrado por id.

Llamar a glDrawTransformFeedback() es equivalente a llamar a glDrawTransformFeedbackStream con stream establecido a cero.

ERRORES

Se genera GL_INVALID_ENUM si mode no es un valor aceptado.

Se genera GL_INVALID_VALUE si id no es el nombre de un objeto de retroalimentación de transformación.

Se genera GL_INVALID_VALUE si stream es mayor o igual al valor de GL_MAX_VERTEX_STREAMS.

Se genera GL_INVALID_OPERATION si un objeto de buffer no cero está enlazado a un array habilitado y el almacén de datos del objeto de buffer está actualmente mapeado.

Se genera GL_INVALID_OPERATION si un shader de geometría está activo y mode es incompatible con el tipo de primitiva de entrada del shader de geometría en el objeto de programa instalado actualmente.

Se genera GL_INVALID_OPERATION si mode es GL_PATCHES y no hay ningún shader de control de teselación activo.

Se genera GL_INVALID_OPERATION si

glEndTransformFeedback nunca ha sido llamado mientras el objeto de retroalimentación de transformación nombrado por id estaba enlazado.
