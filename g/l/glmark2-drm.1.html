GLMARK2-DRM(1) Manual de comandos generales GLMARK2-DRM(1)

NOMBRE

glmark2-drm - suite de puntos de referencia de OpenGL (ES) 2.0

SINOPSIS

glmark2-drm [opciones]

DESCRIPCIÓN

glmark2-drm es un punto de referencia para OpenGL (ES) 2.0. Solo utiliza el subconjunto de la API de OpenGL 2.0 que es compatible con OpenGL ES 2.0.

OPCIONES

-b, --benchmark BENCH
Un punto de referencia para ejecutar: 'scene(:opt1=val1)*' (la opción se puede usar varias veces)
-f, --benchmark-file ARCHIVO
Cargar puntos de referencia para ejecutar desde un archivo que contiene una lista de descripciones de puntos de referencia (una por línea) (la opción se puede usar varias veces)
--validate
Ejecutar una prueba rápida de validación de salida en lugar de ejecutar los puntos de referencia
--data-path RUTA
Ruta a los modelos, shaders y texturas de glmark2
--frame-end METODO
Cómo finalizar un fotograma [default,none,swap,finish,readpixels]
--swap-mode MODO
Cómo intercambiar un fotograma, todos los modos compatibles solo en el flavor DRM, 'fifo' disponible en todos los flavors para forzar vsync [default,immediate,mailbox,fifo]
--off-screen
Renderizar a una superficie fuera de pantalla
--visual-config
La configuración visual a utilizar para el objetivo de renderizado: ´id=ID:red=R:green=G:blue=B:alpha=A:buffer=BUF:stencil=STENCIL:samples=SAMPLES'. Los parámetros se pueden definir en cualquier orden, y cualquier parámetro omitido asume un valor predeterminado de '0' (id, stencil, samples) o '1' (red, green, blue, alpha, buffer). Si 'id' se establece en un valor distinto de cero, todos los demás parámetros se ignoran
--reuse-context
Utilizar un único contexto para todas las escenas (por defecto, cada escena obtiene su propio contexto)
-s, --size AXA
Tamaño de la ventana de salida (predeterminado: 800x600)
--fullscreen
Ejecutar en modo de pantalla completa (equivalente a --size -1x-1)
--results RESULTADOS
Los tipos de resultados a informar para cada punto de referencia, como una lista separada por ':' [fps,cpu,shader]
--results-file ARCHIVO-RESULTADOS
El archivo donde guardar los resultados, en el formato determinado por la extensión del archivo [csv,xml]
--winsys-options OPTS
Una lista de pares 'opt=value' para opciones específicas del sistema de ventanas, separadas por ':'
-l, --list-scenes
Mostrar información sobre las escenas disponibles y sus opciones
--show-all-options
Mostrar todos los valores de opciones de escena utilizados para los puntos de referencia (por defecto, solo se muestran las opciones configuradas explícitamente)
--run-forever
Ejecutar indefinidamente, repitiendo desde el último punto de referencia hasta el primero
--annotate
Anotar los puntos de referencia con información en pantalla (igual que -b :show-fps=true:title=#info#)
-d, --debug
Mostrar mensajes de depuración
--version
Mostrar la versión del programa
-h, --help
Mostrar ayuda

PUNTOS DE REFERENCIA

glmark2-drm ofrece un conjunto de escenas que se pueden utilizar para medir muchos aspectos del rendimiento de OpenGL (ES) 2.0. La forma en que se renderiza cada escena es configurable a través de un conjunto de opciones. Para obtener las escenas disponibles y sus opciones aceptables, puede usar la opción de línea de comandos -l, --list-scenes.

En glmark2-drm, un punto de referencia se define como una escena más un conjunto de valores de opción. Puede especificar la lista y el orden de los puntos de referencia a ejecutar utilizando la opción de línea de comandos -b, --benchmark (posiblemente varias veces). Si no se especifican puntos de referencia, se utiliza un conjunto predeterminado de puntos de referencia. Si no se especifica una opción de punto de referencia, asume su valor predeterminado (listado con -l, --list-scenes).

Como caso especial, se permite que una cadena de descripción de punto de referencia no contenga un nombre de escena (es decir, que comience con ':'). En este caso, cualquier valor de opción especificado se usa como los valores predeterminados para los puntos de referencia que siguen a esta cadena de descripción.

EJEMPLOS

Para ejecutar los puntos de referencia predeterminados:

glmark2-drm

Para ejecutar un punto de referencia utilizando la escena 'shading' con una 'duration' de 5.0 segundos y 'shading' de tipo 'phong':

glmark2-drm -b shading:duration=5.0:shading=phong

Para ejecutar una serie de puntos de referencia, use la opción de línea de comandos -b, --benchmark varias veces:

glmark2-drm -b shading:duration=5.0 -b build:use-vbo=false -b texture

Para establecer valores de opción predeterminados para los puntos de referencia:

glmark2-drm -b :duration=2.0 -b shading -b build -b :duration=5.0 -b texture
