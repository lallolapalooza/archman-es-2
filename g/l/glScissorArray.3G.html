NOMBRE

glScissorArray - define el cuadro de tijera para múltiples vistas

ESPECIFICACIÓN C

void glScissorArrayv(GLuint first, GLsizei count, const GLint *v);

PARÁMETROS

first

Especifica el índice de la primera vista cuyo cuadro de tijera se modificará.

count

Especifica el número de cuadros de tijera a modificar.

v

Especifica la dirección de un array que contiene la izquierda, la parte inferior, el ancho y la altura de cada cuadro de tijera, en ese orden.

DESCRIPCIÓN

glScissorArrayv define rectángulos, llamados cuadros de tijera, en coordenadas de ventana para cada vista. first especifica el índice del primer cuadro de tijera a modificar y count especifica el número de cuadros de tijera a modificar. first debe ser menor que el valor de GL_MAX_VIEWPORTS, y first + count debe ser menor o igual al valor de GL_MAX_VIEWPORTS. v especifica la dirección de un array que contiene enteros que especifican la esquina inferior izquierda de los cuadros de tijera, y el ancho y la altura de los cuadros de tijera, en ese orden.

Para habilitar y deshabilitar la prueba de tijera, llame a glEnable() y

glDisable() con el argumento GL_SCISSOR_TEST. La prueba está inicialmente deshabilitada para todas las vistas. Mientras la prueba esté habilitada, solo los píxeles que se encuentren dentro del cuadro de tijera podrán ser modificados por los comandos de dibujo. Las coordenadas de la ventana tienen valores enteros en las esquinas compartidas de los píxeles del búfer de fotogramas. glScissor(0,0,1,1) permite la modificación solo del píxel inferior izquierdo en la ventana, y glScissor(0,0,0,0) no permite la modificación de ningún píxel en la ventana.

Cuando la prueba de tijera está deshabilitada, es como si el cuadro de tijera incluyera toda la ventana.

ERRORES

Se genera GL_INVALID_VALUE si first es mayor o igual al valor de GL_MAX_VIEWPORTS.

Se genera GL_INVALID_VALUE si first + count es mayor o igual al valor de GL_MAX_VIEWPORTS.

Se genera GL_INVALID_VALUE si algún ancho o altura especificado en el array v es negativo.

GETS ASOCIADOS

glGet() con el argumento GL_SCISSOR_BOX

glIsEnabled() con el argumento GL_SCISSOR_TEST
