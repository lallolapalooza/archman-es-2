NOMBRE

glTexSubImage2D, glTextureSubImage2D - especificar una subimagen de textura bidimensional

C ESPECIFICACIÓN

void glTexSubImage2D(GLenum target, GLint level, GLint xoffset, GLint yoffset, GLsizei width, GLsizei height, GLenum format, GLenum type, const void * pixels);

void glTextureSubImage2D(GLuint texture, GLint level, GLint xoffset, GLint yoffset, GLsizei width, GLsizei height, GLenum format, GLenum type, const void *pixels);

PARÁMETROS

target

Especifica el objetivo al que se enlaza la textura para glTexSubImage2D. Debe ser GL_TEXTURE_2D, GL_TEXTURE_CUBE_MAP_POSITIVE_X, GL_TEXTURE_CUBE_MAP_NEGATIVE_X, GL_TEXTURE_CUBE_MAP_POSITIVE_Y, GL_TEXTURE_CUBE_MAP_NEGATIVE_Y, GL_TEXTURE_CUBE_MAP_POSITIVE_Z, GL_TEXTURE_CUBE_MAP_NEGATIVE_Z, o GL_TEXTURE_1D_ARRAY.

texture

Especifica el nombre del objeto de textura para glTextureSubImage2D. El objetivo efectivo de texture debe ser uno de los valores válidos de target anteriores.

level

Especifica el número de nivel de detalle. El nivel 0 es el nivel de imagen base. El nivel n es la imagen de reducción mipmap n.

xoffset

Especifica un desplazamiento de texel en la dirección x dentro del array de texturas.

yoffset

Especifica un desplazamiento de texel en la dirección y dentro del array de texturas.

width

Especifica el ancho de la subimagen de textura.

height

Especifica la altura de la subimagen de textura.

format

Especifica el formato de los datos de píxeles. Se aceptan los siguientes valores simbólicos: GL_RED, GL_RG, GL_RGB, GL_BGR, GL_RGBA, GL_BGRA, GL_DEPTH_COMPONENT y GL_STENCIL_INDEX.

type

Especifica el tipo de datos de los datos de píxeles. Se aceptan los siguientes valores simbólicos: GL_UNSIGNED_BYTE, GL_BYTE, GL_UNSIGNED_SHORT, GL_SHORT, GL_UNSIGNED_INT, GL_INT, GL_FLOAT, GL_UNSIGNED_BYTE_3_3_2, GL_UNSIGNED_BYTE_2_3_3_REV, GL_UNSIGNED_SHORT_5_6_5, GL_UNSIGNED_SHORT_5_6_5_REV, GL_UNSIGNED_SHORT_4_4_4_4, GL_UNSIGNED_SHORT_4_4_4_4_REV, GL_UNSIGNED_SHORT_5_5_5_1, GL_UNSIGNED_SHORT_1_5_5_5_REV, GL_UNSIGNED_INT_8_8_8_8, GL_UNSIGNED_INT_8_8_8_8_REV, GL_UNSIGNED_INT_10_10_10_2 y GL_UNSIGNED_INT_2_10_10_10_REV.

pixels

Especifica un puntero a los datos de la imagen en memoria.

DESCRIPCIÓN

La texturización mapea una porción de una imagen de textura especificada a cada primitiva gráfica para la que se habilita la texturización.

glTexSubImage2D y glTextureSubImage2D redefinen una subregión contigua de una imagen de textura bidimensional o de array unidimensional existente. La región especificada por pixels reemplaza la porción del array de textura existente con índices x xoffset y xoffset + width - 1, inclusive, e índices y yoffset y yoffset + height - 1, inclusive. Esta región no puede incluir ningún texel fuera del rango del array de textura tal como se especificó originalmente. No es un error especificar una subtextura con ancho o alto cero, pero dicha especificación no tiene ningún efecto.

Si un objeto de buffer nombrado no nulo está enlazado al objetivo GL_PIXEL_UNPACK_BUFFER (ver glBindBuffer()) mientras se especifica una imagen de textura, pixels se trata como un desplazamiento de bytes en el almacén de datos del objeto de buffer.

NOTAS

Los modos de glPixelStore() afectan a las imágenes de textura.

glTexSubImage2D y glTextureSubImage3D especifican una subtextura bidimensional para la unidad de textura actual, especificada con glActiveTexture().

GL_STENCIL_INDEX se acepta para format solo si la versión de GL es 4.4 o superior.

ERRORES

Se genera GL_INVALID_ENUM si target o el objetivo efectivo de texture no es GL_TEXTURE_2D, GL_TEXTURE_CUBE_MAP_POSITIVE_X, GL_TEXTURE_CUBE_MAP_NEGATIVE_X, GL_TEXTURE_CUBE_MAP_POSITIVE_Y, GL_TEXTURE_CUBE_MAP_NEGATIVE_Y, GL_TEXTURE_CUBE_MAP_POSITIVE_Z, GL_TEXTURE_CUBE_MAP_NEGATIVE_Z, o GL_TEXTURE_1D_ARRAY.

GL_INVALID_OPERATION es generado por glTextureSubImage2D si texture no es el nombre de un objeto de textura existente.

Se genera GL_INVALID_ENUM si format no es una constante de formato aceptada.

Se genera GL_INVALID_ENUM si type no es una constante de tipo.

Se genera GL_INVALID_VALUE si level es menor que 0.

Se puede generar GL_INVALID_VALUE si level es mayor que log 2 max, donde max es el valor devuelto por GL_MAX_TEXTURE_SIZE.

Se genera GL_INVALID_VALUE si xoffset < - b, xoffset + width > w - b, yoffset < - b, o yoffset + height > h - b, donde w es el GL_TEXTURE_WIDTH, h es el GL_TEXTURE_HEIGHT, y b es el ancho del borde de la imagen de textura que se está modificando. Tenga en cuenta que w y h incluyen el doble del ancho del borde.

Se genera GL_INVALID_VALUE si width o height es menor que 0.

Se genera GL_INVALID_OPERATION si el array de textura no ha sido definido por una operación anterior de glTexImage2D().

Se genera GL_INVALID_OPERATION si type es uno de GL_UNSIGNED_BYTE_3_3_2, GL_UNSIGNED_BYTE_2_3_3_REV, GL_UNSIGNED_SHORT_5_6_5, o GL_UNSIGNED_SHORT_5_6_5_REV y format no es GL_RGB.

Se genera GL_INVALID_OPERATION si type es uno de GL_UNSIGNED_SHORT_4_4_4_4, GL_UNSIGNED_SHORT_4_4_4_4_REV, GL_UNSIGNED_SHORT_5_5_5_1, GL_UNSIGNED_SHORT_1_5_5_5_REV, GL_UNSIGNED_INT_8_8_8_8, GL_UNSIGNED_INT_8_8_8_8_REV, GL_UNSIGNED_INT_10_10_10_2, o GL_UNSIGNED_INT_2_10_10_10_REV y format no es GL_RGBA ni GL_BGRA.

Se genera GL_INVALID_OPERATION si format es GL_STENCIL_INDEX y el formato interno base no es GL_STENCIL_INDEX.

Se genera GL_INVALID_OPERATION si un objeto de buffer con nombre no nulo está enlazado al objetivo GL_PIXEL_UNPACK_BUFFER y el almacén de datos del objeto de buffer está actualmente mapeado.

Se genera GL_INVALID_OPERATION si un objeto de buffer con nombre no nulo está enlazado al objetivo GL_PIXEL_UNPACK_BUFFER y los datos se desempaquetarían del objeto de buffer de tal manera que las lecturas de memoria requeridas excederían el tamaño del almacén de datos.

Se genera GL_INVALID_OPERATION si un objeto de buffer con nombre no nulo está enlazado al objetivo GL_PIXEL_UNPACK_BUFFER y pixels no es divisible uniformemente por el número de bytes necesarios para almacenar en memoria un dato indicado por type.
