glutJoystickFunc(3)

Paquete: freeglut

Licencias: X11

glutJoystickFunc(3) freeglut glutJoystickFunc(3)

NOMBRE

glutJoystickFunc - establece la función de callback del joystick para la ventana actual.

SINTAXIS

void glutJoystickFunc(void (*func)(unsigned int buttonMask,
                     int x, int y, int z), int pollInterval);

ARGUMENTOS

func
La nueva función de callback del joystick.
pollInterval
Intervalo de sondeo del joystick en milisegundos.

DESCRIPCIÓN

glutJoystickFunc establece la función de callback del joystick para la ventana actual.

La función de callback del joystick se llama ya sea debido al sondeo del joystick en el intervalo de tiempo uniforme especificado por pollInterval (en milisegundos) o en respuesta a llamar a glutForceJoystickFunc. Si pollInterval no es positivo, no se realiza ningún sondeo del joystick y la aplicación GLUT debe llamar frecuentemente (generalmente desde una función de callback inactiva) a glutForceJoystickFunc.

Los botones del joystick se informan a través del parámetro buttonMask de la función de callback. Las constantes GLUT_JOYSTICK_BUTTON_A (0x1), GLUT_JOYSTICK_BUTTON_B (0x2), GLUT_JOYSTICK_BUTTON_C (0x4) y GLUT_JOYSTICK_BUTTON_D (0x8) se proporcionan para facilitar la programación.

Los parámetros x, y, z de la función de callback informan sobre los ejes X, Y y Z del joystick. El joystick está centrado en (0,0,0). X, Y y Z se escalan para que oscilen entre -1000 y 1000. Mover el joystick hacia la izquierda informa X negativo; moverlo hacia la derecha informa X positivo. Empujar la palanca hacia usted informa Y negativo; alejar la palanca de usted informa Y positivo. Si el joystick tiene un tercer eje (timón o arriba/abajo), bajar informa Z negativo; subir informa Z positivo.

Pasar un valor de func NULL a glutJoystickFunc deshabilita la generación de callbacks del joystick. Sin una función de callback de joystick registrada, glutForceJoystickFunc no hace nada.

Cuando se crea una nueva ventana, inicialmente no se registra ninguna función de callback de joystick.

LIMITACIONES

La función de callback de joystick de GLUT solo informa los primeros 3 ejes y 32 botones. GLUT solo admite un único joystick.

NOTAS DE IMPLEMENTACIÓN GLUT PARA X11

La implementación actual de GLUT para X11 admite la API del joystick, pero no la entrada del joystick. Una implementación futura de GLUT para X11 puede agregar soporte para joystick.

NOTAS DE IMPLEMENTACIÓN GLUT PARA WIN32

La implementación actual de GLUT para Win32 admite la API del joystick y la entrada del joystick, pero lo hace a través de la antigua API Multimedia Win32 joySetCapture y joyGetPosEx. El soporte actual de joystick de GLUT para Win32 tiene todas las limitaciones del soporte de joystick de la API Multimedia Win32. Una implementación futura de GLUT para Win32 puede usar DirectInput.

NOTAS DE IMPLEMENTACIÓN GLUT PARA JOYSTICKS NO ANALÓGICOS

Si el joystick conectado no devuelve (x,y,z) como un rango continuo (por ejemplo, un joystick Atari 2600 de 8 posiciones), la implementación debe informar la ubicación más extrema (x,y,z). Es decir, si un joystick 2D se empuja hacia la parte superior izquierda, informe (-1000,1000,0).
