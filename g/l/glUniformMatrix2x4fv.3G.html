DESCRIPTION glUniform modifie la valeur d'une variable uniforme ou d'un tableau de variables uniformes. L'emplacement de la variable uniforme à modifier est spécifié par location, qu

i doit

être une valeur retournée par glGetUniformLocation(). glUniform opère sur l'objet programme qui a été rendu partie de l'état courant en appelant glUseProgram(). Les commandes glUniform{1|2|3|4}{f|i|ui} sont utilisées pour changer la valeur de la variable uniforme spécifiée par 1 pour float, int, unsigned int, bool ; 2 pour vec2, ivec2, uvec2, bvec2, etc.). Le suffixe f indique que des valeurs en virgule flottante sont passées ; le suffixe i indique que des valeurs entières sont passées ; le suffixe ui indique que des valeurs entières non signées sont passées, et ce type doit également correspondre au type de données de la variable uniforme spécifiée. Les variantes i de cette fonction doivent être utilisées pour fournir des valeurs pour des variables uniformes définies as int, ivec2, ivec3, ivec4, o arrays de estos. Las variantes ui de esta función deben usarse para proporcionar valores para variables uniformes definidas como unsigned int, uvec2, uvec3, uvec4, o arrays de estos. Las variantes f deben usarse para proporcionar valores para variables uniformes de tipo float, vec2, vec3, vec4, o arrays de estos. Cualquiera de las variantes i, ui o f puede usarse para proporcionar valores para variables uniformes de tipo bool, bvec2, bvec3, bvec4, o arrays de estos. La variable uniforme se establecerá en false si el valor de entrada es 0 o 0.0f, y se establecerá en true en caso contrario.

Todas las variables uniformes activas definidas en un objeto de programa se inicializan a 0 cuando el objeto de programa se vincula correctamente. Conservan los valores que se les asignan mediante una llamada a glUniform hasta la siguiente operación de vinculación exitosa en el objeto de programa, momento en el que se inicializan nuevamente a 0.

Los comandos glUniform{1|2|3|4}{f|i|ui}v pueden usarse para modificar una sola variable uniforme o un array de variables uniformes. Estos comandos pasan un recuento y un puntero a los valores que se cargarán en una variable uniforme o un array de variables uniformes. Se debe usar un recuento de 1 si se modifica el valor de una sola variable uniforme, y se puede usar un recuento de 1 o mayor para modificar un array completo o parte de un array. Al cargar n elementos comenzando en una posición arbitraria m en un array de variables uniformes, los elementos m + n - 1 en el array serán reemplazados con los nuevos valores. Si m + n - 1 es mayor que el tamaño del array de variables uniformes, los valores para todos los elementos del array más allá del final del array se ignorarán. El número especificado en el nombre del comando indica el número de componentes para cada elemento en value, y debe coincidir con el número de componentes en el tipo de datos de la variable uniforme especificada (por ejemplo, 1 para float, int, bool; 2 para vec2, ivec2, bvec2, etc.). El tipo de datos especificado en el nombre del comando debe coincidir con el tipo de datos de la variable uniforme especificada, como se describió anteriormente para glUniform{1|2|3|4}{f|i|ui}.

Para arrays de variables uniformes, cada elemento del array se considera del tipo indicado en el nombre del comando (por ejemplo, glUniform3f o glUniform3fv se pueden usar para cargar un array de variables uniformes de tipo vec3). El número de elementos del array de variables uniformes a modificar se especifica mediante count.

Los comandos glUniformMatrix{2|3|4|2x3|3x2|2x4|4x2|3x4|4x3}fv se utilizan para modificar una matriz o un array de matrices. Los números en el nombre del comando se interpretan como la dimensionalidad de la matriz. El número 2 indica una matriz de 2 × 2 (es decir, 4 valores), el número 3 indica una matriz de 3 × 3 (es decir, 9 valores), y el número 4 indica una matriz de 4 × 4 (es decir, 16 valores). La dimensionalidad de matrices no cuadradas es explícita, y el primer número representa el número de columnas y el segundo número representa el número de filas. Por ejemplo, 2x4 indica una matriz de 2 × 4 con 2 columnas y 4 filas (es decir, 8 valores). Si transpose es GL_FALSE, se asume que cada matriz se suministra en orden de columnas. Si transpose es GL_TRUE, se asume que cada matriz se suministra en orden de filas. El argumento count indica el número de matrices que se pasarán. Se debe usar un recuento de 1 si se modifica el valor de una sola matriz, y se puede usar un recuento mayor que 1 para modificar un array de matrices.

NOTAS

glUniform1i y glUniform1iv son las únicas dos funciones que pueden usarse para cargar variables uniformes definidas como tipos sampler. La carga de samplers con cualquier otra función resultará en un error GL_INVALID_OPERATION.

Si count es mayor que 1 y la variable uniforme indicada no es un array, se generará un error GL_INVALID_OPERATION y la variable uniforme especificada permanecerá sin cambios.

Aparte de las excepciones anteriores, si el tipo y tamaño de la variable uniforme tal como se definen en el shader no coinciden con el tipo y tamaño especificados en el nombre del comando utilizado para cargar su valor, se generará un error GL_INVALID_OPERATION y la variable uniforme especificada permanecerá sin cambios.

Si location es un valor distinto de -1 y no representa una ubicación uniforme válida en el objeto de programa actual, se generará un error y no se realizarán cambios en el almacenamiento de la variable uniforme del objeto de programa actual. Si location es igual a -1, los datos pasados serán ignorados silenciosamente y la variable uniforme especificada no se modificará.

ERRORES

Se genera GL_INVALID_OPERATION si no hay un objeto de programa actual.

Se genera GL_INVALID_OPERATION si el tamaño de la variable uniforme declarada en el shader no coincide con el tamaño indicado por el comando glUniform.

Se genera GL_INVALID_OPERATION si se utiliza una de las variantes de entero con signo o sin signo de esta función para cargar una variable uniforme de tipo float, vec2, vec3, vec4, o un array de estos, o si se utiliza una de las variantes de punto flotante de esta función para cargar una variable uniforme de tipo int, ivec2, ivec3, ivec4, unsigned int, uvec2, uvec3, uvec4, o un array de estos.

Se genera GL_INVALID_OPERATION si se utiliza una de las variantes de entero con signo de esta función para cargar una variable uniforme de tipo unsigned int, uvec2, uvec3, uvec4, o un array de estos.

Se genera GL_INVALID_OPERATION si se utiliza una de las variantes de entero sin signo de esta función para cargar una variable uniforme de tipo int, ivec2, ivec3, ivec4, o un array de estos.

Se genera GL_INVALID_OPERATION si location es una ubicación uniforme inválida para el objeto de programa actual y location no es igual a -1.

Se genera GL_INVALID_VALUE si count es menor que 0.

Se genera GL_INVALID_OPERATION si count es mayor que 1 y la variable uniforme indicada no es una variable de array.

Se genera GL_INVALID_OPERATION si se carga un sampler utilizando un comando que no sea glUniform1i y glUniform1iv.
