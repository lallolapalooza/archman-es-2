NOMBRE

glFlushMappedBufferRange, glFlushMappedNamedBufferRange - indicar modificaciones en un rango de un buffer mapeado

ESPECIFICACIÓN C

void glFlushMappedBufferRange(GLenumtarget, GLintptroffset, GLsizeiptrlength);

void glFlushMappedNamedBufferRange(GLuintbuffer, GLintptroffset, GLsizeiptrlength);

PARÁMETROS

target

Especifica el objetivo al que está vinculado el objeto buffer para glFlushMappedBufferRange, que debe ser uno de los objetivos de vinculación de buffer de la siguiente tabla:
Objetivo de Vinculación de Buffer Propósito
GL_ARRAY_BUFFER Atributos de vértice
GL_ATOMIC_COUNTER_BUFFER Almacenamiento de contadores atómicos
GL_COPY_READ_BUFFER Fuente de copia de buffer
GL_COPY_WRITE_BUFFER Destino de copia de buffer
GL_DISPATCH_INDIRECT_BUFFER Comandos de despacho de cómputo indirecto
GL_DRAW_INDIRECT_BUFFER Argumentos de comando indirecto
GL_ELEMENT_ARRAY_BUFFER Índices de matriz de vértices
GL_PIXEL_PACK_BUFFER Objetivo de lectura de píxeles
GL_PIXEL_UNPACK_BUFFER Fuente de datos de textura
GL_QUERY_BUFFER Buffer de resultados de consulta
GL_SHADER_STORAGE_BUFFER Almacenamiento de lectura-escritura para shaders
GL_TEXTURE_BUFFER Buffer de datos de textura
GL_TRANSFORM_FEEDBACK_BUFFER Buffer de transform feedback
GL_UNIFORM_BUFFER Almacenamiento de bloques uniformes

buffer

Especifica el nombre del objeto buffer para glFlushMappedNamedBufferRange.

offset

Especifica el inicio del subrango del buffer, en unidades básicas de máquina.

length

Especifica la longitud del subrango del buffer, en unidades básicas de máquina.

DESCRIPCIÓN

glFlushMappedBufferRange indica que se han realizado modificaciones en un rango de un objeto buffer mapeado. El objeto buffer debe haber sido mapeado previamente con el GL_MAP_FLUSH_EXPLICIT_BIT flag.

offset y length indican el subrango modificado del mapeo, en unidades básicas de máquina. El subrango especificado para vaciar es relativo al inicio del rango actualmente mapeado del buffer. Estos comandos pueden llamarse múltiples veces para indicar subrangos distintos del mapeo que requieren ser vaciados.

Si un rango de buffer está mapeado con GL_MAP_PERSISTENT_BIT y GL_MAP_FLUSH_EXPLICIT_BIT establecidos, entonces estos comandos pueden llamarse para asegurar que los datos escritos por el cliente en la región vaciada se hagan visibles para el servidor. Los datos escritos en un almacén coherente siempre se harán visibles para el servidor después de un período de tiempo indeterminado.

NOTAS

Los objetivos GL_DISPATCH_INDIRECT_BUFFER y GL_SHADER_STORAGE_BUFFER solo están disponibles si la versión de GL es 4.3 o superior.

El objetivo GL_QUERY_BUFFER solo está disponible si la versión de GL es 4.4 o superior.

ERRORES

GL_INVALID_ENUM es generado por glFlushMappedBufferRange si target no es uno de los objetivos de vinculación de buffer listados arriba.

GL_INVALID_OPERATION es generado por glFlushMappedBufferRange si cero está vinculado a target.

GL_INVALID_OPERATION es generado por glFlushMappedNamedBufferRange si buffer no es el nombre de un objeto buffer existente.

GL_INVALID_VALUE es generado si offset o length es negativo, o si offset + length excede el tamaño del mapeo.

GL_INVALID_OPERATION es generado si el objeto buffer no está mapeado, o está mapeado sin el GL_MAP_FLUSH_EXPLICIT_BIT flag.
