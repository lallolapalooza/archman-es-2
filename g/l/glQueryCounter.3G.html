NOMBRE

glQueryCounter - registra el tiempo de GL en un objeto de consulta después de que todos los comandos anteriores hayan llegado al servidor GL pero no necesariamente se hayan ejecutado.

ESPECIFICACIÓN C

void glQueryCounter(GLuint id, GLenum target);

PARÁMETROS

id

Especifica el nombre de un objeto de consulta en el que registrar el tiempo de GL.

target

Especifica el contador a consultar. target debe ser GL_TIMESTAMP.

DESCRIPCIÓN

glQueryCounter hace que el GL registre la hora actual en el objeto de consulta llamado id. target debe ser GL_TIMESTAMP. El tiempo se registra después de que todos los comandos anteriores en el cliente y servidor de GL, así como el framebuffer, se hayan realizado por completo. Cuando se registra el tiempo, el resultado de la consulta para ese objeto se marca como disponible. Las consultas de tiempo glQueryCounter se pueden usar dentro de un bloque glBeginQuery() /

glEndQuery() donde el objetivo es GL_TIME_ELAPSED y no afecta el resultado de ese objeto de consulta.

NOTAS

glQueryCounter solo está disponible si la versión de GL es 3.3 o superior.

ERRORES

Se genera GL_INVALID_OPERATION si id es el nombre de un objeto de consulta que ya está en uso dentro de un bloque glBeginQuery() /

glEndQuery().

Se genera GL_INVALID_VALUE si id no es el nombre de un objeto de consulta devuelto por una llamada anterior a glGenQueries().

Se genera GL_INVALID_ENUM si target no es GL_TIMESTAMP.
