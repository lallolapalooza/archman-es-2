DESCRIPCIÓ

N

glUniform modifica el valor de una variable uniforme o de un array de variables uniformes. La ubicación de la variable uniforme que se va a modificar se especifica mediante location, que debe ser un valor devuelto por glGetUniformLocation(). glUniform opera sobre el objeto de programa que se hizo parte del estado actual mediante la llamada a glUseProgr

am().

Los comandos glUniform{1|2|3|4}{f|i|ui} se utilizan para cambiar el valor de la variable uniforme especificada por location usando los valores pasados como argumentos. El número especificado en el comando debe coincidir con el número de componentes en el tipo de datos de la variable uniforme especificada (por ejemplo, 1 para float, int, unsigned int, bool; 2 para vec2, ivec2, uvec2, bvec2, etc.). El sufijo f indica que se están pasando valores de punto flotante; el sufijo i indica que se están pasando valores enteros; el sufijo ui indica que se están pasando valores enteros sin signo, y este tipo también debe coincidir con el tipo de datos de la variable uniforme especificada. Las variantes i de esta función deben usarse para proporcionar valores para variables uniformes definidas como int, ivec2, ivec3, ivec4, o matrices de estos. Las variantes ui de esta función deben usarse para proporcionar valores para variables uniformes definidas como unsigned int, uvec2, uvec3, uvec4, o matrices de estos. Las variantes f deben usarse para proporcionar valores para variables uniformes de tipo float, vec2, vec3, vec4, o matrices de estos. Cualquiera de las variantes i, ui o f puede usarse para proporcionar valores para variables uniformes de tipo bool, bvec2, bvec3, bvec4, o matrices de estos. La variable uniforme se establecerá en false si el valor de entrada es 0 o 0.0f, y se establecerá en true en caso

contrario.

Todas las variables uniformes activas definidas en un objeto de programa se inicializan a 0 cuando el objeto de programa se vincula correctamente. Conservan los valores asignados por una llamada a glUniform hasta que se produce la siguiente operación de vinculación correcta en el objeto de programa, cuando se inicializan de nuevo a

0.

Los comandos glUniform{1|2|3|4}{f|i|ui}v pueden usarse para modificar una única variable uniforme o una matriz de variables uniformes. Estos comandos pasan un recuento y un puntero a los valores que se cargarán en una variable uniforme o una matriz de variables uniformes. Debe usarse un recuento de 1 si se modifica el valor de una única variable uniforme, y puede usarse un recuento de 1 o mayor para modificar toda una matriz o parte de una matriz. Al cargar n elementos que comienzan en una posición arbitraria m en una matriz de variables uniformes, los elementos m + n - 1 en la matriz serán reemplazados con los nuevos valores. Si m + n - 1 es mayor que el tamaño de la matriz de variables uniformes, los valores de todos los elementos de la matriz más allá del final de la matriz serán ignorados. El número especificado en el nombre del comando indica el número de componentes de cada elemento en value, y debe coincidir con el número de componentes en el tipo de datos de la variable uniforme especificada (por ejemplo, 1 para float, int, bool; 2 para vec2, ivec2, bvec2, etc.). El tipo de datos especificado en el nombre del comando debe coincidir con el tipo de datos de la variable uniforme especificada como se describió anteriormente para glUniform{1|2|3|4}

{f|i|ui}.

Para matrices de variables uniformes, cada elemento de la matriz se considera que es del tipo indicado en el nombre del comando (por ejemplo, glUniform3f o glUniform3fv pueden usarse para cargar una matriz de variables uniformes de tipo vec3). El número de elementos de la matriz de variables uniformes que se modificará lo especifica coun

t

Los comandos glUniformMatrix{2|3|4|2x3|3x2|2x4|4x2|3x4|4x3}fv se usan para modificar una matriz o una matriz de matrices. Los números en el nombre del comando se interpretan como la dimensionalidad de la matriz. El número 2 indica una matriz de 2 × 2 (es decir, 4 valores), el número 3 indica una matriz de 3 × 3 (es decir, 9 valores), y el número 4 indica una matriz de 4 × 4 (es decir, 16 valores). La dimensionalidad de la matriz no cuadrada es explícita, con el primer número que representa el número de columnas y el segundo número que representa el número de filas. Por ejemplo, 2x4 indica una matriz de 2 × 4 con 2 columnas y 4 filas (es decir, 8 valores). Si transpose es GL_FALSE, se asume que cada matriz se proporciona en orden de columnas. Si transpose es GL_TRUE, se asume que cada matriz se proporciona en orden de filas. El argumento count indica el número de matrices que se pasarán. Debe usarse un recuento de 1 si se modifica

el valor de una única matriz, y puede usarse un recuent
o mayor que 1 para modificar una matriz de matrices.

NOTA

S

glUniform1i y glUniform1iv son las únicas dos funciones que pueden usarse para cargar variables uniformes definidas como tipos sampler. Cargar samplers con cualquier otra función resultará en un error GL_INVALID_OPERATION

.

Si count es mayor que 1 y la variable uniforme indicada no es una matriz, se genera un error GL_INVALID_OPERATION y la variable uniforme especificada permanecerá sin

cambios.

Aparte de las excepciones anteriores, si el tipo y el tamaño de la variable uniforme tal como se define en el shader no coinciden con el tipo y el tamaño especificados en el nombre del comando usado para cargar su valor, se generará un error GL_INVALID_OPERATION y la variable uniforme especificada permanecerá sin

cambios.

Si location es un valor distinto de -1 y no representa una ubicación de variable uniforme válida en el objeto de programa actual, se generará un error, y no se realizarán cambios en el almacenamiento de variables uniformes del objeto de programa actual. Si location es igual a -1, los datos pasados serán ignorados silenc

iosamente y la variable uniforme
especificada no será cambiada.

ERRORE

S

Se genera GL_INVALID_OPERATION si no hay objeto de programa

actual.

Se genera GL_INVALID_OPERATION si el tamaño de la variable uniforme declarada en el shader no coincide con el tamaño indicado por el comando glUn

iform.

Se genera GL_INVALID_OPERATION si se usa una de las variantes de entero con signo o sin signo de esta función para cargar una variable uniforme de tipo float, vec2, vec3, vec4, o una matriz de estos, o si se usa una de las variantes de punto flotante de esta función para cargar una variable uniforme de tipo int, ivec2, ivec3, ivec4, unsigned int, uvec2, uvec3, uvec4, o una matriz de

estos.

Se genera GL_INVALID_OPERATION si se usa una de las variantes de entero con signo de esta función para cargar una variable uniforme de tipo unsigned int, uvec2, uvec3, uvec4, o una matriz de

estos.

Se genera GL_INVALID_OPERATION si se usa una de las variantes de entero sin signo de esta función para cargar una variable uniforme de tipo int, ivec2, ivec3, ivec4, o una matriz de

estos.

Se genera GL_INVALID_OPERATION si location es una ubicación de uniforme no válida para el objeto de programa actual y location no es igual a

-1.

Se genera GL_INVALID_VALUE si count es menor que

0.

Se genera GL_INVALID_OPERATION si count es mayor que 1 y la variable uniforme indicada no es una variable de

matriz.

Se genera GL_INVALID_OPERATION si se carga un sampler usando un comando distinto de glUniform1i y glUniform1i

v
