NOMBRE

glab-repo-publish-catalog - [EXPERIMENTAL] Publica componentes CI/CD en el catálogo.

SINOPSIS

glab repo publish catalog [flags]

DESCRIPCIÓN

[EXPERIMENTAL] Publica componentes CI/CD en el proyecto en el catálogo CI/CD usando el nombre de etiqueta proporcionado.

Requiere que la bandera de funcionalidad ci_release_cli_catalog_publish_option esté habilitada para este proyecto en tu instancia de GitLab.

Requiere el mismo usuario que el autor de la versión.

  • Recupera componentes del repositorio actual buscando archivos yml dentro del directorio "templates" y sus subdirectorios.
  • Falla si la bandera de funcionalidad ci_release_cli_catalog_publish_option no está habilitada para este proyecto en tu instancia de GitLab.

Los componentes se pueden definir:

  • En archivos individuales que terminan en .yml para cada componente, como templates/secret-detection.yml.
  • En subdirectorios que contienen archivos template.yml como puntos de entrada, para componentes que agrupan varios archivos relacionados. Por ejemplo, templates/secret-detection/template.yml.

OPCIONES HEREDADAS DE COMANDOS PADRE

-h, --help[=false] Muestra la ayuda para este comando.

EJEMPLO

- glab repo publish catalog v1.2.3
