GLBINDVERTEXBUFFER(3G) [FIXME: manual] GLBINDVERTEXBUFFER(3G)

NOMBRE

glBindVertexBuffer, glVertexArrayVertexBuffer - vincula un búfer a un punto de enlace de búfer de vértices

ESPECIFICACIÓN EN C

void glBindVertexBuffer(GLuintbindingindex, GLuintbuffer, GLintptroffset, GLsizeistride);

void glVertexArrayVertexBuffer(GLuintvaobj, GLuintbindingindex, GLuintbuffer, GLintptroffset, GLsizeistride);

PARÁMETROS

vaobj

Especifica el nombre del objeto de arreglo de vértices que será utilizado por la función glVertexArrayVertexBuffer .

bindingindex

El índice del punto de enlace del búfer de vértices al que se debe vincular el búfer.

buffer

El nombre del búfer que se vinculará al punto de enlace del búfer de vértices.

offset

El desplazamiento del primer elemento del búfer.

stride

La distancia entre elementos dentro del búfer.

DESCRIPCIÓN

glBindVertexBuffer y glVertexArrayVertexBuffer vinculan el búfer llamado buffer al punto de enlace del búfer de vértices cuyo índice es dado por bindingindex. glBindVertexBuffer modifica el enlace del objeto de arreglo de vértices actualmente vinculado, mientras que glVertexArrayVertexBuffer permite al llamador especificar el ID del objeto de arreglo de vértices con un argumento llamado vaobj, para el cual se debe modificar el enlace. offset y stride especifican el desplazamiento del primer elemento dentro del búfer y la distancia entre elementos dentro del búfer, respectivamente, y ambos se miden en unidades básicas de máquina. bindingindex debe ser menor que el valor de GL_MAX_VERTEX_ATTRIB_BINDINGS. offset y stride deben ser mayores o iguales que cero. Si buffer es cero, entonces cualquier búfer actualmente vinculado al punto de enlace especificado se desvincula.

Si buffer no es el nombre de un objeto búfer existente, el GL primero crea un nuevo vector de estado, inicializado con un búfer de memoria de tamaño cero y que comprende todo el estado y con los mismos valores iniciales que en el caso de glBindBuffer. buffer se adjunta entonces al bindingindex especificado del objeto de arreglo de vértices.

ERRORES

GL_INVALID_OPERATION es generado por glBindVertexBuffer si no hay ningún objeto de arreglo de vértices vinculado.

GL_INVALID_OPERATION es generado por glVertexArrayVertexBuffer si vaobj no es el nombre de un objeto de arreglo de vértices existente.

GL_INVALID_VALUE es generado si bindingindex es mayor o igual que el valor de GL_MAX_VERTEX_ATTRIB_BINDINGS.

GL_INVALID_VALUE es generado si offset o stride es menor que cero, o si stride es mayor que el valor de GL_MAX_VERTEX_ATTRIB_STRIDE.

GL_INVALID_VALUE es generado si buffer no es cero o el nombre de un objeto búfer existente (como el devuelto por glGenBuffers o glCreateBuffers).

OBTENCIONES ASOCIADAS

glGet() con el argumento GL_MAX_VERTEX_ATTRIB_BINDINGS.
