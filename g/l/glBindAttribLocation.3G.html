GLBINDATTRIBLOCATION(3G) [FIXME: manual] GLBINDATTRIBLOCATION(3G)

NOMBRE

glBindAttribLocation - Asocia un índice de atributo de vértice genérico con una variable de atributo con nombre

ESPECIFICACIÓN EN C

void glBindAttribLocation(GLuintprogram, GLuintindex, const GLchar *name);

PARÁMETROS

program

Especifica el identificador del objeto de programa en el que se realizará la asociación.

index

Especifica el índice del atributo de vértice genérico que se va a enlazar.

name

Especifica una cadena terminada en nulo que contiene el nombre de la variable de atributo del shader de vértices a la que index se le va a enlazar.

DESCRIPCIÓN

glBindAttribLocation se utiliza para asociar una variable de atributo definida por el usuario en el objeto de programa especificado por program con un índice de atributo de vértice genérico. El nombre de la variable de atributo definida por el usuario se pasa como una cadena terminada en nulo en name. El índice de atributo de vértice genérico que se va a enlazar a esta variable se especifica mediante index. Cuando program se convierte en parte del estado actual, los valores proporcionados a través del atributo de vértice genérico index modificarán el valor de la variable de atributo definida por el usuario especificada por name.

Si name se refiere a una variable de atributo de matriz, index se refiere a la primera columna de la matriz. Las demás columnas de la matriz se enlazan automáticamente a las ubicaciones index+1 para una matriz de tipo mat2; index+1 y index+2 para una matriz de tipo mat3; y index+1, index+2y index+3 para una matriz de tipo mat4.

Este comando permite que los shaders de vértices utilicen nombres descriptivos para las variables de atributo en lugar de variables genéricas numeradas desde cero hasta el valor de GL_MAX_VERTEX_ATTRIBS menos uno. Los valores enviados a cada índice de atributo genérico forman parte del estado actual. Si se hace actual un objeto de programa diferente mediante la llamada glUseProgram(), los atributos de vértice genéricos se rastrean de tal manera que los mismos valores serán observados por los atributos en el nuevo objeto de programa que también estén enlazados a index.

Los enlaces de nombre de variable de atributo a índice de atributo genérico para un objeto de programa pueden asignarse explícitamente en cualquier momento mediante la llamada glBindAttribLocation. Los enlaces de atributos no surten efecto hasta que se llama a glLinkProgram(). Después de que un objeto de programa se haya enlazado correctamente, los valores de índice para los atributos genéricos permanecen fijos (y sus valores pueden consultarse) hasta que se produzca el siguiente comando de enlace.

Cualquier enlace de atributo que ocurra después de que el objeto de programa haya sido enlazado no surtirá efecto hasta la próxima vez que se enlace el objeto de programa.

NOTAS

glBindAttribLocation puede llamarse antes de que se enlacen objetos de shader de vértices al objeto de programa especificado. También está permitido enlazar un índice de atributo genérico a un nombre de variable de atributo que nunca se utilice en un shader de vértices.

Si name fue enlazado previamente, esa información se pierde. Por lo tanto, no se puede enlazar una variable de atributo definida por el usuario a múltiples índices, pero se pueden enlazar múltiples variables de atributo definidas por el usuario al mismo índice.

Se permite a las aplicaciones enlazar más de una variable de atributo definida por el usuario al mismo índice de atributo de vértice genérico. Esto se denomina aliasing, y solo se permite si solo uno de los atributos con alias está activo en el programa ejecutable, o si ningún camino a través del shader consume más de un atributo de un conjunto de atributos con alias en la misma ubicación. El compilador y el enlazador pueden asumir que no se realiza aliasing y tienen libertad para emplear optimizaciones que solo funcionan en la ausencia de aliasing. Las implementaciones de OpenGL no están obligadas a realizar comprobaciones de errores para detectar aliasing.

Los atributos activos que no estén enlazados explícitamente serán enlazados por el enlazador cuando se glLinkProgram() llame. Las ubicaciones asignadas pueden consultarse mediante la llamada a glGetAttribLocation().

OpenGL copia la name cadena cuando se glBindAttribLocation llama, por lo que una aplicación puede liberar su copia de la name cadena inmediatamente después de que la función retorne.

Las ubicaciones de atributos genéricas pueden especificarse en el texto fuente del shader mediante un calificador de diseño location . En este caso, la ubicación del atributo especificada en el código fuente del shader tiene prioridad y puede consultarse mediante la llamada a glGetAttribLocation().

ERRORES

GL_INVALID_VALUE se genera si index es mayor que o igual a GL_MAX_VERTEX_ATTRIBS.

GL_INVALID_OPERATION se genera si name comienza con el prefijo reservado "gl_".

GL_INVALID_VALUE se genera si program no es un valor generado por OpenGL.

GL_INVALID_OPERATION se genera si program no es un objeto de programa.

CONSULTAS ASOCIADAS

glGet() con el argumento GL_MAX_VERTEX_ATTRIBS

glGetActiveAttrib() con el argumento program

glGetAttribLocation() con los argumentos program y name

glIsProgram()
