glutSpecialFunc(3)

Paquete: freeglut

Licencias: X11

glutSpecialFunc(3) freeglut glutSpecialFunc(3)

NOMBRE

glutSpecialFunc - establece la función de devolución de llamada del teclado especial para la ventana actual.

SINTAXIS

void glutSpecialFunc(void (*func)(int key, int x, int y));

ARGUMENTOS

func
La nueva función de devolución de llamada especial.

DESCRIPCIÓN

glutSpecialFunc establece la función de devolución de llamada del teclado especial para la ventana actual. La función de devolución de llamada del teclado especial se activa cuando se presionan las teclas de función o las teclas direccionales del teclado. El parámetro de la tecla de la función de devolución de llamada es una constante GLUT_KEY_* para la tecla especial presionada. Los parámetros x e y de la función de devolución de llamada indican la posición del ratón en coordenadas relativas a la ventana cuando se presionó la tecla. Cuando se crea una nueva ventana, inicialmente no se registra ninguna función de devolución de llamada especial y las pulsaciones de teclas especiales en la ventana se ignoran. Pasar NULL a glutSpecialFunc deshabilita la generación de devoluciones de llamada especiales.

Durante una devolución de llamada especial, se puede llamar a glutGetModifiers para determinar el estado de las teclas modificadoras cuando ocurrió la pulsación de tecla que generó la devolución de llamada.

Una implementación debe hacer todo lo posible para proporcionar formas de generar todas las teclas especiales GLUT_KEY_*. Los valores disponibles de GLUT_KEY_* son:

GLUT_KEY_F1
Tecla de función F1.
GLUT_KEY_F2
Tecla de función F2.
GLUT_KEY_F3
Tecla de función F3.
GLUT_KEY_F4
Tecla de función F4.
GLUT_KEY_F5
Tecla de función F5.
GLUT_KEY_F6
Tecla de función F6.
GLUT_KEY_F7
Tecla de función F7.
GLUT_KEY_F8
Tecla de función F8.
GLUT_KEY_F9
Tecla de función F9.
GLUT_KEY_F10
Tecla de función F10.
GLUT_KEY_F11
Tecla de función F11.
GLUT_KEY_F12
Tecla de función F12.
GLUT_KEY_LEFT
Tecla direccional izquierda.
GLUT_KEY_UP
Tecla direccional arriba.
GLUT_KEY_RIGHT
Tecla direccional derecha.
GLUT_KEY_DOWN
Tecla direccional abajo.
GLUT_KEY_PAGE_UP
Tecla direccional Av Pág.
GLUT_KEY_PAGE_DOWN
Tecla direccional Re Pág.
GLUT_KEY_HOME
Tecla direccional Inicio.
GLUT_KEY_END
Tecla direccional Fin.
GLUT_KEY_INSERT
Tecla direccional Insertar.

Tenga en cuenta que las teclas escape, retroceso y suprimir se generan como un carácter ASCII.
