NOMBRE

glGetCompressedTexImage, glGetnCompressedTexImage, glGetCompressedTextureImage - devuelve una imagen de textura comprimida

ESPECIFICACIÓN EN C

void glGetCompressedTexImage(GLenum target, GLint level, void * pixels);

void glGetnCompressedTexImage(GLenum target, GLint level, GLsizei bufSize, void *pixels);

void glGetCompressedTextureImage(GLuint texture, GLint level, GLsizei bufSize, void *pixels);

PARÁMETROS

target

Especifica el destino al que está enlazada la textura para las funciones glGetCompressedTexImage y glGetnCompressedTexImage. Se aceptan GL_TEXTURE_1D, GL_TEXTURE_1D_ARRAY, GL_TEXTURE_2D, GL_TEXTURE_2D_ARRAY, GL_TEXTURE_3D, GL_TEXTURE_CUBE_MAP_ARRAY, GL_TEXTURE_CUBE_MAP_POSITIVE_X, GL_TEXTURE_CUBE_MAP_NEGATIVE_X, GL_TEXTURE_CUBE_MAP_POSITIVE_Y, GL_TEXTURE_CUBE_MAP_NEGATIVE_Y, GL_TEXTURE_CUBE_MAP_POSITIVE_Z, y GL_TEXTURE_CUBE_MAP_NEGATIVE_Z, GL_TEXTURE_RECTANGLE.

texture

Especifica el nombre del objeto de textura para la función glGetCompressedTextureImage.

level

Especifica el número de nivel de detalle de la imagen deseada. El nivel 0 es el nivel de imagen base. El nivel $n$ es la $n$-ésima imagen de reducción mipmap.

bufSize

Especifica el tamaño del búfer pixels para las funciones glGetCompressedTextureImage y glGetnCompressedTexImage.

pixels

Devuelve la imagen de textura comprimida.

DESCRIPCIÓN

glGetCompressedTexImage y glGetnCompressedTexImage devuelven la imagen de textura comprimida asociada con target y lod en pixels. glGetCompressedTextureImage cumple el mismo propósito, pero en lugar de tomar un destino de textura, toma el ID del objeto de textura. pixels debe ser un array de bufSize bytes para las funciones glGetnCompresedTexImage y glGetCompressedTextureImage, y de bytes GL_TEXTURE_COMPRESSED_IMAGE_SIZE en el caso de glGetCompressedTexImage. Si los datos reales ocupan menos espacio que bufSize, los bytes restantes no se modificarán. target especifica el destino de la textura, al que está enlazada la textura de la que la función debe extraer los datos. lod especifica el número de nivel de detalle de la imagen deseada.

Si un objeto de búfer con nombre y distinto de cero está enlazado al destino GL_PIXEL_PACK_BUFFER (ver glBindBuffer()) mientras se solicita una imagen de textura, pixels se trata como un desplazamiento de bytes en el almacén de datos del objeto de búfer.

Para minimizar errores, primero verifica que la textura esté comprimida llamando a glGetTexLevelParameter() con el argumento GL_TEXTURE_COMPRESSED. Si la textura está comprimida, puedes determinar la cantidad de memoria requerida para almacenar la textura comprimida llamando a glGetTexLevelParameter() con el argumento GL_TEXTURE_COMPRESSED_IMAGE_SIZE. Finalmente, recupera el formato interno de la textura llamando a glGetTexLevelParameter() con el argumento GL_TEXTURE_INTERNAL_FORMAT. Para almacenar la textura para su uso posterior, asocia el formato interno y el tamaño con la imagen de textura recuperada. Estos datos se pueden usar en la rutina de carga de texturas o subtexturas correspondiente utilizada para cargar texturas de tipo target.

ERRORES

GL_INVALID_OPERATION es generado por glGetCompressedTextureImage si texture no es el nombre de un objeto de textura existente.

GL_INVALID_VALUE se genera si level es menor que cero o mayor que el número máximo de LODs permitido por la implementación.

GL_INVALID_OPERATION se genera si glGetCompressedTexImage, glGetnCompressedTexImage, y glGetCompressedTextureImage se utilizan para recuperar una textura que está en un formato interno no comprimido.

GL_INVALID_OPERATION se genera si un objeto de búfer con nombre y distinto de cero está enlazado al destino GL_PIXEL_PACK_BUFFER, el almacenamiento del búfer no se inicializó con glBufferStorage utilizando el flag GL_MAP_PERSISTENT_BIT y el almacén de datos del objeto de búfer está actualmente mapeado.

GL_INVALID_OPERATION se genera si un objeto de búfer con nombre y distinto de cero está enlazado al destino GL_PIXEL_PACK_BUFFER y los datos se empaquetarían al objeto de búfer de tal manera que las escrituras de memoria requeridas excederían el tamaño del almacén de datos.
