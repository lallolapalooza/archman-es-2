GLBINDVERTEXBUFFERS(3G) [FIXME: manual] GLBINDVERTEXBUFFERS(3G)

NOMBRE

glBindVertexBuffers, glVertexArrayVertexBuffers - adjunta múltiples objetos de búfer a un objeto de arreglo de vértices

ESPECIFICACIÓN EN C

void glBindVertexBuffers(GLuintfirst, GLsizeicount, const GLuint *buffers, const GLintptr *offsets, const GLsizei *strides);

void glVertexArrayVertexBuffers(GLuintvaobj, GLuintfirst, GLsizeicount, const GLuint *buffers, const GLintptr *offsets, const GLsizei *strides);

PARÁMETROS

vaobj

Especifica el nombre del objeto de arreglo de vértices para glVertexArrayVertexBuffers.

first

Especifica el primer punto de enlace de búfer de vértices al que se debe enlazar un objeto de búfer.

count

Especifica el número de búferes a enlazar.

buffers

Especifica la dirección de un arreglo de nombres de objetos de búfer existentes.

offsets

Especifica la dirección de un arreglo de desplazamientos a asociar con los puntos de enlace.

strides

Especifica la dirección de un arreglo de incrementos (strides) a asociar con los puntos de enlace.

DESCRIPCIÓN

glBindVertexBuffers y glVertexArrayVertexBuffers enlazan almacenamiento de un arreglo de objetos de búfer existentes a un número especificado de puntos de enlace consecutivos de búfer de vértices en un objeto de arreglo de vértices. Para glBindVertexBuffers, el objeto de arreglo de vértices es el objeto de arreglo de vértices actualmente enlazado. Para glVertexArrayVertexBuffers, vaobj es el nombre del objeto de arreglo de vértices.

count objetos de búfer existentes se enlazan a puntos de enlace de búfer de vértices numerados $first$ a $first + count - 1$. Si buffers no es NULL, especifica un arreglo de count valores, cada uno de los cuales debe ser cero o el nombre de un objeto de búfer existente. offsets y strides especifican arreglos de count valores que indican el desplazamiento del primer elemento y el incremento entre elementos en cada búfer, respectivamente. Si buffers es NULL, cada punto de enlace de búfer de vértices afectado desde $first$ hasta $first + count - 1$ se restablecerá para no tener ningún objeto de búfer enlazado. En este caso, los desplazamientos e incrementos asociados con los puntos de enlace se establecen a valores predeterminados, ignorando offsets y strides.

glBindVertexBuffers es equivalente (suponiendo que no se generan errores) a:

    for (i = 0; i < count; i++) {
        if (buffers == NULL) {
            glBindVertexBuffer(first + i, 0, 0, 16);
        } else {
            glBindVertexBuffer(first + i, buffers[i], offsets[i], strides[i]);
        }
    }

excepto que los búferes no se crearán si no existen.

glVertexArrayVertexBuffers es equivalente al pseudocódigo anterior, pero reemplazando glBindVertexBuffers(args) con glVertexArrayVertexBuffers(vaobj, args).

Los valores especificados en buffers, offsetsy strides se verificarán por separado para cada punto de enlace de búfer de vértices. Cuando un valor para un punto de enlace de búfer de vértices específico es inválido, el estado para ese punto de enlace permanecerá sin cambios y se generará un error. Sin embargo, el estado para otros puntos de enlace de búfer de vértices seguirá cambiando si sus valores correspondientes son válidos.

ERRORES

GL_INVALID_OPERATION es generado por glBindVertexBuffers si no hay ningún objeto de arreglo de vértices enlazado.

GL_INVALID_OPERATION es generado por glVertexArrayVertexBuffers si vaobj no es el nombre del objeto de arreglo de vértices.

GL_INVALID_OPERATION es generado si $first + count$ es mayor que el valor de GL_MAX_VERTEX_ATTRIB_BINDINGS.

GL_INVALID_OPERATION es generado si algún valor en buffers no es cero o el nombre de un objeto de búfer existente.

GL_INVALID_VALUE es generado si algún valor en offsets o strides es negativo, o si un valor de stride es mayor que el valor de GL_MAX_VERTEX_ATTRIB_STRIDE.
