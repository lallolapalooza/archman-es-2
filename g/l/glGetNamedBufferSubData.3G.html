NOMBRE

glGetBufferSubData, glGetNamedBufferSubData - devuelve un subconjunto de los datos del almacén de un objeto de búfer

ESPECIFICACIÓN EN C

void glGetBufferSubData(GLenumtarget, GLintptroffset, GLsizeiptrsize, void *data);

void glGetNamedBufferSubData(GLuintbuffer, GLintptroffset, GLsizeiptrsize, void *data);

PARÁMETROS

target

Especifica el destino al que está vinculado el objeto de búfer para glGetBufferSubData, que debe ser uno de los destinos de enlace de búfer de la siguiente tabla:
Destino de enlace de búfer Propósito
GL_ARRAY_BUFFER Atributos de vértices
GL_ATOMIC_COUNTER_BUFFER Almacenamiento de contadores atómicos
GL_COPY_READ_BUFFER Origen de copia de búfer
GL_COPY_WRITE_BUFFER Destino de copia de búfer
GL_DISPATCH_INDIRECT_BUFFER Comandos de despacho de cómputo indirecto
GL_DRAW_INDIRECT_BUFFER Argumentos de comandos indirectos
GL_ELEMENT_ARRAY_BUFFER Índices de matrices de vértices
GL_PIXEL_PACK_BUFFER Destino de lectura de píxeles
GL_PIXEL_UNPACK_BUFFER Fuente de datos de textura
GL_QUERY_BUFFER Búfer de resultados de consultas
GL_SHADER_STORAGE_BUFFER Almacenamiento de lectura y escritura para shaders
GL_TEXTURE_BUFFER Búfer de datos de textura
GL_TRANSFORM_FEEDBACK_BUFFER Búfer de transform feedback
GL_UNIFORM_BUFFER Almacenamiento de bloques uniformes

buffer

Especifica el nombre del objeto de búfer para glGetNamedBufferSubData.

offset

Especifica el desplazamiento dentro del almacén de datos del objeto de búfer desde el que se devolverán los datos, medido en bytes.

size

Especifica el tamaño en bytes de la región del almacén de datos que se está devolviendo.

data

Especifica un puntero a la ubicación donde se devuelven los datos del objeto de búfer.

DESCRIPCIÓN

glGetBufferSubData y glGetNamedBufferSubData devuelven parte o todo el contenido de datos del almacén de datos del objeto de búfer especificado. Los datos que comienzan en el desplazamiento de byte offset y se extienden durante size bytes se copian del almacén de datos del objeto de búfer a la memoria apuntada por data. Se lanza un error si el objeto de búfer está actualmente mapeado, o si offset y size definen juntos un rango que excede los límites del almacén de datos del objeto de búfer.

NOTAS

Si se genera un error, no se realiza ningún cambio en el contenido de data.

El destino GL_ATOMIC_COUNTER_BUFFER solo está disponible si la versión de GL es 4.2 o superior.

Los destinos GL_DISPATCH_INDIRECT_BUFFER y GL_SHADER_STORAGE_BUFFER solo están disponibles si la versión de GL es 4.3 o superior.

El destino GL_QUERY_BUFFER solo está disponible si la versión de GL es 4.4 o superior.

ERRORES

GL_INVALID_ENUM es generado por glGetBufferSubData si target no es uno de los destinos genéricos de enlace de búfer.

GL_INVALID_OPERATION es generado por glGetBufferSubData si está vinculado cero a target.

GL_INVALID_OPERATION es generado por glGetNamedBufferSubData si buffer no es el nombre de un objeto de búfer existente.

GL_INVALID_VALUE es generado si offset o size es negativo, o si $offset + size$ es mayor que el valor de GL_BUFFER_SIZE para el objeto de búfer.

GL_INVALID_OPERATION es generado si el objeto de búfer está mapeado con glMapBufferRange() o glMapBuffer(), a menos que haya sido mapeado con el bit GL_MAP_PERSISTENT_BIT establecido en los indicadores de glMapBufferRange de acceso .

GLAPI(3G) OpenGL Manual glGetNamedBufferSubData(3G)

NAME

glGetNamedBufferSubData - return a subset of the data from a buffer object

C SPECIFICATION

void glGetNamedBufferSubData( GLenum target, GLintptr offset, GLsizeiptr size, void *data );

PARAMETERS

target Specifies the buffer object target.

offset Specifies the offset into the buffer object of the first value to be returned.

size Specifies the length of the buffer data to be returned.

data Specifies the address of the buffer into which the specified parameters are returned.

DESCRIPTION

glGetNamedBufferSubData retrieves all or a portion of the data contained in a buffer object. The data is copied from the buffer object into the memory addressed by data.

The buffer object must be bound to the specified target. If the buffer object is not currently bound to the specified target, GL_INVALID_OPERATION is generated.

The offset and size parameters specify the range of the buffer object to be returned. The range must be within the buffer object's allocated size. If the range is not within the buffer object's allocated size, GL_OUT_OF_RANGE is generated.

The data is returned in the format specified by the buffer object's current binding.

glGetNamedBufferSubData is equivalent to calling glGetBufferSubData with the buffer object bound to the specified target.

NOTES

glGetNamedBufferSubData is available only if the GL version is 4.5 or higher.

Buffer objects are objects that store an array of generic data that can be accessed by the vertex, tessellation, geometry, and fragment shaders.

The GL_COPY_READ_BUFFER and GL_COPY_WRITE_BUFFER targets are available only if the GL version is 3.1 or higher.

ERRORS

GL_INVALID_ENUM is generated if target is not one of the valid buffer object targets.

GL_INVALID_OPERATION is generated if the buffer object is not bound to target.

GL_INVALID_VALUE is generated if offset or size are negative.

GL_OUT_OF_RANGE is generated if the specified range is outside the bounds of the buffer object.

VERSION_SUPPORT

Function Version Compatibility
glGetNamedBufferSubData 4.5 N/A
