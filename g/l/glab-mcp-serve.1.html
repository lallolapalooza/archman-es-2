NOMBRE

glab-mcp-serve - Inicia un servidor MCP con transporte stdio. (EXPERIMENTAL)

SINOPSIS

glab mcp serve [flags]

DESCRIPCIÓN

Inicia un servidor del Protocolo de Contexto de Modelo (MCP) para exponer las características de GitLab como herramientas para asistentes de IA como Claude Code.

El servidor utiliza el transporte stdio (entrada y salida estándar) para la comunicación y proporciona herramientas para:

  • Gestionar issues (listar, crear, actualizar, cerrar, añadir notas)
  • Gestionar peticiones de fusión (listar, crear, actualizar, fusionar, añadir notas)
  • Gestionar proyectos (listar, obtener detalles)
  • Gestionar pipelines y trabajos de CI/CD

Para configurar este servidor en Claude Code, añade este código a tu configuración de MCP:

{
  "mcpServers": {
    "glab": {
      "type": "stdio",
      "command": "glab",
      "args": ["mcp", "serve"]
    }
  }
}

Esta característica es experimental. Podría estar rota o eliminada sin previo aviso. Lee más sobre lo que significan las características experimentales en https://docs.gitlab.com/policy/development_stages_support/

Utiliza las características experimentales bajo tu propio riesgo.
