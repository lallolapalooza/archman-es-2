NOMBRE

glBindFramebuffer - enlaza un framebuffer a un objetivo de framebuffer

ESPECIFICACIÓN C

void glBindFramebuffer(GLenum target, GLuint framebuffer);

PARÁMETROS

target

Especifica el objetivo de framebuffer de la operación de enlace.

framebuffer

Especifica el nombre del objeto framebuffer a enlazar.

DESCRIPCIÓN

glBindFramebuffer enlaza el objeto framebuffer con el nombre framebuffer al objetivo de framebuffer especificado por target. target debe ser GL_DRAW_FRAMEBUFFER, GL_READ_FRAMEBUFFER o GL_FRAMEBUFFER. Si un objeto framebuffer se enlaza a GL_DRAW_FRAMEBUFFER o GL_READ_FRAMEBUFFER, se convierte en el objetivo para las operaciones de renderizado o lectura, respectivamente, hasta que se elimine o se enlace otro framebuffer al punto de enlace correspondiente. Llamar a glBindFramebuffer con target establecido en GL_FRAMEBUFFER enlaza framebuffer tanto al objetivo de framebuffer de lectura como al de escritura. framebuffer es el nombre de un objeto framebuffer devuelto previamente por una llamada a glGenFramebuffers(), o cero para romper el enlace existente de un objeto framebuffer a target.

ERRORES

Se genera GL_INVALID_ENUM si target no es GL_DRAW_FRAMEBUFFER, GL_READ_FRAMEBUFFER o GL_FRAMEBUFFER.

Se genera GL_INVALID_OPERATION si framebuffer no es cero o el nombre de un framebuffer devuelto previamente por una llamada a glGenFramebuffers().
