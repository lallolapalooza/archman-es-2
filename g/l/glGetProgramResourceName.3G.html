NOMBRE

glGetProgramResourceName - consulta el nombre de un recurso indexado dentro de un programa

ESPECIFICACIÓN C

void glGetProgramResourceName(GLuint program, GLenum programInterface, GLuint index, GLsizei bufSize, GLsizei * length, char * name);

PARÁMETROS

program

El nombre de un objeto de programa cuyos recursos se consultarán.

programInterface

Un token que identifica la interfaz dentro de program que contiene el recurso indexado.

index

El índice del recurso dentro de programInterface de program.

bufSize

El tamaño del array de caracteres cuya dirección se proporciona en name.

length

La dirección de una variable que recibirá la longitud del nombre del recurso.

name

La dirección de un array de caracteres en el que se escribirá el nombre del recurso.

DESCRIPCIÓN

glGetProgramResourceName recupera la cadena de nombre asignada al único recurso activo con un índice de index en la interfaz programInterface del objeto de programa program. index debe ser menor que el número de entradas en la lista de recursos activos para programInterface.

program debe ser el nombre de un objeto de programa existente. programInterface es el nombre de la interfaz dentro de program que contiene el recurso y debe ser uno de los siguientes valores:

GL_UNIFORM

La consulta está dirigida al conjunto de uniformes activos dentro de program.

GL_UNIFORM_BLOCK

La consulta está dirigida al conjunto de bloques uniformes activos dentro de program.

GL_PROGRAM_INPUT

La consulta está dirigida al conjunto de variables de entrada activas utilizadas por la primera etapa del shader de program. Si program contiene múltiples etapas de shader, las variables de entrada de cualquier etapa que no sea la primera no se enumerarán.

GL_PROGRAM_OUTPUT

La consulta está dirigida al conjunto de variables de salida activas producidas por la última etapa del shader de program. Si program contiene múltiples etapas de shader, las variables de salida de cualquier etapa que no sea la última no se enumerarán.

GL_VERTEX_SUBROUTINE, GL_TESS_CONTROL_SUBROUTINE, GL_TESS_EVALUATION_SUBROUTINE, GL_GEOMETRY_SUBROUTINE, GL_FRAGMENT_SUBROUTINE, GL_COMPUTE_SUBROUTINE

La consulta está dirigida al conjunto de subrutinas activas para las etapas de shader de vértices, control de teselación, evaluación de teselación, geometría, fragmentos y cómputo de program, respectivamente.

GL_VERTEX_SUBROUTINE_UNIFORM, GL_TESS_CONTROL_SUBROUTINE_UNIFORM, GL_TESS_EVALUATION_SUBROUTINE_UNIFORM, GL_GEOMETRY_SUBROUTINE_UNIFORM, GL_FRAGMENT_SUBROUTINE_UNIFORM, GL_COMPUTE_SUBROUTINE_UNIFORM

La consulta está dirigida al conjunto de variables uniformes de subrutina activas utilizadas por las etapas de shader de vértices, control de teselación, evaluación de teselación, geometría, fragmentos y cómputo de program, respectivamente.

GL_TRANSFORM_FEEDBACK_VARYING

La consulta está dirigida al conjunto de variables de salida de la última etapa no de fragmentos de program que se capturarían si la retroalimentación de transformación estuviera activa.

GL_BUFFER_VARIABLE

La consulta está dirigida al conjunto de variables de búfer activas utilizadas por program.

GL_SHADER_STORAGE_BLOCK

La consulta está dirigida al conjunto de bloques de almacenamiento de shader activos utilizados por program.

La cadena de nombre asignada al recurso activo identificado por index se devuelve como una cadena terminada en nulo en el array de caracteres cuya dirección se proporciona en name. El número real de caracteres escritos en name, excluyendo el terminador nulo, se devuelve en length. Si length es NULL, no se devuelve ninguna longitud. El número máximo de caracteres que se pueden escribir en name, incluyendo el terminador nulo, se especifica por bufSize. Si la longitud de la cadena de nombre *incluyendo el terminador nulo* es mayor que bufSize, los primeros bufSize-1 caracteres de la cadena de nombre se escribirán en name, seguidos de un terminador nulo. Si bufSize es cero, no se generará ningún error pero no se escribirán caracteres en name. La longitud de la cadena de nombre más larga para programInterface, incluyendo un terminador nulo, se puede consultar llamando a glGetProgramInterface() con un pname de GL_MAX_NAME_LENGTH.

ERRORES

GL_INVALID_ENUM se genera si programInterface no es uno de los tipos de interfaz aceptados.

GL_INVALID_VALUE se genera si progam no es el nombre de un programa existente.

GL_INVALID_VALUE se genera si index es mayor o igual que el número de entradas en la lista de recursos activos para programInterface.

GL_INVALID_ENUM se genera si programInterface es GL_ATOMIC_COUNTER_BUFFER o GL_TRANSFORM_FEEDBACK_BUFFER, ya que los recursos activos de búfer de contador atómico y de retroalimentación de transformación no tienen nombres asignados.
