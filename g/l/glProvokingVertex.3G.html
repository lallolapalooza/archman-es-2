GLPROVOKINGVERTEX(3G) [FIXME: manual] GLPROVOKINGVERTEX(3G)

NOMBRE

glProvokingVertex - especifica el vértice a ser usado como fuente de datos para variables planas sombreadas (flat shaded)

ESPECIFICACIÓN C

void glProvokingVertex(GLenum provokeMode);

PARÁMETROS

provokeMode

Especifica el vértice a ser usado como fuente de datos para variables planas sombreadas.

DESCRIPCIÓN

El sombreado plano (flatshading) de una variable de salida de un shader de vértices significa asignar a todos los vértices de la primitiva el mismo valor para esa salida. El vértice del cual se derivan estos valores se conoce como el vértice provocador y glProvokingVertex especifica qué vértice se usará como fuente de datos para las variables planas sombreadas.

provokeMode debe ser GL_FIRST_VERTEX_CONVENTION o GL_LAST_VERTEX_CONVENTION, y controla la selección del vértice cuyos valores se asignan a las salidas de variables planas sombreadas. La interpretación de estos valores para los tipos de primitivas soportados es:

Tipo de Primitiva de Polígono i Convención del Primer Vértice Convención del Último Vértice
point i i
línea independiente 2i - 1 2i
bucle de línea i i + 1, si i < n .PP 1, si i = n
tira de línea i i + 1
triángulo independiente 3i - 2 3i
tira de triángulo i i + 2
abanico de triángulo i + 1 i + 2
adyacencia de línea 4i - 2 4i - 1
tira de adyacencia de línea i + 1 i + 2
adyacencia de triángulo 6i - 5 6i - 1
tira de adyacencia de triángulo 2i - 1 2i + 3

Si un shader de vértices o geometría está activo, las salidas de variables definidas por el usuario pueden ser planas sombreadas usando el calificador flat al declarar la salida.

NOTAS

glProvokingVertex solo está disponible si la versión de GL es 3.2 o superior.

ERRORES

GL_INVALID_ENUM se genera si provokeMode no es un valor aceptado.
