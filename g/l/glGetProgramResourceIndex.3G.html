DESCRIPCIÓ

N

glGetProgramResourceIndex devuelve el índice entero sin signo asignado a un recurso con nombre name en el tipo de interfaz programInterface del objeto programa program

.

program debe ser el nombre de un objeto programa existente. programInterface es el nombre de la interfaz dentro de program que contiene el recurso con nombre name y debe ser uno de los siguientes

valores:

GL_UNIFOR

M
La consulta se dirige al conjunto de uniforms activos dentro de program
.

GL_UNIFORM_BLOC

K
La consulta se dirige al conjunto de bloques de uniforms activos dentro de program
.

GL_PROGRAM_INPU

T
La consulta se dirige al conjunto de variables de entrada activas utilizadas por la primera etapa del shader de program. Si program contiene múltiples etapas de shader, las variables de entrada de cualquier etapa que no sea la primera no serán
enumeradas.

GL_PROGRAM_OUTPU

T
La consulta se dirige al conjunto de variables de salida activas producidas por la última etapa del shader de program. Si program contiene múltiples etapas de shader, las variables de salida de cualquier etapa que no sea la última no serán
enumeradas.

GL_VERTEX_SUBROUTINE, GL_TESS_CONTROL_SUBROUTINE, GL_TESS_EVALUATION_SUBROUTINE, GL_GEOMETRY_SUBROUTINE, GL_FRAGMENT_SUBROUTINE, GL_COMPUTE_SUBROUTIN

E
La consulta se dirige al conjunto de subrutinas activas para las etapas de shader de vértice, control de teselado, evaluación de teselado, geometría, fragmento y cómputo de program, respectivamente
.

GL_VERTEX_SUBROUTINE_UNIFORM, GL_TESS_CONTROL_SUBROUTINE_UNIFORM, GL_TESS_EVALUATION_SUBROUTINE_UNIFORM, GL_GEOMETRY_SUBROUTINE_UNIFORM, GL_FRAGMENT_SUBROUTINE_UNIFORM, GL_COMPUTE_SUBROUTINE_UNIFOR

M
La consulta se dirige al conjunto de variables uniformes de subrutina activas utilizadas por las etapas de shader de vértice, control de teselado, evaluación de teselado, geometría, fragmento y cómputo de program, respectivamente
.

GL_TRANSFORM_FEEDBACK_VARYIN

G
La consulta se dirige al conjunto de variables de salida de la última etapa que no sea de fragmento de program que serían capturadas si transform feedback estuviera
activo.

GL_TRANSFORM_FEEDBACK_BUFFE

R
La consulta se dirige al conjunto de puntos de enlace de búfer activos a los que se escriben las variables de salida en la GL_TRANSFORM_FEEDBACK_VARYING
interfaz.

GL_BUFFER_VARIABL

E
La consulta se dirige al conjunto de variables de búfer activas utilizadas por program
.

GL_SHADER_STORAGE_BLOC

K
La consulta se dirige al conjunto de bloques de almacenamiento de shader activos utilizados por program
.

Si name coincide exactamente con la cadena de nombre de uno de los recursos activos para programInterface, se devuelve el índice del recurso coincidente. Además, si name coincidiría exactamente con la cadena de nombre de un recurso activo si se añadiera "[0]" a name, se devuelve el índice del recurso coincidente. De lo contrario, name se considera que no es el nombre de un recurso activo, y se devuelve GL_INVALID_INDEX

.

Para la interfaz GL_TRANSFORM_FEEDBACK_VARYING, se debe devolver el valor GL_INVALID_INDEX al consultar el índice asignado a los nombres especiales gl_NextBuffer, gl_SkipComponents1, gl_SkipComponents2, gl_SkipComponents3 o gl_SkipComponents

4
.

ERRORE

S

Se genera GL_INVALID_ENUM si programInterface no es uno de los tipos de interfaz

aceptados.

Se genera GL_INVALID_ENUM si programInterface es GL_ATOMIC_COUNTER_BUFFER o GL_TRANSFORM_FEEDBACK_BUFFER, ya que a los recursos activos de contadores atómicos y búferes de transform feedback no se les asignan cadenas de

nombre.

Aunque no es un error, se devuelve GL_INVALID_INDEX si name no es el nombre de un recurso dentro de la interfaz identificada por programInterfac

e
.
