DESCRIPCIÓ

N

glGetCompressedTexImage y glGetnCompressedTexImage devuelven la imagen de textura comprimida asociada con target y lod en pixels. glGetCompressedTextureImage sirve para el mismo propósito, pero en lugar de tomar un objetivo de textura, toma el ID del objeto de textura. pixels debe ser un arreglo de bufSize bytes para las funciones glGetnCompresedTexImage y glGetCompressedTextureImage, y de GL_TEXTURE_COMPRESSED_IMAGE_SIZE bytes en el caso de glGetCompressedTexImage. Si los datos reales ocupan menos espacio que bufSize, los bytes restantes no serán tocados. target especifica el objetivo de textura, al que está vinculada la textura de la que la función debe extraer los datos. lod especifica el número de nivel de detalle de la imagen

deseada.

Si un objeto de búfer con nombre distinto de cero está vinculado al objetivo GL_PIXEL_PACK_BUFFER (ver glBindBuffer()) mientras se solicita una imagen de textura, pixels se trata como un desplazamiento de bytes en el almacén de datos del objeto de

búfer.

Para minimizar errores, primero verifique que la textura está comprimida llamando a glGetTexLevelParameter() con el argumento GL_TEXTURE_COMPRESSED. Si la textura está comprimida, puede determinar la cantidad de memoria necesaria para almacenar la textura comprimida llamando a glGetTexLevelParameter() con el argumento GL_TEXTURE_COMPRESSED_IMAGE_SIZE. Finalmente, obtenga el formato interno de la textura llamando a glGetTexLevelParameter() con el argumento GL_TEXTURE_INTERNAL_FORMAT. Para almacenar la textura para un uso posterior, asocie el formato interno y el tamaño con la imagen de textura obtenida. Estos datos pueden ser usados por la respectiva rutina de carga de textura o subtextura usada para cargar texturas

tar
get.

ERRORE

S

GL_INVALID_OPERATION es generado por glGetCompressedTextureImage si texture no es el nombre de un objeto de textura

existente.

GL_INVALID_VALUE es generado si level es menor que cero o mayor que el número máximo de LODs permitidos por la

implementación.

GL_INVALID_OPERATION es generado si glGetCompressedTexImage, glGetnCompressedTexImage y glGetCompressedTextureImage se usan para recuperar una textura que está en un formato interno sin

comprimir.

GL_INVALID_OPERATION es generado si un nombre de objeto de búfer distinto de cero está vinculado al objetivo GL_PIXEL_PACK_BUFFER, el almacenamiento del búfer no fue inicializado con glBufferStorage usando el indicador GL_MAP_PERSISTENT_BIT, y el almacén de datos del objeto de búfer está actualmente

mapeado.

GL_INVALID_OPERATION es generado si un nombre de objeto de búfer distinto de cero está vinculado al objetivo GL_PIXEL_PACK_BUFFER y los datos se empaquetarían en el objeto de búfer de tal m

anera que las escrituras de memoria requeridas
excederían el tamaño del almacén de datos.
