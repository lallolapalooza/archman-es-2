NOMBRE

glab-mr-update - Actualizar una solicitud de fusión.

SINOPSIS

glab mr update [ | ] [flags]

DESCRIPCIÓN

Actualiza una solicitud de fusión.

OPCIONES

-a, --assignee=[] Asigna usuarios por nombre de usuario. Prefija con '!' o '-' para eliminar de los asignados existentes, '+' para añadir. De lo contrario, reemplaza a los asignados existentes con los usuarios dados. Se pueden especificar varios nombres de usuario separados por comas o repitiendo la opción.

-d, --description="" Descripción de la solicitud de fusión. Establecer a "-" para abrir un editor.

--draft[=false] Marca la solicitud de fusión como un borrador.

-f, --fill[=false] No solicitar título ni cuerpo, y simplemente usar la información del commit.

--fill-commit-body[=false] Rellena el cuerpo con el cuerpo de cada commit cuando hay varios commits. Solo se puede usar con --fill.

-l, --label=[] Añadir etiquetas.

--lock-discussion[=false] Bloquea la discusión en la solicitud de fusión.

-m, --milestone="" Título del hito al que asignar. Establecer a "" o 0 para desasignar.

-r, --ready[=false] Marca la solicitud de fusión como lista para ser revisada y fusionada.

--remove-source-branch[=false] Activa/desactiva la eliminación de la rama de origen al fusionar.

--reviewer=[] Solicita la revisión de usuarios por sus nombres de usuario. Prefija con '!' o '-' para eliminar de los revisores existentes, '+' para añadir. De lo contrario, reemplaza a los revisores existentes con los usuarios dados. Se pueden especificar varios nombres de usuario separados por comas o repitiendo la opción.

--squash-before-merge[=false] Activa/desactiva la opción de fusionar commits en un solo commit al fusionar.

--target-branch="" Establece la rama de destino.

-t, --title="" Título de la solicitud de fusión.

--unassign[=false] Desasigna a todos los usuarios.

-u, --unlabel=[] Elimina etiquetas.

--unlock-discussion[=false] Desbloquea la discusión en la solicitud de fusión.

--wip[=false] Marca la solicitud de fusión como un trabajo en progreso. Alternativa a --draft.

-y, --yes[=false] Omite la solicitud de confirmación.

OPCIONES HEREDADAS DE COMANDOS PADRE

-h, --help[=false] Muestra la ayuda para este comando.

-R, --repo="" Selecciona otro repositorio. Puede usar el formato PROPIETARIO/REPO o GRUPO/NAMESPACE/REPO. También acepta una URL completa o una URL de Git.

EJEMPLO

# Marca una solicitud de fusión como lista
$ glab mr update 23 --ready
# Marca una solicitud de fusión como borrador
$ glab mr update 23 --draft
# Actualiza la solicitud de fusión para la rama actual
$ glab mr update --draft
# Actualiza la solicitud de fusión con la información del commit
$ glab mr update 23 --fill --fill-commit-body --yes
