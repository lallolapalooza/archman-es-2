GLMARK2-WAYLAND(1) Manual de comandos generales GLMARK2-WAYLAND(1)

NOMBRE

glmark2-wayland - Suite de benchmark de OpenGL (ES) 2.0

SINOPSIS

glmark2-wayland [opciones]

DESCRIPCIÓN

glmark2-wayland es un benchmark para OpenGL (ES) 2.0. Solo utiliza el subconjunto de la API de OpenGL 2.0 que es compatible con OpenGL ES 2.0.

OPCIONES

-b, --benchmark BENCHMARK
Un benchmark a ejecutar: 'escena(:opt1=val1)*' (la opción se puede usar varias veces)
-f, --benchmark-file ARCHIVO
Cargar benchmarks a ejecutar desde un archivo que contiene una lista de descripciones de benchmarks (una por línea) (la opción se puede usar varias veces)
--validate
Ejecutar una prueba rápida de validación de salida en lugar de ejecutar los benchmarks
--data-path RUTA
Ruta a los modelos, shaders y texturas de glmark2
--frame-end MÉTODO
Cómo finalizar un frame [default,none,swap,finish,readpixels]
--swap-mode MODO
Cómo intercambiar un frame, todos los modos son compatibles solo en el sabor DRM, 'fifo' está disponible en todos los sabores para forzar la sincronización vertical [default,immediate,mailbox,fifo]
--off-screen
Renderizar a una superficie fuera de pantalla
--visual-config
La configuración visual a usar para el objetivo de renderizado: 'id=ID:red=R:green=G:blue=B:alpha=A:buffer=BUF:stencil=STENCIL:samples=SAMPLES'. Los parámetros se pueden definir en cualquier orden y los parámetros omitidos asumen un valor predeterminado de '0' (id, stencil, samples) o '1' (red, green, blue, alpha, buffer). Si 'id' se establece en un valor distinto de cero, se ignoran todos los demás parámetros
--reuse-context
Usar un único contexto para todas las escenas (por defecto, cada escena obtiene su propio contexto)
-s, --size ANxAL
Tamaño de la ventana de salida (predeterminado: 800x600)
--fullscreen
Ejecutar en modo de pantalla completa (equivalente a --size -1x-1)
--results RESULTADOS
Los tipos de resultados a reportar para cada benchmark, como una lista separada por ':' [fps,cpu,shader]
--results-file ARCHIVO-RESULTADOS
El archivo donde guardar los resultados, en el formato determinado por la extensión del archivo [csv,xml]
--winsys-options OPS
Una lista de pares 'opt=valor' para opciones específicas del sistema de ventanas, separadas por ':'
-l, --list-scenes
Mostrar información sobre las escenas disponibles y sus opciones
--show-all-options
Mostrar todos los valores de opciones de escena utilizados para los benchmarks (por defecto, solo se muestran las opciones establecidas explícitamente)
--run-forever
Ejecutar indefinidamente, volviendo desde el último benchmark al primero
--annotate
Anotar los benchmarks con información en pantalla (igual que -b :show-fps=true:title=#info#)
-d, --debug
Mostrar mensajes de depuración
--version
Mostrar la versión del programa
-h, --help
Mostrar ayuda

BENCHMARKS

glmark2-wayland ofrece un conjunto de escenas que se pueden usar para medir muchos aspectos del rendimiento de OpenGL (ES) 2.0. La forma en que se renderiza cada escena es configurable a través de un conjunto de opciones. Para obtener las escenas disponibles y sus opciones aceptables, puede usar la opción de línea de comandos -l, --list-scenes.

En glmark2-wayland, un benchmark se define como una escena más un conjunto de valores de opción. Puede especificar la lista y el orden de los benchmarks a ejecutar usando la opción de línea de comandos -b, --benchmark (posiblemente varias veces). Si no se especifican benchmarks, se utiliza un conjunto predeterminado de benchmarks. Si no se especifica una opción de benchmark, asume su valor predeterminado (listado con -l, --list-scenes).

Como caso especial, se permite que una cadena de descripción de benchmark no contenga un nombre de escena (es decir, que comience con ':'). En este caso, cualquier valor de opción especificado se utiliza como los valores predeterminados para los benchmarks que siguen a esta cadena de descripción.

EJEMPLOS

Para ejecutar los benchmarks predeterminados:

glmark2-wayland

Para ejecutar un benchmark usando la escena 'shading' con una 'duración' de '5.0' segundos y
'shading' de tipo 'phong':

glmark2-wayland -b shading:duracion=5.0:shading=phong

Para ejecutar una serie de benchmarks, use la opción de línea de comandos -b, --benchmark varias veces:

glmark2-wayland -b shading:duracion=5.0 -b build:use-vbo=false -b texture

Para establecer valores de opción predeterminados para los benchmarks:

glmark2-wayland -b :duracion=2.0 -b shading -b build -b :duracion=5.0 -b texture
