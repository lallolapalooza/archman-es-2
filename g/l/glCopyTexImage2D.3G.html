NOMBRE

glCopyTexImage2D - copia píxeles en una imagen de textura 2D

ESPECIFICACIÓN C

void glCopyTexImage2D(GLenumtarget, GLintlevel, GLenuminternalformat, GLintx, GLinty, GLsizeiwidth, GLsizeiheight, GLintborder);

PARÁMETROS

target

Especifica la textura de destino. Debe ser GL_TEXTURE_2D, GL_TEXTURE_CUBE_MAP_POSITIVE_X, GL_TEXTURE_CUBE_MAP_NEGATIVE_X, GL_TEXTURE_CUBE_MAP_POSITIVE_Y, GL_TEXTURE_CUBE_MAP_NEGATIVE_Y, GL_TEXTURE_CUBE_MAP_POSITIVE_Z, o GL_TEXTURE_CUBE_MAP_NEGATIVE_Z.

level

Especifica el número de nivel de detalle. El nivel 0 es el nivel de imagen base. El nivel n es la nº imagen de reducción de mipmap.

internalformat

Especifica el formato interno de la textura. Debe ser una de las siguientes constantes simbólicas: GL_COMPRESSED_RED, GL_COMPRESSED_RG, GL_COMPRESSED_RGB, GL_COMPRESSED_RGBA. GL_COMPRESSED_SRGB, GL_COMPRESSED_SRGB_ALPHA. GL_DEPTH_COMPONENT, GL_DEPTH_COMPONENT16, GL_DEPTH_COMPONENT24, GL_DEPTH_COMPONENT32, GL_STENCIL_INDEX8, GL_RED, GL_RG, GL_RGB, GL_R3_G3_B2, GL_RGB4, GL_RGB5, GL_RGB8, GL_RGB10, GL_RGB12, GL_RGB16, GL_RGBA, GL_RGBA2, GL_RGBA4, GL_RGB5_A1, GL_RGBA8, GL_RGB10_A2, GL_RGBA12, GL_RGBA16, GL_SRGB, GL_SRGB8, GL_SRGB_ALPHA, o GL_SRGB8_ALPHA8.

x, y

Especifican las coordenadas de ventana de la esquina inferior izquierda de la región rectangular de píxeles que se va a copiar.

width

Especifica el ancho de la imagen de textura.

height

Especifica la altura de la imagen de textura.

border

Debe ser 0.

DESCRIPCIÓN

glCopyTexImage2D define una imagen de textura bidimensional, o una imagen de textura de mapa cúbico con píxeles del GL_READ_BUFFERactual.

El rectángulo de píxeles alineado con la pantalla, con la esquina inferior izquierda en (x, y) y con un ancho de width y una altura de height define el arreglo de textura en el nivel de mipmap especificado por level. internalformat especifica el formato interno del arreglo de textura.

Los píxeles en el rectángulo se procesan exactamente como si glReadPixels() hubiera sido llamado, pero el proceso se detiene justo antes de la conversión final. En este punto, todos los valores de los componentes de píxel se limitan al rango 0 1 y luego se convierten al formato interno de la textura para almacenarse en el arreglo de texeles.

El orden de los píxeles es tal que las coordenadas de pantalla x e y más bajas corresponden a las coordenadas de textura s y t más bajas.

Si alguno de los píxeles dentro del rectángulo especificado del GL_READ_BUFFER actual está fuera de la ventana asociada con el contexto de renderizado actual, entonces los valores obtenidos para esos píxeles son indefinidos.

Cuando internalformat es uno de los tipos sRGB, el GL no convierte automáticamente los píxeles de origen al espacio de color sRGB. En este caso, la función glPixelMap puede usarse para realizar la conversión.

NOTAS

1, 2, 3 y 4 no son valores aceptados para internalformat.

Una imagen con altura o ancho de 0 indica una textura NULA.

GL_STENCIL_INDEX8 se acepta para internalformat solo si la versión de GL es 4.4 o superior.

ERRORES

GL_INVALID_ENUM se genera si target no es GL_TEXTURE_2D, GL_TEXTURE_CUBE_MAP_POSITIVE_X, GL_TEXTURE_CUBE_MAP_NEGATIVE_X, GL_TEXTURE_CUBE_MAP_POSITIVE_Y, GL_TEXTURE_CUBE_MAP_NEGATIVE_Y, GL_TEXTURE_CUBE_MAP_POSITIVE_Z, o GL_TEXTURE_CUBE_MAP_NEGATIVE_Z.

GL_INVALID_VALUE se genera si level es menor que 0.

GL_INVALID_VALUE puede generarse si level es mayor que log 2 ⁢ max, donde max es el valor devuelto de GL_MAX_TEXTURE_SIZE.

GL_INVALID_VALUE se genera si width es menor que 0 o mayor que GL_MAX_TEXTURE_SIZE.

GL_INVALID_VALUE se genera si border no es 0.

GL_INVALID_VALUE se genera si internalformat no es un formato aceptado.

GL_INVALID_OPERATION se genera si internalformat es GL_DEPTH_COMPONENT, GL_DEPTH_COMPONENT16, GL_DEPTH_COMPONENT24, o GL_DEPTH_COMPONENT32 y no hay búfer de profundidad.
