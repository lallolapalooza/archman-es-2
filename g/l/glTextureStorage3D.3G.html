DESCRIPCIÓ

N

glTexStorage3D y glTextureStorage3D especifican los requisitos de almacenamiento para todos los niveles de una textura tridimensional, de arreglo bidimensional o de arreglo de mapa cúbico simultáneamente. Una vez que una textura es especificada con este comando, el formato y las dimensiones de todos los niveles se vuelven inmutables a menos que sea una textura proxy. El contenido de la imagen puede seguir siendo modificado, sin embargo, sus requisitos de almacenamiento no pueden cambiar. Tal textura se denomina una textura de formato

inmutable.

El comportamiento de glTexStorage3D depende del parámetro target . Cuando target es GL_TEXTURE_3D, o GL_PROXY_TEXTURE_3D, llamar a glTexStorage3D es equivalente, asumiendo que no se generan errores, a ejecutar el siguiente

pseudocódigo: 
    for (i = 0; i < levels; i++) {
        glTexImage3D(target, i, internalformat, width, height, depth, 0, format, type, NULL);
        width = max(1, (width / 2));
        height = max(1, (height / 2));
        depth = max(1, (depth / 2));
}

Cuando target es GL_TEXTURE_2D_ARRAY, GL_PROXY_TEXTURE_2D_ARRAY, GL_TEXTURE_CUBE_MAP_ARRAY, o GL_PROXY_TEXTURE_CUBE_MAP_ARRAY, glTexStorage3D es equivalente

a: 
    for (i = 0; i < levels; i++) {
        glTexImage3D(target, i, internalformat, width, height, depth, 0, format, type, NULL);
        width = max(1, (width / 2));
        height = max(1, (height / 2));
}

Llamar a glTextureStorage3D es equivalente al pseudocódigo anterior, donde target es el destino efectivo de texture y es como si texture estuviera enlazada a target para los propósitos de glTexImage3D

.

Dado que no se proporciona realmente ningún dato de textura, los valores usados en el pseudocódigo para format y type son irrelevantes y pueden considerarse como cualquier valor que sea legal para el enumerante internalformat elegido. internalformat debe ser uno de los formatos internos con tamaño dados en la Tabla 1 a continuación, uno de los formatos de componente de profundidad con tamaño GL_DEPTH_COMPONENT32F, GL_DEPTH_COMPONENT24, o GL_DEPTH_COMPONENT16, uno de los formatos combinados de profundidad-esténcil, GL_DEPTH32F_STENCIL8, o GL_DEPTH24_STENCIL8, o el formato solo de esténcil, GL_STENCIL_INDEX8. Con éxito, el valor de GL_TEXTURE_IMMUTABLE_FORMAT se convierte en GL_TRUE. El valor de GL_TEXTURE_IMMUTABLE_FORMAT puede ser descubierto llamando a glGetTexParameter() con pname establecido a GL_TEXTURE_IMMUTABLE_FORMAT. No pueden hacerse más cambios a las dimensiones o al formato del objeto de textura. Usar cualquier comando que pueda alterar las dimensiones o el formato del objeto de textura (como glTexImage3D() u otra llamada a glTexStorage3D) resultará en la generación de un error GL_INVALID_OPERATION, incluso si de hecho no alteraría las dimensiones o el formato del

objeto.

NOMBRE

glTextureStorage3D - establece la especificación de almacenamiento de una textura tridimensional o de array de texturas 3D especificada.

C ESPECIFICACIÓN

void glTextureStorage3D(GLuint texture, GLsizei levels, GLenum internalformat, GLsizei width, GLsizei height, GLsizei depth);

PARÁMETROS

texture
El identificador de la textura objetivo.
levels
El número de niveles demipmap que se van a reservar para la textura. El valor debe ser 1 si la textura no es multifrecuencia. Si es mayor que 1, el valor máximo permitido para los niveles demipmap es el resultado de floor(log2(max(width, height, depth))) + 1.
internalformat
El formato interno del almacenamiento de datos de la textura. Consulta la sección GL_EXT_texture_storage de la especificación de OpenGL para ver una lista de formatos admitidos.
width
El ancho de la textura en texels.
height
La altura de la textura en texels.
depth
La profundidad de la textura en texels.

DESCRIPCIÓN

glTextureStorage3D establece la especificación de almacenamiento de una textura tridimensional o de array de texturas 3D especificada.

Cuando se llama a glTextureStorage3D, se reserva un bloque inmutable de memoria para la textura especificada por texture. Las dimensiones, el número de niveles demipmap y el formato interno de la textura se establecen en los valores especificados por los argumentos width, height, depth, levels y internalformat.

Una vez que se ha asignado el almacenamiento de una textura utilizando glTextureStorage3D, las dimensiones, el número de niveles demipmap y el formato interno de la textura no se pueden modificar. Los intentos de modificar estos parámetros utilizando otras funciones deglTexImage* o glTextureImage* generarán un error GL_INVALID_OPERATION. Sin embargo, los datos de la textura sí se pueden actualizar utilizando llamadas a funciones como glTexSubImage3D o glTextureSubImage3D.

El parámetro levels especifica el número de niveles demipmap que se van a reservar para la textura. Si la textura no es multifrecuencia, levels debe ser 1. Si la textura es multifrecuencia, el valor máximo permitido para levels es floor(log2(max(width, height, depth))) + 1. Si se especifica un valor mayor que este, se genera un error GL_INVALID_VALUE.

El parámetro internalformat especifica el formato interno del almacenamiento de datos de la textura. Debe ser uno de los formatos internos de textura de tamaño fijo admitidos por la implementación de OpenGL.

NOTAS

GL_STENCIL_INDEX8
se acepta para internalformat solo si la versión de GL es 4.4 o superior.

ERRORES

GL_INVALID_OPERATION es generado por glTexStorage3D si cero está enlazado a target.

GL_INVALID_OPERATION es generado por glTextureStorage3D si texture no es el nombre de un objeto de textura existente.

GL_INVALID_ENUM es generado si internalformat no es un formato interno dimensionado válido.

GL_INVALID_ENUM es generado si target o el objetivo efectivo de texture no es uno de los objetivos aceptados descritos anteriormente.

GL_INVALID_VALUE es generado si width, height, depth o levels son menores que 1.

GL_INVALID_OPERATION es generado si target es GL_TEXTURE_3D o GL_PROXY_TEXTURE_3D y levels es mayor que log 2 max width ,   height ,   depth + 1.

GL_INVALID_OPERATION es generado si target es GL_TEXTURE_2D_ARRAY, GL_PROXY_TEXTURE_2D_ARRAY, GL_TEXURE_CUBE_MAP_ARRAY, o GL_PROXY_TEXTURE_CUBE_MAP_ARRAY y levels es mayor que log 2 max width ,   height + 1.
