NOMBRE

glTransformFeedbackBufferBase - enlaza un objeto buffer a un objeto buffer de transform feedback

ESPECIFICACIÓN C

void glTransformFeedbackBufferBase(GLuint xfb, GLuint index, GLuint buffer);

PARÁMETROS

xfb

Nombre del objeto buffer de transform feedback.

index

Índice del punto de enlace dentro de xfb.

buffer

Nombre del objeto buffer a enlazar al punto de enlace especificado.

DESCRIPCIÓN

glTransformFeedbackBufferBase enlaza el objeto buffer buffer al punto de enlace en el índice index del objeto de transform feedback xfb.

NOTAS

Llamar a glTransformFeedbackBufferBase es equivalente a llamar a glTransformFeedbackBufferRange() con offset cero y size igual al tamaño de buffer.

ERRORES

GL_INVALID_OPERATION se genera si xfb no es el nombre de un objeto de transform feedback existente.

GL_INVALID_VALUE se genera si buffer no es cero o el nombre de un objeto buffer existente.

GL_INVALID_VALUE se genera si index es mayor o igual que el número de puntos de enlace de buffer de transform feedback (el valor de GL_TRANSFORM_FEEDBACK_BUFFER_BINDING).
