NOMBRE

glPatchParameter - especifica los parámetros para primitivas de parche

ESPECIFICACIÓN C

void glPatchParameteri(GLenum pname, GLint value);

void glPatchParameterfv(GLenum pname, const GLfloat *values);

PARÁMETROS

pname

Especifica el nombre del parámetro a establecer. Se aceptan los constantes simbólicos GL_PATCH_VERTICES, GL_PATCH_DEFAULT_OUTER_LEVEL y GL_PATCH_DEFAULT_INNER_LEVEL.

value

Especifica el nuevo valor para el parámetro dado por pname.

values

Especifica la dirección de un array que contiene los nuevos valores para el parámetro dado por pname.

DESCRIPCIÓN

glPatchParameter especifica los parámetros que se utilizarán para las primitivas de parche. pname especifica el parámetro a modificar y debe ser GL_PATCH_VERTICES, GL_PATCH_DEFAULT_OUTER_LEVEL o GL_PATCH_DEFAULT_INNER_LEVEL. Para glPatchParameteri, value especifica el nuevo valor para el parámetro especificado por pname. Para glPatchParameterfv, values especifica la dirección de un array que contiene los nuevos valores para el parámetro especificado por pname.

Cuando pname es GL_PATCH_VERTICES, value especifica el número de vértices que se utilizarán para formar una única primitiva de parche. Las primitivas de parche son consumidas por el shader de control de teselación (si está presente) y utilizadas posteriormente para la teselación. Cuando se especifican primitivas utilizando glDrawArrays() o una función similar, cada parche se formará a partir de parameter puntos de control, cada uno representado por un vértice tomado de los arrays de vértices habilitados. parameter debe ser mayor que cero, y menor o igual al valor de GL_MAX_PATCH_VERTICES.

Cuando pname es GL_PATCH_DEFAULT_OUTER_LEVEL o GL_PATCH_DEFAULT_INNER_LEVEL, values contiene la dirección de un array que contiene los niveles de teselación externos o internos por defecto, respectivamente, que se utilizarán cuando no haya un shader de control de teselación presente.

ERRORES

GL_INVALID_ENUM se genera si pname no es un valor aceptado.

GL_INVALID_VALUE se genera si pname es GL_PATCH_VERTICES y value es menor o igual a cero, o mayor que el valor de GL_MAX_PATCH_VERTICES.
