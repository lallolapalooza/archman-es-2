NOMBRE

glGetSubroutineIndex - recupera el índice de una subrutina uniforme de una etapa de sombreado dada dentro de un programa

ESPECIFICACIÓN EN C

GLuint glGetSubroutineIndex(GLuint program, GLenum shadertype, const GLchar *name);

PARÁMETROS

program

Especifica el nombre del programa que contiene la etapa de sombreado.

shadertype

Especifica la etapa de sombreado desde la cual consultar el índice de la subrutina uniforme. shadertype debe ser uno de GL_VERTEX_SHADER, GL_TESS_CONTROL_SHADER, GL_TESS_EVALUATION_SHADER, GL_GEOMETRY_SHADER o GL_FRAGMENT_SHADER.

name

Especifica el nombre de la subrutina uniforme cuyo índice se va a consultar.

DESCRIPCIÓN

glGetSubroutineIndex devuelve el índice de una subrutina uniforme dentro de una etapa de sombreado adjunta a un objeto de programa. program contiene el nombre del programa al que está adjunta la etapa de sombreado. shadertype especifica la etapa desde la cual consultar el índice de la subrutina de sombreado. name contiene el nombre terminado en nulo de la subrutina uniforme cuyo nombre se va a consultar.

Si name no es el nombre de una subrutina uniforme en la etapa de sombreado, se devolverá GL_INVALID_INDEX, pero no se generará ningún error. Si name es el nombre de una subrutina uniforme en la etapa de sombreado, se devolverá un valor entre cero y el valor de GL_ACTIVE_SUBROUTINES menos uno. Los índices de subrutina se asignan utilizando enteros consecutivos en el rango de cero al valor de GL_ACTIVE_SUBROUTINES menos uno para la etapa de sombreado.

ERRORES

Se genera GL_INVALID_ENUM si shadertype o pname no son uno de los valores aceptados.

Se genera GL_INVALID_VALUE si program no es el nombre de un objeto de programa existente.
