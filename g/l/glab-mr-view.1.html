NOMBRE

glab-mr-view - Muestra el título, cuerpo y otra información de una solicitud de fusión.

SINOPSIS

glab mr view { | } [flags]

DESCRIPCIÓN

Muestra el título, cuerpo y otra información de una solicitud de fusión.

OPCIONES

-c, --comments[=false] Mostrar comentarios y actividades de la solicitud de fusión.

-F, --output="text" Formatear la salida como: text, json.

-p, --page=0 Número de página.

-P, --per-page=20 Número de elementos a listar por página.

-s, --system-logs[=false] Mostrar actividades y registros del sistema.

-w, --web[=false] Abrir la solicitud de fusión en un navegador. Usa el navegador predeterminado o el especificado en la variable BROWSER.

OPCIONES HEREDADAS DE COMANDOS PADRE

-h, --help[=false] Mostrar ayuda para este comando.

-R, --repo="" Seleccionar otro repositorio. Puede usar el formato PROPIETARIO/REPO o GRUPO/ESPACIO-DE-NOMBRES/REPO. También acepta URL completa o URL de Git.
