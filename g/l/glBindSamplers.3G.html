NOMBRE

glBindSamplers - enlaza uno o más objetos de muestreador nombrados a una secuencia de unidades de muestreador consecutivas

ESPECIFICACIÓN C

void glBindSamplers(GLuint first, GLsizei count, const GLuint *samplers);

PARÁMETROS

first

Especifica la primera unidad de muestreador a la que se va a enlazar un objeto de muestreador.

count

Especifica el número de muestreadores a enlazar.

samplers

Especifica la dirección de una matriz de nombres de objetos de muestreador existentes.

DESCRIPCIÓN

glBindSamplers enlaza muestreadores de una matriz de objetos de muestreador existentes a un número especificado de unidades de muestreador consecutivas. count especifica el número de objetos de muestreador cuyos nombres están almacenados en la matriz samplers. Ese número de nombres de muestreador se lee de la matriz y se enlaza a las count unidades de muestreador consecutivas que comienzan en first.

Si el nombre cero aparece en la matriz samplers, se restablece cualquier enlace existente a la unidad de muestreador. Cualquier entrada distinta de cero en samplers debe ser el nombre de un objeto de muestreador existente. Cuando hay presente una entrada distinta de cero en samplers, ese objeto de muestreador se enlaza a la unidad de muestreador correspondiente. Si samplers es NULL, es como si se hubiera especificado una matriz de tamaño apropiado que solo contuviera ceros.

glBindSamplers es equivalente al siguiente pseudocódigo:

    for (i = 0; i < count; i++) {
        if (samplers == NULL) {
            glBindSampler(first + i, 0);
        } else {
            glBindSampler(first + i, samplers[i]);
        }
    }

Cada entrada en samplers se comprobará individualmente y, si se encuentra que es inválida, el estado de esa unidad de muestreador no se cambiará y se generará un error. Sin embargo, el estado de otras unidades de muestreador a las que se hace referencia en el comando todavía se actualizará.

NOTAS

glBindSamplers solo está disponible si la versión de GL es 4.4 o superior.

ERRORES

Se genera GL_INVALID_OPERATION si first + count es mayor que el número de unidades de muestreador admitidas por la implementación.

Se genera GL_INVALID_OPERATION si cualquier valor en samplers no es cero o el nombre de un objeto de muestreador existente.

GETS ASOCIADOS

glGet() con el argumento GL_SAMPLER_BINDING
