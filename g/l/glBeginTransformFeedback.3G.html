NOMBRE

glBeginTransformFeedback - inicia una operación de transform feedback

ESPECIFICACIÓN EN C

void glBeginTransformFeedback(GLenumprimitiveMode);

void glEndTransformFeedback(void);

PARÁMETROS PARA GLBEGINTRANSFORMFEEDBACK

primitiveMode

Especifica el tipo de salida de las primitivas que serán registradas en los objetos buffer que están enlazados para el transform feedback.

DESCRIPCIÓN

El modo de transform feedback captura los valores de las variables varying escritas por el vertex shader (o, si está activo, el geometry shader). Se dice que el transform feedback está activo después de una llamada a glBeginTransformFeedback hasta una llamada posterior a

glEndTransformFeedback. Los comandos de transform feedback deben ser emparejados.

Si no hay un geometry shader presente, mientras el transform feedback está activo, el modo parámetro de glDrawArrays() debe coincidir con los especificados en la siguiente tabla:

Transform Feedback primitiveMode Modo de Primitiva de Renderizado Permitido modos
GL_POINTS GL_POINTS
GL_LINES GL_LINES, GL_LINE_LOOP, GL_LINE_STRIP, GL_LINES_ADJACENCY, GL_LINE_STRIP_ADJACENCY
GL_TRIANGLES GL_TRIANGLES, GL_TRIANGLE_STRIP, GL_TRIANGLE_FAN, GL_TRIANGLES_ADJACENCY, GL_TRIANGLE_STRIP_ADJACENCY

Si hay un geometry shader presente, el tipo de primitiva de salida del geometry shader debe coincidir con los proporcionados en la siguiente tabla:

Transform Feedback primitiveMode Tipo de Primitiva de Salida del Geometry Shader Permitido
GL_POINTS points
GL_LINES line_strip
GL_TRIANGLES triangle_strip

NOTAS

Los geometry shaders, y los GL_TRIANGLES_ADJACENCY, GL_TRIANGLE_STRIP_ADJACENCY, GL_LINES_ADJACENCY y GL_LINE_STRIP_ADJACENCY modos de primitiva están disponibles solo si la versión de GL es 3.2 o superior.

ERRORES

GL_INVALID_OPERATION se genera si glBeginTransformFeedback se ejecuta mientras el transform feedback está activo.

GL_INVALID_OPERATION se genera si glEndTransformFeedback se ejecuta mientras el transform feedback no está activo.

GL_INVALID_OPERATION se genera por glDrawArrays() si no hay un geometry shader presente, el transform feedback está activo y mode no es uno de los modos permitidos.

GL_INVALID_OPERATION se genera por glDrawArrays() si hay un geometry shader presente, el transform feedback está activo y el tipo de primitiva de salida del geometry shader no coincide con el transform feedback primitiveMode.

GL_INVALID_OPERATION se genera por glBeginTransformFeedback si algún punto de enlace usado en el modo de transform feedback no tiene un objeto buffer enlazado.

GL_INVALID_OPERATION se genera por glBeginTransformFeedback si no se usarían puntos de enlace, ya sea porque no hay un objeto programa activo o porque el objeto programa activo no ha especificado variables varying para registrar.
