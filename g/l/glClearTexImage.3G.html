GLCLEARTEXIMAGE(3G) [FIJO: manual] GLCLEARTEXIMAGE(3G)

NOMBRE

glClearTexImage - rellena toda una imagen de textura con un valor constante

ESPECIFICACIÓN C

void glClearTexImage(GLuint texture, GLint level, GLenum format, GLenum type, const void * data);

PARÁMETROS

texture

El nombre de un objeto de textura existente que contiene la imagen a limpiar.

level

El nivel de texture que contiene la región a limpiar.

format

El formato de los datos cuya dirección en memoria se proporciona en data.

type

El tipo de los datos cuya dirección en memoria se proporciona en data.

data

La dirección en memoria de los datos a utilizar para limpiar la región especificada.

DESCRIPCIÓN

glClearTexImage rellena toda una imagen contenida en una textura con un valor proporcionado por la aplicación. texture debe ser el nombre de una textura existente. Además, texture no puede ser el nombre de una textura de búfer, ni su formato interno puede estar comprimido.

format y type especifican el formato y tipo de los datos de origen y se interpretan como se hace para glTexImage3D(). Las texturas con un formato interno base de GL_DEPTH_COMPONENT, GL_STENCIL_INDEX, o GL_DEPTH_STENCIL requieren datos de componente de profundidad, plantilla o profundidad-plantilla respectivamente. Las texturas con otros formatos internos base requieren formatos RGBA. Las texturas con formatos internos enteros requieren datos enteros.

data es un puntero a una matriz de entre uno y cuatro componentes de datos de texel que se utilizará como fuente para el valor de relleno constante. Los elementos de data son convertidos por el GL al formato interno de la imagen de textura (que se especificó cuando el nivel se definió mediante cualquiera de los comandos glTexImage*, glTexStorage* o glCopyTexImage*), y luego se utilizan para rellenar el rango especificado del nivel de textura de destino. Si data es NULL, entonces se ignora el puntero y el sub-rango de la imagen de textura se rellena con ceros. Si la textura es una textura multiextraída, todas las muestras en un texel se limpian al valor especificado por data.

NOTAS

glClearTexImage solo está disponible si la versión de GL es 4.4 o superior.

ERRORES

Se genera GL_INVALID_OPERATION si texture es cero o no es el nombre de un objeto de textura existente.

Se genera GL_INVALID_OPERATION si texture es una textura de búfer.

Se genera GL_INVALID_OPERATION si texture tiene un formato interno comprimido.

Se genera GL_INVALID_OPERATION si el formato interno base es GL_DEPTH_COMPONENT y format no es GL_DEPTH_COMPONENT.

Se genera GL_INVALID_OPERATION si el formato interno base es GL_DEPTH_STENCIL y format no es GL_DEPTH_STENCIL.

Se genera GL_INVALID_OPERATION si el formato interno base es GL_STENCIL_INDEX y format no es GL_STENCIL_INDEX.

Se genera GL_INVALID_OPERATION si el formato interno base es GL_RGBA y format es GL_DEPTH_COMPONENT, GL_STENCIL_INDEX, o GL_DEPTH_STENCIL.

Se genera GL_INVALID_OPERATION si el formato interno es entero y format no especifica datos enteros.

Se genera GL_INVALID_OPERATION si el formato interno no es entero y format especifica datos enteros.

Se genera GL_INVALID_OPERATION si el array de imágenes identificado por level no ha sido previamente definido por una llamada a glTexImage* o glTexStorage*.

GETS ASOCIADOS

glGetTexImage(), glGetInternalformat()
