global(n) Comandos integrados de Tcl global(n)

NOMBRE

global - Acceder a variables globales

SINOPSIS

global ?nombre_var ...?

DESCRIPCIÓN

Este comando no tiene ningún efecto a menos que se ejecute en el contexto del cuerpo de un procedimiento. Si el comando global se ejecuta en el contexto del cuerpo de un procedimiento, crea variables locales vinculadas a las variables globales correspondientes (aunque estas variables vinculadas, como las creadas por upvar, no se incluyen en la lista devuelta por info locals).

Si nombre_var contiene calificadores de espacio de nombres, el nombre de la variable local es el nombre no calificado de la variable global, según lo determinado por el comando namespace tail.

nombre_var siempre se trata como el nombre de una variable, no como un elemento de matriz. Se devuelve un error si el nombre parece un elemento de matriz, como a(b).

EJEMPLOS

Este procedimiento establece la variable del espacio de nombres ::a::x

proc reset {} {
    global a::x
    set x 0
}

Este procedimiento acumula las cadenas que se le pasan en un búfer global, separadas por saltos de línea. Es útil para situaciones en las que desea construir un mensaje pieza por pieza (como con puts) pero enviar ese mensaje completo en una sola pieza (por ejemplo, a través de una conexión abierta con socket o como parte de una respuesta HTTP contada).

proc accum {string} {
    global accumulator
    append accumulator $string \n
}
