NOMBRE

glab-cluster-agent-token-cache - Gestiona tokens cacheados de GitLab Agent.

SINOPSIS

glab cluster agent token-cache [flags]

DESCRIPCIÓN

Gestiona tokens cacheados de GitLab Agent creados por 'glab cluster agent get-token'.

Este grupo de comandos te permite listar y limpiar tokens que están cacheados localmente en el keyring y en la caché del sistema de archivos.

ALMACENAMIENTO DE LA CACHÉ

La CLI de GitLab cachea los tokens de los agentes en dos ubicaciones:

1.
Keyring - Utiliza el keyring del sistema (Administrador de credenciales de Windows, Llavero de macOS, Servicio de secretos de Linux)
2.
Sistema de archivos - Almacena tokens en el directorio de caché del usuario como archivos cifrados.

La caché mejora el rendimiento al evitar la necesidad de crear nuevos tokens para cada operación de kubectl al usar 'glab cluster agent update-kubeconfig'.

FORMATO DE CLAVE DE LA CACHÉ

Los tokens cacheados se almacenan utilizando un formato de clave que incluye:

  • URL de la instancia de GitLab codificada en Base64
  • ID del agente

Esto asegura que los tokens estén correctamente aislados por instancia de GitLab y agente.

OPCIONES HEREDADAS DE COMANDOS PADRE

-h, --help[=false] Muestra la ayuda para este comando.

-R, --repo="" Selecciona otro repositorio. Puede usar el formato PROPIETARIO/REPO o GRUPO/NAMESPACE/REPO. También acepta URL completa o URL de Git.
