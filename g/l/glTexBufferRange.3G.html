DESCRIPCIÓ

N

glTexBufferRange y glTextureBufferRange adjuntan un rango del almacén de datos de un objeto buffer especificado a un objeto de textura especificado, y especifican el formato de almacenamiento para la imagen de textura encontrada en el objeto buffer. El objeto de textura debe ser una textura de

buffer.

Si buffer es cero, cualquier objeto buffer adjuntado a la textura de buffer es desadjuntado y no se adjunta ningún nuevo objeto buffer. Si buffer es distinto de cero, debe ser el nombre de un objeto buffer

existente.

El inicio y el tamaño del rango se especifican mediante offset y size respectivamente, ambos medidos en unidades básicas de máquina. offset debe ser mayor o igual que cero, size debe ser mayor que cero, y la suma de offset y size no debe exceder el valor de GL_BUFFER_SIZE para buffer. Además, offset debe ser un múltiplo entero del valor de GL_TEXTURE_BUFFER_OFFSET_ALIGNMENT

.

Cuando un rango de un objeto buffer se adjunta a una textura buffer, el rango especificado del almacén de datos del objeto buffer se toma como el arreglo de texels de la textura. El número de texels en el arreglo de texels de la textura buffer viene dado por $$ \left\lfloor { size \over { components \times sizeof(base\_type) } } \right\rfloor $$ donde $components$ y $base\_type$ son el número de elementos y el tipo de datos base de los elementos, tal como se especifica en la tabla anterior. El número de texels en el arreglo de texels se limita entonces al valor del límite dependiente de la implementación GL_MAX_TEXTURE_BUFFER_SIZE. Cuando se accede a una textura buffer en un shader, los resultados de una obtención de texel son indefinid

os si la coordenada de texel especificada es negativa, o es mayor
o igual que el número limitado de texels en el arreglo de texels.

ERRORE

S

GL_INVALID_ENUM es generado por glTexBufferRange si target no es GL_TEXTURE_BUFFER

.

GL_INVALID_OPERATION es generado por glTextureBufferRange si texture no es el nombre de un objeto de textura

existente.

GL_INVALID_ENUM es generado por glTextureBufferRange si el target efectivo de texture no es GL_TEXTURE_BUFFER

.

GL_INVALID_ENUM es generado si internalformat no es uno de los formatos internos dimensionados descritos

anteriormente.

GL_INVALID_OPERATION es generado si buffer no es cero y no es el nombre de un objeto buffer

existente.

GL_INVALID_VALUE es generado si offset es negativo, si size es menor o igual a cero, o si offset + size es mayor que el valor de GL_BUFFER_SIZE para buffer

.

GL_INVALID_VALUE es generado si offset no es un múltiplo entero del valor de GL_TEXTURE_BUFFER_OFFSET_ALIGNMEN

T
.
