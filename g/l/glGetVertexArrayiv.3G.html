NOMBRE

glGetVertexArrayiv - recuperar parámetros de un objeto de array de vértices

ESPECIFICACIÓN C

void glGetVertexArrayiv(GLuint vaobj, GLenum pname, GLint *param);

PARÁMETROS

vaobj

especifica el nombre del objeto de array de vértices a utilizar para la consulta.

pname

Nombre de la propiedad a utilizar para la consulta. Debe ser GL_ELEMENT_ARRAY_BUFFER_BINDING.

param

Devuelve el valor solicitado.

DESCRIPCIÓN

Esta función proporciona un medio para consultar propiedades de un objeto de array de vértices existente. El objeto de array de vértices no tiene que estar enlazado al contexto de renderizado en el momento de la llamada, pero debe haber sido enlazado al menos una vez antes de esta llamada.

glGetVertexArrayiv se puede utilizar para recuperar el ID de un objeto de búfer que se enlazará al punto de enlace GL_ELEMENT_ARRAY_BUFFER siempre que el objeto de array de vértices consultado se enlace al contexto de renderizado. El enlace se puede cambiar para un objeto de array de vértices activo con una llamada a glBindBuffer.

ERRORES

Se genera un error GL_INVALID_OPERATION si vaobj no es el nombre de un objeto de array de vértices existente.

Se genera un error GL_INVALID_ENUM si pname no es GL_ELEMENT_ARRAY_BUFFER_BINDING.
