GLSTENCILFUNC(3G) [FIJACIÓN: manual] GLSTENCILFUNC(3G)

NOMBRE

glStencilFunc - establece la función frontal y posterior y el valor de referencia para la prueba de stencil

ESPECIFICACIÓN C

void glStencilFunc(GLenum func, GLint ref, GLuint mask);

PARÁMETROS

func

Especifica la función de prueba. Son válidos ocho constantes simbólicas: GL_NEVER, GL_LESS, GL_LEQUAL, GL_GREATER, GL_GEQUAL, GL_EQUAL, GL_NOTEQUAL y GL_ALWAYS. El valor inicial es GL_ALWAYS.

ref

Especifica el valor de referencia para la prueba de stencil. ref se limita al rango 0 2 n - 1, donde n es el número de planos de bits en el búfer de stencil. El valor inicial es 0.

mask

Especifica una máscara que se aplica mediante AND tanto al valor de referencia como al valor de stencil almacenado cuando se realiza la prueba. El valor inicial es todos los 1.

DESCRIPCIÓN

El stencil, al igual que el búfer de profundidad, habilita y deshabilita el dibujo en una base por píxel. Primero se dibuja en los planos de stencil usando primitivas de dibujo GL, luego se renderizan la geometría y las imágenes utilizando los planos de stencil para enmascarar partes de la pantalla. El stencil se utiliza típicamente en algoritmos de renderizado multipaso para lograr efectos especiales, como calcomanías, contornos y renderizado de geometría sólida constructiva.

La prueba de stencil elimina condicionalmente un píxel basándose en el resultado de una comparación entre el valor de referencia y el valor en el búfer de stencil. Para habilitar y deshabilitar la prueba, llame a glEnable() y

glDisable con el argumento GL_STENCIL_TEST. Para especificar acciones basadas en el resultado de la prueba de stencil, llame a glStencilOp() o glStencilOpSeparate().

Puede haber dos conjuntos separados de parámetros func, ref y mask; uno afecta a los polígonos con cara posterior y el otro afecta a los polígonos con cara frontal, así como a otras primitivas no poligonales. glStencilFunc() establece el estado del stencil frontal y posterior a los mismos valores. Utilice glStencilFuncSeparate() para establecer el estado del stencil frontal y posterior a valores diferentes.

func es una constante simbólica que determina la función de comparación de stencil. Acepta uno de los ocho valores, que se muestran en la siguiente lista. ref es un valor de referencia entero que se utiliza en la comparación de stencil. Se limita al rango 0 2 n - 1, donde n es el número de planos de bits en el búfer de stencil. mask se aplica mediante AND bit a bit tanto al valor de referencia como al valor de stencil almacenado, y los valores resultantes de la operación AND participan en la comparación.

Si stencil representa el valor almacenado en la ubicación correspondiente del búfer de stencil, la siguiente lista muestra el efecto de cada función de comparación que se puede especificar mediante func. Solo si la comparación tiene éxito, el píxel pasa a la siguiente etapa del proceso de rasterización (consulte glStencilOp()). Todas las pruebas tratan los valores de stencil como enteros sin signo en el rango 0 2 n - 1, donde n es el número de planos de bits en el búfer de stencil.

Los siguientes valores son aceptados por func:

GL_NEVER

Siempre falla.

GL_LESS

Pasa si ( ref & mask ) < ( stencil & mask ).

GL_LEQUAL

Pasa si ( ref & mask ) <= ( stencil & mask ).

GL_GREATER

Pasa si ( ref & mask ) > ( stencil & mask ).

GL_GEQUAL

Pasa si ( ref & mask ) >= ( stencil & mask ).

GL_EQUAL

Pasa si ( ref & mask ) = ( stencil & mask ).

GL_NOTEQUAL

Pasa si ( ref & mask ) != ( stencil & mask ).

GL_ALWAYS

Siempre pasa.

NOTAS

Inicialmente, la prueba de stencil está deshabilitada. Si no hay un búfer de stencil, no se puede realizar ninguna modificación del stencil y es como si la prueba de stencil siempre pasara.

glStencilFunc() es lo mismo que llamar a glStencilFuncSeparate() con face establecido en GL_FRONT_AND_BACK.

ERRORES

Se genera GL_INVALID_ENUM si func no es uno de los ocho valores aceptados.

GETS ASOCIADOS

glGet() con el argumento GL_STENCIL_FUNC, GL_STENCIL_VALUE_MASK, GL_STENCIL_REF, GL_STENCIL_BACK_FUNC, GL_STENCIL_BACK_VALUE_MASK, GL_STENCIL_BACK_REF o GL_STENCIL_BITS

glIsEnabled() con el argumento GL_STENCIL_TEST
