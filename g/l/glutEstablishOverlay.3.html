glutEstablishOverlay(3)

Paquete: freeglut

Licencias: X11

glutEstablishOverlay(3) freeglut glutEstablishOverlay(3)

NOMBRE

glutEstablishOverlay - establece una superposición (si es posible) para la ventana actual.

ADVERTENCIA

Aún no implementado en freeglut.

SINTAXIS

void glutEstablishOverlay(void);

DESCRIPCIÓN

glutEstablishOverlay establece una superposición (si es posible) para la ventana actual. El modo de visualización solicitado para la superposición está determinado por el modo de visualización inicial. Se puede llamar a glutLayerGet(GLUT_OVERLAY_POSSIBLE) para determinar si una superposición es posible para la ventana actual con el modo de visualización inicial actual. No intente establecer una superposición cuando no sea posible; GLUT terminará el programa.

Si se llama a glutEstablishOverlay cuando ya existe una superposición, la superposición existente se elimina primero y luego se establece una nueva superposición. Se descarta el estado del contexto OpenGL de la superposición antigua.

El estado de visualización inicial de una superposición se muestra, sin embargo, la superposición solo se muestra realmente si la ventana de la superposición se muestra.

Implícitamente, la capa de la ventana en uso cambia a la superposición inmediatamente después de que se establece la superposición.

EJEMPLO

Establecer una superposición es un poco complicado, pero fácil una vez que te acostumbras. Aquí tienes un ejemplo:

  int overlaySupport;
  int transparent, red, white;
  glutInitDisplayMode(GLUT_SINGLE | GLUT_INDEX);
  overlaySupport = glutLayerGet(GLUT_OVERLAY_POSSIBLE);
  if (overlaySupport) {
    glutEstablishOverlay();
    glutHideOverlay();
    transparent = glutLayerGet(GLUT_TRANSPARENT_INDEX);
    glClearIndex(transparent);
    red = (transparent + 1) % glutGet(GLUT_WINDOW_COLORMAP_SIZE);
    white = (transparent + 2) % glutGet(GLUT_WINDOW_COLORMAP_SIZE);
    glutSetColor(red, 1.0, 0.0, 0.0);  /* Rojo. */
    glutSetColor(white, 1.0, 1.0, 1.0);  /* Blanco. */
    glutOverlayDisplayFunc(redrawOverlay);
    glutReshapeFunc(reshape);
  } else {
    printf("Lo siento, no hay una superposición elegante (¡prueba una estación de trabajo SGI!)0);
  }

Si configura una superposición e instala una función de respuesta de redimensionamiento, debe actualizar las vistas y posiblemente las matrices de proyección tanto del plano normal como de la superposición. Por ejemplo, su función de respuesta de redimensionamiento podría verse así:

  void
  reshape(int w, int h)
  {
    if (overlaySupport) {
      glutUseLayer(GLUT_OVERLAY);
      /* Configura la superposición para tener un sistema de coordenadas estilo X. */
      glViewport(0, 0, w, h);
      glMatrixMode(GL_PROJECTION);
      glLoadIdentity();
      gluOrtho2D(0, w, 0, h);
      glScalef(1, -1, 1);
      glTranslatef(0, -h, 0);
      glMatrixMode(GL_MODELVIEW);
      glutUseLayer(GLUT_NORMAL);
    }
    glViewport(0, 0, w, h);
  }

Consulte la página del manual de glutOverlayDisplayFunc para ver un ejemplo que muestra una forma de escribir su función de visualización de superposición.

NOTAS SOBRE LA IMPLEMENTACIÓN DE X

GLUT para X utiliza la convención SERVER_OVERLAY_VISUALS para determinar si hay visualizaciones de superposición disponibles. Si bien la convención permite superposiciones opacas (sin transparencia) y superposiciones con transparencia especificada como una máscara de bits, la gestión de superposiciones de GLUT solo proporciona acceso a superposiciones de píxeles transparentes.

Hasta que las superposiciones RGBA se comprendan mejor, GLUT solo admite superposiciones de índice de color.
