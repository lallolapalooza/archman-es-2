NOMBRE

glReadBuffer, glNamedFramebufferReadBuffer - seleccionar una fuente de búfer de color para píxeles

ESPECIFICACIÓN EN C

void glReadBuffer(GLenummode);

void glNamedFramebufferReadBuffer(GLuintframebuffer, GLenummode);

PARÁMETROS

framebuffer

Especifica el nombre del objeto framebuffer para la función glNamedFramebufferReadBuffer .

mode

Especifica un búfer de color. Los valores aceptados son GL_FRONT_LEFT, GL_FRONT_RIGHT, GL_BACK_LEFT, GL_BACK_RIGHT, GL_FRONT, GL_BACK, GL_LEFT, GL_RIGHT, y las constantes GL_COLOR_ATTACHMENTi.

DESCRIPCIÓN

glReadBuffer especifica un búfer de color como la fuente para los comandos glReadPixels(), glCopyTexImage1D(), glCopyTexImage2D(), glCopyTexSubImage1D(), glCopyTexSubImage2D(), y glCopyTexSubImage3D() posteriores. mode acepta uno de doce o más valores predefinidos. En un sistema completamente configurado, GL_FRONT, GL_LEFT, y GL_FRONT_LEFT nombran todos el búfer frontal izquierdo, GL_FRONT_RIGHT y GL_RIGHT nombran el búfer frontal derecho, y GL_BACK_LEFT y GL_BACK nombran el búfer trasero izquierdo. Además, las constantes GL_COLOR_ATTACHMENTi pueden usarse para indicar el i-ésimo acoplamiento de color, donde i varía desde cero hasta el valor de GL_MAX_COLOR_ATTACHMENTS menos uno.

Las configuraciones de doble búfer no estéreo tienen solo un búfer frontal izquierdo y un búfer trasero izquierdo. Las configuraciones de búfer único tienen un búfer frontal izquierdo y uno frontal derecho si es estéreo, y solo un búfer frontal izquierdo si no es estéreo. Es un error especificar un búfer inexistente a glReadBuffer.

mode es inicialmente GL_FRONT en configuraciones de búfer único y GL_BACK en configuraciones de doble búfer.

Para glReadBuffer, el framebuffer objetivo es el enlazado a GL_READ_FRAMEBUFFER. Para glNamedFramebufferReadBuffer, framebuffer debe ser cero o el nombre del framebuffer objetivo. Si framebuffer es cero, entonces se afecta al framebuffer de lectura predeterminado.

ERRORES

GL_INVALID_ENUM se genera si mode no es uno de los doce (o más) valores aceptados.

GL_INVALID_OPERATION se genera si mode especifica un búfer que no existe.

GL_INVALID_OPERATION se genera por glNamedFramebufferReadBuffer si framebuffer no es cero o el nombre de un objeto framebuffer existente.

OBTENCIONES ASOCIADAS

glGet() con el argumento GL_READ_BUFFER
