NOMBRE

glDrawRangeElements - renderizar primitivas a partir de datos de array

ESPECIFICACIÓN C

void glDrawRangeElements(GLenum mode, GLuint start, GLuint end, GLsizei count, GLenum type, const void * indices);

PARÁMETROS

mode

Especifica qué tipo de primitivas renderizar. Se aceptan los constantes simbólicos GL_POINTS, GL_LINE_STRIP, GL_LINE_LOOP, GL_LINES, GL_LINE_STRIP_ADJACENCY, GL_LINES_ADJACENCY, GL_TRIANGLE_STRIP, GL_TRIANGLE_FAN, GL_TRIANGLES, GL_TRIANGLE_STRIP_ADJACENCY, GL_TRIANGLES_ADJACENCY y GL_PATCHES.

start

Especifica el índice mínimo del array contenido en indices.

end

Especifica el índice máximo del array contenido en indices.

count

Especifica el número de elementos a renderizar.

type

Especifica el tipo de los valores en indices. Debe ser uno de GL_UNSIGNED_BYTE, GL_UNSIGNED_SHORT o GL_UNSIGNED_INT.

indices

Especifica un puntero a la ubicación donde se almacenan los índices.

DESCRIPCIÓN

glDrawRangeElements es una forma restringida de glDrawElements(). mode y count coinciden con los argumentos correspondientes de glDrawElements(), con la restricción adicional de que todos los valores en los arrays count deben estar entre start y end, inclusive.

Las implementaciones denotan cantidades máximas recomendadas de datos de vértices e índices, que pueden consultarse llamando a glGet() con los argumentos GL_MAX_ELEMENTS_VERTICES y GL_MAX_ELEMENTS_INDICES. Si end - start + 1 es mayor que el valor de GL_MAX_ELEMENTS_VERTICES, o si count es mayor que el valor de GL_MAX_ELEMENTS_INDICES, entonces la llamada puede operar con un rendimiento reducido. No hay requisito de que todos los vértices en el rango start end sean referenciados. Sin embargo, la implementación puede procesar parcialmente vértices no utilizados, reduciendo el rendimiento del que se podría lograr con un conjunto de índices óptimo.

Cuando se llama a glDrawRangeElements, utiliza count elementos secuenciales de un array habilitado, comenzando en start, para construir una secuencia de primitivas geométricas. mode especifica qué tipo de primitivas se construyen y cómo los elementos del array construyen estas primitivas. Si se habilita más de un array, se utiliza cada uno.

Los atributos de vértice que son modificados por glDrawRangeElements tienen un valor indeterminado después de que glDrawRangeElements retorna. Los atributos que no son modificados mantienen sus valores previos.

NOTAS

GL_LINE_STRIP_ADJACENCY, GL_LINES_ADJACENCY, GL_TRIANGLE_STRIP_ADJACENCY y GL_TRIANGLES_ADJACENCY solo están disponibles si la versión de GL es 3.2 o superior.

ERRORES

Es un error que los índices queden fuera del rango start end, pero las implementaciones pueden no verificar esta situación. Dichos índices provocan un comportamiento dependiente de la implementación.

Se genera GL_INVALID_ENUM si mode no es un valor aceptado.

Se genera GL_INVALID_VALUE si count es negativo.

Se genera GL_INVALID_VALUE si end < start.

Se genera GL_INVALID_OPERATION si un shader de geometría está activo y mode es incompatible con el tipo de primitiva de entrada del shader de geometría en el objeto de programa actualmente instalado.

Se genera GL_INVALID_OPERATION si un nombre de objeto de buffer distinto de cero está enlazado a un array habilitado o al array de elementos y el almacén de datos del objeto de buffer está actualmente mapeado.

GETS ASOCIADOS

glGet() con el argumento GL_MAX_ELEMENTS_VERTICES

glGet() con el argumento GL_MAX_ELEMENTS_INDICES
