DESCRIPCIÓN glProgra

modifica el valor de una variable uniforme o de un array de variables uniformes. La ubicación de la variable uniforme a modificar se especifica

mediante

location , que debe ser un valor devuelto por glGetUniformLocation (). glProgramUniform opera sobre el objeto de programa especificado por program .

Los comandos glProgramUniform{1|2|3|4}{f|i|ui} se utilizan para cambiar el valor de la variable uniforme especificada por location utilizando los valores pasados como argumentos. El número especificado en el comando debe coincidir con el número de componentes en el tipo de datos de la variable uniforme especificada (por ejemplo, 1 para float, int, unsigned int, bool; 2 para vec2, ivec2, uvec2, bvec2, etc.). El sufijo f indica que se están pasando valores de punto flotante; el sufijo i indica que se están pasando valores enteros; el sufijo ui indica que se están pasando valores enteros sin signo, y este tipo también debe coincidir con el tipo de datos de la variable uniforme especificada. Las

variantes

i de esta función deben utilizarse para proporcionar valores para variables uniformes definidas como int, ivec2, ivec3, ivec4, o arrays de estos. Las

variantes

ui de esta función deben utilizarse para proporcionar valores para variables uniformes definidas como unsigned int, uvec2, uvec3, uvec4, o arrays de estos. Las variantes f deben utilizarse para proporcionar valores para variables uniformes de tipo float, vec2, vec3, vec4, o arrays de estos. Puede utilizarse cualquiera de las variantes i , ui o f para proporcionar valores para variables uniformes de tipo bool, bvec2, bvec3, bvec4, o arrays de estos. La variable uniforme se establecerá en false si el valor de entrada es 0 o 0.0f, y se establecerá en true en caso contrario. Todas las variables uniformes activas definidas en un objeto de programa se inicializan a 0 cuando el objeto de programa se enlaza correctamente. Conservan los valores asignados a ellos por una llamada a glProgramUniform hasta que se produce la siguiente operación de enlace exitosa en el objeto de programa, cuando se inicializan nuevamente a 0. Los comandos glProgramUniform{1|2|3|4}{f|i|ui}v pueden utilizarse para modificar una única variable uniforme o un array de variables uniformes. Estos comandos pasan un count y un puntero a los valores que se cargarán en una variable uniforme o en un array de variables uniformes. Debe utilizarse un count de 1 si se modifica el valor de una única variable uniforme, y puede utilizarse un count de 1 o mayor para modificar un array completo o parte de un

array. Al cargar

n elementos a partir de una posición arbitraria m en un array de variables uniformes, los

elementos

m + n - 1 del array serán reemplazados con los nuevos valores. Si m + n - 1 es mayor que el tamaño del array de variables uniformes, los valores de todos los elementos del array más allá del final del array serán ignorados. El número especificado en el nombre del comando indica el número de componentes para cada elemento en valor , y debe coincidir con el número de componentes en el tipo de datos de la variable uniforme especificada (por ejemplo, 1 para float, int, bool; 2 para vec2, ivec2, bvec2, etc.). El tipo de datos especificado en el nombre del comando debe coincidir con el tipo de datos para la variable uniforme especificada como se describió anteriormente para glProgramUniform{1|2|3|4}{f|i|ui}

.

Para arrays de variables uniformes, cada elemento del array se considera que es del tipo indicado en el nombre

del comando (por ejemplo,
