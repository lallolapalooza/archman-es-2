Opciones de línea de comandos:

-c --config-file RUTA

Ruta al archivo de configuración

-e --env-variables

Usar variables de entorno para configurar Glewlwyd

-p --port PUERTO

Puerto en el que escuchar

-u --url-prefix PREFIJO

Prefijo de la URL de la API

-m --log-mode MODO

Modos de registro disponibles: consola, syslog o archivo. Si desea múltiples modos, sepárelos con una coma ",". Por defecto: consola

-l --log-level NIVEL

Niveles de registro disponibles: NONE, ERROR, WARNING, INFO, DEBUG. Por defecto: INFO

-f --log-file RUTA

Ruta para el archivo de registro si se especifica el modo de registro de archivo

-v --version

Imprimir la versión actual de Glewlwyd

-h --help

Imprimir este mensaje

VER TAMBIÉN

La documentación completa de glewlwyd se mantiene como un manual de Texinfo. Si los programas info y glewlwyd están correctamente instalados en su sitio, el comando

info glewlwyd

debería darle acceso al manual completo.
