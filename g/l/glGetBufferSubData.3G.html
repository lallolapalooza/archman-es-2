DESCRIPCIÓ

N

glGetBufferSubData y glGetNamedBufferSubData devuelven parte o todos los contenidos de datos del almacén de datos del objeto de búfer especificado. Los datos que comienzan en el desplazamiento de byte offset y se extienden durante size bytes se copian del almacén de datos del objeto de búfer a la memoria a la que apunta data. Se lanza un error si el objeto de búfer está actualmente mapeado, o si offset y size definen juntos un rango que excede los

límites del almacén de da
tos del objeto de búfer.

NOTA

S

Si se genera un error, no se realiza ningún cambio en el contenido de data

.

El destino GL_ATOMIC_COUNTER_BUFFER está disponible solo si la versión de GL es 4.2 o

superior.

Los destinos GL_DISPATCH_INDIRECT_BUFFER y GL_SHADER_STORAGE_BUFFER están disponibles solo si la versión de GL es 4.3 o

superior.

El destino GL_QUERY_BUFFER está disponible solo

si la versión de
GL es 4.4 o superior.

ERRORE

S

Se genera GL_INVALID_ENUM por glGetBufferSubData si target no es uno de los destinos genéricos de vinculación de

búfer.

Se genera GL_INVALID_OPERATION por glGetBufferSubData si está vinculado cero a target

.

Se genera GL_INVALID_OPERATION por glGetNamedBufferSubData si buffer no es el nombre de un objeto de búfer

existente.

Se genera GL_INVALID_VALUE si offset o size es negativo, o si $offset + size$ es mayor que el valor de GL_BUFFER_SIZE para el objeto de

búfer.

Se genera GL_INVALID_OPERATION si el objeto de búfer está mapeado con glMapBufferRange() o glMapBuffer(), a menos que haya sido mapeado con el bit GL_MAP_PERSISTENT_BIT establecido en los flags de acceso de glMapBufferRang

e
.
