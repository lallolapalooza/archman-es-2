NOMBRE

glab-ci-delete - Eliminar pipelines de CI/CD.

SINOPSIS

glab ci delete [flags]

DESCRIPCIÓN

Eliminar pipelines de CI/CD.

OPCIONES

--dry-run[=false] Simular el proceso, pero no eliminar nada.

--older-than=0s Filtrar pipelines más antiguos que la duración dada. Unidades válidas: h, m, s, ms, us, ns.

--page=0 Número de página.

--paginate[=false] Realizar solicitudes HTTP adicionales para obtener todas las páginas de proyectos antes de clonar. Respeta '--per-page'.

--per-page=0 Número de elementos a listar por página.

--source="" Filtrar pipelines por origen: api, chat, external, external_pull_request_event, merge_request_event, ondemand_dast_scan, ondemand_dast_validation, parent_pipeline, pipeline, push, schedule, security_orchestration_policy, trigger, web, webide.

-s, --status="" Eliminar pipelines por estado: running, pending, success, failed, canceled, skipped, created, manual.

OPCIONES HEREDADAS DE COMANDOS PADRE

-h, --help[=false] Mostrar ayuda para este comando.

-R, --repo="" Seleccionar otro repositorio. Puede usar el formato OWNER/REPO o GROUP/NAMESPACE/REPO. También acepta URL completa o URL de Git.

EJEMPLO

$ glab ci delete 34
$ glab ci delete 12,34,2
$ glab ci delete --source=api
$ glab ci delete --status=failed
$ glab ci delete --older-than 24h
$ glab ci delete --older-than 24h --status=failed
