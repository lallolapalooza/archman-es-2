L'emplacement de la variable uniforme à modifier est spécifié par location, qui doit être une valeur retournée par glGetUniformLocation(). glUniform opère sur l'objet programme qui a été rendu partie de l'état courant en appelant glUseProgram(). Les commandes glUniform{1|2|3|4}{f|i|ui} sont utilisées

pour

changer la valeur de la variable uniforme spécifiée par location en utilisant les valeurs passées en arguments. Le nombre spécifié dans la commande doit correspondre au nombre de composantes dans le type de données de la variable uniforme spécifiée (par exemple, 1 pour float, int, unsigned int, bool ; 2 pour vec2, ivec2, uvec2, bvec2, etc.). Le suffixe f indique que des valeurs en virgule flottante sont passées ; le suffixe i indique que des valeurs entières sont passées ; le suffixe ui indique que des valeurs entières non signées sont passées, et ce type doit également correspondre au type de données de la variable uniforme spécifiée. Les variantes i de cette fonction doivent être utilisées pour fournir des valeurs pour les variables uniformes définies en tant que int, ivec2, ivec3, ivec4, o arreglos de estos. Las variantes ui de esta función deben usarse para proporcionar valores para variables uniformes definidas como unsigned int, uvec2, uvec3, uvec4, o arreglos de estos. Las variantes f deben usarse para proporcionar valores para variables uniformes de tipo float, vec2, vec3, vec4, o arreglos de estos. Cualquiera de las variantes i, ui o f puede usarse para proporcionar valores para variables uniformes de tipo bool, bvec2, bvec3, bvec4, o arreglos de estos. La variable uniforme se establecerá en false si el valor de entrada es 0 o 0.0f, y se establecerá en true en caso

contrario.

Todas las variables uniformes activas definidas en un objeto de programa se inicializan a 0 cuando el objeto de programa se vincula correctamente. Retienen los valores asignados a ellos por una llamada a glUniform hasta que ocurre la siguiente operación de vinculación exitosa en el objeto de programa, cuando se inicializan nuevamente a

0.

Los comandos glUniform{1|2|3|4}{f|i|ui}v pueden usarse para modificar una sola variable uniforme o un arreglo de variables uniformes. Estos comandos pasan un conteo y un puntero a los valores que se cargarán en una variable uniforme o un arreglo de variables uniformes. Se debe usar un conteo de 1 si se modifica el valor de una sola variable uniforme, y se puede usar un conteo de 1 o mayor para modificar un arreglo completo o parte de un arreglo. Al cargar n elementos comenzando en una posición arbitraria m en un arreglo de variables uniformes, los elementos m + n - 1 en el arreglo serán reemplazados con los nuevos valores. Si m + n - 1 es mayor que el tamaño del arreglo de variables uniformes, los valores para todos los elementos del arreglo más allá del final del arreglo serán ignorados. El número especificado en el nombre del comando indica el número de componentes para cada elemento en value, y debe coincidir con el número de componentes en el tipo de datos de la variable uniforme especificada (por ejemplo, 1 para float, int, bool; 2 para vec2, ivec2, bvec2, etc.). El tipo de datos especificado en el nombre del comando debe coincidir con el tipo de datos para la variable uniforme especificada como se describió anteriormente para glUniform{1|2|3|4}

{f|i|ui}.

Para arreglos de variables uniformes, cada elemento del arreglo se considera que es del tipo indicado en el nombre del comando (por ejemplo, glUniform3f o glUniform3fv puede usarse para cargar un arreglo de variables uniformes de tipo vec3). El número de elementos del arreglo de variables uniformes a modificar es especificado por coun

t

Los comandos glUniformMatrix{2|3|4|2x3|3x2|2x4|4x2|3x4|4x3}fv se usan para modificar una matriz o un arreglo de matrices. Los números en el nombre del comando se interpretan como la dimensionalidad de la matriz. El número 2 indica una matriz 2 × 2 (es decir, 4 valores), el número 3 indica una matriz 3 × 3 (es decir, 9 valores), y el número 4 indica una matriz 4 × 4 (es decir, 16 valores). La dimensionalidad de la matriz no cuadrada es explícita, con el primer número representando el número de columnas y el segundo número representando el número de filas. Por ejemplo, 2x4 indica una matriz 2 × 4 con 2 columnas y 4 filas (es decir, 8 valores). Si transpose es GL_FALSE, se asume que cada matriz se proporciona en orden columna mayor. Si transpose es GL_TRUE, se asume que cada matriz se proporciona en orden fila mayor. El argumento count indica el número de matrices a pasar. Se debe usar un conteo de 1 si se modifica el

valor de una sola matriz, y se puede usar un conteo
mayor que 1 para modificar un arreglo de matrices.

NOTA

S

glUniform1i y glUniform1iv son las únicas dos funciones que pueden usarse para cargar variables uniformes definidas como tipos sampler. Cargar samplers con cualquier otra función resultará en un error GL_INVALID_OPERATION

.

Si count es mayor que 1 y la variable uniforme indicada no es un arreglo, se genera un error GL_INVALID_OPERATION y la variable uniforme especificada permanecerá sin

cambios.

Aparte de las excepciones anteriores, si el tipo y tamaño de la variable uniforme tal como se define en el shader no coinciden con el tipo y tamaño especificados en el nombre del comando usado para cargar su valor, se generará un error GL_INVALID_OPERATION y la variable uniforme especificada permanecerá sin

cambios.

Si location es un valor distinto de -1 y no representa una ubicación de variable uniforme válida en el objeto de programa actual, se generará un error, y no se harán cambios en el almacenamiento de variables uniformes del objeto de programa actual. Si location es igual a -1, los datos pasados serán ignorados silenc

iosamente y la variable uniforme
especificada no será cambiada.
