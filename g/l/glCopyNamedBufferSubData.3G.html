NAME

glCopyNamedBufferSubData - Copies data between buffer objects

C SPECIFICATION

void glCopyNamedBufferSubData( GLuint readBuffer, GLuint writeBuffer, GLintptr readOffset, GLintptr writeOffset, GLsizeiptr size );

PARAMETERS

readBuffer
Specifies the buffer object to copy data from.
writeBuffer
Specifies the buffer object to copy data to.
readOffset
Specifies the offset in the read buffer where the copy begins.
writeOffset
Specifies the offset in the write buffer where the copy is placed.
size
Specifies the number of bytes to copy.

DESCRIPTION

`glCopyNamedBufferSubData` copies a region of data from one buffer object to another.

The region to be copied is specified by `readOffset` and `size`. The destination for the copy is specified by `writeOffset`.

If `readBuffer` and `writeBuffer` are the same, the copy behaves as if the source data is first copied to a temporary buffer, and then the temporary buffer is copied to the destination.

The behavior is undefined if the source and destination regions overlap.

NOTES

`glCopyNamedBufferSubData` is available for buffer objects created with the `glGenBuffers` command.

ERRORS

GL_INVALID_VALUE is generated if `readBuffer` or `writeBuffer` are not valid buffer objects.

GL_INVALID_OFFSET is generated if `readOffset`, `writeOffset`, or `size` are negative, or if `readOffset` + `size` exceeds the size of `readBuffer`, or if `writeOffset` + `size` exceeds the size of `writeBuffer`.

VERSION SUPPORT

glCopyNamedBufferSubData is available in OpenGL 4.3 and later.
