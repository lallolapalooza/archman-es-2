GLOBASH(1) Manual de comandos generales GLOBASH(1)

NOMBRE

globash - un shell especial para Global usando GNU bash

SINOPSIS

globash

DESCRIPCIÓN

Globash es un shell especial para Global usando GNU bash. Puedes utilizar muchas funciones para facilitar la lectura del código fuente, como la pila de etiquetas, la marca de etiquetas y las cookies. Primero, debes crear archivos de etiquetas usando gtags e invocar este comando en el proyecto. Consulta la ayuda (escribe ´ghelp<RET>´) para obtener detalles de uso.

ARCHIVOS

´GTAGS´
Archivo de etiquetas para definiciones.
´GRTAGS´
Archivo de etiquetas para referencias.
´GPATH´
Archivo de etiquetas para archivos fuente.
´~/.globashrc´
Archivo de inicio.
´~/.globash/´
Directorio de sesiones.
