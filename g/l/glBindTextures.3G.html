DESCRIPCIÓ

N

glBindTextures vincula un array de objetos de textura existentes a un número especificado de unidades de textura consecutivas. count especifica el número de objetos de textura cuyos nombres están almacenados en el array textures. Ese número de nombres de textura se leen del array y se vinculan a las count unidades de textura consecutivas a partir de first. El destino, o tipo de textura, se deduce del objeto de textura y cada textura se vincula al destino correspondiente de la unidad de textura. Si el nombre cero aparece en el array textures, cualquier vinculación existente a cualquier destino de la unidad de textura se restablece y la textura predeterminada para ese destino se vincula en su lugar. Cualquier entrada distinta de cero en textures debe ser el nombre de un objeto de textura existente. Si textures es NULL, entonces es como si se hubiera especificado un array de tamaño apropiado que contiene solo

ceros.

Con la excepción de que el selector de textura activa mantiene su valor actual, glBindTextures es equivalente al siguiente

pseudocódigo: 
    for (i = 0; i < count; i++) {
        GLuint texture;
        if (textures == NULL) {
            texture = 0;
        } else {
            texture = textures[i];
        }
        glActiveTexture(GL_TEXTURE0 + first + i);
        if (texture != 0) {
            GLenum target = /* destino de textures[i] */;
            glBindTexture(target, textures[i]);
        } else {
            for (target in all supported targets) {
                glBindTexture(target, 0);
            }
        }
}

Cada entrada en textures se comprobará individualmente y si se encuentra que es inválida, el estado de esa unidad de textura no se cambiará y

se generará un error. Sin embargo, el estado de las otras unidades
de textura referenciadas por el comando seguirá actualizándose.

NOTA

S

glBindTextures solo está disponible si la versión de GL es 4.4 o

superior.

Tenga en cuenta que debido a que glBindTextures no puede crear nuevas texturas (incluso si un nombre pasado ha sido generado previamente por una llamada a glGenTextures()), los nombres pasados a glBindTextures deben haber sido vinculados al menos una vez previamente mediante una llamada a glBindTe

xtur
e().

ERRORE

S

Se genera GL_INVALID_OPERATION si first + count es mayor que el número de unidades de imagen de textura soportadas por la

implementación.

Se genera GL_INVALID_OPERATION si algún valor en textures

no es cero o el nombre de u
n objeto de textura existente.
