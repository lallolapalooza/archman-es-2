NOMBRE

glBindBufferBase - enlaza un objeto de buffer a un objetivo de buffer indexado

ESPECIFICACIÓN C

void glBindBufferBase(GLenum target, GLuint index, GLuint buffer);

PARÁMETROS

target

Especifica el objetivo de la operación de enlace. target debe ser uno de GL_ATOMIC_COUNTER_BUFFER, GL_TRANSFORM_FEEDBACK_BUFFER, GL_UNIFORM_BUFFER o GL_SHADER_STORAGE_BUFFER.

index

Especifica el índice del punto de enlace dentro del array especificado por target.

buffer

El nombre de un objeto de buffer para enlazar al punto de enlace especificado.

DESCRIPCIÓN

glBindBufferBase enlaza el objeto de buffer buffer al punto de enlace en el índice index del array de objetivos especificados por target. Cada target representa un array indexado de puntos de enlace de buffer, así como un único punto de enlace general que puede ser utilizado por otras funciones de manipulación de buffers como glBindBuffer() o glMapBuffer(). Además de enlazar buffer al objetivo de enlace de buffer indexado, glBindBufferBase también enlaza buffer al punto de enlace de buffer genérico especificado por target.

NOTAS

Llamar a glBindBufferBase es equivalente a llamar a glBindBufferRange() con offset cero y size igual al tamaño del buffer.

El objetivo GL_ATOMIC_COUNTER_BUFFER solo está disponible si la versión de GL es 4.2 o superior.

El objetivo GL_SHADER_STORAGE_BUFFER solo está disponible si la versión de GL es 4.3 o superior.

ERRORES

Se genera GL_INVALID_ENUM si target no es GL_ATOMIC_COUNTER_BUFFER, GL_TRANSFORM_FEEDBACK_BUFFER, GL_UNIFORM_BUFFER o GL_SHADER_STORAGE_BUFFER.

Se genera GL_INVALID_VALUE si index es mayor o igual al número de puntos de enlace indexados específicos de target.

Se genera GL_INVALID_VALUE si buffer no tiene un almacén de datos asociado, o si el tamaño de dicho almacén es cero.
