GLBLENDFUNCSEPARATE(3G) [FIXME: manual] GLBLENDFUNCSEPARATE(3G)

NOMBRE

glBlendFuncSeparate - especifica la aritmética de píxeles por separado para los componentes RGB y alfa

ESPECIFICACIÓN C

void glBlendFuncSeparate(GLenumsrcRGB, GLenumdstRGB, GLenumsrcAlpha, GLenumdstAlpha);

void glBlendFuncSeparatei(GLuintbuf, GLenumsrcRGB, GLenumdstRGB, GLenumsrcAlpha, GLenumdstAlpha);

PARÁMETROS

buf

Para glBlendFuncSeparatei, especifica el índice del búfer de dibujo para el cual se establecen las funciones de mezcla.

srcRGB

Especifica cómo se calculan los factores de mezcla de los colores rojo, verde y azul. El valor inicial es GL_ONE.

dstRGB

Especifica cómo se calculan los factores de mezcla de destino de los colores rojo, verde y azul. El valor inicial es GL_ZERO.

srcAlpha

Especifica cómo se calcula el factor de mezcla de origen del alfa. El valor inicial es GL_ONE.

dstAlpha

Especifica cómo se calcula el factor de mezcla de destino del alfa. El valor inicial es GL_ZERO.

DESCRIPCIÓN

Los píxeles se pueden dibujar utilizando una función que mezcla los valores RGBA entrantes (de origen) con los valores RGBA que ya están en el búfer de cuadro (los valores de destino). La mezcla está inicialmente deshabilitada. Utilice glEnable() y

glDisable con el argumento GL_BLEND para habilitar y deshabilitar la mezcla.

glBlendFuncSeparate define la operación de mezcla para todos los búferes de dibujo cuando está habilitada. glBlendFuncSeparatei define la operación de mezcla para un solo búfer de dibujo especificado por buf cuando está habilitada para ese búfer de dibujo. srcRGB especifica qué método se utiliza para escalar los componentes de color RGB de origen. dstRGB especifica qué método se utiliza para escalar los componentes de color RGB de destino. Del mismo modo, srcAlpha especifica qué método se utiliza para escalar el componente de color alfa de origen, y dstAlpha especifica qué método se utiliza para escalar el componente alfa de destino. Los métodos posibles se describen en la siguiente tabla. Cada método define cuatro factores de escala, uno para cada color: rojo, verde, azul y alfa.

En la tabla y en las ecuaciones siguientes, los componentes de color de la primera fuente, de la segunda fuente y de destino se denominan R s0 G s0 B s0 A s0, R s1 G s1 B s1 A s1 y R d G d B d A d, respectivamente. El color especificado por glBlendColor() se denomina R c G c B c A c. Se entiende que tienen valores enteros entre 0 y k R k G k B k A, donde

k c = 2 m c - 1

y m R m G m B m A es el número de planos de bits de rojo, verde, azul y alfa.

Los factores de escala de origen y destino se denominan s R s G s B s A y d R d G d B d A. Todos los factores de escala tienen un rango de 0 1.

En la tabla,

i = min ⁡ A s 1 - A d

Para determinar los valores RGBA mezclados de un píxel, el sistema utiliza las siguientes ecuaciones:

R d = min ⁡ k R R s ⁢ s R + R d ⁢ d R G d = min ⁡ k G G s ⁢ s G + G d ⁢ d G B d = min ⁡ k B B s ⁢ s B + B d ⁢ d B A d = min ⁡ k A A s ⁢ s A + A d ⁢ d A

A pesar de la aparente precisión de las ecuaciones anteriores, la aritmética de mezcla no está especificada exactamente, ya que la mezcla opera con valores de color enteros imprecisos. Sin embargo, se garantiza que un factor de mezcla que debería ser igual a 1 no modificará su multiplicando, y un factor de mezcla igual a 0 reduce su multiplicando a 0. Por ejemplo, cuando srcRGB es GL_SRC_ALPHA, dstRGB es GL_ONE_MINUS_SRC_ALPHA, y A s es igual a k A, las ecuaciones se reducen a un reemplazo simple:

R d = R s G d = G s B d = B s A d = A s

NOTAS

El alfa entrante (de origen) se considera correctamente como la opacidad del material, que varía desde 1.0 (K A), que representa opacidad completa, hasta 0.0 (0), que representa transparencia completa.

Cuando hay más de un búfer de color habilitado para el dibujo, el GL realiza la mezcla por separado para cada búfer habilitado, utilizando el contenido de ese búfer como color de destino. (Véase glDrawBuffer().)

Cuando la mezcla de doble fuente está habilitada (es decir, se utiliza uno de los factores de mezcla que requieren la segunda entrada de color), el número máximo de búferes de dibujo habilitados viene dado por GL_MAX_DUAL_SOURCE_DRAW_BUFFERS, que puede ser menor que GL_MAX_DRAW_BUFFERS.

ERRORES

GL_INVALID_ENUM se genera si srcRGB o dstRGB no es un valor aceptado.

GL_INVALID_VALUE se genera por glBlendFuncSeparatei si buf es mayor o igual que el valor de GL_MAX_DRAW_BUFFERS.

CONSULTAS ASOCIADAS

glGet() con el argumento GL_BLEND_SRC_RGB

glGet() con el argumento GL_BLEND_SRC_ALPHA

glGet() con el argumento GL_BLEND_DST_RGB

glGet() con el argumento GL_BLEND_DST_ALPHA
