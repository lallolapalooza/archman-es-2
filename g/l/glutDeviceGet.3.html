NOMBRE

glutDeviceGet - recupera información del dispositivo GLUT representada por enteros.

SINTAXIS

int glutDeviceGet(GLenum info);

ARGUMENTOS

info
Nombre de la información del dispositivo a recuperar.
GLUT_HAS_KEYBOARD
Distinto de cero si hay un teclado disponible; cero si no está disponible. Para la mayoría de las implementaciones de GLUT, se puede asumir la disponibilidad de un teclado.
GLUT_HAS_MOUSE
Distinto de cero si hay un ratón disponible; cero si no está disponible. Para la mayoría de las implementaciones de GLUT, se puede asumir la disponibilidad de un teclado.
GLUT_HAS_SPACEBALL
Distinto de cero si hay un Spaceball disponible; cero si no está disponible.
GLUT_HAS_DIAL_AND_BUTTON_BOX
Distinto de cero si hay una caja de diales y botones disponible; cero si no está disponible.
GLUT_HAS_TABLET
Distinto de cero si hay una tableta disponible; cero si no está disponible.
GLUT_NUM_MOUSE_BUTTONS
Número de botones soportados por el ratón. Si no se soporta ningún ratón, se devuelve cero.
GLUT_NUM_SPACEBALL_BUTTONS
Número de botones soportados por el Spaceball. Si no se soporta ningún Spaceball, se devuelve cero.
GLUT_NUM_BUTTON_BOX_BUTTONS
Número de botones soportados por el dispositivo de caja de diales y botones. Si no se soporta ningún dispositivo de caja de diales y botones, se devuelve cero.
GLUT_NUM_DIALS
Número de diales soportados por el dispositivo de caja de diales y botones. Si no se soporta ningún dispositivo de caja de diales y botones, se devuelve cero.
GLUT_NUM_TABLET_BUTTONS
Número de botones soportados por la tableta. Si no se soporta ninguna tableta, se devuelve cero.
GLUT_DEVICE_IGNORE_KEY_REPEAT
Devuelve verdadero si las teclas auto-repetidas de la ventana actual son ignoradas. Este estado se controla mediante glutIgnoreKeyRepeat.
GLUT_DEVICE_KEY_REPEAT
El estado global de repetición de teclas del sistema de ventanas. Devuelve GLUT_KEY_REPEAT_OFF, GLUT_KEY_REPEAT_ON o GLUT_KEY_REPEAT_DEFAULT. Esto no necesariamente devolverá el valor pasado por última vez a glutSetKeyRepeat.
GLUT_JOYSTICK_POLL_RATE
Devuelve la tasa de sondeo del joystick de la ventana actual, tal como la estableció glutJoystickFunc. Si no se soporta ningún joystick, la tasa de sondeo será siempre cero. La tasa de sondeo del joystick también devuelve cero si la tasa de sondeo especificada por última vez a glutJoystickFunc es negativa o si se registró una devolución de llamada NULL.
GLUT_HAS_JOYSTICK
Distinto de cero si hay un joystick disponible; cero si no está disponible.
GLUT_JOYSTICK_BUTTONS
Número de botones soportados por el joystick. Si no se soporta ningún joystick, se devuelve cero.
GLUT_JOYSTICK_AXES
Número de ejes soportados por el joystick. Si no se soporta ningún joystick, se devuelve cero.

DESCRIPCIÓN

glutDeviceGet recupera información del dispositivo GLUT representada por enteros. El parámetro info determina qué tipo de información del dispositivo devolver. Solicitar información del dispositivo para un nombre de información de dispositivo GLUT no válido devuelve menos uno.

NOTAS DE IMPLEMENTACIÓN X

La implementación actual utiliza la extensión X Input para reconocer los dispositivos Spaceball, tableta y caja de diales y botones de SGI.

NOTAS DE IMPLEMENTACIÓN WIN32

GLUT_DEVICE_KEY_REPEAT siempre devuelve GLUT_KEY_REPEAT_ON.

VER TAMBIÉN

glutGet, glutKeyboardFunc, glutMouseFunc, glutSpaceballMotion, glutTabletMotionFunc, glutTabletButtonFunc, glutDialsFunc, glutButtonBoxFunc, glutIgnoreKeyRepeat, glutSetKeyRepeat, glutJoystickFunc
