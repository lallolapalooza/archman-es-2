NOMBRE

glRenderbufferStorage, glNamedRenderbufferStorage - establece el almacenamiento de datos, el formato y las dimensiones de la imagen de un objeto de búfer de renderizado

ESPECIFICACIÓN EN C

void glRenderbufferStorage(GLenumtarget, GLenuminternalformat, GLsizeiwidth, GLsizeiheight);

void glNamedRenderbufferStorage(GLuintrenderbuffer, GLenuminternalformat, GLsizeiwidth, GLsizeiheight);

PARÁMETROS

target

Especifica un objetivo de enlace para la asignación de la función glRenderbufferStorage . Debe ser GL_RENDERBUFFER.

renderbuffer

Especifica el nombre del objeto de búfer de renderizado para la función glNamedRenderbufferStorage .

internalformat

Especifica el formato interno a utilizar para la imagen del objeto de búfer de renderizado.

width

Especifica el ancho del búfer de renderizado, en píxeles.

height

Especifica la altura del búfer de renderizado, en píxeles.

DESCRIPCIÓN

glRenderbufferStorage es equivalente a llamar a glRenderbufferStorageMultisample() con samples establecido a cero, y glNamedRenderbufferStorage es equivalente a llamar a glNamedRenderbufferStorageMultisample con las muestras establecidas a cero.

Para glRenderbufferStorage, el objetivo de la operación, especificado por target debe ser GL_RENDERBUFFER. Para glNamedRenderbufferStorage, renderbuffer debe ser el nombre de un objeto de búfer de renderizado existente. internalformat especifica el formato interno a utilizar para el almacenamiento del objeto de búfer de renderizado y debe ser un formato renderizable de color, de profundidad o de stencil. width y height son las dimensiones, en píxeles, del búfer de renderizado. Tanto width como height deben ser menores o iguales al valor de GL_MAX_RENDERBUFFER_SIZE.

Tras el éxito, glRenderbufferStorage y glNamedRenderbufferStorage eliminan cualquier almacén de datos existente para la imagen del búfer de renderizado y el contenido del almacén de datos después de llamar a glRenderbufferStorage es indefinido.

ERRORES

GL_INVALID_ENUM es generado por glRenderbufferStorage si target no es GL_RENDERBUFFER.

GL_INVALID_OPERATION es generado por glNamedRenderbufferStorage si renderbuffer no es el nombre de un objeto de búfer de renderizado existente.

GL_INVALID_VALUE es generado si width o height es negativo, o mayor que el valor de GL_MAX_RENDERBUFFER_SIZE.

GL_INVALID_ENUM es generado si internalformat no es un formato renderizable de color, de profundidad o de stencil.

GL_OUT_OF_MEMORY es generado si el GL no puede crear un almacén de datos del tamaño solicitado.
