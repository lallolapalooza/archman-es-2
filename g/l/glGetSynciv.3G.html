NOMBRE

glGetSynciv - consulta las propiedades de un objeto sync

ESPECIFICACIÓN C

void glGetSynciv(GLsync sync, GLenum pname, GLsizei bufSize, GLsizei *length, GLint *values);

PARÁMETROS

sync

Especifica el objeto sync cuyas propiedades se van a consultar.

pname

Especifica el parámetro cuyo valor se va a recuperar del objeto sync especificado en sync.

bufSize

Especifica el tamaño del búfer cuya dirección se proporciona en values.

length

Especifica la dirección de una variable para recibir el número de enteros colocados en values.

values

Especifica la dirección de una matriz para recibir los valores del parámetro consultado.

DESCRIPCIÓN

glGetSynciv recupera las propiedades de un objeto sync. sync especifica el nombre del objeto sync cuyas propiedades se van a recuperar.

En caso de éxito, glGetSynciv reemplaza hasta bufSize enteros en values con los valores de propiedad correspondientes del objeto que se está consultando. El número real de enteros reemplazados se devuelve en la variable cuya dirección se especifica en length. Si length es NULL, no se devuelve ninguna longitud.

Si pname es GL_OBJECT_TYPE, se coloca un único valor que representa el tipo específico del objeto sync en values. El único tipo admitido es GL_SYNC_FENCE.

Si pname es GL_SYNC_STATUS, se coloca un único valor que representa el estado del objeto sync (GL_SIGNALED o GL_UNSIGNALED) en values.

Si pname es GL_SYNC_CONDITION, se coloca un único valor que representa la condición del objeto sync en values. La única condición admitida es GL_SYNC_GPU_COMMANDS_COMPLETE.

Si pname es GL_SYNC_FLAGS, se coloca un único valor que representa las banderas con las que se creó el objeto sync en values. Actualmente no se admiten banderas [1].

Si ocurre un error, no se escribirá nada en values ni en length.

ERRORES

Se genera GL_INVALID_VALUE si sync no es el nombre de un objeto sync.

Se genera GL_INVALID_ENUM si pname no es uno de los tokens aceptados.
