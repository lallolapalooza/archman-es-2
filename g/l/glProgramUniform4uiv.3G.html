PARÁMETROS

program

Especifica el identificador del programa que contiene la variable uniforme a modificar.

location

Especifica la ubicación de la variable uniforme a modificar.

count

Para los comandos vectoriales (glProgramUniform*v), especifica el número de elementos que se van a modificar. Esto debería ser 1 si la variable uniforme objetivo no es un array, y 1 o más si es un array.

Para los comandos de matriz (glProgramUniformMatrix*), especifica el número de matrices que se van a modificar. Esto debería ser 1 si la variable uniforme objetivo no es un array de matrices, y 1 o más si es un array.

transpose

Para los comandos de matriz, especifica si se debe transponer la matriz. Debe ser GL_TRUE para transponer la matriz o GL_FALSE para no hacerlo.

value

Especifica el valor o los valores que se utilizarán para actualizar la variable uniforme del programa especificado.

v0, v1, v2, v3

Especifican los valores que se utilizarán para actualizar la variable uniforme del programa especificado.

DESCRIPCIÓN

Las funciones glProgramUniform* establecen los valores de las variables uniformes especificadas en el objeto de programa especificado. Estas funciones no requieren que el programa esté actualmente activo (es decir, que no se llame a glUseProgram antes de llamar a estas funciones).

Las variables uniformes son variables de entrada a los shaders. Se denominan "uniformes" porque un valor uniforme dado se aplica por igual a todas las primitivas procesadas por un nivel de shader dado.

Si program es 0, las funciones de establecimiento de uniformes se aplican al programa actualmente activo.

Si location es el valor devuelto por una llamada anterior a glGetUniformLocation para el programa program, entonces el uniforme correspondiente se establece en el valor especificado.

Si location es -1, el valor especificado se ignora. Esto se puede usar para llamar a las funciones de establecimiento de uniformes de forma condicional o para evitar la recuperación de la ubicación de un uniforme que se sabe que no se está utilizando.

Las funciones con un sufijo de un solo número (por ejemplo, glProgramUniform1f) establecen un único valor.

Las funciones con un sufijo de dos, tres o cuatro números (por ejemplo, glProgramUniform3i) establecen dos, tres o cuatro valores, respectivamente. Los valores se pasan como argumentos escalares separados.

Las funciones con un sufijo 'v' (por ejemplo, glProgramUniform4fv) establecen un número especificado de elementos a partir de un puntero a un array de valores.

Para los comandos de matriz, la matriz se pasa en orden de columnas. Por ejemplo, mat2 se pasa como un array de 4 valores: los dos primeros valores son la primera columna y los dos segundos valores son la segunda columna.

Si el tipo de la variable uniforme en el programa no coincide con el tipo especificado por la función llamada, el valor se convertirá implícitamente.

Las funciones que establecen valores flotantes con un sufijo de entero (por ejemplo, glProgramUniform1i) realizan una conversión de tipo de entero a flotante.

Las funciones que establecen valores enteros con un sufijo flotante (por ejemplo, glProgramUniform1f) realizan una conversión de tipo de flotante a entero.

Los valores enteros sin signo se convierten a flotantes para las funciones de punto flotante.

Los valores de punto flotante se truncan al entero más cercano para las funciones enteras.

Si el tipo de uniforme es un vector, los valores pasados se asignan a los componentes del vector. Por ejemplo, si se llama a glProgramUniform2f para un uniforme de tipo vec4, se establecen los componentes x e y, y los componentes z y w se establecen en 0.0 y 1.0, respectivamente.

Si el uniforme es un array, los valores pasados se asignan a los primeros elementos del array. El parámetro count especifica cuántos elementos del array se van a establecer.

Si el uniforme es una matriz, los valores pasados se asignan a los elementos de la matriz. El parámetro count especifica cuántas matrices se van a establecer.

Si se llama a una función de establecimiento de uniformes con un parámetro location que no se corresponde con un uniforme en el programa especificado, o si se llama a una función que no es apropiada para el tipo de uniforme (por ejemplo, llamar a glProgramUniform1f para un uniforme de tipo sampler2D), no se produce ningún error, pero el valor no se actualiza.

Para obtener más información sobre las conversiones de tipos, consulte la especificación de OpenGL.

Los comandos glProgramUniform{1|2|3|4}{f|i|ui} se utilizan para cambiar el valor de la variable uniforme especificada por location usando los valores pasados como argumentos. El número especificado en el comando debe coincidir con el número de componentes en el tipo de datos de la variable uniforme especificada (por ejemplo, 1 para float, int, unsigned int, bool; 2 para vec2, ivec2, uvec2, bvec2, etc.). El sufijo f indica que se están pasando valores de punto flotante; el sufijo i indica que se están pasando valores enteros; el sufijo ui indica que se están pasando valores enteros sin signo, y este tipo también debe coincidir con el tipo de datos de la variable uniforme especificada. Las variantes i de esta función deben usarse para proporcionar valores para variables uniformes definidas como int, ivec2, ivec3, ivec4, o arrays de estas. Las variantes ui de esta función deben usarse para proporcionar valores para variables uniformes definidas como unsigned int, uvec2, uvec3, uvec4, o arrays de estas. Las variantes f deben usarse para proporcionar valores para variables uniformes de tipo float, vec2, vec3, vec4, o arrays de estas. Tanto las variantes i, ui como f pueden usarse para proporcionar valores para variables uniformes de tipo bool, bvec2, bvec3, bvec4, o arrays de estas. La variable uniforme

se

Los comandos glProgramUniform{1|2|3|4}{f|i|ui}v pueden usarse para modificar una sola variable uniforme o un array de variables uniformes. Estos comandos pasan un count y un puntero a los valores que se cargarán en una variable uniforme o en un array de variables uniformes. Se debe usar un count de 1 si se modifica el valor de una sola variable uniforme, y se puede usar un count de 1 o mayor para modificar un array c ompleto o parte de un array. Al cargar n elementos a partir de una p osición arbitraria m en un array de variables uniformes, los elementos m + n - 1 en el array serán reemplazados con los nuevos valores. Si m + n - 1 es mayor que el tamaño del array de variables uniformes, los valores de todos los elementos del array más allá del final del array serán ignorados. El número especificado en el nombre del comando indica el número de componentes para cada elemento en value, y debe coincidir con el número de componentes en el tipo de datos de la variable uniforme especificada (por ejemplo, 1 para float, int, bool; 2 para vec2, ivec2, bvec2, etc.).
