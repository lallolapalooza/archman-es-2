glib-genmarshal(1)

Paquete: glib2-devel

Licencias: LGPL-2.1-or-later

glib-genmarshal() glib-genmarshal()

Nombre

glib-genmarshal - Utilidad de generación de código C marshaller para los closures de GLib

SINOPSIS

glib-genmarshal [OPCIÓN…] [ARCHIVO…]

DESCRIPCIÓN

glib-genmarshal es una pequeña utilidad que genera marshallers de código C para las funciones de callback del mecanismo GClosure en la subbiblioteca GObject de GLib. Las funciones marshaller tienen una firma estándar; se les pasa el closure que invoca, un array de estructuras de valor que contienen los parámetros de la función de callback y una estructura de valor para el valor de retorno del callback. El marshaller es entonces responsable de llamar a la respectiva función de código C del closure con todos los parámetros en la pila y de recoger su valor de retorno.

glib-genmarshal toma como entrada una lista de marshallers a generar. La lista de marshallers se lee ya sea de archivos pasados como argumentos adicionales en la línea de comandos; o de la entrada estándar, usando - como archivo de entrada.

FORMATO DE LA LISTA DE MARSHALLERS

Las listas de marshallers se procesan línea por línea; una línea puede contener un comentario en la forma de:

# este es un comentario

o una especificación de marshaller en la forma de:

RTYPE:PTYPE
RTYPE:PTYPE,PTYPE
RTYPE:PTYPE,PTYPE,PTYPE
…

La RTYPE parte especifica el tipo de retorno del callback y las PTYPE instancias a la derecha de los dos puntos especifican la lista de parámetros del callback, excepto el primer y el último argumentos que siempre son punteros.

TIPOS DE PARÁMETRO

Actualmente, se soportan los siguientes tipos:

VOID

Indica que no hay tipo de retorno, o que no hay parámetros extra. Si VOID se usa como lista de parámetros, no pueden estar presentes parámetros adicionales.

BOOLEAN

Para tipos booleanos (gboolean).

CHAR

Para tipos de caracteres con signo (gchar).

UCHAR

Para tipos de caracteres sin signo (guchar).

INT

Para tipos de enteros con signo (gint).

UINT

Para tipos de enteros sin signo (guint).

LONG

Para tipos de enteros largos con signo (glong).

ULONG

Para tipos de enteros largos sin signo (gulong).

INT64

Para tipos de enteros de 64 bits con signo (gint64).

UINT64

Para tipos de enteros de 64 bits sin signo (guint64).

ENUM

Para tipos de enumeración (gint).

FLAGS

Para tipos de enumeración de banderas (guint).

FLOAT

Para tipos de punto flotante de precisión simple (gfloat).

DOUBLE

Para tipos de punto flotante de doble precisión (gdouble).

STRING

Para tipos de cadena de caracteres (gchar*).

BOXED

Para tipos empaquetados (anónimos pero con conteo de referencias) (GBoxed*).

PARAM

Para GParamSpec o tipos derivados (GParamSpec*).

POINTER

Para tipos de puntero anónimos (gpointer).

OBJECT

Para GObject o tipos derivados (GObject*).

VARIANT

Para GVariant tipos (GVariant*).

NONE

Alias obsoleto para VOID.

BOOL

Alias obsoleto para BOOLEAN.

OPCIONES

--header

Genera el contenido del archivo de cabecera de los marshallers. Esta opción es mutuamente exclusiva con la --body opción.

--body

Genera el contenido del archivo de código C de los marshallers. Esta opción es mutuamente exclusiva con la --header opción.

--prefix <PREFIJO>

Especifica el prefijo del marshaller. El prefijo por defecto es g_cclosure_user_marshal.

--skip-source

Omite las notas de ubicación del origen en los comentarios generados.

--stdinc

Usa los marshallers estándar de la biblioteca GObject, e incluye glib-object.h en los archivos de cabecera generados. Esta opción es mutuamente exclusiva con la --nostdinc opción.

--nostdinc

No usa los marshallers estándar de la biblioteca GObject, y omite la directiva de inclusión glib-object.h en los archivos de cabecera generados. Esta opción es mutuamente exclusiva con la --stdinc opción.

--internal

Marca las funciones generadas como internas, usando G_GNUC_INTERNAL.

-valist-marshallers

Genera marshallers valist , para usar con g_signal_set_va_marshaller().

-v, --version

Imprime la información de versión y sale.

--g-fatal-warnings

Hace que las advertencias sean fatales. Es decir, sale inmediatamente una vez que ocurre una advertencia.

-h, --help

Imprime una ayuda breve y sale.

--output <ARCHIVO>

Escribe la salida en ARCHIVO en lugar de la salida estándar.

--prototypes

Genera prototipos de función antes de la definición de la función en el archivo fuente C, para evitar una missing-prototypes advertencia del compilador. Esta opción solo es útil cuando se usa la --body opción.

--pragma-once

Usa el pragma once en lugar de un guard de cabecera de estilo antiguo al generar el archivo de cabecera C. Esta opción solo es útil cuando se usa la --header opción.

--include-header <CABECERA>

Añade una directiva #include para el archivo dado en el archivo fuente C. Esta opción solo es útil cuando se usa la --body opción.

-D <SÍMBOLO>[=<VALOR>]

Añade una directiva de preprocesador C #define para SÍMBOLO y su VALORdado, o "1" si el valor no está establecido. Puedes usar esta opción varias veces; si lo haces, todos los símbolos se definirán en el mismo orden dado en la línea de comandos, antes de los símbolos indefinidos usando la opción -U . Esta opción solo es útil cuando se usa la --body opción.

-U <SÍMBOLO>

Añade una directiva de preprocesador C #undef para indefinir el SÍMBOLOdado. Puedes usar esta opción varias veces; si lo haces, todos los símbolos se indefinirán en el mismo orden dado en la línea de comandos, después de los símbolos definidos usando la opción -D . Esta opción solo es útil cuando se usa la --body opción.

--quiet

Minimiza la salida de glib-genmarshal, mediante la impresión de solo advertencias y errores. Esta opción es mutuamente exclusiva con la --verbose opción.

--verbose

Aumenta el nivel de detalle de glib-genmarshal, mediante la impresión de información de depuración. Esta opción es mutuamente exclusiva con la --quiet opción.

USO DE GLIB-GENMARSHAL CON MESON

Meson admite la generación de marshallers de clausura usando glib-genmarshal de forma nativa en su gnome módulo.

En su meson.build archivo normalmente llamará al gnome.genmarshal() método con la lista de fuentes de los marshallers a generar:

gnome = import('gnome')
marshal_files = gnome.genmarshal('marshal',
  sources: 'marshal.list',
  internal: true,
)

El marshal_files variable contendrá un array de dos elementos en el siguiente orden:

  • un objetivo de compilación para el archivo fuente
  • un objetivo de compilación para el archivo de cabecera

Debería usar los objetos devueltos para proporcionar una dependencia en todos los demás objetivos de compilación que referencien el archivo fuente o de cabecera; por ejemplo, si está usando la fuente para compilar una biblioteca:

mainlib = library('project',
  sources: project_sources + marshal_files,
  …
)

Adicionalmente, si está incluyendo el archivo de cabecera generado dentro de un objetivo de compilación que depende de la biblioteca que acaba de compilar, debe asegurarse de que la dependencia interna incluya el archivo de cabecera generado como archivo fuente requerido:

mainlib_dep = declare_dependency(sources: marshal_files[1], link_with: mainlib)

No debe incluir también el archivo fuente generado, de lo contrario se compilará por separado para cada objetivo que dependa de él, causando fallos de compilación. Para saber más sobre por qué todo esto es necesario, por favor consulte la entrada correspondiente en las preguntas frecuentes de Meson https://mesonbuild.com/FAQ.html#how-do-i-tell-meson-that-my-sources-use-generated-headers.

Para más información sobre cómo usar el método, consulte la documentación de Meson https://mesonbuild.com/Gnome-module.html#gnomegenmarshal para gnome.genmarshal().

USO DE GLIB-GENMARSHAL CON AUTOTOOLS

Para usar glib-genmarshal en su proyecto cuando use Autotools como sistema de compilación, primero necesitará modificar su configure.ac archivo para asegurarse de encontrar el comando apropiado usando pkg-config, de manera similar a como descubre los flags del compilador y enlazador para GLib:

PKG_PROG_PKG_CONFIG([0.28])
PKG_CHECK_VAR([GLIB_GENMARSHAL], [glib-2.0], [glib_genmarshal])

En su Makefile.am archivo normalmente necesitará reglas muy simples para generar los archivos C necesarios para la compilación:

marshal.h: marshal.list
        $(AM_V_GEN)$(GLIB_GENMARSHAL) \
                --header \
                --output=$@ \
                $<
marshal.c: marshal.list marshal.h
        $(AM_V_GEN)$(GLIB_GENMARSHAL) \
                --include-header=marshal.h \
                --body \
                --output=$@ \
                $<
BUILT_SOURCES += marshal.h marshal.c
CLEANFILES += marshal.h marshal.c
EXTRA_DIST += marshal.list

En el ejemplo de arriba, la primera regla genera el archivo de cabecera y depende de un marshal.list archivo para regenerar el resultado en caso de que la lista de marshallers sea actualizada. La segunda regla genera el archivo fuente para el mismo marshal.list, e incluye el archivo generado por la regla de cabecera.

EJEMPLO

Para generar marshallers para las siguientes funciones de retorno de llamada:

void   foo (gpointer data1,
            gpointer data2);
void   bar (gpointer data1,
            gint     param1,
            gpointer data2);
gfloat baz (gpointer data1,
            gboolean param1,
            guchar   param2,
            gpointer data2);

El marshaller.list archivo tiene que verse así:

VOID:VOID
VOID:INT
FLOAT:BOOLEAN,UCHAR

y llama a glib-genmarshal así:

glib-genmarshal --header marshaller.list > marshaller.h
glib-genmarshal --body marshaller.list > marshaller.c

Los marshallers generados tienen los argumentos codificados en su nombre de función. Para esta lista en particular, son:

g_cclosure_user_marshal_VOID__VOID(...),
g_cclosure_user_marshal_VOID__INT(...),
g_cclosure_user_marshal_FLOAT__BOOLEAN_UCHAR(...).

Pueden usarse directamente para GClosures o pasarse como el GSignalCMarshaller c_marshaller argumento al crear señales:

GClosure *cc_foo, *cc_bar, *cc_baz;
cc_foo = g_cclosure_new (NULL, foo, NULL);
g_closure_set_marshal (cc_foo, g_cclosure_user_marshal_VOID__VOID);
cc_bar = g_cclosure_new (NULL, bar, NULL);
g_closure_set_marshal (cc_bar, g_cclosure_user_marshal_VOID__INT);
cc_baz = g_cclosure_new (NULL, baz, NULL);
g_closure_set_marshal (cc_baz, g_cclosure_user_marshal_FLOAT__BOOLEAN_UCHAR);
