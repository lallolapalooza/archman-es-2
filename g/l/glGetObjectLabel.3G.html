NOMBRE

glGetObjectLabel - recupera la etiqueta de un objeto con nombre identificado dentro de un espacio de nombres

ESPECIFICACIÓN C

void glGetObjectLabel(GLenum identifier, GLuint name, GLsizei bufSize, GLsizei * length, char * label);

PARÁMETROS

identifier

El espacio de nombres del cual se asigna el nombre del objeto.

name

El nombre del objeto cuya etiqueta se va a recuperar.

bufSize

La longitud del búfer cuya dirección está en label.

length

La dirección de una variable para recibir la longitud de la etiqueta del objeto.

label

La dirección de una cadena que recibirá la etiqueta del objeto.

DESCRIPCIÓN

glGetObjectLabel recupera la etiqueta del objeto identificado por name dentro del espacio de nombres dado por identifier. identifier debe ser uno de GL_BUFFER, GL_SHADER, GL_PROGRAM, GL_VERTEX_ARRAY, GL_QUERY, GL_PROGRAM_PIPELINE, GL_TRANSFORM_FEEDBACK, GL_SAMPLER, GL_TEXTURE, GL_RENDERBUFFER, GL_FRAMEBUFFER, para indicar el espacio de nombres que contiene los nombres de búferes, sombreadores, programas, objetos de array de vértices, objetos de consulta, pipelines de programas, objetos de feedback de transformación, samplers, texturas, búferes de renderizado y búferes de fotogramas, respectivamente.

label es la dirección de una cadena que se utilizará para almacenar la etiqueta del objeto. bufSize especifica el número de caracteres en el array identificado por label. length contiene la dirección de una variable que recibirá el número de caracteres en la etiqueta del objeto. Si length es NULL, entonces se ignora y no se escriben datos. De manera similar, si label es NULL, o si bufSize es cero, entonces no se escriben datos en label.

ERRORES

GL_INVALID_ENUM se genera si identifier no es uno de los tipos de objeto aceptados.

GL_INVALID_OPERATION se genera si name no es el nombre de un objeto existente del tipo especificado por identifier.

GL_INVALID_VALUE se genera si bufSize es cero.

Si no es NULL, length y label deben ser direcciones a las que el cliente tenga acceso de escritura; de lo contrario, podría producirse un comportamiento indefinido, incluida la terminación del proceso.

ASOCIADOS GETS

glGet() con el argumento GL_MAX_LABEL_LENGTH.
