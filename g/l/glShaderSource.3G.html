NOMBRE

glShaderSource - Reemplaza el código fuente en un objeto de shader

ESPECIFICACIÓN C

void glShaderSource(GLuint shader, GLsizei count, const GLchar **string, const GLint *length);

PARÁMETROS

shader

Especifica el manejador del objeto de shader cuyo código fuente se va a reemplazar.

count

Especifica el número de elementos en los arrays string y length.

string

Especifica un array de punteros a cadenas que contienen el código fuente a cargar en el shader.

length

Especifica un array de longitudes de cadena.

DESCRIPCIÓN

glShaderSource establece el código fuente en shader al código fuente en el array de cadenas especificado por string. Cualquier código fuente almacenado previamente en el objeto de shader se reemplaza completamente. El número de cadenas en el array se especifica mediante count. Si length es NULL, se asume que cada cadena termina en nulo. Si length es un valor distinto de NULL, apunta a un array que contiene una longitud de cadena para cada uno de los elementos correspondientes de string. Cada elemento en el array length puede contener la longitud de la cadena correspondiente (el carácter nulo no se cuenta como parte de la longitud de la cadena) o un valor menor que 0 para indicar que la cadena termina en nulo. Los códigos fuente no se escanean ni se analizan en este momento; simplemente se copian en el objeto de shader especificado.

NOTAS

OpenGL copia las cadenas de código fuente del shader cuando se llama a glShaderSource, por lo que una aplicación puede liberar su copia de las cadenas de código fuente inmediatamente después de que la función regrese.

ERRORES

Se genera GL_INVALID_VALUE si shader no es un valor generado por OpenGL.

Se genera GL_INVALID_OPERATION si shader no es un objeto de shader.

Se genera GL_INVALID_VALUE si count es menor que 0.

GETS ASOCIADOS

glGetShader() con los argumentos shader y GL_SHADER_SOURCE_LENGTH

glGetShaderSource() con el argumento shader

glIsShader()
