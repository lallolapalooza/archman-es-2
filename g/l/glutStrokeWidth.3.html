glutStrokeWidth(3)

Paquete: freeglut

Licencias: X11

glutStrokeWidth(3) freeglut glutStrokeWidth(3)

NOMBRE

glutStrokeWidthf, glutStrokeWidth - devuelve el ancho de un carácter de trazo.
glutStrokeLengthf, glutStrokeLength - devuelve la longitud de una cadena de fuente de trazo.

SINTAXIS

float glutStrokeWidthf(void *font, int character);
float glutStrokeLengthf(void *font, const unsigned char *string);
Interfaces obsoletas
int glutStrokeWidth(void *font, int character);
int glutStrokeLength(void *font, const unsigned char *string);

ARGUMENTOS

fuente
Fuente de trazo a usar. Para valores válidos, ver la descripción de glutStrokeWidth.
carácter
Carácter del que se devolverá el ancho (no limitado a 8 bits).
cadena
Cadena de texto (caracteres de 8 bits), terminada en nulo.

DESCRIPCIÓN

glutStrokeWidthf devuelve el ancho en unidades de modelado de un carácter de trazo en una fuente de trazo compatible. Si bien el ancho de los caracteres en una fuente puede variar (aunque las fuentes de ancho fijo no varían), las características de altura máxima de una fuente particular son fijas.

glutStrokeLengthf devuelve la longitud en unidades de modelado de una cadena (caracteres de 8 bits). Esta longitud es equivalente a sumar todos los anchos devueltos por glutStrokeWidthf para cada carácter de la cadena.

BUGS

Las rutinas obsoletas glutStrokeWidth y glutStrokeLength devuelven un entero en lugar de un flotante. Los programas GLUT más nuevos deberían usar las rutinas más nuevas que devuelven flotantes, glutStrokeWidthf y glutStrokeLengthf. Tenga en cuenta que estas rutinas más nuevas no existen en implementaciones anteriores a GLUT 3.8. Además, la rutina glutStrokeLength sumaba anchos de caracteres enteros, por lo que subestimaba la longitud de las cadenas antes de GLUT 3.8, pero la implementación de glutStrokeLength en GLUT 3.8 y posteriores suma los anchos de caracteres para las cadenas en un flotante (aunque glutStrokeLength todavía devuelve un entero).
