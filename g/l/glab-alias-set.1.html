NOMBRE

glab-alias-set - Establece un alias para un comando más largo.

SINOPSIS

glab alias set '' [flags]

DESCRIPCIÓN

Declara una palabra como alias para un comando más largo.

Tu expansión puede incluir argumentos y flags. Si tu expansión incluye marcadores de posición de argumentos como $1 o $2, cualquier argumento adicional que siga a la invocación de un alias se insertará apropiadamente.

Especifica --shell en tu alias para ejecutarlo a través de sh, un conversor de shell. La conversión de shell te permite componer comandos con | o redirigir con >, con las siguientes advertencias:

  • Cualquier argumento adicional que siga al alias no se pasa a los argumentos de la expresión expandida por defecto.
  • Debes aceptar explícitamente los argumentos usando $1, $2, y así sucesivamente.
  • Usa $@ para aceptar todos los argumentos.

Solo para usuarios de Windows:

  • En Windows, los alias de shell se ejecutan con sh instalado por Git Para Windows. Si instalaste Git de alguna otra manera en Windows, los alias de shell podrían no funcionar para ti.
  • Utiliza siempre comillas al definir un comando, como en los ejemplos.

OPCIONES

-s, --shell[=false] Declara un alias que se pasará a través de un intérprete de shell.

OPCIONES HEREDADAS DE COMANDOS PADRE

-h, --help[=false] Muestra la ayuda para este comando.

EJEMPLO

$ glab alias set mrv 'mr view'
$ glab mrv -w 123
> glab mr view -w 123
$ glab alias set createissue 'glab create issue --title "$1"'
$ glab createissue "Mi Incidencia" --description "Algo está roto."
> glab create issue --title "Mi Incidencia" --description "Algo está roto."
$ glab alias set --shell igrep 'glab issue list --assignee="$1" | grep $2'
$ glab igrep user foo
> glab issue list --assignee="user" | grep "foo"
