NOMBRE

glDebugMessageInsert - inyecta un mensaje proporcionado por la aplicación en la cola de mensajes de depuración

ESPECIFICACIÓN C

void glDebugMessageInsert(GLenum source, GLenum type, GLuint id, GLenum severity, GLsizei length, const char *message);

PARÁMETROS

source

La fuente del mensaje de depuración a insertar.

type

El tipo de inserción del mensaje de depuración.

id

El identificador proporcionado por el usuario del mensaje a insertar.

severity

La severidad de los mensajes de depuración a insertar.

length

La longitud de la cadena contenida en el array de caracteres cuya dirección se da por message.

message

La dirección de un array de caracteres que contiene el mensaje a insertar.

DESCRIPCIÓN

glDebugMessageInsert inserta un mensaje proporcionado por el usuario en la cola de salida de depuración. source especifica la fuente que se utilizará para clasificar el mensaje y debe ser GL_DEBUG_SOURCE_APPLICATION o GL_DEBUG_SOURCE_THIRD_PARTY. Todas las demás fuentes están reservadas para uso de la implementación de GL. type indica el tipo de mensaje a insertar y puede ser uno de GL_DEBUG_TYPE_ERROR, GL_DEBUG_TYPE_DEPRECATED_BEHAVIOR, GL_DEBUG_TYPE_UNDEFINED_BEHAVIOR, GL_DEBUG_TYPE_PORTABILITY, GL_DEBUG_TYPE_PERFORMANCE, GL_DEBUG_TYPE_MARKER, GL_DEBUG_TYPE_PUSH_GROUP, GL_DEBUG_TYPE_POP_GROUP o GL_DEBUG_TYPE_OTHER. severity indica la severidad del mensaje y puede ser GL_DEBUG_SEVERITY_LOW, GL_DEBUG_SEVERITY_MEDIUM, GL_DEBUG_SEVERITY_HIGH o GL_DEBUG_SEVERITY_NOTIFICATION. id está disponible para uso definido por la aplicación y puede ser cualquier valor. Este valor se registrará y se utilizará para identificar el mensaje.

length contiene un recuento de los caracteres en el array de caracteres cuya dirección se indica en message. Si length es negativo, entonces message se trata como una cadena terminada en null. La longitud del mensaje, ya sea especificada explícitamente o implícitamente, debe ser menor o igual que la constante definida por la implementación GL_MAX_DEBUG_MESSAGE_LENGTH.

NOTAS

GL_DEBUG_TYPE_MARKER, GL_DEBUG_TYPE_PUSH_GROUP, GL_DEBUG_TYPE_POP_GROUP y GL_DEBUG_SEVERITY_NOTIFICATION solo están disponibles si la versión de GL es 4.3 o superior.

ERRORES

Se genera GL_INVALID_ENUM si alguno de source, type o severity no es uno de los tipos de interfaz aceptados.

Se genera GL_INVALID_VALUE si la longitud del mensaje es mayor que el valor de GL_MAX_DEBUG_MESSAGE_LENGTH.
