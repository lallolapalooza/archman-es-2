NOMBRE

glab-repo-fork - Crear una bifurcación (fork) de un repositorio de GitLab.

SINOPSIS

glab repo fork [flags]

DESCRIPCIÓN

Crear una bifurcación (fork) de un repositorio de GitLab.

OPCIONES

-c, --clone[=false] Clonar la bifurcación. Opciones: true, false.

-n, --name="" El nombre asignado al nuevo proyecto después de la bifurcación.

-p, --path="" La ruta asignada al nuevo proyecto después de la bifurcación.

--remote[=false] Añadir un remoto para la bifurcación. Opciones: true, false.

OPCIONES HEREDADAS DE COMANDOS PADRE

-h, --help[=false] Mostrar ayuda para este comando.

EJEMPLO

$ glab repo fork
$ glab repo fork namespace/repo
$ glab repo fork namespace/repo --clone
