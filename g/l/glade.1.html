GLADE(1) Comandos de usuario GLADE(1)

NOMBRE

glade - Crear interfaces de usuario GTK+

SINOPSIS

glade [OPCIÓN...] [ARCHIVO...]

DESCRIPCIÓN

glade es una herramienta para crear o editar interfaces de usuario para aplicaciones GTK+ o GNOME. Guarda las descripciones de la interfaz de usuario en archivos XML que pueden ser leídos por la API GtkBuilder, que forma parte de GTK+.

OPCIONES

Se pueden especificar las siguientes opciones:

-h, --help

Mostrar opciones de ayuda.

--help-all

Mostrar todas las opciones de ayuda.

--help-debug

Mostrar opciones de depuración de Glade.

--help-gtk

Mostrar opciones de GTK+.

--version

Mostrar información de la versión y salir.

--without-devhelp

Deshabilitar la integración con devhelp.

--display=PANTALLA

Pantalla X a utilizar.
