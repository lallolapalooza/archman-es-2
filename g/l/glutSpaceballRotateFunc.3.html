NOMBRE

glutSpaceballRotateFunc - establece la devolución de llamada de rotación del Spaceball para la ventana actual.

SINTAXIS

void glutSpaceballRotateFunc(void (*func)(int x, int y, int z));

ARGUMENTOS

func
La nueva función de devolución de llamada de rotación del Spaceball.

DESCRIPCIÓN

glutSpaceballRotateFunc establece la devolución de llamada de rotación del Spaceball para la ventana actual. La devolución de llamada de rotación del Spaceball para una ventana se llama cuando la ventana tiene el foco de entrada del Spaceball (normalmente, cuando el ratón está en la ventana) y el usuario genera rotaciones del Spaceball. Los parámetros de devolución de llamada x, y, y z indican la rotación a lo largo de los ejes X, Y y Z. Los parámetros de devolución de llamada se normalizan para estar dentro del rango de -1800 a 1800 inclusive.

Registrar una devolución de llamada de rotación del Spaceball cuando no se dispone de un dispositivo Spaceball es ineficaz y no es un error. En este caso, no se generarán devoluciones de llamada de rotación del Spaceball.

Pasar NULL a glutSpaceballRotateFunc deshabilita la generación de devoluciones de llamada de rotación del Spaceball. Cuando se crea una nueva ventana, inicialmente no se registra ninguna devolución de llamada de rotación del Spaceball.
