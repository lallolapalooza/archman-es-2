NAME

glProgramUniformMatrix2fv — set uniform matrix values

C SPECIFICATION

void glProgramUniformMatrix2fv( GLuint program,
                                GLint location,
                                GLsizei count,
                                GLboolean transpose,
                                const GLfloat *value );

PARAMETERS

program
The target shader program.
location
The location of the uniform variable to be modified.
count
The number of matrices to be modified.
transpose
For each matrix supplied in value, whether to transpose the matrix.
value
A pointer to the first element of an array of floating-point values that will reside in the specified uniform variable.

DESCRIPTION

glProgramUniformMatrix2fv, glProgramUniformMatrix3fv, and glProgramUniformMatrix4fv set the value of a uniform matrix variable in one or more shader programs. The commands differ in the size of the matrices they set: glProgramUniformMatrix2fv sets 2x2 matrices, glProgramUniformMatrix3fv sets 3x3 matrices, and glProgramUniformMatrix4fv sets 4x4 matrices.

The program argument specifies the target shader program. The location argument specifies the uniform variable location.

The count argument indicates the number of individual matrices whose values are to be modified. All matrices must be of the same size.

The transpose argument indicates whether to transpose the matrix. If transpose is GL_TRUE, all matrices in value will be transposed before being loaded into the uniform variable. If transpose is GL_FALSE, the matrices will be loaded as is.

The value argument is a pointer to the first element of an array of count matrices to be loaded into the uniform variable specified by location. Each matrix is specified in column-major order. For a 2x2 matrix, 4 floating-point values are required for each matrix. For a 3x3 matrix, 9 floating-point values are required for each matrix. For a 4x4 matrix, 16 floating-point values are required for each matrix.

For a uniform variable named name, location can be found using glGetUniformLocation(). If location is equal to -1, the uniform variable will not be accessed and the function will not update the specified uniform variable. This may happen when the uniform variable is unused in its shader.

These functions do not reset the current program.

The transpose parameter is ignored for uniform variables that are not matrices.

NOTES

When using glProgramUniform* functions, the program object must be active. glUseProgram() must be called first.

When matrices are specified using glProgramUniform* functions, the matrices are specified in column-major order. Thus, for a 2x2 matrix, the elements are arranged as:

    m00 m10
    m01 m11
which means value[0] through value[3] are populated as:

    value[0] = m00
    value[1] = m01
    value[2] = m10
    value[3] = m11

ERRORS

There are no error codes generated by these functions.
