NOMBRE

glPrimitiveRestartIndex - especificar el índice de reinicio de primitiva

ESPECIFICACIÓN C

void glPrimitiveRestartIndex(GLuint index);

PARÁMETROS

index

Especifica el valor que se interpretará como el índice de reinicio de primitiva.

DESCRIPCIÓN

glPrimitiveRestartIndex especifica un elemento del array de vértices que se trata de forma especial cuando se habilita el reinicio de primitivas. Esto se conoce como el índice de reinicio de primitiva.

Cuando uno de los comandos Draw* transfiere un conjunto de elementos de array de atributos genéricos a la GL, si el índice dentro de los arrays de vértices correspondiente a ese conjunto es igual al índice de reinicio de primitiva, la GL no procesa esos elementos como un vértice. En su lugar, es como si el comando de dibujo terminara con la transferencia inmediatamente anterior, y otro comando de dibujo se iniciara inmediatamente con los mismos parámetros, pero transfiriendo solo el elemento inmediatamente siguiente hasta el final de los elementos especificados originalmente.

Cuando se utiliza glDrawElementsBaseVertex(), glDrawElementsInstancedBaseVertex() o glMultiDrawElementsBaseVertex(), la comparación de reinicio de primitiva ocurre antes de que se agregue el desplazamiento basevertex al índice del array.

NOTAS

glPrimitiveRestartIndex solo está disponible si la versión de GL es 3.1 o superior.
