DESCRIPCIÓ

N

glBufferSubData y glNamedBufferSubData redefinen algunos o todos los datos del almacén para el objeto buffer especificado. Los datos que comienzan en el desplazamiento de byte offset y se extienden durante size bytes se copian al almacén de datos desde la memoria apuntada por data. offset y size deben definir un rango que se encuentre complet

amente dentro del almacén d
e datos del objeto buffer.

NOTA

S

Al reemplazar todo el almacén de datos, considere usar glBufferSubData en lugar de recrear completamente el almacén de datos con glBufferData. Esto evita el costo de reasignar el almacén de

datos.

Considere usar múltiples objetos buffer para evitar bloquear el pipeline de renderizado durante las actualizaciones del almacén de datos. Si algún renderizado en el pipeline hace referencia a datos en el objeto buffer que está siendo actualizado por glBufferSubData, especialmente de la región específica que se está actualizando, ese renderizado debe drenarse del pipeline antes de que el almacén de datos pueda ser

actualizado.

Los clientes deben alinear los elementos de datos de manera consistente con los requisitos de la plataforma del cliente, con un requisito adicional de nivel base de que un desplazamiento dentro de un buffer a un dato que comprende $N$ bytes debe ser un múltiplo de

$N$.

El destino GL_ATOMIC_COUNTER_BUFFER está disponible solo si la versión de GL es 4.2 o

superior.

Los destinos GL_DISPATCH_INDIRECT_BUFFER y GL_SHADER_STORAGE_BUFFER están disponibles solo si la versión de GL es 4.3 o

superior.

El destino GL_QUERY_BUFFER está disponible solo

si la versión de GL
es 4.4 o superior.

ERRORE

S

GL_INVALID_ENUM es generado por glBufferSubData si target no es uno de los destinos de buffer

aceptados.

GL_INVALID_OPERATION es generado por glBufferSubData si cero está vinculado a target

.

GL_INVALID_OPERATION es generado por glNamedBufferSubData si buffer no es el nombre de un objeto buffer

existente.

GL_INVALID_VALUE es generado si offset o size es negativo, o si $offset + size$ es mayor que el valor de GL_BUFFER_SIZE para el objeto buffer

especificado.

GL_INVALID_OPERATION es generado si alguna parte del rango especificado del objeto buffer está mapeado con glMapBufferRange() o glMapBuffer(), a menos que haya sido mapeado con el bit GL_MAP_PERSISTENT_BIT establecido en los flags de acceso de glMapBufferRange

.

GL_INVALID_OPERATION es generado si el valor del flag GL_BUFFER_IMMUTABLE_STORAGE del objeto buffer es GL_TRUE y el valor de GL_BUFFER_STORAGE_FLAGS para el objeto buffer no tiene el bit GL_DYNAMIC_STORA

GE_BIT es
tablecido.
