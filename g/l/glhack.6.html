glHack(6) Manual de Juegos glHack(6)

NOMBRE

glhack - Explorando los Laberintos del Peligro

SINOPSIS

glhack [opciones]

glhack -s [opciones]

DESCRIPCIÓN

glHack es un puerto del juego NetHack, usando la aceleración por hardware a través de OpenGL(R) para renderizar la gráfica de teselas 2D. Utiliza LibSDL como biblioteca de vídeo y entrada. También hay un buen soporte para el renderizado por software.

NetHack es un juego tipo Dungeons & Dragons(tm) orientado a la visualización. La estructura estándar de comandos y la visualización tty se asemejan a rogue.

Para empezar, realmente solo necesitas conocer dos comandos. El comando `?' te dará una lista de los comandos disponibles (así como otra información) y el comando `/' identificará las cosas que ves en la pantalla.

Para ganar el juego (a diferencia de simplemente jugar para superar las puntuaciones más altas de otras personas) debes localizar el Amuleto de Yendor, que está en algún lugar por debajo del nivel 20 de la mazmorra, y sacarlo. ¡Esta no es una hazaña fácil!

Cuando el juego termina, ya sea por tu muerte, por salir o por escapar de las cuevas, glHack te dará (un fragmento de) la lista de los mejores puntuadores. La puntuación se basa en muchos aspectos de tu comportamiento, pero se obtiene una estimación aproximada sumando la cantidad de oro que has encontrado en la cueva más cuatro veces tu experiencia (real). Las piedras preciosas pueden valer mucho oro cuando se llevan a la salida. Hay una penalización del 10% por hacerte matar.

OPCIONES DE NETHACK

Estas son las opciones estándar que NetHack soporta.

-u nombrejugador
Esta opción proporciona la respuesta a la pregunta "¿Quién eres?". Anula cualquier nombre de las opciones o del archivo de configuración, las variables de shell USER o LOGNAME, o getlogin(), que de lo contrario se probarán en orden. Si ninguno de estos proporciona un nombre útil, se le pedirá al jugador uno. Los nombres de jugador (en conjunción con los uids) se usan para identificar los archivos de guardado, por lo que puedes tener varias partidas guardadas bajo diferentes nombres. A la inversa, debes usar el nombre de jugador apropiado para restaurar una partida guardada.

Se puede usar un sufijo en el nombrejugador para especificar la profesión, raza, alineación y/o género del personaje. La sintaxis completa del nombrejugador que incluye un sufijo es "nombre-ppp-rrr-aaa-ggg". "ppp" son al menos las primeras tres letras de la profesión (esto también se puede especificar usando la -p opción). "rrr" son al menos las primeras tres letras de la raza del personaje (esto también se puede especificar usando la -r opción). "aaa" son al menos las primeras tres letras de la alineación del personaje, y "ggg" son al menos las primeras tres letras del género del personaje. Cualquiera de las partes del sufijo puede omitirse.

-p profesión
Esto se puede usar para determinar el rol del personaje. Puedes especificar el nombre masculino o femenino para el rol del personaje, o los primeros tres caracteres del rol como una abreviatura. `@' y random también se pueden usar para significar "elegir un rol aleatorio".
-r raza
Del mismo modo, esto se puede usar para solicitar explícitamente que se elija una raza.

Nota: Omitir cualquiera de estas características resultará en que se te pregunte durante el inicio del juego por la información.

-@
Elige todos los atributos (restantes) del personaje aleatoriamente. No afecta a ninguna característica que ya haya sido especificada por otros medios.
-s
Esta opción por sí sola imprimirá la lista de tus puntuaciones en la versión actual. El -s también puede ir seguido de los argumentos -p y -r para imprimir solo las puntuaciones de roles y razas particulares. También puede ir seguido de uno o más nombres de jugador para imprimir las puntuaciones de los jugadores mencionados, por 'all' para imprimir todas las puntuaciones, o por un número para imprimir esa cantidad de las mejores puntuaciones.
-dec y -ibm
Estas opciones de línea de comandos son equivalentes a las decgraphics y ibmgraphics opciones del juego, y se proporcionan puramente por conveniencia en sistemas que soportan múltiples tipos de terminales.
-D o -X
Estas opciones iniciarán el juego en un modo especial de descubrimiento sin puntuación. Si el jugador es el administrador del juego, -D iniciará en modo de depuración (mago) en su lugar.
-n
Esta opción suprime la impresión de cualquier noticia del administrador del juego.
-d
Esta opción normalmente solo es útil para el administrador del juego. Si aparece, debe ser el primer argumento, y proporciona un directorio que servirá como el área de juego. Anula el valor de NETHACKDIR, HACKDIR, o el directorio especificado por el administrador del juego durante la compilación (usualmente /usr/lib/games/glhack). El área de juego debe contener varios archivos auxiliares como archivos de ayuda, la lista de los mejores puntuadores, y un subdirectorio save donde se guardan las partidas.

OPCIONES DE GLHACK

Estas son las opciones de línea de comandos específicas de glHack.

Todas comienzan con un guion doble (`--'). Los valores normalmente se separan de la opción con un espacio, como "--depth 32".

Alternativamente, un valor puede colocarse después de un signo `=' sin ningún espacio, como "--depth=32". Esto debe usarse si el valor comienza con un signo menos (`-'), de lo contrario el número se confundirá con una nueva opción.

Las opciones que toman un valor se muestran aquí con valores de ejemplo.

--mode 640x480
Especifica el modo de vídeo. Normalmente glHack autodetectará el modo, pero usar esta opción lo anulará. El valor por defecto (cuando todo lo demás falla) es 800x600.
--depth 8
Profundidad de vídeo (bits por píxel). Los valores posibles son 15, 16, 24 y 32, y 8 al usar el renderizador por software. El valor por defecto se autodetecta.
--windowed
Jugar dentro de una ventana, en lugar de a pantalla completa.
--gamma=-2
Valor de corrección de gamma. El rango es de -5 a +5, donde los valores positivos hacen la pantalla más brillante, y los negativos la hacen más oscura. Cero es el valor por defecto (sin ajuste).
--tileheight 64
Elige el juego de teselas, que puede ser 16, 32 o 64. El valor por defecto es 32. Para obtener el juego de teselas 3D Isométrico, usa el valor 64.
--fontsize 22
Elige el tamaño de fuente, entre 8, 14, 20 o 22. El valor por defecto es 20. El tamaño dado se usará para todas las ventanas de texto, anulando cualquier configuración de wincap en el archivo de configuración.
--help
Muestra una página de ayuda.
--version
Muestra la versión actual. Esto también se puede hacer dentro del juego usando el comando #version.

ENTORNO

USER o LOGNAME
Tu nombre de inicio de sesión (usado como el nombre del jugador).
HOME
Tu directorio de inicio (usado para encontrar el archivo de configuración).
NETHACKOPTIONS
Cadena que predefine varias opciones estándar de NetHack.
GLHACKOPTIONS
Cadena que predefine varias opciones específicas de glHack.
NETHACKDIR
Directorio del área de juego (ver la opción -d arriba).

Además, SHOPTYPE se usa en el modo de depuración (mago).

SEGURIDAD

glHack se ejecuta con set-gid games. Esto es necesario para crear/modificar los archivos persistentes del juego. En general, los programas set-gid son mucho más seguros que los set-uid programs. An attacker who successfully compromises a set-gid game executable can only mess around with various game data files (typically those in /var/games and /var/lib/games).

Since glHack is based on NetHack 3.4.0, any security issues with NetHack 3.4.0 (past or future) will almost certainly apply to this release of glHack.

Currently there is only one place in the glHack-specific code that creates or writes to a file: the screenshot code. Taking screenshots is restricted to the game administrator (the "wizard" account).

As far as I know, glHack will never execute another program. The following features of the NetHack 3.4.0 codebase which do execute other programs are disabled in glHack's standard (compile-time) configuration: running a compression utility (COMPRESS), running a shell (SHELL), reading mail (MAIL), and running an external pager (TTY code).

FILES

~/.glhackrc
Archivo de configuración de glHack. Consulte la glhackrc(5) página del manual para más información.
/usr/lib/games/glhack
El playground estático. Aquí se almacenan los archivos de solo lectura. Los archivos que se encuentren aquí se marcarán como "(STATIC)" en las entradas siguientes.
/var/lib/games/glhack
El playground variable. Aquí se almacenan los archivos de datos persistentes (lectura/escritura). Estos archivos se marcan como "(VAR)" a continuación.
nhdat (STATIC)
Archivo que contiene todo lo que NetHack necesita para jugar (archivos de niveles, archivos de texto, archivos de ayuda, etc). El formato es DLB (Data LiBrarian) y es específico de NetHack.
license (STATIC)
Reglas que rigen la redistribución.
glhack_recover (STATIC)
Este programa se puede utilizar para recuperar una partida después de que glHack haya fallado (asumiendo que los archivos no estén corruptos). Solo se puede ejecutar como superusuario (root).
gl*.png (STATIC)
Imágenes (fuentes, conjuntos de teselas, etc) utilizadas por glHack.
gl*.lst (STATIC]
Archivos de datos misceláneos (p. ej. información de orientación de las teselas) utilizados por glHack.
record (VAR)
La lista de los mejores puntuadores.
logfile (VAR)
Una lista extendida de las partidas jugadas.
perm (VAR)
Archivo vacío utilizado para fines de bloqueo.
bonDD.nn (VAR)
Archivos bone: descripciones del fantasma y las pertenencias de un aventurero fallecido.
NNNNname.dd (VAR)
Archivos temporales para un usuario que está jugando actualmente a glHack, o después de que glHack haya fallado. La parte `NNNN' es el identificador de usuario numérico, seguido del nombre del jugador.
save/ (VAR)
Un subdirectorio que contiene las partidas guardadas.
