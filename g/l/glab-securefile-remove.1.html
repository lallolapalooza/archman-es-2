NOMBRE

glab-securefile-remove - Eliminar un archivo seguro.

SINOPSIS

glab securefile remove [flags]

DESCRIPCIÓN

Elimina un archivo seguro.

OPCIONES

-y, --yes[=false] Omitir la solicitud de confirmación.

OPCIONES HEREDADAS DE COMANDOS PADRE

-h, --help[=false] Mostrar ayuda para este comando.

-R, --repo="" Seleccionar otro repositorio. Se puede usar el formato PROPIETARIO/REPO o GRUPO/NAMESPACE/REPO. También acepta URL completa o URL de Git.

EJEMPLO

Eliminar un archivo seguro de un proyecto utilizando el ID del archivo.
- glab securefile remove 1
Omitir la solicitud de confirmación y forzar la eliminación.
- glab securefile remove 1 -y
Eliminar un archivo seguro de un proyecto con el alias 'rm'.
- glab securefile rm 1
Eliminar un archivo seguro de un proyecto con el alias 'delete'.
- glab securefile delete 1
