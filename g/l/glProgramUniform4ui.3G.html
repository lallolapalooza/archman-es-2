PARÁMETROS

program

Especifica el manejador del programa que contiene la variable uniforme a modificar.

location

Especifica la ubicación de la variable uniforme a modificar.

count

Para los comandos de vector (glProgramUniform*v), especifica el número de elementos que se van a modificar. Debe ser 1 si la variable uniforme objetivo no es un array y 1 o más si es un array.

Para los comandos de matriz (glProgramUniformMatrix*), especifica el número de matrices que se van a modificar. Debe ser 1 si la variable uniforme objetivo no es un array de matrices y 1 o más si es un array de matrices.

transpose

Para los comandos de matriz (glProgramUniformMatrix*), especifica si se debe transponer la matriz. Si transpose es GL_TRUE, la matriz de 2x2, 2x3, 3x2, 2x4, 4x2, 3x3, 3x4, 4x3 o 4x4 se transpone como se describe en la especificación de OpenGL. Si transpose es GL_FALSE, la matriz se utiliza tal como está.

value

Especifica el puntero a la matriz o arreglo de valores que se van a utilizar para actualizar la variable uniforme especificada.

v0, v1, v2, v3

Especifican los valores que se van a utilizar para actualizar la variable uniforme especificada.

DESCRIPCIÓN

Estas funciones establecen el valor de una variable uniforme numérica dentro de un objeto de programa activo. Las funciones glProgramUniform son similares a las funciones glUniform, pero no requieren que el programa sea activado con glUseProgram antes de llamar a la función. También, si el programa especificado no es el programa activo, las funciones glProgramUniform modificarán el programa especificado, y las funciones glUniform no tienen ningún efecto.

Las funciones glProgramUniform son de la forma glProgramUniformTv, donde T es un número (1 a 4) que indica el número de componentes en el valor a establecer, y donde v es opcional y tiene uno de los siguientes valores: `f` para flotante, `i` para entero con signo, `ui` para entero sin signo, `fv` para un arreglo de flotantes, `iv` para un arreglo de enteros con signo, `uiv` para un arreglo de enteros sin signo, y `Matrix` seguido de las dimensiones de la matriz y `fv` para un arreglo de matrices de flotantes.

Los valores escalares se establecen directamente con glProgramUniform*. Los valores vectoriales se establecen con glProgramUniform*v. Los valores de matriz se establecen con glProgramUniformMatrix*.

Los tipos de datos se mapean de la siguiente manera:

• f (GLfloat)
• i (GLint)
• ui (GLuint)

Los comandos de vector se utilizan para establecer los valores de las variables uniformes que son arrays. El parámetro count especifica cuántos elementos (para escalares) o cuántas matrices (para matrices) se deben actualizar. Si el uniforme no es un array, count debe ser 1.

Los comandos de matriz establecen los valores de las variables uniformes de matriz. El parámetro transpose indica si la matriz debe ser transpuesta antes de ser establecida. Las matrices se almacenan en memoria en orden de columna por defecto, por lo que si las está transponiendo, esto se reflejará en cómo se almacenan los datos en el búfer.

Las variables uniformes `sampler*` no se pueden modificar directamente con estas funciones; deben ser enlazadas a unidades de textura utilizando glUniform.

La llamada a estas funciones provoca errores si program no es un programa válido, o si location no es una ubicación válida para una variable uniforme en el programa especificado, o si el tipo de la variable uniforme no coincide con el tipo de la función llamada.

El comportamiento de estas funciones está definido por el estado del programa activo y los valores de las variables uniformes dentro de ese programa.

NOTAS

Estas funciones están disponibles en la versión 2.0 de OpenGL y posteriores.

NAME

glProgramUniform4ui — set the value of a single unsigned integer uniform variable in an active program object

C SPECIFICATION

#include <GL/glcorearb.h>
void glProgramUniform4ui(
    GLint program,
    GLint location,
    GLuint v0,
    GLuint v1,
    GLuint v2,
    GLuint v3
);
void glProgramUniform4uiv(
    GLint program,
    GLint location,
    const GLuint *value
);

PARAMETERS

program
Specifies the program object containing the uniform variable to be modified.
location
Specifies the integer token for the uniform variable to be modified. The token is obtained by calling glGetUniformLocation.
v0, v1, v2, v3
Specify the new values for the uniform variable.
value
Specifies a pointer to a buffer containing the new values for the uniform variable.

DESCRIPTION

glProgramUniform4ui specifies the value of a single unsigned integer uniform variable within the program object program. This function can only be used to update uniform variables that are active in the specified program object. If the uniform variable is not active, or if program is not an active program, then glProgramUniform4ui and glProgramUniform4uiv do nothing.

glProgramUniform4ui specifies the values of a single unsigned integer uniform variable using four values. glProgramUniform4uiv specifies the values of a single unsigned integer uniform variable using a pointer to an array of four unsigned integers.

The results of glProgramUniform4ui and glProgramUniform4uiv are undefined if the indicated uniform variable does not have type int, ivec2, ivec3, or ivec4.

NOTES

If the indicated uniform variable is not an unsigned integer type, then the results are undefined.

If program is not zero, and is not the name of an object compiled from a program object, then glProgramUniform4ui and glProgramUniform4uiv are rejected and an GL_INVALID_OPERATION error is generated.

Uniform variables can be set at any time. However, if program is part of an active execution list, then modifications to it might not be visible until the next invocation of glDrawArrays, glDrawElements, or other drawing commands.

glProgramUniform4ui is equivalent to calling glUniform4ui after glUseProgram(program), except that glProgramUniform4ui does not change the current program object.

ERRORS

GL_INVALID_OPERATION is generated if program is not zero or the name of an existing program object.

GL_INVALID_OPERATION is generated if location is not a valid uniform location for the specified program object.

GL_INVALID_OPERATION is generated if the type of the uniform variable indicated by location is not an unsigned integer type.
