DESCRIPCIÓ

N

glProgramUniform modifica el valor de una variable uniforme o de una matriz de variables uniformes. La ubicación de la variable uniforme a modificar se especifica mediante location, que debería ser un valor devuelto por glGetUniformLocation(). glProgramUniform opera sobre el objeto de programa especificado por program

.

Los comandos glProgramUniform{1|2|3|4}{f|i|ui} se utilizan para cambiar el valor de la variable uniforme especificada por location usando los valores pasados como argumentos. El número especificado en el comando debe coincidir con el número de componentes en el tipo de datos de la variable uniforme especificada (por ejemplo, 1 para float, int, unsigned int, bool; 2 para vec2, ivec2, uvec2, bvec2, etc.). El sufijo f indica que se están pasando valores de punto flotante; el sufijo i indica que se están pasando valores enteros; el sufijo ui indica que se están pasando valores enteros sin signo, y este tipo también debe coincidir con el tipo de datos de la variable uniforme especificada. Las variantes i de esta función deben utilizarse para proporcionar valores para variables uniformes definidas como int, ivec2, ivec3, ivec4, o matrices de estas. Las variantes ui de esta función deben utilizarse para proporcionar valores para variables uniformes definidas como unsigned int, uvec2, uvec3, uvec4, o matrices de estas. Las variantes f deben utilizarse para proporcionar valores para variables uniformes de tipo float, vec2, vec3, vec4, o matrices de estas. Se puede utilizar cualquiera de las variantes i, ui o f para proporcionar valores para variables uniformes de tipo bool, bvec2, bvec3, bvec4, o matrices de estas. La variable uniforme se establecerá en false si el valor de entrada es 0 o 0.0f, y se establecerá en true en caso

contrario.

Todas las variables uniformes activas definidas en un objeto de programa se inicializan a 0 cuando el objeto de programa se enlaza correctamente. Conservan los valores asignados a ellos por una llamada a glProgramUniform hasta que ocurra la siguiente operación de enlace exitosa en el objeto de programa, cuando se inicializan de nuevo a

0.

Los comandos glProgramUniform{1|2|3|4}{f|i|ui}v se pueden usar para modificar una única variable uniforme o una matriz de variables uniformes. Estos comandos pasan un count y un puntero a los valores a cargar en una variable uniforme o en una matriz de variables uniformes. Se debe usar un count de 1 si se modifica el valor de una sola variable uniforme, y se puede usar un count de 1 o mayor para modificar toda una matriz o parte de una matriz. Al cargar n elementos comenzando en una posición arbitraria m en una matriz de variables uniformes, los elementos m + n - 1 en la matriz serán reemplazados con los nuevos valores. Si m + n - 1 es mayor que el tamaño de la matriz de variables uniformes, los valores de todos los elementos de la matriz más allá del final de la matriz serán ignorados. El número especificado en el nombre del comando indica el número de componentes para cada elemento en value, y debería coincidir con el número de componentes en el tipo de datos de la variable uniforme especificada (por ejemplo, 1 para float, int, bool; 2 para vec2, ivec2, bvec2, etc.). El tipo de datos especificado en el nombre del comando debe coincidir con el tipo de datos para la variable uniforme especificada como se describió anteriormente para glProgramUniform{1|2|3|

4}{f|i|ui}.

Para matrices de variables uniformes, cada elemento de la matriz se considera que es del tipo indicado en el nombre del comando (por ejemplo, glProgramUniform3f o glProgramUniform3fv se pueden usar para cargar una matriz de variables uniformes de tipo vec3). El número de elementos de la matriz de variables uniformes a modificar se especifica mediante coun

t

Los comandos glProgramUniformMatrix{2|3|4|2x3|3x2|2x4|4x2|3x4|4x3}fv se utilizan para modificar una matriz o una matriz de matrices. Los números en el nombre del comando se interpretan como la dimensionalidad de la matriz. El número 2 indica una matriz de 2 × 2 (es decir, 4 valores), el número 3 indica una matriz de 3 × 3 (es decir, 9 valores), y el número 4 indica una matriz de 4 × 4 (es decir, 16 valores). La dimensionalidad de la matriz no cuadrada es explícita, con el primer número representando el número de columnas y el segundo número representando el número de filas. Por ejemplo, 2x4 indica una matriz de 2 × 4 con 2 columnas y 4 filas (es decir, 8 valores). Si transpose es GL_FALSE, se asume que cada matriz se proporciona en orden de columnas. Si transpose es GL_TRUE, se asume que cada matriz se proporciona en orden de filas. El argumento count indica el número de matrices a pasar. Se debe usar un count de 1 si se modifica el

valor de una sola matriz, y se puede usar un count m
ayor que 1 para modificar una matriz de matrices.

NOTA

S

glProgramUniform1i y glProgramUniform1iv son las únicas dos funciones que se pueden usar para cargar variables uniformes definidas como tipos sampler. Cargar samplers con cualquier otra función resultará en un error GL_INVALID_OPERATION

.

Si count es mayor que 1 y la variable uniforme indicada no es una matriz, se genera un error GL_INVALID_OPERATION y la variable uniforme especificada permanecerá sin

cambios.

Aparte de las excepciones anteriores, si el tipo y el tamaño de la variable uniforme tal como se define en el shader no coinciden con el tipo y el tamaño especificados en el nombre del comando utilizado para cargar su valor, se generará un error GL_INVALID_OPERATION y la variable uniforme especificada permanecerá sin

cambios.

Si location es un valor distinto de -1 y no representa una ubicación de variable uniforme válida dentro de program, se generará un error, y no se harán cambios en el almacenamiento de la variable uniforme de program. Si location es igual a -1, los datos pasados serán ignorados silenc

iosamente y la variable uniforme
especificada no será cambiada.

NAME

glProgramUniformMatrix2x4fv — set the value of a uniform variable for a program object

C SPECIFICATION

void glProgramUniformMatrix2x4fv( GLuint
       program, GLint location, GLsizei count, GLboolean transpose, const GLfloat *value );

PARAMETERS

program
Specifies the program object to which the uniform variables belong.
location
Specifies the location of the uniform variable to be modified.
count
Specifies the number of variables to be updated.
transpose
Specifies whether to transpose the matrix when it is stored in the GL.
value
Specifies a pointer to an array of count values that will be used to update the specified uniform block members.

DESCRIPTION

Uniform variables are the mechanism by which user-created programs can receive data from applications. These functions, collectively called “program uniform commands”, set the values of uniform variables that are available to a program object.

These commands can be called in the same manner as glUniform(3G) can be called, but they operate on uniform variables that are part of program objects, and they do not affect the current program object.

The location of a uniform variable within a program object is initially unknown. The application must first query the location of the uniform variable by calling glGetUniformLocation(3G). This query returns a negative value if name string does not correspond to an active uniform variable in the program object. Otherwise, it returns the symbolic uniform location of the specified uniform variable.

Once the application has the location of the uniform variable, it can call one of the program uniform commands to set the uniform variable’s value.

If the uniform variable is not of type matrxcf, then glProgramUniformMatrix2x4fv is equivalent to calling glUniform(3G) with the appropriate glUniform...v command.

If the uniform variable is of type matrxcf, then glProgramUniformMatrix2x4fv sets the value of the named uniform variable to value.

The transpose parameter specifies whether the matrix is transposed when it is set. If transpose is GL_TRUE, then the data in value is assumed to be in column-major order and is transposed into row-major order before being stored. If transpose is GL_FALSE, then the data in value is assumed to be in row-major order and is stored directly.

The uniform variable referred to by location must be either an array of uniforms, or a single uniform variable. The count parameter indicates the number of elements or matrices to be updated. It must be one if the uniform variable is not an array. If the uniform variable is an array, count must be greater than or equal to one, and it indicates the number of matrices to be updated.

The value parameter points to an array of count matrices, each of size 2x4.

NOTES

If program is not zero, it is the name of the program object of which the uniform variables are a part. If program is zero, the uniform variable is assumed to be a current uniform of the active program.

The value of a uniform variable is not remembered across glLinkProgram(3G) or other program validation steps. Applications should update uniform values in response to events that might cause validation to fail, or before rendering geometry.

The uniform variable can be updated by any of the glProgramUniform commands. However, the data type of the uniform variable must match the data type expected by the command. For example, calling glProgramUniformMatrix2x4fv for a uniform variable of type int is undefined.

The location must be a valid uniform location for the specified program. Otherwise, the command is ignored.

The program parameter is ignored by these commands. Uniforms are always updated in the currently active program.

ERRORS

GL_INVALID_OPERATION is generated if program is not zero and is not the name of a program object.

GL_INVALID_OPERATION is generated if program is not zero and is not zero or the name of an active program object.

GL_INVALID_OPERATION is generated if the uniform variable indicated by location is of a type that cannot be set by glProgramUniformMatrix2x4fv.

GL_INVALID_OPERATION is generated if program is zero and the active program object does not have a uniform variable with the specified location.

GL_INVALID_VALUE is generated if location is not a valid uniform location.

GL_INVALID_VALUE is generated if count is less than zero.
