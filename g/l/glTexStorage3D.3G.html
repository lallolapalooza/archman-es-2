NOMBRE

glTexStorage3D, glTextureStorage3D - especificar simultáneamente el almacenamiento para todos los niveles de una textura de arreglo tridimensional, bidimensional o de mapa de cubos

C ESPECIFICACIÓN

void glTexStorage3D(GLenum target, GLsizei levels, GLenum internalformat, GLsizei width, GLsizei height, GLsizei depth);

void glTextureStorage3D(GLuint texture, GLsizei levels, GLenum internalformat, GLsizei width, GLsizei height, GLsizei depth);

PARÁMETROS

target

Especifica el destino al que se vincula el objeto de textura para glTexStorage3D. Debe ser uno de GL_TEXTURE_3D, GL_TEXTURE_2D_ARRAY, GL_TEXTURE_CUBE_MAP_ARRAY, GL_PROXY_TEXTURE_3D, GL_PROXY_TEXTURE_2D_ARRAY o GL_PROXY_TEXTURE_CUBE_MAP_ARRAY.

texture

Especifica el nombre del objeto de textura para glTextureStorage3D. El destino efectivo de texture debe ser uno de los valores de destino no proxy válidos anteriores.

levels

Especifica el número de niveles de textura.

internalformat

Especifica el formato interno con tamaño que se utilizará para almacenar los datos de la imagen de la textura.

width

Especifica el ancho de la textura, en texels.

height

Especifica el alto de la textura, en texels.

depth

Especifica la profundidad de la textura, en texels.

DESCRIPCIÓN

glTexStorage3D y glTextureStorage3D especifican los requisitos de almacenamiento para todos los niveles de una textura tridimensional, de arreglo bidimensional o de mapa de cubos de forma simultánea. Una vez que una textura se especifica con este comando, el formato y las dimensiones de todos los niveles se vuelven inmutables, a menos que sea una textura proxy. El contenido de la imagen aún puede ser modificado, sin embargo, sus requisitos de almacenamiento no pueden cambiar. Dicha textura se denomina textura de formato inmutable.

El comportamiento de glTexStorage3D depende del parámetro target. Cuando target es GL_TEXTURE_3D o GL_PROXY_TEXTURE_3D, llamar a glTexStorage3D es equivalente, suponiendo que no se generen errores, a ejecutar el siguiente pseudocódigo:

    para (i = 0; i < levels; i++) {
        glTexImage3D(target, i, internalformat, width, height, depth, 0, format, type, NULL);
        width = max(1, (width / 2));
        height = max(1, (height / 2));
        depth = max(1, (depth / 2));
    }

Cuando target es GL_TEXTURE_2D_ARRAY, GL_PROXY_TEXTURE_2D_ARRAY, GL_TEXTURE_CUBE_MAP_ARRAY o GL_PROXY_TEXTURE_CUBE_MAP_ARRAY, glTexStorage3D es equivalente a:

    para (i = 0; i < levels; i++) {
        glTexImage3D(target, i, internalformat, width, height, depth, 0, format, type, NULL);
        width = max(1, (width / 2));
        height = max(1, (height / 2));
    }

Llamar a glTextureStorage3D es equivalente al pseudocódigo anterior, donde target es el destino efectivo de texture y es como si texture estuviera vinculada a target para los fines de glTexImage3D.

Dado que no se proporcionan datos de textura reales, los valores utilizados en el pseudocódigo para format y type son irrelevantes y pueden considerarse cualquier valor que sea legal para el enumerador internalformat elegido. internalformat debe ser uno de los formatos internos con tamaño que se encuentran en la Tabla 1 a continuación, uno de los formatos de componente de profundidad con tamaño GL_DEPTH_COMPONENT32F, GL_DEPTH_COMPONENT24 o GL_DEPTH_COMPONENT16, uno de los formatos combinados de profundidad-esténcil, GL_DEPTH32F_STENCIL8 o GL_DEPTH24_STENCIL8, o el formato solo de esténcil, GL_STENCIL_INDEX8. Tras el éxito, el valor de GL_TEXTURE_IMMUTABLE_FORMAT se convierte en GL_TRUE. El valor de GL_TEXTURE_IMMUTABLE_FORMAT puede descubrirse llamando a glGetTexParameter() con pname establecido en GL_TEXTURE_IMMUTABLE_FORMAT. No se podrán realizar más cambios en las dimensiones o el formato del objeto de textura. El uso de cualquier comando que pueda alterar las dimensiones o el formato del objeto de textura (como glTexImage3D() u otra llamada a glTexStorage3D) generará un error GL_INVALID_OPERATION, incluso si no alterara las dimensiones o el formato del objeto.
