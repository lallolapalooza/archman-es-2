PARÁMETROS

program

Especifica el manejador del programa que contiene la variable uniforme a modificar.

location

Especifica la ubicación de la variable uniforme a modificar.

count

Para los comandos de vector (glProgramUniform*v), especifica el número de elementos que se modificarán. Esto debe ser 1 si la variable uniforme objetivo no es un array, y 1 o más si es un array.

Para los comandos de matriz (glProgramUniformMatrix*), especifica el número de matrices que se modificarán. Esto debe ser 1 si la variable uniforme objetivo no es un array de matrices, y 1 o más si es un array de matrices.

transpose

Para los comandos de matriz (glProgramUniformMatrix*), especifica si se debe transponer la matriz. Debe ser GL_TRUE si la matriz debe transponerse y GL_FALSE si no.

value

Para los comandos de un solo valor (ej. glProgramUniform*f), especifica el nuevo valor o valores para el uniforme.

Para los comandos de vector (ej. glProgramUniform*fv), especifica un puntero al primer elemento de una matriz o array de nuevos valores para el uniforme.

Para los comandos de matriz (ej. glProgramUniformMatrix*fv), especifica un puntero a los primeros elementos de una matriz o array de matrices de nuevos valores para el uniforme.

DESCRIPCIÓN

glProgramUniform* establecen el valor de una variable uniforme en un objeto de programa especificado. A diferencia de glUniform*glUniform(3G), estos comandos no requieren que el programa sea activo. También, en lugar de recibir la ubicación del uniforme como un argumento, la ubicación es calculada internamente basándose en el nombre del uniforme.

Los comandos glProgramUniform* son apropiados para establecer los valores de los uniformes para un programa específico, sin tener que llamar a glUseProgram primero.

Los comandos con sufijos 1f, 2f, 3f, y 4f establecen los valores de un solo componente, dos componentes, tres componentes y cuatro componentes, respectivamente, de un tipo float. glProgramUniform1f establece un solo componente float, glProgramUniform2f establece un vector de dos componentes float, glProgramUniform3f establece un vector de tres componentes float, y glProgramUniform4f establece un vector de cuatro componentes float.

Los comandos con sufijos 1i, 2i, 3i, y 4i establecen los valores de un solo componente, dos componentes, tres componentes y cuatro componentes, respectivamente, de un tipo int. glProgramUniform1i establece un solo componente int, glProgramUniform2i establece un vector de dos componentes int, glProgramUniform3i establece un vector de tres componentes int, y glProgramUniform4i establece un vector de cuatro componentes int. Los valores se copian directamente, y los valores de tipo int son mapeados a float uniformes si es necesario.

Los comandos con sufijos 1ui, 2ui, 3ui, y 4ui establecen los valores de un solo componente, dos componentes, tres componentes y cuatro componentes, respectivamente, de un tipo unsigned int. glProgramUniform1ui establece un solo componente unsigned int, glProgramUniform2ui establece un vector de dos componentes unsigned int, glProgramUniform3ui establece un vector de tres componentes unsigned int, y glProgramUniform4ui establece un vector de cuatro componentes unsigned int. Los valores se copian directamente, y los valores de tipo unsigned int son mapeados a float uniformes si es necesario.

Los comandos con sufijo v (ej. glProgramUniform*fv) establecen un número de componentes de un tipo dado. Los comandos glProgramUniform1fv, glProgramUniform2fv, glProgramUniform3fv, y glProgramUniform4fv establecen arrays de uno, dos, tres y cuatro componentes float, respectivamente. Los comandos glProgramUniform1iv, glProgramUniform2iv, glProgramUniform3iv, y glProgramUniform4iv establecen arrays de uno, dos, tres y cuatro componentes int, respectivamente. Los comandos glProgramUniform1uiv, glProgramUniform2uiv, glProgramUniform3uiv, y glProgramUniform4uiv establecen arrays de uno, dos, tres y cuatro componentes unsigned int, respectivamente.

Los comandos con el sufijo Matrix (ej. glProgramUniformMatrix2fv) establecen matrices. Los comandos glProgramUniformMatrix2fv, glProgramUniformMatrix3fv, y glProgramUniformMatrix4fv establecen arrays de matrices de 2x2, 3x3 y 4x4 float, respectivamente. Los comandos glProgramUniformMatrix2x3fv y glProgramUniformMatrix3x2fv establecen arrays de matrices de 2x3 y 3x2 float, respectivamente. Los comandos glProgramUniformMatrix2x4fv y glProgramUniformMatrix4x2fv establecen arrays de matrices de 2x4 y 4x2 float, respectivamente. Los comandos glProgramUniformMatrix3x4fv y glProgramUniformMatrix4x3fv establecen arrays de matrices de 3x4 y 4x3 float, respectivamente. El argumento transpose indica si se deben transponer las matrices; debe ser GL_TRUE si las matrices en el array están transpuestas y GL_FALSE en caso contrario. Las matrices se almacenan en memoria en orden de columnas por defecto.

count es el número de elementos (para los comandos vector) o matrices (para los comandos matrix) a actualizar. Los valores se copian del puntero value.

La variable uniforme especificada por program y location debe ser compatible con el tipo de dato del comando de establecimiento de valor. Si no lo es, el comando de establecimiento de valor fallará silenciosamente.

Si program no es el nombre de un programa o si location no es una ubicación válida para una variable uniforme en program, se generará un error GL_INVALID_OPERATION.

NOTAS

Si el programa que contiene la variable uniforme no está siendo actualmente utilizado, el valor del uniforme permanecerá inalterado hasta que el programa sea seleccionado con glUseProgram.

Las funciones **glProgramUniform* ** no cambian el programa activo. El programa activo sigue siendo el que fue establecido por la última llamada a glUseProgram.

Los valores de los uniformes son parte del estado del programa y permanecerán inalterados hasta que se vuelvan a llamar a las funciones glProgramUniform* o hasta que se elimine el programa.

ERRORES

Se genera GL_INVALID_OPERATION si program no es un programa válido.

Se genera GL_INVALID_OPERATION si location no es una ubicación válida para una variable uniforme en program.

Se genera GL_INVALID_VALUE si count es negativo.

NAME

glProgramUniform2ui - set uniform stored in an application-controlled GLSL uniform variable

C SPECIFICATION

void glProgramUniform2ui( GLuint program,
                          GLint location,
                          GLuint v0, GLuint v1 );

PARAMETERS

program specifies the program object containing the uniform variable to be modified.

location specifies the location of the uniform variable within the program object.

v0, v1 specify the new values of the uniform variable.

DESCRIPTION

Calls to glProgramUniform* functions are used to set the value of a uniform variable, after a program object has been linked successfully, and before it has been used in a rendering call. If program is zero, the calls are made to the uniform variables of the currently active program object.

If location is not GL_INVALID_INDEX, then the uniform variable indicated by location is set to the specified value.

If location is GL_INVALID_INDEX, the specified uniform variable is not affected.

The glProgramUniform2ui function sets the value of the specified uniform variable to the specified vector of two unsigned integers.

The name of the uniform variable is not specified. Instead, the application must provide the location of the uniform variable. The location can be found using glGetUniformLocation(program, name), where name is the name of the uniform variable.

If the uniform variable's data type is not `uint[2]`, the command is ignored.

The glProgramUniform2ui function is available on all GL implementations.

In order to call glProgramUniform2ui, program must be a program object for which linking has completed successfully.

NOTES

The glProgramUniform* functions are part of the GL_ARB_explicit_uniform_location extension, which is intended to provide a more convenient way to set uniform values than the older glUniform* functions.

The glProgramUniform* functions are equivalent to calling glUseProgram(program) followed by a call to glUniform*(location, ...).

Uniforms updated via glProgramUniform* functions are not reset by a call to glUseProgram(0).

The location of a uniform variable can also be queried using glGetUniformLocation, but glGetUniformBlockIndex should be used for uniform buffer objects.

ERRORS

GL_INVALID_OPERATION is generated if program is not zero or a value returned by glCreateProgram.

GL_INVALID_OPERATION is generated if program is the name of a program object that has not been linked successfully.

GL_INVALID_OPERATION is generated if location is GL_INVALID_INDEX.

GL_INVALID_OPERATION is generated if the uniform variable referred to by location is not contained in the program object specified by program.

GL_INVALID_OPERATION is generated if the data type of the uniform variable referred to by location is not compatible with the data type specified by the function.
