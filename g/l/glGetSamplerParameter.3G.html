GLGETSAMPLERPARAMETE(3G) [FIXME: manual] GLGETSAMPLERPARAMETE(3G)

NOMBRE

glGetSamplerParameter - devuelve los valores de los parámetros del muestreador

ESPECIFICACIÓN C

void glGetSamplerParameterfv(GLuintsampler, GLenumpname, GLfloat *params);

void glGetSamplerParameteriv(GLuintsampler, GLenumpname, GLint *params);

void glGetSamplerParameterIiv(GLuintsampler, GLenumpname, GLint *params);

void glGetSamplerParameterIuiv(GLuintsampler, GLenumpname, GLuint *params);

PARÁMETROS

sampler

Especifica el nombre del objeto muestreador del cual recuperar los parámetros.

pname

Especifica el nombre simbólico de un parámetro del muestreador. GL_TEXTURE_MAG_FILTER, GL_TEXTURE_MIN_FILTER, GL_TEXTURE_MIN_LOD, GL_TEXTURE_MAX_LOD, GL_TEXTURE_LOD_BIAS, GL_TEXTURE_WRAP_S, GL_TEXTURE_WRAP_T, GL_TEXTURE_WRAP_R, GL_TEXTURE_BORDER_COLOR, GL_TEXTURE_COMPARE_MODEy GL_TEXTURE_COMPARE_FUNC son aceptados.

params

Devuelve los parámetros del muestreador.

DESCRIPCIÓN

glGetSamplerParameter devuelve en params el valor o valores del parámetro del muestreador especificado como pname. sampler define el muestreador de destino, y debe ser el nombre de un objeto muestreador existente, devuelto por una llamada previa a glGenSamplers(). pname acepta los mismos símbolos que glSamplerParameter(), con las mismas interpretaciones:

GL_TEXTURE_MAG_FILTER

Devuelve el filtro de magnificación de textura de valor único, una constante simbólica. El valor inicial es GL_LINEAR.

GL_TEXTURE_MIN_FILTER

Devuelve el filtro de minificación de textura de valor único, una constante simbólica. El valor inicial es GL_NEAREST_MIPMAP_LINEAR.

GL_TEXTURE_MIN_LOD

Devuelve el valor de nivel de detalle mínimo de textura de valor único. El valor inicial es -1000.

GL_TEXTURE_MAX_LOD

Devuelve el valor de nivel de detalle máximo de textura de valor único. El valor inicial es 1000.

GL_TEXTURE_WRAP_S

Devuelve la función de envoltura de valor único para la coordenada de textura s, una constante simbólica. El valor inicial es GL_REPEAT.

GL_TEXTURE_WRAP_T

Devuelve la función de envoltura de valor único para la coordenada de textura t, una constante simbólica. El valor inicial es GL_REPEAT.

GL_TEXTURE_WRAP_R

Devuelve la función de envoltura de valor único para la coordenada de textura r, una constante simbólica. El valor inicial es GL_REPEAT.

GL_TEXTURE_BORDER_COLOR

Devuelve cuatro números enteros o de punto flotante que componen el color RGBA del borde de la textura. Los valores de punto flotante se devuelven en el rango 0 1. Los valores enteros se devuelven como un mapeo lineal de la representación interna de punto flotante de tal manera que 1.0 se mapea al entero representable más positivo y -1.0 se mapea al entero representable más negativo. El valor inicial es (0, 0, 0, 0).

GL_TEXTURE_COMPARE_MODE

Devuelve un modo de comparación de textura de valor único, una constante simbólica. El valor inicial es GL_NONE. Ver glSamplerParameter().

GL_TEXTURE_COMPARE_FUNC

Devuelve una función de comparación de textura de valor único, una constante simbólica. El valor inicial es GL_LEQUAL. Ver glSamplerParameter().

NOTAS

Si se genera un error, no se realiza ningún cambio en el contenido de params.

glGetSamplerParameter está disponible solo si la versión de GL es 3.3 o superior.

ERRORES

GL_INVALID_VALUE se genera si sampler no es el nombre de un objeto muestreador devuelto por una llamada previa a glGenSamplers().

GL_INVALID_ENUM se genera si pname no es un valor aceptado.
