PARÁMETROS

location

Especifica la ubicación de la variable uniforme a modificar.

count

Para los comandos de vector (glUniform*v), especifica el número de elementos que se van a modificar. Debe ser 1 si la variable uniforme de destino no es un array, y 1 o más si es un array.

Para los comandos de matriz (glUniformMatrix*), especifica el número de matrices que se van a modificar. Debe ser 1 si la variable uniforme de destino no es un array de matrices, y 1 o más si es un array de matrices.

transpose

Para los comandos de matriz, especifica si se debe transponer la matriz al cargar los valores en la variable uniforme.

v0, v1, v2, v3

Para los comandos escalares, especifica los nuevos valores que se utilizarán para la variable uniforme especificada.

value

Para los comandos de vector y matriz, especifica un puntero a un array de count valores que se utilizarán para actualizar la variable uniforme especificada.

DESCRIPCIÓN

glUniform modifica el valor de una variable uniforme o un array de variables uniformes. La ubicación de la variable uniforme a modificar se especifica mediante location, que debe ser un valor devuelto por glGetUniformLocation(). glUniform opera sobre el objeto de programa que se hizo parte del estado actual llamando a glUseProgram().

Los comandos glUniform{1|2|3|4}{f|i|ui} se utilizan para cambiar el valor de la variable uniforme especificada por location utilizando los valores pasados como argumentos. El número especificado en el comando debe coincidir con el número de componentes en el tipo de dato de la variable uniforme especificada (por ejemplo, 1 para float, int, unsigned int, bool; 2 para vec2, ivec2, uvec2, bvec2, etc.). El sufijo f indica que se están pasando valores de punto flotante; el sufijo i indica que se están pasando valores enteros; el sufijo ui indica que se están pasando valores enteros sin signo, y este tipo también debe coincidir con el tipo de dato de la variable uniforme especificada. Las variantes i de esta función deben usarse para proporcionar valores para variables uniformes definidas como int,
