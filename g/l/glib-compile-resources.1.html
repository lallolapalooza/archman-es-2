glib-compile-resources lee la descripción del recurso desde ARCHIVO y los archivos a los que hace referencia, y crea un paquete de recursos binario adecuado para su uso con la API GResource. El paquete resultante se escribe entonces tal cual, o como código fuente de C para enlazarlo en una

aplicación.

Los archivos de recursos XML normalmente tienen la extensión de nombre de archivo .gresource.xml. Para una descripción detallada del formato de archivo XML, consulta la documentación de GResource https://docs.gtk.org/gi

--manual-registe

r
Por defecto, el código generado por --generate-source usa la inicialización automática del recurso. Esto funciona en la mayoría de los sistemas usando el soporte del compilador para constructores. Sin embargo, algunos compiladores (poco comunes) pueden no soportar esto, en cuyo caso puedes especificar --manual-register, lo que generará funciones de registro y desregistro personalizadas que tu código puede llamar manualmente en el momento de la inicialización y desinicializació
n

--interna

l
Por defecto, el código generado por --generate-source declara todas las funciones de inicialización como extern. Así que se exportan a menos que esto sea impedido por un script de enlace u otros medios. Dado que las bibliotecas normalmente quieren usar las funciones solo internamente, puede ser más útil declararlas como G_GNUC_INTERNAL, que es lo que hace --inte
rn
