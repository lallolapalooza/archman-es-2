NOMBRE

glab-auth-login - Autentícate con una instancia de GitLab.

SINOPSIS

glab auth login [flags]

DESCRIPCIÓN

Autentícate con una instancia de GitLab. Puedes pasar un token por entrada estándar usando --stdin. Los ámbitos mínimos requeridos para el token son: api, write_repository. La configuración y las credenciales se almacenan en el archivo de configuración global (por defecto ~/.config/glab-cli/config.yml)

Al ejecutarse en modo interactivo dentro de un repositorio Git, glab detectará automáticamente las instancias de GitLab de tus remotos Git y las presentará como opciones, ahorrándote tener que escribir manualmente el nombre del host.

OPCIONES

-a, --api-host="" URL del host de la API.

-p, --api-protocol="" Protocolo de la API: https, http

-g, --git-protocol="" Protocolo Git: ssh, https, http

--hostname="" El nombre del host de la instancia de GitLab con la que autenticarse.

-j, --job-token="" Token de trabajo de CI.

--stdin[=false] Leer el token de la entrada estándar.

-t, --token="" Tu token de acceso de GitLab.

--use-keyring[=false] Almacenar el token en el llavero de tu sistema operativo.

OPCIONES HEREDADAS DE COMANDOS PADRE

-h, --help[=false] Mostrar ayuda para este comando.

EJEMPLO

# Iniciar configuración interactiva
# (Si estás en un repositorio Git, glab detectará y sugerirá instancias de GitLab desde los remotos)
$ glab auth login
# Autenticarse contra `gitlab.com` leyendo el token desde un archivo
$ glab auth login --stdin < myaccesstoken.txt
# Autenticarse con GitLab Autogestionado o GitLab Dedicado
$ glab auth login --hostname salsa.debian.org
# Configuración no interactiva
$ glab auth login --hostname gitlab.example.org --token glpat-xxx --api-host gitlab.example.org:3443 --api-protocol https --git-protocol ssh
# Configuración no interactiva leyendo el token desde un archivo
$ glab auth login --hostname gitlab.example.org --api-host gitlab.example.org:3443 --api-protocol https --git-protocol ssh  --stdin < myaccesstoken.txt
# Configuración no interactiva de CI/CD
$ glab auth login --hostname $CI_SERVER_HOST --job-token $CI_JOB_TOKEN
