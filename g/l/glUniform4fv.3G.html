glUniform modifie la
valeur d'une variable

uniform

e

ou d'un tableau de variables uniformes. L'emplacement de la variable uniforme à modifier est spécifié par location, qui doit être une valeur retournée par glGetUniformLocation(). glUniform opère sur l'objet programme qui a été rendu partie de l'état courant en appelant glUseProgram(). Les commandes glUniform{1|2|3|4}{f|i|ui} sont util

isées

pour changer la valeur de la variable uniforme spécifiée par location en utilisant les valeurs passées en arguments. Le nombre spécifié dans la commande doit correspondre au nombre de composantes dans le type de données de la variable uniforme spécifiée (par ex., 1 pour float, int, unsigned int, bool ; 2 pour vec2, ivec2, uvec2, bvec2, etc.). Le suffixe f indique que des valeurs en virgule flottante sont passées ; le suffixe i indique que des valeurs entières sont passées ; le suffixe ui indique que des valeurs entières non signées sont passées, et ce type doit également correspondre au type de données de la variable uniforme spécifiée. Les variantes i de cette fonction doivent être utilisées pour fournir des valeurs pour des variables uniformes définies comme int, ivec2, ivec3, ivec4, o matrices de estos. Las ui variantes de esta función deben usarse para proporcionar valores para variables uniformes definidas como unsigned int, uvec2, uvec3, uvec4, o matrices de estos. Las f variantes deben usarse para proporcionar valores para variables uniformes de tipo float, vec2, vec3, vec4, o matrices de estos. Cualquiera de las i

, u

i

o f variantes puede usarse para proporcionar valores para variables uniformes de tipo bool, bvec2, bvec3, bvec4, o matrices de estos. La variable uniforme se establecerá en false si el valor de entrada es 0 o 0.0f, y se establecerá en true en caso contrario. Todas las variables uniformes activas definidas en un objeto de programa son inicializadas a 0 cuando el objeto de programa se enlaza correctamente. Conservan los valores asignados por una llamada a glUniform hasta que se produce la siguiente operación de enlace exitosa en el objeto de programa, cuando se vuelven a inicializar a 0. Los comandos glUniform{1|2|3|4}{f|i|ui}v pueden usarse para modificar una variable uniforme individual o una matriz de variables uniformes. Estos comandos pasan un conteo y un puntero a los valores que se cargarán en una variable uniforme o una matriz de variables uniformes. Debe usarse un conteo de 1 si se modifica el valor de una sola variable uniforme, y un conteo de 1 o mayor puede usarse para modificar toda una matriz o parte de una matriz. Al cargar n elementos comenzando en una posición arbitraria m

en una matriz de variables uniformes, los elementos m +

n

- 1 en la matriz serán reemplazados con los nuevos valores. Si m + n - 1 es mayor que el tamaño de la matriz de variables uniformes, los valores de todos los elementos de la matriz más allá del final de la matriz serán ignorados. El número especificado en el nombre del comando indica el número de componentes para cada elemento en value , y debe coincidir con el número de componentes en el tipo de datos de la variable uniforme especificada (por ejemplo, 1 para float, int, bool; 2 para vec2, ivec2, bvec2, etc.).
