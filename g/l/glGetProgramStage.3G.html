NOMBRE

glGetProgramStage - recupera propiedades de un objeto de programa correspondientes a una etapa de sombreador especificada

ESPECIFICACIÓN C

void glGetProgramStageiv(GLuint program, GLenum shadertype, GLenum pname, GLint *values);

PARÁMETROS

program

Especifica el nombre del programa que contiene la etapa de sombreador.

shadertype

Especifica la etapa de sombreador de la que se consultará el parámetro de subrutina. shadertype debe ser uno de GL_VERTEX_SHADER, GL_TESS_CONTROL_SHADER, GL_TESS_EVALUATION_SHADER, GL_GEOMETRY_SHADER o GL_FRAGMENT_SHADER.

pname

Especifica el parámetro del sombreador a consultar. pname debe ser GL_ACTIVE_SUBROUTINE_UNIFORMS, GL_ACTIVE_SUBROUTINE_UNIFORM_LOCATIONS, GL_ACTIVE_SUBROUTINES, GL_ACTIVE_SUBROUTINE_UNIFORM_MAX_LENGTH, o GL_ACTIVE_SUBROUTINE_MAX_LENGTH.

values

Especifica la dirección de una variable en la que se colocarán el valor o los valores consultados.

DESCRIPCIÓN

glGetProgramStage consulta un parámetro de una etapa de sombreador adjunta a un objeto de programa. program contiene el nombre del programa al que está adjunto el sombreador. shadertype especifica la etapa de la que se consultará el parámetro. pname especifica qué parámetro se consultará. El valor o los valores del parámetro a consultar se devuelven en la variable cuya dirección se proporciona en values.

Si pname es GL_ACTIVE_SUBROUTINE_UNIFORMS, se devuelve el número de variables de subrutina activas en la etapa en values.

Si pname es GL_ACTIVE_SUBROUTINE_UNIFORM_LOCATIONS, se devuelve el número de ubicaciones de variables de subrutina activas en la etapa en values.

Si pname es GL_ACTIVE_SUBROUTINES, se devuelve el número de subrutinas activas en la etapa en values.

Si pname es GL_ACTIVE_SUBROUTINE_UNIFORM_MAX_LENGTH, se devuelve la longitud del uniforme de subrutina más largo para la etapa en values.

Si pname es GL_ACTIVE_SUBROUTINE_MAX_LENGTH, se devuelve la longitud del nombre de subrutina más largo para la etapa en values. La longitud del nombre devuelta incluye espacio para el terminador nulo.

Si no hay ningún sombreador presente del tipo shadertype, el valor devuelto será coherente con un sombreador que no contenga subrutinas ni uniformes de subrutina.

ERRORES

GL_INVALID_ENUM se genera si shadertype o pname no son uno de los valores aceptados.

GL_INVALID_VALUE se genera si program no es el nombre de un objeto de programa existente.
