NOMBRE

glCreateProgram - Crea un objeto de programa

ESPECIFICACIÓN C

GLuint glCreateProgram(void);

DESCRIPCIÓN

glCreateProgram crea un objeto de programa vacío y devuelve un valor distinto de cero por el cual puede ser referenciado. Un objeto de programa es un objeto al que se pueden adjuntar objetos de shader. Esto proporciona un mecanismo para especificar los objetos de shader que se enlazarán para crear un programa. También proporciona un medio para comprobar la compatibilidad de los shaders que se utilizarán para crear un programa (por ejemplo, comprobar la compatibilidad entre un shader de vértices y un shader de fragmentos). Cuando ya no son necesarios como parte de un objeto de programa, los objetos de shader pueden ser desadjuntados.

Se crean uno o más ejecutables en un objeto de programa adjuntando con éxito objetos de shader a él con glAttachShader(), compilando con éxito los objetos de shader con glCompileShader() y enlazando con éxito el objeto de programa con glLinkProgram(). Estos ejecutables pasan a formar parte del estado actual cuando se llama a glUseProgram(). Los objetos de programa se pueden eliminar llamando a glDeleteProgram(). La memoria asociada al objeto de programa se eliminará cuando deje de formar parte del estado de renderizado actual para cualquier contexto.

NOTAS

Al igual que los objetos de búfer y textura, el espacio de nombres para los objetos de programa puede ser compartido entre un conjunto de contextos, siempre que los lados del servidor de los contextos compartan el mismo espacio de direcciones. Si el espacio de nombres se comparte entre contextos, todos los objetos adjuntos y los datos asociados a dichos objetos adjuntos también se comparten.

Las aplicaciones son responsables de proporcionar la sincronización entre las llamadas a la API cuando los objetos son accedidos desde diferentes hilos de ejecución.

ERRORES

Esta función devuelve 0 si ocurre un error al crear el objeto de programa.
