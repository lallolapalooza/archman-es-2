NOMBRE

glGetProgramInfoLog - Devuelve el registro de información para un objeto de programa

ESPECIFICACIÓN C

void glGetProgramInfoLog(GLuint program, GLsizei maxLength, GLsizei *length, GLchar *infoLog);

PARÁMETROS

program

Especifica el objeto de programa cuyo registro de información se va a consultar.

maxLength

Especifica el tamaño del búfer de caracteres para almacenar el registro de información devuelto.

length

Devuelve la longitud de la cadena devuelta en infoLog (excluyendo el terminador nulo).

infoLog

Especifica una matriz de caracteres que se utiliza para devolver el registro de información.

DESCRIPCIÓN

glGetProgramInfoLog devuelve el registro de información para el objeto de programa especificado. El registro de información de un objeto de programa se modifica cuando el objeto de programa se enlaza o se valida. La cadena que se devuelve estará terminada en nulo.

glGetProgramInfoLog devuelve en infoLog la mayor parte del registro de información que puede, hasta un máximo de maxLength caracteres. El número de caracteres devueltos, excluyendo el carácter de terminación nulo, se especifica en length. Si no se requiere la longitud de la cadena devuelta, se puede pasar un valor de NULL en el argumento length. El tamaño del búfer necesario para almacenar el registro de información devuelto se puede obtener llamando a glGetProgram() con el valor GL_INFO_LOG_LENGTH.

El registro de información de un objeto de programa es o bien una cadena vacía, o una cadena que contiene información sobre la última operación de enlace, o una cadena que contiene información sobre la última operación de validación. Puede contener mensajes de diagnóstico, mensajes de advertencia y otra información. Cuando se crea un objeto de programa, su registro de información será una cadena de longitud 0.

NOTAS

El registro de información de un objeto de programa es el principal mecanismo del implementador de OpenGL para transmitir información sobre el enlace y la validación. Por lo tanto, el registro de información puede ser útil para los desarrolladores de aplicaciones durante el proceso de desarrollo, incluso cuando estas operaciones son exitosas. Los desarrolladores de aplicaciones no deben esperar que diferentes implementaciones de OpenGL produzcan registros de información idénticos.

ERRORES

Se genera GL_INVALID_VALUE si program no es un valor generado por OpenGL.

Se genera GL_INVALID_OPERATION si program no es un objeto de programa.

Se genera GL_INVALID_VALUE si maxLength es menor que 0.

GETS ASOCIADOS

glGetProgram() con el argumento GL_INFO_LOG_LENGTH

glIsProgram()
