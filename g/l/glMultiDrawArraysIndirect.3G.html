NOMBRE

glMultiDrawArraysIndirect - dibuja múltiples conjuntos de primitivas a partir de datos de arrays, tomando parámetros de la memoria

ESPECIFICACIÓN C

void glMultiDrawArraysIndirect(GLenum mode, const void *indirect, GLsizei drawcount, GLsizei stride);

PARÁMETROS

mode

Especifica qué tipo de primitivas dibujar. Se aceptan símbolos constantes GL_POINTS, GL_LINE_STRIP, GL_LINE_LOOP, GL_LINES, GL_LINE_STRIP_ADJACENCY, GL_LINES_ADJACENCY, GL_TRIANGLE_STRIP, GL_TRIANGLE_FAN, GL_TRIANGLES, GL_TRIANGLE_STRIP_ADJACENCY, GL_TRIANGLES_ADJACENCY y GL_PATCHES.

indirect

Especifica la dirección de un array de estructuras que contienen los parámetros de dibujo.

drawcount

Especifica el número de elementos en el array de estructuras de parámetros de dibujo.

stride

Especifica la distancia en unidades básicas de máquina entre elementos del array de parámetros de dibujo.

DESCRIPCIÓN

glMultiDrawArraysIndirect especifica múltiples primitivas geométricas con muy pocas llamadas a subrutinas. glMultiDrawArraysIndirect se comporta de forma similar a una multitud de llamadas a glDrawArraysInstancedBaseInstance(), excepto que los parámetros de cada llamada a glDrawArraysInstancedBaseInstance() se almacenan en un array en memoria en la dirección dada por indirect, separados por el paso (stride), en unidades básicas de máquina, especificado por stride. Si stride es cero, entonces se asume que el array está empaquetado directamente en memoria.

Los parámetros direccionados por indirect se empaquetan en un array de estructuras, cada elemento de las cuales toma la forma (en C):

    typedef  struct {
        uint  count;
        uint  instanceCount;
        uint  first;
        uint  baseInstance;
    } DrawArraysIndirectCommand;

Una única llamada a glMultiDrawArraysIndirect es equivalente, asumiendo que no se generan errores, a:

    GLsizei n;
    for (n = 0; n < drawcount; n++) {
        const DrawArraysIndirectCommand *cmd;
        if (stride != 0) {
            cmd = (const DrawArraysIndirectCommand  *)((uintptr)indirect + n * stride);
        } else  {
            cmd = (const DrawArraysIndirectCommand  *)indirect + n;
        }
        glDrawArraysInstancedBaseInstance(mode, cmd->first, cmd->count, cmd->instanceCount, cmd->baseInstance);
    }

Si un buffer está enlazado al enlace GL_DRAW_INDIRECT_BUFFER en el momento de una llamada a glMultiDrawArraysIndirect, indirect se interpreta como un desplazamiento, en unidades básicas de máquina, dentro de ese buffer y los datos de los parámetros se leen del buffer en lugar de la memoria del cliente.

A diferencia de glDrawArraysInstancedBaseInstance(), el primer miembro de la estructura de parámetros es sin signo, y los índices fuera de rango no generan un error.

Los atributos de vértice que son modificados por glMultiDrawArraysIndirect tienen un valor indefinido después de que glMultiDrawArraysIndirect retorna. Los atributos que no se modifican permanecen bien definidos.

NOTAS

El miembro baseInstance de la estructura DrawArraysIndirectCommand solo está definido si la versión de GL es 4.2 o superior. Para versiones de GL anteriores a 4.2, este parámetro está presente pero está reservado y debe establecerse en cero. En versiones anteriores de GL, el comportamiento no está definido si es distinto de cero.

glMultiDrawArraysIndirect solo está disponible si la versión de GL es 4.3 o superior.

ERRORES

Se genera GL_INVALID_ENUM si mode no es un valor aceptado.

Se genera GL_INVALID_VALUE si stride no es un múltiplo de cuatro.

Se genera GL_INVALID_VALUE si drawcount es negativo.

Se genera GL_INVALID_OPERATION si un objeto de buffer no cero está enlazado a un array habilitado o al enlace GL_DRAW_INDIRECT_BUFFER y el almacén de datos del objeto de buffer está actualmente mapeado.

Se genera GL_INVALID_OPERATION si un shader de geometría está activo y mode es incompatible con el tipo de primitiva de entrada del shader de geometría en el objeto de programa actualmente instalado.

Se genera GL_INVALID_OPERATION si mode es GL_PATCHES y no hay un shader de control de teselación activo.
