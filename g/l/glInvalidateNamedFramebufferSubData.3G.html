GLINVALIDATESUBFRAME(3G) [FIXME: manual] GLINVALIDATESUBFRAME(3G)

NOMBRE

glInvalidateSubFramebuffer, glInvalidateNamedFramebufferSubData - invalidar el contenido de una región de algunas o todas las adjunciones de un framebuffer

ESPECIFICACIÓN EN C

void glInvalidateSubFramebuffer(GLenumtarget, GLsizeinumAttachments, const GLenum *attachments, GLintx, GLinty, GLintwidth, GLintheight);

void glInvalidateNamedFramebufferSubData(GLuintframebuffer, GLsizeinumAttachments, const GLenum *attachments, GLintx, GLinty, GLsizeiwidth, GLsizeiheight);

PARÁMETROS

target

Especifica el destino al que está adjunto el objeto framebuffer para glInvalidateSubFramebuffer.

framebuffer

Especifica el nombre del objeto framebuffer para glInvalidateNamedFramebufferSubData.

numAttachments

Especifica el número de entradas en el attachments array.

attachments

Especifica un puntero a un array que identifica las adjunciones a invalidar.

x

Especifica el desplazamiento X de la región a invalidar.

y

Especifica el desplazamiento Y de la región a invalidar.

width

Especifica el ancho de la región a invalidar.

height

Especifica el alto de la región a invalidar.

DESCRIPCIÓN

glInvalidateSubFramebuffer y glInvalidateNamedFramebufferSubData invalidan los contenidos de una región especificada de un conjunto especificado de adjunciones de un framebuffer.

Para glInvalidateSubFramebuffer, el objeto framebuffer es el que está vinculado a target, el cual debe ser uno de GL_FRAMEBUFFER, GL_READ_FRAMEBUFFER o GL_DRAW_FRAMEBUFFER. GL_FRAMEBUFFER es equivalente a GL_DRAW_FRAMEBUFFER. Los framebuffers predeterminados también pueden ser invalidados si están vinculados a target.

Para glInvalidateNamedFramebufferSubData, framebuffer es el nombre del objeto framebuffer. Si framebuffer es cero, el framebuffer de dibujo predeterminado es el afectado.

El conjunto de adjunciones de las cuales una región debe ser invalidada son especificadas en el attachments array, el cual contiene numAttachments elementos.

Si el framebuffer especificado es un objeto framebuffer, cada elemento de attachments debe ser uno de GL_DEPTH_ATTACHMENT, GL_STENCIL_ATTACHMENT GL_DEPTH_STENCIL_ATTACHMENT, o GL_COLOR_ATTACHMENTi, donde i está entre cero y el valor de GL_MAX_FRAMEBUFFER_ATTACHMENTS menos uno.

Si el framebuffer especificado es un framebuffer predeterminado, cada elemento de attachments debe ser uno de GL_FRONT_LEFT, GL_FRONT_RIGHT, GL_BACK_LEFT, GL_BACK_RIGHT, GL_AUXi, GL_ACCUM, GL_COLOR, GL_DEPTH, o GL_STENCIL. GL_COLOR, es tratado como GL_BACK_LEFT para un contexto de doble buffer y GL_FRONT_LEFT para un contexto de buffer simple. Las otras adjunciones identifican el búfer específico correspondiente.

Los contenidos de la región especificada de cada adjunción especificada se vuelven indefinidos después de la ejecución de glInvalidateSubFramebuffer o glInvalidateNamedFramebufferSubData. La región a invalidar es especificada por x, y, width y height donde x y y dan el desplazamiento desde el origen (con la esquina inferior izquierda en $(0,0)$) y width y height son el ancho y el alto, respectivamente, de la región. Cualquier píxel que se encuentre fuera de la ventana asignada al contexto GL actual (para el framebuffer predeterminado), o fuera de las adjunciones del objeto framebuffer, es ignorado. Si el objeto framebuffer no está completo, estos comandos pueden ser ignorados.

Si el objeto framebuffer no está completo, glInvalidateSubFramebuffer y glInvalidateNamedFramebufferSubData pueden ser ignorados. Esto no es un error.

ERRORES

GL_INVALID_ENUM por glInvalidateSubFramebuffer si target no es uno de los destinos de framebuffer aceptados.

GL_INVALID_OPERATION por glInvalidateNamedFramebufferSubData si framebuffer no es cero ni el nombre de un objeto framebuffer existente.

GL_INVALID_VALUE se genera si numAttachments, width o height es negativo.

GL_INVALID_ENUM se genera si algún elemento de attachments no es uno de los puntos de adjunción de framebuffer aceptados, como se describe arriba.

GL_INVALID_OPERATION se genera si un elemento de attachments es GL_COLOR_ATTACHMENTm donde m es mayor o igual al valor de GL_MAX_COLOR_ATTACHMENTS.

OBTENCIONES ASOCIADAS

glGet() con el argumento GL_MAX_COLOR_ATTACHMENTS
