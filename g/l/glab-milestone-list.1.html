NOMBRE

glab-milestone-list - Obtiene una lista de hitos para un proyecto o grupo.

SINOPSIS

glab milestone list [flags]

DESCRIPCIÓN

Obtiene una lista de hitos para un proyecto o grupo.

OPCIONES

--group="" El ID o ruta codificada en URL del grupo.

--include-ancestors[=false] Incluye hitos de todos los grupos padres.

-p, --page=1 Número de página.

-P, --per-page=20 Número de elementos a listar por página.

--project="" El ID o ruta codificada en URL del proyecto.

--search="" Devuelve solo hitos con un título o descripción que coincidan con la cadena proporcionada.

--show-id[=false] Muestra los IDs en la salida de tabla.

--state="" Devuelve solo hitos 'activos' o 'cerrados'.

--title="" Devuelve solo los hitos que tengan el título dado.

OPCIONES HEREDADAS DE COMANDOS PADRE

-h, --help[=false] Muestra la ayuda para este comando.

-R, --repo="" Selecciona otro repositorio. Puede usar el formato PROPIETARIO/REPO o GRUPO/NAMESPACE/REPO. También acepta URL completo o URL de Git.

EJEMPLO

 # Lista de hitos para un proyecto dado
$ glab milestone list --project 123
$ glab milestone list --project example-group/project-path
# Lista de hitos para un grupo
$ glab milestone list --group example-group
# Lista solo hitos activos para un grupo dado
$ glab milestone list --group example-group --state active
