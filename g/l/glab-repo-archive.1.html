NOMBRE

glab-repo-archive - Obtener un archivo del repositorio.

SINOPSIS

glab repo archive [flags]

DESCRIPCIÓN

Clone soporta estas referencias abreviadas:

  • repo
  • namespace/repo
  • namespace/group/repo

OPCIONES

-f, --format="zip" Opcional. Especificar el formato si desea un archivo descargado: tar.gz, tar.bz2, tbz, tbz2, tb2, bz2, tar, zip.

-s, --sha="" El SHA del commit a descargar. Se puede usar una etiqueta, una referencia de rama o un SHA. Por defecto es la punta de la rama predeterminada si no se especifica.

OPCIONES HEREDADAS DE COMANDOS PADRE

-h, --help[=false] Mostrar ayuda para este comando.

EJEMPLO

$ glab repo archive profclems/glab
# Descarga el archivo zip del repositorio actual
$ glab repo archive
# Descarga el archivo zip del repositorio en mydirectory
$ glab repo archive profclems/glab mydirectory
# Encuentra el repositorio para el usuario actual y descarga en formato ZIP
$ glab repo archive profclems/glab --format=zip
