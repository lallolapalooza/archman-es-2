NOMBRE

glGetVertexAttribPointerv - devuelve la dirección del puntero de atributo de vértice genérico especificado

ESPECIFICACIÓN C

void glGetVertexAttribPointerv(GLuint index, GLenum pname, void **pointer);

PARÁMETROS

index

Especifica el parámetro del atributo de vértice genérico a devolver.

pname

Especifica el nombre simbólico del parámetro del atributo de vértice genérico a devolver. Debe ser GL_VERTEX_ATTRIB_ARRAY_POINTER.

pointer

Devuelve el valor del puntero.

DESCRIPCIÓN

glGetVertexAttribPointerv devuelve información del puntero. index es el atributo de vértice genérico a consultar, pname es una constante simbólica que indica el puntero a devolver, y params es un puntero a una ubicación en la que colocar los datos devueltos.

El puntero devuelto es un desplazamiento en bytes dentro del almacén de datos del objeto de búfer que estaba enlazado al destino GL_ARRAY_BUFFER (ver glBindBuffer()) cuando se especificó previamente el puntero deseado.

NOTAS

El estado devuelto se recupera del objeto de arreglo de vértices enlazado actualmente.

El valor inicial para cada puntero es 0.

ERRORES

Se genera GL_INVALID_OPERATION si actualmente no hay ningún objeto de arreglo de vértices enlazado.

Se genera GL_INVALID_VALUE si index es mayor o igual que GL_MAX_VERTEX_ATTRIBS.

Se genera GL_INVALID_ENUM si pname no es un valor aceptado.

GETS ASOCIADOS

glGet() con el argumento GL_MAX_VERTEX_ATTRIBS
