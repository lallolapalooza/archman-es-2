NOMBRE

glGetProgramResourceLocationIndex - consulta el índice de color del fragmento de una variable nombrada dentro de un programa

ESPECIFICACIÓN C

GLint glGetProgramResourceLocationIndex(GLuint program, GLenum programInterface, const char * name);

PARÁMETROS

program

El nombre de un objeto de programa cuyos recursos se van a consultar.

programInterface

Un token que identifica la interfaz dentro de program que contiene el recurso llamado name.

name

El nombre del recurso cuya ubicación se va a consultar.

DESCRIPCIÓN

glGetProgramResourceLocationIndex devuelve el índice de color del fragmento asignado a la variable llamada name en la interfaz programInterface del objeto de programa program. program debe ser el nombre de un programa que se ha enlazado correctamente. programInterface debe ser GL_PROGRAM_OUTPUT.

Se devolverá el valor -1 si ocurre un error, si name no identifica una variable activa en programInterface, o si name identifica una variable activa que no tiene una ubicación válida asignada, como se describe anteriormente. Las ubicaciones devueltas por estos comandos son las mismas ubicaciones devueltas al consultar las propiedades de recurso GL_LOCATION y GL_LOCATION_INDEX.

Una cadena proporcionada a glGetProgramResourceLocationIndex se considera que coincide con una variable activa si:

•la cadena coincide exactamente con el nombre de la variable activa
•si la cadena identifica el nombre base de un array, donde la cadena coincidiría exactamente con el nombre de la variable si se añadiera el sufijo "[0]" a la cadena
•si la cadena identifica un elemento activo del array, donde la cadena termina con la concatenación del carácter "[", un entero sin signo "+", ceros iniciales adicionales o espacios en blanco que identifica un elemento del array, el entero es menor que el número de elementos activos de la variable array, y donde la cadena coincidiría exactamente con el nombre enumerado del array si el entero decimal se reemplazara con cero.

Cualquier otra cadena se considera que no identifica una variable activa. Si la cadena especifica un elemento de una variable array, glGetProgramResourceLocation devuelve la ubicación asignada a ese elemento. Si especifica el nombre base de un array, identifica los recursos asociados con el primer elemento del array.

ERRORES

GL_INVALID_VALUE se genera si program no es el nombre de un objeto de programa existente.

GL_INVALID_ENUM se genera si programInterface no es uno de los tipos de interfaz aceptados.

GL_INVALID_OPERATION se genera si program no se ha enlazado correctamente.
