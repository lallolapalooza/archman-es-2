NOMBRE

glClipControl - controla el comportamiento de las coordenadas de recorte a las coordenadas de ventana

ESPECIFICACIÓN C

void glClipControl(GLenum origin, GLenum depth);

PARÁMETROS

origin

Especifica el origen del control de recorte. Debe ser uno de GL_LOWER_LEFT o GL_UPPER_LEFT.

depth

Especifica el modo de profundidad del control de recorte. Debe ser uno de GL_NEGATIVE_ONE_TO_ONE o GL_ZERO_TO_ONE.

DESCRIPCIÓN

glClipControl controla el comportamiento del volumen de recorte y el comportamiento de la transformación de las coordenadas de recorte a las coordenadas de ventana.

El volumen de vista se define por $$z_{min} \leq z_c \leq w_c$$ donde $z_{min} = -w_c$ cuando depth es GL_NEGATIVE_ONE_TO_ONE, y $z_{min} = 0$ cuando depth es GL_ZERO_TO_ONE.

La coordenada de dispositivo normalizada $y_d$ se da por $$y_d = { { f \times y_c } \over w_c }$$ donde $f = 1$ cuando origin es GL_LOWER_LEFT, y $f = -1$ cuando origin es GL_UPPER_LEFT.

La coordenada de ventana $z_w$ se da por $$z_w = s \times z_d + b$$ donde $s = { { f - n } \over 2 }$ y $b = { {n + f} \over 2 }$ cuando depth es GL_NEGATIVE_ONE_TO_ONE, y $s = f - n$ y $b = n$ cuando depth es GL_ZERO_TO_ONE. $n$ y $f$ son los valores del rango de profundidad cercano y lejano establecidos con glDepthRange().

Finalmente, el cálculo del área del polígono definido por gl_FrontFacing() para determinar si un polígono es de cara frontal o posterior tiene su signo negado cuando origin es GL_UPPER_LEFT.

NOTAS

La definición predeterminada del volumen de recorte de GL es para un origin de GL_LOWER_LEFT y una depth de GL_NEGATIVE_ONE_TO_ONE.

Un origin de GL_UPPER_LEFT y una depth de GL_ZERO_TO_ONE corresponde a la definición del volumen de recorte de Direct3D.

Un origin de GL_UPPER_LEFT y una depth de GL_NEGATIVE_ONE_TO_ONE corresponde al origen superior izquierdo del sistema de coordenadas de ventana de Microsoft Windows y del X Window System.

Hay una discusión extensa sobre los usos y las consecuencias adicionales de las diferentes configuraciones del volumen de recorte en la especificación de la extensión GL_ARB_clip_control en el Registro de OpenGL en la URL http://www.opengl.org/registry/.

ERRORES

Se genera un error GL_INVALID_ENUM si origin no es GL_LOWER_LEFT o GL_UPPER_LEFT.

Se genera un error GL_INVALID_ENUM si depth no es GL_NEGATIVE_ONE_TO_ONE o GL_ZERO_TO_ONE.
