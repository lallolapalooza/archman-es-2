GLREADPIXELS(3G) [FIJAR: manual] GLREADPIXELS(3G)

NOMBRE

glReadPixels, glReadnPixels - leer un bloque de píxeles del búfer de fotogramas

ESPECIFICACIÓN EN C

void glReadPixels(GLint x, GLint y, GLsizei width, GLsizei height, GLenum format, GLenum type, void * data);

void glReadnPixels(GLint x, GLint y, GLsizei width, GLsizei height, GLenum format, GLenum type, GLsizei bufSize, void *data);

PARÁMETROS

x, y

Especifican las coordenadas de la ventana del primer píxel que se lee del búfer de fotogramas. Esta ubicación es la esquina inferior izquierda de un bloque rectangular de píxeles.

width, height

Especifican las dimensiones del rectángulo de píxeles. width y height de uno corresponden a un solo píxel.

format

Especifica el formato de los datos del píxel. Se aceptan los siguientes valores simbólicos: GL_STENCIL_INDEX, GL_DEPTH_COMPONENT, GL_DEPTH_STENCIL, GL_RED, GL_GREEN, GL_BLUE, GL_RGB, GL_BGR, GL_RGBA y GL_BGRA.

type

Especifica el tipo de datos de los datos del píxel. Debe ser uno de GL_UNSIGNED_BYTE, GL_BYTE, GL_UNSIGNED_SHORT, GL_SHORT, GL_UNSIGNED_INT, GL_INT, GL_HALF_FLOAT, GL_FLOAT, GL_UNSIGNED_BYTE_3_3_2, GL_UNSIGNED_BYTE_2_3_3_REV, GL_UNSIGNED_SHORT_5_6_5, GL_UNSIGNED_SHORT_5_6_5_REV, GL_UNSIGNED_SHORT_4_4_4_4, GL_UNSIGNED_SHORT_4_4_4_4_REV, GL_UNSIGNED_SHORT_5_5_5_1, GL_UNSIGNED_SHORT_1_5_5_5_REV, GL_UNSIGNED_INT_8_8_8_8, GL_UNSIGNED_INT_8_8_8_8_REV, GL_UNSIGNED_INT_10_10_10_2, GL_UNSIGNED_INT_2_10_10_10_REV, GL_UNSIGNED_INT_24_8, GL_UNSIGNED_INT_10F_11F_11F_REV, GL_UNSIGNED_INT_5_9_9_9_REV o GL_FLOAT_32_UNSIGNED_INT_24_8_REV.

bufSize

Especifica el tamaño del búfer data para la función glReadnPixels.

data

Devuelve los datos del píxel.

DESCRIPCIÓN

glReadPixels y glReadnPixels devuelven datos de píxeles del búfer de fotogramas, comenzando con el píxel cuya esquina inferior izquierda está en la ubicación (x, y), a la memoria del cliente comenzando en la ubicación data. Varios parámetros controlan el procesamiento de los datos de píxeles antes de colocarlos en la memoria del cliente. Estos parámetros se establecen con glPixelStore(). Esta página de referencia describe los efectos sobre glReadPixels y glReadnPixels de la mayoría, pero no todos, los parámetros especificados por estos tres comandos.

Si un objeto de búfer nombrado no nulo está enlazado al objetivo GL_PIXEL_PACK_BUFFER (ver glBindBuffer()) mientras se solicita un bloque de píxeles, data se trata como un desplazamiento de bytes en el almacén de datos del objeto de búfer en lugar de un puntero a la memoria del cliente.

glReadPixels y glReadnPixels devuelven valores de cada píxel con la esquina inferior izquierda en x + i y + j para 0 <= i < width y 0 <= j < height. Se dice que este píxel es el i-ésimo píxel en la j-ésima fila. Los píxeles se devuelven en orden de fila desde la fila más baja a la más alta, de izquierda a derecha en cada fila.

format especifica el formato para los valores de píxeles devueltos; los valores aceptados son:

GL_STENCIL_INDEX

Se leen los valores de plantilla del búfer de plantilla.

GL_DEPTH_COMPONENT

Se leen los valores de profundidad del búfer de profundidad. Cada componente se convierte a punto flotante de tal manera que el valor de profundidad mínimo se mapea a 0 y el valor máximo se mapea a 1. Cada componente se limita al rango 0 1.

GL_DEPTH_STENCIL

Los valores se toman tanto del búfer de profundidad como del de plantilla. El parámetro type debe ser GL_UNSIGNED_INT_24_8 o GL_FLOAT_32_UNSIGNED_INT_24_8_REV.

GL_RED, GL_GREEN, GL_BLUE, GL_RGB, GL_BGR, GL_RGBA, GL_BGRA

Se toman los valores de color del búfer de color.

Finalmente, los índices o componentes se convierten al formato correcto, según lo especificado por type. Si format es GL_STENCIL_INDEX y type no es GL_FLOAT, cada índice se enmascara con el valor de máscara dado en la siguiente tabla. Si type es GL_FLOAT, entonces cada índice entero se convierte al formato de punto flotante de precisión simple.
