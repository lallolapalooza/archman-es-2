NOMBRE

glScissorIndexed - definir el cuadro de tijera para una vista específica

ESPECIFICACIÓN C

void glScissorIndexed(GLuint index, GLint left, GLint bottom, GLsizei width, GLsizei height);

void glScissorIndexedv(GLuint index, const GLint *v);

PARÁMETROS

index

Especifica el índice de la vista cuyo cuadro de tijera se va a modificar.

left, bottom

Especifican la coordenada de la esquina inferior izquierda del cuadro de tijera, en píxeles.

width, height

Especifican las dimensiones del cuadro de tijera, en píxeles.

v

Para glScissorIndexedv, especifica la dirección de un array que contiene la izquierda, la inferior, el ancho y la altura de cada cuadro de tijera, en ese orden.

DESCRIPCIÓN

glScissorIndexed define el cuadro de tijera para una vista especificada. index especifica el índice del cuadro de tijera a modificar. index debe ser menor que el valor de GL_MAX_VIEWPORTS. Para glScissorIndexed, left, bottom, width y height especifican la izquierda, la inferior, el ancho y la altura del cuadro de tijera, en píxeles, respectivamente. Para glScissorIndexedv, v especifica la dirección de un array que contiene enteros que especifican la esquina inferior izquierda del cuadro de tijera, y el ancho y la altura del cuadro de tijera, en ese orden.

Para habilitar y deshabilitar la prueba de tijera, llame a glEnable() y

glDisable() con el argumento GL_SCISSOR_TEST. La prueba está inicialmente deshabilitada para todas las vistas. Mientras la prueba está habilitada, solo los píxeles que se encuentran dentro del cuadro de tijera pueden ser modificados por comandos de dibujo. Las coordenadas de la ventana tienen valores enteros en las esquinas compartidas de los píxeles del buffer de fotogramas. glScissor(0,0,1,1) permite la modificación solo del píxel inferior izquierdo en la ventana, y glScissor(0,0,0,0) no permite la modificación de ningún píxel en la ventana.

Cuando la prueba de tijera está deshabilitada, es como si el cuadro de tijera incluyera toda la ventana.

ERRORES

GL_INVALID_VALUE se genera si index es mayor o igual que el valor de GL_MAX_VIEWPORTS.

GL_INVALID_VALUE se genera si cualquier ancho o alto especificado en el array v es negativo.

GETS ASOCIADOS

glGet() con el argumento GL_SCISSOR_BOX

glIsEnabled() con el argumento GL_SCISSOR_TEST
