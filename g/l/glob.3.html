glob(3) Manual de funciones de biblioteca glob(3)

NOMBRE

glob, globfree - buscar nombres de ruta que coincidan con un patrón, liberar memoria de glob()

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <glob.h>
int glob(const char *restrict patrón, int flags,
         typeof(int (const char *epath, int eerrno)) *errfunc,
         glob_t *restrict pglob);
void globfree(glob_t *pglob);

DESCRIPCIÓN

La función glob() busca todos los nombres de ruta que coinciden con patrón según las reglas utilizadas por el shell (ver glob(7)). No se realiza expansión de tilde ni sustitución de parámetros; si desea esto, utilice wordexp(3).

La función globfree() libera el almacenamiento asignado dinámicamente de una llamada anterior a glob().

Los resultados de una llamada a glob() se almacenan en la estructura apuntada por pglob. Esta estructura es de tipo glob_t (declarada en <glob.h>) e incluye los siguientes elementos definidos por POSIX.2 (pueden haber más como extensión):


typedef struct {
    size_t   gl_pathc;    /* Contador de rutas coincidentes hasta el momento  */
    char   **gl_pathv;    /* Lista de nombres de ruta coincidentes.  */
    size_t   gl_offs;     /* Espacios para reservar en gl_pathv.  */
} glob_t;

Los resultados se almacenan en almacenamiento asignado dinámicamente.

El argumento flags está compuesto por el OR bit a bit de cero o más de las siguientes constantes simbólicas, que modifican el comportamiento de glob():

GLOB_ERR
Retornar ante un error de lectura (debido a que un directorio no tiene permiso de lectura, por ejemplo). Por defecto, glob() intenta continuar a pesar de los errores, leyendo todos los directorios que pueda.
GLOB_MARK
Añadir una barra inclinada ('/') a cada ruta que corresponda a un directorio.
GLOB_NOSORT
No ordenar los nombres de ruta devueltos. La única razón para hacer esto es ahorrar tiempo de procesamiento. Por defecto, los nombres de ruta devueltos están ordenados.
GLOB_DOOFFS
Reservar pglob->gl_offs espacios al principio de la lista de cadenas en pglob->pathv. Los espacios reservados contienen punteros nulos.
GLOB_NOCHECK
Si ningún patrón coincide, devolver el patrón original. Por defecto, glob() devuelve GLOB_NOMATCH si no hay coincidencias.
GLOB_APPEND
Añadir los resultados de esta llamada al vector de resultados devueltos por una llamada anterior a glob(). No establecer esta bandera en la primera invocación de glob().
GLOB_NOESCAPE
No permitir la barra invertida ('\') como carácter de escape. Normalmente, una barra invertida puede usarse para escapar el carácter siguiente, proporcionando un mecanismo para desactivar el significado especial de los metacaracteres.

flags también puede incluir cualquiera de los siguientes, que son extensiones GNU y no están definidos por POSIX.2:

GLOB_PERIOD
Permitir que un punto inicial sea coincido por metacaracteres. Por defecto, los metacaracteres no pueden coincidir con un punto inicial.
GLOB_ALTDIRFUNC
Utilizar funciones alternativas pglob->gl_closedir, pglob->gl_readdir, pglob->gl_opendir, pglob->gl_lstat y pglob->gl_stat para el acceso al sistema de archivos en lugar de las funciones normales de la biblioteca.
GLOB_BRACE
Expandir expresiones de llaves estilo csh(1) del tipo {a,b}. Las expresiones de llaves pueden anidarse. Por lo tanto, por ejemplo, especificar el patrón "{foo/{,cat,dog},bar}" devolvería los mismos resultados que cuatro llamadas separadas a glob() usando las cadenas: "foo/", "foo/cat", "foo/dog", y "bar".
GLOB_NOMAGIC
Si el patrón no contiene metacaracteres, entonces debe devolverse como la única palabra coincidente, incluso si no existe ningún archivo con ese nombre.
GLOB_TILDE
Realizar la expansión de tilde. Si una tilde ('~') es el único carácter en el patrón, o una tilde inicial va seguida inmediatamente de una barra inclinada ('/'), entonces el directorio de inicio del llamador se sustituye por la tilde. Si una tilde inicial va seguida de un nombre de usuario (por ejemplo, "~andrea/bin"), entonces la tilde y el nombre de usuario son sustituidos por el directorio de inicio de ese usuario. Si el nombre de usuario no es válido, o no se puede determinar el directorio de inicio, no se realiza ninguna sustitución.
GLOB_TILDE_CHECK
Esto proporciona un comportamiento similar al de GLOB_TILDE. La diferencia es que si el nombre de usuario no es válido, o no se puede determinar el directorio de inicio, en lugar de usar el patrón en sí como nombre, glob() devuelve GLOB_NOMATCH para indicar un error.
GLOB_ONLYDIR
Esto es una pista para glob() de que el llamador solo está interesado en directorios que coinciden con el patrón. Si la implementación puede determinar fácilmente información del tipo de archivo, los archivos que no son directorios no se devuelven al llamador. Sin embargo, el llamador aún debe comprobar que los archivos devueltos son directorios. (El propósito de esta bandera es simplemente optimizar el rendimiento cuando el llamador solo está interesado en directorios).

Si errfunc no es NULL, se llamará en caso de error con los argumentos epath, un puntero a la ruta que falló, y eerrno, el valor de errno devuelto por una de las llamadas a opendir(3), readdir(3), o stat(2). Si errfunc devuelve un valor distinto de cero, o si GLOB_ERR está establecido, glob() terminará después de la llamada a errfunc.

Al retornar exitosamente, pglob->gl_pathc contiene el número de nombres de ruta coincidentes y pglob->gl_pathv contiene un puntero a la lista de punteros a los nombres de ruta coincidentes. La lista de punteros está terminada por un puntero nulo.

Es posible llamar a glob() varias veces. En ese caso, la bandera GLOB_APPEND debe estar establecida en flags en las invocaciones segunda y posteriores.

Como extensión GNU, pglob->gl_flags se establece en las banderas especificadas, o con GLOB_MAGCHAR si se encontraron metacaracteres.

VALOR DE RETORNO

Al completarse con éxito, glob() devuelve cero. Otros posibles retornos son:

GLOB_NOSPACE
por quedarse sin memoria,
GLOB_ABORTED
por un error de lectura, y
GLOB_NOMATCH
por no encontrar coincidencias.

ATRIBUTOS

Para una explicación de los términos utilizados en esta sección, consulte attributes(7).

Interfaz Atributo Valor
glob () Seguridad de hilos MT-Unsafe race:utent env sig:ALRM timer locale
globfree () Seguridad de hilos MT-Safe

En la tabla anterior, utent en race:utent

> indica que si alguna de las funciones setutent(3), getutent(3), o endutent(3) se usa en paralelo en diferentes hilos de un programa, podrían ocurrir condiciones de carrera. glob() llama a esas funciones, por lo que usamos race:utent para recordar a los usuarios.

ESTÁNDARES

POSIX.1-2008.

HISTORIA

POSIX.1-2001, POSIX.2.

NOTAS

Los elementos de la estructura gl_pathc y gl_offs están declarados como size_t en glibc 2.1, como deberían ser según POSIX.2, pero están declarados como int en glibc 2.0.

ERRORES

La función glob() puede fallar debido a fallos en las llamadas a funciones subyacentes, como malloc(3) o opendir(3). Estas almacenarán su código de error en errno.

EJEMPLOS

Un ejemplo de uso es el siguiente código, que simula escribir


ls -l *.c ../*.c

en el shell:


glob_t globbuf;
globbuf.gl_offs = 2;
glob("*.c", GLOB_DOOFFS, NULL, &globbuf);
glob("../*.c", GLOB_DOOFFS | GLOB_APPEND, NULL, &globbuf);
globbuf.gl_pathv[0] = "ls";
globbuf.gl_pathv[1] = "-l";
execvp("ls", &globbuf.gl_pathv[0]);
