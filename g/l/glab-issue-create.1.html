NOMBRE

glab-issue-create - Crear un problema.

SINOPSIS

glab issue create [flags]

DESCRIPCIÓN

Crear un problema.

OPCIONES

-a, --assignee=[] Asignar el problema a personas por sus nombres de usuario. Se pueden separar varios nombres de usuario por comas o especificarlos repitiendo la bandera.

-c, --confidential[=false] Establecer un problema como confidencial. (predeterminado false)

-d, --description="" Descripción del problema.

--due-date="" Una fecha en formato 'YYYY-MM-DD'.

--epic=0 ID de la épica a la que añadir el problema.

-l, --label=[] Añadir etiqueta por nombre. Se pueden separar varias etiquetas por comas o especificarlas repitiendo la bandera.

--link-type="relates_to" Tipo de enlace del problema

--linked-issues=[] Los IIDs de los problemas a los que este problema se enlaza. Se pueden separar varios IIDs por comas o especificarlos repitiendo la bandera.

--linked-mr=0 El IID de una solicitud de fusión en la que resolver todos los problemas.

-m, --milestone="" El ID global o título de una hito a asignar.

--no-editor[=false] No abrir el editor para introducir una descripción. Si se establece a true, utiliza el prompt. (predeterminado false)

--recover[=false] Guardar las opciones en un archivo si el problema no se puede crear. Si el archivo existe, las opciones se cargarán desde el archivo de recuperación. (EXPERIMENTAL)

-e, --time-estimate="" Establecer estimación de tiempo para el problema.

-s, --time-spent="" Establecer tiempo empleado en el problema.

-t, --title="" Título del problema.

--web[=false] Continuar la creación del problema con la interfaz web.

-w, --weight=0 Peso del problema. Los valores válidos son mayores o iguales a 0.

-y, --yes[=false] No pedir confirmación para enviar el problema.

OPCIONES HEREDADAS DE COMANDOS PADRE

-h, --help[=false] Mostrar ayuda para este comando.

-R, --repo="" Seleccionar otro repositorio. Se puede usar el formato PROPIETARIO/REPO o GRUPO/NAMESPACE/REPO. También acepta URL completa o URL de Git.

EJEMPLO

$ glab issue create
$ glab issue new
$ glab issue create -m release-2.0.0 -t "necesitamos esta característica" --label important
$ glab issue new -t "Corregir CVE-YYYY-XXXX" -l security --linked-mr 123
$ glab issue create -m release-1.0.1 -t "corrección de seguridad" --label security --web --recover
