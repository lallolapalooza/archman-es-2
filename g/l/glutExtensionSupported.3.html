glutExtensionSupported(3)

Paquete: freeglut

Licencias: X11

glutExtensionSupported(3) freeglut glutExtensionSupported(3)

NOMBRE

glutExtensionSupported - ayuda a determinar fácilmente si una extensión de OpenGL dada es compatible.

SINTAXIS

int glutExtensionSupported(char *extension);

ARGUMENTOS

extension
Nombre de la extensión de OpenGL.

DESCRIPCIÓN

glutExtensionSupported ayuda a determinar fácilmente si una extensión de OpenGL dada es compatible o no. El parámetro de extensión nombra la extensión a consultar. Las extensiones compatibles también se pueden determinar con glGetString(GL_EXTENSIONS), pero glutExtensionSupported realiza el análisis correcto de la cadena devuelta.

glutExtensionSupported devuelve un valor distinto de cero si la extensión es compatible, cero si no lo es.

Debe haber una ventana actual válida para llamar a glutExtensionSupported.

glutExtensionSupported solo devuelve información sobre extensiones de OpenGL. Esto significa que las extensiones dependientes del sistema de ventanas (por ejemplo, extensiones GLX) no son informadas por glutExtensionSupported.

EJEMPLO

Aquí hay un ejemplo de uso de glutExtensionSupported:

  if (!glutExtensionSupported("GL_EXT_texture")) {
    fprintf(stderr, "¡Falta la extensión de textura!\n");
    exit(1);
  }
Note que el argumento del nombre incluye tanto el prefijo GL como el prefijo de familia de extensión (EXT).

VER TAMBIÉN

glutGet, glGetString
