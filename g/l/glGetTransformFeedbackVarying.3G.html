NOMBRE

glGetTransformFeedbackVarying - obtener información sobre variables variantes seleccionadas para feedback de transformación

ESPECIFICACIÓN C

void glGetTransformFeedbackVarying(GLuint program, GLuint index, GLsizei bufSize, GLsizei *length, GLsizei *size, GLenum *type, char *name);

PARÁMETROS

program

El nombre del objeto de programa objetivo.

index

El índice de la variable variante cuya información se debe obtener.

bufSize

El número máximo de caracteres, incluido el terminador nulo, que se pueden escribir en name.

length

La dirección de una variable que recibirá el número de caracteres escritos en name, excluyendo el terminador nulo. Si length es NULL, no se devuelve ninguna longitud.

size

La dirección de una variable que recibirá el tamaño de la variable variante.

type

La dirección de una variable que recibirá el tipo de la variable variante.

name

La dirección de un búfer en el que se escribirá el nombre de la variable variante.

DESCRIPCIÓN

La información sobre el conjunto de variables variantes en un programa enlazado que se capturarán durante el feedback de transformación puede obtenerse llamando a glGetTransformFeedbackVarying. glGetTransformFeedbackVarying proporciona información sobre la variable variante seleccionada por index. Un index de 0 selecciona la primera variable variante especificada en la matriz varyings pasada a glTransformFeedbackVaryings(), y un index del valor de GL_TRANSFORM_FEEDBACK_VARYINGS menos uno selecciona la última de dichas variables.

El nombre de la variable variante seleccionada se devuelve como una cadena terminada en nulo en name. El número real de caracteres escritos en name, excluyendo el terminador nulo, se devuelve en length. Si length es NULL, no se devuelve ninguna longitud. El número máximo de caracteres que se pueden escribir en name, incluido el terminador nulo, se especifica por bufSize.

La longitud del nombre de variable variante más largo en el programa se indica en GL_TRANSFORM_FEEDBACK_VARYING_MAX_LENGTH, que se puede consultar con glGetProgram().

Para la variable variante seleccionada, su tipo se devuelve en type. El tamaño de la variable variante se devuelve en size. El valor en size está en unidades del tipo devuelto en type. El tipo devuelto puede ser cualquiera de los tipos de atributos escalares, vectoriales o matriciales devueltos por glGetActiveAttrib(). Si ocurrió un error, los parámetros de retorno length, size, type y name no se modificarán. Este comando devolverá tanta información sobre las variables variantes como sea posible. Si no hay información disponible, length se establecerá en cero y name será una cadena vacía. Esta situación podría surgir si se llama a glGetTransformFeedbackVarying después de un enlace fallido.

ERRORES

GL_INVALID_VALUE se genera si program no es el nombre de un objeto de programa.

GL_INVALID_VALUE se genera si index es mayor o igual al valor de GL_TRANSFORM_FEEDBACK_VARYINGS.

GL_INVALID_OPERATION se genera si program no ha sido enlazado.

OBTENCIÓNES ASOCIADAS

glGetProgram() con el argumento GL_TRANSFORM_FEEDBACK_VARYING_MAX_LENGTH.
