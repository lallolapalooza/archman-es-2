DESCRIPCIÓ

N

glFlushMappedBufferRange indica que se han realizado modificaciones en un rango de un objeto buffer mapeado. El objeto buffer debe haber sido mapeado previamente con el GL_MAP_FLUSH_EXPLICIT_BIT

flag.

offset y length indican el subrango modificado del mapeo, en unidades básicas de máquina. El subrango especificado para vaciar es relativo al inicio del rango actualmente mapeado del buffer. Estos comandos pueden llamarse múltiples veces para indicar subrangos distintos del mapeo que requieren ser

vaciados.

Si un rango de buffer está mapeado con GL_MAP_PERSISTENT_BIT y GL_MAP_FLUSH_EXPLICIT_BIT establecidos, entonces estos comandos pueden llamarse para asegurar que los datos escritos por el cliente en la región vaciada se haga

n visibles para el servidor. Los datos escritos en un almacén coherente siempre s
e harán visibles para el servidor después de un período de tiempo no especificado.

NOTA

S

Los objetivos GL_DISPATCH_INDIRECT_BUFFER y GL_SHADER_STORAGE_BUFFER están disponibles solo si la versión de GL es 4.3 o

superior.

El objetivo GL_QUERY_BUFFER está disponible solo

si la versión de G
L es 4.4 o superior.

ERRORE

S

GL_INVALID_ENUM es generado por glFlushMappedBufferRange si target no es uno de los objetivos de enlazado de buffers listados

arriba.

GL_INVALID_OPERATION es generado por glFlushMappedBufferRange si cero está enlazado a target

.

GL_INVALID_OPERATION es generado por glFlushMappedNamedBufferRange si buffer no es el nombre de un objeto buffer

existente.

GL_INVALID_VALUE es generado si offset o length es negativo, o si offset + length excede el tamaño del

mapeo.

GL_INVALID_OPERATION es generado si el objeto buffer no está mapeado, o está mapeado sin el GL_MAP_FLUSH_EXP

LICIT_BIT
flag.
