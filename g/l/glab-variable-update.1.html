NOMBRE

glab-variable-update - Actualiza una variable existente para un proyecto o grupo.

SINOPSIS

glab variable update [flags]

DESCRIPCIÓN

Actualiza una variable existente para un proyecto o grupo.

OPCIONES

-d, --description="" Establece la descripción de una variable.

-g, --group="" Establece la variable para un grupo.

-m, --masked[=false] Indica si la variable está enmascarada.

-p, --protected[=false] Indica si la variable está protegida.

-r, --raw[=false] Indica si la variable se trata como una cadena de texto sin procesar.

-s, --scope="" El environment_scope de la variable. Valores: all (), o entornos específicos.

-t, --type="env_var" El tipo de una variable: env_var, file.

-v, --value="" El valor de una variable.

OPCIONES HEREDADAS DE COMANDOS PADRE

-h, --help[=false] Muestra la ayuda para este comando.

-R, --repo="" Selecciona otro repositorio. Puede usar el formato PROPIETARIO/REPO o GRUPO/NAMESPACE/REPO. También acepta una URL completa o una URL Git.

EJEMPLO

$ glab variable update CON_ARGUMENTO "algun valor"
$ glab variable update DESDE_FLAG -v "algun valor"
$ glab variable update DESDE_ENV_CON_ARGUMENTO "${VAR_ENTORNO}"
$ glab variable update DESDE_ENV_CON_FLAG -v"${VAR_ENTORNO}"
$ glab variable update DESDE_ARCHIVO < secreto.txt
$ cat archivo.txt | glab variable update TOKEN_SERVIDOR
$ cat token.txt | glab variable update TOKEN_GRUPO -g mi-grupo --scope=prod
