Especifica una constante simbólica, una de GL_VENDOR, GL_RENDERER, GL_VERSION o GL_SHADING_LANGUAGE_VERSION. Adicionalmente, glGetStringi acepta el token GL_EXTENSIONS

DESCRIPCIÓ

N

glGetString devuelve un puntero a una cadena estática que describe algún aspecto de la conexión GL actual. name puede ser uno de los

siguientes:

GL_VENDO

R
Devuelve la empresa responsable de esta implementación de GL. Este nombre no cambia de una versión a
otra.

GL_RENDERE

R
Devuelve el nombre del renderizador. Este nombre es típicamente específico de una configuración particular de una plataforma de hardware. No cambia de una versión a
otra.

GL_VERSIO

N
Devuelve un número de versión o de
lanzamiento.

GL_SHADING_LANGUAGE_VERSIO

N
Devuelve un número de versión o de lanzamiento para el lenguaje de
sombreado.

glGetStringi devuelve un puntero a una cadena estática indexada por index. name puede ser uno de los

siguientes:

GL_EXTENSION

S
Solo para glGetStringi, devuelve la cadena de extensiones soportadas por la implementación en index
.

Cadenas GL_VENDOR y GL_RENDERER juntas especifican únicamente una plataforma. No cambian de una versión a otra y deben ser usadas por los algoritmos de reconocimiento de

plataforma.

Las cadenas GL_VERSION y GL_SHADING_LANGUAGE_VERSION comienzan con un número de versión. El número de versión usa una de estas

formas:

número_mayor.número_menor número_mayor.número_menor.número_lanzamient

o

Puede seguir información específica del proveedor después del número de versión. Su formato depende de la implementación, pero un espacio siempre separa el número de versión y la información específica del

proveedor.

Todas las cadenas e

stán terminadas co
n un carácter nulo.
