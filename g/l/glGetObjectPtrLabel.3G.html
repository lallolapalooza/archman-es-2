NOMBRE

glGetObjectPtrLabel - recuperar la etiqueta de un objeto de sincronización identificado por un puntero

ESPECIFICACIÓN C

void glGetObjectPtrLabel(void * ptr, GLsizei bufSize, GLsizei * length, char * label);

PARÁMETROS

ptr

El nombre del objeto de sincronización cuya etiqueta se va a recuperar.

bufSize

La longitud del búfer cuya dirección está en label.

length

La dirección de una variable para recibir la longitud de la etiqueta del objeto.

label

La dirección de una cadena que recibirá la etiqueta del objeto.

DESCRIPCIÓN

glGetObjectPtrLabel recupera la etiqueta del objeto de sincronización identificado por ptr.

label es la dirección de una cadena que se utilizará para almacenar la etiqueta del objeto. bufSize especifica el número de caracteres en el array identificado por label. length contiene la dirección de una variable que recibirá el número de caracteres de la etiqueta del objeto. Si length es NULL, se ignora y no se escribe ningún dato. Del mismo modo, si label es NULL, o si bufSize es cero, no se escribe ningún dato en label.

ERRORES

Se genera GL_INVALID_ENUM si identifier no es uno de los tipos de objeto aceptados.

Se genera GL_INVALID_VALUE si ptr no es el nombre de un objeto de sincronización existente.

Se genera GL_INVALID_VALUE si bufSize es cero.

Si no son NULL, length y label deben ser direcciones a las que el cliente tenga acceso de escritura; de lo contrario, puede ocurrir un comportamiento indefinido, incluida la terminación del proceso.

GETS ASOCIADOS

glGet() con el argumento GL_MAX_LABEL_LENGTH.
