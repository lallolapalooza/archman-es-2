NOMBRE

glTexStorage1D, glTextureStorage1D - especificar simultáneamente el almacenamiento para todos los niveles de una textura unidimensional

C ESPECIFICACIÓN

void glTexStorage1D(GLenum target, GLsizei levels, GLenum internalformat, GLsizei width);

void glTextureStorage1D(GLuint texture, GLsizei levels, GLenum internalformat, GLsizei width);

PARÁMETROS

target

Especifica el destino al que se vincula el objeto de textura para glTexStorage1D. Debe ser uno de GL_TEXTURE_1D o GL_PROXY_TEXTURE_1D.

texture

Especifica el nombre del objeto de textura para glTextureStorage1D. El destino efectivo de texture debe ser uno de los valores de destino válidos que no sean proxy anteriores.

levels

Especifica el número de niveles de textura.

internalformat

Especifica el formato interno dimensionado que se utilizará para almacenar los datos de la imagen de textura.

width

Especifica el ancho de la textura, en texels.

DESCRIPCIÓN

glTexStorage1D y glTextureStorage1D especifican los requisitos de almacenamiento para todos los niveles de una textura unidimensional simultáneamente. Una vez que una textura se especifica con este comando, el formato y las dimensiones de todos los niveles se vuelven inmutables, a menos que sea una textura proxy. El contenido de la imagen aún puede modificarse; sin embargo, sus requisitos de almacenamiento no pueden cambiar. Dicha textura se denomina textura de formato inmutable.

Llamar a glTexStorage1D es equivalente, asumiendo que no se generan errores, a ejecutar el siguiente pseudocódigo:

    for (i = 0; i < levels; i++) {
        glTexImage1D(target, i, internalformat, width, 0, format, type, NULL);
        width = max(1, (width / 2));
    }

Llamar a glTextureStorage1D es equivalente al pseudocódigo anterior, donde target es el destino efectivo de texture y es como si texture estuviera vinculado a target a efectos de glTexImage1D.

Dado que no se proporcionan datos de textura reales, los valores utilizados en el pseudocódigo para format y type son irrelevantes y pueden considerarse como cualquier valor que sea legal para el enumerador internalformat elegido. internalformat debe ser uno de los formatos internos dimensionados que se encuentran en la Tabla 1 a continuación, uno de los formatos dimensionados de componente de profundidad GL_DEPTH_COMPONENT32F, GL_DEPTH_COMPONENT24 o GL_DEPTH_COMPONENT16, uno de los formatos combinados de profundidad-plantilla, GL_DEPTH32F_STENCIL8 o GL_DEPTH24_STENCIL8, o el formato solo de plantilla, GL_STENCIL_INDEX8. Tras el éxito, el valor de GL_TEXTURE_IMMUTABLE_FORMAT se convierte en GL_TRUE. El valor de GL_TEXTURE_IMMUTABLE_FORMAT se puede descubrir llamando a glGetTexParameter() con pname establecido en GL_TEXTURE_IMMUTABLE_FORMAT. No se pueden realizar más cambios en las dimensiones o el formato del objeto de textura. El uso de cualquier comando que pueda alterar las dimensiones o el formato del objeto de textura (como glTexImage1D() u otra llamada a glTexStorage1D) generará un error GL_INVALID_OPERATION, incluso si, de hecho, no alterara las dimensiones o el formato del objeto.

Also accepted are the depth and stencil formats:

    GL_DEPTH_COMPONENT16
    GL_DEPTH_COMPONENT24
    GL_DEPTH_COMPONENT32F
    GL_STENCIL_INDEX8
    GL_DEPTH24_STENCIL8
    GL_DEPTH32F_STENCIL8

The width must be between 1 and the maximum allowable texture width for the specified internalformat, in whichever dimension is relevant (see glGetIntegerv).

The levels argument must be between 0 and log2(width) + 1.

If width is not a power of two, then the dimensions of all levels are rounded up to the nearest power of two.

If a proxy target is used, no memory is allocated, and no exceptions are made to the state mentioned below. Instead, the query returns whether such a texture could be created. If the requested texture dimensions or format are not supported by the implementation, glGetError will return GL_NO_ERROR but the query will fail.

ERRORS

GL_INVALID_ENUM is generated if target is not GL_TEXTURE_1D or GL_PROXY_TEXTURE_1D.

GL_INVALID_VALUE is generated if levels is negative, or if width is negative.

GL_INVALID_VALUE is generated if levels is greater than log2(width) + 1.

GL_INVALID_OPERATION is generated if target is GL_TEXTURE_1D and the effective target of texture (if using glTextureStorage1D) is not GL_TEXTURE_1D.

GL_INVALID_OPERATION is generated if levels is not zero when the texture is not already bound.

GL_INVALID_OPERATION is generated if internalformat is not one of the valid sized internal formats.

GL_INVALID_OPERATION is generated if a texture object with the immutable bit set is re-specified.

GL_OUT_OF_MEMORY is generated if the depth of the texture is greater than the available texture units, or if the number of texels requested is too large.

ASSOCIATED FUNCTIONS

glGetTexParameter(), glTexImage1D(), glGenTextures(), glBindTexture(), glDeleteTextures()
