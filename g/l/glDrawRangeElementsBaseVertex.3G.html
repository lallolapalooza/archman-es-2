NOMBRE

glDrawRangeElementsBaseVertex - renderiza primitivas a partir de datos de arrays con un desplazamiento por elemento

ESPECIFICACIÓN EN C

void glDrawRangeElementsBaseVertex(GLenum mode, GLuint start, GLuint end, GLsizei count, GLenum type, void *indices, GLint basevertex);

PARÁMETROS

mode

Especifica qué tipo de primitivas se deben renderizar. Se aceptan los símbolos constantes GL_POINTS, GL_LINE_STRIP, GL_LINE_LOOP, GL_LINES, GL_TRIANGLE_STRIP, GL_TRIANGLE_FAN, GL_TRIANGLES, GL_LINES_ADJACENCY, GL_LINE_STRIP_ADJACENCY, GL_TRIANGLES_ADJACENCY, GL_TRIANGLE_STRIP_ADJACENCY y GL_PATCHES.

start

Especifica el índice mínimo del array contenido en indices.

end

Especifica el índice máximo del array contenido en indices.

count

Especifica el número de elementos a renderizar.

type

Especifica el tipo de los valores en indices. Debe ser uno de GL_UNSIGNED_BYTE, GL_UNSIGNED_SHORT o GL_UNSIGNED_INT.

indices

Especifica un puntero a la ubicación donde se almacenan los índices.

basevertex

Especifica una constante que se debe sumar a cada elemento de indices al seleccionar elementos de los arrays de vértices habilitados.

DESCRIPCIÓN

glDrawRangeElementsBaseVertex es una forma restringida de glDrawElementsBaseVertex(). mode, count y basevertex coinciden con los argumentos correspondientes de glDrawElementsBaseVertex(), con la restricción adicional de que todos los valores en el array indices deben estar entre start y end, inclusive, antes de sumar basevertex. Los valores de índice que se encuentren fuera del rango [start, end] se tratan de la misma manera que glDrawElementsBaseVertex(). El elemento i transferido por la llamada de dibujo correspondiente se tomará del elemento indices[i] + basevertex de cada array habilitado. Si el valor resultante es mayor que el valor máximo representable por type, es como si el cálculo se hubiera convertido a enteros sin signo de 32 bits (con envoltura en condiciones de desbordamiento). La operación no está definida si la suma fuera negativa.

ERRORES

Se genera GL_INVALID_ENUM si mode no es un valor aceptado.

Se genera GL_INVALID_VALUE si count es negativo.

Se genera GL_INVALID_VALUE si end < start.

Se genera GL_INVALID_OPERATION si un shader de geometría está activo y mode es incompatible con el tipo de primitiva de entrada del shader de geometría en el objeto de programa actualmente instalado.

Se genera GL_INVALID_OPERATION si un nombre de objeto de buffer no cero está enlazado a un array habilitado o al array de elementos y el almacén de datos del objeto de buffer está actualmente mapeado.
