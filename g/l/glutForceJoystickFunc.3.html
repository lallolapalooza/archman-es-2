glutForceJoystickFunc(3)

Paquete: freeglut

Licencias: X11

glutForceJoystickFunc(3) freeglut glutForceJoystickFunc(3)

NOMBRE

glutForceJoystickFunc - fuerza la llamada de retorno del joystick de la ventana actual para que se ejecute.

SINTAXIS

void glutForceJoystickFunc(void);

DESCRIPCIÓN

glutForceJoystickFunc fuerza la llamada de retorno del joystick de la ventana actual para que se ejecute, informando del último estado del joystick.

La llamada de retorno del joystick se ejecuta ya sea debido a la sondeo del joystick al intervalo de tiempo uniforme establecido por el intervalo de sondeo de glutJoystickFunc (especificado en milisegundos) o en respuesta a la llamada a glutForceJoystickFunc. Si el intervalo de sondeo es no positivo, no se realiza ningún sondeo del joystick y la aplicación GLUT debe llamar frecuentemente (generalmente desde una llamada de retorno inactiva) a glutForceJoystickFunc.

La llamada de retorno del joystick se ejecutará una vez (si existe) por cada vez que se llame a glutForceJoystickFunc. La llamada de retorno se realiza desde glutJoystickFunc. Es decir, cuando glutJoystickFunc regrese, la llamada de retorno ya habrá ocurrido.

NOTAS DE IMPLEMENTACIÓN DE GLUT PARA X11

La implementación actual de GLUT para X11 soporta la API del joystick, pero no la entrada real del joystick. Una implementación futura de GLUT para X11 puede añadir soporte para joysticks.

NOTAS DE IMPLEMENTACIÓN DE GLUT PARA WIN32

La implementación actual de GLUT para Win32 soporta la API del joystick y la entrada del joystick, pero lo hace a través de la anticuada API de Multimedia de Win32 joySetCapture y joyGetPosEx. El soporte actual de joystick de GLUT para Win32 tiene todas las limitaciones del soporte de joystick de la API de Multimedia de Win32. Una implementación futura de GLUT para Win32 puede utilizar DirectInput.
