NOMBRE

glGetProgramResourceLocation - consulta la ubicación de un recurso con nombre dentro de un programa

ESPECIFICACIÓN C

GLint glGetProgramResourceLocation(GLuint program, GLenum programInterface, const char * name);

PARÁMETROS

program

El nombre de un objeto de programa cuyos recursos se van a consultar.

programInterface

Un token que identifica la interfaz dentro de program que contiene el recurso llamado name.

name

El nombre del recurso cuya ubicación se va a consultar.

DESCRIPCIÓN

glGetProgramResourceLocation devuelve la ubicación asignada a la variable llamada name en la interfaz programInterface del objeto de programa program. program debe ser el nombre de un programa que se haya enlazado correctamente. programInterface debe ser uno de los siguientes: GL_UNIFORM, GL_PROGRAM_INPUT, GL_PROGRAM_OUTPUT, GL_VERTEX_SUBROUTINE_UNIFORM, GL_TESS_CONTROL_SUBROUTINE_UNIFORM, GL_TESS_EVALUATION_SUBROUTINE_UNIFORM, GL_GEOMETRY_SUBROUTINE_UNIFORM, GL_FRAGMENT_SUBROUTINE_UNIFORM, GL_COMPUTE_SUBROUTINE_UNIFORM, o GL_TRANSFORM_FEEDBACK_BUFFER.

Se devolverá el valor -1 si ocurre un error, si name no identifica una variable activa en programInterface, o si name identifica una variable activa que no tiene una ubicación válida asignada, como se describe anteriormente. Las ubicaciones devueltas por estos comandos son las mismas ubicaciones devueltas al consultar las propiedades del recurso GL_LOCATION y GL_LOCATION_INDEX.

Una cadena proporcionada a glGetProgramResourceLocation se considera una coincidencia con una variable activa si:

•la cadena coincide exactamente con el nombre de la variable activa
•si la cadena identifica el nombre base de un array activo, donde la cadena coincidiría exactamente con el nombre de la variable si se añadiera el sufijo "[0]" a la cadena
•si la cadena identifica un elemento activo del array, donde la cadena termina con la concatenación del carácter "[", un entero sin signo "+", ceros iniciales adicionales, ni espacios en blanco que identifique un elemento de array, el entero es menor que el número de elementos activos de la variable de array, y donde la cadena coincidiría exactamente con el nombre enumerado del array si el entero decimal fuera reemplazado por cero.

Cualquier otra cadena se considera que no identifica una variable activa. Si la cadena especifica un elemento de una variable de array, glGetProgramResourceLocation devuelve la ubicación asignada a ese elemento. Si especifica el nombre base de un array, identifica los recursos asociados con el primer elemento del array.

ERRORES

Se genera GL_INVALID_VALUE si program no es el nombre de un objeto de programa existente.

Se genera GL_INVALID_ENUM si programInterface no es uno de los tipos de interfaz aceptados.

Se genera GL_INVALID_OPERATION si program no se ha enlazado correctamente.
