NOMBRE

glWaitSync - instruye al servidor GL a bloquear hasta que el objeto sync especificado se active

ESPECIFICACIÓN C

void glWaitSync(GLsync sync, GLbitfield flags, GLuint64 timeout);

PARÁMETROS

sync

Especifica el objeto sync sobre el cual esperar su estado.

flags

Un campo de bits que controla el comportamiento de vaciado del comando. flags puede ser cero.

timeout

Especifica el tiempo de espera que el servidor debe esperar antes de continuar. timeout debe ser GL_TIMEOUT_IGNORED.

DESCRIPCIÓN

glWaitSync hace que el servidor GL se bloquee y espere hasta que sync se active. sync es el nombre de un objeto sync existente sobre el cual esperar. flags y timeout actualmente no se usan y deben establecerse en cero y en el valor especial GL_TIMEOUT_IGNORED, respectivamente[1]. glWaitSync siempre esperará no más que un tiempo de espera dependiente de la implementación. La duración de este tiempo de espera en nanosegundos se puede consultar llamando a glGet() con el parámetro GL_MAX_SERVER_WAIT_TIMEOUT. Actualmente no hay forma de determinar si glWaitSync se desbloqueó porque expiró el tiempo de espera o porque el objeto sync sobre el que se estaba esperando se activó.

Si ocurre un error, glWaitSync no provoca que el servidor GL se bloquee.

NOTAS

glWaitSync solo está disponible si la versión de GL es 3.2 o superior.

ERRORES

Se genera GL_INVALID_VALUE si sync no es el nombre de un objeto sync.

Se genera GL_INVALID_VALUE si flags no es cero.

Se genera GL_INVALID_VALUE si timeout no es GL_TIMEOUT_IGNORED.
