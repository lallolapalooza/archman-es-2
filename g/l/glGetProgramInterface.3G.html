NOMBRE

glGetProgramInterface - consulta una propiedad de una interfaz en un programa

ESPECIFICACIÓN EN C

void glGetProgramInterfaceiv(GLuintprogram, GLenumprogramInterface, GLenumpname, GLint *params);

PARÁMETROS

program

El nombre de un objeto programa cuya interfaz se va a consultar.

programInterface

Un token que identifica la interfaz dentro de program a consultar.

pname

El nombre del parámetro dentro de programInterface a consultar.

params

La dirección de una variable para recuperar el valor de pname para la interfaz del programa.

DESCRIPCIÓN

glGetProgramInterfaceiv consulta la propiedad de la interfaz identificada por programInterface en program, cuyo nombre de propiedad es el dado por pname.

program debe ser el nombre de un objeto programa existente. programInterface es el nombre de la interfaz dentro de program a consultar y debe ser uno de los siguientes valores:

GL_UNIFORM

La consulta se dirige al conjunto de uniforms activos dentro de program.

GL_UNIFORM_BLOCK

La consulta se dirige al conjunto de bloques de uniforms activos dentro de program.

GL_ATOMIC_COUNTER_BUFFER

La consulta se dirige al conjunto de puntos de enlace de búfer de contadores atómicos activos dentro de program.

GL_PROGRAM_INPUT

La consulta se dirige al conjunto de variables de entrada activas utilizadas por la primera etapa del shader de program. Si program contiene múltiples etapas de shader, las variables de entrada de cualquier etapa distinta de la primera no serán enumeradas.

GL_PROGRAM_OUTPUT

La consulta se dirige al conjunto de variables de salida activas producidas por la última etapa del shader de program. Si program contiene múltiples etapas de shader, las variables de salida de cualquier etapa distinta de la última no serán enumeradas.

GL_VERTEX_SUBROUTINE, GL_TESS_CONTROL_SUBROUTINE, GL_TESS_EVALUATION_SUBROUTINE, GL_GEOMETRY_SUBROUTINE, GL_FRAGMENT_SUBROUTINE, GL_COMPUTE_SUBROUTINE

La consulta se dirige al conjunto de subrutinas activas para las etapas de shader de vértice, control de teselación, evaluación de teselación, geometría, fragmento y cómputo de program, respectivamente.

GL_VERTEX_SUBROUTINE_UNIFORM, GL_TESS_CONTROL_SUBROUTINE_UNIFORM, GL_TESS_EVALUATION_SUBROUTINE_UNIFORM, GL_GEOMETRY_SUBROUTINE_UNIFORM, GL_FRAGMENT_SUBROUTINE_UNIFORM, GL_COMPUTE_SUBROUTINE_UNIFORM

La consulta se dirige al conjunto de variables uniformes de subrutina activas utilizadas por las etapas de shader de vértice, control de teselación, evaluación de teselación, geometría, fragmento y cómputo de program, respectivamente.

GL_TRANSFORM_FEEDBACK_VARYING

La consulta se dirige al conjunto de variables de salida de la última etapa no fragmentaria de program que serían capturadas si la transform feedback estuviera activa.

GL_BUFFER_VARIABLE

La consulta se dirige al conjunto de variables de búfer activas utilizadas por program.

GL_SHADER_STORAGE_BLOCK

La consulta se dirige al conjunto de bloques de almacenamiento de shader activos utilizados por program.

GL_TRANSFORM_FEEDBACK_BUFFER

La consulta se dirige al conjunto de puntos de enlace de búfer activos a los que se escriben las variables de salida en la interfaz GL_TRANSFORM_FEEDBACK_VARYING .

pname identifica la propiedad de programInterface a devolver en params.

Si pname es GL_ACTIVE_RESOURCES, el valor devuelto es el número de recursos en la lista de recursos activos para programInterface. Si la lista de recursos activos para programInterface está vacía, se devuelve cero.

Si pname es GL_MAX_NAME_LENGTH, el valor devuelto es la longitud de la cadena de nombre activa más larga para un recurso activo en programInterface. Esta longitud incluye un carácter extra para el terminador nulo. Si la lista de recursos activos para programInterface está vacía, se devuelve cero. Es un error especificar GL_MAX_NAME_LENGTH cuando programInterface es GL_ATOMIC_COUNTER_BUFFER, ya que a los recursos activos de búfer de contadores atómicos no se les asignan cadenas de nombre.

Si pname es GL_MAX_NUM_ACTIVE_VARIABLES, el valor devuelto es el número de variables activas que pertenecen al bloque de interfaz o al recurso de búfer de contador atómico en programInterface con el mayor número de variables activas. Si la lista de recursos activos para programInterface está vacía, se devuelve cero. Cuando pname es GL_MAX_NUM_ACTIVE_VARIABLES, programInterface debe ser GL_UNIFORM_BLOCK, GL_ATOMIC_COUNTER_BUFFER, o GL_SHADER_STORAGE_BLOCK.

Si pname es GL_MAX_NUM_COMPATIBLE_SUBROUTINES, el valor devuelto es el número de subrutinas compatibles que pertenecen a la variable uniforme de subrutina activa en programInterface con el mayor número de subrutinas compatibles. Si la lista de recursos activos para programInterface está vacía, se devuelve cero. Cuando pname es GL_MAX_NUM_COMPATIBLE_SUBROUTINES, programInterface debe ser uno de GL_VERTEX_SUBROUTINE_UNIFORM, GL_TESS_CONTROL_SUBROUTINE_UNIFORM, GL_TESS_EVALUATION_SUBROUTINE_UNIFORM, GL_GEOMETRY_SUBROUTINE_UNIFORM, GL_FRAGMENT_SUBROUTINE_UNIFORM, o GL_COMPUTE_SUBROUTINE_UNIFORM.

ERRORES

Se genera GL_INVALID_ENUM si identifier no es uno de los tipos de objeto aceptados.

Se genera GL_INVALID_VALUE si program no es el nombre de un objeto de sincronización existente.

Se genera GL_INVALID_VALUE si bufSize es cero.

Se genera GL_INVALID_OPERATION si pname es GL_MAX_NAME_LENGTH y programInterface es GL_ATOMIC_COUNTER_BUFFER o GL_TRANSFORM_FEEDBACK_BUFFER, ya que a los recursos activos de búfer de contadores atómicos y de transform feedback no se les asignan cadenas de nombre.

Se genera el error GL_INVALID_OPERATION si pname es GL_MAX_NUM_ACTIVE_VARIABLES y programInterface no es GL_UNIFORM_BLOCK, GL_SHADER_STORAGE_BLOCK, GL_ATOMIC_COUNTER_BUFFER, o GL_TRANSFORM_FEEDBACK_BUFFER.

Si no es NULL, length y label deben ser direcciones a las que el cliente tiene acceso de escritura; de lo contrario, puede ocurrir un comportamiento indefinido, incluyendo la terminación del proceso.
