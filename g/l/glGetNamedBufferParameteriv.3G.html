DESCRIPCIÓ

N

Estas funciones devuelven en data un parámetro seleccionado del objeto de búfer

especificado.

pname nombra un parámetro específico del objeto de búfer, como

sigue:

GL_BUFFER_ACCES

S
params devuelve la política de acceso establecida al mapear el objeto de búfer (el valor del parámetro enum access pasado a glMapBuffer). Si el búfer fue mapeado con glMapBufferRange, la política de acceso se determina traduciendo los bits en ese parámetro access a uno de los enums soportados para glMapBuffer como se describe en la Especificación de
OpenGL.

GL_BUFFER_ACCESS_FLAG

S
params devuelve la política de acceso establecida al mapear el objeto de búfer (el valor del campo de bits del parámetro access pasado a glMapBufferRange). Si el búfer fue mapeado con glMapBuffer, la política de acceso se determina traduciendo los enums en ese parámetro access a los bits correspondientes para glMapBufferRange como se describe en la Especificación de OpenGL. El valor inicial es
cero.

GL_BUFFER_IMMUTABLE_STORAG

E
params devuelve un indicador booleano que indica si el objeto de búfer es inmutable. El valor inicial es GL_FALSE
.

GL_BUFFER_MAPPE

D
params devuelve un indicador que indica si el objeto de búfer está actualmente mapeado. El valor inicial es GL_FALSE
.

GL_BUFFER_MAP_LENGT

H
params devuelve la longitud del mapeo en el objeto de búfer establecido con glMapBuffer*. Las versiones i64v de estas consultas deben usarse para este parámetro. El valor inicial es
cero.

GL_BUFFER_MAP_OFFSE

T
params devuelve el desplazamiento del mapeo en el objeto de búfer establecido con glMapBuffer*. Las versiones i64v de estas consultas deben usarse para este parámetro. El valor inicial es
cero.

GL_BUFFER_SIZ

E
params devuelve el tamaño del objeto de búfer, medido en bytes. El valor inicial es
0.

GL_BUFFER_STORAGE_FLAG

S
params devuelve un campo de bits que indica los flags de almacenamiento para el objeto de búfer. Si el objeto de búfer es inmutable, el valor devuelto será el especificado cuando el almacén de datos fue establecido con glBufferStorage. Si el almacén de datos fue establecido con glBufferData, el valor será GL_MAP_READ_BIT | GL_MAP_WRITE_BIT | GL_DYNAMIC_STORAGE_BIT | GL_MAP_WRITE_BIT. El valor inicial es
cero.

GL_BUFFER_USAG

E
params devuelve el patrón de uso del objeto de búfer. El valor inicial es GL_STATIC_DRA
W
.

NOTA

S

Si se genera un error, no se realiza ningún cambio en el contenido de data

.

El destino GL_ATOMIC_COUNTER_BUFFER está disponible solo si la versión de GL es 4.2 o

superior.

Los destinos GL_DISPATCH_INDIRECT_BUFFER y GL_SHADER_STORAGE_BUFFER están disponibles solo si la versión de GL es 4.3 o

superior.

El destino GL_QUERY_BUFFER está disponible solo

si la versión de GL
es 4.4 o superior.

ERRORE

S

Se genera GL_INVALID_ENUM con glGetBufferParameter* si target no es uno de los destinos de búfer

aceptados.

Se genera GL_INVALID_OPERATION con glGetBufferParameter* si cero está vinculado a target

.

Se genera GL_INVALID_OPERATION con glGetNamedBufferParameter* si buffer no es el nombre de un objeto de búfer

existente.

Se genera GL_INVALID_ENUM si pname no es uno de los nombres de parám

etros del objeto de b
úfer descritos arriba.
