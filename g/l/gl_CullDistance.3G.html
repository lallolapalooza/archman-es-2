NOMBRE

gl_CullDistance - proporciona un mecanismo para controlar el culling por parte del usuario

DECLARACIÓN

gl_CullDistance es un miembro del bloque con nombre gl_PerVertex:

    out gl_PerVertex {
        vec4 gl_Position;
        float gl_PointSize;
        float gl_ClipDistance[];
        float gl_CullDistance[];
    };

En los shaders de fragmentos, se declara intrínsecamente como: in float gl_CullDistance[] ;

DESCRIPCIÓN

La variable gl_CullDistance proporciona un mecanismo para controlar el culling por parte del usuario. El elemento gl_CullDistance[i] especifica una distancia de culling para cada plano i. Una distancia de 0.0 significa que el vértice está en el plano, una distancia positiva significa que el vértice está dentro del volumen de culling y una distancia negativa significa que el punto está fuera del volumen de culling. Las primitivas cuyos vértices tengan todos una distancia de clip negativa para el plano i serán descartadas.

El array gl_CullDistance se predeclara sin tamaño y debe ser dimensionado por el shader, ya sea redeclarándolo con un tamaño o indexándolo solo con expresiones constantes enteras. El tamaño determina el número y el conjunto de distancias de culling habilitadas y puede ser como máximo gl_MaxCullDistances. El número de componentes variables consumidos por gl_CullDistance coincidirá con el tamaño del array. Los shaders que escriban en gl_CullDistance deben escribir todas las distancias habilitadas, o los resultados del culling no están definidos.

Como variable de salida, gl_CullDistance proporciona el lugar para que el shader escriba estas distancias. Como entrada en todos los lenguajes excepto en el de fragmentos, lee los valores escritos en la etapa anterior del shader. En el lenguaje de fragmentos, el array gl_CullDistance contiene valores interpolados linealmente para los valores de vértice escritos por un shader en la variable de salida de vértice gl_CullDistance.

Es un error en tiempo de compilación o en tiempo de enlace que la suma de los tamaños de los arrays gl_ClipDistance y gl_CullDistance sea mayor que gl_MaxCombinedClipAndCullDistances.
