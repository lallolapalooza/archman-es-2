NAME

glGetnUniformfv, glGetnUniformiv, glGetnUniformuiv - return the values of implementation-dependent program resources

C SPECIFICATION

GLint glGetnUniformiv(GLuint program, GLint location, GLsizei bufSize,
    GLint *params);
GLuint glGetnUniformuiv(GLuint program, GLint location, GLsizei bufSize,
    GLuint *params);
GLfloat glGetnUniformfv(GLuint program, GLint location, GLsizei bufSize,
    GLfloat *params);

PARAMETERS

program
Specifies the program object associated with the uniforms.
location
Specifies the location of the uniform variable within the program.
bufSize
Specifies the size of the buffer pointed to by params.
params
A buffer into which the values of the specified uniform variable will be written. For glGetnUniformiv, the buffer must be able to hold at least `bufSize` integers. For glGetnUniformuiv, the buffer must be able to hold at least `bufSize` unsigned integers. For glGetnUniformfv, the buffer must be able to hold at least `bufSize` floating-point values.

DESCRIPTION

These commands retrieve the values of a program object's uniform variables. The commands are similar to glGetUniformfv, glGetUniformiv, and glGetUniformuiv, but they accept an additional argument, bufSize, which specifies the maximum number of items that may be written into params. The commands are guaranteed to write at most bufSize elements.

If the uniform variable specified by location does not exist, or if location is not a valid uniform location, the contents of params are not modified.

If bufSize is less than the number of components in the uniform variable, then only the first bufSize components will be returned.

The location parameter can be obtained by calling glGetUniformLocation().

The results returned depend on the type of the uniform variable. If the uniform variable is a single-component integer type, its value is returned in the first element of params.

If the uniform variable is an array, its values are returned as a contiguous sequence in params. If the uniform variable is an array of `n` elements, the first element of the array will be stored in params[0], the second element in params[1], and so on, up to the minimum of `n` and `bufSize`.

If the uniform variable is a vector type (e.g., vec2, ivec3, uvec4), its components are returned as a contiguous sequence in params. For example, if the uniform variable is a float whose type is vec3, then params[0], params[1], and params[2] will contain the x, y, and z components, respectively.

If the uniform variable is a matrix type (e.g., mat2, mat3, mat4), its column-major elements are returned as a contiguous sequence in params. For example, if the uniform variable is a float whose type is mat3, then params[0] through params[8] contain the elements of the mat3 in column-major order.

glGetnUniformfv returns floating-point values. glGetnUniformiv returns integer values. glGetnUniformuiv returns unsigned integer values.

NOTES

The behavior of glGetnUniformfv, glGetnUniformiv, and glGetnUniformuiv is undefined if program is not a program object.

If location is invalid, no error is generated.

These functions are available in version 3.2 of the OpenGL API, with the exception of glGetnUniformuiv, which is available in version 4.2.

The behavior of these commands is undefined if program does not contain an attached and linked program object.

These commands are part of the OpenGL query mechanism and may be insecure if used to query information about objects created by or accessed by an untrusted application.

ERRORS

GL_INVALID_VALUE is generated if bufSize is negative.

GL_INVALID_OPERATION is generated if program is not a value returned by glCreateProgram, or if program has not been linked successfully.

ASSOCIATED GETS

glGetProgram, glGetProgramiv, glGetProgramInfoLog, glGetUniformLocation
