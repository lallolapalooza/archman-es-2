NOMBRE

glDrawArrays - renderiza primitivas a partir de datos de array

ESPECIFICACIÓN C

void glDrawArrays(GLenum mode, GLint first, GLsizei count);

PARÁMETROS

mode

Especifica qué tipo de primitivas se renderizarán. Se aceptan los símbolos constantes GL_POINTS, GL_LINE_STRIP, GL_LINE_LOOP, GL_LINES, GL_LINE_STRIP_ADJACENCY, GL_LINES_ADJACENCY, GL_TRIANGLE_STRIP, GL_TRIANGLE_FAN, GL_TRIANGLES, GL_TRIANGLE_STRIP_ADJACENCY, GL_TRIANGLES_ADJACENCY y GL_PATCHES.

first

Especifica el índice de inicio en los arrays habilitados.

count

Especifica el número de índices que se renderizarán.

DESCRIPCIÓN

glDrawArrays especifica múltiples primitivas geométricas con muy pocas llamadas a subrutinas. En lugar de llamar a un procedimiento GL para pasar cada vértice, normal, coordenada de textura, bandera de arista o color individual, puede preespecificar arrays separados de vértices, normales y colores y usarlos para construir una secuencia de primitivas con una sola llamada a glDrawArrays.

Cuando se llama a glDrawArrays, utiliza count elementos secuenciales de cada array habilitado para construir una secuencia de primitivas geométricas, comenzando con el elemento first. mode especifica qué tipo de primitivas se construyen y cómo los elementos del array las construyen.

Los atributos de vértice que se modifican mediante glDrawArrays tienen un valor indefinido después de que glDrawArrays retorna. Los atributos que no se modifican permanecen bien definidos.

NOTAS

GL_LINE_STRIP_ADJACENCY, GL_LINES_ADJACENCY, GL_TRIANGLE_STRIP_ADJACENCY y GL_TRIANGLES_ADJACENCY solo están disponibles si la versión de GL es 3.2 o superior.

ERRORES

GL_INVALID_ENUM se genera si mode no es un valor aceptado.

GL_INVALID_VALUE se genera si count es negativo.

GL_INVALID_OPERATION se genera si un objeto de búfer con un nombre distinto de cero está enlazado a un array habilitado y el almacén de datos del objeto de búfer está actualmente mapeado.

GL_INVALID_OPERATION se genera si un shader de geometría está activo y mode es incompatible con el tipo de primitiva de entrada del shader de geometría en el objeto de programa actualmente instalado.
