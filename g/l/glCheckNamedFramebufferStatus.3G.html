GLCHECKFRAMEBUFFERST(3G) [FIXME: manual] GLCHECKFRAMEBUFFERST(3G)

NOMBRE

glCheckFramebufferStatus, glCheckNamedFramebufferStatus - comprueba el estado de integridad de un framebuffer

ESPECIFICACIÓN EN C

GLenum glCheckFramebufferStatus(GLenumtarget);

GLenum glCheckNamedFramebufferStatus(GLuintframebuffer, GLenumtarget);

PARÁMETROS

target

Especifica el objetivo al que está enlazado el framebuffer para glCheckFramebufferStatus, y el objetivo contra el que se comprueba la integridad del framebuffer de framebuffer para glCheckNamedFramebufferStatus.

framebuffer

Especifica el nombre del objeto framebuffer para glCheckNamedFramebufferStatus

DESCRIPCIÓN

glCheckFramebufferStatus y glCheckNamedFramebufferStatus devuelven el estado de integridad de un objeto framebuffer cuando se trata como un framebuffer de lectura o de dibujo, dependiendo del valor de target.

Para glCheckFramebufferStatus, el framebuffer comprobado es el enlazado a target, que debe ser GL_DRAW_FRAMEBUFFER, GL_READ_FRAMEBUFFER o GL_FRAMEBUFFER. GL_FRAMEBUFFER es equivalente a GL_DRAW_FRAMEBUFFER.

Para glCheckNamedFramebufferStatus, framebuffer es cero o el nombre del objeto framebuffer a comprobar. Si framebuffer es cero, se devuelve el estado del framebuffer de lectura o de dibujo predeterminado, según lo determinado por target.

El valor de retorno es GL_FRAMEBUFFER_COMPLETE si el framebuffer especificado está completo. De lo contrario, el valor de retorno se determina como sigue:

•GL_FRAMEBUFFER_UNDEFINED se devuelve si el framebuffer especificado es el framebuffer de lectura o de dibujo predeterminado, pero el framebuffer predeterminado no existe.
•GL_FRAMEBUFFER_INCOMPLETE_ATTACHMENT se devuelve si alguno de los puntos de conexión del framebuffer está incompleto.
•GL_FRAMEBUFFER_INCOMPLETE_MISSING_ATTACHMENT se devuelve si el framebuffer no tiene al menos una imagen conectada a él.
•GL_FRAMEBUFFER_INCOMPLETE_DRAW_BUFFER se devuelve si el valor de GL_FRAMEBUFFER_ATTACHMENT_OBJECT_TYPE es GL_NONE para cualquier punto de conexión de color nombrado por GL_DRAW_BUFFERi.
•GL_FRAMEBUFFER_INCOMPLETE_READ_BUFFER se devuelve si GL_READ_BUFFER no es GL_NONE y el valor de GL_FRAMEBUFFER_ATTACHMENT_OBJECT_TYPE es GL_NONE para el punto de conexión de color nombrado por GL_READ_BUFFER.
•GL_FRAMEBUFFER_UNSUPPORTED se devuelve si la combinación de formatos internos de las imágenes conectadas viola un conjunto de restricciones dependiente de la implementación.
•GL_FRAMEBUFFER_INCOMPLETE_MULTISAMPLE se devuelve si el valor de GL_RENDERBUFFER_SAMPLES no es el mismo para todos los renderbuffers conectados; si el valor de GL_TEXTURE_SAMPLES no es el mismo para todas las texturas conectadas; o, si las imágenes conectadas son una mezcla de renderbuffers y texturas, el valor de GL_RENDERBUFFER_SAMPLES no coincide con el valor de GL_TEXTURE_SAMPLES.
•GL_FRAMEBUFFER_INCOMPLETE_MULTISAMPLE también se devuelve si el valor de GL_TEXTURE_FIXED_SAMPLE_LOCATIONS no es el mismo para todas las texturas conectadas; o, si las imágenes conectadas son una mezcla de renderbuffers y texturas, el valor de GL_TEXTURE_FIXED_SAMPLE_LOCATIONS no es GL_TRUE para todas las texturas conectadas.
•GL_FRAMEBUFFER_INCOMPLETE_LAYER_TARGETS se devuelve si alguna conexión de framebuffer es de capas, y alguna conexión poblada no es de capas, o si todas las conexiones de color pobladas no provienen de texturas del mismo objetivo.

Adicionalmente, si ocurre un error, se devuelve cero.

ERRORES

GL_INVALID_ENUM se genera si target no es GL_DRAW_FRAMEBUFFER, GL_READ_FRAMEBUFFER o GL_FRAMEBUFFER.

GL_INVALID_OPERATION lo genera glCheckNamedFramebufferStatus si framebuffer no es cero o el nombre de un objeto framebuffer existente.
