NOMBRE

glab-config-edit - Abre el archivo de configuración de glab.

SINOPSIS

glab config edit [flags]

DESCRIPCIÓN

Abre el archivo de configuración de glab. El comando utiliza el siguiente orden al elegir el editor a utilizar:

1.
Campo 'glab_editor' en el archivo de configuración
2.
Variable de entorno 'VISUAL'
3.
Variable de entorno 'EDITOR'

OPCIONES

-l, --local[=false] Abre el archivo '.git/glab-cli/config.yml' en lugar del archivo global '~/.config/glab-cli/config.yml'.

OPCIONES HEREDADAS DE COMANDOS PADRE

-h, --help[=false] Muestra la ayuda para este comando.

EJEMPLO

Abre el archivo de configuración con el editor predeterminado
- glab config edit
Abre el archivo de configuración con vim
- EDITOR=vim glab config edit
Establece vim para ser utilizado en todas las futuras invocaciones de 'glab config edit'
- glab config set editor vim
- glab config edit
Abre el archivo de configuración local con el editor predeterminado
- glab config edit -l
