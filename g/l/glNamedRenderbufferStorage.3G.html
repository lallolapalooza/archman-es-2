NOMBRE

glRenderbufferStorage, glNamedRenderbufferStorage - establecer el almacenamiento de datos, el formato y las dimensiones de la imagen de un objeto renderbuffer

ESPECIFICACIÓN C

void glRenderbufferStorage(GLenum target, GLenum internalformat, GLsizei width, GLsizei height);

void glNamedRenderbufferStorage(GLuint renderbuffer, GLenum internalformat, GLsizei width, GLsizei height);

PARÁMETROS

target

Especifica un destino de enlace para la asignación de la función glRenderbufferStorage. Debe ser GL_RENDERBUFFER.

renderbuffer

Especifica el nombre del objeto renderbuffer para la función glNamedRenderbufferStorage.

internalformat

Especifica el formato interno que se utilizará para la imagen del objeto renderbuffer.

width

Especifica el ancho del renderbuffer, en píxeles.

height

Especifica la altura del renderbuffer, en píxeles.

DESCRIPCIÓN

glRenderbufferStorage es equivalente a llamar a glRenderbufferStorageMultisample() con samples establecido a cero, y glNamedRenderbufferStorage es equivalente a llamar a glNamedRenderbufferStorageMultisample con samples establecido a cero.

Para glRenderbufferStorage, el destino de la operación, especificado por target, debe ser GL_RENDERBUFFER. Para glNamedRenderbufferStorage, renderbuffer debe ser un nombre de un objeto renderbuffer existente. internalformat especifica el formato interno que se utilizará para el almacenamiento del objeto renderbuffer y debe ser un formato apto para renderizado de color, profundidad o plantillas. width y height son las dimensiones, en píxeles, del renderbuffer. Tanto width como height deben ser menores o iguales al valor de GL_MAX_RENDERBUFFER_SIZE.

Al tener éxito, glRenderbufferStorage y glNamedRenderbufferStorage eliminan cualquier almacén de datos existente para la imagen del renderbuffer y el contenido del almacén de datos después de llamar a glRenderbufferStorage es indefinido.

ERRORES

GL_INVALID_ENUM es generado por glRenderbufferStorage si target no es GL_RENDERBUFFER.

GL_INVALID_OPERATION es generado por glNamedRenderbufferStorage si renderbuffer no es el nombre de un objeto renderbuffer existente.

GL_INVALID_VALUE es generado si width o height es negativo, o mayor que el valor de GL_MAX_RENDERBUFFER_SIZE.

GL_INVALID_ENUM es generado si internalformat no es un formato apto para renderizado de color, profundidad o plantillas.

GL_OUT_OF_MEMORY es generado si la GL no puede crear un almacén de datos del tamaño solicitado.
