NOMBRE

Glusterd - Demonio de gestión de volúmenes elásticos de Gluster

SINOPSIS

glusterd [OPCIÓN...]

DESCRIPCIÓN

El demonio glusterd se utiliza para la gestión de volúmenes elásticos. El demonio debe ejecutarse en todos los servidores de exportación.

OPCIONES

Opciones básicas

-l <ARCHIVO_LOG>, --log-file=<ARCHIVO_LOG>
Archivo a utilizar para el registro.
-L <NIVEL_LOG>, --log-level=<NIVEL_LOG>
Severidad del registro. Las opciones válidas son TRACE, DEBUG, INFO, WARNING, ERROR y CRITICAL (el valor predeterminado es INFO).
--localtime-logging
Habilita las marcas de tiempo del registro en hora local.
--debug
Ejecuta el programa en modo de depuración. Esta opción establece --no-daemon, --log-level a DEBUG y --log-file a la consola.
-N, --no-daemon
Ejecuta el programa en primer plano.

Opciones varias:

-?, --help
Muestra esta ayuda.
--usage
Muestra un breve mensaje de uso.
-V, --version
Imprime la versión del programa.
