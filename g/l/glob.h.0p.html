NOMBRE

glob.h — tipos de coincidencia de patrones de nombres de ruta

SINOPSIS

#include <glob.h>

DESCRIPCIÓN

El archivo de cabecera <glob.h> definirá las estructuras y constantes simbólicas utilizadas por la función glob().

El archivo de cabecera <glob.h> definirá el tipo de estructura glob_t, que contendrá al menos los siguientes miembros:

size_t   gl_pathc Número de rutas que coinciden con el patrón.
char   **gl_pathv Puntero a una lista de nombres de ruta coincidentes.
size_t   gl_offs  Espacios a reservar al principio de gl_pathv.

El archivo de cabecera <glob.h> definirá el tipo size_t como se describe en <sys/types.h>.

El archivo de cabecera <glob.h> definirá las siguientes constantes simbólicas como valores para el argumento flags:

GLOB_APPEND
Añadir los nombres de ruta generados a los obtenidos previamente.
GLOB_DOOFFS
Especificar cuántos punteros nulos añadir al principio de gl_pathv.
GLOB_ERR
Hacer que glob() devuelva un error.
GLOB_MARK
A cada nombre de ruta que sea un directorio y que coincida con el patrón se le añadirá una barra inclinada (<slash>).
GLOB_NOCHECK
Si el patrón no coincide con ningún nombre de ruta, devolver una lista que solo contenga el patrón.
GLOB_NOESCAPE
Deshabilitar el escape con barra invertida.
GLOB_NOSORT
No ordenar los nombres de ruta devueltos.

El archivo de cabecera <glob.h> definirá las siguientes constantes simbólicas como valores de error:

GLOB_ABORTED
El escaneo se detuvo porque GLOB_ERR estaba establecido o porque (*errfunc)() devolvió un valor distinto de cero.
GLOB_NOMATCH
El patrón no coincide con ningún nombre de ruta existente, y GLOB_NOCHECK no estaba establecido en flags.
GLOB_NOSPACE
Falló un intento de asignar memoria.

Las siguientes funciones serán declaradas y también podrán definirse como macros. Se proporcionarán prototipos de función.

int  glob(const char *restrict, int, int(*)(const char *, int),
         glob_t *restrict);
void globfree(glob_t *);
