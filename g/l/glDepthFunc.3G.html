GLDEPTHFUNC(3G) [FIJAR: manual] GLDEPTHFUNC(3G)

NOMBRE

glDepthFunc - especifica el valor utilizado para las comparaciones del búfer de profundidad

ESPECIFICACIÓN C

void glDepthFunc(GLenum func);

PARÁMETROS

func

Especifica la función de comparación de profundidad. Se aceptan los constantes simbólicos GL_NEVER, GL_LESS, GL_EQUAL, GL_LEQUAL, GL_GREATER, GL_NOTEQUAL, GL_GEQUAL y GL_ALWAYS. El valor inicial es GL_LESS.

DESCRIPCIÓN

glDepthFunc especifica la función utilizada para comparar cada valor de profundidad de píxel entrante con el valor de profundidad presente en el búfer de profundidad. La comparación se realiza solo si las pruebas de profundidad están habilitadas. (Consulte glEnable() y

glDisable de GL_DEPTH_TEST).

func especifica las condiciones bajo las cuales se dibujará el píxel. Las funciones de comparación son las siguientes:

GL_NEVER

Nunca pasa.

GL_LESS

Pasa si el valor de profundidad entrante es menor que el valor de profundidad almacenado.

GL_EQUAL

Pasa si el valor de profundidad entrante es igual al valor de profundidad almacenado.

GL_LEQUAL

Pasa si el valor de profundidad entrante es menor o igual que el valor de profundidad almacenado.

GL_GREATER

Pasa si el valor de profundidad entrante es mayor que el valor de profundidad almacenado.

GL_NOTEQUAL

Pasa si el valor de profundidad entrante no es igual al valor de profundidad almacenado.

GL_GEQUAL

Pasa si el valor de profundidad entrante es mayor o igual que el valor de profundidad almacenado.

GL_ALWAYS

Siempre pasa.

El valor inicial de func es GL_LESS. Inicialmente, las pruebas de profundidad están deshabilitadas. Si las pruebas de profundidad están deshabilitadas o si no existe un búfer de profundidad, es como si la prueba de profundidad siempre pasara.

NOTAS

Incluso si existe el búfer de profundidad y la máscara de profundidad no es cero, el búfer de profundidad no se actualiza si la prueba de profundidad está deshabilitada. Para escribir incondicionalmente en el búfer de profundidad, la prueba de profundidad debe habilitarse y establecerse en GL_ALWAYS.

ERRORES

Se genera GL_INVALID_ENUM si func no es un valor aceptado.

GETS ASOCIADOS

glGet() con el argumento GL_DEPTH_FUNC

glIsEnabled() con el argumento GL_DEPTH_TEST
