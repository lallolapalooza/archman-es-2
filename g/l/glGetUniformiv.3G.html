Si la variable uniforme está definida en el shader como booleano, int o float, se devolverá un único valor. Si está definida como vec2, ivec2 o bvec2, se devolverán dos valores. Si está definida como vec3, ivec3 o bvec3, se devolverán tres valores, y así sucesivamente. Para consultar los valores almacenados en variables uniformes declaradas como arreglos, llame a glGetUniform para cada elemento del arreglo. Para consultar los valores almacenados en variables uniformes declaradas como estructuras, llame

a

Las ubicaciones asignadas a las variables uniformes no se conocen hasta que el objeto programa se enlaza. Después de que se haya producido el enlace, el comando glGetUniformLocatio

n

() puede usarse para obtener la ubicación de una variable uniforme. Este valor de ubicación puede luego pasarse a glGetUniform o glGetnUniform para consultar el valor actual de la variable uniforme. Después de que un objeto programa se haya enlazado correctamente, los valores de índice de las variables uniformes permanecen fijos hasta que se produzca el siguiente comando de enlace.
