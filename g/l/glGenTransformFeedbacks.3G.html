NOMBRE

glGenTransformFeedbacks - reserva nombres de objetos de feedback de transformación

ESPECIFICACIÓN C

void glGenTransformFeedbacks(GLsizei n, GLuint *ids);

PARÁMETROS

n

Especifica el número de nombres de objetos de feedback de transformación a reservar.

ids

Especifica un array en el que se escribirán los nombres reservados.

DESCRIPCIÓN

glGenTransformFeedbacks devuelve n nombres de objetos de feedback de transformación previamente no utilizados en ids. Estos nombres se marcan como usados, solo a efectos de glGenTransformFeedbacks, pero no adquieren estado de feedback de transformación hasta que se enlazan por primera vez.

GETS ASOCIADOS

glGet() con el argumento GL_TRANSFORM_FEEDBACK_BINDING

glIsTransformFeedback()
