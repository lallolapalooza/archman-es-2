NAME

glTexStorage3DMultisample, glTextureStorage3DMultisample - especificar el almacenamiento para una textura de muestreo multivectorial bidimensional

C ESPECIFICACIÓN

void glTexStorage3DMultisample(GLenum target, GLsizei samples, GLenum internalformat, GLsizei width, GLsizei height, GLsizei depth, GLboolean fixedsamplelocations);

void glTextureStorage3DMultisample(GLuint texture, GLsizei samples, GLenum internalformat, GLsizei width, GLsizei height, GLsizei depth, GLboolean fixedsamplelocations);

PARÁMETROS

target

Especifica el objetivo al que está vinculada la textura para glTexStorage3DMultisample. Debe ser uno de GL_TEXTURE_2D_MULTISAMPLE_ARRAY o GL_PROXY_TEXTURE_2D_MULTISAMPLE_ARRAY.

texture

Especifica el nombre del objeto de textura para glTextureStorage3DMultisample. El objetivo efectivo de texture debe ser uno de los valores no proxy válidos de target mencionados anteriormente.

samples

Especifica el número de muestras en la textura.

internalformat

Especifica el formato interno de tamaño a utilizar para almacenar los datos de imagen de la textura.

width

Especifica el ancho de la textura, en texeles.

height

Especifica la altura de la textura, en texeles.

depth

Especifica la profundidad de la textura, en capas.

fixedsamplelocations

Especifica si la imagen utilizará ubicaciones de muestra idénticas y el mismo número de muestras para todos los texeles en la imagen, y si las ubicaciones de muestra no dependerán del formato interno o del tamaño de la imagen.

DESCRIPCIÓN

glTexStorage3DMultisample y glTextureStorage3DMultisample especifican los requisitos de almacenamiento para una textura de muestreo multivectorial bidimensional. Una vez que se especifica una textura con este comando, su formato y dimensiones se vuelven inmutables a menos que sea una textura proxy. Sin embargo, el contenido de la imagen aún puede modificarse; no obstante, sus requisitos de almacenamiento no pueden cambiar. Tales texturas se denominan texturas de formato inmutable.

samples especifica el número de muestras a utilizar para la textura y debe ser mayor que cero y menor o igual al valor de GL_MAX_SAMPLES. internalformat debe ser un formato renderizable de color, renderizable de profundidad o renderizable de estoc. width y height especifican el ancho y la altura, respectivamente, de la textura y depth especifica la profundidad (o el número de capas) de la textura. Si fixedsamplelocations es GL_TRUE, la imagen utilizará ubicaciones de muestra idénticas y el mismo número de muestras para todos los texeles en la imagen, y las ubicaciones de muestra no dependerán del formato interno o del tamaño de la imagen.

ERRORS

GL_INVALID_OPERATION
se genera en glTexStorage3DMultisample si 0 está unido a target.

GL_INVALID_OPERATION se genera en glTextureStorage3DMultisample si texture no es el nombre de un objeto de textura existente.

GL_INVALID_ENUM se genera si internalformat no es un formato válido de renderizado de color, renderizado de profundidad o renderizado de plantilla.

GL_INVALID_ENUM se genera si target o el objetivo efectivo de texture no es uno de los objetivos aceptados descritos anteriormente.

GL_INVALID_VALUE se genera si width o height son menores que 1 o mayores que el valor de GL_MAX_TEXTURE_SIZE.

GL_INVALID_VALUE se genera si depth es menor que 1 o mayor que el valor de GL_MAX_ARRAY_TEXTURE_LAYERS.

GL_INVALID_VALUE se genera si levels es menor que 1.

GL_INVALID_VALUE se genera si samples es cero.

GL_INVALID_OPERATION se genera si samples es mayor que el número máximo de muestras soportado para este target y internalformat.

GL_INVALID_OPERATION se genera si el valor de GL_TEXTURE_IMMUTABLE_FORMAT para la textura unida a target no es GL_FALSE.

ASSOCIATED GETS

glGetInteger con argumentos GL_MAX_TEXTURE_SIZE, GL_MAX_ARRAY_TEXTURE_LEVELS, GL_TEXTURE_VIEW_MIN_LAYER, GL_TEXTURE_VIEW_NUM_LAYERS, o GL_TEXTURE_IMMUTABLE_LEVELS.
