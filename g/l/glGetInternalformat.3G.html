NOMBRE

glGetInternalformat - recupera información sobre el soporte de formatos internos dependiente de la implementación

ESPECIFICACIÓN EN C

void glGetInternalformativ(GLenumtarget, GLenuminternalformat, GLenumpname, GLsizeibufSize, GLint *params);

void glGetInternalformati64v(GLenumtarget, GLenuminternalformat, GLenumpname, GLsizeibufSize, GLint64 *params);

PARÁMETROS

target

Indica el uso del formato interno. target debe ser GL_TEXTURE_1D, GL_TEXTURE_1D_ARRAY, GL_TEXTURE_2D, GL_TEXTURE_2D_ARRAY, GL_TEXTURE_3D, GL_TEXTURE_CUBE_MAP, GL_TEXTURE_CUBE_MAP_ARRAY, GL_TEXTURE_RECTANGLE, GL_TEXTURE_BUFFER, GL_RENDERBUFFER, GL_TEXTURE_2D_MULTISAMPLE o GL_TEXTURE_2D_MULTISAMPLE_ARRAY.

internalformat

Especifica el formato interno sobre el que recuperar información.

pname

Especifica el tipo de información a consultar.

bufSize

Especifica el número máximo de enteros del ancho especificado que pueden escribirse en params por la función.

params

Especifica la dirección de una variable en la que escribir la información recuperada.

DESCRIPCIÓN

glGetInternalformativ y glGetInternalformati64v recuperan información sobre el soporte de formatos internos dependiente de la implementación. target indica el objetivo con el que se usará el formato interno y debe ser uno de GL_RENDERBUFFER, GL_TEXTURE_2D_MULTISAMPLE, o GL_TEXTURE_2D_MULTISAMPLE_ARRAY, correspondiente al uso como búfer de renderizado, textura multisample bidimensional o textura multisample de arreglo bidimensional, respectivamente.

internalformat especifica el formato interno sobre el que recuperar información y debe ser un formato renderizable en color, profundidad o esténcil.

La información recuperada se escribirá en la memoria direccionada por el puntero especificado en params. No se escribirán más de bufSize enteros en esta memoria.

Si pname es GL_NUM_SAMPLE_COUNTS, el número de conteos de muestras que devolvería la consulta de GL_SAMPLES se devolverá en params.

Si pname es GL_SAMPLES, los conteos de muestras soportados para internalformat y target se escriben en params en orden numérico descendente. Solo se devuelven valores positivos. La consulta de GL_SAMPLES con bufSize igual a uno devolverá solo el número máximo de muestras soportadas para este formato. El valor máximo en GL_SAMPLES está garantizado que será al menos el menor de los siguientes:

•El valor de GL_MAX_INTEGER_SAMPLES si internalformat es un formato entero con signo o sin signo.
•El valor de GL_MAX_DEPTH_TEXTURE_SAMPLES si internalformat es un formato renderizable en profundidad o esténcil y target es GL_TEXTURE_2D_MULTISAMPLE, GL_TEXTURE_2D_MULTISAMPLE_ARRAY.
•El valor de GL_MAX_COLOR_TEXTURE_SAMPLES si internalformat es un formato renderizable en color y target es GL_TEXTURE_2D_MULTISAMPLE o GL_TEXTURE_2D_MULTISAMPLE_ARRAY.
•El valor de GL_MAX_SAMPLES.

Si pname es GL_INTERNALFORMAT_SUPPORTED, params se establece en GL_TRUE si internalformat es un formato interno soportado para target y en GL_FALSE en caso contrario.

Si pname es GL_INTERNALFORMAT_PREFERRED, params se establece en GL_TRUE si internalformat es un formato para target preferido por la implementación y en GL_FALSE en caso contrario.

Si pname es GL_INTERNALFORMAT_RED_SIZE, GL_INTERNALFORMAT_GREEN_SIZE, GL_INTERNALFORMAT_BLUE_SIZE, GL_INTERNALFORMAT_ALPHA_SIZE, GL_INTERNALFORMAT_DEPTH_SIZE, GL_INTERNALFORMAT_STENCIL_SIZE, o GL_INTERNALFORMAT_SHARED_SIZE entonces params se establece en las resoluciones reales que se usarían para almacenar los componentes del arreglo de imagen para el recurso en los canales rojo, verde, azul, alfa, profundidad, esténcil y compartido, respectivamente. Si internalformat es un formato interno comprimido, entonces params se establece en la resolución de componente de un formato interno no comprimido que produce una imagen de calidad aproximadamente igual a la del algoritmo de compresión. Si el formato interno no está soportado, o si un componente particular no está presente en el formato, se escribe 0 en params.

Si pname es GL_INTERNALFORMAT_RED_TYPE, GL_INTERNALFORMAT_GREEN_TYPE, GL_INTERNALFORMAT_BLUE_TYPE, GL_INTERNALFORMAT_ALPHA_TYPE, GL_INTERNALFORMAT_DEPTH_TYPE, o GL_INTERNALFORMAT_STENCIL_TYPE entonces params se establece en un token que identifica el tipo de datos usado para almacenar el componente respectivo. Si el internalformat representa un formato interno comprimido, entonces los tipos devueltos especifican cómo se interpretan los componentes después de la descompresión.

Si pname es GL_MAX_WIDTH, GL_MAX_HEIGHT, GL_MAX_DEPTH, o GL_MAX_LAYERS entonces pname se rellena con el ancho, alto, profundidad o número de capas máximo para texturas con formato interno internalformat, respectivamente. Si pname es GL_MAX_COMBINED_DIMENSIONS entonces pname se rellena con las dimensiones combinadas máximas de una textura del formato interno especificado.

Si pname es GL_COLOR_COMPONENTS entonces params se establece en el valor GL_TRUE si el formato interno contiene algún componente de color (es decir, rojo, verde, azul o alfa) y en GL_FALSE en caso contrario. Si pname es GL_DEPTH_COMPONENTS o GL_STENCIL_COMPONENTS entonces params se establece en GL_TRUE si el formato interno contiene un componente de profundidad o esténcil, respectivamente, y en GL_FALSE en caso contrario.

Si pname es GL_COLOR_RENDERABLE, GL_DEPTH_RENDERABLE o GL_STENCIL_RENDERABLE entonces params se establece en GL_TRUE si el formato interno especificado es renderizable en color, profundidad o esténcil, respectivamente, y en GL_FALSE en caso contrario.

Si pname es GL_FRAMEBUFFER_RENDERABLE o GL_FRAMEBUFFER_RENDERABLE_LAYERED entonces params se establece en uno de GL_FULL_SUPPORT, GL_CAVEAT_SUPPORT o GL_NONE para indicar que los adjuntos de framebuffer (adjuntos en capas en el caso de GL_FRAMEBUFFER_RENDERABLE_LAYERED) con ese formato interno son renderizables sin restricciones, renderizables con algunas restricciones o no renderizables en absoluto.

Si pname es GL_FRAMEBUFFER_BLEND, params se establece en GL_TRUE para indicar que el formato interno está soportado para operaciones de mezcla cuando se adjunta a un framebuffer, y en GL_FALSE en caso contrario.

Si pname es GL_READ_PIXELS entonces params se establece en GL_FULL_SUPPORT, GL_CAVEAT_SUPPORT o GL_NONE para indicar que se proporciona soporte completo, soporte limitado o ningún soporte para leer píxeles de adjuntos de framebuffer en el formato interno especificado.

Si pname es GL_READ_PIXELS_FORMAT o GL_READ_PIXELS_TYPE entonces params se rellena con el formato o tipo, respectivamente, más recomendado para obtener la mayor calidad de imagen y rendimiento. Para GL_READ_PIXELS_FORMAT, el valor devuelto en params es un token que se acepta para el argumento format de glReadPixels(). Para GL_READ_PIXELS_TYPE, el valor devuelto en params es un token que se acepta para el argumento type de glReadPixels().

Si pname es GL_TEXTURE_IMAGE_FORMAT o GL_TEXTURE_IMAGE_TYPE entonces params se rellena con el formato o tipo recomendado por la implementación para usar en llamadas a glTexImage2D() y otras funciones similares. Para GL_TEXTURE_IMAGE_FORMAT, params se rellena con un token adecuado para usar como el argumento format de glTexImage2D(). Para GL_TEXTURE_IMAGE_TYPE, params se rellena con un token adecuado para usar como el argumento type de glTexImage2D().

<p class="Pp">Si pname es GL_GET_TEXTURE_IMAGE_FORMAT o GL_GET_TEXTURE_IMAGE_TYPE entonces params se rellena con el formato o tipo recomendado por la implementación para usar en llamadas a glGetTexImage() y otras funciones similares. Para GL_GET_TEXTURE_IMAGE_FORMAT, params se rellena con un token adecuado para usar como el argumento format de glGetTexImage(). Para GL_GET_TEXTURE_IMAGE_TYPE, params se rellena con un token adecuado para usar como el argumento type de glGetTexImage().

Si pname es GL_MIPMAP entonces pname se establece en GL_TRUE para indicar que el formato interno especificado admite mipmaps, y en GL_FALSE en caso contrario.

Si pname es GL_GENERATE_MIPMAP o GL_AUTO_GENERATE_MIPMAP entonces params indica el nivel de soporte para la generación manual o automática de mipmaps para el formato interno especificado, respectivamente. Los valores devueltos pueden ser uno de GL_FULL_SUPPORT, GL_CAVEAT_SUPPORT y GL_NONE para indicar soporte completo, soporte limitado o sin soporte alguno.

Si pname es GL_COLOR_ENCODING entonces la codificación de color del recurso se devuelve en params. Los valores posibles para los búferes de color son GL_LINEAR o GL_SRGB, para componentes de color lineales o codificados en sRGB, respectivamente. Para formatos que no son de color (como profundidad o stencil), o para recursos no soportados, se devuelve el valor GL_NONE .

Si pname es GL_SRGB_READ, o GL_SRGB_WRITE entonces params indica el nivel de soporte para leer y escribir en imágenes codificadas en sRGB, respectivamente. Para GL_SRGB_READ, el soporte para la conversión desde el espacio de color sRGB en operaciones de lectura se devuelve en params y para GL_SRGB_WRITE, el soporte para la conversión al espacio de color sRGB en operaciones de escritura en el recurso se devuelve en params. params puede establecerse en GL_FULL_SUPPORT, GL_CAVEAT_SUPPORT, o GL_NONE para indicar soporte completo, soporte limitado o sin soporte alguno, respectivamente.

Si pname es GL_FILTER entonces params se establece en ya sea GL_TRUE o GL_FALSE para indicar soporte o falta de soporte para modos de filtrado distintos de GL_NEAREST o GL_NEAREST_MIPMAP para el formato interno especificado.

Si pname es GL_VERTEX_TEXTURE, GL_TESS_CONTROL_TEXTURE, GL_TESS_EVALUATION_TEXTURE, GL_GEOMETRY_TEXTURE, GL_FRAGMENT_TEXTURE, o GL_COMPUTE_TEXTURE, entonces el valor escrito en params indica el soporte para el uso del recurso como fuente de texturizado en los etapas de shader de vértice, control de teselado, evaluación de teselado, geometría, fragmento y cómputo, respectivamente. params puede establecerse en GL_FULL_SUPPORT, GL_CAVEAT_SUPPORT o GL_NONE para indicar soporte completo, soporte limitado o sin soporte alguno, respectivamente.

Si pname es GL_TEXTURE_SHADOW, GL_TEXTURE_GATHER o GL_TEXTURE_GATHER_SHADOW entonces el valor escrito en params indica el nivel de soporte para usar el recurso con un muestreador de sombras, en operaciones de recopilación o como un muestreador de sombras en operaciones de recopilación, respectivamente. Los valores devueltos pueden ser GL_FULL_SUPPORT, GL_CAVEAT_SUPPORT o GL_NONE para indicar soporte completo, soporte limitado o sin soporte alguno, respectivamente.

Si pname es GL_SHADER_IMAGE_LOAD, GL_SHADER_IMAGE_STORE o GL_SHADER_IMAGE_ATOMIC entonces el valor devuelto en params indica el nivel de soporte para cargas de imagen, almacenamientos y operaciones atómicas para recursos del formato interno especificado. Los valores devueltos pueden ser GL_FULL_SUPPORT, GL_CAVEAT_SUPPORT o GL_NONE para indicar soporte completo, soporte limitado o sin soporte alguno, respectivamente.

Si pname es GL_IMAGE_TEXEL_SIZE entonces el tamaño de un texel cuando el recurso se usa como una imagen de textura se devuelve en params. Si el recurso no está soportado para imágenes de textura, se devuelve cero.

Si pname es GL_IMAGE_COMPATIBILITY_CLASS entonces la clase de compatibilidad del recurso cuando se usa como una imagen de textura se devuelve en params. Los valores posibles devueltos son GL_IMAGE_CLASS_4_X_32, GL_IMAGE_CLASS_2_X_32, GL_IMAGE_CLASS_1_X_32, GL_IMAGE_CLASS_4_X_16, GL_IMAGE_CLASS_2_X_16, GL_IMAGE_CLASS_1_X_16, GL_IMAGE_CLASS_4_X_8, GL_IMAGE_CLASS_2_X_8, GL_IMAGE_CLASS_1_X_8, GL_IMAGE_CLASS_11_11_10, y GL_IMAGE_CLASS_10_10_10_2, que corresponden a los formatos 4x32, 2x32, 1x32, 4x16, 2x16, 1x16, 4x8, 2x8, 1x8, la clase (a) formato de punto flotante empaquetado 11/11/10, y la clase (b) formatos empaquetados 10/10/10/2, respectivamente. Si el recurso no está soportado para imágenes de textura, GL_NONE es devuelto.

Si pname es GL_IMAGE_PIXEL_FORMAT o GL_IMAGE_PIXEL_TYPE entonces el formato de píxel o el tipo del recurso cuando se usa como una imagen de textura se devuelve en params, respectivamente. En cualquiera de los dos casos, si el recurso no está soportado para imágenes de textura GL_NONE es devuelto.

Si pname es GL_IMAGE_FORMAT_COMPATIBILITY_TYPE, los criterios de coincidencia usados para el recurso cuando se usa como una imagen de textura se devuelven en params. Los valores posibles devueltos en params son GL_IMAGE_FORMAT_COMPATIBILITY_BY_SIZE o GL_IMAGE_FORMAT_COMPATIBILITY_BY_CLASS. Si el recurso no está soportado para imágenes de textura, GL_NONE es devuelto.

Si pname es GL_SIMULTANEOUS_TEXTURE_AND_DEPTH_TEST o GL_SIMULTANEOUS_TEXTURE_AND_STENCIL_TEST, el soporte para usar el recurso tanto como fuente para el muestreo de textura mientras está vinculado como búfer para la prueba de profundidad o stencil, respectivamente, se escribe en params. Los valores posibles devueltos son GL_FULL_SUPPORT, GL_CAVEAT_SUPPORT, o GL_NONE para indicar soporte completo, soporte limitado o sin soporte alguno. Si el recurso o la operación no está soportado, GL_NONE es devuelto.

Si pname es GL_SIMULTANEOUS_TEXTURE_AND_DEPTH_WRITE o GL_SIMULTANEOUS_TEXTURE_AND_STENCIL_WRITE, el soporte para usar el recurso tanto como fuente para el muestreo de textura mientras se realizan escrituras de profundidad o stencil en los recursos, respectivamente, se escribe en params. Los valores posibles devueltos son GL_FULL_SUPPORT, GL_CAVEAT_SUPPORT, o GL_NONE para indicar soporte completo, soporte limitado o sin soporte alguno. Si el recurso o la operación no está soportado, GL_NONE es devuelto.

Si pname es GL_TEXTURE_COMPRESSED entonces GL_TRUE es devuelto en params si internalformat es un formato interno comprimido. GL_FALSE es devuelto en params en caso contrario.

Si pname es GL_TEXTURE_COMPRESSED_BLOCK_WIDTH, GL_TEXTURE_COMPRESSED_BLOCK_HEIGHT o GL_TEXTURE_COMPRESSED_BLOCK_SIZE entonces el ancho, la altura o el tamaño total, respectivamente, de un bloque (en unidades básicas de máquina) se devuelve en params. Si el formato interno no está comprimido, o el recurso no está soportado, se devuelve 0.

Si pname es GL_CLEAR_BUFFER, el nivel de soporte para usar el recurso con glClearBufferData() y glClearBufferSubData() se devuelve en params. Los valores posibles devueltos son GL_FULL_SUPPORT, GL_CAVEAT_SUPPORT, o GL_NONE para indicar soporte completo, soporte limitado o sin soporte alguno, respectivamente. Si el recurso o la operación no está soportado, GL_NONE es devuelto.

Si pname es GL_TEXTURE_VIEW, el nivel de soporte para usar el recurso con el comando glTextureView() se devuelve en params. Los valores posibles devueltos son GL_FULL_SUPPORT, GL_CAVEAT_SUPPORT, o GL_NONE para indicar soporte completo, soporte limitado o sin soporte alguno, respectivamente. Si el recurso o la operación no está soportado, GL_NONE es devuelto.

Si pname es GL_VIEW_COMPATIBILITY_CLASS entonces la clase de compatibilidad del recurso cuando se usa como una vista de textura se devuelve en params. Los valores posibles devueltos son GL_VIEW_CLASS_128_BITS, GL_VIEW_CLASS_96_BITS, GL_VIEW_CLASS_64_BITS, GL_VIEW_CLASS_48_BITS, GL_VIEW_CLASS_32_BITS, GL_VIEW_CLASS_24_BITS, GL_VIEW_CLASS_16_BITS, GL_VIEW_CLASS_8_BITS, GL_VIEW_CLASS_S3TC_DXT1_RGB, GL_VIEW_CLASS_S3TC_DXT1_RGBA, GL_VIEW_CLASS_S3TC_DXT3_RGBA, GL_VIEW_CLASS_S3TC_DXT5_RGBA, GL_VIEW_CLASS_RGTC1_RED, GL_VIEW_CLASS_RGTC2_RG, GL_VIEW_CLASS_BPTC_UNORM, y GL_VIEW_CLASS_BPTC_FLOAT.

Si pname es GL_CLEAR_TEXTURE entonces la presencia de soporte para usar los comandos glClearTexImage() y glClearTexSubImage() con el recurso se escribe en params. Los valores posibles escritos son GL_FULL_SUPPORT, GL_CAVEAT_SUPPORT, o GL_NONE para indicar soporte completo, soporte limitado o sin soporte alguno, respectivamente. Si el recurso o la operación no está soportado, GL_NONE es devuelto.

NAME

glGetInternalformativ, glGetInternalformati64v - query information about implementation-dependent maximums and available formats

C SPECIFICATION

void glGetInternalformativ(GLenum target, GLenum internalformat, GLenum pname, GLsizei bufSize, GLint *params);

void glGetInternalformati64v(GLenum target, GLenum internalformat, GLenum pname, GLsizei bufSize, GLint64 *params);

PARAMETERS

target

    Specifies the renderable target. Must be one of
    GL_RENDERBUFFER, GL_TEXTURE_1D_ARRAY,
    GL_TEXTURE_2D_ARRAY, GL_TEXTURE_2D_MULTISAMPLE,
    GL_TEXTURE_2D_MULTISAMPLE_ARRAY, or
    GL_TEXTURE_CUBE_MAP_ARRAY.

internalformat

    Specifies the internal format of the image to be queried.

pname

    Specifies the symbolic name of the parameter to be returned.
    Must be one of GL_INTERNALFORMAT_SUPPORTED,
    GL_INTERNALFORMAT_RED_SIZE, GL_INTERNALFORMAT_GREEN_SIZE,
    GL_INTERNALFORMAT_BLUE_SIZE, GL_INTERNALFORMAT_ALPHA_SIZE,
    GL_INTERNALFORMAT_DEPTH_SIZE, GL_INTERNALFORMAT_STENCIL_SIZE,
    GL_INTERNALFORMAT_SHARED_SIZE,
    GL_INTERNALFORMAT_RED_TYPE, GL_INTERNALFORMAT_GREEN_TYPE,
    GL_INTERNALFORMAT_BLUE_TYPE, GL_INTERNALFORMAT_ALPHA_TYPE,
    GL_INTERNALFORMAT_DEPTH_TYPE, GL_INTERNALFORMAT_STENCIL_TYPE,
    GL_TEXTURE_IMAGE_FORMAT, GL_TEXTURE_IMAGE_TYPE,
    GL_TEXTURE_IMAGE_FORMAT_COMPATIBILITY_TYPE,
    GL_TEXTURE_VIEW_MIN_LEVEL, GL_TEXTURE_VIEW_NUM_LEVELS,
    GL_TEXTURE_VIEW_MIN_LAYER, GL_TEXTURE_VIEW_NUM_LAYERS,
    GL_IMAGE_COMPATIBILITY_CLASS, GL_IMAGE_PIXEL_FORMAT,
    GL_IMAGE_PIXEL_TYPE, GL_IMAGE_FORMAT_COMPATIBILITY_TYPE,
    GL_SIMULTANEOUS_TEXTURE_AND_DEPTH_TEST,
    GL_SIMULTANEOUS_TEXTURE_AND_STENCIL_TEST,
    GL_SIMULTANEOUS_TEXTURE_AND_DEPTH_WRITE,
    GL_SIMULTANEOUS_TEXTURE_AND_STENCIL_WRITE,
    GL_TEXTURE_COMPRESSED, GL_TEXTURE_COMPRESSED_BLOCK_WIDTH,
    GL_TEXTURE_COMPRESSED_BLOCK_HEIGHT,
    GL_TEXTURE_COMPRESSED_BLOCK_SIZE, GL_CLEAR_BUFFER,
    GL_TEXTURE_VIEW, or GL_VIEW_COMPATIBILITY_CLASS.

bufSize

    Specifies the size of the array pointed to by params.

params

    Returns the requested data.

DESCRIPTION

This function returns information about the implementation's support for a given internal format for a specified renderable target.

The target parameter specifies the renderable target. Currently supported targets are GL_RENDERBUFFER, GL_TEXTURE_1D_ARRAY, GL_TEXTURE_2D_ARRAY, GL_TEXTURE_2D_MULTISAMPLE, GL_TEXTURE_2D_MULTISAMPLE_ARRAY, and GL_TEXTURE_CUBE_MAP_ARRAY.

The internalformat parameter specifies the internal format of the image to be queried. This can be a sized internal format like GL_RGB8 or GL_RGBA32F.

The pname parameter specifies the parameter to be queried. The following symbolic constants are accepted:

GL_INTERNALFORMAT_SUPPORTED
Returns a single value indicating whether the internalformat is supported for the specified target. Returns GL_TRUE if supported, and GL_FALSE otherwise.
GL_INTERNALFORMAT_RED_SIZE
Returns the number of bits used by the red component of the internalformat.
GL_INTERNALFORMAT_GREEN_SIZE
Returns the number of bits used by the green component of the internalformat.
GL_INTERNALFORMAT_BLUE_SIZE
Returns the number of bits used by the blue component of the internalformat.
GL_INTERNALFORMAT_ALPHA_SIZE
Returns the number of bits used by the alpha component of the internalformat.
GL_INTERNALFORMAT_DEPTH_SIZE
Returns the number of bits used by the depth component of the internalformat.
GL_INTERNALFORMAT_STENCIL_SIZE
Returns the number of bits used by the stencil component of the internalformat.
GL_INTERNALFORMAT_SHARED_SIZE
Returns the number of bits shared by the red, green, and blue components of the internalformat.
GL_INTERNALFORMAT_RED_TYPE
Returns the data type of the red component. Possible values include GL_UNSIGNED_NORMALIZED, GL_SIGNED_NORMALIZED, GL_FULL_BITS, GL_FLOAT, etc.
GL_INTERNALFORMAT_GREEN_TYPE
Returns the data type of the green component.
GL_INTERNALFORMAT_BLUE_TYPE
Returns the data type of the blue component.
GL_INTERNALFORMAT_ALPHA_TYPE
Returns the data type of the alpha component.
GL_INTERNALFORMAT_DEPTH_TYPE
Returns the data type of the depth component.
GL_INTERNALFORMAT_STENCIL_TYPE
Returns the data type of the stencil component.
GL_TEXTURE_IMAGE_FORMAT
Returns the texture image format that is compatible with the specified internalformat and target. This can be used with glTexImage2D, glTexImage3D, etc.
GL_TEXTURE_IMAGE_TYPE
Returns the texture image type that is compatible with the specified internalformat and target.
GL_TEXTURE_IMAGE_FORMAT_COMPATIBILITY_TYPE
Returns the texture image format compatibility type. This can be GL_COMPATIBLE or GL_INCOMPATIBLE.
GL_TEXTURE_VIEW_MIN_LEVEL
Returns the minimum level of the texture that can be included in a texture view.
GL_TEXTURE_VIEW_NUM_LEVELS
Returns the number of levels of the texture that can be included in a texture view.
GL_TEXTURE_VIEW_MIN_LAYER
Returns the minimum layer of the texture that can be included in a texture view.
GL_TEXTURE_VIEW_NUM_LAYERS
Returns the number of layers of the texture that can be included in a texture view.
GL_IMAGE_COMPATIBILITY_CLASS
Returns the image format compatibility class of the specified internalformat and target.
GL_IMAGE_PIXEL_FORMAT
Returns the image pixel format that is compatible with the specified internalformat and target. This can be used with functions like glBindImageTexture.
GL_IMAGE_PIXEL_TYPE
Returns the image pixel type that is compatible with the specified internalformat and target.
GL_IMAGE_FORMAT_COMPATIBILITY_TYPE
Returns the image format compatibility type. This can be GL_COMPATIBLE or GL_INCOMPATIBLE.
GL_SIMULTANEOUS_TEXTURE_AND_DEPTH_TEST
Returns a boolean indicating if depth testing can be performed simultaneously with texture access for the specified internalformat and target.
GL_SIMULTANEOUS_TEXTURE_AND_STENCIL_TEST
Returns a boolean indicating if stencil testing can be performed simultaneously with texture access for the specified internalformat and target.
GL_SIMULTANEOUS_TEXTURE_AND_DEPTH_WRITE
Returns a boolean indicating if depth writes can be performed simultaneously with texture access for the specified internalformat and target.
GL_SIMULTANEOUS_TEXTURE_AND_STENCIL_WRITE
Returns a boolean indicating if stencil writes can be performed simultaneously with texture access for the specified internalformat and target.
GL_TEXTURE_COMPRESSED
Returns a boolean indicating whether the specified internalformat is a compressed format.
GL_TEXTURE_COMPRESSED_BLOCK_WIDTH
Returns the width of a compressed texture block in pixels for the specified internalformat.
GL_TEXTURE_COMPRESSED_BLOCK_HEIGHT
Returns the height of a compressed texture block in pixels for the specified internalformat.
GL_TEXTURE_COMPRESSED_BLOCK_SIZE
Returns the size of a compressed texture block in bytes for the specified internalformat.
GL_CLEAR_BUFFER
Returns a boolean indicating whether the specified internalformat can be cleared using glClearBufferiv, glClearBufferuiv, glClearBufferfv, or glClearBufferfi.
GL_TEXTURE_VIEW
Returns a boolean indicating whether the specified internalformat can be used to create texture views.
GL_VIEW_COMPATIBILITY_CLASS
Returns the view compatibility class of the specified internalformat and target. This can be used to determine if texture views can be created from this format.

glGetInternalformativ returns values as GLints. glGetInternalformati64v returns values as GLint64s. This is useful for querying parameters that might exceed the range of a 32-bit integer, such as block sizes for compressed textures.

ERRORS

GL_INVALID_VALUE is generated if bufSize is negative.

GL_INVALID_ENUM is generated if pname is not GL_SAMPLES or GL_NUM_SAMPLE_COUNTS.

GL_INVALID_ENUM is generated if internalformat is not color-, depth-, or stencil-renderable.

GL_INVALID_ENUM is generated if target is not one of GL_TEXTURE_2D_MULTISAMPLE, GL_TEXTURE_2D_MULTISAMPLE_ARRAY or GL_RENDERBUFFER.
