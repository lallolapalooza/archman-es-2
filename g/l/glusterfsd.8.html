NOMBRE

GlusterFS - Sistema de archivos agrupado.

SINOPSIS

glusterfsd [opciones] [punto de montaje]

DESCRIPCIÓN

GlusterFS es un sistema de archivos agrupado capaz de escalar a varios peta-bytes. Agrega varios bloques de almacenamiento sobre interconexiones RDMA de Infiniband o TCP/IP en un único sistema de archivos de red paralelo grande. Los bloques de almacenamiento pueden estar compuestos por cualquier hardware comercial, como servidores x86-64 con RAID SATA-II y HBAs de Infiniband.

GlusterFS es un sistema de archivos totalmente compatible con POSIX. En el lado del cliente, tiene dependencia del paquete FUSE; en el lado del servidor, funciona sin problemas en diferentes sistemas operativos (actualmente soportado en GNU/Linux, Solaris).

OPCIONES

Los argumentos obligatorios u opcionales para las opciones largas también son obligatorios u opcionales para cualquier opción corta correspondiente.

Opciones básicas

-f, --volfile=ARCHIVO_VOLUMEN
Archivo a utilizar como ARCHIVO_VOLUMEN [por defecto: /etc/glusterfs/glusterfs.vol]
-l, --log-file=ARCHIVO_LOG
Archivo a utilizar para el registro [por defecto: /var/log/glusterfs/glusterfs.log]
-L, --log-level=NIVEL_LOG
Severidad del registro. Las opciones válidas son TRACE, DEBUG, INFO, WARNING, ERROR y CRITICAL [por defecto: WARNING]
-s, --volfile-server=SERVIDOR
Servidor del cual obtener el volumen. Esta opción anula la opción --volfile.

Opciones avanzadas

--localtime-logging
Habilita las marcas de tiempo de registro en hora local.
--debug
Ejecutar en modo de depuración. Esta opción establece --no-daemon, --log-level a DEBUG y --log-file a la consola.
-N, --no-daemon
Ejecutar en primer plano.
--read-only
Hace que el sistema de archivos sea de solo lectura.
-p, --pid-file=ARCHIVO_PID
Archivo a utilizar como archivo PID.
-SARCHIVO_SOCKET
Archivo de socket a utilizar para la comunicación entre procesos.
--brick-name DIRECTORIO
Directorio a utilizar como directorio de exportación para GlusterFS.
--brick-port PUERTO
Puerto de ladrillo a registrar con el asignador de puertos de Gluster.
--volfile-id=CLAVE
CLAVE del archivo de volumen a obtener del servidor.
--volfile-server-port=PUERTO
Número de puerto del servidor de volfile.
--volfile-server-transport=TRANSPORTE
Tipo de transporte para obtener el archivo de volumen del servidor [por defecto: tcp].
--volume-name=NOMBRE_VOLUMEN
Nombre del volumen a utilizar para el PUNTO DE MONTAJE [por defecto: el volumen más alto en ARCHIVO_VOLUMEN].
--xlator-option=NOMBRE_VOLUMEN.OPCIÓN=VALOR
Añadir/anular una opción de traductor para un volumen con el valor especificado.

Opciones de Fuse

--attribute-timeout=SEGUNDOS
Establece el tiempo de espera de atributos en SEGUNDOS para los inodos en el módulo del kernel de fuse [por defecto: 1].
--entry-timeout=SEGUNDOS
Establece el tiempo de espera de entrada en SEGUNDOS en el módulo del kernel de fuse [por defecto: 1].
--direct-io-mode=BOLEANO
Habilita/deshabilita el modo direct-io en el módulo de fuse [por defecto: habilitado].
--resolve-gids
Resuelve todos los grupos auxiliares en el traductor de fuse (máximo 32 en caso contrario).
--auto-invalidation=BOLEANO
Controla si el kernel de fuse puede invalidar automáticamente la caché de atributos, dentry y páginas. Deshabilite esto solo si los mismos archivos/directorios no se acceden simultáneamente a través de dos montajes diferentes [por defecto: activado].

Opciones varias

-?, --help
Proporciona esta lista de ayuda.
--usage
Proporciona un breve mensaje de uso.
-V, --version
Imprime la versión del programa.

ARCHIVOS

/etc/glusterfs/*.vol

EJEMPLOS

Iniciar un servidor GlusterFS en localhost con el nombre de volumen foo.

glusterfsd -s localhost --volfile-id foo.server.media-disk-1 -p /var/lib/glusterd/vols/foo/run/server-media-disk-1.pid -S /tmp/<uniqueid>.socket --brick-name /media/disk-1 -l /var/log/glusterfs/bricks/media-disk-1.log --brick-port 24009 --xlator-option foo-server.listen-port=24009
