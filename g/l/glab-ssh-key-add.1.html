NOMBRE

glab-ssh-key-add - Añadir una clave SSH a tu cuenta de GitLab.

SINOPSIS

glab ssh-key add [archivo-clave] [flags]

DESCRIPCIÓN

Crea una nueva clave SSH propiedad del usuario autenticado actualmente.

Requiere la bandera '--title'.

OPCIONES

-e, --expires-at="" La fecha de expiración de la clave SSH. Utiliza el formato ISO 8601: YYYY-MM-DDTHH:MM:SSZ.

-t, --title="" Título de la nueva clave SSH.

-u, --usage-type="auth_and_signing" Ámbito de uso para la clave. Los valores posibles son: 'auth', 'signing' o 'auth_and_signing'. El valor por defecto es 'auth_and_signing'.

OPCIONES HEREDADAS DE COMANDOS PADRE

-h, --help[=false] Mostrar ayuda para este comando.

-R, --repo="" Seleccionar otro repositorio. Puede usar el formato PROPIETARIO/REPO o GRUPO/ESPACIO DE NOMBRES/REPO. También acepta URL completa o URL Git.

EJEMPLO

# Leer clave ssh desde stdin y subirla.
$ glab ssh-key add -t "mi título"
# Leer clave ssh desde un archivo de clave especificado, subirla y establecer el tipo de clave ssh a "autenticación".
$ glab ssh-key add ~/.ssh/id_ed25519.pub -t "mi título" --usage-type "auth"
