GLFRAMEBUFFERTEXTURE(3G) [FIXME: manual] GLFRAMEBUFFERTEXTURE(3G)

NOMBRE

glFramebufferTexture - adjuntar un nivel de un objeto de textura como un buffer lógico de un objeto de framebuffer

ESPECIFICACIÓN C

void glFramebufferTexture(GLenum target, GLenum attachment, GLuint texture, GLint level);

void glFramebufferTexture1D(GLenum target, GLenum attachment, GLenum textarget, GLuint texture, GLint level);

void glFramebufferTexture2D(GLenum target, GLenum attachment, GLenum textarget, GLuint texture, GLint level);

void glFramebufferTexture3D(GLenum target, GLenum attachment, GLenum textarget, GLuint texture, GLint level, GLint layer);

void glNamedFramebufferTexture(GLuint framebuffer, GLenum attachment, GLuint texture, GLint level);

PARÁMETROS

target

Especifica el destino al que está enlazado el framebuffer para todos los comandos *excepto* glNamedFramebufferTexture.

framebuffer

Especifica el nombre del objeto framebuffer para glNamedFramebufferTexture.

attachment

Especifica el punto de adjunción del framebuffer.

textarget

Para glFramebufferTexture1D, glFramebufferTexture2D y glFramebufferTexture3D, especifica qué tipo de textura se espera en el parámetro texture, o para texturas de mapa de cubos, qué cara se va a adjuntar.

texture

Especifica el nombre de un objeto de textura existente para adjuntar.

level

Especifica el nivel mipmap del objeto de textura a adjuntar.

DESCRIPCIÓN

Estos comandos adjuntan un nivel mip o una imagen de un objeto de textura seleccionado como uno de los buffers lógicos del objeto de framebuffer especificado. Las texturas no se pueden adjuntar al framebuffer de dibujo y lectura predeterminados, por lo que no son destinos válidos de estos comandos.

Para todos los comandos *excepto* glNamedFramebufferTexture, el objeto de framebuffer es el que está enlazado a target, que debe ser GL_DRAW_FRAMEBUFFER, GL_READ_FRAMEBUFFER, o GL_FRAMEBUFFER. GL_FRAMEBUFFER es equivalente a GL_DRAW_FRAMEBUFFER.

Para glNamedFramebufferTexture, framebuffer es el nombre del objeto de framebuffer.

attachment especifica la adjunción lógica del framebuffer y debe ser GL_COLOR_ATTACHMENTi, GL_DEPTH_ATTACHMENT, GL_STENCIL_ATTACHMENT o GL_DEPTH_STENCIL_ATTACHMENT. i en GL_COLOR_ATTACHMENTi puede variar de cero al valor de GL_MAX_COLOR_ATTACHMENTS menos uno. Adjuntar un nivel de una textura a GL_DEPTH_STENCIL_ATTACHMENT es equivalente a adjuntar ese nivel tanto a los puntos de adjunción GL_DEPTH_ATTACHMENT *como* a los de GL_STENCIL_ATTACHMENT simultáneamente.

Para glFramebufferTexture1D, glFramebufferTexture2D y glFramebufferTexture3D, textarget especifica qué tipo de textura tiene el nombre texture, y para texturas de mapa de cubos, especifica la cara que se adjuntará. Si texture no es cero, debe ser el nombre de un objeto de textura existente con objetivo efectivo textarget, a menos que sea una textura de mapa de cubos, en cuyo caso textarget debe ser GL_TEXTURE_CUBE_MAP_POSITIVE_X GL_TEXTURE_CUBE_MAP_NEGATIVE_X, GL_TEXTURE_CUBE_MAP_POSITIVE_Y, GL_TEXTURE_CUBE_MAP_NEGATIVE_Y, GL_TEXTURE_CUBE_MAP_POSITIVE_Z, o GL_TEXTURE_CUBE_MAP_NEGATIVE_Z.

Si texture es distinto de cero, el level especificado del objeto de textura llamado texture se adjunta al punto de adjunción del framebuffer llamado por attachment. Para glFramebufferTexture1D, glFramebufferTexture2D y glFramebufferTexture3D, texture debe ser cero o el nombre de una textura existente con un objetivo efectivo de textarget, o texture debe ser el nombre de una textura de mapa de cubos existente y textarget debe ser uno de GL_TEXTURE_CUBE_MAP_POSITIVE_X, GL_TEXTURE_CUBE_MAP_POSITIVE_Y, GL_TEXTURE_CUBE_MAP_POSITIVE_Z, GL_TEXTURE_CUBE_MAP_NEGATIVE_X, GL_TEXTURE_CUBE_MAP_NEGATIVE_Y, o GL_TEXTURE_CUBE_MAP_NEGATIVE_Z.

Si textarget es GL_TEXTURE_RECTANGLE, GL_TEXTURE_2D_MULTISAMPLE, o GL_TEXTURE_2D_MULTISAMPLE_ARRAY, entonces level debe ser cero.

Si textarget es GL_TEXTURE_3D, entonces level debe ser mayor o igual a cero y menor o igual a $log_2$ del valor de GL_MAX_3D_TEXTURE_SIZE.

Si textarget es uno de GL_TEXTURE_CUBE_MAP_POSITIVE_X, GL_TEXTURE_CUBE_MAP_POSITIVE_Y, GL_TEXTURE_CUBE_MAP_POSITIVE_Z, GL_TEXTURE_CUBE_MAP_NEGATIVE_X, GL_TEXTURE_CUBE_MAP_NEGATIVE_Y, o GL_TEXTURE_CUBE_MAP_NEGATIVE_Z, entonces level debe ser mayor o igual a cero y menor o igual a $log_2$ del valor de GL_MAX_CUBE_MAP_TEXTURE_SIZE.

Para todos los demás valores de textarget, level debe ser mayor o igual a cero y menor o igual a $log_2$ del valor de GL_MAX_TEXTURE_SIZE.

layer especifica la capa de una imagen bidimensional dentro de una textura tridimensional.

Para glFramebufferTexture1D, si texture no es cero, entonces textarget debe ser GL_TEXTURE_1D. Para glFramebufferTexture2D, si texture no es cero, textarget debe ser uno de GL_TEXTURE_2D, GL_TEXTURE_RECTANGLE, GL_TEXTURE_CUBE_MAP_POSITIVE_X, GL_TEXTURE_CUBE_MAP_POSITIVE_Y, GL_TEXTURE_CUBE_MAP_POSITIVE_Z, GL_TEXTURE_CUBE_MAP_NEGATIVE_X, GL_TEXTURE_CUBE_MAP_NEGATIVE_Y, GL_TEXTURE_CUBE_MAP_NEGATIVE_Z, o GL_TEXTURE_2D_MULTISAMPLE. Para glFramebufferTexture3D, si texture no es cero, entonces textarget debe ser GL_TEXTURE_3D.

Para glFramebufferTexture y glNamedFramebufferTexture, si texture es el nombre de una textura tridimensional, de matriz de mapas de cubos, de mapa de cubos, de matriz unidimensional o bidimensional, o de matriz multisample bidimensional, el nivel de textura especificado es una matriz de imágenes, y la adjunción del framebuffer se considera *con capas*.

ERRORES

GL_INVALID_ENUM es generado por todos los comandos que aceptan un parámetro target si no es uno de los destinos de framebuffer aceptados.

GL_INVALID_OPERATION es generado por todos los comandos que aceptan un parámetro target si cero está enlazado a ese destino.

GL_INVALID_OPERATION es generado por glNamedFramebufferTexture si framebuffer no es el nombre de un objeto de framebuffer existente.

GL_INVALID_ENUM es generado si attachment no es uno de los puntos de adjunción aceptados.

GL_INVALID_VALUE es generado si texture no es cero o el nombre de un objeto de textura existente.

GL_INVALID_VALUE es generado si texture no es cero y level no es un nivel de textura compatible para texture.

GL_INVALID_VALUE es generado por glFramebufferTexture3D si texture no es cero y layer es mayor que el valor de GL_MAX_3D_TEXTURE_SIZE menos uno.

GL_INVALID_OPERATION es generado por todos los comandos que aceptan un parámetro textarget si texture no es cero, y textarget y el objetivo efectivo de texture no son compatibles.

GL_INVALID_OPERATION es generado si texture es una textura de buffer.
