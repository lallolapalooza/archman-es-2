NOMBRE

glGetShaderiv - Devuelve un parámetro de un objeto shader

ESPECIFICACIÓN EN C

void glGetShaderiv(GLuint shader, GLenum pname, GLint *params);

PARÁMETROS

shader

Especifica el objeto shader a consultar.

pname

Especifica el parámetro del objeto. Los nombres simbólicos aceptados son GL_SHADER_TYPE, GL_DELETE_STATUS, GL_COMPILE_STATUS, GL_INFO_LOG_LENGTH, GL_SHADER_SOURCE_LENGTH.

params

Devuelve el parámetro del objeto solicitado.

DESCRIPCIÓN

glGetShader devuelve en params el valor de un parámetro para un objeto shader específico. Se definen los siguientes parámetros:

GL_SHADER_TYPE

params devuelve GL_VERTEX_SHADER si shader es un objeto shader de vértices, GL_GEOMETRY_SHADER si shader es un objeto shader de geometría y GL_FRAGMENT_SHADER si shader es un objeto shader de fragmentos.

GL_DELETE_STATUS

params devuelve GL_TRUE si shader está actualmente marcado para su eliminación y GL_FALSE en caso contrario.

GL_COMPILE_STATUS

params devuelve GL_TRUE si la última operación de compilación en shader fue exitosa y GL_FALSE en caso contrario.

GL_INFO_LOG_LENGTH

params devuelve el número de caracteres en el registro de información para shader, incluyendo el carácter de terminación nula (es decir, el tamaño del búfer de caracteres requerido para almacenar el registro de información). Si shader no tiene un registro de información, se devuelve 0.

GL_SHADER_SOURCE_LENGTH

params devuelve la longitud de la concatenación de las cadenas fuente que componen el código fuente del shader para el shader, incluyendo el carácter de terminación nula (es decir, el tamaño del búfer de caracteres requerido para almacenar el código fuente del shader). Si no existe código fuente, se devuelve 0.

NOTAS

Si se genera un error, no se realizan cambios en el contenido de params.

ERRORES

Se genera GL_INVALID_VALUE si shader no es un valor generado por OpenGL.

Se genera GL_INVALID_OPERATION si shader no se refiere a un objeto shader.

Se genera GL_INVALID_ENUM si pname no es un valor aceptado.

GETS ASOCIADOS

glGetShaderInfoLog() con argumento shader

glGetShaderSource() con argumento shader

glIsShader()
