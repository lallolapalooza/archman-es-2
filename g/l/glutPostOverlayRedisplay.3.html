glutPostOverlayRedisplay(3)

Paquete: freeglut

Licencias: X11

glutPostOverlayRedisplay(3) freeglut glutPostOverlayRedisplay(3)

NOMBRE

glutPostOverlayRedisplay, glutPostWindowOverlayRedisplay - marca la superposición de la ventana actual o especificada como necesitada de ser redibujada.

ADVERTENCIA

Aún no implementado en freeglut.

SINTAXIS

void glutPostOverlayRedisplay(void);
void glutPostWindowOverlayRedisplay(int win);

DESCRIPCIÓN

Marca la superposición de la ventana actual como necesitada de ser redibujada. En la próxima iteración del glutMainLoop, se llamará a la función de callback de visualización de la superposición de la ventana (o simplemente a la función de callback de visualización si no hay ninguna registrada) para redibujar el plano de superposición de la ventana. Múltiples llamadas a glutPostOverlayRedisplay antes de la siguiente oportunidad de callback de visualización (o de callback de visualización de superposición si hay una registrada) generan una única redibujada. glutPostOverlayRedisplay puede ser llamado dentro de la función de callback de visualización o de superposición de una ventana para volver a marcar esa ventana para su redibujado.

Lógicamente, la notificación de daño de superposición para una ventana se trata como una llamada a glutPostOverlayRedisplay en la ventana dañada. A diferencia del daño reportado por el sistema de ventanas, glutPostOverlayRedisplay no establecerá a verdadero el estado dañado de la superposición (devuelto por glutLayerGet(GLUT_OVERLAY_DAMAGED).

Si la ventana sobre la que desea marcar una redibujada de superposición no es la actual (y no requiere que se convierta en la actual inmediatamente), usar glutPostWindowOverlayRedisplay es más eficiente que llamar a glutSetWindow a la ventana deseada y luego llamar a glutPostOverlayRedisplay.

EJEMPLO

Si está realizando un efecto interactivo como el elástico en la superposición, es una buena idea estructurar su renderizado para minimizar el parpadeo (la mayoría de las superposiciones son de un solo búfer). Solo borre la superposición si sabe que la ventana ha sido dañada. De lo contrario, intente simplemente borrar lo último que dibujó y volver a dibujarlo en una posición actualizada. Aquí hay una función de callback de visualización de superposición de ejemplo utilizada para implementar el elástico en la superposición:

  void
  redrawOverlay(void)
  {
    static int prevStretchX, prevStretchY;
    if (glutLayerGet(GLUT_OVERLAY_DAMAGED)) {
      /* El daño significa que necesitamos un borrado completo. */
      glClear(GL_COLOR_BUFFER_BIT);
    } else {
      /* Borrar el último elástico. */
      glIndexi(transparent);
      glBegin(GL_LINE_LOOP);
      glVertex2i(anchorX, anchorY);
      glVertex2i(anchorX, prevStretchY);
      glVertex2i(prevStretchX, prevStretchY);
      glVertex2i(prevStretchX, anchorY);
      glEnd();
    }
    glIndexi(red);
    glBegin(GL_LINE_LOOP);
    glVertex2i(anchorX, anchorY);
    glVertex2i(anchorX, stretchY);
    glVertex2i(stretchX, stretchY);
    glVertex2i(stretchX, anchorY);
    glEnd();
    prevStretchX = stretchX;
    prevStretchY = stretchY;
  }

Note cómo se utiliza glutLayerGet(GLUT_OVERLAY_DAMAGED) para determinar si se necesita un borrado debido a daños; si un borrado no es necesario, es más rápido simplemente dibujar el último elástico usando el píxel transparente.

Cuando la aplicación termina con el efecto de elástico, la mejor manera de eliminar el elástico es simplemente ocultar la superposición llamando a glutHideOverlay.
