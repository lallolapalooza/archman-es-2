NOMBRE

glab-securefile-download - Descarga un archivo seguro para un proyecto.

SINOPSIS

glab securefile download [flags]

DESCRIPCIÓN

Descarga un archivo seguro para un proyecto.

OPCIONES

--all[=false] Descarga todos (límite 100) los archivos seguros de un proyecto. Los archivos se descargarán con su nombre original y extensión de archivo.

--force-download[=false] Fuerza la descarga de archivos incluso si la verificación de la suma de comprobación falla. Advertencia: cuando está habilitado, esta configuración permite la descarga de archivos que están corruptos o manipulados.

--id=0 ID del archivo seguro a descargar.

--name="" Nombre del archivo seguro a descargar. Guarda el archivo con este nombre, o en la ruta especificada por --path.

--no-verify[=false] No verificar la suma de comprobación de los archivos descargados. Advertencia: cuando está habilitado, esta configuración permite la descarga de archivos que están corruptos o manipulados.

--output-dir="." Directorio de salida para los archivos descargados con --all.

-p, --path="./downloaded.tmp" Ruta para descargar el archivo seguro, incluyendo el nombre de archivo y la extensión.

OPCIONES HEREDADAS DE COMANDOS PADRE

-h, --help[=false] Mostrar ayuda para este comando.

-R, --repo="" Seleccionar otro repositorio. Puede usar el formato PROPIETARIO/REPO o GRUPO/NAMESPACE/REPO. También acepta URL completa o URL de Git.

EJEMPLO

# Descargar un archivo seguro de un proyecto usando el ID del archivo por argumento o bandera.
$ glab securefile download 1
$ glab securefile download --id 1
# Descargar un archivo seguro de un proyecto a una ruta dada.
$ glab securefile download 1 --path="securefiles/file.txt"
# Descargar un archivo seguro de un proyecto sin verificar su suma de comprobación.
$ glab securefile download 1 --no-verify
# Descargar un archivo seguro de un proyecto incluso si la verificación de la suma de comprobación falla.
$ glab securefile download 1 --force-download
# Descargar un archivo seguro de un proyecto usando el nombre del archivo al directorio actual.
$ glab securefile download --name my-secure-file.pem
# Descargar un archivo seguro de un proyecto usando el nombre del archivo a una ruta dada.
$ glab securefile download --name my-secure-file.pem --path=securefiles/some-other-name.pem
# Descargar todos (límite 100) los archivos seguros de un proyecto.
$ glab securefile download --all
# Descargar todos (límite 100) los archivos seguros de un proyecto a un directorio dado.
$ glab securefile download --all --output-dir secure_files/
