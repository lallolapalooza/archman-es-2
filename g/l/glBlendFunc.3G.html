DESCRIPCIÓ

N

Los píxeles se pueden dibujar utilizando una función que mezcla los valores RGBA entrantes (de origen) con los valores RGBA que ya están en el búfer de cuadro (los valores de destino). La mezcla está inicialmente deshabilitada. Utilice glEnable()

y

glDisable con el argumento GL_BLEND para habilitar y deshabilitar la

mezcla.

glBlendFunc define la operación de mezcla para todos los búferes de dibujo cuando está habilitada. glBlendFunci define la operación de mezcla para un solo búfer de dibujo especificado por buf cuando está habilitada para ese búfer de dibujo. sfactor especifica qué método se utiliza para escalar los componentes de color de origen. dfactor especifica qué método se utiliza para escalar los componentes de color de destino. Ambos parámetros deben ser uno de los siguientes constantes simbólicas: GL_ZERO, GL_ONE, GL_SRC_COLOR, GL_ONE_MINUS_SRC_COLOR, GL_DST_COLOR, GL_ONE_MINUS_DST_COLOR, GL_SRC_ALPHA, GL_ONE_MINUS_SRC_ALPHA, GL_DST_ALPHA, GL_ONE_MINUS_DST_ALPHA, GL_CONSTANT_COLOR, GL_ONE_MINUS_CONSTANT_COLOR, GL_CONSTANT_ALPHA, GL_ONE_MINUS_CONSTANT_ALPHA, GL_SRC_ALPHA_SATURATE, GL_SRC1_COLOR, GL_ONE_MINUS_SRC1_COLOR, GL_SRC1_ALPHA, y GL_ONE_MINUS_SRC1_ALPHA. Los métodos posibles se describen en la siguiente tabla. Cada método define cuatro factores de escala, uno para cada uno de rojo, verde, azul y alfa. EJEMPLO

S

La transparencia se implementa mejor utilizando la función de mezcla (GL_SRC_ALPHA, GL_ONE_MINUS_SRC_ALPHA) con primitivas ordenadas desde la más lejana a la más cercana. Tenga en cuenta que este cálculo de transparencia no requiere la presencia de planos de bits de alfa en el búfer de

cuadro.

La función de mezcla (GL_SRC_ALPHA, GL_ONE_MINUS_SRC_ALPHA) también es útil para renderizar puntos y líneas antialiasing en un orden

arbitrario.

El antialiasing de polígonos se optimiza utilizando la función de mezcla (GL_SRC_ALPHA_SATURATE, GL_ONE) con polígonos ordenados desde el más cercano al más lejano. (Vea la página de referencia de glEnabl

e(),

glDisable y el argumento GL_POLYGON_SMOOTH para información sobre el antialiasing de polígonos.) Los planos de bits de alfa de destino, q

ue deben estar presentes para que esta función de mezcl
a opere correctamente, almacenan la cobertura acumulada.

NOTA

S

La alfa entrante (de origen) se utilizaría típicamente como opacidad del material, que va desde 1.0 (K A), que representa opacidad completa, hasta 0.0 (0), que representa transparencia

completa.

Cuando se habilita más de un búfer de color para dibujar, la GL realiza la mezcla por separado para cada búfer habilitado, utilizando el contenido de ese búfer como color de destino. (Vea glDrawBuffer().

)

Cuando la mezcla de doble fuente está habilitada (es decir, se utiliza uno de los factores de mezcla que requiere la segunda entrada de color), el número máximo de búferes de dibujo habilitados viene dado por GL_MAX_DUAL_SOURCE_DRAW_BUFFERS, que puede ser menor que GL_MAX_DRAW_BUFFER
