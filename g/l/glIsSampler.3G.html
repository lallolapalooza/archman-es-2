NOMBRE

glIsSampler - determina si un nombre corresponde a un objeto sampler

ESPECIFICACIÓN C

GLboolean glIsSampler(GLuint id);

PARÁMETROS

id

Especifica un valor que puede ser el nombre de un objeto sampler.

DESCRIPCIÓN

glIsSampler devuelve GL_TRUE si id es actualmente el nombre de un objeto sampler. Si id es cero, o es un valor distinto de cero que actualmente no es el nombre de un objeto sampler, o si ocurre un error, glIsSampler devuelve GL_FALSE.

Un nombre devuelto por glGenSamplers() es el nombre de un objeto sampler.

NOTAS

glIsSampler solo está disponible si la versión de GL es 3.3 o superior.
