glutCreateMenu(3)

Paquete: freeglut

Licencias: X11

glutCreateMenu(3) freeglut glutCreateMenu(3)

NOMBRE

glutCreateMenu - crea un nuevo menú emergente.

SINTAXIS

int glutCreateMenu(void (*func)(int value));

ARGUMENTOS

func
La función de callback para el menú que se llama cuando se selecciona una entrada del menú. El valor que se pasa al callback viene determinado por el valor de la entrada de menú seleccionada.

DESCRIPCIÓN

glutCreateMenu crea un nuevo menú emergente y devuelve un identificador entero pequeño y único. El rango de identificadores asignados comienza en uno. El rango de identificadores de menú es independiente del rango de identificadores de ventana. Implícitamente, el menú actual se establece en el menú recién creado. Este identificador de menú puede usarse al llamar a glutSetMenu.

Cuando se llama al callback del menú porque se ha seleccionado una entrada para el menú, el menú actual se establecerá implícitamente en el menú con la entrada seleccionada antes de que se realice el callback.

EJEMPLO

Aquí tienes un rápido ejemplo de cómo crear un menú emergente de GLUT con dos submenús y adjuntarlo al botón derecho de la ventana actual:

  int submenu1, submenu2;
  submenu1 = glutCreateMenu(selectMessage);
  glutAddMenuEntry("abc", 1);
  glutAddMenuEntry("ABC", 2);
  submenu2 = glutCreateMenu(selectColor);
  glutAddMenuEntry("Verde", 1);
  glutAddMenuEntry("Rojo", 2);
  glutAddMenuEntry("Blanco", 3);
  glutCreateMenu(selectFont);
  glutAddMenuEntry("9 por 15", 0);
  glutAddMenuEntry("Times Roman 10", 1);
  glutAddMenuEntry("Times Roman 24", 2);
  glutAddSubMenu("Mensajes", submenu1);
  glutAddSubMenu("Color", submenu2);
  glutAttachMenu(GLUT_RIGHT_BUTTON);

NOTAS SOBRE LA IMPLEMENTACIÓN X

Si está disponible, GLUT para X aprovechará los planos de superposición para implementar menús emergentes. El uso de planos de superposición puede eliminar los callbacks de visualización cuando se desactivan los menús emergentes. La convención SERVER_OVERLAY_VISUALS se utiliza para determinar si los visuales de superposición están disponibles.

VER TAMBIÉN

glutCreateWindow, glutDestroyMenu, glutSetMenu, glutAttachMenu
