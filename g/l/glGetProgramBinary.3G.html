NOMBRE

glGetProgramBinary - devuelve una representación binaria del código ejecutable compilado y enlazado de un objeto de programa

ESPECIFICACIÓN C

void glGetProgramBinary(GLuint program, GLsizei bufSize, GLsizei *length, GLenum *binaryFormat, void *binary);

PARÁMETROS

program

Especifica el nombre de un objeto de programa cuya representación binaria se va a recuperar.

bufSize

Especifica el tamaño del búfer cuya dirección se proporciona en binary.

length

Especifica la dirección de una variable para recibir el número de bytes escritos en binary.

binaryFormat

Especifica la dirección de una variable para recibir un token que indica el formato de los datos binarios devueltos por el GL.

binary

Especifica la dirección de un array en el que el GL devolverá la representación binaria de program.

DESCRIPCIÓN

glGetProgramBinary devuelve una representación binaria del código ejecutable compilado y enlazado para program en el array de bytes cuya dirección se especifica en binary. El número máximo de bytes que se pueden escribir en binary se especifica mediante bufSize. Si el binario del programa es mayor en tamaño que bufSize bytes, se genera un error; de lo contrario, el número real de bytes escritos en binary se devuelve en la variable cuya dirección se proporciona en length. Si length es NULL, no se devuelve ninguna longitud.

El formato del binario del programa escrito en binary se devuelve en la variable cuya dirección se proporciona en binaryFormat, y puede depender de la implementación. El binario producido por el GL puede ser devuelto posteriormente al GL llamando a glProgramBinary(), con binaryFormat y length establecidos en los valores devueltos por glGetProgramBinary, y pasando los datos binarios devueltos en el parámetro binary.

ERRORES

Se genera GL_INVALID_OPERATION si bufSize es menor que el tamaño de GL_PROGRAM_BINARY_LENGTH para program.

Se genera GL_INVALID_OPERATION si GL_LINK_STATUS para el objeto de programa es falso.

GETS ASOCIADOS

glGetProgram() con el argumento GL_PROGRAM_BINARY_LENGTH
