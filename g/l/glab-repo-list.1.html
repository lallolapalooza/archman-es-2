NOMBRE

glab-repo-list - Obtiene la lista de repositorios.

SINOPSIS

glab repo list [flags]

DESCRIPCIÓN

Obtiene la lista de repositorios.

OPCIONES

-a, --all[=false] Lista todos los proyectos en la instancia.

--archived[=false] Filtra por estado archivado. Usa 'false' para excluir repositorios archivados. Usado con la bandera '--group'.

-g, --group="" Devuelve repositorios solo del grupo dado.

-G, --include-subgroups[=false] Incluye proyectos en subgrupos de este grupo. Por defecto es false. Usado con la bandera '--group'.

--member[=false] Lista solo los proyectos de los que eres miembro.

-m, --mine[=false] Lista solo los proyectos que posees. Por defecto si no se proporcionan filtros.

-o, --order="last_activity_at" Devuelve repositorios ordenados por id, nombre, ruta, created_at, updated_at, similaridad, star_count, last_activity_at.

-F, --output="text" Formatea la salida como: text, json.

-p, --page=1 Número de página.

-P, --per-page=30 Número de elementos a listar por página.

-s, --sort="" Devuelve repositorios ordenados en orden ascendente o descendente.

--starred[=false] Lista solo los proyectos marcados con estrella.

-u, --user="" Lista proyectos del usuario.

OPCIONES HEREDADAS DE COMANDOS PADRE

-h, --help[=false] Muestra la ayuda para este comando.

EJEMPLO

$ glab repo list
