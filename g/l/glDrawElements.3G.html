NOMBRE

glDrawElements - Renderiza primitivas a partir de datos en arreglo

ESPECIFICACIÓN EN C

void glDrawElements(GLenum mode, GLsizei count, GLenum type, const void * indices);

PARÁMETROS

mode

Especifica qué tipo de primitivas se renderizarán. Se aceptan los símbolos constantes GL_POINTS, GL_LINE_STRIP, GL_LINE_LOOP, GL_LINES, GL_LINE_STRIP_ADJACENCY, GL_LINES_ADJACENCY, GL_TRIANGLE_STRIP, GL_TRIANGLE_FAN, GL_TRIANGLES, GL_TRIANGLE_STRIP_ADJACENCY, GL_TRIANGLES_ADJACENCY y GL_PATCHES.

count

Especifica el número de elementos a renderizar.

type

Especifica el tipo de los valores en indices. Debe ser uno de GL_UNSIGNED_BYTE, GL_UNSIGNED_SHORT o GL_UNSIGNED_INT.

indices

Especifica un puntero a la ubicación donde se almacenan los índices.

DESCRIPCIÓN

glDrawElements especifica múltiples primitivas geométricas con muy pocas llamadas a subrutinas. En lugar de llamar a una función GL para pasar cada vértice, normal, coordenada de textura, flag de arista o color individual, puedes predefinir arreglos separados de vértices, normales, etc., y usarlos para construir una secuencia de primitivas con una sola llamada a glDrawElements.

Cuando se llama a glDrawElements, utiliza count elementos secuenciales de un arreglo habilitado, comenzando en indices, para construir una secuencia de primitivas geométricas. mode especifica qué tipo de primitivas se construyen y cómo los elementos del arreglo las construyen. Si se habilita más de un arreglo, se utilizan todos.

Los atributos de vértice que son modificados por glDrawElements tienen un valor indefinido después de que glDrawElements regresa. Los atributos que no se modifican mantienen sus valores previos.

NOTAS

GL_LINE_STRIP_ADJACENCY, GL_LINES_ADJACENCY, GL_TRIANGLE_STRIP_ADJACENCY y GL_TRIANGLES_ADJACENCY solo están disponibles si la versión de GL es 3.2 o superior.

ERRORES

GL_INVALID_ENUM se genera si mode no es un valor aceptado.

GL_INVALID_VALUE se genera si count es negativo.

GL_INVALID_OPERATION se genera si un shader de geometría está activo y mode es incompatible con el tipo de primitiva de entrada del shader de geometría en el objeto de programa actualmente instalado.

GL_INVALID_OPERATION se genera si un nombre de objeto de buffer no cero está enlazado a un arreglo habilitado o al arreglo de elementos y el almacén de datos del objeto de buffer está actualmente mapeado.
