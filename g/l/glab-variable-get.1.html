NOMBRE

glab-variable-get - Obtiene una variable para un proyecto o grupo.

SINOPSIS

glab variable get [flags]

DESCRIPCIÓN

Obtiene una variable para un proyecto o grupo.

OPCIONES

-g, --group="" Obtiene la variable para un grupo.

-F, --output="text" Formatea la salida como: text, json.

-s, --scope="" El scope_entorno de la variable. Valores: all (), o entornos específicos.

OPCIONES HEREDADAS DE COMANDOS PADRE

-h, --help[=false] Muestra la ayuda para este comando.

-R, --repo="" Selecciona otro repositorio. Puede usar el formato OWNER/REPO o GROUP/NAMESPACE/REPO. También acepta URL completas o URL de Git.

EJEMPLO

$ glab variable get VAR_KEY
$ glab variable get -g GROUP VAR_KEY
$ glab variable get -s SCOPE VAR_KEY
