NAME

glClearBufferfv, glClearBufferuiv, glClearBufferiv, glClearNamedFramebufferfi, glClearNamedFramebufferfv, glClearNamedFramebufferiv, glClearNamedFramebufferuiv — clear a buffer or the named framebuffer with a vector of values

C SPECIFICATION

“glcorearb.h”

    void glClearBufferfv(GLenum buffer, GLint drawbuffer, const GLfloat *value);
    void glClearBufferuiv(GLenum buffer, GLint drawbuffer, const GLuint *value);
    void glClearBufferiv(GLenum buffer, GLint drawbuffer, const GLint *value);
    void glClearNamedFramebufferfi(GLuint framebuffer, GLenum buffer,
                                   GLfloat depth);
    void glClearNamedFramebufferfv(GLuint framebuffer, GLenum buffer,
                                   const GLfloat *value);
    void glClearNamedFramebufferiv(GLuint framebuffer, GLenum buffer,
                                   const GLint *value);
    void glClearNamedFramebufferuiv(GLuint framebuffer, GLenum buffer,
                                    const GLuint *value);

PARAMETERS

buffer
Specifies the buffer to be cleared. The symbolic constants GL_COLOR, GL_DEPTH, GL_STENCIL, GL_DEPTH_STENCIL, and GL_ACCUM are accepted.
drawbuffer
For glClearBufferfv, glClearBufferuiv, and glClearBufferiv, this parameter is ignored. For glClearNamedFramebufferfv, glClearNamedFramebufferiv, and glClearNamedFramebufferuiv, this parameter specifies the draw buffer index. For glClearNamedFramebufferfi, this parameter is ignored.
value
A pointer to a single element array containing the value(s) to be used for clearing.
framebuffer
The name of the framebuffer object to be cleared.
depth
The value to be used for clearing the depth buffer.

DESCRIPTION

These commands clear the specified buffer or buffers of the current framebuffer or a specified framebuffer object with a specified color, depth value, or stencil index.

The buffer to be cleared is specified by buffer. GL_COLOR indicates the color buffer; GL_DEPTH indicates the depth buffer; GL_STENCIL indicates the stencil buffer; GL_DEPTH_STENCIL indicates both the depth and stencil buffers; GL_ACCUM indicates the accumulate buffer.

If buffer is GL_COLOR, the color buffer is cleared. The value parameter points to an array of four GLfloat, GLuint, or GLint values, respectively, that specify the red, green, blue, and alpha values to be used for clearing. These values are clamped to the range [0, 1] for GL_RGBA32F, and written as-is for other formats.

If buffer is GL_DEPTH, the depth buffer is cleared. The value parameter points to a single GLfloat, GLuint, or GLint value, respectively. This value is converted to fixed-point and written to the depth buffer. The value must be in the range [0, 1].

If buffer is GL_STENCIL, the stencil buffer is cleared. The value parameter points to a single GLuint or GLint value, respectively. This value is written to the stencil buffer.

If buffer is GL_DEPTH_STENCIL, the depth and stencil buffers are cleared. The value parameter points to a single GLuint or GLint value, respectively. This value is written to both the depth and stencil buffers.

If buffer is GL_ACCUM, the accumulate buffer is cleared. The value parameter points to an array of four GLfloat, GLuint, or GLint values, respectively. These values are converted to the range [-1, 1] and written to the accumulate buffer.

The glClearNamedFramebufferfi, glClearNamedFramebufferfv, glClearNamedFramebufferiv, and glClearNamedFramebufferuiv commands perform the same actions but operate on a specified framebuffer object, identified by framebuffer.

ERRORS

GL_INVALID_ENUM is generated if buffer is not one of the accepted values.

GL_INVALID_VALUE is generated if the contents of value result in a value outside the valid range for the specified buffer.

GL_INVALID_FRAMEBUFFER_OPERATION is generated if the currently bound framebuffer is not complete.

GL_INVALID_OPERATION is generated if glClearNamedFramebufferfi is called with a depth buffer format that does not support this operation.
