DESCRIPCIÓN Las funciones glGetTexImage, glGetnTexImage y glGetTextureImage devuelven una imagen de textura en pixels. Para glGetTexImage y glGetnTexImage,target especifica si la imagen de textura deseada es la especificada por glTexImage1D() (GL_TEXTURE_1D), glTexImage2D() ( GL_TEXTURE_1D_ARRAY, GL_TEXTURE_RECTANGLE, GL_TEXTURE_2D o cualquiera deGL_TEXTURE_CUBE_MAP_*), o glTexImage3D() ( GL_TEXTURE_2D_ARRAY, GL_TEXTURE_3D, GL_TEXTURE_CUBE_MAP_ARRAY). Para glGetTextureImage, texture especifica el nombre del objeto de textura. Además de los tipos de textura aceptados por glGetTexImage y glGetnTexImage, la función también acepta objetos de textura de mapa cúbico (con destino efectivo GL_TEXTURE_CUBE_MAP). level especifica el número de nivel de detalle de la imagen deseada. format y type especifican el formato y el tipo del array de imagen deseado. Consulte la página de referencia de glTexImage1D() para una descripción de los valores aceptables para los parámetros format y type, respectivamente. Para las funciones glGetnTexImage y glGetTextureImage, bufSize indica el tamaño del búfer para recibir los datos de píxel recuperados. glGetnTexImage y glGetTextureImage no esc

riben más de

bufSize bytes en pixels. Si un objeto de búfer con nombre distinto de cero está enlazado al destino GL_PIXEL_PACK_BUFFER

(véase

glBindBuffer()) mientras se solicita una imagen de textura, pixels se trata como un desplazamiento en bytes dentro del almacén de datos del objeto de búfer. Para comprender el funcionamiento de glGetTexImage, considere que la imagen de textura interna de cuatro componentes seleccionada es un búfer de color RGBA del tamaño de la imagen. La semántica de glGetTexImage es entonces idéntica a la de glReadPixels(), con la excepción de que no se realizan operaciones de transferencia de píxeles, cuando se llama con el mismo format y type, con x y y establecidos en

0,

width establecido al ancho de la imagen de textura

y

height establecido a 1 para imágenes 1D, o a la altura de la imagen de textura para imágenes 2D. Si la imagen de textura seleccionada no contiene cuatro componentes, se aplican las siguientes correspondencias. Las texturas de un solo componente se tratan como búfers RGBA con el rojo establecido al valor del componente único, el verde a 0, el azul a 0 y el alfa a 1. Las texturas de dos componentes se tratan como búfers RGBA con el rojo establecido al valor del componente cero, el alfa al valor del componente uno, y el verde y el azul a 0. Finalmente, las texturas de tres componentes se tratan como búfers RGBA con el rojo establecido al componente cero, el verde al componente uno, el azul al componente dos y el alfa a 1. Para determinar el tamaño requerido de pixels, use glGetTexLevelParameter() para determinar las dimensiones de la imagen de textura interna, y luego escale el número requerido de píxeles por el almacenamiento requerido para cada píxel, basándose en forma
