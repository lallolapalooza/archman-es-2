NOMBRE

glDeleteSync - elimina un objeto de sincronización

ESPECIFICACIÓN EN C

void glDeleteSync(GLsync sync);

PARÁMETROS

sync

El objeto de sincronización a eliminar.

DESCRIPCIÓN

glDeleteSync elimina el objeto de sincronización especificado por sync. Si el comando de barrera correspondiente al objeto de sincronización especificado ha finalizado, o si ningún comando glWaitSync() o glClientWaitSync() está bloqueando en sync, el objeto se elimina inmediatamente. De lo contrario, sync se marca para su eliminación y se eliminará cuando ya no esté asociado con ningún comando de barrera y ya no esté bloqueando ningún comando glWaitSync() o glClientWaitSync(). En cualquier caso, después de que glDeleteSync regrese, el nombre sync no es válido y ya no puede usarse para referirse al objeto de sincronización.

glDeleteSync ignorará silenciosamente un valor de sync de cero.

NOTAS

glSync solo se admite si la versión de GL es 3.2 o posterior, o si se admite la extensión ARB_sync.

ERRORES

Se genera GL_INVALID_VALUE si sync no es cero ni el nombre de un objeto de sincronización.
