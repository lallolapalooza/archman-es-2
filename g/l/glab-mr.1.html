NOMBRE

glab-mr - Crear, ver y administrar solicitudes de fusión.

SINOPSIS

glab mr [opciones]

DESCRIPCIÓN

Crear, ver y administrar solicitudes de fusión.

OPCIONES

-R, --repo="" Seleccionar otro repositorio. Puede usar el formato PROPIETARIO/REPO o GRUPO/NAMESPACE/REPO. También acepta URL completa o URL de Git.

OPCIONES HEREDADAS DE COMANDOS PADRE

-h, --help[=false] Mostrar ayuda para este comando.

EJEMPLO

$ glab mr create --fill --label bugfix
$ glab mr merge 123
$ glab mr note -m "se debe hacer X antes de que se pueda fusionar" branch-foo
