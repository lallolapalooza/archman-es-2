NOMBRE

glab-mr-rebase - Reorganizar la rama de origen de una solicitud de fusión contra su rama de destino.

SINOSIS

glab mr rebase [ | ] [flags]

DESCRIPCIÓN

Si no tienes permiso para hacer push a la rama de origen de la solicitud de fusión, recibirás una respuesta 403 Prohibido.

OPCIONES

--skip-ci[=false] Reorganizar la solicitud de fusión mientras se omiten los pipelines de CI/CD.

OPCIONES HEREDADAS DE COMANDOS PADRE

-h, --help[=false] Mostrar ayuda para este comando.

-R, --repo="" Seleccionar otro repositorio. Se puede usar el formato OWNER/REPO o GROUP/NAMESPACE/REPO. También acepta URL completas o URL de Git.

EJEMPLO

# Reorganizar la solicitud de fusión 123
$ glab mr rebase 123
# Reorganizar la rama actual
$ glab mr rebase
# Reorganizar la solicitud de fusión desde la rama
$ glab mr rebase branch
$ glab mr rebase branch --skip-ci
