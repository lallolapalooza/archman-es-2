NOMBRE

glShaderBinary - cargar binarios de shaders precompilados

ESPECIFICACIÓN C

void glShaderBinary(GLsizei count, const GLuint *shaders, GLenum binaryFormat, const void *binary, GLsizei length);

PARÁMETROS

count

Especifica el número de identificadores de objetos de shader contenidos en shaders.

shaders

Especifica la dirección de una matriz de identificadores de shaders en la cual cargar los binarios de shaders precompilados.

binaryFormat

Especifica el formato del código binario de shaders contenido en binary.

binary

Especifica la dirección de una matriz de bytes que contiene el código binario precompilado del shader.

length

Especifica la longitud de la matriz cuya dirección se da en binary.

DESCRIPCIÓN

glShaderBinary carga código binario de shader precompilado en los count objetos de shader cuyos identificadores se dan en shaders. binary apunta a length bytes de código de shader binario almacenado en memoria del cliente. binaryFormat especifica el formato del código precompilado.

La imagen binaria contenida en binary se decodificará de acuerdo con la especificación de la extensión que define el token binaryFormat especificado. OpenGL no define ningún formato binario específico, pero sí proporciona un mecanismo para obtener valores de token para dichos formatos proporcionados por dichas extensiones.

Dependiendo de los tipos de los objetos de shader en shaders, glShaderBinary cargará individualmente binarios de shaders de vértice o fragmento, o cargará un binario ejecutable que contiene un par optimizado de shaders de vértice y fragmento almacenados en el mismo binario.

ERRORES

GL_INVALID_OPERATION se genera si más de uno de los identificadores en shaders se refiere al mismo objeto de shader.

GL_INVALID_ENUM se genera si binaryFormat no es un valor aceptado.

GL_INVALID_VALUE se genera si los datos apuntados por binary no coinciden con el formato especificado por binaryFormat.

GETS ASOCIADOS

glGet() con el parámetro GL_NUM_SHADER_BINARY_FORMATS.

glGet() con el parámetro GL_SHADER_BINARY_FORMATS.
