NOMBRE

glTransformFeedbackVaryings - especificar los valores a registrar en los búferes de realimentación de transformación

ESPECIFICACIÓN C

void glTransformFeedbackVaryings(GLuintprogram, GLsizeicount, const char **varyings, GLenumbufferMode);

PARÁMETROS

program

El nombre del objeto de programa de destino.

count

El número de variables varying utilizadas para la realimentación de transformación.

varyings

Un array de count cadenas terminadas en cero que especifican los nombres de las variables varying a utilizar para la realimentación de transformación.

bufferMode

Identifica el modo utilizado para capturar las variables varying cuando la realimentación de transformación está activa. bufferMode debe ser GL_INTERLEAVED_ATTRIBS o GL_SEPARATE_ATTRIBS.

DESCRIPCIÓN

Los nombres de las salidas del shader de vértices o de geometría que se registrarán en el modo de realimentación de transformación se especifican utilizando glTransformFeedbackVaryings. Cuando un shader de geometría está activo, la realimentación de transformación registra los valores de las variables de salida seleccionadas del shader de geometría a partir de los vértices emitidos. De lo contrario, se registran los valores de las salidas seleccionadas del shader de vértices.

El estado establecido por glTranformFeedbackVaryings se almacena y entra en vigor la próxima vez que se llame a glLinkProgram() sobre program. Cuando se llama a glLinkProgram(), se enlaza program de modo que los valores de las variables varying especificadas para los vértices de cada primitiva generada por la GL se escriben en un único objeto de búfer si bufferMode es GL_INTERLEAVED_ATTRIBS o en múltiples objetos de búfer si bufferMode es GL_SEPARATE_ATTRIBS.

glTransformFeedbackVaryings también puede utilizar identificadores especiales si bufferMode es GL_INTERLEAVED_ATTRIBS:

gl_NextBuffer

Las variables siguientes en varyings se asignarán al siguiente punto de enlace de búfer.

gl_SkipComponents#

Donde # puede ser 1, 2, 3 o 4. La variable se trata como si tuviera este número de componentes, pero el contenido de la memoria se conserva durante las operaciones de realimentación.

Además de los errores generados por glTransformFeedbackVaryings, el programa program no se enlazará si:

•El count especificado por glTransformFeedbackVaryings no es cero, pero el objeto de programa no tiene shader de vértices ni de geometría.
•Cualquier nombre de variable especificado en el array varyings no está declarado como salida en el shader de vértices (o en el shader de geometría, si está activo), o no es uno de los identificadores especiales listados arriba.
•Aparecen identificadores especiales en un array varyings donde bufferMode no es GL_INTERLEAVED_ATTRIBS.
•Cualquiera de las dos entradas en el array varyings , que no sean uno de los varying especiales anteriores, especifican la misma variable varying.
•Sin contar los identificadores especiales, el número total de componentes a capturar en cualquier variable varying en varyings es mayor que la constante GL_MAX_TRANSFORM_FEEDBACK_SEPARATE_COMPONENTS y el modo de búfer es GL_SEPARATE_ATTRIBS.
•El número total de componentes a capturar es mayor que la constante GL_MAX_TRANSFORM_FEEDBACK_INTERLEAVED_COMPONENTS y el modo de búfer es GL_INTERLEAVED_ATTRIBS.

NOTAS

glGetTransformFeedbackVarying solo está disponible si la versión de GL es 3.0 o superior.

ERRORES

GL_INVALID_VALUE se genera si program no es el nombre de un objeto de programa.

GL_INVALID_VALUE se genera si bufferMode es GL_SEPARATE_ATTRIBS y count es mayor que el límite dependiente de la implementación GL_MAX_TRANSFORM_FEEDBACK_SEPARATE_ATTRIBS.

    glTransformFeedbackVaryings(3G)

    glTransformFeedbackVaryings — specify the varyings to capture during transform feedback.

    PROTOTYPE 

    void glTransformFeedbackVaryings(
                    GLuint program,
                    GLsizei count,
                    const GLchar **varyings,
                    GLenum bufferMode
                );

    PARAMETERS

    program
    Specifies the program object whose varyings are to be captured.
    count
    Specifies the number of varyings to be captured.
    varyings
    An array of pointers to null-terminated strings, representing the names of the varyings to be captured.
    bufferMode
    Specifies the capture mode. Must be either GL_SEPARATE_ATTRIBS or GL_INTERLEAVED_ATTRIBS.

    DESCRIPTION

    glTransformFeedbackVaryings specifies the names of the varying variables in the vertex shader, geometry shader (optional), or tessellation control/evaluation shader (optional) that should be captured in transform feedback mode. The varying variables specified in the varyings array must be declared in the vertex shader, geometry shader, or tessellation control/evaluation shader.

    The bufferMode parameter determines how the captured varying variables are stored in the transform feedback buffer.

    • GL_SEPARATE_ATTRIBS: Each varying variable is written to a separate buffer.
    • GL_INTERLEAVED_ATTRIBS: All varying variables are written to a single buffer in an interleaved format.

    This function must be called before linking the program object.

    NOTES

    • The names of the varying variables must match exactly, including case.
    • If a varying variable is declared in multiple shader stages, it will be captured only once.
    • The number of varyings specified in count must be less than or equal to the maximum number of varyings supported by the implementation (queried with GL_MAX_TRANSFORM_FEEDBACK_INTERLEAVED_COMPONENTS or GL_MAX_TRANSFORM_FEEDBACK_SEPARATE_COMPONENTS).

    ERRORS

    GL_INVALID_VALUE is generated if program is not the name of a program object.

    GL_INVALID_VALUE is generated if count is negative.

    GL_INVALID_VALUE is generated if bufferMode is not GL_SEPARATE_ATTRIBS or GL_INTERLEAVED_ATTRIBS.

    GL_INVALID_OPERATION is generated if program has already been linked.

    GL_INVALID_OPERATION is generated if any of the strings in varyings are not the name of a varying variable in the vertex, geometry, or tessellation shaders.
