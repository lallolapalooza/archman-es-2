NOMBRE

glGetActiveSubroutineUniform - consulta una propiedad de un uniforme de subrutina de sombreador activo

ESPECIFICACIÓN EN C

void glGetActiveSubroutineUniformiv(GLuint program, GLenum shadertype, GLuint index, GLenum pname, GLint *values);

PARÁMETROS

program

Especifica el nombre del programa que contiene la subrutina.

shadertype

Especifica la etapa del sombreador desde la cual consultar el parámetro de la subrutina. shadertype debe ser uno de GL_VERTEX_SHADER, GL_TESS_CONTROL_SHADER, GL_TESS_EVALUATION_SHADER, GL_GEOMETRY_SHADER o GL_FRAGMENT_SHADER.

index

Especifica el índice del uniforme de la subrutina del sombreador.

pname

Especifica el parámetro del uniforme de la subrutina del sombreador a consultar. pname debe ser GL_NUM_COMPATIBLE_SUBROUTINES, GL_COMPATIBLE_SUBROUTINES, GL_UNIFORM_SIZE o GL_UNIFORM_NAME_LENGTH.

values

Especifica la dirección de una matriz en la que se colocarán uno o varios valores consultados.

DESCRIPCIÓN

glGetActiveSubroutineUniform consulta un parámetro de un uniforme de subrutina de sombreador activo. program contiene el nombre del programa que contiene el uniforme. shadertype especifica la etapa en la que la ubicación del uniforme, dada por index, es válida. index debe estar entre cero y el valor de GL_ACTIVE_SUBROUTINE_UNIFORMS menos uno para la etapa del sombreador.

Si pname es GL_NUM_COMPATIBLE_SUBROUTINES, se devuelve un solo entero que indica el número de subrutinas que se pueden asignar al uniforme en values.

Si pname es GL_COMPATIBLE_SUBROUTINES, se devuelve una matriz de enteros en values, donde cada entero especifica el índice de una subrutina activa que se puede asignar al uniforme de subrutina seleccionado. El número de enteros devueltos es el mismo que el valor devuelto para GL_NUM_COMPATIBLE_SUBROUTINES.

Si pname es GL_UNIFORM_SIZE, se devuelve un solo entero en values. Si el uniforme de subrutina seleccionado es una matriz, se devuelve el tamaño declarado de la matriz; de lo contrario, se devuelve uno.

Si pname es GL_UNIFORM_NAME_LENGTH, se devuelve un solo entero que especifica la longitud del nombre del uniforme de subrutina (incluido el carácter nulo de terminación) en values.

ERRORES

GL_INVALID_ENUM se genera si shadertype o pname no son uno de los valores aceptados.

GL_INVALID_VALUE se genera si index es mayor o igual que el valor de GL_ACTIVE_SUBROUTINES.

GL_INVALID_VALUE se genera si program no es el nombre de un objeto de programa existente.

GETS ASOCIADOS

glGetProgramStage() con el argumento GL_ACTIVE_SUBROUTINE_UNIFORMS
