NOMBRE

glProgramParameteri - especificar un parámetro para un objeto de programa

ESPECIFICACIÓN C

void glProgramParameteri(GLuint program, GLenum pname, GLint value);

PARÁMETROS

program

Especifica el nombre de un objeto de programa cuyos parámetros se modificarán.

pname

Especifica el nombre del parámetro a modificar.

value

Especifica el nuevo valor del parámetro especificado por pname para program.

DESCRIPCIÓN

glProgramParameter especifica un nuevo valor para el parámetro denominado por pname para el objeto de programa program.

Si pname es GL_PROGRAM_BINARY_RETRIEVABLE_HINT, value debe ser GL_FALSE o GL_TRUE para indicar a la implementación la intención de la aplicación de recuperar la representación binaria del programa con glGetProgramBinary(). La implementación puede utilizar esta información para almacenar datos que puedan ser útiles para una futura consulta del binario del programa. Se recomienda establecer GL_PROGRAM_BINARY_RETRIEVABLE_HINT para el programa a GL_TRUE antes de llamar a glLinkProgram(), y usar el programa en tiempo de ejecución si el binario se va a recuperar más tarde.

Si pname es GL_PROGRAM_SEPARABLE, value debe ser GL_TRUE o GL_FALSE e indica si program puede ser vinculado a etapas de tubería individuales a través de glUseProgramStages(). El parámetro GL_PROGRAM_SEPARABLE de un programa debe establecerse en GL_TRUE *antes* de llamar a glLinkProgram() para que pueda ser utilizado con un objeto de tubería de programa. El estado inicial de GL_PROGRAM_SEPARABLE es GL_FALSE.

ERRORES

GL_INVALID_OPERATION se genera si program no es el nombre de un objeto de programa existente.

GL_INVALID_ENUM se genera si pname no es uno de los valores aceptados.

GL_INVALID_VALUE se genera si value no es un valor válido para el parámetro denominado por pname.

OBTENCIÓN ASOCIADA

glGetProgram().
