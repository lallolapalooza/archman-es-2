NOMBRE

gl_SampleMaskIn - contiene la máscara de cobertura de muestras calculada para el fragmento actual

DECLARACIÓN

in int gl_SampleMaskIn[] ;.SH "DESCRIPCIÓN"

gl_SampleMaskIn es un lenguaje de fragmentos que indica el conjunto de muestras cubiertas por la primitiva que genera el fragmento durante la rasterización multiespecífica. Tiene un bit de muestra establecido si y solo si la muestra se considera cubierta para esta invocación del sombreador de fragmentos. El bit B de la máscara gl_SampleMask[M] corresponde a la muestra 32 * M + B. La matriz tiene ceil(s / 32) elementos donde s es el número máximo de muestras de color compatibles con la implementación.
