L'emplacement de la variable uniforme à modifier est spécifié par location, qui doit être une valeur renvoyée par glGetUniformLocation(). glProgramUniform opère sur l'objet programme spécifi

Le nombre spécifié dans la commande doit correspondre au nombre de composantes du type de données de la variable uniforme spécifiée (par exemple, 1 pour float, int, unsigned int, bool ; 2 pour vec2, ivec2, uvec2, bvec2, etc.). Le suffixe f indique que des valeurs en virgule flottante sont passées ; le suffixe i indique que des valeurs entières sont passées ; le suffixe ui indique que des valeurs entières non signées sont passées, et ce type doit également correspondre au type de données de la variable uniforme spécifiée. Les variantes i de cette fonction doivent être utilisées pour fournir des valeurs à des variables uniformes définies comme int, ivec2, ivec3, ivec4, ou des tableaux de ceux-ci. Les variantes ui de cette fonction doivent être utilisées pour fournir des valeurs à des variables uniformes définies comme unsigned int, uvec2, uvec3, uvec4, ou des tableaux de ceux-ci. Les variantes f doivent être utilisées pour fournir des valeurs à des variables u niformes de type float, vec2, vec3, vec4, ou des tableaux de ceux-ci. Soit les variantes i, ui ou variantes f peuvent être utilisées pour fournir des valeurs à des variables uniformes de type bool, bvec2, bvec3, bvec4, ou des tableaux de ceux-ci. La

variable

uniforme sera définie à false si la valeur d'entrée est 0 ou 0.0f, et elle sera définie à true dans le cas contraire. Toutes les variables uniformes actives définies dans un objet programme sont initialisées à 0 lorsque l'objet programme est lié avec succès. Elles conservent les valeurs qui leur ont été assignées par un appel

à

glProgramUniform jusqu'à ce que la prochaine opération de liaison réussie ait lieu sur l'objet programme, moment où elles sont à nouveau initialisées à 0. Les commandes glProgramUniform{1|2|3|4}{f|i|ui}v peuvent être utilisées pour modifier une seule variable uniforme ou un tableau de variables uniformes. Ces commandes passent un count et un pointeur vers les valeurs à charger dans une variable uniforme ou un tableau de variables uniformes. Un count de 1 doit être utilisé si l'on modifie la valeur d'une seule variable uniforme, et un count de 1 ou supérieur peut être utilisé pour modifier un tableau entier ou une partie d'un t ableau. Lors du chargement de n éléments à partir d'une position arbitraire m dans un tableau de variables uniformes, les éléments m + n - 1 dans le tableau seront remplacés par les nouvelles valeurs. Si m + n - 1 est supérieur à la taille du tableau de variables uniformes, les valeurs pour tous les éléments du tableau au-delà de la fin du tableau seront ignorées. Le nombre spécifié dans le nom de la commande indique le nombre de composantes pour chaque élément dans value, et il doit correspondre au nombre de composantes dans le type de données de la variable uniforme spécifiée (par exemple, 1 pour float, int, bo

C SPECIFICATION

    void glProgramUniform1uiv(GLint location,
                               GLsizei count,
                               const GLuint *value);

PARAMETERS

location

Specifies the location of an program.

count

Specifies the number of elements that are to be downloaded to the value

Specifies a pointer to the buffer where the values to be downloaded are stored.

DESCRIPTION

Calls to count elements of type location.

The uniforms are identified by the These commands are unaffected by the current program object. The commands are executed by the currently active program object.
