NAME

glProgramUniform4iv — set the value of a uniform variable in an active program object

C SPECIFICATION

void glProgramUniform4iv( GLuint program,
                          GLint location,
                          GLsizei count,
                          const GLint * value );

PARAMETERS

program
Specifies the program object of which the uniform variables are to be modified.
location
Specifies the location of the uniform variable to be modified.
count
Specifies the number of elements that are to be modified.
value
Specifies a pointer to an array of count values that will be used to update the uniform variable.

DESCRIPTION

glProgramUniform4iv specifies the value of a uniform variable in the active program object that is associated with the program object specified by program.

The command signature and parameters are analogous to the corresponding glUniform4iv command, except that the uniform variable is queried from the program object specified by program, not from the currently active program object.

If program is not the name of an active program object, or if location is not a valid uniform location for the active program object, or if the indicated uniform variable is not of type sampler1D, sampler2D, sampler3D, samplerCube, sampler1DShadow, sampler2DShadow, sampler1DArray, sampler2DArray, samplerCubeMap, samplerBuffer, sampler2DMS, or sampler2DMultisampleArray, then glProgramUniform4iv, glProgramUniform4iv, glProgramUniform4iuii, and glProgramUniform4uiv are respectively, are ignored.

The uniform variables specified by program and location must be of type integer, or int-vec4.

If location is the location of a uniform variable that is an array, glProgramUniform4iv updates the element of the array whose index is 0.

If location is the location of a uniform variable that is an array, glProgramUniform4iv updates the elements of the array whose indices are 0 through count-1.

If program is the active program object, and location is the location of a uniform variable, then glProgramUniform4iv assigns the value of the uniform variable in the active program object.

If program is not the active program object, then glProgramUniform4iv assigns the value of the uniform variable in the program object specified by program.

If program is not the active program object, and location is not a valid uniform location for the program object specified by program, then glProgramUniform4iv is ignored.

If location is the location of a uniform variable that is not of type int-vec4, then glProgramUniform4iv is ignored.

If location is the location of a uniform variable that is an array, then glProgramUniform4iv updates the element of the array whose index is 0.

If location is the location of a uniform variable that is an array, then glProgramUniform4iv updates the elements of the array whose indices are 0 through count-1.

If location is the location of a uniform variable that is not of type int-vec4, then glProgramUniform4iv is ignored.

If program is not the active program object, then glProgramUniform4iv assigns the value of the uniform variable in the program object specified by program.

If program is not the active program object, and location is not a valid uniform location for the program object specified by program, then glProgramUniform4iv is ignored.
