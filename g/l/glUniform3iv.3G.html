glUniform modifie la
valeur d'une variable

uniform

e

ou d'un tableau de variables uniformes. L'emplacement de la variable uniforme à modifier est spécifié par location, qui doit être une valeur retournée par glGetUniformLocation(). glUniform opère sur l'objet programme qui a été rendu partie de l'état courant en appelant glUseProgram(). Les commandes glUniform{1|2|3|4}{f|i|ui} sont util

isées

pour changer la valeur de la variable uniforme spécifiée par location en utilisant les valeurs passées en arguments. Le nombre spécifié dans la commande doit correspondre au nombre de composantes dans le type de données de la variable uniforme spécifiée (par ex., 1 pour float, int, unsigned int, bool ; 2 pour vec2, ivec2, uvec2, bvec2, etc.). Le suffixe f indique que des valeurs en virgule flottante sont passées ; le suffixe i indique que des valeurs entières sont passées ; le suffixe ui indique que des valeurs entières non signées sont passées, et ce type doit également correspondre au type de données de la variable uniforme spécifiée. Les variantes i de cette fonction doivent être utilisées pour fournir des valeurs pour des variables uniformes définies comme int, ivec2, ivec3, ivec4, o arrays de estos. Las variantes ui de esta función deben usarse para proporcionar valores para variables uniformes definidas como unsigned int, uvec2, uvec3, uvec4, o arrays de estos. Las variantes f deben usarse para proporcionar valores para variables uniformes de tipo float, vec2, vec3, vec4, o arrays de estos. Cualquiera de las variantes i, ui o f puede usarse para proporcionar valores para variables uniformes de tipo bool, bvec2, bvec3, bvec4, o arrays de estos. La variable uniforme se establecerá en false si el valor de entrada es 0 o 0.0f, y se establecerá en true en caso

contrario.

Todas las variables uniformes activas definidas en un objeto de programa se inicializan a 0 cuando el objeto de programa se vincula correctamente. Conservan los valores asignados a ellos por una llamada a glUniform hasta que se produce la siguiente operación de vinculación exitosa en el objeto de programa, cuando se vuelven a inicializar a

0.

Los comandos glUniform{1|2|3|4}{f|i|ui}v pueden usarse para modificar una variable uniforme individual o una variable uniforme array. Estos comandos pasan un conteo y un puntero a los valores a cargar en una variable uniforme o una variable uniforme array. Debe usarse un conteo de 1 si se modifica el valor de una variable uniforme individual, y un conteo de 1 o superior puede usarse para modificar un array completo o parte de un array. Al cargar n elementos comenzando en una posición arbitraria m en un array de variables uniformes, los elementos m + n - 1 en el array serán reemplazados con los nuevos valores. Si m + n - 1 es mayor que el tamaño del array de variables uniformes, los valores de todos los elementos del array más allá del final del array serán ignorados. El número especificado en el nombre del comando indica el número de componentes para cada elemento en value, y debe coincidir con el número de componentes en el tipo de datos de la variable uniforme especificada (por ejemplo, 1 para float, int, bool; 2 para vec2, ivec2, bvec2, etc.). El tipo de datos especificado en el nombre del comando debe coincidir con el tipo de datos de la variable uniforme especificada como se describió anteriormente para glUniform{1|2|3|4}

{f|i|ui}.

Para arrays de variables uniformes, cada elemento del array se considera que es del tipo indicado en el nombre del comando (por ejemplo, glUniform3f o glUniform3fv pueden usarse para cargar un array de variables uniformes de tipo vec3). El número de elementos del array de variables uniformes a modificar se especifica mediante coun

t

Los comandos glUniformMatrix{2|3|4|2x3|3x2|2x4|4x2|3x4|4x3}fv se usan para modificar una matriz o un array de matrices. Los números en el nombre del comando se interpretan como la dimensionalidad de la matriz. El número 2 indica una matriz 2 × 2 (es decir, 4 valores), el número 3 indica una matriz 3 × 3 (es decir, 9 valores), y el número 4 indica una matriz 4 × 4 (es decir, 16 valores). La dimensionalidad de matrices no cuadradas es explícita, con el primer número representando el número de columnas y el segundo número representando el número de filas. Por ejemplo, 2x4 indica una matriz 2 × 4 con 2 columnas y 4 filas (es decir, 8 valores). Si transpose es GL_FALSE, se asume que cada matriz se proporciona en orden column-major. Si transpose es GL_TRUE, se asume que cada matriz se proporciona en orden row-major. El argumento count indica el número de matrices a pasar. Debe usarse un conteo de 1 si se modifica el v

alor de una matriz individual, y un conteo mayor que
1 puede usarse para modificar un array de matrices.

S

glUniform1i y glUniform1iv son las únicas dos funciones que pueden usarse para cargar variables uniformes definidas como tipos sampler. Cargar samplers con cualquier otra función resultará en un error GL_INVALID_OPERATION

.

Si count es mayor que 1 y la variable uniforme indicada no es un array, se genera un error GL_INVALID_OPERATION y la variable uniforme especificada permanecerá sin

cambios.

Aparte de las excepciones anteriores, si el tipo y tamaño de la variable uniforme tal como se define en el shader no coinciden con el tipo y tamaño especificados en el nombre del comando usado para cargar su valor, se generará un error GL_INVALID_OPERATION y la variable uniforme especificada permanecerá sin

cambios.

Si location es un valor diferente de -1 y no representa una ubicación de variable uniforme válida en el objeto de programa actual, se generará un error, y no se realizarán cambios en el almacenamiento de variables uniformes del objeto de programa actual. Si location es igual a -1, los datos pasados serán ignorados silenc

especificada no será cambiada.

NAME

glUniformMatrix2x3fv, glUniformMatrix3x2fv, glUniformMatrix2x4fv, glUniformMatrix4x2fv, glUniformMatrix3x4fv, glUniformMatrix4x3fv ― set matrix uniforms

C SPECIFICATION

    void glUniformMatrix2x3fv(GLint location, GLsizei count, GLboolean transpose,
                              const GLfloat *value);
    void glUniformMatrix3x2fv(GLint location, GLsizei count, GLboolean transpose,
                              const GLfloat *value);
    void glUniformMatrix2x4fv(GLint location, GLsizei count, GLboolean transpose,
                              const GLfloat *value);
    void glUniformMatrix4x2fv(GLint location, GLsizei count, GLboolean transpose,
                              const GLfloat *value);
    void glUniformMatrix3x4fv(GLint location, GLsizei count, GLboolean transpose,
                              const GLfloat *value);
    void glUniformMatrix4x3fv(GLint location, GLsizei count, GLboolean transpose,
                              const GLfloat *value);

PARAMETERS

location
Specifies the location of the uniform variable to be modified.
count
Specifies the number of matrices to be downloaded.
transpose
Specifies whether to transpose each matrix as the values are loaded into the associated uniform variable. For glUniformMatrix3x2fv, glUniformMatrix2x3fv, glUniformMatrix3x4fv, glUniformMatrix4x3fv, glUniformMatrix2x4fv, and glUniformMatrix4x2fv, the transpose parameter must be GL_FALSE. If GL_TRUE is used with these commands, the matrix values are transposed as they are loaded.
value
Specifies a pointer to an array of count matrices, which will be used to update the specified uniform variable.
The number of elements to be loaded is count times the number of elements in the specified matrix type. For example, if glUniformMatrix2x3fv is called, then count * 6 matrix elements will be loaded.

DESCRIPTION

Uniform variables are immutable pieces of data that are part of a shader program. They are referred to as uniform because they are the same (uniform) across all the vertices of a primitive or all the fragments generated by a primitive.

These commands load count matrices into the uniform variable specified by location.

The matrices are loaded from the array of floating-point values pointed to by value. If transpose is GL_TRUE, each individual matrix is transposed before it is uploaded to the uniform variable.

The matrices loaded by glUniformMatrix2x3fv, glUniformMatrix3x2fv, glUniformMatrix2x4fv, glUniformMatrix4x2fv, glUniformMatrix3x4fv, and glUniformMatrix4x3fv are specified in column-major order. For example, glUniformMatrix2x3fv expects an array of 2x3 matrices. Each matrix has 2 columns and 3 rows, and it will be specified in column-major order as:

    m00 m10 m01 m11 m02 m12

If transpose is GL_TRUE, the matrix will be transposed before it is loaded.

If transpose is GL_FALSE, the matrix is assumed to be in column-major order.

The parameters location and count must be consistent with the type of the uniform variable specified by location. If the uniform variable specified by location is not of type matrix, or if location is not a valid uniform location, or if count is negative, then a GL_INVALID_OPERATION error is generated.

If the uniform variable specified by location is an array, then count indicates the number of elements in the array whose values are to be downloaded. Otherwise, count must be 1.

If transpose is GL_TRUE, the number of elements transferred from value must be count * * , where and are the dimensions of the matrix. For glUniformMatrix2x3fv, the number of elements is count * 2 * 3.

If transpose is GL_FALSE, the number of elements transferred from value must be count * * . For glUniformMatrix2x3fv, the number of elements is count * 2 * 3.

If the number of elements in value is not equal to the product of count, rows, and columns, then a GL_INVALID_OPERATION error is generated.

NOTES

For versions of OpenGL prior to 2.0, the functions glUniformMatrix2x3fv, glUniformMatrix3x2fv, glUniformMatrix2x4fv, glUniformMatrix4x2fv, glUniformMatrix3x4fv, and glUniformMatrix4x3fv are not available.

The transpose parameter for these commands is ignored if the version of OpenGL ES or the GLSL version being used is less than 1.30. For these older versions, matrices are always specified in column-major order.

ERRORS

GL_INVALID_OPERATION is generated if location is not a valid uniform location. GL_INVALID_OPERATION is generated if the size of the uniform variable indicated by location is not compatible with the specified command, including the transpose parameter. For example, if transpose is GL_TRUE, then the uniform variable must not be a matrix of incompatible dimensions. For example, glUniformMatrix2x3fv must be used to set a uniform variable of type mat2x3.

GL_INVALID_VALUE is generated if count is negative.
