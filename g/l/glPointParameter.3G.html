GLPOINTPARAMETER(3G) [FIXME: manual] GLPOINTPARAMETER(3G)

NOMBRE

glPointParameter - especificar parámetros de punto

C ESPECIFICACIÓN

void glPointParameterf(GLenum pname, GLfloat param);

void glPointParameteri(GLenum pname, GLint param);

void glPointParameterfv(GLenum pname, const GLfloat * params);

void glPointParameteriv(GLenum pname, const GLint * params);

PARÁMETROS

pname

Especifica un parámetro de punto de valor único. Se aceptan GL_POINT_FADE_THRESHOLD_SIZE y GL_POINT_SPRITE_COORD_ORIGIN.

param

Para glPointParameterf y glPointParameteri, especifica el valor al que se establecerá pname.

params

Para glPointParameterfv y glPointParameteriv, especifica un puntero a una matriz donde se almacena el valor o los valores que se asignarán a pname.

DESCRIPCIÓN

Los siguientes valores son aceptados para pname:

GL_POINT_FADE_THRESHOLD_SIZE

params es un único valor de punto flotante que especifica el valor umbral al que se limitan los tamaños de punto si exceden el valor especificado. El valor predeterminado es 1.0.

GL_POINT_SPRITE_COORD_ORIGIN

params es una única enumeración que especifica el origen de coordenadas de textura del sprite de punto, ya sea GL_LOWER_LEFT o GL_UPPER_LEFT. El valor predeterminado es GL_UPPER_LEFT.

ERRORES

Se genera GL_INVALID_VALUE si el valor especificado para GL_POINT_FADE_THRESHOLD_SIZE es menor que cero.

Se genera GL_INVALID_ENUM si el valor especificado para GL_POINT_SPRITE_COORD_ORIGIN no es GL_LOWER_LEFT ni GL_UPPER_LEFT.

GETS ASOCIADOS

glGet() con el argumento GL_POINT_FADE_THRESHOLD_SIZE

glGet() con el argumento GL_POINT_SPRITE_COORD_ORIGIN
