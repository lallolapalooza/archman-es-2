DESCRIPCIÓ

N

glMapBuffer y glMapNamedBuffer mapean todo el almacén de datos de un objeto buffer especificado en el espacio de direcciones del cliente. Los datos pueden entonces ser leídos y/o escritos directamente en relación con el puntero devuelto, dependiendo de la política de acceso especi

ficada.

Se devuelve un puntero al inicio del rango mapeado una vez que todas las operaciones pendientes en ese objeto buffer se han completado, y puede usarse para modificar y/o consultar el rango correspondiente del almacén de datos de acuerdo con el valor de access

:
•GL_READ_ONLY indica que el puntero devuelto puede usarse para leer datos del objeto
buffer.
•GL_WRITE_ONLY indica que el puntero devuelto puede usarse para modificar datos del objeto
buffer.
•GL_READ_WRITE indica que el puntero devuelto puede usarse para leer y modificar datos del objeto
buffer.

Si se genera un error, se devuelve un puntero

NULL.

Si no ocurre ningún error, el puntero devuelto reflejará una alineación al valor de GL_MIN_MAP_BUFFER_ALIGNMENT unidades básicas de

máquina.

Los valores de punteros devueltos no pueden pasarse como valores de parámetro a comandos GL. Por ejemplo, no pueden usarse para especificar punteros de arrays, ni para especificar o consultar datos de imágenes de píxeles o texturas; tales acciones producen resultados indefinidos, aunque las implementaciones pueden no comprobar este comportamiento por razones de

rendimiento.

No se genera ningún error GL si el puntero devuelto se accede de una manera inconsistente con access (p. ej., usado para leer de un mapeo hecho con access GL_WRITE_ONLY o para escribir en un mapeo hecho con access GL_READ_ONLY), pero el resultado es indefinido y pueden ocurrir errores del sistema (posiblemente incluyendo la terminación del programa)

.

Los mapeos a los almacenes de datos de objetos buffers pueden tener características de rendimiento no estándar. Por ejemplo, tales mapeos pueden marcarse como regiones de memoria no cacheables, y en tales casos leer de ellos puede ser muy lento. Para asegurar un rendimiento óptimo, el cliente debe usar el mapeo de una manera consistente con los valores de GL_BUFFER_USAGE para el objeto buffer y de access. Usar un mapeo de una manera inconsistente con estos valores probab

lemente sea varios órdenes de magnit
ud más lento que usar memoria normal.

NOTA

S

La alineación del puntero devuelto solo se garantiza si la versión de GL es 4.2 o superior. Además, el objetivo GL_ATOMIC_COUNTER_BUFFER solo se acepta si la versión de GL es 4.2 o

superior.

Los objetivos GL_DISPATCH_INDIRECT_BUFFER y GL_SHADER_STORAGE_BUFFER solo están disponibles si la versión de GL es 4.3 o

superior.

El objetivo GL_QUERY_BUFFER solo está disponi

ble si la versión de
GL es 4.4 o superior.
