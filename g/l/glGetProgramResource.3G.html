NOMBRE

glGetProgramResource - recupera valores para múltiples propiedades de un único recurso activo dentro de un objeto de programa

ESPECIFICACIÓN C

void glGetProgramResourceiv(GLuint program, GLenum programInterface, GLuint index, GLsizei propCount, const GLenum * props, GLsizei bufSize, GLsizei * length, GLint * params);

PARÁMETROS

program

El nombre de un objeto de programa cuyos recursos se van a consultar.

programInterface

Un token que identifica la interfaz dentro de program que contiene el recurso llamado name.

DESCRIPCIÓN

glGetProgramResourceiv devuelve valores para múltiples propiedades de un único recurso activo con un índice de index en la interfaz programInterface del objeto de programa program. Para cada recurso, se devuelven los valores para propCount propiedades especificadas por el array props. propCount no puede ser cero. Se genera un error si algún valor en props no es una de las propiedades descritas a continuación o si algún valor en props no está permitido para programInterface. El conjunto de valores permitidos de programInterface para cada propiedad se puede encontrar en la siguiente tabla:

Para la propiedad GL_NAME_LENGTH, se escribe un único entero que identifica la longitud de la cadena de nombre asociada con una variable, bloque de interfaz o subrutina activa en params. La longitud del nombre incluye un carácter nulo de terminación.

Para la propiedad GL_TYPE, se escribe un único entero que identifica el tipo de una variable activa en params. El entero devuelto es uno de los valores que se encuentran en la tabla 2.16.

Para la propiedad GL_ARRAY_SIZE, se escribe un único entero que identifica el número de elementos de array activos de una variable activa en params. El tamaño del array devuelto está en unidades del tipo asociado con la propiedad GL_TYPE. Para variables activas que no corresponden a un array de tipos básicos, se escribe el valor cero en params.

Para la propiedad GL_BLOCK_INDEX, se escribe un único entero que identifica el índice del bloque de interfaz activo que contiene una variable activa en params. Si la variable no es miembro de un bloque de interfaz, se escribe el valor -1 en params.

Para la propiedad GL_OFFSET, se escribe un único entero que identifica el desplazamiento de una variable activa en params. Para variables en las interfaces GL_UNIFORM y GL_BUFFER_VARIABLE que están respaldadas por un objeto de buffer, el valor escrito es el desplazamiento de esa variable relativo a la base del rango del buffer que contiene su valor. Para la propiedad GL_ARRAY_STRIDE, se escribe en params un único entero que identifica el intervalo entre elementos de una matriz en una variable activa. Para las variables activas declaradas como una matriz de tipos básicos, el valor escrito es la diferencia, en unidades básicas de máquina, entre los desplazamientos de elementos consecutivos en una matriz. Para las variables activas no declaradas como una matriz de tipos básicos, se escribe cero en params. Para las variables activas no respaldadas por un objeto de búfer, se escribe -1 en params, independientemente del tipo de

variable.

Para la propiedad GL_MATRIX_STRIDE, se escribe en params un único entero que identifica el intervalo entre columnas de una matriz en orden por columnas o filas de una matriz en orden por filas. Para las variables activas declaradas como una sola matriz o una matriz de matrices, el valor escrito es la diferencia, en unidades básicas de máquina, entre los desplazamientos de columnas o filas consecutivas en cada matriz. Para las variables activas no declaradas como una matriz o una matriz de matrices, se escribe cero en params. Para las variables activas no respaldadas por un objeto de búfer, se escribe -1 en params, independientemente del tipo de

variable.

Para la propiedad GL_IS_ROW_MAJOR, se escribe en params un único entero que identifica si una variable activa es una matriz en orden por filas. Para las variables activas respaldadas por un objeto de búfer, declaradas como una sola matriz o una matriz de matrices, y almacenadas en orden por filas, se escribe uno en params. Para todas las demás variables activas, se escribe cero en params

.

Para la propiedad GL_ATOMIC_COUNTER_BUFFER_INDEX, se escribe en params un único entero que identifica el índice del búfer de contadores atómicos activo que contiene una variable activa. Si la variable no es un contador atómico uniforme, se escribe el valor -1 en params

.

Para la propiedad GL_BUFFER_BINDING, se escribe en params el índice del punto de enlace de búfer asociado con el bloque uniforme activo, el bloque de almacenamiento de sombreado, el búfer de contadores atómicos o el búfer de

realimentación de transformación.

Para la propiedad GL_BUFFER_DATA_SIZE, se escribe en params el tamaño total mínimo del objeto de búfer, en unidades básicas de máquina, dependiente de la implementación, necesario para contener todas las variables activas asociadas con un bloque uniforme activo, un bloque de almacenamiento de sombreado o un búfer de contadores atómicos. Si el miembro final de un bloque de almacenamiento de sombreado activo es una matriz sin tamaño declarado, el tamaño mínimo del búfer se calcula asumiendo que la matriz fue declarada como una matriz con un

elemento.

Para la propiedad GL_NUM_ACTIVE_VARIABLES, se escribe en params el número de variables activas asociadas con un bloque uniforme activo, un bloque de almacenamiento de sombreado, un búfer de contadores atómicos o un búfer de realimentación

de transformación.

Para la propiedad GL_ACTIVE_VARIABLES, se escribe en params un array de índices de variables activas asociadas con un bloque uniforme activo, un bloque de almacenamiento de sombreado, un búfer de contadores atómicos o un búfer de realimentación de transformación. El número de valores escritos en params para un recurso activo está dado por el valor de la propiedad GL_NUM_ACTIVE_VARIABLES para el

recurso.

Para las propiedades GL_REFERENCED_BY_VERTEX_SHADER, GL_REFERENCED_BY_TESS_CONTROL_SHADER, GL_REFERENCED_BY_TESS_EVALUATION_SHADER, GL_REFERENCED_BY_GEOMETRY_SHADER, GL_REFERENCED_BY_FRAGMENT_SHADER y GL_REFERENCED_BY_COMPUTE_SHADER, se escribe en params un único entero que identifica si el recurso activo es referenciado por los sombreadores de vértice, control de teselación, evaluación de teselación, geometría o fragmento, respectivamente, en el objeto de programa. Se escribe el valor uno en params si una variable activa es referenciada por el sombreador correspondiente, o si un bloque uniforme activo, un bloque de almacenamiento de sombreado o un búfer de contadores atómicos contiene al menos una variable referenciada por el sombreador correspondiente. De lo contrario, se escribe el valor cero en params

.

Para la propiedad GL_TOP_LEVEL_ARRAY_SIZE, se escribe en params un único entero que identifica el número de elementos de matriz activos del miembro de nivel superior del bloque de almacenamiento de sombreado que contiene la variable activa. Si el miembro de nivel superior del bloque no está declarado como una matriz, se escribe el valor uno en params. Si el miembro de nivel superior del bloque es una matriz sin tamaño declarado, se escribe el valor cero en params

.

Para la propiedad GL_TOP_LEVEL_ARRAY_STRIDE, se escribe en params un único entero que identifica el intervalo entre elementos de la matriz del miembro de nivel superior del bloque de almacenamiento de sombreado que contiene la variable activa. Para los miembros de nivel superior del bloque declarados como matrices, el valor escrito es la diferencia, en unidades básicas de máquina, entre los desplazamientos de la variable activa para elementos consecutivos en la matriz de nivel superior. Para los miembros de nivel superior del bloque no declarados como una matriz, se escribe cero en params

.

Para la propiedad GL_LOCATION, se escribe en params un único entero que identifica la ubicación asignada para una variable uniforme activa, de entrada, de salida o de subrutina. Para variables de entrada, de salida o uniformes con ubicaciones especificadas por un calificador de diseño, se utiliza la ubicación especificada. Para variables de entrada del sombreador de vértice o de salida del sombreador de fragmento sin un calificador de diseño, se escribe en params la ubicación asignada cuando se enlaza un programa. Para todas las demás variables de entrada y salida, se escribe el valor -1 en params. Para uniformes en bloques uniformes, se escribe el valor -1 en params

.

Para la propiedad GL_LOCATION_INDEX, se escribe en params un único entero que identifica el índice de color de fragmento de una variable de salida del sombreador de fragmento activa. Si la variable activa es una salida para un sombreador que no es de fragmento, se escribirá el valor -1 en params

.

Para la propiedad GL_IS_PER_PATCH, un entero único que identifica si la entrada o salida es un atributo por parche. Si la variable activa es un atributo por parche (declarada con el calificador patch), se escribe el valor uno en params; de lo contrario, se escribe el valor cero en pa

rams.

Para la propiedad GL_LOCATION_COMPONENT, se escribe en params un entero único que indica el primer componente de la ubicación asignada a una variable de entrada o salida activa. Para variables de entrada y salida con un componente especificado por un calificador de diseño, se escribe el componente especificado. Para todas las demás variables de entrada y salida, se escribe el valor

cero.

Para la propiedad GL_TRANSFORM_FEEDBACK_BUFFER_INDEX, se escribe en params un entero único que identifica el índice del búfer de realimentación de transformación activo asociado con una variable activa. Para variables correspondientes a los nombres especiales "gl_NextBuffer", "gl_SkipComponents1", "gl_SkipComponents2", "gl_SkipComponents3" y "gl_SkipComponents4", se escribe -1 en params

.

Para la propiedad GL_TRANSFORM_FEEDBACK_BUFFER_STRIDE, se escribe en params un entero único que identifica el intervalo, en unidades básicas de máquina, entre vértices consecutivos escritos en el búfer

de realimentación de transformación.
