GLBINDBUFFERSBASE(3G) [FIXME: manual] GLBINDBUFFERSBASE(3G)

NOMBRE

glBindBuffersBase - enlaza uno o varios objetos de búfer a una secuencia de objetivos indexados de búfer

ESPECIFICACIÓN C

void glBindBuffersBase(GLenum target, GLuint first, GLsizei count, const GLuint *buffers);

PARÁMETROS

target

Especifica el objetivo de la operación de enlace. target debe ser uno de GL_ATOMIC_COUNTER_BUFFER, GL_TRANSFORM_FEEDBACK_BUFFER, GL_UNIFORM_BUFFER o GL_SHADER_STORAGE_BUFFER.

first

Especifica el índice del primer punto de enlace dentro del array especificado por target.

count

Especifica el número de puntos de enlace contiguos a los que enlazar los búferes.

buffers

Un puntero a un array de nombres de objetos de búfer para enlazar a los objetivos en el punto de enlace especificado, o NULL.

DESCRIPCIÓN

glBindBuffersBase enlaza un conjunto de count objetos de búfer cuyos nombres se proporcionan en el array buffers a los count puntos de enlace consecutivos que comienzan en el índice first del array de objetivos especificado por target. Si buffers es NULL, entonces glBindBuffersBase desvincula cualquier búfer que esté actualmente enlazado a los puntos de enlace referenciados. Suponiendo que no se generen errores, es equivalente al siguiente pseudocódigo, que llama a glBindBufferBase(), con la excepción de que el target no indexado no se modifica por glBindBuffersBase:

    for (i = 0; i < count; i++) {
        if (buffers != NULL) {
            glBindBufferBase(target, first + i, buffers[i]);
        } else {
            glBindBufferBase(target, first + i, 0);
        }
    }

Cada entrada en buffers se verificará individualmente y, si se encuentra inválida, el estado de ese índice de enlace de búfer no se modificará y se generará un error. Sin embargo, el estado de otros índices de enlace de búfer referenciados por el comando aún se actualizará.

NOTAS

glBindBuffersBase solo está disponible si la versión de GL es 4.4 o superior.

ERRORES

Se genera GL_INVALID_ENUM si target no es GL_ATOMIC_COUNTER_BUFFER, GL_TRANSFORM_FEEDBACK_BUFFER, GL_UNIFORM_BUFFER o GL_SHADER_STORAGE_BUFFER.

Se genera GL_INVALID_OPERATION si first + count es mayor que el número de puntos de enlace indexados específicos del objetivo.

Se genera GL_INVALID_OPERATION si cualquier valor en buffers no es cero o el nombre de un objeto de búfer existente.
