NOMBRE

glDrawElementsInstancedBaseVertex - renderiza múltiples instancias de un conjunto de primitivas a partir de datos de array con un desplazamiento por elemento

ESPECIFICACIÓN C

void glDrawElementsInstancedBaseVertex(GLenum mode, GLsizei count, GLenum type, void *indices, GLsizei instancecount, GLint basevertex);

PARÁMETROS

mode

Especifica qué tipo de primitivas se deben renderizar. Se aceptan los símbolos constantes GL_POINTS, GL_LINE_STRIP, GL_LINE_LOOP, GL_LINES, GL_TRIANGLE_STRIP, GL_TRIANGLE_FAN, GL_TRIANGLES, GL_LINES_ADJACENCY, GL_LINE_STRIP_ADJACENCY, GL_TRIANGLES_ADJACENCY, GL_TRIANGLE_STRIP_ADJACENCY y GL_PATCHES.

count

Especifica el número de elementos a renderizar.

type

Especifica el tipo de los valores en indices. Debe ser uno de GL_UNSIGNED_BYTE, GL_UNSIGNED_SHORT, o GL_UNSIGNED_INT.

indices

Especifica un puntero a la ubicación donde se almacenan los índices.

instancecount

Especifica el número de instancias de la geometría indexada que se deben dibujar.

basevertex

Especifica una constante que se debe añadir a cada elemento de indices al seleccionar elementos de los arrays de vértices habilitados.

DESCRIPCIÓN

glDrawElementsInstancedBaseVertex se comporta de manera idéntica a glDrawElementsInstanced() excepto que el i-ésimo elemento transferido por la llamada de dibujo correspondiente se tomará del elemento indices[i] + basevertex de cada array habilitado. Si el valor resultante es mayor que el valor máximo representable por type, es como si el cálculo se hubiera convertido a enteros sin signo de 32 bits (con desbordamiento en condiciones de desbordamiento). La operación no está definida si la suma fuera negativa.

NOTAS

glDrawElementsInstancedBaseVertex solo se admite si la versión de GL es 3.2 o superior.

ERRORES

Se genera GL_INVALID_ENUM si mode no es un valor aceptado.

Se genera GL_INVALID_VALUE si count o instancecount son negativos.

Se genera GL_INVALID_OPERATION si un shader de geometría está activo y mode es incompatible con el tipo de primitiva de entrada del shader de geometría en el objeto de programa actualmente instalado.

Se genera GL_INVALID_OPERATION si un nombre de objeto de buffer distinto de cero está enlazado a un array habilitado o al array de elementos y el almacén de datos del objeto de buffer está actualmente mapeado.
