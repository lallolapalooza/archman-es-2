NOMBRE

glab-deploy-key-get - Devuelve una única clave de despliegue especificada por el ID.

SINOPSIS

glab deploy-key get [flags]

DESCRIPCIÓN

Devuelve una única clave de despliegue especificada por el ID.

OPCIONES HEREDADAS DE LOS COMANDOS PADRE

-h, --help[=false] Mostrar ayuda para este comando.

-R, --repo="" Seleccionar otro repositorio. Se puede usar el formato OWNER/REPO o GROUP/NAMESPACE/REPO. También acepta URL completa o URL de Git.

EJEMPLO

# Obtener clave de despliegue con ID como argumento
$ glab deploy-key get 1234
