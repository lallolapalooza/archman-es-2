NOMBRE

glTexSubImage3D, glTextureSubImage3D - especificar una subimagen de textura tridimensional

ESPECIFICACIÓN C

void glTexSubImage3D(GLenum target, GLint level, GLint xoffset, GLint yoffset, GLint zoffset, GLsizei width, GLsizei height, GLsizei depth, GLenum format, GLenum type, const void * pixels);

void glTextureSubImage3D(GLuint texture, GLint level, GLint xoffset, GLint yoffset, GLint zoffset, GLsizei width, GLsizei height, GLsizei depth, GLenum format, GLenum type, const void *pixels);

PARÁMETROS

target

Especifica el destino al que se vincula la textura para glTexSubImage3D. Debe ser GL_TEXTURE_3D o GL_TEXTURE_2D_ARRAY.

texture

Especifica el nombre del objeto de textura para glTextureSubImage3D. El destino efectivo de texture debe ser uno de los valores de target válidos anteriores.

level

Especifica el número de nivel de detalle. El nivel 0 es el nivel de imagen base. El nivel n es la reducción de mipmap de nivel n.

xoffset

Especifica un desplazamiento de texel en la dirección x dentro de la matriz de textura.

yoffset

Especifica un desplazamiento de texel en la dirección y dentro de la matriz de textura.

zoffset

Especifica un desplazamiento de texel en la dirección z dentro de la matriz de textura.

width

Especifica el ancho de la subimagen de textura.

height

Especifica la altura de la subimagen de textura.

depth

Especifica la profundidad de la subimagen de textura.

format

Especifica el formato de los datos de píxeles. Se aceptan los siguientes valores simbólicos: GL_RED, GL_RG, GL_RGB, GL_BGR, GL_RGBA, GL_DEPTH_COMPONENT y GL_STENCIL_INDEX.

type

Especifica el tipo de datos de los píxeles. Se aceptan los siguientes valores simbólicos: GL_UNSIGNED_BYTE, GL_BYTE, GL_UNSIGNED_SHORT, GL_SHORT, GL_UNSIGNED_INT, GL_INT, GL_FLOAT, GL_UNSIGNED_BYTE_3_3_2, GL_UNSIGNED_BYTE_2_3_3_REV, GL_UNSIGNED_SHORT_5_6_5, GL_UNSIGNED_SHORT_5_6_5_REV, GL_UNSIGNED_SHORT_4_4_4_4, GL_UNSIGNED_SHORT_4_4_4_4_REV, GL_UNSIGNED_SHORT_5_5_5_1, GL_UNSIGNED_SHORT_1_5_5_5_REV, GL_UNSIGNED_INT_8_8_8_8, GL_UNSIGNED_INT_8_8_8_8_REV, GL_UNSIGNED_INT_10_10_10_2, y GL_UNSIGNED_INT_2_10_10_10_REV.

pixels

Especifica un puntero a los datos de la imagen en memoria.

DESCRIPCIÓN

La texturización mapea una porción de una imagen de textura especificada a cada primitiva gráfica para la que la texturización está habilitada.

glTexSubImage3D y glTextureSubImage3D redefinen una subregión contigua de una textura existente tridimensional o de matriz bidimensional. Los texeles referenciados por pixels reemplazan la porción de la matriz de textura existente con índices x entre xoffset y xoffset + width - 1, inclusive, índices y entre yoffset e yoffset + height - 1, inclusive, e índices z entre zoffset y zoffset + depth - 1, inclusive. Para texturas tridimensionales, el índice z se refiere a la tercera dimensión. Para texturas de matriz bidimensional, el índice z se refiere al índice de la rebanada. Esta región no puede incluir ningún texel fuera del rango de la matriz de textura tal como se especificó originalmente. No es un error especificar una subtextura con ancho, alto o profundidad cero, pero tal especificación no tiene efecto.

Si un objeto de búfer con nombre distinto de cero está vinculado al destino GL_PIXEL_UNPACK_BUFFER (ver glBindBuffer()) mientras se especifica una imagen de textura, pixels se trata como un desplazamiento de bytes en el almacén de datos del objeto de búfer.

NOTAS

Los modos de glPixelStore() afectan a las imágenes de textura.

glTexSubImage3D y glTextureSubImage3D especifican una subtextura tridimensional o de matriz bidimensional para la unidad de textura actual, especificada con glActiveTexture().

GL_STENCIL_INDEX se acepta para format solo si la versión de GL es 4.4 o superior.

ERRORES

GL_INVALID_ENUM se genera si target o el destino efectivo de texture no es GL_TEXTURE_3D, GL_TEXTURE_2D_ARRAY o GL_TEXTURE_CUBE_MAP_ARRAY.

GL_INVALID_OPERATION es generado por glTextureSubImage3D si texture no es el nombre de un objeto de textura existente.

GL_INVALID_ENUM se genera si format no es una constante de formato aceptada.

GL_INVALID_ENUM se genera si type no es una constante de tipo.

GL_INVALID_VALUE se genera si level es menor que 0.

GL_INVALID_VALUE puede generarse si level es mayor que log 2 de max, donde max es el valor devuelto por GL_MAX_TEXTURE_SIZE.

GL_INVALID_VALUE se genera si xoffset < - b, xoffset + width > w - b, yoffset < - b, o yoffset + height > h - b, o zoffset < - b, o zoffset + depth > d - b, donde w es GL_TEXTURE_WIDTH, h es GL_TEXTURE_HEIGHT, d es GL_TEXTURE_DEPTH y b es el ancho del borde de la imagen de textura que se está modificando. Tenga en cuenta que w, h y d incluyen el doble del ancho del borde.

GL_INVALID_VALUE se genera si width, height o depth es menor que 0.

GL_INVALID_OPERATION se genera si la matriz de textura no ha sido definida por una operación anterior de glTexImage3D() o glTexStorage3D().

GL_INVALID_OPERATION se genera si type es uno de GL_UNSIGNED_BYTE_3_3_2, GL_UNSIGNED_BYTE_2_3_3_REV, GL_UNSIGNED_SHORT_5_6_5, o GL_UNSIGNED_SHORT_5_6_5_REV y format no es GL_RGB.

GL_INVALID_OPERATION se genera si type es uno de GL_UNSIGNED_SHORT_4_4_4_4, GL_UNSIGNED_SHORT_4_4_4_4_REV, GL_UNSIGNED_SHORT_5_5_5_1, GL_UNSIGNED_SHORT_1_5_5_5_REV, GL_UNSIGNED_INT_8_8_8_8, GL_UNSIGNED_INT_8_8_8_8_REV, GL_UNSIGNED_INT_10_10_10_2, o GL_UNSIGNED_INT_2_10_10_10_REV y format no es GL_RGBA ni GL_BGRA.

GL_INVALID_OPERATION se genera si format es GL_STENCIL_INDEX y el formato interno base no es GL_STENCIL_INDEX.

GL_INVALID_OPERATION se genera si un objeto de búfer con nombre distinto de cero está vinculado al destino GL_PIXEL_UNPACK_BUFFER y el almacén de datos del objeto de búfer está actualmente mapeado.

GL_INVALID_OPERATION se genera si un objeto de búfer con nombre distinto de cero está vinculado al destino GL_PIXEL_UNPACK_BUFFER y los datos se desempaquetarían del objeto de búfer de tal manera que las lecturas de memoria requeridas excederían el tamaño del almacén de datos.

GL_INVALID_OPERATION se genera si un objeto de búfer con nombre distinto de cero está vinculado al destino GL_PIXEL_UNPACK_BUFFER y pixels no es divisible uniformemente por el número de bytes necesarios para almacenar en memoria un dato indicado por type.
