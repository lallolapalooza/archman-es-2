NOMBRE

glGetError - devolver información de error

ESPECIFICACIÓN C

GLenum glGetError(void);

DESCRIPCIÓN

glGetError devuelve el valor de la bandera de error. A cada error detectable se le asigna un código numérico y un nombre simbólico. Cuando ocurre un error, la bandera de error se establece en el valor del código de error apropiado. No se registran otros errores hasta que se llama a glGetError, se devuelve el código de error y la bandera se restablece a GL_NO_ERROR. Si una llamada a glGetError devuelve GL_NO_ERROR, no ha habido ningún error detectable desde la última llamada a glGetError, o desde que se inicializó el GL.

Para permitir implementaciones distribuidas, puede haber varias banderas de error. Si alguna bandera de error individual ha registrado un error, se devuelve el valor de esa bandera y se restablece a GL_NO_ERROR cuando se llama a glGetError. Si más de una bandera ha registrado un error, glGetError devuelve y borra un valor de bandera de error arbitrario. Por lo tanto, glGetError siempre debe llamarse en un bucle, hasta que devuelva GL_NO_ERROR, si se van a restablecer todas las banderas de error.

Inicialmente, todas las banderas de error se establecen en GL_NO_ERROR.

Actualmente se definen los siguientes errores:

GL_NO_ERROR

No se ha registrado ningún error. Se garantiza que el valor de esta constante simbólica sea 0.

GL_INVALID_ENUM

Se especifica un valor inaceptable para un argumento enumerado. El comando que causa el problema se ignora y no tiene otro efecto secundario que establecer la bandera de error.

GL_INVALID_VALUE

Un argumento numérico está fuera de rango. El comando que causa el problema se ignora y no tiene otro efecto secundario que establecer la bandera de error.

GL_INVALID_OPERATION

La operación especificada no está permitida en el estado actual. El comando que causa el problema se ignora y no tiene otro efecto secundario que establecer la bandera de error.

GL_INVALID_FRAMEBUFFER_OPERATION

El objeto del framebuffer no está completo. El comando que causa el problema se ignora y no tiene otro efecto secundario que establecer la bandera de error.

GL_OUT_OF_MEMORY

No queda suficiente memoria para ejecutar el comando. El estado del GL no está definido, excepto por el estado de las banderas de error, después de que se registra este error.

GL_STACK_UNDERFLOW

Se ha intentado realizar una operación que causaría un desbordamiento inferior de una pila interna.

GL_STACK_OVERFLOW

Se ha intentado realizar una operación que causaría un desbordamiento superior de una pila interna.

Cuando se establece una bandera de error, los resultados de una operación GL no están definidos solo si ha ocurrido GL_OUT_OF_MEMORY. En todos los demás casos, el comando que genera el error se ignora y no tiene ningún efecto sobre el estado del GL ni sobre el contenido del framebuffer. Si el comando que genera el error devuelve un valor, devuelve 0. Si glGetError genera un error, devuelve 0.
