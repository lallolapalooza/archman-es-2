NOMBRE

gl_PrimitiveIDIn - contiene el índice de la primitiva actual

DECLARACIÓN

in int gl_PrimitiveIDIn ;.SH "DESCRIPCIÓN"

gl_PrimitiveIDIn es una variable de entrada del lenguaje de geometría que almacena el número de primitivas procesadas por el sombreador desde que se inició el conjunto actual de primitivas de renderizado. La primera primitiva procesada por el comando de dibujo tiene el número cero y el contador de ID de primitiva se incrementa después de procesar cada primitiva individual de punto, línea o triángulo. Para triángulos dibujados en modo de punto o línea, el contador de ID de primitiva se incrementa solo una vez, incluso si se dibujan múltiples puntos o líneas. Reiniciar una topología de primitiva usando el índice de reinicio de primitiva no tiene ningún efecto en el contador de ID de primitiva.
