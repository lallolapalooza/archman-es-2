GLUNIFORMBLOCKBINDIN(3G) [FIXME: manual] GLUNIFORMBLOCKBINDIN(3G)

NOMBRE

glUniformBlockBinding - asignar un punto de enlace a un bloque uniform activo

ESPECIFICACIÓN C

void glUniformBlockBinding(GLuint program, GLuint uniformBlockIndex, GLuint uniformBlockBinding);

PARÁMETROS

program

El nombre de un objeto de programa que contiene el bloque uniform activo al que se asignará el enlace.

uniformBlockIndex

El índice del bloque uniform activo dentro de program al que se asignará el enlace.

uniformBlockBinding

Especifica el punto de enlace al que se enlazará el bloque uniform con el índice uniformBlockIndex dentro de program.

DESCRIPCIÓN

Los puntos de enlace para bloques uniform activos se asignan usando glUniformBlockBinding. Cada uno de los bloques uniform activos de un programa tiene un punto de enlace de búfer uniform correspondiente. program es el nombre de un objeto de programa para el cual se ha emitido el comando glLinkProgram() en el pasado.

Si tiene éxito, glUniformBlockBinding especifica que program utilizará el almacén de datos del objeto de búfer enlazado al punto de enlace uniformBlockBinding para extraer los valores de los uniformes en el bloque uniform identificado por uniformBlockIndex.

Cuando un objeto de programa se enlaza o se vuelve a enlazar, el punto de enlace del objeto de búfer uniform asignado a cada uno de sus bloques uniform activos se restablece a cero.

ERRORES

Se genera **GL_INVALID_VALUE** si uniformBlockIndex no es un índice de bloque uniform activo de program.

Se genera **GL_INVALID_VALUE** si uniformBlockBinding es mayor o igual al valor de **GL_MAX_UNIFORM_BUFFER_BINDINGS**.

Se genera **GL_INVALID_VALUE** si program no es el nombre de un objeto de programa generado por GL.

NOTAS

glUniformBlockBinding solo está disponible si la versión de GL es 3.1 o superior.

GETS ASOCIADOS

glGetActiveUniformBlock() con el argumento **GL_UNIFORM_BLOCK_BINDING**
