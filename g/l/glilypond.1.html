Nombre

glilypond - incrusta notación musical LilyPond en groff documentos

Sinopsis

glilypond [-k] [{--ly2eps|--pdf2eps}] [-e directory] [-o output-file] [-p filename-prefix] [-t tdir[{-v|-V}] [--] [file...]
glilypond [{--ly2eps|--pdf2eps}] [--eps_dir directory] [--keep_all] [--output output-file] [--prefix filename-prefix] [--temp_dir tdir] [--verbose] [--] [file...]
glilypond -?
glilypond -h
glilypond --help
glilypond --usage
glilypond -l
glilypond --license
glilypond --version

Descripción

glilypond es un groff(7) preprocesador que permite la incrustación de partituras musicales LilyPond en groff documentos. Si no se proporcionan operandos, o si file es “-”, glilypond lee el flujo de entrada estándar. Un argumento de guion doble (“--”) hace que todos los argumentos posteriores se interpreten como file operandos, incluso si sus nombres comienzan con un guion.

Uso

Actualmente, glilypond funciona con los dispositivos groff ps, dvi, html, y xhtml . Los dispositivos lbp y lj4 no han sido probados. Desafortunadamente, el dispositivo pdf aún no funciona.

Resumen de opciones

-?|-h|--help|--usage
Muestra información de uso y termina.
--version
Muestra información de versión y termina.
-l|--license
Muestra información de la licencia de copyright y termina.

Opciones para construir archivos EPS

--ly2eps
Indica a lilypond(1) que cree archivos Encapsulated PostScript (EPS). Esta es la opción predeterminada.
--pdf2eps
El programa glilypond genera un archivo PDF usando lilypond. Luego, el archivo EPS es generado por pdf2ps y ps2eps.

Directorios y archivos

-e|--eps_dir directory_name
Normalmente todos los archivos EPS se envían al directorio temporal. Con esta opción, puede generar su propio directorio, en el cual se envían todos los archivos EPS útiles. Así, al final, el directorio temporal puede ser eliminado.
-p|--prefix begin_of_name
Normalmente todos los archivos temporales reciben nombres que comienzan con el ly... prefijo. Con esta opción, puede cambiar libremente este prefijo.
-k|--keep_all
Normalmente todos los archivos temporales sin los archivos eps son eliminados. Con esta opción, todos los archivos generados ya sea por el lilypond programa u otros transpositores de formato son conservados.
-t|--temp_dir dir
Con esta opción, usted especifica un directorio que sirve como base para el directorio temporal. Este nombre de directorio se usa tal cual sin extensiones. Si este directorio no existe, será creado. El directorio temporal es creado por las operaciones de seguridad de Perl directamente bajo este directorio. En este directorio temporal, los archivos temporales son almacenados.

Salida

-o|--output file_name
Normalmente toda la salida groff de este programa se envía a STDOUT. Con esta opción, eso puede ser cambiado, de modo que la salida es almacenada en un archivo nombrado en el argumento de la opción file_name.
-v|-V|--verbose
Se envía mucha más información a STDERR.

Colecciones de opciones cortas

El manejo de argumentos de las opciones

Las opciones cortas son argumentos que comienzan con un guion simple -. Un argumento así puede consistir de arbitrariamente muchas opciones sin argumento de opción, compuestas como una colección de caracteres de opción que siguen al guion simple.

Tal colección puede ser terminada por un carácter de opción que espera un argumento de opción. Si este carácter de opción no es el último carácter del argumento, la parte final siguiente del argumento es el argumento de opción. Si es el último carácter del argumento, el siguiente argumento es tomado como el argumento de opción.

Este es el estándar para el manejo de opciones POSIX y GNU .

Por ejemplo,

-kVe some_dir
es una colección de las opciones cortas -k y -V sin argumento de opción, seguida de la opción corta -e con argumento de opción que es la parte siguiente del argumento some_dir. Así este argumento también podría ser escrito como varios argumentos -k -V -e some_dir.

Manejo de opciones largas

Los argumentos que comienzan con un guion doble -- son las llamadas opciones largas R . Cada argumento de guion doble solo puede tener una única opción larga.

Las opciones largas tienen o no un argumento de opción. Un argumento de opción puede ser el siguiente argumento o puede ser añadido con un signo igual = al mismo argumento que la opción larga.

--help
es una opción larga sin argumento de opción.
--eps_dir some_dir
--eps_dir=some_dir
es la opción larga --eps_dir con el argumento de opción some_dir.

Además, el programa permite abreviaturas de opciones largas, tanto como sea posible.

La opción larga --keep_all puede ser abreviada desde --keep_al hasta --k porque el programa no tiene otra opción larga cuyo nombre comience con el carácter k.

Por otro lado, la opción --version no puede ser abreviada más allá de --vers porque también existe la opción larga --verbose que puede ser abreviada hasta --verb.

Un argumento de opción también puede ser añadido a una abreviatura. Así --e=some_dir es lo mismo que --eps_dir some_dir.

Además, el programa permite un uso arbitrario de mayúsculas y minúsculas en el nombre de la opción. Este es el estilo Perl .

Por ejemplo, la opción larga --keep_all puede también ser escrita como --Keep_All o incluso como una abreviatura como --KeE.
