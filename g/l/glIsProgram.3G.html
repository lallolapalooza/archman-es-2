NOMBRE

glIsProgram - Determina si un nombre corresponde a un objeto de programa

ESPECIFICACIÓN C

GLboolean glIsProgram(GLuint program);

PARÁMETROS

program

Especifica un posible objeto de programa.

DESCRIPCIÓN

glIsProgram devuelve GL_TRUE si program es el nombre de un objeto de programa creado previamente con glCreateProgram() y que no ha sido eliminado con glDeleteProgram(). Si program es cero o un valor distinto de cero que no es el nombre de un objeto de programa, o si ocurre un error, glIsProgram devuelve GL_FALSE.

NOTAS

No se genera ningún error si program no es un nombre de objeto de programa válido.

Un objeto de programa marcado para eliminación con glDeleteProgram() pero que todavía está en uso como parte del estado de renderizado actual se considera todavía un objeto de programa y glIsProgram devolverá GL_TRUE.
