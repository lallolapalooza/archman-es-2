NOMBRE

glab-issue-board-view - Ver el tablero de incidencias del proyecto.

SINOPSIS

glab issue board view [flags]

DESCRIPCIÓN

Ver el tablero de incidencias del proyecto.

OPCIONES

-a, --assignee="" Filtrar incidencias del tablero por nombre de usuario asignado.

-l, --labels=[] Filtrar incidencias del tablero por etiquetas. Múltiples etiquetas pueden separarse por comas o especificarse repitiendo el flag.

-m, --milestone="" Filtrar incidencias del tablero por hito.

OPCIONES HEREDADAS DE COMANDOS PADRE

-h, --help[=false] Mostrar ayuda para este comando.

-R, --repo="" Seleccionar otro repositorio usando el formato OWNER/REPO o el ID del proyecto. Soporta namespaces de grupo.
