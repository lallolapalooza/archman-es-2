NOMBRE

glutMouseFunc - establece la función de devolución de llamada del ratón para la ventana actual.

SINTAXIS

void glutMouseFunc(void (*func)(int button, int state,
                   int x, int y));

ARGUMENTOS

func
La nueva función de devolución de llamada del ratón.

DESCRIPCIÓN

glutMouseFunc establece la función de devolución de llamada del ratón para la ventana actual. Cuando un usuario presiona y suelta botones del ratón en la ventana, cada presión y cada liberación generan una devolución de llamada del ratón. El parámetro button es uno de GLUT_LEFT_BUTTON, GLUT_MIDDLE_BUTTON o GLUT_RIGHT_BUTTON. Para sistemas con solo dos botones de ratón, puede que no sea posible generar la devolución de llamada GLUT_MIDDLE_BUTTON. Para sistemas con un solo botón de ratón, puede que solo sea posible generar una devolución de llamada GLUT_LEFT_BUTTON. El parámetro state es GLUT_UP o GLUT_DOWN, indicando si la devolución de llamada se debió a una liberación o a una presión respectivamente. Los parámetros x e y de la devolución de llamada indican las coordenadas relativas a la ventana cuando cambió el estado del botón del ratón. Si se activa una devolución de llamada GLUT_DOWN para un botón específico, el programa puede asumir que se generará una devolución de llamada GLUT_UP para el mismo botón (suponiendo que la ventana todavía tenga registrada una devolución de llamada del ratón) cuando se suelte el botón del ratón, incluso si el ratón se ha movido fuera de la ventana.

Si se adjunta un menú a un botón para una ventana, no se generarán devoluciones de llamada del ratón para ese botón.

Durante una devolución de llamada del ratón, se puede llamar a glutGetModifiers para determinar el estado de las teclas modificadoras cuando ocurrió el evento del ratón que generó la devolución de llamada.

Pasar NULL a glutMouseFunc deshabilita la generación de devoluciones de llamada del ratón.
