NOMBRE

glCompressedTexImage2D - especifica una imagen de textura bidimensional en un formato comprimido

ESPECIFICACIÓN EN C

void glCompressedTexImage2D(GLenumtarget, GLintlevel, GLenuminternalformat, GLsizeiwidth, GLsizeiheight, GLintborder, GLsizeiimageSize, const void *data);

PARÁMETROS

target

Especifica la textura de destino. Debe ser GL_TEXTURE_2D, GL_PROXY_TEXTURE_2D, GL_TEXTURE_1D_ARRAY, GL_PROXY_TEXTURE_1D_ARRAY, GL_TEXTURE_CUBE_MAP_POSITIVE_X, GL_TEXTURE_CUBE_MAP_NEGATIVE_X, GL_TEXTURE_CUBE_MAP_POSITIVE_Y, GL_TEXTURE_CUBE_MAP_NEGATIVE_Y, GL_TEXTURE_CUBE_MAP_POSITIVE_Z, GL_TEXTURE_CUBE_MAP_NEGATIVE_Z, o GL_PROXY_TEXTURE_CUBE_MAP.

level

Especifica el número de nivel de detalle. El nivel 0 es el nivel de imagen base. El nivel n es la n-ésima imagen de reducción de mipmap.

internalformat

Especifica el formato de los datos de imagen comprimidos almacenados en la dirección data.

width

Especifica el ancho de la imagen de textura. Todas las implementaciones admiten imágenes de textura 2D y de mapa cúbico que tienen al menos 16384 texeles de ancho.

height

Especifica la altura de la imagen de textura. Todas las implementaciones admiten imágenes de textura 2D y de mapa cúbico que tienen al menos 16384 texeles de alto.

border

Este valor debe ser 0.

imageSize

Especifica el número de bytes sin signo de los datos de la imagen que comienzan en la dirección especificada por data.

data

Especifica un puntero a los datos de la imagen comprimida en memoria.

DESCRIPCIÓN

El mapeo de texturas permite que los elementos de un arreglo de imágenes sean leídos por shaders.

glCompressedTexImage2D carga una imagen de textura bidimensional comprimida previamente definida y obtenida si target es GL_TEXTURE_2D, o una de las caras del mapa cúbico, como GL_TEXTURE_CUBE_MAP_POSITIVE_X. (véase glTexImage2D()).

Si target es GL_TEXTURE_1D_ARRAY, data se trata como un arreglo de texturas 1D comprimidas.

Si target es GL_PROXY_TEXTURE_2D, GL_PROXY_TEXTURE_1D_ARRAY o GL_PROXY_TEXTURE_CUBE_MAP, no se leen datos de data, pero todo el estado de la imagen de textura se recalcula, se comprueba su consistencia y se verifica contra las capacidades de la implementación. Si la implementación no puede manejar una textura del tamaño solicitado, establece todo el estado de la imagen en 0, pero no genera un error (véase glGetError()). Para consultar un arreglo de mipmap completo, use un nivel de arreglo de imágenes mayor o igual que 1.

internalformat debe ser un formato de imagen comprimida conocido (como GL_RGTC) o un formato de textura comprimida especificado por una extensión. Cuando una textura se carga con glTexImage2D() usando un formato de textura comprimido genérico (por ejemplo, GL_COMPRESSED_RGB), la GL selecciona una de sus extensiones que admiten texturas comprimidas. Para cargar la imagen de textura comprimida usando glCompressedTexImage2D, consulte el tamaño y el formato de la imagen de textura comprimida usando glGetTexLevelParameter().

Si un objeto de búfer con nombre distinto de cero está enlazado al objetivo GL_PIXEL_UNPACK_BUFFER (véase glBindBuffer()) mientras se especifica una imagen de textura, data se trata como un desplazamiento de bytes dentro del almacén de datos del objeto de búfer.

Si los datos comprimidos están organizados en bloques de tamaño fijo de texeles, se pueden usar los modos de almacenamiento de píxeles para seleccionar un subrectángulo de un rectángulo contenedor más grande. Estos modos de almacenamiento de píxeles operan de la misma manera que lo hacen para glTexImage2D(). En la siguiente descripción, denótese por bs, bw, bh y bd los valores de los modos de almacenamiento de píxeles GL_UNPACK_COMPRESSED_BLOCK_SIZE, GL_UNPACK_COMPRESSED_BLOCK_WIDTH, GL_UNPACK_COMPRESSED_BLOCK_HEIGHTy GL_UNPACK_COMPRESSED_BLOCK_DEPTH, respectivamente. bs es el tamaño del bloque comprimido en bytes; bw, bh y bd son el ancho, la altura y la profundidad del bloque comprimido en píxeles.

De forma predeterminada, los modos de almacenamiento de píxeles GL_UNPACK_ROW_LENGTH, GL_UNPACK_SKIP_ROWS, GL_UNPACK_SKIP_PIXELS, GL_UNPACK_IMAGE_HEIGHT y GL_UNPACK_SKIP_IMAGES se ignoran para imágenes comprimidas. Para habilitar GL_UNPACK_SKIP_PIXELS y GL_UNPACK_ROW_LENGTH, bs y bw deben ser distintos de cero. Para habilitar también GL_UNPACK_SKIP_ROWS y GL_UNPACK_IMAGE_HEIGHT, bh debe ser distinto de cero. Para habilitar también GL_UNPACK_SKIP_IMAGES, bd debe ser distinto de cero. Todos los parámetros deben ser consistentes con el formato comprimido para producir los resultados deseados.

Al seleccionar un subrectángulo de una imagen comprimida:

•El valor de GL_UNPACK_SKIP_PIXELS debe ser un múltiplo de bw;
•el valor de GL_UNPACK_SKIP_ROWS debe ser un múltiplo de bw.

imageSize debe ser igual a:

b s × width b w × height b h

NOTAS

Los formatos internos comprimidos específicos GL_COMPRESSED_RGB8_ETC2, GL_COMPRESSED_SRGB8_ETC2, GL_COMPRESSED_RGB8_PUNCHTHROUGH_ALPHA1_ETC2, GL_COMPRESSED_SRGB8_PUNCHTHROUGH_ALPHA1_ETC2, GL_COMPRESSED_RGBA8_ETC2_EAC, GL_COMPRESSED_SRGB8_ALPHA8_ETC2_EAC, GL_COMPRESSED_R11_EAC, GL_COMPRESSED_SIGNED_R11_EAC, GL_COMPRESSED_RG11_EACy GL_COMPRESSED_SIGNED_RG11_EAC solo están disponibles si la versión de GL es 4.3 o superior.

ERRORES

Se genera GL_INVALID_ENUM si internalformat no es uno de los formatos internos comprimidos específicos: GL_COMPRESSED_RED_RGTC1, GL_COMPRESSED_SIGNED_RED_RGTC1, GL_COMPRESSED_RG_RGTC2, GL_COMPRESSED_SIGNED_RG_RGTC2. GL_COMPRESSED_RGBA_BPTC_UNORM, GL_COMPRESSED_SRGB_ALPHA_BPTC_UNORM, GL_COMPRESSED_RGB_BPTC_SIGNED_FLOAT, GL_COMPRESSED_RGB_BPTC_UNSIGNED_FLOAT, GL_COMPRESSED_RGB8_ETC2, GL_COMPRESSED_SRGB8_ETC2, GL_COMPRESSED_RGB8_PUNCHTHROUGH_ALPHA1_ETC2, GL_COMPRESSED_SRGB8_PUNCHTHROUGH_ALPHA1_ETC2, GL_COMPRESSED_RGBA8_ETC2_EAC, GL_COMPRESSED_SRGB8_ALPHA8_ETC2_EAC, GL_COMPRESSED_R11_EAC, GL_COMPRESSED_SIGNED_R11_EAC, GL_COMPRESSED_RG11_EAC, o GL_COMPRESSED_SIGNED_RG11_EAC.

Se genera GL_INVALID_VALUE si imageSize no es consistente con el formato, las dimensiones y el contenido de los datos de imagen comprimida especificados.

Se genera GL_INVALID_VALUE si border no es 0.

Se genera GL_INVALID_OPERATION si las combinaciones de parámetros no son admitidas por el formato interno comprimido específico como se especifica en la extensión de compresión de textura específica.

Se genera GL_INVALID_OPERATION si un nombre de objeto de búfer distinto de cero está enlazado al objetivo GL_PIXEL_UNPACK_BUFFER y el almacén de datos del objeto de búfer está actualmente mapeado.

Se genera GL_INVALID_OPERATION si un nombre de objeto de búfer distinto de cero está enlazado al objetivo GL_PIXEL_UNPACK_BUFFER y los datos se desempaquetarían del objeto de búfer de manera que las lecturas de memoria requeridas excederían el tamaño del almacén de datos.

Se generan resultados indefinidos, incluida la terminación anormal del programa, si data no está codificado de una manera consistente con la especificación de la extensión que define el formato de compresión interno.

CONSULTAS ASOCIADAS

glGetCompressedTexImage()

glGet() con el argumento GL_TEXTURE_COMPRESSED

glGet() con el argumento GL_PIXEL_UNPACK_BUFFER_BINDING

glGetTexLevelParameter() con los argumentos GL_TEXTURE_INTERNAL_FORMAT y GL_TEXTURE_COMPRESSED_IMAGE_SIZE
