DESCRIPCIÓ

N

glTexStorage2D y glTextureStorage2D especifican los requisitos de almacenamiento para todos los niveles de una textura bidimensional o de una matriz de texturas unidimensional simultáneamente. Una vez que una textura es especificada con este comando, el formato y las dimensiones de todos los niveles se vuelven inmutables, a menos que sea una textura proxy. El contenido de la imagen puede ser modificado, sin embargo, sus requisitos de almacenamiento no pueden cambiar. Tal textura es referida como una textura de formato

inmutable.

El comportamiento de glTexStorage2D depende del parámetro target. Cuando target es GL_TEXTURE_2D, GL_PROXY_TEXTURE_2D, GL_TEXTURE_RECTANGLE, GL_PROXY_TEXTURE_RECTANGLE o GL_PROXY_TEXTURE_CUBE_MAP, llamar a glTexStorage2D es equivalente, asumiendo que no se generan errores, a ejecutar el siguiente

pseudocódigo: 
    for (i = 0; i < levels; i++) {
        glTexImage2D(target, i, internalformat, width, height, 0, format, type, NULL);
        width = max(1, (width / 2));
        height = max(1, (height / 2));
}

Cuando target es GL_TEXTURE_CUBE_MAP, glTexStorage2D es equivalente

a: 
    for (i = 0; i < levels; i++) {
        for (face in (+X, -X, +Y, -Y, +Z, -Z)) {
            glTexImage2D(face, i, internalformat, width, height, 0, format, type, NULL);
        }
        width = max(1, (width / 2));
        height = max(1, (height / 2));
}

Cuando target es GL_TEXTURE_1D_ARRAY o GL_PROXY_TEXTURE_1D_ARRAY, glTexStorage2D es equivalente

a: 
    for (i = 0; i < levels; i++) {
        glTexImage2D(target, i, internalformat, width, height, 0, format, type, NULL);
        width = max(1, (width / 2));
}

Llamar a glTextureStorage2D es equivalente al pseudocódigo anterior, donde target es el destino efectivo de texture y es como si texture estuviera enlazada a target a los efectos de glTexImage2D

.

Dado que no se proporciona realmente ningún dato de textura, los valores usados en el pseudocódigo para format y type son irrelevantes y pueden considerarse como cualquier valor que sea legal para el enumerante internalformat elegido. internalformat debe ser uno de los formatos internos con tamaño dados en la Tabla 1 a continuación, uno de los formatos de componente de profundidad con tamaño GL_DEPTH_COMPONENT32F, GL_DEPTH_COMPONENT24 o GL_DEPTH_COMPONENT16, uno de los formatos combinados de profundidad-esténcil, GL_DEPTH32F_STENCIL8 o GL_DEPTH24_STENCIL8, o el formato solo de esténcil, GL_STENCIL_INDEX8. Tras el éxito, el valor de GL_TEXTURE_IMMUTABLE_FORMAT se convierte en GL_TRUE. El valor de GL_TEXTURE_IMMUTABLE_FORMAT puede ser descubierto llamando a glGetTexParameter() con pname establecido a GL_TEXTURE_IMMUTABLE_FORMAT. No pueden realizarse más cambios en las dimensiones o el formato del objeto de textura. Usar cualquier comando que pueda alterar las dimensiones o el formato del objeto de textura (como glTexImage2D() u otra llamada a glTexStorage2D) resultará en la generación de un error GL_INVALID_OPERATION, incluso si de hecho no alteraría las dimensiones o el formato del

objeto.

ERRORE

S

Se genera GL_INVALID_OPERATION por glTexStorage2D si está enlazado cero a target

.

Se genera GL_INVALID_OPERATION por glTextureStorage2D si texture no es el nombre de un objeto de textura

existente.

Se genera GL_INVALID_ENUM si internalformat no es un formato interno dimensionado

válido.

Se genera GL_INVALID_ENUM si target o el target efectivo de texture no es uno de los targets aceptados descritos

arriba.

Se genera GL_INVALID_VALUE si width, height o levels son menores que

1.

Se genera GL_INVALID_OPERATION si target es GL_TEXTURE_1D_ARRAY o GL_PROXY_TEXTURE_1D_ARRAY y levels es mayor que log 2 width +

1.
