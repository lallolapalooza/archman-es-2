NOMBRE

glDeleteRenderbuffers - elimina objetos de buffer de renderizado

ESPECIFICACIÓN C

void glDeleteRenderbuffers(GLsizei n, GLuint *renderbuffers);

PARÁMETROS

n

Especifica el número de objetos de buffer de renderizado a eliminar.

renderbuffers

Un puntero a una matriz que contiene n objetos de buffer de renderizado a eliminar.

DESCRIPCIÓN

glDeleteRenderbuffers elimina los n objetos de buffer de renderizado cuyos nombres se almacenan en la matriz a la que apunta renderbuffers. El nombre cero está reservado por el GL y se ignora silenciosamente, al igual que otros nombres no utilizados, si aparece en renderbuffers. Una vez que se elimina un objeto de buffer de renderizado, su nombre vuelve a estar libre y no tiene contenido. Si un buffer de renderizado que está actualmente enlazado al destino GL_RENDERBUFFER se elimina, es como si se hubiera ejecutado glBindRenderbuffer() con un target de GL_RENDERBUFFER y un name de cero.

Si un objeto de buffer de renderizado está adjunto a uno o más puntos de adjunción en el framebuffer actualmente enlazado, entonces es como si se hubiera llamado a glFramebufferRenderbuffer(), con un renderbuffer de cero para cada punto de adjunción al que se adjuntó esta imagen en el framebuffer actualmente enlazado. En otras palabras, este objeto de buffer de renderizado se desvincula primero de todos los puntos de adjunción en el framebuffer actualmente enlazado. Tenga en cuenta que la imagen del buffer de renderizado específicamente no se desvincula de ningún framebuffer no enlazado.

ERRORES

GL_INVALID_VALUE se genera si n es negativo.
