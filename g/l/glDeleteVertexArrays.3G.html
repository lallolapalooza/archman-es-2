NOMBRE

glDeleteVertexArrays - eliminar objetos de array de vértices

ESPECIFICACIÓN C

void glDeleteVertexArrays(GLsizei n, const GLuint *arrays);

PARÁMETROS

n

Especifica el número de objetos de array de vértices a eliminar.

arrays

Especifica la dirección de un array que contiene los n nombres de los objetos a eliminar.

DESCRIPCIÓN

glDeleteVertexArrays elimina n objetos de array de vértices cuyos nombres están almacenados en el array al que apunta arrays. Una vez que un objeto de array de vértices es eliminado, no tiene contenido y su nombre vuelve a estar libre. Si se elimina un objeto de array de vértices que está actualmente enlazado, el enlace para ese objeto vuelve a cero y el array de vértices predeterminado se vuelve actual. Los nombres no utilizados en arrays se ignoran silenciosamente, al igual que el valor cero.

ERRORES

Se genera GL_INVALID_VALUE si n es negativo.
