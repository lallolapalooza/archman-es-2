NOMBRE

glab-repo-members-add - Añadir un miembro al proyecto.

SINOPSIS

glab repo members add [banderas]

DESCRIPCIÓN

Añade un miembro al proyecto con el rol especificado.

Roles:

  • invitado (10): Puede ver el proyecto.
  • reportero (20): Puede ver y crear incidencias.
  • desarrollador (30): Puede hacer push a ramas no protegidas.
  • mantenedor (40): Puede gestionar el proyecto.
  • propietario (50): Acceso completo al proyecto.

Para roles personalizados, usa --role-id con el ID de un rol personalizado definido en el proyecto o grupo. Nota: Si el rol personalizado no existe, se devolverá un error.

OPCIONES

-e, --expires-at="" Fecha de expiración de la membresía (AAAA-MM-DD)

-R, --repo="" Selecciona otro repositorio. Puede usar el formato PROPIETARIO/REPO o GRUPO/NAMESPACE/REPO. También acepta URL completas o URL de Git.

-r, --role="developer" Rol para el usuario (invitado, reportero, desarrollador, mantenedor, propietario)

--role-id=0 ID de un rol personalizado definido en el proyecto o grupo

-u, --user-id=0 ID de usuario en lugar de nombre de usuario

--username="" Nombre de usuario en lugar de ID de usuario

OPCIONES HEREDADAS DE COMANDOS PADRE

-h, --help[=false] Mostrar ayuda para este comando.

EJEMPLO

# Añadir un usuario como desarrollador
$ glab repo members add --username=john.doe --role=developer
# Añadir un usuario como mantenedor con fecha de expiración
$ glab repo members add --username=jane.smith --role=maintainer --expires-at=2024-12-31
# Añadir un usuario por ID
$ glab repo members add --user-id=123 --role=reporter
# Añadir un usuario con un rol personalizado
$ glab repo members add --username=john.doe --role-id=101
