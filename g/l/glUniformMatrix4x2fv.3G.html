PARÁMETROS

location

Especifica la ubicación de la variable uniforme a modificar.

count

Para los comandos de vector (glUniform*v), especifica el número de elementos que se modificarán. Este debería ser 1 si la variable uniforme objetivo no es un array, y 1 o más si es un array.

Para los comandos de matriz (glUniformMatrix*), especifica el número de matrices que se modificarán. Este debería ser 1 si la variable uniforme objetivo no es un array de matrices, y 1 o más si es un array de matrices.

transpose

Para los comandos de matriz, especifica si se debe transponer la matriz al cargar los valores en la variable uniforme.

v0, v1, v2, v3

Para los comandos escalares, especifica los nuevos valores que se utilizarán para la variable uniforme especificada.

value

Para los comandos de vector y matriz, especifica un puntero a un array de count valores que se utilizarán para actualizar la variable uniforme especificada.

DESCRIPCIÓN

glUniform modifica el valor de una variable uniforme o un array de variables uniformes. La ubicación de la variable uniforme a modificar se especifica mediante location, que debe ser un valor devuelto por glGetUniformLocation(). glUniform opera sobre el objeto de programa que se convirtió en parte del estado actual al llamar a glUseProgram().

Los comandos glUniform{1|2|3|4}{f|i|ui} se utilizan para cambiar el valor de la variable uniforme especificada por location utilizando los valores pasados como argumentos. El número especificado en el comando debe coincidir con el número de componentes del tipo de dato de la variable uniforme especificada (por ejemplo, 1 para float, int, unsigned int, bool; 2 para vec2, ivec2, uvec2, bvec2, etc.). El sufijo f indica que se están pasando valores de punto flotante; el sufijo i indica que se están pasando valores enteros; el sufijo ui indica que se están pasando valores enteros sin signo, y este tipo también debe coincidir con el tipo de dato de la variable uniforme especificada. Las variantes i de esta función deben usarse para proporcionar valores a variables uniformes definidas como tipos enteros.

NAME

glUniformMatrix2fv, glUniformMatrix3fv, glUniformMatrix4fv, glUniformMatrix2x3fv, glUniformMatrix3x2fv, glUniformMatrix2x4fv, glUniformMatrix4x2fv, glUniformMatrix3x4fv, glUniformMatrix4x3fv, glUniform - set OpenGL uniform variable values

void glUniformMatrix4x3fv(GLint location, GLsizei count, GLboolean transpose, const GLfloat *value);

PARAMETERS

• location: Specifies the integer location of the uniform variable to be modified.
• count: Specifies the number of matrices to be downloaded into the uniform variable.
• transpose: Specifies whether to transpose the matrix or matrices as they are transposed. transpose must be GL_FALSE.
• value: Specifies a pointer to the first element of a count * N x M matrix (or matrices) to be downloaded into the uniform variable.

DESCRIPTION

glUniformMatrix†fv functions are used to update the value of a uniform variable from within the current GL program. They should be used in conjunction with glUniform(), which can set uniforms of various types.

The glUniformMatrix†fv functions load `count` matrices into the uniform variable specified by location. The matrices are taken from the array of floating-point values pointed to by value.

If transpose is GL_FALSE, the matrices are loaded in their specified order. transpose must always be GL_FALSE for these functions.

The count argument can be zero, in which case the matrix specified by location will not be changed.

The matrix types available are:

  • glUniformMatrix2fv: loads 2x2 matrices.
  • glUniformMatrix3fv: loads 3x3 matrices.
  • glUniformMatrix4fv: loads 4x4 matrices.
  • glUniformMatrix2x3fv: loads 2x3 matrices.
  • glUniformMatrix3x2fv: loads 3x2 matrices.
  • glUniformMatrix2x4fv: loads 2x4 matrices.
  • glUniformMatrix4x2fv: loads 4x2 matrices.
  • glUniformMatrix3x4fv: loads 3x4 matrices.
  • glUniformMatrix4x3fv: loads 4x3 matrices.

All matrices are specified in column-major order.

The value argument points to an array of count matrices. For glUniformMatrix2fv, each matrix consists of 4 values, for a total of 4 * count values. For glUniformMatrix3fv, each matrix consists of 9 values, for a total of 9 * count values. For glUniformMatrix4fv, each matrix consists of 16 values, for a total of 16 * count values. For glUniformMatrix2x3fv, each matrix consists of 6 values, for a total of 6 * count values. For glUniformMatrix3x2fv, each matrix consists of 6 values, for a total of 6 * count values. For glUniformMatrix2x4fv, each matrix consists of 8 values, for a total of 8 * count values. For glUniformMatrix4x2fv, each matrix consists of 8 values, for a total of 8 * count values. For glUniformMatrix3x4fv, each matrix consists of 12 values, for a total of 12 * count values. For glUniformMatrix4x3fv, each matrix consists of 12 values, for a total of 12 * count values.

Prior to calling these functions, glUniform* functions must be used to set the uniform variable's location. This is typically done by calling glGetUniformLocation() after linking the program.

NOTES

The glUniformMatrix†fv functions are available only if the GLSL version is greater than or equal to 1.10.
The non-square matrix functions are available only if the GLSL version is greater than or equal to 1.30.

The transpose parameter must be GL_FALSE. This is a difference from the OpenGL 1.1 matrix functions, where it could be used to transpose matrices.

The value of a uniform variable can also be updated by calling glUniform() with appropriate arguments.

ERRORS

GL_INVALID_OPERATION is generated if the specified location is invalid, or if the specified location is not a uniform variable location for the active program.

GL_INVALID_VALUE is generated if count is negative.

GL_INVALID_OPERATION is generated if the size of the uniform variable indicated by location is not compatible with the function called (e.g., calling glUniformMatrix2fv for a uniform variable that is not a 2x2 matrix).
