NOMBRE

glGetUniformBlockIndex - recupera el índice de un bloque uniforme nombrado

ESPECIFICACIÓN C

GLuint glGetUniformBlockIndex(GLuint program, const GLchar *uniformBlockName);

PARÁMETROS

program

Especifica el nombre de un programa que contiene el bloque uniforme.

uniformBlockName

Especifica la dirección de una matriz de caracteres que contiene el nombre del bloque uniforme cuyo índice se va a recuperar.

DESCRIPCIÓN

glGetUniformBlockIndex recupera el índice de un bloque uniforme dentro de program.

program debe ser el nombre de un objeto de programa para el cual el comando glLinkProgram() debe haber sido llamado en el pasado, aunque no es necesario que glLinkProgram() haya tenido éxito. El enlace pudo haber fallado porque el número de uniformes activos excedió el límite.

uniformBlockName debe contener una cadena terminada en nulo que especifique el nombre del bloque uniforme.

glGetUniformBlockIndex devuelve el índice del bloque uniforme para el bloque uniforme llamado uniformBlockName de program. Si uniformBlockName no identifica un bloque uniforme activo de program, glGetUniformBlockIndex devuelve el identificador especial, GL_INVALID_INDEX. Los índices de los bloques uniformes activos de un programa se asignan en orden consecutivo, comenzando desde cero.

ERRORES

Se genera GL_INVALID_OPERATION si program no es el nombre de un objeto de programa para el cual se ha llamado a glLinkProgram() en el pasado.

NOTAS

glGetUniformBlockIndex solo está disponible si la versión de GL es 3.1 o superior.
