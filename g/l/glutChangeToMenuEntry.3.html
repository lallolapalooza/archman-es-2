glutChangeToMenuEntry(3) freeglut glutChangeToMenuEntry(3)

NOMBRE

glutChangeToMenuEntry - cambia la entrada de menú especificada en el menú actual a una entrada de menú.

SINTAXIS

void glutChangeToMenuEntry(int entry, char *name, int value);

ARGUMENTOS

entrada
Índice de los elementos del menú actual (1 es el elemento superior del menú).
nombre
Cadena de caracteres ASCII para mostrar en la entrada del menú.
valor
Valor a devolver a la función de callback del menú si se selecciona la entrada del menú.

DESCRIPCIÓN

glutChangeToMenuEntry cambia la entrada de menú especificada en el menú actual a una entrada de menú. El parámetro entry determina qué elemento del menú debe cambiarse, siendo uno el elemento superior. entry debe estar entre 1 e glutGet(GLUT_MENU_NUM_ITEMS) inclusive. El elemento del menú a cambiar no tiene por qué ser ya una entrada de menú. La cadena name se mostrará para la entrada de menú recién cambiada. El valor value se devolverá al callback del menú si se selecciona esta entrada de menú.

VER TAMBIÉN

glutChangeToSubMenu(3), glutAddMenuEntry(3), glutRemoveMenuItem(3)
