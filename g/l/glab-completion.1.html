NOMBRE

glab-completion - Genera scripts de completado para la shell.

SINOPSIS

glab completion [flags]

DESCRIPCIÓN

Este comando genera código destinado a ser guardado en un archivo, o evaluado inmediatamente por una shell interactiva. Para cargar los completados:

Bash

Para cargar los completados en tu sesión de shell actual:

source <(glab completion -s bash)

Para cargar los completados en cada nueva sesión, ejecuta este comando una vez:

Linux

glab completion -s bash > /etc/bash_completion.d/glab

macOS

glab completion -s bash > /usr/local/etc/bash_completion.d/glab

Zsh

Si el completado de shell aún no está habilitado en tu entorno, debes habilitarlo. Ejecuta este comando una vez:

echo "autoload -U compinit; compinit" >> ~/.zshrc

Para cargar los completados en tu sesión de shell actual:

source <(glab completion -s zsh); compdef _glab glab

Para cargar los completados en cada nueva sesión, ejecuta este comando una vez:

Linux

glab completion -s zsh > "${fpath[1]}/_glab"

macOS

Para versiones antiguas de macOS, podrías necesitar este comando:

glab completion -s zsh > /usr/local/share/zsh/site-functions/_glab

La versión de glab de Homebrew debería instalar los completados automáticamente.

fish

Para cargar los completados en tu sesión de shell actual:

glab completion -s fish | source

Para cargar los completados en cada nueva sesión, ejecuta este comando una vez:

glab completion -s fish > ~/.config/fish/completions/glab.fish

PowerShell

Para cargar los completados en tu sesión de shell actual:

glab completion -s powershell | Out-String | Invoke-Expression

Para cargar los completados en cada nueva sesión, añade la salida del comando anterior a tu perfil de PowerShell.

Sin embargo, al instalar glab a través de un gestor de paquetes, es posible que no necesites más configuración de shell para admitir los completados. Para Homebrew, consulta completado de shell de brew ⟨https://docs.brew.sh/Shell-Completion⟩

OPCIONES

--no-desc[=false] No incluir la descripción del completado de shell.

-s, --shell="bash" Tipo de shell: bash, zsh, fish, powershell.

OPCIONES HEREDADAS DE COMANDOS PADRE

-h, --help[=false] Mostrar ayuda para este comando.
