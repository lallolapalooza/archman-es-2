NOMBRE

glPointSize - especifica el diámetro de los puntos rasterizados

ESPECIFICACIÓN EN C

void glPointSize(GLfloat size);

PARÁMETROS

size

Especifica el diámetro de los puntos rasterizados. El valor inicial es 1.

DESCRIPCIÓN

glPointSize especifica el diámetro rasterizado de los puntos. Si el modo de tamaño de punto está deshabilitado (ver glEnable() con el parámetro GL_PROGRAM_POINT_SIZE), este valor se usará para rasterizar puntos. De lo contrario, se usará el valor escrito en la variable incorporada del lenguaje de sombreado gl_PointSize.

NOTAS

El tamaño del punto especificado por glPointSize se devuelve siempre cuando se consulta GL_POINT_SIZE. El ajuste y redondeo para los puntos no tienen ningún efecto en el valor especificado.

ERRORES

Se genera GL_INVALID_VALUE si size es menor o igual a 0.

GETS ASOCIADOS

glGet() con argumento GL_POINT_SIZE_RANGE

glGet() con argumento GL_POINT_SIZE_GRANULARITY

glGet() con argumento GL_POINT_SIZE

glGet() con argumento GL_POINT_FADE_THRESHOLD_SIZE

glIsEnabled() con argumento GL_PROGRAM_POINT_SIZE
