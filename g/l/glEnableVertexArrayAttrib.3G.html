GLENABLEVERTEXATTRIB(3G) [FIXME: manual] GLENABLEVERTEXATTRIB(3G)

NOMBRE

glEnableVertexAttribArray, glDisableVertexAttribArray, glEnableVertexArrayAttrib, glDisableVertexArrayAttrib - Habilitar o deshabilitar un array de atributos de vértice genérico

ESPECIFICACIÓN C

void glEnableVertexAttribArray(GLuint index);

void glDisableVertexAttribArray(GLuint index);

void glEnableVertexArrayAttrib(GLuint vaobj, GLuint index);

void glDisableVertexArrayAttrib(GLuint vaobj, GLuint index);

PARÁMETROS

vaobj

Especifica el nombre del objeto de array de vértices para las funciones glDisableVertexArrayAttrib y glEnableVertexArrayAttrib.

index

Especifica el índice del atributo de vértice genérico a habilitar o deshabilitar.

DESCRIPCIÓN

glEnableVertexAttribArray y glEnableVertexArrayAttrib habilitan el array de atributos de vértice genérico especificado por index. glEnableVertexAttribArray utiliza el objeto de array de vértices actualmente enlazado para la operación, mientras que glEnableVertexArrayAttrib actualiza el estado del objeto de array de vértices con el ID vaobj.

glDisableVertexAttribArray y glDisableVertexArrayAttrib deshabilitan el array de atributos de vértice genérico especificado por index. glDisableVertexAttribArray utiliza el objeto de array de vértices actualmente enlazado para la operación, mientras que glDisableVertexArrayAttrib actualiza el estado del objeto de array de vértices con el ID vaobj.

Por defecto, todas las capacidades del lado del cliente están deshabilitadas, incluyendo todos los arrays de atributos de vértice genéricos. Si están habilitados, los valores en el array de atributos de vértice genérico serán accedidos y utilizados para el renderizado cuando se realicen llamadas a comandos de array de vértices como glDrawArrays(), glDrawElements(), glDrawRangeElements(), glMultiDrawElements(), o glMultiDrawArrays().

ERRORES

GL_INVALID_OPERATION se genera por glEnableVertexAttribArray y glDisableVertexAttribArray si no hay ningún objeto de array de vértices enlazado.

GL_INVALID_OPERATION se genera por glEnableVertexArrayAttrib y glDisableVertexArrayAttrib si vaobj no es el nombre de un objeto de array de vértices existente.

GL_INVALID_VALUE se genera si index es mayor o igual a GL_MAX_VERTEX_ATTRIBS.

GETS ASOCIADOS

glGet() con el argumento GL_MAX_VERTEX_ATTRIBS

glGetVertexAttrib() con los argumentos index y GL_VERTEX_ATTRIB_ARRAY_ENABLED

glGetVertexAttribPointerv() con los argumentos index y GL_VERTEX_ATTRIB_ARRAY_POINTER
