NOMBRE

glIsQuery - determina si un nombre corresponde a un objeto de consulta

ESPECIFICACIÓN C

GLboolean glIsQuery(GLuint id);

PARÁMETROS

id

Especifica un valor que puede ser el nombre de un objeto de consulta.

DESCRIPCIÓN

glIsQuery devuelve GL_TRUE si id es actualmente el nombre de un objeto de consulta. Si id es cero, o es un valor distinto de cero que no es actualmente el nombre de un objeto de consulta, o si ocurre un error, glIsQuery devuelve GL_FALSE.

Un nombre devuelto por glGenQueries(), pero que aún no se ha asociado con un objeto de consulta llamando a glBeginQuery(), no es el nombre de un objeto de consulta.
