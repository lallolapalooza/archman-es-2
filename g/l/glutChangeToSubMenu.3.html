glutChangeToSubMenu(3)

Paquete: freeglut

Licencias: X11

glutChangeToSubMenu(3) freeglut glutChangeToSubMenu(3)

NOMBRE

glutChangeToSubMenu - cambia el elemento de menú especificado en el menú actual en un disparador de submenú.

SINTAXIS

void glutChangeToSubMenu(int entry, char *name, int menu);

ARGUMENTOS

entry
Índice entre los elementos del menú actual (1 es el elemento de menú superior).
name
Cadena de caracteres ASCII a mostrar en el elemento de menú para desplegar el submenú.
menu
Identificador del menú desde el cual desplegar este elemento de menú de submenú.

DESCRIPCIÓN

glutChangeToSubMenu cambia el elemento de menú especificado en el menú actual en un disparador de submenú. El parámetro entry determina qué elemento de menú debe ser cambiado, siendo uno el elemento superior. entry debe estar entre 1 y glutGet(GLUT_MENU_NUM_ITEMS) inclusive. El elemento de menú a cambiar no tiene por qué ser ya un disparador de submenú. La cadena name se mostrará para el disparador de submenú recién cambiado. El identificador menu nombra el submenú a desplegar desde el disparador de submenú recién añadido.

VER TAMBIÉN

glutChangeToMenuEntry, glutAddSubMenu, glutRemoveMenuItem
