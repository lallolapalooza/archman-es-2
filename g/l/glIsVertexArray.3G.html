NOMBRE

glIsVertexArray - determinar si un nombre corresponde a un objeto de array de vértices

ESPECIFICACIÓN C

GLboolean glIsVertexArray(GLuint array);

PARÁMETROS

array

Especifica un valor que puede ser el nombre de un objeto de array de vértices.

DESCRIPCIÓN

glIsVertexArray devuelve GL_TRUE si array es actualmente el nombre de un objeto de array de vértices. Si array es cero, o si array no es el nombre de un objeto de array de vértices, o si ocurre un error, glIsVertexArray devuelve GL_FALSE. Si array es un nombre devuelto por glGenVertexArrays(), pero que aún no ha sido enlazado a través de una llamada a glBindVertexArray(), entonces el nombre no es un objeto de array de vértices y glIsVertexArray devuelve GL_FALSE.
