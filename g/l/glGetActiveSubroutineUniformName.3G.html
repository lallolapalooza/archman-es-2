NOMBRE

glGetActiveSubroutineUniformName - consultar el nombre de un uniforme de subrutina de sombreador activo

ESPECIFICACIÓN C

void glGetActiveSubroutineUniformName(GLuint program, GLenum shadertype, GLuint index, GLsizei bufSize, GLsizei *length, GLchar *name);

PARÁMETROS

program

Especifica el nombre del programa que contiene la subrutina.

shadertype

Especifica la etapa del sombreador de la que se consultará el parámetro de la subrutina. shadertype debe ser uno de GL_VERTEX_SHADER, GL_TESS_CONTROL_SHADER, GL_TESS_EVALUATION_SHADER, GL_GEOMETRY_SHADER o GL_FRAGMENT_SHADER.

index

Especifica el índice del uniforme de subrutina del sombreador.

bufSize

Especifica el tamaño del búfer cuya dirección se proporciona en name.

length

Especifica la dirección de una variable en la que se escribirá el número de caracteres copiados en name.

name

Especifica la dirección de un búfer que recibirá el nombre del uniforme de subrutina de sombreador especificado.

DESCRIPCIÓN

glGetActiveSubroutineUniformName recupera el nombre de un uniforme de subrutina de sombreador activo. program contiene el nombre del programa que contiene el uniforme. shadertype especifica la etapa para la que es válido el índice del uniforme, dado por index. index debe estar entre cero y el valor de GL_ACTIVE_SUBROUTINE_UNIFORMS menos uno para la etapa del sombreador.

El nombre del uniforme se devuelve como una cadena terminada en nulo en name. El número real de caracteres escritos en name, excluyendo el terminador nulo, se devuelve en length. Si length es NULL, no se devuelve ninguna longitud. El número máximo de caracteres que se pueden escribir en name, incluido el terminador nulo, se especifica mediante bufSize. La longitud del nombre de subrutina uniforme más largo en program y shadertype se da por el valor de GL_ACTIVE_SUBROUTINE_UNIFORM_MAX_LENGTH, que se puede consultar con glGetProgramStage().

ERRORES

Se genera GL_INVALID_ENUM si shadertype o pname no son uno de los valores aceptados.

Se genera GL_INVALID_VALUE si index es mayor o igual que el valor de GL_ACTIVE_SUBROUTINE_UNIFORMS.

Se genera GL_INVALID_VALUE si program no es el nombre de un objeto de programa existente.

GETS ASOCIADOS

glGetProgramStage() con el argumento GL_ACTIVE_SUBROUTINE_UNIFORMS
