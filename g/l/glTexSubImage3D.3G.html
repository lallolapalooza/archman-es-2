NOMBRE

glTexSubImage3D, glTextureSubImage3D - especificar una subimagen de textura tridimensional

ESPECIFICACIÓN C

void glTexSubImage3D(GLenum target, GLint level, GLint xoffset, GLint yoffset, GLint zoffset, GLsizei width, GLsizei height, GLsizei depth, GLenum format, GLenum type, const void * pixels);

void glTextureSubImage3D(GLuint texture, GLint level, GLint xoffset, GLint yoffset, GLint zoffset, GLsizei width, GLsizei height, GLsizei depth, GLenum format, GLenum type, const void *pixels);

PARÁMETROS

target

Especifica el destino al que se enlaza la textura para glTexSubImage3D. Debe ser GL_TEXTURE_3D o GL_TEXTURE_2D_ARRAY.

texture

Especifica el nombre del objeto de textura para glTextureSubImage3D. El destino efectivo de texture debe ser uno de los valores de target válidos anteriores.

level

Especifica el número de nivel de detalle. El nivel 0 es el nivel de imagen base. El nivel n es la imagen de reducción mipmap n.

xoffset

Especifica un desplazamiento de texel en la dirección x dentro de la matriz de texturas.

yoffset

Especifica un desplazamiento de texel en la dirección y dentro de la matriz de texturas.

zoffset

Especifica un desplazamiento de texel en la dirección z dentro de la matriz de texturas.

width

Especifica el ancho de la subimagen de textura.

height

Especifica la altura de la subimagen de textura.

depth

Especifica la profundidad de la subimagen de textura.

format

Especifica el formato de los datos de píxeles. Se aceptan los siguientes valores simbólicos: GL_RED, GL_RG, GL_RGB, GL_BGR, GL_RGBA, GL_DEPTH_COMPONENT y GL_STENCIL_INDEX.

type

Especifica el tipo de datos de los datos de píxeles. Se aceptan los siguientes valores simbólicos: GL_UNSIGNED_BYTE, GL_BYTE, GL_UNSIGNED_SHORT, GL_SHORT, GL_UNSIGNED_INT, GL_INT, GL_FLOAT, GL_UNSIGNED_BYTE_3_3_2, GL_UNSIGNED_BYTE_2_3_3_REV, GL_UNSIGNED_SHORT_5_6_5, GL_UNSIGNED_SHORT_5_6_5_REV, GL_UNSIGNED_SHORT_4_4_4_4, GL_UNSIGNED_SHORT_4_4_4_4_REV, GL_UNSIGNED_SHORT_5_5_5_1, GL_UNSIGNED_SHORT_1_5_5_5_REV, GL_UNSIGNED_INT_8_8_8_8, GL_UNSIGNED_INT_8_8_8_8_REV, GL_UNSIGNED_INT_10_10_10_2 y GL_UNSIGNED_INT_2_10_10_10_REV.

pixels

Especifica un puntero a los datos de la imagen en la memoria.

DESCRIPCIÓN

La texturización mapea una porción de una imagen de textura especificada sobre cada primitivo gráfico para el que la texturización está habilitada.

glTexSubImage3D y glTextureSubImage3D redefinen una subregión contigua de una textura tridimensional o de matriz bidimensional existente. Los texels referenciados por pixels reemplazan la porción de la matriz de textura existente con índices x entre xoffset y xoffset + width - 1, inclusivos, índices y entre yoffset y yoffset + height - 1, inclusivos, e índices z entre zoffset y zoffset + depth - 1, inclusivos. Para texturas tridimensionales, el índice z se refiere a la tercera dimensión. Para texturas de matriz bidimensional, el índice z se refiere al índice de la rebanada. Esta región no puede incluir texels fuera del rango de la matriz de textura tal como se especificó originalmente. No es un error especificar una subtextura con ancho, alto o profundidad cero, pero tal especificación no tiene ningún efecto.

Si un objeto de búfer con nombre no cero está enlazado al destino GL_PIXEL_UNPACK_BUFFER (ver glBindBuffer()) mientras se especifica una imagen de textura, pixels se trata como un desplazamiento de bytes en el almacén de datos del objeto de búfer.

NOTAS

Los modos de glPixelStore() afectan a las imágenes de textura.

glTexSubImage3D y glTextureSubImage3D especifican una subtextura tridimensional o de matriz bidimensional para la unidad de textura actual, especificada con glActiveTexture().

Se acepta GL_STENCIL_INDEX para format solo si la versión de GL es 4.4 o superior.

ERRORES

Se genera GL_INVALID_ENUM si target o el destino efectivo de texture no es GL_TEXTURE_3D, GL_TEXTURE_2D_ARRAY o GL_TEXTURE_CUBE_MAP_ARRAY.

GL_INVALID_OPERATION es generado por glTextureSubImage3D si texture no es el nombre de un objeto de textura existente.

Se genera GL_INVALID_ENUM si format no es una constante de formato aceptada.

Se genera GL_INVALID_ENUM si type no es una constante de tipo.

Se genera GL_INVALID_VALUE si level es menor que 0.

Se puede generar GL_INVALID_VALUE si level es mayor que log 2 max, donde max es el valor devuelto por GL_MAX_TEXTURE_SIZE.

Se genera GL_INVALID_VALUE si xoffset < - b, xoffset + width > w - b, yoffset < - b, o yoffset + height > h - b, o zoffset < - b, o zoffset + depth > d - b, donde w es el GL_TEXTURE_WIDTH, h es el GL_TEXTURE_HEIGHT, d es el GL_TEXTURE_DEPTH y b es el ancho del borde de la imagen de textura que se está modificando. Tenga en cuenta que w, h y d incluyen el doble del ancho del borde.

Se genera GL_INVALID_VALUE si width, height o depth es menor que 0.

Se genera GL_INVALID_OPERATION si la matriz de textura no ha sido definida por una operación anterior de glTexImage3D() o glTexStorage3D().

Se genera GL_INVALID_OPERATION si type es uno de GL_UNSIGNED_BYTE_3_3_2, GL_UNSIGNED_BYTE_2_3_3_REV, GL_UNSIGNED_SHORT_5_6_5, o GL_UNSIGNED_SHORT_5_6_5_REV y format no es GL_RGB.

Se genera GL_INVALID_OPERATION si type es uno de GL_UNSIGNED_SHORT_4_4_4_4, GL_UNSIGNED_SHORT_4_4_4_4_REV, GL_UNSIGNED_SHORT_5_5_5_1, GL_UNSIGNED_SHORT_1_5_5_5_REV, GL_UNSIGNED_INT_8_8_8_8, GL_UNSIGNED_INT_8_8_8_8_REV, GL_UNSIGNED_INT_10_10_10_2, o GL_UNSIGNED_INT_2_10_10_10_REV y format no es ni GL_RGBA ni GL_BGRA.

Se genera GL_INVALID_OPERATION si format es GL_STENCIL_INDEX y el formato interno base no es GL_STENCIL_INDEX.

Se genera GL_INVALID_OPERATION si un objeto de búfer con nombre no cero está enlazado al destino GL_PIXEL_UNPACK_BUFFER y el almacén de datos del objeto de búfer está actualmente mapeado.

Se genera GL_INVALID_OPERATION si un objeto de búfer con nombre no cero está enlazado al destino GL_PIXEL_UNPACK_BUFFER y los datos se desempaquetarían del objeto de búfer de tal manera que las lecturas de memoria requeridas excedan el tamaño del almacén de datos.

Se genera GL_INVALID_OPERATION si un objeto de búfer con nombre no cero está enlazado al destino GL_PIXEL_UNPACK_BUFFER y pixels no es divisible uniformemente por el número de bytes necesarios para almacenar en memoria un dato indicado por type.
