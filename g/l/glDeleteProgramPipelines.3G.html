NOMBRE

glDeleteProgramPipelines - elimina objetos de canalización de programas

ESPECIFICACIÓN C

void glDeleteProgramPipelines(GLsizei n, const GLuint *pipelines);

PARÁMETROS

n

Especifica el número de objetos de canalización de programas a eliminar.

pipelines

Especifica una matriz de nombres de objetos de canalización de programas a eliminar.

DESCRIPCIÓN

glDeleteProgramPipelines elimina los n objetos de canalización de programas cuyos nombres están almacenados en la matriz pipelines. Se ignoran los nombres no utilizados en pipelines, así como el nombre cero. Después de que se elimina un objeto de canalización de programa, su nombre vuelve a estar sin usar y no tiene contenido. Si se elimina un objeto de canalización de programa que está actualmente enlazado, el enlace para ese objeto vuelve a cero y ningún objeto de canalización de programa se vuelve actual.

GETS ASOCIADOS

glGet() con el argumento GL_PROGRAM_PIPELINE_BINDING
