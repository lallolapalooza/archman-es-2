NOMBRE

glGetFragDataLocation - consulta las vinculaciones de números de color a variables de salida definidas por el usuario

ESPECIFICACIÓN C

GLint glGetFragDataLocation(GLuint program, const char * name);

PARÁMETROS

program

El nombre del programa que contiene la variable de salida definida por el usuario cuya vinculación consultar.

name

El nombre de la variable de salida definida por el usuario cuya vinculación consultar.

DESCRIPCIÓN

glGetFragDataLocation recupera la vinculación del número de color asignado para la variable de salida definida por el usuario name para el programa program. program debe haber sido enlazado previamente. name debe ser una cadena terminada en nulo. Si name no es el nombre de una variable activa de salida de fragmento definida por el usuario dentro de program, se devolverá -1.

ERRORES

Se genera GL_INVALID_OPERATION si program no es el nombre de un objeto de programa.
