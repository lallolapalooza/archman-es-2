NOMBRE

glmark2-es2-wayland - Suite de benchmark OpenGL (ES) 2.0

SINOPSIS

glmark2-es2-wayland [opciones]

DESCRIPCIÓN

glmark2-es2-wayland es un benchmark para OpenGL (ES) 2.0. Solo utiliza el subconjunto de la API de OpenGL 2.0 que es compatible con OpenGL ES 2.0.

OPCIONES

-b, --benchmark BENCH
Un benchmark para ejecutar: 'escena(:opt1=val1)*' (la opción puede usarse múltiples veces)
-f, --benchmark-file ARCHIVO
Cargar benchmarks para ejecutar desde un archivo que contiene una lista de descripciones de benchmark (una por línea) (la opción puede usarse múltiples veces)
--validate
Ejecutar una prueba rápida de validación de salida en lugar de ejecutar los benchmarks
--data-path RUTA
Ruta a los modelos, shaders y texturas de glmark2
--frame-end MÉTODO
Cómo finalizar un fotograma [default,none,swap,finish,readpixels]
--swap-mode MODO
Cómo intercambiar un fotograma, todos los modos son compatibles solo en la implementación DRM, 'fifo' está disponible en todas las implementaciones para forzar vsync [default,immediate,mailbox,fifo]
--off-screen
Renderizar a una superficie fuera de pantalla
--visual-config
La configuración visual a utilizar para el objetivo de renderizado: ´id=ID:red=R:green=G:blue=B:alpha=A:buffer=BUF:stencil=STENCIL:samples=SAMPLES'. Los parámetros pueden definirse en cualquier orden, y cualquier parámetro omitido asume un valor predeterminado de '0' (id, stencil, samples) o '1' (red, green, blue, alpha, buffer). Si 'id' se establece en un valor distinto de cero, todos los demás parámetros se ignoran
--reuse-context
Usar un único contexto para todas las escenas (por defecto, cada escena obtiene su propio contexto)
-s, --size AxA
Tamaño de la ventana de salida (por defecto: 800x600)
--fullscreen
Ejecutar en modo de pantalla completa (equivalente a --size -1x-1)
--results RESULTADOS
Los tipos de resultados a reportar para cada benchmark, como una lista separada por ':' [fps,cpu,shader]
--results-file ARCHIVO-RESULTADOS
El archivo donde guardar los resultados, en el formato determinado por la extensión del archivo [csv,xml]
--winsys-options OPTS
Una lista de pares 'opt=valor' para opciones específicas del sistema de ventanas, separadas por ':'
-l, --list-scenes
Mostrar información sobre las escenas disponibles y sus opciones
--show-all-options
Mostrar todos los valores de opciones de escena utilizados para los benchmarks (solo se muestran las opciones establecidas explícitamente por defecto)
--run-forever
Ejecutar indefinidamente, volviendo del último benchmark al primero
--annotate
Anotar los benchmarks con información en pantalla (igual que -b :show-fps=true:title=#info#)
-d, --debug
Mostrar mensajes de depuración
--version
Mostrar la versión del programa
-h, --help
Mostrar ayuda

BENCHMARKS

glmark2-es2-wayland ofrece un conjunto de escenas que pueden usarse para medir muchos aspectos del rendimiento de OpenGL (ES) 2.0. La forma en que se renderiza cada escena es configurable a través de un conjunto de opciones. Para obtener las escenas disponibles y sus opciones aceptables, puedes usar la opción de línea de comandos -l, --list-scenes.

En glmark2-es2-wayland, un benchmark se define como una escena más un conjunto de valores de opciones. Puedes especificar la lista y el orden de los benchmarks a ejecutar usando la opción de línea de comandos -b, --benchmark (posiblemente varias veces). Si no se especifican benchmarks, se utiliza un conjunto predeterminado de benchmarks. Si no se especifica una opción de benchmark, asume su valor predeterminado (listado con -l, --list-scenes).

Como caso especial, se permite que una cadena de descripción de benchmark no contenga un nombre de escena (es decir, que comience con ':'). En este caso, cualquier valor de opción especificado se usa como valores predeterminados para los benchmarks que sigan a esta cadena de descripción.

EJEMPLOS

Para ejecutar los benchmarks predeterminados:

glmark2-es2-wayland

Para ejecutar un benchmark utilizando la escena 'shading' con una 'duración' de '5.0' segundos y
'shading' de tipo 'phong':

glmark2-es2-wayland -b shading:duration=5.0:shading=phong

Para ejecutar una serie de benchmarks, usa la opción de línea de comandos -b, --benchmark varias veces:

glmark2-es2-wayland -b shading:duration=5.0 -b build:use-vbo=false -b texture

Para establecer valores de opción predeterminados para los benchmarks:

glmark2-es2-wayland -b :duration=2.0 -b shading -b build -b :duration=5.0 -b texture
