NOMBRE

glab-repo-create - Crea un nuevo proyecto/repositorio de GitLab.

SINOPSIS

glab repo create [ruta] [flags]

DESCRIPCIÓN

Crea el nuevo proyecto con tu primer host configurado en tu configuración de glab. El host por defecto es GitLab.com si no se establece. Para establecer un host, proporciona una de las siguientes opciones:

  • Una variable de entorno GITLAB_HOST.
  • Una URL completa para el proyecto.

OPCIONES

--defaultBranch="" Rama por defecto del proyecto. Por defecto es master si no se proporciona.

-d, --description="" Descripción del nuevo proyecto.

-g, --group="" Espacio de nombres o grupo para el nuevo proyecto. Por defecto es el espacio de nombres del usuario actual.

--internal[=false] Hacer el proyecto interno: visible para cualquier usuario autenticado. Por defecto.

-n, --name="" Nombre del nuevo proyecto.

-p, --private[=false] Hacer el proyecto privado: visible solo para los miembros del proyecto.

-P, --public[=false] Hacer el proyecto público: visible sin ninguna autenticación.

--readme[=false] Inicializar el proyecto con README.md.

--remoteName="origin" Nombre del remoto para el repositorio Git en el que te encuentras. Por defecto es origin si no se proporciona.

-s, --skipGitInit[=false] Omitir la ejecución de 'git init'.

-t, --tag=[] La lista de etiquetas para el proyecto.

OPCIONES HEREDADAS DE COMANDOS PADRE

-h, --help[=false] Mostrar ayuda para este comando.

EJEMPLO

# Crear un repositorio bajo tu cuenta usando el nombre del directorio actual.
$ glab repo create
# Crear un repositorio bajo un grupo usando el nombre del directorio actual.
$ glab repo create --group glab-cli
# Crear un repositorio con un nombre específico.
$ glab repo create my-project
# Crear un repositorio para un grupo.
$ glab repo create glab-cli/my-project
# Crear en un host diferente a gitlab.com.
$ GITLAB_HOST=example.com glab repo create
$ glab repo create <host>/ruta/al/repositorio
