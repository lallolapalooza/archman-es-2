NOMBRE

glSampleCoverage - especifica parámetros de cobertura de multimuestreo

ESPECIFICACIÓN C

void glSampleCoverage(GLfloat value, GLboolean invert);

PARÁMETROS

value

Especifica un único valor de cobertura de muestra flotante. El valor se limita al rango 0 1. El valor inicial es 1.0.

invert

Especifica un único valor booleano que representa si las máscaras de cobertura deben invertirse. Se aceptan GL_TRUE y GL_FALSE. El valor inicial es GL_FALSE.

DESCRIPCIÓN

El multimuestreo toma múltiples muestras de un píxel en varias ubicaciones subpíxel dependientes de la implementación para generar efectos de antialiasing. El multimuestreo aplica antialiasing de forma transparente a puntos, líneas, polígonos e imágenes si está habilitado.

value se utiliza para construir una máscara temporal utilizada para determinar qué muestras se utilizarán al resolver el color final del fragmento. Esta máscara se somete a una operación AND bit a bit con la máscara de cobertura generada a partir del cálculo de multimuestreo. Si se establece la bandera invert, la máscara temporal se invierte (todos los bits se invierten) y luego se realiza la operación AND bit a bit.

Si una implementación no tiene búferes de multimuestreo disponibles, o si el multimuestreo está deshabilitado, la rasterización ocurre con una única muestra que calcula el color RGB final de un píxel.

Siempre que una implementación admita búferes de multimuestreo y el multimuestreo esté habilitado, el color final de un píxel se genera combinando varias muestras por píxel. Cada muestra contiene información de color, profundidad y stencil, lo que permite realizar esas operaciones en cada muestra.

NOTAS

El tipo del parámetro value se cambió de GLclampf a GLfloat. Este cambio es transparente para el código del usuario y se describe en detalle en la página removedTypes().
