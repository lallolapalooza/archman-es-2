NOMBRE

glClientWaitSync - espera y bloquea un objeto de sincronización para que sea señalizado

ESPECIFICACIÓN C

GLenum glClientWaitSync(GLsync sync, GLbitfield flags, GLuint64 timeout);

PARÁMETROS

sync

El objeto de sincronización cuyo estado se espera.

flags

Un campo de bits que controla el comportamiento de vaciado de comandos. flags puede ser GL_SYNC_FLUSH_COMMANDS_BIT.

timeout

El tiempo de espera, especificado en nanosegundos, durante el cual la implementación debe esperar a que sync sea señalizado.

DESCRIPCIÓN

glClientWaitSync hace que el cliente se bloquee y espere a que el objeto de sincronización especificado por sync sea señalizado. Si sync es señalizado cuando se llama a glClientWaitSync, glClientWaitSync regresa inmediatamente; de lo contrario, se bloqueará y esperará hasta timeout nanosegundos para que sync sea señalizado.

El valor de retorno es uno de los cuatro valores de estado:

•GL_ALREADY_SIGNALED indica que sync fue señalizado en el momento en que se llamó a glClientWaitSync.
•GL_TIMEOUT_EXPIRED indica que transcurrieron al menos timeout nanosegundos y sync no fue señalizado.
•GL_CONDITION_SATISFIED indica que sync fue señalizado antes de que expirara el tiempo de espera.
•GL_WAIT_FAILED indica que ocurrió un error. Adicionalmente, se generará un error de OpenGL.

NOTAS

glClientWaitSync solo está disponible si la versión de GL es 3.2 o superior.

ERRORES

Se genera GL_INVALID_VALUE si sync no es el nombre de un objeto de sincronización existente.

Se genera GL_INVALID_VALUE si flags contiene cualquier indicador no compatible.
