NOMBRE

glValidateProgram - Valida un objeto de programa

ESPECIFICACIÓN C

void glValidateProgram(GLuint program);

PARÁMETROS

program

Especifica el identificador del objeto de programa a validar.

DESCRIPCIÓN

glValidateProgram comprueba si los ejecutables contenidos en program pueden ejecutarse dado el estado actual de OpenGL. La información generada por el proceso de validación se almacenará en el registro de información de program. La información de validación puede consistir en una cadena vacía, o puede ser una cadena que contenga información sobre cómo el objeto de programa actual interactúa con el resto del estado actual de OpenGL. Esto proporciona una forma para que los implementadores de OpenGL transmitan más información sobre por qué el programa actual es ineficiente, subóptimo, no se ejecuta, etc.

El estado de la operación de validación se almacenará como parte del estado del objeto de programa. Este valor se establecerá en GL_TRUE si la validación tuvo éxito y GL_FALSE en caso contrario. Se puede consultar llamando a glGetProgram() con los argumentos program y GL_VALIDATE_STATUS. Si la validación es exitosa, se garantiza que program se ejecutará dado el estado actual. De lo contrario, se garantiza que program no se ejecutará.

Esta función es típicamente útil solo durante el desarrollo de aplicaciones. La cadena informativa almacenada en el registro de información depende completamente de la implementación; por lo tanto, una aplicación no debe esperar que diferentes implementaciones de OpenGL produzcan cadenas de información idénticas.

NOTAS

Esta función imita la operación de validación que las implementaciones de OpenGL deben realizar cuando se emiten comandos de renderizado mientras los shaders programables forman parte del estado actual. Se generará el error GL_INVALID_OPERATION en cualquier comando que desencadene el renderizado de geometría si:

•dos samplers activos en el objeto de programa actual son de tipos diferentes, pero se refieren a la misma unidad de imagen de textura,
•el número de samplers activos en el programa supera el número máximo de unidades de imagen de textura permitidas.

Puede ser difícil o causar una degradación del rendimiento para las aplicaciones detectar estos errores cuando se emiten comandos de renderizado. Por lo tanto, se recomienda a las aplicaciones que realicen llamadas a glValidateProgram para detectar estos problemas durante el desarrollo de la aplicación.

ERRORES

Se genera GL_INVALID_VALUE si program no es un valor generado por OpenGL.

Se genera GL_INVALID_OPERATION si program no es un objeto de programa.

GETS ASOCIADOS

glGetProgram() con los argumentos program y GL_VALIDATE_STATUS

glGetProgramInfoLog() con el argumento program

glIsProgram()
