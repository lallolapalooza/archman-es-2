DESCRIPCIÓ

N

glVertexAttribFormat, glVertexAttribIFormat y glVertexAttribLFormat, así como glVertexArrayAttribFormat, glVertexArrayAttribIFormat y glVertexArrayAttribLFormat especifican la organización de los datos en los arrays de vértices. Las tres primeras llamadas operan sobre el objeto de array de vértices enlazado, mientras que las tres últimas modifican el estado de un objeto de array de vértices con ID vaobj. attribindex especifica el índice del array de atributos de vértices genérico cuyo diseño de datos se está describiendo, y debe ser menor que el valor de GL_MAX_VERTEX_ATTRIBS

.

size determina el número de componentes por vértice que se asignan al atributo especificado y debe ser 1, 2, 3, 4 o GL_BGRA. type indica el tipo de los datos. Si type es uno de GL_BYTE, GL_SHORT, GL_INT, GL_FIXED, GL_FLOAT, GL_HALF_FLOAT y GL_DOUBLE indican los tipos GLbyte, GLshort, GLint, GLfixed, GLfloat, GLhalf y GLdouble, respectivamente; los valores GL_UNSIGNED_BYTE, GL_UNSIGNED_SHORT, y GL_UNSIGNED_INT indican los tipos GLubyte, GLushort y GLuint, respectivamente; los valores GL_INT_2_10_10_10_REV y GL_UNSIGNED_INT_2_10_10_10_REV indican respectivamente cuatro elementos con signo o sin signo empaquetados en un solo GLuint; y el valor GL_UNSIGNED_INT_10F_11F_11F_REV indica tres valores de punto flotante empaquetados en un solo

GLuint.

glVertexAttribLFormat y glVertexArrayAttribLFormat se utilizan para especificar el diseño de los datos asociados con una variable de atributo genérico declarada como componentes de doble precisión de 64 bits. Para glVertexAttribLFormat y glVertexArrayAttribLFormat, type debe ser GL_DOUBLE. En contraste con glVertexAttribFormat o glVertexArrayAttribFormat, que harán que los datos declarados como GL_DOUBLE se conviertan a una representación de 32 bits, glVertexAttribLFormat y glVertexArrayAttribLFormat harán que tales datos permanezcan en su representación natural de 64

bits.

Para glVertexAttribFormat y glVertexArrayAttribFormat, si normalized es GL_TRUE, entonces los datos enteros se normalizan al rango [-1, 1] o [0, 1] si son con signo o sin signo, respectivamente. Si normalized es GL_FALSE entonces los datos enteros se convierten directamente a punto

flotante.

relativeoffset es el desplazamiento, medido en unidades básicas de máquina, del primer elemento relativo al inicio del enlace del búfer de vértices desde el que este atributo obtiene

datos.

glVertexAttribFormat y glVertexArrayAttribFormat deben usarse para describir el diseño de los atributos de vértices para atributos de vértices de punto flotante, glVertexAttribIFormat y glVertexArrayAttribIFormat deben usarse para describir el diseño de los atributos de vértices para atributos de vértices enteros, y glVertexAttribLFormat y glVertexArrayAttribLFormat deben usarse para describir el diseño para atributos de vértices de 64 bits. Los datos para un array especificado por glVertexAttribIFormat y glVertexArrayAttribIFormat siempre se dejarán como valor

es enteros; tales datos
se denominan enteros puros.
