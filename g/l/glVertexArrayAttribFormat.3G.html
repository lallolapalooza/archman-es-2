PARAMETERS

vaobj, attributeIndex, size, type, normalized, relativeOffset

Specify the parameters for the vertex attribute.

DESCRIPTION

These commands describe the format of per-vertex data for a generic vertex attribute. They specify how data read from a vertex buffer will be interpreted and converted into a vertex attribute. The commands are divided into two groups: those that operate on a vertex array object (VAO) and those that operate on the current generic vertex attribute list.

The commands operating on a VAO take the VAO object as their first parameter. The commands that do not take a VAO object operate on the currently bound VAO.

The vertex attribute format is defined by the following parameters:

attributeIndex
Specifies the index of the generic vertex attribute to be modified. Generic vertex attributes are indexed from 0.
size
Specifies the number of components per generic vertex attribute. Must be 1, 2, 3, or 4. The initial value is 4.
type
Specifies the data type of each component in the vertex array. Symbolic constants are GL_BYTE, GL_UNSIGNED_BYTE, GL_SHORT, GL_UNSIGNED_SHORT, GL_INT, GL_UNSIGNED_INT, GL_HALF_FLOAT, GL_FLOAT, GL_DOUBLE, GL_INT_2_10_10_10_REV, GL_UNSIGNED_INT_2_10_10_10_REV, and GL_UNSIGNED_INT_8_8_8_8, GL_UNSIGNED_INT_8_8_8_8_REV.
normalized
(Only for glVertexArrayAttribFormat and glVertexAttribFormat.) Specifies whether fixed-point data should be normalized. If set to GL_TRUE, values are mapped from the range [-1, 1] for signed integers or [0, 1] for unsigned integers to the range [-1, 1] or [0, 1] respectively. If set to GL_FALSE, values are used directly.
relativeOffset
Specifies the offset, in bytes, of the first component of the vertex attribute from the start of the corresponding vertex buffer binding. The initial value is 0.

The functions ending in Format describe how vertex array data is interpreted. The functions ending in IFormat assume the data is integer data, and will be converted to GL_INT_2_10_10_10_REV or GL_UNSIGNED_INT_2_10_10_10_REV depending on the type parameter. The functions ending in LFormat assume the data is double-precision floating-point data, and will be converted to GL_DOUBLE.

The glVertexArrayAttribFormat, glVertexArrayAttribIFormat, and glVertexArrayAttribLFormat functions associate the vertex attribute format with the specified vertex array object, vaobj.

The glVertexAttribFormat, glVertexAttribIFormat, and glVertexAttribLFormat functions associate the vertex attribute format with the currently bound vertex array object.

NOTES

These commands are part of the OpenGL specification and are used to configure vertex attribute formats. They are typically used in conjunction with glVertexAttribBinding to associate vertex attributes with specific vertex buffer bindings.

The normalized parameter is ignored for the IFormat and LFormat variants.

The type parameter for glVertexArrayAttribIFormat and glVertexAttribIFormat must be one of GL_BYTE, GL_UNSIGNED_BYTE, GL_SHORT, GL_UNSIGNED_SHORT, GL_INT, or GL_UNSIGNED_INT.

The type parameter for glVertexArrayAttribLFormat and glVertexAttribLFormat must be GL_HALF_FLOAT, GL_FLOAT, or GL_DOUBLE.
