NOMBRE

glab-opentofu-state-download - Descarga el estado dado y lo emite en formato JSON a la salida estándar.

SINOPSIS

glab opentofu state download [] [flags]

DESCRIPCIÓN

Descarga el estado dado y lo emite en formato JSON a la salida estándar.

OPCIONES HEREDADAS DE COMANDOS PADRE

-h, --help[=false] Muestra la ayuda para este comando.

-R, --repo="" Selecciona otro repositorio. Puede usar el formato PROPIETARIO/REPO o GRUPO/ESPACIO_DE_NOMBRES/REPO. También acepta URL completa o URL de Git.

EJEMPLO

# Descarga la última serie del estado de producción
$ glab opentofu state download production
# Descarga la serie 42 del estado de producción
$ glab opentofu state download production 42
