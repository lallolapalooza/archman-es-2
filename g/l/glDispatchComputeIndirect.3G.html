NOMBRE

glDispatchComputeIndirect - lanza uno o más grupos de trabajo de cómputo utilizando parámetros almacenados en un búfer

ESPECIFICACIÓN C

void glDispatchComputeIndirect(GLintptr indirect);

PARÁMETROS

indirect

El desplazamiento dentro del objeto de búfer actualmente enlazado al destino de búfer GL_DISPATCH_INDIRECT_BUFFER donde se almacenan los parámetros de envío.

DESCRIPCIÓN

glDispatchComputeIndirect lanza uno o más grupos de trabajo de cómputo utilizando parámetros almacenados en el objeto de búfer actualmente enlazado al destino GL_DISPATCH_INDIRECT_BUFFER. Cada grupo de trabajo es procesado por el objeto de programa activo para la etapa de sombreado de cómputo. Mientras que las invocaciones de sombreado individuales dentro de un grupo de trabajo se ejecutan como una unidad, los grupos de trabajo se ejecutan completamente de forma independiente y en un orden no especificado. indirect contiene el desplazamiento dentro del almacén de datos del objeto de búfer enlazado al destino GL_DISPATCH_INDIRECT_BUFFER donde se almacenan los parámetros.

Los parámetros a los que se accede mediante indirect se empaquetan en una estructura, que tiene la siguiente forma (en C):

    typedef  struct {
        uint  num_groups_x;
        uint  num_groups_y;
        uint  num_groups_z;
    } DispatchIndirectCommand;

Una llamada a glDispatchComputeIndirect es equivalente, suponiendo que no se generan errores, a:

    cmd = (const DispatchIndirectCommand  *)indirect;
    glDispatchCompute(cmd->num_groups_x, cmd->num_groups_y, cmd->num_groups_z);

A diferencia de glDispatchCompute(), no se genera ningún error si alguno de los miembros num_groups_x, num_groups_y o num_groups_z del DispatchIndirectCommand es mayor que el valor de GL_MAX_COMPUTE_WORK_GROUP_COUNT para la dimensión correspondiente. En tales circunstancias, el comportamiento no está definido y puede provocar la terminación de la aplicación.

ERRORES

Se genera GL_INVALID_OPERATION si no hay un programa activo para la etapa de sombreado de cómputo.

Se genera GL_INVALID_VALUE si indirect es menor que cero o no es un múltiplo de cuatro.

Se genera GL_INVALID_OPERATION si no hay ningún búfer enlazado al destino GL_DISPATCH_INDIRECT_BUFFER o si el comando intentara obtener datos más allá del final del almacén de datos del objeto de búfer.

GETS ASOCIADOS

glGet() con el argumento GL_MAX_COMPUTE_WORK_GROUP_COUNT
