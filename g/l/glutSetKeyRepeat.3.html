glutSetKeyRepeat(3)

Paquete: freeglut

Licencias: X11

glutSetKeyRepeat(3) freeglut glutSetKeyRepeat(3)

NOMBRE

glutSetKeyRepeat - establece el modo de repetición de teclas

SINTAXIS

int glutSetKeyRepeat(int repeatMode);

ARGUMENTOS

repeatMode
Modo para establecer la repetición de teclas.
GLUT_KEY_REPEAT_OFF
Deshabilita la repetición de teclas para el sistema de ventanas a nivel global si es posible.
GLUT_KEY_REPEAT_ON
Habilita la repetición de teclas para el sistema de ventanas a nivel global si es posible.
GLUT_KEY_REPEAT_DEFAULT
Restablece el modo de repetición de teclas para el sistema de ventanas a su estado predeterminado si es posible.

DESCRIPCIÓN

glutSetKeyRepeat establece el modo de repetición de teclas para el sistema de ventanas a nivel global si es posible. Si es compatible con el sistema de ventanas, la repetición de teclas puede habilitarse, deshabilitarse o establecerse en el estado predeterminado del sistema de ventanas.

NOTAS DE IMPLEMENTACIÓN DE GLUT PARA X11

X11 envía eventos KeyPress repetidamente cuando la repetición automática global del sistema de ventanas está habilitada. glutIgnoreKeyRepeat puede evitar que estas pulsaciones de teclas repetidas automáticamente se informen como callbacks de teclado o especiales, pero todavía hay una sobrecarga mínima por parte del servidor X para transmitir continuamente eventos KeyPress a la aplicación GLUT. La rutina glutSetKeyRepeat se puede usar para deshabilitar realmente el envío global de eventos KeyPress repetidos automáticamente. Tenga en cuenta que glutSetKeyRepeat afecta al estado global de repetición automática del sistema de ventanas, por lo que otras aplicaciones no se repetirán si deshabilita la repetición automática globalmente a través de glutSetKeyRepeat.

Las aplicaciones GLUT que utilizan la implementación GLUT de X11 deberían deshabilitar la repetición de teclas con glutSetKeyRepeat para deshabilitar la repetición de teclas de manera más eficiente.

Las aplicaciones GLUT que cambian el estado de repetición de teclas con glutSetKeyRepeat son responsables de restaurar explícitamente el estado predeterminado de repetición de teclas al salir.

NOTAS DE IMPLEMENTACIÓN DE GLUT PARA WIN32

La implementación de Win32 de glutSetKeyRepeat no hace nada. La rutina glutIgnoreKeyRepeat se puede usar en la implementación GLUT de Win32 para ignorar las teclas repetidas por ventana sin cambiar la repetición global de teclas del sistema de ventanas.
