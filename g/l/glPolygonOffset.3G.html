NOMBRE

glPolygonOffset - establece la escala y las unidades utilizadas para calcular los valores de profundidad

ESPECIFICACIÓN C

void glPolygonOffset(GLfloat factor, GLfloat units);

PARÁMETROS

factor

Especifica un factor de escala que se utiliza para crear un desplazamiento de profundidad variable para cada polígono. El valor inicial es 0.

units

Se multiplica por un valor específico de la implementación para crear un desplazamiento de profundidad constante. El valor inicial es 0.

DESCRIPCIÓN

Cuando GL_POLYGON_OFFSET_FILL, GL_POLYGON_OFFSET_LINE o GL_POLYGON_OFFSET_POINT están habilitados, el valor de profundidad de cada fragmento se desplazará después de ser interpolado a partir de los valores de profundidad de los vértices apropiados. El valor del desplazamiento es factor × DZ + r × units, donde DZ es una medida del cambio de profundidad en relación con el área de la pantalla del polígono, y r es el valor más pequeño que garantiza la producción de un desplazamiento resoluble para una implementación dada. El desplazamiento se añade antes de que se realice la prueba de profundidad y antes de que el valor se escriba en el búfer de profundidad.

glPolygonOffset es útil para renderizar imágenes con líneas ocultas, para aplicar calcomanías a superficies y para renderizar sólidos con bordes resaltados.

GETS ASOCIADOS

glIsEnabled() con el argumento GL_POLYGON_OFFSET_FILL, GL_POLYGON_OFFSET_LINE o GL_POLYGON_OFFSET_POINT.

glGet() con el argumento GL_POLYGON_OFFSET_FACTOR o GL_POLYGON_OFFSET_UNITS.
