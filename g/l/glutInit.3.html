NOMBRE

glutInit - inicializa la librería GLUT.

SINTAXIS

void glutInit(int *argcp, char **argv);

ARGUMENTOS

argcp
Un puntero a la variable argc del programa sin modificar de main. Al retornar, el valor apuntado por argcp se actualizará, ya que glutInit extrae cualquier opción de línea de comandos destinada a la librería GLUT.
argv
La variable argv del programa sin modificar de main. Al igual que argcp, los datos de argv se actualizarán porque glutInit extrae cualquier opción de línea de comandos entendida por la librería GLUT.

DESCRIPCIÓN

glutInit inicializará la librería GLUT y negociará una sesión con el sistema de ventanas. Durante este proceso, glutInit puede causar la terminación del programa GLUT con un mensaje de error al usuario si GLUT no puede ser inicializado correctamente. Ejemplos de esta situación incluyen la falta de conexión con el sistema de ventanas, la falta de soporte del sistema de ventanas para OpenGL y opciones de línea de comandos inválidas.

glutInit también procesa opciones de línea de comandos, pero las opciones específicas que analiza dependen del sistema de ventanas.

NOTAS DE IMPLEMENTACIÓN X

Las opciones específicas del Sistema de Ventanas X analizadas por glutInit son las siguientes:

-display DISPLAY
Especifica el servidor X al que conectarse. Si no se especifica, se usa el valor de la variable de entorno DISPLAY.
-geometry WxH+X+Y
Determina dónde se deben crear las ventanas en la pantalla. El parámetro siguiente a -geometry debe tener el formato de una especificación de geometría X estándar. El efecto de usar esta opción es cambiar el tamaño inicial y la posición inicial de GLUT como si se hubieran llamado directamente glutInitWindowSize o glutInitWindowPosition.
-iconic
Solicita que todas las ventanas de nivel superior se creen en estado icónico.
-indirect
Fuerza el uso de contextos de renderizado OpenGL indirectos.
-direct
Fuerza el uso de contextos de renderizado OpenGL directos (no todas las implementaciones de GLX admiten contextos de renderizado directos). Se genera un error fatal si la implementación de OpenGL no admite el renderizado directo.

Si no se utilizan ni -indirect ni -direct para forzar un comportamiento particular, GLUT intentará utilizar el renderizado directo si es posible y, de lo contrario, recurrirá al renderizado indirecto.

-gldebug
Después de procesar las devoluciones de llamada y/o eventos, comprueba si hay algún error de OpenGL llamando a glGetError. Si se informa de un error, imprime una advertencia buscando el código de error con gluErrorString. Usar esta opción es útil para detectar errores de tiempo de ejecución de OpenGL.
-sync
Habilita transacciones síncronas del protocolo X. Esta opción facilita el rastreo de posibles errores del protocolo X.

VER TAMBIÉN

glutCreateWindow, glutInitWindowPosition, glutInitWindowSize, glutMainLoop
