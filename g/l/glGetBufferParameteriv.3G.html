GLGETBUFFERPARAMETER(3G) [FIXME: manual] GLGETBUFFERPARAMETER(3G)

NOMBRE

glGetBufferParameteriv, glGetBufferParameteri64v, glGetNamedBufferParameteriv, glGetNamedBufferParameteri64v - devuelven parámetros de un objeto de búfer

ESPECIFICACIÓN EN C

void glGetBufferParameteriv(GLenumtarget, GLenumvalue, GLint *data);

void glGetBufferParameteri64v(GLenumtarget, GLenumvalue, GLint64 *data);

void glGetNamedBufferParameteriv(GLuintbuffer, GLenumpname, GLint *params);

void glGetNamedBufferParameteri64v(GLuintbuffer, GLenumpname, GLint64 *params);

PARÁMETROS

target

Especifica el destino al que está vinculado el objeto de búfer para glGetBufferParameteriv y glGetBufferParameteri64v. Debe ser uno de los destinos de vinculación de búfer en la siguiente tabla:
Destino de vinculación de búfer Propósito
GL_ARRAY_BUFFER Atributos de vértice
GL_ATOMIC_COUNTER_BUFFER Almacenamiento de contadores atómicos
GL_COPY_READ_BUFFER Origen de copia de búfer
GL_COPY_WRITE_BUFFER Destino de copia de búfer
GL_DISPATCH_INDIRECT_BUFFER Comandos de despacho de cómputo indirecto
GL_DRAW_INDIRECT_BUFFER Argumentos de comando indirectos
GL_ELEMENT_ARRAY_BUFFER Índices de matriz de vértices
GL_PIXEL_PACK_BUFFER Destino de lectura de píxeles
GL_PIXEL_UNPACK_BUFFER Fuente de datos de textura
GL_QUERY_BUFFER Búfer de resultados de consulta
GL_SHADER_STORAGE_BUFFER Almacenamiento de lectura-escritura para shaders
GL_TEXTURE_BUFFER Búfer de datos de textura
GL_TRANSFORM_FEEDBACK_BUFFER Búfer de transform feedback
GL_UNIFORM_BUFFER Almacenamiento de bloques uniformes

buffer

Especifica el nombre del objeto de búfer para glGetNamedBufferParameteriv y glGetNamedBufferParameteri64v.

value

Especifica el nombre del parámetro del objeto de búfer a consultar.

data

Devuelve el parámetro solicitado.

DESCRIPCIÓN

Estas funciones devuelven en data un parámetro seleccionado del objeto de búfer especificado.

pname nombra un parámetro específico del objeto de búfer, como sigue:

GL_BUFFER_ACCESS

params devuelve la política de acceso establecida al mapear el objeto de búfer (el valor del access parámetro enum pasado a glMapBuffer). Si el búfer fue mapeado con glMapBufferRange, la política de acceso se determina traduciendo los bits en ese access parámetro a uno de los enums soportados para glMapBuffer como se describe en la Especificación de OpenGL.

GL_BUFFER_ACCESS_FLAGS

params devuelve la política de acceso establecida al mapear el objeto de búfer (el valor del access parámetro bitfield pasado a glMapBufferRange). Si el búfer fue mapeado con glMapBuffer, la política de acceso se determina traduciendo los enums en ese access parámetro a los bits correspondientes para glMapBufferRange como se describe en la Especificación de OpenGL. El valor inicial es cero.

GL_BUFFER_IMMUTABLE_STORAGE

params devuelve un indicador booleano que indica si el objeto de búfer es inmutable. El valor inicial es GL_FALSE.

GL_BUFFER_MAPPED

params devuelve un indicador que indica si el objeto de búfer está actualmente mapeado. El valor inicial es GL_FALSE.

GL_BUFFER_MAP_LENGTH

params devuelve la longitud del mapeo en el objeto de búfer establecido con glMapBuffer*. Las i64v versiones de estas consultas deben usarse para este parámetro. El valor inicial es cero.

GL_BUFFER_MAP_OFFSET

params devuelve el desplazamiento del mapeo en el objeto de búfer establecido con glMapBuffer*. Las i64v versiones de estas consultas deben usarse para este parámetro. El valor inicial es cero.

GL_BUFFER_SIZE

params devuelve el tamaño del objeto de búfer, medido en bytes. El valor inicial es 0.

GL_BUFFER_STORAGE_FLAGS

params devuelve un bitfield que indica los flags de almacenamiento para el objeto de búfer. Si el objeto de búfer es inmutable, el valor devuelto será el especificado cuando el almacén de datos fue establecido con glBufferStorage. Si el almacén de datos fue establecido con glBufferData, el valor será GL_MAP_READ_BIT | GL_MAP_WRITE_BIT | GL_DYNAMIC_STORAGE_BIT | GL_MAP_WRITE_BIT. El valor inicial es cero.

GL_BUFFER_USAGE

params devuelve el patrón de uso del objeto de búfer. El valor inicial es GL_STATIC_DRAW.

NOTAS

Si se genera un error, no se realiza ningún cambio en el contenido de data.

El GL_ATOMIC_COUNTER_BUFFER destino está disponible solo si la versión de GL es 4.2 o superior.

Los GL_DISPATCH_INDIRECT_BUFFER y GL_SHADER_STORAGE_BUFFER destinos están disponibles solo si la versión de GL es 4.3 o superior.

El GL_QUERY_BUFFER destino está disponible solo si la versión de GL es 4.4 o superior.

ERRORES

GL_INVALID_ENUM es generado por glGetBufferParameter* si target no es uno de los destinos de búfer aceptados.

GL_INVALID_OPERATION es generado por glGetBufferParameter* si cero está vinculado a target.

GL_INVALID_OPERATION es generado por glGetNamedBufferParameter* si buffer no es el nombre de un objeto de búfer existente.

GL_INVALID_ENUM es generado si pname no es uno de los nombres de parámetros del objeto de búfer descritos arriba.
