NOMBRE

glab-ci-view - Ver, ejecutar, rastrear, registrar y cancelar el pipeline actual de un trabajo de CI/CD.

SINOPSIS

glab ci view [rama/etiqueta] [opciones]

DESCRIPCIÓN

Permite ver, ejecutar, rastrear y cancelar trabajos.

Usa las teclas de flecha para navegar por los trabajos y los registros.

  • Intro para alternar entre los registros/rastreos de un trabajo, o mostrar un pipeline hijo. Los trabajos desencadenantes están marcados con un ».
  • Esc o q para cerrar los registros o el rastreo, o volver al pipeline padre.
  • Ctrl+R, Ctrl+P para ejecutar o reintentar un trabajo. Usa Tab o las teclas de flecha para navegar por el modal, y Intro para confirmar.
  • Ctrl+D para cancelar un trabajo. Si el trabajo seleccionado no se está ejecutando o está pendiente, sale de la vista CI/CD.
  • Ctrl+Q para salir de la vista CI/CD.
  • Ctrl+Espacio para suspender la aplicación y ver los registros. Similar a glab pipeline ci trace.
  • Soporta atajos de estilo vi y las teclas de flecha para navegar por los trabajos y los registros.

OPCIONES

-b, --branch="" Comprueba el estado del pipeline para una rama o etiqueta. Por defecto, la rama actual.

-p, --pipelineid=0 Comprueba el estado del pipeline para un ID de pipeline específico.

-w, --web[=false] Abre el pipeline en un navegador. Utiliza el navegador predeterminado, o el especificado en la variable BROWSER.

OPCIONES HEREDADAS DE COMANDOS PADRE

-h, --help[=false] Muestra la ayuda para este comando.

-R, --repo="" Selecciona otro repositorio. Puede usar el formato PROPIETARIO/REPO o GRUPO/NOMBRE ESPACIO/REPO. También acepta URL completas o URLs de Git.

EJEMPLO

# Usa la rama actual
$ glab pipeline ci view
# Obtiene el último pipeline de la rama main
$ glab pipeline ci view main
# Igual que el segundo ejemplo
$ glab pipeline ci view -b main
# Obtiene el último pipeline de la rama main del repositorio myusername/glab
$ glab pipeline ci view -b main -R myusername/glab
