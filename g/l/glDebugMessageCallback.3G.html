NOMBRE

glDebugMessageCallback - especificar una devolución de llamada para recibir mensajes de depuración de GL

ESPECIFICACIÓNC

void glDebugMessageCallback(DEBUGPROC callback, const void * userParam);

PARÁMETROS

callback

La dirección de una función de devolución de llamada que se llamará cuando se genere un mensaje de depuración.

userParam

Un puntero suministrado por el usuario que se pasará en cada invocación de callback.

DESCRIPCIÓN

glDebugMessageCallback establece la función de devolución de llamada de salida de depuración actual a la función cuya dirección se proporciona en callback. La función de devolución de llamada debe tener el siguiente prototipo (en C), o ser compatible de alguna otra manera con dicho prototipo:

        typedef void (APIENTRY *DEBUGPROC)(GLenum source,
            GLenum type,
            GLuint id,
            GLenum severity,
            GLsizei length,
            const GLchar *message,
            const void *userParam);

Esta función está definida para tener la misma convención de llamada que las funciones de la API de GL. En la mayoría de los casos, esto se define como APIENTRY, aunque variará según la plataforma, el lenguaje y el compilador.

Cada vez que se genera un mensaje de depuración, la función de devolución de llamada de depuración se invocará con source, type, id y severity asociados con el mensaje, y length establecido en la longitud del mensaje de depuración cuya cadena de caracteres está en la matriz apuntada por message. userParam se establecerá en el valor pasado en el parámetro userParam a la llamada más reciente a glDebugMessageCallback.

NOTAS

Cuando GL está en uso remoto, el servidor puede no ser capaz de llamar a funciones en el espacio de direcciones del cliente. En tales casos, la función de devolución de llamada puede no ser invocada y el usuario debe recuperar los mensajes de depuración del registro de mensajes de depuración del contexto llamando a glGetDebugMessageLog().
