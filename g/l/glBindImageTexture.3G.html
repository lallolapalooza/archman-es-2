NOMBRE

glBindImageTexture - enlaza un nivel de una textura a una unidad de imagen

ESPECIFICACIÓN C

void glBindImageTexture(GLuint unit, GLuint texture, GLint level, GLboolean layered, GLint layer, GLenum access, GLenum format);

PARÁMETROS

unit

Especifica el índice de la unidad de imagen a la que se enlazará la textura.

texture

Especifica el nombre de la textura que se enlazará a la unidad de imagen.

level

Especifica el nivel de la textura que se enlazará.

layered

Especifica si se establecerá un enlace de textura en capas.

layer

Si layered es GL_FALSE, especifica la capa de texture que se enlazará a la unidad de imagen. Se ignora en caso contrario.

access

Especifica un token que indica el tipo de acceso que se realizará en la imagen.

format

Especifica el formato en el que se tratarán los elementos de la imagen para propósitos de escrituras formateadas.

DESCRIPCIÓN

glBindImageTexture enlaza un solo nivel de una textura a una unidad de imagen con el fin de leerla y escribirla desde los shaders. unit especifica el índice basado en cero de la unidad de imagen a la que se enlazará el nivel de textura. texture especifica el nombre de un objeto de textura existente que se enlazará a la unidad de imagen. Si texture es cero, se romperá cualquier enlace existente a la unidad de imagen. level especifica el nivel de la textura que se enlazará a la unidad de imagen.

Si texture es el nombre de una textura de matriz unidimensional, bidimensional o tridimensional, una textura de mapa de cubos o de matriz de mapas de cubos, o una textura de matriz multisample bidimensional, entonces es posible enlazar toda la matriz o solo una capa individual de la matriz a la unidad de imagen. En tales casos, si layered es GL_TRUE, toda la matriz se adjuntará a la unidad de imagen y layer se ignorará. Sin embargo, si layered es GL_FALSE, entonces layer especifica la capa de la matriz que se adjuntará a la unidad de imagen.

access especifica los tipos de acceso que serán realizados por los shaders y puede establecerse en GL_READ_ONLY, GL_WRITE_ONLY o GL_READ_WRITE para indicar acceso de solo lectura, solo escritura o lectura/escritura, respectivamente. La violación del tipo de acceso especificado en access (por ejemplo, si un shader escribe en una imagen enlazada con access establecido en GL_READ_ONLY) conducirá a resultados indefinidos, incluyendo posiblemente la terminación del programa.

format especifica el formato que se utilizará al realizar escrituras formateadas en la imagen desde los shaders. format debe ser compatible con el formato interno de la textura y debe ser uno de los formatos que se enumeran en la siguiente tabla.

Cuando una textura se enlaza a una unidad de imagen, el
parámetro format para la unidad de imagen no necesita coincidir exactamente con el formato interno de la textura siempre que los formatos se consideren compatibles según se define en la Especificación OpenGL. El criterio de coincidencia utilizado para una textura dada se puede determinar llamando a glGetTexParameter() con value establecido en GL_IMAGE_FORMAT_COMPATIBILITY_TYPE, con valores de retorno de GL_IMAGE_FORMAT_COMPATIBILITY_BY_SIZE y GL_IMAGE_FORMAT_COMPATIBILITY_BY_CLASS, especificando coincidencias por tamaño y por clase, respectivamente.

NOTAS

La función glBindImageTexture solo está disponible si la versión de GL es 4.2 o superior.

ERRORES

Se genera GL_INVALID_VALUE si unit es mayor o igual al valor de GL_MAX_IMAGE_UNITS.

Se genera GL_INVALID_VALUE si texture no es el nombre de un objeto de textura existente.

Se genera GL_INVALID_VALUE si level o layer son menores que cero.

Se genera GL_INVALID_ENUM si access o format no son uno de los tokens admitidos.

GETS ASOCIADOS

glGet() con el argumento GL_IMAGE_BINDING_NAME.

glGet() con el argumento GL_IMAGE_BINDING_LEVEL.

glGet() con el argumento GL_IMAGE_BINDING_LAYERED.

glGet() con el argumento GL_IMAGE_BINDING_LAYER.

glGet() con el argumento GL_IMAGE_BINDING_ACCESS.

glGet() con el argumento GL_IMAGE_BINDING_FORMAT.
