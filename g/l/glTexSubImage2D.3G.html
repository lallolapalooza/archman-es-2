DESCRIPCIÓ

N

El mapeo de texturas asigna una porción de una imagen de textura especificada a cada primitiva gráfica para la cual el mapeo de texturas está

habilitado.

glTexSubImage2D y glTextureSubImage2D redefinen una subregión contigua de una imagen de textura bidimensional o de arreglo unidimensional existente. Los texels referenciados por pixels reemplazan la porción del arreglo de textura existente con índices x xoffset y xoffset + width - 1, inclusive, e índices y yoffset y yoffset + height - 1, inclusive. Esta región no puede incluir ningún texel fuera del rango del arreglo de textura tal como se especificó originalmente. No es un error especificar una subtextura con ancho o alto cero, pero tal especificación no tiene

efecto.

Si un objeto de búfer con nombre distinto de cero está enlazado al destino GL_PIXEL_UNPACK_BUFFER (véase glBindBuffer()) mientras se especifica una imagen de textura, pixels se trata como un desplazamiento en bytes de

ntro del almacén de d
atos del objeto de búfer.

NOTA

S

Los modos de glPixelStore() afectan a las imágenes de

textura.

glTexSubImage2D y glTextureSubImage3D especifican una subtextura bidimensional para la unidad de textura actual, especificada con glActiveText

ure().

GL_STENCIL_INDEX se acepta para format solo si la versi

ón de GL es 4
.4 o superior.

ERRORE

S

Se genera GL_INVALID_ENUM si target o el destino efectivo de texture no es GL_TEXTURE_2D, GL_TEXTURE_CUBE_MAP_POSITIVE_X, GL_TEXTURE_CUBE_MAP_NEGATIVE_X, GL_TEXTURE_CUBE_MAP_POSITIVE_Y, GL_TEXTURE_CUBE_MAP_NEGATIVE_Y, GL_TEXTURE_CUBE_MAP_POSITIVE_Z, GL_TEXTURE_CUBE_MAP_NEGATIVE_Z, o GL_TEXTURE_1D_ARRAY

.

Se genera GL_INVALID_OPERATION por glTextureSubImage2D si texture no es el nombre de un objeto de textura

existente.

Se genera GL_INVALID_ENUM si format no es una constante de formato

aceptada.

Se genera GL_INVALID_ENUM si type no es una constante de

tipo.

Se genera GL_INVALID_VALUE si level es menor que

0.

Se puede generar GL_INVALID_VALUE si level es mayor que log 2 max, donde max es el valor devuelto por GL_MAX_TEXTURE_SIZE

.

Se genera GL_INVALID_VALUE si xoffset < - b, xoffset + width > w - b, yoffset < - b, o yoffset + height > h - b, donde w es el GL_TEXTURE_WIDTH, h es el GL_TEXTURE_HEIGHT, y b es el ancho del borde de la imagen de textura que se está modificando. Nótese que w y h incluyen dos veces el ancho del

borde.

Se genera GL_INVALID_VALUE si width o height es menor que

0.

Se genera GL_INVALID_OPERATION si el arreglo de textura no ha sido definido por una operación previa glTexImage

2D().

Se genera GL_INVALID_OPERATION si type es uno de GL_UNSIGNED_BYTE_3_3_2, GL_UNSIGNED_BYTE_2_3_3_REV, GL_UNSIGNED_SHORT_5_6_5, o GL_UNSIGNED_SHORT_5_6_5_REV y format no es GL_RGB

.

Se genera GL_INVALID_OPERATION si type es uno de GL_UNSIGNED_SHORT_4_4_4_4, GL_UNSIGNED_SHORT_4_4_4_4_REV, GL_UNSIGNED_SHORT_5_5_5_1, GL_UNSIGNED_SHORT_1_5_5_5_REV, GL_UNSIGNED_INT_8_8_8_8, GL_UNSIGNED_INT_8_8_8_8_REV, GL_UNSIGNED_INT_10_10_10_2, o GL_UNSIGNED_INT_2_10_10_10_REV y format no es GL_RGBA ni GL_BGRA

.

Se genera GL_INVALID_OPERATION si format es GL_STENCIL_INDEX y el formato interno base no es GL_STENCIL_INDEX

.

Se genera GL_INVALID_OPERATION si un nombre de objeto de búfer distinto de cero está enlazado al destino GL_PIXEL_UNPACK_BUFFER y el almacén de datos del objeto de búfer está actualmente

mapeado.

Se genera GL_INVALID_OPERATION si un nombre de objeto de búfer distinto de cero está enlazado al destino GL_PIXEL_UNPACK_BUFFER y los datos se desempaquetarían del objeto de búfer de modo que las lecturas de memoria requeridas excederían el tamaño del almacén de

datos.

Se genera GL_INVALID_OPERATION si un nombre de objeto de búfer distinto de cero está enlazado al destino GL_PIXEL_UNPACK_BUFFER y pixels no es divisible exactamente por el número de bytes necesarios para almacenar en memoria un dato indicado por ty

pe
.
