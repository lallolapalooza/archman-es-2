GLDEPTHRANGEARRAY(3G) [FIJADO: manual] GLDEPTHRANGEARRAY(3G)

NOMBRE

glDepthRangeArray - especifica el mapeo de valores de profundidad de coordenadas de dispositivo normalizadas a coordenadas de ventana para un conjunto especificado de vistas

ESPECIFICACIÓN C

void glDepthRangeArrayv(GLuint first, GLsizei count, const GLdouble *v);

PARÁMETROS

first

Especifica el índice de la primera vista cuyo rango de profundidad se actualizará.

count

Especifica el número de vistas cuyo rango de profundidad se actualizará.

v

Especifica la dirección de un array que contiene los valores cercano y lejano para el rango de profundidad de cada vista modificada.

DESCRIPCIÓN

Después del recorte y la división por w, las coordenadas de profundidad van de -1 a 1, correspondientes a los planos de recorte cercano y lejano. Cada vista tiene un rango de profundidad independiente especificado como un mapeo lineal de las coordenadas de profundidad normalizadas en este rango a coordenadas de profundidad de ventana. Independientemente de la implementación del búfer de profundidad real, las coordenadas de profundidad de la ventana se tratan como si fueran de 0 a 1 (como los componentes de color). glDepthRangeArray especifica un mapeo lineal de las coordenadas de profundidad normalizadas en este rango a coordenadas de profundidad de ventana para cada vista en el rango [first, first + count). Por lo tanto, los valores aceptados por glDepthRangeArray se recortan a este rango antes de ser aceptados.

El parámetro first especifica el índice de la primera vista cuya rango de profundidad se modificará y debe ser menor que el valor de GL_MAX_VIEWPORTS. count especifica el número de vistas cuya rango de profundidad se modificará. first + count debe ser menor o igual al valor de GL_MAX_VIEWPORTS. v especifica la dirección de un array de pares de valores de punto flotante de doble precisión que representan los valores cercano y lejano del rango de profundidad para cada vista, en ese orden.

El ajuste de (0,1) mapea el plano cercano a 0 y el plano lejano a 1. Con este mapeo, se utiliza completamente el rango del búfer de profundidad.

NOTAS

No es necesario que la distancia del plano cercano sea menor que la distancia del plano lejano. Se aceptan mapeos inversos como cercano = 1 y lejano = 0.

El tipo del parámetro v se cambió de GLclampd a GLdouble. Este cambio es transparente al código del usuario y se describe en detalle en la página removedTypes().

ERRORES

Se genera GL_INVALID_VALUE si first es mayor o igual al valor de GL_MAX_VIEWPORTS.

Se genera GL_INVALID_VALUE si first + count es mayor o igual al valor de GL_MAX_VIEWPORTS.

GETS ASOCIADOS

glGet() con el argumento GL_DEPTH_RANGE
