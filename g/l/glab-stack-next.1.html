NOMBRE

glab-stack-next - Se mueve al siguiente diff en la pila. (EXPERIMENTAL)

SINOPSIS

glab stack next [flags]

DESCRIPCIÓN

Se mueve al siguiente diff en la pila y extrae esa rama.

Esta función es experimental. Puede estar rota o eliminarse sin previo aviso. Lee más sobre lo que significan las funciones experimentales en https://docs.gitlab.com/policy/development_stages_support/

Utiliza las funciones experimentales bajo tu propio riesgo.

OPCIONES HEREDADAS DE COMANDOS PADRE

-h, --help[=false] Muestra la ayuda para este comando.

-R, --repo="" Selecciona otro repositorio. Puede usar el formato PROPIETARIO/REPO o GRUPO/NAMESPACE/REPO. También acepta URL completas o URL de Git.

EJEMPLO

$ glab stack next
