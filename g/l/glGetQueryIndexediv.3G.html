NOMBRE

glGetQueryIndexediv - devuelve parámetros de un objetivo de objeto de consulta indexado

ESPECIFICACIÓN C

void glGetQueryIndexediv(GLenum target, GLuint index, GLenum pname, GLint * params);

PARÁMETROS

target

Especifica un objetivo de objeto de consulta. Debe ser GL_SAMPLES_PASSED, GL_ANY_SAMPLES_PASSED, GL_ANY_SAMPLES_PASSED_CONSERVATIVE, GL_PRIMITIVES_GENERATED, GL_TRANSFORM_FEEDBACK_PRIMITIVES_WRITTEN, GL_TIME_ELAPSED o GL_TIMESTAMP.

index

Especifica el índice del objetivo del objeto de consulta.

pname

Especifica el nombre simbólico de un parámetro del objetivo del objeto de consulta. Los valores aceptados son GL_CURRENT_QUERY o GL_QUERY_COUNTER_BITS.

params

Devuelve los datos solicitados.

DESCRIPCIÓN

glGetQueryIndexediv devuelve en params un parámetro seleccionado del objetivo de objeto de consulta indexado especificado por target e index. index especifica el índice del objetivo del objeto de consulta y debe estar entre cero y un máximo específico del objetivo.

pname nombra un parámetro específico del objetivo del objeto de consulta. Cuando pname es GL_CURRENT_QUERY, el nombre de la consulta activa actualmente para el index especificado de target, o cero si no hay ninguna consulta activa, se colocará en params. Si pname es GL_QUERY_COUNTER_BITS, se devuelve en params el número de bits, dependiente de la implementación, utilizado para almacenar el resultado de las consultas para target.

NOTAS

El objetivo GL_ANY_SAMPLES_PASSED_CONSERVATIVE solo está disponible si la versión de GL es 4.3 o superior.

Si se genera un error, no se realiza ningún cambio en el contenido de params.

Llamar a glGetQueryiv() es equivalente a llamar a glGetQueryIndexediv con index establecido en cero.

ERRORES

Se genera GL_INVALID_ENUM si target o pname no son valores aceptados.

Se genera GL_INVALID_VALUE si index es mayor o igual que el máximo específico del target.
