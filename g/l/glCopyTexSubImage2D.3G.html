GLCOPYTEXSUBIMAGE2D(3G) [FIXME: manual] GLCOPYTEXSUBIMAGE2D(3G)

NOMBRE

glCopyTexSubImage2D, glCopyTextureSubImage2D - copia una subimagen de textura bidimensional

ESPECIFICACIÓN C

void glCopyTexSubImage2D(GLenum target, GLint level, GLint xoffset, GLint yoffset, GLint x, GLint y, GLsizei width, GLsizei height);

void glCopyTextureSubImage2D(GLuint texture, GLint level, GLint xoffset, GLint yoffset, GLint x, GLint y, GLsizei width, GLsizei height);

PARÁMETROS

target

Especifica el destino al que se vincula el objeto de textura para la función glCopyTexSubImage2D. Debe ser GL_TEXTURE_1D_ARRAY, GL_TEXTURE_2D, GL_TEXTURE_CUBE_MAP_POSITIVE_X, GL_TEXTURE_CUBE_MAP_NEGATIVE_X, GL_TEXTURE_CUBE_MAP_POSITIVE_Y, GL_TEXTURE_CUBE_MAP_NEGATIVE_Y, GL_TEXTURE_CUBE_MAP_POSITIVE_Z, GL_TEXTURE_CUBE_MAP_NEGATIVE_Z, o GL_TEXTURE_RECTANGLE.

texture

Especifica el nombre del objeto de textura para la función glCopyTextureSubImage2D.

level

Especifica el número de nivel de detalle. El nivel 0 es el nivel de imagen base. El nivel n es la n-ésima imagen de reducción mipmap.

xoffset

Especifica un desplazamiento de texel en la dirección x dentro del array de texturas.

yoffset

Especifica un desplazamiento de texel en la dirección y dentro del array de texturas.

x, y

Especifican las coordenadas de ventana de la esquina inferior izquierda de la región rectangular de píxeles a copiar.

width

Especifica el ancho de la subimagen de textura.

height

Especifica la altura de la subimagen de textura.

DESCRIPCIÓN

glCopyTexSubImage2D y glCopyTextureSubImage2D reemplazan una porción rectangular de una imagen de textura bidimensional, imagen de textura de mapa de cubos, imagen rectangular, o una porción lineal de un número de "slices" de un array de texturas unidimensional con píxeles del GL_READ_BUFFER actual (en lugar de la memoria principal, como ocurre con glTexSubImage2D()).

El rectángulo de píxeles alineado con la pantalla con la esquina inferior izquierda en x y y y con ancho width y alto height reemplaza la porción del array de texturas con índices x desde xoffset hasta xoffset + width - 1, inclusive, e índices y desde yoffset hasta yoffset + height - 1, inclusive, en el nivel mipmap especificado por level.

Los píxeles en el rectángulo se procesan exactamente como si se hubiera llamado a glReadPixels(), pero el proceso se detiene justo antes de la conversión final. En este punto, todos los valores de los componentes de píxel se limitan al rango $[0,1]$ y luego se convierten al formato interno de la textura para su almacenamiento en el array de texels.

El rectángulo de destino en el array de texturas no puede incluir ningún texel fuera del array de texturas tal como se especificó originalmente. No es un error especificar una subtextura con ancho o alto cero, pero tal especificación no tiene ningún efecto.

Cuando target es GL_TEXTURE_1D_ARRAY, la coordenada y y la altura se tratan como el "slice" de inicio y el número de "slices" a modificar, respectivamente.

Si alguno de los píxeles dentro del rectángulo especificado del GL_READ_BUFFER actual está fuera de la ventana de lectura asociada con el contexto de renderizado actual, entonces los valores obtenidos para esos píxeles son indefinidos.

No se realizan cambios en los parámetros internalformat, width o height del array de texturas especificado, ni en los valores de texel fuera de la subregión especificada.

NOTAS

Los modos de glPixelStore() afectan a las imágenes de textura.

ERRORES

Se genera GL_INVALID_ENUM si target no es GL_TEXTURE_2D, GL_TEXTURE_CUBE_MAP_POSITIVE_X, GL_TEXTURE_CUBE_MAP_NEGATIVE_X, GL_TEXTURE_CUBE_MAP_POSITIVE_Y, GL_TEXTURE_CUBE_MAP_NEGATIVE_Y, GL_TEXTURE_CUBE_MAP_POSITIVE_Z, GL_TEXTURE_CUBE_MAP_NEGATIVE_Z, GL_TEXTURE_1D_ARRAY o GL_RECTANGLE.

Se genera GL_INVALID_FRAMEBUFFER_OPERATION si el objeto vinculado a GL_READ_FRAMEBUFFER_BINDING no está completo en el framebuffer.

Se genera GL_INVALID_OPERATION si el array de texturas no ha sido definido por una operación previa de glTexImage2D(), glTexStorage2D() o glCopyTexImage2D().

glCopyTextureSubImage2D genera GL_INVALID_OPERATION si texture no es el nombre de un objeto de textura existente.

glCopyTextureSubImage2D genera GL_INVALID_OPERATION si el destino efectivo de la textura no se corresponde con uno de los destinos de textura soportados por la función.

Se genera GL_INVALID_VALUE si level es menor que 0.

Se genera GL_INVALID_VALUE si el destino efectivo es GL_TEXTURE_RECTANGLE y level no es cero.

Se puede generar GL_INVALID_VALUE si level > log 2 ⁡ max, donde max es el valor devuelto por GL_MAX_TEXTURE_SIZE.

Se genera GL_INVALID_VALUE si xoffset < 0, xoffset + width > w, yoffset < 0, o yoffset + height > h, donde w es GL_TEXTURE_WIDTH y h es GL_TEXTURE_HEIGHT de la imagen de textura que se modifica.

Se genera GL_INVALID_OPERATION si:

•el buffer de lectura es GL_NONE, o
•el valor de GL_READ_FRAMEBUFFER_BINDING no es cero, y:
•el buffer de lectura selecciona un adjunto que no tiene una imagen adjunta, o
•el valor efectivo de GL_SAMPLE_BUFFERS para el framebuffer de lectura es uno.
