NOMBRE

glDeleteFramebuffers - elimina objetos de framebuffer

ESPECIFICACIÓN C

void glDeleteFramebuffers(GLsizei n, GLuint *framebuffers);

PARÁMETROS

n

Especifica el número de objetos de framebuffer a eliminar.

framebuffers

Un puntero a un array que contiene n objetos de framebuffer a eliminar.

DESCRIPCIÓN

glDeleteFramebuffers elimina los n objetos de framebuffer cuyos nombres se almacenan en el array al que apunta framebuffers. El nombre cero está reservado por el GL y se ignora silenciosamente si aparece en framebuffers, al igual que otros nombres no utilizados. Una vez que se elimina un objeto de framebuffer, su nombre vuelve a estar disponible y no tiene adjuntos. Si se elimina un framebuffer que está actualmente enlazado a uno o más de los objetivos GL_DRAW_FRAMEBUFFER o GL_READ_FRAMEBUFFER, es como si se hubiera ejecutado glBindFramebuffer() con el target y framebuffer correspondientes a cero.

ERRORES

Se genera GL_INVALID_VALUE si n es negativo.
