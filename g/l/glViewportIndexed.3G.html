NOMBRE

glViewportIndexed - establece un viewport especificado

ESPECIFICACIÓN C

void glViewportIndexedf(GLuint index, GLfloat x, GLfloat y, GLfloat w, GLfloat h);

void glViewportIndexedfv(GLuint index, const GLfloat *v);

PARÁMETROS

index

Especifica el primer viewport a establecer.

x, y

Para glViewportIndexedf, especifica la esquina inferior izquierda del rectángulo del viewport, en píxeles. El valor inicial es (0,0).

w, h

Para glViewportIndexedf, especifica el ancho y la altura del viewport. Cuando un contexto GL se asocia por primera vez a una ventana, w y h se establecen a las dimensiones de esa ventana.

v

Para glViewportIndexedfv, especifica la dirección de un array que contiene los parámetros del viewport.

DESCRIPCIÓN

glViewportIndexedf y glViewportIndexedfv especifican los parámetros para un único viewport. index especifica el índice del viewport a modificar. index debe ser menor que el valor de GL_MAX_VIEWPORTS. Para glViewportIndexedf, x, y, w, y h especifican la izquierda, la parte inferior, el ancho y la altura del viewport en píxeles, respectivamente. Para glViewportIndexedfv, v contiene la dirección de un array de valores de punto flotante que especifican la izquierda (x), la parte inferior (y), el ancho (w) y la altura (h) de cada viewport, en ese orden. x e y dan la ubicación de la esquina inferior izquierda del viewport, y w y h dan el ancho y la altura del viewport, respectivamente. El viewport especifica la transformación afín de x e y de coordenadas normalizadas del dispositivo a coordenadas de ventana. Sean x nd e y nd coordenadas normalizadas del dispositivo. Entonces las coordenadas de ventana x w e y w se calculan de la siguiente manera:

x w = x nd + 1 ⁢ ancho 2 + x

y w = y nd + 1 ⁢ alto 2 + y

La ubicación de la esquina inferior izquierda del viewport, dada por (x, y) se recorta para estar dentro del rango de límites del viewport dependiente de la implementación. El rango de límites del viewport [min, max] se puede determinar llamando a glGet() con el argumento GL_VIEWPORT_BOUNDS_RANGE. El ancho y la altura del viewport se recortan silenciosamente a un rango que depende de la implementación. Para consultar este rango, llame a glGet() con el argumento GL_MAX_VIEWPORT_DIMS.

La precisión con la que GL interpreta los límites del viewport de punto flotante es dependiente de la implementación y puede determinarse consultando la constante definida por la implementación GL_VIEWPORT_SUBPIXEL_BITS.

Llamar a glViewportIndexedfv es equivalente a llamar a glViewportArray() con first establecido a index, count establecido a 1 y v pasado directamente. glViewportIndexedf es equivalente a:

    void glViewportIndexedf(GLuint index, GLfloat x, GLfloat y, GLfloat w, GLfloat h) {
        const float v[4]  = { x, y, w, h };
        glViewportArrayv(index, 1, v);
    }

ERRORES

Se genera GL_INVALID_VALUE si index es mayor o igual que el valor de GL_MAX_VIEWPORTS.

Se genera GL_INVALID_VALUE si w o h es negativo.

GETS ASOCIADOS

glGet() con el argumento GL_VIEWPORT

glGet() con el argumento GL_MAX_VIEWPORT_DIMS

glGet() con el argumento GL_VIEWPORT_BOUNDS_RANGE

glGet() con el argumento GL_VIEWPORT_SUBPIXEL_BITS
