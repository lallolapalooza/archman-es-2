NOMBRE

glUseProgramStages - enlaza etapas de un objeto de programa a una pipeline de programa

ESPECIFICACIÓN C

void glUseProgramStages(GLuint pipeline, GLbitfield stages, GLuint program);

PARÁMETROS

pipeline

Especifica el objeto de pipeline de programa al que se enlazarán las etapas de program.

stages

Especifica un conjunto de etapas de programa para enlazar al objeto de pipeline de programa.

program

Especifica el objeto de programa que contiene los ejecutables del sombreador a usar en pipeline.

DESCRIPCIÓN

glUseProgramStages enlaza ejecutables de un objeto de programa asociado con un conjunto especificado de etapas de sombreador al objeto de pipeline de programa dado por pipeline. pipeline especifica el objeto de pipeline de programa al que se enlazarán los ejecutables. stages contiene una combinación lógica de bits que indican las etapas de sombreador a usar dentro de program con el objeto de pipeline de programa pipeline. stages debe ser una combinación lógica de GL_VERTEX_SHADER_BIT, GL_TESS_CONTROL_SHADER_BIT, GL_TESS_EVALUATION_SHADER_BIT, GL_GEOMETRY_SHADER_BIT, GL_FRAGMENT_SHADER_BIT y GL_COMPUTE_SHADER_BIT. Adicionalmente, el valor especial GL_ALL_SHADER_BITS puede especificarse para indicar que todos los ejecutables contenidos en program deben instalarse en pipeline.

Si program se refiere a un objeto de programa con un sombreador válido adjunto para una etapa de sombreador indicada, glUseProgramStages instala el código ejecutable para esa etapa en el objeto de pipeline de programa indicado pipeline. Si program es cero, o se refiere a un objeto de programa sin un ejecutable de sombreador válido para una etapa dada, es como si el objeto de pipeline no tuviera ninguna etapa programable configurada para las etapas de sombreador indicadas. Si stages contiene bits distintos de los enumerados anteriormente, y no es igual a GL_ALL_SHADER_BITS, se generará un error.

NOTAS

El bit GL_COMPUTE_SHADER_BIT solo está disponible si la versión de GL es 4.3 o superior.

ERRORES

Se genera GL_INVALID_VALUE si shaders contiene bits establecidos que no son reconocidos, y no es el valor reservado GL_ALL_SHADER_BITS.

Se genera GL_INVALID_OPERATION si program se refiere a un objeto de programa que no fue enlazado con su estado GL_PROGRAM_SEPARABLE establecido.

Se genera GL_INVALID_OPERATION si program se refiere a un objeto de programa que no ha sido enlazado exitosamente.

Se genera GL_INVALID_OPERATION si pipeline no es un nombre devuelto previamente por una llamada a glGenProgramPipelines() o si dicho nombre ha sido eliminado por una llamada a glDeleteProgramPipelines().
