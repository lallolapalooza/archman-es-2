NOMBRE

glCreateSamplers - crear objetos de muestreador

ESPECIFICACIÓN C

void glCreateSamplers(GLsizei n, GLuint *samplers);

PARÁMETROS

n

Número de objetos de muestreador a crear.

samplers

Especifica un array en el que se almacenan los nombres de los nuevos objetos de muestreador.

DESCRIPCIÓN

glCreateSamplers devuelve n nombres de muestreador previamente no utilizados en samplers, cada uno representando un nuevo objeto de muestreador inicializado al estado por defecto.

ERRORES

GL_INVALID_VALUE se genera si n es negativo.
