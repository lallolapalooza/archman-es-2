NOMBRE

glGetActiveUniform - Devuelve información sobre una variable uniforme activa para el objeto de programa especificado

ESPECIFICACIÓN EN C

void glGetActiveUniform(GLuint program, GLuint index, GLsizei bufSize, GLsizei *length, GLint *size, GLenum *type, GLchar *name);

PARÁMETROS

program

Especifica el objeto de programa a consultar.

index

Especifica el índice de la variable uniforme a consultar.

bufSize

Especifica el número máximo de caracteres que OpenGL puede escribir en el búfer de caracteres indicado por name.

length

Devuelve el número de caracteres realmente escritos por OpenGL en la cadena indicada por name (excluyendo el terminador nulo) si se pasa un valor distinto de NULL.

size

Devuelve el tamaño de la variable uniforme.

type

Devuelve el tipo de dato de la variable uniforme.

name

Devuelve una cadena terminada en nulo que contiene el nombre de la variable uniforme.

DESCRIPCIÓN

glGetActiveUniform devuelve información sobre una variable uniforme activa en el objeto de programa especificado por program. El número de variables uniformes activas se puede obtener llamando a glGetProgram() con el valor GL_ACTIVE_UNIFORMS. Un valor de 0 para index selecciona la primera variable uniforme activa. Los valores permitidos para index van de cero al número de variables uniformes activas menos uno.

Los shaders pueden usar variables uniformes incorporadas, variables uniformes definidas por el usuario o ambas. Las variables uniformes incorporadas tienen el prefijo "gl_" y hacen referencia al estado existente de OpenGL o a valores derivados de dicho estado (por ejemplo, gl_DepthRangeParameters, consulte la especificación del Lenguaje de Sombreado de OpenGL para obtener una lista completa). Las variables uniformes definidas por el usuario tienen nombres arbitrarios y obtienen sus valores de la aplicación a través de llamadas a glUniform(). Una variable uniforme (ya sea incorporada o definida por el usuario) se considera activa si se determina durante la operación de enlace que puede ser accedida durante la ejecución del programa. Por lo tanto, program debería haber sido previamente el objetivo de una llamada a glLinkProgram(), pero no es necesario que se haya enlazado correctamente.

El tamaño del búfer de caracteres necesario para almacenar el nombre de variable uniforme más largo en program se puede obtener llamando a glGetProgram() con el valor GL_ACTIVE_UNIFORM_MAX_LENGTH. Este valor debe usarse para asignar un búfer de tamaño suficiente para almacenar el nombre de variable uniforme devuelto. El tamaño de este búfer de caracteres se pasa en bufSize, y un puntero a este búfer de caracteres se pasa en name.

glGetActiveUniform devuelve el nombre de la variable uniforme indicada por index, almacenándolo en el búfer de caracteres especificado por name. La cadena devuelta estará terminada en nulo. El número real de caracteres escritos en este búfer se devuelve en length, y este recuento no incluye el carácter de terminación nulo. Si no se requiere la longitud de la cadena devuelta, se puede pasar un valor de NULL en el argumento length.

El argumento type devolverá un puntero al tipo de dato de la variable uniforme. Las constantes simbólicas devueltas para los tipos uniformes se muestran en la siguiente tabla.

El argumento size devolverá un puntero al tamaño del uniforme. Si el uniforme es un array, size contendrá el número de elementos en el array. Si no es un array, size contendrá 1.

NOTAS

Las variables uniformes con el mismo nombre pero con tipos diferentes se tratan como variables uniformes separadas. Las variables uniformes que son miembros de arrays o estructuras se tratan como variables uniformes separadas. Los nombres de estas variables uniformes contendrán las notaciones de índice de array y/o de miembro de estructura apropiadas.

Si program no es un objeto de programa, se generará GL_INVALID_OPERATION.

Si index es mayor o igual que el número de variables uniformes activas en program, se generará GL_INVALID_VALUE.

Si bufSize es negativo, se generará GL_INVALID_VALUE.

ERRORES

GL_INVALID_OPERATION se genera si program no es un objeto de programa.

GL_INVALID_VALUE se genera si index es mayor o igual que el número de variables uniformes activas en program.

GL_INVALID_VALUE se genera si bufSize es negativo.

glGetActiveUniform

glGetActiveUniform

OpenGL Version 4.5

Name

glGetActiveUniform - query the properties of an active uniform variable of a program object

C Specification

void glGetActiveUniform( GLuint program,
                         GLuint index,
                         GLsizei bufSize,
                         GLsizei *length,
                         GLint *size,
                         GLenum *type,
                         GLchar *name );

Parameters

program
The program object to be queried.
index
The index of the uniform variable to be queried.
bufSize
The size of the character array used to store the name of the uniform variable.
length
A pointer to an integer that will be written with the length of the uniform variable name, excluding the null termination character.
size
A pointer to an integer that will be written with the number of elements in the uniform variable. For a uniform variable that is not an array, this will be 1. For a uniform variable that is an array, this will be the number of elements in the array.
type
A pointer to an enum that will be written with the data type of the uniform variable.
name
A pointer to a character array that will be written with the name of the uniform variable.

Description

glGetActiveUniform retrieves information about an active uniform variable in the specified program object. The active uniform variables are numbered from 0 to N-1, where N is the value of GL_ACTIVE_UNIFORMS.

The index parameter specifies the index of the uniform variable to be queried. The value of index must be in the range [0, N-1].

If the uniform variable specified by index is not an array, then size will be 1, and name will contain the name of the uniform variable. If the uniform variable is an array, then size will contain the number of elements in the array, and name will contain the name of the array followed by an empty bracket ([]) to indicate that it is an array.

The type parameter will be set to the data type of the uniform variable. The possible data types are:

GL_FLOAT GL_FLOAT_VEC2 GL_FLOAT_VEC3 GL_FLOAT_VEC4
GL_INT GL_INT_VEC2 GL_INT_VEC3 GL_INT_VEC4
GL_UNSIGNED_INT GL_UNSIGNED_INT_VEC2 GL_UNSIGNED_INT_VEC3 GL_UNSIGNED_INT_VEC4
GL_BOOL GL_BOOL_VEC2 GL_BOOL_VEC3 GL_BOOL_VEC4
GL_FLOAT_MAT2 GL_FLOAT_MAT3 GL_FLOAT_MAT4 GL_FLOAT_MAT2x3
GL_FLOAT_MAT2x4 GL_FLOAT_MAT3x2 GL_FLOAT_MAT3x4 GL_FLOAT_MAT4x2
GL_FLOAT_MAT4x3 GL_SAMPLER_1D GL_SAMPLER_2D GL_SAMPLER_3D
GL_SAMPLER_CUBE GL_SAMPLER_1D_SHADOW GL_SAMPLER_2D_SHADOW GL_SAMPLER_1D_ARRAY
GL_SAMPLER_2D_ARRAY GL_SAMPLER_BUFFER GL_SAMPLER_2D_MULTISAMPLE GL_SAMPLER_2D_MULTISAMPLE_ARRAY
GL_INT_SAMPLER_1D GL_INT_SAMPLER_2D GL_INT_SAMPLER_3D GL_INT_SAMPLER_CUBE
GL_INT_SAMPLER_1D_ARRAY GL_INT_SAMPLER_2D_ARRAY GL_INT_SAMPLER_2D_MULTISAMPLE GL_INT_SAMPLER_2D_MULTISAMPLE_ARRAY

GL_UNSIGNED_INT_SAMPLER_2D_MULTISAMPLE GL_UNSIGNED_INT_SAMPLER_2D_MULTISAMPLE_ARRAY GL_UNSIGNED_INT_SAMPLER_BUFFER GL_UNSIGNED_INT_SAMPLER_2D_RECT
GL_IMAGE_1D GL_IMAGE_2D GL_IMAGE_3D GL_IMAGE_2D_RECT
GL_IMAGE_CUBE GL_IMAGE_BUFFER GL_IMAGE_1D_ARRAY GL_IMAGE_2D_ARRAY
GL_IMAGE_2D_MULTISAMPLE GL_IMAGE_2D_MULTISAMPLE_ARRAY GL_INT_IMAGE_1D GL_INT_IMAGE_2D
GL_INT_IMAGE_3D GL_INT_IMAGE_2D_RECT GL_INT_IMAGE_CUBE GL_INT_IMAGE_BUFFER
GL_INT_IMAGE_1D_ARRAY GL_INT_IMAGE_2D_ARRAY GL_INT_IMAGE_2D_MULTISAMPLE GL_INT_IMAGE_2D_MULTISAMPLE_ARRAY
GL_UNSIGNED_INT_IMAGE_1D GL_UNSIGNED_INT_IMAGE_2D GL_UNSIGNED_INT_IMAGE_3D GL_UNSIGNED_INT_IMAGE_2D_RECT
GL_UNSIGNED_INT_IMAGE_CUBE GL_UNSIGNED_INT_IMAGE_BUFFER GL_UNSIGNED_INT_IMAGE_1D_ARRAY GL_UNSIGNED_INT_IMAGE_2D_ARRAY

If one or more elements of an array are active, the name of the array is returned in name, the type is returned in type, and the size parameter returns the highest array element index used, plus one, as determined by the compiler and/or linker. Only one active uniform variable will be reported for a uniform array.

Uniform variables that are declared as structures or arrays of structures will not be returned directly by this function. Instead, each of these uniform variables will be reduced to its fundamental components containing the "." and "[]" operators such that each of the names is valid as an argument to glGetUniformLocation(). Each of these reduced uniform variables is counted as one active uniform variable and is assigned an index. A valid name cannot be a structure, an array of structures, or a subcomponent of a vector or matrix.

The size of the uniform variable will be returned in size. Uniform variables other than arrays will have a size of 1. Structures and arrays of structures will be reduced as described earlier, such that each of the names returned will be a data type in the earlier list. If this reduction results in an array, the size returned will be as described for uniform arrays; otherwise, the size returned will be 1.

The list of active uniform variables may include both built-in uniform variables (which begin with the prefix "gl_") as well as user-defined uniform variable names.

This function will return as much information as it can about the specified active uniform variable. If no information is available, length will be 0, and name will be an empty string. This situation could occur if this function is called after a link operation that failed. If an error occurs, the return values length, size, type, and name will be unmodified.

NOTES

The double types, GL_DOUBLE, GL_DOUBLE_VEC2, GL_DOUBLE_VEC3, GL_DOUBLE_VEC4, GL_DOUBLE_MAT2, GL_DOUBLE_MAT3, GL_DOUBLE_MAT4, GL_DOUBLE_MAT2x3, GL_DOUBLE_MAT2x4, GL_DOUBLE_MAT3x2, GL_DOUBLE_MAT3x4, GL_DOUBLE_MAT4x2, and GL_DOUBLE_MAT4x3 are only available if the GL version is 4.1 or higher.

The image types, GL_IMAGE_1D, GL_IMAGE_2D, GL_IMAGE_3D, GL_IMAGE_2D_RECT, GL_IMAGE_CUBE, GL_IMAGE_BUFFER, GL_IMAGE_1D_ARRAY, GL_IMAGE_2D_ARRAY, GL_IMAGE_2D_MULTISAMPLE, GL_IMAGE_2D_MULTISAMPLE_ARRAY, GL_INT_IMAGE_1D, GL_INT_IMAGE_2D, GL_INT_IMAGE_3D, GL_INT_IMAGE_2D_RECT, GL_INT_IMAGE_CUBE, GL_INT_IMAGE_BUFFER, GL_INT_IMAGE_1D_ARRAY, GL_INT_IMAGE_2D_ARRAY, GL_INT_IMAGE_2D_MULTISAMPLE, GL_INT_IMAGE_2D_MULTISAMPLE_ARRAY, GL_UNSIGNED_INT_IMAGE_1D, GL_UNSIGNED_INT_IMAGE_2D, GL_UNSIGNED_INT_IMAGE_3D, GL_UNSIGNED_INT_IMAGE_2D_RECT, GL_UNSIGNED_INT_IMAGE_CUBE, GL_UNSIGNED_INT_IMAGE_BUFFER, GL_UNSIGNED_INT_IMAGE_1D_ARRAY, GL_UNSIGNED_INT_IMAGE_2D_ARRAY, GL_UNSIGNED_INT_IMAGE_2D_MULTISAMPLE, GL_UNSIGNED_INT_IMAGE_2D_MULTISAMPLE_ARRAY, and the atomic counter type, GL_UNSIGNED_INT_ATOMIC_COUNTER are only available if the GL version is 4.2 or higher.

ERRORS

GL_INVALID_VALUE is generated if program is not a value generated by OpenGL.

GL_INVALID_OPERATION is generated if program is not a program object.

GL_INVALID_VALUE is generated if index is greater than or equal to the number of active uniform variables in program.

GL_INVALID_VALUE is generated if bufSize is less than 0.

glGetActiveUniform

glGetActiveUniform - devuelven información sobre un bloque de variables uniformes o una variable uniforme dentro de un bloque uniforme.

C SPECIFICATION

                    void glGetActiveUniform(
                        GLuint program,
                        GLuint index,
                        GLsizei bufSize,
                        GLsizei *length,
                        GLint *size,
                        GLenum *type,
                        GLchar *name
                    );

PARAMETERS

program
Especifica el programa que contiene el bloque uniforme o la variable uniforme.
index
Especifica el índice de la variable uniforme activa cuyo nombre o información se va a consultar.
bufSize
Especifica el tamaño del búfer de caracteres que contendrá el nombre de la variable uniforme.
length
Devuelve el número de caracteres de escritura real (excluido el terminador nulo) en el búfer de nombres de la variable uniforme, si el tamaño del búfer es suficiente. Si no, devuelve el tamaño del búfer. Si length es NULL, no se devuelve ninguna información.
size
Devuelve el tamaño de la variable uniforme en unidades de su tipo. Las variables uniformes escalares tienen un tamaño de 1. Los vectores uniformes tienen un tamaño que es el número de componentes del vector. Las matrices uniformes tienen un tamaño que es el número de columnas de la matriz (y, por lo tanto, el número de filas para las matrices de tipo fila mayor y el número de columnas para las matrices de tipo columna mayor).
type
Devuelve el tipo de datos de la variable uniforme.
name
Devuelve los caracteres de escritura en el búfer de caracteres especificado por name. Estos caracteres forman el nombre de la variable uniforme.

DESCRIPTION

glGetActiveUniform devuelve información sobre una variable uniforme activa dentro de un programa especificado. El parámetro index especifica la variable uniforme de interés. El nombre de la variable uniforme se devuelve en el búfer de caracteres name. El tamaño de la variable uniforme, en unidades de su tipo, se devuelve en size. El tipo de datos de la variable uniforme se devuelve en type.

El parámetro length devuelve el número real de caracteres de escritura en el búfer de nombres. Si el búfer proporcionado es demasiado pequeño para contener el nombre completo, se escribirán bufSize caracteres en el búfer y el nombre se truncará.

Si index está fuera del rango de las variables uniformes activas para el programa especificado, se generará GL_INVALID_VALUE.

El número de variables uniformes activas en un programa se puede determinar llamando a glGetProgramiv con el parámetro GL_ACTIVE_UNIFORMS.

NOTES

Los nombres de las variables uniformes pueden contener caracteres que requieren codificación para ser utilizados en el código fuente C, como [0] para los elementos de un array uniforme.

ERRORS

GL_INVALID_VALUE se genera si program no es el nombre de un programa válido.

GL_INVALID_VALUE se genera si index es mayor o igual al número de variables uniformes activas en program.

GL_INVALID_VALUE se genera si bufSize es negativo.
