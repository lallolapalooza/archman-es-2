NOMBRE

glGet - devuelve el valor o valores de un parámetro seleccionado

ESPECIFICACIÓN EN C

void glGetBooleanv(GLenumpname, GLboolean *data);

void glGetDoublev(GLenumpname, GLdouble *data);

void glGetFloatv(GLenumpname, GLfloat *data);

void glGetIntegerv(GLenumpname, GLint *data);

void glGetInteger64v(GLenumpname, GLint64 *data);

void glGetBooleani_v(GLenumtarget, GLuintindex, GLboolean *data);

void glGetIntegeri_v(GLenumtarget, GLuintindex, GLint *data);

void glGetFloati_v(GLenumtarget, GLuintindex, GLfloat *data);

void glGetDoublei_v(GLenumtarget, GLuintindex, GLdouble *data);

void glGetInteger64i_v(GLenumtarget, GLuintindex, GLint64 *data);

PARÁMETROS

pname

Especifica el valor del parámetro que se devolverá para las versiones no indexadas de glGet. Se aceptan las constantes simbólicas de la lista siguiente.

target

Especifica el valor del parámetro que se devolverá para las versiones indexadas de glGet. Se aceptan las constantes simbólicas de la lista siguiente.

index

Especifica el índice del elemento particular que se está consultando.

data

Devuelve el valor o valores del parámetro especificado.

DESCRIPCIÓN

Estos comandos devuelven valores para variables de estado simples en GL. pname es una constante simbólica que indica la variable de estado que se devolverá, y data es un puntero a un array del tipo indicado en el cual colocar los datos devueltos.

Se realiza una conversión de tipo si data tiene un tipo diferente al del valor de la variable de estado que se solicita. Si se llama a glGetBooleanv , un valor de punto flotante (o entero) se convierte en GL_FALSE si y solo si es 0.0 (o 0). De lo contrario, se convierte en GL_TRUE. Si se llama a glGetIntegerv , los valores booleanos se devuelven como GL_TRUE o GL_FALSE, y la mayoría de los valores de punto flotante se redondean al valor entero más cercano. Sin embargo, los colores y normales de punto flotante se devuelven con un mapeo lineal que asigna 1.0 al valor entero representable más positivo y -1.0 al valor entero representable más negativo. Si se llama a glGetFloatv o glGetDoublev , los valores booleanos se devuelven como GL_TRUE o GL_FALSE, y los valores enteros se convierten en valores de punto flotante.

Las siguientes constantes simbólicas son aceptadas por pname:

GL_ACTIVE_TEXTURE

data devuelve un solo valor que indica la unidad de multitextura activa. El valor inicial es GL_TEXTURE0. Ver glActiveTexture().

GL_ALIASED_LINE_WIDTH_RANGE

data devuelve un par de valores que indica el rango de anchos soportados para líneas aliasadas. Ver glLineWidth().

GL_ARRAY_BUFFER_BINDING

data devuelve un solo valor, el nombre del objeto buffer actualmente enlazado al objetivo GL_ARRAY_BUFFER. Si no hay ningún objeto buffer enlazado a este objetivo, se devuelve 0. El valor inicial es 0. Ver glBindBuffer().

GL_BLEND

data devuelve un solo valor booleano que indica si el blending está habilitado. El valor inicial es GL_FALSE. Ver glBlendFunc().

GL_BLEND_COLOR

data devuelve cuatro valores, los valores rojo, verde, azul y alfa que son los componentes del color de blending. Ver glBlendColor().

GL_BLEND_DST_ALPHA

data devuelve un valor, la constante simbólica que identifica la función de blending de destino alfa. El valor inicial es GL_ZERO. Ver glBlendFunc() y glBlendFuncSeparate().

GL_BLEND_DST_RGB

data devuelve un valor, la constante simbólica que identifica la función de blending de destino RGB. El valor inicial es GL_ZERO. Ver glBlendFunc() y glBlendFuncSeparate().

GL_BLEND_EQUATION_RGB

data devuelve un valor, una constante simbólica que indica si la ecuación de blending RGB es GL_FUNC_ADD, GL_FUNC_SUBTRACT, GL_FUNC_REVERSE_SUBTRACT, GL_MIN o GL_MAX. Ver glBlendEquationSeparate().

GL_BLEND_EQUATION_ALPHA

data devuelve un valor, una constante simbólica que indica si la ecuación de blending Alfa es GL_FUNC_ADD, GL_FUNC_SUBTRACT, GL_FUNC_REVERSE_SUBTRACT, GL_MIN o GL_MAX. Ver glBlendEquationSeparate().

GL_BLEND_SRC_ALPHA

data devuelve un valor, la constante simbólica que identifica la función de blending de origen alfa. El valor inicial es GL_ONE. Ver glBlendFunc() y glBlendFuncSeparate().

GL_BLEND_SRC_RGB

data devuelve un valor, la constante simbólica que identifica la función de blending de origen RGB. El valor inicial es GL_ONE. Ver glBlendFunc() y glBlendFuncSeparate().

GL_COLOR_CLEAR_VALUE

data devuelve cuatro valores: los valores rojo, verde, azul y alfa usados para limpiar los buffers de color. Los valores enteros, si se solicitan, se mapean linealmente desde la representación interna de punto flotante de modo que 1.0 devuelve el valor entero representable más positivo, y -1.0 devuelve el valor entero representable más negativo. El valor inicial es (0, 0, 0, 0). Ver glClearColor().

GL_COLOR_LOGIC_OP

data devuelve un solo valor booleano que indica si los valores de color RGBA de un fragmento se fusionan en el framebuffer usando una operación lógica. El valor inicial es GL_FALSE. Ver glLogicOp().

GL_COLOR_WRITEMASK

data devuelve cuatro valores booleanos: las habilitaciones de escritura de rojo, verde, azul y alfa para los buffers de color. El valor inicial es (GL_TRUE, GL_TRUE, GL_TRUE, GL_TRUE). Ver glColorMask().

GL_COMPRESSED_TEXTURE_FORMATS

data devuelve una lista de constantes simbólicas de longitud GL_NUM_COMPRESSED_TEXTURE_FORMATS que indica qué formatos de textura comprimidos están disponibles. Ver glCompressedTexImage2D().

GL_MAX_COMPUTE_SHADER_STORAGE_BLOCKS

data devuelve un valor, el número máximo de bloques de almacenamiento de shaders activos a los que puede acceder un shader de cómputo.

GL_MAX_COMBINED_SHADER_STORAGE_BLOCKS

data devuelve un valor, el número total máximo de bloques de almacenamiento de shaders activos a los que pueden acceder todos los shaders activos.

GL_MAX_COMPUTE_UNIFORM_BLOCKS

data devuelve un valor, el número máximo de bloques uniformes por shader de cómputo. El valor debe ser al menos 14. Ver glUniformBlockBinding().

GL_MAX_COMPUTE_TEXTURE_IMAGE_UNITS

data devuelve un valor, el número máximo de unidades de imagen de textura soportadas que pueden usarse para acceder a mapas de textura desde el shader de cómputo. El valor debe ser al menos 16. Ver glActiveTexture().

GL_MAX_COMPUTE_UNIFORM_COMPONENTS

data devuelve un valor, el número máximo de valores individuales de punto flotante, enteros o booleanos que pueden almacenarse en variables uniformes para un shader de cómputo. El valor debe ser al menos 1024. Ver glUniform().

GL_MAX_COMPUTE_ATOMIC_COUNTERS

data devuelve un valor, el número máximo de contadores atómicos disponibles para shaders de cómputo.

GL_MAX_COMPUTE_ATOMIC_COUNTER_BUFFERS

data devuelve un valor, el número máximo def contadores atómicos que pueden ser accedidos por un sombreador de cómputo.

GL_MAX_COMBINED_COMPUTE_UNIFORM_COMPONENTS

data devuelve un valor, el número de palabras para variables uniformes de sombreadores de cómputo en todos los bloques uniformes (incluido el predeterminado). El valor debe ser al menos 1. Consulte glUniform().

GL_MAX_COMPUTE_WORK_GROUP_INVOCATIONS

data devuelve un valor, el número de invocaciones en un único grupo de trabajo local (es decir, el producto de las tres dimensiones) que se pueden enviar a un sombreador de cómputo.

GL_MAX_COMPUTE_WORK_GROUP_COUNT

Aceptado por las versiones indexadas de glGet. data el número máximo de grupos de trabajo que se pueden enviar a un sombreador de cómputo. Los índices 0, 1 y 2 corresponden a las dimensiones X, Y y Z, respectivamente.

GL_MAX_COMPUTE_WORK_GROUP_SIZE

Aceptado por las versiones indexadas de glGet. data el tamaño máximo de un grupo de trabajo que se puede usar durante la compilación de un sombreador de cómputo. Los índices 0, 1 y 2 corresponden a las dimensiones X, Y y Z, respectivamente.

GL_DISPATCH_INDIRECT_BUFFER_BINDING

data devuelve un único valor, el nombre del objeto de búfer actualmente enlazado al destino GL_DISPATCH_INDIRECT_BUFFER. Si ningún objeto de búfer está enlazado a este destino, se devuelve 0. El valor inicial es 0. Consulte glBindBuffer().

GL_MAX_DEBUG_GROUP_STACK_DEPTH

data devuelve un único valor, la profundidad máxima de la pila de grupos de mensajes de depuración.

GL_DEBUG_GROUP_STACK_DEPTH

data devuelve un único valor, la profundidad actual de la pila de grupos de mensajes de depuración.

GL_CONTEXT_FLAGS

data devuelve un valor, las banderas con las que se creó el contexto (como la funcionalidad de depuración).

GL_CULL_FACE

data devuelve un único valor booleano que indica si la eliminación de polígonos está habilitada. El valor inicial es GL_FALSE. Consulte glCullFace().

GL_CULL_FACE_MODE

data devuelve un único valor que indica el modo de eliminación de polígonos. El valor inicial es GL_BACK. Consulte glCullFace().

GL_CURRENT_PROGRAM

data devuelve un valor, el nombre del objeto de programa que está activo actualmente, o 0 si no hay ningún objeto de programa activo. Consulte glUseProgram().

GL_DEPTH_CLEAR_VALUE

data devuelve un valor, el valor que se utiliza para limpiar el búfer de profundidad. Los valores enteros, si se solicitan, se mapean linealmente desde la representación interna de punto flotante de manera que 1.0 devuelve el valor entero representable más positivo, y -1.0 devuelve el valor entero representable más negativo. El valor inicial es 1. Consulte glClearDepth().

GL_DEPTH_FUNC

data devuelve un valor, la constante simbólica que indica la función de comparación de profundidad. El valor inicial es GL_LESS. Consulte glDepthFunc().

GL_DEPTH_RANGE

data devuelve dos valores: los límites de mapeo cercano y lejano para el búfer de profundidad. Los valores enteros, si se solicitan, se mapean linealmente desde la representación interna de punto flotante de manera que 1.0 devuelve el valor entero representable más positivo, y -1.0 devuelve el valor entero representable más negativo. El valor inicial es (0, 1). Consulte glDepthRange().

GL_DEPTH_TEST

data devuelve un único valor booleano que indica si la prueba de profundidad de fragmentos está habilitada. El valor inicial es GL_FALSE. Consulte glDepthFunc() y glDepthRange().

GL_DEPTH_WRITEMASK

data devuelve un único valor booleano que indica si el búfer de profundidad está habilitado para escritura. El valor inicial es GL_TRUE. Consulte glDepthMask().

GL_DITHER

data devuelve un único valor booleano que indica si el difuminado de colores e índices de fragmentos está habilitado. El valor inicial es GL_TRUE.

GL_DOUBLEBUFFER

data devuelve un único valor booleano que indica si se admite el doble búfer.

GL_DRAW_BUFFER

data devuelve un valor, una constante simbólica que indica a qué búferes se está dibujando. Consulte glDrawBuffer(). El valor inicial es GL_BACK si hay búferes traseros, de lo contrario es GL_FRONT.

GL_DRAW_BUFFERi

data devuelve un valor, una constante simbólica que indica a qué búferes se está dibujando para el color de salida correspondiente. Consulte glDrawBuffers(). El valor inicial de GL_DRAW_BUFFER0 es GL_BACK si hay búferes traseros, de lo contrario es GL_FRONT. Los valores iniciales de los búferes de dibujo para todos los demás colores de salida son GL_NONE.

GL_DRAW_FRAMEBUFFER_BINDING

data devuelve un valor, el nombre del objeto de búfer de fotogramas actualmente enlazado al destino GL_DRAW_FRAMEBUFFER. Si el búfer de fotogramas predeterminado está enlazado, este valor será cero. El valor inicial es cero. Consulte glBindFramebuffer().

GL_READ_FRAMEBUFFER_BINDING

data devuelve un valor, el nombre del objeto de búfer de fotogramas actualmente enlazado al destino GL_READ_FRAMEBUFFER. Si el búfer de fotogramas predeterminado está enlazado, este valor será cero. El valor inicial es cero. Consulte glBindFramebuffer().

GL_ELEMENT_ARRAY_BUFFER_BINDING

data devuelve un único valor, el nombre del objeto de búfer actualmente enlazado al destino GL_ELEMENT_ARRAY_BUFFER. Si ningún objeto de búfer está enlazado a este destino, se devuelve 0. El valor inicial es 0. Consulte glBindBuffer().

GL_FRAGMENT_SHADER_DERIVATIVE_HINT

data devuelve un valor, una constante simbólica que indica el modo de la pista de precisión de derivadas para sombreadores de fragmentos. El valor inicial es GL_DONT_CARE. Consulte glHint().

GL_IMPLEMENTATION_COLOR_READ_FORMAT

data devuelve un único valor GLenum que indica el formato de datos de píxeles preferido de la implementación. Consulte glReadPixels().

GL_IMPLEMENTATION_COLOR_READ_TYPE

data devuelve un único valor GLenum que indica el tipo de datos de píxeles preferido de la implementación. Consulte glReadPixels().

GL_LINE_SMOOTH

data devuelve un único valor booleano que indica si el suavizado antialiasing de líneas está habilitado. El valor inicial es GL_FALSE. Consulte glLineWidth().

GL_LINE_SMOOTH_HINT

data devuelve un valor, una constante simbólica que indica el modo de la pista de antialiasing de líneas. El valor inicial es GL_DONT_CARE. Consulte glHint().

GL_LINE_WIDTH

data devuelve un valor, el ancho de línea especificado con glLineWidth(). El valor inicial es 1.

GL_LAYER_PROVOKING_VERTEX

data devuelve un valor, el vértice específico de una primitiva dependiente de la implementación que se utiliza para seleccionar la capa de renderizado. Si el valor devuelto es equivalente a GL_PROVOKING_VERTEX, la selección de vértice sigue la convención especificada por glProvokingVertex(). Si el valor devuelto es equivalente a GL_FIRST_VERTEX_CONVENTION, la selección se toma siempre del primer vértice de la primitiva. Si el valor devuelto es equivalente a GL_LAST_VERTEX_CONVENTION, la selección se toma siempre del último vértice de la primitiva. Si el valor devuelto es equivalente a GL_UNDEFINED_VERTEX, la selección no está garantizada que se tome de ningún vértice específico de la primitiva.

GL_LOGIC_OP_MODE

data devuelve un valor, una constante simbólica que indica el modo de operación lógica seleccionado. El valor inicial es GL_COPY. Consulte glLogicOp().

GL_MAJOR_VERSION

GL_MAX_COMBINED_ATOMIC_COUNTERS

data devuelve un único valor, el número máximo de contadores atómicos disponibles para todos los sombreadores activos.

GL_MAX_COMBINED_FRAGMENT_UNIFORM_COMPONENTS

glGet - return parameters of current OpenGL state

C FUNCTION

void glGet( GLenum pname, GLenum type, GLvoid *data );

void glGetBooleanv( GLenum pname, GLboolean *data );

void glGetDoublev( GLenum pname, GLdouble *data );

void glGetFloatv( GLenum pname, GLfloat *data );

void glGetFloati_v( GLenum target, GLuint index, GLfloat *data );

void glGetDoublei_v( GLenum target, GLuint index, GLdouble *data );

void glGetInteger64i_v( GLenum target, GLuint index, GLint64 *data );

PARAMETERS

pname
Specifies the query. See "Parameters" in glGet.
type
Specifies the data type of the value being returned. Must be one of GL_BYTE, GL_UNSIGNED_BYTE, GL_SHORT, GL_UNSIGNED_SHORT, GL_INT, GL_UNSIGNED_INT, GL_INT_64, GL_FLOAT, GL_FALSE, GL_TRUE.
data
Returns the requested data.
target
Specifies the buffer binding target. Must be one of GL_TRANSFORM_FEEDBACK_BUFFER, GL_UNIFORM_BUFFER.
index
Specifies the index of the buffer binding.

DESCRIPTION

glGet returns the value or values of a specified GL parameter. The symbolic constant pname specifies the parameter to be returned. The parameters are grouped into the following categories:

Texture parameters
GL_MAX_TEXTURE_SIZE, GL_MAX_ARRAY_TEXTURE_LAYERS, GL_MAX_CUBE_MAP_TEXTURE_SIZE, GL_MAX_TEXTURE_ LOD_BIAS, GL_MAX_3D_TEXTURE_SIZE.
Query objects
GL_CURRENT_QUERY.
Buffer object binding
GL_TRANSFORM_FEEDBACK_BUFFER_BINDING, GL_UNIFORM_BUFFER_BINDING.
Texture binding
GL_TEXTURE_BINDING_1D, GL_TEXTURE_BINDING_2D, GL_TEXTURE_BINDING_2D_ARRAY, GL_TEXTURE_BINDING_3D, GL_TEXTURE_BINDING_CUBE_MAP.
Framebuffer parameters
GL_MAX_FRAMEBUFFER_WIDTH, GL_MAX_FRAMEBUFFER_HEIGHT, GL_MAX_FRAMEBUFFER_LAYERS, GL_MAX_FRAMEBUFFER_SAMPLES.
Viewport and scissor parameters
GL_VIEWPORT, GL_SCISSOR_BOX, GL_VIEWPORT_SUBPIXEL_BITS, GL_VIEWPORT_BOUNDS_RANGE, GL_VIEWPORT_INDEX_PROVOKING_VERTEX.
Vertex array object parameters
GL_VERTEX_ARRAY_BINDING.
Vertex buffer binding parameters
GL_VERTEX_BINDING_BUFFER, GL_VERTEX_BINDING_OFFSET, GL_VERTEX_BINDING_STRIDE, GL_VERTEX_BINDING_DIVISOR.
Compute shader parameters
GL_MAX_COMPUTE_WORK_GROUP_INVOCATIONS, GL_MAX_COMPUTE_WORK_GROUP_COUNT, GL_MAX_COMPUTE_WORK_GROUP_SIZE.
Transform feedback parameters
GL_TRANSFORM_FEEDBACK_BUFFER_START, GL_TRANSFORM_FEEDBACK_BUFFER_SIZE.
Uniform buffer parameters
GL_UNIFORM_BUFFER_SIZE, GL_UNIFORM_BUFFER_START, GL_UNIFORM_BUFFER_OFFSET_ALIGNMENT.
Pixel storage parameters
GL_UNPACK_ALIGNMENT, GL_UNPACK_ROW_LENGTH, GL_UNPACK_SKIP_ROWS, GL_UNPACK_SKIP_PIXELS, GL_UNPACK_SWAP_BYTES, GL_UNPACK_LSB_FIRST, GL_UNPACK_IMAGE_HEIGHT, GL_UNPACK_SKIP_IMAGES.

The various `glGet*v` functions retrieve the same parameters as `glGet`, but they take a pointer to a variable of the appropriate type to store the result. This avoids the need to cast the pointer to `GLvoid *` and to know the type of the parameter in advance.

The `gl*i_v` functions retrieve parameters associated with an indexed target. For example, GL_TRANSFORM_FEEDBACK_BUFFER and GL_UNIFORM_BUFFER are indexed targets. The index parameter specifies which binding point to query.

The specific parameters are:

GL_ACTIVE_TEXTURE

Returns the index of the currently active texture unit. The initial value is 0.

GL_ALPHA_BITS

Returns the number of bits used for the alpha component of the color buffer. The initial value depends on the capabilities of the implementation.

GL_BLEND

Returns a single boolean value indicating whether blending is enabled. Initially GL_FALSE.

GL_BLEND_COLOR

Returns four values: R, G, B, A, the red, green, blue, and alpha values of the blend color. Initially 0, 0, 0, 0.

GL_BLEND_DST_ALPHA

Returns one value, the source blend factor for the alpha term. See glBlendFunc().

GL_BLEND_DST_RGB

Returns one value, the source blend factor for the RGB term. See glBlendFunc().
