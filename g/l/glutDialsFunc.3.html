glutDialsFunc(3) freeglut glutDialsFunc(3)

NOMBRE

glutDialsFunc - establece la función de callback de diales de diales y botones para la ventana actual.

SINTAXIS

void glutDialsFunc(void (*func)(int dial, int value));

ARGUMENTOS

func
La nueva función de callback de diales.

DESCRIPCIÓN

glutDialsFunc establece la función de callback de diales de diales y botones para la ventana actual. La función de callback de diales de diales y botones para una ventana se llama cuando la ventana tiene el foco de entrada de diales y botones (normalmente, cuando el ratón está en la ventana) y el usuario genera cambios en los diales de diales y botones. El parámetro dial será el número del dial (empezando por uno). El número de diales de diales y botones disponibles se puede determinar con glutDeviceGet(GLUT_NUM_DIALS). El valor mide la rotación absoluta en grados. Los valores de los diales no se "reinician" con cada rotación completa, sino que continúan acumulando grados (hasta que el valor entero del dial se desborde).

Registrar una función de callback de diales de diales y botones cuando un dispositivo de diales y botones no está disponible es ineficaz y no es un error. En este caso, no se generarán funciones de callback de diales de diales y botones.

Pasar NULL a glutDialsFunc deshabilita la generación de funciones de callback de diales de diales y botones. Cuando se crea una nueva ventana, inicialmente no se registra ninguna función de callback de diales de diales y botones.

VER TAMBIÉN

glutButtonBoxFunc, glutDeviceGet
