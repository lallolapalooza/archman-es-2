GLANCES(1) Glances GLANCES(1)

NOMBRE

glances - un vistazo a tu sistema

SINOPSIS

glances [OPCIONES]

DESCRIPCIÓN

glances es una herramienta de monitoreo basada en curses multiplataforma que tiene como objetivo presentar la máxima información en el mínimo espacio, idealmente cabiendo en un terminal clásico de 80x24 o más grande para más detalles. Puede adaptarse dinámicamente a la información mostrada dependiendo del tamaño del terminal. También puede funcionar en modo cliente/servidor. El monitoreo remoto se puede realizar a través de una interfaz de terminal o web.

glances está escrito en Python y utiliza la biblioteca psutil para obtener información de tu sistema.

SINTAXIS

Glances lee los archivos de configuración en la sintaxis ini

.

Hay disponible una primera sección (llamada global):

y una segunda sección relativa a la interfaz de usuario:

[outputs]
# Opciones para todas las interfaces de usuario
#--------------------
# Separador en las interfaces Curses y WebUI (entre el plugin superior y los demás)
separator=True
# Establece la lista de plugins del menú izquierdo de las interfaces Curses y WebUI (separada por comas)
#left_menu=network,wifi,connections,ports,diskio,fs,irq,folders,raid,smart,sensors,now
# Limita el número de procesos a mostrar (en la WebUI)
max_processes_display=25
# Opciones para la WebUI
#------------------
# Establece el prefijo de URL para la WebUI y la API
# Ejemplo: url_prefix=/glances/ => http://localhost/glances/
# Nota: La barra final / es obligatoria
# Por defecto no hay prefijo (/)
#url_prefix=/glances/
# Establece la ruta raíz para los archivos estáticos de la WebUI
# ¿Por qué? En sistemas Debian, los archivos estáticos de la WebUI no se incluyen.
# Puedes descargarlos en una carpeta específica
# gracias a https://github.com/nicolargo/glances/issues/2021
# y luego configurar esta carpeta con la clave webui_root_path
# Por defecto es la carpeta donde se aloja glances_restful_api.py
#webui_root_path=
# Opciones CORS
# Lista separada por comas de orígenes que deben permitirse para realizar solicitudes de origen cruzado.
# Por defecto es *
#cors_origins=*
# Indica que se deben admitir cookies para solicitudes de origen cruzado.
# Por defecto es True
#cors_credentials=True
# Lista separada por comas de métodos HTTP que deben permitirse para solicitudes de origen cruzado.
# Por defecto es *
#cors_methods=*
# Lista separada por comas de cabeceras de solicitud HTTP que deben admitirse para solicitudes de origen cruzado.
# Por defecto es *
#cors_headers=*

Con Glances 3.0 o superior, puedes usar valores de configuración dinámicos utilizando comandos del sistema. Por ejemplo, si quieres establecer el prefijo de una exportación de InfluxDB al nombre de host actual, usa:

[influxdb]
...
prefix=`hostname`

O si quieres añadir el nombre del sistema operativo como etiqueta:

[influxdb]
...
tags=system:`uname -a`

REGISTRO

Glances registra todos sus mensajes internos en un archivo de registro.

Los mensajes de DEBUG se pueden registrar usando la opción -d

en la línea de comandos. La ubicación del archivo de registro de Glances depende de tu sistema operativo. Puedes mostrar la ruta completa del archivo de registro de Glances usando el comando glances -V

.

El archivo se rota automáticamente cuando su tamaño supera los 1 MB. Si quieres usar otra ruta del sistema o cambiar el mensaje de registro, puedes usar tu configuración de logger. Primero, tienes que crear un archivo glances.json

con, por ejemplo, el siguiente contenido (formato
    JSON):

y iniciar Glances usando la siguiente línea de comandos:

LOG_CFG=<path>/glances.json glances

NOTA:

Reemplaza <path> con el directorio donde se aloja tu archivo glances.json .

EJEMPLOS

Monitorizar la máquina local, también llamada modo independiente, con la interfaz de usuario basada en texto (TUI):

$ glances

Para monitorizar la máquina local con la interfaz de usuario web (WebUI), , ejecuta la siguiente línea de comandos:

$ glances -w

luego, abre un navegador web en la URL proporcionada.

Monitorizar la máquina local y exportar estadísticas a un archivo CSV:

$ glances –export csv –export-csv-file /tmp/glances.csv

Monitorizar la máquina local y exportar estadísticas a un servidor InfluxDB con un tiempo de actualización de 5s (también es posible exportar a OpenTSDB, Cassandra, Statsd, ElasticSearch, RabbitMQ y Riemann):

$ glances -t 5 –export influxdb

También es posible exportar estadísticas a múltiples destinos:

$ glances -t 5 –export influxdb,statsd,csv

Iniciar un servidor Glances (modo servidor):

$ glances -s

Conectar Glances a un servidor Glances (modo cliente):

$ glances -c <ip_server>

Conectar a un servidor Glances y exportar estadísticas a un servidor StatsD:

$ glances -c <ip_server> –export statsd

Iniciar el Explorador Central de Glances TUI:

$ glances –browser

Iniciar el Explorador Central de Glances WebUI (nuevo en Glances 4.3 o superior):

$ glances –browser -w

Si no quieres ver el Servidor Web Glances local en la lista del navegador, usa la opción –disable-autodiscover.
