GLOBAL(1) Manual de comandos generales GLOBAL(1)

NOMBRE

global - imprime ubicaciones de símbolos dados

SINOPSIS

global [-adEFGilMnNqrstvx][-S dir][-e] patrón
global -c[dFiIMoOPqrsTv] prefijo
global -f[adlnqrstvx][-L lista-archivos][-S dir] archivos
global -g[aEGilMnoOqtvVx][-L lista-archivos][-S dir][-e] patrón [archivos]
global -I[ailMnqtvx][-S dir][-e] patrón
global -P[aEGilMnoOqtvVx][-S dir][-e] patrón
global -p[qrv]
global -u[qv]

DESCRIPCIÓN

Global encuentra ubicaciones de símbolos dados en archivos fuente C, Yacc, Java, PHP y ensamblador, e imprime el nombre del archivo, el número de línea y la línea de las ubicaciones. Global puede localizar no solo definiciones sino también referencias y otros símbolos.

Global puede tratar un árbol de fuentes, es decir, un directorio que tiene subdirectorios y archivos fuente, como un proyecto. Antes de usar este comando, debes ejecutar gtags(1) en el directorio raíz del proyecto que deseas investigar para crear archivos de etiquetas. Luego puedes usar el comando global en cualquier lugar del proyecto. No necesitas especificar dónde está el archivo de etiquetas. En cambio, global lo localiza por sí mismo.

Puedes especificar una expresión regular para patrón. Global entiende dos versiones diferentes de sintaxis de expresiones regulares: básica y extendida (predeterminada).

COMANDOS

Los siguientes comandos están disponibles:

<sin comando> patrón
Sin comando significa comando de búsqueda de etiquetas. Imprime etiquetas que coinciden con patrón. Por defecto, imprime etiquetas de definición.
-c, --completion[=límite] [prefijo]
Imprime símbolos que comienzan con prefijo. Si no se proporciona prefijo, imprime todos los símbolos. Si se proporciona límite, imprime hasta el límite de líneas.
-f, --file archivos
Imprime todas las etiquetas en los archivos. Este comando implica la opción -x.
-g, --grep patrón [archivos]
Imprime todas las líneas que coinciden con el patrón. Si se proporcionan archivos, este comando busca en esos archivos.
--help
Imprime un mensaje de uso.
-I, --idutils patrón
Imprime todas las líneas que coinciden con patrón. Esta función utiliza idutils(1) como motor de búsqueda. Para usar este comando, necesitas instalar idutils(1) en tu sistema y ejecutar gtags(1) con la opción -I.
-P, --path [patrón]
Imprime nombres de rutas que coinciden con patrón. Si no se proporciona patrón, imprime todas las rutas en el proyecto.
-p, --print-dbpath
Imprime la ubicación de 'GTAGS'.
--print nombre
Imprime la ubicación de nombre, que puede ser uno de: 'root', 'dbpath' o 'conf'. 'root' significa el directorio raíz del proyecto. 'dbpath' significa un directorio donde existen bases de datos de etiquetas. 'conf' significa archivo de configuración.
-u, --update
Actualiza archivos de etiquetas de forma incremental. Este comando invoca internamente gtags(1). Puedes ejecutar este comando en cualquier lugar del proyecto, a diferencia de gtags(1).
--version
Muestra el número de versión.

OPCIONES

Las siguientes opciones están disponibles:

-a, --absolute
Imprime nombres de ruta absolutos. Por defecto, imprime nombres de ruta relativos.
--color cuándo
Usa color para resaltar el patrón dentro de la línea; cuándo puede ser uno de: nunca, siempre o auto (predeterminado). El color predeterminado es texto rojo en negrita sobre el fondo actual; la variable de entorno GREP_COLORS (solo mt y ms son efectivas en la actualidad) o GREP_COLOR la define. Esta opción es efectiva para los siguientes comandos: <sin comando>, -f, -g, -I, -P.
-C, --directory dir
Cambia el directorio antes de realizar todo el trabajo, incluido el análisis de parámetros.
-d, --definition
Imprime ubicaciones de definiciones.
-e, --regexp patrón
Usa patrón como el patrón; útil para proteger patrones que comienzan con '-'.
-E, --extended-regexp
Interpreta patrón como una expresión regular extendida. Esta es la predeterminada.
--encode-path caracteres
Convierte caracteres de ruta en caracteres en un símbolo '%' seguido de la representación hexadecimal de dos dígitos del carácter. Un espacio se convertirá en '%20'.
-F, --first-match
Finaliza la búsqueda sin recorrer todos los archivos de etiquetas listados en GTAGSLIBPATH cuando se encuentran etiquetas en un archivo de etiquetas. Esta es la predeterminada.
--from-here contexto
Decide el tipo de etiqueta por contexto. Su sintaxis debe ser 'lineno:path'. Si el contexto es una definición del patrón, usa -r; de lo contrario, si hay al menos una definición del patrón, usa -d; de lo contrario, usa -s. Si se especifica esta opción, se ignoran -d, -r y -s en la línea de comandos. La expresión regular no está permitida para patrón. Esta opción asume el uso en entornos conversacionales como editores y IDEs.
-G, --basic-regexp
Interpreta patrón como una expresión regular básica. La predeterminada es una expresión regular extendida.
--gtagsconf archivo
Establece la variable de entorno GTAGSCONF a archivo.
--gtagslabel etiqueta
Establece la variable de entorno GTAGSLABEL a etiqueta.
-i, --ignore-case
Ignora las distinciones de mayúsculas y minúsculas en el patrón.
-L, --file-list archivo
Obtiene archivos de archivo además de los argumentos. El argumento archivo puede establecerse a '-' para aceptar una lista de archivos de la entrada estándar. Los nombres de archivo deben estar separados por saltos de línea.
-l, --local
Imprime solo las etiquetas que existen en el directorio actual.
--literal
Ejecuta búsqueda literal en lugar de búsqueda de expresiones regulares. Esta opción funciona con el comando de búsqueda de etiquetas, el comando -g, el comando -P y el comando -I.
-M, --match-case
La búsqueda distingue entre mayúsculas y minúsculas. Esta es la predeterminada.
--match-part parte
Especifica cómo debe coincidir la finalización del nombre de ruta, donde parte es uno de: 'first', 'last' o 'all' (predeterminado). Esta opción solo es válida con el comando -c en conjunción con -P.
-n, --nofilter
Suprime el filtro de ordenación y el filtro de conversión de ruta.
-N, --nearness[=inicio]
Utiliza el método de ordenación Nearness (ordenación por el más cercano desde inicio) para la salida. Por predeterminad
ult, se utiliza el método de ordenación alfabética. Esta opción es efectiva para el comando de búsqueda de etiquetas, el comando -P y el comando -g. Como excepción, el comando -g ignora esta opción cuando los archivos se especifican mediante argumentos. La cercanía se define por cuántos directorios padre se deben subir para alcanzar el objetivo. El resultado de la ordenación por cercanía es la concatenación de los siguientes ([0]-[n]) en este orden. El valor predeterminado de start es el directorio actual. 
[0] Si el inicio es un archivo, salida de la búsqueda local en el archivo.
[1] Salida de la búsqueda local en el directorio de inicio, excepto [0].
[2] Salida de la búsqueda local en el directorio padre, excepto [0]-[1].
[3] Salida de la búsqueda local en el directorio abuelo, excepto [0]-[2].
... (repetir hasta el directorio raíz del proyecto)
[n] Salida de la búsqueda local en el directorio raíz del proyecto, excepto [0]-[n-1].
En cada directorio, se ordenan alfabéticamente.
-O, --only-other
Tratar solo archivos de texto que no sean código fuente, como ´README´. Esta opción solo es válida con el comando -g o -P. Esta opción anula la opción -o.
-o, --other
Tratar no solo archivos fuente sino también archivos de texto que no sean código fuente, como ´README´. Esta opción solo es válida con el comando -g o -P.
--path-style formato
Imprimir nombres de ruta utilizando formato, que puede ser uno de: ´relative´, ´absolute´, ´shorter´, ´abslib´ o ´through´. ´relative´ significa ruta relativa. ´absolute´ significa ruta absoluta. ´shorter´ significa la más corta entre la relativa y la absoluta. ´abslib´ significa ruta absoluta para bibliotecas (GTAGSLIBPATH) y ruta relativa para el resto. ´through´ significa la ruta relativa desde el directorio raíz del proyecto (formato interno de GPATH). El predeterminado es ´relative´. La opción --path-style tiene más prioridad que la opción -a.
--print0
Imprimir cada registro seguido de un carácter nulo en lugar de una nueva línea.
-q, --quiet
Modo silencioso.
-r, --reference, --rootdir
Imprimir etiquetas de referencia. Referencia significa la referencia a un símbolo que tiene definiciones. Con la opción -p, imprimir el directorio raíz del proyecto.
--result formato
Imprimir usando formato, que puede ser uno de: ´path´ (predeterminado), ´ctags´, ´ctags-x´, ´grep´ o ´cscope´. Las opciones --result=ctags y --result=ctags-x son equivalentes a las opciones -t y -x respectivamente. La opción --result tiene más prioridad que las opciones -t y -x.
--single-update archivo
Actualizar archivos de etiquetas usando gtags(1) con la opción --single-update. Se considera que archivo fue agregado, actualizado o eliminado, y no hay cambios en otros archivos. Esta opción implica la opción -u.
-s, --symbol
Imprimir otras etiquetas de símbolos. Otro símbolo significa la referencia a un símbolo que no tiene definición.
-S, --scope dir
Imprimir solo etiquetas que existen bajo el directorio dir. Es similar a la opción -l, pero no necesita cambiar de directorio.
-T, --through
Recorrer todos los archivos de etiquetas listados en GTAGSLIBPATH. Por defecto, deja de buscar cuando se encuentra una etiqueta. Esta opción se ignora cuando se especifica la opción -s, -r o -l.
-t, --tags
Usar el formato estándar de ctags.
-V, --invert-match
Invertir el sentido de la coincidencia, para seleccionar líneas no coincidentes. Esta opción es válida solo con los comandos -g o -P.
-v, --verbose
Modo detallado.
-x, --cxref
Usar el formato estándar de ctags cxref (con -x).

EJEMPLOS

$ ls -F
Makefile      src/    lib/
$ gtags
$ ls G*
GPATH   GRTAGS  GTAGS
$ global main
src/main.c
$ (cd src; global main)
main.c
$ global -x main
main              10 src/main.c  main (argc, argv) {
$ global -f src/main.c
main              10 src/main.c  main (argc, argv) {
func1             55 src/main.c  func1() {
func2             72 src/main.c  func2() {
func3            120 src/main.c  func3() {
$ global -x '^[sg]et'
set_num           20 lib/util.c  set_num(values) {
get_num           30 lib/util.c  get_num() {
$ global -rx set_num
set_num          113 src/op.c            set_num(32);
set_num          225 src/opop.c               if (set_num(0) > 0) {
$ global strlen
$ (cd /usr/src/sys; gtags)
$ export GTAGSLIBPATH=/usr/src/sys
$ global -a strlen
/usr/src/sys/libkern/strlen.c
$ (cd /usr/src/lib; gtags)
$ GTAGSLIBPATH=/usr/src/lib:/usr/src/sys
$ global -a strlen
/usr/src/lib/libc/string/strlen.c

ARCHIVOS

´GTAGS´
Archivo de etiquetas para definiciones.
´GRTAGS´
Archivo de etiquetas para referencias.
´GPATH´
Archivo de etiquetas para archivos fuente.
´GTAGSROOT´
Si la variable de entorno GTAGSROOT no está establecida y el archivo ´GTAGSROOT´ existe en el mismo directorio que ´GTAGS´, entonces global establece GTAGSROOT al contenido del archivo.
´gtags.conf´, ´$HOME/.globalrc´
Datos de configuración para GNU Global. Ver gtags.conf(5).

ENTORNO

Las siguientes variables de entorno afectan la ejecución de global:

GREP_COLOR
El color a usar para --color; GREP_COLORS tiene precedencia.
GREP_COLORS
El color (mt o ms) a usar para --color; ver grep(1).
GTAGSBLANKENCODE
Si esta variable está establecida, se especifica la opción --encode-path=" <TAB>".
GTAGSCACHE
El tamaño de la caché del árbol B. El valor predeterminado es 50000000 (bytes).
GTAGSCONF
Archivo de configuración.
GTAGSDBPATH
El directorio en el que existen los archivos de etiquetas. Este valor se ignora cuando GTAGSROOT no está definido. No se recomienda el uso de esta variable.
GTAGSFORCECPP
Si esta variable está establecida, cada archivo cuyo sufijo sea ´.h´ se trata como un archivo fuente de C++.
GTAGSLABEL
Etiqueta de configuración. El valor predeterminado es default.
GTAGSLIBPATH
Si esta variable está establecida, se usa como ruta para buscar funciones de biblioteca. Si el símbolo dado no se encuentra en el proyecto actual, global también busca en estas rutas. Dado que solo se apunta a ´GTAGS´ en la recuperación, esta variable se ignora cuando se especifican las opciones -r o -s.
GTAGSLOGGING
Si esta variable está establecida, ´$GTAGSLOGGING´ se usa como nombre de ruta de un archivo de registro. No hay valor predeterminado.
GTAGSROOT
El directorio raíz del proyecto. Por lo general, se reconoce por la existencia de ´GTAGS´. No se recomienda el uso de esta variable.
GTAGSTHROUGH
Si esta variable está establecida, se especifica la opción -T.
GTAGSOBJDIR, MAKEOBJDIR
Si alguna de las dos variables está establecida, se usa como nombre de objdir estilo BSD. La primera tiene prioridad. El valor predeterminado es ´obj´.
GTAGSOBJDIRPREFIX, MAKEOBJDIRPREFIX
Si alguna de las dos variables está establecida, se usa como prefijo de objdir estilo BSD. La primera tiene prioridad. El valor predeterminado es ´/usr/obj´.

CONFIGURACIÓN

Las siguientes variables de configuración afectan la ejecución de global:

icase_path (booleano)
Ignorar distinciones de mayúsculas y minúsculas en patrón.

DIAGNÓSTICO

Global sale con un valor distinto de 0 si ocurrió un error, 0 en caso contrario.

global - Un visor de código fuente y de referencias cruzadas

global Un visor de código fuente y de referencias cruzadas

NAME

global - Un visor de código fuente y de referencias cruzadas

SYNOPSIS

global [-aDeFghJkKlmOqsStvVwX?] [-c tag-file] [-f tag-file] [-i tag-file] [-L path] [-p port] [-r tag-file] [-T tag-file] [-u tag-file] [--compilations=tag-file] [--database=tag-file] [--defines=tag-file] [--display=tag-file] [--files=tag-file] [--fullpaths] [--help] [--images=tag-file] [--join=tag-file] [--skip=tag-file] [--tag-relative=tag-file] [--use-cc=tag-file] [--version] [--warn=tag-file] [--wildcards] pattern ...

DESCRIPTION

global es una utilidad que permite buscar referencias cruzadas a identificadores en un conjunto de archivos fuente. Está diseñado para ser utilizado con un archivo de etiquetas generado por gtags. Después de crear un archivo de etiquetas, puede invocar global para buscar una definición de etiqueta, una referencia de etiqueta o una lista de todos los archivos fuente en el proyecto.

COMMANDS

El comando global se utiliza típicamente con uno de los siguientes patrones:

  • /pattern/: Busca todas las ocurrencias de pattern.
  • ?pattern?: Busca todas las ocurrencias de pattern que sean identificadores.
  • @pattern@: Busca todas las definiciones de pattern.
  • #pattern#: Busca todos los archivos que contengan pattern.

Si no se especifica ningún patrón, global mostrará una lista de todos los archivos fuente en el proyecto.

OPTIONS

-a, --show-tag
Muestra las etiquetas que contienen el patrón dado.
-c, --compilations
Especifica un archivo de compilaciones para analizar.
-D, --defines
Busca definiciones de macros.
-e, --regex
Interpreta el patrón como una expresión regular.
-F, --fullpaths
Muestra las rutas completas de los archivos.
-g, --images
Busca etiquetas de imágenes.
-h, --help
Muestra un mensaje de ayuda y sale.
-i, --case-insensitive
Ignora mayúsculas y minúsculas en las búsquedas.
-J, --join
Une las salidas de varios archivos de etiquetas.
-k, --skip
Omite los archivos especificados en la búsqueda.
-L, --location
Muestra la ubicación de la etiqueta dada.
-l, --list-files
Muestra una lista de todos los archivos fuente en el proyecto.
-m, --warn
Muestra advertencias sobre archivos no encontrados.
-O, --tag-relative
Utiliza rutas relativas a los archivos de etiquetas.
-p, --port
Especifica el puerto para la conexión con el servidor de etiquetas.
-q, --quiet
Suprime los mensajes informativos.
-s, --no-symlinks
No sigue enlaces simbólicos.
-S, --use-cc
Utiliza el compilador C para buscar etiquetas.
-t, --show-definitions
Muestra las definiciones de las etiquetas que contienen el patrón dado.
-T, --tag-file
Especifica un archivo de etiquetas alternativo.
-v, --verbose
Muestra información detallada sobre las búsquedas.
-V, --version
Muestra la información de la versión y sale.
-w, --warn-file
Especifica un archivo para escribir las advertencias.
-X, --wildcards
Interpreta el patrón como comodines de shell.
-?
Muestra información de ayuda y sale.

EXAMPLES

Para buscar todas las referencias a la función `main` en el proyecto:

global /main/

Para buscar la definición de la variable `count`:

global @count@

Para listar todos los archivos fuente en el proyecto:

global -l

FILES

GTAGS
El archivo de etiquetas principal generado por gtags.

ENVIRONMENT

global utiliza las siguientes variables de entorno:

  • GTAGSLABEL: Especifica el nombre del archivo de etiquetas a utilizar. Por defecto, es GTAGS.
  • GTAGSCONF: Especifica el archivo de configuración de global.
  • GTAGSFORCECPP: Obliga a global a tratar todos los archivos como archivos C++.
  • GTAGSLIBPATH: Especifica una lista de directorios donde buscar archivos de etiquetas.
  • GTAGSOUTPUTWIDTH: Especifica el ancho de la salida de las líneas largas.

CONFIGURATION

La configuración de global se puede realizar a través de un archivo de configuración especificado por la variable de entorno GTAGSCONF, o mediante la línea de comandos.

DIAGNOSTICS

global informa de los errores a la salida de error estándar. Los errores comunes incluyen archivos de etiquetas no encontrados o patrones no coincidentes.
