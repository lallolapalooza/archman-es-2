GLCULLFACE(3G) [FIXME: manual] GLCULLFACE(3G)

NOMBRE

glCullFace - especifica si las facetas frontales o traseras pueden ser descartadas

C ESPECIFICACIÓN

void glCullFace(GLenum mode);

PARÁMETROS

mode

Especifica si las facetas frontales o traseras son candidatas para descarte. Se aceptan las constantes simbólicas GL_FRONT, GL_BACK y GL_FRONT_AND_BACK. El valor inicial es GL_BACK.

DESCRIPCIÓN

glCullFace especifica si las facetas frontales o traseras son descartadas (como se especifica en mode) cuando el descarte de facetas está habilitado. El descarte de facetas está inicialmente deshabilitado. Para habilitar y deshabilitar el descarte de facetas, llame a los comandos glEnable() y

glDisable con el argumento GL_CULL_FACE. Las facetas incluyen triángulos, cuadriláteros, polígonos y rectángulos.

glFrontFace() especifica cuáles facetas, de las horarias y antihorarias, son frontales y traseras. Ver glFrontFace().

NOTAS

Si mode es GL_FRONT_AND_BACK, no se dibujan facetas, pero se dibujan otras primitivas como puntos y líneas.

ERRORES

Se genera GL_INVALID_ENUM si mode no es un valor aceptado.

GETS ASOCIADOS

glIsEnabled() con argumento GL_CULL_FACE

glGet() con argumento GL_CULL_FACE_MODE
