GLCOMPRESSEDTEXSUBIM(3G) [FIXME: manual] GLCOMPRESSEDTEXSUBIM(3G)

NOMBRE

glCompressedTexSubImage2D, glCompressedTextureSubImage2D - especificar una subimagen de textura bidimensional en un formato comprimido

ESPECIFICACIÓN C

void glCompressedTexSubImage2D(GLenum target, GLint level, GLint xoffset, GLint yoffset, GLsizei width, GLsizei height, GLenum format, GLsizei imageSize, const void * data);

void glCompressedTextureSubImage2D(GLuint texture, GLint level, GLint xoffset, GLint yoffset, GLsizei width, GLsizei height, GLenum format, GLsizei imageSize, const void *data);

PARÁMETROS

target

Especifica el destino al que se vincula la textura para la función glCompressedTexSubImage2D. Debe ser GL_TEXTURE_1D_ARRAY, GL_TEXTURE_2D, GL_TEXTURE_CUBE_MAP_POSITIVE_X, GL_TEXTURE_CUBE_MAP_NEGATIVE_X, GL_TEXTURE_CUBE_MAP_POSITIVE_Y, GL_TEXTURE_CUBE_MAP_NEGATIVE_Y, GL_TEXTURE_CUBE_MAP_POSITIVE_Z, o GL_TEXTURE_CUBE_MAP_NEGATIVE_Z.

texture

Especifica el nombre del objeto de textura para la función glCompressedTextureSubImage2D.

level

Especifica el número de nivel de detalle. El nivel 0 es el nivel de imagen base. El nivel n es la n-ésima imagen de reducción mipmap.

xoffset

Especifica un desplazamiento de texel en la dirección x dentro de la matriz de texturas.

yoffset

Especifica un desplazamiento de texel en la dirección y dentro de la matriz de texturas.

width

Especifica el ancho de la subimagen de textura.

height

Especifica la altura de la subimagen de textura.

format

Especifica el formato de los datos de la imagen comprimida almacenados en la dirección data.

imageSize

Especifica el número de bytes sin signo de datos de imagen que comienzan en la dirección especificada por data.

data

Especifica un puntero a los datos de la imagen comprimida en memoria.

DESCRIPCIÓN

La texturización permite que los elementos de una matriz de imágenes sean leídos por los shaders.

glCompressedTexSubImage2D y glCompressedTextureSubImage2D redefinen una región contigua de una imagen de textura bidimensional existente. Los texels referenciados por data reemplazan la porción de la matriz de textura existente con índices x xoffset y xoffset + width - 1, e índices y yoffset y yoffset + height - 1, inclusive. Esta región no puede incluir ningún texel fuera del rango de la matriz de textura tal como se especificó originalmente. No es un error especificar una subtextura con un ancho de 0, pero tal especificación no tiene ningún efecto.

internalformat debe ser un formato de imagen comprimido conocido (como GL_RGTC) o un formato de textura comprimida especificado por una extensión. El format de la imagen de textura comprimida es seleccionado por la implementación de GL que la comprimió (ver glTexImage2D()) y debe ser consultado en el momento en que la textura fue comprimida con glGetTexLevelParameter().

Si un objeto de búfer con nombre y distinto de cero está vinculado al destino GL_PIXEL_UNPACK_BUFFER (ver glBindBuffer()) mientras se especifica una imagen de textura, data se trata como un desplazamiento de bytes en el almacén de datos del objeto de búfer.

ERRORES

Se genera GL_INVALID_ENUM si internalformat es de los formatos internos comprimidos genéricos: GL_COMPRESSED_RED, GL_COMPRESSED_RG, GL_COMPRESSED_RGB, GL_COMPRESSED_RGBA. GL_COMPRESSED_SRGB, o GL_COMPRESSED_SRGB_ALPHA.

GL_INVALID_ENUM es generado por glCompressedTexSubImage2D si target es GL_TEXTURE_RECTANGLE o GL_PROXY_TEXTURE_RECTANGLE.

Se genera GL_INVALID_VALUE si imageSize no es consistente con el formato, dimensiones y contenido de los datos de imagen comprimidos especificados.

Se genera GL_INVALID_OPERATION si las combinaciones de parámetros no son compatibles con el formato interno comprimido específico, según lo especificado en la extensión de compresión de texturas específica.

Se genera GL_INVALID_OPERATION si un objeto de búfer con nombre y distinto de cero está vinculado al destino GL_PIXEL_UNPACK_BUFFER y el almacén de datos del objeto de búfer está actualmente mapeado.

Se genera GL_INVALID_OPERATION si un objeto de búfer con nombre y distinto de cero está vinculado al destino GL_PIXEL_UNPACK_BUFFER y los datos se descomprimirían del objeto de búfer de tal manera que las lecturas de memoria requeridas excederían el tamaño del almacén de datos.

Se genera GL_INVALID_OPERATION por glCompressedTextureSubImage2D si texture no es el nombre de un objeto de textura existente.

Se genera GL_INVALID_OPERATION por glCompressedTextureSubImage2D si el destino efectivo es GL_TEXTURE_RECTANGLE.

Se generan resultados indefinidos, incluida la terminación anormal del programa, si data no está codificado de una manera consistente con la especificación de la extensión que define el formato de compresión interno.

GETS ASOCIADOS

glCompressedTexImage2D()

glGet() con argumento GL_TEXTURE_COMPRESSED

glGet() con argumento GL_PIXEL_UNPACK_BUFFER_BINDING

glGetTexLevelParameter() con argumentos GL_TEXTURE_INTERNAL_FORMAT y GL_TEXTURE_COMPRESSED_IMAGE_SIZE
