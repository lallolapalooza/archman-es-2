NOMBRE

glGetMultisamplefv - recuperar la ubicación de una muestra

ESPECIFICACIÓN C

void glGetMultisamplefv(GLenum pname, GLuint index, GLfloat *val);

PARÁMETROS

pname

Especifica el nombre del parámetro de la muestra. pname debe ser GL_SAMPLE_POSITION.

index

Especifica el índice de la muestra cuya posición se va a consultar.

val

Especifica la dirección de una matriz para recibir la posición de la muestra.

DESCRIPCIÓN

glGetMultisamplefv consulta la ubicación de una muestra dada. pname especifica el parámetro de la muestra a recuperar y debe ser GL_SAMPLE_POSITION. index corresponde a la muestra cuya ubicación se debe devolver. La ubicación de la muestra se devuelve como dos valores de punto flotante en val[0] y val[1], cada uno entre 0 y 1, correspondientes a las ubicaciones x e y respectivamente en el espacio de píxeles GL de esa muestra. (0.5, 0.5) corresponde al centro del píxel. index debe estar entre cero y el valor de GL_SAMPLES menos uno.

Si el modo multisample no tiene ubicaciones de muestra fijas, los valores devueltos solo pueden reflejar las ubicaciones de las muestras dentro de algunos píxeles.

ERRORES

Se genera GL_INVALID_ENUM si pname no es GL_SAMPLE_POSITION.

Se genera GL_INVALID_VALUE si index es mayor o igual al valor de GL_SAMPLES.
