NOMBRE

glab-release-upload - Sube archivos o enlaces de activos de lanzamiento a un lanzamiento de GitLab.

SINOPSIS

glab release upload [...] [flags]

DESCRIPCIÓN

Sube activos de lanzamiento a un lanzamiento de GitLab.

Define el nombre de visualización añadiendo '#' después del nombre del archivo. El tipo de enlace viene después del nombre de visualización, de esta manera: 'myfile.tar.gz#Mi nombre de visualización#package'

OPCIONES

-a, --assets-links="" Representación en cadena JSON de los enlaces de activos, como: --assets-links='[{"name": "Asset1", "url":"https://<domain>/some/location/1", "link_type": "other", "direct_asset_path": "path/to/file"}]'.

--package-name="release-assets" El nombre del paquete a usar al subir los activos al lanzamiento de paquete genérico con --use-package-registry.

--use-package-registry[=false] Sube los activos de lanzamiento al registro de paquetes genérico del proyecto. Alternativamente a esta bandera, también puedes configurar la variable de entorno GITLAB_RELEASE_ASSETS_USE_PACKAGE_REGISTRY a true o 1. La bandera tiene prioridad sobre esta variable de entorno.

OPCIONES HEREDADAS DE COMANDOS PADRE

-h, --help[=false] Mostrar ayuda para este comando.

-R, --repo="" Seleccionar otro repositorio. Puede usar el formato OWNER/REPO o GROUP/NAMESPACE/REPO. También acepta URL completa o URL Git.

EJEMPLO

# Sube un activo de lanzamiento con un nombre de visualización. 'Type' por defecto es 'other'.
$ glab release upload v1.0.1 '/path/to/asset.zip#Mi etiqueta de visualización'
# Sube un activo de lanzamiento con nombre de visualización y tipo.
$ glab release upload v1.0.1 '/path/to/asset.png#Mi etiqueta de visualización#image'
# Sube todos los activos en una carpeta especificada. 'Type' por defecto es 'other'.
$ glab release upload v1.0.1 ./dist/*
# Sube todas las tarballs en una carpeta especificada. 'Type' por defecto es 'other'.
$ glab release upload v1.0.1 ./dist/*.tar.gz
# Sube enlaces de activos de lanzamiento especificados como cadena JSON
$ glab release upload v1.0.1 --assets-links='
  [
    {
      "name": "Asset1",
      "url":"https://<domain>/some/location/1",
      "link_type": "other",
      "direct_asset_path": "path/to/file"
    }
  ]'
