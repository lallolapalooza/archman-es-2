GLGETBUFFERPARAMETER(3G) [FIJARME: manual] GLGETBUFFERPARAMETER(3G)

NOMBRE

glGetBufferParameteriv, glGetBufferParameteri64v, glGetNamedBufferParameteriv, glGetNamedBufferParameteri64v - devolver parámetros de un objeto de buffer

ESPECIFICACIÓN C

void glGetBufferParameteriv(GLenum target, GLenum value, GLint * data);

void glGetBufferParameteri64v(GLenum target, GLenum value, GLint64 * data);

void glGetNamedBufferParameteriv(GLuint buffer, GLenum pname, GLint *params);

void glGetNamedBufferParameteri64v(GLuint buffer, GLenum pname, GLint64 *params);

PARÁMETROS

target

Especifica el destino al que está enlazado el objeto de buffer para glGetBufferParameteriv y glGetBufferParameteri64v. Debe ser uno de los destinos de enlace de buffer en la siguiente tabla:
Destino de enlace de buffer Propósito
GL_ARRAY_BUFFER Atributos de vértice
GL_ATOMIC_COUNTER_BUFFER Almacenamiento de contador atómico
GL_COPY_READ_BUFFER Origen de copia de buffer
GL_COPY_WRITE_BUFFER Destino de copia de buffer
GL_DISPATCH_INDIRECT_BUFFER Comandos indirectos de cómputo de despacho
GL_DRAW_INDIRECT_BUFFER Argumentos indirectos de comando
GL_ELEMENT_ARRAY_BUFFER Índices de array de vértices
GL_PIXEL_PACK_BUFFER Destino de lectura de píxeles
GL_PIXEL_UNPACK_BUFFER Origen de datos de textura
GL_QUERY_BUFFER Buffer de resultado de consulta
GL_SHADER_STORAGE_BUFFER Almacenamiento de lectura-escritura para shaders
GL_TEXTURE_BUFFER Buffer de datos de textura
GL_TRANSFORM_FEEDBACK_BUFFER Buffer de retroalimentación de transformación
GL_UNIFORM_BUFFER Almacenamiento de bloque uniforme

buffer

Especifica el nombre del objeto de buffer para glGetNamedBufferParameteriv y glGetNamedBufferParameteri64v.

value

Especifica el nombre del parámetro del objeto de buffer a consultar.

data

Devuelve el parámetro solicitado.

DESCRIPCIÓN

Estas funciones devuelven en data un parámetro seleccionado del objeto de buffer especificado.

pname nombra un parámetro específico del objeto de buffer, como sigue:

GL_BUFFER_ACCESS

params devuelve la política de acceso establecida al mapear el objeto de buffer (el valor del enum de parámetro access pasado a glMapBuffer). Si el buffer se mapeó con glMapBufferRange, la política de acceso se determina traduciendo los bits en ese parámetro access a uno de los enums admitidos para glMapBuffer como se describe en la Especificación OpenGL.

GL_BUFFER_ACCESS_FLAGS

params devuelve la política de acceso establecida al mapear el objeto de buffer (el valor del campo de bits del parámetro access pasado a glMapBufferRange). Si el buffer se mapeó con glMapBuffer, la política de acceso se determina traduciendo los enums en ese parámetro access a los bits correspondientes para glMapBufferRange como se describe en la Especificación OpenGL. El valor inicial es cero.

GL_BUFFER_IMMUTABLE_STORAGE

params devuelve un flag booleano que indica si el objeto de buffer es inmutable. El valor inicial es GL_FALSE.

GL_BUFFER_MAPPED

params devuelve un flag que indica si el objeto de buffer está actualmente mapeado. El valor inicial es GL_FALSE.

GL_BUFFER_MAP_LENGTH

params devuelve la longitud del mapeo en el objeto de buffer establecido con glMapBuffer*. Las versiones i64v de estas consultas deben usarse para este parámetro. El valor inicial es cero.

GL_BUFFER_MAP_OFFSET

params devuelve el desplazamiento del mapeo en el objeto de buffer establecido con glMapBuffer*. Las versiones i64v de estas consultas deben usarse para este parámetro. El valor inicial es cero.

GL_BUFFER_SIZE

params devuelve el tamaño del objeto de buffer, medido en bytes. El valor inicial es 0.

GL_BUFFER_STORAGE_FLAGS

params devuelve un campo de bits que indica las flags de almacenamiento para el objeto de buffer. Si el objeto de buffer es inmutable, el valor devuelto será el especificado cuando se estableció el almacén de datos con glBufferStorage. Si el almacén de datos se estableció con glBufferData, el valor será GL_MAP_READ_BIT | GL_MAP_WRITE_BIT | GL_DYNAMIC_STORAGE_BIT | GL_MAP_WRITE_BIT. El valor inicial es cero.

GL_BUFFER_USAGE

params devuelve el patrón de uso del objeto de buffer. El valor inicial es GL_STATIC_DRAW.

NOTAS

Si se genera un error, no se realiza ningún cambio en el contenido de data.

El destino GL_ATOMIC_COUNTER_BUFFER solo está disponible si la versión de GL es 4.2 o superior.

Los destinos GL_DISPATCH_INDIRECT_BUFFER y GL_SHADER_STORAGE_BUFFER solo están disponibles si la versión de GL es 4.3 o superior.

El destino GL_QUERY_BUFFER solo está disponible si la versión de GL es 4.4 o superior.

ERRORES

GL_INVALID_ENUM es generado por glGetBufferParameter* si target no es uno de los destinos de buffer aceptados.

GL_INVALID_OPERATION es generado por glGetBufferParameter* si cero está enlazado a target.

GL_INVALID_OPERATION es generado por glGetNamedBufferParameter* si buffer no es el nombre de un objeto de buffer existente.

GL_INVALID_ENUM es generado si pname no es uno de los nombres de parámetro de objeto de buffer descritos anteriormente.
