PARÁMETROS

program

Especifica el identificador del programa que contiene la variable uniforme a modificar.

location

Especifica la ubicación de la variable uniforme a modificar.

count

Para los comandos vectoriales (glProgramUniform*v), especifica el número de elementos que se van a modificar. Debe ser 1 si la variable uniforme objetivo no es un array, y 1 o más si es un array.

Para los comandos de matrices (glProgramUniformMatrix*), especifica el número de matrices que se van a modificar. Debe ser 1 si la variable uniforme objetivo no es un array de matrices, y 1 o más si es un array.

transpose

Para los comandos de matrices (glProgramUniformMatrix*), especifica si la matriz debe transponerse. Debe ser GL_TRUE si la matriz debe transponerse, y GL_FALSE en caso contrario.

value

Puntero a la matriz o vector que contiene los nuevos valores para la variable uniforme especificada.

v0, v1, v2, v3

Especifican los nuevos valores para la variable uniforme especificada.

DESCRIPCIÓN

glProgramUniform* establece el valor de una variable uniforme individual para un objeto de programa especificado. A diferencia de glUniform, estas funciones no requieren que el programa sea el programa actualmente en uso en el momento de llamar a la función.

Si program no es el identificador de un programa compilado y enlazado, se generará un error GL_INVALID_OPERATION. Si location no es una ubicación válida para una variable uniforme en el program, o si la variable uniforme en location no es del tipo apropiado para la función llamada, se generará un error GL_INVALID_OPERATION. Si la variable uniforme es un array, estas funciones establecen los valores de los primeros count elementos del array. Si la variable uniforme es una matriz, estas funciones establecen los valores de la primera count matriz. Si count es mayor que 1 y la variable uniforme no es un array o una matriz, se generará un error GL_INVALID_OPERATION.

Las funciones terminadas en 'f' toman argumentos de tipo float, las terminadas en 'i' toman argumentos de tipo int, y las terminadas en 'ui' toman argumentos de tipo unsigned int. Las funciones terminadas en 'v' toman un puntero a un array de valores.

Las funciones glProgramUniformMatrix* establecen los valores de una o más matrices. El argumento transpose especifica si las matrices en el array de entrada value deben transponerse antes de ser establecidas. Si transpose es GL_TRUE, las columnas de la matriz se convierten en filas y viceversa. Si transpose es GL_FALSE, las matrices se establecen tal como se proporcionan.

Si la variable uniforme es de tipo sampler, el comportamiento es indefinido.

La llamada a estas funciones no afecta al programa actualmente en uso.

ERRORES

GL_INVALID_OPERATION se genera si program no es el identificador de un programa válido.

GL_INVALID_OPERATION se genera si location no es una ubicación válida para una variable uniforme en el program, o si el tipo de la variable uniforme en location no es compatible con el tipo de parámetro de la función llamada.

GL_INVALID_OPERATION se genera si count es mayor que 1 y la variable uniforme objetivo no es un array.

GL_INVALID_VALUE se genera si count es negativo.

DESCRIPCIÓ

N

glProgramUniform modifica el valor de una variable uniforme o de un array de variables uniformes. La ubicación de la variable uniforme a modificar se especifica mediante location, que debe ser un valor devuelto por glGetUniformLocation(). glProgramUniform opera sobre el objeto de programa especificado por program

.

Los comandos glProgramUniform{1|2|3|4}{f|i|ui} se utilizan para cambiar el valor de la variable uniforme especificada por location usando los valores pasados como argumentos. El número especificado en el comando debe coincidir con el número de componentes en el tipo de datos de la variable uniforme especificada (por ejemplo, 1 para float, int, unsigned int, bool; 2 para vec2, ivec2, uvec2, bvec2, etc.). El sufijo f indica que se están pasando valores de punto flotante; el sufijo i indica que se están pasando valores enteros; el sufijo ui indica que se están pasando valores enteros sin signo, y este tipo también debe coincidir con el tipo de datos de la variable uniforme especificada. Las variantes i de esta función deben usarse para proporcionar valores para variables uniformes definidas como int, ivec2, ivec3, ivec4, o arrays de estos. Las ui variantes de esta función deben usarse para proporcionar valores para variables uniformes definidas como unsigned int, uvec2, uvec3, uvec4, o arrays de estos. Las f variantes deben usarse para proporcionar valores para variables uniformes de tipo float, vec2, vec3, vec4, o arrays de estos. Se pueden usar las variantes i, ui o f para proporcionar valores para variables uniformes de tipo bool, bvec2, bvec3, bvec4, o arrays de estos. La variable uniforme se establecerá en false si el valor de entrada es 0 o 0.0f, y se establecerá en true en caso

contrario.

Todas las variables uniformes activas definidas en un objeto de programa se inicializan a 0 cuando el objeto de programa se enlaza correctamente. Conservan los valores asignados por una llamada a glProgramUniform hasta que se produce la siguiente operación de enlace exitosa en el objeto de programa, momento en el que se inicializan nuevamente a

0.

Los comandos glProgramUniform{1|2|3|4}{f|i|ui}v pueden usarse para modificar una única variable uniforme o un array de variables uniformes. Estos comandos pasan un count y un puntero a los valores que se cargarán en una variable uniforme o en un array de variables uniformes. Debe usarse un count de 1 si se modifica el valor de una única variable uniforme, y un count de 1 o mayor puede usarse para modificar un array completo o parte de un array. Al cargar n elementos a partir de una posición arbitraria m en un array de variables uniformes, los elementos m + n - 1 del array serán reemplazados con los nuevos valores. Si m + n - 1 es mayor que el tamaño del array de variables uniformes, los valores de todos los elementos del array más allá del final del array serán ignorados. El número especificado en el nombre del comando indica el número de componentes de cada elemento en value, y debe coincidir con el número de componentes en el tipo de datos de la variable uniforme especificada (por ejemplo, 1 para float, int, bool; 2 para vec2, ivec2, bvec2, etc.). El tipo de datos especificado en el nombre del comando debe coincidir con el tipo de datos de la variable uniforme especificada como se describió anteriormente para glProgramUniform{1|2|3|

4}{f|i|ui}.

Para arrays de variables uniformes, cada elemento del array se considera que es del tipo indicado en el nombre del comando (por ejemplo, glProgramUniform3f o glProgramUniform3fv pueden usarse para cargar un array de variables uniformes de tipo vec3). El número de elementos del array de variables uniformes a modificar se especifica mediante coun

t

Los comandos glProgramUniformMatrix{2|3|4|2x3|3x2|2x4|4x2|3x4|4x3}fv se utilizan para modificar una matriz o un array de matrices. Los números en el nombre del comando se interpretan como la dimensionalidad de la matriz. El número 2 indica una matriz de 2 × 2 (es decir, 4 valores), el número 3 indica una matriz de 3 × 3 (es decir, 9 valores), y el número 4 indica una matriz de 4 × 4 (es decir, 16 valores). La dimensionalidad de matrices no cuadradas es explícita, con el primer número representando el número de columnas y el segundo número representando el número de filas. Por ejemplo, 2x4 indica una matriz de 2 × 4 con 2 columnas y 4 filas (es decir, 8 valores). Si transpose es GL_FALSE, se asume que cada matriz se proporciona en orden de columnas. Si transpose es GL_TRUE, se asume que cada matriz se proporciona en orden de filas. El argumento count indica el número de matrices a pasar. Debe usarse un count de 1 si se modifica el valo

r de una única matriz, y un count mayor que 1
puede usarse para modificar un array de matrices.

NOTA

S

glProgramUniform1i y glProgramUniform1iv son las únicas dos funciones que pueden usarse para cargar variables uniformes definidas como tipos sampler. Cargar samplers con cualquier otra función resultará en un error GL_INVALID_OPERATION

.

Si count es mayor que 1 y la variable uniforme indicada no es un array, se genera un error GL_INVALID_OPERATION y la variable uniforme especificada permanecerá sin

cambios.

Aparte de las excepciones anteriores, si el tipo y el tamaño de la variable uniforme tal como se define en el shader no coinciden con el tipo y el tamaño especificados en el nombre del comando utilizado para cargar su valor, se generará un error GL_INVALID_OPERATION y la variable uniforme especificada permanecerá sin

cambios.

Si location es un valor distinto de -1 y no representa una ubicación válida de variable uniforme dentro de program, se generará un error y no se realizarán cambios en el almacenamiento de variables uniformes de program. Si location es igual a -1, los datos pasados serán ignorados silenc

iosamente y la variable uniforme
especificada no será cambiada.

ERRORE

S

Se genera GL_INVALID_OPERATION si program no se refiere a un objeto de programa propiedad de

GL.

Se genera GL_INVALID_OPERATION si el tamaño de la variable uniforme declarada en el shader no coincide con el tamaño indicado por el comando glProgramUniform

.

Se genera GL_INVALID_OPERATION si se usa una de las variantes de entero con signo o sin signo de esta función para cargar una variable uniforme de tipo float, vec2, vec3, vec4, o un array de estos, o si se usa una de las variantes de punto flotante de esta función para cargar una variable uniforme de tipo int, ivec2, ivec3, ivec4, unsigned int, uvec2, uvec3, uvec4, o un array de

estos.

Se genera GL_INVALID_OPERATION si se usa una de las variantes de entero con signo de esta función para cargar una variable uniforme de tipo unsigned int, uvec2, uvec3, uvec4, o un array de

estos.

Se genera GL_INVALID_OPERATION si se usa una de las variantes de entero sin signo de esta función para cargar una variable uniforme de tipo int, ivec2, ivec3, ivec4, o un array de

estos.

Se genera GL_INVALID_OPERATION si location es una ubicación de uniforme inválida para program y location no es igual a

-1.

Se genera GL_INVALID_VALUE si count es menor que

0.

Se genera GL_INVALID_OPERATION si count es mayor que 1 y la variable uniforme indicada no es una variable

array.

Se genera GL_INVALID_OPERATION si se carga un sampler usando un comando distinto a glProgramUniform1i y glProgramUniform1i

v
