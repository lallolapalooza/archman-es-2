GLOBJECTLABEL(3G) [FIXME: manual] GLOBJECTLABEL(3G)

NOMBRE

glObjectLabel - etiqueta un objeto con nombre identificado dentro de un espacio de nombres

ESPECIFICACIÓN C

void glObjectLabel(GLenum identifier, GLuint name, GLsizei length, const char * label);

PARÁMETROS

identifier

El espacio de nombres del cual se asigna el nombre del objeto.

name

El nombre del objeto a etiquetar.

length

La longitud de la etiqueta que se utilizará para el objeto.

label

La dirección de una cadena que contiene la etiqueta a asignar al objeto.

DESCRIPCIÓN

glObjectLabel etiqueta el objeto identificado por name dentro del espacio de nombres dado por identifier. identifier debe ser uno de GL_BUFFER, GL_SHADER, GL_PROGRAM, GL_VERTEX_ARRAY, GL_QUERY, GL_PROGRAM_PIPELINE, GL_TRANSFORM_FEEDBACK, GL_SAMPLER, GL_TEXTURE, GL_RENDERBUFFER, GL_FRAMEBUFFER, para indicar el espacio de nombres que contiene los nombres de búferes, sombreadores, programas, objetos de array de vértices, objetos de consulta, canalizaciones de programas, objetos de retroalimentación de transformación, samplers, texturas, búferes de renderizado y búferes de fotogramas, respectivamente.

label es la dirección de una cadena que se utilizará para etiquetar un objeto. length contiene el número de caracteres en label. Si length es negativo, se implica que label contiene una cadena terminada en nulo. Si label es NULL, cualquier etiqueta de depuración se elimina efectivamente del objeto.

ERRORES

Se genera GL_INVALID_ENUM si identifier no es uno de los tipos de objeto aceptados.

Se genera GL_INVALID_OPERATION si name no es el nombre de un objeto existente del tipo especificado por identifier.

Se genera GL_INVALID_VALUE si el número de caracteres en label, excluyendo el terminador nulo cuando length es negativo, es mayor que el valor de GL_MAX_LABEL_LENGTH.

ASOCIADOS GETS

glGet() con el argumento GL_MAX_LABEL_LENGTH.
