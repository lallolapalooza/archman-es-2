libc(7) Información Miscelánea Manual libc(7)

NOMBRE

libc - resumen de bibliotecas C estándar en Linux

DESCRIPCIÓN

El término "libc" se usa comúnmente como abreviatura de "biblioteca C estándar", una biblioteca de funciones estándar que pueden ser utilizadas por todos los programas C (y a veces por programas en otros lenguajes). Debido a alguna historia (ver más abajo), el uso del término "libc" para referirse a la biblioteca C estándar es algo ambiguo en Linux.

glibc

Con mucho, la biblioteca C más utilizada en Linux es la Biblioteca C de GNU, a menudo referida como glibc. Esta es la biblioteca C que hoy en día se utiliza en todas las principales distribuciones de Linux. Es también la biblioteca C cuyos detalles se documentan en las páginas relevantes del proyecto man-pages (principalmente en la Sección 3 del manual). La documentación de glibc también está disponible en el manual de glibc, accesible mediante el comando info libc. La versión 1.0 de glibc se lanzó en septiembre de 1992. (Hubo versiones anteriores 0.x). La siguiente versión principal de glibc fue la 2.0, a principios de 1997.

La ruta del archivo /lib/libc.so.6 (o algo similar) es normalmente un enlace simbólico que apunta a la ubicación de la biblioteca glibc, y ejecutar esta ruta hará que glibc muestre diversa información sobre la versión instalada en su sistema.

Linux libc

A principios y mediados de la década de 1990, existió durante un tiempo Linux libc, una bifurcación de glibc 1.x creada por desarrolladores de Linux que sentían que el desarrollo de glibc en ese momento no satisfacía las necesidades de Linux. A menudo, esta biblioteca se denominaba (ambiguamente) simplemente "libc". Linux libc lanzó las versiones principales 2, 3, 4 y 5, así como muchas versiones menores de esas publicaciones. Linux libc4 fue la última versión en usar el formato binario a.out, y la primera versión en proporcionar (soporte primitivo de) bibliotecas compartidas. Linux libc 5 fue la primera versión en soportar el formato binario ELF; esta versión utilizaba el nombre de biblioteca compartida libc.so.5. Durante un tiempo, Linux libc fue la biblioteca C estándar en muchas distribuciones de Linux.

Sin embargo, a pesar de las motivaciones originales del esfuerzo de Linux libc, para cuando glibc 2.0 fue lanzada (en 1997), era claramente superior a Linux libc, y todas las principales distribuciones de Linux que habían estado usando Linux libc pronto volvieron a cambiar a glibc. Para evitar cualquier confusión con las versiones de Linux libc, glibc 2.0 y posteriores utilizaron el nombre de biblioteca compartida libc.so.6.

Dado que el cambio de Linux libc a glibc 2.0 ocurrió hace mucho tiempo, man-pages ya no se encarga de documentar los detalles de Linux libc. No obstante, la historia es visible en vestigios de información sobre Linux libc que permanecen en algunas páginas del manual, en particular, referencias a libc4 y libc5.

Otras bibliotecas C

Existen varias otras bibliotecas C menos utilizadas para Linux. Estas bibliotecas son generalmente más pequeñas que glibc, tanto en términos de funcionalidades como de huella de memoria, y a menudo están destinadas a la creación de binarios pequeños, quizás orientados al desarrollo para sistemas Linux integrados. Entre tales bibliotecas se encuentran uClibc, dietlibc y musl libc. Los detalles de estas bibliotecas se cubren en el proyecto man-pages, donde se conocen.
