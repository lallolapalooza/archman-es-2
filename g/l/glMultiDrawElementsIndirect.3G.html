DESCRIPCIÓ

N

glMultiDrawElementsIndirect especifica múltiples primitivas geométricas indexadas con muy pocas llamadas a subrutinas. glMultiDrawElementsIndirect se comporta de manera similar a una multitud de llamadas a glDrawElementsInstancedBaseVertexBaseInstance(), excepto que los parámetros para glDrawElementsInstancedBaseVertexBaseInstance() están almacenados en un array en la memoria en la dirección dada por indirect, separados por el stride, en unidades básicas de máquina, especificado por stride. Si stride es cero, entonces se asume que el array está empaquetado de forma contigua en la

memoria.

Los parámetros direccionados por indirect se empaquetan en una estructura que toma la forma (en C)

: 
    typedef  struct {
        uint  count;
        uint  instanceCount;
        uint  firstIndex;
        int  baseVertex;
        uint  baseInstance;
    } DrawElementsIndirectComman
d
;

Una sola llamada a glMultiDrawElementsIndirect es equivalente, asumiendo que no se generan errores,

a: 
    GLsizei n;
    for (n = 0; n < drawcount; n++) {
        const DrawElementsIndirectCommand *cmd;
        if (stride != 0) {
            cmd = (const DrawElementsIndirectCommand  *)((uintptr)indirect + n * stride);
        } else {
            cmd = (const DrawElementsIndirectCommand  *)indirect + n;
        }
        glDrawElementsInstancedBaseVertexBaseInstance(mode,
                                                      cmd->count,
                                                      type,
                                                      cmd->firstIndex * size-of-type,
                                                      cmd->instanceCount,
                                                      cmd->baseVertex,
                                                      cmd->baseInstance);
}

Si un buffer está vinculado al enlace GL_DRAW_INDIRECT_BUFFER en el momento de una llamada a glDrawElementsIndirect, indirect se interpreta como un desplazamiento, en unidades básicas de máquina, dentro de ese buffer y los datos de los parámetros se leen del buffer en lugar de la memoria del

cliente.

Ten en cuenta que los índices almacenados en la memoria del cliente no están soportados. Si no hay ningún buffer vinculado al enlace GL_ELEMENT_ARRAY_BUFFER, se generará un

error.

Los resultados de la operación son indefinidos si el miembro reservedMustBeZero de la estructura de parámetros no es cero. Sin embargo, en este caso no se genera ningún

error.

Los atributos de vértice que son modificados por glDrawElementsIndirect tienen un valor no especificado después de que glDrawElementsIndirect retorna. Los atributos qu

e no son modificados pe
rmanecen bien definidos.

NOTA

S

El miembro baseInstance de la estructura DrawElementsIndirectCommand está definido solo si la versión de GL es 4.2 o superior. Para versiones de GL menores a 4.2, este parámetro est

á presente pero está reservado y debería establecerse en cero. En vers
iones anteriores de GL, el comportamiento es indefinido si no es cero.

ERRORE

S

GL_INVALID_ENUM se genera si mode no es un valor

aceptado.

GL_INVALID_VALUE se genera si stride no es un múltiplo de

cuatro.

GL_INVALID_VALUE se genera si drawcount es

negativo.

GL_INVALID_OPERATION se genera si no hay ningún buffer vinculado al enlace GL_ELEMENT_ARRAY_BUFFER, o si el almacén de datos de dicho buffer está actualmente

mapeado.

GL_INVALID_OPERATION se genera si un nombre de objeto buffer distinto de cero está vinculado a un array habilitado o al enlace GL_DRAW_INDIRECT_BUFFER y el almacén de datos del objeto buffer está actualmente

mapeado.

GL_INVALID_OPERATION se genera si un shader de geometría está activo y mode es incompatible con el tipo de primitiva de entrada del shader de geometría en el objeto programa actualmente

instalado.

GL_INVALID_OPERATION se genera si mode es GL_PATCHES y no hay ningún shader

de control de te
selación activo.
