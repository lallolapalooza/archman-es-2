DESCRIPCIÓ

N

glGetTextureSubImage devuelve una subimagen de textura en

pixels.

texture es el nombre del objeto de textura de origen y no debe ser una textura de búfer ni de muestreo múltiple. El parámetro target efectivo es el valor de GL_TEXTURE_TARGET para texture. Level, format, type y pixels tienen el mismo significado que para glGetTexImage. bufSize es el tamaño del búfer para recibir los datos de píxel

recuperados.

Para las texturas de mapa cúbico, el comportamiento es como si se llamara a GetTextureImage, pero solo se devuelven los texels de las caras del mapa cúbico solicitadas (seleccionadas por zoffset y depth, como se describe más abajo). Los valores

de

xoffset, yoffset y zoffset indican la posición de la subregión a devolver. width, height y depth indican el tamaño de la región a devolver. Estos parámetros tienen el mismo significado que para glTexSubImage3D, aunque para las texturas de una y dos dimensiones existen restricciones adicionales, descritas en la sección de errores más

abajo.

Para las texturas de array de una dimensión, yoffset se interpreta como la primera capa a acceder y height es el número de capas a

acceder.

Para las texturas de array de dos dimensiones, zoffset se interpreta como la primera capa a acceder y depth es el número de capas a

acceder.

Las texturas de mapa cúbico se tratan como un array de seis cortes en la dimensión z, donde el valor de zoffset se interpreta como que especifica la cara del mapa cúbico para la capa correspondiente (como se presenta en la tabla siguiente) y depth es el número de caras a

acceder: capa l mapa cúbico 0 IVE_X 1 IVE_X 2 IVE_Y 3 IVE_Y 4 IVE_Z 5 VE_

Para las texturas de array de mapa cúbico, zoffset es la primera capa-cara a acceder, y depth es el número de capas-caras a acceder. Una capa-cara descrita por $k$ se traduce en una capa de array y una cara según $$ layer = \left\lfloor { layer \over 6 } \right\rfloor$$ y $$ face = k \bmod 6.

Los grupos de componentes de la subregión especificada se empaquetan y colocan en memoria como se describe para glGetTextureImage, empezando con el texel en (xoffset, yoffset, zoff

).

ERRORE

S

Se genera el error GL_INVALID_VALUE si texture no es el nombre de un objeto de textura

existente.

Se genera el error GL_INVALID_OPERATION si texture es el nombre de una textura de búfer o de muestreo

múltiple.

Se genera GL_INVALID_VALUE si xoffset, yoffset o zoffset son

negativos.

Se genera GL_INVALID_VALUE si xoffset + width es mayor que el ancho de la textura, yoffset + height es mayor que la altura de la textura, o zoffset + depth es mayor que la profundidad de la

textura.

Se genera el error GL_INVALID_VALUE si el objetivo efectivo es GL_TEXTURE_1D y yoffset no es cero, o height no es

uno.

Se genera el error GL_INVALID_VALUE si el objetivo efectivo es GL_TEXTURE_1D, GL_TEXTURE_1D_ARRAY, GL_TEXTURE_2D o GL_TEXTURE_RECTANGLE y zoffset no es cero, o depth no es

uno.

Se genera el error GL_INVALID_OPERATION si el tamaño de búfer necesario para almacenar los datos solicitados es mayor que bufS

iz
e.
