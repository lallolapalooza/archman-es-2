glutSpecialUpFunc(3)

Paquete: freeglut

Licencias: X11

glutSpecialUpFunc(3) freeglut glutSpecialUpFunc(3)

NOMBRE

glutSpecialUpFunc - establece la devolución de llamada de teclado especial de subida (liberación de tecla) para la ventana actual.

SINTAXIS

void glutSpecialUpFunc(void (*func)(int key, int x, int y));

ARGUMENTOS

func
La nueva función de devolución de llamada especial.

DESCRIPCIÓN

glutSpecialUpFunc establece la devolución de llamada de teclado especial de subida (liberación de tecla) para la ventana actual. La devolución de llamada de teclado especial de subida se activa cuando se liberan las teclas de función o las teclas direccionales. El parámetro de devolución de llamada `key` es una constante GLUT_KEY_* para la tecla especial liberada. Los parámetros de devolución de llamada `x` e `y` indican la posición del ratón en coordenadas relativas a la ventana cuando se pulsó la tecla. Cuando se crea una nueva ventana, inicialmente no se registra ninguna devolución de llamada especial de subida y las liberaciones de teclas especiales en la ventana se ignoran. Pasar NULL a glutSpecialUpFunc deshabilita la generación de devoluciones de llamada especiales de subida.

Durante una devolución de llamada especial de subida, se puede llamar a glutGetModifiers para determinar el estado de las teclas modificadoras cuando se produjo la liberación de tecla que generó la devolución de llamada.

Para evitar la notificación de pares de liberación/pulsación de teclas debido a la repetición automática, utilice glutIgnoreKeyRepeat para ignorar las pulsaciones de teclas repetidas automáticamente.

Una implementación debería hacer todo lo posible para proporcionar formas de generar todas las teclas especiales GLUT_KEY_*. Los valores GLUT_KEY_* disponibles son:

Tecla de función F1.
GLUT_KEY_F2
Tecla de función F2.
GLUT_KEY_F3
Tecla de función F3.
GLUT_KEY_F4
Tecla de función F4.
GLUT_KEY_F5
Tecla de función F5.
GLUT_KEY_F6
Tecla de función F6.
GLUT_KEY_F7
Tecla de función F7.
GLUT_KEY_F8
Tecla de función F8.
GLUT_KEY_F9
Tecla de función F9.
GLUT_KEY_F10
Tecla de función F10.
GLUT_KEY_F11
Tecla de función F11.
GLUT_KEY_F12
Tecla de función F12.
GLUT_KEY_LEFT
Tecla direccional izquierda.
GLUT_KEY_UP
Tecla direccional arriba.
GLUT_KEY_RIGHT
Tecla direccional derecha.
GLUT_KEY_DOWN
Tecla direccional abajo.
GLUT_KEY_PAGE_UP
Tecla direccional Av Pág.

Tecla direccional Insertar.

Tenga en cuenta que las teclas Escape, Retroceso y Suprimir se generan como un carácter ASCII.
