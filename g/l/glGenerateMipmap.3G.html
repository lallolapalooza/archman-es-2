NOMBRE

glGenerateMipmap, glGenerateTextureMipmap - generar mipmaps para un objeto de textura especificado

ESPECIFICACIÓN C

void glGenerateMipmap(GLenum target);

void glGenerateTextureMipmap(GLuint texture);

PARÁMETROS

target

Especifica el objetivo al que está enlazado el objeto de textura para glGenerateMipmap. Debe ser uno de GL_TEXTURE_1D, GL_TEXTURE_2D, GL_TEXTURE_3D, GL_TEXTURE_1D_ARRAY, GL_TEXTURE_2D_ARRAY, GL_TEXTURE_CUBE_MAP, o GL_TEXTURE_CUBE_MAP_ARRAY.

texture

Especifica el nombre del objeto de textura para glGenerateTextureMipmap.

DESCRIPCIÓN

glGenerateMipmap y glGenerateTextureMipmap generan mipmaps para el objeto de textura especificado. Para glGenerateMipmap, el objeto de textura que está enlazado a target. Para glGenerateTextureMipmap, texture es el nombre del objeto de textura.

Para texturas de mapas cúbicos y arrays de mapas cúbicos, el objeto de textura debe ser completo cúbico o completo de array cúbico, respectivamente.

La generación de mipmaps reemplaza los niveles de imagen de texel $level_{base} + 1$ hasta $q$ con imágenes derivadas de la imagen $level_{base}$, independientemente de su contenido anterior. Todas las demás imágenes de mipmap, incluida la imagen $level_{base}$, no se modifican por este cálculo.

Los formatos internos de las imágenes de mipmap derivadas coinciden todos con los de la imagen $level_{base}$. El contenido de las imágenes derivadas se calcula mediante la reducción repetida y filtrada de la imagen $level_{base}$. Para texturas de arrays unidimensionales y bidimensionales, así como arrays de mapas cúbicos, cada capa se filtra de forma independiente.

NOTAS

Las texturas de arrays de mapas cúbicos solo se aceptan si la versión de GL es 4.0 o superior.

ERRORES

Se genera GL_INVALID_ENUM por glGenerateMipmap si target no es uno de los objetivos de textura aceptados.

Se genera GL_INVALID_OPERATION por glGenerateTextureMipmap si texture no es el nombre de un objeto de textura existente.

Se genera GL_INVALID_OPERATION si target es GL_TEXTURE_CUBE_MAP o GL_TEXTURE_CUBE_MAP_ARRAY, y el objeto de textura especificado no es completo cúbico o completo de array cúbico, respectivamente.
