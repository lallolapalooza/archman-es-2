NOMBRE

glab-variable-list - Lista variables para un proyecto o grupo.

SINOPSIS

glab variable list [flags]

DESCRIPCIÓN

Lista variables para un proyecto o grupo.

OPCIONES

-g, --group="" Selecciona un grupo o subgrupo. Ignorado si se establece un argumento de repositorio.

-i, --instance[=false] Muestra variables de instancia.

-F, --output="text" Formatea la salida como: text, json.

-p, --page=1 Número de página.

-P, --per-page=20 Número de elementos a listar por página.

-R, --repo="" Selecciona otro repositorio. Puede usar el formato PROPIETARIO/REPO o GRUPO/ESPACIO-DE-NOMBRES/REPO. También acepta URL completa o URL de Git.

OPCIONES HEREDADAS DE COMANDOS PADRE

-h, --help[=false] Muestra la ayuda para este comando.

EJEMPLO

$ glab variable list
$ glab variable list -i
$ glab variable list --per-page 100 --page 1
$ glab variable list --group gitlab-org
$ glab variable list --group gitlab-org --per-page 100
