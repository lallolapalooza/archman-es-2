DESCRIPCIÓ

N

glGetVertexArrayIndexediv y glGetVertexArrayIndexed64iv proporcionan una forma de consultar los parámetros de un atributo en un índice especificado por el usuario de un objeto de matriz de vértices. El objeto de matriz de vértices no tiene que estar vinculado al contexto de renderizado en el momento de la llamada, pero debe haber sido vinculado al menos una vez antes de esta

llamada.

Los siguientes valores de parámetro se pueden recuperar con glGetVertexArrayIndexediv para cada uno de los atributos definidos para un objeto de matriz de

vértices:
•GL_VERTEX_ATTRIB_ARRAY_ENABLED: param devuelve un valor que no es cero (verdadero) si la matriz de atributos de vértices para index está habilitada y 0 (falso) si está deshabilitada. El valor inicial es GL_FALSE
.
•GL_VERTEX_ATTRIB_ARRAY_SIZE: param devuelve un solo valor, el tamaño de la matriz de atributos de vértices para index. El tamaño es el número de valores para cada elemento de la matriz de atributos de vértices, y será 1, 2, 3 o 4. El valor inicial es
4.
•GL_VERTEX_ATTRIB_ARRAY_STRIDE: param devuelve un solo valor, el paso de la matriz para (número de bytes entre elementos sucesivos en) la matriz de atributos de vértices para index. Un valor de 0 indica que los elementos de la matriz se almacenan secuencialmente en memoria. El valor inicial es
0.
•GL_VERTEX_ATTRIB_ARRAY_TYPE: param devuelve un solo valor, una constante simbólica que indica el tipo de matriz para la matriz de atributos de vértices para index. Los valores posibles son GL_BYTE, GL_DOUBLE, GL_FIXED, GL_FLOAT, GL_HALF_FLOAT, GL_INT, GL_INT_2_10_10_10_REV, GL_SHORT, GL_UNSIGNED_BYTE, GL_UNSIGNED_SHORT, GL_UNSIGNED_INT, GL_UNSIGNED_INT_2_10_10_10_REV, y GL_UNSIGNED_INT_10F_11F_11F_REV . El valor inicial es GL_FLOAT
.
•GL_VERTEX_ATTRIB_ARRAY_NORMALIZED: param devuelve un solo valor que no es cero (verdadero) si los tipos de datos de punto fijo para la matriz de atributos de vértices indicada por index se normalizan cuando se convierten a punto flotante, y 0 (falso) en caso contrario. El valor inicial es GL_FALSE
.
•GL_VERTEX_ATTRIB_ARRAY_INTEGER: param devuelve un solo valor que no es cero (verdadero) si los tipos de datos de punto fijo para la matriz de atributos de vértices indicada por index tienen un tipo de datos entero, y 0 (falso) en caso contrario. El valor inicial es 0 (GL_FALS
E).
•GL_VERTEX_ATTRIB_ARRAY_LONG: param devuelve un solo valor que no es cero (verdadero) si un atributo de vértices se almacena como un doble sin convertir, y 0 (falso) en caso contrario. El valor inicial es 0 (GL_FALS
E).
•GL_VERTEX_ATTRIB_ARRAY_DIVISOR: param devuelve un solo valor que es el divisor de frecuencia utilizado para renderizado instanciado. Véase glVertexAttribDivisor. El valor inicial es
0.
•GL_VERTEX_ATTRIB_RELATIVE_OFFSET: param devuelve un solo valor que es el desplazamiento en bytes del primer elemento con respecto al inicio de la vinculación del búfer de vértices desde la que el atributo especificado obtiene datos. El valor inicial es
0.

glGetVertexArrayIndexed64iv se puede utilizar para recuperar el valor del parámetro GL_VERTEX_BINDING_OFFSET para cualquiera de los atributos definidos para un objeto de matriz de vértices. Cuando pname se establece en GL_VERTEX_BINDING_OFFSET, param devuelve un solo valor que es el desplazamiento en bytes del primer elemento e

n el almacén de datos del búfer vinculado. El
valor inicial para este parámetro es 0.

S

existente.

Se genera el error GL_INVALID_VALUE si index es mayor o igual al valor de GL_MAX_VERTEX_ATTRIBS

.

Se genera el error GL_INVALID_ENUM si pname no es uno de los valores vál

idos. Para más deta
