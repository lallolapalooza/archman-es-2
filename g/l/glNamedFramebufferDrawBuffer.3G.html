GLDRAWBUFFER(3G) [FIXME: manual] GLDRAWBUFFER(3G)

NOMBRE

glDrawBuffer, glNamedFramebufferDrawBuffer - especifica en qué buffers de color se va a dibujar

ESPECIFICACIÓN EN C

void glDrawBuffer(GLenum buf);

void glNamedFramebufferDrawBuffer(GLuint framebuffer, GLenum buf);

PARÁMETROS

framebuffer

Especifica el nombre del objeto framebuffer para la función glNamedFramebufferDrawBuffer. Debe ser cero o el nombre de un objeto framebuffer.

buf

Para el framebuffer predeterminado, el argumento especifica hasta cuatro buffers de color en los que dibujar. Se aceptan las constantes simbólicas GL_NONE, GL_FRONT_LEFT, GL_FRONT_RIGHT, GL_BACK_LEFT, GL_BACK_RIGHT, GL_FRONT, GL_BACK, GL_LEFT, GL_RIGHT y GL_FRONT_AND_BACK. El valor inicial es GL_FRONT para contextos con un solo buffer y GL_BACK para contextos con doble buffer. Para objetos framebuffer, se aceptan los enums GL_COLOR_ATTACHMENT$m$ y GL_NONE, donde $m$ es un valor entre 0 y GL_MAX_COLOR_ATTACHMENTS.

DESCRIPCIÓN

Cuando se escriben colores en el framebuffer, se escriben en los buffers de color especificados por glDrawBuffer. Se puede utilizar uno de los siguientes valores para el framebuffer predeterminado:

GL_NONE

No se escriben buffers de color.

GL_FRONT_LEFT

Solo se escribe el buffer de color izquierdo frontal.

GL_FRONT_RIGHT

Solo se escribe el buffer de color derecho frontal.

GL_BACK_LEFT

Solo se escribe el buffer de color izquierdo trasero.

GL_BACK_RIGHT

Solo se escribe el buffer de color derecho trasero.

GL_FRONT

Solo se escriben los buffers de color izquierdo y derecho frontales. Si no hay un buffer de color derecho frontal, solo se escribe el buffer de color izquierdo frontal.

GL_BACK

Solo se escriben los buffers de color izquierdo y derecho traseros. Si no hay un buffer de color derecho trasero, solo se escribe el buffer de color izquierdo trasero.

GL_LEFT

Solo se escriben los buffers de color izquierdo frontal y izquierdo trasero. Si no hay un buffer de color izquierdo trasero, solo se escribe el buffer de color izquierdo frontal.

GL_RIGHT

Solo se escriben los buffers de color derecho frontal y derecho trasero. Si no hay un buffer de color derecho trasero, solo se escribe el buffer de color derecho frontal.

GL_FRONT_AND_BACK

Se escriben todos los buffers de color frontales y traseros (izquierdo frontal, derecho frontal, izquierdo trasero, derecho trasero). Si no hay buffers de color traseros, solo se escriben los buffers de color izquierdo y derecho frontales. Si no hay buffers de color derechos, solo se escriben los buffers de color izquierdo frontal e izquierdo trasero. Si no hay buffers de color derechos ni traseros, solo se escribe el buffer de color izquierdo frontal.

Si se seleccionan varios buffers de color para dibujar, las operaciones de mezcla o lógicas se calculan y aplican de forma independiente para cada buffer de color y pueden producir resultados diferentes en cada buffer.

Los contextos monosóficos solo incluyen buffers *izquierdos*, y los contextos estereoscópicos incluyen ambos buffers, *izquierdo* y *derecho*. Del mismo modo, los contextos de un solo buffer incluyen solo buffers *frontales* y los contextos de doble buffer incluyen ambos buffers, *frontales* y *traseros*. El contexto se selecciona en la inicialización de GL.

Para los objetos framebuffer, se aceptan los enums GL_COLOR_ATTACHMENT$m$ y GL_NONE, donde $m$ es un valor entre 0 y GL_MAX_COLOR_ATTACHMENTS. glDrawBuffer establecerá el buffer de dibujo para colores de fragmento distintos de cero a GL_NONE.

ERRORES

glNamedFramebufferDrawBuffer genera un error GL_INVALID_OPERATION si framebuffer no es cero ni el nombre de un objeto framebuffer existente.

Se genera GL_INVALID_ENUM si buf no es un valor aceptado.

Se genera GL_INVALID_OPERATION si se ve afectado el framebuffer predeterminado y no existe ninguno de los buffers indicados por buf.

Se genera GL_INVALID_OPERATION si se ve afectado un objeto framebuffer y buf no es igual a GL_NONE o GL_COLOR_ATTACHMENT$m$, donde $m$ es un valor entre 0 y GL_MAX_COLOR_ATTACHMENTS.

GETS ASOCIADOS

glGet() con el argumento GL_DRAW_BUFFER
