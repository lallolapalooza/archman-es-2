NOMBRE

glGetProgramiv - Devuelve un parámetro de un objeto programa

ESPECIFICACIÓN EN C

void glGetProgramiv(GLuintprogram, GLenumpname, GLint *params);

PARÁMETROS

program

Especifica el objeto programa que se va a consultar.

pname

Especifica el parámetro del objeto. Los nombres simbólicos aceptados son GL_DELETE_STATUS, GL_LINK_STATUS, GL_VALIDATE_STATUS, GL_INFO_LOG_LENGTH, GL_ATTACHED_SHADERS, GL_ACTIVE_ATOMIC_COUNTER_BUFFERS, GL_ACTIVE_ATTRIBUTES, GL_ACTIVE_ATTRIBUTE_MAX_LENGTH, GL_ACTIVE_UNIFORMS, GL_ACTIVE_UNIFORM_BLOCKS, GL_ACTIVE_UNIFORM_BLOCK_MAX_NAME_LENGTH, GL_ACTIVE_UNIFORM_MAX_LENGTH, GL_COMPUTE_WORK_GROUP_SIZE, GL_PROGRAM_BINARY_LENGTH, GL_TRANSFORM_FEEDBACK_BUFFER_MODE, GL_TRANSFORM_FEEDBACK_VARYINGS, GL_TRANSFORM_FEEDBACK_VARYING_MAX_LENGTH, GL_GEOMETRY_VERTICES_OUT, GL_GEOMETRY_INPUT_TYPE, y GL_GEOMETRY_OUTPUT_TYPE.

params

Devuelve el parámetro del objeto solicitado.

DESCRIPCIÓN

glGetProgram devuelve en params el valor de un parámetro para un objeto programa específico. Se definen los siguientes parámetros:

GL_DELETE_STATUS

params devuelve GL_TRUE si program está actualmente marcado para eliminación, y GL_FALSE en caso contrario.

GL_LINK_STATUS

params devuelve GL_TRUE si la última operación de enlace en program fue exitosa, y GL_FALSE en caso contrario.

GL_VALIDATE_STATUS

params devuelve GL_TRUE o si la última operación de validación en program fue exitosa, y GL_FALSE en caso contrario.

GL_INFO_LOG_LENGTH

params devuelve el número de caracteres en el registro de información para program incluyendo el carácter de terminación nulo (es decir, el tamaño del búfer de caracteres necesario para almacenar el registro de información). Si program no tiene registro de información, se devuelve un valor de 0.

GL_ATTACHED_SHADERS

params devuelve el número de objetos shader adjuntos a program.

GL_ACTIVE_ATOMIC_COUNTER_BUFFERS

params devuelve el número de búferes de contadores atómicos de atributos activos utilizados por program.

GL_ACTIVE_ATTRIBUTES

params devuelve el número de variables de atributos activos para program.

GL_ACTIVE_ATTRIBUTE_MAX_LENGTH

params devuelve la longitud del nombre de atributo activo más largo para program, incluyendo el carácter de terminación nulo (es decir, el tamaño del búfer de caracteres necesario para almacenar el nombre de atributo más largo). Si no existen atributos activos, se devuelve 0.

GL_ACTIVE_UNIFORMS

params devuelve el número de variables uniformes activas para program.

GL_ACTIVE_UNIFORM_MAX_LENGTH

params devuelve la longitud del nombre de variable uniforme activa más largo para program, incluyendo el carácter de terminación nulo (es decir, el tamaño del búfer de caracteres necesario para almacenar el nombre de variable uniforme más largo). Si no existen variables uniformes activas, se devuelve 0.

GL_PROGRAM_BINARY_LENGTH

params devuelve la longitud del binario del programa, en bytes que será devuelta por una llamada a glGetProgramBinary(). Cuando el estado de GL_LINK_STATUS de un programa es GL_FALSE, su longitud de binario del programa es cero.

GL_COMPUTE_WORK_GROUP_SIZE

params devuelve un arreglo de tres enteros que contiene el tamaño del grupo de trabajo local del programa de cómputo según lo especificado por su(s) calificador(es) de diseño de entrada. program debe ser el nombre de un objeto programa que haya sido enlazado previamente con éxito y que contenga un binario para la etapa del shader de cómputo.

GL_TRANSFORM_FEEDBACK_BUFFER_MODE

params devuelve una constante simbólica que indica el modo de búfer utilizado cuando la retroalimentación por transformación está activa. Este puede ser GL_SEPARATE_ATTRIBS o GL_INTERLEAVED_ATTRIBS.

GL_TRANSFORM_FEEDBACK_VARYINGS

params devuelve el número de variables varying a capturar en modo de retroalimentación por transformación para el programa.

GL_TRANSFORM_FEEDBACK_VARYING_MAX_LENGTH

params devuelve la longitud del nombre de variable más largo a utilizar para la retroalimentación por transformación, incluyendo el terminador nulo.

GL_GEOMETRY_VERTICES_OUT

params devuelve el número máximo de vértices que el shader de geometría en program producirá.

GL_GEOMETRY_INPUT_TYPE

params devuelve una constante simbólica que indica el tipo de primitiva aceptado como entrada para el shader de geometría contenido en program.

GL_GEOMETRY_OUTPUT_TYPE

params devuelve una constante simbólica que indica el tipo de primitiva que será producido por el shader de geometría contenido en program.

NOTAS

GL_ACTIVE_UNIFORM_BLOCKS y GL_ACTIVE_UNIFORM_BLOCK_MAX_NAME_LENGTH están disponibles solo si la versión de GL es 3.1 o superior.

GL_GEOMETRY_VERTICES_OUT, GL_GEOMETRY_INPUT_TYPE y GL_GEOMETRY_OUTPUT_TYPE se aceptan solo si la versión de GL es 3.2 o superior.

GL_COMPUTE_WORK_GROUP_SIZE se acepta solo si la versión de GL es 4.3 o superior.

Si se genera un error, no se realiza ningún cambio en el contenido de params.

ERRORES

GL_INVALID_VALUE se genera si program no es un valor generado por OpenGL.

GL_INVALID_OPERATION se genera si program no hace referencia a un objeto programa.

GL_INVALID_OPERATION se genera si pname es GL_GEOMETRY_VERTICES_OUT, GL_GEOMETRY_INPUT_TYPE, o GL_GEOMETRY_OUTPUT_TYPE, y program no contiene un shader de geometría.

GL_INVALID_ENUM se genera si pname no es un valor aceptado.

GL_INVALID_OPERATION se genera si pname es GL_COMPUTE_WORK_GROUP_SIZE y program no contiene un binario para la etapa del shader de cómputo.

OBTENCIONES ASOCIADAS

glGetActiveAttrib() con el argumento program

glGetActiveUniform() con el argumento program

glGetAttachedShaders() con el argumento program

glGetProgramInfoLog() con el argumento program

glIsProgram()
