NOMBRE

glIsTransformFeedback - determina si un nombre corresponde a un objeto de feedback de transformación

ESPECIFICACIÓN C

GLboolean glIsTransformFeedback(GLuint id);

PARÁMETROS

id

Especifica un valor que puede ser el nombre de un objeto de feedback de transformación.

DESCRIPCIÓN

glIsTransformFeedback devuelve GL_TRUE si id es actualmente el nombre de un objeto de feedback de transformación. Si id es cero, o si id no es el nombre de un objeto de feedback de transformación, o si ocurre un error, glIsTransformFeedback devuelve GL_FALSE. Si id es un nombre devuelto por glGenTransformFeedbacks(), pero que aún no ha sido enlazado mediante una llamada a glBindTransformFeedback(), entonces el nombre no es un objeto de feedback de transformación y glIsTransformFeedback devuelve GL_FALSE.
