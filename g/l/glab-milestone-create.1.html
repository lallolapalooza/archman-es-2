NOMBRE

glab-milestone-create - Crea un hito de grupo o proyecto.

SINOPSIS

glab milestone create [flags]

DESCRIPCIÓN

Crea un hito de grupo o proyecto.

OPCIONES

--description="" Descripción del hito.

--due-date="" Fecha de vencimiento del hito. Se espera en formato ISO 8601 (2025-04-15T08:00:00Z).

--group="" El ID o la ruta codificada en URL del grupo.

--project="" El ID o la ruta codificada en URL del proyecto.

--start-date="" Fecha de inicio del hito. Se espera en formato ISO 8601 (2025-04-15T08:00:00Z).

--title="" Título del hito.

OPCIONES HEREDADAS DE COMANDOS PADRE

-h, --help[=false] Muestra la ayuda para este comando.

-R, --repo="" Selecciona otro repositorio. Puede usar el formato PROPIETARIO/REPO o GRUPO/ESPACIO DE NOMBRES/REPO. También acepta URL completas o URL de Git.

EJEMPLO

 # Crea un hito para el proyecto actual
$ glab milestone create --title='Título de ejemplo' --due-date='2025-12-16'
# Crea un hito para el proyecto especificado
$ glab milestone create --title='Hito de grupo de ejemplo' --due-date='2025-12-16' --project 123
# Crea un hito para el grupo especificado
$ glab milestone create --title='Hito de grupo de ejemplo' --due-date='2025-12-16' --group 456
