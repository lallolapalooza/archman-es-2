NOMBRE

glIsSync - determinar si un nombre corresponde a un objeto de sincronización

ESPECIFICACIÓN C

GLboolean glIsSync(GLsync sync);

PARÁMETROS

sync

Especifica un valor que puede ser el nombre de un objeto de sincronización.

DESCRIPCIÓN

glIsSync devuelve GL_TRUE si sync es actualmente el nombre de un objeto de sincronización. Si sync no es el nombre de un objeto de sincronización, o si ocurre un error, glIsSync devuelve GL_FALSE. Tenga en cuenta que cero no es el nombre de un objeto de sincronización.

NOTAS

glIsSync solo está disponible si la versión de GL es 3.2 o superior.
