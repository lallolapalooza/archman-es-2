NOMBRE

glab-config - Gestiona la configuración de glab.

SINOPSIS

glab config [flags]

DESCRIPCIÓN

Gestiona cadenas de clave/valor.

Configuraciones actuales respetadas:

  • browser: Si no está configurado, utiliza el navegador predeterminado. Anula con la variable de entorno $BROWSER.
  • check_update: Si es verdadero, notifica sobre nuevas versiones de glab. El valor predeterminado es verdadero. Anula con la variable de entorno $GLAB_CHECK_UPDATE.
  • display_hyperlinks: Si es verdadero, y se usa un TTY, muestra hipervínculos para problemas y listas de solicitudes de fusión. El valor predeterminado es falso.
  • editor: Si no está configurado, utiliza el editor predeterminado. Anula con la variable de entorno $EDITOR.
  • glab_pager: Tu comando paginador deseado, como 'less -R'.
  • glamour_style: Tu estilo de renderizador de Markdown deseado. Las opciones son dark, light, notty. Hay estilos personalizados disponibles usando glamour ⟨https://github.com/charmbracelet/glamour#styles⟩.
  • host: Si no está configurado, el valor predeterminado es https://gitlab.com.
  • token: Tu token de acceso de GitLab. El valor predeterminado son las variables de entorno.
  • visual: Tiene prioridad sobre 'editor'. Si no está configurado, utiliza el editor predeterminado. Anula con la variable de entorno $VISUAL.

OPCIONES

-g, --global[=false] Usa el archivo de configuración global.

OPCIONES HEREDADAS DE COMANDOS PADRE

-h, --help[=false] Muestra la ayuda para este comando.
