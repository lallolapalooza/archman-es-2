NOMBRE

glDrawElementsInstanced - dibuja múltiples instancias de un conjunto de elementos

ESPECIFICACIÓN C

void glDrawElementsInstanced(GLenum mode, GLsizei count, GLenum type, const void * indices, GLsizei instancecount);

PARÁMETROS

mode

Especifica qué tipo de primitivas se van a renderizar. Se aceptan los símbolos constantes GL_POINTS, GL_LINE_STRIP, GL_LINE_LOOP, GL_LINES, GL_LINE_STRIP_ADJACENCY, GL_LINES_ADJACENCY, GL_TRIANGLE_STRIP, GL_TRIANGLE_FAN, GL_TRIANGLES, GL_TRIANGLE_STRIP_ADJACENCY, GL_TRIANGLES_ADJACENCY y GL_PATCHES.

count

Especifica el número de elementos a renderizar.

type

Especifica el tipo de los valores en indices. Debe ser uno de GL_UNSIGNED_BYTE, GL_UNSIGNED_SHORT o GL_UNSIGNED_INT.

indices

Especifica un puntero a la ubicación donde se almacenan los índices.

instancecount

Especifica el número de instancias del rango de índices especificado que se van a renderizar.

DESCRIPCIÓN

glDrawElementsInstanced se comporta de manera idéntica a glDrawElements() excepto en que se ejecutan instancecount instancias del conjunto de elementos y el valor del contador interno instanceID se incrementa por cada iteración. instanceID es un contador interno de 32 bits que puede ser leído por un shader de vértices como gl_InstanceID.

glDrawElementsInstanced tiene el mismo efecto que:

    si mode, count o type son inválidos
        genera el error apropiado
    else {
        para (int i = 0; i < instancecount ; i++) {
            instanceID = i;
            glDrawElements(mode, count, type, indices);
        }
        instanceID = 0;
    }

NOTAS

glDrawElementsInstanced solo está disponible si la versión de GL es 3.1 o superior.

GL_LINE_STRIP_ADJACENCY, GL_LINES_ADJACENCY, GL_TRIANGLE_STRIP_ADJACENCY y GL_TRIANGLES_ADJACENCY solo están disponibles si la versión de GL es 3.2 o superior.

ERRORES

Se genera GL_INVALID_ENUM si mode no es uno de GL_POINTS, GL_LINE_STRIP, GL_LINE_LOOP, GL_LINES, GL_TRIANGLE_STRIP, GL_TRIANGLE_FAN o GL_TRIANGLES.

Se genera GL_INVALID_VALUE si count o instancecount son negativos.

Se genera GL_INVALID_OPERATION si un shader de geometría está activo y mode es incompatible con el tipo de primitiva de entrada del shader de geometría en el objeto de programa instalado actualmente.

Se genera GL_INVALID_OPERATION si un nombre de objeto de buffer distinto de cero está enlazado a un array habilitado y el almacén de datos del objeto de buffer está actualmente mapeado.
