PARÁMETROS

location

Especifica la ubicación de la variable uniforme que se va a modificar.

count

Para los comandos de vector (glUniform*v), especifica el número de elementos que se van a modificar. Esto debe ser 1 si la variable uniforme de destino no es un array, y 1 o más si es un array.

Para los comandos de matriz (glUniformMatrix*), especifica el número de matrices que se van a modificar. Esto debe ser 1 si la variable uniforme de destino no es un array de matrices, y 1 o más si es un array de matrices.

transpose

Para los comandos de matriz, especifica si se debe transponer la matriz al cargar los valores en la variable uniforme.

v0, v1, v2, v3

Para los comandos escalares, especifica los nuevos valores a usar para la variable uniforme especificada.

value

Para los comandos de vector y matriz, especifica un puntero a un array de count valores que se usarán para actualizar la variable uniforme especificada.

DESCRIPCIÓN

glUniform modifica el valor de una variable uniforme o de un array de variables uniformes. La ubicación de la variable uniforme que se va a modificar se especifica mediante location, que debe ser un valor devuelto por glGetUniformLocation(). glUniform opera sobre el objeto de programa que se hizo parte del estado actual al llamar a glUseProgram().

Los comandos glUniform{1|2|3|4}{f|i|ui} se usan para cambiar el valor de la variable uniforme especificada por location usando los valores pasados como argumentos. El número especificado en el comando debe coincidir con el número de componentes en el tipo de datos de la variable uniforme especificada (por ejemplo, 1 para float, int, unsigned int, bool; 2 para vec2, ivec2, uvec2, bvec2, etc.). El sufijo f indica que se están pasando valores de punto flotante; el sufijo i indica que se están pasando valores enteros; el sufijo ui indica que se están pasando valores enteros sin signo, y este tipo también debe coincidir con el tipo de datos de la variable uniforme especificada. Las variantes i de esta función deben usarse para proporcionar valores para variables uniformes definidas como int, ivec2, ivec3, ivec4, o arreglos de estos. Las ui variantes de esta función deben usarse para proporcionar valores para variables uniformes definidas como unsigned int, uvec2, uvec3, uvec4, o arreglos de estos. Las f variantes deben usarse para proporcionar valores para variables uniformes de tipo float, vec2, vec3, vec4, o arreglos de estos. Las variantes i

, u

i

o f pueden usarse para proporcionar valores para variables uniformes de tipo bool, bvec2, bvec3, bvec4, o arreglos de estos. La variable uniforme se establecerá en false si el valor de entrada es 0 o 0.0f, y se establecerá en true en caso contrario. Todas las variables uniformes activas definidas en un objeto de programa se inicializan a 0 cuando el objeto de programa se vincula correctamente. Conservan los valores asignados por una llamada a glUniform hasta que se produce la siguiente operación de vinculación correcta en el objeto de programa, cuando se vuelven a inicializar a 0. Los comandos glUniform{1|2|3|4}{f|i|ui}v pueden usarse para modificar una variable uniforme individual o un arreglo de variables uniformes. Estos comandos pasan un recuento y un puntero a los valores que se cargarán en una variable uniforme o en un arreglo de variables uniformes. Debe usarse un recuento de 1 si se modifica el valor de una sola variable uniforme, y puede usarse un recuento de 1 o superior para modificar un arreglo completo o parte de un arreglo. Al cargar n elementos a partir de una posición arbitraria m

en un arreglo de variables uniformes, los elementos m +

El número especificado en el nombre del comando indica el número de componentes de cada elemento en value , y debe coincidir con el número de componentes en el tipo de datos de la variable uniforme especificada (por ejemplo, 1 para float, int, bool; 2 para vec2, ivec2, bvec2, etc.).
