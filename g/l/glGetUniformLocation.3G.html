NOMBRE

glGetUniformLocation - Devuelve la ubicación de una variable uniforme

ESPECIFICACIÓN C

GLint glGetUniformLocation(GLuint program, const GLchar *name);

PARÁMETROS

program

Especifica el objeto programa a consultar.

name

Apuntan a una cadena terminada en nulo que contiene el nombre de la variable uniforme cuya ubicación se va a consultar.

DESCRIPCIÓN

glGetUniformLocation devuelve un entero que representa la ubicación de una variable uniforme específica dentro de un objeto programa. name debe ser una cadena terminada en nulo que no contenga espacios en blanco. name debe ser un nombre de variable uniforme activa en program que no sea una estructura, una matriz de estructuras o un subcomponente de un vector o una matriz. Esta función devuelve -1 si name no corresponde a una variable uniforme activa en program, si name comienza con el prefijo reservado "gl_", o si name está asociado con un contador atómico o un bloque uniforme con nombre.

Las variables uniformes que son estructuras o matrices de estructuras se pueden consultar llamando a glGetUniformLocation para cada campo dentro de la estructura. El operador de elemento de matriz "[]" y el operador de campo de estructura "." se pueden usar en name para seleccionar elementos dentro de una matriz o campos dentro de una estructura. El resultado del uso de estos operadores no puede ser otra estructura, una matriz de estructuras o un subcomponente de un vector o una matriz. Excepto si la última parte de name indica una matriz de variables uniformes, la ubicación del primer elemento de una matriz se puede recuperar utilizando el nombre de la matriz, o utilizando el nombre concatenado con "[0]".

Las ubicaciones reales asignadas a las variables uniformes no se conocen hasta que el objeto programa se enlaza correctamente. Después de que se haya producido el enlace, el comando glGetUniformLocation se puede utilizar para obtener la ubicación de una variable uniforme. Este valor de ubicación se puede pasar a glUniform() para establecer el valor de la variable uniforme o a glGetUniform() para consultar el valor actual de la variable uniforme. Después de que un objeto programa se haya enlazado correctamente, los valores de índice para las variables uniformes permanecen fijos hasta que ocurra el próximo comando de enlace. Las ubicaciones y los valores de las variables uniformes solo se pueden consultar después de un enlace si el enlace fue exitoso.

ERRORES

GL_INVALID_VALUE se genera si program no es un valor generado por OpenGL.

GL_INVALID_OPERATION se genera si program no es un objeto programa.

GL_INVALID_OPERATION se genera si program no se ha enlazado correctamente.

OBTENCIÓN ASOCIADA

glGetActiveUniform() con argumentos program y el índice de una variable uniforme activa

glGetProgram() con argumentos program y GL_ACTIVE_UNIFORMS o GL_ACTIVE_UNIFORM_MAX_LENGTH

glGetUniform() con argumentos program y el nombre de una variable uniforme

glIsProgram()
