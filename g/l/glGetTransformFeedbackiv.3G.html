NOMBRE

glGetTransformFeedbackiv - consultar el estado de un objeto de transformación de feedback.

ESPECIFICACIÓN C

void glGetTransformFeedbackiv(GLuint xfb, GLenum pname, GLint *param);

void glGetTransformFeedbacki_v(GLuint xfb, GLenum pname, GLuint index, GLint *param);

void glGetTransformFeedbacki64_v(GLuint xfb, GLenum pname, GLuint index, GLint64 *param);

PARÁMETROS

xfb

El nombre de un objeto de transformación de feedback existente, o cero para el objeto de transformación de feedback predeterminado.

pname

Propiedad a utilizar para la consulta. Debe ser uno de los valores: GL_TRANSFORM_FEEDBACK_BUFFER_BINDING, GL_TRANSFORM_FEEDBACK_BUFFER_START, GL_TRANSFORM_FEEDBACK_BUFFER_SIZE, GL_TRANSFORM_FEEDBACK_PAUSED, GL_TRANSFORM_FEEDBACK_ACTIVE.

index

Índice del flujo de transformación de feedback (para estado indexado).

param

La dirección de un búfer en el que se escribirán los datos de estado solicitados.

DESCRIPCIÓN

Para utilizar la funcionalidad de Transformación de Feedback, necesita configurar las uniones indexadas del Búfer de Transformación de Feedback. Esto se puede lograr utilizando glBindBufferBase o glBindBuffersBase para asociar el almacenamiento completo de un objeto de búfer a uno de los Puntos de Unión de Transformación de Feedback, o llamando a glBindBufferRange o glBindBuffersRange para usar una región del almacenamiento de un objeto de búfer para la unión. Puede optar por (pero no está obligado a) enlazar un Objeto de Transformación de Feedback primero, para almacenar en caché la configuración de unión. Esto generalmente le permite restaurar la configuración de Transformación de Feedback más rápido que si ejecutara una lista de llamadas API necesarias para configurar el estado de Transformación de Feedback de su agrado.

Esta página de referencia discute dos tipos de getters que operan en Objetos de Transformación de Feedback y sus uniones.

La primera clase opera en el punto de unión general de Transformación de Feedback e incluye la función glGetTransformFeedbackiv. glGetTransformFeedbackiv puede usarse para recuperar información sobre el Objeto de Transformación de Feedback enlazado al punto de unión general de Transformación de Feedback, tal como se configuró con una llamada a glBindTransformFeedback. En este caso, puede verificar:

•¿Cuál es el ID del Objeto de Transformación de Feedback actualmente enlazado? (GL_TRANSFORM_FEEDBACK_BUFFER_BINDING)
•¿Está actualmente pausado el proceso de Transformación de Feedback? (GL_TRANSFORM_FEEDBACK_PAUSED)
•¿Se ha iniciado el proceso de Transformación de Feedback y está actualmente en curso? (GL_TRANSFORM_FEEDBACK_ACTIVE)

La última clase, que incluye las funciones glGetTransformFeedbacki_v y glGetTransformFeedbacki64_v, puede usarse para verificar cuál es la configuración actual de cada una de las regiones del objeto de búfer enlazadas a los puntos de unión del Búfer de Transformación de Feedback. Esto le permite consultar la siguiente información:

•Solo glGetTransformFeedbacki_v: ¿Cuál es el ID del Objeto de Búfer enlazado a un Punto de Unión de Transformación de Feedback de índice especificado por el usuario? (GL_TRANSFORM_FEEDBACK_BUFFER_BINDING).
•Solo glGetTransformFeedbacki64_v: ¿Cuál es el desplazamiento de inicio configurado para la unión? (GL_TRANSFORM_FEEDBACK_BUFFER_START);
•Solo glGetTransformFeedbacki64_v: ¿Cuál es la longitud de la región utilizada para la unión? (GL_TRANSFORM_FEEDBACK_BUFFER_SIZE);

ERRORES

Se genera un error GL_INVALID_OPERATION si xfb no es cero ni el nombre de un objeto de transformación de feedback existente.

GL_INVALID_ENUM es generado por glGetTransformFeedbackiv si pname no es GL_TRANSFORM_FEEDBACK_PAUSED o GL_TRANSFORM_FEEDBACK_ACTIVE.

GL_INVALID_ENUM es generado por glGetTransformFeedbacki_v si pname no es GL_TRANSFORM_FEEDBACK_BUFFER_BINDING.

GL_INVALID_ENUM es generado por glGetTransformFeedbacki64_v si pname no es GL_TRANSFORM_FEEDBACK_BUFFER_START o GL_TRANSFORM_FEEDBACK_BUFFER_SIZE.

Se genera un error GL_INVALID_VALUE por glGetTransformFeedbacki_v y glGetTransformFeedbacki64_v si index es mayor o igual que el número de puntos de unión para la transformación de feedback (el valor de GL_MAX_TRANSFORM_FEEDBACK_BUFFERS).
