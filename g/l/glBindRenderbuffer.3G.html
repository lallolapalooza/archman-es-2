GLBINDRENDERBUFFER(3G) [FIXME: manual] GLBINDRENDERBUFFER(3G)

NOMBRE

glBindRenderbuffer - enlaza un buffer de renderizado a un objetivo de buffer de renderizado

ESPECIFICACIÓN EN C

void glBindRenderbuffer(GLenum target, GLuint renderbuffer);

PARÁMETROS

target

Especifica el objetivo del buffer de renderizado de la operación de enlazado. target debe ser GL_RENDERBUFFER.

renderbuffer

Especifica el nombre del objeto de buffer de renderizado a enlazar.

DESCRIPCIÓN

glBindRenderbuffer enlaza el objeto de buffer de renderizado con el nombre renderbuffer al objetivo de buffer de renderizado especificado por target. target debe ser GL_RENDERBUFFER. renderbuffer es el nombre de un objeto de buffer de renderizado devuelto previamente por una llamada a glGenRenderbuffers(), o cero para romper el enlace existente de un objeto de buffer de renderizado a target.

ERRORES

Se genera GL_INVALID_ENUM si target no es GL_RENDERBUFFER.

Se genera GL_INVALID_OPERATION si renderbuffer no es cero o el nombre de un buffer de renderizado devuelto previamente por una llamada a glGenRenderbuffers().
