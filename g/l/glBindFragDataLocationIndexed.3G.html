DESCRIPCIÓ

N

glBindFragDataLocationIndexed especifica que la variable varying out name en program debe vincularse al color de fragmento colorNumber cuando el programa se vuelva a enlazar. index puede ser cero o uno para especificar que el color se utilice como primera o segunda entrada de color a la ecuación de mezcla, respectivamente

.

Los enlaces especificados por glBindFragDataLocationIndexed no tienen efecto hasta que program se vuelva a enlazar. Los enlaces pueden especificarse en cualquier momento después de que program haya sido creado. Específicamente, pueden especificarse antes de que los objetos de shader se adjunten al programa. Por lo tanto, cualquier nombre puede especificarse en name, incluido un nombre que nunca se utilice como variable varying out en ningún objeto de shader de fragmentos. Los nombres que comienzan con gl_ están reservados por

GL.

Si name fue vinculado previamente, su enlace asignado se reemplaza con colorNumber y index. name debe ser una cadena terminada en nulo. index debe ser menor o igual que uno, y colorNumber debe ser menor que el valor de GL_MAX_DRAW_BUFFERS si index es cero, y menor que el valor de GL_MAX_DUAL_SOURCE_DRAW_BUFFERS si index es mayor o igual que

uno.

Además de los errores generados por glBindFragDataLocationIndexed, el programa program fallará al enlazar

si:
•El número de salidas activas es mayor que el valor GL_MAX_DRAW_BUFFERS
.

ying out está vinculada a
l mismo número de color.

S

Las variables varying out pueden tener ubicaciones asignadas explícitamente en el texto del shader usando un calificador de ubicación (location layout qualifier). Si un shader asigna estáticamente una ubicación a una variable varying out en el texto del shader, se utiliza esa ubicación y se ignora cualquier ubicación asignada con glBindFragDa

taLoc

uno.

Se genera GL_INVALID_VALUE si index es mayor que

Se genera GL_INVALID_OPERATION si name comienza con el prefijo reservado gl_
