NOMBRE

glabels - Programa de creación de etiquetas y tarjetas de visita para GNOME

SINOPSIS

glabels-3 [OPCIONES] [archivo-de-etiquetas...]

glabels-3-batch [OPCIONES] [archivo-de-etiquetas...]

DESCRIPCIÓN

glabels-3 es un programa ligero para la creación de etiquetas y tarjetas de visita para el entorno de escritorio GNOME. Está diseñado para funcionar con varias hojas de etiquetas y tarjetas de visita extraíbles para láser/inyección de tinta que se encuentran en la mayoría de las tiendas de suministros de oficina. glabels-3 está preconfigurado con plantillas para muchos de estos productos. También proporciona un diseñador de plantillas interactivo para crear nuevas plantillas según las especificaciones del usuario.

Para una documentación completa, consulte la ayuda en línea de gLabels.

glabels-3-batch es una utilidad de línea de comandos para imprimir etiquetas preparadas previamente con glabels-3.

OPCIONES

-?, --help
Muestra un resumen de las opciones de línea de comandos disponibles.
--usage
Muestra un resumen de uso breve.
-v, --version
Imprime información de la versión del programa.

Opciones específicas de glabels-batch

-o nombre-archivo, --output=nombre-archivo
Establece el nombre del archivo de salida a nombre-archivo. (por defecto="output.ps")
-s n, --sheets=n
Establece el número de hojas a n. (por defecto=1)
-c n, --copies=n
Establece el número de copias a n. (por defecto=1)
-f n, --first=n
Establece la etiqueta en la primera hoja desde la que empezar a imprimir a n. (por defecto=1)
-l, --outline
Imprime contornos alrededor de las etiquetas. Esto es útil para probar la alineación de la impresora o imprimir hojas de prueba.
-r, --reverse
Imprime una imagen especular de las etiquetas. Esto es útil para etiquetas transparentes destinadas a ser vistas desde atrás a través del cristal.

ARCHIVOS

El directorio $HOME/.config/libglabels/templates contiene todas las plantillas definidas por el usuario.

VER TAMBIÉN

La página de inicio de gLabels en http://glabels.org/.
