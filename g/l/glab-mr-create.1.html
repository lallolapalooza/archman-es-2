NOMBRE

glab-mr-create - Crea una nueva solicitud de fusión.

SINOPSIS

glab mr create [flags]

DESCRIPCIÓN

Crea una nueva solicitud de fusión.

OPCIONES

--allow-collaboration[=false] Permite commits de otros miembros.

-a, --assignee=[] Asigna la solicitud de fusión a personas por sus nombres de usuario. Se pueden separar varios nombres de usuario con comas o especificándolos repitiendo la opción.

--copy-issue-labels[=false] Copia las etiquetas del problema a la solicitud de fusión. Se usa con --related-issue.

--create-source-branch[=false] Crea una rama de origen si no existe.

-d, --description="" Proporciona una descripción para la solicitud de fusión.

--draft[=false] Marca la solicitud de fusión como borrador.

-f, --fill[=false] No solicita título ni descripción, y solo usa la información del commit. Establece push a true y hace push de la rama.

--fill-commit-body[=false] Rellena la descripción con el cuerpo de cada commit cuando hay varios commits. Solo se puede usar con --fill.

-H, --head="" Selecciona otro repositorio de origen usando el formato PROPIETARIO/REPO o GRUPO/NAMESPACE/REPO, el ID del proyecto o la URL completa.

-l, --label=[] Añade una etiqueta por nombre. Se pueden separar varias etiquetas con comas o especificándolas repitiendo la opción.

-m, --milestone="" El ID global o el título de un hito a asignar.

--no-editor[=false] No abre el editor para introducir una descripción. Si es verdadero, usa el prompt. Por defecto es falso.

--push[=false] Hace push de los cambios confirmados después de crear la solicitud de fusión. Asegúrate de haber confirmado cambios.

--recover[=false] Guarda las opciones en un archivo si la creación de la solicitud de fusión falla. Si el archivo existe, las opciones se cargan del archivo de recuperación. (EXPERIMENTAL)

-i, --related-issue="" Crea una solicitud de fusión para un problema. Si no se proporciona --title, usa el título del problema.

--remove-source-branch[=false] Elimina la rama de origen al fusionar.

--reviewer=[] Solicita revisión a usuarios por sus nombres de usuario. Se pueden separar varios nombres de usuario con comas o especificándolos repitiendo la opción.

--signoff[=false] Añade una firma DCO a la descripción de la solicitud de fusión.

-s, --source-branch="" Crea una solicitud de fusión desde esta rama. Por defecto es la rama actual.

--squash-before-merge[=false] Fusiona los commits en un solo commit al fusionar.

-b, --target-branch="" La rama de destino o base en la que deseas fusionar tu código.

-t, --title="" Proporciona un título para la solicitud de fusión.

-w, --web[=false] Continúa la creación de la solicitud de fusión en un navegador.

--wip[=false] Marca la solicitud de fusión como borrador. Alternativa a --draft.

-y, --yes[=false] Omite la pregunta de confirmación de envío. Usa --fill para omitir todas las preguntas opcionales.

OPCIONES HEREDADAS DE COMANDOS PADRE

-h, --help[=false] Muestra la ayuda para este comando.

-R, --repo="" Selecciona otro repositorio. Puede usar el formato PROPIETARIO/REPO o GRUPO/NAMESPACE/REPO. También acepta URL completa o URL de Git.

EJEMPLO

$ glab mr new
$ glab mr create -a username -t "arreglar molesto bug"
$ glab mr create -f --draft --label RFC
$ glab mr create --fill --web
$ glab mr create --fill --fill-commit-body --yes
