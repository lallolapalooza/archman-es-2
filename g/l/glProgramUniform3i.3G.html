NAME

glProgramUniform4iv — set the value of a uniform variable in an active program object

C SPECIFICATION

void glProgramUniform4iv( GLuint program, GLint location, GLsizei count, const GLint *value );

PARAMETERS

program
Specifies the program object whose uniform variables will be modified.
location
Specifies the location of the uniform variable to be modified.
count
Specifies the number of elements that are to be modified. Should be 1 if the uniform variable is not an array. If value corresponds to the uniform variable named name[i], then the maximum legal value for count is determined by the glGetProgramiv query for GL_MAX_ARRAY_TEXTURE_LAYERS. If name is not an array variable, count must be 1.
value
Specifies a pointer to an array of count values that will be used to form the list of uniform variable values.

DESCRIPTION

glProgramUniform4iv, glProgramUniformMatrix2x3iv, etc. set the value of a uniform variable or a uniform variable array. These commands operate on uniform variables that belong to program objects. They do not affect the active program object.

If program is not zero, it is the name of a program object that has been linked successfully. If program is zero, the uniform variables are updated in the currently active program object.

The commands differ in the number of components in the uniform variable. The commands ending in 1i, 1iv set a single integer uniform variable. The commands ending in 2i, 2iv set a vec2i uniform variable. The commands ending in 3i, 3iv set a vec3i uniform variable. The commands ending in 4i, 4iv set a vec4i uniform variable.

The commands ending in Matrix set uniform variables which are matrices. The ending of the command specifies the dimensions of the matrix. For example, glProgramUniformMatrix3x2iv sets a 3x2 matrix.

The v suffix on the command name indicates that the uniform variable values are passed as a pointer to an array of values. The non-v suffixed commands take the values directly as arguments.

If the uniform variable is an array, the command can be used to update one or more elements of the array. count specifies the number of elements to update, and value points to the first element to be updated. For non-array uniform variables, count must be 1.

If the program object is not active, the value of the uniform variable is updated in the specified program object.

If the program object is active, the value of the uniform variable is updated in the active program object.

If location is not valid for the specified program object, or if program is not the name of a program object that has been linked successfully, then a GL error is generated.

The uniform variable is specified by location, which is obtained by calling glGetUniformLocation.

The value of a uniform variable is updated with the specified values.

These commands require:

  • Version 2.0 of OpenGL Core Profile
  • Version 4.0 of OpenGL

ERRORS

A GL error GL_INVALID_VALUE is generated if program is not zero and is not the name of a valid program object.

A GL error GL_INVALID_OPERATION is generated if program is not zero and has not been linked successfully.

A GL error GL_INVALID_OPERATION is generated if program is zero and no program object is active.

A GL error GL_INVALID_OPERATION is generated if location is not a valid uniform location for the specified program.

A GL error GL_INVALID_VALUE is generated if count is less than zero.

A GL error GL_INVALID_VALUE is generated if count is greater than 1 and the indicated uniform variable is not an array.
