NOMBRE

glab-mr-list - Listar solicitudes de fusión.

SINOPSIS

glab mr list [banderas]

DESCRIPCIÓN

Listar solicitudes de fusión.

OPCIONES

-A, --all[=false] Obtener todas las solicitudes de fusión.

-a, --assignee=[] Obtener solo solicitudes de fusión asignadas a usuarios. Se pueden especificar varios usuarios separados por comas o repitiendo la bandera.

--author="" Filtrar solicitud de fusión por autor.

-c, --closed[=false] Obtener solo solicitudes de fusión cerradas.

-d, --draft[=false] Filtrar por solicitudes de fusión en borrador.

-g, --group="" Seleccionar un grupo/subgrupo. Esta opción se ignora si se establece un argumento de repositorio.

-l, --label=[] Filtrar solicitud de fusión por etiqueta. Se pueden especificar varias etiquetas separadas por comas o repitiendo la bandera.

-M, --merged[=false] Obtener solo solicitudes de fusión fusionadas.

-m, --milestone="" Filtrar solicitud de fusión por hito.

--not-draft[=false] Filtrar por solicitudes de fusión que no sean borradores.

--not-label=[] Filtrar solicitudes de fusión por no tener la etiqueta. Se pueden especificar varias etiquetas separadas por comas o repitiendo la bandera.

-o, --order="" Ordenar solicitudes de fusión por. Opciones de ordenación: created_at, title, merged_at o updated_at.

-F, --output="text" Formatear salida como: text, json.

-p, --page=1 Número de página.

-P, --per-page=30 Número de elementos a listar por página.

-R, --repo="" Seleccionar otro repositorio. Se puede usar el formato PROPIETARIO/REPO o GRUPO/NOMBRE_DE_ESPACIO/REPO. También acepta URL completas o URL de Git.

-r, --reviewer=[] Obtener solo solicitudes de fusión con usuarios como revisores. Se pueden especificar varios usuarios separados por comas o repitiendo la bandera.

--search="" Filtrar por título y descripción.

-S, --sort="" Ordenar solicitudes de fusión por. Opciones de ordenación: asc, desc.

-s, --source-branch="" Filtrar por rama de origen.

-t, --target-branch="" Filtrar por rama de destino.

OPCIONES HEREDADAS DE COMANDOS PADRE

-h, --help[=false] Mostrar ayuda para este comando.

EJEMPLO

$ glab mr list --all
$ glab mr ls -a
$ glab mr list --assignee=@me
$ glab mr list --reviewer=@me
$ glab mr list --source-branch=new-feature
$ glab mr list --target-branch=main
$ glab mr list --search "esto añade la característica X"
$ glab mr list --label necesita-revisión
$ glab mr list --not-label esperando-feedback-mantenedor,subsistema-x
$ glab mr list -M --per-page 10
$ glab mr list --draft
$ glab mr list --not-draft
