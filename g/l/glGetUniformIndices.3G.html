NOMBRE

glGetUniformIndices - recupera el índice de un bloque uniforme nombrado

ESPECIFICACIÓN C

void glGetUniformIndices(GLuint program, GLsizei uniformCount, const GLchar **uniformNames, GLuint *uniformIndices);

PARÁMETROS

program

Especifica el nombre de un programa que contiene uniformes cuyos índices se consultarán.

uniformCount

Especifica el número de uniformes cuyos índices se consultarán.

uniformNames

Especifica la dirección de un array de punteros a buffers que contienen los nombres de los uniformes consultados.

uniformIndices

Especifica la dirección de un array que recibirá los índices de los uniformes.

DESCRIPCIÓN

glGetUniformIndices recupera los índices de varios uniformes dentro de program.

program debe ser el nombre de un objeto de programa para el cual el comando glLinkProgram() debe haber sido llamado en el pasado, aunque no es obligatorio que glLinkProgram() haya tenido éxito. El enlace podría haber fallado porque el número de uniformes activos excedió el límite.

uniformCount indica tanto el número de elementos en el array de nombres uniformNames como el número de índices que se pueden escribir en uniformIndices.

uniformNames contiene una lista de uniformCount cadenas de nombres que identifican los nombres de los uniformes cuyos índices se consultarán. Para cada cadena de nombre en uniformNames, el índice asignado al uniforme activo de ese nombre se escribirá en el elemento correspondiente de uniformIndices. Si una cadena en uniformNames no es el nombre de un uniforme activo, el valor especial GL_INVALID_INDEX se escribirá en el elemento correspondiente de uniformIndices.

Si ocurre un error, no se escribe nada en uniformIndices.

ERRORES

GL_INVALID_OPERATION se genera si program no es el nombre de un objeto de programa para el cual glLinkProgram() se ha llamado en el pasado.

NOTAS

glGetUniformIndices solo está disponible si la versión de GL es 3.1 o superior.
