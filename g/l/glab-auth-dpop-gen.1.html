NOMBRE

glab-auth-dpop-gen - Genera una prueba JWT de DPoP (demonstrating-proof-of-possession). (EXPERIMENTAL)

SINOPSIS

glab auth dpop-gen [flags]

DESCRIPCIÓN

La demostración de posesión (DPoP) es una técnica para vincular criptográficamente los tokens de acceso personal con sus propietarios. Este comando proporciona las herramientas para gestionar los aspectos del cliente de DPoP. Genera una prueba JWT (JSON Web Token) de DPoP.

Requisitos previos:

  • Debes tener un par de claves SSH en formato RSA, ed25519 o ECDSA.
  • Debes haber habilitado DPoP para tu cuenta, como se describe en la documentación de GitLab. ⟨https://docs.gitlab.com/user/profile/personal_access_tokens/#require-dpop-headers-with-personal-access-tokens⟩

Utiliza el JWT en combinación con un Token de Acceso Personal (PAT) para autenticarte en la API de GitLab. Tu JWT seguirá siendo válido durante 5 minutos. Después de que expire, deberás generar otro token. Tu clave privada SSH se utilizará para firmar el JWT.

Esta característica es experimental. Podría estar rota o eliminarse sin previo aviso. Lee más sobre lo que significan las características experimentales en https://docs.gitlab.com/policy/development_stages_support/

Usa las características experimentales bajo tu propio riesgo.

OPCIONES

--hostname="gitlab.com" El nombre de host de la instancia de GitLab con la que autenticarse. Por defecto es 'gitlab.com'.

--pat="" Token de Acceso Personal (PAT) para generar una prueba DPoP. Por defecto es el token establecido con 'glab auth login'. Devuelve un error si ambos están vacíos.

-p, --private-key="" Ubicación de la clave SSH privada en el sistema local.

OPCIONES HEREDADAS DE COMANDOS PADRE

-h, --help[=false] Muestra la ayuda para este comando.

EJEMPLO

# Genera un JWT DPoP para autenticación en GitLab
$ glab auth dpop-gen [flags]
$ glab auth dpop-gen --private-key "~/.ssh/id_rsa" --pat "glpat-xxxxxxxxxxxxxxxxxxxx"
# No se requiere PAT si anteriormente utilizaste el comando 'glab auth login' con un PAT
$ glab auth dpop-gen --private-key "~/.ssh/id_rsa"
# Genera un JWT DPoP para una instancia de GitLab diferente
$ glab auth dpop-gen --private-key "~/.ssh/id_rsa" --hostname "https://gitlab.com"
