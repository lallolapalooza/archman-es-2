GLTEXBUFFERRANGE(3G) [FIXME: manual] GLTEXBUFFERRANGE(3G)

NOMBRE

glTexBufferRange, glTextureBufferRange - adjuntar un rango del almacenamiento de datos de un objeto de búfer a un objeto de textura de búfer

ESPECIFICACIÓN C

void glTexBufferRange(GLenum target, GLenum internalformat, GLuint buffer, GLintptr offset, GLsizeiptr size);

void glTextureBufferRange(GLuint texture, GLenum internalformat, GLuint buffer, GLintptr offset, GLsizei size);

PARÁMETROS

target

Especifica el destino al que se enlaza el objeto de textura para glTexBufferRange. Debe ser GL_TEXTURE_BUFFER.

texture

Especifica el nombre del objeto de textura para glTextureBufferRange.

internalformat

Especifica el formato interno de los datos en el almacenamiento perteneciente a buffer.

buffer

Especifica el nombre del objeto de búfer cuyo almacenamiento se adjuntará a la textura de búfer activa.

offset

Especifica el desplazamiento del inicio del rango del almacenamiento de datos del búfer a adjuntar.

size

Especifica el tamaño del rango del almacenamiento de datos del búfer a adjuntar.

DESCRIPCIÓN

glTexBufferRange y glTextureBufferRange adjuntan un rango del almacenamiento de datos de un objeto de búfer especificado a un objeto de textura especificado, y especifican el formato de almacenamiento para la imagen de textura encontrada en el objeto de búfer. El objeto de textura debe ser una textura de búfer.

Si buffer es cero, cualquier objeto de búfer adjunto a la textura de búfer se desvincula y no se adjunta ningún objeto de búfer nuevo. Si buffer no es cero, debe ser el nombre de un objeto de búfer existente.

El inicio y el tamaño del rango se especifican por offset y size respectivamente, ambos medidos en unidades básicas de máquina. offset debe ser mayor o igual a cero, size debe ser mayor que cero, y la suma de offset y size no debe exceder el valor de GL_BUFFER_SIZE para buffer. Además, offset debe ser un múltiplo entero del valor de GL_TEXTURE_BUFFER_OFFSET_ALIGNMENT.

Cuando se adjunta un rango de un objeto buffer a una textura buffer, el rango especificado del almacén de datos del objeto buffer se toma como el arreglo de texels de la textura. El número de texels en el arreglo de texels de la textura buffer viene dado por $$ \left\lfloor { size \over { components \times sizeof(base\_type) } } \right\rfloor $$ donde $components$ y $base\_type$ son el número de elementos y el tipo de datos base de los elementos, como se especifica en la tabla anterior. El número de texels en el arreglo de texels se limita entonces al valor del límite dependiente de la implementación GL_MAX_TEXTURE_BUFFER_SIZE. Cuando se accede a una textura buffer en un shader, los resultados de una obtención de texel son indefinidos si la coordenada de texel especificada es negativa, o mayor o igual que el número limitado de texels en el arreglo de texels.

ERRORES

GL_INVALID_ENUM se genera por glTexBufferRange si target no es GL_TEXTURE_BUFFER.

GL_INVALID_OPERATION se genera por glTextureBufferRange si texture no es el nombre de una textura existente.

GL_INVALID_ENUM se genera por glTextureBufferRange si el destino efectivo de texture no es GL_TEXTURE_BUFFER.

GL_INVALID_ENUM se genera si internalformat no es uno de los formatos internos con tamaño descritos anteriormente.

GL_INVALID_OPERATION se genera si buffer no es cero y no es el nombre de un objeto buffer existente.

GL_INVALID_VALUE se genera si offset es negativo, si size es menor o igual a cero, o si offset + size es mayor que el valor de GL_BUFFER_SIZE para buffer.

GL_INVALID_VALUE se genera si offset no es un múltiplo entero del valor de GL_TEXTURE_BUFFER_OFFSET_ALIGNMENT.

OBTENCIONES ASOCIADAS

glGet() con el argumento GL_TEXTURE_BUFFER_OFFSET_ALIGNMENT

glGetTexLevelParameter() con los argumentos GL_TEXTURE_BUFFER_OFFSET o GL_TEXTURE_BUFFER_SIZE.
