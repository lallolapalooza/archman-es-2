glutCopyColormap(3)

Paquete: freeglut

Licencias: X11

glutCopyColormap(3) freeglut glutCopyColormap(3)

NOMBRE

glutCopyColormap - copia el mapa de colores lógico para la capa en uso desde una ventana especificada a la ventana actual.

SINTAXIS

void glutCopyColormap(int win);

ARGUMENTOS

win
El identificador de la ventana desde la cual copiar el mapa de colores lógico.

DESCRIPCIÓN

glutCopyColormap copia (de forma perezosa si es posible para promover el uso compartido) el mapa de colores lógico de una ventana especificada a la capa en uso de la ventana actual. La copia se realizará del plano normal al plano normal; o de la superposición a la superposición (nunca entre capas diferentes). Una vez que se ha copiado un mapa de colores, evite establecer celdas en el mapa de colores con glutSetColor, ya que esto forzará una copia real del mapa de colores si se copió anteriormente por referencia. glutCopyColormap solo debe llamarse cuando tanto la ventana actual como la ventana `win` sean ventanas de índice de color.

EJEMPLO

Aquí hay un ejemplo de cómo crear dos ventanas GLUT de índice de color con sus mapas de colores cargados idénticamente y de manera que las ventanas probablemente compartan el mismo mapa de colores:

  int win1, win2;
  glutInitDisplayMode(GLUT_INDEX);
  win1 = glutCreateWindow("primera ventana índice de color");
  glutSetColor(0, 0.0, 0.0, 0.0);  /* negro */
  glutSetColor(1, 0.5, 0.5, 0.5);  /* gris */
  glutSetColor(2, 1.0, 1.0, 1.0);  /* blanco */
  glutSetColor(3, 1.0, 0.0, 0.0);  /* rojo */
  win2 = glutCreateWindow("segunda ventana índice de color");
  glutCopyColormap(win1);

VER TAMBIÉN

glutSetColor, glutGetColor, glutCreateWindow
