NOMBRE

glBindBuffersRange - enlaza rangos de uno o más objetos de búfer a una secuencia de objetivos de búfer indexados

ESPECIFICACIÓN C

void glBindBuffersRange(GLenumtarget, GLuintfirst, GLsizeicount, const GLuint *buffers, const GLintptr *offsets, const GLintptr *sizes);

PARÁMETROS

target

Especifica el objetivo de la operación de enlace. target debe ser uno de GL_ATOMIC_COUNTER_BUFFER, GL_TRANSFORM_FEEDBACK_BUFFER, GL_UNIFORM_BUFFER o GL_SHADER_STORAGE_BUFFER.

first

Especifica el índice del primer punto de enlace dentro del array especificado por target.

count

Especifica el número de puntos de enlace contiguos a los cuales enlazar búferes.

buffers

Un puntero a un array de nombres de objetos de búfer para enlazar a los objetivos en el punto de enlace especificado, o NULL.

offsets

Un puntero a un array de desplazamientos dentro del búfer correspondiente en buffers para enlazar, o NULL si buffers es NULL.

sizes

Un puntero a un array de tamaños del búfer correspondiente en buffers para enlazar, o NULL si buffers es NULL.

DESCRIPCIÓN

glBindBuffersRange enlaza un conjunto de count rangos de objetos de búfer cuyos nombres se dan en el array buffers a los count puntos de enlace consecutivos comenzando desde el índice first del array de objetivos especificado por target. offsets especifica la dirección de un array que contiene count desplazamientos iniciales dentro de los búferes, y sizes especifica la dirección de un array de count tamaños de los rangos. Si buffers es NULL entonces offsets y sizes se ignoran y glBindBuffersRange desenlaza cualquier búfer que esté actualmente enlazado a los puntos de enlace referenciados. Asumiendo que no se generan errores, es equivalente al siguiente pseudocódigo, que llama a glBindBufferRange(), con la excepción de que el objetivo no indexado target no es cambiado por glBindBuffersRange:

    for (i = 0; i < count; i++) {
        if (buffers != NULL) {
            glBindBufferRange(target, first + i, buffers[i], offsets[i], sizes[i]);
        } else {
            glBindBufferRange(target, first + i, 0);
        }
    }

Cada entrada en buffers, offsets, y sizes será verificada individualmente y si se encuentra que es inválida, el estado para ese índice de enlace de búfer no será cambiado y se generará un error. Sin embargo, el estado para otros índices de enlace de búfer referenciados por el comando seguirá siendo actualizado.

NOTAS

glBindBuffersBase está disponible solo si la versión de GL es 4.4 o superior.

ERRORES

GL_INVALID_ENUM se genera si target no es GL_ATOMIC_COUNTER_BUFFER, GL_TRANSFORM_FEEDBACK_BUFFER, GL_UNIFORM_BUFFER o GL_SHADER_STORAGE_BUFFER.

GL_INVALID_OPERATION se genera si first + count es mayor que el número de puntos de enlace indexados específicos del objetivo.

GL_INVALID_OPERATION se genera si cualquier valor en buffers no es cero o el nombre de un objeto de búfer existente.

GL_INVALID_VALUE se genera si cualquier valor en offsets es menor que cero o si cualquier valor en sizes es menor que cero.

GL_INVALID_VALUE se genera si cualquier par de valores en offsets y sizes no satisface respectivamente las restricciones descritas para esos parámetros para el objetivo especificado.
