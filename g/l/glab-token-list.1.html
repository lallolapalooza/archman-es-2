NOMBRE

glab-token-list - Listar tokens de acceso de usuario, grupo o proyecto.

SINOPSIS

glab token list [flags]

DESCRIPCIÓN

Lista todos los tokens de un usuario, grupo o proyecto.

La salida contiene metadatos del token, no el valor real del token. El formato de salida puede ser "JSON" o "text". El nivel de acceso se imprime en formato legible en la salida de texto, pero muestra el valor entero en JSON.

Los administradores pueden listar tokens de otros usuarios.

OPCIONES

-a, --active[=false] Listar solo los tokens activos.

-g, --group="" Listar tokens de acceso de grupo. Ignorado si se establece un argumento de usuario o repositorio.

-F, --output="text" Formatear la salida como: text, json. text proporciona una tabla legible, json imprime los tokens con metadatos.

-R, --repo="" Seleccionar otro repositorio. Puede usar el formato PROPIETARIO/REPO o GRUPO/NAMESPACE/REPO. También acepta URL completa o URL de Git.

-U, --user="" Listar tokens de acceso personal. Use @me para el usuario actual.

OPCIONES HEREDADAS DE COMANDOS PADRE

-h, --help[=false] Mostrar ayuda para este comando.

EJEMPLO

# Listar los tokens de acceso del proyecto actual
$ glab token list
$ glab token list --output json
# Listar los tokens de acceso del proyecto de un proyecto específico
$ glab token list --repo user/my-repo
# Listar tokens de acceso de grupo
$ glab token list --group group/sub-group
# Listar mis tokens de acceso personal
$ glab token list --user @me
# Solo administradores: listar los tokens de acceso personal de otro usuario
$ glab token list --user johndoe
