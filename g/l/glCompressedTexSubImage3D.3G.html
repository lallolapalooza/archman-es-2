GLCOMPRESSEDTEXSUBIM(3G) [FIXME: manual] GLCOMPRESSEDTEXSUBIM(3G)

NOMBRE

glCompressedTexSubImage3D, glCompressedTextureSubImage3D - especifica una subimagen de textura tridimensional en formato comprimido

C ESPECIFICACIÓN

void glCompressedTexSubImage3D(GLenum target, GLint level, GLint xoffset, GLint yoffset, GLint zoffset, GLsizei width, GLsizei height, GLsizei depth, GLenum format, GLsizei imageSize, const void * data);

void glCompressedTextureSubImage3D(GLuint texture, GLint level, GLint xoffset, GLint yoffset, GLint zoffset, GLsizei width, GLsizei height, GLsizei depth, GLenum format, GLsizei imageSize, const void *data);

PARÁMETROS

target

Especifica el destino al que se enlaza la textura para la función glCompressedTexSubImage3D. Debe ser GL_TEXTURE_2D_ARRAY, GL_TEXTURE_3D, o GL_TEXTURE_CUBE_MAP_ARRAY.

texture

Especifica el nombre del objeto de textura para la función glCompressedTextureSubImage3D.

level

Especifica el número de nivel de detalle. El nivel 0 es el nivel de imagen base. El nivel n es la n-ésima imagen de reducción mipmap.

xoffset

Especifica un desplazamiento de texel en la dirección x dentro del array de texturas.

yoffset

Especifica un desplazamiento de texel en la dirección y dentro del array de texturas.

zoffset

Especifica un desplazamiento de texel en la dirección z dentro del array de texturas.

width

Especifica el ancho de la subimagen de textura.

height

Especifica la altura de la subimagen de textura.

depth

Especifica la profundidad de la subimagen de textura.

format

Especifica el formato de los datos de imagen comprimidos almacenados en la dirección data.

imageSize

Especifica el número de bytes sin signo de datos de imagen que comienzan en la dirección especificada por data.

data

Especifica un puntero a los datos de imagen comprimidos en memoria.

DESCRIPCIÓN

La texturización permite leer elementos de un array de imágenes mediante shaders.

glCompressedTexSubImage3D y glCompressedTextureSubImage3D redefinen una subregión contigua de una imagen de textura tridimensional existente. Los texeles referenciados por data reemplazan la porción del array de texturas existente con índices x xoffset y xoffset + width - 1, e índices y yoffset y yoffset + height - 1, e índices z zoffset y zoffset + depth - 1, inclusive. Esta región no puede incluir ningún texel fuera del rango del array de texturas tal como se especificó originalmente. No es un error especificar una subtextura con un ancho de 0, pero tal especificación no tiene efecto.

internalformat debe ser un formato de imagen comprimido conocido (como GL_RGTC) o un formato de textura comprimida especificado por una extensión. El format de la imagen de textura comprimida es seleccionado por la implementación de GL que la comprimió (ver glTexImage3D()) y debe ser consultado en el momento en que la textura se comprimió con glGetTexLevelParameter().

Si un objeto de buffer nombrado no nulo está enlazado al destino GL_PIXEL_UNPACK_BUFFER (ver glBindBuffer()) mientras se especifica una imagen de textura, data se trata como un desplazamiento de bytes dentro del almacén de datos del objeto de buffer.

ERRORES

GL_INVALID_ENUM se genera si internalformat es uno de los formatos internos comprimidos genéricos: GL_COMPRESSED_RED, GL_COMPRESSED_RG, GL_COMPRESSED_RGB, GL_COMPRESSED_RGBA. GL_COMPRESSED_SRGB, o GL_COMPRESSED_SRGB_ALPHA.

GL_INVALID_ENUM es generado por glCompressedTexSubImage3D si target no es GL_TEXTURE_2D_ARRAY, GL_TEXTURE_3D, o GL_TEXTURE_CUBE_MAP_ARRAY.

GL_INVALID_OPERATION es generado por glCompressedTextureSubImage3D si texture no es el nombre de un objeto de textura existente.

GL_INVALID_VALUE se genera si imageSize no es consistente con el formato, las dimensiones y el contenido de los datos de imagen comprimidos especificados.

GL_INVALID_OPERATION se genera si las combinaciones de parámetros no son compatibles con el formato interno comprimido específico, según lo especificado en la extensión de compresión de textura específica.

GL_INVALID_OPERATION se genera si un objeto de buffer con nombre no nulo está enlazado al destino GL_PIXEL_UNPACK_BUFFER y el almacén de datos del objeto de buffer está actualmente mapeado.

GL_INVALID_OPERATION se genera si un objeto de buffer con nombre no nulo está enlazado al destino GL_PIXEL_UNPACK_BUFFER y los datos se desempaquetarían del objeto de buffer de tal manera que las lecturas de memoria requeridas excederían el tamaño del almacén de datos.

Se generan resultados indefinidos, incluida la terminación anormal del programa, si data no está codificado de manera consistente con la especificación de la extensión que define el formato de compresión interno.

GETS ASOCIADOS
