NAME

glMapNamedBufferRange - map all or part of a buffer object's data store into the client's address space

C SPECIFICATION

void glMapNamedBufferRange(GLuint buffer, GLintptr offset, GLsizeiptr length, GLbitfield access);

PARAMETERS

• buffer: The buffer object.

• offset: The offset of the buffer range that is to be mapped into the client's address space.

• length: The length of the buffer range that is to be mapped into the client's address space.

• access: A bitwise combination of the flags indicating the access pattern of the buffer's data store.

DESCRIPTION

glMapNamedBufferRange maps the data store of the buffer object specified by buffer into the client's address space and returns a pointer to the beginning of the mapped range. The buffer object must be an existing buffer object.

The range of the buffer object to be mapped is specified by offset and length. offset specifies the starting offset of the range, and length specifies the number of basic memory units whose contents are to be mapped. The value of offset must be a multiple of the value of GL_MIN_MAP_BUFFER_ALIGNMENT.

The access argument specifies the desired access to the buffer's data store. It is a bitwise OR of the following values:

GL_MAP_READ_BIT
Indicates that the returned pointer can be used to read from the buffer's data store.
GL_MAP_WRITE_BIT
Indicates that the returned pointer can be used to write to the buffer's data store.
GL_MAP_PERSISTENT_BIT
Indicates that the buffer's data store is a persistent mapping. The buffer can be accessed by both the client and the client API without explicit synchronization until glUnmapBuffer is called. Requires the buffer to be created with glBufferStorage. See NOTES.
GL_MAP_COHERENT_BIT
Indicates that memory accesses to the buffer's data store are coherent. The buffer can be accessed by both the client and the client API without explicit synchronization until glUnmapBuffer is called. Requires the buffer to be created with glBufferStorage and must be used with GL_MAP_PERSISTENT_BIT. See NOTES.
GL_MAP_FLUSH_EXPLICIT_BIT
Indicates that explicit calls to glFlushMappedBufferRange are required to flush modified regions of the buffer's data store. If this flag is not set, any modifications to the buffer's data store may be flushed by the GL at any time without explicit indication. Requires the buffer to be created with glBufferStorage and must be used with GL_MAP_WRITE_BIT.
GL_MAP_INVALIDATE_RANGE_BIT
Indicates that the contents of the mapped range are not useful to the application and can be discarded. This is a hint to the GL that it may discard the contents of the range, and may allocate new memory for the buffer's data store. This flag can only be used with GL_MAP_WRITE_BIT.
GL_MAP_INVALIDATE_BUFFER_BIT
Indicates that the entire contents of the buffer's data store are not useful to the application and can be discarded. This is a hint to the GL that it may discard the contents of the entire buffer, and may allocate new memory for the buffer's data store. This flag can only be used with GL_MAP_WRITE_BIT.
GL_MAP_UNSYNCHRONIZED_BIT
Indicates that the buffer's data store is not subject to any pending writes from the GL. This is a hint to the GL that it can immediately return a pointer to the buffer's data store, and that it does not need to wait for any previous GL operations to complete. This flag can only be used with GL_MAP_WRITE_BIT.

If length is zero, a NULL pointer is returned.

If the buffer object is already in a mapped state, GL_INVALID_OPERATION is generated.

If GL_MAP_READ_BIT is set and any of GL_MAP_INVALIDATE_RANGE_BIT, GL_MAP_INVALIDATE_BUFFER_BIT, or GL_MAP_UNSYNCHRONIZED_BIT are set, GL_INVALID_OPERATION is generated.

If GL_MAP_FLUSH_EXPLICIT_BIT is set and GL_MAP_WRITE_BIT is not set, GL_INVALID_OPERATION is generated.

If any of GL_MAP_READ_BIT, GL_MAP_WRITE_BIT, GL_MAP_PERSISTENT_BIT, or GL_MAP_COHERENT_BIT are set, but the same bit is not included in the buffer's storage flags (set by glBufferStorage), GL_INVALID_OPERATION is generated.

If the buffer object is not zero, and the buffer object is not a valid buffer object name, GL_INVALID_OPERATION is generated.

If length is zero, GL_INVALID_OPERATION is generated.

If offset or length is negative, GL_INVALID_VALUE is generated.

If $offset + length$ is greater than the value of GL_BUFFER_SIZE for the buffer object, GL_INVALID_VALUE is generated.

If access has any bits set other than those defined above, GL_INVALID_VALUE is generated.

If zero is bound to target, GL_INVALID_OPERATION is generated.

NOTES

glMapNamedBufferRange is available if the OpenGL version is 3.0 or greater.

The GL_DISPATCH_INDIRECT_BUFFER and GL_SHADER_STORAGE_BUFFER targets are accepted only if the GL version is 4.3 or greater.

The GL_QUERY_BUFFER target is available only if the GL version is 4.4 or greater.

The GL_MAP_PERSISTENT_BIT and GL_MAP_COHERENT_BIT flags are available only if the GL version is 4.4 or greater.

ERRORS

GL_INVALID_ENUM is generated by glMapBufferRange if target is not one of the buffer binding targets listed above.

GL_INVALID_OPERATION is generated by glMapBufferRange if zero is bound to target.

GL_INVALID_OPERATION is generated by glMapNamedBufferRange if buffer is not the name of an existing buffer object.

GL_INVALID_VALUE is generated if offset or length is negative, if $offset + length$ is greater than the value of GL_BUFFER_SIZE for the buffer object, or if access has any bits set other than those defined above.

GL_INVALID_OPERATION is generated for any of the following conditions:

•length is zero.
•The buffer object is already in a mapped state.
•Neither GL_MAP_READ_BIT nor GL_MAP_WRITE_BIT is set.
•GL_MAP_READ_BIT is set and any of GL_MAP_INVALIDATE_RANGE_BIT, GL_MAP_INVALIDATE_BUFFER_BIT or GL_MAP_UNSYNCHRONIZED_BIT is set.
•GL_MAP_FLUSH_EXPLICIT_BIT is set and GL_MAP_WRITE_BIT is not set.
•Any of GL_MAP_READ_BIT, GL_MAP_WRITE_BIT, GL_MAP_PERSISTENT_BIT, or GL_MAP_COHERENT_BIT are set, but the same bit is not included in the buffer's storage flags.

No error is generated if memory outside the mapped range is modified or queried, but the result is undefined and system errors (possibly including program termination) may occur.

ASSOCIATED GETS

glGet() with pname GL_MIN_MAP_BUFFER_ALIGNMENT. The value must be a power of two that is at least 64.
