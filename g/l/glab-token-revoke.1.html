NOMBRE

glab-token-revoke - Revocar tokens de acceso de usuario, grupo o proyecto

SINOPSIS

glab token revoke [flags]

DESCRIPCIÓN

Revoca un token de acceso de usuario, grupo o proyecto. Si existen múltiples tokens con el mismo nombre, puedes especificar el ID del token.

El formato de salida puede ser "JSON" o "text". La salida JSON mostrará la información meta del token revocado. La salida de texto normal es una descripción del nombre y ID del token revocado.

Los administradores pueden revocar tokens de acceso personal pertenecientes a otros usuarios.

OPCIONES

-g, --group="" Revocar token de acceso de grupo. Ignorado si se establece un argumento de usuario o repositorio.

-F, --output="text" Formatear la salida como: text, json. 'text' proporciona el nombre y el ID del token revocado; 'json' muestra el token con metadatos.

-R, --repo="" Seleccionar otro repositorio. Puede usar el formato PROPIETARIO/REPO o GRUPO/NAMESPACE/REPO. También acepta URL completa o URL de Git.

-U, --user="" Revocar token de acceso personal. Usa @me para el usuario actual.

OPCIONES HEREDADAS DE COMANDOS PADRE

-h, --help[=false] Mostrar ayuda para este comando.

EJEMPLO

# Revocar un token de acceso de proyecto del proyecto actual
$ glab token revoke mi-token-de-proyecto
# Revocar un token de acceso de proyecto de un proyecto específico
$ glab token revoke --repo usuario/mi-repo mi-token-de-proyecto
# Revocar un token de acceso de grupo
$ glab token revoke --group grupo/sub-grupo mi-token-de-grupo
# Revocar mi token de acceso personal
$ glab token revoke --user @me mi-token-personal
# Revocar el token de acceso personal de otro usuario (solo administrador)
$ glab token revoke --user juanperez token-personal-de-juan
