NOMBRE

glMultiDrawElementsBaseVertex - renderiza múltiples conjuntos de primitivas especificando los índices de los elementos de datos de array y un índice para aplicar a cada índice

ESPECIFICACIÓN EN C

void glMultiDrawElementsBaseVertex(GLenum mode, const GLsizei *count, GLenum type, const void * const *indices, GLsizei drawcount, const GLint *basevertex);

PARÁMETROS

mode

Especifica qué tipo de primitivas renderizar. Se aceptan los símbolos constantes GL_POINTS, GL_LINE_STRIP, GL_LINE_LOOP, GL_LINES, GL_LINE_STRIP_ADJACENCY, GL_LINES_ADJACENCY, GL_TRIANGLE_STRIP, GL_TRIANGLE_FAN, GL_TRIANGLES, GL_TRIANGLE_STRIP_ADJACENCY, GL_TRIANGLES_ADJACENCY y GL_PATCHES.

count

Puntero a un array con los recuentos de elementos.

type

Especifica el tipo de los valores en indices. Debe ser uno de GL_UNSIGNED_BYTE, GL_UNSIGNED_SHORT o GL_UNSIGNED_INT.

indices

Especifica un puntero a la ubicación donde se almacenan los índices.

drawcount

Especifica el tamaño de los arrays count, indices y basevertex.

basevertex

Especifica un puntero a la ubicación donde se almacenan los vértices base.

DESCRIPCIÓN

glMultiDrawElementsBaseVertex se comporta de manera idéntica a glDrawElementsBaseVertex(), excepto que se especifican drawcount listas separadas de elementos en su lugar.

Tiene el mismo efecto que:

    for (int i = 0; i < drawcount; i++)
        if (count[i] > 0)
            glDrawElementsBaseVertex(mode,
                                     count[i],
                                     type,
                                     indices[i],
                                     basevertex[i]);

NOTAS

glMultiDrawElementsBaseVertex solo está disponible si la versión de GL es 3.1 o superior.

GL_LINE_STRIP_ADJACENCY, GL_LINES_ADJACENCY, GL_TRIANGLE_STRIP_ADJACENCY y GL_TRIANGLES_ADJACENCY solo están disponibles si la versión de GL es 3.2 o superior.

ERRORES

Se genera GL_INVALID_ENUM si mode no es un valor aceptado.

Se genera GL_INVALID_VALUE si drawcount es negativo.

Se genera GL_INVALID_OPERATION si un nombre de objeto de buffer distinto de cero está enlazado a un array habilitado o al array de elementos y el almacén de datos del objeto de buffer está actualmente mapeado.
