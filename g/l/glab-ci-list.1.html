NOMBRE

glab-ci-list - Obtener la lista de pipelines de CI/CD.

SINOPSIS

glab ci list [flags]

DESCRIPCIÓN

Obtener la lista de pipelines de CI/CD.

OPCIONES

-n, --name="" Devuelve solo pipelines con el nombre dado.

-o, --orderBy="id" Ordena los pipelines por este campo. Opciones: id, status, ref, updated_at, user_id.

-F, --output="text" Formato de salida. Opciones: text, json.

-p, --page=1 Número de página.

-P, --per-page=30 Número de elementos a listar por página.

-r, --ref="" Devuelve solo pipelines para la referencia dada.

--scope="" Devuelve solo pipelines con el ámbito dado: {running|pending|finished|branches|tags}

--sha="" Devuelve solo pipelines con el SHA dado.

--sort="desc" Ordena los pipelines. Opciones: asc, desc.

--source="" Devuelve solo pipelines activados a través de la fuente dada. Consulte https://docs.gitlab.com/ci/jobs/job_rules/#ci_pipeline_source-predefined-variable para ver la lista completa. Opciones comúnmente usadas: {merge_request_event|parent_pipeline|pipeline|push|trigger}

-s, --status="" Obtiene el pipeline con este estado. Opciones: running, pending, success, failed, canceled, skipped, created, manual, waiting_for_resource, preparing, scheduled

-a, --updated-after="" Devuelve solo pipelines actualizados después de la fecha especificada. Se espera en formato ISO 8601 (2019-03-15T08:00:00Z).

-b, --updated-before="" Devuelve solo pipelines actualizados antes de la fecha especificada. Se espera en formato ISO 8601 (2019-03-15T08:00:00Z).

-u, --username="" Devuelve solo pipelines activados por el nombre de usuario dado.

-y, --yaml-errors[=false] Devuelve solo pipelines con configuraciones inválidas.

OPCIONES HEREDADAS DE COMANDOS PADRE

-h, --help[=false] Mostrar ayuda para este comando.

-R, --repo="" Seleccionar otro repositorio. Puede usar el formato PROPIETARIO/REPO o GRUPO/NAMESPACE/REPO. También acepta una URL completa o una URL de Git.

EJEMPLO

$ glab ci list
$ glab ci list --status=failed
