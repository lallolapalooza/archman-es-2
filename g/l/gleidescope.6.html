NOMBRE

gleidescope - un caleidoscopio de mosaico con OpenGL

SINOPSIS

gleidescope [--display host:display.screen] [--visual visual] [--window] [--root] [--window-id número] [-delay número] [-move] [-rotate] [-zoom] [-image archivo] [-fps] [-size número] [-duration número]

DESCRIPCIÓN

Un caleidoscopio de mosaico usando OpenGL.

OPCIONES

--visual visual
Especificar qué visual usar. Los valores legales son el nombre de una clase visual o el número de id (decimal o hexadecimal) de un visual específico.
--window
Dibujar en una ventana recién creada. Esta es la opción predeterminada.
--root
Dibujar en la ventana raíz.
--window-id número
Dibujar en la ventana especificada.
--delay número
Retardo por fotograma, en microsegundos. Predeterminado: 20000 (0.02 segundos).
--move
Mover la cámara.
--rotate
Rotar la cámara.
--zoom
Acercar y alejar la cámara.
--image archivo
El mapa de texturas a usar al final del caleidoscopio.
--fps
Mostrar la tasa de fotogramas actual, la carga de la CPU y el recuento de polígonos.
--size número
El tamaño de los hexágonos que se muestran [1 (pequeño) -10 (grande)]
--duration número
El tiempo en segundos antes de que se elija otra imagen.

ENTORNO

DISPLAY
para obtener el host y número de pantalla predeterminados.
XENVIRONMENT
para obtener el nombre de un archivo de recursos que anula los recursos globales almacenados en la propiedad RESOURCE_MANAGER.
XSCREENSAVER_WINDOW
El ID de ventana a usar con --root.

VER TAMBIÉN

X(1), xscreensaver(1)
