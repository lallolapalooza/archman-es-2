GLTRANSFORMFEEDBACKB(3G) [FIXME: manual] GLTRANSFORMFEEDBACKB(3G)

NOMBRE

glTransformFeedbackBufferRange - enlaza un rango dentro de un objeto de búfer a un objeto de búfer de retroalimentación de transformación

ESPECIFICACIÓN EN C

void glTransformFeedbackBufferRange(GLuint xfb, GLuint index, GLuint buffer, GLintptr offset, GLsizei size);

PARÁMETROS

xfb

Nombre del objeto de búfer de retroalimentación de transformación.

index

Índice del punto de enlace dentro de xfb.

buffer

Nombre del objeto de búfer para enlazar al punto de enlace especificado.

offset

El desplazamiento inicial en unidades básicas de máquina dentro del objeto de búfer.

size

La cantidad de datos en unidades básicas de máquina que se pueden leer o escribir en el objeto de búfer cuando se usa como un destino indexado.

DESCRIPCIÓN

glTransformFeedbackBufferRange enlaza un rango del objeto de búfer buffer representado por offset y size al punto de enlace en el índice index del objeto de retroalimentación de transformación xfb.

offset especifica el desplazamiento en unidades básicas de máquina dentro del objeto de búfer buffer y size especifica la cantidad de datos que se pueden leer del objeto de búfer cuando se utiliza como un destino indexado.

NOTAS

ERRORES

Se genera **GL_INVALID_OPERATION** si xfb no es el nombre de un objeto de retroalimentación de transformación existente.

Se genera **GL_INVALID_VALUE** si buffer no es cero o el nombre de un objeto de búfer existente.

Se genera **GL_INVALID_VALUE** si index es mayor o igual al número de puntos de enlace de búfer de retroalimentación de transformación (el valor de **GL_TRANSFORM_FEEDBACK_BUFFER_BINDING**).

Se genera **GL_INVALID_VALUE** si offset es negativo.

Se genera **GL_INVALID_VALUE** si buffer no es cero y either size es menor o igual a cero, o offset + size es mayor que el valor de **GL_BUFFER_SIZE** para buffer.
