La ubicación de la variable uniforme a modificar se especifica mediante location, que debe ser un valor devuelto por glGetUniformLocation(). glProgramUniform opera sobre

el

objeto de programa especificado por program. Los comandos glProgramUniform{1|2|3|4}{f|i|ui} se utilizan para cambiar el valor de la variable uniforme especificada por location usando los valores pasados como argumentos. El número especificado en el comando debe coincidir con el número de componentes en el tipo de datos de la variable uniforme especificada (por ejemplo, 1 para float, int, unsigned int, bool; 2 para vec2, ivec2, uvec2, bvec2, etc.). El sufijo f indica que se están pasando valores de punto flotante; el sufijo i indica que se están pasando valores enteros; el sufijo ui indica que se están pasando valores enteros sin signo, y este tipo también debe coincidir con el tipo de datos de la variable uniforme especificada. Las variantes i de esta función deben usarse para proporcionar valores para variables uniformes definidas como int, ivec2, ivec3, ivec4, o arrays de estas. Las variantes ui de esta función deben usarse para proporcionar valores para variables uniformes definidas como unsigned int, uvec2, uvec3, uvec4, o arrays de estas. Las variantes f deben usarse para proporcionar valores p ara variables uniformes de tipo float, vec2, vec3, vec4, o arrays de estas. Se puede usar cualquiera de las variantes i, ui o f para proporcionar valores para variables uniformes de tipo bool, bvec2, bvec3, bvec4, o arrays de estas. La

variable

uniforme se establecerá en false si el valor de entrada es 0 o 0.0f, y se establecerá en true en caso contrario. Todas las variables uniformes activas definidas en un objeto de programa se inicializan a 0 cuando el objeto de programa se enlaza correctamente. Conservan los valores asignados por una llamada a glProgramUnifor

m

hasta que se produce la siguiente operación de enlace exitosa en el objeto de programa, cuando se vuelven a inicializar a 0. Los comandos glProgramUniform{1|2|3|4}{f|i|ui}v pueden usarse para modificar una sola variable uniforme o un array de variables uniformes. Estos comandos pasan un count y un puntero a los valores que se cargarán en una variable uniforme o en un array de variables uniformes. Debe usarse un count de 1 si se modifica el valor de una sola variable uniforme, y un count de 1 o mayor puede usarse para modificar un array completo o parte de un array. Al cargar n elementos a partir de una posición arbitraria m en un array de variables uniformes, los elementos m + n - 1 en el array serán reemplazados con los nuevos valores. Si m + n - 1 es mayor que el tamaño del array de variables uniformes, los valores de todos los elementos del array más allá del final del array serán ignorados. El número especificado en el nombre del comando indica el número de componentes para cada elemento en value, y debe coincidir con el número de componentes en el tipo de datos de la variable uniforme especificada (por ejemplo, 1 para float, int, bool; 2 para vec2, ivec2, bvec2, etc.)

.

El tipo de datos especificado en el nombre del comando debe coincidir con el tipo de datos para la variable uniforme especificada como se describió anteriormente para glProgramUniform{1|2|3|4}{f|i|ui}. Los números en el nombre del comando se interpretan como la dimensionalidad de la matriz. El número 3 indica una matriz de 3 × 3 (es decir, 9 valores), y el número 4 indica una matriz de 4 × 4 (es decir, 16 valores). La dimensionalidad de las matrices no cuadradas es explícita, con el primer número representando el número de columnas y el segundo número representando el número de filas. glProgramUniform1ui

Set the value of an unsigned int uniform variable in shader programs

C SPECIFICATION

    void glProgramUniform1ui( int location,
                              uint v0 );

    void glProgramUniform2ui( int location,
                              uint v0, uint v1 );

    void glProgramUniform3ui( int location,
                              uint v0, uint v1, uint v2 );

    void glProgramUniform4ui( int location,
                              uint v0, uint v1, uint v2, uint v3 );

    void glProgramUniform1uiv( int location,
                               sizei count,
                               const uint *value );

    void glProgramUniform2uiv( int location,
                               sizei count,
                               const uint *value );

    void glProgramUniform3uiv( int location,
                               sizei count,
                               const uint *value );

    void glProgramUniform4uiv( int location,
                               sizei count,
                               const uint *value );

PARAMETERS

location
Specifies the uniform variable location.
v0, v1, v2, v3
Specify the new values for the uniform variable.
count
For the vector commands, specifies the number of elements to be updated.
value
For the vector commands, points to the location of the first value to be written to the uniform variable.

DESCRIPTION

glProgramUniform family of functions sets the value of a uniform variable in the current active program object. These functions do not take a program object as an argument, instead they modify uniforms in the currently active program. If no program object is active, or if the specified program object has not been linked or is not currently part of the active program object, a GL error will be generated.

The functions ending in ui load uniform variables that are of type uint. The functions ending in uiv load uniform variables of type uint[]. The functions ending in i load uniform variables that are of type int.

The functions ending in 2ui, 3ui, and 4ui load two-, three-, and four-component vectors, respectively. The functions ending in 2uiv, 3uiv, and 4uiv load vector variables with two, three, or four components, respectively.

The functions ending in Matrix load matrix uniforms. The names indicate the dimensions of the matrix (e.g. glProgramUniformMatrix2fv loads a 2x2 matrix). The 'f' suffix indicates that the matrix is composed of floating-point values. The 'v' suffix indicates that the values are passed as a vector.

If the uniform variable whose location is specified by location is not found in the active program object, or if the specified type does not match the type of the uniform variable, then no action is taken.

The uniform variable named by querying its location using glGetUniformLocation is set to the specified value.

The functions ending in Matrix...fv load `count` `numrows` x `numcolumns` floating point matrices. If transpose is set to GL_TRUE, each component of the uniform variable will be transposed before being set. Otherwise, if transpose is GL_FALSE, the matrix will be set as is.

The functions ending in Matrix...dv load `count` `numrows` x `numcolumns` double precision floating point matrices. If transpose is set to GL_TRUE, each component of the uniform variable will be transposed before being set. Otherwise, if transpose is GL_FALSE, the matrix will be set as is.

The functions ending in Matrix...iv load `count` `numrows` x `numcolumns` integer matrices. If transpose is set to GL_TRUE, each component of the uniform variable will be transposed before being set. Otherwise, if transpose is GL_FALSE, the matrix will be set as is.

The functions ending in Matrix...uiv load `count` `numrows` x `numcolumns` unsigned integer matrices. If transpose is set to GL_TRUE, each component of the uniform variable will be transposed before being set. Otherwise, if transpose is GL_FALSE, the matrix will be set as is.

The matrix functions take an additional parameter, transpose. If transpose is GL_TRUE, then all matrices are transposed before they are specified. Otherwise, they are sent in the specified order.

If location is equal to -1, the commands are ignored.

If the uniform variable is not specified as a single value (e.g. it is an array, or part of a struct), the behaviour is undefined.

NOTES

These functions are available only if the GL version is 2.0 or higher.

These functions are available only if the GL_ARB_explicit_uniform_location extension is supported.

The use of glProgramUniform* functions supersedes the use of glUniform* functions when using programmable shaders.

If the uniform variable is declared as an array, the functions ending in v are used to update the elements of the array. For example, to update the first three elements of an integer array uniform named myArray, you would call:

    GLint loc = glGetUniformLocation(prog, "myArray");
    const GLint myValues[3] = { 1, 2, 3 };
    glProgramUniformiv(loc, 3, myValues);

If a uniform variable is declared as a struct, you must use glGetUniformSubroutineuiv to get the location of the struct members.

The following functions are deprecated. Use glProgramUniformMatrix2x3fv and glProgramUniformMatrix3x2fv instead.

  • glProgramUniformMatrix2x3fv

  • glProgramUniformMatrix3x2fv

ERRORS

GL_INVALID_OPERATION is generated if no vertex or fragment shader is active, or if the program object containing the uniform has not been linked successfully or is not part of the active program object.

GL_INVALID_OPERATION is generated if location does not correspond to a valid uniform variable location in the active program object.

GL_INVALID_VALUE is generated if count is negative.

ASSOCIATED GETS

glGetUniformLocation, glGetActiveUniform, glGetActiveUniformName, glGetUniformSubroutineuiv
