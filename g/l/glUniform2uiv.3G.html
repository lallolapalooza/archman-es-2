PARÁMETROS

location

Especifica la ubicación de la variable uniforme a modificar.

count

Para los comandos de vector (glUniform*v), especifica el número de elementos que se van a modificar. Esto debe ser 1 si la variable uniforme de destino no es una matriz, y 1 o más si es una matriz.

Para los comandos de matriz (glUniformMatrix*), especifica el número de matrices que se van a modificar. Esto debe ser 1 si la variable uniforme de destino no es una matriz de matrices, y 1 o más si es una matriz de matrices.

transpose

Para los comandos de matriz, especifica si se debe transponer la matriz al cargar los valores en la variable uniforme.

v0, v1, v2, v3

Para los comandos escalares, especifica los nuevos valores que se utilizarán para la variable uniforme especificada.

value

Para los comandos de vector y matriz, especifica un puntero a una matriz de count valores que se utilizarán para actualizar la variable uniforme especificada.

DESCRIPCIÓN

glUniform modifica el valor de una variable uniforme o una matriz de variables uniformes. La ubicación de la variable uniforme a modificar está especificada por location, que debe ser un valor retornado por glGetUniformLocation(). glUniform opera sobre el objeto de programa que se convirtió en parte del estado actual al llamar a glUseProgram().

Los comandos glUniform{1|2|3|4}{f|i|ui} se utilizan para cambiar el valor de la variable uniforme especificada por location utilizando los valores pasados como argumentos. El número especificado en el comando debe coincidir con el número de componentes en el tipo de datos de la variable uniforme especificada (por ejemplo, 1 para float, int, unsigned int, bool; 2 para vec2, ivec2, uvec2, bvec2, etc.). El sufijo f indica que se están pasando valores de punto flotante; el sufijo i indica que se están pasando valores enteros; el sufijo ui indica que se están pasando valores enteros sin signo, y este tipo también debe coincidir con el tipo de datos de la variable uniforme especificada. Las variantes i de esta función deben usarse para proporcionar valores para variables uniformes definidas como int,

ivec2, ivec3, ivec4, o arreglos de estos. Las ui variantes de esta función deben usarse para proporcionar valores para variables uniformes definidas como unsigned int, uvec2, uvec3, uvec4, o arreglos de estos. Las f variantes deben usarse para proporcionar valores para variables uniformes de tipo float, vec2, vec3, vec4, o arreglos de estos. Cualquiera de las i ,

ui o

f variantes puede usarse para proporcionar valores para variables uniformes de tipo bool, bvec2, bvec3, bvec4, o arreglos de estos. La variable uniforme se establecerá en false si el valor de entrada es 0 o 0.0f, y se establecerá en true en caso contrario. Todas las variables uniformes activas definidas en un objeto de programa se inicializan a 0 cuando el objeto de programa se enlaza correctamente. Conservan los valores asignados por una llamada a glUniform hasta que se produce la siguiente operación de enlace exitosa en el objeto de programa, cuando se vuelven a inicializar a 0. Los comandos glUniform{1|2|3|4}{f|i|ui}v pueden usarse para modificar una única variable uniforme o una variable uniforme de tipo arreglo. Estos comandos pasan un conteo y un puntero a los valores que se cargarán en una variable uniforme o en un arreglo de variables uniformes. Debe usarse un conteo de 1 si se modifica el valor de una única variable uniforme, y puede usarse un conteo de 1 o mayor para modificar un arreglo completo o parte de un arreglo. NAME

glUniformMatrix2fv, glUniformMatrix3fv, glUniformMatrix4fv - establecer valores de matrices uniformes

C SPECIFICATION

void glUniformMatrix2fv( GLint location, GLsizei count, GLboolean transpose, const GLfloat *value );

void glUniformMatrix3fv( GLint location, GLsizei count, GLboolean transpose, const GLfloat *value );

void glUniformMatrix4fv( GLint location, GLsizei count, GLboolean transpose, const GLfloat *value );

PARAMETERS

location
Especifica el localizador de la primera matriz uniforme a modificar.
count
Especifica el número de matrices uniformes a modificar. Debe ser no negativo.
transpose
Especifica si se deben transponer las matrices. Debe ser GL_FALSE.
value
Especifica un puntero a la primera de las matrices uniformes a modificar.

DESCRIPTION

The glUniformMatrix*fv commands are used to set the value of a matrix-valued uniform variable in one or more shader programs. If count is greater than 1, then location refers to the location of the first matrix in an array of matrices. The matrices are loaded into the uniform variable specified by location.
If transpose is GL_FALSE, the matrices are assumed to be in column-major order. If transpose is GL_TRUE, the matrices are assumed to be in row-major order.

glUniformMatrix2fv specifies the value of a single 2- by 2-matrix, a 2- by 3-matrix, or a 3- by 2-matrix, or an array of such matrices, consisting of floating-point values.

glUniformMatrix3fv specifies the value of a single 3- by 3-matrix, a 3- by 2-matrix, a 2- by 3-matrix, a 3- by 4-matrix, or a 4- by 3-matrix, or an array of such matrices, consisting of floating-point values.

glUniformMatrix4fv specifies the value of a single 4- by 4-matrix, a 4- by 2-matrix, a 2- by 4-matrix, a 4- by 3-matrix, or a 3- by 4-matrix, or an array of such matrices, consisting of floating-point values.

NOTES

The transpose parameter is ignored when using the OpenGL specification prior to version 4.4. In these earlier versions, matrices are always assumed to be in column-major order.

ERRORS

  • GL_INVALID_OPERATION is generated if program is not 0 and is not the name of an active program.
  • GL_INVALID_VALUE is generated if count is negative.
  • GL_INVALID_OPERATION is generated if location is not a valid uniform location for the active program.
  • GL_INVALID_OPERATION is generated if the indicated uniform variable is not of type matrix or is not of a compatible type.
