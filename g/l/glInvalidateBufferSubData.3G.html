NOMBRE

glInvalidateBufferSubData - invalida una región de la tienda de datos de un objeto de búfer

ESPECIFICACIÓN C

void glInvalidateBufferSubData(GLuint buffer, GLintptr offset, GLsizeiptr length);

PARÁMETROS

buffer

El nombre de un objeto de búfer, de una subsección cuyo almacenamiento de datos se invalidará.

offset

El desplazamiento dentro del almacenamiento de datos del búfer del inicio del rango a invalidar.

length

La longitud del rango dentro del almacenamiento de datos del búfer a invalidar.

DESCRIPCIÓN

glInvalidateBufferSubData invalida todo o parte del contenido de la tienda de datos de un objeto de búfer. Después de la invalidación, el contenido del rango especificado del almacenamiento de datos del búfer se vuelve indefinido. El inicio del rango viene dado por offset y su tamaño viene dado por length, ambos medidos en unidades básicas de máquina.

ERRORES

Se genera GL_INVALID_VALUE si offset o length son negativos, o si offset + length es mayor que el valor de GL_BUFFER_SIZE para buffer.

Se genera GL_INVALID_VALUE si buffer no es el nombre de un objeto de búfer existente.

Se genera GL_INVALID_OPERATION si alguna parte de buffer está actualmente mapeada.

GETS ASOCIADOS

glGetBufferParameter() con el argumento GL_BUFFER_SIZE
