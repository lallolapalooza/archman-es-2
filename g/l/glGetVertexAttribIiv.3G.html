DESCRIPCIÓ

N

glGetVertexAttrib devuelve en params el valor de un parámetro de atributo de vértice genérico. El atributo de vértice genérico a consultar se especifica mediante index, y el parámetro a consultar se especifica mediante pname

.

Los nombres de parámetros aceptados son los

siguientes:

GL_VERTEX_ATTRIB_ARRAY_BUFFER_BINDIN

G

params devuelve un único valor, el nombre del objeto de búfer actualmente vinculado al punto de enlace correspondiente al array de atributos de vértice genérico index. Si no hay ningún objeto de búfer vincul

ado, se devuelve 0.
El valor inicial es 0.

GL_VERTEX_ATTRIB_ARRAY_ENABLE

D

params devuelve un único valor que es distinto de cero (verdadero) si el array de atributos de vértice para index está habilitado y 0 (falso) si está deshabilitado. El valor inicial es GL_F

ALS
E.

GL_VERTEX_ATTRIB_ARRAY_SIZ

E

params devuelve un único valor, el tamaño del array de atributos de vértice para index. El tamaño es el número de valores para cada elemento del arra

y de atributos de vértice, y será 1,
2, 3 o 4. El valor inicial es 4.

GL_VERTEX_ATTRIB_ARRAY_STRID

E

params devuelve un único valor, el paso del array (número de bytes entre elementos sucesivos en) el array de atributos de vértice para index. Un valor de 0 indica que los elementos del array se alm

acenan secuencialmente en
memoria. El valor inicial es 0.

GL_VERTEX_ATTRIB_ARRAY_TYP

E

params devuelve un único valor, una constante simbólica que indica el tipo de array para el array de atributos de vértice para index. Los valores posibles son GL_BYTE, GL_UNSIGNED_BYTE, GL_SHORT, GL_UNSIGNED_SHORT, GL_INT, GL_UNSIGNED_INT, GL_FLOAT y GL_DOUBLE. El valor inicial es GL_F

LOA
T.

GL_VERTEX_ATTRIB_ARRAY_NORMALIZE

D

params devuelve un único valor que es distinto de cero (verdadero) si los tipos de datos de punto fijo para el array de atributos de vértice indicado por index se normalizan cuando se convierten a punto flotante, y 0 (falso) en caso contrario. El valor inicial es GL_F

ALS
E.

GL_VERTEX_ATTRIB_ARRAY_INTEGE

R

params devuelve un único valor que es distinto de cero (verdadero) si los tipos de datos de punto fijo para el array de atributos de vértice indicado por index tienen tipos de datos enteros, y 0 (falso) en caso contrario. El valor inicial es 0 (GL_FA

LSE
).

GL_VERTEX_ATTRIB_ARRAY_LON

G

param devuelve un único valor que es distinto de cero (verdadero) si un atributo de vértice se almacena como un doble sin convertir, y 0 (falso) en caso contrario. El valor inicial es 0 (GL_FA

LSE
).

GL_VERTEX_ATTRIB_ARRAY_DIVISO

R

params devuelve un único valor que es el divisor de frecuencia utilizado para el renderizado instanciado. Véase glVertexAttribDivisor(). E

l valor
inicial es 0.

GL_VERTEX_ATTRIB_BINDIN

G

params devuelve un único valor, la vinculación del búfer de vértices del array de atributos de vértice ind

e
x.

GL_VERTEX_ATTRIB_RELATIVE_OFFSE

T

params devuelve un único valor que es el desplazamiento en bytes de el primer elemento relativo al inicio

del búfer de vértices vinculado del que el atributo
especificado obtiene sus datos. El valor inicial es 0.

GL_CURRENT_VERTEX_ATTRI

B

params devuelve cuatro valores que representan el valor actual para el atributo de vértice genérico especificado por index. El atributo de vértice genérico 0 es único en que no tiene estado actual, por lo que se generará un error si index es 0. El valor inicial para todos los demás atributos de vértice genéricos es (0,0,0,1)

.

glGetVertexAttribdv y glGetVertexAttribfv devuelven los valores de atributo actuales como cuatro valores de punto flotante de precisión simple; glGetVertexAttribiv los lee como valores de punto flotante y los convierte en cuatro valores enteros; glGetVertexAttribIiv y glGetVertexAttribIuiv los leen y devuelven como valores enteros con o sin signo, respectivamente; glGetVertexAttribLdv los lee y devuelve como c

uatro valores de punto flo
tante de precisión doble.

Todos los parámetros excepto GL_CURRENT_VERTEX_ATTRIB representan estado almacenado

en el objeto de array de vé
rtices actualmente vinculado.

NOTA

S

Si se genera un error, no se realiza ningún cambio en el contenido de para

m
s.

ERRORE

S

Se genera GL_INVALID_OPERATION si pname no es GL_CURRENT_VERTEX_ATTRIB y no hay ningún objeto de array de vértices actualmente

vinculado.

Se genera GL_INVALID_VALUE si index es mayor o igual a GL_MAX_VERTEX_ATTRIBS

.

Se genera GL_INVALID_ENUM si pname no es un valor

aceptado.

Se genera GL_INVALID_OPERATION si index es 0 y pname es GL_CURRENT_VERTEX_ATTRI

B
.
