glGetTexLevelParameter(3G)

GLGETTEXLEVELPARAMET(3G) [FIJARME: manual] GLGETTEXLEVELPARAMET(3G)

NOMBRE

glGetTexLevelParameter - devuelve valores de parámetros de textura para un nivel de detalle específico

ESPECIFICACIÓN C

void glGetTexLevelParameterfv(GLenum target, GLint level, GLenum pname, GLfloat * params);

void glGetTexLevelParameteriv(GLenum target, GLint level, GLenum pname, GLint * params);

void glGetTextureLevelParameterfv(GLuint texture, GLint level, GLenum pname, GLfloat *params);

void glGetTextureLevelParameteriv(GLuint texture, GLint level, GLenum pname, GLint *params);

PARÁMETROS

target

Especifica el destino al que está enlazada la textura para las funciones glGetTexLevelParameterfv y glGetTexLevelParameteriv. Debe ser uno de los siguientes valores: GL_TEXTURE_1D, GL_TEXTURE_2D, GL_TEXTURE_3D, GL_TEXTURE_1D_ARRAY, GL_TEXTURE_2D_ARRAY, GL_TEXTURE_RECTANGLE, GL_TEXTURE_2D_MULTISAMPLE, GL_TEXTURE_2D_MULTISAMPLE_ARRAY, GL_TEXTURE_CUBE_MAP_POSITIVE_X, GL_TEXTURE_CUBE_MAP_NEGATIVE_X, GL_TEXTURE_CUBE_MAP_POSITIVE_Y, GL_TEXTURE_CUBE_MAP_NEGATIVE_Y, GL_TEXTURE_CUBE_MAP_POSITIVE_Z, GL_TEXTURE_CUBE_MAP_NEGATIVE_Z, GL_PROXY_TEXTURE_1D, GL_PROXY_TEXTURE_2D, GL_PROXY_TEXTURE_3D, GL_PROXY_TEXTURE_1D_ARRAY, GL_PROXY_TEXTURE_2D_ARRAY, GL_PROXY_TEXTURE_RECTANGLE, GL_PROXY_TEXTURE_2D_MULTISAMPLE, GL_PROXY_TEXTURE_2D_MULTISAMPLE_ARRAY, GL_PROXY_TEXTURE_CUBE_MAP, o GL_TEXTURE_BUFFER.

texture

Especifica el nombre del objeto de textura para las funciones glGetTextureLevelParameterfv y glGetTextureLevelParameteriv.

level

Especifica el número de nivel de detalle de la imagen deseada. El nivel 0 es el nivel de imagen base. El nivel n es la imagen de reducción mipmap n.

pname

Especifica el nombre simbólico de un parámetro de textura. Se aceptan GL_TEXTURE_WIDTH, GL_TEXTURE_HEIGHT, GL_TEXTURE_DEPTH, GL_TEXTURE_INTERNAL_FORMAT, GL_TEXTURE_RED_SIZE, GL_TEXTURE_GREEN_SIZE, GL_TEXTURE_BLUE_SIZE, GL_TEXTURE_ALPHA_SIZE, GL_TEXTURE_DEPTH_SIZE, GL_TEXTURE_COMPRESSED, GL_TEXTURE_COMPRESSED_IMAGE_SIZE y GL_TEXTURE_BUFFER_OFFSET.

params

Devuelve los datos solicitados.

DESCRIPCIÓN

glGetTexLevelParameterfv, glGetTexLevelParameteriv, glGetTextureLevelParameterfv y glGetTextureLevelParameteriv devuelven en params valores de parámetros de textura para un valor de nivel de detalle específico, especificado como level. Para las dos primeras funciones, target define la textura objetivo, ya sea GL_TEXTURE_1D, GL_TEXTURE_2D, GL_TEXTURE_3D, GL_PROXY_TEXTURE_1D, GL_PROXY_TEXTURE_2D, GL_PROXY_TEXTURE_3D, GL_TEXTURE_CUBE_MAP_POSITIVE_X, GL_TEXTURE_CUBE_MAP_NEGATIVE_X, GL_TEXTURE_CUBE_MAP_POSITIVE_Y, GL_TEXTURE_CUBE_MAP_NEGATIVE_Y, GL_TEXTURE_CUBE_MAP_POSITIVE_Z, GL_TEXTURE_CUBE_MAP_NEGATIVE_Z, o GL_PROXY_TEXTURE_CUBE_MAP. Las dos últimas toman un argumento texture que especifica el nombre del objeto de textura.

GL_MAX_TEXTURE_SIZE y GL_MAX_3D_TEXTURE_SIZE no son realmente lo suficientemente descriptivos. Tienen que informar la imagen de textura cuadrada más grande que se puede acomodar con mipmaps, pero una textura larga y delgada, o una textura sin mipmaps, pueden caber fácilmente en la memoria de textura. Los destinos proxy permiten al usuario consultar con mayor precisión si la GL puede acomodar una textura de una configuración dada. Si la textura no puede ser acomodada, las variables de estado de textura, que pueden ser consultadas con glGetTexLevelParameter y glGetTextureLevelParameter, se establecen en 0. Si la textura puede ser acomodada, los valores de estado de textura se establecerán como lo harían para un destino no proxy.

pname especifica el parámetro de textura cuyo valor o valores serán devueltos.

Los nombres de parámetros aceptados son los siguientes:

GL_TEXTURE_WIDTH

params devuelve un solo valor, el ancho de la imagen de textura. El valor inicial es 0.

GL_TEXTURE_HEIGHT

params devuelve un solo valor, la altura de la imagen de textura. El valor inicial es 0.

GL_TEXTURE_DEPTH

params devuelve un solo valor, la profundidad de la imagen de textura. El valor inicial es 0.

GL_TEXTURE_INTERNAL_FORMAT

params devuelve un solo valor, el formato interno de la imagen de textura.

GL_TEXTURE_RED_TYPE, GL_TEXTURE_GREEN_TYPE, GL_TEXTURE_BLUE_TYPE, GL_TEXTURE_ALPHA_TYPE, GL_TEXTURE_DEPTH_TYPE

El tipo de datos utilizado para almacenar el componente. Los tipos GL_NONE, GL_SIGNED_NORMALIZED, GL_UNSIGNED_NORMALIZED, GL_FLOAT, GL_INT y GL_UNSIGNED_INT pueden ser devueltos para indicar componentes de punto fijo normalizado con signo, punto fijo normalizado sin signo, punto flotante, entero no normalizado y entero sin signo no normalizado, respectivamente.

GL_TEXTURE_RED_SIZE, GL_TEXTURE_GREEN_SIZE, GL_TEXTURE_BLUE_SIZE, GL_TEXTURE_ALPHA_SIZE, GL_TEXTURE_DEPTH_SIZE

La resolución de almacenamiento interno de un componente individual. La resolución elegida por la GL será una coincidencia cercana a la resolución solicitada por el usuario con el argumento del componente de glTexImage1D(), glTexImage2D(), glTexImage3D(), glCopyTexImage1D() y glCopyTexImage2D(). El valor inicial es 0.

GL_TEXTURE_COMPRESSED

params devuelve un solo valor booleano que indica si la imagen de textura está almacenada en un formato interno comprimido. El valor inicial es GL_FALSE.

GL_TEXTURE_COMPRESSED_IMAGE_SIZE

params devuelve un solo valor entero, el número de bytes sin signo de la imagen de textura comprimida que se devolvería de glGetCompressedTexImage().

GL_TEXTURE_BUFFER_OFFSET

params devuelve un solo valor entero, el desplazamiento en el almacén de datos del búfer enlazado a una textura de búfer. glTexBufferRange().

GL_TEXTURE_BUFFER_SIZE

params devuelve un solo valor entero, el tamaño del rango de un almacén de datos de un búfer enlazado a una textura de búfer. glTexBufferRange().

NOTAS

Si se genera un error, no se realiza ningún cambio en el contenido de params.

glGetTexLevelParameter devuelve los parámetros del nivel de textura para la unidad de textura activa.

GL_TEXTURE_BUFFER_OFFSET y GL_TEXTURE_BUFFER_SIZE solo están disponibles si la versión de GL es 4.3 o superior.

ERRORES

GL_INVALID_OPERATION es generado por las funciones glGetTextureLevelParameterfv y glGetTextureLevelParameteriv si texture no es el nombre de un objeto de textura existente.

GL_INVALID_ENUM es generado por las funciones glGetTexLevelParameterfv y glGetTexLevelParameteriv si target o pname no son valores aceptados.

GL_INVALID_VALUE se genera si level es menor que 0.

GL_INVALID_VALUE puede ser generado si level es mayor que log 2 max, donde max es el valor devuelto de GL_MAX_TEXTURE_SIZE.

GL_INVALID_VALUE se genera si target es GL_TEXTURE_BUFFER y level no es cero.

GL_INVALID_OPERATION se genera si se consulta GL_TEXTURE_COMPRESSED_IMAGE_SIZE en imágenes de textura con un formato interno no comprimido o en destinos proxy.
