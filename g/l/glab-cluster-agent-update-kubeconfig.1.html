NOMBRE

glab-cluster-agent-update-kubeconfig - Actualiza el kubeconfig seleccionado.

SINOPSIS

glab cluster agent update-kubeconfig [flags]

DESCRIPCIÓN

Actualiza el kubeconfig seleccionado para su uso con un agente de GitLab para Kubernetes.

OPCIONES

-a, --agent=0 El ID numérico del agente para el cual crear la entrada kubeconfig.

-c, --cache-mode="force-keyring" Modo a usar para el almacenamiento en caché del token. Valores permitidos: keyring-filesystem-fallback, force-keyring, force-filesystem, no

--check-revoked[=false] Comprueba si un token almacenado en caché está revocado. Requiere una llamada a la API de GitLab, lo que añade latencia cada vez que se accede a un token almacenado en caché.

--kubeconfig="" Utiliza un archivo kubeconfig en particular.

--token-expiry-duration=24h0m0s Duración de la validez del token generado. El mínimo es 1 día. Caduca al final del día y no tiene en cuenta la hora.

-u, --use-context[=false] Usar como contexto predeterminado.

OPCIONES HEREDADAS DE COMANDOS PADRE

-h, --help[=false] Mostrar ayuda para este comando.

-R, --repo="" Seleccionar otro repositorio. Se puede usar el formato OWNER/REPO o GROUP/NAMESPACE/REPO. También acepta URL completa o URL de Git.
