DESCRIPCIÓ

N

El mapeo de texturas asigna una porción de una imagen de textura especificada a cada primitiva gráfica para la que el mapeo de texturas está habilitado. Para habilitar o deshabilitar el mapeo de texturas unidimensional, llame a glEnable()

y

glDisable con el argumento GL_TEXTURE_1D

.

glTexSubImage1D y glTextureSubImage1D redefinen una subregión contigua de una imagen de textura unidimensional existente. Los texels referenciados por pixels reemplazan la porción del arreglo de textura existente con índices x xoffset y xoffset + width - 1, inclusive. Esta región no puede incluir ningún texel fuera del rango del arreglo de textura tal como se especificó originalmente. No es un error especificar una subtextura con un ancho de 0, pero tal especificación no tiene

efecto.

Si un objeto de búfer con nombre distinto de cero está enlazado al objetivo GL_PIXEL_UNPACK_BUFFER (véase glBindBuffer()) mientras se especifica una imagen de textura, pixels se trata como un desplazamiento en byte

s dentro del almacén de d
atos del objeto de búfer.

NOTA

S

Los modos de glPixelStore() afectan a las imágenes de

textura.

glTexSubImage1D y glTextureSubImage1D especifican una subtextura unidimensional para la unidad de textura actual, especificada con glActiveText

ure().

GL_STENCIL_INDEX se acepta para format solo si la versi

ón de GL es 4
.4 o superior.

ERRORE

S

Se genera GL_INVALID_ENUM si target o el objetivo efectivo de texture no es uno de los valores

permitidos.

Se genera GL_INVALID_OPERATION por glTextureSubImage1D si texture no es el nombre de un objeto de textura

existente.

Se genera GL_INVALID_ENUM si format no es una constante de formato

aceptada.

Se genera GL_INVALID_ENUM si type no es una constante de

tipo.

Se genera GL_INVALID_VALUE si level es menor que

0.

Se puede generar GL_INVALID_VALUE si level es mayor que log 2 max, donde max es el valor devuelto de GL_MAX_TEXTURE_SIZE

.

Se genera GL_INVALID_VALUE si xoffset < - b, o si xoffset + width > w - b, donde w es el GL_TEXTURE_WIDTH, y b es el ancho del GL_TEXTURE_BORDER de la imagen de textura que se está modificando. Nótese que w incluye el doble del ancho del

borde.

Se genera GL_INVALID_VALUE si width es menor que

0.

Se genera GL_INVALID_OPERATION si el arreglo de textura no ha sido definido por una operación previa glTexImage

1D().

Se genera GL_INVALID_OPERATION si type es uno de GL_UNSIGNED_BYTE_3_3_2, GL_UNSIGNED_BYTE_2_3_3_REV, GL_UNSIGNED_SHORT_5_6_5 o GL_UNSIGNED_SHORT_5_6_5_REV y format no es GL_RGB

.

Se genera GL_INVALID_OPERATION si type es uno de GL_UNSIGNED_SHORT_4_4_4_4, GL_UNSIGNED_SHORT_4_4_4_4_REV, GL_UNSIGNED_SHORT_5_5_5_1, GL_UNSIGNED_SHORT_1_5_5_5_REV, GL_UNSIGNED_INT_8_8_8_8, GL_UNSIGNED_INT_8_8_8_8_REV, GL_UNSIGNED_INT_10_10_10_2 o GL_UNSIGNED_INT_2_10_10_10_REV y format no es ni GL_RGBA ni GL_BGRA

.

Se genera GL_INVALID_OPERATION si format es GL_STENCIL_INDEX y el formato interno base no es GL_STENCIL_INDEX

.

Se genera GL_INVALID_OPERATION si un nombre de objeto de búfer distinto de cero está enlazado al objetivo GL_PIXEL_UNPACK_BUFFER y el almacén de datos del objeto de búfer está actualmente

mapeado.

Se genera GL_INVALID_OPERATION si un nombre de objeto de búfer distinto de cero está enlazado al objetivo GL_PIXEL_UNPACK_BUFFER y los datos se desempaquetarían del objeto de búfer de manera que las lecturas de memoria requeridas excederían el tamaño del almacén de

datos.

Se genera GL_INVALID_OPERATION si un nombre de objeto de búfer distinto de cero está enlazado al objetivo GL_PIXEL_UNPACK_BUFFER y pixels no es divisible exactamente por el número de bytes necesarios para almacenar en memoria un dato indicado por ty

pe
.
