PARÁMETROS

program

Especifica el identificador del programa que contiene la variable uniforme a modificar.

location

Especifica la ubicación de la variable uniforme a modificar.

count

Para los comandos de vector (glProgramUniform*v), especifica el número de elementos que se van a modificar. Debe ser 1 si la variable uniforme objetivo no es un array, y 1 o más si es un array.

Para los comandos de matriz (glProgramUniformMatrix*), especifica el número de matrices que se van a modificar. Debe ser 1 si la variable uniforme objetivo no es un array de matrices, y 1 o más si es un array.

transpose

Para los comandos de matriz (glProgramUniformMatrix*), especifica si la matriz debe ser transpuesta. Debe ser GL_TRUE si la matriz en el shader está transpuesta con respecto a la matriz proporcionada en value, y GL_FALSE en caso contrario.

value

Puntero a la matriz o matrices que se utilizarán para actualizar el valor de la variable uniforme especificada. Las matrices se almacenan en orden de columna mayor (column-major order).

DESCRIPCIÓN

glProgramUniform* establece el valor de una o más variables uniformes en el objeto de programa especificado. Estas funciones están diseñadas para ser utilizadas después de que un programa ha sido enlazado y activado usando glUseProgram, o para establecer uniformes que no son parte de un programa activo.

Las funciones que terminan en 1f, 2f, 3f, y 4f establecen un solo valor float.

Las funciones que terminan en 1i, 2i, 3i, y 4i establecen un solo valor int.

Las funciones que terminan en 1ui, 2ui, 3ui, y 4ui establecen un solo valor unsigned int.

Las funciones que terminan en fv, iv, y uiv establecen un array de valores float, int, o unsigned int, respectivamente.

Las funciones glProgramUniformMatrix* establecen un array de matrices.

El parámetro program es el identificador del programa de la lista de programas enlazados. Si program es 0, el valor se establece en el programa actualmente activo.

El parámetro location es la ubicación de la variable uniforme que se va a modificar. Esta ubicación se obtiene normalmente llamando a glGetUniformLocation.

El parámetro count especifica cuántos elementos (para arrays de vectores) o matrices (para arrays de matrices) se van a establecer. Si la variable uniforme no es un array, count debe ser 1.

Para las funciones de matriz, transpose indica si las matrices en el array value deben ser transpuestas. Si es GL_TRUE, las matrices se transponen antes de ser establecidas.

El parámetro value apunta al primer elemento de un array de valores que se utilizarán para establecer la variable uniforme.

Estas funciones son las preferidas sobre el uso de glUniform cuando se trabaja con programas creados explícitamente, ya que no requieren que el programa sea activado primero.

ERRORES

Se genera GL_INVALID_OPERATION si program no es el nombre de un programa válido.

Se genera GL_INVALID_OPERATION si program es 0 y no hay ningún programa activo.

Se genera GL_INVALID_OPERATION si location es un valor no válido devuelto por glGetUniformLocation.

Se genera GL_INVALID_OPERATION si la variable uniforme referenciada por location en program no es del tipo apropiado para la función llamada.

Se genera GL_INVALID_OPERATION si el tipo de la variable uniforme referenciada por location no coincide con el tipo de los valores en value.

Se genera GL_INVALID_VALUE si count es negativo.

Se genera GL_INVALID_OPERATION si la variable uniforme referenciada por location es una matriz y la función llamada es una de las funciones de vector, o viceversa.

Se genera GL_INVALID_OPERATION si program está activo y la variable uniforme referenciada por location es una variable en el bloque UBO.

DESCRIPCIÓN glProgramUniform modifica el valor de una variable uniforme o de un array de variables uniformes. La ubicación de la variable uniforme a modificar se especifica mediante location, que debe ser un valor devuelto por glGetUniformLocation(). glProgramUniform opera sobre el objeto

Los comandos glProgramUniform{1|2|3|4}{f|i|ui} se usan para cambiar el valor de la variable uniforme especificada por location usando los valores pasados como argumentos. El número especificado en el comando debe coincidir con el número de componentes en el tipo de datos de la variable uniforme especificada (por ejemplo, 1 para float, int, unsigned int, bool; 2 para vec2, ivec2, uvec2, bvec2, etc.). El sufijo f indica que se están pasando valores de punto flotante; el sufijo i indica que se están pasando valores enteros; el sufijo ui indica que se están pasando valores enteros sin signo, y este tipo también debe coincidir con el tipo de datos de la variable uniforme especificada. Las variantes i de esta función deben usarse para proporcionar valores para variables uniformes definidas como int, ivec2, ivec3, ivec4, o arrays de estos. Las variantes ui de esta función deben usarse para proporcionar valores para variables uniformes definidas como unsigned int, uvec2, uvec3, uvec4, o arrays de estos. Las variantes f deben usarse para proporcionar valores para v ariables uniformes de tipo float, vec2, vec3, vec4, o arrays de estos. Se pueden usar las variantes i, ui o f para proporcionar valores para variables uniformes de tipo bool, bvec2, bvec3, bvec4, o arrays de estos. La variable uniforme

se

establecerá en false si el valor de entrada es 0 o 0.0f, y se establecerá en true en caso contrario. Todas las variables uniformes activas definidas en un objeto de programa se inicializan a 0 cuando el objeto de programa se enlaza correctamente. Retienen los valores asignados por una llamada a glProgramUniform hasta

que

ocurre la siguiente operación de enlace exitosa en el objeto de programa, cuando se vuelven a inicializar a 0. Los comandos glProgramUniform{1|2|3|4}{f|i|ui}v pueden usarse para modificar una sola variable uniforme o un array de variables uniformes. Estos comandos pasan un count y un puntero a los valores a cargar en una variable uniforme o en un array de variables uniformes. Se debe usar un count de 1 si se modifica el valor de una sola variable uniforme, y se puede usar un count de 1 o mayor para modificar un array completo o parte de un array. Al cargar n elementos a partir de una posición arbitraria m en un array de variables uniformes, los elementos m + n - 1 en el array serán reemplazados con los nuevos valores. Si m + n - 1 es mayor que el tamaño del array de variables uniformes, los valores para todos los elementos del array más allá del final del array serán ignorados. El número especificado en el nombre del comando indica el número de componentes para cada elemento en value, y debe coincidir con el número de componentes en el tipo de datos de la variable uniforme especificada (por ejemplo, 1 para float, int, bool; 2 para vec2, ivec2, bvec2, etc.).
