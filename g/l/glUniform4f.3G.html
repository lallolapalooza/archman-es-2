DESCRIPCIÓ

N

glUniform modifica el valor de una variable uniforme o de un array de variables uniformes. La ubicación de la variable uniforme a modificar se especifica con location, que debe ser un valor devuelto por glGetUniformLocation(). glUniform opera sobre el objeto de programa que se hizo parte del estado actual al llamar a glUseProgr

am().

Los comandos glUniform{1|2|3|4}{f|i|ui} se usan para cambiar el valor de la variable uniforme especificada por location usando los valores pasados como argumentos. El número especificado en el comando debe coincidir con el número de componentes en el tipo de datos de la variable uniforme especificada (por ejemplo, 1 para float, int, unsigned int, bool; 2 para vec2, ivec2, uvec2, bvec2, etc.). El sufijo f indica que se están pasando valores de punto flotante; el sufijo i indica que se están pasando valores enteros; el sufijo ui indica que se están pasando valores enteros sin signo, y este tipo también debe coincidir con el tipo de datos de la variable uniforme especificada. Las variantes i de esta función deben usarse para proporcionar valores para variables uniformes definidas como int, i

DESCRIPCIÓN

glUniform{1 | 2 | 3 | 4}{f | i | ui} [location, value] sets the single uniform variable whose location is location to the single value value.

glUniform{1 | 2 | 3 | 4}{f | i | ui}v [location, count, value] sets the indicated uniform variable or variables to count values from the array pointed to by value.

glUniformMatrix{2 | 3 | 4 | 2x3 | 3x2 | 2x4 | 4x2 | 3x4 | 4x3}fv [location, count, transpose, value] sets the indicated matrix or matrices to count matrices specified by value.

The commands with a single letter suffix correspond to loading a single value. The commands with a v suffix correspond to loading multiple values or an array of uniform variables. For example, glUniform3f loads three floating-point values, and glUniform3fv loads an array of three floating-point values.

The data types of the parameters for the glUniform functions correspond to the data types of the uniform variables as follows: the i variants load uniform variables of type int, ivec2, ivec3, ivec4, or arrays of these. The ui variants of this function should be used to provide values for uniform variables defined as unsigned int, uvec2, uvec3, uvec4, or arrays of these. The f variants should be used to provide values for uniform variables of type float, vec2, vec3, vec4, or arrays of these. Either the i, ui or f variants may be used to provide values for uniform variables of type bool, bvec2, bvec3, bvec4, or arrays of these. The uniform variable will be set to false if the input value is 0 or 0.0f, and it will be set to true otherwise.

All active uniform variables defined in a program object are initialized to 0 when the program object is linked successfully. They retain the values assigned to them by a call to glUniform until the next successful link operation occurs on the program object, when they are once again initialized to 0.

The commands glUniform{1|2|3|4}{f|i|ui}v can be used to modify a single uniform variable or a uniform variable array. These commands pass a count and a pointer to the values to be loaded into a uniform variable or a uniform variable array. A count of 1 should be used if modifying the value of a single uniform variable, and a count of 1 or greater can be used to modify an entire array or part of an array. When loading n elements starting at an arbitrary position m in a uniform variable array, elements m + n - 1 in the array will be replaced with the new values. If m + n - 1 is larger than the size of the uniform variable array, values for all array elements beyond the end of the array will be ignored. The number specified in the name of the command indicates the number of components for each element in value, and it should match the number of components in the data type of the specified uniform variable (e.g., 1 for float, int, bool; 2 for vec2, ivec2, bvec2, etc.). The data type specified in the name of the command must match the data type for the specified uniform variable as described previously for glUniform{1|2|3|4}{f|i|ui}.

For uniform variable arrays, each element of the array is considered to be of the type indicated in the name of the command (e.g., glUniform3f or glUniform3fv can be used to load a uniform variable array of type vec3). The number of elements of the uniform variable array to be modified is specified by count

The commands glUniformMatrix{2|3|4|2x3|3x2|2x4|4x2|3x4|4x3}fv are used to modify a matrix or an array of matrices. The numbers in the command name are interpreted as the dimensionality of the matrix. The number 2 indicates a 2 × 2 matrix (i.e., 4 values), the number 3 indicates a 3 × 3 matrix (i.e., 9 values), and the number 4 indicates a 4 × 4 matrix (i.e., 16 values). Non-square matrix dimensionality is explicit, with the first number representing the number of columns and the second number representing the number of rows. For example, 2x4 indicates a 2 × 4 matrix with 2 columns and 4 rows (i.e., 8 values). If transpose is GL_FALSE, each matrix is assumed to be supplied in column major order. If transpose is GL_TRUE, each matrix is assumed to be supplied in row major order. The count argument indicates the number of matrices to be passed. A count of 1 should be used if modifying the value of a single matrix, and a count greater than 1 can be used to modify an array of matrices.

NOTAS

glUniform1i y glUniform1iv son las únicas dos funciones que pueden usarse para cargar variables uniformes definidas como tipos de sampler. Cargar samplers con cualquier otra función resultará en un error GL_INVALID_OPERATION.

Si count es mayor que 1 y la variable uniforme indicada no es un array, se generará un error GL_INVALID_OPERATION y la variable uniforme especificada permanecerá sin cambios.

Aparte de las excepciones anteriores, si el tipo y tamaño de la variable uniforme declarada en el shader no coinciden con el tipo y tamaño especificados en el nombre del comando utilizado para cargar su valor, se generará un error GL_INVALID_OPERATION y la variable uniforme especificada permanecerá sin cambios.

Si location es un valor distinto de -1 y no representa una ubicación uniforme válida en el objeto de programa actual, se generará un error y no se realizarán cambios en el almacenamiento de la variable uniforme del objeto de programa actual. Si location es igual a -1, los datos proporcionados se ignorarán silenciosamente y la variable uniforme especificada no se modificará.

ERRORES

Se genera GL_INVALID_OPERATION si no hay un objeto de programa actual.

Se genera GL_INVALID_OPERATION si el tamaño de la variable uniforme declarada en el shader no coincide con el tamaño indicado por el comando glUniform.

Se genera GL_INVALID_OPERATION si se utiliza una de las variantes de entero con signo o sin signo de esta función para cargar una variable uniforme de tipo float, vec2, vec3, vec4, o un array de estas, o si se utiliza una de las variantes de punto flotante de esta función para cargar una variable uniforme de tipo int, ivec2, ivec3, ivec4, unsigned int, uvec2, uvec3, uvec4, o un array de estas.

Se genera GL_INVALID_OPERATION si se utiliza una de las variantes de entero con signo de esta función para cargar una variable uniforme de tipo unsigned int, uvec2, uvec3, uvec4, o un array de estas.

Se genera GL_INVALID_OPERATION si se utiliza una de las variantes de entero sin signo de esta función para cargar una variable uniforme de tipo int, ivec2, ivec3, ivec4, o un array de estas.

Se genera GL_INVALID_OPERATION si location es una ubicación uniforme no válida para el objeto de programa actual y location no es igual a -1.

Se genera GL_INVALID_VALUE si count es menor que 0.

Se genera GL_INVALID_OPERATION si count es mayor que 1 y la variable uniforme indicada no es una variable de array.

Se genera GL_INVALID_OPERATION si se carga un sampler utilizando un comando que no sea glUniform1i y glUniform1iv.
