DESCRIPCIÓ

N

glGetDebugMessageLog recupera mensajes del registro de mensajes de depuración. Se recuperan como máximo count mensajes del registro. Si sources no es NULL, entonces la fuente de cada mensaje se escribe en hasta count elementos del array. Si types no es NULL, entonces el tipo de cada mensaje se escribe en hasta count elementos de el array. Si id no es NULL, entonces el identificador de cada mensaje se escribe en hasta count elementos del array. Si severities no es NULL, entonces la severidad de cada mensaje se escribe en hasta count elementos del array. Si lengths no es NULL, entonces la longitud de cada mensaje se escribe en hasta count elementos de el

array.

messageLog especifica la dirección de un array de caracteres en el que se escribirán los mensajes de depuración. Cada mensaje se concatenará en el array a partir del primer elemento de messageLog. bufSize especifica el tamaño del array messageLog. Si un mensaje no cabe en el espacio restante en messageLog, entonces la función termina y devuelve el número de mensajes escritos hasta el momento, que puede ser

cero.

Si glGetDebugMessageLog devuelve cero, entonces no hay mensajes presentes en el registro de depuración, o no había suficiente espacio en messageLog para recuperar el primer mensaje de la cola. Si messageLog es NULL, entonces no se escribe ningún mensaje y el valor de bufSize s

e ign
ora.

S

Aunque los mensajes de depuración pueden estar habilitados en un contexto no de depuración, la cantidad y el detalle d

e dichos mensajes pueden ser sustancialmente inferiores a los de un contexto de depuración. En particular, una implem
entación válida de la cola de mensajes de depuración en un contexto no de depuración puede no producir ningún mensaje.
