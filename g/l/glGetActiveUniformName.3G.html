NOMBRE

glGetActiveUniformName - consultar el nombre de un uniforme activo

ESPECIFICACIÓN C

void glGetActiveUniformName(GLuint program, GLuint uniformIndex, GLsizei bufSize, GLsizei *length, GLchar *uniformName);

PARÁMETROS

program

Especifica el programa que contiene el índice de uniforme activo uniformIndex.

uniformIndex

Especifica el índice del uniforme activo cuyo nombre se va a consultar.

bufSize

Especifica el tamaño del búfer, en unidades de GLchar, del búfer cuya dirección se especifica en uniformName.

length

Especifica la dirección de una variable que recibirá el número de caracteres que se escribieron o se habrían escrito en el búfer dirigido por uniformName.

uniformName

Especifica la dirección de un búfer en el que GL colocará el nombre del uniforme activo en uniformIndex dentro de program.

DESCRIPCIÓN

glGetActiveUniformName devuelve el nombre del uniforme activo en uniformIndex dentro de program. Si uniformName no es NULL, se escribirán hasta bufSize caracteres (incluido un terminador nulo) en la matriz cuya dirección se especifica en uniformName. Si length no es NULL, el número de caracteres que se escribieron (o se habrían escrito) en uniformName (sin incluir el terminador nulo) se colocará en la variable cuya dirección se especifica en length. Si length es NULL, no se devuelve ninguna longitud. La longitud del nombre de uniforme más largo en program se indica en el valor de GL_ACTIVE_UNIFORM_MAX_LENGTH, que se puede consultar con glGetProgram().

Si glGetActiveUniformName no tiene éxito, no se escribe nada en length ni en uniformName.

program debe ser el nombre de un programa para el que se ha emitido el comando glLinkProgram() anteriormente. No es necesario que program se haya enlazado correctamente. El enlace puede haber fallado porque el número de uniformes activos superó el límite.

uniformIndex debe ser un índice de uniforme activo del programa program, en el rango de cero al valor de GL_ACTIVE_UNIFORMS menos uno. El valor de GL_ACTIVE_UNIFORMS se puede consultar con glGetProgram().

ERRORES

Se genera GL_INVALID_VALUE si uniformIndex es mayor o igual al valor de GL_ACTIVE_UNIFORMS.

Se genera GL_INVALID_VALUE si bufSize es negativo.

Se genera GL_INVALID_VALUE si program no es el nombre de un objeto de programa para el que se ha emitido glLinkProgram().
