DESCRIPCIÓ

N

glDrawElementsInstancedBaseInstance se comporta de manera idéntica a glDrawElements() excepto que se ejecutan instancecount instancias del conjunto de elementos y el valor del contador interno instanceID avanza en cada iteración. instanceID es un contador interno de enteros de 32 bits que puede ser leído por un shader de vértices como gl_InstanceID

.

glDrawElementsInstancedBaseInstance tiene el mismo efecto

que: 
    if (mode, count, or type is invalid )
        generate appropriate error
    else {
        for (int i = 0; i < instancecount ; i++) {
            instanceID = i;
            glDrawElements(mode, count, type, indices);
        }
        instanceID = 0;
}

Los atributos de vértice específicos pueden ser clasificados como instanciados a través del uso de glVertexAttribDivisor(). Los atributos de vértice instanciados proporcionan datos de vértice por instancia al shader de vértices. El índice del vértice obtenido de los arrays de atributos de vértice instanciados habilitados se calcula como gl _ InstanceID divisor + baseInstance. Ten en cuenta que baseinstance no afecta el valor de gl_InstanceID visi

NOTA

S

glDrawElementsInstancedBaseInstance está disponible solo si la versión de GL es 4.2 o

superior.

GL_LINE_STRIP_ADJACENCY, GL_LINES_ADJACENCY, GL_TRIANGLE_STRIP_ADJACENCY y GL_TRIANGLES_ADJACENCY están disponibles

solo si la versión de
GL es 3.2 o superior.

ERRORE

S

Se genera GL_INVALID_ENUM si mode no es uno de GL_POINTS, GL_LINE_STRIP, GL_LINE_LOOP, GL_LINES, GL_TRIANGLE_STRIP, GL_TRIANGLE_FAN o GL_TRIANGLES

.

Se genera GL_INVALID_VALUE si count o instancecount es

negativo.

Se genera GL_INVALID_OPERATION si un shader de geometría está activo y mode es incompatible con el tipo de primitiva de entrada del shader de geometría en el objeto de programa actualmente

instalado.

Se genera GL_INVALID_OPERATION si un nombre de objeto buffer distinto de cero está vincula

do a un array habilitado y el almacén de datos
del objeto buffer está actualmente mapeado.
