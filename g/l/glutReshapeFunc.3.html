NOMBRE

glutReshapeFunc - establece la función de callback de redimensionamiento para la ventana actual.

SINTAXIS

void glutReshapeFunc(void (*func)(int width, int height));

ARGUMENTOS

func
La nueva función de callback de redimensionamiento.

DESCRIPCIÓN

glutReshapeFunc establece la función de callback de redimensionamiento para la ventana actual. La función de callback de redimensionamiento se activa cuando se redimensiona una ventana. También se activa una función de callback de redimensionamiento inmediatamente antes de la primera función de callback de visualización de una ventana después de su creación o cada vez que se establece una superposición para la ventana. Los parámetros `width` (ancho) y `height` (alto) de la función de callback especifican el nuevo tamaño de la ventana en píxeles. Antes de la llamada a la función de callback, la ventana actual se establece en la ventana que ha sido redimensionada.

Si no se registra una función de callback de redimensionamiento para una ventana o se pasa NULL a glutReshapeFunc (para anular el registro de una función de callback previamente registrada), se utiliza la función de callback de redimensionamiento por defecto. Esta función de callback por defecto simplemente llamará a glViewport(0,0,width,height) en el plano normal (y en la superposición si existe).

Si se establece una superposición para la ventana, se genera una única función de callback de redimensionamiento. Es responsabilidad de la función de callback actualizar tanto el plano normal como la superposición de la ventana (cambiando la capa en uso según sea necesario).

Cuando se redimensiona una ventana de nivel superior, las subventanas no se redimensionan. Corresponde al programa GLUT administrar el tamaño y las posiciones de las subventanas dentro de una ventana de nivel superior. Aun así, se activarán funciones de callback de redimensionamiento para las subventanas cuando su tamaño cambie usando glutReshapeWindow.

VER TAMBIÉN

glutDisplayFunc, glutReshapeWindow
