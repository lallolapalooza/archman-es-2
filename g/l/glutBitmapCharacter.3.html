glutBitmapCharacter(3)

Paquete: freeglut

Licencias: X11

glutBitmapCharacter(3) freeglut glutBitmapCharacter(3)

NOMBRE

glutBitmapCharacter - renderiza un carácter de mapa de bits usando OpenGL.

SINTAXIS

void glutBitmapCharacter(void *font, int character);

ARGUMENTOS

fuente
Fuente de mapa de bits a utilizar.
carácter
Carácter a renderizar (no limitado a 8 bits).

DESCRIPCIÓN

Sin utilizar ninguna lista de visualización, glutBitmapCharacter renderiza el carácter en la fuente de mapa de bits nombrada. Las fuentes disponibles son:

GLUT_BITMAP_8_BY_13
Una fuente de ancho fijo en la que cada carácter cabe en un rectángulo de 8 por 13 píxeles. Los mapas de bits exactos a utilizar se definen mediante los mapas de bits de glifos X estándar para la fuente X denominada:

-misc-fixed-medium-r-normal--13-120-75-75-C-80-iso8859-1

GLUT_BITMAP_9_BY_15
Una fuente de ancho fijo en la que cada carácter cabe en un rectángulo de 9 por 15 píxeles. Los mapas de bits exactos a utilizar se definen mediante los mapas de bits de glifos X estándar para la fuente X denominada:

-misc-fixed-medium-r-normal--15-140-75-75-C-90-iso8859-1

GLUT_BITMAP_TIMES_ROMAN_10
Una fuente Times Roman de 10 puntos con espaciado proporcional. Los mapas de bits exactos a utilizar se definen mediante los mapas de bits de glifos X estándar para la fuente X denominada:

-adobe-times-medium-r-normal--10-100-75-75-p-54-iso8859-1

GLUT_BITMAP_TIMES_ROMAN_24
Una fuente Times Roman de 24 puntos con espaciado proporcional. Los mapas de bits exactos a utilizar se definen mediante los mapas de bits de glifos X estándar para la fuente X denominada:

-adobe-times-medium-r-normal--24-240-75-75-p-124-iso8859-1

GLUT_BITMAP_HELVETICA_10
Una fuente Helvetica de 10 puntos con espaciado proporcional. Los mapas de bits exactos a utilizar se definen mediante los mapas de bits de glifos X estándar para la fuente X denominada:

-adobe-helvetica-medium-r-normal--10-100-75-75-p-56-iso8859-1

GLUT_BITMAP_HELVETICA_12
Una fuente Helvetica de 12 puntos con espaciado proporcional. Los mapas de bits exactos a utilizar se definen mediante los mapas de bits de glifos X estándar para la fuente X denominada:

-adobe-helvetica-medium-r-normal--12-120-75-75-p-67-iso8859-1

GLUT_BITMAP_HELVETICA_18
Una fuente Helvetica de 18 puntos con espaciado proporcional. Los mapas de bits exactos a utilizar se definen mediante los mapas de bits de glifos X estándar para la fuente X denominada:

-adobe-helvetica-medium-r-normal--18-180-75-75-p-98-iso8859-1

La renderización de un carácter inexistente no tiene ningún efecto. glutBitmapCharacter establece automáticamente los modos de almacenamiento de píxeles de desempaquetado de OpenGL que necesita de manera apropiada, y guarda y restaura los modos anteriores antes de regresar. La llamada generada a glBitmap ajustará la posición actual del raster según el ancho del carácter.

EJEMPLO

Aquí hay una rutina que muestra cómo renderizar una cadena de texto ASCII con glutBitmapCharacter:

  void
  output(int x, int y, char *string)
  {
    int len, i;
    glRasterPos2f(x, y);
    len = (int) strlen(string);
    for (i = 0; i < len; i++) {
      glutBitmapCharacter(GLUT_BITMAP_HELVETICA_18, string[i]);
    }
  }
