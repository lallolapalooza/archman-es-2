DESCRIPCIÓ

N

glGetActiveUniformsiv consulta el valor del parámetro llamado pname para cada uno de los uniformes dentro de program cuyos índices se especifican en el array de uniformCount enteros sin signo uniformIndices. Tras un éxito, el valor del parámetro para cada uniforme se escribe en la entrada correspondiente del array cuya dirección se da en params. Si se genera un error, no se escribe nada en params

.

Si pname es GL_UNIFORM_SIZE, se devuelve un array que identifica el tamaño de los uniformes especificados por el array correspondiente de uniformIndices. Los tamaños devueltos están en unidades del tipo devuelto por una consulta de GL_UNIFORM_TYPE. Para uniformes activos que son arrays, el tamaño es el número de elementos activos en el array; para todos los demás uniformes, el tamaño es

uno.

Si pname es GL_UNIFORM_NAME_LENGTH, se devuelve un array que identifica la longgth, incluyendo el carácter nulo final, de las cadenas de nombre uniforme especificadas por la matriz correspondiente de uniformIndices es

devuelta.

Si pname es GL_UNIFORM_BLOCK_INDEX, se devuelve una matriz que identifica el índice del bloque uniforme de cada uno de los uniformes especificados por la matriz correspondiente de uniformIndices. El índice del bloque uniforme de un uniforme asociado con el bloque uniforme por defecto es

-1.

Si pname es GL_UNIFORM_OFFSET, se devuelve una matriz de desplazamientos del búfer de uniformes. Para los uniformes en un bloque uniforme con nombre, el valor devuelto será su desplazamiento, en unidades básicas de máquina, relativo al comienzo del bloque uniforme en el almacén de datos del objeto búfer. Para los uniformes de contador atómico, el valor devuelto será su desplazamiento relativo al comienzo de su búfer de contador atómico activo. Para todos los demás uniformes, se devolverá

-1.

Si pname es GL_UNIFORM_ARRAY_STRIDE, se devuelve una matriz que identifica el intervalo entre elementos de cada uno de los uniformes especificados por la matriz correspondiente de uniformIndices. Para los uniformes en bloques uniformes con nombre y para los uniformes declarados como contadores atómicos, el intervalo es la diferencia, en unidades básicas de máquina, de elementos consecutivos en un array, o cero para los uniformes no declarados como un array. Para todos los demás uniformes, se devolverá un intervalo de

-1.

Si pname es GL_UNIFORM_MATRIX_STRIDE, se devuelve una matriz que identifica el intervalo entre columnas de una matriz en orden de columnas o filas de una matriz en orden de filas, en unidades básicas de máquina, de cada uno de los uniformes especificados por la matriz correspondiente de uniformIndices. El intervalo de matriz de un uniforme asociado con el bloque uniforme por defecto es -1. Nótese que esta información solo tiene sentido para los uniformes que son matrices. Para los uniformes que no son matrices, pero están declarados en un bloque uniforme con nombre, se devuelve un intervalo de matriz de

cero.

Si pname es GL_UNIFORM_IS_ROW_MAJOR, se devuelve una matriz que identifica si cada uno de los uniformes especificados por la matriz correspondiente de uniformIndices es una matriz en orden de filas o no. Un valor de uno indica una matriz en orden de filas, y un valor de cero indica una matriz en orden de columnas, una matriz en el bloque uniforme por defecto, o una no

matriz.

Si pname es GL_UNIFORM_ATOMIC_COUNTER_BUFFER_INDEX, se devuelve una matriz que identifica el índice del búfer de contador atómico activo de cada uno de los uniformes especificados por la matriz correspondiente de uniformIndices . Para los uniformes que no sean contadores atómicos, el índice de búfer devuelto es -1. Los índices devueltos pueden pasarse a glGetActiveAtomicCounterBufferiv() para consultar las propiedades del búfer asociado

, y no necesariamente el punto de enlace espe
cificado en la declaración del uniforme.

NOTA

S

Los tipos dobles, GL_DOUBLE, GL_DOUBLE_VEC2, GL_DOUBLE_VEC3, GL_DOUBLE_VEC4, GL_DOUBLE_MAT2, GL_DOUBLE_MAT3, GL_DOUBLE_MAT4, GL_DOUBLE_MAT2x3, GL_DOUBLE_MAT2x4, GL_DOUBLE_MAT3x2, GL_DOUBLE_MAT3x4, GL_DOUBLE_MAT4x2, y GL_DOUBLE_MAT4x3 solo están disponibles si la versión de GL es 4.1 o

superior.

GL_UNIFORM_ATOMIC_COUNTER_BUFFER_INDEX solo es aceptado por pname si la versión de

GL es 4.2
o superior.

ERRORE

S

Se genera GL_INVALID_VALUE si program no es un valor generado por

OpenGL.

Se genera GL_INVALID_OPERATION si program no es un objeto de

programa.

Se genera GL_INVALID_VALUE si uniformCount es mayor o igual que el valor de GL_ACTIVE_UNIFORMS para program

.

Se genera GL_INVALID_ENUM si pname no es un

token a
ceptado.
