DESCRIPCIÓ

N

glGetActiveAttrib devuelve información sobre una variable de atributo activa en el objeto de programa especificado por program. El número de atributos activos se puede obtener llamando a glGetProgram() con el valor GL_ACTIVE_ATTRIBUTES. Un valor de 0 para index selecciona la primera variable de atributo activa. Los valores permitidos para index van desde cero hasta el número de variables de atributo activas menos

uno.

Un vertex shader puede usar variables de atributo integradas, variables de atributo definidas por el usuario, o ambas. Las variables de atributo integradas tienen un prefijo de "gl_" y referencian los atributos de vértice convencionales de OpenGL (por ejemplo, gl_Vertex, gl_Normal, etc., consulte la especificación del Lenguaje de Sombreado de OpenGL para una lista completa.) Las variables de atributo definidas por el usuario tienen nombres arbitrarios y obtienen sus valores a través de atributos de vértice genéricos numerados. Una variable de atributo (integrada o definida por el usuario) se considera activa si se determina durante la operación de enlace que puede ser accedida durante la ejecución del programa. Por lo tanto, program debería haber sido previamente el destino de una llamada a glLinkProgram(), pero no es necesario que haya sido enlazado con

éxito.

El tamaño del búfer de caracteres necesario para almacenar el nombre de variable de atributo más largo en program se puede obtener llamando a glGetProgram() con el valor GL_ACTIVE_ATTRIBUTE_MAX_LENGTH. Este valor debería usarse para asignar un búfer de tamaño suficiente para almacenar el nombre de atributo devuelto. El tamaño de este búfer de caracteres se pasa en bufSize, y un puntero a este búfer de caracteres se pasa en name

.

glGetActiveAttrib devuelve el nombre de la variable de atributo indicada por index, almacenándolo en el búfer de caracteres especificado por name. La cadena devuelta estará terminada en nulo. El número real de caracteres escritos en este búfer se devuelve en length, y este recuento no incluye el carácter de terminación nulo. Si no se necesita la longitud de la cadena devuelta, se puede pasar un valor de NULL en el argumento l

ength.

El argumento type especifica un puntero a una variable en la que se escribirá el tipo de datos de la variable de atributo. Las constantes simbólicas GL_FLOAT, GL_FLOAT_VEC2, GL_FLOAT_VEC3, GL_FLOAT_VEC4, GL_FLOAT_MAT2, GL_FLOAT_MAT3, GL_FLOAT_MAT4, GL_FLOAT_MAT2x3, GL_FLOAT_MAT2x4, GL_FLOAT_MAT3x2, GL_FLOAT_MAT3x4, GL_FLOAT_MAT4x2, GL_FLOAT_MAT4x3, GL_INT, GL_INT_VEC2, GL_INT_VEC3, GL_INT_VEC4, GL_UNSIGNED_INT, GL_UNSIGNED_INT_VEC2, GL_UNSIGNED_INT_VEC3, GL_UNSIGNED_INT_VEC4, GL_DOUBLE, GL_DOUBLE_VEC2, GL_DOUBLE_VEC3, GL_DOUBLE_VEC4, GL_DOUBLE_MAT2, GL_DOUBLE_MAT3, GL_DOUBLE_MAT4, GL_DOUBLE_MAT2x3, GL_DOUBLE_MAT2x4, GL_DOUBLE_MAT3x2, GL_DOUBLE_MAT3x4, GL_DOUBLE_MAT4x2, o GL_DOUBLE_MAT4x3 pueden ser devueltas. El argumento size devolverá el tamaño del atributo, en unidades del tipo devuelto en type

.

La lista de variables de atributo activas puede incluir tanto variables de atributo integradas (que comienzan con el prefijo "gl_") como nombres de variables de atributo definidas por el

usuario.

Esta función devolverá tanta información como pueda sobre la variable de atributo activa especificada. Si no hay información disponible, length será 0, y name será una cadena vacía. Esta situación podría ocurrir si se llama a esta función después de una operación de enlace que falló. Si ocurre un error, los valores de retorno length, size, type, y name no serán

modifi
cados.

ERRORE

S

Se genera GL_INVALID_VALUE si program no es un valor generado por

OpenGL.

Se genera GL_INVALID_OPERATION si program no es un objeto de

programa.

Se genera GL_INVALID_VALUE si index es mayor o igual al número de variables de atributo activas en program

.

Se genera GL_INVALID_VALUE si bufSize es men

or
que 0.
