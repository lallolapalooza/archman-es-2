glutDisplayFunc(3)

Paquete: freeglut

Licencias: X11

glutDisplayFunc(3) freeglut glutDisplayFunc(3)

NOMBRE

glutDisplayFunc - establece la función de retorno de llamada de visualización para la ventana actual.

SINTAXIS

void glutDisplayFunc(void (*func)(void));

ARGUMENTOS

func
La nueva función de retorno de llamada de visualización.

DESCRIPCIÓN

glutDisplayFunc establece la función de retorno de llamada de visualización para la ventana actual. Cuando GLUT determina que el plano normal de la ventana necesita ser redibujado, se llama a la función de retorno de llamada de visualización de la ventana. Antes de la llamada de retorno, la ventana actual se establece como la ventana que necesita ser redibujada y (si no hay una función de retorno de llamada de visualización de superposición registrada) la capa en uso se establece como el plano normal. La función de retorno de llamada de visualización se llama sin parámetros. Se debe redibujar toda la región del plano normal en respuesta a la llamada de retorno (esto incluye los búferes auxiliares si su programa depende de su estado).

GLUT determina cuándo se debe activar la función de retorno de llamada de visualización basándose en el estado de redibujado de la ventana. El estado de redibujado de una ventana se puede establecer explícitamente llamando a glutPostRedisplay o implícitamente como resultado de daños en la ventana informados por el sistema de ventanas. Múltiples redibujados publicados para una ventana se fusionan por GLUT para minimizar el número de llamadas de retorno de visualización que se realizan.

Cuando se establece una superposición para una ventana, pero no hay una función de retorno de llamada de visualización de superposición registrada, la función de retorno de llamada de visualización se utiliza para redibujar tanto la superposición como el plano normal (es decir, se llamará si se establece el estado de redibujado o el estado de redibujado de superposición). En este caso, la capa en uso no se cambia implícitamente al entrar en la función de retorno de llamada de visualización.

Consulte glutOverlayDisplayFunc para comprender cómo se pueden establecer funciones de retorno de llamada distintas para la superposición y el plano normal de una ventana.

Cuando se crea una ventana, no existe una función de retorno de llamada de visualización para ella. Es responsabilidad del programador instalar una función de retorno de llamada de visualización para la ventana antes de que se muestre. Se debe registrar una función de retorno de llamada de visualización para cualquier ventana que se muestre. Si una ventana se muestra sin registrar una función de retorno de llamada de visualización, se produce un error fatal. Pasar NULL a glutDisplayFunc es ilegal a partir de GLUT 3.0; no hay forma de "desregistrar" una función de retorno de llamada de visualización (aunque siempre se puede registrar otra rutina de retorno de llamada).

Al regresar de la función de retorno de llamada de visualización, se borra el estado dañado normal de la ventana (devuelto llamando a glutLayerGet(GLUT_NORMAL_DAMAGED). Si no hay una función de retorno de llamada de visualización de superposición registrada, también se borra el estado dañado de superposición de la ventana (devuelto llamando a glutLayerGet(GLUT_OVERLAY_DAMAGED).

VER TAMBIÉN

glutCreateMenu, glutPostRedisplay, glutOverlayDisplayFunc
