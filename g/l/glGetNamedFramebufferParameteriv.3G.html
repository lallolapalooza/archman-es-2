DESCRIPCIÓ

N

glGetFramebufferParameteriv y glGetNamedFramebufferParameteriv consultan parámetros de un objeto framebuffer

especificado.

Para glGetFramebufferParameteriv, el objeto framebuffer es el que está enlazado a target, que debe ser uno de GL_DRAW_FRAMEBUFFER, GL_READ_FRAMEBUFFER o GL_FRAMEBUFFER. GL_FRAMEBUFFER es equivalente a GL_DRAW_FRAMEBUFFER. Los framebuffers predeterminados también pueden ser consultados si están enlazados a target

.

Para glGetNamedFramebufferParameteriv, framebuffer es el nombre del objeto framebuffer. Si framebuffer es cero, se consulta el framebuffer de dibujo

predeterminado.

Tras una devolución exitosa, param contendrá el valor del parámetro del framebuffer especificado por pname, como se describe a

continuación.

Los siguientes parámetros solo pueden ser consultados para objetos

framebuffer:

GL_FRAMEBUFFER_DEFAULT_WIDT

H
params devuelve el valor de GL_FRAMEBUFFER_DEFAULT_WIDTH para el objeto
framebuffer.

GL_FRAMEBUFFER_DEFAULT_HEIGH

T
params devuelve el valor de GL_FRAMEBUFFER_DEFAULT_HEIGHT para el objeto
framebuffer.

GL_FRAMEBUFFER_DEFAULT_LAYER

S
params devuelve el valor de GL_FRAMEBUFFER_DEFAULT_LAYERS para el objeto
framebuffer.

GL_FRAMEBUFFER_DEFAULT_SAMPLE

S
params devuelve el valor de GL_FRAMEBUFFER_DEFAULT_SAMPLES para el objeto
framebuffer.

GL_FRAMEBUFFER_DEFAULT_FIXED_SAMPLE_LOCATION

S
params devuelve el valor booleano de GL_FRAMEBUFFER_DEFAULT_FIXED_SAMPLE_LOCATIONS
.

Los siguientes parámetros pueden ser consultados tanto para framebuffers predeterminados como para objetos

framebuffer:

GL_DOUBLEBUFFE

R

framebuffer.

GL_IMPLEMENTATION_COLOR_READ_FORMA

ls().

GL_SAMPLE

NOTA

S

Las consultas de framebuffers predeterminados solo están soportadas si la versión de GL es 4.5 o superior. De lo contrario, se genera un error GL_INVALID_OPERATION

.

Las consultas de los parámetros dependientes del framebuffer GL_DOUBLEBUFFER, GL_IMPLEMENTATION_COLOR_READ_FORMAT, GL_IMPLEMENTATION_COLOR_READ_TYPE, GL_SAMPLES, GL_SAMPLE_BUFFERS y GL_STEREO solo están soportadas si la versión de GL es 4.5 o

superior.

El estado dependiente del framebuffer GL_SAMPLE_POSITION no puede s

er consultado con
estos comandos.

ERRORE

S

Se genera GL_INVALID_ENUM con glGetFramebufferParameteriv si target no es uno de los destinos de framebuffer

aceptados.

Se genera GL_INVALID_OPERATION con glGetNamedFramebufferAttachmentParameteriv si framebuffer no es cero o el nombre de un objeto framebuffer

existente.

Se genera GL_INVALID_ENUM si pname no es uno de los nombres de parámetro

aceptados.

Se genera GL_INVALID_OPERATION si se consulta un framebuffer predeterminado y pname no es uno de GL_DOUBLEBUFFER, GL_IMPLEMENTATION_COLOR_READ_FORMAT, GL_IMPLEMENTATION_COLOR_READ_TYPE, GL_SAMPLES, GL_SAMPLE_BUFFERS o GL_ST
