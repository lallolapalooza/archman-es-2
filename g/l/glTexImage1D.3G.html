DESCRIPCIÓ

N

El mapeo de texturas asigna una porción de una imagen de textura especificada a cada primitiva gráfica para la que el mapeo de texturas está habilitado. Para habilitar y deshabilitar el mapeo de texturas unidimensional, llame a glEnable()

y

glDisable con el argumento GL_TEXTURE_1D

.

Las imágenes de textura se definen con glTexImage1D. Los argumentos describen los parámetros de la imagen de textura, como el ancho, el ancho del borde, el número de nivel de detalle (véase glTexParameter()), y la resolución interna y el formato utilizados para almacenar la imagen. Los últimos tres argumentos describen cómo se representa la imagen en

memoria.

Si target es GL_PROXY_TEXTURE_1D, no se leen datos de data, pero todo el estado de la imagen de textura se recalcula, se comprueba su consistencia y se verifica con las capacidades de la implementación. Si la implementación no puede manejar una textura del tamaño solicitado, establece todo el estado de la imagen en 0, pero no genera un error (véase glGetError()). Para consultar un array de mipmap completo, use un nivel de array de imagen mayor o igual que

1.

Si target es GL_TEXTURE_1D, se leen datos de data como una secuencia de bytes, shorts o longs con signo o sin signo, o valores de punto flotante de precisión simple, dependiendo de type. Estos valores se agrupan en conjuntos de uno, dos, tres o cuatro valores, dependiendo de format, para formar elementos. Cada byte de datos se trata como ocho elementos de 1 bit, con el orden de bits determinado por GL_UNPACK_LSB_FIRST (véase glPixelStore())

.

Si un objeto de búfer con nombre distinto de cero está vinculado al objetivo GL_PIXEL_UNPACK_BUFFER (véase glBindBuffer()) mientras se especifica una imagen de textura, data se trata como un desplazamiento en bytes dentro del almacén de datos del objeto de

búfer.

El primer elemento corresponde al extremo izquierdo del array de textura. Los elementos posteriores avanzan de izquierda a derecha a través de los texels restantes en el array de textura. El último elemento corresponde al extremo derecho del array de

textura.

format determina la composición de cada elemento en data. Puede asumir uno de estos valores

simbólicos:

GL_RE

D
Cada elemento es un único componente rojo. GL lo convierte a punto flotante y lo ensambla en un elemento RGBA adjuntando 0 para verde y azul, y 1 para alfa. Cada componente se limita al rango [0,1]
.

GL_R

G
Cada elemento es un doble rojo/verde. GL lo convierte a punto flotante y lo ensambla en un elemento RGBA adjuntando 0 para azul y 1 para alfa. Cada componente se limita al rango [0,1]
.

GL_RGB, GL_BG

R
Cada elemento es una tripleta RGB. GL lo convierte a punto flotante y lo ensambla en un elemento RGBA adjuntando 1 para alfa. Cada componente se limita al rango [0,1]
.

GL_RGBA, GL_BGR

A
Cada elemento contiene los cuatro componentes. Cada componente se limita al rango [0,1]
.

GL_DEPTH_COMPONEN

T
Cada elemento es un único valor de profundidad. GL lo convierte a punto flotante y lo limita al rango [0,1]
.

Si una aplicación desea almacenar la textura en una cierta resolución o en un cierto formato, puede solicitar la resolución y el formato con internalformat. GL elegirá una representación interna que se aproxime estrechamente a la solicitada por internalformat, pero puede que no coincida exactamente. (Las representaciones especificadas por GL_RED, GL_RG, GL_RGB y GL_RGBA deben coincidir exactamente.

)

Una imagen de textura de un componente utiliza solo el componente rojo del color RGBA de data. Una imagen de dos componentes utiliza los valores R y A. Una imagen de tres componentes utiliza los valores R, G y B. Una imagen de cuatro componentes utiliza todos los componentes RGBA. El sombreado basado en imágenes se puede habilitar comparando las coordenadas r de la textura con los valores de profundidad de la textura para generar un resultado booleano.

glTexParameter() para detalles sobre la comparación de texturas. NOTA
