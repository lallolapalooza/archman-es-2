NAME

glProgramUniformMatrix4fv - specify the value of a uniform variable implemented as a matrix

C SPECIFICATION

void glProgramUniformMatrix4fv(GLint location, GLsizei count, GLboolean transpose,
    const GLfloat *value);

PARAMETERS

location
Specifies the location of an existing uniform variable in the program object to which value will be applied.
count
Specifies the number of matrices that will be downloaded and applied to the uniform variable named by location.
transpose
Specifies whether to transpose the matrix or matrices. Must be GL_FALSE.
value
Specifies a pointer to an array of count values that will be used to load the uniform variable.

DESCRIPTION

glProgramUniformMatrix4fv specifies the value of a uniform variable implemented as a 4x4 matrix of floating-point numbers. It can only be used to update uniform variables specified in the active program object.

If location is the uniform location of a matrix or an array of matrices, then glProgramUniformMatrix4fv assigns count matrices of 16 floating-point values each, from the array of matrices specified by value, to the indicated uniform variables.

If location is the uniform location of an array of mat4 uniform variables, then glProgramUniformMatrix4fv assigns count arrays of 16 floating-point values each, from the array of matrices specified by value, to the indicated uniform array variables.

If transpose is GL_TRUE, then all matrices specified in value will be transposed before being stored in the uniform variable. However, the OpenGL specification requires transpose to be GL_FALSE for glProgramUniformMatrix4fv.

If location specifies a uniform variable that is not of type mat4 or an array of mat4, a GL error is generated.

If location specifies an array of uniform variables, glProgramUniformMatrix4fv loads count elements of the array, starting at the element corresponding to location. The actual elements loaded are those from index 0 to count-1 of the uniform variable. If location is the handle of a uniform variable that is not an array, then count must be 1.

If location is not valid, is for a uniform variable that does not match the specified type, or if a font error occurs, then no data is written and no action is taken.

This function can only affect the values of uniform variables that are contained in the currently active program object.

The matrix is assumed to be stored in column-major order. That is, the first 4 values in the value array specify the first column of the matrix, the next 4 values specify the second column, and so on.

NOTES

The functions glProgramUniformMatrix2fv, glProgramUniformMatrix2x3fv, glProgramUniformMatrix2x4fv, glProgramUniformMatrix3fv, glProgramUniformMatrix3x2fv, glProgramUniformMatrix3x4fv, glProgramUniformMatrix4fv, glProgramUniformMatrix4x2fv, and glProgramUniformMatrix4x3fv are deprecated. Use glProgramUniformMatrix4dv instead.

The function glProgramUniformMatrix4fv is available in version 3.0 of the OpenGL API and later.

ERRORS

GL_INVALID_OPERATION is generated if there is no active program object.

GL_INVALID_VALUE is generated if location is invalid, or if the type of the uniform variable indicated by location is not a mat4 or an array of mat4.

GL_INVALID_VALUE is generated if transpose is not GL_FALSE.

GL_INVALID_VALUE is generated if count is negative.
