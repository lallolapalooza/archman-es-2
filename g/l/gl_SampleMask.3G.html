NOMBRE

gl_SampleMask - especifica la máscara de cobertura de muestras para el fragmento actual

DECLARACIÓN

out int gl_SampleMask[] ;.SH "DESCRIPCIÓN"

gl_SampleMask es un array de salida del lenguaje de fragmentos que puede ser utilizado para establecer la máscara de muestra para el fragmento que se está procesando. La cobertura para el fragmento actual será el AND lógico de la máscara de cobertura y la salida gl_SampleMask. Es decir, establecer un bit en gl_SampleMask a cero hará que la muestra correspondiente se considere no cubierta a efectos de operaciones de fragmentos multiescala. Sin embargo, establecer los bits de la máscara de muestra a uno nunca habilitará muestras no cubiertas por la primitiva original. El bit B de la máscara gl_SampleMask[M] corresponde a la muestra 32 * M + B. Este array debe ser dimensionado en el shader de fragmentos, ya sea implícita o explícitamente, para que tenga el mismo tamaño que la máscara de muestras máxima dependiente de la implementación (como un array de elementos de 32 bits), determinado por el número máximo de muestras. Si el shader de fragmentos asigna estáticamente un valor a gl_SampleMask, la máscara de muestras será indefinida para cualquier elemento del array de cualquier invocación del shader de fragmentos que no logre asignar un valor. Si un shader no asigna estáticamente un valor a gl_SampleMask, la máscara de muestras no tiene ningún efecto en el procesamiento de un fragmento. Si el shader de fragmentos se está evaluando a una frecuencia distinta de por fragmento, los bits dentro de la máscara de muestras que no corresponden a la invocación actual del shader de fragmentos se ignoran.
