NOMBRE

goid-tool - utilidad de tarjeta inteligente para la tarjeta de huellas dactilares GoID

SINOPSIS

goid-tool [OPCIONES] [modo]

DESCRIPCIÓN

La utilidad goid-tool se puede utilizar desde la línea de comandos para leer y escribir datos de la tarjeta de huellas dactilares GoID[1].

OPCIONES

--help, -h

Muestra el mensaje de ayuda en pantalla.

--version, -V

Muestra la versión de la release del paquete OpenSC.

--reader cadena, -r cadena

Especifica el número del lector a usar. Por defecto, se usa el primer lector con tarjeta presente. Si el argumento es un ATR, se elegirá el lector con una tarjeta coincidente.

--verbose, -v

Hace que goid-tool sea más detallado. Úselo varias veces para ser aún más detallado.

--verify-pin, -p

Verifica el PIN.

--verify-bio, -b

Verifica la huella dactilar.

--verify-pin-or-bio

Verifica el PIN o la huella dactilar (elección del usuario).

OPCIONES PARA LA APLICACIÓN SOCMANAGER

--new-pin

Cambia el PIN.

--new-bio

Úselo (varias veces) para cambiar una o más plantillas biométricas.

--info

Vuelca información sobre la configuración del SoCManager.

OPCIONES PARA LA APLICACIÓN PACCESS

--certificate nombrearchivo, -c nombrearchivo

Úselo (varias veces) para pasar certificados CV.

--key, -k,

Clave privada para el certificado CV.

--print-cardid

Imprime el ID de la tarjeta.

--write-cardid datos

Escribe el ID de tarjeta especificado.

--print-paccessid

Imprime el ID PAccess.

--write-paccessid datos

Escribe el ID PAccess especificado.

--read-dg id

Lee el grupo de datos especificado; úselo varias veces para leer varios archivos.

--out-file nombrearchivo

Escribe la salida en un archivo en lugar de imprimirla; úselo una vez por cada uso de --read-dg.

--write-dg id

Escribe el grupo de datos especificado; úselo varias veces para escribir varios archivos.

--in-file nombrearchivo

Lee la entrada de un archivo; úselo una vez por cada uso de --write-dg.

--delete-dg id

Elimina el grupo de datos especificado; úselo varias veces para eliminar varios archivos.

--create-dg id

Crea el grupo de datos especificado; úselo varias veces para crear varios archivos.

--new-size tamaño

Tamaño del archivo de los DG recién creados.

--new-read-ac condición

Condición de acceso para leer los DG recién creados.

--new-read-ac condición

Condición de acceso para leer los DG recién creados.

--new-read-ac-chatbit índice

Bit de acceso requerido en el CHAT del certificado para leer los DG recién creados.

--new-write-ac condición

Condición de acceso para escribir los DG recién creados.

--new-write-ac-chatbit índice

Bit de acceso requerido en el CHAT del certificado para escribir los DG recién creados.

VER TAMBIÉN

opensc.conf(5)
