GOSOP(1) Manual de Comandos Generales GOSOP(1)

NOMBRE

gosop - Implementación de OpenPGP sin estado para GopenPGP

USO:

gosop [opciones globales] comando [opciones del comando] [argumentos...]

AUTOR:

Proton Technologies AG

COMANDOS

armor
Añadir Armadura ASCII
USO:
gosop armor [opciones del comando] < DATOS
OPCIONES:
--label valor
--label={auto|sig|key|cert|message} (por defecto: auto)
--help, -h: mostrar ayuda (por defecto: false)
dearmor
Eliminar Armadura ASCII
USO:
gosop dearmor < DATOS
OPCIONES:
--help, -h: mostrar ayuda (por defecto: false)
decrypt
Descifrar un Mensaje
USO:
gosop decrypt [opciones del comando] [CLAVE...] < TEXTOCIFRADO
OPCIONES:
--session-key-out valor
--session-key-out=CLAVE_SESION
--with-session-key valor
--with-session-key=CLAVE_SESION
--with-password valor
--with-password=CONTRASEÑA
--verify-out valor
--verify-out=VERIFICACIONES
--verify-with valor
--verify-out=CERTIFICADOS
--verify-not-before valor
--verify-not-before={-|FECHA} (por defecto: -)
--verify-not-after valor
--verify-not-after={-|FECHA} (por defecto: ahora)
--help, -h: mostrar ayuda (por defecto: false)
encrypt
Cifrar un Mensaje
USO:
gosop encrypt [opciones del comando] [CERTIFICADOS...] < DATOS
OPCIONES:
--as valor
--as={binary|text} (por defecto: binary)
--no-armor (por defecto: false)
--with-password valor
--with-password=CONTRASEÑA
--sign-with valor
--sign-with=CLAVE
--help, -h: mostrar ayuda (por defecto: false)
extract-cert
Extraer un Certificado de una Clave Secreta
USO:
gosop extract-cert [opciones del comando]
OPCIONES:
--no-armor (por defecto: false)
--help, -h: mostrar ayuda (por defecto: false)
generate-key
Generar una Clave Secreta
USO:
gosop generate-key [opciones del comando] [ID_USUARIO...]
OPCIONES:
--no-armor (por defecto: false)
--help, -h: mostrar ayuda (por defecto: false)
sign
Crear una Firma Desvinculada
USO:
gosop extract-cert [opciones del comando]
OPCIONES:
--no-armor (por defecto: false)
--help, -h: mostrar ayuda (por defecto: false)
verify
Verificar una Firma Desvinculada
USO:
gosop verify FIRMA CERTIFICADOS [CERTIFICADOS...] < DATOS
OPCIONES:
--not-before valor
--not-before={-|FECHA} (por defecto: -)
--not-after valor
--not-after={-|FECHA} (por defecto: ahora)
--help, -h: mostrar ayuda (por defecto: false)
version
Información de Versión
USO:
gosop version [opciones del comando] [argumentos...]
OPCIONES:
--backend (por defecto: false)
--extended (por defecto: false)
--help, -h: mostrar ayuda (por defecto: false)
help, h
Muestra una lista de comandos o ayuda para un comando

OPCIONES GLOBALES:

--help, -h
mostrar ayuda (por defecto: false)
--version, -v
imprimir la versión (por defecto: false)
