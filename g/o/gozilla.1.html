GOZILLA(1) Manual de comandos generales GOZILLA(1)

NOMBRE

gozilla - fuerza a firefox a mostrar una parte especificada de un archivo fuente

SINOPSIS

gozilla [-b navegador][-p][+número] archivo
gozilla [-b navegador][-p] -d nombre

DESCRIPCIÓN

Gozilla fuerza a firefox a mostrar una parte especificada de un archivo fuente. Gozilla puede ser usado con otros navegadores como chrome.

Antes de usar este comando, debes ejecutar gtags(1) y htags(1) en el directorio raíz del proyecto para crear los archivos de etiquetas. Luego puedes ejecutar este comando desde cualquier lugar del proyecto.

Primera forma:
Puedes especificar un archivo fuente y un número de línea opcional. Esta sintaxis es similar a vi(1) y emacs(1).

Segunda forma:
Puedes especificar un nombre de definición directamente. El nombre de definición debe existir en ´GTAGS´. Esta opción requiere ´HTML/MAP´ generado por htags(1).

Algunos navegadores requieren que los cargues antes de ejecutar gozilla.

OPCIONES

Las siguientes opciones están disponibles:

+número
Número de línea.
-b navegador
Navegador a usar. Por defecto, se asume firefox.
-d nombre
Imprimir definiciones.
--help
Mostrar ayuda.
-p
Simplemente imprimir una URL generada en lugar de mostrarla.
archivo
Nombre del archivo o nombre alias.
-q, --quiet
Modo silencioso.
-v, --verbose
Modo detallado.
--version
Mostrar número de versión.

ARCHIVOS

´GTAGS´
Archivo de etiquetas para definiciones.
´HTML/´
Hipertexto del código fuente.
´HTML/MAP´
Archivo de mapeo para convertir el nombre de la etiqueta a la ruta de la lista de etiquetas.
´gtags.conf´, ´$HOME/.globalrc´
Datos de configuración para GNU Global. Ver gtags.conf(5).

ENTORNO

BROWSER
Navegador a usar. Por defecto, se asume firefox. Si quieres cargar el navegador por defecto en OSX, puedes establecer esta variable a osx-default.
GTAGSDBPATH
El directorio en el que existen los archivos de etiquetas. Este valor se ignora cuando GTAGSROOT no está definido.
GTAGSROOT
El directorio raíz del proyecto.

EJEMPLOS

$ gtags
$ htags
$ global -x main
main              82 ctags.c          main(argc, argv)
$ gozilla +82 ctags.c
$ gozilla -d main
$ gozilla -b lynx +82 ctags.c

DIAGNÓSTICOS

Gozilla sale con un valor distinto de 0 si ocurrió un error, 0 en caso contrario.

VER TAMBIÉN

global(1), gtags(1), htags(1), epiphany(1), firefox(1), gtags.conf(5).

Sistema de etiquetas de código fuente GNU Global
(http://www.gnu.org/software/global/).
