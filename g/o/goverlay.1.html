NOMBRE

goverlay - Interfaz gráfica para ayudar a gestionar overlays de Vulkan/OpenGL

SINOPSIS

goverlay [--style ESTILO]

DESCRIPCIÓN

GOverlay puede configurar overlays de Vulkan / OpenGL con una vista previa. Actualmente soportados son MangoHud, vkBasalt y ReplaySorcery.

OPCIONES

--style ESTILO
Forzar un estilo Qt específico. Una alternativa a esta opción es establecer la variable de entorno QT_STYLE_OVERRIDE.

NOTA

Se recomienda usar el tema Breeze (Qt/KDE) o Adwaita (Gtk/Gnome).
