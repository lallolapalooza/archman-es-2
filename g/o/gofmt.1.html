gofmt(1) Comandos de usuario gofmt(1)

NOMBRE

gofmt - formatea código Go

SINOPSIS

gofmt [opciones] [ruta]...

DESCRIPCIÓN

Una herramienta para formatear código fuente de Go. Para una documentación completa, ejecuta gofmt -help o consulta http://golang.org/cmd/gofmt.
