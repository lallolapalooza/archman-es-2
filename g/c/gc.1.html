NOMBRE

gc - contar componentes de grafos

SINOPSIS

gc [ -necCaDUrsv? ] [ archivos ]

DESCRIPCIÓN

gc es un análogo de grafo de wc en el sentido de que imprime en la salida estándar el número de nodos, aristas, componentes conectados o clústeres contenidos en los archivos de entrada. También imprime un recuento total para todos los grafos si se proporcionan más de un grafo.

OPCIONES

Se admiten las siguientes opciones:

-n
Contar nodos.
-e
Contar aristas.
-c
Contar componentes conectados.
-C
Contar clústeres. Por definición, un clúster es un grafo o subgrafo cuyo nombre comienza con "cluster".
-a
Contar todo. Equivalente a -encC
-r
Analizar subgrafos recursivamente.
-s
No imprimir nada. Solo el valor de salida es importante.
-D
Analizar solo grafos dirigidos.
-U
Analizar solo grafos no dirigidos.
-v
Salida detallada.
-?
Imprimir información de uso.

Por defecto, gc devuelve el número de nodos y aristas.

OPERANDOS

Se admite el siguiente operando:

archivos
Nombres de archivos que contienen 1 o más grafos en formato dot. Si no se especifica ningún operando de archivos, se utilizará la entrada estándar.

ESTADO DE SALIDA

Se devuelven los siguientes valores de salida:

0
Finalización exitosa.
1
Se utilizó la opción -U o -E y se encontró un grafo del tipo incorrecto.
