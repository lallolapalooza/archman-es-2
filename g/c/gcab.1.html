NOMBRE

gcab - Programa para crear archivos cabinet de Microsoft (.cab)

SINOPSIS

gcab [OPCIÓN]... ARCHIVO_CAB ARCHIVOS...

DESCRIPCIÓN

Crea el archivo cabinet ARCHIVO_CAB a partir de la lista de ARCHIVOS.

OPCIONES

-c, --crear
crear un nuevo archivo cabinet
-x, --extraer
extraer archivos de un archivo cabinet
-t, --listar
listar los archivos de un archivo cabinet
-n, --sin-ruta
crear archivos sin nombres de ruta
-C, --directorio DIR
cambiar o extraer al directorio DIR
-v, --detallado
listar detalladamente los archivos procesados
-z, --zip
usar compresión zip
