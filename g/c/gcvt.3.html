gcvt(3) Manual de Funciones de Biblioteca gcvt(3)

NOMBRE

gcvt - convertir un número de punto flotante a una cadena

BIBLIOTECA

Biblioteca estándar de C (libc, -lc)

SINOPSIS

#include <stdlib.h>
char *gcvt(double number, int ndigit, char *buf);
Requisitos de macro de prueba de características para glibc (ver feature_test_macros(7)):

gcvt():

    Desde glibc 2.17
        (_XOPEN_SOURCE >= 500 && ! (_POSIX_C_SOURCE >= 200809L))
            || /* glibc >= 2.20 */ _DEFAULT_SOURCE
            || /* glibc <= 2.19 */ _SVID_SOURCE
    glibc 2.12 a glibc 2.16:
        (_XOPEN_SOURCE >= 500 && ! (_POSIX_C_SOURCE >= 200112L))
            || _SVID_SOURCE
    Antes de glibc 2.12:
        _SVID_SOURCE || _XOPEN_SOURCE >= 500

DESCRIPCIÓN

La función gcvt() convierte number a una cadena ASCII de longitud mínima y terminada en nulo y almacena el resultado en buf. Produce ndigit dígitos significativos en formato F o E de printf(3).

VALOR DE RETORNO

La función gcvt() devuelve buf.

ATRIBUTOS

Para obtener una explicación de los términos utilizados en esta sección, ver attributes(7).

Interfaz Atributo Valor
gcvt () Seguridad en hilos MT-Safe

ESTÁNDARES

Ninguno.

HISTORIAL

Marcado como LEGACY en POSIX.1-2001. POSIX.1-2008 lo eliminó, recomendando el uso de sprintf(3) en su lugar (aunque snprintf(3) puede ser preferible).

VER TAMBIÉN

ecvt(3), fcvt(3), sprintf(3)
