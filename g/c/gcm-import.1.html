NOMBRE

gcm-import - Herramienta de Importación de GNOME Color Manager

SINOPSIS

gcm-import [ --verbose ]

DESCRIPCIÓN

Esta página del manual documenta brevemente el comando gcm-import.

gcm-import te permite importar archivos ICC proporcionados por los proveedores.

VER TAMBIÉN
