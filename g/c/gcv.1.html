gcv(1) Manual de usuario de Scotch gcv(1)

NOMBRE

gcv - conversor de archivos de grafos

SINOPSIS

gcv [opciones] [archivo_entrada] [archivo_salida_grafo] [archivo_salida_geometría]

DESCRIPCIÓN

El programa gcv convierte archivos de grafos de Scotch desde y hacia otros formatos de archivo externos.

El archivo archivo_entrada se convierte en el archivo de grafo archivo_salida_grafo, con datos de geometría opcionales que se colocan en el archivo de geometría archivo_salida_geometría, si está disponible.

Cuando no se especifican nombres de archivo, los datos se leen de la entrada estándar y se escriben en la salida estándar. Los flujos estándar también se pueden representar explícitamente con un guion '-'.

Cuando las bibliotecas apropiadas se han incluido en el momento de la compilación, gcv puede manejar directamente grafos comprimidos, tanto en entrada como en salida. Un flujo se trata como comprimido siempre que su nombre tenga un sufijo de extensión de archivo comprimido, como en 'brol.grf.bz2' o '-.gz'. Los formatos de compresión que se pueden admitir son el formato bzip2 ('.bz2'), el formato gzip ('.gz') y el formato lzma ('.lzma').

OPCIONES

-h
Muestra ayuda.
-i?formato_entrada
Establece el formato del archivo de grafo de entrada, que puede ser:
b?num
Formato Boeing-Harwell. Este es un formato de matriz. Solo se admiten matrices cuadradas. Las matrices cuadradas con patrón asimétrico se simetrizan. En caso de que el archivo contenga varias matrices, el parámetro num permite al usuario proporcionar el índice de la matriz a convertir, empezando desde 0. Cuando el parámetro num no se establece, se asume que es 0.
c
Formato Chaco. Este es un formato de grafo de adyacencia, también utilizado por MeTiS.
m
Formato Matrix Market. Este es un formato de matriz que describe aristas individuales. El patrón de la matriz se simetriza, de modo que las matrices rectangulares se convierten eventualmente en cuadradas.
s
Formato de grafo Scotch. Este es un formato de grafo de adyacencia.
-o?formato_salida
Establece el formato del archivo de grafo de salida, que puede ser:
c
Formato Chaco.
m
Formato de patrón simétrico de Matrix Market.
s
Formato Scotch. Este es el valor predeterminado.
-V
Muestra la versión del programa y los derechos de autor.

EJEMPLO

Convertir un grafo de Matrix Market a un grafo de Scotch. Los archivos de Matrix Market no contienen datos de geometría, por lo que no se necesita un archivo de geometría en la salida:

    $ gcv -im brol.mm brol.grf
