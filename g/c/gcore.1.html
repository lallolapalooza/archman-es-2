NOMBRE

gcore - Generar un archivo core de un programa en ejecución

SINOPSIS

gcore [-a] [-o prefijo] [-d directorio] pid1 [pid2...pidN]

DESCRIPCIÓN

Genera volcados de memoria core de uno o más programas en ejecución con los IDs de proceso pid1, pid2, etc. Un archivo core producido por gcore es equivalente a uno producido por el kernel cuando el proceso falla (y cuando se usó "ulimit -c" para establecer un límite adecuado de volcados de memoria core). Sin embargo, a diferencia de después de un fallo, después de que gcore termina su trabajo, el programa sigue ejecutándose sin ningún cambio.

OPCIONES

-a
Volcar todos los mapeos de memoria. El efecto real de esta opción depende del Sistema Operativo. En GNU/Linux, deshabilitará "use-coredump-filter" y habilitará "dump-excluded-mappings".
-o prefijo
El argumento opcional prefijo especifica el prefijo que se usará al componer los nombres de archivo de los volcados de memoria core. El nombre de archivo se compone como prefijo.pid, donde pid es el ID del proceso del programa en ejecución que está siendo analizado por gcore. Si no se especifica, prefijo por defecto es gcore.
-d directorio
Usa directorio como el directorio de datos al invocar GDB para ejecutar el comando gcore. Este argumento es opcional.
