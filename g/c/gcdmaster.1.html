NOMBRE

gcdmaster - Interfaz gráfica para cdrdao para componer CDs de audio

SINOPSIS

gcdmaster [archivo-toc]

DESCRIPCIÓN

gcdmaster permite la creación de archivos toc para cdrdao y puede controlar el proceso de grabación. Su aplicación principal es la composición de CDs de audio a partir de uno o más archivos de audio. Soporta edición de canales PQ, entrada de metadatos como códigos ISRC/CD-TEXT y corte no destructivo de los datos de audio.

Si se especifica un archivo-toc, se leerá y se mostrarán los datos de audio referenciados. También es posible especificar un archivo ".cue".

La GUI consulta periódicamente todos los dispositivos CD-ROM y grabadoras de CD configurados (ver sección DIÁLOGO DE CONFIGURACIÓN DE DISPOSITIVOS) para obtener su estado (listo, ocupado, sin disco). Esto se hace enviando un comando TEST UNIT READY a los dispositivos. Pueden surgir los siguientes problemas:

o
Algunos dispositivos (por ejemplo, Philips CDD2600) bloquean el bus SCSI cuando se emite un TEST UNIT READY mientras se está registrando un nuevo medio. Esto provocará una subejecución del búfer para todos los dispositivos que estén grabando actualmente y que estén conectados al mismo bus.
o
La GUI no puede detectar si un dispositivo está siendo utilizado por otro programa. Continuará consultando el dispositivo, lo que puede perturbar el funcionamiento del otro programa.

La GUI admite la grabación de los mismos o diferentes proyectos en múltiples dispositivos en paralelo. Sin embargo, existen algunas advertencias y su sistema debe cumplir algunos prerrequisitos:

o
En Linux se debe utilizar una versión del kernel >= 2.2.6. El dispositivo SCSI genérico de kernels más antiguos no admite acceso paralelo a múltiples dispositivos.
o
Los anchos de banda de los discos que contienen los datos de origen y los buses implicados deben ser lo suficientemente grandes para servir a todos los dispositivos de grabación.
o
Algunos dispositivos de grabación pueden bloquear el bus SCSI cuando el disco es expulsado por el software después del proceso de grabación (por ejemplo, Plextor PX-R412). Por esta razón, se mostrará un mensaje de advertencia si la casilla "Eject" está marcada en el diálogo "Record". La expulsión manual de un disco no parece ser un problema.
o
Los dispositivos ATAPI compatibles con el controlador 'generic-mmc' bloquearán el bus IDE durante la escritura del lead-in y el lead-out. Por lo tanto, la escritura paralela con tales dispositivos conectados al mismo canal IDE no funcionará. Existe una forma de evitar este bloqueo con algunos dispositivos ATAPI, pero aún no está implementada.

CONCEPTOS

La idea principal de esta GUI es mantener un flujo continuo de datos de audio que puede componerse de varios archivos de audio. Es posible utilizar solo porciones de archivos de audio en el flujo de audio, que es la idea básica para la capacidad de corte no destructivo.

Por ejemplo, si corta algunas muestras en medio de un archivo de audio, el resultado será una porción que comienza al principio del archivo de audio y termina al principio de la región cortada, y una segunda porción que comienza al final de la región cortada y llega hasta el final del archivo de audio. Por supuesto, todo esto está oculto por la GUI y solo verá el resultado.

Las marcas de pista e índice se colocan relativamente al flujo de audio continuo. No es necesario tener un archivo de audio separado para cada pista. Las marcas de pista/índice se pueden configurar, mover y eliminar sin influir en el flujo de datos de audio.

Marcador de Muestra

Un marcador de muestra sirve como posición de inserción para los datos de audio. Es equivalente al cursor de un editor de texto. Todas las funciones que insertan datos de audio requieren un marcador definido. Como máximo, puede haber un marcador de muestra activo en cualquier momento.

Selección de Muestra

Una selección de muestra especifica un rango continuo de muestras de audio. Como máximo, puede haber una selección de muestra activa en cualquier momento.

Marca de Pista

Una marca de pista especifica un punto en el flujo de audio donde cambia el número de pista o el número de índice. Las marcas de pista se escriben como un par de dos números, como 5.1 para la pista 5, índice 1. Los números de pista pueden estar en el rango 1..99, el rango válido para los números de índice es 0..99. El índice 0 representa el pre-gap de una pista donde el tiempo relativo de la pista cuenta hacia atrás hasta cero. El índice 1 marca el inicio real de la pista. Esta posición se almacena en el toc central del CD y es utilizada por los reproductores de CD para saltar directamente a una pista. Todos los números de índice > 2 se pueden usar para subdividir una pista pero no tienen ningún efecto adicional. Algunos reproductores de CD pueden saltar a tales marcas de índice.

Las marcas de pista se pueden seleccionar para mostrar datos sobre una pista o para realizar operaciones en la pista completa. Como máximo, puede haber una marca de pista seleccionada en cualquier momento.

Tiempos

El tiempo se muestra generalmente como m:s:f.x donde m representa minutos, s representa segundos (0..59), f representa fotogramas (0..74, 1/75 de segundo) y x representa muestras (0..587, 1/44100 de segundo).

VENTANA PRINCIPAL

La ventana principal consta de una barra de menú, una pantalla de muestras, una línea de marcadores/selección, una línea de botones y una línea de estado.

El título de la ventana principal muestra el nombre del archivo toc actual. Un "(*)" detrás del nombre indica que los cambios no se han guardado.

Barra de Menú

Las funciones accesibles a través de la barra de menú se describen en la sección FUNCIONES DEL MENÚ.

Pantalla de Muestras

La pantalla de muestras proporciona una representación visual del flujo de audio y las marcas de pista/índice colocadas.

Las muestras se muestran como dos gráficos separados para el canal izquierdo y derecho, donde el eje x representa el tiempo y el eje y denota la amplitud (escalada linealmente). Si un píxel representa más de 1 muestra, se muestra la amplitud máxima y mínima de todas las muestras que caen dentro de este píxel. Es posible hacer zoom y cambiar la porción mostrada con la barra de desplazamiento.

Las marcas de pista/índice se muestran encima de los dos gráficos. Las marcas de pista con índice 1 se representan con un símbolo de pista relleno. Todas las demás marcas de pista utilizan un símbolo de pista hueco. El par de números de pista/índice se muestra en el lado derecho de un símbolo de pista.

Las marcas de pista se pueden seleccionar o mover haciendo clic o arrastrando con el puntero del ratón sobre un símbolo de pista. Los pares de números de pista/índice no son sensibles.

Línea de Marcador/Selección

Esta línea muestra la posición actual del cursor, del marcador activo y de la selección de muestra activa.

El campo del cursor es de solo lectura y muestra el valor de tiempo de la posición actual del puntero del ratón dentro del flujo de audio si se encuentra dentro de la pantalla de muestras. Durante la reproducción, el campo del cursor muestra el valor de tiempo del sonido actualmente audible.

El campo del marcador muestra el valor de tiempo del marcador activo. Se puede introducir un valor de tiempo y al presionar la tecla Enter se establecerá la nueva posición del marcador si el valor de tiempo es válido.

Los campos de selección de muestra muestran el rango de muestra seleccionado activo. Se pueden introducir valores de tiempo y al presionar la tecla Enter en uno de estos campos se establecerá la nueva selección de muestra si los valores de tiempo son válidos.

Línea de Botones

Los botones de radio de zoom/seleccionar especifican el comportamiento al arrastrar con el ratón en la pantalla de muestras. Si está activo "zoom", la pantalla de muestras se acercará al rango de muestras seleccionado. Si está activo "select", la selección de muestra activa se establecerá en el rango de muestras seleccionado.

El botón de reproducción reproducirá la selección de muestra activa actualmente a través de la tarjeta de sonido. Si no hay ninguna selección de muestra activa, se utilizará el rango de muestras mostrado actualmente. Mientras se reproduce, el proyecto actual es

se establece en estado de solo lectura

Marco

CD-TEXT

Los datos CD-TEXT pueden especificarse para hasta 8 idiomas diferentes. Cada idioma se referencia con un número de idioma 0..7. El primer idioma debería tener el número de idioma 0. Los números de idioma deberían usarse

continuamente.

El idioma real para un número de idioma se especifica con el menú de opciones "Idioma": La opción "Desconocido" se muestra para un código de idioma desconocido (por ejemplo, si el archivo toc fue editado manualmente). No es posible seleccionar esta opción. La opción "Indefinido" significa que no se ha asignado ningún idioma para este número de idioma. Es posible introducir datos CD-TEXT y los datos introducidos se guardarán en el archivo toc, pero no se grabarán en un CD-R/CD-RW. Las opciones restantes seleccionan el idioma deseado. Cada idioma solo puede asignarse a un número de

idioma.

DIÁLOGO DE GRABACIÓN (Acciones->

Grabar)

Este diálogo no modal puede usarse para grabar el proyecto actual en un CD-R/CD-RW. Es posible grabar el proyecto actual en múltiples grabadoras simultáneamente

.

El botón "Iniciar" iniciará los procesos de grabación en todos los dispositivos que estén seleccionados en el explorador "Dispositivos grabadores disponibles". Para este propósito se llamará al ejecutable cdrdao y debería estar disponible en su PATH. Para cada dispositivo seleccionado se abrirá un diálogo de progreso no

modal.

Después de iniciar la grabación en todos los dispositivos seleccionados, es posible cargar otro archivo toc o continuar editando el proyecto existente. También es seguro salir de la interfaz gráfica. La grabación continuará en segundo plano, pero no tendrá información sobre el

progreso.

El botón "Cancelar" cerrará el cuadro de

diálogo.
