gccmakedep(1) Manual de comandos generales gccmakedep(1)

NOMBRE

gccmakedep - crea dependencias en makefiles usando 'gcc -M'

SINOPSIS

gccmakedep [ -sseparador ] [ -fmakefile ] [ -a ] [ -- opciones -- ] archivo_fuente ...

DESCRIPCIÓN

El programa gccmakedep llama a 'gcc -M' para generar reglas del makefile que describen las dependencias de cada archivo_fuente, de modo que make(1) sepa qué archivos objeto deben ser recompilados cuando una dependencia ha cambiado.

Por defecto, gccmakedep coloca su salida en el archivo llamado makefile si existe, de lo contrario en Makefile. Se puede especificar un makefile alternativo con la opción -f. Primero busca en el makefile una línea que comience con

# DO NOT DELETE

o una proporcionada con la opción -s, como delimitador para la salida de dependencias. Si la encuentra, eliminará todo lo que siga hasta el final del makefile y colocará la salida después de esta línea. Si no la encuentra, el programa agregará la cadena al makefile y colocará la salida después de ella.

EJEMPLO

Normalmente, gccmakedep se utilizará en un objetivo de makefile para que al escribir 'make depend' las dependencias se actualicen para el makefile. Por ejemplo,

    SRCS = file1.c file2.c ...
    CFLAGS = -O -DHACK -I../foobar -xyz
    depend:
            gccmakedep -- $(CFLAGS) -- $(SRCS)

OPCIONES

El programa ignorará cualquier opción que no entienda, por lo que puedes usar los mismos argumentos que usarías para gcc(1), incluyendo las opciones -D y -U para definir y anular la definición de símbolos, y -I para establecer la ruta de inclusión.

-a
Agrega las dependencias al archivo en lugar de reemplazar las existentes.
-fmakefile
Nombre de archivo. Esto te permite especificar un makefile alternativo en el cual gccmakedep puede colocar su salida. Especificar “-” como nombre de archivo (es decir, -f-) envía la salida a la salida estándar en lugar de modificar un archivo existente.
-scadena
Cadena delimitadora de inicio. Esta opción te permite especificar una cadena diferente para que gccmakedep la busque en el makefile. El valor predeterminado es “# DO NOT DELETE”.
-- opciones --
Si gccmakedep encuentra un doble guion (--) en la lista de argumentos, entonces cualquier argumento no reconocido que siga será ignorado silenciosamente. Un segundo doble guion termina este tratamiento especial. De esta manera, se puede hacer que gccmakedep ignore de forma segura argumentos de compilador esotéricos que normalmente se encontrarían en una macro CFLAGS de make (ver la sección EJEMPLO arriba). Las opciones -D, -I y -U que aparecen entre el par de dobles guiones todavía se procesan normalmente.

VER TAMBIÉN

gcc(1), make(1), makedepend(1).
