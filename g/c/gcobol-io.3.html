DESCRIPCIÓN

gcobol proporciona funcionalidad de E/S reemplazable a través de gcobol_fileops(). Devuelve un puntero a una estructura de punteros a funciones de C que implementan operaciones de archivos secuenciales, relativos e indexados sobre archivos cuyo Formato en Disco (ODF) está definido por gcobol. Un usuario que desee usar otra biblioteca que implemente la misma funcionalidad sobre un ODF diferente debe proporcionar una implementación diferente de gcobol_fileops(), más 7 funciones, como se describe en este documento. Los punteros a esas funciones implementadas por el usuario se colocan en un objeto C++ de tipo gcobol_io_t y una instanciación de ese tipo es devuelta por gcobol_fileops(). El programa compilado inicializa las operaciones de E/S llamando a esa función la primera vez que se abre cualquier archivo.

Cada función toma como su primer argumento un puntero a un objeto cblc_file_t , que es análogo a un objeto FILE usado en las funciones de C stdio . La estructura cblc_file_t actúa como un área de comunicación entre el programa compilado y la biblioteca de E/S. Cualquier información necesaria sobre el archivo se guarda allí. Notablemente, el resultado de cualquier operación se almacena en esa estructura en el miembro file_status , no como un código de retorno. La información sobre la operación (a diferencia de la información sobre el archivo) aparece como parámetros de la función.

cblc_file_t tiene un miembro, no usado por gcobol, que está reservado para el usuario:

void * implementation
.

Las funciones de E/S proporcionadas por el usuario pueden asignar y desreferenciar implementation. gcobol preservará el valor, pero nunca lo referencia.

La biblioteca implementa una función que el gcobol-binario producido llama directamente:

  • gcobol_io_t * gcobol_fileops()
    Esta función rellena un gcobol_io_t objeto con los punteros de función anteriores. El binario compilado comienza llamando a gcobol_fileops(), y luego usa los punteros proporcionados para realizar E/S.

VALORES DE RETORNO

Las funciones de E/S devuelven void. gcobol_fileops() devuelve gcobol_io_t*.

ESTÁNDARES

La biblioteca de E/S proporcionada por gcobol, libgcobolio.so, soporta la semántica de E/S definida por ISO COBOL. No está destinada a ser compatible con ningún otro ODF. Es decir, libgcobolio.so no se puede usar para intercambiar datos con ninguna otra implementación de COBOL.

El propósito de la estructura gcobol_io_t es permitir el uso de otras implementaciones de E/S con otras representaciones de ODF.

ADVERTENCIAS

La biblioteca no está bien probada, en parte porque no está implementada.
