gcov2perl(1p)

Paquete: perl-devel-cover

Licencias: PerlArtistic, GPL

GCOV2PERL(1) Documentación de Perl contribuida por el usuario GCOV2PERL(1)

NOMBRE

gcov2perl - convertir archivos gcov a bases de datos Devel::Cover

VERSIÓN

versión 1.51

SINOPSIS

gcov2perl -h -i -v -db base_datos archivos_gcov

DESCRIPCIÓN

Convierte archivos gcov a bases de datos Devel::Cover.

OPCIONES

Se admiten las siguientes opciones de línea de comandos:

-db base_datos - especificar la base de datos a usar
-h -help        - mostrar ayuda
-i -info        - mostrar documentación
-v -version     - mostrar versión

DETALLES

Para obtener cobertura de archivos XS, estos deben compilarse primero con las opciones apropiadas. En un entorno Makefile estándar, como el creado por ExtUtils::MakeMaker, esto se puede lograr con el comando:

HARNESS_PERL_SWITCHES=-MDevel::Cover make test \
  CCFLAGS=-O0\ -fprofile-arcs\ -ftest-coverage \
  OTHERLDFLAGS=-fprofile-arcs\ -ftest-coverage

Si ya ha compilado sus archivos objeto, puede ser necesario ejecutar make clean primero, o encontrar alguna otra forma de asegurarse de que se recompilen con las opciones que requiere gcov.

Ahora que se han recopilado los datos de cobertura de código, "gcov" debe ejecutarse:

gcov Mi_libreria.xs

Esto creará uno o más archivos gcov sobre los que puede ejecutar "gcov2perl":

gcov2perl Mi_libreria.xs.gcov

Finalmente, "cover" debe ejecutarse como de costumbre con las opciones requeridas:

cover

Si está ejecutando todo con opciones estándar, puede hacer todo esto con un solo comando:

cover -test

ESTADO DE SALIDA

Se devuelven los siguientes valores de salida:

0   Todos los archivos se convirtieron correctamente
>0  Ocurrió un error.
