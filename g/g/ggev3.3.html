Documentación de la Función

subrutina cggev3 (character jobvl, character jobvr, integer n, complex, dimension( lda, * ) a, integer lda, complex, dimension( ldb, * ) b, integer ldb, complex, dimension( * ) alpha, complex, dimension( * ) beta, complex, dimension( ldvl, * ) vl, integer ldvl, complex, dimension( ldvr, * ) vr, integer ldvr, complex, dimension( * ) work, integer lwork, real, dimension( * ) rwork, integer info)

CGGEV3 calcula los valores propios generalizados y, opcionalmente, los vectores propios izquierdos y/o derechos para matrices GE (algoritmo en bloques)

Propósito:

!>
!> CGGEV3 calcula para un par de matrices complejas no simétricas de N por N
!> (A,B), los valores propios generalizados, y opcionalmente, los vectores
!> propios generalizados izquierdos y/o derechos.
!>
!> Un valor propio generalizado para un par de matrices (A,B) es un escalar
!> lambda o una relación alpha/beta = lambda, tal que A - lambda*B es
!> singular. Generalmente se representa como el par (alpha,beta), ya que
!> existe una interpretación razonable para beta=0, e incluso para que ambos
!> sean cero.
!>
!> El vector propio generalizado derecho v(j) correspondiente al valor propio
!> generalizado lambda(j) de (A,B) satisface
!>
!>              A * v(j) = lambda(j) * B * v(j).
!>
!> El vector propio generalizado izquierdo u(j) correspondiente a los valores
!> propios generalizados lambda(j) de (A,B) satisface
!>
!>              u(j)**H * A = lambda(j) * u(j)**H * B
!>
!> donde u(j)**H es la transpuesta conjugada de u(j).
!>

Parámetros

JOBVL 
!>          JOBVL es CHARACTER*1
!>          = 'N':  no calcular los vectores propios generalizados izquierdos;
!>          = 'V':  calcular los vectores propios generalizados izquierdos.
!>

JOBVR

!>          JOBVR es CHARACTER*1
!>          = 'N':  no calcular los vectores propios generalizados derechos;
!>          = 'V':  calcular los vectores propios generalizados derechos.
!>

N

!>          N es INTEGER
!>          El orden de las matrices A, B, VL y VR.  N >= 0.
!>

A

!>          A es un array COMPLEX, dimension (LDA, N)
!>          En la entrada, la matriz A en el par (A,B).
!>          En la salida, A ha sido sobrescrita.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal de A.  LDA >= max(1,N).
!>

B

!>          B es un array COMPLEX, dimension (LDB, N)
!>          En la entrada, la matriz B en el par (A,B).
!>          En la salida, B ha sido sobrescrita.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal de B.  LDB >= max(1,N).
!>

ALPHA

!>          ALPHA es un array COMPLEX, dimension (N)
!>

BETA

!>          BETA es un array COMPLEX, dimension (N)
!>          En la salida, ALPHA(j)/BETA(j), j=1,...,N, serán los
!>          valores propios generalizados.
!>
!>          Nota: los cocientes ALPHA(j)/BETA(j) pueden fácilmente
!>          desbordarse o subdesbordarse, y BETA(j) puede incluso ser cero.
!>          Por lo tanto, el usuario debe evitar calcular ingenuamente la
!>          relación alpha/beta.
!>          Sin embargo, ALPHA siempre será menor y usualmente comparable
!>          con norm(A) en magnitud, y BETA siempre menor y usualmente
!>          comparable con norm(B).
!>

VL

!>          VL es un array COMPLEX, dimension (LDVL,N)
!>          Si JOBVL = 'V', los vectores propios generalizados izquierdos u(j) se
!>          almacenan uno tras otro en las columnas de VL, en el mismo
!>          orden que sus valores propios.
!>          Cada vector propio se escala para que el componente más grande tenga
!>          abs(parte real) + abs(parte imaginaria) = 1.
!>          No referenciado si JOBVL = 'N'.
!>

LDVL

!>          LDVL es INTEGER
!>          La dimensión principal de la matriz VL. LDVL >= 1, y
!>          si JOBVL = 'V', LDVL >= N.
!>

VR

!>          VR es un array COMPLEX, dimension (LDVR,N)
!>          Si JOBVR = 'V', los vectores propios generalizados derechos v(j) se
!>          almacenan uno tras otro en las columnas de VR, en el mismo
!>          orden que sus valores propios.
!>          Cada vector propio se escala para que el componente más grande tenga
!>          abs(parte real) + abs(parte imaginaria) = 1.
!>          No referenciado si JOBVR = 'N'.
!>

LDVR

!>          LDVR es INTEGER
!>          La dimensión principal de la matriz VR. LDVR >= 1, y
!>          si JOBVR = 'V', LDVR >= N.
!>

WORK

!>          WORK es un array COMPLEX, dimension (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK. LWORK >= MAX(1,2*N).
!>          Para un buen rendimiento, LWORK generalmente debe ser mayor.
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo;
!>          la rutina solo calcula el tamaño óptimo del array WORK, devuelve
!>          este valor como la primera entrada del array WORK, y no se emite
!>          ningún mensaje de error relacionado con LWORK por XERBLA.
!>

RWORK

!>          RWORK es un array REAL, dimension (8*N)
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>          =1,...,N:
!>                La iteración QZ falló. No se han calculado vectores propios,
!>                pero ALPHA(j) y BETA(j) deberían ser correctos para
!>                j=INFO+1,...,N.
!>          > N:  =N+1: falló la iteración QZ en CHGEQZ,
!>                =N+2: retorno de error de CTGEVC.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal de B.  LDB >= max(1,N).

ALPHA

!>          ALPHA es un array COMPLEX*16, de dimensión (N)
!>

BETA

!>          BETA es un array COMPLEX*16, de dimensión (N)
!>          A la salida, ALPHA(j)/BETA(j), j=1,...,N, serán los
!>          valores propios generalizados.
!>
!>          Nota: los cocientes ALPHA(j)/BETA(j) pueden desbordarse o
!>          subdesbordarse fácilmente, y BETA(j) puede incluso ser cero.
!>          Por lo tanto, el usuario debe evitar calcular ingenuamente
!>          la relación alpha/beta. Sin embargo, ALPHA siempre será
!>          menor y generalmente comparable con norm(A) en magnitud, y
!>          BETA siempre menor y generalmente comparable con norm(B).
!>

VL

!>          VL es un array COMPLEX*16, de dimensión (LDVL,N)
!>          Si JOBVL = 'V', los vectores propios generalizados izquierdos u(j)
!>          se almacenan uno tras otro en las columnas de VL, en el mismo
!>          orden que sus valores propios.
!>          Cada vector propio se escala de modo que el componente más
!>          grande tenga abs(parte real) + abs(parte imag.) = 1.
!>          No se referencia si JOBVL = 'N'.
!>

LDVL

!>          LDVL es un INTEGER
!>          La dimensión principal de la matriz VL. LDVL >= 1, y
!>          si JOBVL = 'V', LDVL >= N.
!>

VR

!>          VR es un array COMPLEX*16, de dimensión (LDVR,N)
!>          Si JOBVR = 'V', los vectores propios generalizados derechos v(j)
!>          se almacenan uno tras otro en las columnas de VR, en el mismo
!>          orden que sus valores propios.
!>          Cada vector propio se escala de modo que el componente más
!>          grande tenga abs(parte real) + abs(parte imag.) = 1.
!>          No se referencia si JOBVR = 'N'.
!>

LDVR

!>          LDVR es un INTEGER
!>          La dimensión principal de la matriz VR. LDVR >= 1, y
!>          si JOBVR = 'V', LDVR >= N.
!>

WORK

!>          WORK es un array COMPLEX*16, de dimensión (MAX(1,LWORK))
!>          A la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es un INTEGER
!>          La dimensión del array WORK. LWORK >= MAX(1,2*N).
!>          Para un buen rendimiento, LWORK generalmente debe ser mayor.

!>          con LWORK.

RWORK

!>          RWORK es un array DOUBLE PRECISION, de dimensión (8*N)

INFO
