CGGSVD3 calcula la descomposición de valor singular (SVD) para matrices OTHER

Propósito:

!>
!> CGGSVD3 calcula la descomposición de valor singular generalizada (GSVD)
!> de una matriz compleja A de M por N y una matriz compleja B de P por N:
!>
!>       U**H*A*Q = D1*( 0 R ),    V**H*B*Q = D2*( 0 R )
!>
!> donde U, V y Q son matrices unitarias.
!> Sea K+L = el rango numérico efectivo de la
!> matriz (A**H,B**H)**H, entonces R es una matriz triangular superior
!> no singular de (K+L)-por-(K+L), D1 y D2 son matrices de M-por-(K+L) y P-por-(K+L)
!> y de las siguientes estructuras, respectivamente:
!>
!> Si M-K-L >= 0,
!>
!>                     K  L
!>        D1 =     K ( I  0 )
!>                 L ( 0  C )
!>             M-K-L ( 0  0 )
!>
!>                   K  L
!>        D2 =   L ( 0  S )
!>             P-L ( 0  0 )
!>
!>                 N-K-L  K    L
!>   ( 0 R ) = K (  0   R11  R12 )
!>             L (  0    0   R22 )
!>
!> donde
!>
!>   C = diag( ALPHA(K+1), ... , ALPHA(K+L) ),
!>   S = diag( BETA(K+1),  ... , BETA(K+L) ),
!>   C**2 + S**2 = I.
!>
!>   R se almacena en A(1:K+L,N-K-L+1:N) en la salida.
!>
!> Si M-K-L < 0,
!>
!>                   K M-K K+L-M
!>        D1 =   K ( I  0    0   )
!>             M-K ( 0  C    0   )
!>
!>                     K M-K K+L-M
!>        D2 =   M-K ( 0  S    0  )
!>             K+L-M ( 0  0    I  )
!>               P-L ( 0  0    0  )
!>
!>                    N-K-L  K   M-K  K+L-M
!>   ( 0 R ) =     K ( 0    R11  R12  R13  )
!>               M-K ( 0     0   R22  R23  )
!>             K+L-M ( 0     0    0   R33  )
!>
!> donde
!>
!>   C = diag( ALPHA(K+1), ... , ALPHA(M) ),
!>   S = diag( BETA(K+1),  ... , BETA(M) ),
!>   C**2 + S**2 = I.
!>
!>   (R11 R12 R13 ) se almacena en A(1:M, N-K-L+1:N), y R33 se almacena
!>   ( 0  R22 R23 )
!>   en B(M-K+1:L,N+M-K-L+1:N) en la salida.
!>
!> La rutina calcula C, S, R y opcionalmente las matrices de
!> transformación unitaria U, V y Q.
!>
!> En particular, si B es una matriz no singular de N por N, entonces la GSVD de
!> A y B da implícitamente el SVD de A*inv(B):
!>                      A*inv(B) = U*(D1*inv(D2))*V**H.
!> Si ( A**H,B**H)**H tiene columnas ortonormales, entonces la GSVD de A y B también es
!> igual a la descomposición CS de A y B. Además, la GSVD puede
!> usarse para derivar la solución del problema de valores propios:
!>                      A**H*A x = lambda* B**H*B x.
!> En algunas literaturas, la GSVD de A y B se presenta en la forma
!>                  U**H*A*X = ( 0 D1 ),   V**H*B*X = ( 0 D2 )
!> donde U y V son ortogonales y X es no singular, y D1 y D2 son
!> ``diagonales''.  La forma anterior de la GSVD puede convertirse a la forma
!> posterior tomando la matriz no singular X como
!>
!>                       X = Q*(  I   0    )
!>                             (  0 inv(R) )
!>

Parámetros

JOBU 
!>          JOBU es CHARACTER*1
!>          = 'U':  Se calcula la matriz unitaria U;
!>          = 'N':  No se calcula U.
!>

JOBV

!>          JOBV es CHARACTER*1
!>          = 'V':  Se calcula la matriz unitaria V;
!>          = 'N':  No se calcula V.
!>

JOBQ

!>          JOBQ es CHARACTER*1
!>          = 'Q':  Se calcula la matriz unitaria Q;
!>          = 'N':  No se calcula Q.
!>

M

!>          M es INTEGER
!>          El número de filas de la matriz A.  M >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas de las matrices A y B.  N >= 0.
!>

P

!>          P es INTEGER
!>          El número de filas de la matriz B.  P >= 0.
!>

K

!>          K es INTEGER
!>

L

!>          L es INTEGER
!>
!>          En la salida, K y L especifican la dimensión de los subbloques
!>          descritos en Propósito.
!>          K + L = rango numérico efectivo de (A**H,B**H)**H.
!>

A

!>          A es un arreglo COMPLEX, dimensión (LDA,N)
!>          En la entrada, la matriz A de M por N.
!>          En la salida, A contiene la matriz triangular R, o parte de R.
!>          Consulte Propósito para más detalles.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del arreglo A. LDA >= max(1,M).
!>

B

!>          B es un arreglo COMPLEX, dimensión (LDB,N)
!>          En la entrada, la matriz B de P por N.
!>          En la salida, B contiene parte de la matriz triangular R si
!>          M-K-L < 0.  Consulte Propósito para más detalles.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del arreglo B. LDB >= max(1,P).
!>

ALPHA

!>          ALPHA es un arreglo REAL, dimensión (N)
!>

BETA

!>          BETA es un arreglo REAL, dimensión (N)
!>
!>          En la salida, ALPHA y BETA contienen los pares de valores
!>          singulares generalizados de A y B;
!>            ALPHA(1:K) = 1,
!>            BETA(1:K)  = 0,
!>          y si M-K-L >= 0,
!>            ALPHA(K+1:K+L) = C,
!>            BETA(K+1:K+L)  = S,
!>          o si M-K-L < 0,
!>            ALPHA(K+1:M)=C, ALPHA(M+1:K+L)=0
!>            BETA(K+1:M) =S, BETA(M+1:K+L) =1
!>          y
!>            ALPHA(K+L+1:N) = 0
!>            BETA(K+L+1:N)  = 0
!>

U

!>          U es un arreglo COMPLEX, dimensión (LDU,M)
!>          Si JOBU = 'U', U contiene la matriz unitaria U de M por M.
!>          Si JOBU = 'N', no se referencia U.
!>

LDU

!>          LDU es INTEGER
!>          La dimensión principal del arreglo U. LDU >= max(1,M) si
!>          JOBU = 'U'; LDU >= 1 en caso contrario.
!>

V

!>          V es un arreglo COMPLEX, dimensión (LDV,P)
!>          Si JOBV = 'V', V contiene la matriz unitaria P-por-P V.
!>          Si JOBV = 'N', V no es referenciada.
!>

LDV

!>          LDV es INTEGER
!>          La dimensión principal del array V. LDV >= max(1,P) si
!>          JOBV = 'V'; LDV >= 1 en caso contrario.
!>

Q

!>          Q es un array COMPLEX, dimensión (LDQ,N)
!>          Si JOBQ = 'Q', Q contiene la matriz unitaria N-por-N Q.
!>          Si JOBQ = 'N', Q no es referenciada.
!>

LDQ

!>          LDQ es INTEGER
!>          La dimensión principal del array Q. LDQ >= max(1,N) si
!>          JOBQ = 'Q'; LDQ >= 1 en caso contrario.
!>

WORK

!>          WORK es un array COMPLEX, dimensión (MAX(1,LWORK))
!>          Al salir, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK. LWORK >= 1.
!>
!>          Si LWORK = -1, se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo del array WORK, devuelve
!>          este valor como la primera entrada del array WORK, y no se emite
!>          ningún mensaje de error relacionado con LWORK por parte de XERBLA.
!>

RWORK

!>          RWORK es un array REAL, dimensión (2*N)
!>

IWORK

!>          IWORK es un array INTEGER, dimensión (N)
!>          Al salir, IWORK almacena la información de ordenación. Más
!>          precisamente, el siguiente bucle ordenará ALPHA
!>             for I = K+1, min(M,K+L)
!>                 swap ALPHA(I) y ALPHA(IWORK(I))
!>             endfor
!>          de modo que ALPHA(1) >= ALPHA(2) >= ... >= ALPHA(N).
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa.
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>          > 0:  si INFO = 1, el procedimiento de tipo Jacobi no
!>                convergió. Para más detalles, ver el subrutina CTGSJA.
!>

Parámetros Internos:

!>  TOLA    REAL
!>  TOLB    REAL
!>          TOLA y TOLB son los umbrales para determinar el rango
!>          efectivo de (A**H,B**H)**H. Generalmente, se establecen como
!>                   TOLA = MAX(M,N)*norm(A)*MACHEPS,
!>                   TOLB = MAX(P,N)*norm(B)*MACHEPS.
!>          El tamaño de TOLA y TOLB puede afectar al tamaño de los errores
!>          hacia atrás de la descomposición.
!>

!> Si M-K-L >= 0,
!>
!>                     K  L

!>                 L ( 0  C )

!>   ( 0 R ) = K (  0   R11  R12 )

!> donde

!>   S = diag( BETA(K+1),  ... , BETA(K+L) ),
!>   C**2 + S**2 = I.
!>
!>   R se almacena en A(1:K+L,N-K-L+1:N) en la salida.
!>
!> Si M-K-L < 0,
!>
!>                   K M-K K+L-M
!>        D1 =   K ( I  0    0   )
!>             M-K ( 0  C    0   )
!>
!>                     K M-K K+L-M
!>        D2 =   M-K ( 0  S    0  )
!>             K+L-M ( 0  0    I  )
!>               P-L ( 0  0    0  )
!>
!>                    N-K-L  K   M-K  K+L-M
!>   ( 0 R ) =     K ( 0    R11  R12  R13  )
!>               M-K ( 0     0   R22  R23  )
!>             K+L-M ( 0     0    0   R33  )
!>
!> donde
!>
!>   C = diag( ALPHA(K+1), ... , ALPHA(M) ),
!>   S = diag( BETA(K+1),  ... , BETA(M) ),
!>   C**2 + S**2 = I.
!>
!>   (R11 R12 R13 ) se almacena en A(1:M, N-K-L+1:N), y R33 se almacena
!>   ( 0  R22 R23 )
!>   en B(M-K+1:L,N+M-K-L+1:N) en la salida.
!>
!> La rutina calcula C, S, R, y opcionalmente las matrices de
!> transformación ortogonales U, V y Q.
!>
!> En particular, si B es una matriz no singular N-por-N, entonces la GSVD de
!> A y B da implícitamente la SVD de A*inv(B):
!>                      A*inv(B) = U*(D1*inv(D2))*V**T.

!> también igual a la descomposición CS de A y B. Además, la GSVD
!> puede usarse para derivar la solución del problema de valores propios:
!>                      A**T*A x = lambda* B**T*B x.
!> En alguna literatura, la GSVD de A y B se presenta en la forma
!>                  U**T*A*X = ( 0 D1 ),   V**T*B*X = ( 0 D2 )
!> donde U y V son ortogonales y X es no singular, D1 y D2 son
!> ``diagonales''. La forma anterior de la GSVD puede convertirse a la
!> forma posterior tomando la matriz no singular X como

!>                            ( 0 inv(R) ).
!>

NAME

        
ggsvd3

        
general matrix singular value decomposition

    

    

        
SYNOPSIS

        
SUBROUTINE ZGGSVD3( JOBU, JOBV, M, N, P, A, LDA, B, LDB, SIGMA, ALPHA, BETA, WORK, LWORK, IWORK, INFO )

  CHARACTER JOBU, JOBV
  INTEGER INFO, LDA, LDB, LWORK, M, N, P
  INTEGER IWORK(*)
  DOUBLE PRECISION SIGMA( * )
  DOUBLE COMPLEX A( LDA, * ), B( LDB, * )
  DOUBLE PRECISION ALPHA( * ), BETA( * ), WORK( * )


    

    

        
Detailed Description

        
ZGGSVD3 computes the generalized singular value decomposition of two
            general complex matrices A and B.

        
This subroutine returns the matrices U and V and the lower
            triangular matrices R and T such that

        
   A = U * R * [  0 ]
               [  X ]
   B = V * T * [  Y ]
               [  0 ]


        
where U and V are unitary matrices, and R and T are lower
            triangular matrices.

        
The potentially non-zero parts of R and T are x and y,
            respectively.

        
X and Y are upper triangular matrices.

        
The generalized singular values are returned in the array
            SIGMA.

        
The following is the list of parameters for ZGGSVD3:

        

            
JOBU

            
CHARACTER*1.
                
Specifies whether to compute the matrices U and V
                    as follows:

                
   = 'U':  U is computed and returned.
   = 'N':  U is not computed.
                

            

            
JOBV

            
CHARACTER*1.
                
Specifies whether to compute the matrices U and V
                    as follows:

                
   = 'V':  V is computed and returned.
   = 'N':  V is not computed.
                

            

            
M

            
INTEGER.
                
The number of rows of A and B.

            

            
N

            
INTEGER.
                
The number of columns of A and B. N must be at least
                    MIN(M,P).

            

            
P

            
INTEGER.
                
The number of columns of B. P must be at least
                    MIN(M,N).

            

            
A

            
DOUBLE COMPLEX array, dimension (LDA, N).
                
On entry, the M-by-N matrix A.

                
On exit, A is overwritten by details of its
                    decomposition.

            

            
LDA

            
INTEGER.
                
The leading dimension of A.

            

            
B

            
DOUBLE COMPLEX array, dimension (LDB, P).
                
On entry, the M-by-P matrix B.

                
On exit, B is overwritten by details of its
                    decomposition.

            

            
LDB

            
INTEGER.
                
The leading dimension of B.

            

            
SIGMA

            
DOUBLE PRECISION array, dimension (N).
                
On exit, the generalized singular values SIGMA.

            

            
ALPHA

            
DOUBLE PRECISION array, dimension (N).
                
On exit, the values of ALPHA.

            

            
BETA

            
DOUBLE PRECISION array, dimension (N).
                
On exit, the values of BETA.

            

            
WORK

            
DOUBLE PRECISION array, dimension (LWORK).
                
On exit, WORK(1) contains the optimal value of
                    LWORK.

            

            
LWORK

            
INTEGER.
                
The dimension of the array WORK.

                
If LWORK = -1, then LWORK is an input and WORK(1)
                    is an output, and the subroutine is called without the
                    actual computation of the decomposition. The program
                    should be run again with LWORK computed as described
                    below.

            

            
IWORK

            
INTEGER array, dimension (M + N + P).
                
On exit, IWORK contains the sorting information.

                
More precisely, the following loop will sort ALPHA
                    for I = K+1, min(M,K+L)

                
 swap ALPHA(I) and ALPHA(IWORK(I))
 endfor
                

                such that ALPHA(1) >= ALPHA(2) >= ... >= ALPHA(N).
            

            
INFO

            
INTEGER.
                
= 0: successful exit.

                
< 0: if INFO = -i, the i-th argument had an
                    illegal value.

                
> 0: if INFO = 1, the Jacobi-type procedure failed
                    to converge. For further details, see subroutine ZTGSJA.

            

        

    

    

        
Internal Parameters

        

            
  TOLA    DOUBLE PRECISION
  TOLB    DOUBLE PRECISION
          TOLA and TOLB are the thresholds to determine the effective
          rank of (A**H,B**H)**H. Generally, they are set to
                   TOLA = MAX(M,N)*norm(A)*MACHEPS,
                   TOLB = MAX(P,N)*norm(B)*MACHEPS.
          The size of TOLA and TOLB may affect the size of backward
          errors of the decomposition.
