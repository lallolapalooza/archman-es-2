subrutina cgglse (entero m, entero n, entero p, complejo, dimensión( lda, * ) a, entero lda, complejo, dimensión( ldb, * ) b, entero ldb, complejo, dimensión( * ) c, complejo, dimensión( * ) d, complejo, dimensión( * ) x, complejo, dimensión( * ) work, entero lwork, entero info)

CGGLSE resuelve el problema de mínimos cuadrados con restricciones de igualdad (LSE):

Propósito:

!>
!> CGGLSE resuelve el problema de mínimos cuadrados con restricciones de
!> igualdad (LSE):
!>
!>         minimizar || c - A*x ||_2   sujeto a   B*x = d
!>
!> donde A es una matriz M por N, B es una matriz P por N, c es un vector
!> M dado, y d es un vector P dado. Se asume que
!> P <= N <= M+P, y
!>
!>          rango(B) = P y  rango( (A) ) = N.
!>                               ( (B) )
!>
!> Estas condiciones aseguran que el problema LSE tiene una solución única,
!> la cual se obtiene utilizando una factorización RQ generalizada de las
!> matrices (B, A) dada por
!>
!>    B = (0 R)*Q,   A = Z*T*Q.
!>
!> Los llamadores de esta subrutina deben tener en cuenta que las comprobaciones
!> de singularidad/deficiencia de rango implementadas en esta subrutina son rudimentarias.
!> La subrutina CTRTRS llamada por esta subrutina solo señala un fallo debido a
!> singularidad si el problema es exactamente singular.
!>
!> Es concebible que uno (o más) de los factores involucrados en la factorización
!> RQ generalizada del par (B, A) esté cerca de la singularidad sin que esta
!> subrutina señale un error. Las soluciones calculadas para problemas
!> casi-rank-deficientes pueden ser menos precisas debido a una pérdida de precisión numérica.
!> 
!>

Parámetros

M 
!>          M es ENTERO
!>          El número de filas de la matriz A. M >= 0.
!>

N

!>          N es ENTERO
!>          El número de columnas de las matrices A y B. N >= 0.
!>

P

!>          P es ENTERO
!>          El número de filas de la matriz B. 0 <= P <= N <= M+P.
!>

A

!>          A es array COMPLEJO, dimensión (LDA,N)
!>          En la entrada, la matriz M por N A.
!>          En la salida, los elementos en y por encima de la diagonal del array
!>          contienen la matriz T trapezoidal superior min(M,N)-por-N.
!>

LDA

!>          LDA es ENTERO
!>          La dimensión principal del array A. LDA >= max(1,M).
!>

B

!>          B es array COMPLEJO, dimensión (LDB,N)
!>          En la entrada, la matriz P por N B.
!>          En la salida, el triángulo superior de la submatriz B(1:P,N-P+1:N)
!>          contiene la matriz triangular superior P por P R.
!>

LDB

!>          LDB es ENTERO
!>          La dimensión principal del array B. LDB >= max(1,P).
!>

C

!>          C es array COMPLEJO, dimensión (M)
!>          En la entrada, C contiene el vector del lado derecho para la
!>          parte de mínimos cuadrados del problema LSE.
!>          En la salida, la suma de cuadrados residual para la solución
!>          se da por la suma de cuadrados de los elementos N-P+1 a M
!>          del vector C.
!>

D

!>          D es array COMPLEJO, dimensión (P)
!>          En la entrada, D contiene el vector del lado derecho para la
!>          ecuación restringida.
!>          En la salida, D es destruido.
!>

X

!>          X es array COMPLEJO, dimensión (N)
!>          En la salida, X es la solución del problema LSE.
!>

WORK

!>          WORK es array COMPLEJO, dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es ENTERO
!>          La dimensión del array WORK. LWORK >= max(1,M+N+P).
!>          Para un rendimiento óptimo LWORK >= P+min(M,N)+max(M,N)*NB,
!>          donde NB es un límite superior para los tamaños de bloque óptimos para
!>          CGEQRF, CGERQF, CUNMQR y CUNMRQ.
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo del array WORK, devuelve
!>          este valor como la primera entrada del array WORK, y XERBLA no emite
!>          ningún mensaje de error relacionado con LWORK.
!>

INFO

!>          INFO es ENTERO
!>          = 0:  salida exitosa.
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>          = 1:  el factor triangular superior R asociado con B en la
!>                factorización RQ generalizada del par (B, A) es exactamente
!>                singular, de modo que rango(B) < P; no se pudo calcular la
!>                solución de mínimos cuadrados.
!>          = 2:  la parte de (N-P) por (N-P) del factor trapezoidal superior
!>                T asociado con A en la factorización RQ generalizada
!>                del par (B, A) es exactamente singular, de modo que
!>                rango( (A) ) < N; no se pudo calcular la solución de mínimos
!>                    ( (B) )
!>                cuadrados.
!>
