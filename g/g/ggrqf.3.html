CGGRQF

Propósito:

!>
!> CGGRQF calcula una factorización RQ generalizada de una matriz A de M por N
!> y una matriz B de P por N:
!>
!>             A = R*Q,        B = Z*T*Q,
!>
!> donde Q es una matriz unitaria de N por N, Z es una matriz unitaria
!> de P por P, y R y T asumen una de las formas:
!>
!> si M <= N,  R = ( 0  R12 ) M,   o si M > N,  R = ( R11 ) M-N,
!>                  N-M  M                           ( R21 ) N
!>                                                      N
!>
!> donde R12 o R21 es triangular superior, y
!>
!> si P >= N,  T = ( T11 ) N  ,   o si P < N,  T = ( T11  T12 ) P,
!>                 (  0  ) P-N                         P   N-P
!>                    N
!>
!> donde T11 es triangular superior.
!>
!> En particular, si B es cuadrada y no singular, la factorización GRQ
!> de A y B da implícitamente la factorización RQ de A*inv(B):
!>
!>              A*inv(B) = (R*inv(T))*Z**H
!>
!> donde inv(B) denota la inversa de la matriz B, y Z**H denota la
!> transpuesta conjugada de la matriz Z.
!>

Parámetros

M 
!>          M es ENTERO
!>          El número de filas de la matriz A.  M >= 0.
!>

P

!>          P es ENTERO
!>          El número de filas de la matriz B.  P >= 0.
!>

N

!>          N es ENTERO
!>          El número de columnas de las matrices A y B. N >= 0.
!>

A

!>          A es un arreglo COMPLEJO, dimensión (LDA,N)
!>          En la entrada, la matriz A de M por N.
!>          En la salida, si M <= N, el triángulo superior del subarreglo
!>          A(1:M,N-M+1:N) contiene la matriz triangular superior R de M por M;
!>          si M > N, los elementos en y sobre la (M-N)-ésima subdiagonal
!>          contienen la matriz trapezoidal superior R de M por N; los
!>          elementos restantes, junto con el arreglo TAUA, representan la
!>          matriz unitaria Q como un producto de reflectores elementales
!>          (ver Detalles Adicionales).
!>

LDA

!>          LDA es ENTERO
!>          La dimensión principal del arreglo A. LDA >= max(1,M).
!>

TAUA

!>          TAUA es un arreglo COMPLEJO, dimensión (min(M,N))
!>          Los factores escalares de los reflectores elementales que
!>          representan la matriz unitaria Q (ver Detalles Adicionales).
!>

B

!>          B es un arreglo COMPLEJO, dimensión (LDB,N)
!>          En la entrada, la matriz B de P por N.
!>          En la salida, los elementos en y sobre la diagonal del arreglo
!>          contienen la matriz trapezoidal superior T de min(P,N) por N (T es
!>          triangular superior si P >= N); los elementos por debajo de la
!>          diagonal, junto con el arreglo TAUB, representan la matriz unitaria
!>          Z como un producto de reflectores elementales (ver Detalles
!>          Adicionales).
!>

LDB

!>          LDB es ENTERO
!>          La dimensión principal del arreglo B. LDB >= max(1,P).
!>

TAUB

!>          TAUB es un arreglo COMPLEJO, dimensión (min(P,N))
!>          Los factores escalares de los reflectores elementales que
!>          representan la matriz unitaria Z (ver Detalles Adicionales).
!>

WORK

!>          WORK es un arreglo COMPLEJO, dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es ENTERO
!>          La dimensión del arreglo WORK. LWORK >= max(1,N,M,P).
!>          Para un rendimiento óptimo LWORK >= max(N,M,P)*max(NB1,NB2,NB3),
!>          donde NB1 es el tamaño de bloque óptimo para la factorización RQ
!>          de una matriz de M por N, NB2 es el tamaño de bloque óptimo para
!>          la factorización QR de una matriz de P por N, y NB3 es el tamaño
!>          de bloque óptimo para una llamada de CUNMRQ.
!>
!>          Si LWORK = -1, se asume una consulta de espacio de trabajo; la
!>          rutina solo calcula el tamaño óptimo del arreglo WORK, devuelve
!>          este valor como la primera entrada del arreglo WORK, y XERBLA no
!>          emite ningún mensaje de error relacionado con LWORK.
!>

INFO

!>          INFO es ENTERO
!>          = 0:  salida exitosa
!>          < 0:  si INFO=-i, el i-ésimo argumento tenía un valor ilegal.
!>

!>
!>  La matriz Q se representa como un producto de reflectores elementales
!>
!>     Q = H(1) H(2) . . . H(k), donde k = min(m,n).
!>
!>  Cada H(i) tiene la forma
!>
!>     H(i) = I - taua * v * v**H
!>
!>  donde taua es un escalar complejo, y v es un vector complejo con
!>  v(n-k+i+1:n) = 0 y v(n-k+i) = 1; v(1:n-k+i-1) se almacena en la salida en
!>  A(m-k+i,1:n-k+i-1), y taua en TAUA(i).
!>  Para formar Q explícitamente, use la subrutina de LAPACK CUNGRQ.
!>  Para usar Q para actualizar otra matriz, use la subrutina de LAPACK CUNMRQ.
!>
!>  La matriz Z se representa como un producto de reflectores elementales
!>
!>     Z = H(1) H(2) . . . H(k), donde k = min(p,n).
!>
!>  Cada H(i) tiene la forma
!>
!>     H(i) = I - taub * v * v**H
!>
!>  donde taub es un escalar complejo, y v es un vector complejo con
!>  v(1:i-1) = 0 y v(i) = 1; v(i+1:p) se almacena en la salida en B(i+1:p,i),
!>  y taub en TAUB(i).
!>  Para formar Z explícitamente, use la subrutina de LAPACK CUNGQR.
!>  Para usar Z para actualizar otra matriz, use la subrutina de LAPACK CUNMQR.
!>

Detailed Description


ZGGRQF computes a generalized RQ factorization of an M-by-N matrix A
    and a P-by-N matrix B:


             A = R*Q,        B = Z*T*Q,



where Q is an N-by-N unitary matrix, Z is a P-by-P unitary
    matrix, and R and T assume one of the forms:


    if M <= N,  R = ( 0  R12 ) M,   or if M > N,  R = ( R11 ) M-N,
                     N-M  M                           ( R21 ) N
                                                        N



where R12 or R21 is upper triangular, and


    if P >= N,  T = ( T11 ) N  ,   or if P < N,  T = ( T11  T12 ) P,
                   (  0  ) P-N                         P   N-P
                      N



where T11 is upper triangular.


In particular, if B is square and nonsingular, the GRQ factorization
    of A and B implicitly gives the RQ factorization of A*inv(B):


              A*inv(B) = (R*inv(T))*Z**H



where inv(B) denotes the inverse of the matrix B, and Z**H denotes the
    conjugate transpose of the matrix Z.


Parameters


M M is INTEGER. The number of rows of the matrix A. M >= 0.


P P is INTEGER. The number of rows of the matrix B. P >= 0.


N N is INTEGER. The number of columns of the matrices A and B. N >= 0.


A A is DOUBLE PRECISION array, dimension (LDA,N)


On entry, the M-by-N matrix A.


On exit, if M <= N, the upper triangle of the subarray
    A(1:M,N-M+1:N) contains the M-by-M upper triangular matrix R;
    if M > N, the elements on and above the (M-N)-th subdiagonal
    contain the M-by-N upper trapezoidal matrix R; the remaining
    elements, with the array TAUA, represent the unitary
    matrix Q as a product of elementary reflectors (see Further
    Details).


LDA LDA is INTEGER. The leading dimension of the array A. LDA >= max(1,M).


TAUA TAUA is DOUBLE PRECISION array, dimension (min(M,N))


The scalar factors of the elementary reflectors which
    represent the unitary matrix Q (see Further Details).


B B is DOUBLE PRECISION array, dimension (LDB,N)


On entry, the P-by-N matrix B.


On exit, the elements on and above the diagonal of the array
    contain the min(P,N)-by-N upper trapezoidal matrix T (T is
    upper triangular if P >= N); the elements below the diagonal,
    with the array TAUB, represent the unitary matrix Z as a
    product of elementary reflectors (see Further Details).


LDB LDB is INTEGER. The leading dimension of the array B. LDB >= max(1,P).


TAUB TAUB is DOUBLE PRECISION array, dimension (min(P,N))


The scalar factors of the elementary reflectors which
    represent the unitary matrix Z (see Further Details).


WORK WORK is DOUBLE PRECISION array, dimension (MAX(1,LWORK))


On exit, if INFO = 0, WORK(1) returns the optimal LWORK.


LWORK LWORK is INTEGER. The dimension of the array WORK. LWORK >= max(1,N,M,P).


For optimum performance LWORK >= max(N,M,P)*max(NB1,NB2,NB3),
    where NB1 is the optimal blocksize for the RQ factorization
    of an M-by-N matrix, NB2 is the optimal blocksize for the
    QR factorization of a P-by-N matrix, and NB3 is the optimal

ZGGRQF


Purpose:




!>
!> ZGGRQF computes a generalized RQ factorization of an M-by-N matrix A
!> and a P-by-N matrix B:
!>
!>             A = R*Q,        B = Z*T*Q,
!>
!> where Q is an N-by-N unitary matrix, Z is a P-by-P unitary
!> matrix, and R and T assume one of the forms:
!>
!> if M <= N,  R = ( 0  R12 ) M,   or if M > N,  R = ( R11 ) M-N,
!>                  N-M  M                           ( R21 ) N
!>                                                      N
!>
!> where R12 or R21 is upper triangular, and
!>
!> if P >= N,  T = ( T11 ) N  ,   or if P < N,  T = ( T11  T12 ) P,
!>                 (  0  ) P-N                         P   N-P
!>                    N
!>
!> where T11 is upper triangular.
!>
!> In particular, if B is square and nonsingular, the GRQ factorization
!> of A and B implicitly gives the RQ factorization of A*inv(B):
!>
!>              A*inv(B) = (R*inv(T))*Z**H
!>
!> where inv(B) denotes the inverse of the matrix B, and Z**H denotes the
!> conjugate transpose of the matrix Z.
!>
