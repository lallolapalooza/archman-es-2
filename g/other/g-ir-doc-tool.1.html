NOMBRE

g-ir-doc-tool - Generador de documentación

SINOPSIS

g-ir-doc-tool [OPCIÓN...] ARCHIVO.GIR

DESCRIPCIÓN

g-ir-doc-tool genera la documentación de la biblioteca directamente desde archivos .gir. La salida se ajusta según el idioma de programación para el que se estén generando los documentos.

OPCIONES

--help
Muestra las opciones de ayuda
--output=DIRECTORIO
Guarda la salida resultante en DIRECTORIO.
--format=FORMATO
Formato de salida. Uno de devdocs, mallard o sections.
--language=IDIOMA
Idioma de salida. Uno de c, python o gjs.
--add-include-path=DIRECTORIO
Agrega un directorio que se utilizará para encontrar inclusiones dentro del formato GIR.
--version
Muestra el número de versión del programa y sale
--write-sections-file
Equivalente compatible con versiones anteriores a -f sections.

ERRORES

Reporte errores en https://gitlab.gnome.org/GNOME/gobject-introspection/issues
