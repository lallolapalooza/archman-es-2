NOMBRE

gawkbug - reportar un error en gawk

SINOPSIS

gawkbug [--version] [--help] [dirección-de-correo]

DESCRIPCIÓN

gawkbug es un script de shell para ayudar al usuario a componer y enviar informes de errores concernientes a gawk en un formato estándar. gawkbug invoca el editor especificado por la variable de entorno EDITOR en una copia temporal del esquema del formato del informe de errores. El usuario debe completar los campos apropiados y salir del editor. gawkbug luego envía el informe completado a bug-gawk@gnu.org, o a dirección-de-correo. Si el informe no puede ser enviado, se guarda en el archivo dead.gawkbug en el directorio principal del usuario que lo invoca.

El esquema del formato del informe de errores consta de varias secciones. La primera sección proporciona información sobre la máquina, el sistema operativo, la versión de gawk y el entorno de compilación. La segunda sección debe completarse con una descripción del error. La tercera sección debe ser una descripción de cómo reproducir el error. La cuarta sección opcional es para una corrección propuesta. Se alientan las correcciones.

ENTORNO

gawkbug utilizará las siguientes variables de entorno si existen:

EDITOR
Especifica el editor preferido. Si EDITOR no está establecido, gawkbug intenta localizar varios editores alternativos, incluyendo vim, y si debe hacerlo, emacs. Si gawkbug no puede localizar ninguno de los editores alternativos, intenta ejecutar vi.
HOME
Directorio en el que se guarda el informe de errores fallido si el envío de correo falla.
TMPDIR
Directorio en el que crear archivos y directorios temporales.
