NOMBRE

gameconqueror - Una GUI para scanmem, una herramienta de hackeo de juegos.

SINOPSIS

gameconqueror [opciones] [pid-del-programa-objetivo]

DESCRIPCIÓN

Scanmem es una utilidad de depuración interactiva simple para Linux, utilizada para localizar la dirección de una variable en un proceso en ejecución. Esto se puede utilizar para el análisis o modificación de un proceso hostil en una máquina comprometida, para ingeniería inversa, o como un "detector de trucos" para hacer trampa en videojuegos.

GameConqueror es una GUI para scanmem, cuyo objetivo es proporcionar más funciones que scanmem y una interfaz fácil de usar similar a CheatEngine.

OPCIONES

-v, --version
Imprimir versión y salir.
-h, --help
Imprimir una breve descripción de las opciones de la línea de comandos y salir.
-s, --search=valor
Rellenar el cuadro de búsqueda con el valor dado.
