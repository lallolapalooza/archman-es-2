NOMBRE

gammu-smsd-pgsql - backend de gammu-smsd(1) que usa el servidor de base de datos PostgreSQL como almacenamiento de mensajes

DESCRIPCIÓN

El backend PGSQL almacena todos los datos en un servidor de base de datos de PostgreSQL, cuyos parámetros se definen en la configuración (ver gammu-smsdrc para la descripción de las opciones de configuración).

Para la descripción de las tablas, ver gammu-smsd-tables.

Este backend se basa en gammu-smsd-sql.

CONFIGURACIÓN

Antes de ejecutar gammu-smsd, necesita crear las tablas necesarias en la base de datos, lo cual se describe a continuación.

El archivo de configuración puede ser entonces como:

[smsd]
service = sql
driver = native_pgsql
host = localhost

VER TAMBIÉN:

gammu-smsdrc

CREATE OR REPLACE FUNCTION update_timestamp() RETURNS trigger AS $update_timestamp$
  BEGIN
    NEW."UpdatedInDB" := LOCALTIMESTAMP(0);
    RETURN NEW;
  END;
