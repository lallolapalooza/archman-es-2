gamma(3) Manual de funciones de biblioteca gamma(3)

NOMBRE

gamma, gammaf, gammal - (logaritmo de la) función gamma

BIBLIOTECA

Biblioteca matemática (libm, -lm)

SINOPSIS

#include <math.h>
[[deprecated]] double gamma(double x);
[[deprecated]] float gammaf(float x);
[[deprecated]] long double gammal(long double x);
Requisitos de macros de prueba de características para glibc (ver feature_test_macros(7)):

gamma():

    _XOPEN_SOURCE
        || /* Desde glibc 2.19: */ _DEFAULT_SOURCE
        || /* glibc <= 2.19: */ _BSD_SOURCE || _SVID_SOURCE

gammaf(), gammal():

    _XOPEN_SOURCE >= 600 || (_XOPEN_SOURCE && _ISOC99_SOURCE)
        || /* Desde glibc 2.19: */ _DEFAULT_SOURCE
        || /* glibc <= 2.19: */ _BSD_SOURCE || _SVID_SOURCE

DESCRIPCIÓN

Estas funciones están obsoletas: en su lugar, utilice las funciones tgamma(3) o lgamma(3), según corresponda.

Para la definición de la función Gamma, consulte tgamma(3).

Versión *BSD

La libm en 4.4BSD y algunas versiones de FreeBSD tenía una función gamma() que calculaba la función Gamma, como cabría esperar.

Versión glibc

glibc tiene una función gamma() que es equivalente a lgamma(3) y calcula el logaritmo natural de la función Gamma.

VALOR DE RETORNO

Ver lgamma(3).

ERRORES

Ver lgamma(3).

ATRIBUTOS

Para una explicación de los términos utilizados en esta sección, consulte attributes(7).

Interfaz Atributo Valor
gamma (), gammaf (), gammal () Seguridad de hilos MT-Unsafe race:signgam

ESTÁNDARES

Ninguno.

HISTORIA

SVID 2.

Debido a las variaciones históricas en el comportamiento entre sistemas, esta función no está especificada en ningún estándar reciente.

4.2BSD tenía una gamma() que calculaba ln(|Gamma(|x|)|), dejando el signo de Gamma(|x|) en el entero externo signgam. En 4.3BSD, el nombre se cambió a lgamma(3), y la página del manual promete:


"En algún momento futuro, el nombre gamma será rehabilitado y se utilizará para la función Gamma"

Esto sucedió de hecho en 4.4BSD, donde gamma() calcula la función Gamma (sin afectar a signgam). Sin embargo, esto llegó demasiado tarde, y ahora tenemos tgamma(3), la función "gamma verdadera".

VER TAMBIÉN

lgamma(3), signgam(3), tgamma(3)
