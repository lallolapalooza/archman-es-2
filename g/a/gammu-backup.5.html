NOMBRE

gammu-backup - Formato de archivo de copia de seguridad de gammu(1).

El formato de copia de seguridad es un archivo de texto codificado en codificaciones ASCII o UCS-2-BE.

Este archivo utiliza la sintaxis de archivos ini, véase ini.

EJEMPLOS

Si realizará una copia de seguridad de la configuración en un archivo de texto de Gammu, será posible editarlo. Es fácil: muchas cosas en este archivo se escribirán dos veces, una en Unicode y otra en ASCII. Cuando elimine la versión Unicode, Gammu utilizará ASCII en la restauración (y podrá editar fácilmente el texto ASCII) y lo convertirá de acuerdo con la configuración regional de su sistema operativo. Cuando esté disponible la versión Unicode del texto, se utilizará en lugar de ASCII (útil con teléfonos Unicode; no es importante qué configuración regional esté establecida en el ordenador y no se realiza ninguna conversión Unicode -> ASCII y ASCII -> Unicode).

Puede utilizar cualquier editor con función de expresiones regulares para editar el archivo de texto de copia de seguridad. Ejemplos de dichos editores pueden ser vim o TextPad, que ambos admiten expresiones regulares.

Eliminar información sobre etiquetas de voz

Buscar:

^Entry\([0-9][0-9]\)VoiceTag = \(.*\)\n

Reemplazar:

<espacio en blanco>

Cambiar todos los números que comienzan con +3620, +3630, +3660, +3670 a +3620

Buscar:

Type = NumberGeneral\nEntry\([0-9][0-9]\)Text = "\+36\(20\|30\|60\|70\)\n

Reemplazar:

Type = NumberMobile\nEntry\1Text = "\+3620

Cambiar el tipo de números de teléfono a móvil para los números que comienzan con +3620, +3630,... y eliminando la línea TextUnicode correspondiente

Buscar:

Type = NumberGeneral\nEntry\([0-9][0-9]\)Text = "\+36\([2367]0\)\([^\"]*\)"\nEntry\([0-9][0-9]\)TextUnicode = \([^\n]*\)\n

Reemplazar:

Type = NumberMobile\nEntry\1Text = "\+36\2\3"\n
