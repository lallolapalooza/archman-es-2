getaddrinfo_a(3) Library Functions Manual getaddrinfo_a(3)

NOMBRE

getaddrinfo_a, gai_suspend, gai_error, gai_cancel - traducción asíncrona de direcciones y servicios de red

BIBLIOTECA

Biblioteca de búsqueda de nombres asíncrona (libanl, -lanl)

SINOPSIS

#define _GNU_SOURCE         /* Ver feature_test_macros(7) */
#include <netdb.h>
int getaddrinfo_a(int mode, struct gaicb *list[restrict n],
                  int n, struct sigevent *restrict sevp);
int gai_suspend(const struct gaicb *const list[n], int n,
                  const struct timespec *timeout);
int gai_error(struct gaicb *req);
int gai_cancel(struct gaicb *req);

DESCRIPCIÓN

La función getaddrinfo_a() realiza la misma tarea que getaddrinfo(3), pero permite que múltiples búsquedas de nombres se realicen de forma asíncrona, con notificación opcional al completar las operaciones de búsqueda.

El argumento mode tiene uno de los siguientes valores:

GAI_WAIT
Realiza las búsquedas de forma síncrona. La llamada se bloquea hasta que las búsquedas se completan.
GAI_NOWAIT
Realiza las búsquedas de forma asíncrona. La llamada regresa inmediatamente y las solicitudes se resuelven en segundo plano. Ver la discusión del argumento sevp más abajo.

El array list especifica las solicitudes de búsqueda a procesar. El argumento n especifica el número de elementos en list. Las operaciones de búsqueda solicitadas se inician en paralelo. Los elementos NULL en list se ignoran. Cada solicitud se describe mediante una estructura gaicb, definida de la siguiente manera:


struct gaicb {
    const char            *ar_name;
    const char            *ar_service;
    const struct addrinfo *ar_request;
    struct addrinfo       *ar_result;
};

Los elementos de esta estructura corresponden a los argumentos de getaddrinfo(3). Por lo tanto, ar_name corresponde al argumento node y ar_service al argumento service, identificando un host de Internet y un servicio. El elemento ar_request corresponde al argumento hints, especificando los criterios para seleccionar las estructuras de direcciones de socket devueltas. Finalmente, ar_result corresponde al argumento res; no necesitas inicializar este elemento, se establecerá automáticamente cuando se resuelva la solicitud. La estructura addrinfo referenciada por los dos últimos elementos se describe en getaddrinfo(3).

Cuando mode se especifica como GAI_NOWAIT, las notificaciones sobre las solicitudes resueltas se pueden obtener utilizando la estructura sigevent apuntada por el argumento sevp. Para la definición y detalles generales de esta estructura, ver sigevent(3type). El campo sevp->sigev_notify puede tener los siguientes valores:

SIGEV_NONE
No proporcionar ninguna notificación.
SIGEV_SIGNAL
Cuando una búsqueda se completa, genera la señal sigev_signo para el proceso. Ver sigevent(3type) para detalles generales. El campo si_code de la estructura siginfo_t se establecerá en SI_ASYNCNL.
SIGEV_THREAD
Cuando una búsqueda se completa, invoca sigev_notify_function como si fuera la función de inicio de un nuevo hilo. Ver sigevent(3type) para detalles.

Para SIGEV_SIGNAL y SIGEV_THREAD, puede ser útil apuntar sevp->sigev_value.sival_ptr a list.

La función gai_suspend() suspende la ejecución del hilo llamador, esperando la finalización de una o más solicitudes en el array list. El argumento n especifica el tamaño del array list. La llamada se bloquea hasta que ocurre uno de los siguientes eventos:

•
Una o más de las operaciones en list se completan.
•
La llamada es interrumpida por una señal que es capturada.
•
El intervalo de tiempo especificado en timeout transcurre. Este argumento especifica un tiempo de espera en segundos y nanosegundos (ver nanosleep(2) para detalles de la estructura timespec). Si timeout es NULL, la llamada se bloquea indefinidamente (hasta que ocurra uno de los eventos anteriores).

No se da ninguna indicación explícita de qué solicitud se completó; debes determinar qué solicitud(es) se completaron iterando con gai_error() sobre la lista de solicitudes.

La función gai_error() devuelve el estado de la solicitud req: EAI_INPROGRESS si la solicitud aún no se ha completado, 0 si se resolvió correctamente, o un código de error si la solicitud no pudo ser resuelta.

La función gai_cancel() cancela la solicitud req. Si la solicitud se ha cancelado correctamente, el estado de error de la solicitud se establecerá en EAI_CANCELED y se realizará la notificación asíncrona normal. La solicitud no puede cancelarse si se está procesando actualmente; en ese caso, se manejará como si gai_cancel() nunca se hubiera llamado. Si req es NULL, se intenta cancelar todas las solicitudes pendientes que el proceso ha realizado.

VALOR DE RETORNO

La función getaddrinfo_a() devuelve 0 si todas las solicitudes se han encolado correctamente, o uno de los siguientes códigos de error distintos de cero:

EAI_AGAIN
Los recursos necesarios para encolar las solicitudes de búsqueda no estaban disponibles. La aplicación puede verificar el estado de error de cada solicitud para determinar cuáles fallaron.
EAI_MEMORY
Sin memoria.
EAI_SYSTEM
mode es inválido.

La función gai_suspend() devuelve 0 si al menos una de las solicitudes listadas se ha completado. De lo contrario, devuelve uno de los siguientes códigos de error distintos de cero:

EAI_AGAIN
El tiempo de espera dado expiró antes de que cualquiera de las solicitudes pudiera completarse.
EAI_ALLDONE
No se proporcionaron solicitudes reales a la función.
EAI_INTR
Una señal ha interrumpido la función. Tenga en cuenta que esta interrupción podría haber sido causada por la notificación de señal de alguna solicitud de búsqueda completada.

La función gai_error() puede devolver EAI_INPROGRESS para una solicitud de búsqueda sin terminar, 0 para una búsqueda completada con éxito (como se describe anteriormente), uno de los códigos de error que podrían ser devueltos por getaddrinfo(3), o el código de error EAI_CANCELED si la solicitud ha sido cancelada explícitamente antes de que pudiera ser terminada.

La función gai_cancel() puede devolver uno de estos valores:

EAI_CANCELED
La solicitud se ha cancelado correctamente.
EAI_NOTCANCELED
La solicitud no ha sido cancelada.
EAI_ALLDONE
La solicitud ya se ha completado.

La función gai_strerror(3) traduce estos códigos de error a una cadena legible por humanos, adecuada para la notificación de errores.

EJEMPLO

S

Se proporcionan dos ejemplos: uno simple que resuelve varias solicitudes en paralelo de forma sincrónica, y otro complejo que muestra algunas de las capacidades

asíncronas.

Ejemplo

sincrónico

El programa siguiente simplemente resuelve varios nombres de host en paralelo, logrando una aceleración en comparación con resolver los nombres de host secuencialmente usando getaddrinfo(3). El programa podría usarse

así: 


$ ./a.out mirrors.kernel.org enoent.linuxfoundation.org gnu.org;
mirrors.kernel.org: 139.178.88.99
enoent.linuxfoundation.org: Name or service not known
gnu.org: 209.51.188.
116

Aquí está el código fuente del

programa 
#define _GNU_SOURCE
#include <err.h>
#include <netdb.h>
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#define MALLOC(n, type)  ((type *) reallocarray(NULL, n, sizeof(type)))
int
main(int argc, char *argv[])
{
    int ret;
    struct gaicb *reqs[argc - 1];
    char host[NI_MAXHOST];
    struct addrinfo *res;
    if (argc < 2) {
        fprintf(stderr, "Usage: %s HOST...\n", argv[0]);
        exit(EXIT_FAILURE);
    }
    for (size_t i = 0; i < argc - 1; i++) {
        reqs[i] = MALLOC(1, struct gaicb);
        if (reqs[i] == NULL)
            err(EXIT_FAILURE, "malloc");
        memset(reqs[i], 0, sizeof(*reqs[0]));
        reqs[i]->ar_name = argv[i + 1];
    }
    ret = getaddrinfo_a(GAI_WAIT, reqs, argc - 1, NULL);
    if (ret != 0) {
        fprintf(stderr, "getaddrinfo_a() failed: %s\n",
                gai_strerror(ret));
        exit(EXIT_FAILURE);
    }
    for (size_t i = 0; i < argc - 1; i++) {
        printf("%s: ", reqs[i]->ar_name);
        ret = gai_error(reqs[i]);
        if (ret == 0) {
            res = reqs[i]->ar_result;
            ret = getnameinfo(res->ai_addr, res->ai_addrlen,
                              host, sizeof(host),
                              NULL, 0, NI_NUMERICHOST);
            if (ret != 0) {
                fprintf(stderr, "getnameinfo() failed: %s\n",
                        gai_strerror(ret));
                exit(EXIT_FAILURE);
            }
            puts(host);
        } else {
            puts(gai_strerror(ret));
        }
    }
    exit(EXIT_SUCCESS);
}

asíncrono

demuestra.

así:

[01] enoent.linuxfoundation.org: Processing request in progress
[02] gnu.org: 209.51.188.116

[00] mirrors.kernel.org: 139.178.88.99
[01] enoent.linuxfoundation.org: Name or service not known
[02] gnu.org: 209.51.188.
116

El código fuente del programa es el

siguiente: 
#define _GNU_SOURCE
#include <assert.h>
#include <err.h>
#include <netdb.h>
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#define CALLOC(n, type)  ((type *) calloc(n, sizeof(type)))
#define REALLOCF(ptr, n, type)                                          \
({                                                                      \
    static_assert(__builtin_types_compatible_p(typeof(ptr), type *));   \
                                                                        \
    (type *) reallocarrayf(ptr, n, sizeof(type));                       \
})
static struct gaicb **reqs = NULL;
static size_t nreqs = 0;
static inline void *
reallocarrayf(void *p, size_t n, size_t size)
{
    void  *q;
    q = reallocarray(p, n, size);
    if (q == NULL && n != 0 && size != 0)
        free(p);
    return q;
}
static char *
getcmd(void)
{
    static char buf[256];
    fputs("> ", stdout);
    fflush(stdout);
    if (fgets(buf, sizeof(buf), stdin) == NULL)
        return NULL;
    if (buf[strlen(buf) - 1] == '\n')
        buf[strlen(buf) - 1] = 0;
    return buf;
}
/* Add requests for specified hostnames.  */
static void
add_requests(void)
{
    size_t nreqs_base = nreqs;
    char *host;
    int ret;
    while ((host = strtok(NULL, " "))) {
        nreqs++;
        reqs = REALLOCF(reqs, nreqs, struct gaicb *);
        if (reqs == NULL)
            err(EXIT_FAILURE, "reallocf");
        reqs[nreqs - 1] = CALLOC(1, struct gaicb);
        if (reqs[nreqs - 1] == NULL)
            err(EXIT_FAILURE, "calloc");
        reqs[nreqs - 1]->ar_name = strdup(host);
    }
    /* Queue nreqs_base..nreqs requests.  */
    ret = getaddrinfo_a(GAI_NOWAIT, &reqs[nreqs_base],
                        nreqs - nreqs_base, NULL);
    if (ret) {
        fprintf(stderr, "getaddrinfo_a() failed: %s\n",
                gai_strerror(ret));
        exit(EXIT_FAILURE);
    }
}
/* Wait until at least one of specified requests completes.  */
static void
wait_requests(void)
{
    char *id;
    int ret;
    size_t n;
    struct gaicb const **wait_reqs;
    wait_reqs = CALLOC(nreqs, const struct gaicb *);
    if (wait_reqs == NULL)
        err(EXIT_FAILURE, "calloc");
                /* NULL elements are ignored by gai_suspend().  */
    while ((id = strtok(NULL, " ")) != NULL) {
        n = atoi(id);
        if (n >= nreqs) {
            printf("Bad request number: %s\n", id);
            return;
        }
        wait_reqs[n] = reqs[n];
    }
    ret = gai_suspend(wait_reqs, nreqs, NULL);
    if (ret) {
        printf("gai_suspend(): %s\n", gai_strerror(ret));
        return;
    }
    for (size_t i = 0; i < nreqs; i++) {
        if (wait_reqs[i] == NULL)
            continue;
        ret = gai_error(reqs[i]);
        if (ret == EAI_INPROGRESS)
            continue;
        printf("[%02zu] %s: %s\n", i, reqs[i]->ar_name,
               ret == 0 ? "Finished" : gai_strerror(ret));
    }
}
/* Cancel specified requests.  */
static void
cancel_requests(void)
{
    char *id;
    int ret;
    size_t n;
    while ((id = strtok(NULL, " ")) != NULL) {
        n = atoi(id);
        if (n >= nreqs) {
            printf("Bad request number: %s\n", id);
            return;
        }
        ret = gai_cancel(reqs[n]);
        printf("[%s] %s: %s\n", id, reqs[atoi(id)]->ar_name,
               gai_strerror(ret));
    }
}
/* List all requests.  */
static void
list_requests(void)
{
    int ret;
    char host[NI_MAXHOST];
    struct addrinfo *res;
    for (size_t i = 0; i < nreqs; i++) {
        printf("[%02zu] %s: ", i, reqs[i]->ar_name);
        ret = gai_error(reqs[i]);
        if (!ret) {
            res = reqs[i]->ar_result;
            ret = getnameinfo(res->ai_addr, res->ai_addrlen,
                              host, sizeof(host),
                              NULL, 0, NI_NUMERICHOST);
            if (ret) {
                fprintf(stderr, "getnameinfo() failed: %s\n",
                        gai_strerror(ret));
                exit(EXIT_FAILURE);
            }
            puts(host);
        } else {
            puts(gai_strerror(ret));
        }
    }
}
int
main(void)
{
    char *cmdline;
    char *cmd;
    while ((cmdline = getcmd()) != NULL) {
        cmd = strtok(cmdline, " ");
        if (cmd == NULL) {
            list_requests();
        } else {
            switch (cmd[0]) {
            case 'a':
                add_requests();
                break;
            case 'w':
                wait_requests();
                break;
            case 'c':
                cancel_requests();
                break;
            case 'l':
                list_requests();
                break;
            default:
                fprintf(stderr, "Bad command: %c\n", cmd[0]);
                break;
            }
        }
    }
    exit(EXIT_SUCCESS)
;
}
