NOMBRE

gammurc - archivo de configuración de gammu(1)

SINOPSIS

En Linux, MacOS X, BSD y otros sistemas similares a Unix, el archivo de configuración se busca en el siguiente orden:

1.
$XDG_CONFIG_HOME/gammu/config
2.
~/.config/gammu/config
3.
~/.gammurc
4.
/etc/gammurc

En Microsoft Windows:

1.
%PROFILE%\Application Data\gammurc
2.
.\gammurc

DESCRIPCIÓN

Gammu requiere configuración para poder comunicarse correctamente con tu teléfono. gammu lee la configuración de un archivo de configuración. Su ubicación se determina en tiempo de ejecución, ver arriba para las rutas de búsqueda.

Puedes usar gammu-config o gammu-detect para generar un archivo de configuración o empezar desde el ejemplo completamente documentado.

Para obtener pistas sobre cómo configurar tu teléfono, puedes consultar la Base de Datos de Teléfonos de Gammu en https://wammu.eu/phones/ para ver qué experiencias han tenido los usuarios.

Este archivo utiliza sintaxis de archivo ini, ver ini.

El archivo de configuración para gammu puede contener varias secciones - [gammu], [gammu1], [gammuN], ... Cada sección configura una configuración de conexión y en modo predeterminado gammu prueba todas en orden numérico. También puedes especificar qué sección de configuración usar dándole su número ([gammu] tiene el número 0) como parámetro a gammu y luego usará solo esa sección.

[gammu]

Esta sección se lee por defecto a menos que especifiques otra en la línea de comandos.

Parámetros de conexión del dispositivo

Connection
Protocolo que se utilizará para comunicarse con tu teléfono.

Para cables Nokia, querrás usar uno de los siguientes:

fbus
conexión FBUS serie
dlr3
cables DLR-3 y compatibles
dku2
cables DKU-2 y compatibles
dku5
cables DKU-5 y compatibles
mbus
conexión MBUS serie

Si usas algún cable no original, podrías necesitar añadir -nodtr (por ejemplo, para cables basados en ARK3116) o -nopower, pero Gammu debería ser capaz de detectarlo automáticamente.

Para teléfonos no Nokia conectados por cable, generalmente querrás:

at
conexión genérica basada en comandos AT

Opcionalmente, puedes especificar la velocidad de la conexión, por ejemplo, at19200, pero no es necesario para los cables USB modernos.

Para conexiones IrDA usa una de las siguientes:

irdaphonet
conexión Phonet para teléfonos Nokia.
irdaat
conexión de comandos AT para la mayoría de los teléfonos (esto no es compatible en Linux).
irdaobex
conexión OBEX (IrMC o transferencia de archivos) para la mayoría de los teléfonos.
irdagnapbus
conexión basada en GNapplet para teléfonos Symbian, ver gnapplet.

Para conexión Bluetooth usa una de las siguientes:

bluephonet
conexión Phonet para teléfonos Nokia.
bluefbus
conexión FBUS para teléfonos Nokia.
blueat
conexión de comandos AT para la mayoría de los teléfonos.
blueobex
conexión OBEX (IrMC o transferencia de archivos) para la mayoría de los teléfonos.
bluerfgnapbus
conexión basada en GNapplet para teléfonos Symbian, ver gnapplet.
blues60
conexión a la aplicación Series60 en teléfonos S60, ver s60.

Nuevo en la versión 1.29.90.

Nuevo en la versión 1.36.7: Gammu ahora soporta conectarse usando un comando proxy.

También puedes proxyar la conexión usando un comando de shell, por ejemplo, a un host diferente. Esto se puede hacer usando conexiones proxy:

proxyphonet
conexión Phonet para teléfonos Nokia.
proxyfbus
conexión FBUS para teléfonos Nokia.
proxyat
conexión de comandos AT para la mayoría de los teléfonos.
proxyobex
conexión OBEX (IrMC o transferencia de archivos) para la mayoría de los teléfonos.
proxygnapbus
conexión basada en GNapplet para teléfonos Symbian, ver gnapplet.
proxys60
conexión a la aplicación Series60 en teléfonos S60, ver s60.

Device
Nuevo en la versión 1.27.95.

Nodo o dirección del dispositivo del teléfono. Depende de la conexión utilizada.

Para cables o puertos serie emulados, introduces el nombre del dispositivo (por ejemplo /dev/ttyS0, /dev/ttyACM0, /dev/ircomm0, /dev/rfcomm0 en Linux, /dev/cuad0 en FreeBSD o COM1: en Windows). La excepción especial son los cables DKU-2 y DKU-5 en Windows, donde el dispositivo se detecta automáticamente a partir de la información del controlador y este parámetro se ignora.

NOTA:

Algunos módems USB exponen varias interfaces, en tales casos Gammu funciona mejor con la del "Usuario", puedes encontrar más información en http://www.dd-wrt.com/wiki/index.php/Mobile_Broadband.

Para conexiones USB (actualmente solo fbususb y dku2 en Linux), puedes especificar a qué dispositivo USB debe conectarse Gammu. Puedes proporcionar identificadores de proveedor/producto o la dirección del dispositivo en USB:

Device = 0x1234:0x5678  # Coincidir dispositivo por ID de proveedor y producto
Device = 0x1234:-1      # Coincidir dispositivo por ID de proveedor
Device = 1.10           # Coincidir dispositivo por bus USB y dirección del dispositivo
Device = 10             # Coincidir dispositivo por dirección del dispositivo USB
Device = serial:123456  # Coincidir dispositivo por cadena de serie

NOTA:

En sistemas Linux, podrías carecer de permisos para algunos nodos de dispositivo. Podrías necesitar ser miembro de algún grupo (por ejemplo, plugdev o dialout) o añadir reglas udev especiales para permitirte acceder a estos dispositivos como no root.

Para teléfonos Nokia puedes colocar el siguiente archivo (también disponible en las fuentes como contrib/udev/69-gammu-acl.rules) como /etc/udev/rules.d/69-gammu-acl.rules:

#
# regla udev para dar a los usuarios acceso al dispositivo USB para ser utilizado por Gammu
#
ACTION!="add|change", GOTO="gammu_acl_rules_end"
KERNEL!="ttyACM[0-9]*", GOTO="gammu_acl_rules_end"
SUBSYSTEM!="tty", GOTO="gammu_acl_rules_end"
# Dispositivos Nokia
ATTRS{manufacturer}=="Nokia", TAG+="uaccess"
# Ejemplo para Sony Ericsson J108i Cedar
# ATTRS{idVendor}=="0fce", ATTRS{idProduct}=="d14e", TAG+="uaccess"
LABEL="gammu_acl_rules_end"

Opciones

avanzadas

Las opciones avanzadas se utilizan para alterar la lógica predeterminada; al usar estas opciones, el usuario es responsable de asegurar que cualquier configuración sea correcta para el dispositivo de destino y que produzca el comportamiento

deseado.
atgen_setCN
MI
Para configuraciones que utilizan el protocolo de comandos AT genérico, es posible anular los indicadores predeterminados que se utilizan cuando se recibe un nuevo mensaje SMS.

El valor para la configuración es una lista delimitada por comas de dígitos individuales que corresponden a los valores para el comando de módem AT+CNMI. Si no se proporciona un dígito, o si el dígito proporcionado está fuera del rango aceptable para el dispositivo, se utiliza el valor

predeterminado.

Por ejemplo, establecer atgen_setcnmi = ,,2 establecería el tercer parámetro del comando CNMI al valor 2, dejando el resto de los parámetros en sus valores predeterminados, y atgen_setcnmi = 1,,,1 e
