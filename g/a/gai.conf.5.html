gai.conf(5) Manual de formatos de archivo gai.conf(5)

NOMBRE

gai.conf - archivo de configuración de getaddrinfo(3)

DESCRIPCIÓN

Una llamada a getaddrinfo(3) puede devolver múltiples respuestas. Según RFC 3484, estas respuestas deben ordenarse de modo que la respuesta con la mayor tasa de éxito esté primero en la lista. El RFC proporciona un algoritmo para la ordenación. Las reglas estáticas no siempre son adecuadas, sin embargo. Por esta razón, el RFC también exige que los administradores del sistema deban tener la posibilidad de cambiar dinámicamente la ordenación. Para la implementación de glibc, esto se puede lograr con el archivo /etc/gai.conf.

Cada línea en el archivo de configuración consta de una palabra clave y sus parámetros. Los espacios en blanco en cualquier lugar se ignoran. Las líneas que comienzan con '#' son comentarios y se ignoran.

Las palabras clave actualmente reconocidas son:

etiqueta máscara-red precedencia
El valor se añade a la tabla de etiquetas utilizada en la ordenación RFC 3484. Si está presente alguna definición de etiqueta en el archivo de configuración, la tabla por defecto no se utiliza. Todas las definiciones de etiqueta de la tabla por defecto que deban mantenerse deben duplicarse. Después de la palabra clave, la línea debe contener una máscara de red y un valor de precedencia.
precedencia máscara-red precedencia
Esta palabra clave es similar a etiqueta, pero en su lugar el valor se añade a la tabla de precedencia tal como se especifica en RFC 3484. Una vez más, la presencia de una sola línea de precedencia en el archivo de configuración provoca que la tabla por defecto no se utilice.
recargar <sí|no>
Esta palabra clave controla si un proceso verifica si el archivo de configuración ha cambiado desde la última vez que se leyó. Si el valor es "sí", el archivo se vuelve a leer. Esto podría causar problemas en aplicaciones multihilo y, en general, es una mala idea. El valor por defecto es "no".
scopev4 máscara valor
Añade otra regla a la tabla de ámbito RFC 3484 para direcciones IPv4. Por defecto, se utilizan los IDs de ámbito descritos en la sección 3.2 de RFC 3438. Cambiar estos valores por defecto rara vez debería ser necesario.

ARCHIVOS

/etc/gai.conf

VERSIÓNES

El archivo gai.conf es compatible desde glibc 2.5.

EJEMPLOS

La tabla por defecto según RFC 3484 se especificaría con el siguiente archivo de configuración:


etiqueta  ::1/128       0
etiqueta  ::/0          1
etiqueta  2002::/16     2
etiqueta ::/96          3
etiqueta ::ffff:0:0/96  4
precedencia  ::1/128       50
precedencia  ::/0          40
precedencia  2002::/16     30
precedencia ::/96          20
precedencia ::ffff:0:0/96  10

VER TAMBIÉN

getaddrinfo(3), RFC 3484
