VARIABLES, REGISTROS Y CAMPOS Las variables AWK son dinámicas; entran en existencia cuando se usan por primera vez. Sus valores son números de punto flotante o cadenas, o ambos, dependiendo de cómo se usen. Adicionalmente, gawk permite que las variables tengan tipo de expresión regular. AWK también tiene arreglos unidimensionales; los arreglos con múltiples dimensiones pueden simularse. Sin embargo, gaw

k

proporciona arreglos verdaderos de arreglos. Varias variables predefinidas se establecen a medida que se ejecuta un programa; estas se describen según sea necesario y se resumen a continuación. $0 es el registro completo, incluyendo espacios en blanco iniciales y finales. La variable NF se establece al número total de campos en el registro de entrada. Las referencias a campos no existentes (es decir, campos después de $NF ) producen la cadena nula. Sin embargo, asignar a un ca

Valores Separados por Comas

Cuando se invoca con la opción -k o la opción --csv , gawk no usa la determinación de registros y la división de campos regulares descritas anteriormente. En su lugar, los registros terminan con saltos de línea sin comillas, y los campos se separan con comas. Se pueden usar comillas dobles para encerrar campos que contengan comas, saltos de línea o comillas dobles duplicadas. Vea https://www.gnu.org/software/gawk/manual/html_node/Comma-Separated-Fields.html para más detalles.

Matrices

Las matrices se indexan con una expresión entre corchetes ([ y ]). Si la expresión es una lista de expresiones (expr, expr ...) entonces el subíndice de la matriz es una cadena que consiste en la concatenación del valor (cadena) de cada expresión, separados por el valor de la variable SUBSEP . Esta facilidad se usa para simular matrices de múltiples dimensiones. Por ejemplo:

i = "A"; j = "B"; k = "C"
x[i, j, k] = "hello, world\n"

asigna la cadena "hello, world\n" al elemento de la matriz x que está indexado por la cadena "A\034B\034C". Todas las matrices en AWK son asociativas, es decir, indexadas por valores de cadena.

El operador especial in puede usarse para probar si una matriz tiene un índice que consiste en un valor particular:

if (val in array)
	print array[val]

Si la matriz tiene múltiples subíndices, use (i, j) in array.

La construcción in también puede usarse en un bucle for para iterar sobre todos los elementos de una matriz. Sin embargo, la construcción (i, j) in array solo funciona en pruebas, no en bucles for .

Un elemento puede eliminarse de una matriz usando la instrucción delete . La instrucción delete también puede usarse para eliminar todo el contenido de una matriz, simplemente especificando el nombre de la matriz sin un subíndice.

gawk soporta matrices multidimensionales verdaderas. No requiere que tales matrices sean “rectangulares” como en C o C++. Vea https://www.gnu.org/software/gawk/manual/html_node/Arrays para detalles.

Espacios de nombres

Gawk proporciona una facilidad simple de espacio de nombres para ayudar a sortear el hecho de que todas las variables en AWK son globales.

Un nombre calificado consiste en dos identificadores simples unidos por dos dos puntos (::). El identificador de la izquierda representa el espacio de nombres y el identificador de la derecha es la variable dentro de él. Todos los nombres simples (no calificados) se consideran que están en el espacio de nombres “actual”; el espacio de nombres por defecto es awk. Sin embargo, los identificadores simples que consisten únicamente de letras mayúsculas se fuerzan al espacio de nombres awk , incluso si el espacio de nombres actual es diferente.

Se cambia el espacio de nombres actual con la directiva @namespace "nombre" .

Los nombres de funciones incorporadas predefinidas estándar no pueden usarse como nombres de espacio de nombres. Los nombres de funciones adicionales proporcionadas por gawk pueden usarse como nombres de espacio de nombres o como identificadores simples en otros espacios de nombres. Para más detalles, vea https://www.gnu.org/software/gawk/manual/html_node/Namespaces.html#Namespaces.

Tipado de Variables y Conversión

Las variables y los campos pueden ser números (de punto flotante), o cadenas, o ambos. También pueden ser expresiones regulares. Cómo se interpreta el valor de una variablenterpretada depende de su contexto. Si se usa en una expresión numérica, se tratará como un número; si se usa como una cadena, se tratará como una

cadena.

Para forzar que una variable se trate como un número, sumele cero; para forzar que se trate como una cadena, concaténela con la cadena

nula.

Las variables no inicializadas tienen el valor numérico cero y el valor de cadena "" (la cadena nula o vacía)

.

Cuando se debe convertir una cadena a un número, la conversión se realiza usando strtod(3) . Input/Output Functions

close(file[,how])
Cierra un archivo, tubería o coproceso abierto. El how opcional solo debe usarse al cerrar un extremo de una tubería bidireccional a un coproceso. Debe ser un valor de cadena, ya sea "to" o "from".
getline
Establece $0 a partir del siguiente registro de entrada; establece NF, NR, FNR, RT.
getline <file
Establece $0 a partir del siguiente registro de file; establece NF, RT.
getline var
Establece var a partir del siguiente registro de entrada; establece NR, FNR, RT.
getline var <file
Establece var a partir del siguiente registro de file; establece RT.
command | getline [var]
Ejecuta command, canalizando la salida a $0 o a var, como arriba, y RT.
command |& getline [var]
Ejecuta command como un coproceso canalizando la salida a $0 o a var, como arriba, y RT. (El command también puede ser un socket. Ver la subsección Nombres de Archivo Especiales, más abajo.)
fflush([file])
Vacía cualquier buffer asociado con el archivo de salida o tubería abierto file. Si file falta o si es una cadena nula, entonces vacía todos los archivos de salida y tuberías abiertos.
next
Detiene el procesamiento del registro de entrada actual. Lee el siguiente registro de entrada y comienza el procesamiento de nuevo con el primer patrón en el programa AWK. Al llegar al final de los datos de entrada, ejecuta cualquier regla END.
nextfile
Detiene el procesamiento del archivo de entrada actual. El siguiente registro de entrada leído proviene del siguiente archivo de entrada. Actualiza FILENAME y ARGIND, reinicia FNR a 1, y comienza el procesamiento de nuevo con el primer patrón en el programa AWK. Al llegar al final de los datos de entrada, ejecuta cualquier regla ENDFILE y END.
print
Imprime el registro actual. El registro de salida se termina con el valor de ORS.
print expr-list
Imprime expresiones. Cada expresión está separada por el valor de OFS. El registro de salida se termina con el valor de ORS.
print expr-list >file
Imprime expresiones en file. Cada expresión está separada por el valor de OFS. El registro de salida se termina con el valor de ORS.
printf fmt, expr-list
Formatea e imprime.
printf fmt, expr-list >file
Formatea e imprime en file.
system(cmd-line)
Ejecuta el comando cmd-line y devuelve el estado de salida. (Esto puede no estar disponible en sistemas no POSIX.) Ver https://www.gnu.org/software/gawk/manual/html_node/I_002fO-Functions.html#I_002fO-Functions para todos los detalles sobre el estado de salida.

Las redirecciones de salida adicionales están permitidas para print y printf.

print ... >> file
Añade la salida al file.
print ... | command
Escribe en una tubería.
print ... |& command
Envía datos a un coproceso o socket. (Ver también la subsección Nombres de Archivo Especiales, más abajo.)

La función getline devuelve 1 si tiene éxito, cero si es fin de archivo, y -1 si hay un error. Si el valor de errno(3) indica que la operación de E/S puede ser reintentada, y PROCINFO["input", "RETRY"] está establecida, entonces se devuelve -2 en lugar de -1, y pueden ser intentadas llamadas adicionales a getline. Tras un error, ERRNO se establece a una cadena que describe el problema.

NOTA: El fallo al abrir un socket bidireccional resulta en un error no fatal devuelto a la función que llama. Si se usa una tubería, coproceso o socket para getline, o desde print o printf dentro de un bucle, debe usar close() para crear nuevas instancias del comando o socket. AWK no cierra automáticamente tuberías, sockets o coprocesos cuando devuelven EOF.

Las versiones de AWK de la sentencia printf y la función sprintf() son similares a las de C. Para detalles, ver https://www.gnu.org/software/gawk/manual/html_node/Printf.html.

Funciones de Cadena

Gawk tiene las siguientes funciones de cadena incorporadas; los detalles se proporcionan en https://www.gnu.org/software/gawk/manual/html_node/String-Functions.

asort(s [, d [, how] ])
Devuelve el número de elementos en el array de origen s. Ordena el contenido de s usando las reglas normales de gawk para comparar valores, y reemplaza los índices de los valores ordenados de s con enteros secuenciales comenzando por 1. Si se especifica el array de destino opcional d, primero duplica s en d, y luego ordena d, dejando los índices del array de origen s sin cambios. La cadena opcional how controla la dirección y el modo de comparación. Los valores válidos para how se describen en https://www.gnu.org/software/gawk/manual/html_node/String-Functions.html#String-Functions. Se permite que s y d sean el mismo array; esto solo tiene sentido al proporcionar también el tercer argumento.
asorti(s [, d [, how] ])
Devuelve el número de elementos en el array de origen s. El comportamiento es el mismo que el de asort(), excepto que los índices del array se usan para ordenar, no los valores del array. Cuando se hace, el array se indexa numéricamente y los valores son los de los índices originales. Los valores originales se pierden; por lo tanto, proporcione un segundo array si desea preservar el original. El propósito de la cadena opcional how es el mismo que para asort(). Aquí también, s y d pueden ser el mismo array; esto solo tiene sentido cuando también se proporciona el tercer argumento.

Funciones de cadena

Estas son las funciones de cadena proporcionadas por *gawk*.

gensub(r, s, h [, t])
Busca la cadena objetivo t en busca de coincidencias de la expresión regular r. Si h es una cadena que comienza con g o G, entonces reemplaza todas las coincidencias de r con s. De lo contrario, h es un número que indica qué coincidencia de r reemplazar. Si t no se proporciona, usa $0 en su lugar. Dentro del texto de reemplazo s, la secuencia \n, donde n es un dígito del 1 al 9, se puede usar para indicar solo el texto que coincidió con la subexpresión entre paréntesis n. La secuencia \0 representa todo el texto coincidente, al igual que el carácter &. A diferencia de sub() y gsub(), la cadena modificada se devuelve como resultado de la función, y la cadena objetivo original no se cambia.
gsub(r, s [, t])
Para cada subcadena que coincida con la expresión regular r en la cadena t, sustituye la cadena s y devuelve el número de sustituciones. Si t no se proporciona, usa $0. Un & en el texto de reemplazo se reemplaza con el texto que realmente coincidió. Usa \& para obtener un & literal. (Esto debe escribirse como "\\&"; consulta https://www.gnu.org/software/gawk/manual/html_node/Gory-Details.html#Gory-Details para una discusión más detallada de las reglas para ampersands y barras invertidas en el texto de reemplazo de sub(), gsub() y gensub()).
index(s, t)
Devuelve el índice de la cadena t en la cadena s, o cero si t no está presente. (Esto implica que los índices de caracteres comienzan en uno).
length([s])
Devuelve la longitud de la cadena s, o la longitud de $0 si s no se proporciona. Con un argumento de matriz, length() devuelve el número de elementos en la matriz.
match(s, r [, a])
Devuelve la posición en s donde ocurre la expresión regular r, o cero si r no está presente, y establece los valores de RSTART y RLENGTH. Ten en cuenta que el orden de los argumentos es el mismo que para el operador ~: str ~ re. Consulta https://www.gnu.org/software/gawk/manual/html_node/String-Functions.html#String-Functions para una descripción de cómo se rellena la matriz a si se proporciona.
patsplit(s, a [, r [, seps] ])
Divide la cadena s en la matriz a y la matriz de separadores seps según la expresión regular r, y devuelve el número de campos. Los valores de los elementos son las porciones de s que coincidieron con r. El valor de seps[i] es el separador posiblemente nulo que apareció después de a[i]. El valor de seps[0] es el separador inicial posiblemente nulo. Si se omite r, se usa FPAT en su lugar. Las matrices a y seps se borran primero. La división se comporta de manera idéntica a la división de campos con FPAT.
split(s, a [, r [, seps] ])
Divide la cadena s en la matriz a y la matriz de separadores seps según la expresión regular r, y devuelve el número de campos. Si se omite r, se usa FS en su lugar. Las matrices a y seps se borran primero. seps[i] es el separador de campo que coincidió con r entre a[i] y a[i+1]. La división se comporta de manera idéntica a la división de campos.
sprintf(fmt, expr-list)
Imprime expr-list según fmt y devuelve la cadena resultante.
strtonum(str)
Examina str y devuelve su valor numérico. Si str comienza con un 0 inicial, trátalo como un número octal. Si str comienza con un 0x o 0X inicial, trátalo como un número hexadecimal. De lo contrario, asume que es un número decimal.
sub(r, s [, t])
Igual que gsub(), pero reemplaza solo la primera subcadena coincidente. Devuelve cero o uno.
substr(s, i [, n])
Devuelve la subcadena de s de como máximo n caracteres que comienza en i. Si se omite n, usa el resto de s.
tolower(str)
Devuelve una copia de la cadena str, con todos los caracteres mayúsculas en str traducidos a sus correspondientes minúsculas. Los caracteres no alfabéticos no se modifican.
toupper(str)
Devuelve una copia de la cadena str, con todos los caracteres minúsculas en str traducidos a sus correspondientes mayúsculas. Los caracteres no alfabéticos no se modifican.

Gawk es consciente de los multibyte. Esto significa que index(), length(), substr() y match() operan en términos de caracteres, no de bytes.

Funciones de tiempo

Gawk proporciona las siguientes funciones para obtener marcas de tiempo y formatearlas. Los detalles se proporcionan en https://www.gnu.org/software/gawk/manual/html_node/Time-Functions.

mktime(datespec [, utc-flag])
Convierte datespec en una marca de tiempo del mismo formato que la devuelta por systime() y devuelve el resultado. Si utc-flag está presente y es distinto de cero o no nulo, se asume que la hora está en la zona horaria UTC; de lo contrario, se asume que la hora está en la zona horaria local. Si datespec no contiene suficientes elementos o si la hora resultante está fuera de rango, mktime() devuelve -1. Consulta https://www.gnu.org/software/gawk/manual/html_node/Time-Functions.html#Time-Functions para los detalles de datespec.
strftime([format [, timestamp[, utc-flag]]])
Formatea timestamp según la especificación en format. Si utc-flag está presente y es distinto de cero o no nulo, el resultado está en UTC, de lo contrario el resultado está en hora local. El timestamp debe ser del mismo formato que el devuelto por systime(). Si falta timestamp, se utiliza la hora actual del día. Si falta format, se utiliza un formato predeterminado equivalente a la salida de date(1). El formato predeterminado está disponible en PROCINFO["strftime"]. Consulta la especificación de la función strftime() en ISO C para ver las conversiones de formato que se garantizan que están disponibles.
systime()
Devuelve la hora actual del día como el número de segundos desde la Época (1970-01-01 00:00:00 UTC en sistemas POSIX).

Devuelve la traducción de cadena en el dominio de texto dominio para la categoría de localización categoría. El valor por defecto para dominio es el valor actual de TEXTDOMAIN. El valor por defecto para categoría es "LC_MESSAGES".
dcngettext(cadena1, cadena2, número [, dominio [, categoría]])
Devuelve la forma plural utilizada para número de la traducción de cadena1 y cadena2 en el dominio de texto dominio para la categoría de localización categoría. El valor por defecto para dominio es el valor actual de TEXTDOMAIN. El valor por defecto para categoría es "LC_MESSAGES".

Funciones con valor Booleano

Puedes crear valores especiales de tipo Booleano; consulta el manual para saber cómo funcionan y por qué existen.

mkbool(expresión)
Basado en el valor booleano de expresión, devuelve un valor verdadero o falso. Los valores verdaderos tienen un valor numérico de uno. Los valores falsos tienen un valor numérico de cero.

FUNCIONES DEFINIDAS POR EL USUARIO

Las funciones en AWK se definen de la siguiente manera:

function nombre(lista de parámetros) { sentencias }

Las funciones se ejecutan cuando se llaman desde dentro de expresiones en patrones o acciones. Los parámetros reales suministrados en la llamada a la función se utilizan para instanciar los parámetros formales declarados en la función. Los arrays se pasan por referencia, las otras variables se pasan por valor.

Las variables locales se declaran como parámetros adicionales en la lista de parámetros. La convención es separar las variables locales de los parámetros reales con espacios adicionales en la lista de parámetros. Por ejemplo:

function  f(p, q,     a, b)	# a y b son locales
{
	...
}
/abc/	{ ... ; f(1, 2) ; ... }

El paréntesis izquierdo en una llamada a función debe seguir inmediatamente al nombre de la función, sin ningún espacio en blanco intermedio. Esta restricción no se aplica a las funciones integradas enumeradas anteriormente.

Las funciones pueden llamarse entre sí y pueden ser recursivas. Los parámetros de función utilizados como variables locales se inicializan a la cadena nula y al número cero al invocar la función.

Utiliza return expr para devolver un valor desde una función. El valor de retorno no está definido si no se proporciona ningún valor, o si la función finaliza al llegar al final.

Las funciones pueden ser llamadas indirectamente. Para hacer esto, asigna el nombre de la función que se va a llamar, como una cadena, a una variable. Luego, usa la variable como si fuera el nombre de una función, precedida por el signo @, de esta manera:

function mi_func()
{
	print "mi_func llamada"
	...
}
{	...
	la_func = "mi_func"
	@la_func()	# llamada a través de la_func a mi_func
	...
}

Si se ha proporcionado --lint, gawk advierte sobre llamadas a funciones no definidas en tiempo de análisis, en lugar de en tiempo de ejecución. Llamar a una función no definida en tiempo de ejecución es un error fatal.

CARGA DINÁMICA DE NUEVAS FUNCIONES

Puedes agregar dinámicamente nuevas funciones escritas en C o C++ al intérprete gawk en ejecución con la declaración @load. Los detalles completos están fuera del alcance de esta página del manual; consulta https://www.gnu.org/software/gawk/manual/html_node/Dynamic-Extensions.html#Dynamic-Extensions.

SEÑALES

El generador de perfiles de gawk acepta dos señales. SIGUSR1 hace que vuelque un perfil y la pila de llamadas de funciones al archivo de perfil, que es awkprof.out, o cualquier archivo que se haya nombrado con la opción --profile. Luego continúa ejecutándose. SIGHUP hace que gawk vuelque el perfil y la pila de llamadas de funciones y luego salga.

INTERNACIONALIZACIÓN

Las constantes de cadena son secuencias de caracteres encerradas entre comillas dobles. En entornos de habla no inglesa, es posible marcar cadenas en el programa AWK como que requieren traducción al idioma natural local. Dichas cadenas se marcan en el programa AWK con un guion bajo inicial (“_”). Por ejemplo,

gawk 'BEGIN { print "hello, world" }'

siempre imprime hello, world. Pero,

gawk 'BEGIN { print _"hello, world" }'

podría imprimir bonjour, monde en Francia. Consulta https://www.gnu.org/software/gawk/manual/html_node/Internationalization.html#Internationalization para conocer los pasos necesarios para producir y ejecutar un programa AWK localizable.

EXTENSIÓN GNU

Gawk tiene un número excesivo de extensiones a POSIX awk. Se describen en https://www.gnu.org/software/gawk/manual/html_node/POSIX_002fGNU.html. Todas las extensiones se pueden deshabilitar invocando gawk con las opciones --traditional o --posix.

VARIABLES DE ENTORNO

La variable de entorno AWKPATH se puede utilizar para proporcionar una lista de directorios que gawk busca al buscar archivos nombrados a través de las opciones -f, --file, -i y --include, y la directiva @include. Si la búsqueda inicial falla, se vuelve a buscar en el directorio después de agregar .awk al nombre del archivo.

La variable de entorno AWKLIBPATH se puede utilizar para proporcionar una lista de directorios que gawk busca al buscar archivos nombrados a través de las opciones -l y --load.

La variable de entorno GAWK_PERSIST_FILE, si está presente, especifica un archivo que se utilizará como almacenamiento de respaldo para la memoria persistente. Consulta GAWK: Effective AWK Programming para obtener más detalles.

La variable de entorno GAWK_READ_TIMEOUT se puede utilizar para especificar un tiempo de espera en milisegundos para leer la entrada de una terminal, tubería o comunicación bidireccional, incluidos los sockets.

Para la conexión a un host remoto a través de un socket, GAWK_SOCK_RETRIES controla el número de reintentos, y GAWK_MSEC_SLEEP el intervalo entre reintentos. El intervalo está en milisegundos. En sistemas que no admiten usleep(3), el valor se redondea al número entero de segundos.

Si POSIXLY_CORRECT existe en el entorno, entonces gawk se comporta exactamente como si se hubiera especificado --posix en la línea de comandos. Si se ha especificado --lint, gawk emite un mensaje de advertencia al respecto.

ESTADO DE SALIDA

Si la declaración exit se utiliza con un valor, entonces gawk sale con el valor numérico que se le dio.

De lo contrario, si no hubo problemas durante la ejecución, gawk sale con el valor de la constante C EXIT_SUCCESS. Esto suele ser cero.

Si ocurre un error, gawk sale con el valor de la constante C EXIT_FAILURE. Esto suele ser uno.

Si gawk sale debido a un error fatal, el estado de salida es 2. En sistemas no POSIX, este valor puede ser mapeado a EXIT_FAILURE.

EJEMPLOS

Imprimir y ordenar los nombres de inicio de sesión de todos los usuarios:
	BEGIN	{ FS = ":" }
		{ print $1 | "sort" }
Contar líneas en un archivo:
		{ nlines++ }
	END	{ print nlines }
Preceder cada línea con su número en el archivo:
	{ print FNR, $0 }
Concatenar y numerar líneas (una variación del tema):
	{ print NR, $0 }
Ejecutar un comando externo para líneas de datos particulares:
	tail -f access_log |
	awk '/myhome.html/ { system("nmap " $1 ">> logdir/myhome.html") }'
