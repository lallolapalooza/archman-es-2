NOMBRE

gamemodelist - buscar procesos en ejecución con gamemode

SINOPSIS

gamemodelist

DESCRIPCIÓN

gamemodelist buscará en el tiempo de ejecución de todos los procesos que iniciaron GameMode a través de libgamemodeauto.so y los imprimirá con la salida del comando ps(1). Este script auxiliar facilita la localización de los procesos que utilizan GameMode a través de libgamemodeauto.so al solucionar problemas potenciales de juegos.

USO

libgamemodeauto.so.0 se encontrará en los mapas de objetos compartidos de los procesos en ejecución que utilizan GameMode. Ejecute el siguiente comando para imprimir los procesos cargados con libgamemodeauto.so.0. GameMode se puede iniciar de otras maneras, pero este script solo detectará los procesos que utilizan GameMode a través de libgamemodeauto.so.

gamemodelist

SALIDA

La salida es una tabla de procesos del comando ps(1).

PID PPID USER NI PSR COMMAND

Donde cada uno de estos campos se define en el manual de ps(1). Para su conveniencia, aquí hay una definición para cada campo.

COLUMNA DESCRIPCIÓN
PID ID del proceso
PPID ID del proceso padre
USER Nombre de usuario propietario del proceso.
NI Valor de nice. Varía de 19 (más amable) a -20 (no amable con otros), ver nice(1).
PSR Procesador al que está asignado actualmente el proceso. Útil al establecer la afinidad del proceso usando la utilidad taskset(1).
COMMAND Nombre del comando (solo el nombre del ejecutable).

VER TAMBIÉN

gamemodrun(1), nice(1), ps(1), taskset(1).

ACERCA DE

El código fuente de GameMode se puede encontrar en https://github.com/FeralInteractive/gamemode.git
