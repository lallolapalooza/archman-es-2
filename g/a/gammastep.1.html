NOMBRE

gammastep - ajusta la temperatura de color de la pantalla según la hora del día

SINOPSIS

gammastep [-l LAT:LON | -l PROVEEDOR:OPCIONES] [-t DIA:NOCHE] [OPCIONES...]

DESCRIPCIÓN

gammastep ajusta la temperatura de color de tu pantalla según tu entorno. Esto puede ayudar a reducir la fatiga visual o el riesgo de síndrome de fase de sueño retrasada si trabajas frente a la pantalla por la noche.

La temperatura de color se ajusta según la posición del sol. Se establece una temperatura de color diferente durante la noche y el día. Durante el crepúsculo y la madrugada, la temperatura de color transiciona suavemente de la temperatura nocturna a la diurna para permitir que tus ojos se adapten lentamente durante aproximadamente una hora. Por la noche, la temperatura de color debe ajustarse para que coincida con la de las lámparas de tu habitación. Típicamente es una temperatura baja, alrededor de 3000K-4000K (el valor predeterminado es 4500K). Durante el día, la temperatura de color debe coincidir con la luz del exterior, típicamente alrededor de 5500K-6500K (el valor predeterminado es 6500K). La luz tiene una temperatura más alta en un día nublado.

Además de la herramienta de línea de comandos gammastep, la GUI gammastep-indicator proporciona una interfaz alternativa que aparece como un icono de notificación en el entorno de escritorio.

OPCIONES

-h
Muestra el mensaje de ayuda.
-v
Activa la salida detallada.
-V
Muestra la versión del programa.
-b DIA:NOCHE
Brillo de la pantalla a aplicar (entre 0.1 y 1.0).
-c ARCHIVO
Carga la configuración desde el archivo especificado.
-g R:G:B
Corrección gamma adicional a aplicar.
-l LAT:LON
Tu ubicación actual, en grados, dada como números de punto flotante, hacia el norte y hacia el este, con números negativos representando sur y oeste, respectivamente.
-l PROVEEDOR[:OPCIONES]
Selecciona el proveedor para actualizaciones automáticas de ubicación (Usa "-l list" para ver los proveedores disponibles).
-m METODO[:OPCIONES]
Método a usar para ajustar la temperatura de color (Usa "-m list" para ver los métodos disponibles).
-o
Modo de un solo paso (no ajusta continuamente la temperatura de color). Úsalo con la opción -P para borrar las rampas gamma existentes antes de aplicar la nueva temperatura de color.
-O TEMP
Modo manual de un solo paso (establece la temperatura de color). Úsalo con la opción -P para borrar las rampas gamma existentes antes de aplicar la nueva temperatura de color.
-p
Modo de impresión (solo imprime los parámetros y sale).
-P
Restablece las rampas gamma existentes antes de aplicar el nuevo efecto de color.
-x
Modo de restablecimiento (elimina el ajuste de la pantalla).
-r
Desactiva el desvanecimiento entre temperaturas de color.
-t DIA:NOCHE
Temperatura de color a establecer durante el día/noche.

La temperatura neutra es 6500K. Usar este valor no cambiará la temperatura de color de la pantalla. Establecer la temperatura de color a un valor mayor que este resulta en más luz azul, y establecer un valor menor resultará en más luz roja.

Valores predeterminados de temperatura:

Diurna: 6500K, Nocturna: 4500K

ARCHIVO DE CONFIGURACION

Opcionalmente, se puede colocar un archivo de configuración llamado config.ini en ~/.config/gammastep/ (si la variable de entorno XDG_CONFIG_HOME no está definida) o ${XDG_CONFIG_HOME}/gammastep/ (si XDG_CONFIG_HOME está definida). El archivo tiene formato INI estándar. Las opciones generales del programa se colocan bajo el encabezado general, mientras que las opciones para los proveedores de ubicación y los métodos de ajuste se colocan bajo un encabezado con el nombre de ese proveedor o método. Las opciones generales son:

temp-day = entero
Temperatura diurna
temp-night = entero
Temperatura nocturna
fade = 0 o 1
Desactiva o activa el desvanecimiento entre temperaturas de color.
brightness-day = 0.1-1.0
Brillo de la pantalla durante el día
brightness-night = 0.1-1.0
Brillo de la pantalla durante la noche
elevation-high = decimal
La elevación solar en grados para la transición al día
elevation-low = decimal
La elevación solar en grados para la transición a la noche
dawn-time = HH:MM[-HH:MM]
El intervalo de tiempo personalizado para la transición de la noche al día por la mañana. Cuando se especifica, la elevación solar no se usará para determinar el período actual de día/noche. Si esta opción está establecida, también se debe especificar dusk-time.
dusk-time = HH:MM[-HH:MM]
El intervalo de tiempo personalizado para la transición del día a la noche por la tarde. Cuando se especifica, la elevación solar no se usará para determinar el período actual de día/noche. Si esta opción está establecida, también se debe especificar dawn-time.
gamma = R:G:B
Ajuste de gamma a aplicar (día y noche)
gamma-day = R:G:B
Ajuste de gamma a aplicar durante el día
gamma-night = R:G:B
Ajuste de gamma a aplicar durante la noche
adjustment-method = nombre
Selecciona el método de ajuste. Las opciones para el método de ajuste se pueden dar bajo el encabezado del archivo de configuración del mismo nombre.
location-provider = nombre
Selecciona el proveedor de ubicación. Las opciones para el proveedor de ubicación se pueden dar bajo el encabezado del archivo de configuración del mismo nombre.

Las opciones para los proveedores de ubicación y los métodos de ajuste se pueden encontrar en la salida de ayuda de los proveedores y métodos.

EJEMPLO

Ejemplo para Copenhague, Dinamarca:

$ gammastep -l 55.7:12.6 -t 5700:3600 -g 0.8 -m randr -v

Un ejemplo de archivo de configuración con el mismo efecto que el comando anterior:

[general]
temp-day=5700
temp-night=3600
gamma=0.8
adjustment-method=randr
location-provider=manual
[manual]
lat=55.7
lon=12.6
