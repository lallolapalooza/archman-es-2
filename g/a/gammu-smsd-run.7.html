NOMBRE

gammu-smsd-run - documentación para la directiva RunOnReceive

DESCRIPCIÓN

Gammu SMSD puede configurarse mediante la directiva RunOnReceive (ver gammu-smsdrc para más detalles) para ejecutar un programa definido después de recibir cada mensaje. Puede recibir un solo mensaje o varios, que son partes de un mensaje multiparte.

Este parámetro se ejecuta a través del shell, por lo que puede ser necesario escapar algunos caracteres especiales y puede incluir cualquier número de parámetros. Además, se añaden a la línea de comandos los parámetros con los identificadores de los mensajes recibidos. Los identificadores dependen del servicio backend utilizado, típicamente es el ID de la fila insertada para los backends de base de datos o el nombre de archivo para los backends basados en archivos.

Gammu SMSD espera a que el script termine. Si hace algo que consuma tiempo allí, hará que SMSD no reciba nuevos mensajes. Sin embargo, para limitar el daño de esta situación, el tiempo de espera se limita a dos minutos. Después de ese tiempo SMSD continuará con la operación normal y podría ejecutar su script de nuevo.

NOTA:

Todos los descriptores de archivo de entrada y salida se cierran cuando se invoca este programa, por lo que tiene que asegurarse de abrir los archivos por su cuenta.

ENTORNO

Nuevo en la versión 1.28.0.

El programa se ejecuta con un entorno que contiene mucha información sobre el mensaje. Puede usarlo junto con el servicio NULL (ver gammu-smsd-null) para implementar un procesamiento completamente propio de mensajes.

Variables globales

SMS_MESSAGES
Número de mensajes físicos recibidos.
DECODED_PARTS
Número de partes de mensaje decodificadas.
PHONE_ID
Nuevo en la versión 1.38.2.

Valor de PhoneID. Útil al ejecutar múltiples instancias (ver smsd-multi).

Variables por mensaje

Las variables descritas más adelante como SMS_1_... se generan para cada mensaje físico, donde 1 se reemplaza por el número actual de mensaje.

SMS_1_CLASS
Clase del mensaje.
SMS_1_NUMBER
Número del remitente.
SMS_1_TEXT
Texto del mensaje. El texto no está disponible para mensajes binarios de 8 bits.
SMS_1_REFERENCE
Nuevo en la versión 1.38.5.

Referencia del mensaje. Si se recibe el estado de entrega, esta variable contiene el TPMR del mensaje original

Variables por parte

Las variables descritas más adelante como DECODED_1_... se generan para cada parte del mensaje, donde 1 se reemplaza por el número actual de parte. Solo se establecen aquellas variables cuyo contenido está presente en el mensaje.

DECODED_1_TEXT
Texto decodificado del mensaje largo.
DECODED_1_MMS_SENDER
Remitente del mensaje de indicación de MMS.
DECODED_1_MMS_TITLE
título del mensaje de indicación de MMS.
DECODED_1_MMS_ADDRESS
Dirección (URL) del MMS del mensaje de indicación de MMS.

VER TAMBIÉN:

faq-mms-download
DECODED_1_MMS_SIZE
Tamaño del MMS como se especifica en el mensaje de indicación de MMS.

EJEMPLOS

Activar RunOnReceive

Para activar esta funcionalidad necesita establecer RunOnReceive en el gammu-smsdrc.

[smsd]
RunOnReceive = /ruta/al/script.sh

Procesar mensajes del backend de archivos

El siguiente script (si se usa como manejador RunOnReceive ) pasa los datos del mensaje a otro programa. Esto solo funciona con el gammu-smsd-files.

#!/bin/sh
INBOX=/ruta/al/smsd/inbox
PROGRAM=/bin/cat
for ID in "$@" ; do
    $PROGRAM < $INBOX/$ID
done

Invocar comandos basados en el texto del mensaje

El siguiente script (si se usa como manejador RunOnReceive ) ejecuta los programas dados basándose en el texto del mensaje.

#!/bin/sh
# Comprobar el número del remitente
if [ "$SMS_1_NUMBER" != "+420123456789" ] ; then
    exit
fi
# Manejar comandos
case "$SMS_1_TEXT" in
    "DMS A")
        /usr/bin/dms-a
        ;;
    "DMS B")
        /usr/bin/dms-b
        ;;
esac

Pasar el texto del mensaje a un programa

El siguiente script (si se usa como manejador RunOnReceive ) pasa el texto del mensaje y el remitente a un programa externo.

#!/bin/sh
PROGRAM=/bin/echo
for i in `seq $SMS_MESSAGES` ; do
    eval "$PROGRAM \"\${SMS_${i}_NUMBER}\" \"\${SMS_${i}_TEXT}\""
done

Pasar los parámetros de indicación de MMS a un programa externo

El siguiente script (si se usa como manejador RunOnReceive ) escribirá información sobre cada indicación de MMS recibida en el archivo de registro. Simplemente reemplace el comando echo con su propio programa para hacer un procesamiento personalizado.

#!/bin/sh
if [ $DECODED_PARTS -eq 0 ] ; then
    # No hay partes decodificadas, nada que procesar
    exit
fi
if [ "$DECODED_1_MMS_ADDRESS" ] ; then
    echo "$DECODED_1_MMS_ADDRESS" "$DECODED_1_MMS_SENDER" "$DECODED_1_MMS_TITLE" >> /tmp/smsd-mms.log
fi

Procesar el texto del mensaje en Python

El siguiente script (si se usa como manejador RunOnReceive ) escrito en Python concatenará todo el texto del mensaje recibido:

#!/usr/bin/env python
from __future__ import print_function
import os
import sys
numparts = int(os.environ['DECODED_PARTS'])
text = ''
# ¿Hay partes decodificadas?
if numparts == 0:
    text = os.environ['SMS_1_TEXT']
# Obtener todas las partes de texto
else:
    for i in range(1, numparts + 1):
        varname = 'DECODED_%d_TEXT' % i
        if varname in os.environ:
            text = text + os.environ[varname]
# Hacer algo con el texto
print('El número %s ha enviado el texto: %s' % (os.environ['SMS_1_NUMBER'], text))
