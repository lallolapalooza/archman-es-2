gammu-smsd-dbi - backend de gammu-smsd(1) que usa la

capa de abstracción DBI para usar cualquier ba
se de datos admitida como almacenamiento de mensajes

DESCRIPCIÓ

N

El backend DBI almacena todos los datos en cualquier base de datos admitida por libdbi, cuyos parámetros se definen en la configuración (consulte gammu-smsdrc para la descripción de las opciones de configuración)

.

Para la descripción de las tablas, consulte gammu-smsd-tables

.

Este backend está basado en

gammu-smsd-sql.

NOTA

:
El controlador DBI actualment
e no está admitido en Windows
porque la biblioteca libd
bi no admite esta plataforma.

CONFIGURACIÓ

N

Antes de ejecutar gammu-smsd, necesita crear las tablas necesarias en la base de datos. Puede usar los ejemplos proporcionados en las partes de los backends específicos de la base de datos de este manual para

hacerlo.

El archivo de configuración entonces puede

ser: 
[smsd]
service
= sql driver
= DBI_DRIVER ho
st = localhost

ACTUALIZACIÓN DE

TABLAS

La forma más fácil de actualizar la estructura de la base de datos es hacer una copia de seguridad de la antigua y empezar creando una nueva basada en el ejemplo

anterior.

Para actualizar una base de datos existente, puede usar los cambios descritos en smsd-tables-history y luego actualizar manualmente el campo Version en la tabla

gam
mu.
