DESCRIPCIÓ

N

gapplication es una implementación en línea de comandos del lado cliente de la interfaz org.freedesktop.Application tal como se especifica en la Especificación de Entradas de Escritorio de freedesktop.

org.

gapplication se puede usar para iniciar aplicaciones que tengan DBusActivatable establecido a true en sus archivos .desktop y se puede usar para enviar mensajes a instancias en ejecución de otras

aplicaciones.

Es posible que las aplicaciones se refieran a gapplication en la línea Exec de su archivo .desktop para mantener la compatibilidad hacia atrás con implementaciones que no soportan directamente DBusActivatable

.

rte de GLib.

Desde las líneas Exec de un archivo .de

sktop

La interfaz de línea de comandos de gapplication fue diseñada de modo que pudiera usarse directamente desde la línea Exec de un archivo .de

sktop.

Es posible que desee hacer esto para permitir la compatibilidad hacia atrás con implementaciones de la especificación que no entiendan cómo hacer la activación D-Bus, sin tener que instalar un programa utilitario

separado.

Considere el siguiente

ejemplo: 
[Desktop Entry]
Version=1.1
Type=Application
Name=Foo Viewer
DBusActivatab
le=true MimeType=image/x-foo; Exec=gapplication launch org.example.fooview
%F Actions=gallery;create; [Desktop Action gallery] Name=Browse Gallery Ex
ec=gapplication action org.example.fooview gallery [Desktop Action create]
Name=Create a new Foo! Exec=gapplication action org.example.fooview create

Desde un

script

Si instala una aplicación que soporte la activación D-Bus, es posible que aún desee colocar un archivo en /usr/bin para que su programa pueda iniciarse desde una

terminal.

Es posible que este archivo sea un script de shell. El script puede manejar argumentos como --help y --version directamente. También puede analizar otros argumentos de línea de comandos y convertirlos en usos de gapplication para activar la aplicación, abrir archivos o invocar

acciones.

Aquí hay un ejemplo simplificado, como podría instalarse en /usr/bin/fooview

: 
#!/bin/sh
case "$1" in
  --help)
    echo "see ‘man fooview’ for mor
e information" ;; --version) echo "fooview 1.2" ;; -
-gallery) gapplication action org.example.fooview gallery ;;
--create) gapplication action org.example.fooview create ;
; -*) echo "unrecognized commandline argument" exit 1
;; *) gapplication launch org.example.fooview "$@" ;; esac
