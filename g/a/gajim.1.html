NOMBRE

gajim - un cliente de chat XMPP con todas las funciones

SINOPSIS

gajim -h

gajim --start-chat

gajim [-q] [-v] [-w] [-l subsystem=level] [-u name] [-p name] [-s] [-c directory] [--gdebug] [--cprofile]

DESCRIPCIÓN

gajim pretende ser un cliente XMPP fácil de usar y con todas las funciones. Simplemente chatea con tus amigos o familiares, comparte fácilmente fotos y pensamientos o discute las noticias con tus grupos. Chatea de forma segura con cifrado de extremo a extremo a través de OMEMO u OpenPGP. gajim se integra bien con tus otros dispositivos: simplemente continúa las conversaciones en tu dispositivo móvil.

XMPP es el Protocolo Extensible de Mensajería y Presencia, un conjunto de tecnologías abiertas para mensajería instantánea, presencia, chat multiusuario, llamadas de voz y video, colaboración, middleware ligero, sindicación de contenido y enrutamiento generalizado de datos XML. Para más información sobre el protocolo XMPP, consulta https://xmpp.org/about/.

OPCIONES

-h, --help
Mostrar opciones de ayuda
-V, --version
Mostrar la versión de la aplicación
-q, --quiet
Mostrar solo errores críticos
-s, --separate
OBSOLETO: Separar completamente los archivos de perfil (incluso la base de datos de historial y los complementos)
-v, --verbose
Imprimir estrofas XML y otra información de depuración
-u, --user-profile=NAME
Usar un perfil para ejecutar múltiples instancias de Gajim
-p, --profile=NAME
OBSOLETO: Usar el perfil definido en el directorio de configuración
-c, --config-path=PATH
Establecer el directorio de configuración
-l, --loglevel=SUBSYSTEM=LEVEL
Configurar el registro.

SUBSYSTEM p.ej. gajim.c.m

LEVEL (DEBUG, INFO, WARNING, ERROR, CRITICAL)

Ejemplo: gajim.c.m=DEBUG

-w, --warnings
Mostrar todas las advertencias
--gdebug
Establece una variable de entorno para que se impriman los mensajes de depuración de GLib
--cprofile
Perfil de aplicación con cprofile
--start-chat
Iniciar un nuevo chat

ARCHIVOS

$XDG_CACHE_HOME/gajim/
El directorio para datos cacheados.
$XDG_CONFIG_HOME/gajim/
El directorio donde se almacenan la configuración y los ajustes.
$XDG_DATA_HOME/gajim/
El directorio donde se almacenan todos los datos persistentes, p.ej. la base de datos de mensajes.
