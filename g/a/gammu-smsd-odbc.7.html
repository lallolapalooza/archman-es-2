GAMMU-SMSD-ODBC(7) Gammu GAMMU-SMSD-ODBC(7)

NOMBRE

gammu-smsd-odbc - backend de gammu-smsd(1) que utiliza la capa de abstracción ODBC para usar cualquier base de datos compatible como almacenamiento de mensajes

DESCRIPCIÓN

Novedad desde la versión 1.29.92.

El backend ODBC almacena todos los datos en cualquier base de datos soportada por ODBC, cuyos parámetros se definen en la configuración (ver gammu-smsdrc para la descripción de las opciones de configuración).

Para la descripción de las tablas, ver gammu-smsd-tables.

Este backend se basa en gammu-smsd-sql.

CONTROLADORES SOPORTADOS

En Microsoft Windows, Gammu utiliza ODBC nativo; en otras plataformas, se puede usar unixODBC.

LIMITACIONES

Debido a las limitaciones de la interfaz ODBC, Gammu no puede detectar de forma fiable con qué motor SQL está conectado.

En la mayoría de los casos, esto se puede resolver estableciendo la opción SQL al dialecto correcto.

Si eso falla, también puede ajustar las consultas SQL para que funcionen en el servidor SQL utilizado, ver Consultas SQL para más detalles. Aun así, debería establecer SQL al dialecto SQL más parecido.

CONFIGURACIÓN

Antes de ejecutar gammu-smsd, debe crear las tablas necesarias en la base de datos. Puede usar los ejemplos proporcionados en las partes de backends específicos de la base de datos de este manual para hacerlo.

Especifica el nombre del origen de datos (DSN) como Host en gammu-smsdrc. El origen de datos se configura dependiendo de su plataforma.

NOTA:

Recuerde que SMSD podría estar ejecutándose en un contexto diferente al de su usuario (cuenta separada en Linux o como servicio en Windows), por lo que el DSN ODBC debe configurarse como global en este caso (DSN de sistema en Windows o en la configuración global en Linux).

En Microsoft Windows, puede encontrar instrucciones en el sitio web de Microsoft: https://support.microsoft.com/kb/305599

Para unixODBC, esto se documenta en el manual de usuario: http://www.unixodbc.org/doc/UserManual/

CREACIÓN DE TABLAS

Antes de iniciar SMSD, debe crear las tablas que utilizará. Gammu incluye scripts SQL para varias bases de datos para hacerlo:

  • mysql-create
  • pgsql-create
  • sqlite-create

EJEMPLO

Ejemplo de configuración:

[smsd]
service = sql
driver = odbc
host = dsn_de_tu_base_de_datos
sql = variante_sql_a_usar
user = nombre_usuario
password = contraseña
