NOMBRE

gammu-detect - Detección de dispositivos Gammu

Nuevo en la versión 1.28.95.

SINOPSIS

gammu-detect [OPCIONES]

DESCRIPCIÓN

Script para detectar dispositivos disponibles, que podrían ser adecuados para gammu.

NOTA:

Este programa lista todos los dispositivos que podrían ser adecuados, no realiza ninguna sondeo en los propios dispositivos.

Actualmente soporta los siguientes dispositivos:

  • Dispositivos USB usando udev
  • Puertos serie usando udev
  • Puertos serie en Windows
  • Dispositivos Bluetooth usando Bluez

NOTA:

Los dispositivos soportados dependen de la plataforma que estés usando y de las características compiladas. Puedes averiguar qué está realmente compilado ejecutando gammu-detect -v.

Este programa sigue la sintaxis habitual de línea de comandos de GNU, con opciones largas que comienzan con dos guiones (--). A continuación se incluye un resumen de las opciones.

-h, --help
Muestra un resumen de las opciones.
-d, --debug
Muestra la salida de depuración para la detección de dispositivos.
-v, --version
Muestra información de la versión y las características compiladas.
-u, --no-udev
Desactiva el escaneo de udev.
-b, --no-bluez
Desactiva el escaneo usando Bluez.
-w, --no-win32-serial
Desactiva el escaneo de puertos serie de Windows.

SALIDA

La salida de gammu-detect es un archivo de configuración para Gammu (ver gammurc) con una sección de configuración para cada dispositivo que podría ser utilizado con gammu.

NOTA:

Puedes elegir qué sección usar en gammu con gammu -s.

Cuando se invoca como gammu-detect -d, también se listan todos los dispositivos examinados como comentarios en la salida.

EJEMPLO

; Archivo de configuración generado por gammu-detect.
; Por favor, consulta el Manual de Gammu para más información.
[gammu]
device = /dev/ttyACM0
name = Nokia E52
connection = at
[gammu1]
device = /dev/ttyACM1
name = Nokia E52
connection = at
[gammu2]
device = /dev/ttyS0
name = Teléfono en puerto serie 0
connection = at
[gammu3]
device = /dev/ttyS1
name = Teléfono en puerto serie 1
connection = at
[gammu4]
device = /dev/ttyS2
name = Teléfono en puerto serie 2
connection = at
[gammu5]
device = /dev/ttyS3
name = Teléfono en puerto serie 3
connection = at
[gammu6]
device = 5C:57:C8:BB:BB:BB
name = Nokia E52
connection = bluephonet
