NOMBRE

gamemoderun - invoca gamemode en cualquier programa

SINOPSIS

gamemoderun PROGRAMA

DESCRIPCIÓN

GameMode es un demonio/biblioteca combinada para Linux que permite a los juegos solicitar que se aplique temporalmente un conjunto de optimizaciones al sistema operativo anfitrión.

El diseño tiene una clara abstracción entre el demonio anfitrión y la biblioteca (gamemoded y libgamemode), y los cargadores cliente (libgamemodeauto y gamemode_client.h) que permite un uso seguro sin preocuparse de si el demonio está instalado o en ejecución. Este diseño también significa que, si bien la biblioteca anfitriona depende actualmente de systemd para intercambiar mensajes con el demonio, es totalmente posible implementar otros internos que aún funcionen con los mismos clientes.

GameMode fue diseñado principalmente como una solución provisional para problemas con los gobernadores de ahorro de energía o bajo demanda de CPU Intel y AMD, pero está destinado a expandirse más allá de los simples estados del gobernador de CPU, ya que existe una gran cantidad de tareas de automatización que uno podría querer aplicar.

USO

libgamemodeauto.so.0 puede pre-cargarse en cualquier programa para solicitar que gamemoded inicie o finalice el modo, de la siguiente manera:

gamemoderun ./juego

O configurando las opciones de lanzamiento de Steam para un juego:

gamemoderun %command%

La biblioteca se puede pre-cargar manualmente si es necesario:

LD_PRELOAD=$LD_PRELOAD:/usr/\$LIB/libgamemodeauto.so.0 ./juego

CONFIGURACIÓN

Es posible establecer comandos de inicio adicionales para gamemoderun estableciendo la variable de entorno:

GAMEMODERUNEXEC="comando"

Cuando esto está configurado, gamemoderun ejecutará el comando dado por esa variable de entorno, y la línea de comandos pasada a gamemoderun se pasará como argumentos a ese comando. GameMode no se aplicará al comando envoltorio, solo al juego en sí.
