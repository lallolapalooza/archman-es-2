NOMBRE

gammu - Realiza acciones interesantes con tu teléfono móvil o módem.

SINOPSIS

gammu [parámetros] <comando> [opciones]

Los comandos indican la operación que Gammu debe realizar. Pueden especificarse con o sin un prefijo --.

DESCRIPCIÓN

Este programa es una herramienta para teléfonos móviles. Se admiten muchos fabricantes y modelos de teléfonos; para una lista actual, consulta la *Base de datos de teléfonos de Gammu*.

Opciones

Los parámetros antes del comando configuran el comportamiento de gammu:

-c, --config <nombrearchivo>
nombre del archivo de configuración (ver gammurc)
-s, --section <nombreconfig>
sección del archivo de configuración a utilizar, p. ej., 42
-d, --debug <nivel>
nivel de depuración (ver LogFormat en gammurc para valores posibles)
-f, --debug-file <nombrearchivo>
archivo para registrar mensajes de depuración

Comandos SMS y EMS

Enviar mensajes puede parecer un poco complicado al principio. Pero ten paciencia, la línea de comandos se ha escrito para permitir casi cualquier uso. Consulta la sección EJEMPLO para obtener algunas pistas sobre cómo usarla.

También existe la opción de usar gammu-smsd cuando quieras enviar o recibir más mensajes y procesarlos automáticamente.

Introducción a los formatos SMS

Gammu admite muchos formatos de SMS como:

Nokia Smart Messaging
utilizado para imágenes de píxeles monocromáticos, perfiles descargables, logotipos de operador monocromáticos, logotipos de llamadas monocromáticos y tonos de llamada monofónicos
SMS Enlazados
tanto con números de identificación de 8 como de 16 bits en las cabeceras
EMS
este es el formato de SMS utilizado para guardar imágenes monocromáticas, tonos de llamada monofónicos, animaciones, formato de texto y otros
Notificaciones MMS
contiene enlaces desde donde el teléfono debe descargar el MMS
Mensajes de logotipos Alcatel
formato propietario para logotipos

Debes asegurarte de que el teléfono de destino admita el tipo de mensaje que deseas enviar. De lo contrario, el teléfono no podrá mostrarlo o incluso podría bloquearse, ya que el firmware del teléfono no esperaba esa posibilidad.

Codificación de caracteres en el texto SMS

El texto de los SMS se puede codificar de dos maneras:

Alfabeto predeterminado GSM

Con el *Alfabeto predeterminado GSM*, puedes encajar como máximo 160 caracteres en un solo SMS (Gammu no admite la compresión de dichos textos según los estándares GSM, pero no es una gran limitación, ya que no hay teléfonos que los admitan), pero provienen de un conjunto limitado:

  • todos los caracteres latinos en minúsculas y mayúsculas
  • todos los dígitos
  • algunos griegos
  • algunos otros nacionales
  • algunos símbolos como @ ¡ " # & / ( ) % * + = - , . : ; < > ?
  • y algunos más

Unicode

Con *Unicode*, un solo SMS puede contener como máximo 70 caracteres, pero estos pueden ser cualquier carácter, incluidos todos los nacionales y especiales.

ADVERTENCIA:

Ten en cuenta que algunos teléfonos más antiguos podrían tener problemas para mostrar dicho mensaje.

Conversión

Gammu intenta hacer lo mejor para manejar caracteres no ASCII en tu mensaje. Todo se maneja internamente en Unicode (la entrada se convierte según la configuración de tu locale) y, en caso de que el mensaje utilice Unicode, el texto se proporcionará como tal al mensaje.

Si el mensaje se va a enviar en el Alfabeto Predeterminado GSM, Gammu intentará convertir todos los caracteres para mantener el mensaje legible. Gammu admite codificación multibyte para algunos caracteres en el Alfabeto Predeterminado GSM (esto i

necesario para ^ { } \ [ ] ~ |). Los caracteres que no están presentes en el Alfabeto Predeterminado GSM se transliteran a su equivalente ASCII más cercano (se eliminan los acentos). Los caracteres restantes desconocidos se reemplazan por un signo de interrogación.

De manera similar a gammu getallsms. La diferencia es que une todos los SMS concatenados.
getsms carpeta inicio [fin]
Obtiene SMS.

Las ubicaciones se numeran a partir de 1.

La carpeta 0 significa que el SMS se está leyendo de la memoria "plana" (todos los SMS de todas las carpetas tienen números únicos). A veces es emulado por Gammu. Puede usarlo con todos los teléfonos.

Otras carpetas como 1, 2, etc. corresponden a las carpetas del teléfono como Bandeja de entrada, Bandeja de salida, etc., y cada SMS tiene un número único en su carpeta. El nombre de las carpetas puede depender de su teléfono (lo más común es 1="Bandeja de entrada", 2="Bandeja de salida", etc.). Este método no es compatible con todos los teléfonos (por ejemplo, no es compatible con Nokia 3310, 5110, 6110). Si funciona con su teléfono, use gammu getsmsfolders para obtener la lista de carpetas.

Comandos en modo lote

batch [archivo]
Inicia Gammu en modo lote. En este modo puedes ejecutar varios comandos cada uno en una línea. Las líneas que comienzan con # se tratan como comentarios.

Por defecto, los comandos se leen de la entrada estándar, pero puedes especificar opcionalmente un archivo del que se leerán (el caso especial - significa entrada estándar).

Comandos de configuración

searchphone [-debug]
Intenta buscar un teléfono conectado.

ADVERTENCIA:

Ten en cuenta que esto puede llevar mucho tiempo, pero si no tienes idea de cómo configurar la conexión del teléfono, esta es una forma conveniente de encontrar una configuración que funcione para Gammu.
install [-minimal]
Instala la aplicación para la conexión configurada actualmente al teléfono.

Puedes configurar la ruta de búsqueda de los archivos de instalación mediante DataPath.

El parámetro -minimal fuerza la instalación solo de la aplicación sin posibles bibliotecas de soporte, esto puede ser útil para actualizaciones.
