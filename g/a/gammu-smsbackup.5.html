NOMBRE

gammu-smsbackup - Formato de archivo de copia de seguridad de SMS de gammu(1).

El formato de copia de seguridad de SMS es un archivo de texto codificado en la codificación actual de la plataforma donde se ejecuta Gammu.

Este archivo utiliza la sintaxis de archivo ini, ver ini.

SECCIONES

El archivo consta de secciones, cuyo nombre comienza con SMSBackup. Al crear el archivo de copia de seguridad, se agregan tres dígitos a este texto definiendo el orden. Al leer la copia de seguridad, se ignora cualquier parte después del texto SMSBackup y todo lo que comienza con esto se procesa. Por lo tanto, también puede dar el nombre de sección SMSBackupFoo y se procesará.

El número de mensajes en el archivo de copia de seguridad está limitado actualmente por GSM_BACKUP_MAX_SMS (100000 en el momento de escribir este documento).

Sección SMSBackup

Cada sección interpreta un mensaje SMS físico (por ejemplo, una parte de mensaje en el caso de mensajes multipartes).

Texto decodificado

Para las copias de seguridad de SMS creadas por Gammu, hay un texto decodificado como comentario justo después del nombre de la sección:

[SMSBackup001]
; Este es el texto del mensaje

El texto se puede dividir en varias líneas si es demasiado largo o si el mensaje original incluía saltos de línea.

NOTA:

Esta es la forma más fácil de obtener el texto del mensaje, pero también la menos confiable, ya que se almacena en los comentarios del archivo.

Variables

Las siguientes variables se pueden definir para cada SMS:

SMSC
Representación textual del número SMSC, no utilizada por Gammu si existe SMSCUnicode.
SMSCUnicode
Cadena UCS-2 codificada en hexadecimal con el número SMSC.
Class
Clase del mensaje.
Sent
Marca de tiempo de cuando se envió el mensaje.
PDU
Tipo de mensaje, uno de:
  • Deliver - mensaje recibido
  • Submit - mensaje para enviar
  • Status_Report - mensaje para enviar con informe de entrega
DateTime
Marca de tiempo del mensaje (enviado o recibido).
RejectDuplicates
Si el receptor debe rechazar duplicados.
ReplaceMessage
ID del mensaje a reemplazar.
MessageReference
Número de referencia del mensaje generado por la red.
State
Estado del mensaje:
  • Read
  • UnRead
  • Sent
  • UnSent
Number
Número del destinatario.
Name
Nombre del mensaje.
Length
Longitud del texto del mensaje.
Coding
Codificación del mensaje:
  • 8bit - mensaje binario
  • Default - codificación GSM, hasta 160 caracteres en el mensaje
  • Unicode - codificación Unicode, hasta 70 caracteres en el mensaje
Text00 ... TextNN
Partes numeradas del contenido del mensaje.
Folder
ID de la carpeta donde se guardó el mensaje.
UDH
Cabecera definida por el usuario del mensaje.

[SMSBackup000]

#
