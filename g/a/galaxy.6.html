NOMBRE

galaxy - dibuja galaxias giratorias

SINOPSIS

galaxy [--display host:display.screen] [--foreground color] [--background color] [--window] [--root] [--window-id número][--mono] [--install] [--visual visual] [--ncolors entero] [--delay microsegundos] [--cycles entero] [--count entero] [--size entero] [--tracks] [--no-tracks] [--spin] [--no-spin]

[--fps]

DESCRIPCIÓN

El programa galaxy dibuja galaxias giratorias.

OPCIONES

galaxy acepta las siguientes opciones:

--window
Dibuja en una ventana de nueva creación. Esta es la opción por defecto.
--root
Dibuja en la ventana raíz.
--window-id número
Dibuja en la ventana especificada.
--mono
Si se está en una pantalla de color, simula que se está en una pantalla monocromática.
--install
Instala un mapa de colores privado para la ventana.
--visual visual
Especifica qué visual usar. Los valores legales son el nombre de una clase visual, o el número de id (decimal o hexadecimal) de un visual específico.
--ncolors entero
Cuántos colores se deben usar (si es posible). Por defecto 64. Los colores utilizados ciclan a través del matiz, haciendo N paradas alrededor de la rueda de colores.
--cycles entero
--count entero
--size entero
--tracks
--no-tracks
--spin
--no-spin
--fps
Muestra la tasa de fotogramas actual y la carga de la CPU.

ENTORNO

DISPLAY
para obtener el host y el número de pantalla por defecto.
XENVIRONMENT
para obtener el nombre de un archivo de recursos que anula los recursos globales almacenados en la propiedad RESOURCE_MANAGER.
XSCREENSAVER_WINDOW
El ID de ventana a usar con --root.
