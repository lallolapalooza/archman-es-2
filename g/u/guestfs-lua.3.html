guestfs-lua(3) Soporte de virtualización guestfs-lua(3)

NOMBRE

guestfs-lua - Cómo usar libguestfs desde Lua

SINOPSIS

local G = require "guestfs"
g = G.create ()
g:add_drive ("test.img", { format = "raw", readonly = true })
g:launch ()
devices = g:list_devices ()
g:close ()

DESCRIPCIÓN

Esta página manual documenta cómo llamar a libguestfs desde el lenguaje de programación Lua. Esta página solo documenta las diferencias con la API de C y proporciona algunos ejemplos. Si no está familiarizado con el uso de libguestfs, también necesita leer guestfs(3).

REQUIRIENDO EL MÓDULO

"require "guestfs"" devuelve el módulo, por lo que tiene que asignarlo a una variable local. El uso típico es:

local G = require "guestfs"

(puede usar cualquier nombre que desee en lugar de "G", pero en los ejemplos de esta página del manual siempre usamos "G").

ABRIENDO Y CERRANDO EL MANEJADOR

Para crear un nuevo manejador, llame a:

g = G.create ()

También puede usar los argumentos opcionales:

g = G.create { environment = 0, close_on_exit = 0 }

para establecer los indicadores "GUESTFS_CREATE_NO_ENVIRONMENT" y/o "GUESTFS_CREATE_NO_CLOSE_ON_EXIT".

El manejador será cerrado por el recolector de basura, pero también puede cerrarlo explícitamente haciendo:

g:close ()

LLAMANDO A MÉTODOS

Use la convención ordinaria de Lua para llamar a métodos en el manejador. Por ejemplo:

g:set_verbose (true)

FUNCIONES CON ARGUMENTOS OPCIONALES

Para funciones que toman argumentos opcionales, los primeros argumentos son los no opcionales. El argumento final opcional es una tabla que proporciona los argumentos opcionales.

g:add_drive ("test.img")

o:

g:add_drive ("test.img", { format = "raw", readonly = true })

VALORES DE 64 BITS

Actualmente, los valores de 64 bits deben pasarse como cadenas y se devuelven como cadenas. Esto se debe a que Lua de 32 bits no puede manejar correctamente enteros de 64 bits. Esperamos encontrar una mejor solución más adelante.

ERRORES

La mayoría (pero no todos) de los errores se convierten en objetos (es decir, tablas) que contienen los siguientes campos:

msg
El mensaje de error (correspondiente a "guestfs_last_error" en guestfs(3)).
code
El "errno" (correspondiente a "guestfs_last_errno" en guestfs(3)).

Estos objetos también tienen funciones "__tostring" adjuntas, por lo que puede usar "tostring" (o la conversión implícita) para convertirlos en cadenas imprimibles.

Tenga en cuenta que la biblioteca también lanza algunos errores como cadenas simples. Puede que necesite comprobar el tipo.

EVENTOS

Los eventos pueden registrarse llamando a "set_event_callback":

eh = g:set_event_callback (cb, "close")

o para registrar un único callback para múltiples eventos, haga que el segundo argumento sea una lista:

eh = g:set_event_callback (cb, { "appliance", "library", "trace" })

Una lista de todos los tipos de eventos válidos (cadenas) está en la variable global "G.event_all".

El callback ("cb") es llamado con los siguientes parámetros:

function cb (g, event, eh, flags, buf, array)
  -- g es el manejador de guestfs
  -- event es una cadena que es el nombre del evento que se activó
  -- flags es siempre cero
  -- buf es el búfer de datos (ej. mensaje de registro, etc.)
  -- array es el array de enteros de 64 bits (ej. estado de la barra de progreso, etc.)
  ...
end

También puede eliminar un callback usando el identificador de evento ("eh") que se devolvió cuando registró el callback:

g:delete_event_callback (eh)

EJEMPLO 1: CREAR UNA IMAGEN DE DISCO

-- Ejemplo que muestra cómo crear una imagen de disco.

local G = require "guestfs"

local output = "disk.img"

local g = G.create ()

-- Crear una imagen de disco dispersa en formato raw, de 512 MB de tamaño.
file = io.open (output, "w")
file:seek ("set", 512 * 1024 * 1024)
file:write (' ')
file:close ()

-- Establecer el indicador de traza para poder ver cada llamada a libguestfs.
g:set_trace (true)

-- Adjuntar la imagen de disco a libguestfs.
g:add_drive (output, { format = "raw", readonly = false })

-- Ejecutar el backend de libguestfs.
g:launch ()

-- Obtener la lista de dispositivos. Como solo añadimos una unidad
-- arriba, esperamos que esta lista contenga un solo
-- elemento.
devices = g:list_devices ()
if table.getn (devices) ~= 1 then
   error "expected a single device from list-devices"
end

-- Particionar el disco como una sola partición MBR.
g:part_disk (devices[1], "mbr")

-- Obtener la lista de particiones. Esperamos un solo elemento, que es
-- la partición que acabamos de crear.
partitions = g:list_partitions ()
if table.getn (partitions) ~= 1 then
   error "expected a single partition from list-partitions"
end

-- Crear un sistema de archivos en la partición.
g:mkfs ("ext4", partitions[1])

-- Ahora montar el sistema de archivos para poder añadir archivos.
g:mount (partitions[1], "/")

-- Crear algunos archivos y directorios.
g:touch ("/empty")
message = "Hello, world\n"
g:write ("/hello", message)
g:mkdir ("/foo")

-- Este sube el archivo local /etc/resolv.conf a la
-- imagen de disco.
g:upload ("/etc/resolv.conf", "/foo/resolv.conf")

-- Como escribimos en el disco y queremos detectar errores de
-- escritura, llame a g:shutdown. No necesita hacer esto:
-- g:close lo hará implícitamente.
g:shutdown ()

-- Tenga en cuenta también que los manejadores se cierran automáticamente si son
-- recogidos por el recolector de basura. Solo necesita llamar a close
-- si quiere cerrar el manejador inmediatamente.
g:close ()

EJEMPLO 2: INSPECCIONAR UNA IMAGEN DE DISCO DE MÁQUINA VIRTUAL

-- Ejemplo que muestra cómo inspeccionar un disco de máquina virtual.

local G = require "guestfs"

if table.getn (arg) == 1 then
   disk = arg[1]
else
   error ("usage: inspect_vm disk.img")
end

local g = G.create ()

-- Adjuntar la imagen de disco de solo lectura a libguestfs.
g:add_drive (disk, { -- format:"raw"
                     readonly = true })

-- Ejecutar el backend de libguestfs.
g:launch ()

-- Pedir a libguestfs que inspeccione los sistemas operativos.
local roots = g:inspect_os ()
if table.getn (roots) == 0 then
   error ("inspect_vm: no operating systems found")
end

for _, root in ipairs (roots) do
   print ("Root device: ", root)

   -- Imprimir información básica sobre el sistema operativo.
   print ("  Product name: ", g:inspect_get_product_name (root))
   print ("  Version:      ",
          g:inspect_get_major_version (root),
          g:inspect_get_minor_version (root))
   print ("  Type:         ", g:inspect_get_type (root))
   print ("  Distro:       ", g:inspect_get_distro (root))

   -- Montar los discos, como guestfish -i.
   --
   -- Ordenar las claves por longitud, la más corta primero, para que
   -- terminemos montando los sistemas de archivos en el orden correcto.
   mps = g:inspect_get_mountpoints (root)
   table.sort (mps,
               function (a, b)
                  return string.len (a) < string.len (b)
               end)
   for mp,dev in pairs (mps) do
      pcall (function () g:mount_ro (dev, mp) end)
   end

   -- Si el archivo /etc/issue.net existe, imprimir hasta 3 líneas.
   filename = "/etc/issue.net"
   if g:is_file (filename) then
      print ("--- ", filename, &quot; ---")
      lines = g:head_n (3, filename)
      for _, line in ipairs (lines) do
         print (line)
      end
   end

   -- Desmontar todo.
   g:umount_all ()
end
