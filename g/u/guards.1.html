NOMBRE

guards - selecciona de una lista de archivos protegidos por condiciones

SINOPSIS

guards [--prefijo=dir] [--ruta=dir1:dir2:...] [--predeterminado=<0|1>] [--comprobar|--listar] [--invertir-coincidencia] [--con-guards] [--config=<archivo>] simbolo ...

DESCRIPCIÓN

El script lee un archivo de configuración que puede contener las llamadas guards, nombres de archivo y comentarios, y escribe los nombres de archivo que cumplen todas las guards a la salida estándar. El script toma una lista de símbolos como argumentos. Cada línea en el archivo de configuración se procesa por separado. Las líneas pueden comenzar con un número de guards. Las siguientes guards están definidas:

+xxx Incluye el/los archivo(s) en esta línea si el símbolo xxx está definido.

-xxx Excluye el/los archivo(s) en esta línea si el símbolo xxx está definido.

+!xxx Incluye el/los archivo(s) en esta línea si el símbolo xxx no está definido.

-!xxx Excluye el/los archivo(s) en esta línea si el símbolo xxx no está definido.

- Excluye este archivo. Se utiliza para evitar mensajes de --comprobar espurios.

Las guards se procesan de izquierda a derecha. La última guard que coincide determina si el archivo se incluye. Si no se especifica ninguna guard, la configuración --predeterminado determina si el archivo se incluye.

Si no se especifica ningún archivo de configuración, el script lee de la entrada estándar.

La opción --comprobar se utiliza para comparar el archivo de especificación con el sistema de archivos. Si se hacen referencias a archivos en la especificación que no existen, o si los archivos no están incluidos en el archivo de especificación, se imprimen advertencias. La opción --ruta se puede utilizar para especificar qué directorio(s) escanear. Múltiples directorios están separados por dos puntos (":"). La opción --prefijo especifica la ubicación de los archivos. Alternativamente, se puede usar la sintaxis --ruta=@<archivo> para especificar un archivo del cual se leerán los nombres de archivo.

Utilice --listar para listar todos los archivos independientemente de cualquier regla. Utilice --invertir-coincidencia para listar solo los parches excluidos. Utilice --con-guards para incluir también todas las reglas de inclusión y exclusión.
