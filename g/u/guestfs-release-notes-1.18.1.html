NOMBRE

guestfs-release-notes - Notas de la versión de libguestfs

NOTAS DE LA VERSIÓN PARA LIBGUESTFS 1.18

Estas notas de la versión solo cubren las diferencias desde la última división de ramas estable/desarrollo (1.16.0). Para los registros de cambios detallados, consulte el repositorio git o el archivo ChangeLog distribuido en el tarball.

Nuevas características

Herramientas virt

- virt-sysprep ha sido reescrito y ampliado (gracias a Wanlong Gao)
  http://libguestfs.org/virt-sysprep.1.html
- virt-sparsify --zero es una nueva opción que pone a cero la
  partición o el sistema de archivos especificado
- virt-sparsify ahora puede esparsificar de forma segura particiones
  de intercambio (swap) de Linux
- virt-sparsify corregido para que limpie después de ^C
  http://libguestfs.org/virt-sparsify.1.html
- se proporciona una nueva herramienta 'libguestfs-make-fixed-appliance'
  para construir appliances fijos que pueden copiarse a otras máquinas
  que no tienen soporte de febootstrap
  http://libguestfs.org/libguestfs-make-fixed-appliance.1.html
- virt-filesystems ahora muestra los padres (contenedores) de los
  dispositivos MD y de los grupos de volúmenes
- virt-alignment-scan, ejecutado sin argumentos, muestra la
  información de alineación de todos los dominios de libvirt
- virt-df y virt-alignment-scan mostrarán información de todos los
  huéspedes incluso cuando un disco sea inaccesible
- nueva opción --scratch de virt-rescue para crear discos temporales
  https://rwmj.wordpress.com/2012/04/26/virt-rescue-scratch/#content
- virt-make-fs ahora puede usarse para crear btrfs
- virt-edit conserva los permisos, UID, GID y el contexto SELinux
  al editar archivos
- guestfish pasa el evento de cierre por stdout y remoto correctamente
- nueva opción '--pipe-error' de guestfish que le permite detectar
  errores en comandos de tubería
- los comodines de guestfish ahora expanden nombres de dispositivos
- los caracteres coma y dos puntos en nombres de archivo ahora son
  manejados correctamente por todas las herramientas virt

inspección

- añadido soporte para Fedora 17+
- añadido soporte para FreeDOS
- añadido soporte para Buildroot y Cirros
- la inspección ahora es compatible con huéspedes Windows que han
  sido procesados con sysprep (gracias a Grant Williamson).

API

- añadido soporte amplio para btrfs, incluyendo la adición de
  múltiples dispositivos, fsck, instantáneas (gracias a Wanlong Gao)
- la nueva API 'mount-local' trae el soporte FUSE directamente al
  núcleo de la API de libguestfs
  https://rwmj.wordpress.com/2012/05/14/tip-using-mount-local-api-from-c/#content
- nueva página del manual: guestfs-performance(1), que contiene
  consejos de ajuste de rendimiento
  http://libguestfs.org/guestfs-performance.1.html
- nueva página del manual: guestfs-faq(1), Preguntas Frecuentes
  http://libguestfs.org/guestfs-faq.1.html
- ENOTSUP (de guestfs_last_errno) ahora se devuelve para las APIs
  que no están soportadas

ejemplos

- ejemplo 'copy_over' que muestra cómo copiar entre dos manejadores
- el programa 'display_icon' muestra el icono asociado con un huésped
- ejemplo 'mount_local.c' que muestra cómo usar la API mount-local

Seguridad

(no se encontraron ni corrigieron problemas de seguridad en esta versión)

Nuevas APIs

btrfs-device-add: Añade dispositivos a un sistema de archivos btrfs.
btrfs-device-delete: Elimina dispositivos de un sistema de archivos btrfs.
btrfs-filesystem-sync: Sincroniza un sistema de archivos btrfs.
btrfs-filesystem-balance: Balancea un sistema de archivos btrfs.
btrfs-fsck: Comprueba un sistema de archivos btrfs.
btrfs-set-seeding: Habilita o deshabilita el seeding.
btrfs-subvolume-create: Crea un subvolumen btrfs.
btrfs-subvolume-delete: Elimina un subvolumen btrfs.
btrfs-subvolume-list: Lista subvolúmenes btrfs.
btrfs-subvolume-set-default: Establece el subvolumen btrfs predeterminado.
btrfs-subvolume-snapshot: Crea una instantánea btrfs escribible.
get-e2attrs: Lista los atributos de archivo ext2 de un archivo.
get-e2generation: Obtiene la generación ext2 de un archivo.
isoinfo, isoinfo-device: Obtiene información del encabezado de archivos ISO.
llz: Lista archivos con información SELinux.
lvcreate-free: Crea un volumen lógico LVM en el % de espacio libre restante.
md-stat: Devuelve los dispositivos subyacentes de un dispositivo MD.
mkfs-brtfs: Crea un sistema de archivos btrfs, con todas las variables configurables.
mount-local, mount-local-run, umount-local: Soporte FUSE en la API.
ntfsclone-in, ntfsclone-out: Guarda, restaura NTFS desde una copia de seguridad.
ntfsfix: Corrige errores comunes y fuerza a Windows a comprobar NTFS.
set-e2attrs: Establece o limpia los atributos de archivo ext2 de un archivo.
set-e2generation: Establece la generación ext2 de un archivo.
set-label: Interfaz unificada para establecer la etiqueta del sistema de archivos.
vgmeta: Obtiene los metadatos del grupo de volúmenes.
wipefs: Borra las firmas del sistema de archivos de un dispositivo.
zero-free-space: Pone a cero el espacio libre en un sistema de archivos.

Internos

- El subdirectorio debian/ ha sido eliminado. Recomendamos que use
  los paquetes oficiales de Debian hechos por Hilko Bengen.
  http://people.debian.org/~bengen/libguestfs/
  http://packages.debian.org/search?keywords=libguestfs
- O_CLOEXEC / SOCK_CLOEXEC ahora se usa para casi todos los
  descriptores de archivo que abre la biblioteca.
- posix_fadvise se llama al leer o escribir secuencialmente archivos
  grandes.
- cerrar todos los descriptores de archivo y eliminar todos los
  manejadores de señales en el proceso de recuperación
- se han corregido múltiples advertencias de gcc y errores de Coverity;
  también se han corregido muchos errores de strict-overflow
- use ./configure --enable-valgrind-daemon para usar valgrind en el
  demonio; se han corregido muchos errores
- use ./configure --with-qemu-options para pasar opciones extra a qemu
- el demonio ahora tiene un tipo de búfer de cadenas ampliable
  (DECLARE_STRINGSBUF)
- el archivo de cabecera <guestfs.h> funciona con C++ y tenemos una
  prueba de regresión para esto
- múltiples APIs que solo deberían llamarse en el estado CONFIG ahora
  dan un error si no se llaman en él
- .gitignore corregido para usar rutas absolutas
- los enlaces gobject han sido ampliados, incluyendo el mapeo de
  eventos de libguestfs a señales gobject (gracias a Matt Booth)
- la documentación de gobject se genera correctamente (gracias a Matt Booth)
- los archivos de cabecera de gobject ahora viven en un subdirectorio
- la prueba CompareWithString en el generador ahora funciona
- los tipos de campo de estructura FUInt32, FUInt64 ahora usan el
  tipo XDR correcto
- las pruebas OCaml ahora se ejecutan en código de bytes y nativo.
- se usa java -Xlint:all, y todas las advertencias han sido corregidas
- bmptopng, wrestool (etc) faltantes o con fallo ya no imprimen
  mensajes de advertencia
- ruby: Use RbConfig en lugar de Config.
- PYTHONPATH es establecido por el script ./run.
- la construcción del appliance ahora es segura para hilos.
- el appliance ahora usa 'ip' en lugar de los comandos 'ifconfig'
  y 'netstat'
- varias correcciones para que las compilaciones paralelas funcionen
  correctamente
- guestfish --listen ahora limpia correctamente
- el estado BUSY ha sido eliminado
- gettextize ha sido eliminado, reemplazado por un simple Makefile.am
- el soporte de gettext ahora cubre virt-resize, virt-sparsify y
  virt-sysprep
- mejor soporte para la arquitectura arm
