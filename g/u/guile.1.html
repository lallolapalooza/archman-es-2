NOMBRE

guile - El Lenguaje de Extensión del Proyecto GNU

SINOPSIS

guile [-L DIRECTORIO] [-l ARCHIVO] [-e FUNCIÓN] [\] [-c EXPR] [-s SCRIPT] [--] [SCRIPT [ARGUMENTOS para SCRIPT]]

Solo se enumeran aquí las opciones más útiles; véase más abajo para el resto.

DESCRIPCIÓN

GNU Guile es una implementación del lenguaje de programación Scheme. Extiende los estándares del lenguaje R5RS y R6RS, proporcionando características adicionales necesarias para el uso en el mundo real.

Guile funciona bien para uso interactivo, scripting básico y extensión de aplicaciones más grandes, así como para desarrollo de aplicaciones Scheme independientes.

El ejecutable guile en sí proporciona un compilador y entorno de ejecución interactivo independiente para programas Scheme, tanto para uso interactivo como para ejecutar scripts o programas Scheme.

Esta página del manual solo proporciona instrucciones breves para invocar guile desde la línea de comandos. Por favor, consulte la documentación de info de Guile para más información (escriba info "(guile)Invoking Guile" en un prompt de comando).

OPCIONES

-L DIRECTORIO
Añade DIRECTORIO al principio de la ruta de carga de módulos de Guile.
-l ARCHIVO
Carga código fuente Scheme desde ARCHIVO.
-e FUNCIÓN
Después de leer SCRIPT, aplica FUNCIÓN a los argumentos de la línea de comandos. Tenga en cuenta que FUNCIÓN se evalúa, por lo que, por ejemplo, (@ (mi-modulo) mi-proc) es válido aquí.
\
El "interruptor meta", utilizado para solucionar limitaciones en scripts #!. Consulte "The Meta Switch" en la documentación de texinfo para más detalles.
--
Detiene el procesamiento de argumentos y comienza guile en modo interactivo.
-c EXPR
Detiene el procesamiento de argumentos y evalúa EXPR como una expresión Scheme.
-s ARCHIVO-DE-SCRIPT
Carga código fuente Scheme desde ARCHIVO-DE-SCRIPT y lo ejecuta como un script. Tenga en cuenta que en muchos casos no es necesario usar -s; se puede invocar guile simplemente como guile ARCHIVO-DE-SCRIPT ARG...
-ds
Lleva a cabo -s SCRIPT en este punto de la secuencia de opciones. Tenga en cuenta que este argumento debe usarse junto con -s.
--debug
Inicia guile con la máquina virtual de depuración. Por defecto, la depuración está activada cuando guile se invoca interactivamente; está desactivada de lo contrario.
--no-debug
Inicia guile sin la máquina virtual de depuración, incluso si guile se está ejecutando interactivamente.
--auto-compile
Compila archivos fuente automáticamente (comportamiento por defecto).
--no-auto-compile
Deshabilita la compilación automática de archivos fuente.
--listen[=P]
Escucha en un puerto o socket para conexiones remotas de REPL. Consulte el manual para más detalles.
--use-srfi=N,M...
Carga las extensiones SRFI N, M, etc. Por ejemplo, --use-srfi=8,13.
-x EXTENSIÓN
Añade EXTENSIÓN a la lista de extensiones de carga de guile.
-h, --help
Describe las opciones de la línea de comandos y sale.
-v, --version
Muestra la versión de guile y sale.
-q
En modo interactivo, suprime la carga del archivo de inicialización del usuario, ~/.guile.

AMBIENTE

GUILE_LOAD_PATH
Si $GUILE_LOAD_PATH está configurado antes de que guile se inicie, su valor se utiliza para aumentar la ruta de búsqueda de archivos Scheme al cargar. Debe ser una lista de directorios separados por dos puntos, que se antepondrán a la ruta de carga predeterminada %load-path.
GUILE_LOAD_COMPILED_PATH
Si $GUILE_LOAD_COMPILED_PATH está configurado antes de que guile se inicie, su valor se utiliza para aumentar la ruta de búsqueda de archivos Scheme compilados (.go) al cargar. Debe ser una lista de directorios separados por dos puntos, que se antepondrán a la ruta de compilación predeterminada %load-compiled-path.

ARCHIVOS

~/.guile
Un script Guile que se ejecuta antes de cualquier otro procesamiento. Por ejemplo, el siguiente .guile activa la interfaz readline de guile:
(use-modules (ice-9 readline))
(activate-readline)

VER TAMBIÉN

La documentación completa para Guile se mantiene como un manual de Texinfo. Si los programas info y guile están instalados correctamente en su sitio, el comando

info guile

debería darle acceso al manual completo.

http://www.schemers.org proporciona una introducción general al lenguaje Scheme.

REPORTAR ERRORES

Hay una lista de correo, bug-guile@gnu.org, para reportar errores y correcciones de Guile. Pero antes de reportar algo como un error, por favor intente asegurarse de que realmente es un error, no una incomprensión o una característica deliberada. Le pedimos que lea la sección ``Reporting Bugs'' en el manual de referencia de Guile (o sistema Info) para obtener pistas sobre cómo y cuándo reportar errores. Además, incluya el número de versión de Guile que está ejecutando en cada reporte de error que envíe. Los errores tienden a corregirse si se pueden aislar, por lo que le interesa reportarlos de una manera que se puedan reproducir fácilmente.
