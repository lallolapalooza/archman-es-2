NOMBRE

guvcview - Visor UVC basado en GTK+

SINOPSIS

guvcview

DESCRIPCIÓN

Guvcview es una aplicación para capturar y ver video desde dispositivos soportados por la interfaz linux kernel video4linux2.

USO

guvcview [opciones...]

OPCIONES

-h,--help
Imprimir ayuda
-v,--version
Imprimir versión
-w,--verbosity=NIVEL
Establecer nivel de verbosidad (def: 0)
-d,--device=DISPOSITIVO_DE_AUDIO
Establecer nombre del dispositivo (def: /dev/video0)
-c,--capture=MÉTODO
Establecer método de captura [read | mmap (def)]
-b,--disable_libv4l2
desactivar llamadas a libv4l2
-x,--resolution=ANCHOxALTO
Solicitar resolución (ej. 640x480)
-f,--format=FOURCC
Solicitar formato (ej. MJPG)
-F,--fps=NUM_FPS/DENOM_FPS
Solicitar fps (ej. 25; 7/3; ...)
-r,--render=API_DE_RENDERIZADO
Seleccionar API de renderizado (ej. none; sdl; sfml)
-m,--render_window=BANDERA_VENTANA_RENDERIZADO
Establecer banderas de ventana de renderizado (ej. none; full; max; ANCHOxALTO)
-a,--audio=API_DE_AUDIO
Seleccionar API de audio (ej. none; port; pulse)
-k,--audio_device=dispositivo_audio
Seleccionar índice de dispositivo de audio para la api seleccionada (0..N)
-g,--gui=API_GUI
Seleccionar API GUI (ej. none; gtk3; qt6)
-o,--audio_codec=codecAudio
Códec de audio [pcm mp2 mp3 aac ac3 vorb]
-u,--video_codec=codec
Códec de video [raw mjpg mpeg flv1 wmv1 mpg2 mp43
dx50 h264 vp80 theo]
-p,--profile=nombre_archivo
Cargar perfil de control
-j,--video=nombre_archivo
nombre de archivo para video capturado)
-i,--image=nombre_archivo
nombre de archivo para imagen capturada)
-y,--video_timer=TIEMPO_EN_SEG
Tiempo (doble) en segundos para captura de video)
-t,--photo_timer=TIEMPO_EN_SEG
Tiempo (doble) en segundos entre fotos capturadas)
-n,--photo_total=total
Número total de fotos capturadas)
-e,--exit_on_term
Salir de la aplicación después de que termine la captura de video o imagen
-z,--control_panel
Iniciar en modo panel de control
