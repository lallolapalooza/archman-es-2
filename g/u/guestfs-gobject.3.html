guestfs-gobject(3) Soporte de Virtualización guestfs-gobject(3)

NOMBRE

guestfs-gobject - Cómo usar libguestfs con los enlaces GObject

OBSOLETO

Estos enlaces están obsoletos y se eliminarán en libguestfs 1.58.

SINOPSIS

Desde Javascript usando gjs:

const Guestfs = imports.gi.Guestfs;
var g = new Guestfs.Session();
g.add_drive('disk.img', null);
g.launch();
g.close();

DESCRIPCIÓN

Esta página del manual documenta cómo llamar a libguestfs usando los enlaces GObject, especialmente desde Javascript.

Tenga en cuenta que los enlaces GObject tienen problemas para manejar valores de 64 bits. No debe utilizar los enlaces GObject si existen enlaces nativos para su lenguaje. Por ejemplo, para usar libguestfs desde Python, se le recomienda encarecidamente que utilice los enlaces nativos de Python en su lugar (consulte guestfs-python(3)).

Esta página solo documenta las diferencias con la API de C y proporciona algunos ejemplos. Si no está familiarizado con el uso de libguestfs, también debe leer guestfs(3).

JAVASCRIPT

Usando gjs, puede escribir un archivo ".js" que contenga:

const Guestfs = imports.gi.Guestfs;
var g = new Guestfs.Session();
g.add_drive('disk.img', null);
g.launch();
g.close();

y luego ejecutarlo usando:

gjs program.js

Para obtener una lista de errores contra libguestfs, utilice este enlace: https://bugzilla.redhat.com/buglist.cgi?component=libguestfs&product=Virtualization+Tools

Al informar de un error, proporcione:

  • La versión de libguestfs.
  • De dónde obtuvo libguestfs (p. ej., qué distribución de Linux, compilado desde la fuente, etc.).
  • Describa el error con precisión y proporcione una forma de reproducirlo.
  • Ejecute libguestfs-test-tool(1) y pegue la salida completa y sin editar en el informe de error.
