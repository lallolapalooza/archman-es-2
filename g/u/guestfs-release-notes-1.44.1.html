guestfs-release-notes - Notas de versión de libguestfs

NOTAS DE VERSIÓN PARA LIBGUESTFS 1.44

Enlaces de lenguaje

Se ha eliminado el soporte para Python 2. La versión mínima requerida de Python es 3.6.

Los enlaces de Python ya no usan el método obsoleto "PyEval_ThreadsInitialized".

Los enlaces de Python ahora incluyen anotaciones de tipo (Sam Eiderman).

Los enlaces de Erlang ahora usan libei en lugar de liberl_interface (Sergei Golovan).

Herramientas

virt-get-kernel(1) ahora puede encontrar kernels sin comprimir (Pino Toscano).

virt-sysprep(1) ahora regenera el almacén de certificados del invitado cuando se elimina un certificado del invitado (Pino Toscano).

virt-sysprep(1) ahora puede eliminar archivos de inscripción de IPA y keytabs de Kerberos (Pino Toscano, Christian Heimes y François Cami).

API

Nuevas APIs

"cryptsetup-open" y "cryptsetup-close" reemplazan "luks-open", luks-open-ro y luks-close. Las nuevas APIs agregan soporte para el cifrado BitLocker.

Otros cambios en la API

"lvm-canonical-lv" ya no produce un mensaje de error ruidoso cuando se llama con un parámetro que no es LV.

Cambios en la compilación

Los programas C que usan libguestfs ahora se pueden compilar contra el directorio de compilación:

../libguestfs/run ./configure
../libguestfs/run make

Los componentes de OCaml ahora se enlazan correctamente cuando se compilan en un directorio diferente al del código fuente (Geoff Toole).

Se admite GCC LTO.

Se utiliza Weblate para la localización en lugar de Zanata (Pino Toscano).

Las dependencias de guestfsd ya no están codificadas en el código, sino que se generan a partir del binario compilado, lo que garantiza que no se desfasarán en el futuro (Hilko Bengen).

Internos

lib/guestfs.h se movió a include/guestfs.h en el código fuente. Esto no es un cambio visible externamente, pero afectó a muchos lugares dentro del sistema de compilación.

Errores corregidos

https://bugzilla.redhat.com/1811539
El comando virt-diff no funciona en la imagen de Windows 2019.
https://bugzilla.redhat.com/1384241
El comando tar-in no permite restaurar las capacidades de archivo.
