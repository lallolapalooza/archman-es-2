NOMBRE

guestfs-release-notes - Notas de lanzamiento de libguestfs

NOTAS DE LANZAMIENTO PARA LIBGUESTFS 1.26

Estas notas de lanzamiento solo cubren las diferencias con la división anterior de la rama estable/desarrollo (1.24.0). Para obtener registros de cambios detallados, consulte el repositorio de git o el archivo ChangeLog distribuido en el tarball.

NUEVAS FUNCIONALIDADES

Herramientas

virt-customize(1) es una nueva herramienta para personalizar imágenes de disco de máquinas virtuales. Permite instalar paquetes, editar archivos de configuración, ejecutar scripts, establecer contraseñas, etc. virt-builder(1) y virt-sysprep(1) utilizan virt-customize, y las opciones de línea de comandos en todas estas herramientas son ahora idénticas.

virt-diff(1) es una nueva herramienta para mostrar las diferencias entre los sistemas de archivos de dos máquinas virtuales. Es útil principalmente para mostrar qué archivos han sido modificados entre instantáneas.

virt-builder(1) ha sido mejorado considerablemente. Hay muchas más formas de personalizar la máquina virtual. Puede extraer plantillas de varios repositorios. Una implementación interna optimizada de xzcat acelera la descompresión de plantillas. Virt-builder utiliza un planificador optimizador para elegir la forma más rápida de construir la VM. Ahora es más fácil usar virt-builder desde otros programas. Se ha agregado soporte de internacionalización a los metadatos. Remarcado de SELinux más eficiente de archivos. Puede construir invitados para múltiples arquitecturas. Los mensajes de error han sido mejorados. (Pino Toscano)

virt-sparsify(1) tiene una nueva opción --in-place. Esto compacta una imagen in situ (sin copiarla) y es también mucho más rápido. (Mucha ayuda proporcionada por Paolo Bonzini)

virt-sysprep(1) puede eliminar y borrar archivos bajo control del usuario. Puede bloquear cuentas de usuario o establecer contraseñas aleatorias en las cuentas. Puede eliminar más archivos de registro. Puede dar de baja a un invitado del Administrador de Suscripciones de Red Hat. Nueva forma flexible de habilitar y deshabilitar operaciones. (Wanlong Gao, Pino Toscano)

virt-win-reg(1) le permite usar URIs para especificar imágenes de disco remotas.

virt-format(1) ahora puede pasar el espacio adicional que recupera al host.

guestfish(1) tiene variables de entorno adicionales para dar un control fino sobre el prompt "><fs>". Guestfish lee su archivo de configuración (raramente utilizado) en un orden diferente ahora para que las configuraciones locales anulen las configuraciones globales. (Pino Toscano)

virt-make-fs(1) fue reescrito en C, pero no ha cambiado en términos de funcionalidad y uso de línea de comandos.

Bindings de idioma

Los bindings de OCaml tienen un nuevo módulo "Guestfs.Errno", utilizado para verificar el número de error devuelto por "Guestfs.last_errno".

Las pruebas de PHP ahora funcionan. (Pino Toscano)

Inspección

La inspección puede reconocer imágenes live de Debian.

Arquitecturas

ARMv7 (32 bits) ahora soporta aceleración KVM.

Aarch64 (ARM 64 bits) está soportado, pero la parte de la aplicación aún no funciona.

El soporte PPC64 ha sido corregido y mejorado.

SEGURIDAD

Denegación de servicio al inspeccionar imágenes de disco con volúmenes btrfs corruptos
Era posible bloquear libguestfs (y programas que usan libguestfs como biblioteca) presentando una imagen de disco que contenía un volumen btrfs corrupto.

Esto fue causado por una desreferencia de puntero NULL que provocó una denegación de servicio, y no se cree que sea explotable más allá.

Consulte el commit d70ceb4cbea165c960710576efac5a5716055486 para la corrección. Esta corrección está incluida en las ramas estables de libguestfs ≥ 1.26.0, ≥ 1.24.6 y ≥ 1.22.8, y también en RHEL ≥ 7.0. Versiones anteriores de libguestfs no son vulnerables.

Mejor generación de contraseñas de root aleatorias y semillas aleatorias
Al generar contraseñas de root aleatorias y semillas aleatorias, se corrigieron dos errores que posiblemente estaban relacionados con la seguridad. En primer lugar, ya no leemos bytes excesivos de /dev/urandom (la mayoría de los cuales se tiraban). En segundo lugar, cambiamos el código para evitar el sesgo de módulo. No se creía que estos problemas fueran explotables. (Ambos cambios sugeridos por Edwin Török)

API

Los parámetros GUID ahora se validan cuando se pasan a las llamadas API, mientras que anteriormente se podía pasar cualquier cadena. (Pino Toscano)

Nuevas APIs

"guestfs_add_drive_opts": nuevo parámetro "discard"
El nuevo parámetro "discard" permite un control detallado sobre el soporte de descarte/trim para un disco específico. Esto permite que el archivo host se vuelva más disperso (o aprovisionado de forma fina) cuando elimina archivos o emite la llamada API "guestfs_fstrim".
"guestfs_add_domain": nuevos parámetros: "cachemode", "discard"
Estos parámetros se pasan cuando se agregan los discos del dominio.
"guestfs_blkdiscard"
Descarta todos los bloques en un dispositivo guestfs. Combinado con el parámetro "discard" anterior, esto hace que el archivo host sea disperso.
"guestfs_blkdiscardzeroes"
Prueba si los bloques descartados se leen como ceros.
"guestfs_compare_*"
"guestfs_copy_*"
Para cada struct devuelto a través de la API, libguestfs ahora genera funciones "guestfs_compare_*" y "guestfs_copy_*" para permitirle comparar y copiar structs.
"guestfs_copy_attributes"
Copia atributos (como permisos, xattrs, propiedad) de un archivo a otro. (Pino Toscano)
"guestfs_disk_create"
Una API flexible para crear imágenes de disco vacías desde cero. Esto evita la necesidad de llamar a programas externos como qemu-img(1).
"guestfs_get_backend_settings"
"guestfs_set_backend_settings"
Configuraciones por backend (también se pueden establecer a través de la variable de entorno "LIBGUESTFS_BACKEND_SETTINGS"). El uso principal para esto es forzar el modo TCG en los backends basados en qemu, por ejemplo: 
export LIBGUESTFS_BACKEND=direct
export LIBGUESTFS_BACKEND_SETTINGS=force_tcg
"guestfs_part_get_name"
Obtiene la etiqueta o nombre de una partición (para imágenes de disco GPT).

CAMBIOS DE COMPILACIÓN

Los siguientes paquetes adicionales son necesarios para compilar libguestfs 1.26:

supermin ≥ 5
Se requiere la versión 5 de Supermin para compilar esta versión de libguestfs.
flex, bison
Virt-builder ahora utiliza un analizador real para analizar su archivo de metadatos, por lo que estas herramientas son necesarias.
xz
Esta es ahora una dependencia de compilación requerida, mientras que anteriormente era (en teoría) opcional.

INTERNOS

La extracción de mensajes PO fue reescrita para ser más robusta. (Pino Toscano)

"podwrapper" da un error si no se encuentra el patrón de argumento --insert o --verbatim.

Libguestfs ahora pasa la opción qemu -enable-fips para habilitar FIPS, si qemu lo soporta.

"./configure --without-qemu" se puede usar si no desea especificar un hipervisor predeterminado.

Las superposiciones de copia en escritura [COW], utilizadas por ejemplo para unidades de solo lectura, ahora se crean a través de una API de backend interna (".create_cow_overlay").

NAME

guestfs-release-notes-1.26.1 - notes for libguestfs 1.26.1

RELEASE NOTES FOR LIBGUESTFS 1.26

This is a bugfix release.

New features

  • guestfish --monitor command.

Bug fixes

  • Fixed crash in virt-rescue when reading from a corrupt or inaccessible filesystem.
  • Fixed a bug where virt-resize could fail to allocate enough space for the new partition table.
  • Fixed a bug where virt-sparsify could corrupt guest images if they contained sparse files.
  • Fixed a bug where guestfish could deadlock when running multiple commands in parallel.

Other changes

  • Updated documentation for all commands.
  • Added new tests to improve code coverage.

SEE ALSO

guestfish(1), virt-rescue(1), virt-resize(1), virt-sparsify(1), libguestfs(3).
