NOTAS DE LA VERSIÓN PARA LIBGUESTFS 1.

10

Estas notas de la versión solo cubren las diferencias desde la anterior división de ramas estable/dev (1.8.0). Para registros de cambios detallados, consulte el repositorio git, o el archivo ChangeLog distribuido en el

tarball.

Nuevas

características 
- libguestfs y las herramientas pueden usarse contra máquinas virtuales en
  vivo. Vea las opciones 'guestfish --live' y 'guestmount --live', y (para
  la interfaz de bajo nivel) las nuevas APIs set-attach-method y
  get-attach-method.
- Nuevas herramientas virt:
  virt-copy-in, virt-copy-out, virt-tar-in, virt-tar-out.
- libguestfs puede obtener las asignaciones de letras de unidad para
  huéspedes Windows.
- virt-inspector muestra las asignaciones de letras de unidad para
  huéspedes Windows.
- Las letras de unidad ahora pueden usarse en los programas virt-edit y
  guestfish al operar en huéspedes Windows.
- virt-resize ahora funciona en hosts de 32 bits.
- Ahora puede inspeccionar los discos de instalación y los CD en vivo de
  muchos sistemas operativos diferentes.
- guestfish <! cmd que ejecuta un cmd de shell e inserta el resultado en línea.
- guestfish, guestmount, virt-rescue ahora soportan todas las opciones --ro y
  --rw, y el valor predeterminado para esto puede elegirse mediante un archivo
  de configuración (/etc/libguestfs-tools.conf).
- Nueva API de eventos permite que se registre más d
e un callback para cada evento, hace posible llamar a la API desde otros lenguajes, y permite que casi todos los mensajes de registro, depuración y seguimiento se redirijan desde stderr. - Mayor cumplimiento de FHS para archivos temporales, incluyendo el uso de /var/tmp para archivos en caché grandes que deberían sobrevivir a un reinicio (en lugar de /tmp). - La opción -m de guestfish, guestmount permite pasar opciones de montaje al sistema de archivos subyacente. - mkfs-opts permite especificar características del sistema de archivos. - Manejo más inteligente de puntos de montaje, permitiendo que los comandos mkmountpoint, mount y umount-all funcionen juntos correctamente. - Los mensajes de seguimiento tienen un prefijo con una cadena distintiva, permitiendo que se puedan 'greppear' fácilmente de la salida de depuración. - guestfs_launch (comando 'run' de guestfish) ahora produce mensajes de progreso (una barra de progreso de guestfish) si tarda más de 5 segundos en ejecutarse. - Varios comandos de larga duración donde no podemos estimar el tiempo hasta la finalización genera
n eventos de progreso en "modo pulso". La barra de progreso en guestfish se ha actualizado para mostrar estos. - Publicar nuevo código de ejemplo en: C, Perl, Python, OCaml, Ruby. - Nuevo programa de ejemplo virt-dhcp-address. - Los bindings de Java y Ruby han sido mejorados enormemente. - Perl incluye una forma de obtener el errno del último error. - Los bindings de Python ahora son compatibles con rpyc (gracias a Erez Shinan). - Transifex se está utilizando ahora para gestionar las traducciones. http://www.transifex.net/projects/p/libguestfs/ - La inspección ahora soporta Red Hat Desktop, distribuciones Slackware. - La inspección ya no falla para huéspedes Windows que tienen dos o más discos. - La inspección ahora puede distinguir entre Windows 2008 Server y Windows 7. - La inspección puede detectar aplicaciones de 32 bits instaladas en Windows de 64 bits, ejecutándose en el emulador WOW64. - Una serie de correcciones de protocolo ha corregido el antiguo bug RHBZ#576879 que solía causar errores durante el comando de subida que perdían la sincronización del protocolo. - ¡Nuevo logotipo!
