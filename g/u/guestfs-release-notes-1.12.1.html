NOMBRE

guestfs-release-notes - Notas de la versión de libguestfs

NOTAS DE LA VERSIÓN PARA LIBGUESTFS 1.12

Estas notas de la versión solo cubren las diferencias desde la división estable/des anterior (1.10.0). Para registros de cambios detallados, consulte el repositorio git, o el archivo ChangeLog distribuido en el tarball.

Nuevas características

guestfish

- Las cadenas de guestfish pueden usar secuencias de escape,
  por ejemplo: ><fs> write /foo "line 1\nline 2\n"
- El comando write-append de guestfish se puede usar para añadir a archivos.
- Las subidas y descargas de archivos de larga duración se pueden cancelar a través de
  la API o presionando ^C en guestfish.
- Nuevo comando "display" de guestfish para mostrar archivos gráficos
  dentro de los huéspedes.
- En guestfish, el autocompletado ahora funciona en dispositivos /dev/mapper.

virt-inspector

- La API de inspección puede obtener un icono o logotipo para ciertos huéspedes.
- virt-inspector incluye el logotipo y el nombre de host para ciertos huéspedes.
- virt-inspector ahora puede obtener los números de versión y lanzamiento para paquetes
  RPM.
- CentOS y Scientific Linux ahora son tratados como distribuciones separadas por
  la API de inspección.

virt-resize

- virt-resize ahora puede manejar btrfs.
- La nueva opción --ntfsresize-force de virt-resize permite que las máquinas virtuales de Windows sean
  redimensionadas varias veces.

otras herramientas virt

- guestfish, guestmount, virt-cat, virt-df, virt-edit, virt-filesystems,
  virt-inspector, virt-ls y virt-rescue ahora le permiten usar
  la opción "-d UUID" para especificar un huésped por UUID. Esto los hace más
  robustos para usar desde otros programas.
- La opción -lR de virt-ls permite la iteración compleja de archivos y el análisis de huéspedes.
- virt-win-reg soporta HKEY_USERS\<SID> y HKEY_USERS\<nombredeusuario>.
- La nueva opción --unsafe-printable-strings de virt-win-reg permite que cadenas imprimibles
  se muestren en la salida (de forma insegura: lea la documentación
  antes de usarla).
- virt-edit ha sido reescrito en C.

API y enlaces de lenguaje

- Java ahora es completamente soportado.
  Vea http://libguestfs.org/guestfs-java.3.html
- JRuby es soportado a través de los enlaces de Java.
- guestfs_close ahora aparece en los mensajes de traza.
- El enlace de Python añade el método explícito g.close().
- Los programas en Python ahora pueden usar la nueva API de eventos.
- El GIL de Python se libera durante las llamadas a libguestfs, permitiendo que los programas
  multihilo de Python funcionen correctamente.
- 9pfs (sistemas de archivos Plan 9 exportados desde el host) ahora son soportados.
- Añada -DGUESTFS_WARN_DEPRECATED=1 para advertir sobre el uso de funciones de API
  obsoletas en programas en C.
- Nueva página del manual guestfs-recipes(1) con recetas.
- mkfs-opts ahora puede establecer el tamaño de inodo y el tamaño de sector en los sistemas de archivos
  creados (gracias a Nikita Menkovich).
- guestfs_last_errno ahora es accesible desde OCaml (como g#last_errno ()).

Seguridad

- optargs_bitmask se verifica incluso para llamadas que no tienen argumentos
  opcionales. Esto cierra una posible explotación en el demonio desde
  llamadores no confiables.

Nuevas APIs

btrfs-filesystem-resize, get-pgroup, inspect-get-icon, is-zero,
is-zero-device, list-9p, list-dm-devices, mount-9p, ntfsresize-opts,
set-pgroup, write-append

Internos

- Coverity (una herramienta de análisis estático) se ejecutó en todo el código base y
  se realizaron muchas correcciones.
- El generador puede manejar funciones que devuelven RBufferOut y tienen
  argumentos opcionales.
- Compatible con Perl 5.14.
- Compatible con gcc 4.6.
- Realiza comprobaciones de seguridad en QEMU.
- Las pruebas de la API en C ahora pueden probar completamente las llamadas que tienen argumentos
  opcionales.
- Use ./configure --enable-install-daemon para instalar /usr/sbin/guestfsd.
- El directorio po-docs ahora cubre todas las páginas del manual.
- stderr del proceso qemu ahora es capturado por el subsistema de eventos.

Errores corregidos

- 602997 part-get-bootable da un resultado incorrecto con una disposición de particiones no ordenada
- 661280 virt-rescue: pánico al apagar: "/sbin/reboot: No such file or directory"
- 700369 qemu-system-x86_64 dice 'KVM not supported for this target'
- 705200 el intento de guestmount resulta en acceso denegado
- 714981 'list-filesystems' no conoce los sistemas de archivos virtio 9p o detecta montajes existentes
- 717786 los enlaces de python de libguestfs deberían tener una llamada close explícita
- 721275 virt-resize en F16 debería soportar btrfs
