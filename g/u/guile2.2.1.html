GUILE(1) GNU Guile 2.2 GUILE(1)

NOMBRE

guile - El Lenguaje de Extensión del Proyecto GNU

SINOPSIS

guile [-L DIRECTORIO] [-l ARCHIVO] [-e FUNCIÓN] [\] [-c EXPRESIÓN] [-s SCRIPT] [--] [SCRIPT [ARGUMENTOS para SCRIPT]]

Solo se enumeran aquí las opciones más útiles; consulte más abajo el resto.

DESCRIPCIÓN

GNU Guile es una implementación del lenguaje de programación Scheme. Extiende los estándares de lenguaje R5RS y R6RS, proporcionando características adicionales necesarias para el uso en el mundo real.

Guile funciona bien para uso interactivo, scripting básico y extensión de aplicaciones más grandes, así como para el desarrollo de aplicaciones Scheme independientes.

El ejecutable guile en sí mismo proporciona un compilador y tiempo de ejecución interactivo independiente para programas Scheme, tanto para uso interactivo como para ejecutar scripts o programas Scheme.

Esta página del manual solo proporciona instrucciones breves para invocar guile desde la línea de comandos. Consulte la documentación de info de Guile para obtener más información (escriba info "(guile)Invoking Guile" en un símbolo del sistema).

OPCIONES

-L DIRECTORIO
Agrega DIRECTORIO al principio de la ruta de carga de módulos de Guile.
-l ARCHIVO
Carga código fuente Scheme desde ARCHIVO.
-e FUNCIÓN
Después de leer SCRIPT, aplica FUNCIÓN a los argumentos de la línea de comandos. Tenga en cuenta que FUNCIÓN se evalúa, por lo que, por ejemplo, (@ (mi-modulo) mi-proc) es válido aquí.
\
El "interruptor meta", utilizado para solucionar limitaciones en scripts #!. Consulte "The Meta Switch" en la documentación de texinfo para obtener más detalles.
--
Detiene el procesamiento de argumentos y comienza guile en modo interactivo.
-c EXPRESIÓN
Detiene el procesamiento de argumentos y evalúa EXPRESIÓN como una expresión Scheme.
-s ARCHIVO-SCRIPT
Carga código fuente Scheme desde ARCHIVO-SCRIPT y lo ejecuta como un script. Tenga en cuenta que en muchos casos no es necesario usar -s; se puede invocar guile simplemente como guile ARCHIVO-SCRIPT ARG...
-ds
Lleva a cabo -s SCRIPT en este punto de la secuencia de opciones. Tenga en cuenta que este argumento debe usarse junto con -s.
--debug
Inicia guile con la máquina virtual de depuración. Por defecto, la depuración está activada cuando guile se invoca interactivamente; está desactivada de lo contrario.
--no-debug
Inicia guile sin la máquina virtual de depuración, incluso si guile se está ejecutando interactivamente.
--auto-compile
Compila archivos fuente automáticamente (comportamiento por defecto).
--no-auto-compile
Desactiva la compilación automática de archivos fuente.
--listen[=P]
Escucha en un puerto o socket para conexiones REPL remotas. Consulte el manual para obtener más detalles.
--use-srfi=N,M...
Carga las extensiones SRFI N, M, etc. Por ejemplo, --use-srfi=8,13.
-x EXTENSIÓN
Agrega EXTENSIÓN a la lista de extensiones de carga de guile.
-h, --help
Describe las opciones de la línea de comandos y sale.
-v, --version
Muestra la versión de guile y sale.
-q
En modo interactivo, suprime la carga del archivo de inicialización del usuario, ~/.guile.

AMBIENTE

GUILE_LOAD_PATH
Si $GUILE_LOAD_PATH está configurado antes de que se inicie guile, su valor se utiliza para aumentar la ruta de búsqueda de archivos Scheme al cargar. Debe ser una lista de directorios separada por dos puntos, que se antepondrán a la ruta de carga predeterminada %load-path.
GUILE_LOAD_COMPILED_PATH
Si $GUILE_LOAD_COMPILED_PATH está configurado antes de que se inicie guile, su valor se utiliza para aumentar la ruta de búsqueda de archivos Scheme compilados (.go) al cargar. Debe ser una lista de directorios separada por dos puntos, que se antepondrán a la ruta de carga compilada predeterminada %load-compiled-path.

ARCHIVOS

~/.guile
Un script de Guile que se ejecuta antes de cualquier otro procesamiento. Por ejemplo, el siguiente .guile activa la interfaz readline de guile:
(use-modules (ice-9 readline))
(activate-readline)

VER TAMBIÉN

La documentación completa de Guile se mantiene como un manual de Texinfo. Si los programas info y guile están correctamente instalados en su sitio, el comando

info guile

debería darle acceso al manual completo.

http://www.schemers.org proporciona una introducción general al lenguaje Scheme.

INFORMAR ERRORES

Existe una lista de correo, bug-guile@gnu.org, para informar sobre errores y correcciones de Guile. Pero antes de informar algo como un error, intente asegurarse de que realmente sea un error, no una incomprensión o una característica deliberada. Le pedimos que lea la sección "Reporting Bugs" en el manual de referencia de Guile (o en el sistema Info) para obtener pistas sobre cómo y cuándo informar errores. Además, incluya el número de versión de Guile que está ejecutando en cada informe de error que envíe. Los errores tienden a corregirse si se pueden aislar, por lo que le interesa informarlos de una manera que se pueda reproducir fácilmente.
