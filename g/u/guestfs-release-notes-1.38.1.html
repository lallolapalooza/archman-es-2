Novedades

El script "make check-root" ahora puede ejecutarse con privilegios de root. Esto es útil para pruebas que requieren privilegios de root (análogo a "make check-slow").

La comprobación de "__attribute__((cleanup))" en tiempo de ejecución de "./configure" ahora funciona en casos de compilación cruzada (Yann E. Morin).

Los archivos "AUTHORS" y "p2v/about-authors.c" ahora se generan desde un único lugar.

Se puede usar GnuPG v1 o v2.

Se puede usar "./configure --with-guestfs-path" para establecer "LIBGUESTFS_PATH" por defecto. Además, la forma en que se busca la ruta ha cambiado ligeramente para que todos los tipos de appliances se busquen en cada elemento de la ruta por separado (Pavel Butsykin).

Se ha eliminado "GUESTFSD_EXT_CMD", que se utilizaba para marcar comandos externos en el demonio. Originalmente lo usaban las compilaciones de SUSE, pero hace tiempo que no lo utilizan.

La salida de "./configure" ahora se agrupa visualmente bajo encabezados relacionados con lo que está haciendo, lo que facilita mucho su lectura (Pino Toscano).

Las dependencias de OCaml ahora se generan a partir de un único script en lugar de varios fragmentos de Makefile casi idénticos.

Se puede usar "./configure --with-distro=ID" para anular la detección automática de la distribución de Linux en tiempo de compilación (Pino Toscano).

Se soporta (pero no es obligatorio) QEMU ≥ 2.10. Esto añade bloqueo obligatorio a los discos y libguestfs lo desactiva en ciertas circunstancias cuando se sabe que es seguro (Lars Seipel, Peter Krempa, Daniel Berrangé, Pino Toscano, Fam Zheng, Yongkui Guo, Václav Kadlčík).

Internos

La mayor parte del código común se ha movido al subdirectorio common/, con el código común de OCaml en los directorios common/ml* (por ejemplo, common/visit y common/mlvisit contienen la biblioteca de visitantes en C y OCaml respectivamente). Se ha eliminado el directorio mllib y se ha reemplazado por common/mltools.

Ahora existe una vinculación ligera de OCaml para PCRE, ver common/mlpcre. El uso de la biblioteca "Str" de OCaml se ha reemplazado en su mayor parte por PCRE.

Se han añadido más llamadas a "udev_settle" para mejorar la estabilidad del código de particiones (Dawid Zamirski).

Se ejecuta "udev_settle" con la opción --exit-if-exists, lo que mejora la velocidad de este comando (Pavel Butsykin).

Detecta nuevas ubicaciones de major(3), minor(3), makedev(3).

Las acciones ahora se pueden marcar como obsoletas sin sugerir un reemplazo, para APIs como "guestfs_wait_ready" que simplemente deberían eliminarse del código del cliente.

Se utiliza el envoltorio de gnulib "set_nonblocking_flag" en lugar de llamar a fcntl(2) con "O_NONBLOCK" (Eric Blake). De manera similar se utiliza "set_cloexec_flag".

Se corrige una fuga de memoria en la versión XFS de "guestfs_vfs_minimum_size" (Pino Toscano).

Las comprobaciones de Valgrind ahora se ejecutan en el binario virt-p2v.

Las comillas simples Unicode ("‘’") se utilizan ahora en lugar de '' o `' en todo el código y la documentación. De manera similar se utiliza "’s" en lugar de "'s".

La función "is_zero" se ha reimplementado para una mayor velocidad (Eric Blake).

En el backend directo, se ha eliminado el soporte para virtio-blk. Virtio-scsi es ahora la única forma admitida de añadir discos.

Los tipos de parámetros y valores de retorno de cadena del generador se han racionalizado para que solo haya dos tipos ("String", "StringList") con muchos subtipos, por ejemplo, "FileIn" se convierte en "String (FileIn, ...)".

La imagen del disco del appliance ahora puede estar en formatos distintos de raw (Pavel Butsykin).

Múltiples mejoras en cómo construimos automáticamente plantillas de Debian para virt-builder (Pino Toscano). Se habilita la consola serial para estas plantillas (Florian Klink).

En el demonio, en lugar de hacer una copia privada de lvm.conf y modificarla (por ejemplo, para filtros), se empieza con un archivo vacío ya que LVM entiende que eso significa "todos los valores predeterminados" (Alasdair Kergon, Zdenek Kabelac).

El backend "direct" ahora puede ejecutar consultas QMP contra el binario QEMU, mejorando los tipos de información que podemos detectar. Además, el código para consultar QEMU se ha hecho más robusto para manejar múltiples consultas paralelas de diferentes versiones de QEMU.

Las vinculaciones Augeas de OCaml se incluyen en common/mlaugeas. El plan a largo plazo es eliminar esto y usar el ocaml-augeas del sistema cuando esté más ampliamente disponible en las distribuciones (Pino Toscano).

Todos los módulos de OCaml (archivos "*.ml") ahora deben tener un archivo de interfaz ("*.mli"). Si no exportan nada, la interfaz estará vacía excepto por los comentarios.

Se utilizan ciertas características de OCaml en OCaml ≥ 4.01 en todo el código, incluido el reemplazo de ‘{ field = field }’ por ‘{ field }’.

La utilidad "make-template" de Virt-builder ahora utiliza la opción "virt-install --transient" para que nunca necesitemos limpiar dominios sobrantes después de un fallo. También guarda los kickstarts y los comandos de virt-install, que se confirman en git para referencia futura.

Se crea /dev/shm en el appliance (Nicolas Hicher).

En modo verboso en invitados Fedora, virt-customize ahora usará "dnf --verbose" permitiendo una mejor salida de depuración.

Las clases de entrada y salida de Virt-v2v ahora contienen un método "#precheck" que se utiliza para realizar comprobaciones ambientales antes de que comience la conversión.

Virt-p2v habilita la depuración de miniexpect. Se escribe en stderr (de virt-p2v).

Las comprobaciones de espacio libre de Virt-v2v son más flexibles, especialmente para invitados más pequeños (Pino Toscano).
