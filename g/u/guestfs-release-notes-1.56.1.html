guestfs-release-notes - Notas de la versión de libguestfs

NOTAS DE LA VERSIÓN PARA LIBGUESTFS 1.56

Estas son las notas de la versión para la versión estable de libguestfs 1.56. Esto describe los cambios principales desde la versión 1.54.

Libguestfs 1.56.0 fue lanzado el 11 de junio de 2025.

Inspección

Se añadió soporte para Windows 2025 (gracias a Ming Xie).

Se añadió soporte para TencentOS (Denise Cheng).

La inspección de huéspedes de Ubuntu 22+ que utilizan una configuración dividida de /usr ahora funciona correctamente (gracias a Jaroslav Spanko, Daniel Berrange).

La inspección de huéspedes que tienen puntos de montaje raíz duplicados ahora funciona.

La inspección de huéspedes de SUSE Linux que utilizan instantáneas de btrfs ahora ignora las instantáneas que reflejan el contenido del sistema de archivos raíz (gracias a Ming Xie).

La inspección de huéspedes de SUSE Linux >= 15 ahora devuelve el nombre corto correcto de osinfo (por ejemplo, "sle15") (gracias a Ming Xie).

API

Nuevas APIs "command_out" y "sh_out" que le permiten capturar la salida de comandos del huésped que generan más salida de la que permite el límite del protocolo.

Nueva API "btrfs_scrub_full" que ejecuta un scrub completo de Btrfs, de forma sincrónica. Funciona de manera más similar a fsck para otros sistemas de archivos.

La API "fstrim" ha sido modificada para sortear varios problemas en los kernels upstream y de RHEL 9 relacionados con el soporte de XFS (Eric Sandeen, Dave Chinner).

La API existente "e2fsck" tiene una nueva opción "FORCENO" que permite el uso del indicador de línea de comandos -n .

Enlaces de Lenguajes

Previamente "-L../lib/.libs" estaba incrustado en los enlaces de OCaml distribuidos. Esto ha sido corregido.

Los enlaces GObject han quedado obsoletos y serán eliminados en libguestfs 1.58.

Cambios de Compilación

json-c ahora es requerido. Esto reemplaza a Jansson que era utilizado previamente para analizar archivos de entrada JSON.

OCaml ≥ 4.08 ahora es requerido.

OCaml oUnit ya no es utilizado.

Ahora asumimos que "__attribute__((cleanup))" siempre funciona. Esto requiere gcc o Clang.

Se corrigió la compatibilidad con file(1) ≥ 5.46.

Se corrigió la compatibilidad con Fedora ≥ 42 que fusiona /usr/sbin en /usr/bin.

Se corrigió la compatibilidad con el compilador de Rust más reciente (Jacob Reger).

lex(1), yacc(1) y libmagic (parte de file(1)) no han sido requeridos por libguestfs por mucho tiempo, pero aún eran verificados por el script ./configure . Esto ha sido corregido, ya no son dependencias de compilación (gracias a Mohamed Akram).

Al utilizar "./configure --disable-daemon" ya no requerimos augeas y hivex (gracias a Mohamed Akram).

El soporte para "zfs-fuse" ha sido eliminado. El proyecto no es mantenido upstream (gracias a Paul Bolle, Gwyn Ciesla, Timothée Ravier).

Se corrigió la compatibilidad con GNU gettext 0.25.

Internos

Las pruebas fueron modificadas para usar un conjunto de funciones comunes y eliminar el uso de la extraña macro $TEST_FUNCTIONS , de manera similar a como lo hacemos en nbdkit.

Se corrigió el fallo de dhcpcd en el stub de systemd-resolved (Thomas Wouters).

Se añadió soporte para dhcpcd y sfdisk en Debian (Daniel Gomez).

Imprimir el utsname del kernel en la salida de depuración.

Las APIs heredadas "pvs_full", "vgs_full" y "lvs_full" fueron completamente reescritas en OCaml.

Algunas macros de autoconf obsoletas ya no son utilizadas.

Ya no emitimos una advertencia falsa sobre "BLKDISCARD" al crear un dispositivo de bloque.

Algunas funciones internas de List y String de OCaml que utilizábamos han sido reemplazadas por las de la biblioteca estándar de OCaml, reduciendo el mantenimiento del código.

Si los comandos qemu-img(1) fallan durante la creación de instantáneas, asegurémonos de capturar e imprimir el stderr del comando qemu (Cole Robinson).
