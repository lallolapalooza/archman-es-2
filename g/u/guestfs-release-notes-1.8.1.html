NOTAS DE LA VERSIÓN PARA LIBGUESTFS 1.

8

Estas notas de la versión solo cubren las diferencias con la división estable/desarrollo anterior (1.6.0). Para registros de cambios detallados, consulte el repositorio git o el archivo ChangeLog distribuido en el

tarball.

Nuevas

características 
- Soporte y paquetes para Debian y Ubuntu.
- Compilaciones diarias desde el repositorio git en Debian y Ubuntu para
  reducir el riesgo de regresiones.
- Port a 'pacman' de ArchLinux (gracias a Thomas S Hatch).
- Las siguientes herramientas han sido reescritas en C (originalmente en Perl):
    . virt-cat
    . virt-df
    . virt-inspector
    . virt-ls
    . virt-rescue
- Algunas herramientas en C admiten invitados cifrados automáticamente. Esto
  es admitido en: guestfish, guestmount, virt-cat, virt-inspector, virt-ls.
- Nueva herramienta virt-filesystems (en C) que es un reemplazo para
  virt-list-filesystems y virt-list-partitions, y tiene un conjunto
  superior de funcionalidades de esas herramientas.
- guestfish, guestmount y las herramientas en C usan un análisis de opciones
de línea de comandos unificado, por lo que admiten muchas opciones comunes como '-a disk.img', '-d libvirt-domain', '-x', '-v'. El análisis antiguo de opciones de línea de comandos se conserva por compatibilidad en scripts, etc. - guestfish ya no tiene ninguna dependencia de Perl - Nuevas páginas man que contienen ejemplos de programación: guestfs-examples(3) (C/C++), guestfs-ocaml(3), guestfs-python(3), guestfs-ruby(3). - El modo de traza imprime los valores de retorno de las funciones de la API. - virt-inspector puede listar aplicaciones instaladas en invitados de Windows, junto con una gran cantidad de información sobre esas aplicaciones. - Se añadió soporte para inspeccionar: Linux Mint, Mandriva, FreeBSD. - Opción --rw de guestfish (sin efecto actualmente) para hace
r explícito el acceso de escritura potencialmente peligroso. - guestfish --listen --csh para compatibilidad con csh, tcsh (gracias a Eric Blake). - La primera versión upstream que introdujo cada función de la API ahora está documentada en guestfs(3). - guestfs_last_errno le permite recuperar el errno del demonio, correctamente traducido al sistema operativo local. - Las funciones ahora pueden tener parámetros opcionales. - Las barras de progreso y las notificaciones de progreso ahora pueden ocurrir para los comandos de subida. - El constructor de appliances es más cuidadoso sobre no dejar archivos temporales alrededor en /tmp. - Se añadieron los comandos getfattr/setfattr a virt-rescue. - El archivo ROADMAP cubre la hoja de ruta y los objetivos para futuras versiones.

Segurida

d 
- Nueva sección de SEGURIDAD en la documentación de la API de guestfs(3).
- virt-inspector ya no ejecuta ningún comando del i
nvitado. - El código de inspección es más cuidadoso al evitar archivos muy grandes de los invitados que anteriormente podría
n haber causado una denegación de servicio. - Las llamadas FUSE a guestmount ahora se rastrean cuando se usa guestmount -x.

APIs

- add-drive-opts
- getxattr
- inspect-get-hostname

pect-get-roots - inspect-list-applications - lgetxattr - mkfs-opts

Interno

s 
- Los programas en C ahora se enlazan precisamente solo con las bibliotecas
  que usan.
- Las bibliotecas PCRE, libmagic, hivex y libvirt ahora son completamente
  opcionales para la compilación.
- Se corrigieron múltiples fugas de memoria y fugas de descriptores de archivo.
- Se añadió un envoltorio POD para unificar la generación de páginas man y
  archivos HTML en todos los prog
ramas. - El código fuente incluye imágenes ficticias de invitados de Fedora, Debian, Ubuntu y Windows. - Los enlaces de Ruby tienen la regla 'make install'. - <guestfs.h> ahora es un solo archivo. - <guestfs.h> no requiere encabezados XDR. - La biblioteca xml-light de ocaml ya no es necesaria para compilar (gracias a Maxim Koltsov). - ./configure --disable-[...] para cada enla
ce de lenguaje (gracias a Maxim Koltsov). - Se eliminó el antiguo programa ocaml-viewer (use guestfs-browser en su lugar). - El nuevo tipo de prueba de API C 'InitScratchFS' hace que las pruebas se ejecuten un poco más rápido. - Los paquetes excluidos en el appliance ahora se enumeran en un archivo separado appliance/excludelist.in, y pueden personalizarse por distribución.

corregidos

- 661280 virt-rescue: pánico al apagar: "/sbin/reboot: No suc
h file or directory" - 657499 checksum: tipo de suma de verificación incorrecto causa que el desmontaje falle - 655554 Las rutas
de disco completo no se hacen canónicas por virt-inspector - 654638 openssl actualizado a 1.0.0b libguestfs depende de nombres de ar
chivo exactos - 652796 los enlaces de ruby no se instalan con 'make install', por lo tanto se omiten de la distribución binaria
