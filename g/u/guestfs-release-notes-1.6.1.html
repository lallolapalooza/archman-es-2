NOTAS DE LA VERSIÓN DE LIBGUESTFS 1.

6

Estas notas de la versión solo cubren las diferencias con la anterior división de ramas estable/dev (1.4.0). Para registros de cambios detallados, consulte el repositorio git, o el archivo ChangeLog distribuido en el

tarball.

Nuevas

características 
- Se utiliza un nuevo método para crear y almacenar en caché el appliance.
  Esto mejora enormemente el rendimiento de libguestfs, a menudo por un
  factor de x 4 a x 5.
- Soporte para la inspección de invitados (como virt-inspector) a través de la
  API ordinaria y todos los enlaces de lenguaje. La opción 'guestfish -i' es,
  como efecto secundario, mucho más rápida.
- virt-inspector y la API de inspección principal ahora pueden detectar
  invitados que ejecuten: Fedora, Debian, Ubuntu, Windows, Red Hat Enterprise
  Linux, CentOS, Scientific Linux, Gentoo, Pardus, Arch Linux, MeeGo.
- Soporte para cifrado de disco completo LUKS en invitados.
- Enlaces de PHP.
- Mensajes de progreso (y barras de progreso en guestfish y virt-resize)
  para ciertas operaciones de larga duración.
- virt-df es ahora mucho más eficiente. Utilice '--one-per-guest' para
  restaurar el antiguo comportamiento de aislamiento por invitado.
- Comandos 'copy-in' y 'copy-out' de guestfish para copiar archivos y
  directorios recursivamente dentro y fuera del invitado.
- Comando 'hexedit' de guestfish para realizar ediciones binaria
s en dispositivos y archivos. - Se cambió la sintaxis de guestfish -i para permitir que se especifiquen comandos en la línea de comandos (manteniendo la compatibilidad hacia atrás). - guestfish '-d <domain>' para añadir discos desde dominios de libvirt. - La opción '-N' de guestfish soporta varios nuevos tipos de imágenes de disco preparadas: lvfs : disco con LV formateado con sistema de archivos lv : disco con LV bootroot : boot+root bootrootlv : boot y root en LV - Los comandos 'more' y 'edit' de guestfish ahora funcionan con archivos arbitrarios. - La opción '--echo-keys' de guestfish le permite mostrar las claves/frases de paso mientras las escribe. - guestmount ahora soporta las opciones -a / -d / -i, como guestfish. - Se utiliza virtio-serial para las comunicaciones con el appliance. Esto también tiene un beneficio importante de rendimiento. - Opción '-b' de virt-edit para crear una copia de seguridad de los archivos editados. - Opción '-e' de virt-edit para ediciones no interactivas de archivos. - Capacidad para capturar volcados de memoria (core dumps) de
sde el appliance (gracias a Matthew Booth). - virt-rescue ahora se apaga limpiamente (gracias a Matthew Booth). - virt-rescue ahora tiene una opción --network para habilitar el acceso a la red. - virt-resize ahora puede manejar invitados que usan el formato de tabla de particiones GPT. - virt-resize tiene mejor soporte para reducir el tamaño de los invitados. - virt-resize soporta invitados en formato qcow2. - $TMPDIR se puede usar para anular casi todo el uso de directorios temporales. - Los usuarios de OCaml pueden usar un estilo de codificación OO alternativo, por ejemplo, g#launch () - La API soporta llamadas que toman parámetros opcionales, por ejemplo, $g->add_drive_opts ("disk", readonly => 1); - La salida de trazado ahora escapa y acorta las cadenas grandes (gracias a Matthew Booth). - La sincronización automática (Autosync) ahora está activada por defecto, lo que resulta en un comportamiento más fiable cuando se cierra el manejador. - La opción --uuid de virt-df le permite seguir un dominio a través de la migración y el renombrado. - Traducciones de las páginas del manual.

iento de opciones de guestfish y guestmount está unificado. - Cambios en el protocolo: tamaño del mensaje de error aumentado a 64K se envía errno a la biblioteca - Se añadió 'make bindist' para crear una distribución binar
