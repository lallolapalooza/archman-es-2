guestfs-tools-release-notes - Notas de la versión de guestfs tools

NOTAS DE LA VERSIÓN PARA GUESTFS TOOLS 1.50

Estas son las notas de la versión para la versión estable 1.50 de guestfs tools. Describe los principales cambios desde la 1.48.

Guestfs tools 1.50.0 fue lanzado el 7 de febrero de 2023.

Seguridad

CVE-2022-2211
https://bugzilla.redhat.com/show_bug.cgi?id=2100862

Se encontró un desbordamiento de búfer en la opción --key de varias herramientas de guestfs. Para más información sobre este error de baja severidad, consulte el informe de error anterior (Laszlo Ersek).

Nueva herramienta virt-drivers

Esta nueva herramienta puede examinar una imagen de disco para determinar:

  • Si usa BIOS o UEFI para arrancar
  • Qué gestor de arranque utiliza (solo Linux)
  • Qué kernels se pueden elegir al arrancar (solo Linux)
  • Qué controladores (módulos del kernel) están instalados

Esto es útil para determinar cómo (o si) una máquina virtual puede arrancar en un hipervisor de virtualización.

virt-customize

--selinux-relabel es ahora el valor predeterminado para las máquinas virtuales SELinux. Ya no necesita especificar esta opción. En el raro caso en que no desee volver a etiquetar una máquina virtual después de personalizarla, puede usar --no-selinux-relabel. Tenga en cuenta que esto no es necesario para máquinas virtuales que no usan SELinux, ya hará lo correcto automáticamente (Laszlo Ersek).

Nuevas operaciones --inject-qemu-ga y --inject-virtio-win que inyectan respectivamente el agente invitado QEMU y los controladores virtio-win en máquinas virtuales Windows.

Ahora se admiten las máquinas virtuales Rocky Linux (gracias Harry Benson).

virt-inspector

Virt-inspector ahora genera el nuevo elemento <build_id> que contiene el ID de compilación de la máquina virtual, si se usa libguestfs ≥ 1.50.

virt-sysprep

Nueva operación "lvm-system-devices" para eliminar el archivo system.devices de LVM2. Esto evita ciertos problemas al clonar una VM (Laszlo Ersek).

Virt-sysprep admite máquinas virtuales que usan volúmenes lógicos LUKS sobre LVM (Laszlo Ersek).

Cambios comunes

Todas las herramientas que admiten la opción --key ahora pueden usar Clevis/Tang para descifrar el cifrado de disco completo utilizando este esquema basado en red (Laszlo Ersek).

Cambios de compilación

Tenga en cuenta que libguestfs ahora requiere un mínimo de OCaml 4.04. No compilará en RHEL 6.

Tenga en cuenta que libosinfo es una nueva dependencia requerida.

OCaml 4.14 ahora está soportado.

"./configure --disable-ocaml" y "./configure --disable-perl" ahora deshabilitan las herramientas basadas en OCaml y Perl respectivamente (gracias Simon Walter).

Soporte experimental para compilar en macOS.

Al ejecutar "make check-valgrind", los registros de Valgrind ya no se escriben en archivos separados en tmp/. En su lugar, la salida se escribe en el archivo normal test-name.log.
