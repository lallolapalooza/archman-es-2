NOMBRE

guestfs-release-notes - Notas de la versión de libguestfs

NOTAS DE LA VERSIÓN PARA LIBGUESTFS 1.16

Estas notas de la versión solo cubren las diferencias con la división anterior de rama estable/dev (1.14.0). Para ver registros de cambios detallados, consulte el repositorio de git o el archivo ChangeLog distribuido en el tarball.

Nuevas características

libguestfs

- permitir la creación de sistemas de archivos XFS sobre un sistema de archivos existente
  (Wanlong Gao)
- la alineación predeterminada (no especificada) para part-disk se ha
  cambiado a 64K para un mejor soporte de almacenamiento de red de alta gama
- nueva página de manual guestfs-testing(1)
- list-filesystems devuelve dispositivos MD que contienen sistemas de archivos
  (Matthew Booth)
- soporte para GCC >= 4.7 (Jim Meyering)
- comprobar que el usuario no añade la misma unidad dos veces (Wanlong Gao).

enlaces de idiomas

- Enlaces GObject experimentales, con soporte para GObject
  Introspection. Ahora puedes usar libguestfs desde Javascript.
  Ten en cuenta que no son estables y finales en esta versión.
  (Matthew Booth).
- soporte para Ruby >= 1.9
- los enlaces de Ruby se pueden deshabilitar individualmente (Hilko Bengen)
- soporte para Python 2.6, 3.x (Richard Jones, Hilko Bengen)
- soporte para PHP >= 5.4
- el nuevo hash %guestfs_introspection está disponible en los enlaces de Perl para que
  puedas consultar qué argumentos opcionales están disponibles

inspección

- se pueden inspeccionar invitados con dispositivos MD (Matthew Booth)
- soporte para invitados GNU/Hurd

guestfish

- los eventos de libguestfs (como eventos de barra de progreso y mensajes de registro) pueden
  ser capturados y procesados por scripts de shell definidos por el usuario.
- los dispositivos MD se completan con tabulador (Matthew Booth)

virt tools

- Nueva herramienta virt-format para borrar y crear discos en blanco
- virt-sparsify nuevas opciones --compress y -o para permitir salida comprimida
  y de diferentes formatos
- virt-sparsify ahora puede detectar y hacer sparsify archivos .vdi
- virt-sysprep ya no requiere xmlstarlet; se ha añadido una nueva opción virt-inspector --xpath
  para reemplazar esta funcionalidad
- virt-rescue tiene una nueva opción --suggest que sugiere comandos de montaje
  para el invitado
- virt-resize ya no requiere la biblioteca pcre de OCaml

libguestfs live

- el demonio ya no intentará editar tu configuración de lvm en vivo /etc/
- corrige un posible problema de seguridad con nombres predecibles en /tmp (Steve Kemp)

Seguridad

CVE-2011-4127, RHBZ#757071
Mitiga posible escalada de privilegios a través de ioctl SG_IO
Para más información, ver: https://github.com/libguestfs/libguestfs/commit/9a5f784d511a8f00a8386f316eab41fe660430db

Nuevas APIs

blkid: imprime todos los atributos de un dispositivo conocido por blkid (Wanlong Gao)
e2fsck: acceso a más funciones de e2fsck (Wanlong Gao)
list-md-devices: lista de dispositivos MD de Linux (Matthew Booth)
md-create: crea un dispositivo MD
md-detail: devuelve metadatos para un dispositivo MD (Matthew Booth)
md-stop: detiene un dispositivo MD (Wanlong Gao)
tune2fs: permite ajustar sistemas de archivos ext2/3/4

Internos

El alojamiento de Git se ha trasladado a http://github.com/libguestfs
Los diversos directorios de pruebas se han reorganizado lógicamente, y ahora
todos aparecen bajo 'tests/'.
Hay una regla 'make extra-tests' que ejecuta pruebas ordinarias y
pruebas adicionales, utilizando valgrind para comprobar problemas de memoria.
Se han corregido múltiples fugas de memoria y otros problemas encontrados por valgrind.
El soporte para argumentos opcionales en el generador se ha reescrito
para proporcionar más características y seguridad (Matthew Booth).
Con gcc se utiliza -fvisibility=hidden para símbolos internos, evitando
la indirección de llamadas a través del PLT.
Las funciones RHashtable se pueden probar en el generador.
La macro ADD_ARG en el demonio permite construir listas de argumentos sin
riesgo de desbordamiento de pila.
Corrige la generación de funciones OCaml que tienen más de 10 argumentos.
Se ha añadido psmisc a la aplicación, permitiendo el uso de 'fuser',
'killall' y 'pstree' para depuración.
bindtests ahora cubren RBufferOut y argumentos opcionales (Matthew Booth).

Errores corregidos

- 769680 los directorios temporales creados durante la compilación de la aplicación no se limpian en caso de error
- 761460 guestfs_utimens se cuelga en tuberías con nombre
- 761451 guestfs_utimens no puede establecer tiempos en un directorio
- 760775 "guestfish: los sistemas operativos de arranque múltiple no son compatibles con la opción -i" debería ser más explicativo
- 760669 guestfish copy-in y <! (ejecución en línea) no se mezclan bien: pclose: No child processes
- 760000 libguestfs falla al compilar con Ruby >= 1.9
- 755729 El mensaje de error para resize2fs-M necesita ser ajustado
- 750889 Código Python incompatible con Python v3.
- 596761 Ctrl-\ hace que guestfish se aborte
