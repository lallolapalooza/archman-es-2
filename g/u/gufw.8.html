NOMBRE

Gufw - Interfaz gráfica de usuario para gestionar ufw

DESCRIPCIÓN

Gufw es un firewall de Ubuntu / Linux fácil de usar, impulsado por ufw.

Gufw es una forma fácil e intuitiva de gestionar tu firewall de Ubuntu. Soporta tareas comunes como permitir o bloquear puertos preconfigurados comunes, puertos p2p comunes, o puertos individuales, ¡y mucho más! Gufw está impulsado por ufw. Introducción iptables es ya una herramienta muy potente por sí sola, pero su sintaxis puede resultar incómoda a veces y difícil de entender, por lo que los desarrolladores de Ubuntu decidieron crear ufw ("La razón por la que se desarrolló ufw es que queríamos crear una utilidad de firewall a nivel de servidor que fuera un poco más para `seres humanos`"), que fuera más simple. Ahora, en el lado gráfico, Firestarter ya existía. Pero, ¿por qué no hacer una GUI aún más fácil de usar para los `seres humanos` de escritorio, impulsada por ufw? Aquí es donde entra Gufw.

USO

AJUSTES BÁSICOS

Gufw tiene dos estados: Habilitado y deshabilitado. Cuando Gufw está habilitado, puedes permitir/rechazar/denegar todas las conexiones entrantes y salientes.

AÑADIR REGLA(S) PRECONFIGURADA(S)

Puedes elegir entre más Programas y Servicios preconfigurados. Un Programa/Servicio puede tener múltiples reglas.

ELIMINAR UNA REGLA

Pasos:
1. Selecciona una regla en la lista.
2. Haz clic en el botón Eliminar. Puedes eliminar más reglas si las seleccionas.

RESTAURAR CONFIGURACIÓN

¡Eliminarás todas las reglas y restaurarás la configuración de ufw a su estado inicial (deshabilitado)!

EDITAR PREFERENCIAS

Puedes editar tus preferencias en el menú /Editar/Preferencias.

REENVÍO IP/PUERTOS

Para la política y las reglas de enrutamiento, debes configurar el reenvío de IP:
Cierra Gufw
Descomenta las siguientes líneas en /etc/ufw/sysctl.conf:
net/ipv4/ip_forward=1
net/ipv6/conf/default/forwarding=1
net/ipv6/conf/all/forwarding=1
Reinicia el firewall:
ufw reload
Abre Gufw de nuevo: Verás una nueva opción "Enrutado" (con una flecha alrededor del escudo) y podrás reenviar cualquier regla desde la ventana Actualizar o la Pestaña Avanzado en la ventana Añadir.

USAR GUFW SIN ENTORNO GRÁFICO O COMPUTADORA REMOTA

Puedes usar Gufw en un Linux sin Entorno Gráfico (por ejemplo, un servidor Ubuntu) o desde una computadora remota. Necesitarás Gufw 13.10.2 o superior. Simplemente exporta tu pantalla X. Todas las operaciones en Gufw se aplicarán en la computadora remota. Importante: Si habilitas el firewall bajo ssh sin la regla ssh, cerrarás la conexión ssh, así que antes de habilitar Gufw bajo una conexión ssh, agrega la regla ssh usando ufw con este comando:
sudo ufw enable ssh Linux, por ejemplo:
Computadora remota sin entorno gráfico (IP = 192.168.1.102, Gufw instalado y servidor ssh).
Linux local. En esta computadora local, abre una Terminal y ejecuta este comando:
ssh user_remote@192.168.1.102 -X
sudo /usr/bin/gufw-pkexec -ssh Windows (Por ejemplo, IP de Windows = 192.168.1.101; IP de Linux = 192.168.1.100):
Instala Putty & Xming.
En Windows: Ejecuta XLaunch desde el Menú de Inicio y marca "No Access Control" en el último paso.
Conéctate a tu Linux con Putty y ejecuta:
export DISPLAY=192.168.1.101:0.0
sudo /usr/bin/gufw-pkexec -ssh
