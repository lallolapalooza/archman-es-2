GUVCVIEW(1) Manual de Comandos Generales GUVCVIEW(1)

NOMBRE

guvcview - Visor UVC basado en GTK+

SINOPSIS

guvcview

DESCRIPCIÓN

Guvcview es una aplicación para capturar y ver video de dispositivos compatibles con la interfaz video4linux2 del kernel de Linux.

USO

guvcview [opciones...]

OPCIONES

-h,--ayuda
Imprimir ayuda
-v,--versiòn
Imprimir versión
-w,--verbosidad=NIVEL
Establecer nivel de verbosidad (por defecto: 0)
-d,--dispositivo=DISPOSITIVO_AUDIO
Establecer nombre del dispositivo (por defecto: /dev/video0)
-c,--captura=MÉTODO
Establecer método de captura [read | mmap (por defecto)]
-b,--deshabilitar_libv4l2
Deshabilitar llamadas a libv4l2
-x,--resoluciòn=ANCHOxALTO
Solicitar resolución (ej. 640x480)
-f,--formato=FOURCC
Solicitar formato (ej. MJPG)
-F,--fps=NUM_FPS[/DENOM_FPS]
Solicitar fps (ej. 25; 7/3; ...)
-r,--render=API_RENDER
Seleccionar API de renderizado (ej. none; sdl; sfml)
-m,--ventana_render=FLAGS_VENTANA_RENDER
Establecer flags de ventana de renderizado (ej. none; full; max; ANCHOxALTO)
-a,--audio=API_AUDIO
Seleccionar API de audio (ej. none; port; pulse)
-k,--dispositivo_audio=dispositivo_audio
Seleccionar índice de dispositivo de audio para la API seleccionada (0..N)
-g,--gui=API_GUI
Seleccionar API GUI (ej. none; gtk3; qt6)
-o,--codec_audio=codecAudio
Códec de audio [pcm mp2 mp3 aac ac3 vorb]
-u,--codec_video=codec
Códec de video [raw mjpg mpeg flv1 wmv1 mpg2 mp43
dx50 h264 vp80 theo]
-p,--perfil=nombre_archivo
Cargar perfil de control
-j,--video=nombre_archivo
nombre de archivo para video capturado)
-i,--imagen=nombre_archivo
nombre de archivo para imagen capturada)
-y,--temporizador_video=TIEMPO_EN_SEG
Tiempo (doble) en seg. para captura de video)
-t,--temporizador_foto=TIEMPO_EN_SEG
Tiempo (doble) en seg. entre fotos capturadas)
-n,--total_fotos=total
Número total de fotos capturadas)
-e,--salir_al_terminar
Salir de la aplicación después de que finalice la captura de video o imagen
-z,--panel_control
Iniciar en modo panel de control
