GUIDELLM2PCP(1) Manual de comandos generales GUIDELLM2PCP(1)

NOMBRE

guidellm2pcp - importador de resultados de benchmark GuideLLM

SINOPSIS

guidellm2pcp [-hv] [-a archivo] [-H nombrehost] resultados [...]

DESCRIPCIÓN

guidellm2pcp es una herramienta de importación de métricas de rendimiento que crea un archivo PCP a partir de los resultados JSON de un benchmark GuideLLM.

Un archivo que abarca el tiempo durante el cual el benchmark y sus iteraciones de ejecución estuvieron activos. Se crean métricas PCP discretas para cada aspecto registrado de una ejecución, y se registran una vez al inicio y una vez al final de cada iteración, seguidas de un registro de marca.

Esto permite a las herramientas PCP informar sobre estas métricas de manera significativa junto con otras métricas del sistema (kernel, hardware, vLLM, etc.) recopiladas durante el benchmark.

El único argumento obligatorio en la línea de comandos es el archivo JSON de resultados de una invocación de GuideLLM. Este JSON puede opcionalmente envolverse con metadatos adicionales de Model Furnace y, si esto se detecta, se extraerán y almacenarán etiquetas PCP adicionales (como los nombres del modelo y del servidor de inferencia).

OPCIONES

Las opciones disponibles en la línea de comandos son:

-a archivo, --archive=archivo
Especifica el nombre del archivo PCP de salida que se producirá. Por defecto, se utilizará un nombre de archivo que utiliza la marca de tiempo del inicio de la ejecución del benchmark.
-H nombrehost, --hostname=nombrehost
Establece el nombrehost que se estampará en la cabecera de la etiqueta del archivo PCP.
-h, --help
Muestra el mensaje de uso y sale.
-v, --verbose
Informa sobre el progreso a medida que se identifica cada ejecución y se guardan sus valores.
