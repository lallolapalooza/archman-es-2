guestunmount(1) Soporte de virtualización guestunmount(1)

NOMBRE

guestunmount - Desmontar un sistema de archivos montado por invitado

SINOPSIS

guestunmount punto_montaje
guestunmount --fd=<FD> punto_montaje

DESCRIPCIÓN

guestunmount es una utilidad para limpiar sistemas de archivos montados automáticamente. guestmount(1) monta sistemas de archivos usando libguestfs. Este programa desmonta el sistema de archivos cuando un programa o script ha terminado con él.

guestunmount es un envoltorio del programa FUSE fusermount(1), que debe existir en la "PATH" actual.

Hay dos maneras de usar guestunmount. Cuando se llama como:

guestunmount punto_montaje

desmonta "punto_montaje" inmediatamente.

Cuando se llama como:

guestunmount --fd=FD punto_montaje

espera hasta que la tubería "FD" se cierre. Esto se puede usar para monitorizar otro proceso y limpiar su punto de montaje cuando ese proceso termina, como se describe a continuación.

DESDE PROGRAMAS

Simplemente puedes llamar a "guestunmount punto_montaje" desde el programa, pero una forma más sofisticada de usar guestunmount es hacer que monitorice tu programa para que pueda limpiar el punto de montaje si tu programa sale inesperadamente.

En el programa, crea una tubería (por ejemplo, llamando a pipe(2)). Sea "FD" el número de descriptor de archivo del lado de lectura de la tubería (es decir, "pipefd[0]").

Después de montar el sistema de archivos con guestmount(1) (en "punto_montaje"), haz un fork y ejecuta guestunmount así:

guestunmount --fd=FD punto_montaje

Cierra el lado de lectura de la tubería en el proceso padre.

Ahora, cuando el lado de escritura de la tubería (es decir, "pipefd[1]") se cierre por cualquier motivo, ya sea explícitamente o porque el proceso padre termina, guestunmount lo detecta y desmonta el punto de montaje.

Si tu sistema operativo lo soporta, deberías establecer la bandera "FD_CLOEXEC" en el lado de escritura de la tubería. Esto es para que otros procesos hijos no hereden el descriptor de archivo y lo mantengan abierto.

Guestunmount nunca se ejecuta como un demonio por sí mismo.

DESDE SCRIPTS DE SHELL

Dado que bash no proporciona una forma de crear una tubería sin nombre, usa un "trap" para llamar a guestunmount al salir, así:

trap "guestunmount punto_montaje" EXIT INT QUIT TERM

OPCIONES

--fd=FD
Especifica el descriptor de archivo de la tubería a monitorizar y retrasa la limpieza hasta que esa tubería se cierre.
--help
Muestra una breve ayuda y sale.
-q
--quiet
No muestra mensajes de error de fusermount. El estado de retorno sigue establecido (ver "ESTADO DE SALIDA" más abajo).
--no-retry
--retry=N
Por defecto, guestunmount reintentará la operación de fusermount hasta 5 veces (es decir, la ejecutará hasta 6 veces = 1 intento + 5 reintentos).

Usa --no-retry para que guestunmount ejecute fusermount solo una vez.

Usa --retry=N para que guestunmount reintente "N" veces en lugar de 5.

guestunmount realiza un retroceso exponencial entre reintentos, esperando 1 segundo, 2 segundos, 4 segundos, etc. antes de cada reintento.

-V
--version
Muestra la versión del programa y sale.

VARIABLES DE ENTORNO

"PATH"
El programa fusermount(1) (suministrado por FUSE) debe estar disponible en la "PATH" actual.

ESTADO DE SALIDA

Este programa devuelve 0 si tiene éxito, o uno de los siguientes códigos de error:

1
Error del programa, por ejemplo, no se pudo asignar memoria, no se pudo ejecutar fusermount. Consulte el mensaje de error impreso para obtener más información.
2
El punto de montaje no se pudo desmontar incluso después de reintentar. Consulte el mensaje de error impreso para ver el error subyacente de fusermount.
3
El punto de montaje no está montado.

VER TAMBIÉN
