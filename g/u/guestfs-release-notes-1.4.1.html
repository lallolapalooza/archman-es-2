NOMBRE

guestfs-release-notes - Notas de la versión de libguestfs

NOTAS DE LA VERSIÓN PARA LIBGUESTFS 1.4

Estas notas de la versión solo cubren las diferencias con la división anterior de ramas estables/de desarrollo (1.2.0). Para ver registros de cambios detallados, consulte el repositorio git o el archivo ChangeLog distribuido en el tarball.

Nuevas características

- guestfish permite elegir una imagen de disco preparada, p. ej.:
    guestfish -N fs:ext4
- Añade soporte de escritura al módulo guestmount (FUSE).
- virt-resize ahora puede redimensionar el contenido de particiones y volúmenes lógicos
  en el invitado, y tenemos mejor soporte para reducir invitados.
- Script de autocompletado Bash para guestfish.
- Añade soporte ZFS a virt-rescue.
- Nueva herramienta 'virt-make-fs' para crear sistemas de archivos con contenido.
- Permite sufijos en cualquier parámetro numérico de guestfish, p. ej., "1M".
- El comando 'man' de guestfish abre la página del manual.
- guestfish admite una sintaxis de "heredoc" para subir archivos:
    upload <<_end_ /foo
    content
    _end_
- Algunos comandos de guestfish ahora imprimen su salida en octal o hexadecimal
  cuando es apropiado (RHBZ#583242).
- Permite prefijo de guion en la línea de comandos de guestfish. Ignora cualquier
  error del segundo comando:                   (RHBZ#578407)
    guestfish -- cmd1 : -cmd2 : cmd3
- guestfish -h / el comando help ahora devuelve un error para comandos inexistentes
  (RHBZ#597145).
- Nuevo comando 'supported' en guestfish para listar grupos opcionales de
  comandos que son compatibles con el demonio / configuración.
- virt-inspector y guestfish -i ahora funcionan para nombres de archivo que
  contienen espacios (RHBZ#507810).
- Cambia el protocolo para usar direcciones de enlace local, para evitar
  conflictos con cualquier dirección que el host pueda estar utilizando
  (RHBZ#588763).
- libguestfs ahora establece la hora y la zona horaria correctas en las modificaciones del sistema de archivos.
- Ordena los dominios alfabéticamente en virt-df.
- Hace que el comando mkfs-b funcione para FAT y NTFS mapeando el tamaño del bloque
  al tamaño del clúster (RHBZ#599464).
- Añade números de versión a los módulos Perl (RHBZ#521674).
- La localización ahora funciona para todas las herramientas de libguestfs (RHBZ#559963).
- Las herramientas ahora soportan VMs con sistema de archivos en imagen (RHBZ#590167).
- virt-list-partitions tiene una opción '-t' para mostrar el tamaño total de los discos.
- Incluye lentes Augeas adicionales en la aplicación supermin (Matthew Booth).
- Añade callbacks de error y cierre.
- Añade método de cierre explícito en la API de Perl.
- Múltiples correcciones para la compatibilidad con RHEL 5.
- Múltiples correcciones para la compatibilidad con Debian/Ubuntu.
- Múltiples revisiones para mejorar la documentación.

Seguridad

- Corrige una posible DoS en virt-inspector y virt-v2v si una imagen de disco especialmente
  elaborada contenía un dispositivo de caracteres en lugar de uno de los
  archivos de configuración que leemos en /etc (RHBZ#582484).

Nuevas APIs

- aug-clear - limpiar ruta de Augeas
- available-all-groups - devolver una lista de todos los grupos opcionales
- base64-in - subir datos codificados en base64 a un archivo
- base64-out - descargar archivo y codificar como base64
- checksum-device - calcular sumas de verificación sobre el contenido de un dispositivo
- checksums-out - calcular sumas de verificación de varios archivos en un directorio
- debug-upload - subir un archivo a la aplicación
- fallocate64 - preasignar un archivo en el sistema de archivos del invitado
- fill-pattern - llenar un archivo con un patrón de bytes repetitivo
- get-umask - obtener la umask actual
- lvresize-free - expandir un LV para llenar el espacio libre
- ntfsresize - redimensionar un sistema de archivos NTFS
- ntfsresize-size - redimensionar un sistema de archivos NTFS (con tamaño)
- part-del - eliminar una partición
- part-get-bootable - obtener el indicador de arranque de una partición
- part-get-mbr-id - obtener el byte de tipo MBR de una partición
- part-set-mbr-id - establecer el byte de tipo MBR de una partición
- pvresize-size - redimensionar un volumen físico (con tamaño)
- pwrite - escribir en parte de un archivo
- resize2fs-size - redimensionar un sistema de archivos ext2/3/4 (con tamaño)
- txz-in - desempaquetar tarball comprimido en directorio (RHBZ#580556)
- txz-out - empaquetar directorio en tarball comprimido (RHBZ#580556)
- vfs-label - obtener la etiqueta del sistema de archivos
- vfs-uuid - obtener la UUID del sistema de archivos
- vgscan - escanear de nuevo volúmenes físicos LVM, grupos de volúmenes y volúmenes lógicos
- write - crear un nuevo archivo
- zero-device - escribir ceros en un dispositivo completo

Internos

- Extender el generador para soportar pruebas de características opcionales.
- Comprobaciones más estrictas en los parámetros de entrada de muchas llamadas (RHBZ#501893 RHBZ#501894)
- Extender el protocolo para soportar el envío de búferes de datos de 8 bits arbitrarios.
- Distribuir el archivo 'BUGS' con las versiones. Es un resumen de los errores en
  la base de datos Red Hat Bugzilla.
- Distribuir el archivo 'RELEASE-NOTES' con las versiones, que contiene las notas de la versión.
- Unificar la construcción de la aplicación supermin en un solo lugar, en febootstrap 2.7.
- Corregir el código del protocolo para manejar el caso en que ambos extremos envían mensajes de cancelación al mismo tiempo.
