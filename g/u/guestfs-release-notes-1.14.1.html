guestfs-release-notes - Notas de la versión de libguestfs

NOTAS DE LA VERSIÓN PARA LIBGUESTFS 1.14

Estas notas de la versión solo cubren las diferencias con la división de la rama estable/desarrollo anterior (1.12.0). Para registros de cambios detallados, consulte el repositorio git o el archivo ChangeLog distribuido en el tarball.

Nuevas características

Enlaces Erlang.
virt-alignment-scan es una nueva herramienta para verificar la alineación de
particiones dentro de máquinas virtuales o imágenes de disco.
virt-sparsify es una nueva herramienta para hacer que las imágenes de disco de
máquinas virtuales sean dispersas (sparse).
virt-sysprep es una nueva herramienta para simplificar la clonación de huéspedes
a partir de una plantilla.

guestfish

- Nuevos comandos setenv, unsetenv, para establecer variables de entorno.
- El archivo de entrada y el número de línea se muestran en los mensajes de error.
- Las barras de progreso de guestfish son ahora una "mini-biblioteca" utilizada
  también por otras herramientas.

guestmount

- la opción --live (para acceder a máquinas virtuales activas) ahora funciona.

virt-cat

- virt-cat ahora puede manejar rutas de Windows y letras de unidad (RHBZ#693359).

virt-filesystems

- el byte de tipo de partición MBR se muestra en la salida --long.

virt-make-fs

- virt-make-fs ahora establece correctamente el byte de tipo de partición MBR,
  mejorando la compatibilidad con Windows (RHBZ#746295).

virt-resize

- virt-resize ahora puede trabajar con huéspedes que usan particiones extendidas
  y lógicas, en particular huéspedes Ubuntu.
- virt-resize ahora puede alinear la primera partición de huéspedes Windows,
  mejorando el rendimiento. La nueva opción virt-resize --align-first
  controla este comportamiento.
- El indicador virt-resize --machine-readable hace posible usar
  virt-resize desde otros programas.
- Las particiones se alinean ahora a 128 sectores (normalmente 64K) por
  defecto. Esto mejora la eficiencia en almacenamiento de gama alta. La nueva
  opción virt-resize --alignment permite ajustar la alineación.

virt-win-reg

- La sintaxis para eliminar claves y valores del registro está documentada
  en la página man (RHBZ#737944).

biblioteca

- los caracteres no imprimibles se escapan correctamente en la salida de depuración.
- GUESTFS_EVENT_ENTER es un nuevo tipo de evento generado cada vez que se
  llama a una función de libguestfs.
- la biblioteca contiene sondas systemtap/DTrace.
- la biblioteca ahora se puede compilar sin hivex (RHBZ#723474).

inspección

- Mejora en la detección de discos Windows.
- Añade soporte para:
      ttylinux - un Linux minimalista
      Mageia (gracias a Michael Scherer)
      OpenSUSE y zypper (gracias a Michael Scherer, Vincent Untz)
      logotipos de Ubuntu (gracias a Michael Scherer)
      NetBSD y pkgsrc (gracias a Michael Scherer)
- Maneja algunos tipos de huéspedes que usan /dev/root en /etc/fstab.
- Corrige el manejo de huéspedes con más de 26 discos (gracias a Matthew Booth)
- Añade soporte para huéspedes con discos HP Smart Array (gracias a Matthew Booth)

febootstrap

- Las variables de entorno FEBOOTSTRAP_KERNEL, FEBOOTSTRAP_MODULES se pueden
  establecer para elegir qué kernel usar para el appliance.

varios

- El soporte de ArchLinux ahora funciona con Linux 3.0 (gracias a Erik Nolte)
- Los discos de libvirt marcados como <readonly/> ahora se añaden de solo lectura
  cuando se usa la opción '-d' de las virt-tools.

Seguridad

(no se encontraron ni corrigieron problemas de seguridad en esta versión)

Nuevas API

compress-out, compress-device-out, copy-device-to-device,
copy-device-to-file, copy-file-to-device, copy-file-to-file,
get-smp, part-to-partnum, set-smp.
La API de montaje ya no añade implícitamente las opciones -o sync,noatime.
add-domain tiene un nuevo parámetro opcional 'readonlydisk' para controlar
cómo se manejan los discos <readonly/>.

Internos

- Se ejecutó Coverity en el código fuente y se identificaron y corrigieron
  más errores.
- La biblioteca PCRE es ahora necesaria para compilar libguestfs.
- APIC es ahora el valor predeterminado para el appliance. También se puede
  habilitar el soporte SMP en el appliance.
- Los enlaces OCaml ahora adquieren correctamente el bloqueo del GC durante
  las devoluciones de llamada.
- Las compilaciones fuera del árbol ahora deberían funcionar correctamente
  (gracias a Hilko Bengen).
- ./configure --with-extra="..." puede ser usado por los empaquetadores para
  establecer la cadena de versión extra.
- APIs zero, zero-device: si los bloques ya contienen ceros, no escribir ceros,
  para no hacer innecesariamente que el almacenamiento subyacente deje de ser
  disperso.
- APIs is-zero, is-zero-device: optimizadas para que la detección de ceros sea
  más rápida.

Errores corregidos

- 748266 libguestfs debería detectar versiones de qemu que requieren la opción -machine pc
- 747290 libguestfs ignora <readonly/> en el XML de libvirt
- 747287 Mensaje de error engañoso cuando se deniega el permiso para abrir una imagen de disco
- 746295 virt-make-fs no establece el ID de partición
- 744795 guestmount --live no es utilizable
- 737944 la sintaxis de virt-win-reg con guion (eliminar clave) puede ser incorrecta y no está documentada
- 733297 los manejadores de eventos de ruby fallan con "exception in callback: wrong argument type Proc (expected Data)"
- 731744 libguestfs debería escapar caracteres especiales/no imprimibles en la salida de depuración
- 729887 el appliance se bloquea al ejecutar aug_init con flags=4
- 729075 libguestfs confunde la partición Hp_recovery con el sistema de archivos raíz de Windows
- 727178 error: luks_open: cryptsetup: error while loading shared libraries: libfipscheck.so.1: cannot open shared object file: No such file or directory
- 726739 libguestfs: error: aug_get: no matching node, trying to find hostname
- 723474 Si hivex y/o pcre no están instalados, libguestfs falla al compilar
- 693359 virt-cat y virt-edit no manejan correctamente las rutas NTFS sensibles a mayúsculas
- 678231 virt-inspector informa un UUID de sistema de archivos desconocido
- 671082 libguestfs no funciona con kernel-rt
- 666578 libguestfs: unknown filesystem label SWAP-sda2
- 642821 virt-resize falla con una imagen de disco con una partición lógica de intercambio
