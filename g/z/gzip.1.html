NOMBRE

gzip, gunzip, zcat - comprimir o descomprimir archivos

SINOPSIS

gzip [ -acdfhklLnNrtvV19 ] [-S sufijo] [ nombre ... ]
gunzip [ -acfhklLnNrtvV ] [-S sufijo] [ nombre ... ]
zcat [ -fhLV ] [ nombre ... ]

DESCRIPCIÓN

El comando gzip reduce el tamaño de los archivos nombrados usando codificación Lempel-Ziv (LZ77). Siempre que sea posible, cada archivo se reemplaza por uno con la extensión .gz, manteniendo los mismos permisos de propietario, acceso y tiempos de modificación. (La extensión por defecto es z para MSDOS, FAT de OS/2, FAT de Windows NT y Atari.) Si no se especifican archivos, o si el nombre de archivo es "-", la entrada estándar se comprime a la salida estándar. El comando gzip solo intentará comprimir archivos regulares. En particular, ignorará los enlaces simbólicos.

Si el nombre del archivo comprimido es demasiado largo para su sistema de archivos, gzip lo trunca. El comando gzip intenta truncar solo las partes del nombre del archivo que tengan más de 3 caracteres. (Una parte está delimitada por puntos). Si el nombre consta solo de partes pequeñas, se truncan las partes más largas. Por ejemplo, si los nombres de archivo se limitan a 14 caracteres, gzip.msdos.exe se comprime a gzi.msd.exe.gz. Los nombres no se truncan en sistemas que no tienen un límite en la longitud del nombre del archivo.

Por defecto, gzip conserva el nombre original del archivo y la marca de tiempo en el archivo comprimido. Estos se usan al descomprimir el archivo con la opción -N. Esto es útil cuando el nombre del archivo comprimido fue truncado o cuando la marca de tiempo no se conservó después de una transferencia de archivos.

Los archivos comprimidos se pueden restaurar a su forma original usando gzip -d o gunzip o zcat. Si el nombre original guardado en el archivo comprimido no es adecuado para su sistema de archivos, se construye un nuevo nombre a partir del original para hacerlo válido.

gunzip toma una lista de archivos en su línea de comandos y reemplaza cada archivo cuyo nombre termina con .gz, -gz, .z, -z, o _z (ignorando mayúsculas/minúsculas) y que comienza con el número mágico correcto, con un archivo descomprimido sin la extensión original. gunzip también reconoce las extensiones especiales .tgz y .taz como atajos para .tar.gz y .tar.Z respectivamente. Al comprimir, gzip usa la extensión .tgz si es necesario en lugar de truncar un archivo con una extensión .tar.

gunzip actualmente puede descomprimir archivos creados por gzip, zip, compress, compress -H o pack. La detección del formato de entrada es automática. Al usar los dos primeros formatos, gunzip comprueba una CRC de 32 bits. Para pack y compress, gunzip comprueba la longitud descomprimida. El formato estándar compress no fue diseñado para permitir comprobaciones de consistencia. Sin embargo, gunzip a veces es capaz de detectar un archivo .Z defectuoso. Si obtiene un error al descomprimir un archivo .Z, no suponga que el archivo .Z es correcto simplemente porque el uncompress estándar no se queja. Esto generalmente significa que el uncompress estándar no comprueba su entrada y genera felizmente salida basura. El formato SCO compress -H (método de compresión lzh) no incluye una CRC pero también permite algunas comprobaciones de consistencia.

Los archivos creados por zip solo pueden ser descomprimidos por gzip si tienen un solo miembro comprimido con el método 'deflate'. Esta característica solo está destinada a ayudar a la conversión de archivos tar.zip al formato tar.gz. Para extraer un archivo zip con un solo miembro, use un comando como 'gunzip <foo.zip' o 'gunzip -S .zip foo.zip'. Para extraer archivos zip con varios miembros, use unzip en lugar de gunzip.

El comando zcat es idéntico a gunzip -c. (En algunos sistemas, zcat puede estar instalado como gzcat para preservar el enlace original a compress.) zcat descomprime ya sea una lista de archivos en la línea de comandos o su entrada estándar y escribe los datos descomprimidos en la salida estándar. zcat descomprimirá archivos que tengan el número mágico correcto independientemente de si tienen un sufijo .gz o no.

El comando gzip utiliza el algoritmo Lempel-Ziv utilizado en zip y PKZIP. La cantidad de compresión obtenida depende del tamaño de la entrada y la distribución de subcadenas comunes. Típicamente, el texto como código fuente o inglés se reduce en un 60%–70%. La compresión es generalmente mucho mejor que la lograda por LZW (utilizado en compress), codificación Huffman (utilizada en pack) o codificación Huffman adaptativa (compact).

La compresión se realiza siempre, incluso si el archivo comprimido es ligeramente más grande que el original. La peor expansión es de unos pocos bytes para la cabecera del archivo gzip, más 5 bytes por bloque de 32 KiB, o una relación de expansión del 0,015% para archivos grandes. El número real de bloques de disco utilizados casi nunca aumenta.

gzip normalmente conserva el modo y la marca de tiempo de modificación de un archivo al comprimir o descomprimir. Si tiene los privilegios apropiados, también conserva el propietario y el grupo del archivo.

OPCIONES

-a --ascii
Modo de texto ASCII: convierte los finales de línea usando convenciones locales. Esta opción solo se admite en algunos sistemas no Unix. Para MSDOS, CR LF se convierte a LF al comprimir, y LF se convierte a CR LF al descomprimir.
-c --stdout --to-stdout
Escribe la salida en la salida estándar; deja los archivos originales sin cambios. Si hay varios archivos de entrada, la salida consiste en una secuencia de miembros comprimidos de forma independiente. Para obtener una mejor compresión, concatene todos los archivos de entrada antes de comprimirlos.
-d --decompress --uncompress
Descomprimir.
-f --force
Forzar la compresión o descompresión incluso si el archivo tiene varios enlaces o el archivo correspondiente ya existe, o si los datos comprimidos se leen o escriben desde o hacia una terminal. Si los datos de entrada no están en un formato reconocido por gzip, y si la opción --stdout también se proporciona, copia los datos de entrada sin cambios a la salida estándar: deja que zcat se comporte como cat. Si no se proporciona -f, y cuando no se ejecuta en segundo plano, gzip pregunta para verificar si se debe sobrescribir un archivo existente.
-h --help
Muestra una pantalla de ayuda y sale.
-k --keep
Mantener (no eliminar) los archivos de entrada durante la compresión o descompresión.
-l --list
Para cada archivo comprimido, lista los siguientes campos:


tamaño comprimido: tamaño del archivo comprimido
tamaño descomprimido: tamaño del archivo descomprimido
ratio: relación de compresión (0.0% si es desconocido)
nombre_descomprimido: nombre del archivo descomprimido

El tamaño descomprimido se da como -1 para archivos que no están en formato gzip, como los archivos .Z comprimidos. Para obtener el tamaño descomprimido de dicho archivo, puede usar:


zcat file.Z | wc -c

En combinación con la opción --verbose, también se muestran los siguientes campos:


método: método de compresión
crc: la CRC de 32 bits de los datos descomprimidos
fecha y hora: marca de tiempo del archivo descomprimido

Los métodos de compresión actualmente admitidos son deflate, compress, lzh (SCO compress -H) y pack. La crc se da como ffffffff para un archivo que no está en formato gzip.

Con --name, el nombre descomprimido, la fecha y la hora son los almacenados dentro del archivo comprimido si están presentes.

Con --verbose, también se muestran los totales de tamaño y la relación de compresión para todos los archivos, a menos que algunos tamaños sean desconocidos. Con --quiet, las líneas de título y totales no se muestran.

-N --name
Cuando se descomprime, restaura el nombre original del archivo y la marca de tiempo. Esta opción está habilitada por defecto.
-n --no-name
Cuando se descomprime, el nombre original del archivo y la marca de tiempo no se restauran. Esta opción está deshabilitada por defecto.
-q --quiet
Suprime todos los mensajes de advertencia. Cuando se usa con --list, solo se imprimen las líneas de datos, no el título ni los totales.
-r --recursive
Comprime o descomprime recursivamente los directorios.
-S --suffix SUFFIX
Usa SUFFIX en lugar de .gz. Por ejemplo, para usar .z, use -S .z.
-t --test
Prueba la integridad de cada archivo comprimido examinando su CRC y su tabla de descompresión. gzip solo muestra los archivos que fallan en la prueba. El equivalente a gunzip -t es gunzip -l.
-v --verbose
Modo detallado. Imprime el porcentaje de reducción del tamaño para cada archivo procesado. Esto es lo mismo que dar la opción --list.
-V --version
Muestra la versión de gzip y sale.
-1 --fast
Comprime más rápido (nivel de compresión 1).

-9 --best

Comprime más lentamente (nivel de compresión 9).

Los niveles de compresión 2 a 8 son un compromiso entre velocidad y compresión. El nivel por defecto es 6.

EJEMPLOS

Comprimir el archivo foo.txt:

gzip foo.txt

Esto crea foo.txt.gz y elimina foo.txt.

Descomprimir foo.txt.gz:

gunzip foo.txt.gz

Esto crea foo.txt y elimina foo.txt.gz.

Comprimir foo.txt y enviar el resultado a la salida estándar:

gzip -c foo.txt > foo.txt.gz

Descomprimir foo.txt.gz y enviar el resultado a la salida estándar:

gunzip -c foo.txt.gz > foo.txt

Ver el contenido de foo.txt.gz sin descomprimirlo:

zcat foo.txt.gz

Comprimir recursivamente todos los archivos del directorio actual:

gzip -r .

Descomprimir recursivamente todos los archivos del directorio actual:

gunzip -r .

UTILIZACIÓN

Si la compresión resulta en un archivo más grande que el original, gzip descarta el archivo comprimido. Esto puede ocurrir si la entrada es un archivo ya comprimido, como un archivo zip o un archivo .gz, o si la entrada es un archivo muy corto. La compresión de archivos muy cortos, como archivos de configuración de 100 bytes, a menudo resulta en una expansión. Por lo tanto, gzip no comprime estos archivos.

El uso de gzip es compatible con el programa zip. Los archivos creados con gzip pueden descomprimirse con unzip y viceversa, siempre que se haya utilizado el mismo método de compresión. Por ejemplo, un archivo .tar.gz creado con gzip se puede descomprimir con gunzip, y un archivo .zip creado con zip se puede descomprimir con unzip. (Para archivos .zip con varios miembros, unzip es la única herramienta utilizable.)

Los archivos comprimidos con gzip normalmente no se pueden modificar. Para añadir o eliminar archivos de un archivo comprimido, primero debe descomprimirlo, modificarlo y luego volver a comprimirlo.

Si la salida se redirige a un archivo, el archivo se sobrescribe sin preguntar. Esto se puede evitar usando la opción -f (forzar).

Para evitar la pérdida accidental de archivos, gzip elimina los archivos de entrada solo después de que se haya confirmado que la escritura del archivo de salida se realizó correctamente. El comando gzip también es seguro si se interrumpe: los archivos de entrada se conservan y los archivos de salida parciales se eliminan.

Cuando se comprime un archivo, el nombre del archivo original se almacena en el archivo comprimido. Esto permite que gunzip restaure el nombre original del archivo. Esta característica está habilitada por defecto y puede ser desactivada con la opción -n.

La opción -r permite comprimir o descomprimir directorios recursivamente.

Al comprimir varios archivos, es mejor concatenarlos primero y luego comprimirlos como un solo archivo. Por ejemplo:

cat file1 file2 file3 | gzip > files.gz

Esto asegura que la compresión se optimice para todo el conjunto de datos. Si comprime cada archivo por separado, la compresión puede ser menos efectiva.

FALLOS

No hay una forma confiable de saber si un archivo .Z (creado con el comando compress original) es válido, a menos que la longitud descomprimida se almacene en el archivo. El comando uncompress original no realiza ninguna verificación. Por lo tanto, los archivos .Z pueden corromperse sin que el usuario se dé cuenta. La CRC de 32 bits en los archivos gzip permite detectar la mayoría de las corrupciones.

Al comprimir archivos muy pequeños, el archivo comprimido puede ser más grande que el original. La opción -f puede usarse para forzar la compresión en tales casos, pero el resultado puede no ser útil.

  • -L --license
    Muestra la gzip licencia y sale.
    -n --no-name
    Al comprimir, no guarda el nombre del archivo original y la marca de tiempo por defecto. (El nombre original siempre se guarda si el nombre tuvo que ser truncado). Al descomprimir, no restaura el nombre del archivo original si está presente (elimina solo el gzip sufijo del nombre del archivo comprimido) y no restaura la marca de tiempo original si está presente (la copia del archivo comprimido). Esta opción es la predeterminada al descomprimir.
    -N --name
    Al comprimir, guarda siempre el nombre del archivo original, y guarda la parte de segundos de la marca de tiempo de modificación original si el original es un archivo normal y su marca de tiempo es al menos 1 (1970-01-01 00:00:01 UTC) y es menos que 2**32 (2106-02-07 06:28:16 UTC, asumiendo que los segundos de salto no son contados); esto es lo predeterminado. Al descomprimir, restaura desde el nombre de archivo y la marca de tiempo guardados si están presentes. Esta opción es útil en sistemas que tienen un límite en la longitud del nombre del archivo o cuando la marca de tiempo se ha perdido después de una transferencia de archivo.
    -q --quiet
    Suprime todas las advertencias.
    -r --recursive
    Recorre la estructura de directorios recursivamente. Si alguno de los nombres de archivo especificados en la línea de comandos son directorios, gzip descenderá al directorio y comprimirá todos los archivos que encuentre allí (o los descomprimirá en el caso de gunzip ).
    -S .suf --suffix .suf
    Al comprimir, usa el sufijo .suf en lugar de .gz. Aunque se puede dar cualquier sufijo no vacío siempre que no contenga "/", se deben evitar los sufijos distintos de .z y .gz para evitar confusión cuando los archivos se transfieren a otros sistemas.

    Al descomprimir, añade .suf al principio de la lista de sufijos a intentar, al derivar un nombre de archivo de salida de un nombre de archivo de entrada.

    --synchronous
    Usa salida síncrona. Con esta opción, gzip es menos probable que pierda datos durante un fallo del sistema, pero puede ser considerablemente más lento.
    -t --test
    Prueba. Comprueba la integridad del archivo comprimido y luego sale.
    -v --verbose
    Detallado. Muestra el nombre y el porcentaje de reducción para cada archivo comprimido o descomprimido.
    -V --version
    Versión. Muestra el número de versión y las opciones de compilación y sale.
    -# --fast --best
    Regula la velocidad de compresión usando el dígito especificado #, donde -1 o --fast indica el método de compresión más rápido (menos compresión) y -9 o --best indica el método de compresión más lento (mejor compresión). El nivel de compresión predeterminado es -6 (es decir, sesgado hacia alta compresión a expensas de velocidad).
    --rsyncable
    Cuando sincroniza un archivo comprimido entre dos computadoras, esta opción permite a rsync transferir solo los archivos que fueron cambiados en el archivo en lugar de todo el archivo. Normalmente, después de que se hace un cambio a cualquier archivo en el archivo, el algoritmo de compresión puede generar una nueva versión del archivo que no coincide con la versión anterior del archivo. En este caso, rsync transfiere toda la nueva versión del archivo a la computadora remota. Con esta opción, rsync puede transferir solo los archivos cambiados así como una pequeña cantidad de metadatos que se requieren para actualizar la estructura del archivo en el área que fue cambiada.

    USO AVANZADO

    Se pueden concatenar múltiples archivos comprimidos. En este caso, gunzip extraerá todos los miembros a la vez. Por ejemplo:


    gzip -c file1 > foo.gz
    gzip -c file2 >> foo.gz

    Entonces


    gunzip -c foo

    es equivalente a


    cat file1 file2

    En caso de daño a un miembro de un archivo .gz, otros miembros pueden ser recuperados (si el miembro dañado es eliminado). Sin embargo, puede obtener mejor compresión comprimiendo todos los miembros a la vez:


    cat file1 file2 | gzip > foo.gz

    comprime mejor que


    gzip -c file1 file2 > foo.gz

    Si desea recomprimir archivos concatenados para obtener mejor compresión, haga:


    gzip -cd old.gz | gzip > new.gz

    Si un archivo comprimido consiste en varios miembros, el tamaño sin comprimir y el CRC reportados por la opción --list se aplican solo al último miembro. Si necesita el tamaño sin comprimir para todos los miembros, puede usar:


    gzip -cd file.gz | wc -c

    Si desea crear un solo archivo de archivo con múltiples miembros para que los miembros puedan ser extraídos independientemente más tarde, use un archivador como tar o zip. GNU tar soporta la opción -z para invocar gzip transparentemente. gzip está diseñado como un complemento a tar, no como un reemplazo.

    ENTORNO

    La variable de entorno GZIP puede contener un conjunto de opciones predeterminadas para gzip. Estas opciones se interpretan primero y pueden ser anuladas por parámetros explícitos en la línea de comandos. Como esto puede causar problemas al usar scripts, esta característica se soporta solo para --rsyncable, --synchronous, y opciones como -9 que establecen el nivel de compresión; cualquier otra opción u operando en GZIP es ignorada silenciosamente.

    Puede usar un alias o script en su lugar. Por ejemplo, en lugar de establecer GZIP="-9" en el entorno, si gzip está en el directorio /usr/bin puede anteponer $HOME/bin a su PATH y crear un script ejecutable $HOME/bin/gzip que contenga lo siguiente:


    #! /bin/sh
    export PATH=/usr/bin
    exec gzip -9 "$@"

    DIAGNÓSTICOS

    El estado de salida es normalmente 0; si ocurre un error, el estado de salida es 1. Si ocurre una advertencia, el estado de salida es 2.

    Uso: gzip [-cdfhklLnNrtvV19] [-S suffix] [file ...]
    Se especificaron opciones inválidas en la línea de comandos.
    file: not in gzip format
    El archivo especificado para gunzip no ha sido comprimido.
    file: Corrupt input.
    Use zcat para recuperar algunos datos. El archivo comprimido ha sido dañado. Los datos hasta el punto de fallo pueden ser recuperados usando


    zcat file > recover

    file: compressed with xx bits, can only handle yy bits
    File was compressed (using LZW) by a program that could deal with more bits than the decompress code on this machine. Recompress the file with gzip, which compresses better and uses less memory.
    file: already has .gz suffix -- unchanged
    Se asume que el archivo ya está comprimido. Renombre el archivo e intente de nuevo.
    file already exists; do you wish to overwrite (y or n)?
    Responda "y" si desea que el archivo de salida sea reemplazado; "n" si no.
    gunzip: corrupt input
    Se detectó una violación SIGSEGV, lo que generalmente significa que el archivo de entrada ha sido corrompido.
    xx.x% Porcentaje de la entrada ahorrada por la compresión.
    (Relevante solo para -v y -l.)
    -- not a regular file or directory: ignored
    Cuando el archivo de entrada no es un archivo normal o directorio, (por ejemplo, un enlace simbólico, socket, FIFO, archivo de dispositivo), se deja sin alterar.
    -- has xx other links: unchanged
    El archivo de entrada tiene enlaces; se deja sin cambios. Vea ln(1) para más información. Use el -f indicador para forzar la compresión de archivos con múltiples enlaces.

    ADVERTENCIAS

    Al escribir datos comprimidos en una cinta, generalmente es necesario rellenar la salida con ceros hasta un límite de bloque. Cuando se leen los datos y todo el bloque se pasa a gunzip para descomprimir, gunzip detecta que hay basura adicional al final después de los datos comprimidos y emite una advertencia por defecto. Puede usar la opción --quiet para suprimir la advertencia.

    ERRORES

    En algunos casos raros, la opción --best da una peor compresión que el nivel de compresión predeterminado (-6). En algunos archivos altamente redundantes, compress comprime mejor que gzip.
