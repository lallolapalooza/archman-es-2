NOMBRE

kubeadm config migrate - Lee tipos de API de configuración de kubeadm de versiones anteriores de un archivo, y genera el objeto de configuración similar para la versión más reciente.

SINOPSIS

kubeadm config migrate [OPCIONES]

DESCRIPCIÓN

Este comando te permite convertir objetos de configuración de versiones anteriores a la última versión admitida, localmente en la herramienta de línea de comandos sin tocar nada en el clúster. En esta versión de kubeadm, las siguientes versiones de API son compatibles: - kubeadm.k8s.io/v1beta4.

Además, kubeadm solo puede generar configuraciones de la versión "kubeadm.k8s.io/v1beta4", pero puede leer ambos tipos. Por lo tanto, independientemente de la versión que pases al parámetro --old-config aquí, el objeto de API se leerá, deserializará, se completarán los valores predeterminados, se convertirá, se validará y se volverá a serializar al escribir en la salida estándar o en --new-config si se especifica.

En otras palabras, la salida de este comando es lo que kubeadm realmente leería internamente si presentaras este archivo a "kubeadm init".

OPCIONES

--allow-experimental-api=false Permite la migración a APIs experimentales y no publicadas.

--new-config="" Ruta al archivo de configuración de kubeadm resultante equivalente que utiliza la nueva versión de API. Opcional, si no se especifica, la salida se enviará a STDOUT.

--old-config="" Ruta al archivo de configuración de kubeadm que utiliza una versión de API antigua y que debe ser convertido. Esta bandera es obligatoria.

OPCIONES HEREDADAS DE COMANDOS PADRE

--kubeconfig="/etc/kubernetes/admin.conf" El archivo kubeconfig a usar al comunicarse con el clúster. Si la bandera no está configurada, se puede buscar un archivo kubeconfig existente en una serie de ubicaciones estándar.

--rootfs="" La ruta al sistema de archivos raíz 'real' del host. Esto hará que kubeadm realice un chroot en la ruta proporcionada.

--version=false --version, --version=raw imprime información de versión y sale; --version=vX.Y.Z... establece la versión reportada.
