NOMBRE

kube-proxy -

SINOPSIS

kube-proxy [OPCIONES]

DESCRIPCIÓN

El proxy de red de Kubernetes se ejecuta en cada nodo. Refleja los servicios definidos en la API de Kubernetes en cada nodo y puede realizar reenvío simple de flujos TCP, UDP y SCTP o reenvío TCP, UDP y SCTP de ronda ronda a través de un conjunto de backends. Las IPs y puertos del clúster de servicios se encuentran actualmente a través de variables de entorno compatibles con Docker-links que especifican puertos abiertos por el proxy del servicio. Existe un complemento opcional que proporciona DNS del clúster para estas IPs del clúster. El usuario debe crear un servicio con la API apiserver para configurar el proxy.

OPCIONES

--allow_dynamic_housekeeping=true Si se permite que el intervalo de mantenimiento sea dinámico

--application_metrics_count_limit=100 Número máximo de métricas de aplicación a almacenar (por contenedor)

--bind-address=0.0.0.0 Anula la idea de kube-proxy de cuál es la IP principal de su nodo. Tenga en cuenta que el nombre es un artefacto histórico y kube-proxy en realidad no enlaza ningún socket a esta IP. Este parámetro se ignora si se especifica un archivo de configuración mediante --config.

--bind-address-hard-fail=false Si es verdadero, kube-proxy tratará el fallo al enlazar a un puerto como fatal y saldrá

--boot_id_file="/proc/sys/kernel/random/boot_id" Lista separada por comas de archivos a comprobar para obtener el boot-id. Utiliza el primero que exista.

--cleanup=false Si es verdadero, limpia las reglas de iptables e ipvs y sale.

--cluster-cidr="" El rango CIDR de los pods en el clúster. (Para clústeres de doble pila, este puede ser un par de rangos CIDR de doble pila separados por comas). Cuando --detect-local-mode se establece en ClusterCIDR, kube-proxy considerará que el tráfico es local si su IP de origen está en este rango. (De lo contrario, no se utiliza). Este parámetro se ignora si se especifica un archivo de configuración mediante --config.

--config="" La ruta al archivo de configuración.

--config-sync-period=15m0s Con qué frecuencia se actualiza la configuración del servidor de API. Debe ser mayor que 0.

--conntrack-max-per-core=32768 Número máximo de conexiones NAT a rastrear por núcleo de CPU (0 para dejar el límite tal cual e ignorar conntrack-min).

--conntrack-min=131072 Número mínimo de entradas conntrack a asignar, independientemente de conntrack-max-per-core (establezca conntrack-max-per-core=0 para dejar el límite tal cual).

--conntrack-tcp-be-liberal=false Habilita el modo liberal para rastrear paquetes TCP estableciendo nf_conntrack_tcp_be_liberal en 1

--conntrack-tcp-timeout-close-wait=1h0m0s Tiempo de espera NAT para conexiones TCP en el estado CLOSE_WAIT

--conntrack-tcp-timeout-established=24h0m0s Tiempo de espera inactivo para conexiones TCP establecidas (0 para dejar tal cual)

--conntrack-udp-timeout=0s Tiempo de espera inactivo para conexiones UDP SIN RESPUESTA (0 para dejar tal cual)

--conntrack-udp-timeout-stream=0s Tiempo de espera inactivo para conexiones UDP ASEGURADAS (0 para dejar tal cual)

--container_hints="/etc/cadvisor/container_hints.json" ubicación del archivo de sugerencias de contenedores

--containerd="/run/containerd/containerd.sock" punto final de containerd

--containerd-namespace="k8s.io" espacio de nombres de containerd

--containerd_env_metadata_whitelist="" OBSOLETO: esta bandera se eliminará, use env_metadata_whitelist. Una lista separada por comas de claves de variables de entorno que coinciden con el prefijo especificado que necesita ser recopilado para contenedores containerd

--crio_client_timeout=0s Tiempo de espera del cliente CRI-O. El valor predeterminado es sin tiempo de espera.

--detect-local-mode= Modo a utilizar para detectar tráfico local. Este parámetro se ignora si se especifica un archivo de configuración mediante --config.

--disable_root_cgroup_stats=false Deshabilita la recopilación de estadísticas del Cgroup raíz

--docker_only=false Solo informa contenedores de docker además de las estadísticas raíz

--enable_load_reader=false Si se habilita el lector de carga de CPU

--event_storage_age_limit="default=0" Duración máxima para la que se almacenarán los eventos (por tipo). El valor es una lista separada por comas de pares clave-valor, donde las claves son tipos de eventos (por ejemplo: creation, oom) o "default" y el valor es una duración. El valor predeterminado se aplica a todos los tipos de eventos no especificados

--event_storage_event_limit="default=0" Número máximo de eventos a almacenar (por tipo). El valor es una lista separada por comas de pares clave-valor, donde las claves son tipos de eventos (por ejemplo: creation, oom) o "default" y el valor es un número entero. El valor predeterminado se aplica a todos los tipos de eventos no especificados

OPTIONS

--show-hidden-metrics-for-version="" La versión anterior para la que desea mostrar métricas ocultas. Solo la versión menor anterior tiene sentido, otros valores no se permitirán. El formato es ., por ejemplo: '1.16'. El propósito de este formato es asegurar que tenga la oportunidad de notar si la próxima versión oculta métricas adicionales, en lugar de sorprenderse cuando se eliminen permanentemente en la versión posterior. Este parámetro se ignora si se especifica un archivo de configuración con --config.

--storage_driver_buffer_duration=1m0s Las escrituras en el controlador de almacenamiento se almacenarán en búfer durante esta duración y se confirmarán en los backends que no sean de memoria como una única transacción.

--storage_driver_db="cadvisor" nombre de la base de datos

--storage_driver_host="localhost:8086" host:puerto de la base de datos

--storage_driver_password="root" contraseña de la base de datos

--storage_driver_secure=false utilizar conexión segura con la base de datos

--storage_driver_table="stats" nombre de la tabla

--storage_driver_user="root" nombre de usuario de la base de datos

--update_machine_info_interval=5m0s Intervalo entre actualizaciones de información de la máquina.

-v, --v=0 número para la verbosidad del nivel de registro

--version=false --version, --version=raw imprime información de versión y sale; --version=vX.Y.Z... establece la versión informada

--vmodule= lista separada por comas de patrones=N para el registro filtrado por archivo (solo funciona para el formato de registro de texto)

--write-config-to="" Si se establece, escriba los valores de configuración predeterminados en este archivo y salga.
