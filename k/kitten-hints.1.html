Nombre

kitten-hints - Seleccionar texto de la pantalla con el teclado

Descripción general

kitty tiene un modo de sugerencias para seleccionar y actuar sobre fragmentos de texto arbitrarios visibles actualmente en la pantalla. Por ejemplo, puedes presionar ctrl+shift+e <#shortcut-kitty.Open-URL> para elegir cualquier URL visible en la pantalla y luego abrirlo usando tu navegador web predeterminado.

Modo de sugerencias de URL (imágenes no soportadas)

De manera similar, puedes presionar ctrl+shift+p>f <#shortcut-kitty.Insert-selected-path> para seleccionar cualquier cosa que parezca una ruta o nombre de archivo e insertarla en la terminal, muy útil para elegir archivos de la salida de un comando git o ls y agregarlos a la línea de comandos para el siguiente comando.

También puedes presionar ctrl+shift+p>n <#shortcut-kitty.Open-the-selected-file-at-the-selected-line> para seleccionar cualquier cosa que parezca una ruta o nombre de archivo seguido de dos puntos y un número de línea, y abrir el archivo en tu editor predeterminado en el número de línea especificado (abrir en el número de línea solo funcionará si tu editor soporta la sintaxis de comando +linenum o es un editor "conocido"). Los patrones y el editor a utilizar se pueden modificar usando opciones pasadas al kitten. Por ejemplo:

map ctrl+g kitten hints --type=linenum --linenum-action=tab nvim +{line} {path}

abrirá el archivo seleccionado en una nueva pestaña dentro de Neovim https://neovim.io/ cuando presiones Ctrl+G.

Presionar ctrl+shift+p>y <#shortcut-kitty.Open-the-selected-hyperlink> abrirá hipervínculos <#term-hyperlinks>, es decir, una URL que ha sido marcada como tal por el programa que se ejecuta en la terminal, por ejemplo, mediante ls --hyperlink=auto. Si ls que viene con tu sistema operativo no soporta hipervínculos, es posible que necesites instalar GNU Coreutils https://www.gnu.org/software/coreutils/.

También puedes personalizar qué acciones se toman para diferentes tipos de URLs <>.

Nota:

Si hay más sugerencias que letras, las sugerencias usarán múltiples letras. En este caso, cuando presiones la primera letra, solo se mostrarán las sugerencias que comienzan con esa letra. Presionar la segunda letra seleccionará esa sugerencia o presiona Enter o Espacio para seleccionar la sugerencia vacía.

Para los amantes del ratón, el kitten de sugerencias también te permite hacer clic en cualquier texto coincidente para seleccionarlo en lugar de escribir el carácter de sugerencia.

El kitten de sugerencias es muy potente. Para ver ayuda más detallada sobre sus diversas opciones y modos de operación, consulta a continuación. Puedes usar estas opciones para crear mapeos en kitty.conf para seleccionar varios fragmentos de texto diferentes. Consulta insert_selected_path <#shortcut-kitty.Insert-selected-path> para ver ejemplos.

Personalización completa de la coincidencia y las acciones del kitten

El kitten de sugerencias soporta la escritura de scripts sencillos de Python que pueden utilizarse para personalizar completamente cómo encuentra coincidencias y qué sucede cuando se selecciona una coincidencia. Esto permite que el kitten de sugerencias proporcione la interfaz de usuario, mientras que tú puedes proporcionar la lógica para encontrar coincidencias y realizar acciones sobre ellas. Esto se ilustra mejor con un ejemplo. Crea el archivo custom-hints.py en el directorio de configuración de kitty <#confloc> con el siguiente contenido:

import re
def mark(text, args, Mark, extra_cli_args, *a):
    # Esta función es responsable de encontrar todo
    # texto coincidente. extra_cli_args son cualesquiera argumentos adicionales
    # pasados en la línea de comandos al invocar el kitten.
    # Marcamos cada palabra individual para posible selección
    for idx, m in enumerate(re.finditer(r'\w+', text)):
        start, end = m.span()
        mark_text = text[start:end].replace('\n', '').replace('\0', '')
        # El diccionario vacío a continuación estará disponible como groupdicts
        # en handle_result() y puede contener claves de cadena y valores arbitrarios serializables en JSON.
        yield Mark(idx, start, end, mark_text, {})
def handle_result(args, data, target_window_id, boss, extra_cli_args, *a):
    # Esta función es responsable de realizar alguna
    # acción sobre el texto seleccionado.
    # matches es una lista de las entradas seleccionadas y groupdicts contiene
    # los datos arbitrarios asociados con cada entrada en mark() arriba
    matches, groupdicts = [], []
    for m, g in zip(data['match'], data['groupdicts']):
        if m:
            matches.append(m), groupdicts.append(g)
    for word, match_data in zip(matches, groupdicts):
        # Busca la palabra en un diccionario, la función open_url
        # abrirá la url proporcionada en el navegador del sistema
        boss.open_url(f'https://www.google.com/search?q=define:{word}')

Ahora ejecuta kitty con:

kitty -o 'map f1 kitten hints --customize-processing custom-hints.py'

Cuando presiones la tecla F1, podrás seleccionar una palabra para buscarla en el diccionario de Google.

Código fuente de las sugerencias

El código fuente de este kitten está disponible en GitHub https://github.com/kovidgoyal/kitty/tree/master/kittens/hints.

Interfaz de línea de comandos

kitten hints [opciones]

Seleccionar texto de la pantalla usando el teclado. Por defecto, busca URLs.

Opciones

--program <PROGRAMA>
Qué programa usar para abrir el texto coincidente. Por defecto, el programa de apertura predeterminado del sistema operativo. Se soportan varios valores especiales:
-
pegar la coincidencia en la ventana de la terminal.
@
copiar la coincidencia al portapapeles
*
copiar la coincidencia a la selección primaria (en sistemas que soportan selecciones primarias)
@NOMBRE
copiar la coincidencia al buffer especificado, por ejemplo, @a
default
ejecutar el programa de apertura predeterminado. Ten en cuenta que al usar el hipervínculo --type, el valor predeterminado es usar las instalaciones de manejo de hipervínculos de kitty <>.
launch
ejecutar el comando launch <> para abrir el programa en una nueva pestaña, ventana, overlay, etc. de kitty. Por ejemplo:
--program "launch --type=tab vim"

Puede especificarse varias veces para ejecutar varios programas.

--type <TIPO>
El tipo de texto a buscar. Un valor de linenum es especial, busca mensajes de error usando el patrón especificado con --regex, que debe tener los grupos nombrados: path y line. Si no se especifica, buscará path:line. La opción --linenum-action controla dónde mostrar el mensaje de error seleccionado; las demás opciones se ignoran. Por defecto: url. Opciones: hash, hyperlink, ip, line, linenum, path, regex, url, word
--regex <REGEX>
La expresión regular a usar cuando la opción --type se establece en regex, en sintaxis Perl 5. Si especificas un grupo numerado en la expresión regular, solo se coincidirá el grupo. Esto te permite hacer coincidir texto ignorando un prefijo/sufijo, según sea necesario. La expresión predeterminada coincide con líneas. Para hacer coincidir texto en varias líneas, las cosas se vuelven un poco complicadas, ya que los finales de línea son una secuencia de cero o más bytes nulos seguidos de un retorno de carro o un carácter de nueva línea. Para que un patrón coincida a través de finales de línea, necesitarás coincidir con el conjunto de caracteres [\0\r\n]. Las nuevas líneas y los bytes nulos se eliminan automáticamente del texto devuelto. Si especificas grupos nombrados y un --program, entonces al programa se le pasarán argumentos

correspondientes a cada grupo con nombre de la forma clave=valor. Predeterminado: (?m)^\s*(.+?)\s*$
--linenum-action <ACCION_NUMERO_LINEA>
Dónde realizar la acción sobre los errores coincidentes. self significa la ventana actual, window una nueva ventana de kitty, tab una nueva pestaña, os_window una nueva ventana del sistema operativo y background ejecutar en segundo plano. remote-control es como background, pero el programa puede usar el control remoto de kitty sin necesidad de activar el control remoto globalmente. La acción real son los argumentos proporcionados al kitten, por ejemplo: kitten hints --type=linenum --linenum-action=tab vim +{line} {path} abrirá la ruta coincidente en el número de línea coincidente en vim en una nueva pestaña de kitty. Tenga en cuenta que para usar --program para copiar o pegar los argumentos proporcionados, debe utilizar el valor especial self. Predeterminado: self Opciones: background, os_window, remote-control, self, tab, window
--url-prefixes <PREFIJOS_URL>
Lista separada por comas de prefijos de URL reconocidos. Predeterminado para la lista de prefijos definida por la opción url_prefixes <#opt-kitty.url_prefixes> en kitty.conf. Predeterminado: default
--url-excluded-characters <CARACTERES_EXCLUIDOS_URL>
Caracteres a excluir al hacer coincidir URLs. Predeterminado para la lista de caracteres definida por la opción url_excluded_characters <#opt-kitty.url_excluded_characters> en kitty.conf. La sintaxis de esta opción es la misma que para url_excluded_characters <#opt-kitty.url_excluded_characters>. Predeterminado: default
--word-characters <CARACTERES_PALABRA>
Caracteres a considerar como parte de una palabra. Además, todos los caracteres marcados como alfanuméricos en la base de datos Unicode se considerarán caracteres de palabra. Predeterminado para la opción select_by_word_characters <#opt-kitty.select_by_word_characters> de kitty.conf.
--minimum-match-length <LONGITUD_MINIMA_COINCIDENCIA>
El número mínimo de caracteres para considerar una coincidencia. Predeterminado: 3
--multiple [=no]
Selecciona múltiples coincidencias y realiza la acción sobre todas ellas juntas al final. En este modo, presiona Esc para terminar de seleccionar.
--multiple-joiner <UNIDOR_MULTIPLE>
Cadena para unir múltiples selecciones al copiar al portapapeles o insertar en la terminal. Los valores especiales son: space - un carácter de espacio, newline - un salto de línea, empty - un unidor vacío, json - una lista serializada en JSON, auto - una elección automática, basada en el tipo de texto que se está seleccionando. Además, los enteros se interpretan como índices basados en cero en la lista de selecciones. Puedes usar 0 para la primera selección y -1 para la última. Predeterminado: auto
--add-trailing-space <ANADIR_ESPACIO_FINAL>
Añade un espacio al final del texto coincidente. Predeterminado auto, que añade el espacio cuando se usa junto con --multiple. Predeterminado: auto Opciones: always, auto, never
--hints-offset <DESPLAZAMIENTO_HINTS>
El desplazamiento (desde cero) en el que comenzar la numeración de las pistas. Tenga en cuenta que solo se respetan los números mayores o iguales a cero. Predeterminado: 1
--alphabet <ALFABETO>
La lista de caracteres a utilizar para las pistas. El valor predeterminado es usar números y alfabetos ingleses en minúsculas. Especifica tu preferencia como una cadena de caracteres. Ten en cuenta que necesitas especificar --hints-offset como cero para usar el primer carácter para resaltar la primera coincidencia, de lo contrario, comenzará con el segundo carácter por defecto.
--ascending [=no]
Hace que las pistas aumenten de arriba a abajo, en lugar de disminuir de arriba a abajo.
--hints-foreground-color <COLOR_PRIMARIO_HINTS>
El color del texto para las pistas. Puedes usar nombres de colores o valores hexadecimales. Para los ocho colores básicos con nombre del terminal, también puedes usar el prefijo bright- para obtener la variante brillante del color. Predeterminado: black
--hints-background-color <COLOR_FONDO_HINTS>
El color de fondo para las pistas. Puedes usar nombres de colores o valores hexadecimales. Para los ocho colores básicos con nombre del terminal, también puedes usar el prefijo bright- para obtener la variante brillante del color. Predeterminado: green
--hints-text-color <COLOR_TEXTO_HINTS>
El color del texto para el texto al que apuntan las pistas. Puedes usar nombres de colores o valores hexadecimales. Para los ocho colores básicos con nombre del terminal, también puedes usar el prefijo bright- para obtener la variante brillante del color. El valor predeterminado es elegir automáticamente un color adecuado. Predeterminado: auto
--customize-processing <PERSONALIZAR_PROCESAMIENTO>
Nombre de un archivo de python en el directorio de configuración de kitty que se importará para proporcionar implementaciones personalizadas para la búsqueda de patrones y la ejecución de acciones sobre coincidencias seleccionadas. También puedes especificar rutas absolutas para cargar el script desde otro lugar. Ver https://sw.kovidgoyal.net/kitty/kittens/hints/ para más detalles.
--window-title <TITULO_VENTANA>
El título de la ventana de pistas, el título predeterminado se basa en el tipo de texto que se está señalando.

Nota:

Para evitar tener que especificar las mismas opciones de línea de comandos en cada invocación, puedes usar la opción action_alias <#opt-kitty.action_alias> en kitty.conf, creando alias que tengan conjuntos comunes de opciones. Por ejemplo: 
action_alias myhints kitten hints --alphabet qfjdkslaureitywovmcxzpq1234567890
map f1 myhints --customize-processing custom-hints.py
