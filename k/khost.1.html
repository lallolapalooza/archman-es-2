NOMBRE

khost - Utilidad simple de consulta DNS

SINOPSIS

khost [opciones] nombre [servidor]

DESCRIPCIÓN

Esta utilidad envía una consulta DNS para el nombre al servidor e imprime una respuesta de forma más legible para el usuario. Para consultas DNS más avanzadas, utilice kdig en su lugar.

Parámetros

nombre
Es un nombre de dominio que se va a buscar. Si el nombre es una dirección IPv4 o IPv6, se utiliza el tipo de consulta PTR.
servidor
Es un nombre o una dirección del servidor de nombres al que enviar una consulta. La dirección se puede especificar usando la notación [dirección]:puerto. Si no se especifica ningún servidor, se utilizan los servidores de /etc/resolv.conf.

Si no se proporcionan argumentos, khost imprime una ayuda breve.

Opciones

-4
Utilizar solo el protocolo IPv4.
-6
Utilizar solo el protocolo IPv6.
-a
Enviar consulta ANY con modo detallado.
-d
Habilitar mensajes de depuración.
-h, --help
Imprimir la ayuda del programa.
-r
Deshabilitar recursión.
-T
Utilizar el protocolo TCP.
-v
Habilitar salida detallada.
-V, --version
Imprimir la versión del programa. La opción -VV hace que el programa imprima el resumen de la configuración de compilación.
-w
Esperar para siempre la respuesta.
-c clase
Establecer la clase de consulta (por ejemplo, CH, CLASS4). La clase predeterminada es IN.
-t tipo
Establecer el tipo de consulta (por ejemplo, NS, IXFR=12345, TYPE65535). El valor predeterminado es enviar 3 consultas (A, AAAA y MX).
-R reintentos
El número (>=0) de reintentos UDP para consultar un servidor de nombres. El valor predeterminado es 1.
-W espera
El tiempo de espera de una respuesta en segundos. Este tiempo de espera se aplica a cada intento de consulta. El valor predeterminado es 2 segundos.

VALORES DE SALIDA

Un estado de salida de 0 significa operación exitosa. Cualquier otro estado de salida indica un error.

EJEMPLOS

1.
Obtener los registros A, AAAA y MX para example.com:
$ khost example.com
2.
Obtener el registro inverso para la dirección 192.0.2.1:
$ khost 192.0.2.1
3.
Realizar una transferencia de zona detallada para la zona example.com:
$ khost -t AXFR -v example.com

ARCHIVOS
