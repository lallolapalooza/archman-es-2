keyctl_set_reqkey_keyring(3)

Paquete: keyutils

Licencias: GPL2, LGPL2.1

KEYCTL_SET_REQKEY_KEYRING(3) Llamadas de gestión de claves de Linux KEYCTL_SET_REQKEY_KEYRING(3)

NOMBRE

keyctl_set_reqkey_keyring - establece el keyring de destino implícito

SINOPSIS

#include <keyutils.h>

long keyctl_set_reqkey_keyring(int reqkey_defl);

DESCRIPCIÓN

keyctl_set_reqkey_keyring() establece el keyring de destino predeterminado para las solicitudes de claves implícitas para el hilo actual y devuelve la configuración anterior.

Después de emitir esta operación, las claves adquiridas por solicitudes de claves implícitas, como las que podría realizar open() en un sistema de archivos AFS o NFS, se vincularán por defecto al keyring especificado por esta función.

Los valores válidos de reqkey_defl son:

KEY_REQKEY_DEFL_NO_CHANGE
Esto no cambia la configuración actual.
KEY_REQKEY_DEFL_THREAD_KEYRING
Esto hace que el keyring específico del hilo sea el destino predeterminado.
KEY_REQKEY_DEFL_PROCESS_KEYRING
Esto hace que el keyring específico del proceso sea el destino predeterminado.
KEY_REQKEY_DEFL_SESSION_KEYRING
Esto hace que el keyring de sesión sea el destino predeterminado.
KEY_REQKEY_DEFL_USER_KEYRING
Esto hace que el keyring específico del UID sea el destino predeterminado.
KEY_REQKEY_DEFL_USER_SESSION_KEYRING
Esto hace que el keyring de sesión específico del UID sea el destino predeterminado.
KEY_REQKEY_DEFL_DEFAULT
Esto selecciona el comportamiento predeterminado, que es usar el keyring específico del hilo si existe, de lo contrario el keyring específico del proceso si existe, de lo contrario el keyring de sesión si existe, de lo contrario el keyring de sesión específico del UID.

Esta configuración se hereda a través de fork() y exec().

VALOR DE RETORNO

En caso de éxito, keyctl_set_reqkey_keyring() devuelve el número de serie del keyring que era el predeterminado anterior para el hilo actual. En caso de error, se devolverá el valor -1 y errno se habrá establecido con un error apropiado.

ERRORES

EINVAL
El valor de reqkey_defl es inválido.

ENLAZADO

Esta es una función de biblioteca que se puede encontrar en libkeyutils. Al enlazar, se debe especificar -lkeyutils al enlazador.
