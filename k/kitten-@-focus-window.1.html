Nombre

kitten-@-focus-window - Enfoca la ventana especificada

Uso

kitten @ focus-window

Descripción

Enfoca la ventana especificada. Si no se especifica ninguna ventana, enfoca la ventana en la que se ejecuta este comando.

Opciones

--match, -m
La ventana a emparejar. Las especificaciones de ventana son de la forma: campo:consulta. Donde campo puede ser uno de: id, title, pid, cwd, cmdline, num, env, var, state, neighbor, session y recent. Consulta es la expresión a emparejar. Las expresiones pueden ser un número o una expresión regular, y pueden combinarse mediante operadores booleanos.

El valor especial all empareja todas las ventanas.

Para campos numéricos: id, pid, num y recent, la expresión se interpreta como un número, no como una expresión regular. Los valores negativos para id emparejan desde el número de id más alto hacia abajo, en particular, -1 es la ventana creada más recientemente.

El campo num se refiere a la posición de la ventana en la pestaña actual, comenzando desde cero y contando en sentido horario (este es el mismo orden en que las ventanas son reportadas por el comando kitten @ ls).

El id de ventana de la ventana actual está disponible como la variable de entorno KITTY_WINDOW_ID.

El campo recent se refiere a las ventanas activadas recientemente en la pestaña activa actual, siendo cero la ventana activa actual, uno la ventana activada previamente y así sucesivamente.

El campo neighbor se refiere a un vecino de la ventana activa en la dirección especificada, que puede ser: left, right, top o bottom.

El campo session empareja ventanas que se crearon en la sesión especificada. Utilice la expresión ^$ para emparejar ventanas que no se crearon en una sesión y . para emparejar la sesión activa actual y ~ para emparejar ya sea la sesión activa actual o la última sesión activa cuando no hay ninguna sesión activa.

Al usar el campo env para emparejar variables de entorno, puede especificar solo el nombre de la variable de entorno o un nombre y valor, por ejemplo, env:MY_ENV_VAR=2.

De manera similar, el campo var empareja variables de usuario establecidas en la ventana. Puede especificar el nombre o el nombre y el valor, como con el campo env.

El campo state empareja el estado de la ventana. Los estados soportados son: active, focused, needs_attention, parent_active, parent_focused, focused_os_window, self, overlay_parent. Las ventanas activas son las ventanas que están activas en su pestaña padre. Solo hay una ventana enfocada y es la ventana a la que se entregan los eventos del teclado. Si no hay ninguna ventana enfocada, se empareja la última ventana enfocada. El valor focused_os_window empareja todas las ventanas en la ventana del sistema operativo enfocada actualmente. El valor self empareja la ventana en la que se ejecuta el comando de control remoto. El valor overlay_parent empareja la ventana que está debajo de la ventana self, cuando la ventana self es una superposición.

Tenga en cuenta que puede utilizar el comando kitten @ ls para obtener una lista de ventanas.

--no-response [=no]
No espere una respuesta de kitty. Esto significa que incluso si no se encuentra ninguna ventana coincidente, el comando saldrá con un código de éxito.
--help, -h [=no]
Mostrar ayuda para este comando

Opciones globales

--to
Una dirección para que la instancia de kitty la controle. Corresponde a la dirección dada a la instancia de kitty a través de la opción --listen-on o la configuración listen_on en kitty.conf. Si no se especifica, se verifica la variable de entorno KITTY_LISTEN_ON. Si tampoco se encuentra, los mensajes se envían al terminal de control para este proceso, es decir, solo funcionarán si este proceso se ejecuta dentro de una ventana de kitty.
--password
Una contraseña para usar al contactar a kitty. Esto hará que kitty solicite al usuario permiso para realizar la acción especificada, a menos que la contraseña haya sido aceptada previamente o esté preconfigurada en kitty.conf. Para usar una contraseña en blanco, especifique --use-password como siempre.
--password-file [=rc-pass]
Un archivo del que leer la contraseña. Se ignoran los espacios en blanco finales. Las rutas relativas se resuelven desde el directorio de configuración de kitty. Utilice - para leer desde STDIN. Utilice fd:num para leer desde el descriptor de archivo num. Se usa si no se proporciona ningún --password. Por defecto, busca el archivo rc-pass en el directorio de configuración de kitty.
--password-env [=KITTY_RC_PASSWORD]
El nombre de una variable de entorno de la que leer la contraseña. Se usa si no se proporciona ningún --password-file. Por defecto, verifica la variable de entorno KITTY_RC_PASSWORD.
--use-password [=if-available]
Si no hay contraseña disponible, kitty generalmente enviará el comando de control remoto sin contraseña. Esta opción se puede usar para forzar el uso de la contraseña proporcionada siempre o nunca. Si se establece en always y no se proporciona ninguna contraseña, se utiliza la contraseña en blanco.

Opciones: if-available, always, never
