Nombre

kitten-@-env - Cambia las variables de entorno vistas por los futuros hijos

Uso

kitten @ env env_var1=val env_var2=val ...

Descripción

Cambia las variables de entorno que serán vistas en las ventanas recién lanzadas. Similar a la opción env en kitty.conf, pero afecta a las instancias de kitty en ejecución. Si no está presente el signo =, la variable se elimina del entorno.

Opciones

--help, -h [=no]
Muestra la ayuda para este comando

Opciones globales

--to
Una dirección para la instancia de kitty a controlar. Corresponde a la dirección proporcionada a la instancia de kitty a través de la opción --listen-on o la configuración listen_on en kitty.conf. Si no se especifica, se comprueba la variable de entorno KITTY_LISTEN_ON. Si tampoco se encuentra, los mensajes se envían a la terminal controladora para este proceso, es decir, solo funcionarán si este proceso se ejecuta dentro de una ventana de kitty.
--password
Una contraseña para usar al contactar a kitty. Esto hará que kitty solicite al usuario permiso para realizar la acción especificada, a menos que la contraseña haya sido aceptada previamente o esté preconfigurada en kitty.conf. Para usar una contraseña vacía, especifique --use-password as always.
--password-file [=rc-pass]
Un archivo del cual leer la contraseña. Se ignoran los espacios en blanco finales. Las rutas relativas se resuelven desde el directorio de configuración de kitty. Utilice - para leer desde STDIN. Utilice fd:num para leer desde el descriptor de archivo num. Se usa si no se proporciona --password. Por defecto, busca el archivo rc-pass en el directorio de configuración de kitty.
--password-env [=KITTY_RC_PASSWORD]
El nombre de una variable de entorno de la cual leer la contraseña. Se usa si no se proporciona --password-file. Por defecto, comprueba la variable de entorno KITTY_RC_PASSWORD.
--use-password [=if-available]
Si no hay contraseña disponible, kitty normalmente enviará el comando de control remoto sin contraseña. Esta opción se puede usar para forzar el uso de la contraseña proporcionada siempre o nunca. Si se establece en always y no se proporciona ninguna contraseña, se utiliza la contraseña vacía.

Opciones: if-available, always, never
