Nombre

kitten-@-set-enabled-layouts - Establece los diseños habilitados en las pestañas

Uso

kitten @ set-enabled-layouts LAYOUT ...

Descripción

Establece los diseños habilitados en las pestañas especificadas (o la pestaña activa si no se especifica). Puedes usar el valor especial de coincidencia `all` para establecer los diseños habilitados en todas las pestañas. Si el diseño actual de la pestaña no está incluido en los diseños habilitados, su diseño se cambia al primer diseño habilitado.

Opciones

--match, -m
La pestaña a coincidir. Las especificaciones de coincidencia son del tipo: campo:consulta. Donde campo puede ser uno de: id, index, title, window_id, window_title, pid, cwd, cmdline env, var, state, session y recent. consulta es la expresión a coincidir. Las expresiones pueden ser un número o una expresión regular, y se pueden combinar usando operadores booleanos.

El valor especial `all` coincide con todas las pestañas.

Para campos numéricos: id, index, window_id, pid y recent, la expresión se interpreta como un número, no como una expresión regular. Los valores negativos para id/window_id coinciden desde el número de id más alto hacia abajo, en particular, -1 es la pestaña/ventana creada más recientemente.

Al usar title o id, primero se busca una pestaña coincidente y, si no se encuentra, se busca una ventana coincidente, y se utiliza la pestaña de esa ventana.

También puedes usar window_id y window_title para coincidir con la pestaña que contiene la ventana con el id o título especificado.

El número de índice se utiliza para coincidir con la n-ésima pestaña en la ventana del sistema operativo activa actualmente. El número `recent` coincide con pestañas activas recientemente en la ventana del sistema operativo activa actualmente, siendo cero la pestaña activa actualmente, uno la pestaña activa anteriormente y así sucesivamente.

El campo `session` coincide con pestañas que fueron creadas en la sesión especificada. Usa la expresión `^$` para coincidir con ventanas que no fueron creadas en una sesión y `.` para coincidir con la sesión activa actualmente o `~` para coincidir con la sesión activa actualmente o la última sesión activa cuando no hay ninguna sesión activa.

Al usar el campo `env` para coincidir con variables de entorno, puedes especificar solo el nombre de la variable de entorno o un nombre y valor, por ejemplo, `env:MY_ENV_VAR=2`. Coinciden las pestañas que contienen cualquier ventana con las variables de entorno especificadas. De manera similar, `var` coincide con pestañas que contienen cualquier ventana con la variable de usuario especificada.

El campo `state` coincide con el estado de la pestaña. Los estados admitidos son: active, focused, needs_attention, parent_active, parent_focused y focused_os_window. Las pestañas `active` son las pestañas que están activas en su ventana del sistema operativo padre. Solo hay una pestaña `focused` y es la pestaña a la que se entregan los eventos del teclado. Si ninguna pestaña está enfocada, se coincide con la última pestaña enfocada. El valor `focused_os_window` coincide con todas las pestañas en la ventana del sistema operativo enfocada actualmente.

Ten en cuenta que puedes usar el comando `kitten @ ls` para obtener una lista de pestañas.

--configured [=no]
Cambia el valor predeterminado del diseño habilitado para que el nuevo valor tenga efecto en todas las pestañas recién creadas también.
--help, -h [=no]
Muestra la ayuda para este comando

Opciones globales

--to
Una dirección para la instancia de kitty a controlar. Corresponde a la dirección dada a la instancia de kitty a través de la opción --listen-on o la configuración listen_on en kitty.conf. Si no se especifica, se comprueba la variable de entorno KITTY_LISTEN_ON. Si tampoco se encuentra, los mensajes se envían al terminal de control para este proceso, es decir, solo funcionarán si este proceso se ejecuta dentro de una ventana de kitty.
--password
Una contraseña para usar al contactar con kitty. Esto hará que kitty solicite permiso al usuario para realizar la acción especificada, a menos que la contraseña haya sido aceptada previamente o esté preconfigurada en kitty.conf. Para usar una contraseña vacía, especifique --use-password como siempre.
--password-file [=rc-pass]
Un archivo del que leer la contraseña. Los espacios en blanco finales se ignoran. Las rutas relativas se resuelven desde el directorio de configuración de kitty. Usa - para leer desde STDIN. Usa fd:num para leer desde el descriptor de archivo num. Se utiliza si no se proporciona --password. Por defecto, se comprueba el archivo rc-pass en el directorio de configuración de kitty.
--password-env [=KITTY_RC_PASSWORD]
El nombre de una variable de entorno de la que leer la contraseña. Se utiliza si no se proporciona --password-file. Por defecto, se comprueba la variable de entorno KITTY_RC_PASSWORD.
--use-password [=if-available]
Si no hay contraseña disponible, kitty normalmente enviará el comando de control remoto sin contraseña. Esta opción se puede usar para forzar que siempre o nunca se use la contraseña proporcionada. Si se establece en `always` y no se proporciona contraseña, se utilizará la contraseña vacía.

Opciones: if-available, always, never
