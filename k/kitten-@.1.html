Nombre

kitten-@ - Controlar kitty remotamente

Uso

kitten @ [opciones globales] [subcomando] [opciones del subcomando] [argumentos del subcomando]

Descripción

Controla kitty enviándole comandos. Establece la opción allow_remote_control en kitty.conf para que esto funcione. Cuando se ejecuta sin subcomandos, iniciará un shell interactivo para controlar kitty.

Opciones globales

--to
Una dirección para la instancia de kitty a controlar. Corresponde a la dirección dada a la instancia de kitty a través de la opción --listen-on o la configuración listen_on en kitty.conf. Si no se especifica, se comprueba la variable de entorno KITTY_LISTEN_ON. Si tampoco se encuentra, los mensajes se envían a la terminal de control de este proceso, es decir, solo funcionarán si este proceso se ejecuta dentro de una ventana de kitty.
--password
Una contraseña a usar al contactar con kitty. Esto hará que kitty solicite al usuario permiso para realizar la acción especificada, a menos que la contraseña haya sido aceptada antes o esté preconfigurada en kitty.conf. Para usar una contraseña en blanco, especifica --use-password como siempre.
--password-file [=rc-pass]
Un archivo del cual leer la contraseña. Los espacios en blanco al final se ignoran. Las rutas relativas se resuelven desde el directorio de configuración de kitty. Usa - para leer desde STDIN. Usa fd:num para leer desde el descriptor de archivo num. Se usa si no se proporciona --password. Por defecto, comprueba el archivo rc-pass en el directorio de configuración de kitty.
--password-env [=KITTY_RC_PASSWORD]
El nombre de una variable de entorno de la cual leer la contraseña. Se usa si no se proporciona --password-file. Por defecto, comprueba la variable de entorno KITTY_RC_PASSWORD.
--use-password [=if-available]
Si no hay contraseña disponible, kitty generalmente enviará el comando de control remoto sin contraseña. Esta opción se puede usar para forzar a usar siempre o nunca la contraseña proporcionada. Si se establece en siempre y no se proporciona ninguna contraseña, se utiliza la contraseña en blanco.

Opciones: if-available, always, never
