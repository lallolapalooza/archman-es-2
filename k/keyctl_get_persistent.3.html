NOMBRE

keyctl_get_persistent - obtener el keyring persistente para un usuario

SINOPSIS

#include <keyutils.h>

long keyctl_get_persistent(uid_t uid, key_serial_t keyring);

DESCRIPCIÓN

keyctl_get_persistent() obtiene el keyring persistente para el ID de usuario especificado. A diferencia de los keyrings de sesión y de usuario, este keyring persistirá una vez que todas las sesiones de inicio hayan sido eliminadas y, por lo tanto, pueda usarse para transportar tokens de autenticación para procesos que se ejecutan sin interacción del usuario, como programas iniciados por cron.

El kernel creará el keyring persistente si aún no existe. Cada vez que se llama a esta función, el keyring persistente restablecerá su tiempo de expiración al valor en:

/proc/sys/kernel/keys/persistent_keyring_expiry

(por defecto tres días). Si se alcanza el tiempo de expiración, se eliminará el keyring persistente y todo lo que contenga se podrá eliminar mediante la recolección de basura.

Si uid es -1, se usará el ID de usuario real del proceso que llama. Si uid no es -1, se dará el error EPERM si el ID de usuario solicitado no coincide con los ID de usuario reales o efectivos del llamante, o si el proceso llamante no tiene la capacidad SetUid.

Si tiene éxito, se añadirá un enlace al keyring persistente en keyring.

VALOR DE RETORNO

En caso de éxito, keyctl_get_persistent() devuelve el número de serie del keyring persistente. En caso de error, se devolverá el valor -1 y errno se habrá establecido en un error apropiado.

ERRORES

EPERM
No se permite el acceso al keyring persistente para el uid solicitado.
ENOMEM
Memoria insuficiente para crear el keyring persistente o para extender keyring.
ENOKEY
keyring no existe.
EKEYEXPIRED
keyring ha expirado.
EKEYREVOKED
keyring ha sido revocado.
EDQUOT
El usuario no tiene cuota suficiente para extender keyring.
EACCES
keyring existe, pero no otorga permiso de escritura al proceso llamante.

ENLAZADO

Esta es una función de biblioteca que se puede encontrar en libkeyutils. Al enlazar, se debe especificar -lkeyutils al enlazador.
