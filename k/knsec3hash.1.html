NOMBRE

knsec3hash - Utilidad simple para calcular el hash NSEC3

SINOPSIS

knsec3hash salt algoritmo iteraciones nombre

knsec3hash algoritmo flags iteraciones salt nombre

knsec3hash [-h] [-V]

DESCRIPCIÓN

Esta utilidad genera un hash NSEC3 para un nombre de dominio dado y los parámetros del hash NSEC3.

Parámetros

salt
Especifica una sal binaria codificada como una cadena hexadecimal.
algoritmo
Especifica un algoritmo de hash por número. Actualmente, el único algoritmo soportado es SHA-1 (número 1).
iteraciones
Especifica el número de iteraciones adicionales del algoritmo de hash.
nombre
Especifica el nombre de dominio a hashear.
flags
Especifica los flags de NSEC3 como un entero sin signo.

Opciones

-h, --help
Imprime la ayuda del programa.
-V, --version
Imprime la versión del programa. La opción -VV hace que el programa imprima el resumen de la configuración de compilación.

VALORES DE SALIDA

Un estado de salida de 0 significa operación exitosa. Cualquier otro estado de salida indica un error.

EJEMPLOS

knotc(8), knotd(8).
