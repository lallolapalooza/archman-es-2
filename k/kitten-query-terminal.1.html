Nombre

kitten-query-terminal - Consultar la terminal para diversas capacidades

Uso

kitten query-terminal [opciones] [consulta1 consulta2 ...]

Descripción

Consulta la terminal en la que se ejecuta kitten para diversas capacidades. Esto envía códigos de escape a la terminal y, basándose en su respuesta, imprime datos sobre las capacidades admitidas. Tenga en cuenta que esta es una operación bloqueante, ya que tiene que esperar una respuesta de la terminal. Puede controlar el tiempo máximo de espera con la opción --wait-for.

La salida son líneas del tipo::


consulta: datos

Si una consulta particular no es admitida por la versión de kitty en ejecución, los datos estarán en blanco.

Tenga en cuenta que al llamar a esto desde otro programa, tenga mucho cuidado de no realizar ninguna E/S en el dispositivo de terminal hasta que este kitten finalice.

Las consultas disponibles son:

name:
Nombre de la terminal (por ejemplo, xterm-kitty)

version:
Versión de la terminal (por ejemplo, 0.44.0)

allow_hyperlinks:
La opción de configuración allow_hyperlinks en kitty.conf para permitir hipervínculos puede ser yes, no o ask

font_family:
El nombre PostScript de la fuente actual

bold_font:
El nombre PostScript de la fuente en negrita actual

italic_font:
El nombre PostScript de la fuente en cursiva actual

bold_italic_font:
El nombre PostScript de la fuente en negrita cursiva actual

font_size:
El tamaño de fuente actual en pts

dpi_x:
El DPI actual en el eje x

dpi_y:
El DPI actual en el eje y

foreground:
El color de primer plano actual como un código de color # de 24 bits

background:
El color de fondo actual como un código de color # de 24 bits

background_opacity:
La opacidad de fondo actual como un número entre 0 y 1

clipboard_control:
La opción de configuración clipboard_control en kitty.conf para permitir lecturas/escrituras al/desde el portapapeles

os_name:
El nombre del sistema operativo en el que se ejecuta la terminal. kitty devuelve los valores: bsd, linux, macos, unknown

Opciones

--wait-for [=10]
La cantidad de tiempo (en segundos) para esperar una respuesta de la terminal, después de consultarla.
--help, -h [=no]
Mostrar ayuda para este comando
