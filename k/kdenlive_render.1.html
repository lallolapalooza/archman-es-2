KDENLIVE_RENDER(1) Programa de renderizado para Kdenlive. KDENLIVE_RENDER(1)

NOMBRE

kdenlive_render - Programa de renderizado para Kdenlive.

SINOPSIS

kdenlive_render [-erase] [in=pos] [out=pos] [render] [profile] [rendermodule] [player] [src] [dest] [[arg1] [arg2] ...]

DESCRIPCIÓN

Programa de renderizado para Kdenlive. Renderiza proyectos de kdenlive independientemente de Kdenlive, proporcionando retroalimentación a través de kuiserver. Este programa no está destinado a ser llamado directamente por los usuarios, sino que es llamado desde Kdenlive cuando se inicia un proceso de renderizado.

OPCIONES

Opciones:

-erase
Si está presente, el archivo src se borrará después de renderizar.
in=pos
Inicia el renderizado en la posición del fotograma pos.
out=pos
Finaliza el renderizado en la posición del fotograma pos.
render
Ruta al programa de renderizado MLT melt.
profile
El perfil de video de MLT.
rendermodule
El consumidor de MLT utilizado para renderizar, normalmente es avformat.
player
Ruta al reproductor de video para reproducir una vez finalizado el renderizado, usa '-' para desactivar la reproducción.
src
Archivo de origen - normalmente una lista de reproducción de MLT.
dest
Archivo de destino.
args
Argumentos de libavformat separados por espacios.

AMBIENTE

KDENLIVE_RENDER_LOG
Si $KDENLIVE_RENDER_LOG está configurada, se escribirá un registro en /tmp/kdenlive_render.log.XXXXXXXX, que contiene información sobre el resultado de la llamada a melt, ffmpeg, etc. Esto se puede utilizar para la depuración.

VER TAMBIÉN

Por favor, consulta la página de inicio en http://www.kdenlive.org/
