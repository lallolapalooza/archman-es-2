NOMBRE

kctreemgr - interfaz de línea de comandos para gestionar la base de datos de árbol de archivos

DESCRIPCIÓN

El comando `kctreemgr' es una utilidad para probar y depurar la base de datos de árbol de archivos y sus aplicaciones. `ruta' especifica la ruta de un archivo de base de datos. `clave' especifica la clave de un registro. `valor' especifica el valor de un registro. `archivo' especifica el archivo de entrada/salida.


kctreemgr create [-otr] [-onl|-otl|-onr] [-apow num] [-fpow num] [-ts] [-tl] [-tc] [-bnum num] [-psiz num] [-rcd|-rcld|-rcdd] ruta
Crea un archivo de base de datos.
kctreemgr inform [-onl|-otl|-onr] [-st] ruta
Imprime información de estado.
kctreemgr set [-onl|-otl|-onr] [-add|-app|-rep|-inci|-incd] [-sx] ruta clave valor
Almacena un registro.
kctreemgr remove [-onl|-otl|-onr] [-sx] ruta clave
Elimina un registro.
kctreemgr get [-onl|-otl|-onr] [-rm] [-sx] [-px] [-pz] ruta clave
Imprime el valor de un registro.
kctreemgr list [-onl|-otl|-onr] [-des] [-max num] [-rm] [-sx] [-pv] [-px] ruta [clave]
Imprime claves de todos los registros, separados por saltos de línea.
kctreemgr clear [-onl|-otl|-onr] ruta
Elimina todos los registros de una base de datos.
kctreemgr import [-onl|-otl|-onr] [-sx] ruta [archivo]
Importa registros desde un archivo TSV.
kctreemgr copy [-onl|-otl|-onr] ruta archivo
Copia toda la base de datos.
kctreemgr dump [-onl|-otl|-onr] ruta [archivo]
Exporta registros a un archivo de instantánea.
kctreemgr load [-otr] [-onl|-otl|-onr] ruta [archivo]
Carga registros desde un archivo de instantánea.
kctreemgr defrag [-onl|-otl|-onr] ruta
Realiza desfragmentación.
kctreemgr setbulk [-onl|-otl|-onr] ruta clave valor ...
Almacena registros a la vez.
kctreemgr removebulk [-onl|-otl|-onr] [-sx] ruta clave ...
Elimina registros a la vez.
kctreemgr getbulk [-onl|-otl|-onr] [-sx] [-px] ruta clave ...
Recupera registros a la vez.
kctreemgr check [-onl|-otl|-onr] ruta
Comprueba la consistencia.

Las opciones incluyen lo siguiente.

-otr : abre la base de datos con la opción de truncamiento.
-onl : abre la base de datos con la opción de no bloqueo.
-otl : abre la base de datos con la opción de intentar bloqueo.
-onr : abre la base de datos con la opción de no reparación automática.
-apow num : especifica la potencia de la alineación del tamaño del registro.
-fpow num : especifica la potencia de la capacidad del grupo de bloques libres.
-ts : ajusta la base de datos con la opción pequeña.
-tl : ajusta la base de datos con la opción lineal.
-tc : ajusta la base de datos con la opción de compresión.
-bnum num : especifica el número de cubetas de la tabla hash.
-psiz num : especifica el tamaño de cada página.
-rcd : utiliza el comparador decimal en lugar del léxico.
-rcld : utiliza el comparador léxico descendente en lugar del ascendente.
-rcdd : utiliza el comparador decimal descendente en lugar del léxico.
-st : imprime información miscelánea.
-add : realiza la operación de adición.
-app : realiza la operación de añadir al final.
-rep : realiza la operación de reemplazo.
-inci : realiza la operación de incremento de enteros.
-incd : realiza la operación de incremento de números reales.
-sx : los datos de entrada se evalúan como una cadena de datos hexadecimal.
-rm : elimina el registro.
-px : los datos de salida se convierten en una cadena de datos hexadecimal.
-pz : no añade un salto de línea al final de la salida.
-des : visita los registros en orden descendente.
-max num : especifica el número máximo de registros mostrados.
-pv : también imprime los valores de los registros.

Este comando devuelve 0 en caso de éxito y otro valor en caso de fallo.
