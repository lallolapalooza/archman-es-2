Paquete: krb5

Licencias: custom

KLIST(1) MIT Kerberos KLIST(1)

NOMBRE

klist - listar tickets Kerberos cacheados

SINOPSIS

klist [-e] [[-c] [-l] [-A] [-f] [-s] [-a [-n]]] [-C] [-k [-i] [-t] [-K]] [-V] [-d] [nombre_cache|nombre_keytab]

DESCRIPCIÓN

klist lista el principal de Kerberos y los tickets de Kerberos contenidos en una caché de credenciales, o las claves contenidas en un archivo keytab.

OPCIONES

-e
Muestra los tipos de cifrado de la clave de sesión y del ticket para cada credencial en la caché de credenciales, o cada clave en el archivo keytab.
-l
Si hay disponible una colección de cachés, muestra una tabla que resume las cichés presentes en la colección.
-A
Si hay disponible una colección de cachés, muestra el contenido de todas las cichés de la colección.
-c
Lista los tickets contenidos en una caché de credenciales. Esta es la opción predeterminada si no se especifica ni -c ni -k.
-f
Muestra las banderas presentes en las credenciales, usando las siguientes abreviaturas:
F    Forwardable (Reenviable)
f    forwarded (reenviado)
P    Proxiable (Proxiable)
p    proxy (proxy)
D    postDateable (Con fecha posterior)
d    postdated (Con fecha posterior)
R    Renewable (Renovable)
I    Initial (Inicial)
i    invalid (inválido)
H    Hardware authenticated (Autenticado por hardware)
A    preAuthenticated (Pre-autenticado)
T    Transit policy checked (Política de tránsito verificada)
O    Okay as delegate (Aceptable como delegado)
a    anonymous (anónimo)
-s
Hace que klist se ejecute silenciosamente (no produzca salida). klist saldrá con el estado 1 si la caché de credenciales no se puede leer o ha expirado, y con el estado 0 en caso contrario.
-a
Muestra la lista de direcciones en las credenciales.
-n
Muestra direcciones numéricas en lugar de resolver inversamente las direcciones.
-C
Lista los datos de configuración que se han almacenado en la caché de credenciales cuando klist los encuentra. De forma predeterminada, los datos de configuración no se listan.
-k
Lista las claves contenidas en un archivo keytab.
-i
En combinación con -k, utiliza por defecto la caché de claves del cliente en lugar de la caché de claves del aceptador, si no se proporciona ningún nombre.
-t
Muestra las marcas de tiempo de entrada de claves para cada entrada del archivo keytab.
-K
Muestra el valor de la clave de cifrado en cada entrada del archivo keytab.
-d
Muestra los tipos de authdata (si los hay) para cada entrada.
-V
Muestra el número de versión de Kerberos y sale.

Si no se especifica nombre_cache o nombre_keytab, klist mostrará las credenciales en la caché de credenciales o archivo keytab predeterminados, según corresponda. Si la variable de entorno KRB5CCNAME está establecida, su valor se utiliza para localizar la caché de tickets predeterminada.

AMBIENTE

Ver kerberos(7) para una descripción de las variables de entorno de Kerberos.

ARCHIVOS

ARCHIVO:/tmp/krb5cc_%{uid}
Ubicación predeterminada de la caché de credenciales Kerberos 5
ARCHIVO:/etc/krb5.keytab
Ubicación predeterminada para el archivo keytab del host local.

VER TAMBIÉN

kinit(1), kdestroy(1), kerberos(7)
