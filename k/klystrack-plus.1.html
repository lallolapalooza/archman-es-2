NOMBRE

klystrack - crea chiptunes al estilo C64/NES/Amiga

SINOPSIS

klystrack [opciones] archivos...

DESCRIPCIÓN

Esta página del manual documenta brevemente el comando klystrack.

klystrack es un tracker para crear chiptunes al estilo C64/NES/Amiga en una plataforma moderna. Se puede utilizar para crear audio para juegos.

CARACTERÍSTICAS

Sonido
Síntesis aditiva con filtros (piensa en SID, Atari, NES, etc.)
Sincronización dura y modulación en anillo (como SID)
Síntesis FM (piensa en Adlib, MSX, OPL2, etc.)
Tabla de ondas para muestras u ondas personalizadas para usar en síntesis (piensa en Amiga, SNES)
Generador de ondas y editor integrados
Instrumentos programables no limitados a arpegios simples
Secuenciador
Tracker con posicionamiento libre de patrones
Transposición de patrones
La longitud del patrón no es fija
Límite duro de 32 canales, pero se puede aumentar (solo pregunta si necesitas más... suena loco, sin embargo)
Temas completamente personalizables, incluye media docena de temas
Efectos
Chorus estéreo
Eco multitap al estilo SNES
Bit crusher/decimador
Exportación
Formato propio personalizado con una pequeña biblioteca de reproducción para usar en juegos, demos, etc.
Exportar como .WAV
Exportar cada pista como .WAV separados
Exportar elementos de tabla de ondas como .WAV (¡usa klystrack para crear formas de onda de un ciclo para otros sintetizadores!)
Importación
Importar módulos .AHX
Importar .WAV para usar como muestras
Importar módulos Protracker y FT2
Importar archivos C64 SID (reproductor Rob Hubbard)
