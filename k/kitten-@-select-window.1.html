Nombre

kitten-@-select-window - Seleccionar visualmente una ventana en la pestaña especificada

Uso

kitten @ select-window

Descripción

Imprime el id de la ventana seleccionada. Otros comandos pueden ser encadenados para utilizarlo.

Opciones

--match, -m
La pestaña a coincidir. Las especificaciones de coincidencia tienen la forma: campo:consulta. Donde campo puede ser uno de: id, index, title, window_id, window_title, pid, cwd, cmdline env, var, state, session y recent. consulta es la expresión a coincidir. Las expresiones pueden ser un número o una expresión regular, y se pueden combinar usando operadores booleanos.

El valor especial all coincide con todas las pestañas.

Para campos numéricos: id, index, window_id, pid y recent, la expresión se interpreta como un número, no como una expresión regular. Los valores negativos para id/window_id coinciden desde el id más alto hacia abajo, en particular, -1 es la pestaña/ventana creada más recientemente.

Al usar title o id, primero se busca una pestaña coincidente, y si no se encuentra, se busca una ventana coincidente, y se utiliza la pestaña de esa ventana.

También puede usar window_id y window_title para coincidir con la pestaña que contiene la ventana con el id o título especificado.

El número de índice se utiliza para coincidir con la enésima pestaña en la ventana del sistema operativo activa actualmente. El número recent coincide con pestañas activas recientemente en la ventana del sistema operativo activa actualmente, donde cero es la pestaña activa actualmente, uno la pestaña activa anteriormente y así sucesivamente.

El campo session coincide con pestañas que fueron creadas en la sesión especificada. Use la expresión ^$ para coincidir con ventanas que no fueron creadas en una sesión y . para coincidir con la sesión activa actualmente y ~ para coincidir con la sesión activa actualmente o la última sesión activa cuando no hay ninguna sesión activa.

Al usar el campo env para coincidir con variables de entorno, puede especificar solo el nombre de la variable de entorno o un nombre y valor, por ejemplo, env:MY_ENV_VAR=2. Se coinciden las pestañas que contienen cualquier ventana con las variables de entorno especificadas. De manera similar, var coincide con pestañas que contienen cualquier ventana con la variable de usuario especificada.

El campo state coincide con el estado de la pestaña. Los estados admitidos son: active, focused, needs_attention, parent_active, parent_focused y focused_os_window. Las pestañas activas son las pestañas que están activas en su ventana del sistema operativo padre. Hay una sola pestaña enfocada y es la pestaña a la que se entregan los eventos del teclado. Si ninguna pestaña está enfocada, se coincide con la última pestaña enfocada. El valor focused_os_window coincide con todas las pestañas en la ventana del sistema operativo actualmente enfocada.

Tenga en cuenta que puede usar el comando kitten @ ls para obtener una lista de pestañas.

--response-timeout [=60]
El tiempo en segundos para esperar a que el usuario seleccione una ventana.
--self [=no]
Selecciona una ventana de la pestaña que contiene la ventana en la que se ejecuta este comando, en lugar de la pestaña activa.
--title
Un título que se mostrará al usuario para describir para qué es esta selección.
--exclude-active [=no]
Excluye la ventana activa actualmente de la lista de ventanas para elegir.
--reactivate-prev-tab [=no]
Cuando finaliza la selección, se reactivará la pestaña en la misma ventana del sistema operativo que estaba activa antes de la selección. La última ventana del sistema operativo activada también se volverá a enfocar.
--help, -h [=no]
Muestra la ayuda para este comando

Opciones globales

--to
Una dirección para la instancia de kitty a controlar. Corresponde a la dirección dada a la instancia de kitty a través de la opción --listen-on o la configuración listen_on en kitty.conf. Si no se especifica, se comprueba la variable de entorno KITTY_LISTEN_ON. Si tampoco se encuentra, los mensajes se envían a la terminal de control para este proceso, es decir, solo funcionarán si este proceso se ejecuta dentro de una ventana de kitty.
--password
Una contraseña para usar al contactar con kitty. Esto hará que kitty solicite al usuario permiso para realizar la acción especificada, a menos que la contraseña haya sido aceptada anteriormente o esté preconfigurada en kitty.conf. Para usar una contraseña en blanco, especifique --use-password como siempre.
--password-file [=rc-pass]
Un archivo desde el cual leer la contraseña. Se ignora el espacio en blanco al final. Las rutas relativas se resuelven desde el directorio de configuración de kitty. Use - para leer desde STDIN. Use fd:num para leer desde el descriptor de archivo num. Se utiliza si no se proporciona --password. Por defecto, se busca el archivo rc-pass en el directorio de configuración de kitty.
--password-env [=KITTY_RC_PASSWORD]
El nombre de una variable de entorno de la que leer la contraseña. Se utiliza si no se proporciona --password-file. Por defecto, se comprueba la variable de entorno KITTY_RC_PASSWORD.
--use-password [=if-available]
Si no hay contraseña disponible, kitty generalmente enviará el comando de control remoto sin contraseña. Esta opción se puede usar para forzarlo a usar siempre o nunca la contraseña proporcionada. Si se establece en always y no se proporciona contraseña, se usa la contraseña en blanco.

Opciones: if-available, always, never
