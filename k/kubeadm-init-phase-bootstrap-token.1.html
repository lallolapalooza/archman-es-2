NOMBRE

kubeadm init phase bootstrap-token - Genera tokens de arranque utilizados para unir un nodo a un clúster

SINOPSIS

kubeadm init phase bootstrap-token [OPCIONES]

DESCRIPCIÓN

Los tokens de arranque se utilizan para establecer una confianza bidireccional entre un nodo que se une al clúster y un nodo de control.

Este comando realiza todas las configuraciones necesarias para que los tokens de arranque funcionen y luego crea un token inicial.

OPCIONES

--config="" Ruta a un archivo de configuración de kubeadm.

--dry-run=false No aplicar ningún cambio; solo mostrar lo que se haría.

--kubeconfig="/etc/kubernetes/admin.conf" El archivo kubeconfig a utilizar al comunicarse con el clúster. Si la bandera no está establecida, se puede buscar en una serie de ubicaciones estándar un archivo kubeconfig existente.

--skip-token-print=false Omitir la impresión del token de arranque predeterminado generado por 'kubeadm init'.

OPCIONES HEREDADAS DE COMANDOS PADRE

--rootfs="" La ruta al sistema de archivos raíz del host 'real'. Esto hará que kubeadm realice un chroot en la ruta proporcionada.

--version=false --version, --version=raw imprime la información de la versión y sale; --version=vX.Y.Z... establece la versión reportada.

EJEMPLO

  # Realizar todas las configuraciones del token de arranque y crear un token inicial, funcionalmente
  # equivalente a lo que genera kubeadm init.
  kubeadm init phase bootstrap-token
