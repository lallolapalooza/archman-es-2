NOMBRE

kubeone-config-print - Imprimir un manifiesto de configuración de ejemplo

SINOPSIS

kubeone config print [flags]

DESCRIPCIÓN

Imprime un manifiesto de configuración de ejemplo. Usando las banderas apropiadas, puede personalizar el manifiesto de configuración. Para la referencia completa del manifiesto de configuración, ejecute el comando print con la bandera --full.

OPCIONES

--api-endpoint-alternative-names=[] Lista separada por comas de nombres alternativos del punto final de la API, ejemplo: host.com,192.16.0.100

--api-endpoint-host="" Nombre de host o dirección del punto final de la API

--api-endpoint-port=6443 Puerto del punto final de la API

-n, --cluster-name="demo-cluster" nombre del clúster

--container-log-max-files=5 ContainerLogMaxFiles

--container-log-max-size="100Mi" ContainerLogMaxSize

--control-plane-hosts="" hosts del plano de control en formato de lista de clave:valor separada por comas, ejemplo: publicAddress:192.168.0.100,privateAddress:192.168.1.100,sshUsername:ubuntu,sshPort:22. Use una cadena entre comillas de valores separados por espacios para múltiples hosts

--deploy-machine-controller[=true] desplegar kubermatic machine-controller

--enable-dynamic-audit-log[=false] habilitar DynamicAuditLog

--enable-encryption-providers[=false] habilitar Proveedores de Cifrado

--enable-metrics-server[=true] habilitar metrics-server

--enable-openid-connect[=false] habilitar la autenticación OpenID Connect

--enable-pod-node-selector[=false] habilitar el plugin de admisión PodNodeSelector

--enable-pod-security-policy[=false] habilitar PodSecurityPolicy. NO-OP: esta característica ha sido eliminada

--enable-static-audit-log[=false] habilitar StaticAuditLog

-f, --full[=false] mostrar manifiesto completo

-h, --help[=false] ayuda para imprimir

-k, --kubernetes-version="v1.32.5" versión de Kubernetes

--node-port-range="" Rango de puertos a utilizar para NodePort

--pod-subnet="" Subred a utilizar para la red de pods

-p, --provider="aws" nombre del proveedor en la nube (aws, digitalocean, gce, hetzner, equinixmetal, openstack, vsphere, none)

--proxy-http="" Proxy HTTP a utilizar para la provisión y Docker

--proxy-https="" Proxy HTTPS a utilizar para la provisión y Docker

--proxy-no-proxy="" No Proxy a utilizar para la provisión y Docker

--service-dns="" Nombre de dominio a utilizar para los Servicios

--service-subnet="" Subred a utilizar para los Servicios

OPCIONES HEREDADAS DE COMANDOS PADRE

-c, --credentials="" Archivo para obtener credenciales y secretos

-d, --debug[=false] salida de depuración con stacktrace

-l, --log-format="text" formato para el registro

-m, --manifest="./kubeone.yaml" Ruta al archivo de configuración de KubeOne

-t, --tfjson="" Fuente para la salida de terraform en JSON - para leer desde stdin. Si la ruta es un archivo, se utilizarán los contenidos. Si la ruta es un diccionario, se ejecuta terraform output -json en esa ruta

-v, --verbose[=false] salida detallada

EJEMPLO

kubeone config print --provider digitalocean --kubernetes-version v1.32.5 --cluster-name example

VER TAMBIÉN

kubeone-config(1)
