kbuffer_refresh(3)

Paquete: libtraceevent

Licencias: GPL-2.0-only, LGPL-2.1-only

LIBTRACEEVENT(3) libtraceevent Manual LIBTRACEEVENT(3)

NOMBRE

kbuffer_alloc, kbuffer_dup, kbuffer_free, kbuffer_load_subbuffer, kbuffer_subbuffer, kbuffer_refresh, kbuffer_subbuffer_size, kbuffer_start_of_data - Creación de elementos kbuffer para analizar el búfer de anillo de trazas del kernel de Linux

SINOPSIS

#include <kbuffer.h>
enum kbuffer_endian {
        KBUFFER_ENDIAN_BIG,
        KBUFFER_ENDIAN_LITTLE,
        KBUFFER_ENDIAN_SAME_AS_HOST,
};
enum kbuffer_long_size {
        KBUFFER_LSIZE_4,
        KBUFFER_LSIZE_8,
        KBUFFER_LSIZE_SAME_AS_HOST,
};
struct kbuffer;
struct tep_handle;
struct kbuffer *kbuffer_alloc(enum kbuffer_long_size size, enum kbuffer_endian endian);
struct kbuffer *kbuffer_dup(struct kbuffer *kbuf);
void kbuffer_free(struct kbuffer *kbuf);
int kbuffer_load_subbuffer(struct kbuffer *kbuf, void *subbuffer);
int kbuffer_subbuffer_size(struct kbuffer *kbuf);
int kbuffer_refresh(struct kbuffer *kbuf);
int kbuffer_start_of_data(struct kbuffer *kbuf);
void *kbuffer_subbuffer(struct kbuffer *_kbuf);

DESCRIPCIÓN

Estas funciones crean un manejador kbuffer que puede ser utilizado para analizar los sub-búferes crudos del búfer de anillo de trazas del kernel de Linux. El búfer de anillo se encuentra en el directorio tracefs y puede ser recuperado por tracefs_instance_get_file(3) en per_cpu/cpuX/trace_pipe_raw donde X es reemplazado por el número de CPU del búfer de anillo especificado. El búfer de anillo dentro del kernel está dividido por CPU, de tal manera que el búfer de anillo crudo debe ser recuperado por CPU también.

kbuffer_alloc() creará un descriptor que puede ser utilizado para gestionar un sub-búfer leído por el búfer de anillo. El parámetro size denota el tamaño de palabra del búfer dado (nota, esto funciona leyendo datos crudos de máquinas distintas a la que está llamando a esta función). El parámetro endian denota el orden de bytes de la máquina.

Si endian se establece en KBUFFER_ENDIAN_SAME_AS_HOST, el orden de bytes se establecerá igual que el orden de bytes del host, lo cual es útil cuando la aplicación está leyendo los datos del búfer de anillo directamente desde la misma máquina en la que se está ejecutando.

Si size se establece en KBUFFER_LSIZE_SAME_AS_HOST, si el tamaño de palabra es 8, establecerá el descriptor kbuffer a un tamaño largo de 8. Pero si el tamaño es 4, entonces realizará una llamada a uname(2), y si el campo machine contiene la cadena "64", se establecerá a un tamaño de 8 bytes y no a 4 bytes. Esto se debe a que el tamaño largo del búfer de anillo depende del kernel y no del espacio de usuario.

La función kbuffer_dup() duplicará una estructura kbuffer existente con una nueva asignada. Tendrá todas las propiedades del kbuf pasado, incluyendo apuntar al mismo sub-búfer que fue cargado en el kbuf. Debe ser liberado con kbuffer_free().

La función kbuffer_free() liberará los recursos creados por kbuffer_alloc().

La función kbuffer_load_subbuffer() tomará un subbuffer que es un bloque de datos crudo del archivo trace_pipe_raw de tracefs. El búfer de anillo de trazas de Linux está dividido en sub-búferes. Cada sub-búfer es un segmento de datos independiente que tiene toda la información para separar los eventos individuales y las marcas de tiempo. Este sub-búfer es lo que kbuffer utiliza para recorrer los eventos.

La función kbuffer_subbuffer_size() devuelve la ubicación del final del último evento en el sub-búfer. No devuelve el tamaño del sub-búfer en sí.

La función kbuffer_refresh() se debe utilizar si se realizaron más escrituras en el kbuffer cargado donde el tamaño del kbuffer necesita ser actualizado para poder leer los nuevos eventos que fueron escritos desde la última llamada a kbuffer_load_subbuffer().

Nota: No se implementan barreras de memoria con esta función y cualquier sincronización con el escritor es responsabilidad de la aplicación.

La función kbuffer_start_of_data() devuelve el desplazamiento de dónde comienza la carga de datos real del sub-búfer.

La función kbuffer_subbuffer() devuelve un puntero al sub-búfer actualmente cargado. Es decir, el último sub-búfer que fue cargado por kbuffer_load_subbuffer(). Si no se cargó ningún sub-búfer, se devuelve NULL.

VALOR DE RETORNO

kbuffer_alloc() devuelve un descriptor kbuffer asignado o NULL en caso de error. El descriptor devuelto debe ser liberado con kbuffer_free()

kbuffer_load_subbuffer() devuelve 0 en caso de éxito y -1 en caso de error.

kbuffer_subbuffer_size() devuelve el índice en el sub-búfer donde se encuentra el final del último evento.

kbuffer_start_of_data() devuelve el desplazamiento de dónde comienzan los datos en el sub-búfer cargado en kbuf.

kbuffer_subbuffer() devuelve el último sub-búfer cargado en kbuf que fue cargado por kbuffer_load_subbuffer() o NULL si no se cargó ninguno.

kbuffer_refresh() devuelve 0 en caso de éxito y -1 si kbuf es NULL o si no tiene un sub-búfer cargado a través de kbuffer_load_subbuffer().

EJEMPLO

#include <stdio.h>
#include <stdlib.h>
#include <fcntl.h>
#include <unistd.h>
#include <sys/stat.h>
#include <kbuffer.h>
int main (int argc, char **argv)
{
        unsigned long long ts;
        struct kbuffer *kbuf;
        struct stat st;
        char *buf;
        void *event;
        int ret;
        int fd;
        int i = 0;
        if (argc < 2) {
                printf("usage: %s raw-subbuffer-page\n", argv[0]);
                printf(" Try: dd count=1 bs=4096 if=/sys/kernel/tracing/per_cpu/cpu0/trace_pipe_raw of=/tmp/file\n");
                exit(0);
        }
        if (stat(argv[1], &st) < 0) {
                perror("stat");
                exit(-1);
        }
        buf = malloc(st.st_size);
        if (!buf) {
                perror("Allocating buffer");
                exit(-1);
        }
        fd = open(argv[1], O_RDONLY);
        if (fd < 0) {
                perror(argv[1]);
                exit(-1);
        }
        ret = read(fd, buf, st.st_size);
        if (ret < 0) {
                perror("Reading buffer");
                exit(-1);
        }
        close(fd);
        kbuf = kbuffer_alloc(KBUFFER_ENDIAN_SAME_AS_HOST,
                             KBUFFER_LSIZE_SAME_AS_HOST);
        if (!kbuf) {
                perror("Creating kbuffer");
                exit(-1);
        }
        ret = kbuffer_load_subbuffer(kbuf, buf);
        if (ret < 0) {
                perror("Loading sub bufer");
                exit(-1);
        }
        if (kbuffer_subbuffer_size(kbuf) > st.st_size) {
                fprintf(stderr, "kbuffer is bigger than raw size %d > %ld\n",
                        kbuffer_subbuffer_size(kbuf), st.st_size);
                exit(-1);
        }
        printf("Kbuffer data starts at %d\n", kbuffer_start_of_data(kbuf));
        do {
                event = kbuffer_read_event(kbuf, &ts);
                if (event) {
                        printf(" event %3d ts:%lld\n", i++, ts);
                        event = kbuffer_next_event(kbuf, NULL);
                }
        } while (event);
        if (!event)
                printf("Finished sub buffer\n");
        kbuffer_free(kbuf);
        return 0;
}
