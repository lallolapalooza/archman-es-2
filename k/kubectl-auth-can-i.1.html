NOMBRE

kubectl auth can-i - Comprueba si una acción está permitida

SINOPSIS

kubectl auth can-i [OPCIONES]

DESCRIPCIÓN

Comprueba si una acción está permitida.

VERBO es un verbo lógico de la API de Kubernetes como 'get', 'list', 'watch', 'delete', etc. TIPO es un recurso de Kubernetes. Los atajos y grupos se resolverán. URLNORECURSO es una URL parcial que comienza con "/". NOMBRE es el nombre de un recurso específico de Kubernetes. Este comando se combina bien con la suplantación. Ver la bandera global --as.

OPCIONES

-A, --all-namespaces=false Si es verdadero, comprueba la acción especificada en todos los namespaces.

--list=false Si es verdadero, imprime todas las acciones permitidas.

--no-headers=false Si es verdadero, imprime las acciones permitidas sin encabezados

-q, --quiet=false Si es verdadero, suprime la salida y solo devuelve el código de salida.

--subresource="" Subrecurso como pod/log o deployment/scale

OPCIONES HEREDADAS DE COMANDOS PADRE

--as="" Nombre de usuario a suplantar para la operación. El usuario puede ser un usuario normal o una cuenta de servicio en un namespace.

--as-group=[] Grupo a suplantar para la operación, esta bandera se puede repetir para especificar varios grupos.

--as-uid="" UID a suplantar para la operación.

--cache-dir="/home/username/.kube/cache" Directorio de caché predeterminado

--certificate-authority="" Ruta a un archivo de certificado para la autoridad de certificación

--client-certificate="" Ruta a un archivo de certificado de cliente para TLS

--client-key="" Ruta a un archivo de clave de cliente para TLS

--cluster="" El nombre del clúster kubeconfig a usar

--context="" El nombre del contexto kubeconfig a usar

--disable-compression=false Si es verdadero, desactiva la compresión de respuesta para todas las solicitudes al servidor

--insecure-skip-tls-verify=false Si es verdadero, no se verificará la validez del certificado del servidor. Esto hará que sus conexiones HTTPS no sean seguras

--kubeconfig="" Ruta al archivo kubeconfig a utilizar para las solicitudes de la CLI.

--kuberc="" Ruta al archivo kuberc a utilizar para las preferencias. Esto se puede deshabilitar exportando la puerta de enlace de funciones KUBECTL_KUBERC=false o desactivando la función KUBERC=off.

--match-server-version=false Requiere que la versión del servidor coincida con la versión del cliente

-n, --namespace="" Si está presente, el ámbito del namespace para esta solicitud de CLI

--password="" Contraseña para autenticación básica al servidor de API

--profile="none" Nombre del perfil a capturar. Uno de (none|cpu|heap|goroutine|threadcreate|block|mutex)

--profile-output="profile.pprof" Nombre del archivo donde escribir el perfil

--request-timeout="0" El tiempo de espera antes de renunciar a una única solicitud al servidor. Los valores distintos de cero deben contener una unidad de tiempo correspondiente (por ejemplo, 1s, 2m, 3h). Un valor de cero significa no agotar el tiempo de espera de las solicitudes.

-s, --server="" La dirección y el puerto del servidor de API de Kubernetes

--tls-server-name="" Nombre del servidor a utilizar para la validación del certificado del servidor. Si no se proporciona, se utiliza el nombre de host utilizado para contactar al servidor

--token="" Token de portador para la autenticación al servidor de API

--user="" El nombre del usuario kubeconfig a usar

--username="" Nombre de usuario para autenticación básica al servidor de API

--version=false --version, --version=raw imprime información de versión y sale; --version=vX.Y.Z... establece la versión informada

--warnings-as-errors=false Trata las advertencias recibidas del servidor como errores y sale con un código de salida distinto de cero

EJEMPLO

  # Comprueba si puedo crear pods en cualquier namespace
  kubectl auth can-i create pods --all-namespaces
  # Comprueba si puedo listar deployments en mi namespace actual
  kubectl auth can-i list deployments.apps
  # Comprueba si la cuenta de servicio "foo" del namespace "dev" puede listar pods en el namespace "prod"
  # Debes tener permiso para usar la suplantación para la opción global "--as"
  kubectl auth can-i list pods --as=system:serviceaccount:dev:foo -n prod
  # Comprueba si puedo hacer todo en mi namespace actual ("*" significa todo)
  kubectl auth can-i '*' '*'
  # Comprueba si puedo obtener el job llamado "bar" en el namespace "foo"
  kubectl auth can-i list jobs.batch/bar -n foo
  # Comprueba si puedo leer logs de pods
  kubectl auth can-i get pods --subresource=log
  # Comprueba si puedo acceder a la URL /logs/
  kubectl auth can-i get /logs/
  # Comprueba si puedo aprobar certificates.k8s.io
  kubectl auth can-i approve certificates.k8s.io
  # Lista todas las acciones permitidas en el namespace "foo"
  kubectl auth can-i --list --namespace=foo
