KDESU(1) Manual del Usuario de KDE KDESU(1)

NOMBRE

kdesu - Ejecuta un programa con privilegios elevados

SINOPSIS

kdesu [-c comando] [-d] [-f archivo] [-i nombre_icono] [-n] [-p prioridad] [-r] [-s] [-t] [-u usuario] [--noignorebutton] [--attach=winid]

kdesu [Opciones genéricas de KDE] [Opciones genéricas de Qt(TM)]

DESCRIPCIÓN

KDE su es una interfaz gráfica para el comando su de UNIX® para el Entorno de Escritorio K. Permite ejecutar un programa como un usuario diferente proporcionando la contraseña de ese usuario. KDE su es un programa sin privilegios; utiliza el su del sistema.

KDE su tiene una característica adicional: opcionalmente puede recordar contraseñas por usted. Si está utilizando esta función, solo necesitará introducir la contraseña una vez por cada comando.

Este programa está diseñado para ser iniciado desde la línea de comandos o desde archivos .desktop.

Dado que kdesu ya no se instala en $(kf5-config --prefix)/bin sino en kf5-config --path libexec y, por lo tanto, no está en su Path, debe usar $(kf5-config --path libexec)kdesu para lanzar kdesu.

OPCIONES

-c comando

Esto especifica el comando a ejecutar como root. Debe pasarse en un solo argumento. Así, si, por ejemplo, desea iniciar un nuevo gestor de archivos, introduciría en el prompt: $(kf5-config --path libexec)kdesu -c Dolphin

-d

Muestra información de depuración.

-f archivo

Esta opción permite un uso eficiente de KDE su en archivos .desktop. Indica a KDE su que examine el archivo especificado por archivo. Si este archivo es escribible por el usuario actual, KDE su ejecutará el comando como el usuario actual. Si no es escribible, el comando se ejecutará como el usuario usuario (por defecto root).

archivo se evalúa de la siguiente manera: si archivo comienza con /, se toma como un nombre de archivo absoluto. De lo contrario, se toma como el nombre de un archivo de configuración global de KDE.

-i nombre_icono

Especifica el icono a utilizar en el diálogo de contraseña. Puede especificar solo el nombre, sin ninguna extensión.

-n

No guardar la contraseña. Esto deshabilita la casilla de verificación "guardar contraseña" en el diálogo de contraseña.

-p prioridad

Establece el valor de prioridad. La prioridad es un número arbitrario entre 0 y 100, donde 100 significa la prioridad más alta y 0 la más baja. El valor predeterminado es 50.

-r

Usar planificación en tiempo real.

-s

Detiene el demonio de kdesu. Este es el demonio que almacena en caché las contraseñas exitosas en segundo plano. Esta función también puede deshabilitarse con -n cuando kdesu se ejecuta inicialmente.

-t

Habilita la salida de terminal. Esto deshabilita el mantenimiento de contraseñas. Esto es principalmente para fines de depuración; si desea ejecutar una aplicación en modo consola, use el su estándar en su lugar.

-u usuario

Si bien el uso más común de KDE su es ejecutar un comando como superusuario, puede proporcionar cualquier nombre de usuario y la contraseña apropiada.

--noignorebutton

No mostrar un botón de ignorar.

--attach winid

Hace que el diálogo sea transitorio para una aplicación X especificada por winid.

VER TAMBIÉN

su(1)

Hay disponible documentación de usuario más detallada en help:/kdesu (introduzca esta URL en Konqueror, o ejecute khelpcenter help:/kdesu).

EJEMPLOS

Ejecutar kfmclient como el usuario jim, y mostrar el icono de Konqueror en el diálogo de contraseña:

$(kf5-config --path libexec)kdesu -u jim -i konqueror kfmclient
