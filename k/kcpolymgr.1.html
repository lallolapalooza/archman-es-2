NOMBRE

kcpolymgr - interfaz de línea de comandos para gestionar la base de datos polimórfica

DESCRIPCIÓN

El comando `kcpolymgr' es una utilidad para probar y depurar la base de datos polimórfica y sus aplicaciones. `ruta' especifica la ruta de un archivo de base de datos. `clave' especifica la clave de un registro. `valor' especifica el valor de un registro. `archivo' especifica el archivo de entrada/salida. `src' especifica otros archivos de base de datos.


kcpolymgr create [-otr] [-onl|-otl|-onr] ruta
Crea un archivo de base de datos.
kcpolymgr inform [-onl|-otl|-onr] [-st] ruta
Imprime información de estado.
kcpolymgr set [-onl|-otl|-onr] [-add|-app|-rep|-inci|-incd] [-sx] ruta clave valor
Almacena un registro.
kcpolymgr remove [-onl|-otl|-onr] [-sx] ruta clave
Elimina un registro.
kcpolymgr get [-onl|-otl|-onr] [-rm] [-sx] [-px] [-pz] ruta clave
Imprime el valor de un registro.
kcpolymgr list [-onl|-otl|-onr] [-mp|-mr|-ms] [-des] [-max num] [-rm] [-sx] [-pv] [-px] ruta [clave]
Imprime claves de todos los registros, separadas por saltos de línea.
kcpolymgr clear [-onl|-otl|-onr] ruta
Elimina todos los registros de una base de datos.
kcpolymgr import [-onl|-otl|-onr] [-sx] ruta [archivo]
Importa registros desde un archivo TSV.
kcpolymgr copy [-onl|-otl|-onr] ruta archivo
Copia la base de datos completa.
kcpolymgr dump [-onl|-otl|-onr] ruta [archivo]
Exporta registros a un archivo de instantánea.
kcpolymgr load [-otr] [-onl|-otl|-onr] ruta [archivo]
Carga registros desde un archivo de instantánea.
kcpolymgr merge [-onl|-otl|-onr] [-add|-app|-rep] ruta src...
Fusiona registros de otras bases de datos.
kcpolymgr setbulk [-onl|-otl|-onr] ruta clave valor ...
Almacena registros a la vez.
kcpolymgr removebulk [-onl|-otl|-onr] [-sx] ruta clave ...
Elimina registros a la vez.
kcpolymgr getbulk [-onl|-otl|-onr] [-sx] [-px] ruta clave ...
Recupera registros a la vez.
kcpolymgr check [-onl|-otl|-onr] ruta
Comprueba la consistencia.

Las opciones presentan lo siguiente.

-otr : abre la base de datos con la opción de truncamiento.
-onl : abre la base de datos con la opción de sin bloqueo.
-otl : abre la base de datos con la opción de intentar bloqueo.
-onr : abre la base de datos con la opción de no auto reparación.
-st : imprime información miscelánea.
-add : realiza la operación de adición.
-app : realiza la operación de añadir.
-rep : realiza la operación de reemplazo.
-inci : realiza la operación de incremento de enteros.
-incd : realiza la operación de incremento de números reales.
-sx : los datos de entrada se evalúan como una cadena de datos hexadecimal.
-rm : elimina el registro.
-px : los datos de salida se convierten en una cadena de datos hexadecimal.
-pz : no añade un salto de línea al final de la salida.
-mp : realiza una coincidencia de prefijo en lugar del escaneo habitual.
-mr : realiza una coincidencia de expresión regular en lugar del escaneo habitual.
-ms : realiza una coincidencia similar en lugar del escaneo habitual.
-des : visita los registros en orden descendente.
-max num : especifica el número máximo de registros mostrados.
-pv : también imprime los valores de los registros.

Este comando devuelve 0 en caso de éxito, otro valor en caso de fallo.
