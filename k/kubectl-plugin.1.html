NOMBRE

kubectl plugin - Proporciona utilidades para interactuar con plugins

SINOPSIS

kubectl plugin [OPCIONES]

DESCRIPCIÓN

Proporciona utilidades para interactuar con plugins.

Los plugins proporcionan funcionalidad extendida que no forma parte de la distribución principal de la línea de comandos. Por favor, consulta la documentación y los ejemplos para más información sobre cómo escribir tus propios plugins.

La forma más fácil de descubrir e instalar plugins es a través del subproyecto de Kubernetes krew: [krew.sigs.k8s.io]. Para instalar krew, visita https://krew.sigs.k8s.io/docs/user-guide/setup/install

OPCIONES HEREDADAS DE COMANDOS PADRE

--as="" Nombre de usuario a suplantar para la operación. El usuario puede ser un usuario regular o una cuenta de servicio en un namespace.

--as-group=[] Grupo a suplantar para la operación, este flag se puede repetir para especificar múltiples grupos.

--as-uid="" UID a suplantar para la operación.

--cache-dir="/home/username/.kube/cache" Directorio de caché predeterminado

--certificate-authority="" Ruta a un archivo de certificado para la autoridad de certificación

--client-certificate="" Ruta a un archivo de certificado de cliente para TLS

--client-key="" Ruta a un archivo de clave de cliente para TLS

--cluster="" El nombre del clúster de kubeconfig a utilizar

--context="" El nombre del contexto de kubeconfig a utilizar

--disable-compression=false Si es true, opta por no comprimir las respuestas para todas las solicitudes al servidor

--insecure-skip-tls-verify=false Si es true, el certificado del servidor no se verificará en busca de validez. Esto hará que tus conexiones HTTPS no sean seguras

--kubeconfig="" Ruta al archivo kubeconfig a utilizar para las solicitudes CLI.

--kuberc="" Ruta al archivo kuberc a utilizar para las preferencias. Esto se puede deshabilitar exportando el feature gate KUBECTL_KUBERC=false o desactivando el feature KUBERC=off.

--match-server-version=false Requiere que la versión del servidor coincida con la versión del cliente

-n, --namespace="" Si está presente, el ámbito del namespace para esta solicitud CLI

--password="" Contraseña para la autenticación básica al servidor API

--profile="none" Nombre del perfil a capturar. Uno de (none|cpu|heap|goroutine|threadcreate|block|mutex)

--profile-output="profile.pprof" Nombre del archivo donde escribir el perfil

--request-timeout="0" La cantidad de tiempo a esperar antes de renunciar a una única solicitud al servidor. Los valores no cero deben contener una unidad de tiempo correspondiente (por ejemplo, 1s, 2m, 3h). Un valor de cero significa no agotar el tiempo de espera de las solicitudes.

-s, --server="" La dirección y el puerto del servidor API de Kubernetes

--tls-server-name="" Nombre del servidor a usar para la validación del certificado del servidor. Si no se proporciona, se usa el nombre de host utilizado para contactar al servidor

--token="" Token de portador para la autenticación al servidor API

--user="" El nombre del usuario de kubeconfig a utilizar

--username="" Nombre de usuario para la autenticación básica al servidor API

--version=false --version, --version=raw imprime información de versión y sale; --version=vX.Y.Z... establece la versión reportada

--warnings-as-errors=false Trata las advertencias recibidas del servidor como errores y sale con un código de salida distinto de cero

EJEMPLO

  # Listar todos los plugins disponibles
  kubectl plugin list
  # Listar solo los nombres de binarios de los plugins disponibles sin rutas
  kubectl plugin list --name-only
