Nombre

kitten-choose-files - Elige archivos, rápido

Descripción general

Añadido en la versión 0.43.0.

El kitten choose-files está diseñado para permitirte seleccionar archivos, muy rápido, con solo unas pocas pulsaciones de teclas. Funciona como fzf https://github.com/junegunn/fzf/ y buscadores difusos similares, excepto que está especializado en encontrar archivos. Como tal, soporta características como filtrado por tipo de archivo, iconos de tipo de archivo, previsualizaciones de contenido y demás, directamente. Se puede usar como un reemplazo directo (pero mucho más eficiente y amigable con el teclado) para los cuadros de diálogo Abrir y Guardar archivo comunes en programas GUI. En Linux, con la ayuda del kitten desktop-ui <>, puedes incluso convencer a la mayoría de los programas GUI de tu computadora para que usen este kitten en lugar de los diálogos de archivo regulares.

Simplemente ejecútalo como:

kitten choose-files

para seleccionar un único archivo del árbol con raíz en el directorio de trabajo actual. Escribe unas pocas letras del nombre del archivo y, una vez que se convierta en la selección principal, presiona Enter. Puedes cambiar el directorio actual seleccionando un directorio y presionando la tecla Tab. Shift+Tab sube un nivel de directorio.

Creación de atajos a directorios favoritos/de uso frecuente

Puedes crear atajos de teclado para cambiar rápidamente a cualquier directorio en choose-files.conf. Por ejemplo:

map ctrl+t cd /tmp
map alt+p  cd ~/my/project

Selección de múltiples archivos

Cuando desees seleccionar varios archivos, inicia el kitten con --mode=files. Luego, en lugar de presionar Enter, presiona Shift+Enter y el archivo se agregará a la lista de selecciones. También puedes mantener presionada la tecla Ctrl y hacer clic en los archivos para agregarlos a las selecciones. De manera similar, puedes mantener presionada la tecla Alt y hacer clic para seleccionar rangos de archivos (similar a usar Shift+clic en una aplicación GUI). Presiona Enter en el último archivo seleccionado para finalizar. La lista de archivos seleccionados se muestra en la parte inferior del kitten y puedes hacer clic en ellos para deseleccionar un archivo. De manera similar, presionar Shift+Enter deseleccionará un archivo previamente seleccionado.

Archivos ocultos e ignorados

Por defecto, el kitten no procesa archivos y directorios ocultos (cuyos nombres comienzan con un punto). Esto se puede cambiar en la configuración y también en tiempo de ejecución a través del enlace clicable a la derecha de la entrada de búsqueda.

De manera similar, el kitten respeta ambos archivos .gitignore y .ignore, por defecto. Esto también se puede cambiar tanto en la configuración como en tiempo de ejecución. Ten en cuenta que los archivos .gitignore solo se respetan si también hay un directorio .git presente. El kitten también soporta el archivo global .gitignore, aunque solo se aplica dentro de los árboles de trabajo de git. Puedes especificar patrones de ignorados globales, que se aplican en todas partes en choose-files.conf.

Selección de archivos inexistentes (nombres de archivo para guardar)

Este kitten también se puede usar para seleccionar archivos inexistentes, es decir, un nuevo archivo para un diálogo de tipo "Guardar archivo" usando --mode=save-file. Una vez que te hayas movido al directorio donde quieres que esté el archivo (usando la tecla Tab), presiona Ctrl+Enter y podrás escribir el nombre del archivo.

Selección de directorios

Este kitten también se puede usar para seleccionar directorios, para un diálogo de tipo "Abrir directorio" usando --mode=dir. Una vez que te hayas movido al directorio que deseas, presiona Ctrl+Enter para aceptarlo. O si estás en un directorio padre, puedes seleccionar un directorio descendiente presionando Enter, lo mismo que harías para seleccionar un archivo para abrir.

Configuración

Puedes configurar varios aspectos de la operación del kitten creando un archivo choose-files.conf en tu carpeta de configuración de kitty <#confloc>. Consulta a continuación las directivas de configuración soportadas.

Escaneo del sistema de archivos

mostrar_ocultos
mostrar_ocultos último

Si mostrar archivos ocultos. El valor por defecto de último significa recordar el último valor utilizado. Esta configuración se puede alternar dentro del programa.

ordenar_por_última_modificación
ordenar_por_última_modificación último

Si ordenar la lista de entradas por última modificación, en lugar de por nombre. Ten en cuenta que la ordenación solo se aplica antes de que se ingrese cualquier consulta. Una vez que se ingresa una consulta, las entradas se ordenan por su puntuación de coincidencia. El valor por defecto de último significa recordar el último valor utilizado. Esta configuración se puede alternar dentro del programa.

respetar_ignorados
respetar_ignorados último

Si respetar los archivos .gitignore y .ignore y la configuración ignore. El valor por defecto de último significa recordar el último valor utilizado. Esta configuración se puede alternar dentro del programa.

ignorar

Un patrón de ignorado para ignorar archivos coincidentes. Usa la misma sintaxis que los archivos .gitignore (ver man gitignore). Los patrones anclados coinciden con respecto al directorio que se está mostrando actualmente. Se puede especificar varias veces para usar varios patrones. Ten en cuenta que cada patrón debe verificarse contra cada archivo, así que úsalos con moderación.

Apariencia

mostrar_vista_previa
mostrar_vista_previa último

Si mostrar una vista previa del archivo/directorio actual. El valor por defecto de último significa recordar el último valor utilizado. Esta configuración se puede alternar dentro del programa.

estilo_pygments
estilo_pygments por defecto

El esquema de colores de pygments a usar para el resaltado de sintaxis de las previsualizaciones de archivos. Ver los estilos integrados de pygments https://pygments.org/styles/ para una lista de esquemas. Esto establece los colores utilizados para esquemas de colores claros, usa estilo_pygments_oscuro para cambiar los colores para esquemas de colores oscuros.

estilo_pygments_oscuro
estilo_pygments_oscuro github-oscuro

El esquema de colores de pygments a usar para el resaltado de sintaxis con colores oscuros. Ver los estilos integrados de pygments https://pygments.org/styles/ para una lista de esquemas. Esto establece los colores utilizados para esquemas de colores oscuros, usa estilo_pygments para cambiar los colores para esquemas de colores claros.

Atajos de teclado

Salir
map esc quit
map ctrl+c quit
Aceptar el resultado actual
map enter accept
Seleccionar el resultado actual
map shift+enter select

Al seleccionar varios archivos, esto agregará el archivo actual a la lista de archivos seleccionados. También puedes alternar el estado seleccionado de un archivo manteniendo presionada la tecla Ctrl y haciendo clic en él. De manera similar, la tecla Alt se puede mantener presionada para hacer clic y extender el rango de archivos seleccionados.

Escribir nombre de archivo
map ctrl+enter typename

Escribe un nombre/ruta de archivo en lugar de filtrar la lista de archivos existentes. Útil cuando se especifica un nombre de archivo o directorio para guardar que aún no existe. Al elegir directorios existentes, aceptará el directorio cuyos contenidos se están mostrando actualmente como la elección. No funciona al seleccionar archivos para abrir en lugar de guardar.

Código fuente de choose_files

El código fuente de este kitten está disponible en GitHub https://github.com/kovidgoyal/kitty/tree/master/kittens/choose_files.

Interfaz de línea de comandos

kitten choose_files [options] [directorio para empezar a elegir archivos]

Selecciona uno o más archivos, rápidamente, usando búsqueda difusa, escribiendo solo unos pocos caracteres del nombre del archivo. Navega por los archivos coincidentes, usando las teclas de flecha para navegar por las coincidencias y presiona Enter para seleccionar. La tecla Tab se puede usar para cambiar a una subcarpeta. Consulta la documentación en línea <> para obtener detalles completos.

Opciones

--mode <MODO>
El tipo de objeto(s) a seleccionar. Predeterminado: file. Opciones: dir, dirs, file, files, save-dir, save-file, save-files
--file-filter <FILTRO_ARCHIVO>
Una lista de filtros para restringir los archivos mostrados. Pueden ser mimetypes o patrones de estilo glob. Se pueden especificar varias veces. La sintaxis es type:expresión:Nombre Descriptivo. Por ejemplo: mime:image/png:Imágenes y mime:image/gif:Imágenes y glob:*.[tT][xX][Tt]:Archivos de texto. Ten en cuenta que los patrones glob distinguen entre mayúsculas y minúsculas. La especificación de mimetype se trata como una expresión glob también, por lo que puedes, por ejemplo, usar mime:text/* para coincidir con todos los archivos de texto. El primer filtro de la lista se aplicará por defecto. Usa un filtro como glob:*:Todos para coincidir con todos los archivos. Ten en cuenta que el filtrado solo se aplica a los archivos, no a los directorios.
--suggested-save-file-name <NOMBRE_ARCHIVO_GUARDAR_SUGERIDO>
Un nombre sugerido al elegir un archivo para guardar.
--suggested-save-file-path <RUTA_ARCHIVO_GUARDAR_SUGERIDA>
Ruta a un archivo existente para usar como archivo para guardar.
--title <TÍTULO>
Título de la ventana a usar para este kitten
--display-title [=no]
Muestra el título de la ventana en la parte superior, útil cuando este kitten se usa en una ventana del sistema operativo sin barra de título.
--override <SOBREESCRIBIR>, -o <SOBREESCRIBIR>
Sobrescribe opciones de configuración individuales, se puede especificar varias veces. Sintaxis: nombre=valor.
--config <CONFIG>
Especifica una ruta a los archivos de configuración a usar. Todos los archivos de configuración se fusionan con el archivo incorporado choose-files.conf, anulando los valores incorporados. Esta opción se puede especificar varias veces para leer varios archivos de configuración en secuencia, los cuales se fusionan. Usa el valor especial NONE para no cargar ningún archivo de configuración.

Si esta opción no se especifica, los archivos de configuración se buscan en el siguiente orden: $XDG_CONFIG_HOME/kitty/choose-files.conf, ~/.config/kitty/choose-files.conf, $XDG_CONFIG_DIRS/kitty/choose-files.conf. El primero que exista se usa como archivo de configuración.

Si se especifica la variable de entorno KITTY_CONFIG_DIRECTORY <#envvar-KITTY_CONFIG_DIRECTORY>, ese directorio siempre se usa y la búsqueda anterior no ocurre.

Si existe /etc/xdg/kitty/choose-files.conf, se fusiona antes (es decir, con menor prioridad) que cualquier archivo de configuración de usuario. Se puede usar para especificar valores predeterminados a nivel de sistema para todos los usuarios. Puedes usar cualquiera de

Command line interface

The following command line options are available:

--config <config>
Path to configuration file. If not specified, looks for it in $XDG_CONFIG_HOME/kitty/ or $HOME/.config/kitty/. Default: kitty.conf . Use /dev/null or - or /dev/stdin to read the config from STDIN.
--write-output-to <WRITE_OUTPUT_TO>
Path to a file to which the output is written in addition to STDOUT.
--output-format <OUTPUT_FORMAT>
The format in which to write the output. Default: text Choices: json, text
--write-pid-to <WRITE_PID_TO>
Path to a file to which to write the process ID (PID) of this process to.
