NOMBRE

kcgrasstest - interfaz de línea de comandos para probar la base de datos del árbol de caché

DESCRIPCIÓN

El comando `kcgrasstest' es una utilidad para pruebas de funcionalidad y pruebas de rendimiento de la base de datos del árbol de caché. Este comando se utiliza en el siguiente formato. `rnum' especifica el número de iteraciones.


kcgrasstest orden [-th num] [-rnd] [-etc] [-tran] [-tc] [-bnum num] [-psiz num] [-pccap num] [-rcd|-rcld|-rcdd] [-lv] rnum
Realiza pruebas en orden.
kcgrasstest queue [-th num] [-it num] [-rnd] [-tc] [-bnum num] [-psiz num] [-pccap num] [-rcd|-rcld|-rcdd] [-lv] rnum
Realiza operaciones de cola.
kcgrasstest wicked [-th num] [-it num] [-tc] [-bnum num] [-psiz num] [-pccap num] [-rcd|-rcld|-rcdd] [-lv] rnum
Realiza operaciones mixtas seleccionadas al azar.
kcgrasstest tran [-th num] [-it num] [-tc] [-bnum num] [-psiz num] [-pccap num] [-rcd|-rcld|-rcdd] [-lv] rnum
Realiza la prueba de transacción.

Las opciones incluyen lo siguiente.

-th num : especifica el número de hilos de trabajo.
-rnd : realiza pruebas aleatorias.
-etc : realiza operaciones diversas.
-tran : realiza transacciones.
-tc : sintoniza la base de datos con la opción de compresión.
-bnum num : especifica el número de cubetas de la tabla hash.
-psiz num : especifica el tamaño de cada página.
-pccap num : especifica el tamaño de capacidad de la caché de páginas.
-rcd : usa el comparador decimal en lugar del léxico.
-rcld : usa el comparador léxico descendente en lugar del ascendente.
-rcdd : usa el comparador decimal descendente en lugar del léxico.
-lv : informa de todos los errores.
-it num : especifica el número de repeticiones.

Este comando devuelve 0 si tiene éxito, otro valor si falla.
