kbuffer_subbuf_timestamp(3)

Paquete: libtraceevent

Licencias: GPL-2.0-only, LGPL-2.1-only

LIBTRACEEVENT(3) Manual de libtraceevent LIBTRACEEVENT(3)

NOMBRE

kbuffer_timestamp, kbuffer_subbuf_timestamp - Funciones que leen diversos datos de un descriptor kbuffer

SINOPSIS

#include <kbuffer.h>
unsigned long long kbuffer_timestamp(struct kbuffer *kbuf);
unsigned long long kbuffer_subbuf_timestamp(struct kbuffer *kbuf, void *subbuf);

DESCRIPCIÓN

La función kbuffer_timestamp() devuelve la marca de tiempo del evento actual de kbuf.

La función kbuffer_subbuf_timestamp() devuelve la marca de tiempo para el sub-buffer que se cargó en kbuf. Esto suele ser (pero no se garantiza que sea) la marca de tiempo del primer evento en el sub-buffer.

La función kbuffer_start_of_data() devuelve el desplazamiento de dónde comienza el delta

VALOR DE RETORNO

kbuffer_read_event() devuelve el evento en el que se encuentra actualmente el descriptor kbuf, o NULL si se ha pasado el último evento (mediante kbuffer_next_event()).

kbuffer_next_event() devuelve el siguiente evento después del evento actual o NULL si no hay más eventos.

kbuffer_read_at_offset() devuelve el evento en un desplazamiento dado desde el inicio del sub-buffer almacenado en kbuf, o NULL si no existe ningún evento. Nota: desplazamiento solo necesita ser un desplazamiento que apunte al registro, o que esté al inicio del mismo. No tiene por qué estar exactamente al principio del registro.

kbuffer_missed_events() devuelve 0 si no hubo eventos perdidos antes del sub-buffer cargado. Devuelve -1 si hubo un número desconocido de eventos perdidos, o si se conoce el número de eventos perdidos, se devolverá ese número.

kbuffer_event_size() devuelve el tamaño de la carga útil de datos del evento actual de kbuf.

kbuffer_curr_size() devuelve el tamaño del registro completo del evento actual de kbuf. Esto incluye el tamaño de los metadatos de ese registro.

kbuf_curr_offset() devuelve el desplazamiento del registro actual desde el principio del sub-buffer de kbuf.

kbuf_curr_index() devuelve el índice del registro actual desde el principio de la sección de datos de kbuf.

EJEMPLO

#include <stdio.h>
#include <stdlib.h>
#include <fcntl.h>
#include <unistd.h>
#include <sys/stat.h>
#include <kbuffer.h>
int main (int argc, char **argv)
{
        unsigned long long ts;
        struct kbuffer *kbuf;
        struct stat st;
        char *buf;
        void *event;
        int save_offset = -1;
        int record_size;
        int offset;
        int index;
        int size;
        int ret;
        int fd;
        int i = 0;
        if (argc < 2) {
                printf("uso: %s página de sub-buffer raw\n", argv[0]);
                printf(" Intenta: dd count=1 bs=4096 if=/sys/kernel/tracing/per_cpu/cpu0/trace_pipe_raw of=/tmp/file\n");
                exit(0);
        }
        if (stat(argv[1], &st) < 0) {
                perror("stat");
                exit(-1);
        }
        buf = malloc(st.st_size);
        if (!buf) {
                perror("Asignando buffer");
                exit(-1);
        }
        fd = open(argv[1], O_RDONLY);
        if (fd < 0) {
                perror(argv[1]);
                exit(-1);
        }
        ret = read(fd, buf, st.st_size);
        if (ret < 0) {
                perror("Leyendo buffer");
                exit(-1);
        }
        close(fd);
        kbuf = kbuffer_alloc(KBUFFER_ENDIAN_SAME_AS_HOST,
                             KBUFFER_LSIZE_SAME_AS_HOST);
        if (!kbuf) {
                perror("Creando kbuffer");
                exit(-1);
        }
        ret = kbuffer_load_subbuffer(kbuf, buf);
        if (ret < 0) {
                perror("Cargando sub buffer");
                exit(-1);
        }
        if (kbuffer_subbuffer_size(kbuf) > st.st_size) {
                fprintf(stderr, "kbuffer es más grande que el tamaño raw %d > %ld\n",
                        kbuffer_subbuffer_size(kbuf), st.st_size);
                exit(-1);
        }
        ret = kbuffer_missed_events(kbuf);
        if (ret) {
                if (ret > 0)
                        printf("Perdidos %d eventos antes de este buffer\n", ret);
                else
                        printf("Perdido un número desconocido de eventos antes de este buffer\n");
        }
        do {
                event = kbuffer_read_event(kbuf, &ts);
                if (event) {
                        record_size = kbuffer_curr_size(kbuf);
                        offset = kbuffer_curr_offset(kbuf);
                        index = kbuffer_curr_index(kbuf);
                        size = kbuffer_event_size(kbuf);
                        if (i == 20)
                                save_offset = offset;
                        printf(" evento %3d ts:%lld\ttamaño_registro:%d tamaño:%d\tindice:%d desplazamiento:%d\n",
                               i++, ts, record_size, size, index, offset);
                        event = kbuffer_next_event(kbuf, NULL);
                }
        } while (event);
        if (!event)
                printf("Buffer de sub-eventos finalizado\n");
        if (save_offset > 0) {
                event = kbuffer_read_at_offset(kbuf, save_offset, &ts);
                if (!event) {
                        fprintf(stderr, "Curioso, no se puede encontrar el evento 20 en el desplazamiento %d\n", save_offset);
                        exit(-1);
                }
                record_size = kbuffer_curr_size(kbuf);
                offset = kbuffer_curr_offset(kbuf);
                index = kbuffer_curr_index(kbuf);
                size = kbuffer_event_size(kbuf);
                printf("\n evento 20 guardado ts:%lld\ttamaño_registro:%d tamaño:%d\tindice:%d desplazamiento:%d\n\n",
                       ts, record_size, size, index, offset);
        }
        kbuffer_free(kbuf);
        return 0;
}
