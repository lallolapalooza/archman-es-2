KEYCTL_JOIN_SESSION_KEYRING(3) Llamadas de gestión de claves de Linux KEYCTL_JOIN_SESSION_KEYRING(3)

NOMBRE

keyctl_join_session_keyring - unirse a un keyring de sesión diferente

SINOPSIS

#include <keyutils.h>

key_serial_t keyctl_join_session_keyring(const char *name);

DESCRIPCIÓN

keyctl_join_session_keyring() cambia el keyring de sesión al que un proceso está suscrito.

Si name es NULL, se creará un nuevo keyring anónimo y el proceso se suscribirá a él.

Si name apunta a una cadena, entonces si hay disponible un keyring con ese nombre, el proceso intentará suscribirse a ese keyring, dando un error si no está permitido; de lo contrario, se creará un nuevo keyring con ese nombre y se adjuntará como el keyring de sesión.

Para adjuntarse a un keyring con nombre existente, el keyring debe tener el permiso de búsqueda disponible para el proceso que llama.

VALOR DE RETORNO

En caso de éxito, keyctl_join_session_keyring() devuelve el número de serie de la clave que encontró o creó. En caso de error, se devolverá el valor -1 y errno se habrá establecido con un error apropiado.

ERRORES

ENOMEM
Memoria insuficiente para crear una clave.
EDQUOT
La cuota de claves para este usuario se excedería al crear esta clave o vincularla al keyring.
EACCES
El keyring con nombre existe, pero no es buscable por el proceso que llama.

ENLACE

Esta es una función de biblioteca que se puede encontrar en libkeyutils. Al enlazar, se debe especificar -lkeyutils al enlazador.

VER TAMBIÉN
