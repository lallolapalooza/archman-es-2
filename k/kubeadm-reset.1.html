NOMBRE

kubeadm reset - Realiza un esfuerzo por revertir los cambios hechos en este host por 'kubeadm init' o 'kubeadm join'

SINOPSIS

kubeadm reset [OPCIONES]

DESCRIPCIÓN

Realiza un esfuerzo por revertir los cambios hechos en este host por 'kubeadm init' o 'kubeadm join'

El comando "reset" ejecuta las siguientes fases:

preflight           Ejecuta comprobaciones previas de reinicio
remove-etcd-member  Elimina un miembro de etcd local.
cleanup-node        Ejecuta limpieza del nodo.

OPCIONES

--cert-dir="/etc/kubernetes/pki" La ruta al directorio donde se almacenan los certificados. Si se especifica, limpia este directorio.

--cleanup-tmp-dir=false Limpia el directorio "/etc/kubernetes/tmp"

--config="" Ruta a un archivo de configuración de kubeadm.

--cri-socket="" Ruta al socket CRI para conectar. Si está vacío, kubeadm intentará autodetectar este valor; usa esta opción solo si tienes más de un CRI instalado o si tienes un socket CRI no estándar.

--dry-run=false No apliques ningún cambio; solo muestra lo que se haría.

-f, --force=false Reinicia el nodo sin solicitar confirmación.

--ignore-preflight-errors=[] Una lista de comprobaciones cuyos errores se mostrarán como advertencias. Ejemplo: 'IsPrivilegedUser,Swap'. El valor 'all' ignora los errores de todas las comprobaciones.

--kubeconfig="/etc/kubernetes/admin.conf" El archivo kubeconfig a usar al comunicarse con el clúster. Si la opción no se establece, se puede buscar en una serie de ubicaciones estándar un archivo kubeconfig existente.

--skip-phases=[] Lista de fases a omitir

OPCIONES HEREDADAS DE COMANDOS PADRE

--rootfs="" La ruta al sistema de archivos raíz 'real' del host. Esto hará que kubeadm realice un chroot en la ruta proporcionada.

--version=false --version, --version=raw imprime información de versión y sale; --version=vX.Y.Z... establece la versión reportada
