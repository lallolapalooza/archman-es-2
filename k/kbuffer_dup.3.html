kbuffer_dup(3)

Paquete: libtraceevent

Licencias: GPL-2.0-only, LGPL-2.1-only

LIBTRACEEVENT(3) Manual de libtraceevent LIBTRACEEVENT(3)

NOMBRE

kbuffer_alloc, kbuffer_dup, kbuffer_free, kbuffer_load_subbuffer, kbuffer_subbuffer, kbuffer_refresh, kbuffer_subbuffer_size, kbuffer_start_of_data - Creación de un elemento kbuffer para analizar el búfer de anillo de rastreo del kernel de Linux

SINOPSIS

#include <kbuffer.h>
enum kbuffer_endian {
        KBUFFER_ENDIAN_BIG,
        KBUFFER_ENDIAN_LITTLE,
        KBUFFER_ENDIAN_SAME_AS_HOST,
};
enum kbuffer_long_size {
        KBUFFER_LSIZE_4,
        KBUFFER_LSIZE_8,
        KBUFFER_LSIZE_SAME_AS_HOST,
};
struct kbuffer;
struct tep_handle;
struct kbuffer *kbuffer_alloc(enum kbuffer_long_size size, enum kbuffer_endian endian);
struct kbuffer *kbuffer_dup(struct kbuffer *kbuf);
void kbuffer_free(struct kbuffer *kbuf);
int kbuffer_load_subbuffer(struct kbuffer *kbuf, void *subbuffer);
int kbuffer_subbuffer_size(struct kbuffer *kbuf);
int kbuffer_refresh(struct kbuffer *kbuf);
int kbuffer_start_of_data(struct kbuffer *kbuf);
void *kbuffer_subbuffer(struct kbuffer *_kbuf);

DESCRIPCIÓN

Estas funciones crean un manejador kbuffer que se puede usar para analizar los búferes secundarios crudos del búfer de anillo de rastreo del kernel de Linux. El búfer de anillo se encuentra en el directorio tracefs y se puede recuperar mediante tracefs_instance_get_file(3) en per_cpu/cpuX/trace_pipe_raw donde X se reemplaza por el número de CPU del búfer de anillo especificado. El búfer de anillo dentro del kernel se divide por CPU, por lo que el búfer de anillo crudo también debe recuperarse por CPU.

kbuffer_alloc() creará un descriptor que se puede utilizar para administrar un subbúfer leído por el búfer de anillo. El parámetro size denota cuál es el tamaño de palabra para el búfer dado (nota, esto funciona al leer datos crudos de máquinas distintas de la que está llamando a esta función). El parámetro endian denota el orden de bytes de la máquina.

Si endian se establece en KBUFFER_ENDIAN_SAME_AS_HOST, el orden de bytes se establecerá en el mismo que el orden de bytes del host, lo cual es útil cuando la aplicación lee los datos del búfer de anillo directamente de la misma máquina en la que se está ejecutando.

Si size se establece en KBUFFER_LSIZE_SAME_AS_HOST, si el tamaño de palabra es 8, establecerá el descriptor de kbuffer en un tamaño largo de 8. Pero si el tamaño es 4, realizará una llamada a uname(2) y, si el campo machine contiene la cadena "64", se establecerá en un tamaño largo de 8 bytes y no de 4 bytes. Esto se debe a que el tamaño largo del búfer de anillo depende del kernel y no del espacio de usuario.

La función kbuffer_dup() duplicará una estructura kbuffer existente con una nueva asignada. Tendrá todas las propiedades del kbuf pasado, incluido el apuntar al mismo subbúfer que se cargó en el kbuf. Debe liberarse con kbuffer_free().

La función kbuffer_free() liberará los recursos creados por kbuffer_alloc().

kbuffer_load_subbuffer() tomará un subbuffer, que es un bloque de datos crudos del archivo trace_pipe_raw de tracefs. El búfer de anillo de rastreo de Linux se divide en subbúferes. Cada subbúfer es un segmento de datos independiente que tiene toda la información para separar los eventos individuales y las marcas de tiempo. Este subbúfer es lo que kbuffer utiliza para recorrer los eventos.

kbuffer_subbuffer_size() devuelve la ubicación del final del último evento en el subbúfer. No devuelve el tamaño del subbúfer en sí.

kbuffer_refresh() se utilizará si se realizaron más escrituras en el kbuffer cargado, donde el tamaño del kbuffer debe actualizarse para poder leer los nuevos eventos que se escribieron desde la última llamada a kbuffer_load_subbuffer().

Nota, no se implementan barreras de memoria con esta función y la sincronización con el escritor es responsabilidad de la aplicación.

La función kbuffer_start_of_data() devuelve el desplazamiento de dónde comienza la carga de datos real del subbúfer.

La función kbuffer_subbuffer() devuelve el puntero al subbúfer actualmente cargado. Es decir, el último subbúfer que fue cargado por kbuffer_load_subbuffer(). Si no se cargó ningún subbúfer, se devuelve NULL.

VALOR DE RETORNO

kbuffer_alloc() devuelve un descriptor kbuffer asignado o NULL en caso de error. El descriptor devuelto debe liberarse con kbuffer_free()

kbuffer_load_subbuffer() devuelve 0 en caso de éxito y -1 en caso de error.

kbuffer_subbuffer_size() devuelve el índice en el subbúfer donde se encuentra el final del último evento.

kbuffer_start_of_data() devuelve el desplazamiento de dónde comienzan los datos en el subbúfer cargado en kbuf.

kbuffer_subbuffer() devuelve el último subbúfer cargado en kbuf que fue cargado por kbuffer_load_subbuffer() o NULL si no se cargó ninguno.

kbuffer_refresh() devuelve 0 en caso de éxito y -1 si kbuf es NULL o si no tiene un subbúfer cargado a través de kbuffer_load_subbuffer().

EJEMPLO

#include <stdio.h>
#include <stdlib.h>
#include <fcntl.h>
#include <unistd.h>
#include <sys/stat.h>
#include <kbuffer.h>
int main (int argc, char **argv)
{
        unsigned long long ts;
        struct kbuffer *kbuf;
        struct stat st;
        char *buf;
        void *event;
        int ret;
        int fd;
        int i = 0;
        if (argc < 2) {
                printf("uso: %s pagina-de-subbuffer-crudo\n", argv[0]);
                printf(" Intenta: dd count=1 bs=4096 if=/sys/kernel/tracing/per_cpu/cpu0/trace_pipe_raw of=/tmp/file\n");
                exit(0);
        }
        if (stat(argv[1], &st) < 0) {
                perror("stat");
                exit(-1);
        }
        buf = malloc(st.st_size);
        if (!buf) {
                perror("Asignando buffer");
                exit(-1);
        }
        fd = open(argv[1], O_RDONLY);
        if (fd < 0) {
                perror(argv[1]);
                exit(-1);
        }
        ret = read(fd, buf, st.st_size);
        if (ret < 0) {
                perror("Leyendo buffer");
                exit(-1);
        }
        close(fd);
        kbuf = kbuffer_alloc(KBUFFER_ENDIAN_SAME_AS_HOST,
                             KBUFFER_LSIZE_SAME_AS_HOST);
        if (!kbuf) {
                perror("Creando kbuffer");
                exit(-1);
        }
        ret = kbuffer_load_subbuffer(kbuf, buf);
        if (ret < 0) {
                perror("Cargando sub buffer");
                exit(-1);
        }
        if (kbuffer_subbuffer_size(kbuf) > st.st_size) {
                fprintf(stderr, "kbuffer es más grande que el tamaño crudo %d > %ld\n",
                        kbuffer_subbuffer_size(kbuf), st.st_size);
                exit(-1);
        }
        printf("Los datos de Kbuffer comienzan en %d\n", kbuffer_start_of_data(kbuf));
        do {
                event = kbuffer_read_event(kbuf, &ts);
                if (event) {
                        printf(" evento %3d ts:%lld\n", i++, ts);
                        event = kbuffer_next_event(kbuf, NULL);
                }
        } while (event);
        if (!event)
                printf("Terminó el sub buffer\n");
        kbuffer_free(kbuf);
        return 0;
}
