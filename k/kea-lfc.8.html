NOMBRE

kea-lfc - Proceso de Limpieza de Archivos de Concesión en Kea

SINOPSIS

kea-lfc [-4**|-6**] [-c archivo-config] [-p archivo-pid] [-x archivo-anterior] [-i archivo-copia] [-o archivo-salida] [-f archivo-final] [-v] [-V] [-W] [-d] [-h]

DESCRIPCIÓN

El servicio kea-lfc es un proceso que elimina información redundante de los archivos utilizados para proporcionar almacenamiento persistente al backend de la base de datos memfile. El servicio está escrito para ejecutarse como un proceso independiente. Si bien puede iniciarse externamente, generalmente no hay necesidad de hacerlo. Los servidores DHCP de Kea lo ejecutan periódicamente.

ARGUMENTOS

Los argumentos son los siguientes:

-4 | -6
Indica la versión del protocolo de los archivos de concesión; debe ser 4 o 6.
-c archivo-config
Especifica el archivo con la configuración para el proceso kea-lfc. También puede contener entradas de configuración para otros servicios de Kea. Actualmente kea-lfc obtiene todos sus argumentos de la línea de comandos.
-p archivo-pid
Especifica el archivo PID. Cuando el proceso kea-lfc se inicia, intenta determinar si otra instancia del proceso ya está en ejecución, examinando el archivo PID. Si ya hay una en ejecución, el nuevo proceso se termina. Si no hay ninguna en ejecución, Kea escribe su PID en el archivo PID.
-x archivo-anterior
Especifica el archivo de concesión anterior o ex-concesión. Cuando kea-lfc se inicia, este es el resultado de cualquier ejecución anterior de kea-lfc; cuando kea-lfc finaliza, es el resultado de la ejecución actual. Si kea-lfc se interrumpe antes de completarse, este archivo puede no existir.
-i archivo-copia
Especifica el archivo de entrada o copia del archivo de concesión. Antes de que el servidor DHCP invoque kea-lfc, mueve el archivo de concesión actual aquí y luego llama a kea-lfc con este archivo.
-o archivo-salida
Especifica el archivo de concesión de salida, que es el archivo temporal que kea-lfc debe usar para escribir las concesiones. Una vez que este archivo ha terminado de escribirse, se mueve al archivo de finalización (ver más abajo).
-f archivo-final
Especifica el archivo de finalización o conclusión, otro archivo temporal que kea-lfc utiliza para la contabilidad. Cuando kea-lfc termina de escribir el archivo de salida, lo mueve a este nombre de archivo. Después de que kea-lfc termina de eliminar los otros archivos (anterior y de entrada), mueve este archivo al archivo de concesión anterior. Al mover los archivos de esta manera, los procesos kea-lfc y DHCP pueden determinar el archivo correcto a utilizar, incluso si uno de los procesos se interrumpió antes de completar su tarea.
-v
Muestra la versión de Kea.
-V
Muestra la versión extendida de Kea.
-W
Muestra el informe de configuración.
-d
Establece el nivel de registro en depuración con verbosidad adicional. Esto es principalmente para fines de desarrollo en modo independiente.
-h
Hace que se imprima la cadena de uso.

DOCUMENTACIÓN

Kea viene con un extenso Manual de Referencia del Administrador de Kea que cubre todos los aspectos de la ejecución del software Kea: compilación, instalación, configuración, ejemplos de configuración y mucho más. Kea también incluye un Manual de Mensajes de Kea, que enumera todos los mensajes posibles que Kea puede imprimir con una breve descripción de cada uno. Ambos documentos están disponibles en varios formatos (.txt, .html, .pdf) con la distribución de Kea. La documentación de Kea está disponible en https://kea.readthedocs.io.

El código fuente de Kea está documentado en la Guía del Desarrollador de Kea, disponible en https://reports.kea.isc.org/dev_guide/.

El sitio web del proyecto Kea está disponible en https://kea.isc.org.

LISTAS DE MAILING Y SOPORTE

Hay dos listas de correo públicas disponibles para el proyecto Kea. kea-users (kea-users en lists.isc.org) está destinada a los usuarios de Kea, mientras que kea-dev (kea-dev en lists.isc.org) está destinada a los desarrolladores de Kea, contribuyentes potenciales y otros usuarios avanzados. Ambas listas están disponibles en https://lists.isc.org. La comunidad proporciona soporte de mejor esfuerzo en ambas listas.

ISC proporciona soporte profesional para los servicios de Kea. Consulte https://www.isc.org/kea/ para obtener más detalles.

HISTORIA

El proceso kea-lfc fue codificado por primera vez en enero de 2015 por el equipo de Kea/DHCP de ISC.
