Nombre

kitten-@-set-window-logo - Establecer el logo de la ventana

Uso

kitten @ set-window-logo RUTA_A_IMAGEN_PNG

Descripción

Establece la imagen del logo para las ventanas especificadas. Debe especificar la ruta a una imagen que se utilizará como logo. Si especifica el valor especial none, se eliminará cualquier logo existente. Los formatos de imagen admitidos son: PNG, JPEG, WEBP, GIF, BMP, TIFF.

Opciones

--match, -m
La ventana a coincidir. Las especificaciones de coincidencia son del tipo: campo:consulta. Donde campo puede ser uno de: id, title, pid, cwd, cmdline, num, env, var, state, neighbor, session y recent. consulta es la expresión a coincidir. Las expresiones pueden ser un número o una expresión regular, y se pueden combinar utilizando operadores booleanos.

El valor especial all coincide con todas las ventanas.

Para campos numéricos: id, pid, num y recent, la expresión se interpreta como un número, no como una expresión regular. Los valores negativos para id coinciden desde el número de id más alto hacia abajo, en particular, -1 es la ventana creada más recientemente.

El campo num se refiere a la posición de la ventana en la pestaña actual, comenzando desde cero y contando en sentido horario (este es el mismo orden en el que las ventanas son reportadas por el comando kitten @ ls).

El id de ventana de la ventana actual está disponible como la variable de entorno KITTY_WINDOW_ID.

El campo recent se refiere a las ventanas activas recientemente en la pestaña activa actual, siendo cero la ventana activa actual, uno la ventana previamente activa y así sucesivamente.

El campo neighbor se refiere a un vecino de la ventana activa en la dirección especificada, que puede ser: left, right, top o bottom.

El campo session coincide con las ventanas que se crearon en la sesión especificada. Utilice la expresión ^$ para coincidir con ventanas que no se crearon en una sesión y . para coincidir con la sesión actual y ~ para coincidir con la sesión actual o la última sesión activa cuando no hay ninguna sesión activa.

Al usar el campo env para coincidir con variables de entorno, puede especificar solo el nombre de la variable de entorno o un nombre y valor, por ejemplo, env:MY_ENV_VAR=2.

De manera similar, el campo var coincide con variables de usuario establecidas en la ventana. Puede especificar el nombre o el nombre y el valor como con el campo env.

El campo state coincide con el estado de la ventana. Los estados admitidos son: active, focused, needs_attention, parent_active, parent_focused, focused_os_window, self, overlay_parent. Las ventanas activas son las ventanas que están activas en su pestaña padre. Solo hay una ventana enfocada y es la ventana a la que se entregan los eventos del teclado. Si no hay ninguna ventana enfocada, se coincide con la última ventana enfocada. El valor focused_os_window coincide con todas las ventanas en la ventana del sistema operativo enfocada actualmente. El valor self coincide con la ventana en la que se ejecuta el comando de control remoto. El valor overlay_parent coincide con la ventana que está debajo de la ventana self, cuando la ventana self es una superposición.

Tenga en cuenta que puede usar el comando kitten @ ls para obtener una lista de ventanas.

--self [=no]
Actúa sobre la ventana en la que se ejecuta este comando, en lugar de la ventana activa.
--position
La posición del logo de la ventana. Véase window_logo_position.
--alpha [=-1]
La cantidad en la que el logo de la ventana debe desvanecerse en el fondo. Véase window_logo_position.
--no-response [=no]
No espere una respuesta de kitty. Esto significa que incluso si la configuración de la imagen falló, el comando saldrá con un código de éxito.
--help, -h [=no]
Mostrar ayuda para este comando

Opciones globales

--to
Una dirección para la instancia de kitty a controlar. Corresponde a la dirección dada a la instancia de kitty a través de la opción --listen-on o la configuración listen_on en kitty.conf. Si no se especifica, se comprueba la variable de entorno KITTY_LISTEN_ON. Si tampoco se encuentra, los mensajes se envían a la terminal de control para este proceso, es decir, solo funcionarán si este proceso se ejecuta dentro de una ventana de kitty.
--password
Una contraseña para usar al contactar con kitty. Esto hará que kitty solicite al usuario permiso para realizar la acción especificada, a menos que la contraseña haya sido aceptada previamente o esté preconfigurada en kitty.conf. Para usar una contraseña en blanco, especifique --use-password como siempre.
--password-file [=rc-pass]
Un archivo del que leer la contraseña. Los espacios en blanco al final se ignoran. Las rutas relativas se resuelven desde el directorio de configuración de kitty. Use - para leer desde STDIN. Use fd:num para leer desde el descriptor de archivo num. Se utiliza si no se proporciona --password. Por defecto, se comprueba el archivo rc-pass en el directorio de configuración de kitty.
--password-env [=KITTY_RC_PASSWORD]
El nombre de una variable de entorno de la que leer la contraseña. Se utiliza si no se proporciona --password-file. Por defecto, se comprueba la variable de entorno KITTY_RC_PASSWORD.
--use-password [=if-available]
Si no hay ninguna contraseña disponible, kitty normalmente enviará el comando de control remoto sin contraseña. Esta opción se puede utilizar para forzar el uso de la contraseña proporcionada siempre o nunca. Si se establece en always y no se proporciona ninguna contraseña, se utiliza la contraseña en blanco.

Opciones: if-available, always, never
