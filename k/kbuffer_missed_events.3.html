DESCRIPCIÓ

N

La función kbuffer_read_event() lee el siguiente evento en el descriptor kbuf y si ts no es NULL, colocará su marca de tiempo en él. Esto no modifica el descriptor kbuf, y llamar a esta función múltiples veces devolverá el mismo

resultado.

La función kbuffer_next_event() devolverá el siguiente evento en el descriptor kbuf. También establecerá ts a la marca de tiempo del evento devuelto. Se devuelve NULL si no hay más eventos y ts será indefinido. Nótese, si esto se llama directamente después de una kbuffer_load_subbuffer() entonces probablemente dará un resultado inesperado, ya que devolverá el segundo evento y no el primer evento. Usualmente esta función solo se usa para moverse al siguiente evento y saber si hay más eventos por leer, y kbuffer_read_event() siempre se llama

primero.

La función kbuffer_read_at_offset() devuelve el evento ubicado en un offset dado desde el comienzo del subbuffer. Este offset puede ser recuperado por kbuffer_curr_offset(). Si ts apunta a un unsigned long long, entonces se establecerá a la marca de tiempo del evento en el offset

dado.

Si el subbuffer había perdido eventos antes de él, entonces kbuffer_missed_events() devolverá un valor distinto de cero. Si devuelve -1, significa que hubo eventos perdidos, pero el número exacto de eventos perdidos es desconocido. Si devuelve un número positivo, entonces el número de eventos perdidos es el valor de

retorno.

La función kbuffer_event_size() devuelve el tamaño de la porción de datos del evento actual (el que sería devuelto por kbuffer_read_e

vent().

La función kbuffer_curr_size() devuelve el tamaño completo del registro del evento actual (el que sería devuelto por kbuffer_read_event(). La diferencia aquí es que el valor de retorno incluye el tamaño de los metadatos del registro del evento que no es parte de lo que es devuelto por kbuffer_read_e

vent().

La función kbuffer_curr_offset() devuelve el offset desde el comienzo del subbuffer de donde comienzan los metadatos del registro del evento actual. El primer evento no estará en el offset cero. Este offset puede ser usado para recuperar el evento con kbuffer_read_at_o

ffset().

La función kbuffer_curr_index() devuelve el índice desde el comienzo de la porción de datos del subbuffer donde están ubicados los metadatos del evento actual. El primer evento probablemente será cero, pero puede no serlo si hay una marca de tiempo adjunta a

él.

La función kbuffer_read_buffer() llenará el buffer dado desde el kbuf de la misma manera que el kernel haría una llamada al sistema read. Es decir, si la longitud len es menor que el tamaño del subbuffer, o el índice actual del kbuffer no es cero, comenzará a copiar desde el evento actual del kbuf y creará el buffer como un nuevo subbuffer (con una marca de tiempo y cabecera de commit) con ese evento encontrado e incluyendo todos los eventos posteriores que puedan caber dentro de len. El len debe incluir el tamaño de la cabecera del subbuffer así como los eventos a incluir. Es decir, len es el tamaño asignado del buffer que puede ser llenado. El retorno de esta función es el índice del final del último evento que fue agregado. Si no hay más eventos entonces se devuelve cero, y si el buffer no puede copiar ningún evento porque len era demasiado pequeño, e

ntonces s
e devuelve -1.

VALOR DE

RETORNO

kbuffer_read_event() devuelve el evento en el que el descriptor kbuf se encuentra actualmente, o NULL si el último evento fue pasado (por kbuffer_next_event())

.

kbuffer_next_event() devuelve el siguiente evento después del evento actual o NULL si no hay más

eventos.

kbuffer_read_at_offset() devuelve el evento en un offset dado desde el inicio del subbuffer almacenado en kbuf, o NULL si no existe ningún evento. Nótese, offset solo necesita ser un offset que caiga en el registro, o esté en su inicio. No necesita estar exactamente en el comienzo del

registro.

kbuffer_missed_events() devuelve 0 si no hubo eventos perdidos antes del subbuffer cargado. Devuelve -1 si hubo un número desconocido de eventos perdidos, o si el número de eventos perdidos es conocido, ese número será

devuelto.

kbuffer_event_size() devuelve el tamaño de la carga útil de datos del evento actual de kbuf

.

kbuffer_curr_size() devuelve el tamaño del registro completo del evento actual de kbuf. Esto incluye el tamaño de los metadatos de ese

registro.

kbuf_curr_offset() devuelve el offset del registro actual desde el comienzo del subbuffer

kbuf.

kbuf_curr_index() devuelve el índice del registro actual desde el comienzo de la sección de datos

kbuf.

kbuf_read_buffer() devuelve el índice del final del último evento que fue llenado en buffer. Si no hay más eventos para copiar desde start entonces se devuelve 0. Si len no es lo suficientemente grande para c

ontener algún evento, e
ntonces se devuelve -1.

EJEMPL

O 
#include <stdio.h>
#include <stdlib.h>
#include <fcntl.h>
#include <unistd.h>
#include <sys/stat.h>
#include <kbuffer.h>
int main (int argc, char **argv)
{
        unsigned long long ts;
        struct kbuffer *kbuf;
        struct stat st;
        char *buf;
        void *event;
        int save_offset = -1;
        int record_size;
        int offset;
        int index;
        int size;
        int ret;
        int fd;
        int i = 0;
        if (argc < 2) {
                printf("uso: %s raw-subbuffer-page\n", argv[0]);
                printf(" Prueba: dd count=1 bs=4096 if=/sys/kernel/tracing/per_cpu/cpu0/trace_pipe_raw of=/tmp/file\n");
                exit(0);
        }
        if (stat(argv[1], &st) < 0) {
                perror("stat");
                exit(-1);
        }
        buf = malloc(st.st_size);
        if (!buf) {
                perror("Allocando buffer");
                exit(-1);
        }
        fd = open(argv[1], O_RDONLY);
        if (fd < 0) {
                perror(argv[1]);
                exit(-1);
        }
        ret = read(fd, buf, st.st_size);
        if (ret < 0) {
                perror("Leyendo buffer");
                exit(-1);
        }
        close(fd);
        kbuf = kbuffer_alloc(KBUFFER_ENDIAN_SAME_AS_HOST,
                             KBUFFER_LSIZE_SAME_AS_HOST);
        if (!kbuf) {
                perror("Creando kbuffer");
                exit(-1);
        }
        ret = kbuffer_load_subbuffer(kbuf, buf);
        if (ret < 0) {
                perror("Cargando subbuffer");
                exit(-1);
        }
        if (kbuffer_subbuffer_size(kbuf) > st.st_size) {
                fprintf(stderr, "kbuffer es más grande que el tamaño crudo %d > %ld\n",
                        kbuffer_subbuffer_size(kbuf), st.st_size);
                exit(-1);
        }
        ret = kbuffer_missed_events(kbuf);
        if (ret) {
                if (ret > 0)
                        printf("Se perdieron %d eventos antes de este buffer\n", ret);
                else
                        printf("Se perdieron un número desconocido de eventos antes de este buffer\n");
        }
        do {
                event = kbuffer_read_event(kbuf, &ts);
                if (event) {
                        record_size = kbuffer_curr_size(kbuf);
                        offset = kbuffer_curr_offset(kbuf);
                        index = kbuffer_curr_index(kbuf);
                        size = kbuffer_event_size(kbuf);
                        if (i == 20)
                                save_offset = offset;
                        printf(" event %3d ts:%lld\trecord_size:%d size:%d\tindex:%d offset:%d\n",
                               i++, ts, record_size, size, index, offset);
                        event = kbuffer_next_event(kbuf, NULL);
                }
        } while (event);
        if (!event)
                printf("Finished sub buffer\n");
        if (save_offset > 0) {
                event = kbuffer_read_at_offset(kbuf, save_offset, &ts);
                if (!event) {
                        fprintf(stderr, "Funny, can't find event 20 at offset %d\n", save_offset);
                        exit(-1);
                }
                record_size = kbuffer_curr_size(kbuf);
                offset = kbuffer_curr_offset(kbuf);
                index = kbuffer_curr_index(kbuf);
                size = kbuffer_event_size(kbuf);
                printf("\n saved event 20 ts:%lld\trecord_size:%d size:%d\tindex:%d offset:%d\n\n",
                       ts, record_size, size, index, offset);
        }
        kbuffer_free(kbuf);
        return
0;
}
