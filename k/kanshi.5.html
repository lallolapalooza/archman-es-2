kanshi(5) Manual de formatos de archivo kanshi(5)

NOMBRE

kanshi - archivo de configuración

DESCRIPCIÓN

Un archivo de configuración de kanshi es una lista de perfiles. Cada perfil tiene un nombre opcional y contiene directivas de perfil delimitadas por corchetes ({ y }).

Ejemplo:

include /etc/kanshi/config.d/*
profile {
	output LVDS-1 disable
	output "Some Company ASDF 4242" {
		mode 1600x900
		position 0,0
	}
}
profile nomad {
	output LVDS-1 enable scale 2
}

DIRECTIVAS

profile [<nombre>] { <directivas de perfil...> }

Define un nuevo perfil utilizando las directivas de perfil delimitadas por corchetes especificadas. Se puede especificar un nombre, pero es opcional.

output <criterio> <directiva de salida...>

Define los valores predeterminados para las directivas de salida dentro de las definiciones de perfil.

Estos valores predeterminados solo se aplican cuando la salida respectiva se menciona en un perfil específico. Por ejemplo, los dos perfiles siguientes son equivalentes:

output eDP-1 scale 2
profile manual {
	output eDP-1 scale 2
}
profile uses-defaults {
	output eDP-1
}

Las directivas de salida se pueden especificar también en un bloque delimitado por corchetes.

include <ruta>

Incluye otro archivo desde ruta. Expande la sintaxis del shell (consulte wordexp(3) para obtener más detalles).

DIRECTIVAS DE PERFIL

Las directivas de perfil van seguidas de argumentos separados por espacios. Los argumentos pueden entrecomillarse (con ") si contienen espacios.

output <criterio> <directiva de salida...>

Una directiva de salida agrega una salida al perfil.

El criterio puede ser uno de:

  • Un nombre de salida (por ejemplo, "DP-1"). Tenga en cuenta que los nombres de salida pueden no ser estables: pueden cambiar entre reinicios (dependiendo del orden de sondeo del controlador del kernel) o el orden de creación (típicamente para bases de acoplamiento USB-C).
  • Una cadena separada por espacios que contiene el fabricante, modelo y número de serie de la salida (por ejemplo, "Foocorp ASDF 1234"). Se puede utilizar un patrón comodín (por ejemplo, "Foocorp ASDF *"), consulte glob(7). Si falta uno de estos campos, debe rellenarse con la cadena "Unknown" (por ejemplo, "Foocorp ASDF Unknown").
  • Un alias de salida (por ejemplo, "$work-desk3") definido por una directiva de alias de salida. Los alias de salida solo se pueden usar en el ámbito del perfil.
  • Un comodín "*", para que coincida con cualquier salida. Los comodines solo se pueden usar en el ámbito del perfil y solo coincidirán con una salida.

Las directivas de salida se pueden especificar también en un bloque delimitado por corchetes.

En sway(1), los nombres e identificadores de salida se pueden obtener mediante "swaymsg -t get_outputs".

exec <comando>

Una directiva exec ejecuta un comando cuando el perfil se aplicó correctamente. Esto se puede usar para actualizar el estado del compositor al perfil cuando no se hace automáticamente.

Los comandos se ejecutan de forma asíncrona y su orden puede no preservarse. Si necesita ejecutar comandos secuenciales, debe agruparlos en una declaración exec o en un script separado.

En sway(1), por ejemplo, exec se puede usar para mover espacios de trabajo a la salida correcta:

profile multihead {
	output eDP-1 enable
	output DP-1 enable transform 270
	exec swaymsg workspace 1, move workspace to eDP-1
}

Tenga en cuenta que se debe tener especial cuidado con las salidas identificadas por una descripción de salida, ya que el nombre real puede cambiar:

profile complex {
	output "Some Other Company GTBZ 2525" mode 1920x1200
	exec swaymsg workspace 1, move workspace to output '"Some Other Company GTBZ 2525"'
}

DIRECTIVAS DE SALIDA

enable|disable

Habilita o deshabilita la salida especificada.

mode [--custom] <ancho>x<alto>[@<frecuencia>[Hz]]

Configura la salida especificada para usar el modo especificado. Los modos son una combinación de ancho y alto (en píxeles) y una frecuencia de actualización (en Hz) que su pantalla puede configurarse para usar.

Ejemplos:

output HDMI-A-1 mode 1920x1080
output HDMI-A-1 mode 1920x1080@60Hz
output HDMI-A-1 mode --custom 1280x720@60Hz

position <x>,<y>

Coloca la salida en la posición especificada en el espacio de coordenadas global.

Ejemplo:

output HDMI-A-1 position 1600,0

scale <factor>

Escala la salida por el factor de escala especificado.

transform <transformación>

Establece la transformación de la salida. Puede ser una de "90", "180", "270" para una rotación; o "flipped", "flipped-90", "flipped-180", "flipped-270" para una rotación y un volteo; o "normal" para ninguna transformación.

adaptive_sync on|off

Habilita o deshabilita la sincronización adaptativa (también conocida como Frecuencia de Actualización Variable).

alias $<nombre>

Define un alias para esta salida. Los alias de salida solo se pueden definir en el ámbito global.
