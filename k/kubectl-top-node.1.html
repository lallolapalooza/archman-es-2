NOMBRE

kubectl top node - Muestra el uso de recursos (CPU/memoria) de los nodos

SINOPSIS

kubectl top node [OPCIONES]

DESCRIPCIÓN

Muestra el uso de recursos (CPU/memoria) de los nodos.

El comando top-node te permite ver el consumo de recursos de los nodos.

OPCIONES

--no-headers=false Si está presente, imprime la salida sin encabezados

-l, --selector="" Selector (consulta de etiquetas) para filtrar, soporta '=', '==', '!=', 'in', 'notin'.(ej. -l clave1=valor1,clave2=valor2,clave3 in (valor3)). Los objetos coincidentes deben cumplir con todas las restricciones de etiquetas especificadas.

--show-capacity=false Imprime los recursos del nodo basados en la Capacidad en lugar de los Asignables (por defecto) de los nodos.

--show-swap=false Imprime los recursos del nodo relacionados con la memoria swap.

--sort-by="" Si no está vacío, ordena la lista de nodos usando el campo especificado. El campo puede ser 'cpu' o 'memory'.

--use-protocol-buffers=true Habilita el uso de protocol-buffers para acceder a la API de Métricas.

OPCIONES HEREDADAS DE COMANDOS PADRE

--as="" Nombre de usuario a suplantar para la operación. El usuario puede ser un usuario regular o una cuenta de servicio en un namespace.

--as-group=[] Grupo a suplantar para la operación, este flag se puede repetir para especificar múltiples grupos.

--as-uid="" UID a suplantar para la operación.

--cache-dir="/home/username/.kube/cache" Directorio de caché predeterminado

--client-certificate="" Ruta a un archivo de certificado de cliente para TLS

--client-key="" Ruta a un archivo de clave de cliente para TLS

--cluster="" El nombre del clúster de kubeconfig a usar

--context="" El nombre del contexto de kubeconfig a usar

--disable-compression=false Si es verdadero, se opta por no comprimir las respuestas para todas las solicitudes al servidor

--insecure-skip-tls-verify=false Si es verdadero, el certificado del servidor no se verificará en cuanto a su validez. Esto hará que tus conexiones HTTPS no sean seguras

--kubeconfig="" Ruta al archivo kubeconfig a usar para las solicitudes de CLI.

--kuberc="" Ruta al archivo kuberc a usar para preferencias. Esto se puede deshabilitar exportando la puerta de enlace de funcionalidades KUBECTL_KUBERC=false o desactivando la funcionalidad KUBERC=off.

--match-server-version=false Requiere que la versión del servidor coincida con la versión del cliente

-n, --namespace="" Si está presente, el ámbito del namespace para esta solicitud de CLI

--password="" Contraseña para autenticación básica al servidor de la API

--profile="none" Nombre del perfil a capturar. Uno de (none|cpu|heap|goroutine|threadcreate|block|mutex)

--request-timeout="0" El tiempo de espera antes de desistir de una solicitud individual al servidor. Los valores distintos de cero deben contener una unidad de tiempo correspondiente (por ejemplo, 1s, 2m, 3h). Un valor de cero significa que no hay tiempo de espera para las solicitudes.

--token="" Token de portador para la autenticación al servidor de la API

--user="" El nombre de usuario de kubeconfig a usar

--username="" Nombre de usuario para autenticación básica al servidor de la API

--version=false --version, --version=raw imprime la información de la versión y sale; --version=vX.Y.Z... establece la versión informada

--warnings-as-errors=false Trata las advertencias recibidas del servidor como errores y sale con un código de salida distinto de cero

EJEMPLO

  # Muestra métricas para todos los nodos
  kubectl top node
  # Muestra métricas para un nodo dado
  kubectl top node NOMBRE_DEL_NODO
