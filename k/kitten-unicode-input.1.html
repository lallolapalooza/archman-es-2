kitten-unicode-input(1) Manual de kitten kitten-unicode-input(1)

Nombre

kitten-unicode-input - Navegar y seleccionar caracteres unicode por nombre

Uso

kitten unicode-input

Descripción

Introduce un carácter Unicode

Opciones

--emoji-variation [=none]
Si se debe usar la forma textual o gráfica para los emojis. Por defecto se utiliza la forma predeterminada especificada en el estándar Unicode para el símbolo.

Opciones: none, graphic, text

--tab [=previous]
La pestaña inicial a mostrar. Por defecto, utiliza la pestaña de la invocación anterior de kitten.

Opciones: previous, code, emoticons, favorites, name

--help, -h [=no]
Mostrar ayuda para este comando
