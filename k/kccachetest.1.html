NOMBRE

kccachetest - Interfaz de línea de comandos para probar la base de datos hash de caché

DESCRIPCIÓN

El comando `kccachetest' es una utilidad para pruebas de funcionalidad y de rendimiento de la base de datos hash de caché. Este comando se utiliza en el siguiente formato. `rnum' especifica el número de iteraciones.


kccachetest order [-th num] [-rnd] [-etc] [-tran] [-tc] [-bnum num] [-capcnt num] [-capsiz num] [-lv] rnum
Realiza pruebas en orden.
kccachetest queue [-th num] [-it num] [-rnd] [-tc] [-bnum num] [-capcnt num] [-capsiz num] [-lv] rnum
Realiza operaciones de cola.
kccachetest wicked [-th num] [-it num] [-tc] [-bnum num] [-capcnt num] [-capsiz num] [-lv] rnum
Realiza operaciones mixtas seleccionadas al azar.
kccachetest tran [-th num] [-it num] [-tc] [-bnum num] [-capcnt num] [-capsiz num] [-lv] rnum
Realiza pruebas de transacciones.

Las opciones presentan lo siguiente.

-th num : especifica el número de hilos trabajadores.
-rnd : realiza pruebas aleatorias.
-etc : realiza operaciones misceláneas.
-tran : realiza transacciones.
-tc : ajusta la base de datos con la opción de compresión.
-bnum num : especifica el número de cubetas de la tabla hash.
-capcnt num : especifica el número máximo de registros.
-capsiz num : especifica el tamaño máximo de uso de memoria.
-lv : informa de todos los errores.
-it num : especifica el número de repeticiones.

Este comando devuelve 0 en caso de éxito, otro número en caso de fallo.
