Nombre

kitten-ask - Pedir al usuario una entrada

Uso

kitten ask

Descripción

Pedir al usuario una entrada

Opciones

--type, -t [=line]
Tipo de entrada. Por defecto, pide una línea de texto.

Opciones: line, choices, file, password, yesno

--message, -m
El mensaje que se mostrará al usuario. Si no se especifica, se muestra un mensaje predeterminado.
--name, -n
El nombre de esta pregunta. Se utiliza para almacenar el historial de respuestas anteriores que pueden usarse para autocompletar y a través de los enlaces de historial de lectura de `readline`.
--title, --window-title
El título de la ventana en la que se muestra la pregunta. Solo se implementa para los tipos `yesno` y `choices`.
--choice, -c
Una opción para el tipo `choices`. Se puede especificar varias veces. Cada opción tiene la sintaxis: ``letra[;color]:texto``, donde `texto` es el texto de la opción y `letra` es la clave de selección. `letra` es una sola letra que pertenece a `texto`. Esta letra se resaltará dentro del texto de la opción. Puede haber una especificación de color opcional después de la letra para indicar qué color debe tener. Por ejemplo: y:Sí y n;rojo:No
--default, -d
Una opción o texto predeterminado. Si no se especifica, es `y` para el tipo `yesno`, la primera opción para `choices` y vacío para otros tipos. La opción predeterminada se selecciona cuando el usuario presiona la tecla Enter.
--prompt, -p [="> "]
El aviso que se utiliza al introducir una línea de texto o una contraseña.
--unhide-key [=u]
La tecla que se debe presionar para mostrar el texto oculto
--hidden-text-placeholder
El texto en el mensaje que se reemplazará por texto oculto. El texto oculto se lee a través de STDIN.
--help, -h [=no]
Mostrar ayuda para este comando
