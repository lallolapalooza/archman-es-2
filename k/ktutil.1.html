NOMBRE

ktutil - utilidad de mantenimiento de archivos keytab de Kerberos

SINOPSIS

ktutil

DESCRIPCIÓN

El comando ktutil invoca una interfaz de comandos desde la cual un administrador puede leer, escribir o editar entradas en un archivo keytab. (Los archivos srvtab de Kerberos V4 ya no son compatibles).

COMANDOS

list

list [-t] [-k] [-e]

Muestra la lista de claves actual. Si se especifican -t, -k y/o -e, también muestra la marca de tiempo, el contenido de la clave o el cifrado (respectivamente).

Alias: l

read_kt

read_kt keytab

Lee el archivo keytab de Kerberos V5 keytab en la lista de claves actual.

Alias: rkt

write_kt

write_kt keytab

Escribe la lista de claves actual en el archivo keytab de Kerberos V5 keytab.

Alias: wkt

clear_list

clear_list

Borra la lista de claves actual.

Alias: clear

delete_entry

delete_entry slot

Elimina la entrada en la posición número slot de la lista de claves actual.

Alias: delent

add_entry

add_entry {-key|-password} -p principal -k kvno [-e enctype] [-f|-s salt]

Añade principal a la lista de claves usando clave o contraseña. Si se especifica la opción -f, la información de sal se obtendrá del KDC; en este caso, la opción -e puede omitirse, o puede suministrarse para forzar un cifrado específico. Si no se especifica la opción -f, la opción -e debe especificarse, y se usará la sal predeterminada a menos que se anule con la opción -s.

Alias: addent

list_requests

list_requests

Muestra una lista de los comandos disponibles.

Alias: lr, ?

quit

quit

Sale de ktutil.

Alias: exit, q

EJEMPLO

ktutil:  add_entry -password -p alice@BLEEP.COM -k 1 -e
    aes128-cts-hmac-sha1-96
Password for alice@BLEEP.COM:
ktutil:  add_entry -password -p alice@BLEEP.COM -k 1 -e
    aes256-cts-hmac-sha1-96
Password for alice@BLEEP.COM:
ktutil:  write_kt alice.keytab
ktutil:
