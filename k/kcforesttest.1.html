NOMBRE

kcforesttest - interfaz de línea de comandos para probar la base de datos de árbol de directorios

DESCRIPCIÓN

El comando `kcforesttest' es una utilidad para pruebas de facilidad y pruebas de rendimiento de la base de datos de árbol de directorios. Este comando se utiliza en el siguiente formato. `ruta' especifica la ruta de un archivo de base de datos. `rnum' especifica el número de iteraciones.


kcforesttest order [-th num] [-rnd] [-set|-get|-getw|-rem|-etc] [-tran] [-oat|-onl|-onl|-otl|-onr] [-tc] [-bnum num] [-psiz num] [-pccap num] [-rcd|-rcld|-rcdd] [-lv] ruta rnum
Realiza pruebas en orden.
kcforesttest queue [-th num] [-it num] [-rnd] [-oat|-onl|-onl|-otl|-onr] [-tc] [-bnum num] [-psiz num] [-pccap num] [-rcd|-rcld|-rcdd] [-lv] ruta rnum
Realiza operaciones de cola.
kcforesttest wicked [-th num] [-it num] [-oat|-onl|-onl|-otl|-onr] [-tc] [-bnum num] [-psiz num] [-pccap num] [-rcd|-rcld|-rcdd] [-lv] ruta rnum
Realiza operaciones mixtas seleccionadas al azar.
kcforesttest tran [-th num] [-it num] [-hard] [-oat|-onl|-onl|-otl|-onr] [-tc] [-bnum num] [-psiz num] [-pccap num] [-rcd|-rcld|-rcdd] [-lv] ruta rnum
Realiza pruebas de transacción.

Las opciones incluyen lo siguiente.

-th num : especifica el número de hilos trabajadores.
-rnd : realiza pruebas aleatorias.
-set : realiza solo la operación de establecimiento.
-get : realiza solo la operación de obtención.
-getw : realiza solo la operación de obtención con búfer.
-rem : realiza solo la operación de eliminación.
-etc : realiza operaciones varias.
-tran : realiza transacciones.
-oat : abre la base de datos con la opción de transacción automática.
-oas : abre la base de datos con la opción de sincronización automática.
-onl : abre la base de datos sin bloqueo.
-otl : abre la base de datos con bloqueo de intento.
-onr : abre la base de datos sin reparación automática.
-tc : ajusta la base de datos con la opción de compresión.
-bnum num : especifica el número de cubetas de la tabla hash.
-psiz num : especifica el tamaño de cada página.
-pccap num : especifica el tamaño de capacidad de la caché de páginas.
-rcd : utiliza el comparador decimal en lugar del léxico.
-rcld : utiliza el comparador léxico descendente en lugar del ascendente.
-rcdd : utiliza el comparador decimal descendente en lugar del léxico.
-lv : informa de todos los errores.
-it num : especifica el número de repeticiones.
-hard : realiza sincronización física.

Este comando devuelve 0 en caso de éxito y otro valor en caso de fallo.
