KPARTX(8) Manual del Administrador del Sistema KPARTX(8)

NOMBRE

kpartx - Crea mapas de dispositivos a partir de tablas de particiones.

SINOPSIS

kpartx [-a|-d|-u|-l] [-r] [-p] [-f] [-g] [-s|-n] [-v] discoCompleto

DESCRIPCIÓN

Esta herramienta, derivada de util-linux partx, lee las tablas de particiones en el dispositivo especificado y crea mapas de dispositivos sobre los segmentos de particiones detectados. Se llama desde hotplug al crear y eliminar mapas de dispositivos.

OPCIONES

-a
Añade mapeos de particiones.
-d
Elimina mapeos de particiones.
-u
Actualiza mapeos de particiones.
-l
Lista los mapeos de particiones que se añadirían con -a.
-r
Mapeos de particiones de solo lectura.
-p
Establece el delimitador nombre_dispositivo-número_partición.
-f
Fuerza la creación de mapeos; anula la característica 'no_partitions'.
-g
Fuerza la tabla de particiones GUID (GPT).
-s
Modo síncrono (Por defecto). No retorna hasta que se crean las particiones.
-n
Modo nosync. Retorna antes de que se creen las particiones.
-v
Opera de forma detallada.

EJEMPLO

Para montar todas las particiones en una imagen de disco sin formato:

kpartx -av disco.img

Esto generará líneas como:

add map loop1p1 (254:4): 0 409597 linear 7:1 3

El loop1p1 es el nombre de un archivo de dispositivo bajo /dev/mapper que puede utilizar para acceder a la partición, por ejemplo para ejecutarle fsck:

fsck /dev/mapper/loop1p1

Cuando termine, deberá eliminar los dispositivos:

kpartx -d disco.img
