KEYUTILS(7) Gestión de claves del kernel KEYUTILS(7)

NOMBRE

keyutils - utilidades de gestión de claves en el kernel

DESCRIPCIÓN

El paquete keyutils es una biblioteca y un conjunto de utilidades para acceder a la instalación de keyrings del kernel.

Se proporciona un archivo de cabecera para ofrecer las definiciones y declaraciones necesarias para acceder a la biblioteca:

#include <keyutils.h>

Para enlazar con la biblioteca, se debe especificar lo siguiente al enlazador:

-lkeyutils

Se proporcionan tres llamadas al sistema:

add_key(2)
Suministrar una nueva clave al kernel.
request_key(2)
Encontrar una clave existente para su uso o, opcionalmente, crear una si no existe.
keyctl(2)
Controlar una clave de diversas maneras. La biblioteca proporciona una variedad de envoltorios alrededor de esta llamada al sistema y se deben usar en lugar de llamarla directamente.

Consulte las páginas del manual add_key(2), request_key(2) y keyctl(2) para obtener más información.

Los envoltorios de keyctl() se enumeran en la página del manual keyctl(3).

UTILIDADES

Se proporciona un programa para interactuar con la instalación del kernel mediante una serie de subcomandos, p. ej.:

keyctl add user foo bar @s

Consulte la página del manual keyctl(1) para obtener información al respecto.

El kernel tiene la capacidad de hacer "upcall" a userspace para fabricar nuevas claves. Esto puede ser activado por request_key(), pero es mejor que userspace use add_key() en su lugar si es posible.

El mecanismo de "upcall" generalmente se dirige a través del programa request-key(8). Lo que hace este programa con cualquier clave particular es configurable en:

/etc/request-key.conf
/etc/request-key.d/

Consulte las páginas del manual request-key.conf(5) y request-key(8) para obtener más información.
