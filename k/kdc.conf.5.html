kdc.conf - Archivo de configuración del KDC de Kerberos

V5

El archivo kdc.conf complementa a krb5.conf(5) para los programas que normalmente solo se utilizan en un KDC, como los demonios krb5kdc(8) y kadmind(8) y el programa kdb5_util(8). Las relaciones documentadas aquí también pueden especificarse en krb5.conf; para los programas KDC mencionados, krb5.conf y kdc.conf se fusionarán en un único perfil de

configuración.

Normalmente, el archivo kdc.conf se encuentra en el directorio de estado del KDC, /var/lib/krb5kdc. Puede anular la ubicación predeterminada configurando la variable de entorno KRB5_KDC_PROFILE

.

Tenga en cuenta que necesita reiniciar

el demonio KDC para que cualquier
cambio de configuración surta efecto.

[realms

Cada etiqueta en la sección [realms] es el nombre de un realm de Kerberos. El valor de la etiqueta es una subsección donde las relaciones definen los parámetros del KDC para ese realm en particular. El siguiente ejemplo muestra cómo definir un parámetro para el realm ATHENA.MIT.

EDU: 
[realms]
    ATHENA.MIT.EDU = {
        max_renewable_life = 7d 0h 0m 0s
}

La sección [dbmodules] contiene parámetros utilizados por la biblioteca de base de datos del KDC y los módulos de base de datos. Cada etiqueta en la sección [dbmodules] es el nombre de un reino de Kerberos o un nombre de sección especificado por el parámetro database_module de un reino.
