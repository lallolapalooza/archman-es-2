NOMBRE

krb5kdc - Servicio de Autenticación y Centro de Distribución de Claves (KDC) de Kerberos V5

SINOPSIS

krb5kdc [-x db_args] [-d dbname] [-k keytype] [-M mkeyname] [-p portnum] [-m] [-r realm] [-n] [-w numworkers] [-P pid_file] [-T time_offset]

DESCRIPCIÓN

krb5kdc es el Servicio de Autenticación y Centro de Distribución de Claves (AS/KDC) de Kerberos versión 5.

OPCIONES

La opción -r realm especifica el reino para el cual el servidor debe proporcionar servicio. Esta opción puede especificarse varias veces para servir a múltiples reinos. Si no se proporciona la opción -r, se servirá el reino por defecto (según se especifica en krb5.conf(5)).

La opción -d dbname especifica el nombre bajo el cual se puede encontrar la base de datos de principales. Esta opción no se aplica a la base de datos LDAP.

La opción -k keytype especifica el tipo de clave de la clave maestra que se ingresará manualmente como contraseña cuando se use -m; el valor por defecto es aes256-cts-hmac-sha1-96.

La opción -M mkeyname especifica el nombre principal de la clave maestra en la base de datos (generalmente K/M en el reino del KDC).

La opción -m especifica que la contraseña de la base de datos maestra se obtendrá del teclado en lugar de un archivo de almacenamiento (stash).

La opción -n especifica que el KDC no se ejecutará en segundo plano y no se desasociará de la terminal.

La opción -P pid_file indica al KDC que escriba su PID en pid_file después de iniciarse. Esto se puede usar para identificar si el KDC todavía se está ejecutando y para permitir que los scripts de inicio detengan el proceso correcto.

La opción -p portnum especifica los números de puerto UDP y TCP por defecto en los que el KDC debe escuchar las solicitudes de Kerberos versión 5, como una lista separada por comas. Este valor anula los números de puerto especificados en la sección kdcdefaults de kdc.conf(5), pero puede ser anulado por valores específicos del reino. Si no se proporciona ningún valor de ninguna fuente, el puerto por defecto es 88.

La opción -w numworkers indica al KDC que cree numworkers procesos para escuchar en los puertos del KDC y procesar las solicitudes en paralelo. El proceso KDC de nivel superior (cuyo pid se registra en el archivo pid si también se proporciona la opción -P) actúa como supervisor. El supervisor retransmitirá las señales SIGHUP a los subprocesos trabajadores y terminará los subprocesos trabajadores si se termina a sí mismo o si algún otro proceso trabajador sale.

La opción -x db_args especifica argumentos específicos de la base de datos. Consulte Opciones de base de datos en kadmin(1) para ver los argumentos admitidos.

La opción -T offset especifica un desfase de tiempo, en segundos, bajo el cual operará el KDC. Está destinado únicamente a fines de prueba.

EJEMPLO

El KDC puede atender solicitudes para múltiples reinos (máximo 32 reinos). Los reinos se listan en la línea de comandos. Las opciones por reino que se pueden especificar en la línea de comandos se aplican a cada reino que las sigue y son reemplazadas por definiciones posteriores de la misma opción.

Por ejemplo:

krb5kdc -p 2001 -r REALM1 -p 2002 -r REALM2 -r REALM3

especifica que el KDC escuche en el puerto 2001 para REALM1 y en el puerto 2002 para REALM2 y REALM3. Además, los parámetros por reino pueden especificarse en el archivo kdc.conf(5). La ubicación de este archivo puede ser especificada por la variable de entorno KRB5_KDC_PROFILE. Los parámetros por reino especificados en este archivo tienen prioridad sobre las opciones especificadas en la línea de comandos. Consulte la descripción de kdc.conf(5) para obtener más detalles.

MEDIO AMBIENTE

Consulte kerberos(7) para una descripción de las variables de entorno de Kerberos.
