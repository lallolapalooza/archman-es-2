Nombre

kitten-show-key - Muestra los códigos generados por la terminal para las pulsaciones de teclas en varios modos de teclado

Uso

kitten show-key

Descripción

Muestra los códigos generados por la terminal para las pulsaciones de teclas en varios modos de teclado

Opciones

--modo-teclado, -m [=normal]
El modo de teclado a usar al mostrar teclas. El modo normal es con DECCKM restablecido y el modo aplicación es con DECCKM establecido. kitty es el protocolo de teclado extendido completo de kitty.

Opciones: normal, aplicacion, kitty, sin_cambios

--ayuda, -h [=no]
Mostrar ayuda para este comando
