KIWIX-COMPILE-RESOURCES(1) Comandos de usuario KIWIX-COMPILE-RESOURCES(1)

NOMBRE

kiwix-compile-resources - ayudante para compilar y generar algunos recursos de Kiwix

SINOPSIS

kiwix-compile-resources [-h] [--cxxfile CXXFILE] [--hfile HFILE] resource_file ...

DESCRIPCIÓN

resource_file
La lista de recursos a compilar.
-h, --help
mostrar un mensaje de ayuda y salir
--cxxfile CXXFILE
El nombre del archivo Cpp a generar
--hfile HFILE
El nombre del archivo h a generar
