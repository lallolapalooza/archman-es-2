Nombre

kitten-desktop-ui-set-setting - Cambiar una configuración arbitraria

Uso

kitten desktop-ui set-setting clave [valor]

Descripción

Establece una configuración arbitraria. Si desea establecer el esquema de color, utilice el comando dedicado para ello. Utilice este comando con precaución, ya que no realiza ninguna validación del tipo de valor. La sintaxis para especificar valores se describe en: la documentación de glib. Omitir el valor o especificar un valor vacío eliminará la configuración.

Opciones

--namespace, -n [=org.freedesktop.appearance]
El espacio de nombres en el que cambiar la configuración.
--data-type
La firma del tipo de datos DBUS del valor. El valor predeterminado es adivinar a partir de la representación textual; consulte la documentación de glib para obtener detalles.
--help, -h [=no]
Mostrar ayuda para este comando
