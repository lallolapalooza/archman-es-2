Nombre

kitten-@-resize-os-window - Redimensionar/mostrar/ocultar/etc. las Ventanas del Sistema Operativo especificadas

Uso

kitten @ resize-os-window [Configuración del panel del SO ...]

Descripción

Redimensiona (u otras operaciones) las Ventanas del Sistema Operativo especificadas. Tenga en cuenta que algunos gestores de ventanas/entornos no permiten que las aplicaciones redimensionen sus ventanas, por ejemplo, los gestores de ventanas en mosaico.

Para modificar los Paneles del SO creados con el kitten del panel, use --action=os-panel. Especifique las modificaciones en la misma sintaxis que se usa en el kitten del panel, sin los guiones iniciales. Utilice la opción --incremental para cambiar solo la configuración especificada del panel. Por ejemplo, para mover el panel al borde inferior y hacerlo de dos líneas de alto: --action=os-panel --incremental lines=2 edge=bottom

Opciones

--match, -m
La ventana a coincidir. Las especificaciones de coincidencia son del tipo: campo:consulta. Donde campo puede ser uno de: id, title, pid, cwd, cmdline, num, env, var, state, neighbor, session y recent. consulta es la expresión a coincidir. Las expresiones pueden ser un número o una expresión regular, y se pueden combinar usando operadores booleanos.

El valor especial all coincide con todas las ventanas.

Para campos numéricos: id, pid, num y recent, la expresión se interpreta como un número, no como una expresión regular. Los valores negativos para id coinciden desde el número de id más alto hacia abajo, en particular, -1 es la ventana creada más recientemente.

El campo num se refiere a la posición de la ventana en la pestaña actual, comenzando desde cero y contando en sentido horario (este es el mismo orden en que las ventanas son reportadas por el comando kitten @ ls).

El id de ventana de la ventana actual está disponible como la variable de entorno KITTY_WINDOW_ID.

El campo recent se refiere a ventanas activadas recientemente en la pestaña activa actual, donde cero es la ventana activa actual, uno es la ventana previamente activa y así sucesivamente.

El campo neighbor se refiere a un vecino de la ventana activa en la dirección especificada, que puede ser: left, right, top o bottom.

El campo session coincide con ventanas que fueron creadas en la sesión especificada. Use la expresión ^$ para coincidir con ventanas que no fueron creadas en una sesión y . para coincidir con la sesión actualmente activa y ~ para coincidir con la sesión actual o la última sesión activa cuando no hay una sesión activa.

Al usar el campo env para coincidir con variables de entorno, puede especificar solo el nombre de la variable de entorno o un nombre y valor, por ejemplo, env:MY_ENV_VAR=2.

De manera similar, el campo var coincide con variables de usuario establecidas en la ventana. Puede especificar el nombre o el nombre y valor como con el campo env.

El campo state coincide con el estado de la ventana. Los estados admitidos son: active, focused, needs_attention, parent_active, parent_focused, focused_os_window, self, overlay_parent. Las ventanas activas son las ventanas que están activas en su pestaña padre. Solo hay una ventana enfocada y es la ventana a la que se entregan los eventos del teclado. Si ninguna ventana está enfocada, se coincide con la última ventana enfocada. El valor focused_os_window coincide con todas las ventanas en la ventana del SO enfocada actualmente. El valor self coincide con la ventana en la que se ejecuta el comando de control remoto. El valor overlay_parent coincide con la ventana que está debajo de la ventana self, cuando la ventana self es una superposición.

Tenga en cuenta que puede usar el comando kitten @ ls para obtener una lista de ventanas.

--action [=resize]
La acción a realizar.

Opciones: resize, hide, os-panel, show, toggle-fullscreen, toggle-maximized, toggle-visibility

--unit [=cells]
La unidad en la que interpretar los tamaños especificados.

Opciones: cells, pixels

--width [=0]
Cambia el ancho de la ventana. Cero deja el ancho sin cambios.
--height [=0]
Cambia la altura de la ventana. Cero deja la altura sin cambios.
--incremental [=no]
Trata los tamaños especificados como incrementos sobre el tamaño de ventana existente en lugar de tamaños absolutos. Al usar --action=os-panel, solo la configuración especificada se cambia, de lo contrario, la configuración no especificada mantiene su valor actual.
--self [=no]
Redimensiona la ventana en la que se ejecuta este comando, en lugar de la ventana activa.
--no-response [=no]
No espere una respuesta que indique el éxito de la acción. Tenga en cuenta que al usar esta opción, no se le notificará de los fallos.
--help, -h [=no]
Muestra la ayuda para este comando

Opciones globales

--to
Una dirección para la instancia de kitty a controlar. Corresponde a la dirección dada a la instancia de kitty a través de la opción --listen-on o la configuración listen_on en kitty.conf. Si no se especifica, se verifica la variable de entorno KITTY_LISTEN_ON. Si tampoco se encuentra, los mensajes se envían a la terminal de control de este proceso, es decir, solo funcionarán si este proceso se ejecuta dentro de una ventana de kitty.
--password
Una contraseña para usar al contactar a kitty. Esto hará que kitty solicite al usuario permiso para realizar la acción especificada, a menos que la contraseña haya sido aceptada anteriormente o esté preconfigurada en kitty.conf. Para usar una contraseña en blanco, especifique --use-password como siempre.
--password-file [=rc-pass]
Un archivo del cual leer la contraseña. Los espacios en blanco finales se ignoran. Las rutas relativas se resuelven desde el directorio de configuración de kitty. Use - para leer desde STDIN. Use fd:num para leer desde el descriptor de archivo num. Se usa si no se proporciona --password. Por defecto, se verifica el archivo rc-pass en el directorio de configuración de kitty.
--password-env [=KITTY_RC_PASSWORD]
El nombre de una variable de entorno desde la cual leer la contraseña. Se usa si no se proporciona --password-file. Por defecto, se verifica la variable de entorno KITTY_RC_PASSWORD.
--use-password [=if-available]
Si no hay contraseña disponible, kitty generalmente enviará el comando de control remoto sin contraseña. Esta opción se puede usar para forzarlo a usar siempre o nunca la contraseña proporcionada. Si se establece en always y no se proporciona contraseña, se usa la contraseña en blanco.

Opciones: if-available, always, never

kitten(1)

El comando Kitten - Redimensionar ventana del sistema operativo

NAME

kitten - Redimensionar la ventana del sistema operativo

SYNOPSIS

kitten resize os-window <id> <width> <height>

DESCRIPTION

Redimensiona la ventana del sistema operativo especificada por el ID dado a las dimensiones dadas.

OPTIONS

<id>
El ID único de la ventana del sistema operativo.
<width>
El ancho deseado de la ventana en píxeles.
<height>
La altura deseada de la ventana en píxeles.

GLOBAL OPTIONS

Para una lista de opciones globales que se pueden pasar a todos los comandos de Kitten, consulta kitten help global.
