NOMBRE

khard.conf - archivo de configuración para khard

RESUMEN

El archivo de configuración de khard es un archivo de texto plano con una sintaxis similar a ini. Muchas opciones tienen una opción de línea de comandos correspondiente. La única sección obligatoria en el archivo de configuración es la definición de las agendas disponibles.

UBICACIÓN

El archivo se busca en $XDG_CONFIG_HOME/khard/khard.conf. Si la variable de entorno $XDG_CONFIG_HOME no está definida, se utiliza ~/.config/ en su lugar.

La ubicación se puede cambiar con la variable de entorno $KHARD_CONFIG o la opción de línea de comandos -c (que tiene prioridad).

SINTAXIS

Admite secciones marcadas con corchetes y secciones anidadas con más corchetes. Cada sección contiene varias claves con valores delimitados por signos de igual. Los valores son tipificados y se verifica su tipo.

OPCIONES

El archivo de configuración consta de estas cuatro secciones:

agendas
Esta sección contiene varias subsecciones, pero al menos una. Cada subsección puede tener un nombre arbitrario que será el nombre de una agenda conocida por khard. Cada una de estas subsecciones debe tener una clave path con la ruta a la carpeta que contiene los archivos vCard para esa agenda. Opcionalmente, puede establecer el valor type en discover o vdir, el valor predeterminado. El valor path admite variables de entorno y prefijos de tilde. Al usar el tipo discover, también admite globbing. khard espera que los archivos vCard contengan solo un registro VCARD cada uno y terminen con la extensión .vcf.
general
Esta sección permite configurar algunas características generales sobre khard. Las siguientes claves están disponibles en esta sección:
  • debug: una indicación booleana de si el nivel de registro debe establecerse en debug por defecto (mismo efecto que la opción --debug en la línea de comandos)
  • default_action: la acción/subcomando predeterminado a usar si el primer argumento que no es una opción no coincide con ninguno de los subcomandos disponibles
  • editor: el editor de texto a usar para editar las entradas de la agenda, si no se proporciona se usará $EDITOR
  • merge_editor: un comando utilizado para fusionar dos tarjetas interactivamente, si no se proporciona se usará $MERGE_EDITOR
tabla de contacto
Esta sección se utiliza para configurar el comportamiento de las diferentes listas de salida de khard. Las siguientes claves están disponibles:
  • display: qué parte del nombre usar en las listas; esto puede ser first_name, last_name o formatted_name
  • group_by_addressbook: si se agrupan o no los contactos por agenda en las listas
  • localize_dates: si se localizan las fechas o se utilizan formatos de fecha ISO
  • preferred_email_address_type: etiquetas de las direcciones de correo electrónico a preferir
  • preferred_phone_number_type: etiquetas de los números de teléfono a preferir
  • reverse: si se invierte o no el orden de las listas de contactos
  • show_nicknames: si se muestran o no los apodos
  • show_uids: si se muestran o no los UID
  • show_kinds: si se muestran o no los tipos (kinds)
  • sort: campo por el cual ordenar las listas de contactos
vcard
  • private_objects: una lista de cadenas, estos son los nombres de los campos privados de vCard (que comienzan con X-) que serán cargados y mostrados por khard
  • search_in_source_files: si se busca en los archivos vCard antes de analizarlos para acelerar las búsquedas
  • skip_unparsable: si se omiten las vCard no analizables, de lo contrario khard sale en la primera tarjeta no analizable que encuentra
  • preferred_version: la versión de vCard preferida a usar para tarjetas nuevas

EJEMPLO

Este es el archivo de configuración de ejemplo:

# archivo de configuración de ejemplo para khard versión > 0.14.0
# colócalo en ~/.config/khard/khard.conf
# Este archivo es analizado por la biblioteca configobj. La sintaxis se describe en
# https://configobj.readthedocs.io/en/latest/configobj.html#the-config-file-format
[addressbooks]
[[family]]
path = ~/.contacts/family/
[[friends]]
path = ~/.contacts/friends/
[[work]]
path = ~/.work/**/client-*-contacts/
type = discover
[general]
debug = no
default_action = list
# Estos son cadenas o listas separadas por comas
editor = vim, -i, NONE
merge_editor = vimdiff
[contact table]
# mostrar nombres por nombre o apellido: first_name / last_name / formatted_name
display = first_name
# agrupar por agenda: yes / no
group_by_addressbook = no
# invertir el orden de la tabla: yes / no
reverse = no
# añadir apodos al nombre: yes / no
show_nicknames = no
# mostrar columna de UID de la tabla: yes / no
show_uids = yes
# mostrar columna de tipo de la tabla: yes / no
show_kinds = no
# ordenar por nombre o apellido: first_name / last_name / formatted_name
sort = last_name
# localizar fechas: yes / no
localize_dates = yes
# establecer una lista separada por comas de tipos de números de teléfono preferidos en orden de prioridad descendente
# o nada para orden alfabético sin filtrar
preferred_phone_number_type = pref, cell, home
# establecer una lista separada por comas de tipos de direcciones de correo electrónico preferidos en orden de prioridad descendente
# o nada para orden alfabético sin filtrar
preferred_email_address_type = pref, work, home
[vcard]
# extender contactos con tus propios objetos privados
# estos objetos se almacenan con una "X-" inicial antes del nombre del objeto en los archivos vcard
# cada etiqueta de objeto solo puede contener letras, dígitos y el carácter -
# ejemplo:
#   private_objects = Jabber, Skype, Twitter
# predeterminado: , (la lista vacía)
private_objects = Jabber, Skype, Twitter
# versión vcard preferida: 3.0 / 4.0
preferred_version = 3.0
# buscar en los archivos fuente para acelerar las consultas de búsqueda: yes / no
search_in_source_files = no
# omitir archivos vcard no analizables: yes / no
skip_unparsable = no
