Nombre

kitten-@-load-config - (Re)cargar un archivo de configuración

Uso

kitten @ load-config ARCHIVO_CONF ...

Descripción

(Re)carga los archivos de configuración de kitty.conf especificados. Si no se especifican archivos, se recarga el archivo de configuración especificado anteriormente. Tenga en cuenta que las rutas especificadas deben existir y ser legibles por el proceso de kitty en el ordenador en el que se ejecuta dicho proceso. Las rutas relativas se resuelven con respecto al directorio de configuración de kitty en el ordenador que ejecuta kitty.

Opciones

--ignorar-sobrescrituras [=no]
Por defecto, se respetan las sobrescrituras de configuración previamente especificadas en la línea de comandos de invocación de kitty o en un comando anterior de load-config-file. Utilice esta opción para ignorarlas en su lugar.
--sobrescribir, -o
Sobrescribe opciones de configuración individuales, se puede especificar varias veces. Sintaxis: nombre=valor. Por ejemplo: -o font_size=20
--sin-respuesta [=no]
No espere una respuesta que indique el éxito de la acción. Tenga en cuenta que el uso de esta opción significa que no se le notificará de los fallos.
--ayuda, -h [=no]
Mostrar ayuda para este comando

Opciones globales

--a
Una dirección para la instancia de kitty a controlar. Corresponde a la dirección proporcionada a la instancia de kitty a través de la opción --listen-on o la configuración listen_on en kitty.conf. Si no se especifica, se comprueba la variable de entorno KITTY_LISTEN_ON. Si tampoco se encuentra, los mensajes se envían a la terminal de control de este proceso, es decir, solo funcionarán si este proceso se ejecuta dentro de una ventana de kitty.
--contrase%C3%B1a
Una contraseña para usar al contactar con kitty. Esto hará que kitty solicite al usuario permiso para realizar la acción especificada, a menos que la contraseña haya sido aceptada previamente o esté preconfigurada en kitty.conf. Para usar una contraseña en blanco, especifique --usar-contrase%C3%B1a como siempre.
--archivo-contrase%C3%B1a [=rc-pass]
Un archivo del que leer la contraseña. Los espacios en blanco finales se ignoran. Las rutas relativas se resuelven desde el directorio de configuración de kitty. Use - para leer desde STDIN. Use fd:num para leer desde el descriptor de archivo num. Se usa si no se proporciona --contrase%C3%B1a. Por defecto, se busca el archivo rc-pass en el directorio de configuración de kitty.
--env-contrase%C3%B1a [=KITTY_RC_PASSWORD]
El nombre de una variable de entorno de la que leer la contraseña. Se usa si no se proporciona --archivo-contrase%C3%B1a. Por defecto, se comprueba la variable de entorno KITTY_RC_PASSWORD.
--usar-contrase%C3%B1a [=si-disponible]
Si no hay contraseña disponible, kitty normalmente enviará el comando de control remoto sin contraseña. Esta opción se puede usar para forzar que siempre o nunca use la contraseña proporcionada. Si se establece en "siempre" y no se proporciona ninguna contraseña, se utiliza la contraseña en blanco.

Opciones: si-disponible, siempre, nunca
