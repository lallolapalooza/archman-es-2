NOMBRE

kubectl rollout resume - Reanuda un recurso pausado

SINOPSIS

kubectl rollout resume [OPCIONES]

DESCRIPCIÓN

Reanuda un recurso pausado.

Los recursos pausados no serán reconciliados por un controlador. Al reanudar un recurso, permitimos que sea reconciliado de nuevo. Actualmente, solo los despliegues admiten ser reanudados.

OPCIONES

--allow-missing-template-keys=true Si es verdadero, ignora cualquier error en las plantillas cuando un campo o clave de mapa falta en la plantilla. Solo se aplica a los formatos de salida golang y jsonpath.

--field-manager="kubectl-rollout" Nombre del gestor utilizado para rastrear la propiedad de los campos.

-f, --filename=[] Nombre de archivo, directorio o URL de archivos que identifican el recurso a obtener de un servidor.

-k, --kustomize="" Procesa el directorio kustomization. Esta bandera no puede usarse junto con -f o -R.

-o, --output="" Formato de salida. Uno de: (json, yaml, name, go-template, go-template-file, template, templatefile, jsonpath, jsonpath-as-json, jsonpath-file).

-R, --recursive=false Procesa el directorio utilizado en -f, --filename de forma recursiva. Útil cuando se desean gestionar manifiestos relacionados organizados dentro del mismo directorio.

-l, --selector="" Selector (consulta de etiqueta) para filtrar, soporta '=', '==', '!=', 'in', 'notin'. (ej. -l key1=value1,key2=value2,key3 in (value3)). Los objetos coincidentes deben satisfacer todas las restricciones de etiqueta especificadas.

--show-managed-fields=false Si es verdadero, mantiene los managedFields al imprimir objetos en formato JSON o YAML.

--template="" Cadena de plantilla o ruta a un archivo de plantilla a utilizar cuando -o=go-template, -o=go-template-file. El formato de plantilla es el de plantillas de golang [http://golang.org/pkg/text/template/#pkg-overview].

--cluster="" El nombre del clúster kubeconfig a utilizar

--insecure-skip-tls-verify=false Si es verdadero, el certificado del servidor no se verificará para determinar su validez. Esto hará que sus conexiones HTTPS no sean seguras

--kubeconfig="" Ruta al archivo kubeconfig a utilizar para las solicitudes de CLI.

--kuberc="" Ruta al archivo kuberc a utilizar para preferencias. Esto puede ser deshabilitado exportando la puerta de enlace de características KUBECTL_KUBERC=false o desactivando la característica KUBERC=off.

-n, --namespace="" Si está presente, el ámbito del namespace para esta solicitud de CLI

-s, --server="" La dirección y el puerto del servidor de API de Kubernetes

--tls-server-name="" Nombre del servidor a utilizar para la validación del certificado del servidor. Si no se proporciona, se usa el nombre de host utilizado para contactar al servidor

--user="" El nombre de usuario kubeconfig a utilizar
