NOMBRE

kubectl config get-clusters - Muestra los clústeres definidos en el kubeconfig

SINOPSIS

kubectl config get-clusters [OPCIONES]

DESCRIPCIÓN

Muestra los clústeres definidos en el kubeconfig.

OPCIONES HEREDADAS DE COMANDOS PADRE

--as="" Nombre de usuario a suplantar para la operación. El usuario puede ser un usuario normal o una cuenta de servicio en un espacio de nombres.

--as-group=[] Grupo a suplantar para la operación, esta bandera se puede repetir para especificar varios grupos.

--as-uid="" UID a suplantar para la operación.

--cache-dir="/home/username/.kube/cache" Directorio de caché predeterminado

--certificate-authority="" Ruta a un archivo de certificado para la autoridad de certificación

--client-certificate="" Ruta a un archivo de certificado de cliente para TLS

--client-key="" Ruta a un archivo de clave de cliente para TLS

--cluster="" El nombre del clúster kubeconfig a usar

--context="" El nombre del contexto kubeconfig a usar

--disable-compression=false Si es true, se opta por no comprimir las respuestas para todas las solicitudes al servidor

--insecure-skip-tls-verify=false Si es true, el certificado del servidor no se verificará en cuanto a validez. Esto hará que tus conexiones HTTPS no sean seguras

--kubeconfig="" usar un archivo kubeconfig particular

--kuberc="" Ruta al archivo kuberc a usar para preferencias. Esto se puede deshabilitar exportando el feature gate KUBECTL_KUBERC=false o desactivando el feature KUBERC=off.

--match-server-version=false Requerir que la versión del servidor coincida con la versión del cliente

-n, --namespace="" Si está presente, el ámbito del espacio de nombres para esta solicitud de CLI

--password="" Contraseña para la autenticación básica al servidor API

--profile="none" Nombre del perfil a capturar. Uno de (none|cpu|heap|goroutine|block|mutex)

--profile-output="profile.pprof" Nombre del archivo donde escribir el perfil

--request-timeout="0" El tiempo de espera antes de renunciar a una única solicitud al servidor. Los valores distintos de cero deben contener una unidad de tiempo correspondiente (por ejemplo, 1s, 2m, 3h). Un valor de cero significa no agotar el tiempo de espera de las solicitudes.

-s, --server="" La dirección y el puerto del servidor API de Kubernetes

--tls-server-name="" Nombre del servidor a usar para la validación del certificado del servidor. Si no se proporciona, se utiliza el nombre de host utilizado para contactar al servidor

--token="" Token de portador para la autenticación al servidor API

--user="" El nombre del usuario kubeconfig a usar

--username="" Nombre de usuario para la autenticación básica al servidor API

--version=false --version, --version=raw imprime información de versión y sale; --version=vX.Y.Z... establece la versión reportada

--warnings-as-errors=false Tratar las advertencias recibidas del servidor como errores y salir con un código de salida distinto de cero

EJEMPLO

  # Listar los clústeres que kubectl conoce
  kubectl config get-clusters
