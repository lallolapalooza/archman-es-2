NOMBRE

kctreetest - interfaz de línea de comandos para probar la base de datos de árbol de archivos

DESCRIPCIÓN

El comando `kctreetest' es una utilidad para pruebas de facilidad y pruebas de rendimiento de la base de datos de árbol de archivos. Este comando se utiliza en el siguiente formato. `ruta' especifica la ruta de un archivo de base de datos. `num_iter' especifica el número de iteraciones.


kctreetest order [-th num] [-rnd] [-set|-get|-getw|-rem|-etc] [-tran] [-oat|-onl|-onl|-otl|-onr] [-apow num] [-fpow num] [-ts] [-tl] [-tc] [-bnum num] [-psiz num] [-msiz num] [-dfunit num] [-pccap num] [-rcd|-rcld|-rcdd] [-lv] ruta num_iter
Realiza pruebas en orden.
kctreetest queue [-th num] [-it num] [-rnd] [-oat|-onl|-onl|-otl|-onr] [-apow num] [-fpow num] [-ts] [-tl] [-tc] [-bnum num] [-psiz num] [-msiz num] [-dfunit num] [-pccap num] [-rcd|-rcld|-rcdd] [-lv] ruta num_iter
Realiza operaciones de cola.
kctreetest wicked [-th num] [-it num] [-oat|-onl|-onl|-otl|-onr] [-apow num] [-fpow num] [-ts] [-tl] [-tc] [-bnum num] [-psiz num] [-msiz num] [-dfunit num] [-pccap num] [-rcd|-rcld|-rcdd] [-lv] ruta num_iter
Realiza operaciones mixtas seleccionadas al azar.
kctreetest tran [-th num] [-it num] [-hard] [-oat|-onl|-onl|-otl|-onr] [-apow num] [-fpow num] [-ts] [-tl] [-tc] [-bnum num] [-psiz num] [-msiz num] [-dfunit num] [-pccap num] [-rcd|-rcld|-rcdd] [-lv] ruta num_iter
Realiza pruebas de transacción.

Las opciones presentan lo siguiente.

-th num : especifica el número de hilos de trabajo.
-rnd : realiza prueba aleatoria.
-set : solo realiza operación de establecimiento.
-get : solo realiza operación de obtención.
-getw : solo realiza obtención con operación de búfer.
-rem : solo realiza operación de eliminación.
-etc : realiza operaciones misceláneas.
-tran : realiza transacción.
-oat : abre la base de datos con la opción de transacción automática.
-oas : abre la base de datos con la opción de sincronización automática.
-onl : abre la base de datos con la opción de sin bloqueo.
-otl : abre la base de datos con la opción de intentar bloqueo.
-onr : abre la base de datos sin la opción de reparación automática.
-apow num : especifica la potencia de la alineación del tamaño del registro.
-fpow num : especifica la potencia de la capacidad del grupo de bloques libres.
-ts : ajusta la base de datos con la opción pequeña.
-tl : ajusta la base de datos con la opción lineal.
-tc : ajusta la base de datos con la opción de compresión.
-bnum num : especifica el número de cubetas de la tabla hash.
-psiz num : especifica el tamaño de cada página.
-msiz num : especifica el tamaño de la región mapeada en memoria.
-dfunit num : especifica el número de paso de la unidad de desfragmentación automática.
-pccap num : especifica el tamaño de capacidad de la caché de páginas.
-rcd : utiliza el comparador decimal en lugar del léxico.
-rcld : utiliza el comparador léxico descendente en lugar del ascendente.
-rcdd : utiliza el comparador decimal descendente en lugar del léxico.
-lv : informa todos los errores.
-it num : especifica el número de repetición.
-hard : realiza sincronización física.

Este comando devuelve 0 en caso de éxito, y otro valor en caso de fallo.
