KEYBOXD(1) Comandos de usuario KEYBOXD(1)

NOMBRE

keyboxd - Servicio de gestión de claves públicas para GnuPG

SINOPSIS

keyboxd [OPCIONES] [COMANDO]

DESCRIPCIÓN

keyboxd es un servicio de gestión de claves públicas para GnuPG.

COMANDOS

Los comandos no se distinguen de las opciones, excepto por el hecho de que solo se permite un comando.

--version
Imprime la versión del programa y la información de licencia.
--help
Imprime un mensaje de uso que resume las opciones de línea de comandos más útiles.
--server
Ejecuta en modo servidor y espera comandos en la entrada estándar. El modo predeterminado es crear un socket y escuchar comandos allí. Esto solo se usa para pruebas.
--daemon
Ejecuta en modo demonio en segundo plano y escucha comandos en un socket. Esta es la forma en que keyboxd se inicia a demanda por otros componentes de GnuPG. Para forzar el inicio de keyboxd, generalmente es mejor usar gpgconf --launch keyboxd.
--supervised
Ejecuta en primer plano, enviando registros a stderr y escuchando en el descriptor de archivo 3, que debe estar previamente enlazado a un socket de escucha. Esto es útil cuando se ejecuta bajo systemd u otros esquemas de supervisión de procesos similares. Esta opción no es compatible con Windows.

OPCIONES

Tenga en cuenta que todas las opciones largas, con la excepción de --options y --homedir, también se pueden especificar en el archivo de configuración después de eliminar los dos guiones iniciales.

--options archivo
Lee la configuración del archivo en lugar del archivo de configuración por usuario predeterminado. El archivo de configuración predeterminado se llama ‘keyboxd.conf’ y se espera en el directorio personal.
--homedir dir
Establece el nombre del directorio personal a dir. Esta opción solo es efectiva cuando se usa en la línea de comandos. El valor predeterminado es el directorio llamado ‘.gnupg’ directamente debajo del directorio personal del usuario, a menos que la variable de entorno GNUPGHOME se haya establecido, en cuyo caso se utilizará su valor. Muchos tipos de datos se almacenan dentro de este directorio.
-v
--verbose
Muestra información adicional mientras se ejecuta. Puede aumentar la verbosidad proporcionando varios comandos de verbosidad a keyboxd, como -vv.
--log-file archivo
Agrega toda la salida de registro al archivo. Esto es muy útil para ver lo que el agente realmente hace. Use ‘socket://’ para registrar en un socket.
--debug-level nivel
Selecciona el nivel de depuración para investigar problemas. nivel puede ser un valor numérico o una palabra clave:
none
Sin depuración en absoluto. Se puede usar un valor menor que 1 en lugar de la palabra clave.
basic
Algunos mensajes de depuración básicos. Se puede usar un valor entre 1 y 2 en lugar de la palabra clave.
advanced
Mensajes de depuración más detallados. Se puede usar un valor entre 3 y 5 en lugar de la palabra clave.
expert
Mensajes aún más detallados. Se puede usar un valor entre 6 y 8 en lugar de la palabra clave.
guru
Todos los mensajes de depuración que se pueden obtener. Se puede usar un valor mayor que 8 en lugar de la palabra clave. La creación de archivos de rastreo de hash solo se habilita si se utiliza la palabra clave.

No se especifica cómo se mapean estos mensajes a las banderas de depuración reales y puede cambiar con versiones más nuevas de este programa. Sin embargo, están cuidadosamente seleccionados para ayudar mejor en la depuración.

--debug banderas
Establece las banderas de depuración. Esta opción solo es útil para depurar y su comportamiento puede cambiar con una nueva versión. Todas las banderas se combinan mediante OR y se pueden proporcionar en sintaxis C (por ejemplo, 0x0042) o como una lista separada por comas de nombres de banderas. Para obtener una lista de todas las banderas compatibles, se puede usar la palabra única "help".
--debug-all
Igual que --debug=0xffffffff

ARCHIVOS

Keyboxd utiliza un archivo de configuración que controla la operación de keyboxd. Por defecto, todos pueden encontrarse en el directorio personal actual (ver: [opción --homedir]).

keyboxd.conf
Este es el archivo de configuración estándar que lee keyboxd al arrancar. Puede contener cualquier opción larga válida; no se pueden introducir los dos guiones iniciales y la opción no se puede abreviar. Este archivo también se lee después de una señal SIGHUP, sin embargo, no todas las opciones tendrán un efecto real. Este nombre predeterminado se puede cambiar en la línea de comandos (ver: [opción --options]). Debe hacer una copia de seguridad de este archivo.
pubring.db
Este archivo es una base de datos en formato SQLite, para material de claves públicas. Debe hacer una copia de seguridad de este archivo.
