KPACKAGETOOL6(1) Gestor de paquetes KPackage KPACKAGETOOL6(1)

NOMBRE

kpackagetool6 - Instala, lista y elimina paquetes de Plasma

SINOPSIS

kpackagetool6 [-v, --version] [-h, --help] [--hash ruta] [-g, --global] [-t, --type tipo] [-i, --install ruta] [-s, --show nombre] [-u, --upgrade ruta] [-l, --list] [--list-types] [-r, --remove nombre] [-p, --packageroot ruta] [--generate-index]

DESCRIPCIÓN

kpackagetool6 es una herramienta de línea de comandos para instalar, listar y eliminar paquetes de Plasma.

OPCIONES

-v, --version

Muestra información de la versión.

-h, --help

Muestra esta ayuda.

--hash ruta

Genera un hash SHA1 para el paquete en “ruta”.

-g, --global

Para instalar o eliminar, opera sobre paquetes instalados para todos los usuarios.

-t, --type tipo

El tipo de paquete, correspondiente al tipo de servicio del complemento del paquete, por ejemplo, KPackage/Generic, Plasma/Theme, Plasma/Wallpaper, Plasma/Applet, etc.

-i, --install ruta

Instala el paquete en “ruta”.

-s, --show nombre

Muestra información del paquete “nombre”.

-u, --upgrade ruta

Actualiza el paquete en “ruta”.

-l, --list

Lista los paquetes instalados.

--list-types

Lista todos los tipos de paquetes conocidos que se pueden instalar.

-r, --remove nombre

Elimina el paquete llamado “nombre”.

-p, --packageroot ruta

Ruta absoluta a la raíz del paquete. Si no se proporciona, entonces se buscarán los directorios de datos estándar para esta sesión de Plasma.

--generate-index ruta

Recrea el índice del complemento. Para ser utilizado en conjunción con la opción -t o -g. Recrea el índice para el tipo dado o la raíz del paquete. Opera en el directorio del usuario, a menos que se use -g.

VER TAMBIÉN

Documentación de usuario más detallada está disponible en help:/plasma-desktop (introduzca esta URL en Konqueror, o ejecute khelpcenter help:/plasma-desktop).
