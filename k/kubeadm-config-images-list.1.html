NOMBRE

kubeadm config images list - Imprime una lista de las imágenes que utilizará kubeadm. El archivo de configuración se utiliza en caso de que se personalicen imágenes o repositorios de imágenes

SINOPSIS

kubeadm config images list [OPCIONES]

DESCRIPCIÓN

Imprime una lista de las imágenes que utilizará kubeadm. El archivo de configuración se utiliza en caso de que se personalicen imágenes o repositorios de imágenes

OPCIONES

--allow-missing-template-keys=true Si es true, ignora cualquier error en las plantillas cuando falta un campo o una clave de mapa en la plantilla. Solo se aplica a los formatos de salida golang y jsonpath.

--config="" Ruta a un archivo de configuración de kubeadm.

--feature-gates="" Un conjunto de pares clave=valor que describen las puertas de características para varias características. Las opciones son: ControlPlaneKubeletLocalMode=true|false (BETA - predeterminado=true) NodeLocalCRISocket=true|false (BETA - predeterminado=true) PublicKeysECDSA=true|false (OBSOLETO - predeterminado=false) RootlessControlPlane=true|false (ALPHA - predeterminado=false) WaitForAllControlPlaneComponents=true|false (predeterminado=true)

--image-repository="registry.k8s.io" Elige un registro de contenedores para descargar imágenes del plano de control.

--kubernetes-version="stable-1" Elige una versión específica de Kubernetes para el plano de control.

-o, --output="text" Formato de salida. Uno de: text|json|yaml|go-template|go-template-file|template|templatefile|jsonpath|jsonpath-as-json|jsonpath-file.

--show-managed-fields=false Si es true, conserva los managedFields al imprimir objetos en formato JSON o YAML.

OPCIONES HEREDADAS DE COMANDOS PADRE

--kubeconfig="/etc/kubernetes/admin.conf" El archivo kubeconfig a usar al comunicarse con el clúster. Si la bandera no está configurada, se puede buscar en una serie de ubicaciones estándar un archivo kubeconfig existente.

--rootfs="" La ruta al sistema de archivos raíz 'real' del host. Esto hará que kubeadm haga chroot a la ruta proporcionada.

--version=false --version, --version=raw imprime la información de la versión y sale; --version=vX.Y.Z... establece la versión informada.
