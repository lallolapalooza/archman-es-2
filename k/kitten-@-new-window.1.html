Nombre

kitten-@-new-window - Abrir nueva ventana

Uso

kitten @ new-window [CMD ...]

Descripción

OBSOLETO: Usa el comando launch en su lugar.

Abre una nueva ventana en la pestaña especificada. Si usas la opción --match, se utiliza la primera pestaña que coincida. De lo contrario, se utiliza la pestaña activa actualmente. Imprime el id de la ventana recién abierta (a menos que se use --no-response). Cualquier argumento de línea de comandos se asume como la línea de comandos utilizada para ejecutar en la nueva ventana; si no se proporcionan, se ejecuta el shell por defecto. Por ejemplo::


kitten @ new-window --title Email mutt

Opciones

--match, -m
La pestaña a coincidir. Las especificaciones de coincidencia son de la forma: campo:consulta. Donde campo puede ser uno de: id, index, title, window_id, window_title, pid, cwd, cmdline env, var, state, session y recent. La consulta es la expresión a coincidir. Las expresiones pueden ser un número o una expresión regular, y se pueden combinar usando operadores Booleanos.

El valor especial all coincide con todas las pestañas.

Para campos numéricos: id, index, window_id, pid y recent, la expresión se interpreta como un número, no como una expresión regular. Los valores negativos para id/window_id coinciden desde el número de id más alto hacia abajo; en particular, -1 es la pestaña/ventana creada más recientemente.

Al usar title o id, primero se busca una pestaña que coincida y, si no se encuentra, se busca una ventana que coincida, y se utiliza la pestaña de esa ventana.

También puedes usar window_id y window_title para coincidir con la pestaña que contiene la ventana con el id o título especificado.

El número de índice se utiliza para coincidir con la n-ésima pestaña en la ventana del sistema operativo activa actualmente. El número recent coincide con pestañas activas recientemente en la ventana del sistema operativo activa actualmente, siendo cero la pestaña activa actualmente, uno la pestaña activa previamente y así sucesivamente.

El campo session coincide con pestañas que se crearon en la sesión especificada. Usa la expresión ^$ para coincidir con ventanas que no se crearon en una sesión y . para coincidir con la sesión activa actualmente o ~ para coincidir con la sesión activa actual o la última sesión activa cuando no hay ninguna sesión activa.

Al usar el campo env para coincidir con variables de entorno, puedes especificar solo el nombre de la variable de entorno o un nombre y un valor, por ejemplo, env:MY_ENV_VAR=2. Coinciden las pestañas que contienen cualquier ventana con las variables de entorno especificadas. De manera similar, var coincide con pestañas que contienen cualquier ventana con la variable de usuario especificada.

El campo state coincide con el estado de la pestaña. Los estados soportados son: active, focused, needs_attention, parent_active, parent_focused y focused_os_window. Las pestañas active son las pestañas que están activas en su ventana del sistema operativo padre. Solo hay una pestaña focused y es la pestaña a la que se entregan los eventos del teclado. Si ninguna pestaña está focused, se coincide con la última pestaña focused. El valor focused_os_window coincide con todas las pestañas en la ventana del sistema operativo activa actualmente.

Ten en cuenta que puedes usar el comando kitten @ ls para obtener una lista de pestañas.

--title
El título de la nueva ventana. Por defecto, usará el título establecido por el programa que se ejecuta en ella.
--cwd
El directorio de trabajo inicial para la nueva ventana. Por defecto, será el directorio de trabajo del proceso kitty con el que te estás comunicando.
--dont-take-focus, --keep-focus [=no]
Mantener la ventana actual enfocada en lugar de cambiar a la ventana recién abierta.
--window-type [=kitty]
Qué tipo de ventana abrir. Una ventana kitty o una ventana de nivel superior del sistema operativo.

Opciones: kitty, os

--new-tab [=no]
Abrir una nueva pestaña.
--tab-title
Establecer el título de la pestaña al abrir una nueva pestaña.
--no-response [=no]
No esperar una respuesta que proporcione el id de la ventana recién abierta. Ten en cuenta que usar esta opción significa que no se te notificará de los fallos y que el id de la nueva ventana no se imprimirá.
--help, -h [=no]
Mostrar ayuda para este comando

Opciones globales

--to
Una dirección para la instancia de kitty a controlar. Corresponde a la dirección dada a la instancia de kitty a través de la opción --listen-on o la configuración listen_on en kitty.conf. Si no se especifica, se verifica la variable de entorno KITTY_LISTEN_ON. Si tampoco se encuentra, los mensajes se envían a la terminal de control para este proceso, es decir, solo funcionarán si este proceso se ejecuta dentro de una ventana de kitty.
--password
Una contraseña para usar al contactar con kitty. Esto hará que kitty solicite al usuario permiso para realizar la acción especificada, a menos que la contraseña haya sido aceptada previamente o esté preconfigurada en kitty.conf. Para usar una contraseña en blanco, especifica --use-password siempre.
--password-file [=rc-pass]
Un archivo desde el cual leer la contraseña. Se ignora el espacio en blanco final. Las rutas relativas se resuelven desde el directorio de configuración de kitty. Usa - para leer desde STDIN. Usa fd:num para leer desde el descriptor de archivo num. Se utiliza si no se proporciona --password. Por defecto, se comprueba el archivo rc-pass en el directorio de configuración de kitty.
--password-env [=KITTY_RC_PASSWORD]
El nombre de una variable de entorno de la que leer la contraseña. Se utiliza si no se proporciona --password-file. Por defecto, se comprueba la variable de entorno KITTY_RC_PASSWORD.
--use-password [=if-available]
Si no hay contraseña disponible, kitty normalmente enviará el comando de control remoto sin contraseña. Esta opción se puede usar para forzar que siempre o nunca use la contraseña proporcionada. Si se establece en always y no se proporciona contraseña, se utiliza la contraseña en blanco.

Opciones: if-available, always, never
