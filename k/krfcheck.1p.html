NOMBRE

krfcheck - Comprueba un archivo keyrec de DNSSEC-Tools en busca de problemas e inconsistencias

SINOPSIS

krfcheck [-zone | -set | -key] [-count] [-quiet]
         [-verbose] [-Version] [-help] archivo-keyrec

DESCRIPCIÓN

Este script comprueba un archivo keyrec en busca de problemas, problemas potenciales e inconsistencias.

Los problemas reconocidos incluyen:

  • no hay zonas definidas

    El archivo keyrec no contiene ningún keyrec de zona.

  • no hay conjuntos definidos

    El archivo keyrec no contiene ningún keyrec de conjunto.

  • no hay claves definidas

    El archivo keyrec no contiene ningún keyrec de clave.

  • keyrec de zona desconocidos

    Un keyrec de conjunto o un keyrec de clave hace referencia a un keyrec de zona inexistente.

  • falta una clave en el keyrec de la zona

    Un keyrec de zona no tiene una clave KSK y una clave ZSK.

  • falta una clave en el keyrec del conjunto

    Una clave listada en un keyrec de conjunto no tiene un keyrec de clave.

  • keyrec de zonas caducadas

    Una zona ha caducado.

  • clave mal etiquetada

    Una clave está etiquetada como KSK (o ZSK) y la zona propietaria la etiqueta como lo opuesto.

  • valores de datos de zona no válidos

    Se comprueban los datos del keyrec de una zona para asegurar que son válidos. Se comprueban las siguientes condiciones: existencia del archivo de zona, existencia del archivo KSK, existencia de los directorios KSK y ZSK, el tiempo de finalización es mayor que un día y la cadena de fecha y el recuento de segundos coinciden.

  • valores de datos de clave no válidos

    Se comprueban los datos del keyrec de una clave para asegurar que son válidos. Se comprueban las siguientes condiciones: algoritmo de cifrado válido, la longitud de la clave se encuentra dentro del rango de tamaño del algoritmo, existe el archivo del generador aleatorio y la cadena de fecha y el recuento de segundos coinciden.

Los problemas potenciales reconocidos incluyen:

  • caducidad inminente de la zona

    Una zona caducará en menos de una semana.

  • fecha de firma de zona extraña

    La fecha de firma registrada de una zona es posterior al reloj del sistema actual.

  • claves huérfanas

    Un keyrec de clave no es referenciado por ningún keyrec de conjunto.

  • directorios de clave faltantes

    El directorio de clave keyrec de una zona (kskdirectory o zskdirectory) no existe.

Las inconsistencias reconocidas incluyen:

  • campos específicos de clave en un keyrec de zona

    Un keyrec de zona contiene entradas específicas de clave. Para permitir la extensibilidad específica del sitio, krfcheck no comprueba campos keyrec no definidos.

  • campos específicos de zona en un keyrec de clave

    Un keyrec de clave contiene entradas específicas de zona. Para permitir la extensibilidad específica del sitio, krfcheck no comprueba campos keyrec no definidos.

  • marca de tiempo de zona no coincidente

    La marca de tiempo de recuento de segundos de una zona no coincide con su marca de tiempo textual.

  • marca de tiempo de conjunto no coincidente

    La marca de tiempo de recuento de segundos de un conjunto no coincide con su marca de tiempo textual.

  • marca de tiempo de clave no coincidente

    La marca de tiempo de recuento de segundos de una clave no coincide con su marca de tiempo textual.

OPCIONES

-zone
Solo realiza comprobaciones de keyrec de zona. Esta opción no puede combinarse con las opciones -set o -key.
-set
Solo realiza comprobaciones de keyrec de conjunto. Esta opción no puede combinarse con las opciones -zone o -key.
-key
Solo realiza comprobaciones de keyrec de clave. Esta opción no puede combinarse con las opciones -set o -zone.
-count
Muestra un recuento final de errores.
-quiet
No muestra mensajes. Esta opción anula la configuración de la opción -verbose.
-verbose
Muestra muchos mensajes. Esta opción es subordinada a la opción -quiet.
-Version
Muestra la información de la versión de krfcheck y del paquete DNSSEC-Tools.
-help
Muestra un mensaje de uso.
