Paquete: keyutils

Licencias: GPL2, LGPL2.1

KEYCTL_PKEY_QUERY(3) Llamadas de gestión de claves de Linux KEYCTL_PKEY_QUERY(3)

NOMBRE

keyctl_pkey_query - Consultar parámetros de clave pública

SINOPSIS

#include <keyutils.h>

long keyctl_pkey_query(key_serial_t key, const char *info,
                       struct keyctl_pkey_query *result);

DESCRIPCIÓN

keyctl_pkey_query() consulta los parámetros de clave pública asociados con una clave del kernel que soporta estas operaciones (típicamente de tipo asymmetric). El llamador debe tener permiso de búsqueda en la clave objetivo para poder consultar sus parámetros.

Al invocar la función, key indica la clave a consultar, info apunta a una cadena de parámetros "key[=value]" separados por espacios o tabulaciones y result apunta a un búfer en el que se colocará el resultado.

Los parámetros que se pueden usar en la cadena de parámetros info dependen del tipo de clave. Los parámetros pueden especificar cosas como tipos de codificación (como "enc=pkcs1"); consulte asymmetric-key(7) para obtener más información.

Si tiene éxito, el resultado se escribe en la siguiente estructura:


struct keyctl_pkey_query {
        unsigned int    supported_ops;
        unsigned int    key_size;
        unsigned short  max_data_size;
        unsigned short  max_sig_size;
        unsigned short  max_enc_size;
        unsigned short  max_dec_size;
};

El campo supported_ops contiene una máscara de bits de las siguientes constantes:


KEYCTL_SUPPORTS_ENCRYPT
KEYCTL_SUPPORTS_DECRYPT
KEYCTL_SUPPORTS_SIGN
KEYCTL_SUPPORTS_VERIFY

indicando qué operaciones se soportan y, por lo tanto, qué otras operaciones keyctl_pkey_*() se pueden utilizar con esta clave.

El campo key_size indica el número de bits en el tamaño de la clave y los campos max_data_size, max_sig_size, max_enc_size y max_dec_size indican los tamaños máximos en bytes de un bloque de datos a firmar, un bloque de firma, un bloque a cifrar y un bloque a descifrar respectivamente.

VALOR DE RETORNO

En caso de éxito, keyctl_pkey_query() devuelve 0. En caso de error, se devolverá el valor -1 y errno se habrá establecido con un error apropiado.

ERRORES

ENOKEY
La clave especificada no es válida.
EKEYEXPIRED
La clave especificada ha caducado.
EKEYREVOKED
La clave especificada ha sido revocada.
EACCES
La clave existe, pero el proceso llamante no tiene permiso de búsqueda sobre ella.
ENOPKG
Alguna funcionalidad necesaria para completar la operación solicitada no está disponible. Probablemente se trate de un algoritmo de resumen o cifrado solicitado o requerido.
EFAULT
Dirección incorrecta.

ENLAZADO

Esta es una función de biblioteca que se puede encontrar en libkeyutils. Al enlazar, se debe especificar -lkeyutils al enlazador.
