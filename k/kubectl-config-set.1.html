NOMBRE

kubectl config set - Establece un valor individual en un archivo kubeconfig

SINOPSIS

kubectl config set [OPCIONES]

DESCRIPCIÓN

Establece un valor individual en un archivo kubeconfig.

NOMBRE_PROPIEDAD es un nombre delimitado por puntos donde cada token representa un nombre de atributo o una clave de mapa. Las claves de mapa no pueden contener puntos.

VALOR_PROPIEDAD es el nuevo valor que desea establecer. Los campos binarios como 'certificate-authority-data' esperan una cadena codificada en base64 a menos que se utilice la bandera --set-raw-bytes.

Especificar un nombre de atributo que ya existe fusionará los nuevos campos sobre los valores existentes.

OPCIONES

--set-raw-bytes=false Al escribir un VALOR_PROPIEDAD []byte, escribe la cadena dada directamente sin decodificación base64.

OPCIONES HEREDADAS DE COMANDOS PADRE

--as="" Nombre de usuario que se suplantará para la operación. El usuario puede ser un usuario normal o una cuenta de servicio en un namespace.

--as-group=[] Grupo que se suplantará para la operación, esta bandera se puede repetir para especificar múltiples grupos.

--as-uid="" UID que se suplantará para la operación.

--cache-dir="/home/username/.kube/cache" Directorio de caché predeterminado

--certificate-authority="" Ruta a un archivo de certificado para la autoridad certificadora

--client-certificate="" Ruta a un archivo de certificado de cliente para TLS

--client-key="" Ruta a un archivo de clave de cliente para TLS

--cluster="" El nombre del clúster kubeconfig a usar

--context="" El nombre del contexto kubeconfig a usar

--disable-compression=false Si es verdadero, desactiva la compresión de respuesta para todas las solicitudes al servidor

--insecure-skip-tls-verify=false Si es verdadero, el certificado del servidor no se verificará para su validez. Esto hará que sus conexiones HTTPS no sean seguras

--kubeconfig="" usa un archivo kubeconfig particular

--kuberc="" Ruta al archivo kuberc a usar para preferencias. Esto se puede deshabilitar exportando la puerta de enlace de características KUBECTL_KUBERC=false o desactivando la característica KUBERC=off.

--match-server-version=false Requiere que la versión del servidor coincida con la versión del cliente

-n, --namespace="" Si está presente, el ámbito del namespace para esta solicitud de CLI

--password="" Contraseña para autenticación básica al servidor API

--profile="none" Nombre del perfil a capturar. Uno de (none|cpu|heap|goroutine|threadcreate|block|mutex)

--profile-output="profile.pprof" Nombre del archivo donde escribir el perfil

--request-timeout="0" El tiempo de espera antes de abandonar una solicitud de servidor individual. Los valores distintos de cero deben contener una unidad de tiempo correspondiente (por ejemplo, 1s, 2m, 3h). Un valor de cero significa no agotar el tiempo de espera de las solicitudes.

-s, --server="" La dirección y el puerto del servidor API de Kubernetes

--tls-server-name="" Nombre del servidor a utilizar para la validación del certificado del servidor. Si no se proporciona, se utiliza el nombre de host utilizado para contactar al servidor

--token="" Token de portador para la autenticación al servidor API

--user="" El nombre del usuario kubeconfig a usar

--username="" Nombre de usuario para autenticación básica al servidor API

--version=false --version, --version=raw imprime la información de la versión y sale; --version=vX.Y.Z... establece la versión informada

--warnings-as-errors=false Trata las advertencias recibidas del servidor como errores y sale con un código de salida distinto de cero

EJEMPLO

  # Establece el campo server en el clúster my-cluster a https://1.2.3.4
  kubectl config set clusters.my-cluster.server https://1.2.3.4
  # Establece el campo certificate-authority-data en el clúster my-cluster
  kubectl config set clusters.my-cluster.certificate-authority-data $(echo "cert_data_here" | base64 -i -)
  # Establece el campo cluster en el contexto my-context a my-cluster
  kubectl config set contexts.my-context.cluster my-cluster
  # Establece el campo client-key-data en el usuario cluster-admin usando la opción --set-raw-bytes
  kubectl config set users.cluster-admin.client-key-data cert_data_here --set-raw-bytes=true
