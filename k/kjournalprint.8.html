KJOURNALPRINT(8) Knot DNS KJOURNALPRINT(8)

NOMBRE

kjournalprint - Utilidad para imprimir el diario de Knot DNS

SINOPSIS

kjournalprint [opción_config] [opciones] nombre_zona

kjournalprint [opción_config] -z

DESCRIPCIÓN

El programa imprime el historial de zonas almacenado en una base de datos de diario. Por defecto, los cambios se colorean para la terminal.

Parámetros

nombre_zona
El nombre de la zona para la que se imprimirá el historial.

Opciones de configuración

-c, --config archivo
Utilizar un archivo de configuración de texto (por defecto es /etc/knot/knot.conf).
-C, --confdb directorio
Utilizar un directorio de base de datos de configuración binaria (por defecto es /var/lib/knot/confdb). La base de datos de configuración por defecto, si existe, tiene preferencia sobre el archivo de configuración por defecto.
-D, --dir ruta
Utilizar la ruta de la base de datos del diario especificada y la configuración por defecto.

Opciones

-z, --zone-list
En lugar de leer el diario, muestra la lista de zonas en la BD.
-l, --limit límite
Limita el número de cambios mostrados.
-s, --serial soa
Comienza en un número de serie SOA específico.
-M, --merge
Imprime los conjuntos de cambios fusionados en un solo conjunto de cambios. Si la zona en el diario está presente, se imprimirán los contenidos almacenados con todos los conjuntos de cambios aplicados.
-H, --check
Habilita comprobaciones semánticas adicionales del diario durante la impresión.
-d, --debug
Modo de depuración con salida breve.
-x, --mono
No genera salida con color.
-X, --color
Fuerza la salida con color.
-h, --help
Imprime la ayuda del programa.
-V, --version
Imprime la versión del programa. La opción -VV hace que el programa imprima el resumen de la configuración en tiempo de compilación.

VALORES DE SALIDA

Un estado de salida de 0 significa operación exitosa. Cualquier otro estado de salida indica un error.

EJEMPLOS

Los últimos 5 cambios (más recientes) sin colores:

$ kjournalprint -xl 5 /var/lib/knot/journal example.com.

VER TAMBIÉN

knotd(8), knot.conf(5).
