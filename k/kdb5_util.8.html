DESCRIPCIÓ

N

kdb5_util permite a un administrador realizar procedimientos de mantenimiento en la base de datos del KDC. Se pueden crear, destruir y volcar o cargar bases de datos desde/hacia archivos ASCII. kdb5_util puede crear un archivo de reserva de la clave maestra de Kerberos o realizar la rotación en caliente de la clave

maestra.

Cuando se ejecuta kdb5_util, intenta adquirir la clave maestra y abrir la base de datos. Sin embargo, la ejecución continúa independientemente de si kdb5_util abre con éxito la base de datos o no, porque la base de datos puede no existir todavía o el archivo de reserva puede estar

corrupto.

Tenga en cuenta que algunos módulos de

base de datos del KDC pueden no so
portar todos los comandos de kdb5_util.
