KOI8RXTERM(1) Sistema de ventanas X KOI8RXTERM(1)

NOMBRE

koi8rxterm - emulador de terminal X para entornos KOI8-R

SINOPSIS

koi8rxterm [ opciones-xterm ]

DESCRIPCIÓN

koi8rxterm es un envoltorio alrededor del programa xterm(1) que invoca a este último con la clase de recurso X "KOI8RXTerm" establecida. Todos los argumentos para koi8rxterm se pasan a xterm sin procesamiento; las opciones -class y -k8 no deben especificarse ya que son utilizadas por el envoltorio. Consulte la página del manual de xterm para obtener más información sobre opciones-xterm.

La configuración regional (locale) del entorno (ver "ENTORNO" más abajo) se utiliza para determinar el conjunto de caracteres de la configuración regional. Si no se puede determinar ninguna configuración regional actual, se asume la configuración regional "ru_RU.KOI8-R" (el idioma ruso tal como se usa en el territorio de Rusia, con el conjunto de caracteres KOI8-R). La utilidad locale(1) se utiliza para determinar si el sistema soporta la configuración regional seleccionada. Si no es así, koi8rxterm saldrá con un error e informará la salida de locale.

Nota: koi8rxterm puede producir resultados inesperados si la configuración regional actual se establece en una en la que la codificación de caracteres KOI8-R no es compatible, o si las fuentes que utilizan esa codificación no están disponibles. En el sistema Debian, el paquete "xfonts-cyrillic" proporciona las fuentes que koi8rxterm utiliza por defecto. Para cambiar las fuentes que utiliza koi8rxterm, edite el archivo /usr/share/X11/app-defaults//KOI8RXTerm.

Un envoltorio similar, uxterm(1), está disponible para entornos Unicode UTF-8.

ENTORNO

LC_ALL, LC_CTYPE, LANG
Los valores de estas variables se comprueban, en orden, para determinar el conjunto de caracteres utilizado por la configuración regional actual.

AUTORES

koi8rxterm fue escrito por Branden Robinson y se basa en gran medida en uxterm, de Thomas Dickey. La asistencia de Jurij Smakov fue invaluable para verificar su funcionamiento.

VER TAMBIÉN

locale(1), locale(7), uxterm(1), xterm(1)
