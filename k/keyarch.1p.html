NOMBRE

keyarch - Demonio de DNSSEC-Tools para archivar claves KSK y ZSK antiguas

SINOPSIS

keyarch [opciones] <archivo_keyrec | archivo_rollrec>

DESCRIPCIÓN

El programa keyarch archiva claves KSK y ZSK antiguas. Las claves se consideran antiguas si están revocadas u obsoletas. Las claves marcadas como kskrev o zskrev están revocadas; las claves marcadas como kskobs o zskobs son obsoletas. Las claves archivadas se prefijan con los segundos transcurridos desde la época como medio para distinguir las claves de una zona que tienen el mismo número de cinco dígitos.

Si el argumento de archivo requerido es un archivo keyrec, entonces se archivan las claves caducadas listadas en ese archivo. Si el argumento de archivo es un archivo rollrec, se comprueban los archivos keyrec de las zonas en ese archivo en busca de claves caducadas.

Si se proporciona la opción -zone, entonces solo se archivan las claves revocadas y obsoletas pertenecientes a la zona especificada.

El directorio de archivo es específico de la zona (listado en el registro keyrec de la zona en el archivo keyrec de la zona) o el directorio de archivo predeterminado que se encuentra en el archivo de configuración de DNSSEC-Tools.

El recuento de claves archivadas se proporciona como código de salida del programa. Los códigos de salida de error son negativos.

OPCIONES

Se reconocen las siguientes opciones:

-zone archivo_zona
Nombre de la zona cuyas KSK se archivarán. Si no se proporciona, se comprobarán todas las zonas definidas en el archivo rollrec.
-kskonly
Archivar solo claves KSK.
-zskonly
Archivar solo claves ZSK.
-dtconfig archivo_config
Nombre de un archivo de configuración alternativo de DNSSEC-Tools a procesar. Si se especifica, este archivo de configuración se usa *en lugar* del archivo de configuración normal de DNSSEC-Tools, *no* además de él. Además, se manejará antes que los archivos keyrec, rollrec y las opciones de línea de comandos.
-quiet
No se producirá ninguna salida.
-verbose
Se producirá una salida detallada.
-help
Muestra un mensaje de uso.
-Version
Muestra la información de la versión de keyarch y del paquete DNSSEC-Tools.

VALORES DE SALIDA

En caso de éxito, el código de salida de keyarch es el número de claves archivadas.

keyarch tiene un código de salida 0 si se muestra el mensaje de ayuda.

keyarch tiene un código de salida negativo si se encuentra un error.
