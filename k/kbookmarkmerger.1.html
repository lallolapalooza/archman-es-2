DESCRIPCIÓ

N

kbookmarkmerger es un programa para fusionar un conjunto dado de marcadores en el conjunto de marcadores del usuario; si el usuario aún no tiene ningún marcador creado, se crea una nueva lista de marcadores y se insertan en ella los marcadores dados. Mientras hace esto, kbookmarkmerger lleva un registro de qué archivos ya fueron fusionados en una ejecución anterior, de modo que ningún marcador se instalará en los marcadores del usuario más de una

vez.

El enfoque tradicionalmente utilizado para lograr algo así era usar directorios de inicio esqueleto cuidadosamente diseñados al crear una nueva cuenta de usuario, para proporcionar al usuario un conjunto estándar de marcadores. El problema de este enfoque es que, una vez creada la cuenta de usuario, no se pueden propagar marcadores

nuevos.

Este mecanismo es útil para los administradores de sistemas que deseen propagar un marcador que apunte a un documento determinado (por ejemplo, notas importantes sobre el sistema) a todos los usuarios. Los distribuidores también podrían encontrarlo útil, por ejemplo, al añadir archivos de marcadores a los paquetes de software que proporcionan, los cuales kbookmarkmerger fusiona en la lista de marcadores del usuario cuando se instala el paquete. De esa manera, la documentación incluida con un paquete de software es fácilmente y visiblemente accesible justo después de que el paquete haya sido

instalado.

El único parámetro requerido por kbookmarkmerger es el nombre de un directorio que debe ser escaneado en busca de archivos de marcadores. Todos los archivos en el directorio d

ado serán considerados para ser fusionados en la configuración del usuari
o. Los archivos en el directorio dado deberían ser archivos XBEL válidos.

RESTRICCIONE

S

Al determinar si un archivo de marcadores dado ya ha sido fusionado en los marcadores del usuario o no, kbookmarkmerger simplemente mira el nombre de archivo del archivo de marcadores - el contenido no se verifica en absoluto. Esto significa que cambiar un archivo de marcadores que ya fue fusionado en los marcadores de un usuario no provocará que se fusione de

nuevo.

Tenga en cuenta también que, en caso de que un usuario mo

difique un marcador que fue fusionado en su configuración,
el archivo de marcadores original quedará sin modificar.
