Paquete: kubectl

NOMBRE

kubectl logs - Imprime los logs de un contenedor en un pod

SINOPSIS

kubectl logs [OPCIONES]

DESCRIPCIÓN

Imprime los logs de un contenedor en un pod o recurso especificado. Si el pod tiene solo un contenedor, el nombre del contenedor es opcional.

OPCIONES

--all-containers=false Obtiene los logs de todos los contenedores en el(los) pod(s).

--all-pods=false Obtiene logs de todos los pod(s). Establece prefix a true.

-c, --container="" Imprime los logs de este contenedor

-f, --follow=false Especifica si los logs deben ser transmitidos.

--ignore-errors=false Si se observa / sigue los logs del pod, permite que cualquier error que ocurra no sea fatal

--insecure-skip-tls-verify-backend=false Omite la verificación de la identidad del kubelet de donde se solicitan los logs. En teoría, un atacante podría devolver contenido de log inválido. Puede que quieras usar esto si tus certificados de servicio de kubelet han expirado.

--limit-bytes=0 Bytes máximos de logs a devolver. Por defecto no hay límite.

--max-log-requests=5 Especifica el número máximo de logs concurrentes a seguir cuando se usa por un selector. Por defecto es 5.

--pod-running-timeout=20s La duración (como 5s, 2m o 3h, mayor que cero) para esperar hasta que al menos un pod esté en ejecución

--prefix=false Prefija cada línea de log con la fuente del log (nombre del pod y nombre del contenedor)

-p, --previous=false Si es verdadero, imprime los logs de la instancia anterior del contenedor en un pod si existe.

-l, --selector="" Selector (consulta de etiquetas) para filtrar, soporta '=', '==', '!=', 'in', 'notin'.(ej. -l key1=value1,key2=value2,key3 in (value3)). Los objetos coincidentes deben satisfacer todas las restricciones de etiquetas especificadas.

--since=0s Solo devuelve logs más recientes que una duración relativa como 5s, 2m o 3h. Por defecto todos los logs. Solo se puede usar uno de since-time / since.

--since-time="" Solo devuelve logs después de una fecha específica (RFC3339). Por defecto todos los logs. Solo se puede usar uno de since-time / since.

--tail=-1 Líneas del archivo de log reciente a mostrar. Por defecto -1 sin selector, mostrando todas las líneas de log, de lo contrario 10, si se proporciona un selector.

--timestamps=false Incluye marcas de tiempo en cada línea de la salida de logs

OPCIONES HEREDADAS DE COMANDOS PADRE

--as="" Nombre de usuario a suplantar para la operación. El usuario podría ser un usuario regular o una cuenta de servicio en un namespace.

--as-group=[] Grupo a suplantar para la operación, este flag puede repetirse para especificar múltiples grupos.

--as-uid="" UID a suplantar para la operación.

--cache-dir="/home/username/.kube/cache" Directorio de caché por defecto

--certificate-authority="" Ruta a un archivo de certificado para la autoridad certificadora

--client-certificate="" Ruta a un archivo de certificado de cliente para TLS

--client-key="" Ruta a un archivo de clave de cliente para TLS

--cluster="" El nombre del clúster de kubeconfig a usar

--context="" El nombre del contexto de kubeconfig a usar

--disable-compression=false Si es verdadero, opta por no comprimir las respuestas para todas las solicitudes al servidor

--insecure-skip-tls-verify=false Si es verdadero, el certificado del servidor no será verificado por su validez. Esto hará que tus conexiones HTTPS sean inseguras

--kubeconfig="" Ruta al archivo kubeconfig a usar para las solicitudes CLI.

--kuberc="" Ruta al archivo kuberc a usar para preferencias. Esto puede ser deshabilitado exportando el feature gate KUBECTL_KUBERC=false o desactivando el feature KUBERC=off.

--match-server-version=false Requiere que la versión del servidor coincida con la versión del cliente

-n, --namespace="" Si está presente, el ámbito del namespace para esta solicitud CLI

--password="" Contraseña para autenticación básica al servidor API

--profile="none" Nombre del perfil a capturar. Uno de (none|cpu|heap|goroutine|threadcreate|block|mutex)

--profile-output="profile.pprof" Nombre del archivo donde escribir el perfil

--request-timeout="0" La duración a esperar antes de desistir de una solicitud de servidor individual. Los valores distintos de cero deben contener una unidad de tiempo correspondiente (ej. 1s, 2m, 3h). Un valor de cero significa no agotar el tiempo de espera de las solicitudes.

-s, --server="" La dirección y el puerto del servidor API de Kubernetes

--tls-server-name="" Nombre del servidor a usar para la validación del certificado del servidor. Si no se proporciona, se utiliza el nombre de host utilizado para contactar al servidor

--token="" Token de portador para la autenticación al servidor API

--user="" El nombre del usuario de kubeconfig a usar

--username="" Nombre de usuario para autenticación básica al servidor API

--version=false --version, --version=raw imprime información de versión y sale; --version=vX.Y.Z... establece la versión reportada

--warnings-as-errors=false Trata las advertencias recibidas del servidor como errores y sale con un código de salida distinto de cero

EJEMPLO

  # Devuelve logs instantáneos del pod nginx con un solo contenedor
  kubectl logs nginx
  # Devuelve logs instantáneos del pod nginx, prefijando cada línea con el pod y contenedor de origen
  kubectl logs nginx --prefix
  # Devuelve logs instantáneos del pod nginx, limitando la salida a 500 bytes
  kubectl logs nginx --limit-bytes=500
  # Devuelve logs instantáneos del pod nginx, esperando hasta 20 segundos a que se ejecute.
  kubectl logs nginx --pod-running-timeout=20s
  # Devuelve logs instantáneos del pod nginx con múltiples contenedores
  kubectl logs nginx --all-containers=true
  # Devuelve logs instantáneos de todos los pods en el despliegue nginx
  kubectl logs deployment/nginx --all-pods=true
  # Devuelve logs instantáneos de todos los contenedores en pods definidos por la etiqueta app=nginx
  kubectl logs -l app=nginx --all-containers=true
  # Devuelve logs instantáneos de todos los pods definidos por la etiqueta app=nginx, limitando las solicitudes de logs concurrentes a 10 pods
  kubectl logs -l app=nginx --max-log-requests=10
  # Devuelve una instantánea de los logs del contenedor ruby terminado anteriormente del pod web-1
  kubectl logs -p -c ruby web-1
  # Comienza a transmitir los logs del pod nginx, continuando incluso si ocurren errores
  kubectl logs nginx -f --ignore-errors=true
  # Comienza a transmitir los logs del contenedor ruby en el pod web-1
  kubectl logs -f -c ruby web-1
  # Comienza a transmitir los logs de todos los contenedores en pods definidos por la etiqueta app=nginx
  kubectl logs -f -l app=nginx --all-containers=true
  # Muestra solo las 20 líneas de salida más recientes en el pod nginx
  kubectl logs --tail=20 nginx
  # Muestra todos los logs del pod nginx escritos en la última hora
  kubectl logs --since=1h nginx
  # Muestra todos los logs con marcas de tiempo del pod nginx a partir del 30 de agosto de 2024, a las 06:00:00 UTC
  kubectl logs nginx --since-time=2024-08-30T06:00:00Z --timestamps=true
  # Muestra logs de un kubelet con un certificado de servicio caducado
  kubectl logs --insecure-skip-tls-verify-backend nginx
  # Devuelve logs instantáneos del primer contenedor de un job llamado hello
  kubectl logs job/hello
  # Devuelve logs instantáneos del contenedor nginx-1 de un despliegue llamado nginx
  kubectl logs deployment/nginx -c nginx-1
