NOMBRE

kubectl top pod - Mostrar uso de recursos (CPU/memoria) de pods

SINOPSIS

kubectl top pod [OPCIONES]

DESCRIPCIÓN

Mostrar uso de recursos (CPU/memoria) de pods.

El comando 'top pod' te permite ver el consumo de recursos de los pods.

Debido al retraso en la tubería de métricas, pueden no estar disponibles durante unos minutos desde la creación del pod.

OPCIONES

-A, --all-namespaces=false Si está presente, listar los objetos solicitados en todos los namespaces. El namespace en el contexto actual se ignora incluso si se especifica con --namespace.

--containers=false Si está presente, mostrar el uso de los contenedores dentro de un pod.

--field-selector="" Selector (consulta de campo) para filtrar, admite '=', '==', y '!='.(ej. --field-selector clave1=valor1,clave2=valor2). El servidor solo admite un número limitado de consultas de campo por tipo.

--no-headers=false Si está presente, mostrar la salida sin encabezados.

-l, --selector="" Selector (consulta de etiquetas) para filtrar, admite '=', '==', '!=', 'in', 'notin'.(ej. -l clave1=valor1,clave2=valor2,clave3 in (valor3)). Los objetos coincidentes deben cumplir todas las restricciones de etiqueta especificadas.

--show-swap=false Mostrar recursos del pod relacionados con la memoria swap.

--sort-by="" Si no está vacío, ordenar la lista de pods usando el campo especificado. El campo puede ser 'cpu' o 'memory'.

--sum=false Mostrar la suma del uso de recursos

--use-protocol-buffers=true Habilita el uso de protocol-buffers para acceder a la API de Métricas.

OPCIONES HEREDADAS DE COMANDOS PADRE

--as="" Nombre de usuario a suplantar para la operación. El usuario podría ser un usuario normal o una cuenta de servicio en un namespace.

--as-group=[] Grupo a suplantar para la operación, este flag se puede repetir para especificar múltiples grupos.

--as-uid="" UID a suplantar para la operación.

--cache-dir="/home/username/.kube/cache" Directorio de caché predeterminado

--certificate-authority="" Ruta a un archivo de certificado para la autoridad certificadora

--client-certificate="" Ruta a un archivo de certificado de cliente para TLS

--client-key="" Ruta a un archivo de clave de cliente para TLS

--cluster="" El nombre del clúster de kubeconfig a utilizar

--context="" El nombre del contexto de kubeconfig a utilizar

--disable-compression=false Si es verdadero, desactiva la compresión de respuestas para todas las solicitudes al servidor

--insecure-skip-tls-verify=false Si es verdadero, el certificado del servidor no se verificará en cuanto a su validez. Esto hará que sus conexiones HTTPS no sean seguras

--kubeconfig="" Ruta al archivo kubeconfig a utilizar para las solicitudes CLI.

--kuberc="" Ruta al archivo kuberc a utilizar para las preferencias. Esto se puede deshabilitar exportando la puerta de enlace de función KUBECTL_KUBERC=false o desactivando la función KUBERC=off.

--match-server-version=false Requiere que la versión del servidor coincida con la versión del cliente

-n, --namespace="" Si está presente, el ámbito del namespace para esta solicitud CLI

--password="" Contraseña para la autenticación básica al servidor API

--profile="none" Nombre del perfil a capturar. Uno de (none|cpu|heap|goroutine|threadcreate|block|mutex)

--profile-output="profile.pprof" Nombre del archivo donde escribir el perfil

--request-timeout="0" La cantidad de tiempo a esperar antes de rendirse en una única solicitud al servidor. Los valores distintos de cero deben contener una unidad de tiempo correspondiente (por ejemplo, 1s, 2m, 3h). Un valor de cero significa no agotar el tiempo de espera de las solicitudes.

-s, --server="" La dirección y el puerto del servidor API de Kubernetes

--tls-server-name="" Nombre del servidor a utilizar para la validación del certificado del servidor. Si no se proporciona, se utiliza el nombre de host utilizado para contactar al servidor

--token="" Token de portador para la autenticación al servidor API

--user="" El nombre del usuario de kubeconfig a utilizar

--username="" Nombre de usuario para la autenticación básica al servidor API

--version=false --version, --version=raw muestra información de versión y sale; --version=vX.Y.Z... establece la versión informada

--warnings-as-errors=false Tratar las advertencias recibidas del servidor como errores y salir con un código de salida distinto de cero

EJEMPLO

  # Mostrar métricas para todos los pods en el namespace predeterminado
  kubectl top pod
  # Mostrar métricas para todos los pods en el namespace dado
  kubectl top pod --namespace=NAMESPACE
  # Mostrar métricas para un pod dado y sus contenedores
  kubectl top pod POD_NAME --containers
  # Mostrar métricas para los pods definidos por la etiqueta name=myLabel
  kubectl top pod -l name=myLabel
