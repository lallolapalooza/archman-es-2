KDED6(8) Manual de usuario de kded6 KDED6(8)

NOMBRE

kded6 - Demonio de KDE - activa las actualizaciones de la base de datos Sycoca cuando es necesario.

SINOPSIS

kded6 [--check]

DESCRIPCIÓN

kded6 consolida varios servicios pequeños en un solo proceso. Estos son principalmente servicios D-Bus proporcionados por módulos KDED, pero también gestiona sycoca (una caché binaria de tipos de servicio, tipos MIME y servicios utilizados por KService) y scripts de actualización de KConfig según sea necesario.

Para sycoca, monitoriza los directorios que contienen archivos .desktop. Cuando se agrega/elimina un archivo, espera 5 segundos (en caso de una serie de actualizaciones) y luego ejecuta kbuildsycoca6 para actualizar sycoca.

Para KConfig, comprueba los archivos de actualización recién instalados, es decir, los archivos *.upd utilizados para actualizar los archivos de configuración de los usuarios cuando cambian los formatos de los archivos de configuración, y ejecuta la utilidad de actualización de KConfig para realizar las actualizaciones.

Estas tareas también se ejecutan cuando se inicia kded6 para garantizar que la configuración del usuario esté actualizada.

Normalmente no necesita ejecutar kded6 directamente; las sesiones de escritorio de Plasma lo ejecutan automáticamente y se inicia bajo demanda cuando una aplicación intenta utilizar una interfaz D-Bus proporcionada por él o uno de sus módulos.

OPCIONES

--check

Verifica la base de datos sycoca, actualizándola si es necesario, y sale.

CONFIGURACIÓN

kded6 se puede configurar con el archivo de configuración estilo ini kded5rc. En los sistemas UNIX®, esto se puede encontrar en $XDG_CONFIG_HOME/kded5rc; si $XDG_CONFIG_HOME no está configurado, el valor predeterminado es ~/.config/kded5rc.

Las entradas del archivo de configuración se leen bajo demanda, por lo que los cambios se pueden realizar mientras kded6 se está ejecutando. Sin embargo, todas las opciones de configuración actuales solo afectan realmente al comportamiento de inicio de kded6.

La sección [General] tiene las siguientes opciones:

CheckSycoca

Si se debe actualizar sycoca al iniciar (predeterminado: true).

CheckUpdates

Si se deben realizar las actualizaciones pendientes de KConfig al iniciar (predeterminado: true).

CheckFileStamps

Si se deben verificar las marcas de tiempo de los archivos al realizar la actualización inicial de sycoca (predeterminado: true). Consulte la documentación de kbuildsycoca6 para obtener más detalles.

DelayedCheck

Si se debe retrasar la actualización inicial de sycoca hasta aproximadamente un minuto después de iniciarse (predeterminado: false).

Cada módulo también tiene una sección [Module-name] en kded5rc, donde name es el nombre del archivo desktop del módulo sin la extensión .desktop. Esto contiene una opción autoload que especifica si el módulo debe cargarse automáticamente cuando se inicia kded6 (predeterminado: false). Tenga en cuenta que esta configuración también se puede cambiar a través de la interfaz D-Bus de kded6.

VER TAMBIÉN

kbuildsycoca6(8), kdeinit6(8)
