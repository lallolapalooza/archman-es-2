KEEPASS(1) Manual de comandos generales KEEPASS(1)

NOMBRE

keepass - gestor de contraseñas

SINOPSIS

keepass

DESCRIPCIÓN

KeePass es un gestor de contraseñas o caja fuerte gratuito/de código abierto que te ayuda a gestionar tus contraseñas de forma segura. Puedes guardar todas tus contraseñas en una base de datos, la cual está bloqueada con una única clave maestra o un archivo de clave. Así, solo necesitas recordar una única contraseña maestra para desbloquear toda la base de datos. Las bases de datos se cifran utilizando AES-256.

OPCIONES

--auto-type
invoca el auto-type global
--lock-all
bloquea las bases de datos de todas las instancias de KeePass
--unlock-all
desbloquea las bases de datos de todas las instancias de KeePass
--exit-all
sale de todas las instancias de KeePass
