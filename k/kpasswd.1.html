NOMBRE

kpasswd - cambiar la contraseña de un usuario de Kerberos

SINOPSIS

kpasswd [principal]

DESCRIPCIÓN

El comando kpasswd se utiliza para cambiar la contraseña de un principal de Kerberos. kpasswd primero solicita la contraseña actual de Kerberos, luego solicita al usuario dos veces la nueva contraseña, y la contraseña se cambia.

Si el principal está regido por una política que especifica la longitud y/o el número de clases de caracteres requeridas en la nueva contraseña, la nueva contraseña debe cumplir con la política. (Las cinco clases de caracteres son minúsculas, mayúsculas, números, puntuación y todos los demás caracteres.)

OPCIONES

principal
Cambia la contraseña para el principal de Kerberos principal. De lo contrario, kpasswd utiliza el nombre del principal de un ccache existente si lo hay; si no, el principal se deriva de la identidad del usuario que invoca el comando kpasswd.

ENTORNO

Consulte kerberos(7) para ver una descripción de las variables de entorno de Kerberos.

VER TAMBIÉN

kadmin(1), kadmind(8), kerberos(7)
