Paquete: libtraceevent

LIBTRACEEVENT(3) Manual de libtraceevent LIBTRACEEVENT(3)

NOMBRE

kbuffer_read_event, kbuffer_next_event, kbuffer_missed_events, kbuffer_event_size, kbuffer_curr_size, kbuffer_curr_offset, kbuffer_curr_index, kbuffer_read_buffer - Funciones para leer a través del sub-búfer kbuffer.

SINOPSIS

#include <kbuffer.h>
void *kbuffer_read_event(struct kbuffer *kbuf, unsigned long long *ts);
void *kbuffer_next_event(struct kbuffer *kbuf, unsigned long long *ts);
void *kbuffer_read_at_offset(struct kbuffer *kbuf, int offset, unsigned long long *ts);
int kbuffer_missed_events(struct kbuffer *kbuf);
int kbuffer_event_size(struct kbuffer *kbuf);
int kbuffer_curr_size(struct kbuffer *kbuf);
int kbuffer_curr_offset(struct kbuffer *kbuf);
int kbuffer_curr_index(struct kbuffer *kbuf);
int kbuffer_read_buffer(struct kbuffer *kbuf, void *buffer, int len);

DESCRIPCIÓN

La función kbuffer_read_event() lee el siguiente evento en el descriptor kbuf y si ts no es NULL, colocará su marca de tiempo en él. Esto no modifica el descriptor kbuf, y llamar a esta función varias veces devolverá el mismo resultado.

La función kbuffer_next_event() devolverá el siguiente evento en el descriptor kbuf. También establecerá ts a la marca de tiempo del evento devuelto. Se devuelve NULL si no hay más eventos y ts no estará definido. Tenga en cuenta que si se llama directamente después de un kbuffer_load_subbuffer(), probablemente dará un resultado inesperado, ya que devolverá el segundo evento y no el primer evento. Normalmente, esta función solo se usa para pasar al siguiente evento y para saber si hay más eventos para leer, y kbuffer_read_event() siempre se llama primero.

La función kbuffer_read_at_offset() devuelve el evento ubicado en un offset dado desde el principio del sub-búfer. Este offset se puede obtener con kbuffer_curr_offset(). Si ts apunta a un unsigned long long, se establecerá a la marca de tiempo del evento en el offset dado.

Si el sub-búfer se perdió eventos antes que él, entonces kbuffer_missed_events() devolverá un valor distinto de cero. Si devuelve -1, significa que hubo eventos perdidos, pero el número exacto de eventos perdidos es desconocido. Si devuelve un número positivo, entonces el número de eventos perdidos es el valor de retorno.

La función kbuffer_event_size() devuelve el tamaño de la porción de datos del evento actual (el que sería devuelto por kbuffer_read_event().

La función kbuffer_curr_size() devuelve el tamaño total del registro del evento actual (el que sería devuelto por kbuffer_read_event(). La diferencia aquí es que el valor de retorno incluye el tamaño de los metadatos del registro del evento que no forman parte de lo devuelto por kbuffer_read_event().

La función kbuffer_curr_offset() devuelve el offset desde el principio del sub-búfer donde comienzan los metadatos del evento actual para el registro. El primer evento no estará en el offset cero. Este offset se puede utilizar para recuperar el evento con kbuffer_read_at_offset().

La función kbuffer_curr_index() devuelve el índice desde el principio de la porción de datos del sub-búfer donde se encuentran los metadatos del evento actual para el registro. Es probable que el primer evento sea cero, pero puede que no lo sea si hay una marca de tiempo adjunta a él.

La función kbuffer_read_buffer() llenará el buffer dado con el kbuf de la misma manera que el kernel realizaría una llamada al sistema de lectura. Es decir, si la longitud len es menor que el tamaño del sub-búfer, o si el índice actual del kbuffer no es cero, comenzará a copiar desde el evento actual del kbuf y creará un nuevo sub-búfer buffer (con una marca de tiempo y una cabecera de confirmación) con el evento que se encontró e incluyendo todos los eventos posteriores que quepan dentro de len. El len debe incluir el tamaño de la cabecera del sub-búfer, así como los eventos a incluir. Es decir, len es el tamaño asignado de buffer que se puede llenar. El retorno de esta función es el índice del final del último evento que se añadió. Si no quedan más eventos, se devuelve cero, y si el búfer no puede copiar ningún evento porque len era demasiado pequeño, se devuelve -1.

VALOR DE RETORNO

kbuffer_read_event() devuelve el evento en el que se encuentra actualmente el descriptor kbuf, o NULL si se pasó el último evento (por kbuffer_next_event()).

kbuffer_next_event() devuelve el siguiente evento después del evento actual o NULL si no hay más eventos.

kbuffer_read_at_offset() devuelve el evento en un offset dado desde el inicio del sub-búfer almacenado en kbuf, o NULL si no existe ningún evento. Nota: el offset solo necesita ser un offset que apunte al registro, o al inicio del mismo. No necesita ser exactamente al principio del registro.

kbuffer_missed_events() devuelve 0 si no hubo eventos perdidos antes del sub-búfer cargado. Devuelve -1 si hubo un número desconocido de eventos perdidos, o si se conoce el número de eventos perdidos, se devolverá ese número.

kbuffer_event_size() devuelve el tamaño de la carga útil de datos del evento actual de kbuf.

kbuffer_curr_size() devuelve el tamaño total del registro del evento actual de kbuf. Esto incluye el tamaño de los metadatos de ese registro.

kbuf_curr_offset() devuelve el offset del registro actual desde el principio del sub-búfer de kbuf.

kbuf_curr_index() devuelve el índice del registro actual desde el principio de la sección de datos de kbuf.

kbuf_read_buffer() devuelve el índice del final del último evento que se llenó en buffer. Si no quedan más eventos para copiar desde start, se devuelve 0. Si len no es lo suficientemente grande para contener ningún evento, se devuelve -1.

/*
 * This program demonstrates how to read events from a ring buffer using
 * the libtraceevent library.
 */

#include <stdio.h>
#include <stdlib.h>
#include <traceevent/traceevent.h>

int main(int argc, char **argv) {
    struct trace_event_buffer *kbuf;
    struct trace_event *event = NULL;
    int i = 0;
    long long ts;
    int record_size;
    int size;
    int index;
    int offset;
    int save_offset = 0;

    /*
     * Initialize the trace event buffer.
     * In a real application, you would typically get the buffer from the
     * kernel or a trace file. For this example, we'll create an empty one.
     */
    kbuf = kbuffer_new(0);
    if (!kbuf) {
        fprintf(stderr, "Failed to create trace event buffer\n");
        return -1;
    }

    /*
     * Simulate adding some events to the buffer.
     * In a real scenario, these events would be generated by the kernel.
     */
    // Add dummy events for demonstration
    kbuffer_add_dummy_event(kbuf, 1000000000LL, 128);
    kbuffer_add_dummy_event(kbuf, 1000000001LL, 64);
    kbuffer_add_dummy_event(kbuf, 1000000002LL, 256);


    /*
     * Read events from the buffer.
     */
    printf("Reading events from the buffer:\n");
    event = kbuffer_first_event(kbuf, NULL);
    do {
        if (event) {
            ts = kbuffer_event_timestamp(kbuf);
            record_size = kbuffer_curr_size(kbuf);
            offset = kbuffer_curr_offset(kbuf);
            index = kbuffer_curr_index(kbuf);
            size = kbuffer_event_size(kbuf);

            /* Save the offset of the 20th event (or the last one if fewer than 20) */
            if (i == 20) {
                save_offset = offset;
            }

            printf(" event %3d ts:%lld\trecord_size:%d size:%d\tindex:%d offset:%d\n",
                   i++, ts, record_size, size, index, offset);
            event = kbuffer_next_event(kbuf, NULL);
        }
    } while (event);

    if (!event)
        printf("Finished sub buffer\n");

    /*
     * If we saved an offset, try to read the event at that offset.
     */
    if (save_offset > 0) {
        printf("Attempting to read event at saved offset %d\n", save_offset);
        event = kbuffer_read_at_offset(kbuf, save_offset, &ts);
        if (!event) {
            fprintf(stderr, "Funny, can't find event at offset %d\n", save_offset);
            exit(-1);
        }
        record_size = kbuffer_curr_size(kbuf);
        offset = kbuffer_curr_offset(kbuf);
        index = kbuffer_curr_index(kbuf);
        size = kbuffer_event_size(kbuf);
        printf("\n saved event 20 ts:%lld\trecord_size:%d size:%d\tindex:%d offset:%d\n\n",
               ts, record_size, size, index, offset);
    }

    /*
     * Free the trace event buffer.
     */
    kbuffer_free(kbuf);
    return 0;
}

# **EXAMPLES**

The following program demonstrates how to read events from a trace buffer,
save the offset of a specific event, and then read that event again using the
saved offset.
