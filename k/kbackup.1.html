KBACKUP(1) Manual de usuario de KBackup KBACKUP(1)

NOMBRE

kbackup - Programa de copia de seguridad con una interfaz fácil de usar

SINOPSIS

kbackup [OPCIONES...] [nombre de módulo | nombre de conjunto de módulo...]

DESCRIPCIÓN

Kbackup es un programa que le permite hacer copias de seguridad de cualquier directorio o archivo. Utiliza un árbol de directorios fácil de usar para seleccionar los elementos a respaldar y le permite guardar sus configuraciones en archivos de "perfil". Estos son archivos de texto simples que contienen definiciones de directorios y archivos a incluir o excluir del proceso de copia de seguridad.

OPCIONES

-v, --version

Muestra información de la versión.

-h, --help

Muestra ayuda sobre las opciones de la línea de comandos.

--help-all

Muestra ayuda, incluidas las opciones específicas de Qt.

--help-all --qmljsdebugger valor

Activa el depurador QML/JS con un puerto especificado. El valor debe tener el formato puerto:1234[,bloque]. "bloque" hace que la aplicación espere una conexión.

--script archivo

Script a ejecutar después de finalizar una sección del archivo.

--auto perfil

Ejecuta automáticamente la copia de seguridad con el perfil dado y termina cuando finaliza.

--autobg perfil

Ejecuta automáticamente la copia de seguridad con el perfil dado en segundo plano (sin mostrar una ventana) y termina cuando finaliza.

--verbose perfil

En modo autobg, sea detallado e imprima cada nombre de archivo durante la copia de seguridad.

--forceFull

En modo auto/autobg, fuerza que la copia de seguridad sea una copia de seguridad completa en lugar de actuar según la configuración del perfil.

--author

Muestra información del autor.

--license

Muestra información de la licencia.

--desktopfile archivo

El nombre base del archivo de entrada del escritorio para esta aplicación.

AMBIENTE

ARCHIVOS

Archivos de perfil .kbp. Generados por el usuario al guardar el perfil.

VER TAMBIÉN

EJEMPLOS

kbackup myData.kbp Se utiliza para cargar un perfil existente.
