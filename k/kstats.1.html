NOMBRE

kstats - muestra votos del algoritmo FMS estadístico para un volcado de ivs y una clave WEP especificada

SINOPSIS

kstats <archivo ivs> <clave de 104 bits>

DESCRIPCIÓN

kstats es una herramienta diseñada para mostrar los votos del algoritmo FMS para un volcado de ivs (vectores de inicialización) con una clave WEP especificada. El volcado de ivs se puede obtener utilizando la combinación de airodump(1) e ivstools(1).

EJEMPLO

kstats kstats out.ivs 123456789ABCDEF123456789AB
