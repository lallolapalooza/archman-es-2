NOMBRE

kclangctest - interfaz de línea de comandos para probar el enlace del lenguaje C

DESCRIPCIÓN

El comando `kclangctest' es una utilidad para pruebas de funcionalidad y pruebas de rendimiento del enlace del lenguaje C. Este comando se utiliza en el siguiente formato. `path' especifica la ruta de un archivo de base de datos. `rnum' especifica el número de iteraciones.


kclangctest order [-rnd] [-etc] [-tran] [-oat|-onl|-onl|-otl|-onr] path rnum
Realiza pruebas en orden.
kclangctest index [-rnd] [-etc] [-oat|-onl|-onl|-otl|-onr] path rnum
Realiza operaciones de indexación.
kclangctest map [-rnd] [-etc] [-bnum num] rnum
Realiza pruebas del mapa hash que ahorra memoria.
kclangctest list [-rnd] [-etc] rnum
Realiza pruebas de la lista de arrays que ahorra memoria.

Las opciones incluyen lo siguiente:

-rnd : realiza pruebas aleatorias.
-etc : realiza operaciones varias.
-tran : realiza transacciones.
-oat : abre la base de datos con la opción de transacción automática.
-oas : abre la base de datos con la opción de sincronización automática.
-onl : abre la base de datos con la opción de no bloqueo.
-otl : abre la base de datos con la opción de bloqueo de intento.
-onr : abre la base de datos con la opción de no reparación automática.
-bnum num : especifica el número de cubetas (buckets) de la tabla hash.

Este comando devuelve 0 si tiene éxito, otro valor si falla.
