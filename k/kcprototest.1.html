NOMBRE

kcprototest - interfaz de línea de comandos para probar la base de datos prototipo

DESCRIPCIÓN

El comando `kcprototest' es una utilidad para pruebas de facilidad y pruebas de rendimiento de la base de datos prototipo. Este comando se usa en el siguiente formato. `rnum' especifica el número de iteraciones.


kcprototest order [-tree] [-th num] [-rnd] [-etc] [-tran] rnum
Realiza pruebas en orden.
kcprototest queue [-tree] [-th num] [-it num] [-rnd] rnum
Realiza operaciones de cola.
kcprototest wicked [-tree] [-th num] [-it num] rnum
Realiza operaciones mixtas seleccionadas aleatoriamente.
kcprototest tran [-tree] [-th num] [-it num] rnum
Realiza pruebas de transacciones.

Las opciones presentan lo siguiente.

-tree : prueba la base de datos de árbol prototipo en lugar de la base de datos hash prototipo.
-th num : especifica el número de hilos de trabajo.
-rnd : realiza pruebas aleatorias.
-etc : realiza operaciones varias.
-tran : realiza transacciones.
-it num : especifica el número de repeticiones.

Este comando devuelve 0 en caso de éxito, otro valor en caso de fallo.
