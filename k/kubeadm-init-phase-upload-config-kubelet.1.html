NOMBRE

kubeadm init phase upload-config kubelet - Sube la configuración del componente kubelet a un ConfigMap

SINOPSIS

kubeadm init phase upload-config kubelet [OPCIONES]

DESCRIPCIÓN

Sube la configuración del kubelet extraída del objeto kubeadm InitConfiguration a un ConfigMap llamado kubelet-config en el clúster.

OPCIONES

--config="" Ruta a un archivo de configuración de kubeadm.

--cri-socket="" Ruta al socket CRI para conectar. Si está vacío, kubeadm intentará detectar este valor automáticamente; use esta opción solo si tiene más de un CRI instalado o si tiene un socket CRI no estándar.

--dry-run=false No aplique ningún cambio; solo muestre lo que se haría.

--kubeconfig="/etc/kubernetes/admin.conf" El archivo kubeconfig a usar al comunicarse con el clúster. Si la bandera no se establece, se puede buscar en una serie de ubicaciones estándar un archivo kubeconfig existente.

OPCIONES HEREDADAS DE COMANDOS PADRE

--rootfs="" La ruta al sistema de archivos raíz 'real' del host. Esto hará que kubeadm realice un chroot en la ruta proporcionada.

--version=false --version, --version=raw imprime información de la versión y sale; --version=vX.Y.Z... establece la versión reportada.

EJEMPLO

  # Sube la configuración de kubelet desde el archivo de configuración de kubeadm a un ConfigMap en el clúster.
  kubeadm init phase upload-config kubelet --config kubeadm.yaml
