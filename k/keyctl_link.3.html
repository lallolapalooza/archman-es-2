keyctl_link(3)

Paquete: keyutils

Licencias: GPL2, LGPL2.1

KEYCTL_LINK(3) Llamadas de gestión de claves de Linux KEYCTL_LINK(3)

NOMBRE

keyctl_link, keyctl_unlink - enlazar/desenlazar una clave a/desde un keyring

SINOPSIS

#include <keyutils.h>

long keyctl_link(key_serial_t key, key_serial_t keyring);

long keyctl_unlink(key_serial_t key, key_serial_t keyring);

DESCRIPCIÓN

keyctl_link() crea un enlace desde keyring a key, desplazando cualquier enlace a otra clave del mismo tipo y descripción en ese keyring si existe.

keyctl_unlink() elimina el enlace de keyring a key si existe.

El llamador debe tener permiso de escritura en un keyring para poder crear o eliminar enlaces en él.

El llamador debe tener permiso de enlace en una clave para poder crear un enlace a ella.

VALOR DE RETORNO

En caso de éxito, keyctl_link() y keyctl_unlink() devuelven 0. En caso de error, se devolverá el valor -1 y errno se habrá establecido con un error apropiado.

ERRORES

ENOKEY
La clave o el keyring especificados no son válidos.
EKEYEXPIRED
La clave o el keyring especificados han expirado.
EKEYREVOKED
La clave o el keyring especificados han sido revocados.
EACCES
El keyring existe, pero el proceso llamador no tiene permiso de escritura en él.

Solo para keyctl_link():

ENOMEM
Insuficiente memoria para expandir el keyring
EDQUOT
La expansión del keyring excedería la cuota del propietario del keyring.
EACCES
La clave existe, pero el proceso llamador no tiene permiso de enlace para ella.

ENLAZANDO

Esta es una función de biblioteca que se puede encontrar en libkeyutils. Al enlazar, se debe especificar -lkeyutils al enlazador.

VER TAMBIÉN
