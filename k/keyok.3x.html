NOMBRE

keyok - habilitar o deshabilitar un código de tecla de curses

SINOPSIS

#include <curses.h>
int keyok(int keycode, bool enable);

DESCRIPCIÓN

Esta es una extensión de la biblioteca curses. Permite a una aplicación deshabilitar códigos de tecla específicos, en lugar de usar la función keypad para deshabilitar todos los códigos de tecla. Las teclas que han sido deshabilitadas pueden ser re-habilitadas.

VALOR DE RETORNO

El código de tecla debe ser mayor que cero, de lo contrario se devuelve ERR. Si no corresponde a una tecla definida, entonces se devuelve ERR. Si el parámetro enable es verdadero, entonces la tecla debe haber sido deshabilitada, y viceversa. De lo contrario, la función devuelve OK.

PORTABILIDAD

Esta rutina es específica de ncurses. No era compatible con las implementaciones de la Versión 7, BSD o System V. Se recomienda que cualquier código que dependa de ellas se condicione usando NCURSES_VERSION.
