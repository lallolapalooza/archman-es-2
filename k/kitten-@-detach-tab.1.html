Nombre

kitten-@-detach-tab - Desacopla las pestañas especificadas y las coloca en una ventana de SO diferente/nueva

Uso

kitten @ detach-tab

Descripción

Desacopla las pestañas especificadas y las mueve a una nueva ventana de SO o las añade a la ventana de SO que contiene la pestaña especificada por --target-tab

Opciones

--match, -m
La pestaña a emparejar. Las especificaciones de coincidencia tienen la forma: campo:consulta. Donde campo puede ser uno de: id, index, title, window_id, window_title, pid, cwd, cmdline env, var, state, session y recent. consulta es la expresión a emparejar. Las expresiones pueden ser un número o una expresión regular, y pueden combinarse usando operadores booleanos.

El valor especial all empareja todas las pestañas.

Para campos numéricos: id, index, window_id, pid y recent, la expresión se interpreta como un número, no como una expresión regular. Los valores negativos para id/window_id emparejan desde el número de id más alto hacia abajo, en particular, -1 es la pestaña/ventana creada más recientemente.

Al usar title o id, primero se busca una pestaña que coincida, y si no se encuentra, se busca una ventana que coincida, y se usa la pestaña de esa ventana.

También puedes usar window_id y window_title para emparejar la pestaña que contiene la ventana con el id o título especificado.

El número de índice se usa para emparejar la n-ésima pestaña en la ventana de SO actualmente activa. El número recent empareja pestañas activas recientemente en la ventana de SO actualmente activa, siendo cero la pestaña actualmente activa, uno la pestaña activa anterior y así sucesivamente.

El campo session empareja pestañas que fueron creadas en la sesión especificada. Usa la expresión ^$ para emparejar ventanas que no fueron creadas en una sesión y . para emparejar la sesión actualmente activa y ~ para emparejar la sesión actualmente activa o la última sesión activa cuando no hay ninguna sesión activa.

Al usar el campo env para emparejar variables de entorno, puedes especificar solo el nombre de la variable de entorno o un nombre y un valor, por ejemplo, env:MY_ENV_VAR=2. Se emparejan las pestañas que contienen cualquier ventana con las variables de entorno especificadas. De manera similar, var empareja pestañas que contienen cualquier ventana con la variable de usuario especificada.

El campo state empareja según el estado de la pestaña. Los estados soportados son: active, focused, needs_attention, parent_active, parent_focused y focused_os_window. Las pestañas activas son las pestañas que están activas en su ventana de SO padre. Solo hay una pestaña enfocada y es la pestaña a la que se entregan los eventos de teclado. Si no hay ninguna pestaña enfocada, se empareja la última pestaña enfocada. El valor focused_os_window empareja todas las pestañas en la ventana de SO actualmente enfocada.

Ten en cuenta que puedes usar el comando kitten @ ls para obtener una lista de pestañas.

--self [=no]
Desacopla la pestaña en la que se ejecuta este comando, en lugar de la pestaña activa.
--help, -h [=no]
Muestra la ayuda para este comando

Opciones globales

--to
Una dirección para la instancia de kitty a controlar. Corresponde a la dirección dada a la instancia de kitty mediante la opción --listen-on o la configuración listen_on en kitty.conf. Si no se especifica, se comprueba la variable de entorno KITTY_LISTEN_ON. Si tampoco se encuentra, los mensajes se envían a la terminal de control de este proceso, es decir, solo funcionarán si este proceso se ejecuta dentro de una ventana de kitty.
--password
Una contraseña a usar al contactar con kitty. Esto hará que kitty le pida al usuario permiso para realizar la acción especificada, a menos que la contraseña haya sido aceptada antes o esté preconfigurada en kitty.conf. Para usar una contraseña en blanco especifica --use-password como always.
--password-file [=rc-pass]
Un archivo del que leer la contraseña. Se ignora el espacio en blanco final. Las rutas relativas se resuelven desde el directorio de configuración de kitty. Usa - para leer desde STDIN. Usa fd:num para leer desde el descriptor de archivo num. Se usa si no se proporciona --password. Por defecto, se comprueba el archivo rc-pass en el directorio de configuración de kitty.
--password-env [=KITTY_RC_PASSWORD]
El nombre de una variable de entorno de la que leer la contraseña. Se usa si no se proporciona --password-file. Por defecto, se comprueba la variable de entorno KITTY_RC_PASSWORD.
--use-password [=if-available]
Si no hay contraseña disponible, kitty normalmente solo enviará el comando de control remoto sin contraseña. Esta opción se puede usar para forzar que siempre o nunca use la contraseña proporcionada. Si se establece en always y no se proporciona contraseña, se usa la contraseña en blanco.

Opciones: if-available, always, never
