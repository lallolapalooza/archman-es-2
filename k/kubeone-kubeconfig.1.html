NOMBRE

kubeone-kubeconfig - Descargar el archivo kubeconfig desde el maestro

SINOPSIS

kubeone kubeconfig [banderas]

DESCRIPCIÓN

Descarga el archivo kubeconfig desde el maestro.

Este comando toma el manifiesto de KubeOne que contiene información sobre los hosts. Es posible obtener información sobre los hosts a partir de la salida de Terraform, utilizando la bandera '--tfjson'.

OPCIONES

-h, --help[=false] ayuda para kubeconfig

OPCIONES HEREDADAS DE COMANDOS PADRE

-c, --credentials="" Archivo de donde obtener credenciales y secretos

-d, --debug[=false] salida de depuración con trazas de pila

-l, --log-format="text" formato para el registro

-m, --manifest="./kubeone.yaml" Ruta al archivo de configuración de KubeOne

-t, --tfjson="" Origen de la salida de terraform en JSON - para leer desde stdin. Si la ruta es un archivo, se usarán sus contenidos. Si la ruta es un directorio, se ejecutará terraform output -json en esta ruta

-v, --verbose[=false] salida detallada

EJEMPLO

kubeone kubeconfig -m mi_cluster.yaml -t salida_terraform.json

VER TAMBIÉN

kubeone(1), kubeone-kubeconfig-generate(1)
