KDIFF3(1) Manual de Usuario de KDiff3 KDIFF3(1)

NOMBRE

kdiff3 - Herramienta para la Comparación y Fusión de Archivos y Carpetas

SINOPSIS

kdiff3 [-u, --ignore] [--query] [--html] [--abort] [-m, --merge] [-b, --base archivo] [-o, --output archivo] [--out archivo] [--noauto] [--auto] [--L1 alias1] [--L2 alias2] [--L3 alias3] [-L, --fname alias] [--cs cadena] [--confighelp] [--config archivo] [Archivo1] [Archivo2] [Archivo3]

DESCRIPCIÓN

Compara dos o tres archivos o carpetas de entrada.

OPCIONES

-u, --ignore

Ignorado. (Definido por el usuario.)

--query

Ignorado. (Definido por el usuario.)

--html

Ignorado. (Definido por el usuario.)

--abort

Ignorado. (Definido por el usuario.)

-m, --merge

Fusionar la entrada.

-b, --base archivo

Archivo base explícito. Para compatibilidad con ciertas herramientas.

-o, --output archivo

Archivo de salida. Implica -m. Por ejemplo: -o nuevofichero.txt

--out archivo

Archivo de salida, de nuevo. (Para compatibilidad con ciertas herramientas.)

--auto

Sin GUI si todos los conflictos son resolubles automáticamente. (Necesita -o archivo)

--noauto

Ignorar --auto y mostrar siempre la GUI.

--L1 alias1

Reemplazo de nombre visible para el archivo de entrada 1 (base).

--L2 alias2

Reemplazo de nombre visible para el archivo de entrada 2.

--L3 alias3

Reemplazo de nombre visible para el archivo de entrada 3.

-L, --fname alias

Reemplazo de nombre visible alternativo. Proporcione esto una vez por cada entrada.

--cs cadena

Anular una configuración. Use una vez por cada configuración. Por ejemplo: --cs AutoAdvance=1.

--confighelp

Mostrar la lista de configuraciones y los valores actuales.

--config archivo

Usar un archivo de configuración diferente.

Archivo1

archivo1 a abrir (base, si no se especifica a través de --base)

Archivo2

archivo2 a abrir

Archivo3

archivo3 a abrir
