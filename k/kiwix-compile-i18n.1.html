KIWIX-COMPILE-I18N(1) Comandos de usuario KIWIX-COMPILE-I18N(1)

NOMBRE

kiwix-compile-i18n - auxiliar para compilar datos i18n (internacionalización) de Kiwix

SINOPSIS

kiwix-compile-i18n [-h] --cxxfile CXXFILE i18n_resource_files ...

DESCRIPCIÓN

i18n_resource_files ...
La lista de recursos i18n a compilar.
-h, --help
muestra un mensaje de ayuda y sale
--cxxfile CXXFILE
El nombre del archivo Cpp a generar
