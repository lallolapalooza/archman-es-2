NOMBRE

kproplog - muestra el contenido del registro de actualización de principales de Kerberos

SINOPSIS

kproplog [-h] [-e num] [-v] kproplog [-R]

DESCRIPCIÓN

El comando kproplog muestra el contenido del registro de actualización de la base de datos KDC a la salida estándar. Puede usarse para hacer un seguimiento de las actualizaciones incrementales de la base de datos de principales. El archivo de registro de actualizaciones contiene el registro mantenido por el proceso kadmind(8) en el servidor KDC principal y el proceso kpropd(8) en los servidores KDC réplica. Cuando ocurren actualizaciones, se registran en este archivo. Posteriormente, cualquier réplica KDC configurada para actualizaciones incrementales solicitará los datos actuales del KDC principal y actualizará su archivo de registro con cualquier actualización devuelta.

El comando kproplog requiere acceso de lectura al archivo de registro de actualizaciones. Mostrará entradas de actualización solo para el KDC en el que se ejecuta.

Si no se especifican opciones, kproplog muestra un resumen del registro de actualizaciones. Si se invoca en el principal, kproplog también muestra todas las entradas de actualización. Si se invoca en un servidor KDC réplica, kproplog solo muestra un resumen de las actualizaciones, que incluye el número de serie de la última actualización recibida y la marca de tiempo asociada de la última actualización.

OPCIONES

-R
Restablece el registro de actualizaciones. Esto fuerza una resincronización completa. Si se usa en una réplica, esa réplica solicitará una resincronización completa. Si se usa en el principal, todas las réplicas solicitarán resincronizaciones completas.
-h
Muestra un resumen del registro de actualizaciones. Esta información incluye el número de versión de la base de datos, el estado de la base de datos, el número de actualizaciones en el registro, la marca de tiempo de la primera y última actualización, y el número de versión de la primera y última entrada de actualización.
-e num
Muestra las últimas num entradas de actualización en el registro. Esto es útil al depurar la sincronización entre servidores KDC.
-v
Muestra atributos individuales por actualización. Un ejemplo de la salida generada para una entrada:
Entrada de actualización
   Nº de serie de actualización : 4
   Operación de actualización : Añadir
   Principal de actualización : test@EJEMPLO.COM
   Tamaño de actualización : 424
   Confirmada actualización : Verdadero
   Marca de tiempo de actualización : Vie 20 Feb 23:37:42 2004
   Atributos cambiados : 6
         Principal
         Datos de clave
         Último cambio de contraseña
         Principal modificador
         Tiempo de modificación
         Datos TL

Ver kerberos(7) para una descripción de las variables de entorno de Kerberos.
