Nombre

kitten-icat - Muestra imágenes en la terminal

Descripción general

Muestra imágenes en la terminal

El kitten icat se puede usar para mostrar imágenes arbitrarias en la terminal kitty. Usarlo es tan simple como:

kitten icat image.jpeg

Soporta todos los tipos de imágenes soportados por ImageMagick https://www.imagemagick.org. Incluso funciona vía SSH. Para más detalles, consulte el protocolo gráfico de kitty <>.

Quizás quieras crear un alias en los archivos de configuración de tu shell:

alias icat="kitten icat"

Luego podrás usar simplemente icat image.png para ver imágenes.

Nota:

ImageMagick https://www.imagemagick.org debe estar instalado para el rango completo de tipos de imagen. Sin él, solo se soportan PNG/JPG/GIF/BMP/TIFF/WEBP.

Nota:

El protocolo de visualización de imágenes de kitty podría no funcionar cuando se usa dentro de un multiplexor de terminal como screen o tmux, dependiendo de si el multiplexor ha añadido o no soporte para él.

El kitten icat tiene varios argumentos de línea de comandos para permitir su uso desde dentro de otros programas para mostrar imágenes. En particular, --place, --detect-support y --print-window-size.

Si intentas integrar icat en un programa complejo como un gestor de archivos o un editor, hay algunas cosas a tener en cuenta. icat normalmente funciona comunicándose a través del dispositivo TTY, escribe y lee del TTY. Por lo tanto, es imperativo que mientras se ejecuta, el programa anfitrión no realice ninguna E/S del TTY. Cualquier pulsación de tecla u otra entrada del usuario en el dispositivo TTY será descartada. Si prefieres usarlo solo como backend para generar los códigos de escape para la visualización de imágenes, necesitas pasarle opciones para indicar las dimensiones de la ventana, dónde colocar la imagen en la ventana y el modo de transferencia a usar. Si haces eso, no intentará comunicarse con el dispositivo TTY en absoluto. Las opciones requeridas son: --use-window-size, --place y --transfer-mode, --stdin=no. Por ejemplo, para demostrar su uso sin acceso al TTY:

zsh -c 'setsid kitten icat --stdin=no --use-window-size $COLUMNS,$LINES,3000,2000 --transfer-mode=file myimage.png'

Aquí, setsid asegura que icat no tenga acceso al dispositivo TTY. Los valores 3000, 2000 son inventados. Son el ancho y alto de la ventana en píxeles, para obtener los cuales se necesita acceso al TTY.

Para ser realmente robusto, deberías considerar escribir soporte adecuado para el protocolo gráfico de kitty <> en el programa en su lugar. Hoy en día hay muchas bibliotecas que tienen soporte para él.

Código fuente de icat

El código fuente de este kitten está disponible en GitHub https://github.com/kovidgoyal/kitty/tree/master/kittens/icat.

Interfaz de línea de comandos

kitten icat [opciones] archivo-imagen-o-url-o-directorio ...

Una utilidad similar a cat para mostrar imágenes en la terminal. Puedes especificar múltiples archivos de imagen y/o directorios. Los directorios se escanean recursivamente en busca de archivos de imagen. Si STDIN no es una terminal, también se leerán datos de imagen de él. También puedes especificar URLs HTTP(S) o FTP que se descargarán y mostrarán automáticamente.

Opciones

--align <ALIGN>
Alineación horizontal para la imagen mostrada. Por defecto: center Opciones: center, left, right
--place <PLACE>
Elige dónde en la pantalla mostrar la imagen. La imagen se escalará para que quepa en el rectángulo especificado. La sintaxis para especificar rectángulos es <ancho>x<alto>@<izquierda>x<arriba>. Todas las medidas están en celdas (es decir, posiciones del cursor) con el origen (0, 0) en la esquina superior izquierda de la pantalla. Ten en cuenta que la opción --align alineará horizontalmente la imagen dentro de este rectángulo. Por defecto, la imagen se centra horizontalmente dentro del rectángulo. Usar place hará que el cursor se posicione en la esquina superior izquierda de la imagen, en lugar de en la línea siguiente a la imagen.
--scale-up [=no]
Cuando se usa en combinación con --place, hará que las imágenes más pequeñas que el área especificada se escalen para usar la mayor parte del área especificada posible.
--background <BACKGROUND>
Especifica un color de fondo, lo que hará que las imágenes transparentes se compongan sobre el color especificado. Por defecto: none
--mirror <MIRROR>
Refleja la imagen sobre un eje horizontal o vertical o ambos. Por defecto: none Opciones: both, horizontal, none, vertical
--clear [=no]
Elimina todas las imágenes mostradas actualmente en la pantalla. Ten en cuenta que esto no puede funcionar con multiplexores de terminal como tmux, ya que solo el multiplexor puede conocer la posición de la pantalla.
--transfer-mode <TRANSFER_MODE>
Qué mecanismo usar para transferir imágenes a la terminal. El valor por defecto es autodetectar. file significa usar un archivo temporal, memory significa usar memoria compartida, stream significa enviar los datos a través de códigos de escape de la terminal. Ten en cuenta que si usas los modos de transferencia file o memory y te conectas a través de una sesión remota, la visualización de imágenes no funcionará. Por defecto: detect Opciones: detect, file, memory, stream
--detect-support [=no]
Detecta el soporte para la visualización de imágenes en la terminal. Si no es compatible, saldrá con el código de salida 1, de lo contrario saldrá con el código 0 e imprimirá el modo de transferencia soportado a stderr, que puede usarse con la opción --transfer-mode.
--detection-timeout <DETECTION_TIMEOUT>
El tiempo (en segundos) a esperar por una respuesta de la terminal, al detectar el soporte de visualización de imágenes. Por defecto: 10
--use-window-size <USE_WINDOW_SIZE>
En lugar de consultar a la terminal por el tamaño de la ventana, usa el tamaño especificado, que debe tener el formato: ancho_en_celdas,alto_en_celdas,ancho_en_píxeles,alto_en_píxeles
--print-window-size [=no]
Imprime el tamaño de la ventana como <ancho>x<alto> (en píxeles) y sale. Este es un método de conveniencia para consultar el tamaño de la ventana si se usa kitten icat desde un lenguaje de scripting que no puede realizar llamadas termios.
--stdin <STDIN>
Lee datos de imagen desde STDIN. El valor por defecto es hacerlo automáticamente, cuando STDIN no es una terminal, pero puedes desactivarlo o activarlo explícitamente, si es necesario. Por defecto: detect Opciones: detect, no, yes
--silent [=no]
No utilizado, presente por compatibilidad con versiones anteriores.

Name

kitten-icat - display images in the terminal

Overview

kitten-icat is a tool for displaying images in the terminal. It supports various image formats and rendering methods.

Source code for icat

The source code for the icat command is available in the kitty terminal emulator project.

https://github.com/kovidgoyal/kitty/blob/master/kitty/icat.py

Command line interface

The following options control how images are displayed:

--engine <ENGINE>
El motor utilizado para decodificar y procesar imágenes. Por defecto, se utiliza el motor más apropiado. El motor builtin utiliza las bibliotecas de imagen nativas de Go. El motor magick utiliza ImageMagick, que requiere que esté instalado en el sistema. Por defecto: auto Opciones: auto, builtin, magick
--z-index <Z_INDEX>, -z <Z_INDEX>
Z-index de la imagen. Cuando es negativo, el texto se mostrará encima de la imagen. Utiliza un doble guion para valores por debajo del umbral para dibujar imágenes debajo de los colores de fondo de las celdas. Por ejemplo, --1 se evalúa como -1.073.741.825. Por defecto: 0
--loop <LOOP>, -l <LOOP>
Número de veces que se repiten las animaciones. Los valores negativos se repiten indefinidamente. Cero significa que solo se muestra el primer fotograma de la animación. De lo contrario, la animación se repite el número de veces especificado. Por defecto: -1
--hold [=no]
Espera a que se presione una tecla antes de salir después de mostrar las imágenes.
--unicode-placeholder [=no]
Utiliza el método de marcador de posición Unicode para mostrar las imágenes. Útil para mostrar imágenes desde programas de terminal de pantalla completa que no entienden el protocolo de gráficos de kitty, como multiplexores o editores. Consulte los marcadores de posición de gráficos Unicode <#graphics-unicode-placeholders> para obtener más detalles. Tenga en cuenta que al utilizar este método, las imágenes colocadas (con --place) que no caben en la pantalla se ajustarán al borde de la pantalla en lugar de truncarse. Este ajuste es por línea y, por lo tanto, la imagen parecerá entrelazada con líneas en blanco.
--passthrough <PASSTHROUGH>
Si se deben rodear los comandos de gráficos con secuencias de escape que les permitan pasar a través de programas como tmux. Por defecto, se detecta cuándo se está ejecutando dentro de tmux y se utilizan automáticamente los códigos de escape de paso de tmux. Tenga en cuenta que cuando esta opción está habilitada, implica también --unicode-placeholder. Por defecto: detect Opciones: detect, none, tmux
--image-id <IMAGE_ID>
El ID del protocolo de gráficos que se utilizará para la imagen creada. Normalmente, se crea un ID aleatorio si es necesario. Esta opción permite controlar el ID. Cuando se envían varias imágenes, se utilizan IDs secuenciales a partir del ID especificado. Los IDs válidos van de 1 a 4294967295. Los números fuera de este rango se envolverán automáticamente. Por defecto: 0
--no-trailing-newline [=no], -n [=no]
Por defecto, el cursor se mueve a la siguiente línea después de mostrar una imagen. Esta opción lo evita. No debe usarse al concatenar varias imágenes. Tampoco tiene ningún efecto cuando se utiliza la opción --place.
