NOMBRE

kubeadm init phase etcd local - Genera el archivo de manifiesto de Pod estático para una instancia etcd local de nodo único

SINOPSIS

kubeadm init phase etcd local [OPCIONES]

DESCRIPCIÓN

Genera el archivo de manifiesto de Pod estático para una instancia etcd local de nodo único.

OPCIONES

--cert-dir="/etc/kubernetes/pki" La ruta donde guardar y almacenar los certificados.

--config="" Ruta a un archivo de configuración de kubeadm.

--dry-run=false No aplicar ningún cambio; solo mostrar lo que se haría.

--image-repository="registry.k8s.io" Elegir un registro de contenedores para descargar las imágenes del plano de control.

--patches="" Ruta a un directorio que contiene archivos nombrados "target[suffix][+patchtype].extension". Por ejemplo, "kube-apiserver0+merge.yaml" o solo "etcd.json". "target" puede ser uno de "kube-apiserver", "kube-controller-manager", "kube-scheduler", "etcd", "kubeletconfiguration", "corednsdeployment". "patchtype" puede ser uno de "strategic", "merge" o "json" y coinciden con los formatos de parche admitidos por kubectl. El "patchtype" predeterminado es "strategic". "extension" debe ser "json" o "yaml". "suffix" es una cadena opcional que se puede usar para determinar qué parches se aplican primero alfanuméricamente.

OPCIONES HEREDADAS DE LOS COMANDOS PADRE

--rootfs="" La ruta al sistema de archivos raíz 'real' del host. Esto hará que kubeadm realice un chroot en la ruta proporcionada.

--version=false --version, --version=raw imprime información de la versión y sale; --version=vX.Y.Z... establece la versión reportada.

EJEMPLO

  # Genera el archivo de manifiesto de Pod estático para etcd, funcionalmente
  # equivalente a lo que genera kubeadm init.
  kubeadm init phase etcd local
  # Genera el archivo de manifiesto de Pod estático para etcd usando opciones
  # leídas de un archivo de configuración.
  kubeadm init phase etcd local --config config.yaml
