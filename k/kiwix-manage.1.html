KIWIX-MANAGE(1) Manual de comandos generales KIWIX-MANAGE(1)

NOMBRE

kiwix-manage - Gestor de la biblioteca Kiwix

SINOPSIS

kiwix-manage RUTA_BIBLIOTECA add RUTA_ZIM ...
kiwix-manage RUTA_BIBLIOTECA show [ID_ZIM_1] [ID_ZIM_2] ...
kiwix-manage RUTA_BIBLIOTECA remove ID_ZIM_1 [ID_ZIM_2] ...
kiwix-manage --version
kiwix-manage --help

DESCRIPCIÓN

kiwix-manage es una herramienta de línea de comandos para manipular una biblioteca XML de Kiwix.

kiwix-manage permite gestionar las entradas de la biblioteca de Kiwix. El archivo de la biblioteca es un archivo XML plano que lista los archivos ZIM con toda la información necesaria como id, favicon, fecha, creador, descripción, ruta_archivo, título, url, etc.

ACCIONES

add
Añade ARCHIVO_ZIM a ARCHIVO_BIBLIOTECA. Crea el archivo de la biblioteca si es necesario.
remove
Elimina el ID_ZIM dado de ARCHIVO_BIBLIOTECA. Se debe especificar al menos un ID_ZIM.
show
Muestra el ID_ZIM dado de ARCHIVO_BIBLIOTECA. Si no se proporciona ningún ID_ZIM, se muestra todo el contenido de ARCHIVO_BIBLIOTECA.

OPCIONES

Opciones a usar con la acción add:
--url=URL_HTTP
Establece la URL HTTP(S) en línea del ZIM
--zimPathToSave=RUTA_OTRO_FS
Establece una ruta arbitraria del sistema de archivos para el ZIM (en lugar de RUTA_ZIM)
Otras opciones (a usar solas):
--help | -h
Muestra la ayuda de kiwix-manage
--version | -v
Muestra la versión de kiwix-manage y todas sus dependencias
