KF6OPTIONS(7) Documentación de línea de comandos de Frameworks KF6OPTIONS(7)

NOMBRE

kf6options - Opciones comunes de línea de comandos para todas las aplicaciones basadas en KDE Frameworks 6

SINOPSIS

Aplicación KDE [-h, --help] [-v, --version] [--author] [--license] [--desktopfile nombre de archivo]

OPCIONES

Las siguientes opciones se aplican a todas las aplicaciones KDE:

-h --help

Esto lista las opciones disponibles en la línea de comandos.

-v --version

Lista la información de versión de Aplicación KDE.

--author

Lista los autores de Aplicación KDE en la ventana de terminal.

--license

Muestra información de licencia.

--desktopfile nombre de archivo

El nombre base del archivo de entrada de escritorio para esta aplicación.

Esto es especialmente útil para aplicaciones envoltorio y aplicaciones que en general tienen múltiples archivos de escritorio. Por lo tanto, cada archivo de escritorio puede poner su propio nombre en el comando exec.
