kmon(1) Manual de comandos generales kmon(1)

NOMBRE

kmon - kmon 1.7.1 Orhun Parmaksız <orhunparmaksiz@gmail.com> Gestor y monitor de actividad del kernel de Linux

Presiona '?' mientras ejecutas la interfaz de terminal para ver los atajos de teclado.

SINOPSIS

kmon [-a|--color-acento] [-c|--color] [-t|--tasa-ticks] [-r|--reverso] [-u|--unicode] [-E|--regex] [-h|--ayuda] [-V|--version] [subcomandos]

DESCRIPCIÓN

kmon 1.7.1 Orhun Parmaksız <orhunparmaksiz@gmail.com> Gestor y monitor de actividad del kernel de Linux

Presiona '?' mientras ejecutas la interfaz de terminal para ver los atajos de teclado.

OPCIONES

-a, --color-acento=COLOR [por defecto: blanco]
Establece el color de acento usando formato hexadecimal o nombre de color
-c, --color=COLOR [por defecto: gris oscuro]
Establece el color principal usando formato hexadecimal o nombre de color
-t, --tasa-ticks=MS [por defecto: 250]
Establece la tasa de refresco de la terminal
-r, --reverso
Invierte la lista de módulos del kernel
-u, --unicode
Muestra símbolos Unicode para los títulos de los bloques
-E, --regex
Interpreta la consulta de búsqueda de módulos como una expresión regular
-h, --ayuda
Imprime la ayuda
-V, --version
Imprime la versión

SUBCOMANDOS

kmon-sort(1)
Ordena los módulos del kernel
kmon-help(1)
Imprime este mensaje o la ayuda de los subcomandos dados
