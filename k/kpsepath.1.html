kpsetool(1) Manual de Comandos Generales kpsetool(1)

NOMBRE

kpsetool - script para hacer disponibles las herramientas estilo teTeX kpsetool, kpsexpand y kpsepath

SINOPSIS

kpsetool [ OPCIONES... ] COMANDO

kpsexpand [ OPCIONES... ] CADENA

kpsepath [ OPCIONES... ] TIPODERUTA

DESCRIPCIÓN

kpsetool es un script de Bourne shell que hace disponibles las herramientas estilo teTeX kpsetool, kpsexpand y kpsepath. kpsetool utiliza el binario kpsexpand (nuevo) de web2c, por lo que la sintaxis de kpsexpand es incompatible con la de teTeX a partir de la versión 0.4.

OPCIONES

-m modo
establece el modo Metafont
-n nombredeprog
simula ser nombredeprog para kpathsea
-p
actúa como kpsepath(1)
-v
actúa como kpsexpand(1)
-w
actúa como kpsewhich(1)

USO

TIPODERUTA puede ser

base
volcado de memoria Metafont
bib
fuente de bibliografía BibTeX
bst
archivos de estilo BibTeX
cnf
archivos de configuración en tiempo de ejecución de Kpathsea
dvips_config
archivos de configuración de dvips
dvips_header
archivos de cabecera de dvips
fmt
volcado de memoria TeX
gf
mapa de bits de fuente genérico
mem
volcado de memoria MetaPost
mf
fuente Metafont
mfpool
cadenas del programa Metafont
mp
fuente MetaPost
mppool
cadenas del programa MetaPost
mpsupport
archivos de soporte de MetaPost
pict
otros tipos de figuras
pk
fuente de mapa de bits empaquetada
tex
fuente TeX
texpool
cadenas del programa TeX
tfm
métricas de fuente TeX
troff_font
fuentes troff
vf
fuente virtual
