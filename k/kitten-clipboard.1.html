Nombre

kitten-clipboard - Copiar/pegar con el portapapeles del sistema, incluso a través de SSH

Resumen

Copiar/pegar al portapapeles del sistema desde scripts de shell

El kitten clipboard se puede utilizar para leer o escribir en el portapapeles del sistema desde la shell. Incluso funciona a través de SSH. Usarlo es tan simple como:

echo hooray | kitten clipboard

Todo el texto recibido en STDIN se copia al portapapeles.

Para obtener texto del portapapeles:

kitten clipboard --get-clipboard

El texto se escribirá en STDOUT. Tenga en cuenta que por defecto kitty pide permiso cuando un programa intenta leer el portapapeles. Esto se puede controlar a través de clipboard_control <#opt-kitty.clipboard_control>.

Añadido en la versión 0.27.0: Soporte para copiar tipos de datos arbitrarios

El kitten clipboard se puede usar para enviar/recibir más que solo texto plano del portapapeles del sistema. Puedes transferir tipos de datos arbitrarios. Lo mejor se ilustra con algunos ejemplos:

# Copiar una imagen al portapapeles:
kitten clipboard picture.png
# Copiar una imagen y algo de texto al portapapeles:
kitten clipboard picture.jpg text.txt
# Copiar texto desde STDIN y una imagen al portapapeles:
echo hello | kitten clipboard picture.png /dev/stdin
# Copiar cualquier imagen ráster disponible en el portapapeles a un archivo PNG:
kitten clipboard -g picture.png
# Copiar una imagen a un archivo y texto a STDOUT:
kitten clipboard -g picture.png /dev/stdout
# Listar los formatos disponibles en el portapapeles del sistema
kitten clipboard -g -m . /dev/stdout

Normalmente, el kitten adivina los tipos MIME basándose en los nombres de archivo. Para controlar los tipos MIME con precisión, usa la opción --mime.

Este kitten utiliza un nuevo protocolo desarrollado por kitty para funcionar, para más detalles, consulta Copiar todos los tipos de datos al portapapeles <>.

Código fuente de clipboard

El código fuente de este kitten está disponible en GitHub https://github.com/kovidgoyal/kitty/tree/master/kittens/clipboard.

Interfaz de línea de comandos

kitten clipboard [opciones] [archivos para copiar desde/hacia]

Lee o escribe en el portapapeles del sistema.

Este kitten opera más simplemente en modo filtro. Para establecer el texto del portapapeles, redirige el nuevo texto a STDIN. Usa la opción --get-clipboard para en su lugar generar el contenido actual del portapapeles a STDOUT. Ten en cuenta que copiar desde el portapapeles provocará una ventana emergente de permisos, consulta clipboard_control <#opt-kitty.clipboard_control> para más detalles.

Para un mayor control, especifica argumentos de nombre de archivo. Entonces, diferentes tipos MIME se pueden copiar desde/hacia el portapapeles. Algunos ejemplos:

# Copiar una imagen al portapapeles:
kitten clipboard picture.png
# Copiar una imagen y algo de texto al portapapeles:
kitten clipboard picture.jpg text.txt
# Copiar texto desde STDIN y una imagen al portapapeles:
echo hello | kitten clipboard picture.png /dev/stdin
# Copiar cualquier imagen ráster disponible en el portapapeles a un archivo PNG:
kitten clipboard -g picture.png
# Copiar una imagen a un archivo y texto a STDOUT:
kitten clipboard -g picture.png /dev/stdout
# Listar los formatos disponibles en el portapapeles del sistema
kitten clipboard -g -m . /dev/stdout

Opciones

--get-clipboard [=no], -g [=no]
Genera el contenido actual del portapapeles a STDOUT. Ten en cuenta que por defecto kitty solicitará permiso para acceder al portapapeles. Se puede controlar mediante clipboard_control <#opt-kitty.clipboard_control>.
--use-primary [=no], -p [=no]
Utiliza la selección primaria en lugar del portapapeles en sistemas que lo soporten, como Linux.
--mime <MIME>, -m <MIME>
El tipo MIME del archivo especificado. Útil cuando el tipo MIME detectado automáticamente es probable que sea incorrecto o el nombre del archivo no tiene extensión y, por lo tanto, no se puede detectar ningún tipo MIME. Si se especifica más de un archivo, esta opción debe especificarse varias veces, una por cada archivo especificado. Al copiar datos del portapapeles, puedes usar comodines para que coincidan con tipos MIME. Por ejemplo: --mime 'text/*' coincidirá con cualquier tipo MIME textual disponible en el portapapeles, normalmente se copia el primer tipo MIME coincidente. El tipo MIME especial . devolverá la lista de tipos MIME disponibles actualmente en el portapapeles del sistema.
--alias <ALIAS>, -a <ALIAS>
Especifica alias para tipos MIME. Los tipos MIME aliased se consideran equivalentes. Al copiar al portapapeles, tanto el original como el alias se ponen a disposición en el portapapeles. Al copiar desde el portapapeles, si no se encuentra el original, se utiliza el alias como último recurso. Se puede especificar varias veces para crear varios alias. Por ejemplo: --alias text/plain=text/x-rst hace que text/plain sea un alias de text/rst. Los alias no se utilizan en modo filtro. Un alias para text/plain se crea automáticamente si text/plain no está presente en los datos de entrada, pero sí otro tipo MIME text/*.
--wait-for-completion [=no]
Espera hasta que la copia al portapapeles se complete antes de salir. Útil si ejecutas el kitten en una ventana dedicada y efímera. Solo es necesario en modo filtro.
--password <PASSWORD>
Una contraseña para usar al acceder al portapapeles. Si el usuario elige aceptar la contraseña, las invocaciones futuras del kitten no tendrán una solicitud de permiso en esta sesión de tty. No funciona en modo filtro. Debe tener el formato: text:contraseña-real o fd:entero (un número de descriptor de archivo para leer la contraseña) o file:ruta-al-archivo (un archivo del que leer la contraseña). Ten en cuenta que también debes especificar un nombre amigable para humanos usando la opción --human-name.
--human-name <HUMAN_NAME>
Un nombre amigable para humanos que se mostrará al usuario al solicitar permiso para acceder al portapapeles.
