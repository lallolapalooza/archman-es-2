NOMBRE

kubeadm init phase upload-config kubeadm - Sube la ClusterConfiguration de kubeadm a un ConfigMap

SINOPSIS

kubeadm init phase upload-config kubeadm [OPCIONES]

DESCRIPCIÓN

Sube la ClusterConfiguration de kubeadm a un ConfigMap llamado kubeadm-config en el namespace kube-system. Esto permite la configuración correcta de los componentes del sistema y una experiencia de usuario fluida al actualizar.

Alternativamente, puedes usar kubeadm config.

OPCIONES

--config="" Ruta a un archivo de configuración de kubeadm.

--cri-socket="" Ruta al socket CRI para conectar. Si está vacío, kubeadm intentará detectar automáticamente este valor; usa esta opción solo si tienes más de un CRI instalado o si tienes un socket CRI no estándar.

--dry-run=false No apliques ningún cambio; solo muestra lo que se haría.

--kubeconfig="/etc/kubernetes/admin.conf" El archivo kubeconfig a usar al comunicarse con el clúster. Si la opción no está establecida, se puede buscar en una serie de ubicaciones estándar un archivo kubeconfig existente.

OPCIONES HEREDADAS DE COMANDOS PADRE

--rootfs="" La ruta al sistema de archivos raíz 'real' del host. Esto hará que kubeadm haga chroot a la ruta proporcionada.

--version=false --version, --version=raw imprime información de versión y sale; --version=vX.Y.Z... establece la versión reportada.

EJEMPLO

  # sube la configuración de tu clúster
  kubeadm init phase upload-config kubeadm --config=myConfig.yaml
