KBD_MODE(1) Manual de comandos generales KBD_MODE(1)

NOMBRE

kbd_mode - informar o establecer el modo del teclado

SINOPSIS

kbd_mode [ -a | -u | -k | -s | -d ] [ -f ] [ -C CONSOLA ]

DESCRIPCIÓN

Sin argumentos, kbd_mode imprime el modo de teclado actual (RAW, MEDIUMRAW o XLATE). Usando las opciones es posible cambiar el modo del teclado de la consola actual o de la consola especificada.

OPCIONES

-a, --ascii
establecer modo ASCII (XLATE).
-k, --keycode
establecer modo de código de tecla (MEDIUMRAW).
-s, --scancode
establecer modo de código de escaneo (RAW).
-u, --unicode
establecer modo UTF-8 (UNICODE).
-d, --disable
establecer modo Desactivado (OFF).
-f, --force
cambiar el modo incluso si hace que el teclado no sea utilizable.
-C, --console=DEV
el dispositivo de consola a usar.

Por supuesto, el "-a" es solo tradicional, y el código utilizado puede ser cualquier conjunto de caracteres de 8 bits. Con "-u" se espera un conjunto de caracteres de 16 bits, y estos caracteres se transmiten al kernel como 1, 2 o 3 bytes (siguiendo la codificación UTF-8). En estos dos últimos modos se utiliza el mapeo de teclas definido por loadkeys(1).

El modo Desactivado para el teclado de la consola virtual OFF complementa a RAW, en el que se ignoran todos los eventos del teclado. El modo evita que los búferes de entrada de vt se desborden cuando un programa se abre pero no lee de una tty, como Xorg usando solo evdev para la entrada.

kbd_mode opera en la consola especificada por la opción "-C"; si no hay ninguna, se usa la consola asociada con stdin.

Advertencia: cambiar el modo del teclado, aparte de entre ASCII y Unicode, probablemente hará que su teclado no sea utilizable. Establezca la opción "-f" para forzar dichos cambios. Este comando solo está destinado a ser utilizado (por ejemplo, a través de un inicio de sesión remoto) cuando algún programa dejó su teclado en el estado incorrecto. Tenga en cuenta que en algunas versiones obsoletas de este programa la opción "-u" era un sinónimo de "-s" y las versiones anteriores de este programa pueden no reconocer la opción "-f".
