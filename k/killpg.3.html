killpg(3) Manual de funciones de biblioteca killpg(3)

NOMBRE

killpg - enviar señal a un grupo de procesos

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <signal.h>
int killpg(int pgrp, int sig);
Requisitos de Macro de Prueba de Funciones para glibc (ver feature_test_macros(7)):

killpg():

    _XOPEN_SOURCE >= 500
        || /* Desde glibc 2.19: */ _DEFAULT_SOURCE
        || /* glibc <= 2.19: */ _BSD_SOURCE

DESCRIPCIÓN

killpg() envía la señal sig al grupo de procesos pgrp. Ver signal(7) para una lista de señales.

Si pgrp es 0, killpg() envía la señal al grupo de procesos del proceso que llama. (POSIX dice: si pgrp es menor o igual a 1, el comportamiento es indefinido.)

Para los permisos requeridos para enviar una señal a otro proceso, ver kill(2).

VALOR DE RETORNO

En caso de éxito, se devuelve cero. En caso de error, se devuelve -1 y errno se establece para indicar el error.

ERRORES

EINVAL
sig no es un número de señal válido.
EPERM
El proceso no tiene permiso para enviar la señal a ninguno de los procesos de destino. Para los permisos requeridos, ver kill(2).
ESRCH
No se encontró ningún proceso en el grupo de procesos especificado por pgrp.
ESRCH
Se proporcionó el grupo de procesos como 0, pero el proceso que envía no tiene un grupo de procesos.

VERSIONES

Existen varias diferencias entre la verificación de permisos en sistemas tipo BSD y sistemas tipo System V. Ver el razonamiento de POSIX para kill(3p). Una diferencia no mencionada por POSIX se refiere al valor de retorno EPERM: BSD documenta que no se envía ninguna señal y se devuelve EPERM cuando la comprobación de permisos falló para al menos un proceso de destino, mientras que POSIX documenta EPERM solo cuando la comprobación de permisos falló para todos los procesos de destino.

Diferencias C biblioteca/kernel

En Linux, killpg() se implementa como una función de biblioteca que realiza la llamada kill(-pgrp, sig).

ESTÁNDARES

POSIX.1-2008.

HISTORIA

POSIX.1-2001, SVr4, 4.4BSD (apareció por primera vez en 4BSD).

VER TAMBIÉN

getpgrp(2), kill(2), signal(2), capabilities(7), credentials(7)
