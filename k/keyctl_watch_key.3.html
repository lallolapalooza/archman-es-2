keyctl_watch_key(3)

Paquete: keyutils

Licencias: GPL2, LGPL2.1

KEYCTL_GRANT_PERMISSION(3) Llamadas de gestión de claves de Linux KEYCTL_GRANT_PERMISSION(3)

NOMBRE

keyctl_watch_key - Observar cambios en una clave

SINOPSIS

#include <keyutils.h>

long keyctl_watch_key(key_serial_t key,
                      int watch_queue_fd
                      int watch_id);

DESCRIPCIÓN

keyctl_watch_key() establece o elimina una observación sobre key.

watch_id especifica el ID para una observación que se incluirá en los mensajes de notificación. Puede estar entre 0 y 255 para añadir una clave; debe ser -1 para eliminar una clave.

watch_queue_fd es un descriptor de archivo adjunto a una instancia de dispositivo watch_queue. Múltiples aperturas de un dispositivo proporcionan instancias separadas. Cada instancia de dispositivo solo puede tener una observación sobre una clave particular.

Registro de notificación

Los mensajes de notificación específicos de clave que el kernel emite en el búfer tienen el siguiente formato:


struct key_notification {
	struct watch_notification watch;
	__u32	key_id;
	__u32	aux;
};

El campo watch.type se establecerá en WATCH_TYPE_KEY_NOTIFY y el campo watch.subtype contendrá una de las siguientes constantes, indicando el evento que ocurrió y el watch_id pasado a keyctl_watch_key() se colocará en watch.info en el campo ID. Los siguientes eventos están definidos:

NOTIFY_KEY_INSTANTIATED
Esto indica que una clave observada fue instanciada o negativamente instanciada. key_id indica la clave que fue instanciada y aux no se utiliza.
NOTIFY_KEY_UPDATED
Esto indica que una clave observada fue actualizada o instanciada por actualización. key_id indica la clave que fue actualizada y aux no se utiliza.
NOTIFY_KEY_LINKED
Esto indica que una clave fue enlazada a un keyring observado. key_id indica el keyring que fue modificado y aux indica la clave que fue añadida.
NOTIFY_KEY_UNLINKED
Esto indica que una clave fue desenlazada de un keyring observado. key_id indica el keyring que fue modificado y aux indica la clave que fue eliminada.
NOTIFY_KEY_CLEARED
Esto indica que un keyring observado fue vaciado. key_id indica el keyring que fue vaciado y aux no se utiliza.
NOTIFY_KEY_REVOKED
Esto indica que una clave observada fue revocada. key_id indica la clave que fue revocada y aux no se utiliza.
NOTIFY_KEY_INVALIDATED
Esto indica que una clave observada fue invalidada. key_id indica la clave que fue invalidada y aux no se utiliza.
NOTIFY_KEY_SETATTR
Esto indica que los atributos de una clave observada (propietario, grupo, permisos, tiempo de espera) fueron modificados. key_id indica la clave que fue modificada y aux no se utiliza.

Notificación de eliminación

Cuando una clave observada es recolectada por el recolector de basura, todas sus observaciones se destruyen automáticamente y se entrega una notificación a cada observador. Normalmente será una notificación extendida de la forma:


struct watch_notification_removal {
	struct watch_notification watch;
	__u64	id;
};

El campo watch.type se establecerá en WATCH_TYPE_META y el campo watch.subtype contendrá WATCH_META_REMOVAL_NOTIFICATION. Si se proporciona la notificación extendida, la longitud será de 2 unidades; de lo contrario, será 1 y solo estará presente la cabecera.

El watch_id pasado a keyctl_watch_key() se colocará en watch.info en el campo ID.

Si la extensión está presente, id se establecerá en el ID de la clave destruida.

VALOR DE RETORNO

En caso de éxito, keyctl_watch_key() devuelve 0. En caso de error, se devolverá el valor -1 y errno se habrá establecido con el error apropiado.

ERRORES

ENOKEY
La clave especificada no existe.
EKEYEXPIRED
La clave especificada ha expirado.
EKEYREVOKED
La clave especificada ha sido revocada.
EACCES
La clave nombrada existe, pero no otorga permiso de vista al proceso llamante.
EBUSY
La clave especificada ya tiene una observación para esa instancia de dispositivo (solo añadir).
EBADSLT
La clave especificada no tiene una observación (solo eliminación).

ENLAZADO

Esta es una función de biblioteca que se puede encontrar en libkeyutils. Al enlazar, se debe especificar -lkeyutils al enlazador.
