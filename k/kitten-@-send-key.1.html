Nombre

kitten-@-send-key - Envía pulsaciones de teclas arbitrarias a las ventanas especificadas

Uso

kitten @ send-key [TECLAS A ENVIAR ...]

Descripción

Envía pulsaciones de teclas arbitrarias a las ventanas especificadas. Todas las teclas especificadas se envían primero como eventos de pulsación y luego como eventos de liberación en orden inverso. Las teclas se envían a los programas que se ejecutan en las ventanas. Solo se envían si el modo de teclado actual para el programa admite la tecla en particular. Por ejemplo: send-key ctrl+a ctrl+b. Tenga en cuenta que los errores no se informan, por razones técnicas, por lo que send-key siempre tiene éxito, incluso si no se envió ninguna tecla a ninguna ventana.

Opciones

--match, -m
La ventana a buscar. Las especificaciones de búsqueda son del tipo: campo:consulta. Donde campo puede ser uno de: id, title, pid, cwd, cmdline, num, env, var, state, neighbor, session y recent. consulta es la expresión a buscar. Las expresiones pueden ser un número o una expresión regular, y pueden combinarse usando operadores booleanos.

El valor especial all busca todas las ventanas.

Para los campos numéricos: id, pid, num y recent, la expresión se interpreta como un número, no como una expresión regular. Los valores negativos para id buscan desde el número de id más alto hacia abajo, en particular, -1 es la ventana creada más recientemente.

El campo num se refiere a la posición de la ventana en la pestaña actual, comenzando desde cero y contando en sentido horario (este es el mismo orden en que se informan las ventanas mediante el comando kitten @ ls).

El id de ventana de la ventana actual está disponible como la variable de entorno KITTY_WINDOW_ID.

El campo recent se refiere a las ventanas activadas recientemente en la pestaña activa actual, donde cero es la ventana activada actualmente, uno es la ventana activada anteriormente, y así sucesivamente.

El campo neighbor se refiere a un vecino de la ventana activa en la dirección especificada, que puede ser: left, right, top o bottom.

El campo session busca ventanas que se crearon en la sesión especificada. Use la expresión ^$ para buscar ventanas que no se crearon en una sesión y . para buscar la sesión activa actual y ~ para buscar ya sea la sesión activa actual o la última sesión activa cuando no hay ninguna sesión activa.

Al usar el campo env para buscar variables de entorno, puede especificar solo el nombre de la variable de entorno o un nombre y valor, por ejemplo, env:MY_ENV_VAR=2.

De manera similar, el campo var busca variables de usuario establecidas en la ventana. Puede especificar el nombre o el nombre y valor como con el campo env.

El campo state busca el estado de la ventana. Los estados admitidos son: active, focused, needs_attention, parent_active, parent_focused, focused_os_window, self, overlay_parent. Las ventanas activas son las ventanas que están activas en su pestaña principal. Solo hay una ventana enfocada y es la ventana a la que se entregan los eventos del teclado. Si no hay ninguna ventana enfocada, se busca la última ventana enfocada. El valor focused_os_window busca todas las ventanas en la ventana del sistema operativo enfocada actualmente. El valor self busca la ventana en la que se ejecuta el comando de control remoto. El valor overlay_parent busca la ventana que está debajo de la ventana self, cuando la ventana self es una superposición.

Tenga en cuenta que puede usar el comando kitten @ ls para obtener una lista de ventanas.

--match-tab, -t
La pestaña a buscar. Las especificaciones de búsqueda son del tipo: campo:consulta. Donde campo puede ser uno de: id, index, title, window_id, window_title, pid, cwd, cmdline env, var, state, session y recent. consulta es la expresión a buscar. Las expresiones pueden ser un número o una expresión regular, y pueden combinarse usando operadores booleanos.

El valor especial all busca todas las pestañas.

Para los campos numéricos: id, index, window_id, pid y recent, la expresión se interpreta como un número, no como una expresión regular. Los valores negativos para id/window_id buscan desde el número de id más alto hacia abajo, en particular, -1 es la pestaña/ventana creada más recientemente.

Al usar title o id, primero se busca una pestaña coincidente y, si no se encuentra, se busca una ventana coincidente, y se usa la pestaña de esa ventana.

También puede usar window_id y window_title para buscar la pestaña que contiene la ventana con el id o título especificado.

El número de índice se utiliza para buscar la enésima pestaña en la ventana del sistema operativo activa actual. El número recent busca pestañas activadas recientemente en la ventana del sistema operativo activa actual, donde cero es la pestaña activa actual, uno es la pestaña activada anteriormente y así sucesivamente.

El campo session busca pestañas que se crearon en la sesión especificada. Use la expresión ^$ para buscar ventanas que no se crearon en una sesión y . para buscar la sesión activa actual y ~ para buscar ya sea la sesión activa actual o la última sesión activa cuando no hay ninguna sesión activa.

Al usar el campo env para buscar variables de entorno, puede especificar solo el nombre de la variable de entorno o un nombre y valor, por ejemplo, env:MY_ENV_VAR=2. Se buscan las pestañas que contienen cualquier ventana con las variables de entorno especificadas. De manera similar, var busca pestañas que contienen cualquier ventana con la variable de usuario especificada.

El campo state busca el estado de la pestaña. Los estados admitidos son: active, focused, needs_attention, parent_active, parent_focused y focused_os_window. Las pestañas activas son las pestañas que están activas en su ventana del sistema operativo principal. Solo hay una pestaña enfocada y es la pestaña a la que se entregan los eventos del teclado. Si no hay ninguna pestaña enfocada, se busca la última pestaña enfocada. El valor focused_os_window busca todas las pestañas en la ventana del sistema operativo enfocada actualmente.

Tenga en cuenta que puede usar el comando kitten @ ls para obtener una lista de pestañas.

--all [=no]
Buscar todas las ventanas.
--exclude-active [=no]
No enviar texto a la ventana activa, incluso si es una de las ventanas buscadas.

Opciones globales

--to
Una dirección para que la instancia de kitty controle. Corresponde a la dirección dada a la instancia de kitty a través de la opción --listen-on o la configuración listen_on en kitty.conf. Si no se especifica, se verifica la variable de entorno KITTY_LISTEN_ON. Si tampoco se encuentra, los mensajes se envían al terminal de control para este proceso, es decir, solo funcionarán si este proceso se ejecuta dentro de una ventana de kitty.
--password
Una contraseña para usar al contactar con kitty. Esto hará que kitty solicite al usuario permiso para realizar la acción especificada, a menos que la contraseña haya sido aceptada anteriormente o esté preconfigurada en kitty.conf. Para usar una contraseña en blanco, especifique --use-password siempre.
--password-file [=rc-pass]
Un archivo desde el cual leer la contraseña. Se ignora el espacio en blanco final. Las rutas relativas se resuelven desde el directorio de configuración de kitty. Use - para leer desde STDIN. Use fd:num para leer desde el descriptor de archivo num. Se utiliza si no se proporciona --password. Por defecto, se comprueba si existe el archivo rc-pass en el directorio de configuración de kitty.

El nombre de una variable de entorno desde la cual leer la contraseña. Se utiliza si no se proporciona --password-file. Por defecto, se comprueba la variable de entorno KITTY_RC_PASSWORD.

kitty-send-key(1) — kitty manual

Name
kitty-send-key — Send a keyboard event to a kitty window

Usage

kitty @ send-key [--interval interval] [--repeat repeat] key

Description

The kitty-send-key command is used to send a keyboard event to the currently active kitty window. This can be used to automate tasks or to send input to applications running in kitty.

The key argument specifies the key to send. It can be a single character or a special key name. Special key names include:

  • ctrl, alt, shift, super
  • f1 through f12
  • up, down, left, right
  • home, end, pageup, pagedown
  • delete, insert, backspace, tab
  • enter, escape

Modifier keys can be combined using +, e.g., ctrl+shift+a.

Options

--interval interval
Specifies the interval in seconds between sending key presses. Defaults to 0.01.
--repeat repeat
Specifies the number of times to repeat the key press. Defaults to 1. If 0 is used, the key will be held down until explicitly released.

Global options

These options apply to all kitty remote control commands.

--config-file path-to-config
Use the specified config file instead of the default (~/.config/kitty/kitty.conf).
--session-path path-to-session
Use the specified session file instead of the default (~/.local/state/kitty/inbox.sock).
--wait-for-signal
Wait for the STARTSIGNAL or STARTSEND a signal before processing the command. This is useful to ensure that the kitty window is ready to receive input.
--single-window
Send the command to a single window. If more than one window is available, an error is raised.
--to-window window_id
Send the command to the specified window ID.
--to-prompt
Send the command to the prompt line in the current window. This option is only valid when running kitty in its mode for managing input fields, like in the kitty remote control itself.
--to-all-windows
Send the command to all windows.
--to-cwd-and-args cwd,args
Send the command to the window whose current working directory and command-line arguments match the specified ones.
--allow-non-empty-password
Allow sending commands to a window even if it has a password set. By default, if the window is password protected, the command is not sent.
--allow-alternative-protocol
Allow sending commands even if the alternative protocol is enabled. By default, if the alternative protocol is enabled, the command is not sent.
--password password
The password to use when sending commands to a window that requires one. If not provided, and a password is required, the command will fail.
--password-file path-to-password-file
Read the password from the specified file.

If the password is not provided, the blank password is used.

Choices: if-available, always, never
