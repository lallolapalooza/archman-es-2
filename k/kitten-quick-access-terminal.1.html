Name

kitten-quick-access-terminal - Una terminal de acceso rápido que puedes invocar instantáneamente con una pulsación de tecla o un comando.

Vista general

Añadido en la versión 0.42.0: Ver aquí en qué plataformas funciona <#panel-compat>.

Este kitten se puede usar para crear una terminal de acceso rápido, que aparece y desaparece con una pulsación de tecla. Para hacerlo, usa el siguiente comando:

kitten quick-access-terminal

Ejecuta este comando en una terminal y aparecerá una ventana de kitty de acceso rápido en la parte superior de tu pantalla. Vuelve a ejecutarlo y la ventana se ocultará.

Para que la terminal aparezca y desaparezca con una pulsación de tecla:

En Linux, simplemente asigna el comando anterior a un atajo global en tu gestor de ventanas. En macOS, ve a Preferencias del Sistema->Teclado->Atajos de teclado->Servicios->General y establece un atajo para la entrada Acceso rápido a kitty.

Configuración

Puedes configurar la apariencia y el comportamiento de la ventana de acceso rápido creando un archivo quick-access-terminal.conf en tu carpeta de configuración de kitty <#confloc>. En particular, puedes usar la opción kitty_conf para cambiar varias configuraciones de kitty, solo para la ventana de acceso rápido.

Nota:

Este kitten utiliza el kitten panel <> bajo el capó. Puedes usar las técnicas descritas allí <#remote-control-panel> para el control remoto de la ventana de acceso rápido, recuerda añadir kitty_override allow_remote_control=socket-only y kitty_override listen_on=unix:/tmp/whatever a quick-access-terminal.conf.

Ver abajo las directivas de configuración compatibles:

Apariencia de la ventana

lines
lines 25

El número de líneas que se muestran en el panel. Se ignora para paneles de fondo, centrados y verticales. Si tiene el sufijo px, entonces establece la altura del panel en píxeles en lugar de líneas.

columns
columns 80

El número de columnas que se muestran en el panel. Se ignora para paneles de fondo, centrados y horizontales. Si tiene el sufijo px, entonces establece el ancho del panel en píxeles en lugar de columnas.

edge
edge top

En qué borde de la pantalla colocar el panel. Ten en cuenta que algunos gestores de ventanas (como i3) no admiten la colocación de ventanas acopladas en los bordes izquierdo y derecho. El valor background significa hacer del panel el "fondo de pantalla". Ten en cuenta que al usar sway, si estableces un fondo en tu configuración de sway, este cubrirá el fondo dibujado usando este kitten. Además, hay tres valores adicionales: center, center-sized y none. El valor center ancla el panel a todos los lados y cubre toda la pantalla (en macOS, la parte de la pantalla no cubierta por la barra de título y el dock). El panel se puede reducir y colocar usando los parámetros de margen. El valor none ancla el panel a la esquina superior izquierda y debe colocarse usando los parámetros de margen. Su tamaño se establece mediante lines y columns. El valor center-sized es igual que none excepto que el panel está centrado en lugar de en la esquina superior izquierda y los márgenes no tienen ningún efecto.

background_opacity
background_opacity 0.85

La opacidad de fondo de la ventana. Esto funciona igual que la opción de kitty del mismo nombre, está presente aquí ya que tiene un valor predeterminado diferente para la terminal de acceso rápido.

hide_on_focus_loss
hide_on_focus_loss no

Oculta la ventana cuando pierde automáticamente el foco del teclado. Usar esta opción forzará focus_policy a on-demand.

grab_keyboard
grab_keyboard no

Captura el teclado. Esto significa que los atajos globales definidos en el sistema operativo se pasarán a kitty en su lugar. Útil si deseas crear una ventana modal del sistema operativo. La eficacia de esto depende del sistema operativo/gestor de ventanas/entorno de escritorio. En Wayland, solo funciona si el compositor implementa el protocolo inhibit-keyboard-shortcuts https://wayland.app/protocols/keyboard-shortcuts-inhibit-unstable-v1. En macOS, Apple no permite que las aplicaciones capturen el teclado sin permisos especiales, por lo que no funciona.

margin_left
margin_left 0

Establece el margen izquierdo del panel, en píxeles. No tiene efecto en los paneles del borde derecho. Solo funciona en macOS y en compositores Wayland que admiten el protocolo de shell de capa wlr.

margin_right
margin_right 0

Establece el margen derecho del panel, en píxeles. No tiene efecto en los paneles del borde izquierdo. Solo funciona en macOS y en compositores Wayland que admiten el protocolo de shell de capa wlr.

margin_top
margin_top 0

Establece el margen superior del panel, en píxeles. No tiene efecto en los paneles del borde inferior. Solo funciona en macOS y en compositores Wayland que admiten el protocolo de shell de capa wlr.

margin_bottom
margin_bottom 0

Establece el margen inferior del panel, en píxeles. No tiene efecto en los paneles del borde superior. Solo funciona en macOS y en compositores Wayland que admiten el protocolo de shell de capa wlr.

kitty_conf

Ruta al archivo de configuración a usar para kitty al dibujar la ventana. Se puede especificar varias veces. Por defecto, se usa el kitty.conf normal. Las rutas relativas se resuelven con respecto al directorio de configuración de kitty.

kitty_override

Anula opciones de configuración individuales de kitty, se puede especificar varias veces. Sintaxis: kitty_override nombre=valor. Por ejemplo: kitty_override font_size=20.

app_id
app_id kitty-quick-access

En Wayland, establece el espacio de nombres de la superficie del shell de capa. En X11, establece el WM_CLASS asignado a la ventana de acceso rápido. (Solo Linux)

output_name

El panel solo se puede mostrar en un monitor (salida) a la vez. Esto te permite especificar qué salida se utiliza, por nombre. Si no se especifica, el compositor elegirá una salida automáticamente, típicamente la última salida con la que interactuó el usuario o el monitor principal. Ejecuta

kitten-quick-access-terminal(1) — Kitty console emulator

Name

kitten quick_access_terminal - quick access terminal kitten

Overview

The quick access terminal kitten provides a quick access terminal window that you can bring up instantly with a keypress or a command.

Configuration

The quick access terminal kitten supports the following configuration options, which can be set in your kitty configuration file (e.g. ~/.config/kitty/kitty.conf) or set on the command line using --override.

Window appearance

initial_window_width
initial_window_width 80%

The initial width of the window. Can be specified in pixels or as a percentage of the screen width.

initial_window_height
initial_window_height 50%

The initial height of the window. Can be specified in pixels or as a percentage of the screen height.

position
position center

The position of the window. Can be specified as a pixel coordinate (e.g. 100x200) or using keywords like center, top-left, top-right, bottom-left, bottom-right.

border_width
border_width 0

The width of the window border in pixels.

margin
margin 0 0

The margin around the window in pixels. Specified as top-right-bottom-left or top-bottom right-left or all.

output
output

Specify the output (monitor) to display the window on. Use kitten shell --output-name list to get a list of available outputs. Use listjson for a json encoded output. Note that on Wayland the output can only be set at panel creation time, it cannot be changed after creation, nor is there anyway to display a single panel on all outputs. Please complain to the Wayland developers about this.

start_as_hidden
start_as_hidden no

Whether to start the quick access terminal hidden. Useful if you are starting it as part of system startup.

focus_policy
focus_policy exclusive

On a Wayland compositor that supports the wlr layer shell protocol, specify the focus policy for keyboard interactivity with the panel. Please refer to the wlr layer shell protocol documentation for more details. Note that different Wayland compositors behave very differently with exclusive, your mileage may vary. On macOS, exclusive and on-demand are currently the same.

Source code for quick_access_terminal

The source code for this kitten is available on GitHub https://github.com/kovidgoyal/kitty/tree/master/kittens/quick_access_terminal.

Command line interface

kitten quick_access_terminal [options] [cmdline-to-run ...]

A quick access terminal window that you can bring up instantly with a keypress or a command.

Options

--config <CONFIG>, -c <CONFIG>
Specify a path to the configuration file(s) to use. All configuration files are merged onto the builtin quick-access-terminal.conf, overriding the builtin values. This option can be specified multiple times to read multiple configuration files in sequence, which are merged. Use the special value NONE to not load any config file.

If this option is not specified, config files are searched for in the order: $XDG_CONFIG_HOME/kitty/quick-access-terminal.conf, ~/.config/kitty/quick-access-terminal.conf, $XDG_CONFIG_DIRS/kitty/quick-access-terminal.conf. The first one that exists is used as the config file.

If the environment variable KITTY_CONFIG_DIRECTORY <#envvar-KITTY_CONFIG_DIRECTORY> is specified, that directory is always used and the above searching does not happen.

If /etc/xdg/kitty/quick-access-terminal.conf exists, it is merged before (i.e. with lower priority) than any user config files. It can be used to specify system-wide defaults for all users. You can use either - or /dev/stdin to read the config from STDIN.

--override <OVERRIDE>, -o <OVERRIDE>
Override individual configuration options, can be specified multiple times. Syntax: name=value. For example: -o lines=12
--detach [=no]
Detach from the controlling terminal, if any, running in an independent child process, the parent process exits immediately.
--detached-log <DETACHED_LOG>
Path to a log file to store STDOUT/STDERR when using --detach
--instance-group <INSTANCE_GROUP>
The unique name of this quick access terminal Use a different name if you want multiple such terminals. Default: quick-access
--debug-rendering [=no]
For debugging interactions with the compositor/window manager.
--debug-input [=no]
For debugging interactions with the compositor/window manager.

You can download a sample quick-access-terminal.conf file with all default settings and comments describing each setting by clicking: sample quick-access-terminal.conf.
