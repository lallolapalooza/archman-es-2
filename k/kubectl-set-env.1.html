NOMBRE

kubectl set env - Actualiza variables de entorno en una plantilla de pod.

SINOPSIS

kubectl set env [OPCIONES]

DESCRIPCIÓN

Actualiza variables de entorno en una plantilla de pod.

Lista definiciones de variables de entorno en uno o más pods, plantillas de pod. Añade, actualiza o elimina definiciones de variables de entorno de contenedores en una o más plantillas de pod (dentro de controladores de replicación o configuraciones de despliegue). Ve o modifica las definiciones de variables de entorno en todos los contenedores de los pods o plantillas de pod especificados, o solo en aquellos que coincidan con un comodín.

Si se pasa "--env -", las variables de entorno se pueden leer desde STDIN usando la sintaxis estándar de env.

Los recursos posibles incluyen (sin distinción de mayúsculas y minúsculas):

    pod (po), replicationcontroller (rc), deployment (deploy), daemonset (ds), statefulset (sts), cronjob (cj), replicaset (rs)

OPCIONES

--all=false Si es true, selecciona todos los recursos en el namespace de los tipos de recursos especificados

--allow-missing-template-keys=true Si es true, ignora cualquier error en las plantillas cuando un campo o clave de mapa falta en la plantilla. Solo se aplica a los formatos de salida golang y jsonpath.

-c, --containers="*" Los nombres de los contenedores en las plantillas de pod seleccionadas a cambiar - puede usar comodines

--dry-run="none" Debe ser "none", "server", o "client". Si la estrategia es client, solo imprime el objeto que se enviaría, sin enviarlo. Si la estrategia es server, envía una solicitud del lado del servidor sin persistir el recurso.

-e, --env=[] Especifica un par clave-valor para una variable de entorno que se establecerá en cada contenedor.

--field-manager="kubectl-set" Nombre del gestor utilizado para rastrear la propiedad de los campos.

-f, --filename=[] Nombre del archivo, directorio o URL a archivos del recurso para actualizar el entorno.

--from="" El nombre de un recurso desde el cual inyectar variables de entorno.

--keys=[] Lista separada por comas de claves a importar desde el recurso especificado.

-k, --kustomize="" Procesa el directorio kustomization. Esta bandera no se puede usar junto con -f o -R.

--list=false Si es true, muestra el entorno y cualquier cambio en el formato estándar. Esta bandera se eliminará cuando tengamos kubectl view env.

--local=false Si es true, set env NO contactará con el api-server sino que se ejecutará localmente.

-o, --output="" Formato de salida. Uno de: (json, yaml, name, go-template, go-template-file, template, templatefile, jsonpath, jsonpath-as-json, jsonpath-file).

--overwrite=true Si es true, permite sobrescribir el entorno, de lo contrario rechaza las actualizaciones que sobrescriban el entorno existente.

--prefix="" Prefijo a añadir a los nombres de las variables.

-R, --recursive=false Procesa el directorio utilizado en -f, --filename recursivamente. Útil cuando quieres gestionar manifiestos relacionados organizados dentro del mismo directorio.

--resolve=false Si es true, muestra referencias a secretos o configmaps al listar variables.

-l, --selector="" Selector (consulta de etiquetas) para filtrar, soporta '=', '==', '!=', 'in', 'notin'. (ej. -l key1=value1,key2=value2,key3 in (value3)). Los objetos coincidentes deben cumplir todas las restricciones de etiquetas especificadas.

--show-managed-fields=false Si es true, conserva los managedFields al imprimir objetos en formato JSON o YAML.

--template="" Cadena de plantilla o ruta a un archivo de plantilla a utilizar cuando -o=go-template, -o=go-template-file. El formato de plantilla es de plantillas de Go [http://golang.org/pkg/text/template/#pkg-overview].

OPCIONES HEREDADAS DE COMANDOS PADRE

--as="" Nombre de usuario a suplantar para la operación. El usuario podría ser un usuario regular o una cuenta de servicio en un namespace.

--as-group=[] Grupo a suplantar para la operación, esta bandera puede repetirse para especificar múltiples grupos.

--as-uid="" UID a suplantar para la operación.

--cache-dir="/home/username/.kube/cache" Directorio de caché predeterminado.

--certificate-authority="" Ruta a un archivo de certificado para la autoridad de certificación.

--client-certificate="" Ruta a un archivo de certificado de cliente para TLS.

--client-key="" Ruta a un archivo de clave de cliente para TLS.

--cluster="" El nombre del clúster de kubeconfig a usar.

--context="" El nombre del contexto de kubeconfig a usar.

--disable-compression=false Si es true, desactiva la compresión de respuesta para todas las solicitudes al servidor.

--insecure-skip-tls-verify=false Si es true, el certificado del servidor no se verificará su validez. Esto hará que tus conexiones HTTPS sean inseguras.

--kubeconfig="" Ruta al archivo kubeconfig a utilizar para las solicitudes CLI.

--kuberc="" Ruta al archivo kuberc a utilizar para las preferencias. Esto puede ser deshabilitado exportando el feature gate KUBECTL_KUBERC=false o desactivando el feature KUBERC=off.

--match-server-version=false Requiere que la versión del servidor coincida con la versión del cliente.

-n, --namespace="" Si está presente, el alcance del namespace para esta solicitud CLI.

--password="" Contraseña para autenticación básica al servidor API.

--profile="none" Nombre del perfil a capturar. Uno de (none|cpu|heap|goroutine|threadcreate|block|mutex).

--profile-output="profile.pprof" Nombre del archivo donde escribir el perfil.

--request-timeout="0" La duración de tiempo a esperar antes de desistir en una sola solicitud al servidor. Los valores distintos de cero deben contener una unidad de tiempo correspondiente (ej. 1s, 2m, 3h). Un valor de cero significa no realizar timeout en las solicitudes.

-s, --server="" La dirección y el puerto del servidor API de Kubernetes.

--tls-server-name="" Nombre del servidor a usar para la validación del certificado del servidor. Si no se proporciona, se usa el nombre de host utilizado para contactar al servidor.

--token="" Token Bearer para la autenticación al servidor API.

--user="" El nombre del usuario de kubeconfig a usar.

--username="" Nombre de usuario para autenticación básica al servidor API.

--version=false --version, --version=raw imprime información de versión y sale; --version=vX.Y.Z... establece la versión reportada.

--warnings-as-errors=false Trata las advertencias recibidas del servidor como errores y sale con un código de salida distinto de cero.

EJEMPLO

  # Actualiza el despliegue 'registry' con una nueva variable de entorno
  kubectl set env deployment/registry STORAGE_DIR=/local
  # Lista las variables de entorno definidas en el despliegue 'sample-build'
  kubectl set env deployment/sample-build --list
  # Lista las variables de entorno definidas en todos los pods
  kubectl set env pods --all --list
  # Muestra el despliegue modificado en YAML, y no altera el objeto en el servidor
  kubectl set env deployment/sample-build STORAGE_DIR=/data -o yaml
  # Actualiza todos los contenedores en todos los controladores de replicación en el proyecto para tener ENV=prod
  kubectl set env rc --all ENV=prod
  # Importa el entorno desde un secreto
  kubectl set env --from=secret/mysecret deployment/myapp
  # Importa el entorno desde un mapa de configuración con un prefijo
  kubectl set env --from=configmap/myconfigmap --prefix=MYSQL_ deployment/myapp
  # Importa claves específicas de un mapa de configuración
  kubectl set env --keys=my-example-key --from=configmap/myconfigmap deployment/myapp
  # Elimina la variable de entorno ENV del contenedor 'c1' en todas las configuraciones de despliegue
  kubectl set env deployments --all --containers="c1" ENV-
  # Elimina la variable de entorno ENV de una definición de despliegue en disco y
  # actualiza la configuración de despliegue en el servidor
  kubectl set env -f deploy.json ENV-
  # Establece algunas variables del entorno del shell local en una configuración de despliegue en el servidor
  env | grep RAILS_ | kubectl set env -e - deployment/registry
