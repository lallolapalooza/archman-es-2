NOMBRE

kcutiltest - Interfaz de línea de comandos para probar las funciones de utilidad

DESCRIPCIÓN

El comando `kcutiltest' es una utilidad para la prueba de instalaciones y la prueba de rendimiento de las funciones de utilidad. Este comando se utiliza en el siguiente formato. `rnum' especifica el número de iteraciones. `path' especifica la ruta de un archivo.


kcutiltest mutex [-th num] [-iv num] rnum
Realiza pruebas de primitivas de bloqueo.
kcutiltest cond [-th num] [-iv num] rnum
Realiza pruebas de primitivas de variables de condición.
kcutiltest para [-th num] [-iv num] rnum
Realiza pruebas de procesamiento paralelo.
kcutiltest file [-th num] [-rnd] [-msiz num] path rnum
Realiza pruebas de la abstracción del sistema de archivos.
kcutiltest lhmap [-rnd] [-bnum num] rnum
Realiza pruebas de mapa hash de doble enlace.
kcutiltest thmap [-rnd] [-bnum num] rnum
Realiza pruebas de mapa hash que ahorra memoria.
kcutiltest talist [-rnd] rnum
Realiza pruebas de lista de arreglos que ahorra memoria.
kcutiltest misc rnum
Realiza pruebas de mecanismos varios.

Las opciones presentan lo siguiente.

-th num : especifica el número de hilos trabajadores.
-iv num : especifica el intervalo entre iteraciones.
-rnd : realiza pruebas aleatorias.
-msiz num : especifica el tamaño de la región mapeada en memoria.
-bnum num : especifica el número de cubetas de la tabla hash.

Este comando devuelve 0 en caso de éxito, otro valor en caso de fallo.
