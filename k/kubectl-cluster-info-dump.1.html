NOMBRE

kubectl cluster-info dump - Volcar información relevante para depuración y diagnóstico

SINOPSIS

kubectl cluster-info dump [OPCIONES]

DESCRIPCIÓN

Volcar información del clúster adecuada para depurar y diagnosticar problemas del clúster. Por defecto, vuelca todo a la salida estándar. Opcionalmente, puedes especificar un directorio con --output-directory. Si especificas un directorio, Kubernetes creará un conjunto de archivos en ese directorio. Por defecto, solo vuelca elementos del espacio de nombres actual y del espacio de nombres kube-system, pero puedes cambiar a un espacio de nombres diferente con la opción --namespaces, o especificar --all-namespaces para volcar todos los espacios de nombres.

El comando también vuelca los registros de todos los pods en el clúster; estos registros se vuelcan en diferentes directorios según el espacio de nombres y el nombre del pod.

OPCIONES

-A, --all-namespaces=false Si es verdadero, volcar todos los espacios de nombres. Si es verdadero, se ignora --namespaces.

--allow-missing-template-keys=true Si es verdadero, ignorar cualquier error en las plantillas cuando un campo o clave de mapa falta en la plantilla. Solo se aplica a los formatos de salida golang y jsonpath.

--namespaces=[] Una lista separada por comas de espacios de nombres para volcar.

-o, --output="json" Formato de salida. Uno de: (json, yaml, name, go-template, go-template-file, template, templatefile, jsonpath, jsonpath-as-json, jsonpath-file).

--output-directory="" Dónde volcar los archivos. Si está vacío o es '-', usa la salida estándar, de lo contrario crea una jerarquía de directorios en ese directorio

--pod-running-timeout=20s La duración (como 5s, 2m o 3h, mayor que cero) para esperar hasta que al menos un pod esté en ejecución

--show-managed-fields=false Si es verdadero, conservar los managedFields al imprimir objetos en formato JSON o YAML.

--template="" Cadena de plantilla o ruta a un archivo de plantilla para usar cuando -o=go-template, -o=go-template-file. El formato de plantilla son plantillas de Go [http://golang.org/pkg/text/template/#pkg-overview].

OPCIONES HEREDADAS DE COMANDOS PADRE

--as="" Nombre de usuario a suplantar para la operación. El usuario podría ser un usuario regular o una cuenta de servicio en un espacio de nombres.

--as-group=[] Grupo a suplantar para la operación, esta opción se puede repetir para especificar múltiples grupos.

--as-uid="" UID a suplantar para la operación.

--cache-dir="/home/username/.kube/cache" Directorio de caché predeterminado

--certificate-authority="" Ruta a un archivo de certificado para la autoridad de certificación

--client-certificate="" Ruta a un archivo de certificado de cliente para TLS

--client-key="" Ruta a un archivo de clave de cliente para TLS

--cluster="" El nombre del clúster de kubeconfig a usar

--context="" El nombre del contexto de kubeconfig a usar

--disable-compression=false Si es verdadero, optar por no comprimir las respuestas para todas las solicitudes al servidor

--insecure-skip-tls-verify=false Si es verdadero, el certificado del servidor no se verificará en cuanto a validez. Esto hará que tus conexiones HTTPS no sean seguras

--kubeconfig="" Ruta al archivo kubeconfig a usar para las solicitudes de CLI.

--kuberc="" Ruta al archivo kuberc a usar para preferencias. Esto se puede deshabilitar exportando el feature gate KUBECTL_KUBERC=false o desactivando el feature KUBERC=off.

--match-server-version=false Requerir que la versión del servidor coincida con la versión del cliente

-n, --namespace="" Si está presente, el ámbito del espacio de nombres para esta solicitud de CLI

--password="" Contraseña para la autenticación básica al servidor de API

--profile="none" Nombre del perfil a capturar. Uno de (none|cpu|heap|goroutine|threadcreate|block|mutex)

--profile-output="profile.pprof" Nombre del archivo a escribir el perfil

--request-timeout="0" La duración antes de rendirse en una única solicitud al servidor. Los valores distintos de cero deberían contener una unidad de tiempo correspondiente (por ejemplo, 1s, 2m, 3h). Un valor de cero significa no agotar el tiempo de espera de las solicitudes.

-s, --server="" La dirección y el puerto del servidor de API de Kubernetes

--tls-server-name="" Nombre del servidor a usar para la validación del certificado del servidor. Si no se proporciona, se utiliza el nombre de host utilizado para contactar al servidor

--token="" Token Bearer para autenticación al servidor de API

--user="" El nombre del usuario de kubeconfig a usar

--username="" Nombre de usuario para la autenticación básica al servidor de API

--version=false --version, --version=raw imprimen información de la versión y salen; --version=vX.Y.Z... establece la versión informada

--warnings-as-errors=false Tratar las advertencias recibidas del servidor como errores y salir con un código de salida distinto de cero

EJEMPLO

  # Volcar el estado actual del clúster a la salida estándar
  kubectl cluster-info dump
  # Volcar el estado actual del clúster a /ruta/al/estado-del-cluster
  kubectl cluster-info dump --output-directory=/ruta/al/estado-del-cluster
  # Volcar todos los espacios de nombres a la salida estándar
  kubectl cluster-info dump --all-namespaces
  # Volcar un conjunto de espacios de nombres a /ruta/al/estado-del-cluster
  kubectl cluster-info dump --namespaces default,kube-system --output-directory=/ruta/al/estado-del-cluster
