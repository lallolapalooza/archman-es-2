KEYCTL_CAPABILITIES(3) Llamadas de gestión de claves de Linux KEYCTL_CAPABILITIES(3)

NOMBRE

keyctl_capabilities - Consultar las capacidades del subsistema

SINOPSIS

#include <keyutils.h>

long keyctl_capabilities(unsigned char *buffer, size_t buflen);

DESCRIPCIÓN

keyctl_capabilities() consulta el subsistema de keyrings en el kernel para preguntar sobre sus capacidades y rellena la matriz en el buffer con bits que indican la presencia o ausencia de características específicas en el subsistema de keyrings.

La función devuelve la cantidad de datos que el kernel tiene disponibles, independientemente de la cantidad de espacio de buffer disponible. Si el buffer es más corto que los datos, se realizará una copia parcial; si el buffer es más grande que los datos, el espacio sobrante se limpiará.

Si esta operación no está disponible en el kernel, la biblioteca keyutils la emulará lo mejor que pueda y el bit de capacidad que indica si la operación del kernel está disponible se limpiará.

En buffer[0], existen las siguientes capacidades:

KEYCTL_CAPS0_CAPABILITIES
Se establece si el kernel soporta esta operación y se borra en caso contrario. Si se borra, las demás banderas se emulan.
KEYCTL_CAPS0_PERSISTENT_KEYRINGS
Se establece si el kernel soporta keyrings persistentes y se borra en caso contrario. Véase keyctl_get_persistent(3).
KEYCTL_CAPS0_DIFFIE_HELLMAN
Se establece si el kernel soporta el cálculo de Diffie-Hellman y se borra en caso contrario. Véase keyctl_dh_compute(3).
KEYCTL_CAPS0_PUBLIC_KEY
Se establece si el kernel soporta operaciones de clave pública y se borra en caso contrario. Véase keyctl_pkey_query(3).
KEYCTL_CAPS0_BIG_KEY
Se establece si el kernel soporta el tipo de clave big_key y se borra en caso contrario.
KEYCTL_CAPS0_INVALIDATE
Se establece si el kernel soporta la invalidación de claves y se borra en caso contrario. Véase keyctl_invalidate(3).
KEYCTL_CAPS0_RESTRICT_KEYRING
Se establece si el kernel soporta restricciones en los keyrings y se borra en caso contrario. Véase keyctl_restrict_keyring(3).
KEYCTL_CAPS0_MOVE
Se establece si el kernel soporta la operación de mover clave y se borra en caso contrario. Véase keyctl_move(3).

En buffer[1], existen las siguientes capacidades:

KEYCTL_CAPS1_NS_KEYRING_NAME
Se establece si los nombres de los keyrings se segregan según el user-namespace en el que se crea un keyring.
KEYCTL_CAPS1_NS_KEY_TAG
Se establece si una clave o keyring puede ser etiquetado con un namespace, permitiendo así que coexistan múltiples claves con el mismo tipo y descripción, pero diferentes etiquetas de namespace, dentro del mismo keyring. El etiquetado puede ser automático dependiendo del tipo de clave. Actualmente solo se utiliza el etiquetado de network-namespace.

VALOR DE RETORNO

En caso de éxito, keyctl_capabilities() devuelve el tamaño de los datos disponibles, independientemente del tamaño del buffer. En caso de error, se devolverá el valor -1 y se habrá establecido errno con un error apropiado.

ERRORES

EFAULT
No se puede escribir en el buffer.

ENLAZADO

Esta es una función de biblioteca que se puede encontrar en libkeyutils. Al enlazar, se debe especificar -lkeyutils al enlazador.

VER TAMBIÉN
