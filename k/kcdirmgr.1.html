NOMBRE

kcdirmgr - interfaz de línea de comandos para gestionar la base de datos hash de directorios

DESCRIPCIÓN

El comando `kcdirmgr' es una utilidad para probar y depurar la base de datos hash de directorios y sus aplicaciones. `ruta' especifica la ruta de un archivo de base de datos. `clave' especifica la clave de un registro. `valor' especifica el valor de un registro. `archivo' especifica el archivo de entrada/salida.


kcdirmgr create [-otr] [-onl|-otl|-onr] [-tc] ruta
Crea un archivo de base de datos.
kcdirmgr inform [-onl|-otl|-onr] [-st] ruta
Imprime información de estado.
kcdirmgr set [-onl|-otl|-onr] [-add|-app|-rep|-inci|-incd] [-sx] ruta clave valor
Almacena un registro.
kcdirmgr remove [-onl|-otl|-onr] [-sx] ruta clave
Elimina un registro.
kcdirmgr get [-onl|-otl|-onr] [-rm] [-sx] [-px] [-pz] ruta clave
Imprime el valor de un registro.
kcdirmgr list [-onl|-otl|-onr] [-max num] [-rm] [-sx] [-pv] [-px] ruta [clave]
Imprime las claves de todos los registros, separadas por saltos de línea.
kcdirmgr clear [-onl|-otl|-onr] ruta
Elimina todos los registros de una base de datos.
kcdirmgr import [-onl|-otl|-onr] [-sx] ruta [archivo]
Importa registros de un archivo TSV.
kcdirmgr copy [-onl|-otl|-onr] ruta archivo
Copia toda la base de datos.
kcdirmgr dump [-onl|-otl|-onr] ruta [archivo]
Vuelca registros en un archivo snapshot.
kcdirmgr load [-otr] [-onl|-otl|-onr] ruta [archivo]
Carga registros desde un archivo snapshot.
kcdirmgr defrag [-onl|-otl|-onr] ruta
Realiza la desfragmentación.
kcdirmgr setbulk [-onl|-otl|-onr] ruta clave valor ...
Almacena registros a la vez.
kcdirmgr removebulk [-onl|-otl|-onr] [-sx] ruta clave ...
Elimina registros a la vez.
kcdirmgr getbulk [-onl|-otl|-onr] [-sx] [-px] ruta clave ...
Recupera registros a la vez.
kcdirmgr check [-onl|-otl|-onr] ruta
Comprueba la consistencia.

Las opciones incluyen lo siguiente:

-otr : abre la base de datos con la opción de truncamiento.
-onl : abre la base de datos con la opción de no bloqueo.
-otl : abre la base de datos con la opción de intentar bloqueo.
-onr : abre la base de datos con la opción de no reparación automática.
-tc : ajusta la base de datos con la opción de compresión.
-st : imprime información miscelánea.
-add : realiza operación de añadir.
-app : realiza operación de añadir al final.
-rep : realiza operación de reemplazar.
-inci : realiza operación de incremento entero.
-incd : realiza operación de incremento de número real.
-sx : los datos de entrada se evalúan como una cadena de datos hexadecimales.
-rm : elimina el registro.
-px : los datos de salida se convierten en una cadena de datos hexadecimales.
-pz : no añade salto de línea al final de la salida.
-max num : especifica el número máximo de registros mostrados.
-pv : también imprime los valores de los registros.

Este comando devuelve 0 en caso de éxito, otro valor en caso de fallo.
