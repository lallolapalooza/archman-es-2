NOMBRE

kubeadm kubeconfig user - Genera un archivo kubeconfig para un usuario adicional

SINOPSIS

kubeadm kubeconfig user [OPCIONES]

DESCRIPCIÓN

Genera un archivo kubeconfig para un usuario adicional.

OPCIONES

--client-name="" El nombre del usuario. Se usará como CN si se crean certificados de cliente

--config="" Ruta a un archivo de configuración de kubeadm.

--org=[] Las organizaciones del certificado de cliente. Se usarán como O si se crean certificados de cliente

--token="" El token que se utilizará como mecanismo de autenticación para este kubeconfig, en lugar de certificados de cliente

--validity-period=8760h0m0s El período de validez del certificado de cliente. Es un desfase desde el momento actual.

OPCIONES HEREDADAS DE COMANDOS PADRE

--rootfs="" La ruta al sistema de archivos raíz 'real' del host. Esto hará que kubeadm use chroot en la ruta proporcionada.

--version=false --version, --version=raw imprime información de versión y sale; --version=vX.Y.Z... establece la versión reportada

EJEMPLO

  # Genera un archivo kubeconfig para un usuario adicional llamado foo
  kubeadm kubeconfig user --client-name=foo
  # Genera un archivo kubeconfig para un usuario adicional llamado foo usando un archivo de configuración de kubeadm llamado bar
  kubeadm kubeconfig user --client-name=foo --config=bar
