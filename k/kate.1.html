KATE(1) Manual de usuario de Kate KATE(1)

NOMBRE

kate - Editor de texto avanzado de KDE

SINOPSIS

kate [-s, --start nombre] [--startanon] [-n, --new] [-b, --block] [-p, --pid pid] [-e, --encoding nombre] [-l, --line línea] [-c, --column columna] [-i, --stdin] [--tempfile] [archivo]

DESCRIPCIÓN

Kate es el Editor de Texto Avanzado de KDE.

Kate también proporciona la parte del editor para varias aplicaciones, bajo el nombre KWrite.

Algunas de las muchas características de Kate incluyen resaltado de sintaxis configurable para lenguajes que van desde C y C++ hasta HTML y scripts de bash, la capacidad de crear y mantener proyectos, una interfaz de múltiples documentos (MDI) y un emulador de terminal autónomo.

Pero Kate es más que un editor de programadores. Su capacidad para abrir varios archivos a la vez lo hace ideal para editar los muchos archivos de configuración de UNIX®. Este documento fue escrito en Kate.

OPCIONES

-s, --start nombre

Inicia Kate con una sesión dada.

--startanon

Inicia Kate con una nueva sesión anónima, implica -n.

-n, --new

Forzar el inicio de una nueva instancia de Kate (se ignora si se utiliza start y otra instancia de Kate ya tiene la sesión dada abierta), forzado si no se dan parámetros ni URLs.

-b, --block

Si se utiliza una instancia de Kate ya en ejecución, bloquear hasta que se cierre, si se dan URLs para abrir.

-p, --pid pid

Intentar reutilizar solo la instancia de kate con este pid (se ignora si se utiliza start y otra instancia de Kate ya tiene la sesión dada abierta).

-e, --encoding nombre

Establecer la codificación para el archivo a abrir.

Puede usar esto para forzar que un archivo se abra en formato utf-8, por ejemplo. (El comando iconv -l proporciona una lista de codificaciones, que puede ser útil).

-l, --line línea

Navegar a esta línea.

-c, --column columna

Navegar a esta columna.

-i, --stdin

Leer el contenido de la entrada estándar.

--tempfile

Los archivos/URLs abiertos por la aplicación se eliminarán después de su uso.

archivo

Archivo a abrir.

EJEMPLOS

Para abrir un archivo llamado source.cpp en la columna 15, línea 25, en una ventana de Kate existente, puede usar:

kate -c 15 -l 25 source.cpp

Si tiene una conexión a Internet activa, puede aprovechar la transparencia de red de KDE para abrir un archivo desde un sitio FTP. Si no tiene permisos de escritura en el servidor remoto, el archivo se abrirá como solo lectura y se le pedirá un nombre de archivo local para guardar si realiza cambios. Si tiene permisos de escritura, los cambios se guardarán de forma transparente a través de la red.

kate ftp://ftp.kde.org/pub/kde/README
