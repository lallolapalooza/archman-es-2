Nombre

kitten-@-focus-tab - Enfocar la pestaña especificada

Uso

kitten @ focus-tab

Descripción

Se enfocará la ventana activa en la pestaña especificada.

Opciones

--match, -m
La pestaña a coincidir. Las especificaciones de coincidencia son de la forma: campo:consulta. Donde campo puede ser uno de: id, index, title, window_id, window_title, pid, cwd, cmdline env, var, state, session y recent. consulta es la expresión a coincidir. Las expresiones pueden ser un número o una expresión regular, y pueden combinarse usando operadores booleanos.

El valor especial all coincide con todas las pestañas.

Para campos numéricos: id, index, window_id, pid y recent, la expresión se interpreta como un número, no como una expresión regular. Los valores negativos para id/window_id coinciden desde el número de id más alto hacia abajo, en particular, -1 es la pestaña/ventana creada más recientemente.

Al usar title o id, primero se busca una pestaña coincidente y, si no se encuentra, se busca una ventana coincidente, y se utiliza la pestaña de esa ventana.

También puede usar window_id y window_title para coincidir con la pestaña que contiene la ventana con el id o título especificado.

El número de índice se utiliza para coincidir con la enésima pestaña en la ventana del sistema operativo activa actualmente. El número recent coincide con las pestañas activadas recientemente en la ventana del sistema operativo activa actualmente, siendo cero la pestaña activa actualmente, uno la pestaña activada previamente y así sucesivamente.

El campo session coincide con las pestañas que se crearon en la sesión especificada. Use la expresión ^$ para coincidir con ventanas que no se crearon en una sesión y . para coincidir con la sesión activa actualmente y ~ para coincidir con la sesión activa actualmente o la última sesión activa cuando no hay ninguna sesión activa.

Al usar el campo env para coincidir con variables de entorno, puede especificar solo el nombre de la variable de entorno o un nombre y valor, por ejemplo, env:MY_ENV_VAR=2. Coinciden las pestañas que contienen cualquier ventana con las variables de entorno especificadas. De manera similar, var coincide con las pestañas que contienen cualquier ventana con las variables de usuario especificadas.

El campo state coincide con el estado de la pestaña. Los estados admitidos son: active, focused, needs_attention, parent_active, parent_focused y focused_os_window. Las pestañas activas son las pestañas que están activas en su ventana del sistema operativo principal. Solo hay una pestaña enfocada y es la pestaña a la que se entregan los eventos del teclado. Si no hay ninguna pestaña enfocada, se coincide con la última pestaña enfocada. El valor focused_os_window coincide con todas las pestañas en la ventana del sistema operativo enfocada actualmente.

Tenga en cuenta que puede usar el comando kitten @ ls para obtener una lista de pestañas.

--no-response [=no]
No espere una respuesta que indique el éxito de la acción. Tenga en cuenta que utilizar esta opción significa que no se le notificará de los fallos.
--help, -h [=no]
Mostrar ayuda para este comando

Opciones globales

--to
Una dirección para la instancia de kitty a controlar. Corresponde a la dirección proporcionada a la instancia de kitty a través de la opción --listen-on o la configuración listen_on en kitty.conf. Si no se especifica, se comprueba la variable de entorno KITTY_LISTEN_ON. Si tampoco se encuentra, los mensajes se envían a la terminal de control para este proceso, es decir, solo funcionarán si este proceso se ejecuta dentro de una ventana de kitty.
--password
Una contraseña para usar al contactar a kitty. Esto hará que kitty solicite al usuario permiso para realizar la acción especificada, a menos que la contraseña se haya aceptado antes o esté preconfigurada en kitty.conf. Para usar una contraseña en blanco, especifique --use-password como siempre.
--password-file [=rc-pass]
Un archivo del cual leer la contraseña. Los espacios en blanco finales se ignoran. Las rutas relativas se resuelven desde el directorio de configuración de kitty. Usa - para leer desde STDIN. Usa fd:num para leer desde el descriptor de archivo num. Se utiliza si no se proporciona --password. Por defecto, se comprueba el archivo rc-pass en el directorio de configuración de kitty.
--password-env [=KITTY_RC_PASSWORD]
El nombre de una variable de entorno desde la cual leer la contraseña. Se utiliza si no se proporciona --password-file. Por defecto, se comprueba la variable de entorno KITTY_RC_PASSWORD.
--use-password [=if-available]
Si no hay contraseña disponible, kitty normalmente enviará el comando de control remoto sin contraseña. Esta opción se puede usar para forzarlo a usar siempre o nunca la contraseña proporcionada. Si se establece en always y no se proporciona contraseña, se utiliza la contraseña en blanco.

Opciones: if-available, always, never
