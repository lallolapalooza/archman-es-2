NOMBRE

knock - cliente de port-knock

SINOPSIS

knock [opciones] <host> <puerto[:proto]> [puerto[:proto]] ...

DESCRIPCIÓN

knock es un cliente de port-knock. Envía paquetes TCP/UDP a cada puerto especificado en el host, creando una secuencia de knock especial en el servidor que escucha (ver la página del manual de knockd para más información sobre esto).

OPCIONES

-u, --udp
Hace que todos los golpes de puerto utilicen UDP (el valor predeterminado es TCP). Si desea que cada puerto utilice un protocolo diferente (TCP o UDP), puede especificar el protocolo en cada puerto. Ver el ejemplo a continuación.
-d <t>, --delay <t>
Espera <t> milisegundos entre cada golpe de puerto. Esto se puede utilizar en situaciones donde un enrutador confunde su flujo de paquetes SYN como un escaneo de puertos y los bloquea. Si la velocidad del paquete se reduce con --delay, entonces el enrutador debería dejar pasar los paquetes.
-4, --ipv4 <version>
Fuerza el uso de IPv4.
-6, --ipv6 <version>
Fuerza el uso de IPv6.
-v, --verbose
Muestra mensajes de estado detallados.
-V, --version
Muestra la versión.
-h, --help
Ayuda de sintaxis.

EJEMPLOS

knock myserver.example.com 123:tcp 456:udp 789:tcp
knock -u myserver.example.com 8284 4721 18592 42912

VER TAMBIÉN

knockd es el servidor de port-knock que lo acompaña.
