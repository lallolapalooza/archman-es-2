NOMBRE

kubectl scale - Establecer un nuevo tamaño para un despliegue, conjunto de réplicas o controlador de replicación

SINOPSIS

kubectl scale [OPCIONES]

DESCRIPCIÓN

Establece un nuevo tamaño para un despliegue, conjunto de réplicas, controlador de replicación o conjunto de estado.

Scale también permite a los usuarios especificar una o más precondiciones para la acción de escalado.

Si se especifica --current-replicas o --resource-version, se valida antes de intentar el escalado, y se garantiza que la precondición se cumpla cuando se envíe el escalado al servidor.

OPCIONES

--all=false Seleccionar todos los recursos en el espacio de nombres de los tipos de recursos especificados

--allow-missing-template-keys=true Si es verdadero, ignorar cualquier error en las plantillas cuando falta un campo o una clave de mapa en la plantilla. Solo se aplica a los formatos de salida golang y jsonpath.

--current-replicas=-1 Precondición para el tamaño actual. Requiere que el tamaño actual del recurso coincida con este valor para poder escalar. -1 (por defecto) para ninguna condición.

--dry-run="none" Debe ser "none", "server", o "client". Si es estrategia de cliente, solo imprime el objeto que se enviaría, sin enviarlo. Si es estrategia de servidor, envía una solicitud del lado del servidor sin persistir el recurso.

-f, --filename=[] Nombre de archivo, directorio o URL a archivos que identifican el recurso para establecer un nuevo tamaño

-k, --kustomize="" Procesa el directorio de kustomization. Esta bandera no se puede usar junto con -f o -R.

-o, --output="" Formato de salida. Uno de: (json, yaml, name, go-template, go-template-file, template, templatefile, jsonpath, jsonpath-as-json, jsonpath-file).

--record=false Registra el comando kubectl actual en la anotación del recurso. Si se establece en falso, no registra el comando. Si se establece en verdadero, registra el comando. Si no se establece, por defecto actualiza el valor de la anotación existente solo si ya existe.

-R, --recursive=false Procesa el directorio utilizado en -f, --filename recursivamente. Útil cuando desea administrar manifiestos relacionados organizados dentro del mismo directorio.

--replicas=0 El nuevo número deseado de réplicas. Requerido.

--resource-version="" Precondición para la versión del recurso. Requiere que la versión actual del recurso coincida con este valor para poder escalar.

-l, --selector="" Selector (consulta de etiquetas) para filtrar, soporta '=', '==', '!=', 'in', 'notin'. (ej. -l key1=value1,key2=value2,key3 in (value3)). Los objetos coincidentes deben cumplir todas las restricciones de etiquetas especificadas.

--show-managed-fields=false Si es verdadero, mantén los managedFields al imprimir objetos en formato JSON o YAML.

--template="" Cadena de plantilla o ruta a archivo de plantilla a usar cuando -o=go-template, -o=go-template-file. El formato de plantilla es plantillas de Go [http://golang.org/pkg/text/template/#pkg-overview].

--timeout=0s La duración antes de rendirse en una operación de escalado, cero significa no esperar. Cualquier otro valor debe contener una unidad de tiempo correspondiente (ej. 1s, 2m, 3h).

OPCIONES HEREDADAS DE COMANDOS PADRE

--as="" Nombre de usuario a suplantar para la operación. El usuario podría ser un usuario regular o una cuenta de servicio en un espacio de nombres.

--as-group=[] Grupo a suplantar para la operación, esta bandera se puede repetir para especificar múltiples grupos.

--as-uid="" UID a suplantar para la operación.

--cache-dir="/home/username/.kube/cache" Directorio de caché predeterminado

--certificate-authority="" Ruta a un archivo de certificado para la autoridad de certificación

--client-certificate="" Ruta a un archivo de certificado de cliente para TLS

--client-key="" Ruta a un archivo de clave de cliente para TLS

--cluster="" El nombre del clúster de kubeconfig a usar

--context="" El nombre del contexto de kubeconfig a usar

--disable-compression=false Si es verdadero, desactiva la compresión de respuesta para todas las solicitudes al servidor

--insecure-skip-tls-verify=false Si es verdadero, el certificado del servidor no se verificará en cuanto a su validez. Esto hará que sus conexiones HTTPS no sean seguras.

--kubeconfig="" Ruta al archivo kubeconfig a usar para las solicitudes CLI.

--kuberc="" Ruta al archivo kuberc a usar para las preferencias. Esto se puede deshabilitar exportando el feature gate KUBECTL_KUBERC=false o desactivando el feature KUBERC=off.

--match-server-version=false Requiere que la versión del servidor coincida con la versión del cliente

-n, --namespace="" Si está presente, el ámbito del espacio de nombres para esta solicitud CLI

--password="" Contraseña para autenticación básica al servidor API

--profile="none" Nombre del perfil a capturar. Uno de (none|cpu|heap|goroutine|threadcreate|block|mutex)

--profile-output="profile.pprof" Nombre del archivo donde escribir el perfil

--request-timeout="0" La duración antes de rendirse en una única solicitud al servidor. Los valores distintos de cero deben contener una unidad de tiempo correspondiente (ej. 1s, 2m, 3h). Un valor de cero significa no agotar el tiempo de espera de las solicitudes.

-s, --server="" La dirección y el puerto del servidor API de Kubernetes

--tls-server-name="" Nombre del servidor a usar para la validación del certificado del servidor. Si no se proporciona, se usa el nombre de host utilizado para contactar al servidor.

--token="" Token Bearer para autenticación al servidor API

--user="" El nombre del usuario de kubeconfig a usar

--username="" Nombre de usuario para autenticación básica al servidor API

--version=false --version, --version=raw imprime información de la versión y sale; --version=vX.Y.Z... establece la versión reportada

--warnings-as-errors=false Tratar las advertencias recibidas del servidor como errores y salir con un código de salida distinto de cero

EJEMPLO

  # Escalar un conjunto de réplicas llamado 'foo' a 3
  kubectl scale --replicas=3 rs/foo
  # Escalar un recurso identificado por tipo y nombre especificado en "foo.yaml" a 3
  kubectl scale --replicas=3 -f foo.yaml
  # Si el tamaño actual del despliegue llamado mysql es 2, escalar mysql a 3
  kubectl scale --current-replicas=2 --replicas=3 deployment/mysql
  # Escalar múltiples controladores de replicación
  kubectl scale --replicas=5 rc/example1 rc/example2 rc/example3
  # Escalar el conjunto de estado llamado 'web' a 3
  kubectl scale --replicas=3 statefulset/web
