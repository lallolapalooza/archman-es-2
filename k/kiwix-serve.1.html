NOMBRE

kiwix-serve - Servidor HTTP de Kiwix

SINOPSIS

kiwix-serve --library [OPCIONES] RUTA_ARCHIVO_BIBLIOTECA
kiwix-serve [OPCIONES] RUTA_ARCHIVO_ZIM ...

DESCRIPCIÓN

El comando kiwix-serve se utiliza para ejecutar un servidor HTTP autónomo para servir contenido ZIM a través de la red.

ARGUMENTOS

RUTA_ARCHIVO_BIBLIOTECA
Ruta de un archivo XML de biblioteca que lista los archivos ZIM a servir. Se utilizará solo con la opción --library. Se pueden proporcionar varios archivos de biblioteca como una lista separada por punto y coma (;).
RUTA_ARCHIVO_ZIM ...
Ruta(s) de archivo(s) ZIM. Se permiten varios argumentos.

OPCIONES

--library
Por defecto, kiwix-serve espera una lista de archivos ZIM como argumentos de línea de comandos. Al proporcionar la opción --library, se le indica a kiwix-serve que el argumento de la línea de comandos es en realidad un archivo XML de biblioteca.
-i DIRECCION, --address=DIRECCION
Escuchar solo en esta dirección IP. Por defecto, el servidor escucha en todas las direcciones IP disponibles. Alternativamente, puede usar valores especiales para definir qué tipos de conexiones aceptar:

all : Escuchar conexiones en todas las direcciones IP (IPv4 e IPv6).
ipv4 : Escuchar conexiones en todas las direcciones IPv4.
ipv6 : Escuchar conexiones en todas las direcciones IPv6.

-p PUERTO, --port=PUERTO
Puerto TCP en el que escuchar las solicitudes HTTP (por defecto: 80).
-r RAIZ, --urlRootLocation=RAIZ
Prefijo de URL en el que estará disponible el contenido (por defecto: vacío).
-d, --daemon
Separar el demonio del servidor HTTP del proceso principal.
-a PID, --attachToProcess=PID
Salir cuando el proceso con el ID PID deje de ejecutarse.
-M, --monitorLibrary
Monitorizar el archivo XML de la biblioteca y recargarlo automáticamente cuando cambie.

La recarga de la biblioteca se puede forzar en cualquier momento enviando una señal SIGHUP al proceso “kiwix-serve” (esto funciona independientemente de la presencia de la opción “--monitorLibrary”/“-M”).

-m, --nolibrarybutton
Desactivar el botón de inicio de la biblioteca en la barra de herramientas del visor ZIM.
-n, --nosearchbar
Desactivar el cuadro de búsqueda en la barra de herramientas del visor ZIM.
-b, --blockexternal
Evitar que los usuarios naveguen directamente a recursos externos a través de enlaces en el contenido ZIM.
-t N, --threads=N
Número de hilos a ejecutar en paralelo (por defecto: 4).
-s N, --searchLimit=N
Número máximo de archivos ZIM en una búsqueda multizim de texto completo (por defecto: sin límite).
-z, --nodatealiases
Crear alias de URL para cada contenido eliminando la fecha incrustada en el nombre del archivo.

El formato esperado de la fecha en el nombre del archivo es “_AAAA-MM”. Por ejemplo, un archivo ZIM llamado “wikipedia_en_all_2020-08.zim” será accesible tanto como “wikipedia_en_all_2020-08” como “wikipedia_en_all”.

-c RUTA, --customIndex=RUTA
Sobrescribir la página de bienvenida con un archivo HTML personalizado.
-L N, --ipConnectionLimit=N
Número máximo de conexiones (concurrentes) por IP (por defecto: infinito, recomendado: >= 6).
-k, --skipInvalid
Iniciar incluso cuando los archivos ZIM no son válidos (serán omitidos)
-v, --verbose
Imprimir el registro de depuración en STDOUT.
-V, --version
Imprimir la versión del software.
-h, --help
Imprimir un mensaje de ayuda.

EJEMPLOS

Servir un único archivo ZIM:

kiwix-serve mi_archivo.zim

Servir múltiples archivos ZIM:

kiwix-serve archivo1.zim archivo2.zim archivo3.zim

Servir archivos ZIM desde una biblioteca:

kiwix-serve --library biblioteca.xml
