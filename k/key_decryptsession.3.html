key_decryptsession(3) Manual de funciones de biblioteca key_decryptsession(3)

NOMBRE

key_decryptsession, key_encryptsession, key_setsecret, key_gendes, key_secretkey_is_set - interfaces con el demonio keyserver de rpc

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <rpc/rpc.h>
int key_decryptsession(char *remotename, des_block *deskey);
int key_encryptsession(char *remotename, des_block *deskey);
int key_gendes(des_block *deskey);
int key_setsecret(char *key);
int key_secretkey_is_set(void);

DESCRIPCIÓN

Las funciones aquí se utilizan dentro del mecanismo de autenticación segura de RPC (AUTH_DES). Los programas de usuario no deberían necesitar usar estas funciones.

La función key_decryptsession() utiliza el nombre de red del servidor (remoto) y toma la clave DES para descifrar. Utiliza la clave pública del servidor y la clave secreta asociada con el UID efectivo del proceso que llama.

La función key_encryptsession() es la inversa de key_decryptsession(). Cifra las claves DES con la clave pública del servidor y la clave secreta asociada con el UID efectivo del proceso que llama.

La función key_gendes() se utiliza para solicitar al keyserver una clave de conversación segura.

La función key_setsecret() se utiliza para establecer la clave para el UID efectivo del proceso que llama.

La función key_secretkey_is_set() se puede utilizar para determinar si se ha establecido una clave para el UID efectivo del proceso que llama.

VALOR DE RETORNO

Estas funciones devuelven 1 si tienen éxito y 0 si fallan.

ATRIBUTOS

Para una explicación de los términos utilizados en esta sección, consulte attributes(7).

Interfaz Atributo Valor
key_decryptsession (), key_encryptsession (), key_gendes (), key_setsecret (), key_secretkey_is_set () Seguridad de hilos MT-Safe

NOTAS

Tenga en cuenta que aquí hablamos de dos tipos de cifrado. Uno es asimétrico, utilizando una clave pública y secreta. El otro es simétrico, el DES de 64 bits.

Estas rutinas formaban parte del proyecto Linux/Doors, ahora abandonado.
