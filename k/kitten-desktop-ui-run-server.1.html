Nombre

kitten-desktop-ui-run-server - Iniciar los diversos servidores utilizados para integrarse con el escritorio de Linux

Uso

kitten desktop-ui run-server

Descripción

Esto debe ejecutarse muy temprano en la secuencia de inicio de su gestor de ventanas, antes de que se ejecuten otros programas.

Opciones

--override, -o
Sobrescribir opciones de configuración individuales, se puede especificar varias veces. Sintaxis: nombre=valor. Por ejemplo: -o color_scheme=dark
--config, -c
Especificar una ruta a los archivos de configuración a utilizar. Todos los archivos de configuración se fusionan con el archivo incorporado desktop-ui-portal.conf, sobrescribiendo los valores incorporados. Esta opción se puede especificar varias veces para leer varios archivos de configuración en secuencia, los cuales se fusionan. Utilice el valor especial NONE para no cargar ningún archivo de configuración.

Si esta opción no se especifica, los archivos de configuración se buscan en el orden: $XDG_CONFIG_HOME/kitty/desktop-ui-portal.conf, ~/.config/kitty/desktop-ui-portal.conf, $XDG_CONFIG_DIRS/kitty/desktop-ui-portal.conf. El primero que exista se utiliza como archivo de configuración.

Si la variable de entorno KITTY_CONFIG_DIRECTORY se especifica, ese directorio se utiliza siempre y la búsqueda anterior no ocurre.

Si /etc/xdg/kitty/desktop-ui-portal.conf existe, se fusiona antes (es decir, con menor prioridad) que cualquier archivo de configuración de usuario. Se puede utilizar para especificar valores predeterminados a nivel de sistema para todos los usuarios. Puede usar - o /dev/stdin para leer la configuración desde STDIN.
