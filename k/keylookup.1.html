NOMBRE

keylookup - Obtener e importar claves GnuPG de servidores de claves.

SINOPSIS

keylookup [opciones] cadena-de-búsqueda

DESCRIPCIÓN

keylookup es un envoltorio para gpg --search, que te permite buscar claves en un servidor de claves. Presenta la lista de claves coincidentes al usuario y le permite seleccionar las claves para importarlas al keyring de GnuPG.

Para la búsqueda e importación real de claves, se llama al propio GnuPG.

OPCIONES

--keyserver=servidor-de-claves
Especifica el servidor de claves a utilizar. Si no se especifica ningún servidor de claves, analizará el archivo de opciones de GnuPG en busca de un servidor de claves predeterminado. Si no se encuentra ningún servidor de claves, keylookup se abortará.
--port=puerto
Utiliza un puerto diferente a 11371.
--frontend=interfaz
keylookup admite la visualización de los resultados de la búsqueda con 3 interfaces diferentes. Tanto whiptail como dialog son interactivas y permiten al usuario seleccionar las claves a importar. La tercera interfaz, plain, no es interactiva y simplemente imprime las claves en STDOUT. El usuario deberá llamar a GnuPG por sí mismo.

Si está disponible, /usr/bin/dialog es el predeterminado. Si no está disponible pero /usr/bin/whiptail está instalado, se utilizará este en su lugar. Si nada más funciona, se recurrirá a plain.

--importall
No preguntes al usuario qué claves importar, sino que importa todas las claves que coincidan con la cadena-de-búsqueda. Si se utiliza esta opción, no se necesita ninguna interfaz.
--honor-http-proxy
De manera similar a GnuP, keylookup solo respetará la variable de entorno http_proxy si se proporciona esta opción. Si no se proporciona, pero el archivo de opciones de GnuPG la incluye, entonces keylookup la utilizará.
--help
Imprime un breve mensaje de ayuda y sale con éxito.

ENTORNO

HOME
Se utiliza para localizar el directorio de inicio predeterminado.
GNUPGHOME
Si está configurado, se utiliza el directorio en lugar de "~/.gnupg".
GNUPGBIN
Si está configurado, se utiliza como binario de gpg en lugar de "gpg".
http_proxy
Solo se respeta cuando la opción --honor-http-proxy está configurada o honor-http-proxy está configurada en el archivo de configuración de GnuPG.

EJEMPLOS

keylookup Christian Kurz
consultará su servidor de claves predeterminado para las claves de Christian y le ofrecerá importarlas a su keyring con la interfaz de diálogo (si está disponible).
keylookup --honor-http-proxy --frontend plain wk@gnupg
consultará el servidor de claves predeterminado de nuevo, ahora utilizando http_proxy si la variable de entorno está definida, y listará la clave de wk@gnupg (Werner Koch) en STDOUT.
keylookup --keyserver pgp.mit.edu Peter Palfrader
consultará ahora al servidor de claves pgp.mit.edu por mis claves (de Peter) y las mostrará para importarlas en diálogo.

FICHEROS

~/.gnupg/options
Archivo de opciones de GnuPG donde keylookup tomará los valores de servidor de claves y honor-http-proxy si existe.
