NOMBRE

kubectl api-resources - Imprime los recursos de API compatibles en el servidor

SINOPSIS

kubectl api-resources [OPCIONES]

DESCRIPCIÓN

Imprime los recursos de API compatibles en el servidor.

OPCIONES

--api-group="" Limita a recursos en el grupo de API especificado.

--cached=false Usa la lista de recursos en caché si está disponible.

--categories=[] Limita a recursos que pertenecen a las categorías especificadas.

--namespaced=true Si es falso, se devolverán recursos no nombrados (sin namespace), de lo contrario, se devolverán recursos nombrados por defecto.

--no-headers=false Al usar el formato de salida por defecto o de columna personalizada, no imprimas encabezados (imprime encabezados por defecto).

-o, --output="" Formato de salida. Uno de: (json, yaml, name, wide).

--show-managed-fields=false Si es verdadero, mantén los managedFields al imprimir objetos en formato JSON o YAML.

--sort-by="" Si no está vacío, ordena la lista de recursos usando el campo especificado. El campo puede ser 'name' o 'kind'.

--verbs=[] Limita a recursos que admiten los verbos especificados.

OPCIONES HEREDADAS DE COMANDOS PADRE

--as="" Nombre de usuario a suplantar para la operación. El usuario podría ser un usuario normal o una cuenta de servicio en un namespace.

--as-group=[] Grupo a suplantar para la operación, este flag puede repetirse para especificar múltiples grupos.

--as-uid="" UID a suplantar para la operación.

--cache-dir="/home/username/.kube/cache" Directorio de caché por defecto

--certificate-authority="" Ruta a un archivo de certificado para la autoridad certificadora

--client-certificate="" Ruta a un archivo de certificado de cliente para TLS

--client-key="" Ruta a un archivo de clave de cliente para TLS

--cluster="" El nombre del clúster de kubeconfig a utilizar

--context="" El nombre del contexto de kubeconfig a utilizar

--disable-compression=false Si es verdadero, opta por no comprimir las respuestas para todas las solicitudes al servidor

--insecure-skip-tls-verify=false Si es verdadero, el certificado del servidor no se verificará su validez. Esto hará que tus conexiones HTTPS no sean seguras

--kubeconfig="" Ruta al archivo kubeconfig a utilizar para las solicitudes de la CLI.

--kuberc="" Ruta al archivo kuberc a utilizar para preferencias. Esto puede ser deshabilitado exportando la puerta de enlace de funciones KUBECTL_KUBERC=false o desactivando la función KUBERC=off.

--match-server-version=false Requerir que la versión del servidor coincida con la versión del cliente

-n, --namespace="" Si está presente, el ámbito del namespace para esta solicitud de CLI

--password="" Contraseña para autenticación básica al servidor API

--profile="none" Nombre del perfil a capturar. Uno de (none|cpu|heap|goroutine|threadcreate|block|mutex)

--profile-output="profile.pprof" Nombre del archivo donde escribir el perfil

--request-timeout="0" El tiempo de espera antes de rendirse en una única solicitud al servidor. Los valores distintos de cero deben contener una unidad de tiempo correspondiente (por ejemplo, 1s, 2m, 3h). Un valor de cero significa no esperar tiempo de espera en las solicitudes.

-s, --server="" La dirección y el puerto del servidor API de Kubernetes

--tls-server-name="" Nombre del servidor a utilizar para la validación del certificado del servidor. Si no se proporciona, se utiliza el nombre de host utilizado para contactar al servidor

--token="" Token Bearer para la autenticación al servidor API

--user="" El nombre del usuario de kubeconfig a utilizar

--username="" Nombre de usuario para autenticación básica al servidor API

--version=false --version, --version=raw imprime información de versión y sale; --version=vX.Y.Z... establece la versión informada

--warnings-as-errors=false Trata las advertencias recibidas del servidor como errores y sal con un código de salida distinto de cero

EJEMPLO

  # Imprime los recursos de API compatibles
  kubectl api-resources
  # Imprime los recursos de API compatibles con más información
  kubectl api-resources -o wide
  # Imprime los recursos de API compatibles ordenados por una columna
  kubectl api-resources --sort-by=name
  # Imprime los recursos nombrados compatibles
  kubectl api-resources --namespaced=true
  # Imprime los recursos no nombrados compatibles
  kubectl api-resources --namespaced=false
  # Imprime los recursos de API compatibles con un APIGroup específico
  kubectl api-resources --api-group=rbac.authorization.k8s.io
