Nombre

kitten-@-set-font-size - Establece el tamaño de la fuente en la ventana principal activa del sistema operativo

Uso

kitten @ set-font-size TAMAÑO_FUENTE

Descripción

Establece el tamaño de la fuente al tamaño especificado, en pts. Tenga en cuenta que en kitty todas las subventanas en la misma ventana del sistema operativo deben tener el mismo tamaño de fuente. Un valor de cero restablece el tamaño de la fuente al predeterminado. Prefijar el valor con +, -, * o / cambia el tamaño de la fuente en la cantidad especificada. Use -- antes de usar - para evitar que se confunda con una opción. Por ejemplo: kitten @ set-font-size -- -2

Opciones

--all, -a [=no]
Por defecto, el tamaño de la fuente solo se cambia en la ventana activa del sistema operativo, esta opción hará que se cambie en todas las ventanas del sistema operativo. También cambia el tamaño de la fuente para cualquier ventana del sistema operativo recién creada en el futuro.
--help, -h [=no]
Muestra la ayuda para este comando

Opciones globales

--to
Una dirección para la instancia de kitty a controlar. Corresponde a la dirección dada a la instancia de kitty a través de la opción --listen-on o la configuración listen_on en kitty.conf. Si no se especifica, se verifica la variable de entorno KITTY_LISTEN_ON. Si tampoco se encuentra, los mensajes se envían a la terminal de control para este proceso, es decir, solo funcionarán si este proceso se ejecuta dentro de una ventana de kitty.
--password
Una contraseña para usar al contactar a kitty. Esto hará que kitty solicite al usuario permiso para realizar la acción especificada, a menos que la contraseña haya sido aceptada antes o esté preconfigurada en kitty.conf. Para usar una contraseña en blanco, especifique --use-password como siempre.
--password-file [=rc-pass]
Un archivo del cual leer la contraseña. Los espacios en blanco al final se ignoran. Las rutas relativas se resuelven desde el directorio de configuración de kitty. Use - para leer desde STDIN. Use fd:num para leer desde el descriptor de archivo num. Se usa si no se proporciona --password. Por defecto, verifica el archivo rc-pass en el directorio de configuración de kitty.
--password-env [=KITTY_RC_PASSWORD]
El nombre de una variable de entorno de la cual leer la contraseña. Se usa si no se proporciona --password-file. Por defecto, verifica la variable de entorno KITTY_RC_PASSWORD.
--use-password [=if-available]
Si no hay contraseña disponible, kitty generalmente enviará el comando de control remoto sin contraseña. Esta opción se puede usar para forzar el uso o no uso de la contraseña proporcionada. Si se establece en siempre y no se proporciona contraseña, se usa la contraseña en blanco.

Opciones: if-available, always, never
