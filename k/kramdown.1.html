KRAMDOWN(1) Manual de comandos generales KRAMDOWN(1)

NOMBRE

kramdown - un conversor rápido y puro de Ruby a un superconjunto de Markdown

SINOPSIS

kramdown [opciones] [ARCHIVO...]

DESCRIPCIÓN

kramdown se utiliza principalmente para analizar un superconjunto de Markdown y convertirlo a diferentes formatos de salida. Soporta Markdown estándar (con algunas modificaciones menores) y varias extensiones como tablas y listas de definición. Debido a su arquitectura modular, también permite formatos de entrada distintos a Markdown, por ejemplo, HTML o Github Flavored Markdown.

Si no se especifica ARCHIVO, kramdown lee de la entrada estándar. El resultado se escribe en la salida estándar.

Hay dos conjuntos de opciones que kramdown acepta: El primero incluye las opciones que son utilizadas directamente por el binario de kramdown. El segundo conjunto de opciones controla cómo kramdown analiza y convierte su entrada.

Los valores predeterminados para este segundo conjunto se pueden establecer usando YAML a través del archivo de configuración kramdownrc. Tenga en cuenta que los nombres de las opciones de configuración usan guiones bajos, no guiones (los guiones solo se usan en los nombres de las opciones de la CLI), y las opciones booleanas no tienen una variante no, sino un valor de true o false. Este archivo debe estar en XDG_CONFIG_HOME en Linux/Unix, ~/Library/Preferences en macOS y ~/AppData/Local en Windows.

OPCIONES SOLO PARA CLI

-i FORMATO, --input FORMATO
Especificar el formato de entrada. Formatos de entrada disponibles: kramdown (este es el predeterminado), markdown, o html. El formato de entrada GFM está disponible a través del gem kramdown-parser-gfm.
-o FORMATO, --output FORMATO
Especificar uno o más formatos de salida separados por comas: html (predeterminado), kramdown, latex, man o remove_html_tags. El conversor pdf está disponible a través del gem kramdown-converter-pdf.
-x EXT, --extension EXT
Cargar una o más extensiones. El nombre de la extensión no debe incluir el prefijo kramdown-, por ejemplo, solo parser-gfm. Se pueden cargar múltiples extensiones separándolas con comas.

Nota: Esta opción debe usarse antes que cualquier otra opción que dependa de que la extensión ya esté cargada.

--no-config-file
No leer ningún archivo de configuración. El comportamiento predeterminado es verificar la existencia de un archivo de configuración y leerlo si existe.
--config-file ARCHIVO
Anular la ruta y el nombre predeterminados del archivo de configuración.
-v, --version
Mostrar la versión de kramdown.
-h, --help
Mostrar la ayuda.

OPCIONES DE KRAMDOWN

--auto-id-prefix ARG
Prefijo utilizado para las ID de encabezados generadas automáticamente

Esta opción se puede utilizar para establecer un prefijo para las ID de encabezados generadas automáticamente, de modo que no haya conflictos al renderizar múltiples documentos de kramdown en un único archivo de salida por separado. ¡El prefijo solo debe contener caracteres válidos en una ID!

Predeterminado: ‘’ Usado por: Conversor HTML/Latex

--[no-]auto-id-stripping
Eliminar todo el formato del texto del encabezado para la generación automática de ID

Si esta opción es true, solo los elementos de texto de un encabezado se utilizan para generar la ID más tarde (en contraste con solo usar la línea de texto bruta del encabezado).

Esta opción se eliminará en la versión 2.0, ya que será la predeterminada entonces.

Predeterminado: false Usado por: Analizador kramdown

--[no-]auto-ids
Usar generación automática de ID de encabezados

Si esta opción es true, los valores de ID para todos los encabezados se generan automáticamente si no se especifica explícitamente ninguna ID.

Predeterminado: true Usado por: Conversor HTML/Latex

--entity-output ARG
Define cómo se emiten las entidades

Los valores posibles son :as_input (las entidades se emiten en la misma forma que se encuentran en la entrada), :numeric (las entidades se emiten en forma numérica), :symbolic (las entidades se emiten en forma simbólica si es posible) o :as_char (las entidades se emiten como caracteres si es posible, solo disponible en Ruby 1.9).

Predeterminado: :as_char Usado por: Conversor HTML, conversor kramdown

--footnote-backlink ARG
Define el texto que debe usarse para los enlaces de retroceso de notas al pie

El enlace de retroceso de notas al pie es solo texto, por lo que los caracteres especiales de HTML se escaparán.

Si el texto del enlace de retroceso de notas al pie es una cadena vacía, no se generarán enlaces de retroceso de notas al pie.

Predeterminado: ‘&8617;’ Usado por: Conversor HTML

--[no-]footnote-backlink-inline
Especifica si el enlace de retroceso de notas al pie debe estar siempre en línea

Con el valor predeterminado de false, el enlace de retroceso de notas al pie se coloca al final del último párrafo si existe uno, o se crea un párrafo adicional solo con el enlace de retroceso de notas al pie.

Establecer esta opción en true intenta colocar el enlace de retroceso de notas al pie en el último párrafo o encabezado, posiblemente anidado. Si falla (por ejemplo, en el caso de una tabla), se crea un párrafo adicional solo con el enlace de retroceso de notas al pie.

Predeterminado: false Usado por: Conversor HTML

--footnote-nr ARG
El número del primer nota al pie

Esta opción se puede utilizar para especificar el número que se utiliza para la primera nota al pie.

Predeterminado: 1 Usado por: Conversor HTML

--footnote-prefix ARG
Prefijo utilizado para las ID de notas al pie

Esta opción se puede utilizar para establecer un prefijo para las ID de notas al pie. Esto es útil al renderizar múltiples documentos en el mismo archivo de salida para evitar ID duplicadas. ¡El prefijo solo debe contener caracteres válidos en una ID!

Predeterminado: ‘’ Usado por: HTML

--forbidden-inline-options ARG
Define las opciones que no se pueden establecer mediante la extensión {::options}

El valor debe ser una matriz de nombres de opciones.

Predeterminado: [template] Usado por: Conversor HTML

--header-offset ARG
Establece el desplazamiento de salida para los encabezados

Si esta opción es c (puede ser también negativa), entonces un encabezado con nivel n se emitirá como un encabezado con nivel c+n. Si c+n es menor que 1, se utilizará el nivel 1. Si c+n es mayor que 6, se utilizará el nivel 6.

Predeterminado: 0 Usado por: Conversor HTML, conversor Kramdown, conversor Latex

--[no-]html-to-native
Convertir elementos HTML a elementos nativos

Si esta opción es true, el analizador convierte los elementos HTML en elementos nativos. Por ejemplo, al analizar <em>hallo</em>, la etiqueta de énfasis normalmente se convertiría en un elemento :html con tipo de etiqueta :em. Si html_to_native es true, entonces el énfasis se convertiría en un elemento :em nativo.

Esto es útil para conversores que no pueden manejar elementos HTML.

Predeterminado: false Usado por: Analizador kramdown

--latex-headers ARG
Define los comandos de LaTeX para diferentes niveles de encabezado

OPCIONES

Las opciones se pueden pasar a kramdown de varias formas:

  • -c, --constraint OPCION=VALOR
  • -o, --option OPCION=VALOR
  • --[no-]OPCION

Las opciones para los distintos conversores y parsers son descritas abajo.

OPCIONES DE KRAMDOWN

--header-levels ARG
Define los niveles que se usan para los encabezados

Los comandos para los niveles de encabezado uno a seis se pueden especificar separándolos con comas.

Por defecto: section,subsection,subsubsection,paragraph,subparagraph,subparagraph Usado por: convertidor Latex

--line-width ARG
Define el ancho de línea a utilizar al generar un documento

Por defecto: 72 Usado por: convertidor kramdown

--link-defs ARG
Predefine definiciones de enlaces

Esta opción se puede utilizar para predefinir definiciones de enlaces. El valor necesita ser un Hash donde las claves son los identificadores de enlace y los valores son Arrays de dos elementos con la URL del enlace y el título del enlace.

Si el valor es un String, debe contener un hash YAML válido y el hash debe seguir las directrices anteriores.

Por defecto: {} Usado por: parser kramdown

--list-indent ARG
Establece el número de espacios a utilizar para la indentación de listas

Por defecto: 2 Usado por: convertidor Kramdown

--math-engine ARG
Establece el motor de matemáticas

Especifica el motor de matemáticas que debe usarse para convertir bloques/spans de matemáticas. Si esta opción se establece en +nil+, no se usa ningún motor de matemáticas y los bloques/spans de matemáticas se generan tal cual.

Las opciones para el motor de matemáticas seleccionado se pueden establecer con la opción de configuración math_engine_opts.

Por defecto: mathjax Usado por: convertidor HTML

--math-engine-opts ARG
Establece las opciones del motor de matemáticas

Especifica las opciones para el motor de matemáticas establecido a través de la opción de configuración math_engine.

El valor necesita ser un hash con pares clave-valor que sean entendidos por el motor de matemáticas utilizado.

Por defecto: {} Usado por: convertidor HTML

--[no-]parse-block-html
Procesa la sintaxis de kramdown en etiquetas HTML de bloque

Si esta opción es true, el parser kramdown procesa el contenido de las etiquetas HTML de bloque como texto que contiene elementos de nivel de bloque. Dado que esto normalmente no se desea, el valor por defecto es false. Normalmente es mejor habilitar selectivamente el procesamiento de kramdown a través del atributo markdown.

Por defecto: false Usado por: parser kramdown

--[no-]parse-span-html
Procesa la sintaxis de kramdown en etiquetas HTML de span

Si esta opción es true, el parser kramdown procesa el contenido de las etiquetas HTML de span como texto que contiene elementos de nivel de span.

Por defecto: true Usado por: parser kramdown

--[no-]remove-block-html-tags
Elimina etiquetas HTML de bloque

Si esta opción es true, el convertidor RemoveHtmlTags elimina las etiquetas HTML de bloque.

Por defecto: true Usado por: convertidor RemoveHtmlTags

--[no-]remove-line-breaks-for-cjk
Especifica si los saltos de línea deben eliminarse entre caracteres CJK

Por defecto: false Usado por: convertidor HTML

--[no-]remove-span-html-tags
Elimina etiquetas HTML de span

Si esta opción es true, el convertidor RemoveHtmlTags elimina las etiquetas HTML de span.

Por defecto: false Usado por: convertidor RemoveHtmlTags

--smart-quotes ARG
Define los nombres de entidades HTML o puntos de código para la salida de comillas inteligentes

Las entidades identificadas por nombre de entidad o punto de código que deben usarse para, respectivamente, una comilla simple de apertura, una comilla simple de cierre, una comilla doble de apertura y una comilla doble de cierre se especifican separándolas con comas.

Por defecto: lsquo,rsquo,ldquo,rdquo Usado por: convertidor HTML/Latex

--syntax-highlighter ARG
Establece el resaltador de sintaxis

Especifica el resaltador de sintaxis que debe usarse para resaltar bloques y spans de código. Si esta opción se establece en +nil+, no se realiza ningún resaltado de sintaxis.

Las opciones para el resaltador de sintaxis se pueden establecer con la opción de configuración syntax_highlighter_opts.

Por defecto: rouge Usado por: convertidor HTML/Latex

--syntax-highlighter-opts ARG
Establece las opciones del resaltador de sintaxis

Especifica las opciones para el resaltador de sintaxis establecido a través de la opción de configuración syntax_highlighter.

El valor necesita ser un hash con pares clave-valor que sean entendidos por el resaltador de sintaxis utilizado.

Por defecto: {} Usado por: convertidor HTML/Latex

--template ARG
El nombre de un archivo de plantilla ERB que debe usarse para envolver la salida o la plantilla ERB en sí.

Esto se utiliza para envolver la salida en un entorno para que la salida pueda usarse como un documento independiente. Por ejemplo, una plantilla HTML proporcionaría las etiquetas de encabezado y cuerpo necesarias para que toda la salida sea un archivo HTML válido. Si no se especifica ninguna plantilla, la salida será solo el texto convertido.

Al resolver el archivo de plantilla, se usa primero el nombre de plantilla dado. Si no se encuentra dicho archivo, se agrega la extensión del convertidor (la misma que el nombre del convertidor). Si el archivo aún no se encuentra, el nombre de la plantilla se interpreta como un nombre de plantilla que proporciona kramdown (sin la extensión del convertidor). Si el archivo aún no se encuentra, se comprueba si el nombre de la plantilla comienza con 'string://' y, si es así, se elimina este prefijo y el resto se utiliza como contenido de la plantilla.

kramdown proporciona una plantilla predeterminada llamada 'document' para cada convertidor.

Por defecto: '' Usado por: todos los conversores

--toc-levels ARG
Define los niveles que se utilizan para la tabla de contenidos

Los niveles individuales se pueden especificar separándolos con comas (por ejemplo, 1,2,3) o utilizando la sintaxis de rango (por ejemplo, 1..3). Solo se utilizan los niveles especificados para la tabla de contenidos.

Por defecto: 1..6 Usado por: convertidor HTML/Latex

--[no-]transliterated-header-ids
Translitera el texto del encabezado antes de generar el ID

Solo se utilizan caracteres ASCII en los IDs de los encabezados. Esto no es bueno para idiomas con muchos caracteres no ASCII. Al habilitar esta opción, el texto del encabezado se translitera a ASCII lo mejor posible para que el ID del encabezado resultante sea más útil.

¡La biblioteca stringex debe estar instalada para que esta función funcione!

Por defecto: false Usado por: convertidor HTML/Latex

--typographic-symbols ARG
Define un mapeo de símbolo tipográfico a caracteres de salida

Los símbolos tipográficos normalmente se generan utilizando su punto de código Unicode equivalente. Sin embargo, a veces se quiere cambiar la salida, principalmente para recurrir a una secuencia de caracteres ASCII.

Esta opción lo permite especificando un mapeo de símbolo tipográfico a su cadena de salida. Por ejemplo, el mapeo {hellip: ...} generaría la representación ASCII estándar de una elipsis.

Los nombres de símbolos tipográficos disponibles son:

  • hellip: elipsis
  • mdash: raya (em dash)
  • ndash: semirraya (en dash)
  • laquo: comilla angular izquierda (guillemet)
  • raquo: comilla angular derecha (guillemet)
  • laquo_space: comilla angular izquierda seguida de un espacio
  • raquo_space: comilla angular derecha precedida de un espacio

Por defecto: {} Usado por: convertidor HTML/Latex

ESTADO DE SALIDA

El estado de salida es 0 si no ocurrió ningún error. De lo contrario, es 1.
