NOMBRE

kubeadm init phase certs apiserver-kubelet-client - Generar el certificado para que la API server se conecte a kubelet

SINÓPSIS

kubeadm init phase certs apiserver-kubelet-client [OPCIONES]

DESCRIPCIÓN

Genera el certificado para que la API server se conecte a kubelet, y los guarda en los archivos apiserver-kubelet-client.crt y apiserver-kubelet-client.key.

Si ambos archivos ya existen, kubeadm omite el paso de generación y se usarán los archivos existentes.

OPCIONES

--cert-dir="/etc/kubernetes/pki" La ruta donde guardar y almacenar los certificados.

--config="" Ruta a un archivo de configuración de kubeadm.

--dry-run=false No aplicar ningún cambio; solo mostrar lo que se haría.

--kubernetes-version="stable-1" Elegir una versión específica de Kubernetes para el plano de control.

OPCIONES HEREDADAS DE COMANDOS PADRE

--rootfs="" La ruta al sistema de archivos raíz 'real' del host. Esto hará que kubeadm haga chroot en la ruta proporcionada.

--version=false --version, --version=raw imprime la información de la versión y sale; --version=vX.Y.Z... establece la versión reportada
