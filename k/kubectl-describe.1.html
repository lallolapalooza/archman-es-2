NOMBRE

kubectl describe - Mostrar detalles de un recurso específico o grupo de recursos

SINOPSIS

kubectl describe [OPCIONES]

DESCRIPCIÓN

Muestra detalles de un recurso específico o grupo de recursos.

Imprime una descripción detallada de los recursos seleccionados, incluyendo recursos relacionados como eventos o controladores. Puede seleccionar un solo objeto por nombre, todos los objetos de ese tipo, proporcionar un prefijo de nombre o un selector de etiquetas. Por ejemplo:

    $ kubectl describe TIPO PREFIJO_NOMBRE

primero verificará una coincidencia exacta en TIPO y PREFIJO_NOMBRE. Si no existe tal recurso, mostrará detalles para cada recurso cuyo nombre comience con PREFIJO_NOMBRE.

Use "kubectl api-resources" para obtener una lista completa de los recursos compatibles.

OPCIONES

-A, --all-namespaces=false Si está presente, lista los objetos solicitados en todos los namespaces. El namespace en el contexto actual se ignora, incluso si se especifica con --namespace.

--chunk-size=500 Devuelve listas grandes en fragmentos en lugar de todas a la vez. Pase 0 para deshabilitar. Esta opción es beta y puede cambiar en el futuro.

-f, --filename=[] Nombre de archivo, directorio o URL de archivos que contienen el recurso a describir

-k, --kustomize="" Procesa el directorio de kustomization. Esta opción no se puede usar junto con -f o -R.

-R, --recursive=false Procesa el directorio usado en -f, --filename recursivamente. Útil cuando desea gestionar manifiestos relacionados organizados dentro del mismo directorio.

-l, --selector="" Selector (consulta de etiquetas) para filtrar, soporta '=', '==', '!=', 'in', 'notin'. (ej. -l clave1=valor1,clave2=valor2,clave3 in (valor3)). Los objetos coincidentes deben cumplir todas las restricciones de etiquetas especificadas.

--show-events=true Si es verdadero, muestra los eventos relacionados con el objeto descrito.

OPCIONES HEREDADAS DE COMANDOS PADRE

--as="" Nombre de usuario a suplantar para la operación. El usuario puede ser un usuario regular o una cuenta de servicio en un namespace.

--as-group=[] Grupo a suplantar para la operación, esta opción se puede repetir para especificar múltiples grupos.

--as-uid="" UID a suplantar para la operación.

--cache-dir="/home/username/.kube/cache" Directorio de caché predeterminado

--certificate-authority="" Ruta a un archivo de certificado para la autoridad certificadora

--client-certificate="" Ruta a un archivo de certificado de cliente para TLS

--client-key="" Ruta a un archivo de clave de cliente para TLS

--cluster="" El nombre del clúster kubeconfig a usar

--context="" El nombre del contexto kubeconfig a usar

--disable-compression=false Si es verdadero, opta por no comprimir las respuestas para todas las solicitudes al servidor

--insecure-skip-tls-verify=false Si es verdadero, el certificado del servidor no se verificará para determinar su validez. Esto hará que sus conexiones HTTPS no sean seguras

--kubeconfig="" Ruta al archivo kubeconfig a usar para las solicitudes CLI.

--kuberc="" Ruta al archivo kuberc a usar para preferencias. Esto puede deshabilitarse exportando el feature gate KUBECTL_KUBERC=false o desactivando el feature KUBERC=off.

--match-server-version=false Requiere que la versión del servidor coincida con la versión del cliente

-n, --namespace="" Si está presente, el ámbito del namespace para esta solicitud CLI

--password="" Contraseña para la autenticación básica al servidor API

--profile="none" Nombre del perfil a capturar. Uno de (none|cpu|heap|goroutine|threadcreate|block|mutex)

--profile-output="profile.pprof" Nombre del archivo donde escribir el perfil

--request-timeout="0" La duración antes de rendirse en una sola solicitud al servidor. Los valores distintos de cero deben contener una unidad de tiempo correspondiente (ej. 1s, 2m, 3h). Un valor de cero significa no caducar las solicitudes.

-s, --server="" La dirección y el puerto del servidor API de Kubernetes

--tls-server-name="" Nombre del servidor a usar para la validación del certificado del servidor. Si no se proporciona, se utiliza el nombre de host utilizado para contactar al servidor

--token="" Token Bearer para la autenticación al servidor API

--user="" El nombre del usuario kubeconfig a usar

--username="" Nombre de usuario para la autenticación básica al servidor API

--version=false --version, --version=raw imprime información de versión y sale; --version=vX.Y.Z... establece la versión informada

--warnings-as-errors=false Tratar las advertencias recibidas del servidor como errores y salir con un código de salida distinto de cero

EJEMPLO

  # Describir un nodo
  kubectl describe nodes kubernetes-node-emt8.c.myproject.internal
  # Describir un pod
  kubectl describe pods/nginx
  # Describir un pod identificado por tipo y nombre en "pod.json"
  kubectl describe -f pod.json
  # Describir todos los pods
  kubectl describe pods
  # Describir pods por etiqueta name=myLabel
  kubectl describe pods -l name=myLabel
  # Describir todos los pods gestionados por el controlador de replicación 'frontend'
  # (los pods creados por rc obtienen el nombre del rc como prefijo en el nombre del pod)
  kubectl describe pods frontend
