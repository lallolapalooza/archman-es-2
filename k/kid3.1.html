INTRODUCCIÓ

N

Kid3 es una aplicación para editar las etiquetas ID3v1 e ID3v2 en archivos MP3 de manera eficiente. Estas etiquetas pueden ser editadas por la mayoría de los reproductores MP3, pero no de una manera muy cómoda y eficiente. Además, las etiquetas en archivos Ogg/Vorbis, Opus, DSF, FLAC, MPC, APE, MP4/AAC, MP2, Speex, TrueAudio, WavPack, WMA, WAV, AIFF y módulos de tracker (MOD, S3M, IT, XM) también son

soportadas.

Kid3 no graba ni codifica archivos MP3, pero está destinado a editar las etiquetas ID3 de todos los archivos de un álbum de manera eficiente, es decir, con la menor cantidad de clics de ratón y pulsaciones de teclas posible. Mientras que la mayoría de otros programas pueden editar etiquetas ID3v1 o ID3v2, Kid3 tiene control total sobre ambas versiones, puede convertir etiquetas entre los dos formatos y tiene acceso a todas las etiquetas ID3v2. Las etiquetas de múltiples archivos pueden establecerse al mismo valor, por ejemplo, el artista, álbum, año y género de todos los archivos de un álbum típicamente tienen los mismos valores y pueden establecerse juntos. Si la información para las etiquetas está contenida en el nombre del archivo, las etiquetas pueden establecerse automáticamente desde el nombre del archivo. También es posible establecer el nombre del archivo de acuerdo a las etiquetas encontradas en el archivo en formatos

arbitrarios.

La tarea de edición es apoyada adicionalmente por el reemplazo automático de caracteres o subcadenas, por ejemplo para remover caracteres ilegales de nombres de archivo. El control automático de mayúsculas y minúsculas facilita usar un esquema de nombrado consistente en todas las

etiquetas.

La información de etiquetas para álbumes completos puede tomarse de gnudb.org[1], MusicBrainz[2], Discogs[3], Amazon[4] u otras fuentes de listas de pistas. El formato de importación es libremente configurable mediante expresiones

regulares.

Ejemplo de

Uso

Esta sección describe una sesión típica con Kid3. Asumamos que tenemos una carpeta que contiene archivos MP3 con las pistas del álbum "Let's Tag" de la banda "One Hit Wonder". La carpeta está nombrada en el formato "artista - álbum", en nuestro caso One Hit Wonder - Let's Tag. La carpeta contiene las pistas en el formato "pista título.mp3", que creo que es útil porque los nombres de archivo son cortos (importante cuando se usan reproductores MP3 móviles con pantallas pequeñas) y en el orden correcto cuando se ordenan alfabéticamente (importante cuando se usan reproductores MP3 de hardware que reproducen las pistas en orden alfabético o en el orden en el que se queman en CD y ese orden es alfabético cuando se usa mkisofs). Además de esto, la información del artista y álbum ya está en el nombre de la carpeta y no tiene que repetirse en el nombre del archivo. Pero volviendo a nuestro ejemplo, el listado de la carpeta se ve

así:

01 Intro.

mp3

02 We Only Got This One.

mp3

03 Outro.

mp3

Estos archivos no tienen etiquetas todavía y queremos generarlas usando Kid3. Usamos el elemento de menú Archivo → Abrir (o el botón de la barra de herramientas) y seleccionamos uno de los archivos en esta carpeta. Todos los archivos se mostrarán en la lista de archivos. Perezosos como somos, queremos usar la información en los nombres de carpeta y archivo para gen

erar etiquetas. Por lo tanto seleccionamos todos los archivos, luego hacemos clic en el botón A: Etiqueta 1 en la sección Archivo. Esto establecerá el título, artista, álbum y número de pista en todos los archivos. Para establecer los valores de año y género de todos los archivos, mantenemos todos los archivos seleccionados y escribimos "2002" para la Fecha y selec
cionamos "Pop" del cuadro combinado de Género. Para establecer solo estos dos valores, sus casillas de verificación se marcan automáticamente y todas las demás casillas de verificación se dejan sin marcar. Ahora cambiamos la selección seleccionando solo el primer archivo y vemos que todas las etiquetas contienen los valores correctos. Las etiquetas de los otros arch
ivos también pueden verificarse seleccionándolos uno por uno. Cuando estamos satisfechos con las etiquetas, usamos el elemento de menú Archivo → Guardar (o el botón de la barra de herramientas). Seleccionando el elemento de menú Archivo → Crear Lista de Reproducción (o el botón de la barra de herramientas) generará un archivo One Hit Wonder - Let's Tag.m3u en la carpeta.

GUI

La GUI de Kid3 está separada en seis secciones: A la izquierda están las listas de archivos y carpetas, el lado derecho contiene las secciones Archivo, Etiqueta 1, Etiqueta 2 y Etiqueta

3.

Para navegar entre las diferentes secciones usando el tecladord, se admiten varios atajos de teclado. En las secciones de etiquetas, los atajos están activos mientras no se edita texto o cuando se está en la primera columna.

•Alt+Izquierda: Ir a la sección anterior (Comando+[ en macOS®)
•Alt+Derecha: Ir a la sección siguiente (Comando+] en macOS®)
•Ctrl+Shift+V: Desde otra etiqueta
•Ctrl+C: Copiar
•Ctrl+V: Pegar
•Shift+Supr: Eliminar
•F2: Editar
•Insertar: Añadir
•Supr: Eliminar

Lista de Archivos

La lista de archivos contiene los nombres de todos los archivos de la carpeta abierta que coinciden con el filtro de nombre de archivo seleccionado (típicamente *.mp3 *.ogg *.opus *.dsf *.flac *.mpc *.aac *.m4a *.m4b *.m4p *.mp4 *.mp2 *.spx *.tta *.wv *.wma *.wav *.aiff *.ape). Se pueden seleccionar uno o varios archivos. Para no seleccionar ningún archivo, haga clic en el área vacía después de las entradas de la lista. La selección determina los archivos que se ven afectados por las operaciones que están disponibles utilizando los botones que se describen a continuación.

Además del Nombre, también se pueden mostrar otras columnas: Tamaño, Tipo, Fecha de Modificación con detalles del archivo. Las columnas se pueden ocultar desmarcando su nombre en el menú contextual del encabezado de la columna. El orden de las columnas se puede cambiar arrastrando y soltando. El orden de clasificación se puede alternar haciendo clic en el encabezado de la columna.

Los valores de las etiquetas estándar también se pueden mostrar y editar en columnas de la lista de archivos.

A la izquierda de los nombres se puede mostrar un icono: un disco para indicar que el archivo se ha modificado o información sobre qué etiquetas están presentes (V1, V2, V1V2 o SIN ETIQUETA, no se muestra ningún icono si el archivo aún no se ha leído).

Las carpetas se muestran con un icono de carpeta. Si se abre una carpeta, sus archivos se muestran en un árbol jerárquico. Al seleccionar archivos de subcarpetas, se pueden ejecutar operaciones en archivos de diferentes carpetas, lo que es útil si la colección de música está organizada con una carpeta para cada artista que contiene carpetas para álbumes de ese artista.

Al hacer clic con el botón derecho del ratón dentro de la lista de archivos, se abre un menú contextual con los siguientes comandos:

•Expandir todo: Expande todos los árboles de carpetas (solo el árbol actual si se presiona la tecla Shift)
•Contraer todo: Contrae todos los árboles de carpetas
•Renombrar: Cambia el nombre de un archivo
•Mover a la papelera: Mueve un archivo a la papelera
•Reproducir: Reproduce un archivo, consulte Reproducir. Si el archivo seleccionado es una lista de reproducción, se reproducirán los archivos de la lista de reproducción.
•Editar: Editar una lista de reproducción, consulte Editar Lista de Reproducción.
•Las siguientes entradas son comandos de usuario, que se pueden definir en la pestaña Acciones de Usuario de Configurar Kid3. La reproducción al hacer doble clic también se puede activar allí.

Cuando Seleccionar archivo al reproducir está activado, la pista que se está reproduciendo actualmente se selecciona automáticamente en la lista de archivos.

Editar Lista de Reproducción

Se puede crear una lista de reproducción vacía o que contenga las pistas de una carpeta, consulte Crear Lista de Reproducción. El archivo de lista de reproducción creado de esta manera se puede editar haciendo doble clic o utilizando Editar en el menú contextual de la lista de archivos. Se muestra un diálogo con las entradas de la lista de reproducción. Es posible abrir varias listas de reproducción simultáneamente.

Se pueden añadir nuevas entradas arrastrando y soltando desde la lista de archivos, un gestor de archivos u otra lista de reproducción. Si se arrastra una entrada desde otra lista de reproducción, se moverá o copiará dependiendo del sistema. Para invocar la otra operación, respectivamente, se debe presionar la tecla Shift, Ctrl o Alt (para copiar en lugar de mover en macOS®). También es posible reordenar las entradas dentro de la lista de reproducción mediante arrastrar y soltar. Alternativamente, las entradas se pueden mover usando los atajos de teclado Ctrl+Shift+Arriba y Ctrl+Shift+Abajo (en macOS® se debe presionar Comando en lugar de Ctrl). Una entrada se puede eliminar usando la tecla Supr.

Tenga en cuenta lo siguiente: Para arrastrar entradas desde la lista de archivos, deben mantenerse en el lado izquierdo (cerca de los iconos), el mismo gesto en el lado derecho realizará una selección múltiple, tal acción aún es fácilmente posible aquí.

Cuando se modifica una lista de reproducción, los cambios se pueden guardar usando Guardar o descartar usando Cancelar. Al cerrar la ventana, se mostrará un mensaje de confirmación si hay cambios sin guardar.

Las pistas seleccionadas en una lista de reproducción se seleccionarán automáticamente en la lista de archivos, lo que permitirá editar sus etiquetas.

Para ejecutar acciones en una lista de reproducción, su archivo debe estar seleccionado en la lista de archivos. Editar desde el menú contextual llevará al diálogo descrito en esta sección, y Reproducir iniciará el reproductor multimedia con las pistas de la lista de reproducción. Las acciones del usuario pueden actuar sobre las listas de reproducción, por ejemplo, Exportar Carpeta de Lista de Reproducción, que copia los archivos de una lista de reproducción a una carpeta.

Lista de Carpetas

La lista de carpetas contiene los nombres de las carpetas en la carpeta abierta, así como la carpeta actual (.) y la carpeta padre (..). Permite cambiar rápidamente de carpeta sin usar el comando Abrir o arrastrar y soltar.

La visibilidad, el orden y la clasificación de las columnas se pueden configurar como se describe en la sección sobre la lista de archivos.

Archivo

Muestra información sobre la codificación (MP3, Ogg, Opus, DSF, FLAC, MPC, APE, MP2, MP4, AAC, Speex, TrueAudio, WavPack, WMA, WAV, AIFF), tasa de bits, frecuencia de muestreo, canales y la duración del archivo.

El campo de texto Nombre contiene el nombre del archivo (si solo se selecciona un archivo). Si se cambia este nombre, el archivo se renombrará cuando se utilice el comando Guardar.

El cuadro combinado y campo de texto Formato contiene el formato que se utilizará cuando el nombre de archivo se genere a partir de la primera o la segunda etiqueta. El nombre de archivo puede contener caracteres arbitrarios, incluso una parte de carpeta separada por una barra del nombre del archivo, pero esa carpeta debe existir previamente para que el cambio de nombre tenga éxito. Los siguientes códigos especiales se utilizan para insertar valores de etiquetas en el nombre del archivo:

•%s %{title} Título (Canción)
•%a %{artist} Artista
•%l %{album} Álbum
•%c %{comment} Comentario
•%y %{year} Año
•%t %{track} Pista (por ejemplo, 01)
•%t %{track.n} Pista con ancho de campo n (por ejemplo, 001 para %{track.3})
•%T %{tracknumber} Pista (sin ceros iniciales, por ejemplo, 1)
•%g %{genre} Género
•%{ignore} Ignorado al generar etiquetas desde el nombre del archivo

Los códigos de formato no están restringidos a los ejemplos dados anteriormente. Se puede utilizar cualquier nombre de trama, por ejemplo, nombres de trama unificados como %{albumartist}, %{discnumber.1}, %{bpm} o nombres específicos del formato como %{popm}.

Es posible anteponer y añadir cadenas a la sustitución de un código de formato añadiéndolas entre comillas dobles dentro de las llaves de un código de formato. Estas cadenas solo se pondrán en la cadena resultante si el código de formato produce un valor no vacío. Por ejemplo, si el nombre del archivo debe contener tanto el título como el subtítulo, se podría usar %{title} [%{subtitle}] en la cadena de formato. Pero esto daría como resultado una cadena que termina en [] si no existe ninguna trama de subtítulo para un archivo. Para omitir los corchetes si no hay subtítulo presente, se debe usar en su lugar %{title}%{" ["subtitle"]"}. Esto omitirá los corchetes, el espacio inicial y el subtítulo si no existe el subtítulo.

La lista de formatos disponibles se puede editar en el diálogo que aparece al hacer clic en el botón Nombre de archivo desde etiqueta en la pestaña Archivo de la configuración.

Un segundo cuadro combinado de Formato (con flecha hacia abajo) se utiliza para generar las etiquetas desde el nombre del archivo. Si el formato del nombre del archivo no coincide con este patrón, se intentan algunos otros formatos de uso común.

Algunos formatos de nombre de archivo comunes ya están disponibles en el cuadro combinado, pero también es posible escribir un formato especial en el campo de texto.

La lista de formatos disponibles se puede editar en el diálogo que aparece al hacer clic en el botón Etiqueta desde nombre de archivo en la pestaña Archivo de la configuración.

Internamente, se crea una expresión regular a partir de los códigos de formato. Si se requieren expresiones regulares avanzadas, el formato para generar las etiquetas desde los nombres de archivo se puede proporcionar como una expresión regular completa con capturas que van precedidas por los códigos de formato, por ejemplo, para extraer los números de pista sin eliminar los ceros iniciales, se podría usar un formato como "/%{track}(\d+) %{title}(.*)".

Desde: Etiqueta 1, Etiqueta 2: Establece el nombre del archivo utilizando el formato seleccionado y la primera etiqueta o la segunda etiqueta, respectivamente.

A: Etiqueta 1, Etiqueta 2: Las etiquetas se establecen desde el nombre del archivo. Primero, se utiliza el formato especificado en Formato. Si el nombre de archivo existente no coincide con este formato, se intentan los siguientes formatos:

•Artista - Álbum/Pista Canción
•Álbum/Pista - Artista - Canción
•/Artista - Álbum - Pista - Canción
•Álbum/Artista - Pista - Canción
•Álbum/Artista - Canción
•Artista/Álbum/Pista Canción

Si se selecciona un solo archivo, los controles de la interfaz gráfica se rellenan con los valores extraídos del nombre del archivo. Si se seleccionan varios archivos, las etiquetas de los archivos se establecen directamente de acuerdo con los nombres de archivo.

Etiqueta 1

Los controles de campo de texto para Título, Artista, Álbum, Comentario, Fecha, Número de Pista y Género se utilizan para editar el valor correspondiente en la primera etiqueta de los archivos seleccionados. El valor se cambiará cuando se altere la selección del archivo o antes de operaciones como Guardar y Salir y cuando se marque la casilla de verificación correspondiente a la izquierda del nombre del campo. Esto es útil para cambiar solo algunos valores y dejar los otros sin cambios.

Si se selecciona un solo archivo, todas las casillas de verificación están marcadas y los controles de campo de texto contienen los valores encontrados en las etiquetas de este archivo. Si no se encuentra una etiqueta en el archivo, se muestra el valor vacío correspondiente, que es una cadena vacía para los campos de texto Título, Artista, Álbum y Comentario, 0 para los campos de edición numéricos Fecha y Número de Pista, y un valor seleccionado vacío para el cuadro combinado Género. Los valores se pueden cambiar y, si la casilla de verificación correspondiente está marcada, se establecerán para el archivo seleccionado después de que cambie la selección. El archivo se marcará como modificado con un símbolo de disco en la lista de archivos, pero permanecerá sin cambios hasta que se utilice el comando Guardar.

Si se seleccionan varios archivos

ected, solo se muestran los valores que son idénticos en todos los archivos seleccionados. En todos los demás controles, se muestran los valores vacíos descritos anteriormente. Todas las casillas de verificación están desmarcadas para evitar cambios no deseados. Si se debe establecer un valor para todos los archivos seleccionados, se puede editar y marcar la casilla de verificación. Los valores se establecerán para todos los archivos seleccionados cuando se cambie la selección y se pueden guardar usando el comando Guardar.

Las casillas de verificación también controlan la operación de la mayoría de los comandos que afectan a las etiquetas, como copiar, pegar y transferir entre las etiquetas 1 y 2. Para facilitar su uso con varios archivos donde todas las casillas de verificación están desmarcadas, estos comandos se comportan de la misma manera cuando todas las casillas de verificación están marcadas y cuando todas las casillas de verificación están desmarcadas.

Desde la Etiqueta 2: Los campos de la etiqueta 1 se establecen a partir de los valores correspondientes en la etiqueta 2. Si se selecciona un solo archivo, los controles de la GUI se llenan con los valores de la etiqueta 2. Si se seleccionan varios archivos, las etiquetas de los archivos se establecen directamente.

Copiar: El búfer de copia se llena con los valores de la Etiqueta 1. Solo los valores con la casilla de verificación marcada se utilizarán en los comandos de Pegar posteriores.

Pegar: Pega los valores del búfer de copia en los controles de la GUI.

Eliminar: Esto establecerá todos los controles de la GUI a sus valores vacíos, lo que resultará en la eliminación de todos los valores. El archivo guardado no contendrá ninguna etiqueta 1.

Etiqueta 2

Los controles de la GUI funcionan de la misma manera que se describe para la sección Etiqueta 1, pero el tamaño de las cadenas no está limitado.

Para el género de la etiqueta 2, también puede usar sus propios nombres además de los géneros listados en el cuadro combinado; simplemente escriba el nombre en el campo de edición.

La etiqueta 2 no solo puede contener los mismos valores que la etiqueta 1, el formato se construye de manera flexible a partir de varios marcos que a su vez se componen de varios campos. La tabla de la etiqueta 2 muestra todos los marcos disponibles en el archivo seleccionado.

Editar: Esto abrirá una ventana que permite editar todos los campos del marco seleccionado. Si se seleccionan varios archivos, los campos editados se aplicarán a todos los archivos seleccionados que contengan dicho marco.

Agregar: Aparecerá un solicitante para seleccionar el tipo de marco y se puede editar un marco del tipo seleccionado y agregarlo al archivo. Esto también funciona para agregar un marco a varios archivos seleccionados.

Eliminar: Elimina el marco seleccionado en los archivos seleccionados.

Arrastrar carátula del álbum aquí se muestra si el archivo no contiene carátula incrustada. Se puede agregar una imagen arrastrándola y soltándola desde un navegador o administrador de archivos y se mostrará aquí. Los marcos de imagen se pueden editar o agregar haciendo doble clic en este control.

Etiqueta 3

Algunos archivos pueden tener más de dos etiquetas, y la sección de la tercera etiqueta está visible. Los siguientes tipos de archivo pueden tener dicha sección de Etiqueta 3:

•Los archivos MP3 pueden tener una etiqueta ID3v1.1, una etiqueta ID3v2 (2.3.0 o 2.4.0) y en la tercera sección una etiqueta APE. Dichas etiquetas APE se utilizan para información de ganancia de reproducción. En la sección Etiqueta 3, esta información es visible y la etiqueta APE se puede eliminar con el botón Eliminar.
•El bloque RIFF INFO de los archivos WAV está disponible en la sección Etiqueta 3 porque la sección Etiqueta 1 está dedicada a las etiquetas ID3v1.1 y maneja sus restricciones. La Etiqueta 2 todavía se utiliza para las etiquetas ID3v2.4.0, que también se admiten para archivos WAV, pero los bloques RIFF INFO parecen ser mejor compatibles.
•Los archivos FLAC normalmente utilizan comentarios Vorbis para sus metadatos. Sin embargo, hay archivos FLAC que tienen etiquetas ID3v1 e ID3v2, que se pueden encontrar en las secciones Etiqueta 1 y Etiqueta 3. Las etiquetas ID3 en archivos FLAC solo son compatibles con TagLib, por lo tanto, el complemento OggFlacMetadata debe estar deshabilitado en la pestaña Complementos de la configuración.

Los controles de la GUI funcionan de la misma manera que en la sección Etiqueta 2.

Letras de canciones sincronizadas y códigos de tiempo de eventos

Para información sincronizada con los datos de audio, hay un editor específico disponible. Estos marcos son compatibles con las etiquetas ID3v2.3.0 e ID3v2.4.0. Para agregar dicho marco, se debe seleccionar el nombre del marco específico en la lista que aparece al hacer clic en el botón Agregar: Letras de canciones sincronizadas o Códigos de tiempo de eventos, respectivamente. El editor es el mismo para ambos tipos, para los códigos de tiempo de eventos, solo hay disponible un conjunto predefinido de eventos, mientras que para las letras de canciones sincronizadas, se debe introducir texto. A continuación, se explica la edición de letras de canciones sincronizadas.

Se selecciona un archivo que tiene una etiqueta ID3v2, se ingresa al editor de letras haciendo clic en Agregar y seleccionando Letras de canciones sincronizadas. Para un marco de Letras de canciones sincronizadas existente, se selecciona y se hace clic en Editar. El reproductor se abre automáticamente con el archivo actual para que el archivo se pueda reproducir y pausar para sincronizar las letras.

La configuración en la parte superior del editor SYLT normalmente no necesita cambiarse. Si las letras contienen caracteres que no están presentes en el conjunto de caracteres Latin 1, se recomienda cambiar la codificación de texto a UTF16 (o UTF8 para ID3v2.4.0). Para letras en inglés y máxima compatibilidad, se debe usar ISO-8859-1.

La sección de Letras de canciones tiene cinco botones en la parte superior. Agregar agregará un nuevo evento de tiempo en la tabla. El tiempo se toma de la posición del reproductor, por lo tanto, agregar una entrada mientras se reproduce la pista agregará una línea para la posición que se está reproduciendo actualmente. Los eventos en la tabla deben ordenarse cronológicamente, por lo tanto, la fila se insertará en consecuencia. Las entradas con un tiempo inválido se tratan de manera especial: si la fila seleccionada actualmente tiene un tiempo inválido, su marca de tiempo se reemplazará por el tiempo actual en lugar de agregar una nueva fila. Si el tiempo actual no es inválido, se usará la primera fila con un tiempo inválido si está presente. Este comportamiento debería facilitar la adición de marcas de tiempo si el texto de las letras ya está en la tabla pero faltan las marcas de tiempo (que es el caso al importar letras no sincronizadas). Tenga en cuenta que el tiempo inválido se representa como 00:00.00, es decir, lo mismo que el tiempo al principio absoluto de la pista, que no es inválido. Para hacer que un tiempo sea inválido, presione la tecla Supr o use Borrar del menú contextual. Las nuevas filas insertadas usando Insertar fila del menú contextual o creadas al importar letras no sincronizadas con Desde el portapapeles o Importar también contienen marcas de tiempo inválidas. Las filas de la tabla se pueden eliminar haciendo clic en el botón Eliminar o usando Eliminar filas del menú contextual.

Las letras de canciones sincronizadas se pueden importar desde un archivo usando Importar. El formato esperado es LRC simple o mejorado. Si el archivo seleccionado no contiene un corchete en la primera línea, se supone que es un archivo de texto simple con letras no sincronizadas. Las líneas de dicho archivo se importan con marcas de tiempo inválidas. La información de tiempo se puede agregar usando el botón Agregar o mediante entrada manual. También es posible importar letras a través de copiar y pegar usando Desde el portapapeles. Las letras de canciones sincronizadas se pueden guardar en archivos LRC usando Exportar. Tenga en cuenta que solo se exportarán las entradas con marcas de tiempo válidas y que las entradas se ordenarán por tiempo. Las entradas con tiempo inválido tampoco se almacenarán en el marco SYLT, así que asegúrese de incluir toda la información de tiempo antes de salir del diálogo.

La **especificación ID3**[5] sugiere una marca de tiempo para cada sílaba. Sin embargo, la mayoría de los reproductores solo admiten la granularidad de una línea o oración. Para admitir ambos casos de uso, Kid3 sigue las mismas convenciones que el **Editor SYLT**[6]. Se asume que el texto introducido en la tabla comienza una nueva línea a menos que comience con un espacio o un guion. Son posibles excepciones a esta regla al comenzar una línea con un guion bajo ('_') para forzar la continuación o con una almohadilla ('#') para forzar una nueva línea. Estos caracteres de escape no se almacenan dentro del marco SYLT. Dentro del marco SYLT, las nuevas líneas comienzan con un carácter de salto de línea (hex 0A) mientras que las continuaciones no lo hacen. Al leer los marcos SYLT, Kid3 comprueba si la primera entrada comienza con un salto de línea. Si este no es el caso, se asume que todas las entradas son nuevas líneas y que no se utilizan continuaciones de sílabas.

Mientras se reproduce la pista, la fila asociada con la posición actual de reproducción se resalta, para que se pueda verificar la corrección de la información de sincronización. Si es necesario agregar un desplazamiento a una o más marcas de tiempo, esto se puede lograr con el menú contextual Agregar desplazamiento. Se pueden usar valores negativos para reducir el tiempo. Usando Buscar hasta posición en el menú contextual, es posible establecer la posición de reproducción al tiempo de la fila seleccionada.

Procedimiento recomendado para agregar nuevas letras de canciones sincronizadas

•Obtenga las letras de canciones no sincronizadas, por ejemplo, usando Letras de canciones → Incrustar letras de canciones del menú contextual de la lista de archivos.
•Copie las letras de canciones no sincronizadas al portapapeles, simplemente vaya a la fila Letras de canciones en la tabla de marcos y presione Ctrl+C.
•Agregue un marco de letras de canciones sincronizadas (Agregar..., Letras de canciones sincronizadas, Aceptar), haga clic en Desde el portapapeles.
•Ahora todas las líneas de las letras de canciones no sincronizadas están en la tabla, todas las marcas de tiempo son inválidas (0:0:0.00). Puede eliminar entradas vacías de antemano.
•Comience a reproducir la canción haciendo clic en el botón de reproducción ► en la barra de herramientas de reproducción en la parte inferior de la ventana principal.
•Cuando aparezca la siguiente línea de letras con marca de tiempo inválida, haga clic en Agregar o presione Alt+A, la marca de tiempo se actualizará.
•Continúe así hasta que se establezcan todas las marcas de tiempo. Si se perdió algo, detenga la reproducción y borre las marcas de tiempo usando la tecla Supr o seleccionándolas y usando Borrar del menú contextual. Para reiniciar la reproducción desde una marca de tiempo dada, use Buscar hasta posición en el menú contextual.

Capítulos en archivos MP4

Los audiolibros MP4 suelen tener la extensión .m4b y son bastante grandes porque contienen todos los capítulos en un solo archivo. Para navegar en dichos archivos, pueden contener marcas de capítulos, que se pueden editar en Kid3 en un marco pseudo "Capítulos" usando el mismo editor que se usa para las letras de canciones sincronizadas. Tenga en cuenta, sin embargo, que esta característica solo está disponible con el complemento Mp4v2Metadata, así que asegúrese de que esté activado y por encima del complemento TaglibMetadata en la pestaña Complementos de la configuración si necesita editar capítulos MP4.

La información de los capítulos en los audiolibros MP3 se almacena en varios marcos "Capítulo" (CHAP) a los que hace referencia un marco "Tabla de contenido" (CTOC), y estos marcos tienen sub-marcos incrustados. Para editar esta información en un solo lugar, un marco pseudo "Capítulos" también se puede usar para etiquetas ID3v2. Su contenido se utiliza para crear los marcos reales de capítulo, tabla de contenido y sub-marcos incrustados: la Descripción se usa como título de la tabla de contenido, la columna Texto contiene los títulos de los capítulos, y el Tiempo correspondiente será la hora de inicio del capítulo y la hora de finalización del capítulo anterior. La hora de finalización del último capítulo se determina por la Hora de la última fila si su Texto está vacío.

El diálogo de Importación se puede utilizar para importar datos directamente desde un servidor freedb.org, desde un servidor MusicBrainz, desde Discogs, Amazon u otras fuentes de listas de pistas de álbumes en formato de texto.

La importación desde un servidor freedb.org es posible utilizando un diálogo que aparece cuando se selecciona "From Server: gnudb.org". El nombre del artista y del álbum a buscar se puede introducir en los dos campos superiores, los álbumes que coinciden con la consulta se mostrarán al hacer clic en Buscar y recibir los resultados de www.gnudb.org[7]. La importación de los datos de las pistas de un álbum se realiza haciendo doble clic en el álbum de la lista. Se puede seleccionar el servidor freedb.org desde el que importar, así como la ruta CGI. Los datos importados se muestran en la tabla de vista previa del diálogo de importación. Cuando esté satisfecho con las pistas mostradas, se pueden importar finalizando el diálogo de importación con Aceptar.

Si ya tiene un resultado de búsqueda abierto en el navegador web, puede introducir la URL en el primer campo de búsqueda. El resultado aparecerá entonces en la lista de álbumes y se podrá importar directamente en Kid3.

Se puede introducir una dirección de correo electrónico registrada en gnudb.org[8] en el campo Token.

Se puede realizar una búsqueda en el servidor Discogs utilizando Discogs. Al igual que en el diálogo de gnudb.org, puede introducir el artista y el álbum y luego elegir de una lista de lanzamientos. Se puede introducir un Token para utilizar la API RESTful de Discogs en lugar de su interfaz web, que se cambia a menudo, rompiendo así el analizador de importación. Debe registrarse para obtener una cuenta en Discogs[9] y luego generar un token en su sitio web (Configuración/Desarrolladores, Generar nuevo token). No olvide Guardar Configuración después de introducir el token para utilizarlo también en solicitudes posteriores. Si "Standard Tags" está marcado, se importa la información estándar, por ejemplo, artista, álbum y título. Si "Additional Tags" está marcado, se importa más información si está disponible, por ejemplo, intérpretes, arreglistas o el editor. Si "Cover Art" está marcado, se descargará la carátula del álbum si está disponible.

Se puede realizar una búsqueda en Amazon utilizando Amazon. Al igual que en el diálogo de gnudb.org, puede introducir el artista y el álbum y luego elegir de una lista de lanzamientos. Si "Additional Tags" está marcado, se importa más información si está disponible, por ejemplo, intérpretes, arreglistas o el editor. Si "Cover Art" está marcado, se descargará la carátula del álbum si está disponible.

Puede buscar de la misma manera en la base de datos de lanzamientos de MusicBrainz utilizando "From MusicBrainz Release". El flujo de trabajo es el mismo que se describe para "From gnudb.org".

La importación desde un servidor MusicBrainz es posible utilizando el diálogo que aparece cuando se selecciona "From MusicBrainz Fingerprint". El servidor se puede seleccionar como en el diálogo de importación de freedb. Debajo hay una tabla que muestra los datos de las pistas importadas. La columna derecha muestra el estado de la consulta de MusicBrainz, que comienza con "Pending" cuando se abre el diálogo. Luego se busca la huella digital y si no produce un resultado, se intenta otra búsqueda utilizando las etiquetas del archivo. Por lo tanto, puede ser útil para una consulta exitosa de MusicBrainz almacenar la información conocida (por ejemplo, artista y álbum) en las etiquetas antes de la importación. Si se encontró un resultado, la búsqueda termina en el estado "Recognized", de lo contrario, no se encontró nada o varios resultados ambiguos y uno de ellos debe ser seleccionado por el usuario. Aceptar y Aplicar utilizan los datos importados, Cancelar cierra el diálogo. El cierre puede llevar algún tiempo, ya que toda la maquinaria de MusicBrainz tiene que ser apagada.

Para la importación de datos textuales, "From File/Clipboard" abre un subdiálogo, donde hay varios formatos de importación preconfigurados disponibles. Los dos primeros, "CSV unquoted" y "CSV quoted", se pueden utilizar para importar datos que fueron exportados por el diálogo de Exportación. Los datos CSV se pueden editar con una hoja de cálculo y deben escribirse utilizando tabulaciones como delimitadores. La importación debería ser posible entonces utilizando "CSV quoted", que es más flexible que "CSV unquoted". Sin embargo, sus campos no pueden contener comillas dobles. Si solo exporta desde Kid3 e importa más tarde, se puede usar "CSV unquoted" como un formato simple para este propósito. Tenga en cuenta que también hay comandos "Export CSV" e "Import CSV" en el menú contextual de la lista de archivos, que utilizan scripts para exportar e importar datos CSV de una manera más completa, potente y flexible.

El siguiente formato, "freedb HTML text", se puede utilizar para copiar información de una página HTML de freedb.org[10]. Busque un álbum en freedb y si la información deseada se muestra en el navegador web, copie el contenido al portapapeles. Luego haga clic en el botón "From Clipboard" y las pistas importadas se mostrarán en la tabla de vista previa en la parte superior del diálogo. Si está satisfecho con los datos importados, finalice el diálogo con Aceptar, lo que insertará los datos en las etiquetas de la carpeta actual. El destino (Tag 1, Tag 2 o Tag 1 y Tag 2) se puede seleccionar con un cuadro combinado. Los archivos en la carpeta actual deben estar en el orden correcto de las pistas para asignar sus etiquetas. Este es el caso si están numerados.

El siguiente formato de importación preconfigurado, "freedb HTML source", se puede utilizar si los datos están disponibles como un documento HTML. La importación es posible utilizando el botón "From File", que abre un selector de archivos, o copiando su contenido desde un editor y luego importando desde el portapapeles. Este formato puede ser útil para la importación sin conexión, aunque el documento HTML también podría abrirse en un navegador y luego importarse en el primer formato a través del portapapeles.

Hay más formatos preconfigurados disponibles, por ejemplo, "Track Title Time". Se puede crear un formato personalizado vacío con Agregar para que lo configure el usuario. Las dos líneas debajo del nombre del formato se pueden configurar con una expresión regular para capturar los campos del texto de importación. La primera expresión regular se analizará una vez por documento para recopilar datos por álbum, como artista, álbum, año y género. La segunda línea se intentará hacer coincidir desde el principio del documento hasta el final para obtener datos de las pistas, generalmente número y título. Las expresiones regulares incluyen todas las características que ofrece Qt(TM), que es la mayor parte de lo que ofrece Perl. Los constructores de corchetes "(..)" crean búferes de captura para los campos a importar y van precedidos de códigos específicos de Kid3 para especificar qué campo capturar. Los códigos son los mismos que se utilizan para el formato del nombre de archivo, además de los códigos que se enumeran a continuación, cualquier nombre de marco es posible:

•%s %{title} Título (Canción)
•%a %{artist} Artista
•%l %{album} Álbum
•%c %{comment} Comentario
•%y %{year} Año
•%t %{track} Pista
•%g %{genre} Género
•%d %{duration} Duración

Por ejemplo, una expresión regular de pista (segunda línea) para importar desde una lista de reproducción .m3u podría ser "%{track}(\d+)\s+%{title}(\S[^\r\n]*)\.mp3[\r\n]". Todos los formatos se pueden cambiar editando las expresiones regulares y el nombre y luego haciendo clic en Guardar Configuración. Se almacenarán en el archivo kid3rc en la carpeta de configuración. Este archivo se puede editar directamente para tener más formatos de importación o se puede eliminar para volver a los formatos predeterminados. Los formatos se pueden eliminar usando Eliminar.

Accuracy muestra una estimación de qué tan bien la información importada coincide con las pistas dadas. Utiliza las duraciones de las pistas o los nombres de archivo para calcular el nivel de similitud en porcentaje. Cover Art muestra la URL de la imagen de la carátula del álbum que se descargará.

Para comprobar si las pistas importadas coinciden con el conjunto actual de archivos, la duración de las pistas importadas se puede comparar con la duración de los archivos. Esta opción se puede habilitar con la casilla de verificación "Check maximum allowable time difference (sec):" y la diferencia máxima tolerada en el tiempo se puede establecer en segundos. Si se detecta una discrepancia en la duración, la duración se mostrará con un fondo rojo en la tabla de vista previa.

Si los archivos están ordenados de manera diferente a las pistas importadas, sus pistas asignadas deberán cambiarse. Esta tarea se puede facilitar utilizando la opción "Match with" con los botones "Length", "Track" y "Title", que reordenarán las pistas según el campo correspondiente. Para corregir las asignaciones manualmente, se puede arrastrar una pista con el botón izquierdo del ratón y manteniendo pulsada la tecla Ctrl, y luego soltarla en la nueva ubicación.

Si hay más pistas importadas que archivos, por ejemplo, si la carpeta actual contiene solo el segundo disco de un álbum de dos discos pero se importan las pistas de ambos discos, es posible eliminar las pistas del primer disco seleccionándolas haciendo clic en la etiqueta de fila de la primera pista, luego haciendo clic en la etiqueta de fila de la última pista del primer disco mientras se mantiene presionada la tecla Shift, y finalmente eliminando las pistas presionando la tecla Suprimir.

Cuando se abre el diálogo de importación, contiene el contenido actual de las etiquetas. El tipo de etiqueta (Tag 1, Tag 2, Tag 1 y Tag 2) se puede seleccionar utilizando el cuadro combinado "Destination". El botón a la derecha de este cuadro combinado se puede utilizar para revertir la tabla al contenido actual de las etiquetas. Las casillas de verificación en la primera columna de la tabla se pueden utilizar para seleccionar las pistas que se importan. Esto puede ser útil si una carpeta contiene las pistas de ambos CDs de un CD doble y solo se deben importar las pistas del segundo CD.

Para identificar las pistas que se importan, es posible mostrar los nombres de archivo o las rutas completas a los archivos utilizando el menú contextual del encabezado de la tabla. Los valores de la tabla de importación se pueden editar. El botón de revertir a la derecha del cuadro combinado "Destination" se puede utilizar para restaurar el contenido de las etiquetas, lo que también puede ser útil después de cambiar el "Destination".

Dado que no todos los navegadores soportan arrastrar y soltar imágenes y las imágenes en los sitios web a menudo tienen una URL, en tales casos Kid3 recibirá la URL y no la imagen. Si la URL apunta a una imagen, se descargará. Sin embargo, si la URL se refiere a algún otro recurso web, debe ser traducida a la imagen correspondiente. Tales mapeos se definen en la tabla Extracción de URL. La columna izquierda Coincidencia contiene una expresión regular que se compara con la URL. Si coincide, las expresiones capturadas en paréntesis se insertan en el patrón de la columna URL de Imagen de la derecha (en las posiciones marcadas con \1, etc.). La expresión regular reemplazada contiene la URL de la imagen. De esta manera, se pueden importar carátulas desde Amazon, Google Imágenes, etc., usando arrastrar y soltar. También es posible definir sus propios mapeos.

Archivo → Exportar...

El Diálogo de Exportación se utiliza para guardar datos de las etiquetas en un archivo o en el portapapeles. El editor en la parte superior muestra una vista previa de los datos a exportar. Si los datos de exportación contienen caracteres de tabulación, la exportación se muestra en una tabla. Los datos se generarán a partir de las etiquetas de la carpeta actual de acuerdo con el formato configurado.

La configuración del formato es similar a la del diálogo de Importación: El campo superior contiene el título (por ejemplo, "CSV sin comillas"), seguido del encabezado, que se generará al principio del archivo. Los datos de las pistas siguen; se utilizan para cada pista. Finalmente, el pie de página se puede utilizar para generar algún texto final.

Los campos de formato no contienen expresiones regulares como en el diálogo de Importación, sino solo expresiones de formato de salida con %-expresiones especiales, que serán reemplazadas por valores de las etiquetas. Todo funciona como el formato del nombre del archivo, y se usan los mismos códigos más algunos códigos adicionales. No solo los códigos listados a continuación, sino todos los nombres de fotogramas de etiquetas pueden ser utilizados.

•%s %{title} Título (Canción)
•%a %{artist} Artista
•%l %{album} Álbum
•%c %{comment} Comentario
•%y %{year} Año
•%t %{track} Pista (por ejemplo, 01)
•%t %{track.n} Pista con ancho de campo n (por ejemplo, 001 para %{track.3})
•%T %{tracknumber} Número de Pista (sin ceros iniciales, por ejemplo, 1)
•%g %{genre} Género
•%f %{file} Nombre del archivo
•%p %{filepath} Ruta
•%{modificationdate} Fecha de modificación
•%{creationdate} Fecha de creación
•%u %{url} URL

•%d %{duration} Duración en minutos:segundos

•%e %{extension} Extensión del archivo

Varios formatos están predefinidos. "CSV sin comillas" separa los campos por tabulaciones. Los datos en este formato se pueden volver a importar en Kid3 usando el formato de importación con el mismo nombre. "CSV con comillas" encierra adicionalmente los campos entre comillas dobles, lo que facilita la importación en aplicaciones de hoja de cálculo. Sin embargo, los campos no deben contener ninguna comilla doble cuando se usa este formato. "Extended M3U" y "Extended PLS" generan listas de reproducción con atributos extendidos y nombres de ruta absolutos. "HTML" se puede usar para generar una página HTML con hipervínculos a las pistas. "Kover XML" crea un archivo que puede ser importado por el programa de impresión de carátulas Kover. "Detalles Técnicos" proporciona información sobre la tasa de bits, la frecuencia de muestreo, los canales, etc. Finalmente, "Formato Personalizado" se deja vacío para la definición de un formato personalizado. Puede definir más formatos propios agregando líneas en el archivo kid3rc en la carpeta de configuración. Los otros formatos se pueden adaptar a sus necesidades.

kid3-cli> set rating 5

El primer comando eliminará un marco POPM existente, porque si dicho marco existe, set rating 5 establecería el marco POPM y no el marco TXXX. Otra posibilidad sería usar set TXXX.Text 5, pero esto solo funcionaría si no hay ningún otro marco TXXX presente.

Para establecer múltiples marcos del mismo tipo, se puede dar un índice entre corchetes, por ejemplo, para establecer múltiples intérpretes en un comentario Vorbis, usa

kid3-cli> set performer[0] 'Liza don Getti (soprano)'
kid3-cli> set performer[1] 'Joe Barr (piano)'

Para seleccionar ciertos marcos antes de una acción de copiar, pegar o eliminar, se puede usar el nombre de campo pseudo "selected". Normalmente, todos los marcos están seleccionados; para deseleccionar todos, usa set '*.selected' 0, luego, por ejemplo, set artist.selected 1 para seleccionar el marco del artista.

El nombre de marco pseudo "ratingstars" se puede usar para establecer el valor del marco "rating" al valor específico del formato correspondiente al número de estrellas (0 a 5). El nombre de marco "rating" se puede usar para establecer el valor interno.

Establecer "ratingstars" en múltiples archivos con diferentes formatos de etiqueta no funcionará porque el marco con el valor mapeado del recuento de estrellas se crea para el primer archivo y luego se usa para todos los archivos. Por lo tanto, en lugar de kid3-cli -c "set ratingstars 2" *, deberías usar for f in *; do kid3-cli -c "set ratingstars 2" "$f"; done.

Ejemplos

Establecer el título que contiene una comilla simple. Los comandos pasados a kid3-cli con -c deben estar entre comillas si no consisten únicamente en una sola palabra. Si dicho comando contiene a su vez un argumento que contiene espacios, ese argumento también debe ir entre comillas. En los shells de UNIX®, se pueden usar comillas simples o dobles, pero en la línea de comandos de Windows, es importante que las comillas exteriores se hagan con comillas dobles y dentro de estas, se usen comillas simples. Si el texto dentro de las comillas simples contiene una comilla simple, debe escaparse con una barra invertida, como se muestra en el siguiente ejemplo:

kid3-cli -c "set title 'I\'ll be there for you'" /ruta/a/la/carpeta

Establecer la carátula del álbum en todos los archivos de una carpeta utilizando la función de importación por lotes:

kid3-cli -c "autoimport 'Cover Art'" /ruta/a/la/carpeta

Eliminar las tramas de comentarios y aplicar el formato de etiqueta en ambas etiquetas de todos los archivos MP3 de una carpeta:

kid3-cli -c "set comment '' 1" -c "set comment '' 2" \
-c "tagformat 1" -c "tagformat 2" /ruta/a/la/carpeta/*.mp3

Importar automáticamente la etiqueta 2, sincronizar con la etiqueta 1, establecer nombres de archivo desde la etiqueta 2 y finalmente crear una lista de reproducción:

kid3-cli -c autoimport -c "syncto 1" -c fromtag -c playlist \
  /ruta/a/la/carpeta/*.mp3

Para todos los archivos con una etiqueta ID3v2.4.0, convertir a ID3v2.3.0 y eliminar la trama de arreglista:

kid3-cli -c "filter 'ID3v2.4.0 Tag'" -c "select all" -c to23 \
  -c "set arranger ''" /ruta/a/la/carpeta

Este script de Python utiliza kid3-cli para generar tramas iTunNORM de Sound Check de iTunes a partir de información de ganancia de reproducción.

#!/usr/bin/env python3
# Generar Sound Check de iTunes desde ReplayGain.
import os, sys, subprocess
def rg2sc(dirpath):
  for root, dirs, files in os.walk(dirpath):
    for name in files:
      if name.endswith(('.mp3', '.m4a', '.aiff', '.aif')):
        fn = os.path.join(root, name)
        rg = subprocess.check_output([
          'kid3-cli', '-c', 'get "replaygain_track_gain"',
           fn]).strip()
        if rg.endswith(b' dB'):
          rg = rg[:-3]
        try:
          rg = float(rg)
        except ValueError:
          print('Value %s of %s in not a float' % (rg, fn))
          continue
        sc = (' ' + ('%08X' % int((10 ** (-rg / 10)) * 1000) )) * 10
        subprocess.call([
          'kid3-cli', '-c', 'set iTunNORM "%s"' % sc, fn])
if __name__ == '__main__':
  rg2sc(sys.argv[1])

Formato JSON

Para facilitar el análisis de los resultados de kid3-cli, es posible obtener la salida en formato JSON. Cuando la solicitud está en formato JSON, la respuesta también será JSON. Un formato compacto de la solicitud también dará una representación compacta de la respuesta. Si la solicitud contiene un campo "id", se asume que es una solicitud JSON-RPC y la respuesta contendrá un campo "jsonrpc" y el "id" de la solicitud. El formato de la solicitud utiliza los mismos comandos que la CLI estándar, el campo "method" contiene el comando y los parámetros (si los hay) se dan en la lista "params". La respuesta contiene un objeto "result", que también puede ser nulo si el comando kid3-cli correspondiente no devuelve un resultado. En caso de error, se devuelve un objeto "error" con campos "code" y "message" como se usa en JSON-RPC.

kid3-cli> {"method":"set","params":["artist","An Artist"]}
{"result":null}
kid3-cli> {"method":"get","params":["artist",2]}
{"result":"An Artist"}
kid3-cli> {"method": "get", "params": ["artist"]}
{
    "result": "An Artist"
}
kid3-cli> {"jsonrpc":"2.0","id":"123","method":"get","params":["artist"]}
{"id":"123","jsonrpc":"2.0","result":"An Artist"}

Kid3 necesita Qt(TM)[25]. Se recomienda KDE[26] pero no es necesario, ya que Kid3 también se puede compilar como una aplicación Qt(TM). Estos cuatro formatos también son compatibles con TagLib[19], que también puede manejar archivos Opus, MPC, APE, MP2, Speex, TrueAudio, WavPack, WMA, WAV, AIFF y módulos de seguimiento. Para importar desde huellas dactilares acústicas, se utilizan Chromaprint[21] y libav[22].

Kid3 está disponible para la mayoría de las distribuciones de Linux®, Windows® y macOS®. Los enlaces se pueden encontrar en https://kid3.kde.org.

Compilación e instalación

Puedes compilar Kid3 con o sin KDE. Sin KDE, Kid3 es una aplicación Qt(TM) simple y carece de algunas funciones de configuración y sesión.

Para una versión de KDE, ve a la carpeta principal y escribe

% cmake .
% make
% make install

Para compilar para diferentes versiones de Qt(TM) o KDE, establece las opciones de cmake correspondientes.

Si no todas las bibliotecas están presentes, Kid3 se compila con funcionalidad reducida. Por lo tanto, debes asegurarte de tener instalados todos los paquetes de desarrollo deseados. Por otro lado, las opciones de cmake controlan qué bibliotecas se compilan. Los valores predeterminados son -DWITH_TAGLIB:BOOL=ON -DWITH_MP4V2:BOOL=OFF -DWITH_ID3LIB:BOOL=ON -DWITH_CHROMAPRINT:BOOL=ON -DWITH_VORBIS:BOOL=ON -DWITH_FLAC:BOOL=ON. Estas opciones se pueden deshabilitar usando OFF.

Para compilar Kid3 como una aplicación Qt(TM) sin KDE, usa la opción cmake -DWITH_APPS=Qt. Para compilar tanto una aplicación KDE como una Qt(TM), establece -DWITH_APPS="Qt;KDE".

Para usar una instalación específica de Qt(TM), establece -DQT_QMAKE_EXECUTABLE=/ruta/a/qmake.

La generación de paquetes RPM está soportada por el archivo kid3.spec, para paquetes Debian®, ejecuta build.sh deb.

La aplicación Qt(TM) también se puede compilar para Windows® y macOS®. El script build.sh se puede utilizar para descargar y compilar todas las bibliotecas necesarias y crear un paquete Kid3.

Configuración

Con KDE, la configuración se almacena en .config/kid3rc, el estado de la aplicación en .local/share/kid3/kid3staterc. Como aplicación Qt(TM), este archivo está en .config/Kid3/Kid3.conf. En Windows®, la configuración se almacena en el registro. en macOS® en un archivo plist.

La variable de entorno KID3_CONFIG_FILE se puede usar para establecer la ruta del archivo de configuración.

En Linux®, se puede usar una interfaz D-Bus para controlar Kid3 mediante scripts. Los scripts se pueden escribir en cualquier idioma con enlaces D-Bus (por ejemplo, en Python) y se pueden añadir a las Acciones del Usuario para extender la funcionalidad de Kid3.

dbus-send --dest=org.kde.kid3 --print-reply=literal \

Ejemplos QML

Los scripts QML se pueden invocar a través del menú contextual de la lista de archivos y se pueden configurar en la pestaña Acciones del usuario del diálogo de configuración. Los scripts que se configuran allí pueden servir como ejemplos para programar scripts personalizados. QML utiliza JavaScript, aquí está el obligatorio "Hola Mundo":

import Kid3 1.0
Kid3Script {
  onRun: {
    console.log("Hola mundo, la carpeta es", app.dirName)
    Qt.quit()
  }
}

Si este script se guarda como /ruta/a/Ejemplo.qml, el comando del usuario se puede definir como @qml /ruta/a/Ejemplo.qml con el nombre Prueba QML y la salida marcada. Luego se puede iniciar utilizando el elemento Prueba QML en el menú contextual de la lista de archivos, y la salida será visible en la ventana.

Desafortunadamente, iniciar los scripts QML usando qml (por ejemplo, qml -apptype widget -I /usr/lib/kid3/plugins/imports /ruta/a/Ejemplo.qml) está roto en versiones recientes de Qt. Pero kid3-cli ofrece una forma alternativa de ejecutar un script QML desde la línea de comandos usando su comando execute.

kid3-cli -c "execute @qml /ruta/a/Ejemplo.qml"

Para listar los títulos en las etiquetas 2 de todos los archivos en la carpeta actual, se podría usar el siguiente script:

import Kid3 1.0
Kid3Script {
  onRun: {
    app.firstFile()
    do {
      if (app.selectionInfo.tag(Frame.Tag_2).tagFormat) {
        console.log(app.getFrame(tagv2, "title"))
      }
    } while (app.nextFile())
  }
}

Si la carpeta contiene muchos archivos, un script así podría bloquear la interfaz de usuario durante algún tiempo. Para operaciones largas, por lo tanto, debería tener un descanso de vez en cuando. La implementación alternativa a continuación tiene el trabajo para un solo archivo trasladado a una función. Esta función se invoca a sí misma con un tiempo de espera de 1 ms al final, dado que hay más archivos que procesar. Esto asegurará que la GUI permanezca receptiva mientras el script se ejecuta.

import Kid3 1.0
Kid3Script {
  onRun: {
    function doWork() {
      if (app.selectionInfo.tag(Frame.Tag_2).tagFormat) {
        console.log(app.getFrame(tagv2, "title"))
      }
      if (!app.nextFile()) {
        Qt.quit()
      } else {
        setTimeout(doWork, 1)
      }
    }
    app.firstFile()
    doWork()
  }
}

Al usar app.firstFile() con app.nextFile(), se procesarán todos los archivos de la carpeta actual. Si solo se deben afectar los archivos seleccionados, use firstFile() y nextFile() en su lugar, estas son funciones de conveniencia del componente Kid3Script. El siguiente ejemplo es un script que copia solo los marcos de número de disco y copyright de los archivos seleccionados.

import Kid3 1.1
Kid3Script {
  onRun: {
    function doWork() {
      if (app.selectionInfo.tag(Frame.Tag_2).tagFormat) {
        app.setFrame(tagv2, "*.selected", false)
        app.setFrame(tagv2, "discnumber.selected", true)
        app.setFrame(tagv2, "copyright.selected", true)
        app.copyTags(tagv2)
      }
      if (!nextFile()) {
        Qt.quit()
      } else {
        setTimeout(doWork, 1)
      }
    }
    firstFile()
    doWork()
  }
}
