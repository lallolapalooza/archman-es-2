NOMBRE

kubeadm token create - Crea tokens de arranque en el servidor

SINOPSIS

kubeadm token create [OPCIONES]

DESCRIPCIÓN

Este comando creará un token de arranque para ti. Puedes especificar los usos para este token, el "tiempo de vida" y una descripción opcional amigable para el humano.

El [token] es el token real a escribir. Este debe ser un token aleatorio generado de forma segura del formato "[a-z0-9]{6}.[a-z0-9]{16}". Si no se proporciona [token], kubeadm generará un token aleatorio.

OPCIONES

--certificate-key="" Cuando se usa junto con '--print-join-command', imprime el flag completo de 'kubeadm join' necesario para unir el clúster como un plano de control. Para crear una nueva clave de certificado, debes usar 'kubeadm init phase upload-certs --upload-certs'.

--config="" Ruta a un archivo de configuración de kubeadm.

--description="" Una descripción amigable para el humano de cómo se usa este token.

--groups=[system:bootstrappers:kubeadm:default-node-token] Grupos adicionales para los que se autenticará este token al ser utilizado para autenticación. Debe coincidir con "\Asystem:bootstrappers:[a-z0-9:-]{0,255}[a-z0-9]\z"

--print-join-command=false En lugar de imprimir solo el token, imprime el flag completo de 'kubeadm join' necesario para unir el clúster usando el token.

--ttl=24h0m0s La duración antes de que el token sea eliminado automáticamente (por ejemplo, 1s, 2m, 3h). Si se establece en '0', el token nunca expirará

--usages=[signing,authentication] Describe las formas en las que este token puede ser utilizado. Puedes pasar --usages varias veces o proporcionar una lista separada por comas de opciones. Opciones válidas: [signing,authentication]

OPCIONES HEREDADAS DE COMANDOS PADRE

--dry-run=false Si habilitar o no el modo de prueba

--kubeconfig="/etc/kubernetes/admin.conf" El archivo kubeconfig a usar al comunicarse con el clúster. Si el flag no está configurado, se pueden buscar en una serie de ubicaciones estándar archivos kubeconfig existentes.

--rootfs="" La ruta al sistema de archivos raíz 'real' del host. Esto hará que kubeadm realice un chroot en la ruta proporcionada.

--version=false --version, --version=raw imprime la información de la versión y sale; --version=vX.Y.Z... establece la versión reportada
