Nombre

kitten-notify - Notifica al usuario mediante una notificación de escritorio.

Descripción general

Este comando se utiliza para enviar una notificación de escritorio al usuario. Es una herramienta útil para informar al usuario sobre eventos o el final de tareas, sin interrumpir su flujo de trabajo. Puede ser invocado desde scripts o directamente en la terminal.

Código fuente para notify

El código fuente para esta funcionalidad se encuentra en el repositorio de Kitty, específicamente en los archivos relacionados con la extensión `notify`. Puedes encontrarlo en:

kitty/notify.py

Interfaz de línea de comandos

El comando `kitten-notify` se utiliza con la siguiente sintaxis básica:

kitten-notify [OPCIONES] "Título de la notificación" "Cuerpo de la notificación"

Algunas opciones comunes incluyen:

  • --icon ICONO: Especifica un icono para la notificación.
  • --action ACCIÓN: Define una acción que se puede realizar al hacer clic en la notificación.
  • --timeout SEGUNDOS: Establece el tiempo en segundos antes de que la notificación desaparezca automáticamente.
  • --urgency NIVEL: Establece el nivel de urgencia (low, normal, critical).

Por ejemplo, para enviar una notificación de advertencia:

kitten-notify --urgency critical "Tarea finalizada" "La compilación del proyecto ha concluido con éxito."
