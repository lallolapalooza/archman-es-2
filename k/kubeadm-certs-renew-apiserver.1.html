NOMBRE

kubeadm certs renew apiserver - Renueva el certificado para servir la API de Kubernetes

SINOPSIS

kubeadm certs renew apiserver [OPCIONES]

DESCRIPCIÓN

Renueva el certificado para servir la API de Kubernetes.

Las renovaciones se ejecutan incondicionalmente, independientemente de la fecha de expiración del certificado; los atributos adicionales como los SAN se basarán en el archivo/certificados existentes, no es necesario suministrarlos de nuevo.

La renovación intenta por defecto utilizar la autoridad certificadora en la PKI local gestionada por kubeadm; como alternativa es posible utilizar la API de certificados de K8s para la renovación del certificado, o como última opción, generar una solicitud CSR.

Después de la renovación, para que los cambios surtan efecto, se requiere reiniciar los componentes del plano de control y eventualmente redistribuir el certificado renovado en caso de que el archivo se utilice en otro lugar.

OPCIONES

--cert-dir="/etc/kubernetes/pki" La ruta donde guardar los certificados

--config="" Ruta a un archivo de configuración de kubeadm.

--kubeconfig="/etc/kubernetes/admin.conf" El archivo kubeconfig a usar al comunicarse con el clúster. Si la bandera no está establecida, se puede buscar en una serie de ubicaciones estándar un archivo kubeconfig existente.

OPCIONES HEREDADAS DE COMANDOS PADRE

--rootfs="" La ruta al sistema de archivos raíz 'real' del host. Esto hará que kubeadm realice un chroot en la ruta proporcionada.

--version=false --version, --version=raw imprime la información de versión y sale; --version=vX.Y.Z... establece la versión informada
