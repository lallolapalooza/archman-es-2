NOMBRE

k5identity - Reglas de selección de principal de cliente Kerberos V5

DESCRIPCIÓN

El archivo .k5identity, que reside en el directorio personal del usuario, contiene una lista de reglas para seleccionar un principal de cliente basado en el servidor al que se accede. Estas reglas se utilizan para elegir una caché de credenciales dentro de la colección de cachés cuando sea posible.

Las líneas en blanco y las líneas que comienzan con # se ignoran. Cada línea tiene el formato:

principal campo=valor ...

Si el principal del servidor cumple con todas las restricciones de campo, entonces se elige principal como el principal del cliente. Los siguientes campos son reconocidos:

realm
Si se conoce el reino del principal del servidor, se compara con valor, que puede ser un patrón que utiliza comodines de shell. Para principales de servidor basados en host, el reino generalmente solo se conocerá si hay una sección domain_realm en krb5.conf(5) con un mapeo para el nombre de host.
service
Si el principal del servidor es un principal basado en host, su componente de servicio se compara con valor, que puede ser un patrón que utiliza comodines de shell.
host
Si el principal del servidor es un principal basado en host, su componente de nombre de host se convierte a minúsculas y se compara con valor, que puede ser un patrón que utiliza comodines de shell.

Si el principal del servidor coincide con las restricciones de múltiples líneas en el archivo .k5identity, se utiliza el principal de la primera línea coincidente. Si ninguna línea coincide, las credenciales se seleccionarán de alguna otra manera, como la heurística del reino o la caché principal actual.

EJEMPLO

El siguiente ejemplo de archivo .k5identity selecciona el principal de cliente alice@KRBTEST.COM si el principal del servidor está dentro de ese reino, el principal alice/root@EXAMPLE.COM si el host del servidor está dentro de un subdominio de servidores, y el principal alice/mail@EXAMPLE.COM al acceder al servicio IMAP en mail.example.com:

alice@KRBTEST.COM       realm=KRBTEST.COM
alice/root@EXAMPLE.COM  host=*.servers.example.com
alice/mail@EXAMPLE.COM  host=mail.example.com service=imap
