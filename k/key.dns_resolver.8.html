key.dns_resolver(8)

Paquete: keyutils

Licencias: GPL2, LGPL2.1

KEY.DNS_RESOLVER(8) Utilidades de gestión de claves de Linux KEY.DNS_RESOLVER(8)

NOMBRE

key.dns_resolver - upcall para request-key para manejar claves dns_resolver

SINOPSIS

/sbin/key.dns_resolver <clave>
/sbin/key.dns_resolver --dump-config [-c <archivo de configuración>]
/sbin/key.dns_resolver -D [-v] [-v] [-c <archivo de configuración>] <descripción>
<información de llamada>

DESCRIPCIÓN

Este programa es invocado por request-key en nombre del kernel cuando los servicios del kernel (como NFS, CIFS y AFS) desean realizar una búsqueda de nombre de host y el kernel no tiene la clave en caché. No está destinado a ser llamado directamente.

Este programa tiene parámetros internos que pueden cambiarse con un archivo de configuración (ver key.dns_resolver.conf(5) para más información). El archivo de configuración predeterminado está en /etc, pero esto puede ser anulado con la bandera -c.

El programa puede ser llamado en modo de depuración para probar su funcionalidad pasando una bandera -D o --debug en la línea de comandos. Para que esto funcione, se deben proporcionar la descripción de la clave y la información de llamada. La verbosidad se puede aumentar proporcionando una o más banderas -v.

El programa también puede ser llamado con --dump-config para mostrar los valores que tendrán los parámetros configurables después de analizar el archivo de configuración.

ERRORES

Todos los errores se registrarán en syslog.

VER TAMBIÉN

key.dns_resolver.conf(5), request-key.conf(5), keyrings(7), request-key(8)
