KEEPASSXC-CLI(1) General Commands Manual KEEPASSXC-CLI(1)

NOMBRE

keepassxc-cli - interfaz de línea de comandos para el gestor de contraseñas KeePassXC

SINOPSIS

keepassxc-cli comando [opciones]

DESCRIPCIÓN

keepassxc-cli es la interfaz de línea de comandos para el gestor de contraseñas KeePassXC. Proporciona la capacidad de consultar y modificar las entradas de una base de datos KeePass, directamente desde la línea de comandos.

COMANDOS

add [opciones] <base_de_datos> <entrada>

Añade una nueva entrada a una base de datos. Se puede generar una contraseña (opción -g), o se puede mostrar un aviso para introducir la contraseña (opción -p). Se pueden usar las mismas opciones de generación de contraseñas que las documentadas para el comando generate cuando la opción -g está establecida.

analyze [opciones] <base_de_datos>

Analiza las contraseñas de una base de datos en busca de debilidades usando la búsqueda offline de hashes SHA-1 de HIBP.

attachment-export [opciones] <base_de_datos> <entrada> <nombre_del_adjunto> <archivo_de_exportación>

Exporta el contenido de un adjunto a un archivo especificado. Use la opción --stdout para, en su lugar, mostrar el contenido del adjunto en stdout.

attachment-import [opciones] <base_de_datos> <entrada> <nombre_del_adjunto> <archivo_de_importación>

Importa el adjunto a una entrada. Un adjunto existente con el mismo nombre puede ser sobrescrito si se especifica la opción -f.

attachment-rm <base_de_datos> <entrada> <nombre_del_adjunto>

Elimina el adjunto nombrado de una entrada.

clip [opciones] <base_de_datos> <entrada> [tiempo_de_espera]

Copia un atributo o el TOTP actual (si se especifica la opción -t) de una entrada de la base de datos al portapapeles. Si no se especifica ningún nombre de atributo usando la opción -a, se copia la contraseña. Si existen múltiples entradas con el mismo nombre en diferentes grupos, solo se copia el atributo de la primera. Para copiar el atributo de una entrada en un grupo específico, también se debe especificar la ruta del grupo a la entrada, en lugar de solo el nombre. Opcionalmente, se puede especificar un tiempo de espera en segundos para vaciar automáticamente el portapapeles; el tiempo de espera predeterminado es de 10 segundos, establézcalo en 0 para deshabilitarlo.

close

En modo interactivo, cierra la base de datos abierta actualmente (véase open).

db-create [opciones] <base_de_datos>

Crea una nueva base de datos con una contraseña y/o un archivo de clave. El archivo de clave se creará si el archivo al que se hace referencia no existe. Si tanto el archivo de clave como la contraseña están vacíos, no se creará ninguna base de datos.

db-edit [opciones] <base_de_datos>

Edita una base de datos. Al establecer un archivo de clave, el archivo de clave se creará si el archivo al que se hace referencia no existe.

db-info [opciones] <base_de_datos>

Muestra la información de una base de datos.

diceware [opciones]

Genera una frase de contraseña diceware aleatoria.

edit [opciones] <base_de_datos> <entrada>

Edita una entrada de la base de datos. Se puede generar una contraseña (opción -g), o se puede mostrar un aviso para introducir la contraseña (opción -p). Se pueden usar las mismas opciones de generación de contraseñas que las documentadas para el comando generate cuando la opción -g está establecida.

estimate [opciones] [contraseña]

Estima la entropía de una contraseña. La contraseña a estimar se puede proporcionar como argumento posicional, o usando la entrada estándar.

exit

Sale del modo interactivo. Sinónimo de quit.

export [opciones] <base_de_datos>

Exporta el contenido de una base de datos a la salida estándar en el formato especificado (por defecto XML).

generate [opciones]

Genera una contraseña aleatoria.

help [comando]

Muestra una lista de los comandos disponibles, o información detallada sobre el comando especificado.

import [opciones] <xml> <base_de_datos>

Importa el contenido de una base de datos exportada en XML a una base de datos recién creada con una contraseña y/o archivo de clave. El archivo de clave se creará si el archivo al que se hace referencia no existe. Si tanto el archivo de clave como la contraseña están vacíos, no se creará ninguna base de datos. La nueva base de datos estará en formato kdbx 4.

ls [opciones] <base_de_datos> [grupo]

Lista el contenido de un grupo en una base de datos. Si no se especifica ningún grupo, se usará por defecto el grupo raíz.

merge [opciones] <base_de_datos1> <base_de_datos2>

Fusiona dos bases de datos. El primer archivo de base de datos será reemplazado por el resultado de la fusión; por esa razón, es aconsejable mantener una copia de seguridad de los dos archivos de base de datos antes de intentar una fusión. En el caso de que ambas bases de datos usen las mismas credenciales, se puede usar la opción --same-credentials o -s.

mkdir [opciones] <base_de_datos> <grupo>

Añade un nuevo grupo a una base de datos.

mv [opciones] <base_de_datos> <entrada> <grupo>

Mueve una entrada a un nuevo grupo.

open [opciones] <base_de_datos>

Abre la base de datos dada en un modo interactivo estilo shell. Esto es útil para realizar múltiples operaciones en una sola base de datos (p. ej., ls seguido de show).

quit

Sale del modo interactivo. Sinónimo de exit.

rm [opciones] <base_de_datos> <entrada>

Elimina una entrada de una base de datos. Si la base de datos tiene una papelera de reciclaje, la entrada se moverá allí. Si la entrada ya está en la papelera de reciclaje, se eliminará permanentemente.

rmdir [opciones] <base_de_datos> <grupo>

Elimina un grupo de una base de datos. Si la base de datos tiene una papelera de reciclaje, el grupo se moverá allí. Si el grupo ya está en la papelera de reciclaje, se eliminará permanentemente.

search [opciones] <base_de_datos> <término>

Busca todas las entradas que coincidan con un término de búsqueda específico en una base de datos.

show [opciones] <base_de_datos> <entrada>

Muestra el título, el nombre de usuario, la contraseña, la URL y las notas de una entrada de la base de datos. También puede mostrar el TOTP actual. En cuanto a la aparición de múltiples entradas con el mismo nombre en diferentes grupos, todo lo indicado en la sección del comando clip también se aplica aquí.

OPCIONES

Opciones generales

--debug-info

Muestra información de depuración.

-k, --key-file <ruta>

Especifica una ruta a un archivo de clave para desbloquear la base de datos. En una operación de fusión, esta opción se utiliza para especificar la ruta del archivo de clave para la primera base de datos.

--no-password

Desactiva la clave de contraseña para la base de datos.

-y, --yubikey <ranura[:serie]>

Especifica una ranura de yubikey para desbloquear la base de datos. En una operación de fusión, esta opción se utiliza para especificar la ranura de YubiKey para la primera base de datos.

-q, --quiet <ruta>

Silencia el aviso de contraseña y otras salidas secundarias.

-h, --help

Muestra información de ayuda.

-v, --version

Muestra la versión del programa.

Opciones de fusión

-d, --dry-run <ruta>

Imprime los cambios detectados por la operación de fusión sin realizar ningún cambio en la base de datos.

--key-file-from <ruta>

Establece la ruta del archivo de clave para la segunda base de datos.

--no-password-from

Desactiva la clave de contraseña para la base de datos desde la que se fusiona.

--yubikey-from <ranura[:serie]>

Ranura de YubiKey para la segunda base de datos.

-s, --same-credentials

Utiliza las mismas credenciales para desbloquear ambas bases de datos.

Opciones de añadir y editar

Las mismas opciones de generación de contraseñas documentadas para el comando generate se pueden usar con estos 2 comandos cuando la opción -g está establecida.

-u, --username <nombre de usuario>

Especifica el nombre de usuario de la entrada.

--url <url>

Especifica la URL de la entrada.

--notes <notas>

Especifica las notas de la entrada.

-p, --password-prompt

Utiliza un aviso de contraseña para la contraseña de la entrada.

-g, --generate

Genera una nueva contraseña para la entrada.

Opciones de edición

-t, --title <título>

Especifica el título de la entrada.

Opciones de estimación

-a, --advanced

Realiza un análisis avanzado de la contraseña.

Opciones de análisis

-H, --hibp <nombre de archivo>

Comprueba si alguna contraseña se ha filtrado públicamente, comparándola con la lista dada de hashes SHA-1 de contraseñas, que debe estar en formato "Have I Been Pwned". Dichos archivos están disponibles en https://haveibeenpwned.com/Passwords; ten en cuenta que son grandes, por lo que esta operación normalmente tarda algún tiempo (de minutos hasta una hora aproximadamente).

--okon <ruta de okon-cli>

Utiliza el programa okon-cli especificado para realizar comprobaciones de filtraciones sin conexión. Puedes obtener okon-cli desde https://github.com/stryku/okon. Al usar esta opción, -H, --hibp debe apuntar a un archivo okon posprocesado (p. ej., file.okon).

Opciones de portapapeles

-a, --attribute

Copia el atributo especificado al portapapeles. Si no se especifica ningún atributo, el atributo de contraseña es el predeterminado. Por ejemplo, "-a username" copiaría el nombre de usuario al portapapeles. [Predeterminado: password]

-t, --totp

Copia el TOTP actual en lugar del atributo especificado al portapapeles. Informará un error si no hay ningún TOTP configurado para la entrada.

-b, --best

Intenta encontrar y copiar al portapapeles una entrada única que coincida con la entrada. Si se encuentra una entrada única coincidente, se copiará al portapapeles. Si se encuentran varias entradas, se listarán para refinar la búsqueda. (no se realiza copia)

Opciones de Db-create, Db-edit e Import

--set-key-file <ruta>

Establece el archivo de clave para la base de datos.

-p, --set-password

Establece una contraseña para la base de datos.

Opciones de Db-create e Import

-t, --decryption-time <tiempo>

Tiempo de descifrado objetivo en MS para la base de datos.

Opciones de Db-edit

--unset-password <ruta>

Elimina la contraseña de la base de datos.

--unset-key-file <ruta>

Elimina el archivo de clave de la base de datos.

Opciones de visualización

-a, --attributes <atributo>...

Muestra los atributos nombrados. Esta opción se puede especificar más de una vez, mostrando cada atributo uno por línea en el orden dado. Si no se especifican atributos y -t no se especifica, se muestra un resumen de los atributos predeterminados. Los atributos protegidos se mostrarán en texto claro si se especifican explícitamente mediante esta opción.

--all

Muestra todos los atributos de la entrada.

-s, --show-protected

Muestra los atributos protegidos en texto claro.

--show-attachments

Muestra los nombres de los adjuntos junto con el tamaño de los adjuntos.

-t, --totp

También muestra el TOTP actual, informando un error si no hay ningún TOTP configurado para la entrada.

Opciones de Diceware

-W, --words <cantidad>

Establece el número deseado de palabras para la frase de contraseña generada. [Predeterminado: 7]

-w, --word-list <ruta>

Establece la ruta de la lista de palabras para el generador diceware. La lista de palabras debe tener > 1000 palabras; de lo contrario, el programa fallará. Si la lista de palabras tiene < 4000 palabras, se imprimirá una advertencia en STDERR. Se puede usar cualquier lista de palabras compatible con diceware. Ten en cuenta, sin embargo, que KeePassXC NO verificará la firma PGP de las listas de palabras firmadas.

Opciones de exportación

-f, --format

Formato a usar al exportar. Las opciones disponibles son xml o csv. El valor predeterminado es xml.

Opciones de listado

-R, --recursive

Lista recursivamente los elementos del grupo.

-f, --flatten

Aplana la salida a líneas individuales. Cuando esta opción está habilitada, los subgrupos y subentradas se mostrarán con una ruta de grupo relativa en lugar de sangría.

Opciones de generación

-L, --length <longitud>

Establece la longitud deseada para la contraseña generada. [Predeterminado: 16]

-l, --lower

Utiliza caracteres en minúscula para la contraseña generada. [Predeterminado: Habilitado]

-U, --upper

Utiliza caracteres en mayúscula para la contraseña generada. [Predeterminado: Habilitado]

-n, --numeric

Utiliza caracteres numéricos para la contraseña generada. [Predeterminado: Habilitado]

-s, --special

Utiliza caracteres especiales para la contraseña generada. [Predeterminado: Deshabilitado]

-e, --extended

Utiliza caracteres ASCII extendidos para la contraseña generada. [Predeterminado: Deshabilitado]

-x, --exclude <caracteres>

Lista separada por comas de caracteres a excluir de la contraseña generada. Ninguno se excluye de forma predeterminada.

--exclude-similar

Excluye caracteres de aspecto similar. [Predeterminado: Deshabilitado]

--every-group

Incluye caracteres de cada grupo seleccionado. [Predeterminado: Deshabilitado]
