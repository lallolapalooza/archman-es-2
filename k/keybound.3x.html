NOMBRE

keybound - obtener definición de código de tecla de curses

SINOPSIS

#include <curses.h>
char * keybound(int keycode, int count);

DESCRIPCIÓN

Esta es una extensión de la biblioteca curses. Permite a una aplicación determinar la cadena que está definida en terminfo para códigos de tecla específicos.

VALOR DE RETORNO

El parámetro keycode debe ser mayor que cero, de lo contrario se devuelve NULL. Si no corresponde a una tecla definida, se devuelve NULL. El parámetro count se utiliza para permitir que la aplicación itere a través de múltiples definiciones, contando desde cero. Cuando tiene éxito, la función devuelve una cadena que debe ser liberada por el llamador.

PORTABILIDAD

Esta rutina es específica de ncurses. No fue compatible con las implementaciones de la Versión 7, BSD o System V. Se recomienda que el código que dependa de ellas se condicione usando NCURSES_VERSION.
