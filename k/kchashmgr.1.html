NOMBRE

kchashmgr - interfaz de línea de comandos para gestionar la base de datos hash de archivos

DESCRIPCIÓN

El comando `kchashmgr' es una utilidad para probar y depurar la base de datos hash de archivos y sus aplicaciones. `ruta' especifica la ruta de un archivo de base de datos. `clave' especifica la clave de un registro. `valor' especifica el valor de un registro. `archivo' especifica el archivo de entrada/salida.


kchashmgr create [-otr] [-onl|-otl|-onr] [-apow num] [-fpow num] [-ts] [-tl] [-tc] [-bnum num] ruta
Crea un archivo de base de datos.
kchashmgr inform [-onl|-otl|-onr] [-st] ruta
Muestra información de estado.
kchashmgr set [-onl|-otl|-onr] [-add|-app|-rep|-inci|-incd] [-sx] ruta clave valor
Almacena un registro.
kchashmgr remove [-onl|-otl|-onr] [-sx] ruta clave
Elimina un registro.
kchashmgr get [-onl|-otl|-onr] [-rm] [-sx] [-px] [-pz] ruta clave
Muestra el valor de un registro.
kchashmgr list [-onl|-otl|-onr] [-max num] [-rm] [-sx] [-pv] [-px] ruta [clave]
Muestra las claves de todos los registros, separadas por saltos de línea.
kchashmgr clear [-onl|-otl|-onr] ruta
Elimina todos los registros de una base de datos.
kchashmgr import [-onl|-otl|-onr] [-sx] ruta [archivo]
Importa registros desde un archivo TSV.
kchashmgr copy [-onl|-otl|-onr] ruta archivo
Copia la base de datos completa.
kchashmgr dump [-onl|-otl|-onr] ruta [archivo]
Vuelca registros en un archivo de instantánea.
kchashmgr load [-otr] [-onl|-otl|-onr] ruta [archivo]
Carga registros desde un archivo de instantánea.
kchashmgr defrag [-onl|-otl|-onr] ruta
Realiza la desfragmentación.
kchashmgr setbulk [-onl|-otl|-onr] ruta clave valor ...
Almacena registros a la vez.
kchashmgr removebulk [-onl|-otl|-onr] [-sx] ruta clave ...
Elimina registros a la vez.
kchashmgr getbulk [-onl|-otl|-onr] [-sx] [-px] ruta clave ...
Recupera registros a la vez.
kchashmgr check [-onl|-otl|-onr] ruta
Comprueba la consistencia.

Las opciones incluyen lo siguiente.

-otr : abre la base de datos con la opción de truncamiento.
-onl : abre la base de datos con la opción de sin bloqueo.
-otl : abre la base de datos con la opción de intentar bloqueo.
-onr : abre la base de datos con la opción de sin reparación automática.
-apow num : especifica la potencia de la alineación del tamaño del registro.
-fpow num : especifica la potencia de la capacidad del grupo de bloques libres.
-ts : ajusta la base de datos con la opción pequeña.
-tl : ajusta la base de datos con la opción lineal.
-tc : ajusta la base de datos con la opción de compresión.
-bnum num : especifica el número de cubetas de la tabla hash.
-st : muestra información miscelánea.
-add : realiza la operación de añadir.
-app : realiza la operación de añadir al final.
-rep : realiza la operación de reemplazar.
-inci : realiza la operación de incremento entero.
-incd : realiza la operación de incremento de número real.
-sx : los datos de entrada se evalúan como una cadena de datos hexadecimal.
-rm : elimina el registro.
-px : los datos de salida se convierten en una cadena de datos hexadecimal.
-pz : no añade un salto de línea al final de la salida.
-max num : especifica el número máximo de registros mostrados.
-pv : muestra también los valores de los registros.

Este comando devuelve 0 en caso de éxito y otro valor en caso de fallo.
