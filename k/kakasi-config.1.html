NOMBRE

kakasi-config - script para obtener información sobre la versión instalada de KAKASI

SINOPSIS

kakasi-config [--prefix[=DIR]] [--exec-prefix[=DIR]] [--help] [--version] [--libs] [--cflags]

DESCRIPCIÓN

kakasi-config es una herramienta que se utiliza para configurar y determinar los indicadores del compilador y enlazador que deben usarse para compilar y enlazar programas que utilizan KAKASI. También se utiliza internamente en las macros .m4 para GNU autoconf que se incluyen con KAKASI.

OPCIONES

kakasi-config acepta las siguientes opciones:
--help
Imprime el texto de ayuda y sale.
--version
Imprime la versión actualmente instalada de KAKASI en la salida estándar.
--libs
Imprime los indicadores del enlazador que son necesarios para enlazar un programa de KAKASI.
--cflags
Imprime los indicadores del compilador que son necesarios para compilar un programa de KAKASI.
--prefix=PREFIJO
Si se especifica, utiliza PREFIJO en lugar del prefijo de instalación con el que se compiló KAKASI al calcular la salida para las opciones --cflags y --libs. Esta opción también se utiliza para el prefijo de ejecución si --exec-prefix no fue especificado. Esta opción debe especificarse antes que cualquier opción --libs o --cflags.
--exec-prefix=PREFIJO
Si se especifica, utiliza PREFIJO en lugar del prefijo de ejecución de instalación con el que se compiló GTK+ al calcular la salida para las opciones --cflags y --libs. Esta opción debe especificarse antes que cualquier opción --libs o --cflags.
