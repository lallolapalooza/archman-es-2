NOMBRE

killpg — enviar una señal a un grupo de procesos

SINOPSIS

#include <signal.h>
int killpg(pid_t pgrp, int sig);

DESCRIPCIÓN

La función killpg() enviará la señal especificada por sig al grupo de procesos especificado por pgrp.

Si pgrp es mayor que 1, killpg(pgrp, sig) será equivalente a kill(-pgrp, sig). Si pgrp es menor o igual que 1, el comportamiento de killpg() es indefinido.

VALOR DE RETORNO

Consulte kill().

EJEMPLOS

Enviar una señal a todos los demás miembros de un grupo de procesos

El siguiente ejemplo muestra cómo el proceso que llama podría enviar una señal a todos los demás miembros de su grupo de procesos. Para evitar recibir él mismo la señal, primero se vuelve inmune a la señal ignorándola.

#include <signal.h>
#include <unistd.h>
...
    if (signal(SIGUSR1, SIG_IGN) == SIG_ERR)
        /* Manejar error */;
    if (killpg(getpgrp(), SIGUSR1) == -1)
        /* Manejar error */;
