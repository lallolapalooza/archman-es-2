NOMBRE

kateenc - crea flujos Kate a partir de entrada de texto

SINOPSIS

kateenc [-hVM] [-o archivo_salida] [-l idioma] [-c categoría] [-s serie] [-C etiqueta=valor] [-R umbral] [-K umbral] -t tipo_archivo [ archivo_entrada ]

DESCRIPCIÓN

kateenc crea flujos Kate a partir de archivos de entrada (subtítulos SubRip SRT, letras LRC e idioma de descripción personalizado de libkate). Cuando se guarda en un flujo Ogg (el comportamiento predeterminado), un flujo Kate puede fusionarse con otros flujos Ogg (por ejemplo, un video Theora) utilizando las herramientas oggz.

OPCIONES

-h
Muestra la ayuda de la línea de comandos.
-V
Muestra información de la versión.
-M
Permite marcado simple similar a HTML en archivos SRT. Si se usa este parámetro, las cadenas como "<i>" se interpretarán como cursiva, en lugar de aparecer como tales. Tenga en cuenta que varios reproductores interpretan un conjunto ligeramente diferente de etiquetas HTML, y algunos no.
-o archivo_salida
Escribe el flujo Kate de salida en el nombre de archivo dado (escribe en stdout si no se especifica).
-l idioma
Establece el idioma para el flujo (el predeterminado es el idioma especificado en la entrada, o ninguno).
-c categoría
Establece la categoría para el flujo (el predeterminado es la categoría especificada en la entrada, o ninguna).
-s serie
Establece el número de serie para el flujo Kate de salida (no se aplica a flujos brutos).
-C etiqueta=valor
Agrega un comentario para codificar en el flujo Kate de salida. El comentario debe tener el formato etiqueta=valor y cumplir con las reglas de comentarios Vorbis (por ejemplo, la etiqueta está compuesta por un subconjunto particular de caracteres ASCII y el valor es UTF-8 válido). Tenga en cuenta que es posible que deba escapar o citar el comentario para que se vea como un solo parámetro de línea de comandos.
-t tipo_archivo
Especifica el tipo de la entrada (srt, lrc, kate)
-R umbral
Utiliza paquetes de repetición, con el umbral dado (en segundos). Los paquetes de datos se repetirán a intervalos de aproximadamente `umbral` segundos, mientras estén activos.
-K umbral
Utiliza paquetes de mantenimiento, con el umbral dado (en segundos). Los paquetes de mantenimiento se emitirán cuando no se haya emitido ningún otro paquete durante aproximadamente `umbral` segundos.

EJEMPLOS

Crea un flujo Kate para subtítulos en galés a partir de un archivo SubRip:


kateenc -t srt -l cy -c SUB -o salida.ogg entrada.srt
