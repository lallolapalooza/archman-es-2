Nombre

kitten-themes - Gestiona temas de color de kitty fácilmente

Descripción general

El kitten de temas permite cambiar fácilmente los esquemas de color, de una colección de más de trescientos temas preconstruidos disponibles en kitty-themes https://github.com/kovidgoyal/kitty-themes. Para usarlo, simplemente ejecuta:

kitten themes

El kitten permite elegir un tema, con vistas previas en vivo de los colores. Puedes elegir entre temas claros y oscuros y buscar por nombre de tema simplemente escribiendo unos pocos caracteres del nombre.

El kitten mantiene una lista de temas usados recientemente para permitir un cambio rápido.

Si quieres restaurar los colores a los predeterminados, puedes hacerlo eligiendo el tema Default.

Añadido en la versión 0.23.0: El kitten de temas

Cómo funciona

Un tema en kitty es solo un archivo .conf que contiene configuraciones de kitty. Cuando seleccionas un tema, el kitten simplemente copia el archivo .conf a ~/.config/kitty/current-theme.conf y añade una inclusión para current-theme.conf a kitty.conf. También comenta cualquier configuración de color existente en kitty.conf para que no interfiera.

Una vez hecho esto, el kitten envía una señal a kitty para que recargue su configuración.

Nota:

Si quieres tener algunas configuraciones de color en tu kitty.conf que el kitten de temas no anule, muévelas a un archivo conf separado e inclúyelo en kitty.conf. La inclusión debe colocarse después de la inclusión de current-theme.conf para que la configuración en él anule las configuraciones conflictivas de current-theme.conf.

Cambiar los temas de color automáticamente cuando el SO cambia entre claro y oscuro

Añadido en la versión 0.38.0.

Puedes hacer que kitty cambie automáticamente su tema de color cuando el SO cambia entre los modos oscuro, claro y sin preferencia. Para hacer esto, ejecuta el kitten de temas como de costumbre y en la pantalla final selecciona la opción para guardar tu tema elegido como claro, oscuro o sin preferencia. Repite hasta que hayas elegido un tema para cada uno de los tres modos. Luego, una vez que reinicies kitty, usará automáticamente tus temas elegidos dependiendo del esquema de color del SO.

Esto funciona creando tres archivos: dark-theme.auto.conf, light-theme.auto.conf y no-preference-theme.auto.conf en el directorio de configuración de kitty. Cuando estos archivos existen, kitty consulta al SO su esquema de color y usa el archivo apropiado. Ten en cuenta que los colores en estos archivos anulan todos los demás colores, y también todas las configuraciones de imagen de fondo, incluso aquellas especificadas usando el flag de línea de comandos kitty --override <#cmdoption-kitty-override>. kitty también cambiará automáticamente los colores cuando cambie el esquema de color del SO, por ejemplo, durante transiciones de noche/día.

Al usar estos colores, aún puedes cambiar los colores dinámicamente, pero la próxima vez que el SO cambie su modo de color, cualquier cambio dinámico se anulará.

Nota:

En el escritorio GNOME, el escritorio informa la preferencia de color como sin preferencia cuando el "Estilo oscuro" no está activado. Así que usa no-preference-theme.auto.conf para seleccionar colores para el modo claro en GNOME. Puedes habilitar manualmente el estilo claro con gsettings set org.gnome.desktop.interface color-scheme prefer-light, en cuyo caso GNOME informará el esquema de color como claro y kitty usará light-theme.auto.conf.

Usando tus propios temas

También puedes crear tus propios temas como archivos .conf. Ponlos en el subdirectorio themes del directorio de configuración de kitty <#confloc>, usualmente, ~/.config/kitty/themes. El kitten los añadirá automáticamente a la lista de temas. Puedes usar esto para modificar los temas incorporados, dando al archivo conf el nombre Nombre de tema.conf para anular el tema incorporado de ese nombre. Aquí, Nombre de tema es el nombre real del tema incorporado, no su nombre de archivo. Ten en cuenta que después de hacer esto, tienes que ejecutar el kitten y elegir ese tema una vez para que tus cambios se apliquen.

Contribuyendo con nuevos temas

Si deseas contribuir con un nuevo tema al repositorio de temas de kitty, comienza por ir al repositorio de kitty-themes https://github.com/kovidgoyal/kitty-themes. Haz un fork https://docs.github.com/en/get-started/quickstart/fork-a-repo, y usa el archivo template.conf como plantilla al crear tu tema. Una vez que estés satisfecho con cómo se ve, envía una pull request https://docs.github.com/en/pull-requests/collaborating-with-pull-requests/proposing-changes-to-your-work-with-pull-requests/creating-a-pull-request para que tu tema se fusione en el repositorio de kitty-themes https://github.com/kovidgoyal/kitty-themes, lo que lo hará disponible en este kitten automáticamente.

Cambiando el tema de forma no interactiva

Puedes especificar el nombre del tema como un argumento al invocar el kitten para que cambie a ese tema instantáneamente. Por ejemplo:

kitten themes --reload-in=all Dimmed Monokai

Cambiará el tema a Dimmed Monokai en todas las instancias de kitty en ejecución. Ver más abajo para más detalles sobre la operación no interactiva.

Código fuente de los temas

El código fuente de este kitten está disponible en GitHub https://github.com/kovidgoyal/kitty/tree/master/kittens/themes.

Interfaz de línea de comandos

kitten themes [opciones] [nombre del tema al que cambiar]

Cambia el tema de kitty. Si no se proporciona ningún nombre de tema, se ejecuta interactivamente, de lo contrario, cambia el tema actual al nombre de tema especificado.

Opciones

--cache-age <TIEMPO_CACHE>
Comprueba si hay nuevos temas solo después del número especificado de días. Un valor de cero siempre buscará nuevos temas. Un valor negativo nunca buscará nuevos temas, sino que generará un error si no hay una copia local de los temas disponible. Por defecto: 1
--reload-in <RECARGAR_EN>
Por defecto, este kitten solo señalará a la instancia padre de kitty en la que se está ejecutando para que recargue su configuración, después de realizar cambios. Usa esta opción para, en su lugar, no recargar la configuración o hacerlo en todas las instancias de kitty en ejecución. Por defecto: parent Opciones: all, none, parent
--dump-theme [=no]
Al ejecutarse de forma no interactiva, vuelca el tema especificado a STDOUT en lugar de cambiar kitty.conf. Por defecto: false
--config-file-name <NOMBRE_ARCHIVO_CONFIG>
El nombre o ruta del archivo de configuración a editar. Las rutas relativas se interpretan con respecto al directorio de configuración de kitty. Por defecto, se edita el archivo de configuración de kitty, kitty.conf. Esto es más útil si agregas include themes.conf a tu kitty.conf y luego haces que el kitten opere solo en themes.conf, permitiendo que kitty.conf permanezca sin cambios. Por defecto: kitty.conf
