Nombre

kitten-@-action - Ejecutar la acción mapeable especificada

Uso

kitten @ action ACCIÓN [ARGUMENTOS PARA ACCIÓN...]

Descripción

Ejecuta la acción mapeable especificada. Para obtener una lista de todas las acciones mapeables disponibles, consulta actions(1). Cualquier argumento para ACCIÓN debe seguir a la acción. Ten en cuenta que el análisis de los argumentos depende de la acción, por lo que para obtener los mejores resultados, especifica todos los argumentos como una cadena única en la línea de comandos, en el mismo formato que usarías para esa acción en kitty.conf.

Opciones

--self [=no]
Ejecuta la acción en la ventana donde se ejecuta este comando en lugar de la ventana activa.
--no-response [=no]
No esperes una respuesta que indique el éxito de la acción. Ten en cuenta que al usar esta opción, no se te notificará de los fallos.
--match, -m
La ventana a comparar. Las especificaciones de ventana son del tipo: campo:consulta. Donde campo puede ser uno de: id, title, pid, cwd, cmdline, num, env, var, state, neighbor, session y recent. consulta es la expresión a comparar. Las expresiones pueden ser un número o una expresión regular, y se pueden combinar usando operadores booleanos.

El valor especial all compara todas las ventanas.

Para los campos numéricos: id, pid, num y recent, la expresión se interpreta como un número, no como una expresión regular. Los valores negativos para id comparan desde el número de id más alto hacia abajo, en particular, -1 es la ventana creada más recientemente.

El campo num se refiere a la posición de la ventana en la pestaña actual, comenzando desde cero y contando en sentido horario (este es el mismo orden en que las ventanas se informan por el comando kitten @ ls).

El id de ventana de la ventana actual está disponible como la variable de entorno KITTY_WINDOW_ID.

El campo recent se refiere a las ventanas activas recientemente en la pestaña activa actual, donde cero es la ventana activa actual, uno es la ventana activa anterior y así sucesivamente.

El campo neighbor se refiere a un vecino de la ventana activa en la dirección especificada, que puede ser: left, right, top o bottom.

El campo session compara las ventanas que fueron creadas en la sesión especificada. Usa la expresión ^$ para comparar ventanas que no fueron creadas en una sesión y . para comparar la sesión activa actual y ~ para comparar la sesión activa actual o la última sesión activa cuando no hay ninguna sesión activa.

Al usar el campo env para comparar variables de entorno, puedes especificar solo el nombre de la variable de entorno o un nombre y valor, por ejemplo, env:MY_ENV_VAR=2.

De manera similar, el campo var compara las variables de usuario establecidas en la ventana. Puedes especificar nombre o nombre y valor como con el campo env.

El campo state compara el estado de la ventana. Los estados soportados son: active, focused, needs_attention, parent_active, parent_focused, focused_os_window, self, overlay_parent. Las ventanas activas son las ventanas que están activas en su pestaña padre. Solo hay una ventana enfocada y es la ventana a la que se entregan los eventos del teclado. Si no hay ninguna ventana enfocada, se compara la última ventana enfocada. El valor focused_os_window compara todas las ventanas en la ventana del sistema operativo enfocada actualmente. El valor self compara la ventana en la que se ejecuta el comando de control remoto. El valor overlay_parent compara la ventana que está debajo de la ventana self, cuando la ventana self es una superposición.

Ten en cuenta que puedes usar el comando kitten @ ls para obtener una lista de ventanas.

--help, -h [=no]
Muestra la ayuda para este comando

Opciones globales

--to
Una dirección para la instancia de kitty a controlar. Corresponde a la dirección dada a la instancia de kitty a través de la opción --listen-on o el ajuste listen_on en kitty.conf. Si no se especifica, se consulta la variable de entorno KITTY_LISTEN_ON. Si tampoco se encuentra, los mensajes se envían a la terminal de control para este proceso, es decir, solo funcionarán si este proceso se ejecuta dentro de una ventana de kitty.
--password
Una contraseña para usar al contactar kitty. Esto hará que kitty solicite al usuario permiso para realizar la acción especificada, a menos que la contraseña haya sido aceptada previamente o esté preconfigurada en kitty.conf. Para usar una contraseña en blanco, especifica --use-password como siempre.
--password-file [=rc-pass]
Un archivo del cual leer la contraseña. Los espacios en blanco al final se ignoran. Las rutas relativas se resuelven desde el directorio de configuración de kitty. Usa - para leer desde STDIN. Usa fd:num para leer desde el descriptor de archivo num. Se usa si no se proporciona --password. Por defecto, comprueba el archivo rc-pass en el directorio de configuración de kitty.
--password-env [=KITTY_RC_PASSWORD]
El nombre de una variable de entorno de la cual leer la contraseña. Se usa si no se proporciona --password-file. Por defecto, comprueba la variable de entorno KITTY_RC_PASSWORD.
--use-password [=if-available]
Si no hay contraseña disponible, kitty normalmente enviará el comando de control remoto sin contraseña. Esta opción se puede usar para forzar a usar siempre o nunca la contraseña proporcionada. Si se establece en always y no se proporciona ninguna contraseña, se utiliza la contraseña en blanco.

Opciones: if-available, always, never
