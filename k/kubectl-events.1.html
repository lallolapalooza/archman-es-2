NOMBRE

kubectl events - Listar eventos

SINOPSIS

kubectl events [OPCIONES]

DESCRIPCIÓN

Muestra los eventos.

Imprime una tabla con la información más importante sobre los eventos. Puedes solicitar eventos para un namespace, para todos los namespaces, o filtrarlos para que solo pertenezcan a un recurso especificado.

OPCIONES

-A, --all-namespaces=false Si está presente, lista los objetos solicitados en todos los namespaces. El namespace en el contexto actual se ignora incluso si se especifica con --namespace.

--allow-missing-template-keys=true Si es verdadero, ignora cualquier error en las plantillas cuando falta un campo o una clave de mapa en la plantilla. Solo se aplica a los formatos de salida go-template y jsonpath.

--chunk-size=500 Devuelve listas grandes en fragmentos en lugar de todo a la vez. Pasa 0 para deshabilitar. Esta opción es beta y podría cambiar en el futuro.

--for="" Filtra los eventos para que solo pertenezcan al recurso especificado.

--no-headers=false Al usar el formato de salida predeterminado, no imprime encabezados.

-o, --output="" Formato de salida. Uno de: (json, yaml, name, go-template, go-template-file, template, templatefile, jsonpath, jsonpath-as-json, jsonpath-file).

--show-managed-fields=false Si es verdadero, conserva los managedFields al imprimir objetos en formato JSON o YAML.

--template="" Cadena de plantilla o ruta a un archivo de plantilla a utilizar cuando -o=go-template, -o=go-template-file. El formato de plantilla es de plantillas de golang [http://golang.org/pkg/text/template/#pkg-overview].

--types=[] Muestra solo eventos de los tipos dados.

-w, --watch=false Después de listar los eventos solicitados, espera más eventos.

OPCIONES HEREDADAS DE COMANDOS PADRE

--as="" Nombre de usuario a suplantar para la operación. El usuario podría ser un usuario regular o una cuenta de servicio en un namespace.

--as-group=[] Grupo a suplantar para la operación, este flag se puede repetir para especificar varios grupos.

--as-uid="" UID a suplantar para la operación.

--cache-dir="/home/username/.kube/cache" Directorio de caché predeterminado

--certificate-authority="" Ruta a un archivo de certificado para la autoridad de certificación

--client-certificate="" Ruta a un archivo de certificado de cliente para TLS

--client-key="" Ruta a un archivo de clave de cliente para TLS

--cluster="" El nombre del clúster de kubeconfig a utilizar

--context="" El nombre del contexto de kubeconfig a utilizar

--disable-compression=false Si es verdadero, se opta por no comprimir las respuestas para todas las solicitudes al servidor

--insecure-skip-tls-verify=false Si es verdadero, el certificado del servidor no se verificará en cuanto a su validez. Esto hará que tus conexiones HTTPS no sean seguras

--kubeconfig="" Ruta al archivo kubeconfig a utilizar para las solicitudes CLI.

--kuberc="" Ruta al archivo kuberc a utilizar para las preferencias. Esto puede deshabilitarse exportando la puerta de enlace de funciones KUBECTL_KUBERC=false o desactivando la función KUBERC=off.

--match-server-version=false Requiere que la versión del servidor coincida con la versión del cliente

-n, --namespace="" Si está presente, el ámbito del namespace para esta solicitud CLI

--password="" Contraseña para la autenticación básica al servidor API

--profile="none" Nombre del perfil a capturar. Uno de (none|cpu|heap|goroutine|threadcreate|block|mutex)

--profile-output="profile.pprof" Nombre del archivo donde escribir el perfil

--request-timeout="0" La cantidad de tiempo a esperar antes de desistir en una única solicitud al servidor. Los valores distintos de cero deben contener una unidad de tiempo correspondiente (por ejemplo, 1s, 2m, 3h). Un valor de cero significa no agotar el tiempo de espera de las solicitudes.

-s, --server="" La dirección y el puerto del servidor API de Kubernetes

--tls-server-name="" Nombre del servidor a usar para la validación del certificado del servidor. Si no se proporciona, se usa el nombre de host utilizado para contactar al servidor

--token="" Token Bearer para la autenticación al servidor API

--user="" El nombre del usuario de kubeconfig a utilizar

--username="" Nombre de usuario para la autenticación básica al servidor API

--version=false --version, --version=raw imprime la información de la versión y sale; --version=vX.Y.Z... establece la versión informada

--warnings-as-errors=false Trata las advertencias recibidas del servidor como errores y sale con un código de salida distinto de cero

EJEMPLO

  # Listar eventos recientes en el namespace predeterminado
  kubectl events
  # Listar eventos recientes en todos los namespaces
  kubectl events --all-namespaces
  # Listar eventos recientes para el pod especificado, luego esperar más eventos y listarlos a medida que llegan
  kubectl events --for pod/web-pod-13je7 --watch
  # Listar eventos recientes en formato YAML
  kubectl events -oyaml
  # Listar solo eventos recientes de tipo 'Warning' o 'Normal'
  kubectl events --types=Warning,Normal
