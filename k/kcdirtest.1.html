NOMBRE

kcdirtest - interfaz de línea de comandos para probar la base de datos hash de directorios

DESCRIPCIÓN

El comando `kcdirtest' es una utilidad para pruebas de facilidad y pruebas de rendimiento de la base de datos hash de directorios. Este comando se utiliza en el siguiente formato. `path' especifica la ruta de un archivo de base de datos. `rnum' especifica el número de iteraciones.


kcdirtest order [-th num] [-rnd] [-set|-get|-getw|-rem|-etc] [-tran] [-oat|-onl|-onl|-otl|-onr] [-tc] [-lv] path rnum
Realiza pruebas en orden.
kcdirtest queue [-th num] [-it num] [-rnd] [-oat|-onl|-onl|-otl|-onr] [-tc] [-lv] path rnum
Realiza operaciones de cola.
kcdirtest wicked [-th num] [-it num] [-oat|-onl|-onl|-otl|-onr] [-tc] [-lv] path rnum
Realiza operaciones mixtas seleccionadas al azar.
kcdirtest tran [-th num] [-it num] [-hard] [-oat|-onl|-onl|-otl|-onr] [-tc] [-lv] path rnum
Realiza pruebas de transacción.

Las opciones incluyen lo siguiente.

-th num : especifica el número de hilos de trabajo.
-rnd : realiza pruebas aleatorias.
-set : realiza solo la operación de establecimiento.
-get : realiza solo la operación de obtención.
-getw : realiza solo la operación de obtención con búfer.
-rem : realiza solo la operación de eliminación.
-etc : realiza operaciones misceláneas.
-tran : realiza transacciones.
-oat : abre la base de datos con la opción de transacción automática.
-oas : abre la base de datos con la opción de sincronización automática.
-onl : abre la base de datos con la opción de sin bloqueo.
-otl : abre la base de datos con la opción de intento de bloqueo.
-onr : abre la base de datos con la opción de sin reparación automática.
-tc : ajusta la base de datos con la opción de compresión.
-lv : informa de todos los errores.
-it num : especifica el número de repeticiones.
-hard : realiza sincronización física.

Este comando devuelve 0 si tiene éxito, y otro valor si falla.
