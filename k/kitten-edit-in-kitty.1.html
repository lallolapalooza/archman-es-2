Nombre

kitten-edit-in-kitty - Editar un archivo en una ventana superpuesta de kitty

Uso

kitten edit-in-kitty [opciones] archivo-a-editar

Descripción

Edita el archivo especificado en una ventana superpuesta de kitty. Funciona también sobre SSH.

Para instrucciones de uso, consulte: https://sw.kovidgoyal.net/kitty/shell-integration/#edit-file

Opciones

--título, --título-de-ventana
El título que se establecerá para la nueva ventana. Por defecto, el título es controlado por el proceso hijo. El valor especial current copiará el título de la ventana fuente (--source-window).
--título-de-pestaña
El título para la nueva pestaña si se lanza en una nueva pestaña. Por defecto, el título de la ventana activa en la pestaña se utiliza como título de pestaña. El valor especial current copiará el título de la pestaña que contiene la ventana fuente (--source-window).
--tipo [=ventana]
Dónde lanzar el proceso hijo:

ventana
Una nueva ventana de kitty en la pestaña actual

pestaña
Una nueva pestaña en la ventana del sistema operativo actual. No disponible cuando se utiliza el comando de lanzamiento <launch> en sesiones de inicio.

ventana-os
Una nueva ventana del sistema operativo. No disponible cuando se utiliza el comando de lanzamiento <launch> en sesiones de inicio.

superpuesta
Una ventana superpuesta que cubre la ventana activa actual de kitty

superpuesta-principal
Una ventana superpuesta que cubre la ventana activa actual de kitty. A diferencia de una ventana superpuesta normal, esta ventana se considera una ventana principal, lo que significa que se utiliza como ventana activa para obtener el directorio de trabajo actual, el texto de entrada para los kittens, los comandos de lanzamiento, etc. Útil si esta superposición está pensada para ejecutarse durante mucho tiempo como ventana principal.

fondo
El proceso se ejecutará en segundo plano, sin ventana de kitty. Tenga en cuenta que si se especifica --permitir-control-remoto, la variable de entorno KITTY_LISTEN_ON se establecerá en un descriptor de archivo de par de sockets dedicado que el proceso puede usar para control remoto.

portapapeles, primario
Estos dos están diseñados para funcionar con --fuente-de-entrada para copiar datos al portapapeles del sistema o a la selección primaria.

panel-os
Similar a ventana-os, excepto que crea la nueva ventana del sistema operativo como un panel de escritorio. Solo funciona en plataformas que lo admiten, como los compositores de Wayland que admiten el protocolo de shell de capas. Utilice la opción --panel-os para configurar el panel.

Opciones: ventana, fondo, portapapeles, panel-os, ventana-os, superpuesta, superpuesta-principal, primario, pestaña

--no-tomar-foco, --mantener-foco [=no]
Mantener el foco en la ventana activa actual en lugar de cambiar a la ventana recién abierta.
--cwd
El directorio de trabajo para el hijo recién lanzado. Utilice el valor especial current para usar el directorio de trabajo de la ventana fuente (--source-window). El valor especial last_reported utiliza el último directorio de trabajo informado por el shell (requiere shell_integration para funcionar). El valor especial oldest funciona como current pero utiliza el directorio de trabajo del proceso en primer plano más antiguo asociado con la ventana activa actual en lugar del proceso en primer plano más nuevo. Finalmente, el valor especial root se refiere al proceso que se inició originalmente cuando se creó la ventana.

Al abrir en el mismo directorio de trabajo que la ventana actual, esto hace que la nueva ventana se conecte a un host remoto, puede usar la bandera --mantener-después-de-ssh para evitar que la nueva ventana se cierre cuando la conexión termine.

--entorno
Variables de entorno para establecer en el proceso hijo. Se puede especificar varias veces para establecer diferentes variables de entorno. Sintaxis: nombre=valor. Usar nombre= establecerá una cadena vacía y solo nombre eliminará la variable de entorno.
--var
Variables de usuario para establecer en la ventana creada. Se puede especificar varias veces para establecer diferentes variables de usuario. Sintaxis: nombre=valor. Usar nombre= establecerá una cadena vacía.
--mantener [=no]
Mantener la ventana abierta incluso después de que el comando ejecutado termine, en un prompt de shell. El shell se ejecutará después de que el comando lanzado termine.
--ubicación [=predeterminado]
Dónde colocar la ventana recién creada cuando se agrega a una pestaña que ya tiene ventanas existentes. después y antes colocan la nueva ventana antes o después de la ventana activa. vecino es un sinónimo de después. También se aplica a la creación de una nueva pestaña, donde el valor después hará que la nueva pestaña se coloque junto a la pestaña actual en lugar de al final. Los valores de vsplit, hsplit y split solo se utilizan por el diseño de división y controlan si la nueva ventana se coloca en una división vertical, horizontal o automática con la ventana activa actual. El valor predeterminado es colocar la ventana de manera dependiente del diseño, típicamente, después de la ventana activa actual. Consulte --next-to para usar una ventana distinta de la ventana activa actual.

Opciones: predeterminado, después, antes, primero, hsplit, último, vecino, split, vsplit

--al-lado-de
Una expresión de coincidencia para seleccionar la ventana junto a la cual se crea la nueva ventana. Consulte search_syntax para conocer la sintaxis para especificar ventanas. Si no se especifica, se usa la ventana activa por defecto. Cuando se usa a través de control remoto y se especifica una pestaña de destino, esta opción se ignora a menos que la ventana coincidente esté en la pestaña especificada. Al usar --tipo de pestaña, la pestaña se creará en la ventana del sistema operativo que contiene la ventana coincidente.
--clase-ventana-os
Establece la propiedad WM_CLASS en X11 y la propiedad application id en Wayland para la nueva ventana del sistema operativo creada al usar --tipo. Por defecto, es lo que usa el proceso kitty padre, que a su vez por defecto es kitty.
--nombre-ventana-os
Establece la propiedad WM_NAME en X11 para la nueva ventana del sistema operativo creada al usar --tipo. Por defecto, es --clase-ventana-os.
--título-ventana-os
Establece el título para la nueva ventana del sistema operativo creada. Este título anulará cualquier título establecido por los programas que se ejecutan en kitty. El valor especial current copiará el título de la ventana del sistema operativo que contiene la ventana fuente (--source-window).
--estado-ventana-os [=normal]
El estado inicial para la nueva ventana del sistema operativo creada.

Opciones: normal, pantalla completa, maximizada, minimizada

--logo
Ruta a una imagen PNG para usar como logotipo de la nueva ventana creada. Consulte window_logo_path. Las rutas relativas se resuelven desde el directorio de configuración de kitty.
--posición-logo
La posición para el logotipo de la ventana. Solo tiene efecto si se especifica --logo. Consulte window_logo_position.
--alpha-logo [=-1]
La cantidad en que el logotipo de la ventana debe desvanecerse en el fondo. Solo tiene efecto si se especifica --logo. Consulte window_logo_alpha.
--color
Cambiar los colores en la ventana recién lanzada. Puede especificar una ruta a un archivo .conf con la misma sintaxis que kitty.conf para leer los colores, o especificarlos individualmente, por ejemplo::


--color fondo=blanco --color primerplano=rojo

--espaciado
Establecer el margen y el relleno para la nueva ventan
kitty man page

Name

kitten-edit-in-kitty - edit files in kitty

Usage

kitten edit-in-kitty [options] [files...]

Description

Edit the specified files in kitty. If no files are specified, edit the file specified by the file argument to kitten. If no file argument is specified, the file specified by the env variable KITTY_EDIT_FILE is used. If none of the above are available, an empty file is created in the current directory and opened.

This kitten also supports the --allow-unsafe-kittens option, which allows the use of unsafe kittens. See the kitty man page for details.

Options

--allow-unsafe-kittens [=no]
Allow the use of unsafe kittens. This option is ignored if the kitten is not unsafe.
--cwd =current|focus|last
The directory in which to run the kitten. If not specified, defaults to current. for more details see the kitty man page on the --cwd option.
--launch =yes|no
Controls whether the kitten is launched in a new window or in the current window. If set to yes, the kitten is launched in a new window. If set to no, the kitten is launched in the current window. Defaults to yes.
--window-padding =all|*-h|*-v
Sets the padding around the window. The value can be a single number or a comma separated list of numbers. The first number is applied to all sides, and subsequent numbers are applied top, right, bottom, left in order. For example: margin=20 or padding-left=10 or margin-h=30. The shorthand form sets all values, the *-h and *-v variants set horizontal and vertical values. Can be specified multiple times. Note that this is ignored for overlay windows as these use the settings from the base window.
--hold-after-ssh [=no]
When using --cwd=current or similar from a window that is running the ssh kitten, the new window will run a local shell after disconnecting from the remote host, when this option is specified.
--max-file-size [=8]
The maximum allowed size (in MB) of files to edit. Since the file data has to be base64 encoded and transmitted over the tty device, overly large files will not perform well.
--help, -h [=no]
Show help for this command
