krb5-config(1)

Paquete: krb5

KRB5-CONFIG(1) MIT Kerberos KRB5-CONFIG(1)

NOMBRE

krb5-config - herramienta para enlazar con bibliotecas MIT Kerberos

SINOPSIS

krb5-config [--help | --all | --version | --vendor | --prefix | --exec-prefix | --defccname | --defktname | --defcktname | --cflags | --libs [bibliotecas]]

DESCRIPCIÓN

krb5-config informa al programador de aplicaciones qué indicadores usar para compilar y enlazar programas contra las bibliotecas Kerberos instaladas.

OPCIONES

--help
muestra un mensaje de uso. Este es el comportamiento predeterminado cuando no se especifican opciones.
--all
muestra la versión, el proveedor, el prefijo y el prefijo de ejecución.
--version
muestra el número de versión de la instalación de Kerberos.
--vendor
muestra el nombre del proveedor de la instalación de Kerberos.
--prefix
muestra el prefijo para el que se construyó la instalación de Kerberos.
--exec-prefix
muestra el prefijo para ejecutables para el que se construyó la instalación de Kerberos.
--defccname
muestra la ubicación de la caché de credenciales predeterminada integrada.
--defktname
muestra la ubicación de la tabla de claves predeterminada integrada.
--defcktname
muestra la ubicación de la tabla de claves del cliente (iniciador) predeterminada integrada.
--cflags
muestra los indicadores de compilación utilizados para construir la instalación de Kerberos.
--libs [biblioteca]
muestra las opciones del compilador necesarias para enlazar con biblioteca. Los valores permitidos para biblioteca son:
krb5 aplicaciones Kerberos 5 (predeterminado)
gssapi aplicaciones GSSAPI con enlaces Kerberos 5
kadm-client cliente Kadmin
kadm-server servidor Kadmin
kdb aplicaciones que acceden a la base de datos Kerberos

EJEMPLOS

krb5-config es particularmente útil para compilar contra una instalación de Kerberos que se instaló en una ubicación no estándar. Por ejemplo, una instalación de Kerberos instalada en /opt/krb5/ pero que utiliza bibliotecas en /usr/local/lib/ para la localización de texto produciría la siguiente salida:

shell% krb5-config --libs krb5
-L/opt/krb5/lib -Wl,-rpath -Wl,/opt/krb5/lib -L/usr/local/lib -lkrb5 -lk5crypto -lcom_err
