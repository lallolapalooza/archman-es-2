NOMBRE

kcutilmgr - interfaz de línea de comandos de utilidades misceláneas

DESCRIPCIÓN

El comando `kcutilmgr' es una herramienta de utilidades misceláneas, y para mostrar la configuración. Este comando se utiliza en el siguiente formato. `archivo' especifica un archivo de entrada. Si se omite, se lee la entrada estándar. Si comienza con "@", la subcadena siguiente se trata como la entrada. `patrón' especifica un patrón de coincidencia.


kcutilmgr hex [-d] [archivo]
Realiza codificación hexadecimal y su decodificación.
kcutilmgr enc [-hex|-url|-quote] [-d] [archivo]
Realiza codificación Base64 y su decodificación.
kcutilmgr ciph [-key cadena] [archivo]
Realiza cifrado Arcfour y su descifrado.
kcutilmgr comp [-def|-gz|-lzo|-lzma] [-d] [archivo]
Realiza codificación ZLIB y su decodificación. Por defecto, usa el formato raw.
kcutilmgr hash [-fnv|-path|-crc] [archivo]
Calcula el valor hash. Por defecto, usa el hash MurMur.
kcutilmgr regex [-alt cadena] [-ic] patrón [archivo]
Imprime líneas que coinciden con una expresión regular.
kcutilmgr conf [-v|-i|-l|-p]
Muestra la configuración de Kyoto Cabinet.
kcutilmgr version
Muestra la información de la versión de Kyoto Cabinet.

Las opciones incluyen lo siguiente.

-d : realiza decodificación (eliminación de escape), no codificación (escape).
-hex : usa codificación hexadecimal.
-url : usa codificación URL.
-quote : usa codificación Quoted-printable.
-key cadena : establece la clave del cifrado.
-def : usa el formato deflate.
-gz : usa el formato gzip.
-lzo : usa codificación LZO.
-lzma : usa codificación LZMA.
-fnv : usa hash FNV.
-path : usa el hash de ruta de la base de datos del directorio.
-crc : calcula la suma de verificación CRC32.
-alt cadena : reemplaza la subcadena coincidente con la cadena alternativa.
-ic : ignora las diferencias entre mayúsculas y minúsculas.
-v : muestra el número de versión de Kyoto Cabinet.
-i : muestra las opciones para incluir las cabeceras de Tokyo Cabinet.
-l : muestra las opciones para enlazar la biblioteca de Tokyo Cabinet.
-p : muestra la ruta del directorio de los comandos.

Este comando devuelve 0 en caso de éxito, otro valor en caso de fallo.
