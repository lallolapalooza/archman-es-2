Nombre

kitten-diff - Diferenciación bonita de archivos e imágenes, lado a lado

Una herramienta de diferencias rápida, lado a lado, con resaltado de sintaxis e imágenes

Características principales

  • Muestra diferencias lado a lado en la terminal kitty
  • Realiza resaltado de sintaxis de las diferencias mostradas, de forma asíncrona, para máxima velocidad
  • Muestra imágenes además de diferencias de texto, incluso a través de SSH
  • Realiza diferenciación recursiva de directorios
Captura de pantalla, mostrando una diferencia de ejemplo (imágenes no soportadas)

Instalación

Simplemente instala kitty <#quickstart>.

Uso

En la terminal kitty, ejecuta:

kitten diff archivo1 archivo2

para ver la diferencia entre archivo1 y archivo2.

Crea un alias en el archivo de inicio de tu shell para acortar el comando, por ejemplo:

alias d="kitten diff"

Ahora todo lo que necesitas hacer para comparar dos archivos es:

d archivo1 archivo2

También puedes pasar directorios en lugar de archivos para ver la diferencia recursiva del contenido del directorio.

Integración con git

Añade lo siguiente a ~/.gitconfig:

[diff]
    tool = kitty
    guitool = kitty.gui
[difftool]
    prompt = false
    trustExitCode = true
[difftool "kitty"]
    cmd = kitten diff $LOCAL $REMOTE
[difftool "kitty.gui"]
    cmd = kitten diff $LOCAL $REMOTE

Ahora, para usar kitty-diff para ver las diferencias de git, simplemente puedes hacer:

git difftool --no-symlinks --dir-diff

Una vez más, crear un alias para este comando es útil.

¿Por qué esto solo funciona en kitty?

El kitten de diferencias utiliza varias características que son exclusivas de kitty <>, como el protocolo de gráficos de kitty <>, el protocolo de teclado extendido <>, etc. También aprovecha la infraestructura de programas de terminal que creé para todos los demás kittens de kitty para reducir la cantidad de código necesario (toda la implementación tiene menos de 3000 líneas de código).

Y fundamentalmente, solo es para kitty porque lo escribí para mí, y es muy poco probable que use otras terminales :)

Configuración

Puedes configurar los colores utilizados, los atajos de teclado, la implementación de diferencias, las líneas de contexto predeterminadas, etc., creando un archivo diff.conf en tu carpeta de configuración de kitty <#confloc>. Consulta a continuación las directivas de configuración admitidas.

Diferenciación

syntax_aliases
syntax_aliases pyj:py pyi:py recipe:py

Alias de extensiones de archivo para resaltado de sintaxis. Por ejemplo, para resaltar la sintaxis de archivo.xyz como archivo.abc, usa una configuración de xyz:abc. Múltiples alias deben estar separados por espacios.

num_context_lines
num_context_lines 3

El número de líneas de contexto a mostrar alrededor de cada cambio.

diff_cmd
diff_cmd auto

El comando de diferencia a usar. Debe contener el marcador de posición _CONTEXT_ que será reemplazado por el número de líneas de contexto. Se permiten algunos valores especiales: auto elegirá automáticamente una implementación de diferencia disponible. builtin usará el algoritmo de diferencia anclado de la biblioteca estándar de Go. git usará el comando git para realizar la diferenciación. diff usará el comando diff para realizar la diferenciación.

replace_tab_by
replace_tab_by \x20\x20\x20\x20

La cadena para reemplazar las tabulaciones. Por defecto, se usan cuatro espacios.

ignore_name

Este sitio no está asociado de ninguna forma con Arch Linux ni afiliado a este proyecto. El contenido es únicamente una traducción de las páginas del manual de Arch publicadas en man.archlinux.org.

Un patrón glob que se compara solo con el nombre de archivo de los archivos y directorios. Los archivos y directorios coincidentes se ignoran al escanear el sistema de archivos para buscar archivos para comparar. Se puede especificar varias veces para utilizar varios patrones. Por ejemplo:

ignore_name .git
ignore_name *~
ignore_name *.pyc

Colores

color_scheme
color_scheme auto

Si se deben usar colores claros u oscuros. El valor predeterminado de auto significa seguir el esquema de color de la terminal principal. Tenga en cuenta que los colores reales utilizados para los esquemas oscuros se establecen en la configuración dark_* a continuación y la configuración sin prefijo se utiliza para los colores claros.

pygments_style
pygments_style default

El esquema de color de pygments a utilizar para el resaltado de sintaxis. Consulte los estilos integrados de pygments en https://pygments.org/styles/ para obtener una lista de esquemas. Tenga en cuenta que esto no cambia los colores utilizados para la comparación, solo los colores utilizados para el resaltado de sintaxis. Para cambiar los colores generales, utilice la configuración a continuación. Esto establece los colores utilizados para los esquemas de colores claros; utilice dark_pygments_style para cambiar los colores de los esquemas de colores oscuros.

Código fuente para diff

El código fuente de este kitten está disponible en GitHub https://github.com/kovidgoyal/kitty/tree/master/kittens/diff.

Interfaz de línea de comandos

kitten diff [options] file_or_directory_left file_or_directory_right

Muestra una diferencia lado a lado de los archivos/directorios especificados. También puede usar ssh:hostname:remote-file-path para comparar archivos remotos.

Opciones

--context <CONTEXT>
Número de líneas de contexto a mostrar entre cambios. Los valores negativos utilizan el número establecido en diff.conf. Por defecto: -1
--config <CONFIG>
Especifica una ruta a los archivos de configuración a utilizar. Todos los archivos de configuración se fusionan con el diff.conf incorporado, anulando los valores incorporados. Esta opción se puede especificar varias veces para leer varios archivos de configuración en secuencia, que se fusionan. Utilice el valor especial NONE para no cargar ningún archivo de configuración.

Si esta opción no se especifica, los archivos de configuración se buscan en el siguiente orden: $XDG_CONFIG_HOME/kitty/diff.conf, ~/.config/kitty/diff.conf, $XDG_CONFIG_DIRS/kitty/diff.conf. El primero que exista se utiliza como archivo de configuración.

Si se especifica la variable de entorno KITTY_CONFIG_DIRECTORY <#envvar-KITTY_CONFIG_DIRECTORY>, siempre se utiliza ese directorio y la búsqueda anterior no ocurre.

Si /etc/xdg/kitty/diff.conf existe, se fusiona antes (es decir, con menor prioridad) que cualquier archivo de configuración del usuario. Se puede utilizar para especificar valores predeterminados a nivel de sistema para todos los usuarios. Puede usar tanto - como /dev/stdin para leer la configuración desde STDIN.

--override <OVERRIDE>, -o <OVERRIDE>
Anula opciones de configuración individuales, se puede especificar varias veces. Sintaxis: nombre=valor. Por ejemplo: -o background=gray

Puede descargar un archivo diff.conf de ejemplo con todos los valores predeterminados y comentarios que describen cada configuración haciendo clic en: sample diff.conf.
