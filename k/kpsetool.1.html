kpsetool(1) Manual de Comandos Generales kpsetool(1)

NOMBRE

kpsetool - script para hacer disponibles kpsetool, kpsexpand y kpsepath al estilo teTeX

SINOPSIS

kpsetool [ OPCIONES... ] COMANDO

kpsexpand [ OPCIONES... ] CADENA

kpsepath [ OPCIONES... ] TIPORUTA

DESCRIPCIÓN

kpsetool es un script de Bourne shell que hace disponibles kpsetool, kpsexpand y kpsepath al estilo teTeX. kpsetool utiliza el binario kpsexpand (nuevo) de web2c, por lo que la sintaxis de kpsexpand es incompatible con la de teTeX a partir de la versión 0.4.

OPCIONES

-m modo
establece el modo Metafont
-n nombredeprog
pretende ser nombredeprog para kpathsea
-p
actúa como kpsepath(1)
-v
actúa como kpsexpand(1)
-w
actúa como kpsewhich(1)

USO

TIPORUTA puede ser

base
volcado de memoria de Metafont
bib
fuente de bibliografía de BibTeX
bst
archivos de estilo de BibTeX
cnf
archivos de configuración en tiempo de ejecución de Kpathsea
dvips_config
archivos de configuración de dvips
dvips_header
archivos de cabecera de dvips
fmt
volcado de memoria de TeX
gf
mapa de bits de fuente genérico
mem
volcado de memoria de MetaPost
mf
código fuente de Metafont
mfpool
cadenas de programa de Metafont
mp
código fuente de MetaPost
mppool
cadenas de programa de MetaPost
mpsupport
archivos de soporte de MetaPost
pict
otros tipos de figuras
pk
fuente de mapa de bits empaquetada
tex
código fuente de TeX
texpool
cadenas de programa de TeX
tfm
métricas de fuentes de TeX
troff_font
fuentes de troff
vf
fuente virtual
