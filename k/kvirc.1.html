NOMBRE

KVIrc - un cliente de chat por internet (Internet Relay Chat).

SINOPSIS

kvirc [opciones] [servidor [puerto]] [irc[6]://...]

DESCRIPCIÓN

KVIrc es un cliente de chat por internet (Internet Relay Chat) visual basado en la librería Qt.

Está diseñado para ser una interfaz "amigable" para el protocolo IRC (ver RFC1459) y sus extensiones.

OPCIONES

KVIrc acepta las siguientes opciones:

-h, --help
Muestra una lista de todas las opciones de la línea de comandos y sale.
-v, --version
Muestra la información de la versión.
-c <archivo>
Usa <archivo> como archivo de configuración en lugar de ~/.kvirc4.rc. El valor predeterminado es $HOME/.kvirc4.rc si <archivo> no existe.
-n <archivo>
Usa <archivo> como archivo de configuración en lugar de ~/.kvirc4.rc. Crea <archivo> si no existe.
-f
Fuerza una nueva sesión de KVIrc, incluso si ya hay una en ejecución.
-e <comandos>
Si ya hay una sesión de KVIrc en ejecución, ejecuta los <comandos> en esa sesión, de lo contrario, se inicia normalmente y ejecuta <comandos>. <comandos> debe ser un único token de shell. Puedes usar este modificador varias veces.
-x <comandos>
Si ya hay una sesión de KVIrc en ejecución, ejecuta los <comandos> en esa sesión, de lo contrario, no hace nada y sale. <comandos> debe ser un único token de shell. Puedes usar este modificador varias veces.
-r <comandos>
Si ya hay una sesión de KVIrc en ejecución, ejecuta los <comandos> en esa sesión, de lo contrario, se inicia normalmenente (no ejecuta). <comandos> debe ser un único token de shell. Puedes usar este modificador varias veces.
-m
Si ya hay una sesión de KVIrc en ejecución, muestra un cuadro de diálogo informativo en lugar de escribir en la consola. Esto es útil cuando se inicia KVIrc desde un botón de la barra de tareas gráfica.
[servidor]
Conéctate a este servidor después de iniciar.
[puerto]
Usa este puerto para la conexión. Esta opción también requiere un nombre de servidor.
[irc[6]://...]
Una URL con el siguiente formato:


irc[6]://<servidor>[:<puerto>][/<canal>[?<contraseña>]]

Por cada URL en la línea de comandos, crea un nuevo contexto irc e intenta conectarse a <servidor> en el <puerto> especificado. El <canal> opcional se une justo después de que la conexión se haya establecido.

AMBIENTE

KVIRC_LANG
Configuración de idioma. Si no está configurado, KVIrc comprobará $LANG
LANG
Configuración de idioma. Si no está configurado (o está configurado como 'EN', 'POSIX' o 'C'), KVIrc usará el idioma predeterminado (inglés).

ARCHIVOS

$PREFIX/share/kvirc/VERSION/* Directorio con la configuración global de KVIrc, módulos, etc...

$HOME/.kvirc4.rc. Este es el primer archivo que KVIrc busca. Si se especifica la opción de línea de comandos -c, se utiliza el archivo pasado como parámetro de la opción en lugar de este. Si se encuentra el archivo, KVIrc lee la primera línea no vacía y la trata como la ruta al directorio local de KVIrc. Si no se encuentra el archivo o el directorio local de KVIrc no existe, KVIrc entra en modo de configuración y permite seleccionar un nuevo directorio local de KVIrc.

Directorio local de KVIrc/* Directorio con la configuración local (por usuario) de KVIrc. Similar al global.

    kvirc(1)

    NOMBRE

    kvirc - un cliente IRC gráfico y extensible

    SINOPSIS

    kvirc [opciones] [servidor[:puerto] [/contraseña]] ...

    DESCRIPCIÓN

    KVIRC es un cliente IRC gráfico y extensible, escrito en Qt. Permite a los usuarios conectarse a uno o varios servidores IRC simultáneamente. Está diseñado para ser potente y flexible, ofreciendo una amplia gama de funciones para la comunicación y la interacción en canales IRC.

    OPCIONES

    Esta página de manual no contiene opciones específicas. Para ver la lista completa de opciones, por favor ejecuta kvirc --help.
