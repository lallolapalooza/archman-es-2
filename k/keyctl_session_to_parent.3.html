NOMBRE

keyctl_session_to_parent - establece el keyring de sesión del proceso padre

SINOPSIS

#include <keyutils.h>

long keyctl_session_to_parent();

DESCRIPCIÓN

keyctl_session_to_parent() cambia el keyring de sesión al que se suscribe el proceso padre del proceso que llama, al del proceso que llama.

El keyring debe tener permiso de enlace disponible para el proceso que llama, el proceso padre debe tener las mismas UID/GID que el proceso que llama, y el LSM no debe rechazar el reemplazo. Además, esto no se puede usar para afectar a init o a un hilo del kernel.

Tenga en cuenta que el reemplazo no tendrá efecto inmediato en el proceso padre, sino que se pospondrá hasta la próxima vez que regrese al espacio de usuario desde el espacio del kernel.

VALOR DE RETORNO

En caso de éxito, keyctl_session_to_parent() devuelve 0. En caso de error, se devolverá el valor -1 y errno se habrá establecido con un error apropiado.

ERRORES

ENOMEM
Memoria insuficiente para crear una clave.
EPERM
Las credenciales del padre no coinciden con las del llamador.
EACCES
El keyring con nombre existe, pero el proceso que llama no puede enlazarlo.

ENLAZADO

Esta es una función de biblioteca que se puede encontrar en libkeyutils. Al enlazar, se debe especificar -lkeyutils al enlazador.
