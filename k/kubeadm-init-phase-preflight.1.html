NOMBRE

kubeadm init phase preflight - Ejecutar comprobaciones previas

SINOPSIS

kubeadm init phase preflight [OPCIONES]

DESCRIPCIÓN

Ejecuta las comprobaciones previas para kubeadm init.

OPCIONES

--config="" Ruta a un archivo de configuración de kubeadm.

--cri-socket="" Ruta al socket CRI para conectar. Si está vacío, kubeadm intentará autodetectar este valor; utiliza esta opción solo si tienes más de un CRI instalado o si tienes un socket CRI no estándar.

--dry-run=false No aplicar ningún cambio; solo mostrar lo que se haría.

--ignore-preflight-errors=[] Una lista de comprobaciones cuyos errores se mostrarán como advertencias. Ejemplo: 'IsPrivilegedUser,Swap'. El valor 'all' ignora los errores de todas las comprobaciones.

--image-repository="registry.k8s.io" Elige un registro de contenedores para descargar las imágenes del plano de control

OPCIONES HEREDADAS DE COMANDOS PADRE

--rootfs="" La ruta al sistema de archivos raíz 'real' del host. Esto hará que kubeadm realice un chroot a la ruta proporcionada.

--version=false --version, --version=raw imprime la información de la versión y sale; --version=vX.Y.Z... establece la versión informada

EJEMPLO

  # Ejecutar comprobaciones previas para kubeadm init usando un archivo de configuración.
  kubeadm init phase preflight --config kubeadm-config.yaml
