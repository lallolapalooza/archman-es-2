NOMBRE

kubectl config delete-user - Eliminar el usuario especificado del kubeconfig

SINOPSIS

kubectl config delete-user [OPCIONES]

DESCRIPCIÓN

Elimina el usuario especificado del kubeconfig.

OPCIONES HEREDADAS DE COMANDOS PADRE

--as="" Nombre de usuario para suplantar en la operación. El usuario puede ser un usuario regular o una cuenta de servicio en un espacio de nombres.

--as-group=[] Grupo para suplantar en la operación, este flag se puede repetir para especificar múltiples grupos.

--as-uid="" UID para suplantar en la operación.

--cache-dir="/home/usuario/.kube/cache" Directorio de caché predeterminado

--certificate-authority="" Ruta a un archivo de certificado para la autoridad certificadora

--client-certificate="" Ruta a un archivo de certificado de cliente para TLS

--client-key="" Ruta a un archivo de clave de cliente para TLS

--cluster="" El nombre del clúster del kubeconfig a usar

--context="" El nombre del contexto del kubeconfig a usar

--disable-compression=false Si es verdadero, se opta por no comprimir las respuestas para todas las solicitudes al servidor

--insecure-skip-tls-verify=false Si es verdadero, el certificado del servidor no se verificará en cuanto a su validez. Esto hará que tus conexiones HTTPS no sean seguras

--kubeconfig="" usar un archivo kubeconfig particular

--kuberc="" Ruta al archivo kuberc a usar para preferencias. Esto se puede deshabilitar exportando el feature gate KUBECTL_KUBERC=false o desactivando el feature KUBERC=off.

--match-server-version=false Requerir que la versión del servidor coincida con la versión del cliente

-n, --namespace="" Si está presente, el espacio de nombres para este comando CLI

--password="" Contraseña para autenticación básica al servidor API

--profile="none" Nombre del perfil a capturar. Uno de (none|cpu|heap|goroutine|threadcreate|block|mutex)

--profile-output="profile.pprof" Nombre del archivo donde escribir el perfil

--request-timeout="0" El tiempo de espera antes de rendirse en una única solicitud al servidor. Los valores distintos de cero deben contener una unidad de tiempo correspondiente (por ejemplo, 1s, 2m, 3h). Un valor de cero significa no esperar tiempo de espera en las solicitudes.

-s, --server="" La dirección y el puerto del servidor API de Kubernetes

--tls-server-name="" Nombre del servidor a usar para la validación del certificado del servidor. Si no se proporciona, se utiliza el nombre de host utilizado para contactar al servidor

--token="" Token de portador para la autenticación al servidor API

--user="" El nombre del usuario del kubeconfig a usar

--username="" Nombre de usuario para autenticación básica al servidor API

--version=false --version, --version=raw imprime información de versión y sale; --version=vX.Y.Z... establece la versión reportada

--warnings-as-errors=false Tratar las advertencias recibidas del servidor como errores y salir con un código de salida distinto de cero

EJEMPLO

  # Eliminar el usuario minikube
  kubectl config delete-user minikube
