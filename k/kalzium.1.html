KALZIUM(1) Manual de usuario de Kalzium KALZIUM(1)

NOMBRE

kalzium - Herramienta de enseñanza de química basada en KDE

SINOPSIS

kalzium [Opciones] [--molecule archivo]

DESCRIPCIÓN

Kalzium es un programa que le muestra el Sistema Periódico de los Elementos (SPE). Puede usar Kalzium para buscar información sobre los elementos o para aprender hechos sobre el SPE.

Kalzium le proporciona todo tipo de información sobre el SPE. Puede consultar mucha información sobre los elementos y también usar visualizaciones para mostrarlos.

Este paquete forma parte del módulo oficial de edutainment de KDE.

OPCIONES

--molecule archivo

Abre el archivo de molécula dado en formato cml, xyz, ent, pdb, alc, chm, cdx, cdxml, c3d1, c3d2, gpr, mdl, mol, sdf, sd, crk3d, cht, dmol, bgf, gam, inp, gamin, gamout, tmol, fract, mpd, o mol2.

VER TAMBIÉN

La documentación detallada para el usuario está disponible en help:/kalzium (introduzca esta URL en Konqueror o ejecute khelpcenter help:/kalzium).
