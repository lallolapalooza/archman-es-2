kitten(1) Manual de kitten kitten(1)

Nombre

kitten - Implementaciones rápidas y compiladas estáticamente de varios kittens (herramientas de línea de comandos para usar con kitty)

Uso

kitten comando [opciones_comando] [argumentos_comando]

Descripción

kitten sirve como lanzador para ejecutar kittens individuales. Cada kitten puede ser ejecutado como kitten comando. La lista de kittens disponibles se muestra a continuación.
