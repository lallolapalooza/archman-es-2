NOMBRE

kcatalogprint - Utilidad de impresión de catálogo de Knot DNS

SINOPSIS

kcatalogprint [opción_config] [opciones]

DESCRIPCIÓN

El programa imprime el catálogo de zonas almacenado en una base de datos de catálogo.

Opciones de configuración

-c, --config archivo
Utiliza un archivo de configuración textual (el valor predeterminado es /etc/knot/knot.conf).
-C, --confdb directorio
Utiliza un directorio de base de datos de configuración binaria (el valor predeterminado es /var/lib/knot/confdb). La base de datos de configuración predeterminada, si existe, tiene preferencia sobre el archivo de configuración predeterminado.
-D, --dir ruta
Utiliza la ruta de la base de datos de catálogo especificada y la configuración predeterminada.

Opciones

-a, --catalog
Filtra la salida por el nombre de la zona del catálogo.
-m, --member
Filtra la salida por el nombre de la zona miembro.
-h, --help
Imprime la ayuda del programa.
-V, --version
Imprime la versión del programa. La opción -VV hace que el programa imprima el resumen de la configuración de compilación.

VALORES DE SALIDA

El estado de salida 0 significa operación exitosa. Cualquier otro estado de salida indica un error.

VER TAMBIÉN

knotd(8), knot.conf(5).
