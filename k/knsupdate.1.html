NOMBRE

knsupdate - Utilidad de actualización dinámica de DNS

SINOPSIS

knsupdate [-v] [opciones] [archivo]

knsupdate [-q] [opciones_quic] [opciones] [archivo]

DESCRIPCIÓN

Esta utilidad envía mensajes de actualización dinámica de DNS a un servidor DNS. El contenido de la actualización se lee de un archivo (si se proporciona el parámetro archivo) o de la entrada estándar.

El formato de las actualizaciones es textual y está compuesto por comandos. Cada comando se coloca en una línea separada de la entrada. Las líneas que comienzan con un punto y coma son comentarios y no se procesan.

Parámetros

archivo
Ruta al archivo con los comandos de knsupdate.

Opciones

-T, --tcp
Utilizar una conexión TCP. (Se puede usar -v para compatibilidad con nsupdate).
-S, --tls
Utilizar una conexión TLS.
-Q, --quic
Utilizar una conexión QUIC.
-p, --puerto número
Establecer el puerto a utilizar para las conexiones al servidor (si no se especifica explícitamente en la actualización). El valor predeterminado es 53 para UDP/TCP o 853 para QUIC.
-r, --reintentos cantidad
El número de reintentos para solicitudes UDP. El valor predeterminado es 3.
-t, --tiempo-espera segundos
El tiempo de espera total (para todos los intentos de actualización UDP) de la solicitud de actualización en segundos. El valor predeterminado es 12. Si se establece en cero, el tiempo de espera es infinito.
-y, --tsig [alg:]nombre:clave
Utilizar la clave TSIG con el nombre nombre para autenticar la solicitud. La parte alg especifica el algoritmo (el valor predeterminado es hmac-sha256) y clave especifica el secreto compartido codificado en Base64.
-k, --archivo-tsig ruta
Utilizar la clave TSIG almacenada en el archivo archivo-clave para autenticar la solicitud. El archivo debe contener la clave en el mismo formato que se acepta con la opción -y.
-d, --depurar
Habilitar mensajes de depuración.
-h, --ayuda
Imprimir la ayuda del programa.
-V, --versión
Imprimir la versión del programa. La opción -VV hace que el programa imprima el resumen de la configuración de compilación.

Opciones QUIC/TLS

-H, --nombre-host cadena
Habilitar la validación del nombre de host del servidor remoto.
-P, --pin base64
Usar el perfil de privacidad de clave fijada fuera de banda (RFC 7858#section-4.2). El PIN debe ser un hash SHA-256 codificado en Base64 de X.509 SubjectPublicKeyInfo. Se puede especificar varias veces.
-A, --ca [ruta]
Habilitar la validación del certificado. Los certificados de la autoridad de certificación se cargan desde el archivo PEM especificado (el valor predeterminado es el almacenamiento de certificados del sistema si no se proporciona ningún argumento). Se puede especificar varias veces.
-E, --archivo-certificado ruta
Ruta a un archivo de certificado de cliente.
-K, --archivo-clave ruta
Ruta a un archivo de clave de cliente.
-s, --sni cadena
Usar el Server Name Indication especificado.

Comandos

servidor nombre [puerto]
Especifica un servidor receptor del mensaje de actualización dinámica. El parámetro nombre puede ser un nombre de host o una dirección IP. Si no se especifica el puerto, se utiliza el puerto predeterminado. El valor del puerto predeterminado se puede controlar mediante la opción del programa -p.
local dirección [puerto]
Especifica la dirección y el puerto de salida. Si no se especifica local, la dirección y el puerto los establece el sistema automáticamente. El número de puerto predeterminado es 0.
zona nombre
Especifica que todas las actualizaciones se realizan dentro de una zona nombre. El nombre de la zona no tiene un valor predeterminado y debe establecerse explícitamente.
origen nombre
Especifica un sufijo de nombre de dominio completamente calificado que se agrega a los propietarios no FQDN en los comandos de actualización. El valor predeterminado es la etiqueta terminal (.).
clase nombre
Establece nombre como la clase predeterminada para todas las actualizaciones. Si no se usa, la clase predeterminada es IN.
ttl valor
Establece valor como el TTL (en segundos) predeterminado. Si no se usa, el valor predeterminado es 3600.
clave [alg:]nombre clave
Especifica la clave TSIG llamada nombre para autenticar la solicitud. Se puede especificar un algoritmo alg opcional. Este comando tiene el mismo efecto que la opción del programa -y.
[prerrequisito] nxdomain nombre
Agrega un prerrequisito para un registro inexistente propiedad de nombre.
[prerrequisito] yxdomain nombre
Agrega un prerrequisito para un registro existente propiedad de nombre.
[prerrequisito] nxrrset nombre [clase] tipo
Agrega un prerrequisito para un registro inexistente del tipo propiedad de nombre. Se espera la clase de Internet.
[prerrequisito] yxrrset nombre [clase] tipo [datos]
Agrega un prerrequisito para un registro existente del tipo propiedad de nombre con datos opcionales. Se espera la clase de Internet.
[actualización] agregar nombre [ttl] [clase] tipo datos
Agrega una solicitud para agregar un nuevo registro de recurso a la zona. Tenga en cuenta que si el nombre no es un nombre de dominio completamente calificado, se le agregará el nombre de origen actual.
[actualización] eliminar[borrar] nombre [ttl] [clase] [tipo] [datos]
Agrega una solicitud para eliminar todos los registros de recursos (o los que coincidan con clase, tipo o datos) de la zona. Existe el mismo requisito para el parámetro nombre que en el comando actualización agregar. El elemento ttl se ignora.
mostrar
Muestra el contenido actual del mensaje de actualización.
enviar
Envía el mensaje de actualización actual y limpia la lista de actualizaciones.
respuesta
Muestra la última respuesta del servidor.
depurar
Habilita la depuración. Este comando tiene el mismo significado que la opción del programa -d.
salir
Finaliza el programa.

NOTAS

Las opciones -k y -y no se pueden usar simultáneamente.

Ni los formatos de archivo de clave de tsig-keygen(8) ni de dnssec-keygen(1) son compatibles. Utilice keymgr(8) para construir una cadena para -y o el archivo pasado a -k.

La adivinación del nombre de zona/servidor no se admite si el nombre de zona/servidor no está especificado.

Una línea vacía no envía la actualización.

Modo interactivo

La utilidad proporciona un modo interactivo con funcionalidad básica de edición de línea, completado de comandos e historial de comandos.

El comportamiento del modo interactivo se puede personalizar en ~/.editrc. Consulte editrc(5) para obtener detalles.

El historial de comandos se guarda en ~/.knsupdate_history.

VALORES DE SALIDA

Un estado de salida de 0 significa operación exitosa. Cualquier otro estado de salida indica un error.

EJEMPLOS

1.
Enviar una actualización de la zona example.com al servidor 192.168.1.1. La actualización contiene dos nuevos registros:
$ knsupdate
knsupdate> server 192.168.1.1
knsupdate> zone example.com.
knsupdate> origin example.com.
knsupdate> ttl 3600
knsupdate> add test1.example.com. 7200 A 192.168.2.2
knsupdate> add test2 TXT "hola"
knsupdate> show
knsupdate> send
knsupdate> answer
knsupdate> exit
