Nombre

kitten-@-run - Ejecuta un programa en el ordenador en el que se está ejecutando kitty y obtiene la salida

Uso

kitten @ run CMD ...

Descripción

Ejecuta el programa especificado en el ordenador en el que se está ejecutando kitty. Cuando STDIN no es un TTY, se reenvía al programa como su STDIN. STDOUT y STDERR del programa se reenvían aquí. El estado de salida de esta invocación será el estado de salida del programa ejecutado. Si solo desea ejecutar un programa sin esperar una respuesta, utilice @ launch --type=background en su lugar.

Opciones

--env
Variables de entorno para establecer en el proceso hijo. Se pueden especificar varias veces para establecer diferentes variables de entorno. Sintaxis: nombre=valor. Usar nombre= establecerá una cadena vacía y solo nombre eliminará la variable de entorno.
--allow-remote-control [=no]
El programa ejecutado tendrá privilegios para ejecutar comandos de control remoto en kitty.
--remote-control-password
Restringe las acciones que el control remoto puede realizar. Funciona como remote_control_password. Puede especificar una contraseña y una lista de acciones al igual que para remote_control_password. Por ejemplo::


--remote-control-password '"mi frase secreta" get-* set-colors'

Esta contraseña estará en vigor solo para esta ventana. Tenga en cuenta que las contraseñas que haya definido para remote_control_password en kitty.conf también están en vigor. Puede anularlas utilizando la misma contraseña aquí. También puede deshabilitar todas las contraseñas globales de remote_control_password para esta ventana, utilizando::


--remote-control-password '!'

Esta opción solo surte efecto si también se especifica --allow-remote-control. Se puede especificar varias veces para crear varias contraseñas. Esta opción se añadió a kitty en la versión 0.26.0

--help, -h [=no]
Muestra la ayuda para este comando

Opciones globales

--to
Una dirección para la instancia de kitty a controlar. Corresponde a la dirección proporcionada a la instancia de kitty a través de la opción --listen-on o la configuración listen_on en kitty.conf. Si no se especifica, se verifica la variable de entorno KITTY_LISTEN_ON. Si tampoco se encuentra, los mensajes se envían al terminal de control para este proceso, es decir, solo funcionarán si este proceso se ejecuta dentro de una ventana de kitty.
--password
Una contraseña para usar al contactar con kitty. Esto hará que kitty solicite al usuario permiso para realizar la acción especificada, a menos que la contraseña haya sido aceptada anteriormente o esté preconfigurada en kitty.conf. Para usar una contraseña en blanco, especifique --use-password como siempre.
--password-file [=rc-pass]
Un archivo del que leer la contraseña. Los espacios en blanco al final se ignoran. Las rutas relativas se resuelven desde el directorio de configuración de kitty. Utilice - para leer desde STDIN. Utilice fd:num para leer desde el descriptor de archivo num. Se utiliza si no se proporciona --password. Por defecto, comprueba el archivo rc-pass en el directorio de configuración de kitty.
--password-env [=KITTY_RC_PASSWORD]
El nombre de una variable de entorno de la que leer la contraseña. Se utiliza si no se proporciona --password-file. Por defecto, comprueba la variable de entorno KITTY_RC_PASSWORD.
--use-password [=if-available]
Si no hay ninguna contraseña disponible, kitty generalmente enviará el comando de control remoto sin contraseña. Esta opción se puede usar para forzar el uso de la contraseña proporcionada siempre o nunca. Si se establece en always y no se proporciona ninguna contraseña, se utiliza la contraseña en blanco.

Opciones: if-available, always, never
