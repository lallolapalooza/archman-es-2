NOMBRE

kubeone-config-images-list - Listar imágenes que se usarán

SINOPSIS

kubeone config images list [flags]

DESCRIPCIÓN

Listar imágenes que se usarán

OPCIONES

--filter="none" Filtro de lista de imágenes, uno de [none|base|optional]

-h, --help[=false] Ayuda para list

--kubernetes-version="" Filtrar imágenes para una versión de Kubernetes proporcionada

OPCIONES HEREDADAS DE COMANDOS PADRE

-c, --credentials="" Archivo para obtener credenciales y secretos

-d, --debug[=false] Salida de depuración con rastreo de pila

-l, --log-format="text" Formato para el registro

-m, --manifest="./kubeone.yaml" Ruta a la configuración de KubeOne

-t, --tfjson="" Fuente para la salida de terraform en formato JSON - para leer desde la entrada estándar. Si la ruta es un archivo, se utilizarán los contenidos. Si la ruta es un directorio, se ejecutará terraform output -json en esa ruta

-v, --verbose[=false] Salida detallada

EJEMPLO

# Para ver la lista completa de imágenes
kubeone config images list
# Para ver la lista de imágenes base
kubeone config images list --filter base
# Para ver la lista de imágenes opcionales
kubeone config images list --filter optional
# Para ver imágenes de una versión específica de Kubernetes
kubeone config images list --kubernetes-version=1.26.0
# Para ver la lista de imágenes afectadas por la configuración registryConfiguration (en caso de que exista alguna)
kubeone config images list -m mycluster.yaml
