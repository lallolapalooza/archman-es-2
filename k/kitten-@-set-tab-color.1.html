Nombre

kitten-@-set-tab-color - Cambia el color de las pestañas especificadas en la barra de pestañas

Uso

kitten @ set-tab-color COLORES

Descripción

Cambia el color de las pestañas especificadas en la barra de pestañas

Los colores de primer plano y de fondo cuando están activos e inactivos se pueden anular usando este comando. La sintaxis para especificar colores es: active_fg=color active_bg=color inactive_fg=color inactive_bg=color. Donde color puede ser un nombre de color o un valor de la forma #rrggbb o la palabra clave NONE para volver a usar los colores predeterminados.

Opciones

--match, -m
La pestaña a coincidir. Las especificaciones de coincidencia son de la forma: campo:consulta. Donde campo puede ser uno de: id, index, title, window_id, window_title, pid, cwd, cmdline env, var, state, session y recent. consulta es la expresión a coincidir. Las expresiones pueden ser un número o una expresión regular, y se pueden combinar usando operadores booleanos.

El valor especial all coincide con todas las pestañas.

Para campos numéricos: id, index, window_id, pid y recent, la expresión se interpreta como un número, no como una expresión regular. Los valores negativos para id/window_id coinciden desde el número de id más alto hacia abajo, en particular, -1 es la pestaña/ventana creada más recientemente.

Al usar title o id, primero se busca una pestaña coincidente, y si no se encuentra, se busca una ventana coincidente y se utiliza la pestaña de esa ventana.

También puede usar window_id y window_title para coincidir con la pestaña que contiene la ventana con el id o título especificado.

El número de índice se utiliza para coincidir con la enésima pestaña en la ventana del sistema operativo actualmente activa. El número recent coincide con las pestañas activadas recientemente en la ventana del sistema operativo actualmente activa, siendo cero la pestaña actualmente activa, uno la pestaña activada anteriormente y así sucesivamente.

El campo session coincide con las pestañas que se crearon en la sesión especificada. Use la expresión ^$ para coincidir con ventanas que no se crearon en una sesión y . para coincidir con la sesión actualmente activa y ~ para coincidir con la sesión actualmente activa o la última sesión activa cuando no hay ninguna sesión activa.

Al usar el campo env para coincidir con variables de entorno, puede especificar solo el nombre de la variable de entorno o un nombre y valor, por ejemplo, env:MY_ENV_VAR=2. Coinciden las pestañas que contienen cualquier ventana con las variables de entorno especificadas. De manera similar, var coincide con las pestañas que contienen cualquier ventana con las variables de usuario especificadas.

El campo state coincide con el estado de la pestaña. Los estados admitidos son: active, focused, needs_attention, parent_active, parent_focused y focused_os_window. Las pestañas activas son las pestañas que están activas en su ventana del sistema operativo padre. Solo hay una pestaña enfocada y es la pestaña a la que se entregan los eventos del teclado. Si no hay ninguna pestaña enfocada, se coincide con la última pestaña enfocada. El valor focused_os_window coincide con todas las pestañas en la ventana del sistema operativo actualmente enfocada.

Tenga en cuenta que puede usar el comando kitten @ ls para obtener una lista de pestañas.

--self [=no]
Cierra la pestaña en la que se ejecuta este comando, en lugar de la pestaña activa.
--help, -h [=no]
Muestra la ayuda para este comando

Opciones globales

--to
Una dirección para la instancia de kitty a controlar. Corresponde a la dirección dada a la instancia de kitty a través de la opción --listen-on o la configuración listen_on en kitty.conf. Si no se especifica, se verifica la variable de entorno KITTY_LISTEN_ON. Si tampoco se encuentra, los mensajes se envían al terminal de control para este proceso, es decir, solo funcionarán si este proceso se ejecuta dentro de una ventana de kitty.
--password
Una contraseña para usar al contactar con kitty. Esto hará que kitty solicite al usuario permiso para realizar la acción especificada, a menos que la contraseña haya sido aceptada previamente o esté preconfigurada en kitty.conf. Para usar una contraseña en blanco, especifique --use-password como siempre.
--password-file [=rc-pass]
Un archivo del cual leer la contraseña. Se ignoran los espacios en blanco finales. Las rutas relativas se resuelven desde el directorio de configuración de kitty. Use - para leer desde STDIN. Use fd:num para leer desde el descriptor de archivo num. Se usa si no se proporciona --password. Por defecto, comprueba si existe el archivo rc-pass en el directorio de configuración de kitty.
--password-env [=KITTY_RC_PASSWORD]
El nombre de una variable de entorno de la cual leer la contraseña. Se usa si no se proporciona --password-file. Por defecto, comprueba la variable de entorno KITTY_RC_PASSWORD.
--use-password [=if-available]
Si no hay ninguna contraseña disponible, kitty normalmente enviará el comando de control remoto sin contraseña. Esta opción se puede usar para forzar su uso o no uso de la contraseña proporcionada. Si se establece en always y no se proporciona contraseña, se utiliza la contraseña en blanco.

Opciones: if-available, always, never
