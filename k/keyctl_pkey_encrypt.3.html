Paquete: keyutils

Licencias: GPL2, LGPL2.1

KEYCTL_PKEY_ENCRYPT(3) Cifrado de clave pública de Linux KEYCTL_PKEY_ENCRYPT(3)

NOMBRE

keyctl_pkey_encrypt, keyctl_pkey_decrypt - Cifrar y descifrar datos

SINOPSIS

#include <keyutils.h>

long keyctl_pkey_encrypt(key_serial_t key, const char *info,
                         const void *data, size_t data_len,
                         void *enc, size_t enc_len);

long keyctl_pkey_decrypt(key_serial_t key, const char *info,
                         const void *enc, size_t enc_len,
                         void *data, size_t data_len);

DESCRIPCIÓN

keyctl_pkey_encrypt() solicita al kernel que utilice el material criptográfico adjunto a una clave para cifrar un bloque de datos y keyctl_pkey_decrypt() solicita al kernel que utilice la clave para invertir la operación y recuperar los datos originales. Tenga en cuenta que estas operaciones pueden implicar que el kernel acceda a hardware criptográfico. El llamante debe tener permiso de búsqueda en una clave para poder utilizarlas de esta manera.

Al invocar la función, key indica la clave que proporcionará el material criptográfico y info apunta a un espacio o tabulación - separado cadena de parámetros "key[=value]" que indican cosas como formas de codificación y contraseñas para desbloquear la clave; consulte asymmetric-key(7) para obtener más información.

data y datalen indican la dirección y el tamaño del búfer de datos descifrados y enc y enclen indican la dirección y el tamaño del búfer de datos cifrados. La función de cifrado extrae datos del búfer de datos descifrados y coloca la salida en el búfer de cifrado. La función de descifrado hace lo contrario, extrayendo del búfer de cifrado y escribiendo en el búfer de datos.

keyctl_pkey_query(2) puede ser llamada para averiguar qué tamaño necesitan los búferes.

Tenga en cuenta que no todas las claves de tipo asimétrico admitirán estas operaciones; además, las operaciones disponibles pueden depender de qué componentes del material de la clave estén disponibles: típicamente el cifrado solo requiere la clave pública, pero el descifrado también requiere la clave privada. Qué operaciones se admiten en una clave particular también se puede determinar utilizando la función de consulta.

VALOR DEVUELTO

En caso de éxito, keyctl_pkey_encrypt() y keyctl_pkey_decrypt() devuelven la cantidad de datos escritos en el búfer de salida. En caso de error, se devolverá el valor -1 y errno se habrá establecido en un error apropiado.

ERRORES

ENOKEY
La clave especificada no es válida.
EKEYEXPIRED
La clave especificada ha caducado.
EKEYREVOKED
La clave especificada ha sido revocada.
EACCES
La clave existe, pero no es buscable por el proceso llamante.
ENOPKG
Alguna instalación necesaria para completar la operación solicitada no está disponible. Esto es muy probablemente un algoritmo de resumen o cifrado solicitado o requerido.
EFAULT
Dirección incorrecta.

ENLAZADO

Esta es una función de biblioteca que se puede encontrar en libkeyutils. Al enlazar, se debe especificar -lkeyutils al enlazador.
