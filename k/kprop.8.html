NOMBRE

kprop - propaga una base de datos de principales de Kerberos V5 a un servidor réplica

SINOPSIS

kprop [-r reino] [-f archivo] [-d] [-P puerto] [-s llave de registro] host_replica

DESCRIPCIÓN

kprop se utiliza para propagar de forma segura un archivo de volcado de la base de datos de Kerberos V5 desde el servidor Kerberos principal a un servidor Kerberos réplica, que se especifica mediante host_replica. El archivo de volcado debe haber sido creado por kdb5_util(8).

OPCIONES

-r reino
Especifica el reino del servidor principal.
-f archivo
Especifica el nombre del archivo donde se encontrará el archivo de base de datos de principales volcados; por defecto, el archivo de base de datos volcado es normalmente /var/lib/krb5kdc/replica_datatrans.
-P puerto
Especifica el puerto a utilizar para contactar con el servidor kpropd(8) en el host remoto.
-d
Imprime información de depuración.
-s llave de registro
Especifica la ubicación del archivo de llave de registro (keytab).

ENTORNO

Consulte kerberos(7) para una descripción de las variables de entorno de Kerberos.

VER TAMBIÉN

kpropd(8), kdb5_util(8), krb5kdc(8), kerberos(7)
