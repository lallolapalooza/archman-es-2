Nombre

kitten-run-shell - Ejecutar el shell del usuario con la integración del shell habilitada

Uso

kitten run-shell [opciones] [comando opcional para ejecutar antes de ejecutar el shell ...]

Descripción

Ejecuta el shell configurado por el usuario. Si el shell soporta la integración del shell, la habilita según la configuración de shell_integration del usuario.

Opciones

--shell-integration
Especifica un valor para la opción shell_integration, anulando el de kitty.conf.
--shell [=.]
Especifica el comando shell a ejecutar. El valor por defecto de . usará el shell padre si se reconoce, recurriendo al valor de la opción shell de kitty.conf.
--env
Especifica una variable de entorno a establecer antes de ejecutar el shell. De la forma CLAVE=VALOR. Se puede especificar varias veces. Si no hay = presente, CLAVE se elimina.
--cwd
El directorio de trabajo a usar al ejecutar el shell.
--inject-self-onto-path [=always]
Añade el directorio que contiene este binario de kitten a PATH. El directorio se añade solo si no está presente.

Opciones: always, never, unless-root
