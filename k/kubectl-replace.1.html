NOMBRE

kubectl replace - Reemplazar un recurso por nombre de archivo o stdin

SINOPSIS

kubectl replace [OPCIONES]

DESCRIPCIÓN

Reemplazar un recurso por nombre de archivo o stdin.

Se aceptan formatos JSON y YAML. Si se reemplaza un recurso existente, se debe proporcionar la especificación completa del recurso. Esto se puede obtener mediante

    $ kubectl get TIPO NOMBRE -o yaml

OPCIONES

--allow-missing-template-keys=true Si es verdadero, ignora cualquier error en las plantillas cuando un campo o una clave de mapa falta en la plantilla. Solo se aplica a los formatos de salida golang y jsonpath.

--cascade="background" Debe ser "background", "orphan" o "foreground". Selecciona la estrategia de eliminación en cascada para los dependientes (por ejemplo, Pods creados por un ReplicationController). Por defecto es background.

--dry-run="none" Debe ser "none", "server" o "client". Si es estrategia de cliente, solo imprime el objeto que se enviaría, sin enviarlo. Si es estrategia de servidor, envía la solicitud del lado del servidor sin persistir el recurso.

--field-manager="kubectl-replace" Nombre del gestor utilizado para rastrear la propiedad de los campos.

-f, --filename=[] Los archivos que contienen las configuraciones a reemplazar.

--force=false Si es verdadero, elimina inmediatamente los recursos de la API y omite la eliminación gradual. Tenga en cuenta que la eliminación inmediata de algunos recursos puede dar lugar a inconsistencias o pérdida de datos y requiere confirmación.

--grace-period=-1 Período de tiempo en segundos dado al recurso para terminar de forma gradual. Se ignora si es negativo. Establícelo en 1 para un cierre inmediato. Solo se puede establecer en 0 cuando --force es verdadero (eliminación forzada).

-k, --kustomize="" Procesa un directorio de kustomization. Esta bandera no se puede usar junto con -f o -R.

-o, --output="" Formato de salida. Uno de: (json, yaml, name, go-template, go-template-file, template, templatefile, jsonpath, jsonpath-as-json, jsonpath-file).

--raw="" URI cruda para PUT en el servidor. Utiliza el transporte especificado por el archivo kubeconfig.

-R, --recursive=false Procesa el directorio utilizado en -f, --filename recursivamente. Útil cuando desea administrar manifiestos relacionados organizados dentro del mismo directorio.

--save-config=false Si es verdadero, la configuración del objeto actual se guardará en su anotación. De lo contrario, la anotación no cambiará. Esta bandera es útil cuando desea realizar kubectl apply en este objeto en el futuro.

--show-managed-fields=false Si es verdadero, conserva los managedFields al imprimir objetos en formato JSON o YAML.

--subresource="" Si se especifica, replace operará en el subrecurso del objeto solicitado.

--template="" Cadena de plantilla o ruta a la plantilla archivo a usar cuando -o=go-template, -o=go-template-file. El formato de plantilla es de plantillas de golang [http://golang.org/pkg/text/template/#pkg-overview].

--timeout=0s La duración de tiempo a esperar antes de rendirse en una eliminación, cero significa determinar un tiempo de espera a partir del tamaño del objeto

--validate="strict" Debe ser uno de: strict (o true), warn, ignore (o false). "true" o "strict" utilizarán un esquema para validar la entrada y fallarán la solicitud si es inválida. Realizará validación del lado del servidor si ServerSideFieldValidation está habilitado en el api-server, pero recurrirá a una validación del lado del cliente menos confiable si no. "warn" advertirá sobre campos desconocidos o duplicados sin bloquear la solicitud si la validación de campos del lado del servidor está habilitada en el servidor de API, y se comportará como "ignore" en caso contrario. "false" o "ignore" no realizarán ninguna validación de esquema, descartando silenciosamente cualquier campo desconocido o duplicado.

--wait=false Si es verdadero, espere a que los recursos desaparezcan antes de devolver el control. Esto espera los finalizadores.

OPCIONES HEREDADAS DE COMANDOS PADRE

--as="" Nombre de usuario a suplantar para la operación. El usuario puede ser un usuario regular o una cuenta de servicio en un espacio de nombres.

--as-group=[] Grupo a suplantar para la operación, esta bandera se puede repetir para especificar varios grupos.

--as-uid="" UID a suplantar para la operación.

--cache-dir="/home/username/.kube/cache" Directorio de caché predeterminado

--certificate-authority="" Ruta a un archivo de certificado para la autoridad certificadora

--client-certificate="" Ruta a un archivo de certificado de cliente para TLS

--client-key="" Ruta a un archivo de clave de cliente para TLS

--cluster="" El nombre del clúster de kubeconfig a usar

--context="" El nombre del contexto de kubeconfig a usar

--disable-compression=false Si es verdadero, desactiva la compresión de respuesta para todas las solicitudes al servidor

--insecure-skip-tls-verify=false Si es verdadero, el certificado del servidor no se verificará por su validez. Esto hará que sus conexiones HTTPS no sean seguras

--kubeconfig="" Ruta al archivo kubeconfig a utilizar para las solicitudes CLI.

--kuberc="" Ruta al archivo kuberc a utilizar para preferencias. Esto se puede deshabilitar exportando la puerta de enlace de funciones KUBECTL_KUBERC=false o desactivando la función KUBERC=off.

--match-server-version=false Requerir que la versión del servidor coincida con la versión del cliente

-n, --namespace="" Si está presente, el ámbito del espacio de nombres para esta solicitud CLI

--password="" Contraseña para la autenticación básica en el servidor API

--profile="none" Nombre del perfil a capturar. Uno de (none|cpu|heap|goroutine|threadcreate|block|mutex)

--profile-output="profile.pprof" Nombre del archivo donde escribir el perfil

--request-timeout="0" La duración de tiempo a esperar antes de rendirse en una solicitud de servidor individual. Los valores distintos de cero deben contener una unidad de tiempo correspondiente (por ejemplo, 1s, 2m, 3h). Un valor de cero significa no agotar el tiempo de espera de las solicitudes.

-s, --server="" La dirección y el puerto del servidor API de Kubernetes

--tls-server-name="" Nombre del servidor a usar para la validación del certificado del servidor. Si no se proporciona, se utiliza el nombre de host utilizado para contactar al servidor

--token="" Token Bearer para la autenticación en el servidor API

--user="" El nombre del usuario de kubeconfig a usar

--username="" Nombre de usuario para la autenticación básica en el servidor API

--version=false --version, --version=raw imprime información de versión y sale; --version=vX.Y.Z... establece la versión informada

--warnings-as-errors=false Tratar las advertencias recibidas del servidor como errores y salir con un código de salida distinto de cero

EJEMPLO

  # Reemplazar un pod utilizando los datos en pod.json
  kubectl replace -f ./pod.json
  # Reemplazar un pod basándose en el JSON pasado a stdin
  cat pod.json | kubectl replace -f -
  # Actualizar la versión de la imagen de un pod de un solo contenedor (etiqueta) a v4
  kubectl get pod mypod -o yaml | sed 's/\(image: myimage\):.*$/\1:v4/' | kubectl replace -f -
  # Reemplazar forzadamente, eliminar y luego volver a crear el recurso
  kubectl replace --force -f ./pod.json

NAME

kubectl-replace - Replace a resource by filename or stdin

SYNOPSIS

kubectl replace -f FILENAME [-f FILENAME ...]
kubectl replace --src=FILENAME [-f FILENAME ...]
kubectl replace (-f FILENAME | --src=FILENAME) --grace-period=gracePeriod --cascade=[true|false]
kubectl replace jsonpath='{.items[*].metadata.name}' --template='RESOURCE_TEMPLATE'

DESCRIPTION

Replace a collection of resources by filename or stdin. Use a local filename or stdin to replace resources in the cluster. Resources are identified by the resource name and kind. The resource is expected to exist in the cluster.

To replace a resource, you must specify the resource name. You can specify the resource name by providing a filename with the resource definition or by piping the resource definition to kubectl.

This command is intended for replacing existing resources. If the resource does not exist, this command will fail.

For more details on how to use this command, please refer to the official kubectl documentation.

OPTIONS

--cascade=[true|false]
Resource cascading control. Supports 'background', 'foreground', and 'orphan'.
Default: true

-f, --filename=string
Filename, directory, or URL to files identifying the resource to replace.

--grace-period=int
Period of time the grace period will be, from seconds to milliseconds.
Give a relative duration by appending the suffix 's' to the value, e.g. 5s to 5 seconds.

--grace-period-seconds=int
Period of time the grace period will be, from seconds to milliseconds.
Give a relative duration by appending the suffix 's' to the value, e.g. 5s to 5 seconds.

-o, --output=string
Output format. One of: json|yaml|wide|name|jsonpath='<template>'|jsonpath-file='<template-path>'|go-template='<template>'|go-template-file='<template-path>'

--resource-version=string
Only update the object if it matches the specified resource version.

--src=string
Filename or stdin, used to replace resources.

-R, --recursive=false
If true, process the directory recursively. Recursion follows symbolic links only if they are on the command line.

--template=string
Template string or path to template file that defines the resources to be replaced.

-a, --all=false
Select all resources in the specified namespace.

--allow-missing-template-keys=true
If true, ignore any errors in templates when a field or map key is missing in the template. Other errors will still be raised.

--dry-run=none
Must be "none", "server", or "client".
If client strategy, there will be noุย sent to the server upon success.
If server strategy, url is supported and may be sent to the server.

-o, --output=string
Output format. One of: json|yaml|wide|name|jsonpath='<template>'|jsonpath-file='<template-path>'|go-template='<template>'|go-template-file='<template-path>'

-v, --version=false
Print the version number of kubectl and exit.

OPTIONS INHERITED FROM PARENT COMMANDS

--cache-dir="": Default cache directory

--certificate-authority="": Path to a cert file for the certificate authority

--client-certificate="": Path to a client certificate file for TLS

--client-key="": Path to a client key file for TLS

-c, --context="": The name of the kubeconfig context to use

--kubeconfig=""
Path to the kubeconfig file:
kubeconfig is required if in-cluster config is not used.

-n, --namespace="": If present, the namespace scope for this CLI request

--request-timeout="0": The length of time to wait before giving up on a single server request. Non-zero values should contain a corresponding time unit, like 1s to mean a second. 0 means don't timeout...

-s, --server="": The address and port of the Kubernetes API server

EXAMPLE

# Replace the pod definition in 'pod.yaml'
kubectl replace -f pod.yaml
# Replace the pod definition specified in JSON filename 'pod.json'
kubectl replace -f pod.json
# Replace the pod definition from stdin
cat pod.yaml | kubectl replace -f -
# Replace multiple resources from files and stdin
kubectl replace -f pod1.yaml -f pod2.yaml -f pod3.json
# Replace all pods in the 'dev' namespace, using a local file 'pod.yaml' as the template
kubectl replace -f pod.yaml --namespace dev --all
