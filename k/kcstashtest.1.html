NOMBRE

kcstashtest - interfaz de línea de comandos para probar la base de datos stash

DESCRIPCIÓN

El comando `kcstashtest' es una utilidad para pruebas de facilidad y pruebas de rendimiento de la base de datos stash. Este comando se utiliza en el siguiente formato. `rnum' especifica el número de iteraciones.


kccachetest order [-th num] [-rnd] [-etc] [-tran] [-bnum num] [-lv] rnum
Realiza pruebas en orden.
kccachetest queue [-th num] [-it num] [-rnd] [-bnum num] [-lv] rnum
Realiza operaciones de encolamiento.
kccachetest wicked [-th num] [-it num] [-bnum num] [-lv] rnum
Realiza operaciones mixtas seleccionadas al azar.
kccachetest tran [-th num] [-it num] [-bnum num] [-lv] rnum
Realiza pruebas de transacciones.

Las opciones incluyen lo siguiente.

-th num : especifica el número de hilos de trabajo.
-rnd : realiza prueba aleatoria.
-etc : realiza operaciones misceláneas.
-tran : realiza transacciones.
-bnum num : especifica el número de buckets de la tabla hash.
-lv : reporta todos los errores.
-it num : especifica el número de repeticiones.

Este comando devuelve 0 en caso de éxito y otro valor en caso de fallo.
