NOMBRE

kubeone-document - Genera documentación

SINOPSIS

kubeone document [flags]

DESCRIPCIÓN

La documentación se puede generar como páginas man, markdown, documentos de texto reestructurado o yaml.

OPCIONES

-h, --help[=false] Ayuda para documentar

-o, --output-dir="/tmp/" Directorio para llenar con la documentación

OPCIONES HEREDADAS DE COMANDOS PADRE

-c, --credentials="" Archivo de donde obtener credenciales y secretos

-d, --debug[=false] Salida de depuración con traza de pila

-l, --log-format="text" Formato para el registro

-m, --manifest="./kubeone.yaml" Ruta al archivo de configuración de KubeOne

-t, --tfjson="" Fuente para la salida de terraform en formato JSON - para leer desde stdin. Si la ruta es un archivo, se utilizarán los contenidos. Si la ruta es un directorio, se ejecutará terraform output -json en esa ruta.

-v, --verbose[=false] Salida detallada

EJEMPLO

kubeone document man
