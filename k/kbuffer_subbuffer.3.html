DESCRIPCIÓ

N

Estas funciones crean un manejador kbuffer que puede usarse para analizar los sub-búferes sin procesar del búfer circular de rastreo del núcleo de Linux. El búfer circular se encuentra en el directorio tracefs y puede obtenerse mediante tracefs_instance_get_file(3) en per_cpu/cpuX/trace_pipe_raw donde X se sustituye por el número de CPU correspondiente del búfer circular especificado. El búfer circular dentro del núcleo está dividido por CPU, por lo que el búfer circular sin procesar debe obtenerse también por

CPU.

El kbuffer_alloc() creará un descriptor que puede usarse para gestionar un sub-búfer leído por el búfer circular. El parámetro size indica cuál es el tamaño de palabra para el búfer dado (nota: esto funciona al leer datos sin procesar de máquinas distintas de la que llama a esta función). El endian indica el orden de bytes de la

máquina.

Si endian está establecido a KBUFFER_ENDIAN_SAME_AS_HOST, el orden de bytes se establecerá igual que el del host, lo cual es útil cuando la aplicación lee los datos del búfer circular directamente desde la misma máquina en la que se

ejecuta.

Si size está establecido a KBUFFER_LSIZE_SAME_AS_HOST, si el tamaño de palabra es 8, se establecerá el descriptor kbuffer a un tamaño largo de 8. Pero si el tamaño es 4, entonces realizará una llamada a uname(2), y si el campo machine contiene la cadena "64", se establecerá a un tamaño largo de 8 bytes y no de 4. Esto se debe a que el tamaño largo del búfer circular depende del núcleo y no del espacio de

usuario.

La función kbuffer_dup() duplicará una estructura kbuffer existente con una nueva asignada. Tendrá todas las propiedades del kbuf pasado, incluyendo el apuntado al mismo sub-búfer que fue cargado en el kbuf. Debe liberarse con kbuffer_fr

ee().

La función kbuffer_free() liberará los recursos creados por kbuffer_all

oc().

El kbuffer_load_subbuffer() tomará un sub-búfer que es un bloque de datos sin procesar del archivo tracefs trace_pipe_raw. El búfer circular de rastreo de Linux está dividido en sub-búferes. Cada sub-búfer es un segmento de datos independiente que contiene toda la información para separar los eventos individuales y las marcas de tiempo. Este sub-búfer es lo que kbuffer usa para recorrer los

eventos.

El kbuffer_subbuffer_size() devuelve la ubicación del final del último evento en el sub-búfer. No devuelve el tamaño del sub-búfer en

sí.

El kbuffer_refresh() debe usarse si se realizaron más escrituras en el kbuffer cargado donde el tamaño del kbuffer necesita actualizarse para poder leer los nuevos eventos que se escribieron desde la última vez que se llamó a kbuffer_load_subb

uffer().

Nota: no se implementan barreras de memoria con esta función y cualquier sincronización con el escritor es responsabilidad de la

aplicación.

La función kbuffer_start_of_data() devuelve el desplazamiento donde comienza la carga real de datos del

sub-búfer.

La función kbuffer_subbuffer() devuelve el puntero al sub-búfer actualmente cargado. Es decir, el último sub-búfer que fue cargado por kbuffer_load_subbuffer(). Si no se cargó

ningún sub-búfer s
e devuelve NULL.

VALOR DE

RETORNO

kbuffer_alloc() devuelve un descriptor kbuffer asignado o NULL en caso de error. El descriptor devuelto debe liberarse con kbuffer_free(

)

kbuffer_load_subbuffer() devuelve 0 en caso de éxito y -1 en caso de

error.

kbuffer_subbuffer_size() devuelve el índice en el sub-búfer donde se encuentra el final del último

evento.

kbuffer_start_of_data() devuelve el desplazamiento donde comienzan los datos en el sub-búfer cargado en kbuf

.

kbuffer_subbuffer() devuelve el último sub-búfer cargado en kbuf que fue cargado por kbuffer_load_subbuffer() o NULL si no se cargó

ninguno.

kbuffer_refresh() devuelve 0 en caso de éxito y -1 si kbuf es NULL o no tiene un sub-búfer cargado mediante kbuffer_load

_subbuf
fer().

EJEMPL

O 
#include <stdio.h>
#include <stdlib.h>
#include <fcntl.h>
#include <unistd.h>
#include <sys/stat.h>
#include <kbuffer.h>
int main (int argc, char **argv)
{
        unsigned long long ts;
        struct kbuffer *kbuf;
        struct stat st;
        char *buf;
        void *event;
        int ret;
        int fd;
        int i = 0;
        if (argc < 2) {
                printf("uso: %s página-de-sub-búfer-sin-procesar\n", argv[0]);
                printf(" Prueba: dd count=1 bs=4096 if=/sys/kernel/tracing/per_cpu/cpu0/trace_pipe_raw of=/tmp/file\n");
                exit(0);
        }
        if (stat(argv[1], &st) < 0) {
                perror("stat");
                exit(-1);
        }
        buf = malloc(st.st_size);
        if (!buf) {
                perror("Asignando búfer");
                exit(-1);
        }
        fd = open(argv[1], O_RDONLY);
        if (fd < 0) {
                perror(argv[1]);
                exit(-1);
        }
        ret = read(fd, buf, st.st_size);
        if (ret < 0) {
                perror("Leyendo búfer");
                exit(-1);
        }
        close(fd);
        kbuf = kbuffer_alloc(KBUFFER_ENDIAN_SAME_AS_HOST,
                             KBUFFER_LSIZE_SAME_AS_HOST);
        if (!kbuf) {
                perror("Creando kbuffer");
                exit(-1);
        }
        ret = kbuffer_load_subbuffer(kbuf, buf);
        if (ret < 0) {
                perror("Cargando sub-búfer");
                exit(-1);
        }
        if (kbuffer_subbuffer_size(kbuf) > st.st_size) {
                fprintf(stderr, "kbuffer es más grande que el tamaño sin procesar %d > %ld\n",
                        kbuffer_subbuffer_size(kbuf), st.st_size);
                exit(-1);
        }
        printf("Los datos de Kbuffer comienzan en %d\n", kbuffer_start_of_data(kbuf));
        do {
                event = kbuffer_read_event(kbuf, &ts);
                if (event) {
                        printf(" evento %3d ts:%lld\n", i++, ts);
                        event = kbuffer_next_event(kbuf, NULL);
                }
        } while (event);
        if (!event)
                printf("Sub-búfer terminado\n");
        kbuffer_free(kbuf);
        return
0;
}
