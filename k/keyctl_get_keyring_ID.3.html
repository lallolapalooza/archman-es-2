keyctl_get_keyring_ID(3)

Paquete: keyutils

KEYCTL_GET_KEYRING_ID(3) Llamadas de gestión de claves de Linux KEYCTL_GET_KEYRING_ID(3)

NOMBRE

keyctl_get_keyring_ID - obtener el ID de un keyring especial

SINOPSIS

#include <keyutils.h>

key_serial_t keyctl_get_keyring_ID(key_serial_t key,
 int create);

DESCRIPCIÓN

keyctl_get_keyring_ID() mapea una key especial o ID de keyring al número de serie de la clave que realmente representa esa característica. Se devolverá el número de serie si existe esa clave.

Si la clave o el keyring aún no existen, entonces si create es distinto de cero, la clave o el keyring se crearán si es apropiado hacerlo.

Los siguientes IDs de clave especiales pueden especificarse como key:

KEY_SPEC_THREAD_KEYRING
Esto especifica el keyring específico del hilo del llamante.
KEY_SPEC_PROCESS_KEYRING
Esto especifica el keyring específico del proceso del llamante.
KEY_SPEC_SESSION_KEYRING
Esto especifica el keyring específico de la sesión del llamante.
KEY_SPEC_USER_KEYRING
Esto especifica el keyring específico del UID del llamante.
KEY_SPEC_USER_SESSION_KEYRING
Esto especifica el keyring de sesión UID del llamante.
KEY_SPEC_REQKEY_AUTH_KEY
Esto especifica la clave de autorización creada por request_key() y pasada al proceso que genera una clave.

Si se pasa un ID de keyring válido, este simplemente se devolverá si la clave existe; se emitirá un error si no existe.

VALOR DE RETORNO

En caso de éxito, keyctl_get_keyring_ID() devuelve el número de serie de la clave que encontró. En caso de error, se devolverá el valor -1 y errno se habrá establecido con un error apropiado.

ERRORES

ENOKEY
No se encontró ninguna clave coincidente.
ENOMEM
Memoria insuficiente para crear una clave.
EDQUOT
La cuota de claves para este usuario se excedería al crear esta clave o vincularla al keyring.

ENLACE

Esta es una función de biblioteca que se puede encontrar en libkeyutils. Al enlazar, se debe especificar -lkeyutils al enlazador.
