NOMBRE

kcpolytest - Interfaz de línea de comandos para probar la base de datos polimórfica

DESCRIPCIÓN

El comando `kcpolytest' es una utilidad para la prueba de instalaciones y la prueba de rendimiento de la base de datos polimórfica. Este comando se utiliza en el siguiente formato. `path' especifica la ruta de un archivo de base de datos. `rnum' especifica el número de iteraciones.


kcpolytest order [-th num] [-rnd] [-set|-get|-getw|-rem|-etc] [-tran] [-oat|-onl|-onl|-otl|-onr] [-lv] path rnum
Realiza pruebas en orden.
kcpolytest queue [-th num] [-it num] [-rnd] [-oat|-onl|-onl|-otl|-onr] [-lv] path rnum
Realiza operaciones de cola.
kcpolytest wicked [-th num] [-it num] [-oat|-onl|-onl|-otl|-onr] [-lv] path rnum
Realiza operaciones mixtas seleccionadas al azar.
kcpolytest tran [-th num] [-it num] [-hard] [-oat|-onl|-onl|-otl|-onr] [-lv] path rnum
Realiza pruebas de transacciones.
kcpolytest mapred [-rnd] [-ru] [-oat|-onl|-onl|-otl|-onr] [-lv] [-tmp str] [-dbnum num] [-clim num] [-cbnum num] [-xnl] [-xpm] [-xpr] [-xpf] [-xnc] path rnum
Realiza operaciones MapReduce.
kcpolytest index [-th num] [-rnd] [-set|-get|-rem|-etc] [-tran] [-oat|-onl|-onl|-otl|-onr] [-lv] path rnum
Realiza operaciones de indexación.
kcpolytest misc path
Realiza pruebas diversas.

Las opciones incluyen lo siguiente.

-th num : especifica el número de hilos de trabajo.
-rnd : realiza pruebas aleatorias.
-set : realiza solo operaciones de establecimiento.
-get : realiza solo operaciones de obtención.
-getw : realiza solo operaciones de obtención con búfer.
-rem : realiza solo operaciones de eliminación.
-etc : realiza operaciones diversas.
-tran : realiza transacciones.
-oat : abre la base de datos con la opción de transacción automática.
-oas : abre la base de datos con la opción de sincronización automática.
-onl : abre la base de datos con la opción de no bloqueo.
-otl : abre la base de datos con la opción de bloqueo de intento.
-onr : abre la base de datos con la opción de no reparación automática.
-lv : informa de todos los errores.
-it num : especifica el número de repeticiones.
-hard : realiza sincronización física.
-ru : reutiliza la base de datos existente.
-tmp str : especifica la ruta de un directorio para almacenamiento temporal.
-dbnum num : especifica el número de bases de datos temporales.
-clim num : especifica el tamaño límite de la memoria caché.
-cbnum num : especifica el número de cubetas de la memoria caché.
-xnl : ejecuta con la opción de no bloqueo.
-xpm : ejecuta con la opción de mapeador paralelo.
-xpr : ejecuta con la opción de reductor paralelo.
-xpf : ejecuta con la opción de flusher paralelo.
-xnc : ejecuta con la opción de no compresión.

Este comando devuelve 0 si tiene éxito y otro valor si falla.
