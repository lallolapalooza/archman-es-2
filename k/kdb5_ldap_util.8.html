stashsrvpw




stashsrvpw [-f nombre_archivo]
  nombre




Permite a un administrador almacenar la contraseña del objeto de servicio
    en un archivo para que KDC y el servidor de Administración puedan usarla para autenticarse
    al servidor LDAP. Opciones:





  
-f
    nombre_archivo

  
Especifica la ruta completa del archivo de contraseña de servicio. Por defecto,
      se usa /usr/local/var/service_passwd.

  
nombre

  
Especifica el nombre del objeto cuya contraseña se va a almacenar. Si
      krb5kdc(8) o kadmind(8) están configurados para unión simple, este debe ser
      el nombre distinguido que utilizarán, según la
      variable ldap_kdc_dn o ldap_kadmind_dn en kdc.conf(5). Si el KDC o kadmind está
      configurado para unión SASL, este debe ser el nombre de autenticación que
      utilizarán, según la
      variable ldap_kdc_sasl_authcid o ldap_kadmind_sasl_authcid.






Ejemplo:






kdb5_ldap_util stashsrvpw -f /home/andrew/conf_keyfile
    cn=service-kdc,o=org

create_policy




create_policy [-maxtktlife
  vida_max_ticket] [-maxrenewlife
  vida_max_renovable_ticket] [banderas_ticket]
  nombre_politica




Crea una política de tickets en el directorio. Opciones:





  
-maxtktlife
    vida_max_ticket

  
(cadena getdate) Especifica la vida máxima del ticket para los principales.

  
-maxrenewlife
    vida_max_renovable_ticket

  
(cadena getdate) Especifica la vida máxima renovable de los tickets para
      los principales.

  
banderas_ticket

  
Especifica las banderas del ticket. Si esta opción no se especifica, por defecto,
      la política no establecerá ninguna restricción. Las banderas permitidas se documentan
      en la descripción del comando add_principal en kadmin(1).

  
nombre_politica

  
Especifica el nombre de la política de tickets.






Ejemplo:






kdb5_ldap_util -D cn=admin,o=org -H ldaps://ldap-server1.mit.edu
    -r ATHENA.MIT.EDU create_policy -maxtktlife "1 día"
    -maxrenewlife "1 semana" -allow_postdated +needchange
    -allow_forwardable tktpolicy
Contraseña para "cn=admin,o=org":










modify_policy




modify_policy [-maxtktlife
  vida_max_ticket] [-maxrenewlife
  vida_max_renovable_ticket] [banderas_ticket]
  nombre_politica




Modifica los atributos de una política de tickets. Las opciones son las mismas
    que para create_policy.


Ejemplo:






kdb5_ldap_util -D cn=admin,o=org -H
    ldaps://ldap-server1.mit.edu -r ATHENA.MIT.EDU modify_policy
    -maxtktlife "60 minutos" -maxrenewlife "10 horas"
    +allow_postdated -requires_preauth tktpolicy

destroy_policy




destroy_policy [-force]
  nombre_politica




Destruye una política de tickets existente. Opciones:





  
-force

  
Fuerza la eliminación del objeto de política. Si no se especifica, se le pedirá confirmación al usuario antes de eliminar la política.

  
nombre_politica

  
Especifica el nombre de la política de tickets.






Ejemplo:






kdb5_ldap_util -D cn=admin,o=org -H ldaps://ldap-server1.mit.edu
    -r ATHENA.MIT.EDU destroy_policy tktpolicy

(escribe 'yes' para confirmar)? yes
