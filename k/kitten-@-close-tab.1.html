Nombre

kitten-@-close-tab - Cierra las pestañas especificadas

Uso

kitten @ close-tab

Descripción

Cierra un conjunto arbitrario de pestañas. La opción --match se puede usar para especificar conjuntos complejos de pestañas a cerrar. Por ejemplo, para cerrar todas las pestañas no enfocadas en la ventana del sistema operativo actualmente enfocada, usa::


kitten @ close-tab --match "not state:focused and state:parent_focused"

Opciones

--match, -m
La pestaña a comparar. Las especificaciones de comparación son del tipo: campo:consulta. Donde el campo puede ser uno de: id, index, title, window_id, window_title, pid, cwd, cmdline env, var, state, session y recent. La consulta es la expresión a comparar. Las expresiones pueden ser un número o una expresión regular, y se pueden combinar usando operadores booleanos.

El valor especial all compara todas las pestañas.

Para campos numéricos: id, index, window_id, pid y recent, la expresión se interpreta como un número, no como una expresión regular. Los valores negativos para id/window_id comparan desde el número de id más alto hacia abajo, en particular, -1 es la pestaña/ventana creada más recientemente.

Al usar title o id, primero se busca una pestaña que coincida y, si no se encuentra, se busca una ventana que coincida, y se usa la pestaña de esa ventana.

También puedes usar window_id y window_title para comparar la pestaña que contiene la ventana con el id o título especificado.

El número de índice se utiliza para comparar la enésima pestaña en la ventana del sistema operativo activa actualmente. El número recent compara las pestañas activas recientemente en la ventana del sistema operativo activa actualmente, siendo cero la pestaña activa actualmente, uno la pestaña activa anteriormente y así sucesivamente.

El campo session compara pestañas que se crearon en la sesión especificada. Usa la expresión ^$ para comparar ventanas que no se crearon en una sesión y . para comparar la sesión activa actualmente y ~ para comparar la sesión activa actualmente o la última sesión activa cuando no hay ninguna sesión activa.

Al usar el campo env para comparar variables de entorno, solo puedes especificar el nombre de la variable de entorno o un nombre y valor, por ejemplo, env:MY_ENV_VAR=2. Se comparan las pestañas que contienen cualquier ventana con las variables de entorno especificadas. De manera similar, var compara pestañas que contienen cualquier ventana con la variable de usuario especificada.

El campo state compara el estado de la pestaña. Los estados admitidos son: active, focused, needs_attention, parent_active, parent_focused y focused_os_window. Las pestañas activas son las pestañas que están activas en su ventana del sistema operativo principal. Solo hay una pestaña enfocada y es la pestaña a la que se envían los eventos del teclado. Si ninguna pestaña está enfocada, se compara la última pestaña enfocada. El valor focused_os_window compara todas las pestañas en la ventana del sistema operativo actualmente enfocada.

Ten en cuenta que puedes usar el comando kitten @ ls para obtener una lista de pestañas.

--no-response [=no]
No esperes una respuesta que indique el éxito de la acción. Ten en cuenta que usar esta opción significa que no se te notificará de los fallos.
--self [=no]
Cierra la pestaña de la ventana en la que se ejecuta este comando, en lugar de la pestaña activa.
--ignore-no-match [=no]
No devuelvas un error si no se encuentran pestañas para cerrar.
--help, -h [=no]
Mostrar ayuda para este comando

Opciones globales

--to
Una dirección para la instancia de kitty a controlar. Corresponde a la dirección dada a la instancia de kitty a través de la opción --listen-on o la configuración listen_on en kitty.conf. Si no se especifica, se verifica la variable de entorno KITTY_LISTEN_ON. Si tampoco se encuentra, los mensajes se envían al terminal de control de este proceso, es decir, solo funcionarán si este proceso se ejecuta dentro de una ventana de kitty.
--password
Una contraseña para usar al contactar a kitty. Esto hará que kitty solicite permiso al usuario para realizar la acción especificada, a menos que la contraseña haya sido aceptada previamente o esté preconfigurada en kitty.conf. Para usar una contraseña en blanco, especifica --use-password como siempre.
--password-file [=rc-pass]
Un archivo del cual leer la contraseña. Se ignora el espacio en blanco al final. Las rutas relativas se resuelven desde el directorio de configuración de kitty. Usa - para leer desde STDIN. Usa fd:num para leer desde el descriptor de archivo num. Se usa si no se proporciona --password. Por defecto, verifica el archivo rc-pass en el directorio de configuración de kitty.
--password-env [=KITTY_RC_PASSWORD]
El nombre de una variable de entorno de la cual leer la contraseña. Se usa si no se proporciona --password-file. Por defecto, verifica la variable de entorno KITTY_RC_PASSWORD.
--use-password [=if-available]
Si no hay contraseña disponible, kitty normalmente enviará el comando de control remoto sin contraseña. Esta opción se puede usar para forzar el uso de la contraseña proporcionada siempre o nunca. Si se establece en always y no se proporciona contraseña, se utiliza la contraseña en blanco.

Opciones: if-available, always, never
