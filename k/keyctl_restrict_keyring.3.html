keyctl_restrict_keyring(3)

Paquete: keyutils

Licencias: GPL2, LGPL2.1

KEYCTL_RESTRICT_KEYRING(3) Llamadas de gestión de claves de Linux KEYCTL_RESTRICT_KEYRING(3)

NOMBRE

keyctl_restrict_keyring - Restringe las claves que pueden enlazarse a un keyring

SINOPSIS

#include <keyutils.h>

long keyctl_restrict_keyring(key_serial_t keyring,
const char *type, const char *restriction);

DESCRIPCIÓN

keyctl_restrict_keyring() limita el enlace de claves al keyring dado utilizando un tipo de clave y un esquema de restricción proporcionados. Las opciones disponibles varían según el tipo de clave y típicamente contienen un nombre de restricción seguido opcionalmente por identificadores de clave u otros datos relevantes para la restricción. Si el tipo y la restricción son ambos NULL, el keyring rechazará todos los enlaces.

VALOR DE RETORNO

En caso de éxito, keyctl_restrict_keyring() devuelve 0. En caso de error, se devolverá el valor -1 y errno se habrá establecido con un error apropiado.

ERRORES

EDEADLK
Se evitó un ciclo de restricción. Dos keyrings no pueden restringirse mutuamente.
EEXIST
El keyring ya está restringido.
EINVAL
La cadena de restricción es inválida o demasiado grande.
ENOKEY
El tipo de clave en la restricción es inválido o no está disponible.
ENOTDIR
El identificador de clave proporcionado hace referencia a un elemento que no es un keyring.
ENOENT
El tipo de clave existe pero no admite restricciones.

ENLAZADO

Esta es una función de biblioteca que se puede encontrar en libkeyutils. Al enlazar, se debe especificar -lkeyutils al enlazador.

VER TAMBIÉN
