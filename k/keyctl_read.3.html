keyctl_read(3)

Paquete: keyutils

Licencias: GPL2, LGPL2.1

KEYCTL_READ(3) Llamadas de gestión de claves de Linux KEYCTL_READ(3)

NOMBRE

keyctl_read - leer una clave

SINOPSIS

#include <keyutils.h>

long keyctl_read(key_serial_t key, char *buffer, size_t buflen);

long keyctl_read_alloc(key_serial_t key, void **_buffer);

DESCRIPCIÓN

keyctl_read() lee la carga útil de una clave si el tipo de clave lo admite.

El llamante debe tener permiso de lectura en una clave para poder leerla.

buffer y buflen especifican el búfer en el que se colocarán los datos de la carga útil. Si el búfer es demasiado pequeño, se devolverá el tamaño completo de la carga útil y el contenido del búfer puede sobrescribirse de alguna manera indefinida.

keyctl_read_alloc() es similar a keyctl_read() excepto que asigna un búfer lo suficientemente grande como para contener los datos de la carga útil y los coloca en él. Si tiene éxito, se coloca un puntero al búfer en *_buffer. El llamante debe liberar el búfer.

keyctl_read_alloc() agrega un carácter NUL después de los datos que recupera, aunque esto no se cuenta en el valor de tamaño que devuelve.

LECTURA DE KEYRINGS

Esta llamada se puede usar para listar el contenido de un keyring. Los datos se presentan al usuario como una matriz de valores key_serial_t, cada uno de los cuales corresponde a una clave a la que el keyring tiene un enlace.

El tamaño del keyring será sizeof(key_serial_t) multiplicado por el número de claves. El tamaño de key_serial_t es invariante en diferentes tamaños de palabra, aunque el orden de bytes es el apropiado para el kernel.

VALOR DE RETORNO

En caso de éxito, keyctl_read() devuelve la cantidad de datos colocados en el búfer. Si el búfer era demasiado pequeño, se devolverá el tamaño de búfer requerido y el contenido del búfer puede haber sido sobrescrito de alguna manera indefinida.

En caso de éxito, keyctl_read_alloc() devuelve la cantidad de datos en el búfer.

En caso de error, ambas funciones establecen errno a un código apropiado y devuelven el valor -1.

ERRORES

ENOKEY
La clave especificada no es válida.
EKEYEXPIRED
La clave especificada ha expirado.
EKEYREVOKED
La clave especificada ha sido revocada.
EACCES
La clave existe, pero el proceso llamante no tiene permiso de lectura sobre ella.
EOPNOTSUPP
El tipo de clave no admite la lectura de los datos de la carga útil.

ENLACE

Esta es una función de biblioteca que se puede encontrar en libkeyutils. Al enlazar, se debe especificar -lkeyutils al enlazador.
