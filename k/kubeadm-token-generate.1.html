NOMBRE

kubeadm token generate - Genera e imprime un token de arranque, pero no lo crea en el servidor

SINOPSIS

kubeadm token generate [OPCIONES]

DESCRIPCIÓN

Este comando imprimirá un token de arranque generado aleatoriamente que puede ser utilizado con los comandos "init" y "join".

No es necesario usar este comando para generar un token. Puedes hacerlo tú mismo siempre que esté en el formato "[a-z0-9]{6}.[a-z0-9]{16}". Este comando se proporciona para mayor conveniencia al generar tokens en el formato dado.

También puedes usar "kubeadm init" sin especificar un token y generará e imprimirá uno para ti.

OPCIONES HEREDADAS DE COMANDOS PADRE

--dry-run=false Si habilitar o no el modo de prueba (dry-run)

--kubeconfig="/etc/kubernetes/admin.conf" El archivo kubeconfig a usar al comunicarse con el clúster. Si la opción no está establecida, se puede buscar un archivo kubeconfig existente en una serie de ubicaciones estándar.

--rootfs="" La ruta al sistema de archivos raíz 'real' del host. Esto hará que kubeadm realice un chroot en la ruta proporcionada.

--version=false --version, --version=raw imprime información de la versión y sale; --version=vX.Y.Z... establece la versión reportada
