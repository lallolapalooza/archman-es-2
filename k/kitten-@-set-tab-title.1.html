Nombre

kitten-@-set-tab-title - Establecer el título de la pestaña

Uso

kitten @ set-tab-title TÍTULO ...

Descripción

Establece el título para las pestañas especificadas. Si usas la opción --match, el título se establecerá para todas las pestañas coincidentes. Por defecto, solo la pestaña en la que se ejecuta el comando se ve afectada. Si no especificas un título, se usará el título de la ventana actualmente activa en la pestaña.

Opciones

--match, -m
La pestaña a la que coincidir. Las especificaciones de coincidencia son del tipo: campo:consulta. Donde campo puede ser uno de: id, index, title, window_id, window_title, pid, cwd, cmdline env, var, state, session y recent. consulta es la expresión a la que coincidir. Las expresiones pueden ser un número o una expresión regular, y se pueden combinar usando operadores booleanos.

El valor especial all coincide con todas las pestañas.

Para campos numéricos: id, index, window_id, pid y recent, la expresión se interpreta como un número, no como una expresión regular. Los valores negativos para id/window_id coinciden desde el número de id más alto hacia abajo, en particular, -1 es la pestaña/ventana creada más recientemente.

Al usar title o id, primero se busca una pestaña coincidente y, si no se encuentra, se busca una ventana coincidente, y se utiliza la pestaña de esa ventana.

También puedes usar window_id y window_title para coincidir con la pestaña que contiene la ventana con el id o título especificado.

El número de índice se utiliza para coincidir con la enésima pestaña en la ventana del SO actualmente activa. El número recent coincide con las pestañas activadas recientemente en la ventana del SO actualmente activa, donde cero es la pestaña actualmente activa, uno la pestaña activada previamente y así sucesivamente.

El campo session coincide con las pestañas que se crearon en la sesión especificada. Usa la expresión ^$ para coincidir con ventanas que no se crearon en una sesión y . para coincidir con la sesión actualmente activa y ~ para coincidir con la sesión actualmente activa o la última sesión activa cuando no hay ninguna sesión activa.

Al usar el campo env para coincidir con variables de entorno, puedes especificar solo el nombre de la variable de entorno o un nombre y valor, por ejemplo, env:MY_ENV_VAR=2. Se coinciden las pestañas que contienen cualquier ventana con las variables de entorno especificadas. De manera similar, var coincide con las pestañas que contienen cualquier ventana con las variables de usuario especificadas.

El campo state coincide con el estado de la pestaña. Los estados soportados son: active, focused, needs_attention, parent_active, parent_focused y focused_os_window. Las pestañas activas son las pestañas que están activas en su ventana de SO padre. Solo hay una pestaña con foco, y es la pestaña a la que se entregan los eventos del teclado. Si ninguna pestaña tiene foco, se coincide con la última pestaña con foco. El valor focused_os_window coincide con todas las pestañas en la ventana de SO con foco.

Ten en cuenta que puedes usar el comando kitten @ ls para obtener una lista de pestañas.

Opciones globales

--to
Una dirección para la instancia de kitty a controlar. Corresponde a la dirección dada a la instancia de kitty a través de la opción --listen-on o la configuración listen_on en kitty.conf. Si no se especifica, se verifica la variable de entorno KITTY_LISTEN_ON. Si tampoco se encuentra, los mensajes se envían al terminal de control de este proceso, es decir, solo funcionarán si este proceso se ejecuta dentro de una ventana de kitty.
--password
Una contraseña para usar al contactar a kitty. Esto hará que kitty pida al usuario permiso para realizar la acción especificada, a menos que la contraseña haya sido aceptada previamente o esté preconfigurada en kitty.conf. Para usar una contraseña en blanco, especifica --use-password como siempre.
--password-file [=rc-pass]
Un archivo desde el cual leer la contraseña. Se ignora el espacio en blanco final. Las rutas relativas se resuelven desde el directorio de configuración de kitty. Usa - para leer desde STDIN. Usa fd:num para leer desde el descriptor de archivo num. Se utiliza si no se proporciona --password. Por defecto, se busca el archivo rc-pass en el directorio de configuración de kitty.
--password-env [=KITTY_RC_PASSWORD]
El nombre de una variable de entorno desde la cual leer la contraseña. Se utiliza si no se proporciona --password-file. Por defecto, se busca la variable de entorno KITTY_RC_PASSWORD.
--use-password [=if-available]
Si no hay contraseña disponible, kitty generalmente enviará el comando de control remoto sin contraseña. Esta opción se puede usar para forzar el uso de la contraseña proporcionada siempre o nunca. Si se establece en always y no se proporciona ninguna contraseña, se utiliza la contraseña en blanco.

Opciones: if-available, always, never
