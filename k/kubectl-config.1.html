NOMBRE

kubectl config - Modificar archivos kubeconfig

SINOPSIS

kubectl config [OPCIONES]

DESCRIPCIÓN

Modifica archivos kubeconfig utilizando subcomandos como "kubectl config set current-context mi-contexto".

El orden de carga sigue estas reglas:

1.
Si se establece la opción --kubeconfig, entonces solo se carga ese archivo. La opción solo se puede establecer una vez y no se realiza ninguna fusión.
2.
Si la variable de entorno $KUBECONFIG está establecida, entonces se utiliza como una lista de rutas (reglas de delimitación de rutas normales para su sistema). Estas rutas se fusionan. Cuando se modifica un valor, se modifica en el archivo que define la sección. Cuando se crea un valor, se crea en el primer archivo que exista. Si ningún archivo de la cadena existe, se crea el último archivo de la lista.
3.
De lo contrario, se utiliza ${HOME}/.kube/config y no se realiza ninguna fusión.

OPCIONES

--kubeconfig="" usa un archivo kubeconfig particular

OPCIONES HEREDADAS DE COMANDOS PADRE

--as="" Usuario a suplantar para la operación. El usuario podría ser un usuario regular o una cuenta de servicio en un espacio de nombres.

--as-group=[] Grupo a suplantar para la operación, esta opción se puede repetir para especificar varios grupos.

--as-uid="" UID a suplantar para la operación.

--cache-dir="/home/usuario/.kube/cache" Directorio de caché predeterminado

--certificate-authority="" Ruta a un archivo de certificado para la autoridad de certificación

--client-certificate="" Ruta a un archivo de certificado de cliente para TLS

--client-key="" Ruta a un archivo de clave de cliente para TLS

--cluster="" El nombre del clúster kubeconfig a usar

--context="" El nombre del contexto kubeconfig a usar

--disable-compression=false Si es verdadero, renuncia a la compresión de respuestas para todas las solicitudes al servidor

--insecure-skip-tls-verify=false Si es verdadero, el certificado del servidor no se verificará en cuanto a su validez. Esto hará que sus conexiones HTTPS no sean seguras

--kuberc="" Ruta al archivo kuberc a usar para preferencias. Esto puede ser deshabilitado exportando el feature gate KUBECTL_KUBERC=false o desactivando el feature KUBERC=off.

--match-server-version=false Requiere que la versión del servidor coincida con la versión del cliente

-n, --namespace="" Si está presente, el ámbito del espacio de nombres para esta solicitud de CLI

--password="" Contraseña para autenticación básica al servidor de la API

--profile="none" Nombre del perfil a capturar. Uno de (none|cpu|heap|goroutine|threadcreate|block|mutex)

--profile-output="profile.pprof" Nombre del archivo en el que escribir el perfil

--request-timeout="0" El tiempo de espera antes de rendirse en una única solicitud al servidor. Los valores distintos de cero deben contener una unidad de tiempo correspondiente (por ejemplo, 1s, 2m, 3h). Un valor de cero significa no agotar el tiempo de espera de las solicitudes.

-s, --server="" La dirección y el puerto del servidor de la API de Kubernetes

--tls-server-name="" Nombre del servidor a utilizar para la validación del certificado del servidor. Si no se proporciona, se utiliza el nombre de host utilizado para contactar al servidor

--token="" Token Bearer para la autenticación al servidor de la API

--user="" El nombre del usuario kubeconfig a usar

--username="" Nombre de usuario para autenticación básica al servidor de la API

--version=false --version, --version=raw imprime información de versión y sale; --version=vX.Y.Z... establece la versión reportada

--warnings-as-errors=false Tratar las advertencias recibidas del servidor como errores y salir con un código de salida distinto de cero
