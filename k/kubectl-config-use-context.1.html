NOMBRE

kubectl config use-context - Establece el contexto actual en un archivo kubeconfig

SINOPSIS

kubectl config use-context [OPCIONES]

DESCRIPCIÓN

Establece el contexto actual en un archivo kubeconfig.

OPCIONES HEREDADAS DE COMANDOS PADRE

--as="" Nombre de usuario a suplantar para la operación. El usuario puede ser un usuario regular o una cuenta de servicio en un espacio de nombres.

--as-group=[] Grupo a suplantar para la operación, esta bandera se puede repetir para especificar múltiples grupos.

--as-uid="" UID a suplantar para la operación.

--cache-dir="/home/username/.kube/cache" Directorio de caché predeterminado

--certificate-authority="" Ruta a un archivo de certificado para la autoridad de certificación

--client-certificate="" Ruta a un archivo de certificado de cliente para TLS

--client-key="" Ruta a un archivo de clave de cliente para TLS

--cluster="" El nombre del clúster kubeconfig a utilizar

--context="" El nombre del contexto kubeconfig a utilizar

--disable-compression=false Si es verdadero, se desactiva la compresión de respuestas para todas las solicitudes al servidor

--insecure-skip-tls-verify=false Si es verdadero, el certificado del servidor no se verificará en cuanto a su validez. Esto hará que tus conexiones HTTPS sean inseguras

--kubeconfig="" usa un archivo kubeconfig particular

--kuberc="" Ruta al archivo kuberc a utilizar para preferencias. Esto se puede deshabilitar exportando el feature gate KUBECTL_KUBERC=false o desactivando el feature KUBERC=off.

--match-server-version=false Requiere que la versión del servidor coincida con la del cliente

-n, --namespace="" Si está presente, el ámbito del espacio de nombres para esta solicitud de CLI

--password="" Contraseña para la autenticación básica en el servidor API

--profile="none" Nombre del perfil a capturar. Uno de (ninguno|cpu|heap|goroutine|threadcreate|block|mutex)

--profile-output="profile.pprof" Nombre del archivo donde escribir el perfil

--request-timeout="0" El tiempo de espera antes de desistir de una solicitud individual al servidor. Los valores distintos de cero deben contener una unidad de tiempo correspondiente (por ejemplo, 1s, 2m, 3h). Un valor de cero significa que las solicitudes no tienen tiempo de espera.

-s, --server="" La dirección y el puerto del servidor API de Kubernetes

--tls-server-name="" Nombre del servidor a utilizar para la validación del certificado del servidor. Si no se proporciona, se utiliza el nombre de host utilizado para contactar al servidor

--token="" Token de portador para la autenticación en el servidor API

--user="" El nombre de usuario kubeconfig a utilizar

--username="" Nombre de usuario para la autenticación básica en el servidor API

--version=false --version, --version=raw imprime información de la versión y sale; --version=vX.Y.Z... establece la versión reportada

--warnings-as-errors=false Trata las advertencias recibidas del servidor como errores y sale con un código de salida distinto de cero

EJEMPLO

  # Usa el contexto para el clúster minikube
  kubectl config use-context minikube
