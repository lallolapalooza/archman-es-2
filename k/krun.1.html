krun(1) Manual de Comandos Generales krun(1)

NOMBRE

krun - runtime OCI basado en crun que utiliza libkrun para ejecutar programas conteneurizados en entornos KVM aislados

SINOPSIS

krun [opciones globales] comando [opciones de comando] [argumentos...]

DESCRIPCIÓN

krun es un subpaquete del programa de línea de comandos crun para ejecutar contenedores Linux que siguen el formato Open Container Initiative (OCI). El comando krun es un enlace simbólico al ejecutable crun, que le indica a crun que se ejecute en modo krun.

krun utiliza la biblioteca dinámica libkrun para ejecutar procesos en un entorno aislado utilizando la virtualización KVM.

libkrun integra un VMM (Virtual Machine Monitor, el lado de espacio de usuario de un Hipervisor) con la cantidad mínima de dispositivos emulados necesarios para su propósito, abstraendo la mayor parte de la complejidad de la gestión de máquinas virtuales.

Debido al aislamiento adicional, compartir contenido con procesos y otros contenedores fuera de la VM de krun es más difícil.

COMANDOS

Consulte la página del manual de crun.1 para ver los comandos disponibles para krun.
