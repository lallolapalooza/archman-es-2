Nombre

kitten-@-detach-window - Desacopla las ventanas especificadas y las coloca en una pestaña diferente/nueva

Uso

kitten @ detach-window

Descripción

Desacopla las ventanas especificadas y las mueve a una nueva pestaña, a una nueva ventana del sistema operativo o las añade a la pestaña especificada. Usa el valor especial new para --target-tab para mover a una nueva pestaña. Si no se especifica una pestaña de destino, las ventanas se mueven a una nueva ventana del sistema operativo.

Opciones

--match, -m
La ventana a coincidir. Las especificaciones de coincidencia tienen la forma: campo:consulta. Donde campo puede ser uno de: id, title, pid, cwd, cmdline, num, env, var, state, neighbor, session y recent. consulta es la expresión a coincidir. Las expresiones pueden ser un número o una expresión regular, y pueden combinarse usando operadores booleanos.

El valor especial all coincide con todas las ventanas.

Para campos numéricos: id, pid, num y recent, la expresión se interpreta como un número, no como una expresión regular. Los valores negativos para id coinciden desde el número de id más alto hacia abajo, en particular, -1 es la ventana creada más recientemente.

El campo num se refiere a la posición de la ventana en la pestaña actual, empezando desde cero y contando en sentido horario (esto es lo mismo que el orden en que las ventanas son reportadas por el comando kitten @ ls).

El id de la ventana de la ventana actual está disponible como la variable de entorno KITTY_WINDOW_ID.

El campo recent se refiere a las ventanas activas recientemente en la pestaña actualmente activa, con cero siendo la ventana actualmente activa, uno siendo la ventana activa previamente y así sucesivamente.

El campo neighbor se refiere a un vecino de la ventana activa en la dirección especificada, que puede ser: left, right, top o bottom.

El campo session coincide con ventanas que fueron creadas en la sesión especificada. Usa la expresión ^$ para coincidir con ventanas que no fueron creadas en una sesión y . para coincidir con la sesión actualmente activa y ~ para coincidir con la sesión actualmente activa o la última sesión activa cuando no hay sesión activa.

Cuando uses el campo env para coincidir con variables de entorno, puedes especificar solo el nombre de la variable de entorno o un nombre y un valor, por ejemplo, env:MY_ENV_VAR=2.

De manera similar, el campo var coincide con variables de usuario establecidas en la ventana. Puedes especificar nombre o nombre y valor como con el campo env.

El campo state coincide con el estado de la ventana. Los estados soportados son: active, focused, needs_attention, parent_active, parent_focused, focused_os_window, self, overlay_parent. Las ventanas activas son las ventanas que están activas en su pestaña padre. Solo hay una ventana enfocada y es la ventana a la que se entregan los eventos de teclado. Si ninguna ventana está enfocada, se coincide con la última ventana enfocada. El valor focused_os_window coincide con todas las ventanas en la ventana del sistema operativo actualmente enfocada. El valor self coincide con la ventana en la que se ejecuta el comando de control remoto. El valor overlay_parent coincide con la ventana que está debajo de la ventana self, cuando la ventana self es una superposición.

Ten en cuenta que puedes usar el comando kitten @ ls para obtener una lista de ventanas.

--target-tab, -t
La pestaña a coincidir. Las especificaciones de coincidencia tienen la forma: campo:consulta. Donde campo puede ser uno de: id, index, title, window_id, window_title, pid, cwd, cmdline env, var, state, session y recent. consulta es la expresión a coincidir. Las expresiones pueden ser un número o una expresión regular, y pueden combinarse usando operadores booleanos.

El valor especial all coincide con todas las pestañas.

Para campos numéricos: id, index, window_id, pid y recent, la expresión se interpreta como un número, no como una expresión regular. Los valores negativos para id/window_id coinciden desde el número de id más alto hacia abajo, en particular, -1 es la pestaña/ventana creada más recientemente.

Cuando uses title o id, primero se busca una pestaña que coincida, y si no se encuentra, se busca una ventana que coincida, y se usa la pestaña de esa ventana.

También puedes usar window_id y window_title para coincidir con la pestaña que contiene la ventana con el id o título especificado.

El número de índice se usa para coincidir con la n-ésima pestaña en la ventana del sistema operativo actualmente activa. El número recent coincide con pestañas activas recientemente en la ventana del sistema operativo actualmente activa, con cero siendo la pestaña actualmente activa, uno la pestaña previamente activa y así sucesivamente.

El campo session coincide con pestañas que fueron creadas en la sesión especificada. Usa la expresión ^$ para coincidir con ventanas que no fueron creadas en una sesión y . para coincidir con la sesión actualmente activa y ~ para coincidir con la sesión actualmente activa o la última sesión activa cuando no hay sesión activa.

Cuando uses el campo env para coincidir con variables de entorno, puedes especificar solo el nombre de la variable de entorno o un nombre y un valor, por ejemplo, env:MY_ENV_VAR=2. Se coinciden las pestañas que contengan cualquier ventana con las variables de entorno especificadas. De manera similar, var coincide con pestañas que contengan cualquier ventana con la variable de usuario especificada.

El campo state coincide con el estado de la pestaña. Los estados soportados son: active, focused, needs_attention, parent_active, parent_focused y focused_os_window. Las pestañas activas son las pestañas que están activas en su ventana padre del sistema operativo. Solo hay una pestaña enfocada y es la pestaña a la que se entregan los eventos de teclado. Si ninguna pestaña está enfocada, se coincide con la última pestaña enfocada. El valor focused_os_window coincide con todas las pestañas en la ventana del sistema operativo actualmente enfocada.

Ten en cuenta que puedes usar el comando kitten @ ls para obtener una lista de pestañas. Usa el valor especial new para mover a una nueva pestaña.

--self [=no]
Desacopla la ventana en la que se ejecuta este comando, en lugar de la ventana activa.
--stay-in-tab [=no]
Mantiene el foco en una ventana en la pestaña actualmente enfocada después de mover las ventanas especificadas.
--help, -h [=no]
Muestra la ayuda para este comando

Opciones globales

--to
Una dirección para la instancia de kitty a controlar. Corresponde a la dirección dada a la instancia de kitty a través de la opción --listen-on o la configuración listen_on en kitty.conf. Si no se especifica, se comprueba la variable de entorno KITTY_LISTEN_ON. Si tampoco se encuentra, los mensajes se envían al terminal de control de este proceso, es decir, solo funcionarán si este proceso se ejecuta dentro de una ventana de kitty.
--password
Una contraseña a usar al contactar con kitty. Esto hará que kitty pregunte al usuario para dar permiso para realizar la acción especificada, a menos que la contraseña haya sido aceptada antes o esté preconfigurada en kitty.conf. Para usar una contraseña en blanco especifica --use-password como always.
--password-file [=rc-pass]
Un archivo del cual leer la contraseña. El espacio en blanco final se ignora. Las rutas relativas se resuelven desde el directorio de configuración de kitty. Usa - para leer desde STDIN. Usa fd:num para leer desde el descriptor de archivo num. Se usa si no se proporciona --password. Por defecto, comprueba el archivo rc-pass en el directorio de configuración de kitty.
--password-env [=KITTY_RC_PASSWORD]
El nombre de una variable de entorno de la cual leer la contraseña. Se usa si no se proporciona --password-file. Por defecto, comprueba la variable de entorno KITTY_RC_PASSWORD.
--use-password [=if-available]
Si no hay contraseña disponible, kitty normalmente solo enviará el comando de control remoto sin contraseña. Esta opción se puede usar para forzar que siempre o nunca use la contraseña proporcionada. Si se establece en always y no se proporciona contraseña, se usa la contraseña en blanco.

Choices: if-available, always, never
