kbuffer_event_size(3)

Paquete: libtraceevent

Licencias: GPL-2.0-only, LGPL-2.1-only

LIBTRACEEVENT(3) Manual de libtraceevent LIBTRACEEVENT(3)

NOMBRE

kbuffer_read_event, kbuffer_next_event, kbuffer_missed_events, kbuffer_event_size, kbuffer_curr_size, kbuffer_curr_offset, kbuffer_curr_index, kbuffer_read_buffer - Funciones para leer el búfer secundario (sub buffer) de kbuffer.

SINOPSIS

#include <kbuffer.h>
void *kbuffer_read_event(struct kbuffer *kbuf, unsigned long long *ts);
void *kbuffer_next_event(struct kbuffer *kbuf, unsigned long long *ts);
void *kbuffer_read_at_offset(struct kbuffer *kbuf, int offset, unsigned long long *ts);
int kbuffer_missed_events(struct kbuffer *kbuf);
int kbuffer_event_size(struct kbuffer *kbuf);
int kbuffer_curr_size(struct kbuffer *kbuf);
int kbuffer_curr_offset(struct kbuffer *kbuf);
int kbuffer_curr_index(struct kbuffer *kbuf);
int kbuffer_read_buffer(struct kbuffer *kbuf, void *buffer, int len);

DESCRIPCIÓN

La función kbuffer_read_event() lee el siguiente evento en el descriptor kbuf y si ts no es NULL, colocará su marca de tiempo en él. Esto no modifica el descriptor kbuf, y llamar a esta función múltiples veces devolverá el mismo resultado.

La función kbuffer_next_event() devolverá el siguiente evento en el descriptor kbuf. También establecerá ts a la marca de tiempo del evento devuelto. Se devuelve NULL si no hay más eventos y ts no estará definido. Tenga en cuenta que si esto se llama directamente después de un kbuffer_load_subbuffer(), es probable que produzca un resultado inesperado, ya que devolverá el segundo evento y no el primer evento. Normalmente, esta función solo se utiliza para pasar al siguiente evento y para saber si hay más eventos para leer, y kbuffer_read_event() se llama siempre primero.

La función kbuffer_read_at_offset() devuelve el evento ubicado en un offset dado desde el principio del búfer secundario. Este offset se puede obtener mediante kbuffer_curr_offset(). Si ts apunta a un unsigned long long, se establecerá a la marca de tiempo del evento en el offset dado.

Si el búfer secundario ha omitido eventos antes, kbuffer_missed_events() devolverá un valor distinto de cero. Si devuelve -1, significa que hubo eventos omitidos, pero el número exacto de eventos omitidos es desconocido. Si devuelve un número positivo, entonces el número de eventos omitidos es el valor devuelto.

La función kbuffer_event_size() devuelve el tamaño de la porción de datos del evento actual (el que sería devuelto por kbuffer_read_event()).

La función kbuffer_curr_size() devuelve el tamaño total del registro del evento actual (el que sería devuelto por kbuffer_read_event(). La diferencia aquí es que el valor devuelto incluye el tamaño de los metadatos del registro del evento que no forman parte de lo devuelto por kbuffer_read_event().

La función kbuffer_curr_offset() devuelve el offset desde el principio del búfer secundario donde comienza la metadato del evento actual para el registro. El primer evento no estará en el offset cero. Este offset se puede utilizar para recuperar el evento con kbuffer_read_at_offset().

La función kbuffer_curr_index() devuelve el índice desde el principio de la porción de datos del búfer secundario donde se encuentran los metadatos del evento actual para el registro. El primer evento probablemente será cero, pero puede que no lo sea si tiene una marca de tiempo adjunta.

La función kbuffer_read_buffer() llenará el buffer proporcionado desde el kbuf de la misma manera que el kernel realizaría una llamada al sistema de lectura. Es decir, si la longitud len es menor que el tamaño del búfer secundario, o si el índice actual de kbuffer no es cero, comenzará a copiar desde el evento actual de kbuf y creará un nuevo búfer secundario (con una marca de tiempo y una cabecera de confirmación) con el evento encontrado y todos los eventos posteriores que quepan dentro de len. El len debe incluir el tamaño de la cabecera del búfer secundario, así como los eventos a incluir. Es decir, len es el tamaño asignado de buffer que se puede llenar. El valor devuelto por esta función es el índice del final del último evento que se agregó. Si no hay más eventos, se devuelve cero, y si el búfer no puede copiar ningún evento porque len era demasiado pequeño, se devuelve -1.

VALOR DE RETORNO

kbuffer_read_event() devuelve el evento en el que se encuentra actualmente el descriptor kbuf, o NULL si se ha pasado el último evento (mediante kbuffer_next_event()).

kbuffer_next_event() devuelve el evento siguiente al evento actual o NULL si no hay más eventos.

kbuffer_read_at_offset() devuelve el evento en un offset dado desde el inicio del búfer secundario almacenado en kbuf, o NULL si no existe ningún evento. Nota: offset solo necesita ser un offset que apunte al registro, o que esté al inicio del mismo. No es necesario que esté exactamente al principio del registro.

kbuffer_missed_events() devuelve 0 si no hubo eventos omitidos antes del búfer secundario cargado. Devuelve -1 si hubo un número desconocido de eventos omitidos, o si se conoce el número de eventos omitidos, se devolverá ese número.

kbuffer_event_size() devuelve el tamaño de la carga útil de datos del evento actual de kbuf.

kbuffer_curr_size() devuelve el tamaño total del registro del evento actual de kbuf. Esto incluye el tamaño de los metadatos de ese registro.

kbuf_curr_offset() devuelve el offset del registro actual desde el principio del búfer secundario de kbuf.

kbuf_curr_index() devuelve el índice del registro actual desde el principio de la sección de datos de kbuf.

kbuf_read_buffer() devuelve el índice del final del último evento que se llenó en buffer. Si no hay más eventos para copiar desde start, se devuelve 0. Si len no es lo suficientemente grande para contener ningún evento, se devuelve -1.

EJEMPLO

#include <stdio.h>
#include <stdlib.h>
#include <fcntl.h>
#include <unistd.h>
#include <sys/stat.h>
#include <kbuffer.h>
int main (int argc, char **argv)
{
        unsigned long long ts;
        struct kbuffer *kbuf;
        struct stat st;
        char *buf;
        void *event;
        int save_offset = -1;
        int record_size;
        int offset;
        int index;
        int size;
        int ret;
        int fd;
        int i = 0;
        if (argc < 2) {
                printf("uso: %s página-de-búfer-secundario-cruda\n", argv[0]);
                printf(" Intente: dd count=1 bs=4096 if=/sys/kernel/tracing/per_cpu/cpu0/trace_pipe_raw of=/tmp/file\n");
                exit(0);
        }
        if (stat(argv[1], &st) < 0) {
                perror("stat");
                exit(-1);
        }
        buf = malloc(st.st_size);
        if (!buf) {
                perror("Asignación de búfer");
                exit(-1);
        }
        fd = open(argv[1], O_RDONLY);
        if (fd < 0) {
                perror(argv[1]);
                exit(-1);
        }
        ret = read(fd, buf, st.st_size);
        if (ret < 0) {
                perror("Lectura del búfer");
                exit(-1);
        }
        close(fd);
        kbuf = kbuffer_alloc(KBUFFER_ENDIAN_SAME_AS_HOST,
                             KBUFFER_LSIZE_SAME_AS_HOST);
        if (!kbuf) {
                perror("Creación de kbuffer");
                exit(-1);
        }
        ret = kbuffer_load_subbuffer(kbuf, buf);
        if (ret < 0) {
                perror("Carga de búfer secundario");
                exit(-1);
        }
        if (kbuffer_subbuffer_size(kbuf) > st.st_size) {
                fprintf(stderr, "kbuffer es más grande que el tamaño crudo %d > %ld\n",
                        kbuffer_subbuffer_size(kbuf), st.st_size);
                exit(-1);
        }
        ret = kbuffer_missed_events(kbuf);
        if (ret) {
                if (ret > 0)
                        printf("Se omitieron %d eventos antes de este búfer\n", ret);
                else
                        printf("Se omitió un número desconocido de eventos antes de este búfer\n");
        }
        do {
                event = kbuffer_read_event(kbuf, &ts);
                if (event) {
                        record_size = kbuffer_curr_size(kbuf);
                        offset = kbuffer_curr_offset(kbuf);
                        index = kbuffer_curr_index(kbuf);
                        size = kbuffer_event_size(kbuf);
                        if (i == 20)
save_offset = offset; printf(" evento %3d ts:%lld\trecord_size:%d size:%d\tindex:%d offset:%d\n", i++, ts, record_size, size, index, offset); event = kbuffer_next_event(kbuf, NULL); } } while (event); if (!event) printf("Sub buffer finalizado\n"); if (save_offset > 0) { event = kbuffer_read_at_offset(kbuf, save_offset, &ts); if (!event) { fprintf(stderr, "Raro, no se puede encontrar el evento 20 en la posición %d\n", save_offset); exit(-1); } record_size = kbuffer_curr_size(kbuf); offset = kbuffer_curr_offset(kbuf); index = kbuffer_curr_index(kbuf); size = kbuffer_event_size(kbuf); printf("\n evento 20 guardado ts:%lld\trecord_size:%d size:%d\tindex:%d offset:%d\n\n", ts, record_size, size, index, offset); } kbuffer_free(kbuf); return 0; }
