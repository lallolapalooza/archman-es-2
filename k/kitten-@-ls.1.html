Nombre

kitten-@-ls - Listar pestañas/ventanas

Uso

kitten @ ls

Descripción

Lista las ventanas. La lista se devuelve como un árbol JSON. El nivel superior es una lista de ventanas de kitty del sistema operativo. Cada ventana del SO tiene un id y una lista de pestañas. Cada pestaña tiene su propio id, un título y una lista de ventanas. Cada ventana tiene un id, título, directorio de trabajo actual, ID de proceso (PID), línea de comandos y entorno del proceso que se ejecuta en la ventana. Además, al ejecutar el comando dentro de una ventana de kitty, esa ventana puede ser identificada por el parámetro is_self.

Puede usar estos criterios para seleccionar ventanas/pestañas para los otros comandos.

Puede limitar las ventanas/pestañas en la salida utilizando las opciones --match y --match-tab.

Opciones

--all-env-vars [=no]
Mostrar todas las variables de entorno en la salida, no solo las que difieren.
--self [=no]
Solo listar la ventana en la que se ejecuta este comando.
--output-format [=json]
Salida en formato JSON o de sesión de kitty

Opciones: json, session

--match, -m
La ventana a coincidir. Las especificaciones de coincidencia tienen el formato: campo:consulta. Donde campo puede ser uno de: id, title, pid, cwd, cmdline, num, env, var, state, neighbor, session y recent. Consulta es la expresión a coincidir. Las expresiones pueden ser un número o una expresión regular, y se pueden combinar usando operadores booleanos.

El valor especial all coincide con todas las ventanas.

Para campos numéricos: id, pid, num y recent, la expresión se interpreta como un número, no como una expresión regular. Los valores negativos para id coinciden desde el número de id más alto hacia abajo, en particular, -1 es la ventana creada más recientemente.

El campo num se refiere a la posición de la ventana en la pestaña actual, comenzando desde cero y contando en sentido horario (este es el mismo orden en que se informan las ventanas por el comando kitten @ ls).

El id de ventana de la ventana actual está disponible como la variable de entorno KITTY_WINDOW_ID.

El campo recent se refiere a las ventanas activadas recientemente en la pestaña activa actual, donde cero es la ventana activa actual, uno es la ventana activada previamente y así sucesivamente.

El campo neighbor se refiere a un vecino de la ventana activa en la dirección especificada, que puede ser: left, right, top o bottom.

El campo session coincide con ventanas que fueron creadas en la sesión especificada. Usa la expresión ^$ para coincidir con ventanas que no fueron creadas en una sesión y . para coincidir con la sesión activa actual y ~ para coincidir con la sesión activa actual o la última sesión activa cuando no hay ninguna sesión activa.

Al usar el campo env para coincidir con variables de entorno, puedes especificar solo el nombre de la variable de entorno o un nombre y valor, por ejemplo, env:MY_ENV_VAR=2.

De manera similar, el campo var coincide con variables de usuario establecidas en la ventana. Puedes especificar el nombre o el nombre y el valor como con el campo env.

El campo state coincide con el estado de la ventana. Los estados admitidos son: active, focused, needs_attention, parent_active, parent_focused, focused_os_window, self, overlay_parent. Las ventanas activas son las ventanas que están activas en su pestaña padre. Solo hay una ventana enfocada y es la ventana a la que se entregan los eventos del teclado. Si no hay ninguna ventana enfocada, se coincide con la última ventana enfocada. El valor focused_os_window coincide con todas las ventanas en la ventana del SO enfocada actualmente. El valor self coincide con la ventana en la que se ejecuta el comando de control remoto. El valor overlay_parent coincide con la ventana que está debajo de la ventana self, cuando la ventana self es una superposición.

Tenga en cuenta que puede usar el comando kitten @ ls para obtener una lista de ventanas.

--match-tab, -t
La pestaña a coincidir. Las especificaciones de coincidencia tienen el formato: campo:consulta. Donde campo puede ser uno de: id, index, title, window_id, window_title, pid, cwd, cmdline env, var, state, session y recent. consulta es la expresión a coincidir. Las expresiones pueden ser un número o una expresión regular, y se pueden combinar usando operadores booleanos.

El valor especial all coincide con todas las pestañas.

Para campos numéricos: id, index, window_id, pid y recent, la expresión se interpreta como un número, no como una expresión regular. Los valores negativos para id/window_id coinciden desde el número de id más alto hacia abajo, en particular, -1 es la pestaña/ventana creada más recientemente.

Al usar title o id, primero se busca una pestaña coincidente y, si no se encuentra, se busca una ventana coincidente, y se utiliza la pestaña de esa ventana.

También puede usar window_id y window_title para coincidir con la pestaña que contiene la ventana con el id o título especificado.

El número index se utiliza para coincidir con la n-ésima pestaña en la ventana del SO activa actual. El número recent coincide con las pestañas activadas recientemente en la ventana del SO activa actual, donde cero es la pestaña activa actual, uno la pestaña activada previamente y así sucesivamente.

El campo session coincide con pestañas que fueron creadas en la sesión especificada. Usa la expresión ^$ para coincidir con ventanas que no fueron creadas en una sesión y . para coincidir con la sesión activa actual y ~ para coincidir con la sesión activa actual o la última sesión activa cuando no hay ninguna sesión activa.

Al usar el campo env para coincidir con variables de entorno, puedes especificar solo el nombre de la variable de entorno o un nombre y valor, por ejemplo, env:MY_ENV_VAR=2. Coincidirán las pestañas que contengan cualquier ventana con las variables de entorno especificadas. De manera similar, var coincide con pestañas que contengan cualquier ventana con la variable de usuario especificada.

El campo state coincide con el estado de la pestaña. Los estados admitidos son: active, focused, needs_attention, parent_active, parent_focused y focused_os_window. Las pestañas activas son las pestañas que están activas en su ventana de SO padre. Solo hay una pestaña enfocada y es la pestaña a la que se entregan los eventos del teclado. Si no hay ninguna pestaña enfocada, se coincide con la última pestaña enfocada. El valor focused_os_window coincide con todas las pestañas en la ventana de SO enfocada actualmente.

Tenga en cuenta que puede usar el comando kitten @ ls para obtener una lista de pestañas.

Opciones globales

--to
Una dirección para la instancia de kitty a controlar. Corresponde a la dirección dada a la instancia de kitty a través de la opción --listen-on o la configuración listen_on en kitty.conf. Si no se especifica, se comprueba la variable de entorno KITTY_LISTEN_ON. Si tampoco se encuentra, los mensajes se envían a la terminal de control para este proceso, es decir, solo funcionarán si este proceso se ejecuta dentro de una ventana de kitty.
--password
Una contraseña para usar al contactar a kitty. Esto hará que kitty solicite al usuario permiso para realizar la acción especificada, a menos que la contraseña haya sido aceptada antes o esté preconfigurada en kitty.conf. Para usar una contraseña vacía, especifique --use-password como siempre.
--password-file [=rc-pass]
Un archivo del cual leer la contraseña. Se ignoran los espacios en blanco al final. Las rutas relativas se resuelven desde el directorio de configuración de kitty. Usa - para leer desde STDIN. Usa fd:num para leer desde el descriptor de archivo num. Se usa si no se suministra --password. Por defecto, se comprueba el archivo rc-pass en el directorio de configuración de kitty.
--password-env [=KITTY_RC_PASSWORD]
El nombre de una variable de entorno de la cual leer la contraseña. Se usa si no se suministra --password-file. Por defecto, se comprueba la variable de entorno KITTY_RC_PASSWO
RD.
--use-password [=si-está-disponib
le]
Si no hay una contraseña disponible, kitty normalmente simplemente enviará el comando de control remoto sin una contraseña. Esta opción se puede usar para forzar que siempre o nunca use la contraseña proporcionada. Si se establece en always y no se proporciona una contraseña, se usa la contraseña en blanco.
