Nombre

kitten-@-goto-layout - Establecer el diseño de ventanas

Uso

kitten @ goto-layout NOMBRE_DEL_DISEÑO

Descripción

Establece el diseño de ventanas en las pestañas especificadas (o en la pestaña activa si no se especifica). Puedes usar el valor especial de coincidencia all para establecer el diseño en todas las pestañas. En caso de que haya múltiples diseños con el mismo nombre pero con opciones diferentes, especifica la definición completa del diseño o un prefijo único de la definición completa.

Opciones

--match, -m
La pestaña a la que se aplicará la coincidencia. Las especificaciones de coincidencia son del tipo: campo:consulta. Donde campo puede ser uno de: id, index, title, window_id, window_title, pid, cwd, cmdline env, var, state, session y recent. consulta es la expresión a la que se aplicará la coincidencia. Las expresiones pueden ser un número o una expresión regular, y se pueden combinar usando operadores booleanos.

El valor especial all coincide con todas las pestañas.

Para campos numéricos: id, index, window_id, pid y recent, la expresión se interpreta como un número, no como una expresión regular. Los valores negativos para id/window_id coinciden desde el número de id más alto hacia abajo, en particular, -1 es la pestaña/ventana creada más recientemente.

Al usar title o id, primero se busca una pestaña coincidente y, si no se encuentra, se busca una ventana coincidente y se utiliza la pestaña de esa ventana.

También puedes usar window_id y window_title para hacer coincidir la pestaña que contiene la ventana con el id o título especificado.

El número de índice se utiliza para hacer coincidir la n-ésima pestaña en la ventana del sistema operativo activa actualmente. El número recent coincide con las pestañas activadas recientemente en la ventana del sistema operativo activa actualmente, siendo cero la pestaña activa actualmente, uno la pestaña activada previamente y así sucesivamente.

El campo session coincide con las pestañas que se crearon en la sesión especificada. Usa la expresión ^$ para hacer coincidir ventanas que no se crearon en una sesión y . para hacer coincidir la sesión activa actualmente y ~ para hacer coincidir la sesión activa actual o la última sesión activa cuando no hay ninguna sesión activa.

Al usar el campo env para hacer coincidir variables de entorno, puedes especificar solo el nombre de la variable de entorno o un nombre y un valor, por ejemplo, env:MY_ENV_VAR=2. Se coinciden las pestañas que contienen cualquier ventana con las variables de entorno especificadas. De manera similar, var coincide con pestañas que contienen cualquier ventana con la variable de usuario especificada.

El campo state coincide con el estado de la pestaña. Los estados admitidos son: active, focused, needs_attention, parent_active, parent_focused y focused_os_window. Las pestañas activas son las pestañas que están activas en su ventana principal del sistema operativo. Solo hay una pestaña enfocada y es la pestaña a la que se entregan los eventos del teclado. Si ninguna pestaña está enfocada, se coincide con la última pestaña enfocada. El valor focused_os_window coincide con todas las pestañas en la ventana del sistema operativo actualmente enfocada.

Ten en cuenta que puedes usar el comando kitten @ ls para obtener una lista de pestañas.

Opciones globales

--to
Una dirección para la instancia de kitty a controlar. Corresponde a la dirección dada a la instancia de kitty a través de la opción --listen-on o la configuración listen_on en kitty.conf. Si no se especifica, se comprueba la variable de entorno KITTY_LISTEN_ON. Si tampoco se encuentra, los mensajes se envían al terminal de control para este proceso, es decir, solo funcionarán si este proceso se ejecuta dentro de una ventana de kitty.
--password
Una contraseña para usar al contactar con kitty. Esto hará que kitty pida permiso al usuario para realizar la acción especificada, a menos que la contraseña haya sido aceptada previamente o esté preconfigurada en kitty.conf. Para usar una contraseña en blanco, especifica --use-password como siempre.
--password-file [=rc-pass]
Un archivo desde el cual leer la contraseña. Se ignoran los espacios en blanco al final. Las rutas relativas se resuelven desde el directorio de configuración de kitty. Usa - para leer desde STDIN. Usa fd:num para leer desde el descriptor de archivo num. Se utiliza si no se proporciona --password. Por defecto, comprueba el archivo rc-pass en el directorio de configuración de kitty.
--password-env [=KITTY_RC_PASSWORD]
El nombre de una variable de entorno desde la que leer la contraseña. Se utiliza si no se proporciona --password-file. Por defecto, comprueba la variable de entorno KITTY_RC_PASSWORD.
--use-password [=if-available]
Si no hay contraseña disponible, kitty normalmente enviará el comando de control remoto sin contraseña. Esta opción se puede usar para forzar que siempre o nunca se use la contraseña proporcionada. Si se establece en always y no se proporciona contraseña, se utiliza la contraseña en blanco.

Opciones: if-available, always, never
