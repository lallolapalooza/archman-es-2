Nombre

kitten-@-get-colors - Obtener colores de terminal

Uso

kitten @ get-colors

Descripción

Obtiene los colores de la terminal para la ventana especificada (por defecto, la ventana activa). Los colores se mostrarán en STDOUT en la misma sintaxis que se utiliza para kitty.conf.

Para obtener un solo color, use:
get-colors | grep "^background " | tr -s | cut -d" " -f2

Reemplace background en la línea anterior por el color que le interese.

Opciones

--configured, -c [=no]
En lugar de mostrar los colores de la ventana especificada, muestra los colores configurados actualmente.
--match, -m
La ventana a coincidir. Las especificaciones de coincidencia tienen el formato: campo:consulta. Donde campo puede ser uno de: id, title, pid, cwd, cmdline, num, env, var, state, neighbor, session y recent. consulta es la expresión a coincidir. Las expresiones pueden ser un número o una expresión regular, y se pueden combinar usando operadores booleanos.

El valor especial all coincide con todas las ventanas.

Para campos numéricos: id, pid, num y recent, la expresión se interpreta como un número, no como una expresión regular. Los valores negativos para id coinciden desde el número de id más alto hacia abajo, en particular, -1 es la ventana creada más recientemente.

El campo num se refiere a la posición de la ventana en la pestaña actual, comenzando desde cero y contando en sentido horario (este es el mismo orden en que las ventanas son reportadas por el comando kitten @ ls).

El id de ventana de la ventana actual está disponible como la variable de entorno KITTY_WINDOW_ID.

El campo recent se refiere a las ventanas activas recientemente en la pestaña activa actual, siendo cero la ventana activa actual, uno la ventana previamente activa y así sucesivamente.

El campo neighbor se refiere a un vecino de la ventana activa en la dirección especificada, que puede ser: left, right, top o bottom.

El campo session coincide con ventanas que fueron creadas en la sesión especificada. Use la expresión ^$ para coincidir con ventanas que no fueron creadas en una sesión y . para coincidir con la sesión activa actual y ~ para coincidir con la sesión activa actual o la última sesión activa cuando no hay una sesión activa.

Al usar el campo env para coincidir con variables de entorno, puede especificar solo el nombre de la variable de entorno o un nombre y valor, por ejemplo, env:MY_ENV_VAR=2.

Del mismo modo, el campo var coincide con variables de usuario establecidas en la ventana. Puede especificar el nombre o el nombre y valor, como con el campo env.

El campo state coincide con el estado de la ventana. Los estados soportados son: active, focused, needs_attention, parent_active, parent_focused, focused_os_window, self, overlay_parent. Las ventanas activas son las ventanas que están activas en su pestaña padre. Hay una única ventana enfocada y es la ventana a la que se entregan los eventos del teclado. Si no hay ninguna ventana enfocada, se coincide con la última ventana enfocada. El valor focused_os_window coincide con todas las ventanas en la ventana del sistema operativo actualmente enfocada. El valor self coincide con la ventana en la que se ejecuta el comando de control remoto. El valor overlay_parent coincide con la ventana que está debajo de la ventana self, cuando la ventana self es una superposición.

Tenga en cuenta que puede usar el comando kitten @ ls para obtener una lista de ventanas.

--help, -h [=no]
Muestra la ayuda para este comando.

Opciones globales

--to
Una dirección para la instancia de kitty a controlar. Corresponde a la dirección dada a la instancia de kitty a través de la opción --listen-on o la configuración listen_on en kitty.conf. Si no se especifica, se comprueba la variable de entorno KITTY_LISTEN_ON. Si tampoco se encuentra, los mensajes se envían a la terminal de control para este proceso, es decir, solo funcionarán si este proceso se ejecuta dentro de una ventana de kitty.
--password
Una contraseña para usar al contactar con kitty. Esto hará que kitty solicite al usuario permiso para realizar la acción especificada, a menos que la contraseña haya sido aceptada anteriormente o esté preconfigurada en kitty.conf. Para usar una contraseña en blanco, especifique --use-password como siempre.
--password-file [=rc-pass]
Un archivo del que leer la contraseña. Los espacios en blanco finales se ignoran. Las rutas relativas se resuelven desde el directorio de configuración de kitty. Use - para leer desde STDIN. Use fd:num para leer desde el descriptor de archivo num. Se usa si no se proporciona --password. Por defecto, se comprueba el archivo rc-pass en el directorio de configuración de kitty.
--password-env [=KITTY_RC_PASSWORD]
El nombre de una variable de entorno de la que leer la contraseña. Se usa si no se proporciona --password-file. Por defecto, se comprueba la variable de entorno KITTY_RC_PASSWORD.
--use-password [=if-available]
Si no hay contraseña disponible, kitty generalmente enviará el comando de control remoto sin contraseña. Esta opción se puede usar para forzar que siempre use o nunca use la contraseña proporcionada. Si se establece en always y no se proporciona ninguna contraseña, se utiliza la contraseña en blanco.

Opciones: if-available, always, never
