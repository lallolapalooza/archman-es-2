Name


kitten-transfer(1) — Transfer files between machines






Overview


The kitten transfer command is a simple utility for transferring files
    between machines. It is designed to be easy to use and to provide a secure
    way to transfer files over a network.






Basic usage


To transfer a file from the local machine to a remote machine, use
    the following command:


kitten transfer /path/to/local/file user@remote_host:/path/to/remote/file



To transfer a file from a remote machine to the local machine, use
    the following command:


kitten transfer user@remote_host:/path/to/remote/file /path/to/local/file



You can also transfer entire directories by specifying the
    directory name instead of a file name. The directory will be transferred
    recursively.






Avoiding the confirmation prompt


By default, kitten transfer will prompt you for confirmation before
    transferring files. This is to prevent accidental overwrites. If you want to
    bypass this confirmation prompt, you can use the --permissions-bypass
    option.


kitten transfer --permissions-bypass PASSWORD file_to_transfer user@remote_host:destination



The PASSWORD must match the password set for the
    file_transfer_confirmation_bypass option in your kitty.conf
    file.






Delta transfers


If you are transferring large files or directories that may already
    exist on the receiving side, you can use the --transmit-deltas option
    to use the rsync algorithm. This will only transfer the parts of the files
    that have changed, which can save a lot of bandwidth and also automatically
    resume partial transfers.


kitten transfer --transmit-deltas file_to_transfer user@remote_host:destination



Note that this will actually degrade performance on fast links or
    with small files, so use with care.






Source code for transfer


The source code for the kitten transfer utility can be found in the
    kitty terminal emulator's source code repository.






Command line interface





  
--permissions-bypass
    <PERMISSIONS_BYPASS>, -p <PERMISSIONS_BYPASS>

  
La contraseña a usar para omitir el cuadro de diálogo de confirmación de
      transferencia en kitty. Debe coincidir con la contraseña establecida para la
      opción file_transfer_confirmation_bypass
      <#opt-kitty.file_transfer_confirmation_bypass> en
      kitty.conf. Tenga en cuenta que los espacios en blanco al principio
      y al final se eliminan de la contraseña. Se asume que una contraseña que
      comienza con los caracteres ., / o ~ es un nombre de
      archivo del cual leer la contraseña. Un valor de - significa leer
      la contraseña de STDIN. Se asume que una contraseña que es puramente un
      número menor que 256 es el número de un descriptor de archivo del cual
      leer la contraseña real.









  
--confirm-paths
    [=no], -c [=no]

  
Antes de transferir archivos, muestra un mapeo de nombres de archivos locales a
      nombres de archivos remotos y solicita confirmación.









  
--transmit-deltas
    [=no], -x [=no]

  
Si un archivo en el lado receptor ya existe, utiliza el algoritmo rsync para
      actualizarlo y que coincida con el archivo en el lado emisor, lo que
      potencialmente ahorra mucho ancho de banda y también reanuda automáticamente
      transferencias parciales. Tenga en cuenta que esto degradará el rendimiento en
      enlaces rápidos o con archivos pequeños, así que úselo con precaución.
