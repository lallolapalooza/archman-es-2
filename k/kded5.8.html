KDED5(8) Manual del usuario de kded5 KDED5(8)

NOMBRE

kded5 - Demonio de KDE - activa las actualizaciones de la base de datos Sycoca cuando es necesario.

SINOPSIS

kded5 [--check]

DESCRIPCIÓN

kded5 consolida varios servicios pequeños en un solo proceso. Estos son en su mayoría servicios D-Bus proporcionados por módulos KDED, pero también gestiona sycoca (una caché binaria de tipos de servicio, tipos MIME y servicios utilizados por KService) y scripts de actualización de KConfig según sea necesario.

Para sycoca, monitoriza los directorios que contienen archivos .desktop. Cuando se añade/elimina un archivo, espera 5 segundos (en caso de una serie de actualizaciones) y luego lanza kbuildsycoca5 para actualizar sycoca.

Para KConfig, comprueba los archivos de actualización recién instalados, es decir, los archivos *.upd utilizados para actualizar los archivos de configuración de los usuarios cuando los formatos de los archivos de configuración cambian, y ejecuta la utilidad de actualización de KConfig para realizar las actualizaciones.

Estas tareas también se ejecutan cuando se inicia kded5 para garantizar que la configuración del usuario esté actualizada.

Normalmente no necesita ejecutar kded5 directamente; las sesiones de escritorio de Plasma lo ejecutan automáticamente, y se inicia bajo demanda cuando una aplicación intenta utilizar una interfaz D-Bus proporcionada por él o uno de sus módulos.

OPCIONES

--check

Comprueba la base de datos sycoca, actualizándola si es necesario, y sale.

CONFIGURACIÓN

kded5 se puede configurar con el archivo de configuración estilo ini kded5rc. En sistemas UNIX®, este se encuentra en $XDG_CONFIG_HOME/kded5rc; si $XDG_CONFIG_HOME no está establecido, por defecto es ~/.config/kded5rc.

Las entradas del archivo de configuración se leen bajo demanda, por lo que los cambios se pueden realizar mientras kded5 se está ejecutando. Sin embargo, todas las opciones de configuración actuales solo afectan realmente al comportamiento de inicio de kded5.

La sección [General] tiene las siguientes opciones:

CheckSycoca

Si se debe actualizar sycoca al inicio (por defecto: true).

CheckUpdates

Si se deben realizar las actualizaciones pendientes de KConfig al inicio (por defecto: true).

CheckFileStamps

Si se deben comprobar las marcas de tiempo de los archivos al realizar la actualización inicial de sycoca (por defecto: true). Consulte la documentación de kbuildsycoca5 para más detalles.

DelayedCheck

Si se debe retrasar la actualización inicial de sycoca hasta aproximadamente un minuto después de iniciar (por defecto: false).

Cada módulo también tiene una sección [Module-name] en kded5rc, donde name es el nombre del archivo de escritorio del módulo sin la extensión .desktop. Contiene una opción autoload que especifica si el módulo debe cargarse automáticamente al iniciar kded5 (por defecto: false). Tenga en cuenta que esta configuración también se puede cambiar a través de la interfaz D-Bus de kded5.

VER TAMBIÉN

kbuildsycoca5(8), kdeinit5(8)
