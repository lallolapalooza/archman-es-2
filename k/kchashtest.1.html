NOMBRE

kchashtest - interfaz de línea de comandos para probar la base de datos hash de archivos

DESCRIPCIÓN

El comando `kchashtest' es una utilidad para pruebas de facilidad y pruebas de rendimiento de la base de datos hash de archivos. Este comando se utiliza en el siguiente formato. `path' especifica la ruta de un archivo de base de datos. `rnum' especifica el número de iteraciones.


kchashtest order [-th num] [-rnd] [-set|-get|-getw|-rem|-etc] [-tran] [-oat|-onl|-onl|-otl|-onr] [-apow num] [-fpow num] [-ts] [-tl] [-tc] [-bnum num] [-msiz num] [-dfunit num] [-lv] path rnum
Realiza pruebas en orden.
kchashtest queue [-th num] [-it num] [-rnd] [-oat|-onl|-onl|-otl|-onr] [-apow num] [-fpow num] [-ts] [-tl] [-tc] [-bnum num] [-msiz num] [-dfunit num] [-lv] path rnum
Realiza operaciones en cola.
kchashtest wicked [-th num] [-it num] [-oat|-onl|-onl|-otl|-onr] [-apow num] [-fpow num] [-ts] [-tl] [-tc] [-bnum num] [-msiz num] [-dfunit num] [-lv] path rnum
Realiza operaciones mixtas seleccionadas al azar.
kchashtest tran [-th num] [-it num] [-hard] [-oat|-onl|-onl|-otl|-onr] [-apow num] [-fpow num] [-ts] [-tl] [-tc] [-bnum num] [-msiz num] [-dfunit num] [-lv] path rnum
Realiza la prueba de transacción.

Las opciones presentan lo siguiente.

-th num : especifica el número de hilos de trabajo.
-rnd : realiza prueba aleatoria.
-set : realiza solo la operación de establecimiento.
-get : realiza solo la operación de obtención.
-getw : realiza solo la operación de obtención con búfer.
-rem : realiza solo la operación de eliminación.
-etc : realiza operaciones misceláneas.
-tran : realiza transacciones.
-oat : abre la base de datos con la opción de transacción automática.
-oas : abre la base de datos con la opción de sincronización automática.
-onl : abre la base de datos con la opción sin bloqueo.
-otl : abre la base de datos con la opción de bloqueo de intento.
-onr : abre la base de datos con la opción de no reparación automática.
-apow num : especifica la potencia de la alineación del tamaño del registro.
-fpow num : especifica la potencia de la capacidad del grupo de bloques libres.
-ts : ajusta la base de datos con la opción pequeña.
-tl : ajusta la base de datos con la opción lineal.
-tc : ajusta la base de datos con la opción de compresión.
-bnum num : especifica el número de cubetas de la tabla hash.
-msiz num : especifica el tamaño de la región mapeada en memoria.
-dfunit num : especifica el número de pasos de unidad de la desfragmentación automática.
-lv : informa todos los errores.
-it num : especifica el número de repeticiones.
-hard : realiza sincronización física.

Este comando devuelve 0 en caso de éxito y otro valor en caso de fallo.
