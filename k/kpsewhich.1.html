KPSEWHICH(1) Manual de comandos generales KPSEWHICH(1)

NOMBRE

kpsewhich - búsqueda de rutas y expansión independiente para kpathsea

SINOPSIS

kpsewhich [opciones] [nombres de archivo]

DESCRIPCIÓN

Esta página del manual no tiene la intención de ser exhaustiva. La documentación completa de esta versión de TeX se puede encontrar en el archivo info o en el manual Kpathsea: Una biblioteca para la búsqueda de rutas.

kpsewhich se utiliza como una interfaz independiente de la biblioteca kpathsea que puede utilizarse para examinar variables y encontrar archivos. Cuando no se proporciona la opción -format, la ruta de búsqueda utilizada al buscar un archivo se infiere del nombre dado, buscando una extensión conocida. Si no se encuentra ninguna extensión conocida, se utiliza la ruta de búsqueda de los archivos fuente de TeX.

OPCIONES

kpsewhich acepta las siguientes opciones:

-debug num
Establece los indicadores de depuración.
-D num
Utiliza una resolución base de num; la predeterminada, establecida por el instalador, suele ser 600.
-dpi num
Igual que -D.
-engine cadena
Establece $engine en el entorno, que se utiliza en algunas rutas de búsqueda.
-expand-braces cadena
Imprime la expansión de variables y llaves de cadena.
-expand-path cadena
Imprime la expansión completa de la ruta de cadena.
-expand-var cadena
Imprime la expansión de variables de cadena.
-format nombre
Utiliza el tipo de archivo nombre. Consulte el manual info para obtener una lista de nombres válidos, o utilice la opción -help para imprimir la lista.
-help
Imprime el mensaje de ayuda y sale.
-interactive
Pregunta por nombres de archivo adicionales a buscar.
-mktex fmt
Habilita la generación de mktexfmt. (fmt=pk/mf/tex/tfm)
-mode cadena
Establece el nombre del dispositivo para $MAKETEX_MODE en cadena; no hay valor predeterminado.
-must-exist
Busca en el disco y en ls-R si es necesario.
-no-mktex fmt
Inhabilita la generación de mktexfmt. (fmt=pk/mf/tex/tfm)
-path cadena
Busca en la ruta cadena.
-progname cadena
Establece el nombre del programa en cadena.
-show-path nombre
Muestra la ruta de búsqueda para el tipo de archivo nombre. Consulte el manual info para obtener una lista de nombres válidos, o utilice la opción -help para imprimir la lista.
-var-value variable
Imprime la expansión de variable.
-version
Imprime la información de la versión y sale.

VER TAMBIÉN

mktexlsr(1), mktexmf(1), mktexpk(1), mktextfm(1).
