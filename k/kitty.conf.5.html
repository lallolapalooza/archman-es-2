Nombre

kitty.conf - Archivo de configuración para kitty

Descripción_general

kitty es altamente personalizable, desde atajos de teclado hasta la velocidad de fotogramas de renderizado. Consulte a continuación una descripción general de todas las posibilidades de personalización.

Puede abrir el archivo de configuración dentro de kitty presionando Ctrl+Shift+F2 (⌘ + , en macOS). Se creará un kitty.conf con configuraciones predeterminadas comentadas y descripciones si el archivo no existe. Puede recargar el archivo de configuración dentro de kitty presionando Ctrl+Shift+F5 (⌃ + ⌘ + , en macOS) o enviando a kitty la señal SIGUSR1 con kill -SIGUSR1 $KITTY_PID. También puede mostrar la configuración actual presionando Ctrl+Shift+F6 (⌥ + ⌘ + , en macOS).

kitty busca un archivo de configuración en los directorios de configuración del sistema operativo (generalmente ~/.config/kitty/kitty.conf), pero puede pasar una ruta específica a través de la opción kitty --config <#cmdoption-kitty-config> o usar la variable de entorno KITTY_CONFIG_DIRECTORY <#envvar-KITTY_CONFIG_DIRECTORY>. Consulte kitty --config <#cmdoption-kitty-config> para obtener todos los detalles.

Se pueden agregar comentarios al archivo de configuración como líneas que comienzan con el carácter #. Esto solo funciona si el carácter # es el primer carácter de la línea.

Las líneas se pueden dividir comenzando la siguiente línea con el carácter \. Se eliminan todos los espacios en blanco iniciales y el carácter \.

Puede incluir archivos de configuración secundarios a través de la directiva include. Si utiliza una ruta relativa para include, se resuelve con respecto a la ubicación del archivo de configuración actual. Tenga en cuenta que las variables de entorno se expanden, por lo que ${USER}.conf se convierte en nombre.conf si USER=nombre. Una variable de entorno especial KITTY_OS <#envvar-KITTY_OS> está disponible para detectar el sistema operativo. Es linux, macos o bsd. Además, puede usar globinclude para incluir archivos que coincidan con un patrón de glob de shell y envinclude para incluir la configuración de las variables de entorno. Finalmente, puede generar configuración dinámicamente ejecutando un programa usando geninclude. Por ejemplo:

# Incluir other.conf
include other.conf
# Incluir archivos *.conf de todos los subdirectorios de kitty.d dentro del directorio de configuración de kitty
globinclude kitty.d/**/*.conf
# Incluir el *contenido* de todas las variables de entorno que comiencen con KITTY_CONF_
envinclude KITTY_CONF_*
# Ejecutar el script dynamic.py ubicado en el mismo directorio que este archivo de configuración
# e incluir su :file:`STDOUT`. Tenga en cuenta que los scripts de Python son los más rápidos
# ya que utilizan el intérprete de Python incrustado, pero se admite cualquier script
# o programa ejecutable, en cualquier idioma. Recuerde marcar el archivo de script
# como ejecutable.
geninclude dynamic.py

Nota:

El resaltado de sintaxis para kitty.conf en vim está disponible a través de vim-kitty https://github.com/fladson/vim-kitty.

Fuentes

kitty tiene una gestión de fuentes muy potente. Puede configurar caras de fuente individuales e incluso especificar fuentes especiales para caracteres particulares.

font_family, bold_font, italic_font, bold_italic_font
font_family      monospace
bold_font        auto
italic_font      auto
bold_italic_font auto

Puede especificar diferentes fuentes para las variantes en negrita/cursiva/negrita cursiva. La forma más fácil de seleccionar fuentes es ejecutar el comando kitten choose-fonts, que presentará una interfaz agradable para que seleccione las fuentes que desea con vistas previas y soporte para la selección de fuentes variables y características de fuentes. Si desea aprender a seleccionar fuentes manualmente, lea la sintaxis de especificación de fuentes <#font-spec-syntax>.

font_size
font_size 11.0

Tamaño de fuente (en puntos).

force_ltr
force_ltr no

kitty no admite BIDI (texto bidireccional), sin embargo, para secuencias de comandos RTL, las palabras se muestran automáticamente en RTL. Es decir, en una secuencia de comandos RTL, las palabras "HELLO WORLD" se muestran en kitty como "WORLD HELLO", y si intenta seleccionar una subcadena de una cadena con forma RTL, obtendrá el carácter que estaría allí si la cadena fuera LTR. Por ejemplo, asumiendo la palabra hebrea ירושלים, seleccionar el carácter que en la pantalla parece ser ם en realidad escribe en el portapapeles el carácter י. El comportamiento predeterminado de kitty es útil junto con un filtro para invertir el orden de las palabras, sin embargo, si desea manipular glifos RTL, puede ser muy desafiante trabajar con ellos, por lo que se proporciona esta opción para desactivarla. Además, esta opción se puede utilizar con el programa de línea de comandos GNU FriBidi https://github.com/fribidi/fribidi#executable para obtener soporte BIDI, porque obligará a kitty a tratar siempre el texto como LTR, que es lo que FriBidi espera para las terminales.

symbol_map

No tiene valores predeterminados. A continuación se muestran ejemplos de valores:

symbol_map U+E0A0-U+E0A3,U+E0C0-U+E0C7 PowerlineSymbols

Mapea los puntos de código Unicode especificados a una fuente particular. Útil si necesita una representación especial para algunos símbolos, como para Powerline. Evita la necesidad de fuentes parcheadas. Cada punto de código Unicode se especifica en el formato U+<código hexadecimal del punto>. Puede especificar varios puntos de código, separados por comas y rangos separados por guiones. Esta opción se puede especificar varias veces. La sintaxis es:

symbol_map puntos_de_código Nombre de la familia de fuentes
narrow_symbols

No tiene valores predeterminados. A continuación se muestran ejemplos de valores:

narrow_symbols U+E0A0-U+E0A3,U+E0C0-U+E0C7 1

Por lo general, para los caracteres Unicode de Uso Privado y algunos caracteres de símbolos/dingbat, si el carácter va seguido de uno o más espacios, kitty utilizará esas celdas adicionales para renderizar el carácter más grande, si el carácter en la fuente tiene una relación de aspecto amplia. Usando esta opción puede forzar a kitty a restringir los puntos de código especificados para que se rendericen en el número especificado de celdas (con un valor predeterminado de una celda). Esta opción se puede especificar varias veces. La sintaxis es:

narrow_symbols puntos_de_código [opcionalmente el número de celdas]
disable_ligatures
disable_ligatures never

Elija cómo desea manejar las ligaduras de varios caracteres. El valor predeterminado es renderizarlas siempre. Puede indicarle a kitty que no las renderice cuando el cursor esté sobre ellas usando cursor para facilitar la edición, o hacer que kitty nunca las renderice usando always, si no le gustan. La estrategia de ligaduras se puede establecer por ventana utilizando la instalación de control remoto de kitty o definiendo atajos para ella en kitty.conf, por ejemplo:

map alt+1 disable_ligatures_in active always
map alt+2 disable_ligatures_in all never
map alt+3 disable_ligatures_in tab cursor

Tenga en cuenta que esto se refiere a ligaduras de programación, implementadas típicamente usando la característica OpenType calt. Para deshabilitar ligaduras generales, use la opción font_features.

font_features

No tiene valores predeterminados. A continuación se muestran ejemplos de valores:

font_features none

Elija exactamente qué características de OpenType habilitar o deshabilitar. Tenga en cuenta que para las fuentes principales, las características se pueden especificar al seleccionar la fuente utilizando el gatito choose-fonts. Esta configuración es útil para fuentes de reserva.

Algunas fuentes pueden tener características valiosas en una terminal. Por ejemplo, Fira Code incluye una característica discrecional, zero, que en esa fuente cambia la apariencia del cero (0), para que sea más fácil distinguirlo de Ø. Fira Code también incluye otras características discrecionales conocidas como Conjuntos Estilísticos que tienen las etiquetas ss01 a ss20.

Para conocer la sintaxis exacta a usar para las características individuales, consulte la documentación de HarfBuzz https://harfbuzz.github.io/harfbuzz-hb-common.html#hb-feature-from-string.

Tenga en cuenta que este código está indexado por nombre PostScript, y no por familia de fuentes. Esto le permite definir configuraciones de características muy precisas; por ejemplo, puede deshabilitar una característica en la fuente cursiva pero no en la fuente normal.

En Linux, las características de fuente se leen primero de la base de datos de FontConfig y luego se aplica esta opción, por lo que se pueden configurar en un solo lugar central.

Para obtener el nombre PostScript de una fuente, utilice el comando fc-scan file.ttf en Linux o la herramienta Font Book en macOS https://apple.stackexchange.com/questions/79875/how-can-i-get-the-postscript-name-of-a-ttf-font-installed-in-os-x.

Habilita el cero alternativo y los numerales de estilo antiguo:

font_features FiraCode-Retina +zero +onum

Habilita solo el cero alternativo en la fuente en negrita:

font_features FiraCode-Bold +zero

Deshabilita las ligaduras normales, pero mantiene la característica calt que (en esta fuente) rompe la monotonía:

font_features TT2020StyleB-Regular -liga +calt

En conjunción con force_ltr, es posible que desee deshabilitar completamente el modelado árabe y solo mirar sus formas aisladas si aparecen en un documento. Puede hacerlo con, por ejemplo:

font_features UnifontMedium +isol -medi -fina -init
modify_font

Modifica características de la fuente como la posición o el grosor del subrayado y tachado. Las modificaciones pueden tener el sufijo px para píxeles o % para porcentaje del valor original. Sin sufijo significa usar pts. Por ejemplo:

modify_font underline_position -2
modify_font underline_thickness 150%
modify_font strikethrough_position 2px

Además, puede modificar el tamaño de la celda en la que se renderiza cada glifo de fuente y la línea base en la que se coloca el glifo en la celda. Por ejemplo:

modify_font cell_width 80%
modify_font cell_height -2px
modify_font baseline 3

Tenga en cuenta que modificar la línea base ajustará automáticamente las posiciones del subrayado y tachado en la misma cantidad. Aumentar la línea base eleva los glifos dentro de la celda y disminuirla los baja. Disminuir el tamaño de la celda puede causar artefactos de renderizado, así que úselo con cuidado.

box_drawing_scale
box_drawing_scale 0.001, 1, 1.5, 2

Los tamaños de las líneas utilizadas para los caracteres Unicode de dibujo de cajas. Estos valores están en pts. Se escalarán según la DPI del monitor para obtener un valor en píxeles. Debe haber cuatro valores correspondientes a líneas finas, normales, gruesas y muy gruesas.

undercurl_style
undercurl_style thin-sparse

El estilo con el que se renderizan los undercurls. Esta opción toma la forma (thin|thick)-(sparse|dense). Thin y thick controlan el grosor del undercurl. Sparse y dense controlan la frecuencia con la que oscila el rizo. Con sparse, el rizo alcanzará su punto máximo una vez por carácter, con dense dos veces. Cambiar esta opción dinámicamente recargando la configuración o mediante control remoto no está definido.

underline_exclusion
underline_exclusion 1

Por defecto, kitty renderiza huecos en los subrayados cuando se superponen con descendentes (las partes de las letras debajo de la línea base, como en y, q, p, etc.). Esta opción controla el grosor de los huecos. Puede ser un número sin unidades, en cuyo caso es una fracción del grosor del subrayado especificado en la fuente, o puede tener un sufijo de px para píxeles o pt para puntos. Establézcalo en cero para deshabilitar los huecos. Cambiar esta opción dinámicamente recargando la configuración o mediante control remoto no está definido.

text_composition_strategy
text_composition_strategy platform

Controla cómo kitty compone los glifos de texto sobre el color de fondo. El valor predeterminado de platform intenta renderizar texto lo más cercano posible a lo "nativo" de la plataforma en la que se está ejecutando kitty.

Un valor de legacy utiliza la estrategia antigua (anterior a kitty 0.28) para componer los glifos. Esto hará que el texto oscuro sobre fondos claros se vea más grueso y el texto claro sobre fondos oscuros más fino. También puede hacer que algunos textos parezcan tener trazos desiguales.

Puede ajustar la curva de contraste real utilizada para la composición de glifos especificando hasta dos números separados por espacios para esta configuración.

El primer número es el ajuste de gamma, que controla el grosor del texto oscuro sobre fondos claros. Aumentar el valor hará que el texto parezca más grueso. El valor predeterminado es 1.0 en Linux y 1.7 en macOS. Los valores válidos son 0.01 o superiores. El resultado se escala en función de la diferencia de luminancia entre el fondo y el primer plano. El texto oscuro sobre fondos claros recibe el impacto total de la curva, mientras que el texto claro sobre fondos oscuros se ve afectado muy poco.

El segundo número es un contraste multiplicativo adicional. Es un porcentaje que oscila entre 0 y 100. El valor predeterminado es 0 en Linux y 30 en macOS.

Si desea lograr un grosor similar en temas claros y oscuros, una buena manera de experimentar es comenzar estableciendo el valor en 1.0 0 y usar un tema oscuro. Luego, ajuste el segundo parámetro hasta que se vea bien. Luego, cambie a un tema claro y ajuste el primer parámetro hasta que el grosor percibido coincida con el tema oscuro.

text_fg_override_threshold
text_fg_override_threshold 0

Una configuración para prevenir un bajo contraste entre los colores de primer plano y fondo. Útil cuando se trabaja con aplicaciones que utilizan colores que no contrastan bien con su esquema de color preferido. El valor predeterminado es 0, lo que significa que no se realiza ninguna anulación de color. Hay dos modos de operación:

Un valor con el sufijo ratio representa la relación de contraste mínima aceptada entre el color de primer plano y el de fondo. Los valores posibles oscilan entre 0.0 ratio y 21.0 ratio. Por ejemplo, para cumplir con el nivel AA de WCAG https://en.wikipedia.org/wiki/Web_Content_Accessibility_Guidelines, se puede proporcionar un valor de 4.5 ratio. El algoritmo se implementa utilizando HSLuv https://www.hsluv.org/, lo que le permite cambiar la luminosidad percibida de un color tanto como sea necesario sin cambiar realmente su matiz y saturación.

Un valor con el sufijo % representa la diferencia mínima aceptada en luminancia entre el color de primer plano y el de fondo, por debajo de la cual kitty anulará el color de primer plano. Es un porcentaje que oscila entre 0 % y 100 %. Si la diferencia de luminancia del primer plano y el fondo está por debajo de este umbral, el color de primer plano se establecerá en blanco si el fondo es oscuro o negro si el fondo es claro.

ADVERTENCIA: Algunos programas utilizan caracteres (como caracteres de bloque) para la visualización gráfica y pueden esperar poder establecer el primer plano y el fondo al mismo color (o colores similares). Si ve rayas, puntos, líneas inesperados, color incorrecto, sin color donde esperaba color, o cualquier tipo de problema de visualización gráfica, intente configurar text_fg_override_threshold en 0 para ver si esta es la causa del problema o considere usar el modo ratio de operación descrito anteriormente en lugar del modo % de operación.

Personalización del cursor de texto

cursor
cursor #cccccc

Color del cursor de texto predeterminado. Si se establece en el valor especial none, el cursor se renderizará con un efecto de "video inverso". Su color será el color del texto en la celda sobre la que se encuentra y el texto se renderizará con el color de fondo de la celda. Tenga en cuenta que si el programa que se ejecuta en la terminal establece un color de cursor, este tiene prioridad. Además, los colores del cursor se modifican si los colores de fondo y primer plano de la celda tienen un contraste muy bajo. Tenga en cuenta que algunos temas establecen este valor, por lo que si desea anularlo, coloque su valor después de las líneas donde se incluye el archivo del tema.

cursor_text_color
cursor_text_color #111111

El color del texto debajo del cursor. Si desea que se renderice con el color de fondo de la celda debajo en su lugar, use la clave especial

word: background. Nota que si cursor se establece en none, esta opción se ignora. Ten en cuenta que algunos temas establecen este valor, así que si deseas anularlo, coloca tu valor después de las líneas donde se incluye el archivo del tema.

cursor_shape
cursor_shape block

La forma del cursor puede ser block, beam o underline. Ten en cuenta que al recargar la configuración, esto solo cambiará si la forma del cursor no ha sido establecida por el programa que se ejecuta en la terminal. Esto establece la forma predeterminada del cursor; las aplicaciones que se ejecutan en la terminal pueden anularla. En particular, la integración de shell <#shell-integration> en kitty establece la forma del cursor a beam en los prompts del shell. Puedes evitar esto estableciendo shell_integration a no-cursor.

cursor_shape_unfocused
cursor_shape_unfocused hollow

Define la forma del cursor de texto cuando la ventana del sistema operativo no tiene el foco. La forma del cursor sin foco puede ser block, beam, underline, hollow y unchanged (dejar la forma del cursor como está).

cursor_beam_thickness
cursor_beam_thickness 1.5

El grosor del cursor de haz (en puntos).

cursor_underline_thickness
cursor_underline_thickness 2.0

El grosor del cursor de subrayado (en puntos).

cursor_blink_interval
cursor_blink_interval -1

El intervalo para parpadear el cursor (en segundos). Establecer a cero para deshabilitar el parpadeo. Los valores negativos significan usar el valor predeterminado del sistema. Ten en cuenta que el intervalo mínimo se limitará a repaint_delay. También puedes animar el parpadeo del cursor especificando una función de suavizado <#term-easing-function>. Por ejemplo, establecer esta opción a 0.5 ease-in-out hará que el parpadeo del cursor se anime durante un segundo, en la primera mitad del segundo pasará de opaco a transparente y luego de nuevo durante la siguiente mitad. Puedes especificar diferentes funciones de suavizado para las dos mitades, por ejemplo: -1 linear ease-out. kitty admite todas las funciones de suavizado CSS en https://developer.mozilla.org/en-US/docs/Web/CSS/easing-function. Ten en cuenta que activar las animaciones consume energía adicional, ya que implica que la pantalla se redibuja varias veces por intervalo de parpadeo. Ver también, cursor_stop_blinking_after. Esta configuración también controla el texto parpadeante, que parpadea en un ritmo exacto con el cursor.

cursor_stop_blinking_after
cursor_stop_blinking_after 15.0

Detiene el parpadeo del cursor después del número especificado de segundos de inactividad del teclado. Establecer a cero para nunca dejar de parpadear. Esta configuración también controla el texto parpadeante, que parpadea en un ritmo exacto con el cursor.

cursor_trail
cursor_trail 0

Establece esto a un valor mayor que cero para habilitar una animación de "rastro de cursor". Esta es una animación que muestra un "rastro" siguiendo el movimiento del cursor de texto. Facilita el seguimiento de saltos grandes del cursor y proporciona un efecto visual genial del cursor acelerando por la pantalla. El valor real de esta opción controla cuándo se activa la animación. Es un número de milisegundos. La animación del rastro solo sigue a los cursores que han permanecido en su posición durante más tiempo que el número especificado de milisegundos. Esto evita que aparezcan rastros para cursores que cambian rápidamente sus posiciones durante las actualizaciones de UI en aplicaciones complejas. Ver cursor_trail_decay para controlar la velocidad de la animación y cursor_trail_start_threshold para controlar cuándo se inicia un rastro de cursor.

cursor_trail_decay
cursor_trail_decay 0.1 0.4

Controla los tiempos de decaimiento para el efecto de rastro de cursor cuando cursor_trail está habilitado. Esta opción acepta dos valores flotantes positivos que especifican los tiempos de decaimiento más rápido (mínimo) y más lento (máximo) en segundos. El primer valor corresponde al tiempo de decaimiento más rápido y el segundo valor corresponde al tiempo de decaimiento más lento. El segundo valor debe ser igual o mayor que el primero. Valores más pequeños resultan en un decaimiento más rápido del rastro del cursor. Ajusta estos valores para controlar la rapidez con la que desaparece el rastro del cursor.

cursor_trail_start_threshold
cursor_trail_start_threshold 2

Establece el umbral de distancia para iniciar el rastro del cursor. Esta opción acepta un valor entero positivo que representa el número mínimo de celdas que el cursor debe moverse antes de que se inicie el rastro. Cuando el cursor se mueve menos que este umbral, se omite el rastro, reduciendo la animación innecesaria del rastro del cursor.

cursor_trail_color
cursor_trail_color none

Establece el color del rastro del cursor cuando cursor_trail está habilitado. Si se establece en 'none' (el predeterminado), el rastro del cursor usará el color de fondo del cursor. De lo contrario, especifica un valor de color (por ejemplo, #ff0000 para rojo, o un color con nombre como 'red'). Esto te permite personalizar la apariencia del rastro del cursor independientemente del color del cursor.

Scrollback

scrollback_lines
scrollback_lines 2000

Número de líneas de historial a mantener en memoria para hacer scroll hacia atrás. La memoria se asigna bajo demanda. Los números negativos significan scrollback (efectivamente) infinito. Ten en cuenta que no se recomienda usar un scrollback muy grande, ya que puede ralentizar el rendimiento de la terminal y también usar grandes cantidades de RAM. En su lugar, considera usar scrollback_pager_history_size. Ten en cuenta que al recargar la configuración, si se cambia, solo afectará a las ventanas recién creadas, no a las existentes.

scrollbar
scrollbar scrolled

Controla cuándo se muestra la barra de desplazamiento.

scrolled
significa cuando se ha iniciado el desplazamiento hacia atrás.
hovered
significa cuando el mouse está sobre el borde derecho de la ventana.
scrolled-and-hovered
significa cuando el mouse está sobre la región de la barra de desplazamiento y se ha iniciado el desplazamiento hacia atrás.
always
significa siempre que haya scrollback
never
significa deshabilitar la barra de desplazamiento.
scrollbar_interactive
scrollbar_interactive yes

Si está deshabilitado, la barra de desplazamiento no será controlable con el mouse y todos los eventos del mouse pasarán a través de la barra de desplazamiento.

scrollbar_jump_on_click
scrollbar_jump_on_click yes

Cuando está habilitado, hacer clic en la pista de la barra de desplazamiento hará que la posición de desplazamiento salte a la ubicación haga clic, de lo contrario, la posición de desplazamiento solo se moverá hacia la posición por una pantalla completa, que es como se comportan las barras de desplazamiento tradicionales.

scrollbar_width
scrollbar_width 0.5

El ancho de la barra de desplazamiento en unidades del ancho de celda.

scrollbar_hover_width
scrollbar_hover_width 1

El ancho de la barra de desplazamiento cuando el mouse está sobre ella, en unidades de ancho de celda.

scrollbar_handle_opacity
scrollbar_handle_opacity 0.5

La opacidad del manejador de la barra de desplazamiento, siendo 0 totalmente transparente y 1 totalmente opaco.

scrollbar_radius
scrollbar_radius 0.3

El radio (curvatura) del manejador de la barra de desplazamiento en unidades de ancho de celda. Debe ser menor que scrollbar_width.

scrollbar_gap
scrollbar_gap 0.1

El espacio entre la barra de desplazamiento y el borde de la ventana en unidades de ancho de celda.

scrollbar_min_handle_height
scrollbar_min_handle_height 1

La altura mínima del manejador de la barra de desplazamiento en unidades de altura de celda. Evita que el manejador sea demasiado pequeño cuando hay mucho scrollback.

scrollbar_hitbox_expansion
scrollbar_hitbox_expansion 0.25

El área adicional alrededor del manejador para permitir agarrar más fácilmente la barra de desplazamiento en unidades de ancho de celda.

scrollbar_track_opacity
scrollbar_track_opacity 0

La opacidad del fondo de la barra de desplazamiento, siendo 0 totalmente transparente y 1 totalmente opaco.

scrollbar_track_hover_opacity
scrollbar_track_hover_opacity 0.1

La opacidad del fondo de la barra de desplazamiento cuando el ratón está sobre ella, siendo 0 totalmente transparente y 1 totalmente opaco.

scrollbar_handle_color
scrollbar_handle_color foreground

El color del manejador de la barra de desplazamiento. Un valor de foreground significa usar el color de texto frontal actual, un valor de selection_background significa usar el color de fondo de selección actual. También puedes usar un color arbitrario, como #12af59 o red.

scrollbar_track_color
scrollbar_track_color foreground

El color del fondo de la barra de desplazamiento. Un valor de foreground significa usar el color de texto frontal actual, un valor de selection_background significa usar el color de fondo de selección actual. También puedes usar un color arbitrario, como #12af59 o red.

scrollback_pager

  • <hide-wait> <unhide-wait> <unhide-threshold> <scroll-unhide>

Para cambiar el comportamiento de reaparición, se pueden establecer los parámetros opcionales <unhide-wait>, <unhide-threshold> y <scroll-unhide>.

<unhide-wait>
Espera el número especificado de segundos después de los eventos del ratón antes de que el cursor del ratón vuelva a ser visible. Establecer a cero para que el cursor del ratón vuelva a ser visible inmediatamente con la actividad del ratón. Esto es útil para evitar que el cursor del ratón reaparezca con deslizamientos accidentales en el trackpad.
<unhide-threshold>
Establece el umbral de actividad del ratón requerido para que el cursor del ratón vuelva a ser visible, cuando la opción <unhide-wait> no es cero. Cuando <unhide-wait> es cero, esto no tiene efecto.

Por ejemplo, si <unhide-threshold> es 40 y <unhide-wait> es 2.5, cuando kitty detecta un evento del ratón, registra el número de eventos del ratón en los próximos 2.5 segundos y verifica si excede 40 * 2.5 = 100. Si es así, el cursor del ratón vuelve a ser visible, de lo contrario no sucede nada.

<scroll-unhide>
Controla qué eventos del ratón pueden hacer que el cursor del ratón vuelva a ser visible. Si está habilitado, tanto los eventos de desplazamiento como los de movimiento pueden hacer que el cursor vuelva a ser visible. Si está deshabilitado, solo los movimientos del ratón pueden hacer que el cursor vuelva a ser visible.

Acciones del

ratón

Los botones del ratón se pueden asignar para realizar acciones arbitrarias. La sintaxis

es: 
mouse_map b
utton-name
event-type m
odes action

Donde button-name es uno de left, middle, right, b1 ... b8 con modificadores de teclado añadidos. Por ejemplo: ctrl+shift+left se refiere a mantener presionadas las teclas Ctrl+Shift mientras se hace clic con el botón izquierdo del ratón. El valor b1 ... b8 puede used para referirse a hasta ocho botones de un ratón.

event-type es uno de press, release, doublepress, triplepress, click, doubleclick. modes indica si la acción se realiza cuando el programa que se ejecuta en la terminal tiene el ratón capturado, o no. Los valores son grabbed o ungrabbed o una combinación de ellos separada por comas. grabbed se refiere a cuando el programa que se ejecuta en la terminal ha solicitado eventos del ratón. Tenga en cuenta que los eventos click y double click tienen un retraso de click_interval para desambiguar de los eventos double y triple press.

Puede ejecutar kitty con la opción de línea de comandos kitty --debug-input <#cmdoption-kitty-debug-input> para ver los eventos del ratón. Consulte las acciones integradas a continuación para tener una idea de lo que es posible.

Si desea desmapear un botón, mapeelo a nada. Por ejemplo, para deshabilitar la apertura de URL con un clic simple:

Vea todas las acciones mapeables, incluidas las acciones del ratón, aquí <>.

Especifique reglas para filtrar notificaciones enviadas por aplicaciones que se ejecutan en kitty. Se puede especificar varias veces para crear múltiples reglas de filtro. term
term xterm-kitty

El valor de la variable de entorno TERM <#envvar-TERM> a establecer. Cambiar esto puede romper muchos programas de terminal, solo cámbielo si sabe lo que está haciendo, no porque leyó algún consejo en "Stack Overflow" para cambiarlo. La variable TERM <#envvar-TERM> es utilizada por varios programas para obtener información sobre las capacidades y el comportamiento de la terminal. Si la cambia, dependiendo de los programas que ejecute y de cuán diferente sea la terminal a la que la está cambiando, varias cosas desde las pulsaciones de teclas, hasta los colores, hasta varias características avanzadas pueden no funcionar. Cambiar esta opción al recargar la configuración solo afectará a las ventanas recién creadas.

terminfo_type
terminfo_type path

El valor de la variable de entorno TERMINFO <#envvar-TERMINFO> a establecer. Esta variable es utilizada por programas que se ejecutan en la terminal para buscar bases de datos terminfo. El valor predeterminado de path hace que kitty lo establezca en una ubicación del sistema de archivos que contiene la base de datos terminfo de kitty. Un valor de direct significa insertar toda la base de datos directamente en la variable de entorno. Esto puede ser útil al conectarse a contenedores, por ejemplo. Pero, tenga en cuenta que no todo el software soporta esto. Un valor de none significa no tocar la variable.

forward_stdio
forward_stdio no

Reenviar STDOUT y STDERR del proceso kitty a procesos hijos. Esto es útil para depuración, ya que permite que los procesos hijos impriman directamente en el STDOUT de kitty. Por ejemplo, `echo hello world >&$KITTY_STDIO_FORWARDED` en un shell imprimirá en el STDOUT del proceso kitty padre. Establece la variable de entorno KITTY_STDIO_FORWARDED=fdnum para que los procesos hijos sepan sobre el reenvío. Tenga en cuenta que en macOS esto evita que el shell se ejecute a través de la utilidad de inicio de sesión, por lo que getlogin() no funcionará en los programas ejecutados en esta sesión.

Atajos de teclado

Las teclas se identifican simplemente por sus caracteres Unicode en minúsculas. Por ejemplo: a para la tecla A, [ para la tecla de corchete izquierdo, etc. Para las teclas funcionales, como Enter o Escape, los nombres se encuentran en Definiciones de teclas funcionales <#functional>. Algunas funciones útiles que se pueden definir en los archivos rc del shell para realizar varios tipos de borrado de la ventana actual:

clear-only-screen() {
    printf "\e[H\e[2J"
}
clear-screen-and-scrollback() {
    printf "\e[H\e[3J"
}
clear-screen-saving-contents-in-scrollback() {
    printf "\e[H\e[22J"
}

ctrl_l() {
    builtin print -rn -- $'\r\e[0J\e[H\e[22J' >"$TTY"

    builtin zle -R
}

Enviar texto arbitrario al presionar teclas

Puedes indicarle a kitty que envíe texto arbitrario (codificado en UTF-8) al programa cliente cuando se presionan combinaciones de teclas especificadas. Por ejemplo:

map ctrl+alt+a send_text all Special text

Esto enviará "Special text" cuando presiones la combinación de teclas Ctrl+Alt+A. El texto a enviar decodifica escapes de ANSI C https://www.gnu.org/software/bash/manual/html_node/ANSI_002dC-Quoting.html por lo que puedes usar escapes como \e para enviar códigos de control o \u21fb para enviar caracteres Unicode (o puedes ingresar los caracteres Unicode directamente como texto UTF-8). Puedes usar kitten show-key para obtener los códigos de escape de las teclas que deseas emular.

El primer argumento de send_text son los modos de teclado en los que se activará el atajo. Los valores posibles son normal, application, kitty o una combinación separada por comas de ellos. Los modos normal y application se refieren al modo de teclas de cursor DECCKM para terminales, y kitty se refiere al protocolo de teclado extendido de kitty. El valor especial all significa todos ellos.

scroll_to_prompt

Desplázate al prompt del comando de shell anterior/siguiente

Permite saltar fácilmente de un comando al siguiente. Requiere integración de shell funcional <#shell-integration>. Toma dos números opcionales como argumentos:

El primero es el número de prompts a saltar; los valores negativos saltan hacia arriba y los valores positivos saltan hacia abajo. Un valor de cero saltará al último prompt visitado por esta acción. Por defecto es -1

El segundo es el número de líneas a mostrar por encima del prompt al que se saltó. Esto es algo parecido a la opción --jump-target de less o la configuración scrolloff de vim. Por defecto es 0.

Por ejemplo:

map ctrl+p scroll_to_prompt -1 3  # salta al anterior, mostrando 3 líneas previas
map ctrl+n scroll_to_prompt 1     # salta al siguiente
map ctrl+o scroll_to_prompt 0     # salta al último visitado

Atajos por defecto que usan esta acción: ctrl+shift+x <#shortcut-kitty.Scroll-to-next-shell-prompt>, ctrl+shift+z <#shortcut-kitty.Scroll-to-previous-shell-prompt>
