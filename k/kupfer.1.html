KUPFER(1) Manual de comandos generales KUPFER(1)

NOMBRE

kupfer - Herramienta de acceso y comandos conveniente para aplicaciones y documentos

SINOPSIS

kupfer [ OPCIONES | ARCHIVO ... ]
kupfer-exec ARCHIVO ...

DESCRIPCIÓN

Kupfer es una interfaz para acceder rápida y convenientemente a aplicaciones y sus documentos.

El uso más típico es encontrar una aplicación específica y lanzarla. Hemos intentado que Kupfer sea fácil de extender con plugins para que este paradigma de acceso rápido pueda extenderse a muchos más objetos que solo aplicaciones.

kupfer-exec es un script auxiliar que puede ejecutar comandos guardados en un archivo, pero solo conectándose a una instancia de Kupfer ya en ejecución.

LANZAMIENTO

Ejecutar kupfer desde la línea de comandos (sin opciones) intentará mostrar el programa si ya está en ejecución.

Kupfer puede ser invocado con una lista de archivos

kupfer ARCHIVO ...

Las rutas de los archivos se enviarán y seleccionarán en una instancia del programa ya en ejecución.

También puede enviar texto a kupfer para pasarlo a una instancia actualmente en ejecución.

OPCIONES

--no-splash
Lanzar sin mostrar la interfaz principal
--debug
Habilitar una salida más detallada que puede ayudar a comprender el funcionamiento del programa.
--list-plugins
Listar todos los plugins instalados por su identificador, versión y descripción.

Las siguientes son opciones para uso interno

--exec-helper=HELPER
Ejecutar el programa auxiliar del plugin, que debe ser el nombre de un módulo dentro de kupfer.

Las siguientes son opciones genéricas

--help
Mostrar información de uso
--version
Mostrar información de versión

CONFIGURACIÓN

Los plugins personalizados se añaden a kupfer instalándolos en el directorio ~/.local/share/kupfer/plugins, o en cualquier directorio kupfer/plugins dentro de cualquiera de los $XDG_DATA_DIRS.

VARIABLES DE ENTORNO

Si se establece KUPFER_NO_CUSTOM_PLUGINS, solo se permitirá cargar plugins integrados (instalados en el paquete de Python del programa).

Si se establece KUPFER_NO_CACHE, no se cargará ni se escribirá en ningún archivo de caché de origen.

Si se establece KUPFER_NO_KEYBINDER, no se utilizará Keybinder aunque esté instalado.

SOLUCIÓN DE PROBLEMAS / ERRORES CONOCIDOS

Wayland

Establecer la variable de entorno GDK_BACKEND a x11 resuelve el problema de la posición incorrecta de la ventana.

Algunos plugins (por ejemplo, Ventanas) no funcionan debido a la falta de soporte de la biblioteca Wnck.
