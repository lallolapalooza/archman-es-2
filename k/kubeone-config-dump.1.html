NOMBRE

kubeone-config-dump - Fusiona el manifiesto KubeOneCluster con el estado de Terraform y lo vuelca a la salida estándar

SINOPSIS

kubeone config dump [flags]

DESCRIPCIÓN

Fusiona el manifiesto KubeOneCluster con el estado de Terraform y lo vuelca a la salida estándar

OPCIONES

-h, --help[=false] ayuda para dump

OPCIONES HEREDADAS DE COMANDOS PADRE

-c, --credentials="" Archivo del que obtener credenciales y secretos

-d, --debug[=false] salida de depuración con rastreo de pila

-l, --log-format="text" formato para el registro

-m, --manifest="./kubeone.yaml" Ruta a la configuración de KubeOne

-t, --tfjson="" Fuente para la salida de terraform en JSON - para leer de la entrada estándar. Si la ruta es un archivo, se usarán los contenidos. Si la ruta es un diccionario, se ejecuta terraform output -json en esta ruta

-v, --verbose[=false] salida detallada

EJEMPLO

kubeone config dump -m kubeone.yaml -t tf.json

VER TAMBIÉN

kubeone-config(1)
