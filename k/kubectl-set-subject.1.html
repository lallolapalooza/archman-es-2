NOMBRE

kubectl set subject - Actualiza el usuario, grupo o cuenta de servicio en una vinculación de roles o vinculación de roles de clúster

SINOPSIS

kubectl set subject [OPCIONES]

DESCRIPCIÓN

Actualiza el usuario, grupo o cuenta de servicio en una vinculación de roles o vinculación de roles de clúster.

OPCIONES

--all=false Selecciona todos los recursos, en el espacio de nombres de los tipos de recursos especificados

--allow-missing-template-keys=true Si es verdadero, ignora cualquier error en las plantillas cuando falta un campo o una clave de mapa en la plantilla. Solo se aplica a los formatos de salida golang y jsonpath.

--dry-run="none" Debe ser "none", "server", o "client". Si la estrategia es cliente, solo imprime el objeto que se enviaría, sin enviarlo. Si la estrategia es servidor, envía una solicitud del lado del servidor sin persistir el recurso.

--field-manager="kubectl-set" Nombre del gestor utilizado para rastrear la propiedad del campo.

-f, --filename=[] Nombre del archivo, directorio o URL a los archivos del recurso para actualizar los sujetos

--group=[] Grupos a vincular al rol

-k, --kustomize="" Procesa el directorio kustomization. Esta bandera no se puede usar junto con -f o -R.

--local=false Si es verdadero, set subject NO contactará con el api-server sino que se ejecutará localmente.

-o, --output="" Formato de salida. Uno de: (json, yaml, name, go-template, go-template-file, template, templatefile, jsonpath, jsonpath-as-json, jsonpath-file).

-R, --recursive=false Procesa el directorio utilizado en -f, --filename recursivamente. Útil cuando desea administrar manifiestos relacionados organizados dentro del mismo directorio.

-l, --selector="" Selector (consulta de etiquetas) para filtrar, soporta '=', '==', '!=', 'in', 'notin'.(ej. -l key1=value1,key2=value2,key3 in (value3)). Los objetos coincidentes deben satisfacer todas las restricciones de etiquetas especificadas.

--serviceaccount=[] Cuentas de servicio a vincular al rol

--show-managed-fields=false Si es verdadero, conserva los managedFields al imprimir objetos en formato JSON o YAML.

--template="" Cadena de plantilla o ruta al archivo de plantilla a utilizar cuando -o=go-template, -o=go-template-file. El formato de plantilla es golang templates [http://golang.org/pkg/text/template/#pkg-overview].

--user=[] Nombres de usuario a vincular al rol

OPCIONES HEREDADAS DE COMANDOS PADRE

--as="" Nombre de usuario a suplantar para la operación. El usuario podría ser un usuario regular o una cuenta de servicio en un espacio de nombres.

--as-group=[] Grupo a suplantar para la operación, esta bandera se puede repetir para especificar múltiples grupos.

--as-uid="" UID a suplantar para la operación.

--cache-dir="/home/username/.kube/cache" Directorio de caché predeterminado

--certificate-authority="" Ruta a un archivo de certificado para la autoridad de certificación

--client-certificate="" Ruta a un archivo de certificado de cliente para TLS

--client-key="" Ruta a un archivo de clave de cliente para TLS

--cluster="" El nombre del clúster kubeconfig a utilizar

--context="" El nombre del contexto kubeconfig a utilizar

--disable-compression=false Si es verdadero, desactiva la compresión de respuesta para todas las solicitudes al servidor

--insecure-skip-tls-verify=false Si es verdadero, el certificado del servidor no se verificará en busca de validez. Esto hará que sus conexiones HTTPS no sean seguras

--kubeconfig="" Ruta al archivo kubeconfig a utilizar para las solicitudes CLI.

--kuberc="" Ruta al archivo kuberc a utilizar para las preferencias. Esto se puede deshabilitar exportando la puerta de enlace de funciones KUBECTL_KUBERC=false o desactivando la función KUBERC=off.

--match-server-version=false Requiere que la versión del servidor coincida con la versión del cliente

-n, --namespace="" Si está presente, el ámbito del espacio de nombres para esta solicitud CLI

--password="" Contraseña para la autenticación básica al servidor API

--profile="none" Nombre del perfil a capturar. Uno de (none|cpu|heap|goroutine|threadcreate|block|mutex)

--profile-output="profile.pprof" Nombre del archivo donde escribir el perfil

--request-timeout="0" La duración de tiempo a esperar antes de desistir en una sola solicitud al servidor. Los valores distintos de cero deben contener una unidad de tiempo correspondiente (por ejemplo, 1s, 2m, 3h). Un valor de cero significa no agotar el tiempo de espera de las solicitudes.

-s, --server="" La dirección y el puerto del servidor API de Kubernetes

--tls-server-name="" Nombre del servidor a utilizar para la validación del certificado del servidor. Si no se proporciona, se usa el nombre de host utilizado para contactar al servidor

--token="" Token de portador para la autenticación al servidor API

--username="" Nombre de usuario para la autenticación básica al servidor API

--version=false --version, --version=raw imprime información de versión y sale; --version=vX.Y.Z... establece la versión reportada

--warnings-as-errors=false Tratar las advertencias recibidas del servidor como errores y salir con un código de salida distinto de cero

EJEMPLO

  # Actualiza una vinculación de roles de clúster para serviceaccount1
  kubectl set subject clusterrolebinding admin --serviceaccount=namespace:serviceaccount1
  # Actualiza una vinculación de roles para user1, user2 y group1
  kubectl set subject rolebinding admin --user=user1 --user=user2 --group=group1
  # Imprime el resultado (en formato YAML) de la actualización de los sujetos de rolebinding desde una fuente local, sin contactar al servidor
  kubectl create rolebinding admin --role=admin --user=admin -o yaml --dry-run=client | kubectl set subject --local -f - --user=foo -o yaml
