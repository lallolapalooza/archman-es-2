kubeadm-init-phase-addon-all(1)

Licencias: Apache-2.0

Eric Paris Ene 2015

NOMBRE

kubeadm init phase addon all - Instala todos los complementos

SINOPSIS

kubeadm init phase addon all [OPCIONES]

DESCRIPCIÓN

Instala todos los complementos

OPCIONES

--apiserver-advertise-address="" La dirección IP que el Servidor API anunciará que está escuchando. Si no se establece, se utilizará la interfaz de red predeterminada.

--apiserver-bind-port=6443 Puerto en el que se enlazará el Servidor API.

--config="" Ruta a un archivo de configuración de kubeadm.

--control-plane-endpoint="" Especifica una IP estable o un nombre DNS para el plano de control.

--dry-run=false No aplique ningún cambio; solo muestre lo que se haría.

--feature-gates="" Un conjunto de pares clave=valor que describen puertas de características para varias funciones. Las opciones son: ControlPlaneKubeletLocalMode=true|false (BETA - por defecto=true) NodeLocalCRISocket=true|false (BETA - por defecto=true) PublicKeysECDSA=true|false (OBSOLETO - por defecto=false) RootlessControlPlane=true|false (ALPHA - por defecto=false) WaitForAllControlPlaneComponents=true|false (por defecto=true)

--image-repository="registry.k8s.io" Elige un registro de contenedores para descargar las imágenes del plano de control.

--kubeconfig="/etc/kubernetes/admin.conf" El archivo kubeconfig a usar al comunicarse con el clúster. Si no se establece la bandera, se puede buscar un archivo kubeconfig existente en ubicaciones estándar.

--kubernetes-version="stable-1" Elige una versión específica de Kubernetes para el plano de control.

--pod-network-cidr="" Especifica el rango de direcciones IP para la red de pods. Si se establece, el plano de control asignará automáticamente CIDRs para cada nodo.

--service-cidr="10.96.0.0/12" Utiliza un rango alternativo de direcciones IP para las VIPs de servicio.

--service-dns-domain="cluster.local" Utiliza un dominio alternativo para los servicios, por ejemplo, "myorg.internal".

OPCIONES HEREDADAS DE COMANDOS PADRE

--rootfs="" La ruta al sistema de archivos raíz 'real' del host. Esto hará que kubeadm entre en chroot en la ruta proporcionada.

--version=false --version, --version=raw imprime la información de la versión y sale; --version=vX.Y.Z... establece la versión reportada.
