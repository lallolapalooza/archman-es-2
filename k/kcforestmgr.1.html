NOMBRE

kcforestmgr - interfaz de línea de comandos para gestionar la base de datos de árboles de directorios

DESCRIPCIÓN

El comando `kcforestmgr' es una utilidad para probar y depurar la base de datos de árboles de archivos y sus aplicaciones. `path' especifica la ruta de un archivo de base de datos. `key' especifica la clave de un registro. `value' especifica el valor de un registro. `file' especifica el archivo de entrada/salida.


kcforestmgr create [-otr] [-onl|-otl|-onr] [-tc] [-bnum num] [-psiz num] [-rcd|-rcld|-rcdd] path
Crea un archivo de base de datos.
kcforestmgr inform [-onl|-otl|-onr] [-st] path
Imprime información de estado.
kcforestmgr set [-onl|-otl|-onr] [-add|-app|-rep|-inci|-incd] [-sx] path key value
Almacena un registro.
kcforestmgr remove [-onl|-otl|-onr] [-sx] path key
Elimina un registro.
kcforestmgr get [-onl|-otl|-onr] [-rm] [-sx] [-px] [-pz] path key
Imprime el valor de un registro.
kcforestmgr list [-onl|-otl|-onr] [-des] [-max num] [-rm] [-sx] [-pv] [-px] path [key]
Imprime las claves de todos los registros, separadas por saltos de línea.
kcforestmgr clear [-onl|-otl|-onr] path
Elimina todos los registros de una base de datos.
kcforestmgr import [-onl|-otl|-onr] [-sx] path [file]
Importa registros desde un archivo TSV.
kcforestmgr copy [-onl|-otl|-onr] path file
Copia toda la base de datos.
kcforestmgr dump [-onl|-otl|-onr] path [file]
Exporta registros a un archivo de instantánea.
kcforestmgr load [-otr] [-onl|-otl|-onr] path [file]
Carga registros desde un archivo de instantánea.
kcforestmgr setbulk [-onl|-otl|-onr] path key value ...
Almacena registros a la vez.
kcforestmgr removebulk [-onl|-otl|-onr] [-sx] path key ...
Elimina registros a la vez.
kcforestmgr getbulk [-onl|-otl|-onr] [-sx] [-px] path key ...
Recupera registros a la vez.
kcforestmgr check [-onl|-otl|-onr] path
Comprueba la consistencia.

Las opciones incluyen lo siguiente:

-otr : abre la base de datos con la opción de truncado.
-onl : abre la base de datos con la opción de no bloqueo.
-otl : abre la base de datos con la opción de intentar bloqueo.
-onr : abre la base de datos con la opción de no reparación automática.
-tc : ajusta la base de datos con la opción de compresión.
-bnum num : especifica el número de cubos de la tabla hash.
-psiz num : especifica el tamaño de cada página.
-rcd : utiliza el comparador decimal en lugar del léxico.
-rcld : utiliza el comparador léxico descendente en lugar del ascendente.
-rcdd : utiliza el comparador decimal descendente en lugar del léxico.
-st : imprime información miscelánea.
-add : realiza la operación de adición.
-app : realiza la operación de añadir al final.
-rep : realiza la operación de reemplazo.
-inci : realiza la operación de incremento entero.
-incd : realiza la operación de incremento de número real.
-sx : los datos de entrada se evalúan como una cadena de datos hexadecimales.
-rm : elimina el registro.
-px : los datos de salida se convierten en una cadena de datos hexadecimales.
-pz : no añade un salto de línea al final de la salida.
-des : visita los registros en orden descendente.
-max num : especifica el número máximo de registros mostrados.
-pv : también imprime los valores de los registros.

Este comando devuelve 0 si tiene éxito, otro valor si falla.
