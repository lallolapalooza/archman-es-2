NOMBRE

kubectl run - Ejecutar una imagen particular en el clúster

SINOPSIS

kubectl run [OPCIONES]

DESCRIPCIÓN

Crea y ejecuta una imagen particular en un pod.

OPCIONES

--allow-missing-template-keys=true Si es verdadero, ignora cualquier error en las plantillas cuando un campo o clave de mapa falta en la plantilla. Solo se aplica a los formatos de salida golang y jsonpath.

--annotations=[] Anotaciones para aplicar al pod.

--attach=false Si es verdadero, espera a que el Pod comience a ejecutarse y luego se conecta al Pod como si se hubiera llamado a `kubectl attach ...`. Predeterminado falso, a menos que se establezca '-i/--stdin', en cuyo caso el valor predeterminado es verdadero. Con '--restart=Never', se devuelve el código de salida del proceso del contenedor.

--cascade="background" Debe ser "background", "orphan" o "foreground". Selecciona la estrategia de eliminación en cascada para los dependientes (por ejemplo, Pods creados por un ReplicationController). Predeterminado: background.

--command=false Si es verdadero y hay argumentos adicionales presentes, úsalos como el campo 'command' en el contenedor, en lugar del campo 'args', que es el predeterminado.

--dry-run="none" Debe ser "none", "server" o "client". Si la estrategia es client, solo imprime el objeto que se enviaría, sin enviarlo. Si la estrategia es server, envía una solicitud del lado del servidor sin persistir el recurso.

--env=[] Variables de entorno a establecer en el contenedor.

--expose=false Si es verdadero, crea un servicio ClusterIP asociado con el pod. Requiere --port.

--field-manager="kubectl-run" Nombre del gestor utilizado para rastrear la propiedad de los campos.

-f, --filename=[] para usar y reemplazar el recurso.

--force=false Si es verdadero, elimina inmediatamente los recursos de la API y omite la eliminación gradual. Ten en cuenta que la eliminación inmediata de algunos recursos puede resultar en inconsistencia o pérdida de datos y requiere confirmación.

--grace-period=-1 Período de tiempo en segundos otorgado al recurso para terminar de forma gradual. Ignorado si es negativo. Establecido en 1 para cierre inmediato. Solo se puede establecer en 0 cuando --force es verdadero (eliminación forzada).

--image="" La imagen para que el contenedor ejecute.

--image-pull-policy="" La política de extracción de imagen para el contenedor. Si se deja vacío, este valor no será especificado por el cliente y será predeterminado por el servidor.

-k, --kustomize="" Procesa un directorio de kustomization. Esta bandera no se puede usar junto con -f o -R.

-l, --labels="" Etiquetas separadas por comas para aplicar al pod. Anularán los valores anteriores.

--leave-stdin-open=false Si el pod se inicia en modo interactivo o con stdin, deja stdin abierto después de que la primera conexión se complete. Por defecto, stdin se cerrará después de que la primera conexión se complete.

-o, --output="" Formato de salida. Uno de: (json, yaml, name, go-template, go-template-file, template, templatefile, jsonpath, jsonpath-as-json, jsonpath-file).

--override-type="merge" El método utilizado para anular el objeto generado: json, merge o strategic.

--overrides="" Una anulación JSON en línea para el objeto generado. Si esto no está vacío, se utiliza para anular el objeto generado. Requiere que el objeto proporcione un campo apiVersion válido.

--pod-running-timeout=1m0s La duración (como 5s, 2m o 3h, mayor que cero) para esperar hasta que al menos un pod esté en ejecución

--port="" El puerto que expone este contenedor.

--privileged=false Si es verdadero, ejecuta el contenedor en modo privilegiado.

-q, --quiet=false Si es verdadero, suprime los mensajes de solicitud.

--record=false Registra el comando kubectl actual en la anotación del recurso. Si se establece en falso, no registra el comando. Si se establece en verdadero, registra el comando. Si no se establece, el valor predeterminado es actualizar el valor de anotación existente solo si ya existe uno.

-R, --recursive=false Procesa el directorio utilizado en -f, --filename recursivamente. Útil cuando deseas administrar manifiestos relacionados organizados dentro del mismo directorio.

--restart="Always" La política de reinicio para este Pod. Valores legales [Always, OnFailure, Never].

--rm=false Si es verdadero, elimina el pod después de que termine. Solo válido cuando se conecta al contenedor, por ejemplo, con '--attach' o con '-i/--stdin'.

--save-config=false Si es verdadero, la configuración del objeto actual se guardará en su anotación. De lo contrario, la anotación permanecerá sin cambios. Esta bandera es útil cuando deseas realizar `kubectl apply` en este objeto en el futuro.

--show-managed-fields=false Si es verdadero, conserva los managedFields al imprimir objetos en formato JSON o YAML.

-i, --stdin=false Mantiene stdin abierto en el contenedor en el pod, incluso si nada está conectado.

--template="" Plantilla de cadena o ruta a un archivo de plantilla para usar cuando -o=go-template, -o=go-template-file. El formato de plantilla es plantillas de Go [http://golang.org/pkg/text/template/#pkg-overview].

--timeout=0s La duración antes de rendirse en una eliminación, cero significa determinar un tiempo de espera a partir del tamaño del objeto

-t, --tty=false Asigna una TTY para el contenedor en el pod.

--wait=false Si es verdadero, espera a que los recursos desaparezcan antes de regresar. Esto espera por los finalizadores.

OPCIONES HEREDADAS DE COMANDOS PADRE

--as="" Nombre de usuario a suplantar para la operación. El usuario puede ser un usuario regular o una cuenta de servicio en un espacio de nombres.

--as-group=[] Grupo a suplantar para la operación, esta bandera se puede repetir para especificar múltiples grupos.

--as-uid="" UID a suplantar para la operación.

--cache-dir="/home/username/.kube/cache" Directorio predeterminado de caché

--certificate-authority="" Ruta a un archivo de certificado para la autoridad certificadora

--client-certificate="" Ruta a un archivo de certificado de cliente para TLS

--client-key="" Ruta a un archivo de clave de cliente para TLS

--cluster="" El nombre del clúster kubeconfig a utilizar

--context="" El nombre del contexto kubeconfig a utilizar

--disable-compression=false Si es verdadero, opta por no comprimir las respuestas para todas las solicitudes al servidor

--insecure-skip-tls-verify=false Si es verdadero, el certificado del servidor no se verificará su validez. Esto hará que tus conexiones HTTPS no sean seguras

--kubeconfig="" Ruta al archivo kubeconfig a utilizar para las solicitudes de la CLI.

--kuberc="" Ruta al archivo kuberc a utilizar para las preferencias. Esto se puede deshabilitar exportando la puerta de enlace de características KUBECTL_KUBERC=false o desactivando la puerta de enlace KUBERC=off.

--match-server-version=false Requiere que la versión del servidor coincida con la versión del cliente

-n, --namespace="" Si está presente, el ámbito del espacio de nombres para esta solicitud de CLI

--password="" Contraseña para la autenticación básica al servidor de la API

--profile="none" Nombre del perfil a capturar. Uno de (none|cpu|heap|goroutine|threadcreate|block|mutex)

--profile-output="profile.pprof" Nombre del archivo donde escribir el perfil

--request-timeout="0" La duración a esperar antes de rendirse en una solicitud de servidor individual. Los valores distintos de cero deben contener una unidad de tiempo correspondiente (por ejemplo, 1s, 2m, 3h). Un valor de cero significa no agotar el tiempo de espera de las solicitudes.

-s, --server="" La dirección y el puerto del servidor de la API de Kubernetes

--tls-server-name="" Nombre del servidor a utilizar para la validación del certificado del servidor. Si no se proporciona, se usa el nombre de host utilizado para contactar al servidor

--token="" Token de portador para la autenticación al servidor de la API

--user=&qu

NAME

kubectl-run — run a particular image on a cluster

SYNOPSIS

kubectl run [OPTIONS] COMMAND [args...]

DESCRIPTION

Launch a Kubernetes Pod and run a command in it. If the command is not specified, the default ENTRYPOINT of the container will be used.

This command is intended to quickly start a container image on your cluster. It is not intended for long-running applications, and the Pod created will not be automatically restarted if it exits.

To use this command, you must specify the image name and optionally a command and its arguments.

You can also use this command to create other Kubernetes resources such as Deployments, Jobs, or CronJobs. Use the --generator flag to specify the type of resource to create.

OPTIONS

--allow-missing-template-keys=true
If true, ignore any errors in templates when a field or map key is missing in the template. Other errors will still be raised.
--annotations=[]
Annotations is an interface with multiple key-value pairs (e.g. key1=value1,key2=value2).
--attach=false
Attach to the specified pod.
--atomic=false
If true, show all conflicts before attempting to patch.
--capture-output=false
If true, capture and return the output of the command.
--chart="":
The name of the chart to deploy.
--chart-dir="":
Path to a directory containing a chart and potentially templates, buyers, etc.
--chart-timeout=0s:
The amount of time to wait for any Kubernetes operations associated with chart processing.
--command=[]
The command to run in the container. Overrides the container's default command.
--dry-run=none:
Must be "none", "server", or "client". If client is passed, the command prints the server request without sending it, and might return incomplete response because the server version is not known.
--env=[]
Add env variables to container (e.g NV1=val1,NV2=val2).
--expose=false
Specifies if the container's port should be exposed as a Kubernetes Service.
--field-manager="":
Name of the manager used to track field ownership.
--field-selector="":
Selector (field query) to filter on.
--force=false
If true, immediately remove resources from the cluster, even if they are not running.
--generator="":
The URL of the template generator to use.
--grace-period=-1
Period of time in seconds given to the resource to terminate gracefully. Ignored if negative. Set to 1 for immediate shutdown.
--help=false
Help for kubectl run
--image="":
Container image to run.
--image-pull-policy="":
Specify a pull policy for the image. Allowed values: Always, Never, IfNotPresent.
--labels=[]
Labels is an interface with multiple key-value pairs (e.g. key1=value1,key2=value2).
--leave-running=true
If true, leave the running pod on the cluster when the command exits.
--no-headers=false
When using the default or short output format, don't print headers.
--overwrite=false
Automatically overwrite existing objects along with their drift.
--port="":
The port that this container exposes.
--quiet=false
If true, suppress informational output.
--record=false
Record current kustomization and patch in the history.
--recursive=false
Processed the recursive directory listing.
--restart="":
Specify a restart policy for the container. Allowed values: Always, OnFailure, Never.
--save-config=false
If true, the configuration of current object will be saved in its annotation. Otherwise, the defaults from the configuration will be used.
--selector="":
Selector (label query) to filter on.
--server-print=false
If true, have the server echo the rendered template back to the client.
--show-managed-fields=false
If true, keep the managed fields when printing objects.
--timeout=0s:
The length of time to wait before giving up on a single command.
--to-json=false
Print the API objects as JSON.
--template-value=[]
Template values to use when templating the resource.
--validate=true
If true, use a server-side dry run to call apiserver to validate the object before creating it.
--version=false
Print the version number of kubectl and quit.
--warnings-as-errors=false
Treat warnings received from the server as errors and exit with a non-zero exit code

EXAMPLE

  # Start a nginx pod
  kubectl run nginx --image=nginx
  # Start a hazelcast pod and let the container expose port 5701
  kubectl run hazelcast --image=hazelcast/hazelcast --port=5701
  # Start a hazelcast pod and set environment variables "DNS_DOMAIN=cluster" and "POD_NAMESPACE=default" in the container
  kubectl run hazelcast --image=hazelcast/hazelcast --env="DNS_DOMAIN=cluster" --env="POD_NAMESPACE=default"
  # Start a hazelcast pod and set labels "app=hazelcast" and "env=prod" in the container
  kubectl run hazelcast --image=hazelcast/hazelcast --labels="app=hazelcast,env=prod"
  # Dry run; print the corresponding API objects without creating them
  kubectl run nginx --image=nginx --dry-run=client
  # Start a nginx pod, but overload the spec with a partial set of values parsed from JSON
  kubectl run nginx --image=nginx --overrides='{ "apiVersion": "v1", "spec": { ... } }'
  # Start a busybox pod and keep it in the foreground, don't restart it if it exits
  kubectl run -i -t busybox --image=busybox --restart=Never
  # Start the nginx pod using the default command, but use custom arguments (arg1 .. argN) for that command
  kubectl run nginx --image=nginx -- <arg1> <arg2> ... <argN>
  # Start the nginx pod using a different command and custom arguments
  kubectl run nginx --image=nginx --command -- <cmd> <arg1> ... <argN>
