NOMBRE

knotd - Demonio del servidor DNS Knot

SINOPSIS

knotd [opción_config] [opciones]

DESCRIPCIÓN

Knot DNS es un servidor DNS autoritativo de alto rendimiento. El programa knotd es el demonio del servidor DNS.

Opciones de configuración

-c, --config archivo
Utilizar un archivo de configuración textual (el valor por defecto es /etc/knot/knot.conf).
-C, --confdb directorio
Utilizar un directorio de base de datos de configuración binaria (el valor por defecto es /var/lib/knot/confdb). La base de datos de configuración por defecto, si existe, tiene preferencia sobre el archivo de configuración por defecto.

Opciones

-m, --max-conf-size MiB
Establecer el tamaño máximo de la base de datos de configuración (el valor por defecto es 500 MiB, máximo 10000 MiB).
-s, --socket ruta
Utilizar una ruta de socket UNIX de control remoto (el valor por defecto es /run/knot/knot.sock).
-d, --daemonize [directorio]
Ejecutar el servidor como un demonio. Se puede especificar un nuevo directorio raíz (el valor por defecto es /).
-v, --verbose
Habilitar la salida de depuración.
-h, --help
Imprimir la ayuda del programa.
-V, --version
Imprimir la versión del programa. La opción -VV hace que el programa imprima el resumen de la configuración en tiempo de compilación.

Señales

Si el proceso knotd recibe una señal SIGHUP, recarga su configuración y reabre los archivos de registro, si están configurados. Cuando knotd recibe una señal SIGUSR1, recarga todas las zonas configuradas. Al recibir una señal SIGINT, knotd sale.

VALORES DE SALIDA

Un estado de salida de 0 significa operación exitosa. Cualquier otro estado de salida indica un error.

VER TAMBIÉN
