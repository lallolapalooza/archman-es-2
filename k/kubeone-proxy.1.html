NOMBRE

kubeone-proxy - Proxy para el kube-apiserver usando un túnel SSH

SINOPSIS

kubeone proxy [flags]

DESCRIPCIÓN

Proxy HTTPS (método CONNECT) túnel SSH.

Este comando ayuda a acceder al endpoint de kubeapi con kubectl local en caso de que se utilice un endpoint privado/cortafuegos (por ejemplo, un balanceador de carga interno). Crea un túnel SSH a uno de los nodos del plano de control y luego redirige las solicitudes entrantes a través de él.

OPCIONES

-h, --help[=false] Ayuda para proxy

--listen="127.0.0.1:8888" Dirección de enlace del proxy HTTP del túnel SSH

OPCIONES HEREDADAS DE COMANDOS PADRE

-c, --credentials="" Archivo del que extraer credenciales y secretos

-d, --debug[=false] salida de depuración con rastreo de pila

-l, --log-format="text" formato para el registro

-m, --manifest="./kubeone.yaml" Ruta al archivo de configuración de KubeOne

-t, --tfjson="" Fuente para la salida de terraform en JSON - para leer desde stdin. Si la ruta es un archivo, se utilizarán sus contenidos. Si la ruta es un directorio, se ejecutará terraform output -json en esa ruta

-v, --verbose[=false] salida detallada

EJEMPLO

kubeone proxy -m mycluster.yaml -t terraformoutput.json
