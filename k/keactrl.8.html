NOMBRE

keactrl - Script de shell para gestionar Kea

SINOPSIS

keactrl [comando] [-c archivo-de-configuracion-keactrl] [-s servidor[,servidor,...]] [-v]

DESCRIPCION

keactrl es un script de shell que controla el inicio, la parada y la reconfiguración de los servidores Kea (kea-dhcp4, kea-dhcp6, kea-dhcp-ddns, kea-ctrl-agent y kea-netconf). También proporciona una forma de comprobar el estado actual de los servidores y determinar los archivos de configuración en uso.

ARCHIVO DE CONFIGURACION

Dependiendo de los requisitos del usuario, no todos los servidores disponibles necesitan ejecutarse. El archivo de configuración de keactrl especifica qué servidores están habilitados y cuáles están deshabilitados. Por defecto, el archivo de configuración es [directorio-instalacion-kea]/etc/kea/keactrl.conf.

Consulte el Manual de Referencia del Administrador de Kea para obtener documentación sobre los parámetros del archivo de configuración de keactrl.

OPCIONES

comando
Especifica el comando que se emitirá a los servidores. Puede ser uno de los siguientes:
start
Inicia los servidores.
stop
Detiene los servidores.
reload
Instruye a los servidores para que vuelvan a leer el archivo de configuración de Kea. Este comando no es compatible con el agente NETCONF.
status
Muestra el estado de los servidores.
-c|--ctrl-config archivo-de-configuracion-keactrl
Especifica el archivo de configuración de keactrl. Sin esta opción, keactrl utiliza el archivo [directorio-instalacion-kea]/etc/kea/keactrl.conf.
-s|--server servidor[,servidor,...]
Especifica un subconjunto de los servidores habilitados a los que se debe emitir el comando. La lista de servidores debe estar separada por comas, sin espacios intermedios. Los valores aceptables son:
dhcp4
Servidor DHCPv4 (kea-dhcp4).
dhcp6
Servidor DHCPv6 (kea-dhcp6).
dhcp_ddns
Servidor DHCP DDNS (kea-dhcp-ddns).
ctrl_agent
Agente de Control (kea-ctrl-agent).
netconf
Agente NETCONF (kea-netconf).
all
Todos los servidores, incluido NETCONF si fue configurado para ser compilado. Este es el valor por defecto.
-v|--version
Muestra la versión de Kea.
-V
Muestra la versión extendida de Kea.

DOCUMENTACION

Kea viene con un extenso Manual de Referencia del Administrador de Kea que cubre todos los aspectos de la ejecución del software Kea: compilación, instalación, configuración, ejemplos de configuración y mucho más. Kea también incluye un Manual de Mensajes de Kea, que enumera todos los mensajes posibles que Kea puede imprimir con una breve descripción de cada uno. Ambos documentos están disponibles en varios formatos (.txt, .html, .pdf) con la distribución de Kea. La documentación de Kea está disponible en https://kea.readthedocs.io.

El código fuente de Kea está documentado en la Guía del Desarrollador de Kea, disponible en https://reports.kea.isc.org/dev_guide/.

El sitio web del proyecto Kea está disponible en https://kea.isc.org.

LISTAS DE MAILING Y SOPORTE

Hay dos listas de correo públicas disponibles para el proyecto Kea. kea-users (kea-users at lists.isc.org) está destinada a los usuarios de Kea, mientras que kea-dev (kea-dev at lists.isc.org) está destinada a los desarrolladores de Kea, posibles colaboradores y otros usuarios avanzados. Ambas listas están disponibles en https://lists.isc.org. La comunidad proporciona soporte de mejor esfuerzo en ambas listas.

ISC proporciona soporte profesional para los servicios de Kea. Consulte https://www.isc.org/kea/ para más detalles.
