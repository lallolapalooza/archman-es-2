KMAG(1) Manual de Usuario de KMagnifier KMAG(1)

NOMBRE

kmag - Lupa de pantalla

SINOPSIS

kmag

DESCRIPCIÓN

kmag, también conocido como KMagnifier, es una lupa de pantalla. Puede usar KMagnifier para magnificar una parte de la pantalla tal como usaría una lente para magnificar la letra pequeña de un periódico o una fotografía. Esta aplicación es útil para una variedad de personas: desde investigadores hasta artistas, pasando por diseñadores web y personas con baja visión.
