keyctl_get_security(3)

Paquete: keyutils

Licencias: GPL2, LGPL2.1

KEYCTL_GET_SECURITY(3) Llamadas de gestión de claves de Linux KEYCTL_GET_SECURITY(3)

NOMBRE

keyctl_get_security - recuperar el contexto de seguridad de una clave

SINOPSIS

#include <keyutils.h>

long keyctl_get_security(key_serial_t key, char *buffer,
size_t buflen);

long keyctl_get_security_alloc(key_serial_t key, char **_buffer);

DESCRIPCIÓN

keyctl_get_security() recupera el contexto de seguridad de una clave como una cadena terminada en NUL. Esto se mostrará en un formato apropiado para el LSM en vigor; por ejemplo, con SELinux, podría parecerse a:

unconfined_u:unconfined_r:unconfined_t:s0-s0:c0.c1023

El llamador debe tener permiso de vista en una clave para poder obtener su contexto de seguridad.

buffer y buflen especifican el búfer en el que se colocará la cadena. Si el búfer es demasiado pequeño, se devolverá el tamaño completo de la cadena y no se realizará ninguna copia.

keyctl_get_security_alloc() es similar a keyctl_get_security() excepto que asigna un búfer lo suficientemente grande como para contener la cadena y copia la cadena en él. Si tiene éxito, se coloca un puntero al búfer en *_buffer. El llamador debe liberar el búfer.

VALOR DEVUELTO

En caso de éxito, keyctl_get_security() devuelve la cantidad de datos colocados en el búfer. Si el búfer era demasiado pequeño, se devolverá el tamaño de búfer requerido, pero no se transferirá ningún dato. En caso de error, se devolverá el valor -1 y errno se habrá establecido con un error apropiado.

En caso de éxito, keyctl_get_security_alloc() devuelve la cantidad de datos en el búfer, menos el terminador NUL. En caso de error, se devolverá el valor -1 y errno se habrá establecido con un error apropiado.

ERRORES

ENOKEY
La clave especificada no es válida.
EKEYEXPIRED
La clave especificada ha caducado.
EKEYREVOKED
La clave especificada ha sido revocada.
EACCES
La clave existe, pero no es visible por el proceso llamante.

ENLAZADO

Esta es una función de biblioteca que se puede encontrar en libkeyutils. Al enlazar, se debe especificar -lkeyutils al enlazador.

VER TAMBIÉN
