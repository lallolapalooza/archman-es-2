NOMBRE

kubectl completion - Genera código de completado para el shell especificado (bash, zsh, fish o powershell)

SINOPSIS

kubectl completion [OPCIONES]

DESCRIPCIÓN

Genera código de completado para el shell especificado (bash, zsh, fish o powershell). El código del shell debe ser evaluado para proporcionar completado interactivo de comandos kubectl. Esto se puede hacer cargándolo desde el .bash_profile.

Las instrucciones detalladas sobre cómo hacerlo están disponibles aquí:

    para macOS:
    https://kubernetes.io/docs/tasks/tools/install-kubectl-macos/#enable-shell-autocompletion
    para linux:
    https://kubernetes.io/docs/tasks/tools/install-kubectl-linux/#enable-shell-autocompletion
    para windows:
    https://kubernetes.io/docs/tasks/tools/install-kubectl-windows/#enable-shell-autocompletion

Nota para usuarios de zsh: [1] el completado de zsh solo es compatible en versiones de zsh >= 5.2.

OPCIONES HEREDADAS DE COMANDOS PADRE

--as="" Nombre de usuario a suplantar para la operación. El usuario puede ser un usuario normal o una cuenta de servicio en un namespace.

--as-group=[] Grupo a suplantar para la operación, este flag se puede repetir para especificar múltiples grupos.

--as-uid="" UID a suplantar para la operación.

--cache-dir="/home/username/.kube/cache" Directorio de caché predeterminado

--certificate-authority="" Ruta a un archivo de certificado para la autoridad de certificación

--client-certificate="" Ruta a un archivo de certificado de cliente para TLS

--client-key="" Ruta a un archivo de clave de cliente para TLS

--cluster="" El nombre del clúster de kubeconfig a utilizar

--context="" El nombre del contexto de kubeconfig a utilizar

--disable-compression=false Si es true, desactiva la compresión de respuesta para todas las solicitudes al servidor

--insecure-skip-tls-verify=false Si es true, el certificado del servidor no se verificará en busca de validez. Esto hará que sus conexiones HTTPS no sean seguras

--kubeconfig="" Ruta al archivo kubeconfig a utilizar para las solicitudes de CLI.

--kuberc="" Ruta al archivo kuberc a utilizar para las preferencias. Esto se puede deshabilitar exportando la puerta de enlace de características KUBECTL_KUBERC=false o desactivando la puerta de enlace KUBERC=off.

--match-server-version=false Requiere que la versión del servidor coincida con la versión del cliente

-n, --namespace="" Si está presente, el ámbito del namespace para esta solicitud de CLI

--password="" Contraseña para la autenticación básica al servidor de API

--profile="none" Nombre del perfil a capturar. Uno de (none|cpu|heap|goroutine|threadcreate|block|mutex)

--profile-output="profile.pprof" Nombre del archivo donde escribir el perfil

--request-timeout="0" Tiempo de espera antes de rendirse en una única solicitud al servidor. Los valores distintos de cero deben contener una unidad de tiempo correspondiente (por ejemplo, 1s, 2m, 3h). Un valor de cero significa que las solicitudes no tendrán tiempo de espera.

-s, --server="" La dirección y el puerto del servidor de API de Kubernetes

--tls-server-name="" Nombre del servidor a usar para la validación del certificado del servidor. Si no se proporciona, se utiliza el nombre de host utilizado para contactar al servidor

--token="" Token Bearer para autenticación al servidor de API

--user="" El nombre del usuario de kubeconfig a utilizar

--username="" Nombre de usuario para la autenticación básica al servidor de API

--version=false --version, --version=raw imprime información de la versión y sale; --version=vX.Y.Z... establece la versión reportada

--warnings-as-errors=false Tratar las advertencias recibidas del servidor como errores y salir con un código de salida distinto de cero

EJEMPLO

  # Instalación de completado bash en macOS usando homebrew
  ## Si se ejecuta Bash 3.2 incluido con macOS
  brew install bash-completion
  ## o, si se ejecuta Bash 4.1+
  brew install bash-completion@2
  ## Si kubectl se instala a través de homebrew, esto debería funcionar inmediatamente
  ## Si lo ha instalado por otros medios, es posible que necesite agregar el completado a su directorio de completado
  kubectl completion bash > $(brew --prefix)/etc/bash_completion.d/kubectl
  # Instalación de completado bash en Linux
  ## Si bash-completion no está instalado en Linux, instale el paquete 'bash-completion'
  ## a través del gestor de paquetes de su distribución.
  ## Cargue el código de completado de kubectl para bash en el shell actual
  source <(kubectl completion bash)
  ## Escriba el código de completado de bash en un archivo y cárguelo desde .bash_profile
  kubectl completion bash > ~/.kube/completion.bash.inc
  printf "
  # Completado de shell de kubectl
  source '$HOME/.kube/completion.bash.inc'
  " >> $HOME/.bash_profile
  source $HOME/.bash_profile
  # Cargue el código de completado de kubectl para zsh[1] en el shell actual
  source <(kubectl completion zsh)
  # Establezca el código de completado de kubectl para zsh[1] para que se cargue automáticamente al inicio
  kubectl completion zsh > "${fpath[1]}/_kubectl"
  # Cargue el código de completado de kubectl para fish[2] en el shell actual
  kubectl completion fish | source
  # Para cargar los completados para cada sesión, ejecute una vez:
  kubectl completion fish > ~/.config/fish/completions/kubectl.fish
  # Cargue el código de completado de kubectl para powershell en el shell actual
  kubectl completion powershell | Out-String | Invoke-Expression
  # Establezca el completado de kubectl para powershell para que se ejecute al inicio
  ## Guarde el código de completado en un script y ejecútelo en el perfil
  kubectl completion powershell > $HOME\.kube\completion.ps1
  Add-Content $PROFILE "$HOME\.kube\completion.ps1"
  ## Ejecute el código de completado en el perfil
  Add-Content $PROFILE "if (Get-Command kubectl -ErrorAction SilentlyContinue) {
  kubectl completion powershell | Out-String | Invoke-Expression
  }"
  ## Agregue el código de completado directamente al script $PROFILE
  kubectl completion powershell >> $PROFILE
