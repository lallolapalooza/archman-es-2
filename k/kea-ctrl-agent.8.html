NOMBRE

kea-ctrl-agent - Agente de Control proceso en Kea

SINOPSIS

kea-ctrl-agent [-v] [-V] [-W] [-d] [-c archivo-config] [-t archivo-config]

DESCRIPCIÓN

El kea-ctrl-agent proporciona un servicio REST para controlar los servicios de Kea. Las peticiones HTTP recibidas se desencapsulan y se reenvían a los servicios Kea respectivos en formato JSON. Las respuestas JSON recibidas se encapsulan dentro de respuestas HTTP y se devuelven a la entidad que controla. Algunos comandos pueden ser manejados directamente por el Agente de Control, y no reenviados a ningún servicio Kea.

ARGUMENTOS

Los argumentos son los siguientes:

-v
Muestra la versión.
-V
Muestra la versión extendida.
-W
Muestra el informe de configuración.
-d
Establece el nivel de registro en depuración con verbosidad extra. Esto es principalmente para fines de desarrollo en modo independiente.
-c archivo-config
Especifica el archivo con la configuración para el servidor del Agente de Control. También puede contener entradas de configuración para otros servicios Kea.
-t archivo-config
Comprueba la sintaxis del archivo de configuración e informa del primer error, si lo hay. Tenga en cuenta que no todos los parámetros se comprueban completamente; en particular, los sockets de servicio y cliente no se abren, y las bibliotecas de hook no se cargan.

DOCUMENTACIÓN

Kea viene con un extenso Manual de Referencia del Administrador de Kea que cubre todos los aspectos de ejecución del software Kea: compilación, instalación, configuración, ejemplos de configuración y mucho más. Kea también incluye un Manual de Mensajes de Kea, que lista todos los mensajes posibles que Kea puede imprimir con una breve descripción para cada uno de ellos. Ambos documentos están disponibles en varios formatos (.txt, .html, .pdf) con la distribución de Kea. La documentación de Kea está disponible en https://kea.readthedocs.io.

El código fuente de Kea está documentado en la Guía del Desarrollador de Kea, disponible en https://reports.kea.isc.org/dev_guide/.

El sitio web del proyecto Kea está disponible en https://kea.isc.org.

LISTAS DE CORREO Y SOPORTE

Hay dos listas de correo públicas disponibles para el proyecto Kea. kea-users (kea-users en lists.isc.org) está destinada a los usuarios de Kea, mientras que kea-dev (kea-dev en lists.isc.org) está destinada a los desarrolladores de Kea, posibles colaboradores y otros usuarios avanzados. Ambas listas están disponibles en https://lists.isc.org. La comunidad proporciona soporte con el mejor esfuerzo en ambas listas.

ISC proporciona soporte profesional para los servicios Kea. Consulte https://www.isc.org/kea/ para obtener más detalles.

HISTORIA

El kea-ctrl-agent fue codificado por primera vez en diciembre de 2016 por Marcin Siodelski.
