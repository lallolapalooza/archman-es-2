NOMBRE

kubectl apply view-last-applied - Ver las últimas anotaciones last-applied-configuration de un recurso/objeto

SINOPSIS

kubectl apply view-last-applied [OPCIONES]

DESCRIPCIÓN

Ver las últimas anotaciones last-applied-configuration por tipo/nombre o archivo.

La salida predeterminada se imprimirá en la salida estándar en formato YAML. Puedes usar la opción -o para cambiar el formato de salida.

OPCIONES

--all=false Selecciona todos los recursos en el namespace de los tipos de recursos especificados

-f, --filename=[] Nombre de archivo, directorio o URL a archivos que contienen las anotaciones last-applied-configuration

-k, --kustomize="" Procesa el directorio kustomization. Esta opción no se puede usar junto con -f o -R.

-o, --output="yaml" Formato de salida. Debe ser uno de (yaml, json)

-R, --recursive=false Procesa el directorio utilizado en -f, --filename recursivamente. Útil cuando quieres gestionar manifiestos relacionados organizados dentro del mismo directorio.

-l, --selector="" Selector (consulta de etiquetas) para filtrar, soporta '=', '==', '!=', 'in', 'notin'. (ej. -l clave1=valor1,clave2=valor2,clave3 in (valor3)). Los objetos coincidentes deben cumplir todas las restricciones de etiquetas especificadas.

OPCIONES HEREDADAS DE LOS COMANDOS PADRE

--as="" Nombre de usuario a suplantar para la operación. El usuario podría ser un usuario regular o una cuenta de servicio en un namespace.

--as-group=[] Grupo a suplantar para la operación, esta opción se puede repetir para especificar múltiples grupos.

--as-uid="" UID a suplantar para la operación.

--cache-dir="/home/usuario/.kube/cache" Directorio de caché predeterminado

--certificate-authority="" Ruta a un archivo de certificado para la autoridad de certificación

--client-certificate="" Ruta a un archivo de certificado de cliente para TLS

--client-key="" Ruta a un archivo de clave de cliente para TLS

--cluster="" Nombre del clúster de kubeconfig a utilizar

--context="" Nombre del contexto de kubeconfig a utilizar

--disable-compression=false Si es verdadero, opta por no usar la compresión de respuesta para todas las solicitudes al servidor

--insecure-skip-tls-verify=false Si es verdadero, el certificado del servidor no se verificará por su validez. Esto hará que tus conexiones HTTPS no sean seguras

--kubeconfig="" Ruta al archivo kubeconfig a utilizar para las solicitudes CLI.

--kuberc="" Ruta al archivo kuberc a utilizar para preferencias. Esto puede ser deshabilitado exportando la puerta de enlace de funciones KUBECTL_KUBERC=false o desactivando la función KUBERC=off.

--match-server-version=false Requiere que la versión del servidor coincida con la versión del cliente

-n, --namespace="" Si está presente, el ámbito del namespace para esta solicitud CLI

--password="" Contraseña para autenticación básica al servidor API

--profile="none" Nombre del perfil a capturar. Uno de (none|cpu|heap|goroutine|threadcreate|block|mutex)

--profile-output="profile.pprof" Nombre del archivo donde escribir el perfil

--request-timeout="0" El tiempo de espera antes de rendirse en una única solicitud al servidor. Los valores distintos de cero deben contener una unidad de tiempo correspondiente (por ejemplo, 1s, 2m, 3h). Un valor de cero significa no agotar el tiempo de espera de las solicitudes.

-s, --server="" La dirección y el puerto del servidor API de Kubernetes

--tls-server-name="" Nombre del servidor a usar para la validación del certificado del servidor. Si no se proporciona, se utiliza el nombre de host utilizado para contactar al servidor

--token="" Token Bearer para autenticación al servidor API

--user="" Nombre del usuario de kubeconfig a utilizar

--username="" Nombre de usuario para autenticación básica al servidor API

--version=false --version, --version=raw imprime información de la versión y sale; --version=vX.Y.Z... establece la versión informada

--warnings-as-errors=false Trata las advertencias recibidas del servidor como errores y sale con un código de salida distinto de cero

EJEMPLO

  # Ver las anotaciones last-applied-configuration por tipo/nombre en YAML
  kubectl apply view-last-applied deployment/nginx
  # Ver las anotaciones last-applied-configuration por archivo en JSON
  kubectl apply view-last-applied -f deploy.yaml -o json
