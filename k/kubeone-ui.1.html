KubeOne(1) KubeOne(1)

NOMBRE

kubeone-ui - Muestra la interfaz de usuario

SINOPSIS

kubeone ui [flags]

DESCRIPCIÓN

Inicia un servidor web que proporciona una visión general minimalista del Clúster Kubernetes KubeOne.

Por defecto se utilizará el puerto 8080, puedes personalizar el puerto a través de la opción de puerto.

OPCIONES

-h, --help[=false] Ayuda para ui

--port=8080 Puerto en el que se ejecuta el servidor web

OPCIONES HEREDADAS DE COMANDOS PADRE

-c, --credentials="" Archivo del cual extraer credenciales y secretos

-d, --debug[=false] Salida de depuración con rastreo de pila

-l, --log-format="text" Formato para el registro

-m, --manifest="./kubeone.yaml" Ruta al archivo de configuración de KubeOne

-t, --tfjson="" Fuente para la salida de terraform en JSON - para leer desde stdin. Si la ruta es un archivo, se utilizará el contenido. Si la ruta es un directorio, se ejecutará terraform output -json en esa ruta.

-v, --verbose[=false] Salida detallada
