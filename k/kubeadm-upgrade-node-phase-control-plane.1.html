NOMBRE

kubeadm upgrade node phase control-plane - Actualiza la instancia del plano de control desplegada en este nodo, si la hay

SINOPSIS

kubeadm upgrade node phase control-plane [OPCIONES]

DESCRIPCIÓN

Actualiza la instancia del plano de control desplegada en este nodo, si la hay

OPCIONES

--certificate-renewal=true Realiza la renovación de los certificados utilizados por el componente modificado durante las actualizaciones.

--config="" Ruta a un archivo de configuración de kubeadm.

--dry-run=false No cambia ningún estado, solo muestra las acciones que se realizarían.

--etcd-upgrade=true Realiza la actualización de etcd.

--kubeconfig="/etc/kubernetes/admin.conf" El archivo kubeconfig a utilizar al comunicarse con el clúster. Si la opción no está establecida, se puede buscar un archivo kubeconfig existente en una serie de ubicaciones estándar.

--patches="" Ruta a un directorio que contiene archivos con el nombre "target[suffix][+patchtype].extension". Por ejemplo, "kube-apiserver0+merge.yaml" o solo "etcd.json". "target" puede ser uno de "kube-apiserver", "kube-controller-manager", "kube-scheduler", "etcd", "kubeletconfiguration", "corednsdeployment". "patchtype" puede ser uno de "strategic", "merge" o "json" y coinciden con los formatos de parche compatibles con kubectl. El "patchtype" predeterminado es "strategic". "extension" debe ser "json" o "yaml". "suffix" es una cadena opcional que se puede utilizar para determinar qué parches se aplican primero alfabéticamente.

OPCIONES HEREDADAS DE COMANDOS PADRE

--rootfs="" La ruta al sistema de archivos raíz 'real' del host. Esto hará que kubeadm realice un chroot en la ruta proporcionada.

--version=false --version, --version=raw imprime información de la versión y sale; --version=vX.Y.Z... establece la versión reportada
