KBRUCH(1) Manual del Usuario de KBruch KBRUCH(1)

NOMBRE

kbruch - Aprende a calcular con fracciones y porcentajes

SINOPSIS

kbruch [opciones]

DESCRIPCIÓN

KBruch es un pequeño programa para practicar el cálculo con fracciones y porcentajes. Se proporcionan diferentes ejercicios para este propósito. El programa comprueba la entrada del usuario y proporciona retroalimentación.

VER TAMBIÉN

Hay disponible una documentación de usuario más detallada en help:/kbruch (introduzca esta URL en Konqueror, o ejecute khelpcenter help:/kbruch).

También hay información adicional disponible en el sitio web de KDEdu [1]
