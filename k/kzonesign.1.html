NOMBRE

kzonesign - utilidad para firmar DNSSEC

SINOPSIS

kzonesign [opción_config] [opciones] nombre_zona

DESCRIPCIÓN

Esta utilidad lee el archivo de zona, firma la zona según la configuración dada y escribe el archivo de zona firmado de vuelta. Un modo alternativo es la validación DNSSEC de la zona dada. La firma o validación pueden ejecutarse en paralelo si están habilitadas en la configuración (ver policy.signing-threads y zone.adjust-threads).

Parámetros

nombre_zona
Nombre de la zona a firmar.

Opciones de config

-c, --config archivo
Usar un archivo de configuración textual (por defecto es /etc/knot/knot.conf).
-C, --confdb directorio
Usar un directorio de base de datos de configuración binaria (por defecto es /var/lib/knot/confdb). La base de datos de configuración por defecto, si existe, tiene preferencia sobre el archivo de configuración por defecto.

Opciones

-o, --outdir nombre_dir
Escribir el archivo de zona de salida en el directorio especificado en lugar del configurado.
-r, --rollover
Permitir el cambio de claves y el re-salado de NSEC3. Para finalizar la posible entrega de KSK, establezca la marca de tiempo activa de la KSK a ahora (+0) usando keymgr.
-v, --verify
En lugar de (re-)firmar la zona, solo verificar que la zona está correctamente firmada.
-t, --time marca_tiempo
Firmar/verificar la zona (y cambiar las claves si es necesario) como si estuviera en la hora especificada por la marca de tiempo.
-h, --help
Imprimir la ayuda del programa.
-V, --version
Imprimir la versión del programa. La opción -VV hace que el programa imprima el resumen de la configuración de compilación.

VALORES DE SALIDA

El estado de salida 0 significa operación exitosa. Cualquier otro estado de salida indica un error.

VER TAMBIÉN

knot.conf(5), keymgr(8).
