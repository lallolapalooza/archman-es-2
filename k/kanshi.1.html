NOMBRE

kanshi - configuración dinámica de salidas

SINOPSIS

kanshi [opciones...]

OPCIONES

-h, --help

Muestra el mensaje de ayuda y sale.

-c, --config <config>

Especifica un archivo de configuración.

-l, --listen-fd <fd>

Escucha en el descriptor de archivo especificado para IPC.

DESCRIPCIÓN

kanshi es un demonio de Wayland que configura automáticamente las salidas.

kanshi se configura con una lista de perfiles de salida. Cada perfil contiene un conjunto de salidas. Un perfil se activará automáticamente si todas las salidas especificadas están conectadas actualmente. Un perfil contiene la configuración para cada salida.

Si kanshi recibe una señal SIGHUP, volverá a leer su archivo de configuración.

CONFIGURACIÓN

kanshi lee su configuración de $XDG_CONFIG_HOME/kanshi/config. Si no está definida, $XDG_CONFIG_HOME por defecto es ~/.config.

Se genera un error si no se encuentra ningún archivo de configuración.

Para obtener información sobre el formato del archivo de configuración, consulte kanshi(5).

AUTORES

Mantenido por Simon Ser <contact@emersion.fr>, quien cuenta con la ayuda de otros colaboradores de código abierto. Para más información sobre el desarrollo de kanshi, consulte https://gitlab.freedesktop.org/emersion/kanshi.
