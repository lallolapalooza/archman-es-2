NOMBRE

keymod - Modifica parámetros de clave en un archivo keyrec de DNSSEC-Tools

SINOPSIS

keymod [opciones] keyrec1 ... keyrecN

DESCRIPCIÓN

keymod modifica los parámetros de clave en un archivo keyrec que se utilizan para generar claves criptográficas destinadas a firmar zonas. Los nuevos parámetros serán utilizados por zonesigner al generar claves nuevas. No tiene efecto sobre las claves existentes.

zonesigner utilizará el nuevo parámetro para una zona la próxima vez que genere una clave que requiera dicho parámetro. Esto significa que, por ejemplo, una nueva longitud de ZSK no se utilizará durante la siguiente invocación de zonesigner si esa invocación está realizando acciones de cambio de KSK.

Los siguientes campos pueden ser modificados:

kskcount - número de claves KSK
ksklength - longitud de las claves KSK
ksklife - tiempo de vida de las claves KSK
random - archivo del dispositivo generador de números aleatorios
revperiod - período de revocación para claves KSK
zskcount - número de claves ZSK
zsklength - longitud de las claves ZSK
zsklife - tiempo de vida de las claves ZSK

Se añadirán nuevos campos clave/valor a un archivo keyrec de zona para informar a zonesigner de que se deben usar nuevos valores. La parte de clave de los campos añadidos comenzará con "new_". Por ejemplo, una nueva longitud de KSK de 2048 se escribirá en el archivo keyrec como:

new_ksklength        2048

Todos los registros de zona en el archivo keyrec especificado serán modificados, a menos que se proporcione la opción -zone. En ese caso, solo se modificará la zona nombrada.

Si un archivo keyrec de zona ya contiene un nuevo campo clave/valor, su valor se modificará en ejecuciones posteriores de keymod.

OPCIONES

keymod reconoce las siguientes opciones. Se pueden combinar varias opciones en una única ejecución de keymod.

Todos los valores numéricos deben ser positivos o cero.

Si se debe eliminar un nuevo campo clave/valor de un archivo keyrec de zona, se debe especificar un valor cero o una cadena vacía para la opción correspondiente.

-zone zonename
El archivo keyrec de la zona cuyo nombre coincide con zonename se selecciona como el único keyrec que será modificado. Si no se proporciona este nombre, se modificarán todos los registros keyrec de zona.
-ksklength ksklength
El campo ksklength se modificará en los registros keyrec seleccionados al valor dado. Este es un campo numérico cuyos valores dependen del algoritmo criptográfico a utilizar para generar claves para la zona.
-kskcount kskcount
El campo kskcount se modificará en los registros keyrec seleccionados al valor dado. Este es un campo numérico.
-ksklife ksklife
El campo ksklife se modificará en los registros keyrec seleccionados al valor dado. Este es un campo numérico.
-random random
El campo random se modificará en los registros keyrec seleccionados al valor dado. Este es un campo de texto que se pasará al generador de claves.
-revperiod revperiod
El campo revperiod se modificará en los registros keyrec seleccionados al valor dado. Este es un campo numérico.
-zskcount zskcount
El campo zskcount se modificará en los registros keyrec seleccionados al valor dado. Este es un campo numérico.
-zsklength zsklength
El campo zsklength se modificará en los registros keyrec seleccionados al valor dado. Este es un campo numérico cuyos valores dependen del algoritmo criptográfico a utilizar para generar claves para la zona.
-zsklife zsklife
El campo zsklife se modificará en los registros keyrec seleccionados al valor dado. Este es un campo numérico.
-nocheck
Si se proporciona esta opción, el comando krfcheck no se ejecutará en el archivo keyrec modificado.
-verbose
Muestra información sobre cada modificación realizada en el archivo keyrec.
-Version
Muestra la información de la versión de keymod y del paquete DNSSEC-Tools.
-help
Muestra un mensaje de uso.
