Nombre

kitten-@-set-background-opacity - Establecer la opacidad del fondo

Uso

kitten @ set-background-opacity OPACITY

Descripción

Establece la opacidad del fondo para las ventanas especificadas. Esto solo funcionará si has activado dynamic_background_opacity en kitty.conf. La opacidad del fondo afecta a todas las ventanas de kitty en una sola ventana del sistema operativo. Por ejemplo::


kitten @ set-background-opacity 0.5

Opciones

--all, -a [=no]
Por defecto, la opacidad del fondo solo se cambia para la ventana del sistema operativo actualmente activa. Esta opción hará que la opacidad del fondo se cambie en todas las ventanas.
--toggle [=no]
Cuando se especifica, la opacidad del fondo de las ventanas del sistema operativo coincidentes se restablecerá al valor predeterminado si actualmente es igual al valor especificado; de lo contrario, se establecerá en el valor especificado.
--match, -m
La ventana a emparejar. Las especificaciones de coincidencia tienen la forma: campo:consulta. Donde campo puede ser uno de: id, title, pid, cwd, cmdline, num, env, var, state, neighbor, session y recent. consulta es la expresión a emparejar. Las expresiones pueden ser un número o una expresión regular, y se pueden combinar usando operadores booleanos.

El valor especial all empareja todas las ventanas.

Para campos numéricos: id, pid, num y recent, la expresión se interpreta como un número, no como una expresión regular. Los valores negativos para id coinciden desde el número de id más alto hacia abajo; en particular, -1 es la ventana creada más recientemente.

El campo num se refiere a la posición de la ventana en la pestaña actual, empezando desde cero y contando en sentido horario (esto es lo mismo que el orden en el que las ventanas son reportadas por el comando kitten @ ls).

El id de la ventana de la ventana actual está disponible como la variable de entorno KITTY_WINDOW_ID.

El campo recent se refiere a las ventanas activas recientemente en la pestaña actualmente activa, siendo cero la ventana actualmente activa, uno la ventana previamente activa, y así sucesivamente.

El campo neighbor se refiere a un vecino de la ventana activa en la dirección especificada, que puede ser: left, right, top o bottom.

El campo session empareja ventanas que fueron creadas en la sesión especificada. Usa la expresión ^$ para emparejar ventanas que no fueron creadas en una sesión y . para emparejar la sesión actualmente activa y ~ para emparejar tanto la sesión actualmente activa como la última sesión activa cuando no hay ninguna sesión activa.

Cuando uses el campo env para emparejar variables de entorno, puedes especificar solo el nombre de la variable de entorno o un nombre y un valor, por ejemplo, env:MY_ENV_VAR=2.

De manera similar, el campo var empareja variables de usuario establecidas en la ventana. Puedes especificar nombre o nombre y valor como con el campo env.

El campo state empareja el estado de la ventana. Los estados soportados son: active, focused, needs_attention, parent_active, parent_focused, focused_os_window, self, overlay_parent. Las ventanas activas son las que están activas en su pestaña principal. Solo hay una ventana enfocada y es la ventana a la que se entregan los eventos de teclado. Si ninguna ventana está enfocada, se empareja la última ventana enfocada. El valor focused_os_window empareja todas las ventanas en la ventana del sistema operativo actualmente enfocada. El valor self empareja la ventana en la que se ejecuta el comando de control remoto. El valor overlay_parent empareja la ventana que está debajo de la ventana self, cuando la ventana self es una superposición.

Ten en cuenta que puedes usar el comando kitten @ ls para obtener una lista de ventanas.

--match-tab, -t
La pestaña a emparejar. Las especificaciones de coincidencia tienen la forma: campo:consulta. Donde campo puede ser uno de: id, index, title, window_id, window_title, pid, cwd, cmdline env, var, state, session y recent. consulta es la expresión a emparejar. Las expresiones pueden ser un número o una expresión regular, y se pueden combinar usando operadores booleanos.

El valor especial all empareja todas las pestañas.

Para campos numéricos: id, index, window_id, pid y recent, la expresión se interpreta como un número, no como una expresión regular. Los valores negativos para id/window_id coinciden desde el número de id más alto hacia abajo; en particular, -1 es la pestaña/ventana creada más recientemente.

Cuando uses title o id, primero se busca una pestaña que coincida, y si no se encuentra, se busca una ventana que coincida, y se usa la pestaña de esa ventana.

También puedes usar window_id y window_title para emparejar la pestaña que contiene la ventana con el id o título especificado.

El número de índice se usa para emparejar la n-ésima pestaña en la ventana del sistema operativo actualmente activa. El número recent empareja pestañas activas recientemente en la ventana del sistema operativo actualmente activa, siendo cero la pestaña actualmente activa, uno la pestaña previamente activa, y así sucesivamente.

El campo session empareja pestañas que fueron creadas en la sesión especificada. Usa la expresión ^$ para emparejar ventanas que no fueron creadas en una sesión y . para emparejar la sesión actualmente activa y ~ para emparejar tanto la sesión actualmente activa como la última sesión activa cuando no hay ninguna sesión activa.

Cuando uses el campo env para emparejar variables de entorno, puedes especificar solo el nombre de la variable de entorno o un nombre y un valor, por ejemplo, env:MY_ENV_VAR=2. Se emparejan las pestañas que contengan cualquier ventana con las variables de entorno especificadas. De manera similar, var empareja pestañas que contengan cualquier ventana con la variable de usuario especificada.

El campo state empareja el estado de la pestaña. Los estados soportados son: active, focused, needs_attention, parent_active, parent_focused y focused_os_window. Las pestañas activas son las que están activas en su ventana principal del sistema operativo. Solo hay una pestaña enfocada y es la pestaña a la que se entregan los eventos de teclado. Si ninguna pestaña está enfocada, se empareja la última pestaña enfocada. El valor focused_os_window empareja todas las pestañas en la ventana del sistema operativo actualmente enfocada.

Ten en cuenta que puedes usar el comando kitten @ ls para obtener una lista de pestañas.

Opciones globales

--to
Una dirección para la instancia de kitty a controlar. Corresponde a la dirección dada a la instancia de kitty a través de la opción --listen-on o la configuración listen_on en kitty.conf. Si no se especifica, se comprueba la variable de entorno KITTY_LISTEN_ON. Si tampoco se encuentra, los mensajes se envían al terminal de control de este proceso, es decir, solo funcionarán si este proceso se ejecuta dentro de una ventana de kitty.
--password
Una contraseña a usar al contactar con kitty. Esto hará que kitty le pida al usuario permiso para realizar la acción especificada, a menos que la contraseña haya sido aceptada previamente o esté preconfigurada en kitty.conf. Para usar una contraseña en blanco especifica --use-password como always.
--password-file [=rc-pass]
Un archivo del cual leer la contraseña. El espacio en blanco final se ignora. Las rutas relativas se resuelven desde el directorio de configuración de kitty. Usa - para leer desde STDIN. Usa fd:num para leer desde el descriptor de archivo num. Se usa si no se proporciona --password. Por defecto, comprueba el archivo rc-pass en el directorio de configuración de kitty.
--password-env [=KITTY_RC_PASSWORD]
El nombre de una variable de entorno de la que leer la contraseña. Se usa si no se proporciona --password-file. Por defecto, comprueba la variable de entorno KITTY_RC_PASSWORD.
--use-password [=if-available]

Name

kitten - set-background-opacity

Usage

kitten [options] set-background-opacity opacity

Description

Set the background opacity for the specified windows. The opacity is specified as a float between 0.0 and 1.0. A value of 1.0 means fully opaque, while a value of 0.0 means fully transparent.

If no windows are specified, the background opacity of all windows is changed.

Options

--password=PASSWORD

Use PASSWORD to authenticate with the kitten server. If this option is not specified, the password is read from the KITTY_PASSWORD environment variable. If neither is specified, then the blank password is used.

The following values are supported for the password option:

if-available

If a password is required, use it. Otherwise, proceed without a password.

always

Always use the supplied password. If no password is provided, the blank password is used.

never

Never use a password. If the server requires one, the command will fail.

Global options

See kitten(1) for global options.

The password option can be used to force it to always or never use the supplied password. If set to always and no password is provided, the blank password is used.

Choices: if-available, always, never
