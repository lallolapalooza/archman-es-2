KBUILDSYCOCA6(8) KDE Frameworks: KService KBUILDSYCOCA6(8)

NOMBRE

kbuildsycoca6 - Reconstruye la caché de configuración de archivos de escritorio de KService

SINOPSIS

kbuildsycoca6 [OPCIONES...]

DESCRIPCIÓN

kbuildsycoca6 construye una caché binaria de los datos almacenados en archivos .desktop y archivos .xml de tipo MIME que el framework KService utiliza para encontrar plugins, aplicaciones y otros servicios.

La librería KService utiliza esta base de datos para proporcionar eficientemente la información que se le solicita.

Normalmente, los usuarios no necesitan ejecutar esta aplicación directamente; KService la ejecutará si es necesario, cuando cambien cualquiera de los archivos cuyos datos están en caché.

OPCIONES

--global

Ignora los archivos establecidos por el usuario (en XDG_DATA_HOME). Actualmente, esto solo se admite en sistemas UNIX®.

--noincremental

En lugar de utilizar la caché existente y actualizar solo la información que ha cambiado o se ha añadido, comienza con una caché vacía. Se ignora si se establece --global.

--menutest

Prueba la generación de la base de datos del menú de aplicaciones. No construye realmente la caché.

--testmode

Utiliza el "modo de prueba" de QStandardPaths para evitar interferir con los datos del usuario. Esto está destinado a ser utilizado con pruebas unitarias.

--track id-menu

Rastrea un ID de menú para depuración.

--author

Muestra información del autor.

--license

Muestra información de licencia.

-h, --help

Muestra un breve texto de ayuda.

-v , --version

Muestra información de la versión.

ARCHIVOS

cachedir/ksycoca6_[lang]_[sha1-de-directorios]

La caché de KService generada por kbuildsycoca6. En sistemas UNIX®, cachedir es típicamente XDG_CACHE_HOME.
