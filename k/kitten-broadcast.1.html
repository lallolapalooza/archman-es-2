Nombre

kitten-broadcast - Difundir texto escrito a ventanas de kitty

Descripción general

Escribir texto simultáneamente en todas las ventanas de kitty

El kitten broadcast se puede usar para escribir texto simultáneamente en todas las ventanas de kitty <#ventana-terminal> (o un subconjunto según se desee).

Para usarlo, simplemente cree un mapeo en kitty.conf, como:

map f1 launch --allow-remote-control kitty +kitten broadcast

Luego presione la tecla F1 y lo que escriba en la ventana recién creada se enviará a todas las ventanas de kitty.

Puede usar las opciones descritas a continuación para controlar qué ventanas se seleccionan.

Por ejemplo, solo transmitir a otras ventanas en la pestaña actual:

map f1 launch --allow-remote-control kitty +kitten broadcast --match-tab state:focused

Código fuente de broadcast

El código fuente de este kitten está disponible en GitHub https://github.com/kovidgoyal/kitty/tree/master/kittens/broadcast.

Interfaz de línea de comandos

kitty +kitten broadcast [opciones] [texto inicial a enviar ...]

Difundir texto escrito a ventanas de kitty. Por defecto, el texto se envía a todas las ventanas, a menos que se especifique alguna de las opciones de coincidencia.

Opciones

--hide-input-toggle <TOGGLE_OCULTAR_ENTRADA>
Tecla a presionar que alternará la ocultación de la entrada en la propia ventana de difusión. Útil al escribir una contraseña, evita que la contraseña sea visible en la pantalla. Valor predeterminado: Ctrl+Alt+Esc
--end-session <FIN_SESIÓN>
Tecla a presionar para finalizar la sesión de difusión. Valor predeterminado: Ctrl+Esc
--match <COINCIDIR>, -m <COINCIDIR>
La ventana a hacer coincidir. Las especificaciones de coincidencia son del tipo: campo:consulta. Donde campo puede ser uno de: id, título, pid, cwd, cmdline, num, env, var, state, neighbor, session y recent. consulta es la expresión a hacer coincidir. Las expresiones pueden ser un número o una expresión regular, y se pueden combinar utilizando operadores booleanos <#sintaxis-búsqueda>.

El valor especial all coincide con todas las ventanas.

Para campos numéricos: id, pid, num y recent, la expresión se interpreta como un número, no como una expresión regular. Los valores negativos para id coinciden desde el número de id más alto hacia abajo, en particular, -1 es la ventana creada más recientemente.

El campo num se refiere a la posición de la ventana en la pestaña actual, comenzando desde cero y contando en sentido horario (este es el mismo orden en que las ventanas son reportadas por el comando kitten @ ls <#at-ls>).

El id de ventana de la ventana actual está disponible como la variable de entorno KITTY_WINDOW_ID <#variable-entorno-KITTY_WINDOW_ID>.

El campo recent se refiere a las ventanas activas recientemente en la pestaña activa actual, donde cero es la ventana activa actual, uno es la ventana activa anterior y así sucesivamente.

El campo neighbor se refiere a un vecino de la ventana activa en la dirección especificada, que puede ser: left, right, top o bottom.

El campo session coincide con ventanas que fueron creadas en la sesión especificada. Use la expresión ^$ para hacer coincidir ventanas que no fueron creadas en una sesión y . para hacer coincidir la sesión activa actual y ~ para hacer coincidir ya sea la sesión activa actual o la última sesión activa cuando no hay ninguna sesión activa.

Cuando se usa el campo env para hacer coincidir variables de entorno, puede especificar solo el nombre de la variable de entorno o un nombre y valor, por ejemplo, env:MI_VARIABLE_ENTORNO=2.

De manera similar, el campo var coincide con variables de usuario establecidas en la ventana. Puede especificar el nombre o el nombre y el valor como con el campo env.

El campo state coincide con el estado de la ventana. Los estados admitidos son: active, focused, needs_attention, parent_active, parent_focused, focused_os_window, self, overlay_parent. Las ventanas activas son las ventanas que están activas en su pestaña principal. Solo hay una ventana enfocada y es la ventana a la que se entregan los eventos del teclado. Si ninguna ventana está enfocada, se hace coincidir la última ventana enfocada. El valor focused_os_window coincide con todas las ventanas en la ventana del sistema operativo enfocada actualmente. El valor self coincide con la ventana en la que se ejecuta el comando de control remoto. El valor overlay_parent coincide con la ventana que está debajo de la ventana self, cuando la ventana self es una superposición.

Tenga en cuenta que puede usar el comando kitten @ ls <#at-ls> para obtener una lista de ventanas.

--match-tab <COINCIDIR_TAB>, -t <COINCIDIR_TAB>
La pestaña a hacer coincidir. Las especificaciones de coincidencia son del tipo: campo:consulta. Donde campo puede ser uno de: id, index, título, window_id, window_title, pid, cwd, cmdline env, var, state, session y recent. consulta es la expresión a hacer coincidir. Las expresiones pueden ser un número o una expresión regular, y se pueden combinar usando operadores booleanos <#sintaxis-búsqueda>.

El valor especial all coincide con todas las pestañas.

Para campos numéricos: id, index, window_id, pid y recent, la expresión se interpreta como un número, no como una expresión regular. Los valores negativos para id/window_id coinciden desde el número de id más alto hacia abajo, en particular, -1 es la pestaña/ventana creada más recientemente.

Cuando se usa title o id, primero se busca una pestaña coincidente y, si no se encuentra, se busca una ventana coincidente, y se utiliza la pestaña de esa ventana.

También puede usar window_id y window_title para hacer coincidir la pestaña que contiene la ventana con el id o título especificado.

El número index se usa para hacer coincidir la n-ésima pestaña en la ventana del sistema operativo activa actual. El número recent coincide con las pestañas activas recientemente en la ventana del sistema operativo activa actual, donde cero es la pestaña activa actual, uno la pestaña activa anterior y así sucesivamente.

El campo session coincide con pestañas que fueron creadas en la sesión especificada. Use la expresión ^$ para hacer coincidir ventanas que no fueron creadas en una sesión y . para hacer coincidir la sesión activa actual y ~ para hacer coincidir ya sea la sesión activa actual o la última sesión activa cuando no hay ninguna sesión activa.

Cuando se usa el campo env para hacer coincidir variables de entorno, puede especificar solo el nombre de la variable de entorno o un nombre y valor, por ejemplo, env:MI_VARIABLE_ENTORNO=2. Se coinciden las pestañas que contienen cualquier ventana con las variables de entorno especificadas. De manera similar, var coincide con pestañas que contienen cualquier ventana con la variable de usuario especificada.

El campo state coincide con el estado de la pestaña. Los estados admitidos son: active, focused, needs_attention, parent_active, parent_focused y focused_os_window. Las pestañas activas son las pestañas que están activas en su ventana principal del sistema operativo. Solo hay una pestaña enfocada y es la pestaña a la que se entregan los eventos del teclado. Si ninguna pestaña está enfocada, se hace coincidir la última pestaña enfocada. El valor focused_os_window coincide con todas las pestañas en la ventana del sistema operativo enfocada actualmente.

Tenga en cuenta que puede usar el comando kitten @ ls <#at-ls> para obtener una lista de pestañas.
