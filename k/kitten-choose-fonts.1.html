Nombre

kitten-choose-fonts - Documentación de kitten

Resumen

Los aficionados a las terminales pasan todo el día mirando texto, por lo tanto, conseguir que la renderización del texto sea perfecta es muy importante. kitty tiene instalaciones extremadamente potentes para ajustar finamente la renderización del texto. Admite características de OpenType https://en.wikipedia.org/wiki/List_of_typographic_features para seleccionar formas de glifos alternativos, y fuentes variables https://en.wikipedia.org/wiki/Variable_font para controlar el grosor o el espaciado de una fuente con precisión. También puede seleccionar qué fuente se usa para renderizar puntos de código unicode específicos <#opt-kitty.symbol_map> y puede modificar las métricas de la fuente <#opt-kitty.modify_font> e incluso ajustar las curvas gamma <#opt-kitty.text_composition_strategy> utilizadas para renderizar texto sobre el color de fondo.

El primer paso es seleccionar las caras de fuente que kitty utilizará para renderizar texto normal, en negrita e itálica. kitty viene con una interfaz de usuario conveniente para elegir fuentes, en forma del kitten choose-fonts. Simplemente ejecute:

kitten choose-fonts

y siga las indicaciones en pantalla.

Primero, elija la familia que desea, la lista de familias se puede filtrar fácilmente escribiendo unas pocas letras del nombre de la familia que está buscando. La pantalla de selección de familia le muestra una vista previa de cómo se ve la familia.

Una vez que seleccione una familia presionando la tecla Enter, se le mostrarán vistas previas de cómo se ven las caras normal, en negrita y en itálica para esa familia. Puede optar por ajustar finamente cualquiera de las caras. Comience ajustando finamente la cara normal presionando la tecla R. Los otros estilos se ajustarán automáticamente según lo que seleccione para la cara normal.

Puede elegir un estilo o característica de fuente específica haciendo clic en ella. Se puede seleccionar un valor preciso para cualquier eje variable utilizando el deslizador; en la captura de pantalla anterior, la fuente admite el ajuste preciso del grosor. Si tiene suerte, el diseñador de fuentes ha incluido nombres descriptivos para las características de fuente, que se mostrarán; de lo contrario, consulte la documentación de la fuente para ver qué hace cada característica.

La sintaxis de especificación de fuentes

Si no le gusta el kitten choose-fonts o simplemente quiere entender y escribir opciones de selección de fuentes en kitty.conf usted mismo, siga leyendo.

Hay cuatro claves de selección de cara de fuente: font_family, bold_font, italic_font y bold_italic_font. Cada una de estas admite la sintaxis descrita a continuación. Sus valores pueden ser de tres tipos: un nombre de familia de fuentes, la palabra clave auto o una sintaxis extendida de clave=valor para especificar la selección de fuentes con precisión.

Si se especifica un nombre de familia de fuentes, kitty utilizará las APIs del Sistema Operativo para buscar una fuente coincidente. La palabra clave auto significa que kitty elegirá una fuente de forma totalmente automática, lo que se suele usar para seleccionar automáticamente variantes en negrita/itálica una vez que se establece font_family <#opt-kitty.font_family>. Las variantes en negrita e itálica usarán entonces automáticamente el mismo conjunto de características que la cara principal.

Para especificar la selección de cara de fuente con más precisión, se utiliza una sintaxis de clave=valor. Primero, veamos algunos ejemplos:

# Seleccionar solo por familia, la selección real de la cara es automática
font_family family="Fira Code"
# Seleccionar una cara exacta por nombre Postscript
font_family postscript_name=FiraCode
# Seleccionar una cara exacta por familia con características y peso variable
font_family family=SourceCodeVF variable_name=SourceCodeUpright features="+zero cv01=2" wght=380

Las siguientes son las claves conocidas; cualquier otra clave son nombres de ejes variables, es decir, se utilizan para establecer el valor variable para alguna característica de la fuente.

family
Un nombre de familia de fuentes. Una familia típicamente tiene múltiples caras de fuentes reales, como variantes en negrita e itálica. Una o más de las caras pueden ser incluso variables, lo que permite ajustar finamente las características de la fuente.
style
Un nombre de estilo para elegir una fuente particular de una familia dada. Útil solo con la clave family, cuando no se especifican métodos más precisos para la selección de caras. También se puede usar para especificar un estilo variable con nombre para fuentes variables.
postscript_name
El nombre Postscript real de una cara de fuente. Esto permite seleccionar una variante particular dentro de una familia de fuentes. Pero tenga en cuenta que los nombres Postscript suelen ser insuficientes para seleccionar fuentes variables.
full_name
Esto se puede usar para seleccionar una cara de fuente particular en una familia. Sin embargo, es menos preciso que postscript_name y generalmente no debe usarse.
variable_name
Algunas familias con fuentes variables contienen en realidad múltiples archivos de fuentes. Por ejemplo, una familia podría tener pesos variables con un archivo de fuente que contiene caras de peso variable verticales y otro que contiene caras de peso variable en itálica. Las fuentes bien diseñadas usan un nombre de variable para distinguir entre tales archivos. Debe usarse junto con family para seleccionar un archivo de fuente variable particular.
features
Una lista separada por espacios de características de fuentes OpenType para habilitar/deshabilitar o seleccionar un valor, para esta fuente. Consulte la documentación de la familia de fuentes para ver qué características admite y sus efectos. La sintaxis exacta para especificar características está documentada por HarfBuzz https://harfbuzz.github.io/harfbuzz-hb-common.html#hb-feature-from-string
system
Esto se puede usar para pasar una cadena arbitraria, generalmente un nombre de familia o completo, a las APIs de selección de fuentes del SO. No debe usarse junto con ninguna otra clave. Es lo mismo que especificar solo el nombre de la fuente sin ninguna clave.

Además de estas claves, cualquier clave de cuatro letras se trata como el nombre de una característica variable de la fuente. Su valor se utiliza para establecer el valor del nombre.
