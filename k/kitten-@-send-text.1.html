Nombre

kitten-@-send-text - Enviar texto arbitrario a ventanas especificadas

Uso

kitten @ send-text [TEXTO A ENVIAR]

Descripción

Enviar texto arbitrario a ventanas especificadas. El texto sigue las reglas de escape de Python. Por lo tanto, puedes usar escapes como '\e' para enviar códigos de control y '\u21fa' para enviar caracteres Unicode. Recuerda usar comillas simples, de lo contrario la barra invertida se interpreta como carácter de escape de shell. Si usas la opción --match, el texto se enviará a todas las ventanas coincidentes. Por defecto, el texto se envía solo a la ventana actualmente activa. Ten en cuenta que los errores no se informan, por razones técnicas, por lo que send-text siempre tiene éxito, incluso si no se envió texto a ninguna ventana.

Opciones

--match, -m
La ventana a emparejar. Las especificaciones de coincidencia tienen la forma: campo:consulta. Donde campo puede ser uno de: id, title, pid, cwd, cmdline, num, env, var, state, neighbor, session y recent. consulta es la expresión a emparejar. Las expresiones pueden ser un número o una expresión regular, y pueden combinarse usando operadores booleanos.

El valor especial all coincide con todas las ventanas.

Para campos numéricos: id, pid, num y recent, la expresión se interpreta como un número, no como una expresión regular. Valores negativos para id coinciden desde el número de id más alto hacia abajo, en particular, -1 es la ventana creada más recientemente.

El campo num se refiere a la posición de la ventana en la pestaña actual, empezando desde cero y contando en sentido horario (esto es lo mismo que el orden en que las ventanas son reportadas por el comando kitten @ ls).

El id de la ventana de la ventana actual está disponible como la variable de entorno KITTY_WINDOW_ID.

El campo recent se refiere a ventanas activas recientemente en la pestaña actualmente activa, con cero siendo la ventana actualmente activa, uno siendo la ventana previamente activa y así sucesivamente.

El campo neighbor se refiere a un vecino de la ventana activa en la dirección especificada, que puede ser: left, right, top o bottom.

El campo session coincide con ventanas que fueron creadas en la sesión especificada. Usa la expresión ^$ para coincidir con ventanas que no fueron creadas en una sesión y . para coincidir con la sesión actualmente activa y ~ para coincidir con la sesión actualmente activa o la última sesión activa cuando no hay sesión activa.

Al usar el campo env para coincidir con variables de entorno, puedes especificar solo el nombre de la variable de entorno o un nombre y valor, por ejemplo, env:MY_ENV_VAR=2.

De manera similar, el campo var coincide con variables de usuario establecidas en la ventana. Puedes especificar nombre o nombre y valor como con el campo env.

El campo state coincide con el estado de la ventana. Los estados soportados son: active, focused, needs_attention, parent_active, parent_focused, focused_os_window, self, overlay_parent. Las ventanas activas son las ventanas que están activas en su pestaña padre. Solo hay una ventana enfocada y es la ventana a la que se entregan los eventos de teclado. Si ninguna ventana está enfocada, se coincide con la última ventana enfocada. El valor focused_os_window coincide con todas las ventanas en la ventana del sistema operativo actualmente enfocada. El valor self coincide con la ventana en la que se ejecuta el comando de control remoto. El valor overlay_parent coincide con la ventana que está debajo de la ventana self, cuando la ventana self es un overlay.

Ten en cuenta que puedes usar el comando kitten @ ls para obtener una lista de ventanas.

--match-tab, -t
La pestaña a emparejar. Las especificaciones de coincidencia tienen la forma: campo:consulta. Donde campo puede ser uno de: id, index, title, window_id, window_title, pid, cwd, cmdline env, var, state, session y recent. consulta es la expresión a emparejar. Las expresiones pueden ser un número o una expresión regular, y pueden combinarse usando operadores booleanos.

El valor especial all coincide con todas las pestañas.

Para campos numéricos: id, index, window_id, pid y recent, la expresión se interpreta como un número, no como una expresión regular. Valores negativos para id/window_id coinciden desde el número de id más alto hacia abajo, en particular, -1 es la pestaña/ventana creada más recientemente.

Al usar title o id, primero se busca una pestaña coincidente, y si no se encuentra, se busca una ventana coincidente, y se usa la pestaña de esa ventana.

También puedes usar window_id y window_title para coincidir con la pestaña que contiene la ventana con el id o título especificado.

El número de índice se usa para coincidir con la n-ésima pestaña en la ventana del sistema operativo actualmente activa. El número recent coincide con pestañas activas recientemente en la ventana del sistema operativo actualmente activa, con cero siendo la pestaña actualmente activa, uno la pestaña previamente activa y así sucesivamente.

El campo session coincide con pestañas que fueron creadas en la sesión especificada. Usa la expresión ^$ para coincidir con ventanas que no fueron creadas en una sesión y . para coincidir con la sesión actualmente activa y ~ para coincidir con la sesión actualmente activa o la última sesión activa cuando no hay sesión activa.

Al usar el campo env para coincidir con variables de entorno, puedes especificar solo el nombre de la variable de entorno o un nombre y valor, por ejemplo, env:MY_ENV_VAR=2. Se coinciden pestañas que contengan cualquier ventana con las variables de entorno especificadas. De manera similar, var coincide con pestañas que contengan cualquier ventana con la variable de usuario especificada.

El campo state coincide con el estado de la pestaña. Los estados soportados son: active, focused, needs_attention, parent_active, parent_focused y focused_os_window. Las pestañas activas son las pestañas que están activas en su ventana del sistema operativo padre. Solo hay una pestaña enfocada y es la pestaña a la que se entregan los eventos de teclado. Si ninguna pestaña está enfocada, se coincide con la última pestaña enfocada. El valor focused_os_window coincide con todas las pestañas en la ventana del sistema operativo actualmente enfocada.

Ten en cuenta que puedes usar el comando kitten @ ls para obtener una lista de pestañas.

--all [=no]
Coincide con todas las ventanas.
--exclude-active [=no]
No enviar texto a la ventana activa, incluso si es una de las ventanas coincidentes.
--stdin [=no]
Leer el texto a enviar desde stdin. Ten en cuenta que en este caso el texto se envía tal cual, no se interpreta para escapes. Si stdin es una terminal, puedes presionar Ctrl+D para terminar la lectura.
--from-file
Ruta a un archivo cuyo contenido deseas enviar. Ten en cuenta que en este caso el contenido del archivo se envía tal cual, no se interpreta para escapes.
--bracketed-paste [=disable]
Al enviar texto a una ventana, envolver el texto en códigos de escape de pegado con corchetes (bracketed paste). Por defecto no se hace esto. Un valor de auto significa que el pegado con corchetes se usará solo si el programa que se ejecuta en la ventana ha activado el modo de pegado con corchetes.

Opciones: disable, auto, enable

--help, -h [=no]
Mostrar ayuda para este comando

Opciones globales

--to
Una dirección para la instancia de kitty a controlar. Corresponde a la dirección dada a la instancia de kitty a través de la opción --listen-on o la configuración listen_on en kitty.conf. Si no se especifica, se verifica la variable de entorno KITTY_LISTEN_ON. Si tampoco se encuentra, los mensajes se envían al terminal que controla este proceso, es decir, solo funcionarán si este proceso se ejecuta dentro de una ventana de kitty.
--password
Una contraseña a usar al contactar a kitty. Esto hará que kitty le pida al usuario permiso para realizar la acción especificada, a menos que la contraseña haya sido aceptada antes o esté preconfigurada en kitty.conf. Para usar una contraseña en blanco especifica --use-password como always.
--password-file [=rc-pass]
Un archivo desde el cual leer la contraseña. Se ignora el espacio en blanco final. Las rutas relativas se resuelven desde el directorio de configuración de kitty. Usa - para leer desde STDIN. Usa fd:num para leer desde el descriptor de archivo num. Se usa si no se proporciona --password. Por defecto, se comprueba la existencia del archivo rc-pass en el directorio de configuración de
kitty.

D]
El nombre de una variable de entorno desde la cual leer la contraseña. Se usa si no se proporciona --password-file. Por defecto, se comprueba la variable de entorno KITTY_RC_PASSWO

e]
Si no hay ninguna contraseña disponible, kitty normalmente enviará el comando de control remoto sin contraseña. Esta opción se puede usar para forzar que siempre o nunca use la contraseña proporcionada. Si se establece en always y no se proporciona ninguna contraseña, se usará la contraseña en blanco.
