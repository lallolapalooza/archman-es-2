Nombre

kitten-@-get-text - Obtener texto de la ventana especificada

Uso

kitten @ get-text

Descripción

Obtener texto de la ventana especificada

Opciones

--match, -m
La ventana a emparejar. Las especificaciones de coincidencia tienen la forma: campo:consulta. Donde campo puede ser uno de: id, title, pid, cwd, cmdline, num, env, var, state, neighbor, session y recent. consulta es la expresión a emparejar. Las expresiones pueden ser un número o una expresión regular, y pueden combinarse usando operadores booleanos.

El valor especial all empareja todas las ventanas.

Para campos numéricos: id, pid, num y recent, la expresión se interpreta como un número, no como una expresión regular. Los valores negativos para id emparejan desde el número de id más alto hacia abajo, en particular, -1 es la ventana creada más recientemente.

El campo num se refiere a la posición de la ventana en la pestaña actual, empezando desde cero y contando en sentido horario (esto es lo mismo que el orden en que las ventanas son reportadas por el comando kitten @ ls).

El id de la ventana de la ventana actual está disponible como la variable de entorno KITTY_WINDOW_ID.

El campo recent se refiere a las ventanas activas recientemente en la pestaña activa actualmente, con cero siendo la ventana activa actualmente, uno siendo la ventana activa anterior y así sucesivamente.

El campo neighbor se refiere a un vecino de la ventana activa en la dirección especificada, que puede ser: left, right, top o bottom.

El campo session empareja ventanas que fueron creadas en la sesión especificada. Usa la expresión ^$ para emparejar ventanas que no fueron creadas en una sesión y . para emparejar la sesión activa actualmente y ~ para emparejar la sesión activa actualmente o la última sesión activa cuando no hay ninguna sesión activa.

Cuando uses el campo env para emparejar variables de entorno, puedes especificar solo el nombre de la variable de entorno o un nombre y valor, por ejemplo, env:MY_ENV_VAR=2.

De manera similar, el campo var empareja variables de usuario establecidas en la ventana. Puedes especificar nombre o nombre y valor como con el campo env.

El campo state empareja el estado de la ventana. Los estados soportados son: active, focused, needs_attention, parent_active, parent_focused, focused_os_window, self, overlay_parent. Las ventanas activas son las ventanas que están activas en su pestaña padre. Solo hay una ventana enfocada y es la ventana a la que se entregan los eventos de teclado. Si ninguna ventana está enfocada, se empareja la última ventana enfocada. El valor focused_os_window empareja todas las ventanas en la ventana del SO actualmente enfocada. El valor self empareja la ventana en la que se ejecuta el comando de control remoto. El valor overlay_parent empareja la ventana que está debajo de la ventana self, cuando la ventana self es una superposición.

Ten en cuenta que puedes usar el comando kitten @ ls para obtener una lista de ventanas.

--extent [=screen]
Qué texto obtener. El valor predeterminado screen significa todo el texto actualmente en la pantalla. all significa todo el screen+scrollback y selection significa el texto actualmente seleccionado. first_cmd_output_on_screen significa la salida de el primer comando que se ejecutó en la ventana en pantalla. last_cmd_output significa la salida del último comando que se ejecutó en la ventana. last_visited_cmd_output significa la salida del primer comando debajo de la última posición desplazada vía scroll_to_prompt. last_non_empty_output es la salida del último comando ejecutado en la ventana que tuvo alguna salida no vacía. Los últimos cuatro requieren que shell_integration esté habilitado.

Opciones: screen, all, first_cmd_output_on_screen, last_cmd_output, last_non_empty_output, last_visited_cmd_output, selection

--ansi [=no]
Por defecto, solo se devuelve texto plano. Con esta bandera, el texto incluirá los códigos de escape de formato ANSI para colores, negrita, cursiva, etc.
--add-cursor [=no]
Añade códigos de escape ANSI que especifican la posición y estilo del cursor al final del texto.
--add-wrap-markers [=no]
Añade retornos de carro en cada ubicación de salto de línea (donde las líneas largas se envuelven en los bordes de la pantalla).
--clear-selection [=no]
Borra la selección en la ventana emparejada, si la hay.
--self [=no]
Obtener texto de la ventana en la que se ejecuta este comando, en lugar de la ventana activa.
--help, -h [=no]
Mostrar ayuda para este comando

Opciones globales

--to
Una dirección para la instancia de kitty a controlar. Corresponde a la dirección dada a la instancia de kitty vía la opción --listen-on o la configuración listen_on en kitty.conf. Si no se especifica, se verifica la variable de entorno KITTY_LISTEN_ON. Si tampoco se encuentra, los mensajes se envían a la terminal de control para este proceso, es decir, solo funcionarán si este proceso se ejecuta dentro de una ventana de kitty.
--password
Una contraseña a usar al contactar a kitty. Esto hará que kitty le pida al usuario permiso para realizar la acción especificada, a menos que la contraseña haya sido aceptada antes o esté preconfigurada en kitty.conf. Para usar una contraseña en blanco especifica --use-password como always.
--password-file [=rc-pass]
Un archivo del cual leer la contraseña. El espacio en blanco final se ignora. Las rutas relativas se resuelven desde el directorio de configuración de kitty. Usa - para leer desde STDIN. Usa fd:num para leer desde el descriptor de archivo num. Se usa si no se proporciona --password. Por defecto, se verifica el archivo rc-pass en el directorio de configuración de kitty.
--password-env [=KITTY_RC_PASSWORD]
El nombre de una variable de entorno de la cual leer la contraseña. Se usa si no se proporciona --password-file. Por defecto, se verifica la variable de entorno KITTY_RC_PASSWORD.
--use-password [=if-available]
Si no hay una contraseña disponible, kitty normalmente solo enviará el comando de control remoto sin contraseña. Esta opción se puede usar para forzar a kitty a usar o no usar siempre la contraseña proporcionada. Si se establece en always y no se proporciona una contraseña, se usa la contraseña en blanco.

Opciones: if-available, always, never
