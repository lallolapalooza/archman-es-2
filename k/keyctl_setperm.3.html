keyctl_setperm(3)

Paquete: keyutils

Licencias: GPL2, LGPL2.1

KEYCTL_SETPERM(3) Llamadas de gestión de claves de Linux KEYCTL_SETPERM(3)

NOMBRE

keyctl_setperm - cambiar la máscara de permisos de una clave

SINOPSIS

#include <keyutils.h>

long keyctl_setperm(key_serial_t key, key_perm_t perm);

DESCRIPCIÓN

keyctl_setperm() cambia la máscara de permisos de una clave.

Un proceso que no tenga la capacidad SysAdmin no podrá cambiar la máscara de permisos de una clave que no tenga el mismo UID que el llamante.

El llamante debe tener permiso setattr sobre una clave para poder cambiar su máscara de permisos.

La máscara de permisos es un OR a nivel de bits de las siguientes banderas:

KEY_xxx_VIEW
Otorga permiso para ver los atributos de una clave.
KEY_xxx_READ
Otorga permiso para leer la carga útil de una clave o para listar un keyring.
KEY_xxx_WRITE
Otorga permiso para modificar la carga útil de una clave o para añadir o eliminar enlaces de/hacia un keyring.
KEY_xxx_SEARCH
Otorga permiso para encontrar una clave o para buscar en un keyring.
KEY_xxx_LINK
Otorga permiso para crear enlaces a una clave.
KEY_xxx_SETATTR
Otorga permiso para cambiar la propiedad y los atributos de permisos de una clave.
KEY_xxx_ALL
Otorga todos los anteriores.

El 'xxx' en lo anterior debe ser reemplazado por uno de:

POS
Otorga el permiso a un proceso que posee la clave (la tiene adjunta de forma buscable a uno de los keyrings del proceso).
USR
Otorga el permiso a un proceso con el mismo UID que la clave.
GRP
Otorga el permiso a un proceso con el mismo GID que la clave, o con una coincidencia para el GID de la clave entre la lista de Grupos de ese proceso.
OTH
Otorga el permiso a cualquier otro proceso.

Ejemplos incluyen: KEY_POS_VIEW, KEY_USR_READ, KEY_GRP_SEARCH y KEY_OTH_ALL.

Las concesiones de usuario, grupo y otros son exclusivas: si un proceso califica en la categoría de 'usuario', no calificará en la categoría de 'grupos'; y si un proceso califica en 'usuario' o 'grupos', entonces no calificará en la categoría 'otro'.

Las concesiones de poseedor son acumulativas con las concesiones de las categorías 'usuario', 'grupos' y 'otro'.

VALOR DE RETORNO

En caso de éxito, keyctl_setperm() devuelve 0. En caso de error, se devolverá el valor -1 y errno se habrá establecido en un error apropiado.

ERRORES

ENOKEY
La clave especificada no existe.
EKEYEXPIRED
La clave especificada ha expirado.
EKEYREVOKED
La clave especificada ha sido revocada.
EACCES
La clave nombrada existe, pero no otorga permiso setattr al proceso llamante.

ENLAZADO

Esta es una función de biblioteca que se puede encontrar en libkeyutils. Al enlazar, se debe especificar -lkeyutils al enlazador.
