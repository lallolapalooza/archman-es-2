KEEPASSXC(1) Manual de comandos generales KEEPASSXC(1)

NOMBRE

keepassxc - un gestor de contraseñas moderno de código abierto

SINOPSIS

keepassxc [opciones] [nombre(s) de archivo]

DESCRIPCIÓN

KeePassXC es un gestor o caja fuerte de contraseñas libre y de código abierto que le ayuda a gestionar sus contraseñas de forma segura. La base de datos completa está siempre cifrada con el algoritmo de cifrado AES (alias Rijndael) estándar de la industria, utilizando una clave de 256 bits. KeePassXC utiliza un formato de base de datos compatible con KeePass Password Safe. Su billetera funciona sin conexión y no requiere conexión a Internet.

OPCIONES

-h, --help

Muestra esta ayuda.

-v, --version

Muestra información de la versión.

--config <config>

Ruta a un archivo de configuración personalizado.

--keyfile <archivo de clave>

Archivo de clave de la base de datos.

--pw-stdin

Lee la contraseña de la base de datos desde stdin.

--minimized

Inicia KeePassXC minimizado en la bandeja del sistema.

--debug-info

Muestra información de depuración.
