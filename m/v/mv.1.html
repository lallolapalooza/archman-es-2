MV(1) Comandos de usuario MV(1)

NOMBRE

mv - mover (renombrar) archivos

SINOPSIS

mv [OPCIÓN]... [-T] FUENTE DESTINO
mv [OPCIÓN]... FUENTE... DIRECTORIO
mv [OPCIÓN]... -t DIRECTORIO FUENTE...

DESCRIPCIÓN

Renombra FUENTE a DESTINO, o mueve FUENTE(s) a DIRECTORIO.

Los argumentos obligatorios para las opciones largas también son obligatorios para las opciones cortas.

--backup[=CONTROL]
crear una copia de seguridad de cada archivo de destino existente
-b
igual que --backup pero no acepta un argumento
--debug
explicar cómo se copia un archivo. Implica -v
--exchange
intercambiar fuente y destino
-f, --force
no preguntar antes de sobrescribir
-i, --interactive
preguntar antes de sobrescribir
-n, --no-clobber
no sobrescribir un archivo existente

Si especifica más de uno de -i, -f, -n, solo el último tendrá efecto.

--no-copy
no copiar si el renombrado falla
--strip-trailing-slashes
eliminar las barras finales de cada argumento FUENTE
-S, --suffix=SUFIJO
sobrescribir el sufijo de copia de seguridad habitual
-t, --target-directory=DIRECTORIO
mover todos los argumentos FUENTE a DIRECTORIO
-T, --no-target-directory
tratar DESTINO como un archivo normal
--update[=ACTUALIZAR]
controlar qué archivos existentes se actualizan; ACTUALIZAR={all,none,none-fail,older(predeterminado)}
-u
equivalente a --update[=older]. Ver abajo
-v, --verbose
explicar lo que se está haciendo
-Z, --context
establecer el contexto de seguridad SELinux del archivo de destino al tipo predeterminado
--help
mostrar esta ayuda y salir
--version
mostrar información de versión y salir

ACTUALIZAR controla qué archivos existentes en el destino se reemplazan. 'all' es la operación predeterminada cuando no se especifica la opción --update, y resulta en el reemplazo de todos los archivos existentes en el destino. 'none' es como la opción --no-clobber, en el sentido de que no se reemplaza ningún archivo en el destino, y los archivos omitidos no provocan un error. 'none-fail' también asegura que no se reemplacen archivos en el destino, pero cualquier archivo omitido se diagnostica y provoca un error. 'older' es la operación predeterminada cuando se especifica --update, y resulta en el reemplazo de archivos si son más antiguos que el archivo fuente correspondiente.

El sufijo de copia de seguridad es '~', a menos que se establezca con --suffix o SIMPLE_BACKUP_SUFFIX. El método de control de versiones puede seleccionarse a través de la opción --backup o a través de la variable de entorno VERSION_CONTROL. Aquí están los valores:

ninguno, off
nunca hacer copias de seguridad (incluso si se proporciona --backup)
numerado, t
hacer copias de seguridad numeradas
existente, nil
numerado si existen copias de seguridad numeradas, simple en caso contrario
simple, never
siempre hacer copias de seguridad simples
