mlx5dv_query_port(3) Manual de Funciones de Biblioteca mlx5dv_query_port(3)

NOMBRE

mlx5dv_query_port - Consulta atributos no estándar del puerto del dispositivo IB.

SINOPSIS

#include <infiniband/mlx5dv.h>
int mlx5dv_query_port(struct ibv_context *context,
              uint32_t port_num,
              struct mlx5dv_port *info);

DESCRIPCIÓN

Consulta información del puerto que puede usarse para algunos comandos del dispositivo a través de la interfaz DEVX y al acceder directamente a los recursos de hardware.

Una función que permite a un usuario consultar atributos de hardware y configuración asociados con el puerto.

USO

Un usuario debe proporcionar el número de puerto a consultar. En una consulta exitosa, *flags* almacenará un subconjunto de los atributos solicitados que son compatibles/relevantes para ese puerto.

ARGUMENTOS

context
Contexto del dispositivo RDMA sobre el cual trabajar.
port_num
Número de puerto a consultar.
## info
Almacena los atributos devueltos por el kernel.
struct mlx5dv_port {
    uint64_t flags;
    uint16_t vport;
    uint16_t vport_vhca_id;
    uint16_t esw_owner_vhca_id;
    uint16_t rsvd0;
    uint64_t vport_steering_icm_rx;
    uint64_t vport_steering_icm_tx;
    struct mlx5dv_reg reg_c0;
};
flags
Campo de bits de atributos, en una consulta exitosa *flags* almacena los atributos válidos llenos.

MLX5DV_QUERY_PORT_VPORT: El número vport de ese puerto.

MLX5DV_QUERY_PORT_VPORT_VHCA_ID: El ID de VHCA de *vport_num*.

MLX5DV_QUERY_PORT_ESW_OWNER_VHCA_ID: El propietario E-Switch de *vport_num*.

MLX5DV_QUERY_PORT_VPORT_STEERING_ICM_RX: La dirección ICM RX al dirigir tráfico.

MLX5DV_QUERY_PORT_VPORT_STEERING_ICM_TX: La dirección ICM TX al dirigir tráfico.

MLX5DV_QUERY_PORT_VPORT_REG_C0: El valor del registro C0 utilizado para identificar la salida de *vport_num*.

vport
El número VPORT de ese puerto.
vport_vhca_id
El ID de VHCA de *vport_num*.
rsvd0
Un campo reservado. No debe usarse.
esw_owner_vhca_id
El propietario E-Switch de *vport_num*.
vport_steering_ica_rx
La dirección ICM RX al dirigir tráfico.
vport_steering_icm_tx
La dirección ICM TX al dirigir tráfico.
## reg_c0
El valor del registro C0 utilizado para identificar el tráfico de *vport_num*.
struct mlx5dv_reg {
        uint32_t value;
        uint32_t mask;
};
value
El valor que debe usarse como coincidencia.
mask
La máscara que debe usarse al comparar.

VALOR DEVUELTO

Devuelve 0 si tiene éxito, o el valor de errno en caso de fallo (que indica la razón del fallo).

EJEMPLO

for (i = 1; i <= ports; i++) {
    ret = mlx5dv_query_port(context, i, &port_info);
    if (ret) {
        printf("Error al consultar el puerto %d\n", i);
        break;
    }
    printf("Puerto: %d:\n", i);
    if (port_info.flags & MLX5DV_QUERY_PORT_VPORT)
        printf("\tvport_num: 0x%x\n", port_info.vport_num);
    if (port_info.flags & MLX5DV_QUERY_PORT_VPORT_REG_C0)
        printf("\treg_c0: val: 0x%x mask: 0x%x\n",
                port_info.reg_c0.value,
                port_info.reg_c0.mask);
}
