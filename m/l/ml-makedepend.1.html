NOMBRE

ml-makedepend - generador de dependencias makefile para programas SML/NJ

SINOPSIS

ml-makedepend [OPCIONES] proyecto.cm objetivo

DESCRIPCIÓN

ML-Makedepend es una herramienta para generar información de dependencias que permite usar el programa make(1) de Unix para construir programas SML/NJ.

OPCIONES

-f makefile

Especifica el nombre del archivo makefile al que se añade la información de dependencias. Si esta opción *no* se proporciona, la salida se añade al final del archivo makefile (o Makefile). Es un error si ninguno de los archivos existe y no se especifica la opción -f.

-a arch

especifica el nombre de una variable make para nombres y rutas específicas de la arquitectura (el valor predeterminado es ARCH).

-o os

especifica el nombre de una variable make para nombres y rutas específicas del sistema operativo (el valor predeterminado es OPSYS).

-n

genera nombres y rutas de archivo completos con cualquier parte específica de la arquitectura o del sistema operativo expandida a su definición para el sistema host. Si se especifica esta opción, se ignoran cualquier opción -a y -o.

-Cctl=valor

establece el control ctl a valor.

-Dnombre=valor

define la variable CM nombre para que tenga el valor dado.

-D'nombre

define la variable CM nombre para que tenga el valor 1.

-Unombre

elimina cualquier definición de la variable CM nombre.
