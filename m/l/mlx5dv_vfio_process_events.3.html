NOMBRE

mlx5dv_vfio_process_events - procesar eventos del controlador vfio

SINOPSIS

#include <infiniband/mlx5dv.h>
int mlx5dv_vfio_process_events(struct ibv_context *ctx);

DESCRIPCIÓN

Esta API debe ejecutarse desde el hilo de la aplicación y mantener los eventos del dispositivo. La aplicación es responsable de obtener el FD de eventos llamando a mlx5dv_vfio_get_events_fd() y, una vez que el FD se puede consultar, llamar a la API para que el controlador procese sus eventos internos.

ARGUMENTOS

ctx
contexto del dispositivo que se abrió para VFIO llamando a mlx5dv_get_vfio_device_list().

VALOR DE RETORNO

Devuelve 0 si tiene éxito o el valor de errno en caso de que ocurra un fallo.

NOTAS

La aplicación también puede usar esta API para verificar periódicamente el estado de salud del dispositivo, incluso si no hay eventos.

VER TAMBIÉN

ibv_open_device(3) ibv_free_device_list(3) mlx5dv_get_vfio_device_list(3) mlx5dv_vfio_get_events_fd(3)
