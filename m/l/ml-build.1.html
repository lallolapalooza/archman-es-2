NOMBRE

ml-build - herramienta de compilación en línea de comandos para programas SML/NJ

SINOPSIS

ml-build [OPCIONES] grupo.cm [principal [imagen-heap]]

DESCRIPCIÓN

ML-Build es una herramienta de línea de comandos para compilar aplicaciones a partir de archivos fuente SML utilizando el Administrador de Compilación y el compilador SML/NJ.

OPCIONES

-Cctl=valor

establece el control ctl a valor.

-Dnombre=valor

define la variable CM nombre para que tenga el valor dado.

-D'nombre

define la variable CM nombre para que tenga el valor 1.

-Unombre

elimina cualquier definición de la variable CM nombre.

-S setup.cm

carga y ejecuta el código especificado por el archivo CM setup.cm antes del proceso de compilación principal. Esta opción permite personalizar el compilador mediante efectos secundarios.

EJEMPLOS

ml-build foo.cm

compila el programa foo asumiendo una función principal llamada Test.main.

ml-build foo.cm Main.main

compila el programa foo con la función principal llamada Main.main.

ml-build sources.cm Main.main prog

compila el programa prog con la función principal llamada Main.main.
