mlx5dv_mkey_check(3) Manual de funciones de biblioteca mlx5dv_mkey_check(3)

NOMBRE

mlx5dv_mkey_check - Comprobar un MKEY en busca de errores

SINOPSIS

#include <infiniband/mlx5dv.h>
int mlx5dv_mkey_check(struct mlx5dv_mkey *mkey,
              struct mlx5dv_mkey_err *err_info);

DESCRIPCIÓN

Comprueba el mkey en busca de errores y proporciona el resultado en err_info en caso de éxito.

Esto debe llamarse después de usar un MKEY configurado con validación de firma en una operación de transferencia. Aunque la operación de transferencia en sí puede completarse con éxito (es decir, no ocurrieron errores relacionados con el transporte), todavía puede haber errores relacionados con la integridad de los datos. El primero de estos errores se informa al MKEY y se mantiene allí hasta que el software de la aplicación lo consulte llamando a esta API.

El tipo de error indica qué parte de la firma estaba mal (guard, reftag o apptag). También se proporciona el valor calculado real basado en los datos transferidos y el valor esperado basado en los campos de firma. La última parte proporcionada es el desplazamiento en la transferencia que causó el error.

ARGUMENTOS

mkey
El MKEY a comprobar en busca de errores.
err_info
El resultado de la comprobación del MKEY, información sobre los errores detectados, si los hay.
struct mlx5dv_mkey_err {
    enum mlx5dv_mkey_err_type err_type;
    union {
        struct mlx5dv_sig_err sig;
    } err;
};
err_type
Qué tipo de error ocurrió. Si varios errores existen en un bloque verificado por el dispositivo, solo se informa el primero de ellos, según el orden especificado en la especificación T10DIF, que es: MLX5DV_MKEY_SIG_BLOCK_BAD_GUARD, MLX5DV_MKEY_SIG_BLOCK_BAD_APPTAG, MLX5DV_MKEY_SIG_BLOCK_BAD_REFTAG.
MLX5DV_MKEY_NO_ERR
No se detectaron errores para el MKEY.
MLX5DV_MKEY_SIG_BLOCK_BAD_GUARD
Se detectó un error de firma en CRC/CHECKSUM para T10-DIF o CRC32/CRC32C/CRC64_XP10 (depende del tipo de firma configurado). Información adicional sobre el error se proporciona en struct mlx5dv_sig_err de err.
MLX5DV_MKEY_SIG_BLOCK_BAD_REFTAG
Se detectó un error de firma en la etiqueta de referencia. Este tipo de error de firma es relevante solo para T10-DIF. Información adicional sobre el error se proporciona en struct mlx5dv_sig_err de err.
MLX5DV_MKEY_SIG_BLOCK_BAD_APPTAG
Se detectó un error de firma en la etiqueta de aplicación. Este tipo de error de firma es relevante solo para T10-DIF. Información adicional sobre el error se proporciona en struct mlx5dv_sig_err de err.
err
Información sobre el error detectado si err_type no es MLX5DV_MKEY_NO_ERR. De lo contrario, su valor no está definido.

Error de firma

struct mlx5dv_sig_err {
    uint64_t actual_value;
    uint64_t expected_value;
    uint64_t offset;
};
actual_value
El valor real que se calculó a partir de los datos transferidos.
expected_value
El valor esperado basado en lo que aparece en el campo de firma respetado.
offset
El desplazamiento dentro de la transferencia donde ocurrió el error. En la firma de bloque, esto está garantizado que sea un desplazamiento de límite de bloque.

VALOR DE RETORNO

0 en caso de éxito o el valor de errno en caso de fallo (que indica el motivo del fallo).

NOTAS

Se debe abrir un contexto DEVX usando mlx5dv_open_device(3).

La comprobación de errores del MKEY debe realizarse después de que la aplicación sepa que ha finalizado la transferencia de datos que estaba utilizando el MKEY. La aplicación debe esperar la finalización correspondiente (si se trataba de un MKEY local) o esperar un mensaje recibido de un par (si se trataba de un MKEY remoto).
