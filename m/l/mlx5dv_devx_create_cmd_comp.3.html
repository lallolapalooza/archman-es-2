mlx5dv_devx_create_cmd_comp, mlx5dv_devx_destroy_cmd_comp, get_async(3) Manual de funciones de biblioteca mlx5dv_devx_create_cmd_comp, mlx5dv_devx_destroy_cmd_comp, get_async(3)

NOMBRE

mlx5dv_devx_create_cmd_comp - Crear una completación de comandos para ser utilizada para comandos asíncronos DEVX.

mlx5dv_devx_destroy_cmd_comp - Destruir una completación de comandos devx.

mlx5dv_devx_get_async_cmd_comp - Obtener una completación de comandos asíncrona. # SINOPSIS

#include <infiniband/mlx5dv.h>
struct mlx5dv_devx_cmd_comp {
    int fd;
};
struct mlx5dv_devx_cmd_comp *
mlx5dv_devx_create_cmd_comp(struct ibv_context *context)
void mlx5dv_devx_destroy_cmd_comp(struct mlx5dv_devx_cmd_comp *cmd_comp)
struct mlx5dv_devx_async_cmd_hdr {
    uint64_t    wr_id;
    uint8_t     out_data[];
};
int mlx5dv_devx_get_async_cmd_comp(struct mlx5dv_devx_cmd_comp *cmd_comp,
                   struct mlx5dv_devx_async_cmd_hdr *cmd_resp,
                   size_t cmd_resp_len)

DESCRIPCIÓN

Crea o destruye una completación de comandos para ser utilizada para comandos DEVX asíncronos.

La llamada `create` expone un objeto mlx5dv_devx_cmd_comp que puede ser utilizado como parte de comandos DEVX asíncronos. Esto permite a una aplicación ejecutarse asíncronamente sin bloquearse y, una vez que la respuesta está lista, leerla desde este objeto.

La respuesta puede ser leída por la API `mlx5dv_devx_get_async_cmd_comp()`. Tras la respuesta, se devuelve el wr_id que se proporcionó en el comando asíncrono y out_data incluye los datos en sí. La aplicación debe proporcionar un búfer lo suficientemente grande para coincidir con cualquier comando que se haya emitido en el cmd_comp, su tamaño se proporciona mediante el parámetro de entrada cmd_resp_len.

ARGUMENTOS

context
Contexto del dispositivo RDMA en el que crear la acción.
cmd_comp
El objeto de completación de comandos.
cmd_resp
Los datos de salida del comando asíncrono.
cmd_resp_len
El tamaño del búfer de salida para almacenar la respuesta.

VALOR DE RETORNO

En caso de éxito, mlx5dv_devx_create_cmd_comp devolverá un nuevo objeto struct mlx5dv_devx_cmd_comp. En caso de error, devolverá NULL y se establecerá errno.

En caso de éxito, mlx5dv_devx_get_async_cmd_comp devolverá 0. En caso contrario, devolverá errno.

VER TAMBIÉN

mlx5dv_open_device(3), mlx5dv_devx_obj_create(3)
