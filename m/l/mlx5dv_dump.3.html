MLX5DV_DUMP API(3) Manual del programador de mlx5 MLX5DV_DUMP API(3)

NOMBRE

mlx5dv_dump_dr_domain - Volcar Dominio DR

mlx5dv_dump_dr_table - Volcar Tabla DR

mlx5dv_dump_dr_matcher - Volcar Coincidencia DR

mlx5dv_dump_dr_rule - Volcar Regla DR

SINOPSIS

#include <infiniband/mlx5dv.h>
int mlx5dv_dump_dr_domain(FILE *fout, struct mlx5dv_dr_domain *domain);
int mlx5dv_dump_dr_table(FILE *fout, struct mlx5dv_dr_table *table);
int mlx5dv_dump_dr_matcher(FILE *fout, struct mlx5dv_dr_matcher *matcher);
int mlx5dv_dump_dr_rule(FILE *fout, struct mlx5dv_dr_rule *rule);

DESCRIPCIÓN

La API de Volcado (mlx5dv_dump_*) permite volcar los recursos existentes de rdma-core al archivo proporcionado. El formato del archivo de salida es específico del proveedor.

mlx5dv_dump_dr_domain() vuelca las propiedades del objeto Dominio DR a un archivo especificado.

mlx5dv_dump_dr_table() vuelca las propiedades del objeto Tabla DR a un archivo especificado.

mlx5dv_dump_dr_matcher() vuelca las propiedades del objeto Coincidencia DR a un archivo especificado.

mlx5dv_dump_dr_rule() vuelca las propiedades del objeto Regla DR a un archivo especificado.

VALOR DE RETORNO

Las llamadas a la API devuelven 0 si tienen éxito, o el valor de errno en caso de fallo (que indica el motivo del fallo). Las llamadas son bloqueantes: la función solo regresa cuando toda la información de recursos relacionados se escribe en el archivo.
