mlx5dv_devx_create_event_channel, mlx5dv_devx_destroy_event_channel(3) Manual de Funciones de Biblioteca mlx5dv_devx_create_event_channel, mlx5dv_devx_destroy_event_channel(3)

NOMBRE

mlx5dv_devx_create_event_channel - Crea un canal de eventos para ser utilizado para eventos asíncronos DEVX.

mlx5dv_devx_destroy_event_channel - Destruye un canal de eventos DEVX.

SINOPSIS

#include <infiniband/mlx5dv.h>
struct mlx5dv_devx_event_channel {
    int fd;
};
struct mlx5dv_devx_event_channel *
mlx5dv_devx_create_event_channel(struct ibv_context *context,
                                 enum mlx5dv_devx_create_event_channel_flags flags)
void mlx5dv_devx_destroy_event_channel(struct mlx5dv_devx_event_channel *event_channel)

DESCRIPCIÓN

Crea o destruye un canal que se utilizará para eventos asíncronos DEVX.

El verbo de creación expone un objeto mlx5dv_devx_event_channel que puede ser utilizado para leer eventos asíncronos DEVX. Esto permite a una aplicación suscribirse para recibir eventos del dispositivo y, una vez que ocurre un evento, leerlo de este objeto.

ARGUMENTOS

contexto
Contexto del dispositivo RDMA en el que crear el canal.
flags
MLX5DV_DEVX_CREATE_EVENT_CHANNEL_FLAGS_OMIT_EV_DATA: omite los datos del evento en este canal.

VALOR DE RETORNO

En caso de éxito, mlx5dv_devx_create_event_channel devolverá un nuevo objeto struct mlx5dv_devx_event_channel, en caso de error se devolverá NULL y se establecerá errno.

VER TAMBIÉN

mlx5dv_open_device(3), mlx5dv_devx_obj_create(3)
