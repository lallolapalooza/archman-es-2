NOMBRE

mlx5dv_devx_query_eqn - Consulta el EQN para un ID de vector dado.

SINOPSIS

#include <infiniband/mlx5dv.h>
int mlx5dv_devx_query_eqn(struct ibv_context *context, uint32_t vector,
                          uint32_t *eqn);

DESCRIPCIÓN

Consulta el EQN para un vector de entrada dado, el EQN es necesario para otros comandos del dispositivo a través de la interfaz DEVX.

La API DEVX permite el acceso directo desde el área del espacio de usuario al controlador del dispositivo mlx5, la información EQN es necesaria para algunos comandos como la creación de CQ.

ARGUMENTOS

context
Contexto del dispositivo RDMA sobre el que operar.
vector
Número del vector de finalización.
eqn
El número de EQ del dispositivo que se relaciona con el vector de entrada dado.

VALOR DE RETORNO

Devuelve 0 si tiene éxito, o el valor de errno en caso de error (que indica el motivo del fallo).

VER TAMBIÉN

mlx5dv_open_device, mlx5dv_devx_obj_create
