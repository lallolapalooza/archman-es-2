NOMBRE

mlx5dv_reg_dmabuf_mr - Registrar una región de memoria (MR) basada en dma-buf

SINOPSIS

#include <infiniband/mlx5dv.h>
struct ibv_mr *mlx5dv_reg_dmabuf_mr(struct ibv_pd *pd, uint64_t offset,
                                    size_t length, uint64_t iova, int fd,
                                    int access, int mlx5_access)

DESCRIPCIÓN

Registra una región de memoria (MR) basada en dma-buf, sigue la funcionalidad de ibv_reg_dmabuf_mr() con la capacidad de suministrar flags de acceso mlx5 específicos.

ARGUMENTOS

pd
El dominio de protección asociado.
offset
El desplazamiento del dma-buf donde comienza la MR.
length
La longitud de la MR.
iova
Especifica la dirección base virtual de la MR cuando se accede a través de un lkey o rkey. Debe tener el mismo desplazamiento de página que offset y estar alineado con el tamaño de página del sistema.
fd
El descriptor de archivo por el cual se identifica el dma-buf.
access
Los atributos de protección de memoria deseados; es 0 o el OR bit a bit de uno o más de enum ibv_access_flags.
mlx5_access
Flags de acceso específicos del dispositivo, es 0 o lo siguiente.

Si se establece MLX5DV_REG_DMABUF_ACCESS_DATA_DIRECT, esta MR se accederá a través del motor Data Direct enlazado con ese dispositivo RDMA.

VALOR DE RETORNO

Al éxito, devuelve un puntero a la MR registrada, o NULL si la solicitud falla, en cuyo caso el valor de errno indica el motivo de la falla.

VER TAMBIÉN

ibv_reg_dmabuf_mr(3), mlx5dv_get_data_direct_sysfs_path(3)
