NOMBRE

mlx5dv_create_flow_action_packet_reformat - Acción de reformateo de paquete para el proveedor mlx5

SINOPSIS

#include <infiniband/mlx5dv.h>
struct ibv_flow_action *
mlx5dv_create_flow_action_packet_reformat(struct ibv_context *ctx,
                      size_t data_sz,
                      void *data,
                      enum mlx5dv_flow_action_packet_reformat_type reformat_type,
                      enum mlx5dv_flow_table_type ft_type)

DESCRIPCIÓN

Crea una acción de reenvío de flujo de reformatado de paquetes. Permite agregar/eliminar encabezados de paquetes.

ARGUMENTOS

ctx
Contexto del dispositivo RDMA en el que se creará la acción.
data_sz
El tamaño del buffer *data*.
data
Un buffer que contiene encabezados en caso de que las acciones los requieran.
reformat_type
El tipo de reformatado a crear. Utilizar enum mlx5dv_flow_action_packet_reformat_type.

MLX5DV_FLOW_ACTION_PACKET_REFORMAT_TYPE_L2_TUNNEL_TO_L2: Decapsula un paquete genérico L2 tunelizado hasta L2 interno.

MLX5DV_FLOW_ACTION_PACKET_REFORMAT_TYPE_L2_TO_L2_TUNNEL: Encapsula genéricamente, *data* debe contener los encabezados de encapsulación.

MLX5DV_FLOW_ACTION_PACKET_REFORMAT_TYPE_L3_TUNNEL_TO_L2: Realizará la decapsulación donde el paquete interno comienza desde L3. *data* debe ser MAC o MAC + vlan (14 o 18 bytes) para ser agregado al paquete después de la acción de decapsulación.

MLX5DV_FLOW_ACTION_PACKET_REFORMAT_TYPE_L2_TO_L3_TUNNEL: Realizará la encapsulación donde L2 del paquete original no se incluirá. *data* debe ser el encabezado de encapsulación.

ft_type
Define el tipo de tabla de flujo a la que se adjuntará la acción de reformatado
de paquetes.

VALOR DE RETORNO

Al éxito, mlx5dv_create_flow_action_packet_reformat devolverá un nuevo objeto struct ibv_flow_action, en caso de error devolverá NULL y se establecerá errno.

VER TAMBIÉN

ibv_create_flow(3), ibv_create_flow_action(3)
