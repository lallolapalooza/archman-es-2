NOMBRE

mlx5dv_dci_stream_id_reset - Restablecer stream_id de un QP DCI dado

SINOPSIS

#include <infiniband/mlx5dv.h>
int mlx5dv_dci_stream_id_reset(struct ibv_qp *qp, uint16_t stream_id);

DESCRIPCIÓN

Utilizado por SW para restablecer un stream_id erróneo en el contexto DCI de HW.

En una finalización de trabajo con error, la aplicación debe llamar a ibv_query_qp() para verificar si el QP se movió a un estado de error, o si todavía está operativo (en estado RTS), lo que significa que el stream_id específico que causó la finalización con error está en estado de error.

Los errores relacionados con el stream harán que solo la solicitud de trabajo de ese stream_id se vacíe, ya que se manejan en orden en la cola de envío. Una vez que se vacían todas las WR del stream_id, la aplicación debe restablecer el stream_id erróneo llamando a mlx5dv_dci_stream_id_reset(). El trabajo solicitado para otros stream_id continuará siendo procesado por el QP. El QP DCI se moverá a un estado de error y dejará de operar una vez que el número de stream_id únicos en error alcance los streams de DCI QP `log_num_errored' definidos por SW.

La aplicación debe usar el `wr_id' en el ibv_wc para encontrar el stream_id desde su contexto privado.

ARGUMENTOS

qp
El objeto ibv_qp en el que emitir la acción.
stream_id
El ID del canal de stream DCI que necesita ser restablecido.

VALOR DE RETORNO

Devuelve 0 en caso de éxito, o el valor de errno en caso de fallo (que indica el motivo del fallo).
