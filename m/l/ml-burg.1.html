NOMBRE

ml-burg - un generador de analizadores de árboles para Standard ML

SINOPSIS

ml-burg archivo

DESCRIPCIÓN

El programa ml-burg genera un programa en Standard ML para realizar la reescritura de un árbol de entrada de abajo hacia arriba. La información de coste asociada a cada regla de reescritura se utiliza para derivar el coste mínimo de reescritura para todo el árbol. Una reducción exitosa corresponde a la reescritura del árbol de entrada a un símbolo no terminal especial llamado el símbolo no terminal de inicio. Tras la reducción exitosa, se proporcionan herramientas para recorrer el árbol emitiendo acciones semánticas correspondientes a las reglas que coincidieron.
