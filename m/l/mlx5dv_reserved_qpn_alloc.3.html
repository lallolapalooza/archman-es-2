mlx5dv_reserved_qpn_alloc / dealloc(3) Manual del programador de mlx5 mlx5dv_reserved_qpn_alloc / dealloc(3)

NOMBRE

mlx5dv_reserved_qpn_alloc - Asignar un número de QP reservado del dispositivo

mlx5dv_reserved_qpn_dealloc - Liberar el número de QP reservado

SINOPSIS

#include <infiniband/mlx5dv.h>
int mlx5dv_reserved_qpn_alloc(struct ibv_context *ctx, uint32_t *qpn);
int mlx5dv_reserved_qpn_dealloc(struct ibv_context *ctx, uint32_t qpn);

DESCRIPCIÓN

Al trabajar con RDMA_CM RDMA_TCP_PS + soporte de QP externo, un nodo cliente necesita números de QP únicos a nivel de GUID para cumplir con la lógica de timewait del CM.

Si no se asigna un QP real único, se requiere un valor de QP global del dispositivo, que se puede asignar a través de esta interfaz.

El QP DCI de mlx5 es un ejemplo de esto, que podría conectarse a múltiples DCT remotas siempre que la aplicación proporcione QPs únicos para cada nueva conexión RDMA_CM.

Estas 2 APIs proporcionan la asignación/desasignación de un número de QP único desde/hacia el dispositivo. Este qpn se puede usar con QPN de DC en el establecimiento de la conexión RDMA_CM, lo que cumplirá con la lógica del kernel de timewait del CM.

ARGUMENTOS

ctx
El contexto del dispositivo en el que se ejecutará la acción.
qpn
El número de QP asignado (para la API de asignación), o el número de QP que se va a desasignar (para la API de desasignación).

VALOR DE RETORNO

0 si tiene éxito; EOPNOTSUPP si no es compatible, u otro valor errno en caso de otros fallos.
