mlx5dv_create_mkey / mlx5dv_destroy_mkey(3) Manual de funciones de biblioteca mlx5dv_create_mkey / mlx5dv_destroy_mkey(3)

NOMBRE

mlx5dv_create_mkey - Crea una mkey indirecta

mlx5dv_destroy_mkey - Destruye una mkey indirecta

SINOPSIS

#include <infiniband/mlx5dv.h>
struct mlx5dv_mkey_init_attr {
    struct ibv_pd   *pd;
    uint32_t    create_flags;
    uint16_t    max_entries;
};
struct mlx5dv_mkey {
    uint32_t    lkey;
    uint32_t    rkey;
};
struct mlx5dv_mkey *
mlx5dv_create_mkey(struct mlx5dv_mkey_init_attr *mkey_init_attr);
int mlx5dv_destroy_mkey(struct mlx5dv_mkey *mkey);

DESCRIPCIÓN

Crea / destruye una mkey indirecta.

Crea una mkey indirecta para permitir a la aplicación utilizar su funcionalidad específica del dispositivo.

ARGUMENTOS

##mkey_init_attr##

pd
dominio de protección ibv.
create_flags
MLX5DV_MKEY_INIT_ATTR_FLAGS_INDIRECT: Se está creando una mkey indirecta. MLX5DV_MKEY_INIT_ATTR_FLAGS_BLOCK_SIGNATURE: Habilita el soporte de descarga de firma de bloque para mkey. MLX5DV_MKEY_INIT_ATTR_FLAGS_CRYPTO: Habilita el soporte de descarga de criptografía para mkey. Establecer esta bandera significa que se realizarán operaciones criptográficas y, por lo tanto, deben configurarse. Es decir, si esta bandera está establecida y la MKey no fue configurada para propiedades criptográficas usando mlx5dv_wr_set_mkey_crypto(), entonces ejecutar tráfico con la MKey fallará, generando una CQE con error. MLX5DV_MKEY_INIT_ATTR_FLAGS_UPDATE_TAG: Habilita el soporte de actualización de etiqueta para mkey. Establecer esta bandera permite a una aplicación establecer la etiqueta de la mkey después de crearla. Si el kernel no admite la actualización de la etiqueta de la mkey, la creación de la mkey fallará. MLX5DV_MKEY_INIT_ATTR_FLAGS_REMOTE_INVALIDATE: Habilita el soporte de invalidación remota para mkey.
max_entries
Número máximo solicitado de entradas apuntadas por esta mkey indirecta. La función actualizará mkey_init_attr->max_entries con el valor real de mkey que se creó; será mayor o igual al valor solicitado.

VALOR DEVUELTO

En caso de éxito, mlx5dv_create_mkey devolverá una nueva struct mlx5dv_mkey. En caso de error, se devolverá NULL y se establecerá errno.

En caso de éxito, la destrucción devuelve 0 o el valor de errno en caso de fallo.

Notas

Para que esta funcionalidad funcione, se debe abrir un contexto DEVX utilizando mlx5dv_open_device.

La mkey indirecta creada no puede funcionar con la función scatter to CQE, considere mlx5dv_create_qp() con MLX5DV_QP_CREATE_DISABLE_SCATTER_TO_CQE para mensajes pequeños.

VER TAMBIÉN

mlx5dv_open_device(3), mlx5dv_create_qp(3)
