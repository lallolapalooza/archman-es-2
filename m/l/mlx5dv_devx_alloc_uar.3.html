mlx5dv_devx_alloc_uar / mlx5dv_devx_free_uar(3) Manual de funciones de biblioteca mlx5dv_devx_alloc_uar / mlx5dv_devx_free_uar(3)

NOMBRE

mlx5dv_devx_alloc_uar - Asigna un UAR DEVX

mlx5dv_devx_free_uar - Libera un UAR DEVX

SINOPSIS

#include <infiniband/mlx5dv.h>
struct mlx5dv_devx_uar *mlx5dv_devx_alloc_uar(struct ibv_context *context,
                                              uint32_t flags);
void mlx5dv_devx_free_uar(struct mlx5dv_devx_uar *devx_uar);

DESCRIPCIÓN

Crea / libera un UAR DEVX que es necesario para otros comandos del dispositivo a través de la interfaz DEVX.

La API DEVX permite el acceso directo desde el espacio de usuario al controlador de dispositivos mlx5, la información del UAR es necesaria para pocos comandos como la creación de QP.

ARGUMENTOS

context
Contexto del dispositivo RDMA sobre el cual trabajar.
flags
Banderas de asignación para el UAR. MLX5DV_UAR_ALLOC_TYPE_BF: Asigna UAR con propiedades Blueflame. MLX5DV_UAR_ALLOC_TYPE_NC: Asigna UAR con propiedades no cacheadas. MLX5DV_UAR_ALLOC_TYPE_NC_DEDICATED: Asigna un UAR dedicado con propiedades no cacheadas.

devx_uar

struct mlx5dv_devx_uar {
    void *reg_addr;
    void *base_addr;
    uint32_t page_id;
    off_t mmap_off;
    uint64_t comp_mask;
};
reg_addr
La dirección de escritura de DB/BF.
base_addr
La dirección base del UAR.
page_id
El ID de página del dispositivo a utilizar.
mmap_off
El parámetro de desplazamiento mmap a utilizar para re-mapear, a ser usado por un proceso secundario.

VALOR DE RETORNO

Al tener éxito, mlx5dv_devx_alloc_uar devolverá un nuevo struct mlx5dv_devx_uar, en caso de error se devolverá NULL y se establecerá errno.

VER TAMBIÉN

mlx5dv_open_device, mlx5dv_devx_obj_create
