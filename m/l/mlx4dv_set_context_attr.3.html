NOMBRE

mlx4dv_set_context_attr - Establecer atributos del contexto

SINOPSIS

#include <infiniband/mlx4dv.h>
int mlx4dv_set_context_attr(struct ibv_context *context,
                            enum mlx4dv_set_ctx_attr_type attr_type,
                            void *attr);

DESCRIPCIÓN

mlx4dv_set_context_attr proporciona la capacidad de establecer atributos específicos del proveedor en el contexto RDMA.

ARGUMENTOS

context
Contexto del dispositivo RDMA sobre el que trabajar.
attr_type
El tipo del atributo proporcionado.
attr
Puntero al atributo que se va a establecer. ## attr_type
enum mlx4dv_set_ctx_attr_type {
    /* Tipo de atributo uint8_t */
    MLX4DV_SET_CTX_ATTR_LOG_WQS_RANGE_SZ    = 0,
    MLX4DV_SET_CTX_ATTR_BUF_ALLOCATORS  = 1,
};
MLX4DV_SET_CTX_ATTR_LOG_WQS_RANGE_SZ
Cambiar el tamaño del rango de LOG WQs para RSS
MLX4DV_SET_CTX_ATTR_BUF_ALLOCATORS
Proporcionar un asignador de búfer externo
struct mlx4dv_ctx_allocators {
    void *(*alloc)(size_t size, void *priv_data);
    void (*free)(void *ptr, void *priv_data);
    void *data;
};
alloc
Función utilizada para la asignación de búferes en lugar del método interno de libmlx4
free
Función utilizada para liberar búferes asignados por la función alloc
data
Metadatos que pueden ser utilizados por las funciones alloc y free

VALOR DE RETORNO

Devuelve 0 en caso de éxito, o el valor de errno en caso de fallo (que indica el motivo del fallo).
