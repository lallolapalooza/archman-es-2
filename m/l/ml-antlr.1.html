NOMBRE

ml-antlr - generador de analizadores LL(k) para Standard ML

SINOPSIS

ml-antlr [OPCIONES] archivo

DESCRIPCIÓN

ML-Antlr es un generador de analizadores LL(k) para Standard ML que está vagamente modelado según el generador de analizadores ANTLR de Terence Parr.

OPCIONES

-32

ejecuta la versión de 32 bits del programa (actualmente la predeterminada).

-64

ejecuta la versión de 64 bits del programa. Esta opción solo se aplica a la arquitectura x86-64 (también conocida como amd64).

--dot

genera salida DOT ( http://www.graphviz.org). El archivo generado se llamará archivo.dot, donde archivo es el archivo de entrada.

--latex

genera una versión simple en LaTeX de la gramática, llamada archivo.tex.

--unit-actions

ignora el código de acción en la gramática y, en su lugar, devuelve unit para cada producción.

AUTOR
