mlx5dv_get_vfio_device_list(3) Manual de funciones de la biblioteca mlx5dv_get_vfio_device_list(3)

NOMBRE

mlx5dv_get_vfio_device_list - Obtener la lista de dispositivos disponibles para ser utilizados sobre VFIO

SINOPSIS

#include <infiniband/mlx5dv.h>
struct ibv_device **
mlx5dv_get_vfio_device_list(struct mlx5dv_vfio_context_attr *attr);

DESCRIPCIÓN

Devuelve una matriz terminada en NULL de dispositivos basada en el argumento attr de entrada.

ARGUMENTOS

attr
Describe los dispositivos VFIO a devolver en la lista.

Argumento attr

struct mlx5dv_vfio_context_attr {
    const char *pci_name;
    uint32_t flags;
    uint64_t comp_mask;
};
pci_name
El nombre PCI del dispositivo requerido.
flags
Un OR bit a bit de los diversos valores descritos a continuación.
*MLX5DV_VFIO_CTX_FLAGS_INIT_LINK_DOWN*:
Tras la inicialización del dispositivo, el enlace debe permanecer inactivo.
comp_mask
Máscara de bits que especifica qué campos de la estructura son válidos.

VALOR DE RETORNO

Devuelve la matriz de dispositivos coincidentes, o establece errno y devuelve NULL si la solicitud falla.

NOTAS

El código del cliente debe abrir todos los dispositivos que pretende utilizar con ibv_open_device() antes de llamar a ibv_free_device_list(). Una vez que libera la matriz con ibv_free_device_list(), solo podrá utilizar los dispositivos abiertos; los punteros a dispositivos no abiertos ya no serán válidos.

VER TAMBIÉN

ibv_open_device(3) ibv_free_device_list(3)
