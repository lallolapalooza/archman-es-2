NOMBRE

mlx5dv_crypto_login - Crea una sesión de inicio de sesión criptográfico

mlx5dv_crypto_login_query_state - Consulta el estado de la sesión de inicio de sesión criptográfico actual

mlx5dv_crypto_logout - Cierra la sesión de inicio de sesión criptográfico actual

SINOPSIS

#include <infiniband/mlx5dv.h>
int mlx5dv_crypto_login(struct ibv_context *context,
            struct mlx5dv_crypto_login_attr *login_attr);
int mlx5dv_crypto_login_query_state(struct ibv_context *context,
                    enum mlx5dv_crypto_login_state *state);
int mlx5dv_crypto_logout(struct ibv_context *context);

DESCRIPCIÓN

Al utilizar un motor criptográfico que se encuentra en el método de importación cifrada, debe existir una sesión de inicio de sesión criptográfico activa para poder crear y consultar Claves de Cifrado de Datos (DEK).

mlx5dv_crypto_login() Crea una sesión de inicio de sesión criptográfico con las credenciales proporcionadas en login_attr y la asocia con context. Solo puede existir una sesión de inicio de sesión criptográfico activa por contexto de dispositivo.

mlx5dv_crypto_login_query_state() consulta el estado de la sesión de inicio de sesión criptográfico asociada con context y devuelve el estado en state, que indica si es válida, inválida o inexistente. Una sesión de inicio de sesión criptográfico válida puede volverse inválida si las credenciales o la KEK de importación utilizadas en la sesión de inicio de sesión criptográfico fueron eliminadas durante la sesión (por ejemplo, por un oficial criptográfico). En este caso, se debe llamar a mlx5dv_crypto_logout() para destruir la sesión de inicio de sesión criptográfico inválida actual y, si aún es necesario, se debe llamar a mlx5dv_crypto_login() para crear una nueva sesión de inicio de sesión criptográfico con credenciales y KEK de importación válidas.

mlx5dv_crypto_logout() cierra la sesión de inicio de sesión criptográfico actual asociada con context.

Las DEK existentes que se cargaron previamente en el dispositivo durante una sesión de inicio de sesión criptográfico no necesitan una sesión de inicio de sesión criptográfico activa para ser utilizadas (en MKey o durante el tráfico).

ARGUMENTOS

context

El contexto del dispositivo al que asociar la sesión de inicio de sesión criptográfico.

login_attr

Los atributos de inicio de sesión criptográfico especifican las credenciales para iniciar sesión y la KEK de importación que se utilizará para las comunicaciones seguras durante la sesión de inicio de sesión criptográfico.

struct mlx5dv_crypto_login_attr {
    uint32_t credential_id;
    uint32_t import_kek_id;
    char credential[48];
    uint64_t comp_mask;
};
credential_id
Un ID de una credencial, de las credenciales almacenadas en el dispositivo, que indica la credencial que se debe validar frente a la credencial proporcionada en credential.
import_kek_id
Un ID de una KEK de importación, de las KEK de importación almacenadas en el dispositivo, que indica la KEK de importación que se utilizará para desempaquetar las credenciales proporcionadas en credential y también para todas las demás comunicaciones seguras durante la sesión de inicio de sesión criptográfico.
credential
La credencial para iniciar sesión. Debe proporcionarse cifrada con el algoritmo de envoltura de claves AES utilizando la KEK de importación indicada por import_kek_id.
comp_mask
Reservado para futuras extensiones, debe ser 0 por ahora.

state

Indica el estado de la sesión de inicio de sesión criptográfico actual. Puede ser uno de MLX5DV_CRYPTO_LOGIN_STATE_VALID, MLX5DV_CRYPTO_LOGIN_STATE_NO_LOGIN y MLX5DV_CRYPTO_LOGIN_STATE_INVALID.

VALOR DE RETORNO

mlx5dv_crypto_login() devuelve 0 en caso de éxito y el valor de errno en caso de error.

mlx5dv_crypto_login_query_state() devuelve 0 en caso de éxito y actualiza state con el estado consultado. En caso de error, devuelve el valor de errno.

mlx5dv_crypto_logout() devuelve 0 en caso de éxito y el valor de errno en caso de error.

ERRORES

EEXIST
Ya existe una sesión de inicio de sesión criptográfico.
EINVAL
Se proporcionaron atributos inválidos, o una o más de credential, credential_id y import_kek_id son inválidas.
ENOENT
No existe ninguna sesión de inicio de sesión criptográfico.
