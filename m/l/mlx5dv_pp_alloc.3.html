mlx5dv_pp_alloc / mlx5dv_pp_free(3) Manual de funciones de biblioteca mlx5dv_pp_alloc / mlx5dv_pp_free(3)

NOMBRE

mlx5dv_pp_alloc - Asigna una entrada de control de paquetes

mlx5dv_pp_free - Libera una entrada de control de paquetes

SINOPSIS

#include <infiniband/mlx5dv.h>
struct mlx5dv_pp *
mlx5dv_pp_alloc(struct ibv_context *context,
        size_t pp_context_sz,
        const void *pp_context,
        uint32_t flags);
void mlx5dv_pp_free(struct mlx5dv_pp *dv_pp);

DESCRIPCIÓN

Crea / libera una entrada de control de paquetes que puede usarse para algunos comandos del dispositivo a través de la interfaz DEVX.

La API DEVX permite el acceso directo desde el área del espacio de usuario al controlador del dispositivo mlx5, la información de control de paquetes es necesaria para algunos comandos donde se necesita un índice de control de paquetes.

ARGUMENTOS

context
Contexto del dispositivo RDMA en el que trabajar, debe abrirse con soporte DEVX utilizando mlx5dv_open_device().
pp_context_sz
Longitud del búfer de entrada pp_context.
pp_context
Contexto de control de paquetes según la especificación del dispositivo.
flags
MLX5DV_PP_ALLOC_FLAGS_DEDICATED_INDEX: asigna un índice dedicado.

dv_pp

struct mlx5dv_pp {
    uint16_t index;
};
index
El índice del dispositivo a utilizar.

VALOR DE RETORNO

En caso de éxito, mlx5dv_pp_alloc devuelve un puntero al objeto de control de paquetes creado, en caso de error, se devolverá NULL y se establecerá errno.

VER TAMBIÉN

mlx5dv_open_device, mlx5dv_devx_obj_create
