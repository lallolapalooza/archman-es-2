mlx5dv_alloc_var / mlx5dv_free_var(3) Manual de funciones de biblioteca mlx5dv_alloc_var / mlx5dv_free_var(3)

NOMBRE

mlx5dv_alloc_var - Asigna un VAR

mlx5dv_free_var - Libera un VAR

SINOPSIS

#include <infiniband/mlx5dv.h>
struct mlx5dv_var *
mlx5dv_alloc_var(struct ibv_context *context, uint32_t flags);
void mlx5dv_free_var(struct mlx5dv_var *dv_var);

DESCRIPCIÓN

Crea / libera un VAR que se puede usar para algunos comandos del dispositivo a través de la interfaz DEVX.

La API DEVX permite el acceso directo desde el área del espacio de usuario al controlador del dispositivo mlx5; la información VAR es necesaria para algunos comandos relacionados con Virtio.

ARGUMENTOS

context
Contexto del dispositivo RDMA sobre el que trabajar.
flags
Indicadores de asignación para la UAR.

dv_var

struct mlx5dv_var {
    uint32_t page_id;
    uint32_t length;
    off_t mmap_off;
    uint64_t comp_mask;
};
page_id
El ID de página del dispositivo a utilizar.
length
El parámetro de longitud de mmap a usar para mapear una VA a la entrada VAR asignada.
mmap_off
El parámetro de desplazamiento de mmap a usar para mapear una VA a la entrada VAR asignada.

VALOR DE RETORNO

Al éxito, mlx5dv_alloc_var devuelve un puntero a la VAR creada; en caso de error, se devolverá NULL y errno se establecerá.

VER TAMBIÉN

mlx5dv_open_device, mlx5dv_devx_obj_create
