NOMBRE

mlx5dv_is_supported - Comprueba si un dispositivo RDMA implementado por el proveedor mlx5

SINOPSIS

#include <infiniband/mlx5dv.h>
bool mlx5dv_is_supported(struct ibv_device *device);

DESCRIPCIÓN

Las funciones mlx5dv solo se pueden llamar si esta función devuelve true para el dispositivo RDMA.

ARGUMENTOS

device
Dispositivo RDMA a comprobar.

VALOR DEVUELTO

Devuelve true si el dispositivo está implementado por el proveedor mlx5.

VER TAMBIÉN
