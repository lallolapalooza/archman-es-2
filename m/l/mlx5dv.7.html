MLX5DV(7) Manual de información miscelánea MLX5DV(7)

NOMBRE

mlx5dv - Verbos directos para dispositivos mlx5
Este es un acceso de bajo nivel a dispositivos mlx5 para realizar operaciones de ruta de datos, sin el ramificación general realizada por ibv_post_send(3).

DESCRIPCIÓN

La API de libibverbs es abstracta. Es agnóstica a cualquier implementación específica del proveedor subyacente. Si bien esta abstracción tiene la ventaja de la portabilidad de las aplicaciones de usuario, tiene una penalización de rendimiento. Para algunas aplicaciones, optimizar el rendimiento es más importante que la portabilidad.

La API de verbos directos mlx5 está destinada a tales aplicaciones. Expone operaciones de ruta de datos de bajo nivel específicas de mlx5 (envío/recepción/finalización), lo que permite a la aplicación omitir la API de ruta de datos de libibverbs.

Esta interfaz consta de un archivo de encabezado específico del hardware con funciones en línea relevantes y lógica de conversión de estructuras de ibverbs a estructuras específicas de mlx5.

La inclusión directa de mlx5dv.h junto con el enlace a la biblioteca mlx5 permitirá el uso de esta nueva interfaz.

Una vez que una aplicación utiliza el flujo directo, el esquema de bloqueo es gestionado completamente por sí misma. Se espera que no haya flujos mixtos en la ruta de datos para acceso directo/no directo por la misma aplicación.

NOTAS

Todos los dispositivos NIC Mellanox a partir de Connect-IB (Connect-IB, ConnectX-4, ConnectX-4Lx, ConnectX-5, ...) implementan la API mlx5, por lo tanto el uso de verbos directos mlx5 no limita las aplicaciones a un solo dispositivo NIC de hardware, manteniendo así cierto nivel de portabilidad.

VER TAMBIÉN

ibv_post_send(3), verbs(7), mlx5dv_is_supported(3)
