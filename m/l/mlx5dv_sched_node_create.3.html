mlx5dv_sched_node[/leaf]_create / modify / destroy(3) Manual del programador de mlx5 mlx5dv_sched_node[/leaf]_create / modify / destroy(3)

NOMBRE

mlx5dv_sched_node_create - Crea un elemento de nodo de planificación

mlx5dv_sched_leaf_create - Crea un elemento de hoja de planificación

mlx5dv_sched_node_modify - Modifica un elemento de nodo de planificación

mlx5dv_sched_leaf_modify - Modifica un elemento de hoja de planificación

mlx5dv_sched_node_destroy - Destruye un elemento de nodo de planificación

mlx5dv_sched_leaf_destroy - Destruye un elemento de hoja de planificación

SINOPSIS

#include <infiniband/mlx5dv.h>
struct mlx5dv_sched_node *mlx5dv_sched_node_create(struct ibv_context *context,
                           struct mlx5dv_sched_attr *sched_attr);
struct mlx5dv_sched_leaf *mlx5dv_sched_leaf_create(struct ibv_context *context,
                           struct mlx5dv_sched_attr *sched_attr);
int mlx5dv_sched_node_modify(struct mlx5dv_sched_node *node,
                 struct mlx5dv_sched_attr *sched_attr);
int mlx5dv_sched_leaf_modify(struct mlx5dv_sched_leaf *leaf,
                 struct mlx5dv_sched_attr *sched_attr);
int mlx5dv_sched_node_destroy(struct mlx5dv_sched_node *node);
int mlx5dv_sched_leaf_destroy(struct mlx5dv_sched_leaf *leaf);

DESCRIPCIÓN

El elemento de planificación de transmisión (SE) planifica la transmisión de todos los nodos conectados a él. Al configurar el SE, se pueden aplicar políticas de QoS entre las entidades competidoras (por ejemplo, SQ, QP).

En cada ciclo de planificación, el SE planifica todas las entidades listas para transmitir. El SE asegura que se cumpla el peso de cada entidad. Si una entidad ha alcanzado su ancho de banda máximo permitido dentro del ciclo de planificación, no se planificará hasta el final del ciclo. El ancho de banda de transmisión no utilizado se distribuirá entre las entidades restantes, asegurando la configuración del peso.

Los SE están conectados en una estructura de árbol. La entidad se conecta a una hoja. Una o más hojas pueden conectarse a un nodo SE. Uno o más nodos SE pueden conectarse a un nodo SE, hasta llegar a la raíz del SE. Para cada entrada en cada nodo, el usuario puede asignar el ancho de banda máximo y el peso de planificación.

Las API de SE (mlx5dv_sched_*) permiten a la aplicación de verbos acceder y configurar el árbol de SE jerárquico en el dispositivo. El ibv_qp se conectará a una hoja.

ARGUMENTOS

Por favor, consulte la página del manual de ibv_create_qp_ex(3) para obtener información sobre context.

mlx5dv_sched_attr

struct mlx5dv_sched_attr {
    struct mlx5dv_sched_node *parent;
    uint32_t flags;
    uint32_t bw_share;
    uint32_t max_avg_bw;
    uint64_t comp_mask;
};
parent
Un manejador de nodo para el elemento de planificación padre al que se conectará este elemento de planificación. El elemento de planificación raíz no tiene padre.
flags
Especifica qué atributos en la estructura son válidos:

MLX5DV_SCHED_ELEM_ATTR_FLAGS_BW_SHARE para bw_share

MLX5DV_SCHED_ELEM_ATTR_FLAGS_MAX_AVG_BW para max_avg_bw

bw_share
La cuota de ancho de banda relativa asignada a este elemento. Este campo no tiene unidades. El ancho de banda se comparte entre todos los elementos conectados al mismo elemento padre, en relación con su bw_share. Un valor de 0 indica un peso predeterminado del dispositivo. Este campo debe ser 0 para la TSAR raíz.
max_avg_bw
La tasa de transmisión máxima permitida para el elemento, promediada en el tiempo. El valor se proporciona en unidades de 1 Mbit/s. Un valor de 0x0 indica que la tasa no tiene límites. Este campo debe ser 0 para la TSAR raíz.
comp_mask
Reservado para futuras extensiones, debe ser 0 por ahora.
node/leaf
Para modificar, destruir: el elemento de planificación sobre el que trabajar.
sched_attr
Para crear, modificar: el atributo del elemento de planificación sobre el que trabajar.

NOTAS

Por ejemplo, si una aplicación quiere crear 2 grupos de QP con QoS:

g1: cuota de ancho de banda del 70% de esta aplicación
g2: cuota de ancho de banda del 30% de esta aplicación, con un ancho de banda promedio máximo limitado a 4Gbps

Pseudocódigo:

struct mlx5dv_sched_node *root;
struct mlx5dv_sched_leaf *leaf_g1, *leaf_g2;
struct mlx5dv_sched_attr;
struct ibv_qp *qp1, qp2;
/* Crear nodo raíz */
attr.comp_mask = 0;
attr.parent = NULL;
attr.flags = 0;
root = mlx5dv_sched_node_create(context, attr);
/* Crear grupo1 */
attr.comp_mask = 0;
attr.parent = root;
attr.bw_share = 7;
attr.flags = MLX5DV_SCHED_ELEM_ATTR_FLAGS_BW_SHARE;
leaf_g1 = mlx5dv_sched_leaf_create(context, attr);
/* Crear grupo2 */
attr.comp_mask = 0;
attr.parent = root;
attr.bw_share = 3;
attr.max_avg_bw = 4096;
attr.flags = MLX5DV_SCHED_ELEM_ATTR_FLAGS_BW_SHARE | MLX5DV_SCHED_ELEM_ATTR_FLAGS_MAX_AVG_BW;
leaf_g2 = mlx5dv_sched_leaf_create(context, attr);
foreach (qp1 in group1)
    mlx5dv_modify_qp_sched_elem(qp1, leaf_g1, NULL);
foreach (qp2 in group2)
    mlx5dv_modify_qp_sched_elem(qp2, leaf_g2, NULL);

VALOR DE RETORNO

Tras el éxito, *mlx5dv_sched_node[/leaf]_create()* devolverá un nuevo struct mlx5dv_sched_node[/leaf]; en caso de error, se devolverá NULL y se establecerá errno.

Tras el éxito en la modificación y destrucción, se devuelve 0 o el valor de errno en caso de fallo.
