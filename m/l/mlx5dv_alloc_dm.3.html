mlx5dv_alloc_dm(3) Manual del Programador de mlx5 mlx5dv_alloc_dm(3)

NOMBRE

mlx5dv_alloc_dm - asigna memoria del dispositivo (DM)

SINOPSIS

#include <infiniband/mlx5dv.h>
struct ibv_dm *mlx5dv_alloc_dm(struct ibv_context *context,
                   struct ibv_alloc_dm_attr *dm_attr,
                   struct mlx5dv_alloc_dm_attr *mlx5_dm_attr)

DESCRIPCIÓN

mlx5dv_alloc_dm() asigna memoria del dispositivo (DM) con propiedades específicas del controlador.

ARGUMENTOS

Por favor, consulte la página del manual de ibv_alloc_dm(3) para context y dm_attr.

mlx5_dm_attr

struct mlx5dv_alloc_dm_attr {
    enum mlx5dv_alloc_dm_type type;
    uint64_t comp_mask;
};
type
El tipo de memoria del dispositivo que el usuario desea asignar:

MLX5DV_DM_TYPE_MEMIC Memoria del dispositivo de tipo MEMIC - Memoria en chip que puede ser asignada y utilizada como región de memoria para transmitir/recibir paquetes directamente desde/hacia la memoria en el chip.

MLX5DV_DM_TYPE_STEERING_SW_ICM Memoria del dispositivo de tipo STEERING SW ICM - Esta memoria es utilizada por el dispositivo para almacenar las tablas y reglas de direccionamiento de paquetes. Puede ser utilizada para la creación directa de tablas y reglas de direccionamiento cuando es asignada por un usuario privilegiado.

MLX5DV_DM_TYPE_HEADER_MODIFY_SW_ICM Memoria del dispositivo de tipo HEADER MODIFY SW ICM - Esta memoria es utilizada por el dispositivo para almacenar las tablas y reglas de modificación de encabezados de paquetes. Puede ser utilizada para la creación directa de tablas y reglas de modificación de encabezados cuando es asignada por un usuario privilegiado.

MLX5DV_DM_TYPE_HEADER_MODIFY_PATTERN_SW_ICM Memoria del dispositivo de tipo HEADER MODIFY PATTERN SW ICM - Esta memoria es utilizada por el dispositivo para almacenar patrones/plantillas de modificación de encabezados de paquetes. Puede ser utilizada para la creación directa de tablas y reglas de modificación de encabezados cuando es asignada por un usuario privilegiado.

MLX5DV_DM_TYPE_ENCAP_SW_ICM Memoria del dispositivo de tipo PACKET ENCAP SW ICM - Esta memoria es utilizada por el dispositivo para almacenar datos de encapsulación de paquetes. Puede ser utilizada para la creación de reglas de reformatación de encapsulación de paquetes cuando es asignada por un usuario privilegiado.

comp_mask
Máscara de bits que especifica qué campos de la estructura son válidos: Actualmente reservada y debe establecerse en 0.

VALOR DE RETORNO

mlx5dv_alloc_dm() devuelve un puntero a la DM creada; en caso de error, se devuelve NULL y se establece errno.
