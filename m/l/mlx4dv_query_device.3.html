MLX4DV_QUERY_DEVICE(3) Manual de funciones de biblioteca MLX4DV_QUERY_DEVICE(3)

NOMBRE

mlx4dv_query_device - Consultar capacidades del dispositivo específicas de mlx4

SINOPSIS

#include <infiniband/mlx4dv.h>

int mlx4dv_query_device(struct ibv_context *ctx_in,
                        struct mlx4dv_context *attrs_out);

DESCRIPCIÓN

mlx4dv_query_device() Consulta información específica del dispositivo mlx4 que se puede usar a través de la interfaz de verbos directos.

Esta función devuelve una máscara de versión y compatibilidad. La versión representa el formato de las estructuras de hardware internas que expone mlx4dv.h. Las adiciones futuras de nuevos campos a las estructuras existentes se manejan a través del campo comp_mask.

struct mlx4dv_context {
uint8_t         version;
uint32_t        max_inl_recv_sz; /* Tamaño máximo admitido de recepción en línea  */
uint64_t        comp_mask;
};

VALOR DE RETORNO

0 si la operación es exitosa o el valor de errno en caso de fallo (que indica el motivo del fallo).

NOTAS


* La máscara de compatibilidad (comp_mask) es un campo de entrada/salida.

VER TAMBIÉN
