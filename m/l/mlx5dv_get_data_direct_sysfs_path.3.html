NOMBRE

mlx5dv_get_data_direct_sysfs_path - Obtener la ruta sysfs de un dispositivo de datos directo

SINOPSIS

#include <infiniband/mlx5dv.h>
int mlx5dv_get_data_direct_sysfs_path(struct ibv_context *context, char *buf,
                                      size_t buf_len)

DESCRIPCIÓN

Obtiene la ruta sysfs del dispositivo de datos directo que está asociado con el contexto dado.

Esto permite a una aplicación descubrir si hay un dispositivo de datos directo asociado con el contexto dado, y cuál es.

ARGUMENTOS

context
Contexto del dispositivo RDMA sobre el cual operar.
buf
El búfer donde colocar la ruta sysfs del dispositivo de datos directo asociado.
buf_len
La longitud del búfer.

VALOR DE RETORNO

En caso de éxito, se retorna 0 o el valor de errno en caso de fallo.

ERRORES

Los siguientes valores de error específicos deben ser considerados.

ENODEV
No hay un dispositivo de datos directo asociado para el *contexto* dado.
ENOSPC
El tamaño del búfer de entrada es demasiado pequeño para contener la ruta sysfs completa.

NOTAS

En caso de éxito, el llamador debe añadir el prefijo /sys/ para obtener la ruta sysfs completa.
