NOMBRE

mlir-tblgen - Descripción a Código C++ para MLIR

SINOPSIS

mlir-tblgen [opciones] [nombre_archivo]

DESCRIPCIÓN

mlir-tblgen es un programa que traduce archivos de descripción de objetivo relacionados con el compilador (.td) a código C++ y otros formatos de salida. La mayoría de los usuarios de LLVM no necesitarán usar este programa. Solo se utiliza para escribir partes del compilador.

Por favor, consulte tblgen - Descripción a Código C++ <> para obtener una descripción del argumento nombre_archivo y las opciones, incluyendo las opciones comunes a todos los programas *-tblgen.
