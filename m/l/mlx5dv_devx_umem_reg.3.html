NOMBRE

mlx5dv_devx_umem_reg - Registra memoria de usuario para ser utilizada por la interfaz devx

mlx5dv_devx_umem_reg_ex - Registra memoria de usuario para ser utilizada por la interfaz devx

mlx5dv_devx_umem_dereg - Anula el registro de un objeto umem devx

SINOPSIS

#include <infiniband/mlx5dv.h>
struct mlx5dv_devx_umem {
    uint32_t umem_id;
};
struct mlx5dv_devx_umem *
mlx5dv_devx_umem_reg(struct ibv_context *context, void *addr, size_t size,
             uint32_t access)
struct mlx5dv_devx_umem_in {
    void *addr;
    size_t size;
    uint32_t access;
    uint64_t pgsz_bitmap;
    uint64_t comp_mask;
    int dmabuf_fd;
};
struct mlx5dv_devx_umem *
mlx5dv_devx_umem_reg_ex(struct ibv_context *ctx, struct mlx5dv_devx_umem_in *umem_in);
int mlx5dv_devx_umem_dereg(struct mlx5dv_devx_umem *dv_devx_umem)

DESCRIPCIÓN

Registra o anula el registro de memoria de usuario para ser utilizada por la interfaz devx.

El verbo de registro expone un objeto UMEM DEVX para el registro de memoria de usuario para DMA. La API para registrar la memoria de usuario recibe como entrada la dirección del usuario, la longitud y las banderas de acceso, y proporciona al usuario como salida un objeto que contiene el ID de UMEM devuelto por el firmware a esta memoria registrada.

El usuario puede solicitar tamaños de página específicos para la dirección y longitud dadas; en ese caso, se debe usar mlx5dv_devx_umem_reg_ex(). Si el kernel no puede encontrar un tamaño de página coincidente del mapa de bits de umem_in->pgsz_bitmap proporcionado, la API fallará.

El usuario utilizará ese ID de UMEM en comandos directos del dispositivo que utilizan esta memoria en lugar de la lista de direcciones físicas, por ejemplo, al crear un QP con mlx5dv_devx_obj_create.

ARGUMENTOS

context
Contexto del dispositivo RDMA en el que se creará la acción.
addr
La dirección de inicio de la memoria a registrar.
size
El tamaño del búfer *addr*.
access
Los atributos de protección de memoria deseados; es 0 o el OR a nivel de bits de uno o más de enum ibv_access_flags.
umem_in
Una estructura que contiene el conjunto de argumentos.
pgsz_bitmap
Representa los tamaños de página requeridos. La creación de umem fallará si no se puede crear con estos tamaños de página.
comp_mask
Banderas que indican los campos adicionales.
dmabuf_fd
Si MLX5DV_UMEM_MASK_DMABUF está establecido en comp_mask, entonces este valor debe ser un FD de un dmabuf. En este modo, el dmabuf se utiliza como la memoria de respaldo para crear el umem. El dmabuf debe ser fijable. addr se interpreta como el desplazamiento de inicio del dmabuf.

VALOR DE RETORNO

En caso de éxito, mlx5dv_devx_umem_reg / mlx5dv_devx_umem_reg_ex devolverá un nuevo objeto struct mlx5dv_devx_umem; en caso de error, devolverá NULL y se establecerá errno.

mlx5dv_devx_umem_dereg devuelve 0 en caso de éxito, o el valor de errno en caso de fallo (que indica la razón del fallo).

VER TAMBIÉN

mlx5dv_open_device(3), ibv_reg_mr(3), mlx5dv_devx_obj_create(3)
