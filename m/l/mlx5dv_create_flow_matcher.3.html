mlx5dv_create_flow_matcher(3) Manual del Programador de mlx5 mlx5dv_create_flow_matcher(3)

NOMBRE

mlx5dv_create_flow_matcher - crea un comparador para ser usado con mlx5dv_create_flow(3)

SINOPSIS

#include <infiniband/mlx5dv.h>
struct mlx5dv_flow_matcher *
mlx5dv_create_flow_matcher(struct ibv_context *context,
               struct mlx5dv_flow_matcher_attr *attr)

DESCRIPCIÓN

mlx5dv_create_flow_matcher() crea un comparador de flujo (máscara) para ser usado con mlx5dv_create_flow(3).

ARGUMENTOS

Por favor, consulte ibv_open_device(3) para context.

attr

struct mlx5dv_flow_matcher_attr {
    enum ibv_flow_attr_type type;
    uint32_t flags; /* De enum ibv_flow_flags */
    uint16_t priority;
    uint8_t match_criteria_enable; /* Formato específico del dispositivo */
    struct mlx5dv_flow_match_parameters *match_mask;
    uint64_t comp_mask;
    enum mlx5dv_flow_table_type ft_type;
    uint32_t ib_port;
};
type
Tipo de comparador a crear: IBV_FLOW_ATTR_NORMAL: Regla normal según la especificación.
flags
Banderas especiales para controlar la regla: 0: Nada o valor cero significa que el comparador almacenará reglas de flujo de entrada. IBV_FLOW_ATTR_FLAGS_EGRESS: Especificado que este comparador almacenará reglas de flujo de salida.
priority
Consulte ibv_create_flow(3).
match_criteria_enable
Qué criterios de coincidencia están configurados en match_mask, pasados en formato específico del dispositivo.

match_mask

struct mlx5dv_flow_match_parameters {
    size_t match_sz;
    uint64_t match_buf[]; /* Formato específico del dispositivo */
};
match_sz
Tamaño en bytes de match_buf.
match_buf
Establece qué máscara se utilizará, pasada en formato específico del dispositivo.
comp_mask
MLX5DV_FLOW_MATCHER_MASK_FT_TYPE para ft_type MLX5DV_FLOW_MATCHER_MASK_IB_PORT para ib_port

ft_type

Especifica en qué tipo de tabla de flujo se almacenarán las reglas de flujo: MLX5DV_FLOW_TABLE_TYPE_NIC_RX: Especificado que este comparador almacenará reglas de flujo de entrada. MLX5DV_FLOW_TABLE_TYPE_NIC_TX: Especificado que este comparador almacenará reglas de flujo de salida. MLX5DV_FLOW_TABLE_TYPE_FDB: Especificado que este comparador almacenará reglas FDB. MLX5DV_FLOW_TABLE_TYPE_RDMA_RX: Especificado que este comparador almacenará reglas de flujo RDMA de entrada. MLX5DV_FLOW_TABLE_TYPE_RDMA_TX: Especificado que este comparador almacenará reglas de flujo RDMA de salida. MLX5DV_FLOW_TABLE_TYPE_RDMA_TRANSPORT_RX: Especificado que este comparador almacenará reglas de flujo de dominio de transporte RDMA. MLX5DV_FLOW_TABLE_TYPE_RDMA_TRANSPORT_TX: Especificado que este comparador almacenará reglas de flujo de dominio de transporte RDMA.

ib_port

Especifica a qué vport se adjuntará el comparador, esto es válido y requerido solo al crear la tabla de flujo de dominio de transporte RDMA de dirección: MLX5DV_FLOW_TABLE_TYPE_RDMA_TRANSPORT_RX MLX5DV_FLOW_TABLE_TYPE_RDMA_TRANSPORT_TX

VALOR DE RETORNO

mlx5dv_create_flow_matcher devuelve un puntero a mlx5dv_flow_matcher; en caso de error, se devolverá NULL y se establecerá errno.

VER TAMBIÉN

ibv_open_device(3), ibv_create_flow(3)
