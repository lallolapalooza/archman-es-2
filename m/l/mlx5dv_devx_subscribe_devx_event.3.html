NOMBRE

mlx5dv_devx_subscribe_devx_event - Suscribirse a través de un canal de eventos para eventos del dispositivo.

mlx5dv_devx_subscribe_devx_event_fd - Suscribirse a través de un canal de eventos para eventos del dispositivo para señalar eventfd.

SINOPSIS

#include <infiniband/mlx5dv.h>
int mlx5dv_devx_subscribe_devx_event(struct mlx5dv_devx_event_channel *dv_event_channel,
                     struct mlx5dv_devx_obj *obj,
                     uint16_t events_sz,
                     uint16_t events_num[],
                     uint64_t cookie)
int mlx5dv_devx_subscribe_devx_event_fd(struct mlx5dv_devx_event_channel *dv_event_channel,
                    int fd,
                    struct mlx5dv_devx_obj *obj,
                    uint16_t event_num)

DESCRIPCIÓN

Suscribirse a través de un canal de eventos DEVX para eventos del dispositivo.

ARGUMENTOS

dv_event_channel
Canal de eventos para suscribirse.
fd
Un descriptor de archivo que previamente fue abierto por la llamada al sistema eventfd().
obj
Objeto DEVX al que se relacionan events_num, puede ser NULL para eventos no afiliados.
events_sz
Tamaño del búfer events_num que contiene los eventos para los que suscribirse.
events_num
Contiene los números de evento requeridos para suscribirse, los números son según la especificación del dispositivo.
cookie
El valor que se devolverá al leer el evento, puede usarse como un ID para uso de la aplicación.

NOTAS

Cuando se utiliza mlx5dv_devx_subscribe_devx_event_fd, el fd será señalado una vez que ocurra un evento.

VER TAMBIÉN

mlx5dv_open_device(3), mlx5dv_devx_create_event_channel(3), mlx5dv_devx_get_event(3)
