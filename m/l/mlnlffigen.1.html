NOMBRE

mlnlffigen - generador de código de pegamento para usar con la nueva interfaz de función externa "NLFFI" para Standard ML y MLton

SINOPSIS

mlnlffigen [opción ...] archivo-C ...

DESCRIPCIÓN

mlnlffigen toma como entrada un archivo fuente C y produce como salida en NLFFI-Generated el código de pegamento para Standard ML y en NLFFI-Generated\nlffi-generated.mlb un archivo del sistema ML Basis.
