NOMBRE

mlx5dv_modify_qp_udp_sport - Modifica el puerto de origen UDP de un QP dado

SINOPSIS

#include <infiniband/mlx5dv.h>
int mlx5dv_modify_qp_udp_sport(struct ibv_qp *qp, uint16_t udp_sport)

DESCRIPCIÓN

El puerto de origen UDP se utiliza para crear entropía para enrutadores de red (ECMP), balanceadores de carga y conmutación de agregación de enlaces 802.3ad que no son conscientes de las cabeceras RoCE IB.

Esta API permite modificar el puerto de origen UDP configurado de un QP RC/UC dado cuando el QP está en estado RTS.

ARGUMENTOS

qp
El objeto ibv_qp sobre el que se realizará la acción.
udp_sport
El puerto de origen UDP a establecer para el QP.

VALOR DEVUELTO

Devuelve 0 en caso de éxito, o el valor de errno en caso de error (que indica el motivo del fallo).
