NOMBRE

mlx5dv_crypto_login_create - Crea un objeto de inicio de sesión criptográfico

mlx5dv_crypto_login_query - Consulta el objeto de inicio de sesión criptográfico dado

mlx5dv_crypto_login_destroy - Destruye el objeto de inicio de sesión criptográfico dado

SINOPSIS

#include <infiniband/mlx5dv.h>
struct mlx5dv_crypto_login_obj *
mlx5dv_crypto_login_create(struct ibv_context *context,
               struct mlx5dv_crypto_login_attr_ex *login_attr);
int mlx5dv_crypto_login_query(struct mlx5dv_crypto_login_obj *crypto_login,
                  struct mlx5dv_crypto_login_query_attr *query_attr);
int mlx5dv_crypto_login_destroy(struct mlx5dv_crypto_login_obj *crypto_login);

DESCRIPCIÓN

Al utilizar un motor criptográfico que se encuentra en el método de importación cifrada, se debe proporcionar un objeto de inicio de sesión criptográfico válido para crear y consultar claves de cifrado cifradas (DEKs).

Un objeto de inicio de sesión criptográfico válido solo es necesario para crear y consultar DEKs cifradas. Las DEKs existentes que se crearon previamente no necesitan un objeto de inicio de sesión criptográfico válido para ser utilizadas (en MKey o durante el tráfico).

mlx5dv_crypto_login_create() crea y devuelve un objeto de inicio de sesión criptográfico con las credenciales dadas en login_attr. Solo se puede crear un objeto de inicio de sesión criptográfico por contexto de dispositivo. El objeto de inicio de sesión criptográfico creado debe proporcionarse a mlx5dv_dek_create() para crear DEKs cifradas.

mlx5dv_crypto_login_query() consulta el objeto de inicio de sesión criptográfico crypto_login y devuelve los atributos consultados en query_attr.

mlx5dv_crypto_login_destroy() destruye el objeto de inicio de sesión criptográfico dado.

ARGUMENTOS

context

El contexto del dispositivo que se asociará con el objeto de inicio de sesión criptográfico.

login_attr

Los atributos extendidos de inicio de sesión criptográfico especifican las credenciales para iniciar sesión y la KEK de importación que se utilizará para las comunicaciones seguras realizadas con el objeto de inicio de sesión criptográfico.

struct mlx5dv_crypto_login_attr_ex {
    uint32_t credential_id;
    uint32_t import_kek_id;
    const void *credential;
    size_t credential_len;
    uint64_t comp_mask;
};
credential_id
Un ID de una credencial, de las credenciales almacenadas en el dispositivo, que indica la credencial que debe validarse frente a la credencial proporcionada en credential.
import_kek_id
Un ID de una KEK de importación, de las KEKs de importación almacenadas en el dispositivo, que indica la KEK de importación que se utilizará para descifrar las credenciales proporcionadas en credential y también para todas las demás comunicaciones seguras realizadas con el objeto de inicio de sesión criptográfico.
credential
Las credenciales para iniciar sesión. La credencial es un fragmento de datos utilizado para autenticar al usuario para el inicio de sesión criptográfico. La credencial en credential se valida frente a la credencial indicada por credential_id, que está almacenada en el dispositivo. Las credenciales deben coincidir para que el inicio de sesión criptográfico sea exitoso. credential debe proporcionarse cifrada mediante el algoritmo de envoltura de claves AES utilizando la KEK de importación indicada por import_kek_id. El formato de credential es ENC(iv_64b + plaintext_credential) donde ENC() es el algoritmo de envoltura de claves AES y iv_64b es 0xA6A6A6A6A6A6A6A6 según la especificación de envoltura de claves AES NIST SP 800-38F, y plaintext_credential es el valor de la credencial almacenado en el dispositivo.
credential_len
La longitud del valor credential proporcionado en bytes.
comp_mask
Reservado para futuras extensiones, debe ser 0 por ahora.

query_attr

Atributos de inicio de sesión criptográfico a poblar al consultar un objeto de inicio de sesión criptográfico.

struct mlx5dv_crypto_login_query_attr {
    enum mlx5dv_crypto_login_state state;
    uint64_t comp_mask;
};
state
El estado del objeto de inicio de sesión criptográfico, puede ser uno de los siguientes:
MLX5DV_CRYPTO_LOGIN_STATE_VALID
El objeto de inicio de sesión criptográfico es válido y puede ser utilizado.
MLX5DV_CRYPTO_LOGIN_STATE_INVALID
El objeto de inicio de sesión criptográfico es inválido y no puede ser utilizado. Un objeto de inicio de sesión criptográfico válido puede volverse inválido si la credencial o la KEK de importación utilizada en el objeto de inicio de sesión criptográfico se eliminaron mientras estaban en uso (por ejemplo, por un oficial criptográfico). En este caso, se debe llamar a mlx5dv_crypto_login_destroy() para destruir el objeto de inicio de sesión criptográfico inválido y, si aún es necesario, se debe llamar a mlx5dv_crypto_login_create() para crear un nuevo objeto de inicio de sesión criptográfico con una credencial y KEK de importación válidas.
comp_mask
Reservado para futuras extensiones, debe ser 0 por ahora.

VALOR DE RETORNO

mlx5dv_crypto_login_create() devuelve un puntero a un nuevo struct mlx5dv_crypto_login_obj válido en caso de éxito. En caso de error, devuelve NULL y se establece errno.

mlx5dv_crypto_login_query() devuelve 0 en caso de éxito y rellena query_attr con los atributos consultados. En caso de error, devuelve errno.

mlx5dv_crypto_login_destroy() devuelve 0 en caso de éxito y errno en caso de error.

VER TAMBIÉN

mlx5dv_dek_create(3), mlx5dv_query_device(3)
