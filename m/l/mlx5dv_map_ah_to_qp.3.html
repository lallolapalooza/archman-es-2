mlx5dv_map_ah_to_qp(3) Manual de funciones de la biblioteca mlx5dv_map_ah_to_qp(3)

NOMBRE

mlx5dv_map_ah_to_qp - Mapea la información de la ruta de destino en el descriptor de dirección (AH) a la información extraída del qp.

SINOPSIS

#include <infiniband/mlx5dv.h>
int mlx5dv_map_ah_to_qp(struct ibv_ah *ah, uint32_t qp_num);

DESCRIPCIÓN

Esta API mapea la información de la ruta de destino en el descriptor de dirección (ah) a la información extraída del qp (por ejemplo, control de congestión de ECE).

Esta API sirve como una mejora para los QPs de DC y UD para lograr un mejor rendimiento utilizando algoritmos de control de congestión (CC) por dirección, permitiendo a los QPs de DC/UD utilizar múltiples algoritmos de CC en el mismo centro de datos.

El mapeo creado por esta API se destruye implícitamente cuando se destruye el descriptor de dirección. No se ve afectado por la destrucción del QP qp_num.

Se ignora un mapeo duplicado al mismo descriptor de dirección. Como esta API es solo una sugerencia para el hardware, en este caso no haría nada y devolvería éxito independientemente de la nueva ECE de qp_num.

La función debe llamarse después de que la negociación/preconfiguración de ECE se haya realizado por algún medio externo.

ARGUMENTOS

ah
El descriptor de dirección del destino.
qp_num
El QP iniciador del cual se extrae la información de control de congestión de su ECE.

VALOR DE RETORNO

Al tener éxito, devuelve 0; en caso de error, se devuelve el valor de errno.

VER TAMBIÉN

rdma_cm(7), rdma_get_remote_ece(3), ibv_query_ece(3), ibv_set_ece(3)
