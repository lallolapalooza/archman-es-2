NOMBRE

mlx5dv_modify_qp_lag_port - Modificar la información del puerto LAG de un QP dado

SINOPSIS

#include <infiniband/mlx5dv.h>
int mlx5dv_modify_qp_lag_port(struct ibv_qp *qp, uint8_t port_num);

DESCRIPCIÓN

Esta API permite modificar el número de puerto configurado de un QP dado.

Si el estado del QP se modifica posteriormente, el número de puerto puede ser reconfigurado implícitamente.

Utilice la consulta mlx5dv_query_qp_lag_port para comprobar los valores del número de puerto configurados y activos.

ARGUMENTOS

qp
El objeto ibv_qp sobre el cual realizar la acción.
port_num
El número de puerto a establecer para el QP.

VALOR DE RETORNO

0 en caso de éxito; EOPNOTSUPP si no está en modo LAG, u otro valor de errno en caso de otros fallos.

VER TAMBIÉN

mlx5dv_query_qp_lag_port(3)
