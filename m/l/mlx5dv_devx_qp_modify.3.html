DESCRIPCIÓN

Modifica/consulta un objeto de verbos a través de la interfaz DEVX.

La API DEVX permite el acceso directo desde el área del espacio de usuario al controlador de dispositivos mlx5 utilizando el mecanismo KABI. El propósito principal es hacer que el controlador del espacio de usuario sea lo más independiente posible del kernel para que la funcionalidad y los comandos futuros del dispositivo puedan activarse con cambios mínimos o nulos en el kernel.

Las API anteriores permiten modificar/consultar un objeto de verbos a través de la interfaz DEVX. Esto permite la interoperabilidad entre verbos y DEVX. Como tal, una aplicación puede usar el método de creación de verbos (por ejemplo, ibv_create_qp) y modificar y consultar el objeto creado a través de DEVX (por ejemplo, mlx5dv_devx_qp_modify).

ARGUMENTOS

qp/cq/wq/srq/ind_tbl
El objeto ibv_xxx sobre el cual ejecutar la acción.
in
Un búfer que contiene los datos de entrada del comando proporcionados en un formato de especificación de dispositivo.
inlen
El tamaño del búfer in en bytes.
out
Un búfer que contiene los datos de salida del comando de acuerdo con el formato de especificación de dispositivo.
outlen
El tamaño del búfer out en bytes.

VALOR DE RETORNO

Al éxito, se devuelve 0 o el valor de errno en caso de fallo.

Si el valor de error es EREMOTEIO, outbox.status y outbox.syndrome contendrán los detalles del fallo del comando.

VER TAMBIÉN

mlx5dv_open_device, mlx5dv_devx_obj_create
