NOMBRE

mlx5dv_open_device - Abrir un contexto de dispositivo RDMA para el proveedor mlx5

SINOPSIS

#include <infiniband/mlx5dv.h>
struct ibv_context *
mlx5dv_open_device(struct ibv_device *device, struct mlx5dv_context_attr *attr);

DESCRIPCIÓN

Abrir un contexto de dispositivo RDMA con atributos específicos del proveedor mlx5.

ARGUMENTOS

device
Dispositivo RDMA a abrir.

attr

mlx5dv_context_attr

struct mlx5dv_context_attr {
        uint32_t flags;
        uint64_t comp_mask;
        struct ibv_fd_arr *fds;
};
flags
Una combinación OR bit a bit de los diversos valores descritos a continuación.
*MLX5DV_CONTEXT_FLAGS_DEVX*:
Asignar un contexto DEVX
comp_mask
Máscara de bits que especifica qué campos de la estructura son válidos
*MLX5DV_CONTEXT_ATTR_MASK_FD_ARRAY*:
Valor válido en *fds*
fds
Utilizado para pasar un array de descriptores de archivo.

ibv_fd_arr

struct ibv_fd_arr {
        int *arr;
        uint32_t count;
};
arr
Puntero al array de descriptores de archivo.
count
Número de elementos en el array.

VALOR DE RETORNO

Devuelve un puntero al contexto del dispositivo asignado, o NULL si la solicitud falla.

VER TAMBIÉN
