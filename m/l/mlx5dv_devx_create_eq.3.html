mlx5dv_devx_create_eq(3) Manual del Programador de mlx5 mlx5dv_devx_create_eq(3)

NOMBRE

mlx5dv_devx_create_eq - Crear un objeto EQ

mlx5dv_devx_destroy_eq - Destruir un objeto EQ

SINOPSIS

#include <infiniband/mlx5dv.h>
struct mlx5dv_devx_eq *
mlx5dv_devx_create_eq(struct ibv_context *ibctx, const void *in, size_t inlen,
              void *out, size_t outlen);
int mlx5dv_devx_destroy_eq(struct mlx5dv_devx_eq *eq);

DESCRIPCIÓN

Crea / Destruye un objeto EQ. Tras la creación, el llamante prepara los buzones de entrada/salida basándose en el formato de especificación del dispositivo; para el buzón de entrada, el llamante debe preparar todos los campos excepto “eqc.log_page_size” y la lista pas, que serán establecidos por el controlador. El campo “eqc.intr” debe utilizarse a partir de la salida de mlx5dv_devx_alloc_msi_vector().

ARGUMENTOS

ibctx
Contexto del dispositivo RDMA para crear la acción.
in
Un búfer que contiene los datos de entrada del comando proporcionados en un formato de especificación del dispositivo.
inlen
El tamaño del búfer in en bytes.
out
Un búfer que contiene los datos de salida del comando según el formato de especificación del dispositivo.
outlen
El tamaño del búfer out en bytes.
eq
El objeto EQ sobre el que trabajar.
struct mlx5dv_devx_eq {
    void *vaddr;
};
vaddr
Dirección virtual del EQ asignada en el controlador para.

NOTAS

mlx5dv_devx_query_eqn() no admitirá vectores que sean utilizados por mlx5dv_devx_create_eq().

VALOR DE RETORNO

En caso de éxito, mlx5dv_devx_create_eq devolverá un nuevo struct mlx5dv_devx_eq; en caso de error, se devolverá NULL y se establecerá errno.

En caso de éxito, mlx5dv_devx_destroy_eq devolverá 0, en caso de error se devolverá errno.

Si el valor de error es EREMOTEIO, outbox.status y outbox.syndrome contendrán los detalles del fallo del comando.

VER TAMBIÉN

mlx5dv_devx_alloc_msi_vector(3), mlx5dv_devx_query_eqn(3)
