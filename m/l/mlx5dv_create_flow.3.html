mlx5dv_create_flow(3) Manual del Programador de mlx5 mlx5dv_create_flow(3)

NOMBRE

mlx5dv_create_flow - crea una regla de flujo de direccionamiento

SINOPSIS

#include <infiniband/mlx5dv.h>
struct ibv_flow *
mlx5dv_create_flow(struct mlx5dv_flow_matcher *flow_matcher,
           struct mlx5dv_flow_match_parameters *match_value,
           size_t num_actions,
           struct mlx5dv_flow_action_attr actions_attr[])

DESCRIPCIÓN

mlx5dv_create_flow() crea una regla de flujo de direccionamiento con la capacidad de especificar propiedades específicas del controlador.

ARGUMENTOS

Por favor, consulte mlx5dv_create_flow_matcher(3) para flow_matcher y match_value.

num_actions
Especifica cuántas acciones se pasan en actions_attr

actions_attr

struct mlx5dv_flow_action_attr {
    enum mlx5dv_flow_action_type type;
    union {
        struct ibv_qp *qp;
        struct ibv_counters *counter;
        struct ibv_flow_action *action;
        uint32_t tag_value;
        struct mlx5dv_devx_obj *obj;
        struct {
            struct mlx5dv_devx_obj *obj;
            uint32_t offset;
        } bulk_obj;
    };
};
type
MLX5DV_FLOW_ACTION_DEST_IBV_QP El QP pasado recibirá los paquetes coincidente. MLX5DV_FLOW_ACTION_IBV_FLOW_ACTION La acción de flujo a aplicar. MLX5DV_FLOW_ACTION_TAG Etiqueta de flujo a proporcionar en la finalización del trabajo. MLX5DV_FLOW_ACTION_DEST_DEVX El objeto de destino DEVX para los paquetes coincidentes. MLX5DV_FLOW_ACTION_COUNTERS_DEVX El objeto de contador DEVX para los paquetes coincidentes. MLX5DV_FLOW_ACTION_DEFAULT_MISS Direcciona el paquete al destino de fallo predeterminado. MLX5DV_FLOW_ACTION_DROP La acción es descartar el paquete coincidente. MLX5DV_FLOW_ACTION_COUNTERS_DEVX_WITH_OFFSET El objeto de contador DEVX masivo y su compensación de contador para los paquetes coincidentes.
qp
QP pasado, a utilizar con type MLX5DV_FLOW_ACTION_DEST_IBV_QP.
action
Acción de flujo, a utilizar con type MLX5DV_FLOW_ACTION_IBV_FLOW_ACTION consulte mlx5dv_create_flow_action_modify_header(3) y mlx5dv_create_flow_action_packet_reformat(3).
tag_value
valor de etiqueta a pasar en la finalización del trabajo, a utilizar con type MLX5DV_FLOW_ACTION_TAG consulte ibv_create_cq_ex(3).
obj
Objeto DEVX, a utilizar con type MLX5DV_FLOW_ACTION_DEST_DEVX o por MLX5DV_FLOW_ACTION_COUNTERS_DEVX o por MLX5DV_FLOW_ACTION_COUNTERS_DEVX_WITH_OFFSET.
offset
compensación al contador de destino dentro de un objeto DEVX masivo, a utilizar con type MLX5DV_FLOW_ACTION_COUNTERS_DEVX_WITH_OFFSET

VALOR DE RETORNO

mlx5dv_create_flow devuelve un puntero a la regla de flujo creada, en caso de error, devolverá NULL y se establecerá errno.

VER TAMBIÉN

mlx5dv_create_flow_action_modify_header(3), mlx5dv_create_flow_action_packet_reformat(3), mlx5dv_create_flow_matcher(3), mlx5dv_create_qp(3), ibv_create_qp_ex(3) ibv_create_cq_ex(3) ibv_create_counters(3)
