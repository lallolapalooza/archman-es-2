NOMBRE

mlx5dv_flow_action_esp - Acción de flujo esp para el proveedor mlx5

SINOPSIS

#include <infiniband/mlx5/mlx5dv.h>
struct ibv_flow_action *
mlx5dv_create_flow_action_esp(struct ibv_context *ctx,
                  struct ibv_flow_action_esp_attr *esp,
                  struct mlx5dv_flow_action_esp *mlx5_attr);

DESCRIPCIÓN

Crea una acción de dirección de flujo IPSEC ESP.

Este verbo es idéntico al verbo ibv_create_flow_action_esp, pero permite banderas específicas de mlx5.

ARGUMENTOS

Por favor, consulte la página del manual ibv_flow_action_esp(3) para ctx y esp.

Argumento mlx5_attr

struct mlx5dv_flow_action_esp {
    uint64_t comp_mask;  /* Usar enum mlx5dv_flow_action_esp_mask */
    uint32_t action_flags; /* Usar enum mlx5dv_flow_action_flags */
};
comp_mask
Máscara de bits que especifica qué campos en la estructura son válidos (enum mlx5dv_flow_action_esp_mask).
action_flags
Un OR a nivel de bits de los diversos valores descritos a continuación.

MLX5DV_FLOW_ACTION_FLAGS_REQUIRE_METADATA:

Se espera que cada paquete recibido y transmitido que utilice la descarga lleve metadatos en forma de encabezado L2

con tipo de Ethernet 0x8CE4, seguido de 6 bytes de datos y el tipo de Ethernet original del paquete.

NOTA

Se espera que el ESN se coloque en el campo IV para los paquetes de salida.

El número de secuencia de 64 bits se escribe en big-endian sobre el campo IV de 64 bits.

No es necesario llamar a modificar para actualizar la ventana ESN en la salida cuando se utiliza este DV.
