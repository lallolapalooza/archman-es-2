NOMBRE

ml-ulex - un generador de analizador léxico compatible con Unicode para Standard ML

SINOPSIS

ml-ulex [OPCIONES] archivo

DESCRIPCIÓN

ML-Ulex es un generador de lexers que soporta caracteres Unicode (en representación UTF-8) y una forma extendida de expresiones regulares.

OPCIONES

-32

ejecutar la versión de 32 bits del programa (actualmente la predeterminada).

-64

ejecutar la versión de 64 bits del programa. Esta opción solo se aplica a la arquitectura x86-64 (también conocida como amd64).

--dot

generar salida DOT ( http://www.graphviz.org). El archivo generado se llamará archivo.dot, donde archivo es el archivo de entrada.

--match

entrar en modo de coincidencia interactivo. Esto permitirá probar interactivamente la máquina; actualmente, solo el estado de inicio INITIAL está disponible para pruebas (ver la Guía del usuario http://www.smlnj.org/doc/ml-lpt/manual.pdf para más detalles sobre los estados de inicio).

--ml-lex-mode

operar en modo de compatibilidad con ml-lex.

--table-based

generar un lexer basado en tablas.

--fn-based

generar un lexer que representa estados como funciones y transiciones como llamadas de cola.

--minimize

generar una máquina mínima. Tenga en cuenta que esto es lento y casi nunca es necesario.

--strict-sml

generar SML estricto (es decir, no usar extensiones de SML/NJ). Esta bandera es útil si desea usar la salida con un sistema SML diferente.
