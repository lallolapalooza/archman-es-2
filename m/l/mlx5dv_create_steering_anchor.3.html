NOMBRE

mlx5dv_create_steering_anchor - Crea un ancla de dirección

mlx5dv_destroy_steering_anchor - Destruye un ancla de dirección

SINOPSIS

#include <infiniband/mlx5dv.h>
struct mlx5dv_steering_anchor *
mlx5dv_create_steering_anchor(struct ibv_context *context,
                              struct mlx5dv_steering_anchor_attr *attr);
int mlx5dv_destroy_steering_anchor(struct mlx5dv_steering_anchor *sa);

DESCRIPCIÓN

Un usuario puede tomar paquetes en un sandbox configurado por el usuario y realizar un procesamiento de paquetes al final del cual se toma una decisión de la canalización de dirección sobre qué hacer con el paquete.

Un ancla de dirección permite al usuario reinyectar el paquete en el kernel para un procesamiento adicional.

mlx5dv_create_steering_anchor() Crea un ancla que permitirá inyectar el paquete de nuevo en la canalización de dirección del kernel.

mlx5dv_destroy_steering_anchor() Destruye un ancla de dirección.

ARGUMENTOS

context

El contexto del dispositivo al que se asociará el ancla de dirección.

attr

Los atributos del ancla especifican la prioridad y el tipo de tabla de flujo a la que apuntará el ancla.

struct mlx5dv_steering_anchor_attr {
        enum mlx5dv_flow_table_type ft_type;
        uint16_t priority;
        uint64_t comp_mask;
};
ft_type
El tipo de tabla de flujo a la que apuntará el ancla.
priority
La prioridad dentro de ft_type a la que apuntará el ancla creada.
comp_mask
Reservado para futuras extensiones, debe ser 0 por ahora.

mlx5dv_steering_anchor

struct mlx5dv_steering_anchor {
    uint32_t id;
};
id
El ID de la tabla de flujo a utilizar como destino al crear la entrada de la tabla de flujo.

VALOR DE RETORNO

mlx5dv_create_steering_anchor() devuelve un puntero a un nuevo mlx5dv_steering_anchor en caso de éxito. En caso de error, devuelve NULL y establece errno.

mlx5dv_destroy_steering_anchor() devuelve 0 en caso de éxito y el valor de errno en caso de error.
