mlx5dv_devx_alloc_msi_vector(3) Manual del programador de mlx5 mlx5dv_devx_alloc_msi_vector(3)

NOMBRE

mlx5dv_devx_alloc_msi_vector - Asigna un vector msi para ser utilizado para crear un EQ.

mlx5dv_devx_free_msi_vector - Libera un vector msi.

SINOPSIS

#include <infiniband/mlx5dv.h>
struct mlx5dv_devx_msi_vector *
mlx5dv_devx_alloc_msi_vector(struct ibv_context *ibctx);
int mlx5dv_devx_free_msi_vector(struct mlx5dv_devx_msi_vector *msi);

DESCRIPCIÓN

Asigna o libera un vector msi para ser utilizado para crear un EQ.

La API de asignación expone un objeto mlx5dv_devx_msi_vector, que incluye un vector msi y un fd. El vector puede ser utilizado como el campo “eqc.intr” al crear un EQ, mientras que el fd (creado como no bloqueante) puede ser consultado para ver cuando hay datos en ese EQ.

ARGUMENTOS

ibctx
Contexto del dispositivo RDMA para crear la acción.
msi
El objeto vector msi sobre el que trabajar.

vector_msi

struct mlx5dv_devx_msi_vector {
    int vector;
    int fd;
};
vector
El vector a ser utilizado al crear el EQ sobre la especificación del dispositivo.
fd
El FD que se utilizará para la consulta.

VALOR DE RETORNO

En caso de éxito, mlx5dv_devx_alloc_msi_vector devolverá un nuevo struct mlx5dv_devx_msi_vector; en caso de error, devolverá NULL y se establecerá errno.

En caso de éxito, mlx5dv_devx_free_msi_vector devolverá 0, en caso de error, devolverá errno.
