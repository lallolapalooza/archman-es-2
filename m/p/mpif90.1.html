mpicc, mpic++, mpicxx, mpifort, mpijavac — Compiladores envoltorio de Open MPI

SINTAXIS

mpicc [--showme | --showme:compile | --showme:link] ...

mpic++ [--showme | --showme:compile | --showme:link] ...

mpicxx [--showme | --showme:compile | --showme:link] ...

mpifort [--showme | --showme:compile | --showme:link] ...

mpijavac [--showme | --showme:compile | --showme:link] ...

Los siguientes comandos obsoletos también están disponibles, pero se debe usar mpifort en su lugar:

mpif77 [--showme | --showme:compile | --showme:link] ...

mpif90 [--showme | --showme:compile | --showme:link] ...

En sistemas de archivos sensibles a mayúsculas y minúsculas, el siguiente comando también estará disponible:

mpiCC [--showme | --showme:compile | --showme:link] ...

OPCIONES

Las opciones a continuación se aplican a todos los compiladores envoltorio:

•
--showme: Esta opción tiene varias variantes diferentes (ver abajo). Ninguna de las variantes invoca al compilador subyacente; todas proporcionan información sobre cómo se habría invocado el compilador subyacente si --showme no se hubiera utilizado. La opción básica --showme muestra la línea de comandos que se ejecutaría para compilar el programa.

NOTA:

Si se pasa un argumento que no es un nombre de archivo en la línea de comandos, la opción --showme *no* mostrará ninguna bandera adicional. Por ejemplo, tanto "mpicc --showme como mpicc --showme my_source.c mostrarán todas las banderas proporcionadas por el envoltorio. Pero mpicc --showme -v solo mostrará el nombre del compilador subyacente y -v.
  • --showme:compile: Muestra las banderas del compilador que se habrían proporcionado al compilador subyacente.
  • --showme:link: Muestra las banderas del enlazador que se habrían proporcionado al compilador subyacente.
  • --showme:command: Muestra el comando del compilador subyacente (que puede ser uno o varios tokens).
  • --showme:incdirs: Muestra una lista de directorios delimitados por espacios (pero por lo demás sin decorar) que el compilador envoltorio habría proporcionado al compilador subyacente para indicar dónde se encuentran los archivos de cabecera relevantes.
  • --showme:libdirs: Muestra una lista de directorios delimitados por espacios (pero por lo demás sin decorar) que el compilador envoltorio habría proporcionado al enlazador subyacente para indicar dónde se encuentran las bibliotecas relevantes.
  • --showme:libs: Muestra una lista de nombres de bibliotecas delimitados por espacios (pero por lo demás sin decorar) que el compilador envoltorio habría utilizado para enlazar una aplicación. Por ejemplo: mpi open-pal util.
  • --showme:version: Muestra el número de versión de Open MPI.
  • --showme:help: Muestra un breve mensaje de ayuda de uso.

Consulte la página del manual de su compilador subyacente para otras opciones que se pueden pasar a través de mpicc.

DESCRIPCIÓN

Conceptualmente, el papel de estos comandos es bastante simple: añadir de forma transparente las banderas de compilador y enlazador relevantes a la línea de comandos del usuario que son necesarias para compilar / enlazar programas de Open MPI, y luego invocar al compilador subyacente para realizar realmente el comando.

Como tales, estos comandos a menudo se denominan compiladores "envoltorio" porque en realidad no compilan ni enlazan aplicaciones por sí mismos; solo agregan banderas a la línea de comandos e invocan al compilador de backend.

ANTECEDENTES

Open MPI proporciona compiladores envoltorio para varios idiomas:

  • mpicc: C
  • mpic++, mpicxx (y en sistemas con sistemas de archivos sensibles a mayúsculas y minúsculas, mpiCC): C++

    NOTA:

mpic++, mpicxx y mpiCC invocan el mismo compilador C++ subyacente con las mismas opciones. Todos se proporcionan como compatibilidad con otras implementaciones de MPI.
  • mpifort (y sus alias heredados/obsoletos mpif77 y mpif90): Fortran
  • mpijavac: Java

Los compiladores envoltorio para cada uno de los idiomas son idénticos; se pueden usar indistintamente. Los diferentes nombres se proporcionan únicamente para la compatibilidad con versiones anteriores.

NOTAS DE FORTRAN

El compilador envoltorio de Fortran para MPI (mpifort, y sus nombres heredados/obsoletos mpif77 y mpif90) puede compilar y enlazar aplicaciones MPI que utilizan cualquiera/todos los enlaces Fortran de MPI: mpif.h, el módulo mpi y el módulo mpi_f08 (suponiendo que Open MPI se instaló con soporte para cada uno de estos enlaces Fortran). Específicamente: ya no es necesario usar compiladores envoltorio diferentes para aplicaciones que usan mpif.h frente a aplicaciones que usan el módulo mpi; solo use mpifort para todas las aplicaciones MPI de Fortran.

Tenga en cuenta, sin embargo, que el compilador Fortran puede requerir opciones de línea de comandos adicionales para forzar un dialecto Fortran específico. Por ejemplo, en algunas versiones del compilador IBM XLF, -qfixed puede ser necesario para compilar archivos fuente Fortran de formato fijo si xlf90 es el compilador Fortran subyacente.

Finalmente, tenga en cuenta que mpifort estará inoperativo y devolverá un error de uso si el soporte Fortran no se compiló en la capa MPI.

VISIÓN GENERAL

mpicc es un envoltorio de conveniencia para el compilador C subyacente. La traducción de un programa Open MPI requiere el enlace de las bibliotecas específicas de Open MPI que pueden no residir en uno de los directorios de búsqueda estándar de ld(1). A menudo también requiere la inclusión de archivos de cabecera que pueden no encontrarse en una ubicación estándar.

mpicc pasa sus argumentos al compilador C subyacente junto con las opciones -I, -L y -l requeridas por los programas Open MPI.

Lo mismo ocurre con todos los demás compiladores envoltorio de idioma.

El Equipo de Open MPI recomienda *encarecidamente* usar los compiladores envoltorio en lugar de intentar enlazar las bibliotecas de Open MPI manualmente. Esto permite que la implementación específica de Open MPI cambie sin forzar cambios en las directivas del enlazador en los Makefiles de los usuarios. De hecho, el conjunto específico de banderas y bibliotecas utilizado por los compiladores envoltorio depende de cómo se configuró y compiló Open MPI; los valores pueden cambiar entre diferentes instalaciones de la misma versión de Open MPI.

De hecho, dado que los envoltorios son simplemente capas delgadas sobre un compilador subyacente, hay muy, muy pocas razones convincentes para *no* usar los compiladores envoltorio de Open MPI. Cuando no es posible usar los envoltorios directamente, se deben usar las opciones --showme:compile y --showme:link para determinar qué banderas usarían los envoltorios. Por ejemplo:

shell$ cc -c file1.c `mpicc --showme:compile`
shell$ cc -c file2.c `mpicc --showme:compile`
shell$ cc file1.o file2.o `mpicc --showme:link` -o mi_programa_mpi

NOTAS

Es posible hacer que los compiladores envoltorio sean conscientes de múltiples bibliotecas. Es decir, las bibliotecas e inclusiones especificadas pueden diferir según las banderas del compilador especificadas (por ejemplo, con los compiladores GNU en Linux, se puede usar una ruta de biblioteca diferente si se ve -m32 en comparación con -m64). Este no es el comportamiento predeterminado en una compilación estándar, pero se puede activar (por ejemplo, en un paquete binario que proporcione soporte de 32 y 64 bits). *Más información se puede encontrar aquí*.

ARCHIVOS

Las cadenas que los compiladores envoltorio insertan en la línea de comandos antes de invocar al compilador subyacente se almacenan en un archivo de texto creado por Open MPI e instalado en $pkgdata/NOMBRE-wrapper-data.txt, donde:

  • $pkgdata es típicamente $prefix/share/openmpi
  • $prefix es el directorio de instalación superior de Open MPI
  • NOMBRE es el nombre del compilador envoltorio (por ejemplo, $pkgdata/mpicc-wrapper-data.txt)

FILES

The compiler wrappers are configured by default using files located in the Open MPI installation prefix. Specifically:

<prefix>/share/openmpi/openmpif90-wrapper-data.txt

<prefix>/share/openmpi/openmpifort-wrapper-data.txt

It is rarely necessary to edit these files, but they can be examined to gain insight into what flags the wrappers are placing on the command line.

ENVIRONMENT VARIABLES

By default, the wrappers use the compilers that were selected when Open MPI was configured. These compilers were either found automatically by Open MPI’s “configure” script, or were selected by the user in the CC, CXX, and/or FC environment variables before configure was invoked. Additionally, other arguments specific to the compiler may have been selected by configure.

These values can be selectively overridden by either editing the text files containing this configuration information (see the FILES section), or by setting selected environment variables of the form ompi_value.

Valid value names are:

  • CPPFLAGS: Flags added when invoking the preprocessor (C or C++)
  • LDFLAGS: Flags added when invoking the linker (C, C++, or Fortran)
  • LIBS: Libraries added when invoking the linker (C, C++, or Fortran)
  • CC: C compiler
  • CFLAGS: C compiler flags
  • CXX: C++ compiler
  • CXXFLAGS: C++ compiler flags
  • FC: Fortran compiler
  • FCFLAGS: Fortran compiler flags
