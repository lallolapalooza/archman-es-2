Paquete: libmp4v2

Licencias: MPL

MP4TAGS(-) Mayo 2023 MP4TAGS(-)

NOMBRE

mp4tags - MP4v2 - página del manual para mp4tags - MP4v2 2.1.3

SINOPSIS

mp4tags OPCIÓN... ARCHIVO...

DESCRIPCIÓN

Añade o modifica etiquetas compatibles con iTunes en archivos MP4.

-ayuda
Muestra este texto de ayuda y sale
-version
Muestra información de la versión y sale
-A, -album
STR Establece el título del álbum
-a, -artista
STR Establece la información del artista
-b, -tempo
NUM Establece el tempo (pulsaciones por minuto)
-c, -comentario
STR Establece un comentario general
-C, -copyright
STR Establece la información de copyright
-d, -disco
NUM Establece el número de disco
-D, -discos
NUM Establece el número de discos
-e, -codificadopor
STR Establece el nombre de la persona o empresa que codificó el archivo
-E, -herramienta
STR Establece el software utilizado para la codificación
-g, -genero
STR Establece el nombre del género
-G, -agrupacion
STR Establece el nombre de la agrupación
-H, -hdvideo
NUM Establece el indicador HD (0/1)
-i, -tipo
STR Establece el Tipo de Medio (serie, película, música, ...)
-I, -contentid
NUM Establece el ID de contenido
-j, -generoid
NUM Establece el ID de género
-l, -descripcionlarga
STR Establece la descripción larga
-L, -letras
NUM Establece las letras
-m, -descripcion
STR Establece la descripción corta
-M, -episodio
NUM Establece el número de episodio
-n, -temporada
NUM Establece el número de temporada
-N, -red
STR Establece la red de TV
-o, -episodioid
STR Establece el ID del episodio de TV
-O, -categoria
STR Establece la categoría
-p, -playlistid
NUM Establece el ID de la lista de reproducción
-P, -imagen
PTH Establece la imagen como .png
-B, -podcast
NUM Establece el indicador de podcast.
-R, -artistaalbum
STR Establece el artista del álbum
-s, -cancion
STR Establece el título de la canción
-S -programa
STR Establece el programa de TV
-t, -pista
NUM Establece el número de pista
-T, -pistas
NUM Establece el número de pistas
-x, -xid
STR Establece el xid globalmente único (proveedor:esquema:id)
-X, -calificacion
STR Establece la Calificación (ninguna, limpia, explícita)
-w, -compositor
STR Establece la información del compositor
-y, -año
NUM Establece la fecha de lanzamiento
-z, -artistaid
NUM Establece el ID del artista
-Z, -compositorid
NUM Establece el ID del compositor
-nombressort
STR Establece el nombre para ordenar
-artistasort
STR Establece el artista para ordenar
-albumsort
STR Establece el álbum para ordenar
-programatvsort
STR Establece el programa de TV para ordenar
-artistaalbumsort STR
Establece el artista del álbum para ordenar
-compositoresort
STR Establece el compositor para ordenar
-fechacompra
STR Establece la fecha de compra
-r, -eliminar
STR Elimina etiquetas por código (p.ej. "-r comentario,cancion" o "-r cs" elimina las etiquetas de comentario y canción)
