NOMBRE

mpc - Documentación de mpc

DESCRIPCIÓN

mpc es un cliente de línea de comandos para el Music Player Daemon (MPD). Se conecta a un MPD y lo controla de acuerdo con los comandos y argumentos que se le pasan. Si no se proporciona ningún comando, se imprime el estado actual (igual que "mpc status").

SINOPSIS

mpc [opciones] <comando> [--] [<argumentos>]

Después de --, todos los parámetros se consideran argumentos, no opciones, incluso si comienzan con un guion.

OPCIONES

-f, --formato
Configura el formato utilizado para mostrar las canciones.

Los delimitadores de metadatos son:

Nombre Descripción
%nombre% Un nombre para esta canción. Este no es el título de la canción. El significado exacto de esta etiqueta no está bien definido. A menudo es utilizada por estaciones de radio por internet mal configuradas con etiquetas rotas para meter tanto el nombre del artista como el título de la canción en una sola etiqueta.
%artista% Etiqueta de artista del archivo
%album% Etiqueta de álbum del archivo
%albumartist% Etiqueta de artista del álbum del archivo
%comentario% Etiqueta de comentario del archivo (no habilitada por defecto en metadata_to_use de mpd.conf)
%compositor% Etiqueta de compositor del archivo
%fecha% Etiqueta de fecha del archivo
%fechaoriginal% Etiqueta de fecha original del archivo
%disco% Etiqueta de disco del archivo
%genero% Etiqueta de género del archivo
%interprete% Etiqueta de intérprete del archivo
%titulo% Etiqueta de título del archivo
%pista% Etiqueta de pista del archivo
%tiempo% Duración del archivo
%archivo% Ruta del archivo, relativa a la variable music_directory de MPD
%posicion% Número de pista en la cola
%id% Número de ID de pista en la cola
%prio% Prioridad en la cola (aleatoria).
%mtime% Fecha y hora de la última modificación del archivo
%mdate% Fecha de la última modificación del archivo
%audioformat% El formato de audio de la canción.

El operador [] se utiliza para agrupar la salida de tal manera que si no se encuentran o coinciden delimitadores de metadatos entre [ y ], entonces no se imprime ninguno de los caracteres entre [ y ]. & y | son operadores lógicos para 'y' y 'o'. # se utiliza para escapar caracteres. Algunos ejemplos útiles para el formato son: "%archivo%" y "[[%artista% - ]%titulo%|[%archivo%]". Este comando también toma las siguientes secuencias de escape definidas:

\ barra invertida
\[ corchete izquierdo
\] corchete derecho
\a alarma (campanilla)
\b retroceso (backspace)
\e escape
\t tabulación
\n nueva línea
\v tabulación vertical
\f salto de página
\r retorno de carro

Si no se proporciona, se utiliza el valor de la variable de entorno MPC_FORMAT.

--esperar
Espera a que la operación termine (por ejemplo, actualización de la base de datos).
--rango=[INICIO]:[FIN]

Consulte la documentación del protocolo MPD para obtener más detalles. Esta sintaxis también se puede usar con find y findadd. (Requiere libmpdclient 2.16 y MPD 0.21)

find <tipo> <consulta> [<tipo> <consulta>]... - Igual que
search, pero los valores de las etiquetas deben coincidir exactamente con consulta en lugar de realizar una coincidencia de subcadena.
findadd <tipo> <consulta> [<tipo> <consulta>]... - Igual que
find, pero agrega el resultado a la cola actual en lugar de imprimirlos.
list <tipo> [<tipo> <consulta>]... [group <tipo>]... - Devuelve
una lista de todas las etiquetas del tipo de etiqueta dado. La búsqueda opcional de tipo/consulta limita los resultados de manera similar a la búsqueda. Los resultados se pueden agrupar por una o más etiquetas. Ejemplo:
mpc list album group artist

stats - Muestra estadísticas sobre MPD.

update [--wait] [<ruta>] - Escanea la carpeta de música en busca de
archivos actualizados. El parámetro opcional ruta (relativo a la carpeta de música) puede limitar el alcance de la actualización.

Con --wait, mpc espera hasta que MPD haya terminado la actualización.

rescan [--wait] [<ruta>] - Similar a update, pero también escanea
archivos no modificados.

Comandos de Archivo

albumart <archivo> - Descarga la carátula del álbum de la
canción dada y la escribe en la salida estándar.
readpicture <archivo> - Descarga una imagen incrustada en la
canción dada y la escribe en la salida estándar.

Comandos de Montaje

mount - Lista todos los montajes.

mount <ruta-montaje> <uri-almacenamiento> - Crea un nuevo montaje:
monta un almacenamiento en la ruta dada. Ejemplo:
mpc mount server nfs://10.0.0.5/mp3
mpc mount stick udisks://by-id-ata-FOO-part2

unmount <ruta-montaje> - Elimina un montaje.

listneighbors - Imprime una lista de "vecinos"
(es decir, almacenamientos detectados automáticamente que se pueden montar). Esto requiere habilitar al menos un plugin de vecino en mpd.conf. Ejemplo:
$ mpc listneighbors
upnp://uuid:01234567-89ab-cdef-0123-456789abcdef/urn:schemas-upnp-org:service:ContentDirectory:1
udisks://by-id-dm-name-_dev_sdb3
udisks://by-id-ata-FOO-part2

Comandos de Etiquetas

El comando sticker te permite obtener y establecer etiquetas de canciones.

sticker <archivo> set <clave> <valor> - Establece el valor de una
etiqueta de canción.
sticker <archivo> get <clave> - Imprime el valor de una
etiqueta de canción.

sticker <archivo> list - Lista todas las etiquetas de una canción.

sticker <archivo> delete <clave> - Elimina una etiqueta de canción.

sticker <directorio> find <clave> - Busca etiquetas con el
nombre especificado, debajo del directorio especificado.

Comandos de Salida

volume [+-]<num> - Establece el volumen a <num> (0-100). Si
se usa + o -, ajusta el volumen en relación con el volumen actual.

outputs - Lista todas las salidas disponibles

disable [only] <# o nombre de salida> [...] - Deshabilita la(s)
salida(s); se requiere una lista de uno o más nombres o números. Si only es el primer argumento, todas las demás salidas se habilitan.
enable [only] <# o nombre de salida> [...] - Habilita la(s)
salida(s); se requiere una lista de uno o más nombres o números. Si only es el primer argumento, todas las demás salidas se deshabilitan.
toggleoutput <# o nombre de salida> [...] - Cambia el estado de la(s)
salida(s) dada(s); se requiere una lista de uno o más nombres o números.
moveoutput <# o nombre de salida> - Mueve la salida dada
a la partición actual (ver --partition).

Comandos de Partición

partitions - Lista todas las particiones disponibles

makepart <nombre> [...] - Crea nuevas particiones

delpart <nombre> [...] - Elimina particiones

Comandos de Cliente-a-cliente

channels - Lista los canales a los que otros clientes se han
suscrito.
sendmessage <canal> <mensaje> - Envía un mensaje al canal
especificado.
waitmessage <canal> - Espera al menos un mensaje en el canal
especificado.
subscribe <canal> - Suscríbete al canal especificado y recibe
continuamente mensajes.

Otros Comandos

idle [eventos] - Espera hasta que ocurra un evento. Imprime una lista
de nombres de eventos, uno por línea. Consulte la documentación del protocolo MPD para obtener más información.

Si especifica una lista de eventos, solo se consideran estos eventos.

idleloop [eventos] - Similar a idle, pero
vuelve a entrar en el estado "idle" después de que se impriman los eventos.

Si especifica una lista de eventos, solo se consideran estos eventos.

status [formato] - Sin argumento, imprime una salida de estado de tres líneas
equivalente a "mpc" sin argumentos. Si se proporciona una cadena de formato, los delimitadores se procesan exactamente como lo hacen para los metadatos. Consulte la opción '-f' en Opciones
Nombre Descripción
%totaltime% La duración total de la canción.
%currenttime% El tiempo actual del cliente.
%percenttime% El porcentaje de tiempo transcurrido para la canción actual.
%songpos% La posición de la canción actual dentro de la lista de reproducción.
%length% El número de canciones dentro de la lista de reproducción.
%state% Ya sea 'playing', 'paused' o 'stopped'.

NAME

mpc – Music Player Daemon controller

SYNOPSIS

mpc [options] [command [args ...]]

DESCRIPTION

mpc is a command-line client for Music Player Daemon (mpd). It allows you to control your MPD server from the command line.

FORMATTING TAGS

Some commands, like list and status, support formatting tags. They are expanded as follows:

The following formatting tags are supported:

Tag Description
%title% The title of the current song.
%artist% The artist of the current song.
%album% The album of the current song.
%date% The date of the current song.
%track% The track number of the current song.
%genre% The genre of the current song.
%duration% The duration of the current song in seconds.
%time% The elapsed time of the current song in seconds.
%file% The filename of the current song.
%path% The full path of the current song.
%position% The position of the current song in the playlist.
%bitrate% The bit rate in kbps for the current song.
%audioformat% The audio format which MPD is currently playing as 'samplerate:bits:channels'.
%samplerate% The sample rate in Hz extracted from the current MPD audio format.
%bits% The number of significant bits per sample size extracted from the current MPD audio format.
%channels% The number of channels extracted from the current MPD audio format.

OPTIONS

--host host
Connect to MPD server at host. Defaults to localhost.
--port port
Connect to MPD server at port. Defaults to 6600.
--password password
Use password to authenticate with the MPD server.
--format format
Configure the format used to display songs. See the Formatting Tags section.
--clear
Clear the current playlist.
--verbose
Print more detailed output.
--help
Show help message and exit.
--version
Show version information and exit.

COMMANDS

add path ...
Add the specified file or directory to the playlist.
clear
Clear the current playlist.
delete range ...
Delete the specified songs from the playlist. range can be a single song index, a comma-separated list of indices, or a hyphen-separated range of indices.
insert path position
Insert the specified file or directory at the given position in the playlist.
load playlist
Load the specified playlist.
move from to
Move the song at from to to position in the playlist.
play [playlist_index]
Play the specified song in the playlist. If no index is specified, resume playback.
pause
Pause playback.
resume
Resume playback.
stop
Stop playback.
next
Play the next song.
previous
Play the previous song.
random mode
Set random playback mode. mode can be on, off, or 1.
repeat mode
Set repeat playback mode. mode can be on, off, or 1.
consume mode
Set consume playback mode. mode can be on, off, or 1.
status [format]
Show the status of the MPD server. If format is specified, it is used to format the output.
playlist [range]
Show the current playlist. If range is specified, show only those songs.
list subcommand
List music files. subcommand can be:
databases
List all available databases.
artist [directory]
List all artists in the specified directory (or the entire database if no directory is specified).
album [artist]
List all albums by the specified artist (or all albums if no artist is specified).
title [artist] [album]
List all titles by the specified artist and album (or all titles if no artist or album is specified).
genre [artist] [album]
List all genres by the specified artist and album (or all genres if no artist or album is specified).
search key value ...
Search for songs matching the specified key-value pairs.
find key value ...
Find songs matching the specified key-value pairs.
outputs
List available audio outputs.
outputenable output_id ...
Enable the specified audio outputs.
outputdisable output_id ...
Disable the specified audio outputs.
volume [+/-]amount
Set the volume to amount. If +/- is specified, the volume is adjusted relatively.
crossfade [+/-]seconds
Set the crossfade duration to seconds. If +/- is specified, the crossfade duration is adjusted relatively.
save playlist
Save the current playlist to playlist.
rm playlist
Remove the specified playlist.
rename old_name new_name
Rename the specified playlist.
update [directory]
Update the MPD music database. If directory is specified, only update that directory.
rescan [directory]
Rescan the MPD music database. If directory is specified, only rescan that directory.
shutdown
Shut down the MPD server.
settings
Show MPD server settings.

ENVIRONMENT VARIABLES

All environment variables are overridden by any values specified via command line switches.

MPC_FORMAT
Configure the format used to display songs. See option --format.
MPD_HOST
The MPD server to connect to. See option --host.
MPD_PORT
The TCP port of the MPD server to connect to. See option --port.

BUGS

Report bugs on https://github.com/MusicPlayerDaemon/mpc/issues

Since MPD uses UTF-8, mpc needs to convert characters to the charset used by the local system. If you get character conversion errors when you're running mpc you probably need to set up your locale. This is done by setting any of the LC_CTYPE, LANG or LC_ALL environment variables (LC_CTYPE only affects character handling).
