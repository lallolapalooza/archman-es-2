NOMBRE


mptopdf - convierte figuras de MetaPost a PDF

SINOPSIS

mptopdf [ OPCIONES ... ] [ ARCHIVOS ]

DESCRIPCIÓN

convierte figuras de MetaPost a PDF

OPCIONES

--metafun
usa el formato metafun para procesar el archivo (por defecto es mpost)
--texexec
usa texexec (context) para procesar fragmentos de texto
--latex
usa latex para procesar fragmentos de texto

AUTOR
