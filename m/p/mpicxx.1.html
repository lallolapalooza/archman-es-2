mpicc, mpic++, mpicxx, mpifort, mpijavac — compiladores envoltorio de Open MPI

SINTAXIS

mpicc [--showme | --showme:compile | --showme:link] ...

mpic++ [--showme | --showme:compile | --showme:link] ...

mpicxx [--showme | --showme:compile | --showme:link] ...

mpifort [--showme | --showme:compile | --showme:link] ...

mpijavac [--showme | --showme:compile | --showme:link] ...

Los siguientes comandos obsoletos también están disponibles — pero se debería usar mpifort en su lugar:

mpif77 [--showme | --showme:compile | --showme:link] ...

mpif90 [--showme | --showme:compile | --showme:link] ...

En sistemas de archivos sensibles a mayúsculas y minúsculas, el siguiente comando también estará disponible:

mpiCC [--showme | --showme:compile | --showme:link] ...

OPCIONES

Las siguientes opciones se aplican a todos los compiladores envoltorio:

•
--showme: Esta opción tiene varias variantes (ver más abajo). Ninguna de las variantes invoca al compilador subyacente; todas proporcionan información sobre cómo se habría invocado el compilador subyacente si --showme no se hubiera utilizado. La opción básica --showme muestra la línea de comandos que se ejecutaría para compilar el programa.

NOTA:

Si se pasa un argumento que no es un nombre de archivo en la línea de comandos, la opción --showme *no* mostrará ninguna bandera adicional. Por ejemplo, tanto "mpicc --showme como mpicc --showme my_source.c mostrarán todas las banderas suministradas por el envoltorio. Pero mpicc --showme -v solo mostrará el nombre del compilador subyacente y -v.
  • --showme:compile: Muestra las banderas del compilador que se habrían suministrado al compilador subyacente.
  • --showme:link: Muestra las banderas del enlazador que se habrían suministrado al compilador subyacente.
  • --showme:command: Muestra el comando del compilador subyacente (que puede ser uno o varios tokens).
  • --showme:incdirs: Muestra una lista de directorios separados por espacios (pero sin decorar) que el compilador envoltorio habría proporcionado al compilador subyacente para indicar dónde se encuentran los archivos de cabecera relevantes.
  • --showme:libdirs: Muestra una lista de directorios separados por espacios (pero sin decorar) que el compilador envoltorio habría proporcionado al enlazador subyacente para indicar dónde se encuentran las bibliotecas relevantes.
  • --showme:libs: Muestra una lista de nombres de bibliotecas separados por espacios (pero sin decorar) que el compilador envoltorio habría utilizado para enlazar una aplicación. Por ejemplo: mpi open-pal util.
  • --showme:version: Muestra el número de versión de Open MPI.
  • --showme:help: Muestra un breve mensaje de ayuda de uso.

Consulte la página del manual de su compilador subyacente para ver otras opciones que se pueden pasar a través de mpicc.

DESCRIPCIÓN

Conceptualmente, el papel de estos comandos es bastante simple: añadir transparente banderas relevantes del compilador y del enlazador a la línea de comandos del usuario que son necesarias para compilar/enlazar programas de Open MPI, y luego invocar al compilador subyacente para realizar realmente el comando.

Como tales, estos comandos se denominan frecuentemente compiladores "envoltorio" porque en realidad no compilan ni enlazan aplicaciones por sí mismos; solo añaden banderas a la línea de comandos e invocan al compilador de backend.

ANTECEDENTES

Open MPI proporciona compiladores envoltorio para varios idiomas:

  • mpicc: C
  • mpic++, mpicxx (y en sistemas con sistemas de archivos sensibles a mayúsculas y minúsculas, mpiCC): C++

    NOTA:

mpic++, mpicxx y mpiCC invocan al mismo compilador C++ subyacente con las mismas opciones. Todos se proporcionan como compatibilidad con otras implementaciones de MPI.
  • mpifort (y sus alias heredados/obsoletos mpif77 y mpif90): Fortran
  • mpijavac: Java

Los compiladores envoltorio para cada uno de los idiomas son idénticos; se pueden usar indistintamente. Los diferentes nombres se proporcionan únicamente por compatibilidad hacia atrás.

NOTAS DE FORTRAN

El compilador envoltorio de Fortran para MPI (mpifort, y sus nombres heredados/obsoletos mpif77 y mpif90) puede compilar y enlazar aplicaciones MPI que utilicen cualquiera/todas las vinculaciones de Fortran de MPI: mpif.h, el módulo mpi y el módulo mpi_f08 (suponiendo que Open MPI se instaló con soporte para cada una de estas vinculaciones de Fortran). Específicamente: ya no es necesario usar compiladores envoltorio diferentes para aplicaciones que usan mpif.h frente a aplicaciones que usan el módulo mpi — solo use mpifort para todas las aplicaciones MPI de Fortran.

Tenga en cuenta, sin embargo, que el compilador de Fortran puede requerir opciones de línea de comandos adicionales para forzar un dialecto de Fortran específico. Por ejemplo, en algunas versiones del compilador IBM XLF, si xlf90 es el compilador de Fortran subyacente, puede ser necesario -qfixed para compilar archivos fuente de Fortran de formato fijo.

Finalmente, tenga en cuenta que mpifort no funcionará y devolverá un error si el soporte de Fortran no se compiló en la capa de MPI.

VISTA GENERAL

mpicc es un envoltorio de conveniencia para el compilador C subyacente. La traducción de un programa Open MPI requiere el enlace de las bibliotecas específicas de Open MPI que pueden no residir en uno de los directorios de búsqueda estándar de ld(1). También a menudo requiere la inclusión de archivos de cabecera que pueden no encontrarse en una ubicación estándar.

mpicc pasa sus argumentos al compilador C subyacente junto con las opciones -I, -L y -l requeridas por los programas Open MPI.

Lo mismo ocurre con todos los demás compiladores envoltorio de idiomas.

El equipo de Open MPI *insta* a usar los compiladores envoltorio en lugar de intentar enlazar las bibliotecas de Open MPI manualmente. Esto permite que la implementación específica de Open MPI cambie sin forzar cambios en las directivas del enlazador en los Makefiles de los usuarios. De hecho, el conjunto específico de banderas y bibliotecas utilizadas por los compiladores envoltorio depende de cómo se configuró y construyó Open MPI; los valores pueden cambiar entre diferentes instalaciones de la misma versión de Open MPI.

De hecho, dado que los envoltorios son simplemente capas delgadas sobre un compilador subyacente, hay muy, muy pocas razones convincentes para *no* usar los compiladores envoltorio de Open MPI. Cuando no sea posible usar los envoltorios directamente, se deben usar las opciones --showme:compile y --showme:link para determinar qué banderas usarían los envoltorios. Por ejemplo:

shell$ cc -c file1.c `mpicc --showme:compile`
shell$ cc -c file2.c `mpicc --showme:compile`
shell$ cc file1.o file2.o `mpicc --showme:link` -o my_mpi_program

NOTAS

Es posible hacer que los compiladores envoltorio sean conscientes de múltiples bibliotecas. Es decir, las bibliotecas e inclusiones especificadas pueden diferir según las banderas del compilador especificadas (por ejemplo, con los compiladores GNU en Linux, se puede usar una ruta de biblioteca diferente si se ve -m32 frente a si se ve -m64). Este no es el comportamiento predeterminado en una compilación estándar, pero se puede activar (por ejemplo, en un paquete binario que proporcione soporte tanto de 32 como de 64 bits). *Más información se puede encontrar aquí*.

ARCHIVOS

Las cadenas que los compiladores envoltorio insertan en la línea de comandos antes de invocar al compilador subyacente se almacenan en un archivo de texto creado por Open MPI e instalado en $pkgdata/NOMBRE-wrapper-data.txt, donde:

  • $pkgdata es típicamente $prefix/share/openmpi
  • $prefix es el directorio de instalación superior de Open MPI
  • NOMBRE es el nombre del compilador envoltorio (por ejemplo, $pkgdata/mpicc-wrapper-data.txt)

Este sitio no está asociado de ninguna forma con Arch Linux ni afiliado a este proyecto. El contenido es únicamente una traducción de las páginas del manual de Arch publicadas en man.archlinux.org.

SYNTAX

mpicxx [opciones] [archivos]…

OPTIONS

Ver mpicc(1) y mpiCC(1).

DESCRIPTION

El compilador de C++ de Open MPI, mpicxx, es una envoltura alrededor del compilador de C++ predeterminado del sistema (generalmente g++ o CC).

Se puede invocar con exactamente los mismos argumentos que el compilador de C++ subyacente. Todos los argumentos se pasarán directamente al compilador de C++ subyacente, con la adición de los argumentos necesarios para enlazar con la biblioteca MPI.

BACKGROUND

Open MPI, como la mayoría de las implementaciones de MPI, proporciona un conjunto de utilidades de compilación y ejecución para facilitar el uso de su biblioteca.

En el caso de MPI-1, estas eran las utilidades `mpicc`, `mpicxx`, `mpif77`, y `mpif90`. Estas utilidades se encargaban de invocar al compilador C/C++/Fortran subyacente con las opciones correctas para compilar y enlazar código MPI.

Con el tiempo, la comunidad de MPI se dio cuenta de que la idea de una utilidad de compilación separada era demasiado restrictiva. Los usuarios a menudo querían mezclar compiladores C y C++ en el mismo proyecto, o usar opciones de compilador específicas para C++ que `mpicc` no conocía.

Por lo tanto, para MPI-3, Open MPI ha adoptado un enfoque más moderno, donde las utilidades `mpicc`, `mpicxx`, `mpif77`, y `mpif90` son en realidad enlaces simbólicos a la utilidad `mpiextra`. Esta utilidad luego invoca al compilador C/C++/Fortran predeterminado del sistema y añade las opciones necesarias para compilar y enlazar código MPI.

Por lo tanto, `mpicxx` es esencialmente una envoltura alrededor del compilador de C++ predeterminado del sistema, con la adición de las banderas y bibliotecas necesarias para enlazar con la biblioteca MPI.

FORTRAN NOTES

Si el compilador de Fortran predeterminado del sistema se seleccionó durante la configuración de Open MPI, entonces `mpifortran` también estará disponible. Esta utilidad es una envoltura alrededor del compilador de Fortran predeterminado del sistema, con la adición de las banderas y bibliotecas necesarias para enlazar con la biblioteca MPI.

ENVIRONMENT VARIABLES

Por defecto, las envolturas utilizan los compiladores que se seleccionaron cuando Open MPI fue configurado. Estos compiladores fueron encontrados automáticamente por el script “configure” de Open MPI, o fueron seleccionados por el usuario en las variables de entorno CC, CXX, y/o FC antes de que se invocara configure. Adicionalmente, otros argumentos específicos del compilador pueden haber sido seleccionados por configure.

Estos valores pueden ser anulados selectivamente editando los archivos de texto que contienen esta información de configuración (ver la sección FILES), o estableciendo variables de entorno seleccionadas del formulario ompi_value.

Los nombres de valor válidos son:

  • CPPFLAGS: Banderas añadidas al invocar el preprocesador (C o C++)
  • LDFLAGS: Banderas añadidas al invocar el enlazador (C, C++, o Fortran)
  • LIBS: Bibliotecas añadidas al invocar el enlazador (C, C++, o Fortran)
  • CC: Compilador C
  • CFLAGS: Banderas del compilador C
  • CXX: Compilador C++
  • CXXFLAGS: Banderas del compilador C++
  • FC: Compilador Fortran
  • FCFLAGS: Banderas del compilador Fortran
