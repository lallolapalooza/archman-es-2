MPEG2DESC(1) Páginas del manual de DVDAuthor MPEG2DESC(1)

NOMBRE

mpeg2desc - multiplexa flujos de audio/vídeo

SINOPSIS

mpeg2desc [ -a flujo ] [ -v flujo ] [ -o ARCHIVO ] [ -s ] [ -m ] [ -h ] [ < pelicula.mpg ... ]

DESCRIPCIÓN

mpeg2desc multiplexa flujos de audio y vídeo

OPCIONES

-a flujo
Exporta el flujo de audio flujo (0 .. 31) a la salida estándar
-v flujo
Exporta el flujo de vídeo flujo (0 .. 15) a la salida estándar
-o ARCHIVO
Exporta el flujo anterior a ARCHIVO en lugar de a la salida estándar
-s
salta al primer encabezado válido - asegura que mplex pueda manejar la salida
-m
exporta el desplazamiento de mplex a la salida estándar
-u
no exporta mensajes sobre encabezados no reconocidos
-h
muestra ayuda breve

USO

mpeg2desc mpeg2desc [opciones] < pelicula.mpg

PRECAUCIONES

Ninguna.

ERRORES

Ninguno.
