NOMBRE

mpstat - Informar estadísticas relacionadas con los procesadores.

SINOPSIS

mpstat [ -A ] [ --dec={ 0 | 1 | 2 } ] [ -H ] [ -n ] [ -U ] [ -u ] [ -T ] [ -V ] [ -I { palabra_clave[,...] | ALL } ] [ -N { lista_nodos | ALL } ] [ -o JSON ] [ -P { lista_cpu | ALL } ] [ intervalo [ conteo ] ]

DESCRIPCIÓN

El comando mpstat escribe en la salida estándar las actividades de cada procesador disponible, siendo el procesador 0 el primero. También se informan las actividades promedio globales entre todos los procesadores. El comando mpstat puede usarse tanto en máquinas SMP como UP, pero en estas últimas, solo se imprimirán las actividades promedio globales. Si no se selecciona ninguna actividad, el informe predeterminado es el informe de utilización de la CPU.

El parámetro intervalo especifica la cantidad de tiempo en segundos entre cada informe. Un valor de 0 (o ningún parámetro) indica que las estadísticas del procesador se informarán desde el inicio del sistema (arranque). El parámetro conteo se puede especificar junto con el parámetro intervalo si este último no está configurado en cero. El valor de conteo determina el número de informes generados con una separación de intervalo segundos. Si se especifica el parámetro intervalo sin el parámetro conteo, el comando mpstat genera informes continuamente.

OPCIONES

-A
Esta opción es equivalente a especificar -n -u -I ALL. Esta opción también implica especificar -N ALL -P ALL a menos que estas opciones se establezcan explícitamente en la línea de comandos.
--dec={ 0 | 1 | 2 }
Especifica el número de decimales a usar (de 0 a 2, el valor predeterminado es 2).
-H
Detecta y muestra también estadísticas para vCPUs conectadas en caliente físicamente.
-I { palabra_clave[,...] | ALL }
Informa estadísticas de interrupciones. Las palabras_clave posibles son CPU, SCPU y SUM.
Con la palabra clave CPU, se muestra el número de cada interrupción individual recibida por segundo por la CPU o CPUs. Las interrupciones son las que figuran en el archivo /proc/interrupts.

Con la palabra clave SCPU, se muestra el número de cada interrupción de software individual recibida por segundo por la CPU o CPUs. Esta opción solo funciona con kernels 2.6.31 y posteriores. Las interrupciones de software son las que figuran en el archivo /proc/softirqs.

Con la palabra clave SUM, el comando mpstat informa el número total de interrupciones por procesador. Se muestran los siguientes valores:

CPU
Número de procesador. La palabra clave all indica que las estadísticas se calculan como promedios entre todos los procesadores.
intr/s
Muestra el número total de interrupciones recibidas por segundo por la CPU o CPUs.
La palabra clave ALL es equivalente a especificar todas las palabras clave anteriores y, por lo tanto, se mostrarán todas las estadísticas de interrupciones.
-N { lista_nodos | ALL }
Indica los nodos NUMA para los cuales se informarán las estadísticas. lista_nodos es una lista de valores separados por comas o rangos de valores (por ejemplo, 0,2,4-7,12-). Tenga en cuenta que el nodo all es el promedio global entre todos los nodos. La palabra clave ALL indica que se informarán las estadísticas para todos los nodos.
-n
Informa estadísticas de CPU de resumen basadas en la ubicación del nodo NUMA. Se muestran los siguientes valores:
NODE
Número de nodo NUMA lógico. La palabra clave all indica que las estadísticas se calculan como promedios entre todos los nodos.
Todos los demás campos son iguales a los que se muestran con la opción -u (ver más abajo).
-o JSON
Muestra las estadísticas en formato JSON (JavaScript Object Notation). El orden de los campos de salida JSON no está definido y se pueden agregar nuevos campos en el futuro.
-P { lista_cpu | ALL }
Indica los procesadores para los cuales se informarán las estadísticas. lista_cpu es una lista de valores separados por comas o rangos de valores (por ejemplo, 0,2,4-7,12-). Tenga en cuenta que el procesador 0 es el primer procesador, y el procesador all es el promedio global entre todos los procesadores. Los procesadores sin conexión no se muestran.
-T
Muestra elementos de topología en el informe de CPU (ver opción -u a continuación). Se muestran los siguientes elementos:
CORE
Número de núcleo lógico.
SOCK
Número de zócalo lógico.
NODE
Número de nodo NUMA lógico.
-U
Muestra la marca de tiempo (UTC - Tiempo Universal Coordinado) en segundos desde la época.
-u
Informa la utilización de la CPU. Se muestran los siguientes valores:
CPU
Número de procesador. La palabra clave all indica que las estadísticas se calculan como promedios entre todos los procesadores.
%usr
Muestra el porcentaje de utilización de la CPU que ocurrió mientras se ejecutaba a nivel de usuario (aplicación).
%nice
Muestra el porcentaje de utilización de la CPU que ocurrió mientras se ejecutaba a nivel de usuario con prioridad nice.
%sys
Muestra el porcentaje de utilización de la CPU que ocurrió mientras se ejecutaba a nivel del sistema (kernel). Tenga en cuenta que esto no incluye el tiempo dedicado a atender interrupciones de hardware y software.
%iowait
Muestra el porcentaje de tiempo que la CPU o CPUs estuvieron inactivas durante el cual el sistema tenía una solicitud de E/S de disco pendiente.
%irq
Muestra el porcentaje de tiempo dedicado por la CPU o CPUs a atender interrupciones de hardware.
%soft
Muestra el porcentaje de tiempo dedicado por la CPU o CPUs a atender interrupciones de software.
%steal
Muestra el porcentaje de tiempo de espera involuntaria de la CPU virtual o CPUs mientras el hipervisor estaba atendiendo a otro procesador virtual.
%guest
Muestra el porcentaje de tiempo dedicado por la CPU o CPUs a ejecutar un procesador virtual.
%gnice
Muestra el porcentaje de tiempo dedicado por la CPU o CPUs a ejecutar un huésped niced.
%idle
Muestra el porcentaje de tiempo que la CPU o CPUs estuvieron inactivas y el sistema no tenía una solicitud de E/S de disco pendiente.
-V
Imprime el número de versión y luego sale.

AMBIENTE

El comando mpstat tiene en cuenta la siguiente variable de entorno:

S_COLORS
Por defecto, las estadísticas se muestran en color cuando la salida está conectada a un terminal. Usa esta variable para cambiar la configuración. Los valores posibles para esta variable son never, always o auto (este último es equivalente a la configuración predeterminada).
Ten en cuenta que el color (ya sea rojo, amarillo o algún otro color) utilizado para mostrar un valor no indica ningún tipo de problema solo por el color. Solo indica diferentes rangos de valores.
S_COLORS_SGR
Especifica los colores y otros atributos utilizados para mostrar estadísticas en el terminal. Su valor es una lista de capacidades separadas por dos puntos que por defecto es I=32;22:N=34;1:W=35;1:X=

ENVIRONMENT

S_COLORS
Determines if color escape sequences are recognized for the mpstat display. Supported values are:
- 0: Disables color output. - 1: Enables color output (default). -

A list of SGR (Select Graphic Rendition) substrings separated by colons. The default value is "1;22:1;24:1;20:0;31:1;32".

The substrings are used in the following order:

I
SGR substring for CPU number.
N
SGR substring for non-zero statistics values.
W (or M)
SGR substring for percentage values in the range from 75% to 90% (or in the range 10% to 25% depending on the metric's meaning).
X (or H)
SGR substring for percentage values greater than or equal to 90% (or lower than or equal to 10% depending on the metric's meaning).
Z
SGR substring for zero values.
S_TIME_FORMAT
If this variable exists and its value is ISO then the current locale will be ignored when printing the date in the report header. The mpstat command will use the ISO 8601 format (YYYY-MM-DD) instead. The timestamp will also be compliant with ISO 8601 format.

EXAMPLES

mpstat 2 5
Display five reports of global statistics among all processors at two second intervals.
mpstat -P ALL 2 5
Display five reports of statistics for all processors at two second intervals.

BUGS

/proc filesystem must be mounted for the mpstat command to work.

FILES

/proc contains various files with system statistics.
