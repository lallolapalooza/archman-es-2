MPD.CONF(5) Reproductor de Música Daemon MPD.CONF(5)

NOMBRE

mpd.conf - Documentación de mpd.conf

DESCRIPCIÓN

mpd.conf es el archivo de configuración de mpd(1). Si no se especifica en la línea de comandos, MPD primero busca en $XDG_CONFIG_HOME/mpd/mpd.conf, luego en ~/.mpdconf, después en ~/.mpd/mpd.conf y finalmente en /etc/mpd.conf.

Cada línea en el archivo de configuración contiene un nombre de ajuste y su valor, por ejemplo:

connection_timeout "5"

Las líneas que comienzan con # se tratan como comentarios y se ignoran.

Para los ajustes que especifican una ruta del sistema de archivos, la tilde ('~') se expande a $HOME. Además, se admiten las siguientes expansiones de ruta:

  • $HOME
  • $XDG_CONFIG_HOME
  • $XDG_MUSIC_DIR
  • $XDG_CACHE_HOME
  • $XDG_RUNTIME_DIR

music_directory "~/Música"

db_file "$XDG_CONFIG_HOME/mpd/database"

Algunos de los ajustes se agrupan en bloques con llaves, por ejemplo, ajustes por plugin:

audio_output {
    type "alsa"
    name "Mi salida ALSA"
    device "iec958:CARD=Intel,DEV=0"
    mixer_control "PCM"
}

La directiva include se puede usar para incluir ajustes de otro archivo; el nombre de archivo proporcionado es relativo al archivo actual:

include "other.conf"

Puede usar include_optional en su lugar si desea que el archivo incluido sea opcional; la directiva se ignorará si el archivo no existe:

include_optional "may_not_exist.conf"

Consulte docs/mpdconf.example en el archivo tarball de origen para ver un archivo de configuración de ejemplo.

Este manual no está completo, solo enumera las opciones más importantes. Por favor, lea el manual de usuario de MPD para obtener una guía de configuración completa: http://www.musicpd.org/doc/user/

PARÁMETROS OPCIONALES

db_file <archivo>
Esto especifica dónde se almacenará el archivo de la base de datos.
log_file <archivo>
Esto especifica dónde se ubicará el archivo de registro. El valor especial "syslog" hace que MPD utilice el demonio syslog local.
sticker_file <archivo>
La ubicación de la base de datos de pegatinas. Esta es una base de datos que gestiona información dinámica adjunta a las canciones.
pid_file <archivo>
Esto especifica el archivo donde se guardará el ID de proceso de mpd.
music_directory <directorio>
Esto especifica el directorio donde se encuentra la música. Si no configura esto, solo podrá reproducir transmisiones.
playlist_directory <directorio>
Esto especifica el directorio donde se almacenan las listas de reproducción guardadas. Si no configura esto, no podrá guardar listas de reproducción.
state_file <archivo>
Esto especifica si se utiliza un archivo de estado y dónde se encuentra. El estado de mpd se guardará en este archivo cuando mpd se termine con una señal TERM o con el comando kill. Cuando mpd se reinicia, leerá el archivo de estado y restaurará el estado de mpd (incluida la lista de reproducción).
restore_paused <sí o no>
Pon MPD en modo de pausa en lugar de iniciar la reproducción después del arranque.
user <nombredeusuario>
Esto especifica el usuario con el que se ejecutará MPD, si está establecido. MPD nunca debe ejecutarse como root, y puede utilizar esta opción para que MPD cambie su ID de usuario después de la inicialización. No utilice esta opción si inicia MPD como un usuario no privilegiado.
port <puerto>
Esto especifica el puerto en el que escucha mpd. El valor predeterminado es 6600.
log_level <nivel>
Suprime todos los mensajes por debajo del umbral dado. Los siguientes niveles de registro están disponibles:
  • error: errores
  • warning: advertencias
  • notice: mensajes informativos interesantes
  • info: mensajes informativos no importantes
  • verbose: mensajes de depuración (para desarrolladores y para resolución de problemas)

El valor predeterminado es notice.

follow_outside_symlinks <sí o no>
Controla si MPD seguirá los enlaces simbólicos que apuntan fuera del directorio de música. Debe recrear la base de datos después de cambiar esta opción. El valor predeterminado es "yes".
follow_inside_symlinks <sí o no>
Controla si MPD seguirá los enlaces simbólicos que apuntan dentro del directorio de música, añadiendo potencialmente duplicados a la base de datos. Debe recrear la base de datos después de cambiar esta opción. El valor predeterminado es "yes".
zeroconf_enabled <sí o no>
Si es sí, y MPD se ha compilado con soporte para Avahi o Bonjour, la información del servicio se publicará con Zeroconf. El valor predeterminado es sí.
zeroconf_name <nombre>
Si Zeroconf está habilitado, este es el nombre del servicio a publicar. Este nombre debe ser único en su red local, pero las colisiones de nombres se gestionarán correctamente. El valor predeterminado es "Music Player @ %h", donde %h será reemplazado por el nombre de host de la máquina que ejecuta MPD.
audio_output
Consulte DESCRIPCIÓN y las diversas secciones de PARÁMETROS DE SALIDA DE AUDIO para ver el formato de este parámetro. Se pueden especificar varias secciones de audio_output. Si no se especifica ninguna sección audio_output, MPD buscará una salida de audio utilizable.
filesystem_charset <conjunto de caracteres>
Esto especifica el conjunto de caracteres utilizado para el sistema de archivos. Se puede obtener una lista de los conjuntos de caracteres admitidos ejecutando "iconv -l". El valor predeterminado se determina a partir de la configuración regional cuando se creó originalmente la base de datos.
save_absolute_paths_in_playlists <sí o no>
Esto especifica si se utilizan rutas relativas o absolutas para los nombres de archivo de las canciones al guardar listas de reproducción. El valor predeterminado es "no".
auto_update <sí o no>
Esto especifica si se admite la actualización automática de la base de datos de música cuando los archivos se modifican en music_directory. El valor predeterminado es deshabilitar la actualización automática de la base de datos. (Solo implementado en Linux.)
auto_update_depth <N>
Limita la profundidad de los directorios que se observan, 0 significa observar solo el directorio de música en sí. No hay límite por predeterminado.

PARÁMETROS REQUERIDOS DE SALIDA DE AUDIO

type <tipo>
Esto especifica el tipo de salida de audio. Consulte la lista de salidas admitidas en mpd --version para conocer los valores posibles.
name <nombre>
Esto especifica un nombre único para la salida de audio.

AUDIO OUTPUT PARAMETERS

audio_output_format <sample_rate:bits:channels>
Especifica la frecuencia de muestreo, bits por muestra y número de canales del audio que se envía al dispositivo de salida de audio. Consulte la documentación del parámetro audio_output_format para más detalles. El valor por defecto es usar el formato de audio que se pase a la salida de audio. Cualquiera de los tres atributos puede ser un asterisco para especificar que este atributo no debe ser forzado.
replay_gain_handler <software, mixer or none>
Especifica cómo se aplica el replay gain. El valor por defecto es "software", que utiliza un control de volumen interno por software. "mixer" utiliza el control de mezclador (hardware) configurado. "none" deshabilita el replay gain en esta salida de audio.
mixer_type <hardware, software or none>
Especifica qué mezclador se debe utilizar para esta salida de audio: el mezclador de hardware (disponible para ALSA, OSS y PulseAudio), el mezclador de software o ningún mezclador ("none"). Por defecto, se utiliza el mezclador de hardware para los dispositivos que lo soportan, y ninguno para los demás.
