mpi.conf(5) Archivo de configuración de Slurm mpi.conf(5)

NOMBRE

mpi.conf - Archivo de configuración de Slurm para permitir la configuración de plugins MPI.

DESCRIPCIÓN

mpi.conf es un archivo ASCII que define parámetros que controlan el comportamiento de los plugins MPI. Actualmente, el archivo de configuración solo se puede usar para configurar el plugin PMIx, pero se puede ampliar para admitir otros plugins MPI. El archivo siempre se encontrará en el mismo directorio que slurm.conf. Este archivo es opcional.

Los nombres de los parámetros no distinguen entre mayúsculas y minúsculas. Cualquier texto que siga a un carácter "#" en el archivo de configuración se trata como un comentario hasta el final de esa línea. Los cambios en el archivo de configuración surten efecto al reiniciar los demonios de Slurm, al recibir el demonio la señal SIGHUP o al ejecutar el comando "scontrol reconfigure", a menos que se indique lo contrario.

La configuración de este archivo se puede ver en la salida de "scontrol show config". Este archivo de configuración se puede incluir al usar el modo "sin configuración" (configless). slurmctld y slurmd leen la información de mpi.conf al inicio o tras la reconfiguración. Las instancias de slurmstepd para los pasos por lotes recibirán información sobre el plugin solicitado por slurmd.

PARÁMETROS

PMIxCliTmpDirBase=<ruta>
Directorio que PMIx utilizará para archivos temporales. Por defecto, no está establecido.
PMIxCollFence={mixed|tree|ring}
Define el tipo de valla (fence) a utilizar para recopilar datos entre nodos. Por defecto, no está establecido. Consulte también PMIxFenceBarrier.
PMIxDebug={0|1}
Habilita el registro de depuración para el plugin PMIx. Por defecto, es 0.
PMIxDirectConn={true|false}
Deshabilita el lanzamiento directo de tareas. Por defecto es "true".
PMIxDirectConnEarly={true|false}
Permite conexiones tempranas a un nodo padre. Por defecto es "false".
PMIxDirectConnUCX={true|false}
Permite que PMIx utilice UCX para la comunicación. Por defecto es "false".
PMIxDirectSameArch={true|false}
Habilita optimizaciones de comunicación adicionales cuando PMIxDirectConn está establecido en true, asumiendo que todos los nodos del trabajo tienen la misma arquitectura. Por defecto es "false".
PMIxEnv=<variables de entorno>
Lista separada por punto y coma de variables de entorno que se establecerán en los entornos de trabajo para ser utilizados por PMIx. Por defecto, no está establecido.
PMIxFenceBarrier={true|false}
Define si se debe usar valla (fence) en la comunicación inter-nodo para la recopilación de datos. Por defecto es "false". Consulte también PMIxCollFence.
PMIxNetDevicesUCX=<tipo de dispositivo>
Tipo de dispositivo de red a utilizar para la comunicación. Esto establecerá la variable de entorno UCX_NET_DEVICES solo en el entorno de slurmstepd. Por defecto, no está establecido.
PMIxShareServerTopology={true|false}
Permite que el servidor PMIx comparta su copia de la topología local del nodo del trabajo con los clientes. Si se establece en true, el servidor PMIx establecerá los pares clave-valor necesarios en la información a nivel de trabajo proporcionada a cada cliente. La topología no se compartirá a través de memoria compartida. Por defecto es "false".

NOTA: Esto solo es compatible con PMIx v4.x+.

PMIxTimeout=<tiempo>
El tiempo máximo (en segundos) permitido para la comunicación entre hosts. Por defecto son 300 segundos.
PMIxTlsUCX=<tl1>[,<tl2>...]
Establece la variable UCX_TLS, que restringe los transportes a utilizar, en el entorno de slurmstepd. Los valores aceptados se definen en la documentación de UCX y pueden variar entre instalaciones. Se pueden establecer varios valores y deben estar separados por comas. Si no se establece, UCX intenta utilizar todos los transportes disponibles y selecciona los mejores según sus capacidades de rendimiento y escala. Por defecto, no está establecido.
