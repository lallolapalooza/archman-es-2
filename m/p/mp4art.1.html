NOMBRE

mp4art - MP4v2 - página del manual para mp4art - MP4v2 2.1.3

SINOPSIS

mp4art [OPCIÓN]... ACCIÓN archivo...

DESCRIPCIÓN

Para cada archivo mp4 (m4a) especificado, realiza la ACCIÓN especificada. Se debe especificar una acción. Algunas opciones no son aplicables para algunas acciones.

ACCIONES

--list
listar todas las covr-boxes
--add IMG
añadir covr-box desde el archivo IMG
--replace IMG
reemplazar covr-box con el archivo IMG
--remove
eliminar covr-box
--extract
extraer covr-box

PARÁMETROS DE ACCIÓN

--art-any
actuar sobre todas las covr-boxes (por defecto)
--art-index IDX
actuar sobre la covr-box con índice IDX

OPCIONES

-z, --optimize
optimizar el archivo mp4 después de la modificación
-y, --dryrun
no crear ni modificar realmente ningún archivo
-k, --keepgoing
continuar el procesamiento por lotes incluso después de errores
-o, --overwrite
sobrescribir archivos existentes al crear
-f, --force
forzar la sobrescritura incluso si el archivo es de solo lectura
-q, --quiet
equivalente a --verbose 0
-d, --debug NUM
aumentar depuración o opción larga para establecer NUM
-v, --verbose NUM
aumentar verbosidad o opción larga para establecer NUM
-h, --help
imprimir ayuda breve u opción larga para ayuda extendida
--version
imprimir información de versión y salir

NIVELES DE DEBUG (para I/O de archivos mp4 crudos)

0
suprimido
1
añadir advertencias y errores (por defecto)
2
añadir detalles de tabla
3
añadir implícitos
4
todo

NIVELES DE VERBOSIDAD

0
advertencias y errores
1
mensajes informativos normales (por defecto)
2
mensajes más informativos
3
todo
