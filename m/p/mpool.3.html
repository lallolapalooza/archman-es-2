mpool(3) Manual de Funciones de Biblioteca mpool(3)

NOMBRE

mpool - pool de búferes de memoria compartida

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <db.h>
#include <mpool.h>
MPOOL *mpool_open(DBT *key, int fd, pgno_t pagesize, pgno_t maxcache);
void mpool_filter(MPOOL *mp,
                  typeof(void (void *, pgno_t, void *)) *pgin,
                  typeof(void (void *, pgno_t, void *)) *pgout,
                  void *pgcookie);
void *mpool_new(MPOOL *mp, pgno_t *pgnoaddr);
void *mpool_get(MPOOL *mp, pgno_t pgno, unsigned int flags);
int mpool_put(MPOOL *mp, void *pgaddr, unsigned int flags);
int mpool_sync(MPOOL *mp);
int mpool_close(MPOOL *mp);

DESCRIPCIÓN

Nota importante: Esta página documenta las interfaces proporcionadas hasta glibc 2.1. Desde glibc 2.2, glibc ya no proporciona estas interfaces. Probablemente, esté buscando las API proporcionadas por la biblioteca libdb en su lugar.

Mpool es la interfaz de biblioteca destinada a proporcionar gestión de búferes orientada a páginas de archivos. Los búferes pueden ser compartidos entre procesos.

La función mpool_open() inicializa un pool de memoria. El argumento key es la cadena de bytes utilizada para negociar entre múltiples procesos que desean compartir búferes. Si los búferes del archivo están mapeados en memoria compartida, todos los procesos que usen la misma clave compartirán los búferes. Si key es NULL, los búferes se mapean en memoria privada. El argumento fd es un descriptor de archivo para el archivo subyacente, que debe ser buscable. Si key no es NULL y coincide con un archivo que ya está siendo mapeado, el argumento fd se ignora.

El argumento pagesize es el tamaño, en bytes, de las páginas en las que se divide el archivo. El argumento maxcache es el número máximo de páginas del archivo subyacente a almacenar en caché en un momento dado. Este valor no es relativo al número de procesos que comparten los búferes de un archivo, sino que será el valor más grande especificado por cualquiera de los procesos que comparten el archivo.

La función mpool_filter() está destinada a permitir el procesamiento transparente de entrada y salida de las páginas. Si se especifica la función pgin, se llama cada vez que un búfer se lee en el pool de memoria desde el archivo de respaldo. Si se especifica la función pgout, se llama cada vez que un búfer se escribe en el archivo de respaldo. Ambas funciones se llaman con el puntero pgcookie, el número de página y un puntero a la página que se está leyendo o escribiendo.

La función mpool_new() toma un puntero MPOOL y una dirección como argumentos. Si se puede asignar una nueva página, se devuelve un puntero a la página y el número de página se almacena en la dirección pgnoaddr. De lo contrario, se devuelve NULL y se establece errno.

La función mpool_get() toma un puntero MPOOL y un número de página como argumentos. Si la página existe, se devuelve un puntero a la página. De lo contrario, se devuelve NULL y se establece errno. El argumento flags no se utiliza actualmente.

La función mpool_put() desvincula la página referenciada por pgaddr. pgaddr debe ser una dirección devuelta previamente por mpool_get() o mpool_new(). El valor de la bandera se especifica combinando cualquiera de los siguientes valores:

MPOOL_DIRTY
La página ha sido modificada y necesita ser escrita en el archivo de respaldo.

mpool_put() devuelve 0 en caso de éxito y -1 si ocurre un error.

La función mpool_sync() escribe todas las páginas modificadas asociadas con el puntero MPOOL en el archivo de respaldo. mpool_sync() devuelve 0 en caso de éxito y -1 si ocurre un error.

La función mpool_close() libera toda la memoria asignada asociada con la cookie del pool de memoria. Las páginas modificadas **no** se escriben en el archivo de respaldo. mpool_close() devuelve 0 en caso de éxito y -1 si ocurre un error.

ERRORES

La función mpool_open() puede fallar y establecer errno por cualquiera de los errores especificados para la rutina de biblioteca malloc(3).

La función mpool_get() puede fallar y establecer errno por los siguientes motivos:

EINVAL
El registro solicitado no existe.

Las funciones mpool_new() y mpool_get() pueden fallar y establecer errno por cualquiera de los errores especificados para las rutinas de biblioteca read(2), write(2) y malloc(3).

La función mpool_sync() puede fallar y establecer errno por cualquiera de los errores especificados para la rutina de biblioteca write(2).

La función mpool_close() puede fallar y establecer errno por cualquiera de los errores especificados para la rutina de biblioteca free(3).
