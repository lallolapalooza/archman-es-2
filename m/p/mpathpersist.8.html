MPATHPERSIST(8) Manual del Administrador del Sistema MPATHPERSIST(8)

NOMBRE

mpathpersist - Gestiona las reservas persistentes de SCSI en dispositivos dm multipath.

SINOPSIS

mpathpersist [OPCIONES] dispositivo

DESCRIPCIÓN

Esta utilidad se utiliza para gestionar reservas persistentes de SCSI en dispositivos Device Mapper Multipath. Para poder utilizar esta funcionalidad, el atributo reservation_key debe estar definido en el archivo /etc/multipath.conf. De lo contrario, el demonio multipathd no verificará las reservas persistentes para rutas recién descubiertas o rutas reinstauradas.

mpathpersist soporta las mismas opciones de línea de comandos que la utilidad sg_persist. Consulte la página del manual sg_persist (8) para una discusión en profundidad de las diversas opciones.

EJEMPLO

Registrar la clave "123abc" para el dispositivo /dev/mapper/mpath9:

mpathpersist --out --register --param-sark=123abc /dev/mapper/mpath9

Leer las claves de reserva registradas para el dispositivo /dev/mapper/mpath9:

mpathpersist -i -k /dev/mapper/mpath9

Crear una reserva para el dispositivo /dev/mapper/mpath9 con la clave de reserva dada:

mpathpersist --out --reserve --param-rk=123abc --prout-type=8 -d /dev/mapper/mpath9

Leer el estado de la reserva del dispositivo /dev/mapper/mpath9:

mpathpersist -i -s -d /dev/mapper/mpath9

Liberar la reserva creada previamente (tenga en cuenta que el prout-type debe ser el mismo que el de arriba):

mpathpersist --out --release --param-rk=123abc --prout-type=8 -d /dev/mapper/mpath9

Eliminar la clave registrada actualmente para este host (es decir, restablecerla a 0):

mpathpersist --out --register-ignore -K 123abc -S 0 /dev/mapper/mpath9

Eliminar la reserva actual y anular el registro de todas las claves registradas de todos los nexos I_T:

mpathpersist -oCK 123abc /dev/mapper/mpath9

ARCHIVOS DE LOTE

La opción --batch-file (-f) establece un archivo de entrada que será procesado por mpathpersist. Agrupar comandos en archivos de lote puede proporcionar una mejora de velocidad, especialmente en instalaciones grandes, ya que mpathpersist necesita escanear las rutas y mapas existentes solo una vez durante el inicio.

El archivo de entrada es un archivo de texto que se analiza línea por línea. Cada línea del archivo se interpreta como una línea de comandos (es decir, una lista de opciones y parámetros) para mpathpersist. Las opciones y los parámetros están separados por uno o más espacios en blanco (espacio o TAB). Las líneas pueden, pero no tienen que, comenzar con la palabra "mpathpersist". El carácter "#", ya sea al principio de la línea o después de algunos espacios en blanco, denota el inicio de un comentario que dura hasta el final de la línea. Se permiten líneas vacías. La continuación de comandos de mpathpersist en varias líneas no está soportada.

Se permiten en los archivos de lote todas las opciones listadas en esta página del manual, excepto -f y -v. Se pueden usar los formatos de opción cortos y largos. El uso de la opción -f dentro del archivo de lote es un error. La opción -v se ignora en los archivos de lote.

El mapa de multipath sobre el cual actuar debe especificarse en cada línea de entrada, por ejemplo, usando la opción -d. Se pueden combinar comandos que actúan sobre diferentes mapas de multipath en un archivo de lote, y múltiples comandos pueden actuar sobre el mismo mapa de multipath. Los comandos se ejecutan uno por uno, de modo que los comandos posteriores en el archivo ven los cambios de estado causados por comandos anteriores. Si mpathpersist encuentra un error al procesar una línea en el archivo de lote, el procesamiento del archivo de lote no se aborta; los comandos subsiguientes se ejecutan de todos modos. El estado de salida de mpathpersist es el estado del primer comando fallido, o 0 si todos los comandos tuvieron éxito.

Si se utilizan otras opciones y parámetros junto con -f en la línea de comandos de mpathpersist, la línea de comandos se ejecutará primero, seguida de los comandos del archivo de lote.

A continuación se muestra un ejemplo de un archivo de entrada de lote válido.

# Este es un archivo de entrada de mpathpersist.
# Formas cortas y largas del mismo comando
-i -k /dev/dm-1 # forma corta, este comentario se ignora
mpathpersist --in --read-keys --device=/dev/dm-1
# Mezcla de opciones largas y cortas, espacio en blanco variable
  --out  --register    -S  abcde     /dev/dm-1
# Mezcla de com
