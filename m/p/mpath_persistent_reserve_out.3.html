NOMBRE

mpath_persistent_reserve_out - enviar comando PROUT al dispositivo DM

SINOPSIS

#include <mpath_persist.h>

int mpath_persistent_reserve_out(int fd, int rq_servact, struct prin_resp *resp, int noisy, int verbose)

DESCRIPCIÓN

La función mpath_persistent_reserve_out () envía el comando PROUT al dispositivo DM y obtiene la respuesta.

Parámetros:
fd
El descriptor de archivo de un dispositivo multipath. Argumento de entrada.
rq_servact
Acción de servicio del comando PROUT. Argumento de entrada.
rq_scope
Ámbito de reserva persistente. El valor debe ser siempre LU_SCOPE (0h).
rq_type
Tipo de reserva persistente. Los valores válidos de los tipos de reserva persistente son:
5h (Exclusivo de escritura - solo registrantes).
6h (Acceso exclusivo - solo registrantes).
7h (Exclusivo de escritura - Todos los registrantes).
8h (Acceso exclusivo - Todos los registrantes).
paramp
Datos del parámetro del comando PROUT. `paramp` es una estructura que describe la lista de parámetros de PROUT. El llamador debe gestionar la asignación de memoria de esta estructura.
noisy
Activar rastreo de depuración: Argumento de entrada. 0->Desactivar, 1->Activar.
verbose
Establecer el nivel de verbosidad. Argumento de entrada. valor: 0 a 3. 0->Errores, 1->Advertencias, 2->Información, 3->Depuración.

RETORNA

MPATH_PR_SUCCESS
Si el comando PR es exitoso, de lo contrario devuelve cualquiera de los estados mencionados a continuación.
MPATH_PR_SYNTAX_ERROR
Si hay un error de sintaxis o un parámetro inválido.
MPATH_PR_SENSE_NOT_READY
Si el comando falla con [sk,asc,ascq: 0x2,*,*].
MPATH_PR_SENSE_MEDIUM_ERROR
Si el comando falla con [sk,asc,ascq: 0x3,*,*].
MPATH_PR_SENSE_HARDWARE_ERROR
Si el comando falla con [sk,asc,ascq: 0x4,*,*].
MPATH_PR_SENSE_INVALID_OP
Si el comando falla con [sk,asc,ascq: 0x5,0x20,0x0].
MPATH_PR_ILLEGAL_REQ
Si el comando falla con [sk,asc,ascq: 0x5,*,*].
MPATH_PR_SENSE_UNIT_ATTENTION
Si el comando falla con [sk,asc,ascq: 0x6,*,*].
MPATH_PR_SENSE_ABORTED_COMMAND
Si el comando falla con [sk,asc,ascq: 0xb,*,*].
MPATH_PR_NO_SENSE
Si el comando falla con [sk,asc,ascq: 0x0,*,*].
MPATH_PR_SENSE_MALFORMED
Si el comando falla porque el comando SCSI está mal formado.
MPATH_PR_FILE_ERROR
Si el comando falla al acceder al archivo (nodo del dispositivo) problemas (por ejemplo, no encontrado).
MPATH_PR_DMMP_ERROR
Si hay un error relacionado con el Device Mapper (por ejemplo, error al obtener información de dm).
MPATH_PR_OTHER
Si ha ocurrido otro error/advertencia (por ejemplo, error de transporte o controlador).
MPATH_PR_RESERV_CONFLICT
Si el comando falla con conflicto de reserva.

VER TAMBIÉN

mpathpersist(8).
