NOMBRE

mpath_persistent_reserve_in - enviar comando PRIN al dispositivo DM

SINOPSIS

#include <mpath_persist.h>

int mpath_persistent_reserve_in(int fd, int rq_servact, struct prin_resp *resp, int noisy, int verbose)

DESCRIPCIÓN

La función mpath_persistent_reserve_in () envía un comando PRIN al dispositivo DM y obtiene la respuesta.

Parámetros:
fd
El descriptor de archivo de un dispositivo multipath. Argumento de entrada.
rq_servact
Acción de servicio del comando PRIN. Argumento de entrada.
resp
La respuesta de la acción de servicio PRIN. El llamador debe gestionar la asignación de memoria de esta estructura.
noisy
Activar rastreo de depuración: Argumento de entrada. 0->Desactivar, 1->Activar.
verbose
Establecer nivel de verbosidad. Argumento de entrada. valor:[0-3]. 0->Errores, 1->Advertencias, 2->Información, 3->Depuración.

VALOR DE RETORNO

MPATH_PR_SUCCESS
Si el comando PR fue exitoso.
MPATH_PR_SYNTAX_ERROR
Si hay un error de sintaxis o un parámetro inválido.
MPATH_PR_SENSE_NOT_READY
Si el comando falla con [sk,asc,ascq: 0x2,*,*].
MPATH_PR_SENSE_MEDIUM_ERROR
Si el comando falla con [sk,asc,ascq: 0x3,*,*].
MPATH_PR_SENSE_HARDWARE_ERROR
Si el comando falla con [sk,asc,ascq: 0x4,*,*].
MPATH_PR_SENSE_INVALID_OP
Si el comando falla con [sk,asc,ascq: 0x5,0x20,0x0].
MPATH_PR_ILLEGAL_REQ
Si el comando falla con [sk,asc,ascq: 0x5,*,*].
MPATH_PR_SENSE_UNIT_ATTENTION
Si el comando falla con [sk,asc,ascq: 0x6,*,*].
MPATH_PR_SENSE_ABORTED_COMMAND
Si el comando falla con [sk,asc,ascq: 0xb,*,*].
MPATH_PR_NO_SENSE
Si el comando falla con [sk,asc,ascq: 0x0,*,*].
MPATH_PR_SENSE_MALFORMED
Si el comando falla con comando SCSI mal formado.
MPATH_PR_FILE_ERROR
Si el comando falla al acceder al archivo (nodo del dispositivo) problemas (ej. no encontrado).
MPATH_PR_DMMP_ERROR
Si hay un error relacionado con Device Mapper (ej. error al obtener información de dm).
MPATH_PR_OTHER
Si ha ocurrido otro error/advertencia (ej. error de transporte o controlador).

VER TAMBIÉN

mpathpersist(8).
