mpicc, mpic++, mpicxx, mpifort, mpijavac — compiladores envoltorio de Open MPI

SINTAXIS

mpicc [--showme | --showme:compile | --showme:link] ...

mpic++ [--showme | --showme:compile | --showme:link] ...

mpicxx [--showme | --showme:compile | --showme:link] ...

mpifort [--showme | --showme:compile | --showme:link] ...

mpijavac [--showme | --showme:compile | --showme:link] ...

Los siguientes comandos obsoletos también están disponibles — pero se debe usar mpifort en su lugar:

mpif77 [--showme | --showme:compile | --showme:link] ...

mpif90 [--showme | --showme:compile | --showme:link] ...

En sistemas de archivos sensibles a mayúsculas y minúsculas, el siguiente comando también estará disponible:

mpiCC [--showme | --showme:compile | --showme:link] ...

OPCIONES

Las opciones a continuación se aplican a todos los compiladores envoltorio:

•
--showme: Esta opción tiene varias variantes diferentes (ver más abajo). Ninguna de las variantes invoca al compilador subyacente; todas proporcionan información sobre cómo se habría invocado el compilador subyacente si --showme no se hubiera utilizado. La opción básica --showme muestra la línea de comandos que se ejecutaría para compilar el programa.

NOTA:

Si se pasa un argumento que no es un nombre de archivo en la línea de comandos, la opción --showme *no* mostrará ninguna bandera adicional. Por ejemplo, tanto "mpicc --showme como mpicc --showme my_source.c mostrarán todas las banderas proporcionadas por el envoltorio. Pero mpicc --showme -v solo mostrará el nombre del compilador subyacente y -v.
  • --showme:compile: Muestra las banderas del compilador que se habrían proporcionado al compilador subyacente.
  • --showme:link: Muestra las banderas del enlazador que se habrían proporcionado al enlazador subyacente.
  • --showme:command: Muestra el comando del compilador subyacente (que puede ser uno o varios tokens).
  • --showme:incdirs: Muestra una lista de directorios delimitada por espacios (pero de lo contrario sin decorar) que el compilador envoltorio habría proporcionado al compilador subyacente para indicar dónde se encuentran los archivos de encabezado relevantes.
  • --showme:libdirs: Muestra una lista de directorios delimitada por espacios (pero de lo contrario sin decorar) que el compilador envoltorio habría proporcionado al enlazador subyacente para indicar dónde se encuentran las bibliotecas relevantes.
  • --showme:libs: Muestra una lista de nombres de bibliotecas delimitada por espacios (pero de lo contrario sin decorar) que el compilador envoltorio habría utilizado para enlazar una aplicación. Por ejemplo: mpi open-pal util.
  • --showme:version: Muestra el número de versión de Open MPI.
  • --showme:help: Muestra un breve mensaje de ayuda de uso.

Consulte la página del manual de su compilador subyacente para ver otras opciones que se pueden pasar a través de mpicc.

DESCRIPCIÓN

Conceptualmente, el papel de estos comandos es bastante simple: agregar de forma transparente las banderas del compilador y del enlazador relevantes a la línea de comandos del usuario que son necesarias para compilar / enlazar programas Open MPI, y luego invocar al compilador subyacente para realizar la operación.

Como tales, estos comandos a menudo se denominan compiladores "envoltorio" porque no compilan ni enlazan aplicaciones por sí mismos; solo agregan banderas a la línea de comandos e invocan al compilador de fondo.

ANTECEDENTES

Open MPI proporciona compiladores envoltorio para varios idiomas:

  • mpicc: C
  • mpic++, mpicxx (y en sistemas con sistemas de archivos sensibles a mayúsculas y minúsculas, mpiCC): C++

    NOTA:

mpic++, mpicxx y mpiCC invocan el mismo compilador C++ subyacente con las mismas opciones. Todos se proporcionan como compatibilidad con otras implementaciones de MPI.
  • mpifort (y sus alias obsoletos/deprecados mpif77 y mpif90): Fortran
  • mpijavac: Java

Los compiladores envoltorio para cada uno de los idiomas son idénticos; pueden usarse indistintamente. Los diferentes nombres se proporcionan únicamente por compatibilidad hacia atrás.

NOTAS DE FORTRAN

El compilador envoltorio de Fortran para MPI (mpifort, y sus nombres obsoletos/deprecados mpif77 y mpif90) puede compilar y enlazar aplicaciones MPI que utilicen cualquiera/todas las vinculaciones de Fortran de MPI: mpif.h, el módulo mpi y el módulo mpi_f08 (suponiendo que Open MPI se instaló con soporte para cada una de estas vinculaciones de Fortran). Específicamente: ya no es necesario utilizar compiladores envoltorio diferentes para aplicaciones que utilizan mpif.h frente a aplicaciones que utilizan el módulo mpi; simplemente use mpifort para todas las aplicaciones MPI de Fortran.

Sin embargo, tenga en cuenta que el compilador Fortran puede requerir opciones de línea de comandos adicionales para forzar un dialecto Fortran específico. Por ejemplo, en algunas versiones del compilador IBM XLF, si xlf90 es el compilador Fortran subyacente, puede ser necesario -qfixed para compilar archivos fuente Fortran de formato fijo.

Finalmente, tenga en cuenta que mpifort será inoperante y generará un error al usarse si el soporte de Fortran no se compiló en la capa MPI.

VISIÓN GENERAL

mpicc es un envoltorio de conveniencia para el compilador C subyacente. La traducción de un programa Open MPI requiere el enlace de las bibliotecas específicas de Open MPI que pueden no residir en uno de los directorios de búsqueda estándar de ld(1). También requiere la inclusión de archivos de encabezado que pueden no encontrarse en una ubicación estándar.

mpicc pasa sus argumentos al compilador C subyacente junto con las opciones -I, -L y -l requeridas por los programas Open MPI.

Lo mismo ocurre con todos los demás compiladores envoltorio de lenguaje.

El equipo de Open MPI fomenta *encarecidamente* el uso de los compiladores envoltorio en lugar de intentar enlazar a las bibliotecas de Open MPI manualmente. Esto permite que la implementación específica de Open MPI cambie sin forzar cambios en las directivas del enlazador en los Makefiles de los usuarios. De hecho, el conjunto específico de banderas y bibliotecas utilizadas por los compiladores envoltorio depende de cómo se configuró y compiló Open MPI; los valores pueden cambiar entre diferentes instalaciones de la misma versión de Open MPI.

De hecho, dado que los envoltorios son simplemente capas delgadas sobre un compilador subyacente, hay muy, muy pocas razones convincentes para *no* usar los compiladores envoltorio de Open MPI. Cuando no es posible usar los envoltorio directamente, se deben usar las opciones --showme:compile y --showme:link para determinar qué banderas usarían los envoltorio. Por ejemplo:

shell$ cc -c file1.c `mpicc --showme:compile`
shell$ cc -c file2.c `mpicc --showme:compile`
shell$ cc file1.o file2.o `mpicc --showme:link` -o my_mpi_program

NOTAS

Es posible hacer que los compiladores envoltorio sean conscientes de múltiples bibliotecas. Es decir, las bibliotecas e inclusiones especificadas pueden diferir según las banderas del compilador especificadas (por ejemplo, con los compiladores GNU en Linux, se puede usar una ruta de biblioteca diferente si se ve -m32 en comparación con -m64). Este no es el comportamiento predeterminado en una compilación estándar, pero se puede activar (por ejemplo, en un paquete binario que proporcione soporte para 32 y 64 bits). *Puede encontrar más información aquí*.

ARCHIVOS

Las cadenas que los compiladores envoltorio insertan en la línea de comandos antes de invocar al compilador subyacente se almacenan en un archivo de texto creado por Open MPI y se instala en $pkgdata/NOMBRE-wrapper-data.txt, donde:

  • $pkgdata suele ser $prefix/share/openmpi
  • $prefix es el directorio de instalación principal de Open MPI
  • NOMBRE es el nombre del compilador envoltorio (por ejemplo, $pkgdata/mpicc-wrapper-data.txt)

DESCRIPCIÓN

Estos archivos de configuración no suelen ser necesarios de editar, pero pueden ser examinados para obtener información sobre qué indicadores usan los envoltorios en la línea de comandos.

VARIABLES DE ENTORNO

Por defecto, los envoltorios usan los compiladores que fueron seleccionados cuando Open MPI fue configurado. Estos compiladores fueron encontrados automáticamente por el script “configure” de Open MPI, o fueron seleccionados por el usuario en las variables de entorno CC, CXX y/o FC antes de que se invocara configure. Adicionalmente, otros argumentos específicos del compilador pueden haber sido seleccionados por configure.

Estos valores pueden ser anulados selectivamente editando los archivos de texto que contienen esta información de configuración (ver la sección ARCHIVOS), o estableciendo variables de entorno seleccionadas de la forma ompi_value.

Los nombres de valor válidos son:

  • CPPFLAGS: Indicadores añadidos al invocar el preprocesador (C o C++)
  • LDFLAGS: Indicadores añadidos al invocar el enlazador (C, C++ o Fortran)
  • LIBS: Bibliotecas añadidas al invocar el enlazador (C, C++ o Fortran)
  • CC: Compilador C
  • CFLAGS: Indicadores del compilador C
  • CXX: Compilador C++
  • CXXFLAGS: Indicadores del compilador C++
  • FC: Compilador Fortran
  • FCFLAGS: Indicadores del compilador Fortran
