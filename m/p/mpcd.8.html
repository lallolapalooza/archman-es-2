mpcd(8) Comandos de mantenimiento mpcd(8)

NOMBRE

mpcd - demonio cliente MPOA (Multi-Protocol Over ATM) de ATM

SINOPSIS

mpcd [ -s dirección ATM de control ] [ -l dirección ATM de datos ] [ -c dirección ATM de control MPS ] [ -i número de interfaz ] [ -m dirección MAC MPS ] [ -L dirección LEC [ -n nombre ELAN ] [ -C dirección LECS ]]

DESCRIPCIÓN

El cliente MPOA (MPC) es responsable de crear y recibir accesos directos de capa internetwork. Usando estos accesos directos, los MPC reenvían paquetes de capa internetwork de unicast de manera efectiva sobre ATM sin necesidad de protocolos de enrutamiento.

El MPC tiene dos roles; de entrada y de salida. En el rol de entrada, el MPC detecta flujos destinados fuera de su propia subred e intenta establecer accesos directos a esos destinos. En el rol de salida, el MPC acepta accesos directos y paquetes que llegan por esos accesos directos. El mantenimiento de los accesos directos se realiza con la ayuda del servidor MPOA (MPS).

Al igual que el cliente de Emulación de LAN de Linux, el cliente MPOA también está dividido en dos partes. Las partes son el componente del kernel y un proceso demonio. El demonio abre y recibe accesos directos de datos y conexiones de control con el componente del kernel. El componente del kernel totaliza los paquetes que fluyen desde el dispositivo LANE y toma la decisión de si un paquete debe ser reenviado usando accesos directos LANE o MPOA.

Si el demonio es terminado con SIGHUP, cerrará todas las conexiones abiertas, purgará las entradas de caché de entrada y salida, consultará a LECS si es aplicable y luego se reiniciará.

El cliente MPOA de Linux solo soporta accesos directos no multiplexados por LLC. El número de clientes MPOA soportados es ilimitado.

OPCIONES

-s dirección ATM de control
Dirección ATM local que este MPC utiliza para las conexiones de control MPOA.
-l dirección ATM de datos
Dirección ATM local desde y hacia la cual se establecen los accesos directos MPOA.
-c dirección ATM de control MPS
Dirección ATM del MPS. Solo se necesita si el MPS no puede anunciarse por sí mismo.
-i número de interfaz
El número de interfaz de LEC al que sirve este MPC. Por ejemplo, 2 para "lec2".
-m dirección MAC MPS
Dirección MAC del router por defecto donde reside el MPS. Solo útil si el servidor MPOA no logra anunciarse a sí mismo.
-L dirección LEC
Dirección de escucha del cliente LANE zeppelin. mpcd usa esta dirección como su propia dirección ATM cuando consulta a LECS para parámetros de configuración de MPC. Si esta opción no está presente, mpcd no usará LECS para consultar parámetros de configuración. Esta opción es normalmente la misma que la opción -l de zeppelin.
-n nombre ELAN
Nombre del ELAN para el cual mpcd solicita parámetros cuando se conecta a LECS. Si esta opción no se proporciona, LECS debería responder con parámetros que pertenecen al ELAN predeterminado si existe uno. Esta opción es normalmente la misma que la opción -n de zeppelin.
-C dirección LECS
Dirección ATM de LECS. mpcd solicita parámetros. Si esta opción se deja vacía y se proporciona -L, mpcd usa la dirección LECS de Bien Conocida asignada por ATM Forum. Esta opción es normalmente la misma que la opción -c de zeppelin.

EJEMPLOS

Este fragmento de script muestra cómo ejecutar LANE y MPOA. Después de que la señalización UNI y ILMI se han iniciado, se inician LANE (zeppelin) y MPOA (mpcd). La línea comentada muestra cómo iniciar mpcd para que consulte a LECS para parámetros de MPC.

Los argumentos jaarli[1-3] son direcciones ATM locales listadas en el archivo /etc/hosts.atm.

ATM=/usr/src/atm
case "$1" in
start)
cd $ATM
if [ -x sigd/atmsigd ] ; then


sigd/atmsigd -b
fi
if [ -x ilmid/ilmid ] ; then

ilmid/ilmid -b -x
fi
if [ -x led/zeppelin ] ; then

led/zeppelin -2 -n sampo -i2 -l jaarli3 &
ifconfig lec2 10.10.10.208 \

netmask 255.255.255.192 \
broadcast 10.10.10.255
ifconfig lec2 up
route add default gw 10.10.10.193
fi
if [ -x mpoad/mpcd ] ; then

mpoad/mpcd -i2 -s jaarli1 -l jaarli2 &
#mpoad/mpcd -i2 -s jaarli1 -l jaarli2 \
-L jaarli3 -n sampo &
fi
;;
esac
exit 0

ERRORES

Solo soporta ELANs de tipo Ethernet. Probablemente otros también.
