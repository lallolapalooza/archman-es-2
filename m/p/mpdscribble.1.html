NOMBRE

mpdscribble - Un cliente de Music Player Daemon (MPD) que envía información sobre las pistas que se están reproduciendo a un scrobbler (por ejemplo, last.fm).

SINOPSIS

mpdscribble [opciones]

DESCRIPCIÓN

mpdscribble es un cliente para MPD, el Music Player Daemon. mpdscribble se conecta a un MPD en ejecución en la red local y funciona en paralelo con otros clientes MPD en la red.

Por defecto, obtendrá el nombre de host y el puerto de mpd de las variables de entorno MPD_HOST y MPD_PORT. mpdscribble usará localhost:6600 si estas no están establecidas. El nombre de host y el puerto también se pueden especificar en el archivo de configuración o en la línea de comandos.

$ mpdscribble --host mi-host --port=12345

Los valores especificados en la línea de comandos anulan los valores del archivo de configuración o de las variables de entorno.

Si desea usar mpdscribble con un MPD protegido por contraseña, configure la variable de entorno MPD_HOST a password@host, o especifique el host de manera similar en el archivo de configuración.

En caso de fallo al enviar, mpdscribble espera un tiempo y luego reintenta. Enviar una señal USR1 a un proceso mpdscribble en ejecución hace que envíe inmediatamente.

OPCIONES

--help
Muestra la ayuda y sale.
--version
Muestra la información de la versión y sale.
--no-daemon
No demoneizar mpdscribble, ejecutarlo en primer plano.
--pidfile ARCHIVO
Escribe el ID del proceso en este archivo.
--daemon-user NOMBRE_DE_USUARIO
Cambiar a este usuario del sistema después de la demoneización.
--log ARCHIVO
Especifica el archivo de registro. El valor especial "syslog" hace que mpdscribble use el demonio syslog local (que es el predeterminado). "-" significa registrar en stderr.
--conf ARCHIVO
Lee las opciones de configuración del archivo. Se usa /etc/mpdscribble.conf por defecto (si --sysconfdir=/etc). Se puede sobrescribir con una ruta específica.
--host [CONTRASEÑA@]NOMBRE_DE_HOST
Especifica el host protegido por contraseña. Para conectarse a través de un socket de dominio Unix, especifique una ruta absoluta aquí.
--port PUERTO
Especifica en qué puerto escucha MPD.
--proxy URL
URL del proxy HTTP.
--verbose NIVEL
Especifica el nivel de verbosidad del registro de mpdscribble. Los valores posibles son de 0 a 3, siendo 1 el predeterminado.

CONFIGURACIÓN

mpdscribble busca su archivo de configuración en el siguiente orden: $XDG_CONFIG_HOME/mpdscribble/mpdscribble.conf, ~/.config/mpdscribble/mpdscribble.conf, ~/.mpdscribble/mpdscribble.conf, /etc/mpdscribble.conf (si --sysconfdir=/etc) pero esto puede ser anulado especificando un archivo de configuración alternativo usando la opción de línea de comandos --conf.

Opciones de configuración soportadas:

pidfile = ARCHIVO
Escribe el ID del proceso en este archivo.
log = ARCHIVO
El archivo al que mpdscribble debe enviar la información de depuración. El valor especial "syslog" hace que mpdscribble use el demonio syslog local (que es el predeterminado). "-" significa registrar en stderr.
host = [CONTRASEÑA@]NOMBRE_DE_HOST
El host que ejecuta MPD, posiblemente protegido por una contraseña. Para conectarse a través de un socket de dominio Unix, especifique una ruta absoluta aquí.
port = PUERTO
El puerto en el que MPD escucha y al que mpdscribble debe intentar conectarse.
proxy = URL
URL del proxy HTTP.
verbose = 0, 1, 2, 3
Qué tan verboso debe ser el registro de mpdscribble. Predeterminado es 1. "0" significa registrar solo errores críticos (por ejemplo, "memoria insuficiente"); "1" también registra errores no críticos (por ejemplo, "servidor inalcanzable"); "2" registra mensajes informativos (por ejemplo, "nueva canción"); "3" imprime muchos mensajes de depuración.

SCROBBBLERS

Estas opciones van seguidas de al menos una sección de scrobbler (elija un nombre de sección único como "libre.fm" que solo aparece en el archivo de registro; el nombre "mpdscribble" está reservado).

file = RUTA
Registra en un archivo en lugar de enviar las canciones a un servidor AudioScrobbler.
url = URL
La URL de saludo del scrobbler. Ejemplo: "https://post.audioscrobbler.com/", "http://turtle.libre.fm/"
username = NOMBRE_DE_USUARIO
Tu nombre de usuario de audioscrobbler.
password = SumaMD5
Tu contraseña de Last.fm, en texto plano o su suma MD5.
journal = ARCHIVO
El archivo donde mpdscribble debe almacenar su diario en caso de que no tengas conexión con el scrobbler. Esta opción solía llamarse "cache". Es opcional.

ARCHIVOS

/etc/mpdscribble.conf

El archivo de configuración a nivel de sistema.

~/.config/mpdscribble/mpdscribble.conf

Archivo de configuración por usuario.

/var/cache/mpdscribble/mpdscribble.cache

El archivo de caché de Last.fm a nivel de sistema.

~/.cache/mpdscribble/mpdscribble.cache

Archivo de caché de Last.fm por usuario.

/var/log/mpdscribble/mpdscribble.log

El archivo de registro a nivel de sistema.

ERRORES

Los permisos de archivo en el archivo de caché/registro pueden ser inseguros por defecto.

Por favor, informa de nuevos errores en el rastreador de errores de MPD: http://www.musicpd.org/mantis
