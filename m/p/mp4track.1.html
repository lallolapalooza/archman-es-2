MP4TRACK(-) Mayo 2023 MP4TRACK(-)

NOMBRE

mp4track - MP4v2 - página del manual para mp4track - MP4v2 2.1.3

SINOPSIS

mp4track [OPCIÓN]... [PARÁMETROS]... ACCIÓN archivo...

DESCRIPCIÓN

Para cada archivo mp4 especificado, realiza la ACCIÓN especificada. Se debe especificar una acción. Algunas opciones no son aplicables a algunas acciones.

ACCIONES

--list
listar todas las pistas en mp4
--enabled BOOL
establecer flags de trak.tkhd (bit habilitado)
--inmovie BOOL
establecer flags de trak.tkhd (bit inMovie)
--inpreview BOOL
establecer flags de trak.tkhd (bit inPreview)
--layer NUM
establecer trak.tkhd.layer
--altgroup NUM
establecer trak.tkhd.alternate_group
--volume FLOAT
establecer trak.tkhd.volume
--width FLOAT
establecer trak.tkhd.width
--height FLOAT
establecer trak.tkhd.height
--language CODE
establecer trak.mdia.mdhd.language
--hdlrname STR
establecer trak.mdia.hdlr.name
--udtaname STR
establecer trak.udta.name.value
--udtaname-remove
eliminar átomo trak.udta.name
--colr-list
listar todas las cajas colr en mp4
--colr-add
añadir caja colr a una pista de video
--colr-set
establecer parámetros de la caja colr
--colr-remove
eliminar caja colr de la pista
--pasp-list
listar todas las cajas pasp en mp4
--pasp-add
añadir caja pasp a una pista de video
--pasp-set
establecer parámetros de la caja pasp
--pasp-remove
eliminar caja pasp de la pista

PARÁMETROS

--track-any
actuar sobre cualquier/todas las pistas
--track-index IDX
actuar sobre la pista con índice IDX
--track-id ID
actuar sobre la pista con ID
--colr-parms CSV
donde CSV es IDX1,IDX2,IDX3
--colr-parm-hd
equivalente a --colr-parms=1,1,1
--colr-parm-sd
equivalente a --colr-parms=6,1,6
--pasp-parms CSV
donde CSV es hSPACING,vSPACING

OPCIONES

-z, --optimize
optimizar el archivo mp4 después de la modificación
-y, --dryrun
no crear ni modificar ningún archivo
-k, --keepgoing
continuar el procesamiento por lotes incluso después de errores
-o, --overwrite
sobrescribir archivos existentes al crear
-f, --force
forzar la sobrescritura incluso si el archivo es de solo lectura
-q, --quiet
equivalente a --verbose 0
-d, --debug NUM
aumentar depuración o opción larga para establecer NUM
-v, --verbose NUM
aumentar verbosidad o opción larga para establecer NUM
-h, --help
imprimir ayuda breve u opción larga para ayuda extendida
--version
imprimir información de la versión y salir

NIVELES DE DEPURACIÓN (para E/S de archivos mp4 sin procesar)

0
suprimido
1
añadir advertencias y errores (predeterminado)
2
añadir detalles de tablas
3
añadir implícitos
4
todo

NIVELES DE VERBOSIDAD

0
advertencias y errores
1
mensajes informativos normales (predeterminado)
2
mensajes más informativos
3
todo
