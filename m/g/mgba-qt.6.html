NOMBRE

mgba-qt — emulador de Game Boy Advance

SINOPSIS

mgba-qt [-123456fg] [-b archivo_bios] [-C opción=valor] [-l nivel_registro] [-p archivo_parche] [-s n] [-t archivo_estado] archivo

DESCRIPCIÓN

mgba-qt es un emulador de Game Boy Advance. Las opciones son las siguientes:

-1
Escalar la ventana 1x.
-2
Escalar la ventana 2x.
-3
Escalar la ventana 3x.
-4
Escalar la ventana 4x.
-5
Escalar la ventana 5x.
-6
Escalar la ventana 6x.
-b archivo_bios, --bios archivo_bios
Especificar un archivo BIOS para usar durante el arranque. Si esta bandera se omite, mgba-qt usará el BIOS especificado en el archivo de configuración, o un BIOS emulado de alto nivel si no se especifica ninguno.
-C opción=valor, --config opción=valor
Sobrescribir la opción de configuración dada con valor.
-f
Iniciar el emulador en pantalla completa.
-g
Iniciar una sesión de gdb(1). Por defecto, la sesión comienza en el puerto 2345.
-l nivel_registro
Registrar mensajes durante la emulación. nivel_registro es una máscara de bits que define qué tipos de mensajes registrar:
  • 1 – errores fatales
  • 2 – errores
  • 4 – advertencias
  • 8 – mensajes informativos
  • 16 – mensajes de depuración
  • 32 – mensajes de stub para funcionalidades no implementadas
  • 64 – errores dentro del juego
Por defecto, se registran advertencias, errores, errores fatales y mensajes de estado.
-p archivo_parche, --patch archivo_parche
Especificar un archivo de parche en formato BPS, IPS o UPS.
-s n, --frameskip n
Omitir cada n fotogramas.
-t archivo_estado, --savestate archivo_estado
Cargar el estado inicial del juego desde archivo_estado.

ENTORNO

XDG_CONFIG_HOME
La ubicación donde mgba-qt buscará el directorio de configuración. Si no está configurada, se usa ~/.config.

ARCHIVOS

$XDG_CONFIG_HOME/mgba/config.ini
Archivo de configuración por defecto de mgba(6).
$XDG_CONFIG_HOME/mgba/qt.ini
Archivo de configuración por defecto de mgba-qt.
portable.ini
Si este archivo existe en el directorio actual, mgba-qt leerá config.ini y qt.ini desde el directorio actual en lugar de $XDG_CONFIG_HOME/mgba.
