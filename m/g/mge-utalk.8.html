NOMBRE

mge-utalk - Controlador para equipos con protocolo UTalk de MGE UPS SYSTEMS

SINOPSIS

mge-utalk -h

mge-utalk -a NOMBRE_UPS [OPCIONES]


Nota

Esta página del manual solo documenta las características específicas del hardware del controlador mge-utalk. Para obtener información sobre el controlador principal, consulte nutupsdrv(8).

HARDWARE SOPORTADO

mge-utalk soporta las siguientes unidades heredadas, utilizando el protocolo UTalk de MGE:

•Pulsar ESV+
•Pulsar ES+
•Pulsar EL
•Pulsar EX
•Pulsar EXtreme
•Comet EXtreme
•Comet (Tarjeta Serie UTalk, ref 66060)
•Galaxy (Tarjeta Serie UTalk, ref 66060)

Este controlador también soporta modelos más recientes con compatibilidad UTalk hacia atrás, como Pulsar Evolution y Pulsar EXtreme C. Dado que estos modelos también soportan el protocolo SHUT, prefiera mge-shut(8) para la comunicación serie, o utilice el puerto USB, si está disponible, con el controlador usbhid-ups(8).

ARGUMENTOS ADICIONALES

Este controlador soporta las siguientes configuraciones opcionales en el archivo ups.conf(5):

lowbatt=num

Establece el umbral de advertencia de batería baja al que se inicia el apagado por upsmon(8).

El valor predeterminado de fábrica es 30 (en porcentaje), y puede ser configurable dependiendo del modelo exacto.

offdelay=num

Establece el tiempo antes de que la UPS se apague después de que se envíe el comando de corte de energía (a través del interruptor -k).

El valor predeterminado es 20 (en segundos).

ondelay=num

Establece el retardo antes de que la UPS se encienda, después de que regrese la energía.

El valor predeterminado es 1 (en minutos).

oldmac

Establezca esta bandera si está ejecutando Linux en un equipo Macintosh Oldworld (todos los Macintosh Apple beige). Esto también podría ser necesario para otros sistemas operativos (como *BSD) que se ejecutan en PowerMac.

PROBLEMAS CONOCIDOS

Timeout repetitivo y datos obsoletos

Los modelos más antiguos, como los ES/ESV, pueden reportar errores repetitivos de "datos obsoletos". Esto se debe a que estos modelos no soportan demasiadas consultas. Para resolver este problema, agregue pollinterval=20 en ups.conf, y cambie el valor de MAXAGE a 25 en ups.conf, y DEADTIME a 25 en upsmon.conf.
