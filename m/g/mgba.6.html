NOMBRE

mgba — Emulador de Game Boy Advance

SINOPSIS

mgba [-123456dfg] [-b archivo_bios] [-C opcion=valor] [-c archivo_trampas] [-l nivel_log] [-p archivo_parche] [-s n] [-t archivo_estado] archivo

DESCRIPCIÓN

mgba es un emulador de Game Boy Advance. Las opciones son las siguientes:

-1
Escalar la ventana 1×.
-2
Escalar la ventana 2×.
-3
Escalar la ventana 3×.
-4
Escalar la ventana 4×.
-5
Escalar la ventana 5×.
-6
Escalar la ventana 6×.
-b archivo_bios, --bios archivo_bios
Especificar un archivo BIOS para usar durante el arranque. Si esta bandera se omite, mgba usará el BIOS especificado en el archivo de configuración, o un BIOS emulado de alto nivel si no se especifica ninguno.
-C opcion=valor, --config opcion=valor
Anular la opción de configuración dada con valor.
-c archivo_trampas, --cheats archivo_trampas
Aplicar códigos de trampas del archivo_trampas.
-d
Iniciar la emulación a través del depurador de línea de comandos.
-f
Iniciar el emulador a pantalla completa.
-g
Iniciar una sesión de gdb(1). Por defecto la sesión se inicia en el puerto 2345.
-l nivel_log
Registrar mensajes durante la emulación en stdout. nivel_log es una máscara de bits que define qué tipos de mensajes registrar:
  • 1 – errores fatales
  • 2 – errores
  • 4 – advertencias
  • 8 – mensajes informativos
  • 16 – mensajes de depuración
  • 32 – mensajes de marcador de posición para funciones no implementadas
  • 64 – errores dentro del juego
El valor por defecto es registrar advertencias, errores, errores fatales y mensajes de estado.
-p archivo_parche, --patch archivo_parche
Especificar un archivo de parche en formato BPS, IPS o UPS.
-s n, --frameskip n
Saltar cada n fotogramas.
-t archivo_estado, --savestate archivo_estado
Cargar el estado inicial del juego desde archivo_estado.

DEPURADOR

Cuando mgba se ejecuta con la opción -d, el depurador de línea de comandos está habilitado. Soporta los siguientes comandos:

b[reak] direccion
 
b[reak]/a direccion
 
b[reak]/t direccion
Establecer un punto de interrupción – ARM (‘/a’), Thumb (‘/t’), o el modo de CPU actual – en la dirección.
c[ontinue]
Continuar la ejecución.
d[elete] direccion
Eliminar un punto de interrupción en la dirección.
dis[asm] [direccion [contador]]
 
dis[asm]/a [direccion [contador]]
 
dis[asm]/t [direccion [contador]]
 
dis[assemble] [direccion [contador]]
 
dis[assemble]/a [direccion [contador]]
 
dis[assemble]/t [direccion [contador]]
Desensamblar contador instrucciones a partir de la dirección, como ARM (‘/a’), Thumb (‘/t’), o el modo de CPU actual. Si no se especifica contador, solo desensamblar la instrucción en la dirección. Si no se especifica dirección, solo desensamblar la dirección actual.
h[elp]
Imprimir ayuda.
i[nfo]
 
status
Imprimir el contenido actual de los registros de propósito general y el cur

x/1dirección [contador]
 
x/2dirección [contador]
 
x/4dirección [contador]
Examinar contador bytes (‘/1’), medias palabras (‘/2’), o palabras (‘/4’) desde dirección. Si contador no se especifica, examinar 16 bytes, 8 medias palabras, o 4 palabras.

AMBIENTE

XDG_CONFIG_HOME
La ubicación donde mgba buscará el directorio de configuración. Si no está establecido, se utiliza ~/.config.

ARCHIVOS

$XDG_CONFIG_HOME/mgba/config.ini
Archivo de configuración por defecto de mgba.
portable.ini
Si este archivo existe en el directorio actual, mgba leerá config.ini desde el directorio actual en lugar de $XDG_CONFIG_HOME/mgba.
