NOMBRE

memslap - Documentación de libmemcached

SINOPSIS

memslap [opciones]

Prueba de carga y benchmark de un servidor

DESCRIPCIÓN

OPCIONES

-h|--help
Mostrar ayuda.
-V|--version
Mostrar versión.
-q|--quiet
Operar en silencio.
-v|--verbose
Operar de forma más verbosa.
-d|--debug
Ver -v|--verbose.
-s|--servers <lista de servidores>
Especificar la lista de servidores como nombrehost[:puerto][,nombrehost[:puerto]...].
-n|--non-blocking
Habilitar operaciones no bloqueantes.
-N|--tcp-nodelay
Deshabilitar el algoritmo de Nagle.
-b|--binary
Habilitar protocolo binario.
-B|--buffer
Almacenar solicitudes en búfer.
-u|--username <nombredeusuario>
Usar nombredeusuario para autenticación SASL.
-p|--password <contraseña>
Usar contraseña para autenticación SASL.
-H|--hash <algoritmo>
Usar algoritmo como algoritmo hash de claves. Ver memcached_behavior_t::MEMCACHED_BEHAVIOR_HASH.
-U|--udp
Habilitar modo de operación UDP.
-R|--noreply
Habilitar el comportamiento NOREPLY para comandos de almacenamiento.
-F|--flush
Vaciar todos los servidores antes de la prueba.
-t|--test <arg>
Prueba a realizar (opciones: get, mget, set; por defecto: get).
-c|--concurrency <num>
Concurrencia (número de hilos a iniciar; por defecto: 1).
-e|--execute-number <num>
Número de veces que se ejecutarán las pruebas (por defecto: 10000).
-l|--initial-load <num>
Número de claves a cargar antes de ejecutar las pruebas (por defecto: 10000).

AMBIENTE

MEMCACHED_SERVERS
Especificar una lista de servidores.

NOTAS

PREFIJO DEL PROGRAMA

El prefijo de este programa es variable, es decir, puede ser configurado en tiempo de compilación.

Normalmente los programas cliente de libmemcached-awesome tienen el prefijo mem, como memcat o memcp.

Sin embargo, puede ser configurado para reemplazar el prefijo con otra cosa como mc, en cuyo caso, los programas cliente de libmemcached-awesome se llamarían mccat, mccp, respectivamente.
