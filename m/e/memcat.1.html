MEMCAT(1) libmemcached-awesome MEMCAT(1)

NOMBRE

memcat - Documentación de libmemcached

SINOPSIS

memcat [opciones] clave [clave...]

Lee y muestra el valor de una clave o los valores de un conjunto de claves.

DESCRIPCIÓN

Si no se encuentra alguna clave, se devuelve un error.

OPCIONES

-h|--help
Muestra la ayuda.
-V|--version
Muestra la versión.
-q|--quiet
Operar en silencio.
-v|--verbose
Operar de forma más detallada.
-d|--debug
Ver -v|--verbose.
-s|--servers <lista de servidores>
Especifica la lista de servidores como hostname[:puerto][,hostname[:puerto]...].
-n|--non-blocking
Habilita operaciones no bloqueantes.
-N|--tcp-nodelay
Deshabilita el algoritmo de Nagle.
-b|--binary
Habilita el protocolo binario.
-B|--buffer
Almacena las solicitudes en búfer.
-u|--username <nombre de usuario>
Usa nombre de usuario para la autenticación SASL.
-p|--password <contraseña>
Usa contraseña para la autenticación SASL.
-F|--flags
Muestra las banderas de la clave.
-H|--hash <algoritmo>
Usa algoritmo como algoritmo de hash de claves. Ver memcached_behavior_t::MEMCACHED_BEHAVIOR_HASH.
-f|--file [<archivo>]
Salida a un archivo en lugar de a la salida estándar.

NOTA: por defecto es <clave> si no se proporcionó ningún argumento.

ENTORNO

MEMCACHED_SERVERS
Especifica una lista de servidores.

NOTAS

PREFIJO DEL PROGRAMA

El prefijo de este programa es variable, es decir, puede configurarse en el momento de la compilación.

Por lo general, los programas cliente de libmemcached-awesome comienzan con el prefijo mem, como memcat o memcp.

Sin embargo, puede configurarse para reemplazar el prefijo con otra cosa, como mc; en ese caso, los programas cliente de libmemcached-awesome se llamarían mccat, mccp, etc., respectivamente.
