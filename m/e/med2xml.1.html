DESCRIPCIÓN

El conjunto de programas bibutils interconvierte entre varios formatos de bibliografía utilizando el Metadata Object Description Schema (MODS)[2]versión 3.1 de la Library of Congress[1]. Por ejemplo, se pueden convertir archivos en formato RIS a Bibtex realizando dos transformaciones: RIS>MODS>Bibtex.

CONVERSIÓN A MODS

Visión general

Comando Descripción
bib2xml convierte bibtex a MODS
biblatex2xml convierte biblatex a MODS
copac2xml convierte referencias en formato COPAC[3] a MODS
ebi2xml convierte EBI XML a MODS
end2xml convierte EndNote (formato Refer) a MODS
endx2xml convierte EndNote XML a MODS
isi2xml convierte ISI web of science a MODS
med2xml convierte referencias XML de Pubmed a MODS
nbib2xml convierte referencias en formato nbib de Pubmed a MODS
modsclean un conversor de MODS a MODS
ris2xml convierte formato RIS a MODS
wordbib2xml convierte bibliografía XML de Word2007 a MODS

Opciones comunes para convertir a MODS

Varios indicadores disponibles para los programas end2xml, endx2xml, bib2xml, ris2xml, med2xml y copac2xml. La mayoría de las opciones tienen una versión corta y una larga.

-h --help muestra la ayuda
-v --version muestra la versión
-a --add-refcount añade "_#" donde # es el recuento de referencias al id de referencia
-s --single-refperfile pon una referencia por nombre de archivo según el número de referencia
-i --input-encoding interpreta el archivo de entrada utilizando el conjunto de caracteres solicitado (úselo sin argumento para la lista actual derivada de los conjuntos de caracteres en www.kostis.net[4]) unicode es ahora una opción de conjunto de caracteres
-u --unicode-characters codifica caracteres unicode directamente en el archivo en lugar de como entidades XML
-un --unicode-no-bom igual que -u, pero no incluye una marca de orden de bytes
-x --xml-entities codifica caracteres unicode como entidades XML (lo opuesto a -u)
-nl --no-latex no convierte combinaciones de caracteres estilo latex
-s --single-refperfile una referencia por archivo de salida
-d --drop-key no pone la clave de cita en el campo id de mods
-c --corporation-file con un argumento que especifica un archivo que contiene una lista de nombres de corporaciones para colocarlos en <name type="corporate"></name> en lugar de type="personal" y eliminar la manipulación de nombres
-a --asis con un argumento que especifica un archivo que contiene una lista de nombres para ser tratados literalmente
-nt --nosplit-title no divide títulos en pares TÍTULO/SUBTÍTULO
--verbose salida detallada
--debug salida muy detallada (principalmente para depuración)

bib2xml

bib2xml convierte un archivo de referencia en formato bibtex a un archivo de bibliografía intermedio XML. Especifique los archivos a convertir en la línea de comandos. Los archivos que contienen cadenas de sustitución de bibtex deben especificarse antes que los archivos donde se especifican las sustituciones (o en el mismo archivo antes de su uso). Si no se especifican archivos, la información de bibtex se leerá de la entrada estándar.

bib2xml archivo_bibtex.bib > archivo_salida.xml

biblatex2xml

biblatex2xml convierte un archivo de referencia en formato biblatex (no confundir con bibtex) a un archivo de bibliografía intermedio MODS XML.

biblatex2xml archivo_biblatex.bib > archivo_salida.xml

copac2xml

copac2xmlconvierte un archivo de referencia en formato COPAC a un archivo de bibliografía intermedio MODS XML.

end2xml

end2xml convierte un archivo de referencia en formato endnote de texto a un archivo de bibliografía intermedio XML. Este programa no funcionará en la biblioteca binaria; el archivo debe exportarse primero. Los formatos etiquetados de Endnote (exportación en formato "Refer") se parecen al Ejemplo 1, "Archivo de formato refer de ejemplo". Hay instrucciones muy buenas para asegurarse de que está exportando esto correctamente en http://www.sonnysoftware.com/endnoteimport.html[5]

El uso de end2xml es el mismo que el de bib2xml.

end2xml archivo_endnote.end > archivo_salida.xml

ebi2xml

ebi2xml convierte un archivo EBI XML a un archivo de bibliografía intermedio MODS XML.

endx2xml

endx2xml convierte un archivo de referencia exportado de EndNote-XML a un archivo de bibliografía intermedio MODS XML. Este programa no funcionará en la biblioteca binaria; el archivo debe exportarse primero.

isi2xml

isi2xml convierte un archivo de referencia en formato ISI-web-of-science a un archivo de bibliografía intermedio XML.

El uso de isi2xml es el mismo que el de bib2xml.

isi2xml archivo_entrada.isi > archivo_salida.xml

ris2xml

ris2xml convierte un archivo de referencia en formato RIS a un archivo de bibliografía intermedio XML. El uso de ris2xml es como el de end2xml y bib2xml

ris2xml archivo_ris.ris >	archivo_salida.xml

wordbib2xml

wordbib2xml convierte un archivo de referencia en formato Word2007 a un archivo de bibliografía intermedio XML.

Opciones Comunes para la Conversión desde MODS

Tenga en cuenta que --output-encoding se refiere al archivo de entrada.

-h --help mostrar ayuda
-v --version mostrar versión
-o --output-encoding interpretar el archivo de entrada utilizando el juego de caracteres solicitado (usar sin argumento para la lista actual derivada de los juegos de caracteres en www.kostis.net[4]) unicode es ahora una opción de juego de caracteres
-s --single-refperfile poner una referencia por nombre de archivo según el número de referencia
-nb --no-bom no escribir Marcador de Orden de Bytes si se escribe UTF8

xml2bib

xml2bib convierte la bibliografía XML de MODS a un archivo de referencias con formato bibtex. El uso de xml2bib es como el de otras herramientas.

xml2bib xml_file.xml > output_file.bib

Dado que el formato de referencia BibTeX es bastante flexible y parece tener el mayor número de preferencias personales, también ha acumulado una serie de opciones específicas que no están disponibles para otros formatos.

A partir de la versión 3.24, la salida de xml2bib utiliza etiquetas en minúsculas y tipos de referencia con mayúsculas y minúsculas combinadas para una mejor interacción con otro software. El comportamiento anterior con etiquetas/tipos de referencia en mayúsculas se puede generar todavía usando el modificador de línea de comandos -U/--uppercase.

Opciones específicas de xml2bib:

-fc --finalcomma añadir coma final en la salida bibtex para aquellos que la deseen
-sd --singledash usar un guion en lugar de dos (guion más largo en latex) entre números en la salida de páginas
-b --brackets usar corchetes en lugar de comillas alrededor de los datos del campo
-w --whitespace añadir espacios en blanco para embellecer la salida
-U --uppercase usar mayúsculas para etiquetas (nombres de campo) y tipos de referencia (comportamiento anterior a la v3.24)
-sk --strictkey usar solo caracteres alfanuméricos para las claves de citación bibtex

xml2ads

xml2ads convierte la bibliografía XML de MODS al formato de referencia del Sistema de Datos Astrofísicos (ADS) del Smithsonian Astrophysical Observatory (SAO)/National Aeronautics and Space Administration (NASA) [6] (que es muy similar al estilo Endnote etiquetado). El uso de xml2ads es como el de otras herramientas.

xml2ads xml_file.xml > output_file.ads

xml2ris

xml2ris convierte la bibliografía XML de MODS a un archivo bibliográfico con formato RIS. El uso de xml2ris es como el de otras herramientas.

xml2ris xml_file.xml > output_file.ris

xml2end

xml2end convierte la bibliografía XML de MODS a un archivo bibliográfico de Endnote etiquetado (formato refer). El uso de xml2end es como el de otras herramientas.

xml2end xml_file.xml > output_file.end

xml2wordbib

xml2wordbib convierte la bibliografía XML de MODS a un archivo bibliográfico XML con formato Word 2007. El uso de xml2wordbib es como el de otras herramientas.

xml2wordbib xml_file.xml > output_file.word.xml

xml2wordbib se llamaba xml2word en versiones de bibutils anteriores a la 3.40. Se cambió el nombre para evitar confusiones con otras herramientas. Esperamos que esto no rompa demasiados scripts ya en uso.
