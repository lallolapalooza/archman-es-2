NOMBRE

mergerepo_c - Fusionar múltiples repositorios en formato rpm-md juntos

SINOPSIS

mergerepo_c [opciones] --repo repo1 --repo repo2

OPCIONES

--version

Mostrar el número de versión del programa y salir

-r --repo REPOS

URL del repositorio

--repo-prefix-search OLD_PREFIX

Prefijo del repositorio a ser reemplazado por NEW_PREFIX.

--repo-prefix-replace NEW_PREFIX

Prefijo de URL del repositorio por el cual se reemplaza OLD_PREFIX.

-a --archlist ARCHLIST

Por defecto todas las arquitecturas - de lo contrario, especificar arquitecturas

-d --database

--no-database

-v --verbose

-o --outputdir OUTPUTDIR

Ubicación para crear el repositorio

--nogroups

No fusionar metadatos de grupo (comps)

--noupdateinfo

No fusionar metadatos de updateinfo

--compress-type COMPRESS_TYPE

Qué tipo de compresión usar

--zck

Generar archivos zchunk además de los repodata estándar.

--zck-dict-dir ZCK_DICT_DIR

Directorio que contiene diccionarios de compresión para su uso por zchunk

--method MERGE_METHOD

Especificar el método de fusión para paquetes con el mismo nombre y arquitectura.

Métodos de fusión disponibles:

repo

(por defecto) seleccionar paquete del primer repositorio especificado.

nvr

seleccionar el paquete con la versión y release más alta.

ts

seleccionar el paquete con la marca de tiempo más reciente.

--all

Incluir todos los paquetes con el mismo nombre y arquitectura si la versión o release es diferente. Si se usa, ¡el argumento --method se ignora!

--noarch-repo URL

Los paquetes con arquitectura no-arch se reemplazarán por el paquete de este repositorio si existe en él.

--unique-md-filenames

Incluir la suma de verificación del archivo en el nombre del archivo de metadatos, ayuda al caché HTTP (por defecto).

--simple-md-filenames

No incluir la suma de verificación del archivo en el nombre del archivo de metadatos.

--omit-baseurl

No añadir un baseurl a los paquetes que no lo tengan antes.

-k --koji

Habilitar el comportamiento de mergerepos de koji. (Opcionalmente seleccionar modo simple con: --simple)

--simple

Habilitar el modo de fusión simple específico de koji donde conservamos incluso los paquetes con NEVRAs idénticos. Solo funciona en combinación con --koji/-k.

--pkgorigins

Habilitar el comportamiento estándar de mergerepos mientras también se proporciona el archivo pkgorigins para koji.

--arch-expand

Añadir arquitecturas multilib para la archlist especificada y expandirlas todas. Solo funciona en combinación con --archlist.

-g --groupfile GROUPFILE

Ruta al archivo de grupos para incluir en los metadatos.

-b --blocked FILE

Un archivo que contiene una lista de nombres de srpm a excluir del repositorio fusionado. Solo funciona en combinación con --koji/-k.
