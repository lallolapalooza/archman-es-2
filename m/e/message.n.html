message(n) Comandos integrados de Tk message(n)

NOMBRE

message - Crear y manipular widgets de texto no interactivos 'message'

SINOPSIS

message rutaNombre ?opciones?

OPCIONES ESTÁNDAR

-anchor	-background	-borderwidth
-cursor	-font	-foreground
-highlightbackground	-highlightcolor	-highlightthickness
-padx	-pady	-relief
-takefocus	-text	-textvariable

Consulte la entrada del manual options para obtener detalles sobre las opciones estándar.

OPCIONES ESPECÍFICAS DEL WIDGET

Nombre de línea de comandos:	-aspect
Nombre de base de datos:	aspect
Clase de base de datos:	Aspect
Especifica un valor entero no negativo que indica la relación de aspecto deseada para el texto. La relación de aspecto se especifica como 100*ancho/alto. 100 significa que el texto debe ser tan ancho como alto, 200 significa que el texto debe ser el doble de ancho que alto, 50 significa que el texto debe ser el doble de alto que ancho, y así sucesivamente. Se utiliza para elegir la longitud de línea del texto si no se especifica la opción -width. El valor predeterminado es 150.
Nombre de línea de comandos:	-justify
Nombre de base de datos:	justify
Clase de base de datos:	Justify
Especifica cómo justificar las líneas de texto. Debe ser uno de left, center o right. El valor predeterminado es left. Esta opción funciona junto con las opciones -anchor, -aspect, -padx, -pady y -width para proporcionar una variedad de arreglos del texto dentro de la ventana. Las opciones -aspect y -width determinan el espacio de pantalla necesario para mostrar el texto. Las opciones -anchor, -padx y -pady determinan dónde se muestra esta área rectangular dentro de la ventana del widget, y la opción -justify determina cómo se muestra cada línea dentro de esa región rectangular. Por ejemplo, supongamos que -anchor es e y -justify es left, y que la ventana de mensajes es mucho más grande de lo necesario para el texto. El texto se mostrará de manera que los bordes izquierdos de todas las líneas estén alineados y el borde derecho de la línea más larga esté a -padx del borde derecho de la ventana; todo el bloque de texto estará centrado en el tramo vertical de la ventana.
Nombre de línea de comandos:	-width
Nombre de base de datos:	width
Clase de base de datos:	Width
Especifica la longitud de las líneas en la ventana. El valor puede tener cualquiera de las formas aceptables para Tk_GetPixels. Si esta opción tiene un valor mayor que cero, la opción -aspect se ignora y la opción -width determina la longitud de la línea. Si esta opción tiene un valor menor o igual que cero, entonces la opción -aspect determina la longitud de la línea.

DESCRIPCIÓN

El comando message crea una nueva ventana (dada por el argumento rutaNombre) y la convierte en un widget de mensaje. Se pueden especificar opciones adicionales, descritas anteriormente, en la línea de comandos o en la base de datos de opciones para configurar aspectos del mensaje, como sus colores, fuente, texto y alivio inicial. El comando message devuelve su argumento rutaNombre. En el momento en que se invoca este comando, no debe existir una ventana llamada rutaNombre, pero el padre de rutaNombre debe existir.

Un mensaje es un widget que muestra una cadena de texto. Un widget de mensaje tiene tres características especiales que lo diferencian de un widget label. Primero, divide su cadena en líneas para producir una relación de aspecto dada para la ventana. Las rupturas de línea se eligen en los límites de palabras siempre que sea posible (si ni siquiera una sola palabra cabe en una línea, la palabra se dividirá entre líneas). Los caracteres de nueva línea en la cadena forzarán rupturas de línea; se pueden usar, por ejemplo, para dejar líneas en blanco en la pantalla.

La segunda característica de un widget de mensaje es la justificación. El texto puede mostrarse justificado a la izquierda (cada línea comienza en el lado izquierdo de la ventana), centrado línea por línea, o justificado a la derecha (cada línea termina en el lado derecho de la ventana).

La tercera característica de un widget de mensaje es que maneja los caracteres de control y los caracteres no imprimibles de forma especial. Los caracteres de tabulación se reemplazan con suficiente espacio en blanco para alinearse en el siguiente límite de 8 caracteres. Las nuevas líneas provocan rupturas de línea. Otros caracteres de control (código ASCII inferior a 0x20) y caracteres no definidos en la fuente se muestran como una secuencia de cuatro caracteres \xhh donde hh es el número hexadecimal de dos dígitos que corresponde al carácter. En el caso inusual en que la fuente no contenga todos los caracteres de “0123456789abcdef\x”, entonces los caracteres de control y los caracteres indefinidos no se muestran en absoluto.

COMANDO DEL WIDGET

El comando message crea un nuevo comando Tcl cuyo nombre es rutaNombre. Este comando se puede utilizar para invocar varias operaciones en el widget. Tiene la siguiente forma general:

rutaNombre opción ?arg arg ...?
La opción y los args determinan el comportamiento exacto del comando. Los siguientes comandos son posibles para los widgets de mensaje:
rutaNombre cget opción
Devuelve el valor actual de la opción de configuración dada por opción. Opción puede tener cualquiera de los valores aceptados por el comando message.
rutaNombre configure ?opción? ?valor opción valor ...?
Consulta o modifica las opciones de configuración del widget. Si no se especifica ninguna opción, devuelve una lista que describe todas las opciones disponibles para rutaNombre (consulte Tk_ConfigureInfo para obtener información sobre el formato de esta lista). Si se especifica una opción sin valor, entonces el comando devuelve una lista que describe la opción con ese nombre (esta lista será idéntica a la sublista correspondiente del valor devuelto si no se especifica ninguna opción). Si se especifican uno o más pares opción-valor, entonces el comando modifica la(s) opción(es) del widget dada(s) para que tengan el(los) valor(es) dado(s); en este caso, el comando devuelve una cadena vacía. Opción puede tener cualquiera de los valores aceptados por el comando message.

ENLACES PREDETERMINADOS

Cuando se crea un nuevo mensaje, no tiene enlaces de eventos predeterminados: los mensajes están destinados únicamente a fines de salida.

ERRORES

Las tabulaciones no funcionan muy bien con texto que está centrado o justificado a la derecha. El resultado más común es que la línea se justifica incorrectamente.

Nombre

message.n - Comandos de widget

Descripción

La operación de la consola de mensajes se describe en la página del manual de widgets(5).

COMANDO DE WIDGET

La herramienta de línea de comandoswidget (no confundir con el comando widget(1)) está diseñada para enviar mensajes a las consolas de mensajes del sistema. Los mensajes se enviarán a la consola de mensajes especificada por la opción -c o por defecto a la consola de mensajes activa.

Las siguientes opciones están disponibles:

-c <nombre_consola>
Especifica la consola de mensajes a la que se enviarán los mensajes. Si no se especifica, se utilizará la consola de mensajes activa.
-w <nivel_advertencia>
Establece el nivel de advertencia del mensaje. Los niveles disponibles son DEBUG, INFO, NOTICE, WARNING, ERROR, CRITICAL, ALERT y EMERGENCY.
-s <mensaje_corto>
Establece un mensaje corto para el mensaje.
-l <mensaje_largo>
Establece un mensaje largo para el mensaje.
-t <archivo_tag>
Establece un archivo de etiqueta para el mensaje. La etiqueta se extrae de la línea de encabezado del archivo especificado.
-p <identificador_proceso>
Establece un identificador de proceso para el mensaje.
-m <identificador_modulo>
Establece un identificador de módulo para el mensaje.
-f <nombre_fuente>
Establece un nombre de fuente para el mensaje.
-n <número_línea>
Establece un número de línea para el mensaje.
-i <identificador_mensaje>
Establece un identificador de mensaje para el mensaje.
-a <archivo_salida>
Establece un archivo de salida para el mensaje. El mensaje se escribirá en este archivo.
--help
Muestra un mensaje de ayuda y sale.
--version
Muestra información sobre la versión y sale.

Si no se proporciona ningún argumento de mensaje, el comando leerá la entrada estándar hasta que se alcance el fin de archivo.
