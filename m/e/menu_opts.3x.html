menu_opts(3X) Llamadas a la biblioteca menu_opts(3X)

NOMBRE

set_menu_opts, menu_opts_on, menu_opts_off, menu_opts - establecer y obtener opciones de menú

SINOPSIS

#include <menu.h>
int set_menu_opts(MENU *menu, Menu_Options opts);
Menu_Options menu_opts(const MENU *menu);
int menu_opts_on(MENU *menu, Menu_Options opts);
int menu_opts_off(MENU *menu, Menu_Options opts);

DESCRIPCIÓN

La función set_menu_opts establece todos los bits de opción del menú dado (los bits de opción de menú pueden combinarse mediante OR lógico).

La función menu_opts_on activa los bits de opción dados y deja los demás sin cambios.

La función menu_opts_off desactiva los bits de opción dados y deja los demás sin cambios.

La función menu_opts devuelve los bits de opción actuales del menú.

Las siguientes opciones están definidas (todas están activadas por defecto):

O_ONEVALUE
Solo se puede seleccionar un elemento para este menú.
O_SHOWDESC
Mostrar las descripciones de los elementos cuando se publica el menú.
O_ROWMAJOR
Mostrar el menú en orden de fila principal.
O_IGNORECASE
Ignorar mayúsculas/minúsculas al hacer coincidencia de patrones.
O_SHOWMATCH
Mover el cursor dentro del nombre del elemento al hacer coincidencia de patrones.
O_NONCYCLIC
No ciclar entre el siguiente elemento y el elemento anterior, las solicitudes al otro extremo del menú.
O_MOUSE_MENU
Si el usuario hace clic con el ratón y este no cae sobre el menú activo actualmente, empuja KEY_MOUSE y los datos MEVENT de nuevo a la cola para permitir el procesamiento en otra parte del programa que llama.

VALOR DE RETORNO

Excepto para menu_opts, cada rutina devuelve uno de los siguientes:

E_OK
La rutina tuvo éxito.
E_SYSTEM_ERROR
Ocurrió un error del sistema (ver errno(3)).
E_POSTED
El menú ya está publicado.

PORTABILIDAD

Estas rutinas emulan la biblioteca de menús de System V. No fueron soportadas en las versiones Version 7 o BSD.
