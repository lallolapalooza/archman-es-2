DESCRIPCIÓN

libmemcached implementa un lenguaje personalizado para configurar y modificar servidores. Al pasar una cadena de opciones, puedes generar un objeto memcached_st que puedes usar directamente en tu aplicación.

Opciones Generales:

--SERVER=<servername>:<optional_port>/?<optional_weight>
Proporciona un nombre de servidor para ser utilizado por el cliente.

Proporcionar un peso provocará que se realice el ponderado con todos los hosts, y cada servidor recibirá un peso predeterminado de 1.

--SOCKET="<filepath>/?<optional_weight>"
Proporciona una ruta de archivo a un archivo de socket UNIX. Proporcionar un peso provocará que se realice el ponderado con todos los hosts, y cada servidor recibirá un peso predeterminado de 1.
--VERIFY-KEY
Verifica que las claves que se están utilizando se ajusten al diseño del protocolo que se está utilizando.
--REMOVE_FAILED_SERVERS
Habilita el comportamiento MEMCACHED_BEHAVIOR_REMOVE_FAILED_SERVERS.
--BINARY-PROTOCOL
Fuerza que todas las conexiones utilicen el protocolo binario.
--BUFFER-REQUESTS
Por favor, consulta MEMCACHED_BEHAVIOR_BUFFER_REQUESTS.
--CONFIGURE-FILE=
Proporciona un archivo de configuración que se utilizará para cargar solicitudes. Ten en cuenta que al usar un archivo de configuración, libmemcached restablecerá memcached_st basándose en la información contenida únicamente en el archivo.
--CONNECT-TIMEOUT=
Ver memcached_behavior_set() para MEMCACHED_BEHAVIOR_CONNECT_TIMEOUT.
--DISTRIBUTION=
Establece el modelo de distribución utilizado por el cliente. Ver memcached_behavior_set() para más detalles.
--HASH=
Establece el algoritmo de hashing utilizado para colocar claves en los servidores.
--HASH-WITH-NAMESPACE
Cuando está habilitado, la clave prefijo se añadirá a la clave al determinar en qué servidor se almacenarán los datos.
--NOREPLY
Habilita "no reply" para todas las llamadas que lo soporten. Se recomienda encarecidamente utilizar esta opción solo con el protocolo binario.
--NUMBER-OF-REPLICAS=
Establece el número de servidores a los que se replicarán las claves.
--RANDOMIZE-REPLICA-READ
Selecciona aleatoriamente el servidor dentro del pool de replicación para leer.
--SORT-HOSTS
Al añadir nuevos servidores, calcula siempre su distribución basándose en el orden de nombres ordenado.
--SUPPORT-CAS
Ver memcached_behavior_set() para MEMCACHED_BEHAVIOR_SUPPORT_CAS
--USE-UDP
Ver memcached_behavior_set() para MEMCACHED_BEHAVIOR_USE_UDP
--NAMESPACE=
Un espacio de nombres es un contenedor que proporciona contexto para las claves. Solo otras solicitudes que conozcan el espacio de nombres pueden acceder a estos valores. Esto se logra anteponiendo el valor del espacio de nombres a todas las claves.

Opciones del Pool de Memcached:

--POOL-MIN
Tamaño inicial del pool.
--POOL-MAX
Maximizar el tamaño del pool.

Opciones de E/S:

--TCP-NODELAY
Ver memcached_behavior_set() para MEMCACHED_BEHAVIOR_TCP_NODELAY
--TCP-KEEPALIVE
Ver memcached_behavior_set() para MEMCACHED_BEHAVIOR_TCP_KEEPALIVE
--RETRY-TIMEOUT=
Ver memcached_behavior_set() para MEMCACHED_BEHAVIOR_RETRY_TIMEOUT
--SERVER-FAILURE-LIMIT=
Ver memcached_behavior_set() para MEMCACHED_BEHAVIOR_SERVER_FAILURE_LIMIT
--SND-TIMEOUT=
Ver memcached_behavior_set() para MEMCACHED_BEHAVIOR_SND_TIMEOUT
--SOCKET-RECV-SIZE=
Ver memcached_behavior_set() para MEMCACHED_BEHAVIOR_SOCKET_RECV_SIZE

NOMBRE

memcached - cliente para el acceso a servidores de caché de memoria distribuida

SINOPSIS

memcached [OPCIONES] [cadena de configuración]

DESCRIPCIÓN

La rutina memcached() es la función principal para inicializar una estructura de cliente memcached. Esta función toma una cadena de configuración que se puede usar para inicializar una serie de opciones de comportamiento y servidores.

Hay dos formas de pasar una cadena de configuración:

  • Pasar una cadena de configuración al inicializar la estructura memcached_st.
  • Usar las funciones memcached_parse_configuration() o memcached_configure() para pasar una cadena de configuración a una estructura memcached_st ya existente.

La cadena de configuración es una lista de opciones separadas por espacios. Las opciones que contienen espacios deben citarse.

--SERVER=
Permite agregar un servidor a la lista de servidores.
--SOCKET-SEND-SIZE=
Ver memcached_behavior_set() para MEMCACHED_BEHAVIOR_SOCKET_SEND_SIZE
--POLL-TIMEOUT=
Establece el tiempo de espera utilizado por poll(3).
--IO-BYTES-WATERMARK=
--IO-KEY-PREFETCH=
--IO-MSG-WATERMARK=
--TCP-KEEPIDLE
--RCV-TIMEOUT=

Otras Opciones:

INCLUDE
Incluye un archivo en la configuración. A diferencia de --CONFIGURE-FILE=, esto no restablecerá memcached_st.
RESET
Restablece memcached_st y continúa procesando.
END
Finaliza el procesamiento de la configuración.
ERROR
Finaliza el procesamiento de la configuración y genera un error.

AMBIENTE

LIBMEMCACHED

VALOR DE RETORNO

memcached() devuelve un puntero a la estructura memcached_st que fue creada (o inicializada). En caso de fallo de asignación, devuelve NULL.
