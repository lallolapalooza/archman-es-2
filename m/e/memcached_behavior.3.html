NOMBRE

memcached_behavior - Documentación de libmemcached

Manipular el comportamiento de una estructura memcached_st.

SINOPSIS

#include <libmemcached/memcached.h>
Compilar y enlazar con -lmemcached
uint64_t memcached_behavior_get(memcached_st *ptr, memcached_behavior_t flag)
Parámetros
  • ptr -- puntero a una estructura memcached_st inicializada
  • flag -- memcached_behavior_t a consultar
Devuelve
el valor establecido para flag
memcached_return_t memcached_behavior_set(memcached_st *ptr, memcached_behavior_t flag, uint64_t data)
Parámetros
  • ptr -- puntero a una estructura memcached_st inicializada
  • flag -- memcached_behavior_t a establecer
  • data -- el valor a establecer para flag
Devuelve
memcached_return_t indicando éxito

Cambiado en la versión 0.17: El argumento data de memcached_behavior_set() se cambió de tomar un puntero al valor de datos, a tomar un uin64_t.

typedef enum memcached_behavior_t memcached_behavior_t
enum memcached_behavior_t
enumerador MEMCACHED_BEHAVIOR_USE_UDP
Hace que libmemcached use el transporte UDP al comunicarse con un servidor memcached. No todas las operaciones de E/S se prueban cuando este comportamiento está habilitado.

Las siguientes operaciones devolverán MEMCACHED_NOT_SUPPORTED cuando se ejecuten con MEMCACHED_BEHAVIOR_USE_UDP habilitado:

  • memcached_version(),
  • memcached_stat(),
  • memcached_get(),
  • memcached_get_by_key(),
  • memcached_mget(),
  • memcached_mget_by_key(),
  • memcached_fetch(),
  • memcached_fetch_result(),
  • memcached_fetch_execute().

Todas las demás operaciones se prueban pero se ejecutan en modo 'disparar y olvidar', en el que una vez que el cliente ha ejecutado la operación, no se intentará asegurar que la operación haya sido recibida y actuada por el servidor.

libmemcached no permite compartir servidores TCP y UDP dentro de la misma instancia de cliente libmemcached. Un intento de agregar un servidor TCP cuando este comportamiento está habilitado resultará en un MEMCACHED_INVALID_HOST_PROTOCOL, al igual que intentar agregar un servidor UDP cuando este comportamiento no está habilitado.

enumerador MEMCACHED_BEHAVIOR_NO_BLOCK
Esto habilita solo SO_LINGER, por lo que la llamada close(2) en el socket devuelve inmediatamente. Las E/S siempre se manejan asincrónicamente en versiones recientes de libmemcached.
enumerador MEMCACHED_BEHAVIOR_SND_TIMEOUT
Esto establece el comportamiento en microsegundos del socket contra el flag SO_SNDTIMEO.
enumerador MEMCACHED_BEHAVIOR_RCV_TIMEOUT
Esto establece el comportamiento en microsegundos del socket contra el flag SO_RCVTIMEO.
enumerador MEMCACHED_BEHAVIOR_TCP_NODELAY
Deshabilita el algoritmo de Nagle. Ver RFC 896.
enumerador MEMCACHED_BEHAVIOR_HASH
Establece el algoritmo de hash utilizado para las claves.

Cada hash tiene sus ventajas y sus debilidades. Si no sabes o no te importa, usa el predeterminado.

enumerador MEMCACHED_BEHAVIOR_DISTRIBUTION
Estableciendo un memcached_server_distribution_t puedes habilitar diferentes medios de distribuir valores a los servidores.

El método predeterminado es MEMCACHED_DISTRIBUTION_MODULA (hash de la clave módulo número de servidores).

Puedes habilitar el hashing consistente estableciendo MEMCACHED_DISTRIBUTION_CONSISTENT. El hashing consistente ofrece una mejor distribución y permite agregar servidores al clúster con mínimas pérdidas de caché.

Actualmente MEMCACHED_DISTRIBUTION_CONSISTENT es un alias para el valor MEMCACHED_DISTRIBUTION_CONSISTENT_KETAMA.

enumerador MEMCACHED_BEHAVIOR_CACHE_LOOKUPS
Obsoleto desde la versión 0.46(?): Las búsquedas DNS ahora siempre se almacenan en caché hasta que ocurre un error con el servidor.

Memcached puede almacenar en caché las búsquedas con nombre para que las búsquedas DNS se realicen solo una vez.

enumerador MEMCACHED_BEHAVIOR_SUPPORT_CAS
Soporta operaciones CAS (esto no está habilitado por defecto en este punto del servidor ya que impone una ligera penalización de rendimiento).
enumerador MEMCACHED_BEHAVIOR_KETAMA
Establece la distribución predeterminada en MEMCACHED_DISTRIBUTION_CONSISTENT_KETAMA y el hash en MEMCACHED_HASH_MD5.
enumerador MEMCACHED_BEHAVIOR_KETAMA_WEIGHTED
Establece la distribución predeterminada en MEMCACHED_DISTRIBUTION_CONSISTENT_KETAMA con las pruebas ponderadas. Hace que el algoritmo de hash predeterminado para las claves utilice MEMCACHED_HASH_MD5.
enumerador MEMCACHED_BEHAVIOR_KETAMA_HASH
Establece el algoritmo de hash para el mapeo de hosts en el continuum.
enumerador MEMCACHED_BEHAVIOR_KETAMA_COMPAT
Establece el modo de compatibilidad. El valor puede establecerse en MEMCACHED_KETAMA_COMPAT_LIBMEMCACHED (este es el predeterminado) o MEMCACHED_KETAMA_COMPAT_SPY para ser compatible con el cliente SPY Memcached para Java.
enumerador MEMCACHED_BEHAVIOR_POLL_TIMEOUT
Modifica el valor de tiempo de espera en milisegundos que utiliza poll. El valor predeterminado es -1. Se debe pasar un entero con signo a memcached_behavior_set() para cambiar este valor (esto requiere conversión de tipo). Para memcached_behavior_get(), un valor de 'entero con signo' se convertirá y devolverá como 'unsigned long long'.
enumerador MEMCACHED_BEHAVIOR_KETAMA_POLL_TIMEOUT
Modifica el valor de tiempo de espera en milisegundos que se utiliza para la operación de sondeo de continuos Ketama. El valor predeterminado es -1. Se debe pasar un entero con signo a memcached_behavior_set() para cambiar este valor (esto requiere conversión de tipo). Para memcached_behavior_get(), un valor de 'entero con signo' se convertirá y devolverá como 'unsigned long long'.
enumerador MEMCACHED_BEHAVIOR_SOCKET_SEND_SIZE
Establece el tamaño del búfer de envío del socket.
enumerador MEMCACHED_BEHAVIOR_SOCKET_RECV_SIZE
Establece el tamaño del búfer de recepción del socket.
enumerador MEMCACHED_BEHAVIOR_USER_RETRY_MAX
Establece el número máximo de reintentos que deben realizarse al procesar una solicitud.
enumerador MEMCACHED_BEHAVIOR_USER_IDLE_TIMEOUT
Establece el tiempo de espera de inactividad en segundos para un servidor conectado.
enumerador MEMCACHED_BEHAVIOR_SERVER_FAILURE_LIMIT
Establece el número de fallos que un servidor puede tener antes de ser eliminado temporalmente de la rotación.
enumerador MEMCACHED_BEHAVIOR_TCP_KEEPIDLE
Establece el tiempo de inactividad (en segundos) antes de que se envíe la primera sonda Keepalive TCP. Solo se aplica si TCP_KEEPIDLE está disponible en el sistema operativo.
enumerador MEMCACHED_BEHAVIOR_TCP_KEEPINTVL
Establece el intervalo (en segundos) entre sondas Keepalive TCP. Solo se aplica si TCP_KEEPINTVL está disponible en el sistema operativo.
enumerador MEMCACHED_BEHAVIOR_TCP_KEEPCNT
Establece el número de sondas Keepalive TCP que se pueden enviar sin recibir respuesta antes de que la conexión se considere rota. Solo se aplica si TCP_KEEPCNT está disponible en el sistema operativo.
enumerador MEMCACHED_BEHAVIOR_SORT_KEYS
Utilice la ordenación de claves para la coherencia al recuperar varios elementos. Cuando se recuperan varios elementos, se ordenan las claves devueltas.
enumerador MEMCACHED_BEHAVIOR_VERIFY_KEY
Verifica la clave devuelta del servidor con la clave solicitada. Esto puede ser útil para depurar.
enumerador MEMCACHED_BEHAVIOR_CONNECT_TIMEOUT
Establece el tiempo de espera de conexión en milisegundos. El valor predeterminado es 0, lo que significa que no se utiliza ningún tiempo de espera. El valor debe ser un entero sin signo.
enumerador MEMCACHED_BEHAVIOR_RETRY_TIMEOUT
Establece el tiempo de espera de reintento en segundos. El valor predeterminado es 0, lo que significa que no se utiliza ningún tiempo de espera. El valor debe ser un entero sin signo.
enumerador MEMCACHED_BEHAVIOR_DEAD_TIMEOUT
Establece el tiempo de espera de conexión inactiva en segundos. El valor predeterminado es 0, lo que significa que no se utiliza ningún tiempo de espera. El valor debe ser un entero sin signo.

BEHAVIOR FLAGS

enumerator MEMCACHED_BEHAVIOR_USER_DATA
Deprecated since version <: 0.30
enumerator MEMCACHED_BEHAVIOR_BUFFER_REQUESTS
Habilitar IO con buffer hace que los comandos se "almacenen en búfer" en lugar de ser enviados. Cualquier acción que obtenga datos hará que este búfer se envíe a la conexión remota. Salir de la conexión o cerrar la conexión también hará que los datos en búfer se envíen a la conexión remota.
enumerator MEMCACHED_BEHAVIOR_VERIFY_KEY
Habilitar esto hará que libmemcached pruebe todas las claves para verificar que son claves válidas.
enumerator MEMCACHED_BEHAVIOR_SORT_HOSTS
Habilitar esto hará que los hosts que se añadan se coloquen en la lista de hosts en orden ordenado. Esto anulará el hashing consistente.
enumerator MEMCACHED_BEHAVIOR_CONNECT_TIMEOUT
Establece el tiempo de espera durante la conexión del socket en milisegundos. Especificar -1 significa un tiempo de espera infinito.
enumerator MEMCACHED_BEHAVIOR_BINARY_PROTOCOL
Habilita el uso del protocolo binario. Ten en cuenta que no puedes activar/desactivar esta bandera en una conexión abierta.
enumerator MEMCACHED_BEHAVIOR_IO_MSG_WATERMARK
Establece este valor para ajustar el número de mensajes que pueden enviarse antes de que libmemcached comience a vaciar automáticamente la cola de entrada.

Establecer este valor demasiado alto puede hacer que libmemcached se bloquee (intentando enviar datos, pero el envío se bloqueará porque el búfer de entrada en el kernel está lleno).

enumerator MEMCACHED_BEHAVIOR_IO_BYTES_WATERMARK
Establece este valor para ajustar el número de bytes que pueden enviarse antes de que libmemcached comience a vaciar automáticamente la cola de entrada (se necesitan al menos 10 solicitudes de E/S enviadas sin leer el búfer de entrada).

Establecer este valor demasiado alto puede hacer que libmemcached se bloquee (intentando enviar datos, pero el envío se bloqueará porque el búfer de entrada en el kernel está lleno).

enumerator MEMCACHED_BEHAVIOR_IO_KEY_PREFETCH
El protocolo binario funciona de manera un poco diferente al protocolo textual, ya que un multiget se implementa como una tubería de operaciones get individuales que se envían al servidor en un bloque.

Si estás utilizando multiget grandes desde tu aplicación, puedes mejorar la latencia de los gets estableciendo este valor para enviar el primer bloque de solicitudes cuando alcances el límite especificado. Permite a los servidores comenzar a procesar las solicitudes para enviar los datos de vuelta mientras se crean y envían el resto de las solicitudes al servidor.

enumerator MEMCACHED_BEHAVIOR_NOREPLY
Establece este valor para especificar que realmente no te importa el resultado de tus comandos de almacenamiento (set, add, replace, append, prepend).
enumerator MEMCACHED_BEHAVIOR_NUMBER_OF_REPLICAS
Especifica el número de réplicas que libmemcached debe almacenar de cada elemento (en diferentes servidores).

Esta replicación no dedica servidores memcached específicos para almacenar las réplicas, sino que almacenará las réplicas junto con todos los demás objetos (en los 'n' servidores siguientes especificados en tu lista de servidores).

Requiere el protocolo binario y solo soporta (M)GET/SET/DELETE.

NOTA: libmemcached no garantiza ni impone ninguna consistencia.

enumerator MEMCACHED_BEHAVIOR_RANDOMIZE_REPLICA_READ
Permite aleatorizar el punto de inicio de las lecturas de réplicas. Normalmente, la lectura se realiza desde el servidor principal y, en caso de error, la lectura se realiza desde el principal + 1, luego el principal + 2 hasta 'n' réplicas.

Esto permite distribuir la carga de lectura a múltiples servidores a costa de más tráfico de escritura.

NOTA: Solo los errores de comunicación con un servidor se consideran fallos, por lo que MEMCACHED_NOTFOUND no se considera un fallo.

enumerator MEMCACHED_BEHAVIOR_CORK
Deprecated since version ?: Esta opción ha sido deprecada, ahora el comportamiento está integrado y se utiliza apropiadamente en plataformas seleccionadas.
enumerator MEMCACHED_BEHAVIOR_KEEPALIVE
Habilita el comportamiento TCP_KEEPALIVE.
enumerator MEMCACHED_BEHAVIOR_KEEPALIVE_IDLE
Especifica el tiempo, en segundos, para marcar una conexión como inactiva. Esto solo está disponible como opción en Linux.
enumerator MEMCACHED_BEHAVIOR_SOCKET_SEND_SIZE
Encuentra el tamaño actual de SO_SNDBUF. Un valor de 0 significa que ocurrió un error o que no había hosts disponibles. Es seguro asumir el valor predeterminado del sistema si esto ocurre.

Si ocurre un error, puedes consultar el último errno almacenado en caché para encontrar el error específico.

enumerator MEMCACHED_BEHAVIOR_SOCKET_RECV_SIZE
Encuentra el tamaño actual de SO_RCVBUF. Un valor de 0 significa que ocurrió un error o que no había hosts disponibles. Es seguro asumir el valor predeterminado del sistema si esto ocurre.

Si ocurre un error, puedes consultar el último errno almacenado en caché para encontrar el error específico.

enumerator MEMCACHED_BEHAVIOR_SERVER_FAILURE_LIMIT
Deprecated since version 0.48: See MEMCACHED_BEHAVIOR_REMOVE_FAILED_SERVERS

Establece este valor para habilitar que el servidor sea eliminado después de un número continuo de fallos de conexión igual a MEMCACHED_BEHAVIOR_SERVER_FAILURE_LIMIT veces.

enumerator MEMCACHED_BEHAVIOR_AUTO_EJECT_HOSTS
Deprecated since version 0.48: See MEMCACHED_BEHAVIOR_REMOVE_FAILED_SERVERS

Si está habilitado, cualquier host que haya sido marcado como deshabilitado será eliminado de la lista de servidores en la estructura memcached_st. Esto debe usarse en combinación con MEMCACHED_BEHAVIOR_SERVER_FAILURE_LIMIT.

enumerator MEMCACHED_BEHAVIOR_REMOVE_FAILED_SERVERS
Si está habilitado, cualquier host que haya sido marcado como deshabilitado será eliminado de la lista de servidores en la estructura memcached_st.
enumerator MEMCACHED_BEHAVIOR_RETRY_TIMEOUT
Cuando está habilitado, un host que sea problemático solo se verificará para su uso basándose en la cantidad de tiempo establecida por este comportamiento. El valor está en segundos.
enumerator MEMCACHED_BEHAVIOR_HASH_WITH_PREFIX_KEY
Cuando está habilitado, la clave de prefijo se añadirá a la clave al determinar el servidor por hash. Ver MEMCACHED_CALLBACK_NAMESPACE para información adicional.

NAME

memcached_behavior_get, memcached_behavior_set, memcached_behavior_set_key, memcached_behavior_set_distribution

get and set client behaviors

SYNOPSIS

#include <libmemcached/behavior.h>

memcached_behavior_get() takes a behavior flag and returns whether or not that behavior is currently enabled in the client.

memcached_behavior_set() changes the value of a particular option of the client. It takes both a flag and a value. For simple on or off options you just need to pass in a value of 1. Calls to memcached_behavior_set() will flush and reset all connections.

memcached_behavior_set_key() is used to set a key that will be used for distribution. This is used for the MEMCACHED_BEHAVIOR_USE_UDP behavior. When this behavior is enabled, the key is used for the hashing algorithm instead of the data key itself.

memcached_behavior_set_distribution() is used to set the distribution method for the client. The default is MEMCACHED_DISTRIBUTION_CONSISTENT. This behavior is used in conjunction with the MEMCACHED_BEHAVIOR_USE_UDP behavior to enable key distribution by virtual buckets.

RETURN VALUE

memcached_behavior_get() returns either the current value of the key, or 0 or 1 on simple flag behaviors (1 being enabled). memcached_behavior_set() returns failure or success.

NOTES

The data argument of memcached_behavior_set() was changed in version 0.17 from taking a pointer to data value, to taking a uin64_t.
