memccpy(3) Manual de funciones de biblioteca memccpy(3)

NOMBRE

memccpy - copiar área de memoria

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <string.h>
void *memccpy(size_t n;
              void dest[restrict n], const void src[restrict n],
              int c, size_t n);

DESCRIPCIÓN

La función memccpy() copia como máximo n bytes del área de memoria src al área de memoria dest, deteniéndose cuando se encuentra el carácter c (c es copiado).

Si las áreas de memoria se solapan, los resultados no están definidos.

VALOR DE RETORNO

La función memccpy() devuelve un puntero al siguiente carácter en dest después de c, o NULL si c no se encontró en los primeros n caracteres de src.

ATRIBUTOS
