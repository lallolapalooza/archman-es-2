menu_userptr(3x)

Paquete: ncurses

Licencias: MIT-open-group

menu_userptr(3X) Llamadas a bibliotecas menu_userptr(3X)

NOMBRE

set_menu_userptr, menu_userptr - asociar datos de aplicación con un elemento de menú

SINOPSIS

#include <menu.h>
int set_menu_userptr(MENU *menu, void *userptr);
void *menu_userptr(const MENU *menu);

DESCRIPCIÓN

Cada menú y cada elemento de menú tiene un campo que puede usarse para almacenar datos específicos de la aplicación (es decir, el código del controlador de menú lo deja intacto). Estas funciones obtienen y establecen el campo del puntero de usuario del menú.

VALOR DE RETORNO

menu_userptr devuelve un puntero (que puede ser NULL). No establece errno.

set_menu_userptr devuelve E_OK (éxito).

PORTABILIDAD

Estas rutinas emulan la biblioteca de menús de System V. No eran compatibles con las versiones 7 o BSD.

El puntero de usuario es un puntero void. Elegimos no dejarlo como un puntero char por compatibilidad con SVr4.

AUTORES

Juergen Pfeifer. Páginas de manual y adaptación para new curses por Eric S. Raymond.

VER TAMBIÉN
