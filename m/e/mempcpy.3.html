mempcpy(3) Manual de funciones de biblioteca mempcpy(3)

NOMBRE

mempcpy, wmempcpy - copiar área de memoria

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#define _GNU_SOURCE         /* Véase feature_test_macros(7) */
#include <string.h>
void *mempcpy(size_t n;
              void dest[restrict n], const void src[restrict n],
              size_t n);
#define _GNU_SOURCE         /* Véase feature_test_macros(7) */
#include <wchar.h>
wchar_t *wmempcpy(size_t n;
              wchar_t dest[restrict n], const wchar_t src[restrict n],
              size_t n);

DESCRIPCIÓN

La función mempcpy() es casi idéntica a la función memcpy(3). Copia n bytes del objeto que comienza en src al objeto apuntado por dest. Pero en lugar de devolver el valor de dest, devuelve un puntero al byte siguiente al último byte escrito.

Esta función es útil en situaciones donde se deben copiar una serie de objetos a posiciones de memoria consecutivas.

La función wmempcpy() es idéntica pero toma argumentos de tipo wchar_t y copia n caracteres anchos.

VALOR DE RETORNO

dest + n.

ATRIBUTOS

Para una explicación de los términos utilizados en esta sección, véase attributes(7).

Interfaz Atributo Valor
mempcpy (), wmempcpy () Seguridad en hilos MT-Safe

ESTÁNDARES

GNU.

HISTORIA

glibc 2.1.

EJEMPLOS

void *
combine(void *o1, size_t s1, void *o2, size_t s2)
{
    void *result = malloc(s1 + s2);
    if (result != NULL)
        mempcpy(mempcpy(result, o1, s1), o2, s2);
    return result;
}

VER TAMBIÉN

memccpy(3), memcpy(3), memmove(3), wmemcpy(3)
