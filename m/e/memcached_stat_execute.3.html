DESCRIPCIÓN

memcached_stat_execute() utiliza los servidores encontrados en memcached_stat_st y ejecuta un comando "stat" en cada servidor. args es un argumento opcional que se puede pasar para modificar el comportamiento de "stats". Deberás proporcionar una función de devolución de llamada que recibirá cada par de valores devueltos por el servidor memcached.

memcached_stat() recupera un array de estructuras memcached_stat_st que contienen el estado de todos los servidores memcached disponibles. El valor de retorno debe ser liberado por la aplicación que lo llama. Si se llama con el comportamiento MEMCACHED_BEHAVIOR_USE_UDP establecido, se devuelve un valor NULL y el parámetro de error se establece en MEMCACHED_NOT_SUPPORTED.

memcached_stat_servername() se puede usar de forma independiente sin un memcached_st para obtener el estado de un servidor en particular. "args" se utiliza para definir un objeto de estado particular (una lista de estos no es proporcionada por la llamada memcached_stat_get_keys() ni definida en el protocolo memcached). Debes especificar el nombre de host y el puerto del servidor sobre el que deseas obtener información.

memcached_stat_get_value() devuelve el valor de una clave de estado en particular. Especificas la clave que deseas obtener. La clave debe terminar en nulo.

memcached_stat_get_keys() devuelve una lista de claves sobre las que el servidor tiene objetos de estado. Eres responsable de liberar esta lista.

Se proporciona una herramienta de línea de comandos, memstat, para que no tengas que escribir una aplicación para hacer esto.

VALOR DE RETORNO

Varía, ver funciones particulares.

Cualquier método que devuelva un memcached_stat_st espera que liberes la memoria asignada para él.

NAME

memcached_strerror - return a string describing the error code

SYNOPSIS

#include <memcached.h>

char *
memcached_strerror(memcached_st *ptr, int error_code);

DESCRIPTION

The memcached_strerror() function returns a pointer to a static string describing the error_code that was returned by one of the memcached functions. You must not modify the string, as it may be overwritten by subsequent calls to memcached_strerror().

RETURN VALUE

A pointer to a string describing the error code.
