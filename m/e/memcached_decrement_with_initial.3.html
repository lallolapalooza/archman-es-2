NOMBRE

memcached_decrement_with_initial - Incrementando y Decrementando Valores

SINOPSIS

#include <libmemcached/memcached.h>
Compilar y enlazar con -lmemcached
memcached_return_t memcached_increment(memcached_st *ptr, const char *key, size_t key_length, uint32_t offset, uint64_t *value)

Parámetros
  • ptr -- puntero a una estructura memcached_st inicializada
  • group_key -- espacio de nombres de la clave
  • group_key_length -- longitud del espacio de nombres de la clave sin ningún cero terminador
  • key -- la clave
  • key_length -- longitud de la clave sin ningún cero terminador
  • offset -- desplazamiento para incrementar/decrementar
  • initial -- valor inicial si key no existe y expiration no es MEMCACHED_EXPIRATION_NOT_ADD
  • expiration -- expiración como marca de tiempo unix o como tiempo de expiración relativo en segundos
  • value -- el valor resultante después de la inicialización/incremento/decremento
Devoluciones
memcached_return_t indicando éxito

DESCRIPCIÓN

memcached_increment() toma una clave y longitud_clave e incrementa el valor en el desplazamiento que se le pasa. Luego, el valor se devuelve a través del puntero uint32_t value que se le pasa.

memcached_decrement() toma una clave y longitud_clave y decrementa el valor en el desplazamiento que se le pasa. Luego, el valor se devuelve a través del puntero uint32_t value que se le pasa.

memcached_increment_with_initial() toma una clave y longitud_clave e incrementa el valor en el desplazamiento que se le pasa. Si el objeto especificado por clave no existe, puede suceder una de dos cosas: Si el valor de expiración es MEMCACHED_EXPIRATION_NOT_ADD, la operación fallará. Para todos los demás valores de expiración, la operación tendrá éxito al sembrar el valor para esa clave con un valor inicial para que expire con el tiempo de expiración proporcionado. Los flags se establecerán en cero. Luego, el valor se devuelve a través del puntero uint32_t value que se le pasa. memcached_increment_with_initial solo está disponible cuando se utiliza el protocolo binario.

memcached_decrement_with_initial() toma una clave y longitud_clave y decrementa el valor en el desplazamiento que se le pasa. Si el objeto especificado por clave no existe, puede suceder una de dos cosas: Si el valor de expiración es MEMCACHED_EXPIRATION_NOT_ADD, la operación fallará. Para todos los demás valores de expiración, la operación tendrá éxito al sembrar el valor para esa clave con un valor inicial para que expire con el tiempo de expiración proporcionado. Los flags se establecerán en cero. Luego, el valor se devuelve a través del puntero uint32_t value que se le pasa. memcached_decrement_with_initial() solo está disponible cuando se utiliza el protocolo binario.

memcached_increment_by_key(), memcached_decrement_by_key(), memcached_increment_with_initial_by_key() y memcached_decrement_with_initial_by_key() son equivalentes de clave maestra de los anteriores.

VALOR DEVUELTO

Se devuelve un valor de tipo memcached_return_t. En caso de éxito, ese valor será MEMCACHED_SUCCESS. Utilice memcached_strerror() para traducir este valor a una cadena imprimible.

NAME

memcached_decrement_with_initial - decrement a value in memcached with an initial value

LIBRARY

libmemcached

SYNOPSIS

ssize_t memcached_decrement_with_initial (memcached_st *ptr,
        const char *key, size_t key_length,
        uint64_t offset, uint64_t initial_value,
        time_t expiration_time,
        uint32_t flags);

DESCRIPTION

This function is used to decrement the value of a memcached key. If the key does not exist, it will be created with the initial value provided. The offset specifies the amount to decrement the value by.

The expiration_time specifies the time after which the value will expire. If expiration_time is 0, the value will not expire.

The flags parameter is a bitmask that can be used to control various aspects of the operation, such as enabling compression or setting the data type.

RETURN VALUE

On success, the function returns the new value of the key after decrementing. On failure, it returns -1.
