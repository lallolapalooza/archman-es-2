memcmp(3) Manual de funciones de biblioteca memcmp(3)

NOMBRE

memcmp - compara áreas de memoria

BIBLIOTECA

Biblioteca estándar de C (libc, -lc)

SINOPSIS

#include <string.h>
int memcmp(size_t n;
           const void s1[n], const void s2[n], size_t n);

DESCRIPCIÓN

La función memcmp() compara los primeros n bytes (cada uno interpretado como unsigned char) de las áreas de memoria s1 y s2.

VALOR DE RETORNO

La función memcmp() devuelve un entero menor que, igual a, o mayor que cero si los primeros n bytes de s1 se encuentran, respectivamente, menores que, coinciden con, o son mayores que los primeros n bytes de s2.

Para un valor de retorno distinto de cero, el signo se determina por el signo de la diferencia entre el primer par de bytes (interpretados como unsigned char) que difieren en s1 y s2.

Si n es cero, el valor de retorno es cero.

ATRIBUTOS

Para obtener una explicación de los términos utilizados en esta sección, consulte attributes(7).

Interfaz Atributo Valor
memcmp () Seguridad de hilos MT-Safe

ESTÁNDARES

C11, POSIX.1-2008.

HISTORIAL

POSIX.1-2001, C89, SVr4, 4.3BSD.

ADVERTENCIAS

No utilice memcmp() para comparar datos confidenciales, como secretos criptográficos, porque el tiempo de CPU requerido para la comparación depende del contenido de las direcciones comparadas; esta función está sujeta a ataques de canal lateral basados en el tiempo. En tales casos, se requiere una función que realice comparaciones en tiempo determinista, dependiendo solo de n (la cantidad de bytes comparados). Algunos sistemas operativos proporcionan dicha función (por ejemplo, consttime_memequal() de NetBSD), pero ninguna función de este tipo está especificada en POSIX. En Linux, es posible que deba implementar dicha función usted mismo.
