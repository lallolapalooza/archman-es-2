NOMBRE

merge_unicharsets - Herramienta simple para fusionar uno o más conjuntos de unicharsets.

SINOPSIS

merge_unicharsets unicharset-in-1 ... unicharset-in-n unicharset-out

DESCRIPCIÓN

merge_unicharsets(1) es una herramienta simple para fusionar dos o más conjuntos de unicharsets. Podría usarse para crear un conjunto de unicharsets combinado para un motor a nivel de script, como el nuevo latino o devanagari.

ARGUMENTOS DE ENTRADA/SALIDA

unicharset-in-1

(Entrada) El nombre del primer archivo unicharset a fusionar.

unicharset-in-n

(Entrada) El nombre del n-ésimo archivo unicharset a fusionar.

unicharset-out

(Salida) El nombre del archivo unicharset fusionado.

HISTORIA

merge_unicharsets(1) estuvo disponible por primera vez para tesseract4.00.00alpha.
