DESCRIPCIÓN

La estructura de memcached_result_st se ha encapsulado, no debe escribir código que acceda directamente a los miembros de la estructura.

memcached_result_create() asignará memoria para un memcached_result_st o inicializará una estructura que se le pase.

memcached_result_free() liberará cualquier memoria adjunta a la estructura. Si la estructura también fue asignada, la liberará.

NAME

memcached_result_cas, memcached_result_key, memcached_result_key_length, memcached_result_value, memcached_result_take_value, memcached_result_length, memcached_result_flags, memcached_result_set_value, memcached_result_set_flags, memcached_result_set_expiration - query result object

SYNOPSIS

All functions return void unless otherwise specified.

#include <libmemcached/memcached.h>

const char *
memcached_result_key(memcached_result_st *result);

size_t
memcached_result_key_length(memcached_result_st *result);

const char *
memcached_result_value(memcached_result_st *result);

char *
memcached_result_take_value(memcached_result_st *result);

size_t
memcached_result_length(memcached_result_st *result);

uint32_t
memcached_result_flags(memcached_result_st *result);

uint64_t
memcached_result_cas(memcached_result_st *result);

void
memcached_result_set_value(memcached_result_st *result,
    const char *value, size_t length);

void
memcached_result_set_flags(memcached_result_st *result,
    uint32_t flags);

void
memcached_result_set_expiration(memcached_result_st *result,
    time_t expiration);

DESCRIPTION

All of these functions operate on a memcached_result_st structure, which is the result of a single command to the memcached servers. These structures are created and managed by the libmemcached library.

memcached_result_key() returns the key value associated with the current result object.

memcached_result_key_length() returns the key length associated with the current result object.

memcached_result_value() returns the result value associated with the current result object.

memcached_result_length() returns the result length associated with the current result object.

memcached_result_flags() returns the flags associated with the current result object.

memcached_result_cas() returns the cas associated with the current result object. This value will only be available if the server tests it.

memcached_result_set_value() takes a byte array and a size and sets the result to this value. This function is used for trigger responses.

memcached_result_set_flags() takes a result structure and stores a new value for the flags field.

memcached_result_set_expiration() takes a result structure and stores a new value for the expiration field (this is only used by read through triggers).

RETURN VALUE

Varies, see particular functions. All structures must have memcached_result_free() called on them for cleanup purposes. Failure to do this will result in leaked memory.
