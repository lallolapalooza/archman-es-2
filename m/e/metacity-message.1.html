METACITY-MESSAGE(1) Manual de comandos generales METACITY-MESSAGE(1)

NOMBRE

METACITY-MESSAGE - un comando para enviar un mensaje a Metacity

SINOPSIS

METACITY-MESSAGE [ restart | reload-theme | enable-keybindings | disable-keybindings | enable-mouse-button-modifiers | disable-mouse-button-modifiers | toggle-verbose ]

DESCRIPCIÓN

Esta página del manual documenta brevemente metacity-message. Esta página del manual fue escrita para la distribución Debian porque el programa original no tiene una página del manual.

metacity-message envía un mensaje especificado a metacity(1).

OPCIONES

restart
Reinicia metacity(1) que se está ejecutando.
reload-theme
Recarga un tema que se especifica en la base de datos de gsettings.
enable-keybindings
Habilita todas las combinaciones de teclas especificadas en la base de datos de gsettings.
disable-keybindings
Deshabilita todas las combinaciones de teclas especificadas en la base de datos de gsettings.
enable-mouse-button-modifiers
Habilita operaciones de mover/redimensionar mientras se presiona una tecla modificadora.
disable-mouse-button-modifiers
Deshabilita operaciones de mover/redimensionar mientras se presiona una tecla modificadora.
toggle-verbose
Activa o desactiva los mensajes de depuración.

VER TAMBIÉN
