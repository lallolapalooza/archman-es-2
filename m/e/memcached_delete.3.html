memcached_delete(3)

Paquete: libmemcached-awesome

Licencias: BSD

MEMCACHED_DELETE(3) libmemcached-awesome MEMCACHED_DELETE(3)

NOMBRE

memcached_delete - Documentación de libmemcached

SINOPSIS

#include <libmemcached/memcached.h>
Compilar y enlazar con -lmemcached
memcached_return_t memcached_delete(memcached_st *ptr, const char *key, size_t key_length, time_t expiration)
memcached_return_t memcached_delete_by_key(memcached_st *ptr, const char *group_key, size_t group_key_length, const char *key, size_t key_length, time_t expiration)
Parámetros
  • ptr -- puntero a una estructura memcached_st inicializada
  • group_key -- espacio de nombres de la clave
  • group_key_length -- longitud de group_key sin ningún cero terminador
  • key -- la clave a eliminar
  • key_length -- la longitud de key sin ningún cero terminador
  • expiration -- obsoleto desde la versión 1.4 de memcached(1)
Devoluciones
memcached_return_t indicando éxito

DESCRIPCIÓN

memcached_delete() se utiliza para eliminar una clave particular. memcached_delete_by_key() funciona igual, pero toma una clave maestra para encontrar el valor dado.

La expiración funciona colocando el elemento en una cola de eliminación, lo que significa que no será posible recuperarlo mediante el comando "get". Los comandos "add" y "replace" con esta clave también fallarán (sin embargo, el comando "set" tendrá éxito). Después de que pase el tiempo, el elemento se elimina finalmente de la memoria del servidor.

Tenga en cuenta que el servidor memcached eliminó las pruebas de expiración en la versión 1.4.

VALOR DE RETORNO

Se devuelve un valor de tipo memcached_return_t. En caso de éxito, ese valor será MEMCACHED_SUCCESS. Utilice memcached_strerror() para traducir este valor a una cadena imprimible.

Si está utilizando el modo no bloqueante de la biblioteca, el éxito solo significa que el mensaje se ha puesto en cola para su entrega.
