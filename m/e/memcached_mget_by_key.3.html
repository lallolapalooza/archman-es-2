NOMBRE

memcached_mget_by_key - Recuperar datos del servidor

SINOPSIS

#include <libmemcached/memcached.h>
Compilar y enlazar con -lmemcached
memcached_result_st *memcached_fetch_result(memcached_st *ptr, memcached_result_st *result, memcached_return_t *error)

memcached_return_t memcached_mget_execute(memcached_st *ptr, const char *const *keys, const size_t *key_length, size_t number_of_keys, memcached_execute_fn *callback, void *context, uint32_t number_of_callbacks)

DESCRIPCIÓN

memcached_get() se utiliza para obtener un valor individual del servidor. Debes pasar una clave y su longitud para obtener el objeto. Debes proporcionar tres variables puntero que te darán el estado del objeto devuelto. Un puntero uint32_t para contener cualquier bandera que almacenaste con el valor, un puntero size_t que se llenará con el tamaño del objeto y un puntero memcached_return_t para contener cualquier error. El objeto se devolverá si tiene éxito y NULL se devolverá en caso de fallo. Cualquier objeto devuelto por memcached_get() debe ser liberado por la aplicación que lo llama.

memcached_mget() se utiliza para seleccionar múltiples claves a la vez. Para operaciones con múltiples claves, siempre es más rápido utilizar esta función. Esta función siempre funciona de forma asíncrona.

Para recuperar datos después de una ejecución exitosa de memcached_mget(), deberás llamar a memcached_fetch_result(). Debes seguir llamando a esta función hasta que devuelva NULL (es decir, no hay más valores). Si necesitas salir a mitad de una llamada a memcached_mget(), puedes ejecutar un memcached_quit(), aunque esto no es necesario.

memcached_fetch_result() se utiliza para obtener un valor individual del servidor. memcached_mget() siempre debe llamarse antes de usar este método. Debes pasar una clave y su longitud para obtener el objeto. Debes proporcionar tres variables puntero que te darán el estado del objeto devuelto. Un puntero uint32_t para contener cualquier bandera que almacenaste con el valor, un puntero size_t que se llenará con el tamaño del objeto y un puntero memcached_return_t para contener cualquier error. El objeto se devolverá si tiene éxito y NULL se devolverá en caso de fallo. MEMCACHED_END es devuelto por el valor de *error cuando todos los objetos encontrados han sido devueltos. El valor final tras MEMCACHED_END es nulo.

memcached_fetch_result() se utiliza para devolver una estructura memcached_result_st de un servidor memcached. El objeto resultante es compatible con versiones futuras de cambios en el servidor. Para más información, consulta la ayuda de memcached_result_st. Esta función asignará dinámicamente una estructura de resultados para ti si no le pasas una a la función.

memcached_fetch_execute() es una función de callback para conjuntos de resultados. En lugar de devolverte los resultados para su procesamiento, pasa cada uno de los conjuntos de resultados a la lista de funciones que proporcionas. Pasa a la función un memcached_st que puede clonarse para usarlo en la función llamada (no se puede usar directamente). También pasa un conjunto de resultados que no necesita ser liberado. Finalmente, pasa un "contexto". Este es solo un puntero a una referencia de memoria que proporcionas a la función de llamada. Actualmente, solo se pasa un valor a cada llamada de función. En el futuro, habrá una opción para permitir que esto sea un array.

memcached_mget_execute() y memcached_mget_execute_by_key() son similares a memcached_mget(), pero pueden activar los callbacks proporcionados con conjuntos de resultados mientras envían las consultas. Si intentas realizar un multiget muy grande con memcached_mget(), puedes encontrar un deadlock en el kernel del sistema operativo (fallará al escribir datos en el socket porque el búfer de entrada está lleno). memcached_mget_execute() resuelve este problema procesando algunos de los resultados antes de continuar enviando solicitudes. Ten en cuenta que esta función solo está disponible en el protocolo binario.

memcached_get_by_key() y memcached_mget_by_key() se comportan de manera similar a memcached_get() y memcached_mget(). La diferencia es que toman una clave maestra que se utiliza para determinar en qué servidor se almacenó un objeto si se utilizó particionamiento de claves para el almacenamiento.

Todas las funciones anteriores no se prueban cuando se ha activado MEMCACHED_BEHAVIOR_USE_UDP. Ejecutar cualquiera de estas funciones con este comportamiento activado resultará en la devolución de MEMCACHED_NOT_SUPPORTED, o para aquellas funciones que no devuelven un memcached_return_t, el parámetro de la función de error se establecerá en MEMCACHED_NOT_SUPPORTED.

VALOR DE RETORNO

memcached_get() devolverá NULL en caso de error. Debes examinar el valor de error para determinar cuál fue el error real.

memcached_fetch_execute() devuelve MEMCACHED_SUCCESS si todas las claves fueron exitosas. MEMCACHED_NOTFOUND se devolverá si no se encontró ninguna clave.

memcached_fetch_result() establece error a MEMCACHED_END al concluir con éxito. MEMCACHED_NOTFOUND se devolverá si no se encontró ninguna clave.

NAME

memcached_mget_by_key - retrieve multiple values from the memcached server by key

SYNOPSIS

memcached_return_t memcached_mget_by_key(memcached_st *ptr, const char *key, size_t key_length, char **keys, size_t *key_lengths, unsigned int number_of_keys);

DESCRIPTION

The memcached_mget_by_key() function shall retrieve multiple values from the memcached server. The memcached server will be identified by ptr. The key and key_length parameters define the key for which the value is to be retrieved. The keys and key_lengths parameters are arrays which define which keys are to be retrieved. The number_of_keys parameter defines the number of keys in the arrays.

The memcached_mget_by_key() function shall return the result of the operation. The return value shall be one of the values described by memcached_return_t.

The memcached_result_st structure contains the value for the requested key. The memcached_result_st structure contains the following members:

  • value: the value for the requested key.
  • length: the length of the value.
  • flags: the flags for the value.
  • expiration: the expiration time for the value.

The memcached_result_st structure is populated by the memcached_mget_by_key() function.

The memcached_mget_by_key() function shall return MEMCACHED_SUCCESS on success.

The memcached_mget_by_key() function shall return MEMCACHED_FAILURE on failure.

The memcached_mget_by_key() function shall return MEMCACHED_NOTFOUND if the value is not found.

The memcached_mget_by_key() function shall return MEMCACHED_SOME_ERRORS if some of the values were not found.
