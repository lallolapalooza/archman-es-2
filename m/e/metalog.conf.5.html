DESCRIPCIÓN

[valores por defecto] se utilizarán si no los redefine en una sección. Puede elegir el <título de sección> como desee. No significa nada, solo le permite mantener un archivo de configuración fácil de leer.

Los nombres de los valores pueden ser uno de los siguientes:

maxsize = <número (bytes)>
Una vez que un archivo de registro haya superado el valor definido (en bytes), se rotará. Si maxfile es igual a cero, deshabilita la rotación de registros. Definir un valor predeterminado es una buena idea.
maxtime = <número (segundos)>
Una vez que un archivo de registro sea más antiguo que el valor definido (en segundos), se rotará. Definir un valor predeterminado es una buena idea.

NB: Un archivo de registro se rota cuando se alcanza el límite de maxsize o maxtime. Si alguno o ambos es igual a 0, la rotación de registros se deshabilita.

maxfiles = <número>
Este valor indica el número máximo de archivos rotados que se conservan. Por lo tanto, tendrá x archivos rotados (fecha-cadena-registro nombre de archivo tipo), más el archivo llamado "actual".
facility = "<facility>"
Solo registra un mensaje si la aplicación que lo emitió utiliza la instalación de syslog <facility>. Los nombres de las instalaciones son: "auth", "authpriv", "cron", "daemon", "ftp", "kern", "lpr", "mail", "news", "security", "syslog", "user", "uucp", "local0", "local1" ... "local7". Todos los mensajes del kernel se registran con la instalación "kern". Una sección puede tener varias líneas "facility = ..." para que coincidan con más de una instalación. Si <facility> es "*", coincidirá con todas las instalaciones.
remote_host = "<dirección IP o nombre de dominio>"
Las entradas de registro se envían al servidor de registro remoto definido por esta dirección IP o nombre de dominio. Solo se puede definir un servidor de registro remoto. Esto solo se puede definir en la sección de valores predeterminados. Todos los mensajes de registro se envían allí, las limitaciones a través de "ratelimit", "ratelimit_burst" o "showrepeats" se ignoran para los mensajes de registro enviados al servidor de registro remoto. En caso de que se configure un nombre de dominio o de host, la solicitud DNS necesaria se repetirá después de cada intento fallido o después de 120 segundos cuando el nombre se haya resuelto correctamente.
remote_port = "<valor>"
El puerto UDP del servidor de registro remoto. El valor predeterminado es "514". Esto solo se puede definir en la sección de valores predeterminados.
remote_log = "<número>"
El valor predeterminado es 0. Los mensajes de registro se envían al servidor de registro remoto cuando se establece en 1. Se puede definir para los valores predeterminados o en las secciones.
break = <número>
El valor predeterminado es 0. Si se establece en 1 y coincide con una sección, realice la acción, pero no considere ninguna coincidencia de sección adicional a continuación en el archivo de configuración. Esto es útil para crear una configuración donde se comparan y envían tipos específicos de mensajes de registro, mientras que una sección "capturar todo" al final del archivo de configuración maneja el caso predeterminado.

Usar 0 haría que los mensajes fueran manejados potencialmente por múltiples secciones, causando duplicación de mensajes, mientras que usar 1 en las secciones anteriores a un "capturar todo" final evitaría la duplicación.

minimum = <nivel>
Solo registra un mensaje si su urgencia es inferior o igual a <nivel>. El nivel '0' es el más crítico, mientras que el nivel '7' es para mensajes de depuración. 5 eliminará todos los mensajes no importantes. El nivel mínimo predeterminado es 7 (es decir, conservar todos los mensajes).
maximum = <nivel>
No registre si el nivel del mensaje excede ese valor. Por defecto, maximum es el nivel más alto posible.
logdir = "/dir/donde/se/escribirán/los/registros/"
Los archivos se escribirán en el directorio especificado. El valor especial "NONE" omitirá el mensaje de registro.
perms = <modo>
Permisos para el directorio de registro. Predeterminado a 0700
program = "nombre"
Se puede usar para filtrar en lugar de facility. Recuerde usar el nombre del ejecutable.
regex = "expresión regular compatible con perl"
Se puede usar cuando solo desea registrar mensajes que coincidan con el patrón (como "inválido", "fallo", etc.) para enviarlos a un único directorio.

Se pueden definir varios regex en una sola sección, solo uno debe coincidir.

neg_regex = "expresión regular compatible con perl"
Se puede usar cuando solo desea registrar mensajes que no coincidan con el patrón.

Una coincidencia de neg_regex anulará cualquier coincidencia de regex y no registrará el mensaje.

Cuando se proporcionan una o más regex, al menos una de ellas debe coincidir para registrar el mensaje. La falta de cualquier regex resultará en que el mensaje se registre cuando no haya coincidencia de neg_regex.

Se pueden definir varios neg_regex en una sección, solo uno debe coincidir.

postrotate_cmd = "/ruta/a/un/programa"
Ejecuta el programa especificado después de que se haya rotado un archivo de registro.

Al programa se le pasan la fecha, el nombre del programa ("metalog") y el nuevo nombre del archivo de registro.

program_regex = "expresión regular compatible con perl"
Similar a program, esta es una expresión regular que coincide con el nombre del programa para enviar todos los mensajes de programas relacionados al mismo archivo de registro.

Se pueden definir varios program_regex en una sección, solo uno debe coincidir.

program_neg_regex = "expresión regular compatible con perl"
La inversa de program_regex para filtrar registros de programas que coinciden.

Una coincidencia de program_neg_regex anulará cualquier coincidencia de program_regex y no registrará el mensaje.

Cuando se proporcionan uno o más program_regex, al menos uno de ellos debe coincidir para registrar el mensaje. La falta de cualquier program_regex resultará en que el mensaje se registre cuando no haya coincidencia de program_neg_regex.

Se pueden definir varios program_neg_regex en una sección, solo uno debe coincidir.

showrepeats = <número>
Establecer en 0 para filtrar mensajes de registro repetidos.
command = "/ruta/al/programa/a/ejecutar"
Ejecuta el programa especificado tan pronto como se registra algo en una sección dada.

Al programa se le pasan la fecha, el nombre del programa coincidente y el mensaje de registro.

En caso de que el programa no exista al inicio de metalog, metalog no saldrá y simplemente ignorará esa línea de configuración.

NAME

metalog.conf - metalog(8) configuration file format

SYNOPSIS

metalog.conf(5) [FILE...]

DESCRIPTION

The configuration file for metalog(8) consists of key/value pairs. Blank lines and lines starting with a # character are ignored. The first non-empty line may be a format string for the timestamp. If it is not recognized as a configuration directive, it is assumed to be the timestamp format string. The default timestamp format string is %Y-%m-%d %H:%M:%S.

timestamp = "%[nnn]N %a %b %d %T %Y"
Format string for the timestamp, see strftime(3) for details. The special sequence %[nnn]N is supported which prints the time in nanoseconds. The number of n's may be less than 9 to shorten the output. If the timestamp format string is empty, timestamps are disabled. This is useful if the log message already contains a timestamp.
flush = <number>
If set to 0, matching log messages will always be buffered. If set to 1, they will always be written to the file system immediately.

Both settings override the global default given through command line parameters (-a/-s) or signals.

ratelimit = "5/m"
Limits the rate of logged messages to the specified number of messages per unit of time. Valid units of time are second, minute, hour and day, each identified by its first letter. Fractional values are allowed such as "0.5/m" to make human parsing easier.

A limit of 0 (the default) may be used to disable any rate limit handling. In this case, the unit of time may be omitted.

ratelimit_burst = <number>
Up to this number of lines will be printed at the beginning of a burst of message, if the rate of messages has been well below the limit before. The specified message rate will not be exceeded. The default value of 1 disables special treatment for bursts. Values less than 1 are invalid and will be rejected.
configdir = "/path/to/directory/with/more/config/files"
This optional directory can contain more config files that will get interpreted at metalog start. Only file names ending with ".conf" are interpreted. This option is only allowed once, all repetitions will be ignored.

FILES

Note that the exact paths depend on the build settings. These are the standard paths.
