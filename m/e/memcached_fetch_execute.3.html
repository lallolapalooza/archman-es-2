memcached_fetch_execute(3)

Paquete: libmemcached-awesome

Licencias: BSD

MEMCACHED_FETCH_EXECUTE(3) libmemcached-awesome MEMCACHED_FETCH_EXECUTE(3)

NOMBRE

memcached_fetch_execute - Recuperar datos del servidor

SINOPSIS

#include <libmemcached/memcached.h>
Compilar y enlazar con -lmemcached
memcached_result_st *memcached_fetch_result(memcached_st *ptr, memcached_result_st *result, memcached_return_t *error)
char *memcached_get(memcached_st *ptr, const char *key, size_t key_length, size_t *value_length, uint32_t *flags, memcached_return_t *error)
memcached_return_t memcached_mget(memcached_st *ptr, const char *const *keys, const size_t *key_length, size_t number_of_keys)
char *memcached_get_by_key(memcached_st *ptr, const char *group_key, size_t group_key_length, const char *key, size_t key_length, size_t *value_length, uint32_t *flags, memcached_return_t *error)
memcached_return_t memcached_mget_by_key(memcached_st *ptr, const char *group_key, size_t group_key_length, const char *const *keys, const size_t *key_length, size_t number_of_keys)
memcached_return_t memcached_fetch_execute(memcached_st *ptr, memcached_execute_fn *callback, void *context, uint32_t number_of_callbacks)
memcached_return_t memcached_mget_execute(memcached_st *ptr, const char *const *keys, const size_t *key_length, size_t number_of_keys, memcached_execute_fn *callback, void *context, uint32_t number_of_callbacks)
memcached_return_t memcached_mget_execute_by_key(memcached_st *ptr, const char *group_key, size_t group_key_length, const char *const *keys, const size_t *key_length, size_t number_of_keys, memcached_execute_fn *callback, void *context, uint32_t number_of_callbacks)
typedef memcached_return_t (*memcached_execute_fn)(const memcached_st *ptr, memcached_result_st *result, void *context)

DESCRIPCIÓN

memcached_get() se utiliza para obtener un valor individual del servidor. Debe pasar una clave y su longitud para obtener el objeto. Debe suministrar tres variables puntero que le proporcionarán el estado del objeto devuelto. Un puntero uint32_t para contener las banderas que haya almacenado con el valor, un puntero size_t que se llenará con el tamaño del objeto y un puntero memcached_return_t para almacenar cualquier error. El objeto se devolverá si tiene éxito y NULL si falla. Cualquier objeto devuelto por memcached_get() debe ser liberado por la aplicación que llama.

memcached_mget() se utiliza para seleccionar varias claves a la vez. Para operaciones de claves múltiples, siempre es más rápido usar esta función. Esta función siempre funciona de forma asíncrona.

Para recuperar datos después de una ejecución exitosa de memcached_mget(), deberá llamar a memcached_fetch_result(). Deberá seguir llamando a esta función hasta que devuelva NULL (es decir, no hay más valores). Si necesita salir a mitad de una llamada a memcached_mget(), puede ejecutar un memcached_quit(), aunque esto no es obligatorio.

memcached_fetch_result() se utiliza para obtener un valor individual del servidor. memcached_mget() siempre debe llamarse antes de usar este método. Debe pasar una clave y su longitud para obtener el objeto. Debe suministrar tres variables puntero que le proporcionarán el estado del objeto devuelto. Un puntero uint32_t para contener las banderas que haya almacenado con el valor, un puntero size_t que se llenará con el tamaño del objeto y un puntero memcached_return_t para almacenar cualquier error. El objeto se devolverá si tiene éxito y NULL si falla. MEMCACHED_END se devuelve en el valor de *error cuando todos los objetos encontrados han sido devueltos. El valor final en MEMCACHED_END es nulo.

memcached_fetch_result() se utiliza para devolver una estructura memcached_result_st de un servidor memcached. El objeto de resultado es compatible con versiones futuras de los cambios en el servidor. Para más información, consulte la ayuda de memcached_result_st. Esta función asignará dinámicamente una estructura de resultado si no le pasa una función a la función.

memcached_fetch_execute() es una función de devolución de llamada para conjuntos de resultados. En lugar de devolverle los resultados para su procesamiento, pasa cada uno de los conjuntos de resultados a la lista de funciones que usted proporciona. Pasa a la función un memcached_st que puede clonarse para su uso en la función llamada (no se puede usar directamente). También pasa un conjunto de resultados que no necesita ser liberado. Finalmente, pasa un "contexto". Este es solo un puntero a una referencia de memoria que usted suministra a la función que llama. Actualmente solo se pasa un valor a cada llamada de función. En el futuro habrá una opción para permitir que esto sea un array.

memcached_mget_execute() y memcached_mget_execute_by_key() son similares a memcached_mget(), pero pueden activar las devoluciones de llamada suministradas con conjuntos de resultados mientras envían las consultas. Si intenta realizar una operación multiget muy grande con memcached_mget(), puede encontrar un interbloqueo en el kernel del SO (fallará al escribir datos en el socket porque el búfer de entrada está lleno). memcached_mget_execute() resuelve este problema procesando algunos de los resultados antes de continuar enviando solicitudes. Tenga en cuenta que esta función solo está disponible en el protocolo binario.

memcached_get_by_key() y memcached_mget_by_key() se comportan de manera similar a memcached_get() y memcached_mget(). La diferencia es que toman una clave maestra que se utiliza para determinar en qué servidor se almacenó un objeto si se utilizó la partición de claves para el almacenamiento.

Todas las funciones anteriores no se prueban cuando se ha activado MEMCACHED_BEHAVIOR_USE_UDP. La ejecución de cualquiera de estas funciones con este comportamiento activado dará como resultado la devolución de MEMCACHED_NOT_SUPPORTED, o para aquellas funciones que no devuelven un memcached_return_t, el parámetro de función de error se establecerá en MEMCACHED_NOT_SUPPORTED.

VALOR DE RETORNO

memcached_get() devolverá NULL en caso de error. Debe examinar el valor de error para determinar cuál fue el error real.

memcached_fetch_execute() devuelve MEMCACHED_SUCCESS si todas las claves fueron exitosas. MEMCACHED_NOTFOUND se devolverá si no se encontró ninguna clave.

memcached_fetch_result() establece error en MEMCACHED_END tras una conclusión exitosa. MEMCACHED_NOTFOUND se devolverá si no se encontró ninguna clave.

VER TAMBIÉN

memcached_strerror(3)

NAME

memcached_strerror - return a string describing the error

SYNOPSIS

#include <libmemcached/memcached.h>

char *memcached_strerror(memcached_return_t rc);

DESCRIPTION

The memcached_strerror() function shall return a pointer to a string that describes the error code passed in via the rc argument.

RETURN VALUE

On success, memcached_strerror() shall return a pointer to a static string describing the error. The caller must not modify this string. On failure, the caller must not rely on the return value.
