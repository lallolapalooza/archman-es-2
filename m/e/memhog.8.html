NOMBRE

memhog - Asigna memoria con política para pruebas

SINOPSIS

memhog [ -r<NUM> ] [ tamaño kmg ] [ política conjunto-nodos ] [ -f<archivo> ]

DESCRIPCIÓN

memhog mapea una región de memoria de un tamaño dado y establece la política numa (si se especifica). Luego actualiza la región de memoria para el número dado de iteraciones usando memset.

-r<num> Repetir memset NUM veces
-f<archivo> Abrir archivo para respaldo de mmap
-H Deshabilitar páginas grandes transparentes
-tamaño Tamaño de asignación en bytes, puede tener un orden de mayúsculas/minúsculas indiferente
sufijo (G=gigabyte, M=megabyte, K=kilobyte)

Políticas numa soportadas:

intercalar
La memoria se asignará usando round robin en los nodos. Cuando no se pueda asignar memoria en el nodo actual de intercalación, se recurrirá a otros nodos. Se pueden especificar varios nodos.
asignar-memoria
Solo asignar memoria de los nodos. La asignación fallará cuando no haya suficiente memoria disponible en estos nodos. Se pueden especificar varios nodos.
preferido
Preferentemente asignar memoria en el nodo, pero si no se puede asignar allí, se recurrirá a otros nodos. Esta opción solo toma un número de nodo.
predeterminado
La memoria se asignará en el nodo local (el nodo en el que se está ejecutando el hilo)

EJEMPLOS

# Asignar una región de 1G, respaldada por mmap del archivo memhog.mmap, asignar-memoria al nodo 0, repetir la prueba 6 veces
memhog -r6 1G --asignar-memoria 0 -fmemhog.mmap
# Asignar una región de 1G, intercalar entre los nodos 0,1,2,3, repetir la prueba 4 veces
memhog -r4 1G --intercalar 0-3
# Asignar una región de 1G, (implícitamente) política predeterminada, repetir la prueba 8 veces
memhog -r8 1G
