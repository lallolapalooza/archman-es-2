memory(n) Comandos integrados de Tcl memory(n)

NOMBRE

memory - Controla las capacidades de depuración de memoria de Tcl

SINOPSIS

memory opción ?arg arg ...?

DESCRIPCIÓN

El comando memory da al desarrollador de Tcl control sobre las capacidades de depuración de memoria de Tcl. El comando memory tiene varias subopciones, que se describen a continuación. Solo está disponible cuando Tcl ha sido compilado con la depuración de memoria habilitada (cuando TCL_MEM_DEBUG está definido en tiempo de compilación), y después de que Tcl_InitMemory haya sido llamado.

memory active archivo
Escribe una lista de toda la memoria asignada actualmente en el archivo especificado.
memory break_on_malloc contador
Después de que se hayan realizado el contador de asignaciones, ckalloc emite un mensaje a tal efecto y que ahora está intentando entrar en el depurador C. Tcl emitirá entonces una señal SIGINT contra sí mismo. Si está ejecutando Tcl bajo un depurador C, debería entrar entonces en el modo de comandos del depurador.
memory info
Devuelve un informe que contiene las asignaciones y liberaciones totales desde que Tcl comenzó, los paquetes actualmente asignados (el número actual de llamadas a ckalloc no satisfechas por una llamada correspondiente a ckfree), los bytes actualmente asignados, y el número máximo de paquetes y bytes asignados.
memory init [on|off]
Activa o desactiva la preinicialización de toda la memoria asignada con bytes falsos. Útil para detectar el uso de valores no inicializados.
memory objs archivo
Hace que se escriba inmediatamente una lista de todos los valores Tcl_Obj asignados en el archivo especificado, junto con dónde fueron asignados. Útil para comprobar fugas de valores.
memory onexit archivo
Hace que se escriba una lista de toda la memoria asignada en el archivo especificado durante la finalización del subsistema de memoria de Tcl. Útil para comprobar que la memoria se limpia correctamente al salir del proceso.
memory tag cadena
Cada paquete de memoria asignado por ckalloc puede tener asociada una etiqueta con valor de cadena. En las listas de memoria asignada generadas por memory active y memory onexit, la etiqueta de cada paquete se imprime junto con otra información sobre el paquete. El comando memory tag establece el valor de la etiqueta para las llamadas posteriores a ckalloc a ser cadena.
memory trace [on|off]
Activa o desactiva el rastreo de memoria. Cuando el rastreo de memoria está activado, cada llamada a ckalloc hace que se escriba una línea de información de rastreo en stderr, que consiste en la palabra ckalloc, seguida de la dirección devuelta, la cantidad de memoria asignada, y el nombre del archivo C y el número de línea del código que realiza la asignación. Por ejemplo:
ckalloc 40e478 98 tclProc.c 1406

Las llamadas a ckfree se rastrean de la misma manera.

memory trace_on_at_malloc contador
Activa el rastreo de memoria después de que se hayan realizado contador ckallocs. Por ejemplo, si introduce memory trace_on_at_malloc 100, después de la centésima llamada a ckalloc, la información de rastreo de memoria comenzará a mostrarse para todas las asignaciones y liberaciones. Como puede haber mucha actividad de memoria antes de que ocurra un problema, el uso juicioso de esta opción puede reducir la lentitud causada por el rastreo (y la cantidad de información de rastreo producida), si puede identificar un número de asignaciones que ocurren antes de que el problema se manifieste. El número actual de asignaciones de memoria que han ocurrido desde que Tcl comenzó se imprime en un fallo de zona de protección.
memory validate [on|off]
Activa o desactiva la validación de memoria. Cuando la validación de memoria está habilitada, en cada llamada a ckalloc o ckfree, se comprueban las zonas de protección para cada pieza de memoria actualmente existente que fue asignada por ckalloc. Esto tiene un gran impacto en el rendimiento y solo debe usarse cuando se sospechan problemas de sobrescritura. La ventaja de habilitar la validación de memoria es que una sobrescritura de zona de protección puede detectarse en la primera llamada a ckalloc o ckfree después de que ocurrió la sobrescritura, en lugar de cuando se libera la memoria específica con la(s) zona(s) de protección sobrescrita(s), lo que puede ocurrir mucho después de que ocurriera la sobrescritura.

VER TAMBIÉN

ckalloc, ckfree, Tcl_ValidateAllMemory, Tcl_DumpActiveMemory, TCL_MEM_DEBUG

PALABRAS CLAVE
