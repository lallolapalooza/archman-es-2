menubutton(n) Comandos integrados de Tk menubutton(n)

NOMBRE

menubutton - Crear y manipular widgets indicadores de menú emergente 'menubutton'

SINOPSIS

menubutton nombreRuta ?opciones?

OPCIONES ESTÁNDAR

-activebackground	-disabledforeground	-padx
-activeforeground	-font	-pady
-anchor	-foreground	-relief
-background	-highlightbackground	-takefocus
-bitmap	-highlightcolor	-text
-borderwidth	-highlightthickness	-textvariable
-cursor	-image	-underline
-compound	-justify	-wraplength

Consulte la entrada del manual de options para obtener más detalles sobre las opciones estándar.

OPCIONES ESPECÍFICAS DEL WIDGET

Nombre de línea de comandos:	-direction
Nombre de la base de datos:	direction
Clase de la base de datos:	Direction
Especifica dónde se mostrará el menú emergente. above intenta mostrar el menú por encima del menubutton. below intenta mostrar el menú por debajo del menubutton. left intenta mostrar el menú a la izquierda del menubutton. right intenta mostrar el menú a la derecha del menubutton. flush muestra el menú directamente sobre el menubutton. En el caso de above o below, la dirección se invertirá si el menú quedaría fuera de pantalla.
Nombre de línea de comandos:	-height
Nombre de la base de datos:	height
Clase de la base de datos:	Height
Especifica una altura deseada para el menubutton. Si se está mostrando una imagen o un bitmap en el menubutton, el valor se mide en unidades de pantalla (es decir, cualquiera de las formas aceptables para Tk_GetPixels); para texto, se mide en líneas de texto. Si no se especifica esta opción, la altura deseada del menubutton se calculará a partir del tamaño de la imagen, el bitmap o el texto que se esté mostrando en él.
Nombre de línea de comandos:	-indicatoron
Nombre de la base de datos:	indicatorOn
Clase de la base de datos:	IndicatorOn
El valor debe ser un valor booleano válido. Si es verdadero, se mostrará un pequeño rectángulo indicador en el lado derecho del menubutton y los enlaces predeterminados tratarán esto como un menubutton de opción. Si es falso, no se mostrará ningún indicador.
Nombre de línea de comandos:	-menu
Nombre de la base de datos:	menu
Clase de la base de datos:	MenuName
Especifica el nombre de ruta del menú asociado con este menubutton. El menú debe ser un hijo del menubutton.
Nombre de línea de comandos:	-state
Nombre de la base de datos:	state
Clase de la base de datos:	State
Especifica uno de los tres estados para el menubutton: normal, active o disabled. En el estado normal, el menubutton se muestra utilizando las opciones foreground y background. El estado activo se utiliza típicamente cuando el puntero está sobre el menubutton. En el estado activo, el menubutton se muestra utilizando las opciones -activeforeground y -activebackground. El estado deshabilitado significa que el menubutton debe ser insensible: los enlaces predeterminados rechazarán la activación del widget e ignorarán los clics del ratón. En este estado, las opciones -disabledforeground y -background determinan cómo se muestra el botón.
Nombre de línea de comandos:	-width
Nombre de la base de datos:	width
Clase de la base de datos:	Width
Especifica un ancho deseado para el menubutton. Si se está mostrando una imagen o un bitmap en el menubutton, el valor se mide en unidades de pantalla (es decir, cualquiera de las formas aceptables para Tk_GetPixels); para texto, se mide en caracteres. Si no se especifica esta opción, el ancho deseado del menubutton se calculará a partir del tamaño de la imagen, el bitmap o el texto que se esté mostrando en él.

INTRODUCCIÓN

El comando menubutton crea una nueva ventana (dada por el argumento nombreRuta) y la convierte en un widget menubutton. Se pueden especificar opciones adicionales, descritas anteriormente, en la línea de comandos o en la base de datos de opciones para configurar aspectos del menubutton, como sus colores, fuente, texto y relieve inicial. El comando menubutton devuelve su argumento nombreRuta. En el momento en que se invoca este comando, no debe existir ninguna ventana llamada nombreRuta, pero el padre de nombreRuta debe existir.

Un menubutton es un widget que muestra una cadena de texto, un bitmap o una imagen y está asociado con un widget de menú. Si se muestra texto, debe estar todo en una sola fuente, pero puede ocupar varias líneas en la pantalla (si contiene saltos de línea o si se produce un ajuste debido a la opción -wraplength) y uno de los caracteres puede ser opcionalmente subrayado usando la opción -underline. En uso normal, al presionar el botón 1 del ratón sobre el menubutton, el menú asociado se muestra justo debajo del menubutton. Si el ratón se mueve sobre el menú antes de soltar el botón del ratón, la liberación del botón provoca la invocación de la entrada del menú subyacente. Cuando se suelta el botón, el menú se desactiva.

Los menubuttons se utilizan para construir un tk_optionMenu, que es el mecanismo preferido para permitir que un usuario seleccione un elemento de una lista en macOS.

Los menubuttons también se organizaban típicamente en grupos llamados barras de menú que permiten el escaneo: si se presiona el botón del ratón sobre un menubutton (haciendo que muestre su menú) y el ratón se mueve sobre otro menubutton en la misma barra de menú sin soltar el botón del ratón, entonces el menú del primer menubutton se desactiva y se muestra el menú del nuevo menubutton. Este uso está obsoleto en favor de establecer un toplevel con la opción -menu; consulte la opción -menu del toplevel para saber cómo hacerlo.

Existen varias interacciones entre menubuttons y menús; consulte la entrada del manual menu para obtener información sobre varias configuraciones de menú, como menús desplegables y menús de opciones.

COMANDO WIDGET

El comando menubutton crea un nuevo comando Tcl cuyo nombre es nombreRuta. Este comando puede usarse para invocar varias operaciones sobre el widget. Tiene la siguiente forma general:

nombreRuta option ?arg ...?
El opción y los args determinan el comportamiento exacto del comando. Los siguientes comandos son posibles para los widgets menubutton:
nombreRuta cget opción
Devuelve el valor actual de la opción de configuración dada por opción. Opción puede tener cualquiera de los valores aceptados por el comando menubutton.
nombreRuta configure ?opción? ?valor opción valor ...?
Consulta o modifica las opciones de configuración del widget. Si no se especifica ninguna opción, devuelve una lista que describe todas las opciones disponibles para nombreRuta (consulte Tk_ConfigureInfo para obtener información sobre el formato de esta lista). Si se especifica opción sin valor, el comando devuelve una lista que describe la opción con nombre (esta lista será idéntica a la sublista correspondiente del valor devuelto si no se especifica ninguna opción). Si se especifican uno o más pares opción-valor, el comando modifica las opciones dadas del widget para que tengan los valores dados; en este caso, el comando devuelve una cadena vacía. Opción puede tener cualquiera de los valores aceptados por el comando menubutton.

BINDINGS PREDETERMINADOS

Tk crea automáticamente enlaces de clase para los menubuttons que les proporcionan el siguiente comportamiento predeterminado:

[1]
Un menubutton se activa cuando el ratón pasa sobre él y se desactiva cuando el ratón sale de él.
[2]
Al presionar el botón 1 del ratón sobre un menubutton, este se muestra: su relieve cambia a realzado y su menú asociado se muestra debajo del menubutton. Si el ratón se arrastra hacia el menú con el botón aún presionado, y si el botón del ratón se suelta sobre una entrada del menú, el menubutton se desactiva y se invoca la entrada del menú.

DEFAULT BINDINGS

The default bindings for the menubutton widget are described below. These bindings are used to provide the menubutton's functionality. They can be changed using the bind command or by redefining the class bindings.

[1]
When the mouse pointer is over a menubutton, button 1 is pressed and released without moving the mouse, the menubutton posts its menu. If button 1 is pressed over a menubutton and released over a menu entry, the menu entry is invoked.
[2]
If button 1 is pressed over a menubutton and released over the menubutton itself, the menubutton unposts its menu. If the mouse is moved off the menubutton after pressing button 1, and then moved back over the menubutton before releasing the button, the menu remains posted.
[3]
If button 1 is pressed over a menubutton, and then the mouse is moved off the menubutton and button 1 is released, the menubutton unposts itself without invoking any menu entry.
[4]
If button 1 is pressed over a menubutton and then dragged over some other menubutton, the original menubutton unposts itself and the new menubutton posts.
[5]
If button 1 is pressed over a menubutton and released outside any menubutton or menu, the menubutton unposts without invoking any menu entry.
[6]
When a menubutton is posted, its associated menu claims the input focus to allow keyboard traversal of the menu and its submenus. See the menu manual entry for details on these bindings.
[7]
If the -underline option has been specified for a menubutton then keyboard traversal may be used to post the menubutton: Alt+x, where x is the underlined character (or its lower-case or upper-case equivalent), may be typed in any window under the menubutton's toplevel to post the menubutton.
[8]
The F10 key may be typed in any window to post the first menubutton under its toplevel window that is not disabled.
[9]
If a menubutton has the input focus, the space and return keys post the menubutton.

If the menubutton's state is disabled then none of the above actions occur: the menubutton is completely non-responsive.

The behavior of menubuttons can be changed by defining new bindings for individual widgets or by redefining the class bindings.
