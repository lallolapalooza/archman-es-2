MESG(1) Comandos de usuario MESG(1)

NOMBRE

mesg - mostrar (o no mostrar) mensajes de otros usuarios

SINOPSIS

mesg [opción] [n|y]

DESCRIPCIÓN

La utilidad mesg es invocada por un usuario para controlar el acceso de escritura que otros tienen al dispositivo de terminal asociado con la salida de error estándar. Si se permite el acceso de escritura, entonces programas como talk(1) y write(1) pueden mostrar mensajes en la terminal.

Tradicionalmente, el acceso de escritura está permitido por defecto. Sin embargo, a medida que los usuarios son más conscientes de los diversos riesgos de seguridad, existe una tendencia a eliminar el acceso de escritura por defecto, al menos para el shell de inicio de sesión principal.

Los permisos iniciales para la terminal se establecen mediante login(1) según TTYPERM y TTYGROUP de /etc/login.defs. El valor por defecto es el modo 0620 si se utiliza un grupo de tty, y 0600 sin el grupo. El nombre del grupo de tty por defecto es "tty".

Para asegurar que tus ttys se establecen de una manera portable e independiente de la configuración del sistema, mesg debe ejecutarse en tus scripts de inicio de sesión.

mesg modifica los permisos de escritura para un grupo en el dispositivo de terminal actual. Desde la versión 2.41, mesg ya no puede compilarse para hacer la terminal escribible para otros y estrictamente modifica solo los permisos de grupo. La configuración habitual es utilizar un grupo "tty" y añadir los usuarios relevantes a este grupo. Alternativamente, una solución menos segura es configurar utilidades como write(1) o wall(1) con setgid para el grupo "tty".

La utilidad mesg sale silenciosamente con el estado de error 2 si no se ejecuta en una terminal. En este caso, ejecutar mesg es inútil. La opción de línea de comandos --verbose fuerza a mesg a imprimir una advertencia en esta situación. Este comportamiento se introdujo en la versión 2.33.

ARGUMENTOS

n

No permitir mensajes.

y

Permitir que se muestren mensajes.

Si no se proporcionan argumentos, mesg muestra el estado actual de los mensajes en la salida de error estándar.

OPCIONES

-v, --verbose

Explicar lo que se está haciendo.

-h, --help

Mostrar texto de ayuda y salir.

-V, --version

Mostrar la versión y salir.

ESTADO DE SALIDA

La utilidad mesg sale con uno de los siguientes valores:

0

Se permiten mensajes.

1

No se permiten mensajes.

>1

Ha ocurrido un error.

FICHEROS

/dev/[pt]ty*, /dev/pts/[0-9]*

HISTORIA

mesg (I) aparece en el Manual del Programador de UNIX. Solía invertir el estado actual sin argumento antes de la Versión 7 de AT&T UNIX.

VER TAMBIÉN

login(1), talk(1), write(1), wall(1), xterm(1)
