NOMBRE

mev - un programa para informar eventos del ratón

SINOPSIS

mev [ opciones ]

DESCRIPCIÓN

El programa `mev' es parte del paquete gpm. La información a continuación se extrae del archivo texinfo, que es la fuente preferida de información.

El programa mev está modelado según xev. Imprime en la salida estándar los eventos de consola del ratón que recibe.

El comportamiento predeterminado de mev es obtener cualquier cosa, pero se pueden usar opciones de línea de comandos para establecer los diversos campos en la estructura Gpm_Connect, para personalizar el comportamiento del programa. Estoy usando mev para manejar eventos del ratón para Emacs.

Las opciones de línea de comandos para mev son las siguientes:

-C número
Selecciona una consola virtual para obtener eventos. Esto está pensado para usarse en depuración.
-d número
Elige una máscara predeterminada. Por defecto, el servidor recibe todos los eventos que no pertenecen a la máscara de eventos. La máscara se puede proporcionar como un número decimal o como una cadena simbólica.
-e número
Elige la máscara de eventos. Por defecto se reciben todos los eventos. La máscara se puede proporcionar como un número decimal o como una cadena simbólica.
-E
Entra en modo emacs. En modo emacs, los eventos se informan como formas lisp en lugar de números. Este es el formato utilizado por el paquete t-mouse dentro de emacs.
-f
Ajusta los eventos dentro de la pantalla antes de informarlos. Esta opción reajusta los eventos de arrastre, que tienen permitido salir del borde de la pantalla.
-i
Interactivo. Acepta entrada de stdin para cambiar los parámetros de conexión.
-m número
Elige la máscara de modificadores mínima. Cualquier evento con menos modificadores no se informará a mev. Por defecto es 0. La máscara debe proporcionarse como un número decimal o como una cadena simbólica.
-M número
Elige la máscara de modificadores máxima. Cualquier evento con más modificadores que los especificados no se informará a mev. Por defecto es ~0, es decir, se reciben todos los eventos. La máscara debe proporcionarse como un número decimal o como una cadena simbólica.
-p
Solicita dibujar el puntero durante los arrastres. Esta opción es utilizada por emacs para evitar invocar ioctl() desde código lisp.

Cuando los argumentos no son enteros decimales, se consideran listas de caracteres alfanuméricos, separados por un solo carácter no alfanumérico. Utilizo la coma (,), pero cualquiera sirve.

Los nombres permitidos para eventos son move, drag, down o press, up o release, motion (que es tanto move como drag), y hard.

Los nombres permitidos para modificadores son shift, leftAlt, rightAlt, anyAlt (uno u otro), control.

Cuando se especifica la opción -i, mev considera su entrada estándar como líneas de comando en lugar de eventos. Las líneas de entrada se analizan y se reconocen los comandos push y pop.

El comando push, a continuación, acepta las opciones -d, -e, -m y -M, con el mismo significado descrito anteriormente. Las opciones no especificadas conservan el valor anterior y las máscaras resultantes se utilizan para reabrir la conexión con el servidor. pop se utiliza para extraer la pila de conexiones. Si se extrae una pila vacía, el programa sale.

Otros comandos reconocidos son info, utilizado para devolver la profundidad de la pila; quit para terminar el programa prematuramente; y snapshot para obtener información de configuración del servidor.

ERRORES

A partir de la versión 1.16, mev ya no funciona bajo xterm. Por favor, utilice el programa rmev (proporcionado en el directorio sample) para observar eventos gpm bajo xterm o rxvt. rmev también muestra eventos de teclado además de eventos del ratón.
