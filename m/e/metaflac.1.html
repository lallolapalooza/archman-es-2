metaflac(1) Herramienta de metadatos de Free Lossless Audio Codec metaflac(1)

NOMBRE

metaflac - programa para listar, añadir, eliminar o editar metadatos en uno o varios archivos FLAC.

SINOPSIS

metaflac [ opciones ] [ operaciones ] archivoFLAC ...

DESCRIPCIÓN

Utilice metaflac para listar, añadir, eliminar o editar metadatos en uno o varios archivos FLAC. Puede realizar una operación principal, o varias operaciones abreviadas a la vez.

USO GENERAL

metaflac es el editor de metadatos de archivos .flac de línea de comandos. Puede utilizarlo para listar el contenido de los bloques de metadatos, editar, eliminar o insertar bloques, y gestionar el relleno (padding).

metaflac toma un conjunto de "opciones" (aunque algunas no son opcionales) y un conjunto de archivos FLAC sobre los que operar. Hay tres tipos de "opciones":

•
Operaciones principales, que especifican un modo de operación como listar bloques, eliminar bloques, etc. Estas tendrán sub-operaciones que describen exactamente lo que se va a hacer.
•
Operaciones abreviadas, que son sinónimos convenientes para operaciones principales. Por ejemplo, hay una operación abreviada --show-sample-rate que muestra solo el campo de frecuencia de muestreo del bloque de metadatos STREAMINFO.
•
Opciones globales, que afectan a todas las operaciones.

Todas ellas se describen en las tablas siguientes. Debe proporcionarse al menos una operación abreviada o principal. Puede utilizar múltiples operaciones abreviadas para hacer más de una cosa en un archivo o conjunto de archivos. La mayoría de las cosas comunes que se hacen con los metadatos tienen operaciones abreviadas. Como ejemplo, aquí se muestra cómo mostrar las firmas MD5 para un conjunto de tres archivos FLAC:

metaflac --show-md5sum archivo1.flac archivo2.flac archivo3.flac

Otro ejemplo; este elimina todas las etiquetas DESCRIPTION y COMMENT en un conjunto de archivos FLAC, y utiliza la opción global --preserve-modtime para mantener las mismas horas de modificación de los archivos FLAC (generalmente cuando se editan archivos, la hora de modificación se establece en la hora actual):

metaflac --preserve-modtime --remove-tag=DESCRIPTION --remove-tag=COMMENT archivo1.flac archivo2.flac archivo3.flac

OPCIONES

-o nombrearchivo, --output-name=nombrearchivo
Salida a un nuevo archivo en lugar de cambiar o reescribir el archivo de entrada.
--preserve-modtime
Preserva la hora de modificación original a pesar de las ediciones. Esto no hace nada cuando se especifican -o o --output-name.
--with-filename
Prefija cada línea de salida con el nombre del archivo FLAC (el valor predeterminado si se especifican varios archivos FLAC). Esta opción no tiene efecto para las opciones de exportación a un archivo, como --export-tags-to.
--no-filename
No prefije cada línea de salida con el nombre del archivo FLAC (el valor predeterminado si se especifica solo un archivo FLAC).
--no-utf8-convert
No convierta etiquetas de UTF-8 a la codificación local, o viceversa. Esto es útil para scripts y para establecer etiquetas en situaciones donde la configuración regional es incorrecta.
--dont-use-padding
Por defecto, metaflac intenta usar relleno (padding) siempre que sea posible para evitar reescribir todo el archivo si el tamaño de los metadatos cambia. Use esta opción para indicar a metaflac que no aproveche el relleno de esta manera.

OPERACIONES ABREVIADAS

--show-md5sum
Muestra la firma MD5 del bloque STREAMINFO.
--show-min-blocksize
Muestra el tamaño mínimo de bloque del bloque STREAMINFO.
--show-max-blocksize
Muestra el tamaño máximo de bloque del bloque STREAMINFO.
--show-min-framesize
Muestra el tamaño mínimo de fotograma del bloque STREAMINFO.
--show-max-framesize
Muestra el tamaño máximo de fotograma del bloque STREAMINFO.
--show-sample-rate
Muestra la frecuencia de muestreo del bloque STREAMINFO.
--show-channels
Muestra el número de canales del bloque STREAMINFO.
--show-bps
Muestra el número de bits por muestra del bloque STREAMINFO.
--show-total-samples
Muestra el número total de muestras del bloque STREAMINFO.
--show-vendor-tag
Muestra la cadena del proveedor del bloque VORBIS_COMMENT.
--show-tag=nombre
Muestra todas las etiquetas cuyo nombre de campo coincida con `nombre'.
--show-all-tags
Muestra todas las etiquetas. Esto es un alias de --export-tags-to=-.
--remove-tag=nombre
Elimina todas las etiquetas cuyo nombre de campo sea `nombre'.
--remove-first-tag=nombre
Elimina la primera etiqueta cuyo nombre de campo sea `nombre'.
--remove-all-tags
Elimina todas las etiquetas, dejando solo la cadena del proveedor.
--remove-all-tags-except=NOMBRE1[=NOMBRE2[=...]]
Elimina todas las etiquetas, excepto la cadena del proveedor y los nombres de etiqueta especificados. Los nombres de etiqueta deben separarse por un carácter =.
--set-tag=campo
Añade una etiqueta. El campo debe cumplir la especificación de comentarios Vorbis, con el formato “NOMBRE=VALOR”. Si actualmente no existe un bloque de etiquetas, se creará uno.
--set-tag-from-file=campo
Similar a --set-tag, excepto que el VALOR es un nombre de archivo cuyo contenido se leerá literalmente para establecer el valor de la etiqueta. A menos que se especifique --no-utf8-convert, el contenido se convertirá a UTF-8 desde la codificación local. Esto se puede usar para almacenar una hoja de pistas (cuesheet) en una etiqueta (por ejemplo, --set-tag-from-file=“CUESHEET=imagen.cue”). ¡No intente almacenar datos binarios en campos de etiquetas! Utilice bloques APPLICATION para eso.
--import-tags-from=archivo
Importa etiquetas desde un archivo. Use `-' para la entrada estándar. Cada línea debe tener el formato NOMBRE=VALOR. Los comentarios de varias líneas no son compatibles actualmente. Especifique --remove-all-tags y/o --no-utf8-convert antes de --import-tags-from si es necesario. Si ARCHIVO es `-' (entrada estándar), solo se puede especificar un archivo FLAC.
--export-tags-to=archivo
Exporta etiquetas a un archivo. Use `-' para la salida estándar. Cada línea tendrá el formato NOMBRE=VALOR. Especifique --no-utf8-convert si es necesario.
--import-cuesheet-from=archivo
Importa una hoja de pistas (cuesheet) desde un archivo. Use `-' para la entrada estándar. Solo se puede especificar un archivo FLAC. Se añadirá un punto de búsqueda por cada punto de índice en la hoja de pistas a SEEKTABLE, a menos que se especifique --no-cued-seekpoints.
--export-cuesheet-to=archivo
Exporta el bloque CUESHEET a un archivo de hoja de pistas (cuesheet), adecuado para su uso por software de autoría de CD. Use `-' para la salida estándar. Solo se puede especificar un archivo FLAC en la línea de comandos.
--import-picture-from={NOMBREARCHIVO|ESPECIFICACIÓN}
Importa una imagen y la almacena en un bloque de metadatos PICTURE. Se pueden especificar varios comandos --import-picture-from. Se puede usar un nombre de archivo para el archivo de imagen o una forma de especificación más completa. La ESPECIFICACIÓN es una cadena cuyas partes están separadas por caracteres | (barra vertical). Algunas partes pueden dejarse vacías para invocar valores predeterminados. NOMBREARCHIVO es solo una abreviatura de “||||NOMBREARCHIVO”. Para obtener detalles sobre la especificación, consulte la sección Especificación de imagen en el manual de flac(1
) página del manual.
--export-picture-to=archivo
Exporta un bloque PICTURE a un archivo. Usa `-' para la salida estándar. Solo se puede especificar un archivo FLAC en la línea de comandos. Se exportará el primer bloque PICTURE a menos que --export-picture-to esté precedido por una opción --block-number=# para especificar el bloque de metadatos exacto a extraer. Tenga en cuenta que el número de bloque es el que se muestra con --list.
--add-replay-gain
Calcula las ganancias/picos de título y álbum de los archivos FLAC dados como si todos los archivos formaran parte de un álbum, y luego los almacena como etiquetas FLAC. Las etiquetas son las mismas que las utilizadas por vorbisgain. Las etiquetas ReplayGain existentes serán reemplazadas. Si solo se proporciona un archivo FLAC, las ganancias del álbum y del título serán las mismas. Dado que esta operación requiere dos pasadas, siempre se ejecuta al final, después de que todas las demás operaciones se hayan completado y escrito en disco. Todos los archivos FLAC especificados deben tener la misma resolución, frecuencia de muestreo y número de canales. Solo se permiten archivos mono y estéreo, y la frecuencia de muestreo debe ser 8, 11.025, 12, 16, 18.9, 22.05, 24, 28, 32, 36, 37.8, 44.1, 48, 56, 64, 72, 75.6, 88.2, 96, 112, 128, 144, 151.2, 176.4, 192, 224, 256, 288, 302.4, 352.8, 384, 448, 512, 576 o 604.8 kHz.
--scan-replay-gain
Similar a --add-replay-gain, pero solo analiza los archivos en lugar de escribirlos en las etiquetas.
--remove-replay-gain
Elimina las etiquetas ReplayGain.
--add-seekpoint={#|X|#x|#s}
Agrega puntos de búsqueda a un bloque SEEKTABLE. Usando #, se agrega un punto de búsqueda en ese número de muestra. Usando X, se agrega un punto de marcador de posición al final de la tabla. Usando #x, se agregarán # puntos de búsqueda espaciados uniformemente, siendo el primero en la muestra 0. Usando #s, se agregará un punto de búsqueda cada # segundos (# no tiene que ser un número entero; puede ser, por ejemplo, 9.5, lo que significa un punto de búsqueda cada 9.5 segundos). Si no existe un bloque SEEKTABLE, se creará uno. Si ya existe, se agregarán puntos a la tabla existente y los duplicados se convertirán en puntos de marcador de posición. Puede usar muchas opciones --add-seekpoint; el SEEKTABLE resultante será la unión de todos esos valores, eliminando duplicados. Ejemplo: --add-seekpoint=100x --add-seekpoint=3.5s agregará 100 puntos de búsqueda espaciados uniformemente y un punto de búsqueda cada 3.5 segundos.
--add-padding=longitud
Agrega un bloque de relleno de la longitud dada (en bytes). La longitud total del nuevo bloque será 4 + longitud; los 4 bytes adicionales son para la cabecera del bloque de metadatos.

OPERACIONES PRINCIPALES

--list
Lista el contenido de uno o más bloques de metadatos en la salida estándar. Por defecto, se listan todos los bloques de metadatos en formato de texto. Use las opciones --block-number, --block-type o --except-block-type para cambiar este comportamiento.
--remove
Elimina uno o más bloques de metadatos de los metadatos. Use las opciones --block-number, --block-type o --except-block-type para especificar qué bloques deben eliminarse. Tenga en cuenta que si se especifican tanto --block-number como --[except-]block-type, el resultado es la operación AND lógica de ambos argumentos. A menos que se especifique --dont-use-padding, los bloques serán reemplazados con relleno. No puede eliminar el bloque STREAMINFO.
--block-number=#[,#[...]]
Una lista opcional de números de bloque separados por comas para mostrar. El primer bloque, el bloque STREAMINFO, es el bloque 0.

--block-type=tipo[,tipo[...]]

--except-block-type=tipo[,tipo[...]]
Una lista opcional de tipos de bloque separados por comas que se incluirán o ignorarán con esta opción. Use solo una de las opciones --block-type o --except-block-type. Los tipos de bloque válidos son: STREAMINFO, PADDING, APPLICATION, SEEKTABLE, VORBIS_COMMENT, PICTURE. Puede reducir los tipos de bloques APPLICATION seleccionados añadiendo APPLICATION con dos puntos y el ID del bloque APPLICATION en formato ASCII o hexadecimal. Por ejemplo, APPLICATION:abcd para los bloques APPLICATION cuya representación textual del ID de 4 bytes es “abcd” o APPLICATION:0xXXXXXXXX para los bloques APPLICATION cuya representación hexadecimal big-endian del ID de 4 bytes es “0xXXXXXXXX”. Para el ejemplo “abcd” anterior, el equivalente hexadecimal es 0x61626364
--application-data-format=hexdump|text
Si el bloque de aplicación que está mostrando contiene datos binarios pero su --data-format=text, puede mostrar un volcado hexadecimal del contenido de los datos de la aplicación en su lugar usando --application-data-format=hexdump.
--data-format=binary|binary-headerless|text
Para usar con --list. Por defecto, se muestra una representación textual legible por humanos de los datos. Puede especificar --data-format=binary para volcar la forma binaria cruda de cada bloque de metadatos. Especifique --data-format=binary-headerless para omitir la salida de las cabeceras de los bloques de metadatos, incluido el id de los bloques de metadatos APPLICATION.
--append
Inserta un bloque de metadatos desde un archivo. Debe ser un bloque binario tal como se exportó con --list --data-format=binary. El punto de inserción se define con --block-number=#. El nuevo bloque se agregará después del número de bloque especificado. Esto evita la inserción ilegal de un bloque antes del primer bloque STREAMINFO. No puede --append otro bloque STREAMINFO. Es posible copiar un bloque de metadatos de un archivo a otro con esta opción. Por ejemplo, use metaflac --list --data-format=binary --block-number=6 archivo.flac > bloque para exportar el bloque, y luego impórtelo con metaflac --append otroarchivo.flac < bloque
--remove-all
Elimina todos los bloques de metadatos (excepto el bloque STREAMINFO) de los metadatos. A menos que se especifique --dont-use-padding, los bloques serán reemplazados con relleno.
--merge-padding
Fusiona bloques PADDING adyacentes en bloques únicos.
--sort-padding
Mueve todos los bloques PADDING al final de los metadatos y los fusiona en un solo bloque.
