menu_requestname(3x)

Paquete: ncurses

Licencias: MIT-open-group

menu_requestname(3X) Llamadas a bibliotecas menu_requestname(3X)

NOMBRE

menu_request_by_name, menu_request_name - manejar nombres de solicitud de menú imprimibles

SINOPSIS

#include <menu.h>
const char *menu_request_name(int request);
int menu_request_by_name(const char *name);

DESCRIPCIÓN

La función menu_request_name devuelve el nombre imprimible de un código de solicitud de menú.
La función menu_request_by_name busca en la tabla de nombres una solicitud con el nombre dado y devuelve su código de solicitud. De lo contrario, se devuelve E_NO_MATCH.

VALOR DE RETORNO

menu_request_name devuelve NULL en caso de error y establece errno en E_BAD_ARGUMENT.
menu_request_by_name devuelve E_NO_MATCH en caso de error. No establece errno.

PORTABILIDAD

Estas rutinas son específicas de ncurses. No eran compatibles con las implementaciones de la Versión 7, BSD o System V. Se recomienda que cualquier código que dependa de ellas se condicione usando NCURSES_VERSION.

AUTORES

Juergen Pfeifer. Páginas de manual y adaptación para curses nuevas por Eric S. Raymond.
