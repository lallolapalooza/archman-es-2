memcached_delete_by_key(3)

Paquete: libmemcached-awesome

Licencias: BSD

MEMCACHED_DELETE_BY_KEY(3) libmemcached-awesome MEMCACHED_DELETE_BY_KEY(3)

NOMBRE

memcached_delete_by_key - Documentación de libmemcached

SINOPSIS

#include <libmemcached/memcached.h>
Compilar y enlazar con -lmemcached
memcached_return_t memcached_delete(memcached_st *ptr, const char *key, size_t key_length, time_t expiration)
memcached_return_t memcached_delete_by_key(memcached_st *ptr, const char *group_key, size_t group_key_length, const char *key, size_t key_length, time_t expiration)
Parámetros
  • ptr -- puntero a la estructura memcached_st inicializada
  • group_key -- clave del espacio de nombres
  • group_key_length -- longitud de la group_key sin ningún cero terminador
  • key -- la clave a eliminar
  • key_length -- la longitud de la key sin ningún cero terminador
  • expiration -- obsoleto desde la versión 1.4 de memcached(1)
Devuelve
memcached_return_t indicando éxito

DESCRIPCIÓN

memcached_delete() se utiliza para eliminar una clave particular. memcached_delete_by_key() funciona de la misma manera, pero toma una clave maestra para encontrar el valor dado.

La expiración funciona colocando el elemento en una cola de eliminación, lo que significa que no será posible recuperarlo mediante el comando "get". Los comandos "add" y "replace" con esta clave también fallarán (sin embargo, el comando "set" tendrá éxito). Después de que pase el tiempo, el elemento se elimina finalmente de la memoria del servidor.

Tenga en cuenta que el servidor memcached eliminó las pruebas de expiración en la versión 1.4.

VALOR DEVUELTO

Se devuelve un valor de tipo memcached_return_t. En caso de éxito, este valor será MEMCACHED_SUCCESS. Utilice memcached_strerror() para traducir este valor a una cadena imprimible.

Si está utilizando el modo no bloqueante de la biblioteca, el éxito solo significa que el mensaje se puso en cola para su entrega.
