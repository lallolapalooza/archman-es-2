MECH-DUMP(1) Documentación de Perl contribuida por el usuario MECH-DUMP(1)

NOMBRE

mech-dump - Vuelca información sobre una página web

VERSIÓN

versión 2.20

SINOPSIS

mech-dump [opciones] [archivo|url]

Opciones:

--headers              Vuelca cabeceras de respuesta HTTP
--forms                Vuelca tabla de formularios (acción por defecto)
--links                Vuelca tabla de enlaces
--images               Vuelca tabla de imágenes
--all                  Vuelca las cuatro anteriores, en ese orden
--text                 Vuelca la parte textual de la página web
--user=usuario         Establece el nombre de usuario
--password=contraseña  Establece la contraseña
--cookie-file=nombrearchivo Establece el nombre de archivo a usar para cookies persistentes
--agent=agente         Especifica el UserAgent a pasar
--agent-alias=alias
                       Especifica el alias para el UserAgent a pasar.
                       Elige uno de:
                           * Windows IE 6
                           * Windows Mozilla
                           * Mac Safari
                           * Mac Mozilla
                           * Linux Mozilla
                           * Linux Konqueror
--absolute             Muestra URLs como absolutas, incluso si son relativas en la página
--help                 Muestra este mensaje

El orden de las opciones especificadas es relevante. Las opciones repetidas producen volcados repetidos.

"mech-dump" solo funcionará en documentos HTML cuando se use en URLs remotas, pero asumirá que cualquier archivo local que le pases es HTML. Si no lo es, no habrá resultados utilizables.

La configuración del proxy se especifica a través del entorno (por ejemplo, "http_proxy=http://proxy.my.place/"). Ver LWP::UserAgent para más detalles.
