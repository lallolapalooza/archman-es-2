DESCRIPCIÓN

libmemcached te permite especificar tus propios asignadores de memoria, optimizados para tu aplicación. Esto permite que libmemcached se use dentro de aplicaciones que tienen su propia implementación de malloc.

memcached_set_memory_allocators() se usa para establecer los asignadores de memoria utilizados por la instancia de memcached especificada por ptr. Ten en cuenta que no puedes anular solo uno de los asignadores de memoria, debes especificar un conjunto completo nuevo si deseas anular uno de ellos. Todas las funciones de asignación de memoria deben comportarse como se especifica en el estándar C99. Especifica NULL para todas las funciones para restablecerlas a los valores predeterminados.

memcached_get_memory_allocators() se usa para obtener los asignadores de memoria utilizados actualmente por un manejador de memcached.

memcached_get_memory_allocators_context() devuelve el void * que se pasó durante la llamada a memcached_set_memory_allocators().

El primer argumento para las funciones de asignación de memoria es un puntero a una estructura memcached, se pasa como const y deberás clonarlo para poder utilizar cualquier operación que lo modifique.

NOTAS

En la versión 0.38, todas las funciones se modificaron para tener un puntero void de contexto pasado a ellas. Esto fue para que los asignadores personalizados pudieran tener su propio espacio para memoria.

VALOR DE RETORNO

memcached_set_memory_allocators() devuelve MEMCACHED_SUCCESS si tiene éxito, y MEMCACHED_FAILURE si no pasas un conjunto completo de punteros de función.

NOMBRE

memcached_set_memory_allocators — establecer asignadores de memoria para libmemcached

SINOPSIS

#include <libmemcached/memcached.h>

memcached_return_t
memcached_set_memory_allocators(memcached_st *ptr,
                                memcached_malloc_fn malloc_fn,
                                memcached_free_fn free_fn,
                                memcached_realloc_fn realloc_fn,
                                memcached_calloc_fn calloc_fn);

DESCRIPCIÓN

Establece los asignadores de memoria a utilizar por la librería libmemcached. Esto puede ser útil para depurar fugas de memoria o para integrar libmemcached con un asignador de memoria personalizado, como por ejemplo, uno que esté optimizado para aplicaciones de alto rendimiento.

Se deben pasar punteros a funciones para cada una de las operaciones de asignación de memoria que se desean personalizar (malloc, free, realloc, calloc). Si alguno de estos punteros es NULL, se utilizarán los asignadores por defecto de la librería (generalmente los del sistema).

El parámetro ptr es un puntero a una estructura memcached_st, que representa una instancia de cliente memcached.

Las funciones de asignación de memoria personalizadas deben tener la siguiente firma:

typedef void *(*memcached_malloc_fn)(size_t size);
typedef void (*memcached_free_fn)(void *ptr);
typedef void *(*memcached_realloc_fn)(void *ptr, size_t size);
typedef void *(*memcached_calloc_fn)(size_t num, size_t size);

NOTAS

El uso de asignadores de memoria personalizados puede tener un impacto significativo en el rendimiento. Asegúrate de que tus asignadores sean eficientes y correctos antes de usarlos en un entorno de producción.

VALOR DE RETORNO

La función devuelve MEMCACHED_SUCCESS si los asignadores se establecieron correctamente, o un código de error apropiado en caso contrario.

VER TAMBIÉN
