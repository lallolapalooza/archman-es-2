Parámetros

Devoluciones
puntero a una estructura memcached_st inicializada

Parámetros
ptr -- puntero a una estructura memcached_st inicializada para destruir y posiblemente liberar
memcached_st *memcached_clone(memcached_st *destination, memcached_st *source)
Parámetros

Devoluciones
puntero a la nueva estructura destination inicializada, copiada de source
void memcached_servers_reset(memcached_st *ptr)
Parámetros
ptr -- puntero a una estructura memcached_st inicializada

DESCRIPCIÓN

memcached_create() se utiliza para crear una estructura memcached_st que luego será utilizada por otras funciones de libmemcached para comunicarse con el servidor. Debes pasar una memcached_st declarada estáticamente a memcached_create() o un valor NULL. Si se pasa un valor NULL, se asignará una estructura para ti.

Por favor, ten en cuenta que al escribir una nueva aplicación, utiliza memcached() en lugar de memcached_create().

memcached_clone() es similar a memcached_create(), pero copia los valores predeterminados y la lista de servidores del puntero fuente memcached_st. Si pasas NULL como argumento de origen para clonar, es lo mismo que una llamada a memcached_create(). Si el argumento de destino es NULL, se asignará una memcached_st para ti.

memcached_servers_reset() te permite poner a cero la lista de servidores que tiene la memcached_st.

Para limpiar la memoria asociada con una estructura memcached_st, debes pasarla a memcached_free() cuando hayas terminado de usarla. memcached_free() es la única forma de asegurar que toda la memoria sea desasignada cuando termines de usar la estructura.

Puede que desees evitar usar memcached_create() o memcached_clone() con una asignación basada en pila. Los problemas más comunes relacionados con la seguridad de la ABI implican estructuras asignadas en el heap.

VALOR DE RETORNO

memcached_create() devuelve un puntero a la memcached_st que fue creada (o inicializada). En caso de fallo de asignación, devuelve NULL.

memcached_clone() devuelve un puntero a la memcached_st que fue creada (o inicializada). En caso de fallo de asignación, devuelve NULL.
