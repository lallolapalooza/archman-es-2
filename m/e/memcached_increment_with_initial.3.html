Parámetros
  • ptr -- puntero a una estructura memcached_st inicializada
  • group_key -- espacio de nombres de la clave
  • group_key_length -- longitud del espacio de nombres de la clave sin ningún cero terminador
  • key -- la clave
  • key_length -- longitud de la clave sin ningún cero terminador
  • offset -- desplazamiento a incrementar/decrementar
  • initial -- valor inicial si la clave no existe y la expiration no es MEMCACHED_EXPIRATION_NOT_ADD
  • expiration -- expiración como una marca de tiempo de Unix o como tiempo de expiración relativo en segundos
  • value -- el valor resultante después de la inicialización/incremento/decremento
Devoluciones
memcached_return_t indicando éxito

DESCRIPCIÓN

memcached_increment() toma una clave y key_length e incrementa el valor por el offset que se le pasa. Luego, el valor se devuelve a través del puntero uint32_t value que le pasas.

memcached_decrement() toma una clave y key_length y decrementa el valor por el offset que se le pasa. Luego, el valor se devuelve a través del puntero uint32_t value que le pasas.

memcached_increment_with_initial() toma una clave y key_length e incrementa el valor por el offset que se le pasa. Si el objeto especificado por key no existe, puede ocurrir una de dos cosas: Si el valor de expiration es MEMCACHED_EXPIRATION_NOT_ADD, la operación fallará. Para todos los demás valores de expiration, la operación tendrá éxito al sembrar el valor para esa clave con un valor inicial que expirará con el tiempo de expiración proporcionado. Las flags se establecerán en cero. Luego, el valor se devuelve a través del puntero uint32_t value que le pasas. memcached_increment_with_initial solo está disponible cuando se usa el protocolo binario.

memcached_decrement_with_initial() toma una clave y key_length y decrementa el valor por el offset que se le pasa. Si el objeto especificado por key no existe, puede ocurrir una de dos cosas: Si el valor de expiration es MEMCACHED_EXPIRATION_NOT_ADD, la operación fallará. Para todos los demás valores de expiration, la operación tendrá éxito al sembrar el valor para esa clave con un valor inicial que expirará con el tiempo de expiración proporcionado. Las flags se establecerán en cero. Luego, el valor se devuelve a través del puntero uint32_t value que le pasas. memcached_decrement_with_initial() solo está disponible cuando se usa el protocolo binario.

memcached_increment_by_key(), memcached_decrement_by_key(), memcached_increment_with_initial_by_key() y memcached_decrement_with_initial_by_key() son equivalentes de clave maestra de las anteriores.

VALOR DE DEVOLUCIÓN

Se devuelve un valor de tipo memcached_return_t. En caso de éxito, ese valor será MEMCACHED_SUCCESS. Usa memcached_strerror() para traducir este valor a una cadena imprimible.

memcached_increment_with_initial(3)

memcached_increment_with_initial - Incrementa o decrementa un valor en el servidor memcached

Sintaxis

#include <libmemcached/memcached.h>

int memcached_increment_with_initial(memcached_st *ptr,
                                     const char *key, size_t key_length,
                                     uint64_t offset, uint64_t initial,
                                     uint64_t initial_ms, uint64_t *value);

Descripción

La función memcached_increment_with_initial intenta incrementar o decrementar el valor asociado con la clave dada. Si la clave no existe, se creará con el valor initial especificado.

El argumento offset especifica la cantidad en la que se debe incrementar o decrementar el valor. Si offset es positivo, se suma; si es negativo, se resta.

El argumento initial es el valor inicial que se establecerá si la clave no existe. El argumento initial_ms especifica la expiración inicial en milisegundos. Si initial_ms es 0, la expiración se establece en 0 (infinito).

Si la operación es exitosa, el valor resultante se almacena en la variable apuntada por value y la función devuelve MEMCACHED_SUCCESS. Si ocurre un error, se devuelve un código de error apropiado.

Parámetros

  • ptr: Un puntero a la estructura memcached_st.
  • key: La clave a la que se aplicará la operación.
  • key_length: La longitud de la clave.
  • offset: El valor a sumar o restar.
  • initial: El valor inicial si la clave no existe.
  • initial_ms: La expiración inicial en milisegundos.
  • value: Un puntero a una variable de tipo uint64_t donde se almacenará el valor resultante.

Valor de retorno

Devuelve MEMCACHED_SUCCESS en caso de éxito, o un código de error en caso de fallo.

Ejemplo

#include <libmemcached/memcached.h>
#include <stdio.h>

int main() {
    memcached_st *memc;
    uint64_t value;
    memcached_return_t rc;

    memc = memcached_create(NULL);
    memcached_server_add_text(memc, "localhost", 11211);

    // Incrementa la clave "counter" en 1. Si no existe, inicialízala a 5.
    // La expiración inicial es de 60 segundos.
    rc = memcached_increment_with_initial(memc, "counter", strlen("counter"), 1, 5, 60000, &value);

    if (rc == MEMCACHED_SUCCESS) {
        printf("Valor actual de 'counter': %llu\n", (unsigned long long)value);
    } else {
        fprintf(stderr, "Error al incrementar 'counter': %s\n", memcached_strerror(memc, rc));
    }

    memcached_free(memc);
    return 0;
}
