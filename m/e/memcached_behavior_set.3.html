NOMBRE

memcached_behavior_set - Documentación de libmemcached

Manipula el comportamiento de una estructura memcached_st.

SINOPSIS

#include <libmemcached/memcached.h>
Compilar y enlazar con -lmemcached
uint64_t memcached_behavior_get(memcached_st *ptr, memcached_behavior_t flag)
Parámetros
  • ptr -- puntero a una estructura memcached_st inicializada
  • flag -- memcached_behavior_t a consultar
Devuelve
el valor establecido para flag
memcached_return_t memcached_behavior_set(memcached_st *ptr, memcached_behavior_t flag, uint64_t data)
Parámetros
  • ptr -- puntero a una estructura memcached_st inicializada
  • flag -- memcached_behavior_t a establecer
  • data -- el valor a establecer para flag
Devuelve
memcached_return_t indicando éxito

Cambiado en la versión 0.17: El argumento data de memcached_behavior_set() se cambió de tomar un puntero al valor de los datos, a tomar un uin64_t.

typedef enum memcached_behavior_t memcached_behavior_t
enum memcached_behavior_t
enumerador MEMCACHED_BEHAVIOR_USE_UDP
Hace que libmemcached use el transporte UDP al comunicarse con un servidor memcached. No todas las operaciones de E/S se prueban cuando se habilita este comportamiento.

Las siguientes operaciones devolverán MEMCACHED_NOT_SUPPORTED cuando se ejecuten con MEMCACHED_BEHAVIOR_USE_UDP habilitado:

  • memcached_version(),
  • memcached_stat(),
  • memcached_get(),
  • memcached_get_by_key(),
  • memcached_mget(),
  • memcached_mget_by_key(),
  • memcached_fetch(),
  • memcached_fetch_result(),
  • memcached_fetch_execute().

Todas las demás operaciones se prueban pero se ejecutan en modo de "enviar y olvidar", en el cual una vez que el cliente ha ejecutado la operación, no se hará ningún intento para asegurar que la operación ha sido recibida y actuada por el servidor.

libmemcached no permite compartir servidores TCP y UDP dentro de la misma 'instancia' del cliente libmemcached. Un intento de agregar un servidor TCP cuando este comportamiento está habilitado resultará en un MEMCACHED_INVALID_HOST_PROTOCOL, al igual que intentar agregar un servidor UDP cuando este comportamiento no ha sido habilitado.

enumerador MEMCACHED_BEHAVIOR_NO_BLOCK
Esto habilita solo SO_LINGER, por lo que la llamada close(2) al socket devuelve inmediatamente. Las E/S siempre se manejan de forma asíncrona en versiones recientes de libmemcached.
enumerador MEMCACHED_BEHAVIOR_SND_TIMEOUT
Esto establece el comportamiento en microsegundos del socket contra el flag SO_SNDTIMEO.
enumerador MEMCACHED_BEHAVIOR_RCV_TIMEOUT
Esto establece el comportamiento en microsegundos del socket contra el flag SO_RCVTIMEO.
enumerador MEMCACHED_BEHAVIOR_TCP_NODELAY
Deshabilita el algoritmo de Nagle. Ver RFC 896.
enumerador MEMCACHED_BEHAVIOR_HASH
Establece el algoritmo de hash utilizado para las claves.

Cada hash tiene sus ventajas y sus debilidades. Si no lo sabes o no te importa, quédate con el predeterminado.

enumerador MEMCACHED_BEHAVIOR_DISTRIBUTION
Al establecer un memcached_server_distribution_t puedes habilitar diferentes medios para distribuir valores a los servidores.

El método predeterminado es MEMCACHED_DISTRIBUTION_MODULA (hash de la clave módulo número de servidores).

Puedes habilitar el hashing consistente estableciendo MEMCACHED_DISTRIBUTION_CONSISTENT. El hashing consistente ofrece una mejor distribución y permite agregar servidores al clúster con pérdidas mínimas de caché.

Actualmente MEMCACHED_DISTRIBUTION_CONSISTENT es un alias para el valor MEMCACHED_DISTRIBUTION_CONSISTENT_KETAMA.

enumerador MEMCACHED_BEHAVIOR_CACHE_LOOKUPS
Deprecated desde la versión 0.46(?): Las búsquedas DNS ahora siempre se almacenan en caché hasta que ocurre un error con el servidor.

Memcached puede almacenar en caché búsquedas con nombre para que las búsquedas DNS solo se realicen una vez.

enumerador MEMCACHED_BEHAVIOR_SUPPORT_CAS
Soporta operaciones CAS (esto no está habilitado por defecto en este punto del servidor ya que impone una ligera penalización de rendimiento).
enumerador MEMCACHED_BEHAVIOR_KETAMA
Establece la distribución predeterminada a MEMCACHED_DISTRIBUTION_CONSISTENT_KETAMA y el hash a MEMCACHED_HASH_MD5.
enumerador MEMCACHED_BEHAVIOR_KETAMA_WEIGHTED
Establece la distribución predeterminada a MEMCACHED_DISTRIBUTION_CONSISTENT_KETAMA con las pruebas ponderadas. Hace que el algoritmo de hashing predeterminado para las claves utilice MEMCACHED_HASH_MD5.
enumerador MEMCACHED_BEHAVIOR_KETAMA_HASH
Establece el algoritmo de hashing para el mapeo de hosts en el continuo.
enumerador MEMCACHED_BEHAVIOR_KETAMA_COMPAT
Establece el modo de compatibilidad. El valor puede establecerse en MEMCACHED_KETAMA_COMPAT_LIBMEMCACHED (este es el valor predeterminado) o MEMCACHED_KETAMA_COMPAT_SPY para ser compatible con el cliente Java SPY Memcached.
enumerador MEMCACHED_BEHAVIOR_POLL_TIMEOUT
Modifica el valor de tiempo de espera en milisegundos que utiliza poll. El valor predeterminado es -1. Se debe pasar un entero con signo a memcached_behavior_set() para cambiar este valor (esto requiere casting). Para memcached_behavior_get(), un valor de 'entero con signo' se convertirá y se devolverá como 'unsigned long long'.

Obsoleto desde la versión <: 0.30
enumerator MEMCACHED_BEHAVIOR_BUFFER_REQUESTS
Habilitar E/S con búfer hace que los comandos se "almacenen en búfer" en lugar de enviarse. Cualquier acción que obtenga datos hará que este búfer se envíe a la conexión remota. Salir de la conexión o cerrarla también hará que los datos almacenados en búfer se envíen a la conexión remota.
enumerator MEMCACHED_BEHAVIOR_VERIFY_KEY
Habilitar esto hará que libmemcached pruebe todas las claves para verificar que son claves válidas.
enumerator MEMCACHED_BEHAVIOR_SORT_HOSTS
Habilitar esto hará que los hosts que se agregan se coloquen en la lista de hosts en orden ordenado. Esto anulará el hash consistente.
enumerator MEMCACHED_BEHAVIOR_CONNECT_TIMEOUT
Establece el tiempo de espera durante la conexión del socket en milisegundos. Especificar -1 significa un tiempo de espera infinito.
enumerator MEMCACHED_BEHAVIOR_BINARY_PROTOCOL
Habilita el uso del protocolo binario. Tenga en cuenta que no puede alternar esta bandera en una conexión abierta.
enumerator MEMCACHED_BEHAVIOR_IO_MSG_WATERMARK
Establece este valor para ajustar el número de mensajes que pueden enviarse antes de que libmemcached comience a drenar automáticamente la cola de entrada.

Establecer este valor en alto puede hacer que libmemcached se bloquee (intentando enviar datos, pero el envío se bloqueará porque el búfer de entrada en el kernel está lleno).

enumerator MEMCACHED_BEHAVIOR_IO_BYTES_WATERMARK
Establece este valor para ajustar el número de bytes que pueden enviarse antes de que libmemcached comience a drenar automáticamente la cola de entrada (se necesitan al menos 10 solicitudes de E/S enviadas sin leer el búfer de entrada).

Establecer este valor en alto puede hacer que libmemcached se bloquee (intentando enviar datos, pero el envío se bloqueará porque el búfer de entrada en el kernel está lleno).

enumerator MEMCACHED_BEHAVIOR_IO_KEY_PREFETCH
El protocolo binario funciona un poco diferente al protocolo textual en el sentido de que un multiget se implementa como una tubería de operaciones get únicas que se envían al servidor en un bloque.

Si está utilizando multigets grandes desde su aplicación, puede mejorar la latencia de los gets estableciendo este valor para enviar el primer bloque de solicitudes cuando alcance el límite especificado. Permite a los servidores comenzar a procesar las solicitudes para enviar los datos de vuelta mientras se crean y envían el resto de las solicitudes al servidor.

enumerator MEMCACHED_BEHAVIOR_NOREPLY
Establece este valor para especificar que realmente no te importa el resultado de tus comandos de almacenamiento (set, add, replace, append, prepend).
enumerator MEMCACHED_BEHAVIOR_NUMBER_OF_REPLICAS
Especifica el número de réplicas que libmemcached debería almacenar de cada elemento (en diferentes servidores).

Esta replicación no dedica servidores memcached específicos para almacenar las réplicas, sino que las almacenará junto con todos los demás objetos (en los 'n' servidores siguientes especificados en tu lista de servidores).

Requiere el protocolo binario y solo admite (M)GET/SET/DELETE.

NOTA: libmemcached no garantiza ni impone ninguna consistencia.

enumerator MEMCACHED_BEHAVIOR_RANDOMIZE_REPLICA_READ
Permite aleatorizar el punto de partida de las lecturas de réplica. Normalmente, la lectura se realiza desde el servidor principal y, en caso de fallo, la lectura se realiza desde el principal + 1, luego el principal + 2 hasta 'n' réplicas.

Esto permite distribuir la carga de lectura a varios servidores con el coste de más tráfico de escritura.

NOTA: Solo los errores de comunicación con un servidor se consideran fallos, por lo que MEMCACHED_NOTFOUND no cuenta como fallo.

enumerator MEMCACHED_BEHAVIOR_CORK
Obsoleto desde la versión ?: Esta opción ha sido obsoleta y el comportamiento ahora está integrado y se utiliza de forma adecuada en plataformas seleccionadas.
enumerator MEMCACHED_BEHAVIOR_KEEPALIVE
Habilita el comportamiento TCP_KEEPALIVE.
enumerator MEMCACHED_BEHAVIOR_KEEPALIVE_IDLE
Especifica el tiempo, en segundos, para marcar una conexión como inactiva. Esto solo está disponible como opción en Linux.
enumerator MEMCACHED_BEHAVIOR_SOCKET_SEND_SIZE
Encuentra el tamaño actual de SO_SNDBUF. Un valor de 0 significa que ocurrió un error o que no había hosts disponibles. Es seguro asumir el valor predeterminado del sistema si esto ocurre.

Si ocurre un error, puedes consultar el último errno almacenado en caché para encontrar el error específico.

enumerator MEMCACHED_BEHAVIOR_SOCKET_RECV_SIZE
Encuentra el tamaño actual de SO_RCVBUF. Un valor de 0 significa que ocurrió un error o que no había hosts disponibles. Es seguro asumir el valor predeterminado del sistema si esto ocurre.

Si ocurre un error, puedes consultar el último errno almacenado en caché para encontrar el error específico.

enumerator MEMCACHED_BEHAVIOR_SERVER_FAILURE_LIMIT
Obsoleto desde la versión 0.48: Consulte MEMCACHED_BEHAVIOR_REMOVE_FAILED_SERVERS

Establece este valor para habilitar que el servidor sea eliminado después de un número continuo de fallos de conexión MEMCACHED_BEHAVIOR_SERVER_FAILURE_LIMIT.

enumerator MEMCACHED_BEHAVIOR_AUTO_EJECT_HOSTS
Obsoleto desde la versión 0.48: Consulte MEMCACHED_BEHAVIOR_REMOVE_FAILED_SERVERS

Si está habilitado, los hosts que se hayan marcado como deshabilitados se eliminarán de la lista de servidores en la estructura memcached_st. Esto debe usarse en combinación con MEMCACHED_BEHAVIOR_SERVER_FAILURE_LIMIT.

enumerator MEMCACHED_BEHAVIOR_REMOVE_FAILED_SERVERS
Si está habilitado, los hosts que se hayan marcado como deshabilitados se eliminarán de la lista de servidores en la estructura memcached_st.
enumerator MEMCACHED_BEHAVIOR_RETRY_TIMEOUT
Cuando está habilitado, un host problemático solo se verificará para su uso según la cantidad de tiempo establecida por este comportamiento. El valor está en segundos.
enumerator MEMCACHED_BEHAVIOR_HASH_WITH_PREFIX_KEY
Cuando está habilitado, la clave de prefijo se agregará a la clave al determinar el servidor mediante hash. Consulte MEMCACHED_CALLBACK_NAMESPACE para obtener información adicional.

DESCRIPCIÓN

El comportamiento de libmemcached puede ser modificado utilizando memcached_behavior_set(). El comportamiento predeterminado es que la biblioteca se esfuerza por ser rápida y precisa. Algunos comportamientos, si bien son más rápidos, también pueden dar lugar a un comportamiento no del todo preciso (por ejemplo, memcached_set() siempre responderá con MEMCACHED_SUCCESS).

memcached_behavior_get() toma un indicador de comportamiento y devuelve si dicho comportamiento está actualmente activado o no en el cliente.

memcached_behavior_set() cambia el valor de una opción particular del cliente. Toma tanto un indicador como un valor. Para opciones simples de encendido/apagado, solo necesita pasar un valor de 1. Las llamadas a memcached_behavior_set() vaciarán y restablecerán todas las conexiones.

VALOR DE RETORNO

memcached_behavior_get() devuelve el valor actual de la clave, o 0 o 1 en comportamientos de indicadores simples (siendo 1 activado). memcached_behavior_set() devuelve fallo o éxito.

NOTAS

El argumento data de memcached_behavior_set() se cambió en la versión 0.17 de tomar un puntero al valor de los datos, a tomar un uin64_t.
