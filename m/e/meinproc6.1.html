MEINPROC6(1) Manual de Usuario de meinproc6 MEINPROC6(1)

NOMBRE

meinproc6 - traductor de KDE para XML

SINOPSIS

meinproc6 [-h, --help] [-v, --version] [--cache archivo] [--check] [--srcdir directorio] [--param clave=valor] [[[-o] | [--output]] archivo] [--stdout] [--stylesheet xsl] docbook_file

DESCRIPCIÓN

meinproc6 convierte archivos DocBook a HTML.

OPCIONES GENÉRICAS

-h--help

Muestra la ayuda sobre las opciones.

-v--version

Muestra información de la versión.

OPCIONES DE APLICACIÓN

--cache archivo

Crea un archivo de caché para el documento.

--check

Comprueba la validez del documento. 
La salida puede ser un poco desalentadora, ya que un pequeño error puede causar una cascada de errores. 
El truco es mirar el primer error, corregir ese error, guardar el archivo y ejecutar meinproc6 de nuevo.

-o, --output archivo

Genera todo el documento en el archivo.

--stdout

Genera todo el documento en la salida estándar.

--stylesheet xsl

Hoja de estilos a utilizar.

--srcdir directorio

Establece el directorio raíz para buscar `kdoctools`.

--param clave=valor

Establece parámetros para pasar a la hoja de estilos.

USO

La forma más común de ejecutar meinproc6 es simplemente como

meinproc6 archivo-docbook

donde archivo-docbook suele ser `index.docbook`. Este comando crea páginas HTML a partir del archivo DocBook. Ten en cuenta que estas páginas solo se pueden ver en navegadores basados en KDE (como Konqueror).

Si necesitas ver la salida HTML en otro navegador (por ejemplo, si la estás publicando en línea), usa

meinproc6 --stylesheet nombre-hoja-estilos archivo-docbook

donde nombre-hoja-estilos es la ruta completa a una de las hojas de estilo XSL en <kdoctools_installation_prefix>/share/kf5/kdoctools/customization/. Para producir una salida adecuada para la web, puedes usar `kde-web.xsl` o `kde-chunk-online.xsl`. Consulta el archivo README en ese directorio para más detalles.
