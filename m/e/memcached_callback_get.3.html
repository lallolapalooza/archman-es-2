enum memcached_callback_t
enumerador MEMCACHED_CALLBACK_CLEANUP_FUNCTION
Cuando se llama a memcached_free() o memcached_reset, se ejecutará esta función. En el momento de su ejecución, todas las conexiones están cerradas.

Su firma es:

typedef memcached_return_t (*memcached_cleanup_fn)(const memcached_st *ptr)
enumerador MEMCACHED_CALLBACK_CLONE_FUNCTION
Cuando se llama a memcached_clone(), se ejecutará esta función.

Su firma es:

typedef memcached_return_t (*memcached_clone_fn)(memcached_st *destination, const memcached_st *source)
enumerador MEMCACHED_CALLBACK_PREFIX_KEY
Ver MEMCACHED_CALLBACK_NAMESPACE.
enumerador MEMCACHED_CALLBACK_NAMESPACE
Puede establecer un valor que se utilizará para crear un dominio para sus claves. El valor especificado aquí se antepondrá a cada una de sus claves. El valor no puede ser mayor que MEMCACHED_MAX_NAMESPACE - 1 y reducirá MEMCACHED_MAX_KEY en el valor de su clave.

La clave de prefijo solo se aplica a la clave principal, no a la clave maestra. Se devolverá MEMCACHED_FAILURE si no se establece ninguna clave. En el caso de una clave demasiado larga, se devolverá MEMCACHED_BAD_KEY_PROVIDED.

Si establece un valor con el valor siendo NULL, el prefijo de clave se desactiva.

enumerador MEMCACHED_CALLBACK_USER_DATA
Esto le permite almacenar un puntero a una pieza específica de datos. Esto se puede recuperar desde dentro de memcached_fetch_execute(). Clonar un memcached_st copiará el puntero al clon.
enumerador MEMCACHED_CALLBACK_MALLOC_FUNCTION
Obsoleto desde la versión <0.32: Use memcached_set_memory_allocators() en su lugar.
enumerador MEMCACHED_CALLBACK_REALLOC_FUNCTION
Obsoleto desde la versión <0.32: Use memcached_set_memory_allocators() en su lugar.
enumerador MEMCACHED_CALLBACK_FREE_FUNCTION
Obsoleto desde la versión <0.32: Use memcached_set_memory_allocators() en su lugar.
enumerador MEMCACHED_CALLBACK_GET_FAILURE
Esta función implementa el comportamiento de caché de lectura (read-through). En caso de fallo en la recuperación, se llamará a esta devolución de llamada.

Usted es responsable de poblar el objeto de resultado proporcionado. Este objeto de resultado se almacenará luego en el servidor y se devolverá al proceso que llama.

Debe clonar el memcached_st para poder utilizarlo. El valor solo se almacenará si devuelve MEMCACHED_SUCCESS o MEMCACHED_BUFFERED. Devolver MEMCACHED_BUFFERED hará que el objeto se ponga en búfer y no se envíe inmediatamente (si este es el comportamiento predeterminado según la configuración de su conexión, esto ocurrirá automáticamente).

El prototipo para esto es:

typedef memcached_return_t (*memcached_trigger_key)(memcached_st *ptr, char *key, size_t key_length, memcached_result_st *result)
enumerador MEMCACHED_CALLBACK_DELETE_TRIGGER
Esta función implementa un disparador tras la eliminación exitosa de una clave. La estructura memcached_st deberá clonarse para poder utilizarla.

El prototipo para esto es:

typedef memcached_return_t (*memcached_trigger_delete_key)(memcached_st *ptr, char *key, size_t key_length)

DESCRIPCIÓN

libmemcached puede tener devoluciones de llamada establecidas en puntos de ejecución de claves. Estas proporcionan llamadas a funciones en puntos del código o devuelven punteros a estructuras para usos particulares.

memcached_callback_get() toma un indicador de devolución de llamada y devuelve la estructura o función establecida por memcached_callback_set().

memcached_callback_set() cambia la función/estructura asignada por un indicador de devolución de llamada. No se reinician las conexiones.

Puede usar MEMCACHED_CALLBACK_USER_DATA para proporcionar contexto personalizado si es necesario para cualquiera de las devoluciones de llamada.

VALOR DE RETORNO

memcached_callback_get() devuelve la función o estructura que se proporcionó. En caso de error, no se establece nada, se devuelve NULL y el argumento memcached_return_t se establece en MEMCACHED_FAILURE.

memcached_callback_set() devuelve MEMCACHED_SUCCESS si se establece correctamente, de lo contrario, devuelve MEMCACHED_FAILURE en caso de error.
