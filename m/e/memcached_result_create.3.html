DESCRIPCIÓN

La estructura de memcached_result_st ha sido encapsulada, no debe escribir código que acceda directamente a los miembros de la estructura.

memcached_result_create() asignará memoria para una memcached_result_st o inicializará una estructura que se le pase.

memcached_result_free() liberará cualquier memoria adjunta a la estructura. Si la estructura también fue asignada, la liberará.

DESCRIPCIÓN

Estas funciones se utilizan para obtener el valor de clave y valor asociado con un objeto de resultado de memcached.

memcached_result_key_value() devuelve el valor de clave asociado con el objeto de resultado actual.

memcached_result_key_length() devuelve la longitud de clave asociada con el objeto de resultado actual.

memcached_result_value() devuelve el valor de resultado asociado con el objeto de resultado actual.

memcached_result_length() devuelve la longitud del resultado asociada con el objeto de resultado actual.

memcached_result_flags() devuelve las banderas asociadas con el objeto de resultado actual.

memcached_result_cas() devuelve el cas asociado con el objeto de resultado actual. Este valor solo estará disponible si el servidor lo prueba.

memcached_result_set_value() toma una matriz de bytes y un tamaño y establece el resultado a este valor. Esta función se utiliza para activar respuestas.

memcached_result_set_flags() toma una estructura de resultado y almacena un nuevo valor para el campo flags.

memcached_result_set_expiration() toma una estructura de resultado y almacena un nuevo valor para el campo expiration (esto solo es utilizado por los triggers de lectura).

VALOR DE RETORNO

Varía, ver funciones específicas. Todas las estructuras deben tener memcached_result_free() llamado en ellas con fines de limpieza. No hacerlo dará como resultado fugas de memoria.
