MENYOKI.CONF(5) manual de menyoki MENYOKI.CONF(5)

NOMBRE

menyoki.conf - archivo de configuración de menyoki

SINOPSIS

$MENYOKI_CONFIG, $HOME/.config/menyoki.conf, $HOME/.config/menyoki/menyoki.conf, $HOME/.config/menyoki/config

DESCRIPCIÓN

Es posible anular los argumentos de línea de comandos predeterminados con un archivo de configuración. Se puede especificar a través de la opción --config o la variable de entorno $MENYOKI_CONFIG. Además, se puede colocar en una ubicación donde menyoki la busque por defecto.

GENERAL

Opciones que pertenecen a la sección [general].

verbose
Aumenta la verbosidad del registro
quiet
No muestres la salida
color <HEX>
Establece el color principal [por defecto: 3AA431]

NAME

menyoki.conf - menyoki configuration file

DESCRIPTION

The menyoki(1) command reads configuration from a file named menyoki.conf. This file is searched for in the following locations, in order:

  • $XDG_CONFIG_HOME/menyoki/menyoki.conf
  • $HOME/.config/menyoki/menyoki.conf
  • /etc/menyoki/menyoki.conf

If no configuration file is found, menyoki(1) uses its default settings.

The configuration file uses a simple key-value syntax. Each line represents a setting, with the key and value separated by an equals sign (=). Comments can be added using the hash symbol (#) at the beginning of a line or after a value.

The following settings are recognized:

theme

Specifies the color theme to use. Supported themes are "default", "dark", and "light".

Example: theme = "dark"

font

Sets the font family and size. The value should be a string in the format "font-family size".

Example: font = "Monospace 12"

line_numbers

Toggles the display of line numbers. Accepts "true" or "false".

Example: line_numbers = "true"

tab_size

Defines the number of spaces a tab character represents. This should be a positive integer.

Example: tab_size = 4

auto_indent

Enables or disables automatic indentation. Accepts "true" or "false".

Example: auto_indent = "true"

EXAMPLES

A minimal menyoki.conf file might look like this:

# Use the dark theme and enable line numbers
theme = "dark"
line_numbers = "true"
font = "Consolas 11"
