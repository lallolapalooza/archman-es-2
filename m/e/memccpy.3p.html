MEMCCPY(3P) Manual del Programador de POSIX MEMCCPY(3P)

PROLOG

Esta página del manual forma parte del Manual del Programador de POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual de Linux correspondiente para conocer los detalles del comportamiento en Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

memccpy — copia bytes en memoria

SINOPSIS

#include <string.h>
void *memccpy(void *restrict s1, const void *restrict s2,
    int c, size_t n);

DESCRIPCIÓN

La función memccpy() copiará bytes del área de memoria s2 a s1, deteniéndose después de que se copie la primera ocurrencia del byte c (convertido a unsigned char), o después de que se copien n bytes, lo que ocurra primero. Si la copia tiene lugar entre objetos que se solapan, el comportamiento no está definido.

VALOR DE RETORNO

La función memccpy() devolverá un puntero al byte que sigue a la copia de c en s1, o un puntero nulo si c no se encontró en los primeros n bytes de s2.

ERRORES

No se definen errores.

USO DE APLICACIÓN

La función memccpy() no comprueba el desbordamiento del área de memoria receptora.
