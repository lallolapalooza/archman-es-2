memoize-extract(1) Manual de usuario memoize-extract(1)

NOMBRE

memoize-extract.pl, memoize-extract.py - Extraer páginas externas del PDF

SINOPSIS

memoize-extract.pl [OPCIONES] documento.mmz

memoize-extract.py [OPCIONES] documento.mmz

DESCRIPCIÓN

memoize-extract es un script que acompaña a Memoize, un paquete de TeX que permite al autor reutilizar los resultados de código computacionalmente intensivo, como las figuras TikZ.

Memoize vuelca las externas creadas (cajas que contienen el material tipográfico a reutilizar) en sus propias páginas en el archivo PDF producido. Es tarea de memoize-extract extraer estas páginas externas a archivos PDF separados. En compilaciones subsiguientes, Memoize incluirá esos archivos externos en el documento, sin volver a compilar su fuente.

Memoize se comunica con memoize-extract a través del archivo documento.mmz. Cuando se compila documento.tex para producir documento.pdf, Memoize produce documento.mmz, que registra qué páginas en el documento producido son páginas externas y a qué archivos externos deben extraerse. Por lo tanto, después de compilar documento.tex, las externas deben ser extraídas por memoize-extract documento.mmz.

documento.mmz también puede darse como document* o documento.tex. Cuando la variable de entorno TEXMF_OUTPUT_DIRECTORY está configurada, este nombre de archivo es relativo al directorio de salida especificado por esta variable.

documento.mmz también registra el ancho y alto esperados de cada externa. En caso de discrepancia, memoize-extract se niega a extraer la página y elimina el archivo externo si ya existe, e imprime un mensaje de advertencia en la salida estándar de error. El script también se niega a extraer la página si no existe una (c)c-memo asociada a la externa. Ver también la sección SEGURIDAD.

La versión en Perl (.pl) y la versión en Python (.py) del script son funcionalmente equivalentes. El script de Perl requiere la biblioteca PDF::API2, y el script de Python requiere la biblioteca pdfrw2.

OPCIONES

-P, --pdf nombre_archivo.pdf
Las externas se extraerán de nombre_archivo.pdf. Por defecto, se extraen de documento.pdf.
-p, --prune
Eliminar las páginas externas del PDF después de la extracción.
-k, --keep
No modificar documento.mmz para marcar las externas como extraídas. Por defecto, se comentan para evitar la doble extracción.
-F, --format latex|plain|context
Cuando se proporciona esta opción, el script asume que fue llamado desde dentro de una compilación TeX de un documento en el formato dado: antepone toda la salida con el nombre del script y crea un archivo de registro documento.mmz.log, que recibe cualquier advertencia y error relacionado con la extracción.
-f, --force
Extraer la externa incluso si la verificación de tamaño falla.
-q, --quiet
No describir lo que está sucediendo.
-m, --mkdir
Un mkdir -p paranoico. (No ocurre ninguna extracción, documento.mmz se interpreta como un nombre de directorio, que puede terminar en cualquier sufijo; no se realiza ninguna manipulación de sufijo.)
-V, --version
Mostrar el número de versión de Memoize y salir.
-h, --help
Mostrar ayuda y salir.

SEGURIDAD

Este script respeta las restricciones de entrada y salida de archivos impuestas por la configuración de TeX, más precisamente, las variables openin_any y openout_any de la biblioteca kpathsea (https://tug.org/kpathsea). Puedes inspeccionar los valores de estas variables ejecutando kpsewhich -var-value=openin_any y kpsewhich -var-value=openout_any. La interpretación es la siguiente:

a (o y o 1) cualquiera
Permite abrir cualquier archivo.
r (o n o 0) restringido
Significa no permitir nombres de archivo especiales.
p (o cualquier otro valor) paranoico
Significa ser realmente paranoico: no permitir nombres de archivo especiales y restringir los archivos de entrada/salida a estar dentro o debajo del directorio de trabajo o del directorio especificado por TEXMFOUTPUT o TEXMF_OUTPUT_DIRECTORY. TEXMFOUTPUT puede configurarse en texmf.cnf (por ejemplo, por tlmgr) o como una variable de entorno. TEXMF_OUTPUT_DIRECTORY solo puede configurarse como variable de entorno; es configurada automáticamente por TeX cuando se llama mediante la opción -output-directory (a partir de TeXLive 2024).

ESTADO DE SALIDA

0
Las externas se extrajeron correctamente. Este código de salida se devuelve incluso si no hay externas que extraer, o si documento.mmz no existe.
10
Una advertencia reportada de vuelta a la compilación cuando se proporciona la opción --format. Actualmente, cualquiera de: (i) discrepancia de tamaño; (ii) un archivo (c)c-memo asociado inexistente; o (iii) kpsewhich no disponible.
11
Un error reportado de vuelta a la compilación cuando se proporciona la opción --format. Actualmente, cualquiera de: (i) un PDF de documento corrupto, o (ii) un error de permiso de kpathsea.

Otros códigos de salida son los producidos por el lenguaje de script subyacente (Perl o Python).
