TEESTATUS

This enum defines the return values for the TEE API.

TEESTATUS_SUCCESS
Operation successful.
TEESTATUS_ERROR_GENERIC
A generic error occurred.
TEESTATUS_ERROR_INVALID_HANDLE
The provided handle is invalid.
TEESTATUS_ERROR_COMMUNICATION
An error occurred during communication with the TEE.
TEESTATUS_ERROR_TIMEOUT
The operation timed out.
TEESTATUS_ERROR_NOT_INITIALIZED
The TEE is not initialized.
TEESTATUS_ERROR_BUFFER_TOO_SMALL
The provided buffer is too small.
TEESTATUS_ERROR_INVALID_PARAMETER
An invalid parameter was provided.
TEESTATUS_ERROR_UNEXPECTED_RESPONSE
An unexpected response was received from the TEE.
