memdump(1)

Paquete: libmemcached-awesome

Licencias: BSD

MEMDUMP(1) libmemcached-awesome MEMDUMP(1)

NOMBRE

memdump - Documentación de libmemcached

SINOPSIS

memdump [opciones]

Volcar una lista de claves de un servidor.

DESCRIPCIÓN

memdump vuelca una lista de "claves" de todos los servidores de los que se le indica que obtenga información. Dado que memcached no garantiza la provisión de todas las claves, no es posible obtener una "volcada" completa.

OPCIONES

-h|--help
Mostrar ayuda.
-V|--version
Mostrar versión.
-q|--quiet
Operar en silencio.
-v|--verbose
Operar de forma más detallada.
-d|--debug
Ver -v|--verbose.
-s|--servers <lista de servidores>
Especificar la lista de servidores como nombrehost[:puerto][,nombrehost[:puerto]...].
-n|--non-blocking
Habilitar operaciones no bloqueantes.
-N|--tcp-nodelay
Deshabilitar el algoritmo de Nagle.
-b|--binary
Habilitar protocolo binario.
-B|--buffer
Búfer de solicitudes.
-u|--username <nombre de usuario>
Usar nombre de usuario para autenticación SASL.
-p|--password <contraseña>
Usar contraseña para autenticación SASL.
-f|--file [<archivo>]
Salida a archivo en lugar de salida estándar.

NOTA: por defecto es <clave> si no se proporcionó ningún argumento.

AMBIENTE

MEMCACHED_SERVERS
Especificar una lista de servidores.

NOTAS

PREFIJO DEL PROGRAMA

El prefijo de este programa es variable, es decir, puede configurarse en tiempo de compilación.

Normalmente, los programas cliente de libmemcached-awesome llevan el prefijo mem, como memcat o memcp.

Sin embargo, puede configurarse para reemplazar el prefijo por otra cosa como mc, en cuyo caso, los programas cliente de libmemcached-awesome se llamarían mccat, mccp, etc., respectivamente.
