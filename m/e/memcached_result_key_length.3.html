DESCRIPCIÓN

La estructura de memcached_result_st ha sido encapsulada, no debes escribir código que acceda directamente a los miembros de la estructura.

memcached_result_create() asignará memoria para una memcached_result_st o inicializará una estructura que se le pase.

memcached_result_free() desasignará cualquier memoria adjunta a la estructura. Si la estructura también fue asignada, la desasignará.

memcached_result_key_value() devolverá el valor de la clave para el resultado dado.

memcached_result_key_length() devolverá la longitud de la clave para el resultado dado.

memcached_result_value() devolverá el valor de datos para el resultado dado.

memcached_result_take_value() devolverá el valor de datos para el resultado dado y establecerá el puntero de valor interno a nullptr, lo que le permitirá reutilizar el valor de datos pasado. Si no se debe reutilizar, debe liberarse.

memcached_result_length() devolverá la longitud del valor de datos para el resultado dado.

memcached_result_flags() devolverá las banderas para el resultado dado.

memcached_result_cas() devolverá el valor CAS para el resultado dado.

memcached_result_set_value() establece el valor del objeto de resultado a los datos proporcionados.

memcached_result_set_flags() establece las banderas del objeto de resultado a los datos proporcionados.

memcached_result_set_expiration() establece el tiempo de expiración del objeto de resultado a los datos proporcionados.

memcached_result_key_length(3)

NAME

memcached_result_key_value, memcached_result_key_length, memcached_result_value, memcached_result_take_value, memcached_result_length, memcached_result_flags, memcached_result_cas, memcached_result_set_value, memcached_result_set_flags, memcached_result_set_expiration - Access results from libmemcached

SYNOPSIS

const char *memcached_result_key_value(memcached_result_st *result);

size_tmemcached_result_key_length(memcached_result_st *result);

char *memcached_result_value(memcached_result_st *result);

char *memcached_result_take_value(memcached_result_st *result);

size_tmemcached_result_length(memcached_result_st *result);

uint32_tmemcached_result_flags(memcached_result_st *result);

uint64_tmemcached_result_cas(memcached_result_st *result);

memcached_return_tmemcached_result_set_value(memcached_result_st *result, const char *value, size_t length);

voidmemcached_result_set_flags(memcached_result_st *result, uint32_t flags);

voidmemcached_result_set_expiration(memcached_result_st *result, time_t expiration);

DESCRIPTION

memcached_result_key_value() returns the key value associated with the current result object.

memcached_result_key_length() returns the key length associated with the current result object.

memcached_result_value() returns the result value associated with the current result object.

memcached_result_length() returns the result length associated with the current result object.

memcached_result_flags() returns the flags associated with the current result object.

memcached_result_cas() returns the cas associated with the current result object. This value will only be available if the server tests it.

memcached_result_set_value() takes a byte array and a size and sets the result to this value. This function is used for trigger responses.

memcached_result_set_flags() takes a result structure and stores a new value for the flags field.

memcached_result_set_expiration() takes a result structure and stores a new value for the expiration field (this is only used by read through triggers).

RETURN VALUE

Varies, see particular functions. All structures must have memcached_result_free() called on them for cleanup purposes. Failure to do this will result in leaked memory.
