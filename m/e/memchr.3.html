memchr(3) Manual de funciones de la biblioteca memchr(3)

NOMBRE

memchr, memrchr, rawmemchr - buscar un carácter en la memoria

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <string.h>
void *memchr(const void *s, int c, size_t n);
void *memrchr(const void *s, int c, size_t n);
[[deprecated]] void *rawmemchr(const void *s, int c);
Requisitos de Macro de Prueba de Funciones para glibc (ver feature_test_macros(7)):

memrchr(), rawmemchr():

    _GNU_SOURCE

DESCRIPCIÓN

La función memchr() busca en los primeros n bytes del área de memoria apuntada por s la primera aparición de c. Tanto c como los bytes del área de memoria apuntada por s se interpretan como unsigned char.

La función memrchr() es similar a la función memchr(), excepto que busca hacia atrás desde el final de los n bytes apuntados por s en lugar de hacia adelante desde el principio.

La función rawmemchr() es similar a memchr(), pero asume (es decir, el programador sabe con certeza) que una instancia de c se encuentra en algún lugar del área de memoria que comienza en la ubicación apuntada por s. Si no se encuentra una instancia de c, el comportamiento no está definido. Use strlen(3) o memchr(3) en su lugar.

VALOR DE RETORNO

Las funciones memchr() y memrchr() devuelven un puntero al byte coincidente o NULL si el carácter no aparece en el área de memoria dada.

La función rawmemchr() devuelve un puntero al byte coincidente.
