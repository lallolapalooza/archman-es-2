memcached_last_error_errno(3)

Paquete: libmemcached-awesome

Licencias: BSD

MEMCACHED_LAST_ERROR_ERRNO(3) libmemcached-awesome MEMCACHED_LAST_ERROR_ERRNO(3)

NOMBRE

memcached_last_error_errno - Documentación de libmemcached

SINOPSIS

#include <libmemcached/memcached.h>
Compilar y enlazar con -lmemcached
memcached_return_t memcached_last_error(const memcached_st *ptr)
Parámetros
ptr -- puntero a una estructura memcached_st inicializada
Devuelve
memcached_return_t indicando el éxito de la última operación
const char *memcached_last_error_message(const memcached_st *ptr)
Parámetros
ptr -- puntero a una estructura memcached_st inicializada
Devuelve
mensaje que describe el estado de la última operación
int memcached_last_error_errno(const memcached_st *ptr)
Parámetros
ptr -- puntero a una estructura memcached_st inicializada
Devuelve
errno(3) (si lo hay) de la última operación

DESCRIPCIÓN

Recuperar códigos y mensajes de error.

VALOR DEVUELTO

memcached_last_error() devuelve el último código de error.

memcached_last_error_message() devuelve el último mensaje de error. Si este error provino de un servidor específico, su nombre de host y puerto se proporcionarán en el mensaje de error. Cualquier mensaje de error se devolverá como 'const char *' que no necesita ser liberado. Se devolverá NULL si no ha ocurrido ningún error.
