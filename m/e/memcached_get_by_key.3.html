NOMBRE

memcached_get_by_key - Recuperación de datos del servidor

SINOPSIS

#include <libmemcached/memcached.h>
Compilar y enlazar con -lmemcached
memcached_result_st *memcached_fetch_result(memcached_st *ptr, memcached_result_st *result, memcached_return_t *error)
char *memcached_get(memcached_st *ptr, const char *key, size_t key_length, size_t *value_length, uint32_t *flags, memcached_return_t *error)
memcached_return_t memcached_mget(memcached_st *ptr, const char *const *keys, const size_t *key_length, size_t number_of_keys)
char *memcached_get_by_key(memcached_st *ptr, const char *group_key, size_t group_key_length, const char *key, size_t key_length, size_t *value_length, uint32_t *flags, memcached_return_t *error)
memcached_return_t memcached_mget_by_key(memcached_st *ptr, const char *group_key, size_t group_key_length, const char *const *keys, const size_t *key_length, size_t number_of_keys)
memcached_return_t memcached_fetch_execute(memcached_st *ptr, memcached_execute_fn *callback, void *context, uint32_t number_of_callbacks)
memcached_return_t memcached_mget_execute(memcached_st *ptr, const char *const *keys, const size_t *key_length, size_t number_of_keys, memcached_execute_fn *callback, void *context, uint32_t number_of_callbacks)
memcached_return_t memcached_mget_execute_by_key(memcached_st *ptr, const char *group_key, size_t group_key_length, const char *const *keys, const size_t *key_length, size_t number_of_keys, memcached_execute_fn *callback, void *context, uint32_t number_of_callbacks)
typedef memcached_return_t (*memcached_execute_fn)(const memcached_st *ptr, memcached_result_st *result, void *context)

DESCRIPCIÓN

memcached_get() se utiliza para obtener un valor individual del servidor. Debes pasar una clave y su longitud para obtener el objeto. Debes proporcionar tres variables puntero que te darán el estado del objeto devuelto. Un puntero uint32_t para contener cualquier bandera que almacenaste con el valor, un puntero size_t que se llenará con el tamaño del objeto y un puntero memcached_return_t para contener cualquier error. El objeto se devolverá en caso de éxito y se devolverá NULL en caso de fallo. Cualquier objeto devuelto por memcached_get() debe ser liberado por la aplicación que lo llama.

memcached_mget() se utiliza para seleccionar varias claves a la vez. Para operaciones con múltiples claves, siempre es más rápido usar esta función. Esta función siempre funciona de forma asíncrona.

Para recuperar datos después de una ejecución exitosa de memcached_mget(), necesitarás llamar a memcached_fetch_result(). Debes seguir llamando a esta función hasta que devuelva NULL (es decir, no más valores). Si necesitas salir a mitad de una llamada a memcached_mget(), puedes ejecutar un memcached_quit(), aunque no es obligatorio.

memcached_fetch_result() se utiliza para obtener un valor individual del servidor. memcached_mget() siempre debe ser llamado antes de usar este método. Debes pasar una clave y su longitud para obtener el objeto. Debes proporcionar tres variables puntero que te darán el estado del objeto devuelto. Un puntero uint32_t para contener cualquier bandera que almacenaste con el valor, un puntero size_t que se llenará con el tamaño del objeto y un puntero memcached_return_t para contener cualquier error. El objeto se devolverá en caso de éxito y se devolverá NULL en caso de fallo. MEMCACHED_END es devuelto por el valor del error * cuando todos los objetos que se han encontrado han sido devueltos. El valor final en MEMCACHED_END es nulo.

memcached_fetch_result() se utiliza para devolver una estructura memcached_result_st de un servidor memcached. El objeto de resultado es compatible hacia adelante con los cambios en el servidor. Para más información, consulta la ayuda de memcached_result_st. Esta función asignará dinámicamente una estructura de resultado si no le pasas una a la función.

memcached_fetch_execute() es una función de devolución de llamada para conjuntos de resultados. En lugar de devolverte los resultados para su procesamiento, pasa cada uno de los conjuntos de resultados a la lista de funciones que proporcionas. Pasa a la función un memcached_st que puede ser clonado para su uso en la función llamada (no se puede usar directamente). También pasa un conjunto de resultados que no necesita ser liberado. Finalmente, pasa un "contexto". Esto es solo un puntero a una referencia de memoria que proporcionas a la función que llama. Actualmente, solo se pasa un valor a cada llamada de función. En el futuro, habrá una opción para permitir que sea un array.

memcached_mget_execute() y memcached_mget_execute_by_key() son similares a memcached_mget(), pero pueden activar las devoluciones de llamada suministradas con conjuntos de resultados mientras envían las consultas. Si intentas realizar un multiget muy grande con memcached_mget(), puedes encontrarte con un bloqueo en el kernel del sistema operativo (fallará al escribir datos en el socket porque el búfer de entrada está lleno). memcached_mget_execute() resuelve este problema procesando algunos de los resultados antes de continuar enviando solicitudes. Ten en cuenta que esta función solo está disponible en el protocolo binario.

memcached_get_by_key() y memcached_mget_by_key() se comportan de manera similar a memcached_get() y memcached_mget(). La diferencia es que toman una clave maestra que se utiliza para determinar en qué servidor se almacenó un objeto si se utilizó particionamiento de claves para el almacenamiento.

Todas las funciones anteriores no se prueban cuando se establece MEMCACHED_BEHAVIOR_USE_UDP. Ejecutar cualquiera de estas funciones con este comportamiento activado resultará en la devolución de MEMCACHED_NOT_SUPPORTED, o para aquellas funciones que no devuelven memcached_return_t, el parámetro de la función de error se establecerá en MEMCACHED_NOT_SUPPORTED.

VALOR DE RETORNO

memcached_get() devolverá NULL en caso de error. Debes mirar el valor de error para determinar cuál fue el error real.

memcached_fetch_execute() devuelve MEMCACHED_SUCCESS si todas las claves fueron exitosas. MEMCACHED_NOTFOUND se devolverá si no se encontró ninguna clave.

memcached_fetch_result() establece el error a MEMCACHED_END al concluir con éxito. MEMCACHED_NOTFOUND se devolverá si no se encontró ninguna clave.

d_strerror(3)

NAME

d_strerror - return string describing a memcached error

SYNOPSIS

char * d_strerror (
    memcached_return_t rc
);

DESCRIPTION

The d_strerror() function shall return a pointer to a string describing the error code passed in rc.

The string is stored in a static buffer and must not be modified by the caller.

RETURN VALUE

On success, d_strerror() returns a pointer to a string describing the error.

On failure, d_strerror() returns NULL.
