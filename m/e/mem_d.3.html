NOMBRE

mem_d - Driver de memoria de AA-lib.

SINOPSIS

#include <aalib.h>

extern const struct aa_driver mem_d;

DESCRIPCIÓN

Se usa para renderizar imágenes de arte ascii en memoria. Podrías usar este driver para renderizar imágenes en memoria y luego usar tus propias rutinas para manejarlas en caso de que quieras evitar los mecanismos de salida de AA-lib.
