NOMBRE

memoize-extract.pl, memoize-extract.py - Extrae páginas externas del PDF

SINOPSIS

memoize-extract.pl [OPCIONES] documento.mmz

memoize-extract.py [OPCIONES] documento.mmz

DESCRIPCIÓN

memoize-extract es un script que acompaña a Memoize, un paquete de TeX que permite al autor reutilizar los resultados de código intensivo en compilación, como las imágenes TikZ.

Memoize vuelca las externas creadas (cajas que contienen el material tipográfico a reutilizar) en sus propias páginas del archivo PDF producido. La tarea de memoize-extract es extraer estas páginas externas a archivos PDF separados. En compilaciones posteriores, Memoize incluirá esos archivos externos en el documento, sin volver a compilar su código fuente.

Memoize se comunica con memoize-extract a través del archivo documento.mmz. Cuando se compila documento.tex para producir documento.pdf, Memoize produce documento.mmz, que registra qué páginas del documento producido son páginas externas y a qué archivos externos deben extraerse. Por lo tanto, después de compilar documento.tex, las externas deben extraerse con memoize-extract documento.mmz.

documento.mmz también puede proporcionarse como document* o documento.tex. Cuando la variable de entorno TEXMF_OUTPUT_DIRECTORY está configurada, este nombre de archivo es relativo al directorio de salida especificado por esta variable.

documento.mmz también registra el ancho y alto esperados de cada externa. En caso de discrepancia, memoize-extract se niega a extraer la página y elimina el archivo externo si ya existe, e imprime un mensaje de advertencia en la salida estándar de error. El script también se niega a extraer la página si no existe un (c)c-memo asociado a la externa. Ver también la sección SEGURIDAD.

La versión Perl (.pl) y la versión Python (.py) del script son funcionalmente equivalentes. El script Perl requiere la biblioteca PDF::API2, y el script Python requiere la biblioteca pdfrw2.

OPCIONES

-P, --pdf archivo.pdf
Las externas se extraerán de archivo.pdf. Por defecto, se extraen de documento.pdf.
-p, --prune
Elimina las páginas externas del PDF después de la extracción.
-k, --keep
No modifica documento.mmz para marcar las externas como extraídas. Por defecto, se comentan para evitar la doble extracción.
-F, --format latex|plain|context
Cuando se proporciona esta opción, el script asume que fue llamado desde dentro de una compilación TeX de un documento en el formato dado: antepone a toda la salida el nombre del script y crea un archivo de registro documento.mmz.log, que recibe cualquier advertencia y error relacionado con la extracción.
-f, --force
Extrae la externa incluso si la verificación del tamaño falla.
-q, --quiet
No describe lo que está sucediendo.
-m, --mkdir
Un mkdir -p paranoico. (No ocurre ninguna extracción, documento.mmz se interpreta como un nombre de directorio, que puede terminar en cualquier sufijo; no se realiza ninguna manipulación de sufijos).
-V, --version
Muestra el número de versión de Memoize y sale.
-h, --help
Muestra la ayuda y sale.

SEGURIDAD

Este script respeta las restricciones sobre la entrada y salida de archivos impuestas por la configuración de TeX, más precisamente, las variables openin_any y openout_any de la biblioteca kpathsea (https://tug.org/kpathsea). Puede inspeccionar los valores de estas variables ejecutando kpsewhich -var-value=openin_any y kpsewhich -var-value=openout_any. La interpretación es la siguiente:

a (o y o 1) cualquiera
Permite abrir cualquier archivo.
r (o n o 0) restringido
Significa desautorizar nombres de archivo especiales.
p (o cualquier otro valor) paranoico
Significa ser realmente paranoico: desautorizar nombres de archivo especiales y restringir los archivos de entrada/salida a estar en o debajo del directorio de trabajo o el directorio especificado por TEXMFOUTPUT o TEXMF_OUTPUT_DIRECTORY. TEXMFOUTPUT puede establecerse tanto en texmf.cnf (por ejemplo, por tlmgr) como en una variable de entorno. TEXMF_OUTPUT_DIRECTORY solo puede establecerse como una variable de entorno; se establece automáticamente por TeX cuando se llama con la opción -output-directory (a partir de TeXLive 2024).

ESTADO DE SALIDA

0
Las externas se extrajeron con éxito. Este código de salida se devuelve incluso si no hay externas que extraer, o si documento.mmz no existe.
10
Se informó una advertencia a la compilación cuando se proporcionó la opción --format. Actualmente, o bien: (i) discrepancia de tamaño; (ii) un archivo (c)c-memo asociado inexistente; o (iii) kpsewhich no disponible.
11
Se informó un error a la compilación cuando se proporcionó la opción --format. Actualmente, o bien: (i) un PDF de documento corrupto, o (ii) un error de permiso de kpathsea.

Otros códigos de salida son los producidos por el lenguaje de script subyacente (Perl o Python).
