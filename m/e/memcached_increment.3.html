memcached_increment(3)

Paquete: libmemcached-awesome

Licencias: BSD

MEMCACHED_INCREMENT(3) libmemcached-awesome MEMCACHED_INCREMENT(3)

NOMBRE

memcached_increment - Incremento y decremento de valores

SINOPSIS

#include <libmemcached/memcached.h>
Compilar y enlazar con -lmemcached
memcached_return_t memcached_increment(memcached_st *ptr, const char *key, size_t key_length, uint32_t offset, uint64_t *value)
memcached_return_t memcached_decrement(memcached_st *ptr, const char *key, size_t key_length, uint32_t offset, uint64_t *value)
memcached_return_t memcached_increment_with_initial(memcached_st *ptr, const char *key, size_t key_length, uint64_t offset, uint64_t initial, time_t expiration, uint64_t *value)
memcached_return_t memcached_decrement_with_initial(memcached_st *ptr, const char *key, size_t key_length, uint64_t offset, uint64_t initial, time_t expiration, uint64_t *value)
memcached_return_t memcached_increment_by_key(memcached_st *ptr, const char *group_key, size_t group_key_length, const char *key, size_t key_length, uint32_t offset, uint64_t *value)
memcached_return_t memcached_decrement_by_key(memcached_st *ptr, const char *group_key, size_t group_key_length, const char *key, size_t key_length, uint32_t offset, uint64_t *value)
memcached_return_t memcached_increment_with_initial_by_key(memcached_st *ptr, const char *group_key, size_t group_key_length, const char *key, size_t key_length, uint64_t offset, uint64_t initial, time_t expiration, uint64_t *value)
memcached_return_t memcached_decrement_with_initial_by_key(memcached_st *ptr, const char *group_key, size_t group_key_length, const char *key, size_t key_length, uint64_t offset, uint64_t initial, time_t expiration, uint64_t *value)
Parámetros
  • ptr -- puntero a una estructura memcached_st inicializada
  • group_key -- espacio de nombres de clave
  • group_key_length -- longitud del espacio de nombres de clave sin ningún cero terminador
  • key -- la clave
  • key_length -- longitud de la clave sin ningún cero terminador
  • offset -- desplazamiento a incrementar/decrementar
  • initial -- valor inicial si la clave no existe y la expiración no es MEMCACHED_EXPIRATION_NOT_ADD
  • expiration -- expiración como marca de tiempo unix o como tiempo de expiración relativo en segundos
  • value -- el valor resultante después de la inicialización/incremento/decremento
Devoluciones
memcached_return_t indicando éxito

DESCRIPCIÓN

memcached_increment() toma una clave y longitud_clave e incrementa el valor por el offset que se le pasa. El valor se devuelve luego a través del puntero uint32_t valor que le pasas.

memcached_decrement() toma una clave y longitud_clave y decrementa el valor por el offset que se le pasa. El valor se devuelve luego a través del puntero uint32_t valor que le pasas.

memcached_increment_with_initial() toma una clave y longitud_clave e incrementa el valor por el offset que se le pasa. Si el objeto especificado por clave no existe, puede ocurrir una de dos cosas: Si el valor de expiración es MEMCACHED_EXPIRATION_NOT_ADD, la operación fallará. Para todos los demás valores de expiración, la operación tendrá éxito al sembrar el valor para esa clave con un valor inicial que expirará con el tiempo de expiración proporcionado. Las flags se establecerán en cero. El valor se devuelve luego a través del puntero uint32_t valor que le pasas. memcached_increment_with_initial solo está disponible cuando se utiliza el protocolo binario.

memcached_decrement_with_initial() toma una clave y longitud_clave y decrementa el valor por el offset que se le pasa. Si el objeto especificado por clave no existe, puede ocurrir una de dos cosas: Si el valor de expiración es MEMCACHED_EXPIRATION_NOT_ADD, la operación fallará. Para todos los demás valores de expiración, la operación tendrá éxito al sembrar el valor para esa clave con un valor inicial que expirará con el tiempo de expiración proporcionado. Las flags se establecerán en cero. El valor se devuelve luego a través del puntero uint32_t valor que le pasas. memcached_decrement_with_initial() solo está disponible cuando se utiliza el protocolo binario.

memcached_increment_by_key(), memcached_decrement_by_key(), memcached_increment_with_initial_by_key(), y memcached_decrement_with_initial_by_key() son equivalentes de clave maestra de los anteriores.

VALOR DE RETORNO

Se devuelve un valor de tipo memcached_return_t. En caso de éxito, ese valor será MEMCACHED_SUCCESS. Utilice memcached_strerror() para traducir este valor a una cadena imprimible.
