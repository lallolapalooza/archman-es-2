NOMBRE

menu_driver - bucle de procesamiento de comandos del sistema de menús

SINOPSIS

#include <menu.h>
int menu_driver(MENU *menu, int c);

DESCRIPCIÓN

Una vez que un menú ha sido publicado (mostrado), debes canalizar los eventos de entrada a él a través de menu_driver. Esta rutina tiene tres casos principales de entrada:

  • La entrada es una solicitud de navegación del formulario. Los códigos de solicitud de navegación son constantes definidas en <form.h>, que son distintas de los códigos de caracteres y teclas devueltos por wgetch(3X).
  • La entrada es un carácter imprimible. Los caracteres imprimibles (que deben ser positivos, menores que 256) se comprueban según la configuración de localización del programa.
  • La entrada es la tecla especial KEY_MOUSE asociada con un evento del ratón.

Las solicitudes del controlador de menú son las siguientes:

REQ_LEFT_ITEM
Mover a la izquierda a un elemento.
REQ_RIGHT_ITEM
Mover a la derecha a un elemento.
REQ_UP_ITEM
Mover hacia arriba a un elemento.
REQ_DOWN_ITEM
Mover hacia abajo a un elemento.
REQ_SCR_ULINE
Desplazar una línea hacia arriba.
REQ_SCR_DLINE
Desplazar una línea hacia abajo.
REQ_SCR_DPAGE
Desplazar una página hacia abajo.
REQ_SCR_UPAGE
Desplazar una página hacia arriba.
REQ_FIRST_ITEM
Mover al primer elemento.
REQ_LAST_ITEM
Mover al último elemento.
REQ_NEXT_ITEM
Mover al siguiente elemento.
REQ_PREV_ITEM
Mover al elemento anterior.
REQ_TOGGLE_ITEM
Seleccionar/deseleccionar un elemento.
REQ_CLEAR_PATTERN
Borrar el búfer de patrón del menú.
REQ_BACK_PATTERN
Eliminar el carácter anterior del búfer de patrón.
REQ_NEXT_MATCH
Mover al siguiente elemento que coincida con el patrón.
REQ_PREV_MATCH
Mover al elemento anterior que coincida con el patrón.

Si el segundo argumento es un carácter imprimible, el código lo añade al búfer de patrón e intenta mover al siguiente elemento que coincida con el nuevo patrón. Si no hay ninguna coincidencia, menu_driver devuelve E_NO_MATCH y elimina el carácter añadido del búfer.

Si el segundo argumento es una de las solicitudes predefinidas anteriores, se realiza la acción correspondiente.

Manejo del ratón

Si el segundo argumento es la tecla especial KEY_MOUSE, el evento del ratón asociado se traduce en una de las solicitudes predefinidas anteriores. Actualmente solo se manejan los clics en la ventana del usuario (por ejemplo, dentro del área de visualización del menú o en la ventana de decoración).

Si haces clic encima de la región de visualización del menú:

  • se genera un REQ_SCR_ULINE para un solo clic,
  • se genera un REQ_SCR_UPAGE para un doble clic y
  • se genera un REQ_FIRST_ITEM para un triple clic.

Si haces clic debajo de la región de visualización del menú:

  • se genera un REQ_SCR_DLINE para un solo clic,
  • se genera un REQ_SCR_DPAGE para un doble clic y
  • se genera un REQ_LAST_ITEM para un triple clic.

Si haces clic en un elemento dentro del área de visualización del menú:

  • el cursor del menú se posiciona en ese elemento.
  • Si haces doble clic en un elemento, se genera un REQ_TOGGLE_ITEM y se devuelve E_UNKNOWN_COMMAND. Este valor de retorno tiene sentido, ya que un doble clic generalmente significa que se debe devolver una acción específica del elemento. Es precisamente el propósito de este valor de retorno indicar que se debe ejecutar un comando específico de la aplicación.
  • Si se realizó una traducción a una solicitud, menu_driver devuelve el resultado de esta solicitud.

Si hiciste clic fuera de la ventana del usuario o el evento del ratón no pudo traducirse en una solicitud de menú, se devuelve E_REQUEST_DENIED.

Comandos definidos por la aplicación

Si el segundo argumento no es imprimible ni una de las solicitudes de menú predefinidas anteriores o KEY_MOUSE, el controlador asume que es un comando específico de la aplicación y devuelve E_UNKNOWN_COMMAND. Los comandos definidos por la aplicación deben definirse en relación con MAX_COMMAND, el valor máximo de estas solicitudes predefinidas.

VALOR DE RETORNO

menu_driver devuelve uno de los siguientes códigos de error:

E_OK
La rutina tuvo éxito.
E_SYSTEM_ERROR
Ocurrió un error del sistema (ver errno(3)).
E_BAD_ARGUMENT
La rutina detectó un argumento incorrecto o fuera de rango.
E_BAD_STATE
La rutina se llamó desde una función de inicialización o terminación.
E_NOT_POSTED
El menú no ha sido publicado.
E_UNKNOWN_COMMAND
El controlador de menú vio un código de solicitud desconocido.
E_NO_MATCH
El carácter no coincidió.
E_REQUEST_DENIED
El controlador de menú no pudo procesar la solicitud.

PORTABILIDAD

Estas rutinas emulan la biblioteca de menús de System V. No se soportaron en las versiones 7 o BSD. El soporte para eventos del ratón es específico de ncurses.

AUTORES

Juergen Pfeifer. Páginas de manual y adaptación para curses nuevas por Eric S. Raymond.

menu_driver.3x

menu_driver - Menú de conductor

NAME

menu_driver - Menú de conductor

SYNOPSIS

#include <menu.h>

int menu_driver(MENU *menu, int c);

DESCRIPTION

La función menu_driver procesa un carácter de entrada `c` para el menú dado. El carácter de entrada `c` puede ser una tecla presionada o un código de comando especial definido en `menu.h`.

Los comandos comunes incluyen:

  • REQP_UP_ITEM: Mover el cursor hacia arriba un elemento.
  • REQP_DOWN_ITEM: Mover el cursor hacia abajo un elemento.
  • REQP_LEFT_ITEM: Mover el cursor hacia la izquierda un elemento.
  • REQP_RIGHT_ITEM: Mover el cursor hacia la derecha un elemento.
  • REQP_FIRST_ITEM: Mover el cursor al primer elemento.
  • REQP_LAST_ITEM: Mover el cursor al último elemento.
  • REQP_NEXT_PAGE: Mover el cursor a la siguiente página.
  • REQP_PREV_PAGE: Mover el cursor a la página anterior.
  • REQP_TOGGLE_ITEM: Cambiar el estado seleccionado del elemento actual.
  • REQP_SCROLL_UP: Desplazar el menú hacia arriba.
  • REQP_SCROLL_DOWN: Desplazar el menú hacia abajo.
  • REQP_NEWLINE: Procesar una nueva línea.
  • REQP_ ENTER: Procesar la entrada Enter.

La función menu_driver realiza las acciones asociadas con el comando dado, actualizando la pantalla si es necesario. Si el carácter de entrada no corresponde a un comando válido o no puede ser procesado, la función no hace nada y devuelve el carácter de entrada sin cambios.

RETURN VALUE

En caso de éxito, menu_driver devuelve el carácter de entrada que fue procesado. Si se produce un error (por ejemplo, un puntero de menú nulo), devuelve ERR.

PORTABILITY

Todas las funciones son portables en sistemas POSIX.
