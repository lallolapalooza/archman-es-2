DESCRIPCIÓN

memcached_stat_execute() utiliza los servidores encontrados en memcached_stat_st y ejecuta un comando "stat" en cada servidor. args es un argumento opcional que se puede pasar para modificar el comportamiento de "stats". Deberá proporcionar una función de devolución de llamada que recibirá cada par de valores devueltos por el servidor memcached.

memcached_stat() recupera un array de estructuras memcached_stat_st que contienen el estado de todos los servidores memcached disponibles. El valor de retorno debe ser liberado por la aplicación que llama. Si se llama con el comportamiento MEMCACHED_BEHAVIOR_USE_UDP activado, se retorna un valor NULL y el parámetro de error se establece a MEMCACHED_NOT_SUPPORTED.

memcached_stat_servername() se puede usar de forma independiente sin una memcached_st para obtener el estado de un servidor particular. "args" se utiliza para definir un objeto de estado particular (una lista de estos no es proporcionada por la llamada memcached_stat_get_keys() ni están definidos en el protocolo memcached). Debe especificar el nombre de host y el puerto del servidor del cual desea obtener información.

memcached_stat_get_value() retorna el valor de una clave de estado particular. Usted especifica la clave que desea obtener. La clave debe terminar en nulo.

memcached_stat_get_keys() retorna una lista de claves sobre las cuales el servidor tiene objetos de estado. Usted es responsable de liberar esta lista.

Se proporciona una herramienta de línea de comandos, memstat, para que no tenga que escribir una aplicación para hacer esto.

VALOR DE RETORNO

Varía, ver funciones particulares.

Cualquier método que retorne una memcached_stat_st espera que usted libere la memoria asignada para ella.
