DESCRIPCIÓN

libmemcached realiza operaciones sobre una lista de hosts. El orden de estos hosts determina el enrutamiento de las claves. Se proporcionan funciones para añadir claves a las estructuras memcached_st. Para manipular listas de servidores, consulta memcached_server_st.

memcached_server_count() proporciona un recuento del número actual de servidores utilizados por una estructura memcached_st.

memcached_server_add() añade un único servidor TCP a la estructura memcached_st. Este servidor se colocará al final. Se permiten servidores duplicados, por lo que no se realiza una comprobación de duplicados. La ejecución de esta función con el comportamiento MEMCACHED_BEHAVIOR_USE_UDP activado resultará en un MEMCACHED_INVALID_HOST_PROTOCOL.

memcached_server_add_udp() añade un único servidor UDP a la estructura memcached_st. Este servidor se colocará al final. Se permiten servidores duplicados, por lo que no se realiza una comprobación de duplicados. La ejecución de esta función sin activar el comportamiento MEMCACHED_BEHAVIOR_USE_UDP resultará en un MEMCACHED_INVALID_HOST_PROTOCOL.

memcached_server_add_unix_socket() añade un único socket UNIX a la estructura memcached_st. Este socket UNIX se colocará al final. Se permiten sockets duplicados, por lo que no se realiza una comprobación de duplicados. La longitud del nombre de archivo debe ser un carácter menos que MEMCACHED_MAX_HOST_LENGTH.

memcached_server_push() añade un array de memcached_server_st a la estructura memcached_st. Los servidores se añadirán al final de la lista existente. Los servidores duplicados se permiten, por lo que no se realiza ninguna comprobación de duplicados.

memcached_server_by_key() se utiliza para determinar qué servidor debe ser utilizado para una clave dada. Devuelve un puntero a la instancia del servidor. El usuario debe asegurarse de que el puntero devuelto sigue siendo válido y no debe liberarse.

memcached_server_get_last_disconnect() devuelve la instancia del último servidor con el que hubo un problema de conexión. Esto puede ser útil para reconfigurar o eliminar ese servidor de la lista.

memcached_server_cursor() itera sobre cada instancia de servidor en la estructura memcached_st y llama a la función de retorno proporcionada. Esto puede ser útil para realizar operaciones personalizadas en cada servidor, como la obtención de estadísticas o la verificación del estado de la conexión.

NAME

memcached_server_add_unix_socket - add a server to the connection structure

SYNOPSIS

#include <libmemcached/memcached.h>

char *
memcached_server_list_append(char *servers, const char *str,
    memcached_return_t *rc);
char *
memcached_server_from_parse(const char *str,
    memcached_return_t *rc);
void
memcached_server_list_free(char *servers);
int
memcached_server_count(const char *servers);
memcached_server_st *
memcached_server_get_last_disconnect(memcached_st *ptr);
memcached_server_st *
memcached_server_by_key(memcached_st *ptr, const char *key,
    size_t key_length, memcached_return_t *rc);
void
memcached_server_cursor(memcached_st *ptr,
    void (*callback)(memcached_st *, memcached_server_st *, void *),
    void *context);

DESCRIPTION

The following functions allow you to manage the list of servers that the memcached client is connected to.

memcached_server_from_parse() parses a string for servers. The string should be a comma separated list of hosts and ports. The default port is 11211.

memcached_server_list_free() frees a list of servers that was created via memcached_server_list_append() or memcached_server_from_parse().

memcached_server_count() returns the number of servers that are in the list of servers.

memcached_server_st is the structure that describes a server. This includes the hostname, port, state of connection, and other variables that are related to a specific server. These structures are managed internally by the library. The functions that deal with servers allow you to directly manipulate this structure.

memcached_server_add_unix_socket() is used to add a unix domain socket to the list of servers. The value for str should be a path to the socket.

The functions listed in the synopsis deal with the internal list of servers. This list is iterated over.

memcached_server_list_append() adds a server to the list. A copy is made of the str parameter. The new server is added to the end of the list.

memcached_server_from_parse() parses a string (str) for a list of servers. This string should be comma-seperated hosts and ports. The default port is 11211. The list of servers is returned as a NULL terminated array of pointers to memcached_server_st structures. These servers will be placed at the end. Duplicate servers are allowed, so duplication is not checked. A copy is made of structure so the list provided (and any operations on the list) are not saved.

memcached_server_by_key() allows you to provide a key and retrieve the server which would be used for assignment.

memcached_server_get_last_disconnect() returns a pointer to the last server for which there was a connection problem. It does not mean this particular server is currently dead but if the library is reporting a server is, the returned server is a very good candidate.

memcached_server_cursor() takes a memcached_st and loops through the list of hosts currently in the cursor calling the list of callback functions provided. You can optionally pass in a value via context which will be provided to each callback function. An error return from any callback will terminate the loop. memcached_server_cursor() is passed the original caller memcached_st in its current state.

RETURN VALUE

Varies, see particular functions.
