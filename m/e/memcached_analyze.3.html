memcached_analyze(3)

Paquete: libmemcached-awesome

Licencias: BSD

MEMCACHED_ANALYZE(3) libmemcached-awesome MEMCACHED_ANALYZE(3)

NOMBRE

memcached_analyze - Documentación de libmemcached

SINOPSIS

#include <libmemcached/memcached.h>
Compilar y enlazar con -lmemcached
typedef struct memcached_analysis_st memcached_analysis_st
memcached_analysis_st *memcached_analyze(memcached_st *ptr, memcached_stat_st *stat, memcached_return_t *error)
Parámetros
  • ptr -- puntero a la estructura memcached_st inicializada
  • stat -- puntero a una estructura memcached_stat_st para rellenar
  • error -- puntero a memcached_return_t que indica éxito
Retorna
puntero a una estructura memcached_analysis_t asignada y rellenada

DESCRIPCIÓN

libmemcached tiene la capacidad de consultar a un servidor memcached (o a una colección de servidores) su estado actual. Las consultas para encontrar el estado devuelven una estructura memcached_analysis_st. Usted es responsable de liberar esta estructura.

memcached_analyze() analiza información útil basada en los servidores proporcionados y establece el resultado en la estructura memcached_analysis_st. El valor de retorno debe ser liberado por la aplicación que lo llama.

VER TAMBIÉN:

memstat -a|--analyze [<arg>] Una herramienta de línea de comandos para analizar un servidor memcached.

VALOR DE RETORNO

Un puntero a la estructura memcached_analysis_st asignada en caso de éxito y un puntero NULL en caso de fallo. Puede inspeccionar el detalle del error comprobando el valor memcached_return_t.

Cualquier método que devuelva una memcached_analysis_st espera que usted libere la memoria asignada para ella.
