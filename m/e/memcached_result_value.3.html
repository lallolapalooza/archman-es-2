DESCRIPCIÓN

La estructura de memcached_result_st ha sido encapsulada, no debes escribir código que acceda directamente a los miembros de la estructura.

memcached_result_create() asignará memoria para una memcached_result_st o inicializará una estructura que se le pase.

memcached_result_free() liberará cualquier memoria adjunta a la estructura. Si la estructura también fue asignada, la liberará.

SYNOPSIS

#include <libmemcached/results.h>

const char * memcached_result_key(memcached_result_st *result);

size_t memcached_result_key_length(memcached_result_st *result);

const char * memcached_result_value(memcached_result_st *result);

char * memcached_result_take_value(memcached_result_st *result);

size_t memcached_result_length(memcached_result_st *result);

uint32_t memcached_result_flags(memcached_result_st *result);

uint64_t memcached_result_cas(memcached_result_st *result);

void memcached_result_set_value(memcached_result_st *result, const char *value, size_t length);

void memcached_result_set_flags(memcached_result_st *result, uint32_t flags);

void memcached_result_set_expiration(memcached_result_st *result, time_t expiration);

DESCRIPTION

memcached_result_key() devuelve el valor de la clave asociado con el objeto de resultado actual.

memcached_result_key_length() devuelve la longitud de la clave asociada con el objeto de resultado actual.

memcached_result_value() devuelve el valor del resultado asociado con el objeto de resultado actual.

memcached_result_length() devuelve la longitud del resultado asociada con el objeto de resultado actual.

memcached_result_flags() devuelve las banderas asociadas con el objeto de resultado actual.

memcached_result_cas() devuelve el valor cas asociado con el objeto de resultado actual. Este valor solo estará disponible si el servidor lo comprueba.

memcached_result_set_value() toma un array de bytes y un tamaño y establece el resultado a este valor. Esta función se utiliza para activar respuestas.

memcached_result_set_flags() toma una estructura de resultado y almacena un nuevo valor para el campo de banderas.

memcached_result_set_expiration() toma una estructura de resultado y almacena un nuevo valor para el campo de expiración (esto solo es utilizado por los desencadenadores de lectura).

VALOR DE RETORNO

Varía, ver las funciones particulares. A todas las estructuras se les debe llamar memcached_result_free() para fines de limpieza. No hacerlo resultará en una fuga de memoria.
