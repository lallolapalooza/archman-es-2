menu_attributes(3X) Llamadas de biblioteca menu_attributes(3X)

NOMBRE

menu_back, menu_fore, menu_grey, menu_pad, set_menu_back, set_menu_fore, set_menu_grey, set_menu_pad - control de color y atributos para menús

SINOPSIS

#include <menu.h>
int set_menu_fore(MENU *menu, chtype attr);
chtype menu_fore(const MENU *menu);
int set_menu_back(MENU *menu, chtype attr);
chtype menu_back(const MENU *menu);
int set_menu_grey(MENU *menu, chtype attr);
chtype menu_grey(const MENU *menu);
int set_menu_pad(MENU *menu, int pad);
int menu_pad(const MENU *menu);

DESCRIPCIÓN

La función set_menu_fore establece el atributo de primer plano de menu. Este es el resaltado utilizado para los elementos de menú seleccionados. menu_fore devuelve el atributo de primer plano. El valor predeterminado es A_REVERSE.

La función set_menu_back establece el atributo de fondo de menu. Este es el resaltado utilizado para los elementos de menú seleccionables (pero no actualmente seleccionados). La función menu_back devuelve el atributo de fondo. El valor predeterminado es A_NORMAL.

La función set_menu_grey establece el atributo gris de menu. Este es el resaltado utilizado para los elementos de menú no seleccionables en menús que permiten más de una selección. La función menu_grey devuelve el atributo gris. El valor predeterminado es A_UNDERLINE.

La función set_menu_pad establece el carácter utilizado para rellenar el espacio entre el nombre y las partes de descripción de un elemento de menú. menu_pad devuelve el carácter de relleno del menú dado. El valor predeterminado es un espacio en blanco.

VALOR DE RETORNO

Estas rutinas devuelven uno de los siguientes:

E_OK
La rutina tuvo éxito.
E_SYSTEM_ERROR
Ocurrió un error del sistema (ver errno(3)).
E_BAD_ARGUMENT
La rutina detectó un argumento incorrecto o fuera de rango.

PORTABILIDAD

Estas rutinas emulan la biblioteca de menús de System V. No fueron soportadas en las versiones 7 o BSD.

AUTORES
