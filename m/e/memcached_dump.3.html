memcached_dump(3)

Paquete: libmemcached-awesome

Licencias: BSD

MEMCACHED_DUMP(3) libmemcached-awesome MEMCACHED_DUMP(3)

NOMBRE

memcached_dump - Documentación de libmemcached

SINOPSIS

#include <libmemcached/memcached.h>
Compilar y enlazar con -lmemcached
typedef memcached_return_t (*memcached_dump_fn)(memcached_st *ptr, const char *key, size_t key_length, void *context)
Param ptr
puntero al objeto memcached_st
Param key
cadena de clave que se está volcando
Param key_length
longitud de la clave sin ningún cero terminador
Param context
puntero al contexto proporcionado por el usuario
Devuelve
memcached_return_t indicando éxito
memcached_return_t memcached_dump(memcached_st *ptr, memcached_dump_fn *function, void *context, uint32_t number_of_callbacks)
Parámetros
  • ptr -- puntero a la estructura memcached_st inicializada
  • function -- puntero a las funciones de devolución de llamada memcached_dump_fn de number_of_callbacks
  • context -- puntero a un contexto gestionado por el usuario
  • number_of_callbacks -- número de funciones de devolución de llamada en la matriz function
Devuelve
memcached_return_t indicando éxito

DESCRIPCIÓN

Actualmente, el protocolo binario no está probado.

VALOR DEVUELTO

Se devuelve un valor de tipo memcached_return_t. En caso de éxito, ese valor será MEMCACHED_SUCCESS. Utilice memcached_strerror() para traducir este valor a una cadena imprimible.

VER TAMBIÉN

1 de mayo de 2024 1.1
