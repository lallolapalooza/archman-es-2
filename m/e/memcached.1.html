NOMBRE

memcached - sistema de caché de objetos en memoria de alto rendimiento

SINOPSIS

memcached [opciones]

DESCRIPCIÓN

Esta página del manual documenta brevemente el demonio de caché de objetos en memoria memcached.

memcached es un demonio flexible de caché de objetos en memoria diseñado para aliviar la carga de la base de datos en aplicaciones web dinámicas almacenando objetos en memoria. Se basa en libevent para escalar a cualquier tamaño necesario y está específicamente optimizado para evitar el swapping y usar siempre E/S no bloqueante.

OPCIONES

Estos programas siguen la sintaxis habitual de línea de comandos de GNU. A continuación se incluye un resumen de las opciones.

-s, --unix-socket=<archivo>
Ruta del socket Unix en el que escuchar (deshabilita el soporte de red).
-A, --enable-shutdown
Habilita el comando ASCII "shutdown".
-a, --unix-mask=<permisos>
Permisos (en formato octal) para el socket Unix creado con la opción -s.
-l, --listen=<dirección>
Escucha en <dirección>; por defecto INADDR_ANY. <dirección> puede especificarse como host:puerto. Si no especificas un número de puerto, se usa el valor especificado con -p o -U. Puedes especificar múltiples direcciones separadas por comas o usando -l varias veces. Esta es una opción importante a considerar ya que no hay otra forma de asegurar la instalación. Se sugiere vincularse a una interfaz de red interna o protegida por cortafuegos.
-d, --daemon
Ejecuta memcached como un demonio.
-u, --user=<nombredeusuario>
Asume la identidad de <nombredeusuario> (solo cuando se ejecuta como root).
-m, --memory-limit=<número>
Usa un máximo de <número> MB de memoria para el almacenamiento de objetos; por defecto son 64 megabytes.
-c, --conn-limit=<número>
Usa un máximo de <número> conexiones simultáneas; por defecto es 1024.
-R, --max-reqs-per-event=<número>
Esta opción busca prevenir la inanición del cliente estableciendo un límite al número de solicitudes secuenciales que el servidor procesará desde una conexión de cliente individual. Una vez que una conexión ha excedido este valor, el servidor intentará procesar E/S en otras conexiones antes de manejar cualquier solicitud adicional de esta conexión. El valor por defecto para esta opción es 20.
-k, --lock-memory
Bloquea toda la memoria paginada. Esta es una opción algo peligrosa con cachés grandes, así que consulta el README y la página de inicio de memcached para obtener sugerencias de configuración.
-p, --port=<número>
Escucha en el puerto TCP <número>, por defecto es el puerto 11211. 0 significa desactivado.
-U, --udp-port=<número>
Escucha en el puerto UDP <número>, por defecto es el puerto 0, que significa desactivado.
-M, --disable-evictions
Deshabilita la eliminación automática de elementos de la caché cuando no hay memoria. Las adiciones no serán posibles hasta que se libere espacio adecuado.
-r, --enable-coredumps
Aumenta el límite del tamaño de los archivos core al máximo permitido.
-f, --slab-growth-factor=<factor>
Usa <factor> como multiplicador para calcular los tamaños de los bloques de memoria en los que se almacenan los elementos. Un valor menor puede resultar en menos desperdicio de memoria dependiendo de la cantidad total de memoria disponible y la distribución de los tamaños de los elementos. El valor por defecto es 1.25.
-n, --slab-min-size=<tamaño>
Asigna un mínimo de <tamaño> bytes para la clave del elemento, el valor y las banderas. El valor por defecto es 48. Si tienes muchas claves y valores pequeños, puedes obtener una ganancia significativa de eficiencia de memoria con un valor más bajo. Si usas un factor de crecimiento de bloques alto (opción -f), por otro lado, es posible que desees aumentar el tamaño para permitir que un mayor porcentaje de tus elementos quepan en los bloques más densamente empaquetados (los más pequeños).
-C, --disable-cas
Deshabilita el uso de CAS (y reduce el tamaño por elemento en 8 bytes).
-h, --help
Muestra la versión de memcached y un resumen de las opciones.
-v, --verbose
Sé verboso durante el bucle de eventos; imprime errores y advertencias.
-vv
Sé aún más verboso; igual que -v pero también imprime comandos y respuestas del cliente.
-vvv
Sé extremadamente verboso; igual que el anterior y también imprime transiciones de estado internas.
-i, --license
Imprime las licencias de memcached y libevent.
-P, --pidfile=<nombre de archivo>
Escribe el archivo pid en <nombre de archivo>, solo se usa bajo la opción -d.
-t, --threads=<hilos>
Número de hilos a utilizar para procesar las solicitudes entrantes. Esta opción solo es significativa si memcached se compiló con soporte de hilos habilitado. Generalmente no es útil establecer este valor más alto que el número de núcleos de CPU en el servidor memcached. No se recomienda establecer un alto número (64 o más) de hilos de trabajo. El valor por defecto es 4.
-D <caracter>
Usa <caracter> como delimitador entre prefijos de clave e IDs. Esto se usa para la generación de informes de estadísticas por prefijo. El valor por defecto es ":" (dos puntos). Si se especifica esta opción, la recolección de estadísticas se activa automáticamente; si no, puede activarse enviando el comando "stats detail on" al servidor.
-L, --enable-largepages
Intenta usar páginas de memoria grandes (si están disponibles). Aumentar el tamaño de las páginas de memoria podría reducir el número de fallos de TLB y mejorar el rendimiento. Para obtener páginas grandes del sistema operativo, memcached asignará el caché total de elementos en un solo bloque grande. Solo disponible si es compatible en tu sistema operativo.
-b, --listen-backlog=<número>
Establece el límite de la cola de espera de conexiones a <número>. El valor por defecto es 1024.
-B, --protocol=<proto>
Especifica el protocolo de enlace a utilizar. Por defecto, el servidor autonegociará las conexiones de los clientes. Usando esta opción, puedes especificar el protocolo que deben usar los clientes. Las opciones posibles son "auto" (el comportamiento por defecto, de autonegociación), "ascii" y "binary".
-I, --max-item-size=<tamaño>
Ajustar este valor cambia el límite del tamaño de los elementos. El valor por defecto para este parámetro es 1m, el mínimo es 1k, el máximo es 1G (1024 * 1024 * 1024).
-S, --enable-sasl
Activa la autenticación SASL. Esta opción solo es significativa si memcached se compiló con soporte SASL habilitado.
-F, --disable-flush-all
Deshabilita el comando "flush_all". El contador cmd_flush se incrementará, pero los clientes recibirán un mensaje de error y la limpieza no ocurrirá.
-X, --disable-dumping
Deshabilita los comandos "stats cachedump" y "lru_crawler metadump".
-o, --extended=<opciones>
Lista de opciones extendidas o experimentales separadas por comas. Consulta -h o la wiki para obtener la lista actualizada.
-V, --version
imprime la versión y sale
