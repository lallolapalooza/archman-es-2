DESCRIPCIÓN

libmemcached realiza operaciones sobre una lista de hosts. El orden de estos hosts determina el enrutamiento a las claves. Se proporcionan funciones para añadir claves a las estructuras memcached_st. Para manipular listas de servidores, consulte memcached_server_st.

memcached_server_count() le proporciona un recuento del número actual de servidores que está utilizando una estructura memcached_st.

memcached_server_add() añade un único servidor TCP a la estructura memcached_st. Este servidor se colocará al final. Se permiten servidores duplicados, por lo que no se comprueba la duplicación. Ejecutar esta función con el comportamiento MEMCACHED_BEHAVIOR_USE_UDP activado resultará en un MEMCACHED_INVALID_HOST_PROTOCOL.

memcached_server_add_udp() añade un único servidor UDP a la estructura memcached_st. Este servidor se colocará al final. Se permiten servidores duplicados, por lo que no se comprueba la duplicación. Ejecutar esta función sin establecer el comportamiento MEMCACHED_BEHAVIOR_USE_UDP resultará en un MEMCACHED_INVALID_HOST_PROTOCOL.

memcached_server_add_unix_socket() añade un único socket UNIX a la estructura memcached_st. Este socket UNIX se colocará al final. Se permiten sockets duplicados, por lo que no se comprueba la duplicación. La longitud del nombre de archivo debe ser un carácter menor que MEMCACHED_MAX_HOST_LENGTH.

NAME

memcached_server_add, memcached_server_add_udp, memcached_server_add_parsed, memcached_server_by_key, memcached_server_get_last_disconnect, memcached_server_cursor - add a server to the list of servers to be used by the memcached library

SYNOPSIS

#include <libmemcached/memcached.h>

memcached_return_t memcached_server_add(
memcached_st *ptr,
const char *hostname,
in_port_t port);
memcached_return_t memcached_server_add_udp(
memcached_st *ptr,
const char *hostname,
in_port_t port);
memcached_return_t memcached_server_add_parsed(
memcached_st *ptr,
const char *server_string);
memcached_server_st * memcached_server_get_last_disconnect(
const memcached_st *ptr);
memcached_return_t memcached_server_cursor(
memcached_st *ptr,
memcached_server_fn function,
void *context);
memcached_server_st * memcached_server_by_key(
memcached_st *ptr,
const char *key,
size_t key_length);

DESCRIPTION

The memcached_server_add() function adds a new server to the list of servers to be used by the memcached client. The server is added to the end of the list.

memcached_server_add_udp() is the same as memcached_server_add() but adds the server for UDP communication.

memcached_server_add_parsed() allows you to pass a string containing the server name and port. The format is expected to be hostname:port. This function will parse the string and add the server to the list.

A copy is made of the list of servers. The original list is not modified. The addition of servers will be done at the end of the list.

Duplicate servers are allowed, so duplication is not checked. A copy is made of structure so the list provided (and any operations on the list) are not saved.

memcached_server_by_key() allows you to provide a key and retrieve the server which would be used for assignment.

memcached_server_get_last_disconnect() returns a pointer to the last server for which there was a connection problem. It does not mean this particular server is currently dead but if the library is reporting a server is, the returned server is a very good candidate.

memcached_server_cursor() takes a memcached_st and loops through the list of hosts currently in the cursor calling the list of callback functions provided. You can optionally pass in a value via context which will be provided to each callback function. An error return from any callback will terminate the loop. memcached_server_cursor() is passed the original caller memcached_st in its current state.

RETURN VALUE

Varies, see particular functions.
