NOMBRE

memcapable - Documentación de libmemcached

SINOPSIS

memcapable [opciones]

Comprueba las capacidades y la compatibilidad de un servidor memcached.

DESCRIPCIÓN

memcapable se conecta al servidor memcached especificado e intenta determinar sus capacidades ejecutando varios comandos y verificando la respuesta.

OPCIONES

-h hostname
Especifica el nombre de host al que conectarse. El valor predeterminado es localhost.
-p puerto
Especifica el número de puerto al que conectarse. El valor predeterminado es 11211.
-c
abort(3) al detectar un error del servidor.
-v
Imprime la comparación al detectar un error del servidor.
-t n
Establece el tiempo de espera para una operación de E/S hacia/desde el servidor en n segundos.

NOTAS

PREFIJO DEL PROGRAMA

El prefijo de este programa es variable, es decir, puede configurarse en tiempo de compilación.

Normalmente, los programas cliente de libmemcached-awesome tienen el prefijo mem, como memcat o memcp.

Sin embargo, puede configurarse para reemplazar el prefijo por algo más como mc, en cuyo caso, los programas cliente de libmemcached-awesome se llamarían mccat, mccp, etc., respectivamente.

PROGRAMA CONTRIBUIDO

Este es un programa contribuido.

Este programa no sigue el esquema estándar de banderas/opciones.
