menu_win(3x)

Paquete: ncurses

Licencias: MIT-open-group

menu_win(3X) Llamadas a bibliotecas menu_win(3X)

NOMBRE

menu_win - establecer y romper asociaciones de ventanas de menú y subventanas

SINOPSIS

#include <menu.h>
int set_menu_win(MENU *menu, WINDOW *win);
WINDOW *menu_win(const MENU *menu);
int set_menu_sub(MENU *menu, WINDOW *sub);
WINDOW *menu_sub(const MENU *menu);
int scale_menu(const MENU *menu, int *rows, int *columns);

DESCRIPCIÓN

Cada menú tiene un par asociado de ventanas curses. La ventana del menú muestra cualquier título y borde asociado con la ventana; la subventana del menú muestra los elementos del menú que están actualmente disponibles para seleccionar.

Las primeras cuatro funciones obtienen y establecen esas ventanas. No es necesario establecer ninguna de las dos ventanas; por defecto, el código del controlador usa stdscr para ambas.

En las funciones set_, el argumento de ventana NULL se trata como si fuera stsdcr. Un argumento de menú NULL se trata como una solicitud para cambiar la ventana de menú o subventana predeterminada del sistema.

La función scale_menu devuelve el tamaño mínimo requerido para la subventana de menu.

VALOR DE RETORNO

Las rutinas que devuelven punteros devuelven NULL en caso de error. Las rutinas que devuelven un entero devuelven uno de los siguientes códigos de error:

E_OK
La rutina tuvo éxito.
E_SYSTEM_ERROR
Ocurrió un error del sistema (ver errno(3)).
E_BAD_ARGUMENT
La rutina detectó un argumento incorrecto o fuera de rango.
E_POSTED
El menú ya ha sido publicado.
E_NOT_CONNECTED
No hay elementos conectados al menú.

PORTABILIDAD

Estas rutinas emulan la biblioteca de menús de System V. No eran compatibles con las versiones 7 o BSD.

AUTORES

Juergen Pfeifer. Páginas del manual y adaptación para el nuevo curses por Eric S. Raymond.

VER TAMBIÉN
