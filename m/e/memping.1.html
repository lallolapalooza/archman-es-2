NOMBRE

memping - Documentación de libmemcached

SINOPSIS

memping [opciones] [servidor]

Prueba la disponibilidad de un servidor

DESCRIPCIÓN

memping se puede usar para hacer ping a un servidor memcached para ver si está aceptando conexiones.

OPCIONES

-h|--help
Muestra la ayuda.
-V|--version
Muestra la versión.
-q|--quiet
Opera en modo silencioso.
-v|--verbose
Opera de forma más detallada.
-d|--debug
Ver -v|--verbose.
-u|--username <nombre de usuario>
Usa nombre de usuario para la autenticación SASL.
-p|--password <contraseña>
Usa contraseña para la autenticación SASL.
-s|--servers <lista de servidores>
Especifica la lista de servidores como nombre del host[:puerto][,nombre del host[:puerto]...].

ENTORNO

MEMCACHED_SERVERS
Especifica una lista de servidores.

NOTAS

PREFIJO DEL PROGRAMA

El prefijo de este programa es variable, es decir, se puede configurar en tiempo de compilación.

Normalmente, los programas cliente de libmemcached-awesome se prefijan con mem, como memcat o memcp.

Sin embargo, se puede configurar para reemplazar el prefijo por algo más como mc; en ese caso, los programas cliente de libmemcached-awesome se llamarían mccat, mccp, etc., respectivamente.
