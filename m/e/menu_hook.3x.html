Paquete: ncurses

menu_hook(3X) Llamadas a la biblioteca menu_hook(3X)

NOMBRE

menu_hook - establecer ganchos para invocación automática por aplicaciones

SINOPSIS

#include <menu.h>
int set_item_init(MENU *menu, Menu_Hook func);
Menu_Hook item_init(const MENU *menu);
int set_item_term(MENU *menu, Menu_Hook func);
Menu_Hook item_term(const MENU *menu);
int set_menu_init(MENU *menu, Menu_Hook func);
Menu_Hook menu_init(const MENU *menu);
int set_menu_term(MENU *menu, Menu_Hook func);
Menu_Hook menu_term(const MENU *menu);

DESCRIPCIÓN

Estas funciones permiten establecer funciones de gancho para ser llamadas en varios puntos del procesamiento automático de códigos de eventos de entrada por menu_driver.

La función set_item_init establece un gancho que se llamará en el momento de postear el menú y cada vez que cambie el elemento seleccionado (después del cambio). item_init devuelve el gancho de inicialización de elemento actual, si existe (NULL si no hay tal gancho).

La función set_item_term establece un gancho que se llamará en el momento de despostear el menú y cada vez que cambie el elemento seleccionado (antes del cambio). item_term devuelve el gancho de terminación de elemento actual, si existe (NULL si no hay tal gancho).

La función set_menu_init establece un gancho que se llamará en el momento de postear el menú y justo después de que la fila superior del menú cambie una vez que se ha posteado. menu_init devuelve el gancho de inicialización del menú actual, si existe (NULL si no hay tal gancho).

La función set_menu_term establece un gancho que se llamará en el momento de despostear el menú y justo antes de que la fila superior del menú cambie una vez que se ha posteado. menu_term devuelve el gancho de terminación del menú actual, si existe (NULL si no hay tal gancho).

VALOR DEVUELTO

Las rutinas que devuelven punteros devuelven NULL en caso de error. Otras rutinas devuelven uno de los siguientes:

E_OK
La rutina tuvo éxito.
E_SYSTEM_ERROR
Ocurrió un error del sistema (ver errno(3)).

PORTABILIDAD

Estas rutinas emulan la biblioteca de menús de System V. No fueron soportadas en las versiones 7 o BSD.
