MEMCHR(3P) Manual del programador POSIX MEMCHR(3P)

PRÓLOGO

Esta página del manual forma parte del Manual del programador POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual de Linux correspondiente para conocer los detalles del comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

memchr — encontrar byte en memoria

SINOPSIS

#include <string.h>
void *memchr(const void *s, int c, size_t n);

DESCRIPCIÓN

La funcionalidad descrita en esta página de referencia está alineada con el estándar ISO C. Cualquier conflicto entre los requisitos descritos aquí y el estándar ISO C es no intencional. Este volumen de POSIX.1‐2017 se remite al estándar ISO C.

La función memchr() localizará la primera aparición de c (convertido a unsigned char) en los n bytes iniciales (cada uno interpretado como unsigned char) apuntados por s.

Las implementaciones deberán comportarse como si leyeran la memoria byte a byte desde el principio de los bytes apuntados por s y se detuvieran en la primera aparición de c (si se encuentra en los n bytes iniciales).

VALOR DE RETORNO

La función memchr() devolverá un puntero al byte localizado, o un puntero nulo si el byte no se encuentra.

ERRORES

No se definen errores.
