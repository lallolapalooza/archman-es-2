DESCRIPCIÓN

La estructura de memcached_result_st ha sido encapsulada, no debes escribir código que acceda directamente a los miembros de la estructura.

memcached_result_create() asignará memoria para una memcached_result_st o inicializará una estructura que se le pase.

memcached_result_free() liberará cualquier memoria adjunta a la estructura. Si la estructura también fue asignada, la liberará.

memcached_result_key_value() devolverá el valor de la clave asociado con el objeto de resultado actual.

memcached_result_key_length() devolverá la longitud de la clave asociada con el objeto de resultado actual.

memcached_result_value() devolverá el valor del resultado asociado con el objeto de resultado actual.

memcached_result_take_value() devolverá el valor del resultado asociado con el objeto de resultado actual. A diferencia de memcached_result_value(), el puntero devuelto pertenece al llamador y no será liberado por memcached_result_free().

memcached_result_length() devolverá la longitud del valor del resultado asociado con el objeto de resultado actual.

memcached_result_flags() devolverá las banderas asociadas con el objeto de resultado actual.

memcached_result_cas() devolverá el valor CAS asociado con el objeto de resultado actual.

memcached_result_set_value() establecerá el valor y la longitud del objeto de resultado actual. Se espera que el valor asignado por el usuario permanezca válido hasta que el objeto de resultado se libere.

memcached_result_set_flags() establecerá las banderas del objeto de resultado actual.

memcached_result_set_expiration() establecerá el tiempo de expiración del objeto de resultado actual.

NAME

memcached_result_free, memcached_result_set_value, memcached_result_set_flags, memcached_result_set_expiration, memcached_result_key_value, memcached_result_key_length, memcached_result_value, memcached_result_take_value, memcached_result_length, memcached_result_flags, memcached_result_cas - manipulate result objects

SYNOPSIS

#include <libmemcached/memcached.h>

void memcached_result_free(memcached_result_st *ptr);
memcached_return_t memcached_result_set_value(memcached_result_st *ptr,
    const char *value, size_t length);
memcached_return_t memcached_result_set_flags(memcached_result_st *ptr,
    uint32_t flags);
memcached_return_t memcached_result_set_expiration(memcached_result_st *ptr,
    time_t expiration);
const char *memcached_result_key_value(const
    memcached_result_st *ptr);
size_t memcached_result_key_length(const memcached_result_st *ptr);
const char *memcached_result_value(const memcached_result_st *ptr);
char *memcached_result_take_value(memcached_result_st *ptr);
size_t memcached_result_length(const memcached_result_st *ptr);
uint32_t memcached_result_flags(const memcached_result_st *ptr);
uint64_t memcached_result_cas(const memcached_result_st *ptr);

DESCRIPTION

The memcached_result_st structure is used to hold the result of a memcached request. This structure is returned by several memcached functions such as memcached_get().

memcached_result_free() must be called on all memcached_result_st structures upon completion to release any allocated memory.

memcached_result_key_value() returns the key value associated with the current result object.

memcached_result_key_length() returns the key length associated with the current result object.

memcached_result_value() returns the result value associated with the current result object.

memcached_result_length() returns the result length associated with the current result object.

memcached_result_flags() returns the flags associated with the current result object.

memcached_result_cas() returns the cas associated with the current result object. This value will only be available if the server tests it.

memcached_result_set_value() takes a byte array and a size and sets the result to this value. This function is used for trigger responses.

memcached_result_set_flags() takes a result structure and stores a new value for the flags field.

memcached_result_set_expiration() takes a result structure and stores a new value for the expiration field (this is only used by read through triggers).

RETURN VALUE

Varies, see particular functions. All structures must have memcached_result_free() called on them for cleanup purposes. Failure to do this will result in leaked memory.
