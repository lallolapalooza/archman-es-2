DESCRIPCIÓN

libmemcached realiza operaciones sobre una lista de hosts. El orden de estos hosts determina el enrutamiento hacia las claves. Se proporcionan funciones para añadir claves a las estructuras memcached_st. Para manipular listas de servidores, consulta memcached_server_st.

memcached_server_count() proporciona un recuento del número actual de servidores que está utilizando una estructura memcached_st.

memcached_server_add() añade un único servidor TCP a la estructura memcached_st. Este servidor se colocará al final. Se permiten servidores duplicados, por lo que no se realiza ninguna comprobación de duplicación. La ejecución de esta función con el comportamiento MEMCACHED_BEHAVIOR_USE_UDP activado resultará en MEMCACHED_INVALID_HOST_PROTOCOL.

memcached_server_add_udp() añade un único servidor UDP a la estructura memcached_st. Este servidor se colocará al final. Se permiten servidores duplicados, por lo que no se realiza ninguna comprobación de duplicación. La ejecución de esta función sin el comportamiento MEMCACHED_BEHAVIOR_USE_UDP activado resultará en MEMCACHED_INVALID_HOST_PROTOCOL.

memcached_server_add_unix_socket() añade un único socket UNIX a la estructura memcached_st. Este socket UNIX se colocará al final. Se permiten sockets duplicados, por lo que no se realiza ninguna comprobación de duplicación. La longitud del nombre de archivo debe ser un carácter menos que MEMCACHED_MAX_HOST_LENGTH.

memcached_server_cursor.3.en

NAME

memcached_server_cursor, memcached_server_by_key, memcached_server_get_last_disconnect - Iterate over server list

SYNOPSIS

All functions below are related to server lists.

#include <libmemcached/memcached.h>
memcached_server_st *memcached_server_by_key(memcached_st *ptr, const char *key, size_t key_length);
memcached_server_st *memcached_server_get_last_disconnect(memcached_st *ptr);
memcached_return_tmemcached_server_cursor(memcached_st *ptr, memcached_server_fn *callbacks, void *context);

DESCRIPTION

The functions below are used to iterate over the list of servers associated with a memcached_st structure.

memcached_server_cursor() takes a memcached_st structure and a list of callback functions. It will iterate over the list of servers stored within the memcached_st structure and call the provided callback functions for each server. The list of servers is a clone of the original list, so any changes made to the list will not affect the original structure. The context parameter can be used to pass data to the callback functions. The iteration stops if any callback function returns an error.

memcached_server_by_key() allows you to provide a key and retrieve the server which would be used for assignment.

memcached_server_get_last_disconnect() returns a pointer to the last server for which there was a connection problem. It does not mean this particular server is currently dead but if the library is reporting a server is, the returned server is a very good candidate.

memcached_server_cursor() takes a memcached_st and loops through the list of hosts currently in the cursor calling the list of callback functions provided. You can optionally pass in a value via context which will be provided to each callback function. An error return from any callback will terminate the loop. memcached_server_cursor() is passed the original caller memcached_st in its current state.

RETURN VALUE

Varies, see particular functions.
