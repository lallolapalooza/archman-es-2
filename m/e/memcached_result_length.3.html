DESCRIPCIÓN

La estructura de memcached_result_st ha sido encapsulada, no debe escribir código que acceda directamente a los miembros de la estructura.

memcached_result_create() asignará memoria para una memcached_result_st o inicializará una estructura que se le pase.

memcached_result_free() liberará cualquier memoria adjunta a la estructura. Si la estructura también fue asignada, la liberará.

DESCRIPCIÓN

memcached_result_key_value() devuelve el valor de la clave asociado con el objeto de resultado actual.

memcached_result_key_length() devuelve la longitud de la clave asociada con el objeto de resultado actual.

memcached_result_value() devuelve el valor del resultado asociado con el objeto de resultado actual.

memcached_result_length() devuelve la longitud del resultado asociada con el objeto de resultado actual.

memcached_result_flags() devuelve las marcas asociadas con el objeto de resultado actual.

memcached_result_cas() devuelve el valor CAS asociado con el objeto de resultado actual. Este valor solo estará disponible si el servidor lo prueba.

memcached_result_set_value() toma un array de bytes y un tamaño y establece el resultado a este valor. Esta función se utiliza para activar respuestas.

memcached_result_set_flags() toma una estructura de resultado y almacena un nuevo valor para el campo de marcas.

memcached_result_set_expiration() toma una estructura de resultado y almacena un nuevo valor para el campo de expiración (esto solo lo utilizan los desencadenadores de lectura).

VALOR DE RETORNO

Varía, ver funciones particulares. Se debe llamar a memcached_result_free() en todas las estructuras para fines de limpieza. No hacerlo resultará en fugas de memoria.
