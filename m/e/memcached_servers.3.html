DESCRIPCIÓN

libmemcached realiza operaciones sobre una lista de hosts. El orden de estos hosts determina el enrutamiento a las claves. Se proporcionan funciones para añadir claves a las estructuras memcached_st. Para manipular listas de servidores, consulta memcached_server_st.

memcached_server_count() te proporciona un recuento del número actual de servidores que está utilizando una estructura memcached_st.

memcached_server_add() añade un único servidor TCP a la estructura memcached_st. Este servidor se colocará al final. Se permiten servidores duplicados, por lo que no se comprueba si ya existen. La ejecución de esta función con el comportamiento MEMCACHED_BEHAVIOR_USE_UDP activado dará como resultado un MEMCACHED_INVALID_HOST_PROTOCOL.

memcached_server_add_udp() añade un único servidor UDP a la estructura memcached_st. Este servidor se colocará al final. Se permiten servidores duplicados, por lo que no se comprueba si ya existen. La ejecución de esta función sin activar el comportamiento MEMCACHED_BEHAVIOR_USE_UDP dará como resultado un MEMCACHED_INVALID_HOST_PROTOCOL.

memcached_server_add_unix_socket() añade un único socket UNIX a la estructura memcached_st. Este socket UNIX se colocará al final. Se permiten servidores duplicados, por lo que no se comprueba si ya existen. La longitud del nombre de archivo debe ser un carácter menos que MEMCACHED_MAX_HOST_LENGTH.

memcached_server_push() añade un array de memcached_server_st a la estructura memcached_st. Estos servidores se colocarán

DESCRIPTION

This section details the functions for managing the list of servers that a memcached_st structure will interact with.

memcached_server_add() adds a server to the list of servers. The server is identified by its hostname and port.

memcached_server_add_parse() adds a server to the list of servers using a string format such as “hostname:port”.

memcached_server_add_udp() adds a server to the list of servers to be communicated with via UDP.

memcached_server_add_unix() adds a server to the list of servers using a Unix domain socket.

memcached_server_clone() copies the server list from one memcached_st structure to another.

memcached_server_remove() removes a server from the list of servers.

memcached_server_remove_by_key() removes a server from the list of servers based on a key.

memcached_servers_reset() clears the list of servers from the memcached_st structure.

memcached_server_by_key() allows you to provide a key and retrieve the server which would be used for assignment.

memcached_server_get_last_disconnect() returns a pointer to the last server for which there was a connection problem. It does not mean this particular server is currently dead but if the library is reporting a server is, the returned server is a very good candidate.

memcached_server_cursor() takes a memcached_st and loops through the list of hosts currently in the cursor calling the list of callback functions provided. You can optionally pass in a value via context which will be provided to each callback function. An error return from any callback will terminate the loop. memcached_server_cursor() is passed the original caller memcached_st in its current state.

RETURN VALUE

Varies, see particular functions.
