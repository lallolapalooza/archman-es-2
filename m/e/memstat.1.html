NOMBRE

memstat - Documentación de libmemcached

SINOPSIS

memstat [opciones] [argumentos_stat]

Recopilar estadísticas de un servidor

DESCRIPCIÓN

OPCIONES

-h|--help
Mostrar ayuda.
-V|--version
Mostrar versión.
-q|--quiet
Operar en silencio.
-v|--verbose
Operar de forma más detallada.
-d|--debug
Ver -v|--verbose.
-s|--servers <lista de servidores>
Especificar la lista de servidores como hostname[:puerto][,hostname[:puerto]...].
-n|--non-blocking
Habilitar operaciones no bloqueantes.
-N|--tcp-nodelay
Deshabilitar el algoritmo de Nagle.
-b|--binary
Habilitar protocolo binario.
-B|--buffer
Almacenar solicitudes en búfer.
-u|--username <nombre_usuario>
Usar nombre_usuario para autenticación SASL.
-p|--password <contraseña>
Usar contraseña para autenticación SASL.
-A|--args <stat>
Argumentos de estadísticas.

OBSOLETO: usar argumentos posicionales.

-a|--analyze [<arg>]
Analizar e imprimir diferencias de un clúster de servidores. Se realiza una comparación de memoria y tiempo de actividad por defecto.

Opciones:

--analyze[=default]
Comparación de memoria y tiempo de actividad.
--analyze=latencia
Comparación de latencia de red.
-S|-server-version
Obtener e imprimir solo la(s) versión(es) del servidor.
--iterations
Número de iteraciones de GETs enviadas por la prueba de latencia (por defecto: 1000).

ENTORNO

MEMCACHED_SERVERS
Especificar una lista de servidores.

NOTAS

PREFIJO DEL PROGRAMA

El prefijo de este programa es variable, es decir, se puede configurar en el momento de la compilación.

Normalmente, los programas cliente de libmemcached-awesome tienen el prefijo mem, como memcat o memcp.

Sin embargo, se puede configurar para reemplazar el prefijo con otra cosa como mc, en cuyo caso, los programas cliente de libmemcached-awesome se llamarían mccat, mccp, etc., respectivamente.

VER TAMBIÉN

  • Biblioteca cliente C/C++ para memcached
  • Trabajar con información estadística de un servidor
