NOMBRE

memcached_decrement - Incremento y decremento de valores

SINOPSIS

#include <libmemcached/memcached.h>
Compilar y enlazar con -lmemcached
memcached_return_t memcached_increment(memcached_st *ptr, const char *key, size_t key_length, uint32_t offset, uint64_t *value)
memcached_return_t memcached_decrement(memcached_st *ptr, const char *key, size_t key_length, uint32_t offset, uint64_t *value)
memcached_return_t memcached_increment_with_initial(memcached_st *ptr, const char *key, size_t key_length, uint64_t offset, uint64_t initial, time_t expiration, uint64_t *value)
memcached_return_t memcached_decrement_with_initial(memcached_st *ptr, const char *key, size_t key_length, uint64_t offset, uint64_t initial, time_t expiration, uint64_t *value)
memcached_return_t memcached_increment_by_key(memcached_st *ptr, const char *group_key, size_t group_key_length, const char *key, size_t key_length, uint32_t offset, uint64_t *value)
memcached_return_t memcached_decrement_by_key(memcached_st *ptr, const char *group_key, size_t group_key_length, const char *key, size_t key_length, uint32_t offset, uint64_t *value)
memcached_return_t memcached_increment_with_initial_by_key(memcached_st *ptr, const char *group_key, size_t group_key_length, const char *key, size_t key_length, uint64_t offset, uint64_t initial, time_t expiration, uint64_t *value)
memcached_return_t memcached_decrement_with_initial_by_key(memcached_st *ptr, const char *group_key, size_t group_key_length, const char *key, size_t key_length, uint64_t offset, uint64_t initial, time_t expiration, uint64_t *value)
Parámetros
  • ptr -- puntero a una estructura memcached_st inicializada
  • group_key -- namespace de la clave
  • group_key_length -- longitud del namespace de la clave sin ningún cero terminador
  • key -- la clave
  • key_length -- longitud de la clave sin ningún cero terminador
  • offset -- desplazamiento a incrementar/decrementar
  • initial -- valor inicial si la key no existe y la expiration no es MEMCACHED_EXPIRATION_NOT_ADD
  • expiration -- expiración como marca de tiempo unix o como tiempo de expiración relativo en segundos
  • value -- el valor resultante después de la inicialización/incremento/decremento
Retorna
memcached_return_t indicando éxito

DESCRIPCIÓN

memcached_increment() toma una key y key_length e incrementa el valor por el offset que se le pasa. El valor se devuelve luego a través del puntero uint32_t value que le pasas.

memcached_decrement() toma una key y key_length y decrementa el valor por el offset que se le pasa. El valor se devuelve luego a través del puntero uint32_t value que le pasas.

memcached_increment_with_initial() toma una key y key_length e incrementa el valor por el offset que se le pasa. Si el objeto especificado por key no existe, puede ocurrir una de dos cosas: Si el valor de expiration es MEMCACHED_EXPIRATION_NOT_ADD, la operación fallará. Para todos los demás valores de expiration, la operación tendrá éxito al sembrar el valor para esa clave con un valor inicial para que expire con el tiempo de expiración proporcionado. Las flags se establecerán a cero. El valor se devuelve luego a través del puntero uint32_t value que le pasas. memcached_increment_with_initial solo está disponible cuando se usa el protocolo binario.

memcached_decrement_with_initial() toma una key y key_length y decrementa el valor por el offset que se le pasa. Si el objeto especificado por key no existe, puede ocurrir una de dos cosas: Si el valor de expiration es MEMCACHED_EXPIRATION_NOT_ADD, la operación fallará. Para todos los demás valores de expiration, la operación tendrá éxito al sembrar el valor para esa clave con un valor inicial para que expire con el tiempo de expiración proporcionado. Las flags se establecerán a cero. El valor se devuelve luego a través del puntero uint32_t value que le pasas. memcached_decrement_with_initial() solo está disponible cuando se usa el protocolo binario.

memcached_increment_by_key(), memcached_decrement_by_key(), memcached_increment_with_initial_by_key(), y memcached_decrement_with_initial_by_key() son equivalentes de clave maestra de las anteriores.

VALOR DE RETORNO

Se devuelve un valor de tipo memcached_return_t. En caso de éxito, ese valor será MEMCACHED_SUCCESS. Usa memcached_strerror() para traducir este valor a una cadena imprimible.

Descripción

La función memcached_decrement se utiliza para decrementar el valor de un contador numérico en el servidor memcached. El parámetro offset especifica la cantidad a decrementar.

Valor de retorno

La función devuelve memcached_success si la operación se completó correctamente. En caso contrario, devuelve uno de los siguientes valores:

  • memcached_not_found: La clave no se encontró en el servidor.
  • memcached_error: Se produjo un error durante la operación.
  • memcached_server_error: El servidor memcached devolvió un error.
