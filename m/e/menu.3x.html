menu(3X) Llamadas de biblioteca menu(3X)

NOMBRE

menu - extensión de curses para programar menús

SINOPSIS

#include <menu.h>

DESCRIPCIÓN

La biblioteca menu proporciona instalaciones independientes del terminal para componer sistemas de menús en terminales de celdas de caracteres. La biblioteca incluye: rutinas de ítems, que crean y modifican ítems de menú; y rutinas de menú, que agrupan ítems en menús, muestran menús en la pantalla y manejan la interacción con el usuario.

La biblioteca menu utiliza las bibliotecas curses, y una rutina de inicialización de curses como initscr debe ser llamada antes de usar cualquiera de estas funciones. Para usar la biblioteca menu, enlace con las opciones -lmenu -lcurses.

Valores predeterminados actuales para atributos de ítem

La biblioteca menu mantiene un valor predeterminado para los atributos de los ítems. Puede obtener o establecer este valor predeterminado llamando a la rutina get_ o set_ apropiada con un puntero de ítem NULL. Cambiar este valor predeterminado con una función set_ afecta a las creaciones de ítems futuras, pero no cambia la representación de los ítems ya creados.

VALOR DE RETORNO

Las rutinas que devuelven punteros devuelven NULL en caso de error. Las rutinas que devuelven un entero devuelven uno de los siguientes códigos de error:

E_OK
La rutina tuvo éxito.
E_BAD_ARGUMENT
La rutina detectó un argumento incorrecto o fuera de rango.
E_BAD_STATE
La rutina fue llamada desde una función de inicialización o terminación.
E_NO_MATCH
No se encontró ninguna coincidencia (utilizado por menu_pattern).
E_NOT_POSTED
El menú no está publicado (utilizado por menu_driver).
E_UNKNOWN_COMMAND
El comando especificado no es válido (utilizado por menu_driver).
E_OBJ_NOT_INIT
El objeto (menú o ítem) no está inicializado.
E_OBJ_NONEXISTENT
El objeto no existe.
E_PROJECTION_FAILED
Error al proyectar el menú en la ventana.
E_SYSTEM_ERROR
Error del sistema.

E_UNKNOWN_COMMAND

NOTAS

El archivo de cabecera menu.h incluye el archivo de cabecera curses.h.

PORTABILIDAD

Estas rutinas emulan la biblioteca de menú de System V. No fueron soportadas en las versiones Version 7 o BSD.

Una instalación de menú fue documentada en el documento de programación de interfaz de usuario de caracteres de SVr4.2.

No es parte de X/Open Curses.

Aparte de ncurses, hay pocas implementaciones:

  • sistemas basados en el código fuente de SVr4, por ejemplo, Solaris.
  • NetBSD curses.
