NOMBRE

set_menu_pattern, menu_pattern - establecer y obtener el búfer de patrón de un menú

SINOPSIS

#include <menu.h>
int set_menu_pattern(MENU *menu, const char *pattern);
char *menu_pattern(const MENU *menu);

DESCRIPCIÓN

Cada menú tiene un búfer de coincidencia de patrón asociado. A medida que llegan eventos de entrada que son caracteres imprimibles, se añaden a este búfer de coincidencia y se prueban para ver si coinciden, como se describe en menu_driver(3X).

La función set_menu_pattern establece el búfer de patrón para el menú dado y trata de encontrar el primer elemento coincidente. Si tiene éxito, ese elemento se convierte en actual; si no, el elemento actual no cambia.

La función menu_pattern devuelve el búfer de patrón del menú dado.

VALOR DE RETORNO

La función menu_pattern devuelve un puntero, que es NULL si el parámetro menu es NULL. De lo contrario, es un puntero a una cadena que está vacía si no se ha establecido ningún patrón. No establece errno.

La función set_menu_pattern puede devolver los siguientes códigos de error:

E_OK
La rutina tuvo éxito.
E_BAD_ARGUMENT
La rutina detectó un argumento incorrecto o fuera de rango.
E_BAD_STATE
La rutina fue llamada desde una función de inicialización o terminación.
E_NOT_CONNECTED
No hay elementos conectados al menú.
E_NO_MATCH
El carácter no coincidió.
E_SYSTEM_ERROR
Ocurrió un error del sistema (consulte errno(3)).

PORTABILIDAD

Estas rutinas emulan la biblioteca de menús de System V. No fueron soportadas en las versiones 7 o BSD.
