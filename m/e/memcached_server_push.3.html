DESCRIPCIÓN

libmemcached realiza operaciones sobre una lista de hosts. El orden de estos hosts determina el enrutamiento a las claves. Se proporcionan funciones para añadir claves a las estructuras memcached_st. Para manipular listas de servidores, consulte memcached_server_st.

memcached_server_count() le proporciona un recuento del número actual de servidores que está utilizando una estructura memcached_st.

memcached_server_add() inserta un único servidor TCP en la estructura memcached_st. Este servidor se colocará al final. Se permiten servidores duplicados, por lo que no se realiza una comprobación de duplicación. La ejecución de esta función con el comportamiento MEMCACHED_BEHAVIOR_USE_UDP establecido dará como resultado un MEMCACHED_INVALID_HOST_PROTOCOL.

memcached_server_add_udp() inserta un único servidor UDP en la estructura memcached_st. Este servidor se colocará al final. Se permiten servidores duplicados, por lo que no se realiza una comprobación de duplicación. La ejecución de esta función sin establecer el comportamiento MEMCACHED_BEHAVIOR_USE_UDP dará como resultado un MEMCACHED_INVALID_HOST_PROTOCOL.

memcached_server_add_unix_socket() inserta un único socket UNIX en la estructura memcached_st. Este socket UNIX se colocará al final. Se permiten sockets duplicados, por lo que no se realiza una comprobación de duplicación. La longitud del nombre de archivo debe ser un carácter menos que MEMCACHED_MAX_HOST_LENGTH.

NAME

memcached_server_push, memcached_server_push_udp, memcached_server_by_key, memcached_server_get_last_disconnect, memcached_server_cursor - Add server to server list

SYNOPSIS

cc ... -lmemcached

#include <memcached.h>

memcached_return_t memcached_server_push(memcached_st *memc, const char *str);
memcached_return_t memcached_server_push_udp(memcached_st *memc, const char *str);
char *memcached_server_by_key(memcached_st *memc, const char *key, size_t key_length, memcached_return_t *error);
memcached_server_instance_st *memcached_server_get_last_disconnect(memcached_st *memc);
void memcached_server_cursor(memcached_st *memc, memcached_server_fn *function, void *context, uint32_t num_callbacks);

DESCRIPTION

These functions are used to manage the list of servers that the memcached_st structure will use to store and retrieve values.

memcached_server_push() adds a server to the list of servers that will be used by the memcached_st structure. The string is a NULL terminated string in the format of "host:port" or "host:port\nhost2:port2".

memcached_server_push_udp() adds a server to the list of servers that will be used by the memcached_st structure, but it forces the server to be added as a UDP server. The string is a NULL terminated string in the format of "host:port" or "host:port\nhost2:port2".

memcached_server_by_key() returns the server instance that would be used for the given key. This is useful for debugging and for understanding how the hashing algorithm works. The value returned is a pointer into the memcached_st structure, and is NOT valid if the memcached_st structure is destroyed, or if servers are added or removed.

memcached_server_get_last_disconnect() returns a pointer to the last server for which there was a connection problem. It does not mean this particular server is currently dead but if the library is reporting a server is, the returned server is a very good candidate.

memcached_server_cursor() takes a memcached_st and loops through the list of hosts currently in the cursor calling the list of callback functions provided. You can optionally pass in a value via context which will be provided to each callback function. An error return from any callback will terminate the loop. memcached_server_cursor() is passed the original caller memcached_st in its current state.

RETURN VALUE

Varies, see particular functions.

NOMBRE

memcached_server_push, memcached_server_push_udp, memcached_server_by_key, memcached_server_get_last_disconnect, memcached_server_cursor - Añadir servidor a la lista de servidores

SINOPSIS

cc ... -lmemcached

#include <memcached.h>

memcached_return_t memcached_server_push(memcached_st *memc, const char *str);
memcached_return_t memcached_server_push_udp(memcached_st *memc, const char *str);
char *memcached_server_by_key(memcached_st *memc, const char *key, size_t key_length, memcached_return_t *error);
memcached_server_instance_st *memcached_server_get_last_disconnect(memcached_st *memc);
void memcached_server_cursor(memcached_st *memc, memcached_server_fn *function, void *context, uint32_t num_callbacks);

DESCRIPCIÓN

Estas funciones se utilizan para gestionar la lista de servidores que la estructura memcached_st utilizará para almacenar y recuperar valores.

memcached_server_push() añade un servidor a la lista de servidores que será utilizada por la estructura memcached_st. La cadena es una cadena terminada en NULL en el formato "host:puerto" o "host:puerto\nhost2:puerto2".

memcached_server_push_udp() añade un servidor a la lista de servidores que será utilizada por la estructura memcached_st, pero fuerza a que el servidor se añada como un servidor UDP. La cadena es una cadena terminada en NULL en el formato "host:puerto" o "host:puerto\nhost2:puerto2".

memcached_server_by_key() devuelve la instancia del servidor que se utilizaría para la clave dada. Esto es útil para la depuración y para comprender cómo funciona el algoritmo de hash. El valor devuelto es un puntero dentro de la estructura memcached_st, y NO es válido si la estructura memcached_st se destruye, o si se añaden o eliminan servidores.

memcached_server_get_last_disconnect() devuelve un puntero al último servidor con el que hubo un problema de conexión. No significa que este servidor en particular esté actualmente inactivo, pero si la biblioteca informa que un servidor lo está, el servidor devuelto es un candidato muy bueno.

memcached_server_cursor() toma un memcached_st y recorre la lista de hosts actualmente en el cursor llamando a la lista de funciones de callback proporcionadas. Opcionalmente, puede pasar un valor a través de un contexto que se proporcionará a cada función de callback. Un error devuelto por cualquier callback terminará el bucle. A memcached_server_cursor() se le pasa el memcached_st original del llamador en su estado actual.

VALOR DE RETORNO

Varía, ver funciones particulares.
