NOMBRE

memexist - Documentación de libmemcached

SINOPSIS

memexist [opciones] <clave>

Comprueba la existencia de una clave.

DESCRIPCIÓN

memexist comprueba la existencia de una clave dentro de un clúster.

OPCIONES

-h|--help
Muestra la ayuda.
-V|--version
Muestra la versión.
-q|--quiet
Opera en silencio.
-v|--verbose
Opera de forma más verbosa.
-d|--debug
Ver -v|--verbose.
-s|--servers <lista de servidores>
Especifica la lista de servidores como nombrehost[:puerto][,nombrehost[:puerto]...].
-n|--non-blocking
Habilita operaciones no bloqueantes.
-N|--tcp-nodelay
Deshabilita el algoritmo de Nagle.
-b|--binary
Habilita el protocolo binario.
-B|--buffer
Almacena las solicitudes en búfer.
-u|--username <nombredeusuario>
Usa nombredeusuario para la autenticación SASL.
-p|--password <contraseña>
Usa contraseña para la autenticación SASL.
-H|--hash <algoritmo>
Usa algoritmo como algoritmo de hash de clave. Ver memcached_behavior_t::MEMCACHED_BEHAVIOR_HASH.

AMBIENTE

MEMCACHED_SERVERS
Especifica una lista de servidores.

NOTAS

PREFIJO DEL PROGRAMA

El prefijo de este programa es variable, es decir, puede configurarse en el momento de la compilación.

Normalmente, los programas cliente de libmemcached-awesome comienzan con el prefijo mem, como memcat o memcp.

Sin embargo, se puede configurar para reemplazar el prefijo por otra cosa, como mc, en cuyo caso, los programas cliente de libmemcached-awesome se llamarían mccat, mccp, etc. respectivamente.
