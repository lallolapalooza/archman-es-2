DESCRIPCIÓN

memcached_pool() se utiliza para crear un pool de conexiones de objetos que puedes usar para eliminar la sobrecarga de usar memcached_clone para objetos memcached_st de corta duración. Consulta Configuración de libmemcached para obtener detalles sobre el formato de la cadena de configuración.

memcached_pool_destroy() se utiliza para destruir el pool de conexiones creado con memcached_pool_create() y liberar todos los recursos asignados. Devolverá el puntero a la estructura memcached_st pasada como argumento a memcached_pool_create(), y devolverá la propiedad del puntero al llamador cuando se creó con memcached_pool_create(), de lo contrario, se devuelve NULL.

memcached_pool_fetch() se utiliza para obtener una estructura de conexión del pool de conexiones. El argumento relative_time especifica si la función debe bloquear y esperar a que una estructura de conexión esté disponible si intentamos exceder el tamaño máximo. Debes especificar el tiempo en tiempo relativo.

memcached_pool_release() se utiliza para devolver una estructura de conexión al pool.

memcached_pool_behavior_get() y memcached_pool_behavior_set() se utilizan para obtener/establecer banderas de comportamiento en todas las conexiones del pool.

Tanto memcached_pool_release() como memcached_pool_fetch() son seguros para hilos.

VALOR DEVUELTO

memcached_pool_destroy() devuelve el puntero (y la propiedad) a la estructura memcached_st utilizada para crear el pool. Si hay conexiones en uso, devuelve NULL.

memcached_pool_pop() devuelve un puntero a una estructura memcached_st del pool (o NULL si no se puede satisfacer una asignación).

memcached_pool_release() devuelve MEMCACHED_SUCCESS en caso de éxito.

memcached_pool_behavior_get() y memcached_pool_behavior_get() devuelven MEMCACHED_SUCCESS en caso de éxito.

memcached_pool_fetch() puede devolver MEMCACHED_TIMEOUT si ocurre un tiempo de espera mientras se espera una instancia memcached_st libre, MEMCACHED_NOTFOUND si no había ninguna instancia memcached_st disponible, respectivamente.

NOTA:

Si algún método devuelve MEMCACHED_IN_PROGRESS, entonces no se pudo obtener un bloqueo en el pool.

VER VALOR

Retorna MEMCACHED_INVALID_ARGUMENTS.

memcached_return_t memcached_pool_fetch(memcached_pool_st *pool);

DESCRIPCIÓN

La función memcached_pool_fetch recupera una conexión de la piscina.

Si la piscina está vacía, esta función bloqueará hasta que una conexión esté disponible o hasta que ocurra un tiempo de espera.

VALOR RETORNADO

La función memcached_pool_fetch retorna el valor memcached_return_t de la operación realizada. Si la operación es exitosa, retornará MEMCACHED_SUCCESS.

Los posibles valores de error incluyen:

  • MEMCACHED_POOL_FAILURE: La piscina no pudo ser inicializada.
  • MEMCACHED_TIMEOUT: Se agotó el tiempo de espera para obtener una conexión.
  • MEMCACHED_INVALID_ARGUMENTS: Se retornará si se pasan argumentos no válidos.
