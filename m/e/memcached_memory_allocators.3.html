DESCRIPCIÓN

libmemcached te permite especificar tus propias funciones de asignación de memoria, optimizadas para tu aplicación. Esto permite que libmemcached se utilice dentro de aplicaciones que tienen su propia implementación de malloc.

memcached_set_memory_allocators() se utiliza para establecer las funciones de asignación de memoria utilizadas por la instancia de memcached especificada por ptr. Ten en cuenta que no puedes sobrescribir solo una de las funciones de asignación de memoria, debes proporcionar un conjunto completo nuevo si deseas sobrescribir una de ellas. Todas las funciones de asignación de memoria deben comportarse según lo especificado en el estándar C99. Especifica NULL en todas las funciones para restablecerlas a los valores predeterminados.

memcached_get_memory_allocators() se utiliza para obtener las funciones de asignación de memoria actualmente utilizadas por un manejador de memcached.

memcached_get_memory_allocators_context() devuelve el void * que se pasó durante la llamada a memcached_set_memory_allocators().

El primer argumento de las funciones de asignación de memoria es un puntero a una estructura memcached, que se pasa como constante y necesitarás clonarla para poder utilizar cualquier operación que la modifique.

NOTAS

En la versión 0.38, todas las funciones se modificaron para tener un puntero void de contexto pasado a ellas. Esto fue para que los asignadores personalizados pudieran tener su propio espacio para la memoria.

VALOR DE RETORNO

memcached_set_memory_allocators() devuelve MEMCACHED_SUCCESS en caso de éxito, y MEMCACHED_FAILURE si no proporcionas un conjunto completo de punteros de función.
