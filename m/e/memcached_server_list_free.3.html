DESCRIPCIÓN

libmemcached opera sobre una lista de hosts que se almacenan en estructuras memcached_server_st. No debes modificar estas estructuras directamente. Se proporcionan funciones para modificar estas estructuras.

memcached_server_list() se utiliza para proporcionar una matriz de todos los hosts definidos. Esto se documentó incorrectamente como "requiere liberación" hasta la versión 0.39.

memcached_server_list_free() libera toda la memoria asociada con la matriz de memcached_server_st que le pasaste.

memcached_server_list_append() añade un servidor al final de una matriz memcached_server_st. En caso de error, se devolverá null y el puntero memcached_return_t que pasaste a la función se establecerá con el error apropiado. Si el valor del puerto es cero, se establece en el puerto predeterminado de un servidor memcached.

OBSOLETO memcached_servers_parse(), por favor ver memcached()

memcached_server_error() se puede utilizar para ver el texto del último mensaje de error enviado por el servidor al cliente.

Antes de la versión 0.39, estas funciones utilizaban un memcached_server_st *. En 0.39, memcached_server_st * se aliasó a memcached_server_list_st. Esto se hizo por motivos de estilo para ayudar a limpiar algunos conceptos en el código.
