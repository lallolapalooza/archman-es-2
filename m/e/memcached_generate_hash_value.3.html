NOMBRE

memcached_generate_hash_value - Generación directa de valores hash

Generar hash de un valor clave

SINOPSIS

#include <libmemcached/memcached.h>
Compila y enlaza con -lmemcachedutil -lmemcached
uint32_t memcached_generate_hash_value(const char *key, size_t key_length, memcached_hash_t hash_algorithm)
Parámetros
  • key -- la clave para generar el hash
  • key_length -- la longitud de la key sin ningún terminador cero
  • hash_algorithm -- memcached_hash_t, el algoritmo a usar
Devuelve
un valor hash de 32 bits
uint32_t memcached_generate_hash(memcached_st *ptr, const char *key, size_t key_length)
Parámetros
  • ptr -- puntero a una estructura memcached_st inicializada
  • key -- la clave para generar el hash
  • key_length -- la longitud de la key sin ningún terminador cero
Devuelve
un valor hash de 32 bits

DESCRIPCIÓN

memcached_generate_hash_value() te permite generar un hash de una clave utilizando una de las funciones hash definidas en la librería. Este método se proporciona para la conveniencia de los enlaces de lenguaje de nivel superior y no es necesario para las operaciones normales de memcache.

El soporte para MEMCACHED_HASH_HSIEH es una opción de tiempo de compilación que está deshabilitada por defecto. Para habilitar las pruebas para este algoritmo de hash, configura y compila libmemcached con el hash Hsieh habilitado.

memcached_generate_hash() toma una estructura memcached_st y produce el valor hash que se habría generado basándose en los valores por defecto de memcached_st.

A partir de la versión 0.36, todos los métodos hash se han incluido en la librería libhashkit(3), que se enlaza con libmemcached(3). Para más información, consulta su documentación.

VALOR DE RETORNO

Un entero de 32 bits que es el resultado de generar el hash de la clave dada. Para los algoritmos hash de 64 bits, solo se devuelven los 32 bits menos significativos.
