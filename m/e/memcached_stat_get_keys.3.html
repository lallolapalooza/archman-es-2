DESCRIPCIÓN

memcached_stat_execute() utiliza los servidores encontrados en memcached_stat_st y ejecuta un comando "stat" en cada servidor. args es un argumento opcional que se puede pasar para modificar el comportamiento de "stats". Deberá proporcionar una función de devolución de llamada que recibirá cada par de valores devueltos por el servidor memcached.

memcached_stat() recupera una matriz de estructuras memcached_stat_st que contienen el estado de todos los servidores memcached disponibles. El valor de retorno debe ser liberado por la aplicación que llama. Si se llama con el comportamiento MEMCACHED_BEHAVIOR_USE_UDP activado, se devuelve un valor NULL y el parámetro de error se establece en MEMCACHED_NOT_SUPPORTED.

memcached_stat_servername() se puede utilizar de forma independiente sin una memcached_st para obtener el estado de un servidor en particular. "args" se utiliza para definir un objeto de estado particular (una lista de estos no es proporcionada por la llamada memcached_stat_get_keys() ni están definidos en el protocolo memcached). Debe especificar el nombre de host y el puerto del servidor del que desea obtener información.

memcached_stat_get_value() devuelve el valor de una clave de estado en particular. Usted especifica la clave que desea obtener. La clave debe terminar en nulo.

memcached_stat_get_keys() devuelve una lista de claves sobre las que el servidor tiene objetos de estado. Usted es responsable de liberar esta lista.

Se proporciona una herramienta de línea de comandos, memstat, para que no tenga que escribir una aplicación para hacerlo.

memcached_strerror

libmemcached API - February 25, 2022

NAME

memcached_strerror - Return a string describing the error code.

SYNOPSIS

#include <libmemcached/types.h>

char * memcached_strerror(memcached_return_t rc);

DESCRIPTION

The memcached_strerror() function shall return a pointer to a string describing the error code passed in the rc argument.

The return value is a pointer to a static string. The caller must not modify this string.

RETURN VALUE

On success, memcached_strerror() returns a pointer to the error string. If the error code is unknown, it returns a pointer to a string "Unknown error code".
