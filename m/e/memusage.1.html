memusage(1) Manual de comandos generales memusage(1)

NOMBRE

memusage - perfila el uso de memoria de un programa

SINOPSIS

memusage [opción ...] programa [opción_programa ...]

DESCRIPCIÓN

memusage es un script de bash(1) que perfila el uso de memoria del programa, programa. Pre-carga la biblioteca libmemusage.so en el entorno del llamador (a través de la variable de entorno LD_PRELOAD; ver ld.so(8)). La biblioteca libmemusage.so rastrea la asignación de memoria interceptando llamadas a malloc(3), calloc(3), free(3), y realloc(3); opcionalmente, las llamadas a mmap(2), mremap(2), y munmap(2) también pueden ser interceptadas.

memusage puede producir los datos recopilados en forma textual, o puede usar memusagestat(1) (ver la opción -p, abajo) para crear un archivo PNG que contenga una representación gráfica de los datos recopilados.

Resumen del uso de memoria

La línea "Memory usage summary" producida por memusage contiene tres campos:

heap total
Suma de los argumentos size de todas las llamadas a malloc(3), productos de los argumentos (n*size) de todas las llamadas a calloc(3), y suma de los argumentos length de todas las llamadas a mmap(2). En el caso de realloc(3) y mremap(2), si el nuevo tamaño de una asignación es mayor que el tamaño anterior, se suma la suma de todas estas diferencias (nuevo tamaño menos tamaño antiguo).
heap peak
Máximo de todos los argumentos size de malloc(3), todos los productos de n*size de calloc(3), todos los argumentos size de realloc(3), los argumentos length de mmap(2), y los argumentos new_size de mremap(2).
stack peak
Antes de la primera llamada a cualquier función monitorizada, se guarda la dirección del puntero de pila (puntero de pila base). Después de cada llamada a función, se lee la dirección real del puntero de pila y se calcula la diferencia con el puntero de pila base. El máximo de estas diferencias es entonces el pico de la pila.

Inmediatamente después de esta línea de resumen, una tabla muestra el número de llamadas, la memoria total asignada o liberada, y el número de llamadas fallidas para cada función interceptada. Para realloc(3) y mremap(2), el campo adicional "nomove" muestra las reasignaciones que cambiaron la dirección de un bloque, y el campo adicional "dec" muestra las reasignaciones que disminuyeron el tamaño del bloque. Para realloc(3), el campo adicional "free" muestra las reasignaciones que causaron la liberación de un bloque (es decir, el tamaño reasignado fue 0).

La métrica "realloc/total memory" de la tabla producida por memusage no refleja los casos en los que realloc(3) se utiliza para reasignar un bloque de memoria a un tamaño menor que el anterior. Esto puede hacer que la suma de todas las celdas de "total memory" (excluyendo "free") sea mayor que la celda "free/total memory".

Histograma de tamaños de bloque

El "Histogram for block sizes" proporciona un desglose de las asignaciones de memoria en varios tamaños de grupo.

OPCIONES

-n nombre
--nombre_programa=nombre
Nombre del archivo del programa a perfilar.
-p archivo
--png=archivo
Genera un gráfico PNG y lo almacena en archivo.
-d archivo
--datos=archivo
Genera un archivo de datos binarios y lo almacena en archivo.
-u
--sin_buffer
No amortiguar la salida.
-b tamaño
--buffer=tamaño
Recopila tamaño entradas antes de escribirlas.
--sin-temporizador
Deshabilita el muestreo basado en tiempo (SIGPROF) del valor del puntero de pila.
-m
--mmap
También rastrea mmap(2), mremap(2), y munmap(2).
-?
--ayuda
Imprime la ayuda y sale.
--uso
Imprime un breve mensaje de uso y sale.
-V
--version
Imprime la información de la versión y sale.
Las siguientes opciones se aplican solo al generar salida gráfica:
-t
--basado-en-tiempo
Utiliza el tiempo (en lugar del número de llamadas a función) como escala para el eje X.
-T
--total
También dibuja un gráfico del uso total de memoria.
--titulo=nombre
Utiliza nombre como título del gráfico.
-x tamaño
--tamano_x=tamaño
Hace que el gráfico tenga un ancho de tamaño píxeles.
-y tamaño
--tamano_y=tamaño
Hace que el gráfico tenga una altura de tamaño píxeles.

ESTADO DE SALIDA

El estado de salida de memusage es igual al estado de salida del programa perfilado.

ERRORES GRAVES

Para informar de errores graves, ver http://www.gnu.org/software/libc/bugs.html

EJEMPLOS

A continuación se muestra un programa simple que reasigna un bloque de memoria en ciclos que aumentan hasta un pico y luego reasignan cíclicamente la memoria en bloques más pequeños que regresan a cero. Después de compilar el programa y ejecutar los siguientes comandos, se puede encontrar un gráfico del uso de memoria del programa en el archivo memusage.png:


$ memusage --data=memusage.dat ./a.out;
...
Memory usage summary: heap total: 45200, heap peak: 6440, stack peak: 224
        total calls  total memory  failed calls
 malloc|         1           400             0
realloc|        40         44800             0  (nomove:40, dec:19, free:0)
 calloc|

Fuente del programa

#include <stdio.h>
#include <stdlib.h>
#define CYCLES 20
int
main(int argc, char *argv[])
{
    int i, j;
    size_t size;
    int *p;
    size = sizeof(*p) * 100;
    printf("malloc: %zu\n", size);
    p = malloc(size);
    for (i = 0; i < CYCLES; i++) {
        if (i < CYCLES / 2)
            j = i;
        else
            j--;
        size = sizeof(*p) * (j * 50 + 110);
        printf("realloc: %zu\n", size);
        p = realloc(p, size);
        size = sizeof(*p) * ((j + 1) * 150 + 110);
        printf("realloc: %zu\n", size);
        p = realloc(p, size);
    }
    free(p);
    exit(EXIT_SUCCESS);
}
