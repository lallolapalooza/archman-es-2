NOMBRE

memcached_fetch - Recuperar datos del servidor

SINOPSIS

#include <libmemcached/memcached.h>
Compilar y enlazar con -lmemcached
char *memcached_fetch(memcached_st *ptr, char *key, size_t *key_length, size_t *value_length, uint32_t *flags, memcached_return_t *error)
Obsoleto desde la versión 0.50: Usar memcached_fetch_result() en su lugar.

DESCRIPCIÓN

memcached_fetch() se utiliza para obtener un valor individual del servidor. Siempre se debe llamar a memcached_mget() antes de utilizar este método. Debe pasar una clave y su longitud para obtener el objeto.

Debe proporcionar tres variables de puntero que le darán el estado del objeto devuelto:

  • Un puntero uint32_t para contener las banderas que haya almacenado con el valor,
  • un puntero size_t que se rellenará con el tamaño del objeto, y
  • un puntero memcached_return_t para contener cualquier error.

El objeto se devolverá en caso de éxito y se devolverá NULL en caso de error.

MEMCACHED_END se devuelve en el valor de error cuando todos los objetos encontrados han sido devueltos. El valor final al alcanzar MEMCACHED_END es un puntero NULL.

Los valores devueltos por memcached_fetch() deben ser liberados por el llamador.

Todas las funciones anteriores no se prueban cuando se ha establecido el comportamiento MEMCACHED_BEHAVIOR_USE_UDP. Ejecutar cualquiera de estas funciones con este comportamiento activado resultará en la devolución de MEMCACHED_NOT_SUPPORTED, o para aquellas funciones que no devuelven un memcached_return_t, el parámetro de la función de error se establecerá en MEMCACHED_NOT_SUPPORTED.

VALOR DE RETORNO

memcached_fetch() establece error en MEMCACHED_END al concluir con éxito.

Se devolverá MEMCACHED_NOTFOUND si no se encontraron claves en absoluto.

MEMCACHED_KEY_TOO_BIG se establece en error siempre que se utilizó memcached_fetch() y la clave se estableció más grande que MEMCACHED_MAX_KEY, que era la clave más grande permitida para el servidor memcached ascii original.
