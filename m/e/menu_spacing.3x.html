Paquete: ncurses

Licencias: MIT-open-group

menu_spacing(3X) Llamadas a la biblioteca menu_spacing(3X)

NOMBRE

set_menu_spacing, menu_spacing - establecer y obtener el espaciado entre elementos de menú.

SINOPSIS

#include <menu.h>
int set_menu_spacing(MENU *menu,
                     int spc_description,
                     int spc_rows,
                     int spc_columns);
int menu_spacing(const MENU *menu,
                 int* spc_description,
                 int* spc_rows,
                 int* spc_columns);

DESCRIPCIÓN

La función set_menu_spacing establece la información de espaciado para el menú. Sus parámetros proporcionan la descripción y el tamaño (en filas y columnas).

spc_description
controla el número de espacios entre el nombre de un elemento y su descripción. No debe ser mayor que TABSIZE. El sistema de menús coloca el carácter de relleno en el medio de esta área de espaciado. Las partes restantes se rellenan con espacios.
spc_rows
controla el número de filas que se utilizan para un elemento. No debe ser mayor que 3. El sistema de menús inserta las líneas en blanco entre las filas de los elementos; estas líneas contendrán el carácter de relleno en las posiciones apropiadas.
spc_columns
controla el número de espacios en blanco entre columnas de elementos. No debe ser mayor que TABSIZE. Un valor de 0 para todos los valores de espaciado los restablece a los predeterminados, que es 1 para todos ellos.

La función menu_spacing devuelve la información de espaciado para el menú. Si un puntero es NULL, la información correspondiente simplemente no se devuelve.

VALOR DE RETORNO

Ambas rutinas devuelven E_OK si tienen éxito. set_menu_spacing puede devolver E_POSTED si el menú está publicado, o E_BAD_ARGUMENT si uno de los valores de espaciado está fuera de rango.

PORTABILIDAD

Estas rutinas son específicas de ncurses. No fueron soportadas en las implementaciones de la Versión 7, BSD o System V. Se recomienda que cualquier código que dependa de ellas se condicione usando NCURSES_VERSION.

AUTORES
