NOMBRE

memcached_mget_execute_by_key - Recuperación de datos del servidor

SINOPSIS

#include <libmemcached/memcached.h>

DESCRIPCIÓN

memcached_get() se utiliza para obtener un valor individual del servidor. Debes pasar una clave y su longitud para obtener el objeto. Debes proporcionar tres variables puntero que te darán el estado del objeto devuelto. Un puntero uint32_t para contener cualquier indicador que almacenaste con el valor, un puntero size_t que se llenará con el tamaño del objeto y un puntero memcached_return_t para mantener cualquier error. El objeto se devolverá en caso de éxito y se devolverá NULL en caso de fallo. Cualquier objeto devuelto por memcached_get() debe ser liberado por la aplicación que llama.

memcached_mget() se utiliza para seleccionar varias claves a la vez. Para operaciones de claves múltiples, siempre es más rápido usar esta función. Esta función siempre funciona de forma asíncrona.

Para recuperar datos después de una ejecución exitosa de memcached_mget(), necesitarás llamar a memcached_fetch_result(). Debes seguir llamando a esta función hasta que devuelva NULL (es decir, no más valores). Si necesitas salir en medio de una llamada a memcached_mget(), puedes ejecutar un memcached_quit(), aunque no es necesario.

memcached_fetch_result() se utiliza para obtener un valor individual del servidor. memcached_mget() siempre debe llamarse antes de usar este método. Debes pasar una clave y su longitud para obtener el objeto. Debes proporcionar tres variables puntero que te darán el estado del objeto devuelto. Un puntero uint32_t para contener cualquier indicador que almacenaste con el valor, un puntero size_t que se llenará con el tamaño del objeto y un puntero memcached_return_t para mantener cualquier error. El objeto se devolverá en caso de éxito y se devolverá NULL en caso de fallo. MEMCACHED_END es devuelto por el valor *error cuando todos los objetos encontrados han sido devueltos. El valor final después de MEMCACHED_END es nulo.

memcached_fetch_result() se utiliza para devolver una estructura memcached_result_st de un servidor memcached. El objeto resultante es compatible con versiones futuras de cambios en el servidor. Para más información, consulta la ayuda de memcached_result_st. Esta función asignará dinámicamente una estructura de resultado si no pasas una a la función.

memcached_fetch_execute() es una función de devolución de llamada para conjuntos de resultados. En lugar de devolverte los resultados para su procesamiento, pasa cada uno de los conjuntos de resultados a la lista de funciones que proporcionas. Pasa a la función un memcached_st que puede ser clonado para su uso en la función llamada (no se puede usar directamente). También pasa un conjunto de resultados que no necesita ser liberado. Finalmente, pasa un "contexto". Este es solo un puntero a una referencia de memoria que tú proporcionas a la función de llamada. Actualmente solo se pasa un valor a cada llamada de función. En el futuro, habrá una opción para permitir que esto sea un arreglo.

memcached_mget_execute() y memcached_mget_execute_by_key() son similares a memcached_mget(), pero pueden activar las devoluciones de llamada suministradas con conjuntos de resultados mientras envían las consultas. Si intentas realizar un multiget muy grande con memcached_mget(), podrías encontrarte con un bloqueo en el kernel del sistema operativo (fallará al escribir datos en el socket porque el búfer de entrada está lleno). memcached_mget_execute() resuelve este problema procesando algunos de los resultados antes de continuar enviando solicitudes. Ten en cuenta que esta función solo está disponible en el protocolo binario.

memcached_get_by_key() y memcached_mget_by_key() se comportan de manera similar a memcached_get() y memcached_mget(). La diferencia es que toman una clave maestra que se utiliza para determinar en qué servidor se almacenó un objeto si se utilizó particionamiento de claves para el almacenamiento.

Todas las funciones anteriores no se prueban cuando se ha establecido MEMCACHED_BEHAVIOR_USE_UDP. La ejecución de cualquiera de estas funciones con este comportamiento activado devolverá MEMCACHED_NOT_SUPPORTED, o para aquellas funciones que no devuelven un memcached_return_t, el parámetro de función de error se establecerá en MEMCACHED_NOT_SUPPORTED.

VALOR DE RETORNO

memcached_get() devolverá NULL en caso de error. Debes mirar el valor de error para determinar cuál fue el error real.

memcached_fetch_execute() devuelve MEMCACHED_SUCCESS si todas las claves fueron exitosas. Se devolverá MEMCACHED_NOTFOUND si no se encontró ninguna clave.

memcached_fetch_result() establece el error en MEMCACHED_END al concluir con éxito. Se devolverá MEMCACHED_NOTFOUND si no se encontró ninguna clave.

NAME

memcached_strerror - Get a string representation of a memcached error code.

SYNOPSIS

#include <libmemcached/memcached.h>

const char *memcached_strerror(memcached_return_t rc);

DESCRIPTION

The memcached_strerror function takes an error code returned from a memcached library call and returns a human-readable string representation of that error.

RETURN VALUE

Returns a pointer to a constant string describing the error code.
