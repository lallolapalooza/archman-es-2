Parámetros
  • ptr -- puntero a una estructura memcached_st inicializada
  • args -- objeto de estado particular a consultar

Devuelve
memcached_return_t indicando éxito

DESCRIPCIÓN

memcached_stat_execute() utiliza los servidores encontrados en memcached_stat_st y ejecuta un comando "stat" en cada servidor. args es un argumento opcional que se puede pasar para modificar el comportamiento de "stats". Deberá proporcionar una función de callback que recibirá cada par de valores devueltos por el servidor memcached.

memcached_stat() recupera una matriz de estructuras memcached_stat_st que contienen el estado de todos los servidores memcached disponibles. El valor de retorno debe ser liberado por la aplicación llamante. Si se llama con el comportamiento MEMCACHED_BEHAVIOR_USE_UDP activado, se devuelve un valor NULL y el parámetro de error se establece en MEMCACHED_NOT_SUPPORTED.

memcached_stat_servername() se puede usar de forma independiente sin una memcached_st para obtener el estado de un servidor en particular. "args" se utiliza para definir un objeto de estado particular (una lista de estos no está provista por la llamada memcached_stat_get_keys() ni definida en el protocolo memcached). Debe especificar el nombre de host y el puerto del servidor del que desea obtener información.

memcached_stat_get_value() devuelve el valor de una clave de estado particular. Especifica la clave que desea obtener. La clave debe estar terminada en nulo.

memcached_stat_get_keys() devuelve una lista de claves sobre las que el servidor tiene objetos de estado. Usted es responsable de liberar esta lista.

Se proporciona una herramienta de línea de comandos, memstat, para que no tenga que escribir una aplicación para hacer esto.

VALOR DEVUELTO

Varía, ver las funciones particulares.

Cualquier método que devuelva un memcached_stat_st espera que usted libere la memoria asignada para él.

libmemcached(3) — Arch Linux

NAME

memcached_stat - Retrieve memcached server statistics

SYNOPSIS

#include <libmemcached/memcached.h>

memcached_return_t memcached_stat(memcached_st *ptr,
                                  char *buffer, size_t *size);

memcached_stat_t *memcached_stat_get_struct(memcached_st *ptr,
                                            memcached_return_t *rc);

uint32_t memcached_stat_get_value(memcached_stat_t *ptr,
                                  memcached_stat_key_t key,
                                  memcached_return_t *rc);

char *memcached_stat_get_each(memcached_st *ptr,
                              memcached_server_instance_st *instance,
                              memcached_return_t *rc);

uint32_t memcached_stat_get_each_value(memcached_stat_t *ptr,
                                       memcached_server_instance_st *instance,
                                       memcached_stat_key_t key,
                                       memcached_return_t *rc);

void memcached_stat_free(memcached_stat_t *ptr);

DESCRIPTION

The memcached_stat() function is used to retrieve statistics from the memcached servers configured in the memcached_st structure. The statistics are stored in the provided buffer or, if a buffer is not provided, they are allocated by the library. The size parameter should be set to the size of the buffer on input and will be updated with the actual size of the statistics on output.

The memcached_stat_get_struct() function retrieves the statistics and returns them as a memcached_stat_t structure. This structure contains the parsed statistics from the servers.

The memcached_stat_get_value() function retrieves a specific statistic value from the memcached_stat_t structure based on the provided key.

The memcached_stat_get_each() function retrieves statistics for a specific server instance. The returned string needs to be freed by the caller.

The memcached_stat_get_each_value() function retrieves a specific statistic value for a specific server instance.

The memcached_stat_free() function frees the memory allocated for the memcached_stat_t structure.

Available statistics keys for memcached_stat_get_value() and memcached_stat_get_each_value() are defined in memcached_stat_key_t:

MEMCACHED_STAT_GETS
Number of GET requests received.
MEMCACHED_STAT_SETS
Number of SET requests received.
MEMCACHED_STAT_DELETES
Number of DELETE requests received.
MEMCACHED_STAT_CAS
Number of CAS requests received.
MEMCACHED_STAT_GET_HITS
Number of GET requests that found an existing key.
MEMCACHED_STAT_GET_MISSES
Number of GET requests that did not find an existing key.
MEMCACHED_STAT_EXPIRED_UNFETCHED
Number of items that have expired, but not yet been evicted.
MEMCACHED_STAT_EVICTIONS
Number of items evicted due to memory pressure.
MEMCACHED_STAT_RECLAIMED
Number of items that have been reclaimed (e.g., due to LRU).
MEMCACHED_STAT_TOTAL_ITEMS
Current number of items in the cache.
MEMCACHED_STAT_TOTAL_BYTES
Current total size of items in the cache.
MEMCACHED_STAT_CURRENT_CONNECTIONS
Current number of active client connections.
MEMCACHED_STAT_COMMAND_GET
Total number of GET commands executed.
MEMCACHED_STAT_COMMAND_SET
Total number of SET commands executed.
MEMCACHED_STAT_COMMAND_DELETE
Total number of DELETE commands executed.
MEMCACHED_STAT_COMMAND_INCR
Total number of INCR commands executed.
MEMCACHED_STAT_COMMAND_DECR
Total number of DECR commands executed.
MEMCACHED_STAT_COMMAND_CAS
Total number of CAS commands executed.
MEMCACHED_STAT_COMMAND_TOUCH
Total number of TOUCH commands executed.
MEMCACHED_STAT_CMD_GET
Alias for MEMCACHED_STAT_COMMAND_GET.
MEMCACHED_STAT_CMD_SET
Alias for MEMCACHED_STAT_COMMAND_SET.
MEMCACHED_STAT_CMD_DELETE
Alias for MEMCACHED_STAT_COMMAND_DELETE.
MEMCACHED_STAT_CMD_INCR
Alias for MEMCACHED_STAT_COMMAND_INCR.
MEMCACHED_STAT_CMD_DECR
Alias for MEMCACHED_STAT_COMMAND_DECR.
MEMCACHED_STAT_CMD_CAS
Alias for MEMCACHED_STAT_COMMAND_CAS.
MEMCACHED_STAT_CMD_TOUCH
Alias for MEMCACHED_STAT_COMMAND_TOUCH.
MEMCACHED_STAT_AUTH_CMDS
Number of authentication commands processed.
MEMCACHED_STAT_AUTH_TOTAL
Total number of authentication attempts.
MEMCACHED_STAT_AUTH_FAILED
Number of failed authentication attempts.
MEMCACHED_STAT_CONN_TOTAL
Total number of client connections accepted.
MEMCACHED_STAT_RECV_BYTES
Total bytes received from clients.
MEMCACHED_STAT_SEND_BYTES
Total bytes sent to clients.
MEMCACHED_STAT_LIST_MEMCAP
Current memory cap for the cache.
MEMCACHED_STAT_REMOVED_BY_ALLOCATOR
Number of items removed by the allocator (e.g., LRU).
MEMCACHED_STAT_SLAB_GLOBAL_PAGE_FLUSHES
Number of global page flushes from slabs.
MEMCACHED_STAT_SLAB_GLOBAL_REALLOC_SIZE
Total size reallocated by global slab allocator.
MEMCACHED_STAT_SLAB_GLOBAL_WAKEUPS
Number of global slab allocator wakeups.
MEMCACHED_STAT_MEM_LIMIT
Memory limit of the memcached instance.
MEMCACHED_STAT_ACCEPTING_CONNS
Whether the server is accepting new connections (1 or 0).
MEMCACHED_STAT_LISTEN_PORT
The port the memcached server is listening on.
MEMCACHED_STAT_POLL_SKIPPED
Number of times poll() was skipped due to high connection count.
MEMCACHED_STAT_TOTAL_CAPPED
Total number of items capped.

RETURN VALUE

The memcached_stat() function returns MEMCACHED_SUCCESS on success, or an error code on failure.

The memcached_stat_get_struct() function returns a pointer to a memcached_stat_t structure on success, or NULL on failure. The rc parameter is set to indicate the success or failure.

The memcached_stat_get_value() and memcached_stat_get_each_value() functions return the requested statistic value on success, or UINT32_MAX on failure. The rc parameter is set to indicate the success or failure.

The memcached_stat_get_each() function returns a pointer to a dynamically allocated string containing the statistics for the given instance, or NULL on failure. The caller is responsible for freeing this string.

The memcached_stat_free() function does not return a value.
