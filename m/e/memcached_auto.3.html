NOMBRE

memcached_auto - Incremento y Decremento de Valores

SINOPSIS

#include <libmemcached/memcached.h>
Compilar y enlazar con -lmemcached
memcached_return_t memcached_increment(memcached_st *ptr, const char *key, size_t key_length, uint32_t offset, uint64_t *value)
memcached_return_t memcached_decrement(memcached_st *ptr, const char *key, size_t key_length, uint32_t offset, uint64_t *value)
memcached_return_t memcached_increment_with_initial(memcached_st *ptr, const char *key, size_t key_length, uint64_t offset, uint64_t initial, time_t expiration, uint64_t *value)
memcached_return_t memcached_decrement_with_initial(memcached_st *ptr, const char *key, size_t key_length, uint64_t offset, uint64_t initial, time_t expiration, uint64_t *value)
memcached_return_t memcached_increment_by_key(memcached_st *ptr, const char *group_key, size_t group_key_length, const char *key, size_t key_length, uint32_t offset, uint64_t *value)
memcached_return_t memcached_decrement_by_key(memcached_st *ptr, const char *group_key, size_t group_key_length, const char *key, size_t key_length, uint32_t offset, uint64_t *value)
memcached_return_t memcached_increment_with_initial_by_key(memcached_st *ptr, const char *group_key, size_t group_key_length, const char *key, size_t key_length, uint64_t offset, uint64_t initial, time_t expiration, uint64_t *value)
memcached_return_t memcached_decrement_with_initial_by_key(memcached_st *ptr, const char *group_key, size_t group_key_length, const char *key, size_t key_length, uint64_t offset, uint64_t initial, time_t expiration, uint64_t *value)
Parámetros
  • ptr -- puntero a una estructura memcached_st inicializada
  • group_key -- espacio de nombres de clave
  • group_key_length -- longitud del espacio de nombres de clave sin ningún cero terminador
  • key -- la clave
  • key_length -- longitud de la clave sin ningún cero terminador
  • offset -- desplazamiento para incrementar/decrementar
  • initial -- valor inicial si la clave no existe y expiration no es MEMCACHED_EXPIRATION_NOT_ADD
  • expiration -- expiración como una marca de tiempo de unix o como tiempo de expiración relativo en segundos
  • value -- el valor resultante después de la inicialización/incremento/decremento
Devoluciones
memcached_return_t indicando éxito

DESCRIPCIÓN

memcached_increment() toma una clave y longitud_clave e incrementa el valor por el offset pasado. El valor se devuelve a través del puntero uint32_t value que se le pasa.

memcached_decrement() toma una clave y longitud_clave y decrementa el valor por el offset pasado. El valor se devuelve a través del puntero uint32_t value que se le pasa.

memcached_increment_with_initial() toma una clave y longitud_clave e incrementa el valor por el offset pasado. Si el objeto especificado por key no existe, puede ocurrir una de dos cosas: Si el valor de expiration es MEMCACHED_EXPIRATION_NOT_ADD, la operación fallará. Para todos los demás valores de expiration, la operación tendrá éxito al sembrar el valor para esa clave con un valor inicial que expirará con el tiempo de expiración proporcionado. Las flags se establecerán en cero. El valor se devuelve a través del puntero uint32_t value que se le pasa. memcached_increment_with_initial solo está disponible cuando se usa el protocolo binario.

memcached_decrement_with_initial() toma una clave y longitud_clave y decrementa el valor por el offset pasado. Si el objeto especificado por key no existe, puede ocurrir una de dos cosas: Si el valor de expiration es MEMCACHED_EXPIRATION_NOT_ADD, la operación fallará. Para todos los demás valores de expiration, la operación tendrá éxito al sembrar el valor para esa clave con un valor inicial que expirará con el tiempo de expiración proporcionado. Las flags se establecerán en cero. El valor se devuelve a través del puntero uint32_t value que se le pasa. memcached_decrement_with_initial() solo está disponible cuando se usa el protocolo binario.

memcached_increment_by_key(), memcached_decrement_by_key(), memcached_increment_with_initial_by_key() y memcached_decrement_with_initial_by_key() son equivalentes de clave maestra de los anteriores.

VALOR DE RETORNO

Se devuelve un valor de tipo memcached_return_t. En caso de éxito, ese valor será MEMCACHED_SUCCESS. Utilice memcached_strerror() para traducir este valor a una cadena imprimible.

memcached_auto.3.en

NAME

memcached_auto - Set auto-rebalance feature

SYNOPSIS

#include <libmemcached/memcached.h>
memcached_return_t memcached_set_auto_eject_hosts(memcached_st *ptr, uint32_t auto_eject_hosts);
uint32_t memcached_get_auto_eject_hosts(const memcached_st *ptr);

DESCRIPTION

The memcached_set_auto_eject_hosts() function is used to set the auto-eject feature. When this feature is enabled, the client will attempt to re-balance the keys across the available servers. If a server fails to respond to a request, the client will mark the server as dead and try to redistribute the keys that were on that server to the other servers.

The auto_eject_hosts parameter is a boolean value. If it is set to true, the auto-eject feature will be enabled. If it is set to false, the auto-eject feature will be disabled.

The memcached_get_auto_eject_hosts() function is used to retrieve the current value of the auto-eject feature.

RETURN VALUES

memcached_set_auto_eject_hosts() returns MEMCACHED_SUCCESS on success, and a memcached_return_t error code on failure.
