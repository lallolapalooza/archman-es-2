MENYOKI(1) Comandos de usuario MENYOKI(1)

NOMBRE

menyoki - captura de pantalla/screencast y realiza operaciones de imagen en la línea de comandos

SINOPSIS

menyoki [FLAGS] [OPCIONES] <SUBCOMANDO>

DESCRIPCIÓN

menyoki es una utilidad de screencast y captura de pantalla que también puede realizar varias operaciones relacionadas con imágenes, como crear/dividir GIFs y modificar/analizar/ver archivos de imagen. Su objetivo es ser una herramienta ligera de línea de comandos para ayudar en operaciones cotidianas o en problemas complejos centrados en detalles. Originalmente fue diseñado para grabar/capturar ventanas de terminal, pero se puede ajustar fácilmente para otros propósitos con argumentos de línea de comandos, variables de entorno o un archivo de configuración.

USO

Los argumentos de línea de comandos de menyoki están diseñados para ser lo más intuitivos posible. Como resultado, una acción se puede realizar con una cadena de subcomandos junto con las flags y opciones. El prototipo general para el uso de los argumentos de línea de comandos es el siguiente:

menyoki (ACCIÓN) (FORMATO) (SALIDA)

El subcomando que indicará la acción es obligatorio, mientras que los subcomandos de formato y salida pueden ser opcionales (o no existir en absoluto). El subcomando de formato puede ser uno de los formatos soportados y la salida corresponde básicamente al subcomando save.

El formato predeterminado es el primer subcomando listado si no se proporciona ningún subcomando para especificar un formato. Por otro lado, el subcomando save utiliza el directorio “menyoki” en el directorio home (o images si existe) como directorio de salida predeterminado.

ARGUMENTOS GENERALES

Las flags y opciones que generalmente afectarán la ejecución de menyoki se pueden establecer antes de especificar la acción principal a realizar. Luego, se debe especificar el subcomando (acción) principal.

menyoki [FLAGS] [OPCIONES] <SUBCOMANDO>

Argumentos

FLAGS:
    -h, --help       Imprime información de ayuda
    -V, --version    Imprime información de versión
    -v, --verbose    Aumenta la verbosidad del registro
    -q, --quiet      No muestra la salida
OPCIONES:
    -c, --config <ARCHIVO>    Establece el archivo de configuración
        --color <HEX>      Establece el color principal [predeterminado: 3AA431]
SUBCOMANDOS:
    record     Graba una animación
    split      Divide una animación en fotogramas
    make       Crea una animación a partir de fotogramas
    capture    Captura una imagen
    edit       Edita una imagen
    analyze    Analiza una imagen
    view       Muestra una imagen

Ejemplos

Comando Acción
menyoki -V Imprime la información de versión
menyoki -vv --color FF00FF <acción> Establece el nivel de verbosidad del registro a 2 (traza) y usa “FF00FF” como color principal
menyoki -q -c menyoki.conf <acción> Ejecuta en modo silencioso y lee la configuración desde “menyoki.conf”

SUBCOMANDO RECORD

menyoki puede grabar un área de una ventana o toda la pantalla y codificarla como un formato soportado. La selección y el redimensionamiento del área se realizan con las combinaciones de teclas.

Algunos escenarios en los que la acción record podría ser útil son:

•
Grabar un área específica de una ventana
•
Grabar durante una duración determinada
•
Grabar la salida de un comando (especialmente para aplicaciones TUI)

Las opciones de codificación se pueden cambiar usando los argumentos del formato proporcionado. (Ver la salida de menyoki record gif --help)

menyoki record [FLAGS] [OPCIONES] [COMANDO] [SUBCOMANDO]

Argumentos

FLAGS:
    -r, --root          Graba la ventana raíz
    -f, --focus         Graba la ventana enfocada
        --select        Selecciona la ventana a grabar
        --parent        Graba la ventana padre
        --with-alpha    Graba con el canal alfa
        --no-keys       Deshabilita las teclas de acción durante la grabación
    -m, --mouse         Selecciona la ventana con un clic del ratón
    -h, --help          Imprime información de ayuda
OPCIONES:
        --action-keys <TECLAS>    Establece las teclas de acción [predeterminado: LAlt-S,LAlt-Enter]
        --cancel-keys <TECLAS>    Establece las teclas de cancelación [predeterminado: LControl-D,Escape]
    -b, --border <BORDE>       Establece el ancho del borde [predeterminado: 1]
    -p, --padding <T:R:B:L>     Establece el relleno del área de grabación
    -s, --size <ANxAL>            Establece el tamaño del área de grabación
    -d, --duration <S>          Establece la duración de la grabación [predeterminado: ∞]
    -c, --countdown <S>         Establece la cuenta atrás antes de grabar [predeterminado: 3]
    -t, --timeout <S>           Establece el tiempo de espera para la selección de ventana [predeterminado: 300]
    -i, --interval <MS>         Establece el intervalo de actualización para la selección de ventana [predeterminado: 10]
        --font <FUENTE>           Establece la fuente a usar para la selección de ventana
        --monitor <NUM>         Establece el monitor a grabar como ventana raíz
ARG:
    <COMANDO>    Establece el comando a ejecutar
SUBCOMANDOS:
    gif     Usa el codificador GIF
    apng    Usa el codificador APNG
    save    Guarda el/los archivo(s) de salida

Ejemplos

Comando Acción
menyoki record Selecciona una ventana y comienza a grabar con la configuración predeterminada
menyoki record --root --countdown 5 Graba la ventana raíz después de 5 segundos de cuenta atrás
menyoki record --focus --with-alpha Graba la ventana enfocada con el canal alfa (para transparencia)
menyoki record --size 200x300 --duration 10 Graba un área de tamaño 200x300 durante 10 segundos
menyoki record --padding 20:10:0:10 --timeout 120 Graba un área con el relleno dado y establece el tiempo de espera de selección de ventana a 120 segundos
menyoki record --parent Graba la ventana padre de la ventana seleccionada
menyoki record --root --select --monitor 1 Graba el primer monitor como ventana raíz
menyoki record --border 5 Graba el área seleccionada por un borde de ancho 5
menyoki record --action-keys LControl-Q,LAlt-W Graba con la configuración predeterminada usando combinaciones de teclas personalizadas
menyoki record --cancel-keys LControl-X,E Graba con la configuración predeterminada usando combinaciones de teclas personalizadas
menyoki record gif --fps 15 --quality 90 Graba 15 fotogramas por segundo con calidad 90%
menyoki record gif --gifski Graba y codifica usando el codificador gifski
menyoki record gif save "test.gif" --timestamp Graba y guarda como “test.gif” con marca de tiempo en el nombre del archivo
menyoki record apng --fps 30 Graba 30 fotogramas por segundo y codifica como APNG
menyoki -q record save "-" > test.gif Graba y redirige la salida a “test.gif”
menyoki -q record "kmon -t 2000" Ejecuta el comando y graba su salida en modo silencioso
menyoki record --font "-*-dejavu sans-*-*-*-*-17-*-*-*-*-*-*-*" Usa una fuente personalizada para mostrar el tamaño del área (ver xfontsel)

SUBCOMANDO SPLIT

menyoki puede dividir una animación en fotogramas (extraer imágenes) si se proporciona el subcomando split y puede guardar fotogramas como uno de los formatos soportados con el uso del subcomando formato al final.

menyoki split [OPCIONES] <ARCHIVO> [SUBCOMANDO]

Argumentos

FLAGS:
    -h, --help    Imprime información de ayuda

on OPCIONES: -d, --dir <DIRECTORIO> Establecer el directorio de salida ARGUMENTOS: <ARCHIVO> Establecer el archivo de animación SUBCOMANDOS: png Usar el codificador PNG jpg Usar el codificador JPG webp Usar el codificador WebP bmp Usar el codificador BMP ico Usar el codificador ICO tiff Usar el codificador TIFF tga Usar el codificador TGA pnm Usar el codificador PNM ff Usar el codificador farbfeld exr Usar el codificador OpenEXR

Ejemplos

Comando Acción
menyoki split rec.gif Extraer fotogramas del archivo “rec.gif”
menyoki split rec.gif jpg --quality 100 Extraer fotogramas como JPEG en calidad máxima
menyoki split rec.gif --dir frames/ Extraer fotogramas y guardarlos en el directorio especificado

MAKE SUBCOMANDO

El subcomando make sirve para crear una animación a partir de un conjunto de imágenes. Por ejemplo, se puede utilizar para crear GIFs a partir de imágenes dadas, ya sea a través de la línea de comandos o desde el directorio especificado.

menyoki make [FLAGS] [OPCIONES] <FRAMES>... [SUBCOMANDO]

Argumentos

FLAGS:
        --gifski     Usar el codificador gifski
        --fast       Codificar 3 veces más rápido (gifski)
    -n, --no-sort    Usar los fotogramas en el orden dado
    -h, --help       Imprimir información de ayuda
OPCIONES:
    -f, --fps <FPS>            Establecer los FPS [default: 20]
    -q, --quality <CALIDAD>    Establecer la calidad del fotograma (1-100) [default: 75]
    -r, --repeat <REPETICIONES>      Establecer el número de repeticiones [default: ∞]
    -d, --dir <DIRECTORIO>      Establecer el directorio para leer los fotogramas
        --format <FORMATO>      Establecer el formato de la animación [default: gif]  [posibles valores: gif, apng]
ARGUMENTOS:
    <FRAMES>...    Establecer los fotogramas de la animación
SUBCOMANDOS:
    save    Guardar el(los) archivo(s) de salida

Ejemplos

Comando Acción
menyoki make 1.png 2.png Crear un GIF que consta de dos fotogramas como “1.png” y “2.png”
menyoki make 1.png 2.png --fps 5 --quality 100 Crear un GIF con las propiedades especificadas a partir de los fotogramas dados
menyoki make 1.png 2.png save 3.gif --date Crear un GIF y guardar el archivo (“3.gif”) con la información de la fecha
menyoki make 1.png 2.png --format apng Crear un APNG a partir de los fotogramas dados
menyoki make --dir frames/ Crear un GIF a partir de los fotogramas del directorio especificado

CAPTURE SUBCOMANDO

menyoki puede capturar (hacer una captura de pantalla) un área de una ventana o de toda la pantalla y codificarla en un formato compatible. Formatos como png, jpg y pnm tienen sus propias banderas y opciones que pueden usarse para cambiar la configuración de codificación por defecto. Similar al subcomando record, la selección de área y el redimensionamiento se realizan con las combinaciones de teclas. Las mismas banderas y opciones pueden aplicarse tanto a record como a capture, ya que las acciones son abstractamente similares.

menyoki capture [FLAGS] [OPCIONES] [COMANDO] [SUBCOMANDO]

Argumentos

FLAGS:
    -r, --root          Capturar la ventana raíz
    -f, --focus         Capturar la ventana enfocada
        --select        Seleccionar la ventana para capturar
        --parent        Grabar el padre de la ventana
        --with-alpha    Capturar con el canal alfa
    -m, --mouse         Seleccionar la ventana con un clic del ratón
    -h, --help          Imprimir información de ayuda
OPCIONES:
        --action-keys <TECLAS>    Establecer las teclas de acción [default: LAlt-S,LAlt-Enter]
        --cancel-keys <TECLAS>    Establecer las teclas de cancelación [default: LControl-D,Escape]
    -b, --border <BORDE>       Establecer el ancho del borde [default: 1]
    -p, --padding <T:R:B:L>     Establecer el relleno del área de captura
    -s, --size <ANxAL>            Establecer el tamaño del área de captura
    -c, --countdown <S>         Establecer la cuenta atrás antes de capturar [default: 0]
    -t, --timeout <S>           Establecer el tiempo de espera para la selección de ventana [default: 300]
    -i, --interval <MS>         Establecer el intervalo de actualización para la selección de ventana [default: 10]
        --font <FUENTE>           Establecer la fuente a usar para la selección de ventana
        --monitor <NUM>         Establecer el monitor a capturar como ventana raíz
ARGUMENTOS:
    <COMANDO>    Establecer el comando a ejecutar
SUBCOMANDOS:
    png     Usar el codificador PNG
    jpg     Usar el codificador JPG
    webp    Usar el codificador WebP
    bmp     Usar el codificador BMP
    ico     Usar el codificador ICO
    tiff    Usar el codificador TIFF
    tga     Usar el codificador TGA
    pnm     Usar el codificador PNM
    ff      Usar el codificador farbfeld
    exr     Usar el codificador OpenEXR
    save    Guardar el(los) archivo(s) de salida

Ejemplos

Comando Acción
menyoki capture Seleccionar una ventana y hacer una captura de pantalla con la configuración por defecto
menyoki capture --root --countdown 5 Capturar la ventana raíz después de 5 segundos de cuenta atrás
menyoki capture --focus --with-alpha Capturar la ventana enfocada con el canal alfa (para transparencia)
menyoki capture --size 200x300 --duration 10 Capturar un área de tamaño 200x300 durante 10 segundos
menyoki capture --padding 20:10:0:10 --timeout 120 Capturar un área con el relleno dado y establecer el tiempo de espera de selección de ventana a 120 segundos
menyoki capture png --filter avg --compression fast Capturar y codificar con las opciones PNG especificadas
menyoki capture jpg --quality 100 Capturar y codificar con las opciones JPEG especificadas
menyoki capture webp --lossless Capturar y codificar con las opciones WEBP especificadas
menyoki capture pnm --format pixmap --encoding ascii Capturar y codificar con las opciones PNM especificadas
menyoki capture ff save "test.ff" --timestamp Capturar y guardar como “test.ff” en formato farbfeld con marca de tiempo en el nombre del archivo
menyoki -q capture png save "-" > test.png Capturar y redirigir la salida a “test.png”
menyoki -q capture "kmon -t 2000" Ejecutar el comando y capturar su salida en modo silencioso (establece la cuenta atrás en 3 implícitamente)

EDIT SUBCOMANDO

El subcomando edit se puede utilizar para editar (https://github.com/image-rs/image#image-processing-functions) (manipular/filtrar/convertir) archivos en uno de los formatos soportados. Además de las banderas y opciones que edit proporciona, se pueden especificar otras opciones de codificación a través del subcomando format.

menyoki edit [FLAGS] [OPCIONES] <ARCHIVO> [SUBCOMANDO]

Argumentos

FLAGS:
        --convert      Convertir la imagen usando el codificador dado
        --grayscale    Convertir la imagen a escala de grises
        --invert       Invertir los colores de la imagen
    -h, --help         Imprimir información de ayuda
OPCIONES:
        --crop <T:R:B:L>             Aplicar relleno para recortar la imagen
        --resize <ANxAL>               Redimensionar la imagen sin mantener la relación de aspecto
        --ratio <RELACION>              Redimensionar la imagen proporcionalmente por relación de aspecto [default: 1.0]
        --rotate <ROTAR>            Rotar la imagen (en sentido horario) [posibles valores: 90, 180, 270]
        --flip <VOLTEAR>                Voltear la imagen [posibles valores: horizontal, vertical]
        --blur <SIGMA>               Desenfocar la imagen [default: 0.0]
        --hue <TONO>                  Ajustar el tono de la imagen [default: ±0]
        --contrast <CONTRASTE>        Ajustar el contraste de la imagen [default: ±0.0]
        --brightness <BRILLO>    Ajustar el brillo de la imagen [default: ±0]
        --filter <FILTRO>            Establecer el filtro de muestreo para escalar [default: lanczos3]  [posibles valores: nearest, triangle, catmull-rom, gaussian,
                                     lanczos3]
ARGUMENTOS:
    <ARCHIVO>    Establecer el archivo de entrada
SUBCOMANDOS:
    gif     Usar el codificador GIF
    apng    Usar el codificador APNG
    png     Usar el codificador PNG
    jpg     Usar el codificador JPG
    webp    Usar el codificador WebP
    bmp     Usar el codificador BMP
    ico     Usar el codificador ICO
    tiff    Usar el codificador TIFF
    tga     Usar el codificador TGA
    pnm     Usar el codificador PNM
    ff      Usar el codificador farbfeld
    exr     Usar el codificador OpenEXR
    save    Guardar el(los) archivo(s) de salida

Ejemplos

Comando Acción
menyoki edit test.png Re-codificar el archivo “test.png” sin editar
menyoki edit test.png --grayscale Convertir la imagen a escala de grises
menyoki edit test.png --invert Invertir los colores de la imagen
menyoki edit test.png --crop 20:20:20:20 Aplicar el relleno dado a la imagen para recortar
menyoki edit test.png --resize 300x300 Redimensionar la imagen a 300x300 (sin mantener la relación de aspecto)
menyoki edit test.png --ratio 0.5 Redimensionar la imagen a la mitad del tamaño (usando la relación de aspecto)
menyoki edit test.png --ratio 2.0 --filter gaussian Redimensionar la imagen usando el filtro de muestreo especificado
menyoki edit test.png --rotate 90 Rotar la imagen 90 grados (en sentido horario)
menyoki edit test.png --flip horizontal Voltear la imagen horizontalmente

NAME

menyoki - a keyboard and mouse recorder

SYNOPSIS

menyoki [-v] [-h] [record] [-i <input>] [-o <output>] [-s <size>] [-f <format>] [-n] [-d <device>]

menyoki [-v] [-h] split [-i <input>] [-o <output>] [-s <size>] [-d <device>]

menyoki [-v] [-h] make [-i <input>] [-o <output>] [-f <format>] [-d <device>]

menyoki [-v] [-h] capture [-i <input>] [-o <output>] [-s <size>] [-f <format>] [-d <device>]

menyoki [-v] [-h] edit [-i <input>] [-o <output>] [-s <size>] [-d <device>]

menyoki [-v] [-h] analyze [-i <input>] [-o <output>] [-d <device>]

menyoki [-v] [-h] view [-i <input>] [-d <device>]

DESCRIPTION

menyoki is a command-line tool that allows you to record, manipulate, and play back keyboard and mouse events. It uses the libevdev library to capture input events from specified devices.

USAGE

The general usage of menyoki involves specifying a subcommand to perform a specific action. The most common subcommands are:

  • record: Record keyboard and mouse events.
  • split: Split a recorded event file into smaller chunks.
  • make: Create a playable event file from raw input.
  • capture: Capture events and save them in a specific format.
  • edit: Edit recorded events.
  • analyze: Analyze recorded events.
  • view: View recorded events.

GENERAL ARGUMENTS

The following arguments are applicable to most subcommands:

-v, --version
Show version information and exit.
-h, --help
Show help message and exit.
-i, --input <input>
Path to the input file or device. Defaults to reading from stdin.
-o, --output <output>
Path to the output file. Defaults to writing to stdout.
-d, --device <device>
Specify the input device to use (e.g., /dev/input/eventX).

RECORD SUBCOMMAND

Records input events from a specified device.

-s, --size <size>
Maximum size of the output file in bytes. If not specified, the recording will continue until interrupted.
-f, --format <format>
Output format. Supported formats: bin (binary, default), json.
-n, --no-sync
Do not synchronize events to the system clock.

Example: menyoki record -d /dev/input/event5 -o recording.bin

SPLIT SUBCOMMAND

Splits a recorded event file into smaller files based on size.

-s, --size <size>
Maximum size of each output file in bytes.
-d, --device <device>
Specify the input device to filter events (optional).

Example: menyoki split -i recording.bin -o chunk_ -s 102400

MAKE SUBCOMMAND

Creates a playable event file from raw input, potentially replaying events.

-f, --format <format>
Input format. Supported formats: bin (binary, default), json.
-d, --device <device>
Specify the input device to replay events to.

Example: menyoki make -i recording.bin -d /dev/input/event5

CAPTURE SUBCOMMAND

Captures input events and saves them in a specified format, potentially with filtering.

-s, --size <size>
Maximum size of the output file in bytes.
-f, --format <format>
Output format. Supported formats: bin (binary, default), json.
-d, --device <device>
Specify the input device to capture events from.

Example: menyoki capture -d /dev/input/event5 -f json -o capture.json

EDIT SUBCOMMAND

Allows editing of recorded events. This is a placeholder for future functionality.

-s, --size <size>
Maximum size of the output file in bytes.
-d, --device <device>
Specify the input device to apply edits to.

Example: menyoki edit -i recording.bin -o edited.bin

ANALYZE SUBCOMMAND

Analyzes recorded input events and provides statistics or insights.

-o, --output <output>
Path to the output file for analysis results. Defaults to stdout.
-d, --device <device>
Specify the input device to analyze events from (optional).

Example: menyoki analyze -i recording.bin -o analysis.txt

VIEW SUBCOMMAND

Displays the recorded input events in a human-readable format.

-d, --device <device>
Specify the input device to view events from (optional).

Example: menyoki view -i recording.bin

OTHER SUBCOMMANDS

menyoki may have other subcommands for advanced usage or future features. Refer to the help message (menyoki -h) for a complete list.

KEY BINDINGS

During recording, menyoki might respond to specific key bindings for control, such as stopping the recording. This is typically Ctrl+C.
