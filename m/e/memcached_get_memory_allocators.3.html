DESCRIPCIÓN

libmemcached te permite especificar tus propios asignadores de memoria, optimizados para tu aplicación. Esto permite que libmemcached se use dentro de aplicaciones que tienen su propia implementación de malloc.

memcached_set_memory_allocators() se utiliza para establecer los asignadores de memoria utilizados por la instancia de memcached especificada por ptr. Ten en cuenta que no puedes anular solo uno de los asignadores de memoria; debes especificar un conjunto completo nuevo si deseas anular uno de ellos. Todas las funciones de asignación de memoria deben comportarse según lo especificado en el estándar C99. Especifica NULL en todas las funciones para restablecerlas a los valores predeterminados.

memcached_get_memory_allocators() se utiliza para obtener los asignadores de memoria actualmente utilizados por un manejador de memcached.

memcached_get_memory_allocators_context() devuelve el void * que se pasó durante la llamada a memcached_set_memory_allocators().

El primer argumento a las funciones de asignador de memoria es un puntero a una estructura memcached, que se pasa como const y deberás clonarla para poder utilizar cualquier operación que la modifique.

NOTAS

En la versión 0.38, todas las funciones se modificaron para tener un puntero void de contexto pasado a ellas. Esto era para que los asignadores personalizados pudieran tener su propio espacio para la memoria.

VALOR DE RETORNO

memcached_set_memory_allocators() devuelve MEMCACHED_SUCCESS en caso de éxito y MEMCACHED_FAILURE si no se pasa un conjunto completo de punteros de función.

NAME

memcached_get_memory_allocators — Get the available memory allocators.

SYNOPSIS

#include <memcached.h>

char **memcached_get_memory_allocators(memcached_st *shell, size_t *count);

DESCRIPTION

Retrieves a NULL-terminated array of strings of available memory allocators. The caller is responsible for freeing the returned array with memcached_free().

NOTES

The default allocator is always the first element in the returned array.

RETURN VALUE

Returns a NULL-terminated array of strings of allocator names. On failure, NULL is returned and memcached_strerror() can be used to retrieve the error message.
