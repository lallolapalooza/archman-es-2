memcached_set_encoding_key(3)

Paquete: libmemcached-awesome

Licencias: BSD

MEMCACHED_SET_ENCODING_KEY(3) libmemcached-awesome MEMCACHED_SET_ENCODING_KEY(3)

NOMBRE

memcached_set_encoding_key - Documentación de libmemcached

SINOPSIS

#include <libmemcached/memcached.h>
Compilar y enlazar con -lmemcached
memcached_return_t memcached_set_encoding_key(memcached_st *ptr, const char *str, const size_t length)
Parámetros
  • ptr -- puntero a una estructura memcached_st inicializada
  • str -- la clave a utilizar
  • length -- la longitud de la clave sin ningún carácter nulo terminador
Retorna
memcached_return_t indicando el éxito

DESCRIPCIÓN

memcached_set_encoding_key() establece la clave que se utilizará para cifrar y descifrar datos mientras se envían y reciben del servidor.

Actualmente, solo se soporta AES.

VALOR DE RETORNO

Se devuelve un valor de tipo memcached_return_t. En caso de éxito, ese valor será MEMCACHED_SUCCESS. Utilice memcached_strerror() para traducir este valor a una cadena imprimible.
