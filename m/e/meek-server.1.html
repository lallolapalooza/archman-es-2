NOMBRE

meek-server - El plugin de transporte del servidor meek

SINOPSIS

meek-server --acme-hostnames=NOMBRE_HOST [OPCIONES]

DESCRIPCIÓN

meek-server es un plugin de transporte para Tor que codifica un flujo como una secuencia de peticiones y respuestas HTTP.

Necesitarás configurar certificados TLS. Hay dos maneras de configurar los certificados:

•--acme-hostnames=NOMBRE_HOST (con opcional --acme-email=EMAIL) obtendrá automáticamente certificados para NOMBRE_HOST usando Let’s Encrypt. Cuando uses esta opción, meek-server necesitará poder escuchar en el puerto 80.
•--cert=ARCHIVO y --key=ARCHIVO te permiten usar tu propio certificado adquirido externamente.

La configuración para meek-server normalmente aparece en un archivo torrc. Aquí tienes una configuración de ejemplo usando certificados automáticos de Let’s Encrypt:

ExtORPort auto
ServerTransportListenAddr meek 0.0.0.0:443
ServerTransportPlugin meek exec ./meek-server --acme-hostnames meek-server.example --log meek-server.log

Aquí tienes una configuración de ejemplo usando certificados adquiridos externamente:

ExtORPort auto
ServerTransportListenAddr meek 0.0.0.0:8443
ServerTransportPlugin meek exec ./meek-server 8443 --cert cert.pem --key key.pem --log meek-server.log

Para escuchar en los puertos 80 y 443 sin necesidad de ejecutar como root, en Linux, puedes usar el programa setcap, parte de libcap2:

setcap 'cap_net_bind_service=+ep' /usr/local/bin/meek-server

OPCIONES

--acme-email=EMAIL

Dirección de correo electrónico opcional para registrarse para notificaciones de Let’s Encrypt al usar --acme-hostnames.

--acme-hostnames=NOMBRE_HOST[,NOMBRE_HOST]...

Lista separada por comas de nombres de host a honrar al obtener certificados automáticos de Let’s Encrypt. meek-server abrirá un oyente especial en el puerto 80 para manejar mensajes ACME; este oyente está separado del especificado por ServerTransportListenAddr. Los certificados se almacenarán en caché en el directorio pt_state/meek-certificate-cache dentro del directorio de estado de tor.

--cert=ARCHIVO

Nombre de un archivo de certificado TLS codificado en PEM. Requerido a menos que se use --acme-hostnames o --disable-tls.

--disable-tls

Usa HTTP plano en lugar de HTTPS. Esta opción es solo para fines de prueba. No la uses en producción.

--key=ARCHIVO

Nombre de un archivo de clave privada TLS codificado en PEM. Requerido a menos que se use --acme-hostnames o --disable-tls.

--log=ARCHIVO

Nombre de un archivo al que escribir mensajes de registro (por defecto, stderr).

--port=PUERTO

Puerto en el que escuchar. Sobrescribe la variable de entorno TOR_PT_SERVER_BINDADDR establecida por tor. En la mayoría de los casos, deberías establecer la opción ServerTransportListenAddr en torrc, en lugar de usar la opción --port.

-h, --help

Muestra un mensaje de ayuda y sale.
