MBRTOWC(3P) Manual del programador POSIX MBRTOWC(3P)

PROLOG

Esta página del manual forma parte del Manual del programador POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual de Linux correspondiente para conocer los detalles del comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

mbrtowc — convertir un carácter a código de carácter ancho (reiniciable)

SINOPSIS

#include <wchar.h>
size_t mbrtowc(wchar_t *restrict pwc, const char *restrict s,
    size_t n, mbstate_t *restrict ps);

DESCRIPCIÓN

La funcionalidad descrita en esta página de referencia está alineada con el estándar ISO C. Cualquier conflicto entre los requisitos descritos aquí y el estándar ISO C es involuntario. Este volumen de POSIX.1‐2017 se remite al estándar ISO C.

Si s es un puntero nulo, la función mbrtowc() será equivalente a la llamada:

mbrtowc(NULL, "", 1, ps)

En este caso, se ignoran los valores de los argumentos pwc y n.

Si s no es un puntero nulo, la función mbrtowc() inspeccionará como máximo n bytes comenzando en el byte apuntado por s para determinar la cantidad de bytes necesarios para completar el siguiente carácter (incluidas las secuencias de cambio). Si la función determina que el siguiente carácter está completo, determinará el valor del carácter ancho correspondiente y, si pwc no es un puntero nulo, almacenará ese valor en el objeto apuntado por pwc. Si el carácter ancho correspondiente es el carácter ancho nulo, el estado resultante descrito será el estado de conversión inicial.

Si ps es un puntero nulo, la función mbrtowc() utilizará su propio objeto mbstate_t interno, que se inicializará al inicio del programa al estado de conversión inicial. De lo contrario, se utilizará el objeto mbstate_t apuntado por ps para describir completamente el estado de conversión actual de la secuencia de caracteres asociada. La implementación se comportará como si ninguna función definida en este volumen de POSIX.1‐2017 llamara a mbrtowc().

El comportamiento de esta función se ve afectado por la categoría LC_CTYPE de la configuración regional actual.

La función mbrtowc() no necesita ser segura para hilos si se llama con un argumento ps NULL.

La función mbrtowc() no cambiará la configuración de errno si tiene éxito.

VALOR DE RETORNO

La función mbrtowc() devolverá lo primero de lo siguiente que sea aplicable:

0
Si los siguientes n bytes o menos completan el carácter que corresponde al carácter ancho nulo (que es el valor almacenado).
entre 1 y n inclusive

Si los siguientes n bytes o menos completan un carácter válido (que es el valor almacenado); el valor devuelto será el número de bytes que completan el carácter.
(size_t)-2
Si los siguientes n bytes contribuyen a un carácter incompleto pero potencialmente válido, y se han procesado los n bytes (no se almacena ningún valor). Cuando n tiene al menos el valor de la macro {MB_CUR_MAX}, este caso solo puede ocurrir si s apunta a una secuencia de secuencias de cambio redundantes (para implementaciones con codificaciones dependientes del estado).
(size_t)-1
Si ocurre un error de codificación, en cuyo caso los siguientes n bytes o menos no contribuyen a un carácter completo y válido (no se almacena ningún valor). En este caso, se almacenará [EILSEQ] en errno y el estado de conversión no está definido.

ERRORES

La función mbrtowc() fallará si:

EILSEQ
Se detecta una secuencia de caracteres inválida. En la configuración regional POSIX, un error [EILSEQ] no puede ocurrir ya que todos los valores de bytes son caracteres válidos.

La función mbrtowc() puede fallar si:

EINVAL
ps apunta a un objeto que contiene un estado de conversión inválido.
