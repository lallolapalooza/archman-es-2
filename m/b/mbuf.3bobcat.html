FBB::Mbuf(3bobcat) Manejador de mensajes FBB::Mbuf(3bobcat)

NOMBRE

FBB::Mbuf - Manejo de mensajes std::streambuf

SINOPSIS

#include <bobcat/mbuf>
Opción de enlazado: -lbobcat

DESCRIPCIÓN

Los objetos de esta clase se derivan de std::streambuf y se utilizan para manejar mensajes de forma estandarizada. Los mensajes pueden ir precedidos por números de orden (línea) y/o etiquetas.

Por defecto, todos los mensajes se insertan en el flujo de salida estándar, pero otros destinos (salida de error estándar, un archivo con nombre, etc.) se pueden configurar fácilmente.

Los objetos FBB::Mbuf son en sí mismos objetos std::streambuf, por lo que pueden usarse para construir objetos std::ostream. Sin embargo, están destinados a ser utilizados por objetos mstream(3bobcat), y pasar objetos Mbuf a otro tipo de objetos ostream está obsoleto y da como resultado un comportamiento indefinido.

ESPACIO DE NOMBRES

FBB
Todos los elementos mencionados en esta página del manual están definidos en el espacio de nombres FBB.

HEREDA DE

std::streambuf

CONSTRUCTORES

o
Mbuf():
El constructor predeterminado maneja mensajes utilizando el std::streambuf que también utiliza std::cout. No hay límite en la cantidad de mensajes que se pueden insertar. No se muestran números de mensaje o línea, ni se lanzan excepciones al insertar mensajes.
o
explicit Mbuf(std::streambuf *buf, size_t maxCount = std::numeric_limits<size_t>::max(), std::string const &tag = "", bool throwing = false):
Este constructor utiliza buf para manejar mensajes. Por defecto (utilizando los valores predeterminados de los argumentos) no hay límite en la cantidad de mensajes que se pueden insertar. No se muestran números de mensaje o línea, ni se lanzan excepciones al insertar mensajes. Especificar cualquier valor distinto de std::numeric_limits<size_t>::max() establece el número máximo de mensajes que se pueden insertar en ese valor. La tag define el texto de la etiqueta del mensaje (por ejemplo, Error). Cuando throwing se especifica como true, se lanza una excepción FBB::Exception después de completar un mensaje. La excepción generada contiene el id (ver más abajo la miembro id) del objeto FBB::Mbuf desde el cual se lanzó la excepción, así como el texto FBB::Mbuf.
o
explicit Mbuf(std::string const &name, size_t maxCount = std::numeric_limits<size_t>::max(), std::string const &tag = "", bool throwing = false):
Este constructor crea un std::ofstream a partir del parámetro name proporcionado, que recibe los mensajes manejados por el objeto FBB:Mbuf construido. Lanza una excepción FBB::Exception si el flujo no se puede abrir para escritura. Si ya existe un archivo con ese nombre, se sobrescribe. Los parámetros restantes son idénticos a los de los dos constructores anteriores.

Los constructores y operadores de asignación de copia y movimiento no están disponibles.

FUNCIONES MIEMBRO

o
size_t count() const:
devuelve el número de mensajes insertados (si se ha llamado a setCount: el valor establecido por la última llamada a setCount más el número de mensajes insertados desde esa llamada).
o
bool lineExcess() const:
devuelve true después de intentar insertar un mensaje adicional una vez que se han insertado maxCount() mensajes.
o
std::string const &lineTag() const:
devuelve la etiqueta de línea actualmente en uso (por defecto `Line’).
o
size_t maxCount() const:
devuelve el número máximo de mensajes que se pueden insertar. Si el valor devuelto es igual a std::numeric_limits<size_t>::max(), entonces no hay límite en la cantidad de mensajes que se pueden insertar.
o
void noLineNr():
llamar a este miembro suprimirá la visualización de un número de línea si se llama después de setLineNr (ver más abajo) pero antes de que se inserte (o se haya insertado) un mensaje.
o
void reset(std::streambuf *buf, size_t maxCount, std::string const &tag, bool throwing):
los mensajes insertados en los objetos FBB::Mbuf son manejados por std::streambuf buf. Al especificar std::numeric_limits<size_t>::max() para maxCount no hay límite en la cantidad de mensajes que pueden ser manejados por este std::streambuf. La tag define el texto de la etiqueta del mensaje (por ejemplo, Error o una cadena vacía para ninguna etiqueta de mensaje). Cuando throwing se especifica como true, se lanza una excepción FBB::Exception después de completar un mensaje.
o
void reset(std::string const &name, size_t maxCount, std::string const &tag, bool throwing):
los mensajes insertados en los objetos FBB::Mbuf son manejados por un std::ofstream creado utilizando el parámetro name proporcionado. Lanza una excepción FBB::Exception si el flujo no se puede abrir para escritura. Si ya existe un archivo con ese nombre, se sobrescribe. Los parámetros restantes son idénticos a los de los miembros reset anteriores.
o
void reset(FBB::Mbuf const &mbuf):
el objeto actual se reinicia utilizando los parámetros del parámetro mbuf. Después del reinicio, todos los parámetros del objeto actual pueden modificarse de forma independiente de los utilizados por mbuf.
o
void setCount(size_t count):
asigna el valor count al contador de mensajes del objeto.
o
void setLineNr(size_t lineNr):
especifica el valor lineNr como el número de línea del mensaje cuando se muestre la siguiente línea (ver también noLineNr). Este valor *no* es modificado por el objeto FBB::Mbuf. Para mostrar otro número de línea, el miembro deberá ser llamado de nuevo (es decir, el número de línea no se muestra automáticamente de nuevo en cada nueva línea).
o
void setLineTag(std::string const &tag):
especifica la etiqueta que precede a los números de línea. Por defecto, la etiqueta de línea es igual a `Line’.
o
void setMaxCount(size_t maxCount):
define maxCount como el número máximo de mensajes que se pueden insertar en el objeto FBB::Mbuf.
o
void setTag(std::string const &tag):
especifica la etiqueta que precede a los mensajes. Por defecto, la etiqueta está vacía. Si no está vacía, la etiqueta se encierra entre corchetes. Por ejemplo, especificar la etiqueta `Error’ antepondrá a los mensajes [Error].
o
std::string const &tag() const:
devuelve la etiqueta de mensaje actualmente en uso (por defecto una cadena vacía).
o
bool throws():
devuelve true si el objeto FBB::Mbuf lanzará una excepción FBB::Exception en el siguiente mensaje completado. La excepción generada contiene el id (ver anteriormente la miembro id) del objeto FBB::Mbuf desde el cual se lanzó la excepción, así como el texto FBB::Mbuf.
o
void throwing(bool ifTrue):
modifica el comportamiento de los objetos FBB::Mbuf en los mensajes completados. Después de pasar true, los objetos FBB::Mbuf lanzarán una excepción FBB::Exception en el siguiente mensaje completado.
