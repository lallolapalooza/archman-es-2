NAME

mbimcli - Control MBIM devices

DESCRIPTION

Usage:

mbimcli [OPTION?] - Control MBIM devices

EXAMPLES

To connect to the internet:

mbimcli --connect="ip-type=ipv4,apn=internet"

To disconnect:

mbimcli --disconnect

To query signal state:

mbimcli --query-signal-state

To query the list of available providers:

mbimcli --query-visible-providers

To set the radio state to off:

mbimcli --set-radio-state=off

To set the radio state to on:

mbimcli --set-radio-state=on

To enter the PIN:

mbimcli --enter-pin="pin1,1234"

To change the PIN:

mbimcli --change-pin="1234,4321"

To enable the PIN:

mbimcli --enable-pin="4321"

To disable the PIN:

mbimcli --disable-pin="4321"

To enter the PUK:

mbimcli --enter-puk="puk1,12345678,1234"

To query device capabilities:

mbimcli --query-device-caps

To query subscriber ready status:

mbimcli --query-subscriber-ready-status

To query packet service state:

mbimcli --query-packet-service-state

To attach to packet service:

mbimcli --attach-packet-service

To detach from packet service:

mbimcli --detach-packet-service

To query connection state for session 1:

mbimcli --query-connection-state=1

To query IP configuration for session 1:

mbimcli --query-ip-configuration=1

To query packet statistics:

mbimcli --query-packet-statistics

To query provisioned contexts:

mbimcli --query-provisioned-contexts

To set provisioned contexts:

mbimcli --set-provisioned-contexts="context-id=1,context-type=ipv4,apn=internet"

To query phonebook entries:

mbimcli --query-phonebook-entries

To add a phonebook entry:

mbimcli --add-phonebook-entry="0,John Doe,1234567890,,work"

To delete a phonebook entry:

mbimcli --delete-phonebook-entry="0,1"

To find phonebook entries by name:

mbimcli --find-phonebook-entries="0,John Doe"

To query DSS capabilities:

mbimcli --query-dss-capabilities

To query DSS packet service state:

mbimcli --query-dss-packet-service-state

To attach to DSS packet service:

mbimcli --attach-dss-packet-service

To detach from DSS packet service:

mbimcli --detach-dss-packet-service

To query DSS connection state:

mbimcli --query-dss-connection-state

To connect using DSS:

mbimcli --connect-dss="ip-type=ipv4,apn=internet"

To disconnect from DSS:

mbimcli --disconnect-dss

To query DSS packet statistics:

mbimcli --query-dss-packet-statistics

To query DSS IP configuration:

mbimcli --query-dss-ip-configuration

To set DSS IP packet filters:

mbimcli --set-dss-ip-packet-filters="session-id=0,packet-filter=0x1,packet-mask=0xFF"

To query DSS provisioned contexts:

mbimcli --query-dss-provisioned-contexts

To set DSS provisioned contexts:

mbimcli --set-dss-provisioned-contexts="context-id=1,context-type=ipv4,apn=internet"
