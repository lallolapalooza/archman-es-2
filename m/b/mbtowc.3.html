mbtowc(3) Manual de funciones de biblioteca mbtowc(3)

NOMBRE

mbtowc - convertir una secuencia multibyte a un carácter ancho

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <stdlib.h>
int mbtowc(size_t size;
           wchar_t *restrict pwc, const char s[restrict size],
           size_t size);

DESCRIPCIÓN

El caso principal de esta función es cuando s no es NULL y pwc no es NULL. En este caso, la función mbtowc() inspecciona como máximo size bytes de la cadena multibyte que comienza en s, extrae el siguiente carácter multibyte completo, lo convierte a un carácter ancho y lo almacena en *pwc. Actualiza un estado de cambio interno conocido solo por la función mbtowc(). Si s no apunta a un byte nulo ('\0'), devuelve el número de bytes que se consumieron de s, de lo contrario, devuelve 0.

Si los size bytes que comienzan en s no contienen un carácter multibyte completo, o si contienen una secuencia multibyte inválida, mbtowc() devuelve -1. Esto puede suceder incluso si size >= MB_CUR_MAX, si la cadena multibyte contiene secuencias de cambio redundantes.

Un caso diferente es cuando s no es NULL pero pwc es NULL. En este caso, la función mbtowc() se comporta como se describió anteriormente, excepto que no almacena el carácter ancho convertido en memoria.

Un tercer caso es cuando s es NULL. En este caso, pwc y size se ignoran. La función mbtowc() restablece el estado de cambio, conocido solo por esta función, al estado inicial, y devuelve un valor distinto de cero si la codificación tiene un estado de cambio no trivial, o cero si la codificación no tiene estado.

VALOR DE RETORNO

Si s no es NULL, la función mbtowc() devuelve el número de bytes consumidos que comienzan en s, o 0 si s apunta a un byte nulo, o -1 en caso de fallo.

Si s es NULL, la función mbtowc() devuelve un valor distinto de cero si la codificación tiene un estado de cambio no trivial, o cero si la codificación no tiene estado.

ATRIBUTOS

VERSIONES

Esta función no es segura para subprocesos. La función mbrtowc(3) proporciona una mejor interfaz para la misma funcionalidad.

ESTÁNDARES

C11, POSIX.1-2008.

HISTORIA

POSIX.1-2001, C99.

NOTAS

El comportamiento de mbtowc() depende de la categoría LC_CTYPE de la configuración regional actual.
