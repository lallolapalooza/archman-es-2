MBTOWC(3P) Manual de Programador POSIX MBTOWC(3P)

PROLOG

Esta página del manual es parte del Manual de Programador POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual de Linux correspondiente para obtener detalles del comportamiento en Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

mbtowc — convertir un carácter a un código de carácter ancho

SINOPSIS

#include <stdlib.h>
int mbtowc(wchar_t *restrict pwc, const char *restrict s, size_t n);

DESCRIPCIÓN

La funcionalidad descrita en esta página de referencia está alineada con el estándar ISO C. Cualquier conflicto entre los requisitos descritos aquí y el estándar ISO C es no intencional. Este volumen de POSIX.1‐2017 se remite al estándar ISO C.

Si s no es un puntero nulo, mbtowc() determinará el número de bytes que constituyen el carácter apuntado por s. Luego determinará el código de carácter ancho para el valor de tipo wchar_t que corresponde a ese carácter. (El valor del código de carácter ancho correspondiente al byte nulo es 0.) Si el carácter es válido y pwc no es un puntero nulo, mbtowc() almacenará el código de carácter ancho en el objeto apuntado por pwc.

El comportamiento de esta función se ve afectado por la categoría LC_CTYPE de la configuración regional actual. Para una codificación dependiente del estado, esta función se coloca en su estado inicial mediante una llamada para la que su argumento de puntero a carácter, s, es un puntero nulo. Las llamadas posteriores con s distinto de un puntero nulo harán que el estado interno de la función se altere según sea necesario. Una llamada con s como puntero nulo hará que esta función devuelva un valor distinto de cero si las codificaciones tienen dependencia de estado, y 0 en caso contrario. Si la implementación emplea bytes especiales para cambiar el estado de desplazamiento, estos bytes no producirán códigos de carácter ancho separados, sino que se agruparán con un carácter adyacente. Cambiar la categoría LC_CTYPE hace que el estado de desplazamiento de esta función no se especifique. Se examinarán como máximo n bytes del arreglo apuntado por s.

La implementación se comportará como si ninguna función definida en este volumen de POSIX.1‐2017 llamara a mbtowc().

La función mbtowc() no necesita ser segura para subprocesos.

VALOR DE RETORNO

Si s es un puntero nulo, mbtowc() devolverá un valor distinto de cero o 0, si las codificaciones de caracteres tienen o no, respectivamente, codificaciones dependientes del estado. Si s no es un puntero nulo, mbtowc() devolverá 0 (si s apunta al byte nulo), o devolverá el número de bytes que constituyen el carácter convertido (si los siguientes n o menos bytes forman un carácter válido), o devolverá -1 y establecerá errno para indicar el error (si no forman un carácter válido).

En ningún caso el valor devuelto será mayor que n ni el valor de la macro {MB_CUR_MAX}.

ERRORES

La función mbtowc() fallará si:

EILSEQ
Se detecta una secuencia de caracteres inválida. En la configuración regional POSIX, un error de [EILSEQ] no puede ocurrir ya que todos los valores de byte son caracteres válidos.
