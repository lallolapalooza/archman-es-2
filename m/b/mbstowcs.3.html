mbstowcs(3) Manual de Funciones de Biblioteca mbstowcs(3)

NOMBRE

mbstowcs - convertir una cadena multibyte a una cadena de caracteres anchos

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <stdlib.h>
size_t mbstowcs(size_t dsize;
                wchar_t dest[restrict dsize], const char *restrict src,
                size_t dsize);

DESCRIPCIÓN

Si dest no es NULL, convierte la cadena multibyte src a una cadena de caracteres anchos comenzando en dest. Se escriben como máximo dsize caracteres anchos en dest. La secuencia de caracteres en la cadena src comenzará en el estado de cambio inicial. La conversión puede detenerse por tres razones:

•
Se ha encontrado una secuencia multibyte inválida. En este caso, se devuelve (size_t) -1.
•
Se han almacenado dsize caracteres anchos no L'\0' en dest. En este caso, se devuelve el número de caracteres anchos escritos en dest, pero el estado de cambio en este punto se pierde.
•
La cadena multibyte se ha convertido completamente, incluido el carácter nulo de terminación ('\0'). En este caso, se devuelve el número de caracteres anchos escritos en dest, excluyendo el carácter ancho nulo de terminación.

Si dest es NULL, se ignora dsize y la conversión continúa como se describió anteriormente, excepto que los caracteres anchos convertidos no se escriben en memoria, y que no existe límite de longitud.

Para evitar el caso 2 anterior, el programador debe asegurarse de que dsize sea mayor o igual que mbstowcs(NULL,src,0)+1.

El programador debe asegurarse de que haya espacio para al menos dsize caracteres anchos en dest.

VALOR DE RETORNO

El número de caracteres anchos que componen la parte convertida de la cadena de caracteres anchos, sin incluir el carácter ancho nulo de terminación. Si se encontró una secuencia multibyte inválida, se devuelve (size_t) -1.

VERSIONES

ESTÁNDARES

C11, POSIX.1-2008.

HISTORIA

POSIX.1-2001, C99.

NOTAS

El comportamiento de mbstowcs() depende de la categoría LC_CTYPE de la configuración regional actual.

EJEMPLOS

El siguiente programa ilustra el uso de mbstowcs(), así como algunas de las funciones de clasificación de caracteres anchos. Una ejecución de ejemplo es la siguiente:


$ ./t_mbstowcs de_DE.UTF-8 Grüße!
Longitud de la cadena fuente (excluyendo terminador):
    8 bytes
    6 caracteres multibyte
La cadena de caracteres anchos es: Grüße! (6 caracteres)
    G alpha mayúscula
    r alpha minúscula
    ü alpha minúscula
    ß alpha minúscula
    e alpha minúscula
    ! !alpha

Fuente del programa

#include <locale.h>
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <wchar.h>
#include <wctype.h>
int
main(int argc, char *argv[])
{
    size_t mbslen;      /* Número de caracteres multibyte en la fuente */
    wchar_t *wcs;       /* Puntero a la cadena de caracteres anchos convertida */
    if (argc < 3) {
        fprintf(stderr, "Uso: %s <locale> <cadena>\n", argv[0]);
        exit(EXIT_FAILURE);
    }
    /* Aplicar la configuración regional especificada.  */
    if (setlocale(LC_ALL, argv[1]) == NULL) {
        perror("setlocale");
        exit(EXIT_FAILURE);
    }
    /* Calcular la longitud necesaria para contener argv[2] convertido a
       una cadena de caracteres anchos.  */
    mbslen = mbstowcs(NULL, argv[2], 0);
    if (mbslen == (size_t) -1) {
        perror("mbstowcs");
        exit(EXIT_FAILURE);
    }
    /* Describir la cadena fuente al usuario.  */
    printf("Longitud de la cadena fuente (excluyendo terminador):\n");
    printf("    %zu bytes\n", strlen(argv[2]));
    printf("    %zu caracteres multibyte\n\n", mbslen);
    /* Asignar una cadena de caracteres anchos del tamaño deseado.  Añadir 1
       para permitir el carácter ancho nulo de terminación (L'\0').  */
    wcs = calloc(mbslen + 1, sizeof(*wcs));
    if (wcs == NULL) {
        perror("calloc");
        exit(EXIT_FAILURE);
    }
    /* Convertir la cadena de caracteres multibyte en argv[2] a una
       cadena de caracteres anchos.  */
    if (mbstowcs(wcs, argv[2], mbslen + 1) == (size_t) -1) {
        perror("mbstowcs");
        exit(EXIT_FAILURE);
    }
    printf("La cadena de caracteres anchos es: %ls (%zu caracteres)\n",
           wcs, mbslen);
    /* Ahora inspeccionar las clases de los caracteres en
       la cadena de caracteres anchos.  */
    for (wchar_t *wp = wcs; *wp != 0; wp++) {
        printf("    %lc ", (wint_t) *wp);
        if (!iswalpha(*wp))
            printf("!");
        printf("alpha ");
        if (iswalpha(*wp)) {
            if (iswupper(*wp))
                printf("upper ");
            if (iswlower(*wp))
                printf("lower ");
        }
        putchar('\n');
    }
    exit(EXIT_SUCCESS);
}
