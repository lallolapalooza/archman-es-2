MBIM-NETWORK(1) Comandos de usuario MBIM-NETWORK(1)

NOMBRE

mbim-network - Gestión de red simple para dispositivos MBIM

SINOPSIS

mbim-network [OPCIONES] [DISPOSITIVO] [COMANDO]

DESCRIPCIÓN

Gestión de red simple para dispositivos MBIM

Comandos:

start
Iniciar conexión de red
stop
Detener conexión de red
status
Consultar el estado de la conexión de red

OPCIONES

--profile=[RUTA]
Usar el perfil en la ruta especificada
--help, -h
Mostrar opciones de ayuda
--version
Mostrar versión

Notas:

1) [DISPOSITIVO] se proporciona como la ruta completa al dispositivo de carácter cdc-wdm, por ejemplo:
/dev/cdc-wdm0
2) El script mbim-network requiere un perfil para funcionar. A menos que se especifique explícitamente con `--profile', se asume que el archivo está disponible en la siguiente ruta:
/etc/mbim-network.conf
3) El APN a utilizar debe configurarse en el perfil, de la siguiente manera (por ejemplo, asumiendo que el APN se llama 'internet'):
APN=internet
4) Se pueden proporcionar cadenas opcionales de nombre de usuario/contraseña del APN de la siguiente manera:
APN_USER=usuario APN_PASS=contraseña
5) Si se especifica el nombre de usuario/contraseña del APN, también se debe especificar el protocolo de autenticación a utilizar (uno de PAP, CHAP o MSCHAPV2) de la siguiente manera:
APN_AUTH=protocolo
6) Si desea indicar al script mbim-network que utilice la configuración de mbim-proxy, puede hacerlo configurando la siguiente línea en el perfil:
PROXY=yes
7) Una vez que el script mbim-network informe de una conexión exitosa, todavía deberá ejecutar un cliente DHCP en la interfaz de red WWAN asociada.
