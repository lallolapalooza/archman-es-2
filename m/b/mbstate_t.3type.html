mbstate_t(3type) mbstate_t(3type)

NOMBRE

mbstate_t - estado de conversión de caracteres multibyte

BIBLIOTECA

Biblioteca estándar de C (libc)

SINOPSIS

#include <wchar.h>
typedef /* ... */  mbstate_t;

DESCRIPCIÓN

La conversión de caracteres entre la representación multibyte y la representación de caracteres anchos utiliza un estado de conversión, de tipo mbstate_t. La conversión de una cadena utiliza una máquina de estados finitos; cuando se interrumpe después de la conversión completa de un número de caracteres, puede ser necesario guardar un estado para procesar los caracteres restantes. Dicho estado de conversión es necesario para codificaciones como ISO/IEC 2022 y UTF-7.

El estado inicial es el estado al principio de la conversión de una cadena. Hay dos tipos de estado: el que utilizan las funciones de conversión de multibyte a caracteres anchos, como mbsrtowcs(3), y el que utilizan las funciones de conversión de caracteres anchos a multibyte, como wcsrtombs(3), pero ambos caben en una mbstate_t, y ambos tienen la misma representación para un estado inicial.

Para codificaciones de 8 bits, todos los estados son equivalentes al estado inicial. Para codificaciones multibyte como UTF-8, EUC-*, BIG5 o SJIS, las funciones de conversión de caracteres anchos a multibyte nunca producen estados no iniciales, pero las funciones de conversión de multibyte a caracteres anchos como mbrtowc(3) sí producen estados no iniciales cuando se interrumpen a mitad de un carácter.

Una forma posible de crear una mbstate_t en estado inicial es establecerla a cero:


mbstate_t state;
memset(&state, 0, sizeof(state));

En Linux, lo siguiente también funciona, pero puede generar advertencias del compilador:


mbstate_t state = { 0 };
